## Build / Formalization Attempt
**Lemma (Residual Core Size, RESTRICTED).**  
Let G be a linear-size expander, c a consistent parity charge, B a set of Θ(N) free variables, and Q(B) an arbitrary exact-(2,2)-CNF-3 formula. Let F = Tseitin(G,c) ∧ Q(B). Gaussian elimination over GF(2) on the affine shell produces an equisatisfiable residual instance R whose CNF encoding length is Θ(|Q|) = Θ(N) whenever Q is not linearly reducible. Any black-box invocation of A on R therefore incurs time at least |R|^{K+o(1)} = N^{K+o(1)}, which for K≥2 exceeds the local-work budget N^{1.1+o(1)} on a single call. Multiple calls or adaptive strategies cannot reduce the residual description size below Θ(N) without additional semantic work charged to the parent.

Status: PROVED under the black-box residual model; does not yet yield the universal contraction.
