### Proposed Mechanisms (Falsifiable)
1. **Contractive decomposition for arbitrary \(K\)**: Formalize an A-dependent reduction generating \(\le N^{1-\lambda+\zeta+o(1)}\) children of length \(\le N^{\lambda+o(1)}\) (\(\lambda=1/(5K)\), \(\zeta=0.1\)) with local work \(N^{1.1+o(1)}\) and live space \(N^{0.2+o(1)}\). **Status: OPEN**. Requires charging discovery, construction, access, verification, and combination costs uniformly.
2. **Semantic core extraction**: After affine/XOR/Gaussian elimination on Tseitin-like shells, reduce to a non-affine core \(Q(B)\) whose SAT status is equivalent, with linear witness reconstruction. The core remains NP-complete; an A-dependent method must handle it without parent-sized calls. **Status: OPEN**.
3. **Adaptive UNSAT certificate coverage**: Under the near-boundary seed \(T_A \le N^{1.802+o(1)}\), \(S_A = N^{o(1)}\), seek a co-nondeterministic companion below \(\approx 1.8018\) via short certificates. Universal low-cost coverage for all inputs is missing. **Status: CONDITIONAL / OPEN**.
4. **One-sided abstractions**: Sound projections \(R_B(z)\) such that UNSAT(\(G\)) \(\implies\) UNSAT(\(F\)), checked via inexpensive proof-carrying rules. Minimal UNSAT formulas may resist proper-subformula contexts. **Status: OPEN**.

### Strongest Current Result
No new unconditional implication from arbitrary polynomial SAT solver to a forbidden resource profile. Best published lower bounds remain those of Williams / Buss–Williams; they are insufficient for full P \(\neq\) NP because high-degree polynomial solvers with polynomial space evade them.

### Remaining Gap
Prove or refute a universal resource-contracting transformation valid for every fixed polynomial-time SAT algorithm \(A\), accounting for all overheads, that forces a simultaneous \((t', s')\) inside a known forbidden region (e.g., \(t' < 1.3\), \(s' < 0.2\) or the Williams region).

### Next Decisive Lemma

Correctness must hold for adaptive and state-dependent solvers.
