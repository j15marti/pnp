\section*{Open Implication for ARC/FLMV Contraction (2026-11-04)}

\begin{quote}
\textbf{Status:} OPEN. P versus NP remains open.
\end{quote}

Assume there exists a fixed, correct, uniform deterministic SAT solver \(A\) such that on inputs of encoded length \(N\),
\[
T_A(N) \le N^{K+o(1)}, \qquad S_A(N) \le N^{L+o(1)}
\]
for some finite constants \(K,L \ge 2\).

The Fortnow–Lipton–van Melkebeek–Viglas tradeoff (and subsequent improvements) excludes certain simultaneous resource pairs \((t,s)\) in the indexed-input random-access Turing-machine model. In particular, pairs satisfying
\[
s < \beta(t) = \frac{\frac{t+2}{t^2}-t}{2}
\]
lie in a forbidden region (subject to the precise machine-model hypotheses of the cited theorems).

\paragraph{Missing universal implication.}
A transformation \(\Phi\) (depending on \(A\)) is required such that, for every CNF formula \(F\) of length \(N\), \(\Phi(A,F)\) produces a collection of child instances \(F_i\) with the following fully charged properties:
\begin{itemize}
\item number of children \(\le N^{1-\lambda+\zeta+o(1)}\),
\item each child length \(\le N^{\lambda+o(1)}\),
\item total local work (discovery, construction, access, verification, combination) \(\le N^{1.1+o(1)}\),
\item peak live parent space \(\le N^{0.2+o(1)}\),
\end{itemize}
where \(\lambda = 1/(5K)\) and \(\zeta = 0.1\). Correctness must be preserved: \(F\) is satisfiable if and only if at least one (or all, according to the chosen semantics) of the children is satisfiable, and the transformation must be realizable on the same machine model without external oracles.

If such a \(\Phi\) exists for every polynomial \(A\), then the induced simultaneous exponents \((t',s')\) fall strictly inside a forbidden FLMV region, yielding a contradiction. No such fully charged, all-input, same-machine \(\Phi\) is known.

The conditional recurrence
\[
t' \le \max(1.1, 0.6 + t/2), \qquad s' \le \max(0.5, s/2)
\]
possesses the forbidden fixed point \((1.2, 0.5)\), but its realization as a physical transformation remains open.

All claims above are labeled OPEN or RESTRICTED as appropriate. No resolution of P versus NP is asserted.
