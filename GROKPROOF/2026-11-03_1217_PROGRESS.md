#### Restricted Query-Volume Cost Ledger Lemma
**Lemma (RESTRICTED).** Let \(A\) be any correct total SAT decider with \(T_A(N) \le N^{K+o(1)}\) for finite \(K \ge 2\). Any adaptive procedure that correctly decides an arbitrary length-\(N\) exact-(2,2)-CNF-3 instance by issuing \(\Omega(N^\epsilon)\) queries to \(A\) on instances of length \(\ge N/2\), for any fixed \(\epsilon > 0\), must expend total time \(\Omega(N^{1+\epsilon K + o(1)})\) and cannot stay within the local work budget \(N^{1.1+o(1)}\) for any finite \(K \ge 2\). Discovery, simplification, and combination costs are at least linear and do not improve the exponent.

**Proof sketch.** Each query of length \(M \ge N/2\) costs \(M^{K+o(1)} \ge (N/2)^{K+o(1)} = \Omega(N^{K+o(1)})\). With \(\Omega(N^\epsilon)\) such queries the aggregate query cost is \(\Omega(N^{\epsilon + K + o(1)})\), which for \(\epsilon > 0.1/K\) already exceeds \(N^{1.1+o(1)}\); for smaller \(\epsilon\) the linear overheads from residual encoding and combination push the total beyond the budget on positive-density expander families where residual cores remain linear. Correctness requires that failed or inconsistent partial assignments be discarded only after verification, which cannot be free. \(\square\)
