\section{ARC/FLMV Conditional Contraction Attempt}

Assume P=NP, so there exists a uniform deterministic SAT solver A with
\[
T_A(N) \le N^{K+o(1)}, \quad S_A(N) \le N^{L+o(1)}
\]
for some fixed finite K, L \ge 1.

The FLMV forbidden region (in the random-access model) excludes simultaneous
\[
t < \varphi \approx 1.618, \quad s = o(1)
\]
and more generally the curve \(\beta(t)\) as stated in the objective.

\subsection{Proposed Mechanism 1: Self-Reduction via Variable Partitioning}

Partition the n variables of a 3-SAT instance of size N \approx O(n + m) into blocks of size b = N^\lambda with \lambda = 1/(5K).

Generate at most N^{1-\lambda+\zeta+o(1)} subinstances by guessing the boundary literals or using Gaussian elimination on XOR components when present, each of length \le N^{\lambda+o(1)}.

Local work to construct and combine: claimed \le N^{1.1+o(1)} under the assumption that discovery of consistent partial assignments can be done by calling A on smaller instances or by polynomial enumeration of O(1)-width contexts.

This yields an effective time exponent
\[
t' \le \max(1.1, K \cdot \lambda) + o(1) \le 1.3 - \frac{1}{5K}
\]
and space \le N^{0.2+o(1)} if live state is only the current block and a logarithmic number of pointers.

**Status:** CONDITIONAL. The construction of the children without already solving a parent-sized instance remains unproved for arbitrary (non-Horn, non-XOR) 3-SAT. On expander Tseitin formulas the boundary is high-treewidth and Gaussian elimination does not eliminate the hard core.

\subsection{Proposed Mechanism 2: Adaptive Certificate Enumeration}

Under the additional seed T_A \le N^{1.802+o(1)}, S_A = N^{o(1)}, invoke van Melkebeek's two-algorithm incompatibility.

If a co-nondeterministic companion with exponent < 1.8018 exists, contradiction.

For certificate children of max length M \le N^{0.5}, total volume V \le N^b with b < 1.4008, the verification cost satisfies the bound in the objective.

**Status:** OPEN. No universal low-cost certificate system is known that covers all UNSAT instances while remaining verifiable in the required time.

\subsection{Falsification Control}

Any claimed transformation must be tested on:
- Minimal UNSAT formulas (e.g., resolution-hard small instances)
- Exact-(2,2)-CNF-3 instances with expansion
- One-in-three SAT
- Pure Horn and pure 2-SAT (which should not trigger the hard-case path)

If the transformation produces a correct decision on these while claiming resource reduction, the accounting of discovery cost must be explicit.

\section{Conclusion of this cycle}

Strongest new result: explicit statement of the conditional fixed-point recurrence
\[
t' \le \max(1.1, 0.6 + t/2), \quad s' \le \max(0.5, s/2)
\]
whose unique fixed point (1.2, 0.5) lies inside the FLMV forbidden region, but the transformation realizing the recurrence for every input remains OPEN.

Remaining gap: a model-matched, all-input, A-dependent reduction that produces the required child instances with total resource cost below the forbidden curve, without circularly calling A on size-N problems.

Next decisive lemma: prove or refute that for any fixed K there exists \lambda = \Theta(1/K) such that the number of necessary children is N^{1-\lambda+o(1)} and each can be constructed and verified with local work N^{O(1)} independent of the parent time exponent.
