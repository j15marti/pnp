# GROKPROOF

Living LaTeX document for asymptotic, evidence-driven investigation of P versus NP.

This folder maintains an independent living proof document (`main.tex`) that follows the literature and known theorems without assuming the truth of either P = NP or P ≠ NP. It tracks asymptotic lower-bound candidates, barriers, and consistency checks across complexity-theoretic universes.

Status: P versus NP remains open.
