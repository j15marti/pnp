\begin{theorem}[491.1, PROVED/RESTRICTED]
Let \( Q: \mathrm{GF}(2)^n \to \mathrm{GF}(2)^m \) be any vector map whose coordinate functions have algebraic degree at most two, with arbitrary shared input variables and cancellations. Let \( r_s \) be the polar rank of the scalar quadratic \( q_s(x) = s \cdot Q(x) \). For any globally affine vector prediction \( A(x) = Lx + b \),
\[
|\{ x : Q(x) = A(x) \}| \le U(Q) := 2^{n-m} \sum_{s \in \mathrm{GF}(2)^m} 2^{-r_s/2}.
\]
Consequently, any cover of the full domain by \( K \) globally affine predictions requires \( K \ge \lceil 2^n / U(Q) \rceil \). The bound is invariant under invertible affine input changes and invertible linear output recombinations. It recovers the independent-AND case \( U(Q) = 3^g \).
\end{theorem}
