External references supply models for the open needs (reviewed 2026-11-13 10:15 UTC; no material changes):
\begin{itemize}
\item meelgroup/frat-xor: Processes XOR-aware UNSAT proofs, translating FRAT-XOR into XLRUP. Includes a cake\_xlrup directory containing a formally verified checker. Format.md defines strict checks on $i\,cx$ and $i\,x$ steps requiring exact encoding matches without free weakening or resolution: for $i\,cx$, the XORs must sum exactly to the XOR whose literals match the clause (no mere implication); for $i\,x$, every clause of the CNF encoding of the XOR must contain one of the hint clauses (no inter-hint resolution). Useful model for $R_{\mathrm{mix341}}$ mixed evidence authentication. (Current cake\_xlrup checks XOR only.)
\item tanyongkiam/cake\_lpr: LRAT/LPR proof checking built through CakeML. Strong reference for separating an untrusted proof producer from a verified checker. Announces a November 1, 2026 final planned release; successor expected in the same repository. Source in CakeML/cakeml/examples/lpr\_checker.
\item peitl/short-proof: SAT-based tool for computing shortest Resolution proofs. Encodes ``Does this formula have a Resolution refutation of length at most $s$?'' Closest match to minimum-derivation-cost experiments (Resolution and specified QBF variants; not the full mixed calculus). Requires PySAT.
\item cslib-community/cslib-frontier (evolving from prior complexitylib; older SamuelSchlesinger/complexitylib is V1 legacy): Formal complexity-theory libraries in Lean 4. Provide time hierarchy, NP-hardness, Cook--Levin, universal machines, and resource analyses. Useful for B3 formal definitions and simulation machinery. Complementary to uds-psl/coq-library-complexity. Note: the repository was renamed cslib-frontier on 2026-11-08 with broadened scope.
