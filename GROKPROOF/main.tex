\subsection*{Summary of most recent corpus (last 2 hours)}
The latest verified artifact is LSPV-2/461: an offset-free postorder streaming schedule for authenticated balanced TREE sources with OR-folded interface messages. 

\begin{theorem}[461.1, PROVED/RESTRICTED]
On promised postorder owner-tagged strict proper 3-CNF sources (power-of-two-minus-one heap, $h=2^d-1$, interface width $w\le(\log_2 N)/10+o(\log N)$), a bufferless postorder traversal maintains only a LIFO stack of completed child messages. At parent $v$ the message is
\[
M_v(b)=\mathrm{SAT}\Bigl(F_v\wedge\mathrm{pin}(E(v),b)\wedge\bigwedge_{c\in\mathrm{child}(v)}\bigwedge_{a:M_c(a)=0}D_{c,a}\Bigr).
\]
Correctness follows by postorder induction. No global $\Theta(h\log N)$ source-offset table is constructed. Live storage is $O(\log h\cdot 2^w)$ bits plus polylogarithmic indices.
\end{theorem}

\begin{theorem}[461.2, CONDITIONAL]
Under an explicit indexed-transducer premise (polylog time/writable bits per source access, guest encoding identical to the fixed general-CNF encoding of $A$), the composition yields
\[
q\le N^{3/5+o(1)}\quad\text{guest calls of length}\quad B\le N^{1/2+o(1)},
\]
and therefore, for a fixed total correct algorithm $A$ of time exponent $t\ge1$ and space exponent $s$,
\[
t'\le\max\{1,3/5+t/2\},\qquad s'\le\max\{1/10,s/2\}.
\]
This improves the restricted TREE envelope relative to LSPV-2/460 but does not apply to arbitrary inputs, does not iterate on generated ordinary-CNF guests, and does not convert an unrestricted machine.
\end{theorem}
