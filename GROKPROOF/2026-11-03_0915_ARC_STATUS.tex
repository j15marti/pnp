\section{Conditional Numerical Membership (PROVED)}
Assume a uniform deterministic total correct SAT solver \(A\) with
\[
T_A(N) \le N^{K+o(1)}, \qquad S_A(N) \le N^{L+o(1)}
\]
for finite \(K,L \ge 2\). Under the conditional parameters
\[
\lambda = \frac1{5K}, \qquad \zeta = 0.1,
\]
the derived profile
\[
t' \le 1.3 - \frac1{5K}, \qquad s' \le 0.2
\]
lies strictly inside the FLMV forbidden region
\[
s < \beta(t) = \frac12 \Bigl( \frac{t+2}{t^2 - t} - t \Bigr)
\]
for every finite \(K \ge 2\). This is a pure numerical verification and does not construct an algorithm.

\section{Open Lemma (All-Input Resource Contraction)}
\textbf{Status: OPEN.}
Given black-box access to any such \(A\), does there exist a uniform transformation that, on every ordinary \(N\)-bit 3-SAT (or exact-(2,2)-CNF-3) instance \(F\), produces at most
\[
N^{1-\lambda+\zeta+o(1)}
\]
ordinary SAT children each of length at most \(N^{\lambda+o(1)}\), such that \(\operatorname{SAT}(F)\) is recoverable by a local procedure of cost \(N^{1.1+o(1)}\) using live parent space at most \(N^{0.2+o(1)}\), with every ancillary cost (discovery, verification, access, memory allocation, combination) fully charged?

\section{Known Obstacles}
\begin{itemize}
\item Literal clause partitions fail on expander graphs.
\item Affine elimination of Tseitin shells leaves an arbitrary NP-complete residual core \(Q(B)\).
\item Restricted proof-system or circuit bounds do not transfer to unrestricted Turing-machine computation.
\item Pippenger--Fischer simulation incurs an \(O(T\log T)\) overhead that can exhaust available margins.
\end{itemize}

\section{Conclusion}
No unrestricted implication from an arbitrary polynomial-time SAT solver to an impossible simultaneous resource profile has been established. P versus NP remains open.
