\section*{Governance: corpus-wide review and per-run MAIN reconciliation}

\textbf{Effective:} 2026-10-01 11:33 PT.

\textbf{Scope.} This rule applies to every active LSPV-1 through LSPV-5 run in
\texttt{j15marti/pnp}.

\subsection*{Corpus-wide review}

Before substantive new work, each agent must survey the current GitHub repository and review all
materially relevant verified artifacts for its active claim. This includes root
\texttt{main.tex}, governance files, current tasks, the newest and relevant historical MAIN
snapshots, materially relevant reports from all LSPV agents, active causal-branch components
(HEC, CRS--PPC, CCSPC), governance notes, and the code/data/results cited by active claims.
Repository search/history must be used to detect duplicate formulations, contradictions,
superseded assumptions, previously falsified routes, and prior experiments.

A report must state what corpus was reviewed, what was already known, what changed, what was
adopted/rejected/retired, and whether any root-MAIN statement was found stale or overstated.

\subsection*{Root MAIN on every run}

After the standalone report is verified, every successful run must reconcile root
\texttt{main.tex} in the same run.

LSPV-1 through LSPV-4 edit only their marked ownership regions. They must update those regions
to reflect the current verified state of their specialty in light of the total corpus, rather than
merely appending the newest idea. LSPV-5 performs whole-document reconciliation every successful
run and remains final arbiter for cross-agent conflicts.

Every MAIN write must use the current blob revision, reconcile concurrent edits, and be read back
from GitHub. The readback must verify balanced ownership markers, explicit OPEN status while any
load-bearing implication remains open, strict proof-status labels, preservation of falsifications,
and no silent strengthening of results.

\subsection*{Failure semantics}

If a standalone report verifies but the authorized MAIN update fails, the run records a write
failure and is not treated as fully reconciled. The next staggered agent applies the existing
predecessor-recovery protocol. Missing scientific content must never be reconstructed from memory.

\subsection*{Synthesis policy}

LSPV-5 must survey the repository directly rather than relying only on specialist summaries.
Specialist MAIN edits are evidence-bearing inputs, not final authority. LSPV-5 reconciles the
executive summary, proof spine, status tables, barrier ledger, open targets, and references against
the entire verified corpus on every run.

\textbf{Status discipline:} one OPEN load-bearing arrow means $P\neq NP$ is not proved.
