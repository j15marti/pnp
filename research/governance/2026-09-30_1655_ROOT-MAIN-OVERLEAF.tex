\section*{Governance change: canonical root main.tex for Overleaf}

\textbf{Change ID:} ROOT-MAIN-OVERLEAF-20260930-1655

\textbf{Trigger:} The user requested a fixed main.tex location and repair of Overleaf errors.

\textbf{Evidence:} Root main.tex was initially empty and was later populated with a document requiring XeLaTeX through fontspec. The repository instructions still described a dynamically movable main.tex.

\textbf{Old rule:} main.tex may move and agents locate it dynamically.

\textbf{New rule:} the one canonical living document is repository-root main.tex. It must not be moved or duplicated. Overleaf and CI compile this file directly.

\textbf{Compatibility change:} root main.tex is made pdfLaTeX-compatible by removing fontspec and explicit system-font commands and adding standard T1/UTF-8 declarations.

\textbf{Rollback:} revert this commit if the project deliberately returns to XeLaTeX or relocates the living document.

\textbf{Editor:} ChatGPT / LSPV coordination.

\textbf{Supersedes:} dynamic-location governance for main.tex.
