\section*{Change ID}
GITHUB-MIGRATION-2026-09-30-1622

\section*{Scope}
All five active LSPV automations: LSPV-1 Canonical RMV Structure, LSPV-2 Separator Algebra, LSPV-3 Reconstruction Bounds, LSPV-4 Red Team, and LSPV-5 Synthesis.

\section*{Old behavior}
Active reports were written as Google Docs into the LSPV team folder. Repeated blank/approximately 1 KB artifacts were treated as failed prints.

\section*{New behavior}
GitHub repository \texttt{j15marti/pnp} is the canonical active research store. New successful LSPV reports are written directly as UTF-8 XeLaTeX-compatible \texttt{.tex} files into agent-specific folders under \texttt{research/}; synthesis snapshots go to \texttt{research/main/}. Agents read back every created file and verify header/body/sentinel. Empty placeholders are forbidden.

\section*{Reason}
The user explicitly requested migration of recent logs to GitHub and instructed that agents write to GitHub in LaTeX rather than Google Drive. The prior Google Drive workflow also experienced repeated blank-print failures.

\section*{Expected effect}
Version-controlled, directly diffable research logs; fewer blank-print failures; explicit directory separation by agent and research line; easier reproducibility and audit.

\section*{Rollback}
Restore the previous Google Drive write procedures in the five LSPV automation prompts and mark GitHub as archival-only.

\section*{Status}
Migration initiated and active-agent prompts updated. P versus NP remains OPEN.
