## 3. Main new family theorem: two coupled odd-charge systems
Let G_n=C_n square K2, n>=4, simple cubic prism with 2n vertices,3n edges. Each vertex imposes XOR of incident edge variables = charge, one charge1 per block. Encode each parity by its four falsifying-word clauses (width3). Two copies share exactly one edge variable, all others distinct. Removing the chosen edge leaves each prism connected. Thus factor hypergraph is connected, r=6n-1 and m=16n distinct clauses. Each block inconsistent: XOR its vertex equations gives 0=1 since each variable occurs twice within that block, including shared edge. This is Tseitin structure, not an unrestricted hard family.

WIDTH2 REFUSAL: no empty/unit/binary clause RUP against original chart. Zero or one variable assumption cannot force another variable. Two pins in a single scope determine its third variable; in a simple cubic graph, outside that vertex the fixed star edges have distinct other endpoints, leaving at most one fixed incidence per other vertex. If initial pins have no common scope, no local unit. When copies share one variable, any two pins which trigger a local scope in one copy leave at most the shared bit fixed in the other, unless one initial pin is in each block, in which case without the shared pin neither block has two fixed bits; if shared pin and another, exactly one block has two. No contradiction or further propagation. Hence entire width2 pool is at fixed point with no additions for all n, not just bounded search. Exact statement on companion formula; finite compiled native images tested, no claimed all-n normalizer pattern theorem.

CORRECTION RANK: for each clause C define p_C as its Boolean falsity indicator in F2[x]/(x_i^2-x_i). Within a parity scope, four forbidden words disjoint; sum of their indicators is the affine parity violation polynomial. Consider a linear combination of all indicators yielding a polynomial of degree<=1. Distinct scopes intersect in <=1 variable, so any nonlinear monomial belongs to one scope only. Its cancellation must happen within that scope. The remaining affine function of those three variables vanishes on the allowed parity hyperplane, so it is either zero or that scope's unique nonzero affine equation. Thus the four row coefficients at each vertex are either all zero or all one. If the full combination is constant, every nonshared edge's coefficient enforces equality of selections at its endpoints. Each block after deleting shared edge is connected; all its vertex selections equal alpha or beta. Shared edge cancels because each block contributes twice. Constant value=alpha+beta, since each block has odd total charge. Therefore exactly two coefficient masks yield 1: full first block and full second block. Exactly one nonzero coefficient mask yields 0: all rows. Rank P=m-1. This is a statement about linear coefficient reconstruction, not minimum general representation size or proof length.

SKETCH REFUSAL WITH ADVERSARIAL LABEL ASSIGNMENT: H is any binary sketch matrix containing all-ones row, rank h<m-1; rows act on coefficient vector of original indicators. The sketch span contains 1 iff rowspace H contains one of the two full-block masks. Those masks are complementary, so both or neither belong. Balanced masks of weight m/2 span the even-weight subspace of dimension m-1 (m=16n); differences of any two masks that differ by swapping one position give every e_i+e_j. Thus some balanced mask is outside rowspace H, and its complement also outside. Assign labels so that block0 occupies that mask. Polynomial deterministic acquisition: test one balanced mask and all single swaps across its halves; their span already contains even subspace because complete bipartite exchange graph is connected. Each membership by GE, O(m^2) candidates, no oracle. This gives a uniform adversarial label ordering against any such fixed linear sketch (including parity+field labels+cubes with h<=1+2ceil(log2(m+1)) for sufficiently large m). No claim all label orders fail, no claim every sketch must reconstruct all rows. Full linear span correction needs at least rank(P)-rank(HP)>=m-1-h independent row additions; a targeted contradiction can need far fewer. Arbitrary exact correction extraction remains open. Tested label order was a fixed seeded clause permutation, not the adversarial membership construction.

Then GE over all equations across scopes. This recovers contradiction without restoring full linear span. Source-only scope recognition and each row check paid; O(m log m) sorting plus O(m) bounded truth evaluations and polynomial GE/parent reconstruction in original N.
