## 3. Complementary native extension: one-shot streams are already NP-complete
The reason for easy fixed-counter clocks is private progress dimension, not amount of compulsory work. More generally for k independent explicitly recognized deterministic monotone streams with lengths L_a and exact shared modes, product DP has q*product(L_a+1) vertices; for fixed k and clock t all must complete, so each L_a<=t and fixed-k polynomial. For growing k, sum log2(L_a+1) can grow linearly even when each L_a=1. Do not infer tractability from total length alone. Here is an explicit standard U_h extension, not claimed to satisfy counter template.

Take directed graph G on vertices 0..n-1, n>=2. Directed Hamiltonian path is NP-complete (Karp directed circuit Main Theorem #9, split chosen vertex into source with outgoing edges and sink with incoming edges, source indegree0 and sink outdegree0 force endpoints; merge endpoints for reverse). Construct n one-shot private flags as n tape1 cells initially symbol1 (input x=0^n), symbol2 means already consumed. Tape2 blank and stationary always. Start state0, accept1. Canonical IDs: ready(v) for each v, seek(v,r) for 0<=r<=v, return(v), verify; enumerate in fixed order from2. Every record has tape2 read/write0 and direction stay; all other transitions forbidden. Exact catalogue:
- Start at head0: for each v choose stationary edge to seek(v,v), preserving scanned bit1/2.
- Ready(u) head0: choose seek(v,v) iff original edge (u,v) in G, preserving scanned bit. Start/ready also allow stationary choice to verify.
- Seek(v,r), r>0: read1/2, preserve, move right, decrement r.
- Seek(v,0): only read1 allowed; write2, move left to return(v).
- Return(v): read1/2 preserve and move left; at blank preserve, move right to ready(v).
- Verify: read2 move right preserving; blank -> accept; no rule on1.
This is a two-tape native source with only 0->1 changes on encoded flags and no erasure. Invariant head0 at each ready state; selected v reached exactly; repeated vertex cannot be consumed twice; each original edge choice enforced. Verify accepts iff all n flags set, exactly n selections; source prefix list is a directed Hamiltonian path. Conversely every Hamiltonian path lifts to unique canonical physical sequence. Each chosen v costs 1+v+1+v+1=2v+3 steps (choice, seek, mark, left traversal and blank reset), independent of order. Verify costs n+2. Therefore every accepting path has EXACT length
    T(n)=sum_{v=0}^{n-1}(2v+3)+n+2=n²+3n+2.
Choose clock T(n), pad if necessary (for h>=2 N>=T^(1/h)); explicit rules O(n²) and fields O(log n), original encoded N=O(n² log n), polynomial generation including padding. For any graph, YES at clock T iff Hamiltonian path, NO at T-1 even for complete graph. Original rule IDs, flags and actual selected vertex order provide witness map, not an existential abstract relation. Recognize canonical source by extracting original edges from ready(u) to seek(v,v) on sym1, regenerate entire catalogue and compare exact record set; verify x=0^n and framing. This language (recognized source intersect U_h) is in NP by original bounded computation, so NP-complete; no claim P!=NP. Tests use h=4, reduction works all fixed h>=2. This is the first new authenticated NP-complete extension of our private-stream model in this run, not a claim of novel NP-completeness in literature.

**Adversarial scoped lower bound:** For complete digraph without self loops, every nonempty consumed set S and last vertex u in S is reached at a ready seam. There are n*2^(n-1) such seams. Even for fixed u and |S|=k, different S,T have different exact accepting continuation languages over original vertex-choice IDs: list V\S, a valid accepting suffix from S, which repeats some already consumed vertex or omits an unconsumed vertex from T. Thus any representation that enumerates distinct states and preserves the entire set of exact labelled suffix words must have >=binom(n-1,k-1) records at that seam. At middle k this is exponential in n, 2^{Omega(sqrt(N/log N))} in the dense canonical encoding. This is not a lower bound for arbitrary deciders, symbolic DAGs, or even all compressed residual representations: complete graph is immediately YES. A total count and last vertex are insufficient even for existential compatibility across prefixes: graph edges 0->2,1->2,2->1,1->3 (n=4); prefixes 0,2 and 1,2 have same count and last; first extends 1,3 and accepts, second has no valid next unconsumed out-neighbor. Only actual set and continuation constraints justify merge. Subset DP uses exact masks and last; O(n²2^n) elementary edge operations and O(n2^n) states; not a P bound. No reduction from this NP-complete extension to fixed counters supplied. That would be a central unresolved compiler, not an assumed adapter.
