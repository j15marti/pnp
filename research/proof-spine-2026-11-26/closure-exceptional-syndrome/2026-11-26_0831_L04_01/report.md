## 1. Explicit NP decision source
For each FIXED integer h>=2 define U_h. Use ordinary finite-alphabet, locally headed, sequential multitape Turing machines with binary inputs; allow two-way infinite tapes (equivalent to the ordinary model with constant-factor tape overhead for fixed machines). Encode a binary string z by f(z)=1^{|z|}0z. Input w=f(M) f(x) f(bin(t)) 0^p, p>=0, N=|w|. Clock t is a canonical nonnegative binary integer with t<=N^h. M is a list of eight-field transition rules, each field canonically framed; q,a,b,q',a',b',d1,d2. All fields are nonnegative integers in canonical binary; moves 0=left,1=right,2=stay. Two tapes, blank symbol 0, input symbols 1 and 2 for bits 0 and 1, tape 1 initialized with x, tape 2 blank, both heads at origin; state 0 start, state 1 halt accepting. Multiple applicable rules are allowed, no applicable rule rejects, and accepting paths must reach state 1 within t steps. Empty rule lists allowed. No free advice, oracles, succinct expansion or count in the source semantics. All malformed inputs and clocks above cap reject.
Uniform parser: linear scans of self-delimiting fields, binary counters (at most O(log N) bits for lengths), verify clock bit length before computing fixed integer power N^h. O(N polylog N) bit time. For universal verification, store each simulated cell in a padded O(N)-bit block, maintain two actual tape head positions, scan machine table to select and validate one enabled transition nondeterministically, update cells/head and decrement the clock. Conservative O(N^2) per simulated transition, O(N^{h+2}) time, polynomial space; no special fast universal simulator is needed for membership. Hence U_h is in NP for each fixed h.
For any NP language, choose its fixed two-tape nondeterministic acceptor M and polynomial path bound t(m), m=|x|. The two-tape reduction is standard (SFM Lemma 3). Emit w with sufficient zero padding, e.g. p=t(m), and exact binary clock, in polynomial time. Both directions are the definition of accepting path within the bound. Thus U_h is NP-complete under ordinary uniform polynomial many-one reductions, including U_2. This is a family of fixed languages, NOT one source with unbounded exponent h encoded into the input.
Sharper claim: for each fixed h>=2 and each fixed real 1<b<h, U_h is not in NTIME(N^b). Use Seiferas, Fischer, Meyer (1978), Corollary 4.1/4.2 polynomial-gap consequence, on binary inputs and multitape model, to choose H in NTIME(m^h) outside NTIME(m^b). Its fixed two-tape M has accepting path time <=C(m+1)^h on YES. Nonmembers have no accepting path. With p=c(m+1) for a sufficiently large constant c depending on C,h, encode t=C(m+1)^h (round C up to integer) and N=Theta(m+1) with t<=N^h. The reduction is O(m polylog(m+2)) using fixed exponent arithmetic, copying and framing. A hypothetical U_h machine of O(N^b) would decide H nondeterministically in O(m^b), since b>1. Contradiction. The witness H is supplied by the known hierarchy theorem, not claimed to have been enumerated in the audit. The assertion implies the fixed-exponent deterministic lower bound as well, but does not exclude all polynomial exponents for U_h or SAT.

## 2. L04-01A: Positive-transcript simulation with exact suboracle consistency
Let S be ordinary explicit proper signed 3-CNF satisfiability, with canonical bit-encoded literal IDs and clauses; malformed queries outside S. Standard NP-complete language (no compressed circuit query descriptions). Let A be a fixed deterministic adaptive controller with S-oracle, correct on U_h. Define paid work W(N) on its actual computation to include ordinary controller steps, all query materialization and copies, sum of full binary query lengths plus one per call, failure/track management, cache lookup, guards, and output. A query answer costs only the oracle bit in this INTERMEDIATE model; final substitutions below charge the solver. Assume W=O(N^rho), rho<h. Use an explicit clock B(N)=C ceil(N^r) for a rational max(1,rho)<r<h and fixed C covering actual runs, or an integer/rational polynomial clock rounded up. Stop every hypothetical run exceeding B, including altered answer paths. First reject malformed/over-clock source input by the parser; this is a paid wrapper, does not change true labels. Bound time of false paths without assuming any running time for them.
Define U_h^+ = valid w such that this capped A^J accepts w for SOME set J subseteq S. J may depend on w; no claim of a single hard oracle for all w. The actual S path proves U_h subseteq U_h^+.
Construct one ordinary nondeterministic machine B+ for U_h^+: simulate A, guess each oracle answer. For each YES, guess occurrence-level variable bits and verify every clause and consistency of occurrences of each original variable ID. Store exact query word and answer. At accepting halt, compare all repeated query words and reject if two answers differ. Equivalently guess a partial function on actual complete query IDs. No free canonical semantic equivalence: identical strings only, different syntactically equivalent queries may receive different replies under a suboracle J.
If accepted, every YES query is in S, and no query with NO belongs to the finite set J of YES strings. Thus replay with that J yields exactly this adaptive accepting path (induction on calls). Conversely any capped accepting J path has actual SAT witnesses for each YES, repeat consistency, and therefore an accepting branch of B+. This proves both directions, including adaptive queries, and is stronger than accepting independently forged replies for repeated occurrences.
Paid bit implementation: literal occurrence verification uses local clause checks and sorting records by actual identifier; sort exact query-string records once at halt. A fixed-tape external merge sort with variable-length strings can be implemented using delimiter-encoded records: comparison scans up to first difference or end, then rewinds only scanned prefixes; charge comparison length to the emitted (lexicographically smaller or equal) record, since it is at most the shorter length plus header overhead. One merge pass linear in total payload plus O(log B) per record for run counters; O(log B) passes. Thus O(B polylog B) time for all checks, and O(B polylog B) storage with a constant number of tapes. Sum of per-query sort costs bounded by B polylog B. Interleaved controller simulation uses fixed separate tapes; preserve its state while validating, charge copies and clearing traversed cells. Exact counters and timeouts polylog overhead, no free long reads or arbitrary random access. For fixed r choose b with r<b<h; B+ is in NTIME(N^b), all branches clocked. This is nondeterministic verification of an accepting path, NOT a deterministic enumeration of all answer paths. Its witness lengths and all branch verification work are paid. Query grammar/guard parsing included in same budget. On U_h there is no mandated SAT heuristic: initial/after-deduction/stagnation closure is limited to exact parser/clock checks, legal transition checks, verified query clauses and guards; any additional forced-information algorithm is charged to A. A restriction on arbitrary deciders' choice of inference is not assumed.

## 3. L04-01B: Infinite false-negative necessity
PROVED scoped conditional on the existence of a controller A with the above sub-h paid bound. If U_h^+ minus U_h were finite, hardcode that finite exceptional set in B+ and reject it after a linear input check. This would put U_h in NTIME(N^b), contradict section 1. Therefore U_h^+ minus U_h is infinite. Because the parser rejects invalid inputs, these are infinitely many distinct, valid NO instances of the explicit source. On each, a consistent suboracle J subseteq S makes the controller accept, whereas the true S oracle makes it reject. Some true YES reply must have been suppressed along the altered path; every YES on that path is genuinely SAT. This is an existential hard-input statement against each such controller, NOT a single universal suboracle, explicit polynomial-time generator of its mistakes, or unconditional assertion that a sub-h controller exists.
Corollary: a fast deterministic controller robust against every false-negative suboracle on NO inputs is impossible, even if SAT is easy. In particular a uniformly acquired one-query many-one reduction with positive acceptance and fully materialized query plus construction work O(N^rho), rho<h, from U_h to explicit SAT is impossible. This is an unconditional compression restriction for the specified source/grammar, independent of any hypothesized SAT exponent. Positive-only multiple-query/monotone acceptance methods obey the same firewall. It does not rule out complement or nonmonotone adaptive reductions. Direct contradiction proof and constructed B+ are the two complementary methods on the same source.
Falsifier of a stronger claim: a controller may accept a valid input exactly when an explicit UNSAT query returns NO; substituting a false NO for a SAT query can change the answer. Repeated-query inconsistency alone also produces bogus paths, so the suboracle-consistency check is essential. C08 high-degree classifier with small exact Boolean circuit and C02 exponential history/compact Gaussian join are additional warnings that this is not an arbitrary-decider time lower bound.
Certificate refinement: fix any sound ordinary uniform verifier V_-(Q,z) for Q outside S (acceptance implies Q outside S). For every input, try a capped accepting path with every claimed NO justified by a V_- witness and every YES by the above SAT witnesses. Clock the SUM of proof bits, verification, acquisition of query words and transcript work at O(N^r) with r<h, including malformed/timeout checks. All accepted paths coincide with the true oracle path by induction, so this language is a subset of U_h and in NTIME(N^b) for some b<h. If the omitted YES instances were finite, hardcode them and get a contradiction. Thus infinitely many valid YES instances cannot have such a fully budgeted accepting transcript, for ANY fixed sound scheme satisfying the stated total cap, if A is correct and fast. No assertion that all UNSAT queries are hard, or that every decider uses certificates. If other NO cert checks have superlinear overhead, include their actual check/simulation cost in the cap; no free coNP proof system.

## 4. L04-01C: Fully charged adaptive solver-substitution criterion (CONDITIONAL endpoint)
Suppose S in P via one fixed ordinary deterministic multitape decider D of time O((1+ell)^k), k>=1 integer, and let A be a correct controller for U_h on true S paths. Suppose paid ordinary aggregate work plus sum_j(1+ell_j) <= O(N^rho), and max_j(1+ell_j)<=O(N^lambda), where ell_j is actual bit length. Then execute D on each actual query, returning the actual answer (including NO). Preserve A on disjoint tapes and pay copying/clearing, no recomputation of uncharged state. Because
sum_j(1+ell_j)^k <= (max_j(1+ell_j))^(k-1) sum_j(1+ell_j),
the total deterministic time is O(N^rho+N^{rho+(k-1)lambda}), plus parser O(N polylog N), and polylog overhead if required for clock counters. A strict exponent inequality rho+(k-1)lambda<h gives a deterministic and therefore nondeterministic U_h algorithm with some exponent b<h, impossible by section 1. If there are no calls, use direct controller bound. This is an adaptive aggregate generalization of HIERFIRE1 (not a claim that its sufficient speedup budget is necessary for actual specialized algorithms). Both labels, all branches on the actual sequential execution, all failed tracks and all queries are included. Peak storage <= O(N+N^rho+N^{k lambda}) up to polylogs, on the SAME run; cumulative memory <= (T+1)S_peak. This storage bound is not a lower bound or simultaneous independent speedup. Configuration counting only upper bounds halting executions. Query reuse is allowed, but copies/replay/lookup must be charged as applicable. No unrestricted time or space exclusion follows merely from this bookkeeping.
An actual sufficient P!=NP route is: for EVERY integer k>=1, acquire a correct uniform arbitrary-polarity controller (h may depend on k, but each U_h is fixed in NP) with paid rho+(k-1)lambda<h. If SAT had some exponent k, this corresponding controller composed with D would give the incompatible pair above. All k must be covered; an arbitrarily large h family of source lower bounds alone is not a separation. Positive-only controllers of this kind already fail by section 3 (rho<h), so the proposed construction must genuinely exploit nonmonotone polarity or another proved departure. The necessary acquisition is OPEN; ordinary materialized Cook reductions are no such speedup. If a purported compression theorem uses a shared/succinct circuit instead of ordinary explicit query bits, the query language changes and its evaluation/access must be proved separately. No transfer from arithmetic polynomial lower bounds to arbitrary Boolean decisions.
