## 1. Capacitated circulation theorem
Let H be any current source-faithful augmented residual on M vertices; nonempty proper separator S. Partition vertices into singleton blocks for S and SCC blocks of H-S, retaining original vertex lists. For block B, let mu(B,D) denote maximum bipartite matching of actual original arcs from tails in B to heads in D, computed by augmenting paths; certify exact maximum with matching and same-size vertex cover. Set d(B)=1 for singleton separator blocks, and d(B)=max(1,|B|-mu(B,B)) for remaining blocks.

Construct split-node directed network: each block B has B_in -> B_out with lower bound d(B), upper |B| (for S this is exactly1). Each distinct pair B,D has B_out -> D_in with lower0, upper mu(B,D); omit zero-capacity arcs. Basic lane instead uses lower1 at all blocks and actual arc count as interblock upper bound. No intra-block flow edge except split. Any Hamiltonian cycle H projects to a circulation: count selected crossing arcs, incoming=outgoing at each block. All proper nonempty blocks require at least one crossing. Internal selected arcs form a matching, so outgoing count >= |B|-mu(B,B). Across a pair, selected arcs are a matching, so count <=mu(B,D). Counts <=|B|. Hence failure of this relaxation is sufficient for native NO, not conversely. No free simultaneous realizability of the independently attained pair maxima is assumed. Feasible circulation is NOT a Hamiltonian witness.

Lower bounds reduction: subtract l from each arc, residual capacity u-l. b(v)=lower inflow minus lower outflow; add source->v cap b(v) if positive and v->sink cap -b(v) if negative. Feasible iff all source demand saturated, by conservation and reverse adding l. If maxflow deficient, reachable original nodes U in final residual give l(delta^-(U))>u(delta^+(U)); derive directly by moving lower outflow across residual cut. This is a checkable Hoffman inequality and contradicts equal in/out flow. Matching covers verify upper capacities and lower demands from original graph, not supplied labels. Integral capacities and integral augmentation give integral projected solution whenever real feasible. Total demand <=sum_B d(B)<=M, so BFS augmentations at most M, no dependence on exponential numeric capacities. Basic circulation implies SCC-chain width<=|S|: decompose integral flow into directed cycles, every cycle hits S since quotient on non-S blocks is DAG; split at singleton S vertices, at most |S| directed chains cover all non-S blocks (repeat occurrences across paths can be removed from all but one assigned chain using reachability). Therefore basic is at least as strong as L04-15 width on same S. Tightened bounds and matching closure are stronger relaxations, not exact HC. Strong connectivity separately necessary, S empty not treated as ordinary circulation.
