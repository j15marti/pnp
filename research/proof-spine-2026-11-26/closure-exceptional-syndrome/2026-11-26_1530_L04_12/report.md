## 1. Exact phase charges remove a state coordinate

Include all such edges, even if actual carry occurrence unavailable at a particular index; this overapproximation only imposes a stronger admission condition. Compute reachable SCCs from mode0 by paid graph traversal. In an SCC C, suppose all cycles have ratio p/r>0, equivalently weight delta(A)=-p, delta(B)=r sums to zero on every directed cycle. Then there is an integer potential H with H(v)-H(u)=delta for each internal edge: choose root and path root->v; append a fixed return path to root, so all root->v paths have equal charge. Conversely telescoping yields zero cycles. Acquire by testing p,r in [1,q] and graph propagation/verification, all candidates charged. A simple cycle has length<=q and supplies candidate counts if positive ratio works. Singleton without self-loop admits any p,r, algorithm may refuse an accidentally equal chosen slope (safe UNKNOWN, not claimed maximal admission). Potential differences bounded by (q-1)max(p,r).

For an intra-SCC path beginning at actual coordinate (a,b), mode u, let local counts (x,y), layer k=x+y. At mode v,
    r y-p x=H(v)-H(u)
    x=(r k-H(v)+H(u))/(p+r), y=k-x.
Thus each pair (k,v) determines a UNIQUE physical coordinate, or is infeasible if the quotient is not integer. This is stronger than L04-11 approximate strip width: there is no independent lag coordinate in transfer matrices, only actual mode. No marginal support substitution; the coordinate still has to be attained by actual matrix products.

## 3. Two distinct slopes give an exact affine interface
