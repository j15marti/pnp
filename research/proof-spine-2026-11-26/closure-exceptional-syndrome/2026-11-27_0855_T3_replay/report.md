## 2. Named lemma: RECIPROCAL-ANCESTRY-PULLBACK
Original target 29, five nonzero planes with basis pairs (15,32),(13,17),(14,36),(11,53),(10,39), ambient six bits. For any finite explicit iterated zero-private-target reciprocal lift of this SAME atom and any extra affine guard on final owner coefficients, the exact set of root witnesses and lifted witnesses is bijective via an acquired binary linear map P. The rank of the pulled-back extra guard is at most ten, independent of the number of lifted owners. Reject malformed history rather than infer semantics from support. N = full explicit bit length including history, target, guards and original ID references; tables below report dense matrix+target payload only.

Proof: replace span(u,v) by span(a,b+u), span(b,a+v), fresh private a,b. Let (alpha1,beta1),(alpha2,beta2) be child coefficients. Private-zero forces alpha1=beta2, alpha2=beta1. Parent coefficients x=(beta1,beta2); children equal ((x2,x1),(x1,x2)). Both child pairs are nonzero iff parent pair is nonzero. All original shared contributions equal x1*u+x2*v. This is an exact bijection. Iteration applies newest fresh-zero equations first; inductively older fresh coordinates still zero. Therefore P consists of coordinate selectors (duplication and permutation) on original ten bits, full column rank. For any G,h, G y=h iff GP x=h. Combine Hx=t with GPx=h, test all 243 root legal words, lift via P and verify original leaves and guards. If t=29 no legal word exists; extra guards cannot create one. Other targets used only as correctness controls. Supports are actual, not affine hulls. Any extra nonlinear guard needs its own paid checker; not covered. Arbitrary shared target wires, independently chosen roots and nonzero fresh coordinates are not covered.

Constructive lane: 243-word enumeration with explicit ancestor map. Global lane: XOR convolution DP on 64 states independently recovers exact support and multiplicities; GE can reduce pulled-back guards. Adversarial lane: direct original-coordinate sums and every coordinate response from P, compare all root words; kernel differences at target 0 exhaust 16 values, independently confirming T2's linear-recovery obstruction (not a decision lower bound). Integrated exact replay with verified source map, no unproved conditional facts. Certified initial/after-import closure is private cancellation; no semantic closure oracle. Replicas sequentially executed, not separate agents or equal measured bit-clock benchmarking. Falsifiers: wrong private-zero map, spurious source witness, guard losing correlation, history mismatch. Proof excludes first three in admitted family; history checked by exact regeneration in algorithm, experiment constructs history directly.

Costs: with supplied explicit history, process each owner once and compare explicit vectors/IDs. Construct P by propagating root selectors, multiply G by P via XOR (each row of P one-hot), check each of 243 root words and actual lifted coefficients. Conservative O(N^3) bit-RAM work and O(N^2) live bits including reading, index operations, failed guard checks, reconstruction and exact verification, no attention/GE oracle needed. On sequential execution CM<= (T+1)S. Serial TM simulation polynomial by explicit scans, not same exponent. No free ancestry discovery or guarantee all residuals admit history. B. Exact soft comparison: encode each map in positional w-bit words. Compute paired XOR bits, OR by balanced binary tree, or integer Hamming sum then zero test. O(N) Boolean gates after extraction and O(log N) depth; exact uniform indexing, O(log N) accumulator bits, no collision/hash/real oracle. Uniform averaging of nonnegative binary mismatches has zero iff all match; use exact rational sum with denominator equal to number of positions, not uncertified floating softmax. This is a legal free-model comparator, no need to prove specific neural architecture realizes every operation because direct random access suffices. If independent compressed representations must each encode every possible permutation injectively for exact equality, log2(r!) bits necessary by collision, but this is communication/representation complexity not sequential crossing cost.

C. Correct replay theorem: fixed deterministic schedule with explicit polynomial-size data, a fixed poly-time transition family and at most polynomial many events has polynomial total replay work. More generally if original trace cost T, live bits S, collect q requested events in one forward pass with polynomial lookup overhead and output q*B bits for B-bit events. Bound O(poly(T+N)+q*poly(B+log(T+2))) with actual storage charged. Repeating prefix at every request incurs q*T overhead; no free regeneration. Polynomial number of residuals does not imply same O(N^2) bound, even output can exceed it. A deterministic function of input is not necessarily efficiently computable: take L in EXP minus P (deterministic time hierarchy), encode k input bits by independent adjacent swaps of a permutation on 2k+2 elements; diagonal source length O(k log k). Define a residual bit as L of decoded bits. It is a deterministic total function (extend by zero off this family), but polynomial replay of that bit on every encoded diagonal implies L in P. This falsifies the unrestricted pure-function evaluation implication, not a compulsory decision obligation: an exact source decider can ignore that residual and answer NO via equality. Arbitrary external sources are not necessary for computational nonrecoverability; they are outside this deterministic model.
