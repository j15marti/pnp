## A. Exact band transfer (constructive)
Two m-bit counters start at little-endian values n_A,n_B in [0,2^m-1]. Each increment must complete as an atomic physical macro before the other counter moves. Finite shared mode set size q; arbitrary exact nonnegative weighted relations for each counter's carry type r=0..m-1 and overflow type m. These are M^A_r,M^B_r, each q-by-q with infinity for unattainable transitions. Each finite entry is an attained minimum, preserving actual endpoints. Let L_A=2^m-n_A,L_B=2^m-n_B (including final overflow); A_i=M^A_{v2(n_A+i+1)} for 0<=i<L_A-1, A_{L_A-1}=M^A_m, analogously B_j. Here v2(x) is trailing-zero count for positive x. For a normal increment, A^r B C^r D with actual rule names as in L04-08; overflow A^m E. Single-stream suffix products acquired by the carry grammar W_k=W_(k-1)(k-1)W_(k-1), W_0 empty; suffix by comparing high bit, using stored W_j products, append overflow.

Native scheduling guard: while neither counter is done, a complete macro advances exactly one count i or j, and the next endpoint must obey |i-j|<=w; this includes the first completion. After one finishes, other can drain without lag guard. Numeric w>=1, w<=poly(N), not merely its binary bit length. All allowed sequences respecting this physical band and the actual shared-mode transitions, not a restriction imposed on an arbitrary machine. Accept at both done in a permitted mode, with final terminal costs. Min-plus is exact for consecutive macros: minimize over identical actual intermediate mode/physical coordinates; finite product entries attained. If L_A>L_B exchange names (mode initial and terminal unchanged).

Sweep by A-index i. Within one row, B increments can only increase j. Any path from just after previous A macro to just after next A macro uniquely consists of zero or more B macros then one A macro. At interior row i store states (d,u), d=j-i in [-w,w], u shared mode. Dimension D=q(2w+1). For d<=e+1<=w and e>=-w, define row matrix entry (d,u)->(e,v) as
    [ B_(i+d) tensor ... tensor B_(i+e) tensor A_i ]_(u,v),
where B product is empty when e+1=d; all other entries infinity. e denotes next row offset, so before A the j-offset is e+1. This retains ALL allowed B-only steps in row then A; not one guessed alignment. Boundaries j>=0 and no overflow in interior checked below. Product over rows minimizes over every actual compatible seam; no independent marginal minimization.

Put K=L_A-w-1. If K>w: handle initial i=0..w-1 explicitly, central rows i=w..K-1 by compressed matrix product, then i=K..L_A-1 explicitly. In central rows 0<=i-w and i+w<=L_A-2<=L_B-2, so both schedules still unfinished and every A/B used in the matrix is a normal increment. At initial/final explicit rows use j restricted to [0,L_B-1] and band, dynamic B closure in increasing j then A successor. If B or A finishes on an edge, immediately multiply by the other stream's exact suffix from that actual index and final acceptance cost; minimize all such first-completion possibilities. At most O(w) initial/final rows, O(w^2) actual band locations, O(w^2) possible tail queries; if K<=w then L_A<=2w+1, process all rows explicitly. This handles unequal counts and early completion with no phantom overflow. The macro grid is acyclic; decomposition partitions every accepting schedule at the actual first completion and conversely lifts every finite term. Thus both directions exact.

## B. Dyadic signature compression (global)
A central row depends only on v2(n_A+i+1) and v2(n_B+i+d+1) for -w<=d<w, plus fixed q,w and the source macro tables. Decompose central row interval [w,K) into O(m+1) aligned dyadic blocks [a,a+B), B=2^k, a divisible by B; greedily choose maximal fitting aligned block (or ordinary binary interval tree). All evaluated arguments positive and <2^m by interior guard.

Consider B>2w. For arguments from A, the interval n_A+a+1..n_A+a+B contains exactly one multiple of B. For B-side arguments as d varies, the union lies in n_B+a-w+1..n_B+a+B+w-1, span B+2w-2<2B; hence at most two multiples of B. Residues modulo B of every argument depend only on k, fixed n_A,n_B,w, and relative position in block, not a. If residue nonzero, valuation is determined by residue. If zero, value equals one of those at most three actual multiples and its valuation is in {0,...,m-1}. Their relative positions/order depend only on k and fixed offsets (aligned a), so a signature (k, ordered valuations of the A multiple and B multiples) determines the ENTIRE row-matrix word. No assertion that min-plus matrices commute. There are O((m+1)^3) signatures per level and O((m+1)^4) across all levels. Compute block products by recursively splitting in half, memoizing signature and storing first concrete representative's original interval; same signature implies same sequence exactly. When B<=2w expand at most 2w rows, not the full schedule. There are O((m+1)^4) large memo nodes, at most two child calls per new node and O(m) roots, so small leaf evaluations O((m+1)^4(w+1)). Signature acquisition uses actual binary ceil-division by power of 2, at most 3 valuations, O(poly(m,log(w+2))) bit work; no exponential discovery or free equality oracle. Fixed count of shift clusters (one A, one B interval), not one exponent per offset. This is stronger than enumerating signatures of all 2w+1 coordinates separately. Repeated blocks are shared as a DAG; computing products never expands an enormous interval. For q,w,m<=poly(N), finite weights have polynomial bit lengths (for native unit moves, total finite cost <=O(qm2^m+setup)), so evaluation is uniform polynomial.

Independent width-one recurrence: any admissible unfinished path at equal counts must execute exactly one macro of each stream (either A_i B_i or B_i A_i) before next equal counts, except at first completion; shorter stream A finishes on final paired round and longer drains. Even if A finishes first in the last pair, grouping the first B tail macro in the pair is exact, as B has at least as many macros. Therefore exact product over i=0..L_A-1 of (A_i tensor B_i) pointwise-min (B_i tensor A_i), then suffix of B from L_A. For initial normal pairs the same dyadic reasoning needs only two exceptional multiples, O(m^3) signatures, then handle final overflow pair and tail. This is a distinct transfer formulation; code shares generic dyadic evaluator, not an independent external proof audit. No requirement n_A=n_B or AB<=BA; includes arbitrary per-round order, shared-mode choices and delays.

## D. Stagnation and broader barrier
Markus Lohrey, Compressed Subsequence Checking is PSPACE-complete, arXiv:2609.14490 (13 Sep 2026), Theorem 1.1 states fully SLP-compressed subsequence over each alphabet size>=2 is PSPACE-complete under polynomial many-one reductions. Read statement and original reduction overview and final SLP construction in sections3/3.5; not independently audited entire new paper. Derived explicit adapter: for compressed binary u,v, mark u symbols A0,A1 and v symbols B0,B1 by terminal homomorphism, preserving SLP size. Ask whether some shuffle preserving both internal orders belongs to fixed regular language (B0|B1|B0 A0|B1 A1)*. Equivalently a partial 3-mode DFA (no pending B, pending0, pending1): Bc sets pending c (discard previous), Ac allowed only from pending c, resets none; all modes accepting at full consumption. Any accepted shuffle matches A letters to distinct increasing B positions; every subsequence embedding yields such shuffle. Unit weights, deadline |u|+|v| acquired by SLP length arithmetic. Thus general SLP shuffle feasibility with a fixed 3-state partial controller is PSPACE-hard conditional on cited preprint theorem; in PSPACE by nondeterministically advancing binary indices, random symbol access via length descent in SLP, then NPSPACE=PSPACE. The equivalence verified on all binary strings length<=4. This is a different succinct-input problem. No adapter to polynomial-clock U_h preserving size: expanded length can be exponential in SLP description and padding to satisfy t<=N^h can be exponential. No conclusion P!=NP; a polynomial unrestricted SLP-shuffle algorithm would imply P=PSPACE, hence P=NP, not known impossible. This directly explains why a generic SLP compression theorem alone cannot settle the native problem. The native counter schedules are special shifted valuations; no PSPACE-hardness claimed for them.
