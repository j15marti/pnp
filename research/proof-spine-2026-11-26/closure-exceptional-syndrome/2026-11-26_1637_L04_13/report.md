## 3. Complementary theorem: arbitrary numerical strides, fixed flat phase count
Proved with scope; not all of this general theorem executed end-to-end. Suppose normal weighted macro support graph (union of all actual normal carry-type entries) has SCCs each either a singleton with no internal edge or a simple directed cycle with exactly one labelled internal outgoing edge at every vertex. Distinct A/B parallel internal edges disallowed (combine repeated identical endpoints/labels by actual min only). Fix constant K independent of N and require every reachable condensation path visits <=K components; acquire by SCC and longest-path graph computation. Fix original initial and desired normal endpoint coordinates/modes. Enumerate condensation paths and actual bridges, entry/exit modes, <=q^{O(K)} choices (at most O(q²) labelled edges per boundary, fixed number). Within each simple cycle entry to exit has a unique shortest partial-cycle word of length <cycle size, preceded by x>=0 full cycles rooted at entry. Thus every possible normal path belongs to an acquired word scheme
    W_1^{x_1} ... W_b^{x_b},
with b=O(K), each W a known nonempty word of original edges of length <=O(q), x nonnegative; partial words and bridges have x=1, omit empty words. Cycles with only one tape are allowed; no positive-ratio assumption needed. Extra candidate words failing actual carry edges get penalty P. All endpoint coordinates are exact integer sums with coefficients <=O(q). With nonnegative repeats and fixed endpoint counts, every intermediate coordinate stays inside actual preoverflow rectangle, each x<=2^(m+1) (each word advances at least one count). All constants/variables O(m+log q) bits, and guards are fixed source constraints. No reduction by merely matching Parikh images; exact word scheme is an actual mode path with original edge order.

For a fixed word W and tape, let d be number of occurrences of its letters (skip d=0). Given initial tape VALUE z, successive ordinary increments along W^x traverse values z+1..z+dx, and each residue mod d selects exactly one edge position in W, once start residue z mod d is fixed. Enumerate start residues for each block/tape (at most q^{O(K)} tuples); enforce all these congruences on actual endpoint digits. The cost on this tape/block equals
    F(X_end)-F(X_start), where X_start=z+1, X_end=z+dx+1,
    F(X)=sum_{1<=n<X} c(n mod d,nu2(n)).
Here c is exact per-original-edge carry weight selected by fixed start residue. Arbitrary nonnegative finite or penalized weights, signed negation for subtracting start function. No need for d power of two.

**Dyadic prefix automaton.** Scan X MSB-first with fixed digit length sufficient for X<=2^m. Before bit k maintain processed high prefix P0, represented only by its residue mod d and trailing-zero count nu2(P0) (special all-zero symbol). If bit k is1, add the complete block [P0*2^(k+1), P0*2^(k+1)+2^k). These disjoint blocks partition [0,X). Exclude n=0. For internal offsets y=1..2^k-1 the valuation equals nu2(y), while residue depends only on P0 mod d. The sum over those offsets is precomputed for each layer k and shift residue h: for each valuation j<k and residue r, count y in [1,2^k-1] with 2^j divides y and y+h≡r mod d, subtract analogous count for j+1. Solve the two congruences by gcd/CRT and arithmetic progression counting, using polynomial binary arithmetic (or iterate at most d candidates for residue solution, d numerical <=q). The only exceptional offset is y=0: if P0>0, its valuation is k+1+nu2(P0), and residue known; if P0=0 ignore it. Thus exact block cost is an additive transition weight determined by retained state and k. Update residue by (2*rem+bit) mod d, trailing zeros to0 on bit1 and increment on bit0 unless all-zero. State count <=d(m+2) per layer. For fixed digit length beyond native m, define arbitrary weights outside valid range and enforce endpoint bounds; no accepting candidate uses out-of-range valuation. No huge table of residues mod 2^m. All precomputed counts have O(m) bits, total weight length O(m+log(q)+max input weight bits). This proof works for signed c too.

Future legality and cost depend only on full retained state, no marginal compatibility. Hence exact min over all attained parameter choices, no free count or optimizer.
