## A. Unit quotient obstruction (general)
Let G be a finite time-homogeneous concrete transition graph with start a and goal set Z, optionally restricted to a certified inductive invariant I containing a (every actual transition out of I stays in I). A partition map pi into K abstract vertices preserves every admitted concrete edge as an unweighted directed abstract edge; abstract goals include pi(Z intersect I). Extra edges/goals are allowed. The shortest abstract distance delta from pi(a) to abstract goals never exceeds any finite concrete accepting-path length, by projecting every edge. If a concrete path of length T exists, the abstract goal is reachable, so a shortest abstract path is simple and delta<=K-1. Hence rejecting clock t by delta>t requires K>=t+2 whenever the concrete goal is eventually reachable. For t=T-1 with T the true minimum distance, necessarily delta=T and K>=T+1. No refinement that merely chooses a cleverer partition can avoid this. Removing a real edge or replacing it by a non-unit weighted macro edge changes the model. A time-dependent clock guard which makes the eventual goal unreachable is also outside this specific theorem; it may provide a legitimate bypass. The result bounds number of abstract blocks, not the time of an arbitrary solver or a symbolic implicit quotient algorithm.

At state2 p=-1, blank returns to head0. No malformed move is admitted.

Let L=2^m. For complete counter value n at state0 head0, H(n)=4(L-1-n)-m+2 popcount(n)+1. To derive it: a nonoverflow increment of n with r trailing ones uses 2r+2 transitions (r flips, one write, r return-left moves, one right); final overflow uses m+1. Sum r(j)=v2(j+1) over j=n..L-2 equals L-1-m-n+popcount(n), by sum_{k=1}^n v2(k)=n-popcount(n) (count multiples of powers of two). Thus exact remaining time H(n). Extend to actual intermediate states, letting y be the current bit value:
* inc head p: H_inc=H(y+2^p-1)-p (the already cleared low p bits used to be ones);
* return head p: H_ret=H(y)+p+2;
* accept: 0.
Every expression uses O(m) bits and fixed exact arithmetic. Check each original transition: inc on symbol2 keeps recovered n fixed and raises p by one; inc on symbol1 has n with exactly p trailing ones, writes y'=n+1 and moves to return head p-1, while H(n)-H(n+1)=2p+2; return moves reduce p by one, blank at -1 returns to inc0; overflow H_inc=H(L-1)-m=1 then halt.
