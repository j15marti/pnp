## A. Interval-OR compiler (PROVED scoped)
Take ordered list Q_0,...,Q_(q-1) of explicit queries, total mass L=sum(1+|Q_j|), q>=1. Normalize syntax with common dense renumbering of literal IDs, remove tautological clauses and duplicates within each formula; malformed formula becomes a constant false formula, represented by empty clause. Empty formula is TRUE, empty clause FALSE. These are exact unconditional deductions at input and after clause normalization; no SAT/equivalence oracle. Retain occurrence-to-original ID map for witness lifting. Let C_j be normalized set of clauses (each width<=3). Let D=|union_j C_j|, R=sum_C number of maximal nonempty consecutive intervals of indices j with C in C_j. Each variable is shared by name, but selector chooses only one query; no simultaneous witness equality is imposed across different queries. If one query has distinct naming, no semantic renaming beyond the common dense dictionary is necessary.

Use b=max(1,ceil(log_2 q)) selector bits for integer z. Let a_C(z) be OR of interval-membership tests for clause C. Define
  B(x,z) = [0<=z<q] AND AND_C (NOT a_C(z) OR C(x)).
For every z in range, B(x,z) iff Q_z(x); for invalid z, B is false. Therefore exists x,z B iff some original query SAT. Forward witness: take selected query's satisfying assignment and extend unused variables arbitrarily; reverse: selected index and original IDs reconstruct witness. This works even with arbitrary shared names, duplicate formulas and empty clauses. For q=0 the batch is UNSAT by convention, no query needed.

A comparison with a fixed b-bit integer uses O(b) Boolean gates via bitwise prefix recurrence; each closed interval uses two comparisons and AND. Each clause uses O(1) gates, and all OR/AND combinations are binary. Circuit size O((D+R+1)log(q+2)); standard bidirectional Tseitin gate clauses plus a root unit preserve existence AND every original/selector assignment. Convert short clauses to proper signed 3CNF: a two-literal clause c becomes (c OR u) AND (c OR NOT u), with fresh u; a unit uses four patterns on two fresh bits; empty uses all eight patterns on three fresh bits. Remove repeated literals and tautologies before padding. This is logically equivalent after existential padding, and gate values are forced by inputs. The resulting explicit ordinary SAT query has bit size
  B_len = O((D+R+1) log^2(L+2)).
No succinct-SAT oracle: all gates, clauses, IDs materialized. There is no reliance on witness counts or on arithmetic addition equaling OR.

Acquisition: parse full list; sort occurrence records by literal ID, dense-renumber then sort by query/normalized clause, dedup; sort by clause and query index, scan to identify runs. Fixed-tape merge sort on length-prefixed variable records costs O(L polylog(L+2)); a comparison prefix is bounded by the smaller emitted record plus headers and can be rewound at that charge; O(log L) passes. IDs, positions and lengths use O(log L) bits; no free random access. Emit circuit sequentially with counters and carry out proper-CNF conversion. O(L polylog(L+2)) total bit time, including reading every materialized query even when it has identical contents. Peak O(L polylog L). All finite-dimension arithmetic here uses logarithmic-bit counters. No semantic canonicalization or unknown equality query.

## B. Edit tariff (PROVED scoped)
For a full chronological list (including positive replies), write E=sum_(j=1..q-1)|C_j symmetric_difference C_(j-1)|. Every new interval starts with a clause in C_0 or an insertion. Hence
  R_full=|C_0|+sum_(j>=1)|C_j minus C_(j-1)| <= |C_0|+E.
Also D_full<=R_full. Deleting positive indices to obtain the negative-only subsequence cannot increase a clause's number of runs: a run can disappear or merge but cannot split under subsequence compression. Consequently R_neg<=R_full, D_neg<=D_full, and B_len for negative-only union is O((1+|C_0|+E)log^2(L+2)). This is a source-acquired edit tariff, not an assumption that edits are small or that virtual incremental access is free. If q queries each contain O(n) clauses and successive queries change only O(1) clauses, q=O(n), then full materialized mass can be Theta(n^2 log n), while batch is O(n log^2 n). For no-sharing lists E can be linear in full mass and compilation may increase size. Use individual fallback; no universal gain claimed. Alternative ordering/relabeling may help but its discovery is not free.

Independent constructive check: for a fixed assignment x, find falsified clauses C. Their occurrence intervals cover exactly the indices of queries false under x. Compute interval union by sorting endpoints (or scan a difference array of length q+1); an uncovered index is a genuine witness query. This is the same attainable selector set as A, not just a marginal count. Enumerate assignments of v actual dictionary variables to decide OR in O(L polylog L + 2^v(D+R+q+1)polylog L) time with polynomial peak space; bounded width, affine, matching, or other exact verifiers can be substituted only with explicit adapters and paid scope. Empty interval union, tautologies, true empty formulas and false empty clauses checked. Replacing OR by conjunction is false even on [x,NOT x]: conjunction UNSAT despite both queries SAT. This is a real soundness failure, not a cost issue.

## C. Same-execution hierarchy consequence (CONDITIONAL on a SAT time cap)
Suppose fixed ordinary deterministic D_S decides S in O((1+ell)^k), integer k>=1. For each genuine true path of A, let
  I_k = sum over negative queries (1+ell_j)^k,
  J_k = (1+B_len)^k (zero if no negatives).
A nondeterministic transcript verifier guesses answer bits, certifies each positive with a full satisfying assignment and exact literal ID consistency, and chooses either individual verification of negative queries by D_S or the interval-OR compilation plus one D_S negative answer. Both branches require actual completion and are clocked. Even an inconsistent repeated oracle reply cannot survive: if a query is certified YES and also negative, the batch has a witness and fails. Induction on the exact A calls proves surviving transcript equals true path. Ordinary acquisition O(W polylog W) is charged in either mode; use a fixed budget cutoff on every guessed path, including false paths, failed tracks and rejected certificates. No timeout counts as a certified answer.

For every fixed rational r with max(1,rho)<r<h, infinitely many valid YES words AND infinitely many valid NO words have BOTH I_k>N^r and J_k>N^r, up to any fixed multiplicative budget constant. Proof: if either tariff <=constant*N^r, the nondeterministic verifier has a certified transcript within O(N^r polylog N), hence below N^b for fixed r<b<h. Let Y_1,Y_0 be languages having such capped certified final YES/NO transcripts. Y_1 subset U_h, Y_0 subset valid complement. If Y_1 misses only finitely many YES, hardcode finite exceptions and contradict hierarchy; if Y_0 misses only finitely many valid NO, hardcode finite exceptions, handle malformed strings via parser, contradict complement bound. In fact diagonalize against recognizer of Y_0 to generate explicit candidate-dependent valid NO omissions. Every omitted input must fail both tariffs, since either mode would otherwise be a certified path. This is joint failure on SAME execution, not addition of overlapping work or two separate hard families. It is a conditional tariff statement, not actual running-time lower bound on D_S, and not an assertion that arbitrary deciders perform SAT queries. Can include any fixed sound exact negative batch verifier in the same OR dispatcher; no free discovery.

Corollary: sufficient P!=NP theorem would be, for every fixed k>=1, to construct h and correct uniform A_k for U_h with W=O(N^rho), |C_0|+E+1=O(N^lambda), max(1,rho,k*lambda)<h. If SAT is P, choose its actual exponent k; exact batch verifier then contradicts hierarchy. Compared with prior individual tariff rho+(k-1)lambda, this can remove the multiplicative exponent from repeated evaluation when edits remain small. This is a sufficient condition, not an established all-k construction. Actual deterministic controller still pays its answers if used as a deterministic algorithm; nondeterministic transcript verification is used only for hierarchy. The first OPEN arrow is construction of such an all-input, all-k family of low-edit adaptive reductions. A fast A on only a recognizable easy subclass is not enough.

Unconditional alternative: replace J_k with the explicit interval-sweep exponential tariff from B. If uniformly below N^r together with ordinary work, same contradiction without P assumption. This constrains those particular verifiers only.
