## Named obligation CRITICAL-PAIR-OR-CERTIFIED-RETRACTION
Falsifiers: disconnected improving set without improving connected component; sign/residue errors; omitted resolvent or unsound pivot elimination; claim of universal progress at local optimum; lost guard or source map.

1. Connected flip restriction (KNOWN THEOREM, not new). Given an explicit CNF chart, variable co-occurrence graph H joins variables that share a clause. For assignment a, define integer deficit f(a) as number of false rows, counting duplicates if present. For any set S of flips, let S_i be components of H[S]. No clause can contain flipped variables in two distinct components. Thus f(a)-f(a^S) equals the sum of the gains of the S_i. Positive gain implies at least one component with positive gain; any inclusion-minimal improving set is connected. This is exactly the argument in Szeider 2011 Theorem 5 (located in primary text after independent derivation). At a singleton plateau an improving pair must share a clause. For max graph degree Delta fixed, enumerate root-to-root spanning tree walks of length at most 2(k-1); any connected set <=k has such a walk. <=r sum_{j=0}^{2k} max(2,Delta)^j candidates, dedup not required for correctness but charge repeats. With k<=c log2 N fixed c and Delta, candidate count polynomial in original N; score all rows exactly and include bit indexing and storage. Strict integer improvement gives at most m accepted moves in a fixed database. No theorem that an improving set exists on every unresolved state or that normalized graph degree remains bounded; learned clauses may change graph. This is bounded-neighborhood optimization, not decision completeness.

2. Exact pivot cost lemma. For a variable v and fixed values y of all other coordinates, let P(y) be count of positive-v clauses whose remaining literals are all false, Q(y) the corresponding count for negative-v clauses. Local violation count with v=0 is P, with v=1 is Q. The exact existential minimum is min(P,Q). The total number of falsified pair resolvents counting multiplicities is P*Q (a tautological pair cannot have both remainders false). Thus zero min iff no pair resolvent false; counting resolvent rows unweighted or deduplicated does not in general preserve the optimization objective. An optimal pivot choice is reconstructed from comparison P<=Q. For a bounded incident boundary width, min-cost factor can be built by all boundary rows; do not enumerate unbounded width for free. This separates a feasibility-preserving DP projection from deficit-preserving optimization, and identifies why merely adding critical resolvents can distort the energy. Elementary scoped derivation, no claim of general novelty. Not implemented as a weighted solver in this run.

3. Exact bounded-fill DP retirement. Let A contain all clauses with v, B all with -v, U unaffected clauses. Replace A and B by all distinct nontautological resolvents; omit a resolvent only if some U clause subsumes it. For each assignment to remaining variables satisfying U and retained resolvents, P and Q cannot both be positive, hence a valid v exists. Reverse map chooses v=1 if P>0 else v=0; if Q>0 then P=0, so choice valid. Every original witness projects. Accept only if each retained resolvent width<=4 and retained count<=|A|+|B|. Every accepted retirement decreases live variable count by one without growing clause count; potential r is numeric polynomial. All v scans, at most m^2 pair candidates per variable, m subsumption checks per pair, polynomial bit cost in fixed chart size, at most r successful eliminations; charge reverse maps and proof verification. This is standard bounded variable elimination (Eén/Biere, CaDiCaL), with this particular nonincreasing bank criterion. No guaranteed pivot. An over-width or fill witness refuses that specific rule only, not all eliminations. Separate finite cap2e6 events; no cap hit. Initial dedup changes multiplicity objective, so compare tree sizes to deduplicated proof database, not assert deficit unchanged. No root new forced pins from plateau alone.
