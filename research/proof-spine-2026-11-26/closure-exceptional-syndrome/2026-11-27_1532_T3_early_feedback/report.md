## 3. Critical-resolvent availability theorem (PROVED WITH SCOPE)
Let F be a finite CNF with no tautological clauses and no repeated literals within a row; duplicate rows may be counted separately. Let a be a Boolean assignment that is not a satisfying assignment and has no single-variable flip that strictly reduces violated-row count. If an empty clause already exists, terminate immediately. For each v, m_v = number of violated clauses containing v; b_v = number of clauses whose unique true literal is on v. Flipping v repairs exactly m_v and breaks exactly b_v. Hence m_v<=b_v at stall. For any violated nonempty row C and any literal p in C on v, m_v>=1, so at least one row D has exactly one true literal, namely -p. Resolve C,D on p. Every nonpivot literal in C,D is false at a, so their union is false, contains no complementary literals, and is a sound non-tautological resolvent of width <= |C|+|D|-2. It may already be present; no novel-clause guarantee. Number of ordered critical pivot pairs sum_v m_v b_v >= sum_v m_v^2 >= sum_v m_v; direct construction via inverted make/break indices O(L + sum_v m_v b_v * (max width + index bit cost)) plus dedup/verification, where L is total literal occurrence length. This bound is polynomial in explicit input length (pairs<=L^2), fixed original N provided current chart/learned rows bounded by fixed polynomial. On a 3-CNF all such resolvents width<=4, explaining width4 as natural next local discovery stage. Does not mean all such resolvents width exactly4. For wider CNF some critical pairs yield >4. Can certify availability independently without global enumeration of all row pairs or exact survivor counting.
