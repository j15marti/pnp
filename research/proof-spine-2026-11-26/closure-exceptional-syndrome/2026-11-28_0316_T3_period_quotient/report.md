## 2. Exact sumset collision contraction and period quotient theorem
Consider authenticated affine-image/conflict graph model Hz=b, support z independent. Partition conflict graph into connected components V_i, no conflicts between them. Enumerate independent subsets in each bounded component, obtain finite exact set S_i of syndrome sums of its columns; retain one representative independent word per syndrome. Then feasibility is exactly b in S_1+...+S_B over F2. Original form evaluation and affine lift by GE are preserved. For arbitrary explicitly supplied exact dictionaries the following rules are sound, complete as transformations, not universal productive.

Rule F (fusion): if two dictionaries own disjoint blocks, replace S_i,S_j with the exact sumset T=S_i+S_j. Record a decomposition t=u+v for each output t. This is exact even if cardinality grows, but accept only under an original-N fixed dictionary cap K. Collision criterion: |T|<|S_i||S_j| iff there exist a!=a' in S_i and c!=c' in S_j with a+a'=c+c'. Proof directly from equality of two sums; distinct in one coordinate forces distinct in the other. Build exact index of pairwise differences, acquire candidate pairs deterministically. Verify by explicit product enumeration and exact dedup, never a probabilistic hash collision. A collision is a useful acquisition trigger, not permission to collapse distinct sums. Batch disjoint fusions so each has disjoint unchanged input ownership.

Rule A (affine necessary filter): choose one element a_j of each other nonempty dictionary S_j and L_j=span(S_j+a_j). For option s in S_i, any completion satisfies b+s+sum_{j!=i}a_j in sum_{j!=i} L_j. Remove only options failing this necessary condition. All feasible completions survive; restricted dictionaries remain exact for global decision. Empty dictionary or globally incompatible affine hull is sound NO. GE paid; prefix/suffix basis reuse accelerates discovery. Sequential updates use newly restricted prefix and unchanged suffix. Independent replay recomputes complete other-block affine hull from current exact dictionaries.

Rule P (period quotient): if nonzero p satisfies S_i+p=S_i, quotient all dictionaries and target by span(p). This condition is acquired by choosing fixed a in S_i and testing candidate p=a+c for c in S_i, exact membership of all translates. Any original solution projects. Conversely choose original representatives of all projected local options; total discrepancy is 0 or p. If p, replace the owner i's chosen s by s+p, which is present, obtaining exact original target. Reverse fusion frames and period frames restore original independent-set words; reverse affine map by GE and check every native E,B,edge. The test discovers a decision-relevant phase of a nonlinear support without treating linear span as exact support. For a complete affine plane arising from two copies of {0,a,b}, there are two independent periods; both can be absorbed without retaining a large global trellis. Related stabilizers are standard additive combinatorics; no general novelty assertion.

Scoped no-reset credit: B0 initial block count, d initial syndrome dimension, q current ambient quotient dimension, K a fixed polynomial bound on all explicit dictionary sizes (choose max initial bound and fusion cap). Use Phi=(B+q)(B0*K+1)+sum|S_i|. Every strict filter decreases sum, every fusion decreases B by one and increases sum by at most K, every nonzero period quotient reduces q by one and cannot increase sum. Phi is polynomially initialized, nonnegative and decreases at least1. No credit awarded for reloading, representation changes not covered by these rules, or repeated candidates.
