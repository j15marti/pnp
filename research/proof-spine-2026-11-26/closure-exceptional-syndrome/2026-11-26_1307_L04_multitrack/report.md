## A/B/C: exact two-sided midpoint certificate
Finite directed graph with vertices encoded by B bits, explicit circuit E(u,v) for adjacency (invalid encodings isolated). R(u,v,l) proposed Boolean relation for paths of length at most l, with 0<=l<=T, and W(u,v,l) proposed midpoint. Let a=floor(l/2), b=l-a for l>=2. Base l=0: u=v. Base l=1: u=v or E(u,v). Exact reachability P satisfies P_l(u,v) iff exists z P_a(u,z) AND P_b(z,v): split an at-most-l walk at min(a,actual length); reverse concatenate. No independent existential choices for the shared z.

Lower certificate (YES): root R=1; for bases R implies base; for every l>=2 and u,v, R=1 implies both R_a(u,W)=1 and R_b(W,v)=1. By strong induction R subset P. Upper certificate (NO): root R=0; for bases base implies R; for every l>=2,u,v,z, R_a(u,z) AND R_b(z,v) implies R_l(u,v). Induction P subset R. Both conditions imply equality; taking exact P and choosing a midpoint for every positive nonbase pair establishes existence (finite truth tables, no size bound). A lower certificate can ignore irrelevant paths, upper may overapproximate. Neither must be a literal computation history. A NO check based on one guessed midpoint is unsound: missing alternative z can connect the root.

Compile the disjunction of all violations as one explicit Boolean circuit with free bit strings for u,v,l,z; l-range guard; root is fixed; constant copies of R,W,E, mux, comparison, subtraction and shift. For bounded fan-in encoded sizes s_R+s_W=s, adjacency gates g, width B and L=ceil(log2(T+2)), gate count O(s+g+B+L), with standard wire encoding and Tseitin bit size O(H log(H+2)), H=s+g+B+L. Parse circuits, write all copies, index offsets, guard invalid lengths; conservative fixed polynomial bit-time construction, not claimed near-linear multitape implementation. For NO omit W. Violation CNF is UNSAT iff the corresponding certificate passes. If SAT in DTIME(ell^k), validate in charged polynomial time in H (plus syntax, encoding, input parse and construction costs); no uncharged equivalence oracle. Certificate existence is not acquisition. Guessing a certificate gives nondeterministic verification, not deterministic witness search.

Exact adapter for U_h: complete tape windows containing input and every reachable cell in t steps, both heads/state, encoded symbol widths, original rule table; no-op absorbing target sink with one edge from every accepting configuration, T=t+1. E checks one legal transition by explicit comparisons and rule scan plus sink edges; an accepted path to sink of length <=t+1 iff original acceptance by t. Start nonaccepting, sink distinct. Default width B=O((N+t)log(N+2)) and adjacency compiler polynomial in N+B; therefore not a sub-hierarchy construction in general. A small-space restriction can reduce B only if proved to contain an accepting path for every YES in the admitted class. Uncharged succinct configuration access is forbidden. Full witness lift from lower certificate recursively expands midpoint paths, costs at least actual materialized path length when output is requested; not part of decision-only certificate verification. No claim about general low-space source NP hardness.

## E/G: finite certificate portfolio firewall
Use known nondeterministic polynomial time hierarchy (Seiferas/Fischer/Meyer 1978, Theorem 3 cites Cook for 1<=r<s; stronger separation theorem follows). For 1<b<h, choose rational b<r<h and language in NTIME(n^r) outside NTIME(n^b), use fixed two-tape simulation with strict exponent slack and map x to clocked word containing fixed machine, x, and deadline |x|^h (finite small exceptions handled directly). Framing is linear length, construction O(n polylog n); source acceptance equivalent. Thus U_h outside NTIME(N^b). The complement version follows independently by diagonalizing any nondeterministic B alleged to recognize complement within O(N^b): fixed D reads a framed machine description e from its input x, forms w=(e,x,|x|^h), executes B(w); D obtained before choosing x=frame(D)0^j. For large j time fits the clock with strict slack (multitape to two tapes near-linear simulation preserving nondeterministic choices). Therefore w in U_h iff B accepts w, contradicting complement recognition. No free self-reference. These are fixed-h lower bounds only.

For any finite portfolio of uniform, sound certificate checkers for labels 0 and 1, define actual verification tariff on a candidate to include reading N, certificate guessing/writing, parsing, construction, all adaptive queries/evaluation, branch clocks and syntax checks, and require all runs under the cutoff. Under a hypothetical SAT decider if needed, use its actual cost in that tariff. If for one label every correct input except finitely many admits any accepted certificate among the portfolio within O(N^b), where 1<b<h, then a nondeterministic machine guesses track and certificate under the cutoff, accepts on successful verification of that label, hardcodes finite exceptional inputs. This would decide U_h (label1) or its complement (label0) in NTIME(N^b polylog N), with strict margin to h. Contradiction by the respective theorem. Hence for each fixed bound K N^b infinitely many YES and separately infinitely many NO inputs have NO in-budget certificate in ANY track. It is a simultaneous same-input portfolio obstruction, not an arbitrary deterministic lower bound above h. Holds for uniformly indexed families too if selector and dispatch cost are charged. Deterministic racing needs separate proof that at least one track finishes in budget; guessing is not such a proof. No independence of track costs assumed. A uniform bound on exponent across all h would contradict hierarchy; if verification exponent depends on h, no contradiction. C02 dyadic runtime envelope criterion is compatible, but certificate tariffs are not arbitrary decider runtimes. Exact uniform h-independent semantic compression remains OPEN, not a consequence of P=NP.
