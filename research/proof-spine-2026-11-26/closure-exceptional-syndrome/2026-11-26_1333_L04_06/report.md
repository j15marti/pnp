## A: constructive projection
Let finite directed graph (V,E), start a, accepting set Z, and clock t encode the actual computation. For a projection pi:V->A, insert an abstract edge pi(u)->pi(v) for every actual edge. Reverse BFS from pi(Z) gives truncated distance D=min(t+1,dist), with unreachable treated as t+1. Each edge D(pi(u))-D(pi(v))<=1 and all accepting values zero. Thus D(pi(a))>t is a valid NO. Any abstract path is only a relaxation: YES requires native lift. Explicit abstract graph construction is paid; on an implicit configuration space do not assume its image is cheaply acquirable. A's implementation computes actual x-coordinate projection BFS from all original finite-control rules, not a supplied answer.

## B: global resource contradiction
Separately use a second coordinate y. On each actual transition verify y(v)-y(u)<=1, accepting y=k and start y=0. Then H_B=k-y has unit drop upper bound; telescoping any accepting path gives length>=k. This is independent of the projection BFS and does not assume disjoint coordinates. More generally, take a set of integer potentials H_i:V->Z with polynomial-size encodings, verified on a common invariant I. If H=sum_i H_i, H(a)>t, H(z)<=0 for all z in Z intersect I, a in I, and for every actual edge from I:
1. v in I;
2. sum_i(H_i(u)-H_i(v))<=1,
then no accepting path within t exists. Proof: induction preserves I on an arbitrary path. Sum the edge inequalities on that same path; H(a)-H(z)<=length. This contradicts H(a)>t. No per-track independence or sum of minima assumed. Local drops may be negative; the total bound, not individual disjointness, is essential. A sufficient but stronger version allocates nonnegative costs c_i(u,v) with sum<=1 and each H_i drop<=c_i. This is the relevant cost-partitioning interpretation; if all lanes charge the same transition at unit cost, only maximum of individual lower bounds is safe without joint check. This general telescoping argument is elementary, related to known additive abstraction heuristics, not a claim of a new general complexity lower bound.
