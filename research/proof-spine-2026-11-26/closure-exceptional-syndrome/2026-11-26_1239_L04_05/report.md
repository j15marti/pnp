## 1. Exact final-output extractor

Suppose a fixed deterministic two-tape machine M on bin(m) accepts within t<=2^(C m), C a fixed positive integer, and leaves an m-input function g_m's truth table on tape 1 at cells j=0,...,2^m-1, with bit symbols 1/2. The accepting length l is supplied by a valid chart and unique. The output index is an m-bit input j to the extractor. Every cell is written at least once. Both chart types require O(m)-bit time/position addresses since log t=O(m). Machine fixed: rule lookup uses constant table size, and chart codes are fixed by the same source. A valid tableau chart directly gives A_1(l,j). Hardwire l, decode symbol, get a Boolean circuit for g_m of O(s+m) gates.

For a valid event chart, positions H_1(P_1(r)) are nondecreasing in r, with chronological ties. Perform upper_bound for target position j on ranks [0,l): lo=0, hi=l; while lo<hi set mid=floor((lo+hi)/2), compare H_1(P_1(mid))<=j, set lo=mid+1 or hi=mid. Unroll exactly ceil(log2(l+1)) iterations, freeze when lo=hi; guard invalid index l when inactive (can route to 0). Final r=lo-1 exists for output positions; position must equal j. Evaluate R(P_1(r)) and decode actual write symbol for tape 1. This is the last event at that physical position, even if it was later read (a transition rewrites or preserves the symbol). The source output promise assures it is the final correct bit. No array lookup or SAT oracle: each iteration is a constant number of actual chart copies plus O(m) gates for arithmetic, comparison, mux, and guarded indexing. Total gates O(m(s+m)), encoded construction time and size O(m(s+m) polylog(s+m+2)), by writing topological copies with index offsets. The same original IDs survive, and actual output reconstruction is just circuit evaluation. It is a nonuniform extractor from a supplied chart, not a uniform method to acquire a chart. Full output enumeration costs >=2^m and is not used to decide the source.

Consequently if ordinary bounded-fan-in Boolean circuit complexity of g_m is >B_m, then BOTH valid chart minima obey s >= Omega(B_m/m - m) (for A a stronger bound). No statement about arbitrary decision procedures. Independent adversarial check: first-write lookup fails when two writes to same output cell differ. Sorted last-event search fixes it; final tableau is independent exact control. Every invalid ordering/coverage is excluded by L04-04 inverse + strict lex checks.

## 2. Construct a near-maximal truth table using a hypothetical SAT decider

Assume SAT is decidable in deterministic polynomial bit time, with one fixed algorithm D and exponent k. Put L=2^m, B_m=floor(L/(100m)) for m>=1. Count circuits over AND/OR/NOT with at most B_m internal gates, m input nodes and two constants, arbitrary earlier input indices and one output. There are at most (B_m+1)(m+B_m+2)[3(m+B_m+2)^2]^{B_m} descriptions, an overcount including duplicate functions and illegal encodings. Its log2 is <L for all sufficiently large m. Thus some truth table is not realized. For finitely small m where all tables might be realizable, define a default all-zero table; existence can be guaranteed above an effectively fixed cutoff using the elementary bound.

Given a materialized L-bit table y and integer m, predicate Small(y) = exists a syntactically valid circuit with <=B_m internal gates that computes exactly y. NP in L: guess O(B_m log(m+B_m+2)) bits; evaluate every one of L assignments, comparing actual bits, with all wire lookup scans charged (even O(L times a fixed polynomial in B_m,m) suffices). Cook-Levin and D decide this NP predicate in deterministic poly(L). For a fixed prefix p, predicate Ext(p) = exists L-bit y extending p with NOT Small(y). Explicitly pad its input to >=L bits so this is an NP predicate in the actual encoded length using the deterministic Small decision algorithm as subroutine. D then decides Ext in deterministic poly(L), with a fixed exponent, not an oracle. Iterate L times: choose 0 if Ext(p0), otherwise 1. By the invariant Ext(p), this deterministically produces the lexicographically first hard truth table. All L calls, padding, failed 0 probes, nested reductions and D execution, parsing, bits, and output cost poly(L) in total; no claim of a useful small exponent. This is the elementary exponential-hierarchy hard-table construction after collapse, not a new unrestricted Boolean lower bound.

Implement one fixed deterministic two-tape M containing D and the above algorithms: first transfer bin(m) to tape2, simulate all polynomial-in-L multitape work on tape2 alone by standard explicit scanning simulation with polynomial slowdown, then write the complete table to tape1 starting at cell 0, symbols 1/2, stop in state 1. Tape1 can remain stationary while tape2 is used for work, then output sequentially, overwriting input. A fixed integer C bounds ALL time by 2^(Cm) for all sufficiently large m, enlarging for overhead; no dependence of C or M on h or a. Finite small lengths can be handled separately. This has one unique accepting trace, without nonuniform advice. Actual table generation cost is 2^O(m), not O(N) on the padded source.

## 3. Conditional explicit high-exponent families

For every fixed h>=2 and sufficiently large m, set t=2^(Cm), N=2^ceil(Cm/h), pad externally to exactly N bits. Prefix encoding length is O_M(m) and eventually fits. Clock valid t<=N^h. Let w_(h,m)=frame(M)frame(bin(m))frame(bin(t))0^p. This is uniformly materialized in O(N polylog N) time for fixed M,C,h, with binary counters; no trace generation is needed to construct the word. Same-N NO neighbor v replaces clock with zero and adjusts external padding. Start state not accepting. Both are valid U_h inputs. Under the assumption on D, every w_(h,m) is YES; the v's are unconditionally NO. A promised decision procedure for these two families checks the frame, M, m, padding and whether t is 0 or 2^(Cm), with O(N polylog N) time; it need not compute the hard table. On other source words return UNKNOWN, not a total U_h algorithm. This is an explicit adversarial bypass on the SAME inputs.

By sections 1-2 both chart minima on w_(h,m) satisfy
    min(s_A,s_B) >= Omega(2^m/m^2) = Omega_h(N^(h/C)/(log N)^2).
The constants may depend on M,C,h. This holds for every sufficiently large m, not merely an existential infinite hard subsequence. In particular for each fixed a, choose fixed h>C a (and h>=2), and for every fixed multiplicative K both minima eventually exceed K N^a. The same fixed deterministic M works across these h. Therefore under P=NP the proposed universal h-independent chart exponent is false even on easy promised deterministic families. This is a stronger, explicit witness of failure than L04-04 hierarchy argument, but conditional on D. It does NOT prove P=NP false, nor unrestricted time hardness from chart complexity. Counting was on descriptions, not #SAT.

## 4. Exact equivalence to an open exponential-time circuit hypothesis (scoped)

Define E=DTIME(2^O(n)) and E-SUB = for every L0 in E and every fixed epsilon>0, its n-bit characteristic function has circuits of size O(2^(epsilon n)) for all n. Define DET-TRACE(a) for one fixed a>0: for every fixed deterministic two-tape M that accepts bin(m) for all sufficiently large m in <=2^(Cm) steps for fixed integer C, for every fixed integer h>=2, on the above N=2^ceil(Cm/h) padded family at least one exact chart has size O_{M,C,h}(N^a). Ignore finite m where frame does not fit. This is a deliberately narrow subpromise of U_h, not a separate NP-hard source.

Claim: for every fixed a>0, DET-TRACE(a) iff E-SUB. Forward: for arbitrary E language L0, one fixed M enumerates all m-bit inputs, simulates L0 on each, writes their bits in order, accepts in 2^(Cm) for some fixed C (single work tape slowdown still single exponential). Under DET-TRACE(a), section 1 extracts a Boolean circuit of size O(m N^a+m^2) for L0 on m bits. For any epsilon>0 choose h with Ca/h<epsilon/2. This gives O(2^(epsilon m)) eventually. Reverse: fix M,C,h and compute any requested chart bit (type, address, bit position) by exact deterministic replay and, for B, sort the two complete lists of events and obtain inverses; for A materialize/scan the requested cell at requested time. With unary m and fixed-width padded input fields totaling d m bits for one fixed integer d (including bit selector), the bit language is in E: simulation, tape bounds, sorting, replay, invalid-input rejection, and all address access cost 2^O(m). One bit language can select all chart fields. Under E-SUB take its circuits on dm inputs, hardwire unary m, selector and appropriate padding, copy O(m) times for all output bits/constant-many charts. Size O(m 2^(epsilon d m)) plus O(m^2) wiring. Choose epsilon d<a C/(2h). The size is O(N^a); both charts exist, and l is hardwired from the actual unique computation. This is a nonuniform existence implication, not polynomial acquisition or proof discovery. If M rejects finitely many m, ignore them in the promise. No arbitrary input w of N bits treated as free advice in this equivalence.

Thus even this very narrow trace-cap proposal is equivalent to proving subexponential circuit upper bounds for every E language. Section 2 gives the standard conditional contradiction P=NP => NOT E-SUB (the hard table bit language is in E and eventually needs >2^m/(100m) gates). Hence proving DET-TRACE(a) independently would prove P!=NP, but it is not implied by a hypothetical SAT decider; it is refuted under that hypothesis. Conversely any unconditional exponential circuit lower bound for E would refute DET-TRACE(a), not decide P vs NP. The exact equivalence is specific to this deterministic unary-indexed source family and the exact trace chart representation.
