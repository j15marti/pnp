## 1. General endpoint-transition cover theorem
Let finite undirected original graph G have a verified partition into b>=2 nonempty blocks. Ports are distinct external edge incidences; original external edge IDs are called wires. For block R, use an exact or safe upper endpoint-free table of pairs that can occur in spanning acyclic degree-two fragments: components paths connecting distinct selected boundary stubs; no closed cycles. For singleton paths with two stubs at same original vertex, include the pair if feasible. No assumption of joint compatibility of different rows. Build J with vertex set all original wire IDs, edges whenever corresponding ports of one block are paired in some retained endpoint-free row. If exact rows unavailable, a safe superset of actual pair edges (even all pairs) is valid; unverified omission invalid. Let lambda be connected-component labels in J. For each block define support S_R = all lambda labels of its incident wires, including unsupported individual ports conservatively.

In any global Hamiltonian path, each block has at least one selected external wire because path is connected and b>=2. Read external wires in their path order. Consecutive external wires pass through one block. If that block contains neither global endpoint, its full restriction is an endpoint-free spanning fragment (every original vertex visited once); the corresponding pair is among true local rows, so its two labels agree. If block contains one endpoint, its endpoint fragment consumes one external wire (unless both endpoints in same internal component, impossible for b>=2); all remaining internal path components pair external wires. With at most d ports, at most floor((d-1)/2) such through-paths can change component labels. If both endpoints in one block, their separate fragments consume two ports and there are at most floor((d-2)/2) through-paths. Hence for d>=2 a uniform bound of L=1+2 floor((d-1)/2) distinct active labels follows, because each change can add at most one new label. For d=4, L=3. The active label set hits every S_R. If no <=L-label subset intersects every support, G has no Hamiltonian path. In particular L+1 distinct mandatory labels, each witnessed by a block with singleton support, give immediate NO. For d=4 enumerate triples (or all labels if fewer than 3), O(b q³) scans for q components, and polynomial even with unbounded number of switching blocks. Fixed d gives polynomial degree depending on d. This is NOT an exact decision characterization; a cover means UNKNOWN. No requirement for a baseline pairing or exact global count.
