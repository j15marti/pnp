## 3. Theorem: decision-only quotient and minimum correction layer
Let A,D be two disjoint finite exact attainable boundary supports in F2^b from regions with complete separator B and fixed common guard. All solutions must share one boundary word. For a linear map H with kernel K, the projected supports are disjoint iff K intersects the cross-difference set Delta={a+d:a in A,d in D} trivially, in fact K intersect Delta is empty because A,D disjoint and 0 not in Delta. Proof: H(a)=H(d) iff a+d in K. Thus a key may be sufficient to reject by disjoint projected support although neither original response factors through it. No SAT certificate from overlapping projected supports.
Exact membership factorization of a support S through H is equivalent to S+K=S. If |S| odd, a nonzero K element partitions S into two-element translation orbits, impossible; exact lossless linear key requires rank b. This distinction between support membership and decision separation is essential; do not report a decision-only key as a lossless response dictionary.
For a fixed arbitrary key H, allow a default label d_y in {0,1} per key and an exception dictionary with original word and override label. Requiring correct labels 0 on A and1 on D, the minimum number of exceptions equals sum_y min(|A intersect H^-1(y)|,|D intersect H^-1(y)|). Indeed choosing default0 incurs all D words in that fiber; default1 incurs all A words; fibers are disjoint. Take majority, tie deterministic. This is exact for attained labelled supports only (arbitrary outside), not exact membership. For exact membership of S on the full cube the same formula uses S and its complement in each fiber. Certifying any proposed compressed separator requires complete exact supports or independently certified outer supports/region implications. Collision checking on arbitrary implicit regions can itself require paid search. Correction rows may require storing full words, and source maps/witness lifts still charged.
Given explicit supports and b<=c log2 original N with fixed c, compute Delta in O(b|A||D|) bit work plus indexing; enumerate all coordinate-drop masks in O(b 2^b) via subset-OR zeta. A coordinate deletion mask J is valid iff no Delta element has support contained in J. Compute zeta of Delta support indicator, maximize popcount of masks with zeta0. This is optimal among coordinate-drop maps only, not arbitrary linear maps. Greedy arbitrary kernel extension by testing whole proposed coset against Delta is sound but no optimality claim. Storage and indexing O(poly(N)) under explicit bounds; all acquisition, replays, failed candidate checks included. At large b, 2^b enumeration is not a polynomial routine unless paid by input size or proven log bound. Rank decrease in a decision-only key is not UCAC original-variable retirement or a global operational credit. No free oracle or semantic compression.
