## Theorem A: explicit diagonal family for a complement recognizer
For every fixed ordinary NTM B recognizing any language L in NTIME(N^b), 1<b<h, there is an effectively constructed fixed two-tape NTM D and an explicit linear-size sequence of valid w_j such that for all sufficiently large j,
    w_j in U_h iff w_j in L(B).
Proof: first construct a multitape machine P_B. On binary input x, parse its first self-delimited field as an arbitrary string e, compute m=|x| and t=m^h in binary, construct w=f(e) f(x) f(bin(t)) (no final pad), and run B on w. Reject malformed prefix. No recursive construction or self-description inside the program. Copying and counting can use O(m polylog m) tape operations; h is fixed and arithmetic uses O(log m) bits. Even if |e| varies, |w|=O(m+log m). For a valid prefix, P_B accepts exactly when B accepts w, in nondeterministic time O(m^b polylog m). SFM (1978), Lemma 3 (Book-Greibach-Wegbreit two-tape simulation), supplies a fixed two-tape D with same language and accepting-path overhead constant; even O(T log T) overhead would be absorbed by b<h. Normalize fixed input alphabet, tape conventions and accepting state with constant-factor or polylog overhead. This construction is effective and D can be encoded as the fixed rule table in U_h. Now choose x_j=f(code(D)) 0^j, m_j=|x_j|, w_j=f(code(D)) f(x_j) f(bin(m_j^h)). This choice is made only AFTER D is constructed. Distinct j give distinct valid words, N_j=Theta(m_j), t_j=m_j^h<=N_j^h. On a YES for B, D has accepting path of length O(m_j^b polylog m_j)<t_j for sufficiently large j. On a NO for B, D has no accepting path. This proves the equivalence without needing to know which label B gives. The generator constructs words, not labels, in O(j polylog j) bit time for fixed B,h. No recursion theorem, free advice, oracle or universal fast simulator of arbitrary varying machines is used.

Corollaries: U_h not in coNTIME(N^b), since B recognizing its complement would give opposite bits on the same w_j. More generally, for any B whose recognized language on valid words CONTAINS all valid NO words, every sufficiently large w_j is YES and accepted by B: if B rejects, equivalence makes w_j NO, contradiction. For any B whose recognized language on valid words is a SUBSET of the valid NO words, every sufficiently large w_j is NO and rejected by B: acceptance would make w_j YES, contradiction. This yields explicit infinite families of errors/omissions of complement recognition, rather than merely finitely-many-exception reasoning. A deterministic candidate with sub-h time can be flipped to serve as B and yields an explicit adversarial family for that candidate, not for all candidates simultaneously. All these conclusions hold even if P=NP.

## Theorem B: both signs of false-negative vulnerability
Let A be a fixed deterministic explicit SAT-oracle controller correct for U_h on both labels, with all ordinary work and total materialized query mass (including copies and 1 per call) O(N^rho), rho<h. Clock all alternative executions at B0=C N^r for rational max(1,rho)<r<h (ceil using integer powers/root, polylog counter overhead), including every failed track. Reject malformed U_h input before any interaction. On true oracle paths the wrapper does not time out. Let J subset S vary per input, with identical query strings answered consistently. Define X_1 and X_0 as valid inputs admitting a capped accepting or rejecting A^J transcript respectively. A timeout is NOT counted as rejection in X_0. True paths imply U_h subset X_1 and valid complement subset X_0.
Both X_1 and X_0 have ordinary nondeterministic recognizers in NTIME(N^b) for r<b<h: guess answers, certify each YES with a Boolean assignment, verify all literals by sorting identifier/bit records and testing clauses, record complete query strings and bits, check repeated exact-string consistency by fixed-tape merge sort. Same L04-01 positive-transcript proof works for either final bit. For variable-length records, scanned comparison prefixes and rewind are bounded by the emitted smaller record plus headers; linear payload per merge pass, logarithmic passes. Copies, parse, verification, counters, logs, and failed checks charged. Induction on calls proves equivalence: a verified path replays with J equal to the set of its YES query strings, which lies in S and excludes all its NO strings; conversely an actual capped suboracle path has witnesses and consistent strings. This is not enumeration of paths, not an ordinary deterministic speedup, and not an assumption that all query NO answers are correct.
By hierarchy U_h notin NTIME(N^b), X_1 minus U_h is infinite, else finite exceptions hardcoded. By Theorem A applied to recognizer of X_0, an explicit infinite valid YES family lies in X_0 (for sufficiently large padding). Thus on infinitely many genuine NO inputs, suppressing true SAT replies can cause acceptance; on infinitely many genuine YES inputs, suppressing true SAT replies can cause rejection. At least one true affirmative reply was suppressed in each altered path. Both use same A and same ordinary source, but different inputs and possibly different J. No common suboracle or same input for both claims. In particular neither globally monotone-in-oracle-set acceptance nor globally antitone acceptance can implement such a controller. Single complement query, all-negative monotone composition, and all-positive monotone composition cannot attain sub-h paid work; arbitrary nonmonotone controllers remain OPEN. Robustness only needs to hold on the relevant label to trigger the respective contradiction.

## Theorem C: negative-verification budget must fail infinitely often on BOTH labels
Fix any uniform sound negative-query verifier V(Q,z), acceptance implies Q outside S, including optionally a deterministic exact evaluator. Keep the same A. For any fixed rational r in (max(1,rho),h), cap ordinary transcript verification, certificate reading, and verification of every claimed NO at O(N^r polylog N) with fixed constants; absorb logs into b<h. Each YES is verified as above. No need to discover the certificates deterministically: nondeterministic guesses are clocked, all verification paid. A completed certified path agrees exactly with the true S path by induction, including duplicate queries. Let Y_1,Y_0 be the languages having such a certified accepting/rejecting transcript. They lie in NTIME(N^b); Y_1 subset U_h, Y_0 subset valid NO words. By hierarchy Y_1 omits infinitely many YES words. By Theorem A applied to recognizer of Y_0, an explicit infinite sequence of valid NO words has no such budgeted rejecting transcript. These are obligations on A's actual oracle paths, not an assertion that every individual query is hard or every decider uses a SAT oracle. Soundness remains valid if V uses multiple alternative cheap certificate types with a fixed uniform dispatcher and all failed work charged. This is exact contextual proof, not the affine hull of query witnesses.

Unconditional consequence for exhaustive evaluation of negative queries: a materialized formula of length ell with v distinct variables can be verified UNSAT in O((1+ell) polylog(ell+2) 2^v) multitape bit operations. Sort occurrences to acquire actual v, enumerate v-bit assignments, attach bits to occurrences by merge scan and sort clause records, verify each assignment fails a clause; malformed query rejected by parsing. No free random access. On a true path with max negative v<=delta log_2 N, sum negative tariffs <= O(N^(rho+delta) polylog N). For every fixed delta>0 with rho+delta<h, choose r between rho+delta and h and a fixed cap covering this work. Theorem C implies infinitely many YES and infinitely many NO paths must contain a negative query with v>delta log_2 N. This excludes the universal strategy of pushing ALL negative queries into logarithmic-variable exponential kernels at sub-h cost. Large positive queries may still use cheap witnesses. It does not exclude polynomial Gaussian, matching, or other exact shortcuts on these same large queries.
Conditional sharpening if a fixed SAT decider D has O((1+ell)^k) time: certify NO by running D only on guessed negative replies. For every r<h above max(1,rho), infinitely many true YES and true NO inputs must have sum over NO queries (1+ell)^k>N^r (up to fixed chosen threshold constant; choose a larger cap with exponent strictly between r and h). If that sum were smaller then a budgeted transcript exists. For NO this failure occurs on the explicit family supplied by Y_0. Thus the L04-01 aggregate upper bound can be tightened to negative-query tariff alone in the nondeterministic/hierarchy argument, with large positive queries paid by near-linear certificates. This is a tariff restriction conditional on D, not a claim of actual runtime lower bound for D, nor a separation. Under a hypothetical all-k compression construction, ordinary deterministic substitution from L04-01 would also work; no such construction obtained.
