## 1. Directed interchange theorem
Let there be two finite prescribed sequences of physical events U and V on distinct private physical state components. Event on either component leaves the other unchanged, and its available control transitions/costs depend only on its own context (including event type), not the other private state. Global shared mode takes q values. Any order preserving internal order of both sequences is physically permitted; mode impossibility represented by infinity. A final terminal predicate/cost is a function of common mode once both sequences finish. Each letter X has an exact q-by-q matrix L_X of minimum attained nonnegative integer costs for each input/output mode, infinity iff impossible. This is a statement about exact local relations, not arbitrary affine hulls or independent minima.

If for all cross-letter pairs a from U and b from V,
    L_a tensor L_b <= L_b tensor L_a (entrywise),
then the minimum cost over all shuffles is precisely the product for U followed by V, entrywise. Min-plus product (A tensor B)_ij=min_k(A_ik+B_kj) is monotone in either argument including infinity. A shuffle with adjacent b a can be replaced by a b without changing the two physical positions at the seam after these events. Product inequality holds in any compatible prefix/suffix by monotonicity; if original path finite, an actual replacement to the SAME output mode exists at no greater minimum cost. The inversion count strictly decreases; repeated swaps reach U V. Thus the U V product is <= each shuffle product. U V is itself one shuffle, hence equality to pointwise minimum. No expansion or actual sorting performed in algorithm. This is optimal cost preservation, NOT preservation of every path length or all witness identities. Witness lift is a newly attained canonical native accepting path. Reversing the inequality admits V U. Multiple streams: if there is an acyclic consistent preference of stream order (each earlier/later cross pair has the required dominance), a topological order and the same adjacent inversion argument works. Merely finding an orientation for each pair is insufficient if strict preferences cycle.

Only finite alphabet cross-type pairs need checks, not exponentially many occurrences. For arbitrary overlapping state updates, one must separately establish that both orders reach the same complete private state/guard, and use exact shared mode containing all remaining coupling. The theorem does not erase arbitrary overlap. Example of omitted guard: write x=0 and write x=1 have commuting scalar costs but different final x; a goal x=1 distinguishes orders. Thus equality on a forgotten coordinate projection cannot certify interchange.
