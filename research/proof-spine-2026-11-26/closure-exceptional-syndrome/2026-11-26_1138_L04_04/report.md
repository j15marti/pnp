## 1. Two exact certificate languages
For a valid source, dense-renumber states and symbols, preserving start, accept, blank and the two input symbols. Sort framed IDs and record reverse mapping in O(N polylog N) bit time; <=O(N) labels, O(log(N+2)) bits per code. Fix accepting length l with 1<=l<=t, part of certificate, not presumed known. All fields use fixed binary widths O_h(log(N+2)); signed positions encoded via offset t, no modular wrap. Actual touched cells lie in [-t,t]; include input cells up to max(t,|x|-1) for full tableau. Pin q_0=0, p_0=(0,0), q_l=1, q_i!=1 for i<l. Rule ID must be in the explicit source list. These unconditional initial/final consequences and exact range restrictions are checked initially; after composing the rule lookup impose exact state/head successor constraints, and at the consistency stage impose actual memory checks, not guessed forced bits. No other unconditional SAT information claimed. t=0 immediately rejects.

Certificate charts are lists of bounded-fan-in Boolean gates AND/OR/NOT and input/constants, topologically ordered, with explicit wire and output IDs. Let s denote TOTAL gate/wire/output count across chart circuits, with description O((s+log N)log(s+N+2)) bits; count fan-in and outputs, not just noninput gates. Restrict s to a polynomial cap when asserting cost exponents. Nonuniform circuits are guessed per input as certificates, not supplied as free advice.

A (tableau): circuits Q(i), H_k(i), R(i) for state, two head positions, chosen rule ID; A_k(i,j) for actual symbol at tape k, time i, cell j. For all legal i<l, rule R(i) must have source state Q(i), scanned symbols A_k(i,H_k(i)), destination Q(i+1), and moves matching H_k(i+1). For all j in cell domain, A_k(i+1,j) equals write symbol of chosen rule if j=H_k(i), else A_k(i,j). For all j, A_k(0,j) equals input initialization (blank except actual tape1 bits). Accept guard as above; exclude illegal state/head/rule codes and out-of-domain head addresses. No constraint needed on unused address encodings. This is exact by induction on i, with no independent marginal substitution. Conversely any accepting path gives such finite tables, hence circuits by explicit truth-table lookup. Candidate invalid iff some legal pair (i,j) violates one predicate, including initial/final checks. Fixed terminal predicates can be ORed into violation circuit. This uses two address indices.

B (event chart): retain Q,H,R, drop all cell tables. For each tape k=1,2 guess a circuit P_k(r) mapping rank r in [0,l) to chronological event i in [0,l), and I_k(i) for the inverse map. The event at time i is (H_k(i), i, read symbol, write symbol), latter two determined by exact source rule R(i). Check each i in [0,l):
  Q(i) and Q(i+1), H(i) and H(i+1), R(i) satisfy the state and nonwrapping head-move constraints and original transition IDs. Require valid index ranges and first/final states as above.
Check each rank r in [0,l), for each tape:
  0<=P_k(r),I_k(r)<l; I_k(P_k(r))=r and P_k(I_k(r))=r.
  If r>0, (H_k(P_k(r-1)),P_k(r-1)) strictly lexicographically less than (H_k(P_k(r)),P_k(r)).
  Read at P_k(r) equals previous rank's write symbol if r>0 and both positions equal; otherwise read equals actual initial tape symbol at its position.
Use one shared free index u for ALL time and rank tests (OR of violations), plus explicit guards for legal u; no invalid-index accidental witnesses. At u=0 also check initial state/heads, at a fixed constant l check terminal state, or include those checks unconditionally. Only O(log(t+2)) address inputs, with constant number of circuit compositions. P and I are per tape, never independently marginalize their joint inverse and chronology obligations. This is an exact memory consistency test, not a probabilistic permutation check.

Proof (B soundness): inverse/range checks establish bijection of all l events. Strict order forces P to sort by (physical cell, original time), so each cell forms a contiguous block in chronological order. First read equals original initialization, each subsequent read equals preceding actual write. By induction on chronological i these are exactly the reads in the actual execution of selected rule sequence, since no other event writes that cell between the two. State/head checks give legal transitions; final guard gives acceptance. Conversely every accepting path yields the event log and unique sorted lists and inverse maps. All are finite functions and have explicit lookup circuits. No need for small-circuit acquisition in this equivalence, no claim the two charts' minimum sizes are polynomially related below clock scale. Recover actual path by evaluating chronological circuit for every i; costs at least enumerating the path if requested, not part of decision recognizer. The same original IDs preserved throughout.

Adversarial minimal source: two legal rules (0,0,0,2,1,0,stay,stay), (2,2,0,1,2,0,stay,stay), empty input, t=2. Both rows look locally legal, but first writes symbol 1 and second needs symbol 2 at same cell. Source NO; independent per-row or per-window feasibility with unlinked memory falsely accepts. Both charts reject. Duplicate rank omission caught by inverse; a permuted but inverse-consistent ordering caught by strict order. This falsifies marginal-window universal verification, not exact gluing. Independent full direct chronological memory replay is the second implemented semantic checker.

## 2. Explicit violation query, fully charged (PROVED scoped)
For either chart of size s, compile a Boolean circuit V with output 1 iff a legal address exhibits a violation. Compose constant many copies of chart circuits by wiring outputs to next copy's input; there is no recursive unfolding across time. Comparators, increment/decrement, nonwrapping move logic and equality use O(polylog N) gates. Hardwired lookup of source rule table (dense symbols) uses O(N polylog N) gates: equality of index to each listed row and OR/multiplexer of the corresponding output bits, range check; initial tape lookup similarly enumerates original input positions, default blank. No random-access cost hidden, these are explicit gates. Thus V has O((N+s)polylog N) gates, and topological list can be emitted by scanning each fixed copy, renumbering IDs by offsets using O(log(s+N)) bit counters, plus sorted source normalization. No need to evaluate arbitrary guessed gates on a multitape while constructing V. Check guessed gate syntax, arity, backward reference indices, output widths and length bound by sequential parsing; materialized copies and lookup gates all charged. Apply ordinary two-way Tseitin clauses for every gate, output forced true; proper 3CNF using constant-size padding for 1/2-literal clauses with fresh variables, as in L04-03. Encoded length and compile time both O((N+s)polylog(N+s+2)). B violation selector has one O(log t) index, A two; all auxiliary variables forced by the chosen inputs (padding auxiliaries irrelevant for existence). Query satisfiable iff proposed certificate invalid. This is not succinct SAT: the complete ordinary CNF is emitted; only its checked certificate is succinct.

An explicit source-independent circuit cap s=O(N^a), a>=0 fixed, can be guessed in O((N+N^a)polylog N) nondeterministic bit time; abort any malformed or over-budget branch. Assume SAT decider D runs in O((1+ell)^k) for fixed k>=1. Then either chart is verified in time O(N^{k max(1,a)} polylog N) including all guesses, parsing, copies, syntax and SAT evaluation, regardless of actual clock t<=N^h. This is a nondeterministic recognition of YES by ONE certified negative SAT query, not deterministic circuit discovery. Branch choice guesses chart type; any successful certificate passes the same source and guard. No guessing a correct answer without verification. Ordinary explicit full trace lookup provides finite (not necessarily compact) charts: B O((t+1)polylog N) gates, A O((t+1)(t+|x|+1)polylog N), by equality-select lookup across complete finite tables. This upper bound is on witness existence; no free discovery, direct construction requires a real accepting trace.

## 3. Conditional simultaneous witness-size obstruction (PROVED implication)
For fixed h,k,a with k max(1,a)<h, suppose D exists as above. Let Z_h,a be the set of valid YES words admitting at least one chart A or B of size <=C N^a for fixed C>0. It is recognized by the capped nondeterministic compiler/evaluator in NTIME(N^b) for fixed k max(1,a)<b<h. Every accepted word is genuinely YES by the proof; every word with admitted chart has an accepting branch. If only finitely many YES words were missed, hardcode them and contradict U_h notin NTIME(N^b). Therefore infinitely many genuine YES words have BOTH minimum tableau-chart and minimum event-chart sizes >C N^a. The simultaneous obstruction is on the SAME input, not two separate families. No NO chart can be valid, and this is not a coNP proof system for NO. The hard words are existential, not explicitly acquired. Quantifiers: for each fixed k with such D, each fixed h>k, each a>=0 with k max(1,a)<h and each fixed C, infinitely many w in U_h meet both bounds. Do not infer actual evaluation-time lower bounds or representation independence.

Sufficient P!=NP premise: exists fixed a such that for EVERY fixed h every YES w in U_h has one of these charts with size <=C_h N^a (or for arbitrarily large fixed h, uniformly bounded exponent a). Under P=NP choose its actual k then h>k max(1,a). Contradiction. The premise is OPEN; even P=NP would yield per-language polynomial witness generation with h-dependent exponent, not this uniform exponent across h. This is not a new hierarchy theorem; it is an explicit U_h instantiation of the known easy-witness/algorithmic method. Contrast Murray-Williams Lemma 4.1's additional fixed circuit-size assumption, not a consequence of P=NP. Thus no unrestricted conclusion from the theorem.

Same-execution ledger: per branch T=O(N^b), peak S<=O(N+T), cumulative visited-cell-time CM<=O(T(N+T)); upper bounds, not lower bounds. Two chart tracks as nondeterministic disjunction, not parallel deterministic shortcut. A deterministic search over circuit descriptions would cost 2^{O(s log(N+s))} candidates, not free. Candidate checking includes failed guesses on each clocked path. No uncharged proof discovery, semantic canonicalization, equivalence, #SAT, real-valued arithmetic, random/nonuniform decision algorithm, or simultaneous resource lower-bound transfer. Reconstruction on request expands l rows, potentially above speedup deadline; not required for decision. DISJ PASS scoped exact OR of violations and actual witnessed paths; relativization OPEN (arbitrary oracle transition answers cannot be encoded by finite rule lookup); algebrization/Natural Proofs OPEN/no claim; deterministic-configuration and simultaneous DTISP gates scoped upper accounting only. No lower bound from overlapping demand. Equality controls exact through read/write and inverses; affine, matching, bounded-width and alternate compact circuits can still yield easy decisions; no new reductions or benchmarks for those domains.

## 4. Reciprocal-series assessment
For the concrete fixed copy/reverse machine tested below and even m input bits, t=2m+2, N=Theta(m), explicit event-record count f_E(m)=2t=Theta(m), rectangular tableau-cell count f_A(m)=2(t+1)(2t+m+1)=Theta(m^2) for the displayed deliberately oversized rectangle. These are exact representation counts, not unavoidable work. Sum over even m of 1/f_E diverges logarithmically; 1/f_A converges with tail Theta(1/M). For integer p>=0, sum m^p/f_E diverges for all p, while sum m^p/f_A converges only p=0. Exponential-scale samples alone do not preserve multiplicity. Both are polynomial, so unweighted convergence is not a separation diagnostic.
Let F_h(n)=max(1,max over YES |w|<=n of min(s_A(w),s_B(w))). The conditional obstruction gives F_h(n)>C n^a on infinitely many lengths (for each fixed C) in the above exponent range, not eventual superpolynomial growth or summable reciprocal tails. Trivial event lookup gives F_h(n)=O(n^h polylog n), so weighted reciprocal sum n^p/F_h(n) diverges for any integer p>=h, even if SAT were in P. No universal polynomial lower bound for arbitrary deciders follows. Actual charged verification has a single compiler and one SAT evaluation, not a recursive geometric series; if explicitly enumerating candidate descriptions, charge all candidates, and summing inverse sizes is not summing their work. For no-certificate input minimum is undefined and excluded, not treated as infinity in a series.
