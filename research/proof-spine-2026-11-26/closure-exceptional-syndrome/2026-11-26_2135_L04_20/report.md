## 1. General guarded capacity lemma
Given any verified partition of a finite undirected source graph into b>=2 nonempty regions, wires are original interregion edges. An endpoint-free local row is a collection of pairs of boundary edge incidences realized simultaneously by spanning vertex-disjoint path fragments, no closed components. Exact or conservative upper row sets allowed, never omit attained rows. For any wire subset X, define c_R(X)=max over retained rows of the number of pairs having exactly one wire in X. An empty verified table forces an endpoint in R; otherwise capacity well-defined. Fix endpoint-region guard i,j (i=j allowed) and suppose neither endpoint block has any wire in X. A global spanning path in this guard has a nonempty wire sequence, since b>=2. Its first and last wire lie outside X, so total boundary transitions is even; if any X wire selected, >=2. Every consecutive pair of wires corresponds to an internal path fragment; within a region without an endpoint the complete row is retained, hence contribution <=c_R(X). Endpoint blocks contribute zero by disjointness. Thus sum_R c_R(X)<=1 implies no wire in X can be selected in this guard. This is sound even with arbitrary boundary sizes or unbounded switches if chart acquisition is paid. If the union of certified dead wire sets contains every port of some block, that guard is NO (a spanning path must connect the block to other blocks). Discharge all b(b+1)/2 guards to certify whole source NO. No assumption of independent row realizability, no counting oracle. Candidate cuts must be acquired within budget. General extension: safe endpoint-specific upper crossing count or selected-end parity can strengthen, not used here.
