## 1. Exact matching chart adapter
Let L be live original tuples after sound forced closure. Project onto B,C and collapse equal B-C pairs only for graph recognition; keep all labeled original triples in each pair's domain. Require projection maximum degree <=2 and perfect matchings in each component; after removing unsupported edges each component is a single forced edge or even cycle. A cycle has exactly two perfect matchings (one shared Boolean phase); a forced edge has no free phase. Form auxiliary bipartite graph with B-C pair nodes and A-owner nodes, incidences retaining original IDs. Its connected blocks partition all pairs and A-owners. For each block, retain exactly those assignments to the incident phases for which the active B-C edges can be perfectly matched to the block's A-owners. Require at most 3 incident phases per block. At most 8 ordinary bipartite matching calls per block. A native cover gives a projected matching and a feasible block completion; conversely simultaneous phase assignments satisfying all tables give pair-disjoint original tuple selections whose union covers every owner exactly once. The shared phase IDs are not cloned as independent variables. Guarded deletion and selection are handled by sound source pin/exclusion before chart acquisition; unrecognized input returns UNKNOWN. ## 2. Contextual affine-implication lemma
For explicit exact table factors R_i on scopes P_i, let H be the binary implication graph of all absent unary and binary projections. Let A be the GF(2) system of all affine equations true on every row of each table. Both are necessary conditions, not asserted to characterize R. For a guard g of at most two phase literals, propagate H from all pins, then use Gaussian elimination on A and the resulting pins to derive every implied unary bit; alternate until no additional bit is found. Opposite forced bits, H SCC containing a bit and its complement, or an inconsistent Gaussian system are sound contradictions. Every inference is a logical consequence under g; if a solution under g existed it would obey every inferred bit and every affine row. Therefore a conflicting g licenses the unguarded clause not(g) on the current guarded residual, and NOT on unrelated guards. Import the clause as an exact table of permitted unary/binary words, regenerate constraints and reclose. If the resulting binary graph has an inconsistent SCC, refute source. Guard-free contradiction is also valid. No claim that lack of contradiction means SAT. The hybrid is structural: matching changes the source into exact phase relations; implication reachability then changes the RHS/pinned domain for Gaussian, and Gaussian unary conclusions reenter graph reachability. Neither a hull nor a separately attained matching is used as a joint witness.

A useful sufficient coverage condition: if the set of all pair nogoods discoverable by the above closure has inconsistent 2CNF, a complete sweep refutes. Monotonicity of added sound clauses means a sweep never loses a previously available inference. In particular, if the four fibers of any two acquired phase bits each refute by the hybrid, the four learned clauses cover the entire phase square. No recursive exponential branching needed. The general fixed-point variant rescans all unary/pair guards after a new deduction and stops if none is new. At most 2d+4 binom(d,2) distinct guards on d phases. Every individual propagation adds at least one pin or stops, at most d+1 rounds. For constant-arity input and d=O(N), chart tables O(N), learned clauses O(N^2); dense GF(2) row elimination with O(N^2) rows and O(N) columns uses O(N^4) elementary bit work per round; direct scanning graph O(N^2). One closure O(N^5), one complete sweep O(N^7), full fixed point O(N^9) in a straightforward bit-array implementation before polynomial address/tape simulation overhead. Matching acquisition, verification, failed trials, source copies and no more than polynomially many certificate traces are charged. Fixed number of replicas; serial total, peak memory polynomial, cumulative memory <=(T+1)S on same run. This is a polynomial sound partial refuter, not all-input coverage; implementation executes one sweep with reclosure, not full fixed-point version. No exact global counting oracle. For unrestricted-width local relations, charge explicit table size or return UNKNOWN.
