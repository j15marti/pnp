## 2. CST: crossing-cluster synchronized-track lemma
Circular phase occurrence sets cross when four alternating distinct positions belong to two labels. Connect crossing labels, merge each connected component. Fixed-label occurrences may be singleton blocks. Resulting partition is noncrossing: in disk with positions on strictly convex boundary, convex hulls of distinct blocks intersect iff some alternating endpoints; unions of hulls of connected components are connected and pairwise disjoint. Alternating representatives of two unions would force intersecting paths by disk separation (paths can be perturbed in disjoint small neighborhoods). Contradiction. Thus after linear cut spans are laminar and each nested child lies in one gap of parent consecutive occurrences. Bottom-up compute exact child 2x2 gap relations once and compose into parent sequence; free labels disjoint between clusters. Keep boundary bit pair and witness provenance. Distinct clusters' phase assignments need not be enumerated jointly. For each cluster admit any of the following methods.

(a) Frontier: traverse cluster occurrences after gap contraction, remember phase values from first through last use and initial/current A edge bits. Branch on each phase when first introduced, forget after final use. Invariant is exact reachable states under retained values and attained boundary bits; induction by actual transition entries. At most 4*2^w states where w max active free labels. If w<=c log2 N for a fixed c, fixed polynomial cost, even when crossing component size linear.

(b) Synchronized color runs: when crossing graph bipartite, split into maximal runs of either color. For each side independently, orient its runs (try all orientations under a paid logarithmic run cap). Reverse means reverse order and transpose matrices. Collapse adjacent identical phase labels in a run by Boolean multiplication separately for each value. Require no returning label within an oriented run and a common order of labels across all runs on that side. DAG of successive distinct labels tested by topological sort. Process each label once, choose one phase value and perform transitions on every track in which it occurs; other tracks unchanged. Initial/current edge-bit vectors retained. For r runs, at most 2^(2r) states and 2^r next vectors per value. State invariant exact simultaneous path existence; witnesses retained. Join original consecutive run endpoints, reversing coordinates as needed, and combine both sides (their free labels disjoint). No independent assignment of the same phase. Boundary relation is exact. Admit fixed log run cap on total r, including 2^r orientation acquisition and 2^(O(r)) joins.

(c) Arbitrary aligned tracks: same common-order construction but cut into at most fixed R contiguous tracks not necessarily color runs; all tracks processed jointly. Exhaustively acquire cut sets O(N^(R-1)) and 2^R directions, DAG recognition and product DP. This is polynomial for fixed R, NOT for arbitrary logarithmic R cut enumeration. Necessary cut lower bound: two consecutive occurrences of one label with another label intervening require a cut between those positions. Minimum integer interval hitting set computed greedily by earliest right endpoint. If lower bound exceeds cap decline, not NO. Dense staircase example has many color runs but just 3 aligned tracks.
