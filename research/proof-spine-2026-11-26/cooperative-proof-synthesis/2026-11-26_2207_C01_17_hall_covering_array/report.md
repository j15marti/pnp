## Exact phase-linear Hall theorem
Each B-C component with a perfect matching is a forced path or a cycle admitting two alternating perfect matchings. Index original cycle phases in lexicographic matching order. Fixed phase x selects exactly one partner C for each B owner. Construct graph A-B with edge ab iff a native tuple (a,b,c) survives the selected B-C partner. A native perfect matching exists at x iff A-B admits a perfect matching: project one direction, choose the available tuple for each A-B matched edge in the other; B-C partner map is bijective, so C coverage follows. If B-C itself has no perfect matching, reject immediately.

For any U subset A, each B owner's neighbor membership depends on at most its own cycle bit, or is constant. Count separately by phase component; write h_U(x)=|N_x(U)|=c_U+sum w_Ui x_i, with integer weights |w|<=n and c<=n. Every actual solution satisfies h_U>=|U|. All Hall inequalities together are exact by the equivalence above and Hall's theorem. A maximum matching at a proposed full phase word exposes a deficient U by alternating reachability from an unmatched A owner; scan original tuples to acquire coefficients, not only a no-good for the tested word. A cut certificate is source-verifiable by per-B support truth tables. Under a partial guard, maximize each free unary contribution separately to get a sound upper bound. If the upper bound is below |U|, exclude the entire fiber and discharge the guard. No marginal support assumed exact jointly.

## Complete deterministic cut acquisition on bounded-locality chart class
Let H be the incidence graph between A owners and all supported B-C pairs (ignore pairs that occur in neither possible component matching). A connected block of H involves a set P of cycle phases. Suppose each block has |P|<=3 (explicit graph scan verifies this). Under any full word, each B owner has one active B-C pair; its incident A-B edges lie in that pair's block. Consequently maximum matching separates across blocks, and an alternating search from a single unmatched A root stays inside that block. Its Hall neighborhood depends only on that block's phases.
Use d distinct binary labels i=0,...,d-1 of length ell=ceil(log2 d) (d<=1 direct). Enumerate all affine Boolean forms on these labels, word x_i=a dot i+b mod2, a in F2^ell, b in F2. There are 2^(ell+1)<=4d words. On any <=3 distinct labels all values attained: the augmented vectors (i,1) are independent over F2 (no two equal; odd-size sum cannot vanish in final coordinate). Thus every local assignment appears. For each word compute a maximum A-B matching; collect a cut from EVERY unmatched A root. For any invalid full assignment, some block fails to saturate A; the list includes a word agreeing on its local P, and at that word some unmatched root in this block yields a cut also violated by the original assignment. Therefore the acquired finite inequalities are collectively EXACT, not merely necessary. Overfull blocks need no separate rejection rule because total equal shores and all A saturated implies all B saturated. No complete assignment enumeration. For general fixed r one can instead use O(d^r) words with at most r ones covering each r-scope pattern; still polynomial for fixed r, not for variable r. Does not prove all arbitrary P3DM have small locality or the learned formula is always refutable in P. This is an alternate acquisition of the prior bounded-arity chart information, not a universal improvement.
