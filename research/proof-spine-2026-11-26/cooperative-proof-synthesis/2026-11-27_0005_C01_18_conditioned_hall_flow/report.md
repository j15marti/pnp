## Theorem 1: exact fractional Hall projection (no locality cap)
Assume B-C projection degree<=2 with perfect matching, so every supported pair e has indicator z_e(x)=1, x_j or 1-x_j. Unsupported pairs deleted with original IDs retained. For each A owner a, draw an edge to pair node e=(b,c) for every original tuple (a,b,c); a distinct original tuple ID labels that edge. Pair nodes have nonnegative capacities z_e(x), total n, for any x in [0,1]^d. Give every A demand 1; require nonnegative edge flows meeting demands and pair capacities with equality. Fractional max-flow/min-cut (or capacitated Hall) gives feasibility iff for every U subset A, sum of capacities of its pair-node neighborhood >= |U|. The sum equals C01-17 phase-linear Hall expression: if a B has both mode pairs in the neighborhood their masses sum to 1; if one, the matching unary contribution. Hence all Hall inequalities have a polynomial-sized extended formulation independent of regional arity. At integral x the transportation network has an integral solution iff feasible; original tuple reconstruction covers A and the selected perfect B-C matching. At fractional x only a relaxation: cannot accept SAT. This is a projection identity, not integer hull equality.

## Theorem 2: polynomial conditional flow extension
Let x_i be first moments, y_ij=y_ji formal pair moments, y_ii=x_i. For each i, both fibers b=1 and b=0 carry mass h=x_i or 1-x_i respectively. Define q_j=y_ij for b=1 and x_j-y_ij for b=0. For each fiber build the same source-labeled transportation network with demand h per A, pair capacities h, q_j, or h-q_j for forced, phase1, or phase0 pairs. Include base network and 0<=x<=1. Capacities nonnegative follow from nonnegative flows, or lifted box constraints. A genuine integral source matching gives feasible flows in every fiber by multiplying its tuple indicators by x_i or 1-x_i. Conversely projection of the extended LP onto (x,y) is exactly the base Hall+box inequalities plus each multiplied by x_i and 1-x_i and multilinearized (Sherali-Adams degree-two moment relaxation, naming levels varies). Proof: for fixed x,y each network is independently feasible iff all its capacitated Hall inequalities hold, which are exactly the lifted inequalities; shared y symmetry, not independent pin marginals, enforces pair moment agreement. No claim that independent flow realizations glue to a common global distribution. Integral x reconstructs source witness via base network. Thus infeasible LP certifies native NO; feasible fractional LP returns UNKNOWN unless separate witness acquired. This hybrid uses matching conservation to compactly acquire the entire lifted inequality relaxation, not merely a portfolio of solvers. No bounded-locality assumption.

General arbitrary-degree symbolic extension: instead of cycle phases, use all supported B-C edge bits z_e, B/C incident sums=1, and shared moments z_e z_f.
