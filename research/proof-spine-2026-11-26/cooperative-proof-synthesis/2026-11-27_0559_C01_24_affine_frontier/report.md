## Theorem (exact ordered syndrome trellis)
For any explicitly acquired sequence of nonempty finite groups G_i of pairs (c,p) over binary vector spaces, compute the exact set of XOR parent outputs p_1+...+p_m subject to c_1+...+c_m=t. Translate each group's syndrome by a fixed anchor and translate t by their sum, so every group contains a row of syndrome 0 (parent unchanged). Let U_i span all normalized prefix syndrome rows through i, V_i span all remaining rows, and w_i=dim U_i+dim V_i-dim(U_i+V_i). Any compatible path has prefix syndrome s_i in U_i intersect (t+V_i); the latter is empty or a coset of U_i intersect V_i, cardinality 2^w_i. Start s_0=0; from s_i add an actual row (c,p) of G_(i+1) to reach s_(i+1)=s_i+c only if t+s_(i+1) lies in V_(i+1). Label the arc by p. Retain distinct parent labels, and backward trim all vertices/arcs not reaching target t. The path-label XOR set is precisely the exact parent support. Forward proof: any original tuple of factor choices follows these arcs, since its true suffix is in V_i. Reverse proof: every retained path selects actual rows and ends at t. Merging equal prefix syndromes is exact because future choices depend only on that syndrome and factor index; preserve all labels to reconstruct output, not an independent parent marginal. No affine-hull substitution for actual support. An empty terminal layer is an exact NO. At a nonroot join a nonempty DAG alone does not authorize arbitrary cheap future joins. An optional expansion accumulates pairs (syndrome,parent word) under the cap. At root no output expansion is needed. Weighted additive costs also permit ordinary shortest path on this DAG, provided weights are retained on each row/arc and bit costs paid; not implemented.
