## Exact shifted reciprocal lift contraction
For each source owner span(u,v), replace by span(a,b+u), span(b,a+v), where a,b are new private independent coordinates. Given private target (s,t), compare private coefficients: if parent coefficient pair is (x,y), left coefficients are (y+s,x) and right (x+t,y). This follows by writing the two contributions explicitly, not by assuming private zero. In an explicit forest of repeated lifts, every leaf pair is an invertible affine function of its original root pair. Only final leaves must be nonzero; intermediate root or ancestor values may be zero. Recursively compose the swaps and translations. Each leaf excludes exactly one of four possible root values. Intersect these masks per root, yielding exact root domains. A mask of size zero refutes; one or two points over F2^2 is an affine coset and becomes exact linear equations; size three is a puncture. Every valid root tuple with original syndrome and pulled-back affine guards uniquely reconstructs all leaves. Conversely any valid leaf tuple determines such root values. Extra affine guard G y=h pulls back to GP x=h+G c if y=P x+c; no marginal relaxation.

For one lift of each original root, zero private target retains three values; any of the three nonzero private settings leaves exactly two values, because the two excluded root values are (0,s) and (t,0). At later depths the intersection rule is exact, but a nonzero internal shift need not itself guarantee a particular reduction. The theorem requires supplied and verified explicit ancestry, not discovering hidden ancestry for free. It covers arbitrary explicit private targets, unlike a zero-private-only lift lemma.

## Paid potential
Let q be the number of remaining three-value root domains. After incorporating affine masks and all joint equations, choose one such domain and branch over its three values, fixing its coordinates. A contradiction can prune earlier. When q=0 solve by exact GE. Set B(q)=(3^(q+1)-1)/2. B(0)=1 and B(q)=1+3 B(q-1). At each node reserve a fixed finite bundle R of polynomial work tickets for recognition, closure, bounded independent track probes, failed probes, certificate verification, handoff, and one branch or terminal. Each actual operation is charged before execution. No resetting on a new track or failed attempt; duplicated messages still consume their bounded reception/verification tickets. Retire unused tickets; no semantic completeness is asserted for the auxiliary probes. A fixed finite protocol, e.g. four probes with at most twelve directed transmissions among tracks plus deterministic local checking and GE, fits a constant number of tickets per node; the four-probe illustration alone is not the entire ledger. If an optional probe exceeds its prepaid budget, mark UNKNOWN and continue to the exact fallback. A branch transfers at most R*B(q-1) to each child; at least R is retired at expansion. At terminal retire all remaining local credit. At preprocessing reserve a polynomial block for regeneration, masks, guards and the fixed scheduler; no semantic oracle.

A nonnegative integer potential is remaining preprocessing budget + sum over unprocessed branch jobs of R B(q_j) + remaining reserved tickets of active jobs, where each ticket has fixed polynomial bit-work capacity. Under this protocol the credit funds the explicit complete computation; the bound is not inferred from merely capping an unknown solver. For serial DFS peak storage is polynomial in N (depth <=q<=N and explicit matrices, no exponential cache), cumulative memory <=(T+1)S on the same execution. If certificate storage is retained it can instead be proportional to the charged proof length. For fixed root count five, q<=5, all explicit depths and private target settings covered. For general m, time O(poly(N)(forest size+3^q)), polynomial for q<=c log_2 N with fixed c. Use deterministic bit RAM with O(log N)-bit addresses (or charge larger address length), exact F2 bits and integer counters with O(N) bits.
