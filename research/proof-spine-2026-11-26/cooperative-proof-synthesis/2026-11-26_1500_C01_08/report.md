## Replica A constructive rank-cut theorem
For any factor order let A_j=sum of P_i for processed prefix, B_j=sum for suffix, W_j=A_j intersect B_j. W_0=W_s=0. Retain set S_j of precisely those linear functionals on W_j attained by some functional on A_j satisfying every prefix factor. Each evaluation of a basis is a bit word; at most 2^dim W_j states. At step j join prior state u on W_(j-1) with an actual row v on P_j by Gaussian consistency. Since P_j subset B_(j-1), A_(j-1) intersect P_j = W_(j-1) intersect P_j. Thus any actual prefix witness for u glues with v to a functional on A_j, and conversely any new prefix witness restricts to such a pair. W_j subset W_(j-1)+P_j: write w=a+p; w,p belong to B_(j-1), hence a belongs to W_(j-1). Evaluate this new state using u,v alone; it is independent of choice of prefix witness. This proves induction for exact attained S_j, including all correlations with suffix. Empty state set proves NO; nonempty final empty-interface state yields original witness via stored rows and Gaussian extension. Exact witness storage and all original-ID checks paid. Work <=2^k sum_i r_i candidate state-row tests for max cut rank k and r_i explicit rows, plus polynomial Gaussian/access/copy overhead. No enumeration of all words on a large individual factor plane. ## Replica B and integrated cut identity
Let V be raw coordinate form space, A,B spans of scopes on two sides of any factor partition. Let K=span of homogeneous normals of all necessary local affine equations. Every equation belongs to the scope of its originating factor, so K=K_A+K_B with K_A subset A, K_B subset B. For quotient q:V->V/K, q(A) intersect q(B)=q(A intersect B). Indeed q(a)=q(b) implies a+b=k_A+k_B, and a+k_A=b+k_B belongs to A intersect B with the same quotient image. Reverse inclusion immediate. Thus boundary can be acquired by finding raw variables occurring on both sides, reducing their coordinate forms and taking a basis. ## Paid layout acquisition: KNOWN THEOREM transfer
Jeong, Kim, Oum, Constructive algorithm for path-width of matroids, arXiv:1507.02184v4, section 6.1 and theorem 5.10, SODA DOI 10.1137/1.9781611974331.ch116. Input is arrangement of subspaces over fixed finite field, not a graph or required source chart. The iterative compression algorithm tests target width k, returns a layout or rejects that width. Section 6.1 obtains a width-at-most-3k branch decomposition in the iterative test, theorem 5.10 gives a subroutine with polynomial prefactors and 2^(151 theta k)|F|^(12 theta^2); for GF2, theta<=3k, these terms are <=2^(561k^2). Together with preprocessing and polynomial number of subroutine calls this gives 2^O(k^2) poly(N) acquisition on the explicitly encoded arrangement. The native owner adapter above supplies exactly such an arrangement; it requires no Hall-chart recognition. Consequently there is a uniform polynomial partial decider for every fixed c on the class admitting a factor-plane path layout of rank <= floor(c sqrt(log2 N)). It rejects a too-wide layout as an admission failure, NOT source UNSAT. Rank DP given a verified logarithmic-width layout is polynomial, but this specific acquisition theorem only justifies square-root-logarithmic cap. Fixed rank k (e.g. 8) also uniform polynomial. External layout algorithm not implemented or executed; theorem transfer only, not claimed a new FPT theorem. General matroid pathwidth is NP-hard (Kashyap, arXiv:0705.1384v1 theorem3.2); no transfer of that hardness to these native arrangements claimed.
