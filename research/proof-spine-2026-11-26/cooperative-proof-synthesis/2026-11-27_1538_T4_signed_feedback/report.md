## Main theorem: incident-local exact feedback and aggregate strict-move credit
Assume normalized clauses with distinct variables, no tautologies. For row C at assignment a store k=true count and t=signed sum; keep k mod3 and t mod3 separately. Define B(k)=[k=0], Z(k,t)=[k>0 and t=0 mod3]. For literal of sign sigma at variable v, let delta=-1 if currently true, +1 otherwise. Its contribution to the flip score is (B(k+delta)-B(k), Z(k+delta,t+sigma*delta)-Z(k,t)). Summing over rows incident to v is exactly the global change in violated rows and satisfied signed-zero rows; all other rows cancel. To flip v, subtract old contributions to all variables in incident rows, update these rows and assignment, then add new contributions. New certified row adds only its own incidence contributions. Choose a strictly negative first score, minimizing resulting bad count, then signed-zero count for residue arm, then original ID. Initialization O(L+n); each update O(n + sum_{C contains v}|C|) arithmetic operations with linear scan for winner; O(|C|) admission. Each count uses O(log(m+K)) bits, indexes O(log N) for polynomial row store; retain O(L+n) logical cells plus proof store. No floating arithmetic or semantic oracle. This avoids full candidate rescans O(nL), exactly preserves deterministic move sequence including residues. Two-start credit: for h fixed trajectories and at most K distinct admissions, define Phi=sum_j U_j+(h+1)(K-a), U_j current violated-row count, a admitted count. Each admission increases sum by <=h and lowers credit by h+1, each admitted strict flip lowers one U_j by >=1. Thus total flips <= h*m+h*K by telescoping, total flips+admissions <=h*m+(h+1)*K. No credit reset on learning. For fixed width w, K<=sum_{j<=w}2^j binom(n,j) polynomial.
