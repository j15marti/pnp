## 2. GUARDED-MATCH-01: NP-completeness of this same matching restriction with only signed equality guards

Each clause gets one 3x3 selector block plus three 3x3 implication blocks. Every 3x3 block has rows 111,101,011. Its only matching permutations (zero-indexed) are (0,2,1),(1,2,0),(2,0,1). The first-column horizontal prefix bits in rows 0,2,1 respectively are exactly the three one-hot state indicators. The 2x2 block's first row first-column prefix is a free Boolean variable x. Place all blocks on the diagonal of one availability matrix, all off-block availability zero, use the SAME matching grid above with common boundary. Physical edge prefix positions offset by their block starts; no added nonlocal relations except explicit guards.

For clause (l1 OR l2 OR l3), selector indicators s1,s2,s3 sum to1. Its jth implication block has indicators a,b,c summing to1; guard a=s_j and b=1-l_j, each one signed equality on two original physical prefix bits, including negative literals by toggling RHS. Then c= l_j-s_j must be Boolean, precisely s_j<=l_j. If clause true, choose a true literal as selector, all implication blocks uniquely complete for fixed selector and variable values. If grid satisfies guards, one s_j=1 forces l_j=1. Thus full equivalence, witness lift both directions with original grid edge IDs. No target model supplied. ## 3. NEG-SQUARE-02: strengthen L02 negative-coordinate bound by logarithmic factor
Same unguarded matching-grid restriction. Block-local NNF leaves on two-table chain are constants, a_ij or not a_ij. Let r count distinct coordinates with a negative leaf, p=r/n², circuit size s. Bad-coordinate matrix B. Any q-by-q all-good square yields a monotone Match_q circuit of size <=s by fixing outside to a perfect matching on complementary rows/columns and all other edges zero. This preserves exact decision. Cavalar et al arXiv:2507.16105v2 (6 Nov 2025), Theorem1 and Section3, p6: (log s)^3(log q)^2 >= Omega(q) for growing q. Source proof statement and implication inspected, sunflower proof not independently reconstructed.

First audit previous bound: q=floor(min(n/2,n²/(2r))) least-bad rows have at most n/2 bad incidences, leaving q good columns. Correct. New stronger acquisition: at least n/2 columns have <=2pn bad rows (Markov). For uniform q distinct rows, each such column is clean with probability C(d,q)/C(n,q), d>=n-2pn. Hence expected common clean columns >=(n/2)(1-2p-q/n)^q when base nonnegative. For q polylog n and p<=ln(n)/(16q), with 2p+q/n<=1/2, use ln(1-u)>=-2u to get expectation >=(n/2) exp(-4pq-2q²/n)>=n^(3/4)/2 times exp(-o(1)) > q for large n. No random compiler: exact deterministic conditional expectation. At selected rows R, let U be remaining rows, J common clean columns, k=q-|R|; integer mass M=sum_{j in J} C(d_j(U),k). If initial M>=q C(n,q), select remaining row maximizing new mass. Sum of new masses over all rows is k*M (count each completion k times), so max >=k*M/|U| and average clean count never decreases after dividing by C(|U|-1,k-1). At final J has >=q. All binomial integers <=2^n and sum <=n2^n, exact arithmetic O(n+log n) bits; naive O(n^4 poly(n)) scan and arithmetic suffices. No semantic circuit oracle.

If s<=n^C fixed, matching lower bound implies every growing clean square q has q=O(log^5 n) first, then q=O(log³ n (log log n)²). Pick q=ceil(K log³ n (log log n)²) with K sufficiently large depending on C and source constant, so any such square contradicts bound. Therefore p>ln(n)/(16q) eventually (otherwise construction above; when p already large inequality trivial). Thus r=Omega(n²/(log² n (log log n)²)) = Omega(N/(log² N (log log N)²)). This improves L02-02 by factor log n. Does NOT count NOT gates, execution time, arbitrary negative tests or unrestricted circuits.
