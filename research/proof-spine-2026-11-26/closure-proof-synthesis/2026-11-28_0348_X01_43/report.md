## CLOCK-NO-TO-DECIDER (proved conditional composition; not universal coverage)
Fix a deterministic finite multitape bit machine R whose only rejection is a sound independently checked NO terminal. Suppose constants C,c are fixed effectively and R reaches accepted NO on EVERY valid NO input within B(N)=C(N+2)^c transitions, including the checker, failed search, all producers and consumers, all branches and maps. Simulate R for at most B transitions; reject iff accepted NO has occurred; otherwise accept. YES cannot trigger rejection; every NO triggers rejection before deadline. The clock counter has O(log B) bits; a conservative O(B log(B+2)+N^3) total bound includes a polynomial input format validator (reject invalid inputs); peak O(N+B+log B), cumulative at most time times peak. C,c must be proved for a particular implementation, not fitted to benchmarks. For a UCAC implementation with integer potential <=p(N), epochs <=q(N) aggregate bit steps each and initialization/finalization cost <=a(N), B=a+(p+1)q suffices IF every reachable NO state has a checked terminal or strict decrease; pad to C(N+2)^c. A finite set of sound modules can run sequentially with shared charged budget or deterministic dovetail; no free advice. If only partial coverage is proved timeout MUST be UNKNOWN. A proof-length bound or a fast checker alone is not a search clock. For SAT witness lifting after a total decider is established, fix ports incrementally via CNF encoding with prefix pins and a polynomial compiler back to strict E/B (no free native unary pins); at most O(N) calls on polynomial-size compiled inputs, then verify original witness. This is conditional on the compiler and all-input decider, not needed for the decision composition itself.

## FIXED-CAP-BLOCK-CREDIT (proved scoped)
For exact syndrome dictionaries S_i subset F2^r on disjoint root blocks, feasibility iff b in XOR sum of all S_i. Cap every dictionary at M=(N+2)^k (k fixed); require nonempty dictionaries unless terminal. Phi=(M+1)k_live+sum_i |S_i| initially <=(2M+1)k_initial. Exact merge of two blocks by XOR sumset admitted only when size <=M decreases Phi by M+1+|S_i|+|S_j|-|S_new| >=3. Deleting option z only after checked impossibility b+z outside span of the other dictionaries decreases Phi by one per deletion. This span test is an outer relaxation and sound, not complete; using affine translated spans can tighten it. Exact injective rebases of explicit options preserve Phi. Keep root block ownership and one child witness per retained syndrome; no split, rollback credit, or uncharged fresh context. Each epoch enumerates at most O(k_live^2 M^2) pair-word candidates and exact bounded-width span checks via GE, with polynomial bit costs; charge all failed attempts, compare explicit dictionaries and verify joins. Polynomial bound on accepted contractions and their acquisition per epoch follows, but a stalled epoch can have no admissible contraction. No universal coverage. A prospective all-input clock must bound neutral chart changes, newly created dictionaries, proof acquisition and all live guards. This is a special case not a proof of arbitrary UCAC.

## Spectral audit
On local support S of one/two authenticated necessary spin equations A_S y_S=0, every feasible spin word has norm squared |S|. Kernel projector P yields (c^T y)^2 <= |S| c^T P c; strict <4 forces equality/opposition for c=e_i +/-e_j; strict <1 for singleton yields contradiction. This local norm can be much stronger than global N-carrier norm. Homogenize guards with coordinate +1 and include it in norm only when present. For two rows a,b, Gram determinant d=(a.a)(b.b)-(a.b)^2; when d>0 residual norm numerator = ||c||^2*d - ((b.b)(a.c)^2-2(a.b)(a.c)(b.c)+(a.a)(b.c)^2). If d=0 use a nonzero single row. No floats. Verify positives by independent exact rational Gram-Schmidt and local words. Strict equality threshold gives no deduction. PSD certificate Q-D >=0 and tr D>0 verified via exact rational Schur complements: zero pivot with nonzero off-diagonal is invalid, all-zero pivot row removable.
