## Theorem (character-connected key graph)
Given explicit spaces W_i <= GF2^d and allowed functional tables R_i <= W_i*, let p_i be nonnegative normalized probability mass on each R_i. Full Fourier LP equates E[s(a)] in all blocks containing a for every nonzero a. Construct graph G on blocks such that for each nonzero a in union W_i the graph induced by I_a={i:a in W_i} is connected. On each chosen edge ij, equate probability mass of every common restriction key in (W_i intersect W_j)* attained by either endpoint. Omit one key equation per edge because both endpoint masses sum to1. Missing keys have mass0.
Necessity: full moment agreement implies key equality by exact character orthogonality, as proved in X01-26. Sufficiency: each shared character expectation is a linear function of the common key distribution; along any path in G[I_a] its expectations agree. Therefore all full moment equations hold. This is exact equivalence of two LP formulations, NOT global consistency of native solutions. Any genuine exact cover supplies a point mass in every block, hence infeasibility certifies native NO.
Construct G by enumerating all nonempty intersections, sorting in descending intersection size then original block IDs, maintaining disjoint-set structure for each a. Choose edge iff it joins distinct components for at least one shared signature; update every such signature. Complete graph on I_a available, so every I_a connected at end. Number chosen edges <= sum_a(|I_a|-1), because each chosen edge reduces the total component deficit by >=1. Independent check: BFS or fixed-point reachability on each induced subgraph. A connected graph on blocks alone is insufficient: W1=span(a,b), W2=span(b,c), W3=span(a,c), independent a,b,c; path 1-2-3 allows point masses zero on first two and a=1,c=0 on third. Both path keys agree, shared a disagrees. This is an abstract relaxation counterexample, not a native hard family.
Hybrid: perform exact X01-26 support peeling on all overlaps before creating sparse key LP, then omitted key equations are valid on remaining supports by normalization. Deleted states forced to zero in full LP. Both operations preserve full LP feasible set up to adding zero columns. Full LP proof can be recovered without further solve: express selected key row by Fourier indicator expansion in original canonical-reference moment rows; constant terms cancel between normalized blocks (or add the normalization-row difference), and subtract the same reference expectation. Lift reduced dual by X01-26 reverse deletion repairs. This lift is proved symbolically, not executed this run; the unpeeled selective key certificate was directly checked, so no lift needed for native NO.
