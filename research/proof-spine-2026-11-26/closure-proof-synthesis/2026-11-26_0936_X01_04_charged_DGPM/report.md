## 2. Fixed-machine simultaneous charged theorem
Machine A one fixed correct deterministic total DGPM decider on sole writable tape, finite alphabet and Q>=2 finite states (include halt states), one head initially left of all selected cuts, unit transition reads/writes source cell and moves at most one, no separate input tape, random access, free clocks or external caches. Complete configurations include all contents, head position and control. For any fixed self-contained injective binary coding of configurations (decoder fixed for A, no input or history supplied), define S_code=max code length, CM_code=sum over actual configurations including initial and final, T actual steps. Not auxiliary workspace alone. Can normalize halting to stationary final step if needed.
For fixed cut b in middle, CS_b(pi) is sequence of post-crossing control states on diagonal D_pi,pi. Distinct diagonals cannot have equal full crossing sequence: splice left excursions from one with right excursions from other. Entry control and alternating side match, hence each local execution follows original; equal total crossing count yields identical final side and rejecting label on hybrid, which is SAT. Contradiction. Classic Hartmanis crossing method; here exact hybrid certified by DGPM adapter. For any j<=number of crossings, pair (first j crossing states, full current configuration code after jth crossing) is injective across diagonals reaching j. If two collide, splice only through j. Its left and right contents are respective originals at that crossing; both full configs equal, so hybrid reaches common config. Deterministic continuation rejects, contradiction. Crossing times need not coincide; no external time supplied.
For r=floor(H/(4 log2 Q)), s=floor(H/4), at any fixed cut and j<=r, number of diagonals with fewer than j crossings <=sum_(i<j)Q^i <=Q^j (by full sequence injection). Number reaching j with code length<s <=Q^j (2^s-1) (by prefix/config injection). Divide by k!=2^H. Probability of either failure <=2^{-3H/4}+2^{-H/2}. Union bound over all D*r events (polynomial in N) yields failure at most D*r(2^{-3H/4}+2^{-H/2})=2^{-Omega(N)}. Therefore for each fixed correct A, on 1-2^{-Omega(N)} fraction of these UNSAT diagonals, EVERY selected cut has at least r crossings with code length>=s at each of first r events. A transition crosses at most one cut, so all counted events are at distinct times of SAME execution. T>=Dr, S_code>=s, CM_code>=Drs. Since D,H=Theta(N), obtain simultaneously T=Omega_A(N^2), S_code=Omega(N), CM_code=Omega_A(N^3). Constants fixed per A, not one universal input across machines. This includes arbitrary local computation, rewriting, matching and Gaussian shortcuts physically executed on sole tape; no restriction to resolution or solver implementation. Code length lower bound does not imply auxiliary S lower; ordinary complete tape-span encoding can upper-bound code length by physical span up to log coordinate terms, but arbitrary work-space definitions need separate proof.

## 3. What caps are excluded and exact ceiling
On the same hard UNSAT diagonal execution CM<= (T+1)S_code. Hence simultaneous upper caps T=O(N^a), S_code=O(N^b), CM_code=O(N^c) need a>=2,b>=1,c>=3,a+b>=3. This directly concerns uniform UNSAT-only caps since family is NO; no hypothesis about time on SAT. The same-execution result cannot be derived by multiplying separately chosen worst-case inputs. If only auxiliary memory is charged, or separate input tapes/random access, this inference does not apply.
A complementary deterministic input-query lower bound in the bit-probe model: fix N and common middle; simulated decider queries left or right variable bits (adaptive address determined by previous answers, no free precomputed input). Two diagonal computations with identical complete bit-answer transcript would give identical queried values on the mixed hybrid by induction, same reject, contradiction. Thus k! distinct terminating binary transcripts; for almost all diagonals at least H/2=Omega(N) probes. This does not give superlinear time in a random-access model.
Static transport ceiling (already in historical Charged_UNSAT_Transport): each left and right variable string of separated-input family must distinguish all P labels, so lengths >=H=log2 P. If D counts only boundaries inside common middle, D<=N-2H+1. Maximizing (N-2H)H and (N-2H)H^2 gives N^2/8 and N^3/27, respectively (plus lower-order terms for boundary convention). Thus no static separated-input distinguishability family can force superpolynomial T or CM by this counting argument alone. This is ceiling on this proof method, not universal algorithm upper bound. Growing the number of projections, overlapping cuts, or repeated conceptual queries does not evade unless new compulsory nonoverlapping physical events are proved.
Adversarial control: on promised compiled family the two permutation lists can be copied/compared in near-linear bit work on multitape/random-access model (read actual indexed lists, compare corresponding B IDs; verify promised template/permutation validity if needed). On fixed template family one can parse and check in polynomial time and fallback to exhaustive correct solver outside; no claim near-linear template recognition for general DGPM. On sole tape pairwise scan/mark comparison takes polynomial time, not exponential. Hence no generic all-decider lower-bound transfer from this construction; no new joint lower bound combining it with X01-03 ordinary-resolution family, which uses different inputs and is bypassable by parity. Need an execution-sensitive invariant compulsory on a specified dynamic residual sequence, not just a large number of semantic states.
Known FLMV time-space theorem concerns deterministic random-access TM, read-only random-access input, bounded work space; for c<golden ratio there exists d>0 excluding simultaneous SAT T=O(N^c), S=O(N^d). A generic polynomial NP reduction is insufficient to transfer these exponents. DGPM occurrence-link discovery and virtual input access require a separately costed near-linear small-space adapter, not established here. No all-exponent result.
