## A: exact native group choice and rank-conditioned tree join
Partition remaining original tuples by owner v in one chosen color. Pick exactly one labeled tuple per group. Give tuple i a binary vector z_i in F2^(2q), one bit for each owner in each remaining color. Target is all ones. XOR target iff every owner in each remaining color occurs an odd number of times; exactly q selections, q owners per color, so all counts are exactly1. Thus original exact covers correspond bijectively to target sums. Guards remain deleted; if closure selected tuples, remove covered owners and conflicting tuples before using balanced residual q'. No arbitrary cross-source transfer.

Choose a baseline z_iv per group, define D_v={z_i+z_iv : i in group v}, retaining multiplicities and original labels; b=ones+sum baselines. For S a subset of groups define V_S=span union D_v for v in S. Use any acquired binary tree of disjoint group partitions. At node S store A_S(s), the exact count of choices in S summing to s, for keys with b+s in V_(complement S). Leaves enumerate actual original labeled tuples. Join children via XOR of their attained keys, multiply their counts, sum duplicate keys, apply outside-span test. Correctness: any globally valid selection survives every test. Stronger invariant: for a retained parent key s, every realization of s by child choices passes both child tests, because the opposite sibling sum belongs to that child's complementary span, and b+s belongs to the span outside the parent. Therefore no contribution to a retained parent key is lost; exact induction. Root count at b equals number of native exact covers. Empty root or zero count certifies NO. Nonempty affine span is not attainment. Control D={0,e1,e2}, b=e1+e2: target in span yet unattainable.

All retained keys lie in V_S intersect (b+V_complement). When nonempty it is a coset of V_S intersect V_complement, hence at most 2^w(S) keys, where w(S)=rank(V_S)+rank(V_complement)-rank(V_all). This is a sufficient bound, not lower bound. Acquisition: deterministic greedy merges minimizing w of merged subset then subset size then index tie; O(q^3) candidate rank queries, no optimal tree assumed. Counts use O(m) bits.
