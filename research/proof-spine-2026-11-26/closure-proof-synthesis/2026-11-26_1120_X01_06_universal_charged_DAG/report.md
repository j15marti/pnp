## 2. UNIVERSAL-CHARGE: a representation-neutral positive witness optimum
Fix one polynomially efficient universal deterministic sole writable tape machine U (finite alphabet/control, one head) with input p#F (self-delimiting program frame, F proper CNF), fixed witness verifier, accepting only after a concrete n-bit satisfying assignment has been produced and verified against actual F. May use any internal algorithm (arbitrary preprocessing, algebra, matching, auxiliary DAGs, arithmetic at paid bit cost). U is fixed BEFORE input selection, not a different interpreter per input. Standard universal simulation with polynomial overhead suffices; no specific efficient exact universal instruction-level implementation claimed in audit. Malformed formulas/programs rejected or fail to produce verified output. U may have fixed trusted fast-path codes as below, still universal.
For successful p, t(p,F)=actual number of U transitions to verified acceptance, including all parsing/verification. W(F)=min_p 2^|p|*(1+t(p,F)); W=+infty on UNSAT. Integer minimum exists on SAT, since a fixed exhaustive assignment search program succeeds. I=log2 W, equivalently min |p|+log2(1+t). This is a Levin-style time-bounded information measure, not a novel universal search paradigm. Any fixed correct polytime algorithm is one finite program (constant length independent of F); its witness search via n+1 calls to SAT decider (restrictions/padding charged polynomial) is simulated polynomially. No trust in other programs' claims needed because positive witnesses independently verify. A per-instance min over ordinary algorithms ignoring length is vacuous: a different algorithm hardcodes this input and answer, checks equality and falls back to exhaustive decision otherwise.

Exact finite threshold test for integer B>=1: enumerate every binary program of length l<=floor(log2 B), simulate U for at most floor(B/2^l)-1 transitions (allow zero-step acceptance if model permits). Accept iff verified output within budget. All unsuccessful/invalid attempts charged. Thus iff W(F)<=B. For fixed B, <=(floor(log2 B)+1)B simulated transitions; <=2B programs, lengths O(log B). On a fixed multitape scheduler executing fixed U with counters, copies input, initializes/clears tape, validates simulated accepting state and copies witness; per trial O(N+log B+time*poly(log B)) overhead. A conservative time O(poly(N+log B)*B), physical peak cells O(N+B+log B) (one trial live at a time), and cumulative physical memory <=(T+1)S on SAME run. If desired a standard sole-tape simulation incurs fixed polynomial overhead and remains polynomial in N+B; no assertion of exact lower exponent preserved across models. Each trial includes verifier time, not just candidate claimed answer. Increasing B by powers of 2 yields one fixed search algorithm on all SAT, T<=poly(N+W(F)); exact minimum can be found for SAT by doubling then binary search, with cost polynomial in N+W. Nontermination on NO is not a false UNSAT proof.

THEOREM P=NP iff exists K,c such that every valid SAT F of length N has W(F)<=K N^c. Forward: self-reduction and simulation. Reverse: threshold test at ceil(K N^c) accepts all SAT and no UNSAT; reject malformed with paid parser and reject on cutoff. One fixed uniform cap for all YES inputs, one fixed exponent and machine. Equivalently P!=NP iff for every fixed K,c,N0 some SAT input length>=N0 violates W<=K N^c (finitely many exceptions can be absorbed in K). Therefore a superpolynomial lower bound on W on SAT inputs would exclude ALL polynomial-time deciders; no need a universal proof system for NO or a syntactic coverage theorem for solver modules. Does not supply this lower bound. Can interleave exhaustive assignment enumeration to get an all-input correct total decider competitive on YES, not claimed competitive on NO. This is a different object from a minimum unrestricted AND/OR circuit for the assignment predicate, which is trivially small by source CNF.
Budget adversarial test: for any fixed positive integer a, predicate F in SAT and W(F)>N^a is NP: guess and check witness and run the deterministic finite threshold enumeration. This verifies an individual fixed-cap violation in polynomial time (degree depends on a); locating infinitely many such inputs for ALL a remains open. With variable exponent or binary budget do not silently call it poly(N). No counting oracle. For NO, W=infty, which says nothing about decision hardness. Running arbitrary programs and trusting their NO outputs is unsound; for any fixed sound polynomial-verifiable UNSAT proof system one can do analogous proof search, but the choice/coverage of that system is not free. Cook-Reckhow: existence of polynomially bounded propositional proof system iff NP=coNP, not automatability or P=NP. Krajicek 2021 Lemma2.2 gives optimal search for fixed proof system and Theorem2.4 connects all-proof-system optimal search to p-optimal systems under stated conditions; do not assume existence. Our YES lane avoids that dependency.

## 3. LAST-CLAUSE-ACTIVATION and exact growth equivalence
For arbitrary proper H with n vars,m clauses C_i=(l1 OR l2 OR l3), introduce fresh p, y_i, u,v. Replace each C_i by (NOT p OR l1 OR y_i) AND (NOT y_i OR l2 OR l3). Append ordered clauses (p OR u OR v),(p OR u OR NOT v),(p OR NOT u OR v),(p OR NOT u OR NOT v). p assigned ID1, original x shifted+1, y after x, u,v final two. n'=n+m+3, m'=2m+4, N'=poly(N_H), explicit size O((n+m)log(n+m+2)) with header; decoder uniform. Every proper prefix is SAT: p=0, all x,y=0,u=v=1 satisfies all clauses except final, regardless H. Lexicographically first penultimate witness is exactly that string (p first, others in ID order); earlier prefixes lex first can also be computed explicitly: u,v 00 before guard,01 after first guard,10 after second,11 after third. No supplied target satisfying assignment and no claim every prefinal fact is forced. Last four guards resolve to p=1 (pair first two gives p OR u, last two p OR NOT u, resolve). Then eliminating each private y by exact existential join gives original clause; forward for true H choose y=0 if l1 true, y=1 otherwise; choose u,v freely. Thus final F^+ SAT iff H SAT, actual projected witness and actual lift. All preceding stages easy including when H UNSAT. Compiler output not claimed clause-minimal UNSAT. Fixed p0 finds and verifies prefinal witness in polynomial time. H can be reconstructed from template; arbitrary forced closure not assumed. Last activation/resolve and local y elimination are unconditional certified reductions in final guard context, repeat at stagnation.
For H SAT, W(F^-)<=poly(N') and W(F^+)>=1. P=NP implies uniform polynomial bound on ratio W(F^+)/W(F^-). Conversely any bound <=K(N')^c for all SAT H implies W(F^+) poly, run universal threshold and project witness, cutoff rejects all H NO. Therefore P=NP iff uniform polynomial ratio bound across SAT H. Equivalently P!=NP iff for every K,c,N0 there exists SAT H of size>=N0 with ratio >K(N')^c. This is an exact final-insertion growth formulation, not a proof that the growth is superpoly. A universal polynomial incremental update even when given the lex least prior witness and cheap prior execution trace would decide all H by same compiler. A previously acquired small *explicit exact ROBDD* is different: conjunction with one fixed-width clause can be handled by fixed-order product and reduction, O(nodes*constant) new states; satisfiability/witness by traversal. The guarded preterminal predicate still includes H on p=1, so no polynomial all-model representation bound follows from easy predecessor witness.

## 4. PROGRAM-UNION-TRANSPORT on the SAME final-clause family
Construct H_{a,b}=L_a M R_b for a,b in {0,1}^k. Variables x_1..x_k, separate left 2k auxiliaries, separate right 2k auxiliaries, middle 3k dummy vars. For each i left 4 proper clauses (signed x_i OR all sign combinations of fresh two auxiliaries) force x_i=a_i. Right analog forces x_i=b_i. M has k independent positive 3-ORs on dummy triples. n=8k,m=9k, all vars occur, proper distinct clauses. SAT iff a=b; witnesses choose x=a, auxiliaries zero, one positive dummy each. Header fixed, left strings encode a injectively, right b injectively, middle common. Apply activation compiler to ordered rows: replace each clause by consecutive pair with private y per slot, final guard clauses appended to right suffix. Then F^+_{a,b}=L'_a M' R'_b with common header and middle D=Theta(N') bits, N'=Theta(k log k) (n'=17k+3,m'=18k+4). Every hybrid valid, SAT exactly diagonals. All F^- have simple witness, including both types of hybrids. Proof uses SAT diagonals now, not X01-04's NO permutation diagonals.

Let Q>=2 be fixed state alphabet of U. Let H_bits=k, #diagonals=2^k. For each program p and relative cut b in common middle (absolute cut shifts with p frame, aligned for same p), consider only successful verified accepting diagonal executions. Same p and full crossing sequence at this cut cannot occur on two different a: splice left/right excursions with matching entry states, same terminal side, yields accepting offdiagonal UNSAT hybrid, contradiction. U's verifier is inside the actual trace. Similarly for fixed p and crossing index j, (crossing prefix through j, complete current configuration code) injective on successful diagonals reaching j; if collide splice partial histories then use common deterministic continuation. Code any fixed self-contained injective binary code for full config (not auxiliary workspace, no free original input or clock). Thus number of diagonal labels on which some p of length<=floor(k/4) has a successful run with <r crossings at a fixed cut <=2^(k/4+1) sum_{i<r} Q^i <=2^(k/4+1)Q^r. Number on which any such p reaches j with code shorter than s <=2^(k/4+1) Q^j 2^s. Take r=floor(k/(8 log2 Q)), s=floor(k/8). Both ratios to 2^k at most 2^(1-k/2) for j<=r (first even smaller). Union bound over D*r events (poly(k log k)) gives exceptional fraction 2^-Omega(k). This union includes every short program, not a chosen algorithm or independent per-input minima. For every nonexceptional a, EVERY successful p length<=k/4 has >=r crossings at EVERY cut, and full config code length>=s at each first-r crossing event. All selected events distinct physical transition times in that one run. Hence T>=Dr=Omega(N'²/log N'), S_code>=s=Omega(N'/log N'), CM_code>=Drs=Omega(N'³/log² N'). For longer programs the description cost alone exceeds 2^(k/4), larger than Dr eventually. Therefore W(F^+_{a,a})>=Omega(N'²/log N') even though minimizer may change with a. There is a fixed polynomial-time source-specific solver on the whole promised diagonal family (decode left pin rows and lift original assignment, verify); hence W<=poly(N'), so all minimizing programs are short for large k and the three simultaneous raw resource lower bounds apply on THEIR executions too. All constants depend on fixed U/coding, no universal hard input for every interpreter. U sound on well-formed inputs is indispensable. This is a fixed-polynomial lower bound in a specific physical model, not superpoly; arbitrary multitape algorithms may bypass transport.

### Actual polynomial jump on this family
Choose U with one fixed special program p0 producing 0^(n'-2)11 and verifying it, in addition to usual universal interpreter codes. Can perform this sound verification and full parsing on one writable tape with fixed finite alphabet/constant tracks using local moving O(log(N'+2))-bit scratch block (binary n,m counters, w, current clause's 3 IDs/signs, comparisons to n'-1,n'). A finite number of tracks is one physical tape/head; no free access. Scan unary n and gamma m counting and moving scratch, then each clause record; shift scratch one cell per cursor advance by O(log N') local moves; counters, range/distinctness and sign tests cost conservatively O(log² N') per source bit using local scans. Check exact declared m records/terminator, each clause satisfied under known witness. Return to header, write n' explicit witness bits on output track and halt. Scratch growth also local and bounded; input preserved on source track. This yields t(p0,F^-)<=O(N' log² N'), with constant program length, and no need to check arbitrary candidate witness by random indexed lookup. It is a specific admissible interpreter design; exponents are not invariant under polynomial simulations. If use only generic verifier, still have polynomial predecessor upper and conditional ratio equivalence. The concrete p0 moving-window tape implementation was NOT executed; its upper bound is a symbolic algorithm. Combined with same-input lower on F^+, W(F^+)/W(F^-)>=Omega(N'/log³ N') on 1-2^-Omega(k) SAT diagonals. This is actual provable polynomial growth in the optimum, not just in a prescribed assignment-DAG representation. On NO final W=infty, not hardness. Prefix and final measured on separate fresh inputs (as in prior erasure convention), not sum of their resource bounds as if one execution. If an incremental controller retains prior state, its acquisition costs must be included, and this particular two-input W lower does not by itself constrain an uncharged preloaded state.

### Static ceiling and adversarial check
Every separated SAT-diagonal/all-offdiag-NO family with common n variables has disjoint witness sets on different diagonals: a common witness would satisfy hybrid. Thus #labels<=2^n, k-like entropy<=n. With all n variables occurring, fixed-width explicit proper 3CNF N>=n log(n+1), so H_bits=O(N/log N). This yields ceilings O(N²/log N), O(N³/log² N) on the static DH and DH² transport demands, not upper bounds on arbitrary computation. Current construction attains orders for such a static method. Direct equality/pin parsing and lift is polynomial, no superpoly implication; cannot repeatedly charge same label information.
