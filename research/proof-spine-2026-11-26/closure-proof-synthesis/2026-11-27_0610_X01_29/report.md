## Theorem: indexed support closure and reduced dictionary soundness
For any explicitly acquired family of finite local state tables R_i on affine spaces W_i, let K_ij(s)=s restricted to W_i intersect W_j. Initialize live states and directed buckets (i,j,k) with all states s in R_i having K_ij(s)=k. If opposite bucket (j,i,k) is empty, queue deletion of the first bucket. Maintain reverse memberships from each state to all its buckets. Delete state once; remove its memberships; if a bucket becomes empty, queue any nonempty opposite bucket. Induction: a genuine solution selects one consistent local state per region; if it selected the deleted state, its partner would be live, contradiction. Stronger: any feasible full Fourier-overlap LP gives equal masses to each shared key, hence each deleted state has probability zero by nonnegativity and induction. Queue order is immaterial: any subset closed under support survives all deletions, and the terminal sets are closed, hence the greatest closed subfamily. Empty table proves NO; nonempty does not prove YES.

After this exact face reduction of the full LP, retain only normalization and moment equalities for an arbitrary subset D of the shared nonzero signatures. Infeasibility of this weakened reduced LP certifies native NO: a genuine solution (indeed any full-LP distribution) survives every deletion and obeys these retained equalities. A finite ordered deletion trace plus a rational Farkas vector on the final LP is a checkable compound certificate. This is not equivalence between the reduced old-dictionary LP and full LP; weakening may lose strength. Hidden joint keys can contribute to support deductions without being retained as real-valued moment coordinates. In particular it bypasses X01-28's fixed-old-dictionary *individual projected-cut* obstruction by a genuine joint support operation, not by additional independent cuts.

Tariff: m tables, L total states, H=sum over overlapping unordered pairs (|R_i|+|R_j|), max rank r. Acquire intersection bases by Gaussian elimination (or explicitly acquired signature enumeration), evaluate H keys at cost poly(r,d) each. Sort/index H memberships and reverse indices deterministically. Each membership removed at most once over a fixed deletion-only dictionary; each nonempty bucket's transition to empty occurs once; total queue work O(H+L) indexed operations after indexing, with logarithmic dictionary overhead. Space O(H+L) records plus keys, bases and source. For a fixed guard, additional sound deletions reuse indices; new tables/guards require a new charge. No free arbitrary extension oracle. With polynomially acquired L,m and bases, H<= (m-1)L, bit work and memory polynomial; standard rational LP gives polynomial bit complexity in explicit matrix size, not the empirical numerical implementation. Charge matrix acquisition, scan, all failed LPs, trace verification, certificate bits and reconstruction; on sequential tape peak <=O(N+T), cumulative <=O(T(N+T)) for the same execution. No universal bound on successful tables or solver coverage.

Alternative signature admission theorem: for finite shared dictionary Q, retain D, solve the relaxation. For an exactly verified fractional solution, compare every omitted signature across all containing regions. Add violated equalities (all incidences for that signature); strictly excludes incumbent and preserves native solutions. At most |Q-D| productive rounds, plus final LP; if no violated equality, incumbent is feasible for the full LP. Does not imply native feasibility or a polynomial bound if Q not paid. This is finite row generation, not a new general LP theorem.
