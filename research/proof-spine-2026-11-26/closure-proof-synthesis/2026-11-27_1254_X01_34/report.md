## Named obligation: REVERSE-UNIT-REASON-TO-SHARED-CREDIT
PROVED WITH SCOPE (standard conflict-analysis reconstruction adapted to shared native proof IDs). Let F be the currently verified clause database under a single exact guard (or discharged complement gauge). For a nontautological proposed clause C, assume all literals of C false. If deterministic unit propagation derives a contradiction, record each propagated literal l with its reason clause (l OR R) whose remaining literals were already false. Start at the conflicting clause. Traverse the trail backwards; whenever current clause contains -l, resolve against its recorded reason on l. The current clause is false under the trail by induction; after eliminating l every remaining literal was false before that propagation, so the resolvent is nontautological and no later assignment is reintroduced. After the reverse traversal all remaining literals are false under initial assumptions only, and hence the resulting clause C' is a subset of C. This uses at most one binary resolution per assigned reason (at most m variables). No weakening inference needed to store the stronger C'. If input targets are RUP in a database including earlier proposed clauses, substituting derived subclauses preserves the existence of a UP refutation: induct on a unit derivation. A reason subclause either still forces the same literal when its other literals are false, or is already empty under those assignments. If an additional propagation has set the opposite literal, conflict occurs earlier. A fair full closure therefore still refutes. Learned clauses can be checked directly in a different consumer's projection without trusting producer proof steps. Only verified subclauses enter the consumer database. Failed replay gives UNKNOWN for this conversion, not a counterexample to the producer theorem. For arbitrary guards keep guard identity or discharge via a checked implication; never merge raw auxiliary indices. Native min-port+1 representatives and gauge match in actual replays.

For m variables, t explicitly supplied target clauses, maximum explicit active database literal length L including targets/subclauses, a naive full-scan implementation uses O(t(m+1)(L+1)) literal visits, O(tm) new binary resolution steps and O(tm^2) additional literal storage before deduplication (plus index bit costs). Projection proof size P and all construction costs additional. Verify every parent edge and native leaf, charge sender's acquisition, all physical messages, all failed jobs and repeated physical verification. One fixed monotone agenda can reserve credits for at most t trials and tm resolution steps, plus scan, proof representation and verification overhead; dynamic retries require a separately paid finite schedule. If all these acquired artifacts and work are polynomial in original N this is a polynomial transport theorem, NOT an acquisition theorem. For fixed target width w, enumeration of all possible targets is O(m^w); fixed-point rescans after each newly admitted distinct clause can be paid by the square of that count, but the derived intermediate resolution widths may exceed w and bounded target width does not guarantee universal coverage. No free SAT or equivalence oracle.
