## 1. Disjoint-Guard Perfect Matching (DGPM)
Input: explicitly indexed simple bipartite G, components each K2,2 or the 6-vertex graph with adjacency B=[[1,1,0],[1,0,1],[1,1,1]], and unordered pair list of existing distinct edges, no edge in two pairs. Decide perfect matching with both or neither edge in every pair. Validate input and reject malformed inputs for total language. Every base component has a PM, max degree3 and planar (B is theta graph, one direct and two length3 paths between degree3 vertices). Added guard graph on edge IDs is a matching, but the joint factor incidence need not be planar or acyclic. No claim of new literature priority or hardness under planar full guard embedding.
Correction to X01-02: the previously printed A=[[1,1,1],[1,0,1],[0,1,1]] has permutations (0,2,1),(1,0,2),(2,0,1) (not (1,2,0)). Its column0 is not a three-port one-hot indicator. Transpose B has permutations (0,2,1),(1,0,2),(1,2,0), all three first-column edges available and exactly one chosen in every PM. The new construction explicitly fixes the source description.

## 2. Linear-object NP-hardness reduction
From 3SAT with exactly three distinct variables per clause (standard padding/reduction; unused variables removed). For every occurrence create K2,2, two perfect matchings: diagonal x=1, off-diagonal x=0. For the d copies of each variable, link consecutive copies via equality guards on alternating polarities (choose diagonal 00 on even links and off-diagonal 01 on odd links). Each interior copy uses one edge of each polarity; two edges of each polarity exist, hence every occurrence has an unused edge carrying 1-literal. Each clause has four B blocks: one selector with first-column indicators s1,s2,s3, and three implication blocks with a,b,c. For j link a=s_j and b=1-literal_j by two unsigned equality guards, using different first-column ports in each block and the unused variable edge. Thus no edge in two guards, all pairs cross distinct components. Exact constraints s1+s2+s3=1, a+b+c=1 imply s_j<=literal_j. Forward choose a true selector and c_j=literal_j-s_j; lift each unique block PM. Reverse recover common variable values from chain and use selected true literal. All witness checks polynomial. For m clauses and v occurring variables, 3m K2,2 blocks, 4m B blocks, 36m vertices,40m edges,9m-v guards (6m clause links+3m-v copy links). With fixed-width explicit IDs bit length N_s=Theta(m log(m+2)). In NP, therefore NP-complete. Exact reduction to 2/4-set exact cover: unpaired edge is a 2-set, pair of vertex-disjoint edges is a 4-set with 2 left and2 right elements; if a pair shares endpoint neither can be selected, discard both. Choose whole sets covering all vertices exactly once iff PM obeys all guards. Incidence degree <=3 (original degree); use indexed sets. All constructed pairs cross components so no invalid 4-sets.

## 3. Physical grid adapter
Place blocks on diagonal availability matrix of side n=18m, other entries zero; cell table in cyclic N,E,S,W order {0000,0101,1010,1111} plus 0110 iff available. North/west boundary0, south/east1. Integer E-W=S-N equals selected cell indicator, row/column sums telescope to1. Every PM gives unique prefix lift, and conversely. B first-column indicators are horizontal prefix edges at block first column. In K2,2, graph edge00 -> horizontal prefix row0,col0; edge10 -> horizontal row1,col0; edge01 -> vertical prefix row0,col1; edge11 -> vertical row0,col0 (diagonal equality with edge00). Four different physical wires, exact correspondence. All guards are disjoint unsigned equality on physical wires. Explicit grid N_g=Theta(n²)=Theta(m²) including guard list O(m log m). Planarity only of grid local-factor network before adding nonlocal guards; no claim of fully planar guarded interaction. Local support acquisition by two/three-state enumeration and binary guard propagation is exact for each single relation, not full joint feasibility.

## 4. Ordinary-resolution transfer theorem (unconditional)
Define sparse CNF D(F) using one edge bit per available edge, at-least-one and pairwise at-most-one at every matching vertex, two binary clauses for each equality guard. Initial width<=3, 40m variables. For every assignment of original F (even false), define local functions for matching-edge indicators. Each variable copy PM selected by its original bit. For each clause, choose first true literal selector, or first selector if all false; each implication block choose the a state if its selector selected, else b state if literal false, else c. All blocks always choose actual PMs. For true clause all its guards hold. Each edge indicator is a Boolean function of at most3 source vars, and each substituted input clause is tautological or implied by ONE original clause over those <=3 vars.
For any resolution proof of D(F) width w (allow weakening, no new extension variables), replace each proof clause C by truth-table CNF of its substitution over at most3w source variables, using a clause excluding each falsifying assignment. Each image of input axiom follows from a source clause or is tautological. Each original resolution inference or weakening is logically valid after substitution, so the conjunction of image premises entails every image conclusion clause. The union of source variables of two premises has <=6w variables; resolution plus weakening derives any such entailed clause with width at most that many: for each full assignment falsifying desired conclusion choose falsified premise clause, weaken to full assignment-blocking clause, then resolve away free coordinates of conclusion. This is an existence/width argument, not polynomial proof conversion (truth-table size may be exponential). Result width(F) <=6w+3. Standard weakening elimination does not increase needed width. 
Same proof works for the *quotiented* CNF on pair variables: choose the variable-side representative for a guard touching a variable copy, otherwise choose clause-local representative; chain values consistent always, other equality guards consistent if that clause true. Every variable-copy vertex equation then tautological; every clause-block vertex equation implied by that clause. Each pair function still depends on <=3 source vars. All CNF vertex clauses width<=3.
Grid CNF uses forbidden local 4-bit words and guard equalities and boundary units. Fix every physical prefix wire outside the diagonal block interiors to its deterministic constant (0 before its matching block,1 after; all off-block cells satisfied because no selection and prefix unchanged). Only O(m) internal wires remain, each function of <=3 source variables by local PM prefix. Axiom substitution has same property. Restricting a resolution refutation cannot increase size (discard true clauses, simplify, use subsumption/weakening as needed). Hence sparse proof lower bound transfers even to padded grid without charging irrelevant padding as active proof variables.
Take connected 3-regular expander H with t vertices and odd charges; F is its standard parity 3CNF with 4t clauses,3t/2 vars. Ben-Sasson–Wigderson JACM 48(2), 2001, Cor3.6: for unsat CNF with q variables, initial width w0, size exp(Omega((minimum refutation width-w0)^2/q)); Thm4.4: connected graph odd-weight Tseitin minimum width >= balanced edge expansion e(H); Cor4.5 gives exponential size on cubic expanders. Primary PDF https://people.inf.ethz.ch/emo/SatSem05/Papers/BensassonWidgerson01.pdf, sections3,4.1,6.1, pp154–156, screenshots inspected. DOI https://doi.org/10.1145/375827.375835. Infinite cubic expander existence is standard in cited corollary; construction uniform given H, no need to discover expanding graphs in solver. With w(F)=Omega(t), width(D(F))=Omega(t), q=O(t), size >=2^Omega(t). Same for exact-cover quotient and fixed-padding grid. Therefore sparse explicit N_s=Theta(t log t) -> 2^Omega(N_s/log N_s) resolution size; grid N_g=Theta(t²) -> 2^Omega(sqrt(N_g)) resolution size. This is a lower bound on a named proof system, not all deterministic algorithms, not a lower bound on algorithms permitted unrestricted preprocessing/extension/XOR. It is valid even if guards are a matching and local components constant.
Adversarial control: decoding the compiler chart into 3CNF and recognizing the four clauses for each vertex parity gives polynomial Gaussian elimination on these Tseitin families (indeed odd total charge immediately contradicts); even charge on connected H admits a spanning-tree witness. Hence generic all-decider-to-ordinary-resolution transfer on these inputs is false. Historical TMR1 DISTORTION036 search already contained this bypass for original Tseitin. We preserve it. Arbitrary computational lower bound still OPEN.

## 5. Decision bounds and closure
Unconditionally enumerate all g common guard bits; each branch fixes or deletes paired edges, then solve ordinary PM on remaining vertices, so O(2^g poly(N)) time and polynomial peak space (serial). The joint CNF has max width3 and O(m) variables. Local matching support of each component is complete, and all initial unary domains support both values; domain propagation across guards has no deduction on the unpinned construction. Even full joint affine row filtering over GF2 or GF3 of these exact component supports cannot delete any local row: B's affine hull is its two-dimensional first-column plane sum=1; K2,2's affine hull one-dimensional. Choose source variable values freely in field, selector arbitrary sum1, fill all c_j=literal_j-s_j. For prescribed actual selector state choose it and free source bits; prescribed implication state fixes its selector bit and source variable, leaving remaining selector bits freely complete sum1; prescribed variable state fixes source bit only. Thus each actual local row extends to an affine global word, regardless of SAT. Repeating these lanes stagnates. Does NOT cover arbitrary semantic propagation, parity recognition, failed-literal or more powerful inference; Tseitin bypass above.
