## 1. Exact theorem (projection before translation)

This is a promise about the chart verified from source, not about all residuals. In native exact-cover charts, each shared owner can be encoded by XOR=1 if it touches exactly two blocks and each block enforces occupancy in {0,1}; if three or more blocks, XOR alone is NOT exact (three ones counterexample). Write S_i=L_i(R_i), exact projected syndrome support. Retain at least one actual original word per distinct projected signature. Set H_i={d in GF(2)^m: S_i+d=S_i}. This is a linear space (identity and composition, inverse=self). Fix any a_i in S_i. Every d is a_i+s for some s in S_i, so test all these candidates against full S_i membership; at most |S_i|^2 membership comparisons with indexed sets, or cubic naive scans, each m-bit. No SAT or full global solution search. Sum H=sum_i H_i. Compute quotient map pi to GF(2)^(m-dim H) by Gaussian elimination; preserve basis generator origin i. The image of any certified original-word translation in X01-09 is in H_i, but inclusion may be strict.

Solve for d_i in H_i with sum_i d_i=delta, using retained generators; aggregate all chosen generators of each i by XOR. Since d_i is a true period, s_i+d_i belongs to S_i. Retrieve stored actual word x'_i with that syndrome. Local words still satisfy their complete local conditions and disjoint IDs; every remaining guard and shared-owner condition holds by sum=b and exact chart assumption. Verify original native input. This is not a common XOR shift of hidden words; it reselects an actual hidden witness. It does NOT preserve each hidden fiber or number of solutions, and cannot change original fixed guard bits omitted from local constraints.
