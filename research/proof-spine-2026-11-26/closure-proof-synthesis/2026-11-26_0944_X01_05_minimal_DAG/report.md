## 2. Exact minimum ordered diagram
For fixed variable order pi, ROBDD has Boolean terminals, queries original bits, respects pi on every path, and merges equivalent residuals and deletes identical-child nodes. No complemented edges or auxiliary predicates are required; count NONTERMINAL nodes only. Bryant 1986 Theorem1 guarantees unique minimum for fixed order (not across unrestricted DAGs). For consistent Hx=b over GF2, let S be assigned prefix columns. A nonzero residual function is exactly H_complement x=b-z, with z in im(H_S) intersect (b+im(H_complement)). This affine coset has exactly 2^lambda(S) elements, lambda=r(S)+r(complement)-r(all), by intersection dimension. Every z actually occurs because binary free coefficients are the whole GF2 field; no hull/attainability gap. Distinct z give distinct nonempty disjoint residual solution sets. If the next column h_j is nonzero, every such residual depends on x_j (flip x_j in any one accepted completion), and each gives one distinct node; if zero, every residual ignores it, so all nodes skip the variable. Therefore exact D_pi=sum_i 1[h_pi(i+1)!=0] 2^lambda(S_i). Inconsistent system D=0; constant TRUE also D=0, terminal label distinguishes. For a fixed H and b consistent, optimal size (not just optimal maximum width) via DP f(empty)=0, f(S)=min_{j in S}(f(S-j)+1[h_j!=0]2^lambda(S-j)). Every ordering corresponds to a chain, every chain to an ordering; exact Bellman optimality. At most 2^n subsets, n2^n transitions, rank acquisition charged; exact integer node count uses O(n+log n) bits. No polynomial minimization guarantee. ## 3. Genuine minimally UNSAT 3-CNF and all-order exponential plateau

Each vertex parity row encoded as the four proper ternary clauses excluding wrong-parity words. Entire F has 4t clauses, UNSAT since each variable occurs in exactly two parity rows and XOR of RHS=1. Remove any ONE clause at v. Fix its three incident edge bits to the wrong-parity word excluded by that missing clause. The other three local clauses hold. On connected G-v the remaining vertex parities adjusted by these fixed bits have even total (sum of chosen boundary bits is 1+b_v), so its incidence system has a solution, e.g. spanning tree lift. Thus every single-clause deletion SAT and every proper subset SAT. This is clause-minimal UNSAT, not only a grouped equation-minimal source. Immediately before the last clause (regardless of insertion order), solution predicate is exactly remaining parity equations and the three fixed bits. The last clause yields terminal FALSE.

For an infinite cubic 3-vertex-connected family of linear treewidth, start with simple bounded-degree connected expander base B (standard existence of cubic expanders, BSW Cor4.5). Add a Hamilton cycle on its vertex set if necessary, allowing indexed parallel edges but no loops. Replace each vertex of this bounded-degree base multigraph by a cycle with two consecutive ports per incident edge; for each base edge connect the two corresponding port pairs by two disjoint edges. Result G is simple cubic, size O(|B|), and has B minor (contract each cycle, delete duplicates and added edges). It is 3-edge-connected: a cut of <=2 splits at most one cycle; if none split, the added Hamilton cycle guarantees >=2 base crossing edges, each gives two edges; if one split, two internal edges consumed, all wires intact, and base minus this vertex connected by Hamilton path forces all other cycles to same side and all its ports to that side, contradiction. In cubic graph, 3-edge-connectivity implies 3-vertex-connectivity: single vertex cut would need >=6 incident edges; two-vertex cut requires exactly two 3-edge-boundary components and nonadjacent removed vertices. Each removed vertex touches both components (else disconnected), one has 2 edges to one component, adjoining that vertex to that component gives 2-edge cut. Base expander has tw=Omega(|B|): a centroid bag of any tree decomposition is a balanced vertex separator, remaining components <=|B|/2; if separator small, union components of size between |B|/3 and 2|B|/3, all its crossing edges go to bounded-degree separator, so expansion forces linear bag.
