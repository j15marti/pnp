## Lemma 2: exact admissible span for symmetric block

For S_C defined by above homogeneous implication system, span(S_C) = {z: alpha*z=0} (if alpha=0 this is full space). Necessity: sum_i z_i(A_i*z+alpha_i)=alpha*z over Boolean ring, since symmetric off-diagonal terms cancel. Constructive converse: for each zero-labeled vertex v, singleton e_v is admissible. For any two one-labeled vertices u,v joined by a path with only zero-labeled interior, take a shortest such path in the induced graph on the zeros plus u,v; it is chordless, its endpoints have degree1 and interiors degree2, so path support is admissible. Its sum with the zero singletons is e_u+e_v. The graph on one-labeled vertices joined by such paths is connected, since a path between any marked pair splits at consecutive marked vertices. These differences along a spanning tree generate the even-sum space on marked coordinates. Empty/one marked cases follow immediately. Polynomially many BFS paths and singleton witnesses; all generators of span can be represented using a basis of actual admissible assignments. For disconnected graphs use each connected component.
