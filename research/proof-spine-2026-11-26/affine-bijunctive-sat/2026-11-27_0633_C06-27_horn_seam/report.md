## A. Exact Horn closure algebra (constructive)
Let H be any explicit Horn CNF on n Boolean coordinates and M its family of true-variable sets. Horn propagation computes cl(S), the least model containing seed S, or detects that no such model exists. This is polynomial in the explicit H and S. If H itself inconsistent, stop NO. For each C in M let e_C(X)=1[C subset X], X in M. A monomial prod_{i in S}x_i agrees with e_cl(S) on M, or identically zero when cl(S) fails. In GF2,
e_C e_D = e_cl(C union D) (or 0 if inconsistent).
The e_C are linearly independent as FUNCTIONS on M: order M by any linear extension of inclusion; the evaluation matrix indexed by X,C has entries 1[C subset X], is triangular with diagonal1. Alternatively any inclusion-minimal nonzero coefficient C has evaluation1 at X=C. Thus this is an exact canonical representation in the Boolean function ring restricted to M, not formal polynomial equality over an unrestricted field.

For seam A x=b, if inconsistent by Gaussian stop NO; otherwise choose r independent equations. Its Boolean acceptance indicator Q(x)=prod_j (1+b_j+sum_i A_ji x_i) in GF2. Construct this product incrementally in the closure algebra, starting with e_cl(empty). For each current key C and each variable or constant in next affine factor, compute Horn closure of the union, reject inconsistent seed, toggle resulting key (exact GF2 cancellation). An empty dictionary proves NO. Nonempty at the end gives actual witness: inclusion-minimal nonzero key satisfies Q=1 and H, then lift through original map. No counting claim: summing values modulo2 would not decide emptiness. If D_j is the actual intermediate dictionary, paid calls <=1+sum_j |D_{j-1}|(rowweight_j+1), each polynomial; charge candidates before cancellation, not merely attained final keys. Use deterministic sorted dictionaries/balanced trees in complexity analysis (Python set and JS Set used in tests). A hard polynomial aggregate cap gives UNKNOWN on exhaustion. This is a hybrid of Horn propagation, Boolean quotient and affine symbolic expansion.

## B. Independent algebraic closure proof and exact conditional hull
Every degree-d multilinear polynomial on M is a linear combination of e_cl(S) for seeds of size<=d. If it is nonzero, a minimal nonzero closure key gives a witness among those seeds' least models. Hence the exact decision algorithm enumerating all seeds of size<=r is complete with n^{r+O(1)} time (XP, NOT FPT). This independently reconstructs the M=2 multiple-modular-constraint result of Brakensiek-Gopi-Guruswami arXiv:1902.04740v1 section3.2. Moreover the actual affine hull of H AND the r seams is generated by ALL parity-compatible least models from seeds of size<=r+1: if any affine functional vanishes on these but not on some joint model, its product with Q is a nonzero degree<=r+1 function, a contradiction. Empty model set explicitly handled. For r=0 this computes the full affine hull of any Horn (or satisfiable 2CNF after renaming) relaxation using n+1 closures. This is not the hull of the original mixed system unless all seams used.

Stronger constructive feedback on compact Q: compute canonical dictionaries Q and x_i Q for i=1..n. Form coefficient matrix whose columns are those dictionaries, row IDs are their union of actual closure keys. By independence, the kernel consists EXACTLY of (a,c) such that (a.x+c)Q vanishes on M, i.e. all affine identities a.x=c valid on the actual conditioned support. If Q=0, return NO. Otherwise Gaussian nullspace gives a full affine hull equation basis. At most n|D_Q| extra closure calls, at most (n+1)|D_Q| distinct keys, polynomial dense bit elimination and reconstruction in this representation. This avoids seed enumeration for compact high-rank Q. The hull is imported only as necessary equations, never substituted for exact joint support.

## C. Adversarial scope and complexity
A general FPT guarantee in seam rank alone would imply an FPT algorithm for parameterized Clique. Explicit reduction: for each of k copies of graph vertices introduce one variable per vertex; impose all negative binary clauses forbidding two choices in a copy and forbidding incompatible/nonadjacent choices between copies (including same original vertex). Impose one odd parity row per copy. All k rows independent and at-most-one plus odd parity means exactly one per copy, so joint models correspond to k-cliques. This is a parameter-preserving reduction, not a lower bound for unrestricted native planar cubic positive exact-one SAT. No ETH-based conclusion needed, particularly given unverified recent external ETH claims. A logarithmic bound on seam rank alone does not make n^{r+O(1)} polynomial. Likewise closure dictionaries can blow up: independent odd-parity groups each of size3 have 3^r distinct product monomials on unconstrained H; no inference of mandatory exponential decision. Equality control H=(x implies y and y implies x), x+y=1: two terms have same closure key and cancel, proving NO by cancellation rather than deleting forbidden seeds. This falsifies naive syntactic monomial support. Direct pairwise conditioning does not cover the three-group obstruction below; actual row subsets are not interchangeable with independent marginal hulls.
