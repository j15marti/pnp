## L1: small actual implication-seed theorem
Given H satisfiable 2CNF, find one H-model w using ordinary SCC; if H UNSAT reject. Rename x=w XOR y so all-zero satisfies H. Remove tautologies, normalize repeated literals, and interpret every remaining clause as a positive implication y_i -> y_j, a negative pair prohibition, or a negative unary pin. In this normal form every H-model is exactly an implication-closed set avoiding prohibited pairs and pins. Let C(S) be the forward closure of seed set S. It is the union of C({i}) over i in S, and infeasible closures cannot be contained in any H-model. Row reduce XOR equations; inconsistent system rejects, else take r independent equations with syndrome target t translated by w. Let A_i be the r-bit column of variable i.

For every target t attained by an H-model there is an H-model C(S) with |S|<=r attaining t. More generally degree-h Boolean polynomial identities over any field on H can be tested on feasible C(S) with |S|<=h. Proof: on H-models, the squarefree monomial indexed by S equals the indicator that C(S) is contained in the model. Infeasible closures give zero. Group all coefficients by distinct feasible closures arising from <=h seeds. Sort these closures by inclusion. Evaluation at each actual closure gives the sum of coefficients of closures contained in it; triangularity (unit diagonal) shows if all sample evaluations vanish then all grouped coefficients vanish. Thus vanishing on these actual samples iff vanishing on H. For the target syndrome use GF2 and polynomial product over j=1..r of (1+t_j+sum_i A_ji y_i). It has degree <=r after Boolean reduction y_i^2=y_i and equals 1 exactly at target. This is equality as functions on Boolean models, not equality of unrestricted formal polynomials. If the target exists the polynomial does not vanish identically, so an actual seed-closure sample attains it. r=0 uses all-zero. This gives independent exact XP route O(n^r poly(N)); not a new universal algorithm. Brakensiek–Gopi–Guruswami arXiv:1902.04740, section 5/Proposition 5.2 reports n^{O(r)} for GF2^r by a different recurrence; no novelty claim for XP bound.

## L2: deterministic separation makes rank logarithmic sufficient under bounded closure interaction degree
Build a graph K whose vertices are actual feasible singleton closures indexed by original variable seeds (duplicate equal closures may remain). Join two if their closures overlap or their union violates H. Acquire all closures by reachability; test each pair by scanning H. D is maximum degree, computed, no supplied decomposition. Any independent pair of vertices of K represents disjoint compatible closures. More generally unions of collections in different K components are disjoint and mutually compatible because all constraints in renamed H are unary, implication, or pair exclusions and every individual closure is closed. A collection's union is feasible exactly when it contains no prohibited pair or unary pin. Each target model from L1 can be generated by at most r vertices S of K. Set k=min(|V(K)|,r(D+1)). The set S together with its outside neighbor set has size <=k.

A deterministic separating family of binary colorings: let n0=|V(K)|, m=k+ceil(log2(max(1,n0)))+1, q=2^m. Build GF(q) as polynomials modulo the first irreducible monic binary polynomial of degree m (exhaustive search plus trial division through degree floor(m/2), cost 2^{O(m)} poly(m), standard existence). Index K vertices i=0..n0-1. For every a,b in GF(q), color i by a fixed nonzero GF2-linear functional L(a*b^i), e.g. constant coefficient; 0^0=1. For a nonempty subset U of indices, P_U(b)=sum_{i in U} b^i is nonzero formal polynomial of degree <=n0-1. Uniform averaging over a gives E_a (-1)^{L(a P_U(b))}=0 unless P_U(b)=0, when it equals 1. Therefore absolute bias over pairs (a,b) <=(n0-1)/q. Expanding the product of t<=k bit-pattern indicators shows probability of each prescribed pattern >=2^{-t}(1-(2^t-1)(n0-1)/q)>0. This is a counting proof of exhaustive coverage; the algorithm enumerates all q^2 pairs deterministically, uses no random samples, nonuniform advice, or unproved acquisition. If n0<=2m, enumerating all 2^n0 colorings is also within the same cap.

For a coloring, find connected components of the red-induced K. For each red component J, form U_J=union_{i in J} C({i}); discard it if not an H-model. Remaining components are pairwise disjoint on actual y IDs and mutually compatible; their labels s_J=XOR_{i in U_J} A_i add exactly. DP initialized {0}, update R:=R union (R XOR s_J) for each component, with backpointers selecting whole components or none. If t occurs, reconstruct union, undo w, and check H and original XOR rows/guard. If all colorings fail, NO: choose L1's S, use family coloring S red and all its external neighbors blue. Then S is a union of full red components (not necessarily independent), all those components feasible, and their union hits t. Contradiction. No model count or affine-hull substitution: only attained group labels and exact retained witnesses.
