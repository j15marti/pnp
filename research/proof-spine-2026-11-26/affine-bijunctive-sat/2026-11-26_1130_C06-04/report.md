## 2. First method: exact integer occupancy from parity
For each signed exact-one row C, let t_C(x) be the integer sum of its literal values, counting occurrences. Enforce t_C(x)=1 (mod 2) by a linear equation. On this affine system every t_C is odd and nonnegative, so >=1. For positive integer owner weights w_C, define W(x)=sum_C w_C t_C(x). Then W(x)>=sum_C w_C, with equality iff every row satisfies exact-one. This is an exact optimization reduction, not an affine-hull approximation. A consistent parity solution may have strictly greater optimum and hence be a genuine NO. If no parity solution exists, reject. Unit weights suffice.

Each literal x_i or 1-x_i contributes linearly over integers: W=C0+sum_i c_i x_i. Complement coordinates with c_i<0, setting x_i=y_i XOR f_i with f_i=[c_i<0]. Then W=C1+sum_i |c_i| y_i, C1=C0+sum_{c_i<0} c_i. Substitute the same flips into all parity and affine guard rows; d changes by Bf, B columns unchanged. Integer signs and offsets have polynomial bit cost. Zero costs allowed. Thus exact-one feasibility is precisely min_{By=d} sum |c_i| y_i = sum w_C-C1. Witness reverse flips and original integer-row checking mandatory. A computed feasible minimum below that threshold would be an implementation error.

Native cubic positive case: n=m by degree count, and on Ax=1 over GF(2), 3|x|=n+2D(x), where D counts 111 clauses. Hence min |x|=n/3 iff native SAT, and the exact minimum defect is (3 min|x|-n)/2. If n not divisible by 3 reject directly. All-one x is an unguarded parity solution, but not necessarily an exact-one solution. In ordinary exact cover or P3DM each column cost equals its incidence count (3 for triples), so min weighted parity cover exactly tests complete coverage with no extra occurrence promise. Preserve tuple and owner IDs. This is a correct cross-source adapter for C01's source, not a reduction from arbitrary edge coloring or NAE.

General mixed affine-bijunctive adapter: for every binary clause (l OR m) of H add a fresh slack s and the signed exact-one row (NOT l, NOT m, s). If both l,m false there is no extension; if both true s=1; if exactly one true s=0. Thus each satisfying H assignment has a unique slack extension. Units become affine pins; empty clause rejects. Keep the original A and guards. This costs O(number of clauses) variables and rows and polynomial encoded bits, even repeated literals/tautologies; the proof concerns decision, not a claimed symbolic counting circuit. Hence the terminal below genuinely applies to H AND A, not just native H with silently dropped additional constraints.

## 3. Second method: graphic realization and exact minimum T-join
Let B_R have rank r. Pick independent indexed basis columns via Gaussian elimination; express remaining columns as D in [I_r | D] coordinates. Bixby–Wagner (1988) gives a polynomial graph-realization algorithm deciding whether the columns of D are path incidence vectors of a tree T on r+1 vertices, constructing that tree if yes. Tree edge IDs are basis column IDs, and each nonbasis column is an edge between its path endpoints (zero column a loop, isolated by explicit handling). This is equivalent to graphicness: in any graph realization the basis edges are a spanning forest, which can be made a tree by identifying one vertex from each connected component without changing circuits; fundamental cycle dependencies exactly match D over GF(2). Conversely the realized tree and chords have precisely the prescribed dependence matrix. Rank-zero case uses loops only. The publisher's original graph-realization statement and CMR documented implementation were inspected; full Bixby–Wagner proof not accessible here, no independent implementation/build claimed.

Let D_G be the full binary vertex-edge incidence matrix of the constructed graph with loop columns zero. Verify row-space equality with B_R by Gaussian elimination, using edge IDs (both row spaces have the same span in GF(2)^R). Equivalently verify a linear isomorphism phi:span(B_R)->span(D_G) sending each original column to its corresponding incidence column. One can explicitly map any target s by solving B_R z=s and setting phi(s)=D_G z; consistency of the map follows from equality of kernels and does not require enumerating solutions. Reject s outside span(B_R).

For any mapped syndrome t=phi(s), minimizing nonnegative edge cost with D_G z=t is exactly minimum T-join, T the vertices whose bit is 1. Loops of nonnegative cost can be omitted. A component with odd number of T vertices is infeasible. Otherwise form the shortest-path metric on T within each connected component, find a minimum-weight perfect matching there and XOR the paths. This produces correct boundary, and its cost is at most the matching cost. Conversely every edge subset with the target boundary decomposes into T-to-T trails plus cycles: pair incident half-edges at all vertices except leave one unpaired at each T vertex, then follow trails. Dropping cycles and shortening paths cannot increase cost, giving a terminal matching of cost at most the subset cost. Together the inequalities prove exact optimum and witness. This is a constructive proof and an independent optimum lower bound on the SAME system/guards. Standard deterministic weighted matching is polynomial in graph size and cost bit length (Edmonds–Johnson 1973, original parity formulation and metric reduction). All recognition, shortest paths, weighted matching, path XOR and verification are charged. No requirement that realized graph be planar.

## 4. Low-rank exceptions: optimize joint syndrome, not its affine hull
Partition into graphic R and exception set E, k=rank(B_E). Choose a basis for its span (Gaussian). In these coordinates perform exact min-plus DP over exception columns. State delta is the XOR contribution; initially M_0(0)=0 and all others +infinity. On column e of cost c, set M_new(delta)=min(M_old(delta),c+M_old(delta+B_e)). Keep a predecessor, with original edge identity. Pins restricting the exception bit can simply remove the corresponding transition (or compile all affine guards into B). At most 2^k attainable states; do not treat unobserved states as attained. This correctly optimizes all exception subsets with identical contribution because the core sees ONLY residual syndrome d+delta and the cost is additive. For every finite state, solve the core T-join for that residual syndrome. Take min_delta(M(delta)+core_opt(d+delta)). Both components have actual witnesses and combine on disjoint column IDs. Conversely any full witness induces one attained exception state and one core witness, giving a lower bound by the returned optimum. This proves exact compatibility; even |E| very large is harmless if its syndrome rank is small.

Time <= 2^k poly(N), including basis extraction, exceptions DP O(|E|2^k poly(N)), <=2^k weighted matching calls, witness reconstruction, input checking and graph realization. Peak space <=2^k poly(N) with layered backpointers and one matching workspace. For fixed log cap both polynomial, and cumulative memory <=T*S on this same deterministic execution; no claim polynomial space for unrestricted k. Integer costs and sums have polynomial bit length; no exponential unit words. A deterministic acquisition pass scans columns in fixed original-ID order, adding a column to R iff the restriction remains graphic, otherwise adds it to E. Graphicness is hereditary under deletion, so every retained R is graphic. At most n polynomial graph-realization calls; test actual k, not a guessed small exception set. May also try a fixed finite list of orders, charging all failed work. If actual k exceeds fixed c log2(N+2), this admission returns UNKNOWN. It does not guarantee finding a low-rank deletion set whenever one exists. An exact supplied chart can alternatively be admitted after polynomial verification. Additional affine guards change the parity matrix and may break graphicness; reacquire, do not reuse without checking.

## 5. Graphic block gluing (additional scoped corollary)
For a column partition into blocks with graphic realizations and a supplied binary tree on blocks, let V_S=span(columns in subtree S), W_S=V_S intersect V_complement. Solve Bx=d by Gaussian to obtain an arbitrary affine witness x0 or reject. Its restriction yields reference partial syndromes d_S=B_S x0_S with d_parent=d_left+d_right. A globally extendible partial syndrome must be d_S+u for u in W_S: the difference from x0 on S is matched by the difference on its complement. At each leaf block compute minimum costs for all u in W_S by T-join, storing actual witnesses or infinity. Internal children combine u1,u2 only when u=u1+u2 is in W_parent, and minimize the sum of attained child costs. Every stored state has actual partial witnesses; conversely every global witness follows admitted states, including its reference-relative syndromes at all cuts. At root W=0 and the unique target is d. Backtrack and verify. With maximum interface rank w, O(4^w poly(N)) total work and O(2^w poly(N)) space, including all graph recognition and cut basis calculations, GIVEN the partition/tree. Singleton exceptions can instead use exact syndrome DP. No optimal block-partition/tree acquisition theorem claimed. For two graphic blocks, only intersection rank matters, not either block's rank. This extends C06-03's decision separator concept to an additive objective and implicit large graph optimization. It is a mathematical corollary not independently executed in the current audit.

The duality of a full-row-rank binary representation and a kernel-basis representation follows by extending independent columns to bases or standard [I|D] / [D^T|I] duality. F7* has rank 4, seven elements, no loops/parallel pairs/triangles: its circuits are supports of minimal nonzero linear forms on the seven nonzero 3-bit vectors, each of weight 4.
