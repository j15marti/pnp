## A. Exact observation-tree gluing theorem
For owner subset S of the retained set J, W_S=sum of its normal spaces, T=J minus S, I_S=W_S intersect W_T. Set lambda(S)=dim I_S=r(S)+r(T)-r(J). This is an integer nonnegative symmetric submodular connectivity function by rank submodularity; singleton <=2. Given rooted binary owner tree (rooting an edge of a subcubic branch decomposition), store the actual restrictions on I_S of all linear functionals on W_S avoiding every flat owned by S. Leaves enumerate <=4 local words, discard c_i. All observation functionals extend to a chart point by Gaussian elimination. At a join with children A,B and outside C, K=W_A intersect W_B is included in both child interfaces. Two actual table words can be jointly extended iff their restrictions to K agree: necessity immediate, sufficiency by ordinary linear gluing of the corresponding attained child functionals. Parent I_P is included in I_A+I_B: if v=a+b belongs to W_C, then a=v+b belongs to W_C+W_B and similarly b. Thus each agreeing pair uniquely determines its parent restriction, independent of arbitrary chosen decomposition v=a+b, because the difference is an element of K. Exact induction in both directions. Bucket children by their actual restrictions on K before joining. No marginal-hull substitution; the root interface is zero, with empty table iff full retained instance is NO. Actual witnesses can be lifted using backpointers and Gaussian gluing, then original Rado extension and source map. For any verified width w tree, time poly(N)2^(2w), peak space poly(N)2^w including all retained tables and backpointers. Multiple omitted flats or any core deficiency allowed; no single-omitted-flat assumption.

## B. Independent dual-syndrome method and exact adapter
Concatenate bases of W_i as rows of G (L rows, effective rank d). Let D be a parity-check matrix whose rows form a basis of ker G^T; then ker D=image G. Each owner chooses an allowed local observation word a_i. Syndrome sum of D_i a_i must equal zero, exactly, with no counting oracle. At each node S retain actual XOR sums only if they lie in V_T, the span of columns of D outside S. Parent cancellability implies both child sums are cancellable (sibling plus outside), so this filter loses no attainable root zero. Root table nonempty iff SAT. Rank identity: rank D_S=L_S-d+r(T), because codewords supported in S have dimension d-r(T). Therefore dim(V_S intersect V_T)=lambda(S). More strongly there is a canonical bijection I_S^* -> V_S intersect V_T: extend boundary functional to a chart point t, take D_S G_S t. If two extensions agree on I_S their difference can glue its restriction on W_S to zero on W_T, so its S syndrome vanishes. Conversely zero syndrome means the corresponding S word extends with zero outside, hence its boundary restriction vanishes. Equal dimension proves bijective; actual attained tables correspond under this map. This is a verified adapter to grouped XOR-choice joins, including C02-18 quotient-key join on its appropriate input type. Its improved Walsh tariff not required or inherited here; direct pair bound suffices. Decision separated from symbolic counting.

## Polynomial acquisition, not just a supplied tree
Known Oum-Seymour approximation in the general singleton-bound form explicitly stated as Theorem 5.3 of Korhonen and Oum, arXiv:2601.04756v2 (2026-02-09), original p9: for c'=max f({v}), O(2^(3k+c') m^2 SUB(m,km,gamma)) time either supplies width <=3k+c' or confirms optimum >k. Here c'<=2, oracle is ordinary Gaussian rank, values <=2m, submodular minimization polynomial in the stated parameters (their Theorem 2.3). Choose fixed c and k=max(2,ceil(c log2 N)). Thus acquisition and full DP are uniformly polynomial in original N for all optimum width <=c log2 N. Verify every supplied cut by rank computation. On failure return UNKNOWN, not NO. This uses the APPROXIMATION theorem, not the exact-width algorithm with 2^O(k^2) overhead. External theorem not re-proved; acquisition algorithm not implemented in experiments, which use source-order balanced tree and verify its width. Rado deletion cannot increase optimum width: prune leaves/suppress degree two, each surviving cut induced by an old cut and both subspaces shrink. This is the connecting theorem enabling a hybrid.

## Adversarial scope: universal logarithmic width false before forced closure
Mathematical family, not computational test: two disjoint connected symmetric dense k-coordinate blocks, diagonal all1, omitted rank2 flat requiring even parity in each block. Summing equations forces each block parity even (off-diagonal terms cancel), hence NO. Retained owners W_i=<e_i,Q_i>. For any proper subset of retained owners cutting a block, an outgoing neighbor gives rank >= |S|+1; if subset comprises whole blocks, omitted owner adds a missing block parity normal whenever a block is absent. All proper subsets of full owner set therefore have rank-minus-size >=0 and full value -1, so unique tight Rado core. For a random symmetric block, every balanced cut with k/3<=a<=2k/3 has cross rank >=floor(k/8) with probability tending to1: independent cross entries, rank<r probability <=2^(rk-ab) <=2^(-7k^2/72); union bound over <=2^k cuts. Connectivity follows similarly by union bound over disconnected cuts. Every subcubic tree restricted to one block has a balanced edge; on that block r(W_A)=|A|+rank cross, and shared space dimension is twice cross rank by symmetry. Full cut contains that intersection. Thus optimum Omega(k) despite original guarded encoding polynomial in k; not O(log N). This is a guarded, pre-forced-closure falsifier only: quadratic conservation already refutes these examples. Not postclosure hardness or an unrestricted lower bound. At stagnation the rank quotient identity and Rado deletion monotonicity give a complementary adaptive route; universal productive acquisition remains OPEN.
