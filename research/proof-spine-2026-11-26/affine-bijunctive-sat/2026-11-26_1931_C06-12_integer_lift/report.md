## Claim and exact proof
For every explicitly binary-encoded integer matrix A and RHS b, compute the entire affine set of mod-2 residues of solutions to A z=b modulo4 in polynomial bit time. The target source is positive planar cubic exact-one SAT (three distinct variables per clause, every variable occurs three times), with explicit affine guards only as authenticated controls or residual constraints. N is original bit length. Falsifiers: omitted liftable residue, unsound half-row, lost guard, and promotion of a nonempty relaxation to Boolean SAT.

First solve A x=b modulo2. Acquire a GF2 basis of ker(A^T), using binary representatives y. For each basis vector, y^T A is even and y^T b even if the first relaxation is feasible. Add the parity row (y^T A/2)x=y^T b/2 modulo2. For any binary representative x, a mod4 lift has form z=x+2t. It exists iff A t=(b-Ax)/2 modulo2 is consistent. This is equivalent to orthogonality of its RHS to every left-nullspace basis vector, exactly the imported half-rows. Thus all and only liftable residues are retained, without enumerating left-nullspace members or candidate assignments. A GF2 solve reconstructs t if needed. Existing parity guards are intersected with the complete residue chart; never remove original Boolean constraints. This is an exact modular relaxation, not a Boolean decision procedure on all inputs.

Full integer extension (symbolic): use polynomial-bit Smith U A V=D with unimodular U,V, check divisibility of U b at nonzero diagonal and zero entries at zero rows. If feasible fix the first r Smith coordinates to quotients, leave other integer coordinates free, map through V and reduce modulo2. The result is precisely the affine residue set of all integer solutions. Intersect with guards. Certified Boolean pins and signed equality/complement relations in that chart imply true integer equations; feed them back to A. Add only rank-increasing consistent rows over Q or reject inconsistency; likewise for GF2 guard imports. At most n increments of each rank, polynomial normal-form recomputation per round. This full iterative driver is proved symbolically, not executed. Nonempty lattice residue does not imply Boolean SAT; integer values outside [0,1] remain possible.
