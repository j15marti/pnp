## Replica A: chord component theorem
First, K is bipartite for a planar G and its Hamiltonian cycle C: Jordan separation places each chord on either side of C, and alternating endpoints on the same side would force a crossing. Conversely bipartite K gives an explicit two-page planar drawing by assigning one part to each side. The cycle can be verified by scanning original edge IDs; no free Hamiltonicity search. Construct K by O(n^2) endpoint comparisons, BFS components and two-coloring. A maximum bipartite matching via augmenting paths and its alternating reachability give a minimum vertex cover by Konig's theorem: every cover must hit each matching edge, the cover consisting of unreached left and reached right vertices hits all edges and has matching cardinality. Verify both directly.

Gap lemma: Fix a connected chord component B, whose endpoint sequence partitions the circle into open gaps. Any chord d outside B does not alternate with any chord in B. If its two endpoints lay in different gaps, both open arcs cut by d would contain endpoints of B. Each B chord would have both endpoints in one arc, since otherwise it crosses d. The two nonempty sets could have no crossing edges between them, contradicting connectivity. Thus d lies in one gap. Chords lying in distinct gaps do not alternate, so an entire other connected component lies in a single gap. This is an exact structural statement, not a heuristic planar projection.

Recursion: linearize the cycle from a chosen first endpoint. In an interval closed under chord pairing, take the component containing its first endpoint. Recursively eliminate all gap interiors between successive component endpoints and the suffix after its last endpoint. The only edges from a closed interval to the exterior are at its two cycle boundaries. Eliminating its interior produces only a possible binary relation between those boundary vertices, retaining actual backpointers. The virtual edge is permitted in the structural graph even if the relation is full. At the component skeleton, vertices are its own endpoints; skeleton edges are consecutive-endpoint edges (some virtual) and component chords, plus at most two exterior boundary vertices. Each component processed once, even when nested. One can construct an explicit elimination order with no recursion duplicated per boundary assignment.

Choose a minimum cover of the component crossing graph. Hold the VARIABLE endpoint of each covered chord (binary; distinct endpoints because M is a matching) until all other component vertices have been eliminated. Hold the exterior boundary vertices too. On the unheld component vertices the remaining chords do not cross, and consecutive-endpoint edges are outerplanar. Every nonempty outerplanar graph has a vertex of degree <=2: augment to a triangulated polygon and take an ear, or apply the same argument to each block. Eliminating a degree-two vertex and adding an edge between its neighbors preserves outerplanarity, since this fill is a graph minor obtained by contracting one of its incident edges; degree <=1 is deletion. Repeatedly choose a minimum-degree unheld vertex counting ONLY unheld neighbors. Fill involving held vertices cannot introduce additional unheld-unheld edges beyond this two-neighbor operation. Thus at most two unheld neighbors, at most k_i held binary vertices and at most two exterior neighbors; total width <= k_i+4. At the end eliminate the held cover vertices, keeping exterior vertices. No fill from a closed interval ever reaches beyond its two original exterior neighbors. The root has no exterior neighbors. Actual order and all induced scopes can be recomputed and checked.

Exact Boolean-semiring elimination: gather all factors touching a chosen vertex, conjoin them, existentially eliminate its label, and store for each retained boundary tuple one actual eliminated label if it exists. This preserves every attainable joint boundary label; reverse the history to lift a native assignment. A zero factor rejects; no oracle. Each local table evaluates at most 2^k_i * 3^5 tuples (k_i binary cover labels, up to two other neighbors, two exterior labels, and the eliminated label), up to polynomial factors for lookup/conjunction. Held vertex elimination fits same bound. Number of vertices, factors, buckets and structural scans polynomial; each component visited once, not recursively recomputed for each upstream context. Sum of costs <= poly(N) sum_i 2^k_i, including discovery, elimination-order verification, source closure, original witness lift and input validation. For any fixed c, truncate if k_i>c log2(N+2) unless the actual verified table tariff is polynomial; return UNKNOWN if not admitted. Actual weighted domain product per bucket is a stronger admission certificate than k or unweighted width alone. On admitted orders time, peak memory and cumulative memory polynomial (cumulative <= time*peak). No uncharged counting.

## Replica C: adversarial native family and reference

For positive even r,s>=2 all chord endpoints have opposite cycle parity and are not consecutive, so G is simple cubic bipartite. Chords within each letter class are nested; all between classes alternate. K is K_(r,s), hence bipartite, proving planarity by the two-page embedding. k=min(r,s). Take r=s=6b, n=r+s=12b, so this is a genuine connected native family with k=n/2, falsifying any universal logarithmic cover bound for EVERY given cycle chart. ## Further complementary attack: two-edge seam, acquired 2-factor extension (symbolic)
For ANY native vertex region R with exactly two boundary incidence edges, count cubic degrees on each bipartite side: 3(|C_R|-|V_R|)=#boundary clause endpoints - #boundary variable endpoints. The RHS is -2,0,2, so it is zero. Hence one boundary edge at a clause and one at a variable, and equal numbers of original variable and clause vertices inside R. Write their actual edge bits b_c,b_v. Summing native exact-one clauses and subtracting variable occurrence sums gives |C_R|-3 sum_(v in R)x_v=b_c-b_v. Therefore if |C_R|=0 mod3, b_c=b_v; if residue1, (b_c,b_v)=(1,0); if residue2, (0,1). These are unconditional necessary deductions, not guarantees of attainability. Enumerate all pairs of incidence edges and test components to acquire such cuts polynomially; propagate forced bits/equalities, never replace exact support with this congruence alone.

Every cubic bipartite graph has a perfect matching (Hall by counting 3|S| incidences). Obtain one in polynomial time, leaving disjoint even cycles. This avoids needing a Hamiltonian cycle. For an ACQUIRED 2-factor whose simple cycle quotient is a tree and every adjacency consists of exactly two matching edges, root the tree. Each child subtree has a two-edge cut; its exact response is a subset of the modular possibilities above. Compute child response for at most two port words, retaining actual witnesses. An empty response rejects; two equal-bit words give a virtual ordinary incidence between the two parent endpoints; a singleton gives unary restrictions on parent port bits. Equivalently a binary table on those endpoints. Both endpoints are distinct and one is a variable and one a clause, because each cut is balanced as proved. Each parent vertex has at most one matching port, so all virtual chords and original within-cycle matching chords remain a matching, possibly partial. Planarity of each parent skeleton follows by retaining one path through each disjoint child subtree and contracting its interior to a virtual edge; parallel-to-cycle edges can be combined exactly. For a partial chord matching add singleton components for vertices not incident to a chord in the gap recursion. The same bound works; a singleton is eliminated after its suffix and has <=2 exterior neighbors. On each nonroot cycle compute at most two admissible own-parent port words (or <=4 without modular pruning) with all child tables already acquired ONCE. Pins on cut bits become unary restrictions on the corresponding variable or categorical selector; a virtual chord uses the exact projected bit function. Compose and lift through stored actual witnesses. No multiplication of child computations by ancestor boundary words. Thus if local crossing-component covers in these acquired skeletons are logarithmic (or actual bucket tariffs polynomial), the multi-cycle solver is polynomial too, including matching acquisition and verification. The tree/double-edge quotient test is polynomial; arbitrary multi-cycle quotient is OPEN. This extension and cut rule are symbolic in this run, NOT a claim that the multi-cycle driver was executed.
