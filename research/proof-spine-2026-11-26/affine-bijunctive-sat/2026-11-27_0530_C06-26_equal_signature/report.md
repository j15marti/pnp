## 1. Exact space of adapted bases
Acquire one common adapted basis B by weighted matroid greedy on union of nonzero vectors of W_i (<=7m), weight(v)=number of W_i containing v; equality of basis weight and sum_i dim W_i is necessary and sufficient. If no equality, UNKNOWN for this terminal. Define signature S_b={i:b in W_i}. For any adapted basis and any nonempty set J of regions, dim intersection_{i in J} W_i equals number of axes whose signatures contain J. Inclusion-exclusion gives basis-independent counts of each exact nonempty signature. This is an existence proof, not an exponential computation: obtain labels directly from B and match any hypothetical B' by its signature. Any adapted B' with these labels is exactly an invertible scope-preserving block triangular transformation: y_b (new observation) is linear combination of old axes a with S_b subseteq S_a, followed by arbitrary translation. Necessity follows from membership in intersection_{i in S_b} W_i. Sufficiency: diagonal blocks on equal signatures invertible, inclusion order makes full map invertible, each W_i maps into itself and dimensions give equality. Diagonal invertibility also necessary for invertible triangular map. Thus this searches ALL adapted bases, not all arbitrary bases or regional partitions.

## 2. Maximal equal-signature pair
A rank-two equal-signature block (two axes with same signature) can only occur together, optionally with one singleton c. Two distinct pair blocks cannot share a region. For a maximal pair, its invertible affine maps are AGL(2,2)=S4 (all permutations of four points; 24 maps). Signed-pair objective depends only on p=preimage(00), q=preimage(11), p!=q; either ordering of remaining two points works. For hole h in pair coords, pair's number of positive literals is 2 if h=p, 0 if h=q, 1 otherwise; pair contribution 1[h=p]. If a third singleton c is incomparable in signature, c must be maximal (any strict superset axis would have to occur in this same rank3 scope and can only be a pair axis, ruled out). It has only sign r_c. For hole (h,z), extra pair cost 1[z=r_c]*(2 if h=p,0 if h=q,1 otherwise). Pair-only holes have no extra term.

If any p0 absent from every hole in every scope of this pair, fix p=p0 without loss for every choice of outside signs. Replacing old p with p0 decreases or preserves every cost if q!=p0. If q=p0, swap p and q (old p becomes 11, absent p0 becomes 00), again nonincreasing. Applies also to leaf costs below. If all four words occur, every transform pays >=1 from this block's within-pair terms alone. Pair scope sets are disjoint, so more than k fully covered maximal pairs rules out signed-pair distance <=k. Otherwise enumerate only their p choices, <=4^k globally (not 4^number of pairs). For each fixed p, use three Boolean selectors Q_h (h!=p), pairwise hard at-most-one. A hole at p contributes constant1 plus twice the positive singleton indicator (if present). Other hole h contributes violation of the binary clause (z!=r_c OR Q_h); pair-only holes just use constant. At-most-one does NOT require a nonbijunctive at-least-one clause: if all selectors false, choosing any q!=p weakly decreases cost because selectors occur only positively in soft clauses. Thus min over selector assignments equals min over valid affine maps, and any admitted assignment extends to an actual invertible map with cost no greater. This handles arbitrary high degree of a shared pair, not a bounded-width assumption.

## 3. Pair-local leaf shear (complete two-parent optimization)
If singleton b has signature strictly contained in a maximal pair's, every scope containing b is exactly {pair,b}. It has no subordinate axis (would require rank4). Permit y_b=x_b+u(h) for arbitrary affine Boolean function u on the old pair h. Let n_h0,n_h1 count hole occurrences for each leaf value at h across that scope group, n_h=n_h0+n_h1, m_h=min(n_h0,n_h1). With fixed pair p,q the leaf cross contribution has weight 2 at p,0 at q,1 at other points. Affine u satisfies XOR of its four context bits=0. Its values at three points h!=q can be chosen independently (any three distinct points in F2^2 affinely independent); choose each minimizing positive hole occurrences and complete parity at q, which costs nothing. Exact minimum total for these scopes:
  n_p+2m_p+sum_{h!=p,q}m_h = n_p+m_p+sum_h m_h-m_q.
This is reconstructible, not just a bound. Free-p pruning remains valid by the pointwise replacement or the displayed nonnegative expression. For fixed p, charge constant n_p+2m_p and m_h copies of unit Q_h for every h!=p; selector completion weakly improves cost. Multiple private singleton leaves on one shared pair optimize independently, with all original hole occurrences counted exactly once.

## 4. Remaining signature cases (no omitted interaction)
A rank-three equal-signature block occurs in rank3 scopes alone and has no strictly comparable extra axis. Enumerate 168*8 affine transformations locally; add optimum constant. A rank-two block with a strict superset signature must have exactly one dominating singleton c; every pair scope is exactly {pair,c}. c is maximal (a further axis requires rank4). Pair coordinates may mix with c, but c is not mixed with pair. Conditional on r_c, enumerate 24*4 maps of pair (invertible affine diagonal part and two shear bits to c); exact unary cost and argmin. No pair variables occur elsewhere. All these local choices are independent conditional on their named outer signs.
For singleton-only scopes, a singleton b can have at most two strict superset axes, because every scope containing it includes them. Zero: sign only. One: its parent a is maximal, use C06-25 independent context bits u_b0,u_b1; every transformed hole literal depends on one Boolean optimization variable. Ordinary pair cost yields 2-CNF. Two: b occurs only in scope {a,c,b}; no child. If both a,c maximal singletons, enumerate all 8 affine b transforms conditional on two signs (four-entry binary cost table). If they form a chain S_b proper subset S_c proper subset S_a, c has one parent a and independent context bits u_c0,u_c1. The pair map of (a,c) is triangular y_a=x_a+r_a, y_c=x_c+u_c,x_a. The leaf formula from section3 still applies. Its p=(r_a,u_c,r_a), q=(1+r_a,1+u_c,1+r_a). For each old a bit j, group the two m_h in its fiber. If j=r_a, contribution is sum_{h:a=j}m_h+n_p+m_p. Otherwise contribution is sum_{h:a=j}m_h-m_q. Each is nonnegative and depends only on (r_a,u_c,j), two Boolean meta variables (j is a fixed label). Hence exact two binary cost tables and reconstruction, not an unencoded ternary parity. If the two superset axes have equal signature, they form the maximal pair already treated. No singleton in a remaining scope can have a transformation depending on an axis outside that scope. These cases exhaust the block triangular group because rank<=3 limits every upward closure to three axes; each locally eliminated block/leaf's entire set of scopes is assigned to its unique group. Other singleton-only scopes contribute ordinary signed pair clauses. This proves the full adapted-basis theorem, extending C06-25's maximal-anchor restriction.
