## Scoped cooperative theorem and probability
Each epoch close root using exact local row filtering/unanimous-bit GAC. Single-bit lane closes both exhaustive contexts v=0,1. Every actual global witness belongs to one context, so only retain union of local rows surviving either context; both failures imply UNSAT. Pair lane tries one two-pin guard (and singleton failures), learns its negated clause only if local closure contradicts. Hybrid interleaves both methods on same current chart, preserving checked forbidden-pair factors and original row deletions. Each newly learned guard is independently validated by a separate row-scanning, one-pin-at-a-time checker using pre-step state; both contexts checked for row-union changes, final split/root contradiction checked. Discovery uses sound explicit support-bitset operations, verification uses separate table row enumeration. The independent checker was run on every trace, including capped ones. It is algorithmic independence, not external peer review.
Fix explicit original tables with R0 rows and r carriers, and finite possible new unit/binary-guard clause slots L=2r+4 binom(r,2). Store new learned clauses only once. Do not credit arbitrary new tables. Potential Phi=remaining original rows+unlearned slots. Each successful step either removes at least one original row or occupies a fresh clause slot; >=1 decrease. Initial Phi<=R0+L. New clause table storage accounted by fixed slots; even if logically redundant it can spend a fresh syntactic slot only once, no claim of independent semantic deduction. Every fixed epoch candidate pool consists of <=r+4 binom(r,2) actions (a single pivot entails two contexts); enumerating it is polynomial; each closure has <=r+1 full sweeps, each bounded-width factor visit costs polynomial bit operations. Full without-replacement scan or deterministic enumeration with all failed tests charged yields scoped polynomial termination. If at least one productive candidate exists, uniform ideal sampling has probability >=1/pool size, so the existence premise suffices for deterministic exhaustive acquisition too. Universal existence of a productive guard/terminal is OPEN and false for these two isolated lanes (control below). For K successes out of M fixed candidates, expected first hit with replacement M/K, without replacement (M+1)/(K+1) under uniform permutation, K>0. Balanced schedule is stratified, not uniform on union. No independence assumption across changing states; each new state requires its own conditional progress guarantee. Under a hypothetical uniform p>=1/poly(N) on every unresolved NO state, checkable strict global polynomial credits, and fixed polynomial per-trial bit cost, conditional geometric waiting bounds and linearity of expectation give expected polynomial rejection; amplification with fixed cutoff gives one-sided coRP decision for native feasibility if NO coverage and YES soundness established. Not P=NP unless derandomized. No randomized proof of UNSAT based on failures to find witnesses.
