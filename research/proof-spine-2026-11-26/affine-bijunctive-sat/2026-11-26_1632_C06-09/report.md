## Adapter and closure

XOR of group bits=1; since at most one true, exactly one. Nonempty disjoint rows have rank k. For the converse, any satisfying assignment has odd positive selected count in each group; remove all but one, plus all ungrouped bits, preserving negative clauses and group parity. Intra-group negative clauses are optional on this converse; inter-group forbidden pairs are read directly. This is a decision/witness adapter, not counting-preserving for the converse when a group can have more than one true. For explicitly supplied selector chart it is bijective.

Native prism atom: six variables and six clauses C_j=(j-1,j,j+1) mod 6. Exact-one equations imply x_j=x_(j+3) by subtracting neighboring equations. Its three words are (a,b,c,a,b,c), a+b+c=1. ## A constructive exact quotient
For every supplied pair table test whether each row and column has at most one allowed entry. Such a relation is a partial bijection, verified by scanning the actual table, not its affine hull. After optional arc consistency, form graph of such seams. For every connected component C, select one root, enumerate all root labels. Each root label determines at most one label at every vertex by propagating the unique image (or inverse) along a spanning tree; discard if undefined or if any internal relation (including non-tree and non-bijective edges) fails. For every surviving root label store the full actual tuple. Restriction of any satisfying assignment occurs in this list by uniqueness along the tree; every listed word satisfies all internal relations. For every remaining pair of components and every pair of retained tuples, admit iff all original cross-component constraints hold. This is exact quotient, not independent marginal compatibility. Witness lift is direct concatenation. Can repeatedly reclose and contract new partial bijections; every genuine merge reduces number of components, every pruning reduces total stored labels. At most initial number of groups merges and total initial labels deletions (a merged root domain cannot exceed either prior domain because seam is injective). No exponential product of root labels within a component.

## C adversarial parameter barrier and exact reference
Reduction from k-Clique: make k disjoint copies of input vertices, prohibit choices in different groups if same vertex or not adjacent, and prohibit two choices in each group. Group parity=1. YES iff graph contains k-clique. Polynomial encoding, rank exactly k; W[1]-hard under standard parameterized reductions, even all clauses negative and parity supports disjoint. Even a fixed polynomial on the restricted promise rank k<=log_2 N (N explicit encoded input bits) gives FPT for Clique: add 2^k explicitly written disjoint negative-clause pairs on fresh unconstrained-by-parity bits, set all zero. Rank unchanged, encoding length at least 2^k, time f(k)poly(original length). This argument concerns encoded rank promise, not promise after a particular normalization deleting padding. An independent direct subexponential implication under sparse ETH: divide an m-clause sparse 3SAT into k=ceil(sqrt(m)) clause groups; enumerate at most 2^(3 ceil(m/k)) local satisfying assignments per group as domain labels; forbid inconsistent assignments to shared variables.
