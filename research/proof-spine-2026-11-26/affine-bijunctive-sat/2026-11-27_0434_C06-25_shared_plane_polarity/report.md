## A. Exact scope-preserving shared shears
Acquire a common adapted basis by maximum-weight linear matroid greedy on union of the <=7 nonzero vectors per W_i, weight(v)=number of W_i containing v. Total weight <=sum dim W_i, equality iff every W_i spanned by its selected axes. A common basis, when it exists, can be chosen entirely from this union because W=sum W_i. Reject admission if equality fails. Fix the resulting basis, not a universal search over all adapted bases. For each axis j let S_j be its nonempty incidence signature (regions containing it). Pick all axes with inclusion-maximal signatures as anchors A; every other axis b has one or more strict-superset maximal anchor signatures. Let A_b={a in A:S_b proper subset S_a}. Because rank<=3, |A_b|<=2. Every scope containing b also contains all A_b. This partition and all allowed anchor sets computed by explicit subset tests. Consider the family of coordinate changes y_a=x_a+r_a for anchors, y_b=x_b+r_b+sum_{a in A_b} t_ba*x_a for nonanchors, GF2. The linear part is identity plus a matrix whose square is zero, so invertible, and preserves each scope. Inverse: first recover x_a, then x_b. Coefficients and signs are global, including where b is shared between many distinct scopes.

For each regional support table use the specified full-hole CNF: one clause per absent word on the entire region scope, no prime minimization. Every legal shear maps these full holes bijectively, so exact source semantics preserved. A more general fixed forbidden-partial-word list is allowed if every partial pattern mentioning b also mentions all A_b; exactness of such list must be independently certified. We optimize signed-pair cost delta=sum_C binom(p_C,2) for this specified representation, NOT minimum over all equivalent CNFs or arbitrary adapted bases. Width<=3, constant number of holes per region. Empty table immediate NO. Full table no clauses. For a hole h, clause literal for coordinate v is positive iff its new hole coordinate is zero. Each pair of positives contributes precisely one violated binary meta clause.

For |A_b|=1 with anchor a, introduce two independent context bits u_b0=r_b, u_b1=r_b+t_ba. These are in bijection with every sign/shear pair; inverse t_ba=u_b0+u_b1. The new hole value is h_b+u_b,h_a. Thus whether each literal is positive depends on one meta bit, including anchors (h_a+r_a). For every pair of hole coordinates add the binary clause saying they are not both positive. This gives exact cost as a 2-CNF multiset. No conditioning on unknown source assignments: h_a is an explicit constant of the forbidden local word. A shared b must use the same context bits across all regions.

## B. Two-anchor localization, completing the chosen transformation class
For |A_b|=2, naive four context bits are not independent: their XOR is zero for every affine function of two anchor bits. Even parity of four bits is not bijunctive, since 0000,0011,0101 have majority0001; existential projection of a 2-CNF is majority-closed, so auxiliaries cannot directly encode this hard relation as 2-CNF. However rank3 supplies a genuine geometric-algebraic bypass. Every scope containing b must consist EXACTLY of b and its two anchors a,c. No other nonanchor can co-occur. Group all these regions. For each of four anchor polarity words s=(r_a,r_c), optimize over eight local possibilities (r_b,t_ba,t_bc); let c_b(s) be the exact minimum summed pair cost over the whole group and retain a minimizing choice. Encode c_b(s) copies of the 2-clause excluding s in the meta assignment; exactly one such word is realized so the contribution is exact. Since b occurs nowhere else, argmin choices reconstruct simultaneously for every b. Other regions use A. This solves all jointly permitted shears to maximal-signature anchors and all signs, including two-anchor b, without a free affine/meta-SAT oracle. An optimum of the meta formula equals optimum in the prescribed shear family, both directions. Cost multiplicities O(number of regions); replace duplicate binary occurrences (a OR b) by (a OR z),(NOT z OR b) with fresh z if needed, preserving min violation cost. Constants handled as offsets.
