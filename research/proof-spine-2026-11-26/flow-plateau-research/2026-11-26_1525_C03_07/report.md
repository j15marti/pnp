## Track A: cap construction and forced closure

Each nonempty proper pole support contains >=2 types: start a two-color alternating path at port 0, choose another boundary color (arbitrary different color for type 0), follow until another port, interchange the two colors. All four ports in those two colors, so type changes. This is classical Chladny–Skoviera (2010), Prop 3.4 context.
For each pair {0,i} use Petersen four-pole Q (remove adjacent vertices) with equality couples of i. For each pair {j,k} not containing 0 use adjacent new cubic vertices, grouping ports according to the omitted nonzero type i. Exact proper support of the latter follows since the new edge equals XOR of either port pair. ## Track B: adaptive joint compatibility, not marginal equality
Let S (small) and L (large) be attainable proper orbit supports. For ordinary three-probe acquisition on S (when clean or crossing): query pair {0,1}; if NO query {2,3}, either empty or exactly {2,3}. If first YES gives t, query any pair omitting t. NO implies exact complementary pair; YES gives distinct u, query remaining pair; NO gives exact {t,u}, YES gives three actual witnesses. In the exact-pair cases a Kempe exchange from one witness supplies the other. All probes initialize with <=1 zero because S is clean or crossing. If defect is inside L, c belongs to S, so exact acquired pair contains c; if >=3 witnesses choose square whose support contains c. If crossing, any cap works. On large side use exact pair cap or square. For exact pair, the query is equivalent to intersection. For >=3 witnessed types, every nonempty L meets both the square support and witnessed triple; if returned type misses the stored triple, a single Kempe exchange yields a different type which belongs to the triple. Align one global label permutation, remove caps and glue. Every returned witness is verified.
If defect is strictly inside S, L is initially proper with known type c. Query S with the three pairs {c,i}, i != c. All caps accept c without internal zeros. Any reply c gives immediate glue with the initial L witness. Otherwise each query reports NO or the distinct type i. If c is not attainable, these replies give exact S. If c is attainable but never returned, every i must be attainable (otherwise its pair forces c), so three actual witnesses suffice. Empty S is sound; any nonempty support has >=2 types. Exact two-type support is queried on L with corresponding pair cap (possibly one newly introduced internal zero, since L was proper). For three witnesses use any square; it can be chosen to contain c. In all cases at most three smaller queries and one larger query, no hidden exact support oracle, no need to solve an arbitrary guarded subproblem. Exact NO replies mean uniform clock exhausted with NO verified witness under the assumed SAT-side guarantee, NOT an experimental cap failure.
Source graph proper iff one shared orbit, not independent marginal choices. This is existential, not a claim that square relaxation preserves full boundary relation or arbitrary guards. No direction-only plateau claim.

## Global tariff / exact reduction
At a 4-bond with even smaller side s>=10, n>=2s, each small capped child has <=s+8 vertices, single large child <=n-s+8. Both strictly smaller. Integer potential n^40 pays all four branches:
n^40-(n-s+8)^40 >= (s-8)n^39;
3(s+8)^40/[(s-8)n^39] <=27*(0.9)^39 <1,
since (s+8)/(s-8)<=9 and (s+8)/n<=0.9. Thus 3(s+8)^40+(n-s+8)^40 <=n^40-1. Two/three-cut cases from FP26 likewise satisfy exponent 40 by smaller cap sizes, strict decrease (or constant terminals); disconnected splits sum powers strictly below parent, and bridges reject. Enumerate edge sets of size <=4, verify bonds by traversal, O(n^5) graph operations per node, no free separator. Each node uses only polynomial bit work in original N, IDs renumbered and maps retained. There are at most n^40 nodes even without caching; fixed polynomial leaf tariffs remain polynomial in original encoded bit length. Sequential traversal charges all failed calls, cap construction, source authentication, witness verification and lifting, closure, indices, sharing and recomputation. Peak space polynomial on same conditional execution, cumulative memory <=time*peak. Counts in audit are not bit operations; reference searches exponential. Balanced cuts would yield a geometric series but not required. Small sides 4/6/8 are not covered by this strict recurrence, because Q can add eight vertices. No universal terminal solver.

Independent source reduction (no reliance on FP23 high-girth theorem): Given arbitrary simple cubic G, create two copies of each vertex with three parallel seams between the copies, one for each original incidence, initially properly labeled 1,2,3. For each original edge uv, replace its two incidence seams by Q with equality couples joining u_A to v_A and u_B to v_B. The old seam labels p,q give Q boundary (p,q,p,q); above table extends with zero if p=q, otherwise exactly one internal zero. All other edges retain previous verified proper coloring. At stage k colorability is equivalent to a proper partial edge coloring of G on its first k edges: restrict to copy A using equality couples, or extend any partial coloring to distinct local colors at free incidences and duplicate on B. At final stage iff G colorable. There are 3n/2 activations, <=14n vertices, polynomial explicit encoding. Under uniform leaf singleton repair guarantee, use the decomposition reduction and verified polynomial clock at each activation, reject on missing witness. Every YES source passes all stages, every NO cannot supply a final witness. Initial intermediate multigraphs and disconnected stages are permitted by reduction; leaf promise simple. Conversely P=NP gives polynomial witness search by standard NP self-reduction. Therefore uniform singleton repair on the stated leaf class iff P=NP (conditional algorithm equivalence, not a claim of membership or separation).
