# C03-02 / FP22: unguarded optimal-face escape is NP-complete
2026-11-26 Pacific. Status: PROVED WITH SCOPE (mathematical derivation and two independently implemented finite audits; independent human/peer review pending). No conclusion about unrestricted P versus NP.

## Claim and model
Let G be a simple connected cubic graph supplied with a proper 3-edge-coloring and binary incidence matrix D (or its explicit edge list), and binary flows a,b in ker D with Psi(a,b)=1. The problem is whether there exists x in ker D with Psi(a,x)<=1 and x extendible to a nowhere-zero binary flow pair. This is fixed-first-direction, at-most-two-move escape, not unrestricted H_1 reachability. The problem is NP-complete even with all of these additional promises: a has precisely two isolated vertices s,t, joined by st; its other components are even cycles of length at most 160; the unique optimal defect set for a is {st}; every optimal partner is a spanning 2-factor; no affine or other external guards. The source coloring is available even on chart NO instances. Reject malformed inputs by polynomial checks. A witness x plus its companion is polynomially verifiable. This is a strengthening of C03-01's externally guarded square-switch obstruction. It does not prove that a choice among all three directions is hard, nor that unrestricted coloring on these source graphs is hard.

Falsifiers tested: (1) synchronization splicing changes either logical routing phase; (2) a NO formula nevertheless has an extendible optimal partner; (3) a NO chart is actually an uncolorable or noncubic source; (4) bounded occurrence fails to bound the cycle lengths. The proof addresses all four, with finite checks as described below.

## Exact fixed-projection optimization, rederived
Let F be the complement of support(a), and Q the multigraph obtained by contracting each component of support(a), including isolated vertices. An exact defect set Z subset F requires x|F to be the indicator of F minus Z. The necessary and sufficient condition for the remaining incidence equations inside each component to be soluble is even total boundary incidence on that component (the image of a connected binary incidence matrix is the even-parity space, by a spanning-tree lift). Thus the odd boundary of Z must be the set T of odd-degree quotient vertices. Loops count twice. Conversely lift by spanning-tree incidence elimination and add arbitrary cycles inside components. Minimum-cardinality T-join is polynomial by shortest-path distances and minimum-weight perfect matching of T in each connected component: any T-join decomposes into paired terminal paths and cycles, and XOR of shortest paired paths gives a feasible join no larger than the matching cost. No matching oracle is supplied for free; this is the ordinary polynomial weighted matching algorithm. In a cubic graph the a-support components are cycles or isolates. In our construction T={s,t}; only st joins those two singleton components. Consequently min Psi=1, unique Z={st}; outside-a x bits are forced to 1 except st=0. At every cycle vertex x must choose exactly one of its two cycle edges. Each even cycle gives one unconstrained phase bit and all combinations conserve x. At s,t both other edges are selected. All these x are spanning 2-factors. This unconditional closure is acquired directly, with no hidden residual guards.

## Source-authenticated reduction
Input a 3-CNF F, m>=1 clauses, three literal slots each (repetition allowed). Use ordinary 3SAT NP-completeness. Use r=m+4 tracks, 0,1,2,3 plus one private failure track f_j=4+j for each zero-indexed clause. A gate on two tracks is either straight or transposed. For clause j, apply controlled swaps (0,1),(1,2),(2,3) in order, each when its literal is false; then a fixed transposition (3,f_j); then the reverse three controlled swaps. The token entering on 0 reaches 3 iff all three literals are false. If clause satisfied, the fixed swap does not touch that token, and reversal returns it to 0. Otherwise token enters f_j permanently; no subsequent clause touches f_j. Thus the full permutation P satisfies P(0)=0 iff F is satisfied. Prefix two copies of each adjacent gate (i,i+1), i=0,...,r-2, with one fresh common phase bit per pair. Their permutation is identity for either bit, but the prefix connects all physical tracks and gives each track an input/output. One network has 6m+2(m+3)=8m+6 actual gates; central fixed transpositions are direct cross-wiring, not phase gates.

### Physical phase synchronization
Each actual gate is a ten-vertex patch labeled 0,...,9, with cycle edges in cyclic order except 4-5, and additional auxiliary wires (4,7),(5,8),(6,9). Signal inputs are vertices 0,2 and outputs 1,3. Temporarily restore 4-5. Phase 0 selects even-starting cycle edges, phase 1 odd-starting. With all auxiliary wires selected, phase 0 pairs signals (0,1),(2,3), leaving the six auxiliary vertices in a closed cycle; phase 1 pairs (1,2),(3,0) through auxiliary wires. For each variable's occurrences (forward, reverse, both copies), and separately each prefix pair's occurrences (both copies), remove 4_i-5_i and connect 5_i to 4_next cyclically. The resulting one a-cycle has length 10 times its number of occurrences; the 9-edge paths in each patch are joined end-to-end. Phase 0 now reconnects auxiliary loops across patches, without changing signal pairings. Phase 1 does not select any splice edge, so its signal pairings also unchanged. Native cycle conservation, not external guards, now synchronizes the repeated gates. Label gate ports so phase 0 crosses for a positive literal and is straight for a negative literal; phase 1 does the opposite. Prefix gates phase 0 straight. For gates touching track 0 with phase 0 crossing, assign track 0 to input vertex 2 and output vertex 1; if phase 0 straight, assign it input 0 and output 1. This port order is used for the unconditional coloring certificate below.

Make two copies of the same network. Cross-wiring at fixed transpositions exchanges track continuation labels. Splice variable cycles across BOTH copies, hence both realize precisely P. Connect corresponding input ports across copies for every nonzero track, and corresponding output ports for every nonzero track. Attach new s to both input-0 ports and t to both output-0 ports, and add st. All signal wiring and auxiliary wires belong to complement of a, with st also outside a. Set b=1 on all these edges except st, and choose phase 0 on each a-cycle. The graph is cubic by degree inspection: signal vertices have two a edges plus one signal wire, auxiliary vertices two a edges plus one auxiliary wire; s,t degree 3. No loops or duplicate edges: splices use distinct patch ports, auxiliary wires are distinct from cycle edges, and all signal wires join distinct gates/copies or new vertices. Each prefix adjacent gate links two physical tracks by its cycle path, so each network is connected; all later gates attach along its tracks and the terminal closures connect copies. In particular the graph is simple connected cubic, with n=20(8m+6)+2=160m+122 vertices. Every optimal b' has the phases just described.

### Source colorability independent of F

Within each patch the signal-port colors (0,1,2,3) are one of the five rows below, with both splice ends color 3. In internal edge order (0,1),(1,2),(2,3),(3,4),(5,6),(6,7),(7,8),(8,9),(9,0),(4,7),(5,8),(6,9), use:

Direct vertex checks give 1,2,3 at every patch vertex. Thus even chart NO graphs have an explicitly computable proper coloring. The coloring need not extend the fixed a or an optimal partner.

### Exact equivalence
The b'-factor follows input i in one copy to output P(i), then backward through the corresponding path in the duplicate copy to input i. The closures at i=0 and at output 0 contain s and t respectively. Hence s and t lie on the same b'-cycle iff P(0)=0. All other components include auxiliary loops only or unmarked closed routing paths. For any b'-cycle, mark each edge by a-bit. At every vertex except s,t the two selected b'-edges have distinct a bits; at s,t they have equal bits. The number of changes around a cycle is even. Therefore the cycle length modulo 2 equals its number of marked endpoints modulo 2. The entire factor is even iff s,t share a cycle. A spanning even 2-factor extends to a proper coloring by alternating colors 1,2 along each cycle and giving its complement color 3; conversely a binary projection of a nowhere-zero pair in a cubic graph is precisely such a factor. This proves F satisfiable iff an optimal partner extends. Witness lift is explicit in either direction. Equivalently, for rho(a)=min{Psi(a,x): x is an extendible projection}, rho(a)<=1 iff F satisfiable. Since a has isolates, it is not itself extendible; the at-most-two substantive moves retaining a first are (a,b)->(a,x)->(x,y), including color relabeling. Retaining a+x instead makes no difference because Psi(a,x)=Psi(a,a+x). No result for all directions or arbitrary path length follows.

### Bounded occurrence
For each original variable with k occurrences, replace them with distinct clones u_1,...,u_k. For k>=2 add cyclic implications (not u_i OR u_next OR u_next). Every clone appears in one original slot, one negative implication slot and two positive implication slots, at most four slots. The implications enforce equality of the clones, preserving satisfiability. m'<=4m. Each literal slot yields two gates per copy and two copies, so at most sixteen ten-vertex patches in one a-cycle; length <=160. Each prefix bit uses four patches, length 40. This proves the promised bounded-cycle NP-completeness for explicitly constructed graphs, with no input guards.

## Cooperative interpretation and resource ledger
Methods A and B on identical graph/guard (empty): exact quotient T-join plus physical routing, and direct 2-factor verification by independent XOR edge-color propagation. Adversarial NO/SAT neighbors retain source YES and min T-join 1. Constant patch coloring is an independent source-color bypass. The two distinct labels must not be conflated.
Input relabeling/occurrence splitting, gate creation, splices, explicit graph/flows and certificate require polynomial bit work and output O(m log(m+2)) bits after relabeling; even straightforward sorting/search gives fixed polynomial overhead in the input length. In source length N, validate degrees, conservation, proper coloring, connectedness, component lengths and unique quotient edge in polynomial time. Conditional phase verification, endpoint walk, parity propagation and reconstruction require O(|E|) graph operations with O(log N)-bit indices; conservative polynomial bit complexity. No external oracle, counting, exponential hidden preprocessing, failed-track search or canonicalization is used in reduction. Full exhaustive phase search has 2^q trials, each polynomial, polynomial live storage for sequential enumeration, cumulative memory upper bounded by work times peak storage. No polynomial total-work upper bound is established for that search; no peak RSS measurement was made. A uniform polynomial SAT-side search with verified witness and fixed cap for this promise would imply P=NP by this reduction, since the cap handles NO; it is not established. No DISJ/lower-bound transfer: restricted chart NO is not source NO, as explicit witness shows. Relativization, algebrization, Natural Proofs, simultaneous-DTISP and deterministic-configuration exclusion: not used/not established; no arbitrary machine lower bound.
