## Theorem: integer energy lower bound from overlapping cores
Let F_i >=0 be even integer costs on an exactly authenticated chart, each with distinct original B owners. Under guard G, each verified zero-infeasible core C_j gives sum_{i in C_j} I[F_i>0] >=1. Take k such cores, and define a_i as the number containing i. Summation gives k <= sum_i a_i I[F_i>0]. For every nonzero, guard-compatible row of every factor, compute rho=max(2 a_i/F_i), with exact rational comparison. Then k <= rho E/2 and E >= 2 ceil(k/rho), where E=sum_i F_i. If rho=0 and k>0, no assignment can satisfy the hard guard. No disjointness assumption on core scopes; overlap is accounted for by a_i, not ignored. For a single-defect threshold, if every factor with a compatible cost-two row is excluded from at least one core, rho<=max(k-1,k/2)<k when k>=2, implying E>=4. For k=1 the same result holds if its core has no cost-two row (rho<=1/2). This is a weighted core-packing / integer-rounding certificate, not a new unrestricted proof system. It generalizes to rational nonnegative core weights by exact arithmetic and to any certified core lower bounds. Cannot sum core bounds naively if they share owner factors. Greedy coverage selects a finite list; not a guaranteed minimum list or polynomial acquisition of the cores.

Complementary separator lane: partition each variable's incident cost factors into bounded-union groups. Replace each group by its exact min over the eliminated bit of the sum of its costs. The sum of separate minima <= minimum of the sum. Every input factor consumed once; hence resulting constant is a lower bound, not necessarily an equivalent residual. Independent replay enumerates all assignments of each group, verifies owner partition, and reconstructs the minima. If no split occurs it is exact. This is mini-bucket elimination (Dechter/Rish, 2003), not a new completeness claim. For fixed width w, polynomial discovery and replay using explicit tables, O(m n poly(m,n,w) 2^w) is a loose bound; integer bit lengths O(log total original cost). At each elimination number of groups <= removed factor count, so live factor count never grows; cumulative generated factors <= nm. With w=O(log N) and uniformly constructed order still polynomial. A greedy width schedule is NOT nested: a larger cap can choose a different partition or elimination order, so lower bounds need not improve. Retain max of individually checked bounds. A coherent relaxation with nested equality restoration is monotone but can end at unrestricted width. The load-bearing acquisition remains OPEN.
