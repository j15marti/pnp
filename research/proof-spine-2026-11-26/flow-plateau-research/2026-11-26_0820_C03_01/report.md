## Named obligation and exact source
Input explicit simple cubic G with vertex/edge IDs, binary incidence D, a,b in ker D and a fixed zero set Z={e:a_e=b_e=0}, and explicit signed equality/unary guards on support(a) cycle toggles. A phase word x gives b'=b+sum x_i C_i; seek b' extendible to a nowhere-zero binary pair, with same fixed a and Z. This is chart decision, NOT source decision. Guards are on original identified cycle bits; changing base b shifts RHS, not solution set. Standard deterministic bit model, N includes explicit G, flows, guard rows. Falsifiers: (1) source malformed or uncolorable without guards; (2) phase word not conserving or defect not exactly one; (3) a SAT assignment failing to extend or NO guard producing a coloring; (4) inability to lift source conservation across protected seam. All addressed below and finite tests. Claim: guarded chart decision NP-complete even on connected colorable cubic source with Z singleton, all support(a) components squares or two isolates, minimum T-join 1, and guard matrix rows of weight <=2, only signed equality/pins. This does NOT show P!=NP; the unguarded source has an explicit easy coloring.

## Reaudit fixed-direction and parity
Contract components of support(a) (include isolates) into multigraph Q of complement edges; loops are allowed and contribute twice to degree. Let F be complement of support(a). For any defect set Z subset F, b on F is 1 on F minus Z. Internal binary incidence system for b on support(a) is consistent precisely when RHS sums to zero on each support component, i.e. boundary_Q(F minus Z)=0, equivalently boundary_Q Z=T=odd degree vertices of Q. Component spanning-tree elimination lifts; kernel basis consists of cycles in cubic support(a) because degree 0 or 2. Minimum cardinality T-join from shortest path distances and minimum perfect matching on T within connected quotient components; a T-join decomposes into terminal paths and cycles; matching shortest paths yields XOR with no greater size. Loops never improve nonnegative min cost. Disconnected parity tested; polynomial acquisition and lift, not proper-source solution.
For singleton Z=st and b' spanning 2-factor, at nondefect vertices the two b' edges have different a bits (a degree2 and exactly one b' edge in overlap); at s,t they have same a bits (including a degree0 case). Hence along a b' cycle the number of changes in a-bit is even, so cycle length parity equals number of marked endpoints on it modulo2. All cycles even iff s,t share cycle. b' extends iff spanning even factor (zero edges forced color 2; alternate 1 and 3 on each cycle). This also gives an independent direct local color/XOR solver for a supplied phase word.

## New reduction: reversible clause routing with affine guards
Let 3-CNF F have m>=1 clauses, exactly 3 literals each (repetition allowed); remove unused variables. Tracks are 0,1,2,3 and distinct failure tracks 4..m+3. Gate (i,j) has binary straight/cross choice. For each clause C_j with literals l1,l2,l3, perform gates (0,1),(1,2),(2,3), each crosses iff its corresponding literal is false. Then pinned crossing (3,4+j), with j=0-based, then reverse the first three gates using the same bits. This is a conjugated transposition. The token starting on 0 reaches 3 before central gate iff all three literals false; otherwise reverse restores it to 0. If all false it lands on private failure track 4+j. A failure token never touched by any later gate. Consequently total permutation P has P(0)=0 iff F true. Prefix r-1 adjacent gate chain (0,1)...(r-2,r-1) pinned straight ensures all tracks physically connected, with no effect on P. Total gates g=7m+(m+3)=8m+3, r=m+4. No Barrington or counting oracle.

Build TWO copies of this network with matching phase words. Each gate is square K2,2 with distinct input vertices u,v and output vertices w,z; support(a) contains the four edges uw,vz,uz,vw. b chooses straight uw,vz or cross uz,vw; all inter-gate wires b=1,a=0. Connect consecutive occurrences on each track output to next input, even skipping gates not using the track. All first/last endpoints exist by prefix. For each nonzero track, pair the two copies' input ports by a wire and their output ports by a wire. Attach new vertex s to both input-0 ports, t to both output-0 ports, and edge st with a=b=0. At s,t a degree0 and b degree2. At every gate vertex a,b both degree2. All non-a edges except st have b=1. Each port used exactly once outside square, no duplicate edge or loop; no within-square wiring. Prefix touches neighboring tracks, each track chain physically connected, both copies connected through closure, so simple connected cubic. n=8g+2=64m+26, |E|=3n/2. a quotient T={s,t}, edge st proves min T-join 1 (0 impossible). All b' span, every phase word sole defect. Actual b reference can be all straight, or compute any guard-compatible phase word by all input bits 0 and rebase XOR guards; no SAT oracle needed.
For each input variable choose a chain linking all signed occurrences across both copies, including reversed gates, with equality or disequality RHS. Pin central gates of first copy to 1 and padding to 0; link second-copy fixed gates by equality. These rows are independent forest equations plus pins, each row weight<=2, satisfiable and exactly one freely chosen bit per used input variable. No higher-order guard rows. Initial exact closure computes all pins, signed classes and shifts via Gaussian elimination or parity union-find, no guard lost. Subsequent full guard closure alone cannot answer arbitrary 3SAT; local path queries do not commute with independent marginalization.

Under any guard-consistent word both copies have SAME permutation P. Every input track i follows its own path to output P(i), then the corresponding path backward through the duplicate; the exterior closures close it into one circuit, with s on circuit i=0 and t on circuit i=P^{-1}(0). Thus s,t share a b'-cycle iff P(0)=0 iff F true. Endpoint lemma gives forward source coloring lift by alternating colors on cycles; reverse extracts input bits from guard occurrence classes and checks each clause. Every unguarded graph is colorable: all-straight phases make P identity in both copies, even factor, proper witness. NP membership verify supplied x and coloring, polynomial. Exact source graph/guard pair hardness is therefore proved without claiming P!=NP or universal arbitrary guards are reachable from unguarded source. Even a source SAT certificate is insufficient to decide this guarded chart. Guard-only NO never becomes source NO unless independently discharged.

Two copies of core, replace every edge except z by one chain of L four-poles connecting its two corresponding virtual edges in parallel: ports first pair for core1, second for core2, serial seams. n=24+136L. Proper target from core proper words and local Q lifts. Initial core1 defect z and core2 proper; each protected chain colored by legal nonzero boundary relation. All states at defect<=1 project to conserved core flows: at most one chain can contain a zero edge (including seams). All other chains enforce equal colors at each core's two endpoints of its virtual edge. At the affected chain, summing conservation over ALL vertices of each core forces equality there too (all other seam contributions cancel, z internal cancels). Thus each chain's seam ends at each core have equal full two-bit colors, even if some internal module defective. Since zero at any such seam would require two distinct seam edges zero, no seam can be zero. Therefore all virtual protected edges in both cores nonzero. If sole defect is not core1's z, core1 is proper. A move retaining any of a,b,a+b retains that direction in projected core, so projection remains in protected component of initial core1, which contains no proper state. Contradiction. This proves universal nonincreasing escape FALSIFIED on arbitrary simple colorable cubic graphs, even at defect one, regardless of acquisition cost. It also implies any direction-only algorithm confined to r=1 cannot succeed on these YES graphs. Unrestricted solver may change multiple directions or increase budget; no lower bound on such solver. No arbitrary-girth or all-L cyclic4 claim made here. General source lift proof only requires cubic/simple and equality four-pole. High girth adversarial requirement beyond these controls remains open. This is an independent reconstruction of FP04, not a novel proof of P!=NP.
