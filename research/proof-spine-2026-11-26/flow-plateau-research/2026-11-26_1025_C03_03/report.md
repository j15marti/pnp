# C03-03 / FP23: singleton-repair completeness by incremental edge activation
2026-11-26 Pacific. PROVED WITH SCOPE, independent mathematical peer review requested. P versus NP OPEN.

## Claim
Let SINGLE-REPAIR be the search obligation: on every explicitly encoded connected simple cubic graph G of girth at least five and supplied conserved F2^2 flow f with exactly one zero edge, if G is 3-edge-colorable then return a nowhere-zero flow in a fixed polynomial time in its original input bits; no output or correctness obligation on NO other than the caller checking the witness. No guards, no prescribed direction, no planted coloring. The existence of a uniform deterministic algorithm satisfying SINGLE-REPAIR is equivalent to P=NP. This is a polynomial adaptive search reduction, NOT a many-one NP-hardness theorem for the associated decision promise problem. This removes the gap between fixed-face hardness and unrestricted singleton repair as a sufficient constructive target. It is not an unconditional runtime lower bound.

## Source compiler and exact stage semantics
Source arbitrary simple cubic graph G=(V,E), n vertices m=3n/2 edges, label edges and three incident port IDs. For each vertex make two copies A,B of the same 3-pole H: Heawood minus a left vertex L0. Heawood edges L_i R_(i+d) for i mod7, d in {0,1,3}. Ports R0,R1,R3; color edges by d (three distinct nonzero values). Each pole has 13 vertices, all legal proper boundary triples are precisely the six distinct-color permutations: XOR cut law and relabeling. The difference set has all six nonzero differences once, so girth >=6 and port distances >=4. No internal edge shared between copies.

At stage k activate first k original edges. For unactivated e=uv connect corresponding ports of u across A,B by one seam, and likewise v across A,B by another seam. For activated e remove those two seams and insert the eight-vertex Petersen four-pole with its first pair of ports connected to u_A,v_A and second pair to u_B,v_B. All port IDs explicit. H_k has 26n+8k <=38n vertices, simple cubic, girth >=5: local poles have girth >=5; any cycle crossing poles uses at least two seam edges and at least two internal paths between distinct ports, each of length >=2 (the Petersen ports are pairwise nonadjacent), hence length >=6. Components correspond exactly to components of the activated original partial graph, since each duplicated vertex is linked through unactivated seams or activated connected four-poles. For isolated original vertices the three unactivated seams suffice. Connectivity of every component is not needed beyond invoking repair only in the component containing the unique zero.

Exact semantics: H_k is colorable iff original subgraph with first k edges has a proper partial edge coloring (unused port incidences free). Forward: read the A-copy boundary triple, distinct by cut conservation; each activated edge has equal A-side colors by four-pole relation. Reverse: assign distinct unused colors to unused incidences at each vertex, choose the same boundary permutation in both copies, glue each free seam, and use four-pole certificate for the activated edge (all four colors identical). H_0 has explicit coloring; if G YES all stages YES; H_m YES iff G YES.

## Incremental constructive repair
Maintain verified proper coloring of H_k, not necessarily symmetric across copies on activated edges. At activation, the two removed free seams had colors p,q. Attach four replacement boundary edges with colors (p,q,p,q). All old vertex equations unchanged. If p=q the constant four-pole table gives proper H_(k+1). Otherwise the crossed witness gives exactly one zero edge, in the new four-pole. All other components remain properly colored. Restrict to the connected component of the zero edge; authenticate source degrees, edge IDs, binary conservation, zero count. Invoke SINGLE-REPAIR under its one fixed cap and check returned coloring directly. If failure, reject; if success, merge unchanged components and continue. For a YES original all stages and queried components are YES, so failure cannot occur. For any NO original, no execution can return a valid final witness, and accepting only verified witnesses is sound; a timeout is a valid NO decision under the assumed uniform YES-side guarantee. At most m calls. Recover G's coloring from A-side ports. No assumption that each prior graph has arbitrary repair path or that guards persist across activations.

Contradiction form: if P!=NP no fixed uniform polynomial cap can succeed on every colorable connected simple girth-five cubic singleton state, since this would yield the above ordinary Holyer decider. Conversely if P=NP, use prefix-pinned 3-edge-colorability NP queries to obtain a witness by polynomial self-reduction. This is a genuine equivalence, not an unconditional separation. It applies to arbitrary nonlocal simultaneous direction changes, unlike C03-02 fixed-first-direction hardness. At deficiency one any strict productive potential decrease is zero. No universal H_1 connectivity assertion made; old FP04 trap remains a separate scoped obstruction.
