# C03-04 / FP24: Defect-preserving logarithmic-girth amplification

## Claim, model and falsifiers
Explicit simple cubic source G, binary incidence D authenticated by edge IDs, f=(a,b) in ker(D)^2 with exactly one zero edge st; no external guards. For every fixed rational 0<alpha<1, a deterministic polynomial-time map to G' with girth >= alpha log2 |V(G')| preserves a singleton conserved initialization, source colorability in both directions, and has a linear restriction pi from the new cycle space onto the old one. For every pair (x,y), Psi_G(pi x,pi y)<=Psi_G'(x,y); fixing any of x,y,x+y projects to fixing the corresponding old direction, up to the same GL(2,2) global color relabeling. In particular a direction-only plateau trap remains a trap. This is one-way path projection, NOT unrestricted continuation equivalence or a claim of equal optimal-face partners. Connectedness is preserved componentwise. Cyclic four-edge-connectivity is NOT preserved (three-edge cuts).
Falsifiers: (1) same-matching switch creates a cycle no longer than current shortest; (2) singleton lift introduces extra zero; (3) proper target projects to an invalid coloring or move changes all old directions; (4) size exponential in n rather than in chosen g=O(log n). Addressed below.

## A. Deterministic colored high-girth bipartite pole
For integer g>=4 let M=2^(g+1). Start a bipartite multigraph with M vertices on each side and three parallel perfect matchings (one edge of each color at each vertex). Track edge IDs. Treat parallel pair as a 2-cycle. For even l=2,4,...<g, while a cycle of length l exists, choose an edge uv on one, u on left. Find left x at distance >l from {u,v}; let xy be its edge in the same color as uv. Such x exists: union radius-l ball from the adjacent root pair has size at most 2+4*(2^l-1)<4*2^l<=M (since l<=g-1). The first layer has at most four edges leaving the root pair, each following vertex at most two fresh neighbors. y has distance >=l. Delete uv,xy and insert uy,xv, retaining color and edge IDs. A new cycle with one new edge needs a path crossing old endpoint groups, length >=l; adding new edge gives >l. A cycle with both new edges has either two cross-group paths (each >=l) or an old u-v path and old x-y path (each >=l-1 because prior girth >=l, deleted edges excluded). Total length >=2l>l. Thus no new cycle of length <=l, at least one old l-cycle removed. Initial number of l-cycles <= O(M*2^l) by bounded-degree walk enumeration. Induction by l terminates. For g>=4 final graph simple, cubic, and bipartite with explicit proper 3-edge-coloring, no cycles shorter than g. Take component containing left vertex 0, size B<=2M=2^(g+2). Every edge lies on a two-color cycle, hence no bridges; in cubic graph a cut vertex would force a bridge. Delete 0: connected 3-pole P_g, with three distinct ports, distance between each pair >=g-2 (a shorter path plus deleted vertex gives short cycle). Its proper boundary support is exactly all six distinct nonzero triples: XOR cut equation forces distinct, and color permutations of the stored coloring lift all six.

## B. Exact defect and coloring preservation
Leave st endpoints unexpanded. Replace every other vertex v by fresh copy of P_g, assigning each original incidence to a distinct port (fixed order independent of its color). Join corresponding original edge IDs by seams. New n' = 2+(n-2)(B-1)<=n*2^(g+2). Graph simple cubic and original components correspond to expanded ones. Every internal cycle has length >=g. Any simple cycle crossing seams visits at least one pole because the only unexpanded vertices are s,t with at most one edge between them; a segment through that pole joins distinct ports and uses >=g-2 edges, plus at least two seam edges, so length>=g. At every expanded vertex initial colors distinct and nonzero since it is not incident to sole zero. Permute local stored coloring to match its three seam colors. This yields no internal zero, exactly one zero (original seam st). Same fixed graph admits extension of ANY proper original coloring, including one different from initialization. Conversely restriction of any proper coloring to seams is proper by XOR cut equation. This is not a planted-coloring reduction: the supplied near flow suffices to construct, target proper coloring need not be known.

## C. Linear retraction and plateau transfer
For every binary flow on expanded graph, sum its vertex conservation equations within each pole. Internal edges cancel, so seam restriction pi is a binary cycle-space flow on original graph. pi is linear and surjective: for any old binary flow, boundary values have XOR zero, hence internal demands even; solve on a spanning tree of each connected pole. This affine lift may introduce internal zeroes when applied to two arbitrary binary flows; do not assume equal costs or forward plateau lift. For any pair, zero seam count equals original projected Psi and cannot exceed full Psi. A move fixing x,y,x+y or globally relabeling colors therefore projects to a legal move (or identity) with Psi<=r whenever the full pair is in H_r. If a path from the new initial singleton to a zero-defect state exists at budget 1 then it projects to such a path from the original singleton. For singleton initialization, nonincreasing and budget-1 escape are equivalent since any 0 state is the target. This proves the contrapositive trap transfer. At higher r this establishes budget reachability implication, not necessarily stepwise projected monotonicity. No guard is deleted; seam-only linear guards can be copied but internal guards cannot be erased without a new theorem.

## E. Logarithmic-girth strengthening of FP23
Choose g=max(4,ceil(alpha/(1-alpha)*(log2 n+2))) using integer ceiling upper bounds if desired, e.g. ceil(log2 n) in formula with fixed rational alpha. Then log2 n'<=log2 n+g+2, hence g>=alpha log2 n'. For each fixed alpha<1, g=O(log n), map polynomial. Applying this to every connected singleton query of prior FP23 yields: if there exists one fixed uniform deterministic polynomial-time repair algorithm on all connected simple cubic singleton inputs with girth>=alpha log2 n', whenever colorable, then P=NP. Conversely P=NP gives ordinary prefix self-reduction and verified witness in polynomial time. Reconstruct prior FP23: for each original cubic vertex two Heawood-minus-one-vertex 3-poles with free seams; activate an original edge by replacing two seams of colors p,q with Q whose boundary word is (p,q,p,q). Thus activation adds at most one zero, and partial-stage colorability iff original activated partial edges admit proper coloring. If original YES every stage YES; verify each returned witness, final gives original coloring; under uniform YES cap failed repair rejects soundly. At most 3n/2 sequential calls, component containing zero only. Prior source <=38n vertices before amplification. ## F. Productive scope and forced-information closure
Reaudit fixed projection a: contract connected support components including isolated vertices; outside-support partner b is 1 off defect set Z. Sum demands in each component gives incidence parity of Z equal odd-degree quotient set T, loops twice. Conversely lift demands by spanning tree on each a-component. Minimum |Z| is min T-join; shortest path metric + perfect matching obtains it, no extra guard. This does not impose extendibility.
Constructive alternate terminal: enumerate triples of edges and connected components after deleting them. If a proper connected region with exactly three boundary edges has distinct interior port endpoints and restoring it with one new vertex is cubic bipartite, its exact proper boundary relation is all six distinct nonzero triples. Obtain one coloring by bipartite perfect matching then alternate residual even cycles, use color permutation for any proper triple. Contract region to a vertex with original seam IDs, preserve proper source colorability and all outside guards (no internal guards assumed). If sole zero is internal and seams nonzero, projected coloring is already proper; restore region by this polynomial matching lift and get repair. This is a sound unconditional structural closure, but the amplified trap deliberately leaves the zero at an unexpanded edge. Given construction provenance all P_g copies can be retracted, even though arbitrary greedy contractions need not recover those exact copies. Without provenance, enumeration gives admissible regions in polynomial time, not universal productive coverage. Large girth alone is thus not a tractability condition or a lower bound. No need for cross-source adapter to other CSPs.
