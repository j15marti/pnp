## Exact score and parity construction
For a root Boolean bit x, positive literal value v=x, negated value v=x-1. Satisfied positive =+1, satisfied negative =-1, false=0. Let u=v^2 (truth bit), Q=sum u, D=sum v. Then (Q+D)/2 and (Q-D)/2 count satisfied positive and negative literals respectively. Q is an integer, NOT just parity. Keep each original literal/port ID and actual variable/guard: equal (Q,D) on two partial assignments is not a valid merge if future interfaces differ.
Write e_j for the jth elementary symmetric Boolean polynomial in the truth bits u, over GF(2), so e_j=binom(Q,j) mod 2. For a 3-literal clause, Q in 0..3, SAT iff e1=1 OR e2=1. For a native B4 vertex, Q in 0..4 and exact two iff e1=0 AND e2=1. Proof by count table. The exact 0/1 B-defect indicator, viewed in GF(2), is 1+e2+e3: e1*e2=e3 in the Boolean quotient (terms with repeated variable cancel and each distinct triple occurs 3 times), so e1 OR NOT e2=1+e2+e1*e2. This remains sound when some truth bits coincide under a signed equality map, by substitution. Exhaustively executed 64 signed 3-literal patterns and 256 signed B4 patterns, all matched exact truth/occupancy and signed counts. No degree-four monomial is required for this indicator, but global energy is an integer sum, not merely its mod-two residue. The condition that all clause counts are odd is a sufficient SAT condition, not necessary: (x OR y OR z) AND (!x OR y OR z) is satisfiable with y=1 but the two odd-count equations conflict. No rejection from that artificial restriction.

## Guarded polynomial-core theorem
For each exact cost factor f_i under a hard guard G, take local Boolean polynomial identities p of degree <=d that vanish on every allowed zero-cost table row. Obtain a basis by Gaussian elimination on evaluations of all local monomials of degree <=d. Empty relation admits p=1. Multiply p by squarefree monomials m whose formal degree plus deg(p) <=d. Reduce x_j^2=x_j; treat global monomials as coordinates and use GF(2) row elimination. If constant 1 is in this row span, extract and independently verify 1 = XOR_j m_j*p_j, with each p_j checked on the permitted zero rows. All satisfying assignments evaluate RHS to 0, contradiction. The owner indices of used p_j form a verified zero-infeasible core C under G. For nonnegative even costs and total <=2, the single positive factor must lie in C. If 1 is derived after dropping block D, C is disjoint D. Every candidate support missing C can be excluded, not just D. A failed identity search is UNKNOWN, not a witness. This is a bounded-degree Nullstellensatz-style row-span subprocedure, not full degree-d polynomial-calculus saturation; degrees of generator and multiplier bounded before reduction. It is a standard algebraic proof-system method adapted to native signed score charts and FP53 guarded supports. Signed literal encoding preserves truth; the actual additional power comes from higher-order polynomial identities, not an extra independent physical bit.
For n retained variables, number of columns L_d=sum_{j=0}^d binom(n,j). Fixed d and explicit polynomial-sized local tables give polynomial acquisition of the specified evaluation bases, rows and certificates using standard bit GE. For fixed energy support budget k and guard rank t <= C log N, total live candidate (guard syndrome, support) pairs bounded by 2^t * sum_{j<=k} binom(m,j); productive verified cores decrease this count. This is a conditional screening terminal only. Variable d/k or unrestricted guard rank need a separate bound. No theorem that a useful degree-d identity always exists; no unrestricted lower bound from failure.
