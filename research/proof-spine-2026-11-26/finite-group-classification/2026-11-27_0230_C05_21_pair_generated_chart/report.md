## Theorem 1: exact pair-generated quotient
Let G=(V,E) be an explicit undirected graph, with v vertices; let C=a+D be a nonempty affine binary chart in F2^v of deleted-vertex masks. Ask if some z in C has G[V minus supp(z)] perfectly matchable. Compute a full-rank parity check B with ker B=D by elimination (or use canonical residue mod a basis of D). Let b_i=B e_i. Partition vertices into classes P_b of identical columns b. Let q be the number of distinct NONZERO columns and r=rank B. The span H of all weight-one and weight-two vectors in D consists exactly of unrestricted coordinates in P_0 and even parity vectors in each nonzero class. Indeed e_i is in D iff b_i=0 and e_i+e_j is in D iff b_i=b_j. Each class has an explicit spanning tree basis, so dim H=v-q and d=dim(D/H)=q-r. The actual affine chart partitions into exactly 2^d parity patterns y on nonzero classes: sum_b b*y_b=B a. These are acquired by Gaussian elimination, not supplied. Within one pattern the deleted set is otherwise arbitrary subject to each class parity. If P_0 exists, total deletion parity must equal v mod2, so its parity is fixed by other classes and total parity. If P_0 is empty and required parities disagree with total parity, reject that pattern.

For each pattern form augmented graph: retain original graph edges, add a virtual clique on each nonzero class and the free class (if nonempty); if the required parity of deleted vertices in that class is odd, add one new dummy adjacent only to that class. A perfect matching of the augmented graph exists iff some mask in that parity pattern permits an original perfect matching of its complement. Forward: pair deleted vertices within each class, using its dummy for one deleted vertex if odd, and join with the original matching. Reverse: original vertices matched by virtual edges or dummies are precisely the deleted mask; internal pairing guarantees group parities and the other matching edges cover every undeleted vertex exactly once. If an original edge is also virtual, either typed interpretation is valid; the implementation chooses virtual, which changes deletion in a pair of the same class and preserves parity. Preserve original labels for nonvirtual edges if replaying a projected witness. This is a decision/witness result for the RELAXATION; no multiplicity-preserving count claim.

Using deterministic general perfect matching, acquisition and all 2^d tests cost 2^d poly(N), including Gaussian elimination, graph construction (O(v^2) edges, <=2v vertices), reconstruction, and original-guard checks. No determinant counting or finite field-size enumeration. Memory polynomial if patterns are streamed, cumulative memory <=T*S. With d<=c log2 N for fixed c and a polynomially acquired list of cuts, uniformly polynomial. Unknown if cap exceeded. The raw chart dimension dim D can be linear in N. General matching graph need not be planar even if native G is planar. Only binary charts are treated; previous field-independent cut theorem still valid separately.

## Theorem 2: exact representability boundary, and sparse guards
For nonempty even- or odd-parity affine set of port subsets C, an ordinary matching gadget (internal vertices compulsory, choose subset of ports present) realizes C iff its direction space is generated by weight-two vectors. Necessity: feasible port sets have constant parity; for two feasible subsets P,Q, superimpose actual matchings (common edges cancel), take the alternating path starting at any port in P symmetric difference Q. Its other endpoint is a distinct port in that symmetric difference. Flip the path to obtain a feasible set differing from P by exactly the two endpoints. Thus for each d in D and each i in support(d), there is j in support(d) different from i with e_i+e_j in D. Induct on weight(d) by subtracting this pair; D generated by pairs. Sufficiency: equal-syndrome classes as in theorem 1, no weight-one directions because constant parity; for a pair-generated D, q=r and the parity pattern is unique. Add class cliques and odd dummies, require exact selected-port matching. This is a characterization of affine matching-realizable signatures (not all affine signatures; {0000,1111} fails symmetric exchange). For variable total parity restrict to required parity first, or use the free class rule above. Relation to even delta-matroid edge CSP is explicit; no novelty claim against complete literature.

Sparse conditioning lemma: if we add an independent observation ell*z=beta supported on k>=1 coordinates, use appended column (b_i,ell_i). The number q' of distinct nonzero columns increases by at most k: each old nonzero class can split only when at least one of its members has ell_i=1, and at most one new class arises from P_0. The check rank increases by one. Thus d'<=d+k-1. Dependent observation is either redundant or inconsistent. In particular arbitrary unary pins DO NOT increase d, and any two-coordinate parity guard increases it by at most one. For a fixed sparse guard width and d<=c log N, both values of every candidate guard can be tested within polynomial total work.

## Barrier and next lemma
Generic affine-mask compatibility with unbounded d is NP-complete, even on a disjoint union of planar stars K1,3: represent every 1-in-3 clause by one star, force center undeleted, identify leaf deletion bits as complements of shared literal truth values by affine equality/opposition. Exactly one leaf remains matched to center, exactly one true literal. Conversely matching defines consistent assignment. All constraints on mask are affine, construction polynomial, certificate check polynomial. Generic result is not an adapter proving hardness for native projected-cut images.
