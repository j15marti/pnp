## 3. Exact Hall acquisition and two-view fixed point (PROVED)

An E factor splits into two unary full blocks (p0,p2) and two ternary one-hot blocks: a-owner block requires exactly one true; the remaining b,c,p1 block has three selected pairs iff exactly one true, and admits each such word. This can also be recognized directly from acquired tables. No free relation oracle, no generator metadata in extraction.

## 4. Two tiny partition layers (PROVED, exact quotient, not a new native source promise)
Stronger counterexample to independent forest summaries. From exact A and B with rows <=3 and clauses <=2, make fresh port variable for every original constraint occurrence. Keep each parity row as one affine factor with its own ports. Build for each original mode variable v with d occurrences an equality path of max(1,d-2) affine nodes of arity<=3, each node requiring all its ports equal. Adjacent nodes connected by binary equality on separate ports. Use d external ports; for each original A occurrence connect its parity port to an equality-path port by binary equality; for each original B occurrence use its path port directly in that clause. A variable with no occurrences is an unconstrained unary port. For d>=3, number of free path ports =3(d-2)-2(d-3)=d; d<=2 one node suffices. Every new port belongs to EXACTLY ONE affine factor and EXACTLY ONE binary factor. Each affine component has <=3 variables, each binary component <=2; both factor-incidence views are disjoint stars (forests). Number of ports and edges O(total original occurrences). Affine equality factors are linear equations, binary equality is two 2CNF clauses. No claim about ordinary primal graph forest for the expanded clauses within a component. Both directions are immediate by equality propagation: from original mode word assign all copies equal; from split word recover one value per mode path and parity port equality, hence original clauses. This is a bijection of mode solutions, not of native matching witnesses (many may project to same mode). Guards on old mode bits translate to representative ports. A compiled source guard is retained in the exact relation, not silently discarded. Construction uniform and linear; no target-supplied witness. This is an exact *quotient representation* of authenticated native P3DM, not an assertion that two such partitions exist natively on element-tuple incidence. The conjunction is still NP-hard even with both partition component sizes constant; both separate decompositions and their correct local tables do not give a polynomial joint solve. The union interaction graph is where complexity remains. C07 native EX22 result is analogous but no cross-source transfer asserted.
