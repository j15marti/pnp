## Theorem 1: affine cut fibers of actual packing signatures
For ANY field F (including a supplied large prime field), let U_I=span_F{A_e:e in I} for a subset of tuple IDs. Let J=E minus I. A partial packing selects disjoint tuples in I; its occupancy u is a literal 0/1 vector (NOT an arbitrary field-linear solution). A necessary condition for extension is u in U_I and t-u in U_J. Define C_I=U_I intersect (t-U_J). If nonempty, this is a translate of U_I intersect U_J of dimension w_I=rank A_I+rank A_J-rank A. Any affine space of dimension w has at most 2^w points whose coordinates are all 0/1: select w coordinate functionals independent on its direction space; these coordinates injectively determine a point of the affine space, and have only two choices each. This avoids a p^w penalty even for unbounded primes. Arbitrary extra nonbinary guard coordinates are NOT admitted automatically. Over GF2 this also works with explicit parity guard rows if overlap is checked on the native owner coordinates only; not implemented.

Given any verified binary leaf tree over ORIGINAL tuple IDs, at each node I retain an exact table T_I(u) of counts of disjoint partial packings with actual occupancy u in C_I. Leaves: choose tuple or not, filter against complement span. At a join I=L disjoint-union R, iterate child words u,v, require bitwise u AND v=0, set s=u OR v and test s in C_I; add T_L(u)T_R(v) to T_I(s). Necessity of child filter even for a parent state without an actual completion: if t-s is in U_(E\I), then t-u=v+(t-s) is in U_(E\L); similarly right. Thus inductively each admitted parent count exact, no lost valid packings. Disjointness cannot be replaced by XOR without overlap check. At root complement span={0}, so T_E(t) is exact original guarded cover count; zero certifies NO. For decision store booleans and original-ID backpointers instead; verification can replay tables, complement bases and each join. No multiplicity-preserving claim for previous period quotients. Optional sound contextual rejection (matchings/LP) retains all full solutions but changes intermediate table semantics to counts of surviving histories, still exact root. Reapply forced-information closure to native residual after any unconditional deletion; guard-specific complement deductions stay local. All imports this run terminal NO or local filtering.

If width w=max w_I, at most 2^w actual states per cut, no enumeration of the full affine space, 4^w child pairs per join. Polynomial work for Gaussian ranks/bases, input and tree validation, state operations, and O(m)-bit exact counts (at most 2^m subsets). O(m*4^w*poly(N,log p)) deterministic bit-time including preprocessing for supplied prime p (or fixed p); polynomial for w<=c log2 N and log p polynomial in N. Store original occupancy words, exact counts, backpointers and cut bases; O(m*2^w*poly(N,log p)) peak, cumulative <=T*S. For a path with one tuple per step, only two extensions per state, 2^w*poly. This is an exact finite group/matroid cut hybrid, valid even without planarity. Width bounded by number of shared owners but can be much smaller.
