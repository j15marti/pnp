## Theorem A: exact one-bit guard characterization
For any attained set S subset F2^n of projected matching responses, target t and necessary guard H p=Ht, use the *actual* nonempty guarded response set, also with any specified tuple e pinned by removing projection competitors. A row h excludes all of this set at the target bit iff h is constant on S with opposite target bit. Equivalently, there exists such an h iff t is outside aff(S). Proof: fix p0 in S, D=span{p+p0:p in S}. A row h is a separator exactly when h annihilates D and h(t+p0)=1. Conversely if t in p0+D, any linear form constant on S also takes that constant at t; a nonconstant binary form takes BOTH values on S. Empty S separately certifies exclusion. Thus exact affine hull, though not exact support, is precisely the sufficient statistic for *all* possible one-row refutations of a fiber. No assertion that target in hull is actual feasibility. The converse is binary-specific; F3 support {0,1} has full affine hull but row target 2 unattained (abstract illustration).

## Theorem B: determinant-free complete acquisition at guard rank zero

Acquire using one matching M0 and SCCs of the directed graph of alternatives after contracting its matched pairs; an arc x->x' from nonmatched edge to M0's mate of its right endpoint is allowed iff it belongs to a directed cycle, including loops for distinct parallel alternatives. This is exact by symmetric difference. Select one original ID per M0 pair. In the allowed graph, the affine span over F2 of actual matching incidence vectors equals the entire affine solution set of vertex parity equations (all ones).

Proof: subtract M0. Any homogeneous vector satisfying both shore equations is determined by nonbaseline edges, and its values there form a balanced circulation in the contracted directed graph (baseline coordinate = negative sum of outgoing alternatives; column equations give balance). Every remaining arc lies within an SCC. In a strongly connected digraph the vectors of directed simple cycles span the circulation kernel over any field: an edge-linear functional annihilating all directed cycles also annihilates closed directed walks (decompose into simple cycles); fix a root, define path potentials by sums on directed paths from root. Path sums independent of path since both may append same return path. Each arc weight is the difference of endpoint potentials. Thus the annihilator is the row space of directed incidence; taking annihilators yields the span identity. Self-loops and parallel arcs included. Switching M0 along each directed simple cycle is an actual labeled matching. Their differences therefore span precisely the homogeneous kernel. Linear label map sends this identity to exact affine response hull. For F2 compute by ordinary spanning-forest fundamental cycle images in the allowed bipartite multigraph, base p0 and Gaussian basis. For any supplied prime field Fp, signed incidence formulation and field elimination are polynomial in input bit length including log p; this generalizes the exact hull, NOT the binary one-row converse or arbitrary-large-field exact Fourier counting. No planarity needed for this rank-zero result.
