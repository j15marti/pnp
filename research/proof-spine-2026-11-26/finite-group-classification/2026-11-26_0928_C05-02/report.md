## 4. Fixed-PM topology on high-degree triangulation primes (PROVED)
For any fixed projected PM M whose every selected pair has two distinct X owners, construct multigraph H on X with one edge per selected pair between its actual owners. Choosing tuple is orienting that edge to its owner. A connected component with v vertices and e edges has edge-to-vertex incidence matching size min(e,v): tree can match all edges away from a root, cyclic graph choose spanning tree plus one edge and orient resulting unicycle to cover all vertices; upper bound immediate. Include isolated vertices. Globally n edges=n vertices, so Hall deficiency delta equals number of tree components. Feasible iff every component is unicyclic (no tree and total e=v). Exact fixed-chart count is 2^(number of components), because attached trees forced outward and each cycle has two orientations, including length-two parallel cycles. Not a count of full source covers. Unary guards may shrink domains; rederive parity/matching rather than reuse unguarded formula.

All YZ pairs have exactly two X domains (two adjacent triangles), YZ graph is plane cellular, its faces correspond X links; dual of projected pair edge is H edge. Each retained Y/Z color has two poles of degree2 and all other vertices degree3. For any PM, complement K=G minus M thus has exactly two path components (four degree1 endpoints) plus disjoint cycles. Components of H=G*[M] correspond to regions of K: take regular neighborhoods of path components (disks) and cycle components (annuli); complement regions retract onto dual graph after deleting dual edges of K. For a region with b incident cycles and p contained paths this orientable genus-zero region has b+p boundary circles, so first Betti number of H component is b+p-1. Equivalently planar dual contraction/Euler calculation. Nesting adjacency of the disjoint cycle Jordan curves forms a tree T; mark each region containing a path (two marks, possibly same node). Each region's rank is deg_T+p-1. With no cycles single region has two marks and rank1. Otherwise exactly unmarked leaves are tree components of H. Therefore delta=0 iff T is a path with one mark at each end (or single node with both marks), equivalently every complement cycle separates the two paths.
