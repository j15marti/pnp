## Theorem A: exact support deletion via signed cofactors
Fix any current allowed planar bipartite labeled projection E, necessary linear observations H p(M)=H t over F2, r rows (dependent rows permitted, preferably reduce). Let C be the exact number of perfect matchings meeting this guard, and C_e the number including original tuple ID e. For any character a in F2^r form signed Kasteleyn matrix K(a), entry (x,y) equal to the sum over parallel labeled edges e of s_xy * (-1)^(a dot H label(e)). With the SAME global sign sigma calibrated using positive unweighted determinant, character sum
C = 2^(-r) sum_a (-1)^(a dot Ht) sigma det K(a).
By determinant multilinearity in distinct labeled weights, with Cof_xy the ordinary signed cofactor,
C_e = 2^(-r) sum_a (-1)^(a dot Ht) sigma * s_xy * (-1)^(a dot H label(e)) * Cof_xy K(a).
Both equations follow by expanding the same-sign matching monomials and Walsh orthogonality. No abs per character, no division by a potentially zero determinant; actual minors work even at singular characters, and parallel labels are distinguished. If no unconstrained matching, terminate native NO before calibration. Counts are nonnegative integers, sum_e C_e=nC. If C=0, native NO. Otherwise delete exactly the zero-count edges. This preserves the entire guarded matching set: every matching in it uses only positive-support edges; deletion cannot add a matching. As every native solution lies in the guard, all these original-ID deletions are unconditional consequences for the native source (under original input guards), NOT unconditional projection consequences. Replay any additional native closure in all projections; it may remove other non-native guarded matchings, but preserves native covers. Likewise C_e=C certifies a necessary native tuple. Compute at most 1+2^r(1+m) determinants/minors, with O(n log(m+n)) bit bounds on minors and O(r+n log(m+n)) on sums. Use polynomial-bit exact determinant arithmetic including singular cases. Alternatively test via pinned-edge determinant differences. No free count oracle. Source guards must be retained or revalidated if changed.

## Theorem B: exact recycling of observation rank after productive deletion
Let p0 be the response of any ordinary matching of the newly reduced E. All other response differences belong to V, the image under edge-label XOR of the binary incidence cycle space (difference of matching indicators has zero vertex boundary). A spanning forest and fundamental cycle images compute a basis in polynomial time; it suffices that p0+V contains all actual responses, not equality of hull with support. Express each old observation row h as row v -> h(v) on V with RHS h(t-p0). Gaussian elimination either finds an inconsistent equation system on this superset, which proves native NO, or selects an independent row subset H' with identical affine solutions on p0+V. Therefore old and new guard select EXACTLY the same matchings of the current graph. Rank can drop; discard the redundant row and retain a derivation from the current graph. Deletion plus this algebraic reduction is the hybrid: negative counts make structural changes that lower the number of active characters needed by future counts. This is NOT arbitrary guard forgetting merely because every edge has conditional support.
Example falsifier: native cube mask60, XY projection four edges IDs2,3,4,5 with tuples (0,1,0),(0,1,1),(1,0,0),(1,0,1). Requiring owner0 odd leaves 2 of 4 matchings, but all four edges have conditional support. Dropping that guard without a proved equivalence adds 2 defective matchings. Observed 279 such unsafe-forgetting cases in small controls.

## Theorem C: fixed polynomial total cap for successful recycling runs
Choose fixed c, rank cap R=floor(c log2 N), fixed polynomial-size computably acquired candidate dictionary per round (unit rows suffice for experiment; optional certified owner-class rows). At each round recompute closure and guard rank as above; return NO on a sound contradiction. Consider only a candidate row independent on current V of the retained rows; skip implied rows and stop on affine inconsistency. Choose a row by exact count or another fixed rule, append within R; run exact support closure and all-projection native closure, then reduce rank. If no productive row within cap, return UNKNOWN. If no edge is removed, graph and V are unchanged and rank increases by one. If an edge is removed, rank can decrease by at most R, but m decreases. Thus lexicographic (m,R-r), equivalently Phi=(R+1)m+R-r, strictly decreases on every accepted round. At most (m0+1)(R+1) rounds, all failed dictionary trials charged, independent of total possible matchings. With 2^R<=N^c, each row trial, support pass, all-projection closure, recomputation, signature construction, algebra, verification and original-ID storage has fixed polynomial cost; multiplication by polynomial round and dictionary counts preserves one fixed exponent. Peak space polynomial; cumulative <=(T+1)S. No branching required; if extra lanes run their costs must be summed under fixed caps. This proves a sound capped NO/UNKNOWN refuter and exact source-preserving transformations, NOT a universal NO guarantee. The implementation uses stricter finite round and frontier caps; frontier DP is empirical only, determinant route gives the general bit bound.

Verify by zero count in P plus bad bit on E minus J_h, costing 2^(rank(P)+1) signed determinants when cap permits.
