## Theorem 1: exact affine event pivot
Normalize the integer one-hot owner constraint using Boolean prefix s_prev+x=s_next (endpoints 0,1), allowed 000,011,101, equivalently even parity excluding 110. At degree <=3 direct exact-one table can be used. Solve all affine equations with offsets and preserve forbidden affine events. Thus every residual is conjunction of negations of affine systems F_i: A_i y=b_i, over GF2. Remove inconsistent events; a rank-zero consistent event means contradiction. No approximation.

Choose any private coordinate t, with remaining y, such that all protected boundary forms have zero t coefficient (choose a basis extending protected span if needed). For each touched F_i choose a row t+u_i(y)=c_i, add it to every other row containing t, obtaining trigger A'_i y=b'_i. Hence F_i holds exactly when its trigger holds AND t=c_i+u_i(y). Untouched F_i remain unchanged. For each unordered pair i,j of touched events introduce one forbidden event consisting of BOTH triggers and (u_i+u_j)(y)=1+c_i+c_j. Reduce each system by Gaussian elimination; drop inconsistent ones, deduplicate canonical RREF events. For every fixed remaining y, a permitted t exists iff every untouched event is false and no pair of active triggers forbids opposite values. Necessity immediate; sufficiency because active forbidden values form a subset of {0,1}, and if both values occurred there would be such a pair. Reverse lift tests t=0, then t=1 against recorded original touched events. This is exact existential projection preserving all correlations, arbitrary guards already substituted and protected forms, not model count.

For d touched events of ranks r_i, at most d(d-1)/2 new events, with rank <=r_i+r_j-1. Cost polynomial in written input even when their attainable sets have exponentially many words. No enumeration of the complement of an affine event. This extends rank-two-only protected phase elimination to arbitrary rank, and allows offsets and mixed linear forms. Several private independent coordinates can be eliminated consecutively; only a capped aggregate is claimed, not rank closure. For two initial events {t=0,a=0} and {t+b=0,c=0}, the projected forbidden event is {a=0,c=0,b=1}. On the full 3D boundary no conjunction of rank<=2 forbidden flats represents its complement: each nonempty excluded flat would have to be contained in a singleton, impossible. Abstract algebraic adversarial control, not a new native P3DM hardness gadget. General rank growth can be real; no universal rank-two closure.

## Theorem 2: basis-only generalized protected Rado
For arbitrary nonempty consistent bad event F_i choose its independent equation rows (v_ij,b_ij), with span P_i. Satisfying any row at the opposite RHS suffices to avoid the entire event. Let W be any protected subspace. Independent representative acquisition can use JUST the basis vectors v_ij reduced modulo W, not 2^rank(P_i)-1 candidate vectors. Rado condition for any set J depends on rank of sum of spans; union of basis lists has exactly that span. Alternatively, use shortest augmenting paths of owner-labelled linear matroid independent representatives. BFS from unmatched owners explores coefficients on currently selected reps; an outside-span vector is an endpoint. Shortest path implies an earlier candidate has zero coefficient on any later selected owner beyond its immediate successor (otherwise shortcut); triangular replacement and the outside-span endpoint preserve independence. At failure C consists of reachable owners. All basis vectors of C lie in W+span of selected representatives of C; otherwise an endpoint or a new owner would be reachable. Exterior selected reps are therefore independent modulo W+sum(P_i:i in C). Independently verify this final rank certificate. For ANY compatible evaluation on W+core, prescribe each exterior representative opposite its stored RHS, and extend linearly. All exterior events avoided; converse restriction immediate. No need to materialize all nonzero forms, even at higher rank. This proof also covers any earlier exact pivot outputs, not just rank-two events. Zero events are contradictions before acquisition. Computational implementation tests W=0 only; protected generalization is mathematical, not executed.
