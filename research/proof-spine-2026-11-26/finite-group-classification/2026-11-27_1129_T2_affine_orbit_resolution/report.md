## Exact theorem
On every native input, signed equality normalization and B parity rows give a necessary affine chart F. Within the chart a B predicate fails precisely when its four signed port values are all equal: weight 0 or 4. Retain the affine bad events E_i, each specified by equations (empty events removed). Then SAT iff F minus union_i E_i is nonempty. The 16 physical words were checked. Include affine guards in F; a non-affine guard requires an exact separate representation or refusal. Never quotient a guard without checking preservation.
For any nonzero h in the direction space of F, let q be the affine quotient by span(h). For every nonempty event E_i, either h belongs to dir(E_i) and the event is invariant, or each orbit meets the event in at most one point. Hence the forbidden projected set is exactly the union of q(E_i) for invariant i and q(E_i intersect (E_j+h)) for unordered distinct affected i,j. Proof: an orbit {x,x+h} is fully forbidden iff one invariant event contains it or two affected events cover its opposite points. The reverse ordering gives the translate of the same intersection, hence the same projection. Every output event is affine or empty and computable by Gaussian elimination. Every allowed projected point lifts by checking the two preimages against saved input events. The map is exact for feasibility and joint support in the quotient, not exact counting. Branching on a nonconstant affine form gives two exhaustive affine guards; a rank-one forbidden event forces the opposite affine equation; an event equal to the entire chart certifies contradiction.
If k affected events <=3, at most binom(k,2)<=k replace them. The dimension drops by one; m does not grow. Potential d+m decreases on the whole unbranched contraction state, at most O(N) steps. No promise of direction existence. A basis shear transforms h=e_i+e_j into a coordinate: old x=new y+e_j*y_i, so the coefficient on i toggles by the coefficient on j. It is invertible and the same orbit theorem applies.
## Complete acquisition for this restricted terminal
For any current explicit chart, a direction affecting <=3 events exists iff for some excluded set S of at most 3 events the stacked normals of all other events have a nonzero kernel vector in the chart direction space. Enumerate the O(m^3) sets and find such a vector by GE, or return a checked refusal. Forward direction: exclude the actual affected events. Reverse: membership in every remaining direction space guarantees invariance. Empty events must first be removed. This is polynomial even when the found direction is dense. The full subset search was NOT executed in this run. Only axis and two-coordinate directions in the current basis were tested. For general F_p (a separate extension), an affected event intersects each line orbit in at most one point; if k<p, none of these events alone or together covers a line, so only invariant events matter. For a surviving orbit, compute at most k forbidden phases by linear solves and choose an unused phase among 0..k. This is polynomial in k,d,log p; no p-way enumeration. Does not by itself adapt native Boolean constraints to F_p or solve k>=p.

## Costs and falsifiers
On the fixed <=3 terminal: d,m=O(N), explicit chart event matrices O(N^3) bits; naive GE of O(N^2) rows of width O(N) costs O(N^4) bit operations; O(N^3) excluded sets per step and O(N) steps give conservative O(N^8) core GE bit work. Allow O(N^10) for explicit sorting, normalization, trace, reverse maps and checking with ordinary bit algorithms; store O(N^4) bits of history plus working storage, cumulative memory bounded by time times peak. These are deliberately loose polynomial bounds for contraction, not for arbitrary residual search. Branch proof verification polynomial in N plus explicit trace/tree length, not proof acquisition in N. All failed replicas count. Measured counters are row comparisons/XOR loops, support scans, direction checks and branch nodes, not bit time; arithmetic widths <=644/594 bits in native trials. Separate caps row loops 10^7, support scans 10^7 axis/2*10^7 shear, pair direction checks 10^7, branch nodes 10^5; not one common aggregate budget. Parsing, SHA, sorting, allocation, actual memory/time, transport, serialization and communication additionally paid but not instrumented comprehensively. No overall runtime advantage established. No attention oracle used.
Falsifiers: missing opposite-orientation intersection; changing guard under h; invalid/self shear; assuming local potential implies universal progress. Coordinate-axis sufficiency specifically falsified by the two native plateaus above. Equality/pure affine and B4 truth controls passed; bounded-width affine projection checked; matching and compact-circuit controls not separately executed. No all-decider lower bound; DISJ, relativization, natural proofs, algebrization, simultaneous DTISP, deterministic configuration gates not resolved for unrestricted separation.
