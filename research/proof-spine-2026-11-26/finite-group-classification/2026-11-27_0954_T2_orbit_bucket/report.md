## 1. Exact local translation theorem
Let U be a bucket's union of variable coordinates, with all incident factors of a variable set E to be existentially retired. Each actual table R_i is on S_i subset U. Let H_i={h in F2^S_i:R_i+h=R_i}. It is a linear subspace: 0 stabilizes, composition adds translations. For explicit nonempty table, test candidates h=r+r0 for r in R_i using deterministic membership; for an empty table immediately terminate NO. Compute annihilator bases by GE. Set H={h in F2^U: h|S_i in H_i for every i, h fixes every protected pin}. Then H is a linear subspace and the complete joint bucket relation R is H-invariant. In arbitrary finite field the same statement holds for translations in an additive subgroup; F_p stabilizer is a linear subspace since repeated addition gives scalar multiplication. Do not infer F_p symmetry from Boolean complement when p!=2.

Let pi project onto U minus E. Enumerate each coset of H once using a linear complement W, retain w in W iff all bucket factors accept w. Exact output is union over accepted w of (pi(w)+pi(H)). This follows from R=(R intersect W)+H and linear projection. Canonicalize pi(w) modulo pi(H); membership on outside shared variables still sees the full orbit, not merely canonical labels. For an actual boundary vector b in the output, solve pi(h)=b-pi(w), h in H, then w+h is a valid internal witness. Reverse all eliminations and expand equality phase maps. If additional guards are compound, verify invariance of their full predicate or refuse this quotient; coordinate pins use zero flip on each pinned coordinate. No claims about exact model counts or tuple-level backbone from an orbit representative.

This gives fixed-parameter local acquisition poly(N, table bytes) * 2^(|U|-dim H), plus output/canonicalization costs; if output is stored as full rows, orbit expansion must be paid. An orbit-compressed table with explicit generator basis and representatives allows membership via Gaussian quotient reduction. For subsequent joins, intersect the actual stabilizers on shared coordinates; cannot independently gauge-fix children. Local H need not stabilize outside factors, so keeping full projected orbit is mandatory. Only for global H can one fix dim H independent pivot bits without changing feasibility. This is symmetry breaking, not an unconditional forced-bit claim.

## 3. Scoped obstruction: global factor-wise translation group can stay rank one
For a B4 predicate on four distinct root variables, signed literals are a fixed translation of weight-two relation. Its stabilizer is exactly {0000,1111}. Proof: if flip mask has weight k, invariance requires intersection with every weight-two support to have size k/2; k odd impossible, k=2 fails by choosing its own support, k=0,4 work. Signs do not alter the translation stabilizer. Therefore all four flip coordinates of each such factor must agree. In a connected factor-scope hypergraph with no repeated root inside any B factor, global factor-wise translation group is exactly rank one.

The pinned compiler applied to any nonempty 3CNF with three distinct variables per clause and all variables occurring yields this property: every B uses distinct carriers; duplicate B shares the same carriers; every second NAE/B row touches common anchor f, every first row touches its private z which occurs in the second. All original variables and slack carriers lie in the same scope component. Signed E paths and K5-minus-edge wires do not identify distinct carriers. The source class remains NP-complete: remove tautologies/duplicates, expand each binary clause with two choices of a fresh literal and unit with four sign pairs on two fresh variables; trivial cases handled separately.
