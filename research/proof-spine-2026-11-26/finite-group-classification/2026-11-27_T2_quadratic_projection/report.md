2. Deterministic projection: keep factors in original B scan order after deduplication, then remove touched factors and append replacement. Each epoch choose variable occurring in <=2 current factors, whose combined other scope size <= fixed w. Order candidates lexicographically by (incident factor count, boundary size, original representative port ID). Enumerate boundary words numerically with bits assigned to ascending ports, try eliminated bit 0 then 1, preserve first witness bit. Replacement is exact existential join; drop if full table. Owners are sorted union. Record old factors, replacement, lift map; independently enumerate BOTH eliminated bits for each boundary assignment and check all original factors involving that variable were included. Free carrier count strictly decreases. No external compiler map used.
3. In ascending port order relabel survivors 1..r. For each factor enumerate partial assignments by increasing cardinality, lexicographic combination of positions, lexicographic binary words. A forbidden partial word produces the clause negating that word; skip if an existing emitted clause subsumes it. Preserve factor order and emitted clause order; map each clause to its B owners. Check each emitted clause on every allowed word of its source factor and each factor enforced by emitted clauses contained in its scope. Recognize a positive clause S together with every pairwise negative clause (-i,-j) as exact-one. Under F2 Boolean identities, 1+sum(S)=0 and x_i*x_j=0 for each forbidden pair. Generate all square-free monomial multiples of generators whose formal degree fits fixed d; Gaussian elimination tests whether constant 1 belongs to span. Independently check resulting identity by parity counting expanded monomials.

## Scoped progress theorem
For fixed w,d, at most r0 exact projection steps, each using <=2 factors and <=w other variables. Number of live factors does not increase. On a fixed chart, span rank increases only on new independent identities. Let D0=sum_{j<=d} binom(r0,j), and potential Phi=(D0+1)*r + (D0-rank). Each exact variable elimination strictly decreases potential even if rank resets; each independent identity on unchanged chart decreases by 1. Numeric initial value O(r0^(d+1)), fixed polynomial. Uniform enumeration, bounded table joins, elimination over polynomially many degree-d monomials, bounded-size witness maps and deterministic checking all polynomial in original N for fixed w,d, with all failed scans counted. This proves termination and correctness of this scoped saturation algorithm (which can return UNKNOWN), not that every unresolved input decreases or decides.
