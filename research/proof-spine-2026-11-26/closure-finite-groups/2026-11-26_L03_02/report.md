## 2. Fixed-order streaming theorem (PROVED WITH SCOPE)
Model: known k and p>=1, exactly p complete left-to-right scans of the immutable row-major array. Rewind between passes cannot inspect input or write an external store. All computation and persistent information other than fixed program/known scan positions and fixed parameters is in the complete mutable state, including workspace, any caches, retained input, control and any adaptive clock accessible to the machine. Transition may be arbitrary deterministic local computation with the next block and state, no oracle. Early decisions can be kept as state, but for claimed cumulative resource bound the scans actually occur (no charge for hypothetical padded passes). Let S be fixed upper bound in bits of an injective fixed-width encoding of state at scan and reset boundaries. This includes bookkeeping if not hardwired; p and positions are fixed at each boundary. The lower bound does not assume limited computation or exclude branching/learning between reads.

There are M=2k(k-1) indexed internal edges. Uniform YES strings correspond bijectively to independent edge bits. At block cut j, let W_j be the word of c_j crossing edges. For a YES input, record state after reading j blocks in each pass, plus the p-1 states at the start of next pass (including any reset computation). If two YES strings give the same transcript, splice their prefixes/suffixes at j. Induct on alternating segments: first prefix simulation agrees on start state, next suffix agrees on boundary state, and next prefix agrees on reset state. Deterministic segments access only their own input portion and complete state, so the splice is accepted. Distinct W_j makes this splice a valid singleton NO, contradiction. Thus transcripts determine W_j on YES inputs, no local-computation bound needed. There are at least 2^c_j possible transcripts. For full-row cut c_j=k, hence (2p-1)S>=k. This is a deterministic exact equality communication argument, not a claim of priority or unrestricted time lower bound.

Upper bound on SAME source: divide k columns into p nonempty consecutive batches of sizes <=ceil(k/p) (1<=p<=k). In pass h retain the preceding row's south bit only for columns of batch h, compare north and replace by south. Top initializes zero; bottom checked zero. In first pass check every horizontal adjacency with one previous east bit, left/right boundaries and singleton syntax; all passes retain failure flag. At end, all equalities verified and the unique local words are a witness iff accepted. Exact fixed-order implementation reads p*k² blocks, uses ceil(k/p)+O(1) mutable payload bits plus O(log N) counters and fixed-size current block. Deterministic multitape implementation with row-buffer tape scans, counter increments and physical rewinds has O(p N log N) bit time and O(k/p+log N) auxiliary space, including parsing and row positions. Buffer rewinds <=k*ceil(k/p) per pass, input rewind O(N); all charged. Hence fixed-order bound tight in payload up to constants and uniform indexing overhead. One may use at most k passes even if larger p allowed, or use extra actual no-op scans if exactly p specified.

## 3. Shared-reset amortization (PROVED WITH SCOPE)
A stronger same-execution statement uses variable state code lengths. At each of the p forward crossings of each balanced block cut j, record a prefix-free encoding of the complete state. Fixed-width codes are a special case. Canonical code lengths may vary; for an ordinary fixed finite-alphabet work-tape model, a self-delimiting code of the occupied tape span and its head positions plus control has length O(span+log N+log p+1) under ordinary contiguous visited-space accounting, with actual control information included; arbitrary random-access sparse memories must include addresses. This theorem is about the state CODE lengths, not a lower bound on unencoded auxiliary cell count.

Let J=[ceil(k²/3),floor(2k²/3)] intersect integers, B=|J|=Theta(k²). Every such cut crosses at least k edges. Let C be sum of forward snapshot code lengths over all p scans and j in J; let R be sum of p-1 reset snapshot code lengths (the identical states shared by every cut). Define H=sum_j c_j>=kB. Group cuts by residue j mod k. An indexed edge (u,v), row-major u<v, crosses exactly the cuts u<j<=v, an interval of length either 1 or k. Hence each residue class has disjoint crossing edge sets. In each class a, collect its forward state codes and a SINGLE copy of the shared reset states, in fixed order. The code concatenation is prefix-free (known count of self-delimiting components), and by the individual-cut splicing proof it determines the union of its independent crossing bits. Let H_a=sum c_j over this class and L_a its concatenated length. Every transcript accounts for at most 2^(M-H_a) YES words, and there are at most 2^(H_a-t) possible prefix-free strings of length <=H_a-t (Kraft, for integer t; if threshold negative probability zero). Thus Pr[L_a<=H_a-t]<=2^-t. Union bound gives with probability >=1-k*2^-t, simultaneously on SAME uniform YES execution, sum_a L_a=C+kR>=H-kt. This does not sum different difficult inputs and it explicitly identifies duplicated reset information.

Taking t=ceil(3 log2 k) gives probability >=1-k^-2. If actual R<=B/2, then C>=kB/2-kt=Omega(k³)=Omega(N^(3/2)). If R>B/2, only R=Omega(N) is certified; do not multiply that reset expense by k and call it physical time. For fixed-width S, sufficient condition (p-1)S<=B/2. The C snapshots are taken at distinct actual block-consumption steps, so C is a lower bound on cumulative complete-state CODE length over those steps, and on the corresponding full execution code-volume when that volume includes those snapshots. For uniform tapes with O(span+log N+log p) code overhead, subtract the overhead separately before inferring any span-volume lower bound. This is not an unrestricted cumulative-memory theorem, and not an all-exponent bound.

The same fixed-cut proof gives an independent contradiction check: if a claimed complete state budget allowed fewer than 2^k transcripts at a full-row cut, pigeonhole provides a pair with different W_j and a false accepted splice. No use of separate marginal supports, or addition of overlapping reset charges as disjoint events.

## 4. Changed-order bypass and model boundary (PROVED)
Allow two fixed permutations of the same intact original source blocks, first row-major, then column-major. In row-major, compare consecutive horizontal port bits and require zero at row boundaries. In column-major, compare consecutive vertical bits and require zero at column boundaries. Verify singleton syntax and retain failure; exactly two queries per vertex; O(1) state bits apart from schedule/index counters. A layered deterministic branching program with constant width and 2k² query layers decides the same total singleton predicate (rejects malformed non-singleton blocks). Its query order is input-independent and uniformly generated with O(log N) counter bits, labels cost O(log N) bits each, output representation O(N log N) bits, generator polynomial. This is an unconditional linear-node read-twice program, while L03-01 proves exponential size for block-read-once programs on the same source. A decision-only algorithm for full arbitrary-table GRID may first handle the singleton case, then use exhaustive search on others; existence of the fast singleton path does not imply polynomial full-grid runtime.

This is a genuine nonlocal-order counteralgorithm for the generic repeated-read transfer. In an indexed random-access model the query computation is O(N polylog N) bit work, O(log N) auxiliary bits; it is NOT a two-pass same-row-order consumer. On a standard multitape machine the arbitrary-order accesses are not free; the previous one-pass O(N log N)-time row buffer remains a cheap legal alternative with O(k+log N) work bits, or materialize/reorder with paid sorting and O(N) storage. No unrestricted constant-space near-linear tape claim. Two orderings supply exactly the cheap operation missing from fixed-order communication: re-indexing so each equality pair is adjacent in one of the traversals. This falsifies any generic claim that the old exponential block-read-once representation bound survives even two ordered reads of each block. Does not disprove a source-specific hardness theorem for the unrestricted NP-complete grid.

Bounded-width row buffer provides the exact joint state with k bits, not an exponential table.
