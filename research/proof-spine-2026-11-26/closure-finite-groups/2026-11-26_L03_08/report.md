## Track A: local query normal form and disjunctive barrier
For a coordinatewise monotone map R, if B(R(1))=0 then no overflow anywhere. If A(R(1))=0, query identically zero. Otherwise R(1) is exact4, and A(R(x)) implies R(x)=R(1) (coordinatewise inclusion plus same block cardinalities). Thus F(R(x))=A(R(x))*G(R(1)), with one nonuniform fixed baseline bit. For arbitrary maps this is not a free uniform acquisition algorithm. If B(R(1))=1, select any 5 true coordinates of one overflowing table at 1. Choose valid positive certificates there. Their union P_R forces B on every input with x_P_R=1, so F(R(x))=A(R(x)) on that restriction. Literal maps have |P_R|<=5, d-local coordinates <=5d. A is an explicit conjunction of constant-size monotone threshold gates, hence O(number of target membership bits) extra gates. If no overflow at top, constant or A likewise. This is the positive counterpart to L03-07 bottom deficient certificates.

For n>=1, suppose Match_n(x)=OR over q nonadaptive F(R_i(x)), each map monotone and each relevant coordinate has certificates of size <=d, d>=1. Each query is sound on every NO. Ignore identically zero queries. At top nonoverflow, the nonzero query equals A everywhere. At top overflow, choose one positive overflow certificate of <=5d original edges; define E as rows touched by these edges, e<=min(n,5d). In the nonoverflow case E empty. For every row i not in E, let y_i be complete graph minus that entire row. This is NO, hence query rejects. In overflow case B still holds on y_i because no positive witness edge was removed, forcing A=0. In nonoverflow case query equals A, also forcing A=0. Select 13 zero coordinates of a deficient table at y_i. Their zero certificates fix only zero input bits (monotone coordinates permit this: remove all positive pins from any zero certificate, since the maximal completion with just negative pins already respects the original positives). Those zero bits lie entirely in row i. The union of <=13d pinned edge IDs Z_i is a sufficient zero certificate for deficiency. Every query-accepted permutation matrix must select an edge from Z_i in row i; otherwise all certificates hold, contradiction. Thus all n-e nonexception rows have lists of <=13d allowed columns. Once their distinct choices are assigned, remaining columns can be permuted in at most e! ways. Number of accepted permutations <=(13d)^(n-e)e! <=(13d)^n since e<=5d. No independence assumption on rows required. Since n! permutation matrices must be covered, q >= n!/(13d)^n (ceil when needed). For d fixed this is exp(n log n-O(n)), stronger than ordinary exponential. For literal maps, symbolic upper construction: partition rows into groups of size <=6, and for each allocation of columns to these groups (same group sizes) require a perfect matching within each block. Each block Hall clause has at most floor((s+1)^2/4)<=12 positive literals. Realize any width<=13 positive clause by a table with 3 constant-one coordinates, its literals in remaining slots, rest zero. Its A test is exactly that clause. Add a constant 5-word table to force B and pad to a square with 4-word tables. Each query sound, because union of block matchings is a matching. Every matching graph contains some permutation and its block allocation, hence accepted by one query. With groups s_j, exactly n!/prod_j s_j! such query maps suffice; each O(n) cells (large fixed constant from size6 Hall clauses). Together n!/13^n <= q_min <= n!/(720^floor(n/6)*(n mod6)!) for literal OR, so log q_min=n log n-O(n). Not claimed exact count, and not a bound on general circuits. At input length n² this is exp(Theta(sqrt(N) log N)) for N=n². Upper family not enumerated large, actual maps checked.

Further at stagnation: for any sound conjunction term of at most h F queries, same proof using union of top overflow witnesses and ignoring always-zero terms gives e<=min(n,5dh), with <=(13d)^(n-e)e! covered permutations. Thus fixed h,d still requires factorial-scale number of such terms in an outer DNF. Large h or arbitrary shared circuit expansion is not controlled; exponentially many DNF terms can have a small shared circuit. No extension to general outer circuits asserted.

## Track B: exact positive vertex-cover restriction
Let P be ANY set of original edges to fix to 1. Let R subset left and C subset right cover every edge of P. Write r=|R|, c=|C|, t=r+c<=n (minimum cover via bipartite matching always meets this). Select r private right vertices V outside C and c private left vertices U outside R. Fix P to1, add bijections R->V and U->C with their edges fixed1; all other edges except the free submatrix on left complement of R union U and right complement of C union V are fixed0 unless already in P or chosen bijections. All P edges covered, so none inside free submatrix. Dimensions m=n-t. A perfect matching of this restricted graph necessarily matches every V column to R (no other incident allowed edge), exhausting R; every U row to C (no other incident allowed edge), exhausting C. Hence no cross edge to the free rows/columns can be used. Conversely the fixed bijections extend every matching of free m-by-m matrix. Thus exact literal restriction Match_n=Match_m, preserving every positive pin regardless of whether those edges form a matching or touch every column. Actual lift by fixed bijections, no target oracle. For t=n, empty free matrix gives constant YES as expected.

Adversarial C: naive negative-pin recipe of removing only ONE matched pair (0,0) meeting both a left and right cover is false here. At n=3 pin (0,1),(1,0) to1, retain free submatrix on rows/columns 1,2 with only (2,2) allowed. Free 2x2 NO but the full graph has permutation (1,0,2). The new two private-pool construction instead removes two pairs and has exact m=1. This independently falsifies same-pair reuse for mixed positive cover without further hypotheses.

## Integrated theorem for arbitrary monotone outer circuit
Given Match_n=H(x,F(R_i(x))) where all coordinate computations and H are counted monotone circuits, select a top overflow certificate P_i for EACH query with B(R_i(1))=1; set P=union, not sum. The preceding restriction using minimum vertex cover tau(P)=t makes every overflowing-at-top query equal A and every nonoverflow query equal A times a fixed bit or constant zero. Every F gate is eliminated, with O(S+M) total ordinary monotone gate/wire size (S outer/preproc size, M total explicit output membership bits). The fixed bits are nonuniform constants; no uniform discovery assumption. Original circuit after this literal restriction computes Match_m with m=n-t. Cavalar et al., ECCC TR25-102 rev1 theorem1 (Nov6 2025) lower bound 2^(m^(1/3-o(1))) applies. Thus for any fixed polynomial S+M<=n^C, every such selected P must have tau(P)>=n-(log n)^(3+o(1)). Unlike L03-07 negative-pin theorem, NO Hall-blocker exception is needed: setting positive pins never prevents the private padding witness. In particular if q_B is number of queries with top overflow, <=5d q_B positive edges selected, so q_B>= (n-(log n)^(3+o(1)))/(5d). If both endpoints of many pins overlap, union cover can give much stronger exclusion; all n edges in a single row cover1, cross stars cover2.

Together with the independent negative-pin theorem of L03-07, an admitted polynomial reduction has to survive both necessary restrictions. We have NOT shown both can be defeated simultaneously or that a suitable low-cover certificate selection always exists. Arbitrary positive and negative pin sets may conflict; no mixed restriction assumed. No proof of lower bound for actual F. For unrestricted Boolean outer circuits the n² identity queries from L03-07 plus augmenting-path matching still compute Match in polynomial time; OR and cover barriers thus do not apply. Also the block matching queries themselves are P-decidable. A direct ordinary matching algorithm does not acquire exponentially many queries, maximal NOs or permutation covers. This identifies nonlocal shared/adaptive decision as the unhandled cheap operation.
