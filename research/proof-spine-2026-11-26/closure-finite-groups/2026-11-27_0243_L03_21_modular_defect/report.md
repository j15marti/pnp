## Source and named obligation
Test whether simultaneous matching syndromes with feasible affine hull, integer lattice, and fractional relaxation require costly joint-support acquisition. Falsifiers: a genuine matching achieving all odd color counts; a signed lattice witness failing the original incidences; an incorrect modular range certificate; an unjustified all-decider inference. Ordinary explicit Boolean CNF (exact-one per row, column, color; edge variables). Native source is explicit labeled tripartite triples. A perfect matching of the row/column projection selects n edges. Requiring odd counts on each of n colors is equivalent to exactly one per color, since each odd count is >=1 and total n. General equal-shore 3DM reduces identically by retaining each triple as a distinct labeled edge, including parallel edges. This is known NP-complete source (Karp 1972); membership and the adapter both immediate. CNF encoding ALO and pairwise AMO per group has polynomial size; exact witness map is selected triple IDs. Negative-only algorithm sound on all permitted inputs, completeness only for following family.

For n divisible by 4, take complete cyclic Latin-square triples e_(i,j)=(i,j,i+j mod n), 0<=i,j<n, ID i*n+j. Add t extra labeled edges (i,-i mod n,1) for i=0..t-1 with IDs n*n+i; original edge has color0. Parent t_max=n/2-1, guard pins all later special edge IDs to zero. Progressively release extras for t=0..t_max, keeping original IDs. No UP beyond pins and implied removal of disabled literals: every live exact-one group has >=n members and all remaining clauses width>=2. This is only syntactic closure, not a free semantic entailment oracle. Exact parent triple input uses gamma-coded n,m, m triples with 3ceil(log2 n) bits each, plus m-bit disabled-edge mask, N=Theta(n^2 log n). Pairwise CNF adapter O(n^3 log n) bits, clauses counted from original groups; full CNF file not materialized in audit. Fingerprint is deterministic noncryptographic FNV-style; raw code fully regenerates actual original triples and guards.

## Replica A: explicit fractional and integer signed witnesses (not SAT witnesses)
For each color c, the matching M_c uses column c-i mod n on row i, hence all n edges have color c. Their average realizes color-count vector 1 and all row/column constraints; in fact averaging their incidence vectors yields x_e=1/n on every base edge, zero on extras. This proves target lies in convex hull of matching COUNT vectors; every linear price optimization over counts brackets target. No actual cover claimed.
For c=0,...,n-3 construct two matchings by assigning rows 0,1 to columns c,c+1, then swapping those assignments, and completing with any identical bijection on remaining rows/columns. Difference of their color-count vectors is D_c=e_c-2e_(c+1)+e_(c+2). (Here e_c denotes unit color vector, distinct from edge ID.)
When t>=1, replace edge (0,0,0) of M_0 by extra (0,0,1), producing difference d=e_1-e_0.
By telescoping,
e_j-e_0=j d+sum_(c=0)^(j-2)(j-1-c) D_c.
Therefore
1 = n e_0 + [n(n-1)/2] d + sum_(c=0)^(n-3)[(n-1-c)(n-2-c)/2] D_c.
Each difference is of ACTUAL matchings, so lifting the expression to edge incidence gives an integer vector satisfying all original equalities, with signed coordinates permitted and guard respected. This is stronger than checking merely affine projected marginals. It also proves target lies in affine hull over every field (integer coefficients reduce to the field). For t=0 the d coefficient is even because 4|n, so omitting it produces a GF2 witness; original modular obstruction rules out integer solution at t=0. Thus adding just one extra edge destroys the entire integer-lattice obstruction while preserving genuine NO. Do not infer a Boolean solution from signed integer or fractional feasibility. Coefficients polynomial bit size.

## Replica B: modular conservation, and its failure on the damaged family
For every base edge, color c=i+j mod n. A perfect row-column matching has sum of i+j equal to n(n-1), residue zero modulo n. A rainbow matching (equivalently all color counts odd) would sum all colors, residue n/2. Thus clean t=0 NO, classic cyclic Latin-square obstruction. Special edges have color excess one. Once extras are released, pure zero-defect modular invariance fails. More generally the signed integer witness from A rules out ANY infeasibility certificate based only on integer-linear equality inconsistency, including any modulus or any field-linear combination of the original incidence equations. It does not rule out integer inequalities or parity plus actual matching restrictions.

## Integrated hybrid: bounded modular defect on actual matchings
General lemma: for any explicit colored bipartite multigraph, given modulus p>=2, color labels lambda_c, row potentials u_i, column potentials v_j, let w_e be least nonnegative residue of lambda_c-u_i-v_j mod p. For target exact count vector b_c, a matching realizing it must have total W=sum w_e congruent to delta=sum b_c lambda_c - sum u_i - sum v_j mod p. Compute or certify lower and upper bounds L,U on W over ACTUAL perfect matchings using min/max weighted bipartite matching; if no integer in [L,U] congruent to delta, reject. If no perfect matching at all, reject by Hall. Otherwise UNKNOWN. This is a sound negative-only test, not a completeness claim. A target with odd color counts and exactly n colors uses b_c=1 by occupancy. Costs are ordinary integer bit arithmetic and polynomial weighted matching with explicit bit-length weights, not enumeration of syndromes.
On the same source n,t choose p=n, lambda_c=c,u_i=i,v_j=j. Then base costs zero, extras cost one. The interval is exactly [0,t]: upper bound by summing row maxima, lower by nonnegativity; M_0 attains zero, replacing its first t edges by extras attains t. All integer costs and dual inequalities checked by one edge scan. Target delta=n/2. Since t<n/2, no residue in range. The extra edges that destroy integer-lattice inconsistency are therefore harmless under bounded-defect tariff. Hybrid changes the domain: subtract modular potentials, convert their failures into nonnegative local costs, then certify maximum attainable defect over actual matching domain. It uses no global candidate counting. This is the cheap computation missing from any proposed lower-bound transfer based only on these relaxations.
The construction is recognizable with given source labels by checking edge costs. No arbitrary CNF-to-3DM recognizer, label-permutation discovery theorem or universal acquisition of useful moduli/potentials is asserted. Guard-specific bounds retain all disabled edges and are valid on the corresponding residual only.
