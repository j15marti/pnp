## A: conditional rectangle factorization and exact common decoder
Let private sets P_i be disjoint, shared set G disjoint from them, H_i subset G arbitrary. Consider a group on scope union of P_i and H_i for i in I. For each local guard word h on H=union H_i, let E_h be its explicitly listed forbidden private tuples. Project to private sets D_(I,i,h). Verify all 2^|H| guard words present, and |E_h|=product_i |D_(I,i,h)| (E_h already subset of product, so equality proves exactness). No global guard enumeration. Check each projection nonempty proper, contains exactly one of private all-zero/all-one. Orient zero-class by all-zero membership: when projection contains all-zero use it as zero-class, otherwise its complement. Verify every occurrence of private i with the same restricted guard h|H_i yields IDENTICAL zero-class (including across different groups and outside guard coordinates). Verify the sign of forbidden class for each i is independent of h throughout its group. Then group equals one decoded clause for every assignment. This is a direct equivalence of Boolean functions on original assignments, even when different H_i overlap arbitrarily. Any original witness maps to quotient witness. Conversely if each private decoder is surjective at a COMMON fixed guard assignment, any quotient witness lifts by independent choices in disjoint P_i at that guard. Here stronger robust surjectivity holds at EVERY guard: all-zero private bits always give zero and all-one give one, for odd p>=3 and two shared guards. Thus arbitrary global guard values may be set to zero for witness reconstruction, without claiming they are forced. If groups fail, discard them; the same forward implication proves sound original NO whenever retained quotient is NO. For unseen private/guard words extend decoder arbitrarily preserving all-zero/all-one anchors. Do not use weakened YES as original YES. Surjectivity not needed for negative soundness, only for reverse lifting.

Source-only acquisition for this family: bucket variables by unsigned support-group occurrence lists. Each private group of p variables has occurrence set S_i; each guard g_i has S_i union S_(i+1). Distinct unions of one or two S_i are distinguishable: for i in A minus B with |B|<=2, choose a binary exclusion between i and some neighbor outside B (conflict degree >=3). Its support group lies in union A, not union B. Therefore all private buckets (size p>=3) and singleton guards are separated and each guard's endpoint pair can be recovered by enumerating all private pairs, verifying union equality. For pinned stages missing singleton guards simply disappear. Check every group's actual scope equals predicted union. In general source recognizer rejects missing/ambiguous union, inconsistent private chart or invalid rectangle; can drop invalid groups after successful scope acquisition. This is not a generic arbitrary-overlap acquisition theorem. Tests implement fixed p3 using 8-entry local private tables; general odd p polynomial in explicit N via sparse sets, complement by count/disjointness, and count guard slices rather than enumerate absent guards. No need to enumerate absent guards: if distinct slice count is smaller than 2^|H|, reject immediately. If all slices present, number of slices already <=N.
