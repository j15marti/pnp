## Negative certification independently of discovery
For original hidden labels let w=(z-i-j) mod n, base cost zero and extra cost one. An exact cover selects each owner once, so sum w congruent to n/2 mod n. Any projected row-column matching uses at most one selected extra per vertex of a defect cover, hence sum w<=|R|+|C|<n/2. This proves UNSAT on every stage before any experimental solver is run. Conversely the full-cross positive support admits a matching of size |R|+|C| (match R to outside C and C to outside R disjointly), extends to a projected perfect matching using base edges, so the bound is tight for fully contaminated parents. Base matchings selecting a single color show fractional incidence feasibility by their average. For any active extra, translate row/column/color coordinates so its base color is zero. Replacing its base edge in a projected constant-color perfect matching provides signed difference d=e1-e0. Two-row swaps in otherwise identical matchings provide D_c=e_c-2e_(c+1)+e_(c+2), c=0..n-3. Then 1=n e0+n(n-1)d/2+sum_c (n-1-c)(n-2-c)D_c/2, as in L03-21; lifts to an integer incidence witness (signed, not a feasible cover). Reducing modulo any characteristic gives equality consistency. This is algebraic reconstruction, not a new numerical lattice audit.

## A: old one-erasure dictionary, scoped obstruction
Admit rows having singleton distinct colors after at most one omitted column, and restore unique missing color from that cell; do both orientations. Construct row-pair permutation and try n-cycles. In this implementation final certificate uses a minimum cover of ambiguous cells (rather than recomputing positive support for each candidate as L03-22 did); it is a narrower final certificate dictionary, but the failure on fully contaminated parents is already at row admission. If full crosses contain >=2 rows and >=2 columns, every row has >=2 ambiguous cells, every column too. No one-erasure row in either orientation exists, independent of candidate order or final checker. This is an infinite structural failure of the specified discovery method, NOT an all-decider lower bound. ## B: independent translation gluing lemma
Acquire a minimum vertex cover (R,C) of cells with more than one color via augmenting-path matching and alternating reachability. It is no larger than any promised cover. Let I=rows outside R and J=columns outside C. Every cell of I x J is a singleton base label. Write r=|R|, c=|C|, and use hidden cyclic coordinates only in this proof. For every ordered distinct row pair a,b in I, form a partial map P_ab: L(a,j) -> L(b,j) for j in J. Each is a restriction of translation by b-a on color labels, with domain size n-c>n/2.

Two such maps agree on their overlap iff their hidden shifts agree: the overlap is nonempty because both domains exceed n/2, and different cyclic translations disagree at every input. Hence grouping by overlap agreement is an equivalence relation on this family; implementation compares partial maps with the accumulated union in each group. No factorial row completions. Every nonzero shift d occurs, because I intersect (I-d) has size at least n-2r>0. Moreover for any hidden color z, choose a with a,a+d in I and z-a in J. At most 2r+c choices are excluded, and 2r+c<n follows from r+c<n/2. Thus the union of all maps in shift class d is exactly the complete translation by d, defined on every color. There are n-1 groups, all complete, one for each nonidentity translation. In particular translation +1 is present as an n-cycle. This proves polynomial acquisition for arbitrarily many erased columns. It does NOT solve general partial Latin square completion or arbitrary partial permutations. On nonpromised inputs overlap grouping may not be transitive; treat as heuristic discovery, require the independent final certificate for any NO.

## H: actual hybrid changes acquisition representation and checks all original triples
Try each complete cyclic permutation, numbering colors along its orbit from any seed. At least one candidate lambda is the true hidden color numbering plus an additive constant. Let a be any clean row. For j in J put v_j=lambda(L(a,j)). For every row i (including R), collect all residues lambda(z)-v_j from every active triple in columns J. For the true +1 chart the set is either a singleton or two cyclically consecutive residues, contains the true base residue, and the earlier residue (unique for n>=4) is the desired u_i. Now for every column j, including C, collect lambda(z)-u_i across all active triples and choose earlier residue analogously, obtaining all v_j. For true chart both steps recover hidden base coordinates up to compensating constants. Every base triple retained ensures no all-defect ambiguity. Finally recompute all w=(lambda(z)-u_i-v_j) mod n. Require w in {0,1}, every positive edge covered by R union C, and |R|+|C|<delta=(sum lambda-sum u-sum v) mod n. This last certificate is independently sufficient for ANY valid 3DM input; no need to trust discovered coordinate system. For true chart delta=n/2, so the algorithm succeeds. No omitted discovery cell is absent from final proof. A wrong chart can only fail or give another independently valid contradiction.

This is a genuine hybrid: matching first discovers which rectangle to project to; group-translation gluing changes partial maps to a complete coordinate dictionary; exact modular constraints and cover produce a compact refutation. B alone recovers shifts but does not certify negative compatibility; A alone cannot acquire any row on full crosses. A supplied-coordinate modular certificate is a reference, not a source-only solution. C independently enumerates exact row/column/color covers on bounded small inputs. The earlier failure is repaired, not transferred as hardness.
