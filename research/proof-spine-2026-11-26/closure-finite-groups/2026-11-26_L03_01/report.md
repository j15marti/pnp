## 2. Independent source lower-bound control
Let G be k-by-k grid, M=2k(k-1) indexed internal edges. A YES singleton input is uniquely encoded by assigning each edge a bit and putting its two copies at endpoint ports, external ports zero. All 2^M such input strings are valid, one-port flips at internal incidences are NO. Initially read each singleton table and force its only word; compare every shared port pair and boundary. No extra search. Apply any guard by comparison to the forced word and reject conflict; at stagnation no unfixed variables remain. Do not add a target witness to input.
For any vertex cut A|Ac, c=number of crossing edges. A sound rectangle of accepted singleton inputs fixes every crossing bit: cross-splice left blocks of one accepted string with right blocks of another whose bit differs and obtain a valid encoding of NO. Therefore a rectangle covers at most 2^(M-c) YES strings. Every balanced vertex cut (both shores >=k²/3) has c>=ceil(k/3), by mixed-row argument in L02, independently checked. In row-major layout, balanced block prefixes for k>=2 have c>=k. For full-row prefix between rows there are k vertical edges. For a prefix with j of next row, if there is a full preceding and a full following row, k-j and j vertical edges plus one horizontal crossing; the only small cases k=2,3 and endpoint balanced prefixes have full preceding/following rows as required or j=0, checked directly. For k>=3, balanced prefix p>=ceil(k²/3)>=k and p<=floor(2k²/3)<=k²-k. There are B=floor(2k²/3)-ceil(k²/3)+1 such distinct physical tape cuts.

## 3. Actual all-operation single-tape transfer (PROVED scoped)
Model: fixed deterministic off-line one-tape TM with q>=2 internal states, fixed finite alphabet, initially input contiguous on tape, head starts left of each cut, one head, unit moves or stay, writes scanned cell only; no separately readable input, other work tape, clock oracle, or advice. Total correctness on the full language or merely the singleton restriction (all valid singleton strings, including NO), arbitrary preprocessing, rewrites, learning, branching, local recoding, caching on this tape allowed. Input layout never assumed preserved after start.

At each fixed initial tape cut j, record the sequence sigma_j of control states just AFTER each crossing (directions alternate, first L to R). The following is Hennie-style splicing: if two accepted computations have equal sigma_j, splice their initial left and right halves. Induct on crossings: each maximal stay on one side has the same entry state, entry cell and side-local tape contents as that side's original execution; since it cannot inspect the other side before a crossing, it performs exactly those transitions, including writes. Equal crossing states make next entry match. At final segment the same parity places head on the same side and it accepts. Empty sequence included. Thus all YES strings with the same sequence have identical crossing-edge pattern (otherwise cross-splice is NO). This is a theorem on actual unrestricted operations of the one-tape machine, not a hypothesized fixed decomposition circuit.

Set ell=floor(k/(2 log2 q))-1 for k sufficiently large. The number of possible state strings of length <=ell is sum_{i=0}^ell q^i <=q^(ell+1)<=2^(k/2). Each sequence class contains at most 2^(M-c_j) accepted strings. Uniform over actual 2^M singleton YES inputs, Pr[|sigma_j|<=ell] <=2^(-k/2) for every balanced row-major cut. Union bound over B cuts: at least 1-B*2^(-k/2) fraction of the SAME actual accepted executions have |sigma_j|>ell simultaneously at all those cuts. Each machine step crosses at most ONE tape boundary. Hence T(x)>=sum_j |sigma_j(x)|>= B*(ell+1)=Omega_q(k³)=Omega_Machine(N^(3/2)) on that fraction, tending to one. This proves a worst-case and average-on-uniform-YES lower bound, with constants depending on the fixed machine. No disjointness double-counting and no independent hard inputs for different cuts. For arbitrary fixed permutation of intact vertex blocks, same proof with c>=ceil(k/3), giving same exponent and different constants; no claim for arbitrary free input encoding. Proof is independent of running a particular machine and permits adaptive moves. Classical method, no priority claim.

Complementary read-once control: for a deterministic adaptive block-read-once branching program with a fixed finite node set, all accepting singleton paths must query every block (one-port flip at any unread block gives false acceptance). At a node reached after exactly floor(k²/2) blocks on accepting runs, the set A of prefix-read blocks is the same for all such accepted paths: choose a suffix from one, prepend another prefix. Until any attempted repeat the assignments to newly queried blocks can be chosen consistently to follow suffix; an attempted repeat would violate semantic read-once on that input. Thus suffix never rereads prefix blocks. Both sets have complementary fixed sizes, so the prefix sets agree. Splicing then accepts every hybrid, implying same crossing-edge pattern. Each node accounts for at most 2^(M-ceil(k/3)) YES inputs; at least 2^ceil(k/3) nodes are required. This shows why a bounded-step program can still have exponentially many possible states; a read-once scan with O(k) memory can take linear time. Node bound alone does not lower-bound runtime. No need for OR smoothing or rectangle enumeration. All statements scoped to complete actual program and promised singleton NO neighbors, not per-instance representation.

## 4. Adversarial transfer falsifier and information ceiling
On SAME input blocks and fixed boundary, a standard deterministic multitape decider can scan row-major and retain north-port expected bits from previous row on one work tape. At each cell, compare its north to stored bit and west to previous east, overwrite work bit by south. At row end require east zero, rewind the row buffer, at final row require every stored south zero. On top row initialize to zero. Exact parsing and dimension/row delimiters can be acquired with binary counters at O(N log N) bit time, O(k+log N) work bits, plus read-only input. Alternatively two work tapes maintain marked unary row lengths and row buffer with a fixed number of scans. Validate exactly one 16-bit table membership and external flags, reject mismatch; actual witness is unique. No exponential enumeration. The abstract row-buffer implementation was executed and independently checked, not an actual multitape transition program. This cheap operation uses an auxiliary tape to carry many bits across a physical input split without corresponding finite-state crossing symbols. Splicing two input-tape executions with the same control crossing sequence no longer splices the work tape, so the one-tape proof cannot be imported. Standard polynomial simulations between single- and multitape machines do not convert a fixed N^(3/2) lower bound to exclusion of all polynomial exponents.
A deterministic fixed-cut communication protocol for ANY Boolean decision function on N explicit bits can transmit the entire smaller side and evaluate locally, costing <=N+O(1) bits (local compute unbounded here). Therefore an argument based ONLY on distinct crossing transcripts forced by a single input bipartition cannot require superpolynomial bits of communication; summing this distinguishability charge over O(N) physical cuts cannot exceed a quadratic information tariff. This is NOT an upper bound on actual computing time; it isolates the missing computational-work invariant. Hennie himself discusses this limitation, pp577-578. Disjoint repeated equality families add costs, not automatic multiplication.

FALSIFIED generic time-to-low-overlap representation transfer: the easy singleton-consistency language has polynomial (even O(N) bounded-fanin block predicates with immediate AND overlap<=2) circuits from local equality, but L02/X01 show every small-cumulative-context circuit must obey s*sum_{j<=b} binom(k²,j)16^j>=2^ceil(k/3). For b=O(log N), any s=poly(N) violates this for large k. Therefore a generic polynomial-time decision-to-low-context compiler applying to every easy predicate cannot exist, irrespective of P versus NP. A per-input compiler that just outputs the decided constant is not one all-input fixed circuit. Even a full-grid decider can first check singleton inputs with the cheap row scan and otherwise exhaustively solve; this unconditional total algorithm disproves any compulsory exponential cost on every accepted singleton trajectory, not worst-case polynomial time on full grid. The more specialized conditional assertion that a hypothetical polynomial full-grid algorithm implies a small low-context circuit for full grid is still OPEN, not unconditionally refuted by an easy restriction. It would be a substantive hardness theorem, not a generic circuit simulation. Likewise matching, Gaussian elimination, bounded-width DP, and exact native seam joins are legal nonlocal terminals.
