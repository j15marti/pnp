## A: exact optimal tree metric

Define L(G) as minimum number of conflict leaves in an unshared binary original-variable branching tree, with full unit propagation at each node, no learned clauses or nonlocal terminal. Residual row domains are bitmasks over the live hole IDs. Row singleton closure assigns its only remaining hole, removes the row, deletes that column from every other row; empty row is contradiction. A true edge branch removes its row and column, false branch deletes just that edge. Exact equivalence to unit propagation of this functional PHP encoding. All residuals of the NO input remain NO. Thus L=1 on conflict, otherwise min over live edges of L(false)+L(true). Every tree has a first decision, and joining the two optimal children realizes the recurrence. All edges of duplicate rows are redundant choices under relabeling. Canonicalization enumerates column permutations at width <=5 and sorts rows, paying all enumeration; symmetry is used to compute the minimum, not to reduce the measured unshared tree. ## All-decider transfer obstruction and critical-edge control

No pointwise minimum over all total correct SAT deciders can prove a superpolynomial runtime lower bound: for each fixed NO formula F, a machine with F hardwired can compare the input to F, reject on exact equality, and run any correct general decider otherwise. On F its time is O(|F|) on standard sequential input; description length depends on F. A uniform lower bound must fix a single arbitrary decider BEFORE choosing the hard input, e.g. for each correct M, each fixed c and constant K, arbitrarily large F with T_M(F)>K|F|^c (for unrestricted worst-case separation; a NO-only family requires that stronger label restriction). For known uniform PHP family the matching/occupancy shortcut is one algorithm on all scales. Consequently the proposed transfer from optimal unshared refutation growth to arbitrary deciders is FALSIFIED.

For a genuine model-independent input-access lower bound in the explicit adjacency-bit matching control, take K_{n,n} minus S x T, |S|=floor(n/2)+1 and |S|+|T|=n+1. Hall certifies NO. Every missing edge when added individually gives a perfect matching: match its endpoints, match other S vertices into the complement of T, and remaining left vertices into other T vertices. Thus a correct deterministic decision algorithm must inspect each of the |S||T| absent input bits on that NO input, else the single-bit YES neighbor yields the same execution. This is Omega(n^2) bit inspections, not an exponential time bound. Executed all individual critical-edge witness checks on n=4,8,16,32,64: 6,20,72,272,1056 respectively. Matching sizes n-1; all negative labels have explicit Hall certificates. These minimal YES neighbors are falsifier checks only, not a SAT research track. This is an adjacency-input bound, not an automatic transfer to the CNF or native grid encoding.
