## A: acquire cyclic potentials from source alone
Construct a cell table of the active labels. A row is admitted in the zero-erasure dictionary if each cell contains exactly one label and the row is a permutation of all n colors. For each ordered pair of such rows a,b, form sigma taking the color at (a,j) to the color at (b,j), a permutation. If sigma is an n-cycle, assign lambda along that orbit from arbitrary color 0, so lambda(sigma(z))=lambda(z)+1 mod n. Set v_j=lambda(label(a,j)). For every row i compute the set D_i of residues lambda(z)-v_j over ALL active triples in that row. If it is a singleton choose u_i to be that value; if exactly two cyclically adjacent residues, choose the earlier of the two (n>=4 gives unique orientation); otherwise discard chart. Then every original active edge has independently checked w=lambda(z)-u_i-v_j mod n in {0,1}. No supplied hidden coordinates, no guessing an exponential joint assignment. Repeat on the transposed row/column projection.

For any such chart let delta=(sum_z lambda(z)-sum_i u_i-sum_j v_j) mod n. Let P be the bipartite support of positive-cost edges, collapsed only for computing capacity. If R_+ and C_+ are its nonisolated vertices, any projected perfect matching uses at most min(|R_+|,|C_+|) positives. If this bound < delta, reject; else UNKNOWN. The proof uses the same original active triples, not only the rows used to derive the chart. All negative conclusions sound for any admitted valid 3DM input, no completeness on arbitrary inputs.

Completeness on diagonal ladder: fewer than half the rows contain extra labels. More than half the cyclic row indices are clean; some ordered pair is consecutive in hidden cyclic coordinates (otherwise a subset with no adjacent indices has size at most n/2). Their sigma is translation by +1, so candidate lambda recovers hidden color numbering up to a constant, v and u recover the corresponding hidden coordinate potentials. This chart has delta=n/2 and positive support exactly the extras. The algorithm enumerates it unless a prior sound certificate succeeds.

## B: global capacity and equality-relaxation obstruction
The positive-support bipartite maximum matching has cardinality k. Its minimum vertex cover S,T supplies the stronger upper bound k on the number of positive edges of ANY projected perfect matching. A certificate consists only of lambda,u,v and S,T; check every positive edge is covered and |S|+|T|<delta. Maximum matching and its alternating-path cover can be acquired deterministically in polynomial work; no need to count matchings or solve exact-weight matching. The proof works even on noncomplete projections (then k may exceed actual maximum, still a sound bound). For our complete-base family the positive matching can be extended using base edges, so k is attained exactly. This genuinely changes A's representation: map each original triple to an exact 0/1 residual cost, then contract the entire positive support through one bipartite matching / vertex-cover certificate. Bound on positive capacity, not just the number of defective triples, is the operative invariant.

A strict scalar row/column dictionary is FALSIFIED on all partial cross stages t=2n-5. Only two clean rows, and two clean columns, remain; in hidden labels they are n-2,n-1. A pair yields only translation +1 or -1. For +1 chart delta=n/2 and |R_+|=|C_+|=n-2, so elementary bound cannot exclude. For -1 chart, the two residues in every dirty row force a shift of u_i downward by one; its base edges become positive and its extras zero, clean rows remain zero. Then delta=n/2+(n-2) mod n=n/2-2, row bound n-2 and column bound n. Again no exclusion. Same argument for transposed projection. Positive support cover of size two in the +1 chart succeeds. At full cross the zero-erasure dictionary has no admitted rows in either orientation, even with matching. This is an infinite scoped acquisition obstruction, not a time lower bound for all potential algorithms.

For every t>0, the signed integer incidence system and GF2 relaxation still pass. Reconstruct L03-21 proof: M_c selects (i,c-i,c) for all i, average these n matchings to obtain fractional exact count vector 1 with zero on extras. M_0 plus replacing its (0,0,0) by the active extra (0,0,1) gives color difference d=e_1-e_0. Swap columns c,c+1 at rows 0,1 of two otherwise identical perfect matchings to generate D_c=e_c-2e_(c+1)+e_(c+2), c<=n-3. The identity 1=n e_0+n(n-1)d/2+sum_c (n-1-c)(n-2-c) D_c/2 lifts to a signed integer combination of actual matching incidence vectors; differences have zero row/column incidence. Thus the entire incidence equality system is consistent over integers and all fields, despite exact Boolean NO. This proof is independently reconstructed algebraically; signed witnesses not recomputed numerically this run. No positive-coordinate LP claim for every extra. Linear equality-only and fractional-color-count obstructions cannot suffice.

## H: one-erasure reconstruction and proof of guaranteed acquisition
When full cross blocks every complete singleton row, admit a candidate row after omitting one column j*: all other cells must be singleton with distinct colors. Complete the row by the unique missing color, but require that color occur among active triples of the omitted cell. Do not remove that column or any edges from the eventual certificate. Try no erasure and each of n possible erasures in each orientation, all ordered row pairs, construct the exact same chart as A. Then apply B. This is polynomial discovery without a given dirty row, dirty column or label permutation.

More general theorem: for every relabeled cyclic Latin base of even order n>=4, retain all base triples, permit any subset of +1 defect extras supported on a vertex cover R union C with |R|+|C|<n/2 and min(|R|,|C|)<=1. The above algorithm (including transpose) certifies NO. Proof: transpose if necessary so |C|<=1. Omit C if nonempty. For every row outside R all remaining cells are singleton and form a partial permutation; the unique missing label is its actual base color and occurs in the omitted cell. Since |R|<n/2 there are two consecutive such rows in the hidden cyclic order. Their completed rows give the +1 shift, so lambda recovers hidden color residues up to an additive constant. v_j is actual hidden column residue plus constant; u_i from D_i is actual hidden row residue plus constant (every row has its base labels, so true defect 0 appears). The shifts cancel in delta because all three owner counts are n; indeed delta=n/2 mod n. Positive support has a vertex cover of size <=|R|+|C|. The matching/cover algorithm finds one no larger, yielding the strict exclusion. All steps depend only on input, not on known cover or order. In particular every stage of full cross with n>=8 is included. This extends supplied-potential range test to a source-only constructive acquisition theorem for a nontrivial family, not universal P=NP.
