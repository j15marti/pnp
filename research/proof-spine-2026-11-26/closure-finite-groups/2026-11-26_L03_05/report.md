## 2. Explicit address function and primary theorem
Input t truth-table bits x_a (a=0..t-1), and r disjoint groups of m bits y_{j,i}. Set z_j=XOR_i y_{j,i}, z=sum_j 2^j z_j, H_r=x_z. Tal, Shrinkage of de Morgan Formulae by Spectral Techniques, ECCC TR14-048 revision1 2016, https://eccc.weizmann.ac.il/report/2014/048/revision/1/download/ Lemma 7.1 says for every Boolean h, L(h composed with m-input parity on independent blocks)=Theta(L(h)m²). Thm7.2 specializes to Andreev. Original lemma page12 visual and proof/theorem text read. Fix x to a truth table of a function on r bits requiring Omega(2^r/log r) formula leaves by standard counting (at most (Cr)^s labelled binary formula trees of s leaves; compare 2^(2^r) functions). Hence L(H_r)>=Omega(t m²/log r)=Omega(t³/(r² log r)). Floor rounding harmless by Lemma7.1 for arbitrary m, no nonuniform input family construction needed: x remains variable in the original explicit function. No claimed proof of Tal's analytic theorem from our finite tests.

## 3. Constructive register strip with native exact-four cells
Maintain w=r+2 registers: r parity bits, scratch T, accumulator Q. Initial all zero. For each group input perform p_j <- p_j XOR y_ji in one row. For each a=0..t-1: reset T=1; for each j, T <- T AND (p_j if a_j=1 else NOT p_j); T <- T AND x_a; Q <- Q OR T. Finally require Q=1. This has s=2+rm+t(r+3)=Theta(tr) instructions including initialization/termination. Each input bit occurs in one instruction, one varying native table. At end Q=OR_a [z=a]x_a=x_z. Witness both directions by deterministic state induction, no existential shortcut.

Each row has w cells, one vertical track per register. Let P,Q' be incoming and outgoing vertical port (not accumulator notation); choose horizontal orientation as needed. A pass-through cell equates P=Q', fixes one unused port to its baseline, leaves the other free (4 words). A source cell for a two-track update copies P to Q' and toward the destination horizontally, fourth port free (4 words). Intermediate cells are independent vertical/horizontal crossing equalities (4 words). Destination imposes outgoing=f(incoming,horizontal), fixes remaining port0 (4 words), where f is AND, ANDNOT, OR or XOR. Every input-dependent unary update imposes outgoing=f(incoming,external-bit) and fixes one spare port0; other spare port free. For each external-bit value exactly four words, so each membership coordinate is a constant, input bit, or its complement; the two masks are distinct. Reset/initialization pins outgoing and one spare, leaves other two free; termination pins incoming accumulator1 and one spare, other registers simply leave vertical ports free with both horizontal fixed0. Each has exactly4. All nontrack shared edges can be zero, free east/west exterior zero, south exterior one, north zero. No hidden crossing assumption: independent crossing is itself an allowed explicit table.

Fold the s-row strip into L=ceil(s/H) lanes of width w and H=ceil(sqrt(sw)) usable rows. Odd-index lanes read vertically upward, even downward. Reserve w extra rows above and below. Lane j outgoing register column jw+i connects to lane j+1 incoming column (j+1)w+i at turn depth i+1. Use a vertical segment from each endpoint to its assigned turn row and a horizontal segment between the two. Distinct turn rows, distinct vertical columns; any interior crossing is perpendicular with no shared edge. Adjacent lane pairs use opposite top/bottom margins; on each side disjoint pairs use disjoint column intervals. At bends use equality wire on actual two ports with one unused baseline fix; crossings use two independent equalities. The endpoints are the actual strip ports. Last lane may terminate partway. Pad remaining cells with N=E=0, S/W free, valid with unused baseline and all exterior pins. Square side k=max(H+2w,Lw)=Theta(sqrt(sw)); total cells Theta(sw)=Theta(tr²). Every actual bit of the original encoded mask string is a literal or constant; dimension header constant for fixed r. The array-level layout generator uses O(k²) operations after explicit index arithmetic; turn paths O(Lw²) <=O(k²), each cell writes constant bits. On ordinary bit tapes a deliberately conservative fixed polynomial bound via sequential searches suffices. No nonuniform layout advice.

## 4. Formula lower bound and complementary constructive bypass
Take any De Morgan formula correct for every native exact-four input at side k_r, or computing total F there. Substitute each actual mask bit by its constant or literal. This does not increase leaf count; negating a substituted literal simply changes its polarity. By source equivalence resulting formula computes H_r. Thus minimum formula size >=Omega(t³/(r² log r)) = Omega(N_enc³/((log N_enc)^8 log log N_enc)) at these lengths. This is an arbitrary-depth formula bound, not an arbitrary-depth *circuit* bound. It also applies to monotone formulas for F. It is polynomial, not superpolynomial. No claim for the complete binary gate basis including XOR formulas, where Tal's theorem is inapplicable.

Adversarial bypass on identical legal projection family: recognize the fixed codebook using layout and each two-mask membership check, extract one input bit per variable cell, compute the r parities with balanced shared XOR circuits and select x_z with a binary mux tree. Both use O(t) binary gates (parity groups total rm, mux tree t-1) and O(log t) depth, including constant-gate XOR/mux implementation in AND/OR/NOT basis. Codebook membership adds O(N_enc) gates and O(log N_enc) AND depth. Uniform deterministic algorithm regenerates layout, decodes and checks masks, computes parities and selects addressed bit; no target witness, no free equivalence/count oracle. Ordinary multitape polynomial via explicit array simulation, simple direct scan in decoded chart, or native local port-domain closure O(N_enc) constant table updates plus index costs. All initialized registers are pinned, crossing transmits each track independently, deterministic gate/fanout propagates each next value. Thus NO contradiction at terminal and YES baseline spare-edge lift. This exact codebook membership+decision function is not F on other legal masks; no all-grid solver claimed.

Sharing-budget corollary: any binary fan-in De Morgan DAG with S internal gates and B=max sum log2(outdegree(v)) over paths from an internal gate to designated output (ignore output degree0; restrict to ancestors of output) has unfolding leaf count <=2S*2^B for nontrivial circuit. Proof: each input wire entering a gate appears once per directed path from that gate to output. Uniformly follow outgoing edges; paths to output partition probability, and each such path probability >=2^-B, hence at most 2^B paths. Count at most 2S input wires. For a circuit computing F at k_r, 2S*2^B >= c N_enc³/polylog N_enc. If S=O(N_enc), B>=2log2 N_enc-O(loglog N_enc). The same bound holds for circuits correct on projected family. This is a quantitative tradeoff, not a lower bound on arbitrary circuit size or machine time. Shared address bits and parity prefixes are cheap operations not forbidden by a polynomial time cap; B can be large even in linear-size DAGs. Do not infer an all-decider lower bound from mandatory sharing.

## 5. Reciprocal-series diagnostic (user issue comment 7201745672)
Let f_r=t³/(r² log r) for r>=2, source length N_r=Theta(t r²), t=2^r. This is a certified formula lower envelope, not actual optimal decider cost. Sum_r 1/f_r converges (geometric with poly factors), tail O(r² log r / 2^(3r)) after index r. Weighted series sum_r N_r^p/f_r has terms Theta(2^((p-3)r) r^(2p+2) log r); converges for p<3 and diverges for p>=3. If interpolate by integer lengths using f(N)=N³/((log N)^8 loglog N), the dense sum_N N^p/f(N) converges for p<2, diverges for p>=2; not a lower bound at unsampled lengths absent padding argument. Weighting by r instead of N_r incorrectly treats log input length as input size. The actual cheap decision upper bound is polynomial, and does not inherit any representation-size series. Independent of the known L02-05 all-p series for exponential restricted decomposable charts. No claim convergence implies unrestricted superpoly work.
