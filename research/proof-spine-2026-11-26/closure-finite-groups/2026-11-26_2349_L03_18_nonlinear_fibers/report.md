## Track A: local blindness and absence of translation periods
Each majority bit has 2^(b-1) preimages. Original width w becomes 2^((b-1)w) clauses of width bw. All original supports distinct because left degree >=3, and row and hole binary exclusions concern different pairs. Each expanded clause group with a fixed unsigned block support is exactly a Cartesian product of majority falsification fibers. Distinct original edge blocks have distinct unsigned clause occurrence signatures (different rows distinguished by row ALO, same row distinguished by cross-row hole AMO). Every block is touched by some support group.

For odd b, majority has no nonzero XOR translation period. Let t have weight s>0, h=(b-1)/2. If s>h, use zero word (majority changes). Otherwise choose a word of weight h supported outside t, possible since b-s>=h. Flipping t increases weight to h+s, so majority changes. Thus each fiber has trivial translation stabilizer. A global bitwise translation preserving the normalized signed clause set must preserve each fixed unsigned support group, and therefore each block projection of that group. Since these projections are the full majority fibers, each block translation is zero. This is a statement about the syntactic signed-clause set under bit flips, NOT the semantic Boolean function (which is constantly false), arbitrary coordinate permutations, or all feasible symmetries. For b>=3 the decoder is nonaffine, since a nonconstant affine Boolean map on b>1 variables always has a nonzero translation period. The previous L03-17 star-flip quotient cannot contract this family. No UP before 2b-1 pins since minimum width 2b; at least 2^(2b-1) leaves in explicit unshared branching trees. This local bound alone is polynomial for b logarithmic.

Infinite lower-bound lane: use degree-four regular bipartite bases with |N(S)| >= (5/2+delta)|S| for |S|<=epsilon*n, existence by Miksa/Nordstrom 2014 Thm9 (fixed 0<delta<1/2). Choose two holes with disjoint neighbor sets, possible for all sufficiently large n since each hole shares a neighbor with at most 12 other holes. Delete them. For |S|>=2, unique neighbors before deletion >=2|N(S)|-4|S| >= (1+2delta)|S|; after deletion >=2delta|S|. For singleton min degree3 gives same bound. Thus constant degree and linear-scale boundary expansion hold. Miksa/Nordstrom JACM2024 Thm5.8 gives exp(Omega(n)) expanded PC/PCR refutation size (degree > delta' s/(2d)); PCR polynomial simulation of resolution gives exponential resolution size too. Fix all but one majority share with equal numbers of zero/one to recover base exactly. Restriction cannot increase proof size in these models. If b is odd of order log2 n, explicit length N=O(n^5 log^2 n) bits. Therefore shared proof lower bounds remain superpolynomial in original N despite zero translation stabilizer. No claim that finite circulants are expanders or that semantic symmetry is absent. No unrestricted lower bound.

## Track B: source-only nonlinear decoder acquisition (general scoped theorem)
Normalize CNF, remove duplicate clauses, assume nonempty non-tautological clauses with distinct variable IDs per clause (ordinary easy special-case parsing for empty/tautological clauses). Bucket variables by exact unsigned occurrence lists. Each clause touches every variable of each bucket it touches. Group clauses by the set I of touched buckets. Interpret each clause as its unique falsifying word across these buckets, forming explicit finite set E_I. Project E_I to each bucket, obtaining P_{I,j}. By definition E_I subset product_j P_{I,j}; equality holds iff |E_I|=product_j |P_{I,j}|. Cardinalities are exact counts of explicitly listed distinct tuples, no enumeration of the ambient exponential cube or SAT oracle.

For each bucket j, choose any nonempty proper projection D_j from a rectangle-complete group. Partition its words into D_j and complement; orient the class containing the all-zero word as 0. In each complete group verify every projection is either D_j or its complement; complement test is disjointness plus cardinality sum 2^|B_j|. Keep only groups passing both tests; discard all others. If no group used a bucket, it is irrelevant to kept constraints. For every kept group, its original conjunction of blocking clauses is exactly the pullback of ONE quotient clause on the decoded bits, with signs determined by the forbidden class labels. Hence any original satisfying assignment maps to a satisfying assignment of the acquired quotient. If all groups pass, conversely every quotient assignment lifts independently by picking a member of each nonempty class (and arbitrary unused bits). This is an exact SAT-preserving projection without requiring any translation symmetry, affine coordinate change or supplied decoder. If groups are discarded, only the forward implication is guaranteed, and a NO quotient still certifies original NO. A quotient YES in weakening mode proves nothing about original SAT. For the clean majority family all groups pass and decoder is precisely majority because zero is class0. This theorem does not cover arbitrary overlapping blocks, or two different forbidden quotient tuples on one support unless an extra exact decomposition is acquired.

## Track C: hostile one-clause deletion and independent reconstruction
Remove exactly one expanded blocking clause from the first row ALO group. For b>=3 each affected projection still spans the entire majority fiber (each tuple value has multiple completions), but the rectangle product cardinality differs by one. Strict all-groups exact reconstruction fails. The safe weakening method discards that entire group. For b=1 the group is absent, not flagged (first experiment assertion failed by demanding a bad existing group; corrected and reran). Other groups are complete. The resulting quotient has n-1 positive rows; drop all clauses containing variables not in these remaining rows (sound weakening). The remaining formula is exactly functional PHP with n-1 pigeons and n-2 holes. Hence all damaged formulas are genuine NO. Because the damaged formula is a subset of the clean clauses, any resolution/PC/PCR refutation of the damaged formula also refutes the clean formula; thus the restricted superpolynomial bound holds for damaged asymptotic family too. The intact row/hole exclusions ensure a complete group covering each block, so signed-clause translation stabilizer is still trivial. This is stronger than merely masking a base with redundant affine variables: one complete-fiber quotient fails, but negative reasoning survives by exact local weakening. It remains a deliberately constructed masked matching class, NOT a new intrinsically hard general nonaffine core.

Independent audit uses generator edge IDs and majority truth values, not learned buckets or product projection sets: project every listed clause, verify it is an original base clause, count all distinct members and compare to 2^((b-1)w). It recovers exactly the same complete groups and identifies precisely one missing fiber. Another check exhausts all possible local bit translations for b=1,3,5,7,9, stops at first violating word; only zero period survives. Nonrectangular control with original clauses (a OR b), (!a OR !b), (a OR c), (b OR d) and majority3 masks: support of first two constraints has full marginal projections, not one rectangle, correctly discarded. This control is feasible (a=1,b=0,c=1,d=1 suffices), not included as a NO experiment. No universal rejection guarantee.

This is a source-only polynomial NO certificate; it uses no original graph or majority labels in the integrated path.
