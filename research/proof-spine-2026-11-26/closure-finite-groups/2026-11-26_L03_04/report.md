## 2. One-block literal universality (PROVED)
For every NP language K with fixed deterministic polynomial-time verifier V, for every input length n, take a Boolean circuit C_n(x,w) for V on fixed polynomial witness length (pad/encode length if needed). Circuit family polynomial-time generated by the usual deterministic time-to-circuit simulation; fixed machine and polynomial bound, not an assumed discovered bound. Normalize binary gates and unary NOT. Introduce one Boolean variable per gate, encode exact gate truth table by forbidding each inconsistent local tuple (at most four clauses for binary Boolean gate), require output=1. Include input variables x_i as ordinary formula variables u_i. For each external input bit b_i add one unit clause (u_i) if b_i=1 and (not u_i) otherwise, at a fixed dedicated clause position. Hence a fixed layout with one sign switch per external bit; formula has a satisfying assignment iff exists w with V(b,w)=1. A satisfying formula yields an actual accepting verifier witness, and any accepting verifier witness lifts through exact gate values. No model or SAT oracle supplied.

Reconstruct L02-03 grid compiler on this fixed layout. For each variable row i and clause column j choose R_h = {E=W,S=N OR h(W)}, with h=0, not W, W, 1 according to absence, negative, positive, or both signs. All four tables contain exactly four words (masks 0x8421,0x8424,0x8481,0x8484 respectively). Pad rows with h=0; pad columns by h=1 at first row and h=0 elsewhere. k=max(2,#vars,#clauses) and fixed N0/S1/EW free. Horizontal equality enforces one row value, vertical equality accumulates OR of literal satisfaction; bottom1 iff every clause satisfied. Conversely choose row values and column prefixes and lift every original port. Empty clauses reject and tautologies handled by h=1. Thus the fixed-size mapping M_n(b) has one varying cell per input bit, in the variable's own row and pin clause column. Only four membership bits differ between R_W and R_notW (two positive b_i, two negative not b_i); all others constants. Every input is exact-four, no off-promise loophole. K(b)=G(M_n(b))=F(M_n(b)). Output length O((s+n+w+1)^2) mask bits, generation polynomial, each coordinate constant or one literal. This is NP completeness under polynomially acquired literal projections with one varying block per external bit, stronger than a generic polynomial-time many-one reduction for depth-sensitive purposes. Nonuniform fixed polynomial-size verifier circuits yield corresponding nonuniform projections as well. No monotone projection claim.

Consequently any circuit class closed under literal substitution and polynomial length reindexing that contains F contains NP (nonuniform version as appropriate). No implication to a class without that closure. In particular any size lower bound on a concrete NP predicate in such a class transfers at the specified size scaling. Conversely this does not remove the depth/uniformity limitations of the original lower bound.

Balanced rails necessity: in ANY literal projection into D from the full Boolean cube, for each output block and source variable, the number of coordinates equal x_i equals the number equal not x_i, since toggling x_i leaves total weight unchanged. If a variable affects any block, it has at least one negative and one positive coordinate in that block. Thus a method merely fixing raw negatively occurring source variables to constants must fix every relevant source variable. Simplification may exploit cancellation; no lower bound on all simplification methods from this observation.

## 3. Linear-size native parity restriction (PROVED)
For every k>=2, order all k² cells row by row in a snake path (alternating horizontal directions; vertical edge at each row end). Include the north external port of the first cell and south external port of the last. At cell i distinguish predecessor/successor ports a_i,b_i. They are distinct. From the two other ports choose the smaller fixed port f_i in N,E,S,W order, fix it to its baseline bit: 1 if it is on the south exterior, otherwise 0. The other unused port unconstrained. For external label z_i choose the exact four-word mask defined by
  bit(a_i) XOR bit(b_i) = z_i; bit(f_i)=baseline(f_i).
There are two path states and two free unused-port states, so exactly four allowed words for each z_i. These two masks disjoint. Every input coordinate is constant0 or z_i or not z_i. All nonpath physical edges can be assigned0, all unused south exterior stubs1; all fixed extra bits consistent. Start path bit0 from north, end bit1 from south. For any solution path XOR telescopes to 1. Conversely if XOR z=1, assign successive prefix parities along the path and baseline unused edges, yielding actual original grid witness. Thus F on this legal literal projection equals odd parity on m=k² external variables, with N=16m+header. One z flip gives an exact-four SAT/NO neighbor, changing one original table.

For every fixed d>=2, any depth<=d unbounded-fan-in AND/OR circuit with literals at inputs (NOTs allowed at inputs; internal NOTs can be pushed to dual rails at factor<=2 with no increase in AND/OR layer depth) correct on D yields a parity circuit at the same depth, by literal substitution. Håstad's fixed-depth parity bound gives size exp(Omega_d(m^(1/(d-1))))=exp(Omega_d(N^(1/(d-1)))) (constant-length header for fixed k not a relevant variable). This is an actual F / promise lower bound for fixed depth, arbitrary overlap/sharing and NOT, not an all-depth monotone bound. Same applies even to unrestricted circuits of fixed depth with negations. For depth2 DNF or CNF, direct proof: a satisfiable term in parity DNF must fix every source variable, otherwise it covers opposite parities; each term covers at most one of 2^(m-1) YES inputs. Complement argument for CNF. So >=2^(m-1) terms/clauses in either case. On the grid a single term after substitution becomes conjunction of literals and constants; contradictions drop harmlessly. No approximation result about general SAT inferred.

Complementary constructive method on IDENTICAL source, no guard: recognize the two exact masks per known cell, derive their actual signed affine equations (pin and binary XOR), propagate boundary values along path. All NO instances detected by sound domain closure (queue per strict deletion) or signed parity union-find; all YES actual witnesses recovered. Unit propagation is complete here by the path argument; no target assignment given. Balanced XOR tree, or positive dual-rail combination (p,q)->(p0q0 OR p1q1, p0q1 OR p1q0), yields O(m) gates at O(log m) depth for this subpromise. Can also test exact codebook using two inclusion conjunctions per block (equal on D), then build its easy H upper completion A AND (B OR (codebook AND parity)). Thus native parity is an explicit unrestricted cheap bypass despite exponential fixed-depth LB. FALSIFIED any generic polynomial-size-to-fixed-depth conversion even for this native legal family.

## 4. Prime-modulus gate extension (PROVED scoped)
For any fixed q>=2 use m input bits u_i, q one-hot state variables s_{i,j} for stages i=0..m and residues j=0..q-1. At each stage enforce exactly one by one q-literal clause and pairwise at-most-one clauses. Pin s_{0,0}=1 and s_{m,0}=1. For each step i=1..m and j include
  (not s_{i-1,j} OR u_i OR s_{i,j}),
  (not s_{i-1,j} OR not u_i OR s_{i,(j+1) mod q}).
Pin u_i by the dedicated sign-switch unit clause as in section2. The constraints uniquely determine all states by actual prefix residue: if u_i=0 state stays j; if 1 state advances j+1. Conversely this state sequence satisfies every clause iff final residue0. Fixed q gives O_q(m) variables/clauses and grid k=O_q(m), N=Theta_q(m²); every varying input controls one cell, exactly four membership bits. Thus for any fixed prime p, choose q=3 if p=2, q=2 otherwise (or any other distinct prime). A polynomial-size constant-depth F family using AND,OR,NOT,MOD_p gives one for MOD_q under literal substitution. Razborov-Smolensky rules this out. Therefore F not in nonuniform AC0[p] for every fixed prime p. We use qualitative superpolynomial statement, not ambiguous quantitative exponent of scanned primary source, not composite-modulus ACC0 or threshold TC0. One input flip changes residue by ±1 and provides native YES/NO pairs. Fixed-q counter or balanced finite-state product is cheap in unrestricted P and NC1 (linear gates for fixed q, logarithmic depth), so this does not prove P!=NP. Actual decoded native CNF unit closure with pinned inputs determines onehot states; independent port-domain closure on ladder also rejects all negatives. No hard postclosure NO.

## 5. Adversarial LocalNOT audit (FALSIFIED generic implication)
External draft ornab74/p-vs-np paper_full_v1_0.md (2025-12-23, blob76a3d0964d1bde4e54b8eb6f8ccfbb66051aeb5a) explicitly defines LocalNOT(r) as each NOT input depending on at most r input blocks and leaves audit-soundness/uniform seed and restriction issues open. It is not an established proof. The literal definition alone is no circuit restriction: for any size-s Boolean circuit duplicate both output polarities of every AND/OR gate via De Morgan, NOT swaps rails, input negatives supplied by one local input NOT each. O(s+n) gates, all NOTs now LocalNOT(1) for ANY input partition into blocks. This is an exact compiler for arbitrary overlapping Boolean circuits on the whole cube, no special assumptions. Assume generic polynomial monotone conversion from LocalNOT(1) on monotone functions; apply to deterministic polynomial-time matching circuit, obtain polynomial monotone circuit for matching, contrary to Cavalar et al v2 (prior L03-03 exact theorem, rechecked unchanged). Hence local support of negation alone cannot give the desired all-decider bridge. The draft may need stronger audit conditions than its stated LocalNOT property; we do not claim all its other modules disproved. Random restriction killing every input NOT by fixing its underlying bit can kill all input variation; section2 balanced rail theorem shows this is intrinsic in fixed-weight projections. A proof must control surviving hard domain and nonlocal semantic dependencies, not just syntax of NOT gates. This is the cheap currently unhandled operation: shared complementary rails plus logarithmic-depth algebraic/finite-state composition. Same native parity family explicitly admits it, and matching gives whole-cube monotone hardness control.
