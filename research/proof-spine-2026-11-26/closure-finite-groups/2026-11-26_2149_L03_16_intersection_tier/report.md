## A/B: exact attainable violation theorem and minimum product certificates
For each original surviving clause define p_i as Boolean falsification indicator. A static intersection certificate is an explicit GF2 sum of distinct nonempty products p_J=product_{i in J}p_i equal to 1 as a Boolean function; no arbitrary variable multiplier, learned clause or product-of-sums gate allowed. Zero products and duplicate summands can be removed. Tier=max |J|, size=number of nonzero product terms listed. All source IDs and original guard preserved. This is L03-15's static model, not ordinary PC, NS, resolution, circuit or Turing machine complexity.

At each stage only one of A_i,B_i,C_i can fail: if x_i=1, exactly one of A/B fails and C true; if x_i=0, A/B true and C fails exactly when s drops 1->0. Two adjacent C failures impossible. Every nonempty pattern over alphabet {0,A,B,C} with no adjacent C is attained. Proof: assign x_i=1 exactly for A/B stages, a_i=0 for A and 1 for B. If C stages exist, let s drop at precisely those stages, and rise one stage before each subsequent drop; separation ensures no conflict, start1 end0. If no C exists, choose any A/B stage (nonempty) and let s drop just there, hidden by x_i=1. All other stages have no unrequested violation. Conversely every assignment yields such a pattern and cannot yield empty, by UNSAT proof. Thus exact attainable support is a hereditary set system with empty removed. This is a joint support theorem, not merely independent marginals.

General lemma: if the attainable nonempty violation sets form a downward-closed family after adding empty, every explicit identity sum_{J nonempty} c_J p_J=1 has c_J=(-1)^(|J|+1) for EVERY attainable J, over any field. Indeed at each attained P, sum_{empty!=J subset P} c_J=1; induction on |P| fixes each coefficient by binomial identity. Nonattained J yield zero product (any containing attained P would imply J attained), hence cannot assist. In GF2 all forced coefficients equal1. Conversely the sum over all attained J with these coefficients evaluates to 1 at each P. This proves EXACT minimum number of terms, not only lower bound, without a free enumeration assumption. The lower bound also covers arbitrary field coefficients but dynamic proof below is over GF2.

Let f_r count patterns including empty. f_0=1,f_1=4; classify by last symbol. Non-C ending has 3f_(r-1) choices. C ending has 3f_(r-2) choices (previous non-C). Hence f_r=3 f_(r-1)+3 f_(r-2). Exact minimum explicit products f_r-1=Theta(((3+sqrt(21))/2)^r). Exact minimum intersection tier r because all-A pattern attained, no pattern contains more than r clauses. In standalone encoding this is 2^Theta(N/log N) products. This strengthens preliminary 2^r-1 slice lower bound from audit.js, which remains valid but not sharp.
