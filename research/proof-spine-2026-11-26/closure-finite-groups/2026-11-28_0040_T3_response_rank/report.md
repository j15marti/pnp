## Theorem: response transport intersection and no rank renewal by cycling
Let S be an exact feasible boundary response in F2^b, A_d(S) its degree<=d vanishing subspace, P_d the squarefree Boolean polynomial space, and T a bijection from target coordinates to source. L(p)=p composed with T is a linear isomorphism of full Boolean function spaces. Define K = A_d(S) intersection L^{-1}(P_d). Then L(K) = L(A_d(S)) intersection A_d(T^{-1}S), by exact evaluation and bijectivity. Consequently lost source rank = dim A_d(S)-dim K; recomputed target rank outside the transported span = dim A_d(T^{-1}S)-dim K. Neither difference is a new original-coordinate deduction. Pull back target identities by T^{-1}, require original-coordinate degree and independent rank against a persistent root dictionary, not merely independent rank in the new chart. In particular if A_d(S) is already complete, every target identity whose inverse image has degree<=d is already in A_d(S); a round trip earns zero new root rank. Lost ranks remain stored in the root dictionary, never refunded. Affine and explicitly bounded-degree nonlinear maps with fixed d and coordinate degree e permit coefficient-space GE in polynomial work in b via O(b^{de}) squarefree basis; full response acquisition separate. Exact response given as table with b<=c log_2 N permits building evaluation matrix in poly(N), but acquiring that table can still be hard if interior is not cheaply solvable. In this experiment one interior bit, exact two-extension enumeration and independent reverse enumeration. The local response can replace all incident factors; all other factors retained, witness stored per row. No recursive global width bound.
