## A: constructive mixed-pin theorem
Let P and Z be disjoint sets of edges fixed respectively 1 and 0. If K_n,n minus Z has no perfect matching, all completions of the guard are NO, independently of P. Otherwise let C_L,C_R cover P union Z, t=|C_L|+|C_R| (minimum cover computable by bipartite matching). In K_n,n minus Z choose a perfect matching M maximizing a=number of M edges incident to C_L union C_R, equivalently minimize number of other edges. Delete from the free coordinate set all a matched pairs incident to the cover; let I,J be remaining rows, columns. m=n-a>=n-t. Make every P edge and every deleted pair's M edge constant1; make the I x J submatrix independently variable; all other edges constant0. No pinned edge lies in I x J; no fixed1 is in Z. This is a uniform literal restriction preserving every original pin, acquired by one weighted perfect matching plus cover.

## B: independent global proof of exact semantics
Any full perfect matching in an image graph is a matching of K_n,n minus Z and thus has at most a edges incident to the cover. All allowed edges outside I x J are incident to the cover (they are P or deleted M edges). Each deleted row has to use one such edge, giving at least a. If any retained row uses a deleted column, it would contribute another incident edge, contradicting maximality of M. So no retained row can leave I x J, and their matching is perfect there. Conversely a free perfect matching lifts by adding exactly the deleted M pairs. Thus Match_n restricted = Match_m for every free matrix, including m=0 (constant YES). No assumption that positive pins themselves can simultaneously be in a matching; they are available edges only. This proves a stronger common mixed theorem than independently treating P and Z. Independent alternate path interpretation: any directed alternating excursion from a free row through deleted pairs to a free column would replace a collection of incident-cover matched edges with one more such edge; close by free diagonal or the free reverse edge to obtain a better M in K minus Z. No such excursion exists. This is a source-faithful restriction theorem, not a new unrestricted lower bound.

## C: falsifier and independent reference
Naive removal with arbitrary M fails even n=3: P={(0,1),(1,0)}, Z={(0,2),(2,0)}, cover row0+col0, M identity. Remove pair (0,0), keep free 2x2 with only (2,2) available; free NO but full matching permutation (1,0,2) exists. Weighted M instead pairs 0->1,1->0 and leaves one free pair, both labels preserved. Exhaustive ternary pin patterns and independent permutation reference below verify this construction. Cover alone cannot replace the maximum incident-cover optimization.

## Integrated consequence for query networks
For any compatible guard P,Z, suppose each query either has A(R_i(top))=0, B(R_i(bottom))=1, or B(R_i(top))=0, with top/bottom the extremal completions of this guard. First case constant0; second case A; third case either constant0 if A(top)=0 or A times the fixed bit G(R_i(top)), since R_i(top) exact-four and any smaller image satisfying A equals it. This also handles queries already trivial before pinning. No global G oracle in this NONUNIFORM restriction argument: baseline bits are fixed constants, not assumed uniformly acquired. Thus if a valid guard of this type with feasible Z and cover t exists, all F queries can be eliminated after mixed restriction into a monotone circuit for Match_m, size O(S+Mtotal) where S counts all original outer and coordinate gates/wires and Mtotal is explicit membership bit volume. Thresholds are constant-size gates per table. By Cavalar et al. Theorem 1, 2^(m^(1/3-o(1))) <= O(S+Mtotal). For S+Mtotal<=n^C fixed C, every such guard must either block all matching completions or satisfy t>=n-(log n)^(3+o(1)). This quantifies over already compatible guards; no existence/selection assertion and no bound on arbitrary circuits. Positive and negative choices can coexist; union cover counted once. For uniform deciders no free baseline evaluation.

## Further complementary attack: GUARD-OFF-PROMISE acquisition
Decision problem: given explicit positive literal query maps, can one choose a compatible partial guard supported on a specified single row such that for each query one particular off-promise certificate (deficiency or overflow) is forced and K minus Z retains a perfect matching? NP membership: guess P,Z; evaluate maps at extrema, test A(top)=0 OR B(bottom)=1 for each map, run matching avoiding Z. Equivalently for existence a full assignment to the row can be used if all other bits of the maps are constants. Reduction from ordinary 3SAT with r variables: use edges (0,j), j<r, n=r+1, leave last column edge of row0 unpinned. Each clause is a 2x2 grid map with three literal cells and fourth fixed-four cell. Positive literal x_j uses four constant-one membership coordinates plus x_j as fifth; negative literal NOT x_j uses three constant ones plus x_j as fourth. Remaining coordinates0. Each map is positive literal-only. A literal is true exactly when its corresponding table violates exact-four, through overflow for positive, deficiency for negative. If a satisfying assignment exists, pin the r row bits; each clause gets a forced certificate and a matching survives via unused edge (0,r) and arbitrary other rows. Conversely any such guard ensures each query has a true literal in every completion; choose any extension, obtaining satisfying assignment. Cover<=1, original input bit length n² plus query maps polynomial in 3SAT input. Thus the specific simultaneous off-promise certificate acquisition problem is NP-complete, even with constant target grid size and positive literal maps. This is NOT a lower bound on deciding F, nor on choosing guards for networks promised to compute Match. Indeed these query predicates may be trivializable by other means, and no necessity of off-promise certificates for all simplifications was shown. Therefore the implication low cover => easy acquisition is not established and would solve SAT for this general guard task. This closes an otherwise free-search assumption.
