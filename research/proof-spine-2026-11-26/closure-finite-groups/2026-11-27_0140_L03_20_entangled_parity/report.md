## Exact image, restricted lower bound, negative proof

Conversely for any even-parity x and ANY common b assignment, set h_0=0, propagate h_(i+1)=h_i+x_i; cycle closes by even parity; set a_i=h_i+b_i*b_(i+1). No assumption based on stagnation. Both sides of the exact adapter proven.

Restricted obstruction: any conjunction of constraints each scoped to a PROPER subset of the q output coordinates and individually valid on Im(x) is tautological, hence cannot exclude the diagonal perfect matching. Any exact CNF for the image with no auxiliary variables requires 2^(q-1) clauses: every non-tautological valid clause must mention all q coordinates, else its falsifying subcube includes an even word. Each full-width clause excludes one odd word. This lower bound is tight by listing odd words. Explicit tuple listing also costs at least 2^(q-1) records for the positive image. ## Hybrid generalization: polynomial coefficient image + matching span
For an explicitly represented multilinear polynomial map f:GF2^d->GF2^q, f(z)=c+sum_(S nonempty) v_S prod_(i in S) z_i, its affine hull is exactly c+span{v_S}. Every output difference lies in the coefficient span. Conversely v_S=sum_(T subset S)(f(1_T)+c), by Boolean Mobius inversion; terms cancel except S. This formula is a proof of inclusion, NOT an instruction to enumerate subsets during acquisition. Directly read supplied coefficients and Gaussian eliminate; use guards by exact substitution. For fixed degree expanded coefficient representation is polynomial. A compact circuit may require expensive expansion; no blanket circuit-to-coefficient compiler claimed.

For bipartite graph with a perfect matching M0, let E* be edges occurring in some perfect matching (acquire by forcing each edge and matching the remainder, or SCC method). Let B be vertex-edge incidence mod2. Then aff_GF2(M)={z: z_e=0 for e outside E*, Bz=1}. Proof: contract M0 edges; nonmatching edge i->j is a directed arc between matched pairs. An arc lies in a directed cycle iff it occurs in an alternating-cycle swap, iff allowed. Keep arcs inside SCCs. For difference z+1_M0, row and column incidence constraints imply mod2 conservation of nonmatching arc bits at every contracted vertex; the matching-edge difference is determined by outgoing parity. Directed simple cycles span the mod2 circulation space on each strongly connected digraph: any edge label annihilating directed cycles annihilates all closed directed walks by decomposition. Choose root-to-vertex paths, using vertex-to-root paths to prove path weights well-defined; every label equals endpoint potential difference. Thus the orthogonal complement equals the incidence row space, proving the span. Each directed simple cycle lifts to the difference of an actual perfect matching and M0. This establishes both inclusions, no enumeration of matching set. Empty matching class is separately detected with standard Hall certificate. General graphs have related known Lovasz linear-span theorem, not needed for this proof.

Hybrid: intersect the decoder affine hull and matching affine hull by Gaussian elimination; empty intersection is a sound NO for every source whose exact or forward adapter is certified. For an image that is exactly one affine hyperplane, this test is complete for feasibility: if the affine hull of matching incidence intersects the hyperplane, some actual matching does, since otherwise every actual matching has the opposite bit and its affine hull does too. This is correct parity matching, not exact integer-weight matching or multi-parity matching. For general affine image codimension>=2, nonempty intersection is UNKNOWN. Hostile example on the SAME outer graph: the two incident edges e0,e_n never both selected, but attainable two-bit projections are 00,01,10; their affine hull is the full square. The target11 passes every single linear-functional feasibility check but is not jointly attained. This invalidates an extension of completeness to arbitrary simultaneous syndromes. A fixed single affine-hull certificate does not solve general SAT. No multi-bit NP-hardness assertion from this example.
