## 1. Owner-star modular projection theorem
For fixed s>=1, select at most s owners U from X union Y. Let S be all active edge IDs incident to U, and B=A restricted to columns outside S. Every projected X-Y perfect matching has H=M intersect S, |H|<=s. Enumerate subsets H of S with |H|<=s, pairwise disjoint X/Y endpoints, covering every U owner exactly once. Test exact extension to a projected perfect matching by removing chosen endpoints and all unchosen S edges, and testing remaining bipartite perfect matching. Parallel triples retain IDs; only for matching existence may their endpoints be merged. The exact modular projection of the relaxed incidence solution set on this same H is the system
    B v = b - sum_{e in H} A_e (mod 4).
All other S variables zero, H variables one, remaining coordinates arbitrary in Z4. If no attained H has a modular completion, return NO. Otherwise UNKNOWN. Sound: any exact cover supplies a matching and a Boolean completion, hence a surviving H. No claim that a surviving H is an exact cover, or that separate marginal witnesses glue. For s=1 all selected patterns are single incident edges. No SAT oracle. This is a negative-only hybrid: matching/owner geometry changes the modular domain from all assignments to actual bounded-capacity patterns; modular elimination replaces all character enumeration. Matching support is not essential on the family, where every tested one-edge pattern has support.

Solve Bv=d over Z4 by odd (unit) pivots and row elimination; remaining rows all even. If the transformed RHS is odd in an even row, inconsistent. Otherwise divide the even block and RHS by 2 and solve over F2, lift free variables and back-substitute unit rows. Factor B once per U, replay row operations for each RHS. Correctness follows by invertible unit operations and equivalence of 2a=2b mod4 to a=b mod2. Alternatively row/column unit elimination and then pivots of value 2 diagonalize to entries 1,2,0. This also proves the finite-ring annihilator criterion: d is in im(B) iff every p with B^T p=0 satisfies p^T d=0 (mod4); an odd RHS at a 2 pivot is separated by twice the corresponding transformed row, a nonzero RHS at a zero pivot by that row itself. Transform back to original rows. Thus polynomially checkable dual certificates exist per failed pattern and can be extracted in polynomial work, even with unbounded nullity. The executed code uses row factors and replay, not explicit extracted dual vectors; a separate generator-coordinate certificate covers all rejected patterns on tested family.

Cost: <=O(N^s) owner sets, <=O(N^s) patterns each. Explicit matrices dimensions O(N); dense modular elimination O(N^3) elementary constant-ring operations, matching via augmenting paths polynomial, RHS replay/back-substitution O(N^2), witness/check scans O(N^2). Conservative bit-RAM bound O(N^(2s+6)) including indexing, input parsing, failed owner sets and patterns, source replay and fixed number of replicas. Deterministic tape simulation incurs only fixed polynomial overhead; peak storage O(N^3) bits loose when streamed, cumulative <=time*peak. No free counting, canonicalization or preloaded geometry. Fixed s, not FPT or polynomial for growing s. Arbitrary hard caps return UNKNOWN. No exact bit-clock experiment; actual counts below partial.

## 2. Connected infinite NO family with exponential nominal character set
Fix block order n=12, number of blocks k>=1, q=12k. In each block retain all 144 cyclic triples (i,j,i+j mod12), all twelve +1 defects in row i=0, and progressively release +4 defects at diagonal cells (i,i). Cross-connect adjacent blocks h,h+1 by four triples: both orientations of row-0/column-0 cross cells, and both color-0 labels from those blocks for each cell. This connects the native incidence graph and projected row-column graph; no assertion of prime decomposition. All cross tuples have coordinate zero in all involved blocks. Independently permute the three owner label sets, keep parent IDs and guard all unreleased diagonal extras false. N=Theta(k log(k+1)) native explicit encoding with indexed labels. All live owner degrees >=12, initial ALO/AMO unit closure after guard deletion stalls. Certified negative deductions yield contradiction; no conditional fact exported as unconditional.

Authenticate: choose any one block. Potential p assigns -i to its X owner, -j to its Y owner, c to its Z owner mod4; all other blocks zero. Every base, +4 and cross edge has p^T A_e=0, and the selected block's twelve +1 edges have value1. These lie on one X-owner star, so at most one can be selected. Yet p^T b=-12*11/2=2 mod4. Contradiction for every release stage and every k. The very same p annihilates columns outside that star, and separates b-A_e for every incident e (residue2 or1); hence s=1 terminal is complete for this family. No hidden decoder labels are provided to starScan; the proof uses them only for independent replay. Order stars by degree; any highest-degree row is a contaminated row0, so first star succeeds here.

All-instance signed integer consistency: within each block a constant-color 0 row-column matching gives count vector n e0. Recolor its edge (0,0) to +1 gives a difference d=e1-e0. For c=0..n-3, swap columns of rows0,1 in constant-color c+1 matching, giving D_c=e_c-2e_(c+1)+e_(c+2). The identity 1=n e0+n(n-1)/2 d+sum_{c=0}^{n-3}[(n-1-c)(n-2-c)/2]D_c supplies an exact signed integer incidence solution by adding the signed matching differences. Row/column sums remain one; cross edges zero. Also fractional nonnegative solution via 1/n on each base triple. Thus strict linear consistency over every modulus, including mod4, cannot refute any stage. No claim of signed lattice hardness. Each individual +1 edge can be avoided by a column/color translation of the signed construction (other +1 edges retained); the star certificate is joint, not a claim of impossibility for any one Boolean value.

Old singleton character system over F2 has precisely 4k free bits. Per block row0 excluded (all cells ambiguous), cross cells ambiguous, all other rows have at most one missing diagonal. For same shift s, partial color translations from common singleton columns have domains >=10>6; overlap forces the same difference lambda(z+s)-lambda(z). For any z,s, choose row a with a,a+s not row0 and both cells singleton. At most 2 excluded row0 choices and <=4 excluded diagonal choices (solutions to 2a=z or 2(a+s)=z+s mod12), total <=6<12. Thus full translation domain covered for every shift; taking s=1 forces lambda(z)=alpha z+beta, u_i=alpha i+gamma for i!=0, and v_j=alpha j+beta-gamma (every column has singleton). Row0 free. Exactly 4 independent bits per block. No cross singleton ties them. Nominal enumeration 2^(4k)=2^Omega(N/log N), but this is count, not forced time. Both full Z4 linear solve and matching alone are feasible; the hybrid refutes.

## 3. Infinite hostile control against the corrected fixed-modulus terminal
PROVED WITH SCOPE, symbolic extension self-review only: for any fixed s, let n be a multiple of 8 with n>2s, and use the ordinary cyclic table with no added edges. UNSAT by modulus n: required residue n/2, all edges zero. For every U subset X union Y of size <=s and every attained H, the Z4 projection test above passes. Proof: let R,C be the omitted row/column sets (r+c<=s), I,J their complements. A dual vector annihilating B has potentials satisfying lambda(i+j)=u_i+v_j on I x J (sign convention p_X=-u,p_Y=-v,p_Z=lambda). Pair clean rows a,b; domains J+a size n-c>n/2, hence same-shift differences agree across pairs. For each z and shift d, choose a with a,a+d in I and z-a in J; at most 2r+c<n forbidden choices. Thus every shift is completely recovered, lambda(z)=alpha z+beta, u_i=alpha i+gamma on I and v_j=alpha j+beta-gamma on J (n alpha=0 mod4). On omitted owners potentials arbitrary offsets from these affine expressions. Extend affine expressions to all owners; each base triple has zero affine weight, global affine target is -alpha*n(n-1)/2=0 mod4 since 8 divides n. Offsets cancel in p^T(b-sum_H A_e) because H covers each omitted owner exactly once. So every annihilator gives zero; finite-ring dual criterion gives modular completion. This proves fixed s/mod4 incomplete even on arbitrarily large exact NOs and a fixed exact-cover source. Cheap bypass: reconstruct cyclic labels or use supplied coordinates and modulus n; in clean relabeled cyclic table all row translations are complete and a single n-cycle recovers coordinates in poly(N). No arbitrary-decider lower bound.

Additional source-sensitive barrier: unrestricted sparse syndrome feasibility A x=1 over F2 with Boolean x and weight<=q is NP-complete on the very same 3DM incidence matrices. Every owner has odd positive count, total incidence 3|x|<=3q, so each owner has exactly one and |x|=q. Reverse trivial. This is a direct reduction, not a claim about hardness of the dual-character search or about P!=NP. Increasing s to encompass all rows is exact decision, but cannot be assumed cheap.
