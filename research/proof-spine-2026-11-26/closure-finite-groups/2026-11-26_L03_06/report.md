## Track A, constructive extension
For any consistent partial assignment P of fewer than n distinct adjacency bits, construct both labels preserving P: NO graph contains only edges pinned1, fewer than n. YES graph contains every edge except pins0. The n cyclic permutations i->i+j mod n are pairwise edge-disjoint perfect matchings; each pin0 destroys exactly one shift, so a surviving shift supplies an explicit actual witness. Build both adjacency matrices O(n^2) operations, actual grid word O(n^2), verify. No SAT oracle. Pins of size n can force either label (one row all zero or a full diagonal all one). Thus the minimum certificate size over either output class of Match_n is exactly n.

## Track B, independent global contradiction
Hall theorem gives the same extension invariant by different reasoning. If the graph with only pinned-zero edges removed has no perfect matching, deficient S on left has at most |S|-1 neighbors. At least |S|(n-|S|+1)>=n edges must be missing, contradicting fewer than n zero pins. For positive certificate, graph with only required ones must itself match, requiring n edges. Thus no monochromatic subcube of codimension <n. This argument does not rely on the cyclic witnesses. Generalize: for any Boolean function h, write c_b for MIN over inputs of label b of certificate size.

## Track C, literal-map adversarial reconstruction
A map R from adjacency bits to fixed grid masks is a signed literal projection if each membership coordinate is 0,1,x_i,or NOT x_i, with repetitions allowed. For each cell acquire exact minimum and maximum weight by grouping signs of each variable: if c constants1, p_i positive and q_i negative occurrences, weight=c+sum_i q_i+sum_i(p_i-q_i)x_i. Min uses min(p_i,q_i), max max(p_i,q_i). No global enumeration. A deficient cell has at least 13 zero coordinates; preserve any 13 at an extremizing assignment, requiring at most13 distinct pins. An overflowing cell has at least5 one coordinates; preserve any5 using at most5 pins. These are exact local certificates, not merely hulls. For n>=14 the Track A witness preserving these pins supplies a genuine contradiction: deficiency yields YES input mapped to F=0, and overflow yields NO input mapped to F=1 PROVIDED global A always holds. Check all cells for possible deficiency first; only if none exists use overflow. If all cells constant weight4, each p_i=q_i by varying one input bit. Thus each variable occurring in a cell has both signs, and at most4 distinct variables occur per cell. All n^2 input variables essential for Match (permutation containing that edge vs deletion of that edge); omission gives opposite labels with identical image. Every correct signed literal projection consequently uses at least n^2 positive and n^2 negative occurrences, and at least ceil(n^2/4) varying cells. If all coordinates positive literals or constants, constant weight implies constant map; impossible. Diagnostic certifies a contradiction or necessary conditions, NOT correctness in the latter case.

## Integrated theorem (PROVED WITH SCOPE)
The above generalizes beyond literals. Let R be ANY fixed-shape map, and suppose each output coordinate at each input has a certificate of at most d_0 original input bits for a zero value and at most d_1 for a one value (in particular, d-juntas satisfy both with d). For ANY exact reduction h=F(R(x)), if c_0>13d_0 and c_1>5d_1, all R(x) belong to D. Proof: deficiency supplies a 0-certificate for h by joining 13 local zero certificates under the identical x; union preserves actual assignment and forces F=0, so contradiction c_0>13d_0. With deficiency impossible globally, overflow supplies a 1-certificate using five local one certificates, contradicting c_1>5d_1. This does not require independent output-coordinate supports. If R is coordinatewise monotone, R(0)<=R(x)<=R(1); each block has constant weight4, so both extrema and every image coincide. A nonconstant h is impossible. In particular for Match_n, monotone d-junta output maps cannot reduce to F if 13d<n, regardless of target grid size. The literal result n>=14 includes arbitrary signed projections. A second symbolic corollary for CLIQUE_t on v vertices: min 1-certificate >=binom(t,2); min 0-certificate >=v-t+1 (from complete graph remove fewer edges; delete one endpoint of each missing edge to retain t clique vertices). For t>=4 and v-t>=13, no positive literal projection. No CLIQUE experiment or hardness claim for a new narrower source.

## Further attack at stagnation: nonlocal maps
If R is monotone and A(R(x)) is identically1, h nonconstant with h(0)=0 forces R(0) exact-four NO. For any x with B(R(x))=0, monotonicity plus equal block weights implies R(x)=R(0); otherwise B=1 and F=1. Hence h(x)=B(R(x)). If R computed by polynomial-size MONOTONE circuits and target output length polynomial, this would give polynomial monotone circuits for h via thresholds of 16 bits and OR. For Match, Cavalar et al. v2 theorem1 excludes this. Thus any polynomial-size monotone reduction must have nontrivial A, hence at least one deficiency whose 13 local zero certificates have total union size>=n; some output coordinate must have zero-certificate size >=ceil(n/13) there. No claim all nonlocal monotone reductions impossible. The specific allowed cheap computation is decisive: ordinary augmenting-path matching gives a polynomial-time map whose single changing membership bit is Match(x), in the otherwise fixed all-zero-adjacency grid; on positive label add 0110 at first core cell, F accepts by overflow; on NO grid remains exact-four infeasible. This map as a function is monotone and exact for total F, but ordinary preprocessing uses nonmonotone operations and does not yield a cheap monotone implementation. It does not preserve the exact-four promise on YES and is not an admissible positive projection. A decision-first map can similarly select fixed legal YES/NO exact-four templates by complementary rails; not needed here. Currently unhandled arbitrary-decider operation: nonlocal computation/reuse of a global decision bit before encoding, or source-dependent nonmonotone rails. No generic lower bound follows from necessity of large local certificates.
