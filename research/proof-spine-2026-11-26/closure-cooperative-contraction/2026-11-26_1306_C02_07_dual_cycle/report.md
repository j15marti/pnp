## 2. DCP: dual-component projection (PROVED WITH SCOPE)
For each factor i, t_i is B=C occupancy and A quota r_i=e_i+t_i. Each shared B/C owner enforces opposite t values. Build the complement graph, propagate all local phase exclusions, reject parity inconsistency or empty support. This is union of even cycles (including length-two multiedge cycles), choose a gauge t_i=z_K XOR s_i for each phase component K, with z_K a common free Boolean or a pin. Fixed local phase leaves an exact choice of an A subset of cardinality r_i in {0,1,2}, over two distinct ports. If r_i=1, allowed singleton options are exactly those witnessed in its local table; if r_i=0/2 the only set is fixed. No marginal substitution.
Construct a SECOND graph on factors and actual shared A owners, ignoring BC links only AFTER the phase equations have been retained. Include physical A owner obligations even when local guards remove all support; zero supporting owner causes rejection. Each connected A component H has a set of factors F_H, owners A_H, and scope I_H of distinct FREE phase bits occurring in those factors. For a specified word u on I_H, evaluate the exact response R_H(u)=1 iff all A_H owners are covered once by selected local A subsets. This is an integral allocation flow (fixed phase capacity groups). Force quota r_i from source to each factor, allowed port arcs capacity1, owner sink capacity1, total quota must equal |A_H|. Saturation forces exact local support and all actual owners; converse from any local source cover. Retain one actual local original-tuple witness per feasible word.
Global cover iff there exists one common phase assignment z satisfying all R_H(z|I_H). Forward: take the restriction of a source cover, satisfying BC complement equations and every A component. Reverse: for each component select its stored actual witness at the SAME phase word, union over disjoint source factors; all A owners exactly once by component, all private owners by regional witnesses, all BC owners exactly once by phase complements across components. Original guards retained in exact tables. Existential compression, not exact model count or semantic forcedness. Components may share phase variables arbitrarily; their choices of internal A allocations are independent only conditioned on the common word, not unconditionally.
Fix c>0. When each h_H=|I_H|<=floor(c log_2 N), acquire the full table by <=2^h_H exact flow calls. Build formula consisting of every unary forbidden bit and binary forbidden ordered value pair. Verify equivalence to the full table by testing all 2^h_H assignments, NOT assuming the binary hull suffices. Empty table rejects; if formula admits any absent word, this binary terminal declines. In particular h_H<=2 always admits exact binary clauses. When every component is admitted, concatenate all exact clauses and solve once by deterministic SCC 2SAT. Witness reconstruction as above. h0 (total free phase bits) may be linear in N. This is more general than phase-island QPA3: A components may have high degree, and BC islands need not have small boundary or be matroidal.
For fixed chart at most O(N) components, aggregate flow calls <=sum_H 2^h_H <=O(N^(c+1)); each flow has polynomial bit cost, unary/binary projection/check O(2^h_H h_H^2) with straightforward scan, paid witnesses O(N) original IDs per row. Source-only fixed-size chart acquisition can enumerate connected tuple subsets of size<=5 (O(N^5) distinct sets), compute actual private owner sets and boundary, exhaustively enumerate local masks, try deterministic greedy cover, then verify partition, owner multiplicities, exact BC graph and all relevant conditions. Failure OPEN, not NP decision NO. Every chart attempt explicitly paid. No universal existence or acquisition of suitable partition proved.

## 3. Complementary two-state DP on exactly the same residual
When each shared A owner touches exactly two distinct factors, A graph on factors has degree two (two ports per factor) and is a union of cycles, including two-factor parallel-edge cycles. Traverse a cycle as f_1,...,f_l with actual A owner a_i between f_i and f_(i+1). Let x_i=1 iff f_i consumes a_i; then f_i consumes incoming a_(i-1) with bit 1-x_(i-1). For fixed global phases the exact transition test is whether
{a_(i-1): x_(i-1)=0} union {a_i:x_i=1}
is an actual allowed local A subset in factor f_i at that phase. Try both initial values of x_0, propagate reachable states x_i in {0,1}, require x_l=x_0, retain backpointer for a witness. This is a 2-state exact DP with at most O(l) transitions (explicit witness copies in executed code can cost O(l^2); charged). It computes exactly R_H of section 2 by a different method than integral flow. Proof by induction on prefix: reachable bit iff some consistent prefix allocation realizing it, with exact adjacent-owner complement; closing bit enforces final owner once. Fixed phases already enforce all BC seams. Tested both on same exact local masks and phase words. DCP also has a theorem-level high-degree flow extension; large executed native fixtures have A owner chart multiplicity two.

## 4. ZDP: zero-drift paired-cycle theorem (PROVED WITH SCOPE)
A long A cycle can depend on arbitrarily many BC phase bits; full R_H enumeration then fails the log cap. Instead use integer conservation:
x_i-x_(i-1)=r_i-1=e_i+t_i-1.
Suppose a cycle has an acquired partition into consecutive pairs (f_(2j-1),f_(2j)) such that each pair uses ONE common phase component and for every admitted mode its two quotas sum to 2. A sufficient native structural condition is opposite L/U types and opposite t in the same BC component. Pairing may be acquired by trying the two cyclic alignments and checking actual exact mode quotas; no unknown model or SAT witness is needed. Every pair has net drift ZERO:
x_(2j)-x_(2j-2)=0.
Thus every between-pair A edge in this cycle has the SAME bit x_H in oriented consumption coordinates. Introduce one explicit Boolean x_H per such cycle. For each pair acquire its exact joint response on (z_K,x_H), or x_H alone if the phase is fixed, by checking the two possible internal seam bits y. The first factor consumes incoming iff x_H=0 and internal iff y=1. The second consumes internal iff y=0 and outgoing iff x_H=1. Test against the exact guarded local masks, store native witnesses per attainable pair of values. There are at most four (z_K,x_H) words and two internal-bit tests each. This automatically gives a binary relation, no matter how many distinct phase classes occur in the full cycle. Add each forbidden word as a 2CNF clause. The between-pair seam variable is an auxiliary exact equality coordinate, not an affine hull of local responses.
All cycles may be treated by ZDP, by DCP with exact 2CNF verification, or a mixture of both. Correctness in both directions: every native source cover induces x_H constant because of the integer drift identity, its same global phase assignment and true local pair words; conversely a satisfying 2CNF assignment supplies witnesses to every pair/component. Adjacent pairs share actual A owner exactly once because one ends consuming x_H, the next begins consuming 1-x_H; internal A owner covered exactly once; BC owners and private owners handled as above. The graph may be abstract/nonplanar as a solver representation, not a claim of a native cap preserving embedding. Original native embedding and IDs untouched. The two-factor case with two parallel A edges also works: common between-pair bit is the single closing edge.
Contradiction proof of correctness: assume an accepted chart has a false YES; the chosen common phase and seam values plus stored pair witnesses construct a complete actual exact cover, contradiction. For a false NO, any actual cover induces all the binary relations, giving a satisfying assignment, contradiction. An absent pairing or nonbijunctive DCP response causes OPEN, not NO. No unrestricted availability asserted.
Generalization target: acquire balanced consecutive segments whose net drift is identically zero in all modes and whose exact joint response on common seam plus local phase coordinates is 2CNF. Fixed/log bounded phase count per segment permits paid table verification; arbitrary segment discovery/coverage still open. A zero drift for the whole cycle alone is insufficient (see section 6). The *local reset to a common seam* is essential.

## 5. Genuine infinite families, comparison and series
A. Native square-grid construction. For grid side k>=2, at each grid vertex create two consecutive factors (L,U) for each incident grid edge, in the cyclic order of incident edges. B joins each local pair, C joins successive pairs to make a BC cycle (even length 2*degree). For each grid edge uv create an A 4-cycle through its two endpoint L/U pairs, in order L_u,U_u,L_v,U_v. Internal A edge joins each pair, two distinct A edges cross the grid corridor between endpoints (opposite clockwise endpoint order). Draw BC cycles in disjoint vertex disks, paired A edge alongside the B edge, two A wires along each noncrossing edge corridor; hence factor incidence planar. At each factor use the actual C01-04 adjacent or alternating disk template for its cyclic order, with fresh private owner IDs. Distinctness follows from fresh private IDs. Equal L/U counts and conservation balance all three global owner populations (A shared count #factors, B/C each #factors/2; private L balanced, private U has one more B and C than A). Native graph/planarity independently checked at every executed scale. In an orientation L,U,L,U, each pair either has quotas 0,2 or 1,1, both feasible at common x=1; when both t_L=1 both seam bits feasible.
