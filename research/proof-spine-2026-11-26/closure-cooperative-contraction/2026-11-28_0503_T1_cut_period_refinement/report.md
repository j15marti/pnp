## Scoped theorem
Let Hz=b over F2 be the exact root chart with disjoint immutable conflict blocks. Inactive blocks allow all assignments, active blocks allow exactly the independent-set supports. In a fixed binary tree of blocks, define S_v as attainable syndrome set, U_v as span of all columns below v, V_v as span of outside columns, H_v as span of inactive columns below v. S_v+H_v=S_v, with tagged lift by GE on inactive columns. A root-consistent target u at v lies in U_v intersect (b+V_v), a coset of I_v=U_v intersect V_v (or empty). Therefore there are at most 2^(dim I_v-dim(H_v intersect V_v)) distinct target keys modulo H_v. At an internal split L,R, affine candidate left contributions are a coset of U_L intersect U_R. J=H_L intersect H_R acts freely on split candidates and preserves BOTH child feasibility tests by simultaneous addition, since characteristic 2. One representative per J-coset suffices, with at most 2^(dim(U_L intersect U_R)-dim J) candidates. Keep actual target and witness with tags; recover aliases via inactive-column solve. This is an exact split enumeration reduction, not just memoization. On admission H shrinks: version quotient keys locally, invalidate affected ancestor aliases, retain absolute NO because restrictions strengthen; retain a positive witness only after checking new restrictions. Guard changes require a new checked chart, never carry aliases blindly.
Each failed reconstructed relaxation witness satisfies all active owners; any violated original B4 owner lies in an inactive group. Admit its immutable block once. At most M successful corrections and M+1 completed exact relaxed solves; failures and storage charged, no renewed credit. Conditional complexity for polynomially acquired explicit dictionaries and tree: if maximum effective cut key width w AND sibling split width s are <=c log2 N at ALL reached versions, per version O(poly(N) * m * 2^(w+s)) work (all GE, exact basis conversion, witness tags, queries and reconstruction polynomial in chart size); M+1 versions. Storage of attempted absolute queries, witnesses, aliases and version data bounded by total work; cumulative memory <= total work times peak storage in serial, aggregate workers separately. Without BOTH width bounds, credit count alone proves no polynomial runtime.
