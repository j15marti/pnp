## Proof
Let disjoint groups D_i consist of original row IDs. E_ij contains every pair selected by any genuine source cover under the fixed guard. For distinct i,j,k put c(a,b;k)=|{u in D_k: (a,u),(b,u) in E}|. Remove (a,b) if c=0. If a cover selected a,b it would supply a selected row in group k, contradiction. Empty E_ij certifies NO, no LP or count oracle needed. Physical disjointness is a valid initial dictionary; signed lattice exclusions, rational-support zeros and other verified unconditional exclusions shrink it. This is classical binary path consistency; contribution is its source adapter and persistent cooperative accounting, not novelty of PC itself.

Initialize counters by scanning every possible third row for each retained pair. Queue zero-counter edges and certified imported deletions. When deleting e=(a,b), inspect each u in a third group. If both other triangle edges remain live, decrement their counters for the respective third groups once. This maintains exact common-neighbor counts. Every triangle is destroyed at its first edge deletion; subsequent deletions see a missing side and never double-charge. Each edge is deleted at most once and scans <=R third rows. Initialization <=R^3 candidate checks, subsequent total <=R^3. Counter records <=gR^2, logs/queue <=R^2. Indexed arrays give O(R^3) word operations and O(gR^2 log R) counter/ID bits, or an additional logarithmic dictionary overhead; deterministic tape simulation remains polynomial. No need to store all triangles. Keep counters live across imports if row IDs, groups and guard fixed. A new guard/chart requires new accounting; branch-only facts never imported unconditionally. Row deletion entails incident-edge deletion and empty/singleton/overlap closure checks. Alternative global proof: every path-consistent subgraph of starting graph survives each legal deletion; for fixed imported exclusions the greatest closed subgraph is therefore independent of fair order.

With <=R+R^2 permanent row/edge deletions and one stalled sweep, fixed paid module cap P(N) per sweep, total <= acquisition+(R+R^2+1)P(N)+poly(N,R). The path engine alone costs O(R^3 polylog R) word/bit-index work across the whole fixed dictionary, not per sweep. Charge LP/lattice acquisition, coefficient bits, verification, sharing, failed tracks, indexing, reconstruction, storage and duplicates. Sequential tape peak <=O(N+T), cumulative <=O(T(N+T)) on same execution. If total cap fails return UNKNOWN. No universal successful-sweep guarantee.

Guarded lookahead: enumerate choices of acquired pivot groups only when complete row-product is polynomial in original N; reclose every guarded copy and combine only when all branches are certified NO. Fixed k groups costs R^k, not automatically polynomial for k=log N. No cross-source transfer without an exact adapter.
