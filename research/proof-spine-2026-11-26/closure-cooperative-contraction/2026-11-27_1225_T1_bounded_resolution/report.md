## Named obligation: monotone antichain terminal, aggregate cost and refusal scope
Let F be the exact native residual conjunction on r live Boolean carriers after checked full incident bucket elimination and unconditional coordinate-support closure, with explicit local row tables and max acquired bucket width w. Extract every non-tautological clause of length <=a (a fixed, here 3) supported as a logical consequence of one factor: enumerate all partial assignments of <=a coordinates, test all rows for an extension, negate every forbidden partial word. This yields a weakening C of F. C UNSAT implies F UNSAT; C feasible is not enough to decide F. Negative certificate does not require exact reconstruction of all discarded nonlinear dependencies. Original-to-residual exact elimination and gauge preserve feasibility. No counting or semantic oracle. For fixed a and w<=c log N (c fixed), extraction O(m * sum_{j<=a} binom(w,j) 2^j * 2^w * poly(w,log N)) bit work on m explicit factors, including every failed support query. Source-only acquisition checks all candidate scopes.

Use resolution on C up to fixed width d>=a. Clause A subsumes B iff A is a subset of B as literal sets. Maintain active clauses as an antichain: on acquiring a new non-tautological clause, reject it if a previously acquired subclause exists, otherwise retire all active strict supersets. Keep immutable historical parent nodes and a dictionary of all acquired clauses; no deletion of proof ancestry. Process shortest active agenda first and consider opposite-literal pairs; index sets contain only active entries. One accepted clause, including a unit, can delete many active supersets, changing subsequent acquisition. Empty clause is terminal. Imported live clauses must be proved in same guard and carrier semantics; exact existential projection preserves a clause whose variables all remain live. Full parent proofs were checked before import; no final empty clause imported.

**Theorem (scoped, classical bounded-width saturation with charged antichain implementation).** For every explicit residual satisfying the acquisition assumptions and fixed d, this agenda terminates within a fixed polynomial in original N, or returns UNKNOWN when the experimental cap stops it. If exhaustive without empty clause, the final active antichain covers every non-tautological clause derivable from C in resolution width <=d (contains a subclause). In particular, it is complete for the existence of such a width-d refutation of C, not for arbitrary native infeasibility.

Proof of soundness: initial clauses true on F by direct row test, imported clauses have checked parents and identical live guard. Each resolvent follows from both parents. An active clause retired by a strict subclause remains valid in historical proof; its active replacement implies it. Thus every historical clause has an active subsumer at any nonterminal stage (follow strict inclusion chain). A discarded candidate has a historical subsumer and hence an active one. At uncapped agenda exhaustion, any pair of final active clauses was considered when the later of their processing events occurred; each was present then and never retired. Its width-eligible non-tautological resolvent is therefore subsumed by a final active clause. Induct on an arbitrary width-d resolution proof: for both parents use active subclauses. If a subclause lacks its pivot, that subclause already subsumes the target resolvent; otherwise resolve the two subclauses, giving a width-eligible subclause of the target, and use closure. A weakening step is likewise covered. For a non-tautological target, the subresolvent is not tautological. Tautological proof lines can be removed or replaced by a subsuming non-tautological parent for a non-tautological inference. An empty target demands an empty active clause. Contradiction proves restricted completeness. This argument is independent of ordering, not an all-input progress guarantee.

Aggregate ledger: let L=sum_{j=0}^{min(d,r)} 2^j binom(r,j) possible distinct non-tautological clauses. At most L historical acquisitions and L retirements, at most L agenda pops plus stale pops charged once to each insertion. Opposite-literal candidate pairs counted at most twice per pivot, O(d L^2), plus stale snapshot checks bounded by the same order. Each candidate subset test enumerates <=2^d subsets, canonicalizes at polynomial bit cost; each accepted clause tests at most L supersets and deletes <=L index memberships in total times d. A conservative bound O((B + d L^2) * 2^d * poly(d,log N)) indexed bit operations with deterministic dictionary overhead, where B is explicit base candidate count, plus extraction, source authentication, bucket cost and verification. Use deterministic sorted trie or balanced tree (not unproved worst-case hashing); JS Map in finite runs only. Historical proof storage O(d L log(N+L)) bits plus queues, snapshots and indices of comparable size. Charge verification separately including all base row checks, proof parent lookups, import proof replay, trim traversal and serialization; all are polynomial in explicit histories. Cumulative memory <= aggregate serial bit-time times polynomial peak space, not a measured memory value. If d=O(log N) instead of constant, L can be N^{Theta(log N)}; cannot treat this as a logarithmic exponential kernel. Fixed d and acquired logarithmic bucket width are distinct sufficient parameters. A fixed-width cap cannot imply universal success.

Counterexample to arbitrary partial-clause extraction completeness: two explicit five-coordinate factors with opposite parity have empty intersection, but every restriction to <=3 (even <=4) coordinates has an extension in each factor. The extracted clause set is empty, regardless of resolution width; exact Gaussian elimination refutes these factors. This is an abstract control, not a new authenticated native instance. The underlying width-sensitive resolution enumeration is classical (Ben-Sasson/Wigderson), not claimed new; contribution is the acquired native terminal, persistent deletion tariff and measured cooperative benefit.
