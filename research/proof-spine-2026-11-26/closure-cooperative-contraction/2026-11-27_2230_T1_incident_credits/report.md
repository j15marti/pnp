## Scoped theorem and short refusal
Fixed acquired CNF D, r variables, L initial literal occurrences, fixed learned width w; Q=sum_{i<=w}2^i binom(r,i). Maintain root UP closure and initialize consistent guards lazily. Copy current root closure once, apply guard, retain state until contradiction or exhaustion. Each clause stores unassigned count, XOR of unassigned literal codes, already-satisfied flag. Each assignment touches each incident occurrence once; each admitted row installed once per currently live context. Future contexts copy current root closure, not historical versions. Deterministically prioritize pending conflict admissions before initializing next guard; each accepted clause is negation of a refuted guard, admitted once. At exhaustion each candidate either already present or has consistent closed extension. A closed partial assignment extending guard, with every clause satisfied or >=2 unassigned literals, proves absence of UP conflict by induction on any unit derivation. No semantic satisfiability claim. In particular min distinct-variable width >=w+2 implies every <=w guard itself is closed; no new width-w RUP deduction. RANDOM's ungauged 368 width4 clauses/41 variables exhibit exact refusal (3363 guards), confirmed by independent exhaustive guard check; gauge reduces to 184 width3 clauses/40 variables and 173-step checked RUP proof. Global complement preserves every signed edge, E4 and B4; hence pinned UNSAT discharges gauge. A gauge clause lifts to two complementary guarded clauses of width at most w+1; not a free unconditional width-w inference.

For K<=Q admitted rows, charge one initialization/copy per guard, at most one installation and one incident update per possible row occurrence per context, one assignment per variable and one retirement; queue/dispatch/scheduling costs included. O(Q*(L+Kw+r)+Q log Q) word events, polynomial storage O(Q*(L+Kw+r)), plus polynomial checking and certificate extraction; deterministic bit simulation polynomial for fixed w and polynomially acquired explicit chart/map in original N. No context reset, arbitrary clause removal or chart change. Aggregate cumulative space bounded by T*S for serial implementation; concurrent memory summed separately. Falsifiers repeated literals, unsupported imports, weakening guards/rollback, changing chart or unbounded width without separate credit. This is scoped budget/refusal, not universal terminal coverage.
