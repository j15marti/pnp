## Connecting lemma: three signed projections
For any balanced explicit planar-incidence 3DM, erase one shore and suppress degree-two tuple vertices, then merge parallel projected edges, retaining all original tuple IDs. Each of the three projected bipartite simple graphs is planar. Choose one common ordering for each owner shore. If any lacks a perfect matching, reject. Otherwise for each pair ab compute a Kasteleyn–Percus edge signing eta_ab in {0,1} (1 means negative) and one projected perfect matching M_ab. Define k_ab = parity(permutation M_ab) + sum_{e in M_ab} eta_ab(e) mod 2.

Every actual projected matching has the same signed parity k_ab. Proof: assign face equations sum_boundary eta = length/2+1 mod2 for bounded faces, with multiplicity of edge traversals. A dual spanning tree solves these equations bottom up (one root face omitted per connected component; bridges count twice). A matching implies even vertex count in each component, so the root equation follows from Euler as well. For an alternating simple cycle C of length 2k between two perfect matchings, all vertices strictly inside C in the component are matched internally (boundary vertices already matched on C). Let I be their number, E and F count edges and bounded faces in the disk. Summing face equations gives sum_C eta = E-k+F = I+k-1 mod2 by Euler. I even, hence k-1 mod2. The permutation parity changes by k-1 under this alternating cycle. The changes cancel. Symmetric difference decomposes into alternating cycles; treat connected components separately. This proves coherence without enumerating matchings.

For any native cover, its induced bijections obey sigma_AC = sigma_BC composed with sigma_AB, so the three ordinary permutation parities sum to zero. Thus every native Boolean cover x satisfies the additional GF2 row:
sum_t [eta_AB(t_AB)+eta_BC(t_BC)+eta_AC(t_AC)] x_t = k_AB+k_BC+k_AC (mod 2).
Parallel tuple IDs share their projected edge sign but keep separate native variables. This is necessary, not sufficient. Add it to original occupancy equations, all guarded known rows and rational/lattice support closures; inconsistency is sound NO. This is a genuine matching/geometry-to-algebra adapter: it uses the parity of actual matching bijections, not affine hulls of all odd-degree edge sets. No need to count matchings or acquire all matchings. A signed row acquired on a guard is valid on its descendants with proper substitution; do not import it across unrelated guards.

## Infinite-family negative terminal
For s=3q, grid coordinates 0<=i,j<s, triples are exactly the two triangles of each unit square along the (i+1,j)-(i,j+1) diagonal. After affine shear to a triangular lattice, the two-color projection is an induced subgraph of the infinite honeycomb graph (remove one of three colors). Every edge between retained two-color vertices in the square appears in at least one triangle. Every bounded projected face is an original hexagon: a bounded cycle lies inside the convex coordinate square, and every infinite honeycomb vertex/edge strictly inside it is retained. Thus all-positive signing satisfies all bounded face equations. This also follows directly from alternating-cycle Euler proof with 6F=2E-2k giving I+k-2F=1 and k odd.

Partition the square into q² disjoint 3x3 blocks. Each block admits each individual projected matching. In row-major per-color order within one 3x3 block, A=[00,11,22], B=[02,10,21], C=[01,12,20]. Matchings A->B [1,0,2], B->C [1,0,2], A->C [0,2,1] are valid, each odd. Translations by multiples of 3 preserve colors and edges. Use block-major order on all shores: each projected permutation is a block sum, with parity q² mod2. A common reordering of a shore changes two of the three parities, so their sum is order invariant. Therefore q odd gives sum 1, whereas any native cover would give 0. The family s=6h+3 is NO for every h>=0. The same rectangle obstruction is known from ribbon tromino tiling literature; see Junius–Nitica 2017 Lemma 2.2, using Conway–Lagarias invariant. Our scoped contribution is the explicit three-projection sign adapter and tariff for arbitrary native planar 3DM, not discovery of odd-rectangle nontileability. No need to recognize lattice coordinates in general algorithm: compute planar signs directly. For grid recognition, a supplied coordinate map is checked against original IDs/vertices/triples; unknown maps not free.
