## 1. OWNED-TARIFF lemma: a paid recursive plan, with duplicate requests
Fix constants c>=2 and a>=0. Each task has a complete syntactic key (original indexed scope, exact active guard, immutable deduction/representation version, module/query/output semantics, including weights when used). Equality is literal equality of canonical encodings, no semantic equivalence oracle. Each has positive integer acquired mass m<=N^b, from declared original tokens or a certified common potential. A root receives m^c credits. Normalize work units to an explicit polynomial bit clock N^a times a constant, covering local preprocessing, exact module checking, candidate discovery, failed tracks, all kernel invocations local to this expansion, key comparisons, request emission and backpointer/lift work. All local work including any reserve for final join costs at most one such unit per expanded node, or use the explicit weighted variant below. Abort with OPEN on cap exhaustion, not NO.

At a node let its proposed children be groups of exact subquery keys with positive mass s_i<m and at most q_i *new distinct* keys in group i. All duplicate edges, rejected proposals, or requests to completed/in-flight keys still paid locally; deduplicate by comparing full keys. Admit only if sum_i q_i s_i^c <= m^c-1. Reserve the node's one unit, debit each new child exactly once, retain unused credit or discard. No funding from a cached hit. A pending hit depends on the same immutable task and must respect a strictly decreasing common dependency order (e.g. mass); do not recursively evaluate it again. Finish a child before using its result; DAG sharing can use deterministic DFS with memo and pending-state check, or a topological evaluator. A changed guard is a new task unless an exact interface table already covers it. No eviction/recomputation for free: either retain or fund it anew as a new expansion. Polynomial storage follows from bounded number of keys and polynomial per-entry representation. Every emitted dependency edge and every access is charged; no uncharged key lookup, hash collision or arbitrary isomorphism. Linear scan exact dictionary cost can be absorbed into a fixed larger polynomial clock using global admitted task bound; alternatively use deterministic trie. Include all stored messages, proof obligations and original witnesses in key-size and work cap. DAG semantic correctness is inherited only from separately verified exact composition and terminal routines, not from accounting.

Constructive amortization: total credits of pending funded but unexpanded tasks plus spent units never exceeds root m^c. Each expansion consumes at least one, funds children from remainder; all work including unsuccessful tests and final aggregation is charged. Therefore <=m^c expansions and O(N^a m^c) bit work (choose a after charging dictionary and verification); peak space <=poly(N) plus retained keys/tables within work bound; cumulative memory <=(T+1)S in same sequential bit execution. If recursion has multiple roots/projections, fund them from a single root or explicitly polynomial initial sum. Weighted variant replaces 1 by acquired local tariff w(v)>=1, check w(v)+sum new credits<=m^c; local work <=N^a w(v). Fixed polynomial bound on initial credit remains sufficient.

Minimum-counterexample check: on unfolded exact computation tree, assuming every proper smaller call satisfies W(s)<=s^c normalized units, an admitted least-mass violating call has W(m)<=1+sum q_i W(s_i)<=m^c, contradiction. DAG amortization is stronger when reuse is genuine; proof by unfolding would overcharge shared descendants if the check discounts in-flight keys, so use credit proof for that case. No new mass on chart switch: changing potential is allowed only by explicit transfer inequality into same credits. Choosing a different progress measure each round without transfer is invalid.

A non-tautological sufficient tariff for disjoint owned interiors: if sum_i s_i<=m-1 and q_i s_i^(c-1)<=m^(c-1), then sum_i q_i s_i^c <= m^(c-1)(m-1) <=m^c-1. If sum_i s_i<=m, all s_i<m and q_i s_i^(c-2)<=m^(c-2), then sum_i q_i s_i^c <=m^(c-2)sum_i s_i^2 <= m^c-1, since positive strict interior sizes imply sum of squares <m^2. Exact integer checks, no logs or floating rounding. This permits q_i=2^k_i kernels on small shores when their size shrinks enough, but disallows multiplying nearly-full-size recursive calls by poly(N) repeatedly. Example m_i<=m/2: only constant q_i funded at fixed c, not arbitrary N^epsilon. A local exponential kernel of k<=K log2 N bits costing poly(N) is harmless if entirely solved inside one paid node; if its outcomes spawn dependent recursive calls, the distinct child tariff applies. Budget checking is not universal semantic coverage. A source-faithful mass partition and discovery of a passing contraction remain obligations; no oracle-supplied potential.

## 2. RANK-RECONVERGENCE lemma: exact compressed contexts instead of repeated guard histories
General CEC chart: finite-domain edge colors y_e in {1,2,3}, nonaffine factors all-different at each vertex and consistency with actual phase bits x_i of fixed flow chart (FP20), literal color pins and optional exact unary costs. General Boolean finite-domain factors of bounded arity also fit this lemma but no cross-source hardness transfer. Affine guards A x=t explicitly encoded over F2. Construct nonaffine primal graph only; all factor scopes appear in bags of a verified tree decomposition. Acquire candidate bag plan by deterministic polynomial generator (ordinary log treewidth acquisition via Korhonen theorem is a sufficient width-only method; no claim it finds a rank-optimal plan). Convert to rooted binary tree by duplicating bags, assign each nonaffine factor to exactly one bag containing its scope and each affine variable's column contribution to exactly one owning bag containing that variable. Explicit original IDs and unique ownership; factor cost paid once. Every bag variable assignment is actual value, not marginal. Width of full mixed graph with row vertices not required.

For subtree S of bags let I_S be owned affine variable IDs there, U_S=span columns A_i for i in I_S, V_S=span remaining columns. Let C_S=U_S intersect (t+V_S); if t not in im A reject this chart by Gaussian elimination. Otherwise C_S is an affine coset of dimension lambda_S=rank(A_I)+rank(A_complement)-rank(A). Acquire by Gaussian elimination in polynomial bit time, including particular solutions/bases, not by enumerating all attainable rows. Retain message keyed by actual shared variable values on separator (intersection of child/parent bag) and actual syndrome z=sum owned A_i x_i in C_S. For each key retain existence, or minimum of attained additive binary-encoded integer cost with actual backpointer. A possible syndrome is necessary, not sufficient. Never replace attained states by the whole coset. The table is exact for local partial witnesses satisfying local predicates and the necessary seam condition.

Compute bottom-up: enumerate actual current bag assignments, evaluate locally owned factors, add uniquely owned affine contributions, join the two child messages with matching separator values, XOR child syndromes, filter by C_S, minimize or store one witness for each resulting key. Empty leaf/root handled directly. Full syndrome t required at root. Soundness: child witnesses agree precisely on shared variables by running intersection, so union is a true assignment satisfying all owned local factors; contributions add once. Completeness: any admissible parent partial witness has child syndromes in C_child because t+parent syndrome lies in span outside parent and the contributions of other child/current owned columns lie outside that child; hence t+child syndrome belongs to the complementary span. Every global solution passes all such filters, induction retains a feasible witness per key; for optimization a cheaper witness with the same key can safely replace the old one. No multiplication of independent histories; no dropping live guard correlations. Recover original colors by backpointers, verify all original vertex and guard constraints. Decision and optimization distinct; optional sum-product counts exact assignments for this owned-factor scheme if all child combinations unique and all variables counted once, but no count of source colorings is inferred from phase counts.

Let d=3 or fixed finite domain bound, B=max bag size, L=max lambda_S, K=number of bags. Key count <=d^B 2^lambda_S, even if total guard rank linear. Cost bound <=P(N)[1+sum_S d^B product over its at most two children of (1+2^lambda_child)] if messages indexed by separator values (full scan safe with d^(3B) instead). Includes rank computation for all cuts, failed entries, sorting/indexing, local factor scans, exact integer bit costs, actual backmaps, verification and reconstruction. Thus <=K 2^{O(B+L)} poly(N); with fixed log caps and polynomially acquired K, full terminal is deterministic polynomial. More generally test the actual aggregate tariff (not product across levels); an isolated larger parameter can be allowed if actual paid volume bounded. Dense invertible row operations transform every partial syndrome by the same invertible map, preserving all lambda_S and attained state counts; row count alone is not the relevant cost parameter. Arbitrary rank-small guard discovery is not proved. For a sequence of closures/alternative charts, version each plan, cap polynomially many attempts per strict source deduction (O(N) color/tuple/word deletions or separately charged polynomial new fact set); all failed attempts paid, reapply certified unconditional closure after strict deduction and at stagnation. If no productive step and all bounded terminals decline, OPEN. This terminal can be placed wholly within a paid scheduler node, or use explicit table/key tariff; do not count both as free.
