## Lemma T1-Q: factor-generation tariff
Let F be an explicit finite Boolean factor conjunction, n live variables and m initial factors, maximum initial and permitted full bucket width w>=1. Signed equality BFS solves x_p = y_root XOR s_p, rejecting inconsistent signed cycles; each B factor enumerates at most 16 distinct local carrier words and retains exactly integer balance. Merge identical factors by exact scope and row comparison. In the empty guard all relations are complement symmetric, so choosing one gauge is safe (any model has a complement model with chosen carrier zero); not permissible for an arbitrary already fixed guard.

For a variable v, form ALL incident factors B_v and U=union of their scopes. Replace them by one exact factor on U minus v, with membership OR over t=0,1 of AND over B_v evaluated at the corresponding word. Each residual model extends to at least one v, all original models project; save original factor IDs, scopes and old rows for reverse witness reconstruction (or regenerate at charged cost). Delete tautological factors only after exact table equality. If a factor has no rows, contradiction. If a coordinate has a single supported bit, pin it everywhere and remove that coordinate from every incident factor. Reclose after each accepted projection; an untouched factor previously examined cannot acquire a new coordinate-level consequence except through a new restriction, so queueing only new/restricted factors is equivalent to a full repeated scan for this exact named local support rule. This is not semantic backbone closure.

Count a new factor FAMILY at initialization or a bucket output; restriction of an existing factor is a new version of that family. At most m+n families are born, since each bucket elimination permanently removes one variable. Each family has at most w+1 versions: each restriction strictly lowers scope size, never creates a wider version, and bucket elimination ends the family. Each version has at most 2^w rows. Charging a full coordinate scan of every version costs O((m+n)(w+1)^2 2^w) row-bit inspections, and O((m+n)(w+1)2^w) allocated row words; indexed representation overhead, queue slots, deletions and sorting are polynomial in N,w and the table sizes. Every variable is eliminated or pinned at most once in a single exact contraction run. Full candidate discovery is by scanning incident lists, checking actual union scope, no oracle. At most n such rounds plus one unsuccessful scan; each round examines <=n variables and <=m active factors (factor count nonincreasing), with polynomial per-index bit cost. Each accepted join enumerates <=2^w words and checks at most m factors, including rejected candidate words. Even a linear membership search adds only another 2^w factor, hence total poly(N) for w<=c log2 N, c fixed. Verification reconstructs all full buckets and all forced pins; reconstruction stores at most polynomially many factor versions and reverses the exact existential tests. Peak and cumulative memory: full saved version storage bounded by O((m+n)(w+1)^2 2^w log N) bits up to polynomial index overhead; cumulative memory at most charged serial bit-time times peak storage. An arbitrary cap can yield UNKNOWN; a greedy width refusal is not proof that no good order exists.

Global branch caveat: this is one residual path, not a recursive reset. For at most B=N^d (fixed d) paid branch nodes across all replicas, each with width <=c log N and explicitly bounded factor/certificate sizes, total cost <=B*poly(N) plus charged acquisition/verification and communication. Enforce global credit before each operation; return UNKNOWN on exhaustion. Does not prove every NO yields such a branch tree. Direct amortization by versions and contradiction argument agree: if more than w+1 versions of one family exist, some pin failed to remove a scope coordinate or a bucket birth was misidentified, contradicting definitions. No assumption of universal cheap contraction.

## Lemma T1-L: live-coordinate import
Let R be an exact existential projection of gauge-restricted native relation S with acquired forced pins retained in its trace. If S entails clause C and every variable of C remains live in R, then R entails C: otherwise a model of R falsifying C extends to a model of S, contradiction. Therefore adding C as a small exact table cannot remove a real residual model. A different gauge or a clause containing retired variables does not satisfy this premise; a verified adapter or guard discharge is required.
