## Exact recursive template language
Call a fine cover whole-edge if all 12 interior vertices of each coarse edge are covered by triangles on the same coarse side. Every interior vertex belongs privately to a macroface. In a macroface, the 66 private interior vertices have equal numbers of the three colors (cyclic barycentric coordinate permutation rotates the colors, since 13=1 mod3). Each whole owned edge adds four of each color. Every elementary triangle is rainbow. Therefore among the three distinct-color coarse corners a macroface must cover all three or none: color count balance leaves no proper nonempty subset. If it covers a corner, the unique elementary triangle inside the macroface touching that corner requires both adjacent edge interiors; all three corners require all three edges owned. Thus a whole-edge cover induces a coarse face cover, and each selected coarse face must own all its edges. Conversely, any coarse cover and ownership choice consistent with this condition yields a fine cover if each macroface has a local exact cover of its assigned vertices. All nine unguarded states (8 edge masks for unselected, all edges for selected) have independently executed constant exact cover certificates, with counts 22,26,26,30,26,30,30,34,35. Define recursively restricted language H_i at frequency b*13^i: H_0 all native base covers, H_i whole-edge covers whose induced coarse cover belongs to H_{i-1}. This is an exact decision/witness algorithm for H_i with guards, a sound positive terminal only for native P3DM. It is not a count-preserving reduction.

## GUARD-CONE-TARIFF: full proof
Given literal guard support S_i on fine triangles at level i, acquire A=parents(S_i) using the actual 169-to-1 face maps. Let B=A union its face-dual neighbors. E is the set of coarse edges incident to A. At most 3|A| edges, |B|<=4|A|. On each guarded macroface acquire all 9 exact feasible local states by bounded exact search of 169 candidate triangles, checking all actual fine guard IDs, retaining one local witness per feasible state. This is a fixed constant-size problem (even if worst constant very large), not a SAT oracle. Enumerate every coarse selection word sigma on B and every ownership assignment on E consistent with sigma: if both adjacent selected reject, if one selected assign to it, otherwise either side. Test each affected macroface against its exact local table. For a successful ownership assignment, query H_{i-1} with all literal pins sigma on B; one query per sigma suffices because the exterior depends only on those selected bits, not on which viable ownership word was chosen. If child has witness W, assign all remaining edges to selected adjacent face if any, else deterministic first face. Unguarded macrofaces admit all needed nine states. Lift exact local witnesses and verify full original occupancy and all original guards. Conversely a guarded H_i witness induces one of the enumerated sigma and ownership words, with exact local support and guarded H_{i-1} child; induction therefore cannot miss it. This proof by construction also gives a minimal-level counterexample contradiction: a first lost valid template witness would induce a successful local word and a smaller lost valid child, impossible at exact base. If all branches fail, H_i-NO only. Native exact-one propagation can reject true native contradictions independently; propagation pins are consequences of explicit original guards and need not enter child key support, otherwise locality would be lost. No template failure generates native forced facts.

Key geometric result: recursively define S_{i-1}=B from support only, not assignments. Each fine face centroid lies in 13 times its unique coarse parent. Every macroface has coordinate ranges <=1; distance in L-infinity between its centroid and a point within it <=2/3. Adjacent coarse triangles share two vertices; their centroids differ by <=2/3. For a seed face f, every descendant support face after j coarsenings has centroid within R_j of centroid(f)/13^j, where R_0=0, R_{j+1}<=R_j/13+4/3, hence R_j<=13/9. Each vertex of such a face is within 2/3 of its centroid. All vertices lie in a box of radius <=19/9<2.5, so at most five integers per coordinate, <=125 vertices. Each sphere vertex incident to <=6 faces, and every face contains three vertices: at most 250 faces per seed. Thus all supports |S_i|<=250h for h original guards, including poles and facet junctions. This is independent of depth; use actual acquired supports for the tariff. It is not merely a bound on the number of paths.
