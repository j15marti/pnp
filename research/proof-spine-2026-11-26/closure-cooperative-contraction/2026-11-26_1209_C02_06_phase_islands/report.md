## Lemma QPA3 (quota-preserving phase-island absorption)
For C01 chart factor i, e_i=0 for L={0,13,14}, e_i=1 for U={1,2,15}, mask bits 1,2,4,8 on A0,A1,B,C. The phase t_i is B=C occupancy. Its A consumption is exactly e_i+t_i. Each shared B/C owner requires XOR=1 between its two factors. The B/C multigraph is union of two perfect pairings, hence even cycles (parallel edge pairs allowed). In every feasible complete component K, sum_i in K t_i=|K|/2, independently of the phase bit. Restrictions by actual local literal guards can remove a mode but not change this quota. If odd complement cycle, incompatible pins or empty local response: reject. This proof also extends to C01's discharged double-A seams if the remaining free classes retain its proved equal opposite-phase population invariant; executed solver uses whole original BC components BEFORE seam elimination, so does not rely on that extension.
Represent each full phase class as a block with one or two modes, each a list of exact fixed-cardinality groups over actual A owners. In each mode each original factor has rank 0,1,2 over its two distinct A ports and exact local mask witnesses; an allowed set has a witness satisfying private owners and original pins. Whole block quota q_K=sum e_i+|K|/2 is fixed. Previously absorbed blocks have one mode and one exact fixed-cardinality group over <=3 actual A owners, with a witness per allowed subset. Group private data/history disjoint; A owners may have arbitrary incidence degree. The maintained state requires all remaining A owners exactly once. Unattainable incidences can be excluded from connectivity but an owner obligation must never disappear merely because it lost all supporting incidences (then reject).
Choose union J of complete blocks. Let U be A owners in their support, P=owners in U that have support also outside J, I=U minus P. Every local cover must cover I once, some subset X of P at most once. With Q=sum fixed block quotas, conservation forces |X|=Q-|I|=r. If r outside [0,|P|] reject. Let h_J count two-mode blocks in J. For each candidate X of size r, enumerate the 2^h_J assignments to block modes; for each, solve the exact fixed-group allocation by integral flow covering I union X. Retain one actual original witness for each feasible X. This produces EXACT existential boundary support R, not a marginal or hull. If R empty no global solution. If not, and |P|<=3, replace all blocks of J and internal obligations I by ONE single-mode group with support R, retaining P obligations and original witness maps.
Why each <=3-owner constant quota relation is a capacity group: let D=intersection of members of R, V=union. Rank0 or full rank is fixed. Rank1 allows precisely singletons in V (unless singleton fixed). Rank |P|-1 allows precisely complements of the actually allowed omitted elements; equivalently all fixed D plus a uniform selection of r-|D| from V-D. For <=3 this exhausts all cases. Therefore any allowed set is precisely D union Y with Y subset V-D and |Y|=r-|D|. Create a mandatory bucket quota |D| and optional bucket quota r-|D|, arcs to actual owners with capacity1. Use source->bucket capacities, owner->sink capacity1, and prohibit edges to owners outside chosen target. Total quota must equal target size. Integral saturated flow iff exact group selection and target coverage; converse maps each original selection to flow. Labels distinguish local groups even when owners shared. No weights/count preservation claimed.
Exactness: every global cover determines local phase modes and a boundary mask in R, so contraction retains a solution. Conversely every reduced solution chooses one mask in R; use the stored verified original witness, disjoint from outside private IDs and complementing all boundary occupancies. Inductively all original tuple IDs, guards and shared B/C constraints preserved. Materializing one actual witness per retained mask may discard other local covers; no assertion of semantic forcedness or all-model/count preservation. The solver representation is a group/flow constraint system, not a newly claimed native planar replacement. Original native embedding unchanged; no need to embed artificial flow arcs in it.
Constructive method: exact phase sum -> local integral flow -> constant-size capacity representative -> reverse original witness. Contradiction method: suppose a minimum free-block-count admitted instance is decided incorrectly; the first exact contraction gives identical decision and strictly fewer free blocks; terminal exact flow enumeration is correct, contradiction. This is a proof of correctness within admitted computations, not universal admission.

Q(k)=actual number of local flow queries for the admitted schedule is Theta(k): all weighted reciprocal sums k^p/Q(k) diverge for integers p>=0. This is a source-realizable separation between exponentially growing compatibility entropy and linear count of flow invocations. Count and time remain separate; full paid time bound above polynomial. With <=O(N) steps and each work <=N^c P(N), normalize by N^(c+1) P(N) to get a uniform bounded finite sum. No false infinite-convergence inference from a finite sum.
An exact complementary series criterion: for a specified uniform correct halting decider D, set F_D(n)=max(1,max time on inputs of length <=n). It is nondecreasing. D has a fixed polynomial cap iff there exists positive integer p with sum_{j>=0} F_D(2^j)/2^(pj)<infinity. Forward: select p above cap exponent, geometric sum. Reverse: finite sum bounds each term, and for 2^(j-1)<n<=2^j monotonicity gives F_D(n)<=2^p S n^p. Equivalently for non-dyadic series, there exists p with sum_n F_D(n)/n^p finite (choose p>a+1; converse bounded terms). This is the reciprocal of the normalized speed n^p/F_D(n), not the reciprocal of work alone. Thus P!=NP iff for EVERY correct uniform decider of an authenticated NP-complete language and EVERY positive integer p these direct normalized work series diverge. This exact quantifier reformulation avoids requiring eventual superpolynomial growth (the earlier all-p inverse series criterion is sufficient but stronger). Neither side proved; cannot infer from an upper bound on runtime, a restricted representation, sampled sizes without monotonic fill, or a deliberately slow solver. This provides the user-requested reciprocal method a precisely scoped meaning.

## Adversarial four-owner limitation
A constant quota alone is not sufficient at four effective A boundary owners. In the actual 40-triple diagonal prism, take the four L factors as one complete BC island. Negative tuple pins (3,0),(5,0),(13,0),(15,0) in the Python original ordering each suppress one A choice while retaining zero and the other triple mask. Exhaustive local tuple tables give exactly two feasible occupancy masks on the effective four A labels: {0,4} and {2,6}. Other physical A ports have zero support in the island, not discarded global obligations. Global native guarded instance YES by independent exact-cover witness. Opposite masks disjoint, quota2; exchanging one element of first with either element of second gives neither allowed base, violating matroid base exchange. Hence no exact single partition-capacity representation on these same labels. This is a local guarded representation obstruction, NOT a claim about global all-model support or computational hardness. Wider islands need other relation types, exact decomposition or a productive paid alternative. No witness-derived guards used for main family solver; the four pins are explicitly constructed adversarial local restrictions.
