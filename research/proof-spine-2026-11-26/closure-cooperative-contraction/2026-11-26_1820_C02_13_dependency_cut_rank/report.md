## Exact dependency trellis
Split a private k-dimensional block t from exterior y. For each touched affine forbidden event, row-reduce private columns to independent L_i and RHS h_i(y), exterior-only trigger G_i(y); r_i>=1. Untouched events remain. Stack L, R rows, acquire a left-nullspace basis Q, delta=R-rank(L). w=Lt+h(y) is realizable iff Qw=beta=Qh(y), because ker Q=im L. Each active block must have w_i nonzero, inactive permits all words. Scan rows block-contiguously, keeping partial syndrome and one nonzero flag within current block; check flag at block end and reset. End at beta. Store actual prefix word or predecessor, reconstruct w then Gaussian-solve Lt=w+h(y). Verify original events and source. Exact decision/witness search, not unrestricted counting.

At row cut P,S let U=span columns Q_P, V=span columns Q_S. Feasible unrestricted partial syndrome lies in U intersect (beta+V), a nonempty affine coset of dimension lambda=dim U+dim V-delta, since U+V=GF2^delta. Acquire suffix bases; prune a transition if beta+partial syndrome not in V. At most 2^(lambda+1) live states, including current nonzero flag. All true witness paths survive; local checks remain exact. Induction on prefixes or earliest erroneous pruning gives correctness. Same state has identical future obligations, so retaining one actual prefix is sound. No free equivalence queries.

Primal identity: kernel of Q restricted to vectors supported on P is im L supported on P, dimension rank(L)-rank(L_S). Therefore rank(Q_P)=|P|-rank(L)+rank(L_S), similarly S. Subtract delta: lambda=rank(L_P)+rank(L_S)-rank(L). Greedy order tries every remaining whole event and minimizes next boundary lambda via primal ranks; tie by original index. Verify all row cuts in chosen order. This is a hybrid: primal rank ordering changes dual trellis domain; O(q^2) rank-pair tests, each explicit Gaussian work polynomial. Fixed-y bit work poly(M)2^lambda_max using deterministic sorting/maps, M current explicit residual length. If lambda_max<=c log2 N, terminal polynomial regardless of total q,k,delta. Greedy has no universal width guarantee.

## Exact guarded projection
Let eta be rank of exterior linear forms in every trigger and beta(y). Choose independent basis M_ext, enumerate 2^eta attainable observations, Gaussian-representative y for each. All y in observation fiber have identical active flags and target. Run cut terminal; output one forbidden affine event M_ext y=z for each NO fiber. Exact existential projection, replay on actual y. Cost poly(M)2^(eta+lambda_max), at most 2^eta events of eta rows. This is productive if k>0 and actual row tariff passes; no enumeration of all exterior words.

Alternative compiler when delta is small but eta large: for active event set A, H_A is left dependency subspace supported on A rows. Let J be block support of H_A. All dependencies on A already supported in J, so im L_A factors as im L_J times full cube on A\J rows; choose nonzero residual independently in each omitted active block. Coverage depends only on J. Enumerate distinct H_A by starting full dual space and repeatedly intersecting with vanishing-coordinate equations of an excluded block, canonical bases/visited set. At most 2^(delta^2) spaces (padded basis matrix bound). For each space take its J, enumerate syndrome values, check all J active by block DP. Output forbidden affine event consisting of all J triggers and failing syndrome equality. Sound under extra active events; complete by actual A,J. With unconditional triggers evaluate full set only. Connect blocks sharing a basis dependency; all dependencies are component-supported sums, hence im L factors across components; evaluate independently, combine residual words and solve one original L. Compiler poly(M)2^O(delta_max^2), or poly(M)2^O(delta_max) unconditional, where delta_max largest component dependency dimension. Thus arbitrary q,k allowed under sqrt-log or log dependency cap, respectively. Replay all original events, including any previously screened from cover test.
