## 2. Exact chart reduction and signed quotient theorem
For each oriented A cycle, x_i=1 means region i consumes outgoing A owner; incoming occupancy is 1-x_(i-1). B/C graph parity gives t_i=z_K XOR s_i, or a fixed phase t_i. Local A quota r_i=e_i+t_i, e_i in {0,1}, hence integer x_i-x_(i-1)=e_i+t_i-1. The local exact allowed relation F_i consists of at most eight bit words on (z_K,x_(i-1),x_i), omitting a fixed phase, and one original tuple witness for each word. The same global z_K and x_i are shared; every native solution restricts to these relations and every satisfying joint word selects local witnesses that cover all private owners and all three shared colors exactly once. Thus equivalence in both directions. No marginal union or count assertion.

Reduce each integer identity mod 2: x_i XOR x_(i-1) XOR z_K = e_i+s_i-1 (mod 2), or omit z_K when pinned and change RHS accordingly. Equivalently compute the common row parity directly from each actual table. Form the augmented linear system E over F2. Every feasible native assignment satisfies E. Gaussian elimination either proves inconsistency, or expresses each original chart coordinate v as an affine function l_v(y)+b_v of acquired free coordinates y. If l_v=0, pin v=b_v. If l_v=l_u, then v=u XOR (b_v XOR b_u). Use one existing representative for each nonzero homogeneous form. These are necessary signed aliases, not arbitrary directions in an affine hull. Record proof by reducing each candidate equality/constant against the original augmented row space, independently of the elimination that discovered it.

Substitute the verified aliases into EVERY exact original local table. Keep one row precisely if its coordinates agree with the signed map, and carry its original witness. Verify every substituted table by exhaustive reduced rows (scope <=3 here), testing the corresponding original row and witness. In particular do NOT replace a table by its affine hull, even if all coordinates have affine expressions. Apply exact unary support closure to the resulting factors. A contradiction in the necessary system or an empty attained factor proves native NO. Otherwise all original joint satisfying assignments induce quotient assignments. Conversely any satisfying quotient word lifts via the signed map to a word satisfying each original local table and hence a native cover. This remains true even though the quotient solver need not separately enforce all other Gaussian equations: they already follow from the exact original tables. The proof preserves decision and existential witnesses, not the number of native witnesses. Changes of guard require rebuilding or proving implication of the guarded alias certificate; no facts exported across incompatible guards.

Constructive track A: exact join/project bucket elimination on the raw factors. At each step collect ALL factors containing a chosen variable, enumerate every word on the union of their scopes, keep only attained assignments, existentially eliminate that variable, and store one value for each retained word. Reverse chronological lift proves correctness. B: global necessary parity quotient, then local exact bijunctive admission and SCC 2-SAT only if every table equals its unary/binary projection hull. Otherwise B declines. C: independent actual phase allocation flow, with fixed 64 phase-word cap, and independent augmented row-space membership checks (set symmetric difference, opposite pivot order, every original row parity verified). If C exhausts the cap it declines, not NO. Integrated: import only C-verified signed aliases and exact substitution from B into A, reapply exact unary closure, execute same bucket width cap. Independent full small-source recursion tests both labels. Contradiction proof: if integrated YES were false, verified original factor witnesses would construct a native cover; if integrated NO were false, an original cover would project through every attained bucket and survive, contradiction. ## 3. Complete tariff and series analysis
Let L=O(N) acquired chart variables, M=O(N) initial factors (fixed template region size). No representation expands beyond original scopes in signed substitution; one merged factor per bucket, at most L strict eliminations. Fix constant c. Admit bucket union size b<=floor(c log_2 N), INCLUDING eliminated variable. For each admitted step, full 2^b candidates are paid; no free attained-prefix oracle. Bound number of trials sum_i 2^b_i <= L N^c. Factor scan and membership, failed min-scope candidate scans, exact table projection and reverse witness pointers are polynomial overhead. An attempted too-wide bucket stops that lane without enumerating it. Acquiring parity rows, rank, aliases, independent augmented membership certificates and exact local row checks is polynomial by dense bit Gaussian and explicit sets; O(N)-bit coefficients and addresses; no huge integers. Initial exact-one/all-three projected perfect-matching support closure is polynomial (at most O(N) strict deletions), includes actual guard validation and planarity. Source-only greedy fixed-size chart candidate scans O(N^5) subsets times fixed polynomial, but this lane's general chart acquisition was not executed; test charts supplied and verified. Use a fixed-clock or finite fixed polynomial chart enumeration, not a free chart oracle. A failed acquisition is OPEN.
