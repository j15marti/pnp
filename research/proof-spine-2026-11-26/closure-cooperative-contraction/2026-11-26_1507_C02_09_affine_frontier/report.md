## 2. Exact constructive theorem (HAF)
For explicit finite Boolean factors F_i on scopes X_i, with complete exact rows R_i and original witness maps, choose a paid order 1..s. No assumed bound on arity except explicit row encoding polynomial in N. At prefix i define W_i as variables occurring on both processed prefix and remaining suffix. S_i is the exact set of W_i assignments extendible to the prefix factors. Maintain a finite list of affine cosets over GF(2), not an affine hull:
    S_i = union_{(a,H) in C_i} (a+H).
Individual directions H may differ, cosets may overlap, no count claim. Initial S_0={0} on empty frontier. All basis vectors, offsets, table words and guards in the same coordinate system.

For the next actual row r on X=X_(i+1) and a previous coset a+H, let I=W_i intersect X. Solve (a+h)|I=r|I for h in H by Gaussian elimination. If inconsistent discard. Else choose h0 and let K={h in H:h|I=0}; solution set is h0+K. Glue old values a+h0 and row r on overlap; project to W_(i+1). This yields exactly one affine coset b+K', where b is the projected glued assignment and K' the image of K on retained old coordinates with zero on new coordinates. This is a polynomial-time operation on O(poly(N))-bit vectors. There is no enumeration of 2^dim H. Union these outputs for every previous coset and each actual row. A prefix witness exists for every old state by induction, any compatible row glues (only shared variables in I), and every new prefix witness restricts to such a pair. Hence equality of exact supports both ways.

Normalization permits ONLY exact set operations: canonical reduced row echelon bases, offset reduction modulo H, duplicate elimination; discard a+H contained in b+K iff a+b in K and H subset K; merge distinct parallel cosets a+H and b+H into a+span(H,a+b). The latter is exactly the union because GF2 has two coefficients for the new independent vector. NEVER merge nonparallel cosets by affine hull. Every successful normalization strictly reduces record count; deterministic scanning and a fixed tie rule; no claim minimum affine cover found. All operations preserve the exact union including overlap. Backtracking: store every previous layer and actual factor rows. Starting at final empty frontier assignment, for each old coset/row pair constrain the old point simultaneously on shared row variables and on retained output variables (including consistency with new row variables). Gaussian gives one predecessor point if feasible. There is at least one by exact forward identity. Retrieve row witness, iterate backward, verify original cover. This works even if normalization merged records, without free per-point witness tables. Contradiction alternative: a false YES would lift to actual original cover; a false NO would require a first lost prefix of an actual cover, ruled out by exact restriction, join, projection and normalization. Failed cap yields OPEN not NO.

Common-period specialization (B): if all input cosets have the same H, fixed-row restrictions have common projected kernel K'. Canonical quotient representatives R under K' form a finite actual set in a linear quotient. Its entire stabilizer P={d:R+d=R} is acquired by fixing r0 in R, testing d=r+r0 for each r in R and verifying membership for every element of R. Since canonical reduction modulo a linear basis is linear, XOR of canonical reps is a canonical rep. P is a vector space (closure under translation composition and inverse). Enlarge direction to K'+lift(P) and quotient again. This exact compression can be applied repeatedly when new periods emerge across different steps. It is a specialization of the heterogeneous theorem, not identical to X01-10's disjoint sumset period theorem. Its witness lift uses prior attained-state layers; no witness selected merely from affine hull. If full common stabilizer trivial it can leave many states even when a few nonparallel cosets suffice.

Constrain each affine coset of functionals to agree with v on this overlap, and apply the induced affine map to W_i evaluations. All maps acquired from bases by Gaussian.
