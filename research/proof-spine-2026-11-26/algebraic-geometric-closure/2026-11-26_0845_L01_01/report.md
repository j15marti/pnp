## 1. Two tracks: global collision and paid live collision
Let F be any field, C a topologically indexed binary +,-,* division-free arithmetic DAG of s gates computing f in F[x_1,...,x_M]. Constants arbitrary in field gate model. Minus may be represented by multiplication by -1 and addition. ML denotes reduction modulo all x_i²-x_i, equivalently unique multilinear polynomial agreeing on {0,1}^M (valid every field). The direct X01 interpolation for a certified exceptional set B outside which f is already multilinear is sum over a in {0,1}^B of f(x outside B,a) times prod_{i in B} (x_i if a_i=1 else 1-x_i). Exact by evaluation/uniqueness, cost O(2^|B|(s+|B|+1)) with substitutions. Semantic discovery of B not granted, syntactic union safe but may be large.

NEW lemma: compute all syntactic scopes S_g (variable leaf descendants) bottom-up. Remove unreachable gates. Initialize B_root=empty; process reverse topological order, taking unions from ALL parents. For g=h+k or h-k, propagate B_g intersect S_h to h and B_g intersect S_k to k. For g=h*k, additionally propagate I=S_h intersect S_k to BOTH children, including h=k. Let b=max_g |B_g|. These sets are acquired from the given circuit with O(sM) bit-set operations in a coarse bound; even repeated paths are represented by the one union at each gate. No semantic degree or PIT oracle, no target-supplied set.
For each g and a in {0,1}^{B_g}, store one arithmetic DAG output T[g,a]=ML on the remaining variables of the polynomial at g with B_g=a. All references are shared; no unfolded formula.
Child partial restriction: for any assigned subset C of B_h, reconstruct the exact multilinear response by summing T[h,d] times interpolation literals on B_h\C over d extending the assignment. If a provided assignment includes variables outside S_h they are ignored. All relevant fixed variables belong to B_h by construction.
At sum/difference, combine child responses for the parent assignment a; linearity suffices, including overlapping free variables. At product, fix a plus any assignment z to I\B_g. Each child now has no shared free variable, so the product of its reconstructed responses is multilinear and agrees with the product at all remaining Boolean points. Sum over z using interpolation literals on I\B_g. Those variables were fixed inside both children and are absent from their products. The parent response is multilinear and agrees on the cube with the specialized original gate. Leaves use either the assigned constant or original variable. Induction on topological order proves every table entry, with root table one entry ML(f). This handles cancellations, repeated edges, and DAG reconvergence. Alternate proof by contradiction: a nonzero difference between the computed and target multilinear response vanishing on all Boolean inputs is impossible by induction on variables (evaluate 0 then 1); no field size restriction.
Work: <=s 2^b table entries, <=2^b joint shared assignments per entry, <=2^b child interpolation summands each of O(b+1) gates. Thus O(s(b+1)2^{3b}) new gates after binary conversion, plus O(s poly(M)) discovery/storage and addressing. Can cache child partial responses as in audit, but not needed for bound. At b=0 this is usual disjoint-product multilinear construction. No divisions, no coefficient growth assumption for circuit-size consequence. For an explicitly encoded finite-field C with fixed q, all arithmetic constants can be copied or 0,1,-1, field operations have constant bit cost. DAG indices use logarithmic bits in new size. Compilation, peak space, cumulative storage-time and evaluation all bounded by fixed polynomial when s,M polynomial and b=O(log n); peak space includes both DAGs and table entries, cumulative memory <=time*peak space. If input is over arbitrary fields this is a gate-model theorem, not a free bit simulation of arbitrary constants.

## 2. Witness extraction and conditional quantitative consequence
Only require f to give the correct decision bits on graph inputs with <=n present arcs/edges. On smaller supports all values zero; on size n supports value 1 exactly for witness edge sets. Unique multilinear extension coefficients at S equal sum_{A subset S}(-1)^{|S|-|A|}f(1_A). Therefore degree <n coefficients vanish, and homogeneous degree n is exactly HC_n or permanent_n. This also holds for easy total HC-exact and PM-exact functions, for every characteristic, and uses no counting oracle. For the standard full directed matrix with loops, diagonal variables do not occur in HC_n for n>=2. To acquire degree n component, introduce formal t, replace variables by t x_i, maintain coefficients 0..n of each DAG gate; multiplication is truncated convolution. Cost O(n²) per gate, no division/interpolation field-size restriction. Thus
  circuitSize(HC_n or perm_n) <= O(n² s (b+1) 2^{3b})
plus polynomial input/gate overhead (M=n², s includes leaf nodes).
If s<=n^K for fixed K and b=O(log n), this is a polynomial size formal arithmetic circuit, contrary to either source's claimed eventual exact superpoly lower bound in appropriate field. Conditional restricted theorem: any polynomial-size arithmetic circuit family agreeing with HC-exact OR HC-decision on the lower Hamming layers must have b/log n tending to infinity (otherwise a fixed cap on an infinite subsequence contradicts eventual lower bounds). Likewise PM/PM-exact outside characteristic 2. If the Anthropic MainTheorem is valid, log2 s+3b+O(log n+log(b+1)) >= c(log2 n)^{4/3}, so for fixed polynomial s, b=Omega((log n)^{4/3}). This is a structural lower bound on the supplied arithmetic representations; no runtime lower bound for ordinary Boolean decision. Char 2 permanent is determinant, so that control is deliberately excluded from the arithmetic contradiction; char 2 HC remains covered conditionally. For finite-field concrete bit accounting one can choose F2 for HC, F3 for PM. All constants in Boolean arithmetization are small; a uniform polytime decider gives a polynomial-size Boolean circuit and then a polynomial-size arithmetic DAG correct on cube via NOT=1-x, AND=xy, OR=x+y-xy, but no guarantee whatsoever on b. The generic additional claim that every P-time decision admits such an arithmetization is contradicted CONDITIONALLY even by polynomial-time exact-cycle recognition and PM. An HC-specific low-b compiler for arbitrary HC deciders would suffice, but the low-layer proof cannot distinguish them from exact-cycle verifier. A true separation must use higher-layer semantics, actual unrestricted computation, or another bridge.

## 3. Adversarial cumulative overlap and safe OR
Example f=prod_i x_i²: every variable is a semantic collision, but direct product of disjoint square gates has b=1 and acquired ML has O(M) gates. Thus the new parameter strictly extends global exceptional-variable interpolation. Conversely compute prefix P=prod_i x_i, then multiply in each x_i again one by one; all immediate multiplication overlaps <=1, but B_P includes every x_i and b=M. Thus replacing live overlap by max immediate overlap does not bound this compiler. This is an obstruction to a representation, not to the underlying easy polynomial; equivalent disjoint square regrouping is a cheap bypass. L02's distinction between immediate and cumulative context is analogous, not a cross-source theorem. For track polynomials A,B that are Boolean on graph inputs, OR is A+B-AB on the cube (over all fields), not A+B unless exact disjointness in Boolean semantics; ML must still be acquired. On degree n, an OR of monotone witness tests has correct unit coefficients only after the overlap correction; summing witnesses across routes can overcount or cancel mod p. No arbitrary symbolic counting from decision or source-level support DP.
