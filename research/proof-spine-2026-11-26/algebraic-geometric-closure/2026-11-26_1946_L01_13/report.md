## 2. Track A: adaptive native cut acquisition
Fix root vertex 0. For any nonempty proper subset S excluding root, E_S is the event that successor permutation p maps S onto S. Restrict event by deleting all outgoing cut arcs. An HC witness is in no such event. Retain only the target parity fiber C, covers with sign (-1)^(n-1) (equiv. odd number of cycles). Every count below is on C and its exact guard, never on arbitrary independent marginals. Initially obtain a perfect matching, delete cover-unsupported arcs, reclose degree and original reachability. No matching or no strong connectivity implies NO. Assume Pólya signability recognized and valid signing acquired; otherwise UNKNOWN for this lane. RST (1999), section 1.1 and 9, provides polynomial recognition/construction. Counts follow from two integer determinants: B(F)=(|det S_F|+(-1)^(n-1)det A_F)/2. Deletion/pinning preserves sign uniformity. Reference proof L01-11. Signability acquisition general algorithm not executed here; native base signing independently verified by exhaustive 9-cover reference and propagated explicitly through gadgets.

Given already acquired events E_1..E_q, exact residual C' = C minus their union. If C' empty, sound NO. Otherwise acquire one residual cover by lexicographic row pinning using an exact positive residual count (Track B). Inspect its cycles. A single cycle blocks refutation; no SAT-repair track. A disconnected cover has a cycle not containing root: acquire its original vertex subset (shortest such cycle, tie by smallest vertex), append the event. It is a new event since current cover avoided all previous events. No guessing cut size, enumerating all cut sets, or free candidate witness. Guarded exact support closure: for each available edge e, evaluate |C' intersect {p:e in p}|, deleting zero-support arcs only in residual representation C' (not unguarded root counts); every HC still belongs to C'. If this support graph disconnects, sound optional immediate NO. In audit, record this certificate but continue exact exclusion to zero to test theorem. At each iteration recompute exact support after new exclusion, and use row pins on original graph plus prior events for extraction. Matching support closure at root and every guarded count can be applied without changing counts; implementation uses exact target residual support at root of each round, not matching closure inside every determinant call.

## 3. Track B: exact bounded-overlap residual oracle and theorem
For fixed integer d>=1, require at most d simultaneously active acquired events on every cover in root C. Certify by checking exact zero for every (d+1)-wise intersection; when a new event is appended, only intersections containing that event are new. If any is nonempty, stop UNKNOWN (or use separately charged stronger lane). The property persists under every deletion and pin guard. For any guard F,
 R(F)=sum_{J subset [q], |J|<=d} (-1)^|J| |C intersect F intersect intersection_{j in J} E_j|.
This is exact because the contribution of any cover with a active events (a<=d) is sum_{j=0}^a (-1)^j binomial(a,j), 1 if a=0 and 0 otherwise. Empty J means all covers in C intersect F. All intersection guards are unions of arc deletions and actual pins. Determinants over integers, exact division by 2, no finite-field Gram shortcut.

Rooted overlap lemma: if a cover has c cycles, any closed subset is a union of entire cycles, so exactly 2^(c-1)-1 nonempty closed subsets exclude the root. If all target covers have at most K cycles, every distinct rooted cut list has overlap at most d=2^(K-1)-1. Constant K suffices, but this is an existence fact unless proved or checked; algorithm verifies overlap using actual intersections.

Rank progress lemma: let f_S=1_{E_S} in Q^C for every rooted cut S. Each acquired f_new is linearly independent of preceding f's, since the new uncovered witness has every previous indicator zero and the new indicator one. Thus q<=r, rank of full rooted event matrix. In particular, given fixed d and qcap=N^a for fixed a, the procedure is a sound polynomial-time partial NO refuter on all ordinary inputs. It succeeds on every signable NO satisfying the overlap condition for the selected cuts and r<=qcap: by independence it cannot append event r+1; if residual nonempty, since source NO the extraction must yield another disconnected cover, contradiction. We make no general promise about r or actual cut selection. May alternatively prove a small attainable cut universe for a family. This is not a lower bound on arbitrary algorithms or even on number of necessary cuts.

Ledger: at most O(qcap^(d+1)) incremental overlap queries total (each (d+1)-subset tested once). Each round uses <=m support counts + <=m row-pin extension counts + O(1) remaining counts, m<=n(n-1). Each R evaluates O(qcap^d) determinant pairs. Conservative total O((m+1)(qcap+1)^(d+1)) determinant pairs; include final failed overlap check, cache lookup and guards. Each determinant has entries in {-1,0,1}, values <=n!, Bareiss intermediate minors O(n log n) bits; exact products/sums and IE accumulations O(n log n + d log(qcap+1)) bits for fixed d. All indexing, pins, event maps, closure and polynomial sign recognition paid. Explicit polynomial bit work for fixed a,d; peak storage polynomial (cache optional), cumulative storage <= total bit steps * peak bits on same execution. A cap failure is UNKNOWN. No qcap dependence on per-instance exponent. Actual research comparison cap12 acquired cuts, d3, 50000 determinant pairs; not equal measured physical bit time. Production cap can be N^a and the proved polynomial tariff. For fixed count cap, code checks after increment (one attempted extra query, no determinant computed for it). No claim of universal acquisition or global count oracle.

## 5. Track C: bounded overlap does not bound rank; native strongly connected hostile control
Use same base graph with n=9. Exhaustive reference gives 9 covers: three with 2 cycles, five with 3, one with 4. In every 2-cycle cover vertices 0 and 2 lie on the same cycle. In the 4-cycle cover they are in distinct cycles. At least one 3-cycle cover has them in distinct cycles: successor p=[5,6,3,4,8,0,7,1,2] with cycles {0,5},{1,6,7},{2,3,4,8}. These facts independently verified and exact list in rank_control.json. Base graph strongly connected; every arc belongs to some target cover; signed determinant terms all positive.

For k>=3 create k two-vertex layers (a_i,b_i), i=1..k, fresh IDs 9+2(i-1),10+2(i-1). Replace all outgoing arcs from 0 and 2 by fixed arcs 0->a_1,2->b_1. At each consecutive layer include all four directed arcs; route choice is identity or swap. At final a_k restore original outgoing arc options/weights of 0, at b_k those of 2. Other original arcs unchanged. Every cover bijects to a base cover p and a binary word w of k-1 swaps: entry edges forced, each layer uses a bijection, final destinations and other original rows form an original permutation p. Odd swap parity transposes successors of 0,2 relative to p; even leaves p unchanged. Subdivision itself preserves cycle count. Transposing successors splits a cycle into two if 0,2 same cycle; merges two if different. Hence every base 2-cycle cover stays at 2 or becomes3, every 3-cycle cover stays3 or becomes2/4, base4 cover stays4 or becomes3. No cover ever has one cycle; every target (odd number of cycles) has exactly3. Original graph strong connectivity follows from identity-route lifted paths in strong base, including both lane paths. All arcs target-supported: for any base target cover use an even word, and with k-1>=2 can select either routing choice at any layer using compensating swap elsewhere. All original edges supported, fixed entry arcs supported but mandatory, so do not claim unary flexibility. Forced path contraction is legitimate, not an obstacle to the rank construction. Assign -1 to a_i->b_(i+1), other layer edges +1, propagate original signs to exit arcs. Each swap changes determinant permutation sign and selected entry product sign, cancelling each other; even 2k vertex subdivision sign factor +1. Thus Pólya signing persists for every cover. Counts: total 9*2^(k-1); target 9*2^(k-2), since exactly one parity of w yields odd cycle count for each p. All rooted cut lists have maximum overlap3. No graph-specific arithmetic lower-bound assumption.

Rank obstruction: fix p above and restrict even swap words, of which there are 2^(k-2). For each even word w, let S_w be the full cycle containing 2 in its lifted cover; 0 lies in different cycle. S_w contains exactly one vertex per layer, with membership tracking cumulative swap parity. Different even words yield different S_w. In the restricted covers, any closed subset is union of cycles; each cycle contains an original vertex, and original vertices in S_w equal exactly the base cycle of 2. Thus S_w closed in another restricted cover iff it is that cover's cycle of 2 iff word matches. Matrix with rows these covers and columns S_w is identity. Over Q and every field,
 rank(full rooted cut event matrix) >= 2^(k-2) = 2^((n-13)/2).
This falsifies bounded-cycle-count or bounded-overlap => polynomial full cut rank, even on strongly connected signable actual NO inputs with target support saturation. It is a representation bound, not a lower bound on a minimum refutation or adaptive solver.

## 6. Stagnation complementary hybrid: select untouched cycles, not whole rank
The same high-rank source admits a compact bypass. Four short cuts {1,6,7},{1,7},{3,4},{4,8} avoid both switch endpoints and are unaffected by swap. Inspection of all nine base cycle lists proves each base cover has at least one of these closed sets. Hence every lifted cover is excluded by them, including all target covers. They can be acquired without knowing base labels: scan actual simple cycles of length2/3 and dedup; k>=3 all cycles touching a new layer pass through a path of at least k new vertices and at least one original vertex, hence length>=4. On actual switch family exactly five raw short-cut candidates, one zero target count ({6,7}), leaving four. No forced large-rank construction. For the shortest-cycle adaptive rule, every lifted cover has an unaffected 2/3-cycle not containing root; any cycle through layers has length>=4. Thus all acquired events are among these positive short cuts, guaranteeing <=4 rounds even though full rank exponential. This is a symbolic result on the rule, not a claimed executed adaptive solver on large switch graphs. Complementary direct determinants actually executed for k=3,8,16,32,64, n=15,25,41,73,137. First moment=12*2^(k-2), second=3*2^(k-2), third=fourth=0, root B=9*2^(k-2). This counterexample is valuable precisely because bounded overlap alone does not constrain full rank, but the *selected event cover* can remain compact.
