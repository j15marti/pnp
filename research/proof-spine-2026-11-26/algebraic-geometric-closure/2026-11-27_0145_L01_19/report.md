## A: exact source map

Each crossing graph is a star. Let C be cyclic successor on s=2(m+3t) endpoints and p=C composed with all center swaps. For triple j let k_j be the product of its three leaf swaps on six endpoints; choose g_j a cyclic permutation of these six endpoints. All supports disjoint. Write k,g for the products. Fixed endpoints have g,k identity. Native graph has separator S of s endpoints, and region u_i,v_i per endpoint. Fixed region has only i->u_i->v_i->p(i). Other region additionally has g(i)->v_i->u_i->p(k(g(i))). No other arcs. Any tour uses exactly one contiguous path per region: s regions need at least s separator exits, and only s available. Each local path is one of the two stated paths. Entry occupancy at i forces its choice equal to that at g^-1(i), so each six-cycle of g gives a single triple bit. Exit occupancy is automatically bijective on every selected group; compressed permutation P(x)=p product_j k_j^x_j. Conversely each such bit word gives a unique native cycle cover using the specified spanning paths, with same number of cycles as compressed permutation. Any edge guard in a region discards options inconsistent with that guard; equality propagates along g, and fixed choices reduce RHS and target weight. Other guards need a separate adapter.

The Cohn-Lempel identity (L01-18, Traldi arXiv:0903.4405, Thm1/Cor2) gives number of cycles = 1+sum_e |d_e-1|, d_e integer occupancy. Indeed each selected center with d_e selected leaves yields star matrix of nullity |d_e-1| over GF(2), including empty leaves. Therefore a tour exists iff Mx=1 over GF(2) AND integer |x|=q; nonnegative odd d_e sum to 3|x|=m and hence must all be one. This is a decision-preserving adapter, not an evaluation of the formal HC polynomial. The chart language includes arbitrary X3C, so exact global affine weight decision remains NP-complete.

## B: projected affine weight certificate (proved scoped)
Let A={x in {0,1}^t:Mx=b over GF2} include all verified original phase pins; if inconsistent reject. For any source-acquired coordinate patch J, Gaussian elimination yields A_J=pi_J(A)=pi_J(x0)+span(pi_J(kernel basis)). This is exact attainable projection, not just a relaxation of a nonaffine set. Its cardinality is 2^h_J, h_J the projected rank, even if the global dimension is enormous. Acquire local words by independent projected basis enumeration, not global word enumeration. Nonnegative cost shares w_{J,i} (zero outside J) with sum_{J containing i} w_{J,i}<=1 satisfy, for every x in A,
 |x| >= sum_J w_J*x_J >= sum_J min_{z in A_J} w_J*z.
Thus the latter bound >q refutes the entire chart. No need for joint attainability of independently minimizing words; the inequality is valid for each actual global word. This is a lower bound, not an equality claim. For disjoint patches unit shares suffice. Overlapping patches allow a polynomial-size rational LP:
 maximize sum_J l_J subject to w>=0, sum_J w_{J,i}<=1, l_J<=sum_i w_{J,i} z_i for every z in A_J.
May impose l>=0 without losing optimum since zero is feasible and local weights nonnegative. All coefficients small and rational optimum/certificate has polynomial bit length in explicit LP size. A standard polynomial bit-time LP method can acquire optimal shares, or verify supplied rational shares directly. LP optimum <= minimum global weight; lack of separation means UNKNOWN. LP itself not executed this run: only exact integer shares on disjoint patches and a fractional feasible control were checked. This is a local-polytope/dual-decomposition construction, related to LP decoding, no priority claim. It changes the global weight domain into small exact projected supports and charges each coordinate's weight only once.
