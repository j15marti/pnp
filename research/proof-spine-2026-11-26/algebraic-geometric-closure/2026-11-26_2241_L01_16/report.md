## A. Exact occupancy, not marginal Hall alone
Label the two actual table options by x_i=0,1; singleton tables duplicate the option and impose x_i=0. For each separator port j define an ingress occupancy sum I_j and egress O_j. Every chosen table option uses one entry and one exit. Each individual indicator is affine over F2 in x_i: f_ij(x_i)=f_ij(0)+(f_ij(0)+f_ij(1))*x_i. Impose I_j=O_j=1 mod2 for every j. This is an affine linear system with at most 3s equations, s bits. Crucial exactness: each true integer occupancy is a nonnegative odd integer, at least one, and total ingress occupancy=s and total egress occupancy=s. There are s ports, so each integer occupancy is exactly one. Conversely permutations necessarily satisfy every equation. This is not an affine relaxation: the entire joint all-different choice support is exactly the affine solution set. Gaussian inconsistency is a sound NO. Nonempty affine solution set has size 2^d in PAIR LABELS, not in original path witnesses. Separate entry and exit Hall only tests each projection separately. Matching is an easy feasibility control, not counting.
For a solution x, entry a_x and exit b_x are permutations from indexed regions to separator. The induced successor P_x=b_x composed with a_x^{-1} on S. Lifting each compressed edge through its stored regional path gives a cycle cover with the same cycle count; it is HC iff P_x has one cycle. Any original HC induces an x, so this is an exact decision adapter, including arbitrary local path multiplicities. No claim of parsimonious counting of original paths. For s=1 a compressed loop denotes a single tour, not an original graph loop.

## B. Global sign is affine on the actual chart
Fix one Gaussian solution x0. Consider a_x alone. Relative to the reference entry matching a_0, relabel ports as region IDs. A region has at most one distinct alternative entry, hence its exchange graph has outdegree <=1. Every entry matching differs from a_0 on a collection of disjoint directed simple cycles of this fixed graph: each changing row must choose its unique alternative; bijectivity forces the cycle, and any such cycle can be independently flipped in the entry projection. Noncycle alternate ports cannot be selected. A cycle flip of length l multiplies the permutation sign by (-1)^(l-1). For each such cycle, its activation bit on the full joint chart equals x_i+x0_i for any representative region i of that cycle. If a region's two options have identical entry, its bit does not affect entry sign. Hence the entry parity is affine on the joint chart; same argument for exit. Parity(P_x)=parity(a_x)+parity(b_x) mod2. Therefore for any Gaussian nullspace basis v_1,...,v_d, sign on x0+sum t_i v_i equals parity(P_x0)+sum t_i[parity(P_(x0+v_i))+parity(P_x0)] mod2. Exactly d+1 permutation evaluations acquire the coefficients, no oracle. Append target parity s-1 mod2 as one affine equation. If inconsistent, NO, even with exponentially many attained joint charts and connected union of their arcs. This removes need for Pólya signing or determinant counting in this slice. If consistent, remaining chart only necessary for connectedness; do NOT conclude YES/NO from parity alone. If residual nullity <=c log2 N for fixed c, enumerate all actual remaining affine words, test one-cycle condition and lift if needed, total polynomial. Otherwise return UNKNOWN unless another certified method succeeds. Actual affine chart and parity are GF2; permutation signs are integer +/-1 before encoding, not determinants in characteristic 2.

Additional complementary exact scope (proof only, not executed): if the independently selectable phase switches of the full joint chart give compressed permutations P_x=P0 composed with a product of pairwise disjoint input transpositions, test the graph on base cycles with an edge for each transposition joining the two incident cycles. If disconnected no switch connects its components. If connected choose a spanning tree; each successive tree swap merges two currently distinct cycles, yielding one final cycle. The selected switches are independent and commute, so lift is valid. This is an explicit tractable subcase, not a universal guarantee that arbitrary chart switches reduce to transpositions. An even double transposition may prevent this greedy argument (our grouped family below).

## Integrated exponential-family theorem
For b>=2 take s=4b and s regions as above, S complete directed loopless. Partition S into disjoint ordered 4-tuples L_j=(4j,4j+2,4j+1,4j+3). Let g rotate each tuple forward by one; p(i)=i+2 mod s. Each region (u_i,v_i) has arcs u_i<->v_i, i->u_i, g(i)->v_i, v_i->p(i), u_i->p(g^{-1}(i)). Exactly the pairs (i,p(i)) and (g(i),p(g^{-1}(i))). Entry uniqueness forces all natural orientation bits constant along each g-cycle. Exit uniqueness then automatically holds for all independent group choices, because p is a permutation and g^{-1} is a permutation on each group. Thus exactly 2^b attained joint pair assignments, with b independent bits. A group flip replaces compressed map P0=p by P0 composed with g_j^{-2}, a double transposition, preserving sign. Base p has exactly two cycles (even/odd vertices), so its sign is +1 for even s. All 2^b charts have even sign, wrong for a single s-cycle. This proves NO unconditionally for all b. All original vertices retain IDs; no path counting. The union of compressed edges across charts is strongly connected: base p cycles traverse both parity classes internally, and g_j^2 pairs one even with one odd, providing both cross directions in union. Thus union connectivity and separate Hall are insufficient even after exact joint-port acquisition. An exponential number of actual admissible pair assignments does not entail exponential refutation work.

Every original arc is target-sign cycle-cover supported even before this saturated joint constraint (symbolic proof, not large reference test). Hardness comparator: Plesnik (1979) proves directed HC NP-complete even for planar digraphs indegree/outdegree <=2. Given any such H with s vertices, create separator vertex a_i and singleton region r_i, arcs a_i->r_i and r_i->a_j iff H has arc i->j; no other arcs. Each region requires one path, exact table T_i={(a_i,a_j):i->j}, at most two pairs. Input size polynomial, one-to-one normalized HC lift by vertex subdivision; zero-row cases trivial NO. All joint tables are acquired directly from edges and all-different choices are affine by this theorem. Thus the class of saturated binary-port graphs WITH supplied separator remains NP-complete. Full one-cycle coverage of these affine charts, not mere feasibility/parity, is already equivalent to P=NP. This is a model-faithful barrier, NOT proof P!=NP. Exact parity can be solved efficiently, but for general chart there may be exponentially many correct-parity assignments and no tour; a universal negative certificate must exploit connectivity nontrivially. Perfect matching and simple witness verification remain cheap controls.
