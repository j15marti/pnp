## Lemma A: weighted rational spectral certificate, exact and chart-safe
For any acquired necessary homogeneous integer/rational equations Ay=0 on k spin coordinates y_i in {-1,+1}, choose a rational multiplier lambda and positive integer D so D c=A^T alpha+r with integer alpha,r. On every feasible assignment D c^T y=r^T y. For c=e_i±e_j, nonzero magnitude is 2. Thus ||r||_1<2D certifies c^T y=0; for c=e_i, ||r||_1<D certifies NO. Strict inequalities only. The diagonal Gram identity
  (sum |r_i|) sum |r_i| y_i^2 - (r^T y)^2
  = sum_{i<j} |r_i r_j| (y_i-sign(r_i r_j)y_j)^2
(with zero terms discarded) provides an exact PSD certificate, not a floating-point proposal. The L1 bound is never weaker than sqrt(k)||r||_2 for the same residual. For a two-row matrix u,v, D=(u.u)(v.v)-(u.v)^2>0 and adjugate Gram multipliers give the orthogonal residual, exact integer arithmetic for bounded local rows. Positive equality control u=(1,1,1,1,0),v=(1,1,1,0,1), c=(0,0,0,1,-1) gives r=0. NO PSD control u=(2,1,1),v=(2,1,-1), Q=A^TA, Ddiag=diag(0,0,2), Q-Ddiag=2(2,1,0)^T(2,1,0), trace2. These are local spin controls, not claimed registered strict native roots.

Do NOT substitute a general GF2 affine map as a real linear spin map. Instead use characters. Fix original degree d, feature family chi_S=(-1)^(sum_{i in S} x_i), |S|<=d. Under a checked affine chart x=M t+b each original character becomes sign times a character with frequency M^T 1_S. Distinct frequencies are independent over Q (Walsh basis). Store frequency bitsets, not expanded products in the free coordinates. Multiplying each original occupancy row by each original character of degree <=d-1 gives polynomially many necessary rows at fixed d. Select useful multipliers by enumerating that fixed candidate family, exact GE and cancellation against the unwanted coefficient subspace; this is complete for the declared candidate span, not for arbitrary PC/SOS. Exact projector or weighted residual test on a pair of feature coordinates certifies a signed character equality; its XOR frequency difference is a genuine affine equation in t. Check cut target membership by GE before admission. An equality between identical frequencies is either redundant or a contradiction; otherwise it decreases free dimension if valid.

Phi=D-dim W+r. Proper affine restriction rho:F->F' is surjective by definition of the same original feature family. ## Lemma B: exact carrier-intersection path DP
In a checked affine chart with free variables t, each local B row is an occupancy predicate on at most four affine forms. Let W_i be the linear-part span of its forms, U_i=sum_{j<=i} W_j, V_i=sum_{j>i}W_j, I_i=U_i intersect V_i. Store exactly the linear functionals on I_i which are restrictions of some functional on U_i satisfying all first i rows (offsets in row predicate). Initial I_0=0. At step i, enumerate <=16 local functionals on W_i satisfying exact occupancy. A previous state and local functional extend jointly iff they agree on U_{i-1} intersect W_i, which is contained in I_{i-1}; exact tagged GE supplies constraints for this test. Since I_i is contained in I_{i-1}+W_i (write x=u+w, x in V_i, w in W_i, hence u in U_{i-1} intersect V_{i-1}), the next boundary value is uniquely determined by that pair. Conversely every extension restricts to a pair considered. Induction proves exactness. Empty layer is NO; nonempty final zero interface is YES. Retain backpointers and solve the reconstructed consistent linear form values by GE, then apply affine offsets and signed root map and verify every original port constraint. This gives fixed-order recognition and decision in O(m*2^(w+4)*poly(N)) time and O(m*2^w*poly(N)) space including reconstructible bases, where w=max dim I_i, assuming paid chart acquisition. GE finds intersections on the provided fixed source order directly; no advice needed to test that order. Thus any paid chart with this order's width O(log N) gives a polynomial terminal. Does not prove every input admits such a chart/order, nor conflate with general branchwidth recognition. Korhonen-Oum arXiv:2601.04756v2 claims 2^O(k^2) oracle-time branchwidth acquisition; only sqrt-log width guarantee directly yields polynomial paid acquisition using that bound, while a provided log-width decomposition suffices for DP.
