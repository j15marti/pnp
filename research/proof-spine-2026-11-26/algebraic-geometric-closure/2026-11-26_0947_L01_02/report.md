## Exact target and falsifiers
Ordinary directed HC on explicit n×n adjacency bits, n>=2, N=Theta(n²), discard loops as they are irrelevant; PM on explicit bipartite n×n bits (diagonal allowed). A witness is a successor permutation having one cycle (or an arbitrary permutation for PM); rotations not counted again. Standard deterministic bit model; formal arithmetic circuits are division-free binary +,-,* with arbitrary field constants, nonuniform. On full graph function no graph-input bit is globally pinned. In witness semantics loops excluded; for n>=3 every nonloop bit selectable and avoidable in some HC of the complete graph. Row/column singleton propagation is sound, performed before exhaustive witness search, repeated after deletions. Guarded prefixes are explicit row-domain restrictions, not globally forced facts. Exact HC unary support in arbitrary instances not free.

Named load-bearing lemma SLAYER: Can monotonicity plus all low homogeneous layers (including nonminimal overlapping witnesses), efficient coefficient access and arithmetic hardness establish Boolean hardness? FALSIFIED as generic transfer, even with an upper extension that has no false negatives. Surviving lemma: a real decision oracle gives exact output-sensitive witness enumeration, but not small symbolic circuits. Falsifiers: (1) low-layer graph missed by total P extension; (2) incorrect coefficient due to forced-edge factoring or double counting; (3) high-layer monotone false positive persists; (4) loss of witness identity or uncharged queries in prefix enumeration. First two excluded by proof and finite tests; third demonstrated explicitly; fourth checked in scope.

## 1. Uniform monotone P upper extension
Fix any positive integer C. Let d_i be outdegrees after removing loops (row degrees for PM), Q=prod_i d_i. Reject if any row or column is empty. If Q>n^C, accept. Otherwise enumerate all successor choices, reject nonpermutations and (for HC) permutations not one cycle. U_C is total uniform P, since Q computed with saturation and at most n^C leaves explored. It is monotone: a YES due to large Q remains so in supergraphs; a YES due to true witness remains true or crosses cap. It never has a false negative. For all graphs with at most n+floor(C log2 n) relevant edges, if all rows nonempty, k=|E|-n>=0 and Q<=2^k<=n^C, since integer d<=2^(d-1). Thus U_C agrees with actual existential HC on every such input. This includes arbitrary sparse NO, not only witness verification. Strengthen U by AND with any fixed collection of monotone polynomial necessary tests, e.g. strong connectivity and bipartite cycle-cover matching, without changing low-layer correctness or monotonicity. For PM exact augmenting-path decision itself is a full control. These functions are monotone semantically, not necessarily small syntactically monotone circuits; L02's monotone gate lower bound does not contradict their P algorithms.

For any Boolean function f, the unique multilinear representative over any field F has coefficient at S equal to sum_{T subset S} (-1)^(|S|-|T|) f(1_T). Therefore agreement up to Hamming weight L implies all homogeneous layers through L identical. In particular ML(U_C) and ML(HC) have identical layers through n+floor(C log2 n); their degree n part is HC_n. Conversely these layers determine exactly the function on that truncated cube. Thus any function-level certificate depending only on these layers and semantic monotonicity is also exhibited by an explicit total P function, even if it uses higher-order witness overlaps. A compiler from all such P functions to polynomial-size formal arithmetic circuits for these layers would contradict the external HC lower bounds conditionally. This is stronger than the exact-cycle verifier control, which lacks monotonicity and higher-layer agreement. Not a refutation of a source-sensitive compiler that exploits unrestricted NO semantics or particular properties of actual decider executions.

Adversarial opposite direction: if V is monotone, V<=HC, and accepts every exact cycle graph, then every graph containing a cycle must be accepted by monotonicity, hence V=HC. Thus a sound monotone lower extension covering all minimal witnesses is already the entire decision problem. For monotone U>=HC, the equivalent exactness condition is that every accepted graph is either exactly a cycle or has an accepted strict one-edge deletion. Induct on edge count; a minimal accepted graph must be a cycle. This is a decision-sensitive criterion, but not a proved efficient way to verify it.

## 2. Two exact methods for individual low-layer coefficients
Fix S, with no irrelevant loop variable and all rows nonempty (otherwise coefficient zero). Put k=|S|-n. All singleton-row arcs F0 occur in every witness within S. Any subgraph missing one has f=0. Factor their monomial exactly, leaving optional indexed arcs O in nonsingleton rows, |O|<=2k (d<=2(d-1) for d>=2). The coefficient at S is the integer alternating sum of f(F0 union T) over T subset O, then map integers to F. If any arc of S is in no witness, f restricted to subgraphs of S is independent of that arc and the coefficient is zero. This is a proved cancellation, not discarding a variable in the polynomial.

Method A: enumerate all feasible successor permutations within S, at most 2^k, using row/column closure and original IDs. Build array c indexed by masks in O counting witnesses with exactly that optional mask. Subset zeta transform gives Z(T)=sum_{W subset T} c(W). Convert the integer Z to its positivity indicator BEFORE field reduction. Alternating sum of these indicators is the coefficient. This accounts for overlapping cycles exactly; field cancellations of witness counts must not be used as feasibility. Cost O((2^k n+4^k(k+1))poly(N)) bit operations with table O(4^k poly(N)) space. Entries and intermediate absolute sums have O(k+1) bits.

Method B: enumerate all nonempty row subsets T_i independently, fix singleton rows, then enumerate successor candidates of the restricted graph and test existence. Work summed over restrictions <=poly(N)*prod_i [sum_{nonempty T_i subset [d_i]} |T_i|] = poly(N)*prod_i d_i*2^(d_i-1) <=4^k poly(N). No array needed; polynomial peak space, depth/index O(N) plus source and accumulator. This is an independent constructive coefficient algorithm; equality to the zeta method follows by exact subset incidence, not a guessed identity. Both methods have fixed polynomial cost for k<=C log2 n. Coefficients in all characteristics obtained by reducing the exact integer, not thresholding a finite-field count. This is coefficient access, not polynomial-size simultaneous symbolic generation of exponentially many coefficients. Indeed even each degree-n HC coefficient is polynomial-time computable by traversal.

Explicit overlap control: r four-vertex blocks (a,b,c,d), each has paths a-b-c-d and a-c-b-d with six distinct internal arcs. Connect each d to next a, close ring via any padding path. Every HC must traverse each block from a to d and cover b,c, hence exactly two choices per block, independent. n vertices, n+3r arcs, exactly 2^r cycles. The full restricted multilinear decision is mandatory link monomial times product over blocks (A+B-AB), A/B the two path monomials. Full support coefficient=(-1)^r in every field, whereas naive sum of all cycle monomials has coefficient zero there. Two opposite choices certify all optional edges individually selectable/avoidable; links forced. This is a bounded-interface/compact-product control, not intrinsic hardness even for exponential witness multiplicity.

## 3. Surviving genuinely decision-dependent bridge: output-sensitive enumeration
Given an actual correct HC Boolean decider D, enumerate witnesses in row order by prefix fixing one outgoing arc per row (delete its other arcs). Query D on each child graph; recurse only on YES. Every viable prefix lies on at least one distinct original witness, every leaf is one normalized successor permutation. With W witnesses the viable prefix tree has <=1+nW nodes; at most n children queried per node. Including root O(n²(W+1)) queries. With cap B, stop after B+1 witnesses and return overflow; visited viable prefixes lie on completed paths plus one active path, so O(n²(B+2)) queries, no uncharged search or advice. Every original witness is reached once, no overlaps. For weighted field evaluation sum products of weights along each enumerated cycle, exact if no overflow; PM same. Fixed finite fields have constant bit operations; rational weights require charge of numerator/denominator sizes (not needed for arithmetic LB). Uniform bit time for uncapped run O(n²(W+1)*(T_D(N)+poly(N))) with graph copies, DFS, verification and weighted arithmetic; peak polynomial space if D uses polynomial space and witnesses streamed, cumulative memory <= time*peak. If W<=n^B0 fixed exponent and D in P, exact evaluation on that support is in P. This does not give uniform polynomial bound on all supports: complete directed graph has (n-1)! cycles; exact weighted count and circuit construction not assumed. Even graph-specific polynomial evaluation on every field point would need an independent symbolic circuit transfer. Matching decision already allows this same enumeration, so no generic decision-to-count conclusion. No arithmetic circuit size assertion from the prefix tree.

## 4. Hostile NO and controls
Two complete bidirected cliques of size h+1 share exactly one vertex (n=2h+1,h>=3). Strongly connected, nonempty rows/cols, cycle-cover PM exists, every edge can be present/absent in some cycle cover (choose a cycle on one clique containing or avoiding the specified directed arc and another cycle on other side's h nonshared vertices). No HC because deleting shared vertex disconnects underlying graph, whereas deleting any vertex of an HC leaves a spanning path. Q>=h^(2h)*(2h), so for any fixed C the raw U_C and strengthened version with connectivity and PM tests falsely accept for all sufficiently large h. Complete unary support closure in the matching relaxation cannot eliminate it. Articulation recognition itself is a cheap bypass; not a hard NO after all closures. Additional polynomial monotone necessary tests could reject this family; no universal failure of all possible tests claimed. Greedy deletion retaining U_1 yields actual spurious inclusion-minimal YES, independently certified NO by inherited articulation partition. This attacks the exactness condition above on the identical source and guard.
