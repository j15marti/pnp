## A. Conditional exact compilation from the decider (proof)
Assume a correct uniform polynomial-time ordinary HC decider D. At any fixed level i, the predicate R_a != empty has an NP certificate: a suffix of length v-i with each entry O(log v) bits, check graph edges, permutation and single-cycle traversal, and guard. Likewise R_a != R_b has an NP certificate: one suffix and XOR of the two deterministic verification predicates. Use explicit polynomial-time reductions from these NP predicates to ordinary HC, with D, including the negative outcome. No #P oracle. The verification circuit is not a graph deletion oracle for the symmetric-difference predicate; the general NP reduction is essential. First test root emptiness; if empty output zero. Retain one actual prefix representative per nonempty suffix language per level. Expand each by each of at most v possible successor choices, discard empty children and compare every candidate with stored representatives on next level using paid inequality queries. Merge iff exact equality; retain edge label (i,j), never replace original IDs or discard duplicate incoming branches from different parents. Induction: equal languages have equal letter-restricted suffix languages, so each valid successor word follows exactly one root-to-leaf path and every such path gives a valid word. Representatives need not match the actual path's prefix; equality guarantees all its suffixes extend that actual prefix. Reconstruct/check actual path, not representative history.

For any gate/node a at level i, set P_a=sum over transitions j->b of x_(i,j) P_b, with terminal P=1. In this sum branches are disjoint by chosen successor, so no overlap or cancellation of distinct monomials. Suffix supports identical iff suffix polynomials identical as formal polynomials over every field, since each successor word corresponds to a unique squarefree monomial with coefficient one. Every prefix path multiplies its own actual labels; merging never loses distinct complete words. This constructs the formal HC polynomial restricted to the source and guard (not its Boolean OR arithmetization). At root it counts each cycle once. Multiple weights w_l are incorporated by replacing each x_(i,j) with x_(i,j)t^w_l(i,j) in the same DAG: no need to recompute equivalence per track for the unrestricted witness language. For each track individually, coefficient circuits via shift-and-add have O(v^2 W (v B+1)) binary gates if max weight B. For q tracks multiply by q; all indices and bit encodings paid. Multivariate joint signature coefficients may require product of coordinate ranges; no claim of polynomial full joint table. Equality of supports must refer to the same guard and original label universe, not cardinality, affine hull, or isomorphism without paid variable substitution.

Closure: at root, each newly acquired representative and stagnation, use existence queries for each remaining original edge present/absent; reject an empty language, discard unsupported edges and retain mandatory edges as labeled forced transitions (or mark forced without skipping levels). These conditional facts are scoped to that prefix; at root unconditional relative to original guard. Keeping levels avoids hiding factors and state-count costs. Every equivalent prefix has identical suffix forced facts. On arbitrary source no free full closure. With W<=v^c for fixed c, acquisition uses O(v^2 W^2) emptiness/difference calls, plus O(v^3 W) forced-support calls (at most v^2 per vW reps). Each query input and reduction polynomial in source length; sequentially paid D on each. Include failed comparisons, canonical representative indexing, parsing, edge scanning, guard verification, reconstruction. O(v^2 W) formal arithmetic gates for unweighted output, polynomial factor for circuit descriptions; weighted coefficients require numeric B polynomial for dense arrays (bit-length alone insufficient). Fixed field F_p bit evaluations polynomial for fixed p; exact integer counts <= v! have O(v log v) bits and weighted evaluations with polynomial-bit integer inputs have polynomial bits for products/sums. General fields only formal gate count; no uniform arbitrary field bit-cost claim. Peak space polynomial in N,W and max single-call workspace; cumulative <= total time*peak storage. With a fixed polynomial W cap return UNKNOWN on overflow, not NO, and charge failed work. This is essentially a semantic levelled decision diagram (Bryant's classical canonicity background), not a novelty claim for decision diagrams. The gain over L01-02 output-sensitive enumeration is W rather than number of witnesses; width-two independent 2x2 matching blocks have 2^(n/2) witnesses with O(n) states.

## B. Direct factorial HC obstruction (unconditional)
Let v=2k, k>=2, G complete loopless directed (or the complete directed bipartite graph with parts A and B, each size k). In any fixed row order, designate first k row vertices A, remaining B; use complete graph for arbitrary fixed order. For each bijection f:A->B, force its k prefix edges, with original labels unchanged. Every such prefix is extendable: choose any k-cycle tau on A and set g(f(a))=tau(a), where g:B->A is remaining successor map. The full alternating cycle is Hamiltonian iff g∘f is a k-cycle. All other suffix targets B impossible because all B incoming columns already used. For each b in B the exact unary suffix support on A is A minus {f^-1(b)}: the excluded arc creates a 2-cycle (not Hamiltonian for k>=2), and any other arc b->a is extendable by a k-cycle taking f^-1(b) to a. Thus R_f determines f, and there are at least k! distinct nonempty languages at this level. Constructive witness establishes every asserted support. Contradiction variant: if f!=f' shared a state, choose b where inverse differs; suffix containing the forbidden inverse edge of f' and allowed for f is accepted under f but not f'. Even exact unary closure identifies rather than eliminates the distinction; preserving forced facts by edge labels or per-context metadata costs/changes model. With all edge weights 1, every tour belongs to weight 2k; isolation acquisition for other tracks cannot change the fact that this unrestricted coefficient has factorially many distinct labeled row suffix states. For complete graph this holds for any fixed permutation of rows. Does not prove bound for arbitrary adaptive HC row order, arbitrary decision diagrams, circuit representations with factored contexts or relabeling, or arbitrary Boolean time. N=Theta(k^2); k! = exp(Theta(sqrt(N) log N)). Complete graph decision trivial; count (v-1)! easy numerically. A raw width lower bound is not numeric-counting hardness.

## C. Adaptive-row native perfect matching control
Reconstruct L01-03 ring chart: n row vertices r_i, n rings c_(j,i) with i,j mod n. fixed arcs c_(j,i)->c_(j,i+1), c_(j,i-1)->r_(i+1); optional entry r_i->c_(j,i) iff M_ij=1. Exactly n row departures and n rings require exactly one entry per ring; then traverse all its vertices and exit to next row, giving precisely one tour per perfect matching, rotation fixed at r_0. Conversely every matching lifts. Each optional entry factor may be replaced by the product of all native traversal arcs (entry, n-1 ring arcs, exit), preserving exact formal polynomial and native weight (nonnegative); labels have O(n) factors, polynomial overhead. All source graph sizes polynomial in n, dense N=Theta(n^4); chart decision via matching, original labels retained. Certified closure by actual forced/deleted matching queries; in complete chart every entry can be included or excluded and native lifts preserve support.

In the complete chart, any adaptive row-choice policy that assigns one fresh matching row at each step, branches over every feasible column and represents exact labeled residuals (suffix matchings encoded by original entry IDs, zero elsewhere) has at least binom(n,k) distinct residuals at depth k. For each k-subset S of columns, adversarially choose an unused member of S whenever the policy chooses a fresh row; all such partial assignments extend. Every suffix matching uses precisely columns outside S, independent of which rows the policy picked. Distinct S gives unequal nonempty labeled suffix sets. At fixed order the width is exactly binom(n,k), since remaining rows fixed and no other constraints. Adaptive result excludes only this literal suffix-state model, not renaming/parameter passing, compact arithmetic circuits, implicit counting, or decision-only matching. At central k, exponential in n; even F2 where permanent=det, so a legal cheap symbolic bypass exists. Over odd characteristic the external arithmetic claim is conditional, but this width theorem is unconditional. Exact-witness verifier control: checking complete successor or matching word is P and does not imply small suffix quotient. Equality/affine controls: pure equality or parity systems may compactly count using factorization/Gaussian elimination rather than enumerate the fixed labels; no bound on arbitrary affine algorithms is claimed. Independent 2x2 blocks show many witnesses need not cause high width.

## D. Supplemental black-box obstruction (unconditional, restricted)
Take a universe U of normalized tours (e.g. all n! native chart tours). A hidden allowed witness set is either U or U minus one element. Even allow arbitrary query subset T of U (possibly specified by weight vector, joint weight equations, affine guard, or richer constraint), oracle returns first at most b present witnesses in a predetermined known order and an overflow bit indicating more than b. Order may be chosen adaptively per query before response, e.g. weighted optimization then lexicographic tie break. On full U, if |T|<=b+1, at most b+1 witness deletions can change the answer; if |T|>b+1, only returned b witness deletions can change the answer, all others leave list and overflow unchanged. If q(b+1)<|U|, choose one unprotected witness after the full-set transcript. Every adaptive answer on U minus that witness is identical by induction. Counts differ by one (also modulo every prime), so exact count requires q>=ceil(|U|/(b+1)). This also handles an empty/nonempty or optimum-witness oracle as restricted variants. Returning exact optimum multiplicity or an unbounded set is not covered. On the native chart, hidden allowed family can be realized as guard true vs one forbidden exact successor word; the latter has a short explicit circuit. **The oracle model hides that guard**; an ordinary algorithm reading it may immediately count n! or n!-1, so this is not a query lower bound for explicit HC inputs or for arbitrary deciders. Same full chart, alternative direct count bypass and literal quotient obstruction. It explains why repeated bounded isolation/optimization responses alone cannot prove generic exact counting. Joint signature queries do not evade this adversary. No oracle argument promoted to P!=NP.
