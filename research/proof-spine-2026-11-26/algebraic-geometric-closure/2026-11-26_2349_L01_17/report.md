## A. Acquired disjoint switch factorization and relaxed reference
Let exact compressed permutation chart on S be P(t)=p composed with product_i g_i^{t_i}, all t in GF2^d, where each g_i consists of one or two transpositions, and all the transposition endpoints are pairwise disjoint across the entire chart. This is a verifiable restricted condition, not a universal theorem about binary charts. Acquisition: take base and basis solutions of exact Gaussian chart, compute g_i=p^{-1}P(e_i), check disjoint supports, and verify the product formula on the *entire* chart, not merely basis evaluations. For each original regional pair option (a,b) with affine option guard, the predicted map at a is p(a) or p(a') according to at most one phase bit (a' the transposition partner), or constant if not switched. Test every mismatch with the option using Gaussian feasibility of the option guard and phase bit; no feasible mismatch => exact formula (every attained option must agree, and occupancy guarantees permutation). O(s) options and polynomial Gaussian work, including failed acquisitions. Arbitrary other guard types are not silently discarded. Guards restricting choices are recompiled into the exact chart; if new basis fails factorization, decline. Verified fixed phase pins can also be substituted before construction.

Temporarily relax each double switch into two independent transpositions tau_j. Build graph whose vertices are cycles of p and edges join the cycles touched by individual transpositions. If disconnected then no combination merges across components, so NO even in relaxed family. If connected select a spanning tree, and flip its edges. At each stage a tree edge joins two previously distinct cycle components and merges them. All endpoints disjoint, so flips commute; this gives a relaxed single cycle C=p composed with tau_R (R set of selected transpositions). This is a coordinate change only: R may violate grouped choices. In fact it must do so on the studied NO family. For an actual choice U, P(U)=C composed with tau_(R symmetric_difference U). ## B. Interlace nullity and exact delta-matroid reduction
KNOWN: Cohn-Lempel 1972, re-stated in Traldi arXiv:0903.4405v2 Theorem 1. For single cyclic permutation C and disjoint transpositions, form A over GF2, symmetric zero diagonal, A_ij=1 iff endpoints of chords i,j alternate in the circular order of C. For any T, cycles(C composed tau_T)=1+nullity(A[T]). Empty principal matrix is nonsingular.

Independent elementary reconstruction: for x a GF2 vector constant on cycles of C tau_T, equivalently x_{C(v)}=x_{tau_T(v)}. At selected chord endpoints a_i,b_i put z_i=x_ai+x_bi; then x_{C(v)}+x_v equals z_i at those two endpoints and zero elsewhere. Traverse C to reconstruct x from a starting bit and z. Total increments zero since each z occurs twice. Summation from a_i through the predecessor of b_i gives z_i plus exactly the z_j of interlacing chords. Consistency with x_ai+x_bi=z_i holds iff A[T] z=0. This is a linear bijection between invariant vectors and starting bit plus kernel, so dimensions yield identity. No counting oracle or finite-field evaluation of a formal HC polynomial.

For double-only groups let Pi be the partition of chord indices into the original pairs. Define linear delta-matroid D(A) by its nonsingular principal submatrices, then twist by R: feasible U iff A[R symmetric_difference U] is nonsingular. Actual grouped choices are exactly unions of pairs. Thus HC exists iff minimum number of broken pairs over feasible U in D(A) twist R is zero. Theorem 3.1 and Sections 5,5.2 of Geelen-Iwata-Murota (2003) give an exact deterministic O(k^4) field-operation augmenting algorithm for this linear delta-matroid parity problem, explicitly including alternating matrices in characteristic two. It starts with feasible U=R (since A[empty] nonsingular), so no discovery of an original tour needed. A positive optimum is a complete NO certificate for this admitted chart. Use the deterministic original algorithm, not the later randomized acceleration. No independent general implementation or proof of the published augmenting algorithm executed here. This is a proved reduction to a known polynomial algorithm, not a novelty claim about interlace or delta-matroids.

Extension to mixed single/double groups (symbolic proof, not executed): give each free singleton chord a distinct dummy partner. Enlarge A by a direct sum with the zero-diagonal all-ones off-diagonal matrix K on the dummy vertices. Any principal K[D] is nonsingular exactly when |D| is even: for even size (I+J)^2=I over GF2; odd size has all-ones kernel. Extend R with one dummy iff |R| odd, or no dummy if even. An actual union of pairs now chooses each dummy iff its original singleton is selected. For any such U, number of chosen dummy indices in the shifted principal subset has the same parity as |R symmetric_difference U_original| because double groups contribute even. Thus whenever original principal submatrix is nonsingular, dummy principal submatrix is also nonsingular, and converse follows from direct sum. If there are no singletons use the double-only case; odd |R| then gives immediate parity contradiction. This preserves all actual choices exactly and doubles ground set at most. General deterministic polynomial algorithm therefore covers independent disjoint single and double transposition switches. Further fixed-budget extension (symbolic): if verified disjoint independent permutation generators include h exceptional generators of arbitrary lengths, branch on their h bits, compose each fixed choice into p, and invoke paired-switch algorithm on remaining groups. For h<=c log2 N (fixed c) and a verified acquisition of exceptions, charge all 2^h branches; NO iff every branch refuted. No universal bound or discovery of a small h shown.

## C. Hostile cancellation family, exact original source

Each consecutive block of twelve separator positions has chord word (0,1,2,3,4,5,3,2,1,0,5,4), local chord IDs offset by 6*block. Distinct positions of each label are endpoints of a transposition. Local A is K_{4,2} adjacency: first four chords nested, last two nested, every cross pair interlaces, no interblock crossings. Group chord pairs (0,1),(2,3),(4,5) independently within each block. Set R0={0,2} in every block and p=C tau_R0. In original phase chart, selecting a group flips both its chords. Thus T=R0 symmetric_difference U contains exactly one chord from each of first two groups, and zero or two last-group chords. If last group absent, A[T] is zero 2x2; if present it is adjacency of K_{2,2}, rank2 on four rows. Both cases nullity exactly2. So every one of 2^(3b) actual phase assignments has 1+2b cycles, correct HC sign but never one cycle. This proves NO for the entire infinite family, even without the general delta-parity implementation. Every block is pair-compatible direct summand; min broken-pair optimum exactly2 per block (all feasible U even since |R0|=2; no union of pairs feasible; U=R0 feasible with exactly two broken).
