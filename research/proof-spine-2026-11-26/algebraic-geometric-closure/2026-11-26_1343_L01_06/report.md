# L01-06 | All-tree obstruction and paid mixed-cut acquisition

## Source and common guard
Simple explicit loopless directed graph G on n>=2 vertices, N=n(n-1) adjacency bits, all graphs admitted, optional polynomial-size explicit guard charged separately (empty guard in all experiments). Original IDs (i,j); witness w is a successor permutation with one cycle using present edges. Each cycle counted once. V(w) in {0,1} for all n^n words, invalid words zero. Polynomial P_G=sum_w V(w) prod_i x_(i,w_i). On complete G this is the formal HC polynomial, with irrelevant diagonal variables omitted. Immutable common family fingerprint: adjacency bit order lexicographic (i,j), i!=j, all bits one for complete G, empty guard, n as length header. For each small test the mask and order are defined in audit.js. Replicas use identical source and IDs, not separate CSP encodings. At root all edges of complete G supported; for n>=3 none forced. With D, test each edge for inclusion/exclusion using guarded NP predicates; retain fixed factors/IDs and original verifier; closure is repeated for actual representative guards after imported deductions, not imposed on signed combinations. No deletion may remove a witness. Exact support on small cases computed by exhaustive reference only.

Named obligation MIXED-CUT-TRANSFER (prior report blob 7aa744fe35a07c48b52ad1e43a22559684b737da). Falsifiers: (i) child row bases fail to span parent; (ii) tree-rank compiler produces a wrong coefficient; (iii) an image set T!=S has no one-cycle witness on complete G or two distinct image sets permit a crossed completion; (iv) every row-tree admits polynomial dimension or every general circuit is bounded by one row-tree rank. (iv) false. Target is formal arithmetic, not numerical evaluation or Boolean decision.

## A. Constructive replica: exact hierarchical acquisition
Fix F_p for a fixed prime p. Given a binary tree on original row IDs, for node S let M_S[a,z]=V(a,z) with a on S and z on its complement, r_S its rank. At leaves list all n one-row assignments. For parent S=A disjoint union B, take the Cartesian product of the actual basis representatives B_A and B_B of child rows. These at most r_A*r_B candidates span the parent row space: fix b,z and apply the child-A row linear identity, then for each resulting a',z apply child-B row identity. The resulting coefficients multiply and are independent of z. This is an exact tensor statement, including signs, not a join of marginal witnesses. Use original ID placement when forming concatenations.

Acquire actual independent rows and pivot suffixes by the L01-05 discrepancy test, reconstructed here. For candidate a solve c M[B,C]=M[a,C] for current nonsingular pivot matrix. Ask whether some suffix z gives V(a,z)!=sum_b c_b V(b,z) in F_p. This is an explicit NP predicate of size polynomial in n and current rank; each call reduces uniformly to ordinary HC, and a witness is recovered with O(n log n) bit-prefix calls. If yes append a,z; the Schur complement is nonzero. If no retain the exact coordinates. After all candidates, each child-basis pair has a unique coordinate vector in B_S. Leaf coordinates likewise. Form vector of polynomials at each leaf by summing x_(i,j) times coordinates, and at each parent combine child vectors bilinearly using acquired coordinate tensor. Inductively each partial-word coefficient is its exact residual coordinates. Nonempty root has rank 1 and its actual representative evaluates to 1; empty root gives zero. Thus root polynomial is exactly P_G over the field. No inference from nonzero scalar count to decision in positive characteristic. Witnesses use actual verified words or D, never signed states. Independent row-cluster bases, not a common linear ordering, allow mixed products across original cuts.

For rank cap R=n^c (fixed c>=1), stop UNKNOWN before appending rank R+1; never NO from cap. Total candidates O(n^2+n R^2); each witness O(n log n) paid D calls plus explicit reduction costs. Recompute pivots in O(R^3) field ops per candidate; output binary arithmetic gates O(n^2 R+n R^3). Field elements constant width for fixed p. Store actual words/pivots, tensors and source O(poly(n,R)) bits. Charge O(n^2) inclusion/exclusion predicates at each actual representative/candidate guard if desired, also after accepted pivots and imports; no semantic enumeration of all signed combinations. All queries include explicit graph, guard, coefficients, indices and actual witness checks; running time polynomial only assuming D. Peak space and cumulative memory bounded by this same total bit-time (or its square if cumulative memory is sum of live-cell counts per time step); aggregate three replicas multiply fixed constants, no free parallelism. Cap on tree search also required below.

Tree acquisition is itself conditionally paid. Given a tree, rank>R at any node has an NP certificate: node, R+1 actual partial words, R+1 suffix words, nonzero determinant of explicit Boolean submatrix. Certificate polynomial for fixed cap; rank<=R everywhere is therefore decidable in P under D. Existence of a tree encoded in O(n log n) bits whose cuts pass is an NP predicate with this fixed polynomial verifier, hence P under D; obtain by bit-prefix self-reduction. This handles discovering the tree, not proving its existence. No circular rank or counting oracle. For arbitrary fields the rank identity below holds, but acquisition proved here only for fixed finite prime fields.

## B. Global algebraic replica: stronger all-cut rank obstruction
Take the SAME complete directed graph and empty guard. For every proper nonempty S of size a, every a-subset T != S occurs as w(S) for a Hamiltonian permutation. Proof: put A=S\T, B=T\S, I=S intersect T, J=V\(S union T); |A|=|B|=t>=1. List A=(a_1,...,a_t), B=(b_1,...,b_t) in original ID order. Construct one cyclic order a_1, all I, b_1, all J, a_2,b_2,...,a_t,b_t, close to a_1. Every vertex visited once. The vertices preceded by members of S are exactly I union B=T. Conversely T=S forces S closed, impossible for a single cycle. Pick one witness w_T per target T. Its prefix on S and suffix on complement form diagonal pair. For T!=U, joining prefix of w_T and suffix of w_U has image sets T and V\U, intersecting since equal sizes and distinct; not a permutation. Hence the selected minor is identity of size binom(n,a)-1 over EVERY field. This replaces L01-05's weaker transposition bound and covers unequal cuts.

Any binary row tree has a node with ceil(n/3)<=a<=floor(2n/3) for n>=3: descend to a minimal node of size >=n/3; its children have sizes <n/3. Every explicit tree tensor network with edge dimension d at this node factors the flattening through d; rank<=d. Therefore every tree, including adaptively acquired tree chosen after complete graph is known, needs an edge dimension at least binom(n,ceil(n/3))-1=2^Omega(n)=2^Omega(sqrt(N)). Rank certificate for exceeding a fixed polynomial cap R need only R+1 distinct T, not the entire exponential minor. Generate lexicographic subsets, skip S, construct tours and verify distinct image sets. O(poly(n,R)) work and storage; do not charge exponential construction of unused witnesses. For an arbitrary tree on complete G, one such cut suffices to reject that representation. This is a restricted result, not an unrestricted arithmetic or Boolean lower bound.

## C. Adversarial replica
Perfect matching full n-by-n matrix: all a-subsets T occur as images (including S), and the same cross-image proof gives identity size binom(n,a) at EVERY row cut. Yet matching decision is in P and permanent equals determinant over F_2, with polynomial-size general arithmetic circuits. Thus even minimum over all row trees of maximum cut rank is not an unrestricted circuit lower bound. Equality product prod_j(x_j0 y_j0+x_j1 y_j1) has exponential separated rank, linear general arithmetic gates. Affine GF(2) decision remains Gaussian elimination; exact count/weighted coefficient tensor is a different output. Complete HC decision itself is trivial, and exact-witness verification is polynomial on all graphs. Bounded-width independent blocks can be compiled by local products. These are counterexamples to attempted inference, not reductions of a narrower easy promise to general HC.

Further complementary attempt on SAME complete source: nonnegative arithmetic circuits over R_{>=0}, binary +,* with constants, no cancellation. For every live gate choose a monomial context from an output parse tree; any gate monomial multiplied by this context appears in output by positivity. Since every output monomial has exactly one variable from each row and each column, the gate has fixed row and fixed column subsets, same size a. In every output monomial parse tree, a balanced gate of degree in [n/3,2n/3] exists by descent (sum selects child; at product choose child with degree >=n/3 if present; otherwise parent's degree <2n/3). All tours attributed to a particular such gate map its fixed row subset onto its fixed column subset, so at most a!(n-a)! of them, regardless of other contexts. Union cover of all (n-1)! tours implies number of live gates >= binom(n,ceil(n/3))/n. No disjointness is needed for this upper bound on coverage; no count interpreted as vote. This is a classical monotone support argument, not new priority and not valid with cancellation. It handles varying cuts in a nonnegative circuit but excludes legitimate determinant-style signed computations.

## Integrated result and final attempt
Import only B's certified identity witnesses into A's exact guarded acquisition. Verify each witness and its image set on original IDs, reclose root (no change for complete G). Distinct images certify R+1 independent rows, so capped A can reject a candidate tree without full rank search; C prevents upgrading this to a NO answer or unrestricted lower bound. This is a combined certified early overflow, not improved general HC decision coverage. Same theoretical R=n^c cap for all replicas; actual integration test uses R=n. Standalone reference compiler small cases uses exhaustive suffix inspection, not capped D; no equal-cap speed comparison or live-agent concurrency measured. All lanes interleaved within one execution.

At stagnation try general mixed-cut signed set-multilinear circuits (gate carries original row subset, sums equal scopes, products disjoint scopes, scalar constants empty scope). For fixed p and gate cap s=poly(n), existence/acquisition is conditionally in P under D: guess explicit typed circuit of size <=s, verify syntax, ask whether some full word w has coefficient different from V(w). Because output is set-multilinear with full row scope, evaluate on one-hot assignment selecting x_(i,w_i) at each row to compute its coefficient, in O(s) field ops. Inequivalence is NP with explicit witness w; under D equality is P, circuit existence is NP with this verifier, then P, and bit-prefix acquisition is paid. This accommodates arbitrary differently grouped mixed products and cancellations; no claim for untyped general circuits where one-hot evaluations miss extraneous monomials. It closes only acquisition if such circuits exist, not universal polynomial existence. No sum of track votes. Strongest surviving conditional lemma is exact acquisition of capped typed circuit; first OPEN existence/transfer from arbitrary uniform Boolean HC decider to small formal typed or unrestricted circuits. Neither rank nor monotone proof closes this.
