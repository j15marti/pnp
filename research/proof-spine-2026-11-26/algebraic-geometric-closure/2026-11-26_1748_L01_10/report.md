Named obligation ADAPTIVE-GUARD-TRANSFER: can a polynomial explicit adaptive guard DAG bypass the static bijunctive chart count? We give an exact conditional-on-width simulation to a monotone Boolean circuit, hence a lower bound on syntactic live *opposite-polarity* conflict. Quantifiers: for every finite binary fan-in negation-normal-form (NNF) DAG C over m original bits, with constants and literal leaves, arbitrary fanout/sharing, root g*, there is an effectively constructed monotone Boolean circuit for U(C)(x)=exists y<=x C(y)=1, with explicit gate and work bounds below. If C computes HC then U(C)=HC; more strongly C may compute a nonmonotone exact-witness verifier as long as U(C)=HC. No field, no arithmetic counting and no P=NP assumption. Falsifiers: (1) shared child with conflicting polarities lost in join; (2) lost positive pin outside chosen OR child; (3) same-polarity common variable unable to amalgamate; (4) treating overflow or high syntactic width as general NO/hardness. Three interleaved mathematical replicas on identical original ID space, not concurrent independent agents.

## A. Constructive local table compiler
For gate g let P_g and M_g be sets of indices occurring positively and negatively in its syntactic descendant DAG, S_g=P_g union M_g. Compute by forward unions, with zero scope for constants. For AND gate with children u,v define K_g=(P_u intersect M_v) union (M_u intersect P_v). For OR/leaves K_g=empty. These sets are syntactically acquired, not semantic relevance queries. Remove unreachable gates. Define B_root=empty, propagate backwards in reverse topological order:
 B_h <- B_h union ((B_g union K_g) intersect S_h)
for each parent g and each child h. Include all parents, not just one path. B_g subset S_g. Put E_g=B_g union K_g, b=max |B_g|, e=max |E_g|<=2b (K_g subset each child's B, so |K_g|<=b). Gate IDs retained.

For each alpha in {0,1}^{B_g} construct a monotone Boolean function
 F[g,alpha](x) = exists y on S_g, y<=x|S_g, y|B_g=alpha, C_g(y)=1.
For any Q subset B_h define F[h|Q=eta] as OR of all F[h,gamma] with gamma|Q=eta. Build only needed Q tables; group entries by restriction, so O(2^|B_h|) binary OR gates per parent-child edge, not per target assignment. For a leaf, use constants or x_i (positive literal), 1 unless pinned 1 (negative literal); reject contradictory pin. In all cases require all alpha=1 bits present in x. A positive literal pinned 0 yields 0. A negative literal pinned 1 yields 0. Constant leaves have empty scope.

For parent g, for each eta on E_g use child projection tables with Q_h=E_g intersect S_h, which is subset B_h by construction. If g is AND, take both projected functions and AND; if OR, take their OR. For each alpha group terms by eta|B_g=alpha and OR. Finally AND all x_i with alpha_i=1 (essential when chosen OR child omits a pinned variable).

Completeness: restrict an actual y to children; its E assignment gives an included term and every positive pin is available. OR soundness: choose the satisfied child, extend outside its scope by alpha on B_g and zero otherwise; positive pins outside the chosen child are explicitly checked. AND soundness: select child witnesses y_u,y_v. They agree on E_g intersect S_u intersect S_v. For any other shared variable, both children have only positive occurrences of that variable, or both only negative occurrences; otherwise it belongs to K_g. Choose the coordinatewise max of witnesses for positive-only shared variables, min for negative-only shared variables. Each change preserves the truth of its own child by unateness in that coordinate. Unshared variables are copied, E pins unchanged, all y<=x. Thus a joint witness exists. Extraneous child B pins introduced by other parents can be discarded after gluing, since the corresponding child witness remains satisfying and parent does not require those pins. This is exact even if the same child is used twice or DAGs reconverge. Induction proves root output F[root,empty]=U(C). No sum=OR confusion.

## B. Global trace reconstruction and resource theorem
Alternative semantic reconstruction: a successful NNF trace chooses one satisfied child of every OR occurrence and both children of every AND occurrence. Root truth on y iff it has a trace with all literals satisfied by y. Upward closure iff a consistent trace exists whose positive variables are available in x; inconsistent traces have zero contribution. At every AND combination, the only possible cross-trace contradictions lie in K_g. The propagated B assignments fix every such cross conflict in both children and all ancestor pins, so grouping child tables by restrictions precisely discharges these conflicts. At OR there is no simultaneous child demand; check parent positive pins even if outside the selected trace. This independently reconstructs why local conjunction and disjunction are sound without needing to enumerate traces or requiring their disjointness. Trace consistency is a proof invariant, not an algorithm that unfolds shared DAGs.

Size: Let s count input gates, including literals/constants, and wires (binary fan-in means O(s) wires). The monotone circuit uses
 O(m + sum_g (1+|B_g|)2^|B_g| + sum_g 2^|E_g| + sum_(g,h) 2^|B_h|)
 gates, with g,h over parent-child edges. In particular O(m+s(b+1)2^(2b)), or O(m+s(e+1)2^e), since |B_g|<=e and |E_g|<=e. This counts child OR aggregation once per edge, positive pin tests, terms, parent grouping and shared output gates; no exponential recomputation of child tables. Gate descriptions have O(log output size + log m) bits; dense supports use O(sm) bits, set unions and restrictions polynomial in s+m. Deterministic bit work polynomial(s+m+size) with a fixed exponent, using direct indexing, sorting or even polynomial dictionary scans. No arithmetic field/constant bit costs except Boolean bits and bounded index counters. Compute the tariff before expansion using saturated integers and refuse if any fixed polynomial allocation would be exceeded. When s and actual total tariff are polynomial in original N, acquisition, all failed scans, cap checking, all replicas and sharing, evaluation and reconstruction can be charged polynomially; peak <=total work, cumulative <=work^2 in a standard explicit bit implementation. For the theorem of nonuniform existence only, no circuit acquisition is assumed; to use this as a solver, C must be given or paid for. No claim of universal small tariff.

Decision-sensitive consequence (KNOWN external monotone theorem): Alon-Boppana 1987 section 5 p20, using their theorem 3.9, gives undirected HAM monotone circuit complexity exp(Omega(n^(1/6)/(log n)^(1/3))). For n>=3 set x_ij=x_ji=z_{ij} (i<j) in directed HC; undirected HC iff symmetric directed HC, with actual witness orientation both ways. This is a linear-size monotone projection of input bits, so the same bound holds for directed HC. Hence any NNF C (even not itself monotone) with U(C)=HC must satisfy
 log_2(s+m)+e+O(log(e+1)) >= Omega(n^(1/6)/(log n)^(1/3)).
For polynomial-size s, e and b are Omega(n^(1/6)/(log n)^(1/3)), and a fixed logarithmic kernel e=O(log N) is impossible. This covers adaptive nonuniform guard DAGs compiled as below, arbitrary fanout, and nonmonotone exact-tour verifiers. It is not an unrestricted circuit bound.

Witness and source guard closure: on accepted ordinary HC mask x, repeatedly try deleting each available edge using the exact compiled root decision. Keep deletion if accepted. Because HC is monotone, once a deletion fails it cannot later become possible; final inclusion-minimal YES graph is exactly a tour. This needs <=m+1 evaluations and preserves original IDs. To determine whether an available edge i->j is possible in any witness, retain it while deleting all other outgoing edges from i and incoming edges to j, then test HC. Every tour in this restricted mask must use i->j; conversely any original tour using it survives. Mandatory iff removing it makes NO on a previously certified YES mask. Thus exact unary support closure takes <=2m+1 evaluations when the compiled ordinary HC root is available. Each returned deduction is guarded by original mask; no free oracle. This closure is not required for the lower bound, and the general large-case closure algorithm was not executed. For chart-only roots, only chart support deductions are licensed.

## C. Adversarial controls and adaptive guard transfer
An explicit deterministic adaptive decision DAG with test g_v and successors v1,v0 becomes C_v=(g_v AND C_v1) OR ((NOT g_v) AND C_v0), with chart/constant terminal circuits; preserve sharing. General Boolean tests can be converted to NNF by building both polarities per gate using De Morgan, O(s) gates. No duplicate unfolding. With read-once literal tests along every root-leaf path and constant terminals, conflict sets K are empty: no descendant can use the tested variable. Consequently such branching programs for HC require the same exponential monotone circuit size up to constant conversion. With general input-dependent guards, the compiler is correct but e need not be small. The theorem is about acquired NNF circuits, not arbitrary polynomial machine steps. No claim that P implies bounded e.

Perfect matching is a decisive control: Cavalar, Goos, Riazanov, Sofronova, Sokolov ECCC TR25-102 revision 1 (2025-11-06) theorem 1 gives bipartite Match_n monotone circuit size >=2^(n^(1/3-o(1))) (n vertices on each side). Match is in P by augmenting paths; hence even its polynomial general NNF decision circuits must have e>=n^(1/3-o(1)) up to constants for this compiler. Their theorem 2 gives a monotone odd-factor language in L with exponential monotone lower bound; therefore low conflict width is not guaranteed even by deterministic logarithmic space. Matching control is on same original availability semantics, not a new HC hardness reduction. Equality and parity illustrate the distinction between original relation and upward closure (even parity contains zero, closure constant 1; odd parity closure OR of available bits). Gaussian solution of affine systems remains a separate exact terminal; no inference that their encodings have small e.

Naively replacing each negative literal by 1 makes x AND NOT x into x; this fails even as a spurious branch added to a correct HC circuit. The compiler suppresses the branch exactly. Conversely, a positive overlapping CNF has K=empty even if ordinary occurrence overlap is large. Scoped block construction from L01-09: partition n=3r into triples with two independent three-edge traversals per triple, then augment every local option disjunction by a contradictory branch x_e AND NOT x_e for a different local edge. The global mixed-polarity count is r but e=b=1; local support closure is exact and the product retains all original tour lifts for this chart. A polynomial-size circuit can instead be padded with an identically zero branch (AND over all x_i) AND (OR over all NOT x_i); at that AND all m original variables conflict, e>=m, without changing the function. Thus syntactic width can be large for easy reasons. No source-general width lower bound can be claimed from a particular padded encoding. Compact independent factors remain a bypass.

Stronger decisive equivalence to prior static chart result: if arbitrary polynomial HC decision exists, use ordinary edge-deletion self-reduction (<=m queries) to obtain one tour on YES, then dynamically output its conjunction of n edge literals as a sound one-chart certificate. On NO output NONE. Conversely a uniform polynomial-time sound, complete chart selector with polynomial-time chart evaluation gives HC in P. This proves that static factorial chart count does not bound number of charts acquired per execution. Even the exact-tour verifier (P) maps each exact-tour input to its own chart in polynomial time, covering factorially many possible charts across inputs; this weaker language is not ordinary HC. Thus unrestricted adaptive selector existence is equivalent to the actual decision problem, not a solved bridge.
