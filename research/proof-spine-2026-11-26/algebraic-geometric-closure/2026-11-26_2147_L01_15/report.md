## A. Regional path demand and Hall certificate
Let S be any nonempty proper vertex set, and R_1,...,R_t a partition of V-S into nonempty regions with no arcs between distinct regions in either direction (weak components, or verified unions of them). On an arc-deletion residual F, let nu_i be maximum matching size in the bipartite split graph of internal arcs of R_i. Define d_i=max(1, |R_i|-nu_i). In any HC, deleting S gives directed path segments; every segment lies within a single region. If k_i segments cover R_i they use |R_i|-k_i internal edges, forming a matching, hence k_i>=d_i. Each segment requires a distinct predecessor in S and a distinct successor in S. Create d_i slots for region i, each adjacent to s in S if some arc s->R_i exists; second independent graph with R_i->s. A true HC supplies a matching saturating all slots in both graphs. Thus failure on EITHER side is a sound NO certificate. Equivalently there is a region subset J with sum_{i in J} d_i > |union_{i in J} N_i| on that side. Maximum bipartite matching finds such a Hall set by alternating reachability from unmatched slots. All slots for the same region have the same neighbors, so enlarging any deficient slot subset to its full regions preserves deficiency. Slot total <=n; all integer costs polynomial. If sum d_i>|S| can reject immediately. On a DAG region, matching deficit equals exact minimum path cover; on cyclic regions it is only a lower bound. Never equate separate ingress and egress feasibility with joint support or a tour. For t=1 the same necessary test applies.

## Stagnation complement and limitation
For every fixed k, take bidirected universal clique U of size s>=k+8, joined to s+1 disjoint bidirected cliques each of size b>=k+8. No interlobe arcs. Genuine NO: deleting U leaves s+1 components but a tour would have at most s paths. All compatible pins of at most two arcs extend to a cover of either sign: pinned arcs are disjoint directed paths or a 2-cycle; close each incomplete path using a fresh unused universal vertex, preserve any 2-cycle, and cycle-cover each remaining clique internally (at most 6 vertices used in forced paths/closures; enough remain). A free untouched lobe of at least four vertices can be a single cycle or two cycles of lengths 2,b-2, toggling sign. Thus single-pin target support contains all arcs compatible with the pin, and is strongly connected via unused universal vertices (forced head reachable from forced tail; forced tail reached from free connectors, forced head reaches free connectors). Unpinned target support is original. For any nonempty separator T of size<=k after one pin (or none), residual outside T has a single weak component because at least s-k-2 unpinned universal vertices remain. Internal split matching deficiency <=1: if both pin endpoints inside, cover induced clique-lobe graph with the forced path closed via fresh universal vertex, remaining internal cliques each size>=2; if neither inside, ordinary internal cover; if exactly one inside, delete at most one row or column from an internal perfect matching. Thus d=1. There is at least one arc each direction between T and complement in pinned support: for |T|>=2 an unpinned outgoing tail and incoming head in T exist; connect to a fresh universal vertex outside, and for singleton T the only potentially restricted outgoing or incoming arc goes outside T since no loops. Therefore all bounded-separator Hall tests pass and all parity guard tests pass. This is a symbolic infinite fixed point for this particular fixed-k acquisition/one-pin strategy. It was not scaled in code this run. The same family is cheaply refuted by choosing the actual large universal separator U (detect universal vertices by degrees), so it is not an all-decider lower bound.
