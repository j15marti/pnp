## A. Exact hybrid theorem
For any explicit simple bipartite assignment with integer edge weights and perfect matching, acquire max-weight M0 and integral dual U,V; verify dual dominance and tightness on M0. Set W0=sum weights M0 and s_e=U_i+V_j-w_e>=0. Any matching M has deficiency W0-W(M)=sum_{e in M}s_e. For target weight k, d=W0-k; d<0 rejects, d=0 accepts by M0. Contract each M0 pair into one directed vertex, arcs i->M0^{-1}(j) labelled by original edge and slack. Omit the reference self arcs (all tight). Simple assignment means no additional self arcs; parallel edges require a separate treatment. Every matching is represented by vertex-disjoint simple directed cycles plus unused reference edges, and conversely. Since all slacks are nonnegative, no arc of slack>d can occur in a target matching. Delete such arcs. Optionally delete arcs with s(i,j)+shortest_s(j,i)>d; not needed or implemented. This is a certified restriction for the same target, not a claim about other target values.

Compute SCCs of the retained nonreference graph; no directed cycle crosses SCCs. Each SCC with >=2 vertices is admitted if some vertex h has acyclic induced complement. Find h by trying all its vertices and checking topological ordering; no oracle. Within such SCC every nontrivial cycle contains h, hence at most one can be used. For each outgoing arc h->v initialize attained cost set of paths at v with slack of arc, keeping costs <=d. Traverse the DAG excluding h in topological order, propagate attained cost x+s along each arc, and collect return arcs to h. Every such path is simple, all return cycles attained, and every cycle appears. Include 0 for no switch. Retain predecessor for each attained cost if witnesses needed. Different SCCs are vertex-disjoint; exact truncated sumset convolution across SCC supports gives all and only achievable deficiencies <=d. This supplies a direct proof by contradiction of NO when d absent: any target matching survives pruning, its cycles lie in SCCs, each admitted SCC contributes an actual DP cost, so d would occur in convolution. Conversely each tuple of costs has mutually disjoint actual cycle witnesses by construction. Return UNKNOWN if admission fails, not UNSAT. Empty SCC or singleton with no nonreference self arc gives {0}.

Recognition O(t(t+m)) indexed operations, path DP O((m+t)(d+1)), convolution O(t(d+1)^2), with O((t+m)+(t+1)(d+1)) records including backpointers (store one per state and convolution stage). Weight/slack arithmetic bit lengths polynomial in input bits; use exact integers. This is pseudo-polynomial in numeric d, polynomial if d<=N^c for fixed c, particularly red-blue t-edge assignment where d<=t. No binary-weight claim for unrestricted d. Weighted matching optimization/dual acquisition is polynomial and paid. General recognition finds one hub per SCC; original source can have unbounded treewidth and no small global FVS. Importing dual pruning before decomposition changes the geometry on which path DP operates. Reconstruct original cycle pack and native witness with actual IDs when a positive result occurs.
