## 1. Affine-section obstruction
Let X=F2^d with uniform measure. An affine one-hot section for a native variable is five affine Boolean functions f_i on X representing its indicators. If they are a valid one-hot vector on more than 3/4 of X, they are valid everywhere: any pair with simultaneous value1 has solution set an affine flat of codimension at most2, density >=1/4, contradiction. Hence their supports are pairwise disjoint. Every nonconstant affine indicator has weight1/2, a nonzero constant has weight1. Coverage >3/4 forces either a single constant1 or exactly two complementary nonconstant affine functions. Thus every variable takes at most two colors globally.

For any C or R constraint on three such variables, express its value triple via at most three affine scalar bits. If their rank<=2 and the relation ever fails, one nonempty bad fiber has density>=1/4. If rank3, the three 2-color sets have a repeated color since six positions use only five colors; both C and R forbid equal values, so the assignments putting that shared color at those two positions are bad for both values of the third. Thus every non-tautological native constraint has bad density>=1/4. This is valid for actual distinct source IDs, regardless of correlations of the affine maps. Finite check: all 1000 unordered two-color boxes for each C and R, no 7- or 8-accepting box (C max4, R max6). The proof needs only the >=1/4 bound.

Now suppose an exact pp gadget for OR3 (or any Boolean relation accepting all but one word on r>=3 bits) has a satisfying extension in which every native one-hot indicator is a fixed affine function of the r input bits, for all accepted inputs. It is one-hot on >3/4 of the cube, so valid everywhere. Every native clause holds on >3/4, so holds everywhere. Evaluating this same section at the forbidden word yields a native witness, contradicting exactness. Input representation must be fixed and agree with the input bits also at the forbidden word; ordinary Boolean-wire embedding has this property. No affine section of that form exists, irrespective of number of auxiliaries. A nondeterministic nonlinear lift remains possible, as old gadgets show.

Generalization to bit PHP (Braun v2 source formula): n=2^ell holes, n+1 rows of ell bits; each individual forbidden pair-and-label clause has bad density n^-2. A union of t<n^2/4 such clauses has bad density <1/4. If a globally valid affine section pulls each full native constraint back to a consequence of at most t original clauses, every native constraint is tautological; then even an UNSAT source would lift EVERY source assignment to a native model. Contradiction. If each variable's one-hot validity itself is justified by such a local set, the first argument makes it globally valid too. This is a lower bound on number of source axioms in such a local justification, not work/time. The ordinary one-hot CNF individual forbidden triple clauses can each have bad density 1/8 rather than 1/4, so do not apply the grouped 1/4 bound to each separately. Even for individual width<=3 axioms, any non-taut affine pullback fails on >=1/8; pairwise one-hot constraints force disjoint supports first, after which the at-least-one axioms have bad density>=1/2 or zero. Thus a one-source-clause axiom-by-axiom transfer also fails for ell>=2. Global nonlocal proof translation is not excluded.

## 2. Exact auxiliary-free parity-line expansion theorem
For k>=1 disjoint pairs of actual Boolean inputs x_i,y_i, native exact OR gadgets compute o_i=x_i OR y_i. Set q(x,y)=XOR_i o_i=sum_i(x_i+y_i+x_i*y_i) over F2. The valid native affine line XOR_i [o_i has normalized color1]=b pulls back under the actual canonical lift to q=b. Claim: any equivalent conjunction of disjunctions of affine F2 equations over ONLY the 2k original input bits has >=2^(k-1) clauses, and if the rejected level is the minority level then exactly 2^k-1 are necessary and sufficient. This is exact equality of predicates on the whole cube, not proof-line consequences modulo an UNSAT base or auxiliary-extended equivalence.

Each clause's falsifying set is an affine flat (possibly empty), since all its affine equations must fail. In an equivalent conjunction, these flats must cover the rejected level and individually lie in it. The polarization of q is B((x,y),(u,v))=x dot v + u dot y, a nondegenerate alternating form on F2^(2k). If q is constant on a+W, B vanishes on W by second differences. Hence W subset W^perp, dim W<=k. Each rejecting flat covers at most 2^k points. Product bias of independent pairs is (-1/2)^k since OR has three true inputs and one false; level sizes are (4^k+(-2)^k)/2 for zero and (4^k-(-2)^k)/2 for one. Both >=2^(2k-1)-2^(k-1). Taking ceilings yields >=2^(k-1). Majority level lower bound is 2^(k-1)+1.

Sharper minority argument: for any k-dimensional isotropic W, W=W^perp. On each coset a+W, q restricts to an affine function with linear part L(w)+B(a,w), where L(w)=q(w)+q(0) restricted to W is linear. The map a mod W -> B(a,.) is bijective onto W*, by nondegeneracy. Exactly one coset is constant and all other cosets balanced. The sign of the global nonzero bias is therefore the sign of this unique constant coset. No minority constant k-flat exists; minority flats have <=2^(k-1) points. The minority has 2^(k-1)*(2^k-1) points, hence at least 2^k-1 clauses. For an explicit matching upper bound, fix each x=a, then q is affine in y; one clause (x differs from a) OR (that affine equation equals b) handles each a. If a=(1,...,1), q is constant k mod2, the majority value; all other x slices contain 2^(k-1) of each level. For the minority rejection, the all-ones slice needs no clause and the other 2^k-1 clauses suffice. General upper bound 2^k clauses. Thus exponential exact expansion of ONE affine native line, whose raw length O(k log k), when its actual nonlinear gadget outputs are eliminated. Can use O(k) local extension predicates and one affine equation instead; no contradiction.

This directly refutes generic polynomial-size exact linewise expansion after nonlinear substitution, even for disjoint local ORs and regardless of linear-clause width, not a lower bound on proof size of the full native instance. Do not infer every proof contains this line or cannot avoid it. The first audit attempt assumed both levels attain k-flats; failed at k=1. Corrected to majority k/minority k-1; full symbolic proof above and exhaustive rerun below.
