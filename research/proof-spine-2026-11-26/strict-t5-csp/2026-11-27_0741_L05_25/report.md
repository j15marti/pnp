## Exact theorem (conditional on admitted decomposition, not arbitrary source)
For every explicit weighted bipartite graph with t rows and t columns, nonnegative integral weights and numeric target d <= N^constant, let the edge set be partitioned into pieces arranged on a supplied, verified tree. Each vertex's incident-piece set must form a connected subtree. Every vertex incident to at least one edge. Each piece has at most b physical boundary vertices (vertices incident to another piece), and each piece either has fixed size, or a supplied set of r_i edges whose removal makes the piece planar. Alternatively accept a piece only if all required balanced boundary-deleted minors pass paid Pfaffian recognition (or use a separately justified exact minor oracle). Then exact target count is computable in poly(N)*(sum_i 2^(b_i+r_i) + sum_i child_degree_i*4^b_i) bit time, with fixed polynomial factor, assuming b_i+r_i <= C log N for fixed C and polynomial total size. For a signable-minors piece r_i=0; fixed-size pieces use direct enumeration. No need to retain how boundary paths pair. This differs from Hamiltonian cycle / cubic-coloring connectivity targets; no transfer to those sources without an adapter.

Proof: assign each original edge one piece. For each boundary subset U compute the polynomial P_i(U) of matchings in the piece covering all private vertices and exactly U on its boundary. Delete unselected boundary vertices; unbalanced shores give zero; otherwise this is weighted perfect matching on a smaller graph. Remove edges of cost>d. Planar-after-exceptions: enumerate subsets of exceptional edges in the minor, reject collisions, delete occupied endpoints and every other exception, multiply forced monomial, and obtain a fresh planar signing. These branches are disjoint. For planar residual use RST or Kasteleyn signing; for other signable minors use RST recognition independently. Evaluate at base t!+1 and recover exact digits; each minor matching count <=t!, polynomial degree <=td, O(t^2(d+1)log(t+1)) determinant integer bits; fraction-free elimination polynomial bit cost. Truncate polynomial at d, since no negative costs.
Root tree; initialize piece mask table with P_i. For each child, child's message on adhesion records occupied physical vertices and total weight. Join disjoint occupancy masks by union and convolve weights; add multiplicities. Running intersection guarantees all overlap with processed subtree is in its adhesion. Require each vertex not in parent adhesion to be covered exactly once before forgetting; project to parent adhesion. At root require all covered. Inductively bijective between counted tuples and partial matchings of processed edge partition; root is full perfect matching. In the contracted permutation interpretation each port needs independent row and column bits (four states per matched pair), not only occupied/unoccupied, and no path connectivity is required. Global pairing is irrelevant to arbitrary cycle covers but not to a single cycle. ## Critical falsifier: signing is not hereditary under arbitrary boundary deletion
Take a 4x4 matrix with full top-left 3x3 and edges (row4,col1),(row1,col4), no others. Every full matching forces both extra edges; remaining K2,2 can be signed. Delete row4,col4: K3,3, not signable. For fixed two rows, each of three column-pair transpositions requires product of four signs -1; multiplying gives +1=-1. Executed 2048 full signings, 1024 coherent; 512 minor signings, zero coherent. Thus a single global/local signing is insufficient when conditioning deletes arbitrary unmatched boundary vertices. Edge-zeroing on fixed shores remains safe; planar-after-edge-exceptions is hereditary under vertex deletion, so fresh minor signing repairs the theorem. This is a scoped falsification of a possible stronger extension, not a retraction of L05-24 fixed-shore diagonal conditioning.
