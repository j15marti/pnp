## Theorem
Acquire and verify maximum-weight assignment M0 and integral dual U,V. For every perfect matching M, W0-W(M)=sum_{e in M}(U_i+V_j-w_ij). Contract reference pairs; omit reference self arcs, represent other edges by nonnegative-slack directed arcs retaining original IDs. Matchings correspond exactly to vertex-disjoint directed cycles plus reference edges. If d=W0-k>=0, prune arcs of slack>d; no target matching can use one. If d<0 refute; d=0 attained by M0. SCC decomposition is exact because no cycle crosses components. Assume each retained SCC admits feedback vertex set H of size <=f, where f is a fixed constant. Discover by testing all subsets of size <=f with a topological sort; if not found return UNKNOWN.

For each subset B of H and each permutation pi of B, split each active hub into source and sink copies. Remove unused hubs. Keep arcs from active source copies to ordinary vertices or active sinks, from ordinary vertices to ordinary vertices or sinks, and direct hub-to-hub arcs as source-to-sink arcs. The split graph is a DAG: sources have no incoming arcs, sinks have no outgoing arcs, and the ordinary remainder is acyclic. Require pairwise vertex-disjoint paths from each source h to sink pi(h); paths may use no other terminals. A selected collection of cycles induces exactly such paths and permutation, by cutting at active hubs. Conversely join the paths at their corresponding hubs; since pi is a bijection, each active hub has exactly one in/out connection, and internal vertices are disjoint, so this yields a disjoint cycle collection. Empty subset gives cost zero. Original IDs retained on arcs; reference edges fill all unused vertices. No cycles can avoid H.

For prescribed endpoints, maintain one token per path and the accumulated total slack c<=d. Choose a topological ordering with all sources first, sinks last. Advance the unfinished token at minimum topological position along an arc, prohibiting occupied vertices and wrong sinks. A finished token stays at its own sink. Every abandoned internal vertex is earlier than all unfinished tokens at abandonment, since the earliest token moved strictly forward. All later positions increase, so no future path can reuse any abandoned vertex. Hence token positions and total c are a sufficient exact state; no history or collision oracle needed. Conversely every disjoint path tuple admits the earliest-token interleaving and is represented by transitions. State merging preserves attainability, because retired history cannot affect any future move. Record one predecessor per state if reconstruction is needed. Collect exact total costs, union across subsets/permutations, then convolve across SCCs up to d. This proves sound NO by contradiction: a target matching would produce a surviving tuple and hence d in the support. The converse gives explicit witness reconstruction.

For fixed f, discovery O((t+1)^f(t+m)), conservative token transition bound O(2^f f! (t+2f+1)^f (m+t+1)(d+1)), summing over components with a further safe factor t+1; convolution O(t(d+1)^2). Storage bounded by the same polynomial, including states/backpointers, exact integer arithmetic on poly(N)-bit integers, and original input. Dense state arrays or sorted deterministic tables avoid free hashing. For fixed f and d<=N^c fixed c, one uniform polynomial exponent; explicit index access can be implemented by scanning polynomial space for polynomial slowdown on ordinary bit machines. Peak S polynomial, cumulative memory <=T*S on same execution. Failed recognition, all subsets/permutations, unsuccessful states, sharing and reconstruction charged in these bounds; no counting oracle. f=O(log N) alone DOES NOT imply polynomial since t^f can be quasipolynomial.
