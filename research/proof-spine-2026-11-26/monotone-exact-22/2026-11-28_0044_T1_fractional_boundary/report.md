## Theorem: polynomial Hall-robust exact count shell

A set B of Boolean boundary selectors is assigned injectively to bins: when a selector is true, all variables in its assigned bin are false. Assume the entire regional formula consists of precisely the demand clauses, bin pair exclusions and these selector-bin exclusions (duplicates allowed), no other regional constraints. Let H be the bipartite graph of demand rows and bins, with an edge if their variable intersection is nonempty. A boundary mask extends iff H after removal of the blocked bins has a matching saturating the demands. Necessity: select a true variable from each row; pair exclusions ensure distinct bins. Sufficiency: select one original variable on each matching edge and set every other interior variable false. This is an exact source reconstruction, not a relaxation.

Define delta=min_{nonempty S subset demands} (|N_H(S)|-|S|). Since every bin has an incident demand, delta<=q-d. If delta=q-d>=0, the complete jointly attainable boundary relation is EXACTLY sum_{t in B} x_t<=q-d. For a mask with k<=q-d true selectors, any demand subset S loses at most k neighbors, leaving |N_H(S)|-k>=|S|, hence Hall's condition and an integral matching. If k>q-d, the remaining total bin capacity q-k<d, impossible. The entire count-shell support, and a polynomial witness-lifting procedure for each admitted mask, follow without enumerating 2^|B| masks. This is a certified nonlinear response representation; full affine hull can still have dimension |B|.

For every nonempty S containing i the canonical cut with its exact neighbors has capacity d-|S|+|N(S)|. Hence d forced-row max flows each of value q prove delta>=q-d; all bins-to-sink give upper q. Integer augmenting paths take <=q augmentations per network (capacities integral, sink capacity q); polynomial in explicit original regional encoding. Store arc values and independently check capacities, conservation and flow q; no reliance on an optimizer's claim.
