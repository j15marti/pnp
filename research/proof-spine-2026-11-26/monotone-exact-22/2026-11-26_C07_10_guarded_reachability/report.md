## L1 PROVED: bounded guarded-path closure with complete coverage verification
After verified parity/affine closure and actual guards, assume a supplied or acquired common independent protected boundary basis b_1,...,b_b and private quotient basis t_1,...,t_p (C07-09). Local factors yield conditional 2CNF on private coordinates when boundary fixed. Further admission: explicit polynomial-length lists of consistent conjunctions of boundary coordinate literals that enable each directed implication edge; explicit boundary-only forbidden guards. For raw fixed-arity tables whose offsets depend on at most a fixed number of these boundary coordinates, obtain these lists by constant-size truth tables. Arbitrary dense affine offsets need not admit short coordinate guards; check, decline if cap fails. Boundary guard labels refer to actual chosen coordinates, not independent copies of dependent forms. Edge lists can also be explicitly supplied if exact source correspondence is verified.

For fixed integer d>=0, maintain for every ordered pair of private literals (u,v) all discovered path guards of size <=d, each certifying an actual path (store predecessor and edge provenance). Initialize empty guard on every (u,u). Append each outgoing edge to each retained state, form literal-set union, discard inconsistent unions, retain consistent unions of size <=d if new. Saturate finite state universe. Crucial verification: for EVERY retained path guard g for (u,v) and every outgoing edge (v,w) with guard h, if g union h consistent, require some retained guard g' for (u,w) with g' subset of g union h. This includes oversized unions. If any fails, decline UNKNOWN; never silently drop long guards. Soundness: all retained guards imply existence of an enabled path. Completeness for each fixed boundary assignment by induction on path length: the identity is covered; if an actual enabled path prefix has a retained guard contained in that assignment, append its active edge and use the coverage test to find a retained guard contained in the same assignment. Thus exact reachability is the disjunction of retained guards, no boundary-word enumeration. This condition is sufficient, not necessary; can reject some paths even if other Boolean cover identities would certify them.

At most Q=(2p)^2 sum_{j=0}^d 2^j binom(b,j) states = O(p^2 (b+1)^d) for fixed d. Append each edge from each reachable state; even linear scans of all guards for coverage are polynomial. For every opposite literal pair, combine every retained forward/reverse guard; prohibit each consistent union. Add all boundary-only forbidden guards and actual boundary pins. Standard conditional 2SAT SCC criterion proves resulting CNF K is exact joint boundary response. Each reachability conflict clause has length <=2d; no restriction on separately explicit boundary-only clauses beyond paid input length. At most p G_d(b)^2 conflict clauses. No symbolic count claim. Witness given any accepted boundary: evaluate actual guards, run ordinary conditional 2SAT, extend functional through verified basis and original parity equations, verify original rows/pins. ## L2 PROVED: certified binary reduction and hereditary composition
Let H be all <=2-literal clauses of exact K, including empty clause if present. For each longer C, test H AND all negated literals of C via ordinary 2SAT; if UNSAT, H implies C. If all pass, H is exactly K. If any fails decline recognition (not a proof that K is nonbijunctive; further binary consequences may exist). All calls paid; O(poly(N)) for fixed d and polynomial raw chart size.

Stronger hereditary theorem: given a paid polynomial-size family of exact regional 2CNF summaries on subsets of ONE common independent boundary coordinate system, with pairwise disjoint private spaces jointly independent modulo that boundary (or actual disjoint private variable IDs and verified source lift), conjoin all summaries and remaining 2CNF factors, retaining guards. Joint feasibility is exactly ordinary 2SAT; local witnesses lift together by shared coordinate agreement. To reproject a 2CNF summary onto any subset S of its coordinates, ask for each of the O(|S|^2+1) possible unary/binary partial assignments (including empty) whether it extends using the full 2CNF solver. Forbid every absent pattern. Exactness: solution sets of 2CNF are majority-closed (if majority violates a clause, two of three inputs falsify each literal, hence one input falsifies both), existential projection preserves majority closure. Conversely, a majority-closed relation equals the conjunction of all its absent unary/binary patterns: a word agreeing with actual projections on every pair can be matched on every larger subset inductively by taking three actual words, each matching all but one of three distinct positions, then their majority matches all positions. Handle empty support with empty clause. Therefore the reprojected relation is precisely the obtained O(N^2) 2CNF. Reconstruct by pinning actual later coordinates in prior full 2CNF and solving, then lift original regions. A supplied tree/order of O(N) such joins and projections with fixed original coordinate dictionary and certified private separations has polynomial total work, peak storage, and replay; maintain at most O(N) intermediate summaries each O(N^2), retain original source maps, do not expand copies recursively. Unary boundary pins preserve this class. Arbitrary affine mixing of coordinates, new private implication edges, or nonbijunctive factors do not automatically preserve admission. This is genuine hereditary closure for the admitted class, not universal chart acquisition. C05 directness warning: pairwise zero quotient intersections alone are not enough for simultaneous lifts.

## L3 PROVED: coNP-complete semantic recognition even when native response is always nonempty and conditional membership is 2SAT
Take positive linear NAE3-E4 source F(X), converted to 3CNF by replacing each triple by both its positive and negative OR3 clauses. Introduce fresh public selector s and public bits u,v,w. Define R(X,s,u,v,w) by
    (s=0) OR (F(X) AND (u OR v OR w)).
Equivalently every clause C of converted F becomes (not s OR C), plus (not s OR u OR v OR w). This is explicit width4 CNF. Always nonempty, even with a known trivial s=0 witness. If F UNSAT then R is exactly the hyperplane s=0, affine and bijunctive. If F SAT fix actual satisfying x*, set s=1: control words 100,010,001 are allowed but majority 000 excluded. Thus no 2CNF on these fixed boundary coordinates is equivalent to R. Also 100,010,110 allowed with XOR 000 excluded, so R is nonaffine. No assumption about recognition after arbitrary affine change of basis for bijunctivity; affine nonclosure is basis invariant. Nonbijunctivity is in NP on the explicitly admitted native class: exhibit three actual boundary words and rejected majority, membership of each checked by the proved conditional 2SAT algorithm. The necessity and sufficiency of majority closure were established in L2. Similarly affine nonrecognition has three-word XOR certificate (nonempty XOR-closed relation is a coset by translation). Even the union "affine OR bijunctive in this basis" is coNP-complete on the admitted class, via both certificates for its complement. For formal total languages reject malformed/admission failures by a polynomial syntactic chart verification; equivalently state as coNP-completeness on promised verified charts.

Native adapter, all rows distinct IDs: each OR4 (l1,l2,l3,l4) is existentially equivalent to (l1 OR l2 OR r) AND (l3 OR l4 OR not r) with fresh private r. Each OR3 (a,b,c) is existentially equivalent to NAE(a,b,z) AND NAE(not z,c,c0), where fresh z is private and c0=0 is pinned. Proof: if a=b=0 then z=1 forced and c must be 1; if at least one of a,b is 1 choose z=0. Conversely if all three are zero no extension. For each signed literal use actual fresh complement ID bar x via native row (x,bar x,c0,c1) with actual c1=1. For each NAE triple add fresh completion w, native row sum2 iff triple NAE, unique integer lift. All logical vars within each triple distinct; c0,c1 fresh. After parity closure, every complement equals 1+x, every completion is the XOR of its three physical inputs, and there are no other affine restrictions because each completion is unique to its row. Thus the public coordinates and private logical r,z are independent in the parity chart. Each NAE3 has at most two private logical bits, and conditional clause pair is ordinary 2CNF after all public bits fixed. More strongly, each OR4 group has independent private r,z_1,z_2 shared with no other group. Physical membership and witness extension exact by native integer sums; no free decision oracle. Original hard source maps to O(n+m) native variables/rows, with O((n+m)log(n+m)) bits for renumbered IDs. This proves coNP-hardness of recognition even in a syntactically verified native private-aligned, always satisfiable class; it does NOT prove ordinary P!=NP, nor rule out safe sufficient recognition tests, alternate representations, or immediate SAT witness.
