## Named obligation: exact weighted full-or-hole fiber composition without exhaustive enumeration
For a nonempty affine fiber F over F2 with dimension d, let E_1,...,E_m be explicitly described affine subspaces of F (empty allowed), each forbidden by a verified original regional condition. All events are on the SAME fiber and guard. For exact coverage/decision require these events collectively describe precisely all violations, not only a relaxation. For every forest T on the m event indices define
C_T = sum_i |E_i| - sum_{ij in T} |E_i intersect E_j|.
For every x in F let J(x)={i:x in E_i}. The induced forest T[J] has |J|-|edges(T[J])| components; define the number as zero for J empty. It is >=1 whenever J nonempty. Summing pointwise gives |union E_i| <= C_T. Equality holds iff T[J(x)] is connected for every nonempty J(x). This independently reconstructs Hunter's spanning-tree union bound and gives a source-checkable exactness criterion for affine events.

Constructive method: use GE for every singleton and pair cardinality: consistent affine system of rank r in d free coordinates has exactly 2^(d-r) solutions, else zero. Compute a maximum-weight spanning tree with intersection counts as edge weights; this minimizes C_T over all forests (nonnegative weights permit extension). If C_T < |F|, at least one extension exists. A deterministic witness is obtained by fixing free coordinates one at a time, computing the same fixed-tree score on each affine half-fiber via GE. Both half-fibers have equal size and their scores sum to current score, hence at least one half has score strictly below its size. At final point C_T<1 implies no event. No counting oracle; only rank cardinalities. If all independent regional supports and reverse maps are verified, lift the witness. If the fiber is empty, GE directly certifies contradiction. This is not symbolic counting of native assignments.

Complementary global/negative method: for each event pair (i,j) with nonempty intersection, every intermediate event on the unique tree path must contain E_i intersect E_j. For pairs in different components require empty intersection. This is iff the above pointwise connectedness: any x common to endpoints must be common to the path, and connected active sets imply the path property. Affine inclusion is checked by GE: every target equation is implied (row-space membership with RHS), or append its negation and test inconsistency. Thus exactness of a proposed tree is polynomially checkable. If exact and C_T=|F|, full cover proves no extension. If there is ANY exact tree, the optimal maximum-intersection tree is also exact since every forest bound >= true union and optimal score <= exact score. Consequently testing one optimal tree recognizes admission to this exact union-count terminal. If minimum score > |F|, NO forest can be exact, regardless of union's actual size. This is a short scoped refusal, not general UNSAT. If score >= |F| without exactness, UNKNOWN. A simple hostile example: three distinct nonzero-coordinate halfspace events x=0, y=0, x xor y=0 on F2^2 cover all four; any spanning tree has score 6-2=4 and satisfies path inclusion. For an example where union bound fails but tree correction proves extension, take three identical proper events: score reduces from three times their size to one. A nonexact tree occurs whenever two endpoint events overlap at a point excluded from their middle path event. Never use the upper bound >= fiber size as an UNSAT proof.

General multiway full-or-hole specialization: independently extendible local factors A_i=(a_i+P_i) minus explicit affine holes, with affine consistency target sum_i x_i=t and other checked affine interface equations. The full solution fiber in product coordinates is affine. Each hole pulls back to an affine failure event. This avoids enumerating the whole product. If single-point holes and only sum constraint, projection fiber dimension d_i=dim(P_i intersect sum_{j != i}P_j); each relevant hole consumes fraction 2^-d_i. Sum of those fractions <1 is sufficient for saturation, and the forest correction strengthens it. Pairwise P_i intersections need not be nonzero: U, V, diagonal U~V in U direct sum V have pairwise zero intersection but each d_i=k. Three singleton holes cannot exhaust a fiber of size 2^k for k>=2. Exact finite audit of 37448 three-factor hole triples, 37440 strict cases, no disagreements. This is not a theorem for arbitrary binary-encoded integer subset-sum weights or arbitrary compact supports. No independent factor may lose its actual shared phase.
