## L2 PROVED common-coordinate recognition
Given any finite family of two-dimensional subspaces over F2, deduplicate identical planes for recognition only (retain all forbidden words). Let S be the set of nonzero directions occurring in >=2 distinct planes. Distinct 2D subspaces intersect either trivially or in a line. If a common coordinate basis B exists (each P is spanned by two B elements), their intersection is spanned by their common basis subset, hence every shared line vector belongs to B (unique nonzero representative). Consequently S must be independent, and each plane has at most two members of S. If either fails, return UNKNOWN for SAT, not NO.
Start D=S, complete each plane locally to a two-vector basis retaining all S in it; add the other vectors. Different planes cannot share any newly added direction (it would be in S). Thus |D|=|S|+sum_i(2-|P_i intersect S|) with intersection counting nonzero directions in S. Every completion spans the sum of all planes. If any global basis exists, it yields exactly the same number of selected coordinate vectors, spanning exactly the same sum, and they are independent. Therefore every arbitrary local completion passes the rank test whenever some valid completion does. Conversely if rank(D)=|D| it is an independent common coordinate set; extend to basis of ambient V. Exact recognition both ways. Acquisition via hashing/sorting 3 vectors per distinct plane and Gaussian rank test, uniform polynomial; no exponential topology search.
Every row becomes a 2-clause on two actual independent form values, with forbidden pair transformed by that local linear map. Every assignment to D extends to original affine solution; run exact 2-SAT (implemented mutual reachability and greedy unit pin reconstruction, not assuming supplied witness). Verify original rows and guards. In unguarded chart without offset-producing deductions all clauses positive, setting all selected form values to one suffices; general guarded charts use 2-SAT. ## L4 FALSIFIED universal coverage, even on entire authenticated hard restriction
Consider private-completion native source from a nonempty positive linear NAE3-E4 instance on n active original variables, m=4n/3 triples. Eliminating each private completion in parity system leaves original x free. Every neuron plane is span(e_a+e_b,e_a+e_c), its three nonzero vectors are precisely the three original pair differences. Distinct triples share <=1 original variable, so these planes are pairwise disjoint outside zero. Thus no shared nonzero direction at all; no local rank-one closure. Let r be dimension of sum of planes; r=n-c, where c is connected component count of primal graph on original variables. Proof: span of differences within graph edges equals even subspace on each connected component, via path sums and spanning-tree edges. Initial m-r=n/3+c>0.
Under each permitted peel, m drops by one but r drops by at least one (dim intersection <=1). Therefore m-r cannot decrease. All residual planes stay pairwise disjoint in the fixed quotient. They cannot all disappear (empty gives m-r=0), and common alignment would need 2m independent coordinate directions, impossible since m>r. Hence this precise lane cannot decide any nonempty unguarded raw authenticated E4 linear source by alignment after leaf peeling alone. Additional certified deductions, alternate projections, decomposition or terminals remain legal; no unrestricted lower bound, no statement about semantic saturation.
For arbitrary linear NAE triples the raw common-coordinate condition is equivalent to 2m=n-c, i.e. incidence bipartite graph is forest (edge count 3m, vertices n+m). Each plane disjoint from other planes but can have global dependencies. Even choosing different two directions per plane cannot change the 2m-r dependence count. This is exact representation obstruction, not computational hardness.
