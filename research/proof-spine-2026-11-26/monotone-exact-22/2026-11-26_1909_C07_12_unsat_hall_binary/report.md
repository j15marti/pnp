## L1: exact choice projection, proved with scope
Admit verified chart of regions with disjoint private variables (or jointly direct private quotient spaces with actual joint lift), one common independent boundary coordinate dictionary, actual fixed guards retained, and complete original row coverage. For each region i, C07-11 gives exact response NOT P_i, where P_i is an explicit 2CNF activation predicate, and the exterior G is explicit 2CNF. The whole chart is G AND all NOT P_i. Enumerate one option per clause of P_i: the conjunction of its negated literals (at most two pins), with owner i. Normalize tautological/empty clauses and empty conjunction; treat false region response as immediate NO. Options need not be mutually exclusive for an actual boundary assignment. Every feasible assignment can choose ANY one true option for each owner. If G UNSAT refute directly. Otherwise delete individually infeasible options by G plus pins (2SAT). Put edge between distinct-owner options a,b precisely when G plus their combined pins is UNSAT. Every such edge is acquired by exact paid 2SAT. Let D_i be retained option domain and B conflict graph.

Claim: chart feasible iff choose one option from every D_i with no conflict edge. Necessity direct. For sufficiency, a set of pinned literals extends a satisfiable 2CNF iff all singleton and pair restrictions extend. Proof: eliminate all unpinned variables by exact Davis–Putnam resolution: resolve (v OR A) with (not v OR B), each A,B at most one literal; remove tautologies; retain remaining clauses. If no resolvent falsified, either v has no required polarity or a consistent polarity can be chosen. Exact projection is therefore 2CNF. Any excluded pinned word falsifies a clause involving at most two pinned IDs. The single/pair option tests rule these out. Equivalently implication reachability: the closure of a set of pins is consistent iff no pin reaches the complement of any pin (allow same pin and reflexive paths). If two reached literals are opposite, contraposition of one path gives precisely such a reachability. A consistent upward-closed literal set in a satisfiable implication graph extends by SCC ordering of remaining unassigned components, since no literal already fixed can imply an opposite unassigned choice without forcing its complement. This justifies the executed reachability matrix implementation. Once pins jointly extend, choose a boundary model of G and actual private witnesses in each region. Joint directness is essential; no pairwise-only private-space assumption. For refutations only the necessity direction is needed, but exactness prevents losing meaningful alternatives.

## L2: matching changes the domain of binary refutation (genuine hybrid)
Partition options into classes such that any two options of different owners in a class have a verified conflict. A single option class always allowed. Deterministic cheap acquisition: connected components of cross-owner B; accept each as one class if every cross-owner pair is an edge, otherwise split into singletons. May instead use any explicitly verified partition; no maximum-clique oracle. Build bipartite owner-to-class graph, parallel choices kept in maps. Every feasible independent transversal gives an owner-covering matching. Therefore no such matching implies NO (Hall certificate). Moreover, if the edge representing option a is contained in no owner-covering matching, then a is impossible in ANY original feasible boundary: if attainable, select a for its owner and any attained option for all others to obtain the forbidden matching. This proves the unconditional clause NOT option_a under actual chart guard, not merely a restriction to one selected witness. For a two-pin option, the imported exclusion is again 2CNF. If parallel options map to the same edge, all equally unsupported. Check support by forcing that edge and computing a maximum matching on remaining owners/classes; polynomially many calls. This is ordinary all-different filtering (Regin 1994 Thm1) on a newly acquired necessary resource projection; a matching alone is NOT sufficient when conflicts cross classes.

Reclose actual G and native constraints after each import; maintain original IDs and guard. One can recompute option conflicts, or retain old conflicts conservatively (old edges remain valid after strengthening). If a domain empties, refute. A subset of owners with <=2 remaining options is an exact Boolean binary conflict system: encode one Boolean choice per owner, singleton forced, each prohibited pair a binary clause. An UNSAT subset suffices for global NO even if other owners have many choices. Arc consistency removes any option having no compatible option in some other owner, also a sound exclusion. Repeat while a strict deletion occurs, at most M deletions of M initial explicit options. If every owner has <=2 choices, full projected feasibility exact; not needed for UNSAT-only lane. At stagnation return UNKNOWN unless another certified refutation exists.

Infinite NO control: t>=2 owners each choose one of t distinct shared resources; each resource capacity one. k>=5 odd rim owners each have three choices A_i,B_i,C_i. A_i,B_i use private matching classes, C_i uses shared resource 0. For neighboring rim owners conflict same A or same B, and C_i conflicts with every other option using resource 0. Initial arc consistency deletes nothing; each conflicting pair has alternative compatible choice. Owner-covering matching exists, but by saturation of the t tight owners it cannot use any rim C_i. Matching alone returns no global refutation. Import these k exact exclusions: rim now has two choices, neighboring choices must differ, contradiction around odd cycle. The classes for A and B arise from noncomplete cycle conflict components split into singletons; shared resources are complete cross-owner components. Thus the stated cheap acquisition works without resource labels. For t=2, initial two-choice tight owners alone are consistent. All other initial domains >=3. No logical branching or global count is required. Original chart remains connected through common reference and conflicts. ## Native chart adapter, all rows native and unguarded
Given any finite explicit binary conflict graph with owner partition and nonempty D_i, give each option a two boundary labels x_a,y_a and proxy p_a (all distinct). Exterior 2CNF G consists of (x_a OR p_a),(y_a OR p_a), and (not p_a OR not p_b) for every cross-owner edge. Region i is a serial chain of diamonds, one stage per a in D_i, each with two corridors whose forward guards are x_a,y_a. Private phases from distinct regions share only references. Hence exact region response is OR_a(not x_a AND not y_a). Any solution chooses attained options, forces corresponding p=1, respects edges. Conversely a compatible transversal sets chosen x,y=0,p=1 and other x,y=1,p=0; every region has a blocked stage, extend private phases by reachability. This proves exact adapter in both directions, though witness construction is used only as soundness control.

Native reference triangle: rows (r0,b,r1,u),(r0,b,u,v),(r0,b,v,r1). If r0!=b then all rim pairs sum1, impossible; otherwise r0=b and r1=u=v=1-r0. Whole source complement invariant; normalize r0=0 for decision, no external pins. Each logical label/proxy z has physical complement bar z from row (z,bar z,r0,r1). Signed binary clause (l1 OR l2) encoded as row (L1,L2,r0,w) with distinct physical signed IDs and fresh completion, equivalent by integer occupancy. Each diamond corridor label z has fresh middle m and two rows (s,m,z,w1),(m,t,bar z,w2). With phase y_m=1-m, endpoints physical, z=1 enforces s<=y_m<=t, z=0 enforces t<=y_m<=s. Both corridors together imply exactly the stage response: equal endpoints always extend; 1->0 requires both labels0; 0->1 requires both1. In a series pinned 1 to 0, at least one blocked forward stage necessary, sufficient by assigning endpoint phases stepwise 1 then 0 at that stage. Every completion unique, all variable scopes distinct per row. Size O(M+E) records, polynomial encoded bits. Exact source maps checked in code, not universally acquired.

## L3: hostile control and an acquired complementary parity refutation

Its native adapter is genuinely NO: assume proper 3-coloring, let c=apex color, replace original vertices of color c by corresponding shadow color. Every new color avoids c; on each original edge both original endpoints cannot equal c, and when one is replaced its shadow is adjacent to the other. Therefore yields a 2-coloring of odd cycle, contradiction. This is the classical Mycielski recoloring proof, independently reconstructed and verified on exact choice graph. Each same-color conflict component is the connected noncomplete graph; acquisition splits to singleton resource classes.
