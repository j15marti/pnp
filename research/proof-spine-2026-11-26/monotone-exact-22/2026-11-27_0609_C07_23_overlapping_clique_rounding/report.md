## Named obligation MULTI-CLIQUE-ROUNDING
Can overlapping unsaturated clique certificates become productive through a signed affine seam and integrality? For every verified double-punctured Fano region, exact response is a disjunction of two monochromatic triples. Two such regions sharing one missing triple and linked by complement on a nonshared variable of the other missing triple imply an exact equality seam. Falsifiers: missing complement; wrong pair multiplicities; outside incidence or guard on private variables; treating fractional cuts as integral.

## Track A: constructive local interface
Label seven points 1..7, retain five triples (1,6,7),(2,4,6),(2,5,7),(3,4,7),(3,5,6). Missing lines A=(1,2,3), B=(1,4,5). Native private slack per triple. Write D(T)=sum of the three pairwise Boolean disagreements. Each retained NAE contributes exactly 2, all retained pairs distinct; K7 cut capacity 12. Thus D(A)+D(B)<=2. Since each D is 0 or 2, at least one missing triple is monochromatic. Conversely if B is monochromatic with bit t, set 6,7=1-t; each of five retained lines is NAE for arbitrary bits 2,3. If A is monochromatic use the same lift 6,7=1-t (each retained line contains an A point, hence NAE). Therefore exact joint five-bit support is M(A) OR M(B), 8+8-2=14 words; B alone has all eight words. Private slack is uniquely 2 minus the triple sum. No marginal replacement.

## Track B: overlapping capacity and integral rounding
Two private copies share original points 1,3,4,5, use d=2 in first and db in second, actual row (d,db,r0,r1) with guards r0=0,r1=1 imposes db=1-d. Let A'=(1,db,3). Then D(A)+D(A')=2+2[1!=3]>=2, by complementary contributions to the pairs incident to d. The two capacity inequalities add to D(A)+D(A')+2D(B)<=4. Thus D(B)<=1, and Boolean cut parity forces D(B)=0. Each individual block only bounds D(B)<=2; combination and rounding are necessary for this derivation. Conversely when B mono set each copy's private 6,7 opposite B and choose d,3 arbitrarily, db=1-d. All native rows extend. Exact common boundary response is B monochromatic with the other two bits free (8 words), or {000,111} on B if those other IDs are private. This is a genuine hybrid: signed affine linkage of two nonlinear regions produces an exact phase admitted to matching. Not a free MaxCut oracle.

## Further symbolic theorem: signed difference forest
For any collection of verified double-punctured regions with disjoint private interiors, retain each missing line pair A=(a,d,e), B=(a,b,c) on actual IDs. The exact response is ((a=d AND a=e) OR (a=b AND a=c)). Introduce differences y_uv=x_u XOR x_v on the four anchor edges. Equivalent 2-CNF forbids each pair of 1s across {y_ad,y_ae} and {y_ab,y_ac}. First quotient any certified equalities/complements and pins by signed union-find (pins represented against a shared reference fixed to 0); inconsistent parity refutes. Replace differences by signed literals of canonical interclass edge bits, or constants for loops. Deduplicate actual unordered class edges, retaining signs. For every such instance, the resulting 2-CNF plus fundamental-cycle XOR equations exactly characterizes joint extension: a spanning forest reconstructs class potentials and all non-tree edges are valid iff their fundamental-cycle parity is 0. If the canonical difference graph is a forest, there are no cycle equations, hence deterministic polynomial exact decision by 2-SAT and native lift. This condition is checkable and supports arbitrarily many regions, even high-degree anchors. More generally cycle XORs of at most two unfixed edge bits (after certified fixed edges) remain 2-CNF. No claim for arbitrary cycle systems; 2-SAT alone on a triangle may accept differences 111, which have odd parity and no potential assignment. Also retaining only mono-status marginals loses actual identities. This symbolic extension not separately implemented.
