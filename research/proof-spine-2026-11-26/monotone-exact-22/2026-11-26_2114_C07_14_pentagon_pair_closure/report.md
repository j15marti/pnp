## L1 PROVED WITH SCOPE: guarded pair consistency, but not a complete NO refuter
Fix each actual oriented simple pentagon. Proper coloring induces five signed differences +/-1 summing to +/-3 as integers (odd multiple of 3 in [-5,5]). Exactly one is minority; the five options are indexed by that actual edge position. Each option specifies four relative sign equations on actual edge IDs, independent of absolute color permutation. On every pair of options from two regions, union their signed identities; a signed-union-find contradiction is a sound exclusion. Complementary F3 screening: add the identities d_e=+/-d_f to homogeneous vertex potential equations d_e=c_head-c_tail. If rowspace forces any actual graph edge difference zero, pair impossible. Do not assert converse: surviving affine subspace need not contain a point with every edge nonzero. Include unary checks via same-owner diagonal entries; retain full pair tables, not independent marginals.

Path consistency: remove pair (a,b) on owners i,j if some third owner k has no value simultaneously compatible with (i,a) and (j,b) in current tables. Proof by contradiction: a hypothetical global coloring satisfying that pair supplies its actual minority index at k, which must have survived all previously sound deletions. Same-owner diagonal corresponds to unary option support. If a diagonal domain becomes empty, refute. With q pentagons and domain 5, <=25q² distinct ordered pair entries, strict deletion rounds bounded by same. O(q³*constant) per complete scan, hence polynomial for fixed finite domain; q=O(n^5) from bounded cycle enumeration. Pair algebra acquisition O(q²) calls, each fixed-field Gaussian polynomial with explicit edge IDs. Singleton PC is also a sound polynomial sufficient procedure: temporarily pin one owner option and run PC; if contradiction, exclude that option unconditionally (relative to initial guard), reclose; at most 5q successful unary deletions and at most 5q candidate trials per round, all charged. This does not prove universal coverage or exact support. The actual trial implementation uses a stricter 20,000,000 aggregate path support-scan limit, returning UNKNOWN when exhausted.

No direct all-different matching condition on minority physical edges: two distinct pentagons sharing an edge may both choose that same edge as minority. For instance orient both consistently along the shared edge; set it to -1, all four other edges on each cycle to +1. Each cycle sum +3; integrate from the shared endpoints, with all other vertices distinct and no extra edges. This is a minimal symbolic falsifier of a naive capacity-one resource projection, not a SAT research track. Matching can only be used after certifying genuine cross-owner incompatibility; not performed in this run.

## L2 KNOWN TERMINAL plus scoped refinement: dominating-cycle negative cover
The standard dominating-set approach to 3-coloring is known, e.g. Mertzios–Spirakis Algorithmica 74 (2016), Lemma 1: given a dominating set D, enumerate its proper colorings; each vertex outside D then has at most two available colors, so extension is list-2-coloring reducible to 2SAT. The new contribution here is adapting the already acquired five-option pentagon geometry to this terminal on the actual stalled native chart, with an exact regional cover and negative certificate replay. No novelty claim for basic DS approach.

For any verified graph chart, optionally with explicit unary lists and arbitrary binary color relations, let D be covered by k actual pentagons plus t extra vertices, and dominate the graph via actual disequality edges: every vertex outside D has a neighbor in D. Enumerate all 30 proper color words per pentagon (five minority positions times two signs times three starting colors), and 3 possibilities per extra vertex. Join on original shared vertex IDs; reject inconsistent overlaps and all violated constraints within D. The resulting words cover exactly all locally proper D assignments respecting its internal constraints. If color-permutation symmetry is certified, fix one actual edge of the first pentagon to ordered colors 0,1 (then exactly 5 possibilities). For each later pentagon sharing an assigned vertex, at most 10 words extend that color; sharing an assigned edge gives at most 5. More generally, enumerate 30^k*3^t candidate products, including failed joins; no actual-support oracle. A connected ordered cycle cover can reduce actual acquisition to 30*10^(k-1)*3^t by indexing the local word lists by shared colors; no such ordering assumed universally. On each retained word pin D. Every outside vertex loses at least one of three colors from its pinned disequality neighbor. Apply unary list restrictions and all binary constraints incident to D. Empty list refutes the word. Otherwise encode each remaining vertex by one Boolean choice; singleton list has a unit pin. For every remaining binary constraint forbid each disallowed pair of its actual list indices by a width<=2 clause. This includes equality, inequality, arbitrary explicit pair support, or child messages. Then ordinary 2SAT is EXACT, not merely a relaxation, because each outside vertex has at most two actual color options. SCC conflict or empty list gives an exact negative certificate under that D word. If every admitted D word is refuted, the original source is NO. Any actual coloring induces an admitted word and a satisfying Boolean extension, so no false refutation. Conversely any accepted Boolean extension lifts to graph colors, then native one-hot bits and unique completions; retain exact guard. No SAT repair track executed.

Acquisition for two pentagons: enumerate all actual cycles and their unordered pairs, test domination with graph adjacency, minimize union vertex count, deterministic tie rule. For more cycles, a supplied or deterministically acquired cover must be validated; greedy closed-neighborhood coverage is one paid candidate policy, not guaranteed optimal or logarithmic. Direct search over all cycle subsets of logarithmic size could cost N^O(log N) and is NOT an allowed free step. For verified cover and fixed polynomial chart length, T<=poly(N)*(30^k*3^t+1) including complete candidate generation, rejected joins, reconstruction/verification and input chart check.
