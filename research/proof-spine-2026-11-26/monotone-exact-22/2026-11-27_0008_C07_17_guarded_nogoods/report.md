## L1 PROVED: fixed-arity guarded negative knowledge library
Let F be an explicit binary CSP of n original owners, domain size q bounded by constant; keep immutable source ID map and fixed guard G. A nogood is a partial assignment g such that F AND G AND g is inconsistent. Root tables are necessary conditions and retain original constraints. For each actual singleton guard p=(v=a), apply any sound polynomial conditional closure, including C07-16 exact retirement of all currently binary-domain owners on the binary residual. For a local condition set augmented by guarded nogoods, activate a stored clause only when its specified guard holds, retaining all other clauses or dropping them as a relaxation solely for negative reasoning; do not claim exact existential projection of unactivated high-arity clauses.

If conditional closure refutes p, remove a. If it removes u=b under p, import forbidden pair {p,u=b}. If it removes pair {u=b,w=c} under p, import forbidden triple {p,u=b,w=c}, NOT an unconditional pair. Root IDs preserved even when child retirement removes some owners; valid restrictions recorded before retirement still hold for original solutions. For conditional projection tables on survivors, exactness follows by the previous binary-interior theorem; if other clauses are dropped, only necessary condition status remains. Proof by contradiction: a global solution meeting p must obey all original constraints and previously certified nogoods; its restriction satisfies every sound conditional closure and projection. An excluded entry therefore cannot occur. Induct on import order to handle cycles of information without circular proof. A guarded ternary nogood becomes a binary exclusion when ANY one of its three assignments is forced; may be indexed by each literal. Only activate under its actual pin, including pins derived by sound closure. Keep original guard G and exact contextual map. Never use a learned word as attainable support.

For fixed q, at most M=sum_{j=1}^3 q^j binom(n,j) distinct consistent nonempty nogoods of width<=3, plus empty conflict. At most M productive imports, at most M+1 sweeps if each nonfinal sweep adds at least one new nogood or shrinks a root table. Count root projection, table masks and domains in same finite universe; count failed probes even if no change. At most q*n singleton probes per sweep. A conditional run is a polynomial closure: n unary changes, O(q² n²) binary deletions; each sweep uses polynomial AC and binary-core implication closure/fill, guarded-clause activation by explicit indexed scan; retaining original owners at root avoids invalid cross-retirement comparisons. Deterministic bit complexity is O(M*q*n*poly(N)) for the explicit fixed-domain chart of polynomial size. Store at most polynomial proof history; verify by replay of polynomial operations under actual guard; original witness maps retained if exact projection used. No unlimited repeated failed sweeps and no free SAT, equivalence or counting oracle. For q=3, M=3n+9 binom(n,2)+27 binom(n,3). At n66, M=1,255,023 (includes all possible consistent partial patterns, not attained words). The exact general count formula, not the observed learned count, charges candidate space. This gives a finite polynomial saturation, not a proof that empty nogood is always obtained. In general can extend to fixed width k and guard plus projected word of total width<=k, giving O(n^k) record universe, but k cannot grow with n without a separate fixed polynomial bound.

## L2 PROVED: guarded exhaustive split and bounded-disjunction retraction
For a common root guard G split exhaustively on one owner with q actual allowed values; a refuted branch contributes empty response. Let S_a be any sound overapproximation of surviving original assignments under a. If Q is a shared exterior coordinate set, every true root solution's restriction belongs to union_a S_a. For any unary or pair scope I, allowed marginal is union_a proj_I(S_a), and an entry absent in every branch can be excluded unconditionally. All branches must be included or soundly refuted; do not intersect branch responses. If branches produce sound tables rather than true support, union of those tables still safe as a necessary condition, not necessarily exact. This is a stronger import than just singleton failed literals, because any exterior pair absent in every conditional branch can be reused even if not containing the split owner.

Exact form: suppose fixed q branch responses R_a on SAME exterior IDs are exact conjunctions of explicit forbidden patterns of width<=2, e.g. after each branch of a certified modulator eliminates its own private variables with a common exterior. Branch-local fixed variables must be encoded explicitly or absent from all scopes by correct existential projection; not silently omitted. Then union_a R_a has an exact forbidden-pattern representation: choose one forbidden pattern f_a from each nonempty-response branch's list, form their joint union, discard inconsistent combinations, and forbid each remaining union. Proof: a word is rejected by all branches iff it contains at least one forbidden pattern from each. Unsatisfiable branch is represented by one empty forbidden pattern; universal branch has empty list and makes whole union universal. Thus width <=2q, at most product of branch list sizes, polynomial for fixed q, even on ternary exterior. Correlated overlap preserved by actual identities. Not hereditary at fixed width under unrestricted iterated splits.

Stronger tractability recognition: if the exterior has a common independent Boolean coordinate dictionary and each branch is exact 2CNF H_a, acquire the binary hull H by querying every unary and pair word for extension in at least one branch using q paid 2SAT calls per word. Include empty scope to detect empty support. Then union R is subset of H. To determine whether H is exact, enumerate one clause C_a from each H_a; ask 2SAT on H AND all literals falsifying those chosen clauses. If any succeeds, the produced word belongs to H but no branch; else H implies R by complete enumeration. Empty/constant cases handled as above. Cost O(q*b² + product_a max(1,m_a)) 2SAT tests for b exterior bits and m_a clause counts, plus polynomial indexing and witness replay. If H exact, substitute it hereditarily and reconstruct by selecting actual accepting branch under actual exterior word. If H not exact, retain exact bounded-width union or original guarded alternatives; do not replace by H except as a negative-only relaxation. This is a complete polynomial recognizer for a FIXED number of explicit 2CNF disjuncts, not the arbitrary compact-circuit recognition problem shown coNP-hard in C07-10. Given a polynomially acquired decomposition of polynomially many nodes where every such Boolean retraction is accepted, common coordinate/lift conditions hold and fixed q bounded, total sum of local costs is polynomial; no universal decomposition/acquisition theorem.
