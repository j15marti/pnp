## L1 PROVED: exact degree-two integer occupancy terminal
After actual unary pins, each row has residual integer target t_r=2 minus sum of pinned ones; reject if t_r<0 or exceeds number of unpinned variables. Each unpinned variable occurs in at most two rows. Construct general undirected perfect-matching graph. Each row has t_r slot vertices. Each remaining variable has two port vertices a,b and edge ab. A twice-occurring variable attaches a to all slots of its first row, b to all slots of its second; a once-occurring variable attaches a to its row slots, b belongs to a common free-dummy clique. Add one extra vertex to that clique iff total residual target is odd. No loops, all actual variables retain distinct IDs even if same two row endpoints.
If ab is used the variable is zero; otherwise both ports must be matched elsewhere, so a twice-occurring variable is one at both rows, once-occurring variable one at its row and b in dummy clique. Every slot covered once gives exact original row demands. Conversely a satisfying assignment permits bijection between selected occurrence ports and row slots; unused pairs matched internally; the leftover free-dummy vertices have even cardinality since number of selected once-occurring variables equals total demand modulo two. Complete matching follows. Guards on degree-zero variables kept separately. Graph O(N) vertices, O(N^2) edges, integer bit lengths O(log N); standard deterministic general maximum-cardinality matching (Edmonds) yields exact decision and witness. No count preservation claimed.

## L2 PROVED: source-acquired forest of implicit matching regions, including arbitrary wide local scopes
Given native residual with unary pins, build components of factor rows joined via unpinned variables occurring exactly twice globally. Degree-one variables never join regions. Let R be regions, H the unpinned variables of global degree at least three. Build simple bipartite quotient Q between R and H; edge means at least one original occurrence. Record the complete list/multiplicity of original port IDs for each edge. Mark B every H variable that has at least three occurrences in any one region. Remove these marked nodes provisionally. Acquire a spanning forest of remaining Q and mark the H endpoint of every nonforest edge; let K be the union with B and h=|K|. Every edge not in the spanning forest has its H endpoint in K, so Q-K is a forest (even if acquisition marked redundant nodes). In each region every unpinned remaining variable has at most two local occurrences. h<=|B|+cycle rank(Q-B); no optimization oracle.
For each assignment to K (all 2^h attempts charged, or fixed cap decline), carry pins into every actual original incidence and keep Q-K unchanged. Root every component at a region. A variable node sends the intersection of its child regions' feasible parent values, respecting guards. A region sends at most two attainable values of its single parent variable: for each candidate value, impose that value plus every singleton domain sent by child variable nodes, reject empty child domains, and leave two-valued child IDs free. Solve its native residual with L1. Root region has one query. Store actual local matching assignment for each accepted parent value. A child variable with two ports in a region is one variable edge, NOT two independent pins. Different child subtrees share no unpinned IDs outside their attachment (Q-K forest, and global degree-two variables owned in one region). ## L3 PROVED obstruction: exact matching-only network not closed under fanout
Let a native exact occupancy network have each boundary port appear in exactly one row, every other unpinned variable appear at most twice (some degree-one hidden variables allowed), and arbitrary fixed unary pins. Given two attainable full witnesses u,v, color each changed variable red (u=1,v=0) or blue (u=0,v=1). View changed degree-two variables as edges joining row nodes; degree-one variables as edges to distinct free end nodes. Each row has equal red and blue incidences since its integer demand is unchanged. Pair red/blue incidence ends at each row arbitrarily. The resulting transition components are alternating trails or circuits; a trail starting at a changed boundary port has another free end. Flipping precisely its changed variables in u preserves every row's occupancy and every pin. Thus for each differing boundary port i there is an attainable boundary word differing from u at i and at most one other differing port j (possibly no j if other end is hidden). This is a weak symmetric exchange condition; it does NOT require all words have same parity when hidden free ports exist. If there are no hidden degree-one endpoints, the usual even exchange follows. Proof applies at any network size; it excludes exact representations, not algorithms.
Four-port equality relation E4={0000,1111} violates the condition for every port, since changing at most two bits produces an excluded intermediate word. E4 is native-realizable by four two-row equality gadgets linking center c to four single-occurrence ports, each gadget c+p+q+r=2, port+p+q+r=2. Subtraction and arbitrary completion of private triple prove exact relation. To restrict internal degree to <=3, replace center by two centers connected through another equality gadget and attach two ports per center; all external port occurrences one and internal occurrence <=3. This degree-three variant proved symbolically, not executed. E4 is easy by equality/Gaussian contraction, so no unrestricted lower bound. It prevents universal exact replacement of all high-degree native forest hubs by degree-two matching occupancy networks, even with exponentially many hidden degree-two variables. Alternative unrestricted compact algebraic representation remains legitimate.
