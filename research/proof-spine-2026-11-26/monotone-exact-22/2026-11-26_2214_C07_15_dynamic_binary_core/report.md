## L1 PROVED: dynamically expanding binary-core negative closure
Let F be a verified graph-chart region with actual unary lists D_v subset of {0,1,2}, and arbitrary explicit binary color relations, including exact disequality edges and imported child tables. Arc closure deletes values without support in an adjacent current domain and repeats to fixed point. For pure disequality this is exactly singleton-color propagation. Empty list is a contradiction. The core B(D) consists of vertices with at most two colors. Restrict all actual binary constraints between B vertices to their actual lists. Each two-color variable is one Boolean variable, singleton has a unit pin, every forbidden pair gives a width<=2 clause. If this induced 2CNF is UNSAT, original region is UNSAT. A consistent core alone means UNKNOWN; no inference of global feasibility.

For any integer d>=0 define P_d(D) recursively. First arc-close and run the exact 2SAT core test. On contradiction return NO. At d=0, otherwise return UNKNOWN. At d>0, for each actual allowed (v,c), temporarily restrict D_v to {c} and invoke P_(d-1). Only if that call proves NO, delete c from the parent domain, recording the complete guarded proof, reclose arc and core, restart sweep. If a full sweep has no deletion, return UNKNOWN. The proof variant may probe singleton values too, and may first test a guard already contradicted by a smaller domain. The executed implementation omits singleton probes (sound; no completeness equivalence with the all-color version assumed). Each conditional contradiction forbids exactly that fiber, because every actual completion with c would have satisfied the restricted source. Child deductions remain guarded and are not independently promoted. Deletion at parent strictly decreases sum_v |D_v|, at most 3n; once a domain becomes binary it remains in B(D) on that execution path. Thus a local refutation can change the domain on which the next exact 2SAT calculation operates. No upfront dominating set and no complete boundary enumeration. This is standard nested failed-value reasoning combined with a moving exact terminal, not a new general SAT paradigm.

With L<=3n explicit color options, at most L+1 full sweeps per call and L probes per sweep, O(poly(N)) local arc closure, source checks and SCC computations. Recurrence T_d <= (L+1)(poly(N)+(L+1)T_(d-1)), T_0=poly(N); all copying, guard verification, failed probes, certificate storage and replay included in polynomial primitives. Thus T_d <= (L+1)^(2d+1) poly(N) conservatively. For each fixed d a uniform polynomial sound partial refuter; this is an XP-style bound in d, NOT FPT. d=O(log N) is not enough to conclude polynomial work. Use fixed global cap or return UNKNOWN. Base refutation is monotone under restriction: arc contradictions survive restriction because a smaller domain has no new support, and the binary core only grows and narrows, so its existing contradiction survives. This property also holds for exact Boolean native occupancy projection: perform row support closure, conjoin all unary/binary forbidden projections of actual residual row tables (at most 16 words per original row), check 2SAT. UNSAT is sound; narrowing cannot lose an already excluded unary/binary pattern. One may additionally perform sound Gaussian parity closure, but no such arbitrary-native lane or matching/LP full closure was implemented this run.

## L2 PROVED: proof-rank sufficient acquisition criterion
This connects the actual algorithmic budget to a nontrivial structural condition rather than to the number of possible global colorings. Define a complete multiway refutation tree: at a node branch on one actual variable's every permitted color, >=2 nonempty alternatives; retain all constraints and guards. Leaves are domains refutable by the monotone base terminal. Deterministic sound domain closures can be incorporated at nodes; if they are used, require base arc closure (or a separately replayed restriction-preserving base operation) and charge it. Give leaves rank 0. For internal node with child ranks, let M be their maximum. Rank=M if the maximum occurs once, otherwise M+1. This is the multiway analogue of the Horton-Strahler rank (not ordinary tree depth). Use the all-color probing variant in L1.

Claim: for every such tree of rank <=d, P_d refutes its root and every componentwise subdomain, without being supplied the tree. Proof by induction on d. Rank0 trees are leaves (every genuine split has >=2 children and rank>=1), monotonicity supplies the base. Suppose at a subdomain P_d returns a nonrefuting fixed point D*. It is nonempty, base consistent, and every allowed color probe failed to refute at level d-1. Traverse the given tree starting from its root. D* remains contained in the current node's domain: any base arc closure still holds by monotonicity and D* being arc closed. If a child of rank <=d-1 has its branch color in D*, then the corresponding probe starts in a subdomain of that child. Induction says it refutes, contradicting the fixed point. Thus only a unique child of rank d could remain, and its color must be the sole allowed one in D* for that variable. Continue with D* inside that child. Tree finite, so reach a leaf whose base contradiction survives restriction, or a node with no allowed child, either impossible. This proves sufficient rank acquisition even with repeated failed sweeps charged. For d=0 no branching required. All-color variant important: singleton pin tests are included; executed skip-singleton algorithm is not asserted complete for this rank criterion.

Conversely an actual successful P_d deletion sequence yields a binary proof tree of rank <=d with leaves in the base terminal: split v=c versus v!=c, attach the recursively certified NO branch (rank<=d-1), and the remaining deletion chain on the complement. Reverse induction on chain length shows rank<=d by the same max/repeated-max formula. This converse uses binary equality-vs-complement splits, not necessarily the exact multiway language in the preceding sufficient direction. No false equivalence asserted between different proof languages. A version testing both sides of every literal split yields the analogous sufficient theorem for binary trees. This is a scoped specialization of the established nested input-resolution / levelled-height literature, including earlier oracle-relative hardness (Gwynne-Kullmann arXiv:1204.6529v5 sections4.3,5.1); not a novelty claim for Strahler rank or general recursive probing. The new integration point is the exact native chart terminal and its hereditary negative interface budget. No claim that every native NO admits bounded rank, or that rank of a found tree is minimum.

## L3 PROVED: one-sided hereditary negative forest composition
Given a verified tree of regions of the graph chart, each actual constraint assigned to a region containing its endpoints, running intersection of original IDs, independently liftable interiors, each parent-child seam <=2 actual three-color vertices. Every exact attainable seam support is a unary/binary relation with <=9 words. We need not acquire positive witnesses to refute. For each possible parent seam word pin it and run P_d on the local region conjoined with retained child relations. Delete the word ONLY when a sound local NO proof is produced. UNKNOWN words remain in the table, explicitly labelled potential, not attainable. Empty child or root table gives global NO. Inductive soundness: every original completion restricts to a retained word in every child (induction), hence is a local completion in every parent; sound refutation cannot delete its word. All child proofs guard their actual seam assignments and no marginal witness is substituted for a joint row. If all truly infeasible local words admit rank<=d refutation trees relative to the exact child relations, bottom-up induction gives exact tables. Even when not, retained supersets suffice for one-sided root contradiction if root is eventually refuted. If root is not refuted, report UNKNOWN, not SAT. If exact joint support or original witness is needed, additional completeness/positive lift is required; not provided by overapproximation. Thus hereditary sound negative coverage is weaker than and complementary to exact C07-14 composition. Per r-node tree <=9r local calls, each with fixed-d polynomial cost, plus verification of source maps, tables, running intersection, proof replay, failure accounting and original-N chart acquisition. Total sum, not product across regions. General theorem symbolic only, not implemented. Equalities and arbitrary binary tables are handled by the same exact list-2SAT base; pairwise matching resources are not assumed equivalent to general compatibility.
