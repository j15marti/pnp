## 1. Exact upper and constructible lower matching response
Input is an explicitly encoded balanced bipartite matching graph, with n vertices per side and a nonempty explicitly listed set A_ij of possible F2^b responses on each available edge. Selecting a perfect matching and one response independently on each selected edge produces their XOR. Call the set of all response words R. A rectangular Hall shell with exactly k deleted resources can be represented by k dummy demands only when their resource incidence and labels enforce the actual allowed joint deletion observations; no arbitrary cloning of correlated selectors.

Fix a perfect matching M, reorder columns by M, select anchor a_i from each matched edge and an anchor a_ij on every allowed edge. Let a = XOR_i a_i. Arc i->j is an available nonmatching edge to column M(j). It belongs to an alternating cycle exactly when i,j share an SCC. A nonmatching edge is in some perfect matching iff it belongs to an alternating cycle. Delete unsupported arcs from the response analysis (do not delete a constraint without a checked equivalence). Give supported arcs weight w_ij=a_ij+a_i, with all additions in F2^b. In each SCC choose a root and directed paths from the root; p_i is the XOR of arc weights on its path.

Define U as the span of (i) every p_i+w_ij+p_j for supported arcs, and (ii) every label difference x+a_ij for x in the full explicit label set of every allowed edge, including matching edges. Then aff(R)=a+U.

Proof: The symmetric difference of any two perfect matchings decomposes into vertex-disjoint alternating cycles. The p terms cancel on any directed cycle, so every response difference is in U. Conversely a directed closed walk decomposes into simple directed cycles, each of which can be flipped independently relative to M when taken by itself; thus its weight lies in the span of feasible response differences. For a supported arc i->j, use the root-to-i path, arc i->j, a return j-to-root path, and the root-to-j path with the same return. The XOR of these two closed walks is exactly p_i+w_ij+p_j. Each intra-edge response difference is attainable as a difference of two labelled matchings using that supported edge. This proves equality of affine hulls, NOT that every word in the hull is attainable.

For a constructive lower carrier, retain an explicit affine subcoset from each matched edge. An explicit finite label set is exactly affine when its number of distinct labels equals 2^rank of its anchored differences; otherwise the implementation retains a singleton. For a simple directed cycle C let a_C+H_C be the attainable coset from its matched orientation and a'_C+J_C from its alternate orientation, obtained by summing the independently attainable edge cosets. If H_C subseteq J_C, restrict the alternate orientation to a'_C+H_C. Then the union of the two restricted orientation supports is exactly a_C+H_C+span(a_C+a'_C). This strictly generalizes the sufficient equal-period criterion. Select pairwise vertex-disjoint cycles; their flips, and labels on remaining matched edges, can be independently reconstructed. Hence a+L subseteq R subseteq a+U, where L combines base coset directions and the selected cycle deltas. Tagged GE and local GE on orientation labels reconstruct a matching and explicit selected labels. If rank L=rank U, the entire response relation is exactly affine; otherwise accept a target in a+L, reject a target outside a+U, and leave the gap UNKNOWN. Retain partial carriers with exact maps. Do not infer general response completeness from rank alone.

A deterministic polynomial candidate dictionary comes from root-to-i paths, i->j arcs and return paths in supported SCCs, decomposing each closed walk into simple cycles, plus reciprocal two-cycles. Greedy disjoint-cycle admission with independent delta increases fixed-chart lower rank (at most b times), but does not guarantee a disjoint spanning set.
