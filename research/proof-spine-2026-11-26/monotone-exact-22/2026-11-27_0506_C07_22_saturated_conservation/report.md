## Lemma 1: saturation bridge (proved with scope)
In any collection of m verified NAE triples, the number of cut pairs counted with multiplicity is exactly 2m under every solution. Proof: a nonmonochromatic triple has two unlike pairs. If we can add an explicitly given nonnegative integer weighted set E' of pairs such that the resulting weighted graph has a certified cut upper bound U<=2m, then U<2m refutes the region; U=2m forces every positive-weight added pair to have equal endpoint bits. This is a sound necessary inference, not automatically an exact projection. If using actual EX22 rather than private-slack NAE rows, a satisfied EX22 row contributes exactly four unlike pairs among six. More generally mix these identities with their respective targets. Multiplicity must be retained. A sufficient readily verifiable upper bound is a nonnegative integer sum of complete-graph cut bounds floor(s^2/4), with weighted edge incidence checked exactly; no maximal-clique enumeration or oracle assumed. If sums only dominate edge weights the same upper bound is sound. Exact support requires reverse lifts separately. ## Lemma 2: Fano puncture has exact equality interface
Seven IDs labelled 1..7, seven triples {a,b,a XOR b} for distinct nonzero elements of F2^3, each unordered pair once. Remove one line B={1,2,3}. Each of the remaining six triples has one B point and two other points. Each is encoded by a native row with its own private completion. Their pair graph is K7 minus the triangle on B, every retained pair once. Each solution has 12 cut pairs in retained edges. K7 has at most floor(49/4)=12 cut pairs. Therefore zero missing triangle pairs are cut: all three B bits equal. Conversely for either common bit t set all four non-B bits to 1-t; each retained triple has sum 2-t, so its private completion is t. Exact joint boundary support is {000,111}, with explicit lift. Any subset of B can be the actual seam; all interior variables and completions must have no exterior occurrences or extra guards. With additional boundary pins intersect the relation; with interior pins recheck or decline. This is a known-style critical equality gadget; no novelty claim for Fano itself. The new integration is source-acquired saturated conservation followed by exact matching admission. Removing a second line {1,4,5} makes all eight B words attainable (executed), so a missing multiplicity check is fatal.
