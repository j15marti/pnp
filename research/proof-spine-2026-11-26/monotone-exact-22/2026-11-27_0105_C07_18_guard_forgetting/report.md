## L1 PROVED: guarded forgetting and proof-DAG replay
Fix actual root context G, domain alphabet [q] constant, original owner IDs. A guard g is a consistent set of owner=value pins. A negative record means F AND G AND g is inconsistent. Maintain records in chronological order, each verified with earlier records only. Terminal B(g,L) is sound polynomial unit/domain propagation followed by exact 2SAT on currently two-valued owners, with all eligible unary/binary learned constraints; remaining nonbinary constraints may be relaxed ONLY for NO. Dropping a still-active higher-order constraint does not establish exact projection. Original IDs and root G always preserved.

If terminal refutes g, try deleting its pins individually. Accept a deletion only when terminal under remaining g and previously certified library L still refutes. At most |g| tests in a single deletion pass; one need not find a globally minimum guard or all minimal guards. For monotone terminal (below), a single pass obtains inclusion-minimal terminal-refutable subguard relative to fixed L. This is not necessarily a smallest semantic UNSAT core. All failed tests are charged.

Forget a variable v not in parent guard h by acquiring, for every a in the ORIGINAL domain of v, an earlier negative record g_a contained in h union {v=a}. Then h is a negative record: any hypothetical solution meeting h has an actual v=a and satisfies g_a, impossible. When any g_a omits v=a, g_a is already contained in h and can be returned without processing the other branches. Otherwise let h be the union of all g_a with the split pin removed, provided remaining pins agree; this is a subset of the current context and may forget many unrelated branch decisions. All cases must be covered, including values already excluded by propagation, unless separate certified exclusion covers those values. Keep explicit child IDs and check earlier indices, guard containment and every original color alternative. No cyclic proof.

Thus each record is independently sound by chronological induction; empty guard certifies original context NO. A global library of width<=w may be used across all subsequent guards, not just in the originating branch. A guard is a forbidden conjunction, not an assertion that it is attained. Width cap on stored reusable clauses does not itself cap transient branch proofs or search length. This is a scoped integration of known CSP nogood learning/backjumping with a moving binary terminal, not a claim to invent resolution.

## L2 PROVED: search-tree-free acquisition for a fixed guard-width proof class
For each fixed q,w let U_w be all consistent guards of at most w pins including empty, M=sum_{j=0}^w q^j binom(n,j). On a polynomially verified explicit binary CSP chart, initialize L empty (or sound acquired negatives). Repeatedly scan every g in U_w:
(1) add g if B(g,L) refutes;
(2) for every v not in g, check whether for each original a some earlier L record lies within g union {v=a}. If so add g, with actual child records. Exact subset checks, no oracle. Also permit direct weakening (existing record subset g), or absorb it in terminal. Immediately reclose root after each actual new import. Stop on empty record or after a full sweep without change; latter UNKNOWN.
B is monotone under more pins or learned negatives for this implementation: domain-unit closure only shrinks domains (any prior derivation can be replayed or an earlier contradiction occurs). Every old binary-domain owner either remains binary, becomes fixed, or has an empty domain. Old active binary clauses on that core, when restricted by more domain deletions, are either still present, satisfied, or reduced to units/empty which domain-unit propagation handles. An inconsistent old core cannot acquire a solution under those restrictions. This argument also applies to binary clauses activated from learned negatives whose other pins were already fixed. For any alternative terminal lacking this monotonicity, require verification of an explicit earlier proof and do NOT assert completeness of greedy saturation.

Soundness by L1. Completeness for EXACTLY the bounded-width proof class: if a chronological proof exists whose every record has width<=w, whose leaves use B with earlier certified records, and whose internal steps are the all-domain rule or weakening, then each proof record will enter the saturation by induction on its original index. More learned records cannot invalidate a refuting terminal. Root becomes empty. No proof tree or ordering supplied to saturation; no need for number of proof records to be known. This establishes one uniform polynomial algorithm for fixed w, conditional on admitted proof width; w=O(log N) is not enough for polynomial enumeration of arbitrary guard IDs.

Charge every candidate: at most M strict insertions and M+1 sweeps. At most O(M^2) terminal calls including root recloses. Naive all-domain rule subset scans cost O((M+1)M*n*q*M*w*poly(log N)) bit operations; terminal on explicit polynomial chart and at most M records has polynomial cost in N+M*w*log N, including domain closure (<=qn deletions), learned-record scans, binary graph construction, SCC, verification and address/tape simulation overhead. For fixed q,w and polynomial chart size, aggregate is fixed polynomial in original N. Store M guards with provenance and at most q references per split, and charge replay; polynomial peak and cumulative memory <=(T+1)S on same deterministic realization. Constant number of replicas and fixed candidate caps must be added, not measured by parallel span. This is full finite acquisition conditional on existence of bounded-width proof; not universal P=NP. No counting or equivalence oracle.

## L3 PROVED: indexed activation preserves the moving-core terminal
Let each learned nogood be indexed by every original owner=value literal it contains. For a closure call, build/reuse index of actual current library. Queue all singleton domains (including root pins and decision pins). For a processed singleton, propagate graph disequality, and inspect each indexed learned nogood. A nogood is inactive if one literal is impossible. If all are fixed true, refute. If all but one are fixed true, remove the remaining literal's value, queueing newly singleton owner. Process empty/unary records initially. A not-yet-processed constraint can become unit or false only when some literal becomes singleton true (or was already so initially), since impossible literals never reactivate as domains shrink. Therefore queue exhaustion gives same closure as exhaustive scans. For width>=3 learned nogoods to induce a binary clause at least one literal must already be singleton true, hence they have been touched. Include all width<=2 clauses and all touched records when building binary-core 2SAT; only retain clauses whose unfixed pins lie on two-valued owners, after removing actually fixed pins and testing inactive records. All old eligible clauses preserved. Hence indexed terminal returns the same propagation/SCC contradiction result as full rescans, with no loss of guard identity. Queue processes each owner at most once per closure call; touched-record scan charged by actual incidences. Scope explicit graph disequality + forbidden conjunction library; no general CSP indexing claim. This is the hybrid connection: learned guard forgetting changes the binary implication graph; event indexing changes acquisition overhead of both learning and 2SAT. Not merely a parallel solver.
