## 2. L1: exact signed two-port quotient (proved with scope)
Initially enforce all actual pins and native occupancy propagation: a row with known sum s and r free bits fails if s>2 or s+r<2; equality at either endpoint fixes all remaining bits. Iterate to fixed point, at most n additions. In the closed residual classify every row with two live bits and remaining demand one as an exact complement equation x+y=1. Fully satisfied rows can be retired; no other nontrivial row is assumed affine. More generally the following theorem allows any separately verified exact affine subsystem on actual variables and remaining signed integer cardinality rows, with every original factor covered and exact reverse lift.

For the native complement graph, discover components and parity labels by BFS (odd inconsistent component gives immediate refutation). For each component C, x_i=t_C XOR s_i, one independent free bit t_C; fully fixed classes substitute constants into all rows. This is an exact description of the solution set of the complement subsystem, not the affine hull of the entire nonlinear system. Every class assignment lifts by the labels. Joint independence follows from distinct graph components. This is important: merely collecting pairwise equalities from an affine system can omit a ternary parity dependency. For a general exact affine subsystem, compute its affine image on actual surviving port coordinates by Gaussian elimination; either inconsistent or x=x0+Lz on those coordinates. Group identical nonzero linear forms (rows of L); constant forms are pinned. Retain signs from x0. The image is exactly independent signed classes if and only if the number of distinct nonzero forms equals their rank. Proof: the coordinate map onto these distinct forms is surjective exactly at full row rank; otherwise there is a further dependency. Record actual Gaussian witness lift, not only projected hull. This general affine recognition is symbolic here, not implemented.

A PORT is an occurrence in an actual remaining occupancy row. Count occurrences, not distinct variable IDs or geometric edges. Suppose every free class has at most two ports, with arbitrary many internal equalities and variables. Build a perfect matching graph as follows:
- For each occupancy row j with d_j free ports and exact demand b_j, make one vertex for each actual port and d_j-b_j private dummy vertices, each adjacent to all ports of that row. Reject out-of-range b_j. (When a row becomes fixed, its demand is adjusted before this construction.)
- A two-port class of equal signs gives a direct edge between its two port vertices. A two-port class of opposite signs gets a private auxiliary vertex adjacent to both ports. A one-port class gets a private vertex q adjacent to its port. Zero-port class is irrelevant to remaining occupancy and can be lifted arbitrarily in a consistent affine subsystem.
- Let Q be the set of singleton q vertices. Add at most one new vertex to Q to make the total graph vertex count even, and connect Q as a complete graph. The extra vertex has no other neighbors.

Claim: an original satisfying assignment exists iff this explicit graph has a perfect matching. In a perfect matching the d_j-b_j dummies consume exactly that many distinct ports; precisely b_j ports are matched externally. A direct class edge is either used at both equal ports or unused at both; an opposite auxiliary is matched to precisely one port. A singleton port may be matched to q (selected) or to a row dummy (unselected). Therefore selected port bits satisfy every occupancy row and class sign constraint. Recover phase bits and actual native/affine witness. Conversely from a valid assignment use the direct edges for selected equal pairs, the auxiliary edge for the selected opposite port, and port-q edges for selected singletons. Match all unselected ports bijectively to their own row dummies. The only unmatched vertices lie in Q. Its remaining cardinality is even because total vertices are even and all already chosen matching edges cover pairs. A clique on an even number of vertices has a perfect matching, including empty. This also covers two distinct ports of the same row, parallel owner-pair connections and signed orientations; no need to prohibit loops at the row level. Negative result certified by a maximum matching or Tutte obstruction; a direct polynomial deterministic general-graph matching algorithm is standard (Edmonds). No claim that the auxiliary matching graph is planar.

All graph sizes polynomial: with P actual free ports, O(P+1) vertices and O(P^2+1) edges, including the singleton pool. Reading source, propagation, native exact class acquisition and witness lift polynomial in original N. General verified affine input with polynomial bit length is allowed only after source provenance and exact relation acquisition are paid. The construction is a scoped use of familiar f-factor/Tutte port gadgets and edge-CSP tractability, not a priority claim about matching. The useful bridge is applying them after exact affine seam quotient, rather than imposing occurrence two on physical native variables or assuming all affine relations are equality classes.

Hereditary composition: for native complement-only exact subsystem, pinning any actual class variable fixes its entire phase, preserving independent classes and only reducing live port counts; adjust demands and reapply occupancy closure. Joining regions by exact signed equalities is allowed if the combined source and all private lifts are retained, and the global class incidence bound is verified (not just each region's local bound). Internal equality cycles are allowed. Thus no bound on the number of interface bits is necessary for this admitted algebraic geometry. With an arbitrary affine projection, additional private-variable pins may couple previously independent projected phases: recompute the exact projection and recheck rank, do not inherit admission. ## 4. L3: bipartite matching cut transports to native integer refutation
For an admitted same-sign paired quotient with no singleton, distinct row endpoints, bipartite row graph (L,R) and total demand B=sum_L b=sum_R b, form capacitated network source->L with b, L->R capacity1 per actual class, R->sink with b. Integral max flow B iff exact occupancy b-factor. If max flow f<B, let S be reachable from source in residual graph. Cut formula:
B-f = sum_{v in L intersect S} b_v - sum_{v in R intersect S} b_v - |E(L intersect S,R minus S)| > 0.
Hence weighted sum of actual occupancy equations (weights +1 on L intersect S, -1 on R intersect S, zero otherwise) demands more than the sum of positive remaining class coefficients. This inequality refutes the original problem.

For native complement classes, lift the cut entirely to original integer row identities. If ports a,b of a class are equal, their complement-graph path has even length. Alternating sum of path equations x_i+x_(i+1)=1 gives x_a-x_b=0; before guard substitution the same combination is an integer combination of original native rows. For coefficient c_a on a, subtract c_a times this equality. Repeat across classes. For a fixed port value, substitute its actual pin (or previously certified deduction; in tests all constants were original pins). A verifier needs only the original rows, exact pins and integer weights lambda_j. Compute c_i=sum_{rows j containing i}lambda_j and rhs=2 sum_j lambda_j, then subtract pinned contributions and set those c_i=0. If rhs>sum_i max(c_i,0), every Boolean assignment violates the equation. This is a source-native proof without trusting graph recognition, flow implementation or heuristic layout. Weights and path lengths polynomial, dense accumulation polynomial in original N; for test family weights are +/-1. General nonbipartite/signed matching certificate transport to original row-only inequalities is NOT claimed (odd-set obstructions may require stronger reasoning). General L1 negative result uses checked graph adapter + ordinary perfect matching certificate. No arithmetic-circuit lower bound invoked.
