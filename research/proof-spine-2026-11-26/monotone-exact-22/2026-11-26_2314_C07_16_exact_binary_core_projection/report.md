## L1 PROVED: simultaneous exact binary-interior elimination with unbounded exterior
Let a finite-domain binary CSP have explicit unary lists D_v and explicit binary tables R_uv (missing table means universal), all guards retained. Partition into B with nonempty domains of size <=2 and O arbitrary explicit finite-domain owners. Encode B in Boolean choices (singleton may be encoded by two identical choices or an actual unit). Internal constraints H on B are 2CNF: each forbidden pair gives a binary clause. If H inconsistent refute. For each exterior choice e=(u,a), constraints between u and B forbid zero, one or both values of every private Boolean. Hence e induces either impossibility, or a set U_e of forced Boolean literals. Keep exactly individually feasible e (H AND U_e satisfiable). For every pair e,f of different exterior owners, keep the pair iff its original exterior table allows it AND H AND U_e AND U_f is satisfiable. Retain all original exterior constraints and domains. Claim: the resulting binary CSP on O is exactly the existential projection of the original, not merely a necessary pairwise relaxation.

Necessity is immediate. For sufficiency, choose a complete exterior assignment passing the compiled unary and binary tables. Any solution of H under its total set of forced literals lifts this exterior assignment to original constraints. A satisfiable 2CNF H plus any unit set U is inconsistent iff the implication closure of U contains opposite literals. Proof: reachability is necessary; if the closure C is consistent, set every literal of C true, their complements false. No implication leaves C, and by contraposition no implication from an unassigned literal leads to false (that would put its opposite in C). Remaining clauses are satisfiable by restriction to their unassigned variables of an original H solution, since no new unsatisfied units arise. Thus extend. Reachability closure of a union is the union of closures. An opposite pair in the full closure would be obtained from one or two of the U_e. Those same one or two exterior choices would fail the compiled tests, contradiction. If O empty, H alone decides. Every accepted exterior word extends simultaneously; do not combine arbitrary marginal witnesses. Given a word, solve H once with all its demands and lift; preserve original IDs and guards in reverse order. No requirement on geometric seam width or acyclicity of B. This extends the C07-12 pair-option theorem into a dynamically applicable exact retirement operation, not a claim of priority over known binary CSP variable elimination.

Efficient acquisition: construct implication graph, compute transitive reachability (e.g. Boolean Floyd–Warshall, O(b^3) elementary operations), compute closure bitset per actual exterior option; if H inconsistent or an option has a contradictory internal demand, reject; for each pair check union for an opposite literal. All tables obtained without enumerating 3^|O| boundary assignments. For fixed domain bound q=3, O(n^2) options-pair records, bitsets length O(n), O(n^3) elementary bit operations for pair conflicts plus guard construction and reachability, polynomial overhead for indexing/source maps. For arbitrary explicit q use actual total option count L and O(L^2 b) comparisons; no hidden oracle.

## L2 PROVED: independent single-owner set-intersection derivation
For a private owner v with |D_v|<=2 and actual exterior choice e, define S_e subset D_v as allowed private values. For a fixed joint exterior assignment, v extends iff intersection_e S_e nonempty. Empty intersection of subsets of a two-element set has a subfamily of size <=2 with empty intersection: either some S_e empty or the two elements are excluded by one set each. Thus exact projection is obtained by unary and pair exclusions, with no new higher-arity factors. Repeat for each binary-domain owner; fill remains binary, so the same proof applies hereditarily. For each retired v compute every S_e and intersect every pair, store original D_v and masks for actual selected choices. Given an accepted exterior word reconstruct in reverse by selecting a member of the true intersection. This independent proof covers cycles and dense fill; one-at-a-time projection equals simultaneous projection semantically because existential quantifiers commute. No need to guess an elimination order for this admitted set: choose any current <=2-valued owner. After each retirement, arc-close and check contradictions. On any single deterministic contraction execution at most n retirements, at most 9*binom(n,2) possible pair entries; repeated domain narrowing and table intersection only delete. Conservative O(n^3) pair scans plus O(poly(N)) arc closure, parsing, actual ID/index, proof replay and storage; polynomial aggregate fixed-arity representation. With original N explicit, all arithmetic bit lengths polynomial. Retained historical tables/masks for reverse reconstruction polynomial across n steps. For branch-free admitted cases, genuine hereditary exact composition, even without forest layout.

Hostile control (symbolic, minimal for soundness): a ternary owner v with three leaves, disequality edges, leaves pinned respectively colors 0,1,2. The guarded star is NO; every two pins are extendible into v but all three are not. In the unpinned projection the joint leaf relation forbids rainbow triples and admits every pair, so a pure binary table on those leaf IDs cannot encode the exact response. Via the same hub/one-hot/edge adapter this is a native guarded EX22 counterexample. Thus no unconditional ternary extension of L1/L2; the L02 net obstruction reappears. On arbitrary binary domains equality constraints, disequalities, arbitrary exact pair tables handled uniformly. Arc/path consistency is sound but may stall; matching is neither presumed equivalent to these tables nor executed here.
