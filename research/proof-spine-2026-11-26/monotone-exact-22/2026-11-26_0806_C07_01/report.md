## 2. L1 PROVED: two native forests with constant-size components retain NP-completeness
For every EX22 input F of m rows and n active variables, create one fresh occurrence bit for each port, and retain each source row on its four actual occurrence IDs in forest A. For each original variable v, order its d(v) occurrences o_1,...,o_d deterministically. For each consecutive pair o_j,o_{j+1}, create three new private bits p,q,r and two native rows:
 A: o_j+p+q+r=2;
 B: o_{j+1}+p+q+r=2.
All physical variables within each row distinct. Subtraction forces o_j=o_{j+1}; transitivity makes all copies of v equal. Conversely any original solution extends: set every copy to v, then choose 2-v of the three private bits to be one. Decode any compiled model by selecting one occurrence per original ID. This is exact, including fixed original guards translated to copy pins; existential witness multiplicities are not preserved.

There are L=4m-n consecutive links, 4m+3L=16m-3n variables and m+2L=9m-2n rows. Every occurrence bit has at most one original row, one outgoing A row and one incoming B row, degree <=3. Every new private bit has degree2. In A the original rows are disjoint stars; each of their four occurrence leaves has at most one attached extra row with three otherwise private leaves. Each A connected component is a tree on at most 21 incidence nodes (5 row nodes +16 variable nodes). In B the rows are disjoint stars on five nodes because each occurrence is destination at most once and private link bits are fresh. Thus even a supplied valid partition of the native rows into two forests of uniformly bounded component size does not remove NP-completeness. Each forest alone is satisfiable, all individual port polarities locally supported by complementation. This is a new independent hardness authentication for degree<=3 with supplied partition; not a linear-incidence or planar hardness claim. The joint forest query is NP-complete by the original reduction and polynomial verification of partition, promise and witness.

Constructive complementary view: exact row subtraction and equality quotient eliminate the occurrence copies; remaining link rows are tautological after existential elimination of their private bits, so the quotient restores the original arbitrary F, not a tractable terminal. Contradiction-style view: a uniform polynomial algorithm for EVERY such joined forest pair yields a uniform polynomial algorithm for EX22 by this explicit reduction, hence P=NP. This is not a contradiction of known theorems and not a P!=NP proof. What is refuted is the structural assertion that small forest components imply small cumulative interfaces or independent choices.

## 3. L2 PROVED: minimum eligible physical seam acquisition in fixed polynomial exponent
Given m>=4 explicit factors on n actual Boolean IDs, define a proper split as a partition of factors into shores A,B each with >=2 factors; width is the number of IDs occurring in both. This includes exact replacement tables. Build directed node-split graph: one node per factor, v_in,v_out per variable, v_in->v_out capacity1, f->v_in and v_out->f capacity n+1 for each incidence. For every four distinct factor anchors (two each shore), force first two on source side and second two on sink side by arcs of capacity n+1 from super source/to super sink. A finite cut <=n always exists by assigning factors to shores and cutting all shared variable arcs as needed. No cut of minimum capacity crosses a large arc. For every shared variable its in node is on source side and out node on sink side, so its unit arc crosses; conversely a factor partition admits a cut of exactly its shared-variable count by assigning pure-side variables to that side. A minimum cut's shared count equals its capacity, since otherwise the same partition gives a cheaper cut. Every eligible split contains four anchors. Minimize across all O(m^4) anchor tuples. Returns exact global minimum eligible width and actual factor shores, or no eligible split if m<4. No enumeration of all n^k candidate separators; exponent independent of width. Deterministic integral augmenting paths suffice: flow bounded by n, at most n augmentations of >=1, BFS and residual cut construction polynomial; capacities/indices O(log N) bits for polynomial representations. No external theorem about arbitrary constrained balanced cuts is needed. This method does NOT optimize the ratio of shore sizes among all possible cuts. It may fail an asymmetric tariff even when another cut would pass.

## 4. L3 PROVED: exact hereditary composition with an explicit asymmetric tariff
At a residual node with m factors, acquire a split with smaller shore a>=2, larger b>=a, a+b=m; k shared Boolean IDs. Under all inherited unary guards evaluate all q=2^k seam words in the small shore, skipping directly contradictory pins but charging all attempted words. Every recursive call must yield exact YES/NO or the lane declines (UNKNOWN cannot be marked absent). Store precisely attainable words as an exact relation and one actual local witness each. Replace a factors by that single relation, solve larger shore once with b+1 factors, reconstruct using the actual selected shared word. Internal original IDs and guards remain in witness maps. Sufficiency and necessity follow by gluing on the full joint intersection, not on marginals. A coupled guard crossing the partition is itself an actual factor with scope included in cut acquisition; unencoded guards are not silently dropped.

Fix integer d>=2 and accept a cut only if q*a^d <= (a-1)*m^(d-1). Since 0<b+1=m-(a-1)<m,
 (b+1)^d < (b+1)*m^(d-1),
hence q*a^d+(b+1)^d < m^d, so integer potentials give <=m^d-1. For fixed maximum width k0, d=k0+2 suffices: (a-1)/a>=1/2 and m/a>=2 imply 2^k0 <= ((a-1)/a)*(m/a)^(d-1). More generally width can increase asymmetrically if 2^k <= (1/2)(m/a)^(d-1). A small shore can therefore admit a logarithmic seam, but balanced logarithmic seams are not covered. Check the exact integer tariff, not floating logs. This improves the conservative exponent k0+3 in EX22-07 and supplies a width-independent physical cut acquisition routine.

Conditional global solver: repeat the above using deterministic minimum eligible seam choice, admitted non-increasing forced simplifications, exact tables and a verified polynomial terminal when no admitted cut exists. Small m<=3 handled by enumerating the Cartesian product of at most three explicit factor row lists, checking shared IDs and pins; no free enumeration of their entire Boolean cube. The algorithm is uniformly polynomial even if it declines a prime: for root m0<=N, sum of child potentials <= parent potential-1 gives <=m0^d processed nodes, all failed branches included. Each admitted table has at most q<=m0^d rows and polynomial length; all original IDs remain within N. All mincut calls, guard scans, exact arithmetic, sorting, row matching, terminal cost and witness construction paid per node by fixed polynomial p(N) if d fixed and the terminal itself has a fixed polynomial cap. No need to memoize; retaining all nodes and witnesses uses <=m0^d poly(N) bits even without freeing; same execution cumulative memory <=(T+1)S. Polynomial RAM-style finite-array operations can be simulated with polynomial bit-machine overhead. This is a complete budget for the scoped lane, not a proof that all native residuals are admitted. Coupled guards or new factor growth outside these rules require separate tariff or decline.

## 5. L4 FALSIFIED: width-k universality is not hereditary under exact tables
For any fixed k>=5, take four factors as vertices of a K4. Partition its six edges into three opposite-edge matchings; give the two edges in matching i exactly t_i distinct shared variable IDs, where t=(floor(k/3), floor((k+1)/3), floor((k+2)/3)). Every factor scope has k IDs. Every split with >=2 factors per side is 2 vs 2, and its width is 2(k-t_i) for one i. Since max t_i=ceil(k/3)<k/2 for k>=5, all widths exceed k. All four relations may be exact all-equal relations on their k ports. Native realization of each relation: connect its k port IDs by a chain of k-1 instances of the two-row equality gadget in L1, with fresh private triples, and existentially project private bits. This is a source-realizable exact boundary table of two rows with actual lifts. These tables lie in the legal explicit response language, but the universal fixed-width seam premise fails in that language. No claim that the particular deterministic recursive selector necessarily reaches this state. Equality closure solves it immediately; conflicting unary guards yield a NO neighbor. This is a syntax/representation obstruction, not general hardness.

In particular, the observation that any two original four-port factors have union scope at most eight does not prove hereditary width eight: after grouping, actual response scopes can be larger and cumulative overlap can grow. Changing projection order or multiplying replicas does not reduce the full joint support automatically.

## 6. L5 PROVED: grid control with exponential explicit cross-chart relation and cheap exact solver
For side length l>=4, at cell (i,j) introduce horizontal bit h_ij and vertical bit v_ij. Enforce equality between neighboring h along each row and neighboring v along each column using the two-row equality gadget. At each cell add native row h_ij+v_ij+a_ij+b_ij=2 with two fresh private bits. For every pair of h,v values this last row has a completion (choose 2-h-v private ones), so physical coupling creates no semantic restriction. Every row has one independent horizontal phase, every column one independent vertical phase. The exact relation between ordered west+north bits u and east+south bits w is precisely u=w, with all 2^(2l) words attained. Each side has full marginal support; a sound Cartesian rectangle X times Y contained in the equality relation can contain only one word pair (otherwise a cross pair differs). Thus explicit row enumeration or fixed-shore rectangle cover needs >=2^(2l) entries, despite compact equality circuit and polynomial decision. This lower bound is only for the specified representation and port partition. It is NOT a lower bound for arbitrary circuits or all cuts. Applying L1 yields the same exponential exact port support on actual selected occurrence representatives while both native clause forests have constant-size components. The full native SAT/NO neighbor is obtained by adding one native row on four distinct h variables in the first row: equality forces their sum to be 0 or 4. No absolute pin, so genuine native unguarded sources. A guarded version may use any actual pinned bits; equality conflict checks are exact. No incidence-planarity claim made.

Explicit L02 adapter for restricted crossing-only four-port grid relation N=S and E=W with unary port pins: map horizontal/vertical cell bits to their respective local ports, enforce adjacent cell equalities as above, and translate pins to cell variables (conflicting pins reject). Original shared edge labels agree in both directions; the cell occupancy row always extends. O(l^2) records, deterministic witness lifts. Does not transfer L02's full arbitrary explicit-table source, singleton-table decision function, or circuit-scope lower bounds. Cumulative context versus immediate child overlap is an analogous concern, not an automatic theorem transfer. Row/column replicas preserve actual joint IDs and equality relation.

Complementary algorithm on SAME compiled grid residual: acquire common triples in current rows and subtract, union equal IDs, repeat until no new equality; preserve multiplicities when a row now repeats an ID. For each normalized row enumerate its at most 16 local Boolean words. Empty row support certifies NO. If every assignment to the variables shared with other residual rows extends to its private variables, delete row retaining one witness for each exterior word. Recompute actual occurrences, repeat, and lift in reverse. Simultaneous peeling is safe because private variables occur in exactly one retained row that round, and reverse lifts honor retained variables. Source-derived equality gadget rows and all crossing rows eventually disappear on grid YES; the extra row becomes 4h=2 and is rejected on grid NO. This is nonbranching, exact, polynomial in actual source length; at most n successful unions, m peel rounds, polynomial scans/sorts. It is a special case of the general exact-table contextual projection idea, not a P3DM theorem transfer. On arbitrary F the procedure may decline.
