## Theorem A: exact target-conditioned subspace seam
All arithmetic GF(2). For coordinate set X union of leaves let P_X=span(A columns in X), Q_X=span(A columns outside X). Set K_X=P_X intersect (b+Q_X); it is empty or a coset of P_X intersect Q_X of dimension d_X=rank(P_X)+rank(Q_X)-rank(A). If b outside span A, reject immediately. Let S_X be actual syndromes from local assignments satisfying every factor within X; do not enumerate S_X in general. Store T_X=S_X intersect K_X. At leaf i acquire actual local support and filter; bounded-size leaf via enumeration, fixed local affine rank via C07-24 generator theorem testing each local syndrome in its span (not an uncharged oracle). For disjoint children U,V of X:
T_X = {u+v : u in T_U, v in T_V} intersect K_X.
Proof forward: any actual s in S_X intersect K_X has a decomposition u+v via independent factors. Since b+s is in Q_X, b+u=v+(b+s) belongs to Q_U, and b+v=u+(b+s) belongs to Q_V. Thus neither child state was pruned. Reverse: any joined pair supplies actual compatible local witnesses on disjoint coordinate IDs; their sum in K_X gives the exact target-extendible-by-linear-span condition. No inference that outside affine-span membership is actual outside support. At root K={b}; empty iff NO. Retain one actual local witness and child references per attained syndrome to reconstruct a decision witness if desired; duplicate paths are OR, not arithmetic count. The same proof applies to path prefix and single factor transition. Each table <=2^d_X; maximum child-pair work 2^(2d), even when ambient rank is linear. For path with explicit small local supports, work <=2^d times sum of support sizes plus span operations. This is a constrained extension of standard matroid connectivity/trellis state dimension, not a new claim about linear-code trellises. Exact negative composition holds hereditarily at fixed b and fixed factorization; it is not a universal boundary response for all b.
