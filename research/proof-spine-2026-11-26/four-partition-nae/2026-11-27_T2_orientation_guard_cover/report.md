## PROVED WITH SCOPE: necessary flow to direct conservation
For a guarded normalized signed E/B residual let J be any subset of original B owners. For root r define c0(r,J), c1(r,J) as number of original ports in J with signs 0 and 1 relative to r. If root bit t is pinned, its true-port contribution is c0 for t=1, c1 for t=0. Otherwise its contribution lies between min(c0,c1) and max(c0,c1). Every solution needs exactly 2|J| total true ports. Therefore if the sum of these maxima is below 2|J|, or the sum of minima exceeds it, the guard is impossible. The proof is exact integer arithmetic. A subset certificate has O(N log N) bits at worst and is checked in polynomial bit work by rebuilding parity map and scanning original ports. On a fixed chart no hidden counting is needed.

Flow relaxation: make source->root capacity max(c0,c1) across all selected B owners, or exact count if pinned; root->B capacity number of its incident ports that could be true; B->sink capacity 2. Each feasible assignment induces saturating integer flow using its true ports. Thus a cut below demand refutes, but saturating flow is UNKNOWN. For any cut let J be B owners on sink side. Contributions from each root on source side are bounded by crossing arc capacity into J; roots on sink side bounded by source arc capacity. The exact signed max on J is at most the sum of these two contributions. Since other B owners contribute 2 each to cut, deficiency implies max(J)<2|J|. Thus every deficient flow cut has a direct occupancy certificate, no need to replay max flow. Uniform Edmonds-Karp has polynomial aggregate work in explicit graph; integers O(log N) bits; direct verifier is smaller. Finding a different subset without flow remains an optional search. Greedy deletion does not certify global minimality. Flow cut completeness or universal acquisition is not claimed.
