## 2. A: exact graph-cut adapter (PROVED)

For signed literals x_u xor s_u etc., their opposition bit is d_uv=p_uv xor s_u xor s_v. For clause i with variables a,b,c, exact NAE iff d_ab OR d_ac (under relative parity consistency). Can add redundant disjunctions for the other two pairs of edge observations. Implementation includes all three pairs and all three 2CNF disjunctions, with each literal meaning p_uv=1 xor s_u xor s_v. This is a 2CNF B on actual observations. Retain G consisting of fundamental cycle XOR equations of the observation graph, acquired by spanning forest. For a non-tree edge uv impose p_uv xor sum(path uv)=0. Necessity telescoping; sufficiency assign each component root bit arbitrarily and propagate tree edges, verify every non-tree edge. Signed original clauses then follow from B. Thus F SAT iff intersection of B-models and G-models nonempty; witness lift polynomial. For arbitrary extra guards on x, substitute exact tree path expressions plus free component roots; do not silently drop absolute pins or cross-component guards. ## 3. B: exact affine hull of satisfiable 2CNF; polynomial exchange (PROVED)
Let B be satisfiable 2CNF on p Boolean variables. Its implication graph has paired SCCs C and complement(C), distinct since satisfiable. Within each SCC literals equal; variable equalities/oppositions follow; a path from a literal to its complement forces the literal false. These relations are acquired by SCC and reachability in polynomial time. Conversely they generate the ENTIRE affine hull of B's model set over GF2. Proof: given actual models x,y, the SCCs true in y but false in x form a set D. In condensation DAG choose a sink in D. Flip that SCC true and its complement false. Every outgoing implication from newly true SCC goes to a literal already true or same SCC (otherwise another member of D); removal of complement cannot invalidate an implication from a still-true SCC by contraposition, since such an implication yields outgoing edge from newly true SCC to a still-false complement. Thus remains a model and reduces D by one. Repeat to y. For every nonforced complementary SCC pair there are models differing in its bit (2SAT with respective unit assumptions). A path between them has one flip with difference vector supported exactly on the variables of that pair. These disjoint support vectors span the full direction space satisfying forced pins and SCC equivalences. Hence no additional affine equation beyond these is entailed by B. Given a single extra linear parity equation, this also proves intersection with the hull is sufficient for actual B feasibility (a nonconstant parity takes both values); multiple parities need not have jointly attainable values.
Conversely affine G entails unary or binary clauses precisely through its projected one- or two-coordinate affine relations: full 2D projection cannot exclude any word; a proper nonempty affine subset forces a pin or equality/opposition or two pins. Gaussian parameterization p_i=sig_i dot free + offset_i computes these exactly by zero signatures and equal signatures. Transfer unit and signed equivalence clauses; these entail all binary consequences of G, not its higher-arity constraints.
Algorithm: keep both original B,G. Each iteration solve each independently, reject if either inconsistent, accept only after an actual witness satisfies BOTH. Import exact B hull equations into G and exact G pins/equivalences into B. Repeat to no change. Strict progress bounded by <=p independent affine rows plus O(p^2) distinct normalized binary clauses. This is a uniform deterministic polynomial partial decision procedure, no exponential tree. Fixed point with no jointly verified model returns UNKNOWN, NOT UNSAT. It is a relaxation exchange, not replacement of one model set by its hull. Certificates: SCC paths for each equality/opposition, path to complement for units, GF2 row combinations for G consequences, final inconsistent row or SCC with literal and complement. Store source owner IDs for original clauses and graph edges, and parent links for imported rows; alternatively deterministic replay of polynomial procedure verifies the result. Code in this run checks actual SAT lifts and recomputes deductions but does not export a full independently checked proof-term DAG for every instance.
Guarded exchange: in a copy with temporary assumption l (one observation literal), run ONLY the unguarded exchange (not recursively guarded). If contradicts, add not l to parent; if proves fixed q, add binary implication not l OR q. Guard discharge sound because original models satisfying l survive every import. If a child actual witness satisfies both systems, accept original. Repeat all 2p assumptions until new clauses cease. There are O(p^2) distinct clauses and each local probe polynomial, hence aggregate fixed polynomial; failed probes charged. Can retain guarded contradictions in a shared acyclic ledger (each imported clause justified using earlier parent facts plus temporary unit). Implementation imports fixed unary values at UNKNOWN branch fixed point, failed branch opposites, and stops at verified SAT. This is sound but not complete. Higher fixed-width coordinate guards can be enumerated polynomially for fixed width and learn clauses of that bounded size, but no universal coverage. General 2-XNF graph methods with affine linerals and failed-lineral deductions are known; our exact restricted hull proof, native family, and explicit closure falsifiers are the specific findings; no novelty claim over literature.

## 5. D: adversarial limits of the inference language (PROVED scoped)
On any raw positive linear NAE3 with all three observation edges included, B has all-ones word and every single-zero word, so full affine hull. G has full projection onto each pair of distinct edge coordinates (two distinct GF2 variable-difference rows independent). Thus base exchange has no new substantive affine or binary facts, even on raw AG9 UNSAT. It may find verified SAT witnesses on some raw sources. Guarded exchange can be strictly stronger: raw AG9 refuted by failed singleton guards in executed tests. A stronger obstruction for GENERAL affine+2CNF, not asserted to be unguarded genuine NAE4, is below.
Let B be m disjoint positive binary clauses on 2m coordinates. Let G be an affine code of dimension d whose coordinate linear functionals have every subset of <=2t+2 independent. For any guard assigning <=t coordinates, B either already refutes locally (both clause bits0) or fixes at most 2t coordinates. Its remaining disjoint unconstrained two-variable OR supports have full affine hull; hull gives only these pins. G restricted by these consistent pins has full projection on every one or two unpinned coordinates by stated independence, so gives no additional pins/equalities. No new guarded unit implications or conflicts beyond B's own consequences; even allowing higher bounded-width nogoods obtained by such checks cannot strengthen B. Yet can choose G with EMPTY joint intersection: for fixed t let d large, m=4d, choose 2m independent uniform random column vectors in GF2^d (independent draws, not all linearly independent). Probability any nonempty subset of <=2t+2 sums zero <=sum_{j=1}^{2t+2} binom(8d,j)/2^d ->0. For each nonzero latent z, bits at independently sampled columns iid fair; probability all m ORs hold (3/4)^m; union bound <=(2^d-1)(3/4)^(4d)->0. Zero word always fails B. Thus exists a homogeneous code with both properties for arbitrarily large d. Existence proof, no free construction or computational lower bound.
Explicit finite t=1 counterexample: GF64 via x^6+x+1, columns c_u=(1,u,u^3) interpreted as 13-bit vectors for 64 elements u. Every <=4 independent: odd sums have first coordinate1; two columns distinct; equal sums of two disjoint pairs would give equal sum s !=0 and equal cube sum. In char2, u^3+v^3=s^3+uv*s; hence same product, same roots, same pair contradiction. Choose affine offset represented by low/high unsigned32 words 648477357,3348622548; G={ (z dot c_i) xor offset_i : z in GF2^13 }. Verified all8192 latent words, none satisfy32 disjoint OR clauses. Verified rank13, all2016 distinct pair sums, 128 singleton guard branches: each has consistent G projection under B's at most2 pins, every unpinned pair full. Thus singleton exchange cannot learn anything beyond B and fails to refute this exact joint UNSAT. This is an abstract affine guard/2CNF control; can represent by two relative observations per disjoint NAE clause with additional arbitrary affine guard, but not an unguarded four-partition source or a claim about stronger 2-XNF closure using arbitrary affine linerals. No all-decider LB. The exact conjunction general mixed problem is known NP-hard; AB06 and literature clarify scope. Source-native all-input failure of this guarded cut closure remains OPEN.
