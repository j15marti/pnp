## Scoped uniform theorem
For every valid explicit E/B instance, normalize signed equalities; contradiction in a signed cycle is a sound NO. Otherwise construct exact B tables on at most four roots by checking all local words. Duplicate tables can be merged retaining all original IDs. Global complement symmetry permits fixing any existing root gauge to zero (or no gauge if no variables). Repeatedly choose a nongauge root v occurring in one or two factors with union of remaining scopes at most 4. Replace those factors by their exact existential projection on the union less v. For any assignment to all other roots, conjunction can be extended across v iff the projected table contains its restriction, since no other factor mentions v. Record one extension bit per allowed word. Every step removes a root, never increases factor count, table size <=16. A polynomial scan finds a candidate or certifies none of these rules applies. Terminate after <=O(N) projections. This does NOT prove a universal low-width residual.

Convert each table to one clause per forbidden word; exact and O(N) total literals since width<=4. Apply unit closure; split on any deterministically scored unassigned root, reclose each child; no conditional fact imported to a different guard. Cap decision depth d=floor(log2 N) (or fixed c log2 N); additionally measured cap 2,000,000 literal visits for each search lane in the actual experiment. A full binary tree has <=2^(d+1)-1 <=2N-1 nodes; each node scans O(N) literals for at most O(N) rounds, so O(N^3) indexed logical work over all nodes. Table acquisition scans <=O(N^2) scope incidences, local enumeration constant, all maps O(N log N) bits excluding tree. Conservative deterministic bit implementation by sequential scan for every lookup, comparison and map update within O(N^5 polylog N) time and O(N^2 polylog N) peak space; CM <= T*S for same implementation.
