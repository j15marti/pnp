## A. Constructive matching route
Theorem: let H be any signed NAE3 region whose bipartite variable-owner incidence graph is a forest, with three distinct variables per owner. Partition variables into free W=I union J (J subset B) and fixed Z=B minus J. Universal extension of every word on Z to a satisfying word on W is equivalent to existence of a matching saturating all owners into W.
Sufficiency: choose one distinct free representative per owner, select one of the two other variables in that owner, draw arc rep -> other with XOR label 1 xor sign(rep) xor sign(other). Outdegree at most one, and directed cycle would give incidence cycle (distinct owner representatives, each arc uses different owner, no self-loops). Thus directed graph acyclic. Set all nonrepresentative variables to prescribed or arbitrary values, process reps in reverse topological order to satisfy selected XOR. Each NAE owner then has two opposite literals. Original fixed values untouched. Matching, traversal and lift polynomial; no counting. If guards restrict fixed words, sufficiency holds as before; necessity below is only for unrestricted fixed words. Guards involving free/private variables must be retained and are outside this theorem.

## B. Independent contradiction / adversarial minimal Hall set
Assume no matching saturates owners into W. Pick inclusion-minimal nonempty deficient owner set S (Hall), with Q=free neighbors. If singleton then Q empty, pin its three literals equal. Otherwise |Q|=|S|-1: deleting any owner leaves a nondeficient proper set with at least |S|-1 neighbors, while |Q|<=|S|-1. Free-incidence graph on S,Q is connected, since a disconnected deficient component would contradict minimality. No free neighbor has degree1 in S, because removing its sole owner removes at least one neighbor and retains positive deficiency. As a forest, edge count <=|S|+|Q|-1=2|Q|; degree >=2 on Q gives equality. Every free neighbor therefore has degree2, joining two owner nodes of an ordinary tree (subdivision). Every fixed neighbor occurs at most once in S: otherwise its path through the connected free tree plus its two edges forms an incidence cycle. Root this tree at any owner. To force any desired Boolean value of a parent free variable, recursively set both other literals of its child owner opposite to that variable's desired literal, using fixed leaves or recursively forced child free variables. Signs are handled by converting required literal values to physical bit values. No fixed assignments conflict because fixed leaves distinct. At the root force all three literals to one chosen value, yielding an unavoidable contradiction. This pins only Z and proves nonextension independent of how W chosen. The certificate can be acquired by greedily deleting owners while matching remains unsaturable; inclusion-minimal S is reached in polynomial many matching tests, then tree traversal produces pins. This is a constructive counterexample and a proof of necessity.

## C. Exact minimum repair demand and conservation
Let m_R=number of region owners, r_I=maximum cardinality matching of owners into private variables. For forest H, q(R)=min |J| over universal repair sets of the projected relation equals m_R-r_I. Lower bound because adding |J| new endpoints can increase matching rank at most |J|. Upper bound: incidence forest with triples admits full matching by Hall (for any owner subset with t owners, 3t edges and at most t+v-1 edges in nonempty forest, so v>=2t+1). Extend a maximum I matching by augmenting paths in the full graph until all owners matched; augmentations never unmatch a previously matched variable endpoint, and cannot increase matched I count above r_I. Exactly m_R-r_I matched endpoints belong to B, and using those as J gives universal extension by A. Nonnegative weighted repair costs likewise optimize by min-cost owner-saturating matching (zero costs for private endpoints). Feasible repair sets are precisely those whose union with I has full transversal rank. This avoids the overoptimistic identical-neighborhood slot approximation.
For ANY partition of raw genuine NAE4 owners into incidence-forest regions, let each private variable belong to the unique region containing all its occurrences. Each private variable has all four incidences there; each owner arity3. Hall counting 4|Y|<=3|Gamma(Y)| for any subset of private variables implies r_I=|I|. Thus the sum of exact local minimum demands minus number of remaining boundary variables equals sum_R(m_R-|I_R|)-(n-s)=m-n=n/3. More strongly, assigning pairwise disjoint boundary repair sets to all regions is equivalent to a global original owner-saturating matching: union local matches (private variables disjoint, repair sets disjoint); conversely restrict global match to regions and use allocated boundary endpoints. Such matching impossible for raw NAE4 m=4n/3. This applies to regions sharing boundary variables and to merging regions whenever the resulting owner union is still a forest (do not double count common owner IDs). It falsifies universal discharge via independent universal repairs of forest caps, not existential compatibility or general algorithms.
General cycle budget: let K be any set of owners whose deletion leaves incidence forest. If projected R has a repair set J, same J repairs H-K, so theorem A/B gives matching size m_R-|K| into I union J in H-K. Its size <=r_I(H)+|J|. Therefore q(R)>=m_R-r_I(H)-|K|. Positive saving relative to the Hall-demand benchmark requires cycles, and is at most a minimum feedback owner deletion count. This is a structural bound on local universally extendible repairs, not a computational lower bound. For an UNSAT region no universal repair set exists; no finite q claimed. Cyclic regions need not be matchable even when they have universal repair sets.
