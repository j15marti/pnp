The three forms are precisely the three pair directions. Automatically false iff all three rows lie in W with beta=0. No nonlinear hull approximation is used. All tests by Gaussian elimination.
Let f be number of automatically satisfied owners; A all others including automatically false. Project each candidate into GF(2)^n/W and retain only nonzero rows for A. ## 3. B: sharp upper bound and equality structure (PROVED)
Define u~v iff e_u+e_v is in W. This is an equivalence relation; within any class of size s, beta fixes relative bits. All within-class pair spaces for disjoint classes together have dimension sum(s-1)<=q. Choose one forced opposite pair per automatically satisfied owner. Linearity guarantees distinct chosen pairs across owners. Each vertex has degree at most4 in chosen-pair graph because each original owner used once. In a relative class these edges cross its fixed relative-bit bipartition, so e_class<=min(floor(s^2/4),2s). For s=1 zero; for s=2..7 check floor(s^2/4)<(16/7)(s-1); for s>=8, 2s<=(16/7)(s-1), equality only s=8. Sum gives 7f<=16q, sharp.
Since every candidate row is even, quotient representative rank r<=n-1-q. For genuine n,m=4n/3,

Hence guard+independent-rep complete SAT certificate requires q>=ceil((7/9)(n/3+1)); strict certified improvement from d requires q>(7/9)(n/3+1-d). This is a bound on one certificate language, not on actual attainable improvement, adaptive algorithms or unrestricted deciders. In particular the prior rank-repair sufficient condition requires checking all surplus owners.
For q>0 equality 7f=16q forces each nonsingleton class to have eight vertices, four in each relative color, all 16 chosen opposite edges (K4,4), and W equal direct sum of their difference spaces. All eight vertices have chosen-pair degree4, hence all original incidences accounted for. No touched owner can have a third vertex in that class or in any other saturated class, since that would give an unaccounted incidence at that vertex. Thus every touched owner has two opposite variables of its class and its third outside. Each class is an unguarded universal-extension partial assignment (autarky) independent of outside bits. It is safe to set and delete, with stored actual bit values. Sharp example: GF(4) indexed disjoint A,B,C of size4, four classes s, triples (A_i,B_{i+s},C_{i+alpha*s}) with alpha primitive (multiplication 0,2,3,1 in bit basis). Every A-B pair occurs exactly once, all pairs linear, every partition perfect. Guard one 8-variable A/B class rank7 forces all16 original clauses.
