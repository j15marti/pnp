## 1. Exact tractability boundary in a declared selector model
Let disjoint nonempty groups of phase options have the requirement exactly one active option per group. Each option is a signed monomial with its own unguarded private slack variable. All other original variables occur only through these monomials. Each resource conflict is encoded by a fresh variable occurring positively in one block and negatively in the other. Thus every independent subset of the conflict graph is liftable: set shared variables consistently for active options, then falsify each inactive option's private literal. Conversely any simultaneously active conflict endpoints contradict a literal. All incidences and private variables can be checked directly in the explicit representation. Demand groups of size at least 3 have non-Horn positive clauses.

If every option consumes exactly one resource in a common capacity-one resource set, there is an exact polynomial matching quotient: construct group-resource bipartite incidence, match all groups, pick one option witnessing each edge, then lift using private slack. Hall deficiency certifies NO. More generally, if each option consumes one mandatory resource in A and zero or one resource in B (distinct sets), let E be the groups with at least one two-resource option. Enumerate one exact option for every group of E, reject conflicting chosen resources, and delete their A resources from the remaining one-resource matching graph. A matching saturating all remaining groups gives an exact witness. If d_g is the count of options in g, the branch count is product_{g in E} d_g; a uniform fixed bound sum log2(d_g)<=C log2(N) suffices for polynomial total work. Each branch, conflict check, matching, verification and reconstruction is charged. This is a sufficient class condition, not a necessary condition or a universal selector-acquisition theorem. No new group may enter E for free and no branch credit is reset.

Allowing each option two resources from separate sets A and B is NP-complete even with all private slack intact: reduce perfect 3-dimensional matching by letting groups be X, options be triples, and resource sets be Y,Z. Exactly one choice per group with no shared resource is precisely a perfect 3-dimensional matching. Use one distinct signed shared variable per resource-conflicting pair and one private variable per option; total construction O(t^2) incidences and O(t^2 log t) bits for t triples (plus labels). Given phases, the original lift is trivial and exact. The NP-completeness resides in *joint selection*, not reconstruction, and does not imply P!=NP. Pair conflicts form the union of two clique-partition families; each projection alone is a matching problem. Karp 1972, DOI 10.1007/978-1-4684-2001-2_9. This is a reduction in the declared monomial model, not a new universal native E/B recognition algorithm.

## 2. Growing scoped simultaneous refusal with modular escape
For even q>=4, take all triples (a,b,c) with a,b in Z/qZ and c=a+b mod q. Groups indexed by a; each resource set has q elements. Each one-resource projected matching is perfect, and all q^2 options have singleton weight 1/q. Each A and B resource marginal sums to 1. For each distinct pair of groups a,a', choose uniformly among compatible ordered choices (distinct b and distinct c). For every fixed b, exactly q-2 choices of b' survive: excluded b and b+a-a' are distinct. Thus weights 1/[q(q-2)] on compatible pairs have total 1, uniform group singleton marginals and zero support for all binary resource conflicts. This is an exact rational feasible packet for the complete group-pair marginal relaxation, including every group pair, not a claim about higher levels or native factor LP. Projection Hall and group-pair marginal tests cannot reject this family.

Yet any integral feasible choice must use each a,b,c exactly once. Write S=q(q-1)/2. Summing c-a-b=0 mod q would require S-2S=0 mod q, whereas S=q/2 mod q. Contradiction. This is a short exact modular conservation certificate; all listed triples can be checked directly. It is a classical even-order cyclic Latin-square transversal obstruction applied to our nonlinear phase interface, not a claim of a new Latin-square theorem. Matched YES neighbor: q=2m, add (q-1,m,q-1). Choose b=a for a<m, b=a+1 for m<=a<q-1, b=m for a=q-1; the first m phases produce all even c, the next m-1 produce odd c from 1 to q-3, the added triple supplies q-1. Both resource permutations verified, then reconstruct and check every original signed monomial.
