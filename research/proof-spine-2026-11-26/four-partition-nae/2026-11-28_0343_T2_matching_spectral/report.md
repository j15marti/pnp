## 2. Exact spectral/Gram lane
Let z_i=2t_i-1. Multiply the integer resource equations by 2 to obtain delta_c*z + (2(B_c-1)+sum_i delta_ci)=0. When each nonzero row has zero constant and exactly two coefficients +/-1, it is a signed edge relation z_v=s*z_u. Sign-propagation on the graph is the exact kernel test of its rational Gram matrix A^T A: each row is a square term in z^T A^T A z. On an inconsistent signed cycle, tagged paths yield an integer row combination equal to +/-2e_r. Replay each coefficient exactly from the original response rows; this proves 2z_r=0, impossible for a spin. Equivalently the square of the checked identity is 4z_r^2=0 while z_r^2=1. On consistent components one root sign freely determines all others; reconstruct and check every original option. No numerical eigenvalue, approximate PSD or free rational oracle. On the admitted signed-edge systems this gives a separate exact graph-kernel algorithm. General rows or nonhomogeneous constants not admitted here; return UNKNOWN for this spectral lane.

## 3. Infinite mixed family on which the combined selector is necessary relative to the named baseline tests
For m>=3, q=2m. Block i has groups 2i,2i+1 and A resources 2i,2i+1. For b=0,1 put options (2i,2i+b,2i+(b XOR twist_i)) and (2i+1,2i+(1 XOR b),2(i-1 mod m)+b). All twists zero except optionally block 0. Add forward-only (2i,2(i+1),2i) for 0<=i<m-1 and an extra (0,4,1). These connect the projection across blocks, but no perfect matching can use a forward edge: with diagonal matching every forward arc strictly increases block index and cannot participate in a permutation cycle. Remove m such options. Every block has exactly two states. Each C pair indexed i receives one bit from block i and one from block i+1; they must differ. Therefore t_i XOR t_{i+1}=1 XOR twist_i. XOR over the ring gives consistency iff (m mod2) XOR twist_0=0. All SAT orientations lift by exact matching; the NO parity contradiction is a cycle identity.

Toggle the three forward options (0,2,0), (2,4,2), (0,4,1) plus internal option (2,2,2). All G and A degrees change by even amounts, as does C2, while C0 and C1 flip.
