## Exact lemma: merge counts, not violations
Let F be any ordered signed CNF (including repeated occurrences), a a complete Boolean base word, and D_i pairwise disjoint sets of coordinates to toggle relative to a. Write c's exact true-literal count k_c(a)=sum_l 1[l(a)=true] and signed true-literal count h_c(a)=sum_l sign(l)1[l(a)=true], where sums are over occurrences. For each leaf D_i and each affected clause c retain the sparse integer pair (Delta k_c, Delta h_c). A flipped occurrence contributes +1 to Delta k if previously false and -1 if previously true; multiply by its literal sign for Delta h. Then
k_c(a XOR union D_i)=k_c(a)+sum_i Delta k_c(D_i),
h_c(a XOR union D_i)=h_c(a)+sum_i Delta h_c(D_i).
Proof: each occurrence's coordinate belongs to at most one leaf, so its change is counted exactly once. Thus sparse row-keyed integer pair addition is associative and reconstructs all k, k mod 3, and h mod 3 fields. Evaluate the nonlinear violation indicator 1[k=0] only after merging counts. For fixed base and disjoint deltas, one need not re-read all literals of a seam row to combine responses. For overlapping sets, normalize by symmetric difference of the original coordinate IDs first; otherwise an occurrence may be counted twice although two toggles cancel. If the proposals are assignments rather than toggles, disagreement on overlap must be explicitly resolved or refused before merging. The result is a point-response certificate, NOT an exact set of all feasible separator responses.
 
Let L be the number of literal occurrences, Q=sum_{x in union D_i} deg_occ(x), b the number of leaves, w=ceil(log2(L+1))+O(1). With an occurrence index built in O(L) word operations and sorted sparse row lists or deterministic balanced dictionaries, leaves need O(Q log(L+1)) word work (sorting or indexing), merge has depth ceil(log2 b) with O(b+Q log(b+1)) total node/entry visits in the whole tree using sorted merge, not merely in one path. Count arithmetic costs O(w) bits each; row IDs and coordinate IDs have O(log N) bits under ordinary explicit encoding. Including key sorting/comparisons gives a safe O((L+b+Q log(b+1)) polylog(N+b)) bit bound in a random-access implementation for a single batch with b and all declared records polynomial; an explicit tape simulation can use a polynomial overhead. A flat accumulator can be cheaper; balanced hierarchy helps span and sharing only when charged. Reconstruction of the complete table costs another O(L) word operations, or materialize just affected rows. Count index, base, leaf lists, intermediate dictionaries and all failed proposals in the actual run. With disjoint flips Q<=L, but the number of candidate batches may be exponential. No bound on all branches, joint support search, productive acquisition or UCAC potential follows from this lemma. Exact count merging does not refute a formula until a separately checked logical contradiction is acquired.
