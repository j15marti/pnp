## 2. Theorem: exact shared-variable signed monomial quotient
Let B_i be a finite consistent set of signed Boolean literals (no repeated underlying variable within a block), and M_i(x)=AND over B_i. Suppose each block has a variable appearing in no other block, and no constraint depends on x except through the M_i. Let a phase-level formula H(y) be any 2CNF, with y_i=M_i. Form a conflict edge i,j when opposite literals of a shared underlying variable occur in B_i and B_j. Then the exact existential phase image is:
  Q(y) = H(y) AND all (not y_i OR not y_j) for conflict edges.
Proof. If y_i=y_j=1, all corresponding signed literals must hold, which is impossible for an opposite pair. Conversely if Q(y) holds, set every variable occurring in an active block to its required bit; these requirements agree by the conflict clauses. For each inactive block choose one private variable and assign its literal false. This never interferes with any other block, or an active requirement. Assign remaining free variables arbitrarily. This lifts exactly the requested phase word. Thus quotient is bijunctive even on an arbitrary dense overlap graph, with no independent-block assumption. Standard 2SAT solves it and supplies a lift or complementary implication paths. Incidence size L, pair generation O(L^2) worst case, <=m^2 distinct pair clauses, poly bit size and reconstruction. If factor decomposition given and source checked, total module is polynomial in original explicit encoding. Blind discovery on all possible encodings NOT established; exact factor admission and source accounting remain necessary. This proves decision/support, not exact counts.

## 4. Guarded extension and precise failure boundary
For a consistent partial-assignment guard G, drop true pinned literals from each block; any false pinned literal disables its phase (unit y_i=0). Among nondisabled blocks let E be those with no remaining free private variable. These are exceptions, not automatic contradictions. For each exception i with w_i remaining literals, enumerate one of w_i+1 choices: require y_i=1, OR require y_i=0 and choose a specific remaining literal to pin false. If w_i=0 only the true choice exists. Reject incompatible accumulated pins; add all chosen phase units and newly disabled units, then apply exact conflict-quotient 2SAT to remaining active blocks. Each former exception is now either forced true or already disabled; all other nondisabled blocks still have private slack, because exceptional literals cannot contain a free private variable of another block. Apply the same lifting argument, enforcing all chosen units and pins. Conversely any source model chooses the true branch for every true exceptional phase and one false-literal witness for every false exceptional phase. This is exact and covers all solutions, with branch count at most product_i(1+w_i), each branch polynomial. Thus a paid bound sum_i log2(1+w_i) <= C log2 N is sufficient for a fixed polynomial aggregate procedure. This is effective exceptional width, not ordinary graph treewidth or a universal progress theorem. Branches and reconstruction must all count; no reset on guard changes. Random guessing branches has inverse-polynomial probability only if this product is polynomial and at least one productive branch exists; cannot use sampled non-detection as UNSAT.

The private-slack hypothesis is essential for unconditional quotient sufficiency. E.g. M_1=x, M_2=not x, and y_1=y_2=0 has a consistent pair-conflict relaxation but no original lift. More generally for any CNF C, take one monomial per clause consisting of negations of its literals, and force every phase zero. Exact shared lift is exactly SAT(C); even if each monomial initially gets a fresh private p_i, guard p_i=1 removes slack and recovers the same decision problem. Thus arbitrary slack-free shared monomial lift with phase units is NP-complete by direct reduction, not just a poor algorithm. This is not a proof that the UCAC algorithm reaches such guards or that another lane cannot solve them, and does not imply P!=NP.
