## 2. Universal guarded interface decision is coNP-complete (PROVED; conditional obstacle, not P!=NP)
For arbitrary authenticated native F, its forbidden predicate is D(z)=OR over original triples C of [all three variables of C are 0 OR all three are 1]. D is a width3 DNF with 2m terms. Make independent length-three paths for these terms. Each has private vertices x0,x1,x2,x3, private controls c0,c1,c2, three positive NAE triples (x_i,x_(i+1),c_i), colors 0,1,0. Use phase y_i=x_i xor (i mod2), pins y0=1,y3=0 (physical x0=x3=1). For term target bits t_i and corresponding original variable z_v, set physical control c_i=z_v xor t_i xor 1 xor (i mod2). This is implemented by equality/opposition guards tying each occurrence to first physical control of same original variable, no added abstract unguarded variables needed. NAE on edge excludes y_i=1,y_(i+1)=0 exactly if z_v=t_i, otherwise excludes reverse mismatch. With fixed controls, each edge is one implication. Path extension impossible iff all three implications forward: necessity propagation from pinned true to pinned false, sufficiency if one reversed edge choose y=1 before it, 0 after (all other endpoints equal or satisfy that reverse). Thus exact local NO predicate is one DNF term. Each path has distinct variables, max occurrence2 and proper partial coloring. Disjoint paths share only explicit affine control guards. Their conjunction extends for fixed z iff D(z)=0. Thus joint NO for all guard words iff original F UNSAT. Membership in coNP follows by polynomial verification of a guard word and a feasible assignment (or evaluation of exact local interfaces). Therefore even constant-size path interfaces plus equality/opposition and endpoint pins are coNP-complete to decide globally (universal negative coverage). No assumption P!=NP. General 2SAT-with-boundary tractability is not contradicted: each fixed boundary is easy. This is a polynomial reduction from the unrestricted native decision source; if a universal polynomial joint test were established, P=NP would follow. Our experiments restrict to independently certified NO inputs except minimal soundness control.
