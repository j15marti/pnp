## 2. Theorem CAP-COMPONENT (PROVED)
For genuine NAE4 F, fix ordered variables (a,b,c) per owner and L_i(x)=(x_a+x_b,x_a+x_c) over GF2. Let E=(GF2^2)^m, C=im L, H quotient E/C, E_S coordinate subspace for owner set S, T=all minus S. R_S=H({w in E_S: each S block nonzero}); actual attainable support, not span. Given target y, solve H|E_S r=y by Gaussian elimination (reject if impossible). Then y in R_S iff some r+L(u) in E_S has all S blocks nonzero, with L_T u=0. Thus u constant on each primal component of T, including isolated variables; let u_v=z_{comp(v)}. This equality of kernels follows immediately from the pair-difference equations of each T triple and transitive connectivity. For each S triple use signed NAE on (z_A,z_B+r_i1,z_C+r_i2), where A,B,C are actual component IDs, including repetitions. If one comp, all three fixed offsets either equal (contradiction) or not (tautology); if two comps, repeated component literals either opposite (tautology) or equal (single parity equation on distinct comps); if three, genuine signed NAE. Every assignment gives actual r+L(u) word, and every attained word has a preimage by quotient definition. For an explicit consistent affine guard x0+W use C=im L|W, r for the corrected target after offset substitution (C08-02), and constrain u=z lifted to physical IDs to belong to W. If r=L_S x for an actual reference x (zero outside S), then equivalent direct problem is find x+u satisfying S while preserving every T observation. If x already satisfies T, the lift is a complete source witness. H r=H L_T x, because H L x=0, so this target is actually attained by T's support, not a spurious hull query. All original owners and indices retained. No free query. General arbitrary target Gaussian construction polynomial; audit implements reference-x form without materializing H.

Forced-information closure: compute exact reachable 2-bit owner observations on current affine chart by projection. Remove tautologies, reject impossible factors, or impose a sole affine allowed fiber if attainable set is affine. On a rank-two plane with forbidden point attainable, remaining three words are not affine; branch on either of its two complementary coordinate equations. Each rank increase or removal reduces finite potential. Under explicit guard even 3-component owner can become rank-one/zero; do not treat it as unguarded. After exact projected guard and factor scopes (C02-02), independent factors split. If h residual rank-two owners after closure, branch at most twice per owner, each removed on its branch, with exact guard substitution; <=2^(h+1)-1 nodes. No increase of h under substitution on original owners. All other factors are affine or taut and handled by Gaussian elimination. This is a uniform polynomial algorithm if h<=K log2 N for fixed K, or if exact independent components have individually logarithmic h and paid total. Canonical RREF on fixed original phase coordinates and remaining original owner IDs permits sound cache sharing; no bound on distinct keys. A genuine additional nonlinear guard needs actual factors and its own cost; the theorem assumes affine guards or accounts for them separately.

## 3. Theorem ONE-PARTITION-CAP (PROVED; independent review pending)
For any genuine NAE4 F with n variables, uniformly compile a genuine positive linear four-partition G with 9n variables,12n clauses. Distinguished S is exactly one perfect partition of G; T other three consists of disjoint connected 9-variable affine-plane modules, each with an explicit known satisfying word x. Then F SAT iff H L_S x (zero extension) is in R_S. Target is genuinely in R_T. Also G SAT iff F SAT, even if T observation preservation is not required.

Construction: per source variable v create 9 physical variables indexed v,0..8. In T place the three nonhorizontal AG(2,3) parallel classes in each block (explicit AG in audit.js). In S put private third row (6,7,8) per block; also copy the six original perfect partitions in order (0,1,2,3,0,1) onto occurrence slots i=0..5, using one physical port per occurrence. Thus each S clause either is a third private row or contains three ports from distinct blocks. S partitions every physical variable once, all other partitions do also. S clauses disjoint, cross-block pairs never appear in T, internal private-row pairs appear only in removed horizontal class; T linear. Source authentication both directions. T has exactly n components because the retained classes connect all nine points of each block. Source G connectivity follows exactly source F connectivity. No new hardness restriction to connected sources asserted here; actual connected controls tested. Choose x=(000,111,001) in every block. Every transverse line meets both opposite monochromatic rows, so x satisfies T. Every private row satisfied, every external copied clause monochrome (slot i same across owner). Hence H L_S x is in R_T (proof section2). Component flip z_v preserves T; each copied clause becomes NAE(z_a,z_b,z_c), since all its ports have a common offset; private rows taut. Exact support query is thus the original F, with duplicate first two partitions harmlessly redundant. Constructive proof both directions by lift x XOR z blockwise and project from any preserving completion.

Independent direct satisfiability argument: for any 9-point block, if nine transverse AG clauses satisfied, every unordered pair belongs to exactly one line; if k horizontal rows mono then total equal pairs=9+3+2k >=16, so k>=2. If exactly two mono rows share color then at least18 equal pairs, contradict16. All three mono same color also impossible. Conversely two opposite mono rows satisfy all nine transverse clauses. Since the third row is itself constrained NAE in S, the first two must be mono opposite. In ANY satisfying G model, read phase z_v from its first row. All six external slots correspond to z_v or complement uniformly within their respective copied clause. Thus F SAT. Any F model extends by x XOR z. This additionally establishes that preserving the supplied T observations loses no YES instance of this compiler (not claimed for arbitrary G). Construction and verification O(poly(N)); can represent target implicitly via x or explicitly compute H and quotient word with Gaussian bit work, poly(N). NP membership by actual allowed words or complete preserved-observation witness. By authenticated DDD NP-completeness, CAP-COMPONENT membership is NP-complete even for an entire single partition S and explicit attainable counterpart target on these disjoint constant-size T modules. This is exact reduction, not an unconditional superpoly bound. No imported arithmetic result.

Consequences: naive universal cap classification/exact interface membership in P would resolve P=NP. Even acquiring every T solution locally, or a verified complete T word, cannot simply remove the joint compatibility issue. After component closure the compiler has exactly n phase vars and 4n/3 distinct nonaffine rank-two owners (2n incl duplicates), all positive NAE. Every local affine hull full, unary supports full; affine closure as defined above stalls. It is not a universal obstruction to other forced-information deductions or implicit representations. For connected F, full-set raw owner deficiency of G is 3n+1 (12n minus (9n-1)); quotient F still n/3+1. No transfer to bounded surplus and no bound on complete orientation DAG. This shows why a universal hereditary cap theorem cannot be proved merely from constant-size complement regions, an explicit compatible target, or easy individual partition satisfiability. Unlike arbitrary external guard hardness, target here is actually attained by T under native source constraints.
