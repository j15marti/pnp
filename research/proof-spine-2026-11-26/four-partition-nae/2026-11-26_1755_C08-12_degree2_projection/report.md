## A. Constructive exact elimination theorem (PROVED WITH SCOPE)
For all H,W as above, construct a graph with one vertex per owner. A free variable occurring twice gives one edge with its actual variable ID and two endpoint signs; a once-occurring free variable gives a stub. Ignore unused free variables. Parallel edges permitted; no loops because original clauses have distinct variables. For nonempty literal lists A,B and fresh x relative to A,B, exact identity:
exists x [NAE(A,x) AND NAE(B,not x)] iff NAE(A,B).
Proof: if both lists monochrome, x can satisfy both iff their colors are opposite. If either list mixed, select x for the other (or freely if both mixed). Thus forward and reverse valid even when A,B share other variables. If the two original x signs are equal, complement every literal in the second relation before gluing. Record the complement flag, owner IDs and variable ID.
In each connected component K, merge along any spanning tree of double-occurrence free edges. No free edge eliminated on that tree can appear elsewhere. A component with t owners has one NAE of t+2 literal positions after exactly t-1 merges. If a free stub remains, its single occurrence may be chosen opposite another literal. If a non-tree free edge remains, its two occurrences are either opposite, making the relation tautological, or equal, permitting choosing both opposite any other literal. There is at least one other position because t+2>=3. Set all other uneliminated free variables arbitrarily first. Hence a component with a stub or cycle gives the full projected relation. Otherwise all remaining literals are protected; retain this one signed NAE. Repeated equal literals collapse; opposite signs on the same protected ID make the factor tautological. A one-distinct-variable factor is false. Empty H gives unrestricted support. Reconstruct for any permitted boundary word by assigning remaining free variables as above and reversing glues: test the two possible values of each eliminated variable against its two stored factors. Each step succeeds by exact identity. Verify originals. No enumeration of boundary words is required. This proves an exact existential projection for degree-two free variables into a conjunction of signed NAEs of total literal length O(|H|), even if there are exponentially many attained boundary words.

## C. Adversarial native two-partition theorem
In any genuine positive linear NAE4, take two original partitions. Their owner graph G is simple cubic bipartite: vertices are owners, every physical variable is an edge joining its two owners. Choose free W (subset of edges). Each connected component of (V(G),W) yields full response iff its vertex set induces a cycle in G. If selected edges contain a cycle, A applies. If selected edges form a tree, all omitted edges with both endpoints in the component are repeated protected variables. Bipartiteness makes their endpoints at odd tree distance, hence required bad values opposite under positive signs; B proves absorption. If no such internal omitted edge, every protected variable occurs at most once in this tree, so actual bad pins exist. A singleton with no loop has no cycle and fails universal extension. If any component fails, choose one consistent bad pattern on its pins and extend arbitrarily to others: shared fixed values cannot repair that component. Conversely if all components full, each extends the SAME protected word independently (free variables disjoint within this region). This concerns universal repair of one two-color region, not the conjunction with the other two colors.
Let nu_c(G) denote maximum number of vertex-disjoint simple cycles. Exact minimum universal repair count is
q(G)=|V(G)|-nu_c(G).
Lower bound: each full-response free component contains an actual cycle in G, so count components <=nu_c(G), and selected edges >=|V(G)|-component count. Upper: choose maximum cycle packing, seed each cycle's vertices as distinct group, extend disjoint connected groups by multi-source BFS to cover the graph; every connected component of cubic G contains at least one cycle, so maximal packing hits every connected component. Choose a spanning tree inside each group; W consists of those tree edges. Every group contains the original cycle in its induced G, so full response. This is an exact structural characterization, NOT an algorithm for maximum cycle packing. Any supplied packing has polynomially checkable repair certificate, including one cycle per connected component. For girth >=g, q(G)>=|V(G)|-floor(|V(G)|/g).
