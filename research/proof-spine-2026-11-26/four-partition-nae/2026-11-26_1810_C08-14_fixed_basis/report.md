## 2. A: Fixed owner basis for every solution (PROVED)
For each owner i on three distinct positive variable IDs, form three candidate graphic edges. Their GF2 row span U_i is the 2-dimensional variable difference space. Across any set S of owners, graphic rank r(S)=n-c(S), where c(S) counts connected components incl isolated variables. Select edges independent in graphic matroid and at most one per owner (partition matroid). Edmonds' matroid-intersection algorithm computes maximum such forest in polynomial time. Rado criterion for a specified B: independent reps exist iff rank(sum U_i over S)>=|S| for every S subset B. On any assignment satisfying B, each owner has exactly two opposite pairs; their difference rows span exactly U_i, hence Rado inequalities unchanged for every subset. Therefore the SAME previously chosen owner set B has independent representatives all consistent with that assignment. No target needed to acquire B. Acquiring the compatible representatives given x is polynomial, but acquiring x is not free. More generally after substituting an explicit consistent affine guard x=a+Lz, all homogeneous pair differences retain the sum identity; available opposite pairs for an actual model still span the projected U_i. Rado on actual projected rows proves same fixed-independent-owner-basis property; full rank is not automatic in arbitrary guarded residuals. Re-acquire basis under guard if needed, retain every offset. General guarded implementation not executed.

Rank full on connected raw NAE4: partition vertices into k>=2 nonempty blocks. For a block of v variables, boundary incidence count b_j in partition j = v-3*(number of whole clauses in block). Each b_j>=0 and congruent to v modulo3. Connectivity gives positive total boundary incidence, hence >=3 (if v mod3=1 >=4, if2 >=8). Summing over blocks, each crossing owner contributes exactly 3 incidences, so at least k crossing owners. Thus hypergraph partition-connected even after deleting any one specified owner. Hypergraphic rank formula min_partition(n-k+#crossing owners) is n-1; alternatively matroid intersection min_S(r(S)+m-|S|) gives same. There is an acquired common owner basis B of size n-1, with D=m-n+1=n/3+1 other owners. Can avoid any prescribed one owner. A tree with any selected edge from each B owner gives proper two-coloring of the tree and satisfies every B owner. Conversely every assignment satisfying B has such a spanning tree, unique coloring up to global complement for each tree. Original F SAT iff some tree with SAME B has all D extra clauses satisfied. A fixed B is not a fixed tree or matching and no polynomial enumeration asserted. If union of three supplied partitions is connected, same boundary argument with three colors allows B within that union, leaving one complete partition plus one owner as extra; not a universal connected-union promise. The partition-connected theorem is special source structure, hypergraphic matroids/Rado are classical; no novelty priority claim.

## 3. B: Exact pivot coordinate chart and polynomial observation repair (PROVED)
Given an arbitrary acquired tree T indexed by B, anchor one root0 and use y_i=x_u XOR x_v for tree edge e_i=(u,v). This is a bijective linear coordinate system on relative colorings. For third vertex w of owner i, exactly one of u,v shares its component in T-e_i. Choose the tree path P_i from that endpoint to w; it excludes i. Owner is equivalent to y_i OR XOR_{j in P_i} y_j. For each extra owner with triple a,b,c, retain OR of XOR along a-b and a-c paths. All original IDs preserved, exact both directions and root-to-leaf lift. Signed case uses actual offsets; no sign simplification without certified equations. Initial all y=1 gives a witness for B, not necessarily F.
Given ANY coloring x satisfying B and q independent prescribed even-weight binary linear observations with consistent target values, choose a compatible colorful tree T by Section2. In its tree coordinates the q rows have rank q. Gaussian pivot on q coordinate columns; hold every other y at its current value1, solve q pivot bits to realize target observations. Every basis owner outside those q remains satisfied. Thus any prescribed relative observation word of rank q can be acquired by releasing at most q basis owners, without searching owner bases. All other actual owners must still be checked; they can become violated. If observations are actual synchronization equations, keep them all, not their marginals. Existing guard must also be conjoined and charged; the unguarded q bound is not automatic when additional equations are held fixed.
