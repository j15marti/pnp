## Lemma A: inclusion-minimal conflict guards

Let F be a fixed explicit CNF database, G a consistent set of assigned literals, and UP(F,G) contradictory. Scan literals of G once; remove one if UP still contradicts. At all times contradiction is invariant. If removal of l fails when tested on H, then the final H' minus l is a subset of H minus l. Monotonicity of UP conflict under extra assumptions implies UP cannot conflict on that smaller set. Thus final guard is inclusion-minimal relative to the database at that moment, not minimum-cardinality or semantically minimal. Its negation is RUP, verified by a separate propagation implementation. No guard loss, no oracle. For d initial assumptions, at most d additional probes. The clause is reusable at the current database root; after a gauge fixing it remains conditional on that internal gauge until the global complement discharge. Root UP reexecuted after every addition. Learned conflict clause is new for a path generated by propagating before each decision: otherwise an existing clause would have forced a decision's opposite or produced an earlier conflict. General implementations should explicitly check novelty.

## Lemma B: adaptive width credit and its precise barrier

For a fixed chart of r variables and fixed constant w, the complete non-tautological clause vocabulary of width <=w has V=sum_{i=0}^w 2^i binom(r,i) members. Distinct certified additions consume one numeric credit V-|database intersect vocabulary|. Exhaustive RUP saturation terminates after <=V+1 passes; each pass <=V polynomial UP calls on an explicitly bounded database. It finds the empty clause if and only if a RUP-only refutation with additions of width <=w exists in that chart (by monotonicity and induction on derivation). Arbitrary adaptive guard variable choices are allowed; no common basis needed when w is constant. If w=O(log N), V can instead be N^{O(log N)}; a short *attained* trace is not a uniform acquisition bound. Our particular heuristic has 1000 rounds, d=floor(log2 N), a 700000 literal visit cap; cap exhaustion UNKNOWN. General polynomial cap K=N^a on rounds, d=O(log N) and exact UP scanning O(r*database literal count) gives polynomial aggregate time including path scoring, trimming, replay, scans, storage and all branches actually visited; it does not ensure an answer.

Barrier: a fixed-CNF RUP derivation with each learned clause width <=w and input max width k can be transformed into a resolution-with-weakening derivation of width <=w+max(k,w). For a RUP step C, run UP under all literals of C falsified; for each implied literal l derive C OR l by resolving its reason with earlier C OR l_i for the propagated falsifiers (initial assumption falsifiers already occur in C). Each intermediate clause is contained in C union that reason; weaken at the end if needed. Resolve a conflicting reason similarly to derive C. Repeat for every step. Width bound follows, including the empty clause. This does not bound proof size below; it excludes even arbitrarily long bounded-width RUP traces when a fixed-source resolution width lower bound exceeds the bound. Ben-Sasson/Wigderson JACM 2001 Theorem 4.4 gives linear width for bounded-degree expander Tseitin CNF with odd charge. Hence for this original CNF, any w=O(log N) RUP-only policy is eventually insufficient. This is a restricted proof-system obstruction, not a native E/B lower bound: exact affine recovery and GE refute Tseitin in polynomial time. The guard+rank hybrid must be capable of changing representation. This is a concrete example where cooperative coverage is necessary but not yet sufficient.
