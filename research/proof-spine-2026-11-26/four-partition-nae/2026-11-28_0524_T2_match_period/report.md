## 1. Exact polynomial decision module on an explicitly acquired matching-syndrome chart
Input: balanced bipartite graph with m left and m right vertices. For each edge ij an explicit nonempty response set D_ij subset F2^r. Choose a perfect matching and one response from each selected edge; require xor target b. Encoding length L includes all response records and coordinates. Native use requires a paid exact equivalence/lift adapter of size polynomial in original N.

For each edge, test whether a perfect matching containing it exists by removing its two endpoints and finding a perfect matching in the remainder. Delete unsupported edges; their deletion preserves all solutions, and every matching of surviving graph is a matching of the original. If there is no perfect matching, a Hall witness refutes the chart. Connected components of the supported graph are independent. A forced-edge component admits one matching; a connected degree-two component is an even cycle and admits exactly two alternating perfect matchings. All these recognition steps are polynomial. The implementation here handles only forced edges and K2,2, a narrower class than the theorem.

More generally, suppose each admitted edge response dictionary is an affine coset a_e+H_e (verify centered rank and exact distinct cardinality 2^rank). For a fixed matching M in a component, its attainable response set equals a_M+H_M, where a_M=xor a_e and H_M=sum H_e. Compute by tagged GE, no explicit Minkowski sum expansion. For a cycle's two matchings M0 and M1, if H_M0=H_M1=H, their union is exactly a_M0+(H+span(a_M0+a_M1)) over F2. Proof: the coefficient of the difference is either zero or one; if it is in H the cosets coincide. Equal subspace is checked by mutual basis containment. Lift by choosing the corresponding matching and solving its tagged edge-basis equation; use original dictionary records as witnesses. Forced-edge cosets are already affine. For small components with arbitrary explicit dictionaries, alternatively enumerate all local matching choices and response sums within a fixed polynomial cap and test whether the exact resulting set is affine. A refusal is UNKNOWN, not NO.

Thus for this recognized class the global exact sum is affine; tagged GE decides it and reconstructs a perfect matching and local responses. Proof of NO is a checked left-kernel linear functional separating the target from the sum of affine spaces. Polynomial discovery: at most |E|+1 bipartite matching runs, each polynomial; all edge coset tests, two sums of subspaces per component, mutual containment, final tagged GE, lookup and checking polynomial in L and r. Simple explicit forced-edge/K2,2 implementation can enumerate O(L^2) combinations, and verify periods with polynomial membership loops. With L<=N^a and fixed a, including source adapter, all of this is polynomial in N; storage and cumulative memory are bounded by products of these polynomials. Not a proof of the chart acquisition promise on arbitrary E/B.

This uses the matching support filter of Regin (1994) and the peer T1 deletion/syndrome work; the cycle equal-period synthesis is the specific constructive sufficient condition. It is not claimed to be a new general matching theorem.

## 4. Exact native occurrence chart and period quotient, distinct from peer conflict-block chart
For every distinct local B support after equality/transport, give each shared carrier occurrence its own copy; connect nonfirst copies to the first by independent XOR-equality coordinates. Each local satisfying word contributes its endpoint bits to these coordinates. The xor of all selected responses is zero iff copies agree; identical duplicate B tables can be removed with exact owner list. Therefore the chart is exact with polynomial local dictionary acquisition (<=16 words per B row); witnesses lift by choosing consistent carrier bits and applying stored signs to all original ports. Dedup of equal syndrome values is safe since all global coupling is included. A local translation period h is accepted only after verifying S_i+h=S_i on the entire centered explicit dictionary. H=sum H_i, where H_i are period groups. Quotient all dictionaries and centered target by H. Any quotient solution has discrepancy in H, decompose it via tagged GE into local periods h_i, shift each representative by h_i, look up a valid local word, then reconstruct. Conversely an original solution projects. This is the known exact peer period machinery applied to a simple native occurrence chart, not novel universal acquisition.

For a fixed cut let A=sum-side spans, B=complement-side spans, H subset A+B. Exact cut loss:
lambda_before-lambda_after = dim(H intersect A)+dim(H intersect B)-dim H.
Since H is generated by owner-local periods, H=(H intersect A)+(H intersect B), so loss=dim(H intersect A intersect B). Proof: dim pi(A)=dim A-dim(A intersect H), similarly B and A+B; dimension identity. This is the cut-specific test; ambient rank loss alone is not enough. For a nontrivial cut through a connected component of the copy-equality incidence graph, local all-bit-complement periods generate a common nonzero crossing-edge vector (sum periods on each side within that component), yielding at least one cut loss if every involved block has that period. No universal logarithmic width follows.
