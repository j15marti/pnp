## 2. Hall + directed-cycle constructive proof

A mixed-sign variable with p positive and q negative positions (p,q>=1,p+q<=3) is split into xp and xn, all literals now positive. Append NAE with 3-p copies xp and p copies xn. This is exactly xp!=xn, xp occurs p+3-p=3 times, xn q+p<=3. Pure negative variables rename by complement. For any subset of clauses, 3|S| positions with <=3 per variable implies >=|S| distinct variables. Hall matching gives each clause a distinct representative. Build arcs rep -> all other distinct variables of that clause, no loops, deduplicate parallel arcs. Unrepresented variables have no outgoing arcs. Necessity: in a satisfying coloring each rep has an opposite-colored outneighbor. Any sink SCC entirely represented then has a selected successor at every node inside it, hence a simple even directed cycle. Sufficiency: in each represented sink SCC select an even simple directed cycle; any unrepresented sink SCC is singleton unrepresented root. Every vertex has directed path to a chosen cycle or root. For representatives not on cycles, choose an arc decreasing reverse BFS distance. Chosen functional graph consists of rooted trees or trees feeding even cycles; 2-color it.
