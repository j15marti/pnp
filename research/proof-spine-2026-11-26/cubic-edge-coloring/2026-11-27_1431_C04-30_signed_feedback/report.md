## Scoped theorem and genuine hybrid
Let U(a) be #violated clauses of a fixed canonical non-tautological CNF; t_C(a) true literal count. Gain(v)=#violated incident clauses repaired - #clauses whose only true literal is on v. Score exactly equals U(a)-U(a^v). Strict gain >0 gives at most m flips per fixed database, not a decision guarantee. In exhaustive DPLL without learning/shared search state, fixed variable heuristic and UP dependent only on partial assignment, choosing branch polarity only permutes sibling traversal order on UNSAT. Induction on nodes gives same unordered tree and same total discovery work in an uncapped completed run; no improvement from phase-only guidance (verification ordering can differ). Does not apply to CDCL, variable heuristic changes, caching, SAT early exit, or cap-dependent search.
At local minimum, for violated clause C and literal l in C, if flipping l breaks a clause D with unique true literal -l, the exact resolvent R=(C minus l) union (D minus -l) is violated by both a and a with pivot flipped. Thus R is a certified obstruction independent of pivot, and every remaining literal initially false. Adding R cannot improve that pivot's immediate gain; it may create a positive gain on another variable. Enumerate only such blocking pairs at plateau, not indiscriminate resolution, fixed 4 rounds and same 12000 pair cap. Preserve all parent/pivot IDs. Recompute scoring each round, compare original objective as well as augmented (different clause sets).
