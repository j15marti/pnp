2. Prime factor normalization: replace each vertex with a triangle with three external ports. Three-edge parity forces rainbow, and every rainbow extends (each internal triangle edge uses the third color of its endpoints' external edges). Repeatedly replace a cycle vertex with such a triangle; route the two old cycle edges through the new three-vertex path and the third old edge to its middle. Each expansion adds 2 vertices and preserves all original external port relations. For fixed odd prime p, each block has p vertices and a spanning p-cycle, with exactly 3 external ports. The distinguished cycles cover the whole graph and complement is a perfect matching. Projection contracts blocks; lifting extends triangle replacements. For p=5 or 7 this is a linear-size exact reduction from arbitrary cubic edge-coloring, so the promised prime 2-factor class is NP-complete. Not the same as connected six-port regional ring normalization; actual oddness of a minimum 2-factor need not equal the distinguished factor.

3. Exact Heawood-type ternary adapter. Each cubic vertex v has ordered ports 0,1,2. All permutations of F3 are exactly affine bijections c_v(i)=a_v i+b_v, a_v nonzero, b_v arbitrary. For directed edge uv joining ports i,j, enforce b_v-b_u=i a_u-j a_v. Along any spanning forest, choose b_root=0 (unrestricted case) and propagate b; the non-tree edges require exactly fundamental cycle equations A a=0. Row coefficient at a vertex is outgoing port minus incoming port, ±1. Conversely if all a_v nonzero and equations hold, forest reconstruction gives a valid original coloring. A has O(n) rows, n columns; encoded bit cost polynomial. Arbitrary pinned edge colors can instead be retained as affine equations in a,b, or after tree elimination with root offsets; no claim that tested homogeneous closure handles all guarded cases. This is an independently derived version of Heawood's known planar spin representation, using all fundamental cycles instead of faces; no novelty assertion. Repeating a cycle p times just multiplies its equation by p mod3; p=5,7 redundant, p=3 loses that equation. For simple cycle length 3,5,7, after absorbing coefficients into signs, number of + signs is respectively 0 or 3, 1 or 4, 2 or 5.

4. Signed ternary closure theorem. Maintain homogeneous row space R. Let L_i be coordinate linear form on ker R (nullspace basis). If L_i=0, refute. If L_i,L_j nonproportional and L_k=λ(L_i+s L_j), λ,s nonzero, then every full-support vector has a_i+s a_j !=0. Over F3 this means a_i=s a_j. Insert this equality and recompute nullspace; rank increases because L_i,L_j independent. Repeat. Each step preserves exactly full-support solutions, and <=n rank increases. Find candidates via canonical projective normalization of n coordinate forms, deterministic dictionary/sorted lookup of L_i±L_j; O(n^3) field operations per single-row round plus lookup/index overhead, O(n^4 log n) conservative bit-index bound with standard array operations, O(n^2) field storage, polynomial TM simulation. Batch implementation adds all sound equalities at once, higher polynomial overhead. Audit may recompute forms to verify each addition. No counting oracle. If closure stalls return UNKNOWN. Scan all pairs i,j with two guards a_i=±a_j; if both branches refute, source refuted. At most O(n^2) pairs, 2 branches each, so one split scan adds polynomial factor. Fixed depth d with all pair choices can be bounded by n^{O(d)}; logarithmic depth does not automatically give polynomial acquisition. Zero-coordinate certificate sound on YES as well as NO.
