## Exact four-cut cap theorem
Partition V into two connected shores of an actual 4-edge cut; keep its four labeled port ends in each shore. Local colorings restrict, by parity, to the four equality patterns 0000,0011,0101,0110 up to a simultaneous color permutation. Proof: each color forms a perfect matching in a proper coloring, so its cut count equals shore order mod2, which is even by the degree sum. Write 0 for monochromatic type and i=1,2,3 for three pair partitions. Each nonempty type set contains at least two types: for a monochromatic word, choose that color and a second, swap one alternating boundary-to-boundary chain; for a two-pair word use its two boundary colors and swap one chain between two of the four endpoints. Either operation changes the equality type. This is the known Chladny-Skoviera colour-open multipole classification (Factorisation of Snarks, EJC 17 R32, 2010, Lemma 2.1 and section 3, Propositions 3.1-3.5).

For pairing i define E_i cap by joining the two pairs of semiedges directly into two new edges. Its admissible boundary types are precisely {0,i}. Define D_i by joining each pair to a new cubic vertex and joining the two new vertices with an edge. Its admissible types are exactly the two remaining pair partitions: each port pair must have distinct colors; the third missing color is the same at both new vertices because parity gives precisely two boundary colors. Conversely every such word extends. A repeated endpoint can create a loop in E_i, which is correctly uncolorable; parallel edges retain distinct IDs. The reverse map deletes cap edges/new vertices and restores the four semiedges. On unguarded source, exact gluing iff the two type sets intersect, since a permutation aligns actual color labels.
Corollary: G is NO iff for some i, one shore has NO E_i capped graph and one (possibly same) shore has NO D_i capped graph. Sufficiency: every boundary type belongs to exactly one of the two classes. Necessity: if either shore type set empty, both caps on that shore fail. Otherwise disjoint nonempty type sets have at least two elements each and therefore are complementary two-element sets; one is {0,i}, the other its complement. This is a constructive negative-certificate adapter using ordinary edge coloring/even-complement PM on smaller capped graphs, not free access to those decisions. For opposite-shore certificates child sizes are a and b+2, and potential n-2 is additive: (a-2)+(b+2-2)=n-2. With strictly shrinking steps, internal size >=4, polynomial-size certificate tree (O(n^2) nodes from per-level potential and depth n), but certificate discovery is not implied. Same-shore pair can duplicate large shore; no additive claim there.
