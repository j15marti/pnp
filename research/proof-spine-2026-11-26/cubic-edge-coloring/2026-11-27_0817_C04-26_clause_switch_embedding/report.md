# C04-26 | Faithful CNF embedding in guarded binary matching switches
2026-11-27 Pacific. PROVED WITH SCOPE (author proof, finite native replay; independent mathematical review pending). P vs NP OPEN.

## Claim and source
Arbitrary explicit simple cubic G remains the primary decision source (Holyer). This result concerns its forbidden-edge guarded residual language, not a WLOG transformation of arbitrary unguarded inputs. Given G and allowed edge set S, ask whether there is a perfect matching M subset S with even complementary cycles. Even when S is a disjoint union of even cycles and isolated K2 edges, this language is NP-complete. Stronger exact statement: for every CNF with clauses of at least three distinct variables, each appearing at least twice, construct such G,S in polynomial time with one matching switch per variable, a bijection between assignments and admissible ordinary PMs, and exactly twice the number of false clauses as odd complement components. Clause duplicates and usual 3SAT padding establish the source promise without loss of NP-hardness. No assertion of novelty priority. Falsifiers: extra/missing PM, wrong literal polarity, unintended odd cycle on satisfying word, partial circuit on a pin not falsifying a clause. All refutations retain original edge IDs and guard.

## Construction (constructive track A)
For variable v with d>=2 occurrences, create cycle C_(6d), with successive occurrence blocks 0,...,5 indexed relative to that block. Allow every cycle edge in M. Add forbidden chord 0--5 in each block; it is distinct from cycle edges because d>=2. In complement choice A (z=0), retain cycle pairs (0,1),(2,3),(4,5) within each block. The chord gives two open paths (1,4) of length 3 and (2,3) of length 1. In complement choice B (z=1), retain (1,2),(3,4),(5,next0). This yields open paths (1,2),(3,4) of length 1, and the chord/seam edges form a closed even circuit of length 2d. The complementary PM option is respectively the other alternating matching. Each occurrence has four exposed endpoints, each path has odd length. For positive literal designate (L0,R0,L1,R1)=(1,4,2,3); for negative designate (1,2,4,3). Then false pairs L0--R0 and L1--R1 (straight), true pairs L0--L1 and R0--R1 (reflect). All labels are actual source vertices.

For each clause of length ell, connect R_h of occurrence p to L_h of occurrence p+1 modulo ell for each h=0,1 by forbidden wires. At one seam replace both wires by paths of length two, through distinct new vertices u0,u1, and make u0--u1 an allowed K2 matching edge. All other wires are direct. These are the only edges. Each vertex has degree 3, no loops/parallel edges since clauses have distinct variables, d>=2, ell>=3, and each occurrence owns its ports. The allowed graph consists exactly of the even variable cycles and one K2 per clause. Every admissible PM uses the K2s and one of two matchings per variable, with all cycle edges supported and avoidable, K2s forced. Thus the initial ordinary matching closure is exact and inert except for K2s.

## Parity transport proof (global track B)
For any assignment, each clause's two wire rings are insulated from other clauses in the complement after variable path contraction. Each untrue literal continues along its own ring, each true literal reflects into the other ring at each side. If all literals are false, two cycles remain, each with ell odd-length occurrence paths and ell wire paths, exactly one of the latter even. Each total length is odd (2ell-1 mod 2). If some literal is true, each interval between consecutive true positions (cyclically, including the single-true case) forms one cycle traversing both copies of that interval, closed by two reflecting paths. Corresponding paths and wires in the copies have equal parity, and both reflecting paths have odd parity; total length is even. These exhaust the complement, aside from the even internal seam circuits. Therefore #odd components = 2*#false clauses exactly, even when a satisfying word has unequal internal path lengths across copies. Conversely any admissible PM maps to an assignment; alternate remaining edges on each even complement cycle for the coloring. No assumption about the unguarded coloring of G. Graph has n=6L+2m, L total literal occurrences, m clauses, N=n+1+(3n/2)(2 ceil(log2 n)+1) under unary n and sorted endpoint+allowed-bit encoding. Construction, witness verification, bit indexing, and decoding polynomial in source length. NP membership immediate.

## Exact negative-clause extraction and barrier (adversarial track C)
For partial pin a on switch variables, form H(a) from all forbidden edges plus the complement cycle edges fixed by pins (forced K2s never enter). H is exactly the intersection of complements across all ordinary PM extensions. Every full extension has degree two, so any odd cycle in H is a whole component in every extension. By the parity proof that cycle belongs to a particular clause whose literal paths are straight; if any literal of that clause is unpinned one can set it true, eliminating that odd component, contradiction. Conversely a fully pinned false clause contributes both fixed odd cycles. Hence H(a) nonbipartite iff a falsifies at least one entire original clause. This is an exact semantics transfer, not an analogy. In particular for any fixed k>=2 take all 2^(k+1) clauses on k+1 variables, one excluding each assignment. Result is guarded NO, all width<=k partial odd-cycle probes pass; no learned clauses, no pins, no productive repeat of this exact rule. Universal fixed-width raw odd-cycle detection FALSIFIED, not all-decider lower bound. This family is easy by full local enumeration (2^(k+1) already polynomial in its encoded size); no claim of defeating all earlier closure/portfolio rules. For ordinary bounded 3-CNF, width3 recovers original clauses, so the remaining joint satisfiability problem retains NP-hardness; extracting clauses is not deciding their conjunction.

## Genuine hybrid: matching -> native clause -> affine parity
Acquire native allowed cycle components by scanning the actual source; enumerate all pin windows of fixed width k. For each I, record excluded words only from H nonbipartite, with source odd-cycle trace. If all 2^|I| excluded, NO. If every word of one parity is excluded, import XOR equation of opposite parity on I. Sum contradictory parity equations by GF2 Gaussian elimination to refute; retain XOR provenance to the learned rows. Can repeat after new guards, but this run had no new individual pins, and did not execute arbitrary higher-order forced closure. On Tseitin CNF of any simple cubic base with odd total charge, every vertex has four violating triples, so width3 native probes supply its parity row; their sum is 0=1. This gives a scalable polynomial refutation of a guarded family with exponentially many ordinary PMs. No native hard unguarded snark claimed. For even charge minimal control, no false rejection. This changes representation of matching factors into a certified affine system; no claim generic 3CNF is affine.
