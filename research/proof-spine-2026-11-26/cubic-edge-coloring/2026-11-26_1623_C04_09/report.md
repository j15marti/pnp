## A. Exact context union at any fixed width
Let U_k be the finite set of length-k nonzero-color boundary words satisfying the parity lemma, modulo global color permutation. Let F_k be the family of distinct nonempty actual support subsets of U_k of finite cubic k-poles (free wires, disconnected allowed). It is finite, with |F_k|<=2^|U_k|-1. For each S in F_k choose a minimum-order finite representative R_S with precisely that support (existence by well ordering on vertex counts). Ignore colorable closed components. Label ports. For every fixed K, put L=max order of these representatives for 2<=k<=K, q=max |F_k|. Both finite constants; this is NOT a supplied explicit cap catalog or computable bound as a function of variable K.

For any actual support S, including empty, define Q(S)=union of all T in F_k with S intersect T empty. Then for every actual outside T, including empty,
 S intersect T empty iff T subset Q(S).
Proof: forward T occurs in the union if nonempty; reverse Q(S) disjoint S by construction. Thus equality of Q gives exact contextual decision equivalence. This generalizes the five-port cycle signature without requiring a cycle characterization. It is an exact semantic theorem, not an affine-hull approximation. Full support may differ. To acquire Q(S_A) for a smaller actual side A, close it against every R_T and use the NO answers to OR the corresponding support masks. A query with exact YES means intersection nonempty. If all NO then S_A empty (otherwise its own representative gives YES). If not, compare acquired Q to precomputed Q(R_S) and choose a representative with that Q. There is one since S_A actually occurs in F_k. This consumes at most q smaller-side recursive DECISION queries and one large-side query B glued to the chosen cap. It works in both directions by the displayed equivalence. The finite table may be hardwired in a SINGLE deterministic machine for any one fixed K, independent of N and input; this is not length-dependent advice. Its existence follows without any SAT oracle, but we have NOT effectively constructed the universal six-port table, so do not advertise an executable implementation of the general theorem. An implementation with a complete supplied catalog uses only recursive queries and finite table lookup. The nonconstructive finite constants are an explicit limitation. In particular enumeration of small caps alone does not certify completeness.

## B. Global algebra and tariff

 q(s+L)^c+(n-s+L)^c <= n^c-1.
This pays all unsuccessful exact queries, branches and recursion nodes; no free access to decisions on arbitrary inputs.
