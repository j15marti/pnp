## Exact theorem and constructive acquisition
For fixed positive guard S, maintain P (edges required in every good extension of S) and X (edges excluded from every good extension). If H=(V,X) is nonbipartite, refute S. Otherwise compute component labels and a bipartition c on each component. For any original edge uv whose endpoints lie in the SAME component and have c(u)=c(v), force uv into P: an even-length simple path of X joins u,v; if uv also belonged to the complement, it would form an odd cycle. Equivalently every bipartition of an actual even complement restricts to each X component up to a global flip. Opposite shores and different components are NOT forced. Let Q be the complete acquired set of these edges. If any already certified forbidden guard T subset P union Q, refute S; if no ordinary perfect matching includes P union Q and avoids X, refute S. The latter check deletes endpoints of disjoint required edges and forbidden edges, then uses Edmonds matching. Reject intersecting/incompatible required edges directly. These are sound negative certificates on all YES and NO cubic inputs; ordinary matching feasibility alone is never YES.

C04-17 exclusion acquisition: D(T) for |T|<=2 means no good matching contains T. For each S not banned, include in X every e whose ordinary extension S+e is infeasible or contains any already banned T. Include unconditional X0 and P0 from exact initial include/avoid checks. Star/odd-cycle rule refutes S as before. New lite hybrid computes Q from X, tests forbidden subsets of P union Q, then jointly tests PM(P union Q, X). It inserts only the guard S when refuted, not an unguarded parity fact. Fixed point repeats until no new ban; any newly banned singletons are incorporated as exclusions into X on subsequent scans. More expensive full conditional support/avoidance reclosure may add all e where P+e cannot be matched avoiding X (or contains banned subset), recomputing parity; tested heavy lane includes support reclosure, not full avoidability after each import. Sound monotone invariant by induction; each local productive step increases P or X, each global productive scan increases D. No assertion of completeness.

## Complementary exact phase quotient (symbolic, not executed)
For any bipartite X, choose one flip bit per component (including isolated vertices). For each phase assignment, let Q(phi) be all original edges whose endpoints have equal resulting labels. There is a good matching respecting P,X iff there exists phi with ordinary PM(P union Q(phi), X) feasible. Necessity: take bipartition of even complement, restrict to X components; same-label original edges must lie in M. Sufficiency: all edges outside selected PM cross labels, so complement bipartite and 2-regular. One global flip per original connected component redundant. Enumerate 2^q phases for q=number X components minus number G components, with poly work per phase; exact decision for this guard under paid logarithmic q. It is not a universal bound on q, and phase coupling across components cannot be ignored. This independently reconstructs the positive-edge inference by universal quantification over phase flips.
