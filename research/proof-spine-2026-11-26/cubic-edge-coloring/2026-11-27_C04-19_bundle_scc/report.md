## Three mathematical tracks and integration
A matching route: C04-18 forces every original edge within same X component and same shore into P, checks previously banned subsets and ordinary joint PM(P,X).
B Boolean route: x_e=1 means selected in M. Include units for P,X; star pairwise at-most-one; positive star clause when remaining allowed choices <=2 (empty star contradiction); learned negative singleton/pair nogoods. Omit at-least-one on 3-choice stars, a safe weakening. SCC infeasible implies guarded NO.
C signed quotient and hostile audit: if X is nonbipartite then NO. Else choose arbitrary fixed bipartition b in each connected component of X, including isolates. Any good complement label equals b(v)+phi_component mod2. Every nonmatching edge e=uv requires phase difference s(e)=1+b(u)+b(v) mod2. For e inside one component, s(e)=1 forces x_e=1. For edges e,f connecting the same unordered pair of different components, if s(e)!=s(f), both cannot be nonmatching, so x_e OR x_f. This is a genuine bridge: matching support and parity contraction construct positive binary clauses for the implication solver, not separate solver outputs. Equivalent constructive certificate: X union {e,f} contains an odd cycle (for opposite-sign parallel bundle); even-path unit analog. No assumption of arbitrary phase assignments. Each clause independently sound under original guard. Can discover all via grouping and comparing signs in O(m²) time after BFS, without enumerating odd cycles or matching sets. Add clauses to lane B and optionally use A to strengthen required set; reapply closure to every learned guard by global scans. On SCC conflict ban guard S only, never unguarded consequences. At stalled fixed point return UNKNOWN.

Exact forest terminal: if X bipartite, each vertex incident with >=1 X edge, and underlying SIMPLE intercomponent graph (parallel edges grouped, loops ignored after unit rule) is a forest, the full clause system above is exact. Proof: a satisfying assignment selects exactly one edge at each vertex by star units/clauses plus exclusions. It obeys P,X and all learned nogoods. Every nonselected intracomponent edge crosses its fixed bipartition. For each bundle all nonselected edges have a common required phase difference (otherwise violated positive pair clause). Traverse quotient forest, assigning phase differences independently along each nonempty retained bundle; unconstrained edges can be assigned arbitrarily. This provides a bipartition of all nonmatching edges and hence an even 2-factor. Necessity follows from every good M inducing the same phases. Includes any number of components, not a logarithmic phase count. No assumption of matching-support max degree two beyond the stated vertex coverage, and no claim of completeness on cyclic quotient. Exact local computation does not entail universal forest acquisition.
