## Track B: exact synchronous tensor-span theorem (hybrid)
Let a common sequence of disjoint input blocks have finite explicitly enumerated allowed words D_i (size polynomial, total paid). Each of two regional deterministic charts has augmented state vector a_i,b_i (prepend constant 1 so affine updates linear), initial fixed a_0,b_0. For each local word w, verified source-induced matrices A_i(w),B_i(w) satisfy a_i=A_i(w)a_(i-1), b_i=B_i(w)b_(i-1) for every relevant state. Verification sufficient on all states via truth table when total state+local input bits O(log N); for larger widths, a sound syntactic affine-in-old-state coefficient evaluator after fixing local inputs verifies gate maps without exponential truth tables, declining non-affine products. A supplied matrix not a free oracle. Require all private gates functional and accounted for, no omitted extra constraints. Final target tests given by linear forms alpha^T a, beta^T b taking bits 1 exactly when regional target holds. Multiple outputs may be combined by additional tensor factors if product dimension stays polynomial; no claim otherwise.

Define K_i(w)=A_i(w) tensor B_i(w). The actual reachable tensor set Z_i consists of a_i(prefix) tensor b_i(prefix) with SAME prefix on both regions. Let W_i=span(Z_i). Then W_0=span(a_0 tensor b_0), and
W_i=sum_{w in D_i} K_i(w) W_(i-1).
Proof: actual reachable set is union of K_i(w) Z_(i-1) because every prefix extends by every allowed local word, charts deterministic and input blocks disjoint. Linear maps distribute over span. Inductively compute each W_i by applying every matrix to a basis, Gaussian elimination. Terminal indicator (alpha tensor beta)^T z is product of the two acceptance bits, 1 iff both accept on SAME assignment. Thus original joint target UNSAT iff this functional vanishes on W_final. No cancellation error: universal zero on every actual word equivalent to universal zero on its span; not parity of number of witnesses. If nonzero on span, some actual word has value1. For witness acquisition keep independent actual reachable vectors and one predecessor word/index for each, rather than only row-reduced basis vectors. At next layer their actual images span; retain independent actual images. At end at least one retained actual representative accepted, replay gates and physical accumulator lift. Code implements NO-only terminal with reduced basis, returns UNKNOWN on nonzero; witness reconstruction theorem symbolic, not executed from span. Never interpret W_i itself as attainable states or perform nonlinear tests on arbitrary span elements.

In family, a=(1,P,Q), b=(1,S,T), tensor dimension9, first stage direct local initialization; terminal alpha=(0,1,1), beta=(1,1,0) for f=1,S=0. Code acquires affine transition columns by evaluating actual layer on zero and unit old-state words, then checks every old-state word (<=16) and 16 local words, including region independence of state updates.
