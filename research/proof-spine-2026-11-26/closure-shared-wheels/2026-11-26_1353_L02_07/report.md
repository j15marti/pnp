## Native infinite family
Take the simple d-by-d toroidal graph Q, d>=3, v=d² vertices, 2v edges, degree four. Choose charges b_a in GF(2) with odd sum (one charge 1 suffices). For each vertex a, encode XOR of its four incident edge bits = b_a by the eight distinct four-literal clauses excluding the eight wrong-parity words. Use k=8v columns and k rows (first 2v rows are active edge variables, others padding). In the native source change a single cell from literal activation to constant 1 in one chosen column to obtain a same-size YES neighbor: that column becomes tautological. All tables still have four entries. No other table changes.

### A. Constructive chart and group proof
For each row/column use forward/backward two-state support; intersect domains, repeat to fixed point. Each clause has at least two distinct variables (or is tautological), so every row bit has both values in each individual column. After exact vertical label support, every remaining label is supported horizontally by choosing its W value across that row and independently supported labels at the other cells. Thus unary closure does not reject either label and stagnates after the first changing sweep and confirmation sweep. All columns use physical N/S boundary pins and actual labels.
For any omitted column corresponding to forbidden word u at a, fix the four incident edge bits to u. Delete a from Q. Q-a is connected: the toroidal rows and columns give detours around the deleted vertex. Remaining equations have total adjusted charge sum zero because u has parity 1-b_a and total original charge is 1. A spanning-tree leaf elimination solves them: non-tree edges zero, assign parent edges from leaf residual charge, root satisfied by even total. The assignment satisfies every other clause, and violates precisely the omitted one. Hence ALL proper subsets of the k columns are SAT (minimal UNSAT at clause level). This also proves the one-cell positive neighbor. If a group contains fewer than v columns, at least one vertex contributes no clause. Solve all full equations at other vertices by flipping the omitted vertex charge. Every original edge lies on a cycle; toggling that cycle preserves all vertex parities and hence every selected clause, so each active edge bit has both values among solutions of this group. Padding bits are free. This is only shared row-bit support, not all internal labels. No assertion for arbitrary physical guards. The lower bound is k columns for direct unguarded group infeasibility, not k units of compulsory execution. Explicit enumeration of all active rows is 2^(k/4), not a logarithmic kernel.

### B. Global algebraic approach and guarded exact terminal
Decode actual raw h tables by checking all 16 membership bits, recover each clause's actual row IDs and excluded word, skip tautologies, group by sorted four-row scopes. A full group forbids exactly the eight words of one parity; verify before replacing by one XOR. In the NO instance the incidence matrix has each column weight two, so summing all equations gives 0=1. This is an exact global certificate. In the YES instance, one group forbids only seven wrong words and admits the missing wrong word u. All other groups are exact parity. Odd total charge forces that group's parity violation; therefore u is compulsory and its four row bits can be pinned. Flip that equation's RHS, add the four pins, solve GF(2), then lift original physical witness. Conversely every solution of this linear system obeys every original clause including the tautology. All deductions are unconditional for the empty guard, not inferred from separate marginal witnesses.

General exact terminal (symbolic, not implemented for multiple incomplete bundles): accept any decoded four-variable group with a nonempty forbidden set contained entirely in a single parity class, and retain exact scope IDs. Let t groups have missing forbidden words, at most seven per group. Each relation is disjoint union of full opposite parity and singleton missing wrong words. For every incomplete group branch on parity vs each singleton; at most 8^t branches (9^t also safe). For a singleton pin its four rows; for the parity branch impose that XOR. Include any explicit row-bit guards as linear pins. Gaussian consistency gives exact YES/NO per branch and actual lift. Thus for fixed C, t<=C log2 N yields one fixed polynomial total cost. For t=1 on the torus, odd charge rules out all-parity branch. This is a paid terminal with verified admission, not universal coverage. Treewidth obstruction: Q contains the ordinary d-by-d grid; the bramble of unions of a row and column consists of pairwise intersecting connected sets, whose hitting sets have size >=d (any smaller set misses a row and a column).
