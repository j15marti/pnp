## Exact lemma and limits
For a shared disjunction C and signed single-literal tails l_j, conjunction_j(C OR l_j) = C OR conjunction_j l_j. Preserve signs, original carrier identity, occurrence owners and all external uses; no independent cloning. Decoder expands each original row at its saved index and checks exact equality. If C is true every tail has support; if C is false every tail must be true; if C undecided, either a true core literal can extend, or the tail requirements must jointly extend. Opposite tails on the same carrier imply C, by direct resolution, even when scopes differ. More generally under a partial assignment G the motif has extension iff some literal of C can be true under G OR all tails have a jointly consistent extension under G. This assumes no external constraints in the extension test; it is local support, not global feasibility. Arbitrary tails may overlap with other groups; retain them, never independently existentially remove them unless their entire bucket is included. Minimal counterexample: (a OR y) AND (b OR NOT y) under a=b=0. Independent elimination yields true twice, joint elimination yields false. Thus matching support cannot be inferred from marginal feasibility. Exact factorization of shared-core clauses and their unit propagation does not prove bounded global matching width.

For fixed width 3 the candidate list has <=3m entries. Exact sorting/grouping, literal ID comparisons, original occurrence registry and decoding are polynomial in original N for explicit clauses. A sweep of k width-three clauses sharing a pair uses at most k+2 literal inspections instead of 3k if all tails inspected. If the common core is already satisfied, skip every tail. Sequential scans with immediate assignments may use different inspection order but compute the same UP fixed point, or both detect contradiction: fair iteration of monotone sound unit consequences on the identical formula. This is a representation and local propagation theorem, not a new proof of tractability. With immutable exact group representation, no new factors needed, but global branching still unbounded. Same-scope baseline exact duplicate removal precedes cross-scope grouping. Complementary-tail candidates: zero on both native roots; no spurious extra credit. The explicit-to-motif-to-hybrid comparison uses exact source-equivalent formulas; hybrid with complementary-tail additions equals motif on these two inputs. No claim of complete motif grammar or universal compression.
