## Track A: constructive color gadgets
Use colors 0,1,2 (R,G,B). A type t excludes color t, encoding b by (t+1+b) mod3. At a vertex with all three distinct types, the only colorings give all three bits 0 or all three bits1 (the two cyclic derangements). This is an exact EQ3 fanout hub. Join equality hubs in a path with alternating type0/type1 backbone edges, type2 occurrence edge per vertex, missing types terminated at private degree-one leaves. This makes all occurrence bits equal. A degree2 vertex with two same-type edges implements NOT. A degree3 equality hub with the third type terminated converts between two different types. These allow arbitrary signed occurrences and required edge palettes without changing truth values except prescribed NOT.
EO gadget: two cubic vertices linked by unrestricted edge e. Left exterior palettes RG and RB, right RG and GB. Let a,b be true on R in the left palettes, c true on G in right RG; right GB is free auxiliary leaf. e=R gives (0,0,1), e=G gives (1,0,0), e=B gives (0,1,0); each is unique exterior coloring. Thus exact-one with constant-size graph; connect to typed fanout and inversions. Every gadget has separate endpoints and private leaf; unrestricted edges form a matching. Both directions witness reconstruction and polynomial graph size O(CNF length) indexed objects, plus polynomial bit encoding. Therefore this list-edge-coloring restriction is NP-complete. This is not a proof about ordinary unlisted cubic graphs or a claim of novelty versus known list-coloring hardness.
Aligned binary gadget: left RG/RB, right RG/RB with both right ports private leaves. Define two left literals true on R. Left excludes exactly both true, and any remaining pair uniquely determines central color and right completion. This implements any binary prohibition with correct signs through fanout. Thus arbitrary 2-CNF plus EO3 can be directly compiled with binary constraints creating aligned rather than extra misaligned switches.

## Track B: exact classification and decision
Given arbitrary admitted graph, encode every two-color edge by a bit. Vertices without unrestricted incident edge impose pairwise inequalities (binary CNF). For each unrestricted edge, combine its two endpoints into exact joint relation on four restricted ports. If the two lists at an endpoint are distinct, their common color m is one of three colors, and the two Boolean indicator literals that are true when their ports equal m separately indicate e's two possible colors other than m; e=m corresponds to both indicators false. Each central color has unique port word. If both endpoints have the same common color, equate corresponding indicators, with at-most-one, all binary. If common colors differ, the union of indicators covers all three central colors with one duplicate; equate the duplicate, add pairwise at-most-one and a single at-least-one ternary clause. This is exact-one. If lists at one endpoint coincide, e must have their missing color, and that endpoint's port bits have disequality; other endpoint either forces a unique pair or, when also equal lists, requires same fixed missing color and independent disequality. Empty cases reject. Hence each switch either is bijunctive or exact-one plus binary equalities. List pins can be represented as guards in chosen two-color supersets. Classification is exhaustive for stated degree/list promise, not arbitrary graph.
Acquire all pairwise projections and at-least-one when necessary, verify every word on local tables. O(N) local work; linear-size base 2-CNF B, t misaligned switch groups of three indicator literals, each group has at-most-one in B. Exact decision via <=3^t branches plus SCC. Fixed t<=C log2 N gives polynomial total cost (3^t<=N^{C log2 3}), including failed branches and reconstruction. Do not assume universal t bound.

## Track C: exact conflict graph and adversarial reconstruction
If B UNSAT reject. Otherwise for each switch and each of its three literals, test B with that literal pinned; retain only attainable choices. Make one vertex per retained (switch, literal). Within each group put clique edges. Across groups put edge iff B with both literals pinned UNSAT. O(t^2) exact 2-SAT queries, no SAT/counting oracle. For any set of choices, if all pairs individually jointly extend to B then the whole set does. Proof: models of 2-CNF are majority closed (for any clause, if majority falsifies both literals, two sets each of >=2 voters intersect). Induct on number r of choices: r<=2 trivial, for r>=3 select models omitting one of three distinct choices, possible by induction; their majority satisfies all choices and B. Thus original coloring exists iff conflict graph contains an independent set of size t. Recover a witness by SCC on B plus chosen pins and local central colors. Exact but general independent set remains hard. Optional dedup: merge identical literal choice vertices into one vertex weighted by number of distinct groups containing it. Because B enforces at-most-one within each group, independent set weight counts distinct groups covered. Weight t iff full solution, same pairwise argument. No claim that dedup removes all claws.
If acquired graph is a line graph of a known bipartite conflict graph with row/column choices, use bipartite matching; if claw-free, known polynomial maximum (weighted) independent set algorithm. Recognize claws by explicit quadruple scans O(t^4), or faster algorithms. In arbitrary class no such guarantee. Concrete claw with EO groups (p,q,r),(u1,v1,w1),(u2,v2,w2),(u3,v3,w3) and EO(p,u_i,s_i) for i=1..3: p choice incompatible with each u_i by binary base; u_i choices compatible with each other. Every choice individually extendible. This is a genuine induced claw even with distinct literals after dedup. All these constraints compile to native CNF/grid and actual list-coloring gadgets. More directly in ordinary simple cubic 3EC use choices (e,c), clique per edge, same-color conflicts between incident original edges. Independent set size |E| iff proper coloring. For every original edge uv choose disjoint edges f incident u, g incident v, possible since cubic simple. Center (e,R) with leaves (e,G),(f,R),(g,R) forms induced claw. Thus canonical conflict graph for ordinary cubic 3EC is not claw-free without additional transformation.
