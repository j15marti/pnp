## Theorem: synchronized quotient and exact boundary
Let F be a Boolean conjunction partitioned into R and T. Under one checked guard, let Q be a conjunction of binary XOR equations implied by F. Build the signed graph of Q. An inconsistent cycle refutes F. Otherwise each connected component admits a representative z and each variable is z XOR its path phase; these phases are independent of the chosen path by cycle consistency. Substitute this map into **all** constraints of both R and T, deleting tautologies and duplicate literals exactly. For any assignment to representatives there is a unique extension satisfying Q, and F holds iff the substituted F holds; hence this is a bijection of satisfying assignments. Recompute the interface as the intersection of the representative scopes of the substituted R and T, including all variables on which any active external guard depends. A formerly private interior merged into an exterior component is a shared representative, not privately existentially eliminated. The exact regional responses are existential projections onto that recomputed shared interface. Their intersection is nonempty iff the joint residual has a witness: pick common boundary assignment, then combine disjoint private witness maps and invert Q. Conversely restrict any global witness. If using only the old boundary's projected Q-consistent relation, emptiness still proves UNSAT but nonemptiness is not sufficient for exact recomposition unless every newly shared representative is retained. For a region with scope S, the dimension of projection of Q onto S is the number of connected components meeting S; the number of independent equations within S is |S| minus that number. No rank may be credited twice for the same component.

A witness for any derived equality requires both binary clauses, checked independently as RUP in the same fixed chart. Graph BFS verifies path phases, or a closed odd signed cycle verifies inconsistency. For r variables and e equations, graph construction and projection take O(r+e) adjacency operations; all explicit constraints can be rewritten in O(L) map lookups plus sorting/dedup (polynomial bit cost). Given an explicit list of h candidate pairs, testing the two signs with two UP refutations each over a formula of L occurrences, at most r+1 scans per UP check, costs O(h r (L+h)) literal visits per sweep. At most r independent unions can be admitted; if we restart after each union, a conservative polynomial bound follows for the fixed dictionary. Charge failed probes, replay, maps, bits, and source projection separately. With explicit region scope width O(log N), complete response enumeration is polynomial; boundary width alone does NOT bound interior solving. Global rank r-c is monotone only in a fixed chart, no credit reset or universal discovery theorem. A signed bridge through an interior can induce a boundary equality even if neither input equation has two boundary endpoints.

Falsifiers: lost witness after substitution; missed newly shared representative; inconsistent cycle accepted; guard mismatch. Adversarial example: R=(u=v), T=(v=w) is not decomposable after privately eliminating v and forgetting synchronization. For an interior I in R and outside O in T, if Q implies I=O, then I's component must be shared after substitution. Pure affine equations solve by graph or GE, so high explicit interface dimension alone does not imply hardness. Matching admission remains a separate theorem; no general matching test was executed. DISJ/relativization/algebrization/Natural Proofs/DTISP/configuration: no unrestricted lower-bound transfer attempted; not discharged. Decision and support counts distinguished.
