## A. Constructive exact solver
Construct multigraph with vertex for each group and edge for each row in exactly two groups. For a row in just one group add private degree-one dummy factor accepting both bits with baseline b=0; unused rows are isolated free choices. Pins fix edges, remove them from the free graph and shift b at each incident factor by the pinned bit. Retain only compatible local exceptions, project onto unpinned ports. Every resulting relation still contains all assignments of shifted baseline parity (possibly an empty class if degree zero and b=1). Actual group word, dummy and original cell maps are retained. Define an exception to be an accepted word outside the shifted parity class. For each free component C compute B_C=XOR b_v.

**Single-exception normal form.** If C has any satisfying labeling, it has one with exactly B_C exceptions. Proof: XOR all vertex parity discrepancies, each free edge cancels twice, so exception count mod 2 is B_C. If there are >=2 exceptions, select a shortest path between any pair of exceptional vertices, minimized over all pairs. No internal vertex is exceptional, since otherwise a shorter pair exists. Flip all free edge bits along this simple path. Internal vertices flip exactly two ports and retain baseline parity, hence remain accepted; endpoints flip exactly one port and enter the full baseline parity class, hence remain accepted. Other vertices unchanged. All fixed pins unchanged. Strict decrease by 2, terminate. Parallel edges cause no problem; repeated row within a single scope is excluded. Isolated vertices satisfy the same claim. This is an existence argument from an arbitrary satisfying witness, not an algorithm that receives that witness.

Acquisition algorithm: for B_C=0 solve baseline equations by spanning-tree leaf elimination, setting non-tree edges to 0. Total parity even is necessary/sufficient. For B_C=1 enumerate each actual compatible exceptional word at each vertex in C, fix its incident free edges to that word, switch its required parity, and solve all baseline equations of other vertices by tree elimination (isolated fixed vertex checked). Accept first witness or reject if all candidates fail. Soundness by checking each exact local word. Completeness by normal form. Different free components share only already pinned edges; combine independent witnesses, never take product of their trial counts. A does not need to discover a path from an unknown model.

## B. Complementary global algebraic route
For an even component the incidence matrix over GF(2) has image the even-parity vectors: columns are e_u+e_v, a spanning tree generates all even vectors. For an odd component, a chosen exceptional word imposes pins on its incident edges; after deleting newly pinned edges, the remaining charge on every connected component must sum to zero. This is equivalent to Gaussian consistency of the exact parity equations plus pins. In particular for a candidate at v the criterion is that the XOR of the fixed candidate boundary bits incident to each component of C-v equals the XOR of that component's baseline charges. The candidate's own parity is already checked. Algebraic verification is exact, not per-chart affine hull. Independent implementations of tree elimination and Gaussian elimination were executed using a common verified native decoder and component/candidate enumeration, so not fully independent pipelines. The path lemma supplies completeness for both; Gaussian cannot prove the unrestricted model transfer. A globally equivalent reformulation is to minimize the number of exceptions: the optimum if feasible is the number of odd free components. Even arbitrary nonnegative vertex-specific exception penalties minimize by a single feasible exception of minimum penalty per odd component; pair removal never increases such penalties. No claim for edge-dependent costs, exact counts or arbitrary Boolean circuit complexity.

## C. Adversarial reconstruction and hostile native neighbors
Consider a chain of q>=2 disjoint d-by-d ordinary grid graphs (d>=2), identifying the bottom-right corner of each with the top-left corner of the next. All scopes distinct, vertex degree <=4; the q-1 articulation vertices have exactly two incident edges to each side. Put charge 1 at first top-left vertex, zero elsewhere. All ordinary vertices admit exactly baseline parity; each articulation admits full baseline plus one exceptional word w_bad of odd parity, with parity 0 on its two left ports and 1 on its two right ports. For any single exception at that articulation, summing equations to its left forces its left port parity 1, to its right forces 0. Thus no candidate is feasible, hence UNSAT by the normal form. Add one valid exceptional word w_good with left parity 1 and right parity 0 at any articulation; both remaining sides have consistent parity after pins, so SAT. Encode groups by one clause per forbidden word. The positive neighbor replaces exactly one literal-activation cell by constant 1, making that column tautological without altering size or four-entry promise. No target word supplied to solver; generator records changed cell only for test. Both labels survive exact per-chart unary closure because each non-tautological clause has >=2 distinct variables, so both W values individually supported, then every retained label supported horizontally. Group-local arc consistency also cannot reject unguarded instances because each baseline degree>=2. Do not call these instances post-full-portfolio hard: the exact group solver resolves them. The family has q-1 incomplete groups, which may grow polynomially in N, even on connected NO instances. Taking q=d tending to infinity gives t growing as Theta(N^(1/6)) and unbounded raw primal width: each block contains d-grid minor, line-graph primal width >=(d-2)/2 by expanding bags to endpoints as in L02-07. The family does not prove anything about optimal semantic width. This refutes a claim that t must be logarithmic after unary closure, or that t large makes exponential decision compulsory.

Degree-three counterexample: factors on {x,a}, {x,b}, {x,c} with first two full even parity plus (x,aux)=(1,0), third odd parity only. Pins a=b=c=0 force x=1, requiring two exceptional factors despite one shared connected hypergraph component. No edge-path argument for a variable incident to three factors. Actual native adapter is the same forbidden-word column compiler with scopes of size two; projected counterexample exhaustively tested, native guard lift not separately executed. Other counterexample to counting transfer: all-full parity cycle has multiple satisfying edge assignments; one-exception normal form preserves existence not counts, and discards valid models with two or more exceptions.

## Guard extension and complete unary support
Assume every original column, including tautological columns, has <=4 nonconstant literal activations. Horizontal physical pin is a row pin. Vertical accumulator bit at prefix t is OR of its actual activation literals before/through t (north/south indices accordingly). Pin to 0 rejects if a constant 1 occurs, otherwise forces every prefix literal false (row pins). Pin to 1 is tautological if constant 1 occurs, impossible if prefix empty, otherwise a disjunction of <=4 row-literal pins. For q nontrivial positive prefix guards, branch on one actual satisfied literal per guard: <=4^q branches, overlapping branches acceptable for decision but not additive counting. Merge consistent pins and use component solver. For q<=C log2 N with fixed C, cost polynomial; one physical-bit support query takes at most four solver calls. Thus for a satisfiable admitted source under row guards, exact semantic unary support of ALL original physical edge bits is polynomially acquirable by both-value feasibility tests (or opposite of a verified witness). This is exact union of witnesses, not affine hull. Batch deductions are consequences under original guard; reclose per import in theorem, batched in implementation. For general physical guards one can alternatively filter each column's actual <=4-row support by all its prefix requirements, regroup identical scopes and recheck baseline/occurrence admission; if it passes, no branching needed. Some guards destroy full parity, so not universal. The prefix identity was exhaustively tested; complete physical-edge support solver and arbitrary guard branching/filtering remain symbolic, not executed.
