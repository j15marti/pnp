## Named hybrid lemma: exact syndrome affine hull
Let G=(L,R,E) have a perfect matching M0 (otherwise Hall certificate suffices), label each edge by w_e in GF2^p, seek matching M with XOR_{e in M} w_e=b. Acquire M0 by deterministic augmenting paths. Contract reference edges: directed arc i->j corresponds to actual edge (L_i,R_{M0(j)}), label l_ij=w_ij+w_{M0(i)}. Each perfect matching relative to M0 is a permutation, hence a disjoint union of directed cycles (loops allowed, label0), and its syndrome difference is sum of cycle labels. Conversely each directed simple cycle gives an actual perfect matching difference by flipping only that cycle. Arc belongs to some perfect matching iff it stays within one SCC, since it lies on a directed cycle; cross-SCC arcs never selected. Compute actual SCCs, store source IDs. For any excluded arc i->j, reachable set S from j is closed under outgoing arcs and excludes i; its original right columns T=M0(S) contain all neighbors of S, |T|=|S|, j's column in T. Any perfect matching saturates T using S; excluded edge must be zero. This is a checkable tight Hall certificate, not an affine marginal claim.

In each SCC C choose root and directed paths root->i, potential q_i = sum of arc labels on path. For each internal arc define r_ij=l_ij+q_i+q_j. Let V_C be span of these residual vectors. The sum of r_ij on any directed cycle equals its label by telescoping. Conversely each r_ij is the sum of labels of two directed closed walks: root->i->j->root and root->j->root using same return path. Every directed closed walk decomposes into simple directed cycles, so r_ij lies in their span. Thus V_C exactly equals span of ACTUALLY attainable matching syndrome differences within C, not necessarily their set. Let s0=syndrome M0. Exact global affine hull is s0+sum_C V_C. Obtain by Gaussian elimination over p-bit labels in polynomial time. If target outside hull, sound NO; dual linear functional annihilating all residuals and separating target gives certificate (verify potentials, actual graph, all SCC edges). If every SCC rank<=1, the actual local attainable difference set equals V_C (zero always attainable and any nonzero generator attained by at least one directed cycle). SCC choices are independent as all selected arcs internal. In this scoped class the global hull is exact, yielding a full deterministic polynomial decision and witness recovery: solve linear system for one bit per rank-one SCC, recover nonzero cycle by decomposing closed walks, lift disjoint selected cycles. Known single parity matching is consistent with published correct-parity matching theorem; this derivation gives exact vector-SCC criterion and a checkable Hall-to-Gaussian interface. No claim of novelty for classical parity matching.

Further conditional hybrid: let H be SCCs of rank>=2. For each acquire exact attainable local syndrome set A_C with actual witness by paid terminal or bounded enumeration. Quotient all these sets by sum of rank-one V_C. Enumerate their product only under a proved cap product |A_C|<=N^a (and charged acquisition), or use exact DP over a log-dimensional quotient, then combine chosen local matchings. No free state enumeration, no claim all SCCs admit this. Merely being in span does NOT imply actual compatibility.
