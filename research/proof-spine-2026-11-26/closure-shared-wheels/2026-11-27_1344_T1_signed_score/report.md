## A. Exact signed score
For x in {0,1} and sign indicator n in {0,1} (1 negated), v=x-n in {-1,0,1}. v²=x if n=0, 1-x if n=1. Thus Q_C=sum_occ v² counts true literals, D_C=sum_occ v is signed satisfied count. C ordinary OR iff Q_C>=1, B4 iff Q_C=2, NAE iff 0<Q_C<arity, XOR iff Q_C mod2 is target. True positive and true negative counts are respectively (Q+D)/2 and (Q-D)/2. In particular D mod2=Q mod2, so D is not a second independent binary parity bit. Integer D or larger modular D can distinguish signs (but not literal identities within same sign class). For each occurrence x²=x on Boolean domain, so Q and D are affine INTEGER functions of original x. The squared-score condition Q>0 is the standard pseudo-Boolean clause/cardinality representation, not by itself a new SAT decision algorithm. For unassigned variables keep explicit domains; a false-literal value 0 must not be substituted for UNKNOWN.
