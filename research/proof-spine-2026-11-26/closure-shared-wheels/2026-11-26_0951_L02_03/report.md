## 1. Exactly four entries per table remains NP-complete (PROVED)
Source: explicit binary four-port k×k square grid, N,E,S,W physical ports, equality at each shared edge, each cell 16-bit membership mask. North exterior pinned0, south exterior pinned1, east and west free, same fixed pattern for all inputs of size k. Header and boundary encoding fixed, N=Theta(k²). Reject malformed encodings; for total restriction also reject tables with wrong cardinality. No additional guards in theorem; witness pins considered separately below. Define R_h by E=W and S=N OR h(W), h:{0,1}->{0,1}. Exactly four words per table, for h=0, NOT W, W, 1 respectively masks 0x8421, 0x8424, 0x8481, 0x8484 (bit index 8N+4E+2S+W). Four possible h tables only.

For CNF with n variables and m clauses, k=max(2,n,m). Horizontal row i carries x_i, vertical column j begins at 0. Set h_ij(w) to OR of the literal-satisfaction contributions of variable i in clause j; h is one of four functions (including tautological both-sign and absent). For padded rows use h=0; padded columns h=1 in first row, h=0 elsewhere. Top0, bottom1 for ALL columns. Every table has precisely four entries, independently of literal signs, absence, padding or empty clauses. Along each row E=W implies one bit. Down column, induction gives accumulated clause satisfaction. Bottom1 iff all clauses satisfied; any satisfying assignment extends uniquely after choosing arbitrary padding row bits. Empty clauses correctly fail. Conversely extract original row bits from any grid witness. Thus NP-hard already for four table types and fixed boundary; membership by explicit edge witness O(N). Polynomial reduction time and output, n,m bounded by original explicit formula length after relabeling. Counts differ by 2^(k-n) padding choices, not a polynomial counting claim. This is independently reconstructed refinement of L02-01/L05-01 source adapter, not a cross-source assumption.

## 2. Local monotone dual-rail compiler (PROVED)
Let u=(u_0,...,u_15) be a table mask with exactly four 1 bits. For any b:
 NOT u_b = THRESHOLD_4((u_j)_{j!=b}) on the promise.
The right side is positive and constant-size. E.g. DP T(i,j)=T(i-1,j) OR (u_i AND T(i-1,j-1)), with T(i,0)=1, T(0,j>0)=0. It computes threshold4 among 15 bits with <=120 binary gates. Acquire and share all 16 complements per block; O(N) total gates. On the four specific R_h tables an even cheaper adapter exists: all nonconstant bits come in complementary pairs (indices 0,2 and 5,7); bits 10,15 always1 and others always0. No new gates needed for literal complements on that narrower promise.

Given ANY Boolean circuit C size s computing legal grid decision, recursively maintain positive and negative rails. AND: (p AND q, pbar OR qbar); OR: (p OR q, pbar AND qbar); NOT: swap rails. Constants supplied. Input negative rails are the above positive threshold circuits. By induction both rails agree with the gate and its complement at every legal input, despite unrestricted overlap/fanout. Size <=2s+O(N), uniform compiler in polynomial time; no DNNF condition. This does NOT compute complements off the promise. If a deterministic polynomial-time decider exists on the legal grid promise, compile its fixed polynomial-time bounded tape evolution into a uniform Boolean circuit and apply this adapter. Explicit ordinary single-tape simulation if needed, O(T(N+T)) local constant-size transition gates for a time-T single-tape computation, with padded halt and fixed length; polynomial cost generating indices, evaluating gates and storing wires. A polynomial bound and machine are fixed in the conditional complexity-class implication, not acquired from an arbitrary black box. Conversely polynomial-time uniform generation and evaluation of promised positive circuits decides the promise. Nonuniform polynomial size alone yields P/poly, not P.

## 3. Total monotone decision function (PROVED)
For arbitrary 16k² membership bits, let A=AND over cells of [weight>=4], B=OR over cells of [weight>=5], and G be ordinary unrestricted grid satisfiability with the same fixed exterior. Define F=A AND (B OR G).
On all weight-4 tables F=G. Below required weight in any block F=0; if all blocks have weight>=4 and any has >4, F=1. Thus monotone: A and B monotone and G monotone (adding allowed words never removes a witness). For any circuit D correct on the exactly-four promise, the positive dualized D+ above gives F=A AND (B OR D+). Case proof: A false rejects; A and B true accepts; A true B false means all blocks precisely four, where D+ is exact. A,B cost O(N). It follows
 C(F) <= C_mon(F) <= 2 C_promise(G)+O(N) <= 2 C(F)+O(N)
where C denotes general Boolean circuit size and C_promise the minimum on legal inputs. The first inequality includes arbitrary sharing; the last follows by restriction. F is a total NP-complete decision language with fixed grid-length parsing (malformed lengths reject). It is not ordinary G on inputs with other weights. More precisely, polynomial-size nonuniform monotone F families exist iff NP subset P/poly, since 3SAT reduces to G on the promise and F is NP. Uniform polynomial-time constructible monotone F families exist iff P=NP. Therefore proving that F lacks polynomial-size monotone circuits, even nonuniformly, is sufficient for P!=NP. THIS IS A VALID ALL-DECIDER IMPLICATION for the new target; no lower bound for F or the weight-4 promise is established. A fixed depth, read-once or decomposability bound still would not suffice.

## 4. Adversarial audit: no import of full-cube matching lower bound
In L02-02, the actual matching-grid tables were B0={0000,0101,1010,1111} plus optional0110 depending on a_ij. Exactly one varying bit per cell; weights 4 or5. All-zero/full adjacency matrices demonstrate distinct legal matching inputs. Thus this positive projection leaves the exactly-four promise. The totalization F does not give the same values on matching-grid NO matrices with any optional entry (then A=B=1). E.g. first three rows with only two neighbors is a Hall NO for n>=5 and contains optional entries, so F=1. A complement cannot be smuggled in as an allowed positive projection. Formal obstruction: any coordinatewise nondecreasing map from a full Boolean cube into the product of weight-four masks is constant, because its images of 0 and 1 are comparable and equal weight blockwise, hence identical; sandwich all images. So no nonconstant full-cube matching projection that stays entirely within this promise. Does not rule out other reductions into F that leave the promise or hard partial-function distributions. An all-decider implication to ordinary full-cube G remains falsified.

Independent alternative check: exact global NOT count does not rescue L02-02 negative-coordinate bound. Reconstructed known result from Morizumi-Suzuki 2010 Proposition1: Beals-Nishino-Tanaka inverter on m raw input bits with ceil(log2(m+1)) NOTs, O(m log m) gates, bounded fan-in. Combined with dualization, every size-s circuit has representation of size 2s+O(m log m) and <=ceil(log2(m+1)) NOTs, even full-cube. Hence prior near-quadratic distinct antitone leaf coordinate count cannot imply many actual NOT gates or mandatory negative operations. Known theorem, not new proof; no inverter synthesis executed. This is a second complementary model check on the SAME grid matching restriction, which has a P decider.

## 5. Same native restriction: local and affine stagnation controls
For b>=1, construct b independent groups of three variables and eight clauses. The first group has all eight polarity words of a 3-literal clause, so forbids all eight assignments. Each other group repeats polarity word6 in place of word7, so uniquely allows all three variables1. YES neighbor replaces word7 of the first group by word6 by changing exactly one literal sign and therefore one local table type (four membership bits change; not a one-bit neighbor). k=8b, n=3b. NO has no exact source witness; YES has 2^(5b) actual grid witnesses including padded rows. Recognition/independent component enumeration is cheap: no claim of hard post-portfolio UNSAT.

Initial certified domain closure: every horizontal edge both values; in each column, vertical edges before first active literal are 0, after third are1, between are both values. This is arc-consistent: at first literal any row bit allowed and first prefix is its truth; middle literal any pair of incoming prefix and row bit allowed, output support both; last literal output1, any row bit possible by incoming1, incoming0 supported by true literal. Copy cells preserve support, including padding. No empty domain. Iterate exact support filtering initially and at stagnation.

After applying the domain pins, GF(2) and GF(3) local affine hull closure cannot add any Boolean unary pin either. First literal prefix equals a signed row bit; middle full OR graph has affine span all triples over either field (four points affine independent, determinant +/-1); last output pinned1 leaves three noncollinear (incoming,row) points spanning both coordinates. Choose all row bits independently and one arbitrary second-prefix bit per column. Assign first prefix its literal truth and last prefix1, with copies between. This satisfies all local hull equations. Every allowed Boolean value appears in one of these affine witnesses (zero assignment and individual unit choices suffice); exact joint Boolean satisfaction is NOT established for NO. Reapplying domain and these affine unary checks to fixed point has no further effect. This control is specific to local affine hull equations, not arbitrary higher-order algebraic deductions. All guards are just fixed boundaries and derived pins, same original edge IDs. The four-entry promise concerns input membership bits, not these evolving witness domains; do not apply compiler to residual tables pruned to fewer than four entries without retaining original input representation.

## 6. Independent check of X01 strengthened negative-coordinate tariff (scoped)
For completeness, prior L02-02 model (NOT actual general circuit, different source restriction): r marked antitone cells on n×n adjacency. Let d_j be number of unmarked cells in column j, mean n-r/n. Number of common clean columns for a uniformly chosen q-row set has expectation sum_j binom(d_j,q)/binom(n,q). Discrete convexity of binom(d,q) (first difference binom(d,q-1) nondecreasing) gives lower bound n*binom(n-ceil(r/n),q)/binom(n,q). If q<=n/4 and r<=n²/4, ratio >= (1-ceil(r/n)/(n-q+1))^q >= exp(-2q ceil(r/n)/(n-q+1)) for large n. If no clean q×q square, expectation<q. Thus r>=n[(n-q+1)log(n/q)/(2q)-1]. In polynomial-size block NNF, any clean square allows monotone Match_q after fixed outside matching; Cavalar et al Section3 implies log³(s)log²(q)>=Omega(q). Set q=ceil(K log³ n (loglog n)²) with fixed sufficiently large K depending on size exponent and theorem constant; then clean square impossible. r=Omega(n²/(log² n(loglog n)²)). If r>n²/4 bound trivial. Existential selection sufficient for circuit restriction proof; conditional-expectation acquisition by binomial counts is polynomial but not executed here. This independently reconstructs quantitative consequence in X01-02 handoff; no general time claim. Does not transfer to fixed-cardinality tables, where local complements are positive on promise.
