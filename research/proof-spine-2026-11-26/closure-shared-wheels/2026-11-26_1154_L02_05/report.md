## 1. Native source, conservation and exact chart semantics
General source: explicit square binary four-port grid, shared edges equal, fixed north exterior0/south exterior1/east-west free, each table a 16-bit membership mask. It remains NP-complete with exactly-four masks by the independent 3SAT reduction: each cell has E=W, S=N OR h(W) for h in {0,1,W,NOT W}; rows copy variable values, columns accumulate clause satisfaction from 0 to 1, square padding uses saturated extra columns. Each h gives exactly four words; original witnesses project to variable rows and extend via deterministic accumulators. O(max(n,m)^2) cells. This report concerns a narrower easy subpromise, not NP-hardness of that subpromise.
Use L02-04 (k+2)-square with k² core and one-cell frame. Words encoded 8N+4E+2S+W. Core codebook D={0,3,6,9,12,15}. Every mask has exactly one arbitrary label a_v in D, plus fixed dummies even {1,4,5}, odd {2,8,10}; even divergence E+W-N-S, odd reverse. Frame noncorner top pins N=S=0, bottom N=0,S=1, left/right E=W=0; corner pins respectively N=W=0,N=E=0,S=1,W=0,S=1,E=0. Every frame mask exactly four. Core boundary zero. Sum signed divergence over core cancels every shared bit, exterior flux zero. All dummy divergences positive and active words zero, so every native witness uses precisely the chosen active word. Conversely agreement of active words on every internal edge and zero on every core boundary port produces original witness: all internal frame edges zero, exterior south1, other exterior0. This is a complete exact charge certificate, not affine hull. Initial domain propagation followed by this unconditional elimination and reclosure; on any fixed input all remaining core pins are singleton, frame product relations unary. Preserve original edge and cell IDs.
Define H(a) to check horizontal shared edges and left/right core boundary; V(a) to check vertical shared edges and top/bottom core boundary. Hence G(a)=H(a) AND V(a) exactly equals original native decision on this subpromise. Every core label independently ranges over six codewords; H-only witnesses need not be full native YES, but every row/column mixed label word is a valid encoded native input. A physical core edge guard belongs to the chart of that edge's direction; incompatible duplicate guards or nonzero boundary guards reject. Arbitrary unary restrictions D_v subset of D on *input labels* can also be used as a Cartesian subpromise, distinct from restrictions on witness ports. For fixed input and physical guards, check pins on the active word and reconstruct. No cross-source adapter.
Two exact compact charts: for each row interval I maintain four functions P_I(a,b) indexed by left/right endpoint bits. Leaves test one label block; at each binary split P_I(a,b)=OR_{c in {0,1}}(P_L(a,c) AND P_R(c,b)). Each AND is decomposable, OR disjoint since label fixes seam bit. Conjoin row outputs P_row(0,0) by binary tree over rows. All gates typed on the row-first block tree; size O(k²). For V use column-first. Both constructions uniform, original IDs retained. The final AND may overlap on every core block, has size O(k²) as arbitrary circuit and is exact; no compilation step needed. On membership bits every label predicate is positive on the promise (OR of membership coordinates for desired active words). This is a real cheap bypass, not a claim of universal forest coverage.

## 2. Exact chart matrix rank, including arbitrary unary restrictions
For partition S, S^c of core cells, let E_d(S) be edges of direction d crossing cut; h and v counts. Matrix M_d rows indexed by labels on S, columns by labels on S^c, entry chart truth (0/1 over any field), with fixed Cartesian allowed domains D_v. Optional consistent physical pins included in the corresponding chart. Rejecting assignments to a side due to its own internal constraints give zero rows/columns. Every surviving side induces a crossing edge bit word. Entry 1 iff the two words agree. Thus permuting rows/columns groups matrix into mutually disjoint nonempty all-one rectangles indexed by the crossing words attained on BOTH sides. Their number R equals the rank over EVERY field (take one row/col per rectangle for identity; each rectangle rank1), and equals the minimum number of possibly overlapping sound Boolean rectangles (identity diagonal requires distinct rectangles). It is the number of crossing words extendible in that chart, not a count of full assignments or joint H,V witnesses.
With full D, every horizontal input/output bit pair, and every vertical pair, has at least one balanced label realizing it. Choose arbitrary bits on all internal edges in direction d, boundary bits zero, each cell realizes its own two bits, other direction unconstrained. Consequently every crossing word is realized: rank(M_H)=2^h, rank(M_V)=2^v. With consistent literal pins on physical edges assigned to their respective charts, rank becomes 2^(number of unpinned crossing edges); all other edge choices remain independent. For arbitrary unary D_v, compute R without listing words: for each row or column compose local two-bit Boolean relations within intervals between crossing edges (Boolean matrix products, not numerical multiplicities). At each crossing edge use a two-state integer DP counting distinct sequences of crossing bits; final endpoint zero; multiply across independent lines. Each feasible sequence counted once because existential interior was eliminated Booleanly. There are O(k²) fixed-size relation operations and integer additions/multiplications of O(k²) bits; schoolbook conservative O(k^6) bit operations, polynomial space; a logarithmic rank exponent is not the full rank matrix. This is exact rank acquisition, not an arbitrary equivalence or counting oracle.
Second method: on the same native input universe, choose independent directed checkerboard face toggles as in L02-04. Every selected face edge-disjoint, all selected bits independent, every choice yields actual joint YES. For direction d choose the faces touching a crossing edge of direction d, set other face bits0. Pair row and column restrictions from these actual YES inputs. The resulting submatrix of M_d is identity indexed by those face bits (distinct choices differ on at least one crossing edge; same choice lifts). This weaker rank/rectangle certificate uses only joint YES diagonal witnesses, useful when guards pin some face bits. Under consistent guard preserving this product family, freeze every affected selected face, keep original physical IDs. Both methods show signed field cancellation cannot compress an *exact sum of rank-one separated terms at the cut* below the rank; they say nothing about unrestricted arithmetic gates or Boolean execution. Hadamard product M_G=M_H .* M_V, rank(M_G)<=rank(M_H)rank(M_V) by distributing outer products; no rank additivity assumption.

## 3. Common tree lower bound and scope
Binary source-block vtree T: leaves are exactly k² original core blocks. Normalized model: binary AND/OR DAG with unrestricted sharing/fanout; each gate typed by tree node; leaves arbitrary local predicates at leaves; constants can be represented by typed full-subtree tautologies/contradictions; OR children same type; AND children typed by two distinct immediate child nodes; output typed root. Size counts all gates. Scope is the assigned subtree, even if a gate is semantically constant. This enforces decomposability and smoothness. For a weaker block-structured model where each AND's two nonempty syntactic child scopes lie in opposite child subtrees of some node, normalize with O(k² s) gates: compute LCA of each syntactic scope, pad each OR child to its parent's LCA with ANDs on omitted sibling-subtree tautologies, pad AND operands to appropriate children of its separating LCA; constant-only cases simplify, final pad to root. Binary edges O(s), each padding chain at most k². Thus normalized exponential bound persists up to polynomial overhead in that weaker model; not a claim for vtrees splitting one membership block into individual bits.
For any node t of T with subtree leaf set S, every accepting trace (unfold DAG, choose one true OR child, both AND children) visits a gate typed t: follow unique child toward t at AND and chosen OR while same type. Acyclicity ensures termination; no internal terminal allowed except normalized constants. Take first such occurrence. External leaves all outside S. For a fixed gate g typed t, union all external contexts with a hole at g; the set of g-accepting assignments on S times the set of external assignments satisfying at least one of these contexts is a sound rectangle, by substitution into the accepting trace. DAG sharing does not add constraints because all used occurrences are certified by their trace leaves; grouped contexts may vary. Every accepting input is covered. At most number of g gates at t rectangles. No efficient enumeration of contexts asserted, and no determinism required. Therefore size of chart d >=2^|E_d(S)| in the full codebook case by section 2.
Every binary tree on M=k² leaves has a balanced node k²/3<=|S|<=2k²/3 (descend larger child until first <=2M/3). Every balanced cut of k×k grid has >=ceil(k/3) crossing edges: if fewer than k/3, fewer than k/3 rows are mixed; absence of a full S row would force |S|<k²/3; similarly full complement row must exist. Those two full rows force one vertical crossing per column, contradiction. Hence for EVERY common tree and pair of exact normalized H,V circuits:
  s_H s_V >= 2^(h+v) >= 2^ceil(k/3);
  max(s_H,s_V) >= 2^ceil(ceil(k/3)/2).
Under g distinct consistent core physical pins, replace h+v by >=ceil(k/3)-g (or zero lower bound). The output size cannot be polynomial for both charts under common tree, even though separate structured charts each linear. In N=16(k+2)^2 plus fixed encoding bits, exponential in sqrt N. For weak structured model divide by polynomial normalization factors. This is a contradiction to any universal polynomial same-tree realignment that preserves each original chart's full semantics, not to exact cooperative evaluation or arbitrary alternative summaries.
Independent adversarial check for the final conjunction: every accepting trace in any binary block-decomposable AND/OR DAG computing G on the six-label promise must mention every block (change omitted active label, creating genuine NO). External context disjoint from gate's syntactic scope, hence actual trace scope equals syntactic scope; selected OR cannot drop scope; largest-child descent yields balanced gate. For each gate group all outside contexts into one rectangle by same substitution. Under independent checkerboard face toggles, every balanced cut has >=ceil((k-2)/16) distinct selected face bits crossing for k>=36: removing outer ring leaves both shores >=(k-2)^2/4, same row argument gives >=(k-2)/4 interior crossing edges, each belongs to exactly one selected face, at most four per face. A sound rectangle fixes all those bits and has probability <=2^-ceil((k-2)/16). At least that many rectangles hence exponential size. This reconstructs L02-04 decomposable case and shows a polynomial arbitrary-tree decomposable conjunction compiler on these two charts is impossible on output-size grounds, even if it can choose a new output tree. The linear overlapping final AND is the explicit counter-algorithm. No extension to arbitrary overlap is claimed; prior low-context theorem remains scoped.

## 4. Reciprocal series and resource ledger
