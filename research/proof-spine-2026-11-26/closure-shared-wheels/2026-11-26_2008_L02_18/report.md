## Bounded-generator theorem (track A after matching/affine import)
For any 2CNF B and linear system A x=b over GF2 of rank h, if B has a model, obtain one reference r by SCC. If affine system inconsistent, reject; otherwise target syndrome for difference d=x+r is b+A r. Every clause after changing coordinates to d is satisfied by all-zero, hence is an implication (!d_i OR d_j), a pair prohibition (!d_i OR !d_j), or a unit prohibition. Implications give directed graph on flip variables, collapse SCCs. Feasible flipped sets are forward-closed unions of SCCs avoiding all prohibitions. Suppose target achievable. Choose inclusion-minimal such set S with target syndrome. Every minimal SCC in S (no incoming edge from another selected SCC) may be removed, and ANY subset of those minimal SCCs may be removed simultaneously: forward closure remains valid because no retained selected component forces a removed one, and removing choices cannot create a forbidden pair/unit. Give each minimal SCC its vector weight equal to sum of columns of A for its member bits. If there are more than h, linear dependence yields a nonempty zero-sum subset. Its removal preserves target syndrome and strictly shrinks S, contradiction. Every selected SCC reachable from some minimal SCC because finite DAG. Thus S is the union of forward closures of <=h generators. This holds relative to any actual B-reference model; no unknown satisfying full assignment required for acquisition. Enumerate all seed subsets of size <=h of the original flip variables (one representative per SCC would suffice), compute closure, check every prohibition and exact syndrome. Both directions immediate by lemma and direct verification. Candidate count sum_{j=0}^h binom(q,j); for fixed H cap h<=H, polynomial q^H; for h=O(log N) this can be quasipolynomial, not a proved FPT or log-kernel result. Exact decision, witness reconstruction symbolic; no counting transfer. Literature Brakensiek/Gopi/Guruswami arXiv:1902.04740 Section5 Proposition5.2 and last paragraph already give n^{O(h)} for 2SAT-MOD over GF2^h. Our elementary generator proof and actual source adapter provide scoped integration, not novelty claim for parameter tractability.

## Parameterized barrier and universal gap
For arbitrary k-partite multicolored independent-set instance, give one variable per vertex. Add NAND for every conflict edge and every pair in same color class. Require parity1 on each color class. Because at most one chosen in class, parity1 is exactly-one. All k parity rows independent (nonempty disjoint supports). Thus k-colored independent set iff B+Ax=b with rank h=k. Known W[1]-complete parameterized by k (e.g. Fellows et al. 2009); so a general f(h) poly(N) algorithm for this mixed target would imply FPT=W[1], not an unconditional refutation of such algorithm. This applies to residual h as well: use classes of size>=3 (pad via private universally conflicting options or standard sufficiently large hard instances), so no repeated or constant forms in parity chart; class size>=3 gives distinct linear forms and deficit one per class. For source mapping use same NAND components and copy equality/ternary parity chains. Every vertex in a class size>=3 appears in a NAND. The construction is polynomial; parameter h preserved after affine observation quotient. Ordinary NP-hardness follows as well (multicolored clique with unbounded number of colors). No ETH-based conclusion used. This rules out treating bounded local rank2 matching components as a universal easy subclass without resolving NP-hard global coupling. It does NOT prove P!=NP or that h=O(log N) is impossible to solve in P. No complete universal guard-cover construction obtained.
