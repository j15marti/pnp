## Named theorem: affine seam Fourier factorization
Let x be shared Boolean variables, y_i disjoint private tuples. Let cluster i impose r_i quadratic equations q_ij(x,y_i)=0. Require the boundary-only part of each equation to be affine, so
q_ij(x,y_i)=R_ij(y_i)+a_ij·x+sum_k y_ik (b_ijk·x).
Constants are included in R. All coefficients over GF2, Boolean squarefree normal form. Let L_i be a matrix of independent rows spanning the boundary coefficient vectors a_ij,b_ijk, and h_i=rank L_i. Acquire by elimination; for each coefficient retain its coordinates in the basis. Every boundary term depends only on z_i=L_i x, and since rows independent, every z_i in GF2^h_i is attainable in the unrestricted shared domain (do not assume attainability under additional shared guards). For fixed z_i, private q become quadratic polynomials in y_i. Use exact integer character sums:
C_i(z)=2^-r_i sum_{lambda in GF2^r_i} sum_{y_i} (-1)^(sum_j lambda_j q_ij(z,y_i)).
For each summand, eliminate cross pair uv from q=uv+uL+vM+R: sum_{u,v}(-1)^q=2(-1)^(R+LM). Repeat; affine tail zero if nonconstant, else signed power of two. Thus each term polynomial in original encoding, with signed integer bit width O(|y_i|+r_i). Dependent/zero rows may be removed, but count formula also valid without removal. Support S_i={z:C_i(z)>0} acquired exactly, not inferred from signs modulo a prime. Private lift can be recovered by repeated count under private bit pins if needed, polynomial under same fixed cap times number of bits. Do not infer independent shared feature words are jointly attainable.

For each fixed x, disjoint private domains imply the exact count of lifts is product_i C_i(L_i x); existence iff every factor positive. With shared affine guard Gx=g, full decision exactly equivalent to Gx=g AND L_i x in S_i for all i. This is existential elimination, not equality of nominal marginal assignments. If a local S_i is empty refute. If nonempty choose z0, span V=span{z+z0:z in S_i}; S_i is affine iff |S_i|=2^dim V, because S_i subset z0+V. Verify cardinality, not just hull. In that case acquire equations D_i z=D_i z0 for basis of orthogonal complement V^perp, pull back D_i L_i x=D_i z0. Stack all rows with guard. Gaussian inconsistency is exact NO when all clusters affine and sound NO when nonaffine clusters retained but ignored as a relaxation. For exact full join of nonaffine factors use another verified terminal, never silently substitute hull. If all feature ranks <=2 and features are common original literals (or verified independent global coordinate variables), exact 2CNF join available by excluding each missing feature word; arbitrary overlapping linear forms require their actual dependency equations and are NOT automatically 2SAT.
