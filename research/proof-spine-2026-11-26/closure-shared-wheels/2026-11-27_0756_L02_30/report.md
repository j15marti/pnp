## Track A: output-sensitive acquisition proof
Let A be a verified affine guard; work in its free coordinates t in F2^d, or intersect A explicitly. Canonicalize each affine set by RREF of augmented equations with contradiction marked EMPTY. For nonempty C let [C] be its indicator. Let D_i be a finite dictionary of signed integer coefficients on canonical nonempty affine subsets after i fibers, beginning D_0={ambient:1}. Update by taking a snapshot of D_i and for every (C,a) subtract a at key C intersect E_(i+1) if nonempty; leave the original coefficient and combine identical keys; delete zero coefficients. This is exact because [C][E]=[C intersect E] pointwise and f_(i+1)=f_i(1-[E]). In particular f_M is the nonnegative 0/1 feasible indicator. All products are actual intersections, not marginal Cartesian products. Each prefix key is an intersection of a subset of original fibers (empty subset included); the number of all distinct nonempty intersections L is monotone in prefix and bounds every dictionary size. Signed support width W=max_i |D_i| can be much smaller than L; snapshot updates also take O(W) transient entries (at most 2W before deletions). A cap checks work before exceeding fixed polynomial budget and returns UNKNOWN, not NO. The maximum prefix support, not final support alone, is charged. Canonicalization is exact semantic equality for affine sets, so zero-coefficient deletion is safe for ALL later intersections and guards by linearity; no oracle for arbitrary relation equivalence.

At most M W attempted meets (failed/empty included), each requiring polynomial bit work in d and source length via GF2 elimination; coefficients have at most M+1 magnitude bits because each is signed sum of at most 2^M subsets, even prior to cancellations. With deterministic sorted maps or balanced search, storage O(W(d^2+M+log W)) bits apart from source/working matrices; input adapter and parsing separately paid. This proves output-sensitive acquisition O(M W poly(N)), for d,M<=poly(N). No individual rank or overlap bound. For an explicit full intersection lattice one can instead keep zero keys and extend all current distinct keys, O(M L poly(N)); the signed algorithm does not need to certify or enumerate L. An equivalent independent proof groups the ordinary inclusion-exclusion sum by canonical intersection; grouped coefficients are the Möbius coefficients on the reverse-inclusion poset: summing coefficients over all intersections containing a given nonambient C gives (1-1)^k=0 where k is the number of input fibers containing C, positive. This uniquely determines the Möbius recursion except when an input equals ambient (then immediate NO; handle separately). The signed recurrence is valid even in that case.

## Track B: rank-free count and exact affine hull
For any explicitly specified affine query guard G, count feasible assignments in G exactly by C(G)=sum_(C,a in D_M) a*2^(d-rank(C intersect G)), treating empty intersections as zero. Signed arithmetic is over integers, NOT GF2 or a modular count. Each count query costs W poly(N) with O(M+d+log W) bits for intermediate sums. Thus even rank-d forbidden fibers cost no 2^d spectral expansion. If C(ambient)=0, NO. If positive, acquire an actual feasible anchor by fixing coordinates greedily using the count query; one successful branch per bit, no free search. Maintain an affine span p+V of acquired actual points. Compute a basis of normals of V-perp by Gaussian elimination. For each normal u ask C(u*t != u*p). If all zero, feasible set is contained in p+V; since all spanning points were attained, its affine hull equals p+V. If one positive, fix its guard and greedily find an actual outside point, increasing dim V. At most d extensions and d+1 scans, O((d+1)^2) count queries for scans plus O(d(d+1)) for witness construction. Exact affine-hull extraction therefore adds poly(N) W cost independent of ranks, violation multiplicity and ambient dimensions. Count and decision kept distinct; witness reconstruction only local and certified, no global SAT witness from marginal supports. Pull back normals through the verified affine guard map, preserving original IDs. If a region count equals 2^dim V, its feasible set exactly fills this affine hull; otherwise retain original nonlinear factors and import only necessary rows. For a polynomial supplied catalogue and at most n independent global affine imports, restart at most n+1 times; charge all attempts, guard rechecks, row provenance, verification, failed tracks, input parsing and all repetitions under fixed aggregate polynomial caps. ## Same-source UNSAT family and adversarial track
On connected 3-regular K4, assign charge 1 at vertex 0, charge 0 at others. Each vertex has three original edge bits e and shares all h hub bits y with all other regions. For each wrong edge word w (four choices), forbid:
(1) h cubes E_i pinning all hub bits except y_i to zero (and e=w);
(2) binom(h,2) cubes P_ij pinning the first two 1 positions i<j, all other positions <=j to 0, later bits free (and e=w).
These are ordinary CNF clause forbidden cubes, each clause width >= 3. The first collection covers hub weight 0 or 1; the second partitions hub weight >=2 by first two ones. Each regional relation is exactly edge parity, independent of all shared hubs. A zero hub word simultaneously violates h distinct E_i; maximum multiplicity h. The E_i meet pairwise at the all-zero hub word, so for each wrong word the only additional nonempty intersection is this common center. P_ij disjoint from each other and from E_i. Different wrong edge words disjoint. Thus L=1+4*(h+1+binom(h,2)); center coefficient h-1, individual fibers coefficient -1, ambient coefficient 1. Every prefix and final support bounded by L; h>=2 gives final support exactly L. Highest individual codimension h+3, and joint regional variable rank h+3; raw explicit regional table 2^(h+3) entries, while M=16*(h+binom(h,2)), N=Theta(h^4). Hence explicit regional table enumeration superpolynomial in N for this specific model; polynomial signed acquisition despite unbounded overlap and codimension. Does not prove a balanced-rectangle or all-decider lower bound. Summing vertex parity gives zero on left (each edge twice), one on right. Each family instance is genuinely NO. A direct classification by hub weight is an even cheaper bypass, so no exclusive algorithmic superiority. ## Limits and resource gates
Independent forbidden cubes fixing disjoint pairs each to 00 produce all 2^k distinct nonempty intersections, with coefficients +/-1. The unpruned signed dictionary has exponential width, even though separate components make decision trivial. A disconnected contradiction can be appended for a NO source without changing the early prefix cost; an intelligent component algorithm bypasses it. Thus no universal W bound for this representation. A stronger claim about all orders/merges is not proved. DISJ PASS for exact pointwise signed identity; no independent marginals; counts of shared overlaps never multiplied without proof. Deterministic configurations no lower-bound implication; simultaneous DTISP and all-decider bridge OPEN; same sequential bit work T gives conservative peak storage <=T+input, cumulative bit-steps <=T(T+input), with charged replicas.
