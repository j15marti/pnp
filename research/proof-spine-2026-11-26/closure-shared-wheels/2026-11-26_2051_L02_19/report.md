## Track A: capacity on actual option cliques (Hall hybrid)
Let disjoint nonempty option groups G_i each require exactly one selected bit. Conflict graph on option IDs has an edge only when simultaneous selection is source-certified impossible under the same guard. A set of pairwise incompatible options is a capacity-one clique. Acquire a partition of options into such cliques C_j by greedy deterministic scans (singleton always legal; for this run forbid same-owner options from being placed together to recover cross-owner resource constraints). Verify every pair in each clique. Form bipartite graph owner i -> clique j iff G_i intersects C_j. Any solution chooses one option per owner, no two chosen in any clique, inducing a matching saturating all owners. Therefore an owner subset S with |union_{i in S} N(i)|<|S| certifies NO. Maximum matching via deterministic augmenting paths; if unmatched owners remain, reach via alternating paths and collect S,T (all actual neighbors); each T matched into S, at least one S unmatched, verify deficiency. Certificate verification only needs original EO group facts, covered options, explicit cross-pair conflicts and cardinalities. Even an overlapping family of cliques covering all options of S with fewer than |S| cliques is sufficient: assign each selected option to one containing clique; no two can occupy one. No need to enumerate joint interface words. A valid partition with full matching is only a necessary relaxation. If every cross-owner conflict is contained within one of the partition cliques and there are no other constraints, any saturating matching can select an actual option per owner and gives a solution; otherwise no positive decision. This is a source-recognized application of Hall/all-different, not a new general theorem about matching.
More general verified weighted cover: choose nonnegative rational weights w_j with sum over cliques containing each option in selected owners >=1. Then every feasible assignment obeys |S| <= sum_j w_j because each clique has capacity1. If strict violation, exact rational certificate. This can be acquired by LP on a polynomial list of verified cliques, with all bit costs charged. Searching all maximal cliques is not generally polynomial; no claim of such acquisition. This weighted extension is symbolic only.
Connection to overlap model: capacity bound concerns actual pair incompatibility, not nominal cut-rank, and certifies all assignment combinations in one step. Conditioning shared coordinates is safe only when all remaining shared coordinates are joined with joint compatibility; marginal certificates cannot be multiplied. Our cover theorem does not require decomposable AND, smoothing or prescribed DAG. It is an algorithmic bypass, not a rectangular lower bound or a statement about arbitrary deciders.
