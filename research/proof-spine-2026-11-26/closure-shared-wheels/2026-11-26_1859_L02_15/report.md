## 3. Exact negative-cover theorem
Define a literal rejection certificate on this fixed cut as a collection of axis-aligned subcubes (conjunctions of pins on original cut bits), each labeled L or R, which covers ALL 2^k cut assignments, and whose label means that region has NO completion for EVERY assignment in the subcube. Other constraints, arbitrary algebraic predicates, dynamic cuts and cross-region deductions are not allowed as certificate records. A DAG may share subcomputations but if it is charged by the number of explicitly emitted labeled subcubes, duplicate records do not help. This is an output model, not a lower bound on arbitrary DAGs, BDDs or algorithms. Since the two supports partition the cut, each valid labeled subcube is precisely monochromatic for F.
The exact minimum number of such records is
C(k,r)=2^(k-2r)*3^r.
Proof lower: every monochromatic subcube must pin each x_i (flipping that bit changes F). For each paired AND, its product must be constant on the projected subcube; otherwise vary only that pair with all other coordinates held fixed, changing F. In each pair choose the three representatives (0,1),(1,0),(1,1). No constant-product subcube contains two: 01 and10 require both coordinates free, which includes 11; either with 11 already has different product. Therefore take product of these representatives over r pairs and all 2^(k-2r) ordinary words. Any allowed record contains at most one representative. Lower follows. Upper: pin all ordinary x; for each pair use disjoint three subcubes g=0; g=1,h=0; g=h=1. Product yields exactly C monochromatic records, label according to F. No free enumeration claimed. C=2^Theta(k)=2^Theta(sqrt N) even for r proportional to k. All context words counted are genuine attained on exactly one side, no fictitious simultaneous support or marginal Cartesian product. In contrast, a symbolic parity predicate or the joint congruence proof below bypasses literal enumeration. Ordinary coordinate-wise mismatch certificates in other communication models not asserted exponential.

## 4. True hybrid: cross-region functional congruence changes the Gaussian representation

If two local tables, after sound filtering and equality renaming, force outputs y=f(a,b) and z=f(a,b) on the SAME original input classes with the same truth table, import y XOR z=0. The simple equality rule needs only universal local implications; if a table lacks some input values, do not infer attainability; code requires all four input pairs present. No arbitrary equality test/semantic oracle. Output equality is unconditional only when all source constraints used are unconditional; in guarded cases preserve guard. Each input class comes from checked local equality, not mere equal cardinalities or same marginal signatures. Verify using constant-size truth table enumeration plus equality proof paths. Thus addition of imported rows preserves all original solutions exactly (no witness change), but using the affine hull of individual local tables alone loses this equality.

Thus treewidth >=m-2: the sets row∪column in this rectangular grid form pairwise-intersecting connected subgraphs; their bag-subtrees in any tree decomposition pairwise intersect and have a common bag by the Helly property for subtrees of a tree.
