## Corrected theorem: path contexts rather than gate-local overlap
Take any satisfying assignment and descend from root: at an OR choose a satisfied child (same scope); at an AND choose a larger-scope child (both satisfied). Starting with n and ending <=1, the first gate g with |S_g|<=2n/3 has |S_g|>=n/3: the crossing step is an AND with parent >2n/3 and union size at most sum of child sizes, so larger child >n/3. For n=2 the interval includes singleton. Thus each satisfying assignment follows a satisfied root-to-balanced-gate path. No assumption of decomposability required for this coverage; smoothness and leaf locality are essential. Without smoothing, a satisfied OR child may drop many blocks at once.

For any root-to-g path p, define C_p to be conjunction of the full sibling subcircuits at every AND on that path (OR requires no sibling). Empty conjunction true. This is a semantic definition, not an algorithm enumerating paths. Let T_p be union of their syntactic scopes; smoothness gives S_g union T_p=U by telescoping along path. Let O_p=S_g intersect T_p. Then F_g AND C_p implies root acceptance for every assignment by induction upward: at AND both children true, at OR selected child true. Conversely every satisfying descent path gives such a factor. DAG sharing does not invalidate this implication, including cases where a sibling also depends on g; all occurrences use the same block assignment. For each fixed g and O, union C_p over all paths with O_p=O. This grouped context C_{g,O} has scope subset of (U\S_g) union O (all terms have this syntactic block universe). It is safe to share because F_g is exactly the same gate relation in all terms. No grouping of different guarded gate relations without an explicit exact common relation. Fix each o in product of domains of O. Define A_o={a on S_g:F_g(a), a|O=o}; B_o={b on U\S_g:C_{g,O}(o,b)}. Their product implies root, and union over o exactly recovers F_g AND C_{g,O}. Thus the root relation has a balanced rectangle cover of at most
  sum_{g balanced} sum_{O attained by a path to g} product_{v in O}|D_v|.
Alternative: condition on U_g=union_p O_p, grouping all paths to g; cost product_{v in U_g}|D_v|. Use smaller bound per gate. For binary blocks with total path overlap <=r, first bound <=s sum_{j=0}^r binom(n,j)2^j; if each g has one fixed overlap set of size<=r, <=s2^r. For w=0 this reconstructs the ordinary DNNF bound <=s, consistent with Bova et al 2016 Theorem6. No determinism/disjoint cover claimed here.

Proof of overlap bound: along path, S_g lies in selected child scope at each AND; its intersection with sibling is contained in local child intersection. Therefore |O_p|<=sum_{AND steps on p}|S_selected intersect S_sibling|<=dw, where d is max AND depth on these paths. This sum can be n even if w=1. Neither the number of distinct O across paths nor cumulative overlap is controlled just by w. The theorem is existential: cannot assume context enumeration, equivalence checking or output of all rectangles free. Context grouping changes the old candidate into a valid theorem only with cumulative overlap and actual context identification. Even a small context relation does not imply it can be acquired within cap.

## Exact fixed-cut affine rectangle tariff (independent algebra track)
Let R=a+V nonempty affine relation on L disjoint-union Rside bits, V a vector space over GF2. Put V_L=V intersect (GF2^L x {0}), V_R=V intersect ({0} x GF2^Rside). Define lambda=dim V-dim V_L-dim V_R>=0. The exact minimum number of nonempty contained Cartesian products over this fixed cut covering R is 2^lambda, allowing overlapping rectangles and arbitrary local factors.
Proof: cosets of V_L direct-sum V_R in a+V partition R into products. Conversely any nonempty rectangle P x Q contained in R: choose anchor (p,q). For any (p',q') in product, also (p',q) and (p,q') belong to R. Their differences from anchor lie in V_L and V_R. Thus entire rectangle is contained in a single coset. Every coset must be covered; exact count follows. Empty R has cover size0, not this formula. Can compute ranks by Gaussian elimination, not enumerate the cosets. This is an exact representation count, not decision time.
Condition a set O subset L, q=dim projection_O V, t=dim projection_O V_L. There are 2^q attainable guard values. Each nonempty fiber has direction V'=V intersect ker projection_O and left-private dimension dim V_L-t, right-private unchanged. Hence lambda_fiber=lambda-q+t. Total minimum number of fixed-cut rectangles that each belong to a single guard fiber is 2^(q+lambda_fiber)=2^(lambda+t). No discount from partitioning all guards; per-fiber cost can drop, aggregate explicit tariff cannot. This exact statement applies to affine joint support, not its affine hull for a nonlinear relation. Symbolic hybrid: represent actual affine fibers by their verified equations; test incompatible join by elimination. No need to materialize 2^lambda products; can store rank and equations with polynomial bits. This is a cost-preserving change of representation for actual affine regions, not a general shortcut for arbitrary nonlinear supports.
