## Track C: authenticated hardness and explicit falsifier
The mixed degree-two language is already NP-complete with only single signed 3-clauses (good), EQ2 (good) and EQ3 (bad, affine). Each factor table encoded by one signed clause for each forbidden word (<=8 for ternary), then exact native grid as above with O(L^2) bits. Thus a polynomial solver for all mixed instances would imply P=NP. This is the classical fanout phenomenon, not an unrestricted lower bound. The full grid remains NP-complete independent of our grouped promise.
Stronger explicit falsification of UNIVERSAL THREE-MEASURE ADMISSION: take d-by-d ordinary square grid graph d>=3 as hub graph, each hub imposes exact equality of all incident bits (degree 2,3,4). Subdivide each hub edge by a binary wire factor, distinct original row IDs on the two half-edges. On three edges of the upper-left elementary square use EQ2, on the fourth NEQ2={01,10}; all other wire factors have {00,01,11} (written bit-order convention, any 3-word relation containing 00 and full unary support works). The square is inconsistent: XOR the four equality/inequality conditions gives 0=1. Add 00 to the NEQ relation for the SAT neighbor; all-zero witness. Every factor has both unary values supported, so initial group unary closure has no pins, both labels. No bridges since every original grid edge lies in a cycle and subdivision preserves this property. Good factors are binary wires and four corner EQ2 hubs; their induced components are trees (no adjacent corners for d>=3), so contracting them preserves cycle rank. Single block has beta=(d-1)^2, h=d^2-4, a=2d(d-1)-4 for NO and +1 for YES. Both labels have mu=Theta(d^2). Native k=Theta(d^2), N=Theta(d^4), so mu=Theta(sqrt N), violates every fixed logarithmic cap eventually. Same-size one-cell SAT neighbor: in actual column forbidding 00 at NEQ wire, set one h to 1, tautologize that column. No other table changes, exactly four entries maintained, original IDs preserved. This is an unconditional counterexample to UNIVERSAL ADMISSION of the three-measure criterion, not evidence of superpolynomial decision time: every factor is exact bijunctive, equality expressed by binary clauses and each binary relation by forbidden-pair clauses.
