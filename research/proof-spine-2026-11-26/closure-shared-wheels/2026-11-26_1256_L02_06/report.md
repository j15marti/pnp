## 1. Source and two chart acquisition
Grid k=max(2,n,m) with explicit 16-bit membership masks and fixed exterior N=0, S=1, W/E free. At cell (i,j), E=W and S=N OR h_ij(W). h is constant0 for absent variable, x or not x for signed occurrence, constant1 for both signs. Every table has four entries determined uniquely by pair (N,W). Extra columns are saturated by h=1 in first row, extra rows pass through h=0. Parse actual tables, original IDs and boundaries. Standard exact-3-literal distinct-variable SAT is NP-complete; alternatively pad short clauses by fresh variables and paired clauses C OR y and C OR not y. Empty clause can be handled by a fixed contradictory 3-variable eight-clause input. A grid witness uniquely determines all local labels given row assignment (including padding bits); conversely vertical accumulation proves every clause true. Polynomial encoded length N=Theta(k²) including explicit masks; bit index overhead polynomial even if explicit IDs included.

Fix the grid, and distinguish WITNESS predicates H,V over the SAME two-bit code (N,W) at every cell from the INPUT predicate on table membership masks studied in L02-05. H requires row W constant, horizontal boundaries free. V requires column continuity N at next cell = S at previous cell, starts0 and finishes1. Membership is encoded by local two-bit code; physical word reconstructed by local h. Exact original satisfiability iff exists z H(z) AND V(z). Each H row can be read left-to-right with two live states (stored W); each V column top-to-bottom with two live states (expected N). Reset at line boundary, reject on mismatch. On reading N then W, H ignores N; V checks N against expected bit then uses W to update. Hence binary ordered read-once branching programs have at most two live nonreject states per layer, plus rejecting sink (width at most three including reject, depending convention). End acceptance handled at last layer. Different row-major vs column-major orders over identical code bits. With arbitrary unary local label filters, a constant-factor width expansion suffices (remember N within cell); equivalently four-symbol block automata remain two live states at cell boundaries. They compile to O(k²) typed deterministic decomposable gates separately via line interval composition; no common tree assumed. Chart construction and verification linear word work. The intersection problem is in NP (guess code and verify) and NP-hard by reduction even before/after saturation. This is an explicit native width specialization of known differently ordered OBDD consistency hardness, not a general monotone circuit lower bound. Conjunction evaluation on a supplied complete code is easy; existential intersection is the hard target. Do not confuse these operations.

## 2. Constructive closure and affine obstruction
For arbitrary Cartesian local domains D_ij, apply exact forward/backward automaton support on every row and column with actual boundary pins. Keep a label precisely if its preceding state reachable and its succeeding state co-reachable. Each pass O(k²) word work. At most 4k² deletions; O(k^4) fixed-point work (or worklist). Original guard filtering is simply unary filtering on a physical port at its original cell. This is certified unconditional per-chart closure on the unguarded instance; conditional on any explicit retained guard otherwise. On the unguarded reduction from clauses containing at least two distinct variables (or tautological columns), H initially deletes nothing. Every column clause permits both values of each row variable. V's first exact support pass therefore leaves both W fibres at every cell; H now still supports EVERY remaining label (choose that W across row, choose an available label independently at each other cell). V is already exact after its pass. Hence closure stagnates after one changing sweep and one confirmation sweep, or earlier if no deletion. This is true on SAT and UNSAT members. Since saturation can be performed uniformly before join, the NP-hardness is unchanged on outputs with this additional promise.

Stronger affine statement: encode local labels as physical port vectors, (N,W) codes, or full one-hot vectors. Let D_ij be saturated local labels. W is a linear functional of each vector (sum of W=1 one-hot coordinates if one-hot). Both W fibres are nonempty. For a row, affine hull of its actual H assignments is exactly the set of vectors z_i with each z_i in aff(D_i) and all W(z_i) equal. Proof: choose base b_i in W=0 and c_i in W=1. Differences within the same fibre independently generate the kernel of W on the local difference space: any other cross-fibre difference differs from c_i-b_i by within-fibre differences, and W(c_i-b_i)=1. Each within-fibre difference can be realized in a row difference by keeping all other cell labels fixed at that fibre. The simultaneous difference (c_i-b_i)_i realizes any common W change. This spans precisely the stated affine set over every field. Reverse inclusion follows from actual assignments.

For each column the projection of its actual V language onto W row bits is the corresponding clause relation with irrelevant bits free. This affine spans the entire field^k: choose a Boolean assignment making at least two distinct literals true, and its k single-coordinate flips; each remains satisfying. Tautological columns admit all bits. These differences are signed unit vectors over every field. Projection commutes with affine hull. Now prescribe any vector x in field^k: every column affine hull contains a vector with W=x, and concatenating these satisfies all row affine hulls by the previous paragraph. More strongly, choose any remaining label at any cell; exact V support supplies an actual column witness containing it. Its W vector extends affinely through all other columns, preserving that label, and satisfies all row affine hulls. Therefore the joint affine relaxation is consistent and gives no additional sound unary deletions, even when one tests membership of a particular full local label against it. This is stronger than separate local GF2/GF3 consistency. At stagnation repeating both closures changes nothing. No assertion for arbitrary guarded formulas, higher-degree algebra, integer constraints, or semantic closure using a complete SAT oracle.

Affine hulls need not be obtained by enumerating all witnesses: propagate for each automaton state an affine basis of actual prefix vectors, append each permissible next label, union bases from predecessor states and keep affinely independent vectors by elimination. Affine maps and finite unions preserve hull under these replacements. Each basis contains at most O(k) vectors in O(k) coordinates per line; rational exact rank on 0/1 vectors has polynomial bit complexity (minors bounded by Hadamard), fixed finite fields simpler. Retain actual prefix witnesses as basis vectors; no claim arbitrary affine mixtures are actual witnesses. Solve the resulting row/column affine system and test each local vector by linear equations in polynomial total time. This hull acquisition algorithm is proved but not executed end-to-end; finite checks below verify bases on W projections, not global Gaussian runtime.

## 3. Adversarial same-source neighbor and grouping bound
For r>=2, k=2^r, construct k columns C_a indexed by a in {0,1}^r, each containing exactly r literals and false exactly at x=a. Rows r+1..k are pass-through. All k columns together reject every active assignment; deleting ANY one column permits its unique excluded word. A genuine same-size SAT neighbor is obtained by changing the first cell of the column for a=(1,...,1) from h=NOT W to h=1 (add the positive literal). The table still has exactly four entries. That column becomes tautological; the active satisfying assignment is uniquely a, padding rows free. Witness lift is actual via accumulator. Both instances survive the complete chart-unary and joint affine closures above. Negative is not locally trivial after these closures.

Exact grouping statement (only shared active row variables, not all private accumulator labels): for any subset J of t columns, and any guard pinning g distinct active row bits, the guard subcube has 2^(r-g) words, of which at most t are excluded. If t<2^(r-g), the group is feasible. If t<2^(r-g-1), every remaining unpinned row bit has both values supported in that group. Without guards every proper group is SAT, and every group of fewer than k/2 columns has complete shared unary support. This is a lower bound on the group size needed by an explicit group-infeasibility test under these hypotheses, NOT on adaptive inference, arbitrary algebra, or time. In particular, the group formula has a simple polynomial bypass: extract h and discover r active rows (nonconstant h somewhere); for fixed assignment to these rows, column accumulators determined, inactive W bits can be independently chosen rowwise to meet any remaining unary physical guards. Enumerate 2^r active assignments, cost O(2^r k²) word work, exact lifting. On this family 2^r=k, so polynomial even with guards. Can also recognize the full forbidden-word set by sorting/hashing deterministically, with paid verification. No inference that polynomial recognition of this family extends to arbitrary 3SAT with r=Theta(k). This simultaneously tests exact composition and supplies a counter-algorithm to an alleged compulsory group enumeration. The two methods are automaton construction and affine/forbidden-word adversarial analysis of the same source.
