## Track A: exact asynchronous frontier-span theorem
Two supplied and authenticated linear charts over GF2, each processes each of b disjoint shared blocks exactly once in a permutation. Chart C has scalar acceptance e_C^T M_last(w_last)...M_first(w_first)s_C, a bit equal to the true regional acceptance for every input word. Fixed per-block allowed alphabets D_v, |D_v|<=K (or explicit paid word lists), with independent choices across blocks. Dimensions may vary by stage. Private interiors disjoint conditional on complete shared input, exact existential acceptance verified as a hypothesis, no dropped constraints. For deterministic source gate charts this follows from full local transition/source coverage. Nonfunctional charts need additional exact adapter.
At prefix indices (i,j), pending frontier H=P_i symmetric-difference Q_j where P,Q are sets of processed block IDs. Interleaving schedule is a monotone lattice path from (0,0) to (b,b); one chart advances per edge. Store for each assignment g to H the span W_g of actual joint tensors of the two prefix states arising from all partial words on P union Q with those pending values. Initial W_empty=span(s_A tensor s_B). At first occurrence of block v, for each actual allowed word w extend g by v=w and apply M_A(w) tensor I or I tensor M_B(w) to its span. At second occurrence use the SAME word stored in g, apply other chart matrix, erase v from key and merge incoming spaces by linear span. Inductively exact: every partial word extends by all allowed words when first seen, second encounter has no choice, all updates linear, merging exactly spans union of actual vectors. At end only empty key; joint acceptance functional e_A tensor e_B on W_empty vanishes iff every actual common input fails at least one region. No parity counting; no assertion that arbitrary span elements are reachable or valid Boolean states. If nonzero, keep an independent basis of actual images and predecessor records to find one accepting word (symbolic, not implemented). This is sound on YES as well as NO and not a promise-only proof.
For fixed orders, minimum frontier r*=min_path max |H| computed exactly by D(0,0)=0 and D(i,j)=max(|P_i xor Q_j|, min(D(i-1,j),D(i,j-1))), ignoring nonexistent neighbors. Recurrence follows by optimal last predecessor; reconstruct path. Naive explicit prefix bitsets and counts cost O(b³) bit operations, O(b²) entries and polynomial addressing overhead. Weighted block bits can replace cardinalities. With product dimensions d=d_A d_B (max), peak keys<=K^r*, each basis <=d, each update dense O(d²) per vector; total O(b K^(r*+1) d³) algebraic operations, including branch attempts and merges, plus input parsing and chart acquisition. Peak O(K^r* (d² + b log K)) bits for bases and keys plus matrices, path and provenance; retain all layers for witness replay if required, polynomial factor b. ## Track B: transpose and commutation hybrid
Transpose reversal theorem: reverse a chart's block order, replace each M by transpose, swap initial s and final e. New scalar e'=s, s'=e: s^T M_first^T ... M_last^T e equals the original scalar for every input by transposition. No inverse or reachability assumption; reversed intermediate vectors are algebraic states, not necessarily Boolean/source assignments. This is an exact output adapter, not physically reversing implications. Four orientation choices for two charts can be searched with fixed polynomial work. Apply same frontier theorem to transformed charts; source witness lift uses ORIGINAL gate chart on shared word. No source row reorder or guard mutation.
Certified commutation: for charts with a common constant state dimension, associate each transition matrix family with the original block ID. To move adjacent blocks u,v past each other, verify M_u(a) M_v(b)=M_v(b) M_u(a) for EVERY pair of allowed words. Then entire chart scalar unchanged for every input, regardless of prefix or suffix. A sequence of verified adjacent swaps aligning B to A preserves the full input/output function; use insertion sort with <=b(b-1)/2 proposed swaps, at most K² matrix pairs per swap, charge failure and abandon partial alignment if necessary. Cost O(b² K² d_B³), plus chart verification. No arbitrary matrix permutation allowed. For our parity-of-products charts matrices on (1,p) are [[1,0],[x*y,1]]; they commute for all words, so every requested swap valid. Align B to A, then alternate chart advances, frontier one block (a simultaneous update could have zero stored blocks). This is a real hybrid: algebraic commutation changes the frontier geometry used by Track A. Reversal solves reverse-order example even without commutation, though these particular matrices commute too. No exclusive overall benefit: direct parity identity also succeeds. Commutation works with source-derived matrices and preserves exact acceptance, not necessarily source intermediates; keep original maps for any lift.
Further complementary candidate at large frontier: identify local words inducing identical matrices on both charts, replace each word with its verified equivalence class and keep one actual representative; pointwise chart functions constant on each class, exact existential reduction of alphabet. This only compresses alphabet, not necessarily frontier. In family, AND effect gives two classes instead of four, still exponential in raw frontier; symbolic only, not executed.

## Stronger barrier: two constant-width charts can encode all of 3SAT
Symbolic, independently derived, not executed. For any 3CNF create separate shared bit for each literal occurrence (underlying variable value, sign applied only in clause check). Chart A processes occurrences grouped by clauses; a two-bit state (global validity, current clause OR) accepts iff all clauses pass. Reset OR at group start, update OR with literal, conjoin into validity at end. Chart B processes same occurrence IDs grouped by original variables; two-bit state (global validity, first value of current variable) records first bit, tests all later bits equal to it, accumulates validity. Both have at most four deterministic states per layer and O(number of occurrences) transitions, one-bit alphabet. Use one-hot vectors over GF2: each deterministic transition a 4x4 zero-one matrix with one 1 per column, final accepting indicator. These are exact linear charts on a common primary word but different orders. Both accept iff the occurrence word corresponds to an actual satisfying assignment of original formula. Native source can be clause constraints on occurrence bits plus equality chains in each original variable group (two clauses per equality), via same grid adapter; supplied charts certified locally by their group transitions; alternatively encode each functional constant-width state transition with constant-size truth-table CNF. Therefore deciding conjunction of arbitrary two supplied constant-width differently ordered charts is NP-complete (membership by evaluating word), even without acquisition problem. Universal polynomial reordering/alignment or refutation guarantee for all such NO instances, sound on all YES, would imply P=NP by capped scheduler. This is not a proof that it is impossible, nor a restricted-model LB promoted to all deciders. It locates the genuine NP-hard coupling beyond local chart width.
