## Theorem: affine bundle closure
Fix integer b>=1 and a constant c. Suppose each feature rank/length is <=c log2 N and there are at most polynomially many explicit factors and primary coordinates. Start with a verified affine guard A={x:Hx=d}; if empty refute. For every subset J of at most b ORIGINAL factors, define the exact feasible fiber F_J=A intersect all pullbacks R_j. Compute its affine hull (or detect empty) as follows. Parametrize A=x0+Ut. Stack feature maps for J, reduce to a basis of h independent forms on t, h<=sum_{j in J} rank(L_j U). Every one of the 2^h basis words is attainable on A. For each word reconstruct all feature coordinates including constants, test actual R_j. Exact attained set S_J in this basis. If empty, F_J empty. Otherwise obtain affine equations for aff(S_J) by span of differences from an attained word and orthogonal complement; pull back to original x. This is the EXACT affine hull of F_J within A, since the surjective affine map onto basis words has fibers cosets of its common kernel and every lift of a retained word is feasible for this bundle. A representative per word plus the kernel spans precisely the full preimage of its affine hull. No replacement of nonlinear factors by their hulls: retain all original factors and source map. Add only rows implied by current guard and J, then reclose. Each accepted independent row strictly lowers affine dimension, or inconsistency proves NO. At most n primary independent row imports; at most n+1 complete no-progress/changed rounds; one can also restart immediately after every import. If a full pass adds no row and no contradiction, return UNKNOWN, never SAT. Work poly(N) times (n+1) sum_{|J|<=b} 2^{sum rank(L_j U)} using polynomial basis operations per attained word; code enumerates all dual normals as well, at most 2^{2h} tests per bundle, still polynomial for fixed b,c. Exact private witness map stays with original factors; hull is only an overapproximation. Source pins propagated by grouped local truth-table arc closure after each import, and initial closure executed; at final plateau same source remains unchanged or rerun closure. Full semantic forced-information closure is not asserted, as that would solve the target itself on NO inputs.

This is a negative proof system with bounded-width ORIGINAL factor bundles and arbitrary affine deductions. It does not contain arbitrary previously learned nonlinear relations, arbitrary repartitioning, or general resolution. Termination bound holds for all inputs, coverage does not.

## Constructive infinite family: adaptive rank collapse
For m>=3 let X_i (0<=i<=m) and independent t_0,...,t_{m+1}. Require
(X_0 OR t_0) AND (X_0 OR NOT t_0);
for i=1..m, (X_i OR t_i) AND (X_i OR (t_i+X_{i-1}));
(NOT X_m OR t_{m+1}) AND (NOT X_m OR NOT t_{m+1}).
Addition is XOR, OR is Boolean. Seed pair entails X_0=1; terminal pair entails X_m=0. Every interior pair entails X_{i-1} -> X_i: if predecessor=1 the two clauses require X_i OR t_i and X_i OR NOT t_i. If X_i=0, both t_i=1 and t_i+X_{i-1}=1 imply predecessor=0. Hence UNSAT by induction. Each factor initially excludes a codimension-two affine set, full affine hull. Each interior pair prior to conditioning excludes union of two intersecting codim2 sets (fraction 3/8), hence feasible density 5/8, full affine hull. With predecessor fixed 1 the two features t_i and t_i+X_{i-1} become complementary; joint pair entails new affine row X_i=1. Thus independent rank drop creates new exact affine information in subsequent rounds. This is the actual hybrid: nonlinear local pair -> linear quotient -> altered exact pair support -> new independent linear deduction. Initial native grouped GAC has no pins. The unmasked family may be resolved by ordinary GAC once both endpoint pins are imported; no unique adaptive advantage claim for it. Initial static comparison assertion for unmasked instance failed; corrected by the following masking, preserving exact primary semantics.

Replace each X_i by p_i+q_i on two distinct independent primary bits (all other bits unchanged). Every original X assignment has lifts, so UNSAT equivalence; no individual primary pin from X_i alone. Distinct occurrence XOR gate IDs remain. Static pair hull scan at initial full domain yields ONLY two endpoint rows: two distinct forbidden codim2 sets must be disjoint to cover half the domain; otherwise their complement has >half density, full affine hull. Disjointness between factors can arise only through inconsistent assignments on intersecting row spans. For two interior factors from different i, their row spans have trivial intersection (each second row contains its unique t_i; removing t_i leaves distinct X_i), so their forbidden sets intersect. Seed/terminal spans similarly have trivial intersection with other groups except terminal versus last interior: intersection span X_m, conflicting X_m values; their union is half, but the excluded sets have different direction spaces (one involves t_m, other t_{m+1}); their union cannot be an affine hyperplane. Proof: a codim2 affine set contained in a hyperplane requires its normal span contain that hyperplane's normal. Common normal here X_m, but excluded sets impose opposite X_m values. Thus no extra affine rows. Within interior pairs forbidden sets intersect. Within endpoint pairs union is exactly a hyperplane. Therefore static initial pass yields X_0=1,X_m=0, no contradiction for m>=1. Native unary GAC has no pins because masked p_i,q_i remain free and imports do not impose direct local auxiliary aliases; even with endpoint linear rows available to the Gaussian solver, closure on actual grouped factors plus primary pins alone has no new pin. The tested adaptive solver repeats exact pair scans on contracted feature maps, with independent row imports and GAC after each. A static scan with later nonlinear reprocessing would no longer be the static model. There is also an independent cheap direct implication argument from the displayed clauses, so no superiority over every solver.

## Fixed-bundle impossibility theorem and algebraic bypass
For every fixed b choose fixed k>=3 with b<2^(k-1). Take any connected simple k-regular graph (e.g. bipartite circulant with n>=k vertices per shore, edges L_i R_{i+j mod n} for j=0..k-1). Edge bits x_e. At each vertex impose parity sum_{e incident v} x_e = charge_v; total charge odd. Expand each parity row into 2^(k-1) width-k clauses, one forbidding each wrong word. Present these clauses as ORIGINAL factors with standard coordinate features, no grouped parity initially. Encode into native grid via above CNF accumulator. Each forbidden event has uniform mass 2^-k in full primary cube. For ANY J of <=b original factors, union bound gives feasible mass >=1-b/2^k>1/2. Every proper affine subspace of GF2^n has at most half the cube. Consequently aff(F_J) is full cube, every allowed bundle gives no row or conflict, and arbitrary repeated affine closure stalls forever (even with adaptive choice of J and global coordinate changes). Initial unary GAC cannot fix anything since k>=3. This is a source-authenticated infinite UNSAT family, not arbitrary algorithm hardness. Sum actual vertex equations gives 0=1, every edge occurs twice. Acquiring all clauses with equal variable scope and checking their joint support is a uniform polynomial bypass for fixed k: enumerate 2^k words, recognize exact affine parity, import all rows and Gaussian refute. It is outside the fixed-b ORIGINAL factor restriction when 2^(k-1)>b, but inexpensive. For growing k, direct local table recovery remains polynomial in explicit number of clauses if the complete parity block is present; checking all distinct forbidden words have one parity and count 2^(k-1) suffices without enumerating 2^k if insufficient clauses. This shows that fixed-b closure is incomplete, not that every refutation must use exponential time. No expansion assumption or invocation of resolution lower bounds for the tested circulant graphs. If using actual bounded-degree expanders, known resolution width/size results separately apply to the CNF, not automatically to grid algorithms. No lower bound is transferred to arbitrary Boolean machines.
