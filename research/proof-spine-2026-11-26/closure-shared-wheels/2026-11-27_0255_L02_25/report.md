## A: lower bound for ordered-run representation
Two orders are fixed permutations, each block read once per chart. At (i,j) a pending run is maximal contiguous interval in one unprocessed suffix consisting of blocks already consumed by the other. Model stores exact joint tuple of current group states and ordered product for EACH pending run; first occurrence branches on its independent allowed input, and future consumption flushes entire maximal head run. The model explicitly retains all distinct attained tuples before final acceptance filtering, without further quotient, global deductions or alternate schedule transformations. Model not a general solver, not DNNF or arbitrary DAG lower bound.

For every monotone interleaving, consider first chart to consume exactly half the m² grid blocks (refine macrosteps temporarily). Other chart consumed <=half. If row chart first, it consumed m/2 whole rows; column chart's remaining grid suffix contains at least m/2 complete columns. Each such column contains one nonempty marked interval of m/2 cells, separated from the next by unmarked cells (even with traversal reversed). Thus >=m/2 distinct runs. If column chart first, symmetric. Removing six non-grid blocks in the order cannot increase run count because deleting entries in a binary mark string cannot create a new maximal 1-run. Reversing either full order leaves grid row/column traversals reversed and same half argument. Within a macroflush, no new pending run appears, because removing a marked head merely shortens/deletes it and other chart had already consumed these blocks. Therefore some actual macrostep boundary has >=m/2 runs, not only a refined interior. This disproves universal logarithmic run width. At such cut every run has at least one nontrivial group choice; independently toggle one block per run, all other read bits zero. Distinct choices give distinct joint run product tuples because runs are disjoint and both options have distinct group products. Each partial word attains a tuple in the unpruned functional trace. Thus literal enumeration of all exact attained tuples needs at least 2^(m/2) keys, even with optimal whole-run schedule. Since k=Theta(m²), N=Theta(m^4), this is 2^Omega(N^(1/4)) for that model. The bound is about partial words before terminal filters, not the empty SAT witness relation, nor after global deductions. Any compression or earlier negative certificate invalidates the transfer to unrestricted work.

## B: inversion-selective normal quotient (hybrid)
Let G be a finite explicit group, with the same set of input blocks in orders A and B, each block v choosing label g_v(w) in G for allowed local word w in D_v. Two charts multiply in their respective orders from identity and accept terminal sets T_A,T_B. For pair (u,v) appearing in opposite relative order, form every commutator (ba)^(-1)(ab), a in labels(u), b in labels(v). Let H be their normal closure, and pi:G -> G/H. All inverted pairs commute in quotient. Bubble-sort A to B by adjacent swaps of inverted pairs only; for every fixed shared word each such swap preserves quotient product. Therefore pi(P_A(w))=pi(P_B(w)). H is the smallest normal subgroup making every specified inverted label pair commute: any admissible normal subgroup contains all generators and their conjugates, hence contains H. This is finest quotient for these universal pairwise local commutations, NOT necessarily finest semantic quotient on attained complete words.

Exact certificate for NO: if pi(T_A) intersect pi(T_B) is empty, reject; also if exact reachable quotient products in A order avoid that intersection, reject. The latter is acquired by finite DP from identity, multiply each retained quotient class by each allowed label and deduplicate; every reachable quotient class attained by some word when D_v independent, no counting oracle. For correlated guards, either include an exact independent adapter or use product of domains as a sound overapproximation for NO only. If intersection reachable, output UNKNOWN, not SAT. Original quotient is a homomorphic relaxation, not exact lift. When each original target is a union of H-cosets and independent domains are exact, common quotient reachability is sufficient for original YES, but that extra hypothesis is not used here. Same labels and known order maps necessary; no free chart recognition. For group table size s, verify associativity, identity, inverses in O(s³) table lookups, enumerate inverted pairs and label products O(b²K²), conjugate distinct generators by all s group elements, close subgroup by BFS multiplication of generated set; finite closure includes inverses by finite orders. Form cosets, check congruence by all s² products and verify inverted labels commute. Quotient DP O(bsK), all indices O(log(s+b)) bits, polynomial if explicit group/label tables and source adapter polynomially acquired. Even if H nonabelian, proof works. Full abelianization kills ALL commutators; H subset derived subgroup, quotient can preserve extra noncommuting information that is never reordered.
