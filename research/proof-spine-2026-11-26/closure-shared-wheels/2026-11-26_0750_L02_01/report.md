## 2. Independently reconstructed source hardness

Boundary allowed sets are {0},{1},{0,1} independently (can absorb them into vertex tables). Decide if every vertex's four port bits belong to its table and all shared edge bits agree. NP membership by O(k^2) witness and verification.
Reduction from arbitrary 3-CNF with n distinct variables and m clauses: normalize variables to consecutive IDs, k=max(2,n,m). Row i carries a horizontal variable signal W=E; column j carries vertical accumulator S=N OR h_ij(W), where h_ij(b)=1 iff at least one occurrence of variable i in clause j is satisfied at b, else 0. For unused rows or columns h=0. North boundary pinned 0; south pinned 1 for j<=m, 0 for padded columns; west/east free. Each cell enumerates 16 words and sets precisely the permitted bits. Repeated literals and tautologies handled by OR over actual occurrences; empty clauses remain 0 and fail bottom pin. A satisfying assignment lifts by propagating row bits and column prefix OR. Conversely horizontal equality determines each row value; induction gives final column OR, forcing every original clause true. ## 3. Exact circuit model
Fix k and boundary pins all zero for lower-bound restriction (the full decision function must be correct on these inputs). Source blocks are vertex tables, each 16 bits. Circuit is a finite acyclic Boolean DAG with output scope V; fan-in 2 AND/OR, arbitrary unary block predicates and constants as leaves (scope one vertex or empty). Gates have syntactic scope union of descendant leaf scopes, even for redundant tests. No internal NOT; literal negation within leaf allowed. OR smooth: both children have same scope as parent. Constants may have empty scope. Circuits may reuse gates freely; size s counts distinct gates including leaves. A true trace is an unfolded rooted tree keeping both AND children, one true OR child and true leaves. Repeated occurrences of same DAG gate are not merged in the trace. By induction every trace through g has leaf-scope union exactly S_g; smooth OR essential for this version. For each occurrence of g in a root trace, external context is the tree with that occurrence and descendants removed; context scope C is union of its remaining leaf scopes. Context predicate is conjunction of remaining leaves, with fixed OR choices. A context may contain another occurrence of g. Overlap is **total contextual overlap** J=S_g intersect C, not merely intersection of immediate children, nor number of shared DAG nodes. Assumption: every accepted singleton input has some true trace and some balanced occurrence on it with |J|<=b. Sufficient but not necessary: all balanced occurrences in all true traces obey that cap. Singleton inputs use exactly one allowed local port word per table, fixed-zero external half edges. This is a source restriction on input table bits, not a chosen fixed instance.

## 4. Balanced trace existence and safe context grouping (separate lemmas)
Every true root trace has a balanced gate occurrence with k^2/3<=|S_g|<=2k^2/3: follow a child of largest scope at AND, selected child at OR, while above upper threshold. OR does not shrink scope by smoothness, AND largest child has at least half parent's scope even with overlap. Finite DAG reaches singleton leaves; at first crossing of upper threshold the chosen child is >= k^2/3. This proves balanced occurrence existence only; bounded contextual overlap is an additional model hypothesis.
Fix a balanced g, a set J subset S_g of size<=b, and a singleton word assignment z in {0,1}^{4|J|}. Define A(g,J,z) as all singleton block words on S_g for which g evaluates true and which restrict to z on J. Define B(g,J,z) as union over actual trace contexts with scope intersection exactly J of singleton assignments on V minus S_g that satisfy that context when its J words are z. Every context outside g depends only on J plus outside blocks. Empty cases allowed. For any pair a in A, d in B, choose the context witnessing d and use a true trace for g under a. Substitute at the distinguished occurrence only. Other occurrences of g, if any, remain in context and their leaves still satisfied because a and context agree exactly on J. All leaves of new root trace are true, hence full circuit accepts; since circuit correct on singleton inputs, this is a valid grid assignment. Conversely an accepted singleton input with a low-overlap balanced occurrence lies in corresponding product A x B. Union over contexts is safe only after fixing g,J,z; do not separately union inside factors varying with context or forget z. Number of groups <=s D, D=sum_{j=0}^b binom(k^2,j) 16^j (cap b<=k^2). This counts rectangles nonconstructively; no efficient enumeration of exponentially many traces claimed. A fixed per-gate set J0 covering all chosen overlaps allows grouping using its full word z, even if exact intersections differ, then D<=16^|J0|. No need to enumerate contexts to prove existence of cover.
Unsafe grouping example: gate accepts either x, two contexts require x=y with pairs 00 and 11 separately. Union of outside projections and gate accept set includes 01 and 10. Pinning x and keeping labels repairs. This occurs already in equality of two incident singleton port words. Proof by contradiction for any cross splice uses mismatched port equality.

## 5. Rectangle lower bound (PROVED under above scope)
Valid singleton inputs in fixed-zero boundary subclass are in bijection with independent binary assignments to the M=2k(k-1) internal edges. There are 2^M distinct accepted input tables; each invalid one-port flip on an internal incidence is genuine NO. Every balanced vertex partition has >=ceil(k/3) crossing edges. If at least k/3 rows mixed, each contributes a horizontal crossing. Otherwise mixed rows occupy <k^2/3 cells, so each shore (>=k^2/3 vertices) has a full row; every column has a vertical crossing between the full rows. For any nonempty sound rectangle across this partition, each crossing edge's bit is fixed: if two accepted inputs in it disagree, cross-splice their inside/outside blocks, producing inconsistent singleton endpoints, a contradiction. Thus a rectangle contains at most 2^(M-ceil(k/3)) valid inputs. Coverage and group count yield
 s * sum_{j=0}^b binom(k^2,j) 16^j >= 2^ceil(k/3).
For exact decomposable circuits (AND child scopes disjoint), all context intersections empty, including shared nodes, so s>=2^ceil(k/3). For polynomial s in N=Theta(k^2), b=Omega(k/log k); more precisely log2 D <= log2(b+1)+b(4+2log2 k). If fixed per-gate overlap cover size b, s*16^b>=2^ceil(k/3), yielding linear b for polynomial s. Stronger partial coverage: even absent universal overlap cap, fraction of accepted singleton inputs admitting ANY balanced occurrence with |J|<=b is at most min(1,sD*2^-ceil(k/3)). No runtime inference. Bova et al. DNNF balanced multi-partition theorem (IJCAI 2016 Theorems 1,6) is known analogous disjoint-scope construction, not evidence of arbitrary overlap coverage; our block-leaf/smooth version proved directly.

## 6. Adversarial easy bypass and exact matching upper control
On the identical singleton restriction, every local word is uniquely forced by the input. Initial certified domain closure reads each word and checks adjacent endpoint equality and boundary bits; all YES have actual unique edge assignment; every flipped internal endpoint NO has local contradiction. Repeat after any literal guard: compare the fixed edge bits with the guard, reject conflict. At stagnation all edges already forced; no search. Equivalently, Boolean equality / GF(2) unit propagation solves in linear graph work; explicit 2-variable tests also suffice. No matching needed. For arbitrary tables outside this subclass no claim unary closure is complete.
Build small smooth block-local NNF for the singleton consistency predicate (NOT full grid language): each edge factor is OR of <=256 disjoint-scope two-block ANDs testing its endpoint words and their matching bit; all its OR child scopes equal the two endpoints. Boundary tests unary. Conjoin edge factors incrementally in any order. All ANDs have immediate child overlap <=2 and O(k^2) gates (finite per factor). Nevertheless a balanced prefix occurrence can have linear contextual overlap: every crossing edge factor must appear outside that occurrence since its scope includes a vertex outside S_g; its inside endpoint is shared. Degree<=4 gives >=ceil(k/3)/4 shared vertices. This defeats any claim that the formula of section 5 holds with b interpreted as local AND overlap on the singleton function, or that local overlap alone yields the required contextual cap for arbitrary NNF. Not a small solver for all explicit tables. Same source, same pin scope; demonstrates why accepting many singleton inputs is not by itself a difficult computation. Per-instance preprocessing may know all table values and collapse to constants; circuit lower bound concerns a fixed all-input representation, not representation constructed separately per input.
Full source upper control: row-major frontier DP on k-by-k grid retains at most k+1 edge bits (one north/south frontier per column plus current west). At each vertex, for every compatible port word, AND unary predicate T_v contains that word with suffix state function; OR all choices. Fixed/free boundary pins filtered locally; no choice across an edge omitted. Disjoint vertex scopes in each AND, smooth OR over remaining vertices (pad false branches with syntactic tautologies if needed). At most 16 choices per state, k^2 positions and <=2^(k+1) states. Thus uniform block-decomposable circuit of size O(k^2 2^k) up to constant factors, exact for general local tables; construction and evaluation charged same scale times poly(N) bit overhead, witness via chosen transitions. With lower bound this gives 2^Theta(k)=2^Theta(sqrt N) size for this restricted circuit model (polynomial factors absorbed), not an unrestricted lower bound. DP executed at small sizes for actual reduction; no full gate DAG built in tests.
