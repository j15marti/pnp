## Theorem and proof
Let the current verified affine guard A=x0+Ut, t in F2^d. A forbidden fiber E_i is given by explicit linear equations in x (a clause is a special case), translated into t; discard inconsistent fibers and normalize the remaining equations to independent rows. Let r_i<=h be the original/contracted row rank. Assume no assignment lies in more than b forbidden fibers, where b is a fixed constant (called t in the code/overview, not the coordinate vector). Verify this without assuming the promise: enumerate each (b+1)-subset of original fiber IDs, Gaussian-check their conjunction; if any feasible, return OVERLAP/UNKNOWN. Infeasible guard itself is NO. For every nonempty J of size <=b obtain its intersection via elimination, skipping empty ones. Let f(t) be the indicator of satisfying every factor in this region. Exact integer inclusion-exclusion gives
f=1+sum_{1<=|J|<=b}(-1)^|J| 1_{intersection J}.
Proof pointwise: at a point belonging to a violations, a<=b, sum_{j=0}^a (-1)^j binom(a,j)=(1-1)^a. This uses actual joint assignments, not independent marginals or parity counting.

For a nonempty intersection with independent rows L t=v of rank r<=bh, its normalized Walsh expansion is
1_{Lt=v}=2^{-r} sum_{lambda in F2^r} (-1)^{lambda dot v} chi_{L^T lambda}(t),
where chi_u(t)=(-1)^{u dot t}. Orthogonality of the characters proves this by summing each bit of lambda. Thus acquire the complete sparse dictionary of f by enumerating <=2^{bh} coefficients per intersection, combining identical global normals with exact signed addition; cancellation is legitimate and retained. There is no need to enumerate 2^d or 2^{rank of all stacked features}.

If fhat(0)=0, region is empty since f is nonnegative. Otherwise a normal u satisfies a valid affine equation u dot t=e on every feasible point iff fhat(u)=(-1)^e fhat(0). Proof: fhat(0) is normalized support size, fhat(u) is difference of counts of the two possible signs; equality in absolute value requires one count be zero. Conversely a constant sign gives equality. Hence scan only nonzero dictionary entries and take a basis of these extremal normals. This is the EXACT affine hull, since the annihilator of all differences of points of a nonempty set defines its affine hull. No nonlinear factors are replaced by an overapproximation; retain them, import only implied equations, and optionally rescan after guard contraction. If an exact affine replacement is desired, compare fhat(0) to 2^{-rank(normal space)}: equality implies the feasible set fills its affine hull. Guard-coordinate equations can be pulled back by a left inverse of U; charge solving this linear system. The theorem applies to arbitrary shared variables, no private disjointness assumption. Source adapters must be exact, paid and guard preserving.

## Source family: scope-hidden odd-charge parity
For k>=2, s=2^{k+1}, use a connected simple bipartite k-regular circulant graph on 2s vertices, edges L_i R_{i+j mod s}, j=0,...,k-1. Each edge has original bit x_e. Set vertex charge 1 at L_0 and 0 elsewhere. At each vertex list wrong edge words w (parity unequal to charge), ordered lexicographically by binary numeric word; j(w) indexes the list. There are 2^{k-1} shared pairs (a_j,b_j) globally, used by ALL vertices; no private variables or free existential witness elimination. For each wrong word impose four ordinary clauses excluding respectively the following affine cubes:
(edge word=w, a_j=0);
(edge word=w, b_j=0);
(edge word=w, a_j=0,b_j=0);
(edge word=w, a_j=1,b_j=1).
Every assignment to a_j,b_j violates at least one of these cubes when edge word=w. (00 violates three; 01,10,11 one each.) Different wrong words are disjoint. Thus each complete regional feasible indicator is EXACTLY the required edge parity, independent of all shared hub coordinates. The triple violation at 00 means multiplicity 3, not 2. Summing vertex rows over GF2 yields 0=1 because each edge appears twice. This is independently established UNSAT for every k, not inferred from failed solvers. Third cube redundant in this raw-CNF encoding; the two equality cubes together would otherwise encode a single affine fiber a_j+b_j=0. The nonredundant triple of affine fibers is a=0,b=0,a+b=0, each necessary to cover all four words; the tested CNF version explicitly splits the last fiber and includes the redundant 00 cube. No irreducibility claim.

Acquisition from raw clauses: count occurrences of each ID; each edge appears 4*2^k=2^{k+2} times, each hub bit 3*2s=3*2^{k+2} times. Select IDs with frequency strictly greater than half the maximum, then group clauses by sorted residual scope with these IDs removed. This recovers exactly the vertex groups (distinct incident edge sets, k>=2 simple graph). This is a polynomial candidate generator for the family, not a general guarantee. Source-check each acquired region using multiplicity and spectral theorem; no need to trust the scope heuristic. Same full-scope grouping yields no affine rows: at most two clauses per identical scope and feasible density >1/2. Even every fixed-size original-factor bundle b0 stalls if b0<2^k by the union bound (individual forbidden mass <=2^{-(k+1)}). All variables occur in multiple regions; no pure private-coordinate elimination. A cheap direct parity recovery by grouping wrong edge words and testing their two hub bits also works, so the spectral method is NOT an exclusive speedup over all algorithms.

For each vertex the stacked coordinate rank is k+2^k, even though each forbidden rank <=k+2. Explicit joint word enumeration needs 2^{k+2^k} entries; N=Theta(2^{4k}) under padded grid encoding, giving superpolynomial representation expenditure for the prescribed explicit-table terminal. This bound applies only to a terminal enumerating all raw feature words, not arbitrary bit computations, compressed tables, or general balanced-rectangle representations. In contrast, the regional spectrum has exactly two entries and is acquired polynomially by the proved method with b=3. Stronger than fixed-b original-factor scanning; not stronger than every other semantic regrouping. A full-grid all-decider transfer remains OPEN.
