## A. Exact sumset and local-period quotient
Make one copy per distinct carrier occurrence in each factor. For a carrier appearing in several factors, choose a reference occurrence and add one binary equality row to each other occurrence. Linear map L_i sends local factor word to its contribution in the common equality-row space. For nonempty local table R_i select any attained baseline a_i; S_i={L_i(x+a_i):x in R_i}, with one actual local lift per vector, and b=sum L_i(a_i). Then original compatibility is exactly b in sum_i S_i over GF2. Both directions: zero total equality syndrome iff every original copy agrees; baseline translation adjusts target, no marginal joining. For separately retained global affine constraints include their rows in L_i using explicit occurrence mapping and RHS. All local sets explicitly listed, each contains zero. For no B factors decide signed equality feasibility. Empty local table yields NO. If b outside span of all S_i then NO.

H_i={h:S_i+h=S_i} is a subspace, computable by testing h in S_i (0 in S_i) against all local words. Let H=sum H_i. Then global attained sumset S+H=S. For quotient q by H, b in S iff q(b) in sum q(S_i). Proof of lift: choose actual local representatives, the difference from b belongs to H; express difference as sum h_i in H_i and translate each local representative by h_i. These translated vectors are attained and original local witnesses lift through stored maps. This is an exact period quotient, not replacing S_i by hull. Every nonzero quotient removes rank; projected sets do not grow, repeat to fixed point. Bit cost polynomial for explicit sets, including coefficient/witness replay. For unguarded native B4, complement of all local distinct carrier bits maps allowed words to allowed words, so its syndrome difference is a period (possibly zero). If zero, each complement pair already coincides; otherwise quotient identifies the pair. Thus each nonempty native factor has at most 3 distinct attained vectors after quotient. Same property under literal pins on normalized carriers: a pinned local coordinate admits at most one word from each original complement pair, and an untouched factor retains complement pairing; further local support closure only deletes words/pins and retains exact guarded system. Arbitrary nonlinear guards not assumed. This is a UNIVERSAL exact polynomial reduction for native original inputs, not universal polynomial decision.

## B. Largest independent-transversal-saturable block
Write W_i=span S_i, r(J)=dim sum_{i in J}W_i. If r(J) independent vectors can be selected from distinct groups J, each vector ACTUALLY in S_i, they form a basis. Select either zero or that one attained vector in each chosen group to realize every vector of W_J. Thus sum_{i in J}S_i=W_J. Remove J and quotient all other groups and target by W_J. Both directions reconstruct a residual lift by solving in acquired basis and selecting actual local words. Do not assume an arbitrary sum of multiple words from the same group is attainable.

Find a maximum independent partial transversal I on labeled nonzero vectors (i,v), using partition and linear matroid intersection, deterministic polynomial rank operations (Rado/Edmonds). Implemented greedy then shortest augmenting paths: start at unused group, try its actual vectors; an out-of-span vector augments, otherwise its unique representation in I gives exchange arcs to selected groups with nonzero coefficients. Use group BFS and store parent choice. Verify independence of result after every augmentation. Define directed dependency i->j for each coefficient of selected vector j in any in-span vector of group i; mark i bad if any vector outside span I. Safe set U is groups from which no bad group reachable. Maximality ensures all unused groups safe (otherwise augmenting path). By closure, W_U equals span of selected representatives in U. For any J, r(J)>=|I selected in J|, hence f(J)=r(J)-|J|>=-(m-|I|). U attains equality since contains all unmatched groups. Every minimizer must contain all unmatched groups and have W_J=span of selected representatives in J, so closed under dependencies and no bad; it lies in U. Thus U is unique largest minimizer of symmetric-free submodular rank-minus-cardinality f. Furthermore any independent-transversal-saturable block J lies in U: basis from distinct groups implies r(J)-r(K)<=|J\K| for every K subset J; r(U union J)-r(U)<=r(J)-r(U intersect J)<=|J\U|, so U union J also minimizes f. Therefore this is maximal among blocks certified by ONE vector per group, not maximal among all true saturated sumsets. On quotient by W_U, for every nonempty J outside U, r_quot(J)-|J|=f(U union J)-f(U)>0. Exact strict excess. Certificate soundness only requires checking attained selected representatives independent, spanning W_U and quotient; maximality requires exchange/minimizer proof, not free oracle. Explicit implementation verified by exhaustive subset minimizers on 240 small tests.

## C. Universal strict-excess ternary core and cost
After native period quotient sets size<=3. Every singleton or two-word set is a subspace and independently saturable. After largest block quotient each remaining group has exactly 3 words {0,a_i,b_i}, a_i,b_i independent, and every nonempty J has rank> |J|. Let m remaining, r=global rank. If m>0, m<r<=2m, residual affine nullity d=2m-r<m. Exact core: Boolean z_i,t_i with sum_i(a_i z_i+b_i t_i)=b and z_i t_i=0 for each group. The two local bits uniquely encode the three choices. No nominal 2^r counting: when d<=C log2 N, Gaussian chart enumeration of 2^d actual affine candidates and NAND checks is uniform polynomial under fixed C. If residual empty, decide target zero. All admitted quotient transformations preserve original witnesses via stored lifts.

The strict-excess ternary core decision language is NP-complete, not just claimed hard on one family. Every original strict E/B instance maps in polynomial time to this core or a sound decided case. For decided cases map to fixed one-triad {0,e1,e2} with b=0 (YES) or b=e1+e2 (NO); both strict. NP membership explicit (validate strictness via polynomial Rado search, verify choice witness). Reverse adapter to E/B if desired: one NAND per pair, parity equations via fresh XOR chains and their exact forbidden-word CNF, pinned compiler. Same argument applies after exhausting the three-group pattern rule below (fixed one-triad has none). Thus exact normalization alone does not resolve universal progress. Period/quotient and block operations charge decreasing potential m+r on consistent target-span instances; rank decreases for nonzero period, factor count decreases for any retired block. At most O(N) successful changes since original syndrome dimension and group count O(N); local set counts never increase. Deterministic polynomial acquisition and checking for each pass, include all failures, maps and serialization. Explicit bound can be given via naive rank/exchange scans with polynomial factors in total explicit row length; no measured bit tariff. ## D. Strict-excess counterexample and new shared-hub exact saturation

For a target x+y, x in W1,y in W2, varying the 3 actual hub choices in W3 excludes at most one choice per first/second hole, hence one remaining hub choice realizes target exactly. This verifies all 16 words with actual lifts; works for any missing word and translates, not only displayed canonical triads. General higher-dimensional version: independent blocks U_j, each actual table U_j minus one point, hub graph injective onto each block, |S_hub|>number of blocks, same union bound yields exact full sum space; acquisition of such general hubs not proved. Verify 27 actual sums cover 16, then exact quotient/retire three groups, rerun period and Rado. O(m²) pair scans per pass, constant per pair (plus polynomial bit operations). Every successful step decreases m+r. Not necessary condition for arbitrary saturation.
