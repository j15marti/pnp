## Track B: ordered-run future-effect quotient theorem
General setting: two authenticated charts read the same b disjoint blocks once each in distinct fixed permutations. Each allowed word belongs to independently specified D_v, |D_v|<=K. Deterministic charts with states S_A,S_B and transition maps, or linear charts over GF2 with state dimensions at most d. Every chart terminal is exact Boolean regional acceptance on each common word; for linear charts scalar output must equal this bit. Source private interiors disjoint conditional on complete shared word. All source constraints checked by charts or independent block domains. No hidden extra guards. We do not assume commutation, invertibility or linearity in the block word.

For a prefix pair, consider each chart's *unprocessed suffix*. Mark block IDs already processed by the other chart. Partition marks into maximal consecutive runs in that suffix. These are pending runs, one side or the other. A run stores the ordered composite transition on its future consuming chart, not product in first-consuming order. Maintain a fixed, word-independent schedule:
(1) if advancing chart's next block has not occurred in other, consume first occurrence, choose one allowed word, update that chart, insert its future transition at its exact position in other chart's suffix. It either forms a singleton, extends one run or joins two adjacent runs; compose in future order. No other old run is split.
(2) if next block already occurred, it is head of a pending run. Consume the ENTIRE maximal run in a macrostep, apply its stored composite to active state and delete it. No other chart needs these words again, and no run is split.
All schedules monotone and terminate after <=2b macrosteps. Flush entire run is essential. Proof of update templates: on first encounter exactly one new mark is created in other suffix, and advancing chart's removed first unmarked position cannot split marks; on second encounter remove initial maximal marked interval, no new marks. Every existing run is used exactly once in transition except the flush, where it acts on consuming state. No copying or diagonalization of an unknown run product.

Finite monoid case: if all transition maps of both charts lie in known finite monoids with at most s elements (separately, composition explicit), keep joint set of (stateA,stateB, product per run), not independent marginal sets. Two partial words with same tuple give identical future effects along fixed schedule: same new word update maps and same flush products; induction over remaining macrosteps. Every tuple represented is attained by an actual common partial word, and every actual partial word's tuple is represented. At completion no pending runs; test actual joint terminal state acceptance. Witness reconstruction may store actual predecessor per retained tuple and choices for first encounters, then replay original charts and native lift; not implemented for general charts. If peak run count t, state counts q_A,q_B, <=q_A q_B s^t tuples, each transition O(K) candidates per tuple (flush 1). Paid run list and composition bookkeeping polynomial in b, map representations and t. For fixed q,s,K and t=O(log N), exact polynomial decision under separately charged chart acquisition. This is exact future-effect quotient, not an assertion of complete semantic equivalence recognition.

Each old factor used exactly once, so update extends to a linear map of the *whole joint tensor* by universal property of tensor product. For flush, matrix action on consuming state is bilinear, hence linear on their tensor factors. Permutations of tensor factors linear.
