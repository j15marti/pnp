## A. Exact rank-cut theorem and component relationship
Collect all local affine equations by enumerating actual local table differences (bounded original B arity), solve by Gaussian elimination. If inconsistent, certified NO. Otherwise write A=a+K, K linear. For S subset of factors, T=complement, J=X(S) intersect X(T), define lambda(S)=dim projection_J K. Candidate shared words exactly pi_J A, cardinality 2^lambda. Let actual regional supports be P_S, P_T (existential projections onto J of exact conjunctions). Affine pruning restricts each to pi_J A. For any partial witness of S with boundary word in pi_J A, take a global affine point with that word; replace its S-private variables by the partial witness. Every S local hull and every T local hull still satisfied; guards treated locally. Thus this partial witness is compatible with the GLOBAL AFFINE relaxation, even if not with actual T. This proves recursive pruning completeness for actual regional tables restricted to pi_J A. If only sound decision required, even a stronger globally implied affine carrier can be used as a necessary filter; never infer a spurious SAT from a guard that was not explicitly enforced. In a binary tree with leaves exact acquired relations, compute child tables, join on every common original variable, project to parent boundary and discard words outside pi_J A. Proof by induction: any full witness appears at every node; any retained word has an actual subtree witness, by joining witnesses that agree on all overlaps. For exact partial support under local-hull A use previous extension argument. Root boundary empty; table empty iff NO, else lift by storing child pointers and leaf witness maps. No counting claim.

If maximum lambda over tree cuts is w, each table <=2^w actual words. Pairwise join cost O(poly(N) sum over internal nodes 2^(lambda_left+lambda_right)), <=poly(N) 4^w. More precisely replace each 2^lambda by actual acquired table size a_i. Store original ID bitstrings or independent affine coordinate encodings, all arithmetic bit lengths polynomial. Output/support checking, tree construction and all failed candidates separately charged. Peak polynomial when w<=C log2 N and fixed C; cumulative <= time*peak on same sequential run. ## B. Relation to subspace branchwidth: exact invariant and uniform discovery
For every factor make one copy of each carrier occurrence (one per distinct variable per factor). For every variable v choose a reference occurrence, put a binary equality row linking it to every other occurrence (star). Pick global affine point a; local variation space K_i=aff(R_i)-a|X_i. Define W_i as image of K_i in the common equality-row space: a local variation contributes its bit to each equality row incident to its copy. W_S=sum_{i in S}W_i. Then lambda(S)=dim(W_S intersect W_T).
Proof: a globally consistent variation contributes same partial syndrome on S and T. Internal equality rows have contribution0, crossing rows carry the shared carrier's variation. Every shared carrier has at least one crossing star edge. Thus the map from shared boundary variation to the common syndrome is injective. Conversely, any w in intersection has realizations by local variations on S and T; concatenate them, total syndrome zero, hence all copies agree, yielding one globally consistent variation. This gives surjectivity and equality of dimensions. The rank function r(S)=dim W_S is submodular: W_(S union T)=W_S+W_T and W_(S intersect T) subset W_S intersect W_T. lambda(S)=r(S)+r(complement S)-r(all), symmetric submodular with empty value0. Hence exactly a connectivity function and precisely the subspace-arrangement branchwidth studied by Jeong/Kim/Oum. No graph-planarity assumption and invariant under invertible row-basis changes of equality equations. A rank oracle is explicit Gaussian elimination, polynomial in N; no semantic oracle. Conditional on cited theorem, it yields uniform polynomial acquisition for w<=C sqrt(log2 N), fixed C, then exact DP; logarithmic width acquisition is not proved polynomial by that bound. Known theorem not implemented or independently audited in full; own exact cut identity is self-contained. It is NOT a lower bound on arbitrary algorithms if w is large.

## C. Guard alignment, aggregate tariff, and exact contraction monotonicity
In free affine coordinates t write carrier x_v=c_v+ell_v(t). Let U_J span the boundary observation coefficient forms and U_G span independent guard coefficient forms (g=dim U_G). For each consistent guard word, rank after conditioning is
lambda_g(J)=dim(U_J+U_G)-g=lambda(J)-dim(U_J intersect U_G).
This is equality for the restricted affine carrier before new local deductions; further sound strengthening can only lower rank. It is independent of which attainable guard values are chosen. Exactly 2^g affine guard words. The sum of candidate single-cut table caps across all guards is 2^(lambda+g-dim intersection)>=2^lambda. Therefore splitting does not itself reduce total output bound. However a binary join with child subspaces U_L,U_R has aggregate pair-bound factor relative to unguarded 2^(g-dim(U_L intersect U_G)-dim(U_R intersect U_G)). Guarding a g-dimensional common direction subspace in BOTH child spans cuts this pair-bound by 2^g even after paying all branches. Guard aligned with neither side increases bound; aligned with one side alone does not help this bound. A true improvement of bound is not proof of measured speedup; actual tables may already be sparse. This yields a source-checkable criterion to choose shared global guard directions by their overlap with multiple high-rank cuts, rather than random variable splitting. Implemented heuristic chooses two original carrier bits minimizing sum of squared single-cut rank caps, not claiming globally optimal binary-tree tariff; selection, failed candidate computations, all four guards and reclosure charged.

If exact conjunction of two or more factors is replaced by its full attainable relation on the surviving exterior variables (with local guard restrictions), the new local hull is contained in the affine projection of the old local-hull system. Indeed exact regional witnesses satisfy old hulls; their affine hull lies inside that affine projection. Any solution of new joined affine hulls lifts to old joined affine hulls because outside factors use no retired private variables. Thus A_new subset pi_remaining A_old. For every surviving cut corresponding to a union of old factors, new boundary scope subset of old scope and rank cannot increase. Exact merge strictly decreases factor count and cannot increase carrier count or global affine dimension. Use Phi=m+number of surviving carriers+dim A (or keep proved global linear rows separately with same dimension budget); successful merges or independent affine constraints reduce numeric Phi by >=1, no new variables. This yields <=O(N) admitted contraction rounds if tables/intermediate total representation are capped by a fixed N^a and all acquisition and failed scans per round are paid. It is not a claim that arbitrary exact merges have polynomial output or are discoverable. Guard branching is charged separately across all children by above tariff or a proved cover; cannot simply charge only a favorable child. First open arrow is universal acquisition of a productive admitted contraction, exact small-width tree/attained join or alternative certificate on every remaining NO.

## Falsifier to universal low coupling width (same source through explicit adapter, symbolic)
Consider n>=3 x_i and n y_j, all n² cross NAND(x_i,y_j), odd parity of x group and odd parity of y group. Exact NO: each odd parity requires at least one true bit, whose cross NAND forbids joint truth. Encode long parities by ternary XOR chain and two-bit final equations, all NAND and parity tables encoded by forbidden CNF words, then pinned strict E/B compiler. After exact regional recovery of those original tables (constant arity, provenance-assisted adapter sufficient here), every NAND has full affine hull; parity constraints leave projection on x,y dimension2n-2. Any subcubic decomposition of these factors has a cut balancing NAND leaves (weight1 on NAND and0 on others) between n²/3 and 2n²/3, by weighted centroid. Color each NAND edge by its side. If fewer than n original x/y variables are incident to both colors, each bipartite shore has a pure variable. All pure variables have the same edge color because complete bipartite graph joins any pure x to pure y; if opposite pure x colors existed no pure y could exist. Thus edges of other color have both endpoints mixed. With fewer than n mixed variables there can be <n²/4 such edges, contradiction. Therefore at least n shared x/y variables. Projection of two parity constraints loses at most2 dimensions there, so lambda>=n-2. This is a lower bound on branchwidth of the SPECIFIED factorization (not arbitrary re-factorizations of the native source). Compiled native N=O(n² log n) for fixed arity clauses, so this can be polynomially large in N. Yet a simple parity plus cross-conflict refutation is polynomial (also L02-18 rank-two generator terminal). Thus no universal small coupling width or generic rank-to-machine lower transfer. No new native scale execution of this hostile family in this run. It motivates alternate tracks or exact semantic refactorization when rank is large.
