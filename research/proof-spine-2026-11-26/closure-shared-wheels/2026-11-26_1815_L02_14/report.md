## A: exact local existential projection with compensating edges
Let P=(groups D_v, cross-choice incompatibility graph) with |D_v|<=3, same-group choices mutually exclusive. A solution is one choice per group, pairwise compatible. For a candidate group D and external choice x, define M_x subset D of choices incompatible with x. For any partial external independent selection S, it extends to the eliminated group iff union_{x in S} M_x != D. Minimal blocking sets have size <=|D|: each member of a minimal covering family has a private covered color, necessarily distinct. Enumerate all external choices with M_x=D (unary bans), and all compatible pairs with union D (binary bans), excluding unary blockers. If |D|=3, a minimal triple is necessarily three choices with singleton masks of three distinct colors, pairwise compatible. Equivalently an induced net with central group triangle and three independent pendant blockers, each blocking a distinct central choice. For smaller domain no triple. The characterization is exact for ALL partial selections, relative to the existing conflict graph, not a necessary condition for projection over only globally extendible full assignments. A net may never occur in a complete external solution. If no minimal triple exists, record every unary/binary ban and remove D. Both directions: original solution avoids all bans; a reduced solution cannot cover D, since any cover would have a minimal singleton/pair/triple and all such possibilities excluded. Save actual mask record and choose any unblocked original color on reverse reconstruction. Guard-conditioned deletions and summaries retain provenance and apply only under that guard. Reapply arc support closure (a choice is removed if some other group has no compatible option); reject empty group. No complete semantic closure claim. This is exact variable elimination with binary compensating constraints, in contrast to forbidden-pattern rules that eliminate without compensating constraints. ## C: adversarial fixed points and exact NP-hard promise

All base NAND-compatible pairs attain a Boolean model of base (select just those two), so pair-SCC acquisition adds no hidden conflicts. Every vertex with at least 3 distinct neighbors has an induced blocking net: select distinct colors on three distinct neighbors. These choices pairwise compatible (even if neighbors adjacent), each blocks one different central color. If triangle-free, all three neighbors are pairwise nonadjacent, so choosing SAME color in all three yields an induced claw centered at each corresponding choice. Arc consistency no deletion, and path consistency no deduction: any two compatible choices from distinct groups exclude at most two colors in a third group, leaving a third.
