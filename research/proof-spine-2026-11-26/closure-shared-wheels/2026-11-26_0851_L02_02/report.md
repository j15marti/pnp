## 2. Exact native matching-grid adapter (PROVED)
For each n>=2 and arbitrary bipartite adjacency matrix A=(a_ij) in {0,1}^{n×n}, define vertex (i,j)'s table in N,E,S,W order:
 B={0000,0101,1010,1111};
 T_ij=B union {0110} if a_ij=1, else B.
Boundary north and west pinned0, south and east pinned1. This is a positive projection of input bits: 4 membership bits constant1, 11 constant0, only word 0110 has variable membership a_ij. Boundary fixed, exactly one varying bit per block; O(N) encoding. Internal words B pass both prefix states unchanged (E=W, S=N). Optional word 0110 simultaneously increments both 0 to1. Define t_ij=1 for this word, otherwise0. Integer identities E-W=S-N=t_ij. Sum along row, column: each row and column selects exactly one available cell. Thus every grid witness gives a bipartite perfect matching. Conversely any perfect matching determines each horizontal prefix H(i,j)=1 iff the selected column in row i is <=j (using one-based positions); vertical prefix analogous. At chosen cell both incoming bits 0 and both outgoing1; otherwise pass. Unique lift. Both directions, including count bijection; NO polynomial counting claim. Actual selected words and prefix edges preserve identities. This restriction has a deterministic polynomial decision/witness algorithm via ordinary augmenting paths despite the next lower bound.

## 4. Near-quadratic negative-coordinate requirement (PROVED WITH SCOPE)
Consider any block-local binary AND/OR DAG as above with arbitrary unary predicates of the complete 16-bit table of ONE cell. On the matching restriction each leaf reduces to 0,1,a_ij, or NOT a_ij. Mark a cell bad if ANY leaf on it becomes NOT a_ij (whether or not reached on all inputs). Let r count distinct bad cells, not leaf/gate counts. Syntactic mark acquired by evaluating two constant-size table words per leaf; no semantic relevance test. General circuits with internal NOT can be dualized into NNF with at most 2s gate polarities (and block predicate complements); theorem applies to resulting bad-coordinate count, NOT number of internal NOT gates.
If r=0, set q=floor(n/2). Otherwise q=floor(min(n/2,n²/(2r))). If q>=1, choose q rows of smallest bad degree. Total bad cells in them <=qr/n<=n/2. At least n/2 columns avoid every bad position in these rows; choose q such columns. Thus acquired all-good square I×J. Time O(n²) after scanning marks (sort row degrees O(n log n)); no oracle. For q=0 bound vacuous, but r already large.
Fix all other adjacency bits: outside I×J put a fixed perfect matching between complementary rows and columns, set all other bits to0. No edges join the free square to outside. The restricted n×n matching exists iff the arbitrary q×q graph has a perfect matching. This is an exact native source restriction with fixed original labels; no need to preserve balance of a circuit trace. All bad-cell predicates now constant, every free leaf monotone. Result is a size<=s monotone Match_q circuit. Hence for q growing, (log s)^3(log q)^2 >= Omega(q).
If s<=N^c for fixed c, log s=O(log n). First using q<=n gives q=O(log^5 n), then log q=O(log log n), so q=O(log³ n (log log n)²). For sufficiently large n the q=floor(n/2) regime is impossible; floor bound q+1>n²/(2r) gives
 r >= Omega(n²/(log³ n (log log n)²)) = Omega(N/(log³ N (log log N)²)).
Equivalently for any fixed epsilon>0, r<=n^{2-epsilon} precludes polynomial-size circuits; more quantitative lower by plugging q=Omega(min(n,n^epsilon)). This is a lower bound on the number of distinct availability coordinates requiring some negative occurrence in any polynomial-size block NNF, not on time, not on number of NOT gates in general circuit, not on which tests an actual execution must use. It applies irrespective of local/cumulative overlap and circuit shape. It does not restrict nonlocal black-box gates such as matching unless their positive implementations are accounted for. Any fixed finite union of positive tracks with a positive final AND/OR combiner remains monotone, and cannot collectively bypass the bound at polynomial total gates; arbitrary conditional switching/negation is NOT covered. Monotone small-arity multi-block gates can be expanded via positive DNF at cost <=O(w2^w) for w effective input bits; if w=O(log N) and paid gate count poly(N), no escape. No assertion that all cooperative modules admit such expansion.
