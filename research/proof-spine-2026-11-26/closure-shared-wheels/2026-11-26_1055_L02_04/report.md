## 2. Exact native circulation subpromise and inexpensive solver
Number port words by 8N+4E+2S+W. On the core orient horizontal edges from even checkerboard vertices to odd, vertical from odd to even (extend orientations to boundary stubs). At even vertices divergence d=E+W-N-S, odd opposite. Balanced words are {0,3,6,9,12,15} at either parity. Choose fixed positive-divergence dummy triples even {1,4,5}, odd {2,8,10}. Core input mask contains exactly one arbitrary balanced word a_v and the three parity-appropriate dummies. Fixed frame: on top noncorners N=S=0, bottom noncorners N=0,S=1; left/right noncorners E=W=0. Top-left N=W=0, top-right N=E=0, bottom-left S=1,W=0, bottom-right S=1,E=0. Each fixed pair leaves two free ports, exactly four words. All core boundary edges are pinned0. Frame internal edges can all be0, external south1, other exterior0.
For any native solution sum core divergences. Internal physical edge bits cancel with opposite signs; boundary flux0. Every local divergence nonnegative, dummies strictly positive, hence each cell uses its unique balanced a_v. Conversely if all a_v labels agree on shared edges and have zero boundary, they lift directly to a full native witness using frame assignment above. This proves exact YES/NO equivalence, not an affine hull assertion. Physical literal guards can be added: after retiring dummies, core singleton pins and frame product relations are entirely unary. Reject inconsistent pins, set remaining bits arbitrarily, verify original witness. Guards retain original physical edge IDs. No table cardinality promise is assumed for pruned witness domains; original masks remain unchanged.
Second method on SAME source: let P(v,e,b) be OR of membership bits for balanced words whose port e equals b. On subpromise precisely one balanced word is present, so adjacent agreement is (P(u,e,0) AND P(v,e',0)) OR (P(u,e,1) AND P(v,e',1)); also require boundary0. Conjoin all edge conditions. This is a positive AND/OR DAG of O(k²) gates on original input bits, unrestricted fanout, binary gates, local predicates. Sequentially combining edge predicates has immediate AND overlap <=2 source cells, but can have large cumulative contextual overlap. For a total easy comparator H on the exact-four promise, also check every core mask belongs to its six-mask codebook and frame is fixed; a mask check is AND of its four required membership bits, exact on weight4. Thus H's upper completion A AND (B OR H) has an explicit linear-size monotone circuit on the entire cube. H is not F outside this subfamily. This is a native, exact-four counterexample to any generic conversion of the forthcoming rectangle bound into general circuit hardness. Initial domain closure, conservation deduction, reclosure, original witness verification are cheap; no arbitrary equivalence oracle.

## 3. A product distribution of actual source witnesses
Select all elementary core faces whose top-left vertex is even. They are directed 4-cycles and pairwise edge-disjoint (may share vertices). Independently assign each selected face a fair bit; set all four of its edges to that bit, all other edges and boundary stubs0. Every core vertex has balanced word (union of edge-disjoint directed cycles). Use these words as active labels in native masks. Distinct face-bit vectors yield distinct source inputs because each selected face has an edge no other selected face uses. Each is a genuine YES, not an unconstrained table relaxation.
Consider any partition of core cells S and complement with both sizes >=k²/3. Let r=k-2 and remove outer ring. For k>=36 both parts in r×r interior have size >=r²/4, since k²/3-(4k-4)>=r²/4. At least r/4 edges cross the partition inside that interior: if fewer, fewer than r/4 rows are mixed. If no full row of S, its size is <r²/4; similarly for complement. If both full row types occur, each column contributes >=1 vertical crossing, contradiction. Every interior edge belongs to exactly one selected face; at most four crossing edges per face. Thus >=ceil(r/16) distinct independent face bits appear on crossing edges.
Any sound rectangle of labels R=X_S × Y_complement contained in native YES must fix the active bit on every crossing edge. Otherwise two accepted labelings disagree there and mixing S side from one and complement from the other makes a native NO by section 2. The rectangle therefore fixes >=ceil(r/16) independent selected face bits, hence has probability <=2^(-ceil(r/16)) under the product distribution. No use of a counting oracle or assumed independence of arbitrary boundary states. Same argument for any sound rectangle, not only subsets of the selected-face family.

## 4. Balanced trace and conditioned context grouping
First, every accepting trace of a correct circuit on the subpromise mentions every core cell. If omitted, change that cell's balanced label to any distinct balanced word. At least one port changes, violating an unchanged neighbor or fixed zero boundary. This is a legal four-entry input, now NO; the same trace still accepts, contradiction. Thus trace coverage holds, even for arbitrary local leaf predicates.
Decomposable circuits: for an occurrence g, every external trace leaf lies in an AND sibling at an ancestor; disjoint child scopes imply T disjoint S(g). As global trace covers all cells, actual subtree leaf scope U must equal S(g). Consequently selected OR child does not drop core scope along this trace. Starting at root (scope k²), follow chosen OR child or largest-scope AND child while scope>2k²/3. Since union of two scopes has size>2k²/3, at least one child>k²/3. Leaves have <=1. Thus balanced occurrence exists. For smooth overlapping circuits, same argument uses OR smoothness, with no claim that b is small. For arbitrary nonsmooth overlapping circuits, balanced occurrence condition stated separately; see final paragraph for a sufficient variant.
For a fixed g with balanced S, B=S intersect T and assignment beta to the labels in B, group ALL actual accepting trace contexts with hole at occurrence of g having exactly this B and label beta. Define X as assignments on S satisfying the gate and beta. Define Y as assignments on complement that satisfy the outside leaves of at least one such context when combined with beta (context may vary across Y). Then X×Y is sound: any x in X and y in Y, choose witnessing context for y, all its S-side leaf predicates are on B and preserved by beta. Plug gate value true into hole; bottom-up trace evaluation accepts. DAG reuse does not create a new constraint: the unfolded trace is merely a sufficient certificate, and other occurrences are checked by their actual leaves. This groups contexts without counting their possibly exponential number. Every accepted input with the required trace occurrence lies in its rectangle. Frame constant and B-label alphabet size six. At most
  s sum_{j=0}^b binom(k²,j) 6^j
rectangles (count gates rather than occurrences; no free enumeration claimed). Union bound on the product distribution gives
  s sum_{j=0}^b binom(k²,j) 6^j >= 2^ceil((k-2)/16).
In particular s>=2^ceil((k-2)/16) for decomposable circuits; N=16(k+2)^2 plus fixed encoding, so exponential in sqrt N. If s is polynomial, b=Omega(k/log k); fixed per-gate overlap footprint gives s*6^b>=2^ceil((k-2)/16) and b=Omega(k), since smaller B can be conditioned on the entire fixed footprint. Proof: group over same footprint values; external leaves on S within footprint; any x with those fixed values works. No bound asserted for arbitrary immediate overlap.
Nonsmooth sufficient variant: every accepted input has a trace with an occurrence whose actual subtree scope U is in [k²/3,2k²/3] and |S(g) intersect T|<=b<=k²/12. Such U always exists by descending binary trace union; the low-context condition is extra. Coverage implies S(g) minus U subset of T, hence |S(g)|<=|U|+b. Therefore both sides of S have >=k²/4 cells. For k>=64, removing ring leaves both >=r²/5 (k²/4-(4k-4)>=r²/5); row proof with r/5 yields >=ceil(r/20) face bits. Identical grouped rectangle proof yields exponent ceil((k-2)/20), even without smoothness. This separates trace coverage from safe context grouping and does not assume a cheap conversion from arbitrary circuits.

## 5. Additional exact barrier for L03-03's completion distinction
L03-03 distinguished lower completion L=A AND G (hard matching projection) from F=A AND(B OR G). F is maximal only among completions rejecting outside A, not globally. Prove no positive local projection of perfect matching into F even if it leaves the exact-four promise. In n×n matching input, n edge-disjoint cyclic permutation matrices are YES; n matrices with exactly one row isolated and all other edges present are NO (indeed maximal NO). For any set of <n edges, some cyclic permutation avoids it and some isolated-row NO contains it. These are actual matching source completions.
Consider a coordinatewise monotone map into 16-bit grid blocks, correct even just on these 2n controls. Write A_v=[weight>=4], B_v=[weight>=5] after mapping. If every individual output coordinate at all-zero (when zero) has a zero-certificate of size <=d0 and at all-one (when one) a one-certificate of size <=d1, then 13d0<n and 5d1<n imply impossibility. Proof: if A_v(0)=0, 13 zero outputs can be forced by <=13d0 zero pins. A genuine cyclic YES avoids them, hence F=0 contradiction. Thus A identically1 by monotonicity. If B_v(1)=1, five one outputs can be forced by <=5d1 one pins, some actual isolated-row NO contains them, hence F=1 contradiction. Therefore B identically0. All mapped blocks now have weight4 everywhere. Since outputs at 0 and1 comparable with identical block weights, mapping constant on entire cube, cannot distinguish controls. For a positive projection (each output bit constant or input variable), d0=d1=1, so n>=14 suffices. For bounded-fanin binary monotone map depth d, each output certificate at extreme has <=2^d variables; impossible if 13*2^d<n. For any block map depending on <n input variables, simpler independent support proof uses YES avoiding the entire block support to force A_v(0)=1 and NO containing support to force B_v(1)=0. No lower bound on size or arbitrary monotone maps follows; these 2n controls themselves admit the elementary all-rows-nonempty separator. A negative/dual-rail encoding, or unbounded-depth preprocessing, evades this restriction. No arithmetic theorem needed. This closes only the local positive matching-transfer route, not every reduction to F.
