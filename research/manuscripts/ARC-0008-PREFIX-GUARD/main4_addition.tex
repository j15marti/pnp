\section{Unchanged fallbacks cannot supply a contracting ARC certificate}
GLOBAL-PREFIX-LEDGER1 proves that a charged partial member with exponent
pair \(p=(c,u)\), followed on FAIL by an unchanged fallback with pair
\(z=(t,s)\), has the certified envelope
\[
 F_p(z):=z\vee p=(\max\{t,c\},\max\{s,u\}).
\]
This exact upper-bound ledger is useful for implementing restricted members,
but it cannot by itself instantiate the missing contraction premise.  Because
\(\mathcal R\) is upward closed, any one finite achievable pair supplies
cofinally many valid exponent bounds to which the obstruction applies.

\begin{theorem}[PREFIX-FALLBACK-NOEDGE1]
Let \(p\ge0\), let \(0<\lambda<1\), and let every phase weight
\(v_q\in\mathbb R_{>0}^2\).  On the cofinal set of exponent pairs
\(z\ge p\), no scalar inequality
\[
 v^{\mathsf T}F_p(z)\le\lambda v^{\mathsf T}z+c
\]
holds with fixed \(v>0,c<\infty\).  More generally, if every edge of a
directed phase cycle \(q_0\to\cdots\to q_{k-1}\to q_0\) uses only this
certified prefix envelope, then the phase-edge inequalities required by
PHASE-MULTINORM-ARC1 cannot all hold.
\end{theorem}
\begin{proof}
For \(z\ge p\), \(F_p(z)=z\).  Substituting \(z=ru\), where \(u>0\),
would give
\((1-\lambda)r v^{\mathsf T}u\le c\), which fails for sufficiently large
\(r\).  For a phase edge \(q\to r\), the same substitution and division by
\(r\) force \(v_r^{\mathsf T}u\le\lambda v_q^{\mathsf T}u\) for every
\(u\ge0\), hence \(v_r\le\lambda v_q\) componentwise.  Multiplication around
a length-\(k\) cycle yields \(v_{q_0}\le\lambda^k v_{q_0}\), impossible
because \(v_{q_0}>0\) and \(\lambda^k<1\).
\end{proof}

The theorem is a limitation of the \emph{certified max-envelope}, not a
lower bound on the implementation.  A tighter analysis may reveal a smaller
achievable pair, and a mixed phase cycle may contain a genuinely contracting
non-prefix edge.  What is retired is only the proposal that finitely many
partial-family recognizers, each followed by the same current-scale fallback,
already furnish the ARC successor relation.  For the present density member,
\(p=(1,2/3)\); exact rational regression checked 69,904 positive-weight cycle
assignments and found no feasible pure-prefix cycle.  The symbolic proof,
not the finite check, establishes the result.  A source-visible all-CNF
successor with a genuinely improved joint ledger remains \textsc{Open}, so
P versus NP remains open.
