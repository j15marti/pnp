\section{An actual partial-domain extension and its all-input limit}
ARC-STRENGTHEN2 authenticates the existing certified partial portfolio and
proves it misses every connected parity-star CNF with at least two leaf
pairs, including a contradictory-parity variant. These are easy affine
instances, so failure is a coverage counterexample, not a SAT lower bound.
A new exact scanner recognizes complete parity blocks sharing one hub
with disjoint leaf pairs, and detects all eight clauses on a triple.
It returns a correct Boolean answer or UNKNOWN and strictly expands the
old successful domain. A conservative read-only bit implementation uses
$O(N^3\log N)$ time and $O(\log N)$ additional space for encoded input length $N$.
The Python prototype tests semantics; it does not measure that symbolic
bit-machine workspace bound.

For every fixed jointly bounded exact SAT machine $A$, prepend this
scanner and invoke $A$ on UNKNOWN after releasing scanner state. This
constructs a real all-input SAT machine with
\[
 T=O(N^3\log N+T_A(N)),\qquad S=O(\log N+S_A(N)).
\]
The transition $(t,s)\mapsto(\max\{3,t\},s)$ has no certified strict
improvement, despite its enlarged solved domain. The unresolved ARC
obligation is a favorable bound on the remaining domain, not soundness
of this scanner. The report also distinguishes syntactic Horn backdoors
from an implementation that collapses a residual containing an empty
clause: the satisfiable star has minimum backdoor $m+1$, while the
contradictory variant may have an operational backdoor of size three.
Both defeat the old size-two member. The 984 finite semantic checks
support the implementation; P versus NP remains OPEN.
