\paragraph{TESTS-0008: explicit bi-local indexing is easy but offline.}
For every explicit CNF with $L$ literal occurrences and standard encoded
length $N=\Theta(L\log L)$, stable sorting of records
$(v,\sigma,c,s)$ constructs both clause-to-occurrence ranks and inverse
incidence lists in $O(L\log L)$ comparisons and $O(N)$ bits.  Both queries
then take $O(1)$ word accesses and the source reconstructs exactly.
Therefore repeated raw rescanning is not a representation-independent
obligation.  This compiler materializes a linear-size table, however, so it
does not give polylogarithmic-time/logarithmic-space on-demand access from the
Jahanjou--Miles--Viola succinct clause generator.  The source-specific
\texttt{JMV-PORT-LOCALITY1}/\texttt{LOCAL-COOK-BILOCAL-M33-1} first leg,
UCORE-TIME1, arbitrary-exponent bootstrapping and P versus NP remain OPEN.
