\section{Research realization of the density-gated member}
The implementation claim in ARC-0005-ORBIT was not recoverable from the
synchronized GitHub tree or connected Drive.  RSR-0005 therefore did not
promote that missing body.  Instead it supplied an independent, source-visible
realization at
\path{experiments/proof_spines/density_php_file_recognizer.py}.

For its declared canonical DIMACS subset, the first pass uses a fixed byte
chunk, an $O(\log M)$ token buffer, counters, and one previous negative edge.
It requires positive rows followed by strictly ordered, duplicate-free
negative edges and checks
\[
 n=ph,\qquad e=h\binom p2,\qquad h/2\le p\le2h,
 \qquad 32e^2\ge n^3
\]
before allocating a variable-indexed object.  A second immutable-source pass
uses union--find, degrees, row labels, and sorted component--row pairs to
verify the complete rectangular pigeonhole incidence certificate.  Thus this
specific realization is \textsc{Proved/Exact} in the stated encoding model,
with time $M^{1+o(1)}$, space $M^{2/3+o(1)}$, and VALUE equal to
$[p\le h]$; the finite regression record is \textsc{Computational}.

The graph object matches the semi-streaming convention of Feigenbaum et al.,
which permits $O(n\operatorname{polylog}n)$ bits and sequential passes
\cite{rsr0005Semistream}.  That literature definition supports the accounting
but supplies no all-CNF coverage.  Reingold's deterministic logspace
connectivity theorem \cite{rsr0005Reingold} does not preserve the required
near-linear time under this file-access interface.  Beame's sorting/unique-
elements tradeoff \cite{rsr0005Beame} explains why the canonical edge order
is load-bearing; it is not a lower bound for the whole SAT member.

This is still a partial VALUE member.  Under global sequential prefixing it
retains the already proved envelope
$(\max\{1,t\},\max\{2/3,s\})$ and adds no all-input achievable pair.
The SAT-specific ARC closure and P versus NP remain \textsc{Open}.
