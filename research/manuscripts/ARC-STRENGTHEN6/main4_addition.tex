\section{ARC update: actual promise point and enlarged fallback invariance}

The alias--portfolio construction now supports an actual, but promise-relative,
joint point.  For each boundary type $\tau$, let $D_\tau^{(0)}$ be the inputs
receiving an exact zero-child decision from the fixed controller, and put
\[
D_\tau^{(d+1)}=D_\tau^{(0)}\cup
\{X:A_\tau(X)=\operatorname{PLAN}((Q_i,\sigma_i)_i),\ 
Q_i\in D_{\sigma_i}^{(d)}\ \forall i\},
\quad D_\tau^\star=\bigcup_dD_\tau^{(d)}.
\]
One uniform depth-first machine decides SAT on $D^\star$.  Applying the
boundary closure theorem to
$(R,V,H,B)=(6/5,11/10,1/2,1/2)$ gives
\[
 (6/5,1/2)\in\mathcal A(D^\star),\qquad
 C=\max\{1,R,(V-H)/(1-H)\}=6/5,\quad P=\max\{B,H\}=1/2.
\]
This is a real promise-SAT transition, not only recurrence algebra.  Failed
members, aliases, replay, multiplicity, buffers, indexes and ancestor frames
are charged on the same machine.  It is not yet a point of
$\mathcal A(\operatorname{SAT})$.

The enlarged finite prefix also has a SAT-complete fallback.  Direct nesting
$G(G(F))$ is ill-typed because the inner guard has two binary clauses.  Let
$\widehat G(F)$ instead replace each such binary clause $C$ by
$(C\vee z)\wedge(C\vee\neg z)$ with a fresh private variable, and set
$X(F)=G(\widehat G(F))$.  Then $\widehat G(F)$ is proper ternary,
$\operatorname{SAT}(X(F))=\operatorname{SAT}(F)$, and the outer strip exposes
exactly $\widehat G(F)$.

For robustness against every named root member, first clause-isolate the
source: clone each literal occurrence to a private $y$ and enforce $y=x$ by
the four proper clauses $(\neg x\vee y\vee\pm z)$ and
$(x\vee\neg y\vee\pm w)$.  This prevents an arbitrary source triple from
presenting the parity scanner's full eight-pattern mask.  If

\[

\[
 \boxed{\mathcal A(U_2)=\mathcal A(\operatorname{SAT}).}

Consequently the remaining all-input arrow is exact: every root and every
