\section{WRAPPER update: covered-domain closure and a repaired nested guard}

Flattening the finite alias DAG and ordered source-first portfolio yields an
actual recursive machine on its least covered domain.  Let $D^{(0)}$ contain
zero-child decisions and let $D^{(d+1)}$ contain plans whose every executed
ordinary-SAT child occurrence lies in $D^{(d)}$.  On
$D^\star=\bigcup_dD^{(d)}$, the common ledger
\[
 (R,V,H,B)=(6/5,11/10,1/2,1/2)
\]
closes to simultaneous time $N^{6/5+o(1)}$ and space $N^{1/2+o(1)}$ on one
uniform machine.  Same-scale acyclic aliases are local phase nodes; recursive
coverage is required only at completed ordinary-SAT boundaries.  This proves
a promise-SAT point, not all-input coverage.

The corrected hostile composition is type-aware.  Direct $G(G(F))$ is
invalid because $G(F)$ contains two binary equivalence clauses and the outer
strip grammar requires a proper ternary source.  Form $\widehat G(F)$ by
replacing each binary clause $C$ by
$(C\vee z)\wedge(C\vee\neg z)$ with a fresh private $z$, and use
\[
                         X(F)=G(\widehat G(F)).
\]
The strip exposes the proper source $\widehat G(F)$ exactly.  It is
SAT-equivalent to $F$ and sign-balanced, so pure-literal DECIDE returns
UNKNOWN.  If $L=q+m$, every non-hub pivot leaves $L-1$ parity blocks joined
through the hub; the hub pivot creates eight distinct connected width-four
resolvents per block.  The exact encoded parent bound
\[
|\widehat G(F)|\le8[5L+8+(15L+14)
(1+\lfloor\log_{128}(5L+4)\rfloor)]
\]
This implies that the retained
$128(L-1)$-bit component exceeds the PIVOT cap for all $L\ge4$.  Both alias
members therefore fail without executing a child, while the outer amplified
guard defeats every older root member.

To make the embedding robust even when the arbitrary source itself contains
all eight sign patterns on a triple, first clone each literal occurrence and
enforce clone equality by private proper clauses.  For
$T(F)=\widehat G(\mathsf{Iso}(F))$ and $H(F)=G(T(F))$, clause isolation keeps
all source masks incomplete, the outer root prefix declines, exact strip
succeeds, and the post-strip PIVOT/pure pair both decline.  This is the
universal SAT-hard fallback image used by the ARC theorem.

This proves that the exact enlarged fallback remains locally SAT-complete;
it does not lower-bound future wrappers.  The load-bearing OPEN statement is
still one source-visible PRE-A controller which covers every input and sends
every emitted ordinary child back into the covered domain with the common
ledger.  The aggregate fixed point still eliminates $K$ conditional on that
premise.  P versus NP remains OPEN.
