\section{Recovered typed phases: an exact access budget}
\label{sec:recovery-strengthen2-wrapper}
\paragraph{Status: PROVED/EXACT algebra; CONDITIONAL implementation.}
The original CYCLEGAIN1 and STREAMCOMP1 analyses allow one same-scale
typed edge followed by a contracting edge. For charged sufficient
inequalities
\[
 C_P\ge r_P,\quad C_P\ge u+C_Q,\quad
 C_Q\ge r_Q,\quad C_Q\ge v+hC_P,
 \qquad u,v\ge0,\quad 0<h<1,
\]
the componentwise least feasible pair is
\[
 C_P^*=\max\{r_P,u+r_Q,(u+v)/(1-h)\},\qquad
 C_Q^*=\max\{r_Q,v+hC_P^*\}.
\]
Substitution proves both necessity and feasibility. Thus $C_P^*\le1$
holds exactly when $r_P\le1$, $u+r_Q\le1$, and $u+v\le1-h$.
These solve an upper-bound envelope; they are neither an actual SAT
running-time equality nor a lower bound on other algorithms.

If $r_P=r_Q=1$, $u=0$, and $v=1-h+g$, a charged access exponent
$g\ge0$ yields $C_P^*=1+g/(1-h)$. Any positive fixed $g$ loses this
near-linear envelope, unless a tighter implementation or amortized bound
is proved. Shared setup from ORBITBATCH1 can be charged once when the
actual execution shares it. It cannot erase consumer work or repeated
executions. A fresh same-scale $\Theta(N)$-bit buffer breaks sublinear
workspace; aliasing an existing read-only entry input does not allocate
such a buffer. Implicit input needs a proved evaluator with all nested
requests and retained state charged.
