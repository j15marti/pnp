\section{Recovered phase contracts and the ARC endpoint}
\label{sec:recovery-strengthen2-arc}
\paragraph{Status: CONDITIONAL; P versus NP remains open.}
RECOVERY-STRENGTHEN2 rechecks the original RECURCLOSE1, CYCLEGAIN1,
STREAMCOMP1 and ORBITBATCH1 proofs. Conditional elimination of $K$ was
already established; requiring a fresh compiler at each scale or strict
shrinkage at every internal typed edge is unnecessary. A bounded internal
phase can be flattened when its entire local work, peak scratch, nested
access, replay and suspended state are charged on the same machine.

In original encoded SAT bit length $N$, let the multiset of actually
executed returning children have volume $\sum_jm_j\le N^{1+o(1)}$ and
maximum size $N^{h+o(1)}$, for a fixed $h<1$. If the phase takes
$N^{1+o(1)}$ local time and $N^{p+o(1)}$ local workspace with $p<1$,
including all live internal state, and at most one explicit child buffer
is retained, recursive closure gives the one realization
\[
 (T,S)\le\bigl(N^{1+o(1)},N^{\max(p,h)+o(1)}\bigr).
\]
All repeated child executions count separately. This extends the earlier
count-form recovery using the current aggregate-volume lemma; it proves
no new all-input construction.

The endpoint is Fortnow's \emph{Time-Space Tradeoffs for Satisfiability},
Corollary 3.3, on its random-access Turing-machine model: SAT has no single
deterministic machine simultaneously attaining near-linear time and fixed
sublinear-power space. The unrestricted historical sum-of-exponents
shorthand is not used. The remaining bridge is still from $\mathrm{SAT}\in P$
to an implementation of the displayed contract. The implication is not
supplied by existence of an abstract feasible exponent vector.
