\section{UNIT-TAIL-REPLAY1: forced-assignment frame removal}
COMBINED-REPLAY1 already implements a source-backed exact solver.
The new unit-tail variant replaces recursive forced-assignment calls by
an iterative loop while preserving frontier-first processing, exact
cache validation and AND/OR semantics. It does not save eliminated
pre-unit states for later cache insertion; reuse and work may therefore
change. Genuine branching frames and source access remain charged.

A 519-comparison batch and an independent 2,320-check truth-table
regression pass. On the deliberately frontier-capped, cache-free
256-variable chain, active logical descriptor payload falls from
65,538 to 511 bits, with unit recursion depth falling from 255 to zero.
The broader logical peak including transient payload changes from
65,609 to 1,530 bits. Literal reads remain 261,632.
These are declared payload counters, not RSS or a total machine bound.

This is an implementation improvement on forced paths, not a favorable
general-SAT resource theorem. P versus NP remains OPEN.
