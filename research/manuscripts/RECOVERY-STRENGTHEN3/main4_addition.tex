\section{Recovered affine access does not supply the ARC transition}
\label{sec:recovery-strengthen3-arc}
\paragraph{Status: exact interface result; all-input bridge OPEN.}
RECOVERY-STRENGTHEN3 implements a concrete implicit-access special case
from LOCALBIT1 and ORBITBATCH1. Over one supplied field, a sequence of
affine address maps $E_j(z)=B_jz+c_j$ can be composed into one address
$Mz+b$, followed by one call to the same parent evaluator $F$. This
avoids repeated semantic evaluations caused solely by the coordinate
layers. It does not acquire $F$ or reduce the cost of that remaining call.

In original SAT input length $N$, let $A$ be evaluator acquisition,
$E$ per-field-value evaluation, $C_{\rm desc}$ all descriptor work,
$C_{\rm outer}$ all other work, and $Q$ the actual executed request
count. A charged implementation has the sufficient time ledger
\[
 T\le A+C_{\rm desc}+C_{\rm outer}
       +Q(E+\hbox{coordinate-routing cost}).
\]
All retained evaluator state, descriptors, buffers and ancestor state
belong to simultaneous workspace. The coordinate cost can be
polylogarithmic under the previously checked fixed-dimension source
parameters, even when the ambient field table is very large. Neither
$A$ nor $E$ is thereby made polylogarithmic.

Consequently this closes a restricted address-composition obligation,
not the all-input ARC transition or the ordinary-SAT return. Fortnow's
near-linear-time/fixed-sublinear-space endpoint still requires a single
matched deterministic SAT machine. Conditional elimination of $K$ is
unchanged; a $K$-dependent parent evaluation is not erased by address
fusion. Full proof, tests and an independent review accompany
