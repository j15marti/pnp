\section{An exact signed-twin three-state macro}
\label{sec:wrp0006-signed-twin}

For a canonical tautology-free CNF $F$, call $G$ a signed-twin class if every
pair $x,y\in G$ has identical positive and negative clause-incidence columns.
Every incident clause then contains either all variables of $G$ positively or
all negatively.  Fix distinct $g_0,g_1\in G$ and restrict $G$ in three ways:
all zero, all one, and the mixed assignment $g_0=0,g_1=1$ with the remaining
members fixed to zero.

\paragraph{SIGNED-TWIN-MACRO1 (PROVED/EXACT).}
If the resulting residuals are $F_0,F_1,F_\star$, then
\[
 \operatorname{SAT}(F)=
 \operatorname{SAT}(F_0)\lor\operatorname{SAT}(F_1)
 \lor\operatorname{SAT}(F_\star).
\]
Indeed every assignment on $G$ is all zero, all one, or mixed.  In the mixed
case, every incident positive clause has a true class literal and every
incident negative clause has a true negated class literal, so all incident
clauses disappear.  Conversely each residual model extends by its fixed
class assignment.  Every class occurrence disappears from every child and
duplicate residuals may be removed, giving fanout at most three.

Power shrink is conditional on an explicit output-size gate: an independent
outside component can occupy almost the entire formula.  A read-only repeated-
scan realization compares signed columns, searches leaders, simulates the
children, and streams a successful output in $O(M^3)$ time and
$O(\log M)$ workspace, including failed searches.  If it accepts only when
all children have length at most $M^{b+o(1)}$, then
$(a,b,c,s)=(0,b,3,0)$ and the recursive time exponent is $3$.  This is an
exact partial macro but not a favorable all-CNF inner procedure.  On FAIL the
current-scale fallback remains, so the joint WRAPPER implication is OPEN.

The bounded WRP-0006 audit exhausted 1,024 small duplicate-free formulas and
tested 2,000 seeded random formulas, 500 near-twin rejections, 200 independent
products, and 100 padding controls.  All exact checks passed.  These finite
tests support the implementation only; they do not promote coverage or an
asymptotic shrink rate.  Freuder's CSP interchangeability is a structural
analogy, while certified SAT symmetry remains useful context
\cite{wrp0006Freuder,arc0005Orbitopal}; neither source supplies the theorem
above.
