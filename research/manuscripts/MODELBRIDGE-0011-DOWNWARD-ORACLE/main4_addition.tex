\section{Adaptive downward-oracle elimination}

The source-only recursive endpoint extends to fully adaptive black-box
membership calls.  Let one fixed uniform deterministic transducer $M^L$
decide a language $L$ on every encoded input of length $N$.  Suppose it makes
at most $N^{\eta+o(1)}$ adaptive queries to $L$, every query has encoded
length at most $N^{\lambda+o(1)}$ for a fixed $\lambda<1$, and all nonoracle
work is $N^{r+o(1)}$.  Query construction, access, serialization, suspension,
resumption, combining, and output are included.

Well-founded recursion replaces each oracle answer by the same procedure on
the strictly smaller query.  Correctness follows by induction on encoded
length, including adaptive query choice.  The time recurrence
\[
 T(N)\le N^{r+o(1)}+N^{\eta+o(1)}T(N^{\lambda+o(1)})
\]
has the bound
\[
 T(N)\le N^{C+o(1)},
 \qquad C=\max\left\{1,r,\frac{\eta}{1-\lambda}\right\}.
\]
If local retained state is $N^{p+o(1)}$ and explicit query buffers are
charged, depth-first evaluation has conservative workspace exponent
$P=\max\{p,\lambda\}$.

All exact SAT deciders return the same bit on each query.  Hence an
extensional black-box transducer has the same adaptive transcript under
DIRECT/COPY/DELAY/INTERP/RECOMP wrappers.  Merely calling the contract
``$A$-relative'' does not retain the unknown polynomial exponent of $A$:
strict fractional descent eliminates $A$.  Current-scale calls
($\lambda=1$) and exact fallback do retain that exponent.
