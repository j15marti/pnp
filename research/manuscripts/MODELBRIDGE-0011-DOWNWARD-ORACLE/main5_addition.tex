\section{Black-box smaller-instance access is not an intermediate}

A strictly downward SAT oracle can be eliminated even when its calls are
adaptive.  If a uniform transducer makes $N^{\eta+o(1)}$ truth-bit calls of
encoded length at most $N^{\lambda+o(1)}$, with $\lambda<1$, and spends
$N^{r+o(1)}$ charged local work, recursive simulation gives an ordinary
decider with exponent
\[
 C=\max\left\{1,r,\frac{\eta}{1-\lambda}\right\}.
\]
The proof follows the realized adaptive path; it does not expand the latent
query tree.  With $N^{p+o(1)}$ local state and explicit query buffers, the
conservative workspace exponent is $\max\{p,\lambda\}$.

This sharpens the bridge target.  An assumed polynomial SAT solver used only
as a black-box truth function contributes no implementation-specific power:
all exact solvers, including DIRECT/COPY/DELAY/INTERP/RECOMP wrappers, return
the same bits.  Once a favorable strict-downward contract exists, the supplied
solver and its unknown exponent disappear.  If a construction instead reads
code, timing, or traces, it is intensional and must prove wrapper covariance,
uniformity, full cost charging, and SAME\_REALIZATION.
