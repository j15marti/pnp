\paragraph{LB-0014: annotation-semantics trilemma.}
For any language $L$ and annotation map $\tau$, three interfaces must be kept
distinct.  The total language $\{\langle x,a\rangle:x\in L\}$ admits a
uniform erasure wrapper that never reads $a$; the promise problem restricted
to $a=\tau(x)$ admits the same wrapper without validating the promise; and
$\{\langle x,a\rangle:x\in L\wedge a=\tau(x)\}$ is a different total
language.  Thus \texttt{ANNOTATION-SEMANTICS-TRILEMMA1} is
\textsc{Proved/Exact} in the declared locally projectable encoding model, and
unqualified \texttt{TAG-VALIDATION-TO-UCORE1} is
\textsc{Falsified/Retired}.  Occurrence tags remain valid external reduction
infrastructure, but their validation cannot be charged to an arbitrary
one-bit SAT decider.  The exhaustive audit passed 524,288 promise checks,
2,097,152 erasure checks, 2,097,152 validation checks, 1,572,864 mutations,
and all declared hostile controls.  \texttt{JMV-NATIVE-TAG1}, exact local
