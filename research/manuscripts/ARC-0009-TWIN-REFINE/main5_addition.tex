\section{Linear source-visible acquisition of signed-twin classes}
SIGNED-TWIN-MACRO1 previously supplied exact three-child semantics but used
an $O(M^3)$ scan to certify equal signed clause-incidence columns.  The scan
is not intrinsic.  Let $n$ be the number of variables and let $M$ be the
canonical read-only CNF length.  For every clause $C_j$, treat its positive
and negative variable sets as two features.  Starting with one block of all
variables, refine every current block by membership in each feature.

\begin{theorem}[SIGNED-TWIN-REFINE1]
On a read-only clause-major canonical tautology-free CNF, the final blocks of
feature refinement are exactly the equivalence classes of identical signed
clause-incidence columns.  A linked-list implementation takes $O(M)$ time and
$O(n\log M)$ work bits.  In the same pass model, conservative pre-deduplication
sizes for the all-zero, all-one, and one-mixed residuals can be accumulated in
$O(M)$ additional time and $O(n\log M)$ bits; generating one accepted triple
takes one further $O(M)$ scan.
\end{theorem}
\begin{proof}
After processing the first $k$ features, induction shows that two variables
occupy one block exactly when their first $k$ membership bits agree.  After
all $2m$ features, block equality is therefore equality of the full signed
columns.  To refine by a feature $X$, move each $x\in X$ to a temporary
subblock of its current block, recording only touched blocks.  Doubly linked
block lists and variable-to-block pointers make each move constant time.
Every literal occurrence belongs to exactly one signed feature, so the total
number of moves is at most the number of literal occurrences.  The partition,
pointers, marks, touched-block lists, and per-block counters use $O(n)$
machine words, hence $O(n\log M)$ bits.

Once the classes are known, scan each clause and charge each incident class
once.  Under the deletion-monotone token encoding, an all-zero restriction
deletes every negatively incident clause and removes the class literals from
positively incident clauses; all-one is symmetric, while a mixed assignment
deletes every incident clause.  Summing these contributions gives the exact
length before duplicate-clause removal, hence an upper bound after canonical
deduplication.  Class--clause incidences are bounded by literal occurrences,
so this scan is linear.  One selected class is then restricted in one final
source scan.  SIGNED-TWIN-MACRO1 supplies the exact OR semantics.
\end{proof}

If $n=M^{u+o(1)}$ and the accepted children have length
$M^{b+o(1)}$, the explicit-child realization has
\[
 a=0,\qquad c=1,\qquad s=u,\qquad
 C=1,\qquad \sigma=\max\{u,b\}.
\]
Thus this restricted cell meets the general Williams product endpoint only
when $1+\max\{u,b\}<\phi$, equivalently
$\max\{u,b\}<\phi-1$.  The common $u=2/3$ density scale does not pass that
test.  Implicit child access would require a separately proved regeneration
interface and is not inferred here.

The primary modular-decomposition literature provides an exact data-structure
transfer for partition refinement on explicit adjacency lists
\cite{arc0009McConnellSpinrad}.  Recent low-space element-distinctness
algorithms are randomized and assume word-size atomic elements
\cite{arc0009LyuZhu}; signed CNF columns are implicit long strings, so that
route is a failed transfer to the exact deterministic wrapper.

A bounded regression compared refinement with direct profiles on 8,192
exhaustive and 4,000 seeded formulas, checked 1,548 certified macro uses and
2,160 size bounds, and exercised Horn, 2-CNF, affine, bounded-path,
near-twin, product, renaming/complement, and padding controls.  It recorded
138,862 literal touches for exactly 138,862 literal occurrences.  These
finite results are \textsc{Computational}; the proof above establishes the
algorithmic theorem.  No all-CNF coverage theorem follows, and P versus NP
remains \textsc{Open}.
