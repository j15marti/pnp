\paragraph{LB-0011: implementation-quotient factorization guard.}
If a charged extractor yields representatives whose quotient class is
identical for every exact SAT implementation, that class factors through the
source formula.  With $N^{c+o(1)}$ local work, $N^{b+o(1)}$ calls of length
$N^{a+o(1)}$ to one fixed $M^{K+o(1)}$ SAT decider, and
$N^{d+o(1)}$ canonicalization, the canonical class is externally computable
in $N^{\max\{d,c,b+aK\}+o(1)}$ time.  Thus current-scale invariant extraction
retains $K$, while source-only extraction does not certify same-execution
cost.  Literal invariance is retired as a sufficient ARC bridge; a charged
wrapper-covariant, representation-sensitive extractor with strictly
fractional hereditary channels remains OPEN.  No ARC point or lower bound is
added.  P versus NP remains OPEN.  See
\texttt{research/review/reports/lower\_bound/2026-10-11\_1112\_LB-0011.tex}.
