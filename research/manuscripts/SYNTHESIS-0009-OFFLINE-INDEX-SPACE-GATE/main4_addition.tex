\paragraph{Synthesis: offline indexing does not close the local Cook bridge.}
If a first-leg output has $M=N^{q+o(1)}$ encoded bits and the verified
offline compiler materializes a $\Theta(M)$-bit forward/inverse table, then
the same realization has source-scale workspace exponent
$P_{\rm mat}=\max\{q,qp\}=q$ for $q\ge1$.  Thus even a quasilinear output
cannot coexist with the desired $N^{1/2+o(1)}$ workspace bound.  Reclassifying
the generated table as read-only input or nonuniform advice changes the
charged realization.  Full inverse incidence is also unnecessary for the
fixed tagged second leg.  The exact remaining target is on-demand JMV
forward port-label locality with polylogarithmic time and logarithmic space.
That target, the arbitrary-algorithm transfer, and P versus NP remain
\textsc{Open}.
