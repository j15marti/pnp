\paragraph{LB-0009 restriction-service accounting.}
For a fixed SAT decider of exponent $K$, one restriction coordinate simply
replays that decider on the compiled residual.  A polynomial batch contributes
$\alpha+\beta K$ when there are $N^{\alpha+o(1)}$ residuals of length
$N^{\beta+o(1)}$; it does not erase $K$.  Requiring the full service vector
changes the output contract, while a data-structure query bound changes the
machine model.  No all-input successor, contraction, or achievable SAT pair is
added.  FORCED-DATASTRUCTURE-COMPILER1 and P versus NP remain OPEN.  See
\texttt{research/review/reports/lower\_bound/2026-10-11\_0844\_LB-0009.tex}.
