\paragraph{MODELBRIDGE-0010: static-normalizer trilemma.}
A language-generic compiler mapping every clocked polynomial-time decider to
one fixed exponent contradicts the deterministic time hierarchy.  Exact
marked-shell reachability is undecidable even on polynomial-time deciders of
one fixed language whenever that language has a polynomial decider.  Under
$\mathsf{SAT}\in\mathsf P$, a SAT-specific compiler mapping every polynomial
SAT implementation into any fixed favorable resource class exists iff SAT
already has a decider in that class; the reverse direction is constant
replacement.  Thus arbitrary static normalization is not a weaker route to an
ARC point.  A source-only, $K$-independent, hereditary fractional successor
remains OPEN.  P versus NP remains OPEN.  See
\texttt{research/review/reports/model\_bridge/2026-10-11\_1155\_MODELBRIDGE-0010.tex}.
