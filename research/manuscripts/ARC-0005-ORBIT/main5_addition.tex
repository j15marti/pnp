\section{Orbit-first acquisition and density-gated VALUE recognition}
The tested simplification hook uses exact syntactic automorphisms to remove
literal alternatives \emph{before} their residuals are generated. Clausal and
negation fixing are known SAT-preserving rules
\cite[Theorems~3.2--3.3]{arc0005Orbitopal}; the contribution here is a checked
implementation and a charged integration, not a new general symmetry theorem.
Every candidate is verified against the current residual, and failed map tests
are included. A successful single-orbit step removes a variable. The explicit
loop has at most $n$ successful rounds; this is not an inference from fixed
existential ARC depth.

The original double-wrapper source was read back and locally verified at Git
blob \path{04cf06305b5beff2a36f631e4a38b5e09553c1ee}. Its components strategy
with the new hook passed 1,776 inner/outer answer checks on 296 historical
cases. On $\operatorname{PHP}(8,7)$, the original, pure-only, and orbit-stream
modes retained 665, 24, and 1 DAG nodes respectively. Their allocation-traced
runtimes were 3.02133, 0.25667, and 0.02882 seconds, with peak Python allocations
of 7,622,054, 668,791, and 249,896 bytes. These are finite measurements, not
asymptotic bounds; pure-literal gains must not be misattributed to symmetry.

\paragraph{A file-first restricted VALUE member.}
The separate two-pass recognizer is called before materializing a formula.
It verifies $p$ positive clauses of equal width $h$, $n=ph$, balanced dimensions,
and exactly $e=h\binom p2$ distinct negative binary clauses. Before any
variable-indexed allocation, it checks $h/2\le p\le2h$ and those counts.
They imply $e\ge n^{3/2}/(4\sqrt2)$, hence $n=O(M^{2/3})$ on every attempt
that reaches allocation. Union-find, degrees, and a sorted row/component
incidence list then verify disjoint $p$-cliques with one variable from each
positive row. The formula is a rectangular pigeonhole encoding up to a
verified renaming; it is SAT exactly when $p\le h$.

The supplied derivation gives $M^{1+o(1)}$ time and $M^{2/3+o(1)}$ working
space, including later failed attempts, for this partial recognizer. The
zero-child VALUE interface is already established
\cite{arc0005Write002}. A first-pass failure uses small counters only. Successful
answers contain no deferred query or parent reference. The new resource
statement awaits independent review; it must not be inherited by a version
that stores the entire input before the scan.

The scanner passed 62 small tests (14 exact VALUE, 48 safe FAIL) and four
larger balanced-family tests. It read each larger source exactly twice. On
$\operatorname{PHP}(49,48)$, a 747,904-byte source was checked with 158,789 bytes
of peak incremental Python allocation and a measured 1.35682-second runtime.
The exponent claim rests on the density proof, not on that measurement.

Four-variable rigid SAT/UNSAT controls, with all 384 signed permutations
checked for each, show that the symmetry member has no universal success
coverage. Neither the new VALUE member nor the existing portfolio has been
proved favorable on all CNF. W1, existing per-leaf W2, and semantic W5 remain
credited; general W3/W4/W6 and the final all-input implication remain
\textsc{Open}. ARC and P versus NP have no mathematical status change.
