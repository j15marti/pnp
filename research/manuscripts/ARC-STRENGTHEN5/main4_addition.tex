\section{ARC update: the current fallback has SAT's achievable region}

Let $P_{\rm cur}$ be the fixed current favorable prefix, including the
one-pivot factoring member, and let $U$ be its exact UNKNOWN domain.  The
following result is an existence-region audit, not a separation claim.

For a nonempty proper 3CNF $F$ with header maximum $q$ and $m$ clause
occurrences, add a hub $h$, an equivalent bit $r$, one even-parity block
$P_0(h,v,w_v)$ for every $v\in[q]$, and one fresh even-parity block
$P_0(h,a_j,b_j)$ for every clause occurrence.  Call the result $G(F)$.
Then
\[
 \operatorname{SAT}(G(F))=\operatorname{SAT}(F),\qquad
 |G(F)|=|F|^{1+o(1)},
\]
and each requested output bit is computable in polylogarithmic time and
logarithmic workspace.  The binary equivalence, balanced signs, shared hub,
positive-pair triangles and absent marker make every older member fail.
For the new pivot member, every non-hub pivot leaves all but one parity block
in a single hub component; eliminating the hub reproduces all parity blocks
around $r$.  If $L=q+m\ge4$, that component has at least $128(L-1)$ bits,
whereas the complete parent encoding has at most $160L\log_2L$ bits.  The
elementary monotonic comparison
\[
 128(L-1)>\sqrt{|G(F)|}\log_2(|G(F)|+2)
\]
shows that the maximum-child cap fails.  A prior acquisition-cap abort is
also UNKNOWN.  Hence $G(F)\in U$ for every source $F$.

Define $\mathcal A(D)$ using one uniform all-length random-access machine
whose time and workspace bounds hold simultaneously on every input in $D$.
Virtual simulation of any $U$-decider on the locally accessible $G(F)$,
together with the repaired local CNF/3CNF adapter, proves
\[
 \boxed{\mathcal A(U)=\mathcal A(\mathrm{proper\mbox{-}3SAT)
                         =\mathcal A(\operatorname{SAT}).}
\]
Thus the current finite partial prefix supplies no strict achievable-region
edge by itself: a favorable fallback theorem is already a favorable general
SAT theorem.  This does not forbid improvement and does not lower-bound a
future compiler.  Iterated elimination can strip the guard back to an
almost-parent-sized $F$, which still is not the required fixed-power shrink.

Stage witnesses may differ, but each stage needs one joint uniform
all-length machine.  Coordinatewise infima are not witnesses.  The target
$(6/5,1/2)$ does have strict finite FLMV margin: at $c=1201/1000$ the time
gap is $1/1000$ and
\[
 d(c)-\frac12=\frac{26275399}{2884802000}>0.
\]
Therefore the endpoint remains ready if the OPEN all-input phase is ever
constructed.  P versus NP remains OPEN.
