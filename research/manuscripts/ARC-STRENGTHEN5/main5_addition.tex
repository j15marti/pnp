\section{WRAPPER update: a clause-amplified current-portfolio guard}

For proper 3CNF $F$ with header maximum $q$ and $m$ clause occurrences,
introduce
\[
 h=q+1,quad r=q+2,quad w_v=q+2+v,quad
 a_j=2q+2j+1,quad b_j=a_j+1
\]
and set
\[
 G(F)=F\wedge(h\vee\neg r)\wedge(\neg h\vee r)
 \wedge\bigwedge_{v=1}^{q}P_0(h,v,w_v)
 \wedge\bigwedge_{j=1}^{m}P_0(h,a_j,b_j),
\]
where $P_0$ is the four-clause even-parity gadget.  The target has maximum
identifier $2q+2m+2$, clause count $5m+4q+2$, quasilinear complete encoded
length, and a polylog-time/logspace random-access generator.  It is SAT
equivalent to $F$.

This construction lies in the exact UNKNOWN domain of the current finite
portfolio.  Older rules fail by the binary clause, balanced signs, shared
hub, positive-pair triangles and absent flat marker.  Every non-hub DP pivot
leaves at least $q+m-1$ parity blocks in one component; the hub pivot
recreates the blocks around $r$.  Their exact encoded component is larger
than the $N^{1/2}\log N$ cap for every $q+m\ge4$, so
\textsc{PIVOT-FACTOR1} also returns UNKNOWN with zero child calls (or aborts
earlier at its charged acquisition cap).

Consequently the remaining domain is locally SAT-complete and has the same
simultaneous achievable time-space region as general SAT.  The current
partial prefix does not itself create the missing ARC transition.  This is
not a universal preprocessing lower bound: iterated BVE can strip the guard,
but only exposes the almost-parent-sized source core.  The OPEN target is
still one hereditary all-input favorable phase satisfying the aggregate
ledger, with every failed trial, executed child, replay, buffer, index and
ancestor frame charged.  Conditional aggregate $K$ elimination is preserved;
P versus NP remains OPEN.
