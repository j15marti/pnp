\subsection*{RECOVERY-STRENGTHEN6: exact replay is built; favorable hereditary closure is not}

The prior-work audit corrects one stale description without changing the ARC
status.  COMBINED-REPLAY1 is one terminating exact source-backed solver for
every finite CNF, and TRIE-BATCHACQUIRE1 implements exact batch residual
recovery for a supplied assignment trie.  RECURCLOSE1 separately proves
conditional recursive elimination of the initial exponent $K$.  What is not
proved is that one all-input realization satisfies the favorable child scale,
executed multiplicity/local work and simultaneous-space premises.

If a source-checkable marked domain were successor-closed---including every
nested certificate bit and renumbering map in the emitted child's encoded
length---then the current one-level parameters would compose exactly:
\[
 C=\max\left\{\frac{11}{10},
   \frac{3/5}{1-1/2}\right\}=\frac65,
 \qquad P=\frac12.
\]
This is a proved conditional promise-class consequence and preserves
$K$ elimination.  No current nested grammar or all-input certificate
constructor realizes its premise.

The flat marked language is not successor-closed.  For an unmarked $m$-bit
CNF $G_m$, put $G_m$ in one marked block and add $\Theta(m^2)$ charged global
tautologies over a one-variable cutset.  The parent has $N=\Theta(m^2)$ bits,
passes the $\sqrt N\log N$ child cap and emits $G_m$ under both cut values,
but the next flat-parser invocation returns UNKNOWN because $G_m$ has no
magic marker.  This is an unbounded family, not a finite-base exception.

A trivial ordinary-to-marked wrapper does not repair the typed cycle.  Linear
overhead leaves a child too large; padding enough to pass requires
$N=\Omega(m^2/\log^2m)$.  The expanding conversion followed by square-root
emission has no proved strict macro contraction.  CYCLEGAIN1, STREAMCOMP1 and
ORBITBATCH1 charge supplied edges/interfaces/address sharing; none constructs
the missing ordinary-to-hereditary transition.

The literature on recursive/component backdoors supports efficient replay of
a supplied bounded-parameter recursive certificate, not the all-input
implication from $\SAT\in P$ to cheap certificate acquisition.  The strict
FLMV finite-entry arithmetic remains valid in its deterministic random-access
model, subject to the still-open local encoding transfer.  P versus NP remains
OPEN.
