\paragraph{TESTS-0006: source-only terminal successors are endpoint-equivalent.}
For any fixed deterministic time--space resource class closed under constant
postprocessing, a source compiler that emits one of two constant proper
3-CNFs with the same decision as its input exists in that class if and only if
the source language already has a decider in the class.  Thus source-only
construction, a nonempty ordinary-CNF child, strict scale $\lambda=0$,
heredity, and one-bit reconstruction do not form an intermediate ARC bridge
when decision-dependent acquisition is allowed.  A construction-specific
non-Shannon identity with a fixed $K$-independent charged budget remains
OPEN.  No ARC point or lower bound is added.  P versus NP remains OPEN.  See
\texttt{research/review/reports/tests/2026-10-11\_1224\_TESTS-0006.tex}.
