\section{Extensional query-scale normalization does not repair the bridge}

RT-0015 proves two exact guards.  First, for
\[
 \underline\sigma(g)=\inf\{\sigma(E):E^{\mathsf{SAT}}=g,
 \ E\text{ uniform polynomial time}\},
\]
the counterfactual $P=NP$ implies $P^{\mathsf{SAT}}=P$ and hence
$\underline\sigma(g)=0$: substitute one fixed polynomial SAT decider for
every oracle call, yielding an extensionally equivalent oracle-free machine.
This is \textbf{PROVED/EXACT} as a conditional implication and retires
\texttt{SEMANTIC-INFIMUM-QUERY-LB1}.  It does not bound the ordinary runtime
exponent of the replacement.

Second, no total computable canonicalizer for all clocked polynomial-time
Boolean programs can satisfy $C(P)=C(Q)$ exactly when $P$ and $Q$ compute the
same function.  Given $M,w$, the polynomial program that simulates $M(w)$ for
$|x|$ steps and returns whether it halted is extensionally zero exactly when
$M(w)$ never halts.  Complete canonicalization would decide halting.
\texttt{POLY-EXTENSIONAL-CANONIZER-NOGO1} is \textbf{PROVED/EXACT} pending
independent review.

This specializes the earlier canonical-minimization and static-normalizer
guards; it does not contradict LB-0015's fixed-transducer accounting.  The
surviving target is an externally fixed, source-specific, fully charged
compiler into a model-matched forbidden region, independent of the unknown
polynomial exponent.  That target, arbitrary-decider transfer,
nonrelativization, nonalgebrization and P versus NP remain \textbf{OPEN}.
