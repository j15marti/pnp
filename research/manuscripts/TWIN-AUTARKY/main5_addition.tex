\section{One-child signed-twin autarky reduction}
The mixed branch of SIGNED-TWIN-MACRO1 already satisfies every clause
touching its class $G$. Therefore the stronger identity is
\[
 \operatorname{SAT}(F)=\operatorname{SAT}(F_{\neg G}),
\]
where $F_{\neg G}$ contains only clauses disjoint from $G$.
Every model of the latter extends by the fixed mixed assignment.
The all-zero and all-one branches are unnecessary. Disjoint nontrivial
signed-twin classes can be eliminated simultaneously. Reuse the
ARC-0009/DENSE-TWIN partition and charge a constant number of scans to
measure and emit the one remaining ordinary child.
The TWIN-AUTARKY reference model passed 14,393 finite checks; the previous
1,981,360-bit independent-component fixture now reduces to 96 bits.
An added arbitrary component can still survive unchanged. One pass can
expose new twins, so repeated scans require separate amortization.
Minimally unsatisfiable formulas have no nontrivial autarky; a different
reduction is needed for universal coverage. Full details and limitations
are in the 2026-10-08\_0056 TWIN-AUTARKY report.
P versus NP remains \textsc{Open}.
