\subsection*{TESTS-0005: pre-output is not pre-decision}
\texttt{PREOUTPUT-SERVICE-GUARD1} is PROVED/EXACT pending independent
review.  Any exact decider $A$ can be wrapped to decide $F$ first, suppress
the output, compute the exact covariant two-pin service using two additional
current-scale calls, and release the retained bit last.  The service is
pre-output but post-decision, with time
\[
 T_A(N)+2T_A(cN+O(1))+O(N)=N^{K+o(1)}.
\]
Thus pre-output chronology does not create a new ARC point and retains the
unknown exponent $K$.  A useful fractional-predecision compiler must instead
fix a source-defined checkpoint and exclude any prior current-scale decision
or decoded semantic shortcut.  The compiler and matched lower bound remain
OPEN.  P versus NP remains OPEN.  See
