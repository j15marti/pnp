\paragraph{REDTEAM forward-tag/inverse-incidence separation (RT-0013).}
For every $n=9b$ there is a tagged monotone $(3,3)$ family $F_\pi$, indexed
by a permutation oracle $\pi:[n]\to[n]$, in which a requested forward
literal and its sign-specific occurrence tag use one oracle query, while any
deterministic oracle algorithm that recovers the inverse location of an
arbitrary named output variable requires $n-1$ queries in the worst case.
The proof leaves two unqueried domain positions and swaps the target image
between two consistent permutation completions.  Thus full inverse incidence
is not necessary for the tagged second leg; it is optional offline
infrastructure.  The family is an all-YES hostile control, so a one-bit
promise decider need not expose either resource.  The concrete JMV forward
port-label theorem, a charged bi-local first leg, and every arbitrary-SAT
transfer remain \textsc{Open}; P versus NP remains \textsc{Open}.
