## 2. Guard and residual identity

Preserve the original IDs: native vertex and edge array indices are zero-based, port ID=4v+j; source CNF clause ID one-based, variable IDs positive integers. Newly introduced auxiliaries have a declared namespace and exact source map. Never transfer raw indices across different instance IDs without a verified mapping.

A root state uses guard EMPTY and residual ROOT, scoped by the full instance ID. For non-root guards publish a deterministic serialized guard artifact, using UTF-8 JSON plus LF; record guard schema version and SHA-256. For simple original-port or CNF-variable assignments, use sorted pairs [original-id,bit] in ascending numeric order, no repeated IDs and no conflicting assignments (contradictory guards require an explicit contradiction certificate). Specify namespace by schema, e.g. EB-PORT-PINS-v1, CNF-VAR-PINS-v1. More complex guards (affine equations, compound predicates, conditions on auxiliary variables) require exact versioned syntax and authenticated mapping into original semantics; hash their exact bytes, not an informal description. Do not declare two different syntactic guards equivalent without paid proof. Guard ID is SHA-256 of JSON.stringify(["PNP-GUARD-v1",full_instance_id,guard_schema,guard_artifact_sha256]) + LF, prefixed GUARD-v1:sha256:. EMPTY is valid only for genuinely unconditional deductions.

For each transformed residual publish the exact residual artifact and exact reconstruction/provenance map, or a pinned deterministic reproducer for their bytes. Declare residual representation schema. Record their full SHA-256 digests; identity map may use literal IDENTITY only when original IDs and witness map are unchanged. Residual ID is SHA-256 of JSON.stringify(["PNP-RESIDUAL-v1",full_instance_id,guard_id,representation_schema,residual_artifact_sha256,map_sha256_or_IDENTITY]) + LF, prefixed RESIDUAL-v1:sha256:. This prevents treating equal-looking projected tables under different guards or reconstruction maps as identical. Different derivations with identical declared bytes/guard/map may share a logical node, but physical verification and communication costs remain charged. A proved equivalence can permit a safe merge between distinct IDs; never merge by name, rank, size, or hash of only local occupancy.

## 3. Broadcast protocol (issue #328)

Every new verified message must have this header and supporting proof/cost data:

    problem_id: STRICT-EB4-v1
    instance: <registry short ID>
    instance_id: <full model:sha256:...>
    original_N_bits: <N>
    source_pin: <registry/manifest commit and path>
    guard_id: EMPTY or full GUARD-v1:sha256:...
    residual_id: ROOT or full RESIDUAL-v1:sha256:...
    original_ids: <affected original vertices/ports/edges or clauses>
    parents: <verified certificate IDs and comment links>
    claim: <precise quantified deduction>
    certificate: <pinned artifact/checker; discovery and verification cost; scope>
    certificate_id: CERT-v1:sha256:<SHA-256 of exact certificate artifact bytes>

Certificate artifacts exclude their own ID (avoid circular hashing) but include instance, guard, residual, claim, original IDs, parent IDs, proof data and checker specification; publish as a pinned file or exact reproducible bytes. Certificate ID is content identity, not proof validity. Verify actual proof and all dependencies separately. For proofs of identity of two sources, list both full instance IDs and the adapter/checker. For branch joins, list all child guards, residual IDs and checked coverage; no guard is discarded. Distinguish source-only vs provenance-assisted experiments, charge hash computation, validation, serialization, map reconstruction, communication and all failed work. No free semantic canonicalization.

Post to https://github.com/j15marti/pnp/issues/328 after verification; read and replay before importing. If a historical certificate lacks IDs, recover exact source bytes and mapping first or treat as an unverified lead. Log mismatches and conflicting claims, not silent imports. Deduplicate using full instance/guard/residual/claim/model and parent provenance, and preserve scoped rejection versus universal P=NP/P!=NP. The common theorem remains OPEN.
