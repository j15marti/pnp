## New scoped global root credit lemma (proof, independent review pending)
Fix original root Boolean coordinates x (r<=O(N), original port IDs or a verified affine chart), fixed degree d, and a fixed uniform polynomial number h of registered consumers. Let P_d be the square-free Boolean polynomial space over F2, D=sum_{i<=d} binom(r,i). W is the span of root-coordinate certified identities vanishing on every root feasible assignment. U_j is a monotone span of identities independently checked and admitted by consumer j in root coordinates, U_j subset W. For a guarded chart deduction p=0, require a verified map from root assignments in guard G to chart coordinates, and an explicit root polynomial q=I_G p(map(x)) (or another independently proved vanishing root identity). Admit only if degree <=d and representation/construction/check cost paid; nonaffine maps are permitted only when this certificate condition is actually checked. A guarded refutation lifts to I_G=0. Polynomially bounded root basis is fixed, even when local chart ranks shrink, representations are rolled back, or consumers use distinct coordinates. Define
Phi=(D-dim W)+sum_j(D-dim U_j).
Independent producer import decreases Phi by at least one; a consumer's first independent acceptance decreases its term even if producer rank unchanged; exact duplicate spans cannot reset credit. Proof: rank monotonicity on fixed P_d. Initialize Phi <=(h+1)D; polynomial for fixed d, h polynomial. With fixed polynomial epoch allowance B(N) covering all actual attempted discovery, verification, maps, failed transfers, storage and rollback, psi=(B+1)Phi+b decreases for each charged work unit or committed strict rank event. No restart without strict decrease. Per-consumer admission is logical root credit, not assertion that a local chart will exploit a dependent identity. Branch obligations must use guards and share the fixed root ledger; do not give each new branch fresh credit. Separately charge any branch expansion or chart changes lacking a strict rank decrease; they can occur inside an epoch only. Guard codimension and pullback degree may blow up; singleton guard on r bits has degree r, so cannot be admitted at fixed d. Rank exhaustion may leave unresolved feasibility, even if all source packets represented. Thus this lemma covers heterogeneous exports that satisfy the check, not arbitrary contractions or UCAC. First OPEN arrow: every unresolved NO state must acquire at least one new checked root rank, independently credited event or exact terminal within uniform polynomial epoch work; no assumption of favorable chart or universal low degree. On YES, all admitted root identities vanish on actual witnesses; constant 1 cannot be admitted soundly.
