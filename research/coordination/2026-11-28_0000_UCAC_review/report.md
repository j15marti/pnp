## Scoped theorem: insertion-only implication response and credit
Let T be reflexive transitive reachability of q signed literals in a fixed chart and insert edge u->v. T'=T union (Pred_T(u) x Succ_T(v)). Any new reachable pair has a simple witnessing path using the inserted edge once; converse by path concatenation. For a binary clause insert both implications sequentially, unit gives repeated edge. For a consistent 2CNF region, exact existential boundary relation is a 2CNF obtained by eliminating interiors via all non-tautological resolvents; each new binary resolvent corresponds to concatenating implication paths, with unit represented twice. Restrict closure to boundary literals and add implied units; if base has complementary literals in same SCC return false. Exactness also follows by resolution elimination (both signs of eliminated variable cannot be forced by retained assignment without a falsified resolvent). Width <=2 throughout; <=2b^2 nonempty boundary clauses, not support-count guarantee. Verify witnesses via 2SAT on region with boundary pinned.
For fixed q, set potential Phi = (q^2-|T|)+(q^2-|E|), E the distinct inserted arc dictionary. Every unique arc or independent reachability lowers credit; duplicate, failed, checking and consumer work charged from fixed epoch B(N) with no refund. Fixed q poly(N), O(q^2) arc updates per distinct arc, <=q^2 arcs, O(q^4) conservative word work and q^2 matrix storage plus proof reasons; indices O(log q) bits. If all pairs are exported at most once to h polynomially many fixed consumers, extra h*q^2 credits suffice. Reconstruction via paths or checked resolution; no credit for rescoping/guard change without separate proof.
