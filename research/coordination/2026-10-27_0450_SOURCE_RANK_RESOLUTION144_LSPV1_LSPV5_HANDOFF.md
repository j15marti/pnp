All modules share the same actual boundary IDs Y; their clause-variable incidence graph is connected.

Variables n=b+2r+2^t(b-3); original clauses m=4r+2^t(b-2); modules k=r+2^t. Full source F_{r,t} is UNSAT. Deleting any one whole module makes the remaining source SAT. Thus the minimum UNSAT whole-module support is k, exactly matching the earlier Role-3 AFFINE-EXCEPTION-RANK143 abstract bound.

First resolve each pin into a unit in 3 steps; sequentially eliminate each exception chain's b-3 local wires and resolve it against the r pin units; then resolve the 2^t complementary t-bit clauses in a binary reduction using 2^t-1 steps. Every chronological line, original premise and pivot is replayed independently in the published verifier. This is a direct countercontrol to assuming that many essential source modules imply expensive proof acquisition.
