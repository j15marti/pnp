# LSPV-1 ARC229: Edge-bijunctive message composition (2026-10-29 13:00 PDT)

**PROVED/EXACT, RESTRICTED, independent referee pending.** Given a polynomial-time discovered/verified tree of source-authenticated mixed 2CNF plus GF(2) modules, each source constraint owned exactly once, running intersection, and local affine coefficient rank at most a **fixed** e0, solve both SAT and UNSAT by compiling each child's complete edge message into exact **2CNF** before the parent call. If all **edge** separators have size <=2, all child messages are automatically 2CNF-definable. No requirement bounds the union of a node's shared names. No free SAT/UNSAT class bit, advice, oracle, or uncharged joins.

For logarithmic edge widths the same deterministic procedure is sound and complete **on the restricted promise that every computed message is bijunctive**. It independently recognizes this property from the complete table. It returns UNKNOWN if not, never an unchecked answer. Bit-time: `D(N)+poly(N) * sum_t 2^|S_t| (|V_t|+1)^{O(e_t)}`, with D including discovery, complete source and running-intersection validation. Full table storage, all failed AG-style branching, message conversion, joins, physical output, original witnesses and peak space are charged. Every fixed local e is known XP polynomial by Arvind and Guruswami, IPEC 2021, Theorems 2/17. Their Theorem 19 is W[1]-hardness for growing parameter e, not a non-FPT theorem.

**Exact distinction from ARC228 and LSPV5 referee:** The already verified ARC228 raw-table bound charges full B_t. LSPV5's star has center full B0=2q, edge widths 2 and each local affine rank 1; the raw method needs 4^q entries. Here every child exact message is the **binary equality relation**, represented by two 2CNF clauses. The center solves one XOR equation plus q equalities using the known fixed-e=1 solver, requiring only `4q+1` local calls. Both SAT (`center_rhs=0`) and UNSAT (`center_rhs=1`) are decided, despite all q leaf constraints being essential to UNSAT. This is not a lower bound for arbitrary algorithms.

**Counterexample:** one rank-1 child producing the odd-parity relation on 3 shared names has models `{001,010,100,111}`. Majority of 001,010,100 is 000 outside the relation. Therefore exact 2CNF re-encoding fails; the prototype correctly returns `UNKNOWN_NON_BIJUNCTIVE`. Additional structural hypotheses or a compositional richer grammar are necessary at edge width 3 or more.
