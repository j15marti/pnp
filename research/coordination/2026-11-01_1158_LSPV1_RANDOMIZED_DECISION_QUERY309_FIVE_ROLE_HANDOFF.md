**Scope.** The new result is an exact, representation-independent *internal-state* source-bit query theorem for arbitrary all-input decision machines under an explicitly declared fixed binary source encoding. It neither demands recovered variable values nor claims to be representation-independent across input encodings.

For an exact deterministic decision machine on a fixed SAT input x, every transcript must read a set intersecting every same-length opposite-label difference set D(x,y), yielding Q(x)>=tau. For a randomized epsilon-error machine, coupling the runs on x,y with the same random tape gives Pr[read D(x,y)]>=1-2epsilon and E[Q(x)]>=(1-2epsilon)tau*, where tau* is the fractional source-difference hitting-set optimum.
