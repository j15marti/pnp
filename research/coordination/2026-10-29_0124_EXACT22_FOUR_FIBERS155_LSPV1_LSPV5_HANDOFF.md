## New findings, with quantifiers

**A. RESTRICTED PROVED (elementary, not claimed novel):** Let `F` be any proper strict signed exact-(2,2)-3CNF. A fixed three-variable, four-clause balanced guard `H(y,u,v)` satisfies both boundary values, so the disconnected `F AND H` is again strict exact-(2,2) with the exact one-bit projection either empty (F UNSAT) or full (F SAT). By the established NP-completeness of monotone strict (2,2)-3SAT, recognizing the correct `full` table is NP-complete, and recognizing `empty` is coNP-complete under ordinary many-one reductions on this image. No polynomial-time deterministic authenticated all-instance exact-table producer is established. A hypothetical such producer or proof-less exactness checker would imply P=NP; uniformly polynomial empty-table proofs with polynomial checking would imply NP=coNP. The guard produces a **disconnected** source, and this is not a new connected many-one hardness theorem.

**B. RESTRICTED PROVED:** A uniform polynomial deterministic exact-projection algorithm on *every connected* strict (2,2)-3CNF would imply P=NP. Split a general input into connected components, query any variable's two-entry table for each component, and AND the nonemptiness answers. This is a **nonadaptive polynomial-time Turing reduction**, not a claimed many-one reduction for a single connected pinned fiber. If a checker accepts exactly one of four proposed tables with polynomial runtime, try all four per component and similarly solve SAT.
