## Scoped nonrenewable credit theorem
Fix source, guard, a polynomially acquired finite dictionary of regions U, total widths k_U<=c log_2 N, and monotone admitted constraints (no deletion/restoring feasible words). Each region stores all surviving full assignments T_U plus boundary fiber multiplicities. Each newly verified contained constraint deletes exactly violating live words. Each deleted full word removes one witness credit; a boundary word disappears iff count reaches zero. Let A be set of distinct admitted region/constraint keys from a polynomially bounded explicit dictionary J. Phi_local=sum_U |T_U|+|J|-|A|. Initialization <=sum_U 2^k_U+|J| polynomial, every new admission decreases by >=1 even if no new deletion. Count separately failed attempts, duplicate deliveries, mask construction, comparison and certificate checks through one epoch budget; no refund on rollback. Dynamic dictionaries cannot be silently reset. For genuine exact globally eliminating contractions in a fixed guard with no variable resurrection, use root-coordinate n-|E| plus M-|L| for verified unique width<=w original-coordinate clauses (M=sum_{i<=w}2^i binom(n,i)), plus explicit polynomial consumer-admission dictionary credit if required. Every accepted genuine global elimination adds one previously uneliminated variable to E; every new bounded root clause enters monotone L; neither is reset when local tables are rebuilt. With fixed polynomial representation bound, epoch cap B(N), potential (B+1)Phi+b permits rebuilding finite region dictionaries only after a genuine paid progress event, including failed work and storage. Width O(log N) makes individual tables polynomial but all possible logarithmic scopes are not polynomially many; selection/discovery remains a paid unresolved step.
