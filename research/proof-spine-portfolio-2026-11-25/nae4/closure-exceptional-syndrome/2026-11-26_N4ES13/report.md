## B. Cap theorem and paid recurrence (PROVED)
In any connected extended graph G with n vertices, let a bipartition A,B with sizes a<=b, a,b>=2, have 1<=k<=4 actual crossing edges, ordered and retained by original ID. Replace the opposite shore by ONE new vertex with these k ports. For every complement pair {t,t+1} in F2^k, recursively solve A with cap relation consisting of that pair. Record an actual full witness and retain the pair iff feasible. In self-dual case at most 8 small calls; if a small call returns UNKNOWN do not call that pair infeasible. Empty attained support proves NO; otherwise solve B once with cap containing exactly all attained pairs. Every original model projects into accepted B cap. Conversely, a B witness selects actual t; retrieve A witness for its pair, complement A if necessary to match t, merge internal edge assignments with actual crossing IDs, verify every original factor. All A constraints remain valid under this complement. No marginal, affine hull, determinant surrogate or target-supplied tuple used. If any absolute/non-self-dual relation is present, use up to 16 singleton profiles, no complement operation. All child graphs remain degree<=4; capped graph connected because every component of a shore must meet a crossing edge. Components of an initially disconnected graph factor independently. This includes FN08 two-edge parity cap as special case with full joint tables (their direct edge contraction is tighter). No graph embedding needed; no planarity assumption.

Measure mu(G)=n-2 for n>=3, base cases n<=2 constant. Children have a+1 and b+1 vertices, mu=u=a-1, v=b-1 respectively, with u+v=mu(parent), 1<=u<=v. Self-dual:
8u^4+v^4 <= (u+v)^4-1
because expansion difference >= (15-8)u^4 >=1.
General guarded: 16u^5+v^5 <= (u+v)^5-1 by expansion difference >=(31-16)u^5. Hence <=mu^4 (or mu^5) paid recursive calls including rejected profiles, no caching assumption or equal-child double recursion. Every child strictly smaller. Disconnected components independently run; sum n_i^c<=n^c. This directly bypasses RT39's two nearly full children when a genuine small cut exists, not an unrestricted bound on RT39 jobs. All prime leaf solvers must still be charged. Exact discovery in polynomial time: enumerate edge subsets of sizes1..4; after deletion at most5 components; enumerate their unions, check actual cut and shore masses. Does not require a supplied decomposition. Implemented audit uses only prefix discovery followed by exact exponential DPLL; production exhaustive cut discovery and polynomial universal prime backend NOT executed. Graph sizes never increase along branch; per cap <=16 rows of <=4 bits. IDs and counters O(log N) bits (renumber while storing source maps), per node polynomial scans including failed candidates. Store up to eight or sixteen small witnesses until larger call returns; conservative total O(poly(N)) if leaf backend polynomial, since node count polynomial and each witness O(N log N) bits; cumulative memory <=(T+1)S on same serial execution. No counting oracle, arbitrary equivalence/canonicalization or uncharged recomputation. ## C. Exact cap taxonomy (PROVED)
A self-dual arity k relation is an arbitrary subset of F2^(k-1) via differences x_i XOR x_1. For k=3 there are 16 tables, 12 affine including empty: empty, 4 singleton, 6 two-point lines, full. The other four exclude precisely one quotient point, equivalent to one signed NAE3. For k=4 there are 256 tables, 52 affine including empty (1+8+28+14+1). Every table can be written as conjunction of at most 8 signed NAE4 constraints, one per excluded antipodal pair; choose signs that make that pair all-equal. Each signed NAE4(a,b,c,d) is equivalent to exists z NAE(a,b,z) AND NAE(not z,c,d): if both pairs monochromatic, forced z values conflict precisely when all four equal; if either pair mixed its clause imposes no restriction. Thus exact finite guarded affine/nonaffine cap language with witness lift, but no claim that expanding caps preserves source incidence regularity or improves recursion mass. Keep caps as single tabulated vertices in recurrence.

## D. Raw source geometry and stronger FN08 prime obstruction (PROVED)
For a shore with V variable vertices and M_j owner vertices of color j, net signed crossing incidence count in color j equals V-3M_j. Hence counts congruent mod3. At cut size<=4: size1 impossible; size2 same color opposite orientation; size3 same color all same orientation (unaffected color forces every count divisible3); size4 either balanced net zero for every color (at most two colors used), or exactly one incidence per color all same orientation (all four used). For latter, choose side with all crossings leaving its variables; V-3M_j=1 for every j.
On SAME FN08 cyclic grid: prime p>=5, L=floor sqrt(p), shifts 0,1,L,L+1 distinct mod p; clauses (A_i,B_{i+s},C_{i+2s}) with index mod p. Four perfect partitions and linearity by distinct shifts and 2 invertible mod p. Any two colors connect all variables: A_i reaches A_(i+s-t) through B, nonzero shift generates Z_p; B,C attach. Thus any cut confined to <=2 colors cannot split variable vertices. A shore without variables contains independent owner vertices of degree3, so cut<=4 then it has at most one vertex. Only possible remaining nontrivial 4-cut is one crossing per color all same direction. For its outgoing shore, V=3q+1, M_j=q all j. Each color partitions the shore's variables into q complete triples and one leftover vertex. Therefore exactly one of the three variable fibers contains q+1 selected indices, the other two contain q each. The two non-excess fibers are matched in every color without leftovers. For excess A, B and C selected index sets differ by shift s for each s, so s=0 and1 imply invariance under +1, hence both sets empty or full. For excess B, A and C differ by shift 2s, likewise invariance under +2; excess C analogous using +1. Since excess fiber has at most p variables, q=p impossible; q=0 yields a single variable and no owner. This excludes ALL nontrivial cuts of size<=4. FN08's grid minor (contract shift0 stars, retain shift1 and shiftL edges) contains L-by-L grid, so treewidth unbounded. This strengthens FN08's obstruction, but GF3 still solves SAME family as in FN08: if A+S^s B+S^(2s) C=0, shift0 vs 1 and L gives B+(S+I)C and B+(S^L+I)C constant; subtract and sum implies (S^L-S)C=0 since p!=3. All A,B,C constant; dimension2, a nonconstant ternary word forces every triple rainbow (sum zero), so Boolean zero-vs-nonzero solves. No universal prime obstruction to all algorithms.
