## A. Exact conditional two-class factorization (PROVED)
For a verified two-sheet incidence lift of a genuine NAE4 base, each base clause c=(u,v,w) has incidences with offsets e_ci in F2, and physical copies indexed by t in F2. Check every original incidence, partition color, and orbit ID before using this chart. Equivalently a supplied color-preserving fixed-point-free involution must have an actual quotient with three distinct variable orbits per clause and the correct local bijection; otherwise reject chart, not source. Write physical assignment x_(i,0)=a_i, x_(i,1)=a_i+d_i, with d_i in F2. This is a bijective change of coordinates, not a quotient assuming orbit constancy. For fixed d define y_i=a_i+e_ci*d_i in clause c. Its two physical clauses are exactly NAE(y) and NAE(y+d|c).

If d|c constant, they are one signed NAE(y). If d|c mixed, there is a unique pair i,j with equal d. The pair must have opposite y values: if equal, the third y would need to differ from that common value both before and after the sheet flip, impossible since its d differs. If opposite, both clauses already satisfied, regardless of the third. Thus replace the two clauses by a_i+a_j=1+e_ci*d_i+e_cj*d_j. No integer or joint support approximation.

Every resulting constraint lies entirely within d=0 or d=1. For a fixed mask, the source thus factors into TWO independent signed NAE+XOR systems, with actual bijective lift a -> (a,a+d). Physical coordinate pins translate to pins on a_i, preserving this split; general linear guards may couple the classes and must be retained and solved jointly or excluded from this terminal. Initial unguarded source has no absolute forced bit by complement symmetry; anchor optional. Under a fixed mask run parity graph/BFS or Gaussian closure, substitute all exact signed equalities, simplify repeated/equal/opposite literals, rerun after each deduction and at stagnation. Contradictory signed cycle certifies mask NO only. For each class with no additional coupling guards, solve remaining affine avoidance by rank-independent representative method: each owner has up to three nonzero directions, choose a direction with value different from forbidden pair's implied value. Rado condition r(S)>=|S| for every subset gives independent directions by linear/partition matroid intersection; independent equations admit every right-hand side. Rank failure is UNKNOWN, not NO. A remaining component of <=c log2 N variables may be exhaustively solved for fixed c. All physical clauses and original guards verified before returning SAT. If d is supplied as a legal guard, both class decisions exact when admitted; if d is only a candidate, no unconditional inference from its failure. Candidate masks from a uniformly acquired affine subspace of dimension <=c log2 N may all be tested in poly(N); coverage remains open. Even if both class sizes shrink, enumerating all 2^b masks (b base vars) is not a productive recurrence.
