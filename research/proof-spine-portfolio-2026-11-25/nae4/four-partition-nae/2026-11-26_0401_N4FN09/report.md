## 3. Rank-cut acquisition theorem (PROVED)
For any explicitly acquired nonempty L and connected factor multigraph with V vertices, E edges, define r(S)=rank of {b_e:e in delta(S)} over F2 for shore S. This equals dimension of projection of L to the ACTUAL crossing bits. Fix any constant r0>=0.
Enumerate all independent sets of <=r0 edge coordinate vectors, indexed by actual edge IDs (include empty basis). For each set Q form U=span(Q), remove ALL edges whose b_e lies in U, then find components. Any union of components with both shores >=2 yields a cut of rank<=r0. To find such a union without exponential subset search, take any single component of size 2..V-2, else choose two singletons if available (V>=4); if neither exists, only a component of size V or V-1 with at most one singleton is possible. Conversely if a nontrivial cut of rank<=r0 exists, its edge coordinate vectors have an independent basis of <=r0 actual members; enumerating it removes all crossing edges, and the original shore is a union of components. Thus the algorithm necessarily finds an admissible cut, not necessarily the original one. O(E^r0 poly(N)) deterministic bit work with fixed r0, using Gaussian membership and graph scans, including failed probes. No bound on physical cut cardinality or graph degrees required. This is stronger than enumeration of a fixed number of edges or parity classes: correlated edge forms can be distinct but lie in a low-dimensional span. Enumeration for r0 growing as log N is not a polynomial guarantee.

## 4. Exact filtered cap theorem (PROVED)
At a current node split A,B with vertex masses a<=b and a,b>=2. Boundary S=delta(A) in actual order, k=|S| may be linear. Let P=projection_S(L), affine rank r. Enumerate precisely its 2^r words by a basis of P, not all 2^k physical words. If current problem self-dual, P invariant under complement and k>0, so use 2^(r-1) antipodal pairs; otherwise singleton words. Solve smaller shore A for each word/pair with a single cap factor of that exact row/pair, obtaining an actual local witness on success. If any profile UNKNOWN, do not infer it infeasible; this partial implementation may decline the seam. Let D be the UNION of all acquired feasible rows in P. Importantly D = P intersect exact local response of A, not necessarily entire local response; P may contain deductions from B. If D empty after all queries resolved, reject. Solve B ONCE with cap D. Every full parent model has its boundary in P, and its local A realization proves that profile attainable, hence the restriction to B passes. Conversely, any B model selects actual t in D, retrieve corresponding A witness, complement entire A if needed and permitted to match t, then glue on exact edge IDs; every original parent factor is satisfied. Thus global affine filter is safe, even when its equations span both shores, with no illicit inference that A alone implies them. Child closure is reacquired on the child graph, not copied from parent absent a valid local certificate; arbitrary guards retained. Store actual witnesses for all retained rows and verify parent factors. If explicit affine equations were additional parent constraints rather than consequences, they must be represented as factors before cutting. All caps store explicit rows of k bits, not all possible k-bit assignments, so arbitrary cap arity permitted with paid table length.
This closes an exact bridge between owner-plane rank information and the peer's cap composition. It does not claim that affine hull itself is an exact response, or that rank of a marginal suffices for joint compatibility.

## 5. Charged recurrence (PROVED conditional on terminal coverage)
Let mu=V-2, u=a-1, v=b-1. Each child includes one cap vertex, masses u and v, u+v=mu. Use <=2^r small calls and one large, including failed probes. If r<=r0 fixed, choose c=max(2,r0+1). Binomial expansion and v>=u imply (u+v)^c-v^c >= (2^c-1)u^c. Therefore 2^r u^c+v^c <= mu^c-1. Complement pairs only improve budget. Root recursion <=mu^c nodes without memoization; for r0=0, c=2 also valid. Independently solved disconnected components may be factored; one can use root sum-of-powers budget or process them as separate root jobs (sum V_i^c<=V^c). No increase in edge count within any child; each newly introduced cap table has <=2^r rows of <=E bits. All previous caps retained at most original V count per child. Thus for fixed rank the entire node representation and all Gaussian work, filtering, discovery, row generation, verification, reconstruction and stored witnesses polynomial in N; total time polynomial with paid polynomial terminal backend. Original IDs O(log N) after normalization, all field operations constant-bit plus polynomial indices. Serial peak space polynomial, cumulative <=(T+1)S. No oracle or free canonicalization, no integer coefficient growth. A bounded exact terminal (e.g. constant/log number of actual independent bits with explicit factors) suffices for a scoped algorithm, not guaranteed universally.
Extension: if a discovered cut satisfies mu>=16, u^2<=mu and r<=floor(log2 mu), then 2^r u^4+v^4<=mu^4-1: v>=mu/2, v/u>=sqrt(mu)/2, so 4(v/u)^3>=mu^(3/2)/2>=2mu; the 4uv^3 term alone dominates the small-call cost by >=1. Large cap tables then have <=mu rows, still polynomial. This is an acquisition-CONDITIONAL logarithmic-rank/unbalanced recurrence, NOT a polynomial algorithm to find all such cuts. Fixed-r discovery and variable-r recurrence are separate obligations.

## 6. Genuine wide seams, exact infinite compiler (PROVED)

Replace each original variable i by ring of L=4t such modules, all deleting same partition's two rows. Exact phase opposition along ring; even L gives phase z_ij=x_i XOR (j mod2). Negative row ports all remain, with value x_i XOR (j mod2) XOR1. There are 6t ports of each sign for each i. Internal positive connectors use formerly uncovered same-row pair and fresh cross-module pairs; external owners use different rings and disjoint occurrence slots. No repeated unordered pair, all four perfect partitions exact. Raw G has 36tn variables,48tn owners. Connected if F connected, because each module, ring and inter-ring connectivity follows original incidences. This is arbitrarily wide with one complement profile. These seams are acquired without source labels by FN04 neighborhood scan and parity union of equal-pair NAE clauses. Each local motif's interior variable sees all nine module variables; exact ten-line missing-pair test identifies it. Group disjoint detected motifs by acquired phase root; gather every actual fully internal owner; require every crossing port to depend on same root. Construct both local words by phase and private NAE row, verify all internal owners and crossing bits. This verifies exact local support, not merely two candidate rows. For general inputs if motifs overlap, coverage missing, or nonphase/mixed ports arise, scoped implementation declines. Generic affine-basis cut theorem does not depend on this ring detector.
Entire family remains NP-hard, even with all rank-one profiles and regions supplied: one may choose t=1 or polynomially growing t=n; exact joint quotient is arbitrary original F after local phase gauge and deduplication, independent interiors discharged. No unrestricted lower bound; compiler can be unwrapped in P, returning an arbitrary hard source is not progress toward solving it.
