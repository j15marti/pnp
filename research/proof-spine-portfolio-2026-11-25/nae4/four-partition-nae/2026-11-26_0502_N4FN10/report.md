## 2. Sparse-coordinate proxy theorem (PROVED)
Given an explicitly acquired affine search chart for actual edge bits x_e = a_e + b_e z over GF2, permit redundant latent coordinates (need not injectively parameterize words), but require image contains all root models. All explicit independent guards remain actual factors. For each latent coordinate j form graph H_j with edges e such that b_e[j]=1, ignoring isolated vertices. Split H_j into its edge-connected components (ordinary connectivity on endpoints). Let s=max row Hamming weight, d=max number of nonempty components of one coordinate, h=max(1,s*d). For a cut S, let r(S)=rank of crossing rows and w(S)=number of component endpoint sets meeting both shores. Claim r(S)<=w(S)<=h*r(S).
Proof: active coordinates J are exactly those with nonzero entry on at least one crossing row. Each such coordinate has at least one and at most d split support components, because connected support meets both shores iff an edge crosses. Thus |J|<=w<=d|J|. Rank r<=|J|. Select r linearly independent crossing rows spanning all crossing rows. Every active coordinate occurs in some basis row, because a coordinate zero on every basis row is zero on their span. Each basis row has <=s ones, hence |J|<=s*r. Constants and affine offsets do not affect rank. All bounds apply to actual edge IDs, all shores, no independence between coordinate forms required. Components and sparse support certifiable by scans.
This strictly extends ES14 beyond independent distinct directions and beyond connected supports for each direction. For example include every e_i+e_j for all pairs among t coordinates. Number of distinct nonzero directions is quadratic, rank t-1, no bounded matroid-density assumption; rows have weight2. If each latent support connected, h=2. A basis of the span of rows is NOT required as the supplied coordinate system. A convenient redundant system can be retained.

## 3. Uniform mass-sensitive acquisition (PROVED)
Each support component's endpoint set is one hyperedge. Its split indicator can be minimized by the same exact Lawler directed cut gadget as ES14: auxiliary in/out nodes, in->out capacity alpha, arcs v->in and out->v of capacity M for every endpoint v. Anchor source shore A and sink shore B by M-capacity arcs, and mass penalty beta by arcs v->sink. M=alpha*#components+beta*V+1. For disjoint anchors and nonnegative integer alpha>0,beta, mincut exactly minimizes alpha*w(S)+beta*|S|; no M arc in optimal legal cut. Use actual rank only when verifying output, not as unsupported submodular shore objective.
At V>=4 put mu=V-2; for smaller shore size a>=2 put u=a-1, v=mu-u. Fix K>=1 and h0>=1 constants; admit charts with h<=h0. Call a seam K-admitted iff 2^r u^K<=mu^K. Enumerate u=1..floor(mu/2), q=0..floor(h0*K*log2(mu)) (integer length upper bounds adequate), all disjoint anchor pairs on each shore. Use alpha=u,beta=q. A true admitted cut with proxy q=w satisfies q<=h0*r<=h0*K log2(mu/u), so its u,q,anchors appear. For the minimizing shore S' of that probe, u*w'+q*(|S'|-1)<=2u*q. If q=0 then w'=r'=0. Otherwise w'<=2q, smaller mass u'<=|S'|-1<=2u. L=log2(mu/u), L'=log2(mu/u')>=1 and >=L-1, hence L<=2L'. Therefore r'<=w'<=4h0*K*L'. Check exact output integer inequality with Q=4h0*K, return any passing seam. If none, no K-admitted seam exists in that chart. The output guarantee is bicriteria, not exact constrained rank-mincut. O(V^5 log V) flows for fixed h0,K; network polynomial in explicit chart, capacities polynomial bit length. No logarithmic basis enumeration. Fixed rank FN09 remains fallback for unadmitted charts.
The audit uses h of actual chart as bound and skips q when ceil(q/h) violates original K admission, safe because true q<=h*r. A direct exact integer comparison avoids relying on approximate logarithms in production.

## 4. New hereditary search-chart invariant (PROVED)
Problem: a global sound relaxation may contain deductions requiring BOTH shores. Its projected chart need not contain ALL models of a capped child. Copying it as a certified local theorem is invalid. We can nevertheless retain the chart without losing root decision completeness by using one-sided semantics at every call.
For a call on actual local factor network G and an affine chart L (not necessarily sound on all G models), require:
YES returns a verified actual G model, not necessarily in L;
NO establishes absence of a G model IN L;
UNKNOWN carries neither conclusion. At the root every actual model is in L, so this is ordinary exact decision there. At every node delete local rows incompatible with the projection of the inherited L by Gaussian feasibility of each listed row; run domain support closure initially, after deductions and at stagnation. These operations preserve all L-compatible models and any accepted solution still satisfies original local tables. A leaf may solve actual G exactly, or solve G restricted to L and verify actual factors. Terminal cost and admission paid.
For a cut, enumerate boundary projection P of L via a basis of projected column span, not all physical bits. For each profile p in P, solve the smaller shore A with singleton cap p, inheriting the UNCONDITIONED projection of L onto its surviving edges; record every YES witness. Do not call conditional NO an absolute local infeasibility fact. If any unresolved profile could matter, do not reject. If all profiles resolved and none accepted, return NO. Otherwise solve larger B once with the table of accepted boundary words D and its inherited projection of L. If B returns YES, choose its actual cap word p and glue stored A witness matching the exact original edge IDs. Every original local factor survives on one side, so actual G model follows. If parent had an L-compatible model, its boundary p is in P, its A restriction is in inherited L_A and hence recursive completeness forces A to accept p, and its B restriction is in inherited L_B with cap D, forcing B to accept. This proves the invariant by induction. Crucially D is a witness-certified subset of local attainable boundary words, containing all boundaries of parent models in L; it need NOT be the entire local response intersect P because a child NO may be conditional. Do not export D as an exact reusable response under arbitrary new guards. If an exact full local response is required, reacquire locally sound chart or perform exact local solve for every profile.
Keep actual independent constraints/guards as factors; replacing an independently imposed guard by a chart-only hint would make YES unsound. No complement reduction assumed; use singleton profiles. No SAT-equivalence oracle or local target assignment. Source final verification mandatory.

## 5. Hereditary sparsity and charged recursion (PROVED conditional on leaf coverage)
A capped child is the quotient of the parent's graph obtained by identifying opposite shore vertices with the new cap, deleting edges internal to that shore. Edge forms and offsets on surviving actual IDs are retained, without Gaussian reparameterization or conditioning. Each old coordinate support component has connected image after this contraction, except if it vanishes; different components may merge, not split. Thus s and d never increase. Retain the same redundant latent coordinate system throughout; optional stronger deductions may be used as filters but need not replace this chart. For fixed h0,K use the same Q=4h0*K and c=Q+2 throughout. On every admitted cut 2^r u^Q<=mu^Q. Then 2^r u^c<=mu^Q u^2<=u*mu^(c-1)/2 because u<=mu/2. Also mu^c-v^c>=u*mu^(c-1). Therefore 2^r u^c+v^c<=mu^c-1. At most mu^c recursive nodes, including unsuccessful profiles and recomputation, no memoization. This is conditional on finding an admitted seam or paid polynomial terminal at every reached node; no universal coverage proof.
Each cap has <=mu^Q rows of <=E bits. Edges and vertex counts never increase along a branch. Original chart columns, factor rows, actual ID maps and guards have polynomial bit encoding. Polynomial Gaussian row feasibility, projection-basis generation, flow construction/failed probes, cap storage and witness reconstruction per node; leaf solver charged. Serial peak space polynomial on same execution; cumulative <=(T+1)S. No free canonicalization or assumed overlap savings. For disconnected graphs, cannot infer joint chart feasibility by marginal compatibility; either use the same cut proof with zero boundary or solve actual independent components with one-sided invariant: any root chart-compatible solution projects to each component, and independent actual component models glue. Sum powered masses bounded by total powered mass with base-case offset. Explicit cross-component guards must be factors and would prevent independent factorization.

Limitation: for a chart containing every nonzero row direction in a rank-D vector space, any equivalent latent parametrization, even redundant, has a row of weight >=D.
