## 2. Two-cut geometry (PROVED)
Use bipartite incidence graph, variables each with four incidences, one per color, each owner with three same-color slots. For a vertex subset with V variables and M_j color-j owners, V-3M_j equals #crossing edges from internal variable to external owner minus #crossing edges from external variable to internal owner, of color j. A single edge cut impossible by reduction modulo3 in an unaffected color. For exactly two cut edges there is an unaffected color, so every V-3M_j is divisible3; hence the two edges must have the same color and opposite directions. In a connected bridgeless graph removing a 2-cut leaves exactly two components: three or more would require at least two edges leaving each component in the original, exceeding total4. In each component cap its two cut ends by one new variable-to-owner incidence of the same color. The capped graphs stay connected and retain all four variable degrees/colors and all owner arities (allow repeated variable slots/parallel edges in caps; no assertion that linearity remains). They are also bridgeless by the same count. No new vertices, and each side has V=3M_j for every j. Full observation rank on connected variable co-occurrence graph is V-1, so raw full-family deficiency of each capped side is V/3+1. Sum of these full-family deficiencies is parent full deficiency+1; no deficiency-paydown claim from cutting alone. Use actual node mass rather than deficiency for work accounting.

## 3. Exact relational cap theorem (PROVED)

Each incidence connects variable bit x to local clause port bit y with allowed XOR mask S subset {0,1}; input S={0}; signed S={1}; free S={0,1}. Every owner requires NAE of its three local bits. All constraints invariant under simultaneous complement of every local bit. Signed singleton masks compile into literal signs; if an owner contains a free port, its owner constraint is existentially tautological on the variable bits (choose free local bit as needed). Keep local port choices in witnesses. Empty mask means NO. In cap graph a repeated variable is not silently treated as a distinct variable.

At a 2-cut let the smaller side A have outgoing variable u and incoming owner port P; larger B has outgoing variable v and incoming port Q. Crossing masks S1 (u,Q), S2 (v,P). Run smaller side twice, capping u--P with singleton masks {0} and {1}, to compute EXACT set D of feasible parity d=x_u XOR y_P. No assumption that both are possible. If D empty reject; otherwise replace B's cap v--Q by mask D XOR S1 XOR S2 (Minkowski XOR of subsets of F2). Solve B ONCE. Both directions:
- Any original model has d in D and x_v XOR y_Q=d XOR s1 XOR s2 for crossing parities s1,s2, so restriction to B passes.
- From B witness, read t=x_v XOR y_Q, choose recorded d in D,s1 in S1,s2 in S2 with t=d XOR s1 XOR s2. Take stored complete witness of A for d. Simultaneously complement all A variable and port bits if needed to obtain x_u XOR y_Q=s1. Then the other original edge automatically has x_v XOR y_P=s2. All internal masks and NAE owners invariant. ## 4. Uniform quadratic composition (PROVED)

2a^2+b^2 <= (a+b)^2-1
because 2ab-a^2>=a^2>=1. Thus the number of recursive calls, including failed profile calls, is at most root mu^2 by induction (a node spends one). This holds even on unbalanced cuts, without caching, and with arbitrary sequences of earlier cap masks. In contrast, two calls on both sides fail a quadratic budget on balanced cuts.
