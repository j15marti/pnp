## L2 exact regional synchronization (PROVED conditional, same residual)
From arbitrary paired-occurrence split graph under consistent unary guard, acquire its connected components (before pin deletion, retain original IDs). Each component contains whole clause gadgets since each is connected. Dummy clique may merge regions; that's allowed. Every link lies in one region. Let B_K be original labels with links in K and at least one other region; let D_K be labels with multiple links inside K. Form J_K=B_K union D_K, b_K=|J_K|. For each Boolean word on J_K consistent with source guards, pin ALL local links of each label in J_K to that bit. Any other guarded label is pinned too. A forced link is implemented by reserving its endpoints, rejecting clashes; a forbidden link is deleted. Test ordinary perfect matching on remaining local graph (including original dummy edges where present), restore reserved edges; retain one actual local witness for each resulting boundary word. For labels outside J_K, one link and no other region, so no unsynchronized local equality remains. This enumerates exactly the boundary relation R_K, both directions by restriction and union of component matchings; reconstruct all original bits from synchronized links and verify all rows. If any table empty reject. All guard conditions retained, no arbitrary external non-unary guards silently discarded.
