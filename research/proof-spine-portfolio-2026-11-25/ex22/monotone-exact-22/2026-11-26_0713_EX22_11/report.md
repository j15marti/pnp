## L1 PROVED: exact low-rank hybrid guard via source-SCC generators
Given an explicit 2-CNF B (units allowed) and a GF(2) affine system Ax=b on the SAME n Boolean IDs, let r=rank(A). Decide and produce a joint witness in n^{O(r)} poly(N), with a precise candidate bound sum_{i=0}^r binom(n,i), and polynomial peak space. This is polynomial for each fixed r, NOT a uniform fixed-exponent bound for arbitrary r, nor an FPT claim. The rank can also be replaced by the rank of the syndrome columns after quotienting the implication SCCs below.

Acquire an actual model a of B by deterministic SCC 2SAT; reject if none. Gauge x=a XOR d. Now d=0 satisfies every gauged binary clause. The allowed clause forms (after tautology/repeat simplification) are negative units (forbidden flips), two-negative clauses (conflicting pairs), or implication not d_i OR d_j. Thus a flip set D is B-feasible iff closed under the directed implication edges and avoids every forbidden vertex/pair. SCCs of this graph (on flip variables, not the original two-literal graph) are selected all-or-none. Its condensation is a DAG. Assign each SCC C weight w_C=A 1_C; the affine target is t=b XOR A a. A selected set has syndrome sum of its selected SCC weights, with multiplicities mod2, NOT the sum of overlapping reachability-closure weights. Use union of actual flip IDs before computing syndrome.

If any joint model exists, choose an inclusion-minimal feasible flip set D with syndrome t (existence proof only, not input to algorithm). In the induced SCC DAG on D, call a selected vertex a generator if it has no incoming edge from another selected vertex. The set D is the union of full forward closures of its generators. Removing any subset of these generators (only their own SCC vertices, not their closures) preserves forward closure, since no retained selected vertex has an edge into a removed generator; it also preserves all forbidden-pair/unit conditions by downward monotonicity. If the generator weights were linearly dependent, a nonempty subset would sum to zero, so deleting those SCCs would preserve t and contradict minimality. Thus their weights are independent and there are at most r, more precisely at most rank of all SCC weight columns. Enumerate all subsets of at most r distinct SCC seeds, union their reachability closures, test actual B and A, and return x=a XOR d if successful. Necessity by minimality, sufficiency by direct checks. The empty candidate handles t=0. Contradictory affine equations are never accepted; optional row reduction can reject early. This proof does not require a model of the hybrid nor independent assumptions about overlapping closures.

Compute graph, SCCs, rank, and all reachability bitsets uniformly. O(n^2) bits for closures, polynomial exact GF2 work and indices. A depth-first subset iterator uses polynomial space even if r unbounded, recomputes or stores closure unions; each candidate including failed work costs poly(N). The implementation uses raw rank and deduplicated per-vertex reachability masks instead of explicit flip SCCs (mutual reachability yields equal masks). It prunes any union containing a forbidden vertex/pair, sound because larger unions retain them. No hidden search oracle.

## L2 PROVED: contextual forest absorption and guarded join
Use EX22-10 L1/L2: native region each touched clause has two interior variables u,v, one exterior z and private w; no other interior occurrences. On a bipartite interior graph gauge by bipartition. Each actual exterior bit orients an implication. Pinned gauge ones must not reach pinned gauge zeros. On a forest, each connected P-Q pair has one undirected path, producing a clause K over exterior labels that forbids its simultaneous forward orientation. Repeated inconsistent label requirements discard that path; keep guards, no free assumption about label independence. Exact projection R=AND K, at most |L|^2 clauses; lift by actual reachability and w=2-x_u-x_v-x_z.

Let G=B AND Ax=b be an exact acquired exterior guard, or a proved necessary consequence of the actual exterior constraints, EXCLUDING the region under test. For every path clause K, test G AND all opposite literals of K by L1 (these are only additional units in B, rank unchanged). NO proves G entails K; drop that path condition. If every path is absorbed, delete the region, keeping the same actual exterior IDs and exact constructive witness algorithm. If G is exact, a YES countermodel to a path establishes nonabsorption; if only necessary, it establishes no such conclusion about actual global extendibility. Any remaining wider clause stays intact; if all remaining clauses are unary/binary and every other factor is exactly represented by G, append them to B and solve the whole residual by L1. Multiple regions with disjoint interiors can be treated sequentially; do not circularly assume their own responses. Reapply sound forced closure before and after deductions and at stagnation. Unary literal guards on retained coordinates go into B. Pins on private completions or other coupled guards must be exactly integrated or the lane declines. No projection of a mixed guard to separate marginals.

For fixed global rank bound r0, any polynomially acquired candidate portfolio, polynomial size chart with verified source adapters, and at most original m successful deletions (each removes an actual constraint), total work is N^{r0+O(1)} including failed path tests, discovery within that candidate list, verification and reconstruction. Does not claim all regions are uniformly acquired, all guards become low rank, or all remaining path clauses binary. The rank bound is on the actual jointly retained guard, not per-factor rank. Logarithmic r yields only N^{O(log N)} for this algorithm.

## L3 PROVED: unbounded-rank mixed-context absorption coNP-complete for even ONE path
Reduction from arbitrary authenticated native EX22 F. Let s be an exterior activation bit. For each source quadruple C introduce six selector bits t_{C,p} indexed by its six weight-two patterns p and a private escape d_C. Affine constraint XOR(d_C, all six t)=1. Binary constraints d_C -> not s and t_{C,p} -> (x_i=p_i) for each actual port i of C. B and A are polynomial-size; affine rows have disjoint supports (rank m). For s=1 every d_C=0, odd parity requires >=1 selector; distinct patterns cannot simultaneously be selected (they conflict on an actual port). Exactly one selected pattern per C is necessary and sufficient for a satisfying F assignment. Conversely any F witness selects its unique pattern per row and d=0. For s=0 set all d=1, all t=0, arbitrary original x: explicit joint exterior witness independent of F. Under s=1, B alone satisfiable (all selectors and escapes zero), A alone satisfiable (all escapes one), even though their join may be NO. Thus G entails not s iff F UNSAT. Membership in coNP by a counterexample word verified in polynomial time. Absorption coNP-complete with exact typed guard given and even supplied overall SAT witness, not relying on the difficulty of region discovery.

Native source realization, exact both directions: the EX22-10 path compiler realizes any clause K with a disjoint even-length interior path whose first gauge bit is1 and last0. Each literal false is tested by two consecutive edges (positive z: labels c1,z; negative z: labels z,c0; anchors c0=0,c1=1). Every edge uses a native positive proper quadruple with private completion. Then path extension iff K true. Encode each binary guard clause directly. Encode affine parity using a prefix XOR chain with fresh variables; each ternary XOR equality has four forbidden words, hence four ordinary 3CNF clauses. Final parity bit pinned by a unit path. This has linear records per row length and exact lift by prefix parity then reachability. The selected cap not s is a single two-edge path. All absolute pins are made relative to fresh shared reference R by the EX22-03 six-variable alternating module: six rows omit consecutive cyclic pair; sum gives total3 and subtract gives adjacent sum1; put R at index0 and pinned bit at index1 for opposite, index2 for equal. Every unguarded model can complement to R=0. Retain exact relative pin module ownership and actual IDs; the cap's private endpoint pin modules can be removed with the cap, shared anchor modules remain. Thus the two labeled guard tracks and the one cap are source-realizable, with no absolute external pins required in the complete native instance. Both sides are SAT at s=0; the hardness is whether projection onto the exterior changes under deleting the cap, not SAT decision of these examples. No narrower degree, incidence forest or planar promise claimed. Nor is this a lower bound for all semantic retractions or unrestricted EX22.
