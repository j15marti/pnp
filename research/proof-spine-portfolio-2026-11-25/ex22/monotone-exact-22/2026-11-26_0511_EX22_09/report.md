## L1 PROVED: exact signed-kernel characterization
Take recognized private-completion EX22 images in which every clause has exactly one degree-one variable w and remaining three variables have degree >=2. Remove w only as functional projection to NAE3. Let A be the 0/1 row-by-core incidence matrix. A pair retraction is a nonempty core subset L meeting each touched triple in precisely two members, with bipartite graph of those member pairs.
Equivalent exactly to existence of d in {-1,0,1}^n nonzero with A d=0 over the INTEGERS. In a three-port row, the only zero sums are (0,0,0) or permutations of (-1,0,1). Thus nonzero support is L and signs color its pair graph; conversely bipartition assigns signs. All variables occur, so at least one clause removed. Set d=+1 core bits to 1, d=-1 to 0, retain d=0 core bits; every touched row then admits either exterior bit, and its original w=1-exterior. Every original solution restricts to retained clauses, every retained solution lifts through this rule. This is a decision-preserving retraction, not a logically forced assignment. No assumptions on outside width; no lost original IDs. Guards on selected core bits must agree with chosen signs (or flip components), and guards on removed w cannot silently be discarded; decline if not separately certified. All hardness/control results here unguarded.
Equivalent support test: enumerate z in ker_GF2(A), z!=0. Every row has even intersection 0 or 2. Test bipartiteness of induced pair graph. Any bipartite support supplies actual signed direction, not just affine hull. Uniform cost 2^d poly(N), d=binary nullity; polynomial for d<=c log2 N fixed c. A nonzero rational direction or a nonzero binary word alone is not sufficient.

## L2 PROVED: unrestricted pair certificate existence is NP-complete, even with supplied actual SAT model, linear source, maximum occurrence four
Decision language: valid private-completion EX22 F', optionally accompanied by verified satisfying assignment; ask whether a nonempty pair-retraction certificate exists in its recognized core. Ignore unused original variables or include their domain gadgets; use nonempty F for hardness. Arithmetic variables in {-1,0,1}, global activation g.
For every original Boolean variable introduce x,u,v and impose u=x+g, v=u+x. These are signed three-term equations. If g=0 then v=2x forces x=0, and u=v=0. If g=1, x in {0,-1}: x=+1 gives u=2 forbidden. If g=-1, x in {0,+1}; use x=-g b for original Boolean b. Both legal choices have bounded u,v. For every original clause (i,j,k,l), introduce p=u_i+x_j, q=u_k+x_l, impose p+q=0. Thus x_i+x_j+x_k+x_l=-2g, exactly original EX22 when g!=0. Conversely any original SAT assignment lifts by g=1, x=-b, u=1-b, v=1-2b, p=1-b_i-b_j, q=1-b_k-b_l. If g=0 then every abstract symbol zero. Hence nonzero signed arithmetic solution iff original F SAT. No target witness used in construction.

## L4 PROVED: constructive polynomial fundamental-circuit acquisition on admitted matrices
Choose maximal independent column set B of A over Q, using exact Gaussian elimination; choose independent rows I with B_I square invertible. For every nonbasic column e solve B_I y=A_{I,e}. Verify full B y=A_e. If y has all coefficients in {-1,0,1}, d_e=1,d_B=-y, others zero is an actual pair certificate. Deterministic polynomial search even without TU; failure outside admitted cases is UNKNOWN. If A totally unimodular and rank<n, Cramer's rule on B_I (det +/-1; replaced column determinant 0,+/-1) ensures every nonbasic e supplies certificate. If rank=n, none exists. Therefore on TU projected incidence matrices complete acquisition is polynomial, no LP needed. Also extends to allowed-support deletion if removed guard variables fixed d=0: column submatrix TU, check appropriate sign guard compatibility separately. More general guards not claimed. Equivalent LP approach uses Hoffman-Kruskal integrality of A d=0,-1<=d<=1; optimizing signed coordinate with nonzero rational direction yields integral nonzero vertex. This provides alternative paid polynomial lane, not universal TU admission. A failure to find small fundamental circuit on one basis does not certify no pair direction; exact bounded GF2 enumeration remains fallback.
