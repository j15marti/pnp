## 2. Named theorem: native bounded-component two-forest compiler (PROVED)
For every EX22 F with n variables and m clauses, create a distinct clone y_e and three private variables p_e,q_e,r_e for each of the 4m occurrences e of original variable x_e. Put each clause on its four occurrence clones in family A. For each occurrence add A relay clause (y_e,p_e,q_e,r_e) and B relay clause (x_e,p_e,q_e,r_e), both exact-two. Subtraction over integers gives y_e=x_e and p_e+q_e+r_e=2-x_e. For each original bit there are exactly three possible private triples, all actual Boolean assignments. Conversely any F model extends by choosing any such triple independently at every occurrence. Restriction to original x lifts a solution back, pointwise for every x. There are n+16m variables and 9m clauses, all distinct proper clauses. For no-unused-variable input both families form incidence forests: A consists of m components, one central clause and four adjacent relay clauses via distinct clones, 5 clause vertices + 16 variable vertices =21. B consists of one component per original x with d_x clauses sharing only x, 1+4d_x vertices. Isolated vertices irrelevant. This supplied decomposition is constructed deterministically in polynomial time. For the max-occurrence-four hard input from DDD, B components have <=17 vertices. Thus EX22 with a supplied partition into two incidence forests, both with component sizes <=21, is itself NP-complete by explicit reduction (not asserted linear after relay insertion). The same holds with max variable degree four, since clones and ports each have degree two. No claim that hardness implies P!=NP or that the forest split is impossible; rather it exists even for the whole NP-complete source.

## 3. Guarded contextual retraction (PROVED)
