## L1 PROVED: directional reachability cap with exact native witnesses
Input a source-verified candidate interior L of a private-completion EX22 region: each touched row contains two distinct interior core IDs u,v, one exterior core ID z, and a distinct private w (no other occurrences). Interior IDs do not occur in remaining factors. Retain arbitrary unary guards on core variables, but decline pins on private w and coupled guards crossing L unless separately integrated. A projected triple is NAE(u,v,z). Check graph on L with one edge per factor is bipartite, with parts p=0,1; orient the stored edge (u,v) from p0 to p1. Define gauge y_i=x_i XOR p_i. For a fixed actual exterior word x, if x_z=1 the NAE clause prohibits (y_u,y_v)=(1,0), hence imposes y_u<=y_v, directed edge u->v. If x_z=0 it prohibits (y_u,y_v)=(0,1), hence imposes y_v<=y_u, v->u. Translate every interior pin to gauge; let P,Q be pinned-one and pinned-zero vertices. Feasible iff no directed path P->Q. Necessity by implications; sufficiency set y=1 on vertices reachable from P (including P), 0 elsewhere, so all implications and pins hold. Lift x_i=y_i XOR p_i, w=2-x_u-x_v-x_z. Every w is Boolean by NAE; check actual original rows and all guards. This is exact decision/projection under the current guard, not a globally forced assignment.
General symbolic cap: Boolean directed reachability circuit by Floyd-Warshall recurrence with input edge labels (OR for parallel directions), negate OR of P-to-Q reachability. O(|L|^3+|E|) gates, polynomial construction and evaluation; exact on every exterior assignment. Cap may be hard to join; no free oracle. With no opposing gauge pins in each connected component, cap is tautological and a constant-gauge witness works, extending EX22-08 under compatible pins. Given independently labeled edges (each unpinned exterior ID labels at most one edge), build union of possible directions (fixed exterior pins restrict edges). A P->Q directed path exists for some allowed exterior word iff union has such a path, since a simple path uses distinct free labels, which can be assigned independently. Thus universal extension test polynomial in this additional promise, and if fails produce actual nonextendible word. This last test assumes all exterior words respecting unary exterior pins, not arbitrary coupled exterior guard relations.

## L2 PROVED: forest exact CNF cap, even with repeated exterior IDs
If graph on L is a forest (including no parallel edges), for every p in P and q in Q connected in same component, find its unique undirected path. To be directed from p to q each edge imposes one exterior literal z=b. Discard path if repeated z requires both bits or exterior guard contradicts a requirement. Delete fixed literals and deduplicate repeats. The conjunction of remaining requirements is exactly the condition under which that pair creates contradiction; negate it to obtain one clause. Empty conjunction produces empty clause (reject), inconsistent paths produce no clause. Conjoin all such clauses. By L1 this is exact projection, both directions with constructive lift, no enumeration of boundary words. At most |P||Q|<=|L|^2 clauses of length <=|L|-1; O(poly(N)) even naive BFS per pair. If no clauses remain, every exterior word extends. Conversely any retained nonempty consistent path admits a word that violates it, so universal extension iff cap empty (or all path requirements discarded); an empty clause also violates universal extension. If all resulting clauses are unary/binary, and other retained factors are exactly bijunctive, joint decision by deterministic SCC 2SAT and witness lift. For other exterior factors keep actual cap, not its 2CNF projection. Multiple regions with disjoint private IDs can conjoin caps and lift independently; all original exterior IDs must agree. A fixed polynomial acquisition/decision bound applies to a supplied/source-verified partition or polynomial candidate search, not all arbitrary residuals. Candidate subset may be tried from degree classes (EX22-08), but no universal success claimed. This cap is a single exact relation with compact CNF, not necessarily bounded table arity for EX22-07/FN11 recurrences.
Exact expressiveness obstruction: given arbitrary explicit CNF H in Boolean exterior IDs, create one disjoint path per clause. Each literal can be tested by two consecutive edges between p0 layer endpoints a,b with fresh p1 t. With fixed exterior anchors c0=0,c1=1, a->t->b exists iff z=1 using labels (z,c0), or iff z=0 using (c1,z), in path order. For each clause concatenate tests for all its literals being FALSE, pin first gauge1 and last gauge0. Then path extends iff clause true. Whole forest extends iff H. Every edge is a native EX22 clause (a,t,z,w) with private completion and distinct IDs. For empty clause use a direct always-forward two-edge test with c1,c0 (or immediate reject). Thus even a forest of paths supports arbitrary CNF, exact compact caps do not make their global join tractable. In particular EX22 F reduces directly to H: for each native quadruple, all four positive three-subset clauses and all four negative three-subset clauses, enforcing at least and at most two. For each boundary projection the witness lifts by L1. This is NP-hardness of existential compatibility for a GUARDED forest representation, not a claim about unguarded forest incidence of full source. Repeated exterior labels are real source variables, not independent occurrence copies.

## L3 PROVED: universal guarded extension is coNP-complete even on bipartite series-parallel interior with supplied SAT witness
Decision: given verified region as in L1 with absolute unary guards on anchors/interior, ask if EVERY exterior word satisfying its unary guards has an interior extension. Counterexample word check by L1 in polynomial time, so in coNP. Reduce complement of authenticated EX22 F: H is the eight 3CNF clauses per quadruple from L2. For every H clause create a stage between successive p0 vertices a,b. For each literal add a fresh p1 t and two-edge parallel branch with labels (z,c0) for positive literal, (c1,z) for negative. Thus a directed path from a to b exists exactly when at least one literal true. A chain of stages has an end-to-end directed path iff all stages admit forward paths: any simple path must go through cut vertices in order; each branch internal t has no other neighbors. Append final singleton stage testing new exterior selector s=1. Pin first gauge bit1, last0; anchors c0=0,c1=1. The interior graph consists of serial compositions of parallel length-two paths, treewidth <=2, simple bipartite. Source clauses remain positive and proper; no claim of full incidence planarity or bounded degree/linearity. The exact extension condition is NOT(s AND H(x)). Thus universal extension iff F UNSAT. Every constructed guarded source is SAT, with an explicit polynomial-time model by s=0, any exterior x and reachability lift. CoNP-hardness is for given region and guard even with known model, not unrestricted decision lower bound. In particular trying to certify context independence by solving only the polynomial fixed-context subproblem or ignoring repeated labels is not sufficient. No free equivalence or tautology oracle.
Compare EX22-09: that result concerns acquiring a nonzero fixed pair certificate (unguarded). L3 concerns a stronger, adaptive extension rule and a supplied region under pins. No contradiction with EX22-08 unguarded bipartition retraction. A selector witness can make these particular instances easy for decision; no all-lane obstruction claimed.
