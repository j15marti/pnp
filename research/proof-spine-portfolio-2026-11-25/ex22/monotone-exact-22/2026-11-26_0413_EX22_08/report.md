## L1 PROVED: sparse prime completion
Take any authenticated linear positive NAE3 source H=(A,E), n=|A|>=11, m=|E|, each variable occurs between 1 and 4. For hardness take exactly four; if a nonempty small instance, repeat disjoint copies until n>=11 (constant blowup), retaining one copy for source lift. Empty input maps to a fixed YES instance. Index A=(a_i), add B=(b_i), C=(c_i), all disjoint, i in Z/nZ. Add six shifts of triples:
P(i,j)={a_i,b_(i+j),c_(i+2j)}, j=0,...,5.
Keep all E triples (inside A). Then append one private distinct Boolean w per triple to obtain EX22 instance F.
For any assignment of A, choosing all b=0 and all c=1 satisfies every added NAE triple, and its completion is w=1-a_i. Conversely any F witness restricts to a witness of original H. Projection to E completed variables is exact; not a count-preserving reduction and no assertion that every witness has constant B,C. Output m+6n clauses, 9n+m variables, max degree <=10, linear in input record count and O(N log N) or polynomial bit length with normalized IDs.
Linearity: A-B and B-C pair fixes j modulo n; A-C pair fixes 2j modulo n, and 0<=2j<=10<n. Then i is determined. Original triples only use A and meet any added triple in at most one. Each added triple proper, all distinct; every A has degree 6+old degree, B,C degree 6, private completions degree 1. All original IDs retained.

## L2 PROVED: no productive <=4 physical-variable seam
Let G be primal graph on A∪B∪C of all projected triples (not including private completion vertices). For each index i, group a_i,b_i,c_i forms a triangle via j=0. Delete any <=4 core vertices. At most four groups damaged. The intact groups are cyclically connected: consecutive intact indices differ forward by 1..5, and a_i--b_(i+d) is an edge for any d=1..5. Each surviving vertex in a damaged group has neighbors in at least five distinct other groups: use b_(i+j) for a_i, a_(i-j) for b_i, a_(i-2j) for c_i, j=1..5. All distinct since n>=11, so at least one intact group reached. G after deletion is connected.
A variable separator of <=4 IDs can include some private completions, which have degree one and never connect distinct factors. Delete only its core IDs. Every factor with at least one surviving core variable joins the same component of factor adjacency. By linearity of projected triples at most one factor can lose all three core variables: two triples together require >=5 removed core IDs. Thus the factor graph has one component containing all but at most one factor. It cannot be partitioned into two shores each >=2 factors with <=4 shared IDs. Holds for every split and both labels.
This establishes NP-completeness of the recognized EX22 restriction (linear, max degree 10, one private completion per clause, no productive <=4 shared-variable seam). ## L4 PROVED: context-independent pair retraction defeats this very padding
Given any recognized private-completion image and candidate subset L of core variables, require each touched projected triple (meeting L) to contain exactly two members of L. Build graph on L with an edge for the corresponding pair. If bipartite, choose opposite bits along every edge by BFS; then every removed NAE triple is satisfied for EVERY assignment of the outside bit. Reconstruct its actual private EX22 completion as 1-outside bit. Remove all touched clauses, their private completion variables, and L (remove unused isolated variables separately). Every source solution restricts to a remaining solution; every remaining witness extends by the single acquired bipartition and completion formula. This is a contextual retraction, not a claim that the bits of L are logically forced. A standard SAT autarky is a fixed partial assignment satisfying all touched clauses; here completion depends on outside bit, so avoid calling fixed values on all removed variables an autarky in that literal sense.
Safe for unary guards on retained variables/completions; guards on L can be accommodated by checking the two bipartite orientations per component (if none, decline rather than reject). Removed completion guards may couple the outside bit and alternative L assignments; decline unless separately certified; do not infer a new forced outside bit merely from our chosen lift. Executed guard solver only admitted retained core pins. No arbitrary coupled guards or extended tables claimed.
