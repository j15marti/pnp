## 1. Guarded residual and curvature inequality (PROVED)
Apply ordinary exact-one propagation until stable: two selected or no remaining candidates in an unsatisfied row is contradiction; one selected forces other incident tuples off; one candidate in unsatisfied row forces it on. Preserve guards. Delete satisfied rows and fixed tuples only from active chart, not original source. Each live tuple has all four ports still active: if adjacent to a satisfied row it would have been set to zero. Every active row has two or three live tuples. In each connected active component, a completion requires equal row counts across the four colors. Reject imbalance. Components factor exactly.

Fix one connected active component with v live tuples, r2 two-rows and r3 three-rows. Suppose an actual cover S exists. Contract each element into its unique selected tuple, retaining incidence multiedges between selected and nonselected tuples. Result is connected, planar, bipartite, loopless, with v vertices and E=r2+2r3 edges. Count ports: 4v=2r2+3r3; therefore E=2v+r3/2. v>=3, since one tuple cannot support any active row of degree >=2, and two tuples would have to share all four original coordinates, contrary to distinctness. The simple graph obtained by deleting duplicate edges is connected planar bipartite, so has at most 2v-4 edges by Euler (including trees; facial walks have length >=4 in connected simple bipartite graphs with >=3 vertices). Consequently the duplicate excess is >=r3/2+4.

For each pair of live tuples u,v let k_uv be the number of active rows containing both; define w_u=sum_{v != u} max(k_uv-1,0). Since co-occurring tuples cannot both be selected, the duplicate excess is EXACTLY sum_{u in S} w_u: each selected/unselected pair contributes k_uv-1 and unselected/unselected pairs contribute nothing. Hence
  sum w_u s_u >= r3/2+4.
All coefficients acquired by scanning row pairs. r3 even by port identity. For connected unguarded source, threshold is 2n+4. The inequality holds for every completion under the current guard; it does not assert sufficiency or a lower bound on unrestricted computation.

## 2. Six weighted matching projections and forced-information loop (PROVED)
In each active component and each pair of colors, project live original indexed tuples to bipartite edges. The projection of any actual cover is a perfect matching and retains its weight sum. Compute maximum weight among perfect matchings, or detect nonexistence. If below the curvature threshold, reject this guarded component. For each live original tuple, repeat with that edge forced selected (delete its endpoints, add its weight), or forbidden (remove that original ID only). If either maximum is too small, force the opposite bit in the actual source. Parallel projected edges can be replaced by maximum weight after removing forbidden IDs; this is exact for the projected optimization, NOT an actual cover lift. Retain original IDs. Recompute after every strict deduction; repeat ordinary propagation, balance, matching and curvature at stagnation. Each deduction is universal only inside the current guard. A surviving projected matching is never returned as a source witness.

## 3. Repeat-pair backdoor (PROVED)
Let R be the graph on live tuple IDs with an edge iff they share >=2 active rows. If a nonempty residual has R empty, every w=0 and the preceding inequality is impossible, even if every element has two candidates. Thus it is UNSAT, not an unresolved branch.
Take ANY vertex cover K of R. Enumerate its 2^|K| bit assignments, reclose with exact-one, weighted matching and balance; remaining live tuples form an independent set in the original R and hence in their own repeat graph (deletions cannot create new shared rows). If not all fixed, the new residual cannot have a cover by the theorem. Otherwise check every original row and guard, and return that actual set. This algorithm is exact for all guards; time 2^|K| poly(N). K can be acquired as endpoints of a greedy maximal matching, size <=2 minimum vertex cover. Thus a logarithmic residual minimum cover suffices deterministically; no supplied target. Independent components add their work. This is a backdoor theorem, not a general logarithmic-cover theorem.

Raw cover obstruction: in connected E3 incidence graph V=7n,E=12n,F=5n+2. Color degree conservation on a shore gives d_c=m_shore-3e_c for each color, hence no bridge (a sole boundary edge would give incongruent residues). Bipartite simple facial walks have length >=4 and nonquads >=6; thus f4>=3n+6. Each quad is one repeat pair, and no distinct pair shares three rows by P4SW01's planar K2,k face/color congruence argument: an exterior component incident to one shared element has a unique outgoing edge of its color but cannot see all >=3 shared elements from a single face, contradiction modulo 3. A 4-cycle cannot bound two faces in a connected source with these degrees. Each tuple participates in at most four repeat pairs (eight total co-occurrences, two per repeat neighbor). Therefore raw repeat-graph vertex cover size >=(3n+6)/4. Do NOT infer hardness or a lower bound after stronger closure. In a 3-connected source any repeat pair's cycle is facial: the outside component attaching to one shared element must also attach to the other by the same color congruence (both colors have no other ports at cycle tuple vertices); both spare edges are on one side. If opposite side contains vertices, their attachment set lies in the two tuple vertices, contradicting 3-connectivity. This also explains why purely facial grouping can be inadequate without the 3-connected promise. Fixing actual rows of groups hitting repeat edges is a second exact backdoor variant; do not assume these groups independent or uniformly few.

## 4. Other consequences and limits
For simple conflict graph G (tuple pairs with >=1 shared live row) and any W of >=3 live vertices, every cover satisfies sum_{uv in E(G[W])}(s_u+s_v)<=2|W|-4, since this counts exactly edges in induced simple bipartite contracted graph. G is planar: replace each degree-three row by triangle within its local disk, degree-two row by edge, and delete duplicates. Polynomial rational separation: for x in [0,1]^v maximize sum of nonnegative edge profits x_u+x_v minus 2 per included vertex, require each included edge's endpoints. Enumerate triples of forced included vertices to enforce size >=3, use maximum closure min-cut with vertex costs and edge profits (source positive profit arcs, negative costs to sink, capacity above total finite capacity for dependencies and forced vertices). A cut yields a closed set and capacity equals total positive profit minus retained net profit; select all available nonnegative edges. Exact rational scaling by product of denominators has polynomial bit length. Violated inequality iff max > -4. LP integration is theorem-level only. Uniform unguarded x=1/3 satisfies every such inequality by planar |E(G[W])|<=3|W|-6. Thus this entire density family alone cannot reject genuine U (UNSAT). No inference about full portfolio or arbitrary lower bounds.

Auxiliary repair lemma (not required for curvature closure): compare any parity word p to a genuine cover t respecting the same guard. Odd occupancy means every element selected once or thrice by p; each color has d thrice-occupied rows and |p|=n+2d. Every changed row has exactly two flipped tuple bits. Contract those changed rows between flipped tuples to a planar 4-regular multigraph properly edge-colored by the four source colors. Each flipped tuple has one edge of each color. In a connected difference component, each color edge matching covers all its vertices; #p-selected minus #t-selected equals twice the number g of thrice rows repaired of that color. Thus g is independent of color, nonnegative; g=0 components may be left unchanged and still give a cover if all positive components flipped. If d=1, one connected positive component suffices (existential, not target-free acquisition). Euler for connected 4-regular plane multigraph gives 2 f2+f3=8+sum_{l>4}(l-4) f_l. A triangular face must contain a defect edge because all other edges cross the p-bit partition. At most 4g defect edges and each at most two triangular face incidences, hence f3<=8g. A simple g=1 repair necessarily has eight triangles and all other faces quadrilateral. This limits geometry but does not give polynomial discovery; no simple g=1 controls appeared in supplemental audit. No enumeration of hypothetical target used by production algorithm.
