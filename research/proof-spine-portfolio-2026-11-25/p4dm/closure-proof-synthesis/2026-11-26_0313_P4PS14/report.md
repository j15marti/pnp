## 2. Exact classification of every raw four-edge cut (PROVED)
Retain raw physical incidence graph, including vertices of pinned tuples. For any shore S, let t be number of tuple vertices, r_c number of color-c rows, o_c/i_c outward/inward incidence counts (outward means tuple in S, row outside). Degree conservation gives t-3r_c=o_c-i_c. For any cover selecting a tuples in S, a-r_c=sum(out_c x)-sum(in_c x). These are integer identities on actual IDs. With exactly four cut edges, all signed imbalances are congruent to t modulo3. If t=0 mod3, nonzero imbalance would have magnitude >=3; exactly four incidences then leave at most one incidence for others, and 4 minus sum of absolute imbalances must be even. Thus every imbalance zero. There are either two distinct colors with one incidence in and one out each, or one color with two in and two out. Untouched color fixes a=t/3. Actual boundary bits in the two-color case are equal within each color pair; at most FOUR masks, arbitrary subset is a binary relation on the two pair bits (can be represented by 2CNF plus equality). Monochromatic case has equality of two incoming and two outgoing sums; at most SIX masks (0000,0101,0110,1001,1010,1111 in out,out,in,in order). If t=1 mod3, each of four imbalances has magnitude at least1, so all +1; t=2 mod3 similarly all -1. Every color has the same r_c; all four actual boundary bits equal. At most TWO masks. No other types. Guards only reduce attainable masks. These are necessary laws, not claims that every allowed mask extends.
Stronger parity law for ANY cut: sum boundary bits modulo2 equals number of element-row vertices in S modulo2, since every tuple contributes four equal incidence bits (even), every element contributes one (odd), internal incidences counted twice. Holds after pinning, with parity adjustment when a fixed port is removed. Do not reuse E3 color arithmetic on a physically contracted factor chart.
Monochromatic six-mask family has 63 nonempty subsets, of which 21 are both bijunctive and even delta-matroid (EDM), 15 only bijunctive, 15 only EDM, 12 neither, checked exhaustively. This is an abstract representation obstruction, not a claim all 63 supports have native planar realizations.

## 4. A general exact fixed-k bounded-bond replacement (PROVED; executed k=4)
Encode actual native source as a Boolean edge-CSP: one bit per indexed incidence edge, four-port tuple relation {0000,1111} (or pinned singleton), three-port element relation exactly-one. Shared edge equality is intrinsic. Every source cover corresponds to exactly one edge assignment and conversely. Each factor has fixed parity (tuple even, row odd), arity at most4. Extend working class to arbitrary explicit constant-parity relations of arity <=k, fixed k>=4, plane loopless multigraph with indexed edges. Keep original IDs and witness maps, not a new hardness assumption.
For connected working graph choose any bond with q<=k edges, each shore >=2 vertices. Smaller shore A has a vertices, larger B has b=n-a, a<=n/2. For every boundary word w in {0,1}^q, restrict each A factor at its cut ports to w and delete those ports; recursively solve smaller graph on a vertices. Store actual witness for each attainable w. If any required small call UNKNOWN decline (safe). If none attainable reject. Replace all A vertices by ONE new factor R of arity q, its explicitly attained table W (<=2^k masks). Keep cut edge IDs, connect that factor to original B endpoints; larger instance has b+1 vertices and is solved once. Every feasible original assignment gives one W word and a larger solution. Conversely a larger solution chooses one exact W word, its saved A witness combines with B assignment consistently on all indexed cut edges, restores every original factor. For decision retain one witness per word, do not claim counts. All guards imposed at actual factor ports before processing; no free nonlocal coupled constraints. Reclose local support and necessary affine consequences after pinning/contraction, preserve raw IDs. If using independent component factorization, solve each and union actual witnesses, not Cartesian products.
Planarity: both shores connected, contract A along a spanning tree in acquired embedding, discard internal loops and retain ordered indexed cut edges at the new factor vertex; exact table's coordinate order is the physical edge ID order (record map to cyclic order). No arbitrary crossing reconnection. For fixed k deterministic acquisition can enumerate <=O(E^k) candidate edge sets and verify two connected shores by BFS, any one chosen deterministically (executed dual cycle scan, re-embedding indexed edges by subdividing each before obtaining simple embedding; dual bonds correspond to simple cycles including loops/digons; every candidate verified in primal). The theorem permits storing inherited rotation through contractions. Implementation re-acquires plane embedding at each scan instead of checking inherited cyclic order against each previous drawing; no semantics depend on re-embedding. Original source rotation remains recoverable and no source orientation claim from arbitrary new graph. Failed candidates charged. This is a direct constant-size factor representation; no finite native cap existence oracle, no need to enumerate representative graphs. It changes the permitted terminal language, unlike PRRA native replacements.
Parity invariant: each original factor has fixed XOR of all its ports. Sum these equations over A; internal edges occur twice, so the cut mask XOR is sum of the local parities modulo2. Thus W is a fixed-parity relation. Pinning an edge changes parity at both endpoints by its fixed bit and removes it, preserving class. Arity remains <=k. No implicit exponential support.
Recurrence with mu=n factor vertices (including synthetic factors), d=k+2 fixed. For a>=2, b+1<=n-a/2. Put t=a/n in (0,1/2]. Then sum child mu^d/n^d <=2^k t^d+(1-t/2)^d. This is convex, f(0)=1 and f(1/2)<=1/4+(3/4)^(k+2)<1, so by chord strictly below1 for t>0. Integer sizes give sum child mu^d<=n^d-1. Independent components also satisfy strict potential for d>1, unless only a single component (then no recursion); singletons evaluated directly. Thus at most n^d recursive nodes (n<=O(N)); one larger call, no uncontrolled repeated large branches, even on unbalanced cuts. Fixed k=4 yields exponent6, INCLUDING size2 shores, with no cap overhead. Each vertex table <=2^k words, edge count O(kn), per-node parsing, scan, local propagation, arithmetic, new IDs, provenance, and capped terminal calls fixed polynomial. All labels and maps polynomial in original N (synthetic vertex IDs <=initial size+depth under relabeling, physical edge IDs original). Child witnesses at most 2^k per split, polynomial total stored records and reconstruction. No memoization assumed, charge recomputation/failed work. ## 5. Special parity-rank guard theorem for all four-port factor primes (PROVED, symbolic composition)
For any nonempty fixed-parity relation of arity <=3, any distinct feasible words differ at exactly two positions; flipping those two reaches the other word, satisfying even delta-matroid exchange. For any fixed-parity relation of arity4, fixing ANY one coordinate and deleting it leaves a fixed-parity relation of arity<=3, hence EDM (empty means NO). Conversely every failed exchange pair in a fixed-parity 4-table differs in all four coordinates, as distance2 always succeeds. Fibers of already-EDM relations stay EDM since exchanges toward another same-fiber word change only unfixed coordinates. Thus every nonEDM factor is degree4 and one pin suffices; no nonconstant-rank per-factor defect.
Acquire GF2 global affine chart from all local exact table affine hull equations, plus actual edge pins. Reject inconsistency; export chart-forced bits, restrict both endpoints and repeat local/affine closure at most E strict pins. This is a necessary linear chart, not itself a solution. For live edge e write x_e=a_e+l_e(y), nonzero l_e if unpinned. For each nonEDM degree4 factor collect its offered directions C={l_e at its four ports}. Its XOR parity gives sum l_e=0, so span(C) rank<=3, size<=4 directions. A subspace U hitting every C suffices to make every factor EDM after pinning a basis of U; use U generated by offered directions and choose basis of actual edge observations. All 2^rank(U) Boolean values of basis are enumerated, every other edge whose direction lies in U determined. Pin those original indexed live edges consistently at both endpoints; any empty table rejects that branch. Every original solution selects one branch, every exact edge-CSP solution in a branch lifts, by Section4, to original source. Apply KKR explicit EDM edge-CSP theorem (arbitrary graph; loops absent, each live variable two distinct endpoints). All per-branch work polynomial. KKR not implemented in this run; no claim that all EDM tables are ordinary matching gadgets.
Uniform rank acquisition: start U=0; for any unhit C add its entire span. For an optimal hitting subspace U*, some vector in C lies in U* outside old U, so dim(U intersect U*) strictly rises each iteration; <=k*=dim U* iterations, rank(U)<=3k*. Exact bounded-rank recognition: on unhit C branch on its <=4 actual directions, add one direction independent of U; stop at cap r. If an optimal subspace of rank<=r exists, follow one offered vector in it each step. Discovery O(4^r poly(N)), subsequent exact solving O(2^r poly(N)). At fixed r<=C log2 N this is uniformly polynomial; no universal small r. This is stronger uniform constant-degree acquisition than generic PS09 unbounded-rank bad pairs and applies after every generalized 4-cut contraction. If all factors binary, exact 2SAT using forbidden unary/pair masks, no guards needed; if both methods decline, leave prime OPEN. Rank cover here GF2 over actual edge bits, not the raw GF3 native chart.
