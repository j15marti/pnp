## 2. Exact local planar resolutions
Acquire a plane embedding of the actual source incidence graph. At each degree-four tuple t, in cyclic port order 1,2,3,4, either smooth adjacent pairs (12)(34) or (14)(23). Replace the tuple star by two disjoint arcs, one per pair. Any independent choices of the two smoothings preserve planarity; the result P is a loopless indexed multigraph on original element vertices, with two edges per original tuple, each vertex degree three in the unguarded source. The construction is uniform polynomial for each pattern. For three standard global color-pair splittings (AB|CD, AC|BD, AD|BC), each color-pair graph is separately a planar incidence subgraph with degree-two tuples suppressed; the disjoint union is planar even if that particular pairing would cross at a tuple in the original embedding.
For an indexed perfect matching M of P, define d_t(M)=M(e_t0) XOR M(e_t1). An original exact cover gives a PM by selecting both edges for each chosen tuple. Conversely d=0 implies both or neither at every tuple, and PM means each original element is covered once. Thus exact bijection between original covers and zero-discrepancy PMs, for EVERY projection. For two locally complementary resolutions, common original incidence-edge mask iff exact cover: the two pair equalities connect all four ports, while each matching enforces exactly one at every element. Independent PM existence in both planes is not this common-mask condition. Pins on x_t force both edges or delete both, and all matching tests are necessary for original source. Pin tests in different planes can share only certified deductions.
Planar obstruction: raw GF2 Ax=1 has all-one reference (degree3). If no tuple bit is fixed by its full affine equations, EVERY smoothing graph is bridgeless: a bridge separates an odd-size vertex shore S in a cubic component. Summing source rows of S over GF2 gives x_t=|S|=1, where t owns the unique crossing edge, since all other pair edges contribute an even number of endpoints. Contradiction to no fixed bit. Therefore every smoothing has a PM by Petersen. In addition any bridgeless cubic plane loopless multigraph is 3-edge-colorable (Tait and four-color theorem; parallel-edge cases may be reduced, or use planar dual coloring and GF2^2 differences). The three disjoint PMs partition all edges, their GF2 sum is all-one, and the sum of three discrepancy vectors is zero. Consequently zero lies in the affine hull of discrepancies in EVERY smoothing in this no-fixed-bit case. Mere independent matching feasibility and affine-hull feasibility are therefore insufficient as universal terminal criteria; this conditional statement does not assert a hard UNSAT source with no fixed bits.

## 3. Deterministic affine discrepancy acquisition and exact parity filtering
For a guarded nonempty PM family, let D={d(M)}, affine hull d0+W over GF2, r=dim W. An acquired planar Pfaffian orientation supplies a polynomial exact signed partition function Z(ell)=sum_M (-1)^(ell*d(M)), by assigning each of the two edges owned by tuple t weight (-1)^ell_t, and deleted edges weight zero. Retain original IDs; parallel edges may be aggregated into the skew entry using the orientation of the underlying simple plane graph, because at most one such edge is selected in each PM. Calibrate the COMMON Pfaffian sign against positive unweighted counts, never take absolute value of signed Z. For any parity observation ell, C(ell,b)=(Z(0)+(-1)^b Z(ell))/2 counts exactly the satisfying PMs. If initial Z(0)=0 reject. Acquire one actual PM by greedily deleting edges while positive count remains. A minimal retained set is exactly an actual PM. Start W=0 and reference d0. At each step acquire basis of W-perp by Gaussian elimination. For each ell in this basis, test C(ell,1 XOR ell*d0). If positive, self-reduce using that SAME parity-conditioned count and obtain an actual discrepancy outside d0+W; enlarge W by its difference from d0. At most m increases; each uses O(m) parity probes and O(m) edge-deletion witness probes. If all basis tests zero, all D lie in d0+W, and stored actual witnesses prove equality of the hull. O(m^2) signed polynomial Pfaffian evaluations (constant factor per parity probe). This is NOT enumeration of PMs or a SAT oracle.
If 0 outside d0+W, exact NO. If 0 in it, it is a linear space W; select r pivot coordinates I whose restriction is injective on W, and check only d_I=0. Exact cover count equals 2^(-r) sum_{ell supported on I} Z(ell). This is Fourier orthogonality, using exact integer counts and sign calibration. Count positive iff SAT. Reuse the parent hull and same I after edge deletions for witness recovery, since every surviving discrepancy remains in W. Extract actual original tuple IDs and verify all integer rows and guards. At r=0 the count is ordinary PM count. Decision/count/lift cost 2^r poly(N), including polynomial hull discovery and O(m) conditioned count calls for witness. All weights are 0,+/-1 before parallel aggregation, coefficients and counts O(poly(N)) bits; integer elimination intermediate minors bounded by Hadamard. Production implementation uses fraction-free Pfaffian elimination and explicit embeddings/dual face tree orientation. No randomization. For a polynomial-size acquired family of patterns, compute each hull, choose best rank (or any exact contradiction), cost 2^(min rank) poly(N) with acquisition charged. No enumeration of all 2^m patterns, no assertion that one is always low-rank.

## 5. Exact obstruction for the three standard color splits
For a raw complementary pair plane (disjoint union of two cubic bipartite graphs), let c be total connected component count, m=3n tuples, 4n element vertices, 2m indexed edges. Let A be original binary incidence, rho=rank(A). The affine variation space of PM incidence vectors equals the GF2 cycle space of this plane. To prove: PM differences are Eulerian; every even cycle has signed alternating integer circulation v with entries 0,+/-1. The all-one edge multiset and all-one+v are each nonnegative integer 3-regular bipartite multigraphs, each decomposes into 3 PMs by iterative Hall. Their difference v mod2 belongs to span of PM differences (sum of six PM vectors). Even cycles span the entire cycle space, including indexed 2-cycles. Thus dimension 2m-4n+c=2n+c. Restrict discrepancy linear map to this variation space. Its kernel is the duplicated native homogeneous solutions Ax=0, dimension m-rho, because zero discrepancy means the two edge bits equal. Rank-nullity gives
  r_standard = rho - n + c.
In particular changing just global color pairing only changes c; cannot universally make rank small. All raw bipartite projections contain 0 in the discrepancy affine hull because their edges partition into three PMs.
On the genuine PS08 Q mesh, l macro left vertices, m=6l, n=2l. Q's raw GF2 rank4: unsigned K4 edge incidence rank3 plus the total-sum row (outside its cut space). Its affine chart is exactly odd parity on the three exposed color0 ports with unique lift; the three actual local cover words and all-one word give the four possibilities. The connected cubic bipartite macro incidence then has dimension l+1, so rho=5l-1. For every standard split, the pair not containing color0 consists of l connected Q pair components; the color0 pair connects all macro blocks (each block's intact color0 row joins its two other-color vertices). Hence c=l+1, and r_standard=4l=2m/3. This falsifies universal logarithmic raw complementary-plane rank, on easy SAT matching instances. It does not refute arbitrary mixed local resolution, the combined regional solver, or unrestricted P algorithms.
