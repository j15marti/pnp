## 3. Exact support seam with one-hot selector (PROVED)
Work with explicit matrix H over GF(3), Boolean variables, target b, not necessarily a native incidence matrix. Partition columns L,R; U=span(H_L), W=span(H_R), k=dim(U intersect W). If b not in U+W, reject. A Gaussian solution, not a Boolean solution, provides z0=H_L x_L. All possible compatible left syndromes lie in Z=U intersect (b-W)=z0+(U intersect W), so at most 3^k. Compute basis of the intersection by Gaussian elimination, enumerate Z. For each z, solve H_L u=z with u Boolean, record actual witness if YES; an unresolved local query cannot be interpreted as NO. Let S be the set of actual attainable compatible left syndromes. If empty reject. This is not the entire affine coset in general.

For q=|S|, replace L with the following small Boolean system.
* q=1: subtract its sole syndrome from b, no variables.
* q=2: shift by z1; one column z2-z1, chosen by a Boolean bit.
* q=3 with all points on one affine line (always if k=1): shift by z1, use two copies of d=z2-z1. Their sums 0,d,2d attain exactly the line. Decode by number of selected copies. Thus ANY rank-one seam needs at most two virtual columns, regardless of original region size.
* q>=3 in general: create one selector leaf l_i for each z_i, carrying z_i in the retained equations. Enforce exactly one leaf via a binary/suffix tree. For q=3 use l1+l2+l3=1. For q>3 use l1+l2+u1=1; then -u_j+l_{j+2}+u_{j+1}=0; finish -u_{q-3}+l_{q-1}+l_q=0. All variables Boolean. Each root equation has possible integer range [0,3], so modulo 3 RHS1 forces integer1; each internal equation has range [-1,2], so modulo3 zero forces integer zero. Thus exactly one leaf selected, conversely each leaf has an extension. q leaves plus q-3 auxiliaries =2q-3 columns, q-2 extra rows. Auxiliaries carry zero in old equations. No source-geometry or physical tuple interpretation for these columns.

Both directions: original feasible Boolean word has left syndrome in S and can set the corresponding selector; right bits unchanged. Conversely every feasible virtual word chooses exactly one syndrome in S (or a decoded line value), and replacing its entire virtual region with that syndrome's stored actual Boolean witness gives H_L u+H_R v=b. Nested lift uses stored local input-column IDs; never adds two local witnesses. May discard alternative witnesses with same syndrome for decision/lift, not for exact counting or subsequent arbitrary guards on deleted variables. To handle a new original guard, recompile with it first or recompute affected table. Existing guards included in all equations, so no loss. This is an exact adapter for general Boolean GF(3) linear systems, not claimed to preserve planarity or degree.

Contrast SW04 nonnegative GF(2) minimum-weight XOR virtual-column proof. Its stated weighted optimum result is correct under its own assumptions because XOR of binary witnesses remains binary and weight subadditivity applies. It does not imply arbitrary boundary-only tables can be added, or GF(3) Boolean witnesses can be added. A+b may have coordinate2. Our selector retains exact support instead of relying on cancellation or costs.

## 4. Actual counterexample to free boundary-state addition (FALSIFIED)

L-exclusive rows [3,9,17,19], R-exclusive [0,2,6,13], 16 shared rows. Two locally valid left words select {14,16} and {6,8}, respectively; each separately occupies every L-exclusive row exactly once. Right word {7,15,17} satisfies each R-exclusive row. Adding the two left boundary contributions and the right contribution gives integer occupancy1 on ALL 16 shared rows. A naive independent-column boundary relaxation therefore returns false YES, though the union occupies all four L-exclusive rows twice. Actual local support is not closed under addition even when the two local words have disjoint supports. This falsifies only boundary-only multi-selection after deleting local rows, not full-syndrome weighted binary XOR or arbitrary solvers. U is already rejected by affine/ordinary closure; not a postclosure prime lower bound. Separately two disjoint bases (e1,e2) and (e1+e2,e1-e2) over GF(3)^2 have only 8 distinct Boolean subset sums, missing (0,2), so two-base rank packing is not sufficient for full ternary support. ## 6. Complementary exact projective-excess terminal (PROVED)
For Hx=b with x Boolean, acquire affine chart x=a+B y over GF(3) by Gaussian elimination. A zero observation row fixes x_i=a_i; reject a_i=2. Normalize each nonzero observation v_i to projective direction u (first nonzero coefficient normalized to1); its Boolean domain forbids exactly one residue for u*y. Group parallel directions, retaining original row maps. Three distinct forbidden residues reject; two force the remaining residue, add this affine constraint and reparameterize (strict dimension decrease). All remaining projective directions each allow exactly two residues. Their span is the whole free parameter space because B has full column rank. Choose an actual basis of r distinct directions, express e extra directions as coefficient rows in these basis-value coordinates. Connect basis coordinates appearing in the same extra form; connected factors give disjoint coordinate scopes. For a factor with r_i basis values and e_i extra forms, dynamic program over GF(3)^e_i: start zero partial sums, for each basis coordinate add its coefficient vector times each of its two allowed values. At end retain a state meeting every extra form's allowed domain. Store predecessor choices. Alternatively enumerate 2^r_i basis values. Both exactly decide the factor; independent factors combine, solve the acquired basis linear system for y, lift x and check all original equations/domains. Time poly(N)+sum_i min(3^e_i,2^r_i)*poly(N), polynomial when each factor's min(e_i,r_i)=O(log N). No supplied basis or target model. Factors discovered by Gaussian elimination and connected-component search. This can be called on virtual Boolean systems as well, and is a real complementary hereditary terminal, not asserted to cover arbitrary prime matrices. The cap audit returns UNKNOWN rather than treating declined factors as UNSAT.
