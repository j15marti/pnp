## 3. Exact bad-pair literal backdoor characterization
For a nonempty explicit relation R subset {0,1}^a define bad ordered pair (u,v) if weights have different parity OR some i in D=u XOR v has no j in D distinct from i with u XOR e_i XOR e_j in R. In the latter clause it suffices to test same parity pairs. For set P of pinned coordinates, every nonempty fiber R restricted to any P-word is an even delta-matroid iff P meets D(u,v) for EVERY bad ordered pair. Necessity: if P misses D, pair survives in the same fiber, and bad parity or absence of exchange persists in any subset of R. Sufficiency: any surviving pair agrees on P; it was not bad in R, and every admissible exchange toward the other mask toggles only unpinned differing coordinates, hence stays in the fiber. Empty fibers are rejected. This is a full equivalence for all LOCAL fibers, stronger than merely checking globally attainable guards; may overpay relative to a weaker contextual backdoor. Bad pairs acquired in poly(total explicit table size, arity), including actual membership lookups. Twists (complementing coordinates) preserve even delta-matroid property and do not evade the criterion.

## 4. Shared affine rank guards: uniform discovery and global solver
Acquire global affine chart x=x0+B y over GF3 after unconditional exact-one, affine, and indexed matching-support saturation. Retain guards and original IDs. Each occupancy port p has affine form a_p+l_p(y) on the chart (sum of original coordinates on that row). Since R_i was restricted to globally affine-compatible syndromes, its mask is a projection of some global affine word; hence if two retained masks differ at p, l_p is nonzero. Only original true Boolean words need lift, not arbitrary affine words.
For each bad pair define C_p the finite set of nonzero normalized projective directions l_j for its differing coordinates. Want subspace U hitting each C_p: C_p intersect U nonempty. Let k=dim U. Enumerate 3^k values for a basis of U. In each branch compute, for every port direction in U, its affine value; reject if not Boolean; pin all those ports in both region and corresponding row relation. Bad-pair lemma guarantees all nonempty residual region tables are even delta-matroids. Row relations remain one-hot or singleton after pinning. Reclose by exact table pins, shared-row occupancy, affine/guard deductions only if justified (additional literal pins preserve EDM), and call KKR. Any original witness selects one enumerated basis valuation and survives; any returned joined local witness union is a true source witness, and its global affine word has the enumerated relevant port values. If U generated by offered directions, all basis valuations enforced by actual port pins (or use an explicit basis of selected offered forms); this avoids a free semantic restriction. Even with a nonminimal U one may replace it by span of hit offered directions. All guards are conditional, never exported as unconditional source pins. No free nonlinear guard. T(N)=poly(N)+3^k poly(L+N) where L total explicit acquired table/ID length; full peak and cumulative work/space polynomial for k=O(log N), including failed fibers and witness verification. In test construction a single normalized direction is shared; of the three GF3 branches one rejected as non-Boolean, two actual matching joins.
Uniform greedy: start U=0, find unhit bad pair C, add span(C). For any optimal hitting subspace U*, at least one direction in C lies in U* but not in old U, so dim(U intersect U*) grows strictly. <=k*=dim U* iterations. Let d=max_C rank(C). Acquired rank <=d*k*. For rank1 exact acquisition, intersect the projective sets C, check nonempty intersection. More generally, if d fixed, branch on the <=(3^d-1)/2 possible distinct directions in an unhit C, extend span one dimension, depth at most a chosen rank cap k; every optimal U* of dim<=k has a compatible branch. Deterministic O(((3^d-1)/2)^k poly(L+N)) discovery (for d=1 trivially one branch). d<=lambda(S) for a region since its global affine projection has that rank. No promise of universally small k*, d, or affordable partition. Greedy gives a paid approximate separator, not a proof of universal log rank.
Additional exact block combination (theorem-level only): after region adapter, partition all factor nodes (regions and shared rows) into bags forming a tree of interbag edges. For each bag enumerate candidate boundary port masks from the projected global affine chart (rank w), compute local exchange-guard subspace of rank k on its explicit relation tables (pin boundary and guard directions, use KKR on remaining internal wires). Need every bad pair in every local factor hit by the guard span, or boundary pins; may use unconditional bad-pair set as sufficient condition. External boundary pins remove one endpoint of each crossing edge; internal wires still occur exactly twice, pinned external wires eliminated. Each table stores actual local factor words/witnesses. A true global solution survives; any tree join of actual local factor witnesses agreeing on physical wires gives exact global source witness. Candidate affine pruning can omit local-only words that cannot extend globally; never falsely excludes an original witness. Compute bag tables once at cost 3^(w+k) poly(N+L); combine bottom-up on identical wire masks in polynomial total table size. Thus global rank may be large if paid local boundary/guard ranks logarithmic, and global matching subproblems can have arbitrarily large internal width. ## 5. Native four-color conservation classification
Work on raw native tuple groups, retaining original rows and port colors (not arbitrary virtual-selector matrices). Let p_c be number of private element rows of color c in a group, q its selected tuple count, B_c its shared row ports. Then sum_(j in B_c) z_j=q-p_c for each c, since every selected tuple contributes one incidence to every color and all private rows are satisfied. This holds for any retained exact table, including guarded or affine-compatibility-pruned tables. In particular parity of the full boundary mask is fixed because total=4q-sum p_c.
Claim: a nonempty such R is an even delta-matroid iff q is constant across its masks, R is the Cartesian product of its four color marginals, and each marginal is a fixed-cardinality matroid basis family. Proof: EDM exchange allows path between any two masks by two-bit toggles toward target (Hamming distance drops2 at each step). Changing q in one step would require changing all four color totals, impossible with two toggles. Hence q constant. A legal two-bit exchange must preserve every color sum, so it exchanges one selected and one unselected coordinate of the SAME color. For any u,v in R, one can exchange toward v solely on a chosen color until that color agrees with v while all other colors remain as in u. Repeating color-by-color yields every Cartesian product of marginals. On a fixed color, basis exchange follows by applying EDM to two masks with same other colors (choose a departing selected element); quotas are constant, so basis exchange axiom of matroid applies, including singleton or rank0. Conversely product of fixed-rank matroid bases is EDM by same-color exchange. This precisely identifies nonrectangular cross-color joint support, or varying local count, as native obstruction; marginal feasibility alone insufficient. No analogous claim for signed virtual columns unless a verified color-conserving adapter exists.
Special consequence: if exactly one boundary color and min(quota, number of ports minus quota)<=1, every nonempty support is EDM. For more colors a fixed-q nonrectangular joint relation may still require common guard. This also indicates why naive "all 3-state quadrilateral components are automatically matchable" is false.
