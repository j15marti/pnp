## 1. Canonical binary parity torso theorem (PROVED scoped)
Input indexed Boolean edge-CSP, each physical bit occurs exactly twice, explicit fixed-parity factors, actual guard/witness ownership. Let a region consist entirely of bijunctive factors. XOR local parity equations cancels internal edges, so exact projected boundary relation R has fixed parity. Existential projection preserves 2CNF (binary resolution), hence R is bijunctive. Obtain actual compact 2CNF on boundary via implication-graph reachability: if initial formula satisfiable, literals a,b compatible iff individually possible (no a->not a and no b->not b) and no a->not b. Indeed union of their implication closures otherwise consistent (if conflicting consequences from different literals, contraposition gives a->not b), and extends by SCC. All absent unary/pair assignments determine exact projected relation by binary resolution. Empty R rejects. Zero-port region decided by SCC. No enumeration of boundary words.
Take one actual reference boundary word w0 by SCC on region alone, twist by w0. The relation now contains zero and has even parity. It is meet-closed because majority(0,u,v)=u intersect v. Delete constants and partition live coordinates into equality classes of twisted bits. For each class, intersection of all attained supports containing it is attained and is exactly that class plus all its strict successors in the quotient implication order. Reverse-poset induction: strict successors have even size, minimal attained support even, hence own class even. Twisted equality maps back to equality/complement in original coordinates. Distinct live classes have both values supported and zero reference; at most one of four pair assignments can be forbidden, since two forbidden imply pin or equality/complement. Thus actual relation has a compact signed even-block description plus at most one binary clause per distinct block pair. Acquire using reachability and polynomial scans, e.g. O(p(V+E)+p^2) for p ports in formula graph; original extension via pinned SCC.
R is itself an even delta-matroid iff all live classes size2 and no coupling between different classes. Necessity: exchange from any word toward another differing on a class must toggle its entire class, impossible in two coordinates if size>2. With size2, symmetric exchange flips precisely one differing pair; iterating toward any word allows individual block changes and yields full independent product. Converse independent pairs and fixed bits satisfy exchange. No weight/count transfer. This recognizes matching-compatible binary torsos of arbitrary boundary length without explicit exponential supports.
