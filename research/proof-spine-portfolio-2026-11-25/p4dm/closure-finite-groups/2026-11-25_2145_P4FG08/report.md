## 2. Theorem A: all sixteen binary response relations admit a mandatory-cover gadget

A word w=b0+2*b1 is admitted iff deleting ports with corresponding bit1 leaves a graph with a matching covering all remaining mandatory vertices. Equivalently, externally covering those ports by specified edges and internally covering the rest realizes exactly R. Optional internal vertices may remain unmatched. Relation mask M=sum_{w in R}2^w. Here is a complete constant-size library; aux mask a indicates whether 2 (bit0) and 3 (bit1) are mandatory. Edges not listed absent.

Proof is finite exhaustive exact classification: for each of 64 (mask,word) entries, delete specified ports; if mandatory set empty accept, else choose one mandatory vertex u and recurse over each available neighbor v deleting u,v and removing them from mandatory set. This recursion checks all possibilities for covering u and decreases available vertex count by 2. Direct evaluation gives precisely bit w of M; library also executed via independent matching checks. Unary relations pad to a binary relation independent of second port, with no external edge at second port; empty adhesion gives a feasibility bit. These gadgets are NOT necessarily even delta-matroids in the perfect-matching sense and need not be planar.

A matching covering required vertices leaves only optional vertices unmatched; their number in the padded graph is even, so pair arbitrarily. Conversely delete the added optional-only edges from a perfect matching to retain every mandatory vertex covered by an original edge. Use deterministic general graph blossom. No external wire may be confused with arbitrary internal port coverage; record the actual mate on each named interface wire. This is crucial for witness lift.

## 3. Theorem B: acquired two-separator tree and exact local interfaces
Construct quotient graph H with one node for each event and each retained exact-one row, edges for actual signed incidences. Its size polynomial. Decompose H into a tree of bags with adhesion <=2 by explicit search: first split disconnected torsos by empty separator, then articulation points, then vertex pairs, testing each with graph connectivity. Split nonempty sides A,C and duplicate separator S into both new bags; add the edge of a 2-separator as a virtual clique in both torsos. Reattach each old neighbor to a child containing its old adhesion (size <=2 and made a clique, hence cannot be divided). The resulting bag tree retains running intersection for each original node; each original incidence edge has some bag containing both endpoints. Assign each original edge to one such final bag by deterministic scan. Virtual edges only guide decomposition, never enforce logical constraints. Each split strictly reduces sum of cubes of bag vertex counts: if s=2 then sizes a,b>=3, a+b=q+2 and each <=q-1, so a^3+b^3 <= 27+(q-1)^3 < q^3 for q>=4; s=1 use 8+(q-1)^3<q^3 for q>=3; s=0 use 1+(q-1)^3<q^3 for q>=2. Thus polynomially many bags and scans even without sophisticated SPQR; edge copies and adjacency storage polynomial. Quotient graph may be nonplanar, ordinary graph connectivity sufficient.

Root the tree. A subtree's boundary is its parent adhesion. For each boundary event export its actual bit; for each boundary row export integer partial sum 0 or 1 of the original incidence literals OWNED within that subtree. Reject partial sum >1. Interior row requires sum1, shared event requires agreement. For each of <=4 possible boundary words, a child table retains membership and an actual local word/backpointers. By running intersection, all variables shared between a subtree and exterior lie in its boundary. Interior constraints belong to subtree. Thus the table is an exact conditional relation, not separate marginals.

A bag computation incorporates all actual owned incidence edges and one factor for each already computed child table. Let d_B(v) count owned signed incidences of event v plus one incidence for each child factor using v. Parent boundary events are fixed by the boundary word. Mark e_B free event nodes with d_B(v)>=3 (may pessimistically count all not in parent adhesion). For each assignment to these e_B exceptions, construct a mandatory-cover graph:

* A row slot is a mandatory vertex when required sum is 1, absent for 0 (parent-row partial count fixed by boundary word; all other row nodes require 1). Every owned true literal and child-row contribution 1 uses that same slot, so exactly the sum of contributions equals the target; two cannot both use the slot.
* A free event with one incidence has a mandatory port linked to the target and a private optional dummy. Two incidences with identical signs have mandatory ports joined to each other; either both use their corresponding targets or neither. For opposite signs use a mandatory auxiliary linked to both ports; exactly one uses its target. A child-event bit uses sign0. For fixed events, each true incidence has a mandatory port whose only neighbor is its target (or isolated contradiction if target absent), and each false incidence is matched to its private optional dummy, with no external target edge.
* Replace each child two-bit table by Theorem A, with its external wire to the relevant event port or row slot. Zero/unary tables use the stated padding rule. Keep exact original child response IDs.

A satisfying local assignment gives a mandatory-cover matching by selecting external wires corresponding to literal truths and child response coordinates and then matching internally. Conversely, a matching gives an actual local assignment from every event's chosen external wires; row slots enforce exact integer sums, and each child response word is accepted by its exact stored table. The glue induction then recursively lifts each stored child witness, respecting shared event bits, disjoint owned row incidences and original integer occupancies. The root has one empty-boundary query. If a cap fails return UNKNOWN, never NO. Infeasible complete local search gives exact absent state; exact root NO or YES requires admitted all needed child tables. If every bag is admitted this is an exact decision, not a partial heuristic. No Cartesian product of child states or descendants' branch counts.

Optional strengthening (proved symbolically, not executed): merge parallel child messages having identical ordered boundary scope before counting degrees. For shared event coordinates require identical values; for row coordinates add their integer partial contributions, rejecting sums>1. For each pair of words in the two <=4-state tables form one admissible aggregate word, keep split backpointer. Repeat; <=16 joins per factor, exact via disjoint owned incidences/running intersection. ## 4. Costs and limitation
Define local size L_B to include all owned incidences, bag node copies, attached child tables/gadgets, port wiring and retained backpointers. Each has polynomial encoding and total L_B polynomial in N. At most four parent words and 2^e_B conditional exception assignments per bag, deterministic ordinary matching on O(L_B) vertices and O(L_B²) edges after optional completion. Charge failed assignments, actual matching construction, child-word decoding, all separator discovery/reattachment, row/event canonicalization and input scans. Time <= poly(N)+sum_B 4*2^e_B poly(L_B), polynomial if max_B e_B<=c log_2 N for fixed c. Streaming branch enumeration stores at most four local witness words per bag, polynomial peak space; recursive stack/backpointers and original ID lift polynomial. Arithmetic indices O(log N), GF2 bit vectors O(N) each, no arbitrary-precision real oracle. Cumulative memory <= (T+1)S same deterministic sequential realization. Source parsing, planarity/rotation, exact-one and matching-support/affine closure all included. Fixed cap=2 executed; production arbitrary logarithmic cap uses a standard bit-vector enumeration instead of JS 32-bit shift counters. No assumption of universal local-exception bound.

Three-port obstruction: equality relation {000,111} cannot be realized by ANY mandatory-cover graph with three mandatory deletion ports, even with arbitrarily many optional internal vertices. Compare a matching covering all mandatory vertices with all ports present and a matching after deleting all three ports. Their symmetric difference is a union of alternating paths and cycles. Each port is an endpoint (covered by first matching, absent from second). Each component contains at most two such ports. Toggle a component containing one or two ports in first matching: interior nonport mandatory vertices remain covered (covered by both originally), optional endpoints may change coverage, and exactly the one or two ports on that path become unmatched; delete precisely those ports. Gives a mixed word, contradiction. No claim about arbitrary 3-port relations or about unrestricted P4DM hardness; this is a boundary representation obstruction. Need higher-arity nonmatching terminal or structural coverage. Equality of actual tuple bits can of course be retained globally without this gadget, not a proof that equality itself hard.
