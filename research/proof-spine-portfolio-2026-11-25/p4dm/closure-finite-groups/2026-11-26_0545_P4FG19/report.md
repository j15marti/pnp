## 2. Weighted adjacent parity fibers (PROVED)
Fix adjacent pair parity on any constant-parity arity4 table, rotate to pairs (0,1),(2,3). Choose signs inside each pair so signed sum is constant for its equal/complement bit relation. Subtract common offsets: corner height modes (0,a,0,c) with independently complementable representative bits a,c, and arbitrary common integer translate. Every proper subset of four words can be made a chain by complementing representatives: for three words map the missing word to an incomparable corner; for two words map both to comparable words. Then arbitrary costs are submodular (meet/join select inputs). For full support choose complement of one representative if necessary so f00+f11 <= f01+f10. Different integer translates comparable because each offset is 0/1. Thus weighted local signed lattice admission ALWAYS holds; global coherence still independent. Ordinary weighted matching need not admit these fibers, including unequal complementary pair sums. Opposite pairs don't enjoy this local geometric proof.
