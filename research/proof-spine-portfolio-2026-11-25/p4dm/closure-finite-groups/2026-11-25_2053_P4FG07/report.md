## B. Matching lemma for a single region
Let local rows have allowed literal sum A subset {0,1}; a free event has at most two occurrences in this region. Empty allowed set rejects. Make a row slot absent for A={0}, mandatory for A={1}, optional for A={0,1}. Each free occurrence gets a mandatory port, linked to its row slot if present. A port matched to its row means the corresponding signed literal is true.
One occurrence: link its port to a private optional dummy to permit false.
Two occurrences, equal signs: link their ports directly; both must match row slots or both match each other. Two opposite signs: a mandatory dummy linked to both ports forces exactly one port to match a row slot. A fixed event, of any occurrence degree, creates a mandatory port linked only to the row for every true occurrence and no port for false ones.
Every feasible local assignment therefore gives a matching covering all mandatory vertices. Conversely mandatory coverage gives each row an allowed contribution, and the gadgets enforce precisely the equal or complementary occurrence pattern of its one actual event bit. Reconstruct each event from its port truth and sign. No edge disjointness assumption between groups, because their shared event coordinates have been explicitly identified.

The required matching can be found by maximum-weight matching with edge weight equal to number of mandatory endpoints; optimum equals number of mandatory vertices iff feasible. Alternatively join all optional vertices into a clique, add one optional vertex if needed to make the total vertex count even, and seek an ordinary perfect matching: leftover optional vertices of any mandatory-covering matching have even cardinality and can be paired. Removing added edges yields mandatory coverage. Polynomial in region size.

## C. Block-cut composition: arbitrary global hub multiplicity
Build the undirected incidence graph H of the signed exact-one rows and their event variables. Acquire its vertex-biconnected blocks (including bridges); their edge sets partition H. The block-cut graph is a forest with block nodes and articulation nodes. Root each tree at a block. The graph may be nonplanar; use general graph matching.

Two different interfaces are necessary:
* Event articulation: one actual shared Boolean value. Exact child masks are intersected for this value.
* Row articulation: one exact integer occupancy obligation. Child blocks export the actual number 0 or 1 of true literals incident in their block at that row, not a truth value of the row. Combine child masks by a two-state DP retaining sums <=1 and ask the parent block to supply the complementary total. Store one child-count choice for each attainable sum.

For a block with parent articulation, try its two states; root has one query. Each child constraint is a unary event mask or allowed row contribution set. Nonarticulation rows require total 1. The matching lemma decides local feasibility if every free event has at most two occurrences WITHIN the block. Fixed events may have larger degree. If some exceed two, enumerate only the unfixed exceptional event bits in that block then apply matching; store actual witness assignment for each successful parent state. Each query is conditional on the same original interface IDs; no marginal support substitution on an interface of higher arity. Siblings are disjoint away from their shared articulation, and each incidence edge belongs to one block. Induction up the forest and reverse traversal using stored actual choices therefore prove exact feasibility and witness lift. At each row the original sum is the sum over its block incidences; the row articulation DP enforces exact one. At each event articulation all block values agree.

Let e_B count event vertices of local incidence degree at least 3 in block B (before additional conditional pins). Then the aggregate bound is
T(N) <= poly(N) + sum_B 2^e_B poly(|B|).
At most two conditional calls per block, independent of how many descendants it has; no multiplication of child branch counts. If max_B e_B <= c log_2 N for one fixed c, the terminal is uniformly polynomial even if sum_B e_B is linear. For the executable cap test, an exceeded cap returns UNKNOWN, never NO. This is a sufficient scoped condition, not a proof of a universal logarithmic bound. Blocks, event representatives, signs, masks and matching gadgets are polynomially discovered. Source pin closure is re-applied on actual source deductions; at stagnation a completed closure with no new deductions remains a fixed point. Local mask alternatives are guarded conditional queries and not exported as unconditional pins. Production integration of source reclosure after optional new local deductions is unexecuted; the tested solver does not make such exports.

## D. Genuine scalable obstruction to global degree and its bypass
Base cube tuples (zero-based): 0000,1111,0011,1100,0101,1010. Its incidence is cube radial graph (opposite vertices have same element color, faces are tuples), planar. Eight element rows choose all combinations of one bit from each opposite pair. Three untouched colors give six rows, whose differences enforce equality of the three opposite bit pairs: deleting an antipodal pair of cube-pattern rows leaves a connected six-cycle with toggle edges in all three coordinates. Denote the equal opposite-pair events a,b,c. The row becomes a+b+c=1.

Take k disjoint offset copies, then swap color-0 incidences of tuple 1 in copy i and tuple 0 in copy i+1. This is a two-edge splice of planar blocks, preserving degree and distinctness (other coordinates are private). Each cut has one exchanged incidence in each direction; exact coverage and the untouched color quotas enforce equal exchanged tuple bits. Equivalently substitute the opposite-pair equations into exchanged rows. Consequently a_i=a_(i+1); all quotient rows are a+b_i+c_i=1. They are rationally independent due to private b_i. The event a has k occurrences, but every block is a bridge with local event degree one. Both a values extend, and every original tuple is selectable and omittable. Exactly 1+2^k solutions by direct choice. Thus global degree <=2 fails even after sound forced-bit closure and row-basis deletion; this is not a runtime lower bound. The new block matching solver decides it with additive work.
