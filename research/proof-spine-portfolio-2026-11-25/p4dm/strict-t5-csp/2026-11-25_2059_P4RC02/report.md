## 1. Exact row compiler
For each edge-connected component of quadrilateral faces of the actual embedding, collect every clause touching its faces, including all incident tuple IDs (not only facial vertices). Seed one clause with each of its three one-hot rows. If neighboring quadrilaterals share an edge, the next shares a clause; the next clause shares two variables with a fixed clause, so exact-one determines its third. Propagation fixes every incident tuple bit or detects contradiction. Uncovered clauses get their own one-hot row groups. Guard values checked before seed; duplicates and overlaps retain identical IDs. At most three rows per group, polynomial acquisition. The full CSP chooses one row per group, binary compatibility is equality on every shared tuple bit. Pairwise agreement is sufficient for global well-definedness of original bits, and every element clause is covered. Thus both directions and actual witness lift exact. No independent-region assumption. This is the direct all-group variant of P4RC01 (not its projected B conflict graph); can also apply the theorem below to its B-projected deferred groups with SCC lift. ## 2. Rainbow veto theorem (known variable-elimination context, new scoped integration)
Run arc consistency (each row supported in each other group) and path consistency (each allowed pair supported jointly in each third group). Every deleted row/pair is impossible in any full model; fixed point obtained by monotone deletions. Let D_k have at most three states. For row u of another group define L_k(u) = compatible states in D_k. A residual solution extends iff all these sets intersect. If intersection empty choose one veto row for each k-state. A single veto row is impossible by arc consistency. Two incompatible requirements jointly vetoing all states is impossible by path consistency because all chosen residual rows are pairwise compatible. Thus size <=2 always eliminable. For size 3 any minimal obstruction is exactly three distinct-group, pairwise-compatible rows, each forbidding one different state (if one forbade two, together with a veto of third would contradict path consistency). Enumerate these triples. If none, delete k without adding constraints; the induced enriched CSP equals its existential projection. Store D_k and its remaining pair relations; reverse order try <=3 states and lift. This is a sufficient uniform local test; existence of a veto triple does not mean it extends to the full remainder. Cannot infer UNSAT or non-eliminability by other methods. BTP literature Cooper–Jeavons–Salamon AIJ 174 (2010) 570–584 studies related elimination; do not claim novelty for general consistency/elimination. Our exact obstruction taxonomy is specialized to this 3-state setting.

At every fixed point, unanimously assigned original bits in surviving rows are entailed by every original model, because every earlier deletion was exact. Reapply exact-one and all six paid bipartite projection matching-support checks, retaining current guard; prune incompatible rows and repeat. Sound new pins cannot exclude any lifted residual solution (all lifts satisfy original guard). This is implemented in audit.py; recheck at stagnation before UNKNOWN. Reverse lift validates occupancy and guard.

## 3. Acquired event matching terminal (PROVED)
From a path/arc-consistent binary CSP, union live states in different groups if each has exactly the other as its compatible row in the other's group. This is mutual logical implication, hence equivalence in every full model. Transitively merge via union-find; no oracle. Let F(e) be group footprint of each event. Admit only if each class has one state per represented group and covers at most two groups. For every cross-group pair check table compatibility iff same event or disjoint footprints. If failed return UNKNOWN. If passed, create graph on group vertices: two-group event is edge, singleton gets private leaf, weight number of actual group endpoints (1 or 2). Parallel edges of same weight/footprint can retain one actual event, because table criterion makes both interchangeable with all outside events. Every full solution selects entire event classes by equivalence and distinct classes cannot overlap a group. Conversely a matching covering every group supplies one row per group, same-class or disjoint-footprint pairs all compatible. Max weight equal g iff SAT; deterministic weighted blossom algorithm, actual row lift. If used after safe elimination, use the current enriched pair tables and saved stack, not original marginal relation. This theorem integrates the prior finite-groups matching lane at relational level.
