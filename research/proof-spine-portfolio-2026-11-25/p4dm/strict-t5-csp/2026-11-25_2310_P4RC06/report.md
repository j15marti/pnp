## 1. Named lemma: conservation-phase composition
For any region of incidence vertices let K be number of selected internal tuples; A_c number of its internal elements of color c; P_c active outward incidences from internal tuples, Q_c active inward incidences from external tuples. Counting selected incidences gives K-A_c=P_c-Q_c, for each c. If at most one boundary incidence per color, each occupied color restricts K to two consecutive integer values; an absent color fixes K. Hence at most two possible boundary words. If two words, every port bit equals a common phase or its complement, according to incidence orientation. Actual feasible words are a subset of these conservation candidates, acquired by exact local solve with original guard; do not replace actual support by conservation alone. Same tuple may occupy several ports; equality of its actual bit retained. For a partition of incidence vertices into such regions with acquired exact masks/witnesses, introduce one Boolean phase per two-word region and unary constraints for singleton masks. Equate the actual bits on each shared wire. Signed union-find or SCC decides all joins simultaneously, even if region interaction graph cycles. Both directions follow by restricting a source model and gluing actual local witnesses with agreed wires. Polynomial if masks and partition uniformly acquired; arbitrary region partition not proved.
Connected candidate regions of size <=c log N can be listed in N*4^(2c log N) time by walks traversing a spanning tree and verifying each resulting set (maximum degree4). Local brute force 2^O(size), constant-size boundary tables. This is NOT an automatic polynomial discovery of a disjoint covering partition. ## 2. Named lemma: two extremal witnesses imply exact activation cost
Suppose a disjoint region partition covers all elements, internal tuples confined to their own region, each region has A_R elements per color, exactly one incoming port per color, no outgoing port, each external tuple's four incidences hit these regions. External tuples necessarily pairwise disjoint (no element has two external incidences). Each region has actual zero-port exact cover (A_R internal tuples) and actual all-four-port exact cover (A_R-1 internal tuples, together with its external ports). For any nonempty subset of selected external tuple IDs touching R, at least one color has only A_R-1 free elements: local packing size <=A_R-1. All-active internal witness remains valid when fewer ports selected and attains A_R-1. Empty subset optimum A_R. Thus the entire local packing response is acquired from TWO actual extremal witnesses, regardless of region size. No need enumerate 16 patterns in the theorem; execution deliberately checked all subsets. If either extremal word infeasible, this packing-response theorem does not apply, even if a necessary affine relation holds.
Let S be selected external tuples and Gamma(S) the set of regions touched. Total max packing = n+|S|-|Gamma(S)| because sum A_R=n and local disjoint interiors add. Therefore d_opt(S)=|Gamma(S)|-|S|. Optimize S under consistent external-only unary guards using maximum weight closure (Picard): source->external cap1, external->each touched region cap M=m+1, region->sink cap1; require/forbid external using additional source/sink cap M. A finite respecting cut always exists (all external choices disjoint); all ordinary caps sum <=m, so no optimal cut crosses any hard arc. Source-side external set S incurs cut q-|S|+|Gamma(S)| (q=#external tuples); extra activated regions have strictly positive cost and omitted if untouched. Maxflow/mincut computes optimum; retrieve each region's stored witness, verify original packing and original guard. Full cover iff deficit0. For general unequal A_R same formula; q=#regions by counting boundary incidences. For original source exact-cover decision, inferred pins valid for every exact cover can be used to reject inconsistent guards, but do NOT silently restrict maximum partial packing with internal source-logical pins: optimization terminal concerns original external guard only. Local acquisition may be capped or fail. Both-lane execution explicitly solves same original guards.
Proof is a source-to-cut adapter, not a claim that arbitrary P4DM packing is a closure problem. If the connected region graph has both masks feasible, the exact-cover phase itself is simple equality; the additional result is the optimal partial packing even for incompatible exterior guards.

## 3. Genuine planar square mesh and bounded-deficit reconfiguration falsifier
Q = all six 4-bit words of weight2. Its incidence graph is the octahedron radial graph: six tuple vertices, three opposite complementary pairs, eight element vertices on triangular faces (each chooses one vertex of every opposite pair). Remove tuple 0011; remaining five tuple vertices and eight element vertices form a planar disk with four exposed ports on one face. Exact 0-phase covers are (0101,1010) or (0110,1001); exact 1-phase chooses 1100. All active ports are incident to the removed tuple; internal complement covers none of them. Every adjacent pair of the four exposed ports is covered by one nonopposite tuple in one of the two phase-zero choices.
Take even k by k grid, duplicate alternating boundary edges along each of four sides (first, third, etc.; corners receive two duplicates, other boundary vertices one). Connected plane bipartite 4-regular multigraph H, each side q=k^2/2, four edge colors by repeated bipartite perfect matching (Hall degree count). Replace each black vertex with the disk, permute color coordinates respecting the cyclic order of its four incident edges, identify exposed port elements with incidence edges from each white vertex now an external tuple. Parallel edges adjacent in rotation. All colors each have 2q elements, m=6q=3k^2 distinct tuples. Every element degree3; the whole incidence graph planar by disk replacement and actual embedding checked. Distinct external tuples disjoint; internal label sets disjoint. No gadget used as hardness transfer. All external bits must agree in any full cover since each black disk forces equality. Phase0 has 2^q covers, phase1 one. Every original tuple supported both values (different phase0 choices or phase1).
For any external set S, N_H(S)=Gamma(S); d_min(S)=|Gamma(S)|-|S| exact. A=S union Gamma(S) subset of grid vertices has 4d_min(S) multigraph crossing edges (all edges from S end in Gamma(S)). If q/3<=|S|<=2q/3 and d_min<k/4 then k^2/4<=|A|<=3k^2/4 for k>=4, using Hall |Gamma|>=|S| and 2|S|+d_min<=2k^2/3+k/4. Grid edge-isoperimetry implies at least k simple grid edges cross, and these remain among H edges, contradiction. Hence any packing in the middle has d>=k/4. In every sequence from all-external-off to all-external-on where each step changes at most fixed L external choices, for sufficiently large k there is such a middle state. Thus no fixed deficit bound can guarantee connectivity. Moreover choose a corner white tuple w whose four edges are doubled to two black neighbors. Select phase0 cover so its two incident ports at each neighbor are covered by one internal tuple (consecutive by rotation), remove those two tuples, add w: deficit1, respects w=1. Every exact cover under this guard is phase1; bounded-step monotone-deficit path impossible for k>=8 sufficiently large for L. Exact-one propagation already resolves the guard globally, so this is NOT a postclosure counterexample, or lower bound against other repair algorithms. Our collective one-cut optimizer jumps directly to exact cover. Explicit column-sweep optimum deficits peak k/2, not asserted minimum barrier. No intrinsic P4DM hardness claim.
