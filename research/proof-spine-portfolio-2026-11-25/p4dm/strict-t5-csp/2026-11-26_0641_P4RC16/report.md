## L1: local-linear-fiber rank acquisition
Input is an acquired loopless indexed plane Boolean edge-CSP, every edge touching exactly two factors, each explicit exact nonempty table of arity at most four and fixed XOR parity. Preserve actual source IDs, cyclic embedding and witness map. Empty tables reject; disconnected factors may be handled additively. The same selected terminal predicate must apply globally: all factors bijunctive (SCC), all factors admitting the verified ordinary matching library of RC14, or all factors admitting the original-plane one-sided meet-height solver of RC13/14 under a fixed coherent edge orientation. An arbitrary mixture is NOT claimed tractable.

Acquire necessary GF2 equations from each actual table (enumerate its at most 16 linear forms) and guards. Solve by Gaussian elimination; inconsistent equations certify NO. Express every physical bit x_e=c_e+ell_e(y). Delete a local word only if it contradicts the affine projection on its exact scope: equivalently every zero-direction local combination must have its implied constant. Repeat support and affine closure after deletions, and transfer certified pins to native exact-one and all six bipartite projection matching closures; retain guards. At most the explicit table entry count plus source variable count many strict deletion/pin rounds. Keep the actual relation, never substitute its hull. For each factor v the local direction span L_v has dimension <=3 by fixed XOR parity, hence at most seven nonzero directions.

For a candidate subspace U, partition each actual local table by the evaluations of every direction in U intersect L_v, using a corresponding actual local linear form and its offset. After affine consistency different representations of a direction differ only by a known constant. U is admitted iff every nonempty fiber at every factor satisfies the same fixed terminal predicate. For height, constant signed divergence is required per fiber, not necessarily before branching.

Start U=0. At each node rescan ALL factors. If all pass, return U. Otherwise choose one failing factor v; branch on adjoining each of its <=7 nonzero directions outside U, stop at rank cap r. Correctness: if a successful U* extends current U and has rank <=r, its intersection with L_v must strictly exceed U intersect L_v, since otherwise the local partition is unchanged. Some candidate branch therefore remains within U*. Induction on rank slack proves complete bounded-rank acquisition. Conversely the acceptance test verifies the certificate. A successful arbitrary subspace can be replaced by the span of its local intersections, preserving them. Nonmonotone admission under extra parity slicing is possible, so do not carry forward an earlier good-factor mark. Discovery O(7^r poly(N)); no supplied model or SAT oracle.

Enumerate 2^dim(U) assignments to an actual basis of acquired directions. At each factor filter its exact table by all evaluations of U intersect L_v. Each original model appears in its unique branch. Conversely any terminal witness satisfies original exact tables with common physical bits. The basis is generated by actual local forms, so those evaluations also realize the guard. Retain exact lifts. Following branching, literal restrictions (source, support, singleton affine consequences) preserve bijunctive, EDM and meet admission; arbitrary further parity pruning is not silently used. Empty branch rejects. Every admitted fiber is solved by its polynomial terminal. Height uses signed divergence, an integral reference, plane dual face gradients and bounded monotone least extension; no rotation or topology surgery. Matching uses verified matching gadgets; binary uses exact unary/pair clauses. The time bound is O((7^r+2^r) poly(N)); at fixed r<=C log2 N, acquisition AND evaluation are polynomial. ## L2: single-pin original-plane height repair
For any fixed signed-divergence Boolean table on <=4 ports, fixing any one port yields min-closed integer translated prefix heights when the fiber is nonempty. Twist negative bits into positive ones, which changes heights only by fixed offsets. Remove the fixed port: at most three remaining bits of fixed Hamming weight. For weight zero/all the table has one word. For weight one or co-weight one the prefix vectors at shift zero are comparable, with coordinate differences of magnitude <=1. Consequently the minimum of any two integer translates is one of those translates (integer shifts either leave the comparable order or make one dominate everywhere). Reinsert the fixed height coordinate via a repeated coordinate plus constant; minimum closure persists. This applies even to arbitrary subsets of the fixed-weight words. Improves PS17's pin-all-port requirement when an orientation is already fixed-divergence, not when that premise fails.

Abstract example: W={0000,0101,1010}, all signs negative. No single coordinate observation makes both fibers constant-divergence, but x1 XOR x2 separates the zero word from the two alternating weight-two words, both min-admitted. This is an abstract table, not itself an authenticated native input.

Untouched rows [c,a,b], [f,a,b], [f,d,a], [f,b,e] imply f=c,d=b,e=a even over GF2. All eight constraints reduce to a+b+c=1, in conjunction with the exact cap response.

In the chain of k copies, alternate color1/2 splices on tuple42 between adjacent blocks. Only the corresponding row14 in each affected color changes c_i to c_j; untouched rows give a_i+b_i+c_i=1 while altered rows give a_i+b_i+c_j=1. Hence c_i=c_j even over GF2; the full connected chain has one global phase c. The exact joint compatibility is k triples a_i+b_i+c=1, with exact cap lifts. If c=1 all a_i=b_i=0; if c=0 each pair independently chooses a or b. Thus 2^k+1 projected compatible words (not a claim about full native model count). Conversely every such choice satisfies all outside rows and extends via the retained cap witnesses. All source models restrict to these words. Planarity follows from the authenticated RC15 edge-splice construction.

Every nonbijunctive outside ternary factor has the shared c direction in its local GF2 span; conditioning on it leaves at most two states. Cap constraints are already binary (NAND/equalities), and their fibers by c are binary as well: c=0 makes a,b opposite; c=1 fixes both zero. Hence one globally shared parity observation repairs all factors on this exact chart for every k. There are at most two SCC decisions, no product over blocks, no surgery period enumeration, no seam DP needed. RC15's >=2^k actual surgery period vectors therefore coexist with rank-one binary backdoor in a different exact representation. This is an exact representation bypass, not a universal source acquisition theorem.
