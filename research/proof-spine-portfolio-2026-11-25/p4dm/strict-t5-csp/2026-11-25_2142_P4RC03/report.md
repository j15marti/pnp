At the fixed point let E be the live equality classes; every unsatisfied row is a set of two or three distinct live events. Build simple H with one vertex per live event, put an edge iff both occur in an unsatisfied source row, and set w(e)=number of actual original tuples in class e. Let k be number of original tuples pinned selected. Then the exact decision equation is
  source SAT iff alpha_w(H)=n-k,
where alpha_w is the maximum weight of an independent vertex set. Any independent set selects all original tuples of its classes plus the already selected tuples, with no repeated element. Hence it has cardinality <=n, and equals n iff every element in each of the four parts is covered. Conversely every source model respects the proved equality/pin relations, so its selected classes form an independent set attaining n-k. This requires no universal quadrilateral component bound, no free SAT oracle, and no planarity assertion about H itself. It permits events of arbitrarily large footprint, and gives a unique source interpretation to each event. This is an alternative exact compiler into the SAME weighted stable-set objective used by P4RC01/02. It generalizes P4RC02 matching admission beyond size-two footprint: an exact solver for weighted H suffices.

Adapter for P4RC02's enriched row tables (theorem-level, not executed in this audit): union any mutually implied state literals, including transitive closure, retain one class per event with all actual row-state IDs. A class with two different states of one group, or any internally incompatible pair, cannot be chosen. Discard it and reclose. Weight = number of distinct groups in class; edge between classes iff some two member states are incompatible or groups overlap. Then any independent selection of classes expands into one pairwise-compatible state per covered group; equality of covered group count to total g supplies all groups and therefore the full CSP model (and P4RC01 SCC lift when using its projected binary core). ### 3. Exact clique-tree aggregation and compensation
Use Tarjan, Decomposition by clique separators, Discrete Mathematics 55 (1985) 221-232, DOI 10.1016/0012-365X(85)90051-2, which gives polynomial clique-separator decomposition and MWIS applications. Here prove the needed recurrence directly and implement bounded separator discovery (cliques of size <=3), so no unimplemented general recognition assumed.

Split H on a clique S with two nonempty sides A,B and no cross edge, into induced bags A union S, B union S. Potential q(G)=number of unordered nonadjacent vertex pairs. Since S is a clique, no nonedge counted in both children, while every pair in A x B is a lost nonedge. Therefore q(child1)+q(child2)<=q(parent)-1. Recurse until no admitted separator. There are <=q(H) splits and <=q(H)+1 leaves, even if cliques overlap arbitrarily. Empty separators split disconnected components. Every clique appears in some leaf bag by induction: it cannot straddle A and B. Connect the two child trees at bags containing the shared clique. This gives an actual tree of bags with running intersection for every vertex, every edge owned by at least one bag, and intersections along tree edges cliques. Verify these properties explicitly. Separator search at most O(m^3) candidates per bag (singletons/edges/triangles) with paid connectivity. General clique-separator discovery by the cited algorithm would extend the conditional theorem, but is not implemented.

Root tree. Each vertex weight is counted at its highest bag, not on duplicated copies. For child bag subtree j with parent clique C, define F_j(a) as optimum weight of vertices strictly inside that subtree excluding C, conditional on choosing exactly a in C, where a is empty or one vertex of C. No other states exist because C is a clique. Child weights and witnesses include all descendant private ownership; no cross-edge not carried by an intersection. For an arbitrary independent local set I in parent bag, child contribution is exactly
  F_j(empty) + sum_{s in I intersect C} [F_j(s)-F_j(empty)].
Thus a complete child message is a scalar constant plus a weight update at each separator vertex, even for a very large clique. Summing over children modifies local weights additively. Parent query fixes its own separator state, removes all its separator vertices from the free local optimization and forbids neighbors of a chosen separator vertex. Add its conditional adjusted weight (original weight of shared vertex owned above =0 locally). Solve one exact MWIS problem on the remaining induced bag with adjusted weights. Reverse stored state pointers/lifts reconstruct an independent set with original weights counted once. Code stores full witness sets, still polynomial. Proof induction over tree uses complete clique-state enumeration at each edge, no product of child states. At most |C|+1 queries per bag. No re-solving a child subtree per ancestor state. This realizes an additive, charged recurrence, not an existential decomposition.

Simplicial compensation lemma: if optional v has clique neighborhood and weight a>0, remove v, add a to constant, subtract a from every neighbor's weight. For any independent set I of remaining graph at most one neighbor is selected. If none selected, v can and should be added; otherwise cannot. Thus exact max weight identity, with reverse witness. A nonpositive-weight optional v can simply be deleted for optimization. IMPORTANT: this preserves an optimal witness, not every source solution; it is not a universal forced-information pin. Never transfer these choices to source closure as entailed facts. Repeated simplicial removal works for chordal graphs. Remaining graph may admit weighted matching if line graph; acquire an inverse line graph via Roussopoulos, Information Processing Letters 2 (1973) 108-112, and verify explicit incidence bijection. For each vertex of H map it to one actual edge in root graph; all H adjacencies iff edges share endpoint. Weight matching exactly. Library can decline disconnected/nonline cores, which is safe; general component factoring is available. Small residual enumeration capped at 12 in audit, or O(log N) in theorem. Negative weights legitimate after compensation. Every unadmitted atom returns UNKNOWN, not UNSAT.

Consequently an arbitrary source graph with a uniformly acquired clique tree whose compensated conditional atom queries admit these exact terminals is solvable deterministically in polynomial time. Large shared events and large raw bag size alone are not obstructions. P4RC02 can use its exact enriched quotient here; P4FG07 block-cut matching is a separate, complementary occupancy-based join.

### 4. Genuine scalable odd-hole counterexample to simple classification
For every odd k>=5 construct k blocks Q consisting of the six binary four-tuples of Hamming weight two, in lexicographic ID order 0011,0101,0110,1001,1010,1100. Each block has two elements per color and three occurrence per element; Q's planar incidence is the radial graph of an octahedron. Complement pairs (0,5),(1,4),(2,3) are the three states. Place blocks on a cyclic macro graph, seam colors 0,1 alternating for the first k-1 seams and color 2 on the last. Adjacent seams have different colors. At block i pick one incoming and one outgoing incidence in distinct colors on opposite edges of a single quadrilateral face, with different complement pair classes. Such ports for ordered color pairs (2,0),(0,1),(1,0),(1,2) are respectively (tuple IDs 2,0), (1,2), (1,2), (4,0), obtained by the planar face scan in ring.py. Use color-specific coordinate swaps across each seam. Exact source degree and partition balance preserved; distinct tuple IDs remain distinct since each changed tuple has at most one changed coordinate and retains three private ones, and original Q tuples differ in at least two positions. Choose the cofacial port quadrilateral as exterior of each block disk. Opposite incidence edges have the same tuple-to-element traversal sense in its boundary, so disks can be oriented consistently; route each pair of crossed-incidence endpoints along a disjoint corridor between neighboring disks, matching opposite vertex types without crossing. This gives a planar embedding for every odd k. The independent NetworkX checks through k=65 supplement, not replace, this construction.

For each local type only two original rows change. The remaining six unchanged rows force all three complement pair equalities by repeated common-pair subtraction. Explicit finite certificate (rows indexed (color,value), zero-based):
  type (2,0): compare rows (0,1)/(1,0), then (0,1)/(2,0), then (0,1)/(1,1), obtaining 0=5,1=4,2=3;
  types (0,1) and (1,0): first two pairs same, then (0,1)/(2,1), same equalities;
  type (1,2): compare (0,0)/(1,1), then (0,0)/(2,0), then (0,0)/(0,1), obtaining 0=5,2=3,1=4.
After equality all six unchanged rows are the identical one-hot sum of the three local states. Each changed row contains exactly one swapped tuple and two local states; subtract its unchanged one-hot equation to show seam equality between the appropriate events on adjacent blocks. Thus exact original-ID event structure: E_i is shared state across seam i (four tuples), P_i is private state of block i (two tuples), and the row conflict graph is exactly the cycle of triangles on {E_(i-1),E_i,P_i}. These equalities are acquired by repeated pair cancellation; no additional semantic equalities or unary pins exist. To see this, choose all P_i (valid cover) and separately for each seam i choose E_i and P_j for all nonendpoint blocks (valid cover). This family distinguishes all events: distinct E_i by single-seam cover; E vs P by all-private cover; distinct P_i,P_j by a seam incident to exactly one of those blocks. Every tuple both selected and unselected in some source model. Therefore even complete sound unary closure and all actual tuple equalities cannot remove these event vertices. Weighted curvature cannot infer a pin either. No statement about stronger nonunary optimization contractions.

The E_i induce an odd cycle C_k; hence H not chordal or perfect by definition (odd cycle needs three colors but clique number two). Moreover any clique intersects this cycle in at most two adjacent vertices. Deleting such intersection leaves remaining cycle vertices connected; so any recursive clique split retains the whole induced cycle in one child, and at least one final bag has size >=k. The k-cycle itself has no clique separator. A universal logarithmic bound on raw clique bags is false for this exact source quotient, even after perfect unary information acquisition. This does not falsify polynomial MWIS or the proposed full coverage. In fact deleting each private simplicial P_i with weight 2 subtracts 2 from its two shared neighbors. Each E_i starts with weight4 and is adjacent to two such private vertices, so all E_i end with zero weight. The large odd prime is thereby solved without branching; line graph of a cycle is another exact terminal. This separates structural width/perfectness barriers from actual weighted problem difficulty. Unlike arbitrary abstract counterexamples, these are genuine source-realizable infinite family. No unrestricted lower bound.
