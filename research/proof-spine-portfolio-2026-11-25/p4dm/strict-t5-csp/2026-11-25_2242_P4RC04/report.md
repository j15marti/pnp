## Named lemma: quadratic-interface aggregate compilation
For any original weighted event graph G, suppose a bag tree has running intersection, covers every original edge, and each adjacent bag intersection S has alpha(G[S])<=2. Child message F(A) is maximum weight of private vertices in child subtree, conditional on selecting exactly A in S, where A is independent in original G[S]. Boundary weights owned at highest bag, not counted by child. Every such A has an independent extension by choosing no private vertices, so F finite (even signed weights); not a full exact-cover support mask. For alpha<=2,
F(A)=F(empty)+sum_{a in A}d_a+sum_{{a,b} subset A}J_ab,
d_a=F(a)-F(empty), J_ab=F(ab)-F(a)-F(b)+F(empty).
Only independent pairs require coefficients. This is exact on all boundary states, not a hull or marginal approximation. Add children's constants, unary and pair coefficients on actual shared IDs. No product of child state sets. For each net pair coefficient J:
* J>0: add private vertex of weight J adjacent to a,b, add J to each endpoint weight and subtract J from constant. Conditional private optimum is J(1-x_a)(1-x_b).
* J<0: d=-J, add path a-u-v-b with private weights d,d, subtract d from constant. Conditional private optimum is d(1-x_a*x_b).
* J=0: no gadget.
Private gadgets independent conditional on endpoints, so exact additive total. Parent query fixes its own boundary set, excludes other boundary vertices and neighbors of chosen ones, includes chosen adjusted weights and optimizes the remaining augmented bag graph. Lift deletes gadgets, uses actual local independent set and each child's stored witness for its selected A. Induct on bag tree: ownership prevents double count, edge coverage and running intersection ensure no cross-conflict, all optimum extensions enumerated exactly by induced boundary states. At root compare original weight threshold and verify all integer occupancies, guards. This is a scoped polynomial algorithm if every actual augmented conditional atom is admitted by an acquired deterministic polynomial exact MWIS procedure.
