## 1. Acquire exact rows
Compute plane embedding, enumerate four-edge simple facial cycles, group by edge adjacency. For every such component, take all element clauses touching its faces, including the third tuple in each clause. Seed the three possible exact-one rows of one element. Across a face its two clauses share two tuple variables. Knowing both determines the third variable in each clause; inconsistent assignments rejected. Adjacent faces share a clause and tuple edge, so knowing a whole clause propagates along a face adjacency path. Every variable in any of those clauses is determined. Thus <=3 rows, computable by paid propagation, preserving all overlapping original tuple IDs. Check all local clauses and pins; do not equate different rows just because boundary marginals agree. For every element not covered by these groups, create a separate 3-row exact-one group. This supplements the singleton-variable convention in the paper and guarantees every actual element is checked. Every group is nonempty or exact NO. Sum of face incidences and element occurrences in the groups O(N), since bounded degree; even a naive implementation costs poly(N). Keep the source embedding immutable and all row provenance. No claim logical quotient remains planar.
Initially and after new source pins and at stagnation perform exact-one closure plus all six pairwise projected matching tests, including tests with each tuple forced. A failed necessary test implies a source pin or NO. Pair matchings are not a sufficient witness. On originally E3 inputs all six unguarded projections are 3-regular bipartite multigraphs so these checks alone cannot delete any tuple. Guards condition every state row.

## 2. Theorem: exact polynomial binary projection
Let groups G_i have 1,2,3 acquired rows on actual original tuple bits x_j. Introduce a selector p_ia per row. The binary core B includes source guard units, pairwise at-most-one selectors within every group, and implications p_ia -> x_j or not x_j for every bit in that row. Include the at-least-one clause for groups of size <=2. For each 3-row group defer only its positive ternary demand p_i1 OR p_i2 OR p_i3. Then source SAT iff B AND all deferred demands: a source witness selects its row per group; a satisfying selector assignment selects precisely one row per group and all row values agree on shared actual x_j, hence all source clauses satisfied. No independence assumption. This is exact also with arbitrary original unary guards and extra certified binary clauses.
First test B by SCC. If UNSAT reject. For each deferred selector a test B+a; for every distinct pair a,b test B+a+b. Delete individually impossible choices. Conflict graph H on remaining positive selectors has edge iff the pair test is UNSAT. Include same-group cliques (already implied by B). 
**Lemma (pairwise core extension):** For satisfiable 2-CNF B and any collection S of unit literal assumptions, B+S is satisfiable iff every singleton and pair from S is compatible with B. Proof by variable elimination: existentially project B to variables of S, resolving all positive/negative occurrences of each eliminated variable. Resolvents of clauses of length <=2 retain length <=2; discard tautologies and duplicates. Davis-Putnam elimination is exact: an assignment to remaining variables extends unless opposite signs of the eliminated variable are both required, exactly a falsified resolvent. The projection is 2-CNF. An inconsistent full assignment to the projected variables falsifies a clause of length <=2 (or empty, impossible since B satisfiable), hence one/two assumptions already inconsistent. Contradictory repeated assumptions directly fail the pair test. Alternative proof via union of implication reach sets: if closed reach union contains no opposite literals, assign it true and opposites false; every clause touching assigned variables is satisfied or already propagated, and remaining induced subformula is satisfiable as B was. Thus H construction is polynomial using reachability or paid SCC per pair.
If g deferred groups, each independent set has size <=g. Source SAT iff alpha(H)=g. In forward direction a witness chooses one row in every deferred group; backward independent set of size g supplies one per group, pairwise extension lemma gives a common model of B by SCC with units, all demands fulfilled. Lift actual x_j; independently verify every occupancy and guard. No pairwise approximation of the ternary demands: they are represented by exact transversal cardinality.
At stagnation remove every state with no compatible partner in some other remaining group; add its negative unit. If a group's remaining size <=2, activate its at-least-one clause inside B and remove the group from deferred list. Recompute B and H. Empty group is NO. All deletions preserve every source model; <=3g deletions, so polynomial fixed point. Transfer any newly certified original tuple pins to source closure and rebuild under guards. Source pins and state deletions are distinct. Can test B+not x and B+x for valid source pins; state masks unanimous on a tuple give another sound deduction. Reclosure after transferred pins is theorem-level, audit below runs initial source closure then exact state-deletion fixed point (no claim full portfolio).
Independent factors of H can be solved additively, as every group's states form a clique in one component. Any source-valid compact exact independent-set terminal can be applied. If H claw-free, polynomial maximum independent set (Faenza–Oriolo–Stauffer 2011 SODA, DOI 10.1137/1.9781611973082.49) gives a complete decision and lift, no branch over binary mediators. This does not require planarity of H. Recognition by enumerating four vertices. Optional branch: find a maximal family of vertex-disjoint induced claws; their union hits all claws. Take the groups containing those vertices (<=4 per claw), enumerate at most 3^k choices for those k groups; remove chosen groups and neighbors of choices. Remaining induced H is claw-free. This proves polynomial admission when k=O(log N), NOT a universal cover bound. Can solve conflict components separately. The production claw-free solver and hitting-cover implementation are not executed here; audit uses exact DFS as reference only.
