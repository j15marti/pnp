## 1. Named lemma: exact packing-relative paired-port projection

For any acquired reference packing P (disjoint actual tuples, not a target solution), its deficit d=n-|P| leaves d uncovered elements per color. Source-only acquisition: greedy scan of original IDs extending certified selected tuples and excluding certified zero tuples, after exact-one and all six pair-projection support closure. A different reference packing may be used as a guarded analysis/control. Do not treat membership of P as a forced value.

Let b count live alternatives outside P that are not exactly two covered ports at each of two distinct owners of P. This includes every live tuple incident to a hole. Enumerate all 2^b assignments, including inconsistent cases; reapply exact-one and indexed pairwise matching necessity under the branch guard. Fix selected tuples, delete conflicting candidates, keep source IDs. Any remaining live alternative has two ports at each of two distinct old owners. Owners may themselves be prohibited or selected; do not impose their original reference state. Holes must now be covered by selected tuples, or reject branch.

For each owner p, let F be its uncovered ports after fixing selected tuples. If |F| odd reject since remaining alternatives occupy pairs; if empty no obligation; if two, exactly one live alternative must cover that pair, a mandatory port node. If four, keeping p (when not prohibited) covers all four, otherwise choose two alternatives with complementary masks. Each port is incident to at most two live alternatives by source E3. Thus local multigraph on four ports has max degree 2 and at most two complete complementary partition types. No type -> keep p if permitted, pin remaining alternatives zero, else reject. One type -> discard all unusable alternatives, two mandatory matching nodes (one per mask), keep edge between them iff allowed. Alternatives connect to their corresponding node. Two types -> exactly four distinct candidate masks in a C4. If the candidate labels in cycle order are a,b,c,e, impose a=c, b=e, NAND(a,b), and if p prohibited add OR(a,b). With p allowed, both zero means keep p. These are all allowed local assignments, not an affine hull. Local exclusions and necessary pins are reclosed on source until fixed point. The two-port case admits at most two alternatives. Cyclic embedding yields a useful additional necessary constraint: two complementary alternatives cannot occupy interleaved opposite ports of an owner. Their two simple length-four incidence cycles would share only the owner and alternate there, contrary to the Jordan separation of a plane embedding. Not needed for algebraic terminal; no quotient-planarity assumption.

Equality links at two-type owners form a degree <=2 multigraph on actual alternative tuple IDs; each tuple has two owner incidences, each either one equality link or one matching endpoint. A component path or isolated vertex has <=2 endpoints, a cycle has none. A class with two occurrences at same port is forced zero. A self-NAND forces zero, self-OR forces one; reclose source under certified guard. Side clauses on distinct classes are binary; discard NAND between classes sharing a port. This is exact: a selected class includes all its original tuples; matching nodes demand exactly one selected incident edge, keep edges represent actual old tuple choices. Equality is not a substitution of independent marginal values.

Project all zero-footprint event variables from side 2-CNF by exact Davis-Putnam resolution, eliminating every opposite-polarity pair and deduplicating; tautologies discarded. Width <=2, O(m^2) possible clauses. An assignment to port events extends iff it satisfies the projection. Empty clause is NO; retain units. Later reconstruct free event bits by a common SCC solve conditioned on chosen endpoint events. A cycle can participate in arbitrarily many side constraints before projection, including positive OR clauses.

Let H be graph of nonunit nonredundant projected side clauses on events with nonempty footprints. Acquire a vertex cover via endpoints of a greedy maximal matching of H, size h (<=2 minimum). Enumerate its 2^h bit patterns. Each projected clause becomes true, false, or a unit; include all units and reject contradictory assignments. Reapply exact-one and all six source pair matching support under actual original ID pins; all new deductions guarded. Selected port events occupy their endpoints, discard conflicting edges. Remaining mandatory ports are actual required nodes. Parallel edges with same endpoints have identical compatibility after fixed side constraints; retain one representative. General deterministic maximum weight matching covers all mandatory nodes iff total weight equals their number. Lift selected events, use one SCC solve for free classes with endpoint bits and other pins fixed, and retain old owners iff their ports not occupied. ## 2. Named lemma: planar exchange curvature and one-defect anchor

Let C be any full cover of an unguarded source, P any packing. Delete common tuples. On P\C (old) and C\P (new), join by an edge for each element covered by both; preserve parallel edges and colors. This is a plane bipartite multigraph obtained by deleting other incidences and suppressing degree-two element nodes. All old vertices have degree four; new vertices degree <=4. In any connected component with a new vertices and r old, every color has exactly a-r uncovered elements: a new incidences minus r old incidences. Thus gain g=a-r>=0, all four hole counts equal g, and swapping just that component retains a valid packing. Sum gains d. If d=1, exactly one positive component with g=1 repairs all four holes by itself; neutral components can be omitted. This is a structural existence proof using C only as comparison, not an algorithm assuming target C. For a component with >=3 vertices and at least one old vertex, its simple underlying bipartite plane graph has <=2(a+r)-4 edges. Actual multiedges number 4r, hence parallel excess >=4-2g. In particular any nontrivial one-gain component has at least two parallel excess incidences, and a neutral component at least four. Direct gain1 singleton with no old vertex is a tuple covering all four holes. Parallel pair identifies two actual tuples sharing >=2 colors; the two source clauses share these variables, so subtraction identifies their third variables (if distinct). Not necessarily a facial quadrilateral. Candidate anchor pairs can be found in O(m polylog N) by enumerating the O(1) other tuples per port. If no direct hole-only tuple, every YES source with d=1 has a solution in a guarded branch selecting some new anchor tuple and excluding its old owner. Only O(m) anchors, but arbitrary child acquisition still OPEN; no aggregate closure. Bound not a lower bound on decision.

## 3. Native hostile family: fixed-radius repair false

Q is the six 4-bit tuples of weight two, sorted lexicographically. Three complementary pairs (0,5),(1,4),(2,3) are its exact covers. Make k private Q copies, shift labels by 2b per block. Between blocks b,b+1 swap coordinate b mod2 of tuple0 in those blocks. Different seam colors at internal block; splice along removed edges in disconnected plane components, preserving planarity at each step. Every original color remains E3, equal part sizes and distinct tuples. Untouched colors in each block force exactly two selected tuple IDs. In each swapped color, count occupancies of the two original elements in a block; one outward and one incoming incidence yields equality of the two exchanged tuple0 bits. Undo seam swaps; every cover is a complementary pair in each block and all tuple0 bits agree. Repeating any common phase yields full cover. Every tuple is globally supported both selected and unselected by choosing one of the three common pairs.

For even k, P takes pair(0,5) in first k/2 blocks, pair(1,4) in second half; remove tuple0 of last block in first half.
