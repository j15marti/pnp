## 2. Exact paid matching-observation quotient
Find one ordinary PM M, and the exact support of all indexed edges in any PM: orient unmatched pair edges left->right, matched pair edges right->left; a nonmatching edge occurs in a PM iff on an M-alternating cycle, equivalently its endpoints are in one SCC. Proof by symmetric difference in both directions; any other parallel ID at the same matched endpoints is allowed by direct substitution. For forced/forbidden edge probes remove forced endpoints, reject conflicts, delete forbidden edges, run same PM/support computation. No free oracle. Removing unsupported edges preserves every PM. The resulting ordinary connected components B_j partition the exact PM family as a Cartesian product because every vertex is matched within its own component, with a stored initial witness. This is the elementary perfect-matching support decomposition.
Drop forbidden pair clauses containing an unsupported edge (that edge is always0). Let O_j be physical edge IDs of B_j occurring in remaining clauses. Only actual indicator values on O_j are shared. Internal PM completions are existentially quantified, not independently guessed marginals. Need exact projected relation R_j on O_j and one actual matching lift per admitted word.
Uniform two-word admission independent of |O_j|: find base matching and test each observed edge for variation by forcing the opposite value. If none varies, exact singleton. Otherwise choose one varying observed anchor. Obtain actual matching and support in both anchored fibers. ## 3. Exact weighted counting when support blocks and interaction degree are small
Separate counting theorem, not a general consequence of 2SAT. If every connected component of exact indexed matching support has degree<=2 (count parallel edges), it is either a single forced edge or an even cycle, including a two-edge parallel cycle. Proof: any supported degree1 edge must appear in every PM, so its endpoints have no other supported edges; otherwise every vertex degree2 and component is a cycle. A cycle has exactly two complete PMs, acquired from base matching and its complement within the cycle. For each region its actual boundary mask depends on at most two binary block choices (because at most two slots). Construct exact nonnegative integer weight function equal to the number of actual guarded local tuple witnesses of that mask, zero for unattained masks. Forced blocks substitute constants. With fixed slot ownership, each original cover determines unique matching state, and conditioned on that state private witness choices are independent, giving exact total count Z=sum_{z} product_i w_i(z_scope). No double counting or reliance on one witness per mask. 
If graph of binary block variables with pair-factor edges has max degree2 after multiplying all factors with same scope, it is a union of paths/cycles/isolates. Fold constant and unary factors, then compute exact sum-product DP along each path: two-entry messages, each update sums over two prior bit values with exact pair weights. For cycles condition first bit on 0 and1 and include closing factor; sum the two conditioned results. Multiply independent component counts. This is exact #count as well as decision; O(number of factors/variables) arithmetic operations after acquisition. A witness obtained by nonzero backtracking or §2. More general forest interaction admits ordinary tree DP but not executed in this run. If degree>2 or block not cycle/forced edge, counting terminal declines. #2SAT in general not asserted in P.
For arbitrary guarded native source, with disjoint region ownership, weights <=2^|region|. Intermediate products and sums over at most O(m) binary variables therefore have O(m) bits, exact schoolbook arithmetic polynomial in N. Weighted abstract controls arbitrary integer weights finite input length; no unit-cost big integers assumption.
