## 1. Exhaustive physical cut classification up to four wires
Let S be a vertex shore of the original (or capped) bipartite incidence graph. Let m=number of tuple vertices in S, e_c=number of internal elements of color c. A cut wire is outgoing (+) if its tuple is inside, incoming (-) otherwise; let d_c=outgoing count minus incoming count of color c. Counting all incidences of color c gives exactly
  m - 3 e_c = d_c.
Hence all four d_c are congruent modulo 3. For any local satisfying assignment (actual boundary wire bits, each outgoing bit equals its internal tuple selection, each internal element exactly one), let a be the number of selected internal tuples and q_c the signed sum of active boundary wires of color c. Then
  a - e_c = q_c.
These are integer identities, not marginal compatibility. In particular if a color has no boundary wires then m=3e_c0, a=e_c0, and q_c=d_c/3 for every c. If all colors have one wire, d_c must have the same sign, so all e_c equal and all four bits equal.
Enumerating the at most four physical wire occurrences (not grouping distinct endpoint names) now gives the exhaustive possible signatures:
* 1 wire: impossible.
* 2 wires: same color, opposite directions; bits equal (00 or 11).
* 3 wires: all same color, all same direction; exactly one active (100,010,001).
* 4 rainbow wires: one per color, all same direction; all equal (0000 or 1111).
* 4 wires, two colors: one opposite-direction pair per color; each pair equal (4 envelope states).
* 4 wires, one color: two outgoing and two incoming; active outgoing sum equals active incoming sum (6 envelope states).
No other case: if a color absent, each d_c divisible by3; within four wires this permits only a monochromatic signed triple or balanced pairs; all colors present forces four equal signs. Actual local relation may be a strict subset of its envelope, even with guards. No assumption of local feasibility.

## 2. Planarity implies a stronger source promise
**Lemma (no three-coordinate overlap).** In any planar indexed incidence graph with tuple degree four, one incidence per color, and element degree three, distinct tuple vertices cannot share three or more element neighbors. Proof: if they share k=3 or 4, the induced theta subgraph K_{2,k} has k internally disjoint length-two paths; in a plane embedding each face of this subgraph is bounded by two such paths and contains exactly two shared element vertices on its boundary. Choose one shared element; its third edge ends outside this subgraph. The connected component outside the subgraph containing that endpoint lies in a single face and can attach to at most two shared elements. In its cut, the edge to the chosen element is outgoing, the ONLY wire of that shared color (the two original tuple vertices already use their incidence of that color, and the element has just one spare edge). At least one of the k shared colors is entirely absent from the cut. Thus d_chosen=1, d_missing=0, contradicting the color congruence. Other edges to the two tuple vertices, if k=3, have only the missing fourth color. This proof allows other components of the graph. Consequently duplicate tuple signatures are impossible in any planar regular four-colored cap graph, without an extra simplification that would violate E3. Also establishes a genuine local geometric restriction on quadrilateral overlap, not universal grouping.

## 3. Constant native caps for three seam types
A bond is a cut whose two shores are nonempty and connected. In a plane graph a bond has a simple disk boundary crossing the cut edges once (dual cycle, or regular neighborhood of one connected shore; other shore connected lies in one complementary component, fill empty holes). Each shore has a compatible cyclic order of physical stubs. Use cap Q: all six distinct binary 4-tuples of Hamming weight two, two elements per color, E3. Its incidence graph is the cube radial graph: group opposite cube vertices into four colors, label opposite endpoints by parity 0/1; each cube face has one vertex of each color and two of each parity, giving six distinct weight-two words. Opposite cube faces form its three covers. Hence every tuple can be selected or not, and every element's three incident choices individually extend to a full cover.
For a shore S, close its boundary by one of the following caps (new element IDs private).
* 2 opposite wires of same color: join internal tuple's missing port directly to internal element's missing incidence. No new vertices. Enforces equality of the two boundary bits.
* 3 monochrome outgoing: add one element of that color adjacent to the three tuple stubs, enforces exactly one. 3 incoming: use Q with one element of that color removed, attach the three now-open tuple stubs to the three incoming element stubs. 13 new vertices. Every onehot boundary word extends because each possible selected incident tuple of the removed element occurs in a Q cover.
* 4 rainbow incoming: add one tuple with all four ports, enforces common bit. 4 outgoing: use Q with one tuple removed; attach the four element stubs to the four outgoing tuple stubs of matching colors. 13 new vertices. Both common-bit words extend because the removed tuple is selected in one Q cover and unselected in others.
For Q caps remove the node from a planar embedding and use the resulting disk. For three monochrome ports choose the bijection to match cyclic order (all permutations of 3 are rotations/reflections). For rainbow four choose a coordinate permutation of Q and the corresponding deleted tuple to place each colored port in the required cyclic order; the deleted tuple and private 0/1 names need not be fixed. Single-node and single-edge caps have any required order. Thus gluing preserves the given source embedding up to harmless local choices. Recheck planarity and degree in implementation. All tuple degrees/color incidence and element degrees restored, and equality 3|E_c|=|T| then makes part sizes equal. No-three-overlap lemma guarantees distinct tuple signatures. If an input shore has guards, keep every internal tuple unary pin; imposed boundary words pin the tuple incident to each wire (native or cap); repeated port tuple identities must agree. Preserve original IDs and cap IDs separately.
Both directions: any solution of capped shore restricts to a valid local boundary assignment; any local satisfying assignment under an envelope word extends to the cap by the explicitly supported Q cover or trivial cap. Therefore conditional feasibility on each word is exactly the local relation. This is an actual-source adapter, unlike arbitrary signed Ising stars; no new source hardness assumption.
The other two four-wire types are not handled by these caps. Two independent opposite pairs in alternating cyclic order may not be joined by two direct planar wires. One-color 2+2 may require non-bijunctive relation. No claim every 4-cut compresses.

## 5. A fixed polynomial aggregate recurrence
Let M=number of incidence vertices, a<=b shore sizes, C=13 max cap size. Both capped instances have at most a+C,b+C vertices. For a>=52=4C, at most three smaller-side calls and one larger-side call give
  3(a+C)^3 + (b+C)^3 <= (a+b)^3-1.
Proof: put x=a/(a+b) in (0,1/2], C<=a/4. Divide by (a+b)^3, bound by f(x)=3(5x/4)^3+(1-3x/4)^3. Convexity on [0,1/2], f(0)=1, f(1/2)=4(5/8)^3=125/128<1; strict inequality for positive x, then integer decrement. For a<52, enumerate smaller local tuple bits under each word (fixed absolute constant), directly validate every internal element; retain actual local witnesses. Replace only if larger capped side is strictly smaller than parent, i.e. a>actual cap vertex count on B. Then (b+C_actual)^3<=M^3-1. Otherwise ignore that candidate. This is a genuinely charged proof of total recursive node count O(M_initial^3), not a statement of universal coverage. The finite constant enumeration may be impractical but is polynomial in encoded length.

## 6. Reproduce PS05 without conflating source adapters
For zero-field signed Ising energy on an actual disk, PS05's two-replica switching uses alternating ratio signs on four cyclic ports. Two opposite same-ratio connections cannot coexist as vertex-disjoint paths in the disk. Swapping one disagreement component preserves total pair energy and flips a single relative boundary bit. The even Walsh coefficients A=J13,B=J24,q=quartic obey 2q=|A+B|-|A-B|. A star with opposite magnitudes a=|A|+h,b=|B|+h,h=min(|A|,|B|), gauge signs on third/fourth spokes, plus rim correction reproduces the whole min table. Executed 160 independent signed 3x3 grid tables, 70 nonzero quartic, every row and identity verified. A homogenized source ternary occupancy energy (a+s1+s2+s3)^2 is a K4 with A=B=2,q=0, violates this disk identity; a planar abstract K4 is not four-cofacial. Therefore PS05 is not automatically a P4DM native cap theorem. Section 3 uses actual exact-cover support and integer color conservation instead.
Native two-model switching: for any two actual local covers with consistent boundary words, keep changed tuples; at an internal element either no change or exactly two changed incidences (one 0->1, one 1->0, including boundary). Connect these into a difference graph (external incidences terminate as ports). Switching a connected component preserves exact-one, since the two changed incidences at every internal element are switched together. Within each component signed changes of active port occupancy per color equal the change in selected internal tuple count: proof by subtracting the same color count restricted to changed nodes and affected rows. For rainbow 4 seam with both words, all four changed ports must lie in one component (each nonzero flux needs all colors). For two-color pair seam with both bits changed, components changing a given color must include both opposite-direction ports (absent color -> zero change count); either a component carries both pairs or there are two separate paths joining their own pairs, then interlaced order forbids the latter. For noninterlaced pairs, if actual difference components are separate, both intermediate masks are attainable by switching independently. This is an exact conditional exchange-or-coupling statement, NOT a target-free method for acquiring two local covers or guarantee of pair independence. Preserve shared hub coupling.
