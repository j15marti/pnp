## 2. Exact coset seam lemma (refines P3ES04)
Input explicit binary column list H, nonnegative binary-encoded integral weights, target t. Check t in span(H), otherwise exact infeasible. Partition into disjoint L,R. Let U=span(H_L), W=span(H_R), V=U intersect W, k=dim V. Take any parity solution of Hx=t using Gaussian elimination (NOT target cover); z0=H_L x_L. The exactly relevant set of left syndromes is Z=U intersect (t+W)=z0+V. Every z in Z is attainable by some left word and extendible to a global parity word. Obtain V by Gaussian elimination, enumerate at most 2^k vectors. For each nonzero z in Z recursively acquire the minimum f(z) of nonnegative left cost at syndrome z, and actual minimizing left word. f(0)=0 so do not add that column. Replace L by virtual z of weight f(z), keep R and target t. This uses q<=2^k virtual columns, even if t not in W. P3ES04's homogeneous target-aware intersection U intersect span(H_R,t) is also valid, with 2^k-1 columns for its rank k; using the affine coset rather than its enlarged linear span removes one dimension in nonzero-offset cases.
Proof of both optimum inequalities: any feasible original word has left syndrome in Z, can replace its left restriction by one virtual column or empty if zero, cost no greater. Any contracted feasible word selects some virtual columns; XOR their actual left words (NOT union, not independent marginal values), keep unchanged right selection. Syndrome preserved, and cancellation can only decrease nonnegative cost. Thus original optimum <= contracted optimum <= original optimum. At optimum lift has equality. This works if several virtual columns are used; no need to impose onehot artificially. Each virtual column stores a bitset over ROOT event IDs; XOR maps compose. Individual stored cost can overestimate the actual root weight of its lifted bitset, but final root optimum cannot improve under a valid lift by the two inequalities. No preservation claim for arbitrary nonoptimal matching supports. Independent factors can be optimized separately when column spans disjoint.
