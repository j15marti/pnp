## 2. Graphic parity-quotient theorem (P4SW03A)
For an explicit binary matrix H, first test b in its column span. Choose a column basis B, rank r. Compute coordinates of every column and b in B by one deterministic Gaussian elimination. Let the resulting standard form be M and target t. The binary column matroid is graphic iff there is a tree with edges indexed by B such that every nonbasis fundamental support is the edge set of a tree path (zero support can be a loop). This is exactly the graph-realization problem of Bixby & Wagner (1988), a deterministic polynomial constructive algorithm for an explicit 0-1 path incidence matrix. Independently verify its output: for each column, XOR the full two-endpoint incidence vectors of its basis tree edges and check equality with the proposed graph edge incidence vector. Tree incidence columns independent, so this is an injective map L from GF2^r to even vertex syndromes. Then H u=b iff M u=t iff incidence(G)u=L t. Let T be vertices where L t is odd. No planarity requirement for G. Parallel edges retain original event IDs, loops of nonnegative weight can be omitted (set their bits 0).
Minimizing nonnegative edge weights over edge subsets of odd vertex set T is minimum T-join. Decompose any feasible join into terminal-pair paths and cycles; dropping cycles cannot increase weight, distances lower-bound path costs, so shortest-path perfect matching of terminals costs at most optimum. Conversely choose paths for an optimum matching and XOR their indexed edge sets; odd endpoints exactly T, nonnegative costs ensure weight no larger than matching cost. In disconnected components check even terminal count, solve separately. Hence exact optimum, witness and all lifts in fixed polynomial time. All weights bounded by original tuple count. This theorem includes general graphs with high rank, many shared ports, arbitrary signed phase offsets absorbed in b and weights by SW02; no simultaneous independent projection assumption. Geelen-Gerards recognition below is basis invariant; Bixby-Wagner acquisition is a theorem invoked, not a full algorithm implemented in our audit. Even graph planarity is unnecessary; PS05 cyclic disk switching concerns a different spin-energy representation and is not imported as a source adapter.
