## A. Exact discovery for graphic observation matroids

Rows v_i of D are elements of a represented ternary matroid M; zero rows are loops, parallel rows correspond to nonzero proportional forms. Let B be any independent row basis. In B-coordinate representation M has matrix [I|K] (transpose rows into columns). Replacing each nonzero K entry by 1 gives a binary shadow. If M is graphic, its actual B is a spanning forest of any graph realizing M; each nonbasis column has precisely the support of the tree path between its endpoints (its unique fundamental circuit minus itself). Therefore binary shadow K is a graph-realization instance. Bixby--Wagner 1988 constructs a tree for those path sets, or rejects, in polynomial time. It can use a common vertex for separate graphic components without altering the cycle matroid. Add an indexed edge per nonbasis column along the path endpoints, use a loop for empty path. Need not preserve original incidence embedding on this auxiliary graph; original source graph and IDs unchanged.

Signed verification is essential: a binary-shadow graph is not alone proof of ternary graphicness. Orient all realized edges arbitrarily and form the normalized oriented-incidence representation [I|K'] with original B columns. Each nonzero entry is +/-1, same support. Solve for row and column multipliers +/-1 in K_ij = r_i K'_ij c_j by BFS on bipartite nonzero-support graph (equivalent to binary equations on signs). If no solution, reject this graphic lane, not source NO. If success, invertible row scaling and nonzero column scaling (also rescale basis columns) gives a representation of exactly M, so all fundamental circuits match.
