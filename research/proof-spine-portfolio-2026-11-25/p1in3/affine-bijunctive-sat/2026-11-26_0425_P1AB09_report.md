## L4 PROVED: Nonliteral pair-parity guard cannot improve local bad rank2 table admission
A nonconstant linear GF2 form on four live weight-two bits is equivalent, modulo their total parity zero, to a singleton or one of three pair parities. The pair parity zero fiber has the two complementary same-side pairs; if both present this fiber is nonmatroid (two disjoint edges with no exchange). If at most one present, the odd fiber is a bipartite allowed-pair graph across the two port pairs. If it is matroid, it must be complete bipartite on active vertices (or empty). Adding at most one same-side pair keeps matroid: if both endpoints of that same-side pair were active, split their parallel class into two singleton classes; if only one active, put the other endpoint in the opposite-side parallel class; if neither active there were no cross edges and the new table is a single base. If no same-side pair, original is the odd fiber. Therefore if BOTH parity fibers are matroid, the original table is matroid. No single nonliteral pair parity can repair a bad table; all singleton guards do. Enumeration of all 63 nonempty rank-two subsets finds exactly27 bad, zero pair-guard rescues. This is a local, single-linear-guard representational obstruction, not a lower bound on multiple guards or arbitrary algorithms. It justifies four-way literal search rather than seven-way search in L3.
