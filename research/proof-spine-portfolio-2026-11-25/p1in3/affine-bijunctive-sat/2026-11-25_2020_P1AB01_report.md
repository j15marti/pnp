## A. Exact weighted parity and connected repair decomposition
n variables, n clauses by regularity. A is original binary incidence; source solutions exactly As=1 mod2 and all pairwise exclusions. Every parity word has each clause occupancy 1 or3. Let D(s) count occupancy3; counting variable incidences gives 3|s|=n+2D(s). Exact SAT iff minimum Hamming weight on affine chart is n/3; n not divisible by3 rejects. All-one word is parity feasible at root. Any sound additional affine guard/deduction may restrict chart; all guarded source models must be retained. Weight-target witness is actual original model. Compilation O(n log(n+2)) indexed sparse bits, dense matrix polynomial, no reduction to another source needed.
For any two parity words s,t, u=s xor t belongs to ker A. Each original clause meets supp(u) in 0 or2 variables. Build graph G_u on supported variable IDs with one edge (original clause ID) for each double incidence. Every supported variable has degree3, and G_u is planar cubic multigraph: delete unsupported variables and unused clauses in original embedding, suppress each remaining degree2 clause; no loops since clauses have distinct variables, parallel edges legal. Component discovery and embedding restriction polynomial. Any kernel word v supported in u must take equal bits on both endpoints of each edge; conversely union of components is a kernel word. Therefore component supports are precisely the inclusion-minimal nonzero kernel supports contained in u (column-matroid circuits). This proves connected iff minimal for every nonzero kernel word, not just random examples.
Distinct components affect disjoint clause IDs. For a component c let gain g_s(c)=D(s)-D(s xor c). Then gains add exactly to D(s)-D(t); g_s(c) multiple3 by identity 2g=3(|s|-|s xor c|). Equivalently minimize additive signed weight sum_{i in c}(1-2s_i). If a better parity word exists there is an improving connected circuit. Conversely any negative-cost circuit improves. Hence if a deterministic uniform polytime routine finds an improving circuit or certifies no improving circuit, repeated improvements (<=n/3) reach global minimum, decide source and verify witness. No target-supplied word in this conditional algorithm. Initial Gaussian chart and forced closure paid; on a pin-restricted chart components individually respect fixed coordinates. Arbitrary additional affine equations R s=b require guard grouping: assign syndrome R c to each component. The full set sums zero for a difference of guarded words. Partition by extracting inclusion-minimal zero-sum subsets; each has at most rank(R)+1 columns by linear dependence (including singleton zero). Such partition is polynomial given the actual difference, via rank/dependence extraction and iteration. Each group preserves guards and gains add. Thus guarded improvement exists as a group of <=g+1 components for guard rank g; discovery without target remains OPEN. This does not assert each ungrouped circuit respects arbitrary affine guards.
Special three-defect target: if D(s)=3 and a source model exists, without coupled guards a single improving circuit repairs all three defects and creates no new ones, because gain>=3 and D cannot be negative. For a good clause with selected p and other q,r, flip variables satisfy u_p xor u_q xor u_r=0 and implications u_q=>u_p,u_r=>u_p, exactly patterns 000,110,101 in p,q,r order. At an old defect choose exactly two flipped variables; for three defects only 3^3 assignments of the local pair patterns, then Gaussian + implication closure with actual guards. This is exact polynomial source construction of a focused residual, NOT a polynomial compatibility solver. No full near-defect implementation in this run. ## B. FALSIFIED universal polynomial explicit circuit enumeration
For k>=1 construct k copies of hexagonal prism incidence graph, indexed local variables x_0..x_5 and clauses c_i=(x_{i-1},x_i,x_{i+1}) cyclic. Graph is C6 Cartesian K2 with variable/clauses alternating by layer and position. Join consecutive blocks by deleting edge x3-c3 in left, x0-c0 in right, replacing by cross edges x3(left)-c0(right), x0(right)-c3(left). Each block has at most two disjoint cut edges. Preserve bipartition, cubic degree and simplicity; planar 2-edge splice by taking a face containing each edge as exterior, or verify rotation: top cyclic neighbor order [prev,next,rung], bottom [next,prev,rung], replace old neighbors in place. Connected planar source n=6k. Clause IDs retained, no parallel incidence edges.
Choose each block's exact periodic phase p in {1,2}, select x_i iff i congruent p mod3. All crossing variables x0,x3 then zero, so independently chosen phases give 2^k distinct source models. Uniform phase0 also satisfies all cross constraints (both ends have bit1). Uniform phases0,1,2 are source models whose GF2 sum equals the all-one word. Every variable attains both bits across these models. Thus no sound unconditional coordinate pin exists; all-one remains in the affine hull and is retained by every sound affine deduction in original coordinates, as are all model words. For each of 2^k models t, u=1 xor t has 4k support variables, two out of each residue triple. Within a block, its G_u is a 4-cycle with a doubled pair of opposite edges. Replacing x0-c0 or x3-c3 removes only one member of each doubled pair. Remaining block graph still connected. Cross-splice edges join consecutive supported blocks since x0,x3 both supported and affected clause has one additional supported internal variable. Thus each of these 2^k u is one original column-matroid circuit. All improve D from n to0, survive coordinate closure and sound affine restrictions retaining all models (differences satisfy homogeneous guard). So a solver explicitly listing every minimal improving circuit cannot have polynomial total listing cost, even on this connected planar cubic source family. N=O(k log(k+2)) explicit bits, exponential in k is superpolynomial in N. This is a representation-specific obstruction, NOT a lower bound for finding one circuit or unrestricted decision. Indeed these instances are easy by the next exact cut decomposition. No all-input bound on circuit size either (4k for this set, not a claim that no smaller improving circuit exists).
