Lemma U: for g>=r, this explicit r-slot system presents the uniform matroid U_(r,g) iff for every nonempty subset S of slots,
   |N(S)| >= g-r+|S|.
Proof: any r-element owner set B loses at most g-r of N(S), so Hall is sufficient. Conversely if inequality fails, choose B of size r minimizing intersection with N(S). Its intersection size is max(0,|N(S)|-(g-r))<|S|; Hall fails. All smaller sets extend to r-sets. If g<r no full-rank chart; decline. Uniformity criterion is classical (Fink/Olarte Example3.9 and Example6.5, dragon marriage special case); the following implementation is direct.

Minimum cut value is r+min_(S containing q)(|N(S)|-|S|). All r forced mincuts >=g iff every required inequality.
