## 2. Source circuit and planar adapter (PROVED)
Start with arbitrary Boolean Circuit SAT using NAND gates (known NP-complete by standard basis compilation from 3SAT). Each gate has distinct input and output variable IDs. Repeated input NAND(x,x) can be realized using a fresh free t, u=NAND(x,t), v=NAND(x,u), w=NAND(u,v)=x, then NAND(x,w); all inputs distinct, regardless of t. Circuit evaluation with all free inputs zero computes a baseline, not a satisfying input.

For clarity an explicit planarization suffices, independent of any unverified planar-Circuit-SAT promise. Draw the bipartite signal/gate incidence graph using vertex disks below a horizontal line, one distinct integer x-track for each incidence port, and one distinct positive integer y-level per wire. Wire goes up its first track, across its level, down second track. Vertex port tracks contiguous, connections below line noncrossing. Only transverse crossings between a horizontal and a vertical segment of different wires, at most O(s^2) crossings for s wires, no triple crossings. At the signal end of every wire insert the three-NAND copy gadget above (fresh t,u,v,w), so first segment variables on different wires are distinct; all subsequent segment variables fresh. This copy circuit has input/output cofacial: can draw the two gates producing u,v adjacent to x, then output gate attached to u,v. Its interior is connected. Each crossing is replaced by a four-terminal crossover: incoming adjacent terminals a,b; t=a XOR b; opposite outputs a'=t XOR b=a, b'=t XOR a=b. Its incidence graph of three XOR constraints is planar in cyclic terminal order (a,b,a',b'): place common t in center, input XOR between a,b, remaining between b,a' and b',a. Each XOR has a three-terminal cofacial NAND implementation d=NAND(a,b), e=NAND(a,d), f=NAND(b,d), c=NAND(e,f): four gates arranged as diamond, a,b,c outer. Finite boundary-cycle planarity checks were executed for the XOR and three-XOR crossing graph; no claim that arbitrary NAND expansion preserves planarity without the disk argument. Every crossing forces equality on the two corresponding wire segments; converse assign each segment the original signal and evaluate private gates. Any inter-wire cyclic dependency in the planarized constraint network is harmless because these relations, not DAG evaluation of the planarized network, give both directions. Original gate terminals connect to last segment. All new NAND triples distinct. Output variable s remains the original circuit signal; attach a fresh t and output o=s AND t in a face incident to s. For baseline t=0 so o=0 regardless of source answer. Add fresh q and two binary clauses (o OR q),(o OR NOT q). Exactly one of these is violated under any q when o=0; satisfying both is equivalent to o=1. Thus full plane constraint network satisfiable iff original circuit satisfiable. Baseline set q=0 and evaluate all original gates/copies/crossing gadgets, no source SAT query.

Translate each NAND z=NAND(x,y) into clauses (NOT x OR NOT y OR NOT z),(x OR z),(y OR z). AND o=s AND t uses (NOT s OR NOT t OR o),(s OR NOT o),(t OR NOT o). Each ternary clause is a cofacial three-port central factor; its two accompanying binary clauses can lie along two adjacent boundary arcs. For any signed ternary OR(L1,L2,L3), replace by fresh private selector bits a1,a2,a3 with exactly one true and clauses (NOT ai OR Li) for i=1..3. This is a plane tree-shaped macro with three external ports; any true literal admits selector, conversely selector forces a true literal. All selectors are disjoint triples; binary factors touch at most one selector. Choose baseline one-hot selector on any true literal, which exists at every gate clause. All binary clauses satisfied except one output assertion. No hidden model or oracle.

## 4. Stagnation under actual ordinary closure (PROVED)
Strict positive fractional witness independent of original SAT. Assign every original and new NAND signal variable marginal P(bit=1)=3/5, final fresh t also 3/5, o=11/20, q=1/2, each selector=1/3. For binary factor, let d_i be marginal probability of its bad phase at endpoint i. All d_i>0 and d1+d2<1: NAND binary positive clauses sum bad=4/5; AND binary clauses sum bad=2/5+11/20=19/20; output assertions sum bad=9/20+1/2=19/20; selector implication sum bad=1/3+(1-P(L true))<1 since literal marginal is at least2/5. Give allowed words (bad,safe),(safe,bad),(safe,safe) probabilities d1,d2,1-d1-d2. Give ternary one-hot words probability 1/3 each. Within each feasible local mode word distribute uniformly over all local matchings (constant size). Each X occupancy exactly1, each Y position exactly1, each Z occupancy exactly1 in expectation because the two possible incoming projected pairs have probabilities 1-p_v,p_v from adjacent positions of the same variable. Every local tuple has positive mass and is avoidable, hence strict 0<u_t<1. This is a rational certificate with fixed bounded denominators (or constant-size local weights), not a source integer solution. All three pairwise projections have doubly stochastic fractional edge matrix with positive mass on every projected pair; Birkhoff/ordinary bipartite matching implies every such pair belongs to a perfect matching. Each original element has degree>=2 and no singleton/empty; all-projection support deletion stagnant. Even a basic LP unary forcing test cannot fix an original tuple.

GF2 unary stagnation requires separate proof, not inference from fractional feasibility. In mode coordinates each binary three-word relation has full affine hull over GF2; exactly-one selector relation has affine hull a1+a2+a3=1. For any original tuple t, take a local actual word and matching with desired value t=0 or1 (both exist locally). Extend its at most three pinned mode bits to all modes satisfying every disjoint selector parity: a ternary local word is already one-hot; a binary pins at most one selector. Signal bits otherwise arbitrary. For each other factor, chosen local mode vector lies in its affine hull; choose GF2 affine combination of actual local feasible cover vectors realizing those mode bits (sum coefficients1). Such a combination has X and Y parity occupancy1, and its selected-pair parity at each position is [1+bit,bit] because each local matching obeys that deterministic mode indicator, an affine function. Across two adjacent positions at each Z, the two incoming pair parities sum to1 due to common mode bit. Sum all disjoint factor tuple vectors, retaining the chosen actual local vector at target factor. This satisfies the full source GF2 occupancy system and has target tuple value as required. Thus no original tuple has fixed value in GF2 system, both consistency and unary forcing remain stagnant. Applies to both YES and NO cases, including strict-interior fractional witness. No assertion of semantic support in UNSAT cases or of closure with arbitrary certified stronger deductions (e.g. failed-literal, combined GF2 and nonlinear clauses, larger proof systems). Output assertion can be recognized by stronger chart closure; our bound does not claim defect remains1 after such a step. Not prime against the entire portfolio.
