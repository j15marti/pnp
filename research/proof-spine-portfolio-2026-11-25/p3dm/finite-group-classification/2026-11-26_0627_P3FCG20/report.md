## 1. Exact Hall-defect accounting (PROVED)
Acquire an arbitrary simple projected YZ perfect matching B. Let n=|X|=|B| and delta=n-r(B), r(B) maximum actual owner-to-selected-pair matching cardinality. A full native cover exists with this projection iff delta=0. Build ALL-pair/X incidence graph H (not just selected pairs), split into connected blocks j, with g_j actual X owners, s_j selected pairs, and maximum matching cardinality r_j on those selected pairs. Partitions of pairs and owners imply sum s_j=sum g_j=n; rank adds exactly. Hence
delta=sum_j(s_j-r_j)=sum_j(g_j-r_j).
A block is bad if r_j<s_j or r_j<g_j. Each bad block contributes at least one to the sum of these two nonnegative deficits, so b<=2 delta. In the special case s_j=g_j for all j, b<=delta. Important: a block with too few selected pairs may have zero slot deficiency and still be bad. Do not count only unmatched slots and silently omit owner shortages.

## 3. Native linear repair radius obstruction (PROVED)
For integer l>=2 take two l-by-l grids of Boolean mode vertices A,B, right/down implications within each grid, root at (0,0). One cross edge between roots has clause a_root OR b_root. The remaining l-1 cross edges between matching boundary vertices (i,0) are neutral: all four words allowed. Thus interaction graph is a 2l-by-l planar rectangular grid (after reflecting one half), not a bridge-joined pair. Every satisfying mode assignment sets at least one root true; directed paths force all l^2 vertices of that half true. Conversely set one half all 1 and other all 0 to satisfy. All-zero mode assignment violates exactly one clause; every feasible chart differs from it on at least l^2 modes, and this lower bound is attained. No strict repair with fewer than l^2 cycles. This is a lower bound on one-step symmetric-difference cycle count, NOT on number of iterations permitting plateaus or on computational work of other solvers.

Compile to explicit native source using CC16's actual per-edge Hall construction, and CPS17's both-safe neutral block. Give every mode vertex v a separate YZ even cycle on d=2 deg(v) Y and Z labels with pairs (Y_i,Z_i) and (Y_i,Z_(i+1 mod d)); exactly two simple projected PMs. One consecutive two-position group per incident edge, ordered by acquired plane rotation. For edge e endpoints u,v use shared actual X labels a_e,b_e and one private owner p_(v,e) for each endpoint. For an endpoint's forbidden bit, first position has {a_e}, second {p}; for the other (safe) bit first {a_e,p}, second {b_e,p}. For neutral edges BOTH bits safe. Opposite endpoint reverses first/second order in its group. Actual indexed tuples are one per owner in each listed domain. For implication u->v forbidden word (1,0), use respective bad bits 1 and 0; for root OR use bad bits 0,0. Exact Hall graph blocks are edges of interaction graph, four selected pairs and four X labels for every mode word. Both bad forces both endpoints demand shared a, rank exactly 3 (choose a at one, both private p), otherwise rank 4 (allocate a,b across endpoints and use private p). Neutral always rank4. Thus total native Hall deficiency equals number of violated nonneutral clauses for every projected PM, not merely lower bound. In particular lexicographic diagonal chart delta=1 and every strictly improving projected PM must change >=l^2 elementary cycles. The projected components are disjoint cycles; symmetric difference decomposes into exactly the changed component cycles, so no alternate single longer alternating cycle can bypass this obstruction.

Geometry: draw each YZ cycle in vertex disk, each pair represented by one or two length-two tuple paths. In two-path pair shared owner attaches exterior, private owner interior; private star in the consecutive two-position sector. The shared a ports and b ports occupy separate contiguous clusters along each corridor, reverse group order at opposite endpoint, draw two disjoint strips with respective shared stars. This is CC16/CPS17 adapter, but now both ends can be original grid vertices; each edge independently chooses which endpoint is reversed. Each group's exterior ordering is reversed relative to the other end, regardless of other groups. No crossing at disk or corridor. Planarity and connectedness independently tested for all scales. Count edges e=4l(l-1)+l; of these l-1 neutral, rest 4l(l-1)+1 nonneutral. Each edge has four distinct X owners and contributes four Y, four Z labels across endpoints. Tuples m=12[4l(l-1)+1]+16(l-1)=48l^2-32l-4, so radius l^2=Theta(m); bits N=O(m log m) for compact labels. All tuple IDs distinct, no narrower degree promise claimed.

Full unary semantic support/avoidance: each mode bit can be 0 or 1 by choosing other half or its own half all true. For any implication edge, the three permitted words 00,01,11 extend: choose other half all true for 00; for 01 choose other half true and upward-closed reachable set from target in current directed acyclic grid (source not reachable from target); for 11 choose own half true. Root OR has each permitted word via whole-half assignments. Each nonneutral edge therefore permits every locally allowed word globally, and all its actual tuple occurrences appear in some locally feasible allocation (check one-bad/one-safe uses a from bad, b from safe; both-safe allows both allocations). Neutral cross edge's 00 word is globally impossible, but for each endpoint bit one can choose a global mode word with that bit and then either shared allocation independently because both endpoints always safe. Hence every tuple supported; opposite mode avoids it. No semantic unary forced deletion, let alone native closure. We do not claim all local words globally extend on neutral blocks or that the family is prime against the entire portfolio. Both BMH and DMR solve; existence of wide interface does not imply hardness. DMR repairs in three full-word branches (root OR) with Horn propagation, matching the radius lower bound.
