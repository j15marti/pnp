## 1. Realized-signature replacement (RSR, PROVED)
Fix integer k independent of encoded input length N. A connected planar native incidence graph has a bond of 1<=j<=k edges separating two connected shores L,R. Each cut edge has an ordered port label, one color, and direction (internal tuple or internal owner). A bond has a dual circuit, hence a disk interface: a regular neighborhood of L can be enlarged by filling holes not containing the connected R; the separating Jordan curve crosses precisely the bond edges. Cyclic order is acquired from an embedding via dual traversal; repeated attachment vertices are distinguished by incidence darts. An open native disk graph has owner vertices of the three colors and tuple vertices with exactly one incidence of each color including boundary stubs. Boundary port labels and cyclic order fixed; each port Boolean bit is the selection of its incident tuple, wherever it originates. Its exact signature is a subset of {0,1}^j: each word is admitted iff there exists a subset of its tuple vertices with outgoing bit pins and owner occupancy one including incoming bits. No affine or marginal approximation.

There are finitely many typed signatures for j<=k: at most sum_j 6^j*2^(2^j) with labels indexed in cyclic order. Every signature realized by an input shore is realized by some finite open disk graph of this same type (at least that shore). For every realized type/signature choose the minimum vertex count; the maximum B_k of those minima over the finite set is finite. No claim of an explicit computable growth bound in k, no table of nonrealizable signatures, no nonuniform advice.

Uniform deterministic representative acquisition: GIVEN the exact nonempty signature of an actual shore, enumerate all open native graphs with fresh canonical labels by increasing vertex count, all finite assignments of internal edges and port incidences satisfying tuple color degree, and all rotation systems with specified cyclic port order. Check disk embeddability by adding a virtual vertex incident to all stubs (use subdivision marker nodes to distinguish parallel edges) and enumerate rotations with the prescribed apex order, checking connected planar genus-zero combinatorial map; each connected patch is included, and a reflected embedding is allowed. For each admissible graph compute its signature by exhaustive enumeration of its own tuple subsets; stop at first exact match. This is one explicit algorithm, not a chosen advice table. It halts after at most the finite total enumeration cost through B_k for EVERY realized signature at fixed k, regardless of N; equivalently cap the search at original shore size since that shore itself is an admissible graph. The cap is only a safeguard: for exact realizable signature, the first success is always at size <=B_k. Do not run unbounded search on an arbitrary conjectured or overapproximate signature. No uniform polynomial in k claim. This is an application of finite-index/protrusion replacement reasoning, not a new general meta-theorem.

Replace L by that patch P, gluing labelled stubs to R in the same cyclic order (use appropriate reflected orientation). Exact owner occupancy at the seam is enforced by the very same Boolean bit in each paired stub. Forward: restrict any original cover to R and use some patch witness for its admitted word. Reverse: decode word from patched cover, retain its R tuples, use one stored actual L witness for that word. All original rows and literal guards hold. Every admitted word shared, no spurious compatibility. This preserves decision and exact boundary support, NOT the number of covers or every original interior solution. New guards on removed original tuples require recomputing/restricting the original table, not guessing from a single witness. Indexed duplicate triples can occur after gluing; retain identities internally, or deduplicate deterministically with representative provenance for decision after all current literal pins. Do not claim exact count or future ID support after deduplication. Planarity by disk gluing; verify actual embedding before invoking topology-sensitive routines.

Color balance: for any admitted common word w, let n_c denote internal owner counts and s selected internal tuples. Integer conservation s=n_c+sum_{ports color c}epsilon_i w_i with epsilon=+1 for tuple inside and -1 for owner inside. Same w, same port types imply n_c(P)-n_c(L) is constant across all three colors, namely s(P)-s(L). Thus replacing in a balanced source preserves equal part sizes even before knowing a compatible R witness. Empty signature is certified NO. If |L|>B_k, the patch is necessarily strictly smaller; otherwise replace only when an actual strict size decrease is verified.

## 2. Paid recursive response acquisition (PRRA, PROVED)
For a fixed cap k, choose ONE acquired bond deterministically (enumerate O(E^k) edge subsets, BFS both shores and verify, optionally maximize smaller shore). No recursive backtracking among candidates. Let s be total owner+tuple vertices, a=|L|<=s/2 the smaller shore, q<=2^k the number of words. For each word, construct an ordinary closed native local instance of size <=a: selected outgoing tuples pin their own ID and cover only internal rows, zero outgoing pins remove their tuples, incoming bits deduct owner targets, reject conflicting repeated pins/negative or duplicate occupancy, remove zero/covered owners and competing tuples. All remaining tuples have all three native incidences; unequal color counts reject. Thus an actual recursive solve under the same algorithm, not a free oracle, supplies YES/witness or NO for each word. Any UNKNOWN causes UNKNOWN, never an unsupported negative entry. After complete table acquisition use RSR. If patch has c0<a vertices, make ONE additional child of size <=s-a+c0, then lift by word and original-ID maps. If not strictly smaller, decline. Apply certified unconditional closure on each call and after patch. Disconnected factors compose independently; fixed polynomial terminal attempts allowed at each node, but no unbounded portfolio backtracking.

Aggregate bound despite q recursive small-shore calls: B=B_k is a finite constant, delta=1/(B+1), c0<=B and a>c0 imply a-c0>=delta*a. Put r=a/s<=1/2 and choose a fixed integer d>=k+3+ceil(log2(B+1)). Then q*r^(d-1)<=delta/4. Because (1-delta*r)^d<=1-delta*r, the sum of child potentials is at most s^d*(q*r^d+(1-delta*r)^d)<=s^d*(1-3*delta*r/4)<=s^d-1 for integer s>=2,a>=1. In a declined or empty patch case only the small children are charged, even smaller. For split into two or more positive independent components, sum s_i^d<=s^d-1 for d>=2. This bounds total nodes by s_root^d, even when local response calls recursively invoke the same solver and cuts are very unbalanced. B and d are proof constants, not needed by the enumerator or cut selector. Per-node work polynomial for fixed k: native closure, bond enumeration, dual rotation, q guard construction, realized-signature enumerator constant, witness verification, all failed terminal attempts under fixed caps. All retained labels can be canonical counters of O(log(s_root^d+N)) bits, original source bytes retained. Store response tables and witnesses and reverse patch maps for each node, no exponential expansion (at most polynomial nodes and polynomial-size selection sets). Peak space <= total bit work plus input; cumulative memory <= (T+1)S on same execution. Deterministic polynomial for the admitted class, including UNKNOWN termination; no universal guarantee selected bonds or terminals suffice. This closes the prior conditional 'paid local response' gap for recursively admitted constant bonds. The full RSR enumerator and recursive PRRA are theorem-level, not executed.

## 3. Direct practical support pruning (WUP, PROVED, executed)

If an outgoing tuple is omitted, its boundary bit is forced zero; equivalently remove that incidence globally, with matching zero contribution on the other side. Every old admitted word still has its stored witness, and deleting tuples cannot create a new local word. Hence exact boundary support preserved. Simultaneous pruning in disjoint regions preserves global decision, since the shared exact word constraints still agree. If any region's response empty, reject. A strict deletion is a productive native subgraph reduction; reclose. Preserves original rotation by taking a subgraph. No synthetic IDs or count preservation claim. For arbitrary later original literal guards recompute unless proved hereditary. Distinguish this existential decision reduction from unconditional forced-variable inference: a deleted tuple may originally be selected in another valid cover.
