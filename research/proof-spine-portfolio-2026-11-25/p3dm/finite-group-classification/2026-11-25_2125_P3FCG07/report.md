## 2. Lemma RB-Hall: exact contextual block certificate
Fix a nonempty block Q of b slots and its allocated partner set D=f(Q). Assume J has a perfect matching. For every S subset D assign weight
  w_S(a,z)=1 iff a in Q and N(a,z) intersection D is a subset of S,
and 0 otherwise. Compute the maximum W_S of the total weight over perfect matchings of J (ordinary integer weighted bipartite matching).
CLAIM: every perfect matching of J admits a partner lift inside this block iff W_S <= |S| for every S subset D.
PROOF: For fixed g, Hall's theorem is equivalent to saying, for every S subset D, at most |S| vertices a in Q have their whole K_Q(g) neighborhood contained in S. If this inequality fails, those vertices violate Hall. Conversely any Hall-violating group of slots has neighborhood S and is counted in the inequality. The number counted is exactly sum_a w_S(a,g(a)); maximizing over J perfect matchings establishes both directions, including vacuous/no-neighbor S=empty. No target source assignment is used. End proof.
Consequently a proposed partition whose every block passes this check allows every global projected label matching to lift, by disjoint local partner matchings. This is stronger than FCG06 singleton common-scaffold, while still not an unrestricted solver. For a polynomially listed collection of candidate blocks with maximum b<=c log_2 N, fixed c, recognition uses at most N^c weighted matching calls per candidate, all weights 0/1. This does NOT establish polynomial acquisition of a complete partition for b>2. If using local injective labels rather than full global J context one obtains local transversal interface; global-context version must retain J, cannot export an unrestricted local matroid by ignoring context. Weighted Hall test is theorem-level; executed implementation uses equivalent direct enumeration of at most two pinned labels per block with ordinary global J completion tests.

## 4. Lemma GP2: certified local failures and exact 2-SAT
Now allow local lift to fail for some label assignments. Suppose the simple label graph J, after allowed-edge support closure, has each connected component either an isolated edge or an even cycle. This is polynomially recognizable; even cycle has exactly two perfect matchings. Assign one Boolean phase variable per cycle, choose a reference perfect matching and use its complementary cycle matching as other state. Every Boolean phase assignment is exactly one perfect matching of J, with no extra label compatibility constraints.

Fix f as above. For each candidate singleton or pair Q, enumerate at most four assignments p of the distinct cycle variables touched by Q. For each p obtain actual labels z(a) for a in Q. If K_Q(p) has a matching, store or recompute a witness. If not, test the FULL original partner graph P with ONLY these labels pinned: restrict neighbors of a in Q to N(a,z(a)), leave every other slot unrestricted. If no perfect matching, this p is globally impossible for a source cover, since that cover would yield a matching of this restricted graph. Record the clause forbidding p (size at most two; empty clause if p is empty). If this full partner relaxation still has a matching, the local failure is not certified; decline this candidate Q. Define singleton/pair admissible when every pattern either has local lift or has globally certified impossibility.

Use same weighted matching cover as RB2 with this new admissibility notion, then conjoin all forbidden-pattern clauses of the acquired disjoint blocks. It is exactly a 2-CNF. Necessity: every source solution yields a phase assignment; none of the forbidden patterns can occur by their global certificate, even if the original solution uses a different allocation of partners. Sufficiency: every satisfying phase assignment yields a global J perfect matching, and every block's pattern has a local partner lift. Union covers all A, B and Z once with actual triples. Thus SCC 2-SAT decides YES or NO, with explicit source witness lift. No enumeration of global phase assignments or simultaneous pairing choices. Failure of cover acquisition or noncycle J is UNKNOWN, not NO. This is the exact GP2 theorem, a mixed matching/Boolean terminal that can reject closure-stable UNSAT sources. It works even when universal-lift RB fails.
