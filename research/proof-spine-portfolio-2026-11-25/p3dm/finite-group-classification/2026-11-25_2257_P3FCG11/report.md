## 2. Implicit meet-closure theorem (PROVED, executed)
Order each finite port domain by an acquired arbitrary total order. For a relation R let H(R) consist of all nonempty finite coordinatewise minima of words of R (empty relation yields empty hull). For lower bounds l, any min of words >=l is >=l; conversely any hull word >=l must be generated by words individually >=l. Thus if R has no word >=l, neither does H(R); otherwise c_R(l)=coordinatewise min of all words r in R with r>=l is exactly the least H(R) word >=l. This does NOT assume that c_R(l) itself belongs to R. Acquire each component's c by allowing unions of partner classes above the given lower bounds, checking PM existence, then testing each slot's candidate class by restricted matching; scan up to its value in an acquired reference matching. External finite tables c computed by filtering and minima. No full matching table enumeration.
Apply all c maps in repeated deterministic sweeps to the shared vector l; each step extensive and monotone on feasible inputs. Every global solution of the meet-hull CSP above the initial bounds remains above the evolving vector, by induction. Failure of any local query proves hull inconsistent. Each successful strict sweep raises some coordinate, at most sum_p(k_p-1) strict sweeps. At fixed point every local restriction is in its hull, so the word is the least global hull solution. For upper-bound pins u, reject if a current lower bound exceeds u; otherwise fixed point <=u is a genuine model of the bounded hull. Thus exact polynomial satisfiability and least-model acquisition for the implicit hull system with any coordinate lower/upper pins. Hence over GF2 the affine hull of indexed PM incidence vectors is exactly B_G x=1 (all vertex incidences odd). Proof: span of PM differences has orthogonal complement the cut space, so it is the cycle space ker B_G; translate by one PM. Apply to each projection component, then linearly project to one-hot type indicators (parities of incident edges in each class).
At each x, the affine hull of allowed type-pair one-hot words is exactly the set of type-coordinate vectors with parity 1 on each side and equal left/right parity within each connected component of the type-pair graph. Indeed this is the image of edge coefficient vectors with total odd parity under its bipartite incidence matrix. Image of incidence over GF2 is even total on each connected component. All classes consist of vertices with identical nonempty neighborhoods, so quotient preserves components of original R_x graph.
