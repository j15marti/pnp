## 2. Forest theorem and rectangle cutset (PROVED)
If H after rectangular deletion is a forest (parallel edges count as cycles), root each tree. Given children messages, restrict each node's unary partner domain at their shared slots to partners compatible with some child-supported partner. For parent slot enumerate each allowed partner and check local PM with that pin, retaining one matching witness. Root needs one PM. Induction: message contains exactly all partner choices extendible to subtree; child subtrees are independent conditional on the selected parent partners. Reverse traversal chooses compatible child witness and reconstructs source triples. A missing root matching proves NO. No full matching state enumeration. Node with arbitrarily many children still only needs polynomial matching calls.

For each nonrectangular R_x acquire a cover by k_x rectangles contained in R_x: group rows with identical neighbor sets or group columns, use smaller count. These are disjoint partitions and require only polynomial scans. No minimum biclique cover assumption. Select a spanning forest of each interaction factor using maximum weight log k_x (Kruskal in decreasing integer k_x, no logarithm arithmetic). For each omitted feedback edge branch on one of its k_x rectangles, imposing its two unary domains. All choices in a rectangle are real triples and any source solution survives one choice. Remaining constraints are tree edges; solve exactly as above. This minimizes product D_i=product k_x over omitted edges among spanning forests for the acquired covers, because total log-weight fixed and maximum spanning forest optimal. Across independent factors work is additive, not multiplicative: sum_i D_i poly(N). Fixed cap max D_i <= N^c yields polynomial terminal; exceeding cap UNKNOWN, not NO. Covers and candidate lanes deterministic; no claim globally minimum rectangle cover.

## 3. Contextual bundled leaf theorem (PROVED)
In H collapse parallel edges only to identify simple leaves, retaining every edge ID. Leaf C with unique neighboring component P shares slots S. Each node has current unary matching domains, including exact restrictions from already eliminated children. Enumerate all parent partner vectors v on S if product d_x <= fixed polynomial cap. Let Q be vectors extendible to P matching under current domains; let L be those v in Q admitting C matching after all S compatibilities imposed. Compute both by ordinary matching, retaining one child matching per v in L. If L empty reject: any original solution would induce v in L. Else D_x=projection of L to slot x. If L=Q intersect product D_x, replace P domains by D_x and remove C and all its incident edges. Necessity obvious; any remaining parent witness belongs to Q and product, hence L and stored child match lifts. Parent future restrictions only shrink Q, so existing exact lift remains valid. Reverse order restores all earlier descendants, using actual parent vector. If equality fails, do not delete C. Single-edge leaves always admit. Retry after productive deletion; at most O(N) successes, O(N^2) candidates. This is stricter than checking independent marginals and stronger than raw cycle-cut enumeration on FCG07 splices. Arbitrarily large local components can be solved with small seam vectors.

Height extension (PROVED theorem-level, NOT implemented): each planar simple projected component has exact face-potential chart (reference PM, integral circulations, anchor face 0, m_e+h_L-h_R in {0,1}). Simple graph obtained by suppressing tuple vertices then deleting parallel representatives, preserving planarity. Any embedding suffices for circulation; no cofacial assumption. Heights O(m), threshold bits O(m^2), difference bounds/pins/deletions explicit 2CNF (Felsner 2004, AGE08). Maintain one 2CNF B_P per factor, initially matching chart and source literal/domain restrictions. A boundary vector pins actual edges (conjunction of 2CNFs). Compute Q,L by 2SAT instead of ordinary matching including previously accepted exact guards; child compatibility restricts allowed partner edges, expressible by forbidding each excluded edge. Obtain full binary hull B' of union over v in L of (B_P AND pins(v)), by checking every unit/binary clause on each satisfiable branch using SCC (AGE08). This hull is necessary, implies B_P because all its clauses are binary. Test every v in Q minus L for satisfiability with B' and pins(v). If none survive, B' is exactly the projection of parent models extendible to the child; replace B_P by B', eliminate C, store child witnesses and reverse lift. Any B' model induces a vector in Q; if it is in L its arbitrary remaining parent matching has the same child lift, because only S is shared. If some bad vector survives, decline this particular binary interface, not source NO. This generalizes contextual rectangles and supports multistate components without explicit matching masks; no universal admission or proof of strict extra empirical coverage for the height extension. Arbitrary extra guards need a local exact adapter or are kept as dependencies, never silently dropped.
