## 1. Conditional matching consensus (known SA lift, new scoped integration)
Define p_t, q_tu=q_ut, q_tt=p_t. For every source element v, sum_{t contains v} p_t=1 and sum_{t contains v} q_tu=p_u for every u. Require 0<=p<=1 and max(0,p_t+p_u-1)<=q_tu<=min(p_t,p_u). Every actual cover supplies a feasible integral point. These are the degree-two Boolean lift of exact-one equations: multiplying by x_u and by 1-x_u and multilinearizing. Thus no assertion of novelty of Sherali-Adams or integrality of this polytope.
For p_u>0, q_tu/p_u satisfies all three projected fractional perfect-matching equations and has coordinate u=1; for p_u<1, (p_t-q_tu)/(1-p_u) does the same with u=0. On each indexed bipartite multigraph these are convex combinations of actual projected perfect matchings by bipartite matching integrality (parallel edges retained). The combinations need not coincide across projections. This is necessary consensus, not joint-support classification.
Use exact rational LP to identify any event of probability zero in all feasible points: unary p_t,1-p_t; pair q_tu,p_t-q_tu,p_u-q_tu,1-p_t-p_u+q_tu. Infeasibility rejects, feasibility alone does not accept. Efficient acquisition of all zero events: maximize sum of currently unobserved nonnegative events, store at least one newly positive event whenever objective positive; when maximum zero, all remaining are forced zero. At most 2m+4*binom(m,2)+1 LP calls; explicit O(m^2) variables, O(m^2+mn) constraints, polynomial nonzeros and bit size. Production polynomial rational LP theorem-level, finite audit uses numerical proposal plus exact rational primal/dual/Farkas check; failed exactification must return UNKNOWN. Sound zero events are native source clauses. In a chart, export a clause as conditional source pin, not blindly as a binary clause on height bits. Rebuild original charts after strict source deletions and run native exact-one/all-three matching/GF2 closure. Conditional deductions retain original guard; no unconditional weak roof pinning. Fixed polynomial caps per lane; any sound pair-event exclusion can be shared by all lanes, at most O(m^2) distinct exclusions; no claim of scheduling-independent canonicalization for arbitrary nonmonotone lane implementations.
Relation to CC07: false median signed measure has first occupancy expectation (3-c_v(m))/2, not 1 for an actually violated owner. Conditional source consensus excludes this particular obstruction. ## 2. Guard-projected matching terminal (proved)
Take the certified unary/pair exclusions as 2CNF B on original source indicators. If B inconsistent, NO. Positive-literal SCCs give equality classes. Substitute into all original exact-one rows, retaining multiplicities; a repeated class in a row is necessarily zero. Delete it and reclose, deduplicate identical rows. All source solutions survive; every exact quotient solution lifts by assigning every original member its class value. Extra certified binary clauses may be omitted from the final matching terminal because all lifts satisfying original occupancy necessarily satisfy them under the retained source guards. They must not be omitted if they are extra problem requirements rather than consequences, unless explicitly compiled into the rows or guard.
Let H be classes appearing in >2 distinct remaining rows. For each assignment to H consistent with B, reject conflicting selected classes, remove covered rows and competing classes, delete false hubs. Remaining classes have <=2 occurrences (row deletion/column restriction/dedup cannot increase incidence). Construct general graph on remaining rows; a two-row class is an edge of weight 2; one-row class connects to its private dummy with weight 1. Parallel choices retain IDs or one legal representative. Weighted matching saturating total row weight iff exact cover, with original witness lift. This is CPS08/followup terminal. New acquisition improvement: enumerate only the projected B models on H, not all 2^h. Enumerate with binary prefix tree and 2SAT feasibility under pins. Every viable prefix extends to a full projected B word, so at most O((h+1)(K+1)) tests for K admitted words or a cap K and next word; weighted matching at most K, exact NO only if all words exhausted, YES only actual verified lift. If cap exceeded UNKNOWN. For any fixed polynomial K(N), deterministic polynomial total time even when h linear. In particular width w of the acquired positive-implication poset yields at most (h+1)^w projected patterns by chain decomposition (other clauses only shrink); no universal width assertion. This improves guard-product accounting, not a universal decision theorem.
