## 1. Exact planar matching character oracle (known theorem plus explicit adapter)
Delete omitted-color incidence and suppress tuple nodes, retaining indexed parallel XY edges and original z-label on each. This projection is planar because it is a minor of the incidence graph; acquire a plane embedding by polynomial planarity routine. For an indexed perfect matching M define s(M) in GF2^d as the parity vector of its selected omitted labels. d=n for full source; for a projected region, d is number of possible omitted labels. For any literal guard G on indexed edges, let f_G(v) count projected matchings with s(M)=v satisfying G. Nonnegative integer counts. A source cover on full equal parts is precisely a projected matching with s(M)=1^n: n matched edges, n odd label occupancies, hence each occupancy exactly one. Converse immediate. In a region covering r first-color and r second-color elements, ANY attainable parity word of weight r similarly certifies exact occupancy equal to that word. Words of lower weight need not represent exact occupancy and may not be passed as exact regional states.

For character w define Q_G(w)=sum_M (-1)^(w dot s(M)) over guarded indexed perfect matchings. Acquire common Kasteleyn signing on the plane bipartite graph. A bounded face of length 2l requires product of its edge signs (-1)^(l+1); bridge occurrences cancel mod2 in the walk. Solve GF2 equations for all but a chosen exterior face in each component. For indexed parallel pairs, subdivide each edge in the parallel group into length-three path with two unique private bipartite vertices. Exactly one matching completion for unused edge (middle edge) or used edge (two outer edges). The signed determinant of expanded graph is a common sign times matching-character sum, with sign/weight applied to one outer edge when selected. Equivalently eliminate private pairs by block Schur complement: reduced original edge coefficient -s_outer1*s_outer2/s_middle. Sum parallel coefficients in matrix, keeping per-indexed-edge signs and guard IDs. Each determinant monomial, interpreted as indexed PM, has the same sign before character or optional nonnegative edge weight. Calibrate once from nonzero unweighted determinant (zero means no PM). Keep that sign for ALL queries. Do not take absolute values of individual signed character determinants. Literal zero deletes indexed edge; literal one deletes all other edges incident to either of its projected endpoints, rejecting conflicting positives. Same signed polynomial restricted by setting deleted coefficients zero, so sign stays valid without reembedding. Empty source handled directly. Arbitrary reembedding of a verified planar projection is valid for this oracle; no topology-dependent quotient operation. Executed code checks incidence planarity and acquires projection rotations, but does not serialize the original rotation or reuse the original rotation across regional queries; original source IDs and lifts are explicit. Independent double-chain rotation certificate below.

Bit cost: dimension at most O(N), coefficients sums of at most m signed integers, determinant bit size polynomial by Hadamard (unweighted counts <=2^m), fraction-free or other exact integer determinant polynomial. This is a paid oracle, not a SAT/equivalence oracle, and makes no counting claim for arbitrary 3DM. ## 2. Named lemma SP: deterministic sparse Walsh prefix recovery
Let f:{0,1}^d -> nonnegative integers with total bit length B for its total mass, given exact character query Q(w)=sum_x f(x)(-1)^(w dot x). Fix paid cap K>=1. Uniform algorithm either returns the ENTIRE support and counts with an invertible character basis, or certifies support>K and declines; at most 1+dK character calls, polynomial auxiliary bit work in d,K,B. No support promise is needed to avoid false decisions.

Proof: query Q(0). If zero, support empty. At prefix length i maintain distinct positive-mass prefix words P=(p_j), counts c_j=sum f over suffixes, list W=(w_l) of prefix-supported characters, and invertible evaluation matrix H_lj=(-1)^(w_l dot p_j), starting P=W={empty}, H=(1). To extend by bit i+1, query Q(w_l+e_i) for every l. In vector form these are H times a signed split vector v_j=c_{j0}-c_{j1}. Solve using exact H inverse. Then c_{j0}=(c_j+v_j)/2 and c_{j1}=(c_j-v_j)/2; each is nonnegative integer. Drop zero children. Every positive full word has positive prefix mass, and every positive prefix has a full continuation. Thus if number of retained children>K, actual full support>K and safe OPEN; no missed word or unproved approximation. Otherwise maintain a character basis as follows.
Let J be the parent prefixes splitting into two positive children. H restricted to these columns has full column rank |J| since H invertible. Deterministically choose |J| rows I with invertible restriction by rational elimination. Retain all old characters W and append w_l+e_i for l in I. To show invertibility on retained children: any vanishing row linear combination, subtract its two evaluations at each split parent. All old characters cancel; new character coefficients give -2 times the chosen invertible restriction (up to sign), hence all new coefficients zero. Every parent has a child, so remaining old coefficients zero by original H invertibility. Thus new square matrix full rank. If no split, original matrix unchanged. Induct to d. Each stage <=K signed queries, initial one. H entries +/-1; minors and exact inverse rational bit lengths O(K log K), counts B bits; all elimination/interpolation work polynomial, no enumeration of affine hull or Walsh domain. This is an exact adaptive small-support construction, not a priority/novelty claim about general sparse Fourier algorithms. Cheraghchi-Indyk, Nearly Optimal Deterministic Algorithm for Sparse Walsh-Hadamard Transform, arXiv:1504.07648 / SODA2016 DOI 10.1137/1.9781611974331.ch23 / TALG13(2017), gives more general deterministic sparse approximation/recovery literature. Our proof exploits exact nonnegative counts and exact prefix splits, and is self-contained.

Consequence: for any P3DM source with at most N^c actual projected parity patterns in one acquired projection, SP yields uniform deterministic polynomial decision AND exact source count, regardless of affine syndrome rank, including failed cap attempts in all three fixed projections. For a known target v, if absent from acquired support return exact zero; else take its count. For target 1^n this is exact source count by section1. This addresses high fanout directly rather than requiring one Boolean hub occurrence per matching endpoint. It does not follow from low rank and is not universal.

## 3. Lemma GR: reusable guarded interpolation and bounded-cost optimization
Once root support S and basis W,H^{-1} have been acquired, ANY subset of root projected matchings (literal guards on SAME indexed edges, same projected row sets) has support contained in S. With query vector Q_G on W, its complete count vector is H^{-1}Q_G. Thus one target count costs at most |S| determinant queries (zero if target absent), without rerunning support recovery, even when different guards share no actual witnesses. Positive target counts can be used in deterministic self-reduction: try pinning each original tuple false; retain that pin if target count stays positive, otherwise pin true. At most m+1 target evaluations, and final original matching/cover checked. A zero conditional target count proves only that guard impossible, not global NO. Root support closure: if pin-one count zero remove that tuple; if count equals positive root target count, tuple forced (remove its competitors); native closure re-run on certified deletions. Counts under arbitrary nonliteral guards not promised; if deleting covered vertices/relabeling projected owner sets changes matching family, reacquire chart or use separately verified adapter. Guarded interpolation is a compact joint support functional, not marginal pair consistency.

The same root H^{-1} extracts nonnegative integer weighted sums for any reweighting of the same indexed matchings; support can only shrink. With nonnegative integral costs c_e, fixed polynomial bound on total matching cost C, use edge weight B0^c_e with B0=2^(m+1) > total number of matchings. Each base-B0 digit of the target weighted sum is the exact number of target matchings at that cost, no carries. Least nonzero digit gives exact minimum cost, with witness by guarded counts at optimum (or digit comparisons). Bit size O((m+1)(C+1)), polynomial for polynomially bounded C. Arbitrary binary-encoded costs of exponential numeric magnitude NOT admitted by this encoding. Executed 120 random guarded weighted comparisons on four actual source controls, 63 positive; exact weighted sum and minimum agree exhaustive references. This is the paid bridge to MF05 weighted matching charts and ES05 weighted seam tables, not a claim of unbounded-cost polynomial optimization.

## 4. Lemma RJ: exact regional count composition without global support enumeration
Acquire connected components of a projected bipartite graph (implemented XZ, omitted Y). Each component has fixed equal number r of first/second-color owners or global NO. All projected matchings factor across components. For each component C independently use SP, filter actual parity words by weight r to obtain exact omitted occupancy masks, counts and one actual local witness per mask via GR. Preserve original tuple index map. For each omitted owner y impose EXACTLY ONE of its incident components' masks contains y. A global assignment of masks satisfying these constraints lifts by disjoint projected matchings, because no two components share projected owners and the omitted masks cover every omitted owner once; every source cover restricts to one such assignment. Count = sum over compatible masks of product of local counts. No joint affine hull inferred. Build factor graph on component variables, each with finite actual mask domain; each omitted owner's constraint scope forms a clique. Paid min-fill/width cap, then exact sum-product elimination and reverse nonzero backpointer recovery. Initial per-component weights count independently indexed matchings; factors consume each weight once. Every table entry counts partial indexed choices under its fixed boundary, with at most 2^m possibilities, so integer bit lengths polynomial. For fixed c, if acquired table domains polynomial and every bag domain product <=N^c, and order/partition acquisition paid polynomial, global decision/count/lift polynomial. Executed width cap 2 (rather than general bag-product recognizer). Failure to acquire/order/cap returns OPEN, not NO.
