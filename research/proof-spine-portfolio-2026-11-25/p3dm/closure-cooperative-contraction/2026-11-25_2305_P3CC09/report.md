## 1. BS: balanced two-edge source seam (PROVED)
In a connected balanced source component, choose two incidence edges of the SAME color c, with opposite orientations across a vertex bipartition A|B: (t_A,r_B),(t_B,r_A). These are the ONLY crossing edges. Each side contains equal counts of element vertices in all three colors. For any exact cover, sum occupancy on the rows of a color d != c in A. Because no edge of d crosses, this equals the number of selected triple vertices in A. Sum occupancy on the c rows in A: it is the same selected count minus x_{t_A} plus x_{t_B}. Balance implies x_{t_A}=x_{t_B}. Conversely, replace the two cross incidences by (t_A,r_A),(t_B,r_B), retaining tuple IDs and attach equality x_{t_A}=x_{t_B}. All row sums agree with the old row sums under equality, so the resulting two balanced source systems + one equality are EXACTLY equivalent, including any inherited unary pins. This is a source certificate, not matching marginals. If desired retain original rotation and crossing-edge record; no need to assert quotient planarity. For a connected original piece, if removal of the two edges leaves more than two components, the proposed restored edge joins the two complementary components if they are separate (each must meet one removed edge); both restored sides are connected. Can alternatively require both sides connected and preserve the same theorem.

Uniform acquisition: enumerate pairs of incidence edges of same color and compute connected components after deleting them; check orientation, boundary and color row counts, and verify the restored rows. Each successful split partitions the existing triple and row vertices into two nonempty pieces. At most O(N) splits. Naive O(N^2) pair tests times O(N) graph operations times O(N) rounds, O(N^4 polylog N) graph-bit cost; no target phase, separator oracle or exponential search. Disconnected source components must individually have equal color counts or NO. Keep original graph and row IDs. Treat actual source pins as constraints on original triple IDs throughout; neither unguarded nor conditional equality is exported outside its valid guard. Initial exact-one/all-three indexed matching/GF2 closure and optional exact CC08 pair-moment exclusions are safe; in this lane retain deleted variables as zero-pinned original IDs in the structural chart so structural acquisition can still use them.

## 3. SM: signed occurrence-two matching terminal (PROVED, executed)
A sound equality or complement relation (x_i=x_j or x_i=1-x_j) is acquired by exact row identities, certified native implication/contrapositive SCC, CC08 exact zero-event exclusions, or exhaustive local support of fixed-size acquired atoms. Store a signed DSU with original-ID lift, reject contradictory parity only when certified. Substitute into exact-one rows, not a marginal hull. Repeated same-sign literal in a row forces that literal false; if a row has complementary pair once each, all other literals false and row satisfied; two complementary pairs contradict. Handle repeated signs before removing row. Propagate pins, empty/singleton rows, remove only exact duplicate signed rows. Arbitrary extra necessary clauses can be omitted in this lane only when original exact occupancy + certified substitutions + actual unary guards remain equivalent to source; do NOT discard nonliteral imposed guards. Preserve/rebuild original chart for other lanes.

Local row constraints may require occupancy 0, occupancy 1, or either. Rows with pinned contributions subtract their integer occupancy and restrict residual to {0,1}; empty allowed set rejects. Variables of local degree >2 are fixed by an explicit bounded enumeration (or any exact complete alternative). Each remaining variable occurs at most twice, in distinct rows, with one sign per row. Omit residual rows forced zero. Construct graph:
* One occurrence: row-to-private optional dummy edge, chosen iff that literal true.
* Two same signs: one edge joining rows, chosen iff both literals true; omit if either row forced zero.
* Two opposite signs: one private MANDATORY dummy joined to both row vertices; saturating dummy chooses exactly one true literal. If one endpoint forbidden omit that edge, if both forbidden dummy cannot be saturated.
Require every exact-one row and every mandatory dummy matched; optional rows/dummies may be unmatched. Parallel same-endpoint alternatives retain all original IDs or one legal representative with other events inactive; opposite-sign dummies private. Matching -> Boolean lift by each selected gadget edge, defaults inactive for same-sign/single; mandatory dummy chooses opposite sign. Boolean lift -> matching because each row has at most one true incidence. This is exact for decision and witness, not a counting bijection.

Polynomial mandatory saturation by maximum-weight matching with edge weight number of mandatory endpoints (0,1,2), iff optimum equals number of mandatory vertices. Executed alternative: add one private clone for each optional vertex, connect each optional to its clone, make clones a clique, add one extra clone if total vertex count odd. Perfect matching iff original graph has a matching saturating all mandatory vertices. Forward: match unmatched optional to own clones and pair remaining clones (even parity); reverse: delete clone edges, mandatory vertices have no clone neighbors. Uses ordinary general-graph maximum-cardinality blossom; O(s^2) explicit clone edges for block size s. No planarity or bipartite assumption.

## 4. BCT: block-cut matching composition (PROVED, executed)
On any normalized exact signed occupancy system form bipartite row-variable incidence graph (edge = one literal occurrence); compute edge biconnected blocks, bridges are single-edge blocks. A variable articulation shares a bit across all incident blocks; a row articulation shares the requirement that the sum of its block-local partial occupancies equals one. Each block's share of an articulation row lies in {0,1}. Use actual edge partition, not arbitrary overlap of equations. The block-cut graph is a forest. Root at a block. Articulation-to-parent-block message:
- Variable: intersection of child-supported bits.
- Row: parent contribution a=1 iff all children support zero; a=0 iff some child supports one and all others support zero. Empty intersections are contradictions, not default zero. This check is polynomial even for arbitrary articulation degree.
Block-to-parent-articulation: for each parent value a, require internal rows exact-one, fix parent variable or restrict parent row share to a, impose all child masks on local variables and local row shares. Invoke SM under these unary masks, once per state (or enumerate locally high variables first). Store a single local witness and actual chosen child state per child. At root same computation with no parent value. Soundness by summing actual partial occupancies and variable agreement; completeness by restricting any satisfying source assignment; inductive gluing yields a witness on original IDs. Not a claim that every boundary relation is bijunctive. No counting multiplication or independent marginal acceptance.

Let h_B be number of locally degree>2 variable vertices in block B, s_B its encoded size. Once the exact signed quotient acquired, h_B and blocks are computable without SAT. Exact work <= sum_B 2^(h_B+1) poly(s_B) + poly(N) including articulation checks, local messages and reconstruction. Each original incidence edge belongs to one block; sum of sizes polynomial; no product of per-block patterns. For fixed c, admission if max_B h_B <= c log2(max(2,N)), or more generally sum_B 2^h_B <= N^c, checked under saturated arithmetic without materializing huge powers. Hence uniform deterministic polynomial terminal for unlimited global high-degree count and arbitrary node degree. A single block may have arbitrarily many low-degree variables; no block-size restriction theorem-level. This is stronger than CC08 raw/global projected guard count: signed quotient can have Theta(N) high global vars and h_B=0. Sparse-first exact rational row-basis deletion is a possible additional equivalent lane but not executed/claimed universally.
