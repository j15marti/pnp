## Lemma HGO: exact arbitrary target occupancy (PROVED)
Let R be explicit signed Boolean rows, each coordinate used at most once in a row (same literal repeated is also possible with multiplicity handled, not in code). For each row j let d_j(x)=sum of its true literals. Given target t in {0,1}^r, and any consistent literal pins on variables, decide whether all d_j(x)=t_j and return x. Let A_{j,i}=1 for each occurrence modulo 2, p_j=number of negative literals modulo 2. Necessary parity is A x=t XOR p. Define integer total C(x)=sum_j d_j(x)=c+sum_i w_i x_i, where c is number of negative incidences and w_i=#positive minus #negative incidences. On the parity fiber, d_j>=t_j because all d_j are nonnegative integers and t_j is 0/1. Thus C(x)>=sum t_j, with equality iff every d_j=t_j. This includes target-zero owners: positive even occupancy is a defect too. Can use arbitrary strictly positive row weights instead, with appropriate threshold and bit charges. If parity inconsistent reject, if feasible minimize C exactly on the fiber under pins. Return YES iff optimum equals threshold; NO if larger or pin-infeasible. Both directions immediate from nonnegative rowwise deficits. Example x1+x2+x3 target1 and all x pinned1: parity valid, optimum3>1, reject (executed). No relaxation or independent marginal witness acceptance.

Suppose binary column matroid of A is graphic. Known Bixby–Wagner graph realization theorem (1988, DOI 10.1287/moor.13.1.99): reduce to full-row-rank [I|D] by GF2 elimination and column permutation; realize D columns as tree paths. Use one spanning tree (identify one vertex per component of forest); zero columns loops; basis edge incidence matrix reduced at root is invertible over GF2. Multiplying [I|D] by that reduced tree incidence gives graph incidence with same labelled row space. Independently verify equality of row spans by rank of stacked matrices. This theorem gives paid deterministic polynomial recognition; full recognizer not executed in this run. Code uses deterministic sufficient raw/reduced row and path-difference tests, including exhaustive basis row orders only for rank<=6 (fixed constant), verifies equality by Gaussian elimination. Rejection by code is OPEN, not non-graphic or NO. Graph need not be planar; it is a computation chart, not a replacement P3DM source.

Obtain any parity solution x0 by Gaussian elimination (NOT exact-cover model). Its image under graph incidence is target boundary. Same row space implies same affine fiber: Bx=Bx0 iff A(x+x0)=0. Add omitted root row to one-entry columns, zero columns independently optimized. For fixed pins choose their prescribed value; for every free variable choose baseline a_i=1 iff w_i<0. Transform x=a XOR z where z_i=0 for pinned variables. Shift syndrome by Ba and minimize nonnegative sum |w_i| z_i on unpinned edges. A loop costs no parity and can be zero in z. Parallel edges keep the cheapest unpinned toggle (ties by actual ID), since any solution using two same-endpoint toggles can cancel them at no greater cost, and one can choose cheapest; pinned edges handled before simplification. Each connected component must have even number of odd-demand vertices. Min-weight T-join via shortest paths and min-weight perfect matching on terminals: any feasible edge set decomposes into terminal paths and cycles, giving metric pairing no more expensive; XOR of shortest paths for optimal pairing gives feasible edge set no more expensive than pairing. The inequalities imply equality. Restore x and verify parity and exact original d_j before returning YES. Standard Edmonds–Johnson, Math Programming 5 (1973), 88–124, DOI 10.1007/BF01580113. All integer costs polynomial bit size (unweighted incidence costs <=N). Negative coefficients never passed as negative path lengths.
