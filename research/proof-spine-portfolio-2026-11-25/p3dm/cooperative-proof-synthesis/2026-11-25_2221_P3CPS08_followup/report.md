Lemma A. An acquired exact source equality chart with every class appearing in at most two distinct exact-one rows remains an exact matching terminal under arbitrary original literal restrictions. Any original literal pins its equality class. For false pins remove the corresponding class edge. For true pins require that class edge, reject intersecting true classes, remove its covered row vertices and all competing class edges. Preserve class identities when parallel alternatives occur; select a representative only after applying pins. Solve maximum weight matching with edge weight number of covered rows (1 or 2), using private dummy vertices for singleton classes. Saturation of all remaining rows is necessary and sufficient, and class-to-tuple lift verifies actual source. Additional deductions logically implied under the guard need not be compiled if the existing exact chart already implies them. Thus pinning does not require recomputing SCCs, and representation admission is hereditary along source literal branches once an exact chart is acquired. For deletion neighbors use a known authenticated parent with same element sets and target a subset of actual parent tuples; pin removed tuples zero. No oracle or assumption of arbitrary parent discovery. A chart may be retained alongside a newly acquired quotient. This is a polynomial upper bound, not a universal chart theorem.

Lemma B. On any exact acquired occupancy quotient after deleting impossible repeated classes and deduplicating identical rows, define H as all classes with >2 distinct row incidences. For each assignment to H, reject overlaps between selected hub rows, remove covered rows, delete all other hub classes and all classes intersecting covered rows. Every residual class occurs in at most two rows. Apply weighted matching and lift selected classes, preserving original tuple IDs. The OR of branches is exact. Time O(2^h poly(N)) including acquisition and verification; h=|H| is directly computed; polynomial for h<=c log N, fixed c. Independent disconnected row-class incidence factors can be evaluated with additive sum of 2^{h_i}, without crossing guards. An unbounded h remains OPEN. This recovers prior guarded matching/backdoor method, rather than claiming novelty.
