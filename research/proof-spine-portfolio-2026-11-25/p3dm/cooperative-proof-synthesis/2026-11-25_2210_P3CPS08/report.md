## A. Exact elimination of binary root choices
Acquire CPS07 functional roots on one anchor color via literal selection, exact-one and all-three indexed projected support closure. Every true source cover corresponds to one internally disjoint bundle per root, and pairwise disjoint bundles select exactly n actual tuples, covering all colors. This is an exact binary CSP, not a planar quotient assumption.

Use one indicator for each viable bundle. Let B be 2CNF containing all pairwise bundle exclusions, AMO per root, ALO for roots of domain size 1 or 2. If an empty domain or B is inconsistent, NO. Only ALO for wide roots is omitted. For each wide option a retain iff B AND a satisfiable. For pairs of wide options from distinct roots permit iff B AND a AND b satisfiable. These are polynomial SCC queries. Equivalently in satisfiable implication graph, a alone inconsistent iff a reaches not-a; with individual feasibility, a,b inconsistent iff a reaches not-b (equivalently b reaches not-a). Reason: conflicting forced literals from two pins combine by contraposition; a consistent implication-closed pinned set extends via SCC order. The complete pairwise extension property also follows by induction using majority closure of 2CNF: for >=3 prescribed literals, choose three models each missing at most one distinct prescribed literal and take coordinate majority. Thus choosing one remaining option from each wide root subject only to acquired pair constraints is EXACT. The lift is a single original B solve with chosen indicators pinned true, AMO ensures all other wide options false, the small roots each get exactly one choice. All original bundle IDs are checked for exact occupancy. This is not a marginal projection claim.

If the wide graph (edge iff some pair excluded) is a forest, tree DP exports possible values per parent edge. O(sum edge domain products + total domains) after table acquisition; no guard product. More generally supplied tree decomposition with bag products polynomial yields exact DP, but discovery of suitable decomposition is a separate OPEN gate; only forest recognition implemented. Independent components of the wide graph can be solved separately even if B used shared binary variables, since combined chosen options are pairwise compatible and hence jointly extend.

## B. Equality-to-matching theorem
For every pair of root domains after sound arc consistency, enumerate allowed pairs. Acquire every equality of two one-hot option indicators true on all allowed pairs. Verify by full pair table scan that these equalities characterize the relation exactly (otherwise OPEN for this lane). Union equalities into classes. A class containing two distinct options of the same root cannot be true; discard it. If every other class occurs in one or two distinct root exact-one rows, construct a general graph: one vertex per row; a two-row class edge weight 2, a one-row class edge to private dummy weight 1. Parallel edges with identical endpoints represent interchangeable classes and may retain one representative. A maximum weight matching of weight #rows iff exact selection exists. Decode selected classes, unselected false, restore B. Cyclic graph allowed, no assumed planar matching quotient or counting theorem. If any class occupies >2 rows, return OPEN, not NO. All steps paid and polynomial. This is direct weighted Edmonds matching, not arbitrary mixture of constraint languages.
