## 3. New effective-degree matching theorem (PROVED)

Unary pins and universal factors can be handled directly. No planarity of the factor network is assumed. A local gadget has one port vertex per coordinate, a port is locally selected iff matched to an internal gadget edge. Every port is mandatory in the final graph. For fixed-parity R on p<=3 choose f in R and use gauge w'=w XOR f. Normalized R contains zero and only a subset of weight-two words. Add an edge between the corresponding port pair for each allowed weight-two word. Since p<=3 any internal matching chooses zero or one such edge, exactly the normalized support. For binary mixed parity, after removing universal relation only the 3-word case needs attention: complement coordinates so the unique forbidden word becomes 11; connect both ports to a common OPTIONAL private vertex. (The executable gadget enumeration does not directly admit adjacent two-word masks or full cubes; simplifier handles these.) Empty relation rejected.

## 4. New exact private-coordinate elimination (PROVED)
In the current table network, suppose some coordinates of R are private, appearing nowhere else. Replace R by its existential projection onto remaining coordinates Q. For each projected word store one full preimage. If projection is full, remove the factor; if Q empty and R nonempty, remove it. Proof both directions: any old solution projects; any new solution extends by independently choosing the stored private values, which occur in no other current constraint. When the projected factor is universal, surviving coordinates no longer constrained by anything may be assigned arbitrarily unless later restoration determines them. Reconstruct in reverse elimination order. Example exact-one(a,b,c) with c private gives NAND(a,b); if b,c private it gives full unary. Strict decrease in total variable-factor incidences on each step, no wider table introduced. Reapply compatible local terminals after this elimination. This is different from assuming a Cartesian product, and strictly increases admission on the promoted mesh below. No universal elimination guarantee: a network with no private coordinates, remaining nonmatchable masks or hub fanout>2 can persist. Could use exact bounded-interface regional projections or guard higher-degree hubs and repeat, but no universal polynomial aggregate bound established.
