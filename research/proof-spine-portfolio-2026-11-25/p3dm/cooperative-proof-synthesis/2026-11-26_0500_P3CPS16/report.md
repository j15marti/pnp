## 2. PCFA theorem (PROVED scoped)
Apply exact singleton, all three pair projection matching-support and failed-selection native closure (CPS07). Partition surviving tuples into connected YZ projection components. Unequal Y/Z counts reject. For a component with k Y and k Z owners, P is the set of private X owners (occur in no other component), U remaining X owners. Every regional footprint has r=k-|P| boundary owners B0 in U. If r<0 or r>|U| reject. Enumerate all B0 of size r when min(r,|U|-r)<=d for a FIXED d (executed d=2). There are <=O(N^d) candidate words, even when region contains arbitrarily many tuples. B=P union B0 must be covered exactly once. Restrict tuples to X in B. We now need true minimum f(B), not only membership or ordinary projected feasibility.

Acquire a reference simple YZ PM R using lexicographic prefix completion probes (source-derived). Its slots e=(y,z) have actual indexed tuples with X domain D_e. Min-cost bipartite assignment from B to reference slots returns an actual exact regional cover W and cost U_R if feasible. Preserve its IDs. This reference optimum may not be the global regional optimum.

For ANY owner prices p_x (signed rational), define
  L_B(p)=sum_(x in B) p_x + min_(simple YZ PM M) sum_(e in M) min_(t on e, x(t) in B)(w_t-p_x).
Empty projected PM set proves no exact cover for B. For every exact regional cover V, its indexed YZ projection is a PM and each x in B appears once, so L_B(p)<=w(V). The relaxation can use the same X owner multiple times and must NOT be treated as an exact cover. If an attaining indexed projected PM has k distinct X owners, it is itself exact and tight. If L_B(p)=U_R, the reference witness is exact optimum. Neither strict gap nor inability to find a reference cover proves infeasibility.

Acquire p from the reference assignment dual by shortest paths on difference constraints. If x_s is the selected owner in slot s, require p_x-p_(x_s)<=w(x,s)-w(x_s,s) for every allowed edge. A negative cycle would improve reference assignment via cyclic permutation; optimality excludes it. Add zero-cost source arcs; exact Bellman-Ford yields p, and q_s=w(x_s,s)-p_(x_s). For an alternative tighter price, solve explicit rational feasibility for three-part potentials u_x,v_y,z_z:
  u_x+v_y+z_z <= w_(x,y,z) for every allowed original tuple,
  u_x+v_y+z_z = w_(x,y,z) for each t in W.
Summing proves W optimal since every cover uses every owner once. This is ordinary assignment LP duality, not an unrestricted P3DM relaxation theorem. ## 3. BSM theorem (PROVED scoped; integrate CC15 balanced two-incidence seam)
A connected native residual has a cut of exactly two incidence edges of SAME color c, with opposite orientations: tuple a in shore A touches owner beta in B, tuple b in B touches owner alpha in A. Each shore has equal counts of each of its three owner colors. In an exact cover, let s_A=sum selected tuple bits in A. For either other color s_A equals its owner count in A (no crossing). For color c the occupancy sum in A is s_A-x_a+x_b, same owner count. Hence x_a=x_b. Reconnect a to alpha and b to beta internally (undo swap); keep original tuple IDs, weights and all literal guards. In either shore equality implies each changed owner has identical occupancy, all other rows unchanged. Thus an original cover is equivalent to two exact local covers with equal seam bits; reverse lifts by restoring the old incidences and union of selected IDs. Neither side forced to one bit; preserve conditional guards. Check both resulting local sources are balanced, distinct, connected through their shore and planar; if repeated triples or failed certificate reject the split (OPEN for that candidate, not source NO). Reacquire planar cyclic embedding; original embedding separately recorded.

Acquire cuts by scanning each incidence edge e, temporarily remove it and compute bridges of remaining connected graph. Each bridge f then gives a 2-edge cut; test same color/opposite orientation/balance, check actual reconnected children. Enumerate polynomially many candidates and failed attempts. Each accepted split partitions nonempty disjoint tuple ID sets. Recursive splits replace one atom by two linked atoms, routing previous tree edges to new atom containing its endpoint tuple. Invariant factor graph a tree; even if an earlier virtual incidence is redirected, previous equality is retained on the same original bit. Independent disconnected source components add costs; unbalanced component rejects; no source overlap. Source closure is reapplied at stagnation and inside each local guarded evaluation, not after every purely representational cut; no extra semantic source deletion at such cuts. No supplied cuts or construction tags in production solver.

Root the acquired atom tree. Child subtree exports two exact minimum values m(0),m(1), including infinity for infeasibility, conditioned on its endpoint tuple bit. Parent seam equality means child cost for local endpoint bit x is exactly
  m(0) + (m(1)-m(0))*x
when both finite. If one finite, force x to that value and add the finite constant; if neither finite, parent infeasible. Multiple children at same tuple sum unary costs and reconcile pins. This folds arbitrarily many binary messages into existing signed tuple weights WITHOUT constructing a Cartesian boundary table. For each of the two parent-bit guards, invoke exact PCFA + CPS15 local terminal (or bounded direct native enumeration <=12 tuples); root one unguarded call. If any needed local query OPEN, return OPEN, never approximate. Induction: given parent bit, optimizing atom with sum of all child minimum responses equals subtree optimum, since child interiors disjoint and all cross constraints exactly seam bits. Record local optimal IDs, then reconstruct top-down using selected endpoint bits. The union verifies original source and original weights. This is exact min-sum tree DP but new integration uses paid large-atom price acquisition, not a bounded atom size assumption and not an explicit high-degree response table.
