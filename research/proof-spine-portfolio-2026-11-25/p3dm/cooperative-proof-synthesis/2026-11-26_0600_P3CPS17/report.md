## 2. Genuine planar source family and stronger obstruction
Construct from ANY finite simple plane graph G with no isolates (remove isolated vertices and adjust independent-set target separately). Subdivide each edge once to obtain H. At each H vertex v, d=2 deg(v), use disjoint Y,Z labels Y_i,Z_i for i=0..d-1. Simple projection is cycle with D_i=(Y_i,Z_i) and F_i=(Y_i,Z_(i+1 mod d)); two modes 0/1. One consecutive two-position group per incident H edge e, ordered by acquired planar rotation. Shared X owners a_e,b_e and one private p_(v,e) per endpoint. For BOTH modes, first position domain {a_e,p}, second {b_e,p}. Reverse first/second order at subdivision endpoints. Every allowed indexed tuple explicit; for b=|E(H)| there are 4b owners of each color, 16b tuples. Planarity: draw cycle in vertex disk; D_i and F_i meet at Y_i, consecutive. Each pair has two length-two tuple paths, exterior shared label and interior private label. Private owner joins its four interior tuple vertices in the sector of its consecutive two positions. Sectors disjoint. Exterior a and b ports each a contiguous cluster; reversing group order at the subdivision end gives compatible corridor orders. Along each embedded H edge use two disjoint strips to connect the two a-port clusters to a_e and b-port clusters to b_e. This constructs planar incidence embedding (as in CC16 with both endpoint modes safe). Degree-one case d=2 is ordinary four-cycle, no duplicate triples. All finite constructed instances independently authenticated by NetworkX. Each Hall block is exactly one H edge with four owners and eight possible pair slots, 16 indexed tuples; selected modes give four pair slots. Its endpoint private owner forces that endpoint to export either a or b. Both allocations of a,b across endpoints feasible, independently of mode bits. Every global mode word extends, every tuple supported and avoidable; no semantic unary forced deletions on unguarded family. True original ID lift follows selected pairs, not just marginals.

For edge e choose W_e>=0 and preference flips on one endpoint b_e^pref in {0,1} (distinct notation from owner b_e). Charge W_e to shared-label tuple iff its label differs from local preferred label, preferred a when s xor flip=0 and b otherwise; private tuple cost0. Minimum allocation cost = W_e if endpoint preferred labels equal, zero otherwise. Thus realizes arbitrary nonnegative-weight signed XOR violation interaction. To add any unary field on a mode, add its value to both tuples of one fixed Y position in mode1 only; exactly one selected tuple there. This is an exact native source adapter from arbitrary plane binary spin systems with fields, with at most linear source size. No model supplied to production solver.

Weighted-universality barrier (PROVED via planar independent set): for each original G edge use both subdivided interactions weight2, desired differences of opposite parity, so minimizing subdivision bit costs 2 if original endpoint bits equal and 0 otherwise. Add unary (2 deg_G(v)-2)x_v at each original vertex. All original tuple weights nonnegative since no isolates. Minimizing over subdivisions/allocations yields exactly
2|E(G)| - 2 sum_v x_v + 4 sum_(uv in E(G)) x_u x_v.
If an edge has both endpoints selected, remove one: change <=2-4=-2. Therefore optimum = 2|E(G)| -2 alpha(G). Threshold at 2|E|-2k is equivalent to planar independent set size >=k. This is a polynomial reduction proving NP-hardness of arbitrary weighted optimization/threshold decision on even this FULL-support, narrow binary Hall family, with trivial unweighted YES and no forced tuples. NP membership via original cover cost. This does NOT prove P!=NP, does not prove unweighted hardness on the family and does not preclude solving arbitrary P3DM. It identifies a misplaced universal proof obligation: insisting on arbitrary exact signed messages as a universal polynomial backend would already solve an NP-complete problem independently of source decision. Separate decision-preserving scope from weighted exactness; do not require arbitrary cost unless adapter proves special reachable message structure. Fields over all interior vertices destroy apex planarity on grid controls; this is a representation obstruction, not general algorithm lower bound. Conditional theorem remains valid for unweighted/binary, gauge-balanced or planar-anchored weighted instances.
