## 1. Lemma SC (signed complement contraction)
Apply native exact-one singleton/zero, all-three projected perfect matching existence and allowed-edge support, failed-selection closure. For each surviving original tuple a acquire C_a by pinning a and reclosure; whenever an owner has exactly one possible tuple b, record a implies b. SCC classes are exact equalities within current guard. Substitute into every ORIGINAL row with multiplicities retained. Write an exact-one row as sum of [x_v=b] equals 1, with b in {0,1}; retain an expression map from each original class to a signed representative or constant. Each signed step scans original rows under current map:
- two true constants contradict; one true constant forces every other literal false;
- complementary pair contributes one identically, so force every other literal false (including any extra occurrence); repeated identical literal must be false;
- remove false constants, empty row contradicts, singleton pins true;
- exactly two remaining distinct variables imply [x_v=b]=1-[x_w=c], an equality or complement; substitute and rebuild.
Every action eliminates a currently free representative by exact reversible substitution; at most m actions per chart. Equal rows deduplicated; all remaining rows have distinct variables and length at least three. Every source solution gives a reduced solution and every reduced solution lifts to all original occupancy equations, including omitted tautologies. Retain signed expressions for all classes. Certified false original tuple classes reenter native closure, re-acquire contexts after any strict deletion; positive literal consequences enforced by deletion of competitors, no arbitrary extra guard removed. At most m strict source-deletion rounds. Signed contraction can change high-occurrence count either direction; do not assert monotonicity, keep prior exact charts as alternatives. This is exact integer arithmetic, not affine hull. No target model or semantic SAT oracle.

## 2. Lemma SM (signed degree-two matching, including conditional row removal)
For rows R in a signed exact-one system, mark all variables H occurring in >2 distinct rows as shared hubs. For ordinary variable with one occurrence (r,b), introduce edge r--private dummy; using edge sets x=b, otherwise x=1-b. With two occurrences (r,b),(s,c): if b=c, introduce edge r--s (both or neither true). If b != c, introduce mandatory dummy d_v with edges d_v--r and d_v--s, setting x=b or c respectively. Exactly one edge incident to this dummy must be used, representing the fact that precisely one of the two complementary occurrences is true. Rows and mixed-sign dummies are mandatory; private dummies optional. Each edge weight = number of mandatory endpoints (0,1,2); a maximum weighted matching saturating all mandatory vertices exists iff the ordinary exact-one conditions hold. Proof: any assignment covers each row once and every mixed dummy once, hence gives a matching; any saturating matching defines selected ordinary values, unselected same-sign variables take the value making both literals false, every mixed dummy sets its unique selected value. Parallel same-sign edges with identical endpoints can retain one alternative for existence and hub response (all discarded alternative variables false); for further original-variable guards restrict prior to collapsing or retain indexed alternatives. No dropped independent cross-guard.

For fixed hub values, count their true literals in each row: >1 reject, =1 remove row vertex and all incident edges, =0 leave mandatory. KEEP all mixed-sign dummies even if one or both neighboring rows removed. This handles complementary obligations exactly (two removed endpoints imply impossible mandatory dummy). Thus every pinned local response is decided with original signed values and reconstructable witness in deterministic polynomial time by weighted Edmonds matching. No separate matching projections claimed jointly sufficient.

## 3. Lemma HJ (distributed contextual join)
Build graph on rows, connecting two rows whenever an ordinary variable occurs in both. Components J partition rows AND ordinary variables; shared hubs may touch arbitrarily many components. For each J collect actual incident hub IDs H_J. Its exact response table A_J consists of assignments to H_J with successful SM match; store one actual ordinary-variable assignment per admitted word. Conditional matching chart uses all rows of J and all its ordinary variables. Distinct components have no shared ordinary variable; shared hub IDs remain global, not duplicated free choices. For every full hub word x,
source exact quotient feasible with x iff x restricted to H_J belongs to A_J for all J.
Both directions immediate from local exactness and disjointness of ordinary variables. This exact factorization does NOT require independent components of the whole source. Local acquisition cost sum_J 2^|H_J| poly(N) instead of 2^|H|. Empty local table rejects.

If all local tables have at most two Boolean ports, their constraints are exactly 2CNF. More generally acquire a global necessary 2CNF B from every missing unary and pair support of each local table. Repeatedly remove each table word for which B AND its pins is inconsistent by SCC, and append all newly missing unary/pair patterns. At all times every true source cover's hub word satisfies B and all retained tables (induction); at most O(h^2) distinct clauses. A B contradiction or empty table certifies NO. At fixed point certify every local projection: for EVERY missing local word w test B AND pins(w) for UNSAT. If all missing words rejected, every B-model belongs to every table, hence one SCC model and independent stored local witnesses give exact original cover. This is an exact contextual certificate, not an assumption that the binary hull is exact or that separately consistent marginals suffice. If exactness fails, a tested B-model lifting into every table still certifies YES; otherwise OPEN. At stagnation any hub pin forced by B is a necessary source consequence; map signed literals back to original classes, delete false tuples and competitors of true pins, reclose all projections and rebuild on strict source deletion. Implemented. All live source IDs and rotation retained; no nonliteral external guards silently discarded.
