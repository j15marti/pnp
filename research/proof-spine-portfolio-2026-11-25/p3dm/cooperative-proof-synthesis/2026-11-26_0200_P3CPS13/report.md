## 1. CBG theorem, both directions (PROVED)
Let R be an exact acquired signed Boolean occupancy chart, each variable occurs at most once per row; prescribed targets t_j in {0,1}. The native chart from CPS12 is valid for original all-one source targets, not generally arbitrary target changes; for raw local owner targets acquire raw rows. A is its binary occurrence matrix. Partition original chart columns into disjoint nonempty groups G_i. B denotes all rows touched by more than one group. Each nonboundary row is private to at most one group (an empty row handled by global parity/occupancy checks). Let k=|B| and choose a full basis q_1,...,q_k of F2^B, extended by zero on private rows. For each group form A_i from its columns, keeping all boundary rows and touched private rows, and augment with virtual columns q_j and q_j+q_l for every j<l. Do not give these columns occupancy costs or allow them in actual witnesses. Suppose each augmented matrix is graphic. Acquire any equal-row-space labelled graph incidence chart for each augmented matrix; loops and parallel actual edges permitted.

The independent q_j anchor edges are nonloops and distinct. Each pair with its sum is a three-element circuit, so each pair of anchor edges shares an endpoint. A pairwise intersecting family of independent graph edges has a common endpoint: if three instead form a triangle, they are dependent; any additional pairwise intersecting edge must meet the common endpoint. For k=1 choose either endpoint, k=0 no anchors. Thus local anchor edges form a star with distinct leaves, one labelled by each common q_j. Delete ALL auxiliary edges but identify the former anchor root and each corresponding q_j leaf across groups; all nonanchor vertices stay private. Call the resulting incidence matrix D on actual columns only. For the k=0 case disjoint union suffices.

Claim ker D=ker A. For Ax=0, every local contribution A_i x_i has zero private coordinates and therefore equals a unique q-combination y_i on the boundary. The sum of the y_i coefficients is zero over GF2, since the boundary contributions sum to zero. Equal local kernels in the augmented matrices imply that D_i x_i is exactly the same linear combination of the local star edge incidences. After gluing these cancel, so Dx=0. Conversely, if Dx=0, at every nonanchor vertex the local incidence vector D_i x_i vanishes because that vertex is private. Its only possible nonzero coordinates are anchor vertices; their sum is even because an incidence column has two endpoints (or is zero). Hence it is the unique incidence of a subset of the star edges. Equal augmented kernels imply A_i x_i equals the corresponding boundary q-combination, and is zero on private rows. Cancellation at each labelled leaf means the subset coefficient sums vanish. Thus Ax=0. Check full global row space by GF2 stacked rank in the implementation; do not trust independent marginal tests.

For any globally feasible parity RHS t XOR negative-literal parity, find an affine parity solution x0 by Gaussian elimination (not an exact-cover oracle). Then Dx=Dx0 iff Ax=A x0. If inconsistent return NO. Minimize original total integer true-literal count over this single global affine fiber with any simultaneous literal pins, using CPS12 signed-cost toggles and minimum-weight T-join. In particular, do NOT enforce exact target one separately in every region on a shared owner. Each original row's total nonnegative occupancy with parity t_j is >=t_j, so the global sum is at least sum_j t_j, equality iff every row hits its exact target. The objective counts original literal incidences once, including all contributions on shared rows. Equality gives YES, an attained larger optimum or infeasible parity/pins gives NO; reconstruct all original IDs and verify. Chart decline is OPEN only. This proves exact global join, not just parity compatibility.

The simpler unit-basis variant only augments each group with the subset of boundary unit columns it actually touches; roots still shared and leaves named by original row, so the same cancellation proof applies with absent coefficients zero. This is the version in glue.py. For general bases use the full B in every region, including zero actual rows as necessary (tree_glue.py). A path gauge uses q_j=e_1+...+e_j, i.e. physical unit rows become path-edge incidence instead of a star. This is one deterministic alternate gauge. The theorem allows any explicitly acquired full basis; it does NOT imply efficient search over all bases. For any polynomially many candidate partitions and bases (or one given by a paid decomposition), recognition and verification are polynomial. ## 2. Exact scope and falsifier
CBG certifies that the global matrix itself is graphic; the result is a modular acquisition/composition theorem, NOT an enlargement of the full CPS12 graphic tractable class. A complete global graphic recognizer could solve any CBG-admitted chart directly; no comparative speedup shown. It clarifies what a regional interface must preserve to use one graph join rather than 2^k words.
Unanchored local graphic charts alone do not imply a graphic global join. Binary Fano matrix consists of seven distinct nonzero columns in dimension 3. Partition into singleton columns, each graphic. Whole is nongraphic: simple graph of rank 3 has at most six edges, since a connected component of rank r has at most (r+1)r/2 edges and sums over components with total rank 3 are <=6. Fano has seven. This is an abstract matrix counterexample, NOT proof of source hardness. Code rejects anchored singleton partition. An additional fixed-basis contraction scan found no Fano minor on three actual decorated/partial/promoted signed charts; this is not full minor search or graphicity proof.
A native scalable obstruction to the unit-star acquisition condition is CPS07 ternary-chain chart rows h+a_i+b_i=1, i=1..k. Group h alone and all other variables in a second group, chosen from acquired chart by maximum occurrence, not supplied solution. Every row is boundary. On h-side the all-ones column equals sum of k independent unit anchors; in a star its incidence has k distinct leaves (and root if k odd), impossible as one edge for k>=3. Thus star augmentation on this partition is actually nongraphic even though the global matrix is graphic. Path gauge turns same sum into the two path endpoints and each private column into one path edge. Other side admits every one of 2^k exact occupancy words independently (choose neither/one of its two private variables per row). One global T-join resolves all without enumerating them. This is a high-width representation control; the family is easy by CPS11 and direct CPS12, not an irreducible hostile family or new universal coverage.
