## 3. Reversible constraint evaluator with polynomial width

- for each row R_j, starting with scratch t=0, apply one gate t <- t+R_jv*s_v (mod3) for every nonzero coefficient;
- apply constant gate c <- c+1 (mod q) if t!=0, else c unchanged;
- undo all scratch shifts in reverse order.
All operations are bijections on entire lane set, marker always fixed. After row j the scratch returns to0 and counter increments iff row violated. Starting at o, P(o)=(d(s),0), where d(s) is ordinary integer number of nonzero rows, 0<=d<=r<q. No modular alias of d=0.

Let S swap o and marker and fix all other lanes. Append S then reverse P with all gates inverted; full program action T=P^{-1} o S o P (composition right-to-left). It is the transposition of marker and P^{-1}(o). Therefore marker and o lie in the same permutation orbit iff d(s)=0 iff H colorable for this sign word. ## 4. Realize the reversible program by actual cubic source switches
Each of l stages has w input and w output ports, represented by distinct vertices. At stage i, phase b=0/1 pairs input j with output pi_i^b(j), giving two perfect matchings P0_i,P1_i. Wire output j of stage i to input j of stage i+1, cyclically around last to first. Initially these are abstract pairings, not yet a simple graph. All port vertices belonging to stages controlled by the same source variable are grouped, including the constant dummy variable. For each group take disjoint unions of both phase matchings. Their alternating union may contain many cycles, including length2 components with common pairing. Must implement ONE actual even cycle for the whole variable (otherwise illegal independent occurrence choices).

**Cycle-splicing lemma.** Let ab and cd be phase0 pairs in two distinct alternating components of a group's P0 union P1. Add four fresh ports x,y,p,q. Replace P0 pairs ab,cd by ax,by,cp,dq. Keep all old P1 pairs; add P1 pairs xp,yq. Add fixed wires xy,pq. In phase0, fixed wire suppression recovers paths a-x-y-b and c-p-q-d, hence original pairs ab,cd. In phase1, the new vertices form an isolated four-cycle via P1 and wires; old P1 unchanged. Thus for each individual phase every original port pairing and all exterior connectivity are preserved. In the union of the two matchings (excluding wires), deleting ab,cd opens two alternating paths. The added P0/P1 paths a-x-p-c and b-y-q-d join them into a single alternating cycle. The number of components decreases by exactly one. Repeat until one cycle per variable, retaining the original pair indices and dummy wiring. If components of length2 occurred, all merge into cycles of length>=4 because each used variable has at least one full stage with w>=7 original pairs; a solitary alternating component containing a full stage's vertices is already long. No common P0/P1 edge remains in a single alternating cycle of length>=4. This proves exact two-phase realizability, not a free equality constraint on independent components.

Let A be all resulting P0 and P1 edges. Break the two original closing wires of lanes o and marker. For each cut wire attach both ends to a fresh vertex, respectively u and v, replacing that wire by two edges. Add z=uv. G consists of A, original uncut wires, dummy wires and the four new terminal wires plus z. Every ordinary vertex is on one actual simple even A-cycle and has exactly one non-A wire; u,v each degree3 and isolated in A. Original wires join distinct stages (l>=3), whereas original A edges pair within stages or involve fresh ports. Dummy wires join fresh pairs distinct from their P0/P1 edges; the construction creates no loops or duplicate adjacency. Terminal wires have distinct endpoints, z new. G is simple cubic.

Connected/bridgeless proof: every stage's ports lie in one connected A-cycle, and every adjacent pair of stages is linked by w wires (w-2 at the modified closure). Even if stages share a variable these wires do not harm connectivity. All A edges lie on cycles; dummy wires have endpoints in same A-cycle. Deleting any single original interstage wire leaves >=1 other link, so all A cycles stay connected. Each exception vertex attaches by two distinct wires to this connected core, even after deleting one of them; z itself is not a bridge. Thus G connected bridgeless.
