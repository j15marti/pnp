## 1. Parity reduction of a singleton-defect chart
Let E be indexed edges of cubic G, A support of binary flow a, F=E\A. Components of (V,A) are simple cycles and isolated vertices. Contract them; odd-degree components are exactly odd-cardinality components (cycle length odd or singleton). Suppose minimum achievable zero count for fixed a is 1. Then the quotient has exactly two odd components and each feasible singleton z=uv in F joins them. For such z, FP12 proved b_F=1 on F\{z},0 on z and each feasible b_A has one phase per A-cycle. We impose degree_B(v)=2 at every source vertex, B=supp(b), as required for an even spanning 2-factor. At a cycle vertex v, its required number of selected A incident edges is 2-deg_{F\{z}}(v); solve cyclic equations x_{i-1}+x_i=d_i as actual integers with x in {0,1}. Trying first bit 0/1 and propagating determines all options. Isolates must already have fixed degree2. On each odd cycle containing a z endpoint there is one feasible option (if any). Other cycles are even with two alternating perfect matchings. Local membership pins on B edges restrict each phase separately; fixed-edge inconsistency rejects. Every retained combination is a spanning 2-factor and has exactly singleton zero with a. This is exact, not affine hull or fractional occupancy. Arbitrary linear guards coupling distinct phases are NOT included.

Parity lemma: every ordinary vertex (not u,v) has one selected A edge and one selected F edge. At u or v both selected edges have the same type (two A on a cycle, two F at an isolate). On each B cycle the number of changes between edge types A,F is even, so its length modulo 2 equals the number of exceptional vertices it contains modulo 2. Thus B is an even spanning 2-factor iff u and v lie in the SAME B cycle. This is a precise reduction of FP12's two-step escape to terminal connectivity; it includes the case where both exceptional vertices are isolated in A.

## 2. Exact effective-port normalization, no loss of phase correlations
Retain forced edges and all original switch options. For each even A-cycle with two local options, each vertex has one forced F edge; its two phase settings choose two perfect matchings on its vertex set. Split u and v each into two terminal half-edge vertices. Suppress every fixed path to a wire; fixed cycles with no terminal can be omitted for connectivity (they are even by parity lemma). The resulting wire set W is a perfect matching on active switch ports and four terminal ends u0,u1,v0,v1. Each switch independently chooses a perfect matching P_i^0 or P_i^1 on its ports. Any phase assignment gives exactly the original exceptional-terminal pairing, preserving source edge IDs and original choices for reverse lift.

Certified closure, to fixed point: if a pair xy belongs to both P_i^0 and P_i^1, remove it from each; suppress xy in the wire matching by replacing wires x-a,y-b with a-b (if xy itself is a wire, remove closed circuit). If a wire xy has both endpoints in one switch, remove it from W and suppress xy separately in each phase matching by the same splice rule. The two phase choices remain indexed, even if their projected pairings coincide. Each operation removes two active ports, preserves all four-terminal connectivity for EVERY original phase assignment, and never mixes options. Repeat until neither operation applies. Local forced-edge and phase-pin closure precedes this, and can be reapplied after new local pins. Every suppression is a degree-two path contraction; any discarded circuit lacks exceptions and is even in the original B. No planarity/cyclic embedding assumption is required. This gives effective arity, not raw cycle length. A long cycle with two common projected pairs or internal wires may have zero or four effective ports. At most O(n) suppressions, polynomial discovery even using full rescans. A switch with zero remaining ports still retains its original phase witness; choose any allowed phase when lifting.

## 3. Main theorem: exact alternating-path matching terminal
Let L be the number of switches whose effective port count after closure exceeds four. Branch on their two phases, charging all 2^L branches in a negative instance. For each branch define H on remaining ports and four terminal ends: edge set W plus the chosen long-switch pairings plus BOTH options of each other switch. For each of the four choices x in {u0,u1}, y in {v0,v1}, query ordinary perfect matching of H-{x,y}. Use a deterministic general-graph maximum matching algorithm, not a parity-constrained or SAT oracle.

Necessity: if a legal phase assignment joins u,v in B, at least one of its suppressed paths joins such x,y. It starts and ends with a wire edge, alternates wire and switch transition, and is vertex-simple after omitting any closed circuits. Toggling W along this path leaves precisely x,y unmatched, so H-{x,y} has a perfect matching.

Sufficiency: a perfect matching M of H-{x,y} has symmetric difference with W consisting of alternating cycles plus a single simple alternating x-y path (x,y are the only degree-one vertices). Non-W path edges are legal transitions. On a short switch the path uses pairwise disjoint transition edges. On two or four ports, ANY disjoint set drawn from the union of its admissible perfect matchings extends to one of them: zero/one edge trivial, and two disjoint edges on four ports are forced complementary, hence already occur together in every perfect matching containing either. So one actual phase accommodates all visits to that switch. Long phases were already fixed. Choose one allowed phase at each short switch consistent with path (arbitrary where unused), recover original B from stored original options and fixed edges. The x-y path is preserved; hence u,v in same original B cycle; parity lemma gives all cycles even. Alternating two colors on each B cycle and using third on E\B is actual whole-source coloring. Verify every original incidence, selected membership and pin. If W and a transition share the same unordered pair, collapsing duplicate adjacency for matching is harmless: a shared edge cancels in symmetric difference and cannot be a non-W path edge. Original path identity is retained in lift.

Therefore exact two-step decision+witness for a singleton chart in deterministic O(2^L poly(N)), with at most 4 matching calls per branch. No enumeration of short-phase assignments. For a fixed direction a, all feasible singleton z (at most m) can be listed and normalized in polynomial time; if all satisfy L<=c log_2 N for fixed c, complete two-step decision is polynomial. Or budget each admitted chart and return UNKNOWN if unprocessed others might succeed. Local chart NO is not source NO. The min-one current direction is an authenticated input from FP12 state; no free acquisition of a on arbitrary source claimed.

Corollary (proof-level, not executed as a general group solver): an arbitrary group of already short switches with four unpaired external ports, containing no exception, can acquire its exact attainable boundary pairing support using the same deletion-matching path test for each pair of external ends. One connection determines the complementary pair because all internal paths pair boundary ports. This can group many switches into one four-port relation (possibly all three matchings), with stored actual assignments for each. The four-port path-consistency proof works for any nonempty collection of perfect pairings, not just two. Groups with six+ boundary ports require exact joint pairing support, not pairwise marginals. Group discovery/coverage not universal.
