## 1. Exact unguarded source and closure
At each production node verify simplicity, degree, indexed edges. Factor connected components independently. A proper coloring is three disjoint perfect matchings partitioning edges, equivalently one perfect matching plus even-cycle complement, equivalently a nowhere-zero F2^2 flow (three nonzero values, conservation at every vertex). A bridge is impossible by summing conservation over one side. For every edge test inclusion in some perfect matching (delete its endpoints and find residual perfect matching), and exclusion (delete edge and find perfect matching), using ordinary polynomial blossom. If either fails, NO by global permutation of the three colors. Any found perfect matching with all-even complement yields verified YES. None of these necessary matching tests alone proves YES. Apply closure before each recursion/cap query and at stagnation; no unguarded fixed color or arbitrary edge deletion is inferred from matching support. No inherited guards used in this iteration; contextual replacement below does NOT preserve arbitrary precoloring or pinned boundary state.

## 2. Four-port contextual theorem
Cut exactly four indexed edges between two sides; preserve port order (same order on both sides). A pole consists of internal cubic-incidence vertices and four labeled dangling edges; port endpoint vertices may repeat. Treat dangling edges as incident to separate degree-one leaves for Kempe traversal, not as constraints on those leaves. Summing F2^2 conservation shows boundary XOR zero. Therefore up to global color permutation only four types exist: 0=aaaa; 1=aabb; 2=abab; 3=abba, where a!=b. Call type support S(P) subset {0,1,2,3}. Actual colorings of two poles can be glued iff their supports intersect: matching types can be aligned by a global permutation, then join all four original seam edges. No marginal-only joining.

Every nonempty support contains at least two types, and given ANY actual coloring, another type can be acquired by one Kempe path in linear graph work. If all ports have color a, choose another color b; otherwise choose the two colors present on the boundary. Their induced subgraph has internal degree two and exactly four degree-one port ends. The path from a port terminates at a different port. Switching those two colors on that path changes exactly two port colors. With an all-equal word this creates two pairs. With a two-pair word, same-colored endpoints produce all-equal; different-colored endpoints change the pairing. All internal vertex conditions remain valid. This is a boundary-type repair, not a claim of global monotone defect escape.

For any two-element subset Q of types construct a simple cap of <=18 new vertices. If Q={0,i}, two independent equality two-poles realize the two pairs of port positions of i. Each equality two-pole is a diamond K4 minus an edge with dangling ports at its two degree-2 vertices. Summing conservation gives equal port colors; any specified color c extends by a K4 coloring (opposite edges c, other opposite pairs the other colors). Thus exactly Q. If Q excludes 0, let i be the missing pairing type among 1,2,3. Attach the two pairs of i to two new adjacent vertices, one pair per vertex. Each pair must have distinct colors and both must use the same two colors, because the central edge supplies their common missing color. Exactly Q. If attachment would introduce a duplicate edge (repeated original endpoint and cap endpoint), insert a fresh equality diamond on the duplicate link, maintaining both indexed port IDs. At most four such insertions, giving conservative overhead 18. All cap graphs are actual simple cubic graphs, possibly disconnected. A square with one port per vertex has types {0,1,3} in cyclic order: all equal by alternating remaining colors, adjacent pairings via internal edges of common missing color between blocks, alternating pairing impossible since all four internal edges would be the third color.

Define eight contextual classes: empty; six exact two-type classes; universal (>=3 types). Every nonempty context pole contains >=2 types, so any universal class is compatible with every nonempty context. Consequently two universal poles are interchangeable for unguarded CEC decision, although they need not have identical type supports or solution counts. This quotient does not transfer to arbitrary pinned context, which may have a singleton allowed type. A fixed square is a universal representative.

## 3. Adaptive acquisition and lift
A cap query with Q of size two is an ordinary CEC witness-decision call on P attached to cap(Q), returning a boundary witness iff S(P) intersects Q. Make first query Q={0,1}; if NO, query complementary {2,3}. If both NO, S empty. Once a positive witness is found, one Kempe path acquires a different type, so two distinct actual witnesses are available without another CEC query. Query the complementary two types. If NO, the two known types are exact support. If YES, store a third actual witness and classify universal. Thus <=3 ordinary CEC witness-decision calls suffice (not a claim that those calls are free or P). A child UNKNOWN cannot be interpreted as NO. The implementation below requires all its cap queries to return exact answers.

For original G=A joined to B, choose smaller side A, acquire its class as above. Empty -> NO. Otherwise replace A by its pair cap or fixed universal square and solve one ordinary capped B child. Pair cap gives exact equivalence and direct lift. Universal cap gives decision equivalence even if actual type support differs. If a returned B witness has a type outside the three stored A types, perform the one-path Kempe change in B; its new type differs and hence belongs to the three stored types. Use corresponding actual A witness, permute its colors (or B's) and join original indexed edges. Verify every source edge and vertex. This one-switch lifting does not require re-solving A, searching Kempe classes, or preserving a previous guarded state. A recursive lift returns an actual coloring of that node's whole unguarded graph before its parent projects it. If a prior cap is recolored during lift, it is still a valid unguarded coloring; stored internal witnesses are used only at the applicable reverse substitution. No counting conclusion.

## 4. Aggregate recurrence, including unbalanced cuts
Let n be vertex count of current connected simple cubic node, s smaller side, 36<=s<=n/2. Cut acquisition enumerate four-edge subsets and compute components after deletion, test exactly two connected sides with precisely those crossing edges, choose deterministic first eligible cut; O(m^4 poly(n)) paid work. All recursive query graphs remain simple cubic and have <=s+18 (at most three queries) or <=n-s+18 (one query) vertices. Let x=s/n. Since s>=36, s+18<=1.5s and n-s+18<=n-s/2. With mu=n and c=5,
sum child mu^5 <= n^5[3(1.5x)^5+(1-x/2)^5].
The bracket is convex on [0,1/2], with endpoints 1 and 243/256. Hence it is <=1-(13/128)x, so sum child n_i^5 <= n^5-(13/128)s n^4 <= n^5-1. This is the user's sufficient productive recurrence even for highly unbalanced cuts. No shared memoization needed. Disconnected factors also satisfy sum n_i^5 <= n^5-1 for genuine splits. The same argument allows fewer than four actual children and early NO. Each node performs polynomial authentication, bridge/blossom support, deterministic cut discovery, cap construction and witness checking. Constant-size leaf exact search is allowed; known exact polynomial leaf terminals (including a found even factor) are allowed. On graphs where no admitted terminal or productive cut exists, return UNKNOWN, not UNSAT. With deterministic policy and UNKNOWN propagation, even the incomplete procedure has <=n^5 nodes. On the hereditary admitted class where every generated cap child terminates exactly, this is a uniform deterministic polynomial decision and reconstruction algorithm. It does not assume balanced separators or that merely the original source has a small cut.
