## 2. Main lemma: productive three-cut co-cycle composition
For connected bipartite cubic multigraph H define P(H) = for EVERY pair of distinct indexed edges there is an actual common-cycle spanning 2-factor. Permit coincident marks in recursive calls; then any factor containing that one edge suffices. Such a factor is acquired polynomially by decomposing bipartite cubic graph into three perfect matchings or matching with one excluded edge. Suppose an exact two-edge or three-edge cut separates connected sides A,B. Let a,b be numbers of cut incidences on left/right bipartition within a side, so a+b=k and 3(|L|-|R|)=a-b. For k=2, a=b=1 and cap by a single edge. For k=3, all cut incidences in a side lie in one bipartition, so cap by a new opposite-part vertex joined to the three ends (parallel edge IDs allowed). Each capped child is connected cubic bipartite. For three-cuts use only nontrivial sides s>=3; singleton cuts are skipped.

For two-cuts, the cut is either wholly in or wholly out of any spanning factor. Known Diwan proof: if marks split sides, solve each marked edge plus its cap edge, then join by replacing cap edges with original seam edges. If marks same side or on seam, map seam marks to cap edge and solve one side; fill other using any matching containing or avoiding cap edge as required. Any other cycles stay intact. This includes two marks both on seam (same cap edge).

For three-cuts, each factor contains exactly two seams: the cap vertex has factor degree two; equivalently odd-cut parity and perfect matching intersects the cut in one edge (all cut incidences on one side of bipartition). Let labels {0,1,2} identify the original seams. If both marks lie within one side or one/both on seam, choose side containing both after seam-to-cap mapping; solve there, get selected seam pair P. Fill other side using an ordinary bipartite perfect matching containing its omitted cap edge. Any edge belongs to some perfect matching, proved constructively via bipartite regular decomposition, no oracle. The cap-vertex cycle opens into a path; replacing with other side's path preserves marks.

If marks split strictly inside sides, take smaller capped side A' and its mark a. Query common-cycle witness for a and cap edge 0, obtain selected pair P. Query a and the unique seam j absent from P, obtain a different selected pair Q. Both are two-element subsets of {0,1,2}, hence share exactly one seam h. Now query the LARGER side B' once, for its own mark b and cap edge h. Its selected pair T contains h, hence T equals P or Q. Select the stored smaller witness matching T, remove cap vertices, join original indexed seam edges. The two marked cycles are now one, other cycles unchanged. All witnesses actual, no assumed arbitrary independent seam support. This proves closure of property P under 3-edge sums and a constructive algorithm with two smaller queries and one larger query. More general on a particular residual: successful child witnesses suffice, regardless of P on all pairs. If a required child is unresolved, return UNKNOWN, never reject original.

## 3. Square reduction and exact admitted recursion

Opposite bipartition ensures no loops. Distinct IDs permit parallel seams. The reduced graph is connected: if disconnected, each component of the exterior incident to a new seam has both its ends and thus at least two original spokes; two components would give a 2-edge cut in H. A component without spokes would already be disconnected in H. Retain actual port map, map spoke marks to appropriate new seam(s); they may coincide. Lift a factor as follows: if neither cap edge selected, add square as isolated cycle; if one selected, replace it with the three-edge square path plus its two spokes; if both selected, replace each with its own adjacent internal edge plus two spokes.
