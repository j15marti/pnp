\section{Recovered progress and the exact target}
The recent ARC228, TREE227 and referee204 reports establish exact composition given a source-authenticated tree with small full interfaces and fixed local affine codimension \cite{ARC228,Tree227,Ref204}. The paired mixed-port cycle230 shows that requiring every original bridge clause in an UNSAT support does not imply expensive decision: its exact binary relations have a polynomial composition. The earlier wrapper reports establish consequences of favorable contraction premises, without establishing those premises on all SAT inputs. These are distinct results.

An older component, BOUNDARY-RANK-SWITCH80 \cite{Rank80}, already replaces local affine nullity by the dimension of the affine image actually observed by constraints. The present work \emph{combines} this idea with full-interface tree composition and uses residual private rank after substitution. The question is whether full boundaries can be large while their feasible affine profiles and local residual costs remain small. The answer is yes on the explicit recognized subclass below. This does not supply the all-input compiler.

\section{Inputs, quantifiers and machine model}
Let
\[
 F=\bigwedge_t\bigl(C_t\wedge[A_tx=c_t]\bigr)
\]
be an explicitly encoded conjunction of width-at-most-two clauses and affine equations. Each source constraint has a unique ID and is owned exactly once in a supplied rooted tree of bags $X_t$. Its full scope belongs to its owner bag. Every variable's bags form a connected subtree. All declared variable names and all IDs are checked. Let $N$ be the physical source length and $L$ the source plus certificate length. In a source-first application the constructor must produce and validate the certificate with charged cost $D(N)$. A certificate is not a free oracle.

Let $B_t$ contain \emph{all} variables of $X_t$ that occur in another bag, $b_t=|B_t|$, $I_t=X_t\setminus B_t$, and $i_t=|I_t|$. The separator to the parent is $S_t$. Full boundaries are used to perform local joins; messages can subsequently be projected onto $S_t$. Parent separators alone do not bound the row enumeration at a high-degree node.

There is one fixed deterministic uniform program, for every valid source and every valid supplied decomposition, implementing the algorithm below. It does not receive a SAT/UNSAT indicator. Without resource caps it is exact, although potentially exponential. The supplied reference implementation optionally returns \texttt{UNKNOWN} when a computed profile-row budget is exceeded; this is never interpreted as UNSAT. Invalid certificates are rejected as invalid, not as a decision about the source formula.

Time and writable storage refer to the same fixed finite-tape deterministic implementation with read-only original input. Sorting and merging explicit records implements joins without free random access. All matrix entries, keys, source reads, failed trials, table rows, backpointers and output are charged. The Python program checks finite semantics and logical counters; it does not count native tape head moves. Only polynomial prefactors are claimed, not the near-linear time or sublinear space needed for an ARC endpoint.

\section{A feasible-profile composition theorem}
Let $A$ be the conjunction of \emph{all original} affine equations. Gaussian elimination either detects inconsistency, giving an exact NO, or constructs
\[
 \mathcal S(A)=a+\operatorname{im}G.
\]
No 2CNF clause is discarded or replaced by its affine hull. Define
\[
 P_t=\pi_{B_t}\mathcal S(A),\qquad
 d_t=\dim P_t=\operatorname{rank}(\pi_{B_t}G),\qquad
 r_t=\operatorname{rank}(A_t[:,I_t]),\quad u_t=i_t-r_t.
\]
The dimension of a nonempty affine space means the dimension of its direction space. Bases for $P_t$ are obtained by explicit projection and elimination; they are not guessed semantic summaries.

\begin{lemma}[Projection dimension]
For a consistent affine system on coordinates $B\sqcup J$, with matrix $M$, the dimension of its projection onto $B$ is
\[
 |B|-\operatorname{rank}M+\operatorname{rank}M[:,J].
\]
Every feasible pin of the boundary of module $t$ leaves its private affine matrix with rank exactly $r_t$ and private nullity $u_t$.
\end{lemma}
\begin{proof}
The full solution direction space has dimension $|B|+|J|-\operatorname{rank}M$. The kernel of coordinate projection restricted to that direction space consists of the vectors with zero $B$ coordinates and dimension $|J|-\operatorname{rank}M[:,J]$. Rank-nullity gives the formula. Pinning a boundary changes the right-hand side and deletes its columns; it does not append $b_t$ new independent rows. For any feasible pin the remaining coefficient matrix is exactly $A_t[:,I_t]$.
\end{proof}

Put
\[
 W_t=\min\{(i_t+1)^{r_t+1},\;2^{u_t}\}.
\]
The first alternative conservatively bounds the inspected branching backend, which may revisit pivot orders. The sharper binomial bound of the published algorithm is not silently substituted for that backend's bound.

\begin{theorem}[Full-boundary affine profiles; restricted]
For every valid source and decomposition as above, there is a fixed deterministic exact algorithm with
\begin{align*}
 T&\le D(N)+\poly(L)\left(1+\sum_t2^{d_t}W_t\right),\\
 S_{\rm peak}&\le\poly(L)\left(1+\sum_t2^{d_t}\right).
\end{align*}
In particular, polynomial discovery and certificate size, $d_t=O(\log N)$, and, for each module, either uniformly fixed $r_t$ or $u_t=O(\log N)$ give polynomial total time and space. The branch may differ between modules and states; it is selected from computed parameters without knowing the answer.
\end{theorem}
\begin{proof}
First compute all bases $P_t$. This requires polynomial time and space in $L$, even if the global affine rank is large. Enumerate exactly the $2^{d_t}$ distinct full-boundary rows in $P_t$, not $2^{b_t}$ arbitrary rows. For each row, look up all child messages on the complete shared intersections. If a lookup fails, reject the row. Otherwise substitute its boundary values into all local clauses and affine rows before solving the private problem.

This private problem is 2CNF with affine rank $r_t$. A deterministic fixed-codimension algorithm supplies $(i_t+1)^{r_t+1}\poly(L)$ conservative cost \cite{AG2021}; direct enumeration of the affine fiber supplies $2^{u_t}\poly(L)$ cost. Both alternatives have polynomial workspace. The cheaper proved upper bound selects the route. Every failed call and every candidate is counted. An accepting row stores a private witness and compatible child backpointers; the message retains a witness for each feasible parent-separator key, including the empty tuple.

For exactness, add the explicit local constraints $B_t\in P_t$ to form $F^+$. Each is a consequence of $A$, so $F^+$ and $F$ have \emph{identical full assignments}. The table algorithm is ordinary exact tree dynamic programming for $F^+$, with the local private test implemented as above. Running intersection ensures that assignments from distinct child subtrees can conflict only on a variable present in their connecting bags, and every such value is fixed by the full boundary. Induction over the tree proves message exactness for $F^+$. No relation is replaced by a relaxation. At the root, any surviving row gives a model, and an empty root table proves that none exists. Reconstruction follows stored rows and checks every original source constraint.

It is important that messages are exact for the \emph{augmented} subtree problem. They can use affine information from elsewhere in the source. They are not claimed to be source-free summaries supporting arbitrary future continuations after the source is discarded.

For the time bound, emit one parent-projection record per candidate row and child. Sort and merge these records against child tables; the degree and sorting overhead are polynomial in $L$, since every row and key has polynomial length and the logarithm of the row count is at most polynomial in $L$. Record sorting avoids multiplying two exponential row counts. Add the private-call costs and discovery. Tables, row witnesses, backpointers, bases and a depth-first local backend give the space bound. Original input, indexes and temporary matrix storage are included in its polynomial factor.
\end{proof}

\section{Source-first discovery on an unbounded mixed subclass}
The new recognizer receives only the physical mixed source, not a proposed tree or an answer. Its accepted grammar is deliberately limited. Binary affine rows form connected groups of shared variables. Every remaining affine row contains exactly two names outside those groups, private to that row, and meets one or two groups in one representative each. Every group meets exactly two such rows, and their incidence gives a simple connected path. Every 2CNF clause must fit a resulting bag. All original clauses, including units and duplicate occurrences, are assigned an owner and retained.

Connected components of the binary-row graph, row scopes, source-name multiplicities and path validation construct the bags in polynomial time. A group is included in its two endpoint bags, and its internal binary rows are assigned once. A nonbinary row and its two private variables belong to one module. Clauses are assigned to a bag containing their full scope; otherwise recognition returns \texttt{UNKNOWN}. This directly verifies running intersection and exact source coverage.

If the global affine system is consistent, each binary group has one free representative bit. The two private variables in each nonbinary row can absorb any values of its incident group bits. Thus groups are independently free in the affine projection, every bag has $d_t\le2$, and its residual private affine rank is $r_t=1$. Consequently the entire accepted subclass has a polynomial source-first exact solver. This is a concrete acquisition result for this grammar, not an acquisition theorem for arbitrary 3SAT or strict exact-$(2,2)$ inputs.

\section{An infinite paired family and parameter separation}
Take a path of $k\ge2$ modules and a group of $w\ge2$ copies of one shared bit on each edge. Affine equalities tie the copies in each group. Module $t$ has two private variables $u_t,v_t$, units $u_t=v_t=1$, and one row
\[
 u_t\oplus v_t\oplus z_{t-1}\oplus z_t=\eta_t,
\]
with absent endpoint bits interpreted as zero. Binary equality clauses on the shared copies occur at both incident modules. All $\eta_t=0$ gives SAT. Setting only the last $\eta_t=1$ gives UNSAT, since the first equation forces the edge bit to zero and that value propagates to the last equation.

The exact counts and parameters are
\begin{gather*}
 n=(k-1)w+2k,\qquad m=3k+5(k-1)(w-1),\\
 \operatorname{rank}A=(k-1)w+1,\qquad
 \operatorname{nullity}A=2k-1,\\
 \max_t b_t=2w\ (k\ge3),\quad \max_t d_t=2,\quad r_t=u_t=1,\\
 \sum_t2^{d_t}=4k-4,\qquad
 \sum_t2^{b_t}=2^{w+1}+(k-2)2^{2w}.
\end{gather*}
The equations are independent after taking one copy variable per group and one private pivot per module. Their incidence is connected, and every variable occurs in the 2CNF. Thus BOUNDARY-RANK80's \emph{single whole-affine-component} observed dimension is $2k-1$ here, while the full-bag affine-profile dimension is at most two. This improves the stated estimates for the retained representations; it does not assert that an older algorithm with further preprocessing could not also solve this easy family.

With $k=w$ the sparse source and certificate size are $\Theta(k^2\log k)$, while raw boundary width and global affine nullity grow with $k$. The Python interchange uses dense integer masks in JSON and reports its actual byte length separately; those bytes are not identified with the sparse encoding bound.

\section{Why recursive language closure and all-input coverage remain open}
An elementary closure obstruction strengthens the interpretation of the earlier majority counterexample, without claiming priority for its gadget. On three retained ports,
\[
 \exists a,b\;[(x\vee a)\wedge(y\vee b)\wedge(a\oplus b\oplus z=1)]
 \quad\Longleftrightarrow\quad x\vee y\vee z.
\]
When $x=y=0$, both private variables must be one and the row forces $z=1$. If either $x$ or $y$ is one, a private variable is free to satisfy either parity. The resulting seven-point relation has the full affine hull $\F^3$, and each of its binary coordinate projections is the full square. Hence its strongest affine consequences and strongest unary/binary consequences are all tautological. It cannot be expressed as a conjunction of 2CNF and affine equations \emph{on those three ports alone}, even allowing arbitrarily many equations. Allowing fresh private variables reintroduces the original gadget; the obstruction is not against auxiliary-variable representations.

The profile DP avoids requiring this language closure: it preserves exact child tables and tests them at full boundary rows. That helps only while their feasible profile volume remains affordable.

For an arbitrary proper 3CNF $\bigwedge_j(\ell_{j1}\vee\ell_{j2}\vee\ell_{j3})$, use a fresh pair $a_j,b_j$ in the displayed gadget for each clause. This is a polynomial \emph{expansion}, not a contraction. Make a star whose central bag contains all original variables and whose leaf bags contain the three ports and the private pair. Every original-variable assignment extends to the affine equations alone by choosing each private pair. Thus, with $n$ occurring source variables,
\[
 \dim\pi_{\rm centre}\mathcal S(A)=n.
\]
The source is in the mixed language, but this canonical decomposition retains $2^n$ central profiles. The bounded-dimension premise is therefore not automatically supplied by the standard clause gadget. This falsifies only that candidate universal parameter bound, not other decompositions or semantic contractions.
