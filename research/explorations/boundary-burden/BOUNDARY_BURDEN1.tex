\section{What is being measured}
Every test source is connected proper 3CNF with exactly two positive and two negative occurrences of every variable. If there are $n$ variables and $m$ clauses, then $3m=4n$, so $n$ is a multiple of three. Fix a static boundary $Y$, $b=|Y|$, and pairwise disjoint private modules $Z_i$. Every source clause is assigned once, all private names occur in their own module, and no clause contains private variables from two modules. A local set $H_i\subseteq Z_i$ must hit every source ternary clause in its module that avoids $Y$. Set $q=\max_i|H_i|$ and $s=b+q$.

This is the original archive's \emph{syntactic 2CNF-backdoor} condition \cite{archive}, not a backdoor into a solver allowed arbitrary propagation, semantic simplification, Horn recognition, XOR elimination or changing interfaces. The strong-backdoor literature explains the familiar parameterized algorithms under their stated syntactic hypotheses \cite{nrs2004}; it does not make $s$ a universal runtime lower bound.

For each fixed $Y$, private components of the source primal graph after deleting $Y$ give the finest allowed partition. Every valid private module is a union of these components: two private names in the same source clause must remain together. Merging components adds their disjoint hitting requirements and cannot reduce the largest local minimum. Therefore enumerating \emph{all} boundaries and finding exact local hitting minima on these components really does optimize $b+q$ over the entire original static architecture.

\section{The proposed minimization is correct}
The original inequalities are
\[
 k\le4b,\qquad n\le3\left(b+\sum_i|H_i|\right)\le3b+12bq
 \quad (b>0).
\]
Thus $b(q+1/4)\ge n/12$ and arithmetic--geometric mean gives
\[
 \boxed{b+q\ge\sqrt{n/3}-\tfrac14.}
\]
Equivalently, differentiating $b+n/(12b)-1/4$ gives $b^*=\sqrt{n/12}$. The associated relaxed $q$ is $q^*=b^*-1/4$. This is an optimum of a \emph{necessary-condition relaxation}; it does not construct an actual decomposition at that point. For integer parameters the bound can be rounded upward. The case $b=0$ is handled separately by connectedness and the global hitting count, giving $q\ge n/3$.

\section{A stronger count from connectedness}
Let $h$ be the number of source clauses contained entirely in $Y$. Count only private modules with at least one variable.
\begin{lemma}[Quotient incidence count]
Under the same static assumptions,
\[
 \boxed{k+h\le3b+1.}
\]
This includes $b=0$, in which case $k=1$.
\end{lemma}
\begin{proof}
Starting from the connected variable--clause incidence graph, identify all private names in a module and all clauses containing such names with a single module vertex. This identification preserves connectedness, even if an allowed module groups several components. Retain the $b$ boundary vertices and the $h$ boundary-only clause vertices. There are $b+k+h$ vertices in the resulting connected multigraph. Each original boundary variable has exactly four incidences, and every surviving edge is such an incidence; hence there are $4b$ edges, counted with multiplicity. A connected multigraph has at least one fewer edge than vertices. Therefore $b+k+h-1\le4b$.
\end{proof}

\begin{theorem}[Sharper combined burden]
For every connected strict exact-(2,2) source and every original static decomposition,
\begin{align*}
 n&\le3b+3(3b+1-h)q\\
  &\le3(b+q)+9bq\\
  &\le3s+\tfrac94s^2.
\end{align*}
Consequently
\[
 \boxed{s\ge\frac23\bigl(\sqrt{n+1}-1\bigr).}
\]
This improves the asymptotic leading constant from $1/\sqrt3\simeq0.57735$ to $2/3\simeq0.66667$. For very small continuous values one may retain the maximum of the two bounds; the new bound is stronger on the tested sizes $n\ge15$.
\end{theorem}
\begin{proof}
The hitting set $Y\cup\bigcup_iH_i$ meets all $m$ source clauses, and each of its variables meets at most four clauses. Thus $n\le3(b+\sum_i|H_i|)\le3b+3kq$. Apply the lemma, drop the nonnegative $3hq$, and use $bq\le(b+q)^2/4$. Solving the resulting quadratic for the nonnegative $s$ proves the claim. All quantifiers concern the declared static decomposition, not arbitrary SAT algorithms.
\end{proof}

For integers, a useful exact necessary condition is
\[
 n\le3s+9\lfloor s^2/4\rfloor.
\]
The auditor computes the least integer $s$ satisfying this inequality directly. Since valid $n$ is divisible by three, it equals the ceiling of the displayed new continuous bound: when $s$ is odd, the integer capacity is $9/4<3$ below the continuous capacity, too little to skip another admissible multiple of three. This is exact for the arithmetic relaxation, not for every source's minimum burden.

For example, at $n=600$ the old arithmetic relaxation permits $(b,q)=(7,7)$, giving $s=14$, because $3b+12bq=609$. The sharper connected count rules that pair out: $3(b+q)+9bq=483<600$. The new integer floor is $s\ge16$. A pair passing this sharper inequality still need not be realizable by a source decomposition.

\section{Actual sources and search procedures}
\paragraph{Small exact optimization.}
The original periodic signed cyclic sources at $n=6,9,12,15$ and the authenticated $15$-variable, $20$-clause UNSAT source $W_1$ were tested. Its balanced sign mutation $V$ has the same unsigned clause scopes. Source programs are preserved byte-for-byte in \path{inputs/}. Exhaustive assignment enumeration finds zero models for $W_1$ and $54$ for $V$.

Every one of the $2^n$ boundaries is evaluated on each small source. A memoized exact ternary hitting-set recurrence branches on a variable of an unhit source clause; every possible hitting set must make one of those choices. The recurrence returns an explicit hitting set and its minimum cardinality. Every returned set is checked against all its local clauses. Across the five source patterns this gives $70{,}208$ complete boundary evaluations. The two sign-mutant sources have identical results for \emph{every} boundary because components and these hitting requirements depend only on unsigned scopes; that identity is not counted as a second independent enumeration.

\paragraph{Larger connected pairs.}
MIXED-PORT-CYCLE230 \cite{cycle230} supplies opposite-label sources with $n=60,120,240$ and identical unsigned scopes. The search tests every number of equally spaced block-port cuts from zero through the number of blocks. MATCHED-TORUS-BRIDGE232 \cite{torus232} supplies opposite-label connected pairs at $n=81,189,621$; the search tests zero boundary, selected two-column torus cuts, and the fixed connector-variable boundary. These are explicit candidate collections, not all subsets of the larger variable sets.

Local hitting sets on the larger sources are obtained with SciPy's HiGHS-backed integer optimizer, using a one-second limit per local solve and a deterministic greedy fallback if no incumbent is returned. Every selected hitting witness is checked directly. All reported best candidates happened to have solver-optimal local statuses, but no independent integer dual certificate was extracted. Their displayed $s$ values are therefore \emph{achieved upper bounds} on the best structural burden; they are not advertised as globally exact optima over boundaries. The source-independent lower bounds do not rely on optimizer output.

\paragraph{Independent decisions.}
A separately coded ordinary DPLL procedure uses unit propagation, maximum short-clause occurrence, a fixed variable-name tie break, and paid component factoring. The same program handles both answer classes without a supplied label. A $5000$-node cap returns \texttt{UNKNOWN} rather than guessing; none of these runs reached it. Positive assignments are checked against every original source clause. Negative results arise from exhaustive branching within the actual search, not assignment repair or a known-label shortcut. Node counts include recursive component calls. They are not native TM time or measured workspace.

\section{An explicit runtime-interpretation control}
The periodic exact22 source at $n=600$ has a minimum global syntactic 2CNF-backdoor of $200$, and the refined theorem requires every static architecture to have $b+q\ge16$. Nevertheless the independently rerun moving-frontier dynamic program decides it with width four, at most $13$ simultaneously feasible states on this source, and $15{,}512$ transition candidates. It performs actual source parsing and clause checks; the counters are not machine instructions.

No contradiction occurs. The quantity $2^{b+q}$ is an enumeration expression for one prescribed strategy. Its large value does not prove that even an early-stopping static implementation must execute every entry. A moving-frontier solver, factoring, semantic summary, or different tractable leaf language can bypass the static syntactic representation. A source-sign-insensitive structural descriptor also need not classify SAT versus UNSAT to be a useful upper-bound parameter, but it cannot by itself establish an all-algorithm lower bound.

\section{Provenance, checks and scope}
The original \path{Connected_Interface_Audit.zip} was freshly resolved and materialized, and its unchanged \path{audit.py} reproduced the archived JSON exactly: $4680$ boundary checks, $7191$ local checks, and $139$ truth comparisons. Those older counts are separate from the new $70{,}208$ exhaustive boundary evaluations. Each new stage records code SHA-256, the three unchanged source-program hashes, actual wall time, raw decisions, integer witnesses and search parameters. Stage invocations remained under three seconds in this run and were independent; no long uncheckpointed search was required. Timing fields need not reproduce byte-for-byte.

Malformed or incomplete static decompositions are outside the theorem, not counterexamples. The graph proof retains boundary-only clauses and counts parallel incidences. The $b=0$ case is included explicitly. Larger candidate searches are never called exhaustive boundary optimization. Floating optimizer status is distinguished from exact small hitting minima. Renaming and sign mutation cannot change the unsigned structural burden, although variable ordering can change DPLL performance.

The current repository tree and root synthesis, the original archive, prior mixed-cycle and matched-torus source programs, and the immediately preceding affine-profile work were reviewed. Searches for the sharper $3b+1$ and $9bq$ forms found no matching prior theorem in the returned corpus results; no worldwide novelty claim is made for the elementary quotient count. The previous $4b$ theorem is retained as valid but weakened. This Codex experiment has no authorized executive ownership region. The current living root lacks the older specialist marker pattern expected by the preflight script, so preflight reports those marker failures; no unowned root repair is attempted and no global hygiene success is claimed.

This is a finite combinatorial statement and restricted-architecture audit. An arbitrary oracle decider need not construct any of the modules or hitting sets. There is no nonrelativizing or algebrization barrier crossing, no Natural-Proofs circuit property, no cryptographic hardness assumption, and no transport of a graph parameter into a native time--space forbidden region. Input length, candidate acquisition and both SAT/UNSAT computations remain explicitly separated.

\section{Next mathematical target}
Determine the tight attainable minimum of $b+q$ on a specified increasing connected strict22 family, including a decomposition achieving the proposed order and an exact source-dependent obstruction to a better static decomposition. Any proposed implication for general SAT runtime additionally needs a theorem forcing arbitrary exact deciders to incur the static resource; that bridge remains open.
