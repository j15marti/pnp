# CLEANCORE-POLY1 — Polymorphisms and 3-SAT Expressiveness of the Mediator-Eliminated 7-State Language

**Date:** 2026-10-05

This note follows CLEANCORE-EVAL1 and CLEANCORE-EXT1. It classifies the finite relation language generated by eliminating low-degree outside mediators from bare type-1 chains, tests several standard tractable polymorphism signatures, and gives a direct reduction from arbitrary 3-SAT into the ambient binary sublanguage.

The main result is not a lower bound. It is a structural classification:

\[
\boxed{
\text{the ambient mediator-eliminated 7-state language retains full 3-SAT expressive power.}
}
\]

A separate unresolved question is whether the **strict residual clean-core subclass**, after every cheap/direct pair/triple correlation and preprocessing rule is credited, still realizes the gadgets used below.

# 1. The 7-state domain

Let

\[
D=\{0,1\}^3\setminus\{000\}.
\]

A type-1 chain state is one element of \(D\), interpreted as the truth values of the three literals of its local positive 3-clause.

Thus

\[
|D|=7.
\]

For \(s\in D\), write \(s_i\) for coordinate \(i\in\{1,2,3\}\).

---

# 2. Ambient mediator-eliminated relation language

A mediator clause has the form

\[
A(X_u,X_v)\vee y
\]

or

\[
B(X_r,X_s)\vee\neg y,
\]

where \(A,B\) are two-literal disjunctions of bit-literals drawn from two distinct chain variables.

MED-ELIM1 gives, for a positive pair-term \(A\) and negative pair-term \(B\),

\[
\exists y\,[(A\vee y)\wedge(B\vee\neg y)]
\equiv
A\vee B.
\]

Thus one degree-2 mediator produces one relation on between two and four chain variables, described by a clause of at most four chain-bit literals.

Let

\[
\Gamma_{\rm med}
\]

be the finite language of all such relations.

Exact enumeration gives:

| relation arity | number of schemas |
|---:|---:|
| 2 | 324 |
| 3 | 1512 |
| 4 | 1296 |
| **total** | **3132** |

Modulo permutation of relation variables there are 605 schemas:

\[
171+308+126=605.
\]

No two enumerated schemas accidentally collapse to the same relation on \(D\).

# 3. BIN36 — every cross-chain two-literal clause is present

## Lemma BIN36

**Status: PROVED/EXACT.**

For every pair of chain coordinates \(i,j\in\{1,2,3\}\), and every choices of signs \(\alpha,\beta\in\{+,-\}\), the binary relation

\[
R^{\alpha,\beta}_{i,j}(X,Z)
\iff
\ell_i^\alpha(X)\vee \ell_j^\beta(Z)
\]

belongs to \(\Gamma_{\rm med}\).

There are

\[
3\cdot3\cdot2\cdot2=36
\]

such relations.

### Proof

Fix the two-literal clause

\[
Q=\ell_i^\alpha(X)\vee \ell_j^\beta(Z).
\]

Introduce one mediator \(y\) with the two 3-clauses

\[
Q\vee y,
\qquad
Q\vee\neg y.
\]

Both are legal pair-plus-mediator clauses with mediator degree 2.

Eliminating \(y\) yields

\[
(Q\vee Q)=Q.
\]

Therefore the relation defined by \(Q\) is in the mediator-eliminated language. \(\square\)

The exhaustive relation enumeration independently confirms that all 36 occur.

# 4. DUAL3SAT1 — direct 3-SAT reduction

## Theorem DUAL3SAT1

**Status: PROVED/EXACT.**

The CSP over the binary sublanguage

\[
\Gamma_2\subseteq\Gamma_{\rm med}
\]

is NP-complete.

### Proof

Membership in NP is immediate because the domain \(D\) and all relations are finite.

For hardness, let

\[
F=\bigwedge_{a=1}^m
(L_{a1}\vee L_{a2}\vee L_{a3})
\]

be an arbitrary 3-CNF.

Create one CSP variable

\[
X_a\in D
\]

for every clause \(a\).

Interpret coordinate \(j\) of \(X_a\) as the truth value of the literal occurrence \(L_{aj}\).

Because

\[
X_a\in D=\{0,1\}^3\setminus\{000\},
\]

every local clause has at least one true literal.

It remains only to enforce that different occurrences of the same original Boolean variable are globally consistent.

Fix an original variable \(x\). List its literal occurrences in any order:

\[
(a_1,j_1,\sigma_1),\ldots,(a_t,j_t,\sigma_t),
\]

where \(\sigma_r\) records whether the occurrence is \(x\) or \(\neg x\).

It is sufficient to connect consecutive occurrences.

### Same polarity

If \(\sigma_r=\sigma_{r+1}\), enforce

\[
X_{a_r}[j_r]=X_{a_{r+1}}[j_{r+1}].
\]

Boolean equality is equivalent to

\[
(\neg p\vee q)\wedge(p\vee\neg q).
\]

Both binary clause relations belong to \(\Gamma_2\) by BIN36.

### Opposite polarity

If \(\sigma_r\ne\sigma_{r+1}\), enforce

\[
X_{a_r}[j_r]\ne X_{a_{r+1}}[j_{r+1}].
\]

Boolean disequality is equivalent to

\[
(p\vee q)\wedge(\neg p\vee\neg q).
\]

Again both relations belong to \(\Gamma_2\).

Only a spanning path through the occurrences of each original variable is needed, so the number of consistency constraints is linear in the number of literal occurrences.

### Correctness

If \(F\) has a satisfying Boolean assignment, assign to \(X_a\) the three truth values of the three literal occurrences in clause \(a\). Since the clause is satisfied, \(X_a\in D\), and all consistency relations hold.

Conversely, from any satisfying CSP assignment, the equality/disequality chains ensure that every occurrence of each original Boolean variable has one globally consistent underlying truth value. Every \(X_a\in D\), so every original 3-SAT clause has at least one true literal.

Therefore

\[
F\in3SAT
\iff
I(F)\in CSP(\Gamma_2).
\]

The reduction has linear-size overhead. Hence

\[
\boxed{
CSP(\Gamma_2)\text{ is NP-complete}.
}
\]

\(\square\)

This is essentially the standard dual/clause-variable encoding of 3-SAT specialized to the seven satisfying states of a 3-clause.

# 6. Exact finite polymorphism search

The binary language contains 324 named relations.

The experiment searches operation tables that preserve **every** one of them.

These results are machine-exhaustive finite facts about the displayed language; they are not used as substitutes for DUAL3SAT1.

---

## POLY-U1 — unary polymorphisms

Every map

\[
f:D\to D
\]

was tested.

There are

\[
7^7=823543
\]

such maps.

Exactly one preserves all 324 binary relations:

\[
\boxed{f(x)=x.}
\]

Thus the displayed binary structure is a core in this direct finite sense: it has no nonidentity unary endomorphism.

---

## POLY-B2 — binary polymorphisms

**Status: EXACT finite computation with a compact 2-SAT certificate.**

Let

\[
f:D^2\to D
\]

preserve all 324 binary relations.

The relation constraints first force

\[
\boxed{f(a,b)\in\{a,b\}}
\]

for every \(a,b\in D\), and

\[
f(a,a)=a.
\]

Thus each of the 42 ordered off-diagonal pairs has one Boolean choice:

\[
x_{a,b}=
\begin{cases}
0,&f(a,b)=a,\\
1,&f(a,b)=b.
\end{cases}
\]

Preservation of all binary relations induces a 2-SAT instance with

\[
42
\]

Boolean variables and

\[
1764
\]

distinct binary clauses.

Its implication graph has exactly two strongly connected components, and every one of the 42 variables has the same ordered component pair.

Therefore the only two satisfying operation tables are

\[
\boxed{
f(a,b)=a
}
\]

and

\[
\boxed{
f(a,b)=b.
}
\]

Hence the only binary polymorphisms are the two projections.

This immediately rules out any nontrivial binary semilattice polymorphism.

# 7. Ternary tractability-signature tests

The search was then formulated as an operation-CSP over the binary relation language.

For each ternary table entry

\[
f(a,b,c)\in D,
\]

the polymorphism-preservation conditions become binary constraints between operation-table entries. Identity equations are imposed first, then arc consistency is run on the complete finite operation-CSP.

Arc consistency alone derives an empty domain for each tested identity system:

| identity type | operation-table equivalence classes | result |
|---|---:|---|
| majority | 343 | **refuted** |
| Maltsev | 343 | **refuted** |
| weak near-unanimity \(3\) | 259 | **refuted** |
| cyclic \(3\) | 119 | **refuted** |

Thus the binary language admits none of these ternary polymorphisms.

Additional complete candidate-family scans also found:

- 0 of all 5040 total-order semilattice/min operations preserve the language;
- 0 of all 5040 total-order median-majority operations preserve the language;
- 0 of all 5040 cyclic-\(\mathbb Z_7\) Maltsev labelings preserve the language.

These are consistent with DUAL3SAT1.

# 8. What these polymorphism results do and do not establish

Zhuk's CSP dichotomy work characterizes finite-domain tractability in terms of suitable weak-near-unanimity polymorphisms, and Bulatov independently proved the finite-domain dichotomy.

The present computation rules out several low-arity standard tractability signatures.

However:

\[
\boxed{
\text{absence of WNU}_3
\text{ alone is not the full dichotomy test}.
}
\]

A tractable finite language could, in principle, have its relevant polymorphisms only at other arities.

We therefore do **not** infer NP-completeness from the finite low-arity polymorphism search.

NP-completeness here follows independently from the explicit DUAL3SAT1 reduction.

# 9. Important clean-core caveat

DUAL3SAT1 classifies the **ambient language generated by the displayed low-degree mediator schema**.

The BIN36 gadget realizing a two-literal relation uses

\[
Q\vee y,
\qquad
Q\vee\neg y.
\]

Resolving on \(y\) immediately exposes the direct pair constraint \(Q\).

This is a deliberately simple degree-2 mediator gadget.

The current exact-exponential program has already credited cheap direct pair/triple correlations before isolating the residual externally mediated clean core.

Therefore it is not yet justified to claim:

\[
\boxed{
\text{the strict post-processed residual clean-core subclass is NP-hard}
}
\]

from DUAL3SAT1 alone.

A preprocessing rule that detects such opposite-polarity duplicate pair terms may remove exactly the gadgets used by the reduction.

The next structural question is therefore stronger:

> Can arbitrary 3-SAT still be encoded while respecting all residual-clean-core invariants and forbidding every immediately resolvable/direct pair or triple correlation already credited by the decomposition?

That is OPEN.

# 10. SRAS interpretation

The experiment answers the previous universal-evaluator question in an important way.

For the full ambient relation language,

\[
\operatorname{EXT}_{\Gamma_{\rm med}}
\]

is not an accidentally easy algebraic CSP.

It already contains arbitrary 3-SAT under a direct linear reduction.

So asking for a universal polynomial evaluator for all ambient extension instances is essentially asking for a polynomial algorithm for an NP-complete language.

Under the counterfactual \(P=NP\), such an evaluator exists.

Therefore ambient NP-completeness cannot itself provide the SRAS lower bound.

The program must exploit a stricter structural statement, such as:

\[
\boxed{
\text{every hypothetical polynomial SAT algorithm}
\to
\text{a forbidden source/reuse structure on the residual clean core},
}
\]

or prove that even after all known easy correlation gadgets are removed, the residual clean-core family retains enough NP-complete expressive power in a form that interacts with the SRAS accounting invariant.
