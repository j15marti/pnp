# Part I. Boolean-reduction threshold

## Theorem BRTHRESH1 — Exact exponent reduction needed for polynomial residual work

**Status: PROVED/EXACT.**

Let the initial Boolean scale be (2^n). If a reduction of factor (2^x) leaves residual scale (n^d), then

$
n^d = \frac{2^n}{2^x}.
$

Taking (log_2),

$
\boxed{x=n-d\log_2 n.}
$

Equivalently, defining the residual exponent

$
D(n)=n-x(n),
$

polynomial residual scale is equivalent to

$
\boxed{D(n)=O(\log n).}
$

### Consequences

1. Any fixed residual fraction
   [
   D(n)=\epsilon n,qquad \epsilon>0,
   ]
   gives exponential residual scale (2^{\epsilon n}).

2. Any
   [
   D(n)=\omega(\log n)
   ]
   gives
   [
   2^{D(n)}=n^{\omega(1)},
   ]
   hence superpolynomial residual scale.

3. Therefore an exact polynomial-time route based on this reduction accounting must achieve
   [
   \boxed{x=n-O(\log n).}
   ]

This is an algebraic threshold, not by itself a runtime lower bound. A runtime consequence requires a model-matched theorem connecting residual continuation classes or residual subproblems to actual work.

---

## Lemma BRGROW1 — Weak multiplicative acquisition growth sufficient for superpolynomial cost

**Status: PROVED/EXACT conditional on the stated acquisition sequence.**

Let (A_j>0) be a charged acquisition-cost sequence satisfying

$
A_{j+1}\ge (1+\delta_j)A_j.
$

Then

$
A_r\ge A_0\prod_{j<r}(1+\delta_j)
$

and

$
\log A_r\ge \log A_0+\sum_{j<r}\log(1+\delta_j).
$

Hence if polynomial-time reduction requires (r=n-O(\log n)), and

$
\boxed{
\sum_{j< n-O(\log n)}\log(1+\delta_j)
=\omega(\log n),
}
$

then

$
\boxed{A_r=n^{\omega(1)}.}
$

A fixed geometric ratio (1+\delta_j=q>1) is far stronger than necessary. The ratio may tend to (1).

Examples:

- (delta_j=c/j) yields only polynomial growth.
- (delta_j=(\log j)/j) yields quasipolynomial growth.
- (delta_j=1/\sqrt j) yields subexponential but superpolynomial growth.

**Guard:** No theorem currently proves such a sequence for unrestricted SAT computation.

# Part II. Continuation equivalence and sound reduction

## Definition CE1 — Continuation equivalence

Let (mathcal H) be a set of histories or residual computational situations and let (U) be a declared set of legal future consumers/continuations. Let

$
\Phi(h,u)
$

denote the correct future behavior.

Define

$
\boxed{
h\equiv_U h'
\iff
\forall u\in U,;\Phi(h,u)=\Phi(h',u).
}
$

Let

$
\kappa_U(H)=|H/\!\equiv_U|
$

be the number of continuation-distinguishable classes.

---

## Lemma CONTSEP1 — Continuation-safe summaries must separate inequivalent histories

**Status: PROVED/EXACT.**

Let

$
\sigma:H\to Z
$

be a deterministic summary for which there exists a decoder (D) satisfying

$
D(\sigma(h),u)=\Phi(h,u)
$

for all (h\in H) and (u\in U).

Then

$
h\not\equiv_U h'
\Longrightarrow
\sigma(h)\ne\sigma(h').
$

### Proof

If (h\not\equiv_U h'), choose (u) with
$
\Phi(h,u)\ne\Phi(h',u).
$
If (sigma(h)=sigma(h')), then (D) receives the same pair ((sigma,u)) in both cases and returns the same answer, contradicting correctness. (square)

Therefore

$
\boxed{|\operatorname{range}\sigma|\ge\kappa_U(H).}
$

---

## Corollary NO2K1 — Exact no-(2^k)-reduction criterion for continuation-complete summaries

**Status: PROVED/EXACT in the declared continuation-summary model.**

Suppose (|H|=2^n) and a summary is said to achieve reduction factor (2^k) when

$
|\operatorname{range}\sigma|\le 2^{n-k}.
$

By CONTSEP1,

$
\kappa_U(H)\le2^{n-k}.
$

Thus a continuation-sound (2^k) reduction is impossible whenever

$
\boxed{\kappa_U(H)>2^{n-k}.}
$

Equivalently,

$
\boxed{k\le n-\log_2\kappa_U(H).}
$

**Critical limitation:** (log_2\kappa_U(H)) is an information/state requirement, not a time lower bound. Even (kappa_U=2^n) can in principle be named using (n) bits. This theorem must not be promoted from state distinguishability to unrestricted SAT runtime.

# Part III. Provenance and source lineage

## Definition PROV1 — Source lineage

For a derived object (q), maintain a source lineage (J(q)). The useful refinement is

$
\boxed{
J^{U}_{\mathrm{live}}(q)
\subseteq
J_{\mathrm{sem}}(q)
\subseteq
J_{\mathrm{syn}}(q)
\subseteq
J_{\mathrm{origin}}(q).
}
$

Interpretation:

- (J_{\mathrm{origin}}): everything causally used to produce the object.
- (J_{\mathrm{syn}}): syntax-level dependency.
- (J_{\mathrm{sem}}): semantic dependency.
- (J^{U}_{\mathrm{live}}): source information still relevant to the declared future consumer universe (U).

This distinction is essential because a compact summary may have global origin support but small future-live support.

---

## Result PRIME-LQP-NEG1 — Prime provenance is bookkeeping, not hardness

**Status: PROVED/EXACT negative baseline.**

From `research/explorations/random-challenge/2026-10-02_0839_LSPV5_PRIMELQP1.tex`:

1. Positional prime products can injectively encode a finite event history.
2. If two Boolean expressions compute the same Boolean function, no ordinary Boolean context can distinguish them merely because their provenance labels differ.
3. Deterministic polynomial-trace prime labels and polynomial-length residues/digests are polynomial-time reacquirable by rerunning the source computation.
4. Prime factorization hardness is not chargeable when the generating computation already knows the factors.
5. A provenance-aware consumer that directly reads an artificial tag is using an enriched semantics and does not yield an ordinary SAT lower bound.

Hence

$
\boxed{\text{unique provenance}\not\Rightarrow\text{expensive acquisition}.}
$

PRIME-LQP remains potentially useful only as a SAME_REALIZATION bookkeeping layer.

## Result TRACECLOSE1 — Polynomial transcript functionals are P-closed

**Status: PROVED/EXACT.**

Canonical source:
`research/agents/lspv-4/2026-10-02_0449_LSPV-4_TRACECLOSE1.tex`.

Let deterministic (A) run in polynomial time and let (operatorname{Tr}_A(x)) be its complete standard transcript. For any deterministic polynomial-time transducer (E),

$
G_A(x)=E(x,\operatorname{Tr}_A(x))
$

is in FP.

Thus

$
\boxed{
A\in P
\Longrightarrow
E(x,\operatorname{Tr}_A(x))\in FP.
}
$

Under the counterfactual $P=NP$, applying a polynomial extractor to the full polynomial execution transcript of a polynomial SAT solver remains polynomial.

### Consequence

Generic

$
\text{full polynomial trace}
+
\text{polynomial audit}
\Rightarrow
\text{superpolynomial resource}
$

is **FALSIFIED/RETIRED**.

A surviving extraction theorem must use an independently non-P-closed primitive/necessity theorem rather than mere transcript access.

---

## Result REACQ1 — Same-realization deterministic information can be reacquired polynomially

**Status: PROVED/EXACT.**

Canonical source:
`research/agents/lspv-4/2026-10-01_1546_LSPV-4_REACQ1.tex`.

If deterministic selector (S) runs in polynomial time on static readable input (x), then after discarding (y=S(x)), a later audit can reacquire the same (y) by rerunning (S(x)). Polynomially many audits remain polynomial.

Likewise, any individually addressable deterministic trace coordinate (C_i(x)), or the whole polynomial trace, can be regenerated by rerunning the computation.

Therefore

$
\boxed{
\text{REACQUIRE necessary}
\not\Rightarrow
\text{REACQUIRE superpolynomial}.
}
$

The generic promotion of store-or-reacquire necessity to a superpolynomial lower bound is **FALSIFIED/RETIRED** for polynomial-time deterministic selectors on static readable inputs.

# Part IV. Routed causal accounting

## Theorem RCCN-6 — Store-or-reacquire necessity

**Status: PROVED/EXACT in the declared no-reread/no-reacquisition model.**

Canonical source:
`research/explorations/random-challenge/2026-10-01_RCCN1_ROUTED-CAUSAL-COMPUTATION-NETWORK.md`.

Let a (K)-bit record (X) be generated before a cut. Let retained state contain (s) bits and free side information contain at most (r) bits. After the cut, a delayed coordinate (j\in[K]) is revealed. If no additional (X)-dependent information enters after the cut and the computation must output every (X_j) exactly, then

$
\boxed{s\ge K-r.}
$

Equivalently, if

$
s<K-r,
$

then additional (X)-dependent information must be obtained after the cut.

### Limitation

RCCN-6 proves necessity of reacquisition, not expense of reacquisition. REACQ1 supplies the relevant hostile control.

# Part V. Source-Reduction Accounting System (SRAS)

## Definition SRAS1 — Accounting state

At stage (t), use

$
\mathcal A_t=
(X,K,Y,Z,H,J,P,B,U,\Phi_U,V,\Psi_V,R,E,C,Q,G,L,W,\mathsf A,\Omega_D,\Omega_G,\mathrm{Fate}).
$

Key coordinates for extraction:

- (H): actual derivation/execution history.
- (J): causal/source lineage.
- (B): interface/separator.
- (U,\Phi_U): legal future consumers and their required behavior.
- (R): retained representation.
- (G): DAG reuse/sharing.
- (L): quotient/merge operation.
- (Q): recomputation/reacquisition mechanism.
- (W): recoverability.
- (mathsf A): source access.
- (Omega_D): source of data.
- (Omega_G): source/implementation of computational power.
- (mathrm{Fate}): disposition of information.

---

## Definition SRAS2 — Fate labels

Use

$
\boxed{
\mathrm{LIVE},;
\mathrm{ENCODED},;
\mathrm{LOCALIZED},;
\mathrm{QUOTIENTED},;
\mathrm{COMBINED},;
\mathrm{IRRELEVANT},;
\mathrm{TERMINAL},;
\mathrm{EXTERNAL}.
}
$

- **LOCALIZED:** future-relevant reduction has been transferred into strictly smaller live-source regions.
- **EXTERNAL:** information is supplied by an opaque primitive such as an oracle and is intentionally outside the ordinary source-expansion theorem.

---

## Definition SRAS3 — Valid continuation reduction

For stage states (S_s,S_t), define

$
\boxed{
K_{s\to t}
=
\log_2
\frac{\kappa_U(S_s)}
     {\kappa_U(S_t)}.
}
$

This is independent of the observed runtime. It measures continuation-class reduction, not time saved.

---

## Definition SRAS4 — DAG cost

Do not subtract a reuse credit. Charge each actually computed DAG node once:

$
\boxed{
C(\mathcal D)=\sum_{v\in V(\mathcal D)}c(v).
}
$

Multiple outgoing references to an already-computed node are free uses of that paid object. Recomputation creates new nodes and is charged again.

This avoids double charging and negative “reuse credits.”

---

## Accounting invariant SRAS-NFR — No Free Reduction

**Status: FRAMEWORK INVARIANT / requires a fully formal operational semantics before promotion to a theorem.**

Every future-relevant unit of valid reduction must at every later stage be accounted for as one of:

1. **LOCALIZED** to smaller live source;
2. **ENCODED/COMBINED** in a retained reusable representation;
3. **QUOTIENTED/IRRELEVANT** only after continuation equivalence proves it safe to discard;
4. **REACQUIRABLE** through charged (Q/\mathsf A);
5. **EXTERNAL**, in which case the ordinary source theorem explicitly stops.

This is the bookkeeping form of continuation-safe merging. It is intended to prevent semantic reduction from disappearing from the ledger.

---

## Definition ACQCURVE1 — Acquisition curve

For formula (F), consumer universe (U), and declared ordinary machine model (M), define

$
\boxed{
\mathcal C_{F,U,M}(k)
=
\min_{\mathcal D}
\left\{
C(\mathcal D):
K_U(\mathcal D)\ge k
\right\},
}
$

where the minimization ranges only over legal source-transparent DAGs satisfying the declared SRAS rules.

The desired P-vs-NP-strength target is

$
\boxed{
\mathcal C_{F_n,U_n,M}
\bigl(n-O(\log n)\bigr)
=
n^{\omega(1)}.
}
$

This target is **OPEN**.

# Part VI. Extraction and recursive contraction

## Theorem RECURCLOSE1 — Recursive closure of a fractional SAT shrinker

**Status: PROVED/EXACT CONDITIONAL ACCOUNTING.**

Canonical source:
`research/agents/lspv-2/2026-10-04_1604_LSPV-2_RECURCLOSE1.tex`.

Suppose an (A)-derived deterministic SAT oracle procedure has:

- non-oracle work (n^{r+o(1)});
- at most (n^{\eta+o(1)}) SAT queries;
- every query of length at most (n^{\theta+o(1)});
- fixed (0\le\theta<1);
- the same procedure at every scale;
- no hidden uncharged current-scale call to (A).

Then recursive replacement yields

$
\boxed{
T(n)\le n^{C+o(1)},
\qquad
C=
\max\left\{
r,\frac{\eta}{1-\theta}
\right\}.
}
$

This removes dependence on the original exponent of (A).

**OPEN:** existence of the required source-matched shrinker.

---

## Theorem MULTICHANNEL1 — Charged multichannel recursive closure

**Status: PROVED/EXACT CONDITIONAL ACCOUNTING.**

Canonical source:
`research/agents/lspv-3/2026-10-04_1635_LSPV-3_MULTICHANNEL1.tex`.

For finitely many SAT-call channels (j), where channel (j) makes at most (n^{\eta_j+o(1)}) calls of length at most (n^{\theta_j+o(1)}), all with (	heta_j<1), and local nonrecursive work is (n^{r+o(1)}),

$
\boxed{
T(n)\le n^{C+o(1)},
\qquad
C=
\max\left\{
r,\max_j\frac{\eta_j}{1-\theta_j}
\right\}.
}
$

Again the conclusion is exact accounting; the source-matched channels remain unproved.

---

## Theorem SELECTCHARGE1 — Selector acquisition must be charged

**Status: PROVED/EXACT accounting.**

Canonical source:
`research/agents/lspv-2/2026-10-04_1623_LSPV-2_SELECTCHARGE1.tex`.

If a pruning implementation performs (n^{u+o(1)}) selector operations and each selector invokes a SAT decider of cost (n^{K+o(1)}) on residual size (n^{\delta+o(1)}), then the implementation contains cost

$
\boxed{n^{u+\delta K+o(1)}.}
$

Thus a current-scale selector call (delta=1) does not eliminate the unknown SAT exponent (K).

Low algebraic rank, few signatures, or a structural collision do not supply a SAT-preserving selector for free.

# Part VII. Contractive Source Extraction

## Candidate CSE1 — Contractive Source Extraction

**Status: CANDIDATE / OPEN.**

For every deterministic exact SAT decider (A) in a fixed ordinary source-transparent machine model, and every sufficiently large hard instance (F) of size (N), there exists an effectively acquired source-bound object

$
Q=E(A,F)
$

whose recursively consumable children (Q_1,\ldots,Q_m) satisfy a fully charged channel ledger with:

$
m\le N^{a+o(1)},
$

$
|J^{U}_{\mathrm{live}}(Q_i)|\le N^{b+o(1)},
\qquad b<1,
$

and

$
C_{\mathrm{acquire}}+C_{\mathrm{combine}}\le N^{c+o(1)}.
$

The construction must be:

- exact;
- recursively closed;
- SAME_REALIZATION/source-bound where required;
- wrapper covariant under DEAD/COPY/DELAY/INTERP/RECOMP;
- charged for source access, query writing, normalization, indexing, output, and recomputation;
- free of hidden current-scale invocation of the original solver.

A single-channel form would induce

$
k'\le\max\{c,a+bk\}
$

for an assumed (N^{k+o(1)}) solver, while RECURCLOSE1 gives the stronger fixed-shrinker closure when the construction itself forms a fractional SAT self-reduction.

**This is the principal unresolved extraction arrow.**

$

$

while still having

$
|J^{U}_{\mathrm{live}}(Q)|=\Theta(N).
$

Thus

$
\boxed{
\text{source correspondence}
\not\Rightarrow
\text{source contraction}.
}
$

Similarly,

$
\boxed{
\text{small representation}
\not\Rightarrow
\text{small source},
}
$

and

$
\boxed{
\text{small boundary}
\not\Rightarrow
\text{cheap acquisition}.
}
$

SAME_REALIZATION blocks some illegitimate substitutions but does not defeat deterministic rerun, reread, or compact globally supported summaries.

# Part IX. SRAS extraction trichotomy

## Proposition SRAS-TRI1 — Localization / Summary / Reacquisition classification

**Status: ACCOUNTING CLASSIFICATION, not an unrestricted lower-bound theorem.**

Once valid future-relevant reduction is tracked by SRAS-NFR, every such contribution must be accounted for through one of three computational routes:

$
\boxed{
\mathrm{LOCALIZE}
\quad\vee\quad
\mathrm{SUMMARIZE}
\quad\vee\quad
\mathrm{REACQUIRE},
}
$

where:

1. **LOCALIZE:** live source contracts to strictly smaller recursively useful regions;
2. **SUMMARIZE:** a globally supported reusable representation carries the reduction;
3. **REACQUIRE:** discarded information is later regenerated or reread.

Safe quotienting and irrelevance are not separate hardness routes because they mean the information is genuinely no longer needed under (U).

The purpose of the trichotomy is to isolate the three separate closing lemmas required for a P-vs-NP-strength argument.

---

## Candidate LOCALIZE-BARRIER1

**Status: OPEN.**

If LOCALIZE carries enough reduction, derive a model-matched fractional SAT shrinker satisfying RECURCLOSE1/MULTICHANNEL1 parameters in a forbidden time-space region or another contradiction.

No such arbitrary-algorithm source-localization theorem is currently proved.

---

## Candidate GLOBAL-SUMMARY1

**Status: OPEN.**

There exists an infinite hard 3-SAT family (F_n) such that any ordinary source-transparent globally supported representation carrying

$
n-O(\log n)
$

bits of valid continuation reduction has charged acquisition/update cost

$
\boxed{n^{\omega(1)}.}
$

This is the proposed barrier against a Gaussian-elimination-like compact sufficient statistic for general hard 3-SAT.

It must survive Horn, 2-SAT, affine/Tseitin, bounded treewidth, OBDD/d-DNNF/DP, memoization, DAG sharing, and compact algebraic representations.

## Candidate REACQ-BARRIER1

**Status: OPEN.**

$
\boxed{

}
$

REACQ1 proves that this cannot follow generically from delayed challenge, SAME_REALIZATION, or store-or-reacquire necessity alone.

A valid version therefore requires an independently established hard dependency family or other model-preserving obstruction to cheap rerun/reread.

# Part X. Conditional separation theorem

## Theorem SRAS-SEP1 — Conditional P-vs-NP separation from complete SRAS closure

**Status: PROVED AS A CONDITIONAL IMPLICATION; hypotheses OPEN.**

Assume there is an infinite 3-SAT family (F_n) and a source-transparent ordinary machine model such that every deterministic exact SAT algorithm must, on infinitely many (F_n), acquire

$
k=n-O(\log n)
$

valid reduction, and SRAS-TRI1 can be promoted to an exact exhaustive computational theorem with the following three branch closures:

1. LOCALIZE implies a contradiction through a model-matched recursive contraction theorem;
2. SUMMARIZE requires (n^{\omega(1)}) charged cost;
3. REACQUIRE requires (n^{\omega(1)}) charged cost.

Then 3-SAT has no polynomial-time deterministic algorithm; hence

$
\boxed{P\ne NP.}
$

### Proof

Assume $P=NP$. Then 3-SAT has a polynomial-time deterministic exact solver (A). By the reduction-threshold/extraction hypothesis, (A) must account for (n-O(\log n)) valid reduction on the hard family. By exhaustive SRAS classification, that reduction must be discharged through LOCALIZE, SUMMARIZE, or REACQUIRE. Each branch contradicts polynomial-time computation by the corresponding branch theorem. Therefore no such (A) exists. (square)

**This theorem contains no solved P-vs-NP hinge. Its purpose is to expose the exact obligations.**

# Part XI. Relativization audit

## Known barrier

Baker-Gill-Solovay provide oracles (O_=) and (O_{\ne}) with

$
P^{O_=}=NP^{O_=},
\qquad
P^{O_{\ne}}\ne NP^{O_{\ne}}.
$

Therefore a proof whose load-bearing steps relativize uniformly cannot prove ordinary $P\\ne NP$.

### Candidate nonrelativizing mechanism

An ordinary source-transparent computation expands into explicit primitive implementation. An oracle node

$
y=O(x)
$

has

$
\Omega_G=\mathrm{EXTERNAL}
$

and no ordinary internal source DAG available to the theorem.

A legitimate nonrelativizing proof may therefore stop at EXTERNAL nodes rather than redefining oracle cost. The lower-bound theorem must use the internal implementation of ordinary computation in an essential way.

**Guard:** source dependence alone is not nonrelativization. The theorem must actually fail under maximal semantic-oracle replacement while remaining valid for every ordinary polynomial-time SAT algorithm.

Algebrization remains a separate live barrier.

# Part XV. Relation to current 3-SAT structural work

The separate exact-exponential 3-SAT program has already classified several cheap structural reductions in the current chain framework:

- local chain pruning;
- direct pair/triple correlations;
- sufficiently high-degree outside-mediator branching.

The unresolved structural regime is the low-degree externally mediated clean core.

This family is a natural experimental laboratory for SRAS because known cheap reductions can first be credited, after which one can measure whether a hypothetical or restricted solver proceeds by:

1. LOCALIZE: finding smaller source regions;
2. SUMMARIZE: constructing a compact globally supported sufficient statistic;
3. REACQUIRE: repeatedly reconstructing cross-core information.
