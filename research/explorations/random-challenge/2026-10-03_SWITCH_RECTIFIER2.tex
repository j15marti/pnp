\section*{SWITCH-RECTIFIER2: deeper routed contacts and the switch--routing Pareto frontier}

\textbf{STATUS: PROVED/EXACT model lemma plus COMPUTATIONAL routing constructions. P versus NP remains OPEN.}

\paragraph{Model.}
SWITCH-CONTACT1 considered a depth-two passive contact realization of the quadratic
conflict function
\[
f_{H_n}(x)=\bigvee_{\{u,v\}\in E(H_n)}x_ux_v.
\]
The present experiment permits a directed static rectifier layer between controlled contacts.
Each clause variable may control an entry contact, an exit contact, or both. Every conflict
edge is oriented from an entry-capable endpoint to an exit-capable endpoint, and the static
routing relation may itself be factored through deeper rectifier nodes. Controlled contact
occurrences and static routing edges are charged separately.

\paragraph{Exact endpoint-contact theorem.}
Let \(M=8\binom n3\). For any orientation, partition clause vertices into source-only \(S\),
sink-only \(T\), and mixed \(U\). No conflict edge can have both endpoints in \(S\), and no
conflict edge can have both endpoints in \(T\). Thus \(S\) and \(T\) are independent sets
of the conflict graph.

An independent set is a family of pairwise disjoint falsifying codimension-three subcubes.
Each subcube contains \(2^{n-3}\) assignments, so
\[
\alpha(H_n)\le 8.
\]
Consequently
\[
|S|\le8,\qquad |T|\le8,
\]
and the number of controlled endpoint contacts satisfies
\[
C=|S|+|T|+2|U|
=2M-(|S|+|T|)
\ge2M-16.
\]
For every \(n\ge4\), choose two distinct variable triples. The eight sign patterns on either
triple form an exact cover, and the two clause sets are disjoint. Use one as \(S\), the other
as \(T\), and give every remaining clause both endpoint contacts. This attains the lower
bound. Hence, in the declared endpoint-routed architecture,
\[
\boxed{
C_{\rm endpoint}(n,8)
=
2M-16
=
16\binom n3-16.
}
\]

In particular,
\[
C_{\rm endpoint}(4,8)=48,\qquad
C_{\rm endpoint}(5,8)=144.
\]

\paragraph{Routing experiment.}
For \(D(4,8)\), the conflict graph has 96 edges. Direct oriented routing therefore gives
\[
(C,R,D_{\rm route})=(48,96,1).
\]
The deterministic repeated-pair rectifier factorizer finds no reduction of the 96 static
routing edges. This is only a construction result; it does not prove that an unrestricted
rectifier network cannot be smaller.

For \(D(5,8)\), the conflict graph has 960 edges. A deterministic orientation with the exact
144 endpoint contacts, followed by repeated static OR-subexpression factoring, gives
\[
\boxed{
(C,R,D_{\rm route})=(144,548,6)
}
\]
with 98 static intermediate routing nodes. Expanding every intermediate node back to its
source-clause set verifies exactly the intended oriented conflict relation.

\paragraph{Depth-two comparison.}
For \(D(5,8)\), exhaustive enumeration gives 15,542 maximal bicliques. The fractional
weighted biclique-cover LP has optimum
\[
313.84615384612965,
\]
hence every integral depth-two contact cover needs at least 314 contacts. Together with the
known 605-contact greedy construction,
\[
\boxed{
314\le C_{\rm contact}^{(2)}(5,8)\le605.
}
\]

If one controlled contact is weighted by \(\lambda\) relative to one static routing edge, the
resource objective is
\[
\lambda C+R.
\]
For \(D(4,8)\), the exact depth-two realization costs \(96\lambda\), while the routed
construction costs \(48\lambda+96\). Thus routing is beneficial exactly when
\[
\lambda>2.
\]
For \(D(5,8)\), the routed construction beats the known 605-contact depth-two construction
when \(\lambda>1.1887\), and it is smaller than the LP lower bound for every depth-two
realization once \(\lambda>3.2236\).

\paragraph{Literature interpretation.}
Lupanov's switching-and-rectifier model is the direct classical analogue of this
decomposition into controlled switching and static routing. Modern rectifier-network work
shows that depth-two weighted rectangle/biclique covers and unrestricted rectifier networks
can differ polynomially. This warning is strengthened by the quadratic-monotone-circuit
literature: Jukna, and independently Amano--Maruoka, show that arbitrary monotone circuits
for quadratic functions can be dramatically smaller than single-level circuits. Hence the
depth-two biclique number is not a representation-invariant resource.

\paragraph{Main augmentation.}
The switch formulation now yields a concrete Pareto resource rather than a gate count:
\[
\boxed{
\mathcal R_{\rm switch}
=
(C,R,D,L,B,T,S).
}
\]
The present experiment directly measures \(C\), \(R\), and routing depth \(D\).
The next lower-bound candidate should concern cuts of the routing network, where
multisign continuation incompatibility may force breadth or communication, while allowing
the network to trade contacts against routing.

\paragraph{Limitations and hostile controls.}
The exact \(2M-16\) theorem applies only to the endpoint-routed architecture. A fully
unrestricted contact scheme may reuse variable labels inside topology in ways not captured
here. Static routing minima are not proved. Sequential relays and recomputation are stronger
models. Finally fixed \(m=8\) remains a polynomially structured hostile control, so none of
these results imply unrestricted SAT hardness.
