## 1. Strongest candidate

The strongest surviving version is an **interactive causal audit model**, not yet a standard static language.

An exogenous source

[
G=(R_1,R_2,ldots),qquad R_tstackrel{mathrm{i.i.d.}}{sim}mathrm{Bernoulli}(1/2)
]

emits bits at fixed rate. The source is **blind between snapshots**: skipped bits are not visible to the solver and cannot affect its solve time.

For a fixed deterministic controller (C), solver (A), base input (x), and number of epochs (z), define recursively:

[
	au_1=0.
]

At epoch (i), begin a latch at (	au_i) and capture the next (b_i) fresh bits

[
B_i=(R_{	au_i+1},ldots,R_{	au_i+b_i}).
]

After the latch completes, the controller builds a 3-CNF

[
Phi_i=C_i(x,mathcal T_{<i},B_i).
]

The controller should use (B_i) to select a **partial restriction, audit location, pointer edge, or residual formula**, not a full variable assignment.

The solver returns the exact SAT decision (a_i), and when appropriate a witness (w_i). Let

[
c_i=c_A(Phi_i,mathcal T_{<i})
]

be the actual number of charged machine steps used by (A) in that solve segment. Define

[
	au_{i+1}=	au_i+b_i+c_i.
]

The transcript is

[
mathcal T_A(x,G)=
((	au_i,B_i,Phi_i,a_i,w_i,c_i))_{i=1}^z.
]

A PPC extension associates each epoch with a node or path segment in a dependency DAG and lets (B_i) select future pointer/audit choices.

This definition deliberately distinguishes:

- semantic SAT truth/witness,
- deterministic internal state,
- exogenous random challenges,
- actual solver runtime,
- pointer/pebbling state.

## 2. Theorem CRS-1 — Fresh Snapshot Lemma

Let (mathcal F_t) be the sigma-field generated by the base input, all previously captured (G)-bits, and the machine/controller history through time (t). Suppose (	au) is an (mathcal F_t)-stopping time and the bits after (	au) have not been exposed.

Then for every (bge1),

[
(R_{	au+1},ldots,R_{	au+b})midmathcal F_	au
sim U({0,1}^b).
]

In particular the next snapshot is independent of the entire causal past.

### Proof sketch

Condition on ({	au=t}). This event is measurable from the prefix through (t). The IID source makes (R_{t+1},ldots,R_{t+b}) independent uniform conditional on that prefix. Sum over (t).

**Status:** PROVED/EXACT. This is the standard fresh-future property of an IID process at a stopping time.

## 5. Theorem CRS-4 — Full-Assignment Degeneracy

If (B_i) completely assigns every variable of (Phi_i), the remaining task is formula evaluation rather than SAT search. For a 3-CNF with (m) clauses, checking the assigned formula is (O(m)).

Therefore a load-bearing construction must use (B_i) for partial restrictions, pointer choices, audit positions, or other challenge selection while leaving a nontrivial residual search problem.

**Status:** PROVED/EXACT.

## 6. Theorem CRS-5 — Causal Nondeterminism Does Not Need to Predict Future G

Assume every epoch formula is promised satisfiable, (z(n)) is polynomial, every (Phi_i) has polynomial size, and a witness can be verified in polynomial time.

A causal NDTM can process the game as follows:

1. wait until (B_i) is released and (Phi_i) is constructed;
2. guess a satisfying assignment (w_i);
3. verify (Phi_i(w_i)=1);
4. move to the next epoch.

It never guesses a future (G)-block.

The total nondeterministic time is polynomial in the total explicit transcript size when (z) is polynomial.

Thus true randomness defeats **preprediction**, but not ordinary stagewise nondeterministic witness guessing.

**Status:** PROVED/EXACT.

This is a central correction to the initial intuition.

## 7. Corollary CRS-6 — Polynomially Many SAT Epochs Do Not Imply NEXP

For (z(n)=n^{O(1)}) promised-satisfiable explicit 3-CNFs of polynomial size, the concatenation of all satisfying assignments has polynomial length and is polynomially verifiable.

Hence increasing polynomial (z) does not force nondeterministic exponential time.

If an exact YES/NO vector is required, YES entries have NP witnesses while NO entries require coNP-type certification in general; this still does not become NEXP merely from polynomial (z).

Succinctly describing exponentially many epochs can create NEXP-style problems, but that is the known succinct-representation phenomenon and is not itself a P-vs-NP separation.

**Status:** PROVED/EXACT for the polynomial-epoch certificate claim; KNOWN-THEOREM context for succinct complexity.

## 8. Theorem CRS-7 — Quantifier/Clairvoyance Gap

For (b) fresh future bits (B),

[
Pr_B[exists win{0,1}^b:w=B]=1,
]

whereas

[
max_wPr_B[w=B]=2^{-b}.
]

Thus an existential branch selected **after** a full random transcript is revealed is clairvoyant relative to a witness committed before the random challenge.

This is the same order-of-information distinction underlying MA/AM and online Merlin-Arthur models.

**Status:** PROVED/EXACT.

**Important limitation:** CRS-5 shows that a causal NDTM need not precommit witnesses for *future formulas*. It may legitimately wait until the current challenge is revealed and then branch. Therefore CRS-7 alone is not an NP lower bound.

## 9. Theorem CRS-8 — Timing-Sensitivity Lemma

Assume two deterministic solvers (A) and (A') have the same transcript prefix through epoch (i), but their charged solve times at epoch (i) differ. Assume (G) is blind during both solve segments, so the distinct next capture offsets are determined by the common causal prefix and not by skipped source bits.

Let both next snapshots have length (b). Conditional on the common prefix,

[
Pr[B_{i+1}^{A}=B_{i+1}^{A'}]=2^{-b}.
]

This remains true if the two windows overlap but begin at distinct offsets: equality forces a length-((b+d)) IID block to be periodic with shift (d), leaving (d) free bits out of (b+d).

Hence

[
Pr[B_{i+1}^{A}
e B_{i+1}^{A'}]=1-2^{-b}.
]

**Status:** PROVED/EXACT under the stated blind-source/common-prefix hypotheses.

This formalizes the intuition that runtime differences normally push solvers onto different future random transcripts.

## 10. Proposition CRS-9 — Machine-Relative Transcript Obstruction

Because (	au_{i+1}) contains the actual runtime (c_A(Phi_i)), the map

[
(x,G)mapstomathcal T_A(x,G)
]

depends on the chosen solver (A).

Therefore the requirement “output the exact CRS transcript” is not, by itself, a solver-independent language property.

There are only three immediate repairs:

1. **Solver-relative game:** each solver is judged on its own transcript. Then a faster NDTM may see different future formulas and still be correct.
2. **Reference-solver transcript:** require all machines to reproduce (mathcal T_A) for one fixed (A). Then the task is trace simulation of (A), not ordinary SAT.
3. **External schedule:** choose snapshot epochs independently of solver runtime. Then all solvers face the same challenges, but the model becomes an externally timed online/interactive problem.

**Status:** PROVED/EXACT as a definitional/model obstruction.

This is presently the most important issue revealed by formalization.

## 11. Proposition CRS-10 — Reference-Trace Simulation Upper Bound

If (A) and controller (C) are fixed and their code is available, a universal simulator can reproduce (mathcal T_A(x,G)) by simulating the exact steps of (A) and applying the same snapshot interface.

Thus requiring another machine to match (A)'s timed transcript has an (O(T_A))-type simulation upper bound up to standard universal-simulation/controller overhead.

This measures **faithful simulation/provenance**, not SAT decision complexity.

**Status:** PROVED/EXACT at the ordinary simulation level.

## 13. Literature audit

### Interactive proof / witness chronology

Babai-Moran formalize Arthur-Merlin games and make the order of public randomness and prover messages explicit. Goldwasser-Sipser study private versus public coins. Modern online MA communication and annotated-streaming work proves lower bounds when Merlin's help is constrained by online chronology.

**Transfer classification:** EXACT conceptual model for chronology; no direct SAT lower bound.

### Online Merlin-Arthur

Ghosh-Shah (ITCS 2024) prove new lower bounds in MA communication and the online MA model, with translations to annotated streaming. This is particularly relevant because CRS-PPC separates an untrusted semantic/witness channel from a streaming/online verifier state.

**Transfer classification:** ANALOGY/CANDIDATE for the causal witness-state separation; restricted communication/streaming model.

### Pebbling and memory hardness

Nordström surveys the exact use of pebble games to obtain proof-space and size-space tradeoffs for pebbling formulas. Alwen-Blocki-Pietrzak use cumulative pebbling complexity of depth-robust DAGs to quantify memory-hard computations.

**Transfer classification:** EXACT object-level STORE-vs-RECOMPUTE model; restricted proof/cryptographic models.

### Delay functions

Larsen-Simkin (TCC 2025 proceedings published 2026) study iterated functions (F^T) against adversaries with bounded advice, oracle access, parallel queries, and fewer sequential calls. They prove tradeoffs showing that some round functions resist significant sequential shortcutting unless advice or parallel work is large.

**Transfer classification:** strong architectural analogue for (S_{
m pointer}+C_{
m sequential}); oracle-model theorem, not unrestricted SAT.

### General branching programs / RAM and SAT

Beame-Jayram-Saks prove nontrivial time-space lower bounds for branching programs and related RAM models. Fortnow proves a model-independent forbidden near-linear-time/sublinear-space region for SAT on general random-access nondeterministic Turing machines.

**Transfer classification:** KNOWN lower-bound controls; neither excludes arbitrary polynomial-time SAT.

## 15. Falsification findings

### FALSIFIED/RETIRED

1. “True randomness forces an NDTM to predict future SAT witnesses.”  
   False: a causal NDTM can wait for the epoch formula, then guess its witness.

2. “Polynomially many successive 3-SAT tasks force NEXP.”  
   False for explicit polynomial-size promised-satisfiable epochs; all witnesses concatenate to polynomial length.

3. “Fully assigning the variables from G leaves a hard SAT task.”  
   False: it reduces to formula evaluation.

4. “Different runtime-generated transcripts alone prove a P/NP separation.”  
   False: they show solver-relative provenance, not a solver-independent language separation.

### SURVIVES

1. IID future blocks at causal stopping times are genuinely fresh.
2. Different execution times normally induce different future transcripts.
3. The resulting transcript is a rigorous SAME_REALIZATION/provenance object.
4. Pebbling/pointer structure remains a plausible way to charge STORE versus RECOMPUTE after challenge revelation.
5. Online-MA/stream-verification literature provides a closer formal analogue than ordinary NP for the witness/randomness chronology.

## 16. Missing theorems for the project

### Target CRS-A — Result-Oblivious PPC Lower Bound

Prove a store/track/recover/sequential lower bound even if current SAT decision bits are supplied for free.

### Target CRS-B — Causal Witness Lower Bound

Find a challenge relation where a stagewise nondeterministic witness cannot simply be guessed after each fresh block without itself performing the PPC resource obligation.

This must be a stronger condition than ordinary SAT witness verification; otherwise CRS-5 defeats it.

### Target CRS-C — Schedule Externalization / Staticization

Convert the solver-relative causal game into a fixed problem instance or externally scheduled game without revealing enough future information for preprocessing to erase the lower bound.

### Target CRS-D — Fix-the-Transcript with Resource Preservation

Use a positive-probability hard (G)-transcript to obtain a fixed transcript while proving that the fixed transcript remains hard against preprocessing and random access.

### Target CRS-E — Static-to-CRS-PPC Compiler

For every hypothetical static polynomial-time SAT decider (A), construct a SAME_REALIZATION CRS-PPC strategy with controlled state, preprocessing, reread, recomputation, and sequential costs.

This remains the fundamental P-vs-NP-strength implication.

### Target CRS-F — Nonrelativizing/nonalgebrizing hinge

Identify a load-bearing consequence of causal finite computation that is lost under semantic/algebraic oracle replacement. The present stochastic/pebbling lemmas do not yet supply it.

## 17. Current assessment

CRS-PPC-SAT is useful, but its strongest rigorously defensible role is currently as an **auxiliary online audit model**.

The main mathematical gain is a clean trichotomy:

[
oxed{
	ext{solver-relative timing gives provenance}
quad
eqquad
	ext{ordinary NP nondeterminism}
quad
eqquad
	ext{fixed static language hardness}.
}
]

A P-vs-NP proof would require CRS-B/C/E (or an equivalent bridge). Without them, the true-random source and runtime-sensitive snapshots do not imply that an NDTM must follow the DTM's timing trajectory.
