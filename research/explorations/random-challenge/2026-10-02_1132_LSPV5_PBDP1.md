# PBDP1: Exponentially expanding prime products versus succinct arithmetic provenance

**STATUS: PROVED/EXACT representation lemmas + CANDIDATE bit-access experiment. P versus NP remains OPEN.**

## Motivation
Test the recurrence

R_1 = p_1,
R_t = p_t * product_{j<t} R_j

with distinct large primes p_t. The question is whether explicit storage growth can create a SAME_REALIZATION resource that survives succinct representation, reread, recomputation, relativization, and algebrization.

Repository search found no prior BitSLP, PosSLP, PBDP, or straight-line-program formulation. PRIMECRT1 and PRIMELQP1 cover ordinary prime annotations and compact positional-prime codes, not this recursively multiplying-all-previous-results construction.

## PROVED/EXACT: exponential explicit bit growth
Let H_t = product_{j<=t} R_j. Then

R_{t+1} = p_{t+1} H_t,
H_{t+1} = p_{t+1} H_t^2.

Equivalently, for t >= 2,

R_t = p_t p_{t-1} p_{t-2}^2 p_{t-3}^4 ... p_1^(2^(t-2)).

Hence

log_2 R_t = log_2 p_t + sum_{i=1}^{t-1} 2^(t-i-1) log_2 p_i.

If all p_i have Theta(B) bits, then

|R_t|_bits = Theta(B 2^(t-1)).

So polynomially many rounds can create an integer whose explicit binary expansion has exponential length.

## PROVED/EXACT: straight-line-program compression attack
The same recurrence has a succinct arithmetic straight-line program. Maintain only

R_{t+1} = p_{t+1} H_t,
H_{t+1} = H_t R_{t+1}.

This uses two multiplication gates per round plus the prime constants. For B-bit prime descriptions the straight-line representation is O(tB), up to ordinary encoding overhead.

Therefore:

**exponential expanded integer size does not imply exponential representation size.**

This is the arithmetic analogue of ACRTREE1 and STRATFLAT1: an exponentially large explicit object can still have a polynomial-size generator.

## Literature correspondence
Allender, Burgisser, Kjeldgaard-Pedersen, and Miltersen study integers represented by division-free straight-line programs. PosSLP asks whether the represented integer is positive and is shown to lie in the counting hierarchy. Their work also gives the reduction chain through BitSLP and proves BitSLP hard for #P.

This does not prove PosSLP or BitSLP outside P. It therefore cannot supply the missing unconditional lower bound.

Reference: Eric Allender, Peter Burgisser, Johan Kjeldgaard-Pedersen, Peter Bro Miltersen, On the Complexity of Numerical Analysis, SIAM Journal on Computing 38(5), 2009, 1987-2006, DOI 10.1137/070697926.

## CANDIDATE: Prime Bit-Dependent Provenance
The useful strengthening is not to force explicit materialization of R_t. Instead let a later legal source transition depend on a selected bit:

b_t = bit_{k_t}(R_t),

then

p_{t+1} = q_{t,0} if b_t = 0, and q_{t,1} if b_t = 1.

Call this candidate **Prime Bit-Dependent Provenance (PBDP)**.

The hoped-for distinction is between maintaining a short straight-line program for R_t and answering a source-required bit query bit_{k_t}(R_t). BitSLP hardness makes this a legitimate representation question, but not a SAT lower bound.

## Mandatory hostile tests
Any PBDP experiment must attack the candidate through at least four succinct representations:

1. arithmetic straight-line program or arithmetic circuit;
2. prime-exponent vector or recursive exponent DAG;
3. modular or CRT residues sufficient for the requested bit or branch;
4. direct recomputation of only the requested bit or residue rather than expansion of R_t.

The candidate survives only if k_t and the branch rule are generated naturally by the exact SU/vMS/SAME_REALIZATION source and no polynomial-size/evaluable representation answers all legal future queries.

## Critical noncircularity guard
It is invalid to define the next transition using an arbitrary BitSLP-hard query and then infer SAT hardness. That would insert a hard arithmetic problem by definition.

A useful theorem would require all of the following:

1. the recurrence arises from the exact source-typed realization rather than an artificial wrapper;
2. the later legal SAME_REALIZATION transition genuinely requires the selected bit;
3. the required information does not factor through the ordinary semantic SAT answer;
4. every relevant arbitrary SAT solver is forced, by a model-preserving theorem, to supply or acquire that information;
5. the lower bound is not merely the unproved assumption that BitSLP or PosSLP is outside P.

Item 4 is the existing arbitrary-algorithm acquisition bridge. PBDP does not solve it.

## Relation to current closures
PBDP is not killed merely by the polynomial bit length of ordinary positional prime provenance from PRIMECRT1, because the expanded value can have exponentially many bits. But the straight-line-program attack restores polynomial representation size.

The useful pattern would have to be:

large explicit state + adaptive access requirement + no polynomial succinct evaluator.

Large explicit state alone is insufficient.

The current SU05/Hadamard replay already has polynomial-time canonical evaluators, so no PBDP transfer is established there.

## Barrier audit
- **Relativization:** arithmetic-circuit maintenance does not itself break relativization.
- **Algebrization:** the recurrence is explicitly algebraic, so PBDP cannot itself be the nonalgebrizing hinge.
- **TRACECLOSE/REACQ:** if the queried bit or residue is a polynomial-time functional of a deterministic polynomial trace or source, existing closure applies.
- **STRATFLAT1:** if all future bit queries are answered by a polynomial-size/evaluable strategy, adaptive branching remains succinct.
- **Representation bypass:** explicit output length cannot be charged when a polynomial arithmetic circuit, exponent DAG, or residue representation suffices.

## Status and next test
**PROVED/EXACT:** exponential explicit bit growth; polynomial straight-line-program representation.

**FAILED as a standalone lower bound:** explicit storage explosion alone.

**CANDIDATE:** source-derived adaptive bit access to the succinct arithmetic state.

**OPEN:** a source-legal bit index and branch rule defeating SLP, exponent-DAG, CRT, and direct-query representations; arbitrary-SAT necessity; nonrelativizing/nonalgebrizing hinge; final contradiction.

The primary proof target remains the characteristic-two SU/vMS rank problem. PBDP should be tested only as a hostile companion representation experiment, not promoted above BITRANK, MATRIXCERT, or TURANEX.
