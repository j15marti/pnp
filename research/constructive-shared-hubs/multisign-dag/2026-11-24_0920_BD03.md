## 2. Theorem A (PROVED): exact planar energy spectrum under arbitrary affine guards
Input: n Boolean spins x on a simple planar host G=(V,E), m edges, nonnegative integer cost pair c_e(0),c_e(1) for relative bit d_e=x_u XOR x_v; hard mask M_e subset {0,1}. A rank-r affine system Qx=b is arbitrary in original coordinates, including nonedges, odd observations, and correlated equations. Reduce it by Gaussian elimination; inconsistent means empty. W=sum_e max c_e, assumed polynomial in encoded N for polynomial-time corollary. General bound is pseudopolynomial in W. Shift any signed integer pair costs by its minimum and track the scalar offset. Target energy index shifts accordingly; out-of-range indices reject. No need to materialize all spin assignments.

Set B=2^(n+1). Let f_e(d)=B^c_e(d) if d is enabled, else 0. Write A_e=f_e(0)+f_e(1), D_e=f_e(0)-f_e(1). For a binary observation a, define
  Z_a = sum_x (-1)^(a dot x) product_e f_e(d_e)
      = 2^(n-m) sum_{F subset E: boundary(F)=a} product_{e notin F} A_e product_{e in F} D_e.
Proof: expand each f_e=(A_e+D_e(-1)^d_e)/2; sum over all spins annihilates every term whose odd-degree incidence vector differs from a. If a has odd intersection with any component, Z_a=0. Otherwise find a forest path join P by XORing root-to-vertex paths for the set bits of a. Then F=J XOR P bijects the required boundary class with even subgraphs J. Swap A,D on precisely the edges of P. This handles arbitrary nonlocal character observations without changing the graph.

The exact guarded generating integer is
  Z(Q,b)=2^(-r) sum_{lambda in GF2^r} (-1)^(lambda dot b) Z_{Q^T lambda}.
All guard correlations are preserved by the character identity for the indicator of Qx=b. No absolute value may be taken on individual signed Z_a. Coefficient of B^j equals number of hub spin assignments of energy j satisfying masks and guard: each coefficient <=2^n<B, so no carries. Extract digits exactly. Thus SAT/UNSAT at a given energy, exact minimum, and projected hub-model counts are available. This does not count private lifts after minimization of regional costs.

## 3. Planar even-subgraph to weighted perfect matching compiler (PROVED, implemented)
For an even-subgraph weighted sum with unselected/selected weights A,D on each original edge:
1. Split degree d>3 vertex, in cyclic embedding order, into a path of bags of at most 3 ports: first/last two original ports, internal bags one, with connector ports. Enforce even local parity in every bag. Auxiliary selected bits are uniquely determined by prefix parity iff total original parity is even. Give each auxiliary edge both weights 1.
2. Replace each bag by a clique on its at most 3 distinct port vertices. Internal matching covers exactly selected ports: zero or two, unique. Original/auxiliary edge joins its two corresponding ports by a length-three path (u,a,b,v), fresh a,b. If selected, use middle edge (a,b) with weight D, freeing both port vertices for internal matching. If unselected, use both end edges, one with weight A and one with weight 1. No mixed pattern can cover both new vertices. This is a weight-preserving bijection even with zero or negative weights. Planarity preserved in the vertex discs and edge strips. Isolated original vertices contribute through the 2^(n-m) prefactor, not extra matching vertices.
3. Compute a clockwise-odd bounded-face Pfaffian orientation of each connected component: traverse faces, choose a dual spanning tree, flip parent edges bottom-up to make all nonroot face parities odd. Kasteleyn theorem gives a common matching permutation sign; the all-unselected matching exists, so evaluate at all graph-edge weights 1 once to fix that sign. Evaluate signed weights using exact skew Gaussian elimination with pivot permutation and rational Schur complements. Never use abs(Pf) at signed weights. The construction size is O(n+m), bit lengths polynomial in n,m,W (input integer powers have O(nW) bits; minors bounded by factorial times powers of max entry; elimination intermediates ratios of minors/Pfaffians). Charge arithmetic and orientation, not merely graph count. Signed zero weights supported without division by D. Character zero for an odd component parity is exact.

Each character costs poly(N+W) bit time and space, hence T<=2^r poly(N+W), streamed S<=poly(N+W), CM<=(T+1)S for one guarded query, on same execution. We do not use a black-box SAT or counting oracle. No arbitrary exponentially large binary weight guarantee.

## 4. Witness, exact support and GD09 interface (PROVED; edge lift executed)

Never accumulate these edge pins into Q: they are weights/masks on existing host edges. This handles disconnected components and odd observations without arbitrary gauge fixing. Verify original costs, guard, and source lift. ## 5. Theorem B (PROVED): relaxed BD02 guard eligibility
For aggregated even Walsh terms on <=4 distinct ports, cancel equal-support coefficients pointwise first. Pair terms must be on a supplied planar host. For quartic support S, choose any pair e subset S whose complement S minus e is a host edge. Unlike BD02, e need NOT be a host edge: impose e's XOR through Theorem A, then the quartic becomes a signed host pair. Define E'_S as these candidates, reject if empty. Greedily add span(E'_S) on each uncovered S; it lies in the even subspace on S, hence rank <=3. Each addition strictly increases intersection with any optimal hitting space; at most b'_* additions. Thus r<=3 b'_*, polynomial discovery by Gaussian scans. A common eligible pair can be tried first and gives optimal rank one.

Enumerate the 2^r global guard words, transform quartics pointwise, shift each resulting pair cost to nonnegative integer and retain constant offset. For each word, Theorem A accounts for the guard itself using <=2^r characters. Total <=4^r poly(N+Wmax) time, streamed polynomial space, including failed candidates, arithmetic, masks, source verification and reconstruction if source lifts paid. An extra arbitrary parity probe or constant-size boundary observation multiplies work by at most its exponential rank factor. For r=O(log N) and polynomial energies, polynomial. Guard words are disjoint; take min across them, not sum of minima; count hub assignments by summing energy-aligned spectra only. Canonical cache key must include host embedding/version and source IDs, complete signed pair coefficient/cost vector, shift and target, masks and reduced affine guard with RHS. Within one fixed cost/mask vector, character cache keyed by observation a with canonical tree path twist; different cost vectors do not share numeric values. Can reuse orientation and symbolic graph across all guards; no assumption of constant-time lookup, no collision-based proof. Streaming without memoization already proves bound on attempted character evaluations. Cache optional, not executed. Four-port tree glue with boundary relative pins still uses its paid authenticated interfaces; no free discovery of tree or regional costs.

Strict escape from BD02's original eligibility: take quartic supports {a,b,u_i,v_i} with pairwise disjoint host edges u_i v_i and no other host edges. No two complementary host edges on any support, so old test declines. New guard a XOR b (rank 1) reduces every quartic to its host edge simultaneously. This family can be explicit nonnegative unit parity-violation costs. Polynomial construction and lift; not a hard family.
