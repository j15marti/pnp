## PROVED: exact forest projection with shared signed guard circuit
Work on an authenticated explicit binary owner-row chart (all source guards already encoded exactly). Form the owner graph: edge iff some pair of live rows is forbidden. For a block B inducing a forest, root each component. One Boolean input z_s per actual exterior row s denotes its selection; the exterior exact-one constraints and all exterior compatibility constraints remain. For each internal row r of owner i, put A_i(r)=AND_{s exterior incompatible with r} NOT z_s. In postorder set
D_i(r)=A_i(r) AND AND_{j child of i} (OR_{t in R_j, allowed(r,t)} D_j(t)).
The output is AND_{root i} OR_{r in R_i} D_i(r).
Induction proves that D_i(r) is true iff the subtree has a compatible assignment with row r under exactly the exterior vetoes. Nonedges have complete pair compatibility; independent subtrees can be glued. With a full legal exterior transversal this is precisely existential projection; choose true roots then true compatible child rows for a polynomial reverse lift. For partial pins, the same evaluation (other selector inputs zero) means feasibility under just those pins, not joint exterior feasibility. A false output certifies a necessary guarded nogood; a true output is not a global SAT certificate. Never identify a row representative deletion with a necessary nogood (DP19).

Let R be total live explicit rows, L chart bit length. A block has O(R^2) gates/wires (binary fan-in expansion of veto and compatibility lists, including empty disjunction constants), polynomial bit size/acquisition/verification; deterministic graph and forest recognition and a greedy maximal forest are polynomial, not maximum forest optimization. The same bound holds across disjoint blocks with no internal cross-block constraints by counting each original pair once up to constants; store original row IDs and all reverse maps, not unfolded products. Circuit or recurrence evaluation, all consumer incidences, failed probes and lift verification are charged. A fixed bounded number of unary/pair probes per chart fits the existing DR18/BD18 deletion reserve if it makes strict deletions; no deletion does not buy another free attempt. A one-pass projection can remove block owners, but circuit factors and their boundary scope must remain and be charged. Repeated projection through these new factors is not justified by the binary forest argument. Full decision via existential search over exterior rows remains unbounded.

## PROVED: exponential explicit minimal nogoods versus compact circuit
For k>=2, one internal owner has k rows r_i; 2k binary exterior owners a_i,b_i. Only active row a_i=1 or b_i=1 vetoes r_i. Exterior rows otherwise compatible. Projection is OR_i (NOT a_i AND NOT b_i). Every minimal inconsistent positive pin set chooses exactly one of a_i,b_i for every i, giving 2^k distinct minimal nogoods, while the guard circuit uses O(k) gates. This is a lower bound on explicitly listing *all* minimal positive nogoods, not on decision or arbitrary representation. Arc closure is initially stagnant. Empty pins SAT; choosing a_i=1 for every i UNSAT. A single-pin deletion from that guard restores SAT.

## FALSIFIED: universal progress by ignoring factored consumers
For arbitrary 3-CNF, take one binary exterior owner per actual variable, one independent internal owner per clause with one row per literal. A clause row is incompatible only with the exterior choice falsifying its selected literal. No constraints between clause owners, nor between exterior owners. This is an exact polynomial binary chart: a satisfying assignment chooses a true literal per clause; any transversal satisfies every clause. Arc close first, then independently project singleton clause owners. Their O(1) circuits become the actual clauses (using the one-hot exterior bits), and the remaining binary owner graph is empty. Joint composition of these small factored guards is NP-complete in general, even though each block has <=3 rows, and all boundary owners have two rows. Thus owner-count/forest-width potential without a paid factored-consumer decision theorem cannot close U-PROGRESS. Monotonicity in unselected-row inputs is not ordinary monotonicity in free actual variables, because exactly-one couples complementary inputs. This is a reduction, not an unrestricted lower bound. If arc closure rejects a particular input it can return UNSAT; reduction as a decision algorithm with paid preprocessing would still imply P=NP if the remaining class had a uniform polynomial solver.
