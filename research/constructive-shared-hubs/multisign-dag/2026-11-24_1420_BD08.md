## 2. Exact suffix Fourier state (BD08-A, PROVED)
For every explicit finite list of affine bad events E_0,...,E_(m-1) on a common Boolean selector chart under an explicit affine guard G, Gaussian-parameterize G as z in GF(2)^d. Inconsistent G rejects. Before computation and after each forced pin, run certified local closure: drop impossible relative events and duplicate relative events, reject universal event, complement a relative codimension-one bad event to an unconditional equation. Restart after a pin and reach stagnation. These rules preserve the exact feasible chart count via a bijective rechart, not complete semantic closure. General 3-CNF maps each clause to its bad-literal conjunction; tautologies and repeated literals handled by Gaussian consistency, empty clause rejects. Source maps and RHS remain authenticated.

Let p_i(z)=prod_{j<i}(1-1_{E_j}(z)), U_i=span of all coefficient rows of events j>=i, U_m=0. Write chi_w(z)=(-1)^(w dot z). Store only nonzero unnormalized Walsh coefficients
    F_i(w)=sum_z p_i(z) chi_w(z), w in U_i.
The key is (fixed source, normalized chart/guard, layer i, actual ambient frequency w); masks in one chart must not be confused with another. F_0(0)=2^d and all other coefficients vanish. F_m(0) is exact projected model count; zero support at any layer is a sound UNSAT terminal (F_i(0)=0, p_i nonnegative). The suffix restriction loses no observations needed by later factors.

For nonempty affine E_i with row space V, rank r and particular point a, 1_E(z)=2^(-r) sum_{v in V} chi_v(a) chi_v(z). For w in U_(i+1), w+v belongs to U_i, so
    2^r F_(i+1)(w) = 2^r F_i(w) - sum_{u in supp F_i : w+u in V} F_i(u) chi_(w+u)(a).
All signs and RHS are preserved. Division exact because F_(i+1) is an integer count difference. This is linear exact propagation of a signed frequency marginal, not enumeration of prefix assignments or private lift multiplicities.

## 3. Output-sensitive support acquisition (BD08-B, PROVED)
A naive convolution scans up to 2^r per incoming key even when every contribution cancels. Instead form an implicit integer function H(w)=2^r F_(i+1)(w) on U_(i+1), using at most 2W_i terms, W_i=|supp F_i|:
- skip: point support {u} if u is in U_(i+1), coefficient 2^r F_i(u), phase zero;
- include: affine coset (u+V) intersect U_(i+1), coefficient -F_i(u) chi_u(a), phase a, i.e. multiply by chi_w(a).
Each affine coset is computed by Gaussian elimination of orthogonal-space equations. Empty supports discarded; identical support/phase terms can be summed. No enumerated coset words. For affine frequency query Q, compute E(Q)=sum_{w in Q} H(w)^2. Expand ordered term pairs, intersect Q with both supports, giving either empty or affine C=c+K. Character sum over C with phase p is zero unless p annihilates K; otherwise chi_p(c) 2^dim K. This is BA07's exact energy technique applied to frequency-domain transition terms (with explicit character phases). Each query uses O(W_i^2) Gaussian pair intersections/character sums, polynomial bit arithmetic. Exact positivity E(Q)>0 iff there is a nonzero output coefficient in Q, no oracle, no approximation, no independence assumption.
Split on pivot coordinates of an RREF basis of U_(i+1); projection onto these coordinates is bijective on that space. At each trie node test E(Q); skip zero, recurse on both children for positive internal node; at singleton calculate H(w) from terms and divide. At most 1+2 dim(U_(i+1)) W_(i+1) tested nodes (root zero allowed). This includes all failed probes and cancellation. No exponential edge scan hidden inside a probe.
Let N be total encoded input length including source charts/maps, and W_i actual exact supports, W_0=1. For fixed prescribed order, one serial evaluator:
    T <= poly(N) * [1 + sum_{i=0}^{m-1} (1+W_i)^2 (1+W_(i+1))]
    S <= poly(N) * [1 + sum_i W_i + max_i W_i^2]
with all tables kept for reconstruction. Count-only can roll tables. Coefficients F_i are at most 2^d in absolute value, scaled terms at most 2^(d+r), square sums have O(d+r+log(1+W_i)) bits up to fixed factors; log W_i<=d. Charge term and pair construction, orthogonal basis acquisition, every energy probe, explicit edge work, RREF, map/canonical comparisons, integer bit lengths, table retention, guards, source verification and witness queries. CM<= (T+1)S in the same serial realization (including retained input if charged). For any fixed cap B=N^a, stop at discovery of B+1 output coefficients and report UNKNOWN internally; all attempts before stopping polynomial under the cap, including pair build from the previously capped layer. Exact complete fallback or fair portfolio supplies decision, not necessarily polynomial. Cap implementation not run. Thus polynomial *actual nonzero* widths suffice, without a bound on raw convolution edges or supplied support certificate. This does not prove all orders or inputs have polynomial widths.

## 4. Exact reconstruction without new DAG compilation (BD08-C, PROVED)
Retain F_i for every layer. For a consistent affine query P with row space R subset U_i, particular solution c and rank s, define
    C_i(P) = 2^(-s) sum_{w in R intersect supp F_i} F_i(w) chi_w(c).
Inconsistent query returns zero. Fourier expansion of 1_P proves this is the exact prefix-legal count under P. Scan existing keys, not all 2^s frequencies.
Starting with empty P on U_m and F_m(0)>0, process i=m-1,...,0. Extend the complete functional on U_(i+1) to U_i one independent row at a time, maintaining
    C_i(P)-C_i(P AND E_i)>0.
At each bit the two conditional counts add to the previous positive count, so a positive branch exists. The protected suffix factors already fixed remain satisfied under every extension. Across all layers at most d new independent row choices, O(m+d) pairs of conditional count queries up to fixed factors. Run paid closure on original normalized registry after each chosen pin, retain inferred equations in the audit guard; never treat chosen pins as unconditional on root. It is unnecessary to rechart/recompute the saved tables because the queried observations stay in their certified suffix spaces, and guard deductions are logical consequences of full feasible extensions. Final Gaussian lift satisfies original G and all E_j, independently verify. Physical rim/matching lift requires the separately authenticated regional reconstruction map. Arbitrary external nonaffine guards or new observation rows outside U_i are not free queries.

## 6. Infinite separation controls and limitations (PROVED)
(1) For k shared bits x_i, construct two paired 3-CNF bad events per i in prefix: [x_i=0,p_i=q_i=0] and [x_i=1,r_i=s_i=0], all other bits private. Suffix contains two analogous events with fresh private bits per i, keeping x_i observed until later. Process each prefix pair consecutively, then suffix pairs. Each pair has 12 private extensions for either x_i value. Its marginal is constant in x_i; during the pair only a single nonzero nonconstant frequency can survive, and after it none. Thus Fourier peak 2, cut width 1, total states 6k+1, exact count (288)^k=2^(5k)3^(2k). BD07 canonical affine-intersection marginal table at this same prescribed middle cut has 3^k nonzero keys: for each i, skip, pin x_i=0, or pin x_i=1, with mutually incompatible double-include and all distinct keys having nonzero masses. No rank-one initial rejection event or individual containment; formula easy SAT. Another order or decomposition can also escape; no all-order lower bound.
(2) Wide cancellation: prefix events [x=0,y=0] and [x=1,z=0]. Their legal marginal over x is y+z (ordinary integers). Next event E=[y=z=0, h_1=...=h_k=0], rank k+2, is semantically redundant but is not contained in either prefix bad event. Keep y,z,h_i live with suffix pairs of rank-two bad events [v=0,p=0], [v=1,q=0] with private p,q. Marginal has exactly 3 coefficients before/after E; convolution include terms are identical coset/phase with signed weights summing to zero. Naive convolution would visit at least 2^(k+2) candidate edges for this transition. Exact energy/coalescing does not. Full peak <=4; count 2^(2k+4), since prefix contributes 2^(k+2) and suffix gives 2 extensions per live bit. This shows polynomial candidate discovery even with exponentially many cancelled transitions. No universal hardness: E could also be recognized redundant by a stronger paid closure.
(3) Falsify universal sparse Fourier width: process one event [x_i=0,p_i=q_i=0] for each i before any complementary partner, with suffix keeping all x_i. Each individual marginal has two nonzero Fourier coefficients, so the tensor product at cut has 2^k nonzero coefficients, even on an easy SAT instance. Also a single rank-k bad point on k live shared coordinates gives 2^k coefficients but only two affine keys. These are prescribed-order/representation barriers, not lower bounds against arbitrary solvers. An order portfolio or hybrid basis could avoid them. DS07 all-tree affine-key result does not automatically extend to Fourier support; DO08 local rank is not a bound on post-cancellation spectrum.
