## B. The two-space core theorem (PROVED)
Call S feasible if every owner outside S can be given one independent complemented hull equation modulo H+W+sum_{i in S}V_i. Independence is modulo the FULL retained observation space, not merely the retained bad hull U_i. The all-owner set is feasible. With S feasible, fix any word z0 in G satisfying the retained factors and all specified external observations. Append to H z=b the equations Wz=Wz0 and V_i z=V_i z0 (i in S), then append the selected complemented equations. Rank independence guarantees consistency for every such z0. Gaussian solve produces z satisfying all owners while preserving all retained packet truth values and W. The converse is restriction. Therefore exact existential compatibility on every external fiber, with polynomial reconstruction, but NOT a count-preserving reduction.

Find the unique least feasible S without subset enumeration:
1. Set C=empty; remove tautologies. Define base Q=H+W+sum_{i in C}V_i.
2. On owners outside C compute D_Q(J)=|J|-rank(sum_{j in J} U_j modulo Q). Take K as the unique inclusion-minimal maximum-deficiency set, including empty if maximum is zero.
3. If K empty, independent transversal covers all remaining owners; return C and certificate. Otherwise add K to C and repeat.

For fixed Q, D_Q is supermodular, so the intersection of maximizing sets is its unique least maximizer. Rado's theorem gives full transversal iff maximum is zero. To acquire K, run standard partition/linear matroid intersection on tagged basis rows. After maximum matching M, start alternating search at every unmatched owner. An owner reaches a matched owner when one of its candidate rows can replace the matched row in the independent basis modulo Q. No reachable row can augment. Each reachable row therefore has its expansion supported only on reachable selected rows; the span rank of reachable owners is exactly their number of matched rows. All unmatched owners are reached, so their deficiency equals total matching shortfall, the maximum by Rado. Every maximum-deficiency J must contain all unmatched owners, have rank exactly its matched row count, and contain every owner reached by these expansions. Hence reachable owners are precisely K. Shortest augmenting paths and direct Gaussian rank exchange tests suffice; failed searches charged.

Minimality of the outer fixed point: let S be ANY feasible retained set and suppose C subset S (initially trivial). Put R=S minus C. For T disjoint from S, the chosen independent certificates outside S give rank(U_T modulo Q+U_R)>=|T|, since Q+U_R subset H+W+sum_{i in S}V_i. Hence D_Q(R union T)<=D_Q(R). Taking T=K minus R and applying supermodularity gives D_Q(K intersect R)>=D_Q(K), so least maximality forces K subset R. By induction all additions lie in every feasible S. At termination C itself feasible, hence unique least feasible set. At most m nonempty rounds and one final search. This is minimal WITHIN the specified independent-halfspace/full-observation certificate class, not semantic minimality, not all possible autarkies, and not an arbitrary solver lower bound. The theorem reduces to DY10/BA10 one-round core when V_i equals U_i modulo H, since the first maximum deficiency core leaves a full transversal outside it in that quotient. With nonaffine factors the two spaces differ and iteration is essential.

## C. A false one-space extension (FALSIFIED)
On bits x,y,z, f1 rejects x=0 except when y=z=0; f2 rejects x=1 except when y=z=0; f3 rejects y=0 and (z=0 or x=0). Each is Boolean with a three-disjoint-point signed representation. Each accepting set affinely spans the whole chart; local acceptance closure adds no equations. Bad hulls are respectively x=0,x=1,y=0. A single hull-only deficiency core is {1,2}. Those two factors permit exactly y=z=0 with x free, but the third rejects both such words; full formula UNSAT. Deleting f3 while protecting only hull x gives false SAT. The two-space method keeps {1,2}, then {3}, because V1+V2 observes all three bits. Removing rejection point (0,0,0) from f3 gives a SAT neighbor. Both tested; both retain all three under this certificate. This is a concrete source-lift firewall for applying DY10/BA10 to arbitrary nonaffine signed summaries.
