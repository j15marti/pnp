## 1. Input and exact state theorem (PROVED; independent review pending)
For every explicit ordered list of disjoint binary coordinate blocks x_i in GF(2)^{d_i}, local nonnegative integer cost f_i(x_i) (infinity permitted for rejected words), explicit linear maps A_i into GF(2)^q, and target b, minimize sum_i f_i(x_i) subject to XOR_i A_i x_i=b. Cost zero is SAT for exact nonnegative violation encodings. All other constraints must have been included in local costs or the displayed affine guard. Source lift separately charged. Negative integer costs also permit minimization but zero-min is not then an automatic SAT predicate. Multiple global owner budgets are not replaced by an unproved scalarization.

Let U_i=im A_i, P_i=sum_{j<=i}U_j, S_i=sum_{j>i}U_j and R=rank(sum U_i). If b is outside sum U_i, reject by Gaussian elimination. Otherwise the precise *affine-extendable* state set at cut i is
  T_i = P_i intersection (b+S_i),
  w_i = dim P_i + dim S_i - R.
It is one nonempty affine coset of P_i intersection S_i and has exactly 2^w_i states. This ignores costs and masks; actual reachable states can be fewer. Endpoints T_0={0}, T_m={b}. A prefix's full syndrome s is sufficient and necessary for its residual affine RHS b+s; the fixed ordered suffix and all source versions/masks remain in the key. Future feasibility and cost for fixed s depend only on that syndrome, not on how it was obtained. No arbitrary guard contexts or hidden observations may be erased.

The exact set of affine-extendable transitions at layer i is
  E_i = {(s,t): s in P_(i-1), t+s in U_i, b+t in S_i}.
Write a=dim P_(i-1), r_i=dim U_i, c=dim S_i. Then
  tau_i = a + r_i + c - R,
  |E_i|=2^tau_i <= 2^(w_(i-1)+w_i).
Proof: solutions (p,u,v) in P_(i-1) x U_i x S_i of p+u+v=b are an affine coset of the kernel of a rank-R map. The map (p,u,v) -> (p,p+u) is bijective onto E_i because v=b+t. Every such triple lifts to a genuine affine assignment by independent linear preimages in the three disjoint groups; costs may still reject it. This counts transitions without testing all raw syndromes or all Cartesian cut pairs.

Local demand set is exactly
  D_i = U_i intersection (b+P_(i-1)+S_i),
  eta_i = r_i+dim(P_(i-1)+S_i)-R.
There are 2^eta_i distinct local tags, even if many transitions share the same tag. Compute a global particular solution and kernel basis by Gaussian elimination. Project them to each prefix, joint adjacent prefix pair, or local tag. Eliminate dependent projected directions; enumerate only the resulting affine cosets. Polynomial discovery for this supplied order, plus output-proportional enumeration. No optimal-order oracle. The classical linear-code trellis dimension is related; the claimed adapter is the exact weighted local-demand reuse with heterogeneous evaluation, not novelty of the trellis state-space theorem.

## 3. Two paid local backends (PROVED, only affine-fiber enumeration executed here)

Explicit local tables can alternatively scan and group by actual tag; no need to generate unlisted rows.

For a verified planar Boolean pair-energy block satisfying BD03 hypotheses (including polynomial total shifted energy W_i), use its signed character evaluator for arbitrary local guard. Select r_i independent observation rows. Compute all 2^r_i signed character partition integers, then apply exact inverse Walsh-Hadamard transform to get all tag spectra at once; retain exact signs until the inverse transform, not absolute values. Each operation uses integer bit lengths polynomial in d_i and W_i (BD03 base B=2^(d_i+1)); exact division by 2^r_i follows from the indicator identity. Tag outside image rejected. ## 4. Closure, aggregate costs, and limitations
Before global search, reject inconsistent affine guard; exact terminal evaluation, if zero-fiber nonempty, acquire every unary support via opposite-bit probes against a verified base witness. Each forced fact is unconditional relative to the root zero-cost fiber, which is unchanged on insertion of a logically entailed fact. Thus the exact unary support closure remains certified after every insertion and at stagnation. The implementation retains this closure certificate/counters, not physical substitution or all-channel closure. It does not branch globally; enumeration of local affine fibers is the charged terminal acquisition step. Conditional probe results remain in local cache under the probe key; do not export as unconditional except certified root opposite failure. A more general paid single-parity closure is possible if that observation is distributed as an added global affine row (cut widths and local ranks increase by at most one, since projecting back forgets one tag coordinate); each probe done separately, forced equations retained as redundant facts. Full all-channel closure not implemented.

For D=sum d_i, unary probes add <=D evaluations plus root; structural trellis reused, local keys scoped to one optional bit pin. State/edge/table storage at most polynomial bits per entry (including witness paths and counts <=2^D). Retain all prepared edges and local cache in the experiment; do not claim streaming polynomial space independent of widths. A conservative peak bound is poly(N)*(1+sum_i [2^w_i+2^tau_i+(D+1)2^eta_i + 2^k_i]) for the enumeration version as implemented (local fiber coset materialized); planar transient spectra instead add max 2^r_i poly(N+W_i). All counters use exact arithmetic; CM <= (T+1)S on the same serial execution. If the qualifying exponents are logarithmic, T,S,CM polynomial. For fixed prepared universe and root probe cap, reserve <=(D+1)sum_i(2^tau_i+2^eta_i)+poly(N) jobs, each completed or retired once, and charge local work separately; this gives a paid c=1 unary frontier credit, not an aggregate credit for arbitrary branching. DAG key construction, Gaussian basis projection, coset enumeration, table arithmetic, cache lookups, tie aggregation, failed probes and witness verification included. No free source acquisition.

Counterexample to dropping the local-work condition: a single block with arbitrary 3CNF violation cost and zero affine guard has width/rank/edge exponent zero but exact local min is SAT-equivalent. DR04 gives a stronger typed signed-graph example. Counterexample to dropping the order/width condition: 2k one-bit blocks with pairs constrained equal, all first endpoints followed by all second endpoints. Middle cut has k independent shared syndrome bits; all 2^k states occur even with zero costs, and distinct suffix compatibility relations. Interleaving each pair gives width 1, so this is a fixed-order state obstruction only, not a hardness family. No inference from restricted state size to unrestricted time. DO01 high-girth NAE may still have large trellis width; no bound proved. Universal source decomposition/discovery/coverage remains open.
