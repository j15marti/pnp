## 3. Theorem BD06-A (PROVED): sparse modular Walsh nonidentity
Let d>=0, B>=1, modulus m=2^B. Let P(z)=sum_{s in S} c_s (-1)^(s dot z) mod m, with explicit binary masks s in GF(2)^d and integer residue coefficients c_s, M=|S|. A deterministic algorithm either returns an actual z with P(z)!=0 mod m or proves P identically zero, using polynomial work in d,M,B. In particular no enumeration of 2^d is required.
Proof. For each z define evaluation vector v(z) in (Z/m)^M with coordinate (-1)^(s dot z). A bit flip in coordinate j acts by a fixed diagonal sign matrix D_j. Maintain a list of actual orbit representatives z, a queue of unexplored representatives, and a modular elimination table. Start z=0. To insert any actual vector, reduce left-to-right: at its first nonzero coordinate i use the lowest nonzero bit valuation a. If pivot (i,a) exists, subtract that pivot modulo m. Both entries have the same lowest nonzero bit, so the next nonzero bit at that coordinate is strictly higher or the coordinate becomes zero. Prior coordinates stay zero. Otherwise store the reduced vector at the vacant pivot and queue the ORIGINAL z (not the reduced vector). A zero reduction is an explicit linear combination of existing pivots. Each pivot is itself in the span of admitted actual vectors by construction. No claim that this is a canonical module basis or that all nonzero reductions are independent is needed.
There are at most MB pivot slots, each reduction attempts at most MB subtractions, and at most MB original representatives are admitted. From every admitted actual z try all d neighboring bit flips, evaluating P on the actual vector before reduction. If a nonzero value is found return that z. If the queue empties, the span of admitted vectors contains v(0) and is invariant under every D_j: the image of each admitted generator was either admitted or reduced to zero. Consequently every v(z) lies in that span. If the coefficient functional vanishes on all admitted generators it vanishes on the entire orbit. This proves exact identity, not probabilistic testing. All used scalars are exact residues; division by nonunits is never used. At most 1+dMB candidate visits, O(MB) pivot reductions per visit, O(M) residue operations per reduction, plus bitmask parity and actual functional checks. Deterministic indexed arrays or sorted exact keys suffice; no probabilistic hashes.
Canonical key context: immutable row IDs/domains, b,h, affine coordinate chart including offsets, character ordering, modulus, and exact signed residues; orbit pivot key (i,a) valid only within that context. A zero-reduction candidate is reused algebraically, not claimed identical as an original assignment. Distinct admitted orbit states <=MB and every attempted consumer edge charged <=dMB. Queue retains actual words for reconstruction. No need to inspect all possible orbit words or prove a semantic equivalence of arbitrary circuits.

## 4. Theorem BD06-B (PROVED): deterministic guarded feasibility with affine base and arbitrary explicit fibers
Parameterize local base t_i=a_i+B_i u_i using independent directions. Solve XOR t=b by Gaussian elimination, obtaining all u as affine functions of free z. At each local tag list all actual row IDs; pad by repetitions to a common power-of-two number of choices for that factor, using new independent private selector bits. Padding preserves support, NOT counts. Local chart table of length l_i is at most 2|R_i|^2, and every table entry returns an actual row ID. Let L=1+sum l_i, D0=max l_i (a power of two, use 1 for empty product). For each protected bit j let f_j(z)=sum_i g_ij(z) as an INTEGER sum. Desired XOR bit h_j iff f_j+1+h_j is odd.
Each local table bit is a Walsh polynomial with l_i coefficients and denominator l_i. Substitution of affine forms maps each local character to exactly one global character with an offset sign; this does not enumerate free selectors or expand products of linear forms into ANF. Multiply by D0 and combine identical character masks with exact signed addition, obtaining sparse integer numerator A_j=D0(f_j+1+h_j). Form the product numerator P=prod_j A_j by XOR-key convolution modulo 2D0^q. Each A_j has at most L keys; each multiplication has all pair attempts charged. At any actual z, P(z) is a multiple of D0^q; modulo 2D0^q it is D0^q exactly when every guard bit matches, otherwise zero. This retains joint guard correlations, not marginal support. Theorem A directly returns a simultaneous witness or proves no simultaneous witness. For q=0 use the empty product 1. Reconstruction evaluates local chart entries and checks the original tuple, including closure masks. No cumulative pins or signed intermediate row witnesses required.
Let M be final number of nonzero keys, B=1+q log2 D0, d free selector dimension. Let E be all attempted XOR product pairs. A conservative same-serial-realization bound is T<=poly(N+q+B)[1+E+(1+dMB)(1+M^2B)], S<=poly(N+q+B)[1+max intermediate product size+M^2B+dMB], CM<=(T+1)S; include chart/closure, acquisition, arithmetic, keys, attempts, queue, original lift and verification. E<=sum_{j=1}^q L^j, M<=L^q. Hence deterministic polynomial time and space for FIXED q, even with unbounded base rank, unbounded affine selector dimension, arbitrary correlations of local features, and local arity O(log N) from explicit tables. For q=O(log N) worst-case bound is quasipolynomial, not polynomial. A polynomial certified actual product width also suffices with paid pair attempts. No full physical/source compiler cost silently omitted; N includes explicit acquired row domains. General signed counting networks and arbitrary budgets outside domain. This is a decision/witness result, not a count-preserving padding.
Fixed-context global work credit: charge at most MB admitted representatives and dMB consumer attempts, plus product attempt budget and local table work. A unary queue progress potential (remaining admitted slots plus remaining scheduled/possible consumer slots) decreases with each paid job when the finite cap is reserved; do not equate this with universal aggregate branch contraction or reusable credit after arbitrary context switches.

## 5. Theorem BD06-C (PROVED): a root-zero Fourier channel can hide #SAT after ONE pin
For arbitrary proper 3-CNF F(x) with n variables, m clauses, use an independent occurrence bit per literal position and one affine synchronization star per original variable (two rows: all occurrence bits zero or all one). For each clause make 16 actual rows for its three occurrence bits and a private multiplier y_j. Its base tag is the occurrence-bit word, and its one protected bit is y_j times the clause violation indicator v_j(x). Base XOR target zero imposes exact synchronization, with literal signs in v_j. Add one two-row independent factor with base tag zero and protected bit a=0 or 1. All rows unit weight, base supports affine, local size<=16. Total protected bit XOR is a XOR sum_j y_j v_j(x).
Before pinning, both guard target counts equal 2^(n+m). In BD05 every zero-character base factor is constant on its affine support; attributed periods span the entire occurrence space; quotient width zero. The nontrivial character vanishes identically in the mask factor. Thus this family is within BD05's cheap root count domain, regardless of F. After the ONE row pin a=0, let Z0,Z1 be the protected bit counts. Then
 Z0+Z1=2^(n+m),
 Z0-Z1=sum_x prod_j sum_{y_j in {0,1}} (-1)^(y_j v_j(x)) = 2^m #SAT(F).
One exact pinned count thus suffices to recover #SAT by arithmetic. Conditional exact counting in this family is #P-hard under polynomial metric reductions (and lies in #P as an explicit row-product count). If a universal polynomial pin-stability lemma for the BD05 root count evaluator were established, FP=#P would follow, hence P=NP. No unconditional superpolynomial-time claim and no assertion P!=NP. Ordinary pinned feasibility at h=0 is EASY (choose all y=0), also covered by BD06-B. This is not a diagonal-hard decision family and not a proof all possible witness reconstruction needs counting. It directly addresses the zero-channel caveat in BD05; use the new decision terminal instead of mandatory exact counts whenever the affine-base promise holds. BW06 count transfer is conditional on its separate authenticated compiler, not executed on this reduction. Do not reinterpret the source SAT label as the compiled decision label.
