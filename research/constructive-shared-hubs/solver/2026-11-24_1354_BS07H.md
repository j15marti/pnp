## 2. BS07H-A: Hall hyperplane theorem (PROVED)
Let M be the transversal matroid on owner set E defined by subsets matchable to R; r(S) is maximum matching size on S. Let d=m-r(E) be its deficiency, equivalently the dual matroid rank. The standard transversal matroid theorem follows from matching augmenting paths; dual rank r*(S)=|S|-r(E)+r(E\S). This identity follows by maximizing |S intersect (E\B)| over primal bases B and extending a basis of E\S to a primal basis. Hence:
  r*(A)=d iff r(E\A)=m-|A| iff the private region is extendable.
If d=0 the projection is identically true. Otherwise nonspanning A is contained in some dual hyperplane H (maximal rank d-1 flat). Every hyperplane is the closure of an independent (d-1)-subset. Enumerate such subsets S, query r*(S) and r*(S+v) for each v, retain H={v:r*(S+v)=d-1}, deduplicate exact bitsets. At most binom(m,d-1) hyperplanes and O(m binom(m,d-1)) matching calls plus polynomial set operations. Failure is exactly the union of affine events B_H = all exterior equalities of owners outside H are FALSE. Each such failure is an affine conjunction (one complemented row per exterior equality), including inconsistent or universal events, safely normalized by Gaussian elimination. Both SAT directions hold pointwise on G, regardless of exterior chart rank. General exterior predicates not given as ORs of affine equations require a new adapter. Count overlaps are NOT additive.

## 4. Counterexamples / limits
Each 3CNF clause C is a connected 2-owner, 1-private-row region (one row can serve either owner). Owner 0 has the clause literals as exterior equality alternatives; owner 1 has none. Both owners can be covered iff C is true. Deficiency=1, exactly one bad event, physical bipartite tree, each local projection trivial; shared chart retains arbitrary 3SAT. Hence universal polynomial gluing based ONLY on a bound on maximum local deficiency, even 1, would imply P=NP. This is a reduction, not an unconditional hardness claim or a failure of all portfolios. Fano root and relaxed neighbor were replayed using ONLY these deficiency-one regions.

For unbounded d, even flat/hyperplane expansion can be exponential. Take m owners, m-d private rows all adjacent to all owners. Dual is uniform U_{d,m}; owner v externally covered iff z_v=1. Bad set is Hamming weight <=d-1. All binom(m,d-1) hyperplanes are distinct. Any affine subspace of bad words has dimension <=d-1, since independent pivot coordinates can be set simultaneously to one. Thus at least binom(m,d-1)/2^(d-1) affine bad events required for ANY flat affine-union representation. For d=floor(m/4), this is 2^Omega(m) by standard binomial estimates. Yet all-ones is a witness and projected count is 2^m-sum_{j<d} binom(m,j), polynomial by symmetry. This is an explicit-output barrier only. No unrestricted lower bound, no proof of P!=NP.
