For every forbidden event E, copy the current map and subtract c_A from the entry A intersect E for each old entry (skip inconsistent intersections), remove zeros. Canonical keys are reduced row echelon augmented systems with deterministic pivots and original coordinate IDs. The invariant is 1_G product_{processed i}(1-1_{E_i}) = sum_A c_A 1_A. No semantic oracle is used. Run certified rank-one packet closure first, after each accepted deduction, and before an unresolved dispatch; a guard-specific conclusion is not an unconditional root fact. Query any additional affine system H by sum_A c_A 2^(n-rank(A intersect H)), skipping empties. Exact SAT/UNSAT; coordinate self-reduction acquires and verifies a source witness. Full affine hull (theoretical, not implemented): start with a model, compute a basis of equations for its current affine span, query the complement of each equation; a positive count gives a new model outside the span, increasing dimension. At most n+1 rounds, O(n^2) count queries plus witness lifts. This acquires all necessary affine equations only if the map has already been paid for. Reclose after each exported deduction. No arbitrary projected counting claim.

Cap B=(N+2)^c for a fixed c; check during map updates, not only after completion. Coefficients have O(m) bits (at most 2^m absolute from subsets), counts O(m+n+log B) intermediate bits. ## Falsifier for universal flat-map bound
For any linear signed NAE-3 hypergraph with t pairwise vertex-disjoint owners, every subset S of these t defines a nonempty intersection A_S. The constrained coordinates in each selected triple are tied by two signed relative equations; different triples and all unselected vertices have independent flip bits. Distinct subsets yield distinct affine flats. No unselected owner has an event containing A_S: by linearity it meets each selected triple in at most one vertex, so its three coordinates belong to distinct independent flip groups. Its relative observations are not fixed on A_S. Thus the only subset of all owners producing A_S is S itself, with coefficient (-1)^|S|. The final map has at least 2^t nonzero keys, independent of order and signs. In an n-point complete-pair Steiner triple system, m=n(n-1)/6, degree d=(n-1)/2; greedy disjoint packing removes at most 3d-2 owners per step, so t >= m/(3d-2) >= n/9. Hence on the raw complete-pair source the representation is superpolynomial in explicit encoded length O(n^2 log n). This is a lower bound on this precise coefficient map, not on arbitrary representations of the same indicator, or SAT decision. Raw S27 is connected in observation space, so plain BS22 root factorization cannot fix it. Stronger cuts and alternative terminals may bypass the map.
