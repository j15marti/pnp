## 2. Exact input model and closure
For every finite explicitly acquired independent row family, one row r_i per block i, with nonnegative binary integer cost vector c_i(r), base syndrome t_i(r) in GF(2)^D, arbitrary row feature g_i(r) in GF(2)^q, require sum c_i <= K, XOR t_i=b, XOR g_i=h. All other source constraints must already be encoded and authenticated. Public owners P are specified; all others private. Source length N includes explicit blocks, row IDs, bit widths, constraints and output variable list; unused binary-encoded variable ranges are not expanded for free. Features are arbitrary functions of rows, not assumed affine in base tags. Negative capacity rejects. The code uses arbitrary-precision BigInt, and expects decimal strings for values exceeding safe JSON integer precision.

Certified closure: for a candidate row, sum minimum other costs per owner and check the residual target against the affine span of other block tags. For fixed h use joint (t,g) tag; for all-guard mode use only base t, since h is not fixed. Remove only impossible rows, restart after each deletion, reject empty blocks. After fixed point, subtract per-block coordinatewise cost minima, and XOR each block's first row base and feature anchors out of targets; archive original row IDs and offsets. This preserves exact relations. No semantic closure oracle. DP computes exact guarded tables, not unguarded facts from individual branches. Source compilation/projection is authenticated before this row closure; no integrated all-channel source-level preprojection closure claimed.

## 3. Theorem BS04-A: finest guard-separated base partition (PROVED)
Let U_i be the span of normalized base row tags in block i. Let B be a basis of their total span, chosen from actual normalized row tags; record the originating block of every basis vector. For every normalized row tag v of block i, compute its UNIQUE coordinate word in B and union i with the originating blocks of all nonzero basis coefficients. Also union all blocks with a nonzero normalized cost at any common PRIVATE owner. Use DSU. Zero-tag blocks remain independent unless joined by private owners. Reject a base target outside span(B).

Claim: the resulting partition C_1,...,C_J is the unique finest partition of blocks such that
(i) W_j=sum_{i in C_j}U_i form a direct sum, and
(ii) each private owner's varying costs occur in at most one component.
Proof: Every normalized row tag in a component is in the span of basis vectors originating there; conversely these basis vectors belong to its component. Disjoint subsets of one independent basis have direct sum. Private owner union ensures (ii). For any partition satisfying (i),(ii), every basis vector lies in its originating part; the subsets form bases of their parts (their total is a basis of the direct sum). Uniqueness of basis coordinates forces every nonzero coordinate of a row vector to originate in that row's part. Private owner sharing also forces a common part. Hence every union edge is necessary, and the constructed partition refines all admissible partitions. This result is basis-independent; it does not assert finest semantic decomposition, since nonlinear support or other representations may split further.

The base target has unique component coordinates b_j obtained by XORing its selected basis vectors by origin component. Thus XOR_i t_i=b iff XOR_{i in C_j}t_i=b_j for every j. No coordinate sparsity assumption: dense invertible basis changes preserve the partition. Discovery is polynomial by elimination and DSU; the owner unions are explicit scans. This is a block-contracted and owner-augmented fundamental-graph construction.

## 4. Theorem BS04-B: exact profile composition for arbitrary source-row guards (PROVED)
For each component C_j acquire exact table S_j of (g,c_P) realized by choices satisfying base target b_j and every private owner budget (and individually within public budgets). Retain one actual witness per exact pair, not separate coordinate supports. Private costs occur only in their component after minima subtraction, so they can be discarded only AFTER local evaluation. Let H be the set of public resource/guard keys. Starting D_0={(0,0)}, evaluate
 D_j={(g XOR g',c+c'): (g,c) in D_(j-1), (g',c') in S_j, c+c' <= K_P}.
Exact-key deduplication is sound because future compatibility depends only on this complete key, fixed stage, source and guard context. For every retained key store one concatenated witness. Induction proves both directions: restrict an original model to its components to get a path; concatenate independent actual local witnesses along a path to lift. Public owner sums are checked jointly; no independent minimization. Nonnegative costs justify prefix truncation. Guard features may be arbitrary nonlinear functions of base tags, and may contain any q-bit row observations. In all-guard mode calculate all final feature words simultaneously with one witness each; no target-specific row deletions are used in that mode. For fixed target, closure may be stronger, but its table is not reused as an all-guard table. This supplies exact joint, not affine-hull, support and avoids DP05's frozen-quotient reset when base components are cheap.

Fixed-target result is null or original row-index vector; allGuards returns guard-word -> witness map. Exact, not a polynomial-time guarantee.

CNF source: one binary factor for each listed variable, one owner per clause, cost equals number of false literal occurrences contributed by the row, capacity clause length minus one. Exactly encodes OR including repetitions, tautologies, empty clauses, and clauses of length <=3. Dense compiler O(nm) entries, polynomial in explicit input/output length. Both directions via Boolean row identities. The paired monotone NAE budgets of DO01 are literally the two opposite clauses; increasing a single cap by one gives the intended owner relaxation.

Signed graph source: each vertex has four color rows. For edge uv with forbidden XOR s and each a in GF(2)^2, add an owner cap1 whose two endpoint indicators are [x_u=a] and [x_v=a XOR s]. Every signed exclusion is enforced iff all four budgets hold. Wheel source adapter verifies a supplied manifest for private disjoint triangles, exact nine expected signed edges and absence of extra private incidences; unique port b with hub h and shift a. The three rim vertices must use distinct colors, avoiding h and b XOR a, so extension iff b=h XOR a; if equal there are six rim permutations. Substitute port with shifted hub; preserve all non-rim edges and adjust signs. Current adapter requires hubs not to be ports and declines unsupported self-edges or overlapping manifests, not a universal gadget recognizer. Reconstruct actual colors of all private rims and verify all source edges. Actual K5 and deletion neighbors were expanded, projected, solved and lifted. No claims of universal strict tetravalent reduction.

Local adapters in one engine:
* Gaussian exact affine terminal: normalized tag support cardinality equals 2^rank, and no costs or nonconstant public features. Gaussian coefficient solution reconstructs actual rows by lookup.
* Scaled one-owner integral flow: when all local tags/features are constant and no public cost varies, each row has zero or exactly one owner load at its common positive scale. Clip owner slot capacity to number of blocks after integer flooring. Full bipartite matching by augmenting paths is equivalent to integral flow; unit capacities give ordinary bipartite matching. The checker executes this adapter, not BS03's general blossom parity gadget.
* Exact count grouping: binary factors with identical signed full cost difference and XOR differences of BOTH base and public tags. Enumerate count 0..m with actual baseline and deterministic subset lift; every equivalent count has the same full key. Nonbinary rows stay explicit. No other protected constraints omitted.
* Multisign DAG: use exact key (base syndrome, joint feature, full cost vector) per stage, filter by remaining affine BASE extendability and budgets. Each attempted transition is charged. Then project private costs only after the entire component has been evaluated. Global exact profile DAG composes them.
BA04 period cancellation, GD10 Lovasz span, BS03 general tagged blossom, BH04 RST even cycle, and full HCL201 closure are separate certified domains, not executed here. A future adapter may replace a local job only if it supplies its exact required joint profile.

## 6. Charged aggregate theorem and counterexample
Let N be explicit encoded input length. For each component using the count/DAG evaluator, P_j is product of the count alternatives (m+1) and explicit row sizes after grouping. Define H=2^q product_{o in public}(min(K'_o, sum_i max_r c'_io(r))+1), after normalization. H is a capacity, not a claim that all states occur. Set P_j=1 for polynomial terminal components. Each local DP layer has at most the product of preceding alternatives; total transition attempts at most polynomial(N) P_j, including failed attempts. Global transition attempts <= J H^2. Closure has at most total explicit rows strict deletions, with polynomial scans and Gaussian solves after every deletion. Count alternative generation, reconstruction, basis provenance, canonical key serialization, and witness copies are charged polynomial per explicit job. A conservative bound on deterministic bit complexity (implement ordered maps or polynomial scan of keys rather than presupposing O(1) hashing) is poly(N) times a polynomial in 1+sum P_j+J H^2; with deterministic balanced dictionaries it is poly(N)(1+sum P_j+J H^2), since key lengths and logarithms of state counts are polynomial in N. JS Map execution is empirical, not an assumption about worst-case hash lookup. Space <= poly(N)(1+max_j P_j+H), streaming one local job and global layer, with explicit stored witnesses. Same serial CM <= (T+1) S. For count group alternatives, polynomial creation overhead is included. Reserve unique local prefix and global consumer-edge jobs rather than overlapping recursive subtrees, charge verification of source lift. If fixed exponents bound P_j and H, obtain a polynomial integer credit and deterministic polynomial terminal; no universal bound on discovery of a favorable public-owner set or cheap alternative representation.

DO01 hostile family: in the raw monotone NAE owner compiler, connected linear edge-critical hypergraph has degree >=2 and distinct incidence signatures for all vertices (two equal signatures would imply two shared hyperedges). Root affordability/affine closure deletes nothing: each row contributes at most one to each owner, owner caps >=2, other ownerwise minima zero, no tags. Every private owner joins its incident variables; choosing all owners private leaves one connected component. Both row choices pay at least two owner loads, excluding the single-load flow terminal; costs exclude affine terminal. Every signed binary count difference is distinct due to distinct supports; P_1=2^n. This remains true after one owner relaxation (even dropping that owner leaves its paired opposite owner). Hence the sufficient polynomial capacity condition is NOT universal, even on both labels; this is not a lower bound on actual DAG size, alternative public owner selection, alternative portfolio, or arbitrary algorithms. DO01's existential high-girth construction is not executed here. DR04's local acquisition obstruction remains applicable to compact implicit factors.

DP05 reset is resolved for its explicit pair family, not contradicted: preserve the base target nonzero per pair, keep nonlinear zero-marker feature as separate global coordinate, not a lifted stabilizer. Each pair is a direct-sum component even after dense invertible coordinate mixing. Local pair profiles both feature values, exact witnesses; convolution at most two guard keys. With all base targets zero, equal partner tags force feature parity zero, so target 1 is UNSAT although individual row supports remain. At k pairs old frozen order affine capacity 2^(2k+1), new two all-guard evaluations have 40k local transition attempts and <=5k global transitions in the actual controls. Gaussian/closure costs separately charged (not claimed linear total runtime). New exact theorem rules out a compulsory reset for this family and all systems with polynomial paid base-component profiles.
