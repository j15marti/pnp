## 1. Exact source and closure (PROVED)
Input: explicit independent nonempty indexed row sets B_i; each row carries a nonnegative integer vector c and binary XOR tag t. Choose one row per block so sum c<=K componentwise and XOR t=target. All costs are exact binary integers; no hidden constraints. Row IDs retained for source reconstruction; fixed guards enter as actual row filters. For an arbitrary explicit CNF (including repeated literals, short/empty clauses), recode occurring variables and create a binary row for each variable. Owner j is clause j; c_j(v,b) counts occurrences of literals of v false at b, and K_j=length(clause j)-1. Then sum costs<=K iff every clause contains a true literal. Empty clause gives negative K and immediate rejection. Tags are zero. Dense implementation O(nm) entries, still polynomial in encoded source after recoding. Signed strict E4/B4 networks: one bit per wire, opposite endpoint decoded by XOR sign. For E4, three signed literal equalities each encoded by two binary ORs. For B4, all four 3-subsets get positive and negative ORs, equivalent to exactly two ones. Both directions pointwise; isolated original bits freely reconstructed. This compiler was tested on signed K5 networks, and its formulas were solved by the same core. It does not acquire a strict network from an unspecified implicit physical model.

Closure: for any row, reject it if its owner cost plus sum of other blocks' owner minima exceeds the budget, or its tag cannot complete even in the affine sum of all other row sets. Gaussian elimination and integer scans verify these necessary conditions, restart after each deletion. A singleton is forced within this exact query; no inference of semantic completeness. Closure runs at root, after every implemented row deletion, and at every local query/branch before a terminal or further branching. All conditional deductions are held in query-specific domains and capacities. No full all-channel or complete semantic closure is claimed.

## 2. New shared-owner separator theorem (PROVED)
Construct a bipartite support graph with block vertices and owner/tag-coordinate vertices. Incidence whenever a row has nonzero cost or tag bit. (One can first subtract fixed baselines, but code uses conservative raw supports.) A target bit with no incident block must be zero. Delete a single candidate owner o and compute remaining connected components containing blocks. No private owner or tag coordinate occurs in two different components. For every component i let U_i=sum of maximum row costs at o. Define m_i as the minimum total cost to o among actual tuples satisfying all private constraints and private tag targets, or infinity if none.

Then original feasibility iff all m_i are finite and sum_i m_i<=K_o.
Necessity: any global witness restricts to regional witnesses, each costs at least m_i. Sufficiency: concatenate one minimizer per independent region. All private constraints hold, tag coordinates do not overlap, and the only shared constraint holds by the inequality. The proof uses actual minimizers, not independent per-coordinate optima of one region. A regional exact decision backend obtains m_i by monotone binary search on the integer bound for o (including one query at U_i). Retain the last feasible witness: when the interval collapses its cost equals the optimum. No exponential dependence on U_i, only 1+ceil(log2(U_i+1)) exact queries. A disconnected support graph needs just one query per region. Discovery tries every owner, scans all support coordinates and uses union-find; polynomial in dense explicit input. Implementation makes one such split, not recursive repeated optimization calls. It chooses the candidate giving the most components. Different regions may use different exact backends, even when each region has an internally cyclic owner-block graph.

A stronger symbolic extension: allow q shared XOR bits across those regions, keeping every other tag coordinate private. For each region compute m_i(g), g in GF2^q, by the same minimization with that local tag target. Infinity represents unavailable labels. Global combine by min-plus XOR convolution: D_0(0)=0, others infinity; D_{i+1}(g)=min_h[D_i(g XOR h)+m_i(h)]. Keep minimizing backlinks and actual row witnesses. Accept iff D_t(target)<=K_o. Costs O(4^q t) pair comparisons plus at most 2^q sum_i[1+ceil(log2(U_i+1))] backend calls. Polynomial for logarithmic q provided the regional backend calls are polynomial. Ordinary signed WHT does not replace min-plus without further theorem. This extension was not implemented. Multiple shared upper-budget owners cannot in general use independent scalar minima: three factors with choices (0,1),(1,0), budgets (1,1), all individual minima zero, but every full tuple costs total 3>2. The two-owner hostile case was executed. Treating duplicated synchronized wheels as independent factors would also invalidate the graph partition unless the equality/guard constraints are included.

## 3. Cooperative regional solver and canonical DAG (PROVED)
After the above closure, if all budgets dominate total maximum costs, check whether each exact tag table is affine by cardinality equals 2^dimension of its difference span. If so solve the combined linear equation by Gaussian elimination with coefficient backpointers, recovering actual table rows. If not, try S06 hybrid: subtract blockwise owner minima, choose owner scales by gcd of nonzero residual entries, classify a good block only if every row has zero or one scaled owner unit and a constant tag; remaining nonsingletons must be binary. Group bad blocks by full signed cost difference and XOR difference, including baseline costs/tags. Enumerate count vectors only if P_bad<=256 (fixed code cap). Every group count has actual row-ID lift, not just aggregate capacity. For each count vector use residual integer floors for good-owner capacity, reject negative residual or wrong tag, then integral capacitated bipartite matching via augmenting paths. Dummy category is zero load. At most number of good blocks augmentations; clamp capacities to that count. Full nonbipartite DA01 blossom/matroid intersection, planar BD01 and Pfaffian DS01, BA01 period quotient and DP02 WHT are audited but not executed in this first cooperative core; their exact query interfaces may be inserted under their own hypotheses. In particular do not project away budgets to apply an XOR-only terminal.

If the hybrid declines, use an exact target-conditioned DAG. For fixed factor order, prefix tag v and cost a, let M_j and m_j be sums of maximum/minimum suffix costs. If a_j+m_j>K_j, reject. If the target tag minus v is outside suffix affine hull, reject. Canonicalize prefix cost a'_j=max(a_j,K_j-M_j). For any suffix cost b_j<=M_j, a_j+b_j<=K_j iff a'_j+b_j<=K_j: if clipping changes a_j both sides are true. Consequently two prefixes with identical clipped costs and tag have identical feasible continuations, even though their historical row IDs differ. Keep one actual backlink history for decision; no counting claim. Induction proves soundness through later updates: clipping commutes with adding the next row and clipping again because the previous suffix maximum equals max of next row plus subsequent suffix max. The code stores full representative row-ID histories and verifies at final source. Key includes layer/query implicitly by fresh table; no sharing between differing capacities/guards. Charge all attempted edges, key construction, collision tests and histories. A frontier above 2048 distinct keys returns UNKNOWN to fallback, never UNSAT.

Fallback recursively pins a row from a non-singleton factor, redoes certified closure and all bounded terminals. This exhausts the disjoint actual row partition, decreases the number of unfixed blocks on each path, and is complete; it is not asserted polynomial. No need to run exponential count or DAG above caps. All SAT results verified on original rows. UNSAT follows by exact algorithms/proofs, not an independently exported DRAT/Tutte certificate. For BW01 wheel lift, palette K4 plus two carriers per bit, a center fixed to palette color 3 by private triangle equality and private triangle rim per clause; choose true carrier site color 2, alternate 0,1 on other rim vertices. Each actual graph edge checked. Reverse proof: if all literal carriers are false, each rim vertex excludes 2 and 3, an odd triangle cannot be properly colored. If proper graph coloring exists, decode the carrier bits relative to the palette; equality triangle forces correct center. This is an ordinary proper 4-color target, not planar/strict four-regular; no independent whole-graph coloring search or free two-bit packing test in BS01.

## 4. Charged bounds and first universal gap
Let N be full explicit encoded input; q_i=1+ceil(log2(U_i+1)). Each bounded local terminal and closure call has a fixed polynomial cost, including dense source acquisition, repeated Gaussian scans, gcd and binary floors, support graph construction, flow augmentations, row-key serialization, all DAG transitions and histories. Deterministic balanced-tree keys can replace JS Map for theoretical worst-case polynomial key cost (implementation uses Map). If every regional query resolves by a bounded terminal, T<=poly(N)(1+sum_i q_i); generalized protected tags T<=poly(N)(1+2^q sum_i q_i+4^q t). Store only current query plus retained minimizers and finite cap DAG, so polynomial peak space and CM<=T*S. Fixed supplied region/query credits q_i can be precharged and decreased on completed query; this is not a universal credit for the local solver. If fallback used, local work <=poly(N) product of original row counts (depth<=number of blocks), and total paid bound is additive over query calls: poly(N)(1+sum_i q_i product_{b in region i}|B_b|). Without a split use one region. Binary source gives a worst-case exponential upper bound, polynomial peak space by depth-first fallback and bounded frontier. CM may be exponential; no artificial sharing, no free source acquisition. No unbounded enumeration hidden behind UNKNOWN.

The star family of g disjoint NAE triples sharing one upper owner sum of all 3g bits<=K has a connected support graph, g separate regional cyclic NAE owner graphs after removal of shared owner. Each local minimum is 1. Hence K=g is SAT; K=g-1 UNSAT; no root row-affordability or tag deletion for g>=2 (all-zero baseline permits each single row). Every variable's bad difference signature is not unique within its triple: the three blocks share one type, different triples have distinct types, thus fixed S06 global bad-count volume is 4^g (NOT 2^(3g), which is raw row product). Each region has only four count cells. The new split gives polynomial time in g, with exact source witness. This example does not assert hardness of global S06 implementations, which may already use other deductions. Owner scanning is paid and dominates the current dense implementation.

First missing universal lemma: after certified closure, every residual either admits a paid low-cost region/terminal or a further exact transformation with polynomially conserved aggregate credit. DO01 critical high-girth cores can lack a separating owner and S06 raw parameters can be exponential; no coverage assertion. In particular the presence of a shared geometric wheel center does not certify a one-owner separation. If a fixed exact cooperative solver has no polynomial bound, select increasing inputs with T>|F|^j (choose constants to exclude smaller finite sizes); this only excludes fast successful runs of the actual solver, not all representations or all algorithms. DISJ: complete fallback covers disjoint row choices; decision merge existential only. Relativization/algebrization/Natural Proofs: no unrestricted separation claimed; structural terminals scoped.
