## 1. Model, normalization and source transfer
For every finite explicitly encoded independent row domain R_i (actual row IDs retained), each row carries a vector of nonnegative binary-encoded integer contributions c_ij and Boolean contributions p_ik. Require sum_i c_ij <= B_j and XOR_i p_ik = h_k. All couplings are declared owners; no hidden relation or extra output requirement. Decision and witness only, not full counts. Certified BS05 local support closure first: budget minima and singleton parity tests, restart after each deletion, repeat at stagnation. If any domain empties or fixed constraint fails, UNSAT. In each closed row domain subtract each budget-coordinate minimum from all rows and the corresponding owner cap; XOR the first row's bit into all rows and the owner target. Then constant contributions vanish; all residual costs nonnegative. Varying incidence graph has one node per row domain, one per owner, edge if that contribution varies. This is an exact source-ID-preserving change of coordinates.

Arbitrary encoded 3CNF compiles by one Boolean row domain per source variable and one budget per clause: cost counts false literal occurrences, cap clause length minus 1. Both SAT directions immediate; even repeated variables/tautologies handled by summing occurrences, empty clause cap -1. Dense table acquisition polynomial in total encoded input (renumber occurring variables; isolated variables arbitrary). Typed signed tetrahedral edges can instead use BS05's actual triangular rim table: one source color row per vertex, one legal endpoint pair row per private wheel with verified rim witness, and two equality/XOR bits per endpoint occurrence. Duplicate wheels preserve actual source color through these equality owners; independently reconstruct each private rim. The 64 local signed endpoint cases replayed; no strict physical E4/B4 adapter replay, no count transfer. BW06's uniform multiplicity is optional for COUNT, not needed for this decision proof.

## 2. Theorem BS06-A (exact articulation message composition)
Discover vertex-biconnected edge blocks (include bridges as singleton blocks) of the varying incidence graph by DFS lowlinks. The bipartite incidence graph of original vertices and blocks is a forest. Root each component at any original vertex. For each block-to-parent-vertex subtree, retain exactly the following message with actual witness(es):
* parent is row domain: set of surviving ORIGINAL row IDs admitting an extension in the subtree, one actual lift per ID. No independent marginal or affine-hull replacement.
* parent is budget owner: minimum total contribution to that owner from edges in the subtree, among assignments satisfying all other owners there; infeasible if none. Parent budget NOT enforced locally.
* parent is XOR owner: attainable parity subset of {0,1} for edges in subtree, one actual lift per value. Parent parity NOT enforced locally.

At an original row vertex, child blocks share only its row identity. Intersect their feasible ID sets; lifts agree on the identical row. At a budget vertex, child subtrees are disjoint except for the owner, so sum their minima. At parity vertex, XOR-convolve their at-most-two-value support sets. At root, choose any feasible row, compare summed minima against cap, or check required XOR. Isolated vertices treated identically with empty child lists. These are necessary and sufficient: a feasible global tuple restricts to all recorded child states; conversely, actual child witnesses glue without a hidden row overlap. For budget owners only upper bounds matter, so replacing a child contribution by its minimum cannot invalidate another constraint. This is NOT valid for arbitrary two-sided equalities, coupled budget vector interfaces, or required exact counting; parity support cannot be replaced by a min.

Block evaluation: use one local subproblem per query, retaining only edges of that block. Internal row vertices restricted by their child row-ID messages. Internal budget owner caps reduced by child minimum. Internal XOR owner with singleton child parity uses adjusted target; with both parities available remove this local XOR test and later choose child lift with actual required parity; empty support rejects. To compute a parent row message, query once per original row ID, preserving pin. To compute a parent parity message, query both values. To compute a parent budget message, use feasibility with threshold t, binary search from 0 to sum of local row maxima; exact integer minimum found in O(bit length) queries; store actual witness of minimum. This uses no pseudo-polynomial expansion of budget magnitudes. In every query, the BS05 backend recloses masks before/after local deductions and at stagnation before cut branching, preserves pinned IDs/threshold/targets; the root closure was unconditional. Child restrictions are certified necessary under the specified query, not exported as unconditional outside it. Retain all outside correlations through articulation messages. Induction on block-cut forest proves both labels and reconstruction. Complete semantic closure is not assumed. Exact all-row support available by root-pin reruns under the same cost promise (see below), not free.

## 3. Theorem BS06-B (paid additive capacity)
For root block B, let d_e be distinct contribution cardinality (>=2). V_B = minimum over feedback edge cuts C of product_{e in C} d_e. BS05 maximum spanning tree ordered by integer d_e discovers it; maximizing sum log(d_e) is equivalent, no log rounding. All cycles lie in a single biconnected block; therefore raw global optimum is PRODUCT_B V_B. After messages/guards, the local varying graph is a subgraph of B with reduced edge alphabets. Restrict the original spanning forest and extend if needed. The optimal local cut product cannot exceed V_B, including a query in which an internal parity owner is removed. Each query invokes BS05's exact closure/matching/affine/capped multisign profile DAG then cut fallback; failed terminal attempts polynomial per node with fixed DAG cap. At most polynomially many query calls per block, independent of tree depth: each block message is computed once, and child witnesses already stored, not recomputed for each parent query. Define A = sum_B V_B. Discovery and bit length of all V_B and A polynomial in explicit input, root cap test paid. With N encoded input length, same serial realization T <= poly(N)(1+A), S <= poly(N), CM <= (T+1)S. Proof: each query uses <= poly(N)V_B work and serial polynomial space (depth <= #edges, per-state explicit row mask, fixed capped DAG, input-size arithmetic); stored messages <= poly(N) row IDs or at most two parity witnesses or one budget witness per block, each witness O(N) row-ID entries, so even copying whole witnesses and retaining every message is polynomial. Count canonicalization/keys, per-query preprocessing, graph building, failed attempts, all outgoing pins, witness joins and source verification in poly(N). No uncharged fanout or cross-guard reuse. Use cap A<=N^C for a fixed C to make a polynomial terminal. Code uses fixed experimental cap 4096 and exact prior fallback on decline, so entire code is exact but not claimed polynomial.

For fixed root decomposition, schedule every block's polynomially many queries with upper work credits V_B each (plus an explicit polynomial overhead per query/node and per join). Remaining sum of job credits is a nonnegative integral potential: completing one paid job removes at least one unit; within a cut tree BS05's (k+1)V aggregate contraction pays all children. Equivalently flatten the fixed polynomial query upper budget, allocate credits to disjoint child block jobs and reserve parent job credits; sum of child scheduled credits <= parent credit-1. Binary search decisions affect future query thresholds but not their allocated maximum count. This is arithmetic/scheduled work decomposition, not arbitrary SAT-child contraction. Polynomial initial credit on A<=N^C. No proof of universal polynomial A or other terminal.

## 4. Falsifiers / exact repairs
A single 6-cycle (3 binary row nodes, 3 budget owners, each row contributes its bit to both neighboring owners, caps 2) has A=2. Pin one row to zero: its two edges vanish, remaining 4 bridge blocks have A=4. Both masks SAT; closure does not prune other rows. Thus raw recomputed A is NOT monotone even under unary restriction, invalidating a universal potential proof relying on it. Keep original blocks and original cut upper credits under masks, or bound refined sum by |E| times original A: each refined block lies in one original block and V <= its V_B, number of refined blocks <= |E|. Fixed original block groups can be queried even if disconnected. This proves polynomial stability for all row masks and natively supports original row-ID probing/reconstruction. No uncharged repeated pin computations; at most total explicit row IDs queries to acquire global row support. Global forced-information closure beyond row support remains a distinct task.

Raw A not universally polynomial: m=4t rows with two options (a_i,0),(0,a_i), a_i=i+1 for i=0..m-1, two budget caps B=m(m+1)/4 each. Graph K_{m,2} a single biconnected block, d_e=2, V=2^(m-1). Root row support closure stalls because each contribution <= B and all coordinate minima zero. SAT by choosing m/4 complementary pairs summing m+1; lower one cap by 1 -> UNSAT by total conservation, same raw A, closure still stalls. Distinct costs; no unrestricted LB (easy conservation/explicit arithmetic). DO01's critical linear NAE families cannot be declared solved by BS06 without actually bounding their biconnected blocks or importing further certified transforms; Fano controls are finite and may invoke fallback. DP01/S06 exact exception grouping and flow can be used as local oracles if their eligibility and guard masks paid; S06 scaled exception and BD06/DP07 not replayed.
