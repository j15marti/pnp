## 2. Exact fixed-count masked flow lemma (PROVED)
Input: choose exactly one identified row per independent block, costs nonnegative binary integers, upper owner budgets K, XOR tags in GF2^q. Fixed guard and all protected observables are authenticated in rows/constraints. Apply S06 ownerwise minima subtraction once to the entire candidate universe, not to each changing mask. Fixed positive owner scales d_i. GOOD block rows are zero or d_i e_i, with a constant tag. BAD nonsingleton blocks are binary; group by identical signed cost difference D and XOR difference e. Subtract bad row-zero baselines and fixed good tags. Let group multiplicities m_j and P=product(m_j+1). A count vector k is admissible before masks if residual budgets R_i(k)>=0 and XOR condition holds. Define owner capacity floor(R_i(k)/d_i), clamped at B_good, and dummy capacity B_good. Keep one integral flow network for each such count (at most P). Source->block capacity 1; one individually identified block->owner/dummy unit arc for EVERY enabled good row (parallel arcs distinct); owner->sink fixed capacity. This transformation is exact by S06.

For any availability mask on original rows, a binary bad group has f forced-one blocks, z forced-zero blocks, h flexible blocks. A block with neither row enabled invalidates the group. Otherwise the count k is feasible iff f<=k<=f+h. Selecting a particular flexible row 1 is feasible iff k>f; selecting row 0 iff k<f+h. Every enabled forced row is supported whenever the count is feasible. Proof: choose exactly k-f distinct flexible blocks; the stated inequalities are necessary and sufficient, and all choices give the same aggregate costs and XOR because D,e are identical. For fixed count, good and bad choices are independent, so a full flow and a legal group realization combine into an actual tuple. Union the supports of ALL feasible count states to get exactly the original row support. This preserves individual IDs under arbitrary masks, unlike treating a count alone as a guarded key. A witness follows from flow arcs plus forced/flexible choices.

## 3. Dynamic all-mask flow lemma (PROVED)
Retain a maximum integral flow per count. Inserting one unit row arc increases optimum by at most one: remove at most one unit of a new flow on that arc along a source-sink path to obtain a prior feasible flow. Deleting an unused row arc preserves optimum. Deleting a used row arc removes its one unit along source->block->owner->sink, leaving a feasible flow of value old-1. The new maximum lies between old-1 and old. In each case one residual BFS augment attempt restores a maximum (augmenting-path theorem); a failed BFS certifies maximum by residual reachable cut. Source/sink and parallel row IDs are kept. Updates to bad row availability do not change this fixed-count flow; they only change count feasibility. Keep even temporarily infeasible count networks so they can become active later under lower-mask additions.

When flow value equals B_good, an enabled good row is supported iff its arc already carries one unit OR its endpoints belong to the same strongly connected component of the residual directed graph. Sufficiency: an unused enabled arc has forward residual capacity; a return path closes a residual cycle, and integral augmentation on that cycle gives a full flow using the row. Necessity: difference of two equal-valued feasible flows decomposes into directed residual circulations; a newly used arc lies on a directed cycle. Include source and sink in SCCs (slack owner capacities must not be discarded). Compute SCCs in O(V+A) elementary graph operations, with A counting all incidences including parallel arcs. A selected bad row's support follows from section 2. Thus all-support evaluation is exact on every lower or upper mask. This is a stateful polynomial outer evaluator when P is polynomial; no AND/OR representation required. A support witness for any selected row can be obtained by one residual path or choosing a suitable flexible subset.

## 5. Crucial representation firewall (PROVED via known theorem)
Counterexample to strengthening DP03 to universal polynomial positive all-mask circuits even over the tractable S06 domain: take n blocks (left vertices), n owners (right vertices) with budget 1, one row costing e_j for each pair i,j, zero tags, no bad blocks (P=1). The mask is precisely an arbitrary adjacency matrix. J(z)=1 iff bipartite perfect matching exists. Known theorem Cavalar, Goos, Riazanov, Sofronova, Sokolov, Monotone Circuit Complexity of Matching (arXiv:2507.16105, ECCC TR25-102 rev1, 2025-11-06) gives superpolynomial (indeed exponential 2^{n^{Omega(1)}}) AND/OR circuit complexity on bipartite perfect matching. Dense explicit row source length polynomial in n; therefore no fixed polynomial gate bound in that input length. Unbounded fan-in with polynomial incidences reduces to binary gates with polynomial overhead. This directly refutes universal positive all-mask compilation even for exact flow/count terminals with no exception variables. It does NOT refute DP03's conditional ledger or imply unrestricted runtime hardness: the stateful residual-flow evaluator above decides every mask in polynomial time. Prior LSPV-3/383 already established a related source-sign nontransfer; this is a specific architecture transfer plus constructive alternative.

With arbitrary toggles use actual event count Q instead of O(M). Peak storage O(P(V+A+G)+M+N) records plus polynomial bit/access overhead and retained backend states; two masks use two copies. Conservative bit bounds T<=P poly(N)+T_acq+T_lift for monotone schedule; S<=P poly(N)+S_acq+S_lift; CM<=(T+1)S. All costs refer to one sequential execution, no uncharged recomputation or matching oracle. A positive integer ledger can reserve P(B+1) initialization search slots and P(2M+1) per-mask update/support slots for each side, each slot with polynomial cost; consumption monotone for the fixed universe. Retirements must be charged once and counted among upper deletions. Unlike DP03 linear propagation, this bound pays actual graph scans per event. It does not bound unknown acquisition time or growth of newly discovered guard contexts. DP01 P can be exponential (many distinct binary types). Fixed cap fallback exact but no universal bound.
