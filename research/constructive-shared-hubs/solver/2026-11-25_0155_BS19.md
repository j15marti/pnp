## Exact projection and aggregate bound
Canonical signed NAE owner means the literal list must contain both values. Remove duplicate literals; a complementary pair is tautological; an empty or singleton list is false. Complementing the entire list is an exact identity. A binary owner forces a relative parity; substitute it globally and record its lift, then reclose. For variable v in d remaining owners, flip each entire owner so its v literal is positive, writing NAE(v,L_i). For fixed exterior bits, owner i either leaves v free or, when L_i is monochromatic b, requires v=1-b. A common v exists iff no two such requirements disagree. Therefore existentially eliminate v by replacing its incident owners with NAE(L_i, complement L_j) for every i<j. Canonicalize, remove tautologies and duplicates, reject false owners, reclose. A reverse lift takes the common required bit or either if none. Exact exterior support, not counts. The rule covers arbitrarily large boundary widths and owner arities; no truth table or complete semantic closure. If the actual guard includes v, do not eliminate without an exact adapter. Coordinate pins can be encoded relative to a common reference r via signed binary NAE parity, with final gauge r=0; this extension proved by complement symmetry but not executed here. Arbitrary dense affine guards, additional non-NAE row restrictions and native physical port replay are not covered.
For a fixed original-N polynomial occurrence cutoff D(N), always choose a minimum-occurrence pivot, with deterministic ties, and decline if d>D. Each successful projection adds at most binom(d,2) owners and removes d, binary substitution does not grow owner count. After at most n projections/substitutions owner count <=m+n D^2 and each list length <=n; charge discovery, canonicalization, all pair candidates, full source maps, reverse log, closure and final failed sweep with polynomial bit work per step and original-N storage. The single-child credit 1+remaining variable count contracts strictly; no child multiplicity and no reset. Same serial T,S polynomial and cumulative storage <=(T+1)S. This is a terminal only if every pivot passes or another exact terminal accepts. If a cap is hit, return OPEN plus exact residual and reverse lift, not UNSAT. Subsumption is sound when a smaller literal list (or its complement) is a subset of a larger list.
## Structural obstruction
On a simple linear 4-regular 3-uniform signed registry with Berge girth >4, the cap d<=4 cannot eliminate every variable by this rule with canonicalization and binary closure. Inductively eliminated vertices form an independent set in the primal graph. Original incident clauses at distinct eliminated vertices are disjoint as owners. Each elimination generates six 4-variable clauses from disjoint 2-variable lists, no tautology or binary owner; for a fixed pivot scopes distinct. Identical scopes from different pivots would give two common primal neighbors and a Berge cycle of length <=4 (if both neighbors come from one original edge at a pivot, cycle length <=3; if both from one edge at both pivots, linearity fails). A surviving vertex in a touched original owner loses that owner and gains three resolvents, net +2, while an untouched vertex retains degree 4. Thus each eligible next pivot is nonadjacent to all eliminated pivots, no duplicate drops and no binary closure. A maximal independent set leaves adjacent surviving variables (there is an original edge) with degree >=6, and the method stalls. The theorem is for this restricted raw elimination schedule, not for unrestricted algorithms or additional algebraic rewrites. Optional literal-list subsumption cannot occur among equal-width distinct resolvents, nor can a surviving 3-owner be contained in a 4-resolvent: that would share two vertices with a generating owner or create a Berge triangle. This last optional extension is not needed for the cap obstruction and not used to claim a universal barrier.
