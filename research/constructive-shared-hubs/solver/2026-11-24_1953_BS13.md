## B. Binary support absorption (PROVED)
Every subset S of {00,01,10,11} can be encoded by signed interval factors with at most ONE additional incidence per boundary variable. Empty is contradiction; full is no constraint; singleton uses unary pins; two words sharing a coordinate pin it, otherwise the two words are equality or disequality (signed exact-one); three words are the complement of one word (signed at-least-one). Unary supports similarly use a pin or no row, or contradiction. All 16 binary masks checked on all four words. A relation is retained as a full two-bit table with one actual subtree witness per feasible word, not as two marginal supports or an affine hull. The interval encoding is decision-preserving, not counting-preserving.

## C. Region-thin block theorem (PROVED, integrated cactus implementation plus separate SCC controls)
From the closed registry mark every variable of global occurrence >2 as a hub. Remove these incidences, form connected components of owners via nonhubs. A region contains all its original owners and all their original hub occurrences. Verify each variable occurs at most twice inside each region. Form the simple bipartite quotient Q of actual regions and hubs; one edge per region/hub adjacency. Find vertex-biconnected edge blocks, bridges included, by DFS lowlinks. Require:
(1) each region has at most TWO incident edges in any one block;
(2) every region port belonging to a nonbridge block has exactly ONE original local occurrence. Bridge ports may have two local occurrences.
These are efficiently recognizable, no optimal partition search. A cactus quotient is a special case. The theorem also permits blocks with many cycles, arbitrarily many hubs, and hubs of arbitrarily high degree INSIDE a block. Only region degrees inside each block are capped.
Root the block-cut incidence forest at any vertex. A block message to a hub is a unary table on its actual shared bit; to a region it is a unary (bridge) or binary table on the block's actual adjacent hub bits. All children have disjoint internal source variables apart from declared hubs. At a hub intersect child unary tables. At a region absorb each child table via B. A bridge message is just a unary pin or full/empty; apply it as a pin/substitution rather than increasing the original local occurrence cap. The implementation inserts a unary owner then immediately closes it, which removes the pinned variable from the live registry. A nonbridge message touches only single-incidence ports; each such port belongs to precisely one block since quotient edges belong to one block. Thus each port gets at most one new incidence; local degree <=2 is maintained. Query the augmented region with each possible parent-port word (at most four). BH13's exact general factor compiler decides and reconstructs a local assignment; select stored child witnesses under its actual port word. No full regional relation enumerated.
To compute a block message, first prepare all internal vertices with their child messages. Every internal region is now a unary/binary relation over its one/two hub neighbors in the block. Every internal hub is its actual Boolean variable, with its unary child restrictions. For each forbidden word of a binary table add its 2-CNF clause excluding that word; unary tables give units. There are <=4 clauses per region. If parent is a region, leave it out and query each of its at most two adjacent hub bits; if parent is a hub, leave its child restrictions to the parent and query that one bit. SCC solves every such conditioned block. For each successful key, reconstruct hub word and choose corresponding actual internal region witnesses. A bridge needs two queries. On a simple cycle, equivalent two-state path DP from one parent edge to the other suffices: internal hubs enforce equality of incident edge labels; internal regions enforce their full binary support. The integrated implementation uses this cycle recurrence, NOT arbitrary block SCC; the latter is separately executed on explicit support tables.
Induction proves exact existential gluing: any global satisfying word restricts to all retained tables and matching lifts; conversely, a successful root witness agrees on every actual shared bit and all child subtrees are disjoint except those bits. All original constraints occur in exactly one region. No multiplication of independent subproblem searches and no loss of nonaffine binary correlation. At root region one unconditioned matching query; at root hub choose a common allowed value. Disconnected components combine independently.
Matching backend (BH13 audited): equal-polarity double occurrence gives graph edge, opposite-polarity gives two edges with degree-one midpoint, single occurrence gives dummy [0,1]. Each owner vertex has degree interval. For each edge create joined incidence pair; each endpoint incidence joins its own owner's U slots, L mandatory. All optional slots form a clique with a dummy if total slot count odd. Perfect matching iff selected edges satisfy intervals, because incidence pair is either matched together or both matched to local slots; unused optional slots have even size. Deterministic Edmonds blossom backend, no free oracle. Witness decode and original constraint verification executed.
This is a new cooperative integration of BH13 matching with BS06 articulation messages and exact nonaffine guarded support. It is stronger than ordinary cactus DP with explicit tables: high-degree regions are never tabulated on their entire boundary.
