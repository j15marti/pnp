## A. Fixed-topology affine parity region (PROVED)

All private consumers must be contained in this region; no hidden quota, tag or other constraint on x. An owned vertex with no outgoing edge is impossible. Parallel arcs and loops can be retained. This domain is acquired from signed NAE factors whose literal signs are affine functions of z. Find a factor-saturating incidence matching to DISTINCT PRIVATE variables, choosing one actual pivot occurrence per factor. For every other literal occurrence v construct the arc with p=1 XOR signs of pivot and v. NAE is equivalent pointwise to at least one other literal differing from the pivot. Fixed topology, both source directions, no independent copies. If the matching fails this adapter declines; not an UNSAT inference. The general strict physical E4/B4 compiler is NOT established by this adapter.

For fixed z, a closed sink SCC means a private SCC with no outgoing arc to another SCC or exterior endpoint, containing no free private vertex. The region is feasible iff each closed sink SCC contains a SIMPLE directed cycle with XOR of labels zero. Necessity: select one satisfied edge per owned vertex in each closed sink; following the selected function eventually reaches a simple cycle, necessarily consistent. ## B. Polynomial acquisition of an exact single affine rejection event per sink (PROVED)
For each closed sink C, let every simple directed cycle gamma have affine parity ell_gamma(z)=XOR of its edge labels. Exact rejection set is
  R_C = {z in G : ell_gamma(z)=1 for EVERY simple directed cycle gamma in C}.
Thus it is an affine subspace (possibly empty), even if there are exponentially many cycles. The following algorithm acquires it without enumerating the cycle family.

Initialize H=G. If inconsistent, no event. Obtain an affine spanning set of H: one particular point a and one a+v_i for each basis vector of its direction space, all via Gaussian elimination. At each sample z evaluate labels and ask a deterministic simple parity-zero cycle decision/witness routine on C. If a cycle gamma is found, add the equation ell_gamma(z)=1 to H. It excludes that sample, so either H becomes inconsistent or dimension falls by one. Restart acquisition on the new H; keep the actual cycle provenance. If no sample has a consistent cycle, for EVERY gamma the affine function ell_gamma is 1 at every spanning sample, hence 1 everywhere on H. This proves H=R_C. Induction: actual R_C remains a subset of H after each added equation. If H becomes inconsistent, C is universally extendible on G. A singleton SCC with no cycle has R_C=G, handled by the same rule. The sampled words are not SAT branches; the learned equations constrain the REJECTION locus only, NOT all global solutions.

For dimension d, at most d+1 restrictive updates (last can be inconsistent), and at most (d+1)(d+2)/2 cycle decision/witness queries per sink: sample-set sizes decrease from at most d+1 through 1. Use Robertson-Seymour-Thomas (1999) deterministic polynomial even directed simple cycle decision: subdivide each parity-zero arc once, parity-one arcs remain single, with separate intermediate vertices. Directed simple cycles correspond; even length iff XOR zero. Remove edges greedily while preserving existence using O(M) further decision calls to isolate an actual cycle (separately handle loops or subdivide using paths of length two/three with same parity to eliminate loops/parallel arcs). The decision theorem is KNOWN; the affine acquisition reduction above is PROVED here. No SAT, semantic identity or coverage oracle. Runtime is polynomial for the explicit authenticated domain.
