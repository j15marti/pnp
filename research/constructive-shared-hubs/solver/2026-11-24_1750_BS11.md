## 2. Source model and acquisition (PROVED)

Write y_o=a_o*x+b_o, one occurrence per literal, with y_o=1 meaning false; a clause C accepts iff some y_o=0. L=number of occurrence IDs; empty clauses reject, empty conjunction accepts. All actual external observers must be protected by matrix P or remain in exact source factors (nonlinear/occupancy consumers require authentic observation protection). No hidden quotas/tags, no free Boolean conversion of large OR of arbitrary rank packets. A 3-CNF is an immediate source instance. A clause's rejection is an affine event, so it also has a Boolean signed packet 1-1_bad. Arbitrary affine-event OR lists are not asserted to be this language.

Let M have rows a_o and K=ker H intersect ker P. Acquire the variation image E=M K in F2^L by Gaussian elimination, carrying preimages. Test all e_o and e_o+e_p for membership, O(L^2) tests with polynomial bit work. Let D be the span of the weight-one and weight-two vectors in E. Relation o~p iff equal or e_o+e_p in E is transitive by XOR. Its equivalence classes B partition occurrence IDs. If a class contains one e_o in E, all its unit vectors are in E, and all such free occurrences form one class. Within each nonfree class the pair vectors span exactly the even-weight subspace, independently across classes. Hence D is precisely the direct sum of these even subspaces and the full free class. This is exact simultaneous discovery, not a guess at low-degree source variables. For example columns 1110 and 1101 both have weight 3, yet their sum 0011 is a weight-two correction.

Define a demand bit q_B(x)=XOR_{o in B} y_o(x) for each nonfree class; for a free class put q_B=0 identically. The actual available occurrence words at fixed representative x, allowing corrections whose image is in D, are exactly all words with these nonfree block parities and unrestricted free block, by D's decomposition and stored preimages in K. Kernel variations invisible to M are harmless and not counted as additional occurrence directions. This is a quotient preserving G and Px and all invariant parities, not a claim that every E variation is available at a fixed quotient. There is no new physical source identification.

## 3. Exact Hall projection (PROVED)
For any fixed quotient word, each q_B=0 block may set all occurrences true (y=0); each q_B=1 block must have an odd number of false occurrences and can be reduced to exactly one, keeping all other clauses no worse. A free block sets all true. Thus existence is equivalent to routing one unit from each active block q_B=1 to an incident clause, where clause C has capacity |C|-1 (false-literal budget). Conversely each matching routes one false occurrence in that block to its matched clause and yields a valid occurrence word. Multiple edges retain distinct occurrence IDs. Expand a clause into |C|-1 slots for ordinary bipartite matching; total slots <=L.

Consider the bipartite multigraph of ALL parity/free blocks and clauses, one edge per occurrence. In a connected component with b block vertices, c clause vertices and e edges, total capacity=e-c >= b-1. For any nonempty proper subset S of the block vertices, form its incidence subgraph with all neighboring clause vertices. Each of its connected components has at least (#vertices-1) internal edges and at least one additional occurrence from an outside block to a neighboring clause, by connectedness of the original component and inclusion of every neighbor of S. Counting these disjoint additional edges gives total degree of neighbor clauses >= |S|+|N(S)|. Therefore their aggregate capacity >= |S|. Every proper demand subset satisfies all Hall inequalities. If e>=b+c (contains a cycle, including parallel-edge cycles), even the full set satisfies Hall. If e=b+c-1 (tree), the full set is impossible, and EVERY proper subset feasible. Thus the exact projected predicate is
    F_Q(x) = AND_{tree components T} (OR_{B in T} [q_B(x)=0]).
Cyclic components contribute no constraint, and trees containing a free block contribute a tautology. Includes zero-capacity unit clauses and singleton parity blocks. No rank bound on the shared quotient, no local multiplicity assumption, and no quotient assignment enumeration. The result proves for every x in G:
    F_Q(x) iff exists h in K with Mh in D and F(x+h).
Both directions: an original model has each tree with at least one inactive block, and an accepted representative yields a matching, a target occurrence word, and a Gaussian correction h with Mh=target-y(x), Ph=Hh=0. Store actual source, block and preimage registry; verify the lifted model on source clauses and original guard. This is support equivalence only, NOT original model-count equivalence (fiber sizes vary). Unlike arbitrary matroid circuit enumeration, capacities tied to actual occurrence degrees give the one-clause-per-tree result even with many blocks.
