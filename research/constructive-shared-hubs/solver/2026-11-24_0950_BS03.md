## 3. Main theorem BS03-A (PROVED)
For every acquired normalized row product satisfying the above certificate, let P=product_j(m_j+1) over BAD difference groups. In a fixed count k, choose an actual subset of k_j allowed one-rows in each group, respecting forced ones and forbidden alternatives; subtract exact baseline plus k_j signed costs and k_j mod2 XOR differences. The residual capacities are C_o=floor(R_o/d_o) clamped to number of incident GOOD blocks. Reject negative R_o. Dummy capacity is the number of GOOD blocks with a zero row. Let n be number of GOOD blocks.

Partition owners (including dummy) by equal h_o into g label classes, and let p_j be parity of the total number of chosen rows assigned to class j. Define augmented columns a_j=(h_j,1), and target z=(t XOR badTag XOR XOR_i b_i, n mod2). Then every feasible assignment satisfies
    sum_j a_j p_j = z.
Conversely, if such a parity word admits a capacitated assignment, its row lift has exactly the required cost and tag. Gaussian elimination produces a particular parity vector and kernel basis; enumerate ONLY 2^nu words, where nu=g-rank(a_1,...,a_g), not 2^q or 2^g. Inconsistent linear system rejects. Remove zero-capacity owners/classes as needed; deleting columns never increases nullity for a fixed gauge. A class may contain several owners with different capacities. It is their JOINT occupancy parity that is constrained, not each owner parity.

## 4. Exact parity-capacitated matching (PROVED)
For a fixed p, construct a graph:
* one vertex per GOOD block;
* C_o slots per owner o; connect a block to all slots of each owner for which an actual row exists;
* for each label class j, make all its slots a clique, plus one extra dummy vertex iff S_j mod2 differs from p_j, where S_j=sum C_o over the class. Extra dummy has no block edges.
Every perfect matching matches each block to exactly one allowed slot, respecting the owner cap. The unused slots and the extra dummy must pair within their class, so their cardinality is even; this is equivalent to desired class parity. Conversely any capacitated assignment with those parities uses distinct slots, and the remaining class clique vertices have even cardinality and can pair arbitrarily. A dummy requiring an unused slot is isolated if none exists, correctly rejecting. This proves both directions, with direct original row IDs, no counting of private lifts. The graph uses O(B+M) vertices and O((B+M)^2) edges because slot capacities are clipped by actual incident row count M. Binary capacities do not cause pseudopolynomial graph growth. Apply Edmonds general maximum-cardinality matching; if one label class, its parity is already total n mod2 and ordinary bipartite capacitated assignment suffices. No exact weighted-matching derandomization assumption.

This is strictly broader than constant per-block tags: a family with k owners labeled independent unit vectors and a zero-label dummy has augmented rank k+1 and nu=0, even though q=k and there are 2^(k+1) potential occupancy words. It needs one matching per fixed count, not 2^k syndrome states. Equal-label pooling may eliminate many more owner coordinates.
