## 1. Exact model and paid support closure
Explicit finite row domains R_i with distinct IDs. A row has nonnegative binary-encoded integer costs c_ij and Boolean tag coordinates p_ij. Select one actual row per block. For each budget owner j require sum_i c_ij <= B_j; for each parity owner k require XOR_i p_ik = t_k. All couplings must be included; an arbitrary nonlinear feature can be supplied as actual row tag. Input length N includes explicit table, coordinate bits, costs, IDs and source/guard description. Decision/lift only. Protected guard bits are not dropped; here they are factored into individual parity-owner equations. A fixed coordinate need not be represented as an incidence edge: retain its exact constant contribution in the owner equation.

For every candidate row r_i, budget owner j has a supporting tuple iff c_ij(r_i)+sum_{l!=i} min_{r in R_l} c_lj(r) <= B_j. Parity owner k has a supporting tuple iff at least one other block varies its bit, or the fixed bits of all other blocks XOR the candidate's bit to t_k. These are exact per-owner support tests, not independent global feasibility tests. Delete a row when any owner has no local support. Repeat after every strict deletion; detect empty block or impossible owner. At most the original total row count many deletions, polynomial scans, arbitrary precision. This is a certified unconditional closure relative to current fixed guard; branch masks remain conditional. No complete semantic closure assumed. The executable implements these owner tests, not the full all-peer closure.

## 2. Theorem BS05-A: mixed-owner forest terminal (PROVED)
Construct bipartite graph on blocks and ALL budget/parity owners. Join i,j iff contribution to owner j varies across R_i. Absorb constant contributions algebraically into owner constraints (code retains them in exact scans). Suppose the graph is a forest after closure. If no contradiction has been found, every remaining row of every block extends to a global feasible selection.

Proof: root the component at any block and prescribe any remaining row. For each adjacent owner, per-owner generalized arc consistency ensures an actual tuple of rows of its other adjacent blocks compatible with the prescribed parent row and all constant contributions. These tuples can be chosen independently because distinct outward subtrees are disjoint. Continue inductively at each child block, always keeping its selected row across every child owner. Each owner is visited once; all equations hold. A component with no variable incidence has only constant owners or independent blocks and is feasible exactly when closure says so. Disconnected components compose independently. Conversely each deletion is sound, so any original feasible selection survives. This proves both directions. Witness algorithm can repeatedly pin ANY row in a nonsingleton block and rerun closure: forest persists since masks only delete incidences; no failed choice is possible. At most number of blocks many pins. All rows are actual lifts, not minima assembled from inconsistent rows.

Consequences: polynomial deterministic decision and reconstruction independent of the number q of parity equations or numeric budget magnitudes (except encoded size). Unlike DS05 global q-bit message enumeration, we pay for the local parity-owner structure. This does not subsume DS05 when that structure is cyclic or its global XOR rank is tiny. This is the familiar exactness of tree CSP propagation specialized to cheap local support for high-arity parity and nonnegative budgets; no novelty claim for general tree-CSP theory.

## 3. Theorem BS05-B: optimal fixed edge-cut contribution volume (PROVED)
For each varying incidence e=(i,j) let D_e be the set of distinct actual contributions, with d_e=|D_e|>=2. To delete e, branch on its contribution, not the entire row. Restrict R_i to rows with that value; keep original owner equation and all other observations, including correlations with other cut edges. The removed edge becomes constant. An exhaustive disjoint split over D_e preserves every original tuple exactly once. Fixed cut set C whose deletion leaves a forest gives conditional time <= V poly(N), V=product_{e in C} d_e, with a polynomial factor for prefix nodes. This is potentially much smaller than whole-block conditioning: a row domain with M choices may have just two contribution values on the chosen cut edge. Correlations can reduce V further, never increase it.

The minimum such PRODUCT over all fixed feedback-edge sets of the initial varying graph is computable by maximum spanning forest. For a retained forest A, V=product_all d_e / product_{e in A} d_e. Maximize sum_{e in A} log d_e; all weights positive, and Kruskal depends only on their ordering, so sort integer d_e descending without numerical logs and use DSU. Standard graphic matroid exchange proves optimality. This optimizes the stated fixed edge-cut upper bound, not adaptive cuts, factor deletions, basis changes or true runtime. Product has polynomial bit length (sum log d_e over explicit incidences). Each edge can be charged for discovery; no guessed optimum.

Let k be number of remaining planned cut edges and V(R) the product of their current distinct contribution counts. Define credit P=(k+1)V(R), zero for contradiction. On a split, the chosen edge has d values. Subsequent closure only shrinks other domains. Sum V(child)<=V(parent), and k decreases. Thus sum P(child)<=kV(parent)=P(parent)-V(parent)<=P(parent)-1, including a constant-edge one-child skip. Terminal consumes credit. This proves c=1 contraction and <=P(root) processed nodes for the fixed schedule, no duplicate row charge. Polynomial root V is sufficient for polynomial total work; universally small V is not established. An exact state cache would need fixed source/targets, remaining cut index and complete row masks, not just domain cardinalities. Code intentionally has no cross-branch cache; within-layer DAG key is the exact total cost vector and XOR word, with one actual witness. Charge every attempted edge even if duplicate. No signed weight cancellation, projected counting, or unsafe guard merging.
