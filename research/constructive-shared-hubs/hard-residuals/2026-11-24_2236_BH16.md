## A. Exact anchored selector graph
On an actual near-model w, each good owner becomes R(a;b,c), z_a in {z_b,z_c}, z=x XOR w (BH15). Add two uniquely labeled host edges ab,ac, and declare them a conflicting pair. The cut of any flip word z is conflict-free iff all good owners hold: both edges cross exactly when z_a differs from both other bits. For a single bad full NAE triple {s,t,u}, a repair exists iff at least one of its three pairs is separated by a conflict-free cut. For a chosen pair (s,t), use guard z_s=0,z_t=1; global complement accounts for the opposite orientation only when there are no additional guards. In a linear source the host graph is simple and the conflict graph is a disjoint union of edges. Equivalently select one edge of each owner pair; s,t must be disconnected in the selected graph. Any legal cut has a noncrossing edge per owner; conversely label selected components with s,t distinct. This is the anchor-relative two-choice specialization of MS22's signed three-choice selector model, not a claim of polynomial discovery. All labels retained; lift and verification linear in explicit graph/source. With b bad full NAE owners, one can require a chosen pair to differ per owner, but must pay the 3^b combinations and actual common coloring (not independent pair feasibility). A one-sided relaxed owner requires its separate semantics.

## B. Seed-specific sparse hardness versus the unseeded theorem
Kalyanasundaram and Kumar, Conflict-Free Cuts: Exploring the Boundaries of Tractability, arXiv:2611.15846v1 (11 Nov 2026), Definition 1, Section 1.1 and Theorem 2, https://arxiv.org/html/2611.15846v1, report polynomial unseeded CF-cut with matching conflicts and |E|<=2|V|. Their theorem asks for ANY nontrivial cut. The designated s,t version is NP-complete even with a simple connected host, all conflicts local, conflict graph exactly 1-regular, and |E|<=2|V|. Proof: start from arbitrary signed NAE, introduce X_i,Y_i and two terminals s,t. All-good R(s;X_i,Y_i), R(t;X_i,Y_i) force X_i != Y_i when s!=t. Each source NAE becomes R(complement-representative of first literal; representatives of other two). All these R accept zero; under the terminal inequality they exactly encode the original. Apply BH15 occurrence-splitting equality chains using sign-switched six-edge Fano gadgets with all-zero witness, retaining s,t as hubs. All ternary owners now linear, all accept zero and hence are R relations with actual minority centers. This is a polynomial exact seeded reduction; a valid cut decodes source, and source model lifts with s=0,t=1. If graph disconnected, connect components with R(new;a,b) using one vertex in each component, which is freely extensible by new=a. Preserve simplicity/linearity. Append k pendant wedges R(a;p,q) with two private new vertices, chaining from a prior leaf. Each adds 2 host edges and 2 vertices; it preserves every original assignment via p=q=a and contributes no new restrictions on source. Choose k>=max(1,m-n) with m=owner count before padding, n=vertex count. Then host |E|=2(m+k)<=2(n+2k)=2|V|. Every edge belongs to exactly one local conflict pair. Membership in NP is direct. The final leaf singleton is always an unseeded cut, including on UNSAT seeded inputs. Thus mere access to the unseeded polynomial algorithm cannot answer the seeded repair question. This is an NP-completeness reduction, not P!=NP, and asserts no maximum host degree four or growing-girth bound. The padding construction even permits |E|/|V|<=1+epsilon for any fixed positive epsilon using polynomially many wedges. It does not guarantee a sparse terminal core. No claim of novelty for conflict-free cut itself.

## C. Exact aggregate block reduction (new positive normalization)
For ANY undirected explicit host with local conflicts (including unpaired edges), if s,t disconnected, component coloring gives a repair. Otherwise form the block-cut incidence tree with blocks including bridges. On its unique s-to-t path, let a_i,b_i be the two consecutive path vertices of block B_i (including s,t at ends). Seed separation holds iff at least one B_i admits a local conflict-free cut separating a_i,b_i, retaining only conflict pairs with both edges in B_i. Necessity: a path from s to t through these interface vertices has unequal consecutive colors somewhere. Sufficiency: take one local witness, color every component of G-E(B_i) touching B_i constantly with its attachment vertex color; each such component meets B_i in at most one vertex (block maximality). Other components constant. Only edges in B_i can cross, so every discarded conflict has a noncrossing edge, including cross-block conflicts. Recover original variables and verify all good and designated bad owners. This does not transport arbitrary extra guards; a local derived pin may be omitted from the subquery only if logically implied by the original seed problem, and verify it on return. For other guards decline absent exact adapter.
A bridge on the path is an immediate positive terminal. Otherwise nontrivial block subqueries use mu=|E|-1>=1. For k>=2 path blocks, sum mu_i=sum |E_i|-k <= |E|-2=mu-1; for one block with off-path edges, the same strict inequality holds. Every child edge is disjoint, duplicate consumers and graph dictionaries are charged. If one full block remains there is no contraction and the method declines. Block discovery by DFS (or any polynomial standard block algorithm), source maps, all local conflict lists and reconstruction polynomial. Can use polynomial-sized graph states with original N; per-occurrence work polynomial, sum of children credit pays both labels, same serial T/S/CM as theorem aggregate. Three seed pairs may each require an initial whole-chart test; constant factor, charged as three top-level jobs (not pretending their sum contracts raw rank). This result deletes arbitrary irrelevant pendant cores, precisely undoing sparse padding, and never changes a protected terminal inequality. Does not resolve biconnected seeded core. For multi-demand guards do not apply the single-block OR rule: different demands may need different blocks.
