## 2. Theorem: exact affine-disjunction core
For every explicit finite system over GF(2), let Gx=g be a consistent affine guard and each factor j be
    C_j(x) = OR_{(a,b) in L_j} [a dot x = b].
All other couplings must be included or protected. This is precisely avoidance of one affine rejection guard per factor. It includes ordinary CNF, signed NAE triples (two relative-bit alternatives suffice), one-sided owner relaxations and BW03's individual rejection guards. Multiple bad guards are retained as separate factors. Do not replace an arbitrary relation by its affine hull.

Let K=rowspan G. Optionally include a protected observation matrix in K, with fixed consistent values in the current context; if values are not yet fixed, the following lift is pointwise for every consistent value assignment. Let A_J span all observation rows from factors J, and
    h(J)=dim(K+A_J)-dim K,   d(J)=|J|-h(J),   delta=max_J d(J).
The empty set is allowed. Rank is submodular, so d is supermodular. Maximizers are closed under union and intersection, with a unique smallest maximizer X.

For every Y subset of the complement of X:
    h(X union Y)-h(X) >= |Y|
because d(X union Y)<=d(X). Apply the linear/partition matroid intersection min-max (Rado) to labeled alternatives in exterior factors, in the quotient by K+A_X. A full independent transversal exists: one actual observation row from each exterior factor, independent modulo K+A_X. The labels b must be retained.

For every assignment satisfying G and all core factors X, preserve all its A_X and protected observation values. Assign each selected exterior row its own satisfying RHS b. The added equations are independent modulo the preserved row space, so the resulting affine system is consistent and Gaussian elimination produces a complete assignment. Each exterior factor has at least its selected true literal. Conversely a full model restricts to a core model. This is exact decision and exact projection onto protected/core observations, not equality of full solution sets or counts. A chosen representative is an extension device, not forced information about all source models.

Consequences: X=empty (delta=0) gives deterministic polynomial SAT construction even for dense nonlocal observations. The procedure gives exact equisatisfiable reduction for every explicit affine-disjunction formula, but does not guarantee a small core. An inconsistent guard or empty rejection complement is handled before rank analysis.

## 3. Polynomial discovery without subset enumeration
Let q(J) be maximum size of common independent selection from alternatives of J, where each factor has capacity one and rows are independent modulo K. Rado min-max gives
    q(J)=min_{Y subset J} (|J-Y|+h(Y)).
Thus delta(J)=|J|-q(J) equals max deficiency on J. Compute delta on all factors, and for every i on the set omitting i. An i belongs to every maximizer iff delta(E-i)<delta(E). Their intersection is the unique smallest maximizer X. One additional intersection call constructs the exterior transversal modulo K+A_X. If delta=0 skip deletion tests: the full representative forest already solves the source. At most m+2 intersection calls. Shortest exchange-path algorithm is deterministic; each independence test uses Gaussian elimination or graph DSU for incidence rows. All alternative IDs retained; no enumeration of candidate subsets in the solver. Exhaustive subsets are used only in small independent controls.

Given k=dim(K+A_X)-dim K, an exact residual evaluator can enumerate the 2^k consistent core-observation words (or employ better peer terminals); then Gaussian lift. Basis projection and word construction polynomial; no need to branch on every original variable. Thus T<=poly(N)+2^k poly(N) for explicit source length N; conditional polynomial if k=O(log N). This rank-enumeration implementation is symbolic; main test uses DPLL on original core vertex IDs and supplemental uses exhaustive small original-coordinate residual checks. Do not infer 2^delta or a universal logarithmic k.

## 4. DO01 critical structure and direct single-owner repair
For a full signed NAE triple, choose two observation rows x_u+x_v and x_u+x_w with the satisfying RHS making the corresponding literals different (third pair redundant for rank, usable in graph matching). For a monotone hypergraph, h(J)=n-c(V,J) with isolates counted. This is graphic rank of the union of the candidate pair edges. Thus a full transversal is a forest trimmed from the hyperedges. The forest imposes signed pair relations, satisfiable for any signs without cycles. This does not require small Berge cycles, planar primal host, small count volume or local affine closure.

For a connected inclusion-minimal non-2-colorable 3-uniform H with n vertices and m hyperedges, every maximum-deficiency core must be the entire factor set; otherwise a proper subset would be UNSAT by exact extension. Hence
    delta(H)=m-n+1 >=1,
    |J|-h(J)<delta(H) for every proper J.
In particular m>=n, and for every nonempty removed set S, c(V,H-S)<=|S|. This is a necessary structural condition, not a sufficient UNSAT certificate. It applies to DO01 high-girth critical instances irrespective of girth.

Now relax one of the two owner budgets on a single triple: replace NAE by one ordinary three-literal clause, with rows e_u,e_v,e_w and common satisfying bit b. Its row span contains the former two-dimensional difference plane, so no subset rank decreases. For the whole connected H it adds exactly one independent direction (all difference rows span even parity, and a coordinate has odd parity). All proper subsets originally have deficiency <=delta(H)-1, so
    delta(single-owner neighbor)=delta(H)-1
exactly: lower bound from the whole set, upper from every subset.
In particular if m=n (deficiency one), ALL 2m single-owner neighbors have delta=0 and are solved directly by one full linear transversal plus Gaussian lift, no enumeration of hub values, even if the parent has high girth. This proves a conditional generalization; existence of arbitrarily high-girth critical deficiency-one families is NOT asserted. Larger-deficiency neighbors may remain outside this particular terminal. Their SAT status follows from criticality and complement, but computing a witness is still chargeable.

Fano: m=n=7, all 21 pairs occur once, so NAE requires 14 cut pairs while a cut of K7 has at most floor(49/4)=12. Root UNSAT independently of rank method. Both implementations executed exact residual search on root; cut inequality is symbolic. All 14 one-owner neighbors were solved directly; the supplemental implementation retains the surviving one-sided constraint instead of deleting it and complementing. Each has five actual source models (exhaustive reference). This is a new rank repair certificate beyond BH02's alternating two-anchor cover and S06's count-volume terminal.

Counterexample: all four triples on four vertices have delta=1 and are SAT (six 2+2 colorings). Trim the first three triples to the three star edges from vertex zero. This maximum transversal yields a 1+3 coloring and violates the omitted fourth triple; another model satisfies all. Thus neither positive deficiency nor failure of one arbitrary maximum transversal establishes UNSAT. No claim that rank deficiency alone decides arbitrary residuals.
