## BH22-A: tree-corrected conditional expectation (PROVED)
For an explicit affine chart with consistent guard G, each forbidden packet E_i is an affine event on uniform solutions of G. For any forest T on owner IDs, define f(x)=sum_i 1[E_i(x)] - sum_{ij in T} 1[E_i(x) and E_j(x)]. This equals the number of connected components of the forest induced by the violated owners (zero iff none). Hence f>=1 on every rejected word. A sufficient SAT certificate is
B=sum_i P(E_i | G)-sum_{ij in T}P(E_i and E_j | G)<1.
All probabilities are exact Gaussian rank and consistency computations. Maximize edge weight over spanning trees using polynomial maximum spanning tree acquisition (Hunter's classical bound, DOI 10.2307/3212481). Fix that tree, then successively condition on an original coordinate or a kernel basis bit, choosing a nonempty side with smaller conditional expected f. The conditional expectations average to the parent expectation with actual fiber weights. At completion f is a nonnegative integer <1, hence zero. This yields a deterministic verified witness with polynomial bit work, not an oracle and not a rejection rule when B>=1. Before acquisition, delete impossible packets and reject full-fiber packets; a codimension-one forbidden event forces its opposite affine row, restart after each deduction and at stagnation. Internally choosing witness bits is not an unconditional inference. The checker uses fixed tree conditional expectations, verifies actual guard and original packets. Its naive maximum-tree loop uses O(m^3) rank queries; cached weights permit O(m^2) acquisition; lift uses O(nm) rank queries. Exact counts have O(n+log(m+1)) bits. All failed tests, closure, guard access and witness verification charged. Same serial T,S polynomial, CM <= (T+1)S in this admitted chart.
