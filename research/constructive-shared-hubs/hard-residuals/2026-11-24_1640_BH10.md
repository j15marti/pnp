## 2. Exact source adapter and mandatory scoped closure

DO01's paired unit budgets give exactly these masks after fusion: sum bits<=2 rejects all 1, sum (1-bits)<=2 rejects all 0. The block parity cycles carry the actual same selector bit; no new independent copies. One-sided relaxation preserves the surviving budget. The result applies to this authenticated selector domain, not arbitrary physical quota/tag rows. All extra couplings must be represented exactly or terminal declines.

Introduce ONE common reference bit r and write original bits x_v=y_v XOR y_r. For a full NAE factor on signed literals x_v XOR s, use NAE(y_v XOR s) by complement invariance. For a mask rejecting only all b, append literal y_r XOR b. This rejects precisely that original monochromatic word, including when y_r=1. The neither-mask factor is tautological. Every original legal word lifts by y_r=0; conversely any homogeneous solution decodes to original legal word. This also maps an ordinary CNF clause to NAE(literals, reference literal corresponding to forbidden all-false). It does not preserve counts without handling the global complement duplication.

A coordinate pin or signed equality x_u XOR x_v=p is a parity equation y_u XOR y_v=p, with v=r for a pin. Use parity union-find, substitute all current signed representatives, remove tautologies containing opposite literals of same representative, deduplicate equal literals. NAE of one or zero literals is contradictory; NAE of two distinct reps is a necessary XOR inequality, merge and restart closure immediately. Stop at stagnation before matching. Remaining scopes have >=3 distinct reps and full individual affine hull (scoped closure only, not semantic closure). Retain original guard and reconstruction registry; never export variant/branch deductions to other guards. ## 3. Theorem BH10-A: incidence matching + signed functional digraph (PROVED)
For every finite explicit homogeneous signed NAE system after the above closure, if the bipartite incidence graph has a matching saturating every factor, there is an exact deterministic polynomial-time decision and witness algorithm.

Match each factor i to a distinct pivot vertex u. For each other literal v in that factor, add directed arc u->v with bit label p=1 XOR s_u XOR s_v. A factor is legal iff at least one outgoing arc satisfies y_u XOR y_v=p: if the literals are not all equal, any chosen pivot has a different literal somewhere. A matched vertex must choose one such arc; unmatched vertices have no outgoing arcs and are free. Selecting one outgoing arc per matched vertex gives a functional graph. Equations on selected arcs are simultaneously solvable iff the XOR of labels on every selected directed simple cycle is zero. Every tree into a sink or cycle lifts by backwards substitution.

Compute SCCs of the whole directed graph. Exact criterion: every sink SCC is either an unmatched isolated vertex (outdegree zero) or contains a directed SIMPLE cycle with label XOR zero.

Necessity: any satisfying word enables some outgoing arc at every matched vertex. A sink SCC without free vertex must contain a selected functional cycle, and its equations force label XOR zero. Sufficiency: choose one zero-XOR cycle per nonfree sink, color each consistently, set free sinks arbitrarily; every other vertex reaches this seed set because every SCC in the condensation reaches a sink and every vertex in a sink reaches its chosen cycle. Multi-source reverse BFS selects one arc towards an already assigned vertex, sets its value by that arc, and terminates. Thus every matched factor has a witness, independently of chosen incidence matching. Decode all original bits and verify all original factors/guards. All labels are on actual shared hub coordinates; there is no independent marginal gluing.

To find a zero-XOR directed SIMPLE cycle, subdivide every label-0 arc once with a fresh degree-two directed path (length 2), keep label-1 arcs length 1. Simple cycles correspond bijectively; even length iff label XOR zero. Use the deterministic polynomial even-directed-circuit recognition theorem of Robertson, Seymour and Thomas (1999 arXiv math/9911268; Annals 1999), independently McCuaig. This is an established result, not a novel proof of even-cycle recognition. The RST abstract explicitly includes n-vertex/n-hyperedge minimal nonbipartiteness among equivalent problems. Our contribution is the signed, one-sided owner, guard-closure adapter and direct portfolio application. Construct a witness cycle from the recognition algorithm by deleting each arc whenever the remaining graph still has an even simple cycle; by monotonicity an arc once indispensable stays indispensable. At most O(L) decisions, and final surviving arc set is exactly one even cycle up to isolated vertices. Contract subdivision paths. No use of a generic SAT oracle. A repeated odd cycle gives an even closed walk but NOT a simple even cycle; ordinary doubled-state reachability is insufficient.

If incidence matching fails, return UNKNOWN; no inference about decision from failure. A fully arbitrary affine event not of the exact signed NAE form does not enter this terminal.

## 4. Critical core and neighbor consequences (PROVED)
For connected unguarded monotone NAE, let n active variables and m fused triples. A DY10/BA10 strict maximum-deficiency core with m=n has total pair-difference rank n-1 and D(full)=1. For every nonempty proper owner set J, D(J)<=0, hence |J|<=rank U_J<=|V(J)|-1. For the full set |V|=n=m. Therefore Hall holds. Any matching is perfect on active variables. In fact the oriented graph is strongly connected: a proper sink SCC S would own exactly |S| matched factors all contained in S, contradicting the strict proper Hall surplus. BH10-A now decides the whole root by one polynomial even-directed-cycle test. Edge-critical UNSAT m=n cores satisfy this rank premise by DY10; no promise of UNSAT is needed by BH10-A. It handles SAT cores satisfying incidence Hall too.

Relax one of the two paired owners of any triple. Homogenize that remaining one-sided factor by adding r. All proper owner subsets still have |V(J)|>=|J|+1 (no scope shrinks), and full set now has n+1 vertices. Thus every nonempty owner subset has strict Hall surplus. A matching exists and EVERY sink SCC must be free: a matched-only sink S owns |S| factors with all scopes contained in S, contradicting surplus. Reverse BFS from unmatched vertices yields a polynomial witness, with NO even-cycle oracle or syndrome enumeration. This recovers BD10/DY10 neighbor theorem by a simpler graph lift. It also handles any degree, girth or width satisfying the premise. The original Fano and DO02 49/49, 931/931 controls satisfy it (criticality from DO02). The theorem decides these sources even without a supplied equality-wire manifest; the polynomial oracle implementation remains unexecuted, see below.

This does NOT cover all DO01/DO09 high-girth critical instances. Those may have m>n and then the unrelaxed monotone incidence matching cannot saturate all factors. No general bound m=n follows from criticality; indeed linear 4-regular NAE-3SAT is NP-complete (Darmann and Döcker 2019, arXiv:1908.04198), with m=4n/3. DO02 high-girth stretch for general g need not preserve m=n. For any m=n critical high-girth member, the theorem applies independent of girth. Not a P=NP proof.
