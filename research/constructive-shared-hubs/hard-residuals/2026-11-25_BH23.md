## Exact critical-density classification
Suppose there are exactly q+1 hole events, q=2^r, r>=1, each has codimension r within G, and each pair of linear observation maps has joint rank 2r. All individual probabilities 1/q and pair probabilities 1/q^2, irrespective of offsets. For the full simple cycle:
 B=(q+1)/q-(q+1)/q^2+Pr(all holes)=1-1/q^2+Pr(all holes).
Each pair intersection contains the full intersection, hence B<=1. If the full intersection is inconsistent or rank >2r, B<1, yielding a constructive SAT lift. Otherwise the intersection C is nonempty of codimension 2r, and every pair intersection equals C by equal sizes and containment. The union has size |C|+(q+1)(|G|/q-|C|)=|G|. Thus exact UNSAT iff all holes have a common intersection of codimension 2r. This proves both decisions without enumeration of subsets. The optimal tree always has expectation exactly 1, so every strict tree certificate declines. This is a new exact coverage of the MS30 obstruction, not merely another sufficient inequality.

For a group of punctured affine tables, use the kernel of the sum map. Pairwise projection ranks 2r and each rank r are target-independent; offsets vary with the affine target. If the stacked hole observation rank exceeds 2r, every target in the affine sum is accepted. If rank equals 2r, precisely the targets in the affine image of the coefficient slice with every hole block fixed are rejected. This image is computable by Gaussian elimination (a point when all tables have exactly one hole and no other free blocks). Replace q+1 tables by a single full or punctured affine sum in the all-punctured case. With unpunctured blocks, retain one general affine forbidden packet, not a point hole unless proved. Witness reconstruction uses the exact target and conditional expectation; a fixed SAT target never implies uniform full support. In the pure group, 1+#tables+sum dimensions strictly decreases and each reverse lift is paid. One can scan the full current group or other polynomially listed groups; discovering eligible subsets of arbitrary cardinality is not assumed free. Use original-N representation caps. No guarantee of universal eligibility.
