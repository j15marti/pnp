## 1. Model and closure

B={0,1} is signed NAE, singleton is one-sided clause. DO01's unit paired upper budgets 2 on three literals and their complements are exactly B={0,1}; relaxing either to 3 removes precisely one forbidden bit. Pinned unequal literals make it tautological; pinned equal literals intersect B with their common value and are removed. Empty scope with nonempty B is inconsistent; singleton with one forbidden bit forces the complementary value; singleton with both forbidden bits inconsistent. Restart certified normalization/units after each strict deduction and before any branch. No complete semantic/LP/portfolio closure is assumed or implemented. ## 2. BH07-A: tree component projection (PROVED)
If C is a tree, choose a root, assign it offset p_r=0, and for each parent-child edge x with incidence signs s_u,s_v define
 p_v = p_u XOR 1 XOR s_u XOR s_v.
Let A be the boundary literal list, with every literal at v negated if p_v=1. Define projected bad mask
 B' = intersection_v { b : b XOR p_v belongs to B_v }.
Then C is extendable iff the signed wide factor (A,B') is satisfied. In particular at most TWO affine rejection events suffice on any common affine exterior chart: for b in B', all transformed boundary literals equal b. These events are disjoint when at least one boundary port exists. For a ternary tree, number of boundary ports before deduplication is exactly t+2. General arity sum minus 2(t-1).

Proof: root the tree. Each nonroot subtree always permits at least one value of its parent-edge variable, since after choosing feasible child-edge values and fixed external literals, at least one parent literal avoids an all-equal forbidden tuple (arity >=2). The feasible parent-edge set is singleton precisely when ALL other incoming literal values are forced to one common b_v, and b_v belongs to B_v; then the parent-edge literal must be 1 XOR b_v. A flexible child gives the ability to avoid the bad all-equal tuple and hence both parent values are feasible. At the root, failure iff every incoming literal is forced to the same b_r in B_r. Recursing down the unique child-edge requirements gives b_v=b_u XOR 1 XOR s_u XOR s_v, and all boundary literals at v must equal b_v. Conversely those equations plus all local bad-mask memberships force each message and then the root failure. This is exactly the two projected bad events; all other boundary words extend. Boundary repetitions and protected correlations simply constrain those equations, never become independent words.

Given an exterior word, bottom-up two-state support DP stores actual choices per parent bit. For each row, choose feasible child defaults; if they cause a forbidden uniform tuple, flip any flexible child; if none exists the row is infeasible. Then top-down lift verifies all original factors. No exponential boundary enumeration. This generalizes the BH05 degree-two hub resolution from two factors to an arbitrary private tree and retains asymmetric one-owner masks.

## 3. BH07-B: cyclic autarky (PROVED)
If C is cyclic, it is universally extendable for every exterior word EXCEPT a connected pure binary full-NAE cycle with inconsistent parity. For that exception, every factor has exactly two literals and both bad bits, e=t, and all ports are private. It is feasible iff XOR_e (1 XOR s_u XOR s_v)=0. This includes two-edge parallel cycles.

Proof: choose a spanning tree plus one extra edge, forming one simple cycle (allow two parallel edges). Fix remaining chord variables arbitrarily to 0. All off-cycle tree branches can be satisfied bottom-up, choosing their outgoing variable values. At each cycle vertex, remaining noncycle literals are now fixed. For all but one cycle vertex choose the two cycle literals unequal, giving a chain with two solutions related by flipping all cycle variables. If some cycle vertex has another literal (including a fixed chord or attached tree edge), leave that vertex as the break. If the two cycle literals there differ both chain solutions work; if equal, choose the solution opposite one fixed other literal, hence nonmonochromatic. If no cycle vertex has another literal, connectedness and arity force C to be a pure binary cycle. If some vertex has at most one forbidden bit, break there and choose the correct complement of the chain solution; otherwise exact binary parity is necessary and sufficient. All choices preserve actual exterior assignments. Thus every nonexception cyclic component projects to TRUE, even with many independent private cycles. The same tree-support DP gives a lift by fixing all non-tree edges except one to 0 and trying that edge both values. At most two DP runs, no exponential feedback-set enumeration. A fixed odd binary full-NAE cycle is a hostile control: it is UNSAT, so the unconditional claim without the arity/mask exception is false.

## 4. Aggregate reduction, exact decision, and critical structure
Normalize, delete a degree-one variable's sole factor (there is always an extending value for arity>=2), or contract an eligible connected degree-two component. Keep original region records and reverse lift in reverse order. Restart closure after each strict step and at stagnation before branching. Each component replacement removes e variables and at least e*2 literal occurrences, since new ports are a subset of old boundary occurrences. A cyclic deletion removes all its factors; tree projection replaces t>=2 factors with at most one. No variable's occurrence count increases. The potential active literal-occurrence count decreases under every such strict rewrite. This is an actual unary polynomial progress bound, not a bound on the aggregate of arbitrary guarded children. No hidden exponential expansion or exact support query is required.
If h is the number of original variables with active degree >=3 after initial closure, exhaust the contractions and leaf deletions; all remaining variables are a subset of those h. Exact guarded fallback (pin one remaining variable, run closure anew) costs <=2^h poly(N) time, poly(N) peak space in a serial depth-first realization; a polynomial terminal if h=O(log N), or if another paid terminal resolves the residual. No universal h bound. In particular Fano root has seven degree-three variables and stalls at root, so the unconditional local-rewrite-progress claim is false. Finite Fano decisions below use exact fallback.
For an edge-critical monotone NAE-3 source, every degree-two variable belongs to the private clause graph. That graph must be a forest: any cyclic component would project to TRUE, allowing its deletion and lift of a coloring of the proper remainder, contradicting criticality. If n_2 counts degree-two variables, c is the number of components of that forest including isolated factors, and m is the number of triples, then n_2=m-c. There are no degree-one variables in a critical core, so h=n-n_2. The total incidence count on high-degree variables is 3m-2n_2=m+2c. For max degree Delta,
 h >= (m+2c)/Delta >= (2n/3+2)/Delta.
This is a structural tradeoff on DO01 cores, independent of girth. It is linear for bounded Delta, not a claim that bounded-degree infinite critical families were generated here. Criticality does not give logarithmically many remaining hubs; the forest result does not solve general high-girth critical cores.
