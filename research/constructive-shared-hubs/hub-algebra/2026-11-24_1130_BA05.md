## 3. BA05-A: discover a line-transversal repair separator
For each triple R_i define its two-dimensional difference plane U_i=span(R_i+a_i), a_i any point. A separator H <= V is eligible iff dim(H intersect U_i)=1 for every triple. Affine factors impose no such condition.

Given rank cap r, discover H of dimension <=r (or certify none in this particular domain) in O(3^r poly(N)): start at H=0. Reject a node if any U_i is contained in H. Otherwise select a plane disjoint from H; branch over its three nonzero directions, adjoining one to H. If no disjoint plane remains, accept. Every branch adds one independent dimension; at depth r stop. If an eligible H* exists, follow a branch using a direction in H* intersect U_i. The growing H stays in H* so it never contains a whole U_i, and a successful leaf exists. All intersection and equality tests are Gaussian. A failed search is UNKNOWN for SAT, not a contradiction of source.

## 4. BA05-B: exact guarded affine-selector form
Write pi:V->V/H. Each triple has exactly two distinct projected tags, one singleton fiber and one doubleton fiber. Let a_i be the singleton, v_i one point of the doubleton, h_i the nonzero difference of its two points in H. The actual local row set is exactly
 {a_i + s_i(v_i+a_i)+e_i h_i : s_i,e_i in GF(2), e_i=0 if s_i=0}.
An affine factor has an ordinary affine parameterization with no conditional repair. Collect all base coordinates (including affine-factor variables) into s. Their projected XOR equality is a linear system; solve or reject by Gaussian elimination. All its solutions have affine parameterization s=s0+Kz, z in GF(2)^d.

For each z define B(z) the XOR of base tags and a(z)=b+B(z) in H. Exact compatibility iff
 a(z) belongs to W(z)=span{h_i : s_i(z)=1}.
Both directions: every actual tuple yields such coefficients; conversely a Gaussian representation in enabled directions selects actual doubleton alternatives and leaves all singleton fibers unchanged. Recover actual local rows immediately. Every affine observation included in the tag is preserved; no independent mixing of guard words or integer loads. This is a decision/witness terminal, not a model count.

## 5. BA05-C: the low-codimension witness lemma (central advance)
If any z* is feasible, choose a basis h_{i1},...,h_{ik} of W(z*), k<=r. Impose the k affine equations s_{ij}(z)=1, and the r-k affine equations that a(z) lies in their fixed span (apply quotient H/W(z*) to a(z)). This system is consistent at z*. Every solution is feasible, because those same k directions are enabled. Hence the feasible selector set, if nonempty, contains an affine subspace of codimension AT MOST r, regardless of d. The codimension is k+(r-k), not 2r or the number of local constraints. We do not acquire the unknown basis by enumerating subsets of factors; the lemma proves existence of a large affine witness region and is used only to justify an explicit deterministic hitting procedure. The ambient SAT set itself need not be affine.

Generalization (symbolic): if each enabled generator requires at most a affine equations rather than one, the same proof gives codimension <=max(1,a)r, provided the baseline is affine and enabled generator choices are independent and pointwise authenticated. No such claim for arbitrary nonlinear activations.

## 6. BA05-D: construct the hitting family and solve deterministically
For d=0 test the unique word. Otherwise take a power of two Q>(d-1)(2^r-1), Q>=2. Construct GF(Q) with a deterministic irreducible-polynomial search (trial division is already polynomial in Q). Fix a binary coordinate basis. For each x,y in GF(Q) define z_j=<y,coords(x^j)> for j=0,...,d-1, the ordinary binary dot product. Enumerate Q^2 ordered pairs, streaming.

For any nonzero affine system linear combination with coefficient word u in GF(2)^d, its associated nonzero polynomial P_u(X)=sum_j u_j X^j has <=d-1 roots. For a rank k<=r system, union over its 2^k-1 nonzero row combinations excludes at most (d-1)(2^r-1)<Q field elements. At a surviving x, the k field values associated with the independent rows are linearly independent over GF(2). The dot-product map from y to the k desired bits is surjective. Therefore this explicit sample hits every consistent affine system of rank <=r, without knowing which one exists. Test each sample by Gaussian repair membership and lift on success. Exhaustion proves UNSAT under the eligibility promise, not a probabilistic estimate. May instead enumerate all z if cheaper. This proof is self-contained; related standard small-bias constructions cited below. It does not assert small bias fools arbitrary quadratic predicates: the affine witness-subspace lemma is essential (cf. repository AFFINE-TO-QUADRATIC-SMALLBIAS-FIREWALL237, read lines 1-90).

Q=O(max(1,d)2^r), so total time T <= (3^r+4^r)poly(N), including discovery, closure, field construction, all failed attempts, repair and verification. Thus T<=4^r poly(N), S<=poly(N) with streaming samples and a depth-first discovery stack. If the rank r=O(log N), decision and source witness are uniformly polynomial, independent of selector nullity d or fixed-order syndrome width. Iterative deepening adds only a geometric factor. For r=0 the problem is affine. Code uses an explicit field cap (4096) and reports UNKNOWN rather than a false label if exceeded; symbolic algorithm has no such cap.

## 7. Protected observations
For a raw triple with three distinct base tags, append any q-bit XOR observation to each actual row (even nonlinear in base tag). If the original planes admit H, then H times GF(2)^q intersects each lifted plane in exactly one dimension: base projection is injective on that plane and the intersection condition is inherited. Rank rises by at most q. Binary/one-point factors stay affine; larger affine factors require separate verification of the augmented relation. Thus with these premises there is a direct T<=4^(r+q)poly(N) fixed-target terminal; all 2^q guards can be queried with the additional explicit 2^q factor, or a single guard retained without enumeration. This is a different route from BD05's signed counting, and does not guarantee stability of an earlier quotient whose archived original observations were erased. Do not apply to arbitrary key-dependent costs or many rows sharing a base tag. This extension is symbolic, not separately executed.
