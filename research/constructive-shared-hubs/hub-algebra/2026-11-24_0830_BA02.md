## 2. Exact theorem (PROVED)
Let E=GF(2)^D. For every independent product of nonempty explicitly acquired distinct syndrome sets R_i in E and exact target t, feasibility means XOR of one row per factor equals t. Store a source lift for every tag. All other restrictions, including fixed guards and any protected bits needed later, must be encoded in complete rows or retained separately as exact keys. Let H be a nonzero subspace and pi:E->E/H a linear quotient. For two different independent factors A,B, define
  m_A=min over a in pi(A) of |A intersect pi^{-1}(a)|,
  m_B=min over b in pi(B) of |B intersect pi^{-1}(b)|.
If m_A+m_B>2^dim(H), then the original instance is SAT iff the instance with EVERY factor and target projected by pi is SAT. There is no need to merge A and B or materialize A+B.

Proof: a feasible tuple projects. Conversely take any projected solution, choose actual preimages in all factors. Their XOR discrepancy d belongs to H. Hold the other factors fixed. The selected A and B fibers are translated subsets of H. For any desired sum in their sum coset, translation of the B fiber must intersect the A fiber by the strict cardinality inequality. Scan A and look up the required partner in B to repair d, leaving all projected labels intact. This proves exact lift for arbitrary other factor choices, not just for a favorable pair of quotient rows. Equivalently A+B is H-saturated, but we never construct that sumset. Note individual factors need not have ANY period. For three-state tetrahedral fibers of size 3 in a plane of size 4, 3+3>4, so the theorem applies even with independently varying missing colors and different external quotient supports. If A and B are two views of the same selector, the independence premise fails: identical choice gives r+r=0, not arbitrary H.

The strict inequality is essential: two fibers {0,u} in a 2D plane have combined size 4 but cannot reach v outside span(u). Merely measuring total density across all quotient fibers is invalid; the minimum across fibers matters. Count distinct tags, not row multiplicities. This is a decision/witness theorem, NOT a model-count or complete affine-hull-preserving quotient.

## 3. Paid discovery and closure (PROVED)
For each factor define U_i=span(R_i+r_i0). Test H=U_i intersect U_j via deterministic Gaussian elimination for each unordered pair. Construct canonical quotient representatives by pivot reduction and group each factor by projected tag. Count distinct rows in each fiber and verify the inequality using exact integers. No enumeration of H or pairs of full rows. Accept only if certified. A nonzero accepted H lowers the current total difference-span dimension by dim H; every table is projected separately, never increases in cardinality. At most D accepted quotients, with a polynomial number of failed pair checks per sweep.

Before discovery apply affine necessary row-support closure: delete x in R_i if t+x lies outside the affine hull of the sum of other factors. Recompute after EACH strict deletion, after EVERY accepted quotient, and at stagnation before DP. Empty factor rejects. No claim of complete semantic or all-channel closure. Deductions under fixed guard retain guard identity; a changed guard requires recomputation or an exact proved lift. A singleton tag does not imply a unique source assignment. The code does not branch on unresolved variables; exact DP handles the remaining residual.

Optional further discovery (symbolic only): if a valid H has constant dimension h, one of A,B has a fiber of size >|H|/2, whose difference set equals H by the same intersection argument. Consequently H admits a basis of h pair differences from one factor. Enumerate h-tuples of within-factor differences, test independent spans and the fiber inequalities. O(M^(2h) poly(N)) discovery for fixed h, no claim of polynomial for h growing as log N. This tests all valid constant-dimensional H without a supplied basis, even if full intersection fails. Explicit counterexample to full-intersection completeness: H=span(e1,e2), Q={0,e3,e4,e5}, A=B=Q+{0,e1,e2}. Both spans are rank5; full-intersection inequality 12+12>32 is false, yet each H-fiber has 3 elements so H is valid. Neither factor has a nonzero translation period (both component supports are aperiodic). The pair sumset is larger than BA01 cap 8. This is a restricted discovery failure, not a runtime lower bound.

## 5. Source, algorithm and charged resource ledger
Arbitrary explicit 3-CNF (or signed NAE, E4/B4 via their finite local truth tables) compiles into independent clause rows: assign one equality coordinate to every non-first occurrence of each variable; attach it to that occurrence and to the first occurrence. Each row tag is XOR of coordinates attached to its true bits. Target zero enforces exactly all occurrence equalities, since each coordinate occurs twice. Local allowed tuples are exactly the source clauses; polynomial row construction and tags, projection and reverse occurrence lift. Any source model gives a tuple, any target tuple gives a consistent model; unused variables may be set arbitrarily. Duplicate tags can retain one actual row for decision. This does not prove physical strict four-valent source acquisition beyond the explicit authenticated table model.

After closure and quotient, BA01 exact suffix-affine DP in any fixed order. At cut j, w_j=rank(V_L)+rank(V_R)-rank(V_L+V_R). A partial sum that can extend lies in one affine intersection of size 2^w_j. Retain actual prefixes only, with target-compatible suffix affine filter. Merge identical (stage,tag) keys for decision only, not counting; at final stage target iff SAT. Reverse quotient snapshots in reverse order and verify source. For w=max w_j, attempted edges <=2^w sum_i |R_i| and live keys <=2^w per layer; exact vector keys, polynomial overhead. The code uses JS Map/Set; deterministic sorted maps or scans give worst-case polynomial overhead without a hash assumption. Full prefix copies are charged.

Let N include all explicit rows, tags, source and lift descriptions, and frozen guards. Acquisition outside this model charged separately. Each accepted quotient reduces rank, each strict deletion reduces total row count, so at most D+M normalization updates (M initial distinct rows). Each full scan uses polynomial bit work, including all failed pair tests and Gaussian operations. Snapshot storage O(DN) bits up to representation overhead, plus DP full prefixes O(2^w poly(N)). Total T<=2^w poly(N), S<=2^w poly(N), CM<=T*S on the same execution (no empirical peak-byte or CM measurement). Source lift, all lookup/repair, compilation and verification included. Thus polynomial when final fixed-order width O(log N), even if initial width linear. Fixed residual keys and attempted edges admit DP01-style global credits; sequential quotient potential = 1+rank(V_total) plus row-count credit, not a universal aggregate branching bound. If root width is not small and other channels decline, exponential DP may occur. Universal discovery/coverage remains OPEN.
