## 2. Keywise stabilizer quotient (PROVED)
Let V=GF(2)^D, each independent factor i has a finite nonempty explicit set of rows (key k, tag t, original row id/lift). All global constraints other than XOR tag=t* depend only on the tuple of keys; this can include exact integer owner costs, parity guards, local occupancy or protected observations encoded in keys. Any hidden coupling invalidates the adapter. Define nonempty exact fiber R_i(k)={t: an actual row (k,t) exists}. Let S_i=intersection over present k of Stab(R_i(k)), where Stab(R)={h:R+h=R}. Each is a linear subspace: 0 belongs, sums of periods are periods. Define H=sum_i S_i and pi:V->V/H. Replace every tag by pi(t), preserve key and one actual representative per (key,projected tag); keep archived original tables, lift and basis attribution. Then for EVERY key tuple, not just the globally feasible ones,
  sum_i R_i(k_i) = pi^{-1}(sum_i pi(R_i(k_i))).
The identity is for nonempty fibers; empty key fibers are not introduced. Forward inclusion trivial. For reverse, any projected witness has representative tags r_i. Discrepancy t*+sum r_i lies in H; Gaussian elimination in a basis of H chosen from attributed local period generators yields h_i in S_i with sum h_i equal discrepancy. Each r_i+h_i is an ACTUAL tag in the same fiber; recover via lookup. No assumed affine hull saturation or independent mixing of jointly protected values. This is exact existence and witness semantics, not multiplicity, all-original-row support or arbitrary later probe stability. A later probe that changes keys/row masks must recertify from an appropriate archived source. The result is uniform over every target on the fixed tables before target-specific closure.

Discovery: for a nonempty explicit fiber select anchor a. Every period h must equal a+x for some x in the fiber (since a+h must be in it). For each candidate from the smallest fiber, test translation membership in every fiber by exact lookup. At most total row count squared membership tests per complete scan; no enumeration of the ambient syndrome space. Store deterministic sorted maps or even linear scans. Gaussian elimination produces a basis with source-factor attribution. The quotient preserves nonaffine fibers exactly, rather than replacing their support by its linear span. Periodic subsets and quotienting sumsets are classical additive combinatorics; this is a directly proved key-conditioned adapter, not a claim of novelty for the underlying stabilizer identity.

## 3. Cascading quotient closure and canonicality (PROVED)
After projecting, a previously aperiodic fiber can acquire a nonzero period. Repeat. With FIXED source tables and keys (no target-conditioned deletion), for subspace J define
  Phi(J) = J + sum_i preimage under pi_J of the common stabilizer of all pi_J(R_i(k)).
Each inverse image contains J. If J subset K, any period modulo J remains a period modulo K, because image under the next quotient commutes with translation. Thus Phi is extensive and monotone. Starting at zero, simultaneous saturation reaches the least fixed point above zero in at most D strict rank increases. Every sequence of nonzero single-factor/common-period steps continued to stagnation reaches that same fixed point: induction keeps each attained subspace inside the least fixed point, and the final fixed point contains it. This is the largest quotient REACHABLE by these rules, not the full sumset stabilizer and not the greatest fixed point (the full ambient space is trivially fixed). The proof does not assert confluence after target-specific row pruning, which can change fibers. Implemented solver runs necessary affine-support and affordability closure before every quotient, after each strict deletion (restart), and at stagnation before exact residual DP. The fixed-table confluence theorem is symbolic; finite reversal controls compare decisions and removed rank, not equality of final subspace under arbitrary deletion schedules.

Example of cascade: let base factors P_i be any nonempty exact tag sets, and add independent ring coordinates e_0,...,e_(m-1) (m>=3). Factor zero gets independent auxiliary set {0,e_0,e_(m-1),e_0+e_(m-1)}; factor i>=1 gets {0,e_i,e_(i-1)}. Each padded factor is Cartesian product of base support and auxiliary support, with fixed key unaffected. First quotient removes two seed coordinates, then each adjacent triple becomes a two-point affine support; repeat inward until all m auxiliary directions vanish. Each odd three-point support has no nonzero period before a neighbor is removed. Every synthetic target is repairable, irrespective of base target. Requires only O(m) extra bits and constant-factor explicit rows. This is a controlled representation family, not an assertion that arbitrary physical hubs admit this factorization.

## 4. Separation from full switch saturation and hostile controls (PROVED)
For connected unsigned simple graph G, let C be its binary fundamental-cycle matrix. Assign each edge a nonzero two-bit slack, giving factor P_e={(C_e,0),(0,C_e),(C_e,C_e)}. Integrability is XOR tag=0; signed edge labels change the target to C applied to the labels in each coordinate. A spanning tree reconstructs vertex colors from actual slack choices; cycle equations ensure every non-tree edge agrees. Graph source-to-row compiler polynomial. Every nonzero C_e gives an aperiodic 3-element support (translation by nonzero h is a fixed-point-free involution, hence any periodic support has even cardinality).

For K5 and each K5-e, BA03's strict rank inequality h(J)>|J| for every nonempty edge set J follows from its cut-rank formula h(J)=2(|J|+1-components(G-J)) and the 4-edge-connectivity of K5 (after deletion use |J|+1>=2 components if disconnected). Adding independent auxiliary dimensions cannot decrease h(J). Therefore full BA03 switch absorption is unavailable even though the periodic quotient removes every added ring coordinate; for these graph controls no affine-support rows are eliminated (each coordinate direction is supported by the other factors; edge cycle columns lie in the span of other columns by a vertex cut). After all synthetic bits disappear, the raw nonzero-edge factors remain aperiodic and this rule stagnates. The same raw obstruction holds for bridgeless DO04 graph families. This is a specific restricted normalization boundary, not unrestricted hardness.

For each original variable use equations equating its first occurrence to each other occurrence; 14 independent synchronization rows. Tags are each block's contributions to those equations. Every NAE block is invariant under its own three-bit complementation. At the full Fano root their tag period vectors span six dimensions: their only linear dependency is simultaneous complement of all seven blocks, by connected triple intersection graph; thus exact local complement cancellation is possible even without full affine support.
