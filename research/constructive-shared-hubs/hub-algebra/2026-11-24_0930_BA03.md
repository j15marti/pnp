## 2. Independent binary-switch saturation (PROVED)
Work over GF(2)^D with independent factors R_i, each a nonempty explicitly acquired finite set of actual distinct tags, and target t. All other constraints must be encoded or protected; no independent assumption about correlated copies. For each i choose anchor a_i in R_i and D_i={x+a_i:x in R_i, x!=a_i}; U_i=span D_i. For J subset of factors define H_J=sum_{i in J} U_i and h(J)=dim H_J.
A certificate consists of h(J) independent directions selected from the D_i with at most ONE per factor, all from J. It implies
    XOR-sum_{i in J} R_i = XOR_{i in J} a_i + H_J.
Upper inclusion is immediate. For lower inclusion set all group rows to their anchors and, in each selected distinct factor, optionally flip to the one actual row a_i+d_i. The chosen directions form a basis of H_J, so these independent switches realize every syndrome in the affine coset. No local affine-hull replacement is used without actual pair witnesses.
Thus remove every factor in J, project all remaining factors by pi:E->E/H_J, and adjust the target to pi(t+sum a_i). Forward direction follows from projection. Reverse: choose an actual preimage for each remaining projected row, compute discrepancy between target and outside preimages plus group anchors, solve for its basis coordinates, and switch precisely the required group rows. Check original membership and XOR. Keep original row IDs and certified source lifts. No sumset or 2^h table is constructed. A rank-zero group is a constant offset. This is not a model-count preservation theorem, nor does it preserve arbitrary row pins or all original-row support without recertification.

## 3. Polynomial maximal group discovery (PROVED, executed)
Construct a ground set of labeled directions (i,d), d in D_i. Intersect the partition matroid (one per factor) with the represented binary linear matroid. The maximum cardinality rho(J) of independent representatives from J is computed by Edmonds' matroid intersection algorithm using polynomial independence tests. The rank min-max formula (Rado/Edmonds) is
    rho(J)=min_{X subset J} (|J minus X|+h(X)).
Indeed, in the matroid intersection min-max formula choose the linear rank on a ground subset and partition rank on its complement. Let X contain all groups wholly contained in the subset (including empty groups); its span cannot exceed that linear rank and the complement meets exactly the other groups. Conversely use the union of the labeled groups in X. Empty groups can be included without increasing the objective.
Write f(X)=h(X)-|X|. Since h is submodular, f is submodular. A group J admits the switch certificate iff rho(J)=h(J), equivalently f(J)<=f(Y) for all Y subset J.
Let X* be the union of all minimizers of f on the full ground set. Submodularity implies the union is itself a minimizer. It admits a certificate because it minimizes f even on its own subsets. Every certifiable group J is contained in X*: f(J)<=f(X* intersect J) implies by submodularity f(X* union J)<=f(X*); hence the union is another minimizer and maximality gives containment. This proves X* is the unique inclusion-maximal switch-certifiable group, not just an arbitrary sufficient candidate.
Compute opt=rho(all)-m. For each index i, quotient all other direction sets by U_i and compute rho_i on the m-1 other factors. The minimum f among subsets containing i equals dim U_i-1+rho_i-(m-1): write such subset as {i} union Y and apply the min-max formula in the quotient. Include i iff this value equals opt. This uses at most m+1 intersection calls plus a final call on X*. If full ground is already certifiable, use it directly. No exponential subset search is used for discovery. The implementation uses shortest augmenting paths in the exact exchange graph, recomputing linear independence. Exhaustive subset enumeration is only a small-test reference, not the solver.
Certificate verification requires actual anchor/alternative pairs, unique factor indices, independent direction rank equal to h(X*) and span coverage. No optimality claim is necessary for sound acceptance; maximality proof is for discovery.

## 4. Protected cost/key and selective acquisition extension (PROVED; finite separate controls)
Let every group factor have finite explicit upper keys K_i; each key retains all external observations, occupancy, signed owner-cost coordinates and guards needed by the residual, with exact joint key semantics. For a given candidate H, all potentially feasible tags of a given key must lie in a single known H-coset, with known representative a_i(k) modulo H. Let L_i(k) be witnessed lower tags, a subset of actual feasible tags, themselves within the upper fiber. Define
    D_i^common = intersection_{k in K_i} {x+y : x,y in L_i(k), x!=y}.
A spanning independent transversal from D_i^common contained in H is sufficient for uniform saturation. For each selected direction and EVERY upper key, retain a witnessed pair differing by that direction. For unselected group factors, require at least one witnessed row per key. For any jointly allowed key tuple and outside choices the sum discrepancy within H can be repaired by these selected switches. Hence the entire group can be represented by the retained keys and coset representatives; all integer costs and protected bits remain exactly unchanged. If actual lower keys already cover every upper key, the witness guarantee persists under additional lower acquisition and upper deletions of still-unwitnessed rows. This does not assume uniform key counts or any scalarization of owner budgets.
For supplied H and explicit keys, pair differences, intersections and the matroid test are polynomial; verify pair witnesses rather than count multiplicities. Discovery of arbitrary H in this protected-key model is not covered by the maximal-subset proof: common differences need not span the upper variation spaces. The supplemental code tests fixed H, supplied basis directions and complete explicit small upper fibers, choosing only two witnessed tags per selected key. It uses exhaustive reference DP over original tags and enumerates 64 key tuples in this fixed six-factor test, not a general efficient evaluator for arbitrary key compatibility. The theorem does not make S06 owner aggregation or key discovery automatically tractable.
Counterexample to all-mask reuse: A=B={0,1,2} in GF(2)^2 has full sumset; pin A=0 and target 3 becomes infeasible. Recheck after pins or include the pin in protected keys. This is a decision/witness adapter, not a DS02 all-mask support backend or automatic GD09 parity-probe-stable oracle.

## 5. Tetrahedral nonaffine families and exact boundary (PROVED)
Let c_i be distinct nonzero vectors in GF(2)^b, R_i={(c_i,0),(0,c_i),(c_i,c_i)}. Distinct planes U_i=c_i tensor GF(2)^2 intersect only at zero, so BA02 cannot quotient any pair. If the c_i include two disjoint spanning bases, choose first-coordinate directions from one basis and second-coordinate directions from the other. Each punctured plane has an actual two-row pair in any nonzero direction, and the anchor differences span its plane. More specifically for any fixed anchor one can use matroid intersection on the available anchor differences; two disjoint bases also permit the simple explicit construction using arbitrary pair anchors per factor, since saturation does not depend on which anchors are chosen. The selected directions span 2b dimensions, so the entire sumset is GF(2)^(2b). This works for distinct nonzero columns of arbitrary rank b>=3, e.g. first basis e_i and second basis e_i+e_(i+1) for i<b-1 plus e_0+e_1+e_(b-1). Second basis independent because the first b-1 vectors span the even-parity hyperplane and the last is odd. All 2b columns distinct. Scale b=24 eliminates 48 syndrome dimensions without pair fusion or any DP transition.
IMPORTANT: for a fixed anchor, one chosen direction per factor need not equal the above specific coordinate vector; the full-support proof using arbitrary pair anchors is direct. However rho based on any anchor has the same min-max rank formula since all anchor differences span U_i; therefore a switch basis is found with the canonical anchor as well.
Nonnecessity: two copies of {0,1,2,4,7} in GF(2)^3 have full sumset by 5+5>8 (BA02), but each single factor has rank3 and two factors supply only two directions. X* empty. Thus BA03 and BA02 should coexist.
New DO03 obstruction: for a connected graph G with binary fundamental-cycle columns C, rank(C_J)=|J|+1-k(G-J), where k counts components. This follows because the kernel on J consists of cut vectors supported on J, dimension k-1 (dual rank formula). For the tetrahedral factors h(J)=2rank(C_J).
If G is 4-edge-connected, for any nonempty J with k>=2 each component has original boundary at least 4, so |J|>=2k; thus h(J)-|J|=|J|-2k+2>=2. If k=1 the difference is |J|>0. Therefore the maximal switch-certifiable group is empty. The same holds for G-e when G was 4-edge-connected: deleted edges relative to G are J union {e}, so |J|+1>=2k, giving h(J)-|J|>=1 when k>=2. G-e is connected. In a minimally non-four-colorable graph any edge cut of size <=3 would permit combining four-colorings of the two proper sides by a color permutation: each cross edge forbids 1/4 of permutations, union bound <1. So critical roots and every single-edge SAT neighbor simultaneously evade this new multi-factor certificate on their raw representations. DO03 affine closure also stalls at root for girth>=3. This is an obstruction for the specified certificate family, not for all group saturation, nonlinear regrouping, alternate solvers or P versus NP. For example K5-e is SAT despite no such group, and fixed critical blocks can be easy under other decompositions.
