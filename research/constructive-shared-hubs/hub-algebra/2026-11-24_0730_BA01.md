## 3. Exact stabilizer quotient theorem (PROVED)
For finite nonempty R define P(R)={p : R+p=R}. This is a linear subspace: zero is a period and the sum of two periods is a period. For fixed a in R, all periods lie in {r+a:r in R}. Enumerate these candidates and check every row under translation using deterministic sorted exact vector keys. Gaussian elimination finds a basis. This is polynomial in explicit table length, even if ambient rank is large.

If P=P(R_j), project every R_i and t to E/P, using a canonical linear section for the quotient. Original feasible implies projected feasible. Conversely choose actual old representatives r_i of any projected feasible tuple. The discrepancy d=t+sum_i r_i belongs to P. Replace r_j by r_j+d, which remains in R_j and fixes the exact old target. Thus feasibility is equivalent and a witness is recovered without searching over preimages. Save snapshots or source lift records. Quotienting a sequence of factors by their exact periods is valid by reverse replay; a more general simultaneous quotient by sum of periods also follows by decomposing discrepancy into contributions from each factor. The implementation uses sequential quotients. Nonzero period reduces the current effective ambient dimension and shrinks the source table at least by half. All calculations are exact over GF2.

A guard cannot be dropped merely because its tag is in an eliminated span. For example R_1={0,1}, R_2={0}, target=1 is SAT, but under pin r_1=0 it is UNSAT. Reusing the unpinned quotient would erroneously accept. Include all relevant guards/observations in rows and cache identity; reconstruct actual lifts or decline. This is a decision/support quotient, NOT a counting-preserving quotient or a representation of every original witness. Exact support of an arbitrary new row pin requires a new charged solve and need not preserve the same width.

## 4. Emergent period from two genuinely nonaffine hubs (PROVED)
For independent factors A,B replace them by exact sumset A+B, storing one attaining pair per tag. This preserves both directions and lifts immediately. A+B can have strictly larger stabilizer than either factor. In particular, if A and B lie in affine cosets of the same subspace H and |A|+|B|>|H|, then A+B is the entire sum coset of H: after translating to H, for every h, A and h+B must intersect by the pigeonhole principle. No assumption of affine individual sets.

For a two-bit tetrahedral syndrome plane H={0,u,v,u+v}, each three-state NAE-type relative table omits one color and has zero nontrivial stabilizer (an order-two translation would partition the set into pairs, impossible for odd size). Any two such independent factors on the same syndrome plane sum to H, irrespective of which colors were omitted or which cosets were used. All two syndrome bits can now be absorbed via Theorem 3. This is exact cancellation of nonlinear holes through XOR composition, not equality of physical wheel centers, not permission to merge correlated guards, and not cancellation of counts.

Automatic fixed-cap algorithm: at saturation of affine row closure, find a nonzero individual period and quotient; if none, scan all unordered factor pairs, compute exact sumsets, and accept one only if its output has <=K entries (K=8 in code) and nonzero stabilizer. Restart closure. Each merge reduces factor count, each quotient reduces effective ambient dimension, and all intermediate explicit tables have at most max(input maximum,K) rows. The sum of row counts never exceeds initial rows+K*m, so cumulative strict row deletions are polynomially bounded. Each pair trial uses at most polynomially many exact vector additions/membership checks and discarded work is charged. Hence discovery, verification and all normalization are deterministic poly(N) for fixed K (also for an explicit polynomial cap). Dense-coset lemma proves a useful sufficient merge condition; code directly computes sumsets. No claim that all useful mergers are found.

## 5. Target-conditioned cut rank terminal (PROVED)
After normalization, use a fixed ordered sequence of residual tables. Let U_i=span(R_i+a_i) for any baseline a_i in R_i. For cut after i, define V_L=sum_{j<=i} U_j and V_R=sum_{j>i} U_j, with baseline sums b_L,b_R. Any partial syndrome s that can complete must be in
 (b_L+V_L) intersect (t+b_R+V_R).
If nonempty this affine intersection has size 2^w_i, where w_i=dim(V_L intersect V_R)=rank V_L+rank V_R-rank(V_L+V_R). This is a necessary filter, not a sufficient support test. Maintain exact reachable prefixes, extend every retained state by every row, filter by suffix affine membership, and merge identical syndrome values only within the same stage and fixed guarded source. Keep one predecessor or full actual prefix. Induction gives exact target reachability: no extendible prefix is pruned, every retained prefix is actual. At the final stage suffix is {0}; accept iff target is reachable. Witness reverse replay verifies every source row and target. No enumeration of global guard assignments on this explicit fixed-guard input.

Let w=max_i w_i in the actual order. Number of expanded states <=1+m*2^w, and attempted transitions <=2^w sum_i |R_i|, besides rejected normalization trials. Deterministic ordered maps or sorting ensure polynomial key overhead; executed reference uses JS Map and does not establish a worst-case hash bound. Hence T<=2^w poly(N), S<=2^w poly(N) on a single implementation with all saved lift records; CM<=T*S<=4^w poly(N). Fixed w<=C log N is sufficient for polynomial total costs. A tree of supplied factor cuts of width w similarly permits exact compatible pair joins of two child reachable syndrome sets at <=4^w poly(N), retaining actual lifts; proof is same intersection bound at every node. This tree extension not executed. No free optimal order/tree discovery. Verify supplied tree or fixed order by rank scans. Known FPT branch-decomposition discovery for subspaces can be used for fixed w, not automatically polynomial for w=O(log N) without checking dependence.

Aggregate credit: for a fixed normalized input/order, at most (m+1)2^w distinct (stage,syndrome) keys; decrement one global credit for each first expansion and separately charge all attempted edges. This is a DP01-style fixed universe, not a universal child-potential inequality for adaptive rewriting. No new residual or guard may evade accounting.

## 6. Direct formula compilation and NAE gauge interpretation (PROVED)
For arbitrary explicit ternary Boolean relations (including 3CNF and signed NAE), create one independent table of allowed port assignments per factor. For each original variable choose an anchor occurrence and one XOR equality equation with each other occurrence. A local row contributes its port bits to those exact equation coordinates. Require total syndrome zero. Exact because occurrence consistency yields a global assignment, and every original assignment gives consistent local rows. For duplicate tags retain one actual port assignment. Isolated variables arbitrary unless separately pinned. Size polynomial for bounded-arity scopes. Signed clauses enter as allowed rows, not as dropped signs.

For unpinned complement-invariant NAE with n nonisolated variables, m triples and c connected incidence components, the raw equality-coordinate dimension is 3m-n. Each local full complement acts by a translation on its tag set. The span of these m complement translations has rank m-c: a linear combination vanishes iff flip bits assigned to clauses are equal on every pair of clauses sharing a variable, i.e. constant per incidence component. Hence quotient by this full span has dimension 2m-n+c, precisely the incidence cycle rank. This explains the earlier relative minority-state construction as exact quotient of the absolute carrier equations. Additional emergent periods and target affine closure may compress further. For asymmetric single-owner relaxations no complement period is assumed; inspect actual tables.
