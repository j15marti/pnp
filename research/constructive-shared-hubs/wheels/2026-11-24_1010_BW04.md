## A. Exact spare-port obstruction (PROVED)
Let Q=GF(2)^2. A finite loopless undirected signed multigraph has each edge uv forbidding exactly x_u+x_v=s_e, degree counted with multiplicity. All vertices start with the full Q domain. No hidden guards, lists, protected observations or budget couplings. Let P be p distinct ports of degree <=3, so each has at least one available external incidence under a degree-four target. Suppose the gadget is satisfiable and every model satisfies x_i+x_j=a_i+a_j for fixed offsets a_i (i,j in P). Translation invariance ensures that its exact port projection consists of the four synchronized words. We may discard components not touching P; all ports lie in one connected component because independent component translations would otherwise break synchronization.

Every port has degree exactly three: in any model, fixing the rest, each incident edge forbids at most one color. At degree <=2 the port has another choice, contradicting synchronization for p>=2.

Define H={v:deg(v)>4} and Eplus=sum_v max(0,deg(v)-4). For p>=3, every component of G-H contains at most one port. Proof: fix H to its values in ANY actual model x. The remaining lists lose at most one color per crossing edge, so |L(v)|>=deg_{G-H}(v), and at ports |L(v)|>=deg_{G-H}(v)+1. Suppose a component C contains two ports u,w. Pick a third distinct port v anywhere. Add one signed exclusion edge uv forbidding the required synchronized difference a_u+a_v. The degree-list property remains true after consuming the one slack at u and v. The joined component contains w, with strict slack. A reverse spanning-tree greedy order rooted at w colors the entire joined component, since each nonroot has at least one uncolored neighbor, each incident edge forbids at most one color, and the root has slack. Parallel edges are allowed and counted; the order works unchanged. All other components retain x, as does H. This is an original model violating the required synchronization, contradiction. In particular, H cannot be empty when p>=3.

Each of the p distinct port-containing components C must have >=3 crossing edges to H. Otherwise translate all colors in C simultaneously by t in Q. Each crossing edge forbids only one translation; at most two edges leave at least two possible translations, including zero (the given model). A nonzero translation changes the port relative to all other ports outside C, contradiction. Thus
  3p <= |delta(H)| <= sum_{v in H} deg(v) <= 5 Eplus.
The last inequality holds termwise because d<=5(d-4) for integer d>=5. In particular Eplus>=ceil(3p/5). This is a structural necessary cost, NOT a time lower bound. With H empty the sharp two-port example is the ordinary K5-e equality triangle, whose tips have degree three and private rim vertices degree four. With p>=3, a private all-degree-four fanout cannot exist regardless of gadget size or discovery method. This proof uses elementary greedy coloring and translations, not a complexity assumption or a DP-degree oracle.

## B. Constructive model-dependent three-channel certificate (PROVED)
For any authenticated satisfying assignment x, give each edge its nonzero slack label d_e=x_u+x_v+s_e. For d in Q minus {0}, consider G_d with exactly the edges of label d. Translating any one connected component of G_d by d preserves all constraints: only crossing edges with label d could become forbidden, and none crosses a G_d component. Therefore every G_d must have one component containing all ports, or the component translation breaks synchronization. BFS extracts a Steiner tree for each d; the three trees are edge-disjoint, and degree-three ports use one edge of each. With actual witness x, extraction or a countermodel is polynomial and does not require testing arbitrary assignments. This is necessary for every model of a synchronized gadget, not sufficient to certify that ALL models synchronize. It exposes an exact multisign synchronization channel rather than silently identifying copies. No algorithm for acquiring x on arbitrary inputs is presumed.

## C. Exact construction and local-to-global limit (PROVED)

If b_i=h+a_i, the triangle can use the other three colors. Otherwise each rim list has only the same two colors, impossible on a triangle. Thus projection is precisely b_i=h+a_i, both directions, with six independent rim extensions per port. Every port has degree three, every rim vertex degree four, h degree 3p.
