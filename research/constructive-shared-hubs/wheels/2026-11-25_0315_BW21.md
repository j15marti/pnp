\begin{lemma}[Pair-switch generation of affine hull]\label{lem:bw21-hull}
Consider a finite signed B4 gadget with exactly two active ports per vertex, signed internal wires, optional fixed boundary ports, and $d$ remaining free boundary ports, each appearing once. Let $R$ be its exact nonempty boundary relation and $a\in R$. Then
\[
\operatorname{aff}(R)=a+\operatorname{span}\{e_i+e_j:a+e_i+e_j\in R,\ i<j\}.
\]
In particular the affine hull is specified by one parity equation per component of the graph on free ports whose edges are the displayed feasible pair switches (isolated vertices give fixed bits). The hull and witness lifts for its generators are deterministically obtainable using at most $1+\binom d2$ polynomial matching feasibility calls (up to a constant factor for the initial witness).
\end{lemma}
\begin{proof}
Compare lifts of $a,b\in R$. At each B4 vertex the changed ports split equally into increases and decreases, so pair increases with decreases locally. Along each signed wire either both ends change or neither changes. The changed ports, local pairings and changed wires therefore decompose into paths between distinct free boundary ports and cycles. Fixed ports never change. Flipping exactly one path preserves all signed wires and integer balances even if the path visits one vertex twice: it flips one increase and one decrease for each local pairing traversed. Hence each path yields a feasible pair switch from $a$. The sum of their boundary differences is $a+b$. This proves both inclusions; weight-two generators along graph edges span exactly the even subspace in each connected component. For the algorithm, encode a B4 by four port nodes and two private nodes each adjacent to all four port nodes; a perfect matching leaves exactly two ports to be matched outside the gadget. An equal wire is an edge between its port nodes; an unequal wire is subdivided by one node, forcing exactly one end matched to the wire. A fixed active port is removed, and a fixed inactive port has no exterior edge. To allow unpinned boundary values, connect each free port to its own dummy and make the dummies a clique; optionally add one extra dummy. Try both choices, permitting either parity of the number of used exterior edges. Conversely any feasible lift extends in one of these two matching graphs. With all free boundary bits pinned, the same construction without dummies tests a word. Thus one can find a base and test all pair flips by ordinary deterministic perfect matching, retaining actual witnesses; size $O(d^2+|G|)$ in vertices/edges up to encoding overhead, all failed queries paid. Empty support is detected by the initial calls. The hull is not in general equal to nonlinear support.
\end{proof}
\begin{lemma}[Exact affine guard realizability on actual single ports]\label{lem:bw21-affine}
A nonempty affine relation $C=\{x:Ax=b\}$ on actual free ports has an exact pure signed B4 realization with optional fixed ports iff its direction space is the direct sum of even subspaces on disjoint coordinate blocks. Equivalently $C$ is a conjunction of one parity equation on each block of a partition (singletons allowed). This criterion is polynomially decidable from $A,b$. For a consistent system, partition columns of $A$ by equality; the space generated by weight-two kernel vectors has dimension $d-t$, where $t$ is the number of column classes. Acceptance is exactly $\dim\ker A=d-t$. A zero column implies rejection for nonempty coordinate scope. Realization and witness reconstruction use $O(d)$ B4 vertices and fixed ports.
\end{lemma}
\begin{proof}
Necessity follows from Lemma~\ref{lem:bw21-hull}. Since $A(e_i+e_j)=0$ iff columns coincide, the pair span is contained in the kernel and has dimension $d-t$; equality characterizes the requisite direction space. A zero column gives a weight-one kernel vector, which no such pair span contains. Conversely $K_4$ with one free port per vertex realizes the entire even four-bit parity relation: for zero exterior ones choose a four-cycle internally, for four choose a perfect matching, for two choose a spanning path with endpoints at the two active exterior ports; odd totals violate integer degree summation. Sign a boundary wire for odd parity. Use pins on spare ports for ternary and unary parity; concatenate ternary parity gates along a private accumulator for an arbitrary block, computing intermediate bits by prefix parity and lifting each gate by the explicit construction. Use disjoint blocks. No boundary bit needs duplication. This proves exactness in both directions, including lift cost. If the model forbids fixed ports entirely, complement invariance further requires even block sizes; even-size blocks can use four-port parity gates chained on private wires, with a two-port equality wire as the base. The pinned result must not be applied to a pin-free chart without a separately certified pin adapter. A parity checksum output can embed a general affine code in an even code, but does not force it into this class.
\end{proof}
