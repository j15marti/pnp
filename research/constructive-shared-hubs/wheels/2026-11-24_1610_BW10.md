## Theorem BW10-A (exact, symbolic)
K=GF(2)^2. The private graph consists of vertex-disjoint blocks, each a singleton, a simple cycle of length >=3 (odd or even), or K4, connected by single bridges forming a tree. Every private vertex has total degree exactly four, unused ports having one signed exclusion to a protected affine color word. Each edge forbids x_u+x_v=s_uv; signs may themselves be supplied affine words on a common chart G. No other private observations, tags, quotas, or side constraints. Repeated protected IDs are allowed, never independently chosen. Root the block tree. Each nonroot block exposes its actual parent endpoint p. Each child supplies its exact feasible-color set S; if |S|>=2 it imposes no restriction on the parent, since a bridge forbids only one child color. If singleton it supplies one translated forbidden color.

For each block compute a hypothetical affine outgoing singleton color c and a list of local affine ESCAPE events. A subtree emits a singleton exactly when no escape event anywhere in that subtree holds; its singleton is then c. Otherwise it emits at least two colors. Root is uncolorable exactly when no escape event anywhere holds. A nonroot block is always feasible because its missing parent port creates one surplus list. More generally, if any child supplies >=2 colors, the block has a surplus list even after adding an artificial parent port. A connected signed graph with lists at least its internal degree and one surplus list is greedily colorable: choose a spanning tree rooted at surplus vertex, color in reverse tree order, each nonroot has an uncolored parent, root has an extra color. Thus no singleton can propagate through a child escape. All computations below are hypothetical affine expressions even on already escaped inputs.

Singleton block: the three incoming forbidden colors must be pairwise distinct; the missing fourth color is their XOR (XOR of all four colors is zero). Candidate c is that XOR. Equalities between any incoming pair are escape events. At root use all four forbiddances and all six pair equalities.

K4: take an affine gauge q_v from a spanning star, add each failure of s_uv=q_u+q_v as up to two one-bit affine escape events. By DA10, degree-feasible K4 is uncolorable iff signs balance and all normalized missing colors agree. Pick an incoming port away from p as reference t in gauge; candidate c=t+q_p. Add failure of equality of every other actual normalized incoming color to t. Root uses all four ports. For completeness of DA10 local lemma, if no coloring, pin any root color r in its 3-list; each other vertex must lose a color (otherwise surplus triangle greedy). Gauge root edges to zero; all lists coincide. For every r the residual two-color lists must be preserved by each internal translation (otherwise color a mismatched edge endpoint first, then third, then opposite endpoint last). Preserving all three distinct pairs of the common triple forces translation zero. A full 4-list is surplus. This proves both directions.

Cycle: write the two forbidden colors at site i as a_i,b_i. Pick a reference site away from p (root: arbitrary) and d=a_ref+b_ref. At nonroot p the other port is a; candidate c=a+d. Fill the missing port hypothetically with c. Full degree-feasible cycle rejects iff (i) d!=0 and a_i+b_i=d for every site, (ii) k_i=a_i+a_next+s_i belongs to {0,d} on every edge, and (iii) XOR_i s_i=(1+(L mod 2))d. To prove, surplus list or an edge whose translated lists differ allows greedy coloring by starting with a color that does not exclude a color at the last endpoint; otherwise each two-list is a coset of common direction d and the forced legal transition is x_next=x_i+s_i+d. Closure is possible exactly when XOR_i s_i+(L mod 2)d=0; under list alignment XOR signs is in {0,d}. Rejection is its nonzero complement. This is BW07, also covers even cycles. A missing parent port permits a nonempty set; singleton iff adding a forbidden color makes the full block reject. That forbidden color is necessarily c by (i), so the candidate rule is exact. Each failure of (i)/(iii) is an affine event or at most two one-bit affine events; failure of (ii), on d!=0, is the union of the six events d=e, k_i=f, e,f distinct nonzero colors. ## Theorem BW10-C (exponential rejection-cover firewall)
Take k triangle blocks in a bridge chain, zero signs, independent two-bit directions d_i. At every vertex supply pair (0,d_i) except missing parent port and child bridge replace the zero port at distinct sites. Leaf candidate singleton 0 iff d_i!=0. Induction gives root rejection iff every d_i!=0. Thus rejection contains 3^k words; support is simply OR_i[d_i=0], k affine events. Any affine subspace wholly contained in rejection projects into the three nonzero words in each coordinate pair, hence each projection dimension <=1, total dimension <=k, and covers <=2^k words. Explicit positive affine rejection cover therefore needs >=ceil((3/2)^k) terms, even though support cover is linear and local fiber decisions polynomial. This is the dual polarity of DS09-C. Not a lower bound on signed/factored representations or SAT decision. Keeping the polarity of the support adapter is essential.
