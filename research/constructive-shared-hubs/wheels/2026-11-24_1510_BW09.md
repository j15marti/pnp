## A. Exact partial-translation semigroup (PROVED)
For a path with m>=1 private sites, start color p and finish q, let L_i=K minus {a_i,b_i}. Incoming edge at i excludes difference s_(i-1); final edge excludes s_m. With a fixed selector word, if at least two colors are reachable at any site, every allowed color at the next site is reachable: each next color forbids precisely one predecessor. Since all private lists have size >=2, that freedom persists and the final fixed endpoint can always be reached. For a singleton incoming reachable color x, the outgoing set is L_i minus {x+s_(i-1)}. It is nonempty and singleton precisely when d_i=a_i+b_i is nonzero and x+s_(i-1) belongs to L_i. In this case its unique element is x+s_(i-1)+d_i (the two allowed colors have difference d_i).

Thus each site is summarized by a partial translation (D,t), D={x:x+s_(i-1) in L_i} if d_i!=0, else empty; t=s_(i-1)+d_i. Empty states canonicalize t=0. A missing domain means freedom, not an impossible path. Sequential composition is
  (D,t) then (E,u) = (D intersect (E+t), t+u),
with empty canonicalized. Associative by function composition. Every nonempty segment has |D|<=2. The exact endpoint rejection predicate is p in D and p+t+q=s_m. A zero-interior path uses direct endpoint exclusion. Both directions follow from reachable-set propagation, with actual lift by 4-color path DP/backtrace. All pinned-color paths have disjoint private interiors; compose on the SAME chart and glue actual lifts at the protected vertices.

Exactly 41 distinct partial maps arise: 1 empty + 4*4 singleton domain/shift + 6*4 doubleton domain/shift. Every pair-domain D and shift t is realized by choosing the incoming sign s=t+d with d the nonzero difference of D, then list L=D+s. For a singleton choose two distinct doubleton domains meeting in that singleton, first shift zero, second arbitrary; disjoint domains give empty. Any doubleton map can also be represented by two sites (first identity on D), so all 41 occur at a common length two. Distinct partial maps have distinct endpoint rejection tables: choose p where undefinedness or value differs, then choose q equal to a defined image, taking final sign 0. Hence every deterministic segment summary required to work for every independently supplied endpoint pair (and no other segment information) needs >=41 values, i.e. >=6 bits. Three synchronized two-bit hubs suffice; a single BW08 two-bit holonomy hub does NOT suffice for this different protected-endpoint contract. If the shift is supplied separately, this lower bound does not apply to the remaining mask alone. Not a nondeterministic or unrestricted runtime lower bound.

## C. Stronger direct projection: affine escape union and fiber oracle (PROVED; implemented)

  c_0=p; f_i=c_(i-1)+s_(i-1); d_i=a_i+b_i; c_i=f_i+d_i.
All c_i,f_i,d_i are affine, even on assignments on which the trajectory is not actually forced. Safe iff at least one of the following affine events holds:
  d_i=0 OR f_i=a_i OR f_i=b_i (for some i),
  OR either scalar bit of c_m+q+s_m is 1.
Proof: if any of the first three events occurs, choose its earliest index; preceding sites were forced, this site admits >=2 reachable colors, freedom persists. ## D. Hardness firewall for universal deletion of ONE pinned odd rim (PROVED)
Universal extendibility of a single path/one-pinned odd rim for every exterior selector is coNP-complete in this affine-spoke model, although existential fiber support in C is polynomial. Membership: a bad selector can be verified with path DP. For hardness reduce graph 4-colorability (NP-complete by adding a universal vertex to 3-colorability). For each original graph vertex assign independent two-bit color x_v. For each edge uv let d=x_u+x_v, and T(d0,d1)=(d1,d0+d1), an invertible order-three GF2-linear map with no nonzero fixed point. For d!=0, Td and d are independent, so Td notin {0,d}; for d=0 both vanish.

Use one protected rim vertex pinned to 0 and two consecutive private sites per graph edge, all rim signs zero. At first site use a=Td,b=Td+d; at second a=d+Td,b=Td. When d!=0 and incoming predicted color is 0 at first site, each step is forced, with predicted colors d then 0. When d=0 at either site, list size three gives an escape. Thus all sites remain forced iff every original edge has distinct endpoint colors. In that case the last private color is 0 and violates the closing edge to protected 0. Otherwise the earlier escape makes the entire rim feasible. The rim length 2|E|+1 is odd for |E|>=1, and all spokes are explicit affine words. It has a bad selector iff the graph is 4-colorable. Therefore universal safety iff graph NOT 4-colorable. This proof uses actual protected rim color (not a new summary pin). The existential path test remains easy: all-zero graph colors yield an escape. This is not a P!=NP proof; it rejects treating universal exact deletion/identity as a free local primitive. A separate simple clause compiler uses two sites per literal, d=1 and Td=2 scaled by the literal-false bit, with predicted 0 then 1. Each pair escapes iff literal true; a 3-literal clause is exactly a seven-site odd rim with one pinned vertex. Shared selector bits across clauses encode arbitrary 3SAT. Small local arity and exact local support thus do not resolve global composition. DO01/DO09 critical paired NAE and single-owner neighbors transfer through two clause rims per full NAE constraint, preserving every owner; no claim of low joint width.
