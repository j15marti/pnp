## B. Cycle-to-owner projection and port accounting (PROVED)
Suppose G is a cactus multigraph: distinct simple cycles have disjoint edge sets, including length-two parallel cycles. More generally permit arbitrary balanced biconnected blocks (all cycle tag XORs zero); every unbalanced block must be one simple cycle. Balanced blocks impose no restriction on lows because all their subgraphs are balanced. Every simple cycle lies within one block. Thus only the edge-disjoint unbalanced cycles C need attention. Recognition uses multigraph block decomposition and signed forest propagation; the executed checker recognizes the narrower cactus case using a spanning forest, checking edge-disjointness of fundamental cycles. If fundamental cycles are edge-disjoint, every simple cycle is one of them: any binary sum of two or more of these edge-disjoint circuits has either disconnected support or a vertex of degree >=4, and hence cannot be a simple cycle.
For an unbalanced cycle C, rejection occurs iff every constituent star activates. Each activation is two affine equalities l_a XOR l_b=s_a XOR s_b, l_a XOR l_c=s_a XOR s_c. Their equality graph on actual terminal IDs is connected because the endpoint cycle is connected and every pivot attaches to it. If inconsistent, C is never fully active, so discard it. Otherwise compute offsets alpha_v by graph propagation; all active iff l_v XOR alpha_v is one common bit for every v in its scope. Its exact acceptance is signed NAE on all DISTINCT scope variables, with at least three (each star has three distinct terminals). Every original proper coloring satisfies the owner; conversely a low word satisfying all owners leaves no unbalanced active cycle and has a simultaneous high/center lift. This is not independent gluing of high bits across owners.
Port conservation: for each terminal v and each cycle owner containing it, either v is an endpoint of that cycle (two distinct star-edge incidences), or v is a pivot of at least one star in that cycle (two physical incidences). Different cycles have disjoint star IDs, so these charged physical incidences never overlap. Therefore
   2 * occ_owner(v) <= deg_physical(v) <= 4.
Hence the compiled signed NAE owner registry has variable occurrence at most two, even when a terminal is a pivot in one wheel and endpoint of another. Total owner incidence length O(m), where m is star count. Shared hub variables remain one ID. This is a direct application/extension of BH13-C's matched-pivot mechanism, and a new exact adapter into BH13-A interval factors. The mixed owner argument below avoids general blossom entirely in this domain.

## C. Complete low-unit closure plus bipartite matching (PROVED)
At each actual low pin chart, simplify a signed NAE owner: if pinned literals include both bits, delete the owner; if none pinned, keep NAE (arity >=3); if all pinned literals agree on k, require at least one remaining signed literal opposite k, an ordinary signed OR; if none remain, reject. OR unit forces its last literal; restart all closure after each pin. Recheck activated high equations for fully pinned star lows before recognition, after every pin, and at stagnation. The unconditional center-low equality from each original star is absorbed into its exact analytic projection; fixed-active high equations are necessary within their actual chart, not exported to other charts. No assumed complete semantic affine closure. The executed solver uses this specific certified low-unit and fixed-activation parity closure, not arbitrary all-channel closure.
At stagnation without contradiction, every remaining OR has >=2 distinct variables and every remaining NAE >=3; every variable occurs in <=2 owners. For any owner subset J, count incidences: 2|J| <= number of incidences <= 2|V(J)|. Hall gives a matching saturating all owners. Acquire one by deterministic augmenting paths. Distinct matched pivot per owner.
For OR pivots set their signed literal true. Unmatched variables arbitrary (preserve pins). For NAE owner pivot p draw directed arcs p->q for every other variable q in its scope. If a pivot cannot reach an OR pivot or unmatched variable, let R be its reachable set of NAE pivots. All >=3|R| occurrences of those owners lie in R, contradicting occurrence cap 2|R|. Thus each NAE pivot reaches a sink. Reverse BFS assigns shortest distances; choose one outgoing arc decreasing distance. Set NAE pivot so its signed literal disagrees with that chosen variable's signed literal, processing by increasing distance. This guarantees the NAE owner and cannot undo earlier sinks or pivots. All OR owners hold from their assigned pivot. Lift common highs via actual active graph, reconstruct centers and verify all physical edges/pins.
