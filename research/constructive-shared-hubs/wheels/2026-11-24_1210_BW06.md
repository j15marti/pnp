## A. Unique self-dual NAE4 splitting (PROVED)
For all Boolean P,Q,R,S, use the four signed NAE3 clauses
 NAE(P,Q,z), NAE(not z,R,S), NAE(not P,R,not z), NAE(not P,S,not z).
The last three say exactly z=maj(not P,R,S): any equal pair among the three inputs forces its common value, and all other pairs are mixed. This has exactly one solution z. If P!=Q the first clause holds. If P=Q, the first clause requires z=not P, and the majority disagrees exactly when R=S=P. Hence there is exactly one extension for every nonmonochromatic boundary and zero otherwise. No reference bit, global anchor or hidden preference in this local gate. The former two-clause split had two extensions when both input pairs differ. This is a strict functional refinement, not a change in boundary feasibility.

For a signed edge uv forbidding x_u XOR x_v=s in GF(2)^2, let A=x_u0,C=x_v0 XOR s0,B=x_u1,D=x_v1 XOR s1. Use BW05's NAE4(A,C,B,D) and NAE4(A,C,not B,not D), now with the unique split above. ## C. Orbit-balanced odd wheels of arbitrary odd length (PROVED)

For nonzero twist t in GF(2)^2 make a private ordinary cycle of length L; at rim site 0 forbid colors a XOR t and b XOR s (two signed spokes); at every other site forbid a and b XOR s XOR t. Each rim adjacency forbids equality. Gauge translate all colors by a. If d=0 every rim list is the same two colors, so no lift on odd L. If d!=0,t, exceptional list and ordinary list are disjoint two-color sets; the L-1 normal sites form a path with exactly two alternating colorings, and either exceptional color closes the rim, giving four lifts. If d=t, the normal list is the three colors other than 0 and exceptional list is three other than t. Let n=L-1, even. If exceptional color is 0, normal path has 3*2^(n-1) assignments. Each of the two other permitted exceptional colors belongs to normal list, so both path ends must avoid it.
