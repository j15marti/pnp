## 1. Exact local two-bit exclusion without shared reference (PROVED)
For every explicitly indexed loopless signed graph G, color x_v in Q=GF(2)^2. An edge uv forbids x_u XOR x_v=s. Write A=x_u[0], C=x_v[0] XOR s[0], B=x_u[1], D=x_v[1] XOR s[1]. The edge is equivalent pointwise to
    NAE4(A,C,B,D) AND NAE4(A,C,1+B,1+D).
The first fails precisely when A=C=B=D; the second when A=C and B=D=1+A. Their union is exactly A=C and B=D. Thus no external reference is needed, and both endpoint bits remain actual shared observations.

For each NAE4(P,Q,R,S), use independent z and NAE3(P,Q,z) AND NAE3(1+z,R,S). If P=Q, z is forced to 1+P; if R=S, z is forced to R. These requirements conflict exactly when all four inputs agree. If neither pair agrees, either z works. For each NAE3, add a private slack r=2-(sum of the three ordinary Boolean values) and B4 of those three values and r; r is a bit iff NAE3 holds. It is unique. Duplicate each B4 sharing exactly the same four carriers, including r. Both copies are identical constraints, not independent selections.

The four endpoint carrier bits appear four times each per source edge, two private z carriers appear four times each, and four slack carriers twice each. This makes all occurrence counts even. E4 paths and signed transports below give physical identities for every repeated occurrence. All existential choices are local to the edge once source colors are fixed.

## 2. Strict simple four-regular graph (PROVED)
RT01 model: every vertex four distinct edge incidences, E4 means four equal Boolean bits, B4 means exactly two ones; an edge enforces XOR of its two local port bits equal to a specified sign. No constants, dangling ports or degree-two nodes. For a carrier with d=2 occurrences, directly join the two ports with sign equal to XOR of their occurrence signs. For even d>=4, use (d-2)/2 E4 vertices on a path, internal transports sign zero; there are d unoccupied ports. Join each occurrence to a distinct free port with its specified sign. All E4 bits equal, and no extra choices. At a nonisolated source vertex of degree d, there are two independent paths each with 2d-1 E4 vertices, one per source bit. Each private z uses one E4; slacks use direct wires. Every raw vertex is four-valent.

Replace EACH raw wire by five private E4 vertices inducing K5 minus one edge; its two degree-three vertices connect to the original endpoints. Internal signs zero, one attachment original sign and the other zero. Connected equality makes this a unique signed wire lift, and the resulting graph is simple and strictly four-regular. Even a raw self-wire or parallel wire is replaced by distinct private endpoints. Source loopless is needed for the affine-stagnation theorem below; graph compilation itself can handle repeated endpoint occurrences if implemented separately. Isolated source vertices omitted and explicitly restored as free colors.

Let m be number of source edges and n+ the number of nonisolated source vertices. Raw V0=8m B4 +2m private z E4 + (8m-2n+) source E4 =18m-2n+. Raw wires=2V0. Final V=11V0=198m-22n+, E=2V. Indexed size O((n+m)log(n+m)) for explicit source including isolated vertex declarations. Both decision directions hold for EVERY fixed source color word (with omitted isolates kept as external free observations). Reverse decode each E4 path representative; forward choose z satisfying local tests, compute slack, fill all E4/wires. Full verification scans signatures and every wire. This is an exact adapter into RT01's named signature model, NOT a degree-four singleton-exclusion graph or a claim about a more restrictive geometric or planar physical model. ## 3. Pointwise multiplicity and exact count correction (PROVED)
Let d=x_u XOR x_v XOR s, represented by two bits. If d=0, no lift. If d=1 or 2, exactly one of the input pairs agrees in each NAE4 split, forcing each z: exactly one lift. If d=3, both pairs differ, both z free: exactly four lifts. All slack, duplicates and E4 transports uniquely determined. Hence a source coloring x has physical fiber size 4^k(x), k the number of edges with d=3. Not parsimonious.

## 4. Wheel composition and boundary parity obstruction (PROVED)
For every source edge forbidding a+b=d, choose nonzero t and build BW03's private triangle with two spokes per rim: exceptional vertex forbids a+t and b+d; the other two forbid a and b+d+t. Exactly when a+b=d all lists equal the same two colors, hence triangle impossible. When a+b differs: if a+b=d+t then the lists have three colors; otherwise the two list pairs differ between exceptional and other rim sites, permitting coloring (BW03 cycle theorem). Thus exact edge projection. Duplicate wheel any explicit number of times with same source hubs and possibly different nonzero t, using disjoint rim interiors. Each permitted source word lifts all wheels independently, then apply sections 1-2 to EVERY signed rim and spoke edge. This realizes shared-hub duplicate wheels as strict E4/B4 networks with no global high-degree physical vertices. Reconstruct via rim DP or constant 4^3 triangle checks, then physical adapter. For D explicit copies per edge signed size n+3Dm and 9Dm, physical size linear in Dm. Count correction above counts colorings of expanded wheels, not original pre-wheel source colorings unless rim multiplicity also corrected or source projection used.

A necessary interface constraint explains the even duplication: in any open E4/B4 signed port gadget, XOR of ALL external port bits equals XOR of all internal wire signs, because each vertex has even parity and internal ports cancel in pairs up to sign. Consequently no such open gadget with just one unencoded port per each of the four endpoint bits can represent the signed exclusion relation of size 12 (it contains both even and odd parity words). Nor can a single free bit be capped by an unconstrained one-port gadget. Replicating the carrier bits removes this parity mismatch. This is a restricted interface obstruction, not a barrier to alternative encoded interfaces.

## 5. Stagnation and structural width (PROVED)
Initialize all wire/E4 affine equations and replace B4 by its affine hull, even parity. For loopless source with no source pins, independent source bits and two independent z per edge determine the four slack bits by parity; duplicate equations redundant. Affine relaxation on occurring carriers has dimension 2n+ +2m. Every B4 projects to entire even-parity hyperplane: two distinct source bit carriers and z are independent for first factor, and z plus two other distinct source bit carriers independent for second. Its actual support of six weight-two words spans this hyperplane. Therefore repeated exact local B4 affine hull propagation adds no further equation. Every source color word survives this restricted affine closure, including forbidden ones. This does not cover nonlinear region projection, full certified semantic closure or arbitrary protected pins. Both-label critical examples transfer into this specified strict graph representation; raw matching/owner/width parameters of another representation do not automatically transfer.

For bounded source maximum degree Delta, graph-treewidth is preserved up to a constant factor depending on Delta. Given a source tree decomposition, replace each bag vertex with its two complete carrier paths and their private internal-wire subdivisions (O(Delta+1) size). For every edge, attach a bag containing both complete endpoint clusters and its O(1) local B4/z/slack and connecting-wire vertices. Running intersection and edge coverage follow directly. Hence tw(physical)+1 <= O((Delta+1)(tw(source)+1)). Conversely, the nonisolated source graph is a minor: retain each bit-0 carrier path and one private first B4 per edge joining both bit-0 paths, with corresponding subdivided wires, then contract paths and edge connectors. Thus tw(source) <= tw(physical) for nonempty source. This is ordinary graph treewidth, not necessarily BD04 algebraic rank; proof symbolic, not executed. It supplies a controlled strict adapter, not universal width compression.
