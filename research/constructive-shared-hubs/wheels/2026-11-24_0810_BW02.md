## 1. Paid local region discovery and exact replacement (PROVED)
Input is an explicit conjunction of Boolean relations of bounded arity (<=4 suffices), with sorted source port IDs and at most 16 rows per factor. In particular E4 equality and B4 exact-two constraints on four ports, signed wires, CNF clauses of width <=3, signed NAE triples and one-owner relaxations of a NAE triple all have constant local tables computable by evaluating their definitions. A repeated source port is identified before truth table generation, not treated as independent. Fixed guard literals are additional actual factors or substitutions. Any extra crossing owner budget, tag or observation needed downstream must be included in the interface/factor graph or the module must decline. No automatic drop of S06/DP01 cost/tag correlations.

Construct the primal graph by making every active factor scope a clique. For B a set of at most two live variables, take a nonempty connected component C of the graph minus B, and shrink B to the actual neighbors of C. Let H_C be exactly the factors touching C. Then every such factor has all its variables in C union B, and no other factor contains a C variable. Define R_C(b)=1 iff there exists an assignment c to C satisfying H_C(b,c). Enumerate all boundary rows and at most 2^|C| internal assignments per row, retaining one actual witness c for each supported row. Replace H_C by R_C and remove C. For every assignment to the remaining variables, extension to the pre-replacement conjunction exists iff it satisfies the new conjunction: restriction proves forward direction; a recorded witness for its exact boundary row proves reverse direction, with no other factor affected. This is existential elimination, not an approximation or a counting-preserving operation. Empty support is a certified contradiction. Multiple replacements compose by induction, with reverse chronological source reconstruction. Source factor ownership is disjoint at each replacement; duplicate constraints may be intersected, not treated as independent choices with extra multiplicity.

For fixed K, enumerate every B of size 0,1,2 and connected components of G-B, rejecting candidates with |C|>K. This discovers every qualifying private connected region, including ones with no syntactically recognizable Fano pattern. Implementation first tries the cheaper seed-neighbor cuts, then a complete pair/seed search with early size cutoff. Every failed trial is charged; the code uses no supplied region identities. If all factors are explicit and K=O(log N), this is polynomial in total encoded input length N. The theorem also works for b<=3 by enumeration of triples (symbolic, not implemented). For this extension use a table of at most 8 rows.

### Manifest-free wire recovery (PROVED separate batch lemma)
Suppose any source is stretched by an arbitrary fixed collection of two-port equality gadgets with private interiors, each of size <=K (or O(log N)). For the actual terminal pair u,v, each interior component after deleting {u,v} is confined to that gadget. Compute the boundary support of EVERY component of G-{u,v} with size <=K, and intersect their supports on the full ordered pair, extending a unary/empty boundary relation to that pair. Include factors supported entirely on the pair if relevant. The conjunction includes all the gadget's factors and perhaps others, so its support is contained in {00,11}; if empty, reject; otherwise equality u=v is unconditional in the current guard. The same works for a signed inequality gadget with support {01,10}. Repeating this for all pairs obtains all inserted equality-wire consequences without being given their locations or solving the global SAT instance. This is a polynomial batch discovery guarantee for bounded-size gadgets, not a claim that the particular greedy elimination order always removes every possible region. Once an exact wire is collapsed, attached private interiors can be processed by the one-port rule when the complete current factor graph certifies privacy. For arbitrary fixed girth g, the DO02 gadget K_g has fixed finite size (which may depend very badly on g), hence this lemma gives polynomial discovery of inserted wire equalities for fixed g with a suitable fixed cap; no uniform bound in increasing g and no claim to solve the arbitrary original unstretched core. Batch all-component intersection is symbolic; the tested greedy variant projects one region at a time.

## 2. Actual tetrahedral hub and wheel reconstruction (PROVED)
For a two-port ordered boundary (a,b), BW01's packing gadget with a common named K4 palette gives free color H=2a+b and certified bidirectional lift. Encode the entire relation R_C directly as a list on H: add edge H-p_j for each j not in the allowed mask. For all sixteen Boolean binary relations, this is pointwise exact (including empty and full). No affine approximation: an arbitrary three-row mask remains nonaffine. The local hub-list gadget is constant indexed graph size, with at most four mask edges plus the fixed BW01 bit packing; alternatively each forbidden row gives a two-literal OR wheel. The original region can be replaced by this small interface with witness backpointers rather than retaining all private wheels in the active decision graph. Any number of duplicate regions with identical ordered absolute boundary can share H (or BW01 equality-sharded copies), and their permitted colors combine by set intersection. If distinct regions share other variables, these are not private and must not be erased. Duplicating a region with synchronized endpoints gives conjunction R AND R=R, not an independent XOR sumset.

For three Boolean ports, if the region INCLUDING current guards is invariant under simultaneous complement, relative coordinates (a XOR b,a XOR c) have precisely four possible values. The exact support is a four-color mask on H'=2(a XOR b)+(a XOR c). Two XOR definitions can be compiled via four ternary OR clauses each, then BW01 odd wheels and bit packing. Thus constant size physical interface; retain the anchor bit a, or use one common orientation convention with a proved consistent lift. For each relative support state, a witness of the other absolute orientation is obtained by complementing its full region assignment. If an external condition fixes a or observes an internal variable, it must be represented before projecting; complement invariance cannot be assumed. Concrete falsifier: the relations a=0 and a=1 on three ports each allow all four relative states but their intersection is empty. Retaining only the masks would report false SAT. For four absolute ports a single unrestricted two-bit hub is not a generic exact interface: even complement symmetry leaves eight relative states; extra coding or a certified restriction is required. BW01 ordinary proper 4-color graph compiler is used symbolically, not a proof that the target graph is strict 4-regular or planar. Full physical graph construction/recoloring was not executed in BW02; only the sixteen masks and relative truth tables were checked.

## 3. Guarded closure and charged progress
Before regional discovery, after every projection or substitution, and again at stagnation, run available certified closure: intersect same-scope tables, reject empty support, remove full tables, discover unary constants and fixed pair parities from ALL rows of a factor, substitute into every incident factor. Each substitution removes one live variable, updates exact local tables and records its source lift. For conditional deductions keep the complete active guard as actual factors; code does not merge results between different guards. This closure is a sound bounded module, not complete semantic closure and not all peer channels. On stagnation use a bounded final enumeration only if live variable count <=K_end, otherwise UNKNOWN; a complete solver may subsequently use another certified terminal or charged fallback.

Let n,m<=N be the root live variable and factor counts, arity <=4, K and K_end fixed or <=C log N for a fixed C. Every successful rewrite or substitution eliminates >=1 variable; same-scope fusion removes factors; a region with no factors contributes the full relation and adds no factor. Thus m never increases and there are at most n eliminations. Each discovery scan tries O(n^3) pair/seed candidates, each with polynomial graph operations (including failures); exact local truth checks take <=4*2^K times polynomial(N) per projection. Each final bounded enumeration costs <=2^K_end poly(N). Verification can replay all projections from source and reconstruct/verify SAT against original tables. A conservative bit-RAM bound T<=N^8(1+2^K+2^K_end), S<=O(N^3) bits (store source, current tables, explicit graph, ordered keys, stack and <=4 witness rows per eliminated region; no exponential table of internal assignments); CM<=TS on the same sequential realization. For the b=3 symbolic extension allow one extra polynomial factor and <=8 witnesses. These bounds include source parsing/compilation, discovery, failed trials, rebuilding, closure, comparisons, region aggregation, storage, reconstruction and original verification. They are deliberately loose. Actual timing and peak bytes were not measured; operation counters are not bit-RAM time.

Aggregate credit for the unary sequence: mu=number of live variables +1, each paid successful contraction reduces it by >=1; reserve one polynomial scan/closure/verification cost per unit, and a final paid bounded terminal or UNKNOWN. This is not an aggregate branching theorem: if the cap is exceeded there is no guarantee of a further contraction or a paid polynomial complete terminal. No DAG cache was implemented; an optional cache must include source factor ownership, ordered boundary, guard and exact projection semantics and charge all lookup/edge attempts. Do not extrapolate DP01 count volume or DP02 syndrome rank from the physical wheel shape.
