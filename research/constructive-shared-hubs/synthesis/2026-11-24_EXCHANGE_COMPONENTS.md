## A. Exact factorization from one witness
For a mandatory matching graph G with distinct boundary terminals, R consists of deletion masks x for which G minus the selected boundary vertices has a perfect matching. Acquire a feasible anchor x by maximum-weight matching with weight equal to the number of mandatory interior endpoints on each edge; if all interior vertices are coverable, set deleted boundary bits precisely at unmatched terminals. Otherwise R is empty. Define F_x on boundary ports with edge ij iff x XOR e_i XOR e_j is feasible, using one pinned matching query per pair. This is the established fundamental graph of the associated even delta-matroid.

For every y in R, symmetric difference of witnesses for x and y splits into alternating paths/cycles. Every path endpoint is a differing boundary port, each path switch is feasible at x, and the endpoints are an edge of F_x. Hence each component C has fixed boundary parity. For arbitrary y,z, path switches between their witnesses cannot cross component boundaries because they would violate those established parities. Switching the paths for one component independently recombines its boundary projection with all other components. Thus R is EXACTLY the product of its projections onto F_x components. This product is the finest Cartesian partition: any factorization of an even relation must have fixed parity in each factor, so no F_x edge can cross factors. Components are independent of anchor. Query count 1+binom(b,2). Each factor is evaluated implicitly by setting all ports outside it to the original anchor and calling the original matching oracle; this avoids expanding truth tables or duplicating graph regions recursively. A final feasible tuple lifts by querying the original graph at its full boundary word.

## B. Optional vertices
Let O be the private optional vertices. Add one dummy d_o for each o in O, join o to d_o, and make a clique on all dummies plus one additional private boundary vertex p. All vertices except removable boundary terminals are now mandatory. Given an original matching, match each unmatched optional o to d_o; the remaining dummies correspond to matched optional vertices. Include p precisely when necessary to make their number even. Conversely, discard dummy edges and recover a matching covering every original mandatory retained vertex. The new fixed-parity relation is exactly {(x,p(x)):x in R}, p(x)=(|V(G')|-wt(x)) mod 2 under deletion convention. Its fundamental graph can be acquired with original pair-flip queries plus singleton queries (flipping p with the respective bit), at most 1+b+binom(b,2). The executed implementation instead explicitly builds the polynomial-size completion graph. Project p out of its component. This yields an exact product for R, not necessarily its finest partition when R has multiple independent odd factors. No new external hub port is required.

## C. Exact cyclic terminal and paid backdoor
If all discovered factors have at most two unpinned external ports, each is an exact unary/binary Boolean relation. Acquire at most four truth rows per factor by clamping the other components to their anchor. Express each forbidden binary assignment as a 2-CNF clause; encode unary pins directly. All tetrahedral hub masks are also binary relations on authenticated shared bit IDs, so arbitrary cycles and non-Cartesian masks are accepted by this 2SAT terminal. For fixed-parity matching relations the converse holds for exact 2-CNF representability: a fundamental component of size >=3 has incident edges ij,ik. The majority of x, x+ei+ej, x+ei+ek is x+ei, not feasible by parity. Thus the relation is non-bijunctive, including under existential projection of 2-CNF.

More generally, require a guard-bit set B that intersects every triple of distinct port positions in each acquired factor (map positions to actual global variable IDs; repeated IDs only reduce triple sizes). Then at most two unpinned positions remain per factor in every branch. Greedily pick any not-yet-hit triple, add all its IDs to B, repeat. Selected ID sets are pairwise disjoint, so every feasible hitting set contains at least one ID per selected triple; |B|<=3|B*| for an optimum for this explicit triple family. No exact minimum computation needed. For each guard assignment use <=4 original matching queries per factor, with other factors held at anchor, then exact SCC 2SAT. Empty factors reject. Correctness follows from the exact product and exhaustive guards. T<=2^(3|B*|) poly(N) including acquisition, failed guards, matching calls and reconstruction (polynomially many per branch). Sequential branch storage is polynomial; cumulative memory is polynomial times time. Fixed guards and factor identities retained; do not treat semantic equivalence in one guard as unconditional. Pinning cannot merge established independent factors. If |B*|=O(log N), uniform polynomial decision follows. This is a sufficient parameter, not an unrestricted bound. The implementation returns decision, not the final full witness lift.

Infinite control: independent boundary pairs (each linked by an edge) can lie inside one connected graph by connecting them to a path of private mandatory vertices each having a private mandatory degree-one leaf. Those leaf edges are forced, so the remaining pairs factor exactly. Take two such regions and k two-coordinate hubs; label the pair factors by x_i and connect hub i to x_i,x_(i+1) on both sides. Impose inequality on each hub. All masks are non-Cartesian; arbitrary k gives a cyclic dependency graph but exact 2SAT, odd k UNSAT, even k SAT, relaxing any one inequality gives SAT.

## D. Hardness barrier (exact, not lower bound on arbitrary solvers)
Unrestricted degree-two non-Cartesian hubs are already NP-complete in this model. One diagonal mask S={00,11} duplicated to two matching regions is E4 equality. Given 3-CNF, create one such hub for each literal occurrence. In region A connect the second coordinate of each occurrence to the first of the next occurrence of the same variable in a cycle of independent matching equality wires (a single occurrence can use its own two distinct ports). Region B uses the first coordinate of every hub for the corresponding signed clause input, leaves its second free. The diagonal mask enforces one bit per occurrence and A forces all copies of each variable equal. For each clause in B, a mandatory center adjacent to its three retained-boundary literal terminals, each with a private optional leaf, is feasible iff at least one terminal is retained. Interpret retained as true using signs; all retained nonchosen terminals match their optional leaves. A spare free terminal uses an optional leaf. Thus B enforces all original clauses, and both directions lift. Polynomial linear gadget size; if connected regions are demanded, join components via forced pendant connectors that cannot change boundary support. Every hub joins exactly A and B with one terminal per coordinate. The result has arbitrary width but small local masks. Even restricting every exceptional hub to a three-state mask does not remove hardness: two masks forbidding 01 and 10 respectively compose in series through two independent matching wires, enforcing the diagonal. The two hubs each have regional degree two. This is NP-hardness of the broad residual class, not proof that P differs from NP. The small compiler controls test logical occurrence synchronization, not a full strict physical compiler.
