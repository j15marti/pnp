## A. Cardinality-certified parity gluing (PROVED)
For ANY explicit finite loopless multigraph G=(V,E) (distinct edge IDs), n even, binary labels g_e, pins and required syndrome t, let a_e=(incidence(u,v),g_e) in F2^(n+q), target a*=(1^n,t). For any subset X of distinct edges,
  X is a perfect matching with syndrome t iff XOR_{e in X} a_e=a* AND |X|=n/2.
Proof: target incidence says every vertex has positive odd degree. Sum of degrees=2|X|=n. All n positive integers must equal one. Conversely every perfect matching meets both tests. Pins are enforced at leaves. n odd rejects immediately. This is the elementary classical minimum-cardinality V-join identity (Edmonds-Johnson context), not a novel characterization of perfect matching. The advance is its use to remove the nonadditive occupancy join in M18 while preserving every actual edge identity and all tag correlations. At intermediate nodes permit arbitrary subsets, including overlaps; never call them matchings. A parity-only root on K1,3 accepts all three edges incorrectly; cardinality rejects. More generally a fixed target incidence b and |X|=popcount(b)/2 gives a matching covering exactly the support of b, since nonnegative even degrees outside it must then be zero. Unspecified optional ports require a separately authenticated completion, not this fixed-target argument.

For native B4 exact balance, parity and total are NOT sufficient: take two disjoint K5 components, all positive ports. Selecting all edges of one and none of the other gives even degrees and global degree sum 2n, yet local degrees 4 or 0, not 2. Do not apply the extremal argument directly to native B4. A verified matching compiler or different local constraints remain required.

## B. Exact Walsh composition on the supplied edge tree (PROVED)
Use M18's raw spaces U_I=span columns in I and W_I=U_I intersect U_out, w=max dim W_I. Gaussian elimination either proves target outside U_E (UNSAT) or supplies one binary subset r with a*r relation (XOR a_e r_e=a*); r is NOT necessarily a matching or pin-compliant. Center every node key by r_I=XOR_{e in I} a_e r_e. A true target subset has centered contribution in W_I at every cut. Filter only centered parity keys, not actual overlapping occupancies.

At node I retain for each centered key v the exact polynomial F_I(v;z)=sum_{X subset I, pins, centered(X)=v, surviving child filters} z^|X|. Child restrictions are disjoint by edge ID. At an internal join A=W_L,B=W_R,C=W_I, use h(zeta)=sum_{x+y=zeta} f(x)g(y) for zeta in C over the coefficient ring Z[z]. Here zeta denotes a syndrome, not the polynomial indeterminate. All true target subsets survive every filter by their complementary contribution; conversely root accepted subsets have target parity. The coefficient [z^(n/2)] F_E(0;z) counts exactly the requested matchings. Each subset appears exactly once. Optional signed moment uses leaf multiplier (-1)^(p_e x_e) and does not affect the valid subset domain.

For D=A intersect B intersect C, d=dim D, let t_J=dim A+dim B+dim C-dim(A+B+C). The homogeneous relation (x,y,zeta) with x+y+zeta=0 has dimension t_J. Quotient by simultaneous D shifts on both inputs (and sum shift on output) leaves t_J-2d dimensions. Use one common linear remainder modulo D, Gaussian kernel basis for quotient triples; enumerate only those triples. Each requires a length 2^d XOR convolution on D, computed by exact Walsh transforms, multiplication, inverse transform and division by 2^d. Ring coefficients are integers, exact division follows from character orthogonality. Sum contributions by output coset. Cost per join 2^(t_J-d) poly(N), memory 2^w poly(N), including coefficient bit lengths. As I15 proved, pair transfer spaces in the compatibility kernel have span dim i_AB+i_AC+i_BC-d, so t_J>=sum i-d. The projection dimensions w_A=t_J-i_BC etc are <=w; hence t_J-d <= (w_A+w_B+w_C-d)/2 <=3w/2. In the full common-fiber case A=B=C of dimension w the cost is 2^w poly(N). This is an exponential-factor improvement over M18 pair enumeration bound 4^w poly(N), not necessarily faster on every sparse instance. Use cheaper backend where justified; M18 one-pass hull is also valuable.

The implementation packs the degree polynomial into a signed BigInt at z=2^(m+2), m=|E|. Every actual signed coefficient has absolute value <=2^m. Balanced residue extraction (mod base, subtract base if above half, then exact division) recovers coefficients without carry ambiguity even for negative moments. Degree <=m, packed integer bit length O(m^2); intermediate transform and convolution integers have polynomial bit length (triangle inequality, at most exponentially many terms with O(m) dimension). This is NOT a unit-cost huge-word algorithm. Ordinary coefficient arrays also work.
