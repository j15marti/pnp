## A. Domain and exact completion
For every explicitly encoded finite simple bipartite graph G=(L,R,E), mandatory vertex set H, optional ports P=V-H, edge tags g_e in GF(2)^q, let X be matchings covering H. Guards may restrict graph edges or require/exclude particular edges or ports, provided represented exactly by deletion, mandatory coverage, forced-edge removal and constant offsets. Arbitrary extra guard constraints, budgets, or correlations are NOT included in X unless separately compiled; an identity valid on this larger X is still sound on subsets. Keep every guard ID and every protected original coordinate. Define d(M)_v=1 if optional v unmatched, t(M)=XOR_{e in M}g_e, and optionally edge indicator x(M). The empty-domain decision is part of unconditional closure. Source length N includes all edge/port IDs and tag bits.

Let l=|L|, r=|R|, b=l+r. Add r dummy left vertices and l dummy right vertices. Connect each optional original vertex to every opposite dummy, and all dummy pairs. Mandatory originals have no dummy edges. Both sides now have b vertices. For any original matching M covering H, pair its unmatched original vertices with distinct opposite dummies. There remain exactly |M| unused dummies on each side, which can be paired. Conversely any perfect matching of the completion restricts to an original matching covering H. Label original edges with their original tag and edge indicator, and original-to-dummy edges with the unmatched original's port unit coordinate. Dummy-dummy edges are zero. Thus the additive projected support of completed perfect matchings is EXACTLY {(d(M),t(M),x(M)): M in X}. Completion duplicates witnesses, so no count equivalence is asserted. All dummy lifts are polynomial, preserve original IDs, and allow projected reconstruction. Forced original edge can be frozen with its tag/indicator constant and both endpoints covered before reduction.

## B. Joint affine hull from actual alternating-cycle witnesses (PROVED)
Find one perfect matching M0 or certify none by ordinary bipartite matching. Relabel matched pairs (L_i,R_i). For every nonmatching edge L_i R_j add arc i->j, labeled with the XOR of this edge's feature vector and the matched edge L_i R_i's feature vector. For any simple directed cycle C, cyclically reassign the matched right endpoints; the result is a real perfect matching M_C. Its feature difference from M0 is the XOR of arc labels along C. Conversely any perfect matching differs from M0 by disjoint directed cycles (its permutation cycles). Therefore the exact affine direction space is the span of these actual cycle differences.

A polynomial list of actual witnesses suffices, without enumerating cycles. In each SCC choose root r and directed simple paths P_v:r->v and Q_v:v->r. Include the closed walks P_v Q_v and P_u (u->v) Q_v for every internal arc u->v; decompose each walk into simple directed cycles using repeated-vertex stack elimination. Their labeled XOR differences generate all cycle differences: write p_v,q_v for path labels, and observe the sum of the two walk labels p_u+g_uv+q_v and p_v+q_v is p_u+g_uv+p_v. Summing these expressions on any directed cycle telescopes to its label. Every walk component supplies a real witness at the SAME base matching; no claim that arbitrary sums of overlapping flips are real matches. There are O(b+|E'|) walks, each O(b) length. Generate, verify, and Gaussian-eliminate their differences, retaining base and a basis of actual witnessed differences. Project this exact span to any linear observation, including tags not originally designated. This directly implements GD09's single-parity witness capability for this domain, and gives all affine identities at once rather than repeated separate solver calls. A single parity target is attainable iff it equals the base parity or some generating witness has the opposite parity; return that actual source witness. All fixed edge, port and tag bits follow by annihilation, and all affine equations follow by taking orthogonal complement. Enforce certified unconditional closure before terminal use; adding facts already true on X cannot change X or yield further consequences from this same hull. After any actual graph restriction/deduction, rebuild as needed, and at stagnation run all applicable certified channels before any branching. ## C. Exact physicalization rank and witnesses (PROVED)
Write U=span{(d(M)+d0,t(M)+t0):M in X} and K={z:(0,z) in U}. Compute K by Gaussian elimination prioritizing port coordinates. Let D=projection_d U. For every linear tag functional a in GF(2)^q,
  exists p,c such that a.t(M)=c+p.d(M) for EVERY M in X
  iff a is orthogonal to K.
Necessity: the identity extends to U differences, hence vanishes on (0,z). Sufficiency: define linear functional on D by d -> a.t for any (d,t) in U. Well-definedness is exactly annihilation of K. Extend to the ambient port space by Gaussian elimination, obtaining p; c=a.t0+p.d0. Hence the space of all physicalizable tag combinations has dimension q-rank K. Moreover rank K=rank U-rank D. A basis of K together with its Gaussian preimages in actual matching differences is an independently checkable obstruction to any affine port-only representation of the offending tag. It need not be a pair of actual matches with identical port word; do not mistake a span certificate for a feasible pair. For a positive certificate, the identity holds pointwise on every source match and remains valid after ANY further constraint/pin, unlike replacing support by its affine hull. Preserve remaining unphysicalizable observations and original masks under basis changes. Rank K small alone gives no terminal for those residual tags.

Useful full-optional special case (any simple graph): if every vertex is optional and X is all matchings, physicalization of a vector tag is equivalent to existence of vertex potentials h_v satisfying g_uv=h_u+h_v for each edge. Necessity compare the empty matching with each single edge. Sufficiency sums over selected edge endpoints; constant offset is XOR of all potentials. Equivalently every graph cycle has zero tag sum, verifiable by spanning-tree traversal, including odd cycles. This criterion is not necessary on constrained mandatory slices, for which B/C give exact bipartite recognition. General nonbipartite constrained joint hull not established here.

## D. Automatic disjoint-owner test and exact terminal (PROVED)
Suppose source owner classes P_i form a supplied disjoint partition of optional ports with quota intervals, and tag coordinates appear in vertex-disjoint pairs carrying arbitrary four-color masks (or individual unary pins). We require a port owner per nonconstant tag coordinate and distinct owners for distinct tag coordinates. For coordinate j and owner i compare their signatures on U:
  e_j.t + 1_{P_i}.d = 0 on U.
If true, edge j->i in an auxiliary bipartite compatibility graph is allowed, and the XOR offset is e_j.t0+1_{P_i}.d0. Every such edge is an exact identity on X. Find a matching saturating the tag-coordinate side; this is NECESSARY AND SUFFICIENT for this specific injective assignment scheme. Constant tag coordinates can instead be substituted in masks before the test; unary pins can pair with a private empty owner of parity 0. Keep original owner quotas. For accepted mapping, translate masks by the exact offsets and apply I08's physical quota/mask gadget. Every original feasible matching lifts and every enlarged matching restricts to an original feasible matching with all original tags verified. Owner choice discovery and tag offsets are polynomial. A failed auxiliary matching only rejects this representation scheme, not the source SAT instance. Hall deficit proves no injection of this form. If protected tags not used in masks, still retain their IDs and reconstruct them from original matching; arbitrary simultaneous extra parity probes need not preserve disjoint pairing. No free synthesis of owner partitions or arbitrary nonlinear mask transformation.

The actual independent edge example has physicalization rank full even with 2^h original matchings. This does not imply that all edge-labeled matchings are physicalizable. Mandatory K2,2 with exactly one red-tagged edge has two perfect matchings with identical empty defect vector and distinct tags. K has rank 1. Even for bipartite graphs the exact affine hull is not an exact support relation: take three matched pairs with diagonal edges and only two off-diagonal transpositions (1,2) and (1,3). Tag one directed edge of each transposition by independent bits 01 and 10; all other edges zero. The matchings are identity or one transposition, so tag support {00,01,10}, not 11, although affine hull is full. This falsifies unrestricted affine saturation. Likewise, two independent optional defect bits can have prescribed tags p1 and p1+p2, physically affine but not necessarily assignable to distinct supplied owner groups. Do not treat arbitrary port overlaps as disjoint pairs.
