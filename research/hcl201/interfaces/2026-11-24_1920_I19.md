## 2. Uniform native compiler (PROVED)
Input any finite explicit loopless degree-four multigraph, including strict simple RT01 instances. Every vertex is E4 (four equal port bits) or B4 (exactly two one ports). Each wire e=(u,v,s) relates endpoint bits by XOR s. Orient each wire arbitrarily once; x_e is its first endpoint bit, the second is x_e+s. Pins on actual x_e are allowed. Validate ports, degree, signs, IDs and pin format; reject malformed descriptions separately. Let n vertices, b B4, a=n-b E4, m=2n wires, h sign-one wires.

Create four distinct port vertices for each source vertex. B4: two private dummy vertices, connect each to all four ports (K_{2,4}); no other internal edges. E4: pair ports (0,1),(2,3), add the two internal pair edges and give each the same unique tag coordinate for this E4. Require XOR of all E4 tags zero. Wire s=0: one edge between corresponding ports. Wire s=1: a private midpoint with a length-two path between the ports. Declare port bit one iff port is occupied by its wire edge. For a sign-one wire exactly one of the two edges must be selected (midpoint saturated), for sign-zero both port bits equal. The designated first edge of every wire has selection bit exactly x_e. Add pin tags at designated edges, with actual RHS. Graph has 4n+2b+h vertices, 8b+2a+m+h edges, a tag coordinates before pins. No free fanout or implicit source identities. All graphs have distinct port IDs.

At a B4 exactly two ports must match the private dummies and the other two their wires; every legal word has exactly 2! internal matchings. At E4 a pair is either matched internally or both ports use wires; hence both bits in each pair agree. XOR tag zero enforces the two internal pair indicators equal, so all four external bits agree. Each legal E4 word has unique internal lift. Wire lift is unique. Therefore for EVERY fixed source port assignment, its fiber is empty if illegal and has exactly 2^b perfect matchings with the tag target if legal. Consequently #taggedPM=2^b #native port models. This is a pointwise reduction, not just both-label. Decoding actual x_e and choosing arbitrary deterministic bijections between the two free B4 ports and dummies are polynomial. Source pins, arbitrary protected affine XORs of x_e and additive integer quotas can be transported using designated edge labels/weights (affine constants adjusted); the same multiplicity holds. A geometric encoding or earlier SAT-to-port compiler can have its own nonuniform multiplicities, so do NOT divide by 2^b to count original SAT variables without further proof.

This closes the I18 native-B4 gap via a matching compiler rather than asserting parity plus a global degree total on native B4 vertices. I03 E4 boundary obstruction remains valid: the indispensable tag is what enforces agreement between pairs. With no E4/pin/global tag rows ordinary matching solves the entire signed B4 class; with arbitrary E4 the resulting multiple-tag matching problem is NP-hard by RT01's source reduction. This is not P!=NP.

## 3. Exact native-to-matching separator rank identity (PROVED)
Let K be the homogeneous kernel on m source wire bits of the affine relaxation: E4 equalities, B4 parity-even, signed wire transports already eliminated using x_e; include coordinate pin rows (homogeneous differences zero). B4 parity is the exact local affine hull of its six words. Let A be the binary matrix whose graph columns are incidence endpoints plus tag bits, and K' = ker A. Target incidence is all ones plus specified tag RHS. The projection pi from graph selections to designated x_e is linear.

For a graph parity solution (not necessarily matching), each wire obeys the signed relation; a B4 internal parity system on K_{2,4} has incidence image exactly the even-total vectors (connected graph), so solvable iff its four external bits have even parity. Given those bits, its affine solution fiber has dimension 8-6+1=3. At E4 the two internal bits are uniquely forced by port parity and the tag enforces equality. Thus the affine parity solution projects exactly to the source affine relaxation; likewise pi:K'->K is onto, with kernel a direct sum of b private three-dimensional B4 spaces. This also proves equivalence of consistency of the two affine systems. For any fixed source target with all pins, the parity fiber has size 2^(3b) if consistent, but the actual PM fiber is 2^b only for legal B4. Never confuse these.

For a partition of source vertices L,R, assign all vertex gadget edges to their vertex and all edges of a wire gadget to the first source endpoint. These disjoint constant-size edge groups define a matching edge partition L',R'. Write K_L={x in K: x_e=0 unless both endpoints in L}, similarly K_R. For a homogeneous graph solution supported only in L', all crossing wire bits must vanish: at the R port the vertex-gadget contribution is zero, and the wire contribution is the same homogeneous bit even for a sign-one wire (midpoint equation). If the wire belongs to R', the same conclusion follows from its absence. Internal R wire bits vanish as well. Conversely every x in K_L lifts entirely in L' by independent local linear systems, taking zero in R; internal B4 free kernel choices are confined to L. Hence
 dim K' = dim K+3b,
 dim K'_{L'} = dim K_L+3b_L,
 dim K'_{R'} = dim K_R+3b_R.
The joint graph cut width is rank A_L'+rank A_R'-rank A = dim K'-dim K'_{L'}-dim K'_{R'}. The kernel of projection of K onto the crossing wires delta(L) is precisely K_L direct sum K_R (all source rows are vertex-local or coordinate pins). Cancellation therefore gives the exact identity
   w_graph(L') = dim pi_delta(L)(K).
No factor proportional to raw graph cut length or number of tags is needed. Compute source value as rank([R_source; unit rows for crossing wires])-rank(R_source), by Gaussian elimination. This is rank of attainable LINEAR boundary variation, not the nonlinear support. Arbitrary added global tag rows break the local-kernel split; recompute actual joint width (adding q rows increases each matrix cut width by at most q, since global rank increment is at least either side's). No automatic monotonicity of removing tags or freely recharting.

Group size <=16 matching edges per original vertex (8 internal + at most 8 outgoing wire edges). Given any binary source vertex tree with max width k, replace each leaf by a binary tree on its group. Whole-group cuts retain exactly their original width; new internal group cuts differ from its singleton cut by at most 16 column moves, each changing matroid connectivity by at most one. Thus max matching width <=k+16. Actually one can bound isolated subgroup rank by its own size; constant 16 suffices. This transfers any source logarithmic-width tree to I18 with no asymptotic exponent loss. Closure rows local to vertices/pins may be archived without changing compiler support; if adding arbitrary consequences as tags, remeasure rather than assume monotonicity.
