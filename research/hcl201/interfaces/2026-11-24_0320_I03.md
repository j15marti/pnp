## 2. Exact multi-guard selector theorem
Let E=GF(2)^d include full exposed occupancy, syndrome, protected additive observations and (where required for external synchronization) the two color bits. A factor has exact joint support
    S = union_{h in H} (R_h + W_h)
where |H|<=4 for a tetrahedral hub; arbitrary finite H also works. R_h is an explicit list of actual representatives, W_h a subspace given by basis, with exactness and total lift maps certified *within* guard h; empty fibers allowed. If a guard bit is part of an observed tag, put it in every representative and require its coordinates zero on W_h. If guard is a nonlinear predicate, treat guard as internal unless its label is explicitly included and certified. This is NOT arbitrary matching realization of physical four-port occupancy.

Build an edge-labeled DAG with source s and sink t, one private branch per nonempty guard. On branch h choose exactly one representative r in R_h using distinct two-edge alternatives (tag r then 0). For each basis vector w of W_h, add a stage with a direct zero arc and a two-edge detour tagged w then 0. Finish by one zero edge to t. Branches have disjoint interiors. The set of XOR path tags is exactly S. Any path uniquely identifies guard, representative and selected independent basis directions. Distinct representative paths need not have distinct tag values.

Convert the DAG into a private bipartite tagged graph with two copies L_v,R_v of each DAG vertex. Each DAG arc u->v becomes L_u--R_v with the same tag; add diagonal L_v--R_v of tag zero for internal vertices only, and forced return edge L_t--R_s of tag zero. Perfect matchings correspond to permutations of the DAG vertices. Because the only non-loop directed cycle must contain the return arc (DAG acyclic), and s,t lack diagonals, every perfect matching is a single s-to-t path closed by the return edge plus internal diagonals. Conversely each path completes uniquely by diagonals and return edge. This proves exact joint tag support and path/PM bijection. If all branches empty, there is no PM. No parallel edges, no physical connection to exterior, and no extra syndrome coordinates beyond existing joint tag space. The graph has O(1+|H|+sum_h(|R_h|+dim W_h)) vertices/edges, before charging d bits per edge and index size. It is not necessarily degree four or a geometric wheel. High rank is represented, not automatically solved.

Exact exterior composition: after I01 splitting, each original shared vertex occurs in at most two independent local regions. Encode its occupancy as a tag bit in both factors and require global XOR=1. This is equivalent to exactly one region occupying it; internal vertices remain saturated locally. Any ordinary local region can be made private for this composition by adding b+(|I| mod 2) private dummy vertices for b ports, connecting each port to all dummies, and forming a dummy clique, all dummy edges zero tag; original edges carry their original exposed occupancy tags. Unoccupied ports consume one dummy each, remaining dummy count is |occupied|+(|I| mod 2), even by parity; completion exists and conversely restricts to a legal local matching. The dummy completion may introduce multiplicity, no counting claim. Full original matching is recovered by lifting each private factor and gluing. The global joint target is unchanged. A selector therefore replaces arbitrary compact four-color joint fibers without the need to realize their occupancies directly as physical exposed ports. At any cut of the ORIGINAL factor partition, exact local support unchanged implies unchanged affine subspace intersection width. Recompute width if repartitioning inside the selector; no guarantee of reduced width.

Witness and GD03: choose an original representative witness and apply certified total translation maps in its original guard, checking source occupancy and all tags. Include protected features as additive tags only when actually represented; an arbitrary nonlinear feature basis, counts, optimization or all original witnesses are not preserved merely by retaining support. M03 Hall/disjointification is permissible for unprotected additive target with its hypotheses; do not infer separate original feature invariants from one lift. The tests below compared complete support, not executable source translation maps.

## 3. Physical four-port obstruction
Unconditional physical boundary support of an ordinary matching gadget (all interior vertices saturated) satisfies even symmetric exchange: for any two local matchings, their symmetric difference consists of alternating cycles/paths; each port occupied in exactly one has degree one and lies at a path endpoint. Flipping such a path changes just two of the differing port bits and leaves internal saturation intact. Thus a relation {0000,1111} cannot be represented by any such gadget, irrespective of graph size: one flip from the empty occupancy yields a two-occupied-port state. This is the E4 equality obstruction, consistent with even delta-matroid theory. The theorem in Section 2 bypasses this only by explicitly moving occupancy into syndrome targets, not by claiming a forbidden physical realization. Conditioning on extra tag equations can destroy the exchange property; no contradiction with conditional fibers. I02's two-port physical theorem is not an arbitrary four-port theorem.

## 4. Exact affine hull acquisition and unconditional target closure
For ANY finite edge-labeled DAG, discard vertices/edges outside an s-t path, check ordinary reachability. If no path, empty. For each remaining vertex v choose an actual prefix path tag p_v (p_s=0); compute residual labels d_e=p_u+g_e+p_v for arc u->v. Then
    aff(S)=p_t+span{d_e}.
Proof: each residual is the XOR difference of two actual complete paths, obtained by extending the chosen prefix to u via e and the chosen prefix to v with one common suffix from v; acyclicity ensures valid paths. Conversely summing residuals on any path telescopes to its tag plus p_t. Basis and actual witness path pairs can be acquired in polynomial time by graph traversal/Gaussian elimination. This is deterministic affine hull extraction for compact selectors, not exact membership. No need for exponential support or a general PM-span oracle in this subcase. A global vertex gauge/shear does not reduce true width by itself (I01).

Given exact affine-coset factors, first compute their exact affine hulls by spanning all W_h and differences of representatives (or above DAG formula). Reject target outside summed hull. Then for each individual coset C=a+W in factor i intersect with t+sum_{j!=i} aff(S_j), a computable affine space. Empty intersection removes C; otherwise replace C by its exact intersection using Gaussian elimination. Retain guard and original source witness maps; a new basis can be expressed in old basis coordinates. Any actual tuple attaining t survives every step because other actual values lie in their hulls. Hence closure preserves every global target witness tag tuple, not merely existence, and every removed local state has a certified target-relative contradiction. Recompute all unconditional affine consequences after each strict change; repeat at stagnation before considering further branches. For C0 explicit initial cosets, potential sum_C(1+dim W_C) <= C0(d+1); each proper intersection strictly decreases this integer, so repeated scans terminate in polynomial time in explicit coset encoding and d. No recursive enumeration. This is not all-channel forced-information closure, and does not certify target membership if stalled. Local coset completeness/translation certificate discovery remains independently charged.

## 5. A hardness boundary for compact four-color composition
For every strict 3-CNF F with distinct variables in each clause, construct occurrence-coordinate space E=GF(2)^(3m), one bit per literal occurrence. Each variable factor has support {0,d_v}, where d_v is the indicator vector of all occurrences of v (omit variables with no occurrences). Each clause factor has support equal to the seven satisfying local triples in its three occurrence coordinates (all other coordinates zero). Represent this support by THREE affine fibers: choose a guard j in {0,1,2} naming one satisfied literal, fix that variable bit to its satisfying value, let the other two bits vary freely. Fourth color empty. Each fiber has one representative and dimension two. If literal guard overlaps, different paths may have same tag; support is the semantics. Variable factors have one affine fiber dimension one. Use Section 2 to realize all factors as private simple bipartite tagged matching graphs of constant graph-object size per factor (tags dense encoding still polynomial). Require XOR target 0. This forces each clause's occurrence assignment to equal the global variable choice on every occurrence, because precisely two factors contribute that coordinate. Thus both SAT and UNSAT preserved and a matching tuple yields a source truth assignment. Ordinary witness verification polynomial. This is a uniform polynomial reduction from 3SAT to the restricted additive tagged matching problem with at most four fibers, each rank<=2. It proves NP-completeness of that decision class, not P!=NP. In particular low individual guard rank, low fiber dimension, compact graph encoding, and independent physical graphs are not sufficient terminal parameters by themselves unless P=NP. It makes no claim that the compiler lands in the required strict geometric wheel class.

Stronger: exact affine-coset closure in Section 4 always stagnates on these encoded strict 3-CNF formulas, including UNSAT. Each clause support has full affine hull on its own three coordinates. For the complement of a variable factor, all clause hulls already span E. For the complement of any clause factor, other clause hulls span all outside its three coordinates. The three variable vectors of its distinct variables are individually present, and after adding outside coordinates they give each of the missing three unit vectors. Thus every complement affine hull is E. No coset is removed, even conditional affine intersection with that complement. This does not preclude M03/Hall, GD02, 2SAT, exact other closure, branch decomposition or a new unrestricted shortcut. S02's common dictionary may represent clause supports as translated U(2,3) matroids, but occurrence variable vectors create dictionary dependencies; no small global nullity bound asserted.
