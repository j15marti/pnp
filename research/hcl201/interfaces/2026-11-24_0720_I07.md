## 2. Theorem: exact integer exchange recognition (PROVED)
Input N counts explicit finite nonempty row lists c_b(r) of nonnegative binary integers, owner budgets K, IDs, guard and lift data. Let m_bi=min_r c_bi(r), H_i=K_i-sum_b m_bi. If H_i<0 reject. Delete a row when any c_bi(r)-m_bi>H_i; repeat and recompute minima after each deletion; empty list rejects. This certified unconditional closure preserves all feasible tuples. Renew all applicable certified channels after deductions and at stagnation before any conditioning; executed backend only implements affordability, not full source closure.

For each owner choose positive common scale d_i dividing every remaining c_bi(r)-m_bi (e.g. gcd of positive differences; 1 if all zero), or a supplied valid scale. Set U_i=floor(H_i/d_i), a_b(r)_i=(c_bi(r)-m_bi)/d_i. Deduplicate cost vectors while retaining all original IDs and admissible lifts. Require each set A_b of distinct vectors have constant sum k_b and satisfy the integer exchange axiom:
for every x,y in A_b and every i with x_i>y_i, there is j with x_j<y_j and x-e_i+e_j in A_b.
Test all ordered pairs and coordinates by exact dictionary lookup. Failed recognition means UNKNOWN, not UNSAT. This is the standard discrete base-exchange structure, not an assumption of independent loads. I06 rank-one choices are included (add a private unconstrained dummy coordinate to any zero residual choice). General varying totals are not recognized without a separate exact fixed-sum padding construction.

Polynomial clone bound: for each i, min a_i=0. Start at a maximizer x and fix a minimizer y. While x_i>0 apply the axiom to i and y. The i coordinate decreases by exactly one each step; all resulting rows distinct. Thus M_bi=max a_i <= |A_b|-1. This proves even binary encoded normalized loads cannot require exponentially many clones once exchange has passed. More generally the range is <=|A_b|-1. Can reject oversized range before allocation. No optimization of scales claimed.

Construct M_bi labeled unit copies of owner i in block b. Declare bases to be all copy subsets whose count vector belongs to A_b. They are nonempty and equal size k_b. For bases P,Q and copy e in P minus Q of owner i: if count_P(i)<=count_Q(i), a same-owner copy in Q minus P exists and can be exchanged. Otherwise apply integer exchange to count_P,count_Q, choosing owner j with count_P(j)<count_Q(j); take any such copy from Q minus P. Result is a base. By ordinary matroid base exchange these bases define a matroid. Its independence oracle counts copies and tests if some explicit row dominates the count coordinatewise. The direct sum M of block matroids has rank k=sum_b k_b. Partition matroid C on the same ground set permits at most U_i copies from owner i (clamp capacities at total copies).

## 3. Theorem: exact owner-subset Hall certificate (PROVED)
For S a subset of owners define D(S)=sum_b min_{a in A_b} sum_{i in S} a_i. Then compatibility iff for every S, D(S)<=sum_{i in S} U_i.
Necessity immediate. Sufficiency via Edmonds min-max: max common size=min_X [r_M(X)+r_C(E minus X)]. For any X choose S={i: |E_i minus X|>=U_i}. For non-S, partition rank contributes |E_i minus X|. Adding all missing non-S copies to X increases rank by at most their number, giving
r_M(X)+r_C(E minus X) >= r_M(E_notS)+sum_{i in S} U_i.
Here r_M(E_notS)=sum_b max_{a in A_b} sum_{i notin S} a_i = k-D(S).
If all Hall inequalities hold, every min-max candidate >=k and a full base exists. On failure the standard exchange graph reachable set R from M-addable vertices yields X=E minus R with r_M(X)+r_C(R)=|I|<k. The stated S then gives D(S)>U(S). Verify directly by scanning actual rows; no exponential subset search. This is a compact qualitative contradiction across arbitrarily many coupled matching blocks. It also works when total capacity >=k yet a restricted owner group is deficient.
