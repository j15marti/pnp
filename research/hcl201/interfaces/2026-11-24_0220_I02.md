## 2. Two-terminal guarded affine-product theorem
Let H have distinct ports u,v and private interior I; all edges incident to I in the full graph are in H, and H edges are disjoint from exterior edges. A local matching must saturate I, and may occupy a subset of the ports. Every edge has a binary tag in E, including every additional linear observation needed by other factors. The local occupancy states are (a,a+p) for a=0,1 and p=|I| mod 2: the number of covered vertices must be even. Let S_a be the exact set of tag sums in that state. Empty fibers are allowed. To obtain a fiber delete unoccupied ports and find perfect matchings of the remaining graph. First perform ordinary PM checks and complete affine closure (I01/M01); reject if both fibers empty or if global target outside the applicable combined hull.

Suppose for each nonempty S_a a certified subspace W_a and explicit finite set R_a satisfy
    S_a = R_a + W_a.
Here '+' is Minkowski XOR addition. This is an exact support identity, not an affine-hull approximation. W_a may be certified by M02 witness-liftable translations that preserve the fixed occupancy state; R_a may consist of one actual representative of each quotient coset. Empty fibers use R_a=empty, W_a=0. For affine exact fibers, R_a is a singleton. The two W_a may be entirely different, even W_0 intersect W_1=0.

**Claim:** Replace H by a chain of O(1+max(dim W_0,dim W_1)) elementary two-terminal stages, with O(1+dim W_0+dim W_1+|R_0|+|R_1|) vertices/edges, retaining exactly the entire occupancy-tag relation, no global quotient and no enumeration of 2^dim W_a choices. Size is in graph objects; multiply by explicit encoded tag lengths and indices.

Elementary even stage between terminals l,r: use path l-b-c-r with private b,c. For local occupancy 00, choose one b-c edge with tag from an explicitly specified list L_0. For 11, choose one l-b edge from list L_1 and edge c-r of tag zero. There is no mixed occupancy because the interior has even size. Lists can be empty; parallel edges are distinct alternatives. If simple graph required, replace each parallel-edge alternative by a private length-three path, tag on one outer edge and zero otherwise. The unused path uses its middle edge, the used path consumes both endpoints. This preserves the support relation with linear extra size; no parallel edges need remain.

Join consecutive stages by identifying right port of previous with left port of next; the identified vertex is private and must be saturated exactly once. Hence with first-port occupancy a, stage i (zero-based) has local equal port occupancies a XOR (i mod 2). This is a *single common guard*, propagated by exact matching, not two independent guard choices. Choose stage 0's two lists from R_a; on stage i>=1 put list {0,w_(a,i)} if basis generator i of W_a exists, else {0}, in the local state corresponding to the original a. Each generator choice is independent conditional on a. Pad by one zero-tag stage if necessary so number k of stages has (k-1) mod 2=p; the last occupancy is then a+p. Interior count of the basic chain is 3k-1; simple conversion adds an even number. Exact tag support in each state is R_a+span(basis W_a)=S_a. For an empty R_a no matching in that state. The chain is exact under arbitrary exterior gluing because it preserves both port occupancies and tag sums pointwise, and all new interior is private. No use of unrestricted XOR occupancy at vertices incident to three regions; I01 splitting still required when using that separate representation.

Witness: record a real original fiber matching per representative and original lift maps for basis W_a; decode a replacement matching to its representative and selected basis bits, apply the maps within the correct occupancy fiber, verify the original local edges, and glue to unchanged exterior. If multiple replacement witnesses represent the same tag, any valid one suffices. If support known affine by a fully constructive peeling algorithm rather than translation maps, solve the requested tag directly by that lift. For protected linear observations retain them in the full tag; no information is thrown away. Arbitrary original-variable feature spans (GD02), number of matchings, and weighted optimization are NOT implied by this decision/search replacement. Each conditional proof stays guarded by a; it is not an unconditional affine constraint.

**Why this strengthens M02:** intersecting W_0 and W_1 gives a valid common translation, but may discard all opportunities if intersection=0. The present conditional chain factors both spaces while preserving the original two-port relation and all tags. It also provides a way to replace a large local matching predicate by another tagged graph assembled from explicit at-most-two-choice factors, not an implicit truth table. It does not establish that the surrounding synchronization rank or decomposition width is small; residual solving may remain hard.

## 3. Discovery and closure
Polynomial candidate list: for every unordered vertex pair {u,v}, remove it, enumerate connected components, and consider each component together with the two ports, assigning its incident edges to that module; do not silently duplicate uv, assign that edge separately. This finds each single connected interior component of a two-vertex separator, O(n^3) candidates (not every union or arbitrary module). Verify private interior and port ownership. More general supplied modules admissible. For each candidate compute the two fixed-occupancy PM affine hulls and reject empty fibers using M01. Discover witness-liftable translations via M02 twin tests or supplied verified maps separately in each fiber. If certified W_a covers its affine variation span, the nonempty fiber is a single exact coset; if quotient affine rank is 1, its support is automatically the whole two-point quotient and correct-parity matching produces actual representatives (M01). If quotient rank exceeds 1, use a separately charged exact membership solver or return OPEN; do not fill the rank-two hole {0,1,2}. For rank q residual, listing may require 2^q exact tests and storage; no polynomial general discovery claim. W_a may also be 0; no useful compression if explicit R_a grows exponentially. Initial affine closure, renewed closure after each committed certificate (or exact batch with charged checks), and at stagnation before probing remain mandatory. Guards are never promoted to global equations merely because local tests pass. For a polynomial preprocessing schedule only commit replacements that strictly decrease total encoded representation size, including retained lifting records if claiming a global size potential, or impose a fixed polynomial work/replacement cap; a chain with additional auxiliaries need not shrink the original graph. The cap yields a safe incomplete preprocessing, not universal progress. Retain source and all witness records, charge complete lift depth and reuse.

## 4. Partial local-translation width contraction
Generalize S01 from removing full factor spans to absorbing certified subspaces of surviving factors. Given independent additive factors S_i (I01 incidence repair for matching occupancy), a local translation space W_i<=V_i=dir aff(S_i) satisfies S_i+W_i=S_i with local witnesses. W=sum_i W_i. Then sum_i S_i is invariant under W. Exact decision on quotient of global target and actual lifted original-factor witnesses; for protected P use W intersect ker(P), but see width caveat below. At a fixed cut X|Y, A=sum_X V_i, B=sum_Y V_i, W=W_X+W_Y where W_X=sum_X W_i<=A and W_Y<=B. For the quotient pi_W, equality pi_W(A) intersect pi_W(B)=pi_W(A intersect B): equal-image a,b differ by w_X+w_Y, so a+w_X=b+w_Y lies in intersection. Thus
    kappa_new=kappa_old-dim(W intersect A intersect B).
Every inherited tree cut weakly decreases even if no factor is fully peeled. Local lifting can distribute required target difference across W_i via Gaussian basis provenance; adjust each selected local witness before testing final original global occupancy. Do not apply formula to arbitrary cross-cut W or W intersect ker P unless it still decomposes across the cut. For example A=span(e1), B=span(e2), W=span(e1+e2) increases width 0 to 1. Even if W decomposes, W'=W intersect ker P can become that diagonal subspace, so protected global quotient can increase width. A safe alternative is sum_i(W_i intersect ker P), possibly losing some cancellation. Conditional W_a from distinct occupancy fibers cannot simply be counted as unconditional local translations; only common directions, or chain representation keeping the guard, are sound. Width of new chain's rearranged partition must be measured again; no guaranteed decrease from replacing the graph alone.
