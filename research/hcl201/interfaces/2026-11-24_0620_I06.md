## 2. Exact model and mandatory prepass
For each block b, a finite nonempty explicit row set R_b is supplied, with nonnegative integer cost vector c_br in Z^h and a distinct row identity. Rows come with exact local witnesses (or, for the abstract row problem, row identities are the witnesses). Select exactly one row per block, with sum_b c_br[i] <= K_i for each budget owner i. All guards are fixed or retained as conditions, not dropped. The I05 parity target makes block row choices independent except for these budgets; any additional coupling must be represented, not omitted. For nullity-one blocks both possible coefficient joins are generated in polynomial time by a particular parity solution and its XOR with the unique nonzero cycle vector. No general high-nullity row acquisition assumed. Keep separate protected observations: an arbitrary GF(2)-linear combination of row indicator bits is allowed; any original coefficient tag is obtained by assigning its value to each row, and physical tags require an authenticated pullback.

Before classifying the terminal, compute m_bi=min_r c_br[i] and H_i=K_i-sum_b m_bi. Negative H_i certifies UNSAT. For each row r, if c_br[i]-m_bi>H_i for any i, it cannot occur in a feasible tuple: all other blocks must pay at least their minima. Delete it with that certificate. Recompute until fixed point; at most total row count deletions, reject empty row set. Every deduction is unconditional in the fixed-guard cell. Exact same-scope fusion (RT05) can precede this prepass if exact rows are acquired and paid. Do not conflate independent minima with compatible optimal choices. Full outer all-channel closure is not implemented in this primitive.

## 3. Owner-normalized single-load theorem (PROVED)
Promise: for each owner i there is a positive integer d_i such that each residual row c_br-m_b is either zero, or exactly d_i times the i-th unit vector for a single owner i. The d_i may differ across owners and have binary encoding. If an owner has no nonzero residual entry, its scale is irrelevant. Recognition is a direct scan of all residual rows: at most one positive coordinate, all nonzero values at a given coordinate agree. Thus no oracle supplies the decomposition.

Define capacity U_i=floor(H_i/d_i), capped at B (the number of blocks). A dummy owner has capacity B. Construct a directed network: source -> each block (cap 1); each row gives a separate cap-1 arc from its block to its unique residual-load owner or dummy; each owner -> sink with cap U_i (dummy B). Parallel row arcs stay distinct even when costs agree. There are O(B+h+R) arcs and vertices, R total row count.

For EVERY explicit system satisfying the promise, budget feasibility iff integral max flow value B. Proof: a feasible tuple sends one unit through its chosen row per block; the total cost for owner i is sum_b m_bi+d_i times its number of selected nonzero-load rows, so the budget is equivalent to capacity. Conversely a full integral flow saturates each source-block edge, hence selects exactly one distinct row arc and realizes every owner budget by the same identity. This proves exact witness correspondence (in the explicit row model), not merely a relaxation. Integral augmenting paths terminate after at most B augmentations irrespective of binary budget magnitude. A smaller maximum value gives a verified cut certificate. Hall-type obstruction: there is a set of blocks whose available owner set (dummy included) has total capacity less than its cardinality, by capacitated bipartite matching; the network cut alone suffices for certification. No enumeration of cycles in the owner-block incidence graph.

Specialization: a nullity-one graphic block has exactly two feasible coefficient rows. Subtract ownerwise minima. If the two alternatives differ by exchanging one owner-specific unit between at most two owners (opposite signs), or change only one owner by its unit, or have equal cost vectors, the promise holds. The equal-cost row identities are NOT merged: they can differ in protected tags. Unit scales must be consistent across all such blocks for each owner. In particular parallel-edge blocks with one edge per owner of unit cost give a graph orientation problem with prescribed indegree upper bounds; arbitrary cycles are harmless. This bypasses I05 p and MS05/M06 feedback/cut conditions on that class.

## 4. Exact linear feature hull from a single feasible flow (PROVED)
Let f0 be an integral full flow, z0 its row indicator vector. Residual arcs have positive integral residual capacity; keep the identity of the original row arc, and label both residual directions of a row arc with that row's unit vector over GF(2). Non-row arcs have zero label. For a simple directed residual cycle C define delta(C) as XOR of its arc labels. Augmenting one unit on C preserves source-sink value and all capacities; the row indicators of the result are exactly z0+delta(C). This remains true if opposite residual arcs of a non-row arc form a two-cycle (their net change cancels). A row arc has capacity one, so at f0 only one of its two directions is available.

Conversely for any feasible integral full flow f, its signed difference f-f0 is an integral residual circulation: for each original arc take its difference in the appropriate residual direction. It decomposes into directed simple cycles with positive integer multiplicities (follow positive arcs until a cycle closes, subtract minimum multiplicity; repeat). Modulo two, this yields z(f)+z0 as a sum of delta(C). Therefore
  aff{z(f): f full integral} = z0 + span{delta(C): C simple directed residual cycle}.
This is a statement about the affine HULL, not that every vector in the span is a feasible tuple.

Polynomial witnessed acquisition: only arcs internal to a strongly connected component can lie on cycles. In each SCC choose root r, directed paths P_v from r to v and Q_v from v to r. Generate closed directed walks P_v Q_v, and P_u e Q_v for every internal residual arc e:u->v. Decompose each walk into simple directed cycles by removing repeated-vertex segments. This is O(V+E) walks of O(V) length. Their cycle labels span all residual cycle labels: modulo two, for any directed cycle, XOR the labels of P_u e Q_v over its edges and XOR labels of P_v Q_v over its vertices. Every path label cancels twice, leaving exactly the original cycle label. Retain a GF(2) basis of cycle deltas, each with its actual augmented tuple, checked against rows and budgets. At most R independent deltas. No enumeration of all directed cycles or all feasible tuples.

Consequences:
(i) Complete affine hull of row indicators and of any explicitly supplied linear row observations via linear projection. Orthogonal complement gives all linear equalities on feasible tuples, with polynomial Gaussian elimination.
(ii) A single protected parity observation ell(z) can be queried exactly. If ell(z0) is desired, use z0. Otherwise a basis delta with ell(delta)=1 produces an actual witness; if none, the contrary parity is impossible. Multiple requested observations jointly are NOT guaranteed by their affine hull. Higher-degree feature spans and exact counts are not obtained.
(iii) A row never chosen, or always chosen, is detected exactly by the corresponding coordinate. Delete unsupported options or pin mandatory ones with unconditional certificates; recompute baseline and renew the prepass. Exact terminal already captures all linear consequences in one acquisition; any outer source deduction still requires its authenticated pullback and renewed cooperative closure.

This gives qualitative contradiction (cut or unsupported row), integer capacity (owner budgets), and algebraic feedback (actual residual cycle span) in one exact computation. No signed shortest-path assumption, in contrast with the signed-cycle caveat in M05.

## 5. Exceptional block terminal (PROVED, not executed)
For chosen per-owner scales, classify each block by the residual row criterion; let E_bad be the exceptional blocks. Enumerate only their row choices with product D_bad=product_{b in E_bad}|R_b|. Each conditional branch subtracts chosen full costs, discards those blocks, renews certified minima closure, and solves the good part by flow. Restricting available good rows and recomputing their minima preserves single-load form with the same scales: if all surviving rows charge the same owner, the residual costs become zero; otherwise their coordinatewise minimum residual remains zero. Negative capacity is an immediate contradiction. Stream branches; for exact global affine hull, merge actual lifted witness bases across successful branches relative to one global anchor. This is T<=D_bad poly(N), polynomial peak space, including acquisition and verification in the explicit row input. For rank-one bad blocks, D_bad<=2^k with k the number of bad blocks. Scales are selected by any paid rule (e.g. unit or first nonzero), and exceptions scanned; no claim of optimizing scales. This terminal does not assume that all multi-owner differences can be split into independent units; doing so loses row coupling. No implementation of the exceptional outer enumeration this run.
