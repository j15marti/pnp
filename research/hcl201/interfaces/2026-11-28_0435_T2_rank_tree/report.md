## Exact constructive lemma
Collapse signed equalities via parity union-find (contradiction if inconsistent); enumerate each B vertex's <=16 carrier assignments and deduplicate equivalent factors. For every carrier, connect consecutive occurrences in a deterministic chain. Introduce one GF2 syndrome coordinate per link, to which both endpoint copies contribute their local bit. Each factor row contributes its corresponding vector, with a retained row witness. Total XOR zero iff every occurrence of every carrier agrees. Each factor has a finite vector dictionary; choose anchor a_i and center its dictionary D_i by XOR a_i, target t=XOR_i a_i. Distinct original rows producing the same vector can be deduplicated with a single row witness because all external shared bits agree (private coordinates can be reconstructed from selected row). This gives exact decision equivalence and port witness lifting. A necessary early closure is exact row-unanimity propagation and affine span membership; no full rational projector or matching closure was performed.
For any leaf subset P, let U_P=span of the centered dictionaries in P, Q=complement, lambda(P)=dim U_P+dim U_Q-dim(U_P+U_Q). Let S_P be the actually attainable sums in P satisfying s+t in U_Q. All global solutions have their P sum in S_P. If nonempty S_P lies in an affine coset of U_P intersection U_Q; hence |S_P|<=2^lambda(P). For a tree node P=L disjoint-union R, S_P equals {x+y:x in S_L,y in S_R,x+y+t in U_Q}. Forward containment is immediate from actual sums. Conversely any compatible pair is actual, and for any actual P sum satisfying the outside condition, its component x satisfies x+t=(x+y+t)+y in U_Q+U_R, and similarly y; thus child pruning loses no qualifying parent sum. At root Q empty and YES iff t belongs to S_root. Save actual attained representative and child pointers, lift selected rows then check all original native ports and constraints. An empty *completed* node table proves no global solution, but capped/incomplete tables prove nothing.
The exact quotient join avoids enumerating incompatible pairs: reduce vectors by a fixed echelon basis of U_Q to canonical remainders rho. Because rho is linear with kernel U_Q, x+y+t in U_Q iff rho(x)=rho(y)+rho(t). Bucket the right table by rho(y), query each left key rho(x)+rho(t); enumerate only compatible pairs. At root this is an equality join. Can use deterministic balanced search trees or sorted lists for polynomial dictionary operations; JS Maps are experimental. Worst-case compatible pairs can still be 2^(2w), where w=max tree cut lambda. Given explicit dictionary encoding L and an acquired decomposition, time O(m 4^w poly(L)) and stored states/pointers O(m 2^w poly(L)); exact rank, quotient reduction and witness reconstruction included in polynomial factor. Native dictionary encoding L is polynomial in original N. A fixed c and w<=c log2(N+2) plus polynomial tree acquisition suffices for this module, not universally established. A complete tree has <=2m-1 nodes; two deterministic candidate splits per internal node, all failed candidates charged; ranking by max child cross-rank is a heuristic and can yield large global width. Inside and outside bases can be propagated: outside(left)=span(outside(parent),inside(right)), symmetrically. This removes repeated global complement scans. No theorem that either candidate family finds a bounded-width tree on all inputs.
Independent basis-owner check: select a global basis consisting of actual dictionary generators, tag each with owner. For cut P|Q, let I,J be disjoint owner-coordinate sets. U_P contains coordinate axes I, U_Q axes J, so dim U_P=|I|+rank(proj_J U_P) and dim U_Q=|J|+rank(proj_I U_Q); subtract full rank |I|+|J|.
