First apply cheap certified closure: check affine chart/pin consistency, empty local masks, interval target bounds, mandatory registered deductions; substitute/restart where appropriate. Then compile each quota sequentially. Replace -w*x with w*(1-x)-w for w>0, shifting target by +w and complementing that observed bit. All normalized weights nonnegative. Reject targets outside [0,sum weights]. Let n be maximum number of terms in one quota and L its binary sum length. Process bit columns j=0..L-1, one occurrence of x_l for every set bit of weight at that column. Start carry C_0=0. Within column accumulate q=C_j+sum_{l:bit_j(w_l)=1} x_l; at its end reject unless q mod 2 equals bit_j(T), then set C_(j+1)=floor(q/2). Finish with carry zero. Exactness follows by induction from sum of processed low-digit contributions minus target low digits = 2^(j+1) C_(j+1) on a surviving path; all remaining high contributions accounted for in subsequent columns. No modulus, numerical target or coefficient magnitude in the state domain. Carry at column boundaries <= n; within column <=2n. Process quotas consecutively, reset carry only after final check; multiple quotas therefore do NOT multiply carry domains, but repeated observations can increase algebraic width. Empty sums are handled directly. Optional deterministic monitor state K is charged in product, including simultaneously active monitors. Four-color masks can be processed consecutively with one pending bit, rejecting on a forbidden pair.

Define w_i=rank A_prefix + rank A_suffix - rank A, w=max_i w_i. Compute a full-row-rank dependency matrix P with ker P=im A (Gaussian elimination tracking row dependencies). Its columns P_i encode the centered observations x_i+c_i. At each prefix retain p=sum P_i(x_i+c_i), and discard if p not in span of remaining columns. ## B. Probe-stable exact closure (PROVED)
Appending a single affine parity observation and requiring a fixed RHS raises each previous cut width by at most ONE: only the suffix row rank and total rank can increase, each by at most one; the new final cut has width zero. Even a previously unobserved chart direction is handled by the updated rank factor. Count the zero and one fibers using this same exact terminal on the fixed ORIGINAL chart and unchanged guards (one probe at a time). If root count zero reject; otherwise zero fiber implies opposite value unconditionally forced in this context. An exact root count is the closure engine, not an uncharged prerequisite. For complete affine closure, start with a witnessed representative, keep the span of actual witness differences, query an annihilator basis one opposite parity at a time. A positive query returns a new actual witness outside current hull, enlarging it; at most d enlargements and O(d^2) queries. If all opposite fibers zero, the annihilator gives every unconditional affine identity. Restart registered closure after each deduction; counts on the original satisfying relation remain valid because a certified equation removes no accepted word. Can keep equations as a consequence archive rather than cumulatively append them to query stream; if additional *conditional* guards are imposed, recalculate width and keep them attached to the context. At stagnation no unguarded branching is needed in this terminal; a witness may be selected by exact accepted-path traceback, not by asserting conditional choices as facts. This is complete affine, not unrestricted nonlinear closure. Exact coordinate queries for protected selectors require their actual affine bit representation; nonlinear observations not registered as affine need a separately charged monitor. Query stability does not imply stability under arbitrarily many independent conditional guards (RT16).

## C. Two contrasting infinite families (PROVED)
I16 half-interval escape: n independent bits x_i, weights 2^i (0<=i<n), attainable range [0,2^n-1]. Modulus 2^(n+1) is safe for target zero and the half-interval coset representation requires 2^n packets by I16. In digit order each bit is observed once; w=0, carry zero at all column boundaries, direct target selection exact with a unique chart word for each target in range. Optional fixed XOR of two of the bits adds at most one parity observation and width <=1. This is a concrete escape without acquiring the dense subtotal distribution or a general rational function coefficient oracle. Large interval support is not itself compulsory work.

Counterexample to small width of ordinary digit-major scan: n independent chart bits, weights W_i=1+2^(i+1), 0<=i<n. After the low column every x_i has been observed and every x_i occurs again in a later column. Prefix and suffix span F2^n, so w=n, regardless of within-column ordering, although encoded input is O(n^2). Yet this specific family is easy: enumerate candidate Hamming weight c=0..n, require T-c nonnegative and even, decode (T-c)/2 as an n-bit word, check its population count c. At most n+1 candidates. Width is a representation/schedule parameter, not unrestricted complexity. No claim about all possible signed-digit recodings or other schedules. Arbitrary subset sum is already present if no masks/pins and selectors are independent; no universal polynomial-time bound claimed.
