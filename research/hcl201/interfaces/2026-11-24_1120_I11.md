## 1. Rank-one theorem (PROVED)
Let G be an explicitly indexed undirected perfect-matching graph, with independent edge tags g_e in GF2^q, and target t. Assume all remaining conditions are represented by this graph and this ONE global XOR equality (additional protected affine equations can be appended as tag coordinates, recertifying rank). A fixed guard is part of the authenticated graph construction. Connected components, or components after removing every edge that belongs to no perfect matching, are independent. Determine the latter by testing each edge uv via perfect matching of G-{u,v}; this is paid polynomial. Reject if no perfect matching. Decompose into pieces G_i and define S_i as actual XOR tags of their perfect matchings, a_i an attainable anchor, V_i=span(S_i+a_i), r_i=dim V_i. Exact affine hull is acquired by GD10's Lovasz GF2 matching span, projecting edge-indicator vectors; for bipartite graphs I09's alternating-cycle algorithm also applies. A rank-one direction has exactly two affine points, both realized since r_i=1; rank zero is a singleton. Thus when EVERY r_i<=1, the complete global attainable relation is exactly sum_i a_i + sum_i V_i. Gaussian elimination decides target membership with no dependency on GLOBAL rank. Keep two actual matching witnesses per rank-one piece, obtained by deterministic correct parity matching on a coordinate separating the two tags [1] and edge self-reduction. Solve the linear combination and take the union of the chosen witnesses. Exact global affine support, including forced linear observations, follows. Do not infer uniform multiplicities. This is deterministic polynomial decision, not general exact matching counting.

## 2. Exact planar local support acquisition and separator composition (PROVED)

Compress tag coordinates by a projection pi onto r_i coordinate positions injective on V_i, with affine decoding from a_i. The projected tag of each edge is an actual linear projection. Let sigma be the common sign of every perfect matching in the orientation, computed from one actual matching. For u in GF2^r_i, evaluate the integer Pfaffian of the oriented skew matrix with each edge multiplied by (-1)^(u.pi(g_e)). Then sigma Pf(A_u)=sum_M (-1)^(u.pi(g(M))). All local exact multiplicities are the inverse Walsh transform, C(z)=2^(-r_i) sum_u (-1)^(u.z) sigma Pf(A_u). ## 3. Sharp rank-two barrier, even AFTER affine period absorption (PROVED)
For any list s_1,...,s_k of tags, construct a graph with two required endpoints u,v and k internally disjoint length-three paths u-a_i-b_i-v, all vertices required. Exactly one path is active (both endpoint edges matched), and every other path uses its middle edge. Proof: when u chooses a_i, b_i must match v; no other path can then consume either endpoint. Conversely each choice is a perfect matching. Put s_i on edge u-a_i, zero elsewhere. This realizes precisely the list of tags with multiplicity, is simple planar bipartite, has 2+2k vertices and 3k edges, and maximum degree k for k>=2. At k=3 all components are identical eight-vertex nine-edge theta graphs, with exactly three matchings.

For a simple signed graph H, colors x_v in Q=GF2^2 and edge e=uv forbids difference s_e. Use two tag coordinates per edge. Vertex component lists the possible colors repeated on its incident edge coordinates; edge component lists its three permitted relative colors d_e != s_e on its own coordinates. Global XOR target zero imposes d_e=x_u+x_v. This is pointwise exact, including signed cases and optional restriction of vertex colors to {0,1,2}. All local affine ranks <=2. In the three-color unsigned case each nonisolated vertex factor and each edge factor has three distinct tags of affine rank exactly 2; after deleting isolates every component is an identical theta. NP-complete by graph 3-colorability [4]. Membership in NP by explicit matching witness.

Stronger: no palette or overlapping masks required, and no remaining affine vertex factors. Use all four colors at every vertex. Let beta=m-n+c be the cycle rank. The incidence/vertex-image H0={(x_u+x_v)_e} is the two-bit cut space. Each full vertex factor is an affine subspace, with its whole direction space as an exact translation period. Their sum H0 can be absorbed by quotient (I02/BA04 attributed period logic). Compute Q_c(d) as the list of XORs on fundamental cycles of an arbitrary spanning forest; there are beta such cycles, each with a unique chord. Kernel is EXACTLY H0: choose arbitrary root colors, integrate d on the forest, then each chord is consistent iff its cycle XOR is zero. Thus
    H has a legal signed four-coloring iff XOR_e Q_c(d_e)=0, with d_e != s_e.
For each edge e, the projected three-tag list is {Q_c(e tensor d): d in GF2^2 minus {s_e}}. If e is not a bridge, its fundamental-cycle incidence column is nonzero; hence map from the two-bit d is injective, and its local tag support is exactly a three-of-four affine plane with no nonzero translation period (a nonzero translation pairs all points, so cannot preserve an odd cardinality). If e is a bridge, its support collapses to singleton, harmless. Overall direction rank=2 beta, since the chord columns supply basis in each bit. For unsigned 4-color hardness start with a 3-color instance without isolated vertices (remove them, treating trivial inputs separately) and adjoin one universal vertex. Every edge of the new graph lies in a triangle, so it is bridgeless. Four-colorability equivalent to original three-colorability. Every remaining matching component is now a rank-two theta with exactly three tags and ZERO nonzero local periods. Target zero; no costs, quotas, palette, physical overlap, nonlinear external masks or high-degree matching vertices. All components planar. Graph and labels polynomial encoded size (dense O(m beta) bits). This proves NP-completeness even at local rank exactly two AFTER all full vertex-factor periods were absorbed; rank-one threshold sharp. Not an unrestricted lower bound. Contrast DR05: no public integer-cost channel is needed here.

Counts: each admitted difference tuple lifts to exactly 4^c source colorings (one independent root choice per source component including isolates). This is why the quotient experiment multiplies by 4^c; arbitrary affine period removal is NOT count-preserving without such a fiber proof. Witness lift by forest traversal checks every chord and signed exclusion. For BW05, take SAME signed source graph (including constructed universal vertex when used for hardness), use its exact duplicate wheel then strict E4/B4 adapter, and compose via manifest and source colors. Exact both-label transfer in that explicit source family; raw physical matching parameters and weights not transferred.
