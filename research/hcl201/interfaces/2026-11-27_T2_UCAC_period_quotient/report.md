## Exact theorem: joint attainable additive response period quotient
Hypotheses: independent blocks, explicit nonempty *joint attainable* sets R_i subset F2^h under one authenticated guard. Every chosen row has an exact private witness/lift, and the only inter-block obligation is additive XOR target t. Integer occupancy may not be replaced by parity; all local occupancy restrictions must be included in exact row sets or separately checked. No use of marginal relaxations or uncharged response acquisition.
Define K_i={k:R_i+k=R_i}. This is a subspace. For any anchor a_i in R_i, every candidate period k belongs to R_i+a_i, so all periods are discovered deterministically by checking each candidate against every row using exact lookup. Compute K=sum K_i by GE; R=sum R_i satisfies R+K=R. Let pi be quotient by K and d=dim span of union_i pi(R_i+a_i). Then target feasibility iff pi(t+sum a_i) lies in sum_i pi(R_i+a_i). If target outside this d-space reject by GE. Otherwise dynamic programming by reachable XOR sums needs <=2^d states per layer, retaining one predecessor per state. Given quotient witness r_i, target discrepancy lies in K; solve linear system to write it as sum k_i with k_i in K_i, and r_i+k_i remains an actual row. Restore local witness by its paid lift. All operations exact finite bits. Empty R_i immediate NO. Invertible basis changes preserve feasibility; no assumption of global independence when regions share nonadditive variables.
For explicit input length L, discovering periods costs poly(L) (O(sum |R_i|^2) row lookup operations on h-bit words, deterministic dictionary); rank, quotient maps and reconstruction polynomial. DP and witness predecessor storage bounded by 2^d poly(L); cumulative space charged as time times peak or explicit ledger. If L poly(original N), each row has paid witness lift and d<=c log2(N+2) with fixed c, this is a genuine deterministic P terminal. Not a proof those hypotheses are universal; acquiring exact joint sets and discovering a productive block system remain open.

## Exact obstruction: 3-choice syndrome composition is NP-complete
Reduction from graph 3-colorability (remove isolated vertices; Garey-Johnson-Stockmeyer 1976). h=2|E|, two coordinates per edge. A vertex block chooses color from {00,01,10}, replicating the chosen two-bit code into every incident edge slot and zero elsewhere. An edge block chooses any nonzero two-bit word at its edge slot, zero elsewhere. XOR target zero iff for every edge the endpoint colors differ: edge correction is their nonzero XOR. Each local block has precisely three distinct rows, hence no nonzero period (nonzero translation partitions an invariant set into 2-cycles). Differences of edge-block rows span both coordinates of every edge, so K=0 and d=h. Explicit size polynomial; membership in NP by selected row certificate. Thus a general deterministic polynomial consumer would decide 3-coloring, not an established lower bound. This is an abstract response language; no faithful native strict E/B interface embedding asserted. In particular, inability of this DP to finish is not evidence against direct graph solvers or other spines.
