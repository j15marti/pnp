## I25.1 Exact elementary-abelian chart gauge

For each owner whose live rows are paired by an explicitly verified fixed-point-free involution (here actual scope-word complement), let one bit denote flipping that owner; otherwise fix its flip bit to zero. A factor on scope I has stabilizer H_I ⊆ F2^I: test every local flip mask for invariance of the complete relation (for sparse forbidden tuples, invariance of the set suffices by bijectivity). This is a subgroup. The global structural gauge K is the intersection of inverse projections of these H_I and ineligible-owner equations. Obtain K by embedding local annihilator equations and Gaussian elimination. For fixed arity k, explicit acquisition costs polynomial in chart length; for arbitrary arity, 2^k is charged. This finds the entire specified local-factor stabilizer, not all semantic symmetries or arbitrary involutions.

Choose r=dim K free columns of the row-reduced constraint matrix; projection K to them is bijective. Give each row pair a canonical orientation bit. Fix orientation zero at all r free-column owners. Any solution admits exactly one K-translate with those orientations, since the required flip vector on those columns has a unique lift. Every nonzero gauge vector changes a row, so each orbit has size 2^r. Thus this is exact for decision and, on the complete invariant chart, counts can be recovered by multiplying by 2^r. It is NOT a forced-information deduction or preservation of every original solution. The restricted chart is a representative guard; archive its actual row map and prior lift. Any returned row transversal must still satisfy all authenticated source constraints. Repeat actual closure after the symmetry break. Even unpinned connected raw linear NAE with overlap on one bit admits only simultaneous complement; rank one does not imply small residual width.

## I25.3 Exact phase consumer and NP-complete selection

For a binary chart invariant under simultaneous complement and with two-row orbits at each owner, project each owner to its orbit index. For each fixed pair of orbit indices, the allowed phases are empty, all four pairs, or the two pairs with one specified XOR; this follows from invariance under simultaneous phase flip. Thus for a fixed orbit word, actual phase acquisition is polynomial Gaussian/union-find, with actual row reconstruction. A projected feasible orbit word is not enough: the conditional XOR graph must be consistent. In particular a forest of potentially forced edges admits every projected word (and hence provides exact projection), but arbitrary cycles need joint conditional syndrome checks.

Counterexample to universal polynomial joint acquisition from empty projected constraint graph: reduce any 3-CNF with three distinct variable literals per clause. One reference owner and each variable owner have one orbit (two phase rows). Each clause owner has three orbits, one per chosen literal, each with two phase rows. All reference–clause phase pairs require equality. For clause orbit selecting literal x_i or not x_i, the clause–variable pair imposes respectively p_i XOR p_clause=1 or 0 on that selected variable; all other pairs are free. Every pair of orbit indices has at least one compatible phase pair. All factors are invariant under simultaneous complement. For a selected orbit word, the only residual constraints are XOR equalities, and a lift exists iff its selected literals are simultaneously true with x_i=p_i XOR p_ref. Therefore a common transversal exists iff the source is SAT; given a source witness choose any true literal per clause and set phases accordingly. Explicit construction and actual lift polynomial; fixing the reference phase to zero does not change hardness. Membership in NP is immediate. This is an NP-completeness result for this conditional-phase selection language, not a lower bound on unrestricted algorithms, and not a proof that the same abstract chart has a native strict physical adapter. It shows exactly why automatic selection of a globally consistent collection of individually easy XOR consumers remains U-PROGRESS. In particular a small syndrome consumer, a gauge orbit count, and an empty projected binary graph do not suffice. Prior BD19 and DR19 give analogous forest/Horn consumer barriers; this strengthens the obstruction to pure binary conditional XOR.
