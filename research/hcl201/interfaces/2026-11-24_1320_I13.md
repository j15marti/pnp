## 2. Bundle theorem (PROVED)
Let H=F2^2. A component i has a private common shift s_i in H, relative colors fixed by an exterior selector z on a supplied affine chart G. Every original crossing exclusion edge in bundle e=ij forbids s_i+s_j=f_{e,l}(z), where f is an explicit affine two-bit word. For example, original colors a_u(z)+s_i and a_v(z)+s_j and exclusion sign t give f=a_u+a_v+t. Internal relations are translation invariant; all absolute pins or protected observations involving shifts must be retained, not discarded. In this theorem no such extra constraints exist; shift-invariant observations are retained in z. Parallel original edges grouped into a single quotient edge. For a fixed z define D_e(z)=H minus {f_{e,l}(z): all l}. This is exact, not affine hull approximation.

Assume bundle e has k>=1 offsets and choose the first f_0 as anchor. D_e empty iff all three nonzero relative offsets occur among f_l+f_0. Thus its exact rejection predicate is the OR over triples 1<=i<j<k'<k and the six permutations (a,b,c) of (01,10,11), of the affine events
  f_i+f_0=a, f_j+f_0=b, f_k'+f_0=c.
Each event has at most six independent scalar equations; at most 6 binom(k-1,3) events. Zero if k<=3, exactly six candidate events for k=4. Four-color translations depend on these relative offsets only. Enumerate event equations and Gaussian-check against G; remove impossible events, reject if an event covers G, force the complement if an event has relative codimension one. Restart closure after every certified deletion/pin, and at stagnation before any subsequent branching. Facts scoped to G, never merged across incompatible guards. This is a specific sound polynomial closure, NOT all semantic forced information or full cooperative source closure.

If the quotient bundle graph is a forest, all edge differences can be independently chosen: choose root shift 0 per tree then propagate each chosen d_e. Thus its rejected exterior words are exactly the UNION of all bundle events, even if observations overlap across bundles. For each fixed z the number of shift lifts equals 4^c product_e |D_e(z)| (c components, including isolates). This count does not include underlying internal matching or wheel choices. If z describes distinct source words with other multiplicities, those must be accounted separately.

## 4. Exponential flat-affine output barrier (PROVED)
Take one quotient cycle with n variable bundles plus a closing bundle (n>=2), exterior words z=(a_i,b_i) in F2^(2n), freely independent. Label colors 0,1,2,3 by their two-bit binary encodings. For variable bundle i choose forbidden offsets
  2, 3, 2 XOR (3*a_i), 2 XOR (3*b_i).
Each is affine, with at most one nonconstant input bit. The attainable difference set is {0,1} if (a_i,b_i)=00 and {0} otherwise. Closing bundle forbids 0,2,3, so D_close={1}. Therefore cycle compatibility holds iff at least one pair is 00. With k zero pairs its exact shift count is 4*2^(k-1) if k>0, else zero. Rejected exterior set R=(H minus {00})^n has size 3^n. This is a linear-size factored Boolean predicate (OR of n two-bit zero tests for acceptance).

Any nonempty affine subspace A contained in R projects onto each pair as an affine subset avoiding 00, of dimension <=1. The identity map into the product of these projections is injective, so dim A<=n and |A|<=2^n. If R is expressed as a union of affine events on the original exterior chart, every constituent must lie inside R. Hence at least ceil((3/2)^n) events are required, even with arbitrary overlaps. This refutes a uniform polynomial bound for flat affine-event lists after eliminating even one simple quotient cycle (input O(n) sparse forms; dense O(n^2) still exponential in n). It is NOT a lower bound for factored DAGs, affine events with auxiliary existential selectors, decision algorithms, or arbitrary source machines. This family has a particularly easy exact chart-level count 4^n-3^n accepted words. Retain factored representation rather than expand.

## 5. Global common-chart hardness even for forest gauges (PROVED)
Reduce strict 3SAT. For each clause on three distinct variables, create a fresh leaf of a quotient star with four exclusion offsets:
  0, 1*(1+ell_1(z)), 2*(1+ell_2(z)), 3*(1+ell_3(z)),
where ell_j is the Boolean literal truth bit and scalar operations in F2, color multiplication means either zero or the given color. If all literals false, the four offsets cover H; otherwise at least one is repeated zero and some color is absent. Thus the forest gauge instance has some exterior z with valid shifts iff original 3SAT is SAT. Reconstruction: retain z and choose a valid difference for each leaf, root zero. Each bundle has four affine offsets of rank at most one; quotient star treewidth one, every bad event simplifies to the original clause's rank-three falsifying subcube. Ordinary rank-zero/rank-one affine closure on the free chart stagnates on strict 3SAT including unsatisfiable cube. Membership NP by actual z and shifts. This is NP-completeness of the explicit shared affine-chart bundle model, not a proved strict physical E4/B4 compiler or P!=NP. BW07 and DA07 have analogous independent regions with correlated exterior observations; graph topology alone cannot bound GD13 joint observation rank. No assertion of universal portfolio stagnation.
