## Exact lemma A: symbolic complete-bucket response
If bucket C consists of clauses (x OR A_i) and (!x OR B_j), its existential projection is the conjunction of every (A_i OR B_j); tautologies may be omitted, duplicate and subsumed clauses removed. Proof: if any A_i and B_j both false, no x extends; otherwise choose the required side if any, arbitrary otherwise. Reverse reconstruction needs only the stored complete bucket and at most two tests. Thus a large boundary may have a small clause response without enumerating its 2^w words. This is classical Davis-Putnam/BVE, not a new SAT algorithm. With global explicit clause/literal bound polynomial in original N, complete pair testing and subsumption are polynomial per step, at most number of remaining variables many steps. Admission must include rejected work and cannot reset cap. Universal small symbolic response unproved. ## Exact lemma B: joint row-shadow descent
Let the explicitly retained tables T_i have total R rows, max arity k, v variables. Given an allowed row r of one table, temporarily impose its bits, and run sound local support propagation (filter rows compatible with current pins; empty support contradicts; a coordinate identical across surviving rows is forced). On the resulting filtered tables, enumerate every forbidden two-bit projection on surviving unpinned coordinates. Their clauses are logically necessary under the row guard. Construct the union implication graph and test 2-SAT via SCC. If a literal and its negation lie in one SCC, the guarded network is UNSAT. A conflict from either method excludes the guarded row unconditionally within the fixed parent chart. Delete only that actual row, restart unguarded chart closure, and retain row provenance. A SAT binary shadow is not a SAT certificate for the full table chart. Independent checker uses mutual reachability instead of SCC for each supplied deletion and final closure. Root gauge valid because every normalized balance table is complement invariant and the signed equalities are complement invariant; reversal of gauge yields a corresponding witness. Exact complete bucket replay reconstructs the residual and, for YES, a reverse lift by trying both pivot bits in removed buckets; full native SAT reconstruction not executed.

Proof of charged restricted bound: each accepted deletion strictly decreases integer R; at most R initial rows can be deleted. Each epoch examines at most R guards; each closure has at most v new pins, each scan reads O(R*k) row entries, binary-shadow construction O(R*k^2), SCC polynomial in v and emitted edges. For explicit tables with polynomial initial row registry, even all unsuccessful probes, certificate discovery, independent reachability replay, retained maps and serial cumulative memory are polynomial in original N. In abstract word model a loose bound O((R+1)^2 ((v+1)R(k+1)+R(k+1)^2+v+R(k+1)^2)) for SCC consumer, excluding dictionary/sorting/bit overhead, which can be bounded by a further fixed polynomial. Verification can use O(v) graph reachability traversals instead of SCC, still polynomial. Use exact integer IDs and exact Boolean arithmetic; no real precision or semantic oracle. Polynomial peak space and cumulative memory <= serial bit-time times space. This is a polynomial partial normalizer; it returns UNKNOWN when no row is deletable. It does not imply every valid source reaches a terminal or productive transformation. If future operations expand tables, they require a charged global reserve; this R cannot be restarted without proof.

## Obstruction C: infinite local-row shadow fixed points
For each toroidal square grid n>=5, put a binary variable on each undirected edge and a four-variable parity equation at every vertex, all right sides zero except one odd charge. Sum all equations over F2: every edge occurs twice, so 0=1. All local tables contain eight words. Under any single local row guard, only its four incident edges are fixed; every other vertex shares at most one such edge and has at least three free edge variables. Each of those parity relations has full one- and two-coordinate projections on free coordinates. Hence no unit or binary-shadow constraint on remaining coordinates, no contradiction, and no row is deletable. Even-charge control (all zero witness) has identical fixed point. This refutes universal completeness of the named portfolio even with complete row probing. It is NOT a native strict E/B claim (TABLE-CSP-v1 secondary controls, no adapter supplied) and GE immediately solves the entire family; no P!=NP consequence.
