## A. Finite-group interface theorem (PROVED)
For every finite explicit binary decomposition tree with extension-sufficient coarse keys (e.g. actual matching occupancy and syndrome), exact verified joins, additive binary-encoded integer transition costs in Z^k, exact root key and quota Q, choose any positive integer diagonal matrix M=diag(m_1,...,m_k). All moduli are encoded in binary; G=Z^k/MZ^k. A derivation chooses one transition per node. For counts assume distinct indexed derivations correspond bijectively to the objects counted, or separately verify multiplicity. Other guards must be key-determined, else augment and charge or decline.

Do mandatory authenticated source and coarse forced-information closure first; acquire exact coarse support/hull, empty root implies UNSAT. Then use MS19/S19 inside and outside payloads. For node v/key s let A be the actual set of inside cost vectors and B the actual set of outside cost vectors extending any inside realization at that key to the required root key (excluding quota). Exact key sufficiency gives all combinations A+B as actual root costs using the key. Compute their integer affine lattices a+Lambda_A, b+Lambda_B by union and independent addition; reverse recurrence uses the parent outside, sibling inside and actual transition cost. Empty context discarded. No exact cost enumeration, no independent marginal keys.

A quota-compatible residue r must satisfy
  r in (a+Lambda_A+MZ^k) intersect (Q-b+Lambda_B+MZ^k) modulo MZ^k.
Let U=Lambda_A+MZ^k, V=Lambda_B+MZ^k, J=U intersect V. These are full-rank integer lattices containing MZ^k. Solve the integer system a+Uu=Q-b+Vv (basis matrices in this notation). If inconsistent, no residue at this key. Otherwise obtain c and a basis of J by projecting the integer kernel of [U,-V]; use polynomial-bit HNF/SNF with multipliers. Then allowed residues are exactly the *relaxation* coset (c+J)/MZ^k with cardinality
  K_v(s) = [J:MZ^k] = |det M|/|det J|.
This cardinality is exact for the coset intersection, not for the attainable residue support. Both lattice discovery and capacity calculation are polynomial in the charged coarse representation and binary lengths, regardless of modulus value. If needed, explicit coset representatives can be produced with polynomial delay by SNF of the integral matrix J^{-1}M; enumerate its diagonal cyclic coordinates and apply inverse unimodular transform. The actual DP below needs only membership, not enumeration. For scalar m, d_A=gcd(m,g_A), d_B=gcd(m,g_B) where g denotes difference gcd (zero for singleton). The coset exists iff gcd(d_A,d_B) divides Q-b-a; its stride is lcm(d_A,d_B) and K=m/lcm(d_A,d_B). Compute via extended Euclid, no factorization oracle.

Bottom-up DP keeps only actual (coarse key, residue) entries. Generate actual leaf alternatives, combine actual compatible child entries and transition contributions modulo M, discard when outside the certified allowed coset. Carry exact positive derivation count, actual witness anchor, coordinate cost extrema, and exact GF2 observation affine hull. Union alternatives and independent addition over disjoint source-coordinate contributions give MS18 payload; min/max additive then extremize over alternatives. Costs and observation contributions may be signed/additive; parity projection commutes with addition. Induction: every retained entry has an actual derivation with that key/residue; every exact-target AND every modular-target root derivation survives all cuts, because its outside complement proves membership. At root accept only required key and residue Q mod M. Hence this is an EXACT solver for the modular relaxation. No negative cancellation, no spurious support from lattice points.
