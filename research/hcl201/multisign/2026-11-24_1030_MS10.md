## 2. Uniform fiberwise Hunter certificate (PROVED)
Let J be a group of rejection events to erase, and P the concatenation of P0 and ALL linear defining forms D_i for events i outside J (or any larger protected map). Fix A nonempty. K=ker G intersect ker P. Each fiber A_y=A cap {Px=y} for y in P(A) is a translate of K of the same size M=2^dim K.

For an event system E with nonempty A cap E, set r(E)=rank(D_E|K)=rank([G;P;D_E])-rank([G;P]). Intersection with ANY fiber is empty or has relative mass 2^-r(E). Thus define u(E)=2^-r(E) for nonempty A cap E and 0 otherwise. Define l(E)=u(E) iff P(A cap E)=P(A), else 0. Both projection surjectivity and emptiness are polynomial Gaussian checks: for consistent A cap E, projection is full iff
 rank([G;D_E;P])-rank([G;D_E]) = rank([G;P])-rank(G).
An affine subset of the same dimension as its enclosing affine image equals it. Hence l(E) is a uniform lower bound on relative event mass in every fiber. For pair events use D_i,D_j concatenated and both RHS. It is UNSOUND to subtract a pair upper bound or even its positive mass on one target from all targets.

For any tree T on J put U(T)=sum_i u(E_i)-sum_{ij in T} l(E_i cap E_j). On each fiber, define K_T(x)=sum_i 1[E_i](x)-sum_{ij in T}1[E_i cap E_j](x); it counts connected components of active vertices in the induced forest. In particular K_T>=1[union E_i]>=0. Consequently
 |A_y cap union_{i in J} E_i|/M <= E_{A_y} K_T <= U(T).
If U(T)<1, EVERY fiber has an actual point avoiding all J, irrespective of y, so
 P(A minus union_{i in J} E_i)=P(A).
This is a uniform projection identity, not just a lower coset at a baseline. It proves exact deletion of the group while retaining all other event maps and P0. If there are no events use trivial empty tree. Find the best tree for this specific upper bound by maximum spanning tree on the l(E_i cap E_j) weights; integer powers of 2 with O(n+log m) bit arithmetic suffice. Does not claim best possible certificate.

## 3. Deterministic guarded lift (PROVED)
For any supplied valid target y, define for affine subguard B of A_y:
 D(B)=|B|-sum_i |B cap E_i|+sum_{ij in T}|B cap E_i cap E_j|.
All counts are Gaussian, not #SAT queries. D(A_y)>=M(1-U)>0. D is additive under a split by any coordinate or linear form. Choose a positive-credit child deterministically, recompute local rank-one closure, and repeat. Closure removes only points violating an event, whose pointwise credit 1-K_T is nonpositive, so positivity survives. At singleton positive credit implies no event violated. Verify all original group rows and protected values. At most n coordinate pins; both candidate counts charged; exact polynomial bit time. Proof uses signed cancellation but never equates a signed sum of uncertain sign to an exact count of legal assignments.

Probe stability: if U<2^-d, any consistent independent rank-d affine probe INSIDE an original fiber has size M/2^d and expected K_T <=2^d U since K_T>=0; the same tree gives positive credit and actual lift. More generally use the actual relative rank <=d. For U<1/2, all consistent single-parity probes lift. For larger U no such blanket guarantee, recertify with the probe retained in P or run fixed-fiber exact/positive-credit test. Appending an original arc observable may split M10 classes: reaggregate and revalidate, not a free probe. Exact all-word P0 support does not imply exact full joint support of erased coordinates.

## 4. Layered contraction and paid discovery (PROVED)
Maintain G and active events. After closure try each singleton, whole active group and any explicitly encoded polynomial-size list of groups intersected with the active set. For a candidate J compute P as above, rank and tree bound. Accept only U<1, store original guard, event matrices, tree, P and offsets, delete J, re-run applicable unconditional closure. Each accepted group deletes at least one event. At most m rounds plus one stagnation scan; all candidate tests and failed work charged. At stagnation before any branching run closure, then pass the remaining actual problem to a paid terminal or return UNKNOWN, not UNSAT.

The exact reduced problem can use coordinates on the affine image of P0 and remaining event maps. Gaussian decoding of all retained maps preserves masks; a residual solution has an affine preimage. In reverse removal order, restore each group using the recorded guard and protected values of the current solution. The current point obeys the recorded affine guard (later closure only added constraints); the lift preserves every then-surviving event's defining map, hence all later-restored events. Induction yields an original feasible point with the same P0. This is existential decision/projection preservation, not original model count preservation. It is also valid with all variables retained in the implementation; dimension compression is optional, not necessary for correctness.

Strict representation progress is m_active decreasing. Dimension decrease of the joint observable image at one accepted step (before further closure) is rank([G;P;D_J])-rank([G;P]); compute it, do not assume positive. This is not automatically physical matching-defect reduction dim(L/L2). Only independently certified physical pullback of a new unconditional affine equation annihilating L2 and independent modulo prior equations gives that reduction. If all groups erased, the exact protected image is affine and target feasibility is Gaussian. Otherwise no general bound on residual solve. For explicitly polynomial event acquisition and candidate list, certification+layer storage+reconstruction costs poly(N), including failed tests, exact bit counts, source-lift checks when supplied. Same execution peak S=poly(N) and CM<=(T+1)S for the contraction/lift; charge residual solver separately and include its retained ancestry. Explicit rank arithmetic on matrices of size poly(N); no exponential fiber enumeration in proposed solver. No optimal group search asserted.

## 5. Strict improvement and falsifiers (PROVED)

Joint certificate deletes five events, dropping three observable directions; all 2^h protected words survive. Explicit family also has trivial cheap repair b=1; no complexity lower bound. Use distinct class tag coordinates and encoded joint affine constraints; do not identify all parallel arcs as the same tag. All class widths can come from two unit arcs. This is a thin-domain example, not a claim of arbitrary physical wheel transfer.
