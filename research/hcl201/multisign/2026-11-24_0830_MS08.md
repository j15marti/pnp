## 2. Fixed-guard model

Every arc e has a label g_e in G=product_j Z/d_j Z with binary-encoded d_j>=2 and explicit coordinates. Tag is phi(x)=sum_e x_e g_e, a group homomorphism. Negative increments use additive inverses. Target t is in G. This represents protected parity, odd/higher-prime modular observations, and their joint targets, only when authenticated as additive functions of the actual flow. In particular a nonlinear tag of a compressed multiplicity is not automatically additive. N counts full graph, integer/tag/guard/lift encodings. A membership query always retains every original target coordinate and fixed guard.

First find an integral feasible f by ordinary bounded flow, or reject. For each arc test x_e<=f_e-1 and x_e>=f_e+1. If both impossible the arc is fixed; subtract its flow and tag offsets (or freeze it). These are true unconditional consequences within the budget-only guard, so jointly inserting them changes no feasible flow. M08's undirected variable-arc cycle blocks give independent local circulation domains with balances A_B f_B. A fundamental integral cycle basis C_B uses the unique tree path for each chord, signed entries 0,+1,-1; it spans the integer kernel because the chord coordinates uniquely determine a circulation, and the remaining forest supports no nonzero circulation. Union fundamental cycles sharing edge IDs; every simple undirected cycle is contained in one resulting class (restriction of a GF(2) cycle to each class is even). Any integer circulation decomposes into signed simple cycles, hence splits into independent block circulations. No independence across unproved source regions is assumed. ## 3. Exact subgroup theorem
For a block, denote its integer cycle vectors c_i and cycle labels h_i=phi(c_i). Let H=<h_i> in G. Then every feasible local tag belongs to phi(f)+H. This is only a necessary condition in general. Let o_i be the additive order of h_i, computed as lcm_j(d_j/gcd(d_j,h_ij)); let L=lcm_i o_i be the exponent of H (L=1 for trivial H). Both depend on actual cycle labels, not on the order of the ambient group. The bit lengths of L and all o_i are bounded by sum log d_j.

**Theorem A (uniform rounding certificate).** If the block admits an integral f* with L-1<=f*_e<=u_e-(L-1) for all its arcs, its exact tag support equals phi(f*)+H, and every target in that coset admits a constructively recoverable bounded integral witness in polynomial bit time. No enumeration of G, H, residues or capacity units is required.

Proof: solve the unbounded group equation sum_i a_i h_i=t-phi(f*) by an integer column-lattice system with modulus-diagonal slack columns. Let d=sum_i a_i c_i. It is an integer circulation. The rational vector d/L is a circulation, and lies between the componentwise integer floors l=floor(d/L) and ceilings v=ceil(d/L). The bounded circulation system Az=0, l<=z<=v is integrally feasible because it contains d/L and signed incidence with integer bounds is totally unimodular; alternatively shift lower bounds and use ordinary integral max flow. Find such an integral z. Then delta=d-Lz is a circulation with |delta_e|<=L-1, including when d_e is negative. Also phi(Lz)=0 since phi(z) lies in H and L annihilates H. Therefore x=f*+delta is feasible and phi(x)=t. Conversely every feasible difference is an integer circulation, so lies in the tag coset. QED. A bounded-flow midpoint test discovers the certificate, not a guessed witness. For L=2 this recovers M08's interior parity theorem by a flow rounding proof. For L=1 any baseline works.

**Theorem B (heterogeneous cycle-order certificate).** For the same fundamental cycle basis define per-edge margins
 M_e = sum_i |c_i(e)| floor(o_i/2).
If an integral f* exists with M_e<=f*_e<=u_e-M_e, exact support is again phi(f*)+H. Proof: reduce each coefficient a_i modulo o_i to a centered integer representative of absolute value <=floor(o_i/2). This preserves the desired tag. The signed cycle perturbation is a circulation whose coordinate magnitudes are bounded by M_e, even on overlapping edges. It fits simultaneously. No independent-cycle assumption is used inside the block. QED. The test is one bounded-flow query. This certificate may be far cheaper than the uniform margin for independent small-order directions or sparse cycles; the rounding certificate may be cheaper on dense overlap. Try both; no claim to discover an optimal basis or midpoint free of charge.

The lattice system for membership/preimage is [h_1 ... h_beta diag(d_j)] a = t-phi(f*), over Z. Polynomial-bit Hermite/Smith normal form with transformations or a polynomial-bit integer linear-system algorithm gives membership and an actual coefficient solution. The code uses direct integer column Euclidean reduction, whose bit-growth bound is NOT established; the theorem's bound relies on the standard polynomial-bit backend. The full modulus product may have exponentially many elements relative to its bit length, but not exponentially many bits.

## 6. Sharp obstruction
Uniform margin L-1 cannot be replaced by L-2 for all blocks when L>=3. Take L parallel arcs s->t, capacity 2(L-2) each, demand L(L-2), baseline f_e=L-2. Label arc i by its own unit coordinate in (Z/L)^L. All coordinates variable and cycle subgroup is the kernel of coordinate sum mod L. Target t_e=L-1 for every e differs from baseline by the all-ones vector, which lies in H. Yet the only value in [0,2(L-2)] congruent to L-1 is L-1; those flows sum to L(L-1), too large. Thus actual target UNSAT while full lattice membership passes and margin L-2 exists. SAT neighbor at same demand: t=f+e_1-e_2, witnessed by that bounded integer vector. This refutes a weaker sufficient margin, not P=NP or a time lower bound. Thin-block exact flow/residue probes can solve these particular examples. For L=2, three parallel unit arcs with demand one and tag identity have target 111 in affine hull but no actual flow; M08 already records analogous nonaffine thin support.
