## 2. Exact binary-fiber model

For i=1,...,h choose a bit t_i. Conditional on it, independently choose y_i in a_i(t_i)+W_i(t_i), where W_i(t_i) is a binary linear subspace of common ambient E=GF(2)^d. Every nonempty fiber must be certified EXACT (not just its affine hull), with an actual local lift for requested tag. A missing fiber fixes t_i to the other value; two missing fibers imply UNSAT. The two offsets and bases are explicit. Additional linear selector equations B t=b allowed. Require sum_i y_i=c. Independence is an essential hypothesis; for matching it follows only with private interiors and correct gluing, or I01 incidence splitting and full occupancy target. No independent choice assumption for multiple parts of the same hub unless their synchronization is included.

Let W=sum over i,a of W_i(a), r=dim W. Compute a basis and extend it to E; choose linear projection pi:E->E/W and complementary W-coordinate projection P:E->W. Write a_i(t)=a_i(0)+t (a_i(0)+a_i(1)), an affine function because t is a bit. Set a(t)=sum a_i(t), V(t)=sum W_i(t_i), and v(t)=P(c+a(t)).
The quotient condition pi(a(t))=pi(c) and Bt=b together define a linear system Q on t. First execute this unconditional affine precheck (and incorporate certified fixed guards). If no solution, UNSAT. Recompute upon each certified restriction. This is a component of the mandatory cooperative closure; it does not implement all other global closure channels.

## 3. The normalized character theorem

For each character lambda in W* define Q_lambda by adjoining to Q the requirements that lambda annihilate W_i(t_i) for every i. Each local allowed set of t_i is empty, {0}, {1}, or {0,1}; therefore it is a contradiction, unit, or no restriction. Define

    D_lambda = sum_{t satisfies Q_lambda} (-1)^(lambda(v(t))),
    Z = sum_{lambda in W*} D_lambda.

Each D_lambda is computed exactly by Gaussian elimination. Its sign exponent is affine in t. Subtract the counts of two affine systems (exponent 0 and 1). Each consistent system with rank k on h variables has 2^(h-k) models, else 0. Equivalently test whether the sign functional is constant on the solution space. No enumeration of t is necessary.

**Theorem.** For every explicit input satisfying the model hypotheses,

    Z = sum_{t satisfies Q and v(t) in V(t)} 2^(r-dim V(t)) >= 0.

Thus Z>0 iff a globally compatible tuple exists.

Proof: exchange the two finite sums. For a fixed t satisfying Q, the surviving characters are precisely V(t)^perp. Their signed sum equals |V(t)^perp| if v(t) lies in V(t), otherwise zero: in the latter case pair each character with its translate by a character annihilating V(t) but nonzero on v(t). Rank-nullity gives |V(t)^perp|=2^(r-dim V(t)). This also follows by assigning a uniform distribution to every conditional affine fiber. Its normalized transform is the offset sign times the annihilator indicator; convolution produces a uniform distribution on the sum subspace. The normalization is essential when fiber dimensions differ: unnormalized counts would introduce guard-dependent multiplicative powers of two and no longer be evaluated by the same plain Gaussian count. Z is a nonnegative integer mass, not the number of original matching witnesses or source assignments. It counts each compatible selector with a dimension-dependent positive weight.

This is qualitative contradiction via exact signed cancellation: Z=0 proves that every quotient-compatible selector fails its active-span test. It does not require choosing or exploring these selectors. In particular all-rank-two local holes can remain as guarded cosets instead of being incorrectly filled or expanded.

## 5. Scaling family and limits

Let E have independent e_1,...,e_h,d0. Each factor has support {0,e_i,e_i+d0}, decomposed as t=0 singleton zero and t=1 coset e_i+span(d0). Every local affine hull has rank two, so unmodified rank<=1 peeling cannot even start with W=0. Global span rank h+1, while common guarded variation rank r=1. Target e_h+d0 is SAT, target d0 is UNSAT: all quotient coordinates must be zero in the latter, so every guard is inactive. Both targets pass the unconditional sum-of-hulls precheck, since d0 is in the global hull. Two characters decide each target. S01 peeling alone stagnates; other portfolio modules (including low-width DP) can solve this particular family, so no general lower bound or separation from the whole portfolio. Tests reached h=256, global rank257, two characters per decision; h<=64 also witness reconstructed.

Four-color extension: a hub may use a multi-bit selector. The same proof holds if (1) offset map is affine in the selector block and (2) for every character, the set of selector states whose fiber survives is affine or empty, with a polynomial-time way to produce its equations, including any empty-fiber availability constraint. For a two-bit block any subset of size 0,1,2,4 is affine or empty; a three-point subset is not. No universal four-color terminal follows. Explicit obstruction even with r=0 and arbitrary allowed two-bit states: graph 3-colorability reduces to affine constraints and pair exclusions. Give each vertex three color bits, XOR of its bits=1, and forbid each pair both 1 (ensures exactly one). For each edge forbid equal-color indicators both 1. Each pair exclusion can be represented by a separate two-bit selector with domain {00,01,10}; link copies by affine equalities, encode any desired affine equations. Every fiber singleton, offset affine. Feasibility is exactly 3-colorability. Thus a general four-state extension based solely on r would imply P=NP. This is a complexity barrier for this explicit generalized model, not an unrestricted separation or a claim of strict geometric wheel compilation. For actual tetrahedral hubs seek character-survival sets of affine size, or a bounded number of nonaffine guard blocks; enumerating at most three choices per nonaffine block per character is a conditional additional parameter, not a universal solution.
