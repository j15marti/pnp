## 3. Unconditional closure and exact scalar messages (PROVED)
First reject negative budgets or empty tables. For each owner i, compute L_i=sum_B min_a c_Bi(a) over incident blocks. If L_i>K_i reject. For each option a in B, if c_Bi(a)+L_i-min_{a'} c_Bi(a')>K_i for some i, remove it. Repeat to a fixed point, since every removal decreases a finite explicit row count. This is necessary even for cyclic H. Every rejected option has a checkable additive contradiction. The closure may be supplemented by all available certified unconditional source channels; rerun them after each new unconditional deduction and before branching. The executed primitive performs this row-minimum closure initially for each query; it does not execute a full cooperative source scheduler.

Assume H is a forest. Root each component at an owner (or an isolated block). Let Q=2^q. A block-to-parent-owner message M_B(h) is the minimum cost charged to that parent owner by a feasible row assignment in the block subtree, of protected XOR tag h, satisfying all internal owners' budgets. Empty entries are infinity. An owner-to-parent-block message A_i(h) is the minimum total cost charged to i by its descendant blocks, with XOR h and all other internal owner budgets respected. It can be truncated above K_i because parent costs are nonnegative.

At owner i, compute min-plus XOR convolution of all child block messages:
 A_i(h)=min_{xor_j h_j=h} sum_j M_j(h_j).
At block B, for each row a, an owner child i with tag h_i is possible precisely when
 A_i(h_i)+c_Bi(a)<=K_i.
Combine the child tag possibilities by Boolean XOR convolution (start with g_B(a)); for every reachable total tag h, take the minimum c_B,parent(a) over those rows. Store an attaining row and child tag choices. At a root owner, require A_i(h)<=K_i; at an isolated block take all row tags. Combine separate component feasible-tag sets by Boolean XOR convolution to reach the global requested h.

Proof by subtree induction: children are disjoint except for their parent incidence and the specified parity aggregation. For fixed tag, the only information needed outside an owner subtree is the single remaining budget inequality, monotone in child cost. Replacing a subtree choice by its minimum for that SAME tag weakly improves the sole boundary cost and preserves every other budget and tag. Conversely every finite message stores actual choices, and the inequalities and XOR combinations verify their compatibility. This gives both directions and constructive reconstruction. It is not a sum of independent owner minima for a mixed block: the full row cost vector is checked simultaneously. A missing root tag certifies qualitative contradiction by this recurrence, not by interpreting a signed zero as nonexistence.

For q=0 every incidence needs only one exact scalar, independent of the bit length or numerical magnitude of budgets. For q=1 only two minima are needed. Owner convolution cost O(Q^2) per child, and block convolution O(Q^2) per child per row. All integer additions/comparisons have polynomial bit length in the encoded input and table size. Explicit witness masks or backpointers add polynomial overhead. This is a min-plus/Boolean XOR dynamic program, not an approximate relaxation and not a counting algorithm. Do not promote a chosen minimum to a forced coefficient.

## 4. Cut-cost conditioning, with polynomial discovery (PROVED)
For general H, each incidence e=(B,i) has exact finite cost domain D_e={c_Bi(a): a in current table B}. Select a spanning forest F, cut the other incidences, and condition on their cost values z_e in D_e. For every cut incidence, filter the SAME local table to rows with c_Bi(a)=z_e and reduce the SAME owner's remaining budget by z_e exactly once. Retain the block's protected tag unchanged, and omit the cut incidence from the tree messages. Negative residual budget or empty table rejects. Conditional deductions remain guarded. Rerun available sound closure on guarded residuals before further branching; this is a polynomial overhead per visited prefix for explicit tables. The test implementation filters table rows and residual budget at each cut pin, runs initial row-minimum closure, and does not implement all guarded closure channels.

For any original solution, its chosen row determines one cut tuple, yielding a forest witness. Conversely forest witness rows satisfy all cut filters and original budgets after adding back the subtracted costs. Thus union over cut tuples is exact, preserves every possible protected tag, and reconstructs original coefficients. The number of cut tuples is bounded by
 C=product_{e notin F}|D_e|.
Choose F by Kruskal maximum spanning forest with edge weights log |D_e|. This minimizes C among spanning forests because total log product over all incidences is fixed; sorting integer domain sizes suffices, no floating point logs. Proof follows the standard spanning-tree exchange argument. This is NOT an optimal general decomposition or a claim that all H have small C. A fixed cut cost (domain size 1) adds zero exponential burden. Filtered domains can only shrink if old certificate retained. Complement tuple enumeration can stream with polynomial-size state; all cut-prefix work <= poly(M)*C, where M is exact table input size. No resource-magnitude DP.

Overall bit time <= C * 4^q * poly(M+N); bit peak space <= 2^q * poly(M+N) using sequential tuple processing, and CM <= T*S on the same execution. Here N includes graph, weights, tags and source certificates. With graph acquisition M<=2^ell poly(N), bounds can be written T<= C 2^(O(ell)+2q) poly(N), S<=2^(O(ell)+q) poly(N). The explicit-table terminal is polynomial for log C+q=O(log M); the graph terminal sufficient condition is ell+log C+q=O(log N) and polynomial certified source access/lifts. For forest C=1 and for constant q, no dependence on I05 mixed-edge p, graph cycle rank, owner count, or hub feedback beyond polynomial size, PROVIDED local tables are small. No claim about unrestricted universal rank bounds.
