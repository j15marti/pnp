## A. Canonical minimum retained core (PROVED)
Let G be a nonempty affine chart over F2 with equation rowspace H, and W the COMPLETE protected exterior rowspace. Legal means avoiding every explicitly supplied affine rejection E_i=[A_i x=b_i], i in owner set M. No omitted private quotas, nonaffine observations, selector/consumer identities or side constraints. Apply certified closure first: Gaussian consistency, discard impossible/duplicate rejection events, reject if a rejection equals the entire chart, and complement a rank-one rejection to obtain a forced equation. Restart after every deduction, retain the chart and repeat at stagnation before branching. This is scoped certified closure, not an oracle for all semantic consequences.

Write U_i for the image of row(A_i) in the vector-space quotient by H+W. For S subset M, put U_S=sum_{i in S} U_i and
  f(S)=|S|-dim U_S,  d=max_S f(S).
The rank set function is submodular: dim U_S+dim U_T >= dim U_(S union T)+dim U_(S intersect T), by the dimension formula and U_(S intersect T) subset U_S intersect U_T. Thus f is supermodular. Its maximizers are closed under intersection and union, and the unique inclusion-minimal maximizing set C is the intersection of all maximizers. Empty set gives d>=0.

For any T subset M\C, maximality gives
  dim((U_T+U_C)/U_C) >= |T|.
Rado's independent transversal criterion therefore yields one actual equation per exterior-to-core owner i in M\C, with projected rows independent modulo H+W+sum_{j in C} row(A_j). Select the complementary RHS of each chosen equation. For EVERY consistent assignment to the exterior and ALL core observation rows, the simultaneous complementary equations have a Gaussian lift, because their row images are independent in that quotient. If the core assignment avoids its retained events, the lift avoids all events. Conversely every legal original word satisfies the core. Thus exact existential support in the enlarged registered core/exterior observation space is preserved; in particular support projected onto W is preserved. This is a Boolean operation, not an exact count transformation, and the selected complementary values are repair choices, NOT unconditional forced information.

Minimality within the stated operation: suppose another retained set D admits an independent complementary representative for every owner outside D modulo H+W+U_D (notation U_D already in the quotient). For arbitrary S, let J=S\D. The independence certificate gives dim U_S >= dim U_(S intersect D)+|J|. Hence f(S)<=f(S intersect D). The global maximum is attained within D, so C subset D. Consequently the unique smallest retained set for this particular full-complement independent-pivot certificate is C. This does not assert smallest semantically equivalent core, smallest possible proof, or necessity of a transversal for repair.

If a shortest path ends at an independent row, augment by replacing each matched owner's old row on that path with the outgoing row, including the formerly unmatched owner. Proof: except the endpoint, replacement rows lie in the original selected span; relative to the displaced owner columns their coefficient matrix is triangular with nonzero diagonal because an edge from an earlier path owner to a later-than-next owner would be a shorter path.
