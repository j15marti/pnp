## 2. Dual gap certificate (PROVED)
For each block B choose exactly one row a from nonempty R_B, with full integer cost vector c_B(a), q-bit tag g_B(a), and actual local coefficient witness. Feasibility requires sum_B c_B(a_B) <= K componentwise and xor_B g_B(a_B)=t. All other couplings must be explicitly enforced; omitting them gives only a relaxation. Do not replace the rows with independently minimized coordinates. Define nonnegative integral slack s=K-sum c_B.

For any nonnegative rational price vector y, clear denominators to make y integral. Set m_B=min_a y^T c_B(a), Delta=y^T K-sum_B m_B. Every feasible tuple satisfies the exact nonnegative identity
  Delta = sum_B [y^T c_B(a_B)-m_B] + sum_i y_i s_i.
Consequences:
(a) Delta<0 certifies UNSAT.
(b) delete a row whenever its priced excess exceeds Delta.
(c) if y_i>Delta then s_i=0 (integer slack); more generally s_i<=floor(Delta/y_i) for y_i>0.
(d) Delta=0 makes every positive-price owner tight and every chosen row a priced minimizer.
All are valid even if budgets are individually loose. Certificate verification scans the exact row tables; no assignment enumeration. Prices e_i and the all-ones vector cost polynomial time and were executed. An optional exact rational LP discovery route: relax row indicators to nonnegative reals with block sums 1 and cost inequalities. Detect infeasibility by Farkas certificate, maximize each row coordinate (upper bound <1 deletes it), and bound each slack by min/max LP. If rounded integer endpoints coincide, fix that slack. Exact rational LP dual certificates and their discovery are polynomial in explicit encoding. This optional LP discovery was proved but not implemented; scaling fractional feasibility is checked directly by rational witnesses.

## 3. Joint budget and protected parity lattice (PROVED)
Let T be the subset of owners whose slack is certified to be fixed, s_i=s_i* (zero in the executed implementation). Project cost onto T and append the q integer representatives of tag bits to make v_B(a)=(c_B(a)|_T,g_B(a)) in Z^(|T|+q). For each block select a reference row a_B^0. Define
  b = ((K-s*)|_T,t) - sum_B v_B(a_B^0),
  L = span_Z{v_B(a)-v_B(a_B^0) : B,a} + span_Z{2 e_(|T|+j) : 1<=j<=q}.
Every feasible tuple has b in L, by adding its actual row differences and even tag corrections. Nonmembership certifies contradiction. Conversely membership is exactly feasibility of the RELAXATION allowing arbitrary signed integer coefficients for row differences, not necessarily a true tuple. Non-tight budgets omitted here cannot be inferred satisfied. Equivalently use all budget equations but allow unbounded signed integer slacks for unfixed owners. No factoring, modulus guessing or enumeration of the potentially enormous finite quotient is necessary.

For a specified row a in block B, replace R_B by {a}, form its own offset and remaining difference lattice, and apply the same membership test (retaining certified slack equalities). Nonmembership proves the row cannot occur, unconditional within the original guard scope. Batch deletions from a common snapshot are sound; renew price, lattice, affine, same-scope and other available certified closure after new deductions, before any branching. A pin is a conditional assertion until nonmembership proves its complement. If all rows disappear, reject. A genuine feasible row tuple survives every iteration by induction. Opposite exhaustive guards can discharge a common conclusion or prove global contradiction; a single guarded result cannot be promoted outside its guard.

## 5. Infinite odd-modulus controls (PROVED)
Let k>=1, h=2k+1. Six owners split into triples A and B. Each of h crossing blocks chooses either cost (1,1,1,0,0,0) or (0,0,0,1,1,1). In each triple add three internal blocks, each choosing one of that triple's three unit owners. Every row cost is 0 or 1 in each coordinate; the full row totals are constant per block. These are exact abstract row tables, not asserted strict physical four-valent PM gadgets. All-ones price gives Delta=0 for the following budgets, hence all six budgets tight.

UNSAT family: K_A=(k+1,k+1,k+2), K_B=(k+1,k+2,k+2). Total A demand 3k+4 but each actual tuple has A spend 3u+3, where u is integer number of crossing blocks choosing A. Thus contradiction mod 3. The row lattice detects it immediately; per-coordinate gcd of row differences is 1 due to internal choices. Fractional relaxation is feasible with u=k+1/3, remaining cross mass h-u=k+2/3 and internal blocks distributed equally over their remaining owner costs. Exact fractional witness checked. Raw GF(2) span of difference columns contains the target (checked; also construct u=k+1 with internal parity chosen to match each owner). No initial row-minimum/all-ones price deletion.

SAT forced-selector family: add selector block choosing A1 (tag 1) or B1 (tag 0); change K_B to (k+2,k+2,k+2). All-ones tightness retained. A demand 3k+4, A spend 3u+3+t, t=1 iff selector chooses A. Mod 3 requires t=1. SAT witness chooses k crossing A, k+1 crossing B, A-internal owners A2,A3,A3, B-internal B1,B2,B3, selector A1. The t=0 branch has a rational feasible LP witness and a feasible raw mod-2 difference-span relaxation; t=1 branch also LP feasible. Thus direct dual feasibility or raw GF(2) is insufficient to force this bit, whereas lattice nonmembership under t=0 does. With all variable incidences cost domain {0,1}, optimized log2 C before pruning is 5h+8 (connected positive-domain graph, 6h+20 edges, h+13 nodes); after selector pinned it is 5h+7 (positive graph loses two edges and one nonisolated block). The exact proof and independently checked graph counts show one factor-of-two cut reduction, NOT a bound that C becomes polynomial. Multiple independent copies can yield independent such deductions, but no all-channel stagnation claim. I06 single-load hypothesis fails on crossing blocks. Other algorithms might solve these structured examples cheaply, including simple modulo-3 reasoning.

Prime-power control: partition weights (2,4,4), budgets (6,4); all budgets tight, each weight fits either owner. Raw mod2 weighted equality is zero; pinning weight-2 to B would demand A sum 6 from multiples of 4. Exact lattice forces weight-2 to A; two feasible tuples verified.
Hostile incompleteness: partition weights (4,4,5,7), budgets (10,10); total tight, no subset sums to 10. All individual row pins admit LP and integer-lattice feasibility (remaining weights have gcd 1), initial price closure removes nothing, so closure returns UNKNOWN despite UNSAT. This falsifies completeness of this specific polynomial relaxation, even with all row pins. RT05 strong unit-cost NP-completeness in more general model remains intact. No claim against arbitrary methods.
