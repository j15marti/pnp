## Scoped theorem
Consider an exact affine carrier z in F_2^d, boundary bits x_i=c_i+a_i z over F_2 and a nonnegative integer occupancy E(z)=sum_i w_i x_i. Define gamma_a=sum_{i:a_i=a} w_i (-1)^c_i. Then 2E=sum_i w_i - sum_a gamma_a (-1)^(a z). Cancel equal directions exactly. Let W span the nonzero directions whose gamma_a is nonzero, together with all linear observations needed by other consumers. If rows B form a basis of W and t=rank B, E is a function of y=Bz alone. Each fiber has constant E, and every y in F_2^t lifts since B has full row rank. If the other regional response is also determined by y, or is acquired exactly conditional on y, joint compatibility can be tested with 2^t states. For exact E alone the active-direction span gives the minimal dimension of a linear quotient: translation invariance under h requires (-1)^(a h)=1 for each nonzero Fourier coefficient by independence of characters. Additional observations can increase this rank. Do not substitute E alone for arbitrary boundary support. Exactness, not heuristic approximation.

Generalization: fixed bipartite demand-resource graph, each demand needs one distinct resource, availability of resource r is a certified affine Boolean function of z. Group resources by identical demand-neighborhoods; capacity of group g is the sum of its availability bits. Build a capacitated integral flow graph from unit demands to these groups. For each z, full matching iff max flow equals number of demands: an original matching aggregates to flow; an integral flow lifts by choosing distinct available resources inside each group, because each group has identical neighborhoods. If costs or protected observations vary within the group, this argument does not preserve them. Apply character cancellation separately to each group capacity and include surviving directions from all groups plus necessary consumer observations in B. Every fiber has identical exact feasibility response, even if individual resource identities vary. Compute all group capacities and flow for each y; matching witness or mincut verifies the response. If t<=c log2 N and affine acquisition, region recognition, consumer response and reconstruction are polynomial in original N, then this restricted composition is uniform polynomial. All discovery, rank, arithmetic, flow, branching, verification, representation and reconstruction are charged. Integer counts have polynomial bit lengths for explicit inputs. General nonlinear response acquisition is not covered.

## Crucial falsifier / limit
Even one uniform fallback Hall bound on an affine chart includes MAX-CUT: for graph edges uv set b_uv=1 xor z_u xor z_v, q=|E|-K. Existence of a matching under these affine availabilities is equivalent to at least K cut edges. Thus general affine + uniform occupancy feasibility is NP-hard (with input given as explicit graph/affine forms, no extra consumer constraint needed). The active-direction rank on a connected graph is |V|-1; pair cancellation not guaranteed. This is a reduction for the scoped model, not P!=NP, and not evidence of a universal efficient quotient. A complementary structural cut, certified global bound or other track must handle arbitrary high surviving rank. Do not generalize finite constructed cancellation families.
