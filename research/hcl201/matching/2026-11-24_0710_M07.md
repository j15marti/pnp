## 2. Theorem A: exact implicit recognition (PROVED)

Write chi_a(z)=(-1)^(a dot z). Each coefficient bit is x_e=(1-(-1)^x0_e chi_{B_e}(z))/2. Therefore 2c_i has a sparse integer character expansion with at most 1+m_b terms, found by grouping equal masks. No 2^rank table.

For one owner set F=2(c_i(z)-c_i(0)); F(0)=0. If all coefficients vanish, cost is constant. Otherwise compute coefficients of F^2 by pairwise XOR convolution. Let A=[F]_0 and Q=[F^2]_0. Orthogonality of characters gives Q=sum_a [F]_a^2>0. The cost has exactly two values iff A!=0, d=Q/A is a nonzero even integer and F^2=dF coefficientwise.

Proof: if F takes only 0,d, F^2=dF, and constant coefficients force d=Q/A. Conversely polynomial identity forces F(z) in {0,d} for each z; nonconstant F and F(0)=0 ensure both attained. The even integer test follows from integer costs. If failed, classification is UNKNOWN as a solver, not UNSAT. Exact lower and upper values are c_i(0)+min(0,d/2) and c_i(0)+max(0,d/2); denote m_i and m_i+s_i. For nonconstant costs let L_i=(c_i-m_i)/s_i, a Boolean-valued sparse rational character polynomial. For constant costs put L_i=0.

At most one owner has positive residual load on every row iff [L_i L_j]_0=0 for every distinct i,j. Products are nonnegative indicators, and the constant coefficient is the uniform expectation over a finite full Boolean cube, hence zero iff no simultaneous load. Compute these pairwise inner products exactly with integer numerators. This is a deterministic recognition of the single-load property on the complete implicit affine domain, not testing sampled assignments. All positive scales for each owner must agree across blocks, as I06 requires. Failure returns UNKNOWN, not UNSAT.

Dummy category indicator L_* =1-sum_i L_i is Boolean under the proved mutual exclusion condition. Drop categories with zero constant coefficient. The remaining indicators form an exact partition of the entire local domain; category cost is m_b or m_b+s_i e_i. No explicit list of its potentially exponentially many rows is needed. Per-block Fourier construction uses at most O(h^2 (m_b+1)^2) coefficient operations by naive convolution (loose upper bound); masks have at most m_b bits, integer products/sums and a common denominator product of scales have polynomial bit length. This requires no min/max matching oracle, no PIT randomness, no Fourier expansion of an arbitrary guarded DAG. It uses the special sum-of-affine-bits source.

## 3. Theorem B: exact category acquisition under arbitrary local affine pins (PROVED)

For any nonempty affine slice Az=b, write L(z)=sum_a l_a chi_a(z) for one category. Its exact conditional mean is
  E[L|Az=b] = sum_(a in row(A)) l_a (-1)^(lambda dot b), where lambda^T A=a.
Proof: characters nonconstant on the kernel cancel by translation, and constant characters have the indicated sign. Choice of lambda is immaterial for a consistent system. Gaussian elimination computes all membership/sign tests. Inconsistent slice has no witness. Since L is Boolean and nonnegative, its mean is positive iff the slice contains an actual row of this category. Sequentially fix each free coordinate, testing positivity, to reconstruct a real coefficient row in polynomial time. Conditional constraints may include an arbitrary collection of affine pins, not just a single bit. This computes category availability; it does not mean a category itself is affine.

For a linear protected feature p dot x, test the two affine slices with values 0 and 1 to acquire exact local tag sets and lifts, irrespective of local cycle rank. Other affine guard conditions can be included in the same slice. General q tags can be acquired by 2^q slices but simultaneous global tag optimization is not solved by that alone.

## 4. Theorem C: exact global one-bit tagged flow (PROVED)

Each full flow lifts to independently chosen actual local rows. Hall cut is exact qualitative UNSAT when no full flow exists. For support closure, pin each surviving category and rerun flow; delete unsupported categories and renew other available certified closure. This never deletes a feasible row. For any given additive protected XOR bit, each category has a set of possible tag values {0}, {1}, or {0,1} from B.

If some flexible category (both bits possible) occurs in a full flow, detect it by a forced-category flow query. Retain this flow; varying only its local witness realizes either global XOR value. Otherwise every category that occurs in any full flow has a fixed tag; assign arbitrary tags to globally unreachable categories (no feasible flow uses them). Take any integral full flow f0. Label residual forward/reverse category arcs by their bit, all other arcs zero. If its tag is wrong, search for an odd-tag directed closed walk in the residual graph using the two-layer parity lift from each vertex. A closed walk decomposes into directed simple cycles, one of which has odd tag. Augment one unit around this cycle, obtaining a full integral flow with the opposite tag. Conversely if a full flow of opposite tag exists, its difference from f0 is an integral residual circulation; its cycle decomposition contains an odd-tag cycle. Thus failure of all parity-lift reachability queries is a certified contradiction. Actual local lifts come from B; no rounding or independent owner minima substituted for joint feasibility.

All graph sizes and forced-category queries are polynomial in N, no dependence exponential in local nullity, terminal count, owner feedback or number of attainable physical rows. The proof is a specialization of I06 residual-cycle reasoning but now with variable local tags, where selecting a representative before checking flexibility is unsound. One-bit result does NOT extend automatically to multiple simultaneous protected bits. In particular, choosing two parallel owner options per block under capacities (1,1) can give only two feasible global flows with tag supports {00,11}; each bit separately is achievable but joint 01 is not. This elementary counterexample applies to graphic parallel-edge blocks.
