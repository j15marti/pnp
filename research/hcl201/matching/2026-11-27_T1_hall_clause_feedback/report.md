## Exact new Hall explanation rule
Suppose two authenticated exact-one partitions A and B cover the same Boolean variable set E. Each candidate variable e is an edge between its A and B groups. For any S subset of A and T subset of B with |S|>|T|, every full feasible assignment selects at least one edge from S to B\T. Otherwise the |S| selected distinct edges occupy only |T| distinct B groups, impossible. Thus the positive clause OR_{e from S to B\T} e is an unconditional consequence in the authenticated chart. It is valid even if not RUP and even if the Hall witness was discovered under a guard. All affected candidate IDs must remain in the full original chart; use ALL crossing edges, not only live edges. Under unit closure in a guarded probe, if those edges are false, the clause conflicts. For an UNSAT root, a clause with zero crossing edges is empty. Certificate verification checks exact-one groups from clauses, partition coverage and cardinalities, then enumerates crossing edges. Polynomial in explicit chart size; no matching oracle needed to verify. Discovery uses maximum matching and alternating reachability; if full matching fails, the set of reachable left vertices from unmatched left vertices has fewer neighbors. Unconditional here refers only to the chart with its authenticated complement gauge and projection; no raw native bit claims.

## Fixed-width RUP pool theorem

If no new clause is learned and UP does not decide, return UNKNOWN. If all remaining clauses satisfied, a full satisfying assignment can be reconstructed; do not infer SAT merely from no conflict. Every learned clause is a logical consequence because UP is sound. The non-tautological distinct clauses of width <=2 number 1+2r+4 binom(r,2), including empty. At most this many productive rounds. Each round O(r^2) probes, and each naive UP probe O((r+1)(L+r^2+1)) literal inspections. Thus an implementation without experimental caps has a fixed polynomial aggregate bound O((r+1)^5(L+r^2+1)) plus polynomial bit/index and certificate operations. The explicit pool is a global monotone credit for this scoped rule, not a proof of universal successful progress. No recursive DPLL tree and no favorable-child assumption. Hall explanations of arbitrary width do NOT automatically fit this pool; to add them to the same polynomial theorem restrict accepted Hall clauses to a fixed width, or prove independent global budget for their count.
