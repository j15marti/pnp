## A. Planar cardinality support gadget (PROVED)
For integers 0<=k<=d, construct a directed rectangular grid with k rows and d columns. Arcs point right and down. One source at left of each row enters its first grid vertex; one sink below each column receives the last-row vertex (when k=0 no grid). Replace each grid vertex and each sink by an in/out vertex pair joined by an undirected edge. Every directed arc becomes an undirected edge from tail-out to head-in. Each source is an out-only vertex. Sink-out vertices are the d external ports. All edges have positive unit weight. For k=0 use d isolated pairs. All ports are on one face in prescribed left-to-right order. Split each grid node in a small disk: incoming north/west contiguous, outgoing east/south contiguous; attach the two groups to the two split vertices without crossings. Draw the source and sink extensions within the disk. Graph has 2kd+2d+k vertices, O(d(k+1)+k) edges. The exact implementation has 3kd+d edges when k>0, and d for k=0.

For a chosen removed port set S, any perfect matching of the remainder consists of internal pair edges and directed vertex-disjoint source-to-sink paths. Indeed every nontrivial used grid pair has exactly one incoming and one outgoing arc, every source starts a path, a deleted sink-out forces its sink-in to be matched by an incoming arc, and no directed cycle exists. Alternatively, imbalance of out/in cardinalities already implies |S|=k. Conversely, for any k selected columns c1<...<ck, route bottom source horizontally to c1 then down, the next source to c2 then down, and so on. The chosen columns strictly increase upward; paths do not intersect because lower horizontal paths end before each higher path's descent column. Match all unused pairs internally. Hence a matching exists iff |S|=k, with explicit source lift and arbitrary cyclic port order. This is a support gadget, not a parsimonious or symmetric numerical signature. E.g. d=4,k=2 counts in order 12,13,14,23,24,34 are 1,2,3,1,2,1. They satisfy 1*1-2*2+3*1=0, unlike all six counts equal to one. This agrees with the planar matchgate identity of Cai-Gorenstein; no negative cancellation needed in our gadget.
