## 2. Certified partial unateness (PROVED)

This is a semantic property of the EVENT, not of each row. For each event independently use M11's generator-support components (largest size c). For i in component K, enumerate only its remaining bits and compute four local weights: a,b at i=0 and a',b' at i=1. Obtain the exact support of the other components' total pair of weights by convolution of their bivariate histograms. Constant rows contribute offsets. For each outside weight pair with nonzero count, compare both actual bad indicators. All combinations are realized because components use disjoint free variables. This detects both directions exactly, even when individual XOR rows are nonmonotone. Repeating over coordinates costs 2^c poly(N) bit work, no joint graph. Prefix restrictions preserve every certified direction and irrelevance. Recognition is deterministic; a reported direction can be independently verified by rerunning the local histograms.

Call a pair compatible if at EVERY free coordinate either event is irrelevant or both have a common monotone direction. Private coordinates can be completely nonmonotone. Pair eligibility is separate: no common global orientation across all events is required.

## 3. Correlation lower bound and prefix stability (PROVED)
Let F_j(C)=|E_j intersect C|, with exact M11 marginal counts. For a compatible pair,
 L_ij(C)=F_i(C)F_j(C)/M <= |E_i intersect E_j intersect C|.
Proof by induction on free bits (Harris product-measure inequality with irrelevant coordinates). Split a bit, let a_b,b_b be the two events' conditional probabilities in child b. The inductive hypothesis gives E[ef]>= (a_0 b_0+a_1 b_1)/2. The difference from E[e]E[f] is (a_1-a_0)(b_1-b_0)/4>=0: shared coordinate has common direction, or one difference is zero. Base singleton exact. The same calculation proves L(C0)+L(C1)>=L(C) for every coordinate split. Thus these lower bounds are superadditive under refinement even though they are NOT exact intersection counts.

For incompatible pairs use the always-valid Frechet lower bound L=max(0,F_i+F_j-M). It too is superadditive by max(0,x)+max(0,y)>=max(0,x+y). Never use marginal product without eligibility. Counterexample: increasing events x=1 and y=1 on affine guard x XOR y=1 are disjoint despite positive marginals; reparameterization exposes opposing signs.

For any fixed forest T on event indices, pointwise sum of indicators minus tree-edge intersection indicators counts connected components of the induced active forest. This upper-bounds the union indicator. Therefore
 D(C)=M-sum F_i(C)+sum_(ij in T) L_ij(C) <= number of legal words in C.
If D>0, return SAT with a constructive lift. D<=0 means UNKNOWN unless another exact contradiction applies. Choose a maximum-weight spanning tree at root by Kruskal, with weights L_ij (common denominator M); can use any fixed forest, including empty. D(C0)+D(C1)>=D(C). Hence positive parent always has positive child. Keep the root tree and edge eligibility fixed during reconstruction, or reoptimize only if it increases the certified bound; no hidden optimal tree claim. Exact arithmetic: numerator M*D=M*(M-sum F)+sum compatible F_iF_j+sum incompatible M*max(0,F_i+F_j-M). No rounding or probabilistic error. At most n successful prefix choices, evaluate both children and verify actual class totals via M10 pair-fill, then restore indexed original arcs via saved signed capacity intervals.
