## 2. Exact parity-cover terminal (PROVED)
For J subset E write boundary partial J for its odd-degree vertex set, cost w(J), tag g(J)=xor_{e in J} g_e, g_e in GF(2)^q. Seek the minimum cost F(T,h) for every tag h, with infinity for empty fibers. Let Q=2^q, t=max_C |T intersect C| across connected components. Ordinary affine component-parity closure first: if any component contains an odd number of terminals reject. Other available certified source-level closure is required before calling this terminal; full cooperative closure was not executed.

Build the Q-sheet undirected parity cover on (v,a), edge (u,a)--(v,a+g_e) of cost w_e for each base edge and a. Let d(u,v,h) be shortest-walk distance from (u,0) to (v,h), or infinity. Nonnegative weights are essential. Compute by Dijkstra, retaining one witness walk per chosen distance. Projection of a walk as XOR of edge occurrences is an edge subset with boundary {u,v} (empty if u=v), tag h, and cost no larger than walk cost. This avoids requiring projected walks to be simple or mutually edge disjoint.

For each component pair the terminals with subset DP. For even subset A of terminals, choose canonical first u in A. Initialize P_empty(0)=0 and other tags infinity. Set
 P_A(h)=min_{v in A minus {u}, a in GF(2)^q} [d(u,v,a)+P_{A minus {u,v}}(h+a)].
Combine component tables by min-plus XOR convolution. This is the exact minimum of paired-walk representations for the prescribed boundary, not yet the full join.

Define C(a)=min_v d(v,v,a), including C(0)=0. Compute D as the q-fold min-plus XOR convolution of C starting with delta_0. Any tag realizable as XOR of closed-walk tags has a minimum-cost representation with at most q nonzero linearly independent tags: if a list is dependent, remove a nonempty sublist summing to zero, which cannot increase nonnegative cost. Zero tags can be discarded. Thus q convolutions suffice, padding with zero tags. The final table is F=P star D.

Proof of exactness: take any optimum tagged T-join J. Its edge set decomposes into edge-disjoint terminal-to-terminal trails pairing all terminals once, plus closed trails (obtain by adding dummy edges pairing terminals, decomposing into closed trails, then deleting dummy edges; alternatively direct trail extraction). Each piece is a valid walk in the cover with corresponding endpoint/tag. Replacing each by the cheapest walk cannot increase total cost. Removing dependent closed-walk tags cannot increase cost. Hence the table value is <= opt. Conversely every finite table entry corresponds to paired and closed walks. XOR their edge occurrences to obtain an actual subset with exactly boundary T and tag h; its cost is <= table entry, by nonnegativity. Hence opt <= table value. Both inequalities give equality, and XOR of recorded witnesses is optimal. Infinite entries are exact nonexistence. This is a constructive equivalence; no random identity test, no negative undirected walk, no assumed cycle enumeration.
For q=0, ordinary weighted matching is preferable for arbitrary t. For q=1, only zero or one nonzero-tag closed walk is needed. A single path is NOT enough even for two terminals, since a separate cycle can supply the needed tag. For q>=2, several independent closed-walk tags may be required. The terminal is valid for arbitrary q but exponential in q and t.

Costs: cover O(Qn) vertices, O(Qm) edges. At most n shortest-path runs (or terminal-only when q=0), O(n Q (m+n) log(Qn)) arithmetic/index operations for binary heap, polynomial weight bit lengths (simple cover paths have <=Qn-1 edges). DP at most sum_C 2^{t_C} Q states, O(sum_C 2^{t_C} t_C^2 Q^2) arithmetic operations; component and closed-walk convolutions O((#components+q)Q^2). Store witnesses by predecessor or explicit XOR masks (extra poly(N) per state); sequential total time <= 2^{t+2q} poly(N), peak bit space <=2^{t+q} poly(N), CM <= T*S for the same execution, not measured. For t+q=O(log N) all polynomial. No assertion that t or q is universally small. In particular t is an actual connected-component terminal count, not total rank, nullity, or an uncharged optimal decomposition.

## 4. Precise barrier/equivalence for unrestricted cheap-cycle basis discovery (PROVED)
Let J0 be min T-join, d=K-w(J0)>=0 and signed costs s_e=-w_e if e in J0, else +w_e. All simple cycles have nonnegative signed cost by optimality. For any probe p, a feasible J with opposite p-parity exists iff there is a simple cycle C with p dot C=1 and s(C)<=d. Indeed J+J0 is even, decomposes into edge-disjoint cycles, all signed costs nonnegative, and at least one has odd probe parity; conversely toggle C. Thus M04's span search is a minimum signed odd-cycle problem, not ordinary parity-cover Dijkstra on s.
Reverse: for any conservative signed graph with integer weights s (including unit +/-1), take J0=negative edges, T=boundary J0, w=abs(s), K=w(J0)+d. Every T-join differs from J0 by even subgraph of nonnegative total signed cost, so J0 is minimum. An exact affine basis answers whether there is a cycle of signed cost<=d and odd length by checking all-ones character on its directions. The reverse is a polynomial reduction, with nonnegative unit weights for signed +/-1 inputs.
For the unit-cost case the other direction also reduces to ordinary odd length with unit signed weights: each edge e with signed cost s_e in {-1,+1} and probe bit p_e is replaced by a private path of |B s_e+p_e| edges, all having sign sign(B s_e+p_e), where B=2(m+1). Path length parity equals p_e. Simple cycles in the subdivided graph correspond to base cycles; their signed cost is B s(C)+sum_C p_e, nonnegative by conservativeness. Threshold B d+m separates exactly s(C)<=d from s(C)>d (integers). Size O(m^2). Hence a decision oracle for conservative unit signed odd cycles suffices for a parity probe, and a witness can be found by greedy edge deletion preserving a yes answer (conservativeness inherited); an inclusion-minimal remaining graph is an odd cycle. Run at most m basis probes. This establishes polynomial-time Turing equivalence between general nonempty unit-budget coefficient-fiber affine extraction and the conservative unit signed shortest odd cycle decision problem (on its promised input class). For arbitrary nonnegative integer weights, use one zero-cost subdivision of probe-even edges to reduce arbitrary probe parity to ordinary odd length in a conservative weighted graph, without expanding binary weights. No claim of NP-hardness or resolution of this established open deterministic route. This reduction is separate from M04's NP-completeness with arbitrary nonuniform slot constraints.
Literature: Schlotter & Sebo, SIAM J Discrete Math 39 (2025) 484-504, DOI 10.1137/23M158156X, https://arxiv.org/abs/2211.12862 ; published abstract and preprint Proposition 6/Theorem 7 inspected. They distinguish NP-hard conservative shortest odd PATH (or cycle through a point) from unpinned shortest odd cycle and minimum odd T-join, give FPT for nonnegative weights parameterized by components in an efficiently computed min join. The present cover/pairing derivation uses terminal count and arbitrary q-bit observations, not a claim to improve their component-parameter theorem. El Maalouly et al., ESA 2025, https://arxiv.org/abs/2506.22619 , abstract and theorem setup inspected: bounded correct-parity matching (BCPM) is equivalent to conservative shortest odd cycle. No deterministic universal algorithm established by the sources examined. Do not conflate the NP-hard through-point variant with the unpinned one. The current project's universal proof remains open.
