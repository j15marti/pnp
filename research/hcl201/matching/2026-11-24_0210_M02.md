## 1. Translation absorption theorem
Let s(M)=XOR of edge labels in GF(2)^r, S={s(M):M perfect}, aff(S)=a+V computed by M01. Reject if no PM or target c outside a+V. A certified translation is a polynomial-time map tau on PMs with s(tau(M))=s(M)+d for every M. Such a map suffices; bijection not required for decision because applying twice to a syndrome returns it, though the automorphisms below are bijections. Let W=span(d_1,...,d_q). Then S+W=S and W<=V. Proof: for any M and linear combination of d_i, apply the corresponding maps successively. Every intermediate object is a genuine PM and each map applies regardless of previous choices. In particular, maps need not commute and their alternating cycles may overlap.

Let pi:GF(2)^r -> GF(2)^r/W be a linear quotient (reduced normal form). Then c in S iff pi(c) in pi(S). One direction trivial. For the other, an actual matching M with pi(s(M))=pi(c) has c+s(M) in W. Gaussian elimination expresses that difference as a combination of at most rank(W) basis translations. Apply the stored generators in sequence, verify all original constraints. No group enumeration and no assumption of independent physical components. This reduces effective syndrome rank by exactly rank(W); aff(pi(S))=pi(a)+pi(V). If rank(V)-rank(W)<=1, M01's deterministic correct-parity terminal is complete; rank zero needs ordinary PM. Larger residuals may use any exact terminal, including one-vertex conditional matching below, local decomposition or Fourier-Pfaffian randomized filtering (with its usual error). A nonempty projected affine hull alone is not a terminal.

Protected observations: if P is a linear map of the full observed labels, absorb W0=W intersect ker(P), not necessarily all W. Gaussian elimination tracks combinations of generators to form basis of W0, and each composite changes no protected coordinate in its FINAL matching. Intermediate states need not preserve P; if a local algorithm requires intermediate protected feasibility, this construction cannot assert that. For fixed occupancy use I01 dummy-completed graphs with occupancy labels explicitly included, or restrict graph maps to fix protected boundary vertices. If protected information is not encoded in labels, no preservation claim. GD02's entire nonlinear feature span is not recovered from a quotient witness alone; separate exact feature extraction required.

## 2. Deterministic discovery: automorphism discrepancy and twins
Given an explicit vertex permutation sigma, verify it maps graph edges bijectively. Define h_e=g_{sigma(e)}+g_e. The exact discrepancy support is {XOR_{e in M} h_e:M perfect}. M01 affine extraction determines whether it is a singleton, including all discrepancy bits simultaneously. If singleton {d}, sigma is a certified translation. Equivalently, one can first compute a PM incidence affine basis via the finite-field matching-span theorem, then multiply its differences by each candidate discrepancy matrix and test all zero. Independent vectors selected from actual certified generators permit lift without storing an exponential group. No general automorphism enumeration or GI oracle assumed; supplied polynomial-size list charged. If optimization with integer costs is desired, require cost preservation separately (edge-weight-preserving automorphism is sufficient); translation theorem is for feasibility, not general optimum.

A particularly simple fully polynomial discovery algorithm enumerates all pairs of nonadjacent vertices u,v with identical neighborhoods. Their transposition is a graph automorphism. For each distinct pair a,b of common neighbors, test ordinary PM on G-{u,v,a,b}. If feasible then u-a,v-b is extendible, and the discrepancy for either partner orientation is
    delta(a,b)=g_ua+g_va+g_ub+g_vb.
Every PM uses exactly one such pair. Hence constant discrepancy across all extendible pairs is necessary and sufficient for a translation. At most O(n^4) ordinary PM tests over all twins; no Lovasz span implementation required for this certificate. Each swap is a four-edge alternating cycle relative to the current matching, not a fixed cycle at a single baseline. For adjacent twins one must additionally check a PM using uv (discrepancy 0); this run implements nonadjacent bipartite twins only. Edge deletion closure can expose new twins. Re-run exact affine closure after each accepted independent translation (or verified batch, testing each prefix through its exact linear projection), after structural deductions and before any conditional terminal. Never combine branch-only certificates as unconditional ones.

## 3. Weighted tight-cut fiber theorem (extension)
For a supplied odd shore X of a graph with PM, assign edge cost 1 on delta(X) and zero elsewhere. Compute min and max over ordinary perfect matchings. If both equal 1, every PM crosses by exactly one edge; this is an exact polynomial weighted certificate of tightness (for odd X the max alone suffices). For each allowed crossing edge e=uv with u in X, condition on e and compute the internal support S_e of PMs of G[X-{u}], with observations including any protected local information. The outside factor is the PM support of G[V-X-{v}]. The complete support is the union over e of g_e+S_e+outside_e. Do not merge different e without their guards.

If for each allowed e a subspace W_e is certified to act by exact witness-liftable translations within S_e, then W_X=intersection_e W_e is an unconditional translation space of the full graph. Given current M identify its actual e, keep crossing edge and exterior unchanged, replace only its interior matching using the fiber lift for w in W_X. This proves preservation of boundary edge identity and of any additional protected observation included in the kernel. If each S_e is certified affine (e.g. M01 rank<=1 or fully absorbed with reconstruction), choose W_e=direction space of S_e. Discover W_X by Gaussian intersections, not enumerating all crossing combinations. Even overlapping tight shores may contribute globally valid translations; compose their maps successively, re-identifying actual crossing edge each time. ## 4. Connected family and rank-two hole
Replace each left vertex i of a connected bipartite matching-covered graph by two left clones c0,c1 with identical external neighbors, and a private right vertex a joined only to both clones. External tags agree between clones; internal tags 0,d_i. Every PM uses exactly one internal edge and one external edge per triple. Swapping clones toggles d_i on EVERY matching and is certified from local structure alone. Contract to the original base vertex with external tags as given: its support plus span(d_i) is exactly expanded support (choose internal clone independently), with explicit lift. Each base allowed edge lifts and each internal choice occurs; expanded graph stays connected and matching covered, hence M01's disconnected allowed-component peeling alone cannot absorb it.

Base graph for scaling: n left and n right vertices, edges i-i and i-(i+1 mod n), plus 0-2. Only edge 0-1 carries 01, only edge 0-2 carries 10. All edges allowed (two cycle PMs and the additional chord PM); connected. Every PM uses exactly one edge incident to vertex 0, so support exactly {00,01,10}, aff rank 2, target 11 impossible despite every scalar parity being feasible. This is also a counterexample to absorbing the span of two possible but mutually exclusive alternating cycles from a common baseline. Each may be realizable individually, not independently from every current matching.

Attach private triples with independent d_i=e_(i+2). Global support is {00,01,10}+span(d_i), rank n+2. Quotient removes n directions and leaves rank 2. All nonzero residual tags lie on edges incident to one vertex; enumerate that vertex's possible partners, check matching on remainder, compare tag. This deterministic terminal works for arbitrary rank when all residual nonzero tags lie in one star, since exactly one such edge is chosen. For general graph with an explicitly verified cover of k vertices of all nonzero tags, enumerate their incident matching edges consistently (including pairs internal to cover) in n^O(k) time, ordinary PM on remainder. This is XP, not FPT/log-k polynomial. No general small cover claim.
