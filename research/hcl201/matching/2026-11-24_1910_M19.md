## A. Exact nonnegative defect theorem (PROVED)
Input any finite loopless graph or multigraph with distinct edge IDs, n vertices, m edges, edge tags in F2^q, signed binary integer weight vectors h_e in Z^k, target t and Q, and optional actual edge pins. Given a verified binary edge-partition tree, let v be M18's joint occupancy/tag key; maintain actual partial matching occupancy disjointness and the M18 affine coset filter at every cut. The at-most-2^w_I coarse keys per node do NOT include any integer quotas in this first pass. Use exact ordinary untagged matching/affine closure first (Lovasz matching-span theorem transfer as in M13/M18), or charge the actual width of the untagged version of the tree; projection need not preserve width. Compute untagged hull/forced pins; then compute exact tag-conditioned coarse support, count, actual representative and affine hull by M18. These are necessary facts for the exact-quota problem. Empty root at either stage certifies UNSAT. Archive closure identities with the declared guard; applying any already-implied fact does not change its respective support or hull. Do not assume affine hull equals support.

For every nonempty coarse key v of node I, compute each coordinate minimum l_Ij(v) and maximum u_Ij(v) of actual partial matching cost separately. Leaves use actual present/absent options. For a feasible join of child keys x,y (occupancies disjoint, parent key v=x XOR y accepted), minimum candidate is l_Lj(x)+l_Rj(y), maximum candidate u_Lj(x)+u_Rj(y). Min/max across all such joins. Key sufficiency ensures every pair of child configurations combines, so these extrema are exact; distinct coordinates need not share a witness. All arithmetic is on O(input bits+log m) bit integers. At root with v*=all-ones occupancy concatenated with t, reject Q_j outside [l_root,j,u_root,j]. Choose sign s_j=+1 if Q_j-l_root,j <= u_root,j-Q_j, and -1 otherwise. Orient cost c_ej=s_j h_ej, anchor a_Ij(v)=l_Ij(v) when +1, -u_Ij(v) otherwise. Root budget d_j=s_j Q_j-a_root,j(v*)>=0 is the distance to the nearer exact extremum. Define B=prod_j(1+d_j).

For a partial matching M represented by v at I, define residual r_Ij(M)=sum_(e in M)c_ej-a_Ij(v)>=0. For compatible child keys define transition defect
  delta_j(x,y;v)=a_Lj(x)+a_Rj(y)-a_Ij(v)>=0.
Proof: the oriented coordinate minima in each child are attained, and those two minimizers are compatible because actual occupancy, tag and guards are fully determined by their coarse keys. Their joint cost is an eligible candidate for the parent minimum. Different j may use different minimizers; no simultaneous attainment is inferred. At a leaf define r as the actual oriented cost less its anchor. At a join,
  r_I = r_L+r_R+delta(x,y;v)
componentwise, by cancellation of anchors. Thus every component of a child's residual is at most the parent's. The residual at root telescopes to the exact oriented total less the root anchor.

Second pass retain coarse key plus residual vector in [0,d_1] x ... x [0,d_k]. Enumerate leaf options and compatible child pairs, compute residual by this recurrence, discard if any exceeds d_j. All globally legal matchings survive by nonnegative telescoping. Conversely every root object at residual d is an actual perfect matching with exact original tags, pins and Q. No other root key is accepted. Multiple distinct configurations at a key have identical extension behavior, because actual occupancy, tag and full cost are recoverable from the key. No independent marginal approximation. Can apply extra already-certified forced pins from the tag-only hull during this pass while keeping the previous anchors: that only removes feasible choices, and the precomputed nonnegative defects remain valid. No branching required. At root, carry M18's positive count, real edge-ID anchor and complete GF2 difference basis per residual key, using Cartesian product and disjoint union operations. This computes exact count, actual witness and complete target-conditioned affine hull in one residual pass. Verify witness against original graph, tags, weights and pins. Archive final forced identities (complete annihilator), including coordinate pins, before any reconstruction selection; no additional branch is needed. Conditional outputs remain guard-relative. All closure archives are fixed points on their actual supports; no free rechart with cumulative guards. Only edge-level closure is claimed absent a verified source decoder.

## B. Consequences and resource bounds
Let N be encoded input including tree, w=max dim(U_I intersect U_out) on the tagged columns. Coarse pass T<=4^w poly(N), S<=2^w poly(N); k extrema all computed together with polynomial overhead, even if k grows with N. Residual table at most 2^w B keys per node. Pair joins cost at most 4^w B^2 poly(N); space <=2^w B poly(N) even retaining all nodes, exact hull bases, anchors and guards. Counts <=2^m, weights and differences polynomial bit length, use deterministic ordered tables rather than rely on hash lookup guarantees. Charge input validation, all rank bases, extrema and their verification via recurrence, untagged closure, retained tables, unsuccessful joins, bit arithmetic, source-map and graph witness verification, guard archive, reconstruction and sharing. Explicit attempted-pair DAG <=4^w B^2 poly(N); verifier reruns recurrence rather than trusts local extrema. CM <=(T+1)S on same execution, not measured. Add actual untagged acquisition cost (ordinary matching span polynomial by prior theorem transfer, or actual DP width w0 as implemented) and supplied-tree discovery/verification; no optimizer or physical compiler supplied. With w=O(log N), B=poly(N) this is a uniform deterministic polynomial terminal on its declared inputs. No bound on numerical magnitude of weights or quotas; k may grow. In particular B<=2^(sum d_j), so sum d_j=O(log N) suffices. If every target coordinate is an extremum, B=1 even with polynomially many arbitrary binary quota rows. At B=1 this is exact intersection of optimal faces, not a claim that every coordinatewise extremal target is jointly attainable.
Example K4 three matching cost vectors (0,1),(1,0),(2,2): (0,0) has d=(0,0) but is UNSAT. The second pass enforces simultaneous zero defects, rejects. Neighbor (0,1) SAT. This explicit counterexample to separate optimality was executed.

Optional symbolic extensions (not executed): (i) any supplied integer linear transform of the quota vector with full column rank preserves exact equality, so repeat the theorem in that transformed chart, charging transformation and actual B; no free favorable basis discovery. (ii) For each coordinate compute gcd of all nonzero leaf residuals and all transition defects (coarse transitions enumerated in the first pass). Then every residual is a multiple of that gcd; nondivisible root budget proves UNSAT, else divide to reduce B. All-zero defect coordinate requires zero budget and is dropped. This is safe even if some coarse states never extend globally (may weaken gcd). (iii) With I18 cardinality-certified additive gluing, can apply the same anchor recurrence to arbitrary edge subsets with occupancy parity and cardinality as a coarse coordinate, but state-dependent shift means I18's fast Walsh convolution cannot be invoked unchanged; direct joins suffice. No speedup claim for Walsh integration.
