## 2. Target-aware residue proximity (PROVED)
Set H=4m^2 max(1,Delta), C=(4kH+1)^k (C=1 for k=0), R=2Q(C+2m). For EVERY residue vector p mod Q attained by X, there exists a w-optimal integer x in that residue class with ||x-a||_infty<R. The same anchor and radius work for all residues (not all objectives). Proof:

Choose residue-optimal x minimizing ||x-a||_1, possible by boundedness. The real vector d=x-a is in ker B AND ker D. Lift d to the signed double-cover network as in M13, assigning d_j to both complementary arcs, reversing directions when negative; zero columns can use independent coordinate directions. The nonnegative circulation decomposes by repeated simple-cycle extraction into at most 2m terms, one exhausted arc per step. Projection (use half the sum of the two arc coordinates) gives d=sum_i lambda_i g_i, lambda_i>=0, integer Bg_i=0, ||g_i||_infty<=2; g_i conformal to d. Factor 1/2 absorbed in lambda_i. Zero columns contribute e_j times sign, counted within 2m. This holds for rational a, not just half-integral.

Write lambda_i/Q=n_i+theta_i with n_i nonnegative integers and 0<=theta_i<1. Consider the multiset of n_i copies of v_i=Dg_i in Z^k. Each has infinity norm <=2m Delta. Their total S equals -sum_i theta_i v_i by Dd=0. Hence ||S||_infty<=H. If a nonempty submultiset sums to zero, let h=Q sum g_i over it. Then Bh=Dh=0, h is nonzero (conformal nonzero directions cannot cancel), integer and 0<=|h_j|<=|d_j| with correct sign. Both a+h and x-h satisfy all real bounds and equations; x-h is integral and has the same residue as x. LP optimality implies w*h>=0. Therefore x-h either improves residue optimum or ties it at strictly smaller l1 distance, contradiction. The multiset is zero-sum-free.

For k>=1 append the single balancing vector -S, of norm <=H. Apply Steinitz's rearrangement lemma in infinity norm: zero-sum vectors of norm <=H in R^k have an ordering with partial sums bounded by kH. Cyclically rotate to put balancing vector last; every partial sum now lies in [-2kH,2kH]^k. Before that final vector all partial sums are integers; a repetition would be a nonempty zero-sum submultiset of actual vectors. Thus L=sum n_i obeys L+1<=C. For k=0 every actual vector already zero so L=0. Consequently ||d||_infty <=2 sum lambda_i < 2Q(C+2m). Q=2 preserves every parity fiber and its optimum. No need to construct or enumerate the potentially enormous multiset; Steinitz is an existential proximity proof, not an algorithm step. Scope: fixed k and polynomially bounded NUMERICAL Delta and Q imply polynomial radius; arbitrary binary-large Delta or unbounded k does not.

Clip l'_j=max(l_j,floor(a_j)-R), u'_j=min(u_j,ceil(a_j)+R). All side rows remain; every attainable residue and its optimal w is preserved. Width <=2R+1. The clip is not an implied bound on all integer solutions and must never be exported as unconditional integer information. If a coordinate pin or objective is changed, reanchor to keep the guarantee.

## 3. Fixed number of exact quotas reduces to ordinary Exact Matching (PROVED)
For fixed k and Delta<=poly(N), Q=1 suffices to preserve feasibility; Q=2 also preserves all parity support. Split x_j=l'_j+sum_h y_jh into independent binary switches, U=sum(u'-l')=O(mR). Keep each side coefficient on every switch. S12 compiles B to a graph of O(U) vertices and O(U^2) edges (omit fixed and zero switches only when irrelevant; use independent 4-cycle for relevant zero columns). S13 linear decoder gives each matching's quota word as known offset plus sum of integer vectors on selected edges. For each negative first port, subtract its contribution when active and add the coefficient to offset. A positive port contributes only when matched to a row slot; zero-column 4-cycle has one designated edge. Retain source index map and verify decoder.

Bound each coordinate of the difference between a matching's quota and target by V (polynomial): use the shifted target and U*Delta; reject impossible target outside range, or use the fact a satisfies D exactly to bound shifted target. Choose base A=2V+1. Encode vector v by sum_{i=0}^{k-1} v_i A^i. Equality to encoded target implies every difference coordinate zero, by repeated reduction mod A since |difference|<A. Thus all exact rows become a single scalar exact matching cost, with edge weights bounded by poly(N) for fixed k and Delta<=poly(N). No loss of correlations. Offset must be included. Shift all edge weights by C0>=max absolute weight to make nonnegative, adjusting target by C0*|vertices|/2. For each edge of shifted weight c>=0, replace it by an odd path of length 2L+1 with private internal vertices, L+1>=c. The selected path uses all L+1 odd-position edges; color c of them red; unselected uses L even-position edges, all blue. No other local saturation pattern. A perfect matching selects an edge iff both endpoints are matched into that path. This is a polynomial-size red/blue Exact Matching (EM) instance. Negative target or target larger than total matching size is immediate rejection. Mapping and reverse lift deterministic. This is a many-one reduction, not a deterministic solution of general EM. Reverse EM embeds as vertex quota B and one 0/1 red side row D, as S13. Hence for any fixed k>=1 with unit-or-polynomial numerical side coefficients the decision class with at most k rows is polynomial-time equivalent to general EM, even with binary capacities. Unweighted q=0,k=0 stays ordinary matching.

For q fixed protected XOR observations Gx mod2=h, add one slack integer s_i per observation and exact row G_i x-2s_i=h_i (take binary reps of h). Give s_i finite integer bounds from original l,u, using ceil/floor. Slack columns zero in B, all coefficients <=max(Delta,2). Then k+q constant yields same EM reduction for arbitrary binary capacities and global joint protected bits, not just affine hull. For q=2 this captures one complete tetrahedral hub target and fixed many integer quotas. With only one parity bit M13 deterministic correct-parity solver remains preferable. This is an upper reduction to EM for q fixed, not a proof of EM-hardness of two-bit-only parity. Multiple observations growing with input need not satisfy the fixed-k bound. Arbitrary binary-cost weighted optimization in an EM-constrained fiber is not solved by the red-path reduction; proximity preserves optimum but computing it is separate.
