## Theorem A (exact cycle-block product)
Let H be the undirected multigraph on remaining variable arc IDs, ignoring orientation but retaining parallel edges and loops. Compute an undirected spanning forest; each non-tree edge gives a fundamental cycle (loop length one, parallel pair length two allowed). Union the edge IDs on each such cycle, producing disjoint edge classes B. Every simple undirected cycle lies in one class: the fundamental cycles span the binary cycle space, and the restriction of a binary cycle vector to any class remains even at every vertex. A nonempty proper edge subset of a simple cycle cannot be even. Every integer circulation d decomposes into oriented simple cycles after reversing the edges with negative d; therefore its restriction to each class is itself a circulation. Conversely any per-class circulation can be combined because their edge supports are disjoint and each has zero imbalance at every vertex, even shared articulation vertices.
For baseline f on variable arcs, the exact integer feasible set is consequently a Cartesian product of local domains
  F_B={x_B integer: A_B x_B=A_B f_B, 0<=x_B<=u_B}.
In particular S_total = fixed_tag + XOR-sum_B G_B(F_B mod 2). There are no hidden constraints between blocks in this model. One SCC can contain arbitrarily many such independent blocks. This is not an assertion of independence for overlapping source regions. A bridge gives a singleton with zero circulation space and would have been fixed already. The simple fundamental-cycle union implementation is polynomial (O(m(n+m)) traversal plus DSU); linear-time edge block discovery is optional. Discovery uses only the actual bounded flow instance.

## Theorem B (interior parity saturation)
If a block admits a certified integral midpoint f* with 1<=f*_e<=u_e-1 for every edge, then
  {x_B mod 2 : x_B in F_B} = (f* mod 2) + ker_GF(2) A_B.
Necessity is immediate by reducing Ax=b modulo two. Sufficiency: any even edge subset y in the kernel is an Eulerian undirected multigraph. Orient each Euler tour, taking d_e=+1 if the chosen traversal agrees with the original direction, -1 otherwise, zero off the subset. Then A_B d=0, d mod 2=y and f*+d lies within every bound. Loops and parallel edge pairs satisfy the same argument. The midpoint is found by one flow with lower bounds 1 and upper bounds u-1, not guessed. Hence the exact tag support is affine, with direction image G_B ker A_B and actual witness for every tag. Fundamental cycles are a binary basis; elimination stores selected preimages and Euler orientation realizes their XOR simultaneously. It is not necessary that fundamental cycles be physically edge-disjoint, nor that the midpoint lie at a coordinatewise arithmetic average. The certificate is sufficient, not necessary: a capacity-one directed cycle can have full binary-cycle support without an integer interior midpoint. For such blocks S07 rank-one peeling remains valid.

## Theorem C (halved-capacity parity acquisition)
Even without interior, every parity candidate p in (f_B mod 2)+ker_GF(2) A_B can be tested exactly by writing x=2z+p:
  A_B z = (A_B f_B-A_B p)/2,
  0<=z_e<=floor((u_e-p_e)/2), z integer.
The right side is integral by construction; negative upper bounds reject. The substitution is bijective for prescribed parity; one integral feasibility call plus a lift suffices. If beta_B is the binary cycle rank (number of chords) this yields at most 2^beta_B queries and exact witnessed tag table. Complexity depends on the bit length of capacities, not their numerical magnitudes. For general unbounded beta this may be exponential; no claim to solve all fixed-small-tag-rank flow instances via this method.
For a minimal falsifier of replacing support by its affine hull, use three parallel unit arcs s->t with demand (-1,+1) and tags 00,01,10. Exact support excludes 11 although its hull is all GF(2)^2. One cycle block, no interior, two chords; halved-capacity tests reject the false target. This control was executed in the robust variant.

## Composition and resource bounds
Absorb all independently saturated affine blocks into W=sum of their direction images. For noninterior blocks whose exact tables are acquired, let rho be rank of the span of all local tag differences in the quotient E/W. Use one chosen baseline tag per block, then exact XOR DP in the quotient, keeping actual row backlinks. The final discrepancy in W has a Gaussian preimage and Euler lift, independently per saturated block. This gives
  T <= poly(N) [1+sum_noninterior 2^beta_B+2^rho sum_noninterior (1+|S_B|)]
and S <= poly(N)[1+sum_noninterior |S_B|+2^rho], with polynomial factors allowing all stored layers, tags, full local witnesses, source IDs and reconstruction. Can compute smaller tables/peeling when additional exact affine saturation holds. S07 rank-one peeling also applies to cycle-block-local residual supports and can bypass some large beta blocks. If max noninterior beta_B + rho=O(log N) the displayed terminal is deterministic polynomial, regardless of global tag rank or numerical capacities. If no noninterior blocks remain, no exponential dependence at all. Cumulative memory <= T*S for this same declared sequential execution, not a lower bound; all bit lengths, matrix operations, flow queries, branch failures, fixed block discovery, retained witness tables, quotient keys, source conversion, verification, output and sharing are charged. Edmonds-Karp shortest augmenting path gives polynomial bit complexity; no pseudopolynomial unit-flow iteration. This is conditional on paid input acquisition.
