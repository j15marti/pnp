## 3. Untagged implicit forest theorem (PROVED)
Suppose owner/block incidence is a forest. For each block choose a dominant owner d(B) (e.g. largest edge group, polynomial). Root each nontrivial tree at an owner. Let r_B be the sum of edge counts in non-dominant groups of size >=2, and r=max r_B (empty max 0). For a block with parent owner p, child-owner messages are minimum costs A_i for feasible child subtrees; infinity means infeasible. At owner nodes sum child-block minima and reject over budget. Independence plus upper-budget monotonicity makes keeping only the minimum exact (MS05 q=0).

At block B, each child i has remaining budget R_i=K_i-A_i. If i is non-dominant and has precisely one edge e in B, then its constraint reduces to deletion if w_e>R_i, otherwise e is unconstrained by owner i. Retain allowed such edges with zero objective weight. This is exact because all its other edges are outside B and already represented by a genuine minimizing child witness. It is NOT valid for groups of >=2: separate affordability need not imply joint affordability.

Enumerate edge subsets of all non-dominant groups of size >=2; also enumerate the parent edge if p is a non-dominant singleton. Thus at most r_B+1 bits. Check group costs against child residual budgets (and parent budget as safe cap); fix selected edges, delete unselected edges, XOR selected boundaries from local target. Remaining graph contains only dominant edges and allowed singleton child edges. Solve ordinary nonnegative min T-join with original dominant costs and zero singleton costs. If dominant is parent, use its minimum as outgoing parent cost. If dominant is child, test min <= R_d, and use the already fixed cost of parent as outgoing cost. In both cases retain the least parent cost across all feasible patterns, with actual local and child witnesses. The parent may have arbitrary budget weight precision. Root owner checks its sum; separate components independent.

Completeness: any feasible solution chooses one enumerated pattern; each child subtree may be replaced by its minimum without raising its owner's cost. The remaining join is feasible for the ordinary objective, so its cost is at least the optimum. Replacing by an optimum preserves other owners' restrictions since every free singleton independently fits its own budget. Soundness: each retained pattern and min join satisfies all internal owner budgets, boundary and chosen parent cost. Combine stored witnesses by induction. Nonnegative T-join min is shortest paths on terminals plus weighted perfect matching, with XOR of selected paths; path decomposition proves equality (nonnegative weights essential). Integer costs remain polynomial bit length.

Therefore deterministic bit T <= 2^(r+1) poly(N), peak S <= poly(N) by streaming patterns and keeping one witness per message, CM <= T*S on same execution. This does not depend exponentially on local cycle rank ell, total minority edge count p, terminal count or number of singleton owner groups. It is polynomial for r=O(log N); especially when each non-dominant group is singleton. No explicit local row table or counting guarantee. r is a discoverable sufficient parameter, not globally optimized over representations.

## 4. Protected tags: sparse child-deviation theorem (PROVED, primitive tested)
Use MS05 tag-indexed messages A_i(h) for each h in GF(2)^q. At singleton non-dominant child edge e of cost w, define H_b={h:A_i(h)+b*w<=K_i}, b=0,1. Then H1 subset H0. H0 empty means impossible. Choose baseline a in H1 if nonempty, otherwise in H0 and force e absent. Baseline is valid for all remaining legal edge statuses.

Fix any feasible local join and all non-singleton child tags. Each singleton child chooses a tag h_i, contributing deviation d_i=h_i+a_i. If >q nonzero deviations, they are linearly dependent in GF(2)^q. Remove a nonempty zero-XOR subset by reverting those children to baselines; their selected edge statuses are unchanged and their budgets remain valid. Repeat. Thus every attainable combined tag can be realized with <=q deviating singleton children for the SAME local join. Conversely every constructed assignment is valid. This is a qualitative cancellation of conditional choices, not an affine-hull relaxation: every remaining deviation has an actual child witness.

Enumerate up to q distinct singleton children and their alternative H0 tags. If chosen tag lies outside H1, force that edge absent; otherwise keep it free. Nondeviating children use baseline. There are <=sum_{j=0}^q binom(s,j)(2^q-1)^j patterns for s singleton children. The sum is N^{O(q)} 2^{O(q^2)}, with q=1 at most s+1. This is XP in q, NOT FPT claimed. For fixed multi-edge subset pattern, convolve allowed non-dominant multi-edge child tags by Boolean XOR DP; their budgets are already determined by the subset. Parent singleton remains enumerated; its cost is recorded, not tested against an unknown tag. For residual local graph run M05 tagged min T-join with q-bit edge tags and weights only on dominant edges. Fixed selected edge tags are XOR offsets. If dominant is a child, combine each local optimum for tag h with each dominant child A_d(h') testing their sum against K_d. If dominant is parent, minimize its cost for each total tag. Merge singleton deviation offset, multi-edge child tags and local/child tags by XOR; retain minimal parent cost per total tag. At owner nodes use ordinary min-plus XOR convolution; root and component joins as MS05. This preserves every attainable protected tag and actual coefficient witnesses. No rank assumption on the labels.

Let t_* be a safe upper bound on maximum terminal count in a connected component of any residual local min T-join query, e.g. max original block terminal total + 2(r+1) in forest case (deleting edges does not increase total terminal count). Use M05 bound 2^(t_*+2q) poly(N) for local query; extra tag convolution factors absorbed into 2^{O(q^2+q)}. Overall T <= 2^(r+t_*+O(q^2+1)) N^{O(q+1)}, S <= 2^(t_*+O(q)) poly(N) streaming deviation and edge patterns, actual witness storage charged. For fixed q and r+t_*=O(log N) deterministic polynomial. For q=0 use ordinary blossom and drop t_* entirely, stronger than invoking M05. Arbitrary q not polynomial promised. q=1 gives complete affine extraction in <=m dual probes by M05/MS05 dimension argument, independent of singleton count except polynomial overhead; requires t_* bound. Protected tags are coefficient-level until all-witness physical pullback and L2 annihilation certified. No arbitrary source tag assumption.

## 5. Cyclic extension (PROVED, not executed)

Extend by maximum-weight spanning forest on remaining incidences weighted by number of represented edges; this minimizes total cut edge count c among forests containing designated dominant incidences. Negative residual budget rejects. Every feasible solution determines a branch, conversely forest witness lifts with those pins. Stream all <=2^c branches, renew sound guarded closure, no independent per-owner pooling. Can preserve original groups/forest for upper bounds. Untagged T <= 2^(c+r+1) poly(N), polynomial peak space.
