## Exact native representation (PROVED WITH SCOPE)
For each native Boolean port x, use F3 arithmetic with the domain restriction x in {0,1}. Equality x=y is x-y=0; signed complement x XOR y=1 is x+y=1. At B4, x1+x2+x3+x4=2 over F3 is *exact* on Boolean values because the integer sum is in [0,4] and 2 is the only integer in that interval congruent to 2 modulo 3. This is a uniform solution-preserving linear compilation with a non-linear Boolean domain restriction. Signed equality contraction/gauge substitution is exact; a global complement of every port preserves every original E/B constraint, so the benchmark gauge port10=0 is a symmetry choice, not an unconditional forced pin. The general Boolean-restricted linear problem is not solved by Gaussian elimination (positive exact-one of three is already the same F3 equation with RHS1 and is NP-complete; Schaefer 1978). Distinguish this exact balance congruence from the signed clause-table scoring residues, which do NOT decide OR.

After GE, write every Boolean carrier coordinate as x_i=b_i+a_i z over F3, with z an affine free parameter. If a_i=0 and b_i=2, reject. Otherwise for each nonzero a_i normalize to first nonzero coefficient 1: l_i=s_i a_i, s_i in {1,2}. The Boolean domain excludes l_i z=s_i(2-b_i). Group equal normalized l_i. Three excluded residues give an exact contradiction; two distinct exclusions force the remaining residue as a new affine equation. Every new nonzero row lies on the current free coordinates and therefore strictly lowers dimension unless it is already implied by another added row in the batch. Recompute after every batch; repeat local closure. At most n independent contraction rounds, each with polynomial dense GE and canonical row comparison; O(poly(N)) bit work for the deterministic routine, e.g. O(N^4) field operations plus sorting/serialization on explicit rows, conservative polynomial space and cumulative memory CM <= (T+1)S on a serial bit implementation. Retaining all witnesses is polynomial (at most n rounds, O(n) groups of O(n) entries per round). This is a conditional terminal/contraction routine, NOT guaranteed productive.

Exact rank-two extension: for each pair of distinct normalized directions a,b, their span has four directions [a],[b],[a+b],[a-b]. Collect their forbidden values by hash lookup after canonical normalization. Enumerate 9 (a z,b z) words. Empty support certifies contradiction; a common affine equality is a paid new row and lowers rank. A rank-two pair search is polynomial (O(n^2) pairs, O(n) coordinate work per pair, 9 local words); full iterative saturation is polynomial. For example, four directions z1,z2,z1+z2,z1-z2 excluding value0 cover F3^2, even though every parallel class has only one forbidden value. The four-line pencil is solved by the rank-two terminal, not by parallel classes.
