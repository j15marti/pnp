## Exact subcubic selector
For a nonempty explicit relation of r distinct rows use two disjoint paths each of 2r-1 vertices, with cross edges joining corresponding odd positions. A perfect matching must use at least one cross edge because each path has odd cardinality. If it used two or more, the segment between consecutive used odd positions on either path has odd cardinality and no used cross edge, impossible. Thus exactly one cross edge is used; the remaining path segments are even and uniquely matched. Every choice extends uniquely. Degree <=3, 4r-2 vertices, O(r) edges. Label cross edges with the row's contribution to occurrence equality syndromes; all path edges zero. Empty relations reject. This replaces M24's high-degree hub with a bounded-degree ordinary matching graph, not a strict physical E4/B4 compiler.

For an acyclic Boolean circuit over fan-in two AND/OR, NOT, free input and constant/pinned outputs, use each gate truth table as a relation and one input owner per free variable. Each gate row has at most three bits and each relation at most four rows. For each wire/variable occurrence set impose equality by a spanning path or star of pairwise binary XOR equations. A syndrome bit is the XOR of the two occurrence bits. The disjoint union of selectors has a perfect matching of zero total syndrome iff all gate relations and output pins hold. There is exactly one such matching per satisfying external input because both the gate outputs and selector matchings are unique. A spanning path gives each cross edge <=6 nonzero syndrome labels (three occurrences, each degree <=2), and each syndrome row has constant support (two owners, <=4 options each). Star was executed; path sparsity is symbolic. Size O(circuit incidence volume) vertices, edges and sparse tags; dense bit matrices polynomial. Explicit source dictionary, gate topological order and inverse map paid. This compiles the BS19/GD26 projected gate without enumerating its exterior words or raw tail pairs. Applying the same construction to arbitrary Boolean circuit SAT proves NP-completeness of the resulting tagged matching class, even disjoint constant-size subcubic ladders and sparse path tags. The representation does not guarantee low syndrome rank or joint compatibility acquisition.

## Structural dual-rail obstruction
Let a finite ordinary graph have distinct terminal pairs (i0,i1). A boundary set S is feasible if deleting precisely S leaves a perfect matching. Assume every untagged feasible boundary set deletes exactly one terminal of each pair; no external filter is permitted in this premise. For two feasible words x,y, lift to matchings on the graph with the deleted vertices unmatched. Their symmetric difference is a disjoint union of alternating cycles and paths, with path endpoints precisely the terminals of Sx symmetric-difference Sy. Switching one path gives another untagged feasible boundary. Structural one-hot forces the two endpoints of every path to be mates from the same pair, otherwise switching violates one-hot. Thus each differing coordinate can be flipped independently. Every nonempty exact pure dual-rail relation in this model is a Cartesian product of unary sets. In particular NAE and the nonproduct GD26 projected gate cannot be encoded by such a pure boundary gadget regardless of internal size.

If the untagged one-hot property remains structural and graph edges carry q-bit tags, restrict to one target syndrome. Given two target-feasible boundary words at distance d, switch any subset of the d alternating paths. Each path has a fixed XOR tag difference. The kernel of the q-by-d path-label matrix has dimension at least d-q (or zero). All these switches are target-preserving and yield distinct boundary words, an affine subcube-subspace of size >=2^max(0,d-q). Exact all-equal d-copy boundary support {0^d,1^d} consequently needs q>=d-1 in this model. Tight upper bound by independent one-bit gadgets (a path of length two with the two leaves terminals) and d-1 pairwise equality tags on edges. This is a tag-coordinate lower bound, NOT a time lower bound, not a bound for external one-hot filters, weighted-optimal filtering, alternative decoders or native nonmatching constraints. Equality is easy by Gaussian elimination; high rank alone does not establish difficulty.
