## The new scoped terminal: logarithmic Hall slack, not logarithmic boundary width
Let an exact region consist of disjoint unit demands L, resource bins R (at most one chosen occurrence per bin), allowed demand-bin incidences H, and bin-specific availability conditions. Let d=|L|, q=|R|, k=q-d>=0. Each boundary assignment z disables the set D(z) of DISTINCT bins. Assume every nonempty S subset L has |N_H(S)|>=|S|+k. The regional existential response is EXACTLY |D(z)|<=k. Necessity follows from total available resource count; sufficiency follows by losing at most |D| neighbors from any Hall set. Reconstruction is a matching on remaining resources, choosing corresponding source occurrence and setting all other interior occurrences false. The exact syntax and absence of additional interior constraints must be checked. This generalizes peer injective blockers: arbitrary shared and nonlinear Boolean bin predicates allowed, but actual disabled-bin count, not selector count. Robust surplus can be certified by d forced-source-row flows of value q as in peer theorem. Their capacities are bounded by d+q+1; construction/checking polynomial. On special interval shells the proof is simpler: demand i neighbors i..i+k; the smallest demand in a nonempty set contributes k+1 resources and each later demand adds its own larger endpoint, so |N(S)|>=|S|+k.

Assume now that each disabled-bin predicate is a conjunction of at most two signed literals, and the complete remaining consumer response is an explicitly acquired exact 2CNF H0 (may have additional existential variables with checked lift). Represent each bin by one soft clause not(h_j), and H0 by protected hard clauses. Then joint feasibility is equivalent to deleting at most k soft clause occurrences while satisfying every hard clause. This is Almost 2-SAT, not arbitrary MaxSAT. To avoid any ambiguity over clause multiplicities, replace a clause (a OR b) by (a OR u) AND (!u OR b), with a fresh u per copy. For each fixed original assignment, the minimum number of violated clauses in that pair is exactly 0 or 1 according as the original clause is true or false. Use one private pair for each soft occurrence; use k+1 disjoint private pairs for each hard clause. A false hard clause costs at least k+1 violations and cannot occur in a solution of cost<=k. Conversely any assignment satisfying hard clauses and violating at most k soft occurrences extends to a word violating at most k gadget clauses. Unit clauses can be encoded by a=b; always-disabled/always-enabled bins handled as fixed offset or zero soft cost, with budget adjusted and negative remaining budget immediately refuted. Construction polynomial in explicit source and k<=q; no conflation of selectors or hidden group-deletion assumptions.

Ramanujan and Saurabh, Linear Time Parameterized Algorithms via Skew-Symmetric Multicuts, arXiv:1304.7505, give an Almost 2-SAT algorithm O(4^k k^4 ell). Razgon and O'Sullivan, arXiv:0801.1300, earlier O(15^k k m^3) also suffices. Thus for fixed c and k<=c log2 N, a uniform deterministic polynomial terminal exists on the recognized class, even if the boundary contains linearly many independent variables or has large treewidth. Include exact region acquisition, hard response acquisition, source lifts, gadget construction, finite-precision bit simulation and replay. k=0 direct 2SAT. A decision algorithm can be used with polynomially many hard-pin self-reduction queries to reconstruct witnesses; check all original source constraints. This is a reduction to an established algorithm, NOT a fresh implementation of the single-exponential FPT algorithm. Our implemented independent comparison enumerates all pairs of allowed deletions at k=2 and solves exact SCC; it does not establish the FPT bound empirically. The fixed slack proof works on arbitrary selector graph under exact hypotheses. This is a stronger scoped route than forcing boundary dimension to log N.

General k is not automatically tractable. For cubic graph G set one AND blocker per edge and a hard OR for each same pair. Zero-valued vertices form an independent set I; the count of 11 edges is |E|-3|I|. Choose d=|E|, q=d+k with interval H and k=|E|-3K (handle invalid K outside 0..|V|/2 separately). This explicit polynomial-size CNF has matching lift iff G has independent set of size>=K. Cubic independent set hardness: Alimonti & Kann, TCS 237 (2000), DOI 10.1016/S0304-3975(98)00158-3. This is a scoped NP-hardness reduction for unrestricted slack, NOT P!=NP or a restricted-lane lower bound on native sources. Counterexamples to overgeneralization: H=[[0],[1,2]], q-d=1, blocking bin0 is infeasible but blocking bin1 feasible (same disabled count, robust surplus fails); H=[[0,1],[1,2]], one selector blocking two bins fails despite selector count1, actual blocked count2.
