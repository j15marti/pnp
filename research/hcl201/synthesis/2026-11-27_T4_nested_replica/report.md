## Theorem: contextual replica cover
Let an explicit finite CSP have factors F_i on scopes S_i, allowed row domains D_i. A nested copy A'(x',y) of A(x,y) has fresh private variables and shares boundary y. Retaining original A and conjoining the copy preserves satisfiability, since any original witness lifts with x'=x. To gain inference rather than redundancy, choose a host factor i. Each of its live rows t supplies a guard x|S_i=t. In a separate copy of the current domains, pin that row and apply support closure. In joint mode, revise D_j by retaining only rows that agree on the entire S_j intersect S_k with some row of D_k; in flat mode revise one shared coordinate at a time. All such revisions preserve every actual solution of the current guard. Contradictory copies contribute the empty set; noncontradictory copies contribute their surviving domains, which are necessary overapproximations, not claimed exact support. For each factor j set D'_j = union over t in D_i of surviving D_j^(t). All original models select a row t in D_i and survive that copy, so D'_j is contained in D_j and preserves every original model. This is exact decision equivalence after restriction, with identity lift. Reject if an actual domain is empty. If all copies contradict, UNSAT; if none yields progress, UNKNOWN. Reclose after each accepted sweep and at stagnation. Independent contextual copies must not be conjunctively required to realize mutually exclusive host rows. A shared key without its full guard is not a valid cache identity.
