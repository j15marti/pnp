## 3. Algebraic tree defect and exact polynomial discovery (PROVED)
For an undirected tree T on the factors, w_ij=dim(U_i intersect U_j). For each edge ij choose a basis of the intersection. Each common functional has a unique coordinate expression in each endpoint's independent row basis. Their equality gives a dependency vector in K supported on those two factors. Let K_T be the span of these edge dependencies.

**Lemma:** The edge dependency spaces form a direct sum. Proof: if a linear combination of edge relations vanishes, at any leaf only its incident edge contributes; the restriction of that edge space to the leaf coordinates is injective (unique coordinates of the common functional). Hence that edge contribution vanishes. Delete the leaf and repeat. Thus dim K_T=sum_(ij in T) w_ij.

Define
delta(T) = L - rank A - sum_(ij in T) dim(U_i intersect U_j) >=0.
By pairwise Gaussian elimination obtain the weights and intersection coordinate bases. A maximum-weight spanning tree minimizes delta over ALL trees on these fixed factor scopes; no representation search is hidden. Include zero-weight edges to join disconnected components, and treat zero/one-factor cases directly. Extend K_T's basis to K by delta additional dependency vectors c_1,...,c_delta using Gaussian elimination. This is polynomial discovery of both a tree and the missing dependency checks, not an oracle for optimal global representation.

**Exact compatibility theorem:** A tuple of local allowed rows comes from one global assignment iff it agrees on every tree-edge intersection and the XOR of local tags g_i(y_i) is zero, where g_i(y_i)=(c_j restricted to factor i dot y_i)_j. Proof: these conditions annihilate the basis of K_T and its complement, hence all of K. Conversely any global assignment annihilates K. Solve Ax=y by Gaussian elimination for an actual witness; preserve its affine solution fiber if needed. No equality of original variable names is required.

**Cut-separator corollary:** Deleting edge ij partitions factors into P,Q. The dimension of (sum_P U) intersect (sum_Q U) is dim K/(K_P+K_Q), with K_P and K_Q dependencies supported entirely on the indicated side. Map a dependency to the sum of its P-side functionals; image is the cross intersection, kernel K_P+K_Q. Internal tree relations vanish in this quotient, and the crossing edge relations contribute exactly U_i intersect U_j. The complement contributes at most delta dimensions. Hence the actual algebraic cut width is between w_ij and w_ij+delta. In particular delta=0 certifies exact cross-cut separators for every edge. The theorem concerns these tree cuts, not all subcubic branch decompositions or minimum treewidth.

Counterexample to untagged pairwise agreement: U1=<a>, U2=<b>, U3=<a+b>, with a,b independent, each local bit fixed to 1. All pair intersections vanish, but global parity 1+1+1=1 contradicts K. delta=1. Raw tree-only DP accepts; exact tagged DP rejects. Initial affine closure also rejects, so this is a semantic counterexample to a proposed inference, not a hard residual.

## 4. Exact tree DP, protected observations, and qualitative contradiction (PROVED)
Root T. For each listed row at node i, compute its evaluation on the parent and each child intersection basis. Combine child messages with matching boundary signature, XORing residual tags, sequentially across children. Store reachability by (parent signature, accumulated delta-bit tag); for each signature only values appearing in the explicit parent-facing rows are needed. At the root accept tag zero. Induction over disjoint subtrees proves exactness: conditional on the chosen parent row all child requirements are independent except the XOR target; every retained state has an attaining tuple. A missing zero root state is a qualitative contradiction, while an accepted state gives a globally consistent tuple. Tree-only independence without residual tags is unsound. Do not combine independently selected minima that forget tags (MS05 warning).

For any explicit q additional linear observations on the row tuple, carry q extra XOR tag bits; prescribed output tags simply change the target. Affine observations in original x are handled by the affine right inverse and its free kernel (or explicit equations in the source); do not silently drop kernel variation. This gives T<=4^(delta+q) poly(N), S<=2^(delta+q) poly(N), where N includes all listed rows and scope matrices. No exponential cost in edge intersection dimension is needed when the relations are explicit: only observed signatures are retained.

**Protected features (S04 extension):** For fixed degree d, let M=sum_(j<=d) binom(L,j). At each DP cell keep a GF2 basis of degree-d monomial evaluation vectors INCLUDING the constant 1, each with an actual partial tuple witness. For a fixed local row, the product with a child conditioned cell uses disjoint row-coordinate sets; monomial evaluations compose bilinearly (the same S04 map, with outside coordinates zero). At most M^2 witness pairs per combination generate exactly the product span. Across alternative rows or compatible tag splits take union of generated witnesses and compress by Gaussian elimination. Induction proves root basis spans precisely all feasible tuples' evaluations. Thus any polynomial identity of degree <=d in row coordinates is exact, not just inferred from an affine hull, and a failing identity has a real counterexample.

For original free coordinates choose linear right inverse R on im A and kernel basis Z so x=Ry+Zz (plus the previously eliminated affine offset). All z are free in this explicitly scoped model. Generate degree-d evaluation basis of z by points of Hamming weight <=d (triangular monomial evaluation matrix), compose with root row basis, and apply the induced linear substitution on degree-d feature evaluations. This gives a complete degree-d basis of actual original x assignments with polynomial overhead for fixed d. Arbitrary physical source observations require certified pullbacks of bounded degree or preserved exact lifts; GD05 quartic example prohibits assuming degree two. This original-coordinate extension is proved, not separately benchmarked. The executed benchmark checks row-tuple basis witnesses against actual exhaustive x images.

A qualitative implication p=>q is the identity p(1+q)=0; if total degree <=d it can be tested exactly. A new affine forced consequence is returned to unconditional closure. Do not claim all nonlinear certificates or an efficient general coverage test. This proof retains guards if input factors were conditioned; unconditional facts require unconditional input or certified fusion of exhaustive guards.
