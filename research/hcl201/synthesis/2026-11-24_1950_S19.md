This is an upper bound in those parameters, not a universal polynomial algorithm.

Let S_v(k) be the set of all integer cost vectors attained in subtree v at coarse key k, BEFORE quotas, after certified guard/pin closure. Coarse key includes actual occupancy and syndrome, not merely a marginal or inferred hull. For each nonempty set record an actual anchor a, its integer difference lattice Lambda, and coordinate extrema [l,u]. Empty is distinct. Addition of independent sets adds anchors, lattices, and coordinate extrema. Union adds anchor difference to the lattice and takes coordinatewise min/max. These are exact envelope summaries (MS19). Arbitrary-precision normal forms have polynomial bit complexity: all genuine cost coordinates and differences have polynomial bit lengths; determinant bounds bound canonical bases. This is exact by induction: any globally coarse-valid configuration splits into these three disjoint regions, and every combination in the recurrence is valid because the join checks actual keys. ## C. Strict improvement in certified parameter bound
Take two groups of n independent binary choices with positive weights M and M+1 respectively, M>2n, n even. Target Q=nM+n/2. Root interval distance is at least nM, up to additive O(n), and global gcd=1. M19 raw B is exponential if M=2^(2n)+1. In a tree separating the two groups, every proper subtree lies within a homogeneous group, so its inside stride is M or M+1, and its full range contains <=n+1 lattice points. At the group cut, the two cosets intersect with stride M(M+1) (coprime), and interval width <M(M+1), so at most one cost passes. The root has exactly one target key. Writing Q=M(a+b)+b, 0<=a,b<=n implies a=b=n/2. Count binom(n,n/2)^2. Neighbor nM+n+1 impossible because b<=n and M>2n. This is a comparison of certified parameter bounds, not measured speedup over all M19 implementations (sparse DP can also exploit this family). Scalar rank one with gcd1 is still NP-complete in general (Subset Sum); lattice membership is not exact. MS19 weights 3,5,7,9 target11 passes global interval/gcd and odd parity relaxation but has no actual subset; our exact DP rejects. No claim every cut catches holes or that this easy family is hard.
