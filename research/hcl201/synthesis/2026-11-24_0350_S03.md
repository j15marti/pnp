## 2. Anchor-shadow retraction theorem
Let a be a vertex, B a subset of V(G) minus {a}, H=G[B], T subset B. Set Q={1,2,3}. Suppose:
(F) For every v in T there exists p(v) in N_G(a) such that N_H(v) subset N_G(p(v)) intersect B.
(R) There is a graph homomorphism r:G-a -> H with r(v)=v on B and r(N_G(a)) subset T.
These are finite graph-checkable certificates. They allow additional auxiliary vertices, nonuniform neighborhood inclusions, multiple shadows of the same original, and arbitrary edges consistent with r. Direct neighbors of a in B can use p(v)=v.

THEOREM: G is 3-colorable iff H has a proper list coloring with domain {1,2} on T and {1,2,3} on U=B minus T.
Forward: by global color-permutation symmetry set color(a)=3. All p(v) have color 1 or 2. Starting from the ORIGINAL coloring, replace the color of each v in T that had color 3 by the color of p(v). Along any edge uv of H, at most one endpoint could originally have color 3. If v changes, u was not color 3, remains unchanged, and is adjacent to p(v) by F. Hence their colors differ. No changed pair can be adjacent. All T now have binary domains. This proves a qualitative NECESSARY restriction, not a forced original color equation.
Reverse: take any such base list coloring d. Set color(a)=3 and color(w)=d(r(w)) for all w != a. R ensures all non-anchor edges proper and every anchor neighbor binary. This is an actual source witness.
For RT03 Q=F2^2 minus zero, GL(2,2) realizes every color permutation; all incidence labels and target zero are preserved equivariantly. For arbitrary pre-existing pins, nonzero target, protected nonlinear observations or extra constraints, the symmetry and maps must be reverified; otherwise this is not an unconditional equivalence. Even when valid, maps do not preserve every original witness or source features (GD03 warning).
The forward implication F alone is sound for UNSAT certificates: if H[T] has an odd cycle, no 3-coloring of G exists. The odd cycle plus anchor, shadow neighbor edges and cover of its neighboring cycle endpoints gives a polynomial-checkable contradiction. Reverse R is needed for a SAT inference.

Classical Mycielski case: H arbitrary, one twin u_v per v adjacent to every H-neighbor of v, twins independent, apex a linked only to twins of T0. Set T=T0, p(v)=u_v for v in T0, r(u_v)=v. F/R hold, so this incomplete Mycielski graph is 3-colorable iff H admits color 3 only on B minus T0. Full apex gives precisely classical bipartiteness criterion; no novelty claimed for that argument. Our extension allows a partial retraction with nonidentical shadows and a tractable list-terminal beyond full apex links.

## 3. Deterministic terminal by the exceptional-domain conflict cover
Let U=B minus T. For a list coloring, the vertices assigned color 3 form an independent set I subset U, and H-I is bipartite. Conversely every such I gives a list coloring. First perform two sound terminal checks before branching: if H[T] is not bipartite, reject with odd-cycle contradiction; if H is bipartite, lift directly. If neither, use the induced conflict graph H[U].
Let C be ANY vertex cover of H[U], e.g. the endpoints of a greedily constructed maximal matching, |C|<=2 tau(H[U]). For each independent K subset C define
    I_K = K union {u in U minus C : N_H(u) intersect K is empty}.
U minus C is independent, so I_K is independent. Given a legal I, let K=I intersect C. Then I subset I_K: every original color-3 vertex outside C is nonadjacent to K. H-I_K is an induced subgraph of bipartite H-I and thus bipartite. The converse is immediate. Test each K by ordinary BFS bipartiteness, then lift. This is exact, and no minimum cover optimization is needed. Branch failures are guarded by K; all K must fail unless an unconditional contradiction already proves UNSAT.
New terminal parameter k=|C| (or sufficient 2 tau). With certified source and graph data, deterministic T=2^k poly(N), polynomial peak space. If U is independent, C empty and H[T] bipartite iff SAT; even a linearly large U need not generate any binary branching. k=O(log N) is sufficient for polynomial decision. This is an elementary parameterization of the known independent odd-cycle transversal equivalence, not an unrestricted 3-color algorithm. For T empty, general graph 3-coloring is retained and k may be linear.

## 4. Paid acquisition and source transport
For supplied a and B, when P=V minus (B union {a}) is independent, F/R certificates can be acquired without guessing T or r:
1. Build adjacency sets restricted to B. Put v in maximal T iff some p in N(a) covers N_H(v); store the first p. This includes every base vertex adjacent to a (self shadow).
2. For every w in P choose any v in B with N_G(w) intersect B subset N_H(v); if w adjacent to a require v in T. This defines r(w); r identity on B. Check r(N(a)) subset T and all non-anchor edges map to edges. P independence makes choices independent. If any check fails, return UNRECOGNIZED, not UNSAT. Supplied general r can be verified even when P has edges.
3. For F-only UNSAT, no r needed. With B=V minus ({a} union N(a)), compute maximal T and test H[T] for an odd cycle; try all a in polynomial time. This recognizes full RT03 Mycielski grids without a supplied base. For exact F/R in incomplete Mycielski with at most h missing apex-twin edges, enumerate anchor and up to h additional vertices removed from B into P; includes correct partition. For fixed h, deterministic polynomial number O(n^(h+1)) of candidates; h=O(log N) is not a polynomial discovery guarantee. General large-U recognition still needs supplied B or another paid discovery routine. The experiment implements recognition given a,B, not the outer all-anchor or missing-twin search.
