## Scoped theorem
For explicit exact disjoint syndrome-response dictionaries S_i, center each by an attained a_i, let U_i=span(S_i+a_i), r=rank(sum U_i), and for order pi define L(pi)=sum over proper prefix cuts of lambda(P)=dim U_P+dim U_Q-r. Thus 0<=L<=(m-1)r. Adjacent interchange of A,B changes only the intermediate prefix cut; compare rank(U_P+U_A)+rank(U_B+U_Q) against rank(U_P+U_B)+rank(U_A+U_Q), with exact GE. A disjoint set of adjacent interchanges in a sweep can be scored on a single snapshot because every other pair preserves the earlier/later block sets. Admit only strict decreases. At most (m-1)r accepted swaps; full deterministic sweeps alternating parity, stopping after both parities make no change, therefore terminate with a local minimum in polynomial charged work given polynomially sized dictionaries. No need for numerical rank or an eigenvalue threshold. The order change preserves the exact sumset and all local witness choices. **Not** a global UCAC contraction: L can reset after changing dictionaries/guards; a local minimum does not bound maximum width, nor does reducing L guarantee smaller DP cost. Preserve global credits separately. Proof of universal low effective width or alternative terminal remains open. A follow-up can use the guarded suffix-period rank score in #7239253633; that was not implemented here.
