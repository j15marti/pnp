## Fair schedule theorem (proved with scope)
On a fixed explicit CNF chart F with r Boolean coordinates and an append-only database of distinct nontautological clauses of width <=2, enumerate every unary/pair guard in a fixed source-derived order (or any uniform polynomial-cost permutation). Check RUP by unit propagation on complement. Learn only independently admitted clauses. Complete a pass unless a checked terminal intervenes, repeat only if the bank grew. There are K=2r^2 candidate guards and at most K nonempty new clauses; at most K+1 passes, hence O(r^4) candidate probes including failures. For final literal length L, one full-scan propagation needs at most r+1 scans; independent checking and SCC scans after each admission are polynomial in r+L. Sorting, storing the guards, caching O(rK) logical bits plus polynomial index/metadata overhead, arithmetic with O(log(r+L)) indices, replay, and bit-cost simulation of those explicit arrays admit a fixed polynomial. Cumulative memory bounded by total work times peak polynomial space; no fresh budget per epoch. Requires chart acquisition and reverse maps separately bounded in original N. Fixed-chart potential K-|learned| pays restarts; include remaining uninspected candidates inside each pass. Fairness here means no permanently skipped registered guard, not universal coverage. Physical run used serial JS, soft 3M event cap (checked at scan boundary); mixed event counters, not measured bit-time. Failed admission in seed removal was not fully metered because exception discarded that counter; peak logical cache capacities and row counts only, physical memory/cumulative memory unmeasured. No claim of all-lane speedup.

Persistent closure lemma: if A is noncontradictory UP closure of F under g, append H. Scan new clauses on A. If none is unit or contradictory, old closure is already a fixed point of F+H, hence equals its least UP fixed point (monotonicity and containment). If new clauses force bits, resume full UP from A; monotonicity and least fixed point imply equality with fresh propagation. Same guard/coordinate system required. Cache invalidation on nonappend changes necessary. Conflicted guards may be retained as proved forbidden, not mixed with another guard. No cache hit was observed in primary experiment because every arm finished or hit cap in first pass; caching consumed extra storage without benefit.

SCC shortcut lemma: if binary implication graph has a variable v with paths v=>not-v and not-v=>v, then F+not-v propagates to contradiction, so [v] is RUP. After appending [v], F propagates to contradiction, so [] is RUP. Unary clauses are encoded as implication not-l=>l. This is a shortcut, not stronger fixed-point logic: exhausting the singleton RUP guards would also refute. The productive order may differ drastically before that next sweep. Source scope ranking uses original co-occurrence and occurrence counts only, never peer proof. Fixed schedule stops before unnecessary clauses when SCC found.
