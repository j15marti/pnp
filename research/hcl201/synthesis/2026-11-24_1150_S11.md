## 2. Coloop-core discovery (PROVED)
Gaussian elimination gives the exact chart x_i=a_i+ell_i(z) mod 2, z in GF(2)^d, with every original switch indexed. Let U be the SET of distinct nonzero linear forms ell_i. U spans the dual of GF(2)^d because the chart is injective. A form u in U is isolated iff rank(U without u)<d, i.e. a coloop of the represented vector matroid. Let J be all such forms and K=U minus J. Then span(U)=span(K) direct-sum span(J); dim(span K)=p=d-|J|. Proof: a dependence involving any j would express j by other U, contradiction. Choose a basis of K and append J; the evaluation map is invertible. Therefore each non-coloop form depends only on p core coordinates, and each isolated form is its own independent bit. Repeated forms are not separate matroid elements; their actual indexed switch groups are retained for lifting. This decomposition is invariant under invertible changes of free generator coordinates. Rank tests and reparameterization are polynomial; no optimal basis search.

## 3. Exact signed-column contraction (PROVED)
For each isolated form j let I_j={i:ell_i=j}. At its bit 0 each switch equals a_i; changing to bit 1 changes its INTEGER value by 1-2a_i. Aggregate
    D_j=sum_(i in I_j) (1-2a_i) A_i.
This is an integer vertex vector, not a GF(2) sum. All core switches are fixed when the p core coordinates are fixed. If D_j=0, choose its bit freely (0 suffices for decision). If D_j=e_v-e_u for distinct vertices, replace the entire group by a single unit-capacity arc u->v. Otherwise call it exceptional; let q be their number. Complementing the affine origin flips all signs of a given isolated group together, so incidence eligibility is invariant. A change of basis in the core cannot alter isolated groups. Thus p+q is canonical for this authenticated affine chart and fixed physical graph, NOT over arbitrary source representations.

For each of 2^(p+q) guarded assignments to core and exceptional bits, subtract all fixed switch contributions and the baseline contributions of ordinary isolated groups from b. Solve ordinary integral demand flow on R and the remaining aggregate unit arcs. Integral feasibility is polynomial by super-source/sink reduction and shortest augmenting paths. If feasible, set each ordinary group bit to its aggregate arc value; zero columns can use 0. Restore every indexed switch by the original affine formula and every recourse arc from the flow; verify all equations and capacities. If no branch feasible, reject.

Soundness: branch assignments satisfy Gx=t by construction, grouped column equations exactly conserve integer demand, and every flow yields actual unit-valued group bits. Completeness: any original solution has one enumerated core/exception word, and its remaining bits define the corresponding quotient flow. It follows that the algorithm is an exact decision and witness terminal with T<=2^(p+q) poly(N), S=poly(N) (stream branches and retain one witness), CM<=(T+1)S. p+q=O(log N) suffices. In particular p=q=0 needs one terminal flow irrespective of affine nullity d or protected rank. No full-support, pair count, branch-cover identity or guessed source conversion is used. ## 4. Sharp obstruction: pure repetition chart does NOT imply tractability (PROVED)
Take proper 3-CNF with distinct variables in every clause, all occurring. For clause j add a demand vertex of demand 2, and common reservoir of demand -2m. Each literal occurrence is a binary switch from reservoir to j, whose value represents falsity of that literal. Add two independent zero-tag unit slack arcs from reservoir to j. For each variable tie its indexed occurrences by affine equality/complement equations according to literal signs (one reference per variable). The affine chart is a disjoint repetition/complement chart with p=0: one independent form per source variable. Every clause demand is feasible iff its false-literal count is <=2, because exactly 2-minus-count slack arcs can be selected. Thus tagged target feasibility iff source 3SAT; the construction and witness lift are polynomial, all arc capacities unit, all clause demands 2, affine constraints weight two. No numeric encoding trick. Untagged flow is always feasible (zero switches and two slack arcs per clause); every unit coordinate individually supports both values in the untagged relaxation, and the affine chart individually supports both switch values. Root separate affine/flow coordinate closure is stagnant. The integer columns D_j can have multiple nonzero vertex entries; this is precisely what q charges. NP-complete decision for the supplied abstract model even p=0. No proof of strict E4/B4 or arbitrary geometric distributed wheel realization of this specific reduction; no unrestricted time lower bound. Arbitrary representations, BH05 projections, matching, modular and algebraic shortcuts remain eligible.

Hostile two-switch example: two parallel unit arcs, equality x1=x2, demand 1. Chart nullity 1, p=0, D=2(e_v-e_u), q=1. Relaxing aggregate to arbitrary integral flow of capacity 2 incorrectly accepts flow 1; correct branch rejects both 0 and 2. Thus neither integrality alone nor affine closure is sufficient.
