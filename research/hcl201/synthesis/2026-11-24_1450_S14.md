## A. Exact local coefficient terminal (PROVED using Kasteleyn theorem)
For every explicitly indexed undirected perfect-matching block G with 2h vertices and m edges, integer weight vectors d_e in Z^q and binary tags g_e in F2^r, let X be the matchings and define S(d,s)=#{M in X: sum d_e=d, XOR g_e=s}. Edges may have multiplicity with distinct IDs. Assume a certified sign-coherent Pfaffian orientation, i.e. Pfaffian monomials for all indexed perfect matchings have identical sign. A planar embedding gives polynomial acquisition (planarity check, dual-tree face orientation); or supplied sign coherence must be certified by a valid theorem, not guessed. Ordinary feasibility closure can reject empty blocks. Choose fixed sign epsilon from one actual matching, independent of later numerical weights. In a bipartite block use a signed biadjacency determinant with its corresponding fixed sign. The polynomial identity extends to arbitrary signed weights by expansion, not a positivity assumption on those weights.

Discover a basis for U=span(g_e) by Gaussian elimination, r_i=dim U, and express each tag in basis coordinates. For each active integer row a (some d_ea nonzero), choose l_a=min_e d_ea, L_a=h(max_e d_ea-l_a), radix R_a=L_a+1. A matching's shifted quota q_a=sum_e(d_ea-l_a) lies in [0,L_a]. Let P=product R_a and place values p_a=product of previous radices. Define e_e=sum_a p_a(d_ea-l_a); then sum_{e in M} e_e is exactly the mixed-radix index of shifted quota, between 0 and P-1. Zero-width rows are constants with radix one, no ambiguity. Shift back by h*l_a.

Take base B=2^(m+1), greater than every coefficient since at most 2^m edge subsets. For every dual character lambda in F2^r_i assign weight B^e_e * (-1)^(lambda dot g_e). Use signed Pfaffian (or signed bipartite determinant) to compute
 V_lambda=sum_M B^(sum e_e) (-1)^(lambda dot g(M)).
The Pfaffian sign epsilon is fixed before evaluating characters; taking absolute value at each character would be WRONG. Apply exact inverse Walsh:
 W_s=2^-r_i sum_lambda (-1)^(lambda dot s) V_lambda
     =sum_{M:g(M)=s} B^(sum e_e).
Now W_s is a nonnegative integer and digits in base B are exactly S(d,s), with no carry. Extract digits by exact division, decode mixed radices, retain positive coefficients. The entire local support is acquired in 2^r_i poly(N,P) bit time and space; more precisely polynomial in 2^r_i, P and encoded input N (determinant/Pfaffian arithmetic on O(mP+poly(N)) bits). Charge all 2^r_i evaluations, all digit probes, signed intermediates, FFT butterfly or direct Walsh, basis discovery and coefficient storage. A huge integer is NOT one unit of computational work. If P is large due to binary coefficients, the bound is pseudopolynomial in their values; cap and decline rather than materialize it. No dependence on the number of matchings beyond their logarithmic count bound.

Optional known-theorem extension: for a supplied cellular embedding in orientable genus g, Cimasoni–Reshetikhin's 4^g-Pfaffian weighted identity can replace one Pfaffian at each character. The linear combination must be computed before Walsh inversion and decoding. This extension and general planarity/orientation acquisition were not executed. Neither a general graph Pfaffian certificate nor minimum genus discovery is asserted.

## B. Exact joint cut composition (PROVED)
Given independent blocks i=1..b with all global constraints sum_i d_i=t and XOR_i s_i=s*, no omitted occupancy/guard constraint, and a supplied binary factor tree. Define U_J=sum_{i in J}U_i for each node's leaves. Every extendible partial syndrome belongs to U_J intersect (s*+U_out). Empty intersection rejects; otherwise an affine coset of dimension w_J=dim(U_J intersect U_out), discovered by Gaussian elimination. Can also choose a linear baseline and shift to zero as DS08. For integer quota a, let H_a be the set of blocks with any nonzero edge coefficient for a. If H_a empty, require t_a=0. At node J retain subtotal only for active rows a with H_a meeting J and Jc. For internal rows require exact t_a before discarding. Exterior-only rows contribute zero. Use signed bound M_Ja=sum_{i in J} h_i max_e |d_ea|; valid subtotal range [-M_Ja,M_Ja]. Define
 K_J=2^w_J product_{a active}(2M_Ja+1).
At leaves filter full exact joint support by internal quotas and coset membership; at joins add child partial quotas, XOR syndromes, check all newly internal rows before forgetting them, and filter by outside linear span. If row has support in only one child it is carried from that child (or checked already). Counts multiply at joins and add on merged keys; no independent marginal gluing. A backpointer retains an actual pair of compatible child states. At root all quotas have been checked and syndrome equals s*. Induction gives exact count of indexed matching tuples and an actual compatible tuple iff count positive. Counts are bounded by 2^sum m_i, hence polynomial bit length. Guard masks on a certified function of this joint key require no additional state dimensions (DP09); all other guards must be retained as extra observations or declined.

Time <= poly(N)*(sum_i 2^r_i poly(P_i) + sum_J K_J + sum_joins K_L K_R), including attempted failed joins, rank computation, all closure calls, and a polynomial-factor witness reconstruction. The poly(P_i) is explicit polynomial in radix product, not logarithm of P_i; the polynomial also covers exact arithmetic. Space <= poly(N)*(sum_i 2^r_i poly(P_i)+sum_J K_J) for retained tables and backpointers on the same execution, CM <= (T+1)S. One may charge all local coefficient acquisition sequentially or retain it once; never charge shared table cells as independent copies unless physically copied. DAG states/edges, all attempted joins, guards, original decoder IDs, and lift are charged. With all local 2^r_i, P_i and cut K_J polynomial in N and a polynomially supplied tree, this is uniform deterministic polynomial time; no bound on total number of quota rows or total syndrome rank. Discovery of an optimal or universally low-width tree is OPEN.
