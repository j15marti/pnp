## Scoped theorem
For K explicit pin contexts and each literal l, initialize K-bit vector D_l marking assumed true l. For each clause (l_1 OR ... OR l_w), OR into D_l_i the intersection of D_not_l_j for j != i. Mark conflicts when all clause literals false or both signs of one variable true in a column. Iteration monotonic, <=(2r+1)K bit insertions. Each inference sound by induction; scalar UP derivations included by induction, and every conflict bit yields a scalar UP contradiction. Surviving columns equal scalar UP fixed points; discard contradictory-column conclusions except their conflict. Singleton implication l=>b yields not l OR b; contradictory pair guard yields its negation. Check each via reverse unit propagation (RUP) and reclose root after insertion. Context-relative facts remain guarded outside context. Prefix/suffix intersections cost O(w) bit-vector ops per clause, each charged at full K-bit width; explicit masks/guard lists paid. All singleton/pair guards count 2r+4 binom(r,2)=2r^2. Persistent distinct width-two clauses decrease finite numeric credit <=2r^2. Complete scans and checking per epoch polynomial for fixed chart polynomial in original N; no fresh reserve per residual. Peak masks O(rK) bits plus registry, cumulative memory <=(T+1)S on same bounded execution. Neither universal coverage nor global representation acquisition is proved.
