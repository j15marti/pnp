## 2. Hybrid exact model

Each row has a nonnegative binary integer owner-cost vector c, a q-bit XOR tag g, a distinct row ID and a certified lift if used as a physical source representation. Feasibility iff sum costs <= K and XOR tags = t. No hidden constraints.

Conditional results retain original guards.

Subtract ownerwise block minima (I06). Select positive scales d_i for owners. A GOOD block has residual rows 0 or d_i e_i, with the same tag for every row of that block. A BAD block is binary, with residual row vectors r_b(0),r_b(1), and arbitrary tags. Singletons can be fixed into offsets. All block classification and difference grouping are polynomial scans on explicit rows. For an automatic candidate, choose d_i as the least positive normalized entry at owner i, or use gcd of its positive entries; absence of such entry permits d_i=1. One can try a fixed finite list of such rules and charge failed scans. A certified supplied scale vector is also allowed; do NOT optimize scales/partition for free. Good/bad classification is automatic once scales are fixed; if any non-good nonsingleton is not binary this particular terminal declines. Theoretical recognition from the chosen scale is proved; code is given scales (not an optimized-scale search).

Subtract bad row-zero baselines too, producing integer residual budgets R_i(0), and XOR all fixed good tags plus bad row-zero tags out of t. Bad block b has signed difference D_b=r_b(1)-r_b(0) and tag difference e_b=g_b(1) XOR g_b(0). Group by identical (D_b,e_b), retaining IDs and offsets. Let G be number of groups, m_j multiplicity, k_j integer in [0,m_j]. For each k define

  XOR_j (k_j mod 2)e_j = adjusted target.
By RT06, all counts in bounds lift to actual bad choices; any choices with those counts have exactly the same aggregate cost and tags. The good choices are unrestricted by tag once good constants are removed. Do not apply this to arbitrary varying good tags.

## 3. Theorem A: exact flow/count compatibility (PROVED)
For any such instance and any integer count vector satisfying its tag condition, require R_i(k)>=0 for every owner. For each good block add one unit of source capacity and separate row arcs to its unique residual owner (or dummy if zero), with a dummy capacity B_good. For owner i set capacity
  U_i(k)=floor(R_i(k)/d_i),
optionally cap at B_good. Then the original fixed-count instance is SAT iff a full integral flow exists. Proof: any actual assignment pays exactly its bad aggregate plus d_i times the number of good rows assigned to owner i, so it is a full feasible flow. Conversely integral flow saturates one arc per block, preserving its row ID, and selecting any k_j bad IDs in each group gives a witness satisfying original costs and tag. Owners with no good incidences still require R_i(k)>=0. All arithmetic has polynomial input bit length (multiplicities explicit). This is an exact combination, not simultaneous independent minimization of the owners.

A failed fixed-count state has a certified qualitative obstruction: either negative budget, failed tag, or a Hall cut of good blocks whose available owner capacities sum to less than their number. These conclusions are conditional on k; do not claim an unconditional contradiction until all feasible counts are ruled out or the full integer system is refuted.

Enumerate P_bad=product_j(m_j+1) count vectors sequentially, with exact max flow and witness lift at each survivor. T<=P_bad poly(N), S<=poly(N), CM<=(T+1)S; N includes explicit rows, binary costs/tags, IDs, and guard description. DP01 box conservation applies to this count space: mu=2V-1, disjoint children sum mu-1. Closure or Hall certificates may reduce it, but large P_bad is not a lower bound. A fixed-G terminal remains polynomial even if the number of distinct GOOD row types is arbitrarily large.

## 4. Theorem B: remove multiplicity enumeration via a small mixed-integer interface (PROVED, NOT executed)
Let J be the number of active good owners i for which some D_ij is NOT divisible by d_i. A count-aware integer capacity is only required at such misaligned owners. Other active owners have an integral affine capacity for every integer k:
  U_i(k)=floor(R_i(0)/d_i)-sum_j (D_ij/d_i) k_j.
For all owners require R_i(k)>=0. Introduce real nonnegative variables f_br for every good row; sum_r f_br=1 per good block; let L_i(f) be the sum of its row flows to i.
For aligned active owners impose L_i(f)<=U_i(k). For each misaligned active owner introduce one INTEGER u_i with 0<=u_i<=B_good, d_i u_i<=R_i(k), and L_i(f)<=u_i. The dummy is free up to B_good. Each integer k induces integer capacities, so real flow feasibility implies integral max flow feasibility; reconstruction reruns integral flow, never rounds f componentwise.
For protected tags enumerate epsilon in {0,1}^G, reject patterns failing the XOR target, substitute k=2v+epsilon where v is integer and 0<=k_j<=m_j. There are G+J integer variables, arbitrarily many real flow variables, and polynomial-size rational linear inequalities. The two directions of equivalence follow from Theorem A; given a feasible integral k choose u_i=min(B_good,floor(R_i(k)/d_i)); conversely a feasible real flow at integer capacities implies integral flow.
Use Lenstra-type fixed-integer-dimension MILP feasibility (Lenstra 1983 section 5, p.547; modern parameterized formulation cited below). Hence for a certified chosen representation the deterministic time is
  T <= 2^G f(G+J) poly(N)
for a computable parameter function f, with polynomial exponent independent of G+J using the FPT form. For fixed G+J this is polynomial independent of magnitudes and multiplicities. Alternatively use gcd scales so J=0, possibly increasing G. Do not assume a logarithmic bound on G+J suffices for unspecified f. If only a decision implementation is available, recover k by O(G log(B+1)) interval feasibility calls, then reconstruct exact rows by max flow. Charge the calls. For the MILP path S<=O(T+N) conservatively on a standard bit model; CM<=(T+1)S. No variable-parameter polynomial-space claim. This route is a mathematical reduction to a known theorem, not a benchmark of an exact Lenstra implementation. The simpler enumeration/flow backend was executed.

Why J matters: fractional capacities are not safe even if raw LP and price closure survive. Three blocks each choose cost (2,0) or (0,2), K=(3,3), d=(2,2). Half of every row satisfies real constraints, and all rows individually affordable; every integral assignment pays an even total at each owner, with sum 6, so would need (3,3), impossible. Correct capacities are (1,1). Also arbitrary varying protected good tags cannot simply be imposed as a parity equation on fractional flows: two blocks choose unit owner A/B, capacities (1,1); tag 1 for first A or second B, tag 0 otherwise. Both integral feasible assignments have XOR 0; half flow satisfies real tag sum=1. Both counterexamples were exhaustively checked. Keep tag-constant good restriction or find a separate exact tagged flow method.
