## 2. Persistent-context worklist theorem
Fix an append-only explicit non-tautological CNF chart on r Boolean variables, fixed finite guard dictionary G of K contexts, initial checked chart C0, and an a priori bounded set of admissible checked exported clauses. Each literal l has K-bit mask D_l recording derivability in each guarded context. Initialize precisely the guard assumptions and process every initial clause. For C=(l_1 OR ... OR l_t), add intersection of D_not(l_j), j != i, to D_l_i, and mark contradiction on intersection over all t or D_l intersect D_not(l). All additions are monotone. Conflicted contexts may acquire both signs; conclusions only extracted from surviving contexts or as their explicit contradiction. Coordinatewise this is exactly the unit-rule least fixed point (continuing after contradiction does not affect any other context). Finite fair worklist processing reaches the least fixed point. When a certified new clause is appended, preserve all old masks, enqueue the new clause, and enqueue each clause with dependency on a changed input mask. The previous fixed point is contained in the new one since rule set only grows. Induction on new updates shows no mask exceeds the cold least fixed point. Terminating fair saturation is closed under every old/new rule and includes initial guards, so it contains that least fixed point. Equality follows. No arbitrary guarded substitutions, reset, or nonaffine projection allowed within this bank.
Each of 2r masks can strictly grow at most K times. Write L_final for total literal occurrences of the final clause pool and m_final for its rows. Each new clause needs an initial enqueue; each input dependency is triggered at most K times, whether its clause is present from intake or appended later. Thus total enqueues/scans <= m_final + K L_final, with queue dedup only reducing cost. Prefix/suffix intersections and mask unions need O(t) vector operations per scan; charge O(K) bit operations per vector (or explicit ceil(K/W) machine words with charged word operations). A loose fixed-chart bound is O(K*(m_final+K L_final)*w + indexing + candidate queries + all verification). Guard generation, candidate scans, clause-key checks, insertion, output and scalar RUP replay separately charged. If guard and export widths k,w fixed, K=O(r^k), potential clause capacity Q=O(r^w), all proof/context banks polynomial in original N provided chart and source maps polynomially acquired. One monotone credit is unused clause dictionary slots plus missing literal-context bits plus missing bad bits. Adding a distinct certified clause consumes one slot even if it was algebraically dependent in W; mask growth consumes bit credit. This separate export credit is needed because algebraic span dimension alone need not decrease on a cross-method export already in W. A proper affine coordinate contraction can pay a bank rebuild only with separately reserved fixed-polynomial lexicographic budget (at most r initial coordinate retirements, no reintroduction); arbitrary nonaffine changes, branch fanout and new guard directions remain OPEN. Cumulative memory <= T*S under a serial bit machine, not measured here. No oracle, finite bit masks; JS BigInt implementation charged at full width. Fixed scheduling cannot guarantee a productive event at saturation.
