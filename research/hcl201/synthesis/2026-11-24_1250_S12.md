## 1. Model and target-conditioned reduction

Every D_j sums to zero. For fixed core assignment the equations are D z + A_R y = b' with integral unit y; all original guarded affine constraints are enforced by the chart.

Delete one balance row r. The remaining equations imply the deleted row because all full columns and b' sum to zero. This is an exact redundancy, not a relaxation. For each isolated bit use projected D'_j and define q2(r)=number with sum_i |D'_ij|>2. Find r minimizing q2 by enumerating all row deletions, including the original reservoir when present. This is polynomial on the supplied graph; no claim of global optimization over arbitrary row transformations. Every S11 ordinary unit-incidence column has projected norm <=2 for any r, so q2<=q from S11. Zero columns can be fixed arbitrarily for decision only.

Fix the p core bits and the q2 exceptional bits in guarded jobs; all remaining unit recourse and isolated columns have l1 norm <=2. ## 2. Exact signed occurrence gadget (PROVED)
For arbitrary explicit integer system Bx=c, x in {0,1}^m, suppose every column has l1 norm <=2. Represent its nonzero coefficient entries as at most two signed occurrences, including two occurrences at the same row for coefficient +2 or -2. At positive occurrence let local activation a=x_j; at negative occurrence let a=1-x_j. Row i then requires exactly k_i=c_i+number of negative occurrences at that row activations. If k_i outside [0, number of occurrences at row i], UNSAT. Make k_i distinct slot vertices. Make a separate port vertex per occurrence, adjacent to every slot of its row.

- Two occurrences of the same sign: join the two ports by an internal edge. Both must be matched to slots (both active), or matched to each other (neither active). This enforces equal activation, including a repeated same-row coefficient 2.
- Two occurrences of opposite signs: create a mandatory middle vertex adjacent only to the two ports. Exactly one port must match the middle and the other a slot. This enforces complementary activation.
- One occurrence: attach a private optional leaf to its port. The port can either match a slot (active) or the leaf (inactive).
- Zero occurrences: no gadget; select 0 for decision unless a guard requires otherwise.

All slots, ports and middle vertices must be covered. Convert partial saturation to ordinary perfect matching by adding a clique on optional leaves, with one extra optional dummy vertex if the total number of vertices before the clique is odd. A covering matching of the mandatory vertices has an even number of unmatched optional vertices in the resulting even-sized graph; pair them inside the clique. Conversely, any perfect matching covers all mandatory vertices, and the only external leaf adjacency is its own port. If there are no optional leaves and odd mandatory order, the dummy remains isolated and correctly prevents perfect matching.

Every solution of Bx=c gives exactly k_i active occurrences per row, match these bijectively to row slots, satisfy each gadget internally and pair leftover optional vertices. Conversely a perfect matching gives exactly the required activations and each column gadget enforces its original shared binary value; decode from the first port (complement if negative). Restore pinned variables, verify Bx=c and then the full redundant row, indexed original arc constraints and protected affine target. This is exact on both labels. There is no relaxation of 2x=1 to an arbitrary capacity-two flow. Matching multiplicities are NOT source counts (slot permutations and optional pairings can introduce many lifts).

The graph has O(L) vertices and O(L^2) edges for L total explicit occurrence length (if quota bounds pass). General graph perfect matching is polynomial via Edmonds. Negative answer follows from exact maximum matching, or a separately extracted Tutte witness; the experiment did not extract general Tutte barriers.

## 4. Sharp width-three obstruction (PROVED, abstract model)
Reduce 3-dimensional matching / exact cover by triples. Universe U has 3k elements, allowed triples T; choose binary z_T with sum_{T contains u} z_T=1 for each u. All columns have l1=3 and all coefficients positive. Compile into S11 by making one reservoir-to-element unit switch per triple occurrence and synchronizing all three occurrences in that triple by affine equality. Demand 1 at each element and -|U| at reservoir. No other recourse needed. After deleting reservoir, exactly the incidence system above remains, p=0; hence general width-three feasibility is NP-complete, even with unit coefficients, unit physical capacities and tiny nonreservoir demands. Membership in NP by checking a word. This is a barrier to extending the sufficient width-only rule, not a separation or unrestricted runtime bound. Some width-three inputs are easy and another representation may bypass q2. No strict source physical transfer is claimed. Equality grouping alone cannot solve this general model. For any larger width cap the same subfamily is included.

## 5. Infinite family escaping S11 branching
Three disjoint odd cycles each of length L>=3 odd, plus one common hub joined to one vertex of each cycle. One independent bit per edge, all vertex quotas one. Realize each edge bit by two positive occurrence switches from the reservoir, tied by equality; its full D=e_u+e_v-2e_reservoir. S11 counts all 3L+3 such columns as exceptional; after reservoir deletion every column has l1=2, q2=0. No row-support pin at root since each row has degree>=2, total vertex count even. UNSAT: deleting the hub leaves three odd connected components; a perfect matching would need an edge to the hub from each, but hub capacity is one. Add a single cross edge between the designated vertices of two different cycles: select that edge and hub edge to third cycle, and match the remaining even paths. SAT. Both labels solved in one matching call each, not a hardness claim for S11's entire portfolio or other algorithms (Tutte itself is an easy shortcut).
