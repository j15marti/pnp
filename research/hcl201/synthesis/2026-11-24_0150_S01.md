## 2. Joint-product peeling theorem (new synthesis)
Let E be the ambient GF(2) vector space of full occupancy and syndrome, and S_i the exact local support vectors of partial matchings saturating region-exclusive vertices. I01 splitting ensures that sum of independently chosen local states equals target z*=(all-one occupancy,c) iff their union gives a globally compatible PM: no vertex is present in more than two regions, so odd occupancy is exactly one. This condition, NOT physical vertex disjointness, permits independent product algebra. Without splitting or a collision check, odd-star controls invalidate it.

For every nonempty S_i choose a real baseline a_i, define V_i=span(S_i+a_i). Compute exact affine hulls by I01 dummy completion and M01 finite-field matching span; reject empty local support. First test z* in sum_i(a_i+V_i). Keep all unconditional equations. Maintain removed set P, remaining R, offset a=sum_{i in P} a_i and W=sum_{i in P} V_i, invariant:

    sum_i S_i = a + W + sum_{i in R} S_i.

Initially trivial. If rank(pi_W(V_i))<=1 for i in R, the image pi_W(S_i) is exactly its affine hull: nonempty singleton or pair. Hence W+S_i=a_i+W+V_i. Absorb i, update a,W,R, and renew certified affine/available closure. No enumeration of all local states is required for discovery. For rank one, choose a linear functional u annihilating W and nonzero on V_i, request a local matching whose u-observation is opposite to u(a_i). Such a witness exists by definition of V_i and is obtainable by known deterministic correct-parity matching on I01's dummy-completed graph with edge labels projected by u. For rank zero retain baseline. Record each witness pair and prior W basis. Each stage consumes one leaf. Every removed leaf is realizable by its stored baseline or alternate in combination with previously removed leaves; induct backwards, using rank-one quotient to pick the required coset and then lift the remainder in prior W. This does not assert that each S_i itself is affine.

Decision after peeling is exactly pi_W(z*+a) in sum_{i in R} pi_W(S_i). For a successful residual tuple retain actual local witnesses, compute the missing original joint vector and lift backwards through removed leaves; root full occupancy proves no collision even though regions may share vertices. Verify on expanded graph and drop I01 selector edges to obtain original PM. This is decision/search only, not count preserving. All peeled => deterministic polynomial terminal with no tree discovery, even at large original global rank. A rank-one observation probe also applies to any independent additive factor with a proven exact hull and parity-witness algorithm; do not apply to merely necessary obstruction predicates or non-independent products.

**Canonical fixed point.** Eligibility is monotone in W: enlarging W cannot increase projected V_i rank. Therefore any maximal greedy peeling order reaches the same removed set, by induction that the steps of one order must belong to any other terminal removed set. W and offset are then independent of order (given fixed baselines), though witness lifts can differ. No exponential order search. This is a finite monotone closure with <=h productive removals. A later source-certified change of local support invalidates affected hulls and must be recomputed, not silently reused. Full multi-channel closure is not assumed free.

## 3. Exact cut-width contraction theorem
Fix any original cut X|Y. Let A=sum_{i in X}V_i, B=sum_{i in Y}V_i. Since W is spanned by whole removed factor spans, W=(sum_{P intersect X}V_i)+(sum_{P intersect Y}V_i)=W_A+W_B, W_A subset A, W_B subset B. Thus

    pi_W(A) intersect pi_W(B) = pi_W(A intersect B).

Proof: for a' in A,b' in B with equal image, a'+b'=w_A+w_B. Then a'+w_A=b'+w_B lies in A intersect B with the same image. Reverse inclusion immediate. In particular, projected residual spans on either side equal the projected original spans since removed V_i map to zero. Rank-nullity gives the exact formula:

    kappa_new(X|Y) = kappa_old(X|Y) - dim(W intersect A intersect B).

It follows that every cut width weakly decreases; the original branch tree can be pruned to remaining leaves and degree-two nodes suppressed, with no width increase or rediscovery required. Strict reduction occurs precisely when eliminated span intersects the shared-information space nontrivially. This is a true joint-width contraction, unlike I01's common invertible gauge shear. Arbitrary quotienting is unsafe as a width claim: A=span(e1), B=span(e2), W=span(e1+e2) changes width 0 to 1. The whole-factor condition is essential.

**Important interface caution:** projecting joint occupancy can erase some occupancy coordinates. Do NOT use I01's fixed-occupancy leaf predicate unless all occupancy coordinates required for that test remain determined. Exact residual membership must instead query the projected labels of the dummy-completed graph (including occupancy observations), or retain protected observations as part of the global target, or prove an exact alternate predicate. Projected rank-one queries still use M01 parity matching. For general higher-rank projected support, polynomial deterministic membership remains open; randomized Fourier-Pfaffian or exact enumeration must be charged. No support hole may be filled just because it lies in an affine hull. For an exported relation with free external observations, the correct representation retains offset, W and residual support (with witness lifting), not merely the quotient; the decision theorem fixes the entire target.

## 4. Charged deterministic terminal and progress ledger
After peeling, use I01's target-conditioned tree DP on the residual projected supports. For each cut use intersection of shifted affine hulls; at most 2^w live states, where w is maximum remaining cut rank. Leaf testing uses actual projected support. With h polynomial, exact leaf membership cost C(N), discovery cost D(N), the same sequential execution has T <= poly(N)+D(N)+2^w poly(N) C(N)+2^(2w) poly(N), S <= poly(N)+2^w poly(N)+S_C(N)+S_D(N) (retaining all tables/witness pointers, sequential calls), cumulative bit-cell memory <= T*S. Bounds include encoding, splitting O(E), dummy clique O(B^2), GF(2) basis, at most O(h^2) rank tests, <=h extra parity-search witnesses, failed tests, target pruning, basis storage, recovery, source verification. Fixed-field bit operations polynomial in encoded N; no arithmetic magnitude oracle. If a supplied/discovered w=O(log N) and every leaf C polynomial, deterministic polynomial. Jeong-Kim-Oum gives polynomial discovery for fixed w only, not arbitrary logarithmic w. If all peel, D and DP unnecessary. Randomized leaf tests lead only to RP under a global polynomial bound with union-bound error budget and witness verification, not P=NP.

Global progress ledger for a frozen exact independent-factor representation: (|R|, dim(E/W)) lexicographically decreases on each absorption, even when rank-zero leaves removed. Width weakly decreases on inherited cuts. This gives termination of this specific preprocessing, NOT a global potential under arbitrary representation switches. When new constraints or decompositions are proposed, record source equivalence, encoded sizes, spent discovery and verification, changed dimensions, and retained witnesses. Forced-information closure must run initially and after each committed deduction; if additional channels change the base, recompute. At stagnation perform affordable certified unconditional closure before branching. Conditional probes remain guarded. Full all-channel loop needs an explicitly capped or globally decreasing resource measure; exact local closure and rank descent do not guarantee it. An OPEN subroutine is not UNSAT.
