## Theorem 1: exact disjoint affine remainder
Let A be a given affine carrier over GF(2) in r free coordinates containing every model of F. Let k checked conditional contradictions F AND G_i -> false be given, each G_i an affine flat, represented by an ordered finite list of affine equations. For any live affine cell C, subtract G_i by forming the disjoint cells C intersect eq_1 intersect ... intersect eq_(j-1) intersect NOT eq_j, one for each equation j of G_i. Drop inconsistent intersections by GE; omit the final all-true intersection. Every point of C outside G_i has exactly one first failed equation, and every retained point is outside G_i. Thus iterative subtraction produces a disjoint exact representation of A minus union G_i. Empty guard (whole space) removes all cells, inconsistent guards remove none. If equations lists have lengths r_i, cell count <= product max(1,r_i) (unless whole-space guard removes all). Reduce each guard on A first to at most r independent equations, or detect inconsistency. Fixed k<=5 then at most max(1,r)^5 cells; acquisition, intersection, counting and maps polynomial in the already authenticated representation. Counting each disjoint cell via 2^(r-rank) gives exact uncovered volume; empty remainder proves coverage. No free enumeration of Boolean words. Every cell inherits the source and exact guard; do not merge overlapping cell conclusions as unconditional. This procedure handles a nonaffine uncovered union with full affine hull where rank-only compression may stall. The same first-failure construction can grow exponentially for unbounded k (e.g. guards requiring both bits zero on independent pairs); no universal branch amortization follows.
Peer T1 rank firewall #7228625233 audited symbolically: in an irredundant affine cover of size k, choose an exclusive point of guard i. For each other guard choose a violated defining equation; imposing the opposite equation gives an affine flat through the exclusive point of codim <= k-1. By coverage this flat lies in guard i. Hence codim of i <= k-1 relative to A. A noncover similarly yields an uncovered flat of codim <= k using an uncovered point. This is an existence fact, not an efficient discovery theorem for normals. Our explicit remainder makes the uncovered set usable without enumerating its points. 120 seeded dense affine cases in dimension seven, 15,360 pointwise partition checks; peak 50 cells, all partial. Additional hand-coded controls: complementary hyperplanes/full cover, zero-equation whole-space guard, inconsistent guard, partial rank-two flat; passed in isolate. No universal completeness claim.

## Theorem 2: minimum available core union, fixed guard budget
Given M independently checked guard/core pairs (G,C), each C an original owner subset sufficient for F_C AND G -> false, enumerate every candidate subset of at most five pairs. Check exact guard coverage (at most 31 affine intersection counts each) and choose minimum |union C|, breaking ties by guard count. O(M^5) trials, fixed polynomial after paid acquisition; no inference from majority/intersection of incompatible cores. The union suffices, not necessarily an inclusion-minimal or globally minimum original core. Fixed candidate registry exact only. Individual smallest cores need not minimize union (e.g. two guards with alternative core sets {a}, {b} or the common set {c,d}; extend to three guards to make common two-owner set preferable to three disjoint singleton cores). Core cost and guard count are distinct objectives, so retain Pareto frontier. Choosing fixed number of guards does not make discovering them free.
Original-owner compression: signed normalization groups B owners whose four signed literals agree up to permutation and global sign reversal. They impose identical integer balance predicates on the same signed carrier. With all E/edge constraints retained, any single representative owner enforces the entire group's predicate. For a certified projected contradiction, walk each used factor's complete bucket ancestry, replace each normalized group by one original B owner, and independently rederive the guarded restricted-source chart and contradiction. No assumption that dropping owners preserves all source models; this is a sound negative relaxation. This avoids charging duplicate owner IDs as independent hard support.
