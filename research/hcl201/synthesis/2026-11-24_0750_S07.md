## Theorem A: no count enumeration for aligned unit transfers
For each good block subtract its componentwise minima; require residual choices 0 or d_i e_i for positive owner scale d_i, with exact tag sets and source IDs (explicitly supplied or paid acquisition). A binary block has original rows c(0),c(1); subtract c(0), XOR tag g(0) from target. Recognize its normalized signed cost difference D_i=(c_i(1)-c_i(0))/d_i in {0,+1,-1}, at most one +1 and at most one -1. Zero coordinates and absent endpoints allowed. Group identical ordered endpoints and full tag difference e=g(0) XOR g(1), retaining all individual IDs. Let m be multiplicity. Fixed rows are absorbed into offsets. For chosen scales, recognition/grouping are polynomial; unrecognized inputs return UNKNOWN for this route. Good/binary overlap may be classified either way. Do not optimize scales for free.
Let R_i be K_i minus all baselines, U_i=floor(R_i/d_i), possibly negative. Create owner vertices i, reservoir r, and one vertex for every good block. Interpret b(v) as net inflow demand. A good vertex has b=-1, one outgoing unit-capacity arc for each row to owner i (load 1) or r (load 0), tag equal to the row tag. For each binary group add arc from minus owner to plus owner (replace absent endpoint by r), integer capacity m, tag e; its flow is count k. Zero difference can be a reservoir loop. Each owner has demand U_i and an incoming zero-tag slack arc r->i, capacity max(0,U_i+B) where B is total original block count. Set b(r)=number_good-sum_i U_i so total demand is zero.
Owner equation: good_load_i + incoming_transfer_i - outgoing_transfer_i + slack_i = U_i. Thus net normalized load <= U_i exactly, even with negative residual budgets; do NOT reject a negative U_i before allowing outgoing transfers. Slack bound safe since net load >= -B. Exact floor follows because all variable cost increments are multiples of d_i. Reservoir equation follows from all other balances. All arcs retain source IDs. ## Theorem B: exact residual support factorization and affine span
Take one integral feasible flow f (ignoring target tag). Its residual graph contains forward arcs where f<cap and reverse arcs where f>0, both labeled original g_e in GF(2)^q. Every feasible integral flow f' differs by an integral circulation on the residual graph (choose sign per original arc). This circulation decomposes into directed cycles, all within strongly connected components C. Thus changes across SCCs are independent: define S_C to be the tag differences realizable by integral changes supported in C obeying capacities and conservation. S_C contains zero. Every f' decomposes this way; conversely combine arbitrary independently feasible changes in distinct SCCs, since no original edge can have internal residual arcs in two different SCCs. Therefore exact attainable tag support is
  tag(f) + sum_C S_C.
All directed simple cycles individually admit one unit augmentation from f; each contributes actual witnessed tag difference. If a simple residual cycle uses both directions of the same original arc their signed change and tag cancel. No assertion that arbitrary cycles within one SCC can be augmented simultaneously.
Let V_C=span(S_C). Every feasible difference decomposes into cycles, and every simple cycle gives a feasible difference, hence V_C equals the span of directed cycle tags. Construct an actual cycle basis of tag vectors in polynomial time: root each SCC, choose directed paths P_v:r_C->v and Q_v:v->r_C. For every vertex use closed walk P_v Q_v; for every residual arc u->v use P_u (u,v) Q_v. Split each walk into simple directed cycles. These O(V+E) walks of polynomial length span all directed cycle tags: for a directed cycle, XOR the edge walks and the vertex walks for its vertices, canceling P_v,Q_v. Keep independent cycle tags by Gaussian elimination, with actual simple cycle IDs. This gives exact affine hull tag(f)+sum V_C. It is a sound negative test: if target difference outside sum V_C, reject. It is NOT a sufficient test in general.
For a single protected bit, each V_C has dimension <=1, so S_C=V_C and all reachable tags are decided. This extends M07's fixed-count one-bit algorithm to count-variable aligned transfer networks without count enumeration.

By induction the aggregate support of absorbed SCCs equals W; after absorption it is W+V_C. When rank increases by one, choose one actual simple cycle from the stored basis with tag outside old W and retain that witness. Consequently every vector in W can be realized by at most one chosen cycle per absorbed SCC; solve a Gaussian linear combination, augment only selected cycles, no capacity conflict across components. Rank-zero absorption needs no cycle. Eligibility monotone under growing W; the maximal absorbed SCC set is order-independent. Scan/restart after each absorption; at most number of SCCs.
