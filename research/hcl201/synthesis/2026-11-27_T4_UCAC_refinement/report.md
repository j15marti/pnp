## New scoped theorem: productive-frontier restoration
Let a fixed finite CNF F on r named Boolean coordinates, G a fixed explicit bank of K partial assignments, and E an append-only set of sound learned clauses from a dictionary of size M. Retain all original clauses in a passive/active registry. For each context maintain signed-literal mask D_l and contradiction mask B. A context is dead iff sound propagation proved a contradiction; never transfer bits across contexts. Initially use a subset of original clauses (here width<=2); all learned clauses are active. Reclose active rules with an occurrence queue. A passive original clause C is productive in a live context iff all its literals are false, or all but one are false and the remaining literal is not yet known true. Compute this predicate exactly using intersections over masks of complements and excluding B. At an active fixed point, scan all passive clauses and activate productive ones; close and repeat. If no passive rule is productive then the current live literal masks are closed under *every* clause of F+E; since all updates were valid UP derivations, they equal the least full UP closure on each still-consistent context. Conversely every marked dead context has a finite UP conflict proof in F+E. If full UP refutes a context that remained live, a first missing rule would contradict full closure. No need to preserve additional bits in dead contexts. Same deterministic candidate selection from the same contradiction set gives identical learned sequence to eager full closure when both complete and all candidates replay. This is exact for fixed registry and append-only learned clauses, not semantic SAT equivalence of the coarse subset. Coarse UNSAT is sound; coarse fixed point is UNKNOWN. Common root UP is always run on full F+E in all arms.

## Why global rule compression fails on dense guard banks
A non-tautological ternary clause with distinct variables has a pair guard falsifying two literals. On the initial unrestricted pair bank with no other propagated facts, this necessarily triggers the third literal. Therefore every original ternary clause is restored if initial active constraints are absent and pair contexts are all registered. More generally prior propagation can already satisfy, subsume or refute that guard, so not every ternary row must restore on an arbitrary input. This explains the RANDOM result exactly, and falsifies the assumption that global coarse width always buys useful compression. Higher-width clauses can be truly dormant for a given context bank: a 4-clause has no UP action from only two pins. Full closure then cannot activate it without other deductions. Refusal is relative to UP, not unrestricted hardness.

## Exact dynamic quotient of contexts
For same formula F, if nonconflicting guards g,h have identical complete UP literal closure U_F(g)=U_F(h), then after every common append-only extension H, U_(F+H)(g)=U_(F+H)(h) including conflict status. Proof: each original guard is contained in U, every bit in U is derivable from each original guard using F, and closure is idempotent, monotone and remains valid after clause addition. Compute closure of U under F+H to obtain exactly either updated closure. Equal explicit literal-set keys allow a shared state; retain both immutable guard IDs and proof provenance. All conflict contexts may share a dead flag, not an unguarded certificate. Hash match alone is insufficient. Different formulas/guards cannot be merged from size/rank.
