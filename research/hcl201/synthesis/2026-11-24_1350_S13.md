## 2. Exact target-face theorem (PROVED using standard rational LP)
Set S={Dx:x in X}, Q=conv S. Optimize any rational normal a on Q by maximizing a^T D x over X. Q is a well-described rational polytope: integer vertices with coordinates bounded in bit length by the encoded input, and rational facet/equation complexity polynomial by determinant bounds. The standard strong separation/optimization equivalence for well-described rational polytopes (GLS) applies, including lower-dimensional cases. We give an explicit normal LP to make acquisition obligations transparent.

Let C_b={(a,t): |a_i|<=1, -H<=t<=H, a·(s-b)<=t for all s in S}, H=1+k max coordinate magnitude of s-b, bounded using input coefficients and variable bounds. Separation checks box constraints then calls the weighted oracle to find a maximizing s; if the inequality fails, return that actual linear inequality. This is a strong separation oracle with polynomial-bit inequalities. Rational LP over C_b is polynomial in input and oracle cost. Minimize t. If b outside Q, strict separation of a point from a compact convex set gives some normalized a with max_s a·(s-b)<0, and conversely a negative optimal t proves all source words miss b. This is certified UNSAT. If b in Q the optimum is zero (a=0 achieves zero). No need to enumerate S.

For b in Q define K_b={a: |a_i|<=1, max_s a·(s-b)<=0}. All its normals expose a face containing b; separation again uses one weighted optimization. Discover a basis a_1,...,a_h spanning K_b by rational Gaussian elimination and LP: start with zero span; for a basis u of its orthogonal complement maximize and minimize u·a over K_b. If every extremum zero, the current span is complete; otherwise add a returned independent normal and repeat. At most k additions, O(k^2) LP calls, polynomial bit lengths. Let A=sum_i a_i. Since each a_i·(s-b)<=0, equality for A holds iff equality holds for each basis normal, hence for every normal in K_b. The minimal face F_b of Q containing b is exactly
 F_b={s in Q:A·s=A·b}.
Every face of a polytope is exposed; a normal exposing the minimal face can be scaled into K_b. This proves the equality even if Q has lower affine dimension, or A=0 (then the face is Q).

Any exact-target solution lies in X_b={x in X:A·Dx=A·b}; conversely any point of X_b with Dx=b is a source solution. Thus reduction to this exposed optimizer face is exact. Scale A to an integer normal. Optimization of a new integer linear objective v on X_b requires only one ordinary weighted call on M*(A·Dx)+v·x, with M>2 sum_j |v_j|max(|l_j|,|u_j|). Check the returned primary score equals A·b. Pin queries may reduce the face to empty and must check the primary score. Never replace an optimal face by just its allowed edge set: tight odd-set constraints can be lost. Retain the exact objective equality or the lexicographic oracle.

If F_b is a singleton, every maximizer has Dx=b; return actual witness. Discover singleton status by coordinate maxima/minima on X_b (2k paid optimizations) or full normal rank. In particular this deterministically decides every instance with b outside Q or b a vertex of Q, with any number of side rows and exceptional columns. If a returned actual maximizer already has Dx=b even in a larger face, SAT. Otherwise retain the exact target constraints and return reduced state, not an UNSAT claim. No promised terminal for arbitrary interior targets.

An efficient sufficient subroutine: test explicit normal directions (e.g. individual rows and sums/differences). If target exceeds support, reject; if equals a nonconstant support bound, keep the exposed optimizer face. At most k strict projected dimension reductions. Lexicographic aggregate weights have polynomial bits across k such reductions, since each update multiplier has bit length polynomial in source size and individual direction bits. If using already pinned variables, a stale face score is not accepted without reoptimization and equality check. ## 3. Exact quota frontier (PROVED)
Consider binary width-three systems whose one distinguished row has entries in {-1,0,1} and deleting it leaves l1<=2. These are polynomial-time equivalent to general graph Exact Matching (EM, specified number of red edges in a perfect matching). Forward: apply S12 to B, label one designated slot edge per variable with sign-adjusted D_j (constant offset for complement), zero-column 4-cycle if needed. Thus each graph edge contributes w_e in {-1,0,1}, plus fixed offset. Shift by +1 per selected edge, changing target by |V|/2. Replace each edge uv by path u-p-q-v, with private p,q. In any perfect matching the path either uses its two outer edges (selected) or its middle edge (unselected); selecting exactly one outer edge leaves an internal unmatched vertex. Color precisely w_e+1 of the two outer edges red and middle blue. Every original PM lifts and vice versa, with exact adjusted red count. This is a constant-factor graph transformation. Reverse: one bit per graph edge, vertex quotas sum incident x=1, one extra row sum red x=k. Each red column has width three, blue width two, and the row is the only exceptional row. Both transformations preserve witnesses. General graph EM has classical randomized polynomial algorithms; do not equate it to ordinary weighted optimization or assume a deterministic solver. This is a reduction to a named algorithmic question, not NP-hardness of one-row extension. S12 X3C remains NP-complete with unbounded side rows.

An 8-cycle with alternate edges red/blue has two PMs, red count 0 or 4. Target 2 belongs to the convex hull and passes parity of the projected count, but is UNSAT; target 4 is SAT. Individual row support and extrema cannot reject 2; it is correctly left UNKNOWN by the implemented terminal. A mod-4 test could reject this simple example. No unrestricted lower bound.
