## New module: nested common conditional implications
Let C be the current exact CNF, l an outer literal and u an inner pivot. Let UP(C,l,u) and UP(C,l,not u) be independent, fully closed contexts. A contradiction in a context rules out only that guard; otherwise any UP-derived literal b holds in every model of that context. If both children contradict or derive b, then C entails (not l OR b). If both contradict, C entails not l. When only one survives, all its forced literals are valid under l because the other polarity is impossible. A failed pair also yields (not l OR not child_literal). Each conclusion is admitted against the same pre-batch clause DB; no circular simultaneous inference. A direct proof checks UP under negation of the new clause. If direct RUP fails, independently check both u polarities under negation of the new clause. These cover all extensions, so the new clause is entailed; all actual models survive. Never promote a fact from just one unresolved guard. Two contexts do not remain pending branches, only sound learned clauses persist. Root reclosure then repeats. A nonempty fixed point is UNKNOWN unless a verified full witness is available. Depth-one variant collects all unary implications from both polarities, plus binary clauses that are exact residual clauses in both contexts. Both variants are closely related to failed-literal probing and constructive disjunction, not claimed new proof-calculus primitives.

## Aggregate theorem and exact limits
Fixed registered original-coordinate universe r, base CNF width w fixed (for theory width can instead be polynomial), base size B polynomial in original native N. At most K=2r+4*binom(r,2) distinct non-tautological unary/binary clauses. Every nonterminal accepted batch contains a previously unseen clause, decreases K-|L| by >=1. Empty clause terminates. At most K productive epochs plus one failed scan, <=2r outer and <=4r(r-1) inner probes per epoch, all failed work counted. Full-scan UP costs at most r+1 passes over current C, each pass scans <=B+O(K log(r+1)) encoded bits with polynomial lookup/address cost, or naive linear variable map. Independent verifier checks at most 3 UP calls per emitted clause. Index creation, root closure, sorting and membership, witness verification, communication and proof storage are polynomial too; one loose bound O((K+1)(r+1)^3(B+K*log(r+1)+N+1)^2) serial bit work covers naive scans and linear lookup; no measured bit-time claim. Peak storage polynomial for one execution including copies, indexes, proof, exact reverse maps and initial input; sequential cumulative memory <=(T+1)S. Fixed polynomial cap on exact initial table acquisition remains required; no reintroduction of retired coordinates, no renewed reserve per epoch. A conservative combined projection/learning potential (K0+1)r+K0-|L| pays registry resets only on certified original-coordinate retirement, as in earlier T4. Not a universal progress proof.

## New scope barrier: resolution-width simulation
Consider any CNF with initial maximum clause width w, a persistent database of learned clauses of width <=k, and any rule whose proof of each clause D is an exhaustive binary guard tree of maximum depth d, with every leaf refuted by UP under negation of D and its path pins. Let W=max(w,k). Then any refutation by this rule can be translated into ordinary resolution with weakening of width <=W+k+d (and weakening can be eliminated without widening via subclause simulation).
Proof: fix a leaf with consistent pins P, |P|<=k+d. Unit propagation refutes the restricted clause database C|P using unit-resolution steps, all intermediate clauses width <=W. Lift every restricted clause E to E OR not P, with not P the disjunction of complements of every pin. Each restricted input comes from a nonsatisfied current clause by deleting falsified literals, all of which occur in not P; lifting is weakening of that clause. Each lifted resolution on an unassigned variable preserves the same common not P and width bound W+|P|. Thus a leaf derives D OR negated path pins (possibly a subclause). Inconsistent paths can be discarded or split on unassigned variables only. Resolve the two child results on the guard pivot repeatedly to derive D; no width exceeds k+d in this joining step. Induct on the chronological clause database, starting from input. If weakening is unwanted, replace each derived clause by a previously derived subclause whenever a pivot is missing; otherwise resolve the smaller parents. Width does not increase. Empty-clause termination yields a refutation in the stated width.
Known Tseitin contradictions on bounded-degree edge expanders have initial constant width and resolution refutation width Omega(n) for n graph vertices (Ben-Sasson/Wigderson 2001). Hence for these static CNFs any such refutation needs max(w,k)+k+d=Omega(n). Fixed k,d, even k,d=O(log n), cannot suffice. A successful exhaustive enumeration of all guard words at linear d would exceed polynomial work; this does NOT imply every adaptive tree is large merely from its depth, nor does it exclude different proof systems. GE on the original XOR equations immediately refutes these examples, and earlier exact projections/alternate encodings may escape the bound; no native transfer or unrestricted lower bound asserted. This distinguishes our missing load-bearing step from increasing the number of nested UP tracks alone.
