## A. Exact local affine/coaffine terminal (PROVED)
Let G be an explicitly encoded affine chart in F2^d, and D an explicit indexed DAG with s,t. Each edge e has an affine-conjunction guard E_e on the SAME chart. Reach means at least one enabled s-t path, SAT means a word in G with no such path. Empty affine sets and full chart allowed. No counts of private matchings, hidden tags, occupancy, or arbitrary E4/B4 to DAG compilation are assumed. Initial guard consistency, possible/mandatory reachability and single optional rank-one completion closure as GD16: if an edge completes a path with mandatory prefix/suffix, and its event has codimension one on the current guard, any safe word must violate that guard; impose its complementary equation, restart. Mandatory reach => UNSAT, no possible reach => SAT, and at stagnation run the terminal. Every global pin is necessary for the global safe predicate. Re-evaluate all source identities on the narrowed chart. Conditional pins stay local.

For a vertex v define its exact suffix language R_v = {z in G: v reaches t}. R_t=G. Reverse-topological recurrence
  R_v = union_(e:v->w) (E_e intersect R_w).
A local summary is either R_v=A (affine) or R_v=G minus A (coaffine). For an affine child, an outgoing contribution is one affine intersection. For a coaffine child with A defined by rows a_1,...,a_r, the contribution is the DISJOINT union
  E_e intersect G intersect [a_1 holds,...,a_(j-1) holds, a_j fails], j=1,...,r.
Omit inconsistent cells; if A is empty, contribution is E_e; if A=G no contribution. This is a first-failed-row partition on the actual shared chart, not independent guard choices. Each edge contributes at most max(1,d) events. The local union is exact regardless of cross-edge or cross-layer correlations.

Deterministic local coalescing: drop contained events (Gaussian inclusion); if two distinct events have the same direction rowspace, their two parallel cosets unite to a single affine coset. Over F2 their affine hull is exactly their union: choose any displacement between representatives, adjoining that one direction doubles the size and contains both cosets. In canonical RREF use one differing RHS row as pivot, xor it into all other differing RHS rows, drop pivot. Every merge/removal reduces event count, preserves union and never increases pointwise event multiplicity. Repeat to stagnation; no claim of optimal coalescing.

To count the complement of the local union, start with K=G. If an event equals K, complement empty. If an event has relative codimension one, impose its complementary equation on K; re-intersect and coalesce residual events, repeat. This is necessary for the LOCAL nonreach predicate only, not necessarily globally necessary. After closure, either no events remain (safe exactly K), or residual events F_i within K remain. Fix constant b. Enumerate all nonempty intersections of at most b+1 distinct residual event indices; prune inconsistent intersections. If any b+1-fold intersection is nonempty return UNKNOWN for this local counting backend. Otherwise max residual multiplicity <=b, certified, and exact signed packet identity holds pointwise:
  1_(G minus R_v) = sum_(J subset [m], |J|<=b) (-1)^|J| 1_(K intersect all F_j).
The empty subset contributes K. This is standard inclusion-exclusion on bounded multiplicity; it is the local analogue of GD15, not a bound on indexed path multiplicity. For any additional affine query Q, intersection with Q gives exact safe count via Gaussian cardinalities, and reach count = |G intersect Q| - safe count. Store the packet list once and charge every consumer. No need to enumerate Q assignments. A cap failure is UNKNOWN, not UNSAT.

Find one member using conditional coordinate count self-reduction; at each step query the two fibers and follow a positive one. Build affine hull H of found points. For every basis equation of H test its opposite on the original G with the SAME language count oracle. If some query is positive, recover a point outside H, enlarge H; at most d independent additions. If none positive, every word in L lies in H, and all found points lie in L, so H is exact affine hull. L affine iff |L|=|H|. The root of a decision block does not require an affine/coaffine output: its exact safe count and positive witness suffice. Interior nodes must have certified affine/coaffine summary or decline; intermediate recognition is not assumed free. Count-based witness probes are guarded query restrictions, not global deductions. ## C. New recognition barrier (PROVED symbolic)
Even when every nonroot suffix language is affine, deciding whether the root suffix is affine OR coaffine is coNP-complete. Reduce arbitrary strict 3-CNF F(z) on n bits. Add three fresh bits y0,y1,y2 and build parallel contradiction tracks for F's falsified clauses, y0=0 and (y1=y2=0). Thus safe predicate is exactly
  F(z) AND (y0=1) AND ((y1,y2) != (0,0)).
Every nonroot track suffix is an affine conjunction. If F UNSAT, reach is full chart (affine). Otherwise safe cardinality is 3*#SAT(F), positive and not a power of two; reach cardinality 2^(n+3)-3*#SAT(F) is strictly between half and full, also not a power of two. Neither side can be affine. Membership in coNP: if both sides nonaffine, each has three member words whose XOR is not a member (nonempty affine iff closed under triple XOR); membership in each side is polynomial by guarded reachability. The two triples certify failure. Empty permitted as sentinel. Duplicate every optional guarded edge into two successive edges with identical guard if desired: every track has at least two optional edges, specified mandatory/single-optional closure stagnant on the unconditioned chart, all intermediate suffixes remain affine. This proves hardness of unrestricted recognition, not a lower bound against capped sufficient recognizers, and not P!=NP. A complete polynomial recognizer would imply P=NP. This reduction is symbolic and not separately executed.
