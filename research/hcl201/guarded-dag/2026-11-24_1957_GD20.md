## A. Dualization of projection difference (PROVED)
Let z be a common exterior affine chart over GF(2). System A has private variables p and an explicit list of guarded equations, each of the form g_e(z) => d_e^T p = s_e(z). Each g is a conjunction of affine equations, possibly empty or contradictory; s is one affine bit. System B has separate private variables q and its own guarded equations. Fixed private rows may be dense, zero, graphic, repeated or parallel. No extra private constraints except these equations. R_A(z) means existence of p satisfying the active system. Fixed affine exterior restrictions may be included in the chart. A genuine shared hidden coordinate must instead be exposed or represented in a single joint system; we do not assert independent gluing for uninsulated BW13 wheels.

For fixed z, define D_B to have columns d_e, and let y be a bit per B row. By elementary finite-dimensional linear algebra,
NOT R_B(z) iff there exists y with D_B y=0, XOR_e y_e s_e(z)=1, and y_e=1 implies g_e(z).
Proof: a sum of active equations yielding 0=1 proves inconsistency. Conversely if the active RHS is outside the image of the active equation matrix, a linear functional separates it from that image; its coefficient vector is y on active rows, extended by zero. In graphic networks this is an odd-syndrome Eulerian edge subset, not a signed path sum. No need for a simple-cycle or partition oracle; every certificate can be checked by row XOR.

Consequently R_A AND NOT R_B has an existential certificate on (z,p,y), with only local activation tests plus XOR consistency and odd syndrome. R_A subset R_B iff no such certificate exists. Equality uses BOTH directional queries. R_A empty tests ordinary positive feasibility; universal R_B tests the negative query with A empty. A fixed guard H can be included as chart constraints. This handles zero/nonzero of authenticated consistency predicates, not arbitrary signed arithmetic readouts. No multiplicities or arbitrary reachability claimed. This is the main extension beyond BA13's compact pointwise projection and GD19's finite-alphabet terminal.

## B. Exact mixed interface (PROVED)
Fix an explicit interleaved order of all A and B events. Let U_i be rowspace of local observations on the chart x=(z,p): A uses guard rows and the combined equation row d_e on p plus sign row on z; B uses guard and sign rows on z. Let P_i=sum_{j<=i} U_j, S_i=sum_{j>i} U_j, W_i=P_i intersect S_i. For B only let L_i=span of private columns already processed, M_i=span of future private columns; V_i=L_i intersect M_i. At cut i a key is:
(1) actual functional on W_i;
(2) u_i=XOR of selected B columns in prefix, restricted to V_i because a completion must cancel it;
(3) b_i=XOR of selected B sign bits in prefix.
Thus at most 2^(dim W_i+dim V_i+1) keys. No Boolean partition states and no actual exterior word enumeration.

Transitions: enumerate outgoing W_{i+1} functionals, enforce agreement with incoming functional and one local branch by Gaussian feasibility. For A, its implication is a union of at most |g|+1 affine branches (one violated guard row or the equality itself). For B, y=0 is unrestricted and y=1 requires all guard rows and each candidate sign value; update u by d_e and b by that sign. Reject u outside M_{i+1}; it is already in L_{i+1}. Empty guard works as true, inconsistent guard as false. Signed affine RHS is evaluated on the same chart, not independently resampled. Root requires W_m=V_m=0 and b_m=1; a positive-only query omits the dual coordinate.

Gluing proof: W_i+U_{i+1} intersects P_i in W_i, and W_{i+1} is contained in W_i+U_{i+1}. Therefore compatible incoming functional and local witness on these observations extend EVERY prefix history sharing that functional. The additive private syndrome and parity summarize all remaining requirements on y. Induction shows exact extendible-key transitions (possibly retaining keys with no full extension; suffix span test only necessary). Boolean merging is safe: one actual history per key suffices. ## C. Dualization has only one extra bit on a common raw order (PROVED)

The cut intersection on exterior+A private is W_raw, and its B-private summand is exactly V_i. Therefore raw all-primal joint width w_raw=dim W_raw+dim V_i. The mixed observation space W_i is contained in W_raw, so mixed width <= w_raw+1.
