## Theorem (conditional; fixed pool conflict-guided restart)
Fix a constant k and an explicit Boolean CNF F on r<=poly(N) original or authenticated residual coordinates, with polynomial starting size and exact reconstruction map. Maintain a persistent clause database D initially F. In each episode start from the same authenticated outer guard (represented by units in F), perform exact unit propagation (UP) to fixed point after each decision, and choose only currently unassigned variables. If every clause is satisfied, output and lift a witness. If UP conflicts at empty decision guard, terminate UNSAT. Otherwise let p be the conjunction of decision literals. Find a subset q of p such that UP(D AND q) conflicts and |q|<=k; exhaustive subset enumeration costs O((r+1)^k) UP calls. An implemented alternative greedily deletes decision literals and returns UNKNOWN if its final core exceeds k; greed is not assumed to find a minimum. Learn the clause C=OR_{l in q} not l, independently RUP-check it, reclose, restart. Maintain D without deletion. If no permitted core found, return UNKNOWN. All deductions are under the unchanged outer guard, not arbitrary native root pins.

Soundness: UP contradiction under q proves D entails C. Inductively all learned clauses are entailed by F; adding them does not remove a model. Root UP contradiction proves UNSAT. For SAT reconstruction use reverse complete bucket projections testing both pivot values, signed carrier lift, and native verification. For native complement gauge, the outer guard is equisatisfiable by the proved global bit complement, not an unconditional bit fact. No learned clause is exported outside the gauge/chart without a checked adapter.

Novelty invariant (within this research architecture): a conflict core obtained on a path closed by UP after every decision cannot already occur as a clause in D. If q is nonempty and C were present, choose the last decision literal l in q along that path. Before this decision all other literals of q are already assigned true, hence C is either already false or unit and forces not l. This contradicts the previous closed noncontradictory state and the choice of l as an unassigned variable. The empty core is an immediate terminal. Thus every nonterminal restart strictly decreases the numeric credit
  Phi = sum_{i=1}^k 2^i binom(r,i) - (# distinct learned permitted clauses).
Each episode has <=r decisions, each UP scan fixes at least one coordinate or stops, and at most O((r+1)^k) candidate cores are checked. All failed candidates, checking, serialization, proof retention, and scans of the expanding persistent database are polynomial on the same fixed original N. With naive explicit bit lists and sequential lookup, all address/variable lengths O(log N) and D size O(|F|+k*(r+1)^k log N), a fixed polynomial upper bound follows by multiplication of the episode, scan, lookup and checking caps. Peak storage for D, active assignment, history, maps and proof is polynomial; cumulative serial bit memory <=(T+1)S. No oracle or probabilistic scheduling is needed. If exact projection retires a coordinate forever with bounded acquisition and resets the pool, use T4 Synthesis's reserve (K0+1)r+K0-|L| with K0 computed on original coordinate universe; do not reset the original N cap. More general polynomial recognizable finite guard pools also work if discovery is polynomial and each found clause is new. Logarithmic clause width alone gives N^{O(log N)}, not P.

First OPEN arrow: prove that every reachable conflict on every input, or a uniformly discoverable alternative productive transformation, admits a fixed-pool core within the aggregate cap. No such universal statement is established. A cap-decline is UNKNOWN, never SAT. On NO inputs a uniform polynomial rejection bound would suffice, but is not proved.

## Falsifiers and scope
For any h>=2, let y=AND(a1,...,ah) encoded by a chain of exact ternary AND gates (standard three CNF clauses per gate, using binary clauses as needed). Add (not y OR z) AND (not y OR not z). On the legal UP-closed decision path assigning a1,...,ah true in order, no conflict before the last decision: each determined prefix conjunction is true, the last undecided input and y remain unset, and the last two clauses are not unit. When all inputs true, y=1 forces z and not z. Every proper subset of these decisions has a satisfying extension by setting a missing input false, lifting AND gates, and choosing z. Thus the smallest conflict core inside this particular path has h decision literals, even for width-three input. This falsifies a universal fixed-k bound for arbitrary closed decision paths, not the existence of a better deterministic policy, matching/affine reasoning, failed-literal probing, or unrestricted algorithms. It is a SAT control illustrating why guard-width must be proved, not inferred from source arity. The formula is not registered as a new native instance, and this symbolic family was not executed.
