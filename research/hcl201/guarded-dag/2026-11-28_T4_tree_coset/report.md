## Scoped theorem (symbolic proof)
Let disjoint, explicit, nonempty dictionaries S_i in F2^h have checked local choice lift and encode all guards before compression. Feasibility is sum s_i=b; shift b into one dictionary to obtain target 0. A supplied binary tree partitions the owners. For node P write T_P=sum of its dictionaries, A_Q=aff(T_Q)=a_Q+U_Q for its complement Q, with empty sum {0}. Store exactly R_P=T_P intersect (b+A_Q). For children A,B and outside Q, R_P=(R_A+R_B) intersect (b+A_Q): if x+y meets the parent condition then x meets its child outside affine condition since y is attainable, and conversely the sum of child-attainable words is attainable. This is target-conditioned support, not an assertion of extendibility to an actual suffix. Empty support is exact refusal; at root R_root is empty or {b}.

Let each child R_i be represented as a union of cosets of its certified translation subgroup H_i, with actual reps X_i. For each pair x,y, possible sums are x+y+H_A+H_B. Intersect with b+a_Q+U_Q by exact GF2 solving. Every nonempty intersection is r+K for K=(H_A+H_B) intersect U_Q, independently of the pair. Compute a basis for K and retain actual pair backpointers indexed by reduction modulo K. Thus raw distinct cosets <= |X_A||X_B|; no enumeration of K. Find full periods of the finite quotient support D={r mod K} by checking p=d0+d for every d in D and testing D+p=D with exact membership. Lift those periods together with K to H_P=Per(R_P); store a key per coset modulo H_P. For witness reconstruction, retain the pre-period dictionary D with pair backpointers: any requested t in R_P yields t mod K in D, with a stored pair x,y. Solve t+x+y in H_A+H_B with tagged linear algebra to obtain shifts h_A,h_B; recursively request x+h_A and y+h_B. Leaf raw map gives actual local word. Each exact leaf/union, affine pruning, period test, and backpointer is checkable without enumerating any affine coset. Tags for all original guards are mandatory before constructing S_i. Changing a guard may destroy a period. No cross-guard reuse without checked adapter.

A naive two-sided use of suffix memoization is unsound for joins: A=B={0,1}, target 1. Each child may keep representative 0 modulo the opposite child's full period group; comparing representatives alone rejects even though 0+1=1. This algorithm retains shifts and raw quotient backpointers. Also local period sums can miss joint periods: {00,01,10}+{00,01,10}=F2^2 although each input set has trivial period. Restrict first set to {00} and the new full period disappears.

Let B=max(1,max_i |S_i|, max_P |R_P/H_P|) over nonempty nodes, h syndrome dimension, L explicit source chart size. With a polynomially acquired exact tree and chart, B<=N^c for fixed c suffices for deterministic polynomial total bit work. Child raw coset pair count <=B^2, period tests <=B^4, linear algebra and deterministic sorted exact membership polynomial in h,L and bit lengths, m nodes linear in blocks. Store O(m B^2) raw rows/backpointers plus polynomial basis storage, reconstruct by one descent and tagged GE. All work and peak space polynomial, cumulative memory bounded by their product. If lambda(P)=dim(U_P intersect U_Q), then H_P is a subspace of this cut intersection, so |R_P/H_P|<=2^(lambda(P)-dim H_P), not ambient rank. This is a sufficient, not necessary, condition. The certificate is the full deterministic bottom-up trace with exact membership and pair coverage; it is not supplied free. A cap can stop before finding periods, so UNKNOWN does not refute this class.

This extends a provided log-width tree DP, not the branchwidth recognition theorem. Korhonen-Oum arXiv:2601.04756v2 supplies 2^{O(k^2)} gamma m^6 log m for symmetric submodular connectivity oracle, hence polynomial recognition for k=O(sqrt(log N)) with polynomial oracle; log-width DP itself polynomial, discovery at log width only quasipolynomial via this bound. No proof that target-conditioned period-effective width defines a symmetric submodular connectivity function; do not use this external theorem on that quantity. Kashyap doi:10.1137/070691152 concerns trellis/matroid pathwidth, not a general period-effective acquisition theorem. External theorem not independently audited or implemented here.

No full native independent tree transcript as both capped; no benchmark-to-universal inference. No full manuscript edit.
