## 2. GD13-A: exact positive counting, no cyclic distance labels
Input explicit finite directed multigraph with distinguished terminals P (fixed constant size, normally s,t), source affine chart G parameterized by d independent bits z, and each edge enabled iff its explicit affine equations hold. After Gaussian pullback write its guard as affine equations in z. Inconsistent edges are dropped; unconditional edges have empty observation span. N is total explicit encoded length including the affine chart and supplied source/lift maps. Loops and parallel arcs permitted. No succinct arbitrary circuit guard assumed.
For nonreachability run certified closure: remove inconsistent edges, substitute unconditional edges; if unconditional s-t path exists reject, if no possible s-t path exists all chart words are legal. For each edge whose tail is reachable from s via unconditional arcs and whose head reaches t via unconditional arcs, its enabled guard is a rejection condition; if it has relative codimension one force the complementary affine equation. Rebuild chart and restart after every deduction, and at stagnation before evaluation/any branching. Each forced equation lowers dimension, so this repertoire is polynomial. This is not complete semantic closure. For general identity queries only target-independent guard normalization is used unless a target-specific implication is proved. Conditional facts retain the chart/pins.

For any binary edge decomposition tree and region J, let U_J be the span of homogeneous observation forms in its edges and I_J=U_J intersect U_out. Let B_J consist of vertices incident to edges on both sides, plus all terminals P. Write r_J=dim I_J and b_J=|B_J|. A state consists of:
(1) a functional eta on I_J, specifying the exact observed shared information; (2) the complete reflexive directed reachability relation R on B_J induced by enabled edges of J. Store the number of distinct functionals on U_J realizing that state, plus one actual such functional (or traceback). Do NOT count paths. Each functional corresponds to a unique observation word and fixes every regional enabled predicate. This is an unsigned exact count, equivalent to the source count targeted by GD12's signed cancellation, with a different interface.

At join J=L disjoint-union R, U_J=U_L+U_R. Two functionals glue iff they agree on U_L intersect U_R, contained in both child interfaces. Each compatible pair extends UNIQUELY to a functional on U_J. Moreover every p in I_J can be decomposed p=l+r with l in I_L and r in I_R: write p=l+r with l in U_L,r in U_R; p lies in outside span, so l=p+r belongs to U_R+U_out and r=p+l belongs to U_L+U_out. Thus the parent eta is determined by child eta values, not by hidden representative choices. All decompositions give the same value by overlap consistency.
Compute reflexive transitive closure of the union of child boundary reachability relations, on B_L union B_R, then restrict to B_J. Any path in J splits into child paths at shared endpoints; conversely a chain of child relation pairs concatenates to an actual walk, hence reachability. Handles arbitrary cycles without SCC distances, unsupported predecessor choices or signed-marker multiplicities.
Multiply counts for compatible state pairs and add for identical parent states; no double counting because restriction to children is a bijection on compatible pairs. At root I=0 and B=P. Sum states satisfying the desired Boolean terminal reachability test and multiply by 2^(d-rank U_root), the uniform number of chart preimages. Trace back actual compatible functionals (not independent marginal witnesses), Gaussian lift to chart, then verify original predicates and reachability. An unused source coordinate is free and counted exactly.
Identity of two explicitly acquired guarded graphs follows from a disjoint union with separate graph terminals and common source chart: count XOR of the two reachability predicates at root; identity iff zero. Charge the JOINT decomposition, not separate low widths. Universal reach/nonreach is exact zero/full count. This does not decide forall outer selectors exists private repairs without an authenticated projection adapter.

## 3. GD13-B: wide affine guards need not enumerate local words
At a leaf, a consistent conjunction of affine equations specifies exactly one functional h on its observation span U, dimension a. For each eta on I=U intersect U_out, r=dim I, exactly 2^(a-r) local functionals extend eta. Exactly one is enabled if h restricts to eta, otherwise zero. Disabled count = 2^(a-r)-enabled count. This is exact even if a is linear in N and r=0. Each of the two outcomes contributes the corresponding leaf relation. Obtain a disabled witness by solving eta, additionally flipping one independent observation outside I relative to h if h is compatible and a>r; if h is incompatible any lift works. Enabled witness is h. Gaussian work and bit lengths polynomial per eta. Arbitrary local predicates require explicit table acquisition or a separately certified count backend; not implied here.
Hence with a supplied/paid tree, time <= poly(N) 2^{O(max_J(r_J+b_J^2))}, space <= poly(N) 2^{O(max_J(r_J+b_J^2))}, CM <= (T+1)S for same serial realization, including all attempted joins (at most products of child capacities), basis acquisition, key formation, counts of at most 2^d, closure, witness retention and verification. Leaf theorem removes the former maximum local guard-rank exponent for affine conjunctions. The main executed relation backend enumerates leaf observation words; the wide-leaf closed-form backend was independently executed below, not integrated in that implementation. Counts remain exact in both.
A fixed tree reserves each table/attempted pair once. An arithmetic job potential with reserved credit sum over all leaf capacities plus child-pair capacities plus local aggregation units contracts c=1 under disjoint job completion (polynomial factor for per-job work). It is polynomial only when the corresponding widths are sufficiently bounded, not an arbitrary SAT branching potential.

## 4. GD13-C: discovery is paid by a connectivity-function theorem
Attach a fresh independent coordinate e_v to each NONTERMINAL graph vertex v. Associate to each edge its observation subspace plus the coordinate lines of its incident nonterminal vertices, in direct sum. For any cut J, the intersection rank of the sums on its sides is exactly
  f(J)=r_J+|B_J minus P|.
This is a connectivity function: if q(J) is the rank of the sum of these augmented edge spaces, f(J)=q(J)+q(out)-q(all); subspace rank is submodular and the expression is symmetric submodular, normalized at empty set. Each query is polynomial Gaussian work in N. A subcubic branch tree can be rooted by subdividing an edge; all relevant widths preserved. Empty/single-edge inputs direct.
Known theorem (external, preprint status): Korhonen and Oum, Branch-width of connectivity functions is fixed-parameter tractable, arXiv:2601.04756, Jan 8 2026, Theorem 1 as displayed at https://arxiv.org/abs/2601.04756: for a normalized integer symmetric submodular connectivity function with oracle cost gamma, find a branch decomposition of width <=k or certify width >k in time 2^{O(k)} gamma m^6 log m + 2^{O(k^2)} gamma m. Apply it to our explicit rank oracle. Older Jeong/Kim/Oum, arXiv:1711.01381, gives FPT subspace branch decomposition, but without the same explicit parameter bound imported here. No use of uncharged decomposition existence.
Consequently the complete pipeline (including discovery) has time 2^{O(k^2)} poly(N) for joint width k; space polynomial in same time and CM bounded by their product. For k<=C sqrt(log N) with fixed C and fixed number of terminals, this is a deterministic polynomial-time terminal, conditional on the cited theorem; construction not executed in this iteration. For a supplied tree the finer r+b^2 bound allows r=O(log N), b=O(sqrt(log N)); no universal polynomial discovery claim for that asymmetric threshold. Inserting an extra affine observation leaf for a protected parity query raises original observation cut rank by at most one (it may be attached via root subdivision); complete affine identities may be extracted by growing verified witness-difference span and querying annihilator directions with opposite parity, polynomially many paid queries, each separate. No cumulative semantic closure assumed. Identity queries with fixed additional terminals only change b by a constant.

## 6. Falsifiers and hostile families
(i) Directed boundary relations can have 2^{floor(b/2)ceil(b/2)} distinct attainable states: independent edge bits between left and right halves of b boundary vertices, each forward arc optional. Every bipartite relation differs on a pair; an exterior s->left and right->t context isolates that pair, distinguishes it. Thus generic exact context-independent relation-state enumeration cannot have universal polynomial state count even at r=0. This is a restricted state representation bound, not hardness of a particular fixed context or compressed algebra.
(ii) Universal low combined branch width is false even for easy formulas. Parallel s->t edges indexed by all unordered pairs i,j of n source coordinates; edge guard x_i=x_j=0. Nonreach legal iff at most one zero, so exactly n+1 solutions. Root closure above stagnates, each guard codimension two. In any subcubic tree with m=binom(n,2) leaves there is a cut with each side at least m/3 leaves (centroid walk). On each side the observation span is exactly the coordinate span of incident variable indices. At least one side uses all n indices: if i were exclusive to one side and j exclusive to the other, their pair edge could belong to neither. Other side has at least sqrt(2m/3) incident indices, hence shared rank Omega(n). Add the other three forbidden words on one chosen pair to create an UNSAT neighbor. Any balanced cut has >=(m+3)/3-3 original distinct pair edges each side, and the same exclusive-vertex argument on original pairs gives Omega(n) rank. Four local guards cover that pair, easy alternative terminal. No diagonal-hard family established.
(iii) Arbitrary 3-CNF encodes as parallel s->t edges guarded by each clause's false word; nonreach exactly SAT. Therefore physical graph width alone (even two vertices) cannot pay universal guard interaction unless P=NP. Similarly explicit signed E4/B4: one Boolean source per wire, local endpoint sign incorporated; enumerate <=16 port patterns per vertex and add one forbidden parallel edge for each illegal equality/balance pattern. Both directions exact, source replay polynomial. Hub synchronization follows from shared actual wire bits, no new low-width guarantee.
