## A. Exact SCC-reset signed cancellation (PROVED)
Compute SCCs of the STATIC graph (all potentially enabled edges). For each SCC C choose a feedback vertex set F_C, not necessarily minimum, and verify that the induced graph on C minus F_C is acyclic. Polynomial discovery: DFS within C and collect heads of all DFS back edges, including loops; any directed cycle in the residual would contain a DFS back edge, whose head was removed. Alternatively use all vertices. Let k_C=|F_C|. Static certificate is valid for every enabled-edge subgraph.

For v in C give distance label d_v in {0,...,k_C,infinity}; fix d_s=0,d_t=infinity. For an enabled edge u->v define f_uv(a)=0 if the SCC changes, otherwise a+1[v in F_C]. If d_u is finite require d_v finite and d_v<=f_uv(d_u). A tight edge additionally has equality. For each finite non-source vertex allow a marker bit m_v; it is forced zero on infinite vertices and s,t. For each tight edge from a finite vertex to a marked vertex reject. Multiply weight (-1)^m_v exactly once at a designated incident anchor factor. Isolated nonterminal vertices may be removed; their true label infinity adds no multiplicity. All constraints are unary or pair-local in vertex states plus the original edge guard. In particular no predecessor choice is enumerated.

For fixed source x and any labels obeying the inequalities, markers can be selected independently precisely at the unsupported finite vertices, those other than s with no incoming tight edge. If their number is z, sum over markers is (1-1)^z. Thus only labelings in which every finite nonsource has a tight predecessor survive.

**Uniqueness.** Every cycle of tight finite edges must lie within a single static SCC, since the condensation is acyclic. Summing tight equalities around a cycle implies total entering-feedback cost zero; this contradicts F_C intersecting every cycle. Therefore following tight predecessors from any finite vertex terminates at s. A finite label is consequently realized by an enabled path from s, with label propagated using the edge maps f_uv. Conversely along every enabled path from s the inequality implies finite labels no greater than the path's propagated label, by monotonicity of the edge maps (including resets). Hence the surviving labels equal the minimum propagated label of all such paths, and are infinity exactly at unreachable vertices. The minimum is the least number of feedback vertices entered since the last SCC entrance (or since s). It is at most k_C, since a path from an entrance can be simplified inside the SCC and visits each feedback vertex at most once. These minimum labels obey every edge inequality and have tight predecessors: take a path realizing the minimum; a smaller predecessor minimum could not improve the chosen label without contradiction, and reset maps are constant. Thus the canonical labels exist, and exactly one survives if t is unreachable; none otherwise.

For each x, the signed sum over all auxiliary labels and markers is exactly 1[t unreachable]. Summing over G counts complete original source words, not auxiliary certificates. k_C=0 reduces to GD11. Static SCC resets are important: total feedback size may grow linearly while max local k_C remains one. No dynamic guarded SCC enumeration is needed.

## B. Exact rank and resource bounds (PROVED conditional terminal)
Encode each label by b_v=ceil(log2(k_C+2)) bits, with a distinct canonical infinity code and unused codes rejected. For each nonterminal vertex place all its label bits in every incident edge factor; include m_v in each incoming factor and an anchor, enforce domain and weight at the anchor. s,t constants are substituted. For a fixed edge-factor tree, let w_src(J) be the intersection rank of the original source observation spans on opposite sides of a cut J. Let B_J be vertices with incident factors on both sides, excluding s,t, and M_J be markers occurring on both sides. With independent auxiliary coordinates the new width is exactly
  w'(J)=w_src(J)+sum_{v in B_J} b_v+|M_J|.
Since M_J subset B_J, if w(J)=w_src(J)+|B_J| was the original selection-bit interface, w'(J)<=(1+b_max)w(J). A local edge factor has rank <=d_src(e)+sum_{v in endpoints internal}(b_v+1). This proof holds on every cut of the supplied tree simultaneously. If every SCC has bounded feedback size then logarithmic original width stays logarithmic; if k_C is large, the bound can grow to log^2 N, not automatically polynomial. Large total feedback alone is not a barrier.

Parameterize G once by Gaussian elimination, retain all source guards. Concatenate the independent affine observation occurrences into a linear map A (offsets handled at the factors); choose a parity check H with ker H=im A. Generate actual local rows over their observation image, weights in {-1,0,1}. Consistency is exactly XOR of the syndrome contributions equal to zero; every consistent word has 2^(dim(source+aux)-rank A) preimages. All auxiliary bits are observed by construction, so the multiplier represents unobserved source freedom. Signed sum times this multiplier is the exact source count. No guard marginalization, no Boolean OR replacing signed additions.

For each cut, the intersection of possible partial-syndrome spaces from opposite sides has dimension w'(J). Indeed it is the image of the shared compatible observation tuples under the partial-syndrome map, with kernel equal to independently realizable one-side variations; rank-nullity gives rank A_J+rank A_out-rank A. Keep only states in this intersection. At a binary join enumerate all retained child pairs, charge unsuccessful joins and integer arithmetic. Define d'=max local rank and w'=max cut rank. Initial explicit row acquisition costs <=2^d' poly(N). Certified structural row-support closure deletes a row only if its syndrome cannot be completed even by the sum of other affine hulls, and restarts after every strict deletion and at stagnation; never delete on signed cancellation alone. At most R deletions and O(R) row tests per sweep, R<=2^d' poly(N), giving a conservative charged closure bound 2^(2d') poly(N). Other admitted certified preprocessing can be dovetailed/capped but not assumed free. Signed integers have polynomial bit length since absolute sums are bounded by the number of source/aux assignments. With supplied or paid qualifying tree, conservative bounds on one serial execution including all table acquisition, closure, SCC/feedback discovery, rank tests, failed transitions, parsing, canonicalization, arithmetic and output:
  T <= poly(N) 2^max(2d',2w')
  S <= poly(N) (2^d'+2^w')
  CM <= (T+1)S.
Include all live tree messages, masks and reconstruction in the polynomial factors; do not claim measured bytes or CM. N includes explicit graph/guard input and supplied tree, paid construction in original N required for full transfer. Arbitrary decomposition discovery and universal small interface remain OPEN. The actual general affine tree backend is symbolic here; executed code uses ordered finite-domain frontier contraction.

## C. Rank-stable witness and affine identity acquisition (PROVED)
When the count is positive, choose a basis of the span of ORIGINAL source observation rows, selecting actual observed rows as basis elements. Pin one observed value at a designated existing factor (restrict its mask, do not append a new constraint or change A). Global syndrome consistency forces all copies to agree. The two restricted signed counts are nonnegative complete-source counts, additive because the split is on source information only. Retain a positive child, rerun certified structural closure with all pins retained, and continue. At most rank(A_source) source observation pins are needed. Solve their affine equations in G, choosing arbitrary free coordinates. Every source word with these observations has the identical reachability outcome; verify nonreach directly by graph traversal and replay original source if a compiler is authenticated. No cumulative interface growth from the pins, since they only shrink row masks on the same observation matrix. Never reconstruct from the sign of a partial term.

To acquire all affine identities of the nonreaching set, first obtain a witness a. Grow a span of verified witness differences. For each basis vector of its annihilator ask whether a source word exists with the opposite parity. Such a query adds only one explicit affine observation factor to the supplied tree; inserting one leaf adds at most one to any old cut rank and the new leaf cut has rank <=1. Use the same rank-stable observation-mask reconstruction for that query. Any positive answer grows the difference span; when all annihilator tests return zero, the span is exactly the affine hull. O(n^2) count queries and O(n) extra witness acquisitions (each polynomially many counts); never accumulate unrelated extra parity factors. Record certified unconditional identities as redundant facts, with guards if conditional. No free semantic closure. Empty support is detected by count zero.

Exact universal reachability on G iff the nonreach count is zero; universal nonreach iff it equals |G|. For two graphs on the same source, exact identity of their reachability predicates follows from N_A+N_B-2N_AB=0, where N_AB is the count nonreaching in both. Obtain N_AB by disjoint auxiliary copies sharing only source bits (or union with shared s,t and disjoint interiors). Recompute/charge the joint interface; no assumption of equal width. This is not uniform existential repair coverage over hidden source coordinates (DO06).

## D. Physical source adapter and limits
An explicit signed E4/B4 network can be encoded with one Boolean source bit per wire, each endpoint literal adjusted by the sign. At each physical vertex, enumerate its <=16 local port assignments; for each illegal equality/balance pattern add a parallel s->t edge guarded by the corresponding affine equations on the wire bits. Nonreach is exactly physical feasibility, both directions and physical witness replay, O(N) patterns with indexed wires and polynomial bit cost. Duplicate wheel hubs remain synchronized because actual wire/source observations are shared; this does not infer a low-width tree. Projecting physical witnesses to tetrahedral colors may change counts (BW05); retain its separately authenticated correction if needed. A general unannotated matching quotient L/L2 or joint occupancy/syndrome adapter is not proved here. Cyclic contradiction graph theorem applies to any such adapter only after exact source predicate acquisition. Even two-vertex guarded graphs encode arbitrary CNF, so cyclic repair is not a universal SAT algorithm.
