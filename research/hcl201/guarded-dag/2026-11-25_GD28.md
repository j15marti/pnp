BS20 supplies exact learned conflict packets; BA20 explicitly subtracts flats, potentially many pieces; S26 supplies activated dependency factorizations. Instead use a binary Boolean formula tree with leaves affine packet tests. Compute subtree/complement spans and their intersection B by Gaussian elimination. Store attainable (functional on B, Boolean output) pairs and representative equations. Child interfaces include their mutual intersection; parent B is contained in their sum. Hence compatible representatives glue and determine the parent interface independent of private choices. A packet leaf's true state is a linear feasibility test; false is the union of single opposite-row tests, no full rank enumeration. At most 2^(2w+2) pairs per node. Recover actual exterior word by Gaussian solve, replay guard and formula. A consistent affine guard is absorbed first; arbitrary nonlinear guards require actual factors. With polynomial tree size and w <= C log(N+2) this is polynomial; for a supplied tree all rank checks paid. DAG unfolding and discovery not free. Exact coverage is the absence of a true state for the conjunction of exclusion complements. An uncovered word is not a source witness until private and original source verification.

Counterexample: build parallel internally disjoint equality paths with opposite endpoint pins, one per source 3-CNF clause. Each edge active iff a literal is false. Contradiction exactly when some path is intact, hence existential feasibility NP-complete even constant graph treewidth, literal edge guards and linear size. This is a reduction, not an unrestricted lower bound. Small geometric interfaces do not control shared exterior observation width. No claim of simultaneous hardness against all modules.
