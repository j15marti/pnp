## 2. Theorem A (PROVED): existential closed-cut compiler
For every finite directed graph G with distinct source s and sink t (even cycles allowed), each edge e=(u,v) has a deterministic guard g_e(A_e x+b_e) on an explicit finite list of affine Boolean observations of the SAME x. Domain D is given by affine equations; eliminate it by Gaussian parameterization x=x0+Kz, rejecting an empty domain. Source length N includes guards, evaluators, matrices, edge IDs and source/lift provenance. Assume local guard evaluation is polynomial, otherwise charge actual cost.
Introduce one Boolean cut label c_v per internal vertex, with c_s=1,c_t=0 fixed. Impose, for every edge,
    NOT(g_e AND c_u AND NOT c_v).
For fixed x, if t is not reachable from s in the enabled graph, take c as the characteristic function of the reachable set. Conversely if a cut certificate exists, every enabled edge leaving a 1-label has a 1-label head. Induction along any enabled path from s proves that t cannot be reached. Thus noncoverage iff EXISTS c satisfying these local relations. No recurrence, incoming-edge ordering or explicit simultaneous reachable subset is needed. Cut labels are existential, NOT claimed to be exact reachability bits. Fixed endpoints are substituted before compilation. Repeated observations, synchronized copies and signed guard constants are enforced on one vector (z,c); any private source lift/physical synchronization must first be authenticated. For a sound but incomplete contradiction graph, the method decides noncoverage of that graph, not automatically source SAT. Exact iff source compilation or original-source verification is required.

Each edge now supplies a local nonaffine relation on affine forms in q=(z,c); local rank d_e <= rank(A_e K)+2. Enumerate its actual feasible observation words over a local row basis and evaluate the guard. The words are independent choices until compatibility is imposed; no missing row may be treated as excluded without proof. This is a decision and projected witness encoding. Counting cut assignments is NOT counting original x: an isolated or unreachable vertex may take either cut label. Functional reach recurrences with bounded-fanin auxiliary gates could instead supply unique extensions for DAGs, but were not implemented here.

## 3. Theorem B (PROVED): exact factor-tree evaluation with joint affine rank
Collect every observation row (including occurrences of c labels, constants shifted into local relations) into matrix A on q. Let H be a parity check with ker H=im A. Compute H by elimination, retain full occurrence IDs. Each allowed local row y_e has syndrome H_e y_e. Choose one row per edge; global compatibility iff XOR of syndromes is zero. Any compatible complete word lifts by Gaussian elimination; its x projection is a nonreaching assignment by Theorem A. Every nonreaching x supplies such a tuple. If external occupancy, owner costs or nonlinear protected observations are required, retain their actual constraints/keys; affine rank alone does not bound those extra resources.

Take any explicit binary tree with one leaf per factor. For subtree J, define U_J=span of observation rows of its factors, U_out=span of remaining rows, and
    w_J=rank(A_J)+rank(A_out)-rank(A).
In the parity-check representation this is exactly dim(span H_J intersect span H_out), by rank-nullity (GD08). At a leaf, retain allowed local words keyed by their syndrome if it belongs to span H_out. At a merge of disjoint children, XOR child syndromes, reject if outside span fails, retain one actual pair of backlinks per distinct surviving key. Exact induction: all internal words with equal syndrome have exactly the same external compatibility; outside-span filtering is only a necessary filter, never an affirmative feasibility claim. Parent rows are actual concatenations of child rows. Root key zero is feasible iff a complete word exists. The tree can regroup events irrespective of their original topological order. It never enumerates the Cartesian product of all reachable subsets.

Let w=max_J w_J, d=max local rank. Attempted leaves <= sum_e 2^d_e; attempted joins <= sum_internal 2^(w_left+w_right). Thus T<=2^max(d,2w) poly(N), S<=2^w poly(N) plus streamed leaf evaluation and source structures; all for the same sequential bit execution, CM<=(T+1)S. If d,w=O(log N), and acquisition/discovery/lift are paid polynomial, this is a polynomial exact terminal. Retained witnesses cost polynomial per key. The implementation enumerates raw observation patterns rather than local basis patterns; raw arity bounded in tests. This is an application of classical tree realizations of linear codes, not a claim to have invented them.

Paid discovery: build incidence of factors to coordinates in q, union factors sharing any nonzero coordinate occurrence, then group independent components. Removing the fixed s,t cut labels can expose many such components even though the original graph is connected via s,t. A tree grouping components has zero width between independent components; use a deterministic binary split within each group (or any verified alternative). The code groups by coordinate support then splits the sorted list in halves; lane groups align with these splits. This is sound discovery, not complete matroid separator discovery. Computing/validating the ranks of any candidate tree is polynomial; no universal logarithmic-width tree asserted. A more sophisticated tree search must be charged. Fixed-width state cap alone does not pay join attempts.

## 4. Theorem C (PROVED): complete affine identities with at most n+1 exact single-parity decision/witness calls
Let X be the set of feasible source vectors projected from any exact certificate domain, and let n be the dimension of the requested affine observation vector (use source coordinates or an authenticated linear projection). First obtain x0 in X or certify empty. Maintain W, the span of witnessed differences x+x0, and C, a span of certified linear identities a dot (x+x0)=0 on all X. Thus C is a subspace of W-perp.
While dim W+dim C<n choose a in W-perp outside C via Gaussian elimination. Ask the exact backend under ONE extra affine equation a dot x=1+a dot x0. If SAT, its actual witness contributes a difference outside W. If UNSAT, a is a new independent member of C. Both cases increase dim W+dim C by one. After exactly n probes for a nonempty set, C=W-perp and all affine identities are known; retain actual witnesses for W, never replace X by its affine hull. Total <=n+1 exact calls, each with at most one additional parity guard, rather than one arbitrary disjunction outside the current hull. A decision backend without witness reconstruction needs additional charged self-reduction; not silently assumed.

For Theorem B append the extra one-row probe as a new leaf attached to the OLD tree root. At every old subtree cut its inside row span is unchanged, outside rank rises by at most one, total rank cannot decrease. Thus w'_J<=w_J+1, including the old root/new leaf. Local rank cap is max(d,1). A projected affine feature is composed with the source map before appending the probe. Consequently complete identity extraction multiplies the tree terminal cost only polynomially, even though the compiler is decision-only and the cut witness nonunique. This rank stability does NOT follow for arbitrary BA02 quotients or S08 flow contractions; any pin-dependent certificate must be revalidated or a separate pin-safe backend supplied.

Closure protocol: local affine row-support filtering first, restart after each certified deletion, and at stagnation before each exact solve. Given factor tags, an allowed row is deleted only if the XOR of all remaining factors cannot match it even in their exact affine-hull relaxation. This preserves all actual tuples. Each newly certified source identity is inserted into a separate unconditional closure pass, together with all previously certified identities, and verified consistent with the witnessed x0; the exact probe tree uses the fixed base domain to retain the +1 width guarantee. It is safe to omit already implied identities from later exact calls. Guard-local row deletions never exported outside the corresponding probe. No unrestricted branching, complete semantic closure or full mixed-channel closure is claimed. If the whole run is under a guard, resulting identities hold only in that guard.

## 5. Falsifiers, cooperative bridge and limits
- GD08 antichain: h independent x_i select one of two distinct reachable vertices. Process all 2h source arcs first, yielding 2^h incomparable subsets with no observations shared between different lanes. Add exit guards complementary to the entry guards, so no lane reaches t; switching both exit guards on lane 0 creates a coverage/UNSAT neighbor. Closed-cut factors expose h independent components after fixing endpoint labels; the discovered tree has constant width on the tested powers of two. This falsifies the necessity of storing the fixed-order reachable-set antichain, not a lower bound for optimized GD08 orders.
- Counting failure: with no enabled edges and an observed internal cut bit, both cut labels extend each source assignment. Do not report #SAT from certificate multiplicity. Small source model counts in tests are independent reference counts.
- DO03: encode proper four-color edge inequality by a parallel s->t guard requiring its two-bit difference to be zero; the compiler is exact. K5 and K5-e are executed below. For arbitrary high-girth critical graphs the new rank tree is not proved small and no generic escape from DO03 established. The local observations still require exact joint compatibility. Low-rank projection support is not enough.
- BS02/DP03: heterogeneous specialized nodes are welcome; Theorem C requires exact pinned witness support, not arbitrary positive monotone compilation. Row retirement requires row-specific evidence, not just a projected decision quotient. The new generic tree engine does not compile general matching or tagged flow into polynomial positive circuits.
- DISJ PASS for exact scoped SAT/UNSAT both labels and noncoverage proof. Relativization: diagonal scheduling itself relativizes; this source-specific compiler is not a nonrelativizing separation. Simultaneous DTISP: T,S,CM above same execution, no universal forbidden region. Deterministic configuration: no claim that arbitrary solver must retain these keys.
