## 2. New conditional theorem: subpower light-child credit (T4-AS1)
Let d(S) be an integer between 0 and N^a on every reachable obligation; d=0 terminal, and each productive macro replaces an obligation by a correct exhaustive family of strictly smaller-d children, or decides it. Assume a fixed uniformly executable macro selector with all five failed/accepted tracks, scheduling, checking, map changes and reconstruction charged <=N^q bit operations per expanded node. For some fixed K>=1, beta>=0, 0<=alpha<1, every expansion has at most one heavy child d_h<=d-1 and at most K(d+1)^beta other children each with d_l+1<=K(d+1)^alpha. For sufficiently small d, require the same strict decrease and bounded branching (or a uniformly paid terminal). Every live child, even an immediate contradiction, is charged. Let integer c>(1+beta)/(1-alpha).

Claim: node count <=C(d+1)^c, for a constant C independent of N. Thus aggregate work O(N^(ac+q)) with original N preserved, plus any explicitly separately bounded initialization. Peak memory bounded by total bit work if all written cells are charged, and cumulative memory <=T^2 in a serial bit model (or sum of active stores across replicas with writes/retention charged). Polynomial reverse maps and verification must be included in the macro tariff, not presumed.

Proof: write W(d) for the maximum tree node count, including terminal leaves. Finite small d has a constant bound by strict decreases and bounded branching. For larger d inductively W(d)<=1+C d^c + C K^(c+1)(d+1)^(beta+alpha*c). Since c>=1, (d+1)^c-d^c >= (d+1)^(c-1). The exponent beta+alpha*c<c-1 by choice of c. Hence for all sufficiently large d, the light-child term is <= half the heavy credit difference, with at least 1/C remaining. Increase C to cover the finitely many smaller d. This establishes the recurrence. A nonbranching finite-cost macro is included. A polynomial-cost fair portfolio may supply any such macro; all lanes' failed work and all live children must be paid under the same q. Unlike a logarithmic two-survivor-forks condition, this permits a linear heavy spine with a small unresolved child at each step. Conversely two d-1 children at every step yield 2^d leaves, so no such conclusion follows from strict local decrease alone. This is an elementary sufficient recurrence, not a universal branch-acquisition theorem.

Open load-bearing target U-PROGRESS/AS: for every reachable unresolved NO state, acquire a verified terminal or macro satisfying the above child conditions, or another globally charged contraction, by a single uniform deterministic polynomial schedule. Prove soundness on YES. No proof of this disjunctive coverage. No exponent fitted to finite data constitutes a uniform theorem.
