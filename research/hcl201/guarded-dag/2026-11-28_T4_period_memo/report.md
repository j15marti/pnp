## Scoped theorem
Let explicit nonempty finite dictionaries S_i in F2^h encode disjoint local choices with exact reconstruction; feasibility is XOR_i s_i=b. All active guards must already be incorporated into the dictionaries or into additional exact syndrome rows. At cut P|Q let A_P,A_Q be affine hulls of the exact prefix and suffix sumsets, with directions U_P,U_Q. Write H_Q=sum_{i in Q} Per(S_i), where Per(S)={p:S+p=S}. Then H_Q is a subspace of U_Q and a period group of the exact suffix sumset. Two actually attained prefix syndromes s,s' with s+s' in H_Q have identical suffix feasibility; retain one attained representative and its backpointer. The discarded prefix is not required for decision or for reconstructing one feasible word. If a particular original assignment must be reconstructed, that is a different consumer contract.

All live prefix states surviving affine suffix pruning lie in A_P intersect (b+A_Q), which is empty or a coset of U_P intersect U_Q. Quotienting by H_Q therefore gives at most 2^(lambda(P)-dim(H_Q intersect U_P)) states, where lambda(P)=dim(U_P intersect U_Q). This is a safe upper bound, not equality of attained states. At each layer use that layer's exact suffix basis; process the actual stored prefix syndrome, not the quotient representative. Induction on the layers proves completeness: feasibility of a discarded prefix is also feasibility of the retained prefix, by the suffix period property. At the last layer H_Q=0 and the actual sum equals b. Backtrack along actual retained choices; native replay checks every signed edge and every E/B occupancy row.

To acquire periods choose a in S, test only p=a+x for x in S; for every candidate test all translations against explicit S, using exact comparison (or hash then exact comparison). All periods found, at most |S|^2 membership tests per block; deterministic sorted search gives a polynomial bit bound. Build suffix bases and intersection dimensions by GE. With a uniformly acquired exact dictionary decomposition of polynomial total encoded length in original N, an order satisfying max_i(lambda_i-dim(H_Qi intersect U_Pi))<=c log2 N for one fixed c, the whole memoized DP, period acquisition, comparisons, verification, and witness lifting are polynomial. For example explicit sorting and conservative dense GE per suffix are polynomial in h, number of blocks, dictionary length and N^c. Peak storage and cumulative memory are polynomial as products of polynomial quantities. No claim that arbitrary E/B admits this decomposition/order or that actual transitions are linear in input bits.

## Period transport and guards
For certified global period p owned by one block with S+p=S, choose a linear quotient pi with kernel span(p); preserve every quotient option's original parent. Any quotient solution lifts to parent options with XOR differing from b by delta in {0,p}; toggle the owner option by delta, then check membership and exact sum. Reverse every period, fusion (record two actual parents for each option), and filtering step in chronological reverse order. A changed guard must be encoded before period admission, including extra tag rows for exact affine pins on interior forms; an untagged period is not automatically portable. Nonaffine interior guards require a checked response adapter or refusal. No independent guarantee for arbitrary consumer constraints. No semantic inference from hash or spectral equality.
