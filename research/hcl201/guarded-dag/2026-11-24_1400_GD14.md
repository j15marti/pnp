## A. Exact guarded model and closure (PROVED)
For every finite explicit directed multigraph with terminals s,t and common consistent affine Boolean chart, an arc is enabled iff its explicit affine conjunction holds. Goal: exists chart word with NO s-t path (SAT). Equivalently refute universal reachability. Use GD13 closure before solving and at stagnation: Gaussian substitute the protected chart, drop impossible arcs, classify rank-zero true guards as mandatory, reject if mandatory arcs alone reach t from s, accept if all possible arcs cannot reach t (lift any chart word), and whenever a rank-one optional arc together with mandatory arcs suffices for s-t reach, impose the complementary equation. Restart after each pin. Inconsistent protected chart rejects. A pin strictly reduces free dimension, hence polynomial sweeps. This is a certified repertoire, not complete semantic closure. Conditional pins are retained. No branch into source assignments is needed by the new terminal.

After closure, write each optional arc e with an independent basis of a_e>=1 local observation rows and a unique enabling word h_e in F2^{a_e}. The common chart can be parameterized freely by d coordinates. Use the actual reduced homogeneous rows; affine constants belong in h_e. Define A as the concatenation of the local row blocks, M=sum a_e, R=rank A, delta=M-R. Gaussian elimination discovers a basis of ker A^T. Let P be the matrix whose delta rows are this basis, with blocks P_e; an arbitrary collection of local words y=(y_e) is realized by a common chart word iff Py=0, by rank equality (im A=(ker A^T)^perp). No independent-marginal gluing. All local assignments include affine right-hand sides and the same protected chart. Lift by Gaussian elimination and verify original guards and graph.

## B. Sparse-activation theorem GD14-A (PROVED)
For every such chart and any downward-closed allowed family of optional enabled-edge sets (with mandatory arcs fixed), if a legal compatible chart word exists, then one exists enabling at most delta optional arcs. This does not require low graph width or a small shared observation space.

Proof: pick an arbitrary disabled local baseline b_e != h_e at every optional arc (possible because a_e>=1). Set sigma=SUM_e P_e b_e. A legal realized word y satisfies SUM_e P_e y_e=0, so sigma=SUM_e P_e(y_e+b_e). The latter is a sum of vectors in F2^delta. There exists a subset of at most delta of these vectors summing to sigma: choose an independent subset spanning all the vectors, then express sigma in that basis. Retain y_e only on those selected arcs, use b_e elsewhere. The new syndrome is zero; hence a common chart word realizes it. Its enabled optional set is a subset of the original legal enabled set, so it is legal by downward closure. In particular removing enabled arcs cannot create reachability. No generic polynomial test for arbitrary downward-closed predicate is asserted; nonreach is tested by traversal.

Consequences: a witness of nonreach exists iff some subset S of at most delta optional arcs can be the EXACT enabled set of a compatible word and mandatory+S does not reach t. This is qualitative, not a claim that all witnesses have sparse activation, or that existence of an arbitrary sparse word proves nonreach. Two independent parity groups below show delta=2 can be necessary.

## C. Paid exact algorithm (PROVED)
For each optional block compute, for each syndrome value v in F2^delta, an enabled witness if any and a disabled witness if any. Enabled is only h_e, directly evaluate P_e h_e. Disabled: solve P_e y=v by Gaussian elimination; if inconsistent no witness; if the solution set is singleton h_e no disabled witness; if another solution exists obtain it by a kernel vector or the returned particular solution. Thus cost 2^delta poly(N) even for a_e large. The checker uses equivalent coordinate DP retaining up to two distinct local words per syndrome; two suffice to exclude the one enabled word and are closed under extension. Enumerate subsets S of size <=delta; traversal tests mandatory+S. For surviving S, compute reachable cumulative XOR syndromes by DP over edges, using enabled options on S, disabled options elsewhere. At most 2^delta states/layer and 4^delta attempted pairs per layer. Zero syndrome iff a complete compatible word exists. Keep actual backpointers (checker copies a polynomial-size word list), Gaussian lift and verify source. All attempted subsets, including rejected reach checks, charged.

Let B(m,delta)=sum_{k=0}^{min(m,delta)} binom(m,k), N total explicit input including source and maps. One serial realization has
 T <= poly(N) 4^delta (1+B(m,delta)),
 S <= poly(N) 2^delta,
 CM <= (T+1)S.
Arithmetic and index bits polynomial in N; all discovery, canonical block bases, source rereads, failed transitions, guards, graph data, shared storage and lift charged. For each fixed constant delta this is a uniform polynomial terminal; generally XP, not FPT and not a polynomial bound for delta=O(log N). B and 4^delta are polynomial-bit computable but not polynomial numerical credit universally. A predetermined schedule of these jobs supports strict unary job-credit decrease only after reserving setup, every candidate, all DP transitions and reconstruction; no universal SAT-child contraction. A fixed polynomial cap can safely return UNKNOWN; executable implements delta cap only, not full runtime cap.

Sharp low-nullity corollary: after closure, if delta<=1 and no earlier terminal fired, nonreach must be SAT. For delta=0 all-disabled baseline is compatible. For delta=1, either baseline syndrome is zero or some local column has syndrome one. If this block has rank a_e>=2 its one-bit syndrome fiber has >=2 words, so repair while keeping it disabled. If a_e=1 then flipping its observation enables exactly that arc, which is individually safe after rank-one closure. All other arcs stay disabled. Lift. This corollary is symbolic; checker uses general sparse search, not specialized shortcut.

## E. Two barriers (PROVED)
(1) Maximum dependency-component nullity <=2 does NOT make arbitrary guarded nonreach polynomial unless P=NP, even for series-parallel acyclic graphs with rank-one arcs and no unconditional arcs. Given arbitrary strict 3CNF, split each variable occurrence into fresh x_i; add directed implication cycle (not x_i OR x_{i+1}) for each original variable with >=2 occurrences. Cycle forces all copies equal. Each new variable appears in one original clause and at most two binary clauses. Both directions and linear expansion immediate. This is the classical Tovey bounded-occurrence construction (2/3 clauses, not exact-3 clauses of occurrence 3). Compile each clause to a separate s-t path with one arc enabled iff each literal is false; path enabled iff clause violated. Nonreach iff original SAT. Physical graph of this adapter has treewidth <=2; all local observation rows rank one, each variable's kernel component has nullity occurrence_count-1<=2. No unit arc; GD13 unconditional-path closure stagnates at root for nonempty ordinary inputs. Thus universal componentwise-additive evaluation for THIS graph predicate is equivalent to P=NP, despite DP08's valid additive theorem for products of local factors. The graph path grouping couples components. Identity to constant true reachability and universal coverage are coNP-complete on this representation. This does not claim a physical signed tetravalent inverse compiler or that every solver is hard. Common benchmarks tested synchronized source lifts of splitting; full expanded solver not run.

(2) Exact counting is #P-complete even with total delta=0. Given bipartite graph L,R, add optional s->l (enabled iff its private x_l=1) and r->t (private x_r=1), mandatory l->r for every bipartite edge. All optional observations independent. Nonreach iff the selected vertices form an independent set, exactly one word per set. Counting bipartite independent sets is #P-complete via complement of bipartite vertex covers (Provan & Ball 1983, DOI 10.1137/0212053). In #P by assignment verification. All-zero witness always safe. Thus GD14's sparse-decision improvement cannot imply general polynomial count or arbitrary identity of two graphs: the latter mixes reach/nonreach polarities, not downward closed. No separation of P and NP inferred. Counting reduction symbolic only.
