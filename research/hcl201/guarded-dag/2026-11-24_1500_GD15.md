## 2. GD15-A: exact path moment contraction (PROVED)
Input: explicit finite directed acyclic multigraph, s,t, edge IDs, each edge enabled by an explicit affine conjunction on a common freely parameterized d-bit chart z. SAT means some z admits no s-t path; P(z) is the number of enabled indexed s-t paths (not a model count). Any initial protected affine chart is solved/parameterized first; inconsistent chart rejects. Nonaffine additional constraints require authenticated representation and cannot be silently dropped. Topological layering via private subdivisions and mandatory arcs gives equal-length paths and a bijection on enabled paths, polynomial expansion. Trim irrelevant vertices or retain them safely. Let N denote total source+adapter size, L layers, n_i vertices, e_i indexed edges in transition i.

At boundary i, A_i = span of all observation rows in previous transitions, B_i = span of all rows in remaining transitions, I_i=A_i intersect B_i, k=max dim I_i. All bases obtained by Gaussian elimination. Initially and finally I=0. For any q>=1, take ordered q-tuples of paths (with repetition) advancing synchronously through layers. A tuple arc requires the conjunction of all q guards on the SAME z. Thus tuple path count at z is exactly P(z)^q; observation spans of tuple guards lie in original layer spaces. Do not independently sample q words.

For each tuple vertex v and interface value a on I_i, store M_i(v,a)=sum over z in chart with I_i z=a of the number of enabled tuple prefixes reaching v. Initialize with chart cardinality at source tuple. For tuple transition v->w with guard G and next interface value b, add
 M_i(v,a) * # {z: I_i z=a, G(z), I_(i+1) z=b} / # {z: I_i z=a}
to M_(i+1)(w,b). All cardinalities are exact powers of two or zero by Gaussian elimination; skip zero denominators. In fact each contribution is integer. Proof: conditioned on I_i z=a, the A_i and B_i observations are independent uniform on their respective compatible fibers. This follows by solving the union linear system: every pair of functionals agreeing on I_i extends to A_i+B_i, each with the same number of chart preimages. Prefix count is a function of A_i, while G and I_(i+1) are functions of B_i (I_(i+1) subset B_(i+1) subset B_i). Factor the sum accordingly. This proves recurrence and integer divisibility, including overlapping guards. At sink tuple M_q=sum_z P(z)^q. M_0=chart cardinality. No enumeration of all paths.

Protected pins used by this algorithm consist of rows taken from individual original edge guards, not arbitrary combinations across cuts. At every layer cut their span H=H_A+H_B with H_A subset A_i, H_B subset B_i. DP09 formula k'=k+u-a-b then implies k'<=k, since u=dim H and a+b>=dim H. Alternatively keep original I_i: conditioning on pins amounts to separate local restrictions on A and B, so conditional independence remains exact given I_i. The executable uses this latter option. Cross-cut arbitrary new guards must be reparameterized and width recomputed; not covered by this stability statement.

## 4. GD15-C: sparse positive multiplicities (PROVED, general acquisition symbolic)
The numerical maximum multiplicity need not be small. For any fixed b, acquire M_0..M_(2b+1). Let H_{ij}=M_(i+j+1), i,j=0..b. H is a rational PSD Gram matrix, since c^T H c=sum_z P(z) q(P(z))^2, q(X)=sum c_i X^i. Solve Hc=0 with c_0=1 by exact rational linear algebra. Such a solution exists iff the number of DISTINCT positive values taken by P is <=b. Indeed every positive value must be a root of q; conversely their product of normalized linear factors gives q(0)=1. Zero test certifies this without roots or a given support list. Then q(P(z)) is exactly the safe indicator, and Z=sum c_i M_i. On every restricted chart the positive support can only shrink, so witness reconstruction above remains valid. General Gram routine not implemented.

Special b=1: if M_1=0 all chart words safe. Otherwise M_1 M_3=M_2^2 iff all positive P equal a single value a=M_2/M_1, by equality in weighted Cauchy-Schwarz. Exact safe count Z=M_0-M_1^2/M_2. This is implemented separately. It handles a as large as 2^64 in executed tests without enumerating paths or multiplicity states.

Identity extension (symbolic): for two graphs on same chart, align layers by mandatory private subdivisions, compute shared A_i,B_i from union registry. Mixed tensor moments sum P^u Q^v use same recurrence. Arithmetic identity P=Q iff sum(P-Q)^2=0, with q<=2, no bounded multiplicity. Boolean coverage identity when each graph admits its own certified q_P,q_Q of constant degree follows by sum(q_P(P)-q_Q(Q))^2=0 using mixed moments. Apply only common chart and semantics-preserving local guard simplification; NOT separate nonreach closure which may discard differing words. No arbitrary Boolean identity claim.
