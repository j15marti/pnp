## Theorem A (PROVED): guarded parity selector DAG
An owner that is a disjunction of actual binary parity equations can be represented by a choice of one equation. Positive or signed NAE on three literals uses the three opposite-literal pair equations (a complemented literal is transported into the parity RHS); anchored R(a;b,c) uses two equality equations. Keep exact owner and actual coordinate IDs. Under a fixed choice for every owner, the source is feasible iff the chosen equations together with the fixed guard equations are consistent. Here guards are coordinate pins or pair-parity equations, not arbitrary dense affine rows. Use a constant reference vertex for pins. In the doubled graph each chosen equation x_u XOR x_v=b gives edges (u,i)--(v,i XOR b) for i=0,1. Inconsistency iff some (v,0) reaches (v,1). Proof: inconsistent closed walk has odd accumulated parity; conversely in a consistent component choose one root bit and lift along paths, path-independent, orient the constant component to satisfy pins. Source witness follows from every owner having a selected true equation. Conversely any source model selects one true equation per owner. The selector-conditional reachability can be represented with O((n+1)^3+m) Boolean gates by the standard layered recurrence for reachability (including diagonal and direct-edge base cases, actual choice guards, and OR over doubled vertices). It does not yield a polynomial procedure to decide existence of a consistent selection: that task includes NAE-SAT, and universal selector rejection includes UNSAT. A conditional path contradiction is valid only when all its edge-choice literals and guard premises hold. A source-level unconditional equation requires discharge of all alternatives, not just a selected witness. No semantic merge oracle.

## Theorem B (PROVED): unavoidable exponential flat selector CNF on a simple R chart
Use k serial diamonds with endpoints v_0,...,v_k and two internal vertices per diamond; four optional edges per diamond. Each optional undirected equality edge uv has a unique private dummy d_e and an owner R(u;v,d_e)=(x_u=x_v OR x_u=x_d_e). Its selector y_e=1 selects the actual edge, y_e=0 selects the dummy equality. Pin v_0=0 and v_k=1. Private leaf equalities never connect actual vertices. Thus the rejected selection words are exactly those where every diamond has at least one complete selected two-edge path. There are 2^k inclusion-minimal rejected selector sets, one path per diamond. Any exact CNF over the original selector bits alone for accepted selections needs at least 2^k clauses, even allowing arbitrary literal signs. For each minimal rejected set P, take a clause falsified at its indicator. Its negative-literal set D is contained in P and its positive-literal set disjoint from P. The indicator of D also falsifies it. Minimality forces D=P; no clause serves two distinct P. This is a genuine representation lower bound, not a bound on solver time or on auxiliary-variable CNFs. The rejecting function is the AND of k ORs of the two length-two conjunctions, a linear-size circuit; the source itself is trivially SAT by selecting all dummy options. It is a BH16-style R chart with two opposite pins, not a claimed genuine strict four-partition compiler. It falsifies compulsory flat explicit enumeration of minimal path clauses, and supports using factored guard DAGs instead. It does not exclude lazy learning of a small sufficient subset on a particular instance.

## Executable combined closure
A parity DSU stores an actual signed forest and a reference vertex; each chart/branch has its own guards. On each owner enumerate its 8 truth patterns consistent with current pair relations/pins, reject if none, force any coordinate or pair parity common to every allowed pattern. Each strict deduction joins components; restart closure. This is exact because all global satisfying assignments of that chart restrict to an allowed pattern. At fixed point a complete owner is dropped logically only if every pattern consistent with the guard is allowed. If all owners complete, arbitrary free component bits reconstruct a verified witness. Otherwise branch on an unknown coordinate/pair parity with two disjoint exhaustive guard children; negative only after both reject. Optional full failed-parity probing at stagnation tests both guards by closure; an UNSAT branch forces the other, and two rejects imply contradiction. A SAT probe gives a verified witness. A budget decline is UNKNOWN, never negative. Each per-node closure has <=n successful forest joins and <=n+1 scans; a scan costs O(m n) elementary time with naive parent traversal, constant local truth-pattern enumeration; candidate list O(m), O(m) paired probe calls per stagnation round, at most n new joins. The per-node costs are polynomial, but the aggregate DFS can still be exponential. No claim of universal contraction. Serial depth <=n with copied O(n)-size arrays and polynomial temporary candidate lists, so polynomial peak space even without a time bound; CM <= (T+1)S. Copy cells, probes, guard adds, parent searches, branches, closure and pattern checks recorded; no physical CM or bit-level stopwatch. Code cap 1,000,000 pattern tests, checked at scan boundaries, so at most 8m overshoot. The source witness from BS16 is not supplied to any solver; only the authenticated owner list is read.
