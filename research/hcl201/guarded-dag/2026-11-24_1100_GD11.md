## A. Exact signed cut identity (PROVED)
Let D be a finite acyclic directed multigraph with distinguished distinct s,t, n explicitly indexed source bits x and affine domain G. Each edge e=(u,v) has a Boolean guard g_e(A_e x+b_e), evaluable in paid time. Noncoverage means no enabled s->t path. Source SAT equals noncoverage only when a complete sound source compiler is authenticated. This is not a physical E4/B4 compiler.

For fixed x, let c_s=1,c_t=0 and each internal vertex have a selection bit c_v and marker m_v. Isolated internal vertices may be discarded. Require m_v<=c_v. For every enabled edge u->v require c_u<=c_v, and prohibit c_u=m_v=1 (m_s=m_t=0). Give a marked vertex weight -1, others +1; multiply each weight exactly once. Equivalently each internal vertex has states unselected, selected-unmarked, selected-marked, weights +1,+1,-1. Source/sink fixed; only pair-local edge checks and unary weights needed. For each closed selected set C containing s and excluding t, let Z(C) be the selected non-source vertices with no enabled incoming edge from C. Exactly subsets of Z(C) can be marked. Summing weights over markers yields (1-1)^|Z(C)|. If t is reachable there is no closed C. Otherwise reachable set R is closed and every v in R minus s has a predecessor in R, so contributes 1. Every other closed C contains R properly. In a topological order take earliest vertex v in C minus R; it has no enabled predecessor from C minus R, nor from R (would imply reachable), so Z(C) nonempty. Such C contributes 0. Therefore for EACH x, signed sum equals 1 iff t not reachable and 0 otherwise. Summing over x in G counts source assignments EXACTLY, not cut certificates. No inclusion-exclusion over edge subsets is required. Works for multiple incoming edges and parallel arcs. For cyclic graphs it fails: an isolated enabled directed two-cycle with distinct isolated s,t gives two supported closed cuts, true count 1. Reject cyclic eligibility or use GD09 existential decision separately. No universal counting claim.

## B. Width-preserving affine factor compilation (PROVED)
Start with GD09's explicit edge-factor tree: forms are source guard observations and internal selection bits of each incident endpoint. Append affine guard factors if G is not parameterized out. Let A_J contain observation rows of factors in a tree subtree J, and w_J=rank(A_J)+rank(A_out)-rank(A). Let w=max w_J, d=max local rank. For every nonisolated internal vertex choose one incident edge as its anchor, preferring an incoming edge. Attach its unary sign and m<=c condition to that factor. Include m_v in all incoming factors and its anchor. A factor can acquire at most two marker coordinates because its endpoints are the only eligible anchors. No extra tree leaf or large fan-in relation is required. Every marker appearing on both sides of a tree cut has its selection bit appearing on both sides. The source, selection and marker coordinate spaces are independent (substitute endpoints and parameterize source guard if desired). The rank intersection dimension of the signed factors equals the old w_J plus the number of shared marker coordinates. The latter is at most the number of shared selection coordinates, which is <=w_J. Hence w'_J<=2w_J and d'_e<=d_e+2. This holds for every supplied tree simultaneously; actual width may be unchanged if each marker occurs in one factor only.

As in GD09, collect all observation occurrences into matrix A', form parity check H with ker H=im A', retain local nonzero rows with weight +/-1 keyed by H_e y_e. A consistent concatenation of local words has XOR syndrome zero, and exactly 2^(n+2v-rank A') preimages in the source-plus-cut-marker variables (v=number of nonisolated internal vertices, affine guard equations encoded as local factors). Thus weighted compatible row sum times that factor counts original nonreaching x, including unobserved source bits. Each local row enumerated over a basis of its observation space, not over the whole source. Constants evaluated in local guard functions. Row weight must be multiplied once, even when DAG consumers reuse a table.

At a tree join, multiply child signed counts and ADD all contributions with equal parent syndrome. Retain only algebraically extendable states; zero weighted entries can be dropped in this exact arithmetic evaluator, not misreported as absence of compatible existential certificates. Intermediate counts can be negative; don't truncate. The root count is nonnegative by A. Signed integers have polynomial bit length (at most O(total observation occurrences + n + v) for unit weights) because absolute sums are bounded by number of raw local tuples. T<=2^max(d+2,4w) poly(N), S<=2^(2w) poly(N) on the same serial execution, including rank tests, leaf discovery, arithmetic, source acquisition if polynomial, and one supplied/paid tree. CM<=(T+1)S. Exact rank checking of supplied tree polynomial; universal discovery unresolved. ## C. Certified closure, joint probes and reconstruction
Before evaluation, exhaust sound unconditional local support closure: delete a nonzero weighted row only if its syndrome cannot be canceled by the sum of affine hulls of other local nonzero row supports. Restart after any deletion; rerun on every added guard and before any witness pin. This preserves every nonzero compatible tuple, hence its signed sum. It is not complete semantic closure and a signed zero partial state cannot be used as a row-level logical fact. The exact root count under a new affine guard is a genuine source count. Append q affine probe rows as new leaves; old signed widths rise by at most q, new cuts at most q. Evaluate each of 2^q RHS words if full profile required; this remains polynomial for q=O(log N) and eligible base widths, and requires paid acquisition per word. No implication that arbitrary higher-rank profiles are cheap.

To lift a source witness, start with positive root count. Test one coordinate=0 by exact count with all previous pins retained. If positive choose it, else choose 1 since parent count splits additively. Reapply certified local closure after every pin and stagnation before branching. At most n coordinate choices; verify complete source and graph. No arbitrary signed partial term is a witness. Existing GD09 affine identity scheme then uses <=n+1 exact witness/decision probes, each one new global parity, and charged reconstruction; no accumulated redundant guards required for exact probe width, but unconditional identities retained in a separate closure ledger. This complete identity-basis orchestration is symbolic; coordinate pin reconstruction and single-parity counts executed. Arbitrary owner budgets/occupancy and nonlinear protected features must remain explicit factors or exact paid profiles; no independent minimization, quotienting, or general matching transfer.
