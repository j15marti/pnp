## 2. Theorem A (PROVED): affine observation code times live reachability
First Gaussian-eliminate unconditional domain equations; inconsistent domain has zero uncovered assignments. Substitute x=x0+Kz. Translate constants into the local guard truth tables. Let A be the matrix of all homogeneous observation rows on z (repetitions retained), M its row count and r=rank A. Each observation word y=Az is in C=im A. Compute a full-row-rank parity-check matrix H with ker H=C by row dependence elimination. Equivalently, retain affine observations and use a fixed syndrome Hb. All discovery polynomial bit work. Every realizable observation word has exactly 2^(dim D-r) preimages, no guesses of source values.

For cut i, let P_i and S_i be spans of columns of H in past and future observation positions. A partial syndrome s must be in P_i and, in homogeneous convention, in S_i (target shifted in affine convention). Define w_i=dim(P_i intersect S_i). Only 2^w_i syndrome states survive. Exact alternative computation: if A_L,A_R are the past and future rows of A, then
w_i = rank A_L + rank A_R - rank A.
Proof: rank H_L = |L| - dim(C supported on L) = |L|-r+rank A_R; analogously for H_R. Since H_L+H_R spans the full column space, subtract M-r to obtain equality. This is classical linear-code trellis width, not a new theorem about codes.

Let R be the subset of already potentially reachable live vertices (a vertex with a future outgoing edge and a processed incoming edge, or the source). Store only reachability in the processed prefix; sink already reached means discard this state for noncoverage. A vertex whose last outgoing edge has been processed is no longer needed. Let p_i be the number of structurally live vertices at the cut (can omit permanently false/true coordinates with proof). At initial cut source is fixed. For event i+1, enumerate its local observation words using a basis of rank d_i (or all raw bit patterns, as reference code does). Update s by XOR of corresponding H columns, reject if suffix-span test fails, evaluate all event guards and propagate R through arcs, discard if sink reached, then restrict R to next live vertices. Key is (cut, exact partial syndrome, exact reachable subset); optionally use explicit ordered guard scope and original source identities for cross-query caches. Merge identical keys only.

Induction: each DP key represents exactly its prefix words with that syndrome and reach state, excluding sink-reaching histories and globally impossible prefixes. Future code completions are identical for equal s, and reachability for a fixed suffix depends only on R. Thus no cross-history guard correlation lost. At the end require syndrome zero (or affine target), no sink. Existence iff noncoverage. Store one actual prefix backlink per key; solve Az=y and original affine domain by Gaussian elimination to reconstruct original x. If counting, add prefix multiplicities on equal keys; each full observation word is processed exactly once regardless of number of enabled paths. Multiply by constant preimage count 2^(dim D-r). If exact compiler is not parsimonious at the original variable level, do not mislabel auxiliary count as source count.

Time bound with w=max_i w_i, p=max_i p_i, d=max_i d_i: 2^(w+p+d) poly(N), assuming polynomial guard evaluation. More precisely sum_i 2^(w_i+p_i+d_(i+1)) times polynomial bit overhead. State cap at cut 2^(w_i+p_i), one actual word/backlink costs poly(N). Rolling tables + saved full witness prefixes or retained backlinks give peak S<=2^(w+p)poly(N). CM=sum live bits per sequential step<=T max(1,S) (including retained input); no claimed lower bound. Deterministic ordered dictionaries rather than assumed free hashing suffice. Charge every attempted transition, suffix elimination, rejected edge, key lookup, local basis choice, path copy, witness check, and source acquisition. Code enumerates raw observation count per event <=20, uses BigInt and Map; theoretical rank-local enumeration and deterministic bit bounds are symbolic. With logarithmic w+p+d and paid exact source/guard acquisition, polynomial decision and exact counting on x follow; no universally logarithmic order proved.

## 3. Theorem B (PROVED): witnessed affine hull in the SAME state budget
For each key retain a real representative prefix word a and a basis of differences b_j+a where every b_j is a real prefix word of that key. On a fixed valid transition all these words append the same local bits, so their new hull is exactly the old hull translated/embedded. At a merge, Gaussian-eliminate differences of the incoming representatives and basis witnesses relative to the existing representative. This spans precisely the hull of the union of actual histories. It does NOT replace actual support by its affine hull, because future reach tests use the exact key and never enumerate fictitious words. All witnesses in one key have identical suffix possibilities by Theorem A. Induct on cut and transitions. At terminal, lift each observation-word basis witness with a fixed affine section of A, and add a base witness plus every kernel basis direction of A inside D. Then the resulting actual x-witnesses span exactly the affine hull of the uncovered set. At most n+1 independent actual final witnesses are necessary; storing a polynomial number of candidates per key changes only polynomial factors in T and S. For an affine protected observation map, project this witnessed hull; its annihilator yields all affine identities on that observation. General nonlinear protected features not covered. If sound but incomplete DAG, these are valid necessary identities for actual SAT, but may miss additional identities.

Forced information protocol: reduce all guards by current unconditional affine domain, discard impossible edges, propagate unconditional reachability; repeat when new identities are inserted and before further search. All emitted identities are annihilator equations of the actual hull, relative to the current domain. Reinsert independent identities one at a time, recompute guard closure, and retain external guard scope for conditional queries. A theorem-A/B call on an affine guarded subdomain does not assert an unconditional source pin. At most n new independent affine identities per fixed source stage; charge each recomputation (width can change). A useful variant: compute identity probes against original fixed domain rather than repeatedly increasing pin rank; restriction by one affine equation raises any w_i by at most one because both component row ranks cannot increase and total rank falls by at most one. No free complete cooperative closure. Executed closure includes affine-domain reduction, impossible/constant guards, unconditional paths and exact hull feedback; other terminals/source closure unexecuted. No recursive search branch in these tests.

## 4. Theorem C (PROVED): dominance only for decision
Within an identical partial syndrome, if R1 subset R2, discard R2 when searching for a NONREACHING assignment. For every common suffix the reachable sets are monotone in their initial sets, so any avoiding suffix from R2 also avoids from R1. Retain an actual witness for R1. Do not apply this pruning when counting or extracting complete identities: R2 can encode different actual assignments even if it has no unique decision continuation. Naive pairwise dominance checks cost at most poly(N) sum_i 2^(w_i+2p_i), separately charged. Antichain bound per syndrome <=binomial(p_i,floor(p_i/2)) does not ensure polynomial. Concrete family below realizes 2^h incomparable states on 2h vertices, even w=0. This is a fixed-event-order representation barrier, not an unrestricted runtime lower bound.

## 5. Direct signed tetravalent compiler and relative guard rank (PROVED)
For each E4 or B4 node use its four incident wire bits, shifted by local incidence signs. E4 accepts exactly all equal; B4 exactly two ones. A two-vertex contradiction DAG has one edge per forbidden local pattern, guarded by the four literal values of that pattern. Parallel edges OR exactly: sink reachable iff any local node invalid. Wire constraints x_u XOR x_v=s, if represented by separate ports, have one affine rejection equation x_u XOR x_v=1+s. With one bit per wire the wire correlation is built in. Thus linear-size exact compilation and original bit reconstruction for the explicit signed tetravalent relation model (not physical coloring compiler or exact matching quotient acquisition).

Both E4 and B4 are invariant under simultaneous complement. Use three relative observations x_j XOR x_0 (adjust signs in truth table) per local scope; E4 permits one of eight relative patterns, B4 permits three. A NAE triple needs two observations, excludes one relative pattern. Evaluate all local rejection arcs in one event using the same basis; an isolated upper-owner relaxation need not be complement invariant, so retain absolute guards unless paired symmetry actually certified. The two-vertex DAG has p<=1, but w need not be small. At whole-constraint cuts of the relative encoding, row spans are graph incidence difference spaces: rank A_Q=n-c_Q with isolates counted, and rank A=n-c. Hence w(Q)=n+c-c_Q-c_R, agreeing with BH01's cut formula. This removes absolute orientations and makes cut-width discovery for a given order union-find computable. It is not a proof of a universally good ordering. For DO02, a certified local equality gadget can export its true affine hull to the outer source as an exact necessary equality; after substitution re-evaluate widths. Finding all such gadgets is not free.

Falsify the stronger claim that constant frontier or polynomial circuit size suffices: arbitrary 3-CNF maps to a two-vertex parallel-edge graph with one affine conjunction of at most three equations per violated clause. Coverage is exactly UNSAT, hence coNP-complete (uncovered witness is directly verified). No inference P!=NP. Falsify rank-only for this DP: take h independent bits x_i, source edges to pair u_i^0,u_i^1 with complementary guards, all first; then both vertices of pair have arcs to sink with common independent guard y_i=1. Group each pair of complementary or equal guards in one event. At midpoint all 2^h reachable sets are incomparable, w=0, p=2h. All are extendible to noncoverage by y=0. Actual DP exponential in this schedule even after dominance; a better interleaved order or direct algebra solves this family cheaply. Never promote this to compulsory work.
