## Aggregate recurrence (new)
For any rooted exhaustive finite computation tree, suppose each node has positive integer credit a(v) >= 1, a(root) <= N^A, depth <= N^D, representation and per-node aggregate bit work (including failed probes, all generated children, verification, communication, reverse maps and terminal work) <= N^Q. For a nonleaf define r(v)=max(1,sum_{u child of v} a(u)/a(v)). Suppose every root-to-node path has product of r over its strict ancestors <= N^B. Then the total number of nodes is at most (N^D+1) N^(A+B). Proof: assign mass 1 at root and distribute it at each nonleaf in proportions a(u)/sum a(children). Total mass at any level <=1. Inductively a(v) <= a(root) mass(v) product r along ancestors, so the sum of credits on any level <= N^(A+B). Every node has credit at least 1. Summing levels proves the bound. Thus total bit work is polynomial, with all powers fixed; keeping all nodes and maps costs polynomial peak storage, and cumulative memory is bounded by T*S in a serial bit model. Unfolded tree is an upper bound even for safely shared DAG nodes, provided every incoming consumer and validation is charged. No probability assumption or stochastic algorithm: mass is a deterministic proof device. Rational arithmetic in the proof need not be computed; a path-product certificate can be verified with exact integers of polynomial bit length when depth and per-node credit bit length are polynomial. This is a relaxation of per-branch sum a(children) <= a(parent): bounded occasional deficits are allowed; proving a path bound and uniformly obtaining each split are still necessary.

Special case: after charged sound closure, a live node has at most two unresolved children. A failed child certified UNSAT is a charged terminal, not an unresolved obligation; it forces the other polarity under the current guard. If no path has more than K=C log2 N two-live forks, there are at most 2^K live nodes at each level (binary skeleton or the mass argument with a=1), and at most (D+1)2^K live nodes at depth <=D, plus at most two terminal children per live node. A fixed polynomial bound on per-node work and depth is sufficient. This permits many unary deductions. It does NOT imply a universal logarithmic-fork schedule. A finite observed tree cannot supply uniform discovery. If both children retain size n-1, for every fixed c, 2(n-1)^c > n^c-1 for sufficiently large n. Hence a universal immediate power-credit rule with a=n^c cannot accept such a split; this is a local rule obstruction only, not a lower bound on SAT. All branch coverage and guards must be verified; a conditional failed literal is not global unless guard is empty.
