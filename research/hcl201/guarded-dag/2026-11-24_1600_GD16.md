## A. Exact syndrome-conditioned antichain terminal (PROVED)
Input: explicit layered directed acyclic multigraph with one source and one contradiction sink; each indexed edge guarded by affine equations on one common free Boolean chart z. SAT means some z with NO enabled source-to-sink path. Arbitrary acyclic graph can be layered by private mandatory subdivisions, preserving reachability and path identity, polynomial expansion. No free physical E4/B4, L/L2, occupancy or matching compiler. Any retained nonaffine constraint must be authenticated as part of the graph or a charged extension of the state. First apply GD15/GD14 certified closure: Gaussian consistency, impossible and mandatory edges; mandatory path implies UNSAT, absence of even possible path implies SAT; if a rank-one optional edge alone with mandatory edges creates a path, force its complementary equation. Reapply after every pin and at stagnation before the terminal. Arbitrary initial affine guard and all deductions are retained, substituted by Gaussian elimination, then recompute spans. No claim of complete semantic closure.

For transition i let W_i be the span of its guard rows, A_i the sum of W_j for j<i, B_i the sum for j>=i, I_i=A_i intersection B_i. Define Q_i=W_i+I_i+I_(i+1). Work on a freely parameterized chart after closure. All rowspaces computed by Gaussian elimination. The layer observation is a linear functional on Q_i; every such functional is realizable. Enumerate its 2^dim(Q_i) values if within the paid cap. Its restrictions a,b to I_i,I_(i+1) and truth values of all local edge guards are exact. In particular do NOT independently select edge truth values.

For every functional a on I_i, maintain inclusion-minimal sets S of vertices reachable at layer i by actual assignments to A_i agreeing with a, with a compatible prefix witness. Initial source singleton. For each retained S and each functional v on Q_i agreeing with a, form T_v(S), all heads of enabled edges from S. Insert into the bucket b=v|I_(i+1); discard a superset of an already retained mask, or remove existing supersets of a new mask. Equality can merge; guards, layer and syndrome bucket must match. Keep a representative prefix system for each retained mask. Inductively all retained masks are realizable, and each realizable mask contains a retained mask with the same interface value. Proof: Q_i subset B_i, so its intersection with A_i lies in I_i; agreement on I_i is sufficient for exact Gaussian gluing. T_v is monotone for inclusion. Every suppressed prefix can therefore be replaced by a realizable smaller one without invalidating any compatible suffix functional. The final I is zero. A retained mask omitting the sink exists iff there is a safe chart word. This proves both SAT directions without path counting. Witness: concatenate the retained prefix local functional equations, solve with original chart pins, and independently evaluate original graph nonreach. Source-private witnesses require the separately charged authenticated adapter.

This is decision dominance, not count preservation, not exact equality of arbitrary protected-interface relations. Multiple masks with different prefix assignments can merge only for the stated continuation contract. A later constraint on a forgotten row invalidates that contract unless registered before acquisition. The same theorem works in reverse: compute inclusion-minimal sets of vertices reaching the sink from suffix assignments. For any cut, safe existence iff some compatible pair of forward and reverse masks has empty intersection. Agreement on actual I is necessary and sufficient to glue the prefix and suffix. This bidirectional terminal is symbolic here; neither reverse acquisition nor a universal cheap cut is assumed.

## D. Zero overlap and local rank one do not suffice (PROVED)
For any strict 3-CNF F on n variables with m clauses, build m parallel clause tracks. Unconditional split at source, then one layer per variable, in each track retain its arc iff that variable does not satisfy the track's clause (mandatory if absent), unconditional merge into contradiction sink. Every enabled track corresponds to exactly one falsified clause. Thus P(z)=# falsified clauses; reach iff F(z) is false; safe iff F SAT. Graph has O(nm) edges, explicit polynomial encoding, all rows in layer i are multiples of coordinate i, I_i=0 and r_i<=1. The construction preserves both labels and source assignment. Consequently universal coverage is coNP-complete even at zero algebraic overlap and one fresh bit per layer (membership by a safe assignment). Exact Boolean identity is likewise coNP-complete here by comparison with an always-covered graph in matching layers. This is not an unconditional runtime lower bound. It shows that GD15's multiplicity/tensor or another structural bound is necessary for its specific polynomial guarantee; merely replacing numeric counts by Boolean states does not resolve arbitrary SAT. QC01's distinction between syndrome rank and number of guard functions has a qualitative DAG counterpart.

## E. Explicit actual frontier obstruction despite closure (PROVED)
For each k create k disjoint groups of four tracks, labelled by all two-bit patterns. At the two fresh coordinate layers for group i, retain its track iff that coordinate matches the label, leave all other groups' arcs mandatory. Split and final merge are mandatory. Each path has two optional guarded arcs, so the stated mandatory/single-optional closure is stagnant. After all 2k layers exactly one track per group survives, giving 4^k distinct masks of cardinality k, all incomparable, all in the SAME I=0 bucket. The full prescribed antichain is forced to retain them; O(k^2) edges, r<=1, overlap zero, all words covered. SAT neighbor: put the same fresh-bit guard x=1 on every final merge arc; x=0 is a safe word, but the same intermediate frontier occurs. For base, P(z)=k constant; neighbor P(z)=k or 0. GD15 singleton-positive-multiplicity terminal handles both in polynomial time; also direct reasoning or grouping can solve them. Therefore this is an exponential actual state lower bound ONLY for the prescribed antichain algorithm and ordering, not all representations or all algorithms. Stronger closure can derive shortcuts; no claim of obstruction to complete closure. Neither family is a demonstrated hard diagonal sequence.
