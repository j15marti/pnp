## Lemma: guarded reason summaries with immutable dependencies

An atom is a row with exact signed literals and immutable identity in a certified active database. A reason proving output literal l from clause C has prerequisite set {-x: x in C other than l}; a contradiction reason has all negated row literals as prerequisites and distinguished output bottom. A grammar of such implications is summarized by (R,O,D), where D is the set of referenced immutable clause identities. Composition AB is (R_A union (R_B minus O_A), O_A union O_B, D_A union D_B). Treat bottom as an output marker, not an ordinary literal. For any model of the authenticated database in which R holds, all O follow, by induction. This is a sufficient contract, not necessarily minimal. Each leaf must be exact, and at consumption every dependency must be active and certified in its original scope; learned row identities must be checked chronologically, with transitive validity of their certificates. If rollback removes a row, invalidate dependent summaries and transitively dependent learned rows or revalidate from active rows. No reuse based on R/O or a hash alone. Deletion of a learned row with retained independently certified consumers is possible only if their certification context remains valid; do not confuse deletion from active propagation with erasure of a sound theorem. Example C1=(x OR y), C2=(!x OR y), guard !y, output bottom. Remove C1; guard remains consistent with C2, so stale cached summary cannot certify contradiction. If C1 was an independently proved consequence of immutable original source, it can instead be retained in a separate certified archive, charged and explicitly referenced.

For finite active immutable universe M, r variables, g grammar nodes, h consumers, bitset implementation O(g(r+M)+h(r+M)) elementary bit accesses plus exact clause parsing and ID validation; polynomial if M,g,h and encoded identities polynomial in original N. This is NOT a bound for arbitrary compressed parametrized proof grammars, nonmonotone transformations, or acquisition. No expansion of a fixed literal implication grammar required.
