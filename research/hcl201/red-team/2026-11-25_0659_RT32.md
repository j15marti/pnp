## 1. Strict deficiency-one sign theorem
Input an authenticated rank-two avoidance chart over F2^r with m=r+1, full observation rank r, and rank(sum U_i for i in J)>=|J| for every proper owner subset J. This holds for the inclusion-minimal maximum-deficiency core when maximum deficiency is one, via DS15. All statements concern the actual normalized chart, not hidden extra guards. Perform certified rank-zero/rank-one and same-plane closure where applicable, then recertify hypotheses or decline; raw tests below audit the stated class itself (including repeated-plane controls).

Write L_i as two independent rows, s as a 2m-bit sign word, and let G=im L (rank r) be the gauge subspace. Translation of x proves signings in a common coset of G have identical label. A nonzero direction a in U_i has an owner-local two-bit coefficient mask c_{ia}; its satisfied equation is a*x=1+c_{ia}*s. For two signings s,t put delta=s+t. If delta is outside G, lift each a to (a,c_{ia}*delta). The sum of lifted spaces has rank r+1 (otherwise delta is a common source evaluation); proper subsets satisfy Rado's inequalities since projection does not increase rank. Hence polynomial deterministic linear/partition matroid intersection yields a full independent lifted transversal T, one direction per owner. Its projected rows have rank r and unique dependence lambda. Since the lifts are independent, sum lambda_i c_{ia_i}*delta=1. For each signing, the projected equations are consistent iff sum lambda_i(1+c_{ia_i}*s)=0. These consistency bits are opposite for s,t, so exactly one system has a unique solution satisfying every owner. This proves at most one gauge coset of UNSAT signings; it is not a claim that one exists.

## 3. Arbitrary deficiency: exact affine-cube cancellation
For an RT31 Hall core m=r+d, let s(alpha)=s+sum alpha_j delta_j for d specified independent sign shifts. Use the same formal selector variables z for every signing. Sum P_{s(alpha)}(z) over all alpha in F2^d in characteristic two. Combining the summations over x and alpha makes a product of m affine forms in m Boolean variables. Only the coefficient hitting all m variables survives, so there can be no constant term or repeated variable in a contributing product. The result is exactly det[A(z)|D(z)], with D_ij(z)=sum_a z_ia(c_ia*delta_j), A as RT31. Each determinant monomial selects one row direction per owner. Deterministic matroid intersection tests the identity and, when nonzero, produces a full-rank transversal; solving in (x,alpha) yields a witness for one signing in the cube. If all but one distinct signing are independently certified UNSAT, the determinant equals the remaining compatibility polynomial, so exact deterministic two-sided decision follows. No claim that these reference refutations can always be acquired. Even with logarithmic d, acquiring the other certificates is a separate charged obligation. All-sign cube aggregation is not the same as deciding a designated input.

## 4. Private exact substitutions cannot reduce maximum rank-Hall deficiency
Scope: replace each original rank-two puncture i by an exact existential gadget of avoidance packets using only its two original observation directions U_i and its own private coordinates Y_i. Private blocks disjoint; exact projection for every exterior word, including forbidden word. Apply DS15 maximal-deficiency extraction to the private projections of each gadget's row spaces. Since the projection of the whole gadget is not unrestricted, its maximum private deficiency is >=1 (otherwise independent representatives permit extension of every exterior word). Choose a maximizing owner subregistry C_i and let p_i be its private span rank. The outside owners have independent representatives modulo that private span, so every core model extends while preserving exterior and core observations. Its exterior projection is therefore still the original puncture. Let W_i be the full row span of C_i. The projection depends only on K_i=W_i intersect U_i: if two exterior words agree on K_i, the private linear system can preserve every core row observation, since all private-row dependencies correspond to K_i. Since a genuine two-bit puncture has no nonzero period on its observation plane, K_i=U_i. For any old subset J, the union of C_i has full rank sum_i p_i+rank(sum_i U_i), by disjoint private coordinates and exact pure exterior kernels. Its deficiency is sum_i (|C_i|-p_i)-rank(sum_i U_i) >= |J|-rank(sum_i U_i). Maximize over J. Thus local exact padding/substitution with no extra exterior directions cannot lower maximum deficiency. This is an algebraic barrier, not a proof against nonlocal transformations or arbitrary SAT algorithms.
