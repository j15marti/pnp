## 2. Exact non-incidence support compiler
Use colors Q=F2^2 minus {00}. For a simple graph G=(V,E), n=|V|, m=|E|, use syndrome space H=(F2^2)^E. Let J_e(a) insert color a in block e; J_v(a) insert a in every edge block incident to v. Independent factors:
    S_v={J_v(a):a in Q}, S_e={J_e(a):a in Q}.
The target is zero. For each edge uv the target condition is x_u+x_v+y_e=0, hence y_e=x_u+x_v. Since all three variables are nonzero, the target is feasible iff G has a proper 3-coloring. Every coloring gives exactly one tag tuple and every target tuple gives a coloring (no counting transfer to arbitrary original representations). Each support is a punctured two-dimensional linear plane, exactly three values when v is not isolated. Realize each factor as a private K4 with its three star edges at vertex 0 tagged by those three values, all other edges zero. Every PM chooses exactly one star edge, and uniquely determines a value; full occupancy is fixed and the factors have private vertices. This is an explicit polynomial compiler to independent tagged PM, 4(n+m) physical vertices, 6(n+m) edges, dense encoding O((n+m)m+(n+m)log(n+m)) bits. Source witness checking scans original edges and PMs. No abstract unpriced oracle. NP-completeness of this explicit class follows from graph 3-colorability; greedily delete vertices of degree <=1 and extend any coloring backwards, so the min-degree-two restriction retains hardness (empty core maps to fixed SAT triangle). Membership in NP via chosen PMs. This is NP-completeness of a restricted INPUT class, not a separation.

## 3. Two representation-optimization theorems (fixed factors)
Let L_i=span(S_i) for all vertex and edge factors. For min degree >=2, these two-dimensional planes intersect pairwise only at zero: edge planes have distinct blocks; a vertex plane has nonzero entries in at least two incident blocks; distinct vertex supports share at most one edge block and each has another block. Global span equals H because all edge planes occur.
(a) MS02 binary affine fibers. Any two affine cosets whose union equals a 3-point support must include a pair; that pair's direction is a nonzero vector in L_i. Edge factor directions are in independent blocks, so any global variation space has rank r >= m. Conversely use the same nonzero color direction d in every factor, split its triangle into the pair differing by J_i(d) and the remaining singleton. All vertex directions are sums of incident edge directions. Thus EXACT min r=m, even allowing arbitrary overlapping fibers and offsets, with this fixed factor partition.
(b) S02/M03 common dictionary D with q=nullity(D). For ANY exact hereditary coefficient representation S_i=a_i+D 1_{I_i}, empty allowed, each nonloop singleton gives a direction in L_i (a_i is one of the three actual points). All differences from a_i span L_i, so at least two independent nonzero dictionary columns must be accessible to each factor. Pairwise trivial intersections imply at least 2(n+m) distinct nonzero columns; rank(D)<=2m, hence q>=2n (remove unused loops first). Conversely choose an anchor in each triangle and its other two differences as dictionary columns; use a rank-one matroid on those two columns, all other columns loops. This is exact and has q=2n. Therefore EXACT min q=2n, even for arbitrary hereditary representations with free choice of offsets and dependent columns in the same syndrome space. This improves RT02: efficient optimal rank-one recognition alone does NOT imply low dictionary nullity. Each local factor is indeed M03's weighted star/rank-one terminal case. Nontrivial local translation impossible (odd cardinality), and rank-one independent peeling initially inapplicable. No assertion about global/grouped translation or alternate dictionaries after changing factors or tags.

## 4. MS03 nonlinear offsets: exact residual quadratic rank and a tradeoff
Represent each of the three nonzero colors by independent two-bit guards (s_i,t_i), using the singleton map f(s,t)=(s,1+s+st), whose 00 and 01 inputs repeat color (0,1); all four guards nonempty. Thus physical variation rank r=0. First coordinate target gives s_e=s_u+s_v for every edge. Substitute these m affine equations. The second coordinate gives
    P_e=1+s_u t_u+s_v t_v+(s_u+s_v)t_e=0.
Every edge equation has private monomial s_u t_e (and s_v t_e); no other equation has either. The m quadratic parts are independent and no nontrivial combination is affine. Thus q_quad=m after the exact MS03 row-reduction/affine-substitution closure for this parametrization. No false inference that four colors imply q small. If one enlarges W to dimension r artificially even though actual variation is zero, the lambda=0 quotient equations are a linear subspace of the original 2m equations with codimension at most r. On the original first-coordinate affine solution space A, their restricted quadratic parts have rank >=m-r. During quotient affine closure A is contained in every intermediate affine space: any affine consequence from a polynomial row combination restricts to an affine polynomial on A, but on A all combinations of P_e have independent quadratic parts, so it restricts to zero. Induction proves the assertion even after substitutions. The final quadratic parts must have rank >=m-r, since restriction to A cannot increase their rank and affine terms restrict to affine terms. No contradiction occurs in this scoped affine closure. Consequently r+q_quad>=m for MS03's terminal with THIS singleton parametrization, even under this W-enlargement tradeoff. This is not a bound over all possible reparametrizations or nonlinear simplification. Actual phases/character computations can exploit other shortcuts; no compulsory loop lower bound.

## 5. Stronger qualitative/affine closure counterexample
Unconditional closure first: exact local support hulls L_i give target solution affine space x_v arbitrary in F2^2, y_e=x_u+x_v. Each factor projection is its full plane. In I03 target-conditioned individual coset closure, complement span for any factor is H: removing a vertex factor leaves all edge planes, removing an edge factor leaves its two endpoint vertex planes plus every other edge plane. Hence all exact singleton fibers survive. This holds on SAT and UNSAT alike.

Strengthen the tested closure to use exact local join J_e=(x_u,x_v,y_e=x_u+x_v, all three nonzero) for each edge, not just individual factors. Alternate exact local domain projections, exact affine hulls of each J_e intersected with the current global affine projection, Gaussian global closure, and probes fixing one entire vertex color or one entire edge difference to ANY of the three nonzero values; then fuse branch affine hulls unconditionally. All conditional conclusions keep the guard. On EVERY triangle-free simple G with min degree >=2 the unconditioned affine system is a fixed point and all such single-factor probes survive. Proof:
* A local edge without restrictions permits six ordered distinct nonzero color pairs. Their affine hull is F2^4. For fixed x_u=a, the two legal other values differ by a; as a runs over Q these span F2^2, so any affine equation valid on all pairs has zero coefficient on x_v and by symmetry on x_u.
* Pin x_k=a. Take x_k fixed, every neighbor of k in the affine line Q minus {a} (direction a), all other vertices free in F2^2. Impose all y_e=x_u+x_v. Use nonzero domains on free vertices and edge differences. Edges incident to k are already exact; every other edge has at most one restricted endpoint because G is triangle-free. With one endpoint restricted to a two-point nonzero line and the other free, the four legal pairs affinely span their product of dimension three: the two possible nonzero fixed values are linearly independent and give both free directions; their difference gives the restricted-endpoint direction. Domain projection on a free neighbor or a nonincident edge difference remains all three nonzero colors (for each desired color there is a compatible choice of the restricted endpoint). Thus this nonempty affine/domain relaxation is stable, containing every actual branch witness but not necessarily any actual witness.
* Pin y_uv=d. Take x_u in Q minus {d}, x_v=x_u+d, all other vertices free. Edge uv is already exact, every other edge has at most one restricted endpoint (simple graph). The same local span and domain argument proves a nonempty fixed point.
* Fusion gives no affine progress: for a vertex pin, any affine functional constant on the union of the three displayed branch relaxations must have zero coefficients on unrestricted vertices; neighbor coefficient annihilates direction a for ALL a in Q, hence zero; pinned vertex coefficient is zero since Q affinely spans F2^2. For an edge pin the only remaining coefficients could be on u,v; their sum annihilates every direction d of the coupled line, so they coincide, and the functional then evaluates on x_u+x_v=d for all d, forcing them to zero. Thus the affine hull of each three-branch union is the entire original affine space. Weaker single-bit probes cannot remove these stable branch relaxations either. Reapplying this same closure/fusion at stagnation repeats the fixed point. No assertion about arbitrary nonaffine guarded-clause learning, higher-order join, multi-factor probes, global integer or matching-syndrome feasibility or GD02 global feature oracle; those can be stronger. In particular this theorem does NOT say the mandatory all-channel closure was executed or failed universally.

## 6. Infinite paired controls with all-order joint syndrome width
Cycle version: Mycielski transform of an odd cycle C_l, l>=5 odd. For any base graph B, make original v_i, twin u_i and apex w; retain original edges, add u_i-v_j and u_j-v_i for each base edge ij, join all u_i to w. Triangle-free base gives triangle-free transform (any triangle involving a twin would give a base triangle, and apex neighbors are independent). If the transform were 3-colorable, rename w color3; replace each original of color3 by its twin color, which is not 3. Across each base edge both originals could not initially have color3, and the added cross edge guarantees the new colors differ. This produces a 2-coloring of the odd cycle, contradiction. Delete only edge w-u_0: color v_0=3, alternate 1/2 along remaining cycle, twins inherit original colors, w=3. Valid SAT neighbor, no other violation. Both min degree>=2. n=2l+1, m=4l (neighbor m-1), all three scalar bounds linear. But the cycle family has cheap structural/constant-width alternatives.

Stronger GRID version: for s>=3 take s by s square grid B, add an edge joining (0,0) and (2,2). Their grid distance is four, so the added edge creates an odd cycle and no triangle. Let G=Mycielski(B). n=2s^2+1, m=7s^2-6s+3. Same proof gives UNSAT. Delete just apex edge to twin of (0,0); checkerboard 1/2 coloring with original (0,0) recolored 3, twins inherit, apex3 gives explicit SAT witness. Triangle-free, min degree>=2 for both. Unlike the cycle version the FIXED exact tag-factor representation has unbounded algebraic cut width for EVERY factor order. Proof:
Partition factors into sides A,B, let U be vertices whose vertex factors are on A, E_A edge factors on A, E_B others. Analyze one bit of each edge block; the two bit copies double all ranks. Side A rank is |E_A|+rank of incidence columns for U restricted to rows E_B, because edge factors cover E_A. Side B similarly. Combined full rank is m per bit. Thus lambda/2 equals the sum of those two projected incidence ranks. For a crossing grid edge uv with u in U, v outside, if its edge factor is on B, its restricted incidence row on side A is the singleton u; otherwise on side B the row is singleton v. The number of DISTINCT chosen endpoints is a lower bound on lambda/2 and these endpoints cover all crossing grid edges. Grid max degree 4, so lambda>= (# crossing grid edges)/2.
For any order take a cut after exactly floor(s^2/2) original grid vertex factors. If >=s/4 rows have both sides, each contributes a horizontal crossing edge. Otherwise there are both a fully selected row and a fully unselected row (otherwise selected or unselected count <s^2/4), so each column contributes a vertical crossing edge. Hence lambda>=s/8. Identical bound for any cut with 1/3 to 2/3 of original grid vertices on either side. Any subcubic branch-decomposition tree with the fixed factors as leaves has such a cut by weighted centroid (weight one on original grid vertex leaves, zero on all others; a centroid has components weight <=2/3 of total, and at least one >=1/3). Thus the width is Omega(s) also over all such trees. Private K4 occupancy is constant, so joint affine width equals syndrome width in the fixed whole-factor representation. A common invertible gauge cannot change dimension. Arbitrary regrouping, absorption, structural recognition, changing the observation representation or different factor leaves are NOT covered; do not infer an unrestricted algorithmic lower bound. This explicit family itself is easy if recognized via the Mycielski compiler and bipartiteness of B. It is a simultaneous parameter obstruction, not a hard family for every solver.
