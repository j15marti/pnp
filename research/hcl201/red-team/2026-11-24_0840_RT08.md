## 1. Explicit family and both-label equivalence
For every integer k>=1 let n=8k, h=n/2=4k. Three coordinate sets X,Y,Z are copies of Z/n. Include all n² ordinary triples (x,y,x+y mod n), plus k special triples (0,y,y+2 mod n), y=0,...,k-1. In the saturated owner flow, for each y have parallel indexed arcs from an independent source to sink, demand one, capacity one, one arc per triple with that y. Tags e_x+e_z in GF(2)^(2n). Each block is one undirected cycle block, all arcs variable in the budget-only model. Binary cycle rank n-1 or n, no integral interior, no rank-one tag reduction. Implicit binary-selection RT07 model: choose <=1 triple per owner and require X,Z odd at every coordinate. Odd counts and total capacity n force exactly one per X, Y, Z. Conversely any perfect triple matching is a feasible tagged flow. The lifted exact integer incidence matrix A has three ones per column, target 1. All statements concern explicit owner/arc/tag data, not assumed geometry, physical L/L2 pullback or arbitrary simultaneous exact acquisition.

Let delta(x,y,z)=(z-x-y) mod n in [0,n-1]. Ordinary delta=0, special delta=2. A perfect matching must have sum delta congruent to -sum_{i=0}^{n-1}i = h mod n. At most k specials can occur, so 0<=sum delta<=2k<h. Impossible. This proves UNSAT. Add just (n-1,h,n-1), of defect h. SAT witness: (x,x,2x) for x=0..h-1, (x,x+1,(2x+1) mod n) for x=h..n-2, and the added triple. The X,Y,Z lists each cover every value once. No extra ordinary or special triples needed. Thus exact infinite one-arc SAT neighbors, including matching-tag model. This is a cheap structured modular contradiction, not unrestricted hardness.

## 2. Exact signed lattice and strictly positive fractional feasibility
Define D_x(y) = ordinary column(x,y,x+y) minus column(0,y,y). This has X part e_x-e_0, zero Y part and Z part e_{x+y}-e_y (all indices cyclic). Let g_j=e_{j+1}-e_j in Z^n. For consecutive owners a,a+1,
  D_x(a+1)-D_x(a)=(0,0,g_{a+x}-g_a).
The cyclic g_j generate the zero-sum integer vectors and their only integral dependency is sum_j g_j=0. For any zero-sum vector d on Z, q_j=-sum_{i=0}^j d_i gives d=sum_j q_j g_j, with q_{n-1}=0. Changing all q by a common integer preserves d. The quotient by differences g_j-g_a is cyclic of order n, measured by sum q mod n, equivalently sum j*d_j mod n. Therefore two intact consecutive owners generate every zero-sum X,Z difference with weighted Z-minus-X total 0 mod n: first correct X using D_x(a), then correct Z using g_j-g_a after making sum q zero by subtracting its average. This is a constructive integral proof, not a numerical rank assertion.

With any compatible guard fixing at most p<=k-1 individual arc bits (compatible meaning each owner still has a choice satisfying its pins), choose one allowed arc per owner as baseline. At most p owner blocks touched; at least one special owner and one disjoint consecutive pair (0,1),(2,3),... remain wholly untouched. The remaining required weighted defect residue is even because target h and all baseline defects are even. A signed difference of the extra arc and its ordinary x=0 counterpart contributes defect 2. Choose coefficient in {0,...,n/2-1} to repair residue. Correct the X and Z differences via the intact pair as above, using no pinned arc changes. Hence A v=1 has an integer solution respecting pins, but not necessarily 0<=v<=1. This holds at the root and throughout the specified lattice-only probe depths. In particular full signed lattice membership, including original owner rows, cannot certify root UNSAT. No assertion of LP feasibility under every guard.

Root LP has a strictly interior rational witness. Start weight 1/n on ordinary arcs, zero on specials. Add epsilon to each special and subtract epsilon from its ordinary x=0 counterpart. This preserves X and Y; the Z discrepancy has sum zero. Over Q it can be corrected using the same pair differences, since rational subtraction of the average of q is always possible. For a fully explicit witness use common denominator den=10 n^4, ordinary numerators den/n=10 n³, special increments n; q_j integral multiples of n, so their average is integral. Each q has magnitude <=kn, centered coefficients <=2kn. Each ordinary entry changes by at most kn+2n²k < 10n³; hence all entries strictly between zero and den (also each owner sum is den, with multiple positive entries). All coordinates are nonforced in the root LP interval sense. This does NOT certify either endpoint of every coordinate is attainable in the LP, and does not imply all LP-conditioned probes survive.

## 3. Arbitrary low-rank projected support
In GF(2), the variation span of the ordinary choices of any two consecutive owners is
  D = { (u,v): sum u=0, sum v=0, sum_j j(u_j+v_j)=0 mod 2 },
with dimension 2n-3. Proof: the integer quotient description above gives the mod-2 span contained in these three constraints. Conversely lift any binary pair satisfying them to zero-sum integer vectors by subtracting the (even) coordinate sums at index zero; their residual weighted Z-minus-X value is even. Adjust one coordinate at index 1 by an even number and compensate at index 0 to make this value zero mod n. Apply the integer two-owner generation result, reduce modulo 2. Three independent constraints for n>=8. Special differences e_y+e_(y+2) lie in D. The tag discrepancy target XOR any owner baseline lies in D since n even and h even.

Let P be any linear map whose restriction to D has rank r. Under p compatible individual arc pins, at least n/2-p of the disjoint consecutive owner pairs are intact. If r+p<=n/2, choose one independent projected variation from each of r distinct intact pairs greedily. Each pair's elementary differences relative to the current baseline span P(D), so an independent variation exists until full rank; each elementary difference changes exactly one owner choice. The r selected changes act on disjoint pairs and can be applied independently. Their subset sums span all P(D). Thus some actual bounded owner selection realizes the projected target under the pins. This is exact projected support, not merely LP or affine-hull membership. Rank is measured on D, not number of output bits. All arbitrary projections up to this bound survive, regardless of adaptive choice, if each test only enforces its own projection and pins. Combining outputs through richer joint reasoning is not ruled out.

Root forced-information closure: every budget-only arc can be selected or omitted; exact affine tag identities on that domain are precisely D's annihilator. The target satisfies them; even after any single compatible arc pin both outcomes lie in the projected/affine support by the bound. The exact-count LP has a strictly interior witness and full signed lattice passes. For k>=2 the lattice-only single-arc probes pass too; repeat the specified closure to stagnation with no new equations or fixed bits. This is not a claim about mandatory stronger cooperative closure; one-step LP endpoint probes and arbitrary nonlinear guards are not covered. Conditional conclusions retain guard IDs. ## 4. New bounded-residue bridge
Keep the actual integer inequalities together with group information, rather than relaxing them separately. Given authenticated owner choice rows and a candidate integer potential w=(w_X,w_Y,w_Z), choose modulus M and compute each column residue d_j=(w^T A_j) mod M in [0,M-1], target residue R=(w^T 1) mod M. A necessary condition is that R modulo M lie in the possible sums of one residue per owner. A simple certificate uses sum of owner minima and sum of owner maxima; if that interval contains no integer congruent to R, reject. A stronger exact projected test is cyclic residue DP across owners (retain witnessed choices); reject if R absent. Membership is necessary, not sufficient for full incidence feasibility. For explicit rows it costs O(M * number of rows) elementary updates, O(M) live keys for decision, O(nM) predecessor storage for witness plus source data, polynomial if M polynomial in encoded N. The interval certificate avoids even residue enumeration; binary-bit arithmetic is polynomial in input/potential bit length. The cyclic family uses w=(-x,-y,z), M=n and interval [0,2k], R=h. This exploits a **bounded modular** obstruction even though both the convex relaxation and unbounded integral lattice accept. Potential discovery is not free: for the supplied named X,Y,Z coordinates try this explicit template and verify every column; arbitrary relabeled geometry, general potential discovery and a universal bound on useful M remain open. ## 5. I08 overlap boundary, independent symbolic theorem
Extend I08 by allowing a parity owner to participate in multiple pair masks. Feasibility is NP-complete already for a graph that is a disjoint union of single edges and 3-leaf stars, all owner classes singleton, no restrictive intervals (0<=k_i<=1). For each variable make an edge of two optional ports with distinct owners; the defect parity at its first endpoint is an arbitrary truth bit (both endpoints exposed if edge not selected, both covered if selected). For each 3-CNF clause make a mandatory center with three optional leaf ports of three new owners. Exactly one leaf is matched, so exactly one occurrence has defect bit zero. Link each occurrence owner to its variable owner with a binary mask excluding exactly the pair (literal false, leaf defect zero). These masks overlap only at variable owners; their mask graph is a disjoint union of stars. A satisfying truth assignment extends by choosing a true literal per clause, and any legal matching gives a satisfying truth assignment from the variable ports. All owner sets singleton, graph O(n+m), exact original match lift and verifier polynomial. Membership in NP immediate. Thus I08's disjointness is essential even for acyclic mask graph and three-edge physical regions, unless P=NP. No contradiction with I08; its reduction uses one parity port only once. This is a symbolic reduction, not executed in the checker. It is not a strict distributed-wheel compilation.
