## 2. Theorem A: strong NP-completeness of simultaneous tagged single-load flow
Given balanced three-dimensional matching (3DM) on sets X,Y,Z of size n and explicitly listed distinct triples T, create one independent binary block per triple t=(x,y,z). Off has cost/tag zero. On consumes one unit of owner y, and emits tag e_x+e_z in GF(2)^(2n), with disjoint X and Z coordinate sets. Capacity for every y is one; global tag target is the all-ones vector on both sets. Local exact affine domain is one bit and cost is single-load. Add a private unconstrained dummy category for off as in I07. All weights and bounds are one; tags have Hamming weight two on selected rows. A concrete graphic join lift uses a disjoint 4-cycle with odd demand at opposite vertices, even elsewhere: exactly the two length-two paths are feasible; mark one edge on the on path with unit owner load and two tag bits, all other labels zero. No geometric wheel claim.

Proof: at most n selected triples by Y capacities. Every X coordinate must be odd, so at least n selected triples, hence exactly n. Every X is selected exactly once. Likewise every Z exactly once, and each Y cap is saturated. Conversely any perfect 3DM selects n legal on rows with target. Polynomial construction and witness check, membership in NP, so NP-complete even without numerical weights. The reduction is parsimonious for binary block assignments (not arbitrary physical lifts); the square has exactly one edge-mask per choice. O(|T|) blocks and graphic edges, O(n|T|+n) bits using dense tags plus indices (sparse tags can be smaller). No reliance on local row acquisition oracle: affine rank 1, explicit two choices. This is hardness of the varying-tag extension, not I07/M07 with their actual restrictions, nor P!=NP.

## 3. Infinite neighboring family: cyclic Latin triples
Take n=2h, X=Y=Z=Z/nZ, T={(x,y,z):z=x+y mod n}. All pairwise projections of the triple set are complete bipartite graphs. The exact count LP (each X,Y,Z incidence sum =1, nonnegative row choices) is feasible with every triple assigned 1/n. Untagged Hall is feasible even with every Y saturated; every row is extendible in the untagged model. All blocks have rank one and no exceptional cost shapes. Signed cost/tag types for distinct triples are distinct, so RT06 grouping alone gives 2^(n²) raw binary count vectors; not a time lower bound.

If perfect 3DM existed, sum z = sum x + sum y mod n, but each sum is n(n-1)/2 = h mod n. Thus h=0 mod n, impossible. This is the classical even cyclic Latin square nontransversal argument, applied here to tagged flow. Add exactly one triple (h,n-1,n-1) not already present; SAT lift selects x=y for 0<=y<h and x=y+1 for h<=y<=n-2, with z=(x+y) mod n, then the added triple. The first h Z values are even, the next h-1 odd values 1..n-3; missing X=h, Y=n-1, Z=n-1. Same capacities and tag target, just one extra binary block. Each is an infinite UNSAT/SAT pair.

## 4. Theorem B: all low-rank linear projections pass, even after saturation
First unsaturated model. All tag vectors lie in E={v: parity(X)=parity(Z)}, dim 2n-1. The two matchings of X to Z belonging to owners y,y+1 form a connected cycle of length 2n: alternating their edges shifts X by one. Over GF(2) their incidence vectors span E (tree paths give any even-weight pair). Partition Y into h consecutive disjoint pairs. Each untouched pair therefore supplies a set of tags spanning E. For any linear map P, rank(P|E)=k<=h, greedily take one tag per fresh pair whose image is outside the previous span. At each step such a tag exists. Obtain k independent projected directions in distinct owner pairs; select any subset, leave others off. Every element of P(E) attainable, including P(target). For any p compatible coordinate pins (specific triple off/on), at most p pairs touched. Choose fixed on rows, turn remaining touched rows off, and use untouched pairs; translated target still in E. Hence rank k<=h-p cannot exclude the target. This covers arbitrary masks, not just coordinate subsets.

Stronger result: impose the certified unconditional owner saturation and take n divisible by four. Work in full 2n tag coordinates. Let b be any one-row-per-Y baseline. All saturated tag vectors lie in b+D, where
 D={v: parity(X)=0, parity(Z)=0, sum_x (x mod 2)v_Xx + sum_z (z mod 2)v_Zz=0 over GF(2)}.
First two invariants hold since replacing one selected row changes exactly two coordinates per side (or cancels). Third follows because x+z=y mod 2 at every allowed triple, so the saturated tag's weighted parity is sum_y y mod 2=h mod 2. Target satisfies all these invariants for n divisible by four. For n=2 mod 4 the target fails the third invariant, so the stronger theorem intentionally excludes that case.

Prove D is the exact variation span already within any consecutive owner pair. For functional (a_x,b_z) to annihilate all within-owner differences, a_x+b_(x+y) must be constant in x for each of the two owners. Subtracting these conditions shows b_j+b_(j+1)=delta independent of j; hence b_j=B+delta*(j mod 2), a_x=A+delta*(x mod 2). Conversely all these annihilate. Exactly three independent parameters, so the pair's difference span is D of dimension 2n-3. Actual baseline replacement differences from any choice per owner generate that same span, not merely formal combinations with no witness.

For any p compatible pins leaving a baseline one-row-per-owner assignment, at most p pairs touched. For any linear map P with k=rank(P|D)<=h-p, greedily choose one available baseline replacement difference from each of k distinct untouched pairs so images are independent. Any subset of replacements is simultaneously legal because it uses distinct pairs, hence distinct owners. Express P(target-b) in that basis and apply selected replacements; it gives a real saturated tuple obeying pins and projected target. Thus EVERY such low-rank projection has a witness, including under all coordinate probes with p+k<=h. For p<=h-1 at least one untouched pair remains, so full exact tag affine hull under pins remains b+D; no additional affine tag contradiction. If pins are arbitrary global constraints or new semantic consequences outside stated model, no guarantee. No bound on combined inference via different projected tuples or nonaffine feedback. Rank bound linear in n, superlog in N for this explicitly polynomial-sized family. Saturated constraints can be applied before projection without defeating this obstruction.

## 5. Positive terminal: lift parity to exact integer incidence and discover modular contradiction
Before any probing, full target forces owner saturation and exact X/Z multiplicities by the count argument in A. Preserve this consequence even when temporarily relaxing the syndrome. Form the 0/1 three-part incidence matrix A of triples, with one row per X,Y,Z element, and enforce A u=1 on selected binary rows. This is stronger than treating tag constraints as congruences mod 2 while retaining only owner budgets. Apply exact integer lattice feasibility (HNF/SNF) to A u=1 over unrestricted integer u. If infeasible, reject with integer-lattice certificate; if feasible, return UNKNOWN unless another exact solver applies. For cyclic family a modular annihilator w has coefficients x on X, y on Y, -z on Z, mod n. Every triple column gives 0 mod n, but w^T 1=h nonzero. Thus integer lattice detects all UNSAT instances, including n divisible by four, with no branch. Certificate can be checked in O(|T| poly(log n)) bit operations using sparse triples. No need for a guessed Latin-square template: generic exact integer column-lattice membership detects failure once the incidence lift has been proved, with polynomial bit complexity. For SAT neighbor explicit binary witness verifies membership; lattice alone not decision complete for general 3DM. HNF backend not executed; explicit congruence and SAT witnesses executed. MS07 should preserve exact-incidence lift rather than only joint cost/XOR lattice. This is the qualitative (capacity+oddness) to integer algebra feedback escaping the low-rank obstruction.
