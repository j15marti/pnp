## 1. Another certified owner partition is NP-complete (PROVED)
Input: a finite 0/1 matrix A with r candidate row supports over c selection columns, a supplied Boolean primal witness u* with A u*=1, and a supplied Boolean owner vector w0 with A^T w0=1. Every row is nonempty, every column has at most four incident rows. The rows are authenticated exact-one equations, not semantic guesses. Decide whether there exists w != w0 in {0,1}^r with A^T w=1, equivalently a genuinely different disjoint cover of the selection columns by supplied rows. Also consider a designated row forced to 1. Verification of both supplied witnesses and a new cover is polynomial. The following reduction from proper 3-CNF proves both variants NP-hard even on this promise. It addresses explicit candidate-row discovery, not the discovery of all semantic exact-one equations. In particular no hardness claim about the original feasible relation Au=1 follows.

Define abstract cover variables (these are ROW indicators, NOT primal selection variables). Every block of rows creates one primary column whose incident rows are exactly that block, imposing exactly one choice. Make a switch block {off,on}; variable blocks {F_i,T_i}; clause blocks {bypass_j,literal_j1,literal_j2,literal_j3}. To forbid simultaneously selecting rows a,b from distinct blocks, add a new slack block {s, sbar} and a column incident to a,b,s. The column equations are a+b+s=1 and s+sbar=1. Exactly forbid a=b=1; otherwise unique Boolean slack lift. All rows have one primary column. Forbid (off,T_i) for every source variable. For each clause forbid (on,bypass), (off,literal_jk) for each k, and (literal_jk, row falsifying its literal) for each k.

When off=1, all variable rows select F, all clauses select bypass, and slacks are uniquely determined. This gives the supplied cover w0, independently of F. When on=1, each clause chooses a true literal, and the variable rows encode a satisfying assignment. Conversely every satisfying assignment plus any one true literal choice per clause lifts through uniquely determined slack blocks. Thus F SAT iff a second owner partition exists iff a partition with on=1 exists. The supports are distinct: different blocks have different primary columns; rows within a block have distinct incidences with conflict columns (including slack vs slack complement). Hence this is not mere relabeling. Every candidate cover selects exactly one row per primary block, so its cardinality equals that of w0.

For the primal witness u*, choose EVERY primary column and no conflict column. Each row contains precisely one primary column, so Au*=1; indeed this witnesses all exact-one constraints together. All source primal instances are SAT, including those where discovering a different owner cover is UNSAT. This distinction is essential: optimization/discovery can be hard even on an easily solvable source. The reduction does not say a SAT solver must search for another cover. For n variables and m clauses, r=2+4n+18m, c=1+3n+15m, nnz=2+7n+39m; every column has size 2,3,or4, all coefficients unit. Sparse bit encoding O((n+m) log(n+m+2)), construction and witness verification polynomial. Membership in NP plus reduction prove NP-completeness under the stated promise. The plain designated-row problem is NP-complete too even when supplied cover does not contain that row. No strict signed E4/B4/distributed-wheel transfer is asserted.

## 2. Both linear and signed integer discovery relaxations accept every guarded instance (PROVED)
Force on=1. LP witness: off=0, every variable pair (1/2,1/2), bypass=0 and each of three literal rows 1/3. Each conflict a+b<=1 holds: on+bypass=1, off+T=1/2, off+literal=1/3, literal+falsifier=5/6. Slack s=1-a-b, sbar=a+b. All coordinates in [0,1]; exact rational denominators divide 6. This works for all F, including UNSAT. For unbounded signed integer feasibility, set every variable false and choose the first literal per clause regardless of truth. For each conflict set s=1-a-b, sbar=a+b, allowing -1 and 2. This gives A^T w=1 exactly with on=1; reducing modulo 2 also witnesses binary affine relaxation, but not Boolean exact cardinalities. Hence LP plus integer lattice membership plus affine feasibility do not decide the guarded discovery problem. These statements do not exclude joint cutting planes or exact global forced facts.

Infinite neighboring family: start with all eight proper clauses on three variables (one forbidding each assignment), minimally UNSAT. Replace a clause (a or b or c) by (a or b or z),(not z or c or d),(not z or c or not d), fresh z,d. Existentially equivalent: if a,b false first forces z=1, then remaining two require c; if a or b true set z=0. Minimal UNSAT preserved: deleting another clause gives a model of the old deletion and lift; deleting one new clause, take a witness of the old deletion (a,b,c false), set z=0 if the first removed, else z=1 and choose d to satisfy the remaining clause. Inductively n=3+2h,m=8+2h. Every clause deletion gives SAT with an actual cover lift under on=1; intact guarded discovery UNSAT. Original planted cover/primal witness still exist in both labels. This is a discovery-neighbor family, not a family of UNSAT primal systems.

## 3. Exact fixed-parameter cover discovery by exceptional columns (PROVED)
For arbitrary authenticated candidate rows and arbitrary supplied row pins, let h count selection columns incident to at least three rows. Columns of size zero reject; singleton columns force their sole row selected. Each size-two column imposes w_a XOR w_b=1, so construct its complement graph. BFS assigns an orientation offset to each row in a connected component; reject inconsistent cycles or contradictory pins. After closure, each unfixed component has exactly two orientations. This statement covers isolated rows too. For every component and each allowed orientation, compute its NONNEGATIVE integer contributions to each of h exceptional columns from actual selected rows. If any contribution exceeds one, discard the orientation. Otherwise represent it by an h-bit subset. Process components in a fixed order, maintaining reachable occupied subsets. A transition is allowed iff its subset is disjoint from current occupied subset; take their union. Include forced components as single allowed orientations. End at full h-bit set iff exact cover exists. Induction on components establishes exactness; retain predecessor choices and recover actual row vector, verifying A^T w=1 and pins. For alternative cover rather than designated row, add a Boolean flag that records whether any chosen component orientation differs from w0, and require that flag at the end (or repeat row-pin tests). No assumption that pairwise consistency alone solves high-degree columns.

Acquisition: scan nnz incidence and build pair graph, compute offsets, row pins and contributions in polynomial work; precompute using per-row high-column incidences. Let k<=r components. At most 2^(h+1) states with alternative flag, at most twice as many transition attempts per layer; masks take O(h+1) bits. Uniform deterministic T<=2^h poly(N), S<=2^h poly(N) with all predecessor layers, smaller decision space streaming two layers. Witness reconstruction O(k) predecessor steps plus O(nnz) verification, modulo representation bit costs. Same-execution CM<=(T+1)S; state DAG <=(k+1)*2^(h+1) vertices and at most 2 transitions per state. Source rows retained and authenticated; if repartition is used, retain ALL original count equations, and charge subsequent RT09 quotient acquisition/evaluation separately. No free source-certificate enumeration. Failed trials and incompatible guards included. h=0 polynomial, and h<=c log N for fixed c polynomial. This is an FPT algorithm in h, not a universal bound on h. Exact mathematical closure for singleton/pair constraints before branching; rest is exact DP, so no need for uncharged branching. Full semantic closure of arbitrary candidate sets would itself require deciding guarded cover feasibility; do not assume it.

## 4. Independent M10/MS10 composition check (PROVED)
M10 (c6e336c063a9fcde6bc74f7faaa73a9c059e1770) correctly characterizes parity-class support by two cardinality inequalities. Here is a particularly small exact construction showing why individual thin-complement terminals do not automatically compose. For each proper 3-CNF clause use four distinct protected parity classes, each width 2 (two unit parallel arcs with equal tags within each class), net H=2, W=8. Let p be class parity. Exact class feasibility: sum p_i=0 mod2 and wt(p)<=2; the upper-bound condition wt(p XOR 0)<=6 is redundant. Thus exactly seven of the eight even words are attainable; missing only 1111. Set p1,p2,p3 to literal FALSITY bits by affine synchronization with global source variables, and p4=p1 XOR p2 XOR p3. Then exactly the all-false clause is excluded. For p=0000 fill a single class with 2, otherwise fill its two odd classes with 1. With distinct private tag coordinates and the full source-coupling equations retained, the independent bundles and affine synchronization encode 3SAT exactly. Local deficit d=max(0,4-2,4-6)=2, each local rejection list has size one. The reduction is linear in source occurrence count (plus explicit encoded labels). The local solver M10 remains sound; the unrestricted global composition of these constant-deficit bundles is NP-complete, not a contradiction of M10 or a claim that the original paper asserts otherwise. This is a separate explicit bounded-flow/affine-tag realization, not strict wheel geometry.

The seven-point relation affinely spans the 3-dimensional source-literal space. Every rank<=2 linear projection is surjective because its ambient fibers have at least two words and only one is excluded. This also explains why GD10 one-parity hull computation, even when exact on this local domain, cannot resolve global nonlinear conjunction. Conditional source pin leaving two clause bits free preserves full local affine hull (four or three words); joint inference may be stronger.

Use the minimally UNSAT clause family from section 2 with these bundles (now actual feasibility UNSAT, all clause-deletion neighbors SAT). MS10 (cd7aba670a5df39dd7e965e265f392f75525761a) has sound uniform-fiber repair condition U<1 with all outside maps protected. For this minimally UNSAT family, no nonempty subset of clause rejection events can satisfy that certificate at the unstrengthened affine source guard: deleting any nonempty subset leaves a satisfiable conjunction. Its witness supplies a protected word with all outside constraints satisfied. Uniform repair would produce a satisfying assignment to the full formula, contradiction. The whole-group case is identical, with no outside events. This is independent of which tree is chosen, and does not require estimating Hunter bounds. This does not exclude a new representation, contradiction via exact coverage, scope fusion, or learned constraints that change the guard. Our seed and splitting family in particular has short structural contradictions. MS10's theorem is sound; its universal applicability fails at this representation. I10 (be940682d029822c5b81616e1d12b7568b106097) wisely charges unmatched owner injection and uses one-sided randomized residual matching; its fixed-partition matching-based injection is not equivalent to arbitrary exact-one cover discovery. Do not import RT10 hardness into that injection subroutine or into deterministic matching-span computation.
