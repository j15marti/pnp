## 2. Infinite neighboring family (PROVED)
For every integer h>=1 take 4h independent parity cycles, each with two paths of equal length w and prescribed odd boundary at the path endpoints. 2h cycles have w=M=4h+2, the other 2h have w=M+1. All edges unit cost. One path belongs to owner A, the other to owner B. Every local join is exactly one path, by internal degree-two parity and endpoint parity. Thus a row bit x_i selects cost (w_i,0) or (0,w_i). Let S=sum w_i=4hM+2h, T=2hM+2h+1. Budgets K_A=T, K_B=S-T require sum w_i x_i=T exactly.

Let a,b be selected counts in the two groups, 0<=a,b<=2h. Equation M(a+b)+b=T implies b congruent to 2h+1 modulo M. Since 0<=b<=2h<M, impossible. Increase K_B by one, leaving every edge/target/cost and K_A unchanged. Now the weighted sum lies in [T-1,T]. Only T-1 feasible: b=2h, a=0. This SAT neighbor has exactly one coefficient witness. Both claims are symbolic, not numerical extrapolations. Physical coefficient size 2S=32h^2+20h unit edges and vertices, simple disjoint cycles, nullity one per block. Compact exact row encoding O(h log h) bits, explicit coefficient encoding O(h^2 log h) bits with indexed edges. No free source reconstruction assumed.

## 4. New exact terminal: signed cost-difference multiplicity (PROVED)
For every explicitly encoded independent binary-row product, each block i has rows a=0,1 with integer nonnegative owner cost vectors c_i(a) and q-bit XOR tags g_i(a). All couplings must be represented by budgets and target tags (or retained as guard conditions). Define d_i=c_i(1)-c_i(0) in Z^H, e_i=g_i(1) XOR g_i(0). Pinning a row removes the block and adjusts the baseline. Group free blocks by identical pairs (d_i,e_i), retaining exact IDs, baselines and physical witness links. Let G be number of groups, m_j their multiplicities. Signed differences allowed; exact grouping via sort/hash with equality checks, polynomial bit costs.

A count k_j in [0,m_j] chooses any k_j distinct blocks in group j. Cost is c0+sum k_j d_j; tag is g0 XOR sum_GF2 (k_j mod2)e_j. Thus feasibility iff a bounded integer count vector satisfies all owner budgets and exact tag. Each count vector lifts to actual rows; conversely every assignment maps to such a vector. This is exact, not a lattice relaxation, and does not require equal original row baselines. No permutation of hidden external constraints allowed. For fixed G enumerate product P=prod(m_j+1) <=(B+1)^G, polynomial work per vector, polynomial streamed space. The code executes this route, not an ILP solver. With G fixed, Lenstra's fixed-variable integer programming theorem also applies after enumerating 2^G parity patterns and substituting k=2u+epsilon, checking parity and bounds. Polynomial for fixed G; no universal small-G assertion. One may group by cost differences only and refine by at most 2^q tag patterns. A one-bit new observation doubles G at most.

## 5. Exact witnessed affine feedback (PROVED)

For each interior count 0<k_j<m_j, swap one selected bit and one unselected bit in that group. Every swap is an actual feasible assignment with same cost and tag. The complete bipartite graph between selected and unselected IDs is connected; a spanning tree of m_j-1 swap edges generates the entire even-parity difference subspace on those coordinates over GF(2). Indeed any difference of two assignments with same count has even parity; edge incidence vectors of a connected tree span all such vectors. Extreme count groups contribute no variation. Thus the canonical assignment plus at most B swap witnesses spans the exact affine hull of the count fiber.
