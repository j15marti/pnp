## 1. Strict signed equality/balance model
Graph is finite simple undirected, every vertex has exactly four ports incident to four distinct edges. Port bits are local. Signed edge (p,q,s) requires x_p XOR x_q=s. E4 vertices require all four bits equal; B4 vertices require exactly two of four bits equal one. No degree-2, degree-3, dangling, unary or external constant vertices. This theorem assumes precisely these allowed signatures and signed transports; it is not an assertion about an unspecified stronger geometric/tetrahedral correspondence-coloring subclass.

For every 3CNF F with n occurring variables and m clauses (including repeated literals when needed), construct such a graph G in O(m) vertices/edges (O(m log(m+1)) indexed bits, up to input symbol recoding). Its witnesses project to precisely the models of F, by interpreting a logical bit as its physical carrier XOR a shared anchor f. Both anchor orientations are allowed; they are related by global complement, which preserves E4, B4 and signed transport. Free unused source bits are omitted and can be restored arbitrarily.

Proof:
1. Clause (a OR b OR c), where a,b,c denote interpreted literals, is NAE4(A,B,C,f) in physical bits A=x_a XOR literal sign etc. It excludes exactly A=B=C=f (a=b=c=0).
2. For each clause introduce independent carrier z; realize NAE4 as NAE3(A,B,z) AND NAE3(not z,C,f). If A=B, first forces z=not A; otherwise no restriction. If C=f, second forces z=C; otherwise no restriction. Conflict occurs exactly A=B=C=f. This proves both directions with an explicit z choice.
3. NAE3(u,v,w) iff there exists slack r such that B4(u,v,w,r): r=2-(u+v+w) is a bit iff triple is nonconstant. Slack is unique given a legal triple. Introduce one slack per triple.
4. Duplicate each B4 node, sharing the SAME carrier and slack bits in both copies. This does not alter projected feasibility and makes every carrier occurrence count even. For an even number d>=4 of occurrences, use a path of (d-2)/2 E4 vertices; after internal path links there are 2*((d-2)/2)+2=d free ports. Attach each occurrence exactly once, with edge sign equal to literal sign; all occurrences have the required common carrier value. For d=2 use a single transport edge with sign equal to the XOR of the two occurrence signs. No degree-two equality node needed.
5. To ensure strict simplicity even with repeated clauses, replace EVERY transport wire by its own five E4 vertices inducing K5 minus one edge. The two degree-three vertices each attach to an original endpoint, other vertices degree four. All internal edge signs zero; put original wire sign on one attachment and zero on other. All five E4 carrier values agree, so this two-port gadget realizes exactly the required signed transport; every introduced vertex is degree four. Original endpoints can even belong to the same vertex without introducing a loop or parallel edge in the final graph. All graph ports paired and all signatures E4/B4. O(1) overhead per original wire. No planarity, wheel rim geometry, or fixed hub wiring asserted.

Every graph solution decodes carriers, yields NAE clauses and source satisfaction. Conversely a satisfying source assignment gives either anchor orientation, legal z/slack choices, and every duplicate and E4 bit. Witness lift/verification is linear in graph size with word indices. Thus unrestricted signed simple 4-regular E4/B4 feasibility is NP-complete (in NP, reduction from 3SAT). This is a constructive decision-equivalence theorem, not a time lower bound. It may duplicate earlier universal signature constructions; novelty here is explicit simple-graph audit and guarded pointwise transfer, not a claim of first NP-completeness result.

GD-01 transfer: for each source clause l1 OR l2 OR l3, construct conditional implications s->a_j, a_j->b_j, b_j->t enabled respectively when l1,l2,l3 false, with endpoint units s=1,t=0. Encode each guarded implication as a ternary clause (l_i OR not u OR v), endpoint units as repeated literal ternaries, then apply this compiler. For EVERY fixed source hub valuation (relative to f), extending the graph is possible iff the original guarded 2CNF is satisfiable iff that source valuation satisfies F. Therefore GD-01 coNP-complete coverage reduction has a strict E4/B4 realization even with simple 4-regular graphs. Its abstract implication graph has shallow paths; the physical graph itself does NOT have to have small width or shallow paths. Converting to duplicated distributed odd wheels with two-bit hubs under any additional geometric restrictions remains OPEN. A paired two-bit carrier is an abstract four-state hub only; do not infer proper-coloring gadget realization from this.

## 2. Exact affine-only closure stagnation theorem
For any 3CNF F with three DISTINCT variables in each clause, fix anchor f to either orientation; this is safe global complement symmetry breaking, not a free input oracle. Apply the graph compiler above. Define closure precisely: initialize signed edge equations and E4 equalities, then repeatedly replace each B4 relation, restricted to its current projected affine domain, by its exact binary affine hull and add all resulting equations globally by Gaussian elimination. This includes arbitrary linear combinations of those local affine consequences and repeated re-projection. It does not include global exact mixed-support membership, full nonlinear conjunctions, integer matching, or arbitrary conditional probes.

Each B4 has support of six weight-two vectors in F2^4; its affine hull is the even-parity hyperplane (dimension 3). Fixing one coordinate f gives three support points, spanning the full 2-dimensional affine slice of that hyperplane. In the full initial affine relaxation, each first B4 contributes w1=A+B+z over F2; each second B4 contributes w2=(1+z)+C+f. These are independent slack pivots, duplicated equations only. All n source carriers and m independent z bits remain free; all equality wires/gadgets merely copy signed values. Thus the relaxed affine space has exactly n+m free dimensions for fixed f.

For the first B4, A,B,z are independent (distinct variables, fresh z), so the projection is the entire even-parity hyperplane. For the second, z,C independently range while f fixed, so projection is the entire fixed-anchor parity slice. Exact local affine hulls on these projections yield no additional equation; duplicate B4 nodes have the same projected hull, and E4/transport equations already hold. The current relaxation is a fixed point even though the actual network may be UNSAT. In particular every source valuation survives this entire closure, including every false one. If f is not fixed, the same argument uses the whole even-parity slice for each B4; symmetry fixing does not repair the failure. This is a restricted completeness counterexample, not a claim that mandatory *all-channel* closure is impotent.

The single OR clause also has non-affine and non-bijunctive exact relative boundary relation: 7 of 8 assignments, so affine hull full; 100,010,001 are satisfying but their coordinatewise majority 000 is not. Any existential projection of 2CNF preserves majority (take majority of three extensions clause by clause). Hence this strict network cannot be replaced on those three protected logical observations by only affine equations or exact 2CNF over those observations plus arbitrary existential auxiliaries. Combining affine and 2CNF can of course be more expressive (MS01); this is not a barrier to mixed channels.

## 3. Infinite deletion-neighbor family with no affine progress
Start with minimally UNSAT chain U_k: x1, (not x_i OR x_(i+1)) for i=1..k-1, not x_k, k>=2. Replace each unit l by four clauses l OR (+/-a) OR (+/-b) with private a,b, all four sign pairs; replace each binary C by C OR p and C OR not p with fresh p. This gives distinct-variable 3CNF F_k with n=2k+3 variables and m=2k+6 clauses. Conjunction of each bundle is exactly its old unit/binary. Thus F_k is UNSAT. Every single clause deletion is SAT: choose a chain assignment violating only the original clause associated with that bundle (all zero for first unit, all one for last unit, prefix ones then zeros for a broken implication). Assign that bundle's private bits so only the deleted padded clause is false; other bundles hold independently. Therefore all m deletion neighbors are SAT. Compile each into strict graph as above. This proves an infinite decision-sensitive family; deletion changes one source clause/bundle gadget rather than exactly one physical graph edge. For the UNSAT member the fixed-anchor local affine relaxation has dimension n+m=4k+9. For every deletion neighbor, the corresponding relaxation remains surjective on source carriers. No claim that these examples resist SCC reasoning after recognition of padding, joint matching, integer/spectral reasoning, or arbitrary exact backbone queries. Indeed the chain is deliberately easy with a legitimate shortcut. This is a useful mandatory negative control against treating affine dimension decrease as universal progress.
