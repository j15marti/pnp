\section{IDEAS PROPOSED BEFORE LITERATURE}
\paragraph{CANDIDATE A: typed codebook.} A canonical source contains explicit circuits $g:\{0,1\}^n\to\{0,1\}^r$ and $h:\{0,1\}^r\to\{0,1\}^n$ with $r=O(\log N)$. An ordinary machine performs adaptive address transitions $a_{t+1}=h(g(a_t))$. Hypothesis: a source-recomputed $2^r$-state quotient yields a polynomial, globally unique-output endpoint certificate. Missing assumption: syntax must enforce factorization, not merely promise it. Falsifiers: noninjective $h$, horizon 0/1, forged powers, changed source, large binary horizons.
\paragraph{CANDIDATE B: untyped succinct pointer boundary.} A general source Boolean circuit $C$ provides a single read-only virtual row $M[a]=C(a)$ per step. Hypothesis: its exact binary-horizon endpoint bit is PSPACE-complete despite polynomial row evaluation. Missing: a uniform, clock-correct deterministic configuration reduction. Falsifier: invalid states, nonhalting repetition, or a missing absorbing output.
\paragraph{CANDIDATE C: explicit lasso.} A polynomial-length list of orbit addresses might certify endpoints. Missing: a short explicit orbit. Falsifier: $n$-bit modular counters with cycle length $2^n$ despite cheap fast-forward.
\paragraph{CANDIDATE D: completion-time hash.} Source freshness might force a substantial after-disclosure computation. Missing: ruling out public prefix search. Falsifier: a $k=O(\log N)$-bit postdisclosure prefix search using polynomial expected work.

\section{LITERATURE CHECK AND REVISIONS}
Hirahara, ECCC TR20-050 (2020), Theorem 3.9 and Section 9, proves P-immunity for superpolynomial time-bounded $K^t$, using exhaustive $O(\log n)$-suffix search; it does not prove P-immunity for Levin's $Kt$. Baker, Gill, Solovay, SIAM J. Comput. 4(4) (1975), define oracle query machines and establish $P^A=NP^A$ for PSPACE-complete $A$. Standard succinct graph reachability is PSPACE-complete, but its nondeterministic graph-access model is not substituted for our deterministic endpoint language; the direct reduction below checks the model. Synchronous Boolean dynamical-system PSPACE results use different update conventions.

A survives only for syntactically authenticated factorization. B survives by direct deterministic configuration iteration. C fails as a universal explicit-list claim but does not prove a machine lower bound. D fails without independent cryptographic or complexity premises. Searches did not establish a novel generic invariant normal form.

\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Source and costs.} A complete canonical source $S=(n,r,g,h,a_0,T,i)$ encodes acyclic Boolean circuits, start address, binary horizon and bit query, with $r\le\lfloor\log_2 |S|\rfloor$. Malformed sources reject. An ordinary deterministic implementation uses its original source circuits to evaluate the single virtual read-only row $h(g(a))$ each step, with no preloaded $2^n$-row ROM or oracle. Source parsing, all circuit gates, discovery, $r$-bit indices, binary clock and output are charged. Let $N=|S|$, $k=2^r\le N$.

\begin{theorem}[Adaptive codebook endpoint]
Define $G=g\circ h:\{0,1\}^r\to\{0,1\}^r$ and $v_0=g(a_0)$. Then
\[
a_T=\begin{cases}a_0,&T=0,\\ h(G^{T-1}(v_0)),&T\ge1.\end{cases}
\]
One deterministic procedure constructs the $k$ source-recomputed values $G(v)$ and all doubling tables $D_j=G^{2^j}$ necessary for the binary horizon. A polynomial-time verifier checks each original-source row, all identities $D_{j+1}(v)=D_j(D_j(v))$, and the selected terminal bit. The certificate has $O(k r(1+\log(T+1))+N+n)$ bits and can be constructed and verified in polynomial time and peak space in $N$. For fixed authenticated $S$, \emph{every} accepted certificate yields exactly one same $n$-bit endpoint and bit.
\end{theorem}
\begin{proof}
$a_1=h(v_0)$. If $a_t=h(G^{t-1}(v_0))$, then $a_{t+1}=h(g(h(G^{t-1}(v_0))))=h(G^t(v_0))$. The base table is unique because the checker recomputes $g(h(v))$ for all $v$; induction on $j$ forces every doubling row; binary powering forces the terminal address. This establishes initiality, consecution, terminal coverage and global uniqueness over all accepted proofs, not merely per proof. Membership in the time-indexed invariant $I(t,a):=[a=a_0]$ for $t=0$, or $[a=h(G^{t-1}(g(a_0)))]$ otherwise, is polynomially evaluable for an explicit $n$-bit $a$ and binary $t\le T$. Its singleton shape syntactically certifies cardinality one. No existential union of descriptors is performed. All $k$ quotient states are explicitly tested, but none of the $2^n$ virtual memory rows is materialized.
\end{proof}
\paragraph{Important qualification.} This is a source-typed subclass of ordinary computations and a polynomial upper bound. It has genuinely state-dependent addresses, but its finite image is part of the source grammar; it is not a proof that arbitrary machines admit such an image or invariant. Expanding all $2^n$ virtual rows is different from efficient line-query access.

\begin{theorem}[Untyped pointer iteration is PSPACE-complete]
Let $\mathsf{PTRBIT}$ ask for one bit of $C^T(s)$ for a source circuit $C:\{0,1\}^m\to\{0,1\}^m$, start $s$, binary $T$ and selected index. It is PSPACE-complete under polynomial-time many-one reductions, with one source-computed, read-only, adaptive lookup per step.
\end{theorem}
\begin{proof}
Polynomial-space membership follows by retaining current pointer, a binary step counter and a circuit workspace while simulating $T$ steps. For hardness, fix any total deterministic polynomial-space decider $M$ and input $x$. Uniformly compile its locally computable next-configuration relation into a polynomial-size Boolean circuit $C_x$ on $m=\mathrm{poly}(|x|)$ configuration bits, making accepting and rejecting halts absorbing and setting illegal encodings to a specified safe transition. A halting deterministic computation cannot repeat a nonterminal configuration, so it reaches a terminal state within $2^m$ steps. Use its authentic initial configuration as $s$, $T=2^m$ (a binary integer of $m+1$ bits) and query the absorbing acceptance bit. The answer equals $M(x)$. The reduction uses no nondeterministic graph paths.
\end{proof}
\begin{proposition}[Conditional universal-certificate consequence]
A uniform polynomial-time sound verifier with polynomial-size complete endpoint witnesses for \emph{every} untyped $\mathsf{PTRBIT}$ source would imply $\mathrm{PSPACE}=\mathrm{NP}$.
\end{proposition}
\begin{proof} The certificate places the PSPACE-complete language in NP. This does not prove its nonexistence and does not assume $P=NP$ implies $P=\mathrm{PSPACE}$.\end{proof}
\paragraph{Lasso rejection.} $C(a)=a+1\bmod2^n$ has a $2^n$-long orbit from zero and hence an exponentially long explicit orbit list, but $C^T(0)=T\bmod2^n$ has polynomial-time modular evaluation. Explicit-list failure is not machine hardness.

\paragraph{Matched-oracle immunity and two-output barrier.}
Fix one polynomial-overhead universal oracle machine $U^O$ and use the same oracle $O$ in the universal machine, decider and verifier. For any $O$ and $t(n)=n^{\omega(1)}$, $R_{K^{t,O}}=\{x:K_U^{t,O}(x)\ge|x|-1\}$ is $P^O$-immune. Indeed if an infinite $P^O$ subset had decider $M^O$, save $n-m$ prefix bits from one member and enumerate $2^m$ suffixes using $M^O$, $m=(c+5)\lceil\log_2 n\rceil$ for fixed polynomial runtime exponent $c$. For infinitely many $n$ this produces a member in polynomial oracle time with an oracle program of length $n-m+2\log n+O(1)<n-1$, contradicting immunity. This explicitly relativizes Hirahara's suffix proof, without changing oracle or replacing $K^t$ by Levin $Kt$.

Take $O=\mathrm{TQBF}$, for which $P^O=NP^O$. Suppose a polynomial-time oracle verifier $V^O(n,p,x,\pi)$ has polynomial witnesses, covers every $t(n)$-bounded length-$n$ output of $U^O(p)$ for $|p|\le n-2$, and admits at most two distinct $x$ for fixed $(n,p)$ globally across all accepted $\pi$. The accepted union $E_n^O$ is in $NP^O=P^O$ and has at most $2(2^{n-1}-1)=2^n-2$ members. Its infinite $P^O$ complement consists only of strings with $K^{t,O}\ge n-1$, contradicting matched-oracle immunity. Therefore that universal two-output schema cannot work relative to this collapsing oracle. This proves a necessary nonrelativization diagnostic, not ordinary PFCERT existence. Nonalgebrization remains OPEN.
