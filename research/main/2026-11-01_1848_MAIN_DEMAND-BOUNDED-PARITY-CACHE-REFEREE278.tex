\section{Exact address function}
In LSPV-4's authenticated family $F_{r,z}$, $z_i$ records which member of
swappable binary/ternary pair $i$ lies before the fixed pivot. The alternative
block address is
\[
 A(r,z)=1072r+4(r-|z|).
\]
Since $1072$ is divisible by eight, bit 2 is
\[
 a_r(z)= (r-|z|)\bmod2=(r\bmod2)\oplus
 \bigoplus_{i=1}^r z_i.                                      \tag{1}
\]

\begin{theorem}[Raw deterministic and randomized cost]
The exact deterministic bit-query complexity of $a_r$ is $r$. For
$0\le\varepsilon<1/2$, the minimum worst-input expected number of raw width
queries of an adaptive randomized algorithm with error at most $\varepsilon$
is exactly
\[
 R^{\rm exp}_\varepsilon(a_r)=(1-2\varepsilon)r.              \tag{2}
\]
\end{theorem}
\begin{proof}
Each input bit is pivotal in (1), proving deterministic cost $r$. For the
randomized bound, couple a run on $0^r$ with the input having only bit $i$
flipped. If $E$ is correct output on $0^r$ and $Q$ the queried coordinates,
then $\Pr(E)\ge1-\varepsilon$ and
$\Pr(E\land i\notin Q)\le\varepsilon$. Summing gives
$\mathbb E|Q|\ge(1-2\varepsilon)r$. Equality is attained by querying all
bits and deciding with probability $1-2\varepsilon$, and otherwise querying
nothing and guessing fairly.
\end{proof}

\section{Paid demand-bounded semantic cache}
\begin{theorem}[Fixed demand]
After source authentication, one charged scan of the $r$ width tags computes
and retains one parity bit. Every subsequent request for the same fixed-pivot
address bit is answered with no further source probes and constant
cache/address/output work. For $q$ repetitions, width-probe work is $r$, not
$qr$; total operation proxy is $r+O(q)$.
\end{theorem}
This is not a free semantic representative: acquisition, authentication,
the cache write, its address, lookup, output, validation, and guest work are
all charged.

More generally, for $k$ predeclared pivots, one sequential source scan stores
their $k$ prefix parities. If the positions are not implicit, their addresses
must also be retained or recomputed. For all $r$ pivots, write
$p_j=\bigoplus_{i\le j}z_i$. The vector $(p_1,\ldots,p_r)$ is injective because
\[
 z_1=p_1,\qquad z_j=p_j\oplus p_{j-1}.                        \tag{3}
\]
Thus the all-pivot continuation table has $2^r$ possible values and needs
$r$ lossless bits, but it is constructed in $O(r)$ work and supports constant
random-access lookup. Exponential continuation cardinality is not
exponential computation.
