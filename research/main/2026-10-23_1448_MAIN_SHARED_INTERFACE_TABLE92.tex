\section{Target, proposals, and claim card}

This run tested the first shared-interface rung after independent
AGGREGATION-CEILING91.  Before source review, three falsifiable mechanisms
were fixed:
\begin{enumerate}
\item explicit compatibility tables might force $J2^h$ work for $J$ blocks
sharing an $h$-bit interface;
\item exact symbolic projection might compress those tables below $2^h$;
\item repeated interface use might force a persistent table even when the
root SAT answer is one bit.
\end{enumerate}
The first is proved exactly but remains input-order.  The second is false on
easy recognizable controls and open for a deliberately chosen succinct hard
family.  The third is not an obligation of a one-shot SAT decider and is
therefore retired unless an all-algorithm context-extraction theorem is
supplied.

\section{Exact shared-interface function}

Let $K=2^h$, and let
\[
R=(r_{j,a})\in\{0,1\}^{J\times K}.
\]
Think of row $j$ as the feasible assignments to the common interface
$S\in\{0,1\}^h$ for block $j$.  Define
\[
f_{J,h}(R)=\bigvee_{a=0}^{K-1}\bigwedge_{j=1}^{J}r_{j,a}.
\]
Thus $f_{J,h}=1$ precisely when all blocks have a common feasible interface
assignment.  The source has $M=JK=J2^h$ orientation fields.

\begin{theorem}[Exact explicit-table depth]
The deterministic field-query complexity of $f_{J,h}$ is exactly
\[
D(f_{J,h})=M=J2^h.
\]
\end{theorem}
\begin{proof}
Reading every field is an upper bound.  For the lower bound, the unique
multilinear real polynomial is
\[
f_{J,h}(R)=1-\prod_{a=0}^{K-1}
\left(1-\prod_{j=1}^{J}r_{j,a}\right).
\]
Its full monomial $\prod_{a,j}r_{j,a}$ has nonzero coefficient, so the exact
degree is $M$.  A deterministic decision tree of depth $d$ has a multilinear
polynomial of degree at most $d$ (induct on its root query), hence $d\ge M$.
Equivalently, an adversary can answer one unseen position in each column
with zero only after all earlier positions in that column were answered one,
forcing a complete NO certificate.  Both labels occur at identical metadata
and length: the all-zero table is NO, while any table containing one all-one
column is YES.
\end{proof}

One aligned field per fixed-width record gives $M$ field queries, $M$ record
queries, and $M$ word probes.  If $w$ orientation bits are packed per machine
word, the consequence weakens to $\Omega(M/w)$ word probes.  With $c$ fixed
words per record and a fixed header, $N_{\rm src}=\Theta(Mw)$ encoded bits,
so the aligned bound is only $\Theta(N_{\rm src}/w)$ input acquisition.

\section{Fixed-metadata proper-3CNF representation}

Use selector variables $s_0,\ldots,s_{h-1}$.  For every cell introduce
$c_{j,a}$ and include a unit forcing $c_{j,a}=r_{j,a}$.  Also include
\[
\left(\bigvee_{t:a_t=0}s_t\right)\vee
\left(\bigvee_{t:a_t=1}\neg s_t\right)\vee c_{j,a}.
\tag{1}
\]
Only the sign of the forcing unit depends on $R$; all variable identifiers,
clause locations, widths, and record counts are fixed.

\begin{theorem}[Exact ordinary-CNF endpoint]
The resulting CNF $\Gamma(R)$ is satisfiable iff $f_{J,h}(R)=1$.  Converting
every unit, binary, and long clause by the standard fresh-variable chain
gives an equisatisfiable proper-3CNF with $M=J2^h$ and
\[
 n_3=h+M(3+a_h),\qquad m_3=M(4+c_h),
\]
where
\[
a_h=\begin{cases}1&h=1\\0&h=2\\h-2&h\ge3,
\end{cases}
\qquad
c_h=\begin{cases}2&h=1\\1&h=2\\h-1&h\ge3.
\end{cases}
\]
Thus construction, output, and retained representation are
$\Theta(Mh)$ words, and the proper-3CNF encoded length is
$N_3=\Theta(Mh\log(Mh+2))$ bits under fixed clause records.
\end{theorem}
\begin{proof}
When the selector equals $a$, every mismatch literal in (1) is false, so
all $J$ clauses for that column require $c_{j,a}=1$.  Clauses for other
columns already contain a true mismatch literal.  The forcing units identify
the cells with $R$, proving the semantic equivalence.  A unit becomes four
ternary clauses with two fresh variables, a binary becomes two with one
fresh variable, and a length-$\ell\ge4$ clause becomes $\ell-2$ ternaries
with $\ell-3$ fresh variables.  Summing these fixed contributions gives the
displayed counts.
\end{proof}

This is a direct inclusion family inside ordinary proper-3CNF.  In the
declared record layout, restriction of any exact target decision tree to the
orientation words still needs $M$ worst-case reads.  But
\[
M=\Theta\!\left(\frac{N_3}{h\log N_3}\right),
\]
so the result remains at or below input order.  It is not a lower bound on
SAT-solving circuits, proof systems, or unrestricted superlinear time.

\section{Charged transport counterexample}

Suppose instead that the table is the source and a source decider constructs
$\Gamma(R)$ before one target call.  In the required inequality
\[
L_{\rm old}(M)\le R(M)+H(M)+Q(M)\tau(M)T_{\rm new}^{\le}(g(M)),
\]
we have $L_{\rm old}=M$, $Q=1$, $g=\Theta(Mh\log(Mh))$, and already
$R=\Theta(Mh)$ from reading the cells and writing the fixed gadgets.  Hence
\[
L_{\rm old}-R-H\le0
\]
for the explicit construction.  The reduction therefore transports no
positive lower bound.  Direct inclusion avoids the paid construction, but
preserves only the same $M$-field acquisition order and does not amplify it.

This falsifies the proposed ``explicit compatibility table'' amplifier.
The source itself has paid for every interface context.  If $h=O(\log N)$,
enumerating all $2^h$ assignments is polynomial.  If $h=\omega(\log N)$ but
the full table is explicit, its $2^h$ entries are already counted in $N$.

Enumeration over $2^h$ contexts is an \textbf{upper bound}.  The $M$-field

\section{Model and resource ledger}

Source reads, record addressing, metadata checks, all failed columns,
selector enumeration, reduction output, auxiliary variables, verification,
replay, and peak live space are charged.  A streaming table decider uses
$O(M)$ word time and $O(1)$ working words beyond the read-only source;
row-major and column-major layouts differ only by address arithmetic in the
declared random-access model.  Building the proper-3CNF uses
$\Theta(Mh)$ writes and $O(h)$ streaming workspace, or $\Theta(Mh)$ peak
space if the complete output must remain live.  DAG reuse is absent; every
table cell has one fixed gadget.  Formula evaluation circuitry is not a
SAT-solving circuit lower bound.

The argument relativizes and is defeated by a semantic SAT oracle or a
decide-first normalizer; it supplies no nonrelativizing bridge.  Algebraic
oracle access is unnecessary because the explicit table already exposes the
whole function.  No Natural-Proofs conclusion is claimed.
