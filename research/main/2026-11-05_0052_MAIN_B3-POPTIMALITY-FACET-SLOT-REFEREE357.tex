\section{ITERATE I: exact conditional p-optimality theorem}

Let $R$ be a fixed polynomial-time Cook--Reckhow refutation verifier.  Write $L_R(F)$ for the minimum total encoded proof length, not paid-node cost.  Say that $R$ is length-p-bounded if $L_R(F)\le p(|F|)$ for every UNSAT $F$.

\begin{theorem}[P-world equivalence]\label{thm:pworld}
Assume $\mathrm{SAT}\in\mathrm P$.  For fixed $R$, the following are equivalent:
\begin{enumerate}
\item $R$ is length-p-bounded;
\item $R$ p-simulates every Cook--Reckhow UNSAT proof system;
\item one polynomial-time algorithm outputs an $R$-refutation for every UNSAT $F$.
\end{enumerate}
\end{theorem}
\begin{proof}
Suppose (1), and let $Q$ be any proof system.  On a $Q$-proof $\pi$, compute its conclusion $F$ in polynomial time.  There is an $R$-proof $\rho$ of length at most $p(|F|)$.  The prefix-completion relation
\[
\exists\rho\supseteq u\quad |\rho|\le p(|F|)\ \wedge\ V_R(F,\rho)=1
\]
is in NP.  Since $\mathrm{SAT}\in\mathrm P$ implies $\mathrm P=\mathrm{NP}$, decide this relation bit by bit to recover $\rho$ in polynomial time.  Because $|F|\le\operatorname{poly}(|\pi|)$, this is a p-simulation, proving (2).  The same prefix search without $Q$ proves (3).

For (2)$\Rightarrow$(1), use the assumed polynomial SAT decider $A$ to define a fixed proof system $Q_A$: a proof string containing $F$ maps to $F$ when $A$ declares $F$ UNSAT, and to one fixed contradiction otherwise.  Correctness of $A$ makes $Q_A$ sound and complete and gives $O(|F|)$ proofs.  A polynomial translator into $R$ gives (1).  Finally (3)$\Rightarrow$(1) because a polynomial-time machine cannot print more than polynomially many bits.
\end{proof}

This proof does not formalize an arbitrary decider's correctness inside $R$.  Correctness is used externally to define $Q_A$; the system-specific content is exactly the p-simulation into $R$.  Thus it exposes rather than removes the missing bridge.

\begin{proposition}[B3 needs byte domination]\label{prop:bytes}
Let $C_R(\pi)$ be the project's sum of paid inference-node weights.  If a uniform normalization maps every $R$ proof to an equivalent proof $\pi'$ with
\[
|\pi'|\le q(|F|+C_R(\pi'))
\]
for one polynomial $q$, then, under $\mathrm{SAT}\in\mathrm P$, B3 for $C_R$ is equivalent to the three conditions in Theorem~\ref{thm:pworld}.  Without this hypothesis, B3 alone does not justify the bounded witness relation used by prefix search.
\end{proposition}
\begin{proof}
Byte domination converts a polynomial node-cost witness into a polynomial encoded-length witness; Theorem~\ref{thm:pworld} applies.  Conversely any polynomial-length proof contains only polynomially many explicitly serialized paid nodes.  Without domination, one paid LOCAL/AND3/GF(2) record may carry a payload whose expanded encoding is not bounded by any polynomial in node count, so the NP witness length used in the proof is not established.

The necessity is witnessed by a fixed legal Cook--Reckhow weighted calculus $R_{\rm blob}$.  Its proof has one paid node \texttt{BLOB}$(F,\rho)$ whose payload $\rho$ is an ordinary Resolution refutation; the verifier parses and replays $\rho$ in time polynomial in the supplied bytes.  Thus every UNSAT formula has paid cost one, so node-cost B3 holds unconditionally.  Haken's PHP family nevertheless forces $|\rho|=2^{\Omega(h)}$.  In a hypothetical $\mathrm{SAT}\in\mathrm P$ world, the canonical decider system $Q_A$ has linear proofs of these same PHP formulas; a p-simulation of $Q_A$ by $R_{\rm blob}$ would produce polynomial Resolution refutations and contradict Haken.  Hence node-cost B3 does not imply conditional p-optimality without a byte-domination condition.  This is a counterexample to the generic weighted inference, not a claim that native $R_{\mathrm{mix341}}$ has a \texttt{BLOB} rule.
\end{proof}

For $R_{\mathrm{mix341}}$, Proposition~\ref{prop:bytes}'s normalization premise is precisely part of deliverable (1), and remains OPEN.  Therefore Theorem~\ref{thm:pworld} is a noncircular characterization, not a proof of B3.

\section{ITERATE II: smallest DEF-facet selector divergence}

REFEREE356 proved that a paid binary definition must retain two ordered input occurrences.  Complete the record as
\[
D(i,z,f,u,v),\qquad S(i,a,b),\quad a,b\in\{0,1\},
\]
where selector $S(i,a,b)$ denotes the positional clause
\[
(u\ne a)\lor(v\ne b)\lor(z=f(a,b)).
\]
Slots are retained even when aliasing makes one tautological; normalized clauses never renumber the four selectors.

Use the legal SAT source $(x)$ and one paid conservative record
\[
D(1,z,\mathrm{NOT\_A},x,x).
\]
Slot $S(1,1,1)$ is $(\neg x\lor\neg x\lor\neg z)$, normalized to $(\neg x\lor\neg z)$.  One paid RES with source $(x)$ yields $(\neg z)$.  An \emph{explicit-slot completion} accepts this two-node trace.  An equally source-sound \emph{aggregate-record completion}, in which DEF exports only a gate object and RES accepts only clause-typed nodes, rejects it.  No semantic contradiction occurs: the unique extension of source model $x=1$ has $z=0$.

This is a minimal completion-divergence witness for DEF-facet-to-RES consumption: one node must introduce fresh $z$, and a later node must consume the facet.  It is not a counterexample accepted by one already-unique native byte grammar; it proves that the inherited prose still fails to select such a grammar.  The exact repair is an explicit triple \texttt{(def-id,row-a,row-b)} plus a stated consumer type and a stable no-renumber rule.  Analogous typed selectors are still required for DEF-to-GF(2), AND3 outputs, and LOCAL exported wires before a full rule-by-rule compiler can be certified.

\section{Hard-family and physical-cost audit}

Haken's theorem concerns explicit unary PHP CNFs and ordinary shared-DAG Resolution, requiring $2^{\Omega(h)}$ lines for sufficiently large $h$; it is not a theorem about ER, GF(2), $R_{\mathrm{mix341}}$, or SAT machines.  Haken's own abstract notes polynomial Extended Resolution proofs as a countercontrol.  Raz--Tzameret obtain polynomial refutations of PHP and Tseitin in separately defined resolution-over-linear-equation/multilinear systems, while their lower bound is for a stated fragment.  No restricted hardness is transferred here.

Logical paid-node cost, encoded proof bytes, verifier time, construction/search time, random access, intermediate expansion, output work and peak space are distinct.  The exhaustive producer searched closures after free formula selection; its measured work is not $W_R$.  An instruction-only facet selector saves output bytes only if the checker reconstruction cost and addressing are charged.  A fully materialized proof costs at least its printed bytes; an implicit/lazy proof requires a declared access model.  No FLMV or arbitrary-machine time bound follows.
