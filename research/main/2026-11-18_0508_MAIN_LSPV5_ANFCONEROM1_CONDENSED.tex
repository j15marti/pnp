\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Authenticated encoding and quantifiers.} Input is canonical ASCII JSON of length $N$ specifying $m$ explicitly listed state bits, all initial bits $x_0$, a binary time horizon $T$, a complete explicit source-listed ANF for $m$ base polynomials $B_i$, coefficients $C_i$, $d$ address polynomials $A_j$, an acyclic finite AND/OR/XOR/NOT source-ROM gate circuit $G:\{0,1\}^d\to\{0,1\}$, and terminal ANF $Q$. Each source monomial is a sorted set of coordinate indices; duplicate monomials cancel modulo two. Malformed source is INVALID, not an unsatisfiable input. The complete grammar is implemented and checked in the companion Python. All declared $m,d$, total monomial and gate counts, and horizon bit length are $O(N)$. The actual transition on $x\in\{0,1\}^m$ is
\[
 F_i(x)=B_i(x)\oplus\bigl(C_i(x)\wedge G(A_0(x),\ldots,A_{d-1}(x))\bigr).
\]
$G$ represents $2^d$ immutable ROM cells in the sense of one binary bit per address; a read is charged by computing the $d$ source address polynomials and the source gate circuit. It is never a free preloaded $2^d$-bit mutable tape.
\paragraph{Closure.} Let $\supp(P)$ denote coordinates occurring in the canonical ANF of $P$. Starting with $S_0=\supp(Q)$, iterate
\[
 S_{h+1}=S_h\cup\bigcup_{i\in S_h}\bigl(\supp(B_i)\cup\supp(C_i)\bigr)
 \cup\bigcup_{\substack{i\in S_h\\C_i\ne0}}\bigcup_{j<d}\supp(A_j).
\tag{1}
\]
At most $m$ strict enlargements occur. For $C_i=0$ on all observed coordinates this is exactly the least semantically closed coordinate set. With ROM read terms it is a safe \emph{syntactic overapproximation}, not a semantic minimum.
\begin{lemma}[ANF supports]
A variable $x_j$ influences a canonical explicit ANF Boolean function $P$ on at least one input if and only if it occurs in a surviving monomial. Consequently semantic coordinate dependence of an explicitly listed ANF is decidable in polynomial source time.
\end{lemma}
\begin{proof}
The Boolean derivative $P(x\oplus e_j)\oplus P(x)$ is the squarefree sum of those monomials containing $j$, with $j$ deleted. Distinct multilinear monomial functions are linearly independent on the Boolean cube, by induction splitting $x_j=0$ and $x_j=1$. Therefore the derivative vanishes identically iff no such term remains.
\end{proof}
\begin{lemma}[All-fiber semiconjugacy]
For every source and every $S\supseteq\supp(Q)$ satisfying (1) as a closure condition, there are source-computable maps $f_S,q_S$ with
\[
 \pi_S F=f_S\pi_S,\qquad Q=q_S\pi_S
 \quad\text{for every physical state }x\in\{0,1\}^m.
\tag{2}
\]
\end{lemma}
\begin{proof}
For every tracked $i$, the base and coefficient ANFs are independent of off-$S$ bits. If its coefficient is nonzero, every address polynomial also depends only on $S$, so the same source ROM produces the same read value on any two states in a common $S$-fiber. The terminal ANF depends only on $S$ by initialization of the closure. Evaluating $F$ on the canonical zero off-$S$ extension therefore defines $f_S$ without guessing a missing transition.
\end{proof}
\begin{theorem}[Source-discovered adaptive-ROM endpoint certificate]
There is a single uniform conventional algorithm which authenticates every source, constructs (1), and either returns NOT\_CERTIFIED when $r=|S_*|>\lfloor\log_2N\rfloor$ or constructs and verifies an exact endpoint after arbitrary binary $T$ in polynomial source bit time and simultaneous peak space. For $r\le\lfloor\log_2N\rfloor$, $q=2^r\le N$ and $L=\max(1,\operatorname{bitlength}(T))=O(N)$. A proof stores a closed $S$, $L$ complete $q$-entry tables $D_0=f_S$, $D_{j+1}=D_j\circ D_j$, a terminal quotient state, and the claimed one-bit output. Proof length $O(N+qrL)$ bits; a conservative sequential ordinary bit-machine bound is $O((N+1)^7)$ time and $O((N+1)^3)$ peak bits for both source-derived construction and verification. For any fixed source, ALL accepted polynomial-size proofs, including proofs with different valid closed $S$, accept exactly ONE common bit $Q(F^T(x_0))$.
\end{theorem}
\begin{proof}
Enumerate the $q$ projected states, evaluating the genuine source gate circuit on each to derive $D_0$; check all $q$ entries. Verify each subsequent table by direct squaring, then apply the binary powers selected by $T$ to the actual initial projection. Induction on table index gives $D_j=f_S^{2^j}$; induction from (2) gives $\pi_SF^T=f_S^T\pi_S$. Source-verified output evaluation gives the unique physical terminal bit. Because the proof checker checks the source, closure and complete tables independently, the argument holds for EVERY accepted closed set and certificate, establishing global singleton output, not merely one accepted transcript. Parsing, cancellation, discovery, all source reads, ROM address/gate evaluation, table building and checking, retention, index arithmetic and output are charged; $q,L\le O(N)$ makes all of them polynomial. The symbolic invariant $I(x,y)\equiv(y=\pi_Sx)$ has initiality, all-state consecution and terminal coverage from (2). A failure of the logarithmic-width test does not mean UNSAT or hardness.
\end{proof}

\begin{theorem}[Untyped semantic relevance gate]
For an unrestricted Boolean circuit $C(u,z)$ and designated input bit $z$, deciding whether $C(u,0)=C(u,1)$ for all $u$ is coNP-complete.
\end{theorem}
\begin{proof}
The complement has an NP witness $u$. Given CNF $\varphi(u)$, construct $C_\varphi(u,z)=z\wedge\varphi(u)$. This circuit is independent of $z$ iff $\varphi$ is unsatisfiable. This establishes coNP-hardness and membership. It does not exclude other special syntactic compilers, nor prove a lower bound on arbitrary SAT deciders.
\end{proof}
\paragraph{Exact matched-oracle nonrelativization diagnostic.}
Fix the SAME oracle $O$ in a polynomial-overhead universal oracle machine $U^O$, the randomness definition $K_U^{t,O}$, a verifier $V^O$, and $P^O,NP^O$. For superpolynomial $t(n)=n^{\omega(1)}$, the set $R^{t,O}=\{x:K_U^{t,O}(x)\ge|x|-1\}$ is infinite and $P^O$-immune: if an infinite $P^O$ subset existed, hard-code a prefix of length $n-c\log n$ of one of its strings and enumerate polynomially many suffixes with the SAME $P^O$ decider; a universal $O$-oracle program of length $n-c\log n+2\log n+O(1)<n-1$ then prints one of those supposedly random strings within $t(n)$ steps, contradiction. Oracle calls are counted in the same machine convention.
Now let $A=\mathrm{TQBF}$, a legitimate PSPACE-complete collapsing oracle with $P^A=NP^A$ since $NP^{\mathrm{TQBF}}\subseteq\mathrm{NPSPACE}=\mathrm{PSPACE}\subseteq P^{\mathrm{TQBF}}$. Suppose an $A$-oracle PFCERT polynomial verifier, with polynomial proof-length cap, covers every $n$-bit endpoint of $U^A(p)$ produced within $t(n)$ for $|p|\le n-2$, and globally accepts at most two outputs for each $(n,p)$ over ALL proofs. Let $E^A_n$ be the accepted outputs over all such $p$ and proofs. It belongs to $NP^A=P^A$ and satisfies
\[
 |E^A_n|\le2\sum_{i=0}^{n-2}2^i=2^n-2.
\]
Thus its complement is an infinite $P^A$ subset of $R^{t,A}$ by completeness, contradicting the matched-oracle immunity lemma. This is a proved impossibility of a UNIVERSALLY relativizing schema, NOT a construction of the ordinary universal PFCERT object. In particular the ANF-cone promise does not cover all short $U$ programs.
