\section{Claim card and exact obstruction}

\paragraph{Exact obstruction.}
The obstruction is \emph{quantitative local completeness for the chosen target}:
construct, for the exact FLMV source model, a same-realization reduction whose output
has quasilinear length, whose arbitrary output bit is accessible in polylogarithmic
time and logarithmic writable space, and whose malformed-input and residual-child
behavior is total and charged.  A qualitative polynomial Karp reduction does not
supply these bounds.

Let $\M\subseteq\{0,1\}^*$ be the total language defined as follows.  A string is in
$\M$ iff it parses in the fixed canonical encoding as a CNF in which every clause has
three distinct variables and one sign, no two clauses are identical, every variable
occurs exactly twice positively and twice negatively, and the formula is satisfiable.
Every malformed string is a NO instance.  This is a language, not a promise problem.

\paragraph{Same realization.}
Every transport assertion below refers to one fixed uniform deterministic total exact
decider and one fixed indexed read-only-input random-access Turing-machine realization.
Setup, policy discovery, failed trials, arbitrary-bit access, query indices, child
construction, output, proof checking, retained state, and peak writable space are all
charged to that realization.

\section{Four falsifiers}

\begin{enumerate}
\item \textbf{Falsifier F1.}  ``A P=NP route must directly handle every ordinary SAT
formula.''  \textbf{FALSIFIED/RETIRED}: a polynomial decider for every string of the
single NP-complete total language $\M$ suffices.
\item \textbf{Falsifier F2.}  ``NP-completeness alone transports the numerical FLMV
box.''  \textbf{FALSIFIED/RETIRED}: inert polynomial padding after a valid reduction
can change output length from $N$ to $N^B$ and hence change a target $M^K$ simulation
to $N^{BK}$.
\item \textbf{Falsifier F3.}  ``Malformed encodings may be ignored.''
\textbf{FALSIFIED/RETIRED}: that converts the theorem into a promise statement.
A total decider must parse and reject malformed strings; its time and space count.
\item \textbf{Falsifier F4.}  ``Pinning or resolution children can be submitted directly
to the target decider.''  \textbf{FALSIFIED/RETIRED}: one pin creates binary clauses,
and ordinary resolvents may be mixed-sign width four.  The target is not hereditarily
closed, so each such child needs a terminal proof or a charged sound re-encoding.
\end{enumerate}

\section{The exact scope theorem}

\begin{theorem}[TARGET-SCOPE1---qualitative correction, PROVED/EXACT]
The following are equivalent:
\begin{enumerate}
\item $\mathrm{P}=\mathrm{NP}$;
\item the total language $\M$ has a uniform deterministic polynomial-time decider on
all strings, including rejection of malformed strings.
\end{enumerate}
Consequently, a superpolynomial deterministic time lower bound for $\M$ implies
$\mathrm{P}\ne\mathrm{NP}$.
\end{theorem}

\begin{proof}
D\"ocker proves the well-formed satisfiability core NP-complete under polynomial
many-one reductions.  A parser verifies all syntactic conditions and routes malformed
strings to NO in polynomial time, so the total language is in NP and remains NP-hard.
If $\mathrm{P}=\mathrm{NP}$, $\M\in\mathrm P$.  Conversely, if $\M\in\mathrm P$,
compose any NP language's Karp reduction to $\M$ with the decider; hence
$\mathrm{NP}\subseteq\mathrm P$.  The lower-bound consequence is the contrapositive
of the forward implication.  No claim about a numerical FLMV exponent follows.
\end{proof}

\section{The charged quantitative transport theorem}

\begin{theorem}[TARGET-FLMV-TRANSPORT1---PROVED/EXACT]
Let a source string have length $N$.  Suppose a uniform virtual reduction produces a
target string of length
\[
M=N^{a+o(1)},
\]
uses setup time $N^{u+o(1)}$, retained setup space $N^{v+o(1)}$, and answers each
target-symbol request in time $N^{q+o(1)}$ and writable space $N^{r+o(1)}$.
If one fixed target decider runs in time $M^{K+o(1)}$ and writable space
$M^{L+o(1)}$, then the same-realization source simulation has
\[
T(N)=N^{\max\{u,q+aK\}+o(1)},\qquad
S(N)=N^{\max\{v,r,aL\}+o(1)}.
\]
This includes index tapes and retained reduction state; additive logarithmic terms are
absorbed in $o(1)$.
\end{theorem}

\begin{proof}
Perform setup once.  Simulate each target-machine step.  A step that reads target bit
$j$ invokes the reduction accessor on the same source and the explicit target index;
there are at most $M^{K+o(1)}$ such invocations, so query work is
$N^{q+o(1)}M^{K+o(1)}=N^{q+aK+o(1)}$.  Taking the maximum with setup time proves the
time formula.  The simulation stores the target decider's writable state, the accessor
workspace, the target index, and retained setup state simultaneously, not additively
across time.  Their maximum gives the stated space exponent.  Output construction,
if materialized, must be included in $u,v$; switching and failed trials likewise.
\end{proof}

\begin{corollary}[Strict FLMV gate]
Transport into the project's strict forbidden box requires
\[
\max\{u,q+aK\}<\frac{241}{200},\qquad
\max\{v,r,aL\}<\frac{11642479}{23232400}.
\]
A quasilinear locally accessible reduction has $a=1$, $u=1$, and $q,v,r=0$ at the
exponent level, so it preserves $(K,L)$.  Qualitative NP-completeness provides no such
parameter values.
\end{corollary}

Intersecting these rows with the two global clauses left the empty set.  Therefore the

For $V$, the full supplied 198-bit assignment was replayed over all 264 clauses.  Its

\[

As an external standard optimization-solver control, the same clauses were encoded as

work comparison, not an asymptotic SAT or MILP lower bound.

\subsection{Retained signed S/U controls}

For every one of the 792 signed source occurrences, the producer records
\[
S_j(\ell)=\mathbf 1[\ell>0],\quad U_j(\ell)=1-S_j(\ell),
\quad \neg S_j=U_j,\quad \neg U_j=S_j.
\]
For each of the $\binom{264}{2}=34{,}716$ indexed clause pairs it records SS, SU, US,
UU feasibility.  Pair-pattern counts are 786 with mask 0110, 351 with mask 1001, and
33,579 with mask 1111; no pair has both a same-polarity and an opposite-polarity shared
variable, as clausewise monotonicity predicts.  All indexed rows are deterministically
regenerable and hashed in the raw record, preventing silent double counting.

Both endpoints fail on both $U$ and $V$:
\[
0^{198}: (N_0,N_1,N_2,N_3)=(132,0,0,132),\qquad
1^{198}: (132,0,0,132).
\]
The raw record also contains prefix-flip trails through sizes
$0,1,2,4,8,16,32,64,128,198$.  The SAT fixture $V$ is a direct counterexample to the
shortcut ``both endpoints fail, therefore UNSAT.''  Local opposing preferences likewise
do not prove UNSAT.
