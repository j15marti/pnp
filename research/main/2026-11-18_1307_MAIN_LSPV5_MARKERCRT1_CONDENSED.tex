\paragraph{CANDIDATE A: source-certified one-hot exterior read.}
A second physical tape $Y$ stores exactly one active marker at $ut\bmod 2^n$. A controller reads an \emph{individual} physical bit $Y_{v_ct+w_c}$; a unit relative slope gives one possible positive-read event per mode and period. Missing assumptions: one-hot initialization and preservation, odd relative slopes, complete source. Falsifier: physical read disagrees with the congruence predicate on an invariant fiber.
\paragraph{CANDIDATE B: unified event arithmetic and acceleration.}
Add all marker-match times to source-derived target-write residues and power a small finite controller/parity quotient between events. Missing assumptions: polynomial quotient, odd data slopes, phase accounting, independently recomputed tables. Falsifier: missed event or full-tape endpoint mismatch.
\paragraph{CANDIDATE C: nonunit arithmetic progressions.}
Represent repeated marker matches by one arithmetic progression rather than explicit enumeration. Missing assumption: a polynomially verifiable evaluator combining event progressions with nonlinear mode switches. Falsifier: a nonunit residue equation has exponentially many matches.
\paragraph{CANDIDATE D: read-dependent marker motion and a public WRAPPER.}
Allow read feedback to change the next marker motion; separately evaluate a disclosed $h$-bit completion hash. Missing assumption: closed polynomial provenance under feedback or a noncryptographic necessary-work principle. Falsifier: the affine marker invariant fails, or a public short hash prefix is searchable in $2^h$ trials.

\section{CONSTRUCTION OR PROOF ATTEMPT}
\subsection{Authenticated two-tape macrostep source}
Let $M=2^n$, with $n$ unary-padded in an original source string of length $N$. Two physical Boolean tapes are $X,Y\in\{0,1\}^M$. $X$ is initially blank and $Y$ has a single one at address zero. The controller has $Q$ modes; $S=\{a_0,\ldots,a_{s-1}\}$ is a list of distinct target addresses on $X$. $P=2^b$ divides $M$. For mode $c$, the source lists integer coefficients $\alpha_c,\beta_c,v_c,w_c$ modulo $M$ and a global marker stride $u$. Both $\alpha_c$ and $u-v_c$ are odd. Each actual physical macrostep at time $t$:
\[
m_t=ut\bmod M,\qquad b_t=Y_{(v_ct+w_c)\bmod M},\qquad d_t=(\alpha_ct+\beta_c)\bmod M.
\]
Read $b_t$ \emph{before} moving the marker. If $d_t=a_i\in S$, overwrite that $X$ bit and update the mode using fully explicit truth tables $W(c,z,p,b_t,i)$ and $G_{\rm hit}$. Otherwise update $X_{d_t}\leftarrow X_{d_t}\oplus\Delta(c,z,p,b_t,d_t\bmod P)$ and the mode using $G_{\rm ext}$. Here $z_i=X_{a_i}$ and
\[
p_j=\bigoplus_{\substack{0\le a<M\\a\notin S\\a\equiv j\pmod P}}X_a
\]
are true exterior parity buckets. Finally set $Y_{m_t}\leftarrow0$ and $Y_{m_{t+1}}\leftarrow1$. Controller tables may be arbitrarily nonlinear and may branch on the individual marker read. They cannot read hidden data cells. The full original tables and addresses are part of the input and checked for valid lengths and entries. The initial state is $(c,z,p)=(0,0,0)$.
The macrostep grammar is not claimed to be constant-time on an ordinary sequential-head Turing machine. Physical head travel may take $\Omega(M)$ time per macrostep. The separate certificate verifier is a conventional sequential bit machine reading the complete compact source and binary horizon $T$.

\begin{lemma}[Exact source-certified one-hot invariant and all-fiber consecution]
For all $t\ge0$ the source-maintained marker tape has exactly the form $Y=e_{ut\bmod M}$. For any $c$ and arbitrary two physical tapes $X,X'$ with equal $(z,p)$ and both marker tapes satisfying that invariant, the projected successors agree on $(c,z,p)$, whether or not the states are reachable.
\end{lemma}
\begin{proof}
Initialization gives $Y=e_0$. The source's two marker writes preserve the claimed one-hot position, because $u$ is odd and $M\ge2$. The exact marker bit read in mode $c$ is the arithmetic predicate
\[
b_t(c)=[(u-v_c)t\equiv w_c\pmod M].
\]
The source's target overwrite touches one known bit. An exterior XOR update changes precisely one bucket parity by the known $\Delta$, independently of the hidden old data bit. The controller arguments are entirely $(c,z,p,b_t,i)$ or $(c,z,p,b_t,j)$. The same projected successor therefore follows for every pair of states on the invariant fiber.
\end{proof}

\begin{lemma}[Source-certified dual event sparsity]
For each mode $c$ the nonzero marker read can occur only at the unique residue
\[
\rho_c=(u-v_c)^{-1}w_c\pmod M,
\]
and for each target $a_i$ the mode can write it only at the unique residue
\[
\tau_{c,i}=\alpha_c^{-1}(a_i-\beta_c)\pmod M.
\]
The union $E$ of all potentially exceptional residues has $J\le\min(M,Q(s+1))$.
\end{lemma}
\begin{proof}
An odd integer is a unit modulo $2^n$. Every congruence therefore contributes exactly one residue, and the union over all modes covers all possible adaptive mode choices. Duplicates decrease the size. All residues are computed from the original coefficients, not selected by an existential descriptor.
\end{proof}

\subsection{Finite background, return map, binary horizon}
Off $E$, every mode sees marker read zero and every mode writes a non-target data cell. Therefore $z$ stays fixed. The low phase $r=t\bmod P$ determines the parity bucket of any write. Define the background transition $H$ on $(c,z,p,r)$ with $D=PK$ possible states, $K=Q2^{s+P}$. The background map is explicit and can be powered by $H^{2^{i+1}}=H^{2^i}\circ H^{2^i}$ for $0\le i<n+1$. Compose background gaps and exact events in sorted order for a whole $M$-step period to construct $F:[K]\to[K]$. At period end $t\bmod M=t\bmod P=0$ and the one-hot marker returns to zero, so the same map $F$ applies every period. For $T=kM+r$ evaluate
\[
(c_T,z_T,p_T)=R_r(F^k(0,0,0)).
\]
$R_r$ is computed by the same source event list and background powers for the final prefix.

\begin{theorem}[Globally unique source-grounded terminal bit]
Fix $a>0$. For every valid complete source of length $N$ satisfying $n\le N$ and $K=Q2^{s+P}\le N^a$, every binary horizon $T\ge0$ with $L=\lceil\log_2(T+2)\rceil$, and every named target $a_i$, there is a deterministic polynomial-time constructible and polynomial-time verifiable certificate for $X_{a_i}(T)$. Every accepted certificate for the same original source and $T$ agrees on \emph{one global terminal output bit}, not merely one value per certificate.
\end{theorem}
\begin{proof}
The fixed source grammar establishes initiality and the one-hot inductive invariant. The preceding lemmas establish source-level, every-fiber consecution and the complete event union. The verifier independently reconstructs $H$ from original table rows, checks all supplied repeated-squaring identities, independently reconstructs $F$ for every one of the $K$ states using every source event, checks all $F$ powers, and checks the final partial period and output. Its deterministic checks force the same terminal state in \emph{all} accepted proofs. A conservative bit-size bound, with $D=PK$ and $J\le Q(s+1)$, is
\[
O\left(N+Jn+Dn\log(D+2)+KL\log(K+2)\right).
\]
Construction and verification use $O(Dn+K(J+1)n+KL)$ table applications plus polynomial bit arithmetic, sorting, complete source inspection, parsing, comparisons and output. Peak live workspace is bounded by the certificate and polynomial arithmetic buffers on one ordinary sequential bit machine. $K\le N^a$, $n\le N$ and explicit source tables ensure the bounds are polynomial in $N+L$. The $2^n$ physical tape cells are never initialized, traversed or expanded by this endpoint predictor.
\end{proof}

\begin{proposition}[Nonunit event blowup, not a time lower bound]
With $M=2^n$, $u=1$, $v=1-2^{n-1}$ and $w=0$, the read-match equation holds at every even residue, hence at exactly $2^{n-1}$ residues in a period. The unit-relative-slope condition is essential to the \emph{enumerated-event bound}, although a compact progression evaluator may exist.
\end{proposition}
\begin{proof}
$(u-v)t=2^{n-1}t\equiv0\pmod{2^n}$ exactly when $t$ is even.
\end{proof}

\subsection{Matched-oracle PFCERT diagnostic and nonalgebrization gate}
Choose \emph{one} oracle $O$ for the universal program machine $U^O$, all verifiers and complexity classes. Define $K^{t,O}(x)$ as the length of the shortest program printing $x$ within $t(|x|)$ ordinary oracle-machine steps, charging query tape preparation. For superpolynomial $t=n^{\omega(1)}$, the relativized suffix argument makes $R_{K^{t,O}}=\{x:K^{t,O}(x)\ge|x|-1\}$ $P^O$-immune. If infinitely many $n$ have an $x\in A\subseteq R$ for a $P^O$ language $A$, store an $n-C\log n$-bit prefix of an $A$-member and enumerate the at most $n^C$ suffixes with the fixed $P^O$ decider. The output has a program of length $n-C\log n+2\log n+O(1)<n-1$, running in polynomial oracle time, contradiction.
Take $O=\mathrm{TQBF}$ with $P^O=NP^O$. A \emph{complete universal relativizing PFCERT package} would additionally require: polynomial-length descriptors for every relevant $(n,j)$; fixed-$\mathrm{PH}^O$ descriptor validity; coverage of all short $U^O$ programs halting in $2^j$ steps; polynomial-time membership in a \emph{chosen descriptor's} output envelope; and source-certified sparsity leaving some string outside. Under the collapse, fixed $\mathrm{PH}^O$ validity and bit-by-bit lexicographic canonical descriptor/outside-string selection become $P^O$. For fixed large $j=C'\log n$, the chosen outside string has a uniform $O(\log n)$-bit, polynomial-oracle-time description, so must be in the represented covered envelope, contradiction. This isolates a required nonrelativization of the \emph{full package}, not a theorem that universal descriptors exist. Mere two-output label consistency is insufficient. Existential union of exponentially many sparse descriptors is not itself sparse. The restricted marker certificate relativizes and does not establish a route past Aaronson--Wigderson algebrization. Completion-time public short hash prefixes provide no unconditional classical hardness; after disclosure $2^h$ checks suffice for an $h$-bit prefix under direct enumeration when $h=O(\log N)$.
