# PCP-GATE1: Witness-Gating Audit for ADVICE-HIERARCHY / META-LIFT

**Status:** Substantive narrowing result. No P-vs-NP or P-vs-PSPACE separation is claimed.

**Date:** 2026-10-18

## 1. Objective

ADVICE-HIERARCHY1 supplied two of the three ingredients required by META-LIFT:

1. an unconditional hard family for a fixed-resource, length-dependent program measure;
2. a succinct version of the minimization problem lying in \(\Sigma_2^P\).

The remaining problem is GATED-HARDTABLE1:

> Given a source instance \(x\), construct in deterministic polynomial output and polylogarithmic workspace a meta-complexity instance that is easy on one semantic side of \(x\) and inherits an unconditional resource lower bound on the other side, without solving \(x\) inside the reduction.

This note audits PCP, secret-sharing, direct-sum, implicit-input, and communication-complexity mechanisms as possible solutions.

---

## 2. The exact scale mismatch

Let the ordinary source instance have length \(N\).

Suppose the hard object is a truth table of a function on \(n\) bits. Its explicit size is

\[
2^n.
\]

A polynomial-output reduction requires, for some constant \(c\),

\[
2^n\le N^c,
\]

and therefore

\[
n\le c\log N.
\]

Now suppose the available unconditional advice/program lower bound on that \(n\)-bit function is only polynomial in \(n\):

\[
K_n>n^\delta.
\]

Then the guaranteed hard-side gap after polynomial-output scaling is at most

\[
n^\delta
\le
(c\log N)^\delta
=
\operatorname{polylog}N.
\]

### Proposition 2.1: MATERIALIZATION-SCALE1

Any truth-table-based GATED-HARDTABLE construction that uses only a polynomial-in-domain-length advice lower bound can guarantee at most a polylogarithmic-in-\(N\) description gap while keeping the target output polynomial in \(N\).

This does not refute all gating mechanisms. It does refute any construction whose easy-side representation must literally carry \(N^{\Omega(1)}\) source-specific witness or selector information.

---

## 3. PCP alone does not remove the global-information requirement

A PCP can reduce verification of a long witness to a few local queries.

That is not the same as giving the witness a short *description*.

Suppose a proof has \(L=N^{\Omega(1)}\) locations. A verifier may inspect only \(q=O(1)\) or \(O(\log N)\) locations per random string, but a meta-complexity candidate must answer the verifier consistently across all random strings.

A PCP theorem guarantees:

\[
\text{few queried coordinates per test},
\]

not

\[
\text{a polylogarithmic-size program generating a globally consistent proof}.
\]

Thus PCP locality by itself does not bridge Proposition 2.1.

This matches the role PCPs play in known Partial-MCSP hardness proofs: PCP regularization makes tests local and balanced, while a separate information-theoretic mechanism supplies global consistency.

---

## 4. Why per-input query bounds do not imply a global share set

Secret-sharing approaches require a fixed small set of shares/keys that a short program can "know."

A time/query bound does not imply such a fixed set.

### Lemma 4.1: VARYING-SUBSET1

There are access structures and algorithms for which, on every query \(z\), the algorithm reads at most \(q\) shares, but the set

\[
B_z
\]

of shares read can depend on \(z\), and

\[
\left|\bigcup_z B_z\right|
\]

can be arbitrarily larger than \(q\).

Therefore a statement of the form

\[
\text{"the program reads at most }q\text{ shares per example"}
\]

does not imply the existence of one global set \(B\) of size \(q\) that contains all information used by the program.

A threshold-sharing control gives an immediate example: assign a different authorized \(q\)-subset to each query and let the algorithm select that subset from the query index.

### Consequence

Secret-sharing privacy against a fixed unauthorized set cannot be invoked merely from a per-instance time, probe, or workspace bound.

A successful reduction needs a separate theorem converting small **description complexity** into a small global knowledge set.

---

## 5. Hirahara's randomized construction supplies exactly that missing theorem

Hirahara's FOCS 2022 Partial-MCSP / learning reduction uses random functions together with conditional Kolmogorov complexity.

The critical property is not merely that evaluating one sample requires few keys. It is that a small program can have low conditional complexity with respect to only a small **global set** of the independently random functions.

The remaining shares are information-theoretically hidden from that program. Monotone secret sharing then turns this global-knowledge bound into the soundness argument.

Thus the randomized hard functions perform the exact job missing from a pure PCP or charged-query argument:

\[
\boxed{
\text{small program}
\Longrightarrow
\text{small globally known key set}.
}
\]

This also explains why replacing the random functions by a short-seed PRG is invalid for a minimization problem: the minimizing program may simply hardwire the seed if the seed is below the size threshold.

---

## 6. The deterministic direct-sum route is quantitatively much stronger than Tourlakis

Hirahara and Moshkovitz give a deterministic sufficient condition for NP-hardness of Partial MCSP.

Their direct-sum route requires an E-computable indexed family with a \(\sigma\)-direct-sum property. Proposition 14 obtains

\[
\sigma=\Theta(2^n/n)
\]

from a function that cannot be computed in time \(2^{cn}\) even with advice of length approximately

\[
2^{n+k}-2^{n-1}.
\]

This is nearly truth-table-scale advice hardness.

By contrast, the Tourlakis bound used in ADVICE-HIERARCHY1 provides only polynomial advice hardness in the \(n\)-bit input length:

\[
n^{O(1)}.
\]

Under the polynomial-output constraint \(n=O(\log N)\), these become respectively

\[
\Theta(N^{\Theta(1)}/\log N)
\]

versus

\[
\operatorname{polylog}N.
\]

### Proposition 6.1: DIRECTSUM-SCALE1

The Tourlakis advice lower bound cannot be substituted directly into the Hirahara-Moshkovitz deterministic Partial-MCSP theorem. The available advice hardness is exponentially smaller in the hard-function input length than the condition used to derive their direct-sum property.

This is a quantitative mismatch, not merely a missing proof detail.

---

## 7. Why INDEXCUT43 and ADDRESSSEM44 help but do not supply direct sum

INDEXCUT43 can rule out certain explicit representations of many unresolved semantic addresses by forcing nearly linear represented information.

ADDRESSSEM44 can rule out resolving a SAT-dependent address inside a sufficiently strong simultaneous low-time/low-space regime.

Neither theorem currently implies:

\[
\text{short arbitrary program}
\Longrightarrow
\text{small global key set}.
\]

In particular, a program may compute different share/key addresses on different inputs without materializing a branch for every address.

So these project lower bounds remain valuable adversarial tests for a proposed gating implementation, but they do not replace the direct-sum/knowledge lemma needed by the Hirahara framework.

---

## 8. Implicit MCSP avoids the explicit truth-table blowup, but current hardness is assumption-heavy

Goldberg, Juvekar, and Kabanets (ECCC TR26-091, 2026) study Gap-Implicit-MCSP.

The input is a circuit sampling labeled examples rather than an explicitly materialized truth table. This is exactly the kind of representation one would want in order to avoid the exponential-output obstruction from ADVICE-HIERARCHY1.

However, their current NP-hardness theorem requires:

1. subexponentially secure indistinguishability obfuscation; and
2. the nonexistence of infinitely-often subexponentially optimal propositional proof systems.

The reduction is randomized and half-Levin.

Thus implicit input solves the **size** problem but currently moves the missing theorem into cryptography/proof complexity.

It is not an unconditional replacement for GATED-HARDTABLE1.

---

## 9. A useful control: deterministic communication complexity solves gating but loses self-succinctness

Two independent 2025-2026 works establish that computing deterministic two-party communication complexity from a full truth table is NP-hard/NP-complete.

The Hirahara-Ilango-Loff construction gives an explicit polynomial-size communication matrix \(f'_G\) whose optimum protocol depth has an exact one-bit gap determined by Vertex Cover.

This is important conceptually:

\[
\boxed{
\text{deterministic semantic gating into a meta-complexity measure is possible.}
}
\]

The reduction does not need random hard truth tables or cryptographic assumptions.

But the target fails the other side of META-LIFT.

### Lemma 9.1: CIRCUIT-DCC-NEXP-UPPER

Given a Boolean circuit \(C(x,y)\) on \(2n\) input bits and a threshold \(k\), deciding whether the represented communication matrix has deterministic communication complexity at most \(k\) lies in NEXP.

Proof sketch:

- communication complexity is at most \(n+1\), by having one party transmit its whole input;
- a depth-\(k\) protocol has at most \(2^k\le2^{O(n)}\) nodes;
- at each node, an arbitrary local message function can be written as a \(2^n\)-bit truth table;
- the entire explicit protocol therefore has size \(2^{O(n)}\);
- nondeterministically guess that protocol and exhaustively verify it against all \(2^{2n}\) input pairs by evaluating \(C\).

All work is \(2^{\operatorname{poly}(|C|)}\).

No PSPACE upper bound is obtained by this argument. The arbitrary local split functions are exponentially long and can be reused at many descendants, so the straightforward depth-first verifier cannot simply forget them while maintaining consistency.

Thus communication complexity supplies a useful opposite control:

- explicit deterministic gating: YES;
- known low succinct complexity of the kind required by META-LIFT: NO.

---

## 10. A second control: decision-tree complexity has low succinct complexity but weak explicit hardness

Loff and Milovanov (STACS 2025) show:

- truth-table decision-tree complexity is NC\(^1\)-hard and has a near-matching efficient upper bound;
- circuit-input decision-tree complexity is PSPACE-hard, and that bound is tight.

This is almost the reverse of deterministic communication complexity.

It demonstrates the second recurring failure mode:

\[
\boxed{
\text{low/tight succinct complexity}
\quad\text{but}\quad
\text{explicit minimization too easy to encode P/NP hardness}.
}
\]

---

## 11. The Gating Triangle

The literature and project results now organize into three requirements.

### A. Deterministic polynomial-output gating

The source semantic bit must control the meta-complexity optimum without the reduction solving the source.

### B. Low succinct complexity

The succinct target must remain in PSPACE, preferably PH, so that \(P=PSPACE\) collapses it far enough to create a hierarchy contradiction.

### C. Unconditional hard-side lower bound

The hard side must be protected by a genuine resource/representation lower bound, not a concrete-hash assumption.

Current examples:

| Target | A: gating | B: low succinct | C: unconditional hardness |
|---|---|---|---|
| \(LOW_{a,b,\delta}\) | **OPEN** | yes, \(\Sigma_2^P\) | yes, advice/time-space |
| MOCSP/GapMOCSP | randomized/conditional | yes | random-table / gap hardness |
| Partial MCSP | randomized; deterministic under strong direct sum | low explicit certificate | random/direct-sum |
| deterministic communication complexity | yes | no known PSPACE bound; NEXP upper | yes, combinatorial |
| decision-tree complexity | explicit side too weak | yes, circuit case PSPACE-complete | model lower bounds available |

The unresolved research problem is therefore not "find any hard meta-complexity problem."

It is:

\[
\boxed{
\text{find one target satisfying A, B, and C simultaneously.}
}
\]

---

## 12. Revised positive target: RESOURCE-DIRECTSUM1

The clearest route back toward \(LOW_{a,b,\delta}\) is to prove a direct-sum theorem tailored to the resource measure rather than unrestricted circuits.

Seek an explicitly and low-space computable indexed family

\[
F=\{f_i:\{0,1\}^n\to\{0,1\}\}_{i\in[k]}
\]

such that any description \(p\) of length at most \(s\), running in time \(n^a\) and space \(n^b\), can correctly compute only a small global set of the \(f_i\)'s.

A useful form would be:

\[
\left|
\left\{
i:
p(i,\cdot)=f_i(\cdot)
\right\}
\right|
\le q(s,n),
\]

with \(q\ll k\).

An even stronger conditional-complexity form would state that for every program \(p\) there exists one global set \(B_p\subseteq[k]\) of size \(q\) outside of which the \(f_i\)'s retain enough resource-bounded unpredictability to support secret-sharing privacy.

If such a theorem can be obtained from advice/time-space lower bounds plus a direct-product amplification, the Hirahara PCP/secret-sharing architecture could potentially be transplanted to the fixed-resource \(LOW\) target.

No such theorem is currently established.

---

## 13. Exact next experiments

1. **Direct-product audit.**
   Search for advice/time-space direct-product or data-structure lower bounds that yield a global-set conclusion, not merely one hard query.

2. **Communication-gadget transfer.**
   Test whether the rectangle-partition gadgets used in deterministic communication-complexity NP-hardness satisfy an abstract "extension/separation" axiom that can be implemented for bounded-program complexity.

3. **Implicit-LOW.**
   Define an implicit labeled-example analogue of \(LOW_{a,b,\delta}\), then determine its exact succinct complexity before attempting hardness. Reject it if one level of succinctness moves the target to NEXP/EXPSPACE.

4. **INDEXCUT compatibility.**
   For any proposed global-set theorem, explicitly test a program that computes different key addresses on different examples. If the theorem fails under this adaptive control, it is insufficient for secret-sharing soundness.

---

## 14. Current conclusion

The PCP/secret-sharing direction did not close GATED-HARDTABLE1, but it produced a much sharper diagnosis.

The missing theorem is not generic PCP locality.

It is:

\[
\boxed{
\textbf{a resource-bounded global-knowledge/direct-sum theorem}
}
\]

strong enough to convert a short program into one small fixed set of known keys.

The currently available Tourlakis advice lower bound is too weak, quantitatively, to instantiate the known deterministic Partial-MCSP direct-sum route. Communication complexity shows that unconditional deterministic gating is possible in principle, while decision-tree complexity shows that low succinct complexity is possible in principle. The unresolved challenge is achieving both in the same minimization measure.
