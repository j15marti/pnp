\noindent\textbf{Executive result.}
\textbf{PROVED/EXACT restricted symbolic theorem; COMPUTATIONAL independent controls.}
For every prescribed finite window order $k$, there is a valid connected canonical
D\"ocker monotone 3-SAT-(2,2) original and two coherent pinned residuals whose
cyclic profile-factor histograms agree at every length $1,\ldots,k$, while one
residual is SAT and the other is UNSAT.  Therefore neither exact local-profile
multisets, adjacent-pair histograms nor any fixed higher-order cyclic factor deck
is a sound decision/continuation cache key.  This does \emph{not} imply hard
decision: the authenticated family still has a linear ordered four-bit transfer
algorithm.  All-input polynomial total work, arbitrary-$A$ ARC, numerical
same-machine FLMV transfer, and P versus NP remain \textbf{OPEN}.

\section{All fixed windows fail}
For a word $w=a_1\cdots a_m$ and $L\ge0$, define the uniform morphism
\[
h_L(w)=B^L a_1 B^L a_2\cdots B^L a_m.
\]

\begin{lemma}[Cyclic deck lift]
If two cyclic words have the same ordered bigram counts, then
$h_L(w)$ and $h_L(w')$ have the same cyclic factor counts at every length
$j\le L+2$.
\end{lemma}
\begin{proof}
Partition starting positions by the source-symbol index and the offset within its
length-$(L+1)$ image.  A length-$j\le L+2$ window crosses at most one image
boundary and contains at most two designated source symbols.  Its content is
therefore a fixed function of the offset and one cyclic source bigram.  Summing
over equal bigram multiplicities proves equality.  The argument remains valid
when a designated source symbol itself equals $B$; the partition is by source
origin, not inferred parsing.
\end{proof}

\begin{theorem}[Fixed-window histogram firewall]
For every $k\ge1$, put $L=\max(0,k-2)$.  The same valid canonical original
$G_{6(L+1)}$ has coherent residuals described by $h_L(S)$ and $h_L(U)$ with
identical cyclic factor decks through length $k$ and opposite SAT labels.
\end{theorem}
\begin{proof}
The deck statement follows from the lemma.  On Boolean support matrices, the four
profiles are masks $2,8,11,12$ in row-major order.  Mask $11$, the support of
$M_B$, is idempotent.  Direct Boolean-semiring multiplication gives support mask
$3$ for $h_L(S)$ and mask $2$ for $h_L(U)$ for every $L\ge0$.  Mask $3$ has a
diagonal entry and mask $2$ has none.  The exact transfer identity therefore
gives a SAT extension for the first residual and a complete UNSAT conclusion for
the second.  Cyclic F9 splicing preserves two positive and two negative
occurrences, same-sign distinct-variable clauses and duplicate freedom, so every
source original is valid and connected.
\end{proof}

This theorem blocks every \emph{fixed-order unordered} local-deck key.  It does not
block an ordered automaton, a window growing with input length, or another
uniformly acquired exact quotient.  It is a decision/continuation counterexample,
not an arbitrary-machine lower bound.

\section{Cheaper exact algorithm and the tight A/B promise}
The recognized family retains the exact streaming rule
\[
R\leftarrow R\odot R_i,qquad R\in\{0,1\}^{2\times2},
\]
followed by a nonzero-diagonal test.  Once grammar and each local profile have
been paid for, this uses four live relation bits, a logarithmic source index and
$O(N)$ constant-table operations.  The seven-state minimized pin-word automaton
reported independently by LSPV-3 is an even coarser restricted implementation.
Hence the histogram collision proves that order matters, not that decision is
expensive.

The distinct DECISION-WORK307 promise was also reconstructed.  Its profiles
obey
\[
W_A=\begin{pmatrix}1&1\\0&0\end{pmatrix},\qquad W_B=0,
\]
so a $t$-block word is SAT exactly when all blocks are $A$.  On all-$A$, the
$t$ one-$B$ opposite-label inputs have pairwise disjoint two-bit difference
regions.  Every deterministic exact bit-query algorithm must hit all regions,
hence needs at least $t$ pin queries; one discriminating read per block attains
$t$.  No cheaper exact bit-query algorithm exists on that declared promise, but
the result remains linear and restricted.
