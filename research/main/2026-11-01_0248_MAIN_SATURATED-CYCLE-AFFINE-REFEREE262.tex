\section{Independent reconstruction}
\begin{lemma}[signed conservation]
For every satisfying completion $a$ of $p$,
\[
 e-\eta=\sum_{j\in U}(t_j(a)-1)
 +\sum_{x:s_x^+\ne s_x^-}|s_x^+-s_x^-|
   \mathbf 1[a_x\ne b_x],
\]
where $b_x=0$ if $s_x^+>s_x^-$ and $b_x=1$ otherwise.
Every summand is a nonnegative integer.
\end{lemma}
\begin{proof}
Every free variable contributes exactly two true signed occurrences among its
two positive and two negative source occurrences.  Its true occurrences in
covered clauses equal $\min(s_x^+,s_x^-)$ plus the displayed mismatch charge.
The remaining true occurrences are $\sum_{j\in U}t_j(a)$.  Subtracting the
one-true-literal baseline $u$ proves the identity.
\end{proof}

\begin{theorem}[delta-zero cycle-affine union]
Under the claim-card hypotheses and $\delta=0$, each satisfying completion
has exactly one doubly true edge on each selected odd cycle, all remaining
cycle edges and every uncovered noncycle clause have exactly one true
literal, and every signed preference is obeyed.  Selecting the unique doubly
true edge per cycle partitions all completions into pairwise disjoint affine
GF$(2)$ systems.  Hence
\[
 \#\mathrm{SAT}(F\mid p)=
 \sum_{z:\,M_zx=b_z\text{ consistent}}2^{f-\operatorname{rank}M_z}.
\]
UNSAT follows only after all nominal selections have replayable contradictions.
\end{theorem}
\begin{proof}
If every edge on an odd cycle had exactly one true literal, its variable
values would 2-color an odd cycle, impossible.  Thus every selected cycle
contributes at least one unit to the first conservation sum.  Distinct source
clause edge IDs make these $\nu$ units additive.  At $e-\eta=\nu$ they exhaust
the identity, forcing every other nonnegative charge to zero and exactly one
doubly true edge per cycle.  A selected positive edge fixes both endpoints to
one, a selected negative edge fixes both to zero, and every nonselected
binary cycle edge gives $x\oplus y=1$.  A positive residual noncycle support
$V$ gives $\bigoplus_{x\in V}x=1$; a negative support gives RHS
$1\oplus(|V|\bmod2)$.  Preference bits are unary rows.  Conversely these
rows satisfy every noncycle clause and every explicitly selected cycle
template; covered clauses remain satisfied.  The selected edge vector is
unique, so branches do not overlap.  Gaussian rank gives the count.
\end{proof}

Cycles may share variable vertices.  They may not share original clause edge
IDs.  Shared variables merely make some combined selections inconsistent;
Gaussian elimination detects this.  This distinction is load-bearing.

\section{XOR and wrapper red team}
The following are exact only for their declared layouts.
\begin{itemize}
\item A lazy flag can change one physical bit while many virtual clause-status
records change; $d_{\rm logic}$ is not a physical write lower bound.
\item The path $0000\to1000\to0000$ has adjacent sum two and endpoint zero.

\item Binary counter $1\to2$ changes two bits while Gray changes one.  XOR is

curves cannot imply arbitrary-machine hardness.  DEAD, DELAY, COPY, INTERP,
RECOMP, source rereads and a maximal semantic oracle preserve this firewall.
