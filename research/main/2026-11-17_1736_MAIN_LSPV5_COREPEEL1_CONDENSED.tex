\section{CONSTRUCTION OR PROOF ATTEMPT}
A valid raw input specifies $n,m$ and exactly $n$ separate \texttt{v i} vertex records and $m$ sorted duplicate-free \texttt{e u v} directed arc records, including every source byte. Consequently $n+m\le N$ for input byte length $N$; a logarithmic header cannot hide exponentially many isolated vertices. For the fixed five-symbol relation $R(a,b)=[b-a\bmod5\in\{1,3\}]$, count precisely
\[Z(G)=\sum_{x\in\mathbb Z_5^n}\prod_{u\to v\in E} R(x_u,x_v).\]
\begin{lemma}[Authenticated triad contraction]
Every raw transitive triad $u\to v,v\to w,u\to w$ forces $x_v=x_u+3$ and $x_w=x_u+1$ modulo five. Enforce all these equations via a charged polynomial BFS; a contradiction proves $Z=0$, otherwise root labels and fixed offsets give a bijection between original satisfying assignments and satisfying root assignments after \emph{every original arc} is substituted.
\end{lemma}
\begin{proof}
The two-step allowed sums are $2,4,4,1$ and the direct allowed increments are $1,3$, so their intersection is the singleton $1$, obtained only from $3+3$. A consistent system of modular differences determines all offsets uniquely relative to one freely chosen root per connected equation component. Checking each original arc after substitution preserves the exact original count without a multiplicity factor.
\end{proof}
After contraction, build integer unary factors $u_v(a)$ and pair factors $M_{vw}(a,b)$, multiplying all parallel factors entrywise, with orientation transposition. For a current degree-0 vertex $v$, multiply the global scalar by $\sum_a u_v(a)$. For degree 1 at neighbor $w$, set $u_w(b)\gets u_w(b)\sum_aM_{wv}(b,a)u_v(a)$. For degree 2 with neighbors $w,w'$, create
\[K_{ww'}(b,c)=\sum_{a=0}^4 M_{wv}(b,a)u_v(a)M_{vw'}(a,c),\]
and multiply it entrywise into any existing $ww'$ factor. If $w=w'$, treat it as unary. Every operation is exactly finite-sum distributivity: each intermediate factor counts extensions of deleted original variables and has $O(N)$ bits. Lexicographically eliminate every available degree-$\le2$ vertex until all remaining vertices have degree $\ge3$.
