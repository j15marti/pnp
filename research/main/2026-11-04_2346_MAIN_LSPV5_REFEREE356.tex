\section{ITERATE: exact positional-definition theorem}

Let $f:\{0,1\}^2\to\{0,1\}$ and let the two input \emph{positions} name previous wires $u,v$, which may be the same wire.  For each row $(a,b)$ define
\[
 D_{ab}=\bigl(u\ne a\bigr)\ \vee\ \bigl(v\ne b\bigr)\ \vee\ \bigl(z=f(a,b)\bigr),
\]
where each equality or inequality is written as its corresponding literal.

\begin{theorem}[positional four-row paid definition]\label{thm:fourrow}
For every valuation of the previous wires, $\bigwedge_{a,b}D_{ab}$ holds exactly when $z=f(u,v)$.  This remains true when $u=v$.  Thus the record consisting of a fresh output identifier, two ordered input identifiers, and the four truth-table bits is conservative and uniquely extending.
\end{theorem}
\begin{proof}
For the actual ordered input values $(a,b)=(u,v)$, both mismatch literals are false and $D_{ab}$ forces precisely $z=f(u,v)$.  Every other row has at least one true mismatch literal.  If $u=v$, the two impossible off-diagonal rows contain complementary occurrences of the same variable and are tautologies; the diagonal rows impose $z=f(0,0)$ and $z=f(1,1)$ in their respective cases.  No set-valued support operation is used.
\end{proof}

\begin{theorem}[minimal legal alias counterexample]\label{thm:alias}
Any normalization that first deduplicates paid-DEF input positions and then carries an XOR coefficient once is not semantics preserving for native $R_{\mathrm{mix341}}$.  The one-paid-node witness is
\[
  F=(x),\qquad z:=\operatorname{XOR}(x,x).
\]
The authentic definition has the unique extension $x=1,z=0$; the deduplicated row $z\oplus x=0$ has $x=1,z=1$.  A downstream paid gate can observe the differing public wire.  Original-source projection alone cannot detect this error because both relations project to the same $x$ assignment.
\end{theorem}
\begin{proof}
$x\oplus x=0$ in GF(2), while the set-valued mask contains $x$ once.  Freshness and unique extension hold in both records, so conservative source projection is too weak a normalization invariant; consumer-visible wire semantics is necessary.
\end{proof}

More generally, an affine binary gate has a unique form $f(a,b)=c\oplus pa\oplus qb$.  Under aliasing its correct coefficient is $p\oplus q$, not $p\lor q$.  Consequently the set-support compiler fails exactly when $p=q=1$: XOR and XNOR, at aliased input value one.  This proves the full sixteen-gate boundary, not just one sampled witness.

\section{Noncircular B3 audit}

Write $\mathrm{PB}(R)$ for $\exists p\ \forall F\in\mathrm{UNSAT}$, $W_R(F)\le p(|F|)$.  B3 is the system-specific conditional
\[
  \mathrm{SAT}\in\mathrm P\quad\Longrightarrow\quad \mathrm{PB}(R_{\mathrm{mix341}}).
\]
Assume a fixed uniform polynomial-time correct SAT decider $A$.  The relation $Q_A(F,\epsilon)$ that accepts exactly when $A$ rejects the well-formed CNF $F$ is a polynomial-time Cook--Reckhow verifier with a constant certificate.  This demonstrates that the hypothesis supplies \emph{some} polynomially bounded proof system.  It does not supply an $R_{\mathrm{mix341}}$ proof.

\begin{lemma}[generic fixed-system bridge is false]\label{lem:pad}
The implication ``some polynomially bounded Cook--Reckhow system exists, therefore an arbitrary specified complete polynomial-time-verifiable system $R$ is polynomially bounded'' is false.
\end{lemma}
\begin{proof}
Given any Cook--Reckhow system $Q$, form $\operatorname{Pad}(Q)$.  A nondefault proof of formula $F=Q(\pi)$ must contain $\pi$ followed by exactly $2^{|F|}$ padding symbols; malformed strings map to one fixed valid formula.  Verification is polynomial in the padded proof length: compute $Q(\pi)$, scan the padding, and compare its binary counter with $|F|$.  The system remains sound, onto and polynomial-time verifiable, yet every nondefault $F$ has proof length at least $2^{|F|}$.  Hence even if $Q$ is polynomially bounded, $\operatorname{Pad}(Q)$ is not.
\end{proof}

This lemma does not say $R_{\mathrm{mix341}}$ is padded or that B3 is false.  It proves that Cook--Reckhow existence, NP=coNP, or a rejecting trace alone cannot establish same-$R$ B3.  A sufficient noncircular missing premise is a system-specific polynomial size simulation of $Q_A$ by the unchanged $R_{\mathrm{mix341}}$, or polynomial $R_{\mathrm{mix341}}$ proofs of the relevant uniform reflection instances for $A$.  Calling $A$ inside a new ``reject means contradiction'' rule changes the calculus and hides a semantic oracle; asserting short reflection proofs presupposes the desired certificate bound.  No such simulation or reflection theorem was found or proved.  Thus B3 remains \textbf{OPEN}, while the trace-only/existential-system bridge is \textbf{FALSIFIED/RETIRED}.
