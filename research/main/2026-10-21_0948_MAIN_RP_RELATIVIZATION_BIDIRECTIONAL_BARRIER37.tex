\section*{Primary-source contracts}
Baker--Gill--Solovay introduced the two-world relativization test for P versus
NP and constructed both equality and separation oracle worlds; see
\url{https://doi.org/10.1137/0204037}.  Gill's probabilistic Turing-machine
model supplies the classical randomized classes; see
\url{https://doi.org/10.1137/0206049}.  Bennett--Gill later proved random-
oracle separations by counting; see \url{https://doi.org/10.1137/0210008}.
The theorem here is a direct one-sided-error construction specialized to
$P$ versus $RP$; it does not infer an unrelativized conclusion from those
papers.

The P-versus-NP source models remain unchanged: CHMY
\url{https://doi.org/10.4230/LIPIcs.STACS.2021.23}, MMW
\url{https://people.csail.mit.edu/rrw/MCSP-MKTP-stoc19.pdf}, OPS
\url{https://theoryofcomputing.org/articles/v017a011/}, and FLMV
\url{https://doi.org/10.1145/1101821.1101822}.  Their hypotheses are not
replaced by an oracle construction.

\section*{Exact separating oracle}
Enumerate the clocked deterministic polynomial-time oracle machines as
$D_1,D_2,\ldots$.  Construct an oracle $A$ in stages.  At stage $i$, choose a
fresh length $n_i$, larger than every query length fixed earlier, so that the
clock $T_i(n_i)<2^{n_i-1}$.  Run $D_i^A(1^{n_i})$, answering every previously
unset oracle query by zero and permanently retaining those answers.

If $D_i$ accepts, freeze the entire $n_i$-bit slice of $A$ to zero.  If it
rejects, leave its queried strings zero and set exactly $2^{n_i-1}$ unqueried
strings to one.  There are enough unqueried strings by the clock inequality.
No answer on the simulated path changes.

Define
\[
 L^A=\{1^n:|A\cap\{0,1\}^n|=2^{n-1}\}.
\]
Every slice is either empty or exactly half full.  A probabilistic oracle
machine chooses one uniform $n$-bit string, queries $A$, and accepts precisely
on answer one.  It has zero acceptance probability on NO inputs and exactly
$1/2$ on YES inputs, so $L^A\in RP^A$.  At $1^{n_i}$, $D_i^A$ gives the
opposite answer by construction.  Hence $L^A\notin P^A$ and
\[
 P^A\ne RP^A.                                             \tag{1}
\]
The increasing fresh lengths make $A$ recursive: to decide a string of length
$n$, simulate stages until the chosen fresh length exceeds $n$.

\section*{Exact equality oracle}
Let $B=TQBF$.  PSPACE-completeness gives $P^B=PSPACE$.  The inclusions
\[
 P^B\subseteq RP^B\subseteq NP^B\subseteq PSPACE=P^B
\]
give
\[
 P^B=RP^B.                                                \tag{2}
\]
The middle containment holds because an accepting random tape is an NP
witness; polynomial-time nondeterminism with a PSPACE oracle remains in
PSPACE.

Equations (1) and (2) show that no proof valid unchanged relative to every
oracle can resolve unrelativized P versus RP.

\section*{Hitting advice survives both worlds}
For every oracle $O$ and fixed $RP^O$ machine, the acceptance matrix at length
$n$ still has empty NO rows and half-dense YES rows.  The greedy-halving proof
from RP-HITTING-QUANTIFIER-FIREWALL36 therefore gives
\[
 RP^O\subseteq P^O/poly
\]
for every $O$.  In particular, the separating world (1) has machine-specific
polynomial advice but no uniform deterministic simulation.  This exactly
falsifies the inference ``small hitting advice implies $P=RP$.''

\section*{WRAPPER/hash/oracle audit}
A hash, external bitstream, random-AVOID primitive, completion timer, or
black-box SAT oracle may still participate in a standard-model proof, but the
load-bearing arrow must explain how it is implemented and why the argument
does not remain valid for arbitrary oracle $A$.  Merely hiding solver state,
making oracle queries unpredictable, or counting black-box queries does not
cross the two-world barrier.  Proof-system bounds, finite collision tests and
randomized query lower bounds likewise do not transfer to unrestricted time.

This does not retire the deterministic MKTP or ARC routes.  Hardness
magnification and arithmetization can be nonrelativizing; the report only
requires that the exact such step be named and model-matched.

\section*{Computational audit}
The standard-library checker runs 4,608 finite adaptive clocked strategies on
zero paths, freezes each oracle slice to the opposite zero/half label, and
replays the strategy.  It meters 91,344 deterministic queries and checks
exact density, unchanged transcripts, one-sided RP acceptance and opposite
deterministic answers.  It executes 41,472 assertions with zero failures.
These tests validate the implementation only, not the infinite diagonal proof.
