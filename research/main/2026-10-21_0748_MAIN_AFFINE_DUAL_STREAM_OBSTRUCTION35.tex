\section*{Target and proposals fixed before literature}
The target was the newest CHMY Bridge34 suggestion: replace a repeated-source
coordinate map by a high-dual-distance global affine mixer.  Three falsifiable
possibilities were fixed before source checking: (i) dual distance may remove
all streaming tests; (ii) a full-stream parity may still require only one live
bit; (iii) short semantic advice may raise the image dimension enough to evade
the parity.  The first and third fail quantitatively; the second is exact, with
the uniformity qualification below.

\section*{Exact quantifiers, model and SAME\_REALIZATION}
For every $N,d,M$ and every public affine map on the same declared target
realization
\[
 E:\mathbb F_2^N\times\mathbb F_2^d\longrightarrow\mathbb F_2^M,
 \qquad E(f,z)=Af+Bz+h,
\]
if $M>N+d$, there exists a nonzero $v\in\mathbb F_2^M$ such that, for every
source $f$ and every side string $z$,
\[
 v^T E(f,z)=v^T h.                                           \tag{1}
\]
Here $f,z,E(f,z)$ are the actual source, advice and target bits; no hash,
oracle answer or alternative representation is substituted.  A length-specific
one-way scanner with the support of $v$ in finite control uses one parity bit
and $M$ input moves.  A uniform CHMY transfer additionally must compute
membership in $\operatorname{supp}(v_N)$ by one fixed machine within the
claimed resources.  Existence of a different hardwired tester for each length
is not silently promoted to that uniform statement.

\section*{Theorem: affine dual-stream obstruction}
\textbf{Theorem.}  Let $D=N+d$.  If $E(f,z)=A'f\!z+h$ is any affine map from
$\mathbb F_2^D$ to $\mathbb F_2^M$ and $M>D$, then:
\begin{enumerate}
\item its image obeys a nontrivial public affine parity (1);
\item $E(U_D)$ is uniform on an affine subspace of size
      $2^{\operatorname{rank}(A')}$, and its total-variation distance from
      $U_M$ is $1-2^{\operatorname{rank}(A')-M}$;
\item a one-pass parity test accepts every image point and a uniform $M$-bit
      string with probability $1/2$;
\item avoiding this dimension-forced parity requires $d\ge M-N$ in the best
      case.  Thus when $M\gg N$, affine repair requires essentially target-
      length independent side information.
\end{enumerate}

\textbf{Proof.}  The $M\times D$ linear part $A'$ has rank at most $D<M$.
Hence $\ker((A')^T)$ contains nonzero $v$.  Multiplying the affine definition
by $v^T$ proves (1).  Rank-nullity gives the image size.  Uniform measure on a
set of size $2^r$ has total variation $1-2^{r-M}$ from $U_M$.  A streaming
scanner XORs precisely the selected target bits, retaining one accumulator;
under $U_M$ a nonzero parity is unbiased.  Finally, full row rank $M$ is
possible only if $N+d\ge M$, proving the advice lower bound. \hfill$\Box$

\paragraph{High-dual-distance control.}
The systematic binary $[7,4,3]$ Hamming code has dual minimum distance four.
Every nonzero dual relation in the audited representation has weight four,
yet the forward tester still retains only one XOR accumulator.  High dual
distance increases how many positions contribute, not streaming memory.  It
may affect the uniform generation cost of the support; that cost remains
explicit rather than assumed free.

\section*{Relation to verified prior work}
Bridge34 already proved cancellation for repeated-coordinate public maps.  The
new result strictly generalizes that algebraic obstruction to every public
affine map and to $d$ side-information bits.  It also closes Bridge34's proposed
``high dual distance'' repair at the affine level.  It is consistent with
INJECTIVE-THRESHOLD-BARRIER25: when $M>N+d$, the affine image is necessarily
non-surjective; when an affine map is made full-rank by $d\ge M-N$, the side
information carries the missing target dimension.  SHORT-TAG-KT-CLOSURE31 and
ADAPTIVE-TRANSCRIPT-KT-FIREWALL32 separately explain why a short locally
replayable tag does not create high ordinary KT.

No materially identical affine-expansion theorem was found in the current
repository search.  Older ``dual parity'' occurrences concern Tseitin/proof-
transport assignments, not truth-table length expansion or the $M-N$ side-
information threshold.  The root status is therefore stale only by omission
of this new negative result; its global OPEN conclusion remains correct.

\section*{Hostile controls and barrier audit}
\begin{itemize}
\item An invertible $M=N$ affine map has no forced dual relation, but supplies
      no length expansion and hence no exponent descent by padding.
\item Genuinely nonlinear encoders, source-dependent nonlinear fibers and
      semantic quotients are not ruled out.
\item A nonuniform $v_N$ proves a length-specific distinguisher only.  A
      uniform one-tape consequence requires charged support generation and
      tape composition.
\item The theorem relativizes and is algebraic; it is a construction
      obstruction, not a nonrelativizing separation.  No Natural-Proofs
      circuit lower bound is asserted.
\item COMPACT-HISTORY20 is unchanged: black-box iteration bounds do not imply
      the single $\exists W\,\forall i$ succinct witness for explicit
      transitions.
\end{itemize}
