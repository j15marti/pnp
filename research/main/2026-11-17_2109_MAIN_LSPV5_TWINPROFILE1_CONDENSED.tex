\section{CONSTRUCTION OR PROOF ATTEMPT}
Use the canonical ASCII source $\mathtt{p\ t5\ n\ m}$, exactly $n$ consecutive explicit vertex lines and $m$ lexicographically sorted distinct directed arcs. Malformed input rejects; genuine loops give zero; reciprocal arcs remain legal and have zero solutions. Explicit vertex declarations give $n\le N$ for source length $N$. Define
\[
R(a,b)=[(b-a)\bmod5\in\{1,3\}],\qquad
Z(G)=\sum_{x\in\mathbb Z_5^n}\prod_{u\to v} R(x_u,x_v).
\]
Compute each vertex's complete outgoing and incoming bit rows, grouping equal ordered pairs into classes $C_1,\ldots,C_h$. If $u,v$ share rows, then $u\to v$ is absent because $v\to v$ is absent. Full incoming equality similarly excludes reverse arcs. Equal outgoing rows in one class and equal incoming columns in another prove that all directed interclass arcs are complete or absent. The partition and quotient are exactly reconstructible from the original source in polynomial time.

For each nonempty color support $S\subseteq\mathbb Z_5$ on class $C_i$ of size $m_i$, the number of assignments using exactly $S$ is
\[
\omega(m_i,S)=\sum_{T\subseteq S}(-1)^{|S|-|T|}|T|^{m_i}.
\]
Let $\Phi_{ij}(S_i,S_j)=1$ iff every $a\in S_i,b\in S_j$ satisfies $R(a,b)$, for each directed quotient arc $i\to j$. Exact disjoint partitioning by support yields the identity
\[
Z(G)=\sum_{\varnothing\ne S_1,\ldots,S_h\subseteq\mathbb Z_5}
\left(\prod_i\omega(m_i,S_i)\right)
\left(\prod_{i\to j}\Phi_{ij}(S_i,S_j)\right).
\]
Each original assignment enters exactly one support tuple, and every original edge is checked. If a quotient class participates in an arc, its support has size at most two: fix a color in the opposite endpoint, then every color in the selected support must be among its two in-neighbors or two out-neighbors in the regular five-vertex tournament. An isolated class contributes $5^{m_i}$ directly. Thus at most $15$ supports are needed for each of $q$ nonisolated quotient classes.

\textbf{THEOREM 1 (PROVED/EXACT restricted).} For every canonical source, one uniform deterministic total exact counter has conservative sequential bit-machine time
\[
T(N,q)=O((N+1)^8(1+15^q)),\qquad
S_{\rm peak}=O((N+1)^5)\text{ bits}.
\]
The recursive support enumeration checks all cross-class factors and multiplies onto weights; its branch count is $O(15^q)$. Source reading, quotient discovery and reconstruction, failed candidates, integer bit arithmetic, recursion state and exact output are included. All counts and intermediate nonnegative products are bounded by $5^n$, so require $O(N)$ bits. For every fixed $c$, the computably recognized class $q\le c\log_2(N+2)$ is polynomial-time. Outside that class the same algorithm remains exact, possibly exponential.

\textbf{THEOREM 2 (PROVED/EXACT).} Let $G_{a,b}$ have all edges of a complete bipartite graph oriented from $a$ left to $b$ right vertices, $a,b\ge1$. It has $q=2$ profiles, and
\[
\boxed{Z(G_{a,b})=5(2^a+2^b-2).}
\]
Proof: singleton left supports give $5\cdot2^b$ assignments. Exactly five of the ten unordered pairs of distinct left colors share one common out-neighbor, each giving $2^a-2$ onto left assignments and one right assignment. All larger left supports are impossible. Yet $\operatorname{tw}(K_{a,b})=\tau(K_{a,b})=\min(a,b)$. The balanced $a=b$ family therefore has arbitrarily large treewidth and vertex cover but source-authenticated polynomial-time exact counting. This is not an arbitrary-algorithm lower bound.

Further opposite-answer controls are constant-profile blowups of a transitive triple (exactly five $T_5$ assignments) and of a transitive four-vertex tournament (zero); $T_5$ contains no transitive four-vertex subtournament. Both are antisymmetric originals without reciprocal edges. A directed path has $q=n$ but admits the transfer count $5\cdot2^{n-1}$, so $q$ is an upper-bound parameter, not compulsory work.

\textbf{Matched-oracle obstruction (PROVED/EXACT under declared machine convention).} Fix an efficient universal oracle printer $U^O$ and a superpolynomial time bound $t(n)=n^{\omega(1)}$. Define $R^{t,O}=\{x:K_U^{t,O}(x)\ge |x|-1\}$. For any oracle $O$, an infinite $P^O$ subset of this set is impossible: for arbitrarily large populated lengths keep an $n-d\log n$ prefix of one member and an $O(\log n)$-bit length encoding, then search at most $n^d$ suffixes using the same $P^O$ decider. The fixed polynomial-time oracle printer produces a member in eventually less than $t(n)$ steps from a description shorter than $n-1$.

If a polynomially verified oracle PFCERT covers every $n$-bit endpoint of each $|p|\le n-2$ oracle program running within $t(n)$, and accepts at most TWO distinct $n$-bit labels globally over ALL proofs for each fixed $(n,p)$, define its accepted union $E_n^O$. It is in $NP^O$ and has size at most $2\sum_{\ell=0}^{n-2}2^\ell=2^n-2$. Its infinite complement lies in $R^{t,O}$.
