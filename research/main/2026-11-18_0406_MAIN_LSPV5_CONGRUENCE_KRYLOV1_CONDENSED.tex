\section{CONSTRUCTION OR PROOF ATTEMPT}
\subsection{CoNP-complete supplied observation gate}
Define $\mathsf{CONG}$ as the pairs of Boolean circuits $(F,h)$ with $F:\{0,1\}^n\to\{0,1\}^n$, $h:\{0,1\}^n\to\{0,1\}^k$, such that $\forall x,y$ with $h(x)=h(y)$ the successor observations agree. 
\begin{theorem} $\mathsf{CONG}$ is coNP-complete under polynomial-time many-one reductions even for $k=1$, $h(u,t,b)=b$ and $F$ the identity except on coordinate $b$. \end{theorem}
\begin{proof} A counterexample consists of two explicit states $x,y$ sharing observation but having unequal successor observations, verifiable in polynomial time. For a CNF formula $\varphi(u)$, construct the fully source-encoded circuit $F_\varphi(u,t,b)=(u,t,b\oplus(t\wedge\varphi(u)))$ and $h(u,t,b)=b$. If $\varphi$ is UNSAT then $F$ is identity, hence congruent. If $\varphi(u^*)=1$ then $(u^*,0,0)$ and $(u^*,1,0)$ have identical $h$ but different $h\circ F$. Thus UNSAT reduces to congruence; the extra guard handles tautologies. \end{proof}
A two-valued output interface alone therefore does not make all-fiber congruence verification polynomial. Assuming $P=NP$ may make this decision gate polynomial, but does not establish existence of a useful compact congruence for arbitrary source computations. This negative result relativizes, so it is not a nonrelativizing lower bound.

\subsection{Explicit affine source and canonical observable quotient}
An original authenticated input $S=(n,A,b,C,d,x_0,T)$ fully enumerates $n$ state bits, $n\times n$ Boolean matrix $A$, vector $b$, $k\times n$ output matrix $C$, vector $d$, starting state and binary horizon $T$. Source length $N$ charges all rows/addresses, and $n,k,\log(T+1)\le N$. Its physical semantics is $x_{j+1}=Ax_j+b$, $y_j=Cx_j+d$ over $\mathbb F_2$. Define
\[
\mathcal R=\operatorname{span}_{\mathbb F_2}\{\operatorname{row}(C),\operatorname{row}(CA),\ldots,\operatorname{row}(CA^{n-1})\}.
\]
Compute deterministic RREF basis $H$ by closing current rows under right-multiplication by $A$. Rank grows at most $n$ times. With $r=\operatorname{rank}H$, uniquely compute $B,D,c$ from $HA=BH$, $C=DH$, $c=Hb$. Then $z_j=Hx_j$ obeys $z_{j+1}=Bz_j+c$ and $y_j=Dz_j+d$.
\begin{theorem}[Source-discovered affine endpoint certificate]
For every explicit valid $S$ there is a canonical constructible certificate of $O((r+1)^2(1+\lceil\log_2(T+1)\rceil)+rn+kn)$ bits, polynomial-time verifiable with simultaneous polynomial live space. It establishes initiality, consecution, terminal coverage, and a polynomially evaluable singleton temporal invariant. Globally over \emph{all} accepted proofs for fixed $S$, exactly one $k$-bit terminal output is accepted.
\end{theorem}
\begin{proof}
Let $Q=\begin{bmatrix}B&c\\0&1\end{bmatrix}$, $v_0=(Hx_0,1)^\top$. A witness supplies canonical $H,B,D,c$, the table $Q,Q^2,Q^4,\ldots,Q^{2^{\ell-1}}$ for $\ell=\max(1,\lceil\log_2(T+1)\rceil)$ and $y_T=D\pi_r(Q^Tv_0)+d$. The verifier rederives $H$ from the original source and checks each squaring and claimed output. Initiality and consecution follow from $H(Ax+b)=B(Hx)+c$ for \emph{every} explicit state $x$. The invariant $I(j,z):=[z=\pi_r(Q^jv_0)]$, for $0\le j\le T$, has one state, and membership is computed by binary powering in polynomial source and time-index length. Actual-trajectory coverage follows by induction. Every accepted proof has the same source-derived $H,B,D,c,Q$ and verified powers, hence the same terminal output; no union of sparse descriptors occurs.
\end{proof}
\paragraph{Resource ledger.} Canonical source parsing, including malformed dimensions/bytes, costs $O(N^2)$ bits conservatively. Basis discovery is $O(n^4)$ naive bit operations; verified binary squaring $O((r+1)^3\ell)$; peak work memory is $O(N+(r+1)^2\ell+rn+kn)$ bits plus quadratic scratch. Input, intermediate tables and output are all charged on one deterministic execution. Thus both certificate generation and verification are polynomial in $N$.
\begin{lemma}[Minimal row-space but no compulsory hardness] The discovered $\mathcal R$ is the least right-$A$-closed row space containing $\operatorname{row}(C)$. It can have rank $n$, giving $2^n$ abstract states, while terminal evaluation remains polynomial. \end{lemma}
\begin{proof} Any such space contains all $CA^j$; Cayley--Hamilton bounds the generating powers by $n-1$. A cyclic bit rotation with $C=e_0^\top$ has $n$ independent rows, yet output at time $T$ is simply initial bit at index $T\bmod n$. \end{proof}
Important limit: this source explicitly lists all $n$ state bits and the entire $n\times n$ matrix; $2^n$ possible $n$-bit states are not an \emph{individual} $2^n$-bit live configuration. Arbitrary machines with exponential live tape lengths do not admit free polynomial-row access or expansion. Neither nonlinear adaptive addressing nor general PFCERT follows.

\subsection{Matched-oracle immunity and universal two-output obstruction}
Fix one polynomial-overhead universal oracle machine $U^O$, and use the \emph{same} oracle $O$ for all programs, deciders and verifiers. Set $R_{K^{t,O}}=\{x:K_U^{t,O}(x)\ge |x|-1\}$ for $t(n)=n^{\omega(1)}$. Hirahara's suffix proof relativizes: if an infinite $P^O$ subset exists, retain $n-m$ prefix bits from a member, enumerate $2^m$ suffixes using its polynomial-time $O$-decider, with $m=(c+5)\lceil\log_2 n\rceil$. This produces an $O$-program of length $n-m+2\log n+O(1)<n-1$ in polynomial $O$-time, a contradiction.
Choose the collapsing oracle $O=\mathrm{TQBF}$, for which $P^O=NP^O=\mathrm{PSPACE}$. A hypothetical uniform polynomial oracle verifier that covers every length-$n$ output of each $U^O(p)$ with $|p|\le n-2$ in the stipulated time, yet accepts at most two distinct outputs globally over all witnesses for fixed $(n,p)$, yields $E_n\in NP^O=P^O$ with $|E_n|\le 2(2^{n-1}-1)=2^n-2$. Its $P^O$-decidable infinite complement is contained in $R_{K^{t,O}}$, contradicting immunity. Thus that universal PFCERT schema \emph{cannot hold in the collapsing-oracle world}, a necessary nonrelativizing diagnostic, not an ordinary existence theorem. An algebrization audit remains OPEN.
