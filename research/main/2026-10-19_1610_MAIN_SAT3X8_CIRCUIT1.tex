\section*{Exact Boolean reduction}
A proper clause uses one signed literal each of $x,y,z$; a 3-bit code identifies the unique assignment that falsifies it. Let $c_0,\ldots,c_7\in\{0,\ldots,7\}$ be the clause codes. Then
\[
\operatorname{SAT}(c_0,\ldots,c_7)
\iff \exists v\in\{0,\ldots,7\}\ \forall i\ c_i\ne v.
\]
Since there are eight codes in an eight-element alphabet, this is equivalent to repetition among the codes. Of the $8^8=16{,}777{,}216$ lists, exactly $8!=40{,}320$ are UNSAT. If all eight clauses are promised distinct, the problem is always UNSAT: zero decision gates, with physical tie-low driver unspecified.

\section*{Minimum circuit with precomputed eight-bit clause-presence vector}
Let $p_v=1$ iff a clause with falsifying pattern $v$ occurs. Then
\[
\operatorname{SAT}=\neg\bigwedge_{v=0}^7p_v.
\]
A gate-exact construction uses four first-stage NAND2 gates on consecutive input pairs; two second-stage NOR2 gates combining adjacent pair results; and one final NAND2 gate. Thus $5$ NAND2 + $2$ NOR2 $=7$ gates, with $8$ input bits, one output bit, $14$ gate input terminals, $7$ gate output terminals, $15$ logical driver-to-sink connections including output, $15$ driven nets, max fanout $1$, and depth $3$. Conventional static CMOS uses $4$ MOSFETs per NAND2/NOR2, exactly $28$ MOS in all. Each $p_v$ is essential; a connected fan-in-two DAG involving all eight inputs requires at least seven binary gates. Every binary gate in the declared NAND2/NOR2 library costs at least four devices, establishing both model-specific minima. A custom NAND8 cell gives one gate and sixteen complementary-CMOS devices, at the cost of an eight-element NMOS series stack. Mask preprocessing is excluded.

\section*{Verification}
A dependency-free bit-parallel verifier exhaustively evaluated all $16{,}777{,}216$ legal 24-bit clause-code lists through each of three distinct complete proper-24-bit gate networks; $50{,}331{,}648$ outputs agreed with the independently computed all-permutation UNSAT predicate, with no mismatches. The full 256 presence masks passed. The arbitrary-literal 72-bit circuit was checked against direct SAT on 2,000 seeded complete eight-clause formulas; the independently implemented clause evaluator covered all $6^3=216$ legal ordered triples across all eight assignments. Explicit two-load buffer-netlists were checked against their unbuffered equivalents. A separate independently written primitive-level Verilog parser also checked all 40,320 UNSAT permutations, 4,000 random formula inputs, seven base and four buffered netlists, and exact gate/pin censuses. Main seed 2026101901; independent verifier seed 110820261019.

\section*{Resource firewall}

Logical gate net count differs from physical wirelength, transistor nets or time. All unknown physical resource metrics remain unmeasured.
