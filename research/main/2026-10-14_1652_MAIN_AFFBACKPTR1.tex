\section{CONSTRUCTION OR PROOF ATTEMPT}
Fix an explicit binary source \(S\) of length \(N\), an \(n\le N\)-bit counter \(0\le a\le M=2^n\), a genuine random-access bit tape \(T\in\{0,1\}^M\), and accumulator \(y\). The source explicitly lists XORs of at most \(N\) affine-system indicator predicates for two Boolean functions \(f,g\colon\mathbb F_2^n\to\mathbb F_2\). A fully explicit binary decision tree tests affine bits \(c\cdot a\) and selects either NULL (read zero) or a displayed affine pointer \(h_\lambda(a)=M_\lambda a\oplus b_\lambda\). Its leaf path guard \(G_\lambda(a)\) is an affine linear system. The source parser permits a non-NULL pointer only if \(\forall a\in G_\lambda,\ h_\lambda(a)<a\) in ordinary binary order, and a mandatory read-before-write macrotransition
\[
 y'=y\oplus f(a)\oplus T[h_\lambda(a)],\qquad T'[a]=g(a),\qquad a'=a+1
\]
(with zero read on NULL), no other writes, and no visible scratch feedback. Initially \(y=0,T=0^M,a=0\). At \(a=M\), output \(y\) together with any polynomial list of displayed tape probes. The actual \(2^n\) macrosteps are not claimed polynomial.

\begin{lemma}[Affine backward legality; PROVED/EXACT]
The condition \(\forall a\in G_\lambda,\ h_\lambda(a)<a\) is checkable by at most \(n+1\) binary Gaussian elimination feasibility tests of explicit affine linear systems, in time polynomial in \(N\).
\end{lemma}
\begin{proof}
The forbidden relation \(h(a)\ge a\) is the disjoint union of equality of all \(n\) bits and, for each bit \(i\), equality of all more significant bits together with \(h_i(a)=1,a_i=0\). Each is a system of affine equations in \(a\) because all bits of \(h\) are affine. Conjoin the path guard and reject iff any system is consistent. The decision tree supplies total, deterministic guard coverage syntactically.
\end{proof}

\begin{theorem}[Polynomial canonical source-output certificate; PROVED/EXACT]
For every well-formed source above, there exists a \emph{uniform} deterministic polynomial-time constructor and verifier for a polynomial-length descriptor and the exact terminal output. A conservative bit bound is \(O(N^{10})\) time and \(O(N^4)\) workspace, independent of \(M=2^n\). For each fixed source, the verifier accepts exactly one terminal output across \emph{all} accepted descriptors.
\end{theorem}
\begin{proof}
Every cell \(v<a\) has already been written once to \(g(v)\), so every legal non-NULL read equals \(g(h_\lambda(a))\). Each affine predicate \([A_jv=b_j]\) of \(g\) composed with \(h_\lambda\) and conjoined with \(G_\lambda\) remains an affine-system predicate
\[
 Q_{\lambda j}(a)=G_\lambda(a)\land[A_j(M_\lambda a\oplus b_\lambda)=b_j].
\]
The actual accumulator increment is therefore the XOR of \(f(a)\) and the polynomial explicit list of \(Q_{\lambda j}(a)\). To compute its prefix XOR for \(a'< 2^n+1\), partition \([0,a')\) into at most \(n\) disjoint binary prefix cylinders. Each affine-term/cylinder intersection has \(2^{n-r}\) solutions when consistent with rank \(r\), contributing odd parity iff \(r=n\). Gaussian elimination evaluates every term in polynomial bit time. The symbolic full-tape invariant
\[
 J(a,y,T)=[y=Y(a)]\land[\forall v<a:T[v]=g(v)]\land[\forall v\ge a:T[v]=0]
\]
holds initially, is inductive using the mandatory write and backward guarantee, and implies the computed terminal output. The \emph{description and source-level proof} are polynomial. Membership of arbitrary supplied \(T\) in \(J\) is NOT asserted polynomial. The verifier independently recomputes the one canonical ordered term list, requires the supplied descriptor to match, and compares the output to the one recomputed string. Thus the globally accepted output set has size one, not merely size one per proof.
\end{proof}

\begin{theorem}[Far-back fixed-anchor inductive observer; PROVED/EXACT]
If every non-NULL leaf pointer is a constant anchor from an explicit list \(A\) of at most \(N\) cells, the predicate
\[
 I(a,y,T)=[y=Y(a)]\land\bigwedge_{v\in A\cup B}
 [T[v]=g(v)\ {\rm if}\ v<a,\ {\rm else}\ 0],
\]
where \(B\) are the explicitly listed terminal probes, is inductive on ALL accepted configurations and checkable with at most \(|A|+|B|\le2N\) tape point queries and polynomial bit work, irrespective of the time lag.
\end{theorem}
\begin{proof}
A legal read points to a listed earlier anchor, whose value is correct in every accepted state. Mandatory write at \(a\) adds the correct tracked value if \(a\) is listed, and preserves every other tracked cell. The accumulator update agrees with \(Y(a+1)\). Initiality and terminal coverage follow, and only the listed cells are queried.
\end{proof}

\begin{lemma}[Future-read cut; PROVED/EXACT in point-query membership model]
If at one reachable cut state each cell in a set \(U\) can be flipped individually, with all other supplied state values held fixed, to change the terminal output under the actual deterministic suffix, any exact deterministic point-query membership tester for an initially true, universally inductive, terminal-sound invariant must query ALL the cells of \(U\) on that state.
\end{lemma}
\begin{proof}
Otherwise flip one unqueried cell. The adaptive transcript and acceptance are unchanged. Consecution sends the altered accepted state to a terminal accepted state with a wrong output, contradicting terminal soundness.
\end{proof}

\begin{theorem}[Exponential membership frontier from a linear pointer; PROVED/EXACT]
For every \(n\ge3\), the grammar contains an \(O(n^2)\)-bit source with \(M=2^n\) tape writes and actual terminal output \(0\) for which exact sound inductive full-configuration membership requires at least \(M/4=2^{n-2}\) point queries on the reachable state at clock \(M/2\).
\end{theorem}
\begin{proof}
Take \(f=g=0\). At even clocks use NULL; at odd \(a\) read \(T[\lfloor a/2\rfloor]\). Binary right shift is an \(\mathbb F_2\)-linear map and on odd \(a\ge1\) points backward. At cut \(A=M/2\), the set \(U=[M/4,M/2)\) was written but not read. Each \(v\in U\) is read precisely once in the remaining suffix at \(a=2v+1\), never overwritten. Flipping any such tape bit flips the terminal accumulator. Apply the preceding lemma. Nevertheless the source knows \(g=0\) and immediately certifies terminal output 0. The query bound is NOT a SAT, circuit, arbitrary-algorithm, or witness-finding lower bound.
\end{proof}
