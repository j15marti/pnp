\section{Exact obstruction and four falsifiers}
The obstruction is acquisition: the combined cofactor-XOR boundary is positive exactly when a valid canonical original is SAT, but neither its cardinality nor a short checker finds an edge. I tested:
\begin{enumerate}
\item all $n$ miter circuits or the total boundary count must be materialized before one boundary certificate can be checked;
\item a boundary certificate is asymptotically smaller than an explicit SAT witness;
\item zero cofactor boundary remains an UNSAT certificate after coherent original-variable pins; and
\item an exponential number of boundary edges implies arbitrary-decider SAT hardness.
\end{enumerate}
The first is falsified by the paid source transform below; the second is false for explicit encodings, since both records have $n+O(\log n)$ bits; the third is falsified exhaustively by constant-true F9 residuals; the fourth was already falsified by authenticated easy $G_6^t$ and is independently preserved here. None supplies a cheaper all-input decision algorithm.

\section{Paid boundary-certificate equivalence}
Let $F$ be a valid proper duplicate-free D\"ocker monotone 3-SAT-(2,2) original on $n$ numbered original variables and $m=4n/3$ source clauses. For a satisfying original assignment $a$, let $P_F(a)$ be the set of variables whose one-bit flip falsifies $F$. Let
\[
 M_i(z)=F(z,x_i=0)\oplus F(z,x_i=1)
\]
be the exact forward/reverse cofactor-difference miter on the remaining original names.

\begin{theorem}[source-local certificate bijection]
The map $(a,i)\mapsto(i,a\setminus i)$ is a bijection from pairs with $F(a)=1$ and $i\in P_F(a)$ to satisfying inputs of the disjoint union of the $M_i$. Given $a$, one complete original-source scan marks exactly $P_F(a)$: mark the unique true variable of every source clause having exactly one true literal. Given a satisfying miter input $(i,z)$, two original-source evaluations select the unique satisfying endpoint. Either direction costs $O(N)$ word work after ordinary input acquisition and $O(n)$ explicit certificate/output bits; emitting all marked certificates costs $O(N+|P_F(a)|n)$ bits/work.
\end{theorem}
\begin{proof}
Flipping $x_i$ can falsify a clause exactly when $x_i$ was that clause's unique true literal, so the source marks equal the pivotal variables. For fixed $(i,z)$, $M_i(z)=1$ exactly when the two endpoints differ, and exactly one is satisfying. These operations preserve the original variable and clause identities; no Tseitin or residual is called canonical.
\end{proof}

For completeness, if $N_r(a)$ counts source clauses with $r$ true literals, then
\[
 N_1+N_2+N_3=m,\qquad N_1+2N_2+3N_3=2n=3m/2,
\]
so $N_1-N_3=m/2$ and $N_1\ge 2n/3$. Each original variable has exactly two true signed occurrences under $a$, hence uniquely satisfies at most two clauses and $|P_F(a)|\ge n/3$. This independently reproduces the GATE292 fragility step used by LSPV-1 COFACTOR-SENSITIVITY-CIRCUIT324. It proves an evaluation-function fact, not necessary SAT-decision work.

\begin{corollary}[nonheredity under pins]
At the canonical root, boundary positivity is equivalent to SAT. For a pinned residual $F|p$, zero boundary says only that its remaining Boolean function is constant; it may be constant zero (UNSAT) or constant one (SAT). Therefore root decision equivalence does not imply continuation equivalence or a hereditary boundary test.
\end{corollary}

\section{Full charge and exact gap}
Let $W(F)$ denote the unknown fully charged work used by any policy to discover a SAT witness or a miter witness. The theorem only gives
\[
 T_{\rm cert}(F)\le W(F)+c_1N+c_2n,
 \qquad S_{\rm cert}(F)\le S_W(F)+O(n+\log N),
\]
for one checked certificate. It does not bound $W(F)$. A controller recurrence must still include grammar validation, representation acquisition, every failed selector and switch, source/index/head reads, circuit/OBDD construction, semantic comparison, proof/GE/SCC work, cache/replay, child and output-bit access, all guest DELAY/COPY/RECOMP work, and simultaneous ancestor plus guest peak space. In schematic form,
\[
T_D(s)=A(s)+\sum_{j\in\mathrm{tried}(s)}(Q_j(s)+F_j(s))+\sum_{c\in\mathrm{children}(s)}T_D(c),
\]
with proof checking/output charged, while peak space is the maximum simultaneous live sum, not the sum of serialized minima. This run supplies no polynomial potential bounding that recurrence.

The exact gap is discovery/absence: checking a found boundary edge is linearly interconvertible with checking a found SAT witness, but finding either or proving none exists remains the original problem. A decision machine need not recover or store either certificate. Large boundary cardinality, the one-bit output, the 35/52 finite benchmarks, after-answer constant circuits, or fixed-order width therefore prove neither easy decision nor universal hardness.
