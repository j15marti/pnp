\section{Fixed-dictionary theorem}
For a source $F$, let $I(F)$ be its vertex-colored incidence graph.  Variable
vertices and positive/negative clause vertices have distinct colors; a clause
is adjacent to its three variables.  On the target grammar, variable degree is
four and clause degree is three.  Thus $I(F)$ has maximum degree four.  Clause
and literal order are absent from this graph, while sign is preserved by the
clause color.

\begin{theorem}[Proof-carrying component canonicalization escape]
Fix a finite dictionary $\mathcal D$ of connected valid canonical originals.
For every $D\in\mathcal D$, fix either a checked satisfying assignment or a
checked complete UNSAT certificate.  The language consisting of valid sources
whose primal connected components are variable-renamed copies of dictionary
members is decidable in polynomial total source work.  This holds under
arbitrary variable renaming and arbitrary clause, literal, and component
ordering.  If all components are SAT, the transported component witnesses form
a checked witness for the original source; if any component is UNSAT, its
certificate plus conjunction provenance proves the whole source UNSAT.
\end{theorem}
\begin{proof}
Strict parsing, duplicate checking and the exact occurrence quotas are
polynomial.  Build primal connected components.  For each component $C$ and
each fixed $D\in\mathcal D$, test color-preserving isomorphism of $I(C)$ and
$I(D)$.  The graphs have maximum degree four, so Luks's bounded-valence graph
isomorphism theorem gives polynomial time \cite{luks1982}.  Equivalently, since
the dictionary is fixed, exhaustive bijections against each fixed template
have a constant exponent and hence are polynomial in the source length.

An accepted isomorphism transports a stored SAT witness to the component and
is checked against every original clause.  A stored UNSAT certificate is
checked once for the fixed template; isomorphism preserves every clause and
therefore transports soundness.  Disjoint primal components share no variable,
so the conjunction is SAT exactly when each component is SAT.  Failure to
match any component returns UNRESOLVED to the exact fallback rather than a
guessed label.
\end{proof}

The fixed-dictionary theorem strengthens REFEREE289 from one declared
serialization to an isomorphism closure with both SAT and UNSAT components.
GATE331 already identified the SAT-only F9 component-recognition escape; the
new increment is the general proof-carrying both-label theorem.  It is not an
all-input SAT algorithm.

\section{Fully charged recurrence, space, and exact gap}
For parser $P$, component builder $K$, isomorphism guest $G$, certificate
checking $Q$, output $O$, and exact fallback $A$, the decision recurrence is
\[
 T(F)=T_P+T_K+
 \sum_{C\in\mathrm{cc}(F)}\sum_{D\in\mathcal D}T_G(C,D)
 +T_Q+T_O+
 \mathbf 1[\text{unknown component}]\bigl(T_A+T_{\rm failed/access/guest/out}\bigr).
\]
The inner dictionary loop may stop after the first match, but the displayed
sum is a safe total-work charge.  Grammar, duplicate tables, source and
index/head reads, component discovery, every failed match, map acquisition,
certificate checking, transported output, cache keys, and fallback work are
paid.  There is no free SAT label, best order, continuation-equivalence oracle,
or semantic representative.

Peak writable space is the maximum simultaneous live parser state,
incidence/primal index, one isomorphism guest, certificate map, output buffer,
cache, and any fallback guest.  COPY materializes and charges a component;
RECOMP rereads and recomputes it; DELAY retains the guest and charges its live
space.  XOR tracing is offline only.  A streaming implementation may reduce
some materialization, but no such saving is assumed here.

The after-answer constant 0/1 circuit is irrelevant.  Likewise, the 35-gate
F9 evaluator, 52-node best-order OBDD, fixed-order exponential family, or
source-recognition escape proves neither general SAT ease nor hardness.

\textbf{Exact gap.}  There is no polynomial-total-work algorithm for sources
