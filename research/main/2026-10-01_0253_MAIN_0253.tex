\section*{PROVED/EXACT}
Let
\[ M=1+m+\binom m2,\qquad \rho(H)=\dim_{\mathbb F_2}\operatorname{span}\{1,x_i|_H,x_ix_j|_H\}. \]

\paragraph{New affine-block obstruction from LSPV-2.}
If \(H\subseteq\mathbb F_2^m\) contains an affine subspace \(A=a+S\) of affine dimension \(r\), then
\[ \boxed{\rho(H)\ge 1+r+\binom r2.} \]
Restriction to \(A\) contains the degree-at-most-two Boolean functions \(1,z_i,z_i z_j\), which are linearly independent by uniqueness of algebraic normal form. Consequently any coefficient-strong claim \(\rho(H)\le Cm\) forces
\[ \boxed{r\le \left\lfloor\frac{-1+\sqrt{1+8(Cm-1)}}{2}\right\rfloor.} \]
Thus one legal SAME\_REALIZATION affine block with \(r=\omega(\sqrt m)\) falsifies every fixed-coefficient \(O(m)\) product-span theorem for that realization; \(r=\Omega(m)\) forces \(\rho(H)=\Omega(m^2)\); and \(r=m\) forces \(\rho(H)=M\) and zero global quadratic kernel. This bypasses accepted-proof multiplicity and collision-entropy premises entirely.

\paragraph{Exact shortening lift criterion.}
For a linear code \(C\subseteq\mathbb F_q^N\), shortened coordinate set \(J\), \(Z_J=\{v:v|_J=0\}\), \(K=C\cap Z_J\), and puncturing \(P_J\),
\[ S_J(C)=P_J(K),\qquad S_J(C)^{\star2}=P_J(K^{\star2}), \]
whereas \(S_J(C^{\star2})=P_J(C^{\star2}\cap Z_J)\). Therefore
\[ \boxed{S_J(C)^{\star2}=S_J(C^{\star2})} \]
if and only if
\[ \boxed{C^{\star2}\cap Z_J\subseteq K^{\star2}+V_J,}\qquad V_J=\ker P_J. \]
This is the exact lifting test needed before a shortening-based rank defect can be promoted to a global SAME\_REALIZATION relation.
