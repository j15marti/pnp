\section{Obstruction and four falsifiers}
Exact continuation equality can be coNP-hard even when sibling cofactors have equal model counts and equal anonymous profiles. The missing quantifier is necessity: a correct SAT decider need not acquire equality. I tested:
\begin{enumerate}
\item coNP-hard sibling equality adds independent mandatory work beyond deciding one sibling on the reduction family;
\item equal counts and anonymous profiles justify merging the siblings;
\item deciding both siblings requires an exact continuation-equality or dominance query; and
\item the disjoint promise construction yields a connected or all-input SAT lower bound.
\end{enumerate}
Items 1 and 3 are falsified by the exact duality below; item 2 is already false on the SAT side; item 4 is false because the reduction is source-disconnected and recognized. None of this makes its arbitrary canonical factor $G$ easy.

\section{Exact cofactor-equality duality}
Let $Z_6$ be the valid canonical original with positive supports $123,145,246,356$ and their four exact negative twins. Write $h_b=Z_6|z_1=b$. Direct source truth gives
\[
|h_0|=|h_1|=9,\quad |h_0\cap h_1|=4,
\quad |h_0\setminus h_1|=|h_1\setminus h_0|=5.
\]
Thus $h_0,h_1$ are nonempty and incomparable.

For any valid canonical original $G(y)$ on disjoint original names form the same valid canonical source
\[
F_G(y,z)=G(y)\land Z_6(z),\qquad f_b=F_G|z_1=b=G\land h_b.
\]

\begin{theorem}[current-label/equality duality]
For both $b\in\{0,1\}$,
\[
\operatorname{SAT}(f_b)\Longleftrightarrow\operatorname{SAT}(G),
\]
while
\[
f_0=f_1\Longleftrightarrow(f_0\Rightarrow f_1)Longleftrightarrow
(f_1\Rightarrow f_0)\Longleftrightarrow G\text{ is UNSAT}.
\]
Therefore on this promise exact sibling equality and either exact dominance direction are precisely the complement of either sibling's current SAT label. They are coNP-hard, but are not an additional necessary computation after that decision bit has been obtained.
\end{theorem}
\begin{proof}
If $G$ has a model, combine it with any of the nine models of $h_b$, so both siblings are SAT. The fixed five witnesses in each directional difference of $h_0,h_1$ combine with any $G$ model, so neither implication nor equality holds. If $G$ is UNSAT, both sibling functions are identically zero; equality and both implications hold. This also gives $|f_0|=|f_1|=9|G|$, shared models $4|G|$, and five-times-$|G|$ models in each directional difference.
\end{proof}
