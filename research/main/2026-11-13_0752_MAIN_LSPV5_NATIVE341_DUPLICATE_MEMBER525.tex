\section{Target claim and falsifiers}
\textbf{Target claim.}  The archived \texttt{/341} verifier authenticates typed source and proof
identifiers after parsing, but does not authenticate the raw JSON member sequence.  Its concrete
accepted-byte language therefore includes duplicate decoded member names whose earlier values
are discarded by \texttt{JSON.parse}.

The claim would be falsified if (i) duplicate source/proof/deletion members were rejected before
proof checking; (ii) reversing the two occurrences did not change disposition; (iii) the checker
authenticated member multiplicity from the raw bytes; or (iv) an accepted duplicate changed the
parsed proof, reported cost, or result rather than only unauthenticated raw provenance.

\section{Theorem and proof}
Let $P$ be ECMAScript \texttt{JSON.parse} and $V$ the archived verifier body.  The checker computes
$V(P(b))$ for raw bytes $b$ and never retains the raw member sequence.  Hence
\[
  P(b_1)=P(b_2)\quad\Longrightarrow\quad V(P(b_1))=V(P(b_2)).
\]
For duplicate decoded member names, the runtime retains the last value.  Thus any forged-first,
valid-last packet in the replay is in the historical accepted-byte language, while its reverse is
checked with the forged value.  The OS replays establish that all eight chosen mutations reach
exactly those two cases.  This proves the stated quotient property for the archived source and the
listed packets.

\section{Concrete semantics, abstraction, cost, and CEGAR}
Any source-authenticated concrete semantics must begin with the raw byte string and include the
deterministic parse transition $b\mapsto P(b)$.  A parsed-object abstraction is sound only if it
explicitly quotients every byte string in $P^{-1}(o)$ to object $o$; it cannot later claim to have
authenticated discarded member occurrences.  Logical work and the accepted result are unchanged
in the eight accepted packets, so this is not a zero-logical-cost proof shortcut.  Physical parsing
and an optional uniqueness scan still consume resources and must be charged by any machine-level
model.

CEGAR was applied correctly: every cheap abstract hostile path was concretely replayed in the
authoritative checker.  The paths are genuine and therefore may not be refined away.  A recursive
unique-decoded-member scan is a valid repaired front end, including escaped aliases, but it defines
a new versioned grammar; it does not rewrite the historical accepted-byte calculus.

\section{Scope and proof-chain classification}
This run establishes a failure of the proposed strong P2-D1 claim that every accepted raw byte is
source/provenance authenticated.  It does not show semantic unsoundness of the parsed proof, does
not produce a cheaper native refutation, and leaves P2-C3 and P2-B1 \textbf{OPEN}.  P2-B2/B3 remain
separate and unsupported.  No hard-family lower-bound test is justified from this parser result.
