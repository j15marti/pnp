\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Encoded source and physical semantics.} Let $N$ be the authentic source size. It includes unary $n$, target $q$, XOR masks $D$, a sparse explicitly readable initial tape, $Q$ controller modes with polynomial-size source circuits, initial controller and binary time $T$. The physical tape has $M=2^n$ writable bits. Define $H=\operatorname{span}_{\mathbb F_2}(D)$ and $S=q\oplus H$, $s=|S|\le a\log_2(N+2)$, $z=\pi_S(x)$. Mode $c$ has odd $u_c\in\mathbb Z_M$, $v_c\in\mathbb Z_M$, offset circuit $\delta_c(z)$, read mask $d_c\in H$, write circuit $w_c$, and controller-update circuit $g_c$. At physical time $t$:
\[
a_t=(u_ct+v_c+\delta_c(z))\bmod M,\qquad
x'_{a_t}=w_c(z,x_{a_t},x_{a_t\oplus d_c}).
\]
If $a_t\in S$, $c'=g_c(z)$; otherwise $c'=c$. Only the written bit changes. This source-authenticated conditional update is part of the restricted original grammar, not a theorem about arbitrary source programs. All source parsing, bit addresses, clock and original machine actions must be charged.
\begin{lemma}[All-state source projection]
For every full physical tape $x$, controller $c$, and clock phase $t\bmod M$, the next $(c,\pi_S(x))$ depends only on $(c,\pi_S(x),t\bmod M)$. If $a_t\notin S$ both the controller and all monitored bits stay unchanged.
\end{lemma}
\noindent\emph{Proof.} If $a_t\in S$, then $a_t\oplus d_c\in S$ because $d_c\in H$; the write and new controller read only $z$. Otherwise the only written bit lies outside $S$ and the event gate holds $c$ fixed. This is all-fiber consecution for reachable and unreachable configurations. \(\square\)
\begin{lemma}[Feedback-event enumeration]
Let
\[
\mathcal E=\left\{u_c^{-1}(b-v_c-\delta_c(z))\bmod M:
c\in[Q],z\in\{0,1\}^s,b\in S\right\}.
\]
Then $E=|\mathcal E|\le\min(M,Qs2^s)$. For all full machine states, phases outside $\mathcal E$ leave $(c,z)$ unchanged; for each $e\in\mathcal E$, the exact projected event map $\Psi_e$ repeats with period $M$.
\end{lemma}
\noindent\emph{Proof.} $u_c$ is invertible modulo $2^n$. An actual $S$-write necessarily satisfies one of the displayed congruences. Enumerating all $(c,z,b)$ includes every possible adaptive address, not just one guessed trajectory. The equations and source transition depend on the clock only modulo $M$. \(\square\)
\begin{theorem}[Polynomial-time authentic endpoint certificate, restricted]
Fix $a$. For every valid source of size $N$ satisfying the grammar and $s\le a\log_2(N+2)$, a uniform deterministic constructor and verifier output the exact terminal physical cell $x_T[q]$ in polynomial time, even if $T$ and the physical tape have exponential magnitude. Set $B=Q2^s$, $L=\lceil\log_2(T+2)\rceil$. One full certificate occupies
\[
O\bigl(N+E(n+\log(Q+2))+B(s+\log(Q+2))(L+1)\bigr)\text{ bits}.
\]
Conservative same-realization bit time is $\operatorname{poly}(N)+O(BE\operatorname{poly}(N)+BL\operatorname{poly}(N))$ and peak stored certificate/working bits $O(N+En+BL(s+\log(Q+2)))$.
Every accepted proof for one original source yields \emph{exactly one globally consistent output bit}.
\end{theorem}
\noindent\emph{Proof.} Discover $S$ and $\mathcal E$ from the complete original bytes, checking all typing and the size gate. Tabulate the one-period function $P=\Psi_{e_E}\circ\cdots\circ\Psi_{e_1}$ on all $B$ controller/data states. Write $T=kM+r$. Compute and independently verify every function square $P^{2^i}$, apply the binary bits of $k$ to the source-derived $(c_0,z_0)$, then the exact event prefix $\{e<r\}$. The all-state projection lemma proves initiality, consecution and terminal coverage for all physical tapes, even with $2^n$ live bits. The verifier recomputes canonical events, entire period table, all squares, and output; thus any accepted purported alternate proof has the same terminal bit. No existential union of exponentially many separate sparse descriptors is used. Tables cost $B(s+\log Q)$ bits each and $O(L)$ powers. There is no expansion of the physical tape. \(\square\)
\paragraph{Certificate gates.} Length polynomial, initiality source-fixed, all-fiber consecution, terminal coverage, complete polynomial table evaluation, syntactically one output per authenticated source, and output multiplicity one over ALL proofs are established separately. This is NOT a universal sparse envelope on arbitrary $n$-bit outputs. Efficient line access does not claim inexpensive full $2^n$-bit terminal tape expansion.
\paragraph{Necessary counterexample and boundaries.} The rule $x_0\leftarrow x_0\oplus x_1$ with projection $S=\{0\}$ maps states $(1,0)$ and $(1,1)$ (same monitored bit) to different successor monitored bits. Hidden cross-component reads invalidate the lemma. Off-event controller changes also invalidate event skipping. An arbitrary source-defined succinct transition with polynomially many state bits can still demand exponential truth tables. These are barriers to this method, NOT all-algorithm lower bounds. Cheap affine, direct replay, recomputation and factored evaluators remain legal.
\paragraph{Matched-oracle diagnostic.} For the SAME oracle $O$ across $U^O,V^O,P^O,NP^O$, the plain $t(n)=n^{\omega(1)}$ bounded-time randomness set $R_{K^{t,O}}$ is $P^O$-immune: if an infinite $A\in P^O$ contained random strings, hardcode a length $n-C\log n$ prefix of an $A$-string, enumerate polynomially many suffixes with the same oracle $O$, and get a shorter-than-$n-1$ description in time polynomial in $n$, eventually below $t(n)$. If a universal polynomial verifier accepted at most TWO distinct outputs across all proofs per short program $|p|\le n-2$, and covered every actual $n$-bit bounded-time output, the union $E_n$ of accepted outputs has at most $2(2^{n-1}-1)=2^n-2$ strings. Membership in $E_n$ is in $NP^O$. For $O=\mathrm{TQBF}$, $P^O=NP^O$, so its infinite complement is a $P^O$ subset of $R_{K^{t,O}}$, contradiction. This proves a necessary nonrelativization obstacle for UNIVERSAL two-output PFCERT, not existence of such a certificate without oracles. Fixed-PH checking under hypothetical $P=NP$ does not create succinct certificates. Nonalgebrization independently OPEN.
