\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Authenticated source grammar.}
Let the complete source length be $N$. Unary-encode $n\le N$, let $M=2^n$, and explicitly list $Q\ge1$ controller modes, $s\ge1$ distinct $n$-bit target addresses $S=(q_0,\dots,q_{s-1})$, odd $n$-bit slopes $u_c$, offsets $v_c$, an initial controller $c_0$ and target bits $z_0$, a complete controller table $G:[Q]\times\{0,1\}^s\to[Q]$, and full overwrite-bit tables $W:[Q]\times[s]\times\{0,1\}^s\to\{0,1\}$. Hence $B=Q2^s\le N$ by syntactic tabulation. Input parsing rejects incomplete or malformed source records; the rest of the physical $M$-cell tape is implicitly initialized to zero, not supplied as preloaded data. At absolute time $t$ mode $c_t$ selects $a_c(t)=(u_ct+v_c)\bmod M$. If the addressed cell is in $S$, update its bit $j$ by $W(c_t,j,z_t)$, otherwise any source-listed write-only off-target effect is permitted. Set $c_{t+1}=G(c_t,z_t)$ with OLD $z_t$. Neither address selection, controller update, nor target writes read off-target cells. The requested output is one target bit after an $L$-bit binary horizon $T$. All source reads, table entries, indices, modular arithmetic, memory and output are charged.
\begin{lemma}[Static opportunity count]
The set
\[
U=\bigcup_{c\in[Q],j\in[s]}\{(q_j-v_c)u_c^{-1}\bmod M\}
\]
contains at most $Qs$ residues and can be authenticated in polynomial bit time. If $t\bmod M\notin U$, no possible mode writes $S$.
\end{lemma}
\begin{proof}
Each odd $u_c$ is invertible modulo $2^n$, so each mode/address pair supplies exactly one congruence solution modulo $M$. Deduplication cannot increase their number. Outside their union all controller choices address only outside $S$.
\end{proof}
\begin{lemma}[Exact gap jumps]
For each fixed target word $z$, define $G_z(c)=G(c,z)$. A gap of $d$ steps without opportunity residues leaves $z$ unchanged and applies $G_z^d$ to $c$. All maps $G_z^{2^i}$, $0\le i\le n$, have $O(B(n+1))$ entries. Scanning only opportunity residues interleaved with exact controller jumps produces the full $M$-step phase-zero return table $F$ and any $r$-step prefix table $R_r$ on the $B$ projected states.
\end{lemma}
\begin{proof}
Between opportunity residues no physical write touches $S$, and all controller reads depend only on $z$. Therefore the same transition $G_z$ repeats. Binary powering computes each gap in $O(n)$ probes. At an opportunity, the current actual mode decides whether a target write occurs and the original tables uniquely supply its result. This holds for every physical tape with the same $z$, not only reachable states. All mode addresses repeat with period $M$.
\end{proof}
\begin{theorem}[FEEDBACKCRT1, restricted source grammar]
For every source above, every initial $(c_0,z_0)$, binary horizon $T=kM+r$, $0\le r<M$, and designated $q_j\in S$, a uniform deterministic algorithm obtains the exact endpoint
\[
(c_T,z_T)=R_r(F^k(c_0,z_0))
\]
using polynomial total bit time and peak workspace in $N+L$. It emits a polynomial certificate comprising source-authenticated $F^{2^i}$ tables, $R_r$ and endpoint, with length
\[
O\left(N+B(1+L)\lceil\log_2(B+1)\rceil\right).
\]
A uniform polynomial verifier recomputes all rows and squaring identities. Across ALL accepted certificates for a fixed source, $T$ and output target, the set of accepted output bits has cardinality exactly one.
\end{theorem}
\begin{proof}
The lemmas prove all-state source projection, including the exponentially many $n$-bit address phases. At phase zero, $F$ is the exact return; induction on $k$ gives $F^k$. The partial prefix $R_r$ handles arbitrary terminal phase. For each of $B$ projected input states the return computation uses at most $Qs$ explicit event steps plus $O(Qsn)$ controller jump probes, after polynomial event preprocessing. Squaring $B$-entry transition tables $O(L)$ times costs $O(BL)$ lookups and $O(BL\log(B+1))$ proof bits. All integer operations use polynomially many bits. Verification recomputes the canonical tables and the final state. Therefore initiality, all-state consecution, terminal coverage, polynomial evaluation, syntactically certified fixed-source sparsity and GLOBAL one-output multiplicity follow separately. No existential union of alternative descriptors is used. The full $2^n$-cell terminal configuration is not expanded.
\end{proof}
\paragraph{Concrete adaptive feedback.}
For $n=9$, $S=(0,1)$, $Q=2$, $u=(1,3)$, $v=(0,1)$, $G(c,z)=c\oplus z_0\oplus z_1$, and target write $W(c,j,z)=z_j\oplus z_{1-j}\oplus c$, the static opportunity set is exactly $\{0,1,341\}$ despite controller changes at other times. From $(c,z)=(0,(1,0))$ the result after $512$ steps, and after $2^{205}+105$ steps, is $(0,(0,0))$. The general table grammar allows nonlinear data-dependent writes, even though this particular example is affine.
\paragraph{Boundaries.}
If mode/address choice or target write reads an outside hidden bit, two physical tapes with identical projection may have opposite projected next bits. This falsifies the all-fiber quotient immediately. A nonunit slope $u=0$ may cause $M$ target-write opportunities yet a constant overwriter remains trivial. Thus opportunity count and representation growth are not compulsory algorithmic work. DEAD, COPY, DELAY, INTERP, RECOMP, affine, compact evaluator, and disclosed-hash-prefix shortcuts remain legal.
\paragraph{Matched-oracle two-output diagnostic.}
Use the SAME oracle $O$ for a universal oracle machine $U^O$, polynomial verifier $V^O$, $K_U^{t,O}$, and $P^O,NP^O$. Assume a universal polynomial-proof relation covers each actual $n$-bit output of programs $|p|\le n-2$ running within superpolynomial $t(n)$ and accepts at most two distinct outputs for each $(n,p)$ across ALL proofs. Its NP$^O$ union $E_n^O$ has $|E_n^O|\le2(2^{n-1}-1)=2^n-2$. Every string outside the union belongs to the time-bounded random set $R_{K_U^{t,O}}$. If $P^O=NP^O$, the complement is an infinite $P^O$ subset of that immune set. Hirahara's prefix/suffix argument relativizes for the matched oracle: retain $n-C\log n$ bits, encode $n$ in $2\log n+O(1)$ bits, enumerate $n^C$ suffixes using the same oracle decider, and obtain an $n-1$-short description within $t(n)$. Contradiction. For $O=\mathrm{TQBF}$, $P^O=NP^O=\mathrm{PSPACE}$. This rules out a UNIVERSAL RELATIVIZING two-output PFCERT schema in a collapsing world. It DOES NOT construct ordinary universal PFCERT or prove $P\ne NP$. Separate low-degree-extension nonalgebrization remains OPEN; the finite source grammar is not a new nonrelativizing method.
