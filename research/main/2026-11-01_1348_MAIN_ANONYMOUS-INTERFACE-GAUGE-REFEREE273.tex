\section{Anonymous-interface gauge theorem}
Let $M_i$ map interface $i$ to interface $i+1$, and let $P_i$ be a permutation
matrix selecting arbitrary local names for interface $i$, with $P_{t+1}=P_1$.
Define
\[
  \widehat M_i=P_i^{-1}M_iP_{i+1}.
\]
\begin{theorem}[Cyclic interface gauge invariance]
\[
 \prod_{i=1}^{t}\widehat M_i
   =P_1^{-1}\left(\prod_{i=1}^{t}M_i\right)P_1,
 \qquad
 \operatorname{tr}\prod_i\widehat M_i
   =\operatorname{tr}\prod_iM_i.
\]
The same trace is obtained from any cyclic rotation and from reversal accompanied
by transposition of every local matrix.  Over the Boolean semiring, diagonal
nonemptiness---the cyclic decision label---is invariant as well.
\end{theorem}
\begin{proof}
Adjacent $P_{i+1}P_{i+1}^{-1}$ factors cancel, leaving only conjugation by
$P_1$.  Trace is similarity invariant over a commutative semiring.  Cyclic
rotation follows from $\operatorname{tr}(AB)=\operatorname{tr}(BA)$, and
\(
\operatorname{tr}(M_t^{T}\cdots M_1^{T})
=\operatorname{tr}((M_1\cdots M_t)^T)
=\operatorname{tr}(M_1\cdots M_t).
\)
Permutation matrices preserve Boolean diagonal reachability, so the same proof
applies to decision support.
\end{proof}

Thus a traversal may retain only a current physical interface identifier, a local
two-state naming, and a $2\times2$ accumulator.  It need not recover a canonical
block zero, clockwise direction, or globally anchored 0/1 names.  This is a
decision/counting equivalence, not a continuation-equivalence theorem for arbitrary
future edits; semantic cache keys still require the declared continuation scope.
