\section{PROPOSE: one missing lemma and four falsifiable mechanisms}

Construct, for every encoded strict signed exact-(2,2)-3CNF instance and every descendant
used by one fixed total deterministic controller, a polynomial-time discoverable path/tree of
modules whose exact interfaces have logarithmic width and whose residual local constraints
are 2CNF plus \emph{fixed} affine codimension; prove closure, SAT/UNSAT correctness,
reconstruction, and polynomial total work including failed decompositions.  No such coverage
theorem is presently verified.

\begin{enumerate}
\item \textbf{Fixed-codimension repair.}  Replace ARC227's one-parity frontier by the
Arvind--Guruswami deterministic algorithm for 2CNF intersected with an affine subspace of
codimension $e$.  Falsifier: if the cited theorem only handles $e=1$, or hides randomized
access, this extension fails.
\item \textbf{Path-interface composition.}  Enumerate complete boundary assignments, invoke
the fixed-$e$ local decider, and relationally join adjacent bags.  Falsifier: a nonlocal clause
or affine row, an uncharged decomposition search, or an interface exceeding $O(\log N)$.
\item \textbf{Global-rank shortcut.}  Hope that bounded local codimension and small interfaces
bound the global affine codimension.  Falsifier: a connected width-one chain with one
independent affine row per bag.
\item \textbf{Finite portfolio coverage.}  Convert the repair/restart experiments into a
polynomial policy family.  Falsifier: disjoint-product misses, or exponentially many policy
sequences $K^d$ despite a finite action alphabet.
\end{enumerate}

\section{BUILD: a charged local-to-path theorem}

\begin{theorem}[Fixed-codimension path-interface composition]\label{thm:path}
Let an instance be supplied with a path of bags $M_1,\dots,M_k$.  Bag $i$ has variable set
$V_i$, left interface $I_{i-1}$ and right interface $I_i$, where
$V_i\cap V_{i+1}=I_i$, nonadjacent bags are disjoint, and $|I_i|\le w$.  Every constraint is
owned by one bag.  The constraints owned by bag $i$ are a 2CNF $C_i$ and an affine system
$A_i x=b_i$ over $\F$ of codimension at most $e$.  Then satisfiability and a witness can be
decided uniformly and deterministically in
\[
  \operatorname{poly}(N)\sum_{i=1}^k
  2^{|I_{i-1}|+|I_i|}\binom{|V_i|}{\le e}.
\]
In particular, for fixed $e$ and $w=O(\log N)$ the promised class is in P.
\end{theorem}

\begin{proof}
For each bag and each assignment $(\alpha,\beta)$ to
$I_{i-1}\cup I_i$, add the corresponding unit clauses to $C_i$.  Unit clauses preserve the
2CNF form, and the affine system still has codimension at most $e$.  Invoke the deterministic
Arvind--Guruswami algorithm and place $(\alpha,\beta)$ in a relation $R_i$ exactly when the
pinned local instance is satisfiable.  This costs the displayed sum, including all negative
local calls.

Join the relations from left to right: retain a right-interface assignment precisely when it
has a compatible retained predecessor in $R_i$.  Store one predecessor and one local witness
pointer for reconstruction.  If a global witness exists, its bag restrictions produce a path
through these relations.  Conversely, a relation path selects locally satisfying witnesses
that agree on every shared interface; the ownership and intersection hypotheses imply their
union satisfies all global constraints.  The same program performs both directions and is not
given the answer class.  The relation tables have at most $2^{2w}$ entries per bag, so their
construction, joins, storage, and reconstruction are within the stated bound.
\end{proof}

\paragraph{Discovery charge.}
Theorem~\ref{thm:path} is a promise/given-decomposition theorem.  If a decomposition algorithm
runs in polynomial time and certifies every ownership/intersection/codimension condition, its
cost may be added.  Searching exponentially many decompositions, receiving semantic module
answers, or storing a succinct oracle table is not covered.

\begin{lemma}[Local codimension does not bound global codimension]\label{lem:rank}
For every $k\ge1$ there is a connected path instance with interface width one and local affine
codimension one whose displayed global affine system has codimension $k$.
\end{lemma}
\begin{proof}
Use variables $p_i,q_i$ and the independent affine rows $p_i\oplus q_i=0$ for
$i=1,\dots,k$.  Add the 2CNF equalities $q_i\leftrightarrow p_{i+1}$ for $i<k$.
Bag $i<k$ owns its parity row and the equality on $q_i,p_{i+1}$; consecutive bags share only
$p_{i+1}$.  The incidence graph is connected.  The affine rows have pairwise disjoint supports,
so their rank is exactly $k$.  Each bag nevertheless has local affine codimension one, and
Theorem~\ref{thm:path} solves the chain in polynomial time.
\end{proof}
This exact control falsifies the inference ``bounded local $e$ implies bounded global $e$'' and
also shows that large global $e$ by itself does not establish hardness.
