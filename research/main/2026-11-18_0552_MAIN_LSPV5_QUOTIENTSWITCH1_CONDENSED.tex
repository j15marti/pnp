\section{CONSTRUCTION OR PROOF ATTEMPT}
For each explicit source $S$ of length $L$, specify $m\le L$ bit state $x$, $r\le c\log_2(L+2)$ quotient $y=Hx$ for binary $r$-by-$m$ matrix $H$, affine modes $(A_b,a_b)$, witnesses $(B_b,d_b)$, arbitrary Boolean guard circuit $g(y)$, and output $Cy+e$. A source parser authenticates guard $g(Hx)$ and output $CHx+e$ and checks
\[HA_b=B_bH,\qquad Ha_b=d_b,\qquad b\in\{0,1\}.\]
The source also includes an initial state $x_0$ and binary-encoded time $T$ of $\ell$ bits.

\begin{theorem}[Nonlinear endogenous quotient and certified endpoint]
Every valid source has unique exact quotient trajectory
\[y_0=Hx_0,\quad y_{t+1}=B_{g(y_t)}y_t+d_{g(y_t)},\quad z_T=Cy_T+e.\]
The exact output $z_T$ can be computed in
\[O(L+rm^2+2^r(r^2+|g|+r)+\operatorname{poly}(\ell,r))\]
time and $O(L+2^r r+\operatorname{poly}(\ell,r))$ space for a single sequential realization. In particular the cost is polynomial in $L$ despite exponential numeric $T$. A deterministic polynomial-time verifier of valid source and proposed label can accept exactly ONE output across ALL proofs, with empty canonical proof.
\end{theorem}
\begin{proof}
By the checked equations, $Hx_{t+1}=HA_{g(Hx_t)}x_t+Ha_{g(Hx_t)}=B_{g(Hx_t)}Hx_t+d_{g(Hx_t)}$. Enumerate at most $2^r$ distinct quotient states until the first repeat. If the preperiod is $\mu$ and period $\lambda$, use index $\mu+(T-\mu)\bmod\lambda$ after the preperiod. All quotient evaluations, matrix authentication, source parsing, memory and binary arithmetic are charged by the bounds above. Because the readout is $Cy_T+e$, accepting only this exact value gives a globally singleton set of accepted labels.
\end{proof}
Nonlinear switching is genuine: $g(u,v)=u\wedge v$ may select between affine maps $F_0(u,v)=(v,u\oplus1)$ and $F_1(u,v)=(u\oplus1,v)$.

\begin{theorem}[PSPACE boundary]
For an explicitly encoded Boolean circuit $F:\{0,1\}^m\to\{0,1\}^m$, explicit $x_0$, binary $T$ and output coordinate $i$, determining $(F^T(x_0))_i$ is PSPACE-complete.
\end{theorem}
\begin{proof}
Membership stores one $m$-bit state, a binary counter and gate workspace. For hardness take any deterministic polynomial-space halting TQBF decider and compile its next-configuration operation into a polynomial-size Boolean circuit $F_w$ on $m=\operatorname{poly}(|w|)$ configuration bits, with absorbing halts. A deterministic halting run never repeats a configuration, so it halts by $2^m$ steps. Binary time $T=2^m$ requires only $m+1$ bits. Thus the output of $F_w^T$ decides TQBF. AND/OR/NOT gates compile to polynomial-work conditional bit assignments.
\end{proof}
A universal polynomial-time exact endpoint algorithm for this unrestricted model implies $P=PSPACE$. Complete sound UNIQUE-output polynomial-verifiable certificates for all instances imply $NP=PSPACE$. The global at-most-two-label constraint is vacuous for single-bit outputs and by itself implies neither collapse. The restricted quotient theorem uses a supplied quotient and explicit polynomial-size state, not an exponentially large free-access work tape, and does not establish any SAT lower bound.
