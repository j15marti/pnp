## Theorem 1: exact selector-serialization isometry

Fix a weighted semantic calculus `S`. A serialized completion `C` is **view-faithful** if every accepted document decodes to an `S` proof DAG with a fixed original source, typed views, dependency hyperedges, and node weights. Suppose completions `C` and `C'` have total translations on accepted documents in both directions that preserve:

- the exact original source bytes;
- the decoded semantic node and view at every reference;
- dependency hyperedges and sharing;
- every node weight.

Then for every UNSAT source `F`,

$$W_C(F)=W_{C'}(F).$$

**Proof.** Translate a minimum `C` proof to `C'`; its weight is unchanged, so `W_{C'}(F)\le W_C(F)`. The reverse translation gives the opposite inequality. The same argument works with infima. If each byte translation has polynomial output length and runtime, their explicit evidence lengths are polynomially related, but this additional fact is not needed for exact paid-node equality. Sharing is preserved, so distinct nodes are not duplicated and span is preserved. QED.

## Theorem 2: paid whole-gate-to-facet LOCAL repair

Define GATE-B+LOCAL precisely: it has the same sound rules and weights as FACET-A except RES cannot directly name a DEF clause facet. A DEF owner exports its exact two-input gate relation to LOCAL, and LOCAL may derive any explicit clause over the gate's three wires that is verified by the constant eight-row implication check, at unit cost.

For each DEF owner in a FACET-A proof, create at most four LOCAL descendants, one per distinct referenced defining clause, and replace every direct facet reference by its shared LOCAL node. All other nodes and edges replay unchanged. Each defining clause is entailed by the gate relation by construction. Global freshness and original source bytes do not change. Therefore, for `d` two-input DEF nodes,

$$q'\le q+4d\le5q.$$

Every affected dependency path gains at most one node; unaffected paths are unchanged. Evidence grows by `O(d log q)` identifier bits plus constant-size clauses. The transform is topological and shares each restored facet globally rather than paying per use.

**Qualification.** This is an exact theorem about the declared GATE-B+LOCAL completion. It does not prove that historical `/341` exported relation bytes have this type. If the DEF relation is private, or LOCAL accepts only a different input/output type, the premise fails.

The exact /436 proof used all four facets five times. The independent transformer inserted four shared LOCAL nodes, producing a 19-node proof with work 19, span 6, 29 clause references, and 1,961 compact JSON bytes. A forged LOCAL clause was rejected.

## Why B3 remains open

If SAT were in P, one could define a Cook--Reckhow-style proof system whose verifier runs the correct polynomial decider and whose UNSAT certificate is trivial. That proves existence of **some** polynomially bounded proof system under the assumption; it does not give an `R_mix341` refutation. Translating that verifier's rejection into the fixed mixed calculus requires a polynomial reflection/correctness proof for the arbitrary decider. Assuming that `R_mix341` p-simulates this induced proof system is precisely the missing fixed-system certificate bound, not an independent bridge. The selector and LOCAL translations begin with an already accepted proof and therefore cannot supply B3.

Consequently:

- no superpolynomial full-mixed `Wbar_Rmix341` is proved;
- no B1 or B2 simulation is proved;
- no noncircular B3 implication is proved or refuted;
- restricted Resolution hardness remains restricted.
