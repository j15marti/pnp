\section{CONSTRUCTION OR PROOF ATTEMPT}
Fix constant $s\ge0$, integers $1\le k\le d$, an initial $2^d$-cell Boolean array $X$ encoded as zero plus at most $N$ explicit XOR initializers, and $k$ loop index bits $u\in\mathbb F_2^k$. A short source contains a scratch-only controller, source-coded Boolean gate DAGs
$A:\mathbb F_2^{k+m}\to\mathbb F_2^d$ and $B:\mathbb F_2^{k+m}\to\mathbb F_2$, and an output circuit $G$. The controller may perform arbitrary nonlinear computation and read protected cells \emph{between} packets. It freezes a snapshot $z$, then a standard RAM loop traverses all $2^k$ indices and executes
\[
a=A(u,z),\qquad X_a\leftarrow X_a\oplus B(u,z).
\]
Its instruction sites are fully inspected; it has no hidden protected writes, dynamic controller entry, self-modification, midloop HALT or live snapshot update. There is no privileged moment-neutrality opcode. This is a syntactically recognizable subset of ordinary programs, not a general semantic analysis.

Define $Q_R(X)=\bigoplus_a X_a \prod_{i\in R}a_i$ for $|R|\le s$. Suppose the Boolean algebraic-normal-form degrees in $u$, for every frozen $z$, satisfy $\deg A_i\le D$ and $\deg B\le e$.

\begin{theorem}[Packet neutrality]
If $e+sD<k$, every complete packet preserves every $Q_R$ for $|R|\le s$, for every initial array, every snapshot, and arbitrary address collisions. Any adaptively chosen sequence of complete packets preserves the moments at all packet boundaries.
\end{theorem}
\begin{proof}
For each moment,
\[
\Delta Q_R=\bigoplus_{u\in\mathbb F_2^k} B(u,z)\prod_{i\in R}A_i(u,z).
\]
The integrand has multilinear degree at most $e+sD<k$. The XOR over the full cube of every degree-less-than-$k$ Boolean polynomial is zero, since a monomial missing any variable has an even number of satisfying assignments. Repeated-address XOR writes cancel correctly. Induct over completed packets.
\end{proof}
The inequality is worst-case sharp. For $k=e+sD$, partition the index bits into $s$ groups of size $D$ and one of size $e$; take the selected address coordinates as the respective group products and $B$ as the final group product. The degree-$s$ moment changes by $\bigoplus_u\prod_{j=1}^k u_j=1$.

\begin{theorem}[Source-grounded bounded-output verifier]
For each fixed $s$, a deterministic verifier parses the full restricted source, checks the only protected update sites and loop completion, recomputes a DAG-based upper bound on each index degree (XOR: maximum; AND: sum; snapshot: zero), and computes the initial moment vector $q^0$ directly from the sparse initializer list. It uses polynomial certificate length and conservative simultaneous bounds
\[
T_V(N)=O_s((N+2)^{s+7}),\qquad S_V(N)=O_s((N+2)^{s+5}).
\]
Every legal public termination outputs $G(q^0,e)$ for one private bit $e$. The verifier accepts $y$ only if $y$ equals one of the source-canonical pair $G(q^0,0),G(q^0,1)$ and the source manifest checks. Globally over \emph{all} accepted proofs, at most two different $y$ exist.
\end{theorem}
\begin{proof}
There are $\sum_{j\le s}\binom dj=O_s(N^s)$ tracked moments. Sparse initialization and syntax-based degree bounds are polynomial. Packet neutrality proves consecution; output grammar proves terminal coverage. Alternative manifests cannot create a third output because the verifier independently computes the same pair from the source. Its cost does not include the physical execution, which can modify $2^{\Theta(N)}$ cells or use exponential scratch memory.
\end{proof}

\begin{theorem}[Complete-loop semantic obstruction]
Given an unrestricted Boolean mask circuit, deciding whether a fixed complete two-write packet preserves global parity for all snapshots is coNP-complete.
\end{theorem}
\begin{proof}
Choose $k=d=1$, addresses $A(0)=0,A(1)=1$, masks $B(0,z)=C(z)$ and $B(1,z)=0$. Both writes execute; parity changes iff $C(z)=1$. Universal preservation is precisely Circuit-UNSAT, a coNP-complete problem. A violating snapshot is a polynomial witness for the complement.
\end{proof}

\paragraph{Matched-oracle diagnostic.}
Let $U^O$ be one efficient universal oracle machine and $t(n)=n^{\omega(1)}$. For every oracle $O$, time-bounded random strings $R_t^O=\{y:K_U^{t,O}(y)\ge |y|-1\}$ form an infinite $P^O$-immune set: from an infinite $P^O$ subset, hardcode an $n-O(\log n)$ prefix and search polynomially many suffixes using the \emph{same oracle} to output a too-shortly described member. With Baker--Gill--Solovay's collapsing oracle $P^O=NP^O$, a universal polynomial $O$-verifier covering every $U^O(p)$ output for $|p|\le n-2$, globally accepting at most two outputs per $p$, yields an NP$^O$ envelope of at most $2(2^{n-1}-1)=2^n-2$ strings. Its infinite P$^O$ complement would lie in $R_t^O$, contradiction. This forbids a universal relativizing PFCERT, not source-specific certificates. POLYMASK1 itself relativizes; no nonalgebrization or cryptographic-hardness argument is supplied.
