\section{CONSTRUCTION OR PROOF ATTEMPT}
Authenticate the entire canonical original byte input containing explicit vertex records and sorted duplicate-free directed arc records. Invalid sources reject. For $R(a,b)=[b-a\bmod5\in\{1,3\}]$, count exactly
\[
Z(G)=\sum_{x\in\mathbb Z_5^n}\prod_{u\to v}R(x_u,x_v).
\]
Merge opposite arcs into a correctly oriented five-by-five factor on each undirected interaction edge, compute the edge-biconnected blocks $\mathcal B$ and their block-articulation forest, then find each block's minimum cover $C_B$ with iterative edge branching and cost $O(\operatorname{poly}(N)2^{|C_B|})$.

\begin{theorem}[Source-to-count; PROVED/EXACT restricted]
For every well-formed original source, one uniform total deterministic counter has simultaneous bit-machine bounds
\[
T(N)=O\left((N+1)^{14}\left(1+\sum_{B\in\mathcal B}5^{\tau_B}\right)\right),\quad
S_{\rm peak}(N)=O((N+1)^6),\quad \tau_B=|C_B|.
\]
It counts correctly even when the parameter is large; every fixed class $\max_B\tau_B=O(\log N)$ is polynomial-time without externally supplied covers or decomposition.
\end{theorem}
\noindent\emph{Proof.} Since $V(B)\setminus C_B$ is independent, condition on its cover labels (at most $5^{\tau_B}$ assignments), then sum each noncover vertex independently through five possible labels, multiplying pair and unary factors. A block's parent-articulation message comprises the five exact conditioned counts; at cut vertices multiply children pointwise, without summing away the shared label until the root. Induction on the block-articulation forest proves exact extension multiplicity, with each original edge and variable counted once. Isolated vertices multiply the count by five. Source parsing, paid cover search, failed branches, graph discovery, factor arithmetic, message retention, integer bit length $O(N)$, and binary output are all charged on one sequential realization. A polynomial simulation of RAM access gives the loose displayed joint exponents. $\square$

\begin{theorem}[No-peel chain and exact infinite series]
Chain $m\ge1$ original directed $K_{3,3}$ blocks (all internal arcs left-to-right) by single right-to-next-left directed bridges. Then
\[
n=6m,\quad |E|=10m-1,\quad \beta=4m,\quad\tau(H)=3m,\quad
\max_B\tau_B=3,\quad|\mathcal B|=2m-1,
\]
and
\[
Z(G_m)=70\,28^{m-1},\qquad\sum_{m\ge1}Z(G_m)z^m=\frac{70z}{1-28z}.
\]
\end{theorem}
\noindent\emph{Proof.} Each $K_{3,3}$ requires three cover vertices, and choosing every block's left triple covers all bridges too. Every vertex has degree at least three and the graph is bipartite, so degree-at-most-two elimination and transitive-triad contraction do not apply. With one left vertex color fixed, the intersection of allowed right colors for its three left colors has sizes 2, 1, 0 in respectively 1, 6, 18 of the 25 other-left assignments. Thus one prescribed left terminal has $2^3+6=14$ block completions, and one block has 70. Each bridge permits two new left-terminal colors and therefore $2\cdot14=28$ completions of the next block. The series follows. This is an exact solution-count series, not a machine-time lower bound. $\square$

\paragraph{Certificate contract.}
For each fixed $c$, a proof lists original source block descriptions and per-block covers of size at most $c\lceil\log_2(N+2)\rceil$, together with an integer $y$. The polynomial-time verifier re-parses the complete source, recomputes and checks all blocks and covers, computes the exact DP count, and accepts iff $y=Z(G)$. Every accepted proof for a fixed source yields the SAME integer, globally one accepted output, not merely per proof. Length, verification and arithmetic are polynomial in $N$ for fixed $c$. Completeness holds only on sources having such small local covers. Universal endpoint coverage for arbitrary machine computations and exponentially large configurations is OPEN.

\paragraph{Matched-oracle barrier.}
Fix one efficient universal oracle TM $U^O$ and use the same oracle $O$ for $K^{t,O}$, all program sources, polynomial verifier and $P^O/NP^O$, where $t(n)=n^{\omega(1)}$. For any $O$, an infinite $P^O$ subset of $R^{t,O}=\{x:K^{t,O}(x)\ge|x|-1\}$ is impossible: save an $n-O(\log n)$-bit prefix of one member at infinitely many lengths and polynomially search all $O(\log n)$-bit suffixes using that SAME oracle; a program of length below $n-1$ prints a member within $t(n)$. Now assume a polynomial $V^O$ with polynomial proofs covers every $t$-time $n$-bit endpoint of every program $|p|\le n-2$ and accepts at most two outputs globally per $p$. Its accepted set $E_n^O$ lies in $NP^O$ and has size $\le2(2^{n-1}-1)=2^n-2$; its infinite complement is contained in $R^{t,O}$. For a BGS oracle $A$ satisfying $P^A=NP^A$, that complement would be an infinite $P^A$ subset of $R^{t,A}$, contradiction. Thus universal two-output PFCERT cannot relativize; no ordinary certificate-existence theorem is inferred. Fixed-PH verification under $P=NP$ does not supply succinctness. No cryptographic hardness or fresh-hash nonrelativization is asserted.
