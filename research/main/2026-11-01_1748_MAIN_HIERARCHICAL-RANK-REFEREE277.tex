\section{Exact obstruction and falsifiers}
LSPV-4 CHECKPOINT-RANK-TARIFF319 uses a one-level block size
$B=\lceil\sqrt{m\log m}\rceil$, yielding about $B$ source probes per requested
prefix rank. The obstruction is whether this square-root tariff is necessary
for exact decision-only access once semantic representatives may be computed
and retained at paid cost. We tested four falsifiers: (i) a two-level static
directory makes the source probes logarithmic; (ii) directory lookup becomes
free on a sequential tape (false); (iii) the resulting space meets the strict
$N^{1/2+o(1)}$ FLMV target (false); and (iv) rank equality alone implies
continuation equivalence for arbitrary future pins and proofs (false).

\section{Two-level exact construction}
Let $w\in\{0,1\}^m$ be the source-authenticated width/tag vector and let
$\operatorname{rank}(j)=\sum_{i<j}w_i$. Put
\[
 L=\lceil\log_2(m+1)\rceil,\qquad S=L^2,\qquad b=L.
\]
At every superblock boundary store its absolute prefix rank in $L$ bits.
At every subblock boundary store the rank relative to its superblock start in
$\lceil\log_2(S+1)\rceil=O(\log\log m)$ bits.

\begin{theorem}
After one $O(m)$ source scan, the two-level directory uses
\[
 O\!\left(\frac{m\log\log m}{\log m}\right)
\]
retained bits. In a random-access directory model, every exact prefix-rank
query uses two counter lookups, at most $L-1=O(\log m)$ source-tag probes, and
$O(\operatorname{polylog}m)$ address/arithmetic work.
\end{theorem}
\begin{proof}
There are $O(m/L^2)$ absolute counters of $L$ bits and $O(m/L)$ relative
counters of $O(\log L)$ bits. Their total size is
$O(m/L)+O(m\log L/L)$. For a query $j$, find its superblock start $s$ and
subblock start $u$. The exact answer is
\[
 G[s]+R[u]+\sum_{i=u}^{j-1}w_i.
\]
The suffix has length below $b=L$. All construction reads and writes are
charged; there is no SAT-label oracle.
\end{proof}

This is the classical kind of multilevel rank directory originating in
succinct data structures, not a novelty claim. It resolves the explicit
multilevel-index alternative left open in project report ARC\_SELECT\_INDEX252.

\section{Current versus continuation equivalence}
Two prefixes with equal length and rank are interchangeable for the declared
current rank query. That is current decision equivalence only. It does not
show that the prefixes induce the same future pins, affine systems, branch
policies, certificates, or child encodings. A semantic cache key must retain
every future-relevant observable or prove a congruence theorem. Discovering,
canonicalizing, validating, and replaying representatives are paid work.

\section{Charged work and remaining gap}
For $q$ rank requests,
\[
\begin{split}
W_D={}&W_{\rm grammar}+W_{\rm source/index/head}+W_{\rm discover}
+W_{\rm build}(m)\\
&+\sum_{r=1}^{q}(W_{\rm select/switch/failed}+W_{\rm address}
+2W_{\rm lookup}+O(\log m)+W_{\rm GE/proof})\\
&+W_{\rm cache/replay}+W_{\rm child/output/access}+W_{\rm guest},
\end{split}
\]
where $W_{\rm build}(m)=\Theta(m)$ source reads plus all counter writes.
Peak space is the sum of co-live parser, directory, address, counter, proof,
cache, ancestor, guest, and output objects.

Three gaps are decisive. First, on a sequential single-head tape, physically
locating a directory counter may itself be linear unless another paid index
and its head motion are specified. Second, for source encoding
$N=\Theta(m\log m)$, the directory is sublinear but
$N^{1-o(1)}$, not $N^{1/2+o(1)}$. Third, static source summaries may require
paid rebuilds for dynamic noncanonical children. Thus no strict numerical
same-machine FLMV transfer, arbitrary-$A\mapsto\Phi(A)$ shortening, or
all-input polynomial SAT controller follows.

\section{Conclusion}
A paid two-level semantic directory reduces exact rank source probes from a
square-root scale to $O(\log m)$ in the declared random-access model. The price
is near-linear retained space and model-dependent lookup. Therefore
CHECKPOINT-RANK-TARIFF319 is not a universal per-output-bit access lower bound,
while the simultaneous all-input FLMV obstruction remains fully open. P
versus NP remains OPEN.
