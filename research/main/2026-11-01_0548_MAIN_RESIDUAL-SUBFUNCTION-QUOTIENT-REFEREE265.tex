\section{Exact obstruction and four falsifiers}
The obstruction is sound sharing in the adaptive certificate DAG.  Two prefixes can have the same currently materialized affine row span and the same unspent ticket budget while their closed sites leave different legal future ticket families.  A cached count, witness, or proof is then not transportable merely because the visible linear summaries agree.

This run tested four falsifiers.
\begin{enumerate}
\item \emph{Lazy selected-row span plus remaining budget is a semantic cache key.}  An authenticated Y6 root/skip pair has the same empty lazy span and budget one, but exact residual model families of sizes six and four.
\item \emph{Coefficient row space alone determines an affine terminal.}  Two Y6 terminals have the same coefficient span $\langle e_1,e_2,e_3\rangle$, yet one is SAT and one UNSAT because their right-hand sides differ.
\item \emph{Present augmented rows alone prove an all-input quotient.}  On all 79 Y6 processed-site states, the committed augmented key happened to have no semantic collision.  This is a finite observation only; the exact theorem also requires the legal future transition/domain and projection maps.
\item \emph{Outside-cycle parity, XOR state distance, or U198/V198 supplies the missing universal ARC/FLMV step.}  F9 refutes parity-only SAT; DELAY/COPY/RECOMP refute XOR-as-total-work; and the large controls do not establish hereditary target closure or numerical FLMV transport.
\end{enumerate}

\section{Residual-subfunction quotient theorem}
Fix an authenticated target source, aligned free source variables $y$, and a certificate-DAG prefix $s$.  Let $\Omega(s)$ be its legal complete ticket descriptions.  Define the exact residual source function
\[
 f_s(y)=1\quad\Longleftrightarrow\quad y\text{ completes the source and belongs to some authenticated }\omega\in\Omega(s).
\]
If complete descriptions carry multiplicity or source-projection information, attach those weights/maps to $f_s$.

\begin{theorem}[Exact semantic quotient]
Equality $f_s=f_t$ on the same aligned variables is a sufficient cache equivalence for SAT decision, exact witnesses, model-family enumeration, and source-valid proof replay.  For \#SAT, equality of the weighted residual functions (including projection multiplicity) is sufficient.  Conversely, unequal residual functions cannot be merged by a cache contract promising preservation of the exact model family, every valid witness, or the exact count.  A cache storing only one scalar SAT/UNSAT answer may use a coarser quotient only when result-equivalence is proved separately.
\end{theorem}
\begin{proof}
If the functions agree pointwise, their satisfying source assignments, emptiness, witnesses, and cardinality agree; proof replay remains sound when its source/provenance map is part of the alignment.  With equal weights, summing values gives the same projected count.  If the functions differ, some aligned source assignment is admitted on exactly one side, so the exact families differ; a witness or count contract can distinguish them.  The final sentence is necessary because two different nonempty functions have the same scalar SAT result even though witnesses and counts need not transport.
\end{proof}

\begin{corollary}[Replayable structural sufficient condition]
Suppose two prefixes have equal current affine solution sets and a bijection between all legal future ticket transitions that preserves row additions, source clause provenance, output projection/multiplicity, and recursively paired successors.  Then their residual functions agree.
\end{corollary}
\begin{proof}
Induct on remaining ticket depth.  At leaves, equal affine solution sets and projection maps give equal residual functions.  At an internal node, the transition bijection pairs equal child functions; taking their authenticated union (or weighted sum when disjointness/multiplicity is certified) preserves equality.
\end{proof}

This is the certificate-DAG analogue of the familiar fixed-order decision-diagram principle: reduced BDD nodes represent identical residual Boolean subfunctions, while ZDDs canonically represent identical set families.  It does not make construction, equality testing, or traversal free.

\]
After processing source site $0$ as default, only profiles $3,4,5,6,7$ remain and the family is
\[
 33,41,42,44.
\]
Neither prefix has selected an overfull ticket, so a lazy selected-row implementation records the same empty augmented span and the same remaining budget one.  Their residual truth-table masks are respectively $22026$ and $5634$.  Thus the lazy key merges unequal residual subfunctions.

The separate right-hand-side falsifier uses profiles $0$ and $1$, both selecting site $0$.  Their exact unit-row coefficient space is $(1,2,4)$ in the fixed four-variable bit layout.  Profile $0$ fixes $(x_1,x_2,x_3)=(1,1,0)$ and has one source model; profile $1$ fixes $(1,0,1)$ and is inconsistent with the other default rows.  Their augmented spans differ.  Hence coefficient rank/space without RHS and provenance is not a SAT certificate key.
