use a multitape query machine with a query tape and query/yes/no states,
and construct a recursive oracle $A$ with $P^A=NP^A$.

extension test for algebrization.

\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Authenticated source.} Complete original source $\sigma$ contains
unary $n$, $M=2^n$, binary $T$, target $q<M$,
a total explicitly tabulated $Q$-state controller
$c_0=0$, $c_{t+1}=g(c_t)$, and for each state $c$ an odd
$n$-bit $u_c$, $n$-bit $v_c,d_c$, and bits
$\alpha_c,\beta_c,\gamma_c$. Initial physical bits are
$x_i(0)=\mathrm{parity}(i\mathbin{\&}m)\oplus b$
for an explicit $n$-bit $m$ and bit $b$. Each RAM-style step computes
\[
a_t=(u_{c_t}t+v_{c_t})\bmod M,\qquad
x_{a_t}\leftarrow
\alpha_{c_t}x_{a_t}\oplus
\beta_{c_t}x_{a_t\oplus d_{c_t}}\oplus\gamma_{c_t}.
\]
All other cells retain their values. Reads use the \emph{old} bits.
This is a source-defined random-access memory model with $n$-bit
addresses; no uncharged multitape Turing-machine head movement is
claimed. Full source parsing/authentication is included, $n,Q=O(N)$.

Let $H=\operatorname{span}_{\mathbb F_2}\{d_c:c<Q\}$,
$S=q\oplus H$, and $s=|S|=2^{\dim H}$. Source-driven XOR elimination
discovers the exact sorted component $S$. Fix a constant $a\ge1$
and certify only when $s\le N^a$; otherwise return NOT\_CERTIFIED.

\begin{lemma}[All-fiber exactness]
For every two complete physical tapes that agree on $S$, one source
step at the same time/controller position leaves their projections
to $S$ equal. The restricted update is affine on $\mathbb F_2^s$.
\end{lemma}
\noindent\emph{Proof.} If $a_t\notin S$ it does not write inside $S$.
If $a_t\in S$, then $a_t\oplus d_c\in S$ since $d_c\in H$.
Thus all reads involved in any write to $S$ are within $S$, for
\emph{all} physical states, reachable or otherwise. \(\square\)

\paragraph{Source-enumerated full chronology.} Traverse the controller's
orbit, obtaining preperiod $\mu<Q$ and period $1\le\lambda\le Q$.
Put $d=\gcd(\lambda,M)$, $J=M/d$, $L=\lambda J$.
For phase $r<\lambda$, let $c=c_{\mu+r}$. For every $z\in S$, the
write-address condition for that phase is
\[
t\equiv\mu+r\pmod\lambda,\quad
t\equiv \tau_{r,z}:=u_c^{-1}(z-v_c)\pmod M.
\]
The generalized CRT yields no event if
$d\nmid\tau_{r,z}-\mu-r$. Otherwise the unique relative offset in
$[0,L)$ is
\[
e_{r,z}
=r+\lambda\left[
\frac{\tau_{r,z}-\mu-r}{d}
\left(\frac{\lambda}{d}\right)^{-1}\!\!\pmod J
\right],
\]
with bracket zero when $J=1$. All preperiod events are enumerated
directly in at most $Q$ steps. Each controller phase and each $z\in S$
contribute at most one event per period, giving at most $\lambda s\le Qs$
event records; each time/index uses $O(n+\log Q)$ bits.

An event gives an affine map $(A,b)$ on $s$ bits, with composition
$(A,b)\circ(C,d)=(AC,Ad+b)$. In increasing event order compose
the period map $P$, and for each $R<L$ let $P_R$ contain only
events with offset $e<R$. For $T\ge\mu$, $B=\lfloor(T-\mu)/L\rfloor$,
$R=(T-\mu)\bmod L$,
\[
x_S(T)=P_R\,P^B\,x_S(\mu).
\]
For $T<\mu$ direct preperiod replay is sufficient.
Binary powering of the affine map uses $O(\log(T+2))$ matrix stages.

\begin{theorem}[Restricted globally unique endpoint certificate]
For fixed $a\ge1$ and every well-formed authenticated $\sigma$
with $s\le N^a$, the true terminal bit $x_q(T)$ has a
uniform polynomial-time-constructible and polynomial-time-verifiable
source-grounded certificate of length
\[
O\!\left(N+Qs(n+\log(Q+1))+s^2\log(T+2)\right).
\]
Initiality, all-state consecution, exact terminal-event coverage,
and every affine squaring identity are checked separately.
All accepted proofs for the same source yield \emph{exactly one}
terminal output globally; no exponentially large union of sparse
descriptor images is used. For $a=2$, conservative sequential
bit-complexity upper bounds are $O((N+1)^{12})$ time and
$O((N+1)^7)$ peak bits.
\end{theorem}
\noindent\emph{Proof.} All-fiber closure follows from the lemma;
controller periodicity and CRT enumerate every nonidentity event
on the component; matrix products and powers compute the unique
endpoint. The verifier checks the entire original source bytes
and independently recomputes all recorded quantities. Hence no
accepted proof can claim a different final bit. Explicit $s\le N^a$,
$Q\le O(N)$ and $\log(T+2)\le O(N)$ make discovery, arithmetic,
source rereads, verification and peak space polynomial.
The $2^n$-cell configuration is never explicitly expanded.
Only \emph{one original physical output bit} is returned;
expanding the full terminal tape may cost $\Omega(2^n)$ bits.
\(\square\)

\paragraph{Genuine cross-cell feedback and falsifiers.}
With $d=2^{n-1}$ the exact target component consists of a pair
$\{q,q\oplus d\}$; recurring affine cross-reads can act as
noncommuting two-bit shears at exponentially spaced physical
times. The CRT list retains the correct order. A separate
single-controller source with $a_t=t\bmod M$ and
$x_a\leftarrow1$ produces an all-ones physical tape
after $T=M$, without needing to expand that tape to certify $x_q$.

When $s\le c\log_2 N$ and the controller remains tape-independent,
nonlinear two-bit writes can instead be handled by complete
$2^s$-state function-table powering. When the controller reads
an outside hidden bit, the all-fiber projection is not necessarily
consecutive; two full states agreeing on target bits can
produce different next target bits. When $H$ has full rank but
every $\beta_c=0$, an ordinary unary last-writer algorithm remains
cheap: large closure cannot establish necessary work. DEAD, COPY,
DELAY, INTERP, RECOMP, affine, and compact-evaluator shortcuts are
all legitimate. A disclosed $k$-bit hash prefix can be searched
after disclosure; freshness/latency is not classical SAT hardness.
No cryptographic assumption is made.

\paragraph{Matched-oracle diagnostic, proved independently.}
Fix a \emph{single oracle} $O$ for the oracle-universal $U^O$,
the polynomial verifier $V^O$, $P^O$, $NP^O$, and plain
time-bounded $K_U^{t,O}$, with $t(n)=n^{\omega(1)}$.
A prefix/suffix proof of Hirahara's Theorem 3.9 works relative
to this same oracle: if infinite $S\in P^O$ were contained
in $R_{K^{t,O}}$, store an $n-C\log n$-bit prefix
of a length-$n$ member and enumerate $n^C$ suffixes
using the fixed $P^O$ decider, obtaining a description shorter
than $n-1$ and runtime eventually less than $t(n)$.
Thus $R_{K^{t,O}}$ is $P^O$-immune.

Suppose a universal relation $V^O(1^n,p,x,\pi)$ accepts,
for every $|p|\le n-2$ whose $U^O(p)$ prints $n$ bits within
$t(n)$ steps, at least one witness for its actual output; and
for each fixed $(n,p)$, there are \emph{at most two distinct
accepted outputs across all proofs}. Let $E_n^O$ be the
NP$^O$-verifiable union of these output images, with proofs
bounded by a fixed polynomial. The number of candidate programs
is $2^{n-1}-1$, hence $|E_n^O|\le2^n-2$.
Every $x\notin E_n^O$ is time-bounded random and the complement
is infinite. In a legitimate collapsing world, e.g.
$O=\mathrm{TQBF}$ with $P^O=NP^O=\mathrm{PSPACE}$,
that complement becomes infinite $P^O$ inside
$R_{K^{t,O}}$, contradiction. Hence the \emph{universal}
two-output schema cannot hold in such a world.
This is a necessary nonrelativization diagnostic, not an
ordinary certificate-existence proof. Fixed-PH verification
under $P=NP$ does not supply certificate existence or a
succinct configuration. Nonalgebrization remains independently OPEN.
