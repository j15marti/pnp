\section{Target, exact language, and literature preflight}
The run attacks one concrete candidate: replace ROOTGLUE1's independent
local-root selection by exact elimination, then test whether the size or arity
of its retained correlations is unavoidable work. The answer is twofold:
exact elimination is sound, but those proposed resource measures are defeated
by a compact, source-visible tree implementation.

Retain ROOTGLUE1's fixed graph language: header \texttt{01011010}, then
$1^n0$ with $n\ge1$, then the $\binom n2$ adjacency bits of a simple labelled
graph in lexicographic pair order; reject every other string. It has
$N=9+n+\binom n2$ bits and $2n$ Boolean witness bits. Its field form is
\[
 C_\Gamma(w)=\bigwedge_v[w_v^3=1]\land
 \bigwedge_{uv\in E(\Gamma)}[(w_u+w_v)^3=1],
 \qquad w_v\in\F_4.
\]
The allowed colors are the three nonzero field elements $\C$. These equations
are proper 3-colouring, with the exact triangle-carrier witness bijection
already specified in ROOTGLUE1. The audit labels the three nonzero field colors by 0, 1, 2; these are
labels, not a permission to use the zero field element. The current code
operates on validated parsed graphs, not a new replacement bit parser; the previous bit parser is retained.

All new quantifiers are uniform: one algorithm works for every declared
finite input and order, and one compiler works for every declared tree.
The input, projected relation, selected boundary assignment and complete
reconstructed witness are the same realization. Arbitrary polynomial
workspace and access to the original input are allowed. Neither an optimal
order nor a compact representation is assumed to arrive for free.

The direct literature is variable/bucket elimination and tree clustering.
Dechter's formulation predates this project \cite{dechter}; Kask, Dechter,
Larrosa and Cozman state their correctness and complexity with an explicit
\emph{tabular representation} convention \cite{kask}. Pages 2 and 4 of that
primary PDF were inspected visually. The present exact rule is an
instantiation, not a new foundational elimination algorithm. Meijer's
3-colouring paper uses removal of degree-below-three vertices as one
preprocessing component \cite{meijer}; this run does not pursue exponential
base improvement. Constraint inference provides an exact model-matched
transfer; a table-size lower bound for arbitrary machines is a failed
transfer. The correlation/circuit distinction below is proved directly.

\section{The exact elimination rule and charged witness return}
Suppose the current conjunction consists of relations $f$ on subsets of the
remaining variables. For the next variable $v$, collect \emph{all} factors
containing $v$ into its bucket $\mathcal B_v$. Write
$S=(\bigcup_{f\in\mathcal B_v}\operatorname{scope}(f))\setminus\{v\}$.
Replace that bucket by
\begin{equation}\label{eq:bucket}
 g_v(s)=\bigvee_{c\in\C}\bigwedge_{f\in\mathcal B_v} f(s,v=c).
\end{equation}
Retain the three-bit support mask
\[
 M_v(s)=\{c\in\C:\text{every }f\in\mathcal B_v
                       \text{ accepts the same }(s,c)\}.
\]
All other factors are left unchanged. Formula \eqref{eq:bucket} is precisely
existential quantification, not separate existential choices for different
factors. Induction proves that after any prefix of the order, the active
conjunction is exactly the projection of the original solution relation.

If the final zero-variable relation accepts, reconstruct in reverse order:
the later variables determine $s$, and choose any color in the stored
$M_v(s)$. By induction the choice satisfies the removed bucket. Recheck the
original graph at the end. Project the resulting field bits to the same
triangle cotree and reconstruct the full Tseitin witness; the code checks
all original incidence equations, not merely the projected color constraints.

\paragraph{Resource ledger.}
For boundary sizes $b_i$, the executable tests exactly
$\sum_i3^{b_i+1}$ color candidates and retains $\sum_i3^{b_i}$ support rows.
Tuple construction, lookups, factor scans, order discovery and verification
are additional work; those counts are not bit-operation counts. A dense-array
implementation gives the familiar $3^{O(w)}\operatorname{poly}(N)$ algorithmic
upper bound, where $w=\max b_i$. Retaining all reconstruction tables has
exponential worst-case space. This is an implemented \emph{particular}
algorithm, not a lower bound against programs allowed polynomial space,
recomputation or compact circuits. Natural, reversed and polynomially computed
min-fill orders are all audited; an optimal order is never supplied free.

\section{First and second projection: information that cannot be discarded}
For a vertex with neighbor colors $a_1,\ldots,a_d$, eliminating that vertex
is equivalent to
\[
 |\{a_1,\ldots,a_d\}|\le2.
\]
An absent third color reconstructs its witness. For $d\le2$ the constraint
is automatic. For $d=3$ it becomes
\[
 R_3(a,b,c)\iff (a=b)\lor(a=c)\lor(b=c).
\]
Over $\F_4$ it can also be written
$(a+b)(a+c)(b+c)=0$. Every two-variable projection of $R_3$ is full, while
$R_3$ rejects the six rainbow tuples. Consequently no conjunction of unary
or binary predicates on just these variables can represent it exactly.
Auxiliary variables or a different representation are not excluded.

Already the next exact projection can leave this ternary family:
\[
 R_4(a,b,c,d)=\exists y\,[R_3(y,a,b)\land y\ne c\land y\ne d].
\]
If $a=b$, the first condition is automatic. If $a\ne b$, it restricts
$y$ to $\{a,b\}$. Hence
\begin{equation}\label{eq:r4}
 R_4(a,b,c,d)\iff
 \neg\bigl[a\ne b\land c\ne d\land\{a,b\}=\{c,d\}\bigr].
\end{equation}
Exactly 69 of the 81 tuples satisfy it. Every three-variable projection is
full: one can always fill the omitted entry to set $a=b$ or $c=d$.
It cannot be represented as a conjunction of predicates on proper subsets
of its four variables, without auxiliaries.

The original gadget is nevertheless just the six-vertex tree with edges
$xa,xb,xy,yc,yd$. Thus required four-way correlation is not even evidence of
a difficult original graph. The complete-graph control $K_4$ is rejected by
the exact bucket algorithm; $K_3$ is accepted and reconstructed. Discarding
the first ternary relation would have lost the contradiction in $K_4$.

\section{An unbounded-arity theorem with a compact algorithm}
Let $T$ be a finite tree whose leaves form $B$, with $b=|B|\ge2$, and every
nonleaf has degree three. Such a tree has $2b-2$ vertices and $2b-3$ edges.
Let
\[
 R_T=\{\alpha\in\C^B:\alpha\text{ extends to a proper 3-colouring of }T\}.
\]
An explicit family for every $b$ is obtained by starting with one edge and
repeatedly subdividing an edge incident to a fixed leaf, adding a new leaf
at the subdivision vertex. The balanced family used in additional tests is
two full binary trees of equal height, with their roots joined.

\begin{theorem}[Maximal projected arity does not force large circuits]
For every such $T$:
\begin{equation}\label{eq:count}
 |R_T|=3^b-3\cdot2^{b-2},\qquad
 \pi_S(R_T)=\C^S\quad\text{for every }S\subsetneq B.
\end{equation}
No conjunction of arbitrary predicates, each on fewer than $b$ boundary
variables and using no auxiliaries, defines $R_T$.
Nevertheless a uniform algorithm constructs a quantifier-free Boolean
circuit of $O(b)$ gates recognizing $R_T$ from its boundary colors. It also
decides extension of partially assigned boundary colors and constructs a
complete coloring with polynomial time and workspace. These claims concern
the original explicit tree and input; no hidden advice is provided.
\end{theorem}
\begin{proof}
Root any full binary subtree at a nonboundary vertex, with its terminal
leaves prescribed. Every subtree has a nonempty feasible-color set at its
root: each of its two children forbids at most one parent color, and two
forbidden colors cannot exhaust a three-color domain. The parent becomes
forced to color $c$ exactly when both children are forced to the other two
colors, in either order.

For a rooted full binary tree with $\ell$ terminal leaves, let $f(c)$ count
leaf assignments forcing its root to $c$. For a one-leaf tree $f(c)=1$.
If its two subtrees have $\ell_1,\ell_2$ leaves, induction yields
\[
 f(c)=2\cdot2^{\ell_1-1}\cdot2^{\ell_2-1}=2^{\ell-1}.
\]
Root $T$ at any boundary leaf $r$. Its neighbor is the root of a full binary
tree with $b-1$ other boundary leaves. A complete boundary assignment fails
exactly when that neighbor is forced to the color prescribed at $r$.
There are three choices for that color and $2^{b-2}$ assignments forcing it,
which proves the first identity in \eqref{eq:count}. For $b=2$ the neighbor
is itself a leaf and the same base case applies.

For the second identity, take an unassigned boundary leaf $r\notin S$ and
root there. The child subtrees have at most two children per internal vertex;
unassigned terminal leaves start with all three colors. The same induction
gives a nonempty feasible set at the neighbor of $r$, and then $r$ can take
any different color. Thus every assignment on $S$ extends.

If $R_T$ were a conjunction of predicates on proper subsets $S_j\subsetneq B$,
each predicate would have to accept every tuple in $\pi_{S_j}(R_T)=\C^{S_j}$.
All factors would be tautologies, contradicting $R_T\ne\C^B$. This proves
only a lower bound on conjunctive factor arity in the specified no-auxiliary
representation.

For the circuit and algorithm, orient the tree from a selected root. For each
vertex and color form the Boolean feasibility bit
\[
 A_v(c)=I_v(c)\land\bigwedge_{u\text{ child of }v}
                 \bigvee_{a\in\C\setminus\{c\}}A_u(a).
\]
At a boundary leaf, $I_v(c)$ is the input bit allowing color $c$; at other
vertices it is constant true. The final answer is $\bigvee_c A_r(c)$.
There are three input bits per boundary vertex, at most six two-input
Boolean gates per tree edge, and two final OR gates. This is a genuine
quantifier-free shared circuit, constructed bottom-up, not a circuit with
an unevaluated existential quantifier. Decode a full boundary color into its
three one-hot bits at constant cost per leaf.

Store the three feasible bits per vertex. Choose a feasible root color and
then a feasible child color different from its parent. The recurrence proves
that such a choice exists. Verify every original edge and supplied boundary
pin. With explicit indices the encoding uses $O(b\log(b+2))$ bits; input
validation, circuit generation, evaluation and reconstruction are polynomial
in encoded length on an ordinary deterministic bit machine. The linear gate
count is not a claim of linear multitape bit runtime or constant program
workspace. Every source read and output bit is charged.
\end{proof}

The proof is complete, but this new project theorem is \textbf{CANDIDATE}
until an independent specialist reviews it. The bucket identity and
small-tree dynamic-programming mechanism are established algorithmic ideas,
not claimed as foundational discoveries.

\section{A second compactness control: the high-degree star}
Eliminating the center of a $d$-leaf star gives the at-most-two-colors relation.
For $d\ge1$ its positive table has $3\cdot2^d-3$ rows. Even quotienting by
all color permutations leaves $2^{d-1}$ accepted equality patterns. Yet one
three-bit occurrence mask checks a boundary tuple in $O(d)$ color reads and
returns an absent color. A Boolean circuit recording the presence of each
of three colors has $O(d)$ gates. The formula using all no-rainbow triples
has only $\binom d3$ factors, also polynomial, rather than exponentially many
rows. A leaf-first elimination order also avoids the large center-first
boundary entirely. None of these alternatives is excluded for arbitrary
SAT deciders.

The trivalent-tree theorem is stronger than this star-order control: its
boundary relation cannot be decomposed into factors of any fixed smaller
arity, but still has a small circuit and an input-assisted witness algorithm.
Thus even essential arity plus a large table does not measure unavoidable
computation. An easy YES family remains easy; a minimal incompatible boundary
pattern is not a common-input satisfiable UWI obstruction.
