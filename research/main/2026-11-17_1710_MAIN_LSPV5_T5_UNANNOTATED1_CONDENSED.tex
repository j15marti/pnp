\section{LITERATURE CHECK AND REVISIONS}
The 17 November 2026 T5CYCLEFLOW1 source report proves the typed-descriptor potential contraction, $W=A^2(A^\top)^2$ weight and $5^\beta$ Fourier counting but explicitly leaves \emph{unannotated discovery} open. We reuse that exact mathematics rather than claiming it is new.
Govorov--Cai--Dyer (JCSS 132, 2023, doi:10.1016/j.jcss.2022.09.002) prove the nonnegative symmetric weighted-homomorphism dichotomy, including bounded-degree simple input graphs. Our strictly positive $W$ below has determinant 16 and is not block rank one, so unrestricted weighted \emph{counting} is \#P-hard.
Hirahara (STOC 2020/ECCC TR20-050, Theorem 3.9) proves P-immunity for superpolynomial time-bounded $K^t$ random strings, not full P-immunity for Levin's $Kt$.
Baker--Gill--Solovay (SICOMP 4(4), 1975, doi:10.1137/0204037) construct a recursive oracle $A$ with $P^A=NP^A$.
CANDIDATE A is repaired to the promise that every genuine core vertex has undirected degree \emph{different from} two; degree-one and isolated originals are allowed. A pure four-path chain with a degree-two middle original is a genuine counterexample to the unrestricted version, so CANDIDATE B remains OPEN. C and the restricted D survive. The hardness firewall strengthens D.

\section{CONSTRUCTION OR PROOF ATTEMPT}
Use colors $\mathbb Z_5$ and directed relation $R(a,b)=[b-a\pmod5\in\{1,3\}]$.
A successor diamond $D(u,v)$ consists of $u\to v$, $u\to h$, $h\to v$ with fresh $h$.
A four-path factor $P(u,v)$ consists of $u\to a$, $a\to b$, $v\to c$, $c\to b$ with fresh and disjoint $a,b,c$.
The unannotated source is a canonical full sorted duplicate-free directed adjacency list with $n$ explicit vertices. The degree-gap class $\mathcal G_{\ne2}$ contains exactly those raw graphs admitting this complete gadget expansion with \emph{every} original vertex of underlying undirected degree not 2 and \emph{every} private interior of degree 2; no descriptor is input.

\begin{theorem}[Unannotated reconstruction]
A uniform polynomial-time source-authenticating algorithm determines the exact gadget decomposition of every $G\in\mathcal G_{\ne2}$ using only its raw directed arcs, and never accepts a graph lacking such a decomposition. In particular, no typed description or free annotation is assumed.
\end{theorem}
\begin{proof}
Compute the underlying simple undirected degree of every vertex and take the original core to be precisely $C=\{v:\deg(v)\ne2\}$. Follow each incident edge from $C$ through the uniquely continued degree-two chain until reaching $C$ again. Reject chains with lengths other than 1,2,4, unvisited edge components, wrong directed orientation, shared interior, or malformed input. Each length-two chain must read $u\to h\to v$ and pair bijectively, including orientation, with one direct core arc $u\to v$. Each length-four chain must read $u\to a\to b\leftarrow c\leftarrow v$ and contributes one independent four-path. Recheck all original directed arcs and all visited edge identities. Any accepted decomposition expands to exactly the source; in a promised graph the degree gap makes every original and interior uniquely identifiable, so none is missed.
\end{proof}
The genuine raw four-path matrix is
\[
 W=A^2(A^\top)^2,\quad W_{u,v}=w(v-u),\quad
 w=(6,1,4,4,1),\quad \sum_v W_{u,v}=16,\quad\det W=16,
\]
where $A_{ab}=R(a,b)$. Every successor diamond has one completion exactly when $x_v-x_u=1\bmod5$.
A charged traversal of these constraints either finds an inconsistent signed cycle (count 0) or gives $q$ successor components with source-derived potentials $h_v$ and free roots $\theta\in\mathbb Z_5^q$. Four-path factors internal to a component multiply to an integer $I$; cross-component factors become weighted edges
$w_e(z)=w(z+h_v-h_u)$ in a quotient multigraph of $q$ vertices, $e$ edges and $\kappa$ connected components. Its exact original count is
\[
 Z(G)=I\sum_{\theta\in\mathbb Z_5^q}
       \prod_{e:a\to b}w_e(\theta_b-\theta_a).
\]
Put $\beta=e-q+\kappa$, and
$\widehat w_e(k)=\sum_{z\in\mathbb Z_5}w_e(z)\zeta^{-kz}$.
Fourier inversion yields
\[
 \boxed{Z(G)= I5^{q-e}\sum_{\substack{k\in\mathbb Z_5^e\\
                              \operatorname{div}k=0}}
                      \prod_{j=1}^{e}\widehat w_j(k_j).}
\]
The incidence kernel has dimension exactly $\beta$, hence exactly $5^\beta$ frequency vectors. Compute the coefficients in the integer ring $\mathbb Z[X]/(X^5-1)$ using cyclic convolution, Galois-symmetric coefficient differences and checked integral division, with no floating-point arithmetic.

\begin{theorem}[Fully discovered bounded-cycle-excess exact count]
For source bitlength $N$ there is one blank-start sequential machine that charges parsing, failed discovery, complete raw-edge matching, source access, quotient construction, GF(5) Gaussian elimination, every frequency and integer multiplication, and output, within simultaneous
\[
 \boxed{T=O((N+1)^8(1+5^\beta)),\quad S_{\mathrm{peak}}=O((N+1)^4).}
\]
Thus whenever $5^\beta\le(N+1)^c$ for one fixed $c$, exact count and decision are uniform polynomial-time with no supplied descriptor. A verifier recomputing this result and accepting only the true count label has exactly one globally accepted label across all proof strings for each source in the promise, even if multiple proof strings are supplied. Outside this restricted class it rejects, rather than silently claiming completeness.
\end{theorem}

\begin{theorem}[Degree amplification by neutral leaf arms]
For \emph{any} explicitly typed private-gadget source $D$ with core $C$, append $p(v)=\max(0,3-\deg_{\rm undir}(v))$ new four-paths from each original $v$ to distinct fresh original leaf endpoints. For $P=\sum_vp(v)\le3|C|$, the resulting raw graph $G'$ is automatically in $\mathcal G_{\ne2}$ and satisfies
\[
 \boxed{Z(G')=16^P Z(G(D)).}
\]
If the successor equations are consistent, the quotient cycle excess is unchanged.
\end{theorem}
\begin{proof}
Each leaf's label and three auxiliaries sum to $\sum_z W_{a,z}=16$ independently of its anchor's label; the factors multiply. The original core degree becomes at least three, new genuine leaves have degree one, and each new private interior degree two. Every added arm contributes one new root component and one weighted edge, so $q$ and $e$ each increase by $P$ while $\kappa$ is unchanged, preserving $\beta$. The construction has charged polynomial output size.
\end{proof}

\begin{theorem}[Hardness firewall on the same unannotated promise]
Unrestricted \emph{exact counting} on $\mathcal G_{\ne2}$ is \#P-hard under polynomial-time counting reductions, even for four-path-only graphs in which every valid source is satisfiable.
\end{theorem}
\begin{proof}
For any simple graph $H$, replace each edge by a private four-path to obtain $Z_W(H)$. Apply degree amplification, obtaining a raw promised $G'$ with $Z(G')=16^PZ_W(H)$, recoverable by known exact division. The strictly positive full-rank symmetric $W$ fails the tractable block-rank-one condition of Govorov--Cai--Dyer, so its partition function is \#P-hard even on bounded-degree simple $H$. No decision hardness follows: the positivity of $W$ guarantees that these padded sources are always satisfiable.
\end{proof}

\begin{theorem}[Matched-oracle two-output obstruction, diagnostic]
For every fixed oracle $O$ and superpolynomial $t(n)=n^{\omega(1)}$, the language of strings $x$ with oracle time-bounded $K_U^{t,O}(x)\ge |x|-1$ is $P^O$-immune under the same efficient universal-oracle-machine convention. Consequently, in a collapsing Baker--Gill--Solovay oracle world $P^A=NP^A$, no polynomial oracle verifier can cover every $n$-bit endpoint of all oracle programs $|p|\le n-2$ halting by $t(n)$ while accepting at most two outputs per $(n,p)$ across all polynomial-size proofs.
\end{theorem}
\begin{proof}
An infinite $P^O$ subset of time-bounded random strings would allow a program hardwiring $n-c\log n$ prefix bits of a member and enumerating $n^c$ suffixes using the same $P^O$ decider, printing an accepted member in polynomial oracle time with fewer than $n-1$ description bits, eventually within $t(n)$. For the certificate contradiction, set $E_n^A=\{y:\exists p,\pi,\ |p|\le n-2,\ V^A(n,p,y,\pi)\}$. It lies in $NP^A=P^A$ and $|E_n^A|\le 2(2^{n-1}-1)=2^n-2$ by global two-output soundness. Its infinite $P^A$ complement contains only time-bounded random strings by coverage, contradicting immunity. This diagnoses a missing nonrelativizing ordinary certificate-existence theorem, not a proof of that theorem. No nonalgebrization or cryptographic hypothesis is claimed.
\end{proof}
