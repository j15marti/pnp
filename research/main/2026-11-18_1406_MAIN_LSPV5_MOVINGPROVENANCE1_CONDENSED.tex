\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Authenticated source.} Length-$N$ bytes unary-encode $1\le n\le N$, $M=2^n$, odd $n$-bit $u$, $n$-bit $v$, $1\le w<M$, $Q$ controller modes and deterministic tables/circuits $W,G$ on $[Q]\times\{0,1\}^w$. Impose the checked $K=Q2^w\le N^a$ promise, for fixed $a$. The physical RAM macrostep $t$ addresses $a_t=ut+v\bmod M$, physically reads actual tape bits at $a_{t-1},\ldots,a_{t-w}$, sets $y_t=W(c_t,\text{read bits})$, changes mode by $G$, and irreversibly overwrites $X_{t+1}(a_t)=y_t$. The length-$M$ tape is initially ALL ZERO. A binary-encoded horizon $T$ and queried terminal address $q$ are supplied.

\begin{lemma}[Exact last-writer provenance on reachable states]
For every $t\ge0$ and $1\le j\le w$ along the unique blank-start physical trajectory,
\[
X_t(a_{t-j})=
\begin{cases}0 & t<j,\\y_{t-j}&t\ge j.\end{cases}
\]
\end{lemma}
\begin{proof}
Since odd $u$ is invertible modulo $M$, addresses are distinct over any window of $M$ consecutive times. Since $j<M$, when $t\ge j$ no step strictly between $t-j$ and $t$ overwrites $a_{t-j}$, which still holds $y_{t-j}$. When $t<j$, this address has not been written since blank initialization. This proves initialization, reachable-domain consecution, the first sweep and every wrap. Arbitrary tapes outside the reachable invariant are not covered.
\end{proof}
\begin{theorem}[Restricted polynomial endpoint certificate]
For every valid source of length $N$ satisfying $K\le N^a$, every binary horizon $T$ with length $L_T$, and every $q\in[M]$, an ordinary deterministic bit machine constructs and verifies an exact endpoint-bit certificate with
\[
O\big(N+n+L_T+K(1+L_T)\lceil\log_2(K+1)\rceil\big)
\]
bits, polynomial total time and simultaneous peak space in $N+L_T$. Globally over ALL accepted certificates for that fixed source, $T$, and $q$, there is EXACTLY ONE accepted output bit.
\end{theorem}
\begin{proof}
Store the controller and last $w$ emitted bits in a $K$-state register. The source defines a unique transition map $F:[K]\to[K]$, independently recomputed on all states. Supply and verify the entire table $F$ and the $O(L_T)$ repeated squaring tables $F^{2^i}$, with every identity $F^{2^{i+1}}=F^{2^i}\circ F^{2^i}$ checked entrywise. The address $q$ has a unique phase $\rho=u^{-1}(q-v)\bmod M$. If $\rho\ge T$ it is still blank. Otherwise the last write occurs at
\[
t_*=\rho+M\lfloor(T-1-\rho)/M\rfloor;
\]
power $F^{t_*}$ on the initial zero register and compute its new write bit. This is the physical tape's exact terminal $X_T(q)$ by the lemma. Every accepted label is forced by recomputation of exact authenticated source bytes, the full table, all squares and the final index, so global multiplicity is one. Parsing, modular arithmetic, table construction, checking, table lookups, retention and output are all polynomial, with no physical tape expansion.
\end{proof}
\paragraph{Genuinely nonlinear two-point feedback.} Take $w=2$, $Q=2$, $u=3$, $W(c,b_1,b_2)=1\oplus b_1\oplus(c\land b_2)$, $G(c,b_1,b_2)=c\oplus b_1$. Actual physical reads change on every sweep. The first twelve emitted bits are $1,0,0,1,0,1,0,0,1,0,1,0$. The maintained register has eight states even though the actual physical tape has $2^n$ cells and the queried address is arbitrary.
\paragraph{Falsified unrestricted mode switching.} Writing address 0 with 1 at step 0, rewriting it to 0 at step 1 and attempting a lag-two read at step 2 yields actual bit 0, not the stale buffer bit 1. Individually odd slopes cannot prevent this cross-mode collision.
\paragraph{State and sparsity firewall.} The $w$-bit state certifies small LAST-WRITER provenance for THIS source. It is NOT a sparse envelope over all $n$-bit outputs of short universal oracle programs, and point-output uniqueness is NOT universal PFCERT. Physical macrosteps use a random-access addressing grammar; a conventional sequential-head Turing machine may pay $\Omega(2^n)$ for head travel. No arbitrary-machine complexity consequence follows from this evaluator.

\paragraph{Matched-oracle two-output impossibility.}
Fix one legitimate oracle $O$ for the universal interpreter $U^O$, verifier $V^O$ and $P^O/NP^O$. Define plain $K_U^{t,O}(x)$ as shortest oracle program printing $x$ in $t(|x|)$ steps, for superpolynomial $t$ eventually dominating every polynomial. Assume $V^O(n,p,x,\pi)$ has polynomial runtime and witnesses, accepts every $n$-bit $U^O(p)$ endpoint obtained by time $t(n)$ for $|p|\le n-2$, and accepts at most two distinct $x$ over ALL proofs for each fixed $(n,p)$. Let $E_n^O$ be the set of accepted $x$ over all $p,\pi$. There are $2^{n-1}-1$ binary programs of length $\le n-2$, so $|E_n^O|\le2^n-2$. All excluded $x$ have $K_U^{t,O}(x)\ge n-1$. If $P^O=NP^O$, their complement is an infinite $P^O$ subset of the plain $K^{t,O}$-random strings. But for any fixed oracle an infinite $P^O$ subset of this random set is impossible: hardwire $n-O(\log n)$ bits of a member, search all $2^{O(\log n)}$ suffixes using the same oracle decider and output the first matching member in polynomial time, giving a description shorter than $n-1$ for large $n$, contradicting randomness. Take $O=\mathrm{TQBF}$, where $P^O=NP^O=\mathrm{PSPACE}$. Thus a COMPLETE uniform polynomial two-output PFCERT package cannot relativize. Mere soundness, fixed-PH verification, a source hash or existential unions of sparse descriptors do not supply the missing universal existence or coverage. Distinguish time-bounded $K$ from Levin $Kt$; nonalgebrization remains OPEN.
