\section{Claim card, canonical target, and falsifiers}
The sole hardness target is D\"ocker's duplicate-free proper clausewise-monotone
3-SAT-(2,2): every original clause contains three distinct same-sign variables, clauses
are unique, and every original variable occurs exactly twice in each polarity.  A total
language decider must reject malformed strings.  The broader proper strict-2P2N language
is comparison only.

\paragraph{Exact obstruction.}
Does the complete aligned logical XOR adjunct contain an unavoidable resource beyond
ordinary local clause-transition accounting, and can that resource distinguish the
same-target SAT and UNSAT controls or force physical work by an arbitrary exact decider?

\paragraph{Quantifiers and SAME\_REALIZATION.}
Fix one source CNF $F$ with no repeated variable inside a clause, one complete coherent
assignment $a$, one source variable $x_i$, and the aligned offline logical vector
\[
 S_e(F,a)=a\ \Vert\ \bigl(e(t_j(a)),\mathbf1[t_j(a)>0]\bigr)_{j=1}^{m}.
\]
The encoding $e$ is either ordinary two-bit binary or reflected two-bit Gray.  The
theorem below compares $a$ with $a\oplus e_i$ in this same declared vector.  It does not
identify that vector with an arbitrary solver's writable tape.

Four preregistered falsifiers were tested:
\begin{enumerate}

\item F4: low endpoint XOR implies low time despite DELAY, rereads, unchanged writes or

\end{enumerate}
All four proposed stronger readings are false.  The exact restricted identity follows.

\section{Exact local activity theorem}
Let $d_i$ be the number of original clauses containing $x_i$.  On one flip define
\[
 B_i(a)=\#\{j\ni i:\{t_j(a),t_j(a\oplus e_i)\}=\{0,1\}\},
\]
and
\[
 H_i(a)=\#\{j\ni i:\{t_j(a),t_j(a\oplus e_i)\}=\{1,2\}\}.
\]
$B$ is exactly the number of original-clause satisfaction flags that change; $H$ counts
the middle edge on which ordinary binary count coding uses Hamming distance two.

\begin{theorem}[Single-flip XOR activity identity]\label{thm:local}
For every such $F,a,i$,
\[
 \boxed{d_{\rm logic}^{\rm Gray}=1+d_i+B_i(a)},\qquad
 \boxed{d_{\rm logic}^{\rm bin}=1+d_i+B_i(a)+H_i(a)}.
\]
For a valid D\"ocker target $d_i=4$ and $B_i+H_i\le4$, hence both distances lie in
$[5,9]$ and
\[
 d_{\rm logic}^{\rm Gray}=5+B_i,
 \qquad d_{\rm logic}^{\rm bin}=5+B_i+H_i.
\]
The four changed source-clause record IDs are precisely the four clauses incident to
$x_i$.
\end{theorem}
\begin{proof}
The assignment coordinate for $x_i$ contributes one.  Every nonincident original clause
is unchanged.  Because a clause contains $x_i$ at most once, each incident true-literal
count moves by exactly one.  Adjacent reflected Gray codewords have Hamming distance one;
the clause satisfaction bit contributes one exactly on the $0\leftrightarrow1$ edge.
This proves the first identity.  Ordinary two-bit binary has adjacent edge weights one,
two, one on $0\leftrightarrow1$, $1\leftrightarrow2$, $2\leftrightarrow3$,
respectively, proving the second.  In the target, exact two-positive/two-negative
occurrence quotas give four distinct incident clauses.  Every touched clause uses exactly
one of the three adjacent edges, so $B_i+H_i\le4$.
\end{proof}

\begin{corollary}[Arbitrary flip-sequence ledger]\label{cor:sequence}
For any possibly backtracking variable-flip sequence of length $T$ on a valid target,
with $B$ and $H$ summed over its individual steps,
\[
 \boxed{\sum_t d_{{\rm logic},t}^{\rm Gray}=5T+B},\qquad
 \boxed{\sum_t d_{{\rm logic},t}^{\rm bin}=5T+B+H}.
\]
Thus $5T\le\sum_t d_{{\rm logic},t}\le9T$.  The identity holds independently of the
SAT/UNSAT label and makes explicit that this logical XOR is a recoding of local activity,
not a separate decision certificate.
\end{corollary}

Every valid target also obeys $m=4n/3$ and
\[
 \sum_{j=1}^m t_j(a)=2n
\]
for every assignment: each variable contributes exactly two true signed occurrences.
A flip raises two incident counts and lowers two, so this global sum is invariant.  This
is exact source accounting, not a proof that a satisfying assignment exists.

\section{Hostile controls and physical firewall}
The generalized identity was checked exhaustively on Horn, 2-SAT, an easy three-XOR CNF
encoding, and a bounded-treewidth path.  This is adverse to a hardness interpretation:
the representation identity stays cheap on tractable families.  Standard SAT local
search already maintains make/break counts by updating the clauses incident to a flipped
variable \cite{Fukunaga,Pham}.  The present theorem is an exact fixed-encoding
specialization, not a claimed novel algorithm.

The physical transfer fails.  A lazy solver may store only an assignment and recompute
counts from the read-only source.  DELAY and repeated source reads consume time while
data XOR remains zero; unchanged writes and head moves also cost time without changing
content; changed-then-restored cells have zero endpoint delta.  Conversely, materializing
the full logical vector requires layout, index/head motion, writes and peak live storage
not represented by $B,H$ alone.  Online XOR computation itself must be charged.

The FLMV indexed machine adds atomic index-tape erasure.  The verified whole-run potential
bound $D\le Q+E\le2Q+B_0\le2qT+B_0$ remains applicable, but no lower bound on the
solver's $D_{\rm phys}$ follows from Theorem~\ref{thm:local}.  LSPV-4's per-jump
$\sum\operatorname{wt}(a_j)$ theorem applies only to a policy that separately rebuilds
each absolute indexed address; sequential scanning falsifies a universal
$\Omega(N\log N)$ source-time claim.

Boolean-hypercube boundary/influence results concern semantic edge boundaries under
their probability/combinatorial models \cite{EldanGross}.  They are an
\textbf{ANALOGY/CANDIDATE}, not a theorem transfer to FLMV native time: the missing bridge
would have to force an arbitrary exact solver to walk or materialize these assignment
edges in the same execution.  DELAY, semantic-oracle and Gaussian-oracle controls show
that no such bridge is presently available.
