\section{CONSTRUCTION OR PROOF ATTEMPT}
A complete original source has $n$ explicitly unary-encoded, $M=2^n$ physical tape bits, $Q=2^k$ explicitly tabulated controller states, $c_0$, $g:[Q]\to[Q]$, and for each controller state an \emph{odd} $u_c\in[0,M)$, $v_c\in[0,M)$ and unary bit map $h_c$ (identity, toggle, erase, set). Initial data is the random-access circuit $x_i(0)=\operatorname{parity}(i\mathbin{\&}m)\oplus b$, with explicit $n$-bit $m$. At time $t$ the physical address is $a_t=(u_{c_t}t+v_{c_t})\pmod M$; update only $x_{a_t}\leftarrow h_{c_t}(x_{a_t})$ and $c_{t+1}=g(c_t)$. The source contains binary horizon $T$ and requested index $q$. Its complete canonical original bytes, not a hash assumption, authenticate every certificate. This is a deterministic RAM-style physical computation whose live tape may contain $2^n$ bits. It is not an arbitrary hidden-read controller.

Enumerate the controller orbit to find uniquely determined preperiod $\mu<Q$ and cycle length $1\le\lambda\le Q$. Let $d=\gcd(\lambda,M)$, $J=M/d$ and $L=\lambda J=\operatorname{lcm}(\lambda,M)$. For each $r\in[0,\lambda)$, put $c^{(r)}=c_{\mu+r}$ and
\[
\tau_r=u_{c^{(r)}}^{-1}(q-v_{c^{(r)}})\pmod M.
\]
A visit to $q$ during controller phase $r$ occurs iff $d\mid(\tau_r-\mu-r)$; if so the unique relative time in the interval $[0,L)$ is
\[
 e_r=r+\lambda j_r,\qquad
 j_r=\left({\tau_r-\mu-r\over d}\right)
       \left({\lambda\over d}\right)^{-1}\pmod J.
\]
For $J=1$ define $j_r=0$. By generalized CRT, all visits in the eventual cycle occur exactly at $t=\mu+e_r+\ell L$, $\ell\ge0$, with no more than $\lambda\le Q$ listed events per common period. This proves the \emph{exact source-level last-writer chronology}; no other cell can affect $x_q$ under this primitive.

\begin{theorem}[Source-grounded exact one-cell endpoint]
For every authenticated typed source in this grammar, $q$ and binary $T$, a uniform deterministic constructor/verifier have polynomial bit-time and polynomial simultaneous live bits in original source length $N$, accept one and only one correct physical output bit $x_q(T)$ globally across all accepted certificates, and use
\[
 |\pi|=O(N+Q(n+\log(Q+1))+\log(T+2))
\]
certificate bits. A coarse conventional-bit-model bound is $O((N+1)^6)$ time, $O((N+1)^3)$ simultaneous bits.
\end{theorem}
\noindent\emph{Proof.} Replay at most $\mu$ initial steps for $q$, starting with its explicitly computable initial bit. Compose all at most $Q$ unary bit maps in the chronologically sorted CRT event list to obtain the function $H$ for one period. Put $B=\lfloor(T-\mu)/L\rfloor$, $R=(T-\mu)\bmod L$ when $T>\mu$; apply $H^B$ by binary exponentiation of four-element unary-map monoid, then just events $e_r<R$. All listed times have $O(n+\log Q)$ bits. The verifier compares complete original canonical source bytes and recomputes every orbit, CRT equation, event, composition, initiality and endpoint from the source, rejecting any forged alternative certificate. For every original state, the local write affects exactly the addressed cell, proving all-step consecution and terminal coverage. One original source uniquely determines every valid stage and therefore every accepted output, establishing \emph{global} multiplicity one. Unary encoding of $n$ and explicit $Q$ controller entries ensure $n,Q\le O(N)$, so discovery, integer bit operations, source scans, certificate construction, and peak retention are polynomial in the same sequential realization. Nothing expands or asserts a small explicit full tape. \hfill$\square$

For example $Q=1,u=1,v=0,h(x)=1,T=M$, initialized to all zeros, makes an exponentially long terminal tape of all ones; one queried cell has exactly one CRT event and a polynomial certificate, whereas outputting the entire tape still needs $M$ bits. This is \emph{line-query} not total explicit expansion.

\paragraph{Falsifiers and open scope.} Two tapes $(0,0)$ and $(1,0)$ agreeing on target bit $q=1$ respond differently if an illegal hidden-address read sets cell $x_{x_0}$ to one. If $M=64,\lambda=2$, a nonunit phase $u=0,v=q$ has 32 visits in a length-64 period, refuting the unit-slope event-list bound. Neither gives an unrestricted runtime lower bound; repeated updates can sometimes be compactly composed. The source grammar has no state-dependent reads from other cells in $g$, $u$ or $v$. There is no globally sparse union across exponentially many different source descriptors and no general polynomial-state invariant.

\paragraph{Matched-oracle diagnostic.} Fix the \emph{same} oracle $O$ for a universal oracle-query machine $U^O$, plain time-bounded $K_U^{t,O}$, verifier $V^O$, $P^O$ and $NP^O$. Suppose all outputs of programs $|p|\le n-2$ produced by $U^O$ within superpolynomial $t(n)$ have polynomial-length $V^O$ witnesses and each $(n,p)$ has at most two accepted outputs across all proofs. The NP-oracle set $E^O_n$ of accepted outputs over such $(p,\pi)$ has size at most $2(2^{n-1}-1)=2^n-2$; its infinite complement lies in the oracle time-bounded random set $R_{K_U^{t,O}}$. In a legitimate collapsing world $O=\mathrm{TQBF}$, $P^O=NP^O$, so the complement would be an infinite $P^O$ subset of that random set, contradicting the same-oracle prefix/suffix immunity proof. Thus this \emph{universal} schema fails relative to a collapsing oracle; this restricted CRT theorem evades universality and relativizes. It does not prove ordinary PFCERT, $P\ne NP$, or nonalgebrization.
