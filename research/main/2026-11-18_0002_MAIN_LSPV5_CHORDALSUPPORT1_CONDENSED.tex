\section{CONSTRUCTION OR PROOF ATTEMPT}
Fix $\Sigma=\mathbb{Z}_5$ and $R(a,b)=[(b-a)\bmod5\in\{1,3\}]$. The canonical ASCII input lists header \texttt{p t5 n m}, all $n$ vertices explicitly, and $m$ distinct sorted directed arcs. All bytes and endpoints are validated; a loop has exact count zero; malformed inputs are rejected. Its length $N$ satisfies $n\le N$. The exact counting objective is
\[
Z(G)=\sum_{x\in\Sigma^V}\prod_{(u,v)\in E}R(x_u,x_v).
\]
Group vertices by equal full incoming/outgoing signatures. Classes are independent, with uniform complete directed arcs between classes. Each nonisolated class of size $s$ uses precisely one of ten possible nonempty color supports: five singletons with weight one and five admissible pairs $\{a+1,a+3\}$ with exact multiplicity $2^s-2$. Isolated classes contribute $5^s$. The factor between quotient classes $i\to j$ is the conjunction of $R(a,b)$ for all $a\in S_i,b\in S_j$.
\paragraph{Restricted exact theorem.} If the undirected quotient $Q$ is chordal, deterministic MCS plus an explicit PEO verification discovers the decomposition. Supports at the vertices of any clique are pairwise disjoint because $R(a,a)=0$. A quotient clique of six implies exact $Z=0$. Otherwise the maximum clique has size at most five, and the PEO has at most four later neighbors per eliminated vertex. Exact sum-product elimination therefore has tables of at most $10^4$ values and at most $10^5$ transition tuples per elimination, with integer bit length $O(N)$. A clique of five forces the support of each member to a singleton, further reducing the corresponding enumeration to five-state coordinates. Counting, input parsing, quotient discovery, recognition, all integer arithmetic, factor storage, output and verification have conservative same-run bounds
\[
T=O((N+1)^{14})\text{ bit operations},\qquad
S_{\rm peak}=O((N+1)^6)\text{ bits}.
\]
On a nonchordal $Q$ the restricted algorithm returns NOT\_CERTIFIED, not UNSAT. A verifier re-authenticates the complete source and any alleged PEO and recomputes the exact integer. All accepted proofs for the same original graph yield ONE identical output over all certificates. These are restricted results, not a universal long-machine certificate.
\paragraph{Explicit mixed YES/NO family.} Chain $m$ copies of the oriented $K_5=T_5$ tournament, each successive clique sharing one vertex, and blow each quotient vertex into $b$ independent twins with complete arcs across adjacent classes. Then $q=4m+1$, the quotient is chordal of treewidth four, the original contains $K_{b,b}$ and has treewidth at least $b$, and the exact count is $Z=5$ for every $m,b\ge1$. Reversing one arc of the first quotient $K_5$ changes its degree multiset and yields $Z=0$. All five-clique classes have singleton supports. No mandatory-work lower bound follows.
\paragraph{Explicit finite-transition certificate.} For an actual explicitly listed $s$-state deterministic transition function $f$, initial state $a$, and binary-encoded $T$, list the exact functions $f^{2^i}$ for each bit position and verify $F_0=f$, $F_{i+1}=F_i\circ F_i$, and application to $a$ at the set bits of $T$. The certificate has $O(s\log(s+1)\log(T+2))$ bits; verification and endpoint computation are polynomial in the explicit input. This supplies initiality, consecution, terminal coverage and unique output only for an explicitly small configuration set; exponentially many arbitrary-machine configurations or exponentially large single configurations are NOT compressed.
\paragraph{Matched-oracle barrier.} Fix one oracle $A$, one universal oracle machine $U^A$, a superpolynomial time bound $t(n)=n^{\omega(1)}$ large enough for polynomial simulation, and all verifiers/deciders using the SAME $A$. A $P^A$-decidable infinite subset of $\{x:K_U^{t,A}(x)\ge |x|-1\}$ would be compressed by hardcoding the first $n-c\log n$ bits and using its $P^A$ decider to search at most $n^c$ suffixes, a contradiction. If a polynomial $NP^A$ verifier accepted every $n$-bit endpoint from programs $|p|\le n-2$ within $t(n)$, with at most two distinct accepted outputs globally over all proofs for each $(n,p)$, the accepted envelope would have at most $2(2^{n-1}-1)=2^n-2$ strings. Relative to $A=\mathrm{TQBF}$, $P^A=NP^A=PSPACE$, leaving an infinite decidable complement inside the immune random set, a contradiction. Hence the universal two-output PFCERT cannot hold in that collapsing-oracle world. It remains OPEN for ordinary machines; a genuinely nonrelativizing construction is still missing.
\paragraph{Gates.} Polynomial proof size, initiality, consecution, coverage, membership evaluation, syntactically certified sparse-envelope size and global output multiplicity are separate obligations; a fixed-PH verifier under $P=NP$ proves neither descriptor existence nor succinct state. Exponentially many sparse descriptors cannot be existentially unioned without losing sparsity. The local exact algorithm relativizes; algebrization, Natural Proofs applicability and general SAT lower-bound transfer are not closed. DEAD isolated source vertices multiply exact counts by $5^d$; COPY/DELAY, INTERP/RECOMP, affine and compact evaluators remain legal. A post-disclosure search over $B$ given candidates costs $O(B)$ digest evaluations and freshness alone is no classical SAT separation.
