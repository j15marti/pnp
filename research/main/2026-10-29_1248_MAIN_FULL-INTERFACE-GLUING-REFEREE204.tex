\section{BUILD I: exact full-interface composition}
Let $T$ be a rooted tree of modules.  Module $t$ has a variable bag $V_t$ and
owns a set $C_t$ of source constraints.  The certificate must verify:
\begin{enumerate}
\item every source constraint occurs in exactly one $C_t$, and its complete
scope is contained in $V_t$;
\item for every variable $x$, the modules whose bags contain $x$ induce a
connected subtree of $T$;
\item the local conjunction in $C_t$ is a recognized 2CNF together with an
affine system of coefficient rank (codimension) $e_t$;
\item $B_t=V_t\cap\bigcup_{u\ne t}V_u$ is the \emph{full} shared interface,
and $b_t=|B_t|$.
\end{enumerate}
Write $S_{tu}=V_t\cap V_u$ on edge $tu$.

\begin{lemma}[Cut separator]
If a variable occurs in a module inside the child subtree of $u$ and in a
module outside it, then it belongs to $S_{tu}$.
\end{lemma}
\begin{proof}
The unique path between those two modules crosses edge $tu$.  Running
intersection requires every bag on that path, hence both endpoint bags, to
contain the variable.
\end{proof}

\begin{theorem}[Verified full-interface tree composition]
Let $D$ include the complete cost of discovering, parsing and verifying the
certificate above.  There is one uniform deterministic algorithm that decides
both SAT and UNSAT and reconstructs a satisfying assignment on YES in
\[
 D+\operatorname{poly}(N)\sum_{t\in T}
     2^{b_t} (|V_t|+1)^{O(e_t)} .
\]
All failed local calls, child-table lookups, projections, stored backpointers,
joins, source rechecks, output work and peak table space are included.
Consequently polynomially many modules, polynomial $D$, uniformly fixed
$e_t$, and $b_t=O(\log N)$ give a deterministic polynomial algorithm for this
promised and supplied-decomposition class.
\end{theorem}
\begin{proof}
Process the tree bottom-up.  For every $\alpha\in\{0,1\}^{B_t}$, first look up
each child summary on $\alpha|_{S_{tu}}$.  If all lookups succeed, restrict the
local 2CNF by $\alpha$ and pin the same coordinates in the affine system, then
invoke the fixed-codimension solver.  Restriction preserves 2CNF.  Deleting
fixed columns and row reducing cannot increase the coefficient rank on the
remaining coordinates above $e_t$; inconsistency is detected as a zero row
with right side one.  Mark $\alpha$ feasible precisely when all child messages
and the local call succeed, and project feasible entries to the parent
separator.  Store one local witness and compatible child backpointer per
feasible projected entry.

For soundness, compatible local witnesses agree on every edge separator;
the cut-separator lemma implies that these agreements cover every variable
shared across a cut.  Constraint ownership and scope containment ensure every
source constraint is checked exactly where its full scope is present.  Thus
the witnesses glue to one global witness.  For completeness, restrict any
global witness to every $B_t$; induction shows that its entry survives every
child lookup and local call.  Root-table nonemptiness is therefore equivalent
to SAT.  Backtracking reconstructs and source-checks a witness.  The displayed
sum enumerates every full interface entry and charges the local XP call;
degree factors, projection and storage are absorbed in the explicit
polynomial factor.
\end{proof}

Arbitrary cross-module clauses whose full scope is absent from the purported
owner bag invalidate item 1.  Dropping running intersection invalidates the
cut lemma.  Charging only a newly selected separator rather than all of $B_t$
invalidates the enumeration bound.  The theorem is sufficient, not a
universal decomposition or contraction theorem.

\section{BUILD II: essential accumulated-interface star}
For every $q\ge1$, create a star with centre $c$ and leaves $1,\ldots,q$.
The centre bag contains $x_i,y_i$ for all $i$ and owns the one affine row
\begin{equation}
 \bigoplus_{i=1}^q (x_i\oplus y_i)=1. \tag{C}
\end{equation}
Leaf $i$ contains $x_i,y_i$ and owns
\begin{equation}
 x_i\oplus y_i=0. \tag{$L_i$}
\end{equation}
There are no 2CNF clauses.  Every edge separator is
$\{x_i,y_i\}$, every local affine system has rank one, running intersection
holds, and the full centre interface has size $2q$.

\begin{proposition}[Full-interface accumulation is necessary for raw tables]
The star is UNSAT.  Deleting any one leaf row makes it SAT.  Hence all $q$
child messages are essential, although maximum edge width and maximum local
codimension are constant.  The centre's full raw table has $2^{2q}=4^q$
assignments.  A shortcut that keeps only the centre's parent separator (empty)
and the fact that each child table is nonempty answers SAT incorrectly.
\end{proposition}
\begin{proof}
XORing all leaf coefficient rows gives exactly the coefficient row of (C),
but with right side zero instead of one.  Thus the coefficient matrix has rank
$q$ and the augmented matrix rank $q+1$.  If $L_j$ is removed, choose
$x_j\ne y_j$ and make every other pair equal, satisfying all remaining rows.
Therefore every child relation participates essentially in the contradiction.
\end{proof}

This family does \emph{not} prove that $4^q$ work is necessary: Gaussian
elimination solves it in polynomial time.  Absorbing all child messages into
one centre affine system, however, raises accumulated rank from one to $q$.
Thus it escapes raw-table enumeration only by changing the charged structural
parameter.  It precisely falsifies the proposed substitution
``maximum edge separator $O(1)$ plus local $e=O(1)$ implies polynomial raw
tree tables.''

The dependency-free reproducer symbolically checked ranks through $q=32$ and
exhaustively enumerated every assignment for $q\le6$.  All nine tested cases
had coefficient/augmented ranks $q,q+1$, zero global models, and a consistent
system after every single-leaf deletion.  Runtime was 0.04 seconds.  Code
SHA-256 is
