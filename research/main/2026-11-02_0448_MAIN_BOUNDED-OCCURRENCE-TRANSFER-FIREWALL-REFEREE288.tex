\section{Exact obstruction and falsifiable approaches}
The only target is every valid proper duplicate-free D\"ocker monotone
3-SAT-(2,2) original.  A strict parser rejects malformed strings.  Residual
circuits and Tseitin encodings are not canonical children.

The obstruction is quantifier-level: a proposed lower bound on constructing a
forward circuit, OBDD, cofactor DAG, equality certificate, or semantic cache
cannot be necessary decision work if a paid uniform source algorithm decides
the unchanged original without acquiring that representation.

This run tests four falsifiable claims: (i) the 35-gate F9 evaluator is a
necessary precondition for exact decision; (ii) the 52-node optimal F9 OBDD is
necessary; (iii) the new iterated projection point
$\widetilde O(2^{0.838475437n})$ is a universal target decision-time frontier;
and (iv) every exact target decider must discover exact cofactor equality or a
semantic representative.  All four are false as universal necessities.

\section{Published algorithmic input and exact transfer}
Peng and Xiao prove that CNF-SAT with maximum variable occurrence four is
deterministically decidable in $O^*(1.2628^n)$ time
\cite{pengxiao23,pengxiao25}.  Their theorem applies to arbitrary CNF in that
occurrence class, not just monotone formulas.

\paragraph{Transfer theorem (proved here).}
Let $F$ be a declared target original on $n$ variables and source length $N$.
After one strict grammar/duplicate/occurrence scan, exact target decision takes
\[
 T_{\rm target}(F)\le T_{\rm grammar}(N)+T_{\rm occurrence}(N)
       +T_{4\rm occSAT}(F)+T_{\rm output}
       =O^*(1.2628^n).
\]
No forward circuit, Tseitin/PG encoding, OBDD, Shannon/cofactor DAG, semantic
equality table, or assignment-recovery key is constructed.

\paragraph{Proof.}
The target grammar requires exactly two positive and two negative occurrences
of every original variable.  Hence every accepted source has maximum total
occurrence $d=4$.  It is therefore literally an input to the published
$d=4$ algorithm; no reduction and no variable renaming is needed.  A strict
scan checks three distinct same-sign literals per clause, duplicate-freedom,
the $2+2$ signed counters, and the $3m=4n$ relation, rejecting otherwise.
The scan is polynomial in the explicit source length and does not change the
algorithm's exponential base.  Exactness for both SAT and UNSAT is inherited
from the exact deterministic source algorithm. \hfill$\square$

Numerically,
\[
  1.2628^n=2^{0.3366261658n},\qquad
  2^{0.8384754372n}=1.788159512^n,
\]
so the latter base is larger by a factor $1.416027488^n$.  A newer preprint
states $O^*(1.1199^{(d-2)n})$, which would give
$1.25417601^n$ at $d=4$ \cite{jainneohstephan}; it is recorded separately and
is not needed for the peer-reviewed firewall.

\section{What this proves and what it does not}
The transfer is substantive because it is all-input for the canonical target
and bypasses the entire same-original SAT-versus-Circuit-SAT representation
route.  It is nevertheless only an upper bound.  It does not show that the
published branching algorithm is optimal, that any representation is hard,
or that the target is polynomial-time decidable.

The comparison is also not a free time--space dominance claim.  LSPV-1's
slower projection algorithm includes a polynomial combined-peak argument.
This run has not reconstructed a native machine trace or established a
polynomial-space implementation of Peng--Xiao.  Conservatively,
\[
 S_{\rm target}\le S_{\rm parser}+S_{\rm occurrence}+S_{4\rm occSAT}+O(\log n),
\]
and $S_{4\rm occSAT}$ remains exactly what the adopted implementation uses.
Thus the results are distinct upper time--space points.  There is no strict
same-machine FLMV numerical transport.

Likewise, the result does not make semantic comparison free.  It proves that
an unrestricted exact decider need not request it at all.  If a controller
does request circuits, equality, GE, proof checking, cache/replay, children,
or DELAY/COPY/RECOMP guests, all discovery, failed policies, source/index/head
reads, output accesses, and simultaneous live space remain charged.
