\section*{All-algorithm B2/B3 transfer theorem schema}
Let $W_R(F)$ denote the minimum cost of an accepted $R$-refutation of the exact external formula $F$, and let $W_{\rm abs}(F)$ be a minimum abstract cost. A valid contradiction from an abstract superpolynomial lower bound requires both:
\begin{align*}
&\forall F\in\mathrm{UNSAT}:\quad W_{\rm abs}(F)\le W_R(F),\\
&\forall A\,[A\text{ correct total deterministic SAT decider}]\;\exists c_A,r_A\;\forall F\in\mathrm{UNSAT}:\\
&\hspace{35mm}\exists\pi\;V_R(F,\pi)\ \wedge\ W_R(\pi)\le c_A(|F|+T_A(|F|))^{r_A}.
\end{align*}
Concrete-step inclusion and completed-refutation preservation are indispensable in the first line. Source binding, same-calculus proof construction and charged output size are indispensable in the second. If $T_A(n)\le n^{k_A}$, these inequalities imply $W_{\rm abs}(F)\le C_A n^{r_A(k_A+1)}$ for large $n$. A lower bound defeating every fixed polynomial exponent on a common family would contradict this. A bound $\Omega(n^{1+\varepsilon})$ does not. For $c>0$, $n^{(\log n)^c}=\exp((\log n)^{c+1})$ is both quasipolynomial and superpolynomial, but a quasipolynomial \emph{upper} bound alone does not settle P versus NP.

LSPV-2/604 proves a correct and useful restricted bridge from a fully enumerated DPLL conflict tree to accepted /386 SOURCE+RES bytes, with $W_R\le1+I_{\rm DPLL}$. It explicitly does not relate $I_{\rm DPLL}$ to the runtime of an arbitrary different decider. Kraj\'i\v cek's algorithm class $\mathsf{Alg}(P)$ likewise contains algorithms whose soundness is provable in a selected proof system; it is not automatically the class of all correct SAT deciders. No reviewed artifact establishes the quantified second line for every $A$ in the same historical mixed calculus. Therefore [P2-B2/B3] remains \textbf{OPEN}, and the complete chain is not a proof.
