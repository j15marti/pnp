\section{Exact authenticated path model}

Let an explicitly authenticated deterministic module path have $m$ transitions
\[
 x_i=f_i(x_{i-1}),\qquad 1\le i\le m,
\]
where each exact state $x_i$ has at most $B$ bits.  Evaluating one transition, including all source
access, local failed checks, compatibility work, and copying a $B$-bit state, costs at most $K$ time
and $W$ additional live work bits.  Given adjacent exact states, a local reconstruction record is
computable within the same $K,W$ budget.  The output is a write-only stream; buffering it would add
its physical length to space.  This model applies only after discovery, authentication, and
representation closure have been paid.  It is not a decomposition theorem.

\section{BUILD: checkpoint--replay frontier}

\begin{theorem}[Exact path checkpoint/replay schedules]
\label{thm:replay}
The reverse state sequence $x_m,x_{m-1},\ldots,x_0$, and hence any local records recoverable from
adjacent states, can be generated by each of the following deterministic schedules:
\begin{align*}
\text{materialize all: }&T\le mK+O(mB),&
S&\le W+(m+1)B+O(\log m);\\
\text{block length }L: &T\le2mK+O(mB),&
S&\le W+B(\lceil m/L\rceil+L+3)+O(\log m);\\
\text{binary replay: }&T\le\left(m+\frac m2\log_2m\right)K+O(mB),&
S&\le W+B(\log_2m+2)+O(\log^2m)
\end{align*}
when $m$ is a power of two; ceilings give the same asymptotic bounds otherwise.  Pure replay from
$x_0$ uses at most $m(m+1)K/2+O(mB)$ time and $W+2B+O(\log m)$ space.
\end{theorem}

\begin{proof}
Full materialization is immediate.  For block replay, store $x_0,x_L,x_{2L},\ldots,x_m$ during one
forward pass.  Process blocks in reverse order, recomputing and retaining at most $L+1$ states in the
active block.  Every transition is evaluated exactly twice.

For binary replay, recursively split $[a,b]$ at its midpoint.  Starting from $x_a$, compute the
midpoint state, recursively emit the right half, then recursively emit the left half, suppressing the
duplicate midpoint.  At every internal depth the midpoint computations total $m/2$ transitions; the
leaves contribute $m$ more.  The recursion holds one state per level, giving the displayed bounds.
Pure replay recomputes each prefix of lengths $m,m-1,\ldots,1$.
\end{proof}

\begin{corollary}[Block derivative, first equality, and exponent collapse]
\label{cor:collapse}
Ignoring ceilings, block checkpoint state storage is
\[
F(L)=B\left(\frac mL+L\right),\quad
F'(L)=B\left(1-\frac m{L^2}\right),\quad
F''(L)=\frac{2Bm}{L^3}>0.
\]
The checkpoint and active-block terms first coincide at $L^*=\sqrt m$, the unique minimum, with
$F(L^*)=2B\sqrt m$.

If $m=N^{\mu+o(1)}$, $B=N^{\beta+o(1)}$, $K=N^{\kappa+o(1)}$, and
$W=N^{\omega+o(1)}$, then for $L=m^\lambda$ the block schedule has
\[
\tau=\mu+\kappa,qquad
\sigma=\max\{\omega,\beta+\mu\max(\lambda,1-\lambda)\}.
\]
Its space slope with respect to $\lambda$ is $-\mu$ below $1/2$ and $+\mu$ above $1/2$.  Binary
replay has
\[
\boxed{\tau=\mu+\kappa,qquad\sigma=\max\{\omega,\beta\}},
\]
because logarithmic factors do not change polynomial exponents.  It therefore exponent-dominates
every point on the block-cache curve under these hypotheses.
\end{corollary}

\begin{proof}
Differentiate $F$.  Substitute the power parametrization into
Theorem~\ref{thm:replay}.  Since $K$ includes $B$-bit copying, the write-only output term does not
raise the time exponent.  The binary schedule adds only $\log m=N^{o(1)}$ time and live-state factors.
\end{proof}

\begin{proposition}[No generic replay lower bound]
For the invertible chain $x_i=x_{i-1}\oplus c_i$, compute $x_m$ forward and apply the $c_i$ in reverse.
The complete reverse sequence uses $2m$ transitions and two live states.  Thus neither the block
minimum nor the binary-replay logarithm is an unavoidable decision or reconstruction lower bound.
\end{proposition}

\paragraph{Interpretation.}
There is a real finite tradeoff in transition counts: materialization uses $m$, block replay $2m$,
binary replay $m+(m/2)\log_2m$, and pure replay $m(m+1)/2$.  But the first three have the same
polynomial time exponent, while binary replay has the lowest polynomial space exponent.  Therefore a
plot of cache size against exact transition count may show a meaningful finite Pareto curve even when
the curve collapses to one nondominated point in the $(\log_NT,\log_NS)$ exponent plane.  The result
is an upper bound; it neither proves optimality nor constrains algorithms with compact algebraic or
invertible summaries.

\Status{PROVED/EXACT} Theorem~\ref{thm:replay}, Corollary~\ref{cor:collapse}, and the invertible-chain
countercontrol under the stated authenticated deterministic path hypotheses.
