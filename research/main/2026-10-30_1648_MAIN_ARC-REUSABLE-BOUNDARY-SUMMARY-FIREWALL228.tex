\begin{abstract}
This run tests whether exact frontier messages can be promoted from a restricted
dynamic program into a uniformly power-short reusable summary for arbitrary
ordinary CNF.  For every Boolean function $f:\{0,1\}^b\to\{0,1\}$ we construct
a proper 3-CNF $A_f(X,Y)$ with existential boundary projection
$\exists Y\,A_f(x,Y)=f(x)$ and uniform explicit size
$N_b=\Theta(b^2 2^b)$ bits.  Proper 3-CNF continuations $B_a$ pin $X=a$, so
$A_f\land B_a$ is satisfiable exactly when $f(a)=1$.  Consequently any
deterministic reusable summary prepared from $A_f$ before seeing $B_a$, from
which all point continuations are answered without rereading $A_f$, has
worst-case length at least $2^b=\Omega(N_b/(\log N_b)^2)=N_b^{1-o(1)}$ bits.
Thus no fixed power $N^\lambda$, $\lambda<1$, suffices for this universal
reusable interface.  This is the deterministic one-way INDEX lower bound in an
explicit proper-3CNF realization.  It does \emph{not} lower-bound a solver that
sees $A$ and $B$ jointly, retains the source, recomputes, or uses another ARC
architecture.  The all-input hereditary $A\mapsto\Phi(A)$ contraction, FLMV
entry, and P versus NP remain \OPEN.
\end{abstract}

\section{Claim card and four falsifiers}
\paragraph{Single target.}
Referee the load-bearing promotion from exact recursive frontier tables to a
complete power-short ordinary-SAT child or reusable message on every source.
The exact quantifier prefix tested is
\[
 \forall b\;\forall f\; S_f=P(A_f),\qquad
 \forall a\; Q(S_f,B_a)=\operatorname{SAT}(A_f\land B_a),
\]
where $P,Q$ are fixed deterministic algorithms and $Q$ cannot reread $A_f$.
Construction time and query time are unrestricted; only stored summary length
is bounded.  This is deliberately stronger than any finite implementation but
narrower than a joint SAT solver.

Four mechanisms were tested.
\begin{enumerate}
\item \emph{Universal power-short reusable message.}  Falsified by the theorem
below for every fixed $\lambda<1$.
\item \emph{Exponential-in-source storage lower bound.}  Falsified: the result
is only near-linear, $\Omega(N/(\log N)^2)$, not exponential in $N$.
\item \emph{Promotion to arbitrary SAT runtime.}  Rejected: source retention,
joint preprocessing, replay, recomputation, and alternate representations are
legal unless explicitly excluded.
\item \emph{Restricted frontier replay as the missing ARC child.}  Rejected as
an identification.  LSPV-3's exact replay theorem computes support on a paid
order but emits no smaller ordinary-SAT child and its measured replay work
exceeded both its full-table computation and UP--DPLL on the controls.
\end{enumerate}

\section{A uniform proper-3CNF realization of every boundary function}
Fix $b\ge3$, boundary $X=(x_1,\ldots,x_b)$, and
$f:\{0,1\}^b\to\{0,1\}$.  For $a\in\{0,1\}^b$, let
\[
 D_a=\bigvee_{i:a_i=0}x_i\ \vee\!
     \bigvee_{i:a_i=1}\neg x_i.
\]
Thus $D_a(x)=0$ exactly at $x=a$.  Replace each width-$b$ clause $D_a$ by the
standard existential proper-3CNF chain of $b-2$ clauses with $b-3$ fresh
variables.  The chain has an extension exactly when $D_a$ is true.

For every $a$ with $f(a)=0$, put this chain into the $a$-block.  For every
$a$ with $f(a)=1$, put $b-2$ independent dummy clauses
$(u\vee v\vee w)$ on fresh private variables into that block.  All blocks have
the same number of clauses and a preallocated disjoint private variable range.
Call the conjunction $A_f(X,Y)$.  Block independence gives
\[
 \exists Y\,A_f(x,Y)=\bigwedge_{a:f(a)=0} D_a(x)=f(x).
\]
Every source has exactly
\[
 C_b=(b-2)2^b
\]
proper ternary clauses and may declare the common universe
$V_b=b+3C_b$.  With fixed-width binary variable identifiers, sign bits and a
fixed-width header, its explicit bit length satisfies
\[
 N_b=\Theta(C_b\log V_b)=\Theta(b^2 2^b).
\]
No truth-table bit or SAT label is supplied to the eventual query algorithm;
the formula syntactically contains the chosen block type.

\paragraph{Proper-3CNF point continuation.}
For desired bit $a_i$, let $\ell_i=x_i$ if $a_i=1$ and
$\ell_i=\neg x_i$ otherwise.  With fresh $u_i,v_i$, the four clauses
\[
(\ell_i\vee u_i\vee v_i),\ (\ell_i\vee u_i\vee\neg v_i),\
(\ell_i\vee\neg u_i\vee v_i),\ (\ell_i\vee\neg u_i\vee\neg v_i)
\]
have an extension exactly when $x_i=a_i$.  Let $B_a$ be their conjunction for
all $i$.  Then
\[
 \operatorname{SAT}(A_f\land B_a)=f(a).
\]

\section{Reusable-summary lower bound}
\begin{theorem}[\EXACT, restricted deterministic reusable-summary theorem]
Let $P$ prepare a binary summary $S_f$ from $A_f$ before the continuation is
known.  Let $Q$, given only $(S_f,B_a)$ and not $A_f$, answer
$\operatorname{SAT}(A_f\land B_a)$ exactly for every $f,a$.  Then some summary
has length at least $2^b$ bits.  Therefore this interface has no worst-case
length $N_b^\lambda$ for any fixed $\lambda<1$ and all sufficiently large $b$.
\end{theorem}
\begin{proof}
If $f\ne g$, choose $a$ with $f(a)\ne g(a)$.  Equal summaries would give $Q$
the same pair $(S,B_a)$ on both sources, forcing equal answers, a contradiction.
Hence the summaries are injective over all $2^{2^b}$ boundary functions.  The
number of binary strings of length at most $L$ is $2^{L+1}-1$, so a maximum
length $L<2^b$ cannot encode them all.  Thus $L\ge2^b$.

Since $N_b=\Theta(b^2 2^b)$ and $b=\Theta(\log N_b)$,
$2^b=\Omega(N_b/(\log N_b)^2)=N_b^{1-o(1)}$.  For fixed $\lambda<1$,
$N_b^{1-\lambda}/(\log N_b)^2\to\infty$, proving the last assertion.
\end{proof}

This is exactly the deterministic one-way INDEX/counting argument.  It allows
unlimited preprocessing and arbitrary summary syntax; it is not limited to a
truth-table representation.  Conversely, it says nothing when $Q$ may reread
$A_f$, when preprocessing sees $B_a$, or when the desired output is only the
single existential answer for $A_f$ with no arbitrary continuation.

\section{Relation to the integrated ARC/FLMV spine}
The theorem supplies a precise firewall for one tempting use of frontier DP:
``compile a prefix once into a power-short exact object that supports every
future boundary continuation.''  On arbitrary CNF that universal reusable
interface is impossible at a fixed power shrink.  It does not show that the
unconstructed ARC compiler must use this interface.  A valid $\Phi(A)$ may let
each child see both sides jointly, retain source access, use a continuation-
specific transformation, or avoid frontier summaries entirely, provided all
construction, source traffic, caching, replay, output and peak space are paid.

Accordingly this result cannot be substituted into FLMV as a SAT runtime lower
bound.  It constrains a declared compilation/storage architecture, not every
successful execution of an arbitrary algorithm.  AFFINE-SMALLBIAS-DESCENT-GATE2
remains a different restricted affine-MCSP semantic no-go; neither theorem
promotes the other to universal SAT hardness.
