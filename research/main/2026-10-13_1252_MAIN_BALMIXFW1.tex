\section{Primary-literature preflight and transfer classification}

Bogdanov--Trevisan emphasize that worst-case/average-case reductions for NP
are a separate unresolved architecture and review barriers to deriving them
from ordinary worst-case assumptions \cite{bt}.  This is a useful structural
warning, not a transfer theorem for $\Ltwo$.  Holenstein--K\"unzler refine a
barrier for broad nonadaptive worst-case/average-case reductions for NP

specific distribution would be misleading.  Lauria--Nordstr\"om also exhibit
graph-colouring formulas that are hard for PC yet easy for Cutting Planes
\cite{ln}; that is a direct separation of proof systems, not a SAT algorithm.

\section{Candidate tested: balance the hard source by explicit YES mass}
The obvious response to NOBIASFW1 is to force a balanced label distribution.
For each $r\ge1$, define two 6-regular graphs
\[
 Y_r=7r\,K_{3,3,3},\qquad N_r=9r\,K_7.                       \tag{2}
\]
Both have $63r$ vertices, $189r$ edges, and degree multiset
$\{6^{63r}\}$.  The first is 3-colourable by its displayed tripartitions;
the second is not 3-colourable because every component contains a $K_7$.
Mix the compiler images of uniformly relabelled $Y_r$ and $N_r$ with equal
probability.  Size, edge count, degrees, and compiled target totals no longer
reveal the label.

This candidate is attractive because it changes only the distributional
layer and keeps the actual graph-colouring compiler.  It is false as a
hardness bridge.

\begin{theorem}[Recognizable balanced-support firewall]
Let $D_1,D_0$ be distributions supported on YES and NO inputs of a language
$L$.  If a deterministic polynomial-time predicate $S$ satisfies
$S(x)=b$ for every $x\in\operatorname{supp}(D_b)$, then the equal mixture
$\tfrac12D_0+\tfrac12D_1$ is decided with zero error on its support by $S$.
Any random wrapper preserving $S$ leaves this conclusion unchanged.
\end{theorem}
\begin{proof}
On a sample from the mixture, support membership fixes its source label and
$S$ returns that label.  If a wrapper $w$ satisfies $S(w(x))=S(x)$, the same
algorithm applies after wrapping.\qedhere
\end{proof}

For (2), take $S$ to compute connected components: all component sizes nine
means YES support and all sizes seven means NO support.  The test is linear
in the graph representation and survives every vertex permutation.

The compiler is component-local: variable and clause gadgets introduced for
one source component do not couple it to another.  For a 6-regular source
component with $h$ vertices and $e=3h$ edges, the audited identities give
\[
 v=1008h+1188e=4572h,\qquad
 M=1344h+1584e=6096h.                                      \tag{3}
\]
Hence both sides of (2) have identical target totals
\[
 v=288036r,\qquad M=384048r,                               \tag{4}
\]
but distinct target incidence-component signatures:
\[
 \begin{array}{c|c|c|c}
 &\#\text{ components}&v\text{ per component}&M\text{ per component}\\\hline
 U(Y_r)&7r&41148&54864\\
 U(N_r)&9r&32004&42672.
 \end{array}                                                \tag{5}
\]
Thus relabelling, phase switches, clause order, and literal order cannot
hide the selected support.  This does not decide arbitrary $\Ltwo$ inputs;
it falsifies only this proposed balanced distribution.

\section{Barrier, SAME\_REALIZATION, and post-quantum audit}
\paragraph{SAME\_REALIZATION.}
Equations (3)--(5) refer to the same component-local compiler realization
used to define the candidate distribution.  No runtime is inferred from a
semantic-state count.  The separator charges graph/component access and
linear traversal; it does not assume hidden source labels.  If a future
compiler globally couples source components, it must be audited as a new
realization and the present target-side signature argument does not apply
without proof.

\paragraph{Relativization, algebrization, Natural Proofs.}
The firewall is an elementary support-recognition theorem and claims no
nonrelativizing separation.  The PC endpoint remains an algebraic proof-
system lower bound, not an arbitrary arithmetic-circuit or Turing-machine
lower bound.  No largeness/usefulness argument is promoted to a Boolean
circuit lower bound.

\paragraph{Post-quantum ledger.}
Schur squares, quadratic-relation ranks, Hilbert functions, syzygies, and
collision entropy do not repair the recognizable-support defect; using them
here would be a \textbf{FAILED TRANSFER}.  Worst-case/average-case reduction
architecture is an \textbf{ANALOGY/CANDIDATE}: it would become an exact
transfer only after a charged reduction from worst-case $\Ltwo$ to a
balanced, nonseparable samplable distribution.  Collision extraction and
special soundness are likewise candidates only if two transcript openings
yield an unconditional forbidden witness.  Hidden algebraic structure must
also be tested as a possible algorithmic weakness.
