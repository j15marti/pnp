\section{Exact target and source model}
The fixed target language remains $L_{\rm TT}$ from TWOTREEBRIDGE1/PINCORE1.
It uses an eight-bit header, unary universe size $h$, two membership vectors
and two adjacency triangles; $N=9+h^2+2h$. Invalid strings reject.
A correct total uniform decider of this one language running in polynomial
time is the hypothesis to contradict. No family broadening, universal
implementation compiler, or specified exponential rate is required.

For the literal canonical construction, PINCORE1 recovers the source graph
$\Gamma=(V,E)$ and replaces arbitrary target pins by lists
$A_v\subseteq\COL$ and two independent hub masks. Both hub masks must be
nonempty. This report takes the resulting explicit list instance and leaves
the source and every target pin available for reconstruction. Failure of
canonical-image recognition is not rejection of the full language.

Let
\[
 U=\{v:|A_v|=3\},\quad B=V\setminus U,\quad k=|U|.
\]
An empty source list immediately gives NO. Otherwise each vertex of $B$ has
one or two choices. The input is an explicit graph and three-bit lists,
with source labels and lists polynomially related to the retained encoding.
One possible dense internal serialization has unary $n=|V|$, $3n$ list bits
and $\binom n2$ adjacency bits; a fixed header gives length
$9+4n+\binom n2$. It is an internal normal form, not a redefinition of
$L_{\rm TT}$. The code validates parsed integers, lists and canonical edges.

The result must hold for every complete assignment $\alpha:U\to\COL$ on
the same instance, not merely for one tested boundary coloring. Full input
access, arbitrary polynomial workspace, compact representations, and a
witness different from any previous witness are all allowed.

\section{Build one fixed Boolean interior}
Use one Boolean choice variable $x_v$ for each $v\in B$.
For a two-element list, its two truth values select the two colors.
For a singleton list, duplicate that color in the two options and add a
unit clause fixing option zero. For every edge within $B$, exclude every
pair of options giving equal colors. Each exclusion is a clause of length
at most two. Call the conjunction $\Phi_B$.

If $\Phi_B$ is unsatisfiable, the entire source is unsatisfiable. Otherwise
build its implication graph $D_B$, including unit-clause implications.
Every clause $a\lor b$ contributes $\neg a\to b$ and $\neg b\to a$.
Reachability includes paths of length zero.

A boundary equality event $p=(u=c)$ forces neighboring interior vertices not
to use color $c$. Let $\Lambda_p$ be all Boolean literals expressing those
requirements. Fixing a complete $\alpha$ imposes exactly
\[
 \Phi_B\ \land\ \bigwedge_{u\in U}\bigwedge_{\ell\in\Lambda_{(u=\alpha(u))}}\ell,
\]
in addition to the original edges within $U$. The same interior graph is
used for all boundary colorings. It is constructed, stored and queried at
charged polynomial cost, rather than solving a new exponential problem for
each possible combination.

\section{The pair-obstruction lemma}
\begin{lemma}\label{lem:units}
Let $\Phi$ be a satisfiable 2-CNF, with implication graph $D$, and let $S$
be any finite set of unit requirements. Then
\[
 \Phi\land\bigwedge_{\ell\in S}\ell\text{ is unsatisfiable}
 \quad\Longleftrightarrow\quad
 \exists\ell,m\in S:\ \ell\leadsto_D\neg m.
\]
The two requirements may be equal.
\end{lemma}
\begin{proof}
The reverse direction is immediate: $\ell$ implies $\neg m$, contradicting
required $m$. For the forward direction, close $S$ under graph reachability,
calling the closure $C$. If $z,\neg z\in C$, choose
$\ell\leadsto z$ and $m\leadsto\neg z$ with $\ell,m\in S$.
Every implication path has its reverse-complement path, so
$z\leadsto\neg m$. Hence $\ell\leadsto\neg m$.

It remains to show that consistent $C$ extends to a model of $\Phi$.
Set all literals in $C$ true and their complements false. If a clause has
one literal set false, the implication from its true complement forces
the other literal into $C$, making that clause true. All remaining
unsatisfied clauses contain only unassigned variables. They form a subset
of the original satisfiable formula and hence have a satisfying assignment;
combine it with the fixed literals. Thus consistent $C$ permits an extension,
proving the equivalence without an assumption about any particular search order.
\end{proof}

This lemma concerns consistency of unit requirements with a fixed satisfiable
Boolean interior. It does not assert that an arbitrary incomplete coloring
of a remaining three-choice graph is decided by pairwise local checks.
The remaining three-choice variables must still be assigned compatibly.

\section{Exact polynomial boundary projection}
For each boundary guard $p=(u=a)$, create a unary exclusion if
\[
 \exists\ell,m\in\Lambda_p:\ \ell\leadsto\neg m.
\]
For distinct boundary vertices, exclude the pair $p=(u=a),q=(v=b)$ if
\[
 \exists\ell\in\Lambda_p,\ m\in\Lambda_q:\ \ell\leadsto\neg m.
\]
Complement reversal makes this condition symmetric in the two guards.
Also retain the three equal-color exclusions for every original $U$--$U$
edge. Requirements for two different colors of the same boundary vertex
cannot be simultaneously active and do not need pair exclusions.

\begin{theorem}[Exact boundary kernel]\label{thm:main}
One deterministic polynomial-time algorithm computes an impossibility flag
or a collection $\mathcal K$ of unary and binary forbidden assignments on
$U$ such that for every $\alpha:U\to\COL$,
\[
 \alpha\text{ satisfies }\mathcal K
 \iff \exists\beta:B\to\COL\ [\alpha\cup\beta
                      \text{ is a list coloring of }\Gamma].
\]
After deduplication,
\[
 |\mathcal K|\le3k+9\binom{k}{2}.
\]
Every exclusion not inherited from an original edge has a polynomial-size
implication-path certificate. Every accepted $\alpha$ lifts in polynomial
time to a coloring of the entire source and, through PINCORE1, the complete
original two-tree input satisfying its actual pins.
\end{theorem}
\begin{proof}
Construction is explicit above. The empty-list and unsatisfiable-interior
cases are handled first. A full boundary coloring selects one guard per
vertex. By Lemma~\ref{lem:units}, all their interior requirements extend
exactly when none of the constructed unary or binary conflicts is active.
The original boundary-edge exclusions handle the remaining constraints.
This proves equivalence for every $\alpha$, not just equisatisfiability of
one selected source instance.

There are $3k$ possible unary exclusions and nine pairs of colors for each
pair of distinct boundary vertices, proving the count. A nontrivial exclusion
records its two triggering interior literals and a directed path from the
first to the complement of the second. A shortest path uses at most $2|B|$
vertices. Its endpoints and every edge can be checked against the actual
source-derived implication graph. This is an explanation of a derived
constraint, not a proof that an arbitrary decider must discover or use it.

For an accepted boundary coloring, append its required units to $\Phi_B$
and run a constructive 2-SAT solver. Lemma~\ref{lem:units} ensures success.
Translate Boolean options back to source colors, check every original source
list and edge, then invoke PINCORE1's helper/hub reconstruction and check
all original target pins and edges. The input used by these maps is unchanged.
\end{proof}

\paragraph{Resource accounting.}
The base has $|B|$ Boolean variables and $O(n+m)$ clauses.
Repeated graph searches compute all reachability in polynomial time and
$O(|B|^2)$ reachability bits. Guard requirements and all tests of guard pairs
are polynomial in $n+m$; no boundary-assignment enumeration is used in the
projection algorithm. Materializing every explanation costs at most
$O(k^2|B|\log(n+2))$ bits. Dense unary/pair masks use $O(k^2)$ bits after
relabelling $U$, with its original-label map stored separately for lifting.
Source retention, path acquisition, indices, Boolean arithmetic and output
have polynomial bit costs. Python large-integer operations are not being
counted as unit-cost arbitrary-width machine instructions.

The internal 2-SAT encoding is not generally affine. For example, adjacent
lists $\{0,1\}$ and $\{1,2\}$ forbid just one pair of Boolean choices.
The earlier ROOTGLUE1 affine-domain theorem is therefore not silently used
as a Gaussian-elimination solver for this larger class.

\section{A necessary change of representation and a sharp limitation}
Take a path $u-x-v$ with $A_u=A_v=\COL$ and $A_x=\{0,1\}$.
Its exact boundary relation rejects only
\[
                  (u,v)=(0,1)\quad\text{and}\quad(1,0).
\]
It accepts equal colors and several unequal colors. It cannot be represented
on those same two full-domain vertices by either inserting or deleting an
ordinary inequality edge. Thus a graph-only contraction routine is not closed:
the output must retain general forbidden color pairs, not pretend all of
them are ordinary graph edges. The witness map still refers to the original
input graph; no uncharged conversion back to an isomorphic source is assumed.

The at-most-two-choice hypothesis is essential. With a three-choice center
and three full-domain neighbors, elimination gives the no-rainbow relation,
with 21 of 27 tuples allowed and every pair projection full. No conjunction
of unary/binary constraints on just those neighbors represents it. This is
the CORRELATIONELIM1 control, not a contradiction to the present theorem.
Auxiliary variables or other circuit forms are not forbidden to a decider.

The theorem also does not decide arbitrary $\mathcal K$ in polynomial time.
When $B$ is empty, it includes ordinary three-coloring unchanged. Even
$k$ growing without bound is not a hardness measure: all-three-choice
complete bipartite graphs retain immediate colorings. Conversely, enumerating
all $3^k$ boundary assignments is an available upper bound, not required work.

\begin{corollary}[An exact tractable parameter range]
For an explicit input of length $N$, if $k=O(\log N)$, projection followed by
boundary enumeration and one final witness lift is polynomial time and uses
polynomial workspace. For $k=0$, the whole source is solved by 2-SAT.
\end{corollary}
\begin{proof}
Compute $\mathcal K$ once, check each complete boundary assignment against
$O(k^2)$ masks, and lift the first accepted one. If none accepts, the theorem
gives NO. The cost is $\operatorname{poly}(N)+3^k\operatorname{poly}(k)$.
Enumeration can be sequential; storing all boundary assignments is unnecessary.
\end{proof}

This is an algorithmic upper bound, not a requested numerical rate for a
separation proof. The fixed-language qualitative target remains unchanged.
