\section{Additive component upper bound}
Suppose a supplied separator $S$, $|S|=s$, yields
\[
F=F_0(S)\wedge\bigwedge_{j=1}^{J}F_j(S,V_j),
\]
with pairwise disjoint $V_j$, complete shared-source exposure and every clause assigned once. Choose $H_j\subseteq V_j$ hitting every ternary clause not touching $S$, and put $h_j=|H_j|$. Such a hitting set is obtainable by a scan choosing one new variable per unhit clause; no minimum-set discovery is assumed free. Charge separator acquisition separately as $A_S$.

\begin{theorem}
The following identity is exact for both labels:
\[
\operatorname{SAT}(F)\iff\exists\sigma\in\{0,1\}^{S}\left[F_0(\sigma)\wedge\bigwedge_j\exists\eta_j\in\{0,1\}^{H_j}\operatorname{SAT}(F_j|_{\sigma,\eta_j})\right].
\]
Every leaf is 2-CNF. At most $2^s\sum_j2^{h_j}$ SCC calls suffice. With $n_j=|V_j|$ and block literal volumes $\ell_j$, word time is
\[
O\left(A_S+n+\ell+2^s\left[\ell_0+\sum_j2^{h_j}(n_j+\ell_j)\right]\right).
\]
Peak auxiliary storage is $O(n+\ell)$ words, or $O(N)$ bits, plus any larger workspace needed for separator acquisition.
\end{theorem}
\begin{proof}
A common $\sigma$ and successful local assignments give 2-CNF leaves because every ternary clause is hit. SCC decides each leaf. Local witnesses combine exactly because local variable sets are disjoint and all blocks use the same $\sigma$. Conversely any global witness restricts to successful local witnesses. Components therefore require a sum of local searches, not their Cartesian product. Given $S$, connected components, source-membership checking and hitting-set selection take $O(n+\ell)$ word operations. Each leaf scans only its block and builds one linear-size implication graph. Keep the source and partition once, process one branch at a time, and reuse its workspace. This charges unsuccessful attempts, construction and peak live storage.
\end{proof}
The formula $(z)\wedge(\neg z)$ is the minimal omitted-source falsifier: local satisfiability is not independent when $z$ is hidden.

\section{Connected ternary extension with no order amplification}
For $q\ge2$, let
\[
C_b=(z_0)\wedge(\neg z_q)\wedge\bigwedge_{i=1}^{q}D_i(b_i),\quad D_i(1)=(\neg z_{i-1}\vee z_i),\quad D_i(0)=(\neg z_{i-1}\vee\neg z_i).
\]
Introduce $s\leftrightarrow z_{\lfloor q/2\rfloor}$ by two binary clauses. For $j=1,\ldots,k$, add private blocks
\[
P_j=(x_j\vee y_j\vee u_j)\wedge(\neg x_j\vee\neg y_j)\wedge(\neg x_j\vee\neg u_j)\wedge(\neg y_j\vee\neg u_j)\wedge(s\vee\neg x_j).
\]
Set $G_{b,k}=C_b\wedge(s\leftrightarrow z_{\lfloor q/2\rfloor})\wedge\bigwedge_jP_j$. Exactly
\[
n=q+2+3k,\qquad m=q+4+5k,\qquad\ell=2q+6+11k.
\]

\begin{theorem}
$G_{b,k}$ is connected and UNSAT iff $b=1^q$. On every SAT member, all $k$ ternary clauses are irredundant. Its minimum strong backdoor into syntactic 2-CNF, under plain restriction without unit propagation, has size $k$. Nevertheless it has a deterministic $O(q+k)$ word-time algorithm with at most $4k+2$ SCC calls and $O(N)$ bits of workspace. Canonical template recognition also gives an $O(q+k)$ word-time, $O(\log N)$-auxiliary-bit decision path.
\end{theorem}
\begin{proof}
The chain, selector links and private block links make the incidence graph connected. Each $P_j$ admits $(x_j,y_j,u_j)=(0,1,0)$ for either $s$. Thus the chain label is preserved. If $b_i=0$, set $z_t=1$ for $t<i$ and zero thereafter; this satisfies the endpoints and every chain clause. If all bits are one, implications contradict the final endpoint. Extend any chain witness through the selector and private witnesses. Replacing one private witness by $(0,0,0)$ violates exactly its positive ternary clause, proving irredundancy.
The $k$ ternary supports are disjoint. A syntactic backdoor must hit each, and one chosen variable per support suffices; its minimum is $k$. After setting $s$, however, the chain is a 2-CNF component and each private component needs at most one branch variable. The call bound is $2(1+2k)$, and the weighted work is $O(q+k)$. For canonical recognition, headers give $k=(m-n-2)/2$ and $q=n-2-3k$. Scan every record against the template while accumulating the AND of orientation bits. A constant number of counters and current records suffice. Outside the recognized family a total SAT solver uses an exact fallback; recognition itself is charged.
\end{proof}

\paragraph{Surviving lower bound.}
On $G_{1^q,k}$, flipping any orientation changes the label while leaving all metadata and length unchanged. Every orientation occupies a distinct literal word. Thus every deterministic exact decider for the full language reads all $q$ such words: $\Omega(q)$ word time, not $2^{\Omega(k)}$. When $k=\Theta(q)$, this is $\Omega(N/\log N)$. A sequential bit-input head must reach a sensitive position $\Theta(N)$, giving an encoding-specific $\Omega(N)$ input-head bound. No matching bit-machine upper bound is asserted. Paid transport still requires
\[
L_{\rm old}\le R+H+Q\tau T_{\rm new}^{\le}(g);
\]
linear construction can consume the linear source bound. Direct inclusion preserves only its original order.

\section{A gradual NP-complete endpoint}
For a graph $H=(V,E)$ with $|V|=k$, assign three Boolean color variables per vertex. Use exactly-one blocks
\[
(X_{v,1}\vee X_{v,2}\vee X_{v,3})\wedge\bigwedge_{a<b}(\neg X_{v,a}\vee\neg X_{v,b}).
\]
For each edge $uv$, add only binary clauses
\[
\bigwedge_{a=1}^{3}(\neg X_{u,a}\vee\neg X_{v,a}).
\]
The resulting $\Gamma(H)$ has $n=3k$, $m=4k+3|E|$, and $\ell=9k+6|E|$, with exactly $k$ pairwise-disjoint ternary supports.

\begin{lemma}
Satisfying assignments of $\Gamma(H)$ are in bijection with proper 3-colorings of $H$. Construction uses $O(k+|E|)$ word operations and emits $\Theta((k+|E|)\log(k+|E|))$ bits in the declared layout. Explicit vertex/edge lists allow streamed output with $O(1)$ additional words. The resulting image language is NP-complete.
\end{lemma}
\begin{proof}
The local constraints select exactly one color; edge constraints forbid equal neighboring colors. These conditions are precisely proper 3-coloring, in both directions. The record counts prove construction cost. Known NP-completeness of graph 3-colorability supplies hardness; checking a Boolean assignment supplies membership in NP. Classification does not establish a superpolynomial runtime lower bound.
\end{proof}
Independent blocks, paths and cycles are linear-time cases after charged acquisition. A supplied path order admits a three-color boundary state; a cycle may retain its first and last colors, at most nine states. General graph storage/recognition remains charged. Arbitrary graph coupling is NP-complete, but $O(2^k(k+|E|))$ remains only an upper bound. Triangle is SAT and $K_4$ is UNSAT, though every vertex block is satisfiable. Disjoint ternary supports are not source independence when binary edges connect them.
