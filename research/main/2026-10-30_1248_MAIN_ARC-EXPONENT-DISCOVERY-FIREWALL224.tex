\section{Exact conditional exponent-discovery firewall}
For a fixed program $A$, write $T_A(n)$ and $S_A(n)$ for its worst-case time and simultaneous writable/index space over all length-$n$ ordinary SAT inputs in the declared machine. The theorem below uses sequentially filled work cells, so it does not depend on the disputed convention for a single far random-access address.

\begin{theorem}[Joint exponent-gap classification is undecidable]
Assume there exists one fixed uniform correct ordinary-SAT decider $B$ with
\[
 T_B(n)=O(n^\kappa),\qquad S_B(n)=O(n^\ell)
\]
for finite integers $\kappa,\ell$. Fix any integer $d\ge\max\{1,\kappa,\ell\}$. There is no total computable classifier $C_d$ which, on the code of every correct polynomial-time SAT decider promised to lie in one of the following two classes, always distinguishes them:
\[
\begin{array}{ll}
\mathrm{LOW}_d:&T_A(n)=O(n^d)\ \text{and}\ S_A(n)=O(n^d),\\
\mathrm{HIGH}_{d+1}:&T_A(n)=\Omega(n^{d+1})\ \text{and}\ S_A(n)=\Omega(n^{d+1}).
\end{array}
\tag{2}
\]
The impossibility holds even though every input code supplied to $C_d$ is guaranteed to be a total, correct, polynomial-time SAT decider.
\end{theorem}
\begin{proof}
Given a Turing machine $M$ and word $w$, effectively construct $A_{M,w}$. On an ordinary SAT input $F$ of length $n$, it simulates $M(w)$ for $n$ steps. If the simulation has halted, $A_{M,w}$ sequentially writes and visits exactly $n^{d+1}$ work cells and then erases or ignores them. Finally it runs $B(F)$ and returns precisely $B$'s answer.

Every $A_{M,w}$ is a total correct SAT decider. It is polynomial time and space regardless of $M$: the simulation costs $O(n)$ and the optional fill costs $\Theta(n^{d+1})$. If $M(w)$ never halts, the fill never occurs, so $A_{M,w}\in\mathrm{LOW}_d$. If $M(w)$ halts after $h$ steps, then on every input length $n\ge h$ the fill occurs, so $A_{M,w}\in\mathrm{HIGH}_{d+1}$. Therefore $C_d$ would decide whether $M(w)$ halts, a contradiction.
\end{proof}

\paragraph{Quantifier audit.}
The theorem is conditional on the same hypothesis used by the ARC contradiction: one baseline polynomial SAT decider exists. The reduction never receives a SAT answer bit, a satisfying assignment, $(K,L)$, or a separate program for either answer class. The one wrapper is correct on both SAT and UNSAT inputs because it always delegates the final decision to $B$. The theorem does \emph{not} say an external mathematical proof may not quantify over the actual $(K,L)$, and it does not refute an exponent-oblivious $\Phi$. It falsifies only controllers whose effective policy tries to discover an exact/tight guest exponent or a threshold predicate such as (2) from arbitrary guest code.

\begin{lemma}[Finite performance prefixes do not certify the exponent]
Fix a benchmark cutoff $N_0$. Let $M_\infty$ never halt and let $M_h$ halt for the first time after $h=N_0+1$ steps. Then the two corresponding wrapper programs above have identical wrapper behavior on every input of every length $n\le N_0$, but their asymptotic joint resource exponents are respectively at most $d$ and exactly $d+1$.
\end{lemma}
\begin{proof}
Neither bounded simulation observes a halt when $n\le N_0<h$, so neither performs the fill. For all $n\ge h$, $A_{M_h,w}$ performs the $n^{d+1}$ fill. The preceding bounds finish the proof.
\end{proof}
Thus neither a finite regression suite nor observed small-instance speed can supply the missing $K,L$ policy bit. A sound repair is structural and exponent-oblivious: prove a resource inequality for every guest execution from the compiler interface itself, or restrict the guest syntax and verify that restriction. Such a restriction must still match the arbitrary-$A$ quantifier in the intended contradiction or be labeled restricted.
