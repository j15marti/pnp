\section{CONSTRUCTION OR PROOF ATTEMPT}
A canonical complete ASCII input consists of \texttt{p t5 n m}, the explicit lines \texttt{v 0}, ..., \texttt{v (n-1)}, and all lexicographically sorted, distinct, in-range lines \texttt{a u v}, each newline-terminated, with no trailing bytes or noncanonical decimal integers. Thus $n,m\le N$, where N is complete source length. Malformed inputs reject as INVALID. A valid directed loop gives zero. The original exact integer output is
\[
Z(G)=\sum_{x\in\mathbb Z_5^n}\prod_{(u,v)\in A}[x_v-x_u\bmod5\in\{1,3\}].
\]
Construct $s\in\mathbb N$, unaries $U_v(a)$, and one correctly oriented $5$-by-$5$ integer pair factor $F_{uv}(a,b)$ per undirected pair $u<v$, combining opposite directed arcs entrywise. At every point
\[
Z(G)=s\sum_{x\in\mathbb Z_5^W}\prod_{v\in W}U_v(x_v)\prod_{\{u,v\}\in E}F_{uv}(x_u,x_v).
\tag{1}
\]
Repeatedly eliminate any current degree $\le2$ vertex z, updating for degree two
\[
F'_{ab}(i,j)=F_{ab}(i,j)\sum_{k=0}^4 U_z(k)F_{za}(k,i)F_{zb}(k,j),
\tag{2}
\]
with factor one for an absent $ab$ edge; degree one updates $U_a(i)$ by $\sum_k U_z(k)F_{za}(k,i)$; degree zero multiplies $s$ by $\sum_kU_z(k)$. Every elimination is a legitimate finite summation over the actual original witness extension, and no factor has superpolynomial length: the nonnegative entry counts at most $5^n$ partial assignments, hence $O(n)$ bits.

\begin{theorem}[Fully charged discovered-cover exact counter]
Let H be the residual simple factor graph after exhaustive degree-$\le2$ elimination; put $r=|V(H)|$, $e=|E(H)|$, $\kappa=$ number of connected components, $\beta_*=e-r+\kappa$, and $\tau$ equal to the \emph{minimum} vertex-cover size of H. There is a uniform blank-start ordinary deterministic bit-machine exact count algorithm satisfying simultaneous bounds
\[
\boxed{T(N,\tau)=O((N+1)^{12}(1+5^\tau)),\qquad S_{\mathrm{peak}}=O((N+1)^5).}
\]
No source decomposition, discovered cover, preloaded state, or oracle is supplied. In particular $\tau=O(\log N)$ yields polynomial original-source-to-output time.
\end{theorem}
\begin{proof}
Iterative deepening on k=0,1,... branches on an uncovered edge uv, adding either endpoint to C. At k=$\tau$ a successful branch exists, and prior budgets fail. The total explored binary nodes are $O(2^\tau)$. Pay for full graph scans and copies at each node; depth-first records are polynomial.
With C a valid discovered cover and I=V(H)\setminus C independent, exactly evaluate
\[
s\sum_{a\in\mathbb Z_5^C}
 \left(\prod_{u\in C}U_u(a_u)\prod_{uv\in E(C)}F_{uv}(a_u,a_v)\right)
 \prod_{w\in I}\left(\sum_{b=0}^4U_w(b)\prod_{u\in C\cap N(w)}F_{wu}(b,a_u)\right).
\tag{3}
\]
This rearranges (1) without losing integer extension multiplicities and costs $5^\tau\mathrm{poly}(N)$ exact bit operations. All source authentication, failed search nodes, factor construction, intermediate integer lengths, sequential head movement, bookkeeping and output are charged. One same execution uses polynomial storage, with the conservative simultaneous exponents stated. Every authenticated cover satisfies (3), so every verified cover for a fixed source produces the identical one correct accepted count. This is a restricted one-output certificate, not a uniform PFCERT for arbitrary computations.
\end{proof}
\begin{theorem}[Strict improvement over raw reduced-cycle exponent]
After degree-$\le2$ peeling the residual simple graph has minimum degree at least three. For nonempty H, $2e\ge3r$, hence $\beta_*\ge r/2+\kappa$. Therefore
\[
\tau\le r\le2(\beta_*-\kappa)\le2\beta_*,\qquad 5^\tau\le25^{\beta_*}.
\]
For the original complete directed source $G_n$ with three left vertices, n right vertices and every left-to-right arc, $n\ge3$, there is no peeling, $\beta_*=2n-2$, $\tau=3$, but
\[
\boxed{Z(G_n)=5\cdot 2^n+30}.
\]
The infinite generating series over $n\ge1$ is $10z/(1-2z)+30z/(1-z)$. Thus raw/reduced cycle excess can overstate compulsory computational work by an exponential factor.
\end{theorem}
\begin{proof}
The minimum-degree inequality proves the parameter comparison. For $K_{3,n}$, three left colors determine how many of the five right colors are common outgoing neighbors. Among 125 triples, five have 2 choices, thirty have 1 choice, and ninety have zero. Each of n right vertices is independently assigned, giving $5\cdot 2^n+30$ for n>=1. For n>=3 all degrees are at least three. An obvious left-side cover has size three, and a matching of size three forces it to be minimum.
\end{proof}

\paragraph{Oracle and certificate firewall.}
Let O be any legitimate oracle, the universal program interpreter $U^O$, a polynomial-time membership decider $M^O$, and every verifier query exactly the same O. For $t(n)=n^{\omega(1)}$, the set $\{x:K_U^{t,O}(x)\ge|x|-1\}$ is $P^O$-immune: if an infinite $P^O$ subset S existed, for arbitrarily large n retain the first $n-\lceil 5\log_2(n+2)\rceil$ bits of any member, encode n self-delimitingly with $2\log n+O(1)$ bits, and exhaustively search its polynomially many suffixes using $M^O$. A fixed oracle program prints a member of S within polynomial time less than $t(n)$ and description length less than n-1, a contradiction. The prefix's selection is nonuniform \emph{description existence}, not free computational acquisition.

For a BGS collapsing oracle A with $P^A=NP^A$, assume a uniform polynomial oracle verifier $V^A(1^n,p,x,\pi)$ has proofs of polynomial length, covers every true $U^A(p)$ n-bit endpoint within $t(n)$ for $|p|\le n-2$, and for each $(n,p)$ allows globally at most two output strings across \emph{all} accepted proofs. Its envelope $E_n^A=\{x:\exists |p|\le n-2,\exists\pi\ V^A=1\}$ is in $NP^A=P^A$ and has size at most $2(2^{n-1}-1)=2^n-2$. The infinite complement is $P^A$-decidable and, by coverage, contains only $K_U^{t,A}$-random strings, contradicting matched-oracle immunity. Thus universal two-output PFCERT \emph{fails} in a collapsing-oracle world; this does not prove the ordinary verifier exists or construct a nonrelativizing step. Fixed-PH checking under $P=NP$ does not supply polynomial descriptors or succinct exponentially large configurations. Nonalgebrization remains OPEN.
