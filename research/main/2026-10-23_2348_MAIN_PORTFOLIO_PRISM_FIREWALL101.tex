\section{Three falsifiable mechanisms and result}
Fix the NP-complete language of valid proper signed exact-$(2,2)$ 3-CNF:
every clause has three distinct variables, every variable appears exactly
twice positively and twice negatively, duplicates are rejected, and the
fixed addressed-word encoding uses two header words and four words per
clause.  If $n,m$ are the variable and clause counts, then $4n=3m$,
word width is
\(w=\lceil\log_2(64(n+m+1))\rceil\), and encoded bit length is
\(N=(4m+2)w\).

\noindent\textbf{M1, portfolio union (PROVED/EXACT upper bound).}
Run Role~1's complementary-pair/matching-cover decider and Role~2's
paired-support/blossom-factor decider in lockstep.  The first to halt gives
an exact answer, so either small parameter is sufficient for polynomial
time.

\noindent\textbf{M2, large-parameter necessity (FALSIFIED/RETIRED).}
A connected prism family has Role~1 defect $\delta=2q$ and Role~2 defect
$t=8q$, both linear in the source, but has an explicit linear-time witness
and a canonical polynomial recognizer.

\noindent\textbf{M3, representation extraction (FALSIFIED for the tested
bridge).} Role~3's hidden-weighted-bit image has exponential OBDD size in
every order but a polynomial source-aware exact decider.  Thus adding OBDD
size to the matching portfolio still does not yield mandatory work for an
arbitrary one-bit decider.

\section{Imported exact algorithms and a portfolio lemma}
For a valid source $F$, let $\delta(F)$ be the number of unmatched ternary
clauses after canonical complementary-pair contraction in CUBICCOVER75.
Let $t(F)$ be the number of defect clauses after BLOSSOM-FACTOR60's
canonical greedy extraction of all-positive/all-negative paired supports,
never using a source variable in more than two selected support records.
Both are computed from the source and neither is defined from observed
runtime.

The two independently reviewed total exact algorithms have charged bounds
\begin{align*}
T_1(F)&=O\!\left(m\log(m+2)+\delta^4+
  2^{\lfloor5\delta/8\rfloor}(n+m+1)\right),\\
T_2(F)&=O\!\left(N/w+m\log(m+2)+
  3^t(n+m)^3\right).
\end{align*}
The first uses a maximum matching in a cubic clause multigraph to select at
most $\lfloor5\delta/8\rfloor$ original variables and solves each branch by
SCC.  The second enumerates one source witness occurrence per defect and
uses a required-vertex weighted matching gadget on the paired core.  In both
algorithms, parsing, failed searches, construction, every rejected branch,
witness reconstruction, original-source replay and the one-bit output are
charged.

\begin{lemma}[Minimum-of-exact-algorithms portfolio; PROVED/EXACT]
If $A_1,A_2$ are total uniform deterministic exact deciders for the same
encoded language, a total uniform deterministic exact decider $A_\wedge$
simulates one step of each alternately and returns the first answer.  On
every source $F$,
\[
T_{A_\wedge}(F)\le 2\min\{T_{A_1}(F),T_{A_2}(F)\}+O(1).
\]
Its peak live space is at most the sum of the two simulated peak spaces.
\end{lemma}
\begin{proof}
After $2s$ simulator steps, both machines have executed at least $s$ steps.
The first machine to halt is exact because both machines decide the same
language.  Totality follows because both halt.  Keeping two complete
configurations proves the space statement.  No uncharged oracle call,
representation conversion or prediction of the faster branch is used.
\end{proof}

\begin{theorem}[Two-parameter union upper bound; PROVED/EXACT]
Proper signed exact-$(2,2)$ 3-SAT has a uniform total exact decider with
\[
T(F)=O\!\left(\min\left\{
m\log(m+2)+\delta^4+2^{\lfloor5\delta/8\rfloor}(n+m+1),
\;N/w+m\log(m+2)+3^t(n+m)^3
\right\}\right).
\]
It uses $O((n+m)^2+t)$ peak live words conservatively.  Consequently the
union of the regions $\delta=O(\log N)$ and $t=O(\log N)$ is polynomial-time.
\end{theorem}
\begin{proof}
Apply the lemma to the two charged algorithms.  Their declared spaces add
to the displayed conservative bound.  If either parameter is at most a
fixed constant times $\log N$, its exponential term is polynomial in $N$;
all remaining terms are polynomial.  This is an enumeration \emph{upper}
bound and says nothing about necessary work.
\end{proof}

\section{A connected easy family with both parameters linear}
For $q\ge3$, let $P_q=C_q\square K_2$ be the prism graph.  It has
$2q$ vertices and $3q$ edges.  Give every edge $e$ a variable $x_e$ and
order its endpoints.  At the lower endpoint use literal $x_e$ and at the
higher endpoint use $\neg x_e$.  For every prism vertex, emit the proper
ternary consisting of its three incident literals.

Order the $3q$ edges cyclically and add fresh variables
$y_0,\ldots,y_{3q-1}$.  For every edge $e_i$, emit
\[
(y_i\vee\neg y_{i+1}\vee x_{e_i})\quad\text{and}\quad
(y_i\vee\neg y_{i+1}\vee\neg x_{e_i}),
\]
where indices are modulo $3q$.  Call the resulting formula $G_q$.

\begin{theorem}[Prism firewall; PROVED/EXACT]
For every $q\ge3$, $G_q$ is a connected, proper, duplicate-free signed
exact-$(2,2)$ 3-CNF with
\[
n=6q,\qquad m=8q,\qquad
\delta(G_q)=2q,\qquad t(G_q)=8q.
\]
Nevertheless $G_q$ has an explicitly constructible satisfying assignment
and a canonical total exact decider runs in $O(N/w)$ word operations on
every $G_q$.
\end{theorem}
\begin{proof}
Each $x_e$ occurs once with each sign in its two endpoint clauses and once
with each sign in its two selector-cycle clauses.  Each $y_i$ occurs twice
positively in pair $i$ and twice negatively in pair $i-1$.  All supports
have three distinct variable names; graph supports are distinct; and the
two clauses for an edge differ only in the sign of $x_e$.  Thus all grammar
and exact occurrence claims follow, and $4n=3m$.

The $3q$ displayed clause pairs contract exactly to the binary cycle
$(y_i\vee\neg y_{i+1})_i$.  No other complementary pair exists, leaving
the $2q$ prism-vertex ternaries; hence $\delta=2q$.  BLOSSOM-FACTOR60 pairs
only all-positive and all-negative clauses with the same unsigned support.
Every selector-cycle clause is mixed, and distinct prism vertices have
distinct supports, so no paired support is selected and $t=m=8q$.

Orient both $q$-cycles consistently.  Every prism vertex receives an
incoming cycle edge.  Set each $x_e$ so that the literal at the head of its
oriented edge is true; set rung variables arbitrarily and set every $y_i=0$.
Each vertex clause has its incoming true literal, and every selector-cycle
clause contains $\neg y_{i+1}$.  This is a satisfying assignment constructible
by a linear scan.

Finally, a total decider parses and validates the fixed encoding, tests
whether the records equal the canonical $G_q$ template for the inferred
$q$, and returns SAT if so; otherwise it falls back to any exhaustive exact
SAT algorithm.  Recognition, source reads, witness construction and replay
are linear on the family, while the fallback establishes total exactness.
\end{proof}

\begin{countertheorem}[Large portfolio parameters are not lower bounds]
No implication of the form
\[
\min\{\delta(F),t(F)\}=\Omega(n)
\quad\Longrightarrow\quad
T_A(F)=2^{\Omega(n)}
\]
can hold for every total uniform deterministic exact decider $A$ and every
valid source $F$.
\end{countertheorem}
\begin{proof}
The left side holds on $G_q$, while the source-aware total decider in the
theorem is linear there.  The counterexample does not say that every large-
parameter source is easy; it refutes only the claimed universal per-instance
necessity.
\end{proof}
