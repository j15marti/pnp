\section{LITERATURE CHECK AND REVISIONS}
Hirahara's original ECCC TR20-050 (2020), Sec. 9/Theorem 3.9, proves $P$-immunity of $R_{K^t}=\{x:K_U^t(x)\ge |x|-1\}$ for every superpolynomial $t$. The actual proof on PDF page 29 keeps $n-\Theta(\log n)$ prefix bits and uses a polynomial-time decider to search the remaining logarithmic-length suffix. This is shortest-program time-bounded $K^t$, \emph{not} Levin $Kt=\min_p(|p|+\log t_p)$. Baker--Gill--Solovay (SIAM J. Comput. 4 (1975), 431--442) construct a recursive oracle $A$ with $P^A=NP^A$ using one consistent oracle-query-machine convention. Aaronson--Wigderson (STOC 2008) establishes the independent algebrization barrier. A--B survive in a source-matched form. C survives even when the affine datapath has one bit. D survives only on short-controller-lasso sources, not all programs. AFTER search an additional refinement was developed: a universal rational-generating-series and Hankel-rank bound on the length of certificates within this architecture.

\section{CONSTRUCTION OR PROOF ATTEMPT}
Authentic source: complete canonical encoded dimensions $r,m\ge1$, initial $(h_0,y_0)\in\mathbb F_2^r\times\mathbb F_2^m$, binary horizon $T$, explicit nonlinear Boolean gate DAG $g:\mathbb F_2^r\to\mathbb F_2^r$, Boolean mode gate DAG $b:\mathbb F_2^r\to\mathbb F_2$, two explicit affine maps $M_i(y)=A_iy\oplus c_i$, and a terminal linear readout. All source bits, gate references, matrices, initial states and $B=|\operatorname{bin}T|$ bits count toward length $L$. Malformed source is INVALID. Semantics:
\[
h_{t+1}=g(h_t),\qquad y_{t+1}=M_{b(h_t)}(y_t).
\]
The controller must be autonomous, although $g$ may be arbitrarily nonlinear. The datapath is explicitly $m$ bits and can influence future $y$, not the controller.

\begin{theorem}[Exact global terminal binding]
A witness $\pi=(v_0,\ldots,v_k)$ is accepted only if $v_0=h_0$, $v_{i+1}=g(v_i)$ for all $i<k$, the first $k$ states are pairwise distinct and $v_k=v_\mu$ for one $\mu<k$. Set $\lambda=k-\mu$. For $T\ge\mu$, set $q=\lfloor(T-\mu)/\lambda\rfloor$ and $z=(T-\mu)\bmod\lambda$. With $Q$ the first $\mu$ affine maps, $P$ the following $\lambda$-map cycle and $R_z$ the first $z$ maps of that cycle, exactly
\[
 y_T=R_z\circ P^q\circ Q(y_0).
\]
If $T<\mu$ use the initial $T$ maps. A verifier checks every phase source transition and computes the endpoint in
$O(L+kL+k^2r+km^3+m^3B)$ bit work and $O(L+kr+m^2+B)$ simultaneously live bits. It accepts \emph{exactly one} $m$-bit output globally over all accepted proofs. A witness exists of length $O(kr)$, polynomial when $k\le\operatorname{poly}(L)$; for $r\le c\log_2 L$, $k\le2^r\le L^c$ and the witness is polynomially discoverable without advice.
\end{theorem}
\begin{proof}
The authenticated first-repeat trace of deterministic $g$ uniquely specifies every phase for every horizon. The initial/cycle/tail decomposition is forced by the phase sequence; composition of two affine maps is affine and binary exponentiation computes $P^q$ exactly. Source parsing, checking, all matrix products, all switches and output are paid in the displayed bound. Every valid proof defines the same deterministic phase sequence, hence exactly the same reachable output. Global proof multiplicity does not enlarge the output image.
\end{proof}
Initiality, consecution, terminal coverage and certified singleton sparsity each follow from explicit verification; no exponentially large configuration or proof is hidden inside a polynomial state. The full output singleton can be represented by its $m$ bits and counted exactly. An arbitrary program need not have a short controller trace.

\begin{theorem}[Infinite-series Hankel certificate-length obstruction]
If the first-repeat controller lasso has $k$ distinct phases, then the observable sequence $a_t=\ell(y_t)$ has a homogeneous linear realization of dimension at most $(m+1)k$ over $\mathbb F_2$. In particular,
\[
 G(z)=\sum_{t\ge0}a_tz^t=u^\top(I-zD)^{-1}v,\quad
 \operatorname{rank}(a_{i+j})_{i,j\ge0}\le(m+1)k.
\]
Thus $k\ge\lceil R/(m+1)\rceil$ for any source-realization with infinite Hankel rank $R$.
\end{theorem}
\begin{proof}
Lift each affine map to the $(m+1)\times(m+1)$ linear map $\begin{pmatrix}A_i&c_i\\0&1\end{pmatrix}$. Construct a $(m+1)k$-dimensional block matrix $D$ routing each phase block to its next phase, with the last phase routed to the certified repeat index $\mu$. Initialize only phase-zero block at $(y_0,1)$ and let the output row select the readout coordinate from each block. Induction gives $a_t=u^\top D^tv$ for all $t$. The formal Neumann series gives $G(z)$ and every Hankel matrix factors through the dimension of $D$.
\end{proof}
\begin{theorem}[Exponential trace despite polynomial endpoint]
Take $r$-bit controller $g(h)=h+1\bmod2^r$, $h_0=0$, one-bit datapath $y_0=1$, mode $b(h)=[h=2^r-1]$, and constant affine maps $M_0(y)=0,M_1(y)=1$. Then $a_t=[t\equiv0\bmod2^r]$, so
\[
G(z)=\frac{1}{1-z^{2^r}},\quad \operatorname{rank}(a_{i+j})_{0\le i,j<2^r}=2^r.
\]
The Hankel matrix is a permutation matrix; the actual first-repeat certificate needs $k=2^r$ phases. Yet $a_T$ is computed in polynomial bit time by checking $T\bmod2^r=0$. The exponential bound applies only to explicit lasso traces and related finite linear realizations, NOT to SAT decision time or arbitrary implicit source certificates.
\end{theorem}
\begin{theorem}[Unrestricted phase is PSPACE-complete]
Binary-horizon endpoint-bit evaluation with general explicit Boolean $g,b$ is PSPACE-complete even with one datapath bit and two constant affine maps. Polynomial-space membership stores phase, data and binary clock. For hardness, use a polynomial-space deterministic TQBF decider with absorbing halts, its polynomial-size next-configuration circuit $g_w$, and mode $b$ indicating accept. Set horizon $T=2^r+1$, where $r$ bounds configuration length. After $2^r$ steps the halting bit has stabilized; the one-bit affine datapath records its value. A uniform polynomial-time exact solver for all sources would imply $P=PSPACE$; universally complete, sound polynomially verifiable \emph{exact-label} certificates would imply $NP=PSPACE$. A promise of at-most-two one-bit labels alone is vacuous.
\end{theorem}

Matched oracle: for any same oracle $O$ used by $U^O,V^O,P^O,NP^O$, let a hypothetical polynomially verified global-two-output relation cover every length-$n$ output of $U^O(p)$ produced within superpolynomial $t(n)$ by $|p|\le n-2$. The accepted set $E^O$ is in $NP^O$ and satisfies
\[
 |E^O\cap\{0,1\}^n|\le2\sum_{j=0}^{n-2}2^j=2^n-2.
\]
Coverage places its infinite complement inside $R_{K_U^{t,O}}$. Hirahara's proof relativizes under matched oracle access: from any infinite $P^O$ subset retain an $n-C\log n$ prefix and exhaustively find an accepted suffix in polynomial time, with description fewer than $n-1$ bits, contradicting its membership in $R_{K^{t,O}}$. For the BGS collapsing oracle $A$ with $P^A=NP^A$, the complement of $E^A$ is an infinite $P^A$ subset, contradiction. Thus universal relativizing PFCERT fails under these hypotheses. This is NOT universal unrelativized certificate existence. The restricted phase-lasso mechanism itself relativizes; nonalgebrization OPEN.
