\section{Exact obstruction and falsifiers}
The current obstruction is certificate-DAG composition at positive signed defect.  A default GF$(2)$ row for an uncovered source clause is valid only on completions in which that site remains default.  A later overfull-clause ticket replaces the row.  Consequently, a DAG cache key containing only positive ticket choices and remaining budget can merge nodes whose legal-completion families validate different rows.

This run tested four falsifiers.
\begin{enumerate}
\item \emph{Premature parity}: XORing all currently visible default rows is a sound ancestor UNSAT certificate.  This is falsified by an explicit valid Y6 SAT cube.
\item \emph{Positive dependencies suffice}: a cache key $(\hbox{selected tickets},\hbox{remaining budget})$ preserves every cached proof.  This is falsified by a root/skip-node collision.
\item \emph{Logical XOR measures total work}: cumulative state XOR lower-bounds every implementation's time.  DELAY, COPY and RECOMP controls falsify this without contradicting the fixed-tape cell-change lemma.
\item \emph{Finite affine terminals compose to an all-input ARC contractor}: current F9/Y6/F15/U198/V198 controls establish hereditary canonical children or numerical FLMV transport.  This remains unsupported: the children are noncanonical, acquisition and guest costs remain charged, and U198/V198 do not test the new positive-defect scope rule.
\end{enumerate}

\section{Completion-domain row theorem}
Let $s$ be a certificate-DAG prefix and let $\Omega(s)$ be the set of legal complete ticket descriptions extending $s$.  For $\omega\in\Omega(s)$ let $R(\omega)$ be the authenticated affine rows of that complete description, and let $M(\omega)$ be its source-verified solutions.

\begin{theorem}[Completion-domain scope]
A row $r$ may be installed as a semantic invariant at node $s$ only if
\[
  \forall\omega\in\Omega(s)\;\forall a\in M(\omega),\qquad r(a)=0.
\]
A sufficient replayable syntactic condition is $r\in R(\omega)$ for every $\omega\in\Omega(s)$.  An XOR derivation of $0=1$ from installed rows refutes every descendant only under this condition for every source row in its support.  Therefore, a sound memoization key for cached rows must preserve the relevant completion domain (or a proved equivalent validity domain).  Positive choices and remaining budget alone are insufficient when skipped/closed sites differ.
\end{theorem}
\begin{proof}
If every installed row holds on every source model in every legal completion, their GF$(2)$ span also holds on every such model; deriving $0=1$ proves that no model exists in the union.  Conversely, if some legal completion has a model violating a cached row, that row is not a node invariant and any contradiction using it proves at most the intersection of the row-validity domains.  Skipping a site is a negative commitment: it can make that site's default row common to all remaining completions without changing either the set of already selected positive tickets or the unspent budget.  Hence those two fields cannot distinguish all row-validity domains.
\end{proof}

This extends REFEREE263's leaf-to-prefix choice-coordinate firewall.  At positive defect, the dependency tag needs the closed/skipped-site set, an exact allowed-completion family, or another certified equivalent; recording only rows introduced by positive choices is not enough.

\section{Explicit authenticated Y6 falsifier}
Use the valid duplicate-free proper monotone 3-SAT-$(2,2)$ source
\[
123,145,246,356,\overline{124},\overline{136},\overline{235},\overline{456}
\]
and pin $x_5=0,x_6=1$.  The uncovered original source IDs are $0,1,4,5$ and the free variables are $x_1,\ldots,x_4$.  Their premature default one-true parity rows are
\[
\begin{array}{c|c}
0&x_1\oplus x_2\oplus x_3=1\\
1&x_1\oplus x_4=1\\
4&x_1\oplus x_2\oplus x_4=0\\
5&x_1\oplus x_3=1.
\end{array}
\]
Their XOR is $0=1$.  Nevertheless, exhaustive original-source evaluation finds six extensions.  For example
\[
  (x_1,\ldots,x_6)=(0,0,1,1,0,1)
\]
satisfies all eight clauses and has two true literals in original source clause $4$, so it correctly violates clause $4$'s default row and spends the permitted cost-one defect there.

Independent reconstruction gives eight complete cost-one descriptions: three exact two-true patterns at source clause $0$, one at $1$, three at $4$, and one at $5$.  Six affine systems are consistent and contain one source model each; two are inconsistent.  The six solution sets are disjoint and their union is exactly the six original-source models.  Thus the full-profile affine partition survives; only its use at unresolved prefixes fails.

For the cache collision, compare the unresolved root with the node obtained by skipping source site $0$.  Both have no selected positive ticket and remaining budget one.  At the skip node, row $0$ belongs to every one of the five remaining complete descriptions.  At the root, three descriptions select site $0$, and two real source models violate row $0$.  Hence
\[
 (\varnothing,1)_{\rm root}=(\varnothing,1)_{\rm skip0}
\]
as an unsafe key, while the cached row-validity domains differ.  Adding the closed-site set or exact completion-family identifier separates them.

The same source supplies both labels.  Adding pins $x_3=1,x_4=0$ yields no original empty clause but leaves residual original clauses $1=(x_1)$ and $5=(\neg x_1)$.  All four completions were checked and the cube is UNSAT by that source-indexed contradictory unit core.  The SAT parent has six models.  This independently checks both-label correctness without turning failure of endpoints into an UNSAT rule: original Y6 has twenty models although $0^6$ and $1^6$ both fail.
