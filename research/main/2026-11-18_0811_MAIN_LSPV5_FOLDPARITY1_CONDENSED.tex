\section{CONSTRUCTION OR PROOF ATTEMPT}
Let a canonical complete source of encoded size $N$ describe a physical Boolean tape $x$ with $2^n$ cells, $m=2^b$ contiguous equal-size buckets ($n\ge b+1$), an observed $k$-bit controller $c$, and an unobserved $d\le N$-bit address register $r$. Initial tape bits are zero except for at most $N$ explicitly listed distinct one-addresses; the binary horizon $T$ has $L=\max(1,\lceil\log_2(T+1)\rceil)\le N$ bits. Define the observation $P(c,r,x)=(c,p)$ with $p_j=\bigoplus_{a\in B_j}x_a$. Authenticated source circuits $J(c,p)\in[m]$, $H(c,p)\in\{0,1\}$ and $G(c,p)\in\{0,1\}^k$ fix the bucket, parity change and next controller. A typed adaptive selection circuit $A(c,p,r,x)$ may read live tape cells with a charged polynomial query budget and returns a within-bucket pair index. The parser constructs two distinct addresses in bucket $J$: $a=J2^{n-b}+2A,\ a'=a+1$, and imposes the only physical write primitive
\[
(x'_a,x'_{a'})=(x_a\oplus x_{a'}\oplus H(c,p),0),\qquad c'=G(c,p).
\]
Other tape bits remain unchanged; the unobserved register may update through any bounded typed source circuit. Unrestricted semantic circuit equality is NOT assumed or checked.

\begin{theorem}[All-fiber semiconjugacy]
For every well-typed source and every physical state,
\[
P(F_s(c,r,x))=\overline F_s(P(c,r,x)),\quad
\overline F_s(c,p)=\bigl(G(c,p),p\oplus e_{J(c,p)}H(c,p)\bigr).
\]
\end{theorem}
\noindent\emph{Proof.} The two distinct selected cells contribute $u\oplus v$ to their bucket before the update and $(u\oplus v\oplus H)\oplus0$ afterward. Hence the selected parity toggles by $H$ and all others stay unchanged, irrespective of how $a$ was computed or which hidden tape values were read. The controller law is source-defined. A fixed-pair instance is noninjective, because $(u,v)=(0,0)$ and $(1,1)$ collapse to the same pair when $H$ is fixed. Thus this is an exact source-local proof for a class containing irreversible, nonlinear adaptive programs, not merely invertible conjugacy or affine payloads.
\begin{theorem}[Globally unique restricted certificate]
Fix constant $a>0$ and restrict to source-typed inputs with $Q=2^{k+m}\le(N+1)^a$. For every such source and every binary horizon, a uniform constructor and verifier have polynomial bit-time and simultaneous peak-space complexity, accept exactly one terminal output $Y(c_T,p_T)$ across ALL accepted proof strings, and use $O(N+QL(k+m))$ certificate bits.
\end{theorem}
\noindent\emph{Proof.} Compute initial $p_0$ from the explicit sparse ones list. Enumerate the unique $Q$-state source-derived transition $f_0=\overline F_s$. Certify the complete functions $f_{i+1}=f_i\circ f_i$ for $L-1$ levels, then follow the set bits of the authenticated $T$ from $(c_0,p_0)$. Verify every table cell against $f_0$, every doubling equality, the initial quotient, and the unique claimed label $Y$. Induction proves initiality, all-state consecution and terminal coverage, and also proves global accepted-output cardinality one. Let $M=N+QL(k+m+1)$; even with sequential-tape linear scanning of table entries, a conservative one-execution bound is $O(M^4)$ time and $O(M)$ peak bits for constructor and verifier. This bound does NOT claim that evaluating parity of an arbitrary fully explicit $2^n$-cell tape takes polynomial time. The proof checks parity preservation symbolically from local XOR identities. A physical locally headed machine may have exponential tape-access costs; the verifier does not simulate that machine for $T$ steps.

\begin{proposition}[Truly exponential live configuration]
Choose $m=1$, $H=1$, zero initial tape, and an unobserved $(n-1)$-bit counter $r$ that visits pair $(2r,2r+1)$ and then increments mod $2^{n-1}$. After $T=2^{n-1}$ steps the tape contains exactly $2^{n-1}$ ones, all at even addresses, and its XOR parity is zero; source and parity endpoint certificate have polynomial length in $n$.
\end{proposition}
\noindent\emph{Proof.} Each pair is touched exactly once, transforming $(0,0)$ to $(1,0)$. The number of steps is even for $n\ge2$, giving final parity zero. Full tape expansion remains exponential. This is a semantic endpoint certificate, not an output for every terminal bit.

\begin{proposition}[Two exact scope barriers]
With buckets $\{0,1\},\{2,3\}$, $H=1$, and a forbidden bucket selector $J=x_0$, the tapes $0000$ and $1100$ have identical bucket parities $(0,0)$ but different next bucket parities, refuting the untyped all-fiber claim. If an arbitrary initial tape is instead $x_a=C(a)$ for an explicit Boolean circuit $C$, its initial parity is $\bigoplus_a C(a)$, the parity of satisfying assignments. Uniform polynomial initiality for ALL such circuits would imply $\oplus P\subseteq P$; no unconditional lower bound is claimed.
\end{proposition}

\noindent\textbf{Matched-oracle diagnostic.} For any fixed oracle $O$, choose a fixed universal oracle-query machine $U^O$, define plain $K_U^{t,O}$ for programs outputting $n$ bits in at most superpolynomial $t(n)$ oracle steps, and define $R^{t,O}=\{x:K_U^{t,O}(x)\ge |x|-1\}$. If an infinite $P^O$ subset existed, store the $n-C\log n$ prefix of one member, use its fixed $P^O$ decider to search polynomially many suffixes with the SAME oracle, and generate another member using fewer than $n-1$ description bits in time below $t(n)$. Contradiction. A hypothetical polynomial $V^O(1^n,p,x,\pi)$, complete for all $|p|\le n-2$ time-$t(n)$ endpoints, globally accepting at most two distinct outputs for each $(n,p)$ over ALL proofs and admitting polynomially bounded proof strings, defines $E^O\in NP^O$ with $|E^O\cap\{0,1\}^n|\le 2(2^{n-1}-1)=2^n-2$. Its infinite complement lies in $R^{t,O}$. For a BGS collapsing oracle with $P^O=NP^O$, the complement is an infinite $P^O$ subset, contradiction. The restricted fold verifier relativizes and does not claim universal coverage. Ordinary universal PFCERT and nonalgebrization stay OPEN; no cryptographic hardness is assumed.

\noindent\textbf{Controls and resource gates.} DEAD/COPY do not change observed parity if untouched, DELAY must be charged with an explicit phase clock, INTERP/RECOMP are legal alternatives and can be cheaper than tables. For one bucket with $H=1$, the direct affine shortcut $p_T=p_0\oplus(T\bmod2)$ avoids any table. DISJ/static rank is not a time lower-bound argument. Simultaneous DTISP is a positive verifier upper bound, not a forbidden-SAT point. Exponential configuration counting is not necessary execution time. Algebrization: OPEN. Public completion-time WRAPPER hash prefixes permit postdisclosure brute-force search; freshness and unpredictability do not prove a classical SAT separation. Source authentication, querying, table construction, failed attempts, bit precision, retention and output are charged within the declared verifier execution.
