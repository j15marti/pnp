\begin{center}
\fbox{\parbox{.94\linewidth}{\textbf{Executive finding.}
The same connected proper 3CNF family has one distinguishable state for its
decision-only SAT answer but $2^t$ distinguishable states for exact response to
an adversarially selected four-pin continuation.  Hence the $t$-bit online
context floor is \textbf{PROVED/EXACT} for that interface and simultaneously
\textbf{FALSIFIED/RETIRED} as a lower bound on decision-only one-child
contraction.  A uniform constant-child shrinker exists on a syntactically
recognizable closed promise class containing this family, but that class does
not contain arbitrary SAT.  General contraction, general lower bounds, and
$P$ versus $NP$ remain \textbf{OPEN}.}}
\end{center}

\section{PROPOSE: current missing lemma and four falsifiable mechanisms}
The missing constructive lemma is an unconditional, uniform, answer-preserving,
power-short successor on a closed encoded class containing arbitrary SAT, with
all discovery, generation and access costs paid.  The corresponding separation
target is a same-machine lower bound on every such successor, not merely on a
richer continuation interface.  We tested:
\begin{description}
\item[M1: online information transfers to decision contraction.]  If a
source-free summary must answer every later four-pin query, perhaps its $t$-bit
floor also obstructs a child preserving only $\operatorname{SAT}(F)$.
\textbf{FALSIFIED/RETIRED} on the exact family: all unaugmented sources are SAT
and collapse to one YES child.
\item[M2: a closed one-child architecture is already unavailable.]  Perhaps
closure or uniform recognition prevents the collapse.  \textbf{FALSIFIED} on
a restricted canonical class: parsing the grammar and emitting a fixed base is
uniform and polynomial.  Arbitrary-instance coverage remains absent.
\item[M3: compact circuits erase the information distinction.]  Perhaps the
linear circuit for the projected relation gives a sublinear source-free online
state.  \textbf{FALSIFIED} for exact future contexts: the circuit still contains
all $t$ independent sign bits.  It remains a useful compact representation.
\item[M4: polynomial source-authenticated Resolution acquisition extends to
all SAT.]  SOURCE-RUP-CHAIN164 proves acquisition on a fixed-width path-local
grammar.  The extension to unbounded branching or arbitrary incidence width is
\textbf{OPEN}; the supplied proof uses bounded block width essentially.
\end{description}

\section{BUILD I: decision-only versus contextual distinguishability}
For $t\ge1$ and $s\in\{0,1\}^t$, use variables
$z,a_i,b_i,c_i,d_i$ and define
\begin{equation}\label{eq:F}
 F_{t,s}=\bigwedge_{i=1}^t
 \bigl(z\lor(a_i\oplus s_i)\lor b_i\bigr)
 \land\bigwedge_{i=1}^t
 \bigl(\neg z\lor c_i\lor d_i\bigr),
\end{equation}
where $(a_i\oplus s_i)$ is the literal $a_i$ for $s_i=0$ and
$\neg a_i$ for $s_i=1$.  These are connected proper width-three formulas
with $2t$ clauses and $4t+1$ variables.  Every source is SAT: take $z=0$ and
$b_i=1$ for all $i$.

For $i\in[t]$, let
\[
 Q_i=(\neg a_i)\land(\neg b_i)\land(\neg c_1)\land(\neg d_1).
\]
The four pins may be compiled into sixteen proper 3CNF clauses using eight
fresh variables, as in FOUR-PIN-ONLINE-CONTEXT226.

\begin{theorem}[Decision--context separation]\label{thm:sep}
For the family in \eqref{eq:F}:
\begin{enumerate}
\item the decision vector $(\operatorname{SAT}(F_{t,s}))_s$ is constant, so
one state suffices to preserve the unaugmented decision answer;
\item $\operatorname{SAT}(F_{t,s}\land Q_i)=s_i$ for every $s,i$;
\item any deterministic source-free state from which a fixed decoder must
answer an adversarially chosen $Q_i$ has at least $2^t$ possible values, and
therefore some binary state has length at least $t$.
\end{enumerate}
Thus the contextual state complexity is $2^t$ while the decision-only state
complexity is $1$ on the same sources.
\end{theorem}
\begin{proof}
The first statement follows from the displayed witness.  Under $Q_i$, the
clause $(\neg z\lor c_1\lor d_1)$ forces $z=0$.  The $i$th left clause then
evaluates to $s_i$.  If $s_i=1$, set $b_j=1$ for $j\ne i$; all other clauses
are satisfied.  This proves the second statement.  If two distinct strings
$s,s'$ produced the same source-free state, query a coordinate on which they
differ.  A deterministic decoder would receive the same state and the same
query but would need two answers, a contradiction.  Hence the state map is
injective.  There are only $2^t-1$ binary strings shorter than $t$.
\end{proof}

\paragraph{Quantifier firewall.}
The lower bound is
\[
 \forall P\;\bigl[P(F_{t,s})\text{ must support every future }Q_i\bigr]
 \Longrightarrow \max_s |P(F_{t,s})|\ge t.
\]
It is not a statement about preprocessors required only to preserve the single
bit $\operatorname{SAT}(F_{t,s})$.  Adding the universal future-context
quantifier creates the INDEX problem.  Removing it makes all sources
indistinguishable.  Neither decoder time nor nonlinear encoding repairs this
quantifier mismatch.

\section{BUILD II: a genuine but restricted one-child shrinker}
Let $Y$ and $N$ be two fixed canonical base encodings of a satisfiable and an
unsatisfiable formula.  Define the canonical promise class
\[
 \mathcal C_{\mathrm{pin}}=\{Y,N\}\cup
 \{\operatorname{enc}(F_{t,s}):t\ge1,\ s\in\{0,1\}^t\}.
\]
The grammar in \eqref{eq:F} has a deterministic polynomial-time recognizer:
parse the header, check the canonical variable names, clause order, polarities,
and common $t$.  Define one fixed map
\[
 K(Y)=Y,\qquad K(N)=N,\qquad K(\operatorname{enc}(F_{t,s}))=Y.
\]

\begin{proposition}[Restricted strict successor control]\label{prop:K}
$K$ is uniform, deterministic, polynomial-time, answer-preserving and closed on
$\mathcal C_{\mathrm{pin}}$.  Above a threshold larger than $|Y|,|N|$, it
writes one constant-length child, hence satisfies $|K(x)|\le |x|^\lambda$ for
every fixed $0<\lambda<1$ and all sufficiently large sources in the family.
The two bases are directly solvable.
\end{proposition}
\begin{proof}
Recognition and output writing are polynomial.  Every nonbase source is SAT,
so mapping it to $Y$ preserves the answer.  The two bases map to themselves,
and every output belongs to the class.  Constant output length is eventually
bounded by every positive power of the input length.
\end{proof}

This is a real one-child contraction, not an oracle simulation.  It is also
\textbf{RESTRICTED}: $\mathcal C_{\mathrm{pin}}$ does not contain arbitrary SAT
or a proved answer-preserving reduction from arbitrary SAT.  Therefore it does
not meet the load-bearing target and implies neither $P=NP$ nor a general SAT
shrinker.  Its value is adversarial: any proposed lower-bound invariant that
still declares this decision task expensive because of its future contexts is
measuring the wrong problem.

\section{BUILD III: independent controls and peer theorem audit}
The dependency-free reproducer exhaustively checked every sign string through
$t=4$: 30 source witnesses, 98 contextual SAT instances, and exactly
$2,4,8,16$ distinct context signatures.  It also verified all eight assignments
of the four-clause unit-literal gadget and produced a 64-row exact information
table.  Two runs passed in under 1.1 seconds; the canonical payload digest is
\texttt{\seqsplit{11c64e0a6d3e4a5e4896150cbdb170ffcc981e67850f7c040f082957e7b4ac37}}.
These finite checks are \textbf{COMPUTATIONAL}; Theorem~\ref{thm:sep} and
Proposition~\ref{prop:K} have symbolic proofs above.

The unmodified FOUR-PIN-ONLINE-CONTEXT226 code reproduced 34 exhaustive
context cases, 33,824 direct full-port checks, 69,904 selector/resolution
checks, 98 readback checks and 16 gadget cells.  SOURCE-RUP-CHAIN164 reproduced
356 cofactors (245 SAT, 111 UNSAT), 32,613 UNSAT-derived lines, and independent
acceptance of all valid proof traces with three forged rejections.  Its
bounded-block theorem survives audit: eliminating a block can create clauses
only on that block and its successor, and at most $3^{2d}$ distinct
non-tautological clauses exist on a two-block window.  The proof gives
polynomial source-authenticated Resolution/RUP acquisition for fixed $d$, not
for arbitrary SAT.  Its published GitHub TeX at blob
\texttt{\seqsplit{89d79fdd6e845a3c31bf7de8c67c031435023a58}} lacks the
repository-required first report marker and final verification sentinel.  This
is a publication-protocol defect, not a mathematical counterexample.

ARC226's elementary equivalence also survives audit: on a closed SAT-complete
class with fixed YES/NO bases, existence of the charged uniform strict
successor is equivalent to SAT in P.  Its ordinary-resolution coverage route
is blocked by Haken.  The supplied program reproduced all tiny PHP/2SAT and
forged-proof controls, but finite DPLL proof sizes do not establish Haken's
asymptotic theorem.

\section{SAT/UNSAT, representation and machine ledgers}
The unaugmented family has only SAT sources, so it cannot establish side-specific
worst-case bounds $T_-,S_-,Q_-,B_-$ for general SAT.  The contextual instances
contain both answers, but one fixed decoder handles them: $s_i=1$ gives SAT and
$s_i=0$ gives UNSAT.  No side bit is supplied.  With the source present, the
decoder reads the requested sign; with it absent, the retained state pays the
$t$-bit INDEX cost.  This is information acquisition for a supplied query, not
a post-acquisition decision lower bound.

\end{tabular}
\end{center}

An explicit pairwise resolvent CNF may use $\Theta(t^2)$ clauses while the
factored projection has an $O(t)$ circuit.  The circuit does not make the
source-free contextual state sublinear because it must encode all sign choices.
Conversely, that $t$-bit floor does not stop constant decision output.  Thus
explicit CNF, circuit, online data structure and decision child are four
different interfaces.  Succinct-output substitution is rejected unless the
next recursive algorithm accepts and evaluates that representation with all
costs charged.

Schur-square, quadratic-relation, syzygy and cryptographic binding methods are
\textbf{FAILED TRANSFERS} here: the exact obstruction is the elementary INDEX
row count, and the decision countercontrol destroys it.  Knowledge compilation
is an \textbf{ANALOGY/CANDIDATE} beyond the exact query/succinctness distinction;
no general SAT contraction theorem is imported.

\section{DUPLICATION / CONTRADICTION AUDIT}
The $2^t$ context-state floor duplicates the core FOUR-PIN226 theorem and is
used here as independently verified input, not claimed as new.  The new
synthesis contribution is the explicit closed-promise strict successor and the
formal non-transfer theorem from contextual to decision state complexity.
FULLPORT225 already observed informally that all sources can map to a fixed YES
base; this report promotes that observation only for the exact restricted
class with recognition, closure and termination written out.  It does not
contradict SOURCE-RUP-CHAIN164: one theorem is an online information floor, the
other is polynomial proof acquisition on a supplied bounded-width grammar.

\section{WHAT CHANGED RELATIVE TO ROOT MAIN}
Root MAIN201 correctly kept full-port information floors separate from general
SAT.  The living synthesis should now state the stronger firewall explicitly:
context-complete state complexity can be exponential in distinguishable states
while decision-only state complexity is one on the same sources.  It should add
SOURCE-RUP-CHAIN164 as a restricted constructive positive control, retain
ARC226's contraction equivalence, and keep arbitrary-instance coverage,
effective oracle synthesis and general lower bounds OPEN.

\section{ADOPTED / REJECTED / RETIRED PRIOR COMPONENTS}
\textbf{Adopted:} the static connected-interface coverage theorem under its
exact hypothesis; FOUR-PIN226's online INDEX theorem; SOURCE-RUP-CHAIN164's
fixed-width path-local DP/Resolution acquisition; ARC226's uniform-successor
equivalence; Darwiche--Marquis's query/succinctness distinction.
\textbf{Rejected:} treating target-dependent oracle contents as classically
constructible; importing Coq simulation as a native exponent; using a compact
circuit as a free recursive child; using context floors as decision floors.
\textbf{Retired:} any proof arrow ``all-context information floor $\Rightarrow$
decision-only SAT contraction lower bound'' without a theorem that the
successor must support those contexts.
