\section{CONSTRUCTION OR PROOF ATTEMPT}
\paragraph{Authenticated source and ordinary computation.}
For every canonical source $S$ of length $N$ with fields
$n,T,d,seed,i$, require $1\le n\le N$, binary $T$ and $n$-bit
$i$, sorted distinct at-most-$N$ seed coordinates,
$1\le r=|d|\le\lfloor\log_2 N\rfloor$,
$1\le d_h\le N^2$. Reject noncanonical sources as NOT\_CERTIFIED.
Let $L=2^n$ and
\[
R_L=\mathbb F_2[z]/(z^L-1),\quad
F(z)=\prod_{h=1}^r(1+z^{d_h}),\quad
X_0(z)=\sum_{j\in seed}z^j,\qquad X_{t+1}=FX_t.
\]
The output is one bit $(X_T)_i$. A fixed ordinary multi-tape
interpreter executes one synchronous macrotransition in
$O(rL^2\operatorname{poly}(N))$ microsteps with
$O(L+\operatorname{poly}(N))$ workspace. Thus the original physical
run may be exponentially wide and long, while the following
\emph{different} source-checking algorithm is polynomial.

\begin{theorem}[Exact carry recurrence]
For $0\le T<L$ and $a\in[0,L)$, let $C=\sum_hd_h$.
Write $T=\sum T_b2^b$ and $a=\sum a_b2^b$.
Initialize $v_0(0)=1$, $v_0(c)=0$ otherwise, and compute
\[
v_{b+1}(c')=
\bigoplus_{\substack{0\le c\le C,\ e_h\in\{0,T_b\}\\
c+\sum_hd_he_h\equiv a_b\pmod2\\
(c+\sum_hd_he_h-a_b)/2=c'}}v_b(c).
\]
Then $[z^a]F(z)^T=\bigoplus_{c=0}^C v_n(c)$.
The recurrence has at most $C+1$ states per bit position,
and costs $O(n(C+1)r2^r\operatorname{polylog}(C+2))$ bit operations.
\end{theorem}
\begin{proof}
In characteristic two,
$(1+z^{d_h})^T=\prod_{b:T_b=1}(1+z^{d_h2^b})$.
Each monomial corresponds to binary selections
$e_{h,b}\in\{0,T_b\}$ and contributes to exponent $a$
iff the weighted sum is congruent to $a\bmod 2^n$.
The displayed recurrence is ordinary base-two addition with
carry $c$. Starting at zero, $c'\le(c+C)/2\le C$.
The final carry is unrestricted because equality is modulo $2^n$.
XOR preserves the parity of coincident monomials.
\end{proof}
\paragraph{Nilpotence and actual exponential output.}
Since $(1+z^d)^{2^n}=1+z^{d2^n}=0$ in $R_L$,
$F^{2^n}=0$. For $T\ge L$ every endpoint is zero.
For $r=d_1=1$, $seed=\{0\}$ and $T=L-1$, the
\emph{entire} terminal state is
$\sum_{a=0}^{L-1}z^a$, containing $2^n$ one bits.
Only point-query access is polynomial; total expansion is not.
\begin{theorem}[Globally singleton source certificate]
For each admissible canonical source $S$ there exists a
polynomial-length DP-row certificate $\pi$ verifying the selected
terminal bit. Every accepted certificate (not just each individual
proof) has the same output:
\[
\left|\{y:\exists\pi\;V(S,y,\pi)=1\}\right|=1.
\]
The complete source, intermediate rows, parity output and
source-binding identifier are checked; the verifier also caps
accepted proof length at $64(N+1)^6$. Since
$C\le N^2\lfloor\log_2N\rfloor$ and $2^r\le N$,
generation and verification are polynomial in $N$.
\end{theorem}
\begin{proof}
For each seed coordinate $j$ run the exact carry recurrence
at target $(i-j)\bmod L$ and XOR the resulting coefficients.
Store every initial/intermediate/final row. The verifier recomputes
the same deterministic recurrence and rejects altered rows or output;
the $T\ge L$ branch uses the nilpotence identity.
The globally accepted output set is the syntactic singleton
$\{(X_T)_i\}$. No existential union of sparse descriptors is used.
\end{proof}
\paragraph{Inductive invariant and its exact limitation.}
Define $q_S(t,j)=[z^j]F^tX_0$, evaluable by the recurrence,
and $I_S(t,X):\forall j<L,\ X_j=q_S(t,j)$.
Initiality follows from $F^0=1$; consecution from
$F^{t+1}=FF^t$; terminal coverage from the selected coordinate.
The grammar and these identities are verifiable without expanding
a state. Arbitrary-state membership in $I_S$, however, is
NOT claimed polynomial in $N$ because the given $X$ has $L$ bits.
The class is nonadaptive affine and not universal-machine complete.

\paragraph{Explicit matched-oracle PFCERT obstruction.}
For every oracle $O$ and a polynomial-overhead universal oracle
machine $U^O$, Hirahara's suffix search also works with all
machines using $O$: for a $P^O$ decider $M^O$ of an infinite subset
of $R_{K^{t,O}}$, keep $n-m$ bits of an accepted word and enumerate
$2^{m}$ suffixes, $m=(c+5)\log_2 n$. The same-oracle short program
outputs an accepted word in polynomial time with description
length $n-m+2\log n+O(1)<n-1$. Any
$t(n)=n^{\omega(1)}$ eventually dominates its runtime, contradiction.
With $O=\mathrm{TQBF}$, $P^O=NP^O$.
If a uniform oracle verifier covered every length-$n$ endpoint of
all $|p|\le n-2$, with at most two accepted outputs for fixed
$(n,p)$ globally over all proofs, its accepted union
$E_n^O\in NP^O$ has at most
$2(2^{n-1}-1)=2^n-2$ elements.
Its infinite $P^O$ complement lies in the $P^O$-immune
$R_{K^{t,O}}$, contradiction.
This is a barrier to a \emph{universal} relativizing PFCERT,
NOT an ordinary PFCERT construction or a proof of $P\ne NP$.
