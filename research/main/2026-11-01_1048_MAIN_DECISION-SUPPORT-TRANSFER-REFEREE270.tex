\begin{theorem}[CUBEKEY promise collapse]
Every one of the $84^t$ coherent two-pin CUBEKEY306 residuals of $G_t$ is satisfiable.  Consequently, on the prevalidated promise its decision function is constant SAT and needs no pin-value queries.  Rejecting malformed pin records or authenticating membership is a separate paid parsing task.
\end{theorem}
\begin{proof}
The following six complete assignments, written in $x_1\ldots x_9$ order, all set $x_5=0$, satisfy every original $F_9$ clause, and collectively realize all four value pairs on every pair of names in $E$:
\[
\begin{array}{cccccc}
001101001&011001101&100000111&101100010&110001010&110100100.
\end{array}
\]
The source-clause check is direct.  The pair-cover assertion is a finite $\binom72 2^2=84$ table and was independently rechecked without importing the producer.  For each block choose a listed assignment matching its two pins.  Since every chosen assignment has $x_5=0$, the cyclic splice replaces a zero by the next block's zero; every cross-block clause has exactly the same truth value as its checked $F_9$ clause.  The block assignments therefore combine into a full satisfying assignment of $G_t$.
\end{proof}

This is a direct falsifier of assignment-recovery hardness.  A constructive algorithm may output the selected block witnesses in $O(t)$ records, but a decision algorithm does not have to recover or store them.

\section{Exact Boolean support transfer}
For any coherent block-local pin state $p$, let
\[
 M_p(a,b)=\#\{\hbox{internal completions satisfying the block}\mid x_{5,i}=a, x_{5,i+1}=b\}.
\]
Let $R_p(a,b)=1$ iff $M_p(a,b)>0$.  Nonnegative matrix multiplication gives
\[
 \operatorname{SAT}(G_t,p_1,\ldots,p_t)
 \iff \operatorname{tr}_{\mathbb B}(R_{p_1}\cdots R_{p_t})=1,
\]
where multiplication is over the Boolean semiring.  A single current product is four bits; there are at most $16$ continuation relations.  On the 84-state CUBEKEY alphabet the exhaustive exact table contains 82 distinct integer count matrices but only three support relations,
\[
1100\ (2\hbox{ states}),\qquad1101\ (1),\qquad1111\ (81),
\]
and every relation contains transition $0\to0$.  This independently recovers the preceding theorem and displays the difference between counting, continuation equivalence and current decision equivalence.

After paid authentication of the fixed $G_t$ grammar and grouped pin records, a uniform streaming implementation performs one constant lookup and one Boolean $2$-by-$2$ multiplication per block.  Its work is $O(N_{\rm source}+t)$ under a bit-addressable source accessor and its live semantic state is four relation bits plus $O(\log N)$ indexing and parser/proof state.  This is an exact automaton/transfer theorem for this recognized family, not a free semantic quotient for arbitrary target originals.  Nerode continuation equivalence is the exact automata-theoretic analogy; the missing all-input bridge is a uniformly acquired bounded-index congruence for every target source.

\section{The A/B pin lower bound is valid and tight}
Direct enumeration gives
\[
 W_A=\begin{pmatrix}1&1\\0&0\end{pmatrix},\qquad
 W_B=\begin{pmatrix}0&0\\0&0\end{pmatrix}.
\]
Thus an A/B word is satisfiable iff every block is A: the promise decision function is exactly $\mathrm{AND}_t$ after coding A as one.  On $A^t$, for each block $i$ the one-B opposite-label input differs only in the disjoint pair of pin cells $(x_{2,i},x_{3,i})$.  Any deterministic exact transcript must query at least one cell from each pair, hence at least $t$ pin cells.  Reading $x_{2,i}$ once per block attains the bound.  The SAT-side certificate has $t$ bits while an UNSAT-side certificate is one observed B bit.  No lossless pin-name key or assignment transcript is involved.

The result cannot be made asymptotically cheaper in this exact deterministic bit-query model.  It also cannot be promoted to a superlinear source-work bound: authenticating the explicit input is already linear, and a general $N$-bit source can be read in $N$ bit probes.

\section{Independent audit of LSPV-4 grammar floor}
LSPV-4 ALLINPUT-YES-GRAMMAR-WORK-FLOOR308 is accepted at its stated scope.  In its explicit grammar, flipping one unread whole-clause polarity bit of a valid SAT original preserves headers and variable IDs but changes each of the clause's three variables from quota $(2,2)$ to $(1,3)$ or $(3,1)$.  The neighbor is malformed and must be rejected.  Therefore every accepting transcript that is correct on malformed strings reads all $m=4n/3=\Omega(N/\log N)$ polarity cells.

This is a grammar/malformed-rejection floor, not SAT-versus-UNSAT hardness on a promise of valid originals.  If malformed strings are excluded from the domain, those one-bit neighbors are unavailable.  The adversary also gives no symmetric UNSAT-input floor because an UNSAT source and its malformed neighbor are both rejected.  It remains below the linear input-read ceiling and supplies no FLMV contradiction.
