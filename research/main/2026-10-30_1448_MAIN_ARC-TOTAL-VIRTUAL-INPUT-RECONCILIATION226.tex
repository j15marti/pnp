\section{Claim card and falsifiers proposed first}
\textbf{Single target.} Decide whether ordinary input-head moves after an out-of-range indexed jump are a genuine missing arrow in the arbitrary-$A$ virtual-child transfer, or only a defect of partial/materialized implementations.

\begin{description}
\item[Quantifiers.] For every fixed total deterministic indexed random-access ordinary-SAT decider $A$, every source $x$, and every fixed complete child map $G$ satisfying the stated total-access contract, construct one fixed same-model machine that exactly simulates $A(G(x))$ on both source labels.
\item[Machine.] The indexed read-only-input random-access Turing-machine model in FLMV Section 2.1. Input/output tapes are space-exempt; every work and index tape is charged. The guest $A$, compiler, accessor, source, child, and simulation are one realization.
\item[SAME\_REALIZATION.] The source $x$, exact logical string $G(x)$, guest execution $A(G(x))$, retained compiler state, accessor scratch, logical input-head coordinate, and final answer all belong to the same run.
\item[F1.] A far indexed jump followed by ordinary left moves and re-entry falsifies even a complete total virtual accessor.
\item[F2.] A single sticky ``out of range'' state, or an accessor defined only on $[0,|G(x)|)$, suffices.
\item[F3.] Exact simulation requires a free best-policy oracle, a supplied SAT label, or advance knowledge of the guest time exponent $K$.
\item[F4.] If the simulation theorem holds, it supplies the missing power-short ARC contractor.
\end{description}

F1 and F3 are false under the total-access hypotheses below; F2 is false by a seven-operation counterexample; F4 is false because input emulation does not construct a smaller child. The weakest useful repair is to require an exact logical length and a \emph{total} child-symbol accessor returning the standard blank symbol outside the child interval.

\section{Exact total-accessor transfer}
Let $x$ be an $N$-bit source. A \emph{complete logical child contract} consists of:
\begin{enumerate}
\item an exact length $m(x)$ computed uniformly within time $P(N)$ and retained workspace $U(N)$;
\item a valid complete ordinary input string $G(x)\in\Sigma^{m(x)}$ (not a promise fragment or succinct object substituted for the input);
\item a total function
\[
 \widehat g(x,j)=
 \begin{cases}G(x)_j,&0\le j<m(x),\\ \blank,&j\ge m(x),\end{cases}
\]
computed in time $R(N)$ and scratch $V(N)$, including source probes, address arithmetic, grammar decoding and the length comparison;
\item exact both-label semantics when the contract is used as a reduction: $G(x)\in\SAT\Longleftrightarrow x\in\SAT$.
\end{enumerate}
The blank convention is the ordinary finite-input-tape convention. A different left-end or alphabet convention must be compiled explicitly.

\begin{theorem}[Complete total virtual-input transfer]\label{th:total}
Fix a deterministic total indexed random-access machine $A$. If $A$ takes time $T(m)$ and counted workspace $S(m)$ on every ordinary input of length $m$, then under the complete logical child contract there is one fixed same-model machine $\widetilde A_G$ that returns exactly $A(G(x))$ and satisfies
\[
 T_{\widetilde A_G}(N)
 =O\!\left(P(N)+T(m)\bigl(R(N)+\log(m+T(m)+2)\bigr)\right),
\]
\[
 S_{\widetilde A_G}(N)
 =O\!\left(U(N)+V(N)+S(m)+\log(T(m)+2)\right).
\]
All source access, failed guest computation, guest work/index tapes, accessor scratch and retained compiler state are counted. The construction does not know a time exponent $K$, a SAT answer bit, or a best policy.
\end{theorem}

\begin{proof}
Compile the fixed transition table of $A$ into $\widetilde A_G$ and simulate all guest work and index tapes in the declared model. In addition maintain in binary the exact logical position $h$ of the guest input head. On an indexed input move, copy the guest input-index contents into $h$ before performing the guest-specified erasure. On each ordinary left/right input move, decrement/increment $h$ (respecting the left end). On an input read, compare $h$ with the exact $m(x)$ and return $\widehat g(x,h)$; therefore every out-of-range read is blank and a later ordinary-move re-entry is handled automatically.

If the guest input index uses at most $S(m)$ live bits, any indexed destination has at most that many bits. During at most $T(m)$ subsequent ordinary moves,
\[
 \operatorname{bitlength}(h)\le S(m)+\lceil\log_2(T(m)+2)\rceil+O(1).
\]
The duplicate logical coordinate changes space only by a constant multiple of guest space plus $O(\log T)$. Binary comparison/update costs $O(\log(m+T+2))$ per guest step; a guest input read additionally invokes the fully charged accessor. No advance time bound is used by the machine: the displayed $T$ enters only the analysis. This is the explicit input-head implementation of FLMV Section 3.1's on-demand simulation. Exact transition induction proves equality of every guest-visible state and hence of both YES and NO answers.\end{proof}

\paragraph{Exponent ledger.}
For at most $N^{\gamma+o(1)}$ serial children of length $m\le N^{\lambda+o(1)}$, discovery/setup exponent $\alpha$, per-child selection exponent $\zeta$, accessor exponent $\delta$, retained/scratch exponents $\sigma,\eta$, and guest pair $(K,L)$, Theorem~\ref{th:total} yields the sufficient virtual ledger
\[
 K'\le\max\{\alpha,\gamma+\zeta,\gamma+\delta+\lambda K\},\qquad
 L'\le\max\{\sigma,\eta,\lambda L,0\},
\]
with source scanning, failed calls, joins, ancestor retention and reconstruction added to the corresponding declared terms. This is simultaneous same-run accounting, not borrowing independent extrema. A DELAY wrapper simply increases the actual $T$ term. COPY, INTERP and RECOMP are simulated as written. No unknown $K$ is supplied to the controller.

\section{What the theorem does and does not close}
\begin{itemize}
\item \textbf{KNOWN THEOREM; PROVED/EXACT explicit formulation.} Once exact length and a total accessor exist, far jumps, ordinary moves, re-entry, long live input positions and blank reads are not a remaining arbitrary-$A$ model bridge. The recent statement ``complete arbitrary-$A$ input simulator OPEN'' is too broad under these hypotheses.
\item \textbf{Still valid counterexamples.} Redirecting guest input moves to a materialized work tape can create enormous charged work positions. Sticky-OOB and valid-domain-only accessors are extensionally wrong. These falsify partial emulators, not Theorem~\ref{th:total}.
\item \textbf{Still OPEN.} Nothing here constructs $G$ with a fixed power shrink $\lambda<1$ on every ordinary SAT source, verifies hereditary closure, pays adaptive policy discovery/switching, or supplies exact joins. LSPV-2's composed virtual strict22 compiler has an explicit accessor but expands by a polylogarithmic factor rather than contracting. LSPV-3's direct-cofactor calculation remains restricted and requires near-$2n/3$ pinning plus source-NO coverage.
\item \textbf{No affine promotion.} AFFINE-SMALLBIAS-DESCENT-GATE2 remains a restricted semantic/MCSP no-go and is not a SAT runtime theorem. The present transfer relativizes and merely transports a supplied computation.
\end{itemize}

\section{Finite same-source both-label audit}
The Python standard-library reproducer constructs a fixed-width proper 3CNF encoding and an exact formula-bit accessor that never stores the encoded child. Controls are a satisfiable proper 3CNF with six models and the eight-clause all-sign-pattern formula with zero models. Exhaustive truth tables authenticate both labels; no answer bit is given to the simulator.

For each source, every guest trace of length at most five over
\[
 \{L,R,\mathrm{READ},J_0,J_{m-1},J_{m+3},J_{2m+5}\}
\]
was compared between a physical input and the total virtual accessor. A seeded set of 5,000 length-20 traces per source was added. Guest checksums and work state depend on every read. All 49,216 comparisons had identical complete states. A trace that reads blank at $m+3$, moves left four times, and reads position $m-1$ gives two explicit sticky-OOB counterexamples; a valid-domain-only accessor raises on both sources.
