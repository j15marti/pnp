\section{Exact obstruction and four falsifiers}
The only target remains all valid proper duplicate-free D\"ocker monotone
3-SAT-(2,2) originals: every source clause has three distinct literals of one
sign, and every original variable occurs exactly twice with each sign.
Malformed strings reject.  Residual circuits and Tseitin clauses are not
canonical children.

\textbf{Universal obstruction.}  A claim that every exact decider must acquire
a chosen forward circuit, OBDD, Shannon DAG, cofactor quotient, or semantic
cache is already too strong if an unbounded both-label subset of canonical
source strings can be authenticated and decided before that acquisition.
This does not refute a worst-case lower bound on a different subset.

\begin{enumerate}
\item \emph{Every canonical input must compile $C_F$ before decision.}
  \textbf{FALSIFIED} on the family below.
\item \emph{Every canonical input must discover exact continuation
  equivalence.}  \textbf{FALSIFIED} on the same family; the current label is
  obtained without a future-pin table.
\item \emph{A large chosen OBDD/cofactor object on a source lower-bounds every
  decider on that source.}  \textbf{FALSIFIED} as a mandatory-work statement,
  because the recognizer never constructs the object.  No claim is made that
  this family has an OBDD lower bound.
\item \emph{An infinite easy family refutes worst-case canonical SAT
  hardness.}  \textbf{FALSIFIED}: it only separates every-input necessity from
  worst-case or complexity-core claims.
\end{enumerate}

\section{Exact same-source theorem}
Let $U$ be the authenticated 198-variable, 264-clause D\"ocker original with
the independently replayed six-module UNSAT certificate.  Let $V$ be the
same source with the authenticated two-occurrence swap; its stored 198-bit
witness satisfies all 264 original clauses.  Let $Z$ be the canonical
six-variable, eight-clause paired-NAE block with 18 models.  For $t\ge0$ use
fresh consecutive original names for $t$ disjoint copies of $Z$ and define
\[
 R_t^- = U\wedge Z_1\wedge\cdots\wedge Z_t,
 \qquad R_t^+ = V\wedge Z_1\wedge\cdots\wedge Z_t .
\]
The theorem concerns the declared block serialization: the fixed base records
come first, followed by the eight records of each consecutively renamed $Z$
block.  Other legal serializations fall through to the exact fallback.

\begin{theorem}[Recognizable both-label source-family bypass]
Every $R_t^\pm$ is a valid proper duplicate-free D\"ocker monotone
3-SAT-(2,2) original with
\[
 n_t=198+6t,\quad m_t=264+8t=4n_t/3.
\]
$R_t^-$ is UNSAT and $R_t^+$ is SAT.  A deterministic streaming template
recognizer decides the declared family after $\Theta(m_t)$ source-record
comparisons, using only fixed templates and $O(\log n_t)$ counters.  It does
not construct $C_F$, PG/Tseitin clauses, an OBDD, a Shannon/cofactor DAG,
semantic representatives, assignment-recovery keys, or a variable-value
store.  Composed with any total exact fallback, it is a correct all-input
decider and bypasses all those representations on the recognized family.
\end{theorem}
\begin{proof}
Disjoint fresh renaming preserves three distinct same-sign literals,
duplicate-freedom and the exact two-positive/two-negative quota.  The displayed
count identity follows blockwise.  Every $R_t^-$ contains $U$, so is UNSAT.
The stored witness for $V$ concatenated with any fixed witness for each $Z_j$
satisfies $R_t^+$.  A parser compares the first 264 triples against $U$ or
$V$, then compares each next block against the arithmetic rename of the fixed
$Z$ template.  Exact template equality itself authenticates every record and
quota of a recognized string.  On a mismatch, the algorithm runs the paid
fallback; hence recognition cannot create a wrong answer.  Only counters,
the current record and constant templates are live in the abstract streaming
implementation.  The supplied Python implementation materializes its input
and therefore pays $O(N)$ host memory; that implementation detail is not
silently promoted to the streaming bound.
\end{proof}

This is an infinite, unbounded-length, both-label counterexample to
\emph{mandatory representation acquisition}, not an easy-subfamily argument
against worst-case hardness.  The distinction matches the classical
complexity-core and instance-complexity warnings in
\cite{lynch1975,orponen1994}.

\section{Fully charged recurrence and exact gap}
For strict source authentication and recognizer $R$, fallback $A$, and output
cost, the actual decision recurrence is
\[
T_D(F)=T_{\rm parse}(F)+T_R(F)+
\begin{cases}
 T_{\rm out},&R(F)\in\{0,1\},\\
 T_A(F)+T_{\rm guest/access/out},&R(F)=\bot.
\end{cases}
\]
All source bits, clause and literal IDs, grammar work, comparisons, index/head
moves, failed recognition, and output are paid.  On recognized members no
guest launches and no DELAY/COPY/RECOMP state exists.  On nonmembers the full
fallback runtime and simultaneous parser/index/guest peak remain charged.
Constructive SAT output can concatenate the stored $V$ witness and $t$ fixed
$Z$ witnesses; a constructive UNSAT interface can emit the fixed $U$
certificate plus conjunction provenance.  Emission and checking are linear
in the written artifact and are not free.  Decision-only output needs neither.

The source-private forward count is only a restricted representation count.
The after-answer constant 0/1 circuit is not used.  REFEREE288's independent
published all-input $d=4$ source fallback $O^*(1.2628^n)$ remains available
\cite{peng2023}; it is exponential and supplies no lower bound.

\textbf{Exact gap.}  No polynomial-total-work solver for every valid original,
no representation-independent superpolynomial lower bound, no arbitrary
correct-$A$ power-short $A\mapsto\Phi(A)$, and no strict same-machine numerical
FLMV transfer is proved.  The recent OpenAI counting preprint remains
conditional pending independent mathematical review and is not used here.
