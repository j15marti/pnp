# LOCALITY-BOUNDARY3: Polylog-Space Remote Points and the Horn/2SAT Succinctness Jump

**Status:** Two substantive advances.  
(1) The KPI remote-point construction for Boolean locality two admits a direct polylogarithmic-workspace implementation, with quasipolynomial time, by replacing stored spectral computations with trace-moment streaming.  
(2) The most obvious way to raise the explicit 2-local range-membership problem from NL-like behavior to P-hard behavior crosses a sharp succinctness boundary: Horn-style deterministic propagation is P-complete explicitly but EXPTIME-complete under circuit-succinct encoding.

No P-vs-NP or P-vs-PSPACE separation is claimed.

**Date:** 2026-10-18

---

## 1. Context

UNIFORM-LOCAL-DIAG2 produced a representation model with two desired properties simultaneously:

\[
\text{polynomial-scale unconditional hard strings}
\]

and

\[
\operatorname{succ}(M)\in PSPACE.
\]

The model was Boolean 2-local range membership. Its explicit language, however, sits in NL because every output constraint is a 2-CNF relation.

Two questions remained:

1. Can the KPI remote-point construction itself be carried out in polylogarithmic writable space?
2. Can we enrich the local constraints enough to make the explicit problem P-hard while keeping the succinct problem in PSPACE?

This note gives a positive answer to the first question for locality two and a precise barrier for the most natural approach to the second.

---

## 2. KPI locality-two remote points can be streamed in polylogarithmic space

Korten-Pitassi-Impagliazzo (KPI) prove that for even locality \(t\), a sufficiently stretched local generator admits a deterministic remote-point algorithm.

For Boolean locality two, write

\[
G:\{0,1\}^{S}\to\{0,1\}^{M}
\]

with every output bit computed by a depth-two adaptive decision tree.

Their Theorem 4 gives a polynomial-time remote-point algorithm whenever, up to the fixed constant and polylogarithmic factors in the theorem,

\[
M\gtrsim S\log S.
\]

The published proof does not state a space bound.

### Theorem 2.1: POLYLOG-REMOTE2

For fixed \(\varepsilon>0\), the locality-two specialization of the KPI remote-point construction can be implemented using

\[
\boxed{
O(\log^2(M+S))
}
\]

writable bits, with quasipolynomial running time, while emitting the selected \(M\)-bit remote point sequentially.

The same implementation works for a random-access explicit description of the depth-two decision trees, provided every tree record/address can itself be generated in \(O(\log(M+S))\) workspace.

### Why quasipolynomial rather than polynomial time?

KPI use fast polynomial-time linear-algebra routines to compute the relevant spectral norms. For the workspace theorem we instead stream the trace-moment expansion directly. This raises time but keeps the live state polylogarithmic.

That trade is acceptable for META-LIFT's virtual-input use, where the load-bearing resource is workspace.

## 3. Workspace audit of the KPI proof

KPI's proof of Theorem 4 has four algorithmic stages.

### Stage A: Correlation/XOR schemes

Their Theorem 17 converts a time-\(t\), word-\(w\) local generator into at most

\[
2^{tw+1}
\]

XOR schemes.

For \(t=2,w=1\), this is a constant number.

An entry of any scheme can be regenerated by:

1. holding an output coordinate;
2. reading the constant-size depth-two decision tree of that coordinate;
3. holding the branch pattern and the at most two referenced seed addresses.

This requires

\[
O(\log(M+S))
\]

workspace. No scheme is materialized.

### Stage B: Kikuchi matrix entries

KPI Theorem 8 maps a 2-XOR scheme with \(K\le2S\) variables to a matrix ensemble whose row/column indices are constant-size subsets of \([K]\).

For locality two we may take the constant Kikuchi level used in the corresponding certification step. A matrix coordinate can be generated from:

- \(O(1)\) variable addresses;
- one output/XOR constraint index;
- counters bounded by \(\operatorname{poly}(M,S)\).

Hence a raw permutation-ensemble entry is logspace generable.

### Stage C: Reweighting

KPI Lemma 4 replaces the raw matrices by

\[
B_x(i,j)
=
\Gamma_i^{-1/2}\Lambda_j^{-1/2}A_x(i,j),
\]

where \(\Gamma_i,\Lambda_j\) are row/column degree corrections.

A degree can be recomputed on demand by scanning the relevant matrix coordinates with logarithmic counters. Storing one degree uses \(O(\log(M+S))\) bits.

No row, column, or matrix is retained.

### Stage D: Candidate selection

KPI use a Naor-Naor limited-independence list of polynomial size for fixed locality. Candidate bits can be regenerated from the candidate seed and coordinate using polylogarithmic workspace.

The algorithm selects the first candidate passing the constant number of spectral tests.

The remaining issue is how to evaluate those tests without storing a polynomial-size matrix.

## 4. Streaming the spectral test by trace moments

KPI's proof already uses the standard inequality

\[
m^{-1/k}\,
\operatorname{tr}
\!\left((B^\top B)^{k/2}\right)^{1/k}
\le
\|B\|
\le
\operatorname{tr}
\!\left((B^\top B)^{k/2}\right)^{1/k},
\]

with

\[
k=O(\log M).
\]

For polynomial matrix dimension, the factor \(m^{1/k}\) is constant and can be absorbed in the constant-factor certification gap.

Therefore we need only approximate

\[
T_k(B)
=
\operatorname{tr}
\!\left((B^\top B)^{k/2}\right).
\]

Expanding the trace gives a sum over closed walks of length \(k\) in the matrix index set.

A walk is represented using

\[
O(k\log m)
=
O(\log^2(M+S))
\]

bits.

For each walk, all required matrix entries and row/column degrees are regenerated on demand.

### 4.1 Square-root cancellation

Write

\[
B=D_r^{-1/2} A D_c^{-1/2}.
\]

Then

\[
B^\top B
=
D_c^{-1/2}
A^\top D_r^{-1} A
D_c^{-1/2}.
\]

By cyclicity of trace,

\[
\operatorname{tr}\!\left((B^\top B)^r\right)
=
\operatorname{tr}
\!\left(
(D_c^{-1}A^\top D_r^{-1}A)^r
\right).
\]

Thus the trace moment can be evaluated using only rational degree factors. The square roots introduced by the KPI normalization do not need to be represented.

### 4.2 Precision

There are at most

\[
m^{O(k)}
=
2^{O(\log^2(M+S))}
\]

summands.

Each normalized factor has polynomially bounded numerator/denominator bit length.

Compute each term and the running sum to

\[
q=O(\log^2(M+S))
\]

bits after the binary point. Taking per-term error smaller than the inverse of the number of summands times the constant certification gap keeps the final additive error below the gap.

The accumulator, term value, walk index, degree counters, and candidate-list seed together occupy

\[
O(\log^2(M+S))
\]

bits.

### 4.3 Output

After the first passing candidate seed is identified, rerun the Naor-Naor generator coordinate by coordinate and emit the \(M\)-bit candidate on a write-only output tape.

The output itself is not counted as writable workspace.

This proves Theorem 2.1.

### Scope

This is a workspace refinement of the published KPI algorithm, not a new remote-point correctness proof. Correctness and the existence of a passing candidate use KPI Theorems 4, 8, 10, and 17.

The time bound of the streaming implementation is quasipolynomial because it enumerates the trace-moment walks explicitly.

## 5. Consequence for UNIFORM-LOCAL-DIAG2

UNIFORM-LOCAL-DIAG2 diagonalized over polynomially many \(O(\log M)\)-bit decoder descriptions, assigning one remote-point block to each decoder.

The only unresolved construction issue there was the workspace cost of producing each KPI block.

POLYLOG-REMOTE2 closes that issue.

### Corollary 5.1: LOWSPACE-DIAG2

The diagonal hard family \(H_M\) from UNIFORM-LOCAL-DIAG2 can be generated sequentially in

\[
\boxed{
\log^{O(1)} M
}
\]

writable space.

The running time is quasipolynomial in \(M\) under the direct trace-moment implementation.

Therefore the hard-family generator itself is compatible with virtual succinct-input simulation in PSPACE.

This removes one technical uncertainty from the local-data-structure branch.

## 6. Can locality be increased to obtain P-hard explicit gating?

The next natural idea is to enrich the 2-local constraints slightly.

For Boolean 2-local generators, fixed-decoder range membership is 2-CSP/2SAT-like and hence NL-like.

A deterministic polynomial-time computation is naturally represented by Horn implications. This suggests replacing binary constraints by Horn constraints.

That move fails the succinct-complexity requirement in a sharp way.

---

## 7. Explicit Horn satisfiability is P-complete

Consider the monotone circuit value problem.

For every wire/gate variable \(g\):

- a true input is represented by the unit Horn clause \(g\);
- an AND gate
  \[
  g=a\land b
  \]
  contributes the Horn implication
  \[
  a\land b\to g,
  \]
  i.e.
  \[
  \neg a\vee\neg b\vee g;
  \]
- an OR gate
  \[
  g=a\vee b
  \]
  contributes
  \[
  a\to g,
  \qquad
  b\to g,
  \]
  i.e.
  \[
  \neg a\vee g,
  \qquad
  \neg b\vee g.
  \]

Finally add the negative unit clause

\[
\neg o
\]

for the output wire.

The resulting Horn formula is unsatisfiable exactly when the monotone circuit outputs 1: the least Horn model derives precisely the wires whose circuit values are true.

The construction is local/logspace.

Hence Horn satisfiability/unsatisfiability is P-complete under standard weak reductions.

This is the smallest obvious step from the 2SAT implication graph to deterministic AND/OR propagation.

---

## 8. Succinct Horn SAT jumps to EXPTIME

### Theorem 8.1: HORN-SUCCINCT-JUMP1

Circuit-succinct Horn satisfiability is EXPTIME-complete.

### Membership

A succinct descriptor of length \(m\) represents a Horn formula of length at most

\[
2^{\operatorname{poly}(m)}.
\]

Expand conceptually and run the ordinary polynomial-time Horn-SAT algorithm. This takes

\[
2^{\operatorname{poly}(m)}
\]

time.

Thus succinct Horn-SAT is in EXPTIME.

### Hardness

Horn-SAT is P-complete under a local/logspace reduction from monotone circuit value.

The monotone-circuit-to-Horn construction above is record-local: any requested output clause is determined by one gate record and its type.

Standard succinct-representation conversion theorems therefore lift the reduction to succinct inputs. Equivalently, start with an exponentially large monotone circuit given by a small circuit generating gate records and generate the corresponding Horn clauses locally.

Succinct monotone circuit value is EXPTIME-complete.

Therefore succinct Horn-SAT is EXPTIME-hard.

Combining both directions yields EXPTIME-completeness.

---

## 9. Contrast with locality two

For the declared Boolean 2-local range-membership model:

\[
\text{explicit membership}\in NL
\]

and

\[
\text{succinct membership}\in PSPACE.
\]

For Horn deterministic propagation:

\[
\text{explicit membership is P-complete}
\]

but

\[
\text{succinct membership is EXPTIME-complete}.
\]

Thus the obvious attempt to move the explicit target from NL to P crosses exactly the boundary META-LIFT was trying to avoid:

\[
\boxed{
NL\ \longrightarrow\ P
}
\]

becomes

\[
\boxed{
PSPACE\ \longrightarrow\ EXPTIME
}
\]

after one ordinary circuit-succinct encoding.

This is not a proof that every possible P-hard meta-complexity target has EXPTIME-hard succinct form. MCSP/MKTP-type self-succinct minimization is precisely an exception.

It does rule out the straightforward strategy of replacing 2-local consistency by Horn-style deterministic propagation.

---

## 10. The Boolean-CSP boundary is structural

Schaefer's tractable Boolean CSP classes include:

- bijunctive/2CNF;
- Horn;
- dual Horn;
- affine systems;
- 0-valid and 1-valid languages.

Fine-grained classifications refine these tractable cases into classes such as L, NL, \(\oplus L\), and P-complete.

The present project only needs the following robust observation:

- bijunctive implication-graph structure supports the PSPACE succinct reachability recursion;
- Horn-style least-fixed-point propagation already supports P-complete explicit computation and its succinct form supports exponential-time iteration.

So simply moving within classical local CSP syntax is unlikely to provide the missing “explicit P-hard + succinct PSPACE” target.

The remaining hope must exploit a **self-succinct minimization phenomenon**, not merely a more expressive local constraint language.

---

## 11. A new design criterion

The target should have two different ways to represent the same object:

### Explicit-hard mode

A restricted representation class \(R_{\rm hard}\) for which unconditional polynomial-scale lower bounds are available.

### Succinct-fallback mode

Whenever the explicit target string is itself given by a small circuit \(D\), there must be a generic representation of size

\[
\operatorname{poly}(|D|)
\]

that makes large thresholds automatically YES.

This is the MCSP self-succinct trick.

But \(R_{\rm hard}\) need not simulate **all** circuits of polynomial size in the explicit truth-table length. It only needs to simulate circuits whose size is polynomial in the logarithm of that length.

This suggests an intermediate representation class:

\[
\boxed{
\text{small-circuit simulable}
\quad+\quad
\text{large explicit lower bounds}
}
\]

where “small” means \(\operatorname{polylog}(M)\), not \(M^{\Omega(1)}\).

The uniform local decoder model almost has this property, but UNIFORM-LOCAL-DIAG2 only diagonalized against \(O(\log M)\)-bit decoder descriptions. Under \(P=PSPACE\), the output-bit circuit supplied by META-LIFT can have an unknown polynomial size

\[
(\log M)^K.
\]

Therefore the next obstacle is now precise:

### POLYLOG-DESCRIPTION-DIAG1

Extend the hard family from decoder descriptions of length

\[
O(\log M)
\]

to every fixed polynomial

\[
(\log M)^K,
\]

without increasing the final explicit output beyond polynomial length and without making generator locality grow so much that the KPI lower bound vanishes.

The current one-block-per-decoder diagonalization cannot do this because

\[
2^{(\log M)^K}
\]

is superpolynomial for \(K>1\).

This is the same unknown-exponent phenomenon that appeared in EXHAUST1, now in a much cleaner representation-theoretic form.

---

## 12. New synthesis with the prior project

The META-LIFT branch and the old resource-contraction branch have converged on the same mathematical obstruction:

\[
\boxed{
\text{eliminate an unknown polynomial exponent }K.
}
\]

In EXHAUST1, \(K\) was the running-time exponent of an arbitrary SAT solver.

Here, \(K\) is the size exponent of the polynomial circuit computing a succinctly lifted output bit under the collapse assumption.

The local-diagonal construction handles

\[
K=1
\]

(up to constant factors in \(\log M\)).

A successful composition or contraction that maps

\[
(\log M)^K
\]

descriptions into a sequence of smaller/local objects with an exponent contraction

\[
K\mapsto \alpha K+\beta,
\qquad
\alpha<1,
\]

would connect directly to the project's existing resource-contraction machinery.

This appears to be the cleanest point at which the old and new proof spines can genuinely interact.

## 13. Current best targets

### A. POLYLOG-DESCRIPTION-DIAG1

Hardness against decoder descriptions of every polynomial size in \(\log M\).

### B. DESCRIPTION-CONTRACT1

A fully charged transformation on decoder representations satisfying

\[
K'\le \alpha K+\beta,
\qquad
\alpha<1,
\]

while preserving the represented output string and locality/resource conditions needed by the remote-point lower bound.

### C. SELF-SUCCINCT-LOCAL1

Find a local/data-structure representation model with:

1. unconditional polynomial-scale lower bounds;
2. generic polynomial-overhead simulation of **polylog-size** ordinary circuits;
3. a succinct minimization problem in PSPACE.

Any one of these would move beyond the Horn/2SAT boundary established here.

---

## 14. Conclusion

Two questions from the previous run are now resolved.

First, the KPI locality-two remote-point construction can be made compatible with the project's charged low-space framework:

\[
\boxed{
S_{\rm construct}
=
O(\log^2 M)
}
\]

under the explicit-generator interface, at the cost of quasipolynomial time.

Second, simply making the local constraints expressive enough for P-complete deterministic propagation does not preserve the desired succinct bound:

\[
\boxed{
2SAT:\ NL\to PSPACE,
\qquad
Horn:\ P\text{-complete}\to EXPTIME\text{-complete}.
}
\]

The remaining opening is therefore not “use a slightly stronger CSP.”

It is a genuinely meta-complexity phenomenon: construct a representation class that is hard on explicit strings but automatically easy on strings already given by small circuits.

The next quantitative target is POLYLOG-DESCRIPTION-DIAG1, because it isolates the unknown-polynomial-exponent problem in its cleanest current form.
