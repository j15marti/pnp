\fbox{\parbox{.94\linewidth}{\textbf{Executive finding.}
ARC229's exact bijunctive-message composition and LSPV-4's exact
exceptional-union extension survive independent mathematical review under
their authenticated-tree hypotheses.  This report proves a complementary
restricted theorem: an exact child message that is recognized as affine may
be compiled into the parent affine system, but the charged parameter is the
\emph{aggregate embedded coefficient rank} at that parent.  Uniformly bounded
aggregate rank and logarithmic parent separators give polynomial exact
composition.  Constant affine codimension on every edge alone does not: a
width-three parity star has rank-one child messages and aggregate parent rank
$h$.  The star is Gaussian-elimination easy, so this is an accounting
falsifier, not a lower bound.  Universal discovery/coverage, ARC/FLMV closure,
$P=NP$, and $P\ne NP$ remain \textbf{OPEN}.}}
\end{center}

\section{Claim card and PROPOSE}
\begin{description}
\item[Claim ID.] AFFINE-MESSAGE-RANK-REFEREE205.
\item[Concrete missing lemma.] When exact child relations on logarithmic
separators are affine rather than bijunctive, can they be absorbed without
enumerating their accumulated variable union, while preserving the fixed
codimension premise of the published local solver?
\item[Falsifiable mechanisms.] (M1) recognize an explicit exact table as an
affine coset and emit equations; (M2) charge only the maximum affine
codimension of a single child message; (M3) charge the rank increment of all
embedded child rows modulo the original parent rows; (M4) fall back to
LSPV-4's complete exceptional-union table for unrecognized messages.
M1, M3, and M4 survive.  M2 is \textbf{FALSIFIED/RETIRED} by the parity star.
\item[Exact scope.] A polynomial-time discovered and verified module tree,
source-once ownership with full scope containment, running intersection,
local recognized 2CNF plus affine equations, and explicit exact child tables
on parent--child separators.  No decomposition or favorable parameter bound
is assumed for arbitrary SAT.
\item[Uniformity.] One deterministic state-dependent controller computes both
recognizers, uses a certified 2CNF representation when available, otherwise
uses an affine basis when available, and otherwise reports outside the
restricted theorem (or invokes the separately charged exceptional-table
route).  It receives no SAT/UNSAT answer bit.
\end{description}

\section{BUILD I: recognizing exact affine messages}
Represent an assignment to an $s$-variable separator by a vector in
$\F^s$.  For a nonempty explicit relation $R\subseteq\F^s$, choose
$a\in R$ and form $D=\{x-a:x\in R\}$.

\begin{lemma}[Exact affine-table recognition]
$R$ is affine if and only if $D$ is a linear subspace.  In that case a basis
of $D^\perp$ emits an exact system
\[
  \langle q,x\rangle=\langle q,a\rangle
  \qquad(q\in\text{basis}(D^\perp)).
\]
The empty relation is represented by the inconsistent equation $0=1$.
From an explicit table this takes $2^s\operatorname{poly}(s)$ bit operations
and polynomial additional space beyond the table.
\end{lemma}
\begin{proof}
An affine subspace is exactly a translate $a+U$ of a linear subspace $U$.
Thus $D=U$ in the forward direction.  Conversely, if $D$ is a subspace then
$R=a+D$.  Orthogonal-complement equations characterize $a+D$ exactly.
Gaussian elimination tests closure/span equality and computes the bases.
\end{proof}

The same table can be tested for bijunctivity by majority closure, or by a
canonical 2CNF construction.  If both representations exist, the controller
selects the 2CNF representation so that it need not consume affine rank.  This
choice is syntactic and state-dependent, not answer-class advice.

\section{BUILD II: aggregate-rank affine-message composition}
Let $T$ be a rooted module tree.  Module $t$ has bag $V_t$, owns local 2CNF
$C_t$ and affine system $A_tx=b_t$, and has parent separator
$S_t=V_t\cap V_{p(t)}$ (empty at the root).  Every source constraint is owned
once and its complete scope lies in its owner bag.  Modules containing any
fixed variable form a connected subtree.  These conditions are verified and
their discovery/verification cost is $D$.

After processing a child $u$, its exact relation $R_u$ on
$S_u=V_u\cap V_t$ is available as an explicit table.  If $R_u$ is
bijunctive, compile a defining 2CNF into $C_t$.  If it is affine, embed the
recognized equation rows by zero-extending them from $S_u$ to $V_t$ and add
them to a multiset $M_t$.  Empty messages immediately make the parent entry
infeasible.  Define
\[
 e_t=\operatorname{rank}(A_t),\qquad
 \rho_t=\operatorname{rank}\!\binom{A_t}{M_t}-\operatorname{rank}(A_t),
 \qquad E_t=e_t+\rho_t.
\]
Ranks refer to coefficient matrices; augmented inconsistency is checked
separately.

\begin{theorem}[Exact affine-message composition]
Suppose every computed child message is recognized exactly as bijunctive or
affine.  One uniform deterministic bottom-up algorithm decides both SAT and
UNSAT and reconstructs a satisfying assignment on YES in
\[
 D+\operatorname{poly}(N)\sum_{t\in T}
 \left[2^{|S_t|}(|V_t|+1)^{O(E_t)}
       +2^{|S_t|}\operatorname{poly}(|S_t|+1)\right]. \tag{1}
\]
The bound includes every table entry, recognizer, projection, child lookup,
failed local call, Gaussian elimination, stored backpointer, compatibility
join, reconstruction, source recheck, intermediate representation, and peak
table space.  Hence polynomially many modules, polynomial $D$,
$|S_t|=O(\log N)$, and uniformly bounded $E_t$ give a deterministic
polynomial algorithm for this supplied-decomposition class.
\end{theorem}
\begin{proof}
Process children before parents.  For each assignment
$\alpha\in\{0,1\}^{S_t}$, restrict the compiled parent 2CNF and the combined
affine system $[A_t;M_t]$ by $\alpha$, then invoke the published
fixed-codimension solver.  Restriction preserves 2CNF.  Deleting pinned
columns cannot increase coefficient rank above $E_t$; row reduction detects
inconsistency.  Mark $\alpha$ feasible exactly when the local call succeeds,
and store one local witness together with compatible child backpointers.

For soundness, every compiled child representation defines its exact child
table, not an approximation.  Running intersection implies that agreement on
each edge separator is enough to glue all subtree witnesses.  Source-once
ownership and full scope containment then verify every original constraint.
For completeness, the restriction of any global witness survives each exact
child representation and each local call, by induction from leaves to root.
Root nonemptiness is therefore equivalent to SAT, and backtracking gives a
global witness.  Enumerating $S_t$ supplies the $2^{|S_t|}$ factor; the local
solver is charged at rank $E_t$; table recognition and storage give the
second term in (1).
\end{proof}

This theorem is complementary to HYBRID-BAD-MESSAGE228.  That result retains
every non-bijunctive relation as a full table and charges the union of its
separator variables.  The present theorem absorbs certified affine messages
and instead charges aggregate embedded rank.  Neither parameter dominates:
many duplicate affine messages can have large total edge width and rank one,
while disjoint rank-one messages have constant per-edge width and growing
aggregate rank.

\section{BUILD III: the parity-star falsifier}
For $h\ge1$, take a centre with variables
$a_j,b_j,c_j$ for $j=1,\ldots,h$.  Child $j$ sends the exact rank-one message
\[
 a_j\oplus b_j\oplus c_j=1, \tag{$P_j$}
\]
on its width-three separator.  The centre owns
\[
 \bigoplus_{j=1}^{h}(a_j\oplus b_j\oplus c_j)=\beta. \tag{$Q_\beta$}
\]
There are no 2CNF clauses.

\begin{proposition}[Per-edge affine rank does not control parent rank]
All child messages have affine codimension one and all edge separators have
width three.  Their embedded coefficient rows have aggregate rank $h$.  The
whole star is satisfiable exactly when $\beta\equiv h\pmod2$.  In the
opposite case, deleting any one child message restores satisfiability.
Consequently no bound depending only on maximum per-edge affine codimension
can replace $E_t$ in the fixed-codimension invocation.
\end{proposition}
\begin{proof}
The $h$ child coefficient rows have pairwise disjoint supports, hence are
independent.  Their XOR is the centre coefficient row.  XORing their right
sides gives $h\bmod2$, so the augmented system is inconsistent precisely
when this differs from $\beta$.  If one child row is removed, one triple is
free and can be chosen to realize the missing parity, restoring consistency.
\end{proof}

The family is pure affine and Gaussian elimination solves it in polynomial
time.  It proves neither a SAT time lower bound nor $P\ne NP$; it falsifies
only the proposed fixed-local-codimension accounting shortcut.  Conversely,
$h$ duplicate copies of the same three-variable parity relation have total
edge-width sum $3h$ but aggregate rank one, showing why the rank calculation
is materially sharper than counting affine children.

more generally an exactly verified bijunctive child relation can be compiled
into the parent's 2CNF.  Source authentication, once-only ownership, full
scope containment, and running intersection remain essential.  The extension
from separator size two to $O(\log N)$ is conditional on exact table

Its exceptional-union algorithm is exact: absorbed bijunctive messages remain

logarithmic.  The present affine route is an additional certified case, not a
refutation.

\section{Machine/resource ledger}
The native theorem is an indexed deterministic RAM upper bound over explicit
bit encodings.  A fixed-multitape TM may simulate the explicit scans,
Gaussian elimination, and local solver with polynomial overhead.  A
single-tape or fixed universal-machine implementation incurs its own charged
transport and program-prefix overhead; no time exponent is claimed to be
preserved.  No crossing-sequence or tape lower bound is transferred to RAM.
The theorem is an upper construction on a recognized class, so FLMV and
Williams/Buss--Williams lower-bound hypotheses are not invoked.  SAT-side
and UNSAT-side executions are restrictions of the same controller: both
construct every exact table needed before root nonemptiness is known.

\section{DUPLICATION / CONTRADICTION AUDIT}
\begin{itemize}
\item The raw full-interface theorem from run204, ARC229 bijunctive
compilation, and LSPV-4 exceptional-union composition are not duplicated as
new results.  The new result is the exact affine-message absorption rule and
its aggregate-rank parameter.
\item ``Fixed affine rank per child implies fixed affine rank at the parent''
is \textbf{FALSIFIED/RETIRED}.  The parity star gives rank $h$.
\item ``$e=2$ is open'' is stale: fixed $e$ is a \textbf{KNOWN THEOREM}.
\item ``$e=O(\log N)$ is polynomial by the XP bound'' is false; the displayed
bound is quasipolynomial.
\item Pure affine rank growth is not hardness.  Gaussian elimination is an
explicit semantic shortcut and blocks any separation inference from the
star.
\end{itemize}

\section{STALE OR OVERSTATED CLAIMS FOUND}
The load-bearing overstatement is the unqualified phrase ``affine messages
can be absorbed while retaining fixed local codimension.''  Correct form:
they can be absorbed exactly, but the combined rank after embedding all
messages must be recomputed and charged.  A bound on each individual message
does not imply a bound on that combined rank.  No current artifact closes
arbitrary-instance discovery or proves either equality or separation.
