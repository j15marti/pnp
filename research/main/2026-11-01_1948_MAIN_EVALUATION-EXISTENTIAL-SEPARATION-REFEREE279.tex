\section{Exact obstruction and falsifiers}

The obstruction is a quantifier mismatch.  A forward circuit or OBDD computes
$f_F(x)$ for a supplied assignment $x$.  Source SAT asks whether
$\exists x\,f_F(x)=1$.  A lower bound for one compiler or assignment evaluator does not
become necessary source-decision work without a paid uniform reduction that preserves the
machine, source access, time exponent, and simultaneous peak space.

We tested four falsifiable claims:
\begin{enumerate}
\item exponential OBDD width for one order forces exponential work for every compiler or SAT decider;
\item exact assignment-evaluation query depth lower-bounds existential SAT decision on authenticated F9;
\item post-solution minimization of an UNSAT source's zero function supplies a uniform UNSAT method;
\item a finite F9 separation establishes the all-input ARC/FLMV theorem.
\end{enumerate}
The first three are false as unrestricted claims; the fourth remains unproved.

\section{Exact same-source finite theorem}

Let $f:\{0,1\}^9\to\{0,1\}$ be the Boolean function of the canonical F9 source with
positive supports
$(156),(238),(135),(469),(247),(789)$ and negative supports
$(468),(167),(234),(358),(129),(579)$.  Exhaustive original-clause evaluation gives
$70$ accepting assignments.

\paragraph{Theorem 1 (exact finite representation and evaluation audit).}
For reduced OBDDs over F9, the minimum nonterminal-node count over all $9!$ variable orders
is $52$, attained by $(2,6,7,9,8,4,3,1,5)$; the natural order has $66$ nodes; the maximum is
$80$, attained by $(2,6,8,9,1,3,4,5,7)$.  In the deterministic assignment-bit query model,
$D(f)=9$.  More strongly, every correct tree has some accepting input at depth $9$.
All $442$ rejecting assignments have a three-bit falsified-clause certificate.  The $70$
accepting assignments have minimum certificate sizes $6,7,8$ with multiplicities
$26,34,10$.

\paragraph{Proof.}
For a tested-variable set $S$ and next variable $i\notin S$, let $c(S,i)$ be the number of
distinct restricted cofactor pairs $(g|_{i=0},g|_{i=1})$ with unequal children.  The number
of nodes in an order is the sum of these level costs.  The subset recurrence
\[
 M_{\min}(S\cup\{i\})=\min_{i\notin S}\bigl(M_{\min}(S)+c(S,i)\bigr)
\]
and its maximum analogue cover all $9!$ orders in $9\,2^9$ transitions.  A separate exact
Bellman recurrence over partial assignments computes the minimum worst-case query depth.
An independent program recomputed the two reported orders from residual truth vectors and
recomputed the depth from 18,740 reached subproblems.  The certificate histogram was
checked directly against every opposite-valued completion. \qed

This is an exact finite theorem about evaluating or representing $f$, not about deciding
SAT of arbitrary source strings.

\section{Product countermodel to OBDD hardness inference}

Let $F_t$ be $t$ disjoint variable-renamed copies of F9.  It is a valid duplicate-free
proper monotone exact-$(2,2)$ original, but it is disconnected and is therefore explicitly
\emph{not} the requested connected obstruction family.

Test all designated $x_1$ variables before every remaining variable.  The two F9 cofactors
$f_0,f_1$ are nonzero, distinct, and depend on the next tested $x_2$.  Hence the $2^t$
prefixes produce $2^t$ different live residual products, so that order has width at least
$2^t$.  In contrast, grouping variables blockwise gives at most $52t$ OBDD nodes.

Assignment evaluation is only linear: evaluate each block in at most $9t$ queries.  Choose
in every block an accepting assignment whose smallest 1-certificate has size eight.  Any
accepting leaf for the conjunction must certify every block, requiring at least $8t$ queried
bits.  Thus the assignment-evaluation query cost is $\Theta(t)$ even though the declared bad
OBDD order has exponential width.  On the authenticated ordered block promise, source SAT is
also decided in $O(t)$ word work by paid block recognition plus one fixed F9 witness and 12
original-clause checks per block.  No variable recovery or injective pin key is needed.

Therefore
\[
 2^t\ \text{bad-order width}\quad\not\Rightarrow\quad
 2^{\Omega(t)}\ \text{evaluation or SAT-decision work}.
\]

\section{Fully charged recurrence and gap}

For every evaluated controller state $R$ we require
\begin{align*}
W_D(R)={}&W_{\rm grammar}+W_{\rm source/index/head}+W_{\rm discover}
+W_{\rm select/switch/failed}+W_{\rm deduce/GE/proof}\\
&+W_{\rm cache/replay}+W_{\rm child/output/access}+W_{\rm guest}
+\sum_{Q\in\mathrm{evaluatedChildren}(R)}W_D(Q).
\end{align*}
Peak space is the maximum simultaneous writable/index/head/cache/proof/ancestor/child/guest
space.  The truth table and OBDD dynamic program in this experiment are charged offline
storage, not free semantic keys available to a SAT machine.  DELAY may add time with zero
logical XOR; COPY writes and RECOMP rereads remain charged; logical XOR remains OFFLINE.

The exact fallback is still
$O(2^nN\operatorname{polylog}N)$ under straightforward enumeration.  No theorem bounds the
sum of all failed policy trials and descendants polynomially on every valid original.  Nor
is there a same-machine reduction that transports these representation facts into the
numerical FLMV forbidden region.  This is the explicit gap.
