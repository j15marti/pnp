\section{Falsifiable target, mechanisms and answer}
The missing lemma was whether exact counting for hitting clause blocks composes
through a module tree without double-counting.  Four mechanisms were tested:
(M1) store only each block's scalar model count; (M2) store the full function on
every variable shared with any neighboring block; (M3) join only along adjacency,
without checking the running-intersection property; and (M4) use hitting closed
forms locally while switching to ordinary UP--DPLL, 2SAT/Horn or GF(2) controls
outside the recognized class.

M2 is exact under explicit hypotheses and gives a polynomial algorithm when all
full interfaces are logarithmic and the decomposition is polynomially obtained.
M1 and M3 have minimal counterexamples.  M4 remains necessary: a Tseitin parity
contradiction is rejected by the hitting-tree recognizer but easy by Gaussian
elimination.

\section{Exact hitting-tree composition theorem}
Let $T$ be a tree of modules.  Original clauses are assigned exactly once.  Module
$t$ owns a hitting CNF $H_t$ on variables $V_t$.  For every global variable, the
modules containing it induce a connected subtree.  For edge $tc$ put
$S_{tc}=V_t\cap V_c$, and define the \emph{full interface}
\[
B_t=V_t\cap\bigcup_{u\in N_T(t)}V_u,\qquad b_t=|B_t|,
\]
not merely the parent separator.  Let $P_t=V_t\setminus B_t$.

\begin{theorem}[Full-boundary hitting-tree composition]
Given such a decomposition, exact model count, SAT decision and a witness can be
computed in
\[
D_{\rm verify}+N^{O(1)}\sum_{t\in T}2^{b_t}
\]
bit operations and polynomially many $O(N)$-bit count cells.  Here
$D_{\rm verify}$ includes reading every source clause, verifying the tree,
clause ownership, local hitting and running intersection.  If the decomposition
is discovered in polynomial time, there are polynomially many modules and
$b_t=O(\log N)$ uniformly, the resulting algorithm is polynomial on this
restricted encoded class.
\end{theorem}

\begin{proof}
Root $T$.  For a full-interface assignment $\beta$, restrict $H_t$.  Every two
surviving residual clauses still clash: assigning a clash variable satisfies and
removes one of its two parents.  Hence the residual is hitting.  If it has an
empty clause, set $h_t(\beta)=0$; otherwise disjoint falsifying cubes give
\[
h_t(\beta)=2^{|P_t|}\left(1-sum_{C\in H_t\mid\beta}2^{-|C|}\right).
\]
For parent $p$ and assignment $\alpha$ on $S_{tp}$, define
\[
M_{t\to p}(\alpha)=
\sum_{\substack{\beta\in\{0,1\}^{B_t}\\
\beta|_{S_{tp}}=\alpha}}
h_t(\beta)
\prod_{c\text{ child of }t}M_{c\to t}(\beta|_{S_{tc}}).
\]
Running intersection makes every shared global variable appear in every separator
along its path, so each global assignment is joined exactly once and inconsistent
copies never meet.  Induction from the leaves proves that a message counts exactly
the subtree completions conditional on its separator.  The root's empty-separator
message is therefore $\#\mathrm{SAT}(F)$.  Store one positive summand as a
backpointer.  Within its local hitting residual, repeated exact-count restrictions
construct a private witness in polynomial time; following child backpointers
reconstructs a global witness.

Across all assignments to a parent separator and remaining interface variables,
each $\beta$ is processed once, giving $2^{b_t}$ rows.  Exact counts have at most
$N$ bits; their additions and multiplications contribute the displayed polynomial
factor.  No table discovery, join, arithmetic or reconstruction is free.
\end{proof}

This is a hitting-local specialization of standard junction-tree/project--join
model counting, not a new unrestricted inference paradigm.  Existing DPMC
explicitly separates planning (constructing a project--join tree) from execution,
the same separation required here.

\section{Two minimal counterexamples}
For variables $x,y,z$ let
\[
A^+(x,y,z)=\bigwedge_{s,t\in\{+,-\}}(x\vee s y\vee t z),
\quad
A^-(x,y,z)=\bigwedge_{s,t\in\{+,-\}}(\neg x\vee s y\vee t z).
\]
Each is a proper hitting four-clause module.  $A^+$ is equivalent to $x$ and
$A^-$ to $\neg x$.  Both have the same scalar count $4$, but their boundary count
vectors on $x=0,1$ are respectively $(0,4)$ and $(4,0)$.  Let $B^+$ be a fresh
copy of $A^+$ sharing only $x$.  Then
\[
\#(A^+\wedge B^+)=16,qquad \#(A^-\wedge B^+)=0.
\]
Thus equal scalar summaries cannot compose even across a one-bit separator.  The
full boundary vector is necessary for this pair.

For the running-intersection firewall, place $A^+$ and $A^-$ at the endpoints of
a three-node path and a one-clause hitting module on fresh variables in the middle.
The global source is UNSAT because the endpoint occurrences refer to the same
$x$.  A naive adjacent-separator product that treats the disconnected occurrences
as independent returns $4\cdot7\cdot4=112$.  The verifier correctly rejects this
decomposition with \texttt{running\_intersection\_x1}.  Hence adjacency alone is
not a sound composition hypothesis.
