\section{Three falsifiable mechanisms}
Fix $g$ selector variables, each with domain $[d]$, and an explicit binary
relation $R_{uv}\subseteq[d]^2$ for every edge of a constraint graph $H$.
All relation fields, graph records, construction, preprocessing, failed
branches, replay, and peak space are charged.

\begin{enumerate}
\item \textbf{Structural continuation:} forest constraint graphs are solved
by messages, and a supplied feedback vertex set of size $c$ by $d^c$
assignments followed by forest messages. Falsify with a mismatch against
exhaustive search or a hidden cycle after deletion.
\item \textbf{Quadratic acquisition:} a two-selector $d\times d$ table can
have $d^2$ independently critical fields. Falsify its use as amplification by
a matching charged table scan.
\item \textbf{Domain lift:} arbitrary Boolean binary relations reduce to
2-CNF, while domain-three inequality is graph 3-coloring. Falsify the endpoint
by a polynomial-time unrestricted 3-coloring algorithm, or falsify transport
by proving a positive charged remainder.
\end{enumerate}
The first and third mechanisms give an exact ladder. The second remains only
input-order acquisition.

\section{Exact structural algorithm}
\begin{theorem}[PROVED/EXACT: selector graph]
For an explicit selector CSP with $g$ variables, domain $d$, $e$ relation
records, and a supplied feedback vertex set $C$ of size $c$, exact
satisfiability is decidable in
\[
O\!\left(ed^2+gd+d^c(ed^2+gd)\right)
\]
word operations and $O(ed^2+gd+c)$ peak words. If $H$ is a forest, the bound
is $O(ed^2+gd)$ time with linear peak space.
\end{theorem}
\begin{proof}
First verify in $O(g+e)$ graph operations that $H-C$ is a forest. Enumerate
the $d^c$ assignments to $C$, rejecting those that violate an internal
relation. Each surviving assignment filters the domain of every neighboring
forest vertex. Root each component of $H-C$. For an oriented edge $uv$, its
child-to-parent message lists the parent colors having some compatible child
color whose entire child subtree is feasible. Combining child messages is
intersection. Each relation message costs at most $d^2$ table inspections.
The current cut assignment and all forest messages are reused between
branches, yielding the stated peak storage.
\end{proof}

This is a continuation \emph{upper bound}. Even $c$ or treewidth growing
linearly does not prove that an arbitrary decider must materialize or traverse
this dynamic program. Freuder's width analysis supplies the classical
structural precedent for such CSP algorithms \cite{freuder82,freuder90}.

\section{Exact 2-SAT-to-3-coloring ladder}
\begin{theorem}[PROVED/EXACT: domain boundary]
Arbitrary explicit binary CSP over domain two reduces in linear output size
to 2-CNF. Over domain three, restricting every relation to inequality already
gives graph 3-colorability, a known NP-complete language.
\end{theorem}
\begin{proof}
Interpret a two-valued selector as one Boolean variable. For every forbidden
pair $(a,b)$ in a relation on $(u,v)$, add
\[
(X_u\ne a)\vee(X_v\ne b).
\]
There are at most four such binary clauses per relation, and the conjunction
has exactly the original solutions. SCC therefore decides the domain-two
case after charged parsing.

For domain three, assign one color to each selector and put the relation
$R_{\ne}=\{(a,b):a\ne b\}$ on each graph edge. The resulting CSP is exactly
graph 3-colorability, whose NP-completeness was proved by
Garey--Johnson--Stockmeyer \cite{gjs}.
\end{proof}

The explicit selector-to-CNF encoding also makes the progression compatible
with the earlier $2$-CNF-plus-$k$-ternary ladder. For each selector, use $d$
choice variables, a functional binary OR tree with $d-1$ gate variables,
and one free root-forcing auxiliary. With $e$ relation edges, the construction
has
\[
n=2dg,\qquad k=g(d-1)
\]
Boolean variables and genuine ternary clauses, respectively, and at most
\[
m_2=
g\left(\binom d2+2d\right)+ed^2
\]
binary clauses. Every satisfying selector assignment has exactly $2^g$
Boolean extensions because the root-forcing auxiliaries are free and the OR
gate trace is functional.

For $g=2,e=1$ this specializes exactly to Role 4's counts
\[
n=4d,\qquad k=2d-2,\qquad m_2=2d^2+3d.
\]
For fixed $d=3$, $k=2g$ grows linearly and arbitrary inequality coupling
reaches the NP-complete endpoint. This is an explicit representation path,
not a lower-bound transfer.

\section{Field, bit, record, and word accounting}
\begin{lemma}[PROVED/EXACT: two-selector acquisition]
For one explicit $d\times d$ allowed-pair table, the all-zero UNSAT input
requires all $d^2$ table fields in deterministic exact field-query
complexity.
\end{lemma}
\begin{proof}
Flipping any one unread field to allowed creates a one-pair SAT input with the
same observed transcript. Therefore every field is read. A single complete
scan is matching and sufficient.
\end{proof}

If every table entry occupies one addressed $w=\Theta(\log N)$-bit source
word, this is $d^2$ word probes and
$N=\Theta(d^2w)$ bits, hence $\Theta(N/\log N)$ word acquisition. If entries
are densely packed, the same adversary gives $d^2$ bit probes but only
$\lceil d^2/w\rceil$ distinct machine-word probes. A relation record
containing all $d^2$ bits costs one record probe but $\Theta(d^2/w)$ machine
words to scan. These models must not be interchanged.

Role 4's QUADRATIC-SOURCE-LADDER55 uses one separate sign-containing word per
matrix entry and has a stronger fixed-CNF semantic: SAT iff some row contains
exactly one zero. Its all-one input therefore needs $d^2$ addressed words,
yet $N=\Theta(d^2\log d)$ and an $O(d^2)$ row-count scan decides the family.
The audit below independently checks the full CNF and model count.

For any paid lift or reduction,
\[
L_{\rm old}\le R+H+Q\tau T_{\rm new}^{\le}(G).
\]
The explicit table or CNF conversion has input-order construction cost, so
the known $d^2$ source bound can be fully consumed by $R+H$. Direct inclusion
preserves acquisition order without increasing it.

\section{Cross-role reconciliation}
\begin{itemize}
\item \textbf{AFFINECORE69:} untagged XOR extraction plus residual-clause
branching is a charged upper bound; complete extraction is not compulsory for
all deciders.
\item \textbf{AFFINE-INTERFACE54:} a small actual shared interface yields a
$2^{h+t}\operatorname{poly}(N)$ upper bound, while the unrestricted interface
can contain the NP-complete endpoint.
\item \textbf{TWO-EASY-INTERSECTION61:} separately satisfiable affine and
bijunctive factors can have NP-complete joint witness compatibility. The two
root SAT bits are insufficient, but this fact alone supplies no runtime lower
bound.
\item \textbf{QUADRATIC-SOURCE-LADDER55:} every tested functional ternary can
be essential while the source-aware decision remains linear in its quadratic
encoding.
\end{itemize}
Thus the first plausible amplification target is not the number of fields,
clauses, or local choices. It is an all-decider lower bound on \emph{succinct
global compatibility after acquisition}; this remains OPEN.

\section{Exact proof spine and next lemma}
\[
\begin{array}{c}
\text{Boolean binary CSP = 2-CNF (PROVED)}\\
\downarrow\\
\text{domain-three selector CSP; forest/FVS upper bounds (PROVED)}\\
\downarrow\\
\text{unrestricted inequality graph = 3-coloring (KNOWN NP-complete)}\\
\downarrow\\
\text{post-acquisition compatibility lower bound (OPEN)}\\
\downarrow\\
\text{all-decider coverage and superpolynomial contradiction (OPEN).}
\end{array}
\]
The highest-value missing lemma is a representation-independent theorem for
one fixed domain-three relation language: every total uniform exact decider
must, on some growing inputs, either pay superpolynomial cost to construct and
validate a sufficient global compatibility summary or pay superpolynomial
direct continuation cost. It must survive SCC, affine elimination, forest and
treewidth messages, source recognition, caching, clause learning, alternate
encodings, and decide-first normalization.
