\section{Ideas frozen before the literature check}

The following falsifiable integrations were recorded before opening the four
primary sources in this run.
\begin{enumerate}[leftmargin=*]
  \item \textbf{Finite-entry gate.}  Solve the ARC recurrence exactly and find
  a rational point strictly inside an FLMV-forbidden region, so that little-$o$
  bookkeeping has positive slack.
  \item \textbf{Current-scale-call falsifier.}  Apply an artificial-delay
  wrapper to an arbitrary correct polynomial SAT decider.  A claimed
  arbitrary-decider stage making a compulsory call on an $\Omega(N)$-length
  instance cannot achieve exponent halving when all time is charged.
  \item \textbf{Search-output floor.}  In search-MCSP, separate the unavoidable
  $\Omega(s\log s)$ output description from a genuinely superpolynomial
  streaming-space lower bound; the former cannot establish the latter.
  \item \textbf{Threshold-transport gate.}  Any MCSP descent must preserve the
  exact one-tape/input-head/randomness model and both promise sides.  A ratio
  $g(\beta)/\beta\to\infty$ without such a map is not a magnification theorem.
\end{enumerate}

\section{Primary-source check: exact hypotheses, not slogans}

\begin{itemize}[leftmargin=*]
  \item Cheraghchi--Hirahara--Myrisiotis--Yoshida (CHMY) define
  $N=2^n$ and prove that, for some $\mu_2>\mu_1$, randomized two-sided-error
  one-tape machines with an additional one-way read-only input tape cannot
  compute $\MCSP[2^{\mu_2 n}]$ in time $N^{1.99}$.  Their abstract separately
  states the McKay--Murray--Williams implication at a smaller $\mu_1$ and time
  $N^{1.01}$.  This does not itself transport hardness from $\mu_2$ to $\mu_1$.
  \item McKay--Murray--Williams (MMW) define search-$\MCSP^A[s]$ to output an
  AND/OR/NOT/$A$-oracle circuit of size at most $s$, or report that none exists.
  For reasonable $s(n)\ge n$ and $A\in PH$, the stated magnification hypothesis
  rules out a \emph{one-pass deterministic} $\operatorname{poly}(s)$-space
  streaming algorithm with $\operatorname{poly}(s)$ update time.  Output length
  alone is therefore not the desired lower bound.
  \item Oliveira--Pich--Santhanam (OPS) state a universal $c\ge1$ such that, if
  for some $\varepsilon>0$ and \emph{every sufficiently small} $\beta>0$,
  $\GapMCSP[2^{\beta n}/(cn),2^{\beta n}]$ has no circuits of size
  $N^{1+\varepsilon}$, then $NP\nsubseteq P/\mathrm{poly}$.  A single fixed
  $\beta$, a different gap, or a streaming lower bound is not this premise.
  \item FLMV prove SAT time--space lower bounds for deterministic random-access
  Turing machines.  Their public abstract gives the range $c<\varphi$ and some
  positive space exponent tending to $1$ as $c\to1$.  For the quantitative
  audit below we use the Corollary~5.8 sufficient curve already source-checked
  in the project record,
  \[
     b(c)=\frac{(c+2)/c^2-c}{2}.
  \]
  This run independently checks the algebra and keeps the deterministic
  random-access model; it does not broaden the theorem to arbitrary models.
\end{itemize}

\section{Exact integrated result}

Assume a valid stage maps a deterministic random-access SAT decider with
worst-case resource exponents $(t_j,s_j)$ to another such decider, on every
input and hereditarily under iteration, with all construction, instance
selection, input reads, calls, replay, cache transfers, output, and live state
charged, and with
\begin{equation}
 t_{j+1}\le\max\left\{\frac{11}{10},\frac35+\frac{t_j}{2}\right\},
 \qquad
 s_{j+1}\le\max\left\{\frac12,\frac{s_j}{2}\right\}.
 \tag{R}
\end{equation}

\begin{theorem}[FLMV finite-entry gate]
Let $t_0,s_0\ge0$ be finite.  If (R) is realized by valid stages, then after at
most
\[
 J=\max\left\{
 \left\lceil\log_2\!\left(200\max\{t_0-6/5,0\}\right)\right\rceil_+,
 \left\lceil\log_2\!\left(2s_0\right)\right\rceil_+
 \right\}
\]
stages, the resulting exponents satisfy
\[
 t_J\le\frac{241}{200},\qquad s_J\le\frac12,
\]
and
\[
 b(241/200)=\frac{11642479}{23232400}
 =\frac12+\frac{26279}{23232400}>\frac12.
\]
Consequently, after absorbing the $o(1)$ terms into the displayed positive
margin, the resulting deterministic random-access SAT algorithm would violate
the FLMV sufficient tradeoff.  Hence $P=NP$ together with such a universally
iterable fully charged stage is inconsistent with FLMV.
Here $\lceil\log_2 x\rceil_+$ is defined to be $0$ when $x\le1$.
\end{theorem}

\begin{proof}
Above its fixed point the time recurrence solves to
\[
 t_j\le\frac65+\frac{t_0-6/5}{2^j},
\]
while $s_j\le\max\{1/2,s_0/2^j\}$.  The two terms defining $J$ therefore imply
$t_J\le6/5+1/200=241/200$ and $s_J\le1/2$.  Direct rational substitution gives
the displayed value of $b(241/200)$.  Moreover
$b'(c)=(-1-1/c^2-4/c^3)/2<0$ for $c>0$, so any smaller time exponent has at
least this FLMV space margin.  The strict rational margin absorbs eventual
$o(1)$ overheads.  The contradiction is model-matched only under all stage
hypotheses above.
\end{proof}

For the recorded starting pair $(17,14)$, exact iteration first reaches the
safe box at $J=12$:
\[
 (t_{12},s_{12})=\left(\frac{4931}{4096},\frac12\right),\qquad
 b(t_{12})=\frac{100271319077}{199186522112}>\frac12.
\]

\begin{proposition}[current-scale black-box calls are fatal]
Fix $K>6/5$ and let $A_K$ be any correct polynomial SAT decider whose execution
is padded to require $\Omega(M^K)$ time on length-$M$ calls.  If a purported
stage for \emph{every} polynomial decider must execute $A_K$ on an instance of
length $M=\Omega(N^a)$ on some length-$N$ input, then its charged exponent is at
least $aK$.  Therefore (R) requires
\[
 a\le \frac{\max\{11/10,,3/5+K/2\}}{K}.
\]
In particular, a compulsory current-scale call ($a=1$) contradicts (R) for
every $K>6/5$.
\end{proposition}

\begin{proof}
The compulsory padded call costs $\Omega((N^a)^K)=\Omega(N^{aK})$.  Compare
this lower bound with the claimed stage upper exponent.  For $K>6/5$ the
second recurrence branch equals $3/5+K/2<K$, so $a=1$ is impossible.
\end{proof}

This proposition is a falsifier, not a separation: a successful stage could
use substantially shorter queries, non-black-box access to a canonical
decider, or another construction.  Each such escape must be stated and charged.
