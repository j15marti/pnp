\section{Run target and three falsifiable mechanisms}

SHARED-INTERFACE-TABLE92 showed that an explicit $J\times2^h$ compatibility
table costs only input-order acquisition.  This run moved to succinct binary
relations on three-valued root variables and tested:
\begin{enumerate}
\item whether cycles of compact permutation relations force exponential
compatibility work;
\item whether $h$ extra chords force the $3^{2h}$ fallback reported by Role 4;
\item whether enlarging the relation language from permutations to
inequalities transports a lower bound into the NP-complete endpoint.
\end{enumerate}
All three proposed lower-bound mechanisms fail.  Permutation holonomy is
linear on arbitrary graphs; a supplied feedback vertex set gives an exact
$3^c$ upper bound, improving the chord fallback; and relation-language
inclusion does not amplify a linear source bound.

\paragraph{Quantifier/model card.}
The exact algorithmic theorems quantify over every finite graph and every
declared relation labeling.  Inputs use fixed four-word clauses with word
width $w=\Theta(\log(n+m+2))$.  Source reads, recognition, failed checks,
forest/cutset validation, DP tables, witnesses, replay, output, and peak live
space are charged.  The P-versus-NP target still quantifies over every total
uniform deterministic exact decider for one fixed NP-complete language; that
universal arrow is OPEN.

\section{Baseline recheck: fixed-width implication chain}

The endpoints force $z_0=1,z_q=0$.  For $b_i=1$ use
$(\neg z_{i-1}\vee z_i)$; otherwise use
$(\neg z_{i-1}\vee\neg z_i)$.  If every $b_i=1$, implication propagation
forces $z_q=1$, so the formula is UNSAT.  If $j$ is the first zero, set
$z_0,\ldots,z_{j-1}=1$ and $z_j,\ldots,z_q=0$, satisfying every clause.
Thus the formula is UNSAT iff every orientation is one.

On the all-one input, flipping any unread orientation gives an equal-length,
equal-metadata SAT input.  Every deterministic exact field-query decider
therefore reads all $q$ fields.  With one aligned orientation per fixed record
this is $q$ field, record, and word probes; with $w$ packed orientations per
word it yields only $\Omega(q/w)$ word probes.  Since
$N=\Theta(qw)$ bits, the aligned result is $\Theta(N/w)$ acquisition, not an
unrestricted superlinear theorem.

\section{Permutation holonomy is linear on arbitrary graphs}

Let each root variable $x_v$ range over $\mathbb Z_3$.  An oriented edge
$(u,v,b)$ requires
\[
x_v=x_u+b\pmod 3.
\tag{1}
\]
Its one-hot Boolean encoding uses three variables per vertex, one positive
ternary and three at-most-one binaries per vertex, and the six forbidden-pair
binary clauses per edge.

\begin{theorem}[Exact affine-holonomy normalization]
For every graph, the system (1) is satisfiable iff the signed sum of the edge
labels is zero around every cycle.  A spanning-forest potential computation
decides this in $O(|V|+|E|)$ word operations and $O(|V|+|E|)$ peak words.
If consistent, the number of assignments is exactly $3^c$, where $c$ is the
number of connected components.  The one-hot CNF has exactly the same models.
\end{theorem}
\begin{proof}
Choose one root potential zero per component.  A forest determines every
other potential by (1).  Each nontree edge is then satisfied precisely when
its fundamental-cycle sum is zero.  If all checks pass, adding a common
constant in $\mathbb Z_3$ independently to every component gives all and only
the $3^c$ solutions.  The one-hot clauses select a unique color, while its six
edge clauses exclude exactly the six pairs outside (1).
\end{proof}

This strictly strengthens the cycle hostile control.  Arbitrarily many
cycles, chords, large treewidth, and large cyclomatic number remain easy when
the relations retain their permutation/affine algebra.

For a $q$-cycle with $b_i\in\{0,1\}$, SAT is equivalent to
$\sum_i b_i=0\pmod3$.  On the all-zero cycle, changing any unread field to
one flips SAT to UNSAT, proving an exact $q$-field bound on that input.  The
holonomy scan matches it in $O(q)$ time and $O(q)$ conservative peak words.

\section{Arbitrary relations with a feedback vertex set}

Now let every edge carry an arbitrary relation
$R_{uv}\subseteq\{0,1,2\}^2$, represented explicitly by nine bits.  Let
$C$ be a supplied, source-checkable feedback vertex set of size $c$, so
$H-C$ is a forest.

\begin{theorem}[Exact cutset continuation]
SAT is decidable in
\[
O\!\left(3^c\,9(|V|+|E|)
\right)
\]
word operations and $O(|V|+|E|+c)$ peak words after the source and cutset are
validated.  All failed cutset assignments are included.
\end{theorem}
\begin{proof}
Enumerate the $3^c$ assignments to $C$, immediately rejecting those that
violate an internal cutset edge.  For each survivor, compute bottom-up on
every tree of $H-C$.  For vertex $v$ and color $a$, retain a Boolean message
iff every child has some compatible feasible color and every cutset neighbor
is compatible with its fixed color.  Each edge table is inspected at most a
constant nine entries per cutset assignment.  Reusing the message buffer and
assignment counter gives the stated peak space.
\end{proof}

For a base cycle plus $h$ extra chords, take one base-cycle vertex and one
endpoint of each chord.  This is a feedback vertex set of size at most
$h+1$.  Hence Role 4's $3^{2h}\operatorname{poly}(N)$ fallback improves to
\[
3^{h+1}\operatorname{poly}(N).
\]
This remains an upper bound, not necessary work.  On permutation-labeled
instances the preceding holonomy theorem removes the exponential factor
entirely, even if $h$ grows linearly.

\section{The exact NP-complete endpoint and failed transport}

Restrict the relation language to the single nonfunctional relation
\[
R_{\ne}=\{(a,b):a\ne b\}.
\]
The resulting CSP is exactly graph 3-colorability.  Its one-hot CNF uses
$n=3|V|$, $k=|V|$ positive ternaries, and
$m=4|V|+3|E|$ total clauses, with a bijection between CNF models and proper
colorings.  Graph 3-colorability is NP-complete; this is the explicit endpoint
of the ladder, not a deterministic time lower bound.

The source cycle lower bound cannot be transported into this endpoint.  In
\[
L_{\rm old}\le R+H+Q\tau T_{\rm new}^{\le}(g),
\]
the old field bound is $L_{\rm old}=q$, while reading and writing the one-hot
edge gadgets costs $R=\Theta(q)$.  The positive remainder is therefore not
established.  Direct inclusion avoids construction but preserves only the
same $\Omega(q)=\Omega(N/\log N)$ aligned-word acquisition order.

Nor does the containment of permutation instances inside a richer color-CSP
language increase their lower bound: it merely says a target decider must
also decide this easy linear-time subfamily.  The finite-domain CSP dichotomy
classifies fixed relation languages as polynomial-time or NP-complete; it
does not prove a superpolynomial unconditional time lower bound for the
NP-complete side.

\section{Integration of new role reports}

Role 4's PERMUTATION-CYCLE54 claims are independently proved above: exact
modulo-three cycle semantics, three models on consistent connected cycles,
the all-zero $q$-field sensitivity bound, and linear decoding.  The new
cutset theorem improves its extra-chord fallback from $3^{2h}$ to
$3^{h+1}$.

Role 2's COLOR-JOIN51 collapses permutation components to three-valued roots
and solves forest-shaped inequality quotients by exact DP.  This report
extends that DP to any source-checked feedback vertex set and separates the
tractable permutation algebra from the unrestricted inequality endpoint.

Role 1's ONEPASS66 gives a $q^2$-bit one-pass state bound for late selectors,
but two charged passes use $O(\log N)$ workspace and $O(N/\log N)$ reads.
That replay collapse is the memory analogue of the present transport ceiling:
a restricted representation obligation does not bind an arbitrary random-
access SAT decider.

learning, caching, alternate encodings, repeated passes, and decide-first
normalization.  No current theorem supplies this universal dichotomy.
