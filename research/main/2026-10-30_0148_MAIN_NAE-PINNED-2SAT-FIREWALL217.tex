\section{Missing lemma and falsifiable mechanisms}

The preceding run left an imprecise target: pinning might ``shrink ternary NAE
edges to binary NAE edges,'' after which odd binary cycles would certify
inextendibility.  Four mechanisms were tested:
\begin{enumerate}
\item one pinned literal may instead yield only one ordinary binary clause;
\item two equal pins may yield a unit, while two unequal pins satisfy the NAE
constraint completely;
\item if every designated clause is hit, the whole residual may be exactly
2CNF and standard SCC, not an independent NAE odd-cycle calculus;
\item treating every one-pin residual as disequality may reject genuine source
models.
\end{enumerate}
All four hold.  Mechanism 4 produces 2,304 exact false rejections on the K4
paired sign census.

\section{Exact restriction calculus}

Let $D=(\ell_1,\ell_2,\ell_3)$ be a signed NAE clause.  A source assignment
satisfies the complement-paired ordinary clauses $D\wedge\overline D$ exactly
when the three literal truth values are not all equal.

\begin{lemma}[one-clause restriction]
Let $\rho$ pin at least one variable of $D$.
\begin{enumerate}
\item If pinned literal truth values contain both 0 and 1, $D$ is already NAE
satisfied.
\item If all pinned literal truth values equal $c$ and two literals remain,
the residual is the single binary clause requiring at least one remaining
literal to have truth $1-c$.
\item If all pinned literal truth values equal $c$ and one literal remains,
that literal is forced to truth $1-c$.
\item If all three are pinned, equal values give conflict and mixed values give
satisfaction.
\end{enumerate}
\end{lemma}
\begin{proof}
NAE fails exactly when all three literal truth values equal the same bit.
Each case is the direct exclusion of that one all-equal completion.
\end{proof}

For example, pinning $x=0$ in $\operatorname{NAE}(x,y,z)$ gives
\[
 y\vee z,
\]
not $y\ne z$.  The assignment $y=z=1$ satisfies the NAE clause but violates
disequality.  Thus the proposed raw odd-cycle interpretation is false at the
smallest possible source.

\begin{theorem}[hitting partial assignment gives exact 2CNF]
Let $\mathcal D$ be any signed NAE-3 formula and let $\rho$ be a coherent
partial assignment whose domain intersects every source clause.  In time
linear in the source encoding, construct a 2CNF $G_\rho$ such that
\[
 \rho\text{ extends to an NAE model of }\mathcal D
 \quad\Longleftrightarrow\quad
 G_\rho\text{ is satisfiable}.
\]
An UNSAT residual has the standard SCC certificate: some remaining variable
and its negation lie in one implication component.
\end{theorem}
\begin{proof}
Apply the lemma independently to every original clause, retaining its source
index.  Satisfied clauses disappear; the other cases emit an empty, unit, or
binary clause.  Since every clause is hit, no ternary residual remains.
Conjunction preserves exact extension equivalence.  Linear-time 2SAT by SCC
then decides the residual and supplies the usual contradictory-component
certificate.
\end{proof}

\paragraph{Known overlap and scope.}
This is precisely a supplied strong 2CNF-backdoor assignment.  Nishimura,
Ragde and Szeider formalized strong backdoors to 2CNF and Horn and showed
fixed-parameter tractable detection by backdoor size.  The present clause
calculus is an exact NAE/complement-paired instantiation, not a novelty claim.
If a hitting set has size $b$, trying all its assignments costs $2^b$ 2SAT
calls; applicability alone does not imply polynomial total work.
