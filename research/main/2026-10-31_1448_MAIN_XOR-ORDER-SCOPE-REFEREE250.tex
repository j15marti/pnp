\section{Claim card, target, and preregistered falsifiers}
The canonical complete language is D\"ocker's duplicate-free proper clausewise-monotone
3-SAT-(2,2): every clause has three distinct same-sign variables, clauses are unique,
and each variable occurs exactly twice in each polarity.  Malformed strings must be
rejected.  The broader proper strict-2P2N language remains comparison only.

\paragraph{Exact obstruction.}
Does changing the order of one-way assignment flips reduce the cumulative XOR of the
fixed original-source logical residual state, and if it does not, can that invariance
become unavoidable physical work in the indexed FLMV machine?

\paragraph{Quantifiers and SAME\_REALIZATION.}
Fix one clausewise-monotone formula $F$, comparable assignments $a\le b$ or $a\ge b$,
one fixed aligned encoding $e$ of the clause count in two bits, and the logical state
\[
 S_e(F,a)=a\;\Vert\;\bigl(e(t_j(a)),\mathbf 1[t_j(a)>0]\bigr)_{j=1}^m.
\]
For every permutation of the coordinates on which $a$ and $b$ differ, the path flips
each such coordinate exactly once toward $b$.  This is an offline source-indexed
logical object, not an arbitrary solver's physical tape.

Four falsifiers were tested before extension:
\begin{enumerate}
\item F1: a different flip order lowers the complete $0^n\to1^n$ logical XOR ledger;
\item F2: the identity extends unchanged to incomparable endpoints or backtracking;
\item F3: invariant logical XOR fixes physical time or distinguishes SAT from UNSAT;
\item F4: an FLMV index reset obeys a local one-cell-change premise without charging
      the bits previously written into the index tape.
\end{enumerate}
F1 is false by the theorem below; F2--F4 are false as proposed generalizations.

\section{Exact theorem independently reconstructing and strengthening GATE283}
For adjacent counts define the representation edge weight
\[
 w_e(r,r+1)=d_H(e(r),e(r+1))+\mathbf 1[r=0].
\]
The second term is the satisfaction-bit change when the count crosses zero.

\begin{theorem}[Comparable-endpoint XOR order invariance]
Let $F$ be any clausewise-monotone CNF with distinct variables inside each clause.
Let $a,b\in\{0,1\}^n$ satisfy $a\le b$ coordinatewise or $a\ge b$.  Every path that
flips each differing coordinate exactly once from $a$ toward $b$, in an arbitrary
order, has cumulative adjacent logical XOR
\[
 d_H(a,b)+\sum_{j=1}^m
 \sum_{r=\min\{t_j(a),t_j(b)\}}^{\max\{t_j(a),t_j(b)\}-1}w_e(r,r+1).
\]
Its endpoint XOR is
\[
 d_H(a,b)+\sum_{j=1}^m
 \left[d_H(e(t_j(a)),e(t_j(b)))+
 \left|\mathbf1[t_j(a)>0]-\mathbf1[t_j(b)>0]\right|\right].
\]
Both quantities are independent of the flip order and of the SAT/UNSAT label.
\end{theorem}
\begin{proof}
Assume $a\le b$; the other case is symmetric.  Every differing assignment bit changes
once.  In a positive clause, each changed incident variable increases the true-literal
count by one; in a negative clause it decreases that count by one.  Consequently each
clause visits every integer between its endpoint counts exactly once, regardless of
the interleaving of its incident variables with other flips.  Summing the fixed edge
weights proves the path formula.  Direct comparison of the two endpoint vectors gives
the endpoint formula.  No satisfiability assumption occurs in the proof.
\end{proof}

\begin{corollary}[GATE283 full sweep]
For a proper clausewise-monotone width-three formula, the $0^n\to1^n$ sweep has
\[
\begin{array}{c|cc}
&\sum d_{\rm logic}&d_{\rm endpoint}\\\midrule
\text{ordinary binary counts}&n+5m&n+3m\\
\text{reflected Gray counts}&n+4m&n+2m.
\end{array}
\]
Thus LSPV-3 GATE283 is independently certified at its declared logical scope.  The
present theorem adds arbitrary comparable endpoints, not a SAT algorithm or lower bound.
\end{corollary}

\section{Sharp scope boundary and physical countercontrols}
The comparable-endpoint hypothesis is material.  For the single proper positive clause
$(x_1\vee x_2\vee x_3)$, ordinary binary logical state from $001$ to $110$ has sum
$7$ under order $(x_1,x_2,x_3)$ but $9$ under order $(x_1,x_3,x_2)$.  With reflected
Gray counts, $001\to010$ costs $4$ when $x_2$ precedes $x_3$ and $6$ in the reverse
order.  These are exact minimal searched counterexamples to the unrestricted extension,
not target-language hardness examples.  A backtracking route from $000$ to $110$ costs
$12$ binary/$11$ Gray versus $6$/$5$ on a direct route.

Even within the invariant regime, order can change physical work.  Across all 720 full
sweeps of $Y_6$, logical sums were identically $46$ binary and $38$ Gray.  In one
declared eager single-sequential-tape materialization, however, write-plus-head costs
ranged from $295$ to $319$ binary and from $287$ to $311$ Gray.  A lazy realization
stores only assignment bits and recomputes clause counts from the read-only source;
its writes need not resemble the logical ledger, while its reads remain charged.
Read-only DELAY, same-value writes, changed-then-restored bits and repeated source reads
all demonstrate positive time with zero endpoint content XOR.

The native FLMV index primitive adds a separate firewall.  If $Q$ is the number of
ordinary changed cell bits, $E$ the number of live index one-bits atomically erased,
$B_0$ the initial live index ones, and $D$ the sum of endpoint Hamming distances over
disjoint chronological intervals, then
\[
 D\le Q+E\le2Q+B_0\le2qT+B_0.
\]
Every erased one was initially present or previously created, so $E\le B_0+Q$.
For initially blank index tapes this gives $T\ge D/(2q)$ over the whole run.  The factor
two is asymptotically sharp by writing $h$ ones and then erasing them in one indexed
jump.  The isolated reset interval can change $h$ cells in one step; therefore the
user's one-cell-per-tape premise cannot be silently applied to this bulk-erasing model.
This independently certifies LSPV-1 ARC-INDEX-RECHARGE283/LSPV-4 ARC282 at their
model-specific scope.

\section{Resource, arbitrary-algorithm, and affine audits}
The XOR tracer is offline.  If a SAT machine constructs or scans the complete vectors,
it pays source reads, alignment, XOR computation, changed-record indexing, policy
selection, retained states and output.  An arbitrary solver may skip this route, keep
lazy flags, reread the source, use a different encoding, or invoke an exact fallback.
The theorem neither emits a power-short child nor proves hereditary closure, malformed
input totality, or a bit-local SAT-to-target reduction.  Hence it supplies no missing
arrow in the conditional recurrence
\[
 K'\le\max\{11/10,3/5+K/2\},\qquad
 L'\le\max\{1/2,L/2\}.
\]

AFFINE-SMALLBIAS-DESCENT-GATE2 remains correct only for its pointwise all-input,
source-independent affine MCSP maps with the corrected target-set count.  The present
nonlinear clause-count state is outside those hypotheses.  Neither theorem forces an
arbitrary SAT algorithm to instantiate the audited object; neither promotes restricted
semantic indistinguishability to SAT runtime.  The nonlinear, source-dependent semantic
map that simply outputs a fixed YES or NO target according to the SAT answer remains the
quantifier firewall, with acquisition equal to the original decision problem.

Relativization and algebraic-oracle audits are adverse: a semantic SAT oracle bypasses
the entire trace, while an affine/Gaussian oracle bypasses affine controls.  The exact
logical identity survives only as a representation fact.  This is a \emph{failed
