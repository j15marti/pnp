\section*{Executive finding}
The user-approved XOR state-difference adjunct is sound after a strict type
separation.  For one declared execution on $k$ fixed-location binary writable
tapes, the Hamming distance between tape contents at two checkpoints is a lower
bound on the number of cell changes in that interval.  If one native step can
change at most one cell on each tape, then native interval time is at least the
distance divided by $k$.  These interval bounds add across disjoint consecutive
intervals.

The corresponding claim for a source-indexed \emph{logical} residual vector is
\Status{Falsified/Retired}.  The same logical clause counts may be materialized,
stored lazily, or recomputed from the read-only source; reads, head moves,
unchanged writes, restored writes, and DELAY steps can consume time with zero
checkpoint XOR.  Binary versus Gray encodings change the physical delta of the
same abstract counter sequence.  Variable-length insertion changes cell
identity, making a positionwise XOR incomparable.  Thus $d_{\rm logic}$ is a
useful offline diagnostic but not an arbitrary-machine time lower bound.

This report preserves D"ocker's duplicate-free proper Monotone
$3$-SAT-$(2,2)$ as the one canonical NP-complete target, rejects malformed
strings, retains signed $S/U$ extrema as adversarial controls, and does not
promote the affine small-bias MCSP theorem to SAT runtime.  The all-input
hereditary arbitrary-$A\mapsto\Phi(A)$ ARC contraction, numerical FLMV
transport, and P versus NP remain \Status{Open}.

\section{Exact theorem and proof}
Let $W_t\in\{0,1\}^{B}$ be the aligned contents of all declared writable tape
cells at native time $t$.  Fix checkpoint times
$0=t_0<t_1<\cdots<t_r=T$, and define
\[
 d_i=\operatorname{popcount}(W_{t_i}\oplus W_{t_{i+1}}).
\]

\paragraph{Physical interval XOR lemma (\Status{Proved/Exact}).}
If one native step changes at most one binary cell on each of $k$ writable
tapes, then
\[
 t_{i+1}-t_i\ge \left\lceil\frac{d_i}{k}\right\rceil,
 \qquad
 T\ge\sum_{i=0}^{r-1}\left\lceil\frac{d_i}{k}\right\rceil
 \ge \left\lceil\frac{\sum_i d_i}{k}\right\rceil.
\]
Moreover the endpoint distance satisfies
\[
 \operatorname{popcount}(W_{t_0}\oplus W_{t_r})\le\sum_i d_i.
\]

\paragraph{Proof.}
Every cell that differs between two interval endpoints must change an odd,
hence positive, number of times in the interval.  There are $d_i$ such cells.
At most $k$ cells change in one native step, so the interval contains at least
$\lceil d_i/k\rceil$ steps.  The intervals are disjoint, so their lower bounds
sum.  The endpoint inequality is the triangle inequality in the Boolean cube.
\hfill$\square$

The lemma remains true when reads, moves, control changes, and unchanged writes
are present: they increase time without increasing $d_i$.  It becomes invalid
if one compares different cell identities, treats a multi-bit word write as one
single-bit change, or substitutes a virtual logical vector for physical tape
contents.  A full-state tracer is charged if computed online; in this run it is
explicitly an offline diagnostic.

\section{Canonical logical and physical policies}
For a target formula with $n$ variables and $m$ original clauses, the aligned
logical checkpoint vector was
\[
 S_{\rm logic}(a)=
  a_1\cdots a_n\;\Vert\;
  \big\Vert_{j=1}^{m}
   \left(\operatorname{bin}_2(t_j(a)),[t_j(a)>0]\right),
\]
of length $n+3m$.  Record IDs are
\texttt{assignment:x\(i\)}, \texttt{clause:C\(j\):count\_bit0/1}, and
\texttt{clause:C\(j\):sat}.  Two implementations were contrasted:
\begin{itemize}
\item \emph{eager materialized}: the assignment, every two-bit clause count,
and every SAT flag occupy fixed cells, so this selected data layout has
$d_{\rm phys}=d_{\rm logic}$;
\item \emph{lazy assignment-only}: only assignment bits are retained.  Counts
and flags are recomputed by scanning the $3m$ literal occurrences at each
checkpoint.  Its selected physical delta is only the assignment Hamming
distance, while all reads and head work remain charged.
\end{itemize}
Neither is asserted to model HiGHS, CDCL, or every target decider.

\section{Hostile representation and wrapper controls}
\begin{itemize}
\item A width-10 binary counter cycle has delta 2,046; the reflected Gray cycle
has delta 1,024.  Both enumerate the same 1,024 abstract values.
\item A 10,000-step read-only DELAY loop has endpoint $d_{\rm phys}=0$.
\item Repeating scratch $0\to1\to0$ 1,000 times performs 2,000 writes and has
endpoint delta zero.  Inserting checkpoints after every toggle would expose
the changes; coarse checkpoints do not.
\item One thousand same-value writes have endpoint delta zero but consume one
thousand native write steps in the declared model.
\item Prefix insertion into a variable-length packed record changes one
semantic record but gives positionwise Hamming distance seven in the finite
control.  The fixed-location lemma is inapplicable because later cell identities
shifted.
\end{itemize}
These controls falsify equality between XOR and work.  They do not falsify the
physical interval lower bound, which is intentionally one-sided.
