\section{Exact obstruction, target, and falsifiers}
The one hardness language is D\"ocker's duplicate-free proper clausewise-monotone
3-SAT-(2,2): every clause has three distinct variables of one sign, clauses are
unique, and every variable occurs exactly twice in each polarity.  A total
language decider rejects malformed strings.  The broader proper strict-2P2N
class is only a comparative superset.  The exact obstruction addressed here is:
\emph{cumulative logical XOR mixes endpoint boundary flux with arbitrarily
repeatable opposite-direction churn}.  The four predeclared falsifiers were:
\begin{enumerate}
\item[F1.] boundary activity is monotone progress toward SAT;
\item[F2.] fixed endpoints determine cumulative logical XOR;
\item[F3.] XOR churn distinguishes same-target SAT from UNSAT;
\item[F4.] logical XOR churn is an unavoidable physical-write/runtime tariff
for an arbitrary exact solver.
\end{enumerate}
All four fail in their universal form.  The weaker fixed-layout cell-change
lower bound from REFEREE249 remains valid.

\section{Exact endpoint-plus-churn theorem}
For a complete assignment $a_t$, let $N_r(t)$ be the number of original clauses
with exactly $r$ true literals.  The canonical aligned logical state consists of
the assignment bits and, for every source-indexed original clause, its two-bit
true-count code and SAT-status bit.  Let $d_G(t)$ and $d_B(t)$ be adjacent
Hamming distances using respectively Gray and ordinary binary true-count codes.

Across a trace of $T$ single-variable flips define $R_0,F_0$ as the total
numbers of $0\to1$ and $1\to0$ clause-count transitions, and $R_1,F_1$ as the
total numbers of $1\to2$ and $2\to1$ transitions.  Put
\[
C_0=\min(R_0,F_0),\qquad C_1=\min(R_1,F_1).
\]

\begin{theorem}[Endpoint flux plus paired boundary churn]
For every valid canonical target formula, every complete start assignment, and
every finite, possibly backtracking, variable-flip trace,
\begin{align}
\sum_{t<T}d_G(t)
 &=5T+|\Delta N_0|+2C_0,\label{eq:gray}\\
\sum_{t<T}d_B(t)
 &=5T+|\Delta N_0|+|\Delta(N_0+N_1)|+2(C_0+C_1).\label{eq:binary}
\end{align}
\end{theorem}
\begin{proof}
Every target variable occurs in four distinct original clauses.  One flip
changes its assignment bit and moves each of the four incident clause counts by
one.  A Gray count therefore changes one bit per incident clause, while ordinary
binary uses one additional bit exactly on a $1\leftrightarrow2$ transition.  The
SAT-status bit changes exactly on a $0\leftrightarrow1$ transition.  Hence the
already verified single-step identities are
\[
d_G=5+B,qquad d_B=5+B+H,
\]
where $B$ and $H$ count the two respective boundaries.  Summing gives
$\sum B=R_0+F_0$ and $\sum H=R_1+F_1$.  Endpoint conservation gives
\[
\Delta N_0=F_0-R_0,qquad
\Delta(N_0+N_1)=F_1-R_1.
\]
For nonnegative integers $x,y$, $x+y=|x-y|+2\min(x,y)$.
Applying this identity at the two boundaries proves
\eqref{eq:gray}--\eqref{eq:binary}.  No satisfiability label is used.
\end{proof}

\begin{corollary}[Restored-bit churn is arbitrarily amplifiable]
For any nonempty target formula and any variable, repeat the two-step loop that
flips that variable and immediately flips it back.  The endpoint assignment,
all true counts, and every status bit return exactly, so endpoint logical XOR is
zero.  Nevertheless each repetition adds positive adjacent XOR.  Thus
cumulative logical XOR is neither an endpoint potential nor a monotone progress
certificate.  It can be inflated without changing the source, endpoint, or SAT
label.
\end{corollary}

\section{Physical semantics and resource ledger}
Logical and physical state are typed separately.
\begin{itemize}
\item In a fully materialized fixed-slot state, checkpoint $d_{\rm phys}$ equals
the corresponding aligned logical Hamming distance.  On $k$ fixed writable
tapes this gives the exact representation-specific lower bound
$\sum_i\lceil d_{{\rm phys},i}/k\rceil$ over disjoint intervals.
\item In the declared lazy checkpoint model, only the assignment tape is
retained; scratch, control and index fields are returned to the same zero
checkpoint state, and clause counts are virtual.  The 1000-step restored U/V
loops therefore have adjacent checkpoint $d_{\rm phys}=1000$, endpoint zero,
while materialization gives 7000.  This diagnostic still charges 1000 assignment
writes and 12,000 incident-literal source reads after a supplied occurrence
index; native index-head motion/reset was not simulated and no FLMV upper bound
is claimed.
\item A 10,000-step read-only DELAY loop has zero data-bit XOR.  Source rereads,
head movement, unchanged writes and failed attempts can consume time with no
data-bit change.  Conversely, variable-length or unaligned encodings do not
admit cellwise XOR until an alignment and its maintenance cost are declared.
\end{itemize}
Full-state tracing is offline here.  If placed inside a SAT machine, producing,
aligning and comparing the state is charged.  Discovery, policy
selection/switching, failed routes, source/tape/query/child access, guest
simulation, retained ancestors, output, proof checking and simultaneous peak
writable/index space are not supplied by the identity.
