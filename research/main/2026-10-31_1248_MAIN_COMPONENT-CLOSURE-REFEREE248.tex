\section*{Executive finding}
The canonical language is the set of all well-formed, duplicate-free, proper
Monotone $3$-SAT-$(2,2)$ instances: every clause has three distinct literals of
one sign, every clause is unique, and every variable occurs exactly twice in
each polarity.  Malformed strings are rejected.  The broader strict-$2$P$2$N
grammar is comparison only.

This run independently reconstructs and certifies the incidence-component
closure theorem reported by LSPV-2.  If $F$ is a valid canonical instance and
$J$ is a nonempty set of its unchanged original clauses, then $F[J]$ is again a
valid canonical instance if and only if $J$ is a union of whole connected
components of the clause--variable incidence graph.  Consequently, a connected
valid input has no nonempty proper source-faithful deletion child.  This is an
exact hereditary rule, not a universal contraction: the canonical connected
UNSAT instance $U_{198}$ and its connected two-occurrence swap $V_{198}$ (SAT)
both have child/parent ratio $1$ under this rule.

The rule therefore fills only a restricted ARC arrow for disconnected inputs
whose largest component is already power-short.  It does not establish the
required all-input $N\mapsto N^\lambda$ contraction, a strict-FLMV bit-local
compiler, a polynomial target-language decider, or a lower bound.  The affine
small-bias theorem remains a restricted semantic MCSP no-go and is not promoted
to SAT runtime.  \textbf{P versus NP remains open.}

\section{Exact obstruction and falsifiers}
The exact obstruction named before proof work was:
\begin{quote}
Can source-faithful incidence-component decomposition give an all-input,
hereditary, same-model ARC contraction without a free component oracle,
parent-scale routing tables, or a false power-short guarantee?
\end{quote}
The run tested four falsifiable claims.
\begin{enumerate}
  \item Every nonempty proper subset of original clauses remains in the target
  language.  \Status{Falsified}: only unions of whole incidence components do.
  \item Exact component closure implies a universal power-short child.
  \Status{Falsified}: connected $U_{198}$, $V_{198}$, and $Y_6$ have no proper
  source-faithful target child.
  \item Deterministic logspace connectivity makes component routing free in the
  FLMV model.  \Status{Falsified as stated}: Reingold gives logarithmic space
  and polynomial time, not the simultaneous strict exponents or the complete
  dense child-bit accessor required here.
  \item Failure of both endpoint assignments, or opposite literal preferences,
  certifies UNSAT.  \Status{Falsified} by the independently replayed SAT witness
  for $V_{198}$; its endpoints fail while an intermediate assignment satisfies.
\end{enumerate}

\section{Independently reconstructed theorem}
Let $B(F)$ be the bipartite graph with a clause vertex $c_j$, a variable vertex
$x_i$, and edge $(c_j,x_i)$ for every occurrence of $x_i$ in $c_j$.

\paragraph{Theorem (source-faithful component closure; \Status{Proved/Exact}).}
For a valid canonical instance $F$ and nonempty $J\subseteq[m]$, retain exactly
the original clauses indexed by $J$ and delete variables with no remaining
occurrence.  The resulting formula is a valid canonical instance if and only if
$J$ is a union of connected components of $B(F)$.

\paragraph{Proof.}
Suppose the retained formula is valid and $c_j\in J$.  For every variable $x$
in $c_j$, validity requires both positive and both negative occurrences of $x$
to remain.  Hence every clause adjacent to $x$ in $B(F)$ also lies in $J$.
Repeating this closure step along alternating clause--variable paths shows that
the entire connected component of $c_j$ lies in $J$.  Thus $J$ is a union of
components.  Conversely, no variable has an occurrence crossing between two
components.  Retaining a union of components therefore retains all four
occurrences of each retained variable; clause arity, monotonicity, distinctness,
and uniqueness are inherited unchanged.  Hence the child is valid. \hfill$\square$

\paragraph{Corollaries.}
If $F=\bigwedge_{r=1}^k F_r$ is the component decomposition, then
\[
   F\in\mathrm{SAT}\quad\Longleftrightarrow\quad
   \bigwedge_{r=1}^k(F_r\in\mathrm{SAT}).
\]
A SAT witness is the disjoint union of component witnesses; an UNSAT certificate
for one component lifts to $F$.  For this particular source-faithful rule, if
$M(F)=\max_r |F_r|$ and parent size is measured in unchanged clause records,
then a power-short guarantee exists exactly when $M(F)\le |F|^\lambda$.
Connected instances have $M(F)=|F|$, so no fixed $\lambda<1$ works on all valid
inputs.  This is a limitation of this rule, not a lower bound against arbitrary
re-encodings or algorithms.
