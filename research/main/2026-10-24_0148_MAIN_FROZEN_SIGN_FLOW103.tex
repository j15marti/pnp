\begin{abstract}
We give a complete candidate solution to the partial frozen-sign experiment proposed by CAPACITY-SIGNING70.
For a fixed source assignment, prescribed per-variable polarity quotas, and an arbitrary
partial signing, existence of a completion satisfying every clause is exactly a
lower-bounded bipartite flow problem.  A minimum-Hamming full repair is exactly a
min-cost integral circulation.  Specializing further, every monotone exact-$(2,2)$
3-CNF with $m$ clauses is at Hamming distance exactly $m$ from the set of balanced
signings satisfied by all TRUE.  Two Hall matchings construct an optimum repair.
The verified 198-variable, 264-clause D\"ocker UNSAT source therefore has an optimum
all-true balanced repair at distance exactly 264, improving the nonoptimal distance 398
construction in MAIN102.  This sharpens the signed-semantic boundary but supplies no
SAT-preserving hardness reduction and no unrestricted time lower bound.
\end{abstract}

\section{Exact partial-sign completion theorem}

Let $d_v$ be the occurrence degree of $v$ and require exactly $p_v$ positive signs.
Under a fixed assignment $a$, the required number of true literal occurrences at $v$ is
\[
c_v(a)=\begin{cases}p_v,&a_v=1,\\d_v-p_v,&a_v=0.\end{cases}
\]
Some occurrence signs are frozen.  Let $f_v$ be the number of frozen occurrences at $v$
that are true under $a$, and let $h_C$ be the frozen-true count in clause $C$.  For every
unfrozen incidence $e=(v,C)$, let $x_e=1$ mean that its completed literal is true under
$a$.  Define
\[
r_v=c_v(a)-f_v,
\qquad
b_C=\max\{0,1-h_C\}.
\]

\begin{theorem}[Frozen-sign completion, CANDIDATE]
A quota-respecting completion satisfied by the prescribed assignment exists exactly when
the integral system
\[
\sum_{e\ni v}x_e=r_v\quad(v\in V),
\qquad
\sum_{e\in C}x_e\ge b_C\quad(C\in E),
\qquad x_e\in\{0,1\}
\tag{1}
\]
is feasible over unfrozen incidences.  Feasibility, a completed signing, or a violated-cut
certificate is computable in polynomial time and linear network size.
\end{theorem}

\begin{proof}
Reject immediately if some $r_v$ is negative or exceeds the number of unfrozen
occurrences at $v$.  Build a bipartite network from variable nodes to clause nodes, with
one capacity-one edge per unfrozen incidence.  Give each variable exact supply $r_v$.
Give clause $C$ a lower outflow bound $b_C$ and upper bound equal to its number of
unfrozen incidences.  Add the standard return edge and reduce lower bounds to node
imbalances.  An integral feasible circulation is precisely a solution of (1), because
network matrices are totally unimodular.  Each selected occurrence has the unique sign
making it true under $a$; each unselected occurrence has the opposite sign.  Conversely,
any valid completion supplies such a circulation.  Source parsing and explicit output
are linear; any standard augmenting-path or blocking-flow implementation is polynomial.
\end{proof}

This theorem includes arbitrary frozen true and false signs.  It does not choose $a$;
jointly choosing a satisfying assignment remains the SAT problem.

\section{Minimum edit and the exact monotone formula}

For a fully signed source $F$ with the same quotas, put cost one on an occurrence choice
whose truth value under $a$ differs from its current truth value, and cost zero otherwise.

\begin{theorem}[Fixed-witness minimum repair, CANDIDATE]
The minimum sign-field Hamming distance from $F$ to a quota-respecting signing satisfied
by $a$ is the minimum cost of the circulation above.  It is integral and polynomial-time
computable.
\end{theorem}

\begin{proof}
Changing a sign changes exactly the truth status of that occurrence under the fixed
assignment.  Thus the circulation cost is exactly sign Hamming distance.  Integral
min-cost flow returns an optimum signing, and every repaired signing maps back to a flow
of equal cost.
\end{proof}

For the exact endpoint there is a sharper closed form.

\begin{theorem}[Monotone exact-$(2,2)$ edit distance, CANDIDATE]
Let $F$ be any proper monotone exact-$(2,2)$ 3-CNF with $m$ clauses.  Among all balanced
exact-$(2,2)$ signings on the same ordered unsigned occurrence records that are satisfied
by all TRUE, the minimum sign Hamming distance from $F$ is exactly
\[
\boxed{m}.
\]
An optimum repair is constructible by two bipartite matchings.
\end{theorem}

\begin{proof}
Exact balance gives equal total positive and negative occurrences, so precisely $m/2$
clauses are all positive and $m/2$ are all negative.  Every all-true-satisfied target must
flip at least one negative occurrence in each negative clause, hence at least $m/2$
negative-to-positive signs.  Preserving two positive signs per variable forces the same
number of positive-to-negative flips, giving the lower bound $m$.

For achievability, form the negative-clause--variable incidence graph.  Each negative
clause has degree three and each variable has degree two.  For any negative-clause set
$Q$, $3|Q|\le2|N(Q)|$, so Hall's condition holds.  Match every negative clause to a
distinct incident variable and flip that occurrence positive.  Let $R$ be the selected
variables, so $|R|=m/2$ and every selected variable now needs one positive occurrence
flipped negative.  Join each $v\in R$ to its two positive clauses, and give every positive
clause two clones.  For $X\subseteq R$, degree counting gives
$2|X|\le3|N(X)|\le4|N(X)|$, so Hall again assigns each selected variable to one positive
clause while using any clause at most twice.  Flip those assigned positive occurrences
negative.  Every negative clause gains one true literal, every positive clause retains at
least one, and every variable returns to two signs of each polarity.  Exactly $m$ fields
were flipped.
\end{proof}
