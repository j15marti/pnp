\section{Tight randomized theorem}
We use an adaptive randomized bit-query model. Work counts every physical
query, so lower bounding the number of blocks in which an A/B-discriminating
field is read is sound. No assignment, witness, or pin key is retained.

\begin{theorem}
For $0\le\varepsilon<1/2$, the minimum worst-input expected number of
discriminating pin-bit queries for the authenticated $G_t$ A/B promise is
\[
R^{\mathrm{exp}}_\varepsilon=(1-2\varepsilon)t.
\]
Deterministic exact and zero-error randomized complexity are $t$; error
$1/3$ has exact expected complexity $t/3$.
\end{theorem}
\begin{proof}
Run an algorithm on all-A with a fixed random tape. Let $Q$ be the blocks in
which it reads a discriminating field and $E$ the event it outputs SAT.
Correctness gives $\Pr(E)\ge1-\varepsilon$. Couple this run with the input
having a sole B in block $i$. On $E\cap\{i\notin Q\}$ the transcripts are
identical, hence that input is answered incorrectly. Therefore
$\Pr(E\cap\{i\notin Q\})\le\varepsilon$ for every $i$. Summing,
\[
\mathbb E[(t-|Q|)\mathbf1_E]\le\varepsilon t.
\]
The left side is at least
$t(1-\varepsilon)-\mathbb E|Q|$, so
$\mathbb E|Q|\ge(1-2\varepsilon)t$.

For equality, with probability $1-2\varepsilon$ query one discriminating bit
in every block and decide exactly; with probability $2\varepsilon$ query
nothing and guess fairly. Every input has error $\varepsilon$ and expected
cost $(1-2\varepsilon)t$.
\end{proof}

This is a direct coupling proof. Yao's 1977 minimax theorem is relevant
primary context for randomized decision trees, but is not imported.
