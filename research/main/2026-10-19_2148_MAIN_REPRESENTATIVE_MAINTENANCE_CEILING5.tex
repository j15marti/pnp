\section{General representative-maintenance lemma}
Let $\mathcal W$ be a finite, effectively enumerable witness set.  Every
$w\in\mathcal W$ has a descriptor of at most $L$ bits and defines an $N$-bit
word $f_w$.  Assume enumeration uses $G$ work bits and one bit $f_w(j)$ is
evaluable using $V$ work bits in time $E$.

\paragraph{Theorem (PROVED/EXACT).}
There is a deterministic one-pass algorithm which, on stream
$x_0,\ldots,x_{N-1}$, outputs a witness $w$ with $f_w=x$ if one exists and
otherwise rejects.  It uses
\[
 2L+G+V+O(\log N)
\]
work bits.  At position $t$, its update time is at most
\[
 O\bigl(|\mathcal W|(t+1)E\bigr)
\]
plus enumeration overhead.

\paragraph{Proof.}
Maintain either a witness $c_t$ agreeing with the source through position $t$
or a permanent reject flag.  Given $x_t$ and $c_{t-1}$, enumerate witnesses
$w$ and select the first satisfying
\[
 f_w(t)=x_t,
 \qquad
 f_w(j)=f_{c_{t-1}}(j)\quad(0\le j<t).
\]
The induction invariant for $c_{t-1}$ makes the second condition equivalent to
agreement with the unavailable earlier source bits.  If no such witness
exists, no completion of the current prefix belongs to the witness image, so
permanent rejection is sound.  At $t=N-1$, a surviving witness computes the
complete source.  The algorithm stores current and candidate descriptors,
enumerator state, reusable evaluator state, one comparison bit, and counters.
The stated time follows from testing at most $|\mathcal W|$ candidates on at
most $t+1$ positions. \hfill$\square$

\section{Search-MCSP specialization}
For fan-in-two AND/OR/NOT circuits with $n\le s$, use the previously audited
description bound
\[
 L(n,s)=s\left(2+2\left\lceil\log_2(n+s)\right\rceil\right)
 +\left\lceil\log_2(n+s)\right\rceil.
\]
Circuit enumeration fits in $O(L)$ bits, and evaluation at one assignment uses
$O(s+n)$ bits and polynomial time.  Therefore full deterministic one-pass
search-MCSP has an exact uniform algorithm with
\[
 O(s\log s)\text{ space},\qquad
 U_t\le 2^{L(n,s)}(t+1)\operatorname{poly}(s),
\]
and hence worst-case update time $2^{O(s\log s)}$.

This is an upper bound, not a fast algorithm.  It disproves any proposed
$s^{\omega(1)}$ \emph{space-only} lower bound for unrestricted update time.  It
does not meet MMW's polynomial-update hypothesis.

\section{Primary-source model audit}
MMW's source paper gives a one-pass search-MCSP upper bound with
$\widetilde O(s)$ space and $\widetilde O(s^2)$ update time using small
$\Sigma_3\mathrm{SAT}$-oracle queries.  Its magnification statement concerns
the absence of a deterministic one-pass algorithm having both polynomial
space and polynomial update.  The theorem above supplies only the former.
CHMY instead proves a randomized two-sided-error one-tape MCSP lower bound with
an additional one-way read-only input tape at a specific larger threshold.
OPS requires GapMCSP circuit excess for every sufficiently small $\beta>0$.
FLMV concerns deterministic random-access SAT time and space.  None of these
models is supplied by a stationary-DFA section or an exponentially slow
representative update.
