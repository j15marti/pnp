\section{Completed-query DELAY/COPY theorem}
Work on the indexed read-only-input, deterministic random-access multitape model
used by FLMV, with ordinary physical SAT strings.  A \emph{completed guest call}
means that the generated machine invokes the supplied guest on a physical query
and waits for its answer; a step-interleaved simulation that can abandon the
guest is not a completed call.

\begin{theorem}[Large completed-call firewall]
Assume $P=NP$, and fix a correct polynomial ordinary-SAT decider $B$ with finite
simultaneous exponents $(K_0,L_0)$.  Let $\Phi$ be a fixed wrapper-oblivious
black-box compiler claiming (1) for every correct polynomial guest.  Suppose
there are $\eta>\lambda$ and infinitely many source lengths $N$ such that, for
every sufficiently large integer $D$, some $N$-bit execution of $\Phi(A_D)$
completes a call to $A_D$ on a physical ordinary-SAT query of length
$m\ge N^{\eta-o(1)}$.  Here $A_D$ first performs $m^D$ dummy transitions and
then runs $B$.  Then the time inequality in (1) is false.  If instead $A_D$
first touches $m^D$ distinct writable cells, clears them and runs $B$, the space
inequality is false as well.
\end{theorem}

\begin{proof}
Choose $D>K_0,L_0$.  The delayed guest is still a fixed uniform total correct
polynomial SAT decider, with time exponent $D$ up to replacing $D$ by
$\max\{D,K_0\}$.  A completed call takes at least
$m^D\ge N^{\eta D-o(D)}$ transitions.  The claimed upper exponent is at most
$\max\{\alpha,\gamma+\lambda D\}$.  Since $\eta-\lambda>0$, choose
\[
 D>\max\left\{K_0,L_0,\frac{\alpha}{\eta},
                         \frac{\gamma}{\eta-\lambda}\right\}.
\]
Then $\eta D>\alpha$ and $\eta D>\gamma+\lambda D$, a contradiction.
The COPY variant simultaneously occupies at least $m^D$ distinct writable
cells, while (1) permits only exponent $\max\{\sigma,\lambda D\}$; enlarge $D$
once more so $\eta D>\sigma$.  Clearing the cells does not reduce peak space.
Both wrappers return exactly $B$'s answer, so no SAT/UNSAT semantic distinction
is used.\qedhere
\end{proof}

The theorem does \emph{not} rule out a code-transforming compiler that proves a
wrapper irrelevant, preempts it, never calls it, or constructs a source-only
solver.  It proves a necessary physical-query condition for the black-box guest
architecture: every unavoidable completed guest query must have exponent at most
$\lambda$ (up to lower-order terms).  A succinct descriptor is not a physical
ordinary guest input unless every requested input bit and its simulation cost are
supplied.  Thus DELAY is a firewall, not a universal separation theorem.

\section{Independent affine-small-bias referee}
The source claim fixes $0<\nu<\mu<1$, source length $N=2^n$, polynomial target
truth-table length $M=2^m$, source MCSP threshold $\lfloor N^\mu\rfloor$ and
absolute target threshold $u_N\le N^\nu$.  For seed $z$ independent of source
$x$, the map is $R_z(x)=A_zx\oplus b_z$.  Completeness and soundness quantify
over \emph{every} source YES and NO truth table before sampling $z$.

\begin{lemma}[Affine fiber bound, independently checked]
If $D$ is $\epsilon$-biased on $\{0,1\}^N$, $A$ is any rectangular binary
matrix, $b$ any offset and $C$ any set of at most $B$ output strings, then
\[
 \left|\Pr_D[Ax\oplus b\in C]-\Pr_U[Ax\oplus b\in C]\right|
 \le B\epsilon .                                                   \tag{2}
\]
\end{lemma}
\begin{proof}
For a consistent fiber $Ax=y\oplus b$, retain $r=\operatorname{rank}A$
independent equations $Lx=c$.  Fourier expansion of its indicator has one
constant character and $2^r-1$ nonzero characters, each bounded by $\epsilon$.
After the $2^{-r}$ normalization, the point-probability gap is at most
$(1-2^{-r})\epsilon\le\epsilon$.  Inconsistent fibers have gap zero; summing
over $C$ proves (2).  Singular and rank-zero maps are included.
\end{proof}

The actual CHMY Theorem 33 PDF was inspected.  It constructs a local
$\epsilon$-biased generator using $\langle a^i,b\rangle$ over
$\mathbb F_{2^d}$ and Lemma 32's near-linear multiplication circuit, giving
local circuit size $\widetilde O(\log(N/\epsilon))\log N$.  Choosing
$\epsilon=2^{-\lceil N^\rho\rceil}$ for $\nu<\rho<\mu$ places every generated
truth table in source YES.  Circuit counting must be written
\[
 \log_2|Y_{M,u_N}|=O\big((u_N+1)\log(m+u_N+2)\big)
                       \le N^{\nu+o(1)},                            \tag{3}
\]
where the $+1$ covers $u_N=0$.  With source-YES density $\eta_N=o(1)$,
(2)--(3) give worst-case error
\[
 e_N\ge\frac{1-\eta_N-|Y_{M,u_N}|\epsilon}{2-\eta_N}
       =\frac12-o(1).
\]
The proof and source/seed quantifiers are correct after correction (3).  Its
scope is only input-independent affine truth-table transformations.  A nonlinear
source-adaptive SAT controller is outside the theorem, so no SAT runtime or
arbitrary-$\Phi$ lower bound follows.
