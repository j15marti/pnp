\begin{abstract}
REFEREE253 proved that exact Hamming distance of two arbitrary aligned $L$-bit snapshots costs $2L$ deterministic probes, or $L$ probes when the previous snapshot is retained.  This run identifies and proves the exact online escape: on D\"ocker's duplicate-free proper Monotone 3-SAT-(2,2), if an authenticated four-occurrence index and the current assignment/count/status state are already materialized, the identity of the flipped variable reconstructs the complete next logical state and every changed record.  The promised single-flip event needs exactly $\lceil\log_2 n\rceil$ fixed-length bits, not a scan of the $L=5n$ logical bits.  A $T$-flip trace replays from $T\lceil\log_2n\rceil$ event bits by induction.  This does not make tracing free: the displayed realization retains $5n$ state bits and at most $4n(\lceil\log_2m\rceil+1)$ incidence-index bits, or must reacquire them at charged cost.  It also does not constrain a SAT decider that omits the tracer.  Same-target SAT Y6/V198 and UNSAT U198, malformed strings, all signed S/U extremes, binary/Gray, renaming, restored-bit, lazy and DELAY controls were independently checked.  Hereditary arbitrary-$A\mapsto\Phi(A)$, tight FLMV transport, and P versus NP remain \status{OPEN}.
\end{abstract}

\section{Exact delta-event theorem}
For a target formula with $n$ variables and $m=4n/3$ clauses, let $I(v)$ be the authenticated list of the four pairs $(j,\sigma)$ saying that variable $v$ occurs in original clause $C_j$ with sign $\sigma$.  Let
\[
 S_E(a)=a\;\Vert\;\big\Vert_{j=1}^{m}
   \bigl(E(t_j(a)),\mathbf 1[t_j(a)>0]\bigr),
\]
where $E$ is the two-bit binary or Gray encoding of $0,1,2,3$.

\paragraph{Theorem 1 (\status{PROVED/EXACT}).}
Given $F$, $I(v)$, $S_E(a)$, and the action ``flip $v$'', the complete next state $S_E(a\oplus e_v)$ and its exact changed-record set are uniquely reconstructible by touching only the assignment record for $v$ and the four clause records named by $I(v)$.

\paragraph{Proof.}
For each $(j,\sigma)\in I(v)$, the old literal is true exactly when $a_v=\sigma$.  Therefore
\[
 t_j(a\oplus e_v)=t_j(a)+
 \begin{cases}-1,&a_v=\sigma,\\+1,&a_v\ne\sigma.
 \end{cases}
\]
All clauses outside $I(v)$ are unchanged.  Toggle $a_v$, re-encode those four counts, and recompute their four SAT-status bits.  Comparing these explicitly updated records with their prior values yields exactly the changed-record IDs and $d_{\rm logic}$.  No semantic SAT answer is used.  Iterating this deterministic update proves exact replay for every finite action sequence. \qed

\paragraph{Theorem 2 (\status{PROVED/EXACT}).}
Under the promise that one of $n$ named assignment variables is flipped, an exact fixed-length event code from which the next assignment delta is reconstructible requires and suffices with $\lceil\log_2n\rceil$ bits.

\paragraph{Proof.}
The $n$ choices produce $n$ different changed assignment records, so an injective fixed-length code has at least $n$ codewords.  Hence its length is at least $\lceil\log_2n\rceil$.  The binary variable identifier attains the bound. \qed

This does not contradict REFEREE253.  That result concerns two arbitrary snapshots with no generating action supplied; this result concerns a promised, known transition plus retained authenticated auxiliary state.

\section{Exact resource fork}
For the canonical target, $m=4n/3$ and the chosen logical vector has
\[
 L=n+3m=5n\quad\text{bits}.
\]
A fixed four-entry incidence table using one sign bit and a $\lceil\log_2m\rceil$-bit clause ID per entry has the explicit upper bound
\[
 4n\bigl(\lceil\log_2m\rceil+1\bigr)\quad\text{bits}.
\]
Thus Y6 used 30 state bits, 3 event bits, and a 96-bit table upper bound; U198/V198 used 990 state bits, 8 event bits, and a 7,920-bit table upper bound.  These are representation sizes, not native FLMV peak-space measurements.

The controller must choose one charged branch:
\begin{enumerate}
\item retain the state and index, paying construction, authentication, address formation, update, and peak space;
\item omit one or both and reread/recompute them from the source, paying source probes, index-head operations, and time;
\item compute post-hoc from arbitrary snapshots, paying the REFEREE253 scan bound;
\item omit the diagnostic entirely, paying none of its tracer-specific cost.
\end{enumerate}
The compact action code can reconstruct the changed IDs, so explicitly printing every ID is optional output rather than an unavoidable internal tariff.  Eager fixed slots, lazy flags, same-value writes, head moves, index erasure, unaligned variable-length records, COPY/RECOMP, changed-then-restored actions and DELAY remain physically distinct.
