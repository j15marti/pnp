\section{CONSTRUCTION OR PROOF ATTEMPT}
Fix one oracle O, efficiently universal oracle machine U, and superpolynomial t dominating every fixed polynomial. Define K^{t,O}(x) as minimum program length printing x within t(|x|) oracle steps, and R^{t,O} as the strings with K^{t,O}(x) at least |x|-1.
\begin{theorem}[Matched-oracle immunity]
R^{t,O} has no infinite P-oracle subset.
\end{theorem}
\begin{proof}
Given a polynomial O-oracle decider of an infinite subset, fix the first n-m bits of some accepted length-n string, for m=4 log(n)+O(1). Exhaustively enumerate all 2^m suffixes with the same oracle. This takes polynomial time. An efficiently universal oracle program of length n-m+2 log(n)+O(1), eventually less than n-1, prints an accepted string within t(n), contradiction.
\end{proof}
\begin{theorem}[Bounded-output oracle impossibility]
If deterministic and nondeterministic polynomial oracle time coincide, there is no uniformly polynomial verifier accepting certificates for every t(n)-bounded n-bit output of all programs of length at most n-2, while accepting at most two distinct outputs per program globally across all proofs.
\end{theorem}
\begin{proof}
The set E of all accepted outputs is in nondeterministic polynomial oracle time, hence deterministic polynomial oracle time. At length n, at most 2(2^{n-1}-1)=2^n-2 outputs are accepted. Coverage puts its infinite complement inside R^{t,O}, violating immunity. Alternatively polynomial prefix feasibility finds the lexicographically first missing word from n; a fixed short oracle program prints it in polynomial time, contradiction. TQBF is an explicit collapsing oracle.
\end{proof}
Now take n-bit addresses, 2^n initially zero cells, r polynomially many phases, invertible binary matrices A_j and offsets b_j. Phase j visits address A_j c XOR b_j for c=0,...,2^n-1, updating that cell by the supplied Boolean DAG f_j(address,current-cell-bit). Define H_0(i)=0, H_j(i)=f_j(i,H_{j-1}(i)), inverse visit index d_j(i)=A_j^{-1}(i XOR b_j), and W_{j,c}(i)=H_j(i) if d_j(i)<c, else H_{j-1}(i).
\begin{theorem}[Restricted source-grounded certificate]
The indexed full-tape invariant T[i]=W_{j,c}(i) at every address has polynomial-size shared-DAG descriptor and polynomial-time source-level verification of initiality, consecution, phase boundaries and terminal probe coverage. The output of fixed probes q is the unique source-computed tuple H_r(q). A verifier accepting only this tuple across all proof strings ensures syntactic singleton cardinality.
\end{theorem}
\begin{proof}
Matrix inversion is polynomial. Every phase visits each address once, so a step changes exactly one index from the old H value to the new H value. At each boundary H_j equals the next phase initial value. At termination every cell equals H_r. Sharing prior H circuits avoids exponential expansion.
\end{proof}
Exact full-configuration membership by deterministic point queries requires querying all 2^n cells even at the zero-tape initial cut; an unqueried bit could be flipped. Membership of an arbitrary circuit-given tape at that cut is coNP-complete via Circuit UNSAT. Thus source proof is not cheap arbitrary-state testing. A neighbor-cell COPY falsifies the grammar.
