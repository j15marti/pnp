\item[M4.] The all-port obstruction might imply a general SAT lower bound.  \textbf{FALSIFIED}: it assumes retention of $\Omega(n)$ distinct physical ports; the projected-excess SCC family forgets private variables and truly contracts on a restricted recognizable grammar.
\end{description}

\section{BUILD: corrected entry theorem and monotone-rank firewall}
Let $C$ be the archived compiler224 transformation.  It properizes width $0$--$3$ clauses, joins incidence components with satisfiability-neutral tethers, pads signed occurrences, splits each balanced variable into an equality cycle, and completes each implication triple with a fixed $Q$ gadget.  The exhaustive fixed certificate is
\[
 \#\operatorname{Mod}(Q)=244,
 \qquad \{(q_1,q_7,q_{13}):q\models Q\}=\{(0,0,0)\}.
\tag{1}
\]
Thus the three missing positive ports are forced false and every padded ternary is the intended binary implication.

\begin{theorem}[Pointwise connected all-port entry, PROVED/RESTRICTED]
For every canonical ordinary 3CNF $F(x_1,\ldots,x_n)$ in the declared width-$0$--$3$ grammar, the fixed deterministic compiler outputs a connected proper distinct-clause strict signed exact-$(2,2)$ 3CNF $C(F)$ containing the same $n$ names as physical ports and
\[
 \forall \xi\in\{0,1\}^n:\qquad
 F(\xi)\iff \exists Z\ C(F)(\xi,Z).
\tag{2}
\]
If the connected properized source has $M$ clauses and $g$ seven-clause pads, then
\[
 |V(C(F))|=9(M+7g),\qquad |\mathrm{Cl}(C(F))|=12(M+7g),
\tag{3}
\]
with $g\le9M$.  The compiler makes no SAT-oracle call.
\end{theorem}
\begin{proof}
Each properization identity and each hub tether has a source-independent extension.  Every $J$ pad is extendable with its five auxiliaries zero.  Equation~(1) turns the completed links into directed implications, and their cycle forces all clones of a source name equal.  Conversely a source assignment satisfying $F$ extends through every stage.  Choosing one clone as the original physical name yields (2), including every UNSAT pinning.  With $R=\frac32(M+7g)$ clones, the construction has $R+15R/3=6R$ variables and $(M+7g)+R+19R/3=12(M+7g)$ clauses.  For source degree $d=p+q\ge1$, $2\max(p,q,2)-d\le3d$; summing $d=3M$ gives $g\le9M$.
\end{proof}

The theorem corrects the prior LSPV-5 synthesis sentence that arbitrary-instance entry into the connected exact22 class is still missing; the newer LSPV-2 ownership region already records compiler224.  What remains missing is a smaller \emph{decision-preserving forgetful child}, not a regularizing entry reduction.

\begin{theorem}[Entry--fanout monotone rank, PROVED/RESTRICTED]
Consider transformations composed only from: (i) $C$; (ii) the authenticated two-swap equality fanout; and (iii) bijective variable renaming.  Along every such composition the number of retained physical source ports never decreases.  More sharply:
\begin{enumerate}
\item if the input to $C$ is already connected strict exact22 with $n$ variables, then $C$ outputs exactly $12n$ variables and $16n$ clauses;
\item each equality fanout adds exactly $15$ variables and $20$ clauses;
\item renaming preserves both counts.
\end{enumerate}
Consequently this component set alone cannot satisfy $N_{\rm child}\le N^\lambda$ for fixed $0<\lambda<1$ on an unbounded bounded-occurrence family with canonical $N=\Theta(n\log n)$.
\end{theorem}
\begin{proof}
On connected exact22 input, $M=4n/3$, $g=0$, and (3) gives $9M=12n$ variables and $12M=16n$ clauses.  The guard counts follow directly from the fixed 15-variable, 20-clause two-swap construction.  Renaming is a bijection.  Independently, any strict exact22 output retaining $n$ distinct named ports uses each four times, so ASCII DIMACS devotes at least
\[
32\sum_{j=1}^{n}\bigl(1+\lfloor\log_{10}j\rfloor\bigr)=\Omega(n\log n)
\tag{4}
\]
bits to their decimal names alone.  Hence no such composition is power-short.  A semantic operation that existentially forgets most ports is outside the hypothesis and may escape the theorem.
\end{proof}
