\[

\section{Independent sequential epoch-tag theorem}
The following is an independent restatement and proof audit of Role~1's
ARC-EPOCH-TAPES173, not a claim of separate novelty.

\begin{theorem}[Sequential generation-tag compiler]\label{th:seq}
Fix a uniform deterministic guest $A$.  Suppose one fixed exact parent policy
makes at most $Q(N)\le N^{a+o(1)}$ sequential calls on proper ordinary child
encodings of length at most $N^{\lambda+o(1)}$.  On such a child $A$ uses time
$N^{\lambda t+o(1)}$ and reaches work/index position at most
$N^{\lambda s+o(1)}$.  Each requested child bit is generated in
$N^{g+o(1)}$ charged work and $N^{\eta+o(1)}$ peak space.  Other parent work
has exponent $r$, while retained ancestors, selectors and caches have exponent
$\kappa$.  A computable polynomial call bound is part of the fixed contract.

Then one fixed uniform implementation supplies fresh blank guest work/index
tapes at every sequential call with
\[
 t'\le\max\{r,a+\lambda t+g\},\qquad
 s'\le\max\{\kappa,\eta,\lambda s\}.
\]
There is no additional $a+\lambda s$ whole-prefix wipe term.  This statement
does not construct children, joins, or an ARC successor.
\end{theorem}

\begin{proof}
Choose a fixed integer $C$ with $Q(N)<(N+2)^C$, including finite exceptions,
and let $h=\lceil C\log_2(N+2)\rceil+O(1)$.  Replace every logical guest cell
by a block containing an $h$-bit generation tag and its constant-size tape
symbol.  The current generation starts at one and is incremented before each
call.  A read returns the stored symbol iff the tag equals the current
generation, and otherwise returns blank.  A write stores the current tag and
symbol.  Thus no stale cell is logically visible and generations do not wrap.

Every simulated primitive pays $O(h)$ tag comparison/address traffic; every
actual write pays changed and unchanged tag/symbol writes.  Blocking the tape
multiplies its greatest reached physical position by $O(h)$, so the FLMV space
exponent is unchanged.  The epoch counter and its arithmetic use
$N^{o(1)}$ bits/work.  Virtual input probes invoke the charged generator, and
retained parent state remains live.  Summing the real guest calls gives the
displayed time bound; maximizing simultaneous state gives the displayed space
bound.  Code size is fixed after $A$ and the policy are fixed.  No source bit,
child header, malformed-input check, failed strategy, or semantic join is
supplied by this simulation.
\end{proof}

This direct tape proof is model-matched.  The word-RAM initializable-array
literature achieves stronger initialization operations in its own model
\cite{navarro,katoh}; it is a \textbf{useful structural analogy requiring a
model transfer}, not the source of Theorem~\ref{th:seq}.  The explicit
block-tag simulation supplies the needed transfer here.  No electronics,
control-theory, coding-theory, Schur-square, hash, or cryptographic theorem
found in the preflight transfers to the all-input semantic normalizer.

\section{New overlap counterexample and exact repair scope}
Generation tags implement logical clearing by making older records invisible.
That same property destroys a suspended configuration after an overwrite.

\begin{lemma}[Single-arena suspension failure]\label{lem:overlap}
One generation-tag arena cannot in general preserve two overlapping live
guest configurations merely by switching the current generation number.
\end{lemma}
\begin{proof}
Guest~1, at generation one, writes value $1$ to logical cell zero and
suspends.  Guest~2 starts generation two in the same arena and writes value
$0$ to the same cell.  The unique physical record is now $(2,0)$.  Restoring
the current-generation register to one makes a read see a tag mismatch and
therefore return blank $0$, not Guest~1's saved value $1$.  This is a legal
two-write execution; no complexity assumption is used.
\end{proof}

Disjoint physical arenas, or an overwrite log containing the displaced
records, repairs this exact execution.  For a fixed number $D$ of
simultaneously live guests, $D$ dense arenas change neither exponent nor
uniformity.  If an architecture maintains $B=N^{b+o(1)}$ disjoint live arenas
of span $N^{\lambda s+o(1)}$, that explicit repair has space exponent
$b+\lambda s$; this is an implementation upper bound, \emph{not} an
all-algorithm lower bound, because constrained guest states might admit a
smaller proved representation.  Accordingly, Theorem~\ref{th:seq} remains
valid for sequential calls, and recursive wrappers must separately charge
their actual simultaneously retained ancestors/configurations in $\kappa$.
