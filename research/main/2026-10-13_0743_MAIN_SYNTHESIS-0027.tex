\section{Exact semantic object and universal target}

Let $F$ be a properly encoded $3$CNF on the labelled variable set
$X=[n]$.  For a partial assignment $\alpha\in\{0,1,*\}^{X}$ define
\[
 H_F(\alpha)=1\quad\Longleftrightarrow\quad
 \exists x\in\{0,1\}^{X}\;[x\succeq\alpha\ \wedge\ F(x)=1].
\]
The encoded input length $N=|\operatorname{enc}(F)|$ includes variable names, clause
delimiters, signs, multiplicities and all padding.  The unrestricted target remains
\[
\tag{UCORE-TIME}
\forall A\ \forall d\ \forall N_0\ \exists N\ge N_0\ \exists F\in 3\mathrm{CNF}_N:
 T_A(F)>N^d,
\]
where $A$ ranges over deterministic uniform machines deciding $3$SAT and every parsing,
normalization, extraction and reconstruction cost is charged.  UCORE-TIME is just an
explicit form of $3$SAT$\notin P$; it cannot be assumed as a lemma.

The desired bridge would instead start under the counterfactual $3$SAT$\in P$ and prove,
for every such decider $A$, that one execution on a clean-core input must realize a
model-matched object $R(F)$ whose acquisition cost or representation yields a known
unconditional contradiction.  No verified corpus theorem supplies that implication.

\section{Candidate tested and exact falsification}

For a permutation $p\in S_X$, let $pF$ replace each literal on $i$ by the same-signed
literal on $p(i)$, and set $(p\alpha)_{p(i)}=\alpha_i$.  Evaluation commutes with this
action, so extension witnesses are carried bijectively by $p$.  Therefore
\[
\tag{1} H_{pF}(p\alpha)=H_F(\alpha),
\qquad
H_{pF}(\alpha)=H_F(p^{-1}\alpha).
\]
This proves covariance without a complexity assumption.

For the audited BALCOMP1 pair, $H_{G_0}(\beta)=1$ and $H_{G_1}(\beta)=0$.  The concrete
permutation $p=(1)(2)(3)(4)(5\ 6)$ gives
\[
 (H_{pG_0}(\beta),H_{pG_1}(\beta))=(1,1),
 \qquad
 (H_{pG_0}(p\beta),H_{pG_1}(p\beta))=(1,0).
\]
Apply this same local renaming in every block of the $k$-fold independent product.  Then
the untransported fixed probe vector has only one value over all $2^k$ YES functions,
whereas the transported vector recovers all $2^k$ values.  Hence the following statement
is exact:
\[
\tag{2}
\exists p\ \forall k\ge1\ \exists \mathcal F_k\quad
 |\{H_F:F\in\mathcal F_k\}|=2^k,
 \qquad
 |\{(H_{pF}(\beta_i))_{i=1}^k:F\in\mathcal F_k\}|=1.
\]
Equation (2) falsifies a universal fixed-coordinate fingerprint, not the labelled
compatibility object and not a covariant fingerprint.

\paragraph{Smallest repair.}
Replace a hard-coded probe list by a selector $Q$ satisfying
\[
\tag{3} Q(pF)=pQ(F),
\]
or define an orbit-invariant output and charge a canonicalizer that computes it.  Merely
asserting that a canonical ordering exists is insufficient: its construction, encoding
and runtime must be charged in the same model.  If $Q$ is a cheap syntactic parser, as on
BALCOMP1, (3) is a useful algorithmic shortcut rather than a lower-bound resource.

\section{Primary-literature and cross-domain transfer audit}

\begin{itemize}
\item \textbf{Directly transferable theorem/object.}  Angluin's membership-query model
treats queries as points of a specified domain.  Here $H_F(\alpha)$ is exactly a
membership query to a labelled semantic function once the domain action is fixed.  This
supports the coordinate-accounting requirement, not a lower bound.
\item \textbf{Useful analogy requiring a new bridge.}  Bryant's ordered BDD theory makes
variable order part of the representation and supplies representation-specific size
phenomena.  It does not force an arbitrary Turing-machine SAT decider to construct an
OBDD or preserve a designated variable order.
\item \textbf{Useful analogy requiring a new bridge.}  Canonicalization under group
actions, illustrated by graph-isomorphism algorithms, warns that quotienting labels is
itself an algorithmic task.  No general graph-canonization bound transfers to BALCOMP1;
indeed its local transport is linear.
\item \textbf{Misleading/failed transfer.}  Cryptographic limitations on membership
queries are conditional and cannot become an unconditional NP lower bound.  Likewise,
VLSI routing, observability, communication cuts and canonical forms do not transfer until
the SAT computation is proved to realize the corresponding object and costs.
\end{itemize}

Cook--Levin reductions and self-reducibility explain how SAT queries can externally
recover witnesses or fingerprints, but separate oracle calls are not the same execution
whose internal state is being lower-bounded.  Worst-case/average-case extraction remains
blocked by known NP reduction barriers rather than supplied by them.
