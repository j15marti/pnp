\section{CONSTRUCTION OR PROOF ATTEMPT}
Let a validated input of length $N$ encode $M=2^n$ physical binary tape cells ($n\le N$), $P=2^b\mid M$ parity buckets, $s$ distinct target cells $S$, and $Q$ controller modes. Mode $c$ selects address $a(t,c)=(u_ct+v_c)\bmod M$ with odd $u_c$. Define target vector $z_i=X_{a_i}$ and external sketches
\[
p_j=\bigoplus_{\substack{a\notin S\\a\bmod P=j}}X_a,\quad j\in[P].
\]
The controller and writes may depend nonlinearly on $(c,z,p)$. On a target write, update only one $z_i$ and the controller by source-listed circuits. On an exterior write, update $X_a\leftarrow X_a\oplus\Delta(c,z,p,j)$ and the controller, with NO other external bit reads. The sketch changes exactly by $p_j\leftarrow p_j\oplus\Delta$ and all other components stay fixed. Thus the quotient with $K=Q2^{s+P}$ states satisfies an exact identity for every physical tape, not just reachable configurations.
\begin{lemma}[CRT sparse opportunity bound]
The set of residues modulo $M$ at which some mode could address some target has cardinality at most $J\le Qs$. For each pair $(c,a_i)$ the unique residue is $t_{c,i}=u_c^{-1}(a_i-v_c)\bmod M$.
\end{lemma}
\begin{proof}Every odd slope is invertible modulo $2^n$. Take the union of the $Qs$ singleton solution sets.\end{proof}
At non-opportunity times, every mode must write exterior memory. The background quotient on $(c,z,p,\tau)$, $\tau=t\bmod P$, is a time-independent map $H$ on $D=KP$ states, because the selected bucket is $(u_c\tau+v_c)\bmod P$. Compute $H^{2^i}$ for $i\le n$, jump across intervals, and at each candidate residue apply the genuine mode-specific target/exterior transition. One complete $M$-step period induces a well-defined return map $F:[K]\to[K]$ and each prefix a map $R_r$. Because $P\mid M$, $\tau$ resets after each period. For $T=kM+r$, the endpoint is $R_r(F^k(v_0))$. The source specifies the exterior initial tape by a periodic $P$-bit pattern $h$, with explicit target exceptions; bucket initiality is $p_j(0)=h_j((M/P-d_j)\bmod2)$, $d_j$ the number of target exceptions in bucket $j$. No full $2^n$-bit initialization is expanded.
\begin{theorem}[Authenticated endpoint certificate]
Fix $a\ge1$. For EVERY source in the above grammar with distinct targets, odd slopes, authenticated circuits, periodic initial tape and $K\le N^a$, and EVERY binary horizon $T$, one queried terminal target bit has a deterministic source-grounded certificate with length
\[
O\bigl(N+Jn+Dn\log(D+2)+K\log(T+2)\log(K+2)\bigr)
\]
bits and polynomial construction and verification time in the explicit source plus horizon length. All accepted certificates for a fixed source, $T$, and queried target have EXACTLY ONE output bit globally.
\end{theorem}
\begin{proof}
The initiality formula computes $v_0$ from authenticated source bytes. The XOR cancellation proves all-fiber consecution. The CRT lemma gives the event list; binary powers of $H$ and full event compositions determine $F$ on every quotient state. Squaring $F$ and composing $R_r$ yields exact terminal coverage. The verifier checks the sorted CRT list, background table and squares, event-composed $F$ for all $K$ states, return-map powers, initial state and terminal label. Every check is a deterministic function of the original source and $T$, so forged output labels are rejected across ALL accepted proofs. The total table sizes are $O(Dn+K\log T)$ entries, and at most $O(KJn)$ background lookups construct $F$; bit-machine time, source parsing, arithmetic, retention and output are polynomial as $K,D,J,n$ are polynomial in $N$. This provides line/bit evaluation, not polynomial explicit expansion of all $M$ tape cells.
\end{proof}
\paragraph{FALSIFIED extension.} A non-XOR overwrite cannot maintain the exterior sketch: $(0,0)$ and $(1,1)$ both have parity zero, but setting the first cell to zero yields parities zero and one. General hidden old-bit reads and arbitrary succinct initialization are OPEN; a large dependency space alone is no lower bound.
\paragraph{Matched-oracle diagnostic.}
Use a universal oracle machine $U^O$ and plain $K^{t,O}(x)$ with the SAME $O$ for the decider and verifier. Hirahara's proof relativizes: an infinite $P^O$ subset of the $K^{t,O}$-random strings would yield, by fixing $n-O(\log n)$ prefix bits and polynomially searching the remaining $O(\log n)$ suffix, a shorter $O$-oracle description in time $n^{O(1)}<t(n)$, contradiction. Let $O=\mathrm{TQBF}$, so $P^O=NP^O$. A hypothetical universal PFCERT package with polynomially selectable fixed-$\mathrm{PH}^O$ sound descriptors, certified SPARSE envelopes, and COMPLETE coverage of all relevant short oracle-machine outputs would permit canonical descriptor selection and outside-point search in $P^O$, producing a short description of a purportedly excluded output. Thus the COMPLETE package cannot relativize. Two-output soundness alone is not enough: descriptor existence, sparse coverage and selection are essential. Levin $Kt$ is not substituted. Source authentication prevents existential unions of exponentially many sparse descriptors. This diagnostic is NOT universal ordinary PFCERT existence. Fresh completion-time hash prefixes of $h=O(\log N)$ bits are searchable after disclosure in $2^h=\operatorname{poly}(N)$ trials, with no cryptographic assumption. Nonalgebrization OPEN.
