\section{CONSTRUCTION OR PROOF ATTEMPT}
Let $T_5$ have colors $\mathbb Z_5$ and directed relation $R(a,b)=[b-a\bmod5\in\{1,3\}]$. A descriptor $d=(n,U,B)$ is a list of $n$ terminal vertices, ordered successor pairs $U$, and ordered four-path pairs $B$. For each $(u,v)\in U$ introduce a private $h$ and arcs $u\to v,u\to h,h\to v$. For each $(u,v)\in B$ introduce private $a,b,c$ and arcs $u\to a,a\to b,v\to c,c\to b$. The raw graph is a canonically parsed sorted, duplicate-free adjacency list. An accepted descriptor must expand to \emph{exactly} this raw graph, authenticating every edge, private vertex, input byte and equality; no generic raw-graph recognizer is assumed. Directed loops force zero and repeated private gadgets are counted independently.

\begin{theorem}[Mixed-gadget exact quotient]
Each successor diamond has one internal completion precisely when $x_v-x_u=1\pmod5$, otherwise zero. The four-path pinned-endpoint completion matrix is $W=A^2(A^\top)^2$, $A_{ab}=R(a,b)$, and $W_{ab}=w(b-a)$ with $w=(6,1,4,4,1)$, row sum $16$, determinant $16$. Graph traversal of the successor equations either detects inconsistency or gives components $C$ and offsets $h_v$ with $x_v=\theta_{C(v)}+h_v$. Internal four-paths contribute a scalar product $I$; every external one gives an oriented quotient edge $e:C(u)\to C(v)$ and weight $w_e(z)=w(z+h_v-h_u)$. Hence the count of \emph{original} T5 assignments equals
\[
I\sum_{\theta\in\mathbb Z_5^q}\prod_{e:a\to b}w_e(\theta_b-\theta_a).
\]
\end{theorem}
\begin{proof}
The direct diamond arc permits endpoint differences 1 or 3, while the two-step path permits 1,2,4; the intersection is only 1, with unique increments 3,3. Four-path internal summation is the stated matrix product. In each connected successor component, every solution differs from one fixed modular potential by exactly one root shift. All private auxiliary labels contribute their own exact independent multiplicity.
\end{proof}

\begin{theorem}[Cycle-excess flow algorithm and global certificate multiplicity]
Let the quotient have $q$ vertices, $e$ weighted edges and $\kappa$ weak components; let $\beta=e-q+\kappa$. Define $\hat w_e(k)=\sum_{z\in\mathbb Z_5}w_e(z)\zeta^{-kz}$, for a fifth primitive root of unity $\zeta$. For all authenticated inputs,
\[
\boxed{\#\operatorname{Hom}(G,T_5)= I\,5^{q-e}
\sum_{\substack{k\in\mathbb Z_5^e\\\operatorname{div}k=0}}\prod_e\hat w_e(k_e).}
\]
The flow space has exactly $5^\beta$ members. A single blank-start sequential bit-machine realizes the exact integer evaluation within simultaneous $O((N+1)^8(1+5^\beta))$ time and $O((N+1)^4)$ space, charging parsing, source matching, failed checks, graph discovery, integer arithmetic, access and final output. If $\beta=O(\log N)$, a deterministic polynomial verifier accepts exactly one true output count or decision label, even across \emph{all} accepted descriptors for a fixed raw graph.
\end{theorem}
\begin{proof}
Fourier inversion and summation of each vertex's root color remove every nonconserved edge-frequency assignment, leaving the displayed $5^{q-e}$ sum. A spanning forest determines all tree frequencies uniquely from any assignment to the $\beta$ chords. Each Fourier coefficient is an exact five-entry integer polynomial in $\mathbb Z[X]/(X^5-1)$; products use cyclic convolution. The full sum is invariant under $X\mapsto X^j$ for $j=1,2,3,4$ because multiplying every flow by $j$ permutes summands. Thus its four nonconstant coefficients agree; evaluation at $\zeta$ is the integer constant-coefficient difference. All intermediate coefficients have $O(N)$ bits and all exact divisions by $5$ are checked. Every accepted descriptor expands to exactly the same raw graph, so semantic soundness forces the same accepted count. Source parsing and polynomial-time recognition of a \emph{supplied} descriptor do not imply efficient discovery of one.
\end{proof}
For a forest quotient $\beta=0$, the exact count simplifies to $I\,5^\kappa16^e$. Authentic successor grids can have unbounded original treewidth while $q=1$ and this calculation is trivial. For an unshifted weighted cycle of length $\ell$, $a_\ell=\operatorname{tr}(W^\ell)=16^\ell+2L_{4\ell}$, and the exact infinite generating series is
\[
\sum_{\ell\ge0}a_\ell z^\ell
=\frac{5-85z+225z^2}{(1-16z)(1-7z+z^2)}.
\]
This is a solution-count asymptotic, not a runtime lower bound; its recurrence permits $\operatorname{poly}(\log\ell)$ evaluation.

\end{theorem}
