\section*{Selection-free merge lemma}
Let $\mathcal W$ be any finite class of witnesses whose semantics are Boolean strings of length $N$.
Suppose that after reading positions $<t$ the streaming state stores a witness $C\in\mathcal W$ agreeing with the source on those positions.  After reading a block $y$ beginning at $t$, select \emph{any} witness $D\in\mathcal W$ satisfying
\[
  (\forall x<t)\ D(x)=C(x),\qquad D[t,t+|y|)=y.
\]
If no such $D$ exists, reject permanently.  Then after every successful update the stored witness agrees with the complete source prefix read so far.  At end of stream the algorithm accepts exactly the semantic strings represented by $\mathcal W$, and its final witness computes the complete source.

\paragraph{Proof.}
Induct on blocks.  The displayed conditions preserve all earlier represented bits and install the new block.  If the source has a witness $W\in\mathcal W$, then $W$ is feasible at every update, so rejection cannot occur.  If the source has no witness, feasibility must fail by the final block; otherwise the final stored witness would equal the source on all $N$ positions.  Minimum size and lexicographic tie-breaking are nowhere used. \hfill$\square$

\section*{Exact MMW identification}
For size-$s(n)$ circuits, the feasibility predicate is
\[
 \exists D\ (|D|\le s)\ \forall x<t\,[D(x)=C(x)]\ \wedge\ D[t,t+|y|)=y.
\]
For ordinary circuits this lies in $\Sigma_2^P$; MMW use a canonical minimum/lexicographic output and reduce their oracle-circuit version to short $\Sigma_3\mathrm{SAT}^A$ queries.  Their Theorem 1.2 already gives a one-pass search-MCSP algorithm using $\widetilde O(s)$ space and $\widetilde O(s^2)$ update time with those short oracle calls.  Under $P=NP$ and $A\in PH$, the polynomial hierarchy collapses, yielding their Theorem 1.3: a super-polynomial-in-$s$ space/update lower bound for this streaming task implies $P\ne NP$.

The specialist's block-one, nonminimum selector is therefore a valid simplification of the correctness proof, not a new asymptotic or model transfer.  Bitwise self-reduction can recover any feasible descriptor with polynomially many feasibility calls, but it does not remove the conditional PH oracle collapse.
