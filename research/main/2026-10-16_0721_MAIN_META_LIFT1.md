# META-LIFT1: Succinct-Lifting Route from P = PSPACE / P = NP to a Hierarchy Contradiction

**Status:** Research direction / proof spine proposal. No separation is claimed.

**Date:** 2026-10-16

## 1. Motivation

The current PORTFOLIO-SHIELD-SAT program has accumulated strong same-instance lower bounds in several restricted proof systems and increasingly precise charged-access / wrapper analyses. However, the load-bearing EXHAUST1 bridge remains open: an arbitrary polynomial-time SAT decider is not forced to emit Resolution, Cutting Planes, Polynomial Calculus, Sum-of-Squares, SAMEBIT, continuation-consistency, or provenance objects.

A potentially stronger direction is to stop trying to derive an unrestricted SAT runtime lower bound directly and instead use a **succinct-lifting contradiction**.

The core template is:

[
P=PSPACE
quad+quad
	ext{a sufficiently local reduction to a meta-complexity target}
quadLongrightarrowquad
P=EXPSPACE,
]

which contradicts the deterministic space hierarchy theorem.

There is an analogous (P=NP) route:

[
P=NP
quad+quad
	ext{a sufficiently local reduction to a meta-complexity target}
quadLongrightarrowquad
P=NEXP,
]

contradicting the nondeterministic time hierarchy theorem.

The point is not that (P=PSPACE) is itself known to be false. It is not. The contradiction arises only after combining the collapse assumption with a reduction whose succinct version stays unexpectedly low in the complexity hierarchy.

## 2. Existing theorem template: MCSP / MKTP

Allender, Holden, and Kabanets developed precisely this style of argument for the Minimum Circuit Size Problem (MCSP) and Minimum KT Complexity (MKTP).

Their results imply, in particular:

- If MCSP or MKTP is **P-hard under logspace reductions**, then (P
e PSPACE).
- If MCSP or MKTP is **P-hard under sufficiently weak uniform (AC^0) reductions**, then (P
e NP).

The proof idea is crucial for this project because it is based on **output-bit locality**.

Suppose a reduction

[
R : mathrm{QBF} 	o mathrm{MCSP}
]

uses logarithmic workspace.

Now feed (R) a **succinctly represented exponentially long QBF** instead of a materialized one. A requested bit of the huge QBF can be regenerated on demand from its succinct description. Since (R) uses little workspace, a requested output bit (R(arphi)_i) can be computed without materializing the full source or target.

Under the assumption (P=PSPACE), that output-bit function is polynomial-time computable and therefore has polynomial-size circuits. This produces a succinct MCSP instance.

The decisive asymmetry is that:

[
mathrm{Succinct	ext{-}QBF}
]

is EXPSPACE-complete, while the relevant succinct MCSP formulation remains in a low level of the polynomial hierarchy.

If (P=PSPACE), then (PH=P), so the succinct MCSP target becomes polynomial-time decidable. Hence Succinct-QBF becomes polynomial-time decidable, implying

[
EXPSPACE=P,
]

contradicting the space hierarchy theorem.

The NP version replaces QBF by SAT, EXPSPACE by NEXP, and uses a still weaker reduction class so that the reduction itself lifts cleanly to succinct inputs.

## 3. Why this direction fits our project unusually well

A large fraction of the LOCALSHIELD1 / WRAPPER-SHIELD1 work has already been about the exact technical issue that succinct lifting needs:

- output-bit or output-record access without materialization,
- explicit accounting for repeated source reads,
- logarithmic workspace,
- charged preprocessing,
- static-incidence templates,
- avoiding hidden occurrence indexes,
- avoiding free normalization,
- distinguishing construction time from replay time,
- handling virtual child inputs,
- rejecting semantic use of short hashes.

This machinery was originally developed to preserve SAT time-space exponents. It may be better suited to proving that a reduction can be evaluated **locally on a succinct source**.

The project should therefore separate two questions:

1. Can the reduction be lifted to succinct inputs with all access costs charged?
2. Does the target language have a succinct version that remains in a low enough class to collapse under (P=NP) or (P=PSPACE)?

For MCSP / MKTP, the second property is known. For the wrapper-derived targets we have considered so far, it is not.

## 4. New proof-spine target: META-LIFT1

Define a target language (M) satisfying three properties.

### Property I: hardness under a weak reduction

For the PSPACE route, seek

[
mathrm{P}	ext{-hardness of }M
]

under logspace reductions.

For the NP route, seek P-hardness under uniform (AC^0), projections, or another reduction weak enough for the succinct lifting theorem.

### Property II: succinct target remains low

We need

[
mathrm{Succinct}(M)in PH
]

or another class that collapses to P under the relevant assumption.

For the PSPACE route, (P=PSPACE) gives (PH=P).

For the NP route, (P=NP) also gives (PH=P).

This is the structural feature that creates the hierarchy contradiction.

### Property III: bit-local reduction

For every source (x), output index (i), and reduction (R),

[
R(x)_i
]

must be computable with tightly bounded resources from a local / virtual description of (x).

The ideal target is:

[
T_{mathrm{bit}}(n)=operatorname{polylog}(n),
qquad
S_{mathrm{bit}}(n)=O(log n),
]

with no hidden materialization or global index.

This is exactly the kind of contract LOCALSHIELD1 has been developing.

## 5. Candidate target family: continuation meta-complexity

The wrapper work suggests a natural function associated with a SAT instance.

Let (F(X,Y)) be a formula with interface variables (X). Define the continuation function

[
c_F(x)
=
operatorname{SAT}(F|_{X=x}).
]

Instead of requiring a SAT decider to enumerate all continuation values, define a meta-complexity predicate such as

[
mathrm{CMC}(F,s)
=
left[
c_F 	ext{ has a Boolean circuit of size at most }s
ight].
]

This resembles MCSP, but with the truth table represented implicitly by the SAT formula (F).

This is conceptually attractive because WRAPPER-SHIELD1 already constructs continuation functions with rich structure and proves exact continuation identities.

However, the naive continuation meta-complexity problem is not automatically useful. Its succinct version may become too hard because (F) is already an implicit representation.

Therefore the design criterion is not merely "MCSP-like." We need:

[
oxed{
	ext{succinct target remains low}
}
]

under the encoding actually used.

This must be proved, not assumed.

## 6. Relation to UWI

The Universal Witness Insufficiency framework studies

[
H(F)
=
min_{|p|le b(|F|)}
igl(t_p(F)+q(|F|)+1igr),
]

and establishes the equivalence

[
P=NP
iff
H(F)	ext{ is polynomially bounded on all satisfiable }F.
]

This quantity is structurally close to time-bounded Kolmogorov / KT-style meta-complexity.

The important distinction is:

- UWI minimizes witness-discovery time on an input formula.
- MKTP minimizes program-description-plus-time complexity of an explicit string.

The latter has established succinct-lifting theorems.

A promising pivot is therefore:

[
oxed{
	ext{Do not try to lower-bound }H(F)	ext{ directly.}
}
]

Instead, seek a local reduction from a P-complete problem into an MKTP-like quantity built from wrapper / continuation objects.

The desired source YES/NO distinction would be encoded into a provable gap in minimum description/time complexity.

## 7. Why hashes are not yet the missing step

The project has repeatedly used hashes and completion-time provenance to create globally different histories from locally generated states.

This is potentially useful for *constructing* candidate target strings.

But the following implication is invalid:

[
	ext{hash output appears random}
Longrightarrow
	ext{large circuit size or large KT complexity}.
]

A fixed deterministic hash such as SHA-256 or FNV supplies no unconditional circuit lower bound and no unconditional KT lower bound.

Recent random-oracle MCSP hardness results explain why the intuition is attractive, but a true random oracle cannot simply be replaced with a concrete hash function.

Therefore:

- keep hashes as indexing / provenance devices,
- do not use them as the hardness premise,
- require any complexity gap to be proved independently.

## 8. A possible concrete program

### META-HARD1

Construct a uniform reduction

[
R : L_{mathrm{P	ext{-}complete}} 	o M
]

such that:

1. (R) is logspace or preferably uniform (AC^0);
2. every output bit is locally computable with charged access;
3. YES and NO inputs map to objects separated by a provable minimum-complexity gap;
4. (mathrm{Succinct}(M)) stays in (PH) or another collapse-friendly class.

If (R) is logspace and (M) has the MCSP/MKTP-style succinct property, then (P=PSPACE) would force a contradiction with EXPSPACE.

If (R) is uniform (AC^0), the same architecture could potentially convert (P=NP) into a contradiction with NEXP.

### LOCAL-META1

Reuse LOCALSHIELD1's machinery to prove a complete bit-access theorem for (R):

[
T_{mathrm{bit}}(n)=operatorname{polylog}(n),
qquad
S_{mathrm{bit}}(n)=O(log n).
]

Explicitly audit:

- source rereads,
- output addressing,
- hidden rank/select indexes,
- sparse variable identifiers,
- normalization,
- malformed inputs,
- branch selection,
- write-only output assumptions.

### META-GAP1

This is the likely load-bearing theorem:

[
xin L
Longrightarrow
K_{mathrm{target}}(R(x))le a(n),
]

[
x
otin L
Longrightarrow
K_{mathrm{target}}(R(x))>b(n),
]

for some provable gap (b(n)>a(n)).

The gap must be unconditional and must not rely on a random oracle, one-way functions, or unproved circuit lower bounds.

## 9. Alternative target: Succinct-QBF time lower bounds

There is a second, weaker possibility.

Ryan Williams proved unconditional nontrivial time lower bounds for a natural succinct QBF problem.

One could try to show that (P=PSPACE), combined with a resource-normalization or contraction theorem, yields a solver for that succinct QBF problem running inside the forbidden time bound.

This route would avoid MCSP hardness, but it reintroduces the exponent-elimination problem: a generic polynomial-time QBF solver may run in (n^K), and virtualizing an exponentially long input does not remove (K).

Therefore this should be secondary to META-LIFT1.

## 10. How this changes the current project priorities

The strongest current proof-system results remain useful as structural benchmarks, but adding more proof systems is no longer the highest-value activity.

The priority order should become:

1. **META-HARD1**: weak-reduction hardness into an MCSP/MKTP-like target.
2. **META-GAP1**: prove an unconditional minimum-complexity gap.
3. **LOCAL-META1**: prove bit-local / succinct-lifting access with full accounting.
4. **SUCCINCT-CLASS1**: prove the target's succinct version stays in a collapse-friendly class.
5. Only then integrate PORTFOLIO-SHIELD / WRAPPER machinery where it helps implement the reduction.

The reason this direction is stronger is conceptual:

[
oxed{
	ext{We no longer need to prove an arbitrary SAT runtime lower bound directly.}
}
]

Instead, we aim to prove a weak local reduction into a meta-complexity problem whose succinct version creates an already known hierarchy contradiction.

That is a much more sharply defined mathematical target.

## 11. Main risks

This program remains difficult.

The principal risk is that proving the required MCSP/MKTP-style hardness is itself a major open problem. Ordinary deterministic NP-hardness of MCSP remains open, and current strong hardness results rely on random oracles or substantial cryptographic assumptions.

A project-native target may avoid literal MCSP, but then its succinct version may rise to PSPACE / EXPSPACE and lose the crucial low-complexity property.

Thus the two load-bearing requirements are:

[
oxed{
	ext{weak-reduction hardness}
}
]

and

[
oxed{
	ext{low succinct complexity}.
}
]

Both must hold simultaneously.
