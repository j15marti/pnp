 K'\le\max\{\alpha,\gamma+\lambda K\},\qquad

\section{Exact acquisition-query exponent firewall}
Let a particular controller architecture, on an infinite source family of
physical length $N$, make $N^{\delta+o(1)}$ sequential compulsory calls to its
arbitrary correct guest $A$ on ordinary-SAT acquisition queries of length
$N^{c+o(1)}$.  All calls must finish before the claimed terminal or children
are available.

\begin{theorem}[Delayed acquisition-query firewall]
If $c>\lambda$, this architecture cannot satisfy (1) uniformly for every
polynomial-time correct $A$.  If $c=\lambda$, the delayed-call test requires
$\delta\le\gamma$ but does not by itself prove sufficiency.
\end{theorem}
\begin{proof}
Fix any correct polynomial SAT decider $A_0$.  For an integer $D$ exceeding
its exponent, let $A_D$ execute $M^D$ dummy transitions on each $M$-bit input
before running $A_0$.  This is a uniform total correct SAT decider of exponent
$K=D$.  The compulsory acquisition calls cost
\[
 N^{\delta+cD-o(1)}.
\]
When $c>\lambda$, choose $D$ so that
$\delta+cD>\alpha$ and
$\delta+cD>\gamma+\lambda D$.  The realized time exponent then exceeds both
entries of (1), a contradiction.  If $c=\lambda$, comparison with the second
entry leaves the necessary inequality $\delta\le\gamma$.  This argument is
about a compulsory black-box implementation; a code-aware compiler which
provably avoids the calls is outside the hypothesis and must supply its own
charged construction.
\end{proof}

Thus NP-completeness of policy acquisition is not an unconditional obstruction.
Under $P=NP$, ordinary self-reduction can recover an optimum witness with
polynomially many decision calls.  But a generic parent-scale reduction has
$c=1>\lambda=1/2$ and fails this ARC architecture under DELAY.  Existence,
acquisition, verification, and contraction remain distinct.

\section{Independent referee of VERTEX-COVER-POLICY-GATE276}
For a graph $G=(V,E)$, $q=|V|$, repeat each positive edge clause
$(x_u\vee x_v\vee z_{e,j})$ for $j=1,\ldots,q+1$.  Add either the positive
guard $(a\vee b\vee c)$ or all eight signed clauses on $(a,b,c)$.  The first
source is SAT and the second UNSAT; both have minimum strong-Krom backdoor
$\tau(G)+1$.  The proof in GATE276 is correct: every strong backdoor hits each
ternary clause; an uncovered edge forces all $q+1$ private $z$ variables plus
a guard variable, while a vertex cover plus one guard variable hits all
clauses.  The UNSAT guard has the standard seven-step original-source
resolution refutation.  This is an exact restricted theorem, not a mandatory
resource for arbitrary solvers.

To audit acquisition rather than merely label it NP-hard, encode
Vertex-Cover$(G,t)$ as an ordinary proper 3CNF: edge clauses plus a bitonic
sorting network on the selection bits, full AND/OR Tseitin equivalences, and a
unit enforcing at most $t$ selected vertices.  Binary clauses and units are
replaced by exact proper-three-literal existential gadgets.  Binary search for
the optimum and standard witness self-reduction use at most $q\,\mathrm{polylog}
q$ such decision calls.

For cycles, $m=\Theta(q)$, so the replicated source has
\[
 N=\Theta(q^2\log q),\qquad
 M=\Theta(q\log^3q)=N^{1/2+o(1)},\qquad
 \#\text{calls}=N^{1/2+o(1)}.
\]
This particular acquisition lies at $(c,\delta)=(1/2,1/2)$ and is not rejected
by the time recurrence because $1/2<\gamma=3/5$.  For complete graphs,
\[
 N=\Theta(q^3\log q),\qquad
 M=\Theta(q^2\log q)=N^{2/3+o(1)},\qquad
 \#\text{calls}=N^{1/3+o(1)}.
\]
Now $c=2/3>1/2$, and the theorem rejects the compulsory arbitrary-$A_D$
implementation for sufficiently large $D$.  This sparse/dense split is about
one explicit representation and reduction.  It is not a lower bound on every
selector, and both source labels are directly recognizable without computing
the optimum backdoor.

\section{Affine theorem audit and arbitrary-degree nonlinear control}
The AFFINE-SMALLBIAS theorem remains correct within its exact scope.  A
fan-in-two circuit description count gives
\[
 B_N\le (u_N+1)(m+u_N+2)
       [b(m+u_N+2)^2]^{u_N},
\]
for a fixed basis constant $b$, hence
\[
 \log_2B_N=O((u_N+1)\log(m+u_N+2)).                 \tag{2}
\]
Its source is fixed before an independent affine seed; it compares the affine
image of its easy source distribution with the affine image of uniform source
bits, not with uniform target bits.  Both YES completeness and uniform-source
NO density are needed.  Equation (2) corrects no new error in REFEREE237; it
independently preserves that audit.

The prior exact countercontrol covered degree two.  The following classical
Maiorana--McFarland calculation extends the proof-method firewall to every
degree $2\le d\le r$.  For $x,y\in\mathbb F_2^r$ define
\[
 f_{r,d}(x,y)=x\cdot y\oplus\prod_{i=1}^{d}y_i,
\]
and let $D_{r,d}$ be uniform on $f_{r,d}^{-1}(0)$.

\begin{theorem}[Linear small bias versus every nonlinear degree]
$f_{r,d}$ has algebraic degree $d$ and, for every nonzero linear character
$(u,v)$,
\[
 \left|\mathbb E_{D_{r,d}}(-1)^{u\cdot X+v\cdot Y}\right|
 =\frac{1}{2^r+1}.
\]
Nevertheless $f_{r,d}=0$ always under $D_{r,d}$, whereas
\[
 \Pr_U[f_{r,d}=1]=\frac{1-2^{-r}}{2}.
\]
\end{theorem}
\begin{proof}
For every $(u,v)$ the Walsh sum is
\[
 \sum_{x,y}(-1)^{x\cdot y+\prod_{i\le d}y_i+u\cdot x+v\cdot y}
 =2^r(-1)^{\prod_{i\le d}u_i+v\cdot u},
\]
because summing over $x$ vanishes unless $y=u$.  Thus the spectrum is flat,
the zero-frequency coefficient is $2^r$, and
$|f^{-1}(0)|=2^{2r-1}+2^{r-1}$.  Expanding the zero-level indicator and dividing
each nonzero coefficient by the level-set size gives $(2^r+1)^{-1}$.
The complementary level size gives the last equation.  The monomial has degree
$d\ge2$, so the total algebraic degree is $d$.
\end{proof}

This does not show that the actual CHMY easy-source ensemble equals
$D_{r,d}$, nor that a nonlinear MCSP or SAT contraction exists.  It proves only
that linear small bias alone cannot justify a no-go for any nonlinear degree.
