## 2. Theorem A: all-inequality, connected simple 4-regular paired Colorful Cut is NP-complete
Define P4CC: input finite connected simple 4-regular graph G; its edges partitioned into groups each consisting of exactly two vertex-disjoint edges. Each group requires at least one edge to cross a binary cut. All signs are inequality; no pins, constants, parallel edges or loops in this projected model. NP membership via explicit binary vertex word and edge/group verification. We give a uniform linear-object, both-label reduction from [1], with actual witness lift preserving every source bit (not merely the existence of a phase-shifted solution).

A1. Parse/authenticate source, check four partitions and linearity by pair IDs, n nonempty variables, m=4n/3 clauses. For each clause (a,b,c), create four distinct port vertices p0(a),p1(b),p2(b),p3(c). Make one group {p0p1,p2p3}. For every source variable, order ALL its port copies (including repeated middle ports) and join consecutive ports u,v through fresh w by length-two path u-w-v, each edge a separate singleton group. Thus every satisfying word forces equality of all copies, and each clause group is exactly NAE(a,b,c). Conversely any source word fills port bits, w their complement, satisfying all singleton groups; clause truth is preserved identically. Port degrees <=3 (one clause edge and at most two wire edges); wire interiors degree2. All two-edge groups have disjoint endpoints. The graph before connectivity additions has 4m port vertices, 4m-n wire interiors, 8m-n vertices, 2m clause edges, 2(4m-n) singleton edges, m+2(4m-n)=9m-2n groups; components correspond exactly to incidence components of source. Let c denote their number.

A2. Connect these components as a chain by fresh length-four paths between unused wire interiors on consecutive components. For path v0,v1,v2,v3,v4 use groups {v0v1,v2v3} and {v1v2,v3v4}. For ANY endpoint bits choose the first three edges cut (alternating), last unrestricted. Thus both groups true regardless of endpoints, preserving every source witness. Distinct interior wire vertices used for each attachment, two per internal component at most. Each component has ample wire interiors: if n_i variables, m_i=4n_i/3, number 4m_i-n_i=13n_i/3, n_i>=3. Subcubic degrees preserved; at least two unused degree-two vertices remain. Added 3(c-1) vertices and 2(c-1) paired groups. All graphs simple.

A3. K5 false-edge padding. On vertices 0..4 use five pairs:
  01|23, 02|14, 03|24, 04|13, 12|34.
All five cannot be cut-satisfied: a 0/5 or 1/4 partition crosses fewer than five edges; in a 2/3 partition the smaller side's internal edge and its disjoint partner are both uncut. Remove first pair. Remaining four groups are satisfiable (isolate vertex 4), and every model forces x0=x1 and x2=x3, otherwise all five would be satisfied. Introduce a fresh copy of the four-group gadget per singleton source edge e; replace singleton by pair {e,01_dummy}. Leave 23 absent. Every model of four internal groups forces dummy edge 01 uncut; new pair is true iff e cut. The gadget can be lifted for either common phase (global complement). Internal graph is K5 minus edge 23, 9 physical edges including dummy; degrees of vertices 2,3 are three, others four. Notice this is not a claimed arbitrary fanout equality tree.

A4. Connect pad gadgets in a chain physically: start at a spare degree-two source vertex, add edge to vertex 2 of first gadget; join vertex 3 of each gadget to vertex 2 of next. If bridge count odd, add one leaf at final vertex 3. Pair bridge edges successively; bridges are vertex-disjoint even when touching same gadget because their endpoints there are 2 and 3. They can ALL be cut by choosing each gadget's complement successively, without changing any original bits (and choose leaf opposite predecessor). No need for singleton bridge groups. In our NAE compiler the singleton count s=2(4m-n) is even, so no leaf is required. Result H connected simple max degree4, all groups exactly disjoint edge pairs, retains at least one degree<=2 source vertex. Equivalence both ways by inspecting internal groups and original owners.

A5. Regularize H by eight disjoint copies, left copies L0..L3 and right copies R0..R3. For each vertex v of H with deficit d=4-deg_H(v), add, for each shift j=0..d-1, four matching edges L_i(v)R_(i+j mod4)(v), i=0..3. Pair these four into two groups (0,1) and (2,3). No repeated edge, all endpoints distinct, exactly fills all degree deficits. Since some v has d>=2, shifts 0 and 1 connect all eight copies through that v; each original copy connected. For ANY H model, assign all left copies its bits and all right copies the global complement, so every new edge is cut. Conversely restrict any target model to first copy; all H groups still true. This is exact decision and projection, not a proof that copies must be coherent in all target words. P4CC NP-hard by [1], NP-complete.

A6. Generality: [2] gives another authenticated source. Replace each source edge by length-three path with middle edge retaining original group ID, other two edges singleton cut requirements. This preserves original edge cut status when both outer edges cut, separates any formerly adjacent paired edges and provides degree-two slack. Then A3–A5 apply. This alternative proof is not separately implemented in this run.

## 3. Theorem B: NP-complete aligned restricted-hub four-color star model
For every group {uv,st} of P4CC, create one unrestricted center with color in GF(2)^2. Every hub has the SAME binary list {00,01}. Center incident edges to u,v,s,t forbid center XOR hub=00,01,10,11 respectively (equivalently require inequality to translated hub color). Then the four forbidden colors occupy all four possibilities iff x_u=x_v AND x_s=x_t. Hence the center is extendable exactly iff the group is satisfied. All hub bits preserve their interpretation; choose any color outside the four forbidden colors for each center. This is exact MFC43 single-star alignment, not an E4/B4 semantic substitution. Distinct endpoints ensure simple incidence graph, each center and hub degree four; connectedness follows from P4CC connectedness. NP membership obvious. Therefore the signed list-restricted aligned four-port star model itself is NP-complete even with one common binary list and a fixed translation pattern per center. **BW15 unpinned degree-feasible theorem unaffected:** size-two hub list at degree4 violates its list-size>=degree promise. No arbitrary full-color pure-exclusion hardness is asserted.

For connected source, H has (8m-n)+5s=48m-11n=53n vertices; for c components add 3(c-1). P4CC target has Q=424n+24(c-1) vertices, Q groups and 2Q edges. ## 4. Deficiency and local closure: why this does not finish P=NP

## 5. Theorem C: 4-edge-connected strict paired graphs forbid local false-edge padding
Let G be connected simple 4-regular with every nontrivial cut size >=4, and every group two edges. Arbitrary inequality/equality signs, not necessarily vertex-disjoint within groups. For ANY group set S omitting at least two groups, and any edge e of an omitted group, either chosen parity of e extends to a model satisfying S. This is stronger than merely saying S is satisfiable. Proof:

For J subset S, let F union its edges, with v incident vertices and k connected components. For a component C, credit beta(C)=4|C|-2|F[C]|. Each proper C has beta>=4 from its actual outgoing edges; if C contains whole graph, >=8 because at least four edges of omitted groups are missing. Sum beta=4v-4|J|, so r(F)=v-k>=|J|. If r(F)>|J|, adding singleton e causes no Hall problem. If equal, every component must have beta=4 and be proper. If e is in row span F, its endpoints lie in the same component C. Since e not in F, that component's credit includes both missing internal incidences of e PLUS at least four actual outgoing incidences, giving beta>=6, contradiction. Thus r(F+e)>=|J|+1 in every case (including J empty, no loops). The rank-Hall inequalities now hold for all subfamilies of S plus the singleton e. Ordinary graphic/partition matroid intersection (Rado) chooses independent representatives including e; forest parity propagation satisfies all, for either sign of e. Acquisition and witness polynomial; no dependence on arbitrary sign choices.

Consequence: a local subset of groups cannot force an omitted dummy edge uncut in this strict projected class unless it retains all but one group. The K5 pad uses four of five groups, exactly the sharp exceptional boundary. Our padding proof therefore cannot simply be made 4-edge-connected by additional edges without modifying its semantics or using a genuinely global adapter. This does NOT preclude all other strict d1 source compilers or unrestricted algorithms.

Further explicit cut-interface counterexample: take two disjoint copies of the square of an n-cycle (n>=5), delete edge 01 in both, connect 0_A to 0_B and 1_A to 1_B. Pair each remaining internal edge in A with corresponding edge in B; pair the two new cross edges together. Simple connected 4-regular, disjoint pairs. Projected physical cut separating copies has size 2, yet exactly 2n-1 owner groups have alternatives on opposite sides. A cut decomposition of projected edges alone gives no bound on actual owner compatibility interface; distinguish this from the star incidence graph, which carries those owner links. Tsin's cactus decomposition therefore needs an additional exact group-transfer theorem. No claim of hardness for this particular easy family.
