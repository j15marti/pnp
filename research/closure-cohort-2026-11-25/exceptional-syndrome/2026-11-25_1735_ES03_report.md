## 2. Theorem A: all cographic completed rank-two affine avoidance systems
Input explicit binary rank-two rows a_i,b_i and forbidden offsets (s_i,t_i), requiring (a_i*x,b_i*x)!=(s_i,t_i); optionally explicit single-row pins on completed directions. Complete every owner with a_i+b_i, and deduplicate identical nonzero vectors globally, retaining all original owner IDs and ordered maps. Let A be the matrix of distinct completed row vectors. A sufficient, deterministically recognizable condition is that the labeled vector matroid of the rows of A is cographic. No deficiency restriction. All arithmetic over F2.

Acquisition: Gaussian elimination to a standard representation [I|D] of the column matroid of A^T, dual representation [D^T|I] up to permutation, Bixby-Wagner graph realization of the dual graphic matroid. Recover labeled graph G, explicitly verify row-space equality between im A (in edge coordinates) and ker incidence(G) by binary elimination. Explanation: circuit indicators generate the kernel of a binary matroid representation, so the dual graphic representation has row space ker A^T; its orthogonal complement is im A. An unsuccessful recognition is UNKNOWN for this terminal, not NO. Recognition imported as a published polynomial theorem, not implemented in the audit. The CMR documentation provides an implementation route. Any isolated vertices irrelevant. Each completed direction occurs in a dependent triple, so no cographic coloop (graph loop); no zero or parallel cographic elements (graph bridges or two-edge bonds) because A was simplified. Thus every nontrivial graph component is at least 3-edge-connected. If extra pins introduce a free coloop, handle that free loop bit separately; the core theorem uses only completed directions.

Let z=Ax, equivalently an even-degree edge subset of G. Every owner corresponds to three distinct edge IDs whose vectors sum to zero; all three nonzero and distinct, so they are a matroid circuit, hence exactly a 3-edge bond in G. On the bond, z has even parity, and the forbidden word is the ordered triple (s_i,t_i,s_i+t_i). Each owner thus permits a subset of {000,011,101,110}. Multiple owners on the same bond intersect their masks; preserve the actual edge ordering, including when two owners use different bases. A rank-one packet is a forced linear equation after normalization; retain it as a pin if its row is an existing edge direction. An arbitrary joint affine guard is NOT automatically an edge pin; only admit it after paid certified representation or handle in another terminal.

Claim: all such even edge subsets with arbitrary allowed masks on 3-bonds and edge pins are decidable and reconstructible in deterministic polynomial time, for arbitrary number of owners and arbitrary graph treewidth.

## 3. Laminar acquisition, not a free partition
Work per connected component. Root at any vertex, orient each owner bond by its side S excluding the root. Delete the three edges and BFS to recover the side; verify exact boundary. In a 3-edge-connected graph all such rooted sides are laminar. Proof: if S,T cross, write four nonempty regions A=S intersect T, B=S minus T, C=T minus S, D=outside. Cut submodularity gives delta(A)=delta(D)=3 and no B-C edges since both original cuts have size 3. Applying the same identity to S and complement T gives delta(B)=delta(C)=3 and no A-D edges. Put x=e(A,B), y=e(A,C), z=e(B,D), w=e(C,D); then x+y=x+z=y+w=z+w=3, so y=z and delta(S)=y+z is even, contradiction. Therefore no crossings. This is the odd-min-cut fact, proved here without importing a decomposition oracle.

Construct inclusion tree by set containment, root the full component. At each node S contract immediate proper children to individual vertices and all exterior vertices to one boundary vertex; retain actual edge IDs, drop edges internal to a contracted part, and retain all edges joining distinct parts. Ordinary uncontracted vertices impose even degree. Each child-contracted vertex imposes that child's acquired allowed boundary mask on its three original ports. The exterior contracted vertex imposes the candidate boundary word of S, one of the four even words; additionally check S's original allowed mask. Root has no exterior demand. A single edge can occur in several ancestor interfaces: it has the same ID and bits are glued through every intermediate cut, never treated as independent copies.

## 4. Constant mask matching gadgets and exact lift
For each quotient vertex create one port node per incident edge. Represent chosen graph edge by matching its two endpoint ports via an external link. Internal perfect matching must cover the remaining nodes. For an unrestricted even-degree vertex of degree d, use a clique on all d ports plus one auxiliary iff d is odd. Removing selected ports leaves an even number iff selected degree is even; all even selections extend by pairing the remaining nodes. A pin 0 deletes the external link; a pin 1 forces it by reserving both endpoints and removing them from the residual matching instance.

Any allowed subset R of the four even words on three ports P1,P2,P3 has an explicit constant-size internal graph:
* Empty mask: reject.
* Only 000: one private leaf at each port.
* At least one permitted pair: introduce one internal vertex c. Join c to exactly the port left over by each permitted pair. Add no port-port edge if 000 forbidden. If 000 permitted, choose one allowed pair and join its two ports.
For a selected pair, only the remaining port and c survive, so membership is exact. For 000, a perfect matching exists iff the added port-port edge is present. Odd masks are impossible by vertex parity. This includes all 16 even masks, independently tested. Unlike FCG03's 4-port obstruction, every 3-port even mask is matchable; no assumption that arbitrary masks of larger arity are matchable.

For each node evaluate each allowed boundary word by deterministic ordinary maximum matching (Edmonds) on this gadget graph, record actual external-link choices on YES. Process leaves to root. Correctness by induction: an actual even edge subset induces the boundary word and a perfect matching at the quotient by exact local masks; conversely every perfect matching supplies actual quotient edge bits, each child mask certifies an actual child solution for precisely its boundary bits. Reverse recursion restores children and checks consistency on every shared edge ID. Original ordinary vertex parity and all original bonds hold. Solve Ax=z by Gaussian elimination to recover x, then verify every original ordered pair and pin. Multiple components solve independently. No combination of unrelated witness vectors is asserted feasible.

This proves Theorem A and gives exact conditional 3-port summaries, which I27's single global energy optimum does not itself explicitly export. I27 can independently acquire such tables by at most four exact pinned calls, so this is a structural alternate implementation rather than a strictly larger tractable class.

## 5. Five-plane atom is exactly a cographic K3,3 core
The prior atom U_i nonzero triples (15,32,47),(13,17,28),(14,36,42),(11,53,62),(10,39,45) has H columns [15,32,13,17,14,36,11,53,10,39]. A basis of ker H (coordinate masks, low bit first) is [99,168,306,564]. Thus primal rows in owner order are [1,5,8,2,12,15,1,2,4,8]. Completing and deduplicating gives directions [1,2,3,4,5,8,10,12,15]. There are six dependent triples:
    (1,2,3); (1,4,5); (2,8,10); (3,12,15); (4,8,12); (5,10,15).
Each direction appears exactly twice. Connect the two triple indices containing it. The result is K3,3 with bipartition {0,4,5} and {1,2,3} (zero-based triple IDs). Its cycle space has dimension 4 and equals im A by direct incidence verification. Owners are stars [1,2,3,0,4], with star 5 unconstrained. This supplies an explicit legal cographic recognition with no chart search, no guard branching, no tournament assumption, and no need for ES01 feedback conditioning. For target t=29 take offset word b=29 (H b=29); the forbidden words in the sorted direction order at those stars are [3,3,3,0,0], low bit first. All three vertices in one part forbid selecting their first two incident edges without the third. The two constrained vertices in the other part correspond to those first two columns and require a nonempty even selection. Each must therefore have selected degree 2. The three vertices of the first part can supply at most one edge each to those two columns, only three incidences in total versus four required. UNSAT. This is an actual combinatorial obstruction, not merely missing-candidate acquisition. Flipping the first forbidden word to 0 permits row patterns [3,5,6], a witness; all 64 syndromes independently compared to punctured-plane enumeration, exactly 29 absent.

For clarity an independently labeled K3,3 with all 3 left and 2 right vertex-star owners is a strict d1 geometry. For a proper subset selecting a left and b right stars (0<=a<=3,0<=b<=2), when a<=2 the unselected induced graph is connected, and cographic rank of the union of incident edges is 2(a+b)-ab by r(F)=|F|-c(G-F)+1. Hence rank minus owner count is a+b-ab>=0. When a=3, the rank is 4, proper owner count <=4; all 5 have rank 4. Completed matroid is not graphic (Whitney: M*(K3,3) graphic iff K3,3 planar). This is a genuine strict example outside the graphic terminal, not merely a favorable chart of a graphic geometry. It is not a new tractability result relative to I27, but the explicit recognition and direct lift resolve this old benchmark in a complementary way.

K5 paired-edge obstruction is different: complete all five primal edge pairs in coordinates fixing vertex 4 to zero. The 15 completed directions are every nonzero vector of F2^4, containing Fano restriction 1..7. It is neither graphic nor cographic, so Theorem A does not cover it. ## 6. Infinite nonplanar and high-defect family, exact guarded interfaces
Starting from either K3,3 label above, expand a cubic vertex into a triangle, attaching its three old edges to distinct new triangle vertices; keep its old owner as the outer 3-bond, add three star owners forbidding 000. Any even external word extends: for 000 select all three internal triangle edges, for a two-port word select the two-edge internal path via the third vertex. Each new vertex has selected degree 2. Conversely outer word retains the old constraint exactly. Repeat at one of the new cubic vertices; each previous star owner persists as an actual nested cut. The graph remains 3-edge-connected: a cut not splitting the triangle maps to an old cut, a cut splitting it crosses two triangle edges and must cross another edge because G minus the expanded vertex is connected (otherwise cubicity and old 3-edge-connectivity would be contradicted). K3,3 minor persists by contracting triangles. Exact extension works for each actual boundary state, not just SAT labels. At k expansions there are 6+2k vertices, 9+3k edges, 5+3k owners; full rank=4+k and deficit=1+2k, so strict d1 no longer holds. Theorem A still decides the family; no claim that all high-defect source networks are cographic.
