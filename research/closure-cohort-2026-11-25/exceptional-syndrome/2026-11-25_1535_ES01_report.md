## 2. Exact chart transfer

For strict dual punctured planes U_i of dimension two, i=1,...,n, ambient F2^(n+1), assume dim sum_{i in J} U_i >= |J|+1 for every nonempty J. Obtain independent e_i in U_i by linear/partition matroid intersection (Rado); choose f_i another nonzero vector of U_i. Let E=span(e_i). If t+sum f_i is in E, solve directly by choosing f_i or f_i+e_i. Otherwise let w=t+sum f_i outside E, and write f_i=sum_j A_ji e_j+b_i w. Let M=A+I. Write candidate choices as y_i=f_i+p_i(f_i+e_i)+q_i e_i with p_i q_i=0. These encode exactly the three nonzero choices. Comparing coordinates in sum y_i=t gives q=Mp and b^T p=1. Thus the exact task is to find actual p satisfying p_i(Mp)_i=0 for every i and b^T p=1. Conversely these equations lift via the displayed formula and can be verified directly in the original planes. This is the acquired-chart equivalence, not a promise that every convenient chart is discoverable. MFC44 candidate acquisition and RT39 exact classification remain separate. All proofs here use explicit binary matrices.

## 3. Theorem A: minimum fixed-order feedback completion

For an explicitly ordered n by n matrix M, define k=min rank C over completions having C_ij=M_ij for j<i. Then M=T+UR with T upper triangular (diagonal allowed), U n by k, R k by n. k and a minimizing factorization can be computed by Gaussian elimination in polynomial bit time.

Proof. Sweep rows i=n,...,1. For each row, the prefix through i-1 is prescribed. The projections of every already completed row j>i onto this prefix are also fully prescribed, regardless of any completion choices. If the new prefix lies in the span of those projections, compute coefficients expressing it and complete the entire row by that combination of the existing full rows. This gives rank increment zero. Otherwise complete with zeros in unspecified columns. The resulting row is independent, and every possible completion necessarily has rank increment one, since its projection is independent. Summing the forced increments proves optimality. Choose R a row basis of C and U the coefficient matrix. T=M+C has all strict lower entries zero. This algorithm is for a fixed order, not an optimized-order oracle. A canonical input order is a paid option.

This is a triangular-pattern rank-completion fact, in the setting of Woerdeman's minimal rank completion literature. The argument is self-contained; it does not use a general low-rank completion algorithm or assume that arbitrary partial matrix completions are easy.

## 4. Theorem B: joint guarded repair terminal

For any explicit q affine equations g_l^T p=h_l, the system p_i(Mp)_i=0 with all q equations imposed admits a deterministic exact decision and actual witness algorithm in

  2^k poly(N) (1+D^3), D=sum_{j=0}^{min(n,k+q)} binom(n,j),

where N is explicit encoded length and k is Theorem A's minimum rank for the fixed order. Hence fixed k and fixed q suffice for polynomial time, independent of the number or size of strongly connected regions. k=O(log N) with fixed q only guarantees quasipolynomial time under this estimate, not polynomial time.

Proof. Enumerate c in F2^k, conditioning on Rp=c. In that mode sweep i=n,...,1. Generate all local solutions exactly by the two affine transformations indexed by s_i in {0,1}:

  p_i = s_i [1+T_ii+sum_{j>i} T_ij p_j+(Uc)_i].

The other coordinates are unchanged, with the unprocessed prefix initialized to zero. If p_i=0 there is no local constraint; if p_i=1 its bracket must equal 1. Thus these maps generate exactly all solutions of the local conditioned system, before enforcing consistency Rp=c. Even when two maps coincide both are legal; no synthetic XOR assignment is admitted.

For each mode, let d=min(n,k+q) and nu_d(p) be the vector of squarefree monomials through degree d, including the constant. Start with the actual zero state. At each layer apply both maps to each retained actual representative, and keep original representatives whose lift vectors extend a linear basis of the resulting span. Any fixed affine map induces a linear transformation on the monomial lift by substitution and Boolean reduction x_i^2=x_i. Induction therefore proves equality between the retained span and the span of ALL actual reachable states at the same layer. This concerns the lift span, not equality of attainable assignments.

The Boolean indicator of the joint conditions is

  G_c(p)=prod_{a=1}^k (1+c_a+(Rp)_a) prod_{l=1}^q (1+h_l+g_l^T p).

It evaluates to 1 exactly when all conditions hold; its degree after Boolean reduction is at most d. Hence it is a linear functional of nu_d(p). If it is 1 at any actual reachable state, it is 1 at some retained actual representative, since otherwise it vanishes on their entire span. Return that original representative and verify all original equations. If no representative passes in any mode, answer NO. No parity-of-counts argument is used, no individual guard projections substituted for joint support, no black-box PIT or SAT oracle. Forced zero coordinates may be omitted from the affine generation when proven universally zero, retaining the same source map.

Cost: construct C,T,U,R and verify factorization by polynomial Gaussian elimination. Compute D and 2^k before allocation if using a cap; beyond cap return UNKNOWN, never NO. Each mode has n layers, at most 2D candidate representatives per layer, explicit polynomial-in-N times D work for monomial evaluation, and dense elimination costing O(D^2) binary operations per candidate, plus storing n-bit actual states. Final checks, failed modes, read/write and original-coordinate reconstruction included in poly(N)(1+D^3). Process modes serially; peak space poly(N)(1+D^2), with conservative cumulative memory at most (T_work+1)S_peak. No saved exponential table of prior modes. Bound includes chart discovery by ordinary matroid intersection if starting from explicit planes, but does not include any unproved original NP-complete compiler. Fixed parameters are constants in the uniform bound, not chosen for each N.

Forced-information closure integration: audit executes initial unconditional forced-zero propagation to a fixed point, deleting only zeros proved by a row becoming e_i after zero substitutions; this is a sound syntactic closure, not full semantic closure. Theorem B can additionally acquire the actual complete linear span of unguarded repairs by starting with zero and querying each basis row of the annihilator of the current span for a value-1 witness. Add an actual independent witness and repeat; O(n^2) single-demand calls suffice. For a fixed affine guard context use a feasible anchor and opposite-value demands, with one extra guard factor, so every implication retains its context. Gaussian elimination then gives all linear invariants. Before branching and after certified deductions recompute the relevant forced closure; no semantic closure oracle is assumed. Complete semantic closure and integrated multisolver schedule were not executed in this audit.

## 5. Composition with MFC46

The two-diagonal lemma is sound: in a strongly connected off-diagonal graph, take a shortest directed path from nonzero demand support to the set of differing diagonal positions. Intermediate positions have no demand and no changed diagonal, and no forward shortcut exists. In the two diagonal modes, test prefixes starting at the first vertex. If a prefix is not feasible, its last row is the unique unfulfilled row (inductively all earlier rows remain feasible), and adding the next vertex toggles precisely that row among the earlier rows. At the last vertex the diagonal differs across modes, so at least one mode has a feasible prefix with odd demand. This proves the union of the two local feasible-repair spans is full. The argument applies to the same off-diagonal matrix and arbitrary distinct diagonals, including a singleton.

In topological SCC order write M=[[M_C,K],[0,M_D]]. Any actual downstream q extends by p_C=0. To annihilate all global repairs, a demanded row must first annihilate all downstream q. If its restriction to C is nonzero, Kq must be zero for all such q, since a varying shift and the two-diagonal lemma otherwise supply an odd repair in C for one of two actual downstream modes. Then independently test its restriction in C at the original diagonal. For multiple rows, propagate row restrictions plus rows of K if any C-demand is nonzero, keeping their linear basis. Source-to-sink evaluation requires only polynomially many individual row-demand tests per SCC. Reverse the construction with actual local witnesses, using zero prefix or the two-diagonal path if the failure was caused by a variable shift. This is the exact MFC46 decomposition, with Theorem B replacing the local enumeration. For k_C feedback rank in a specified order of each SCC, additive charged bound poly(N)+sum_C poly(N)2^{k_C}(1+D_C^3) with D_C=sum_{j<=min(|C|,k_C+1)}binom(|C|,j). No Cartesian product across components. Symmetric and other independently established terminals may be mixed when their actual witness interfaces are valid. This corollary is proved by the decomposition; the integrated SCC solver was not executed here.

## 6. Infinite strict both-label family outside earlier raw-chart terminals

For even n>=4 let diagonal of M be one, all entries above diagonal one except M_1n=0, and the only lower-triangular one be M_n1=1. This is a strongly connected tournament off diagonal. Its underlying undirected graph is complete, treewidth n-1; M+M^T is the all-off-diagonal-ones matrix, rank n for even n. Any diagonal-plus-rank-r expression of M needs 2r>=n. Vertices in a single interaction type have symmetric pair entries, so the uniform block-interaction model needs n types here. In contrast k=1 (one nonzero lower entry forces one, and a rank-one completion suffices). The repair supports are precisely the empty set or triples {1,j,n}, 1<j<n: greatest selected vertex must be n, otherwise its selected row has only its diagonal one. Vertex n forces 1; row 1 requires an odd number of selected middle vertices; two or more selected middle vertices would make the second-largest selected middle vertex have two larger selected neighbors, including n, violating its row. Each such triple is directly checked.

With b=e_1+e_n the answer is NO; with b=all ones it is YES (any triple). Both have the same all-one candidate diagonal under MFC46 shortest-path candidate construction. These are genuine strict plane charts: define independent coordinate vectors e_i, extra w, and f_i=(M+I) column i plus b_i w. Each proper nonempty J has an edge from outside J into J by strong connectivity, giving rank >=|J|+1, while all J have rank n+1 since b!=0. All f_i give genuine two-dimensional planes. Omega has rank n since its upper-left submatrix is M+M^T and an alternating matrix of odd order n+1 cannot have rank greater than n. Thus large alternating rank, full graph width, full interaction-type count and a single irreducible SCC do not obstruct this terminal. This comparison concerns the displayed charts, not an impossibility of finding other favorable charts.

## 7. Falsified universal restricted chart-normalization conjecture

A counting argument rules out universal coverage by symmetric SCCs and low-feedback SCCs even with arbitrary chart changes and ordering. It is important not to turn the new terminal into a false global closure.

Consider all pairs (M,b) with b nonzero and off-diagonal graph strongly connected. Their number is (1-o(1))2^{n^2+n}: non-strong-connectivity implies a nontrivial directed cut with no edges in one direction; the probability is bounded by 2 sum_{s<=n/2} binom(n,s) 2^{-s(n-s)}=o(1). Each pair produces strict planes as in section 6.

Fix any vertex order and an ordered composition n=s_1+...+s_h of SCC sizes. Upper off-block entries are arbitrary, lower off-block zero. For a symmetric block size s there are at most 2^{s(s+1)/2} choices. For a block expressible as triangular plus rank at most k there are at most 2^{s(s+1)/2+2sk} choices (encode upper triangular part and rank-k factors, padding with zeros). Multiplying across blocks with off-block choices gives at most 2^{n(n+1)/2+2nk}; include at most 2^n block-type choices, 2^{n-1} ordered compositions, n! permutations and 2^n demand labels. These are upper bounds, allowing non-SCC partitions and duplicate encodings.

For a good chart the underlying ordered planes are fixed in its coordinates. Reverse chart changes choose ordered (e_i',f_i') in the three nonzero plane vectors, at most 6^n choices, with e_i' independent, and any complement w', at most 2^{n+1} choices; the resulting coordinate change is determined. Multiplying also by n! if labels are permuted is harmless. Thus all strict pairs equivalent under these chart changes to some good chart are bounded by 2^{n(n+1)/2+2nk+O(n log n)}. Take k=floor(n/8): exponent <=(3/4)n^2+O(n log n). This is asymptotically smaller than the strict-pair count. Consequently there exist strict geometries for which EVERY chart and order contains an SCC that is neither symmetric nor of feedback rank <=floor(n/8). This is a symbolic obstruction to a restricted normal form, not a time lower bound, not a claim about the missing-versus-full syndrome type of the obstructing geometries, and not a refutation of a larger portfolio with other terminals or exact contractions. No large counting experiment was performed. Universal proof would need a different argument, not simply more choices of these chart types.

[1] Chatterjee, Ghosh, Gurjar, Raj, Characterizing and Testing Principal Minor Equivalence of Matrices, STOC 2025, https://arxiv.org/abs/2410.01961. Theorem 1.2 tests equality of all corresponding principal minors over any field in deterministic polynomial time; theorem 1.3 handles identity of pairs of symbolic determinants with rank-one variable coefficient matrices. RT34 needs one-sided support containment, not equality. For any M,b, b annihilates feasible repair span iff for every j support(det(I+diag(z)(M+e_j b^T))) is contained in support(det(I+diag(z)M)). To see the reverse implication, take a minimum-support odd repair S; any nonzero kernel vector of M[S,S] other than its all-ones vector would yield a smaller odd repair, either itself or its complement in S. Therefore nullity one, and a row update by b_S^T at some j makes the determinant nonzero. Forward follows since each principal kernel vector is an actual repair extended by zeros. A nonsingular minor may become singular without contradicting containment: M=[1], b=1, update [0]. Thus equality cannot substitute for containment. ES01 does not claim a general PIT closure.

[2] Brouwer, An inequality in binary vector spaces, Discrete Math. 59 (1986) 315–317, https://ir.cwi.nl/pub/2507/2507D.pdf.
