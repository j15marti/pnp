## 2. Chart and exact module semantics

All arithmetic GF(2). Input explicit n×n binary M=A+diag(d), A zero diagonal; optional q explicit affine guard rows Gp=t, including demand b^T p=1 when q=1. Strip dependent guard equations and reject inconsistent ones. An arc i->j means A_ij=1. Local repairs obey p_i(Mp)_i=0. A module C has identical outgoing AND incoming adjacency to every outside vertex for all its members. If partitioned into modules C_1,...,C_k, arcs between distinct modules are all-or-none in each direction. Quotient Q_ij records that constant, Q_ii=0.

For strict geometry, choose independent e_i in U_i by partition/linear matroid intersection (Rado); choose complementary f_i in each plane and w outside span E of e_i. Write f_i=sum_j A0_ji e_j+b_i w. The affine hyperplane sum f_i+E consists of attainable targets directly. For another target change each f_i by e_i if required to make t_syndrome=sum f_i+w. Set M=A0+I. Select e_i when p_i=1 and otherwise f_i or f_i+e_i. The sum equation is equivalent to b^T p=1 and Mp=qvec with qvec_i=0 whenever p_i=1. Thus exactly homogeneous repair. Changing one f_i by e_i changes M_ii and shifts target by e_i, preserving original planes and b. No general coordinate substitution preserving individual group labels is assumed.

For every module C define exact table T_C(h,s,g) for h,s in GF(2), g in GF(2)^q. Membership means there exists actual p_C with
  p_i((M_CC p_C)_i+h)=0 for every i in C,
  sum_{i in C} p_i=s, G_:C p_C=g.
Store an actual representative or reconstructible backpointer. h is the uniform external shift, not a freely imposed pin. Tables include both h values even when one is not realizable outside; only matching parent combinations count.

For a leaf i, enumerate p_i=0,1, obey local equation and any certified fixed coordinate. For parent partition with quotient Q, enumerate child parities z in GF(2)^k; then child i must use shift h_i=h+sum_j Q_ij z_j, parity z_i. XOR-join actual child guard signatures and retain parent parity sum z_i. Root uses h=0 and guard t, either parity. Proof by disjoint concatenation: every actual parent repair determines its child parities, hence appears in join; every retained join has correct shift at each vertex and guard signature, so is an actual repair. Induction gives both labels and reconstruction. In particular this is not affine-hull substitution and not a Cartesian product of all repair words.

## 3. Paid module discovery

Steiner and Wiederrecht, Parametrised Algorithms for Directed Modular Width, arXiv:1905.13203v1 (30 May 2019), Definition 2.1 exactly the two-direction module condition above; Definition 2.2 defines dmw as smallest k admitting a partition into 2..k modules recursively, with trivial base size<=k. Fact 1: induced subgraphs cannot increase dmw. Theorem 2.7 (attributed to McConnell/de Montgolfier) returns a partition into 2..dmw modules for any loopless digraph with >=2 vertices, in O(vertices+arcs). Primary PDF pp.5,9 consulted; no need to import that implementation.

Self-contained slower discovery, executed in audit: for each pair u,v, begin S={u,v}. Add every outside x whose incoming or outgoing relation to some member differs from its relation to u. Repeat via queue until stable. Every module containing u,v must contain every added x, by induction; stable S is a module. Hence a proper nonsingleton module exists iff some pair closure is proper. When one is found, recursively decompose its induced graph and the quotient graph formed by retaining one representative; replace that representative leaf by the module's decomposition. Intermodule uniformity ensures this substitution is exact. If none found, make the whole subproblem a quotient node with singleton children. Both recursive graphs are induced subgraphs of current graph. If original dmw<=k, then any module-free subproblem has size<=k: otherwise Definition 2.2 gives a partition with a proper nonsingleton module. Thus arbitrary chosen proper modules still guarantee max quotient arity<=dmw (for n>=2). Conversely a returned tree with max arity w is a valid dmw<=w certificate, so this method attains the optimal width, though not the optimal tree shape. Each split sizes a and n-a+1 conserves potential n-1; at most O(n) discovery calls, each at most n^2 pairs and O(n^2) adjacency comparisons per pair using a queue. O(n^5) bit-comparison bound plus polynomial indexing, construction and validation. Verify every original arc against quotient labels if desired. No guessed module partition, isomorphism oracle, or optimal rank oracle.

## 4. Theorem A: hierarchical finite-type terminal

For maximum acquired quotient arity w and q independent explicit guard equations, time <=poly(N) * 2^(w+2q). More precisely sum over internal nodes of 2^arity times polynomial local work and 4^q. Each node stores at most 4*2^q signatures, not 2^|C|. Tree O(n) nodes; joins of at most 2^q guard states cost <=4^q per child/mode. Retain actual representative bit vectors or backpointers. Peak space <=poly(N)*2^q including discovery and stored witnesses; cumulative memory <=(T+1)S on same execution. Includes failed modes, all boundary states, parsing, guard checks, Gaussian work, module discovery and witness output. In fixed-width or w+q=O(log N) regimes polynomial even with unbounded depth and one SCC. A capped solver returns UNKNOWN when no admitted terminal applies, not NO.

Certified forced-information closure: under actual root affine guard, Gaussian reduce factors p_i and (Mp)_i. If either is forced zero or they are complementary, product tautological; if either forced one, force other zero; if equal, force common form zero by f^2=f. Repeat to fixed point after each deduction (at most n independent rows); contradiction exact NO. Keep original equations and input guard; implied fixed coordinates can filter leaf words without changing support. Other derived rows are certificates, not independently added exponential guard bits. At stagnation (unadmitted quotient) repeat closure if new facts, otherwise UNKNOWN; no proof based on incomplete closure. ## 5. Theorem B: large heterogeneous quotient nodes can also be admitted

The same child tables permit alternative local quotient solvers without recomputing children or multiplying search costs across depth.

(i) Directed cycle quotient: fix first parity z_1. Sweep children in directed cycle order, state (current z_i, accumulated parity, accumulated guard), choose next z_{i+1}, use T_i(h+z_{i+1},z_i,g_i), XOR-accumulate and enforce z_{k+1}=z_1. Constant extra parity states and O(4^q poly(N)) time. Store one actual child representative per transition, lift in reverse. Thus large prime quotients which are directed cycles do not require exponential arity enumeration.

(ii) Diagonal-plus-low-rank quotient: use FG01 disjoint-pivot factor acquisition for singleton blocks, Q=D+LR with rank r at most 3 times minimum diagonal-completion rank. For each u=Rz enumerate child parities z_i and read tables at shift h+(Lu)_i+D_ii z_i. Join actual signatures (R_:i z_i,z_i,g_i), demand final accumulated Rz=u, record aggregate parity and guard. At most 2^(r+q+1) states, 2^r modes, child alternatives <=2^(q+1), time <=2^(2r+2q)poly(N). Exact lift retains individual child choices. No arbitrary guard-count elimination claim here: these are nonlinear child tables. For q=1 and r=O(log N) polynomial.

All local node costs add, with common actual support representation. The resulting heterogeneous hierarchy is polynomial when each acquired quotient is of bounded/log arity, a directed cycle, or bounded/log diagonal-completion rank, q=O(log N). A different decomposition can yield different quotient classes; only the width discovery guarantee is unconditional. Implemented independent quotient signature audits (arbitrary child tables); the main graph solver executes arity enumeration, not integrated cycle/rank acquisition plus reconstruction. For any large node outside all admitted terminals, return UNKNOWN. ## 6. Explicit infinite strict family

Let A_1 be adjacency of directed 4-cycle, and A_l the lexicographic substitution of four copies of A_(l-1) into A_1, n=4^l. Every module has 4 children, graph is strongly connected and asymmetric. Use d=all ones and b=all ones. Define U_i=span(e_i,f_i), f_i=w+sum_j (M+I)_ji e_j, with e_i,w independent. Every nonempty subset S of planes has rank >=|S|+1 since all selected e_i independent and any f_i outside E. Thus strict dual expansion and full rank n+1, hence primal strict deficiency one. For a subtree with all-one d, external shift h=0 permits only even selected parity; h=1 permits both parities. Prove by induction: leaf true; at a cycle quotient, z_i=1 requires h+z_(i+1)=1 by induction. For h=0 a nonzero z must be all ones, parity even; for h=1 all-zero and any singleton give both parities. Therefore at root h=0 odd demand is impossible. Flip one diagonal to zero: singleton at that vertex is feasible and odd, so SAT neighbor. This is the same geometry (f_i toggled by e_i, target shifted by e_i). The family is not a bounded-size SCC class, and in this chart diagonal-completion rank grows linearly: in each disjoint deepest 4-cycle choose first two rows' difference and third column; row and column sets disjoint. Against columns from other bottom modules row difference cancels uniform arcs; against its own third column it is 1. The resulting identity minor of row combinations proves every diagonal completion has rank >=n/4. Does not rule out low rank in other charts or FG01 other block partitions. Tests l=1..4, n=4,16,64,256, all correct, arity4 discovered from raw A. The theorem holds for all l.

## 7. Theorem C: universal low modular-width chart normalization is false

This counting obstruction is chart-independent, distinct from an example with one wide chart. Work in fixed V=GF(2)^(n+1), labeled planes. Let F be number of ordered bases (e_1,...,e_n,w). For every such basis and every zero-diagonal n×n matrix A choose f_i=w+sum_j A_ji e_j and U_i=span(e_i,f_i). All geometries are strict by section 6, regardless of A. There are F*2^(n(n-1)) presentations. A geometry has at most 3^n choices of ordered e_i (one from each labeled plane), at most 2^n choices of w outside their span, and at most 2^n choices of f_i after these (actually unique under prescribed b=all ones and zero diagonal). So at least F*2^(n(n-1))/12^n distinct strict geometries exist.

For any geometry admitting ANY legal independent transversal, complement, and choices of f_i whose off-diagonal graph has dmw<=k, encode it by basis (F choices), n-bit b and n-bit diagonal (<=2^(2n)), and a graph with substitution tree of max arity k. The tree has n labeled leaves, at most 2n-1 total nodes, ordered tree shape encoded by <=4n bits of parentheses (allow harmless extra O(log n) for length), leaf labels by n! choices. At each internal node with a children encode a(a-1) arcs. Sum <=(k-1)(2n-2) since sum arities is total edges in tree. Hence count of all low-width geometries <=F*n!*2^(6n+O(log n)+(k-1)(2n-2)). For k<=floor(n/4) and sufficiently large n this is strictly smaller than the lower bound above (exponents after cancel F: n^2/2+O(n log n) vs n^2-O(n)). Therefore infinitely many strict geometries admit NO legal repair chart of modular width <=floor(n/4), even allowing arbitrary plane basis switches and complement, and regardless of target. This is not an explicit constructive family, nor a barrier to a heterogeneous terminal that solves large prime quotients, nor to unrestricted computation. It disproves universal logarithmic modular-width chart discovery as sole closure route. No complexity-class separation.

Additional explicit fixed-chart controls: directed simple cycles n>=3 are module-free: a proper nonempty module has an outgoing arc to exterior by strong connectivity, whose head has indegree one, forcing module size one. For all-one d,b these cycles accept iff n odd (nonzero repair must be full cycle). Thus even this wide class has an elementary terminal. Union-of-two-cycles controls are strongly connected and wide in tested chart, not certified expanders. Do not infer high-width hardness.
