## 2. Exact source projection and paid forced closure

Delete Z element vertices from the planar incidence graph and smooth each triple node to its own indexed edge e=(x,y) labeled z. This is a planar bipartite multigraph; parallel edges must retain IDs. Every perfect matching has exactly q edges. Let L_e be unit vector at z in F2^q. A perfect matching is a P3DM solution iff XOR L_e=1^q: each label then has positive odd count and their integer total is q, so every count equals 1. The proof remains exact after tuple deletions/pins and for arbitrary degrees. This is AGE02's parity-restoration observation; no claim that Gaussian parity alone is sufficient.

Before factoring, repeat exact-one singleton closure and delete any triple whose edge is in no perfect matching of any of the three pair projections. Empty owner or nonexistent pair matching gives exact NO. Find an allowed edge by forcing it, removing its endpoints, and running bipartite matching on the remainder; at most |T| deletions, polynomial number of polynomial matching calls. A pinned-one tuple deletes competitors in all three coordinates; pinned-zero deletes that tuple. After each deletion restart closure to a fixed point. This is a sound necessary-information closure, not all semantic consequences. At stagnation proceed to the exact terminal, not an oracle.

Factor the live XY projection into connected matching components G_i. Let A_i be the actual set of XOR label signatures of its perfect matchings (each signature retains actual local lift). All components must be matched. P3DM iff t=1^q is in S=A_1+...+A_g (binary Minkowski sum). Under explicit affine equations Gx=h on original edge-selection bits, append each edge's guard column to its signature and append h to t; theorem then still exact. Executed source audit tests pins, not all affine guards.

Paid table acquisition: choose baseline matching per component or NO. Matching differences belong to its binary cycle space, compute fundamental cycle basis and its image under L (and appended guards), rank r_i. Pick a linear projection injective on that image and use baseline offset. For each of 2^r_i characters evaluate weighted planar bipartite matching partition function (weight ±1 on indexed edges) using a sign-coherent Kasteleyn determinant. Face equations including digons and bridge occurrences can be solved over F2 after omitting exterior face. Alternating cycle sign proof is AGE02 section 3; Kuperberg, arXiv:math/9810091v2, supplies the planar permanent-determinant theorem. Use one common determinant sign from baseline, not absolute value of signed evaluations. Walsh-Hadamard inversion gives all exact signature counts with 2^r_i poly(N) bit work. Retain positive-count signatures only. An actual chosen signature can later be lifted via edge-deletion count self-reduction, O(|T|) determinant-count probes with the same original signing and rank bound; zero weights preserve coherence. Alternative: enumerate 2^c_i cycle words for component cycle rank c_i, check actual perfect matching, collect distinct signatures. The proof of the local rank terminal is imported from AGE02 and extends its target count to full local table by inverse transform. No Fourier backend executed in this run; small source components enumerated by actual matching recursion. A rank-capped production implementation must decline an unacquired table as UNKNOWN. ## 3. Theorem A: canonical semantic stabilizer saturation

Let V=F2^d, A_i nonempty explicit subsets with actual witnesses, target t. For H a linear subspace write pi_H:V->V/H, and Per(B)={p:B+p=B}. Per(B) is a subspace. For a coalition I of distinct indices let A_I=sum_(i in I) A_i. Fix a family C of permitted nonempty coalitions (e.g. all coalitions of size at most k, for fixed k). Start H=0; whenever a coalition has nonzero period p of pi_H(A_I), lift p to v in V and replace H by H+<v>. Record pre-update H, coalition I, p and actual lookup information.

**Invariant and proof.** H is always a subgroup of Per(S). Initially true. If H<=Per(S), S is the full preimage of pi_H(S). Adding p to pi_H(A_I) leaves it unchanged, so p also stabilizes the full projected sum (other groups are unchanged). Taking preimages shows H+<v> <= Per(S). Thus at every step t in S iff pi_H(t) in sum_i pi_H(A_i). This uses actual sets, not affine spans.

**Canonical fixed point.** Define F(H)=sum over I in C of pi_H^(-1)(Per(pi_H(A_I))). F is extensive, monotone (a period maps to a period under every further quotient). Starting at zero its least fixed point exists. Every individual one-direction update stays contained in that least fixed point by monotonicity. Every terminal exhaustive scan with no available update is a fixed point, hence equals the least fixed point. Thus resulting subspace is independent of scan order or choice of representative. This is a canonical closure for fixed tables and fixed coalition family, NOT canonical across different source compilers/charts, and not necessarily full Per(S).

**Constructive reverse lift, including overlapping coalitions.** Suppose actual representatives a_i in A_i were selected at the final quotient with residual delta=t+sum_i a_i in H_final. Undo updates in reverse. At a step H' = H+<v>, residual mod H is 0 or p. For zero keep choices. Otherwise form current coalition signature u=sum_(i in I) a_i; because p is a period of pi_H(A_I), there is an actual tuple of choices (a'_i) with pi_H(sum a'_i)=pi_H(u)+p. Use saved table or recompute its actual lookup, replace only this coalition's representatives, and residual now lies in H. Overlap does not matter: each step operates on current actual choices, not the old choices at extraction. At H=0 residual vanishes. Lift each final local matching signature by stored actual word or local self-reduction, and verify source. No assertion that arbitrary XOR of actual matchings is a matching.

**Discovery and resources.** For a finite set B and base b in B, every period lies in B+b. For each candidate test translation equality by exact set lookup. Explicitly enumerate coalition sums with actual tuples, at most M^k entries and at most g^k coalitions for max table size M and fixed k. At most d rank increments, then one terminating scan. Conservative time poly(N,g,d)*(g M)^(O(k)), space poly(N,g,d)*M^k for one coalition at a time (store O(d) basis/coalition certificates and recompute lookup in reverse); all exact vector arithmetic. Taking fixed k and polynomial M gives uniform polynomial work including failed period tests and lift. A basis is canonicalized by Gaussian elimination; deduplicate actual equal vectors only. For a single group, affine support is completely absorbed; a nonaffine support can become affine after another group absorbs a direction. Optional k=2 absorbs two aperiodic three-point sets in a 2D plane whose sum is the full plane. This is a decision/witness theorem, not a count-preserving quotient (fiber multiplicities differ).

## 4. Theorem B: exact residual seam, additive join

After saturation choose one actual base a_i of each projected table B_i=pi_H(A_i), normalize to B_i+a_i, and adjust target by XOR bases. All normalized sets contain zero. For a fixed group order let U_j be the span of normalized supports up to j, W_j span after j. For any reachable partial sum u_j that can still reach t', necessarily u_j in U_j and t'+u_j in W_j. Thus candidate partial sums lie in empty set or one coset of U_j intersection W_j. Keep only actual reachable values, not the entire coset. Initialize zero; extend by each actual local signature, reject a partial sum if target+sum outside W_j (paid Gaussian test), merge identical partial sums with one actual backpointer. At final j=g accept exactly target. Completeness: every actual full witness has suffix in W_j and survives all pruning; soundness: every retained representative is an actual disjoint-group concatenation. Theorem A reverse lift then restores the unquotiented witness.

Let w=max_j dim(U_j intersection W_j) for this order. At most 2^w retained states per step; time <=poly(N,g,d)*2^w sum_i |B_i|, space <=poly(N,g,d)*2^w including reconstruction. Orders can be supplied and checked or a fixed deterministic order used; greedy width optimization is not assumed to find a good order. The audit uses input order and caps actual state count, UNKNOWN on overflow. Rank w is a trellis-style interface (cf. Kashyap, arXiv:0705.1384), not total residual rank, and the same actual support discipline is compatible with AB08 branch interfaces. Direct-sum blocks (AGE02) give width zero between independent blocks, and can be processed separately. This is a single-target decision, not full support enumeration. Overall production time with local rank acquisition <=poly(N) [sum_i 2^r_i + (g M)^(O(k)) + 2^w sum_i |B_i|], with fixed k; witness self-reduction adds polynomial factors. Hence uniform polynomial if r_i and w are O(log N), including semantic saturation discovery; high total rank or total number of groups alone does not obstruct.

## 5. Infinite families and a sharp finite-coalition firewall

In V=F2^n take chain A_i={0,e_i,e_i+e_(i+1)} for i=0..n-2, and one seed {0,e_0}. Initial local ranks 2 each and 1 seed, global rank n, redundancy n-1, all spans linked in one direct-sum block (adjacent share e_(i+1)). Absorb e_0, then projected A_0={0,e_1} so absorb e_1; repeat to full V. This proves exponential total-rank enumeration is unnecessary on this family of actual finite tables. Removing seed leaves t=e_(n-1) impossible: to select last bit, last group must select e_(n-2)+e_(n-1), recursively forcing predecessor pair and leaving uncancelled e_0. Natural seam width at most one gives exact NO in polynomial time. This is an abstract support family, NOT a new NP-complete source compiler.

**Theorem C (bounded coalition failure).** Close the chain into a cycle of n>=3 groups A_i={0,e_i,e_i+e_(i+1 mod n)}. The sum over a consecutive proper run of l groups is the entire space on its l+1 consecutive coordinates except the terminal unit vector: induction starting l=1; appending {0,e_l,e_l+e_(l+1)} covers all old coordinates for new bit 0 (old missing vector shifted differently), and all but zero old coordinates for new bit 1. Any proper nonempty subset of cycle groups splits into disjoint runs on disjoint coordinate supports (a missing edge separates endpoints). Its support size is product over runs of (2^(l+1)-1), odd. A nonzero binary period acts as a fixed-point-free involution, so odd-size set has no nonzero period. Therefore for every fixed k<n, bounded-coalition saturation remains H=0, irrespective of order. Yet the full cycle sum is V: n-1 consecutive groups miss only the terminal unit vector, and the last group contains precisely that vector, which lifts from zero. Hence bounded coalition saturation does not universally acquire all global periods, even with three-state factors and a fixed type of local group. This is not a decision lower bound: natural order seam width at most two, solved by Theorem B. It specifically refutes the proposed universal bounded-coalition absorption strategy on arbitrary support tables. Whether P3DM has additional structure preventing this obstruction is open. Pair joins or larger grouping may work but must be paid; no free all-subset search.
