## 2. Theorem A: deterministic coupling acquisition, even without the factorization

All arithmetic is GF(2). Input explicit n x n matrix M and a supplied partition P of its index set into nonempty blocks of maximum size h. Let k_* = min rank(M+D) over matrices D supported on the diagonal blocks (arbitrary entries within each block). In particular, h=1 gives the minimum rank after changing only the diagonal. No supplied optimal D, rank, factorization or SAT witness.

**Theorem.** In deterministic poly(N) bit time acquire D, L, R such that M=D+LR, D block diagonal for P, rank(LR)=r', and
  r <= k_* <= r' <= (4h-1)r <= (4h-1)k_*.
Here r is the number of disjoint-block pivots and a certified lower bound on k_*. For h=1 this is a factor-three rank approximation. More generally the actual certificate r'<=2|E|-r uses the union E of excluded blocks.

**Construction and proof.** Initially residual Q=M, all blocks unused. If Q has a nonzero entry Q_ij with i,j in two distinct unused blocks, choose the lexicographically first such entry, and add the rank-one matrix Q_:j Q_i: to Q (the pivot is 1). This zeros row i and column j. Record i in I, j in J, and mark both blocks used. Repeat. Let r=|I|=|J|. Previously zero rows/columns remain zero under later updates. The chosen I x J submatrix of the original M is nonsingular: the residual pivot updates are exactly its Gaussian Schur elimination in chosen pivot order, and its determinant is product of unit pivots (over GF(2)). Its row and column blocks are disjoint, so *every* allowed block-diagonal edit leaves this submatrix unchanged. Thus r <= k_*.

After stopping, residual entries between distinct unused blocks vanish. Set D equal to the residual within all unused diagonal blocks and zero elsewhere. The remaining residual Q+D is supported on rows or columns from E, the used-block union, and has zero rows I and zero columns J. Split this support into rows E minus I and the remaining columns E minus J. Rank at most (|E|-r)+(|E|-r). Since M is sum of r pivot outer products and Q, rank(M+D) <= 2|E|-r <= (4h-1)r. Gaussian elimination obtains a rank factor of M+D. This proves all inequalities, including r=0 (M already block diagonal). It does not compute the optimum rank, and no optimization over partitions or charts is asserted.

Each pivot scans at most n^2 entries, performs at most n^2 bit updates, and uses two fresh blocks. O(n^3) elementary bit operations plus polynomial Gaussian factorization/storage with ordinary array encoding suffice; standard deterministic TM simulation has polynomial overhead. Verify factor identity and block support and record the actual nonsingular disjoint minor. The cap can decline if actual r' too high; decline is UNKNOWN, not NO. This addresses the acquisition hypothesis of MFC46C at log interaction rank without an oracle. In the block case, the rank approximation depends on h, so the sufficient threshold must charge h*k_* (not just k_*).

## 3. Theorem B: exact group-parity decision with arbitrary local finite types

Given M=D+LR above, consider actual homogeneous repairs p_i(Mp)_i=0 for each i and explicit affine guard Gp=t, G has q rows (remove redundant/contradictory equations first). The target b^T p=1 is one such row. For each z in GF(2)^r', impose Rp=z. In this mode, each block B has entirely local nonlinear condition
  p_i[(D_B p_B)_i+(Lz)_i]=0 for i in B.
Enumerate its <=2^h actual binary words, retain exactly those satisfying all local equations. For each store its signature (R_:B p_B,G_:B p_B), with an actual representative word. Repeated signatures can be merged, because the only residual coupling is the joint target (z,t).

Start the global table at signature 0. Merge the blocks one at a time by XOR of signatures, storing one actual disjoint-block concatenation per signature (or backpointers). After the final block accept iff signature (z,t) exists. Every original feasible repair has one enumerated z and valid local words, so survives every join. Conversely any accepted record is an actual p with Rp=z, all local nonlinear equations and Gp=t; factor identity gives Mp=Dp+Lz. Verify directly. This is an actual joint support DP, NOT affine-span replacement. Local blocks may be symmetric, asymmetric, mixed, or arbitrary. The entire off-diagonal graph may be one SCC.

For each mode the table has at most 2^(r'+q) entries; join cost <=2^(r'+q+h) poly(N), total across modes and all blocks <=2^(2r'+q+h) poly(N); peak space <=2^(r'+q) poly(N) with streamed local enumeration/retained representative maps. Cumulative memory <=(T+1)S for the SAME execution. Includes input and partition checks, rank acquisition, modes that fail, all joins and output. Hence deterministic polynomial when h*k_*+q+h=O(log N). For h=1 use the stronger special terminal: fixed z, activated positions must satisfy D_ii=(Lz)_i. Set all other positions zero and solve [R;G]p=(z,t) by Gaussian elimination. This gives 2^r' poly(N) <=2^(3k_*) poly(N) even for arbitrarily many explicit affine guard equations; no exponential q. Actual feasible-repair span is also obtainable by retaining a base point and its single nullspace-basis toggles in each consistent affine mode, then taking a basis from actual representatives. General block case can obtain unguarded span with <=n+1 actual linear-demand probes (one affine guard per probe): maintain actual witness span, test each annihilator basis direction, add an actual witness if found. A failed query establishes the direction universally vanishes, not that arbitrary combinations of feasible repairs are feasible. Each increment increases dimension. This is a polynomial number of calls, no hidden exponent.

## 4. An infinite family not covered by diagonal-only rank in the given chart

Take three types indexed mod 3, each with s private pairs (n=6s). Within every pair put reciprocal arcs. Each vertex has directed arcs to every vertex of the next type, and no other off-diagonal arcs. Set every diagonal entry to 1. The whole digraph is strongly connected and asymmetric. Partition into pairs; interblock rank is at most 3, since the interaction is exactly a cyclic 3x3 type matrix lifted by indicator vectors. No supplied partition is needed for this example: for s>=2, compare all vertex pairs for symmetric mutual incidence and identical in/out incidence to every outside vertex. Precisely the true pairs pass (other same-type vertices differ on their partners, different types fail on external vertices). Verify unique pair partition in O(n^3). Theorem A acquires r'<=21, independent of n. Theorem B uses h=2 and one demand; polynomial. In contrast, choose first vertices of all s pairs of type 0 as rows, second vertices as columns. The disjoint minor is identity, so every diagonal-only completion in THIS chart has rank >=s. No claim about alternative charts.

Let z_j be the parity of selected vertices in type j. For a pair in type j, if z_(j+1)=0 its effective diagonal is 1 and only 00,11 are legal, so z_j=0. Therefore z_j=1 implies z_(j+1)=1. All type parities coincide. Demand b marks all vertices in types 0 and 1 only, hence b^Tp=z_0+z_1=0 for every repair. Target 1 is UNSAT. Flip a single diagonal at a vertex of type 0: its singleton becomes an actual SAT repair with b^Tp=1. This is an analytic infinite both-label proof.

Authentic strict dual planes for BOTH labels: in V=GF(2)^(n+1) take independent e_i, w, f_i=(M+I)_:i in e-coordinates plus b_i w, U_i=span(e_i,f_i). Every proper nonempty owner subset J has an arc from outside J into J by strong connectivity, so one f_j has nonzero component outside span(e_J). Therefore rank(U_J)>=|J|+1. For the full set some b_i!=0 gives rank n+1. Each U_i is truly 2D. Under ES01 chart mapping y_i=f_i+p_i(f_i+e_i)+q_i e_i, q_i=(Mp)_i, the target w+sum f_i is attainable iff b^Tp=1 repair. The diagonal flip changes f_i to f_i+e_i, preserving each U_i and shifting the target by e_i: true adjacent-syndrome SAT/UNSAT controls on the same strict geometry. No NP-hard source coverage inferred.

### Hostile rank/girth controls

Directed even cycle with d=1 and b=ones: every selected vertex forces its successor selected, so only zero/all-ones repairs, both even. Single diagonal flip makes singleton SAT. The disjoint minor from alternating vertices gives raw minimum diagonal-completion rank >=n/2 despite arbitrarily large girth. The cycle terminal handles it; not a universal barrier.

More generally on any connected simple graph with bounded maximum degree Delta, a greedy induced matching of size Omega(n) exists: each chosen edge removes endpoints and all their neighbors (<=2Delta+2 vertices) and destroys at most 2Delta(Delta+1) edges; initial edge count >=n-1. Orient its edges as disjoint row/column sets; off-diagonal adjacency submatrix is identity. Every diagonal completion therefore has rank Omega(n). In particular, high-girth constant-degree Ramanujan/expander families are controls, not hard instances for this solver portfolio. Symmetric matrix d=ones, b=ones has no odd repair by p^T M p=sum p_i=0; flip one diagonal for an actual SAT singleton. Supplement tests simple-support Margulis-Gabber-Galil graph at 9–289 vertices (loops dropped, parallel edges merged), checks connectivity, symmetry, exact induced identity minor and singleton. The known bounded-degree multigraph expansion persists up to a constant after merging, but no numerical spectral claim is needed or tested. This illustrates why high raw completion rank does not imply general hardness. ES01's counting obstruction to all-chart symmetric-or-low-feedback-rank already subsumes a universal diagonal-only chart conjecture; our new theorem does not negate that obstruction.
