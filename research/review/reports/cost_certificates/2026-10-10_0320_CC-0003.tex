\section{Exact selected implication}
Fix one verifier $V$, explicit read-only input tuple $y=(1^n,p,x)$ of encoded
length $M$, witness bound $w(M)$, verification time $q(M)$, and writable
space $s(M)$.  The selected C2 implication asks whether one deterministic
random-access realization can enumerate all $|\pi|\le w(M)$ without
recopying $y$, while charging initialization, input probes, witness output,
replay and simultaneous workspace.  No assumption about the existence of an
accepted witness is made.

\begin{theorem}[Shared-input exhaustive acquirer]
If each invocation of $V(y,\pi)$ includes every random-access probe and
address operation in $q(M)$, a lexicographic acquirer finds the first
accepted witness or reports none in
\[
 O\!\left((2^{w(M)+1}-1)(q(M)+w(M)+\log(M+2))+w(M)\right)
\]
time and
\[
 O(s(M)+w(M)+\log(M+2))
\]
writable bits.
\end{theorem}
\begin{proof}
Keep one $w+1$-bit counter/witness buffer and one reusable verifier
workspace.  The fixed tuple $y$ remains on shared read-only input tapes.
For each candidate, reset finite control and $O(\log M)$-bit addresses, run
$V$, and increment the counter.  Each input read is already a verifier step.
On success copy the witness once.  Sequential reuse makes workspace additive,
not multiplicative in the number of candidates.
\end{proof}

When $q(M)=M^{v+o(1)}$, $v\ge0$, and
$w(M)=\kappa\log_2M+o(\log M)$, the time exponent is $\kappa+v$.
By contrast, CC-0002's displayed implementation included an $M$-scale copy
inside every candidate trial and therefore has exponent
$\kappa+\max\{v,1\}$.  Both are valid upper bounds for their declared
machines; neither is a universal acquisition lower bound.

\section{Full charge and $K$-elimination consequences}
Initialization consists of constant control plus address and counter setup.
Input access is direct and counted inside $q$.  Failed candidates pay a full
verifier run.  Output copies at most $w$ bits once.  Replay is exactly the
enumeration of distinct candidates; no result cache is assumed.  Peak space
contains the counter/witness, verifier state, and addresses simultaneously.
Ancestors and implicit-source access are outside this standalone interface
and must be added by any recursive wrapper.

If one requested input bit must instead be regenerated in
$M^{g+o(1)}$ time, that cost belongs inside verification and gives the generic
replacement $v\mapsto v+g$.  Materializing an implicit child can add a
separate construction term.  If acquisition, canonicalization, verification,
or replay invokes the hypothetical current-scale SAT algorithm of exponent
$K$, the combined exponent is at least $K$; fixed-depth recursion cannot
eliminate $K$.  Thus exhaustive acquisition can be near-linear only if
$\kappa+v\le1$ in this shared-input model, with compatible space and ancestor
bounds.

\section{Primary sources and transfer audit}
Fortnow--Lipton--van Melkebeek--Viglas use deterministic random-access
machines with read-only input excluded from writable space, while addresses
and local reduction-bit computation remain charged \cite{flmv2005}.  This is
a direct model precedent for shared read-only access, not a PFCERT
construction.  Hirahara--Kabanets--Lu--Oliveira show exact search-to-decision
reductions only in specified time-bounded Kolmogorov settings
\cite{hklo2024}; they do not supply this verifier or witness acquirer.
Bellare--Goldwasser's separation of generic decision and search under a
complexity assumption confirms that cheap verification does not generally
imply cheap witness discovery \cite{bellaregoldwasser1994}.

The direct theorem transfer is only the machine convention and charged local
access.  Treating certificate checking as certificate construction is a
failed transfer.  Streaming, proof-index and digest methods remain structural
analogies unless they provide exact random access and the same-realization
ledger.
