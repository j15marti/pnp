\paragraph{Result and strict status.}
This run falsifies a broad universal-extraction cost premise.  Four explicit
families---2-SAT equality, Horn implication, affine diagonal parity, and a
treewidth-one independent product---have compatibility matrices of full rank
$2^n$, while their canonical decision procedures use $O(n)$ elementary
operations.  With indexed CNF input length $M=\Theta(n\log n)$, all are
decidable in $O(M)$ time and $O(\log M)$ writable space on the declared
read-only random-access model.  This is \textbf{PROVED/EXACT}.  A bounded
suite checked 349,524 source pairs, exact $\mathbb F_2$ ranks through 512,
all four easy algorithms, alternate encodings, padding, redundant clauses,
independent products, and DEAD/COPY/DELAY/INTERP/RECOMP ledgers in 0.54
seconds; that validation is \textbf{COMPUTATIONAL}.

The result does not prove that every proposed clean core is easy.  It proves
that compatibility rank, semantic type count, explicit compatibility-table
extraction cost, and partition communication are not stand-alone lower bounds
on arbitrary SAT time or memory.  A separate SAME\_REALIZATION necessity
theorem remains \textbf{OPEN}.  P versus NP remains \textbf{OPEN}.

\section{Predecessor and selected implication}
The newest completed LOWER\_BOUND predecessor, LB-0004, was read from GitHub

The claim attacked here is the following proposed cost transfer.  For a
source family with compatibility matrix $K_F$, a universal extraction argument
might try to infer from large $\operatorname{rank}(K_F)$, many rows/types, or
large explicit table cost that every exact SAT decider must expose comparable
state, memory, or time.  The exact all-algorithm form would require
\[
 \forall A\ \forall F\in\mathcal H_n\quad
 A(F)=\operatorname{SAT}(F)
 \Longrightarrow
 R_A(F)\ge L\bigl(\operatorname{rank}K_F\bigr),
\]
where $R_A(F)$ is charged to the same execution.  The control families below
show that no superlinear $L$ follows from rank or type count alone.

\section{Four exact hostile families}
Let $u,v\in\{0,1\}^n$.  In every family the CNF contains canonical pins fixing
$x=u$ and $y=v$; unit and binary clauses are permitted because 3-CNF means
width at most three.  If exact width three is required, the standard local
equisatisfiable lifts used in the experiment preserve the same source
relation, with linear size overhead.

\begin{theorem}[FULL-RANK-EASY-CONTROLS1]
Each of the following source compatibility matrices has rank $2^n$ over
$\mathbb F_2$, although its canonical promise problem is decided with $O(n)$
bit comparisons or row operations.
\begin{description}
\item[] \textbf{2-SAT equality:}
$E_n(u,v)=1$ iff $u=v$.  The CNF uses
$(\neg x_i\vee y_i)\wedge(x_i\vee\neg y_i)$, so $K=I_{2^n}$.
\item[] \textbf{Horn implication:}
$H_n(u,v)=1$ iff $u\subseteq v$ bitwise.  The CNF uses the Horn clauses
$(\neg x_i\vee y_i)$.  Under any linear extension of subset inclusion, its
matrix is triangular with a one on every diagonal entry.
\item[] \textbf{Affine diagonal:}
$A_{n,c}(u,v)=1$ iff $v=u\oplus c$ for fixed $c$.  Its matrix is a permutation
matrix.  Direct diagonal elimination uses at most $n$ row checks; generic
Gaussian elimination remains polynomial.
\item[] \textbf{Treewidth-one independent product:}
$T_n=E_1^{\otimes n}$.  Its matrix is $I_2^{\otimes n}=I_{2^n}$.  The primal
graph is a matching, hence has treewidth one, and dynamic programming sends
one constant-size message per component.
\end{description}
\end{theorem}
\begin{proof}
The equality and affine statements give identity and permutation matrices.
For Horn implication, order subsets by any linear extension of inclusion.
The zeta matrix $[u\subseteq v]$ is triangular with diagonal one, so its
determinant is one over every field.  Tensor products multiply ranks, giving
rank $2^n$ for the independent product.  The displayed local predicates give
the $O(n)$ algorithms directly.
\end{proof}

Each source relation has $2^n$ distinct rows.  Thus the semantic rank and row
count are exponential in $n$, and equal
\[
 2^{\Theta(M/\log M)}
\]
under ordinary binary literal indices.  Nevertheless the decision algorithms
do not construct the table.  They inspect at most $2n$ source bits, or $n$
diagonal constraints.  The exponential explicit-table acquisition cost is
optional work, not an obligation of the decider.

\section{Preprocessing, extraction, reconstruction, and wrappers}
For every parameter $n$, the experiment separates four costs.
\begin{description}
\item[] \textbf{Preprocessing:} validate the fixed family syntax and locate
canonical pin slots, $O(M)$ sequential work and $O(\log M)$ counters.
\item[] \textbf{Decision:} at most $2n$ bit probes for equality/Horn and $n$
checks for affine/treewidth-one controls.
\item[] \textbf{Explicit extraction:} constructing all entries of the
$2^n\times2^n$ compatibility matrix uses $4^n$ predicate evaluations in the
literal implementation.  This is a measured upper bound for an unnecessary
construction, not a lower bound on SAT.
\item[] \textbf{Reconstruction:} one Boolean output bit.  No compatibility
row or witness is needed by the promise deciders.
\end{description}

Duplicate-clause padding multiplies indexed representation length without
changing semantics or decision probes.  DEAD tautologies change syntax but
not the relation.  A proper-width-three equality encoding and the direct
2-CNF encoding yield the same compatibility matrix with different source
lengths.  Clause ordering, variable renaming, and global complementation
preserve satisfiability after the corresponding decoder transformation.

The wrapper ledger gives the same decision function to BASE, DEAD, COPY,
DELAY, INTERP, and RECOMP implementations.  DELAY and RECOMP arbitrarily
inflate executed steps, while INTERP changes the internal representation from
clauses to a diagonal affine system.  Therefore raw trace length is not a
semantic invariant, and semantic rank is not an implementation-state
invariant.  A useful obligation must be wrapper-covariant and charged on the
actual realization.

\section{Extensional extraction boundary}
Let $E$ be a deterministic oracle transducer that receives a source and sees
an exact SAT decider only through membership answers.  If $A_0,A_1$ decide the
same language, induction on adaptive queries gives identical transcripts and
outputs for $E^{A_0}$ and $E^{A_1}$.  Hence membership-only extraction cannot
certify which implementation materialized a compatibility object or how much
state it used.  This is \textbf{PROVED/EXACT} for the declared black-box model
and agrees with the earlier REACQ1/TRACECLOSE1 guards.

The surviving EXTRACTOR/G2 form is therefore
\[
 \forall A,F\quad \operatorname{CorrectSAT}(A,F)
 \Longrightarrow
 \left[
  \operatorname{ChargedWhiteBoxExtract}(A,F,Q,\tau)
  \lor R_A(F)\ge L(M)
 \right],
\]
with $Q$ bound to the actual execution $\tau$.  This formula is only an
\textbf{OPEN} target.  It becomes circular if $R_A$ is defined as optimal
remaining runtime or if extraction replays the entire computation.

\section{Bounded experiment}
The command
\begin{verbatim}
timeout 30s python experiments/review/universal_core_compatibility_controls.py \
  --max-n 9 --seed 20261011 \
  --output results/raw/review/2026-10-11_universal_core_compatibility_controls.json
\end{verbatim}
used a 25-second cooperative alarm and completed in 0.54 seconds.  It
exhausted 349,524 source pairs for $1\le n\le9$, computed exact bitset ranks
for four matrices at every size, and compared every matrix entry with the
corresponding direct algorithm.  At $n=9$, all ranks were 512; explicit table
generation used 262,144 predicate evaluations; worst-case direct decision
used 18 probes for equality/Horn and nine checks for affine/treewidth one.

The encoding ledger at $n=9$ recorded 288 indexed bits for the direct 2-CNF,
2,592 for the proper-three-CNF lift, 12,960 after fivefold duplicate padding,
and 3,456 after DEAD padding.  The semantic matrices and direct decision
counts were unchanged.  Finite timings and ranks are \textbf{COMPUTATIONAL}
validation only.

\section{Literature and barrier audit}
Baker, Gill, and Solovay construct relativized worlds with both
$\Pclass^A=\NPclass^A$ and $\Pclass^B\ne\NPclass^B$ \cite{bgs}.  The
membership-only indistinguishability proof relativizes verbatim, so it marks
rather than crosses the barrier.  Aaronson and Wigderson show that P versus NP
requires nonalgebrizing techniques \cite{aw}; low-degree oracle access does
not bind one internal representation.  The recent XOR-Missing-String work
extends algebrization barriers through communication objects, reinforcing the
need for an exact model transfer rather than terminology alone \cite{chr}.
Razborov--Rudich is relevant only if a future compatibility property is both
large and constructive; no circuit lower bound is claimed here \cite{rr}.

Fortnow--van Melkebeek's SAT time--space tradeoff is a valid endpoint in its
declared random-access model \cite{fvm}.  It does not state that an arbitrary
machine stores a communication row or compatibility table.  The transfer from
two-party equality communication to shared-input random-access SAT is a
\textbf{FAILED TRANSFER}; rereading lets the latter compare coordinates with
logarithmic work space.  VLSI area--time, memory-hierarchy, and distributed-cut
analogies fail for the same reason absent a locality-preserving compiler.

Post-quantum collision entropy remains an exact object only at LB-0004's
fiber-count inequality, whose automatic direction is not the required upper
bound.  LWE-style external extraction and special-soundness binding are
\textbf{ANALOGY/CANDIDATE} ideas; the former is blocked in membership-only
form, while the latter needs a construction-specific theorem turning two
openings into a forbidden source witness.  Schur-square, quadratic-relation,
Hilbert, and syzygy methods have no model-matched correspondence to this
implementation-cost question in this run.

\section{DUPLICATION / CONTRADICTION AUDIT}
The project already distinguished semantic objects from machine state and had
retired the broad trace-acquisition reading of G2-0008.  SEM-QUOTIENT-ACQUIRE1
already states that truth-table acquisition does not force enumeration.
CC-0005 adds one unified exact rank theorem covering the required easy-family
controls and a measured cost separation between optional full extraction and
direct decision.  It does not contradict LB-0004: fiber-type quotients bound
an endpoint union once types are available, while this run shows that their
external abundance does not force their internal materialization.

\section{WHAT CHANGED RELATIVE TO ROOT MAIN}
Root main correctly leaves arbitrary-algorithm acquisition OPEN.  The sharper
statement is that any future compatibility-based resource must be normalized
against independent-product rank amplification and the four easy families
above.  Compatibility rank and semantic type count should not appear as
unqualified lower-bound resources.  Root main was not edited because this
review role has no LSPV ownership region.

unless ``expose or pay'' is replaced by an exact wrapper-covariant execution
relation.  The existing spines correctly retain the arrow as OPEN but do not
yet include the Horn/affine/treewidth full-rank counterfamilies as mandatory
regressions.
