\section{Reset-aware direct acquisition}
\begin{theorem}
Let shared read-only \(y\) have length \(M\).  On each blank-start invocation
let \(V(y,\pi)\) use time \(q(M)\), space \(s(M)\), and at most \(b(M)\)
visited writable cells.  If restoring blank state costs \(r(M)\), exhaustive
lexicographic acquisition over \(|\pi|\le w(M)\) costs
\[
 O((2^{w(M)+1}-1)(q(M)+r(M)+w(M)+\log(M+2))+w(M))
\]
time and \(O(s(M)+w(M)+\log M)\) writable bits.
\end{theorem}
\begin{proof}
Reuse one candidate counter and one verifier workspace.  Before each
candidate, clear every cell in the previous visited-cell list and restore
control and addresses.  Charge input probes inside \(q\) and copy the final
witness once.  A self-delimiting visited-cell list gives
\(r=O(b\log(b+2))\).
\end{proof}
If \(b\le q=M^{v+o(1)}\) and
\(w=\kappa\log_2M+o(\log M)\), reset keeps exponent \(\kappa+v\).
This is \textbf{PROVED/EXACT for direct explicit input}.  CC-0003's proof
and stateless harness are \textbf{FALSIFIED/RETIRED as reset proofs}: finite
control and address reset does not clear dirty writable state.  Implicit-bit
regeneration, ancestors, replay and nonconstant access remain unproved.

\section{Pointwise quasipolynomial-window gate}
\begin{theorem}
Suppose for every \(n,p,x\), with \(|p|\le n-2\) and \(|x|=n\),
\[
 U(p)\text{ outputs }x\text{ within }t(n)
 \Longleftrightarrow
 \exists\pi,\ |\pi|\le L(n),\ V(1^n,p,x,\pi)=1.
\]
Then for every constant \(c>0\),
\[
 \operatorname{DTIME}(2^{c(\log m)^2})\subseteq NP\cap coNP.
\]
Consequently the premise implies \(P\ne NP\).
\end{theorem}
\begin{proof}
For \(A\) decided in time \(2^{c(\log m)^2}\) and input \(z\) of length \(m\),
put \(n=m^a\), with constant \(a\) large enough to absorb the fixed universal
simulation degree.  A program \(p_z\) of length \(O(m+\log n)\le n-2\)
simulates the decider and writes \(1^n\) if \(z\in A\), otherwise \(0^n\).
It finishes within \(2^{a^2(\log m)^2}=t(n)\).  The equivalence gives an NP
witness for membership using \(x=1^n\), and one for nonmembership using
\(x=0^n\); all verifier inputs have polynomial length in \(m\).
If \(P=NP\), fixed quasipolynomial time would lie in \(P\), contradicting
the deterministic time hierarchy.
\end{proof}
The argument relativizes for a matched oracle and does not provide the
nonrelativizing hinge.  It also does not apply to a two-list relation, which
may accept both \(0^n\) and \(1^n\); choosing either is wrong for one possible
true endpoint.

\section{Checkpoint and literature transfer}
An explicit binary midpoint tree resolving a \(T\)-step computation to
one-step leaves has \(2T-1\) nodes for power-of-two \(T\).  Thus it is
superpolynomial at \(T=t(n)\).  This count was recovered from SIM-2-0011 and
is not claimed new.
\begin{description}
\item[Direct transfer.] Hartmanis--Stearns supports the hierarchy step.
Hirahara Theorem 3.9 supports the existing two-list immunity endpoint with
the same universal machine and time bound.
\item[Analogy requiring a theorem.] Succinct tableaux, algebraic
fingerprints, recursive checking, and collision extraction still need exact
deterministic noninteractive endpoint soundness and polynomial witness length.
\item[Failed direct transfer.] Cook--Rothblum TR23-097 and
Chen--Hong--Kalai--Xi TR26-102 are interactive proof systems.  They do not
give one deterministic NP relation with a globally bounded accepted-output
union.  Cryptographic binding and random oracles are also inadmissible here.
\end{description}
