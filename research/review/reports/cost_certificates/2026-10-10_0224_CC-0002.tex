\section{Selected implication and claim card}
The selected gap is quantitative attainability of a certificate-bearing
constructor.  The precise question is not whether a short witness exists,
but whether one same deterministic random-access realization can acquire,
verify, encode, expose for local access, replay, and consume it inside the
declared time and simultaneous-space window.

\begin{description}
\item[] \textbf{Quantifiers.} For one fixed verifier $V$, witness bound
$w$, and verification bound $q$, quantify over every legal $(n,p,x)$ and
every witness of length at most $w(n)$.  For the hash statement, quantify
over every finite descriptor set $D$, hash $h:D\to Z$, and semantic map
$f:D\to Y$.
\item[] \textbf{Machine and input measure.} Deterministic random-access
machines; $n$ or $N$ is complete encoded bit length as declared by the
respective PFCERT or SAT interface.  Candidate generation, index counters,
verifier input access, output, and all live buffers are charged.
\item[] \textbf{SAME\_REALIZATION.} The acquisition bound applies only
when the wrapper actually runs the enumerator and verifier.  The PFCERT
NP endpoint uses existential witnesses and has no acquisition phase.
\item[] \textbf{Weakest useful result.} Give an exact witness-length/time
window for the generic acquirer and an exact criterion distinguishing a
semantic quotient from a collision-prone label.
\end{description}

\section{Generic deterministic acquisition}
\begin{theorem}[Exhaustive witness-acquisition ledger]
Let $V(1^n,p,x,\pi)$ be deterministic.  On every legal input with
$|\pi|\le w(n)$, suppose $V$ uses at most $q(n)$ steps and $s(n)$ work
bits.  There is a uniform lexicographic acquirer that returns the first
accepted witness, or correctly reports that none exists, in
\[
 T_{\rm enum}(n,p,x)
 =O\!\left((2^{w(n)+1}-1)
       (q(n)+n+|p|+w(n)+1)\right)
\]
time and
\[
 S_{\rm enum}=O(s(n)+n+|p|+w(n))
\]
writable bits, under ordinary reusable-buffer conventions.
\end{theorem}
\begin{proof}
There are exactly $2^{w+1}-1$ binary strings of length at most $w$.
Enumerate them with a reusable counter and run $V$ on each.  Correctness is
exhaustive.  Candidate formation and address maintenance give the additive
input-length term.  The counter, current witness and verifier workspace are
simultaneously live, but witnesses from earlier iterations are not.
\end{proof}

This is an upper bound for one implementation, not a lower bound on all
acquirers.  If a wrapper chooses this implementation and claims a window
$T(n)$, the displayed product must fit that window.  Ignoring only fixed
constants, the controlling inequality is
\[
 w(n)+\log_2(q(n)+n+|p|+w(n)+1)
 \le \log_2 T(n)-O(1).                 \tag{1}
\]
For $q(N)=N^{v+o(1)}$ and
$w(N)=\kappa\log_2N+o(\log N)$, its time exponent is
$v+\kappa$.  Thus a near-linear constructor using this acquirer needs
$v+\kappa\le1$; $w=o(\log N)$ contributes no exponent, while a
polynomial-length witness makes this generic search superpolynomial.
None of these statements excludes a different structured acquirer.

For a decompression window $T(n)=2^{n^c}$ and
$w(n)=\lambda n^a+o(n^a)$ with polynomial verification, enumeration fits
when $a<c$, fails when $a>c$, and at $a=c$ depends on the leading constant
and lower-order slack.  For
$T(n)=n^{\log^d n}=2^{(\log_2 n)^{d+1}}$, a witness bound $n^a$ is far
outside the generic enumeration window for every fixed $a>0$.

\paragraph{Separation of interfaces.}
PVG-3's bounded-image PFCERT theorem needs only
$\exists\pi,V(1^n,p,x,\pi)$ to place its envelope in NP.  No enumeration
is part of that implication.  A wrapper that needs the actual $\pi$ to
build a child has a different interface and must charge acquisition.  The
equations above therefore narrow a constructive route without weakening
the existential PFCERT endpoint.

\section{Generalized bounded-list time-window obstruction}
Let $B(n)\ge1$ be polynomially bounded and computable, let
\[
 k(n)=n-\lceil\log_2 B(n)\rceil-1,
\]
and let $V$ accept at most $B(n)$ distinct $n$-bit outputs globally over
all witnesses for each program $|p|\le k(n)$.  Witnesses have length at
most $w(n)$ and verification time at most $q(n)$.

\begin{theorem}[Bounded-list diagonal window]
There is a fixed direct-machine routine, with $n$ supplied in a
self-delimiting $O(\log n)$-bit program, that outputs the lexicographically
first string outside the accepted envelope in time
\[
 D(n)=O\!\left(
 2^n(2^{k(n)+1}-1)(2^{w(n)+1}-1)
 (q(n)+\operatorname{poly}(n+w(n)))\right).       \tag{2}
\]
Let $D_U(n)$ include simulation by the same efficient universal machine
used in PFCERT.  If the claimed decompression bound $t(n)$ eventually
satisfies $t(n)\ge D_U(n)$, endpoint completeness is impossible.
\end{theorem}
\begin{proof}
The global envelope size is at most
\[
 B(n)(2^{k(n)+1}-1)<2^n,
\]
so an outside string exists.  Enumerating $x,p,\pi$ gives (2).  For all
sufficiently large $n$, the self-delimiting program for this fixed routine
and $n$ has length at most $k(n)$ because $B$ is polynomial.  If its output
is produced within $t(n)$, PFCERT completeness puts that output inside the
envelope, contradicting its construction.
\end{proof}

This extends the current two-list calculation; it does not prove
nonexistence in a slower window.  In particular the candidate
$t(n)=n^{\log n}$ remains open.  The theorem also does not turn witness
enumeration into a SAT runtime lower bound.

\section{Exact finite-hash semantics}
\begin{theorem}[Hash quotient criterion]
For finite sets $D,Z,Y$, a semantic map $f:D\to Y$ factors through a hash
$h:D\to Z$---that is, $f=g\circ h$ for some $g:Z\to Y$---if and only if
\[
 h(u)=h(v)\quad\Longrightarrow\quad f(u)=f(v)
 \qquad\text{for all }u,v\in D.                 \tag{3}
\]
Equivalently, every hash fiber is contained in one semantic equivalence
class.  Hence $|\operatorname{im}h|$ must be at least the number of
semantic classes met by $D$.
\end{theorem}
\begin{proof}
Necessity follows from applying $g$ to equal hashes.  For sufficiency,
define $g(z)$ to be the common $f$-value on the nonempty fiber $h^{-1}(z)$,
and define it arbitrarily on empty fibers.  Condition (3) makes this
well-defined.
\end{proof}

If $h:\{0,1\}^q\to\{0,1\}^b$ with $b<q$, a collision exists.  After that
hash is fixed, a Boolean semantic map can be chosen to separate the
colliding pair, so no such hash is a universal exact quotient for arbitrary
semantics.  Conversely, a one-bit map could encode SAT semantics exactly
only by already computing the SAT answer.  Short output alone therefore
does not show cheap acquisition.

The post-quantum collision ledger transfers exactly at one point.  With
$a_z=|h^{-1}(z)|$,
\[
 \operatorname{Coll}(h)=\sum_z a_z^2,
 \qquad
 |\operatorname{im}h|\ge
 \frac{|D|^2}{\operatorname{Coll}(h)}.           \tag{4}
\]
Equation (4) is an \textbf{EXACT OBJECT/THEOREM TRANSFER} from collision
entropy to the declared finite map.  It bounds image size, not semantic
fiber purity, collision discovery, or runtime.  Importing cryptographic
collision resistance or a random-oracle assumption as exact binding is a
\textbf{FAILED TRANSFER}.  Proving (3) for a construction-specific replay
or canonicalizer remains the needed bridge.

\section{K-exponent and simultaneous-resource audit}
The existing fixed-depth shrinker lemma remains correct: after $d$ strict
size contractions, the seed solver contributes exponents $Kh^d$ and
$\sigma h^d$.  This run adds no new shrinker.  If each contraction first
acquires a certificate by the exhaustive method, its exponent
$g=v+\kappa$ enters the same maximum:
\[
 T_d(N)\le
 N^{\max\{r,g,h^dK\}+o(1)}.
\]
The witness counter, verifier state, output child, replay decoder, cache,
and suspended ancestors must share one peak-space ledger.  A digest can
index candidates, but exact replay or a proof of (3) is still charged.
Thus finite-depth iteration eliminates $K$ only after acquisition,
encoding, local access, descendant closure, and workspace already satisfy
the favorable bounds.

\section{Primary literature and transfer classification}
Hirahara's Theorem 3.9 proves that $R_{K^t}$ is P-immune for every
superpolynomial $t$; it supplies the PFCERT endpoint but not the verifier
\cite{hirahara2020}.  Hirahara--Kabanets--Lu--Oliveira state that exact
search-to-decision for time-bounded Kolmogorov complexity is a longstanding
open problem and obtain reductions only in declared regimes; this is a
direct warning against treating certificate discovery as automatic
\cite{hklo2024}.  Kraj\'i\v cek's implicit proof system represents
exponentially long proofs by polynomial-size circuits, but the system is
genuinely stronger; it is an analogy for representation, not a free
acquisition theorem \cite{krajicek2003}.  Grochow's IPS result shows that
deterministic Cook--Reckhow simulation of Boolean IPS is equivalent to PIT
in NP; it does not give universal PFCERT \cite{grochow2023}.  Carter--Wegman
universal hashing gives probabilistic collision guarantees for data
structures, not the exact fiber condition (3) \cite{carterwegman1979}.

\section{Hostile controls and bounded test}
DELAY can make an explicit history arbitrarily long without changing its
endpoint; exhaustive search concerns witness length, not unavoidable
semantic work.  COPY and padding enlarge descriptors or hash domains and
must be measured in the active encoding.  INTERP and RECOMP change how a
witness is regenerated.  Horn, 2-SAT, affine/Tseitin and bounded-treewidth
instances may have cheap canonical summaries, confirming that the theorem
is an interface ledger rather than a hardness claim.  A maximal semantic
oracle can return the semantic bit directly; (3) survives as set theory
but supplies no lower bound.  The argument relativizes and algebrizes.

\section{Duplication, contradiction, and root reconciliation}
The acquisition exponent already appeared in SIM-2-0005 and the dynamic
witness tax in SIM-2-0007.  This run does not rename them as new.  Its new
formal contribution is their exact all-length witness count, the generalized
list-diagonal window, and the semantic factorization theorem integrated
with collision entropy.

The result rejects three overstatements: short certificate
$\Rightarrow$ cheap acquisition; finite digest $\Rightarrow$ exact semantic
identity; and collision entropy $\Rightarrow$ runtime or binding.  It does
not contradict COMBINED-REPLAY1, whose exactness comes from replay-based
equality checks rather than the digest alone.  It preserves the root
statement that K-elimination is conditional on a favorable all-input
constructor.  No root ownership region was edited; PROOF\_MAP/LSPV-5 should
incorporate the sharpened witness-window and hash-quotient guards.
