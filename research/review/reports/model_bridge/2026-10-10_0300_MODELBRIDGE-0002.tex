\section{Selected implication and exact model}
Inputs are canonical CNFs of complete encoded bit length $N$ on one uniform
deterministic random-access machine.  The original input is read-only; every
index, certificate, child buffer, verifier state, replay, cache and ancestor
frame is charged.  Fix constant canonical CNFs $Y,Z$ with
$\SAT(Y)=1$ and $\SAT(Z)=0$.

The selected implication was
\[
 \SAT\in\mathsf P
 \quad\stackrel{?}{\Longrightarrow}\quad
 \text{favorable charged terminal or certified typed epoch}.       \tag{1}
\]
The exact quantifiers for a terminal-token constructor are
\[
 \exists G\,\forall F:\quad
 G(F)\in\{Y,Z\},\qquad \SAT(G(F))=\SAT(F),             \tag{2}
\]
with one simultaneous time--space bound on $G$ for every input.  The
same-realization object is the single machine $G$, including any generator
and verifier it invokes.  The weakest useful theorem is whether (2) is
strictly weaker than deciding SAT in those resources.

\section{Terminal-token theorem}

\begin{theorem}[TERMINAL-TOKEN-EQUIVALENCE1, PROVED/EXACT]
For every simultaneous deterministic resource class $\mathcal R$ closed
under constant extra work, the following are equivalent up to constant
overhead:
\begin{enumerate}
\item SAT has an exact decider in $\mathcal R$;
\item a constructor satisfying (2) lies in $\mathcal R$;
\item an all-input constructor in $\mathcal R$ emits one member of any fixed
finite set of terminal types whose type uniquely determines $\SAT(F)$.
\end{enumerate}
The ordinary-CNF output is constant length, strict shrinkage holds for all
sufficiently large inputs, and every output is already a base case.
\end{theorem}

\begin{proof}
Given a decider, run it and emit $Y$ or $Z$.  Conversely, run the constructor
and return the Boolean value attached to its output type.  Identifying one
member of a fixed finite type set costs only constant additional time and
space.  Exactness on every canonical $F$ proves correctness.  Because the
output is a fixed terminal, it has no unresolved descendant and needs no
recursive re-entry theorem.
\end{proof}

\begin{corollary}[Qualitative all-input transfer, PROVED/EXACT]
Under $\SAT\in\mathsf P$, the semantic output, reduction direction,
arbitrary-SAT coverage, strict encoded-size decrease and descendant closure
are all solved by fixed tokens.  If the assumed decider costs
$N^{K+o(1)}$ time and $N^{S+o(1)}$ space, the constructor retains those
costs.  No specified landing such as
$\operatorname{DTISP}(N^{6/5+o(1)},N^{1/2+o(1)})$ follows.
\end{corollary}

This is not a lower bound: a different SAT algorithm may decide faster.  It
is an interface equivalence.  It prevents resource accounting from treating
the terminal bit as a free consequence of a compact output.

\section{Two-sided certificates and the typed-epoch dichotomy}

\begin{corollary}[CERTIFIED-TYPE-NO-GAIN1, PROVED/EXACT]
Let one total generator output $(b,\pi)$ on every CNF $F$, and let a fixed
verifier accept only pairs for which $b=\SAT(F)$.  The machine that runs the
generator and verifier and returns $b$ is an exact SAT decider.  Consequently
a generator--verifier pair in favorable simultaneous resources would already
be the favorable decider; polynomial certificate length or cheap
verification alone does not construct it.
\end{corollary}

Under $P=NP$ one also has $NP=coNP$, so both SAT and UNSAT possess
polynomially balanced verifiable relations.  Under the project's standard
search convention $FP=FNP$, using prefix-extension queries.  This gives a
polynomial-time generator qualitatively, but leaves its degree, query scale,
encoding work and simultaneous space unspecified.  A bit-by-bit SAT witness
search uses current-scale decision calls before enough variables are fixed;
it therefore retains the unknown solver exponent.  The same issue applies to
an UNSAT proof search.  Existence of a certificate is not its acquisition.

There are only two cases for a typed epoch.  If the type determines the
parent answer, it is terminal and TERMINAL-TOKEN-EQUIVALENCE1 applies.  If it
does not, the epoch retains unresolved SAT semantics and is nonterminal; its
ordinary children must satisfy the actual encoded-size, generation, local
access, descendant-closure, fanout, time and workspace contracts.  Renaming
this nonterminal state as a certificate or type does not discharge them.

\section{Recovered source-probe guard}

satisfiable $F_0$ and $r$ unsatisfiable formulas $F_j$, each differing from

$\Omega(N/\log N)$ bit probes in the declared binary-identifier encoding.

\section{Primary literature and transfer classification}
Buhrman--Torenvliet prove that p-selectivity together with their stated
Turing self-reducibility yields membership in P, and obtain a qualitative
characterization of P \cite{buhrman1996}.  Hemaspaandra--Naik--Ogihara--Selman
separate search-to-decision from self-reducibility and analyze exact stated
reductions \cite{hemaspaandra1996}.  Neither theorem bounds the polynomial
degree of a selector derived from an arbitrary $N^K$ SAT decider, so neither
transfers to the favorable endpoint.  FLMV Theorem 3.1 supplies locally
computable reduction bits in its matched random-access model, and its later
time--space endpoint excludes the conditional landing used by the spine
\cite{flmv}; it does not construct that landing.

Proof-carrying output is an EXACT OBJECT transfer only at the level of a
verifier relation.  The cryptographic special-soundness/collapse-binding
lesson is an ANALOGY/CANDIDATE until two conflicting openings yield a
construction-specific unconditional witness and its discovery is charged.
A finite hash or random oracle is a FAILED TRANSFER to exact SAT semantics:
collisions or assumptions remain.  No cryptographic assumption is used.

\section{Bounded tests and hostile controls}
Both Python invocations were limited by a 25-second cooperative alarm and a
30-second subprocess timeout.

The recovered MB4 harness checked 90 formulas through $r=12$: every base was
satisfiable, every single switch flip was unsatisfiable, every pair differed
at exactly the declared slot, and all checks passed in 0.039 seconds.

The new deterministic terminal-token harness exhaustively tested 5,489 CNFs
on four variables with zero through three distinct non-tautological unit or
binary clauses.  It found 5,317 SAT and 172 UNSAT formulas; all fixed-token
semantics passed.  A SAT-witness-only interface source-carried exactly the
172 UNSAT cases.  It also passed 396 tautological-padding checks and 32
disjoint-product checks in 0.177 seconds.  Exact symbolic ledgers for
$K=1,\ldots,8$ confirmed that a current-scale call has exponent $K$ while
the token output exponent is zero but its generation exponent remains $K$.

Easy Horn/unit families, padding, independent products, source carry,
DELAY, a semantic oracle and algebraic replacement do not alter the theorem.
An oracle can supply the type bit at unit oracle cost, but de-oracling restores
the oracle/solver cost.  Algebraic representation can verify or simplify
particular instances; it does not generate the all-input terminal type.
These finite checks support implementation correctness only and are not
asymptotic lower bounds.
