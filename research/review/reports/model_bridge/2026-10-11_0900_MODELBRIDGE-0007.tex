\section{Exact clean core and universal target}

Let $\mathcal H_{2,2}$ be the canonical proper Monotone
$3$-SAT-$(2,2)$ language: every clause contains three distinct variables and
one polarity, clauses are duplicate-free, and every variable occurs exactly
twice positively and twice negatively.  Canonical encoding writes
self-delimiting $n,m$, then lexicographically ordered clauses, each with three
sign bits and three $\lceil\log_2(n+1)\rceil$-bit variable identifiers.  For
$F\in\mathcal H_{2,2}$, $3m=4n$ and the encoded bit length is
\[
  N=|\operatorname{enc}(F)|=\Theta(n\log n).
\]
The language is NP-complete by D\"ocker's reduction, but this report does not
use that theorem as a runtime lower bound.

The final lower-bound target is
\[
\tag{UCORE-TIME1}
\forall A\ \forall d\in\mathbb N\ \forall N_0\ \exists F\in\mathcal H_{2,2}:
\begin{cases}
A\text{ is a total uniform deterministic exact }\SAT\text{ decider},\\
|\operatorname{enc}(F)|\ge N_0,\\
T_A(\operatorname{enc}(F))>|\operatorname{enc}(F)|^d.
\end{cases}
\]
This is \OPEN and is separation-strength.  No premise below assumes it.

For a partial assignment $\rho\in\{*,0,1\}^{V(F)}$, define the pinning
service
\[
 S_F(\rho)=\mathbf 1[F\!\upharpoonright_\rho\text{ is satisfiable}],
 \qquad \rho_\varnothing=(*,\ldots,*).
 \tag{1}
\]
The distinguished empty coordinate satisfies
$S_F(\rho_\varnothing)=\mathbf 1[F\in\SAT]$.

\section{Declared preprocessing/query model}

A service realization is a tuple
\[
 (C,Q,P,S,w,t_q,\varepsilon,\xi,\mathcal O),                 \tag{2}
\]
where $C$ preprocesses $\operatorname{enc}(F)$ into retained data $D$;
$P$ is preprocessing time; $S$ is peak writable/retained space; $w$ is word
size; $Q$ answers one encoded $\rho$ in time $t_q$; $\varepsilon$ is error;
$\xi$ declares whether the original source remains readable; and
$\mathcal O$ declares whether $Q$ may invoke the supplied decider or an
oracle.  The output contract here is one answer bit per requested query, not
the entire service vector.

SAME\_REALIZATION charges parsing, source reads or copying, construction and
writing of $D$, retained data, residual construction or virtual access,
every decider/oracle call, query output, word width, and peak writable space
to the same execution.  A phrase such as ``supports the service'' has no
mathematical content until (2) is fixed.

\section{Exact theorem}

Let $L\subseteq\{0,1\}^*$, let $R(x,q)$ be a total uniform compiler, and let
\[
 S_x(q)=\mathbf 1[R(x,q)\in L].                              \tag{3}
\]
Assume a distinguished query $q_\varnothing$ satisfies
$R(x,q_\varnothing)=x$ (or a linear-time identical re-encoding).  Let $A$
decide $L$ in time $T_A$ and writable space $W_A$.

\begin{theorem}[\texttt{SOURCEBACKED-EMPTYQUERY-TRILEMMA1}]
The following three statements hold uniformly.

\begin{description}[leftmargin=3.4cm,style=nextline]
\item[Source-backed realization.]
There is an exact service realization with retained description
$D=(x,\ulcorner A\urcorner,\ulcorner R\urcorner)$ of length
$|x|+O_A(1)+O_R(1)$ and
\[
 t_q(x,q)\le T_R(|x|+|q|)+T_A(|R(x,q)|)+O(1).               \tag{4}
\]
If the source remains on a declared read-only tape, $D$ may instead contain
a handle and fixed code; all source access remains charged.  For an
$N^{K+o(1)}$ decider, the empty query retains exponent $K$.

\item[Empty-query reversal.]
Every exact compiler/evaluator pair $(C,Q)$ for (3) yields a decider
\[
 B(x)=Q(C(x),q_\varnothing).                                 \tag{5}
\]
If preprocessing takes $P(N)$ time and the empty query takes $t_\varnothing(N)$
time, then
\[
 T_B(N)\le P(N)+t_\varnothing(N)+O(1),                       \tag{6}
\]
with peak space the maximum of the fully charged preprocessing, retained,
source-access, and query spaces.  In exponent notation,
$P=N^{p+o(1)}$, $t_\varnothing=N^{q+o(1)}$ gives time exponent
$\max\{p,q\}$, not a free resource.

\item[Decision-bit-only impossibility.]
Let $\mathcal Q$ contain distinct $q_\varnothing,q_1$.  There do not exist
functions $c:\{0,1\}\to D$ and $e:D\times\mathcal Q\to\{0,1\}$ such that
\[
 e(c(s(q_\varnothing)),q)=s(q)
 \quad\text{for every table }s\in\{0,1\}^{\mathcal Q}
 \text{ and every }q\in\mathcal Q.                          \tag{7}
\]
Thus a black-box compiler receiving only the source decision bit cannot
recover an unrestricted multi-query service.
\end{description}
\end{theorem}

\begin{proof}
For the first statement, retain $x$ and the fixed programs.  On query $q$,
compute $R(x,q)$ and run $A$; this proves (4), including the required
residual buffer or a separately justified streamed accessor.  At
$q_\varnothing$ this is exactly the original decision computation up to the
declared re-encoding, so its exponent is not eliminated.

For the second statement, execute the preprocessing and then request the
distinguished coordinate.  Correctness of the service gives
$Q(C(x),q_\varnothing)=S_x(q_\varnothing)=\mathbf 1[x\in L]$.
Sequential times add and simultaneous peak spaces take the charged maximum,
which proves (5)--(6).

For the third statement, choose two tables $s,s'$ with
$s(q_\varnothing)=s'(q_\varnothing)$ but $s(q_1)\ne s'(q_1)$.  They produce
the same retained object $c(s(q_\varnothing))$, so the deterministic
evaluator must return the same bit at $q_1$, contradicting one of the two
required answers.
\end{proof}

\begin{corollary}[Forced-data-structure trilemma]
For the SAT pinning service (1), every proposed universal bridge falls into
one of the following classes.
\begin{enumerate}[leftmargin=*]
\item If the representation class includes source plus a program, the
compiler exists trivially, but the query cost retains $K$.
\item If preprocessing and empty-query evaluation have a favorable
$K$-independent same-model cost, their composition is already a favorable SAT
algorithm.  The proof burden is the construction and endpoint, not service
cardinality.
\item If the representation class excludes source-backed replay or forces a
particular table, circuit, separator, message, or cell layout, a separate
representation-covariant compiler from every SAT decider is required.
Decision-bit black-box access alone cannot supply it; SAT-specific white-box
source use remains an \OPEN possibility.
\end{enumerate}
\end{corollary}

The corollary does not prove that every restricted compiler is impossible.
It proves that ``forced data structure'' is not, without that missing
compiler, an intermediate consequence of being a one-bit SAT decider.

\section{$\mathsf P=\mathsf{NP}$ audit and charged consequences}

Assume only inside this paragraph that $\mathsf P=\mathsf{NP}$, and fix a
total uniform exact SAT decider $A$ with time $N^{K+o(1)}$.  The source-backed
realization has linear description/preprocessing and query time
$N^{K+o(1)}$ at the empty coordinate.  This is consistent with the
hypothesis and yields no contradiction.  If a new compiler instead has
$P=N^{p+o(1)}$ and empty-query time $N^{q+o(1)}$, (6) gives a SAT decider of
time $N^{\max(p,q)+o(1)}$ with the jointly charged space from the same
realization.  A contradiction follows only if those exact simultaneous
bounds enter an unconditional theorem such as the Fortnow--Lipton--van
Melkebeek--Viglas random-access time--space forbidden region.  Merely being
polynomial, compressed, causal, or predecision is not enough.

No assumption such as $\mathsf{coNP}\not\subseteq\mathsf{NP/poly}$ may be
used here: under $\mathsf P=\mathsf{NP}$, one has
$\mathsf{coNP}=\mathsf P\subseteq\mathsf{NP/poly}$.

\section{Hostile controls, representation, and one-bit output}

\begin{description}[leftmargin=3.2cm,style=nextline]
\item[Affine/Horn/2-SAT.]  Their services can be evaluated by Gaussian
elimination, propagation, or implication graphs.  A fixed service syntax does
not block semantic shortcuts.
\item[Paired high-treewidth core.]  RT-0007 evaluates its entire pinning
service by lower-bounded circulation.  High treewidth and many coordinates do
not escape the trilemma.
\item[Alternative encodings.]  Renaming, complementation, clause order,
COPY, DEAD, INTERP, padding, and compact graph/program encodings change the
decoder/access ledger, not (1) or the empty-query identity.
\item[DIRECT/RECOMP.]  DIRECT returns only the source bit.  RECOMP retains
the source and reruns the chosen evaluator per query.  Neither materializes a
service table.
\item[One-bit output.]  The original contract requests one bit.  Full-table
output size is a lower bound for a different function problem.
\item[Memory/communication.]  Retained bits, cell probes, protocol messages,
or separator states lower-bound only their declared models until a
same-execution compiler is proved.
\end{description}

\section{Primary literature and transfer audit}

Chakraborty--Kamma--Larsen prove the tradeoff
$tr=\widetilde\Omega(n^3)$ for succinct Boolean matrix--vector
multiplication in a cell-probe model with an explicitly read-only matrix and
$r$ retained side bits.  This is a genuine model theorem, not a statement
that an arbitrary one-shot SAT execution uses that layout.  Cadoli--Donini--
Liberatore--Schaerf's compilability framework likewise formalizes a fixed
offline part and a varying online part; it does not manufacture that split
inside every decision algorithm.  Dell--van Melkebeek give an exact
oracle-communication/sparsification lower bound conditional on
$\mathsf{coNP}\not\subseteq\mathsf{NP/poly}$, unavailable in the
$\mathsf P=\mathsf{NP}$ contradiction world.  FLMV supply an unconditional
endpoint only for their declared random-access simultaneous time/space model.

\begin{description}[leftmargin=3.3cm,style=nextline]
\item[THEOREM TRANSFER.]  Once tuple (2) exactly matches a cell-probe or
compilability theorem, its bound applies to that compiled object.
\item[ANALOGY / CANDIDATE.]  Knowledge compilation, memory hierarchy, VLSI,
and static data structures suggest candidate restricted interfaces.
\item[FAILED TRANSFER.]  Applying their lower bounds to arbitrary uniform SAT
deciders without RESTRICTED-DS-COMPILER1 violates SAME\_REALIZATION.

\section{Barrier and post-quantum audit}

All three theorem clauses relativize when $A$ and $Q$ receive the same fixed
oracle.  Baker--Gill--Solovay therefore prevents this classification from
being the final separation hinge.  Algebraic-oracle access only strengthens
the source-backed evaluator; no nonalgebrizing step appears.  No constructive
large circuit property is used, so Natural Proofs is not directly triggered.

Schur powers, quadratic-relation ranks, Hilbert functions, syzygies, graded
Betti numbers, and collision entropy are \textbf{FAILED TRANSFER} here unless
a compiler first forces the corresponding code/algebra object into the same
execution.  The source-plus-program realization is precisely a compact
algorithmic representation that such invariants must defeat.  LWE-style
black-box reduction architecture and collision extraction are
\textbf{ANALOGY/CANDIDATE}; the decision-bit theorem (7) shows why additional
source queries or structure are necessary.  Cryptographic hardness and
random-oracle binding remain inadmissible.
