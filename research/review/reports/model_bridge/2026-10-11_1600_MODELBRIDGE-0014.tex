\section*{Executive result}

This run isolates the weakest auditable interface currently known to bridge a
locally generated bounded-fanout circuit CNF to the tagged second leg of
MODELBRIDGE-0013.  For any fixed finite gate-to-3CNF template library,
local gate type/child access together with a local \emph{parent-port
enumerator} suffices to compute the exact dense sign-specific occurrence tag
of a requested literal in polylogarithmic time and logarithmic writable
space.  This is \status{Proved/Exact} at its declared interface.

The theorem does not close the concrete Cook bridge.  Jahanjou--Miles--Viola
(JMV) state a local clause generator and, in the circuit construction used by
it, local access to a gate's children.  Their theorem does not state a local
enumerator for the parents of a named gate.  Forward child access does not
imply parent access: a fanout-one permutation-oracle circuit gives one-query
forward access while deterministic inversion needs $n-1$ queries in the
worst case.  This is a model-scoped separation, not a lower bound on the
concrete JMV function and not a proof that parent ports are necessary.

Thus \texttt{JMV-PARENT-PORT1}, exact local normalization to tagged Monotone
$3$-SAT-$(3,3)$, \texttt{LOCAL-COOK-TAGGED-M33-1}, and every arbitrary-decider
transfer remain \status{Open}.  P versus NP remains \status{Open}.

\section{Exact claim card and quantifiers}

Fix constants $\Delta,d,c$ and a finite Boolean gate alphabet $\Gamma$.  For
each $\gamma\in\Gamma$, fix at most $c$ proper 3-CNF template clauses, with
each literal position naming either the output gate or one of at most $d$
ordered children.  Let $C$ be an explicitly addressed acyclic circuit with
fanout at most $\Delta$.  Assume uniform deterministic accessors which, on
an $m$-bit circuit description, provide:
\begin{enumerate}[leftmargin=1.5em]
\item the type and ordered children $\child(g,b)$ of a named gate $g$; and
\item $\PPE(u,t)$, the $t$th distinct pair $(p,b)$ satisfying
      $\child(p,b)=u$, or $\bot$, in canonical order, for
      $1\le t\le\Delta$.
\end{enumerate}
Both accessors run in $(\log m)^{O(1)}$ time and $O(\log m)$ writable space.
Clause addresses are triples $(g,r,s)$: owner gate, template row, literal
slot.  Any fixed output-assertion clauses are treated as an additional
constant-size template with a locally recognizable owner.

\paragraph{PARENT-PORT-TO-TAG1.}
For every such fixed library and every such circuit, there is a uniform
deterministic transducer which, from a valid literal address $(g,r,s)$,
outputs its dense sign-specific occurrence tag
\[
  \operatorname{tag}_C(g,r,s)
  =1+\bigl|\{a<a_0:\operatorname{lit}(a)
                     =\operatorname{lit}(a_0)\}\bigr|,
  \qquad a_0=(g,r,s),
\]
where $<$ is the canonical clause/slot order and equality of literals
includes variable and sign.  Its time is $(\log m)^{O(1)}$ and its writable
space is $O(\log m)$.  The same execution uses the stated child accessor,
the stated parent-port accessor, and a constant-size template table; it does
not materialize a global occurrence index.

\paragraph{Proof.}
Let the requested literal name circuit variable $u$ with sign $\sigma$.
Every template occurrence of $u$ belongs either to the template owned by $u$
itself, to the template of a parent $p$ in whose child slot $b$ the value
$u$ occurs, or to a fixed terminal assertion template.  The parent-port
enumerator lists all and only the second class, without duplication.  There
are at most $1+\Delta+O(1)$ relevant owners.  For each owner the fixed
template table and child accessor enumerate a constant number of literal
addresses; discard those whose variable/sign are not $(u,\sigma)$, sort the
remaining constant-size address list, and return the rank of $(g,r,s)$.
Fanout, arity, and the library are constant, so the number of stored
addresses is constant; each address uses $O(\log m)$ bits.  Accessor time and
space therefore dominate.  This proves the claim.\hfill$\square$

This theorem is a sufficient-interface theorem.  It does not assert that a
tag cannot be generated by a different construction-specific method without
parent enumeration.

\section{Why child locality does not entail parent locality}

Consider gates $p_1,\ldots,p_n$ and $v_1,\ldots,v_n$ with the sole wire out
of $p_i$ entering $v_{\pi(i)}$, for a black-box permutation $\pi$.  A forward
child query for $p_i$ uses one oracle query.  To return the parent of a fixed
$v_j$, however, a deterministic algorithm must find $\pi^{-1}(j)$.  After
fewer than $n-1$ negative queries, two unqueried indices can still be swapped
while preserving the transcript, so the answer is not fixed.  Hence the
worst-case deterministic query complexity is $n-1$.

The separation holds at fanout one.  It proves only
\[
  \text{local forward child interface}\not\Rightarrow
  \text{local parent-port interface}
\]
in the declared oracle model.  The concrete JMV circuit may contain routing
regularity from which parents can be derived; establishing that requires an
explicit construction-level theorem.  Conversely, occurrence tags could be
native in the clause address and bypass parent enumeration, as RT-0013
emphasizes.  Accordingly, ``JMV clause locality automatically gives parent
ports'' is \status{Falsified/Retired} as an unqualified interface inference,
while \texttt{JMV-PARENT-PORT1} remains \status{Open}.

\section{Primary-literature and barrier-transfer preflight}

The two blocking obstacles were: (i) the exact direction of local graph
access in JMV, and (ii) whether a sufficient interface can be realized
without the linear materialized index ruled out by SYNTHESIS-0009.  The
primary sources checked were Jahanjou--Miles--Viola, \emph{Local reductions},
\url{https://eccc.weizmann.ac.il/report/2013/118/}, especially its local
3-CNF theorem and the gate/type/children clause generator in the proof; and
Fortnow--Lipton--van Melkebeek--Viglas, \emph{Time-space lower bounds for
satisfiability}, \url{https://lance.fortnow.com/papers/files/tst.pdf}, for the
random-access endpoint model.  JMV's published interface gives the addressed
clause from its address and computes a gate's children; no parent-port
enumerator theorem was found.  FLMV can be invoked only after one actual
realization has both required time and space bounds.

The exact transfer in this report is elementary bounded-degree graph
incidence: bidirectional local adjacency plus fixed local templates gives
local occurrence ranks.  Bidirectional routing and inverse adjacency from
VLSI/switching-network design are \status{Useful Structural Analogy Requiring
A New Transfer Theorem} until the exact JMV labels are shown to support
them.  Succinct rank/select and offline inverse indexes are also analogy only:
SYNTHESIS-0009 correctly charges their materialization.  No control-theory,
coding-theory, proof-complexity, or communication theorem transfers to the
missing inverse accessor merely because it uses similar language.

The result relativizes and does not cross the Baker--Gill--Solovay barrier.
It is combinatorial and does not evade algebrization.  It defines no large,
constructive circuit property of the Razborov--Rudich kind.  Nonuniform
advice containing all parent ports changes the uniform, charged model.

\section{Bounded reproducible experiment}

The script
\texttt{experiments/review/parent\_port\_occurrence\_audit.py} generated 512
bounded-fanout circuits at 8, 16, 32, and 64 gates from seed
\texttt{202610111600}.  Across 15,360 gates, 34,718 clauses, 104,154 literal
records, and 19,167 parent ports, the local parent-port construction matched
an independent global stable-sort reference exactly.  All 512 variable
renaming and clause-slot reversal wrappers preserved dense-tag validity.
There were zero assertion failures in 1.22 seconds.

The hostile forward-only control tested 128 permutations.  Forward child
lookup used one recorded probe; the constructed inverse targets required
$7,15,31,63$ negative probes for $n=8,16,32,64$, respectively, before the
last answer followed by elimination.  This validates the finite harness and
the oracle distinction; the asymptotic lower bound is the symbolic adversary
argument above.  Script SHA-256 and result SHA-256 are recorded in the
verification log.  The computation is \status{Computational}, not evidence
that the concrete JMV port theorem holds.

\section{Semantic compatibility and arbitrary algorithms}

For completeness, let $X,Y$ partition a formula's variables and define the
semantic compatibility relation
\[
 H_F(\alpha,\beta)=1
 \quad\Longleftrightarrow\quad
 \alpha\cup\beta\text{ extends to a satisfying assignment of }F.
\]
The present tagger is external reduction infrastructure.  It neither
computes $H_F$ nor proves that an arbitrary uniform deterministic SAT decider
materializes $H_F$, a row, a rank, an occurrence index, a parent map, or any
other chosen representation.  A one-bit decider is required to output only
$\operatorname{SAT}(F)$.

Assuming SAT is in P yields polynomial search-to-decision and permits the
external reductions to call that decider, but it does not force its internal
states to expose ports.  COPY, DELAY, recomputation, interpretation, padding,
and decide-then-emit wrappers preserve the decision language while changing
traces and representations.  Horn, 2SAT, affine/Tseitin Gaussian
elimination, bounded-treewidth instances, independent products, redundant
clauses, and alternative encodings may compute the one output bit without
using this interface.  These controls therefore block every inference from
semantic-state count or tag cardinality to arbitrary-machine time, memory,
or communication.

\section{SAME\_REALIZATION and endpoint audit}

If \texttt{JMV-PARENT-PORT1} were proved, the child accessor, parent-port
accessor, tagger, first-leg clause generator, fixed MODELBRIDGE-0013 second
leg, and terminal SAT computation would still have to be composed in one
uniform random-access realization.  Setup, every accessor call, clause
normalization, reconstruction, retained ancestors, transient addresses, and
peak workspace must be charged.  Time from a native-port implementation
cannot be combined with space from a materialized-index implementation.
Arbitrary polynomial solver exponents cannot be normalized away.  No such
full ledger is proved here.

\section{Post-quantum technique ledger}

The LWE lesson of external, construction-defined reduction infrastructure is
an \status{Analogy/Candidate}: it motivates proving a black-box external
accessor instead of forcing a solver to materialize one.  It supplies no NP
worst-case/average-case theorem here.  Schur-square distinguishers,
quadratic-relation rank, Hilbert functions/syzygies, collision entropy, and
special-soundness extraction are \status{Failed Transfer} for the current
parent-port obstacle: no exact object map or unconditional theorem yields the
needed inverse adjacency.  Hash/random-oracle or cryptographic binding
assumptions are inadmissible.  Any hidden algebraic regularity in the JMV
routing labels may instead make port generation easier and should be tested
algorithmically.
