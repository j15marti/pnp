\section{Family, encoding, and semantic compatibility}

For $a=(a_1,a_2,a_3)\in\{0,1\}^3$, let
\[
 C_a=\bigvee_{i=1}^3 \ell_{i,a},\qquad
 \ell_{i,a}=\begin{cases}x_i,&a_i=0,\\ \neg x_i,&a_i=1.\end{cases}
\]
Then $C_a$ is the unique proper clause falsified by $a$.  For a mask
$m\in\{0,1\}^8$, define
\[
 F_m=\bigwedge_{a:m_a=1}C_a.                              \tag{1}
\]
For a split $U\mathbin{\dot\cup}V=\{x_1,x_2,x_3\}$, define the exact
semantic compatibility matrix
\[
 H(F_m)(u,v)=\mathbf 1[(u,v)\models F_m].                 \tag{2}
\]
This is a $2^{|U|}\times2^{|V|}$ matrix with eight entries.  It is the
complete solution relation, not a pairwise surrogate.

For $b\ge1$, use disjoint triples $X_j$ and masks $m^{(j)}$, and put
\[
 F_{\mathbf m}=\bigwedge_{j=1}^b F_{m^{(j)}}(X_j).         \tag{3}
\]
The block-mask promise encoding has length
$N_{\rm mask}=8b+O(\log b)$.  In a canonical ordinary-CNF encoding with a
declared $3b$-variable header, sorted clause records, and
$\lceil\log_2(3b+1)\rceil$-bit identifiers, the maximum length is
$N_{\rm cnf}=\Theta(b\log b)$.  The theorem charges parsing, the header,
missing-clause detection, counters, and output.  This is a proper-3CNF
hostile-control family, not the balanced $\mathcal H_{2,2}$ target: only a
complete block has four positive and four negative occurrences per variable.

\section{Exact semantic quotient theorem}

\begin{theorem}[\texttt{FULLCUBE-DECISION-QUOTIENT1}]
For every $m\in\{0,1\}^8$,
\[
 \operatorname{Sol}(F_m)=\{a:m_a=0\},\qquad
 \mathbf 1[F_m\in\SAT]=\bigvee_a(1-m_a).                 \tag{4}
\]
Consequently $m\mapsto H(F_m)$ is a bijection onto all $256$ Boolean
relations on three variables, whereas the SAT quotient has exactly two
fibers of sizes $255$ and $1$.

For (3),
\[
 \operatorname{Sol}(F_{\mathbf m})=
 \prod_{j=1}^b\{a:m^{(j)}_a=0\},\qquad
 \mathbf 1[F_{\mathbf m}\in\SAT]
 =\bigwedge_{j=1}^b\bigvee_a(1-m^{(j)}_a).                \tag{5}
\]
There are $256^b$ distinct global solution relations.  On the block-mask
encoding, deterministic query complexity of the decision bit is exactly
$8b$ in the worst case.  A block-major reduced ordered binary decision
diagram has exactly $8b$ nonterminal nodes.  A canonical stream decider uses
$O(b)$ word operations and $O(\log b)$ writable bits; on ordinary clause
records its fully charged bit cost is $O(N_{\rm cnf})$.
\end{theorem}

\begin{proof}
Clause $C_a$ eliminates exactly assignment $a$, so (4) follows entry by
entry.  Disjoint variables make solution sets multiply, proving (5) and
injectivity of the $b$-block relation map.

For the upper bounds, keep one eight-bit presence mask for the current block
and reject as soon as some completed block is all ones; otherwise accept
after the last block.  The block-major OBDD is the corresponding chain of
eight tests per block: within a block, a zero edge proves that block
satisfiable and jumps to the next block, while the all-one path reaches the
rejecting terminal.  At each level the two residual functions differ and
successive suffix functions are distinct, so reduction removes no one of
the $8b$ nodes.

For the query lower bound, an adversary answers one on queried presence bits
while retaining one unqueried zero in each unfinished block.  A correct SAT
answer requires finding a zero in every block, and the adversary can make it
the last queried bit in each block.  Hence some input requires $8b$ probes.
This is a tight linear input-reading statement, not a superlinear SAT lower
bound.
\end{proof}

Pairwise clause compatibility is maximally misleading here: every two
distinct $C_a,C_{a'}$ are jointly satisfied by six assignments, so their
compatibility graph is complete, but all eight clauses are jointly
inconsistent.  Full $H(F)$ records the missing global information, yet (4)
shows that a one-bit decider only needs its OR quotient.
