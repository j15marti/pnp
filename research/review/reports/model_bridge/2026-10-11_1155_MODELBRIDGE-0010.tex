\begin{abstract}
RT-0009 leaves two repairs for fixed-prefix failure: statically normalize every
supplied solver, or construct a fractional successor from the source alone.
This report attacks the first repair.  Three exact facts exhaust its most
natural readings.  A language-generic compiler that maps every polynomial-time
decider to one fixed time exponent contradicts the deterministic time
hierarchy.  A transparent analyzer that must decide whether a marked wrapper
block is reachable is undecidable, even on polynomial-time deciders of one
fixed language whenever that language has a polynomial-time decider.  Finally,
under $\SAT\in\mathsf P$, a SAT-specific compiler that maps every polynomial
SAT implementation into a favorable resource class exists if and only if SAT
already has a decider in that class: the reverse direction is the constant
replacement compiler.  Thus static normalization is either too generic,
non-total as exact program analysis, or endpoint-equivalent.  This does not
rule out a new source-only fractional successor.  A bounded hostile audit
passed $84{,}898$ checks.  P versus NP remains open.
\end{abstract}

\section{Claim card, clean core, and semantic object}

Let $\Htwo$ be the duplicate-free proper Monotone $3$SAT-$(2,2)$ family:
every clause has three distinct variables and one sign, and each variable
occurs twice positively and twice negatively.  Then $m=4n/3$ and the declared
canonical indexed encoding has length $N=\Theta(n\log n)$.  Define the full
semantic compatibility object by
\[
 H_F(\alpha)=1\quad\Longleftrightarrow\quad \alpha\models F,
 \qquad \alpha\in\{0,1\}^{n}.                         \tag{1}
\]
The one-bit decision is only $\bigvee_\alpha H_F(\alpha)$.  No premise says
that an implementation materializes (1).

The separation-strength target remains
\[
 \forall A\ \forall d\ \forall N_0\ \exists F\in\Htwo:\quad
 |\operatorname{enc}(F)|\ge N_0
 \ \land\ T_A(F)>|\operatorname{enc}(F)|^d,             \tag{2}
\]
where $A$ ranges over total correct uniform deterministic SAT deciders.
Statement (2) is \OPEN and is not used below.

The attacked bridge was:
\[
 \text{arbitrary polynomial SAT implementation}
 \xrightarrow{\text{static normalization}}
 \text{one favorable fixed time--space realization}.     \tag{3}
\]
The SAME\_REALIZATION contains the supplied clocked code, source encoding,
normalizer, normalized code or interpreted run, all static analysis,
validation, source access, output, and workspace.  If normalization occurs
once on a fixed program, its finite compile cost is a constant in input length;
if it runs per input, that work is charged to the promised resource bound.

\section{Generic fixed-exponent normalization is impossible}

\begin{definition}[Generic normalizer]
Fix an integer $r\ge1$.  A generic fixed-exponent normalizer is a total
computable map $C_r$ on descriptions of clocked deterministic polynomial-time
deciders such that
\[
 L(C_r(M))=L(M)
 \quad\text{and}\quad
 T_{C_r(M)}(N)=O(N^r)                                  \tag{4}
\]
for every such $M$.  Constants may depend on $M$.
\end{definition}

\begin{theorem}[\texttt{GENERIC-FIXED-EXP-NORMALIZER1}]
No generic fixed-exponent normalizer exists.
\end{theorem}

\begin{proof}
If $C_r$ existed, every language in $\mathsf P$ would have a deterministic
$O(N^r)$ decider.  The deterministic time hierarchy gives a language
\[
 L_r\in\mathsf{DTIME}(N^{r+2})\setminus\mathsf{DTIME}(N^r), \tag{5}
\]
using the standard constructible-time separation (the two-power gap safely
absorbs logarithmic simulation overhead).  A clocked decider for $L_r$ is in
the domain of $C_r$, while (4) contradicts (5).
\end{proof}

This theorem does not specialize to SAT: all correct SAT implementations
decide one language, whereas the contradiction uses all polynomial-time
languages.  It exactly blocks the proposal that wrapper removal is a
language-independent compiler principle.

\section{Exact transparent reachability is undecidable}

\begin{theorem}[\texttt{PROMISED-SHELL-REACHABILITY1}]
Let $L$ be any language with a fixed deterministic polynomial-time decider
$B$.  There is no total computable analyzer that, given code promised to be a
polynomial-time decider of $L$, decides whether a designated marked block is
reachable on at least one input.
\end{theorem}

\begin{proof}
For an arbitrary Turing machine $E$, construct $W_E$.  On an input $x$ of
length $N$, it simulates $E$ on the blank input for $N$ steps.  If $E$ has
halted, it executes the designated marked block.  It then runs $B(x)$ and
returns that bit in either case.  Universal simulation of $N$ steps has
polynomial overhead, so every $W_E$ is a polynomial-time decider of exactly
$L$.  The marked block is reachable on some input iff $E$ eventually halts.
A total analyzer on this promise would therefore decide the halting problem.
\end{proof}

Under the counterfactual $\SAT\in\mathsf P$, take $L=\SAT$ and the theorem
applies entirely inside the promised set of correct polynomial SAT deciders.
This closes exact reachability classification, not all semantics-preserving
rewriting.  A normalizer may conservatively leave wrappers in place, use
proof-carrying annotations, or replace the entire program.  The first is not
universal; the third is handled next.

\section{SAT-specific normalization is endpoint-equivalent}

Let $\mathcal R$ be any fixed extensional machine-resource class, for example
the deterministic random-access time--space pair required by a declared FLMV
endpoint.  Membership includes all compilation, interpretation, source
access, output, and workspace costs of the resulting one-machine realization.

\begin{theorem}[\texttt{SAT-NORMALIZER-ENDPOINT-EQUIV1}]
Assume $\SAT\in\mathsf P$, and let $\mathcal S$ be the nonempty set of codes
of total correct uniform polynomial-time SAT deciders.  The following are
equivalent:
\begin{enumerate}[label=(\roman*)]
\item $\SAT$ has a decider $B\in\mathcal R$;
\item there is a computable compiler $C$ such that for every $A\in\mathcal S$,
$C(A)$ decides SAT and belongs to $\mathcal R$.
\end{enumerate}
\end{theorem}

\begin{proof}
For (ii)$\Rightarrow$(i), choose any $A_0\in\mathcal S$ and take $C(A_0)$.
For (i)$\Rightarrow$(ii), define the constant compiler $C(A)=B$ for every
input code $A$.  It is computable, implementation-invariant, deletes every
DEAD/COPY/DELAY/INTERP/RECOMP shell by replacement, and has exactly the
resource bounds of $B$.
\end{proof}

Thus covariance, canonical output, and perfect wrapper immunity do not make
(3) an intermediate theorem.  When $\mathcal R$ is the forbidden endpoint,
proving (ii) under $\SAT\in\mathsf P$ already proves the needed endpoint
algorithm.  Requiring the compiler to ``use'' $A$ does not help without a
resource-bearing notion of use: a polynomial guard can make a code-dependent
bit causally present while $B$ still supplies the decision, and running $A$
to completion imports its arbitrary exponent $K$.

\begin{corollary}[Static-normalizer trilemma]
A proposed universal static normalizer must choose among:
\begin{enumerate}[label=(\alph*)]
\item language-generic fixed-resource normalization, contradicted by Theorem 1;
\item exact transparent reachability analysis, contradicted by Theorem 2;
\item SAT-specific replacement, equivalent by Theorem 3 to the desired
favorable SAT endpoint itself.
\end{enumerate}
Partial or proof-carrying normalizers remain legitimate restricted tools but
do not establish the all-decider bridge.
\end{corollary}

\section{Literature, transfer, and barrier audit}

Hartmanis and Stearns introduced machine time hierarchies; the modern
constructible-time form supplies (5).  Rice's theorem is consistent with the
program-analysis obstruction, but Theorem 2 uses a direct promised-domain
halting reduction and does not overextend Rice to a polynomial-time promise.
Blum's axiomatic complexity theory warns that complexity attaches to indexed
programs and measures; no speedup theorem is needed here.  FLMV supplies a
genuine unconditional SAT time--space exclusion only after one fully charged
random-access realization reaches its hypotheses.

Theorems 1--3 relativize in the relevant sense: fix an oracle throughout the
machines, hierarchy, and compiler.  They therefore expose a failed bridge and
do not cross Baker--Gill--Solovay.  Algebraic-oracle access does not invalidate
the trilemma and does not create the missing source-only successor.  No broad
constructive circuit property is used, so Natural Proofs is not the immediate
obstruction.  Aaronson--Wigderson remains a warning that nonrelativization
alone would not suffice.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{THEOREM TRANSFER.}
The deterministic time hierarchy transfers to the declared generic compiler;
the direct halting reduction transfers to exact marked-block reachability;
FLMV transfers only after its simultaneous machine-model premises hold.
\item[] \textbf{ANALOGY / CANDIDATE.}
Proof-carrying code, certified optimization, abstract interpretation, and
compiler refinement can safely remove annotated shells.  A new theorem would
need every polynomial SAT solver to carry or admit such certificates with
all production and checking costs bounded.
\item[] \textbf{FAILED TRANSFER.}
Dead-code elimination, common compiler optimizations, circuit canonicalization,
and fixed branching-program normal forms do not yield unrestricted semantic
normalization of arbitrary Turing/RAM programs.
\end{description}

PQC-style Schur squares, relation-rank filtrations, Hilbert functions, and
syzygies are source-side invariants and do not decide program reachability or
provide a favorable SAT endpoint.  LWE-style reductions and special-soundness
extraction remain analogies requiring an unconditional cost-preserving bridge;
cryptographic assumptions are inadmissible.

\section{Smallest repair and next target}

Retain only the second option in RT-0009's repair: a source-defined,
$K$-independent fractional successor with no dependence on normalizing the
supplied implementation.  Its exact obligation is
\[
 \SAT(F)=\mathcal B\bigl(\SAT(G_1),\ldots,\SAT(G_q)\bigr), \tag{6}
\]
where acquisition, failed routes, child writing or bit access, replay,
reconstruction, ancestor state, output, and peak workspace are charged in one
realization; all unresolved descendants satisfy the same contract; and the
aggregate ledger reaches a model-matched unconditional endpoint.  SYNTHESIS-
0005 rules out full Shannon enumeration as this rule.  The next bridge target
is therefore one non-Shannon source identity, not another solver-code
normalizer.
