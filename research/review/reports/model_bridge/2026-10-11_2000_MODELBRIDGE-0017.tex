\begin{abstract}
LB-0016 leaves a pruned source-dependent restriction pass as the surviving
alternative to exponential all-branch emission.  This run proves the exact
boundary for the weakest total version of that repair.  A uniform polynomial
machine that, on every nonterminal CNF $F$, outputs one literal one-variable
restriction $F\upharpoonright_{x=b}$ with
$\SAT(F)=\SAT(F\upharpoonright_{x=b})$ can be iterated to decide SAT.
Conversely, if SAT is in P, then one call to any fixed polynomial SAT decider
on $F\upharpoonright_{x=0}$ selects such a child: choose zero when that child
is satisfiable and one otherwise.  Thus literal provenance, one-branch
output, and exact compatibility preservation do not define an intermediate
resource.  On the exact-$(2,2)$ clean core the query remains
$N^{1-o(1)}$, so the selector retains the arbitrary decider exponent $K$ and
does not yield a model-matched contradiction.  The predecision,
$K$-independent, strict-power-contraction compiler remains open.  An exhaustive
audit passed 725,007 checks.  P versus NP remains open.
\end{abstract}

The exact quantifier prefix tested is
\[
 \exists S\in\mathsf{FP}\ \forall F\in\mathsf{CNF},\ |\mathrm{vars}(F)|>0:
 S(F)=(x,b,F\upharpoonright_{x=b})\ \land\
 \SAT(F)=\SAT(F\upharpoonright_{x=b}).                 \tag{1}
\]
The machine is one uniform deterministic random-access machine.  All source
reads, simplification, query construction or access, calls, output bytes,
iteration, final evaluation and workspace are charged.  The SAME\_REALIZATION
is the selector together with its recursive evaluator.  The report does not
claim that an arbitrary SAT program internally exposes this selector.

\section{Clean core, encoding and compatibility}

Let $\Htwo$ be the duplicate-free proper Monotone $3$SAT-$(2,2)$ family:
every variable occurs twice positively and twice negatively, so $m=4n/3$.
D\"ocker proves this family NP-complete \cite{doecker}.  In the canonical
indexed clause-list encoding the complete source length is
$N=\Theta(n\log n)$.  A restriction descendant is an ordinary width-at-most-
three CNF with the same declared variable universe; compact renaming is also
permitted when its cost is charged.

For a variable $x$, define the two-bit semantic compatibility set
\[
 H_x(F)=\{b\in\{0,1\}:F\upharpoonright_{x=b}\text{ is satisfiable}\}.
\]
Then $\SAT(F)=[H_x(F)\ne\varnothing]$.  The selector below does not enumerate
$H_x(F)$.  It asks only whether $0\in H_x(F)$ and returns one child.

\section{Exact endpoint equivalence}

\begin{definition}[Exact literal restriction selector]
A selector $S$ is a total uniform machine which, for every CNF with a live
variable, chooses a source variable $x$, a bit $b$, and outputs the canonical
simplification $G=F\upharpoonright_{x=b}$ such that
\[
 \SAT(F)=\SAT(G).                                      \tag{2}
\]
The output must be a literal restriction of the supplied source, not an
unrelated constant endpoint.
\end{definition}

\begin{theorem}[\texttt{RESTRICTION-SELECTOR-ENDPOINT-EQUIV1}]
The following are equivalent.
\begin{enumerate}[label=(\roman*)]
\item SAT has a total uniform deterministic polynomial-time decider.
\item SAT has a total uniform deterministic polynomial-time exact literal
restriction selector.
\end{enumerate}
If the selector uses time $N^{r+o(1)}$ and space $N^{p+o(1)}$, direct
iteration gives a decider using time $N^{r+1+o(1)}$ and conservative writable
space $N^{\max\{p,1\}+o(1)}$ in the explicit-child realization.
\end{theorem}

\begin{proof}
For (ii)$\Rightarrow$(i), repeatedly apply $S$.  Each step fixes a previously
live variable, so at most $n\le N$ steps reach a variable-free formula.
Equation (2) preserves the answer at every step; the terminal formula is
evaluated directly.  Restriction does not increase explicit clause-list size
apart from fixed-format normalization, which can be implemented with linear
overhead.  Charging $N^{r+o(1)}$ at each of at most $N$ steps proves the time
bound.  Keeping the current explicit child and the selector workspace proves
the conservative space bound.

For (i)$\Rightarrow$(ii), fix a polynomial decider $A$ and choose, say, the
first live variable $x$.  Construct $F_0=F\upharpoonright_{x=0}$ and run
$A(F_0)$.  If the answer is one, output $F_0$.  Otherwise output
$F_1=F\upharpoonright_{x=1}$.  If $F_0$ is satisfiable then both $F$ and the
chosen child are satisfiable.  If $F_0$ is unsatisfiable, the elementary
identity
\[
 \SAT(F)=\SAT(F_0)\lor\SAT(F_1)                       \tag{3}
\]
shows that $F$ is satisfiable exactly when $F_1$ is.  Thus (2) holds on both
YES and NO sources.  Construction and the single call are polynomial.
\end{proof}

\begin{corollary}[\texttt{ONE-CALL-RESTRICTION-SELECTOR1}]
Assume $\SAT\in\mathsf P$ via a decider with time exponent $K$.  The reverse
construction makes exactly one SAT call per selected variable.  Its local
time exponent is at least the cost of that call; the construction does not
turn unknown $K$ into a fixed favorable exponent.
\end{corollary}

This is narrower than TESTS-0006's constant decide-then-emit theorem: the
child here is forced to be a literal restriction of the source.  The forward
direction is a special case of SYNTHESIS-0006's recursive endpoint closure.
The incremental result is that the provenance restriction still admits an
exact one-call converse rather than excluding decision-dependent acquisition.

\section{Encoded query scale and the failed bridge}

On $F\in\Htwo$, fixing one variable changes only its four incident clauses.
With inherited fixed-width variable addresses, the first query has
\[
 M=N-\Theta(\log n)=N^{1-o(1)}.                         \tag{4}
\]
Under compact renaming it still contains at least $4n/3-4$ untouched proper
clauses, so $M=\Theta(N)$ and $\log M/\log N\to1$.  Therefore a call costing
$M^{K+o(1)}$ costs $N^{K+o(1)}$.  Repeating the selector is a standard
search-to-decision path, not a $K$-erasing fractional bootstrap.

Equation (4) gives the exact dichotomy with LB-0016.  Emit every restriction
needed for strict power shrink and explicit volume is exponential.  Select
one answer-preserving restriction by a SAT truth-bit call and volume is one,
but the first calls are current-scale and retain $K$.  Neither arm supplies
the open source pass.

Requiring every child to remain in $\Htwo$ would be a different, stronger
promise-preserving compiler theorem: ordinary literal restriction leaves the
exact-occurrence family.  No such clean-core-hereditary normalizer is proved
here.  Re-expanding width-at-most-three descendants to proper 3CNF is a
linear local transformation, but returning exactly to $\Htwo$ with favorable
physical access remains part of the broader open transfer.

Thus \texttt{RESTRICTION-PROVENANCE-REPAIR1} is \RETIRED{}: literal source
provenance, one branch, and answer preservation alone do not make the pass
predecision or cheaper than SAT.  The smallest surviving repair is an
externally specified, source-checkable rule whose construction is proved in a
fixed $K$-independent budget, gives strict power-size children with charged
access, and is hereditary without invoking the parent decision.

\section{Hostile controls and SAME\_REALIZATION}

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{Horn, 2SAT, affine/Tseitin, bounded treewidth.}
The selector theorem holds, while the membership query can be answered by the
fragment's specialized polynomial algorithm.  Large or complicated
$H_x(F)$ is not forced computation.
\item[] \textbf{Independent products.}
One selected bit may be determined by one component; no simultaneous storage
of all component compatibilities follows.
\item[] \textbf{Paired clean-core island.}
The selector follows a satisfying restriction path, while the first query
scale tends to one.  The recognizable matching bypass of TESTS-0012 is
consistent with the theorem and remains a pointwise control.
\item[] \textbf{Padding, redundancy and alternate encodings.}
Semantic selection survives.  Discarding padding may make the child look
short, but parsing, validation, translation and source length conversion are
charged; no endpoint exponent transfers for free.
\item[] \textbf{DIRECT/DEAD/COPY/DELAY/INTERP/RECOMP.}
Every exact implementation returns the same membership bit, so an extensional
selector takes the same semantic branch.  Its actual time nevertheless
includes the chosen implementation.  DELAY therefore prevents a fixed
positive-scale exponent uniform over all polynomial implementations, exactly
as MODELBRIDGE-0015 proves.
\item[] \textbf{One-bit decision output.}
The recursive evaluator returns only SAT.  It never materializes the full
compatibility set, a witness table, proof, branching program, circuit, or
communication transcript.
\end{description}

\section{Literature and barrier-transfer preflight}

The two obstacles were (i) whether literal restriction provenance excludes
decide-first acquisition and (ii) whether the resulting query scale can enter
a model-matched time--space forbidden region.  Downward self-reducibility is
well studied; Harsha--Mitropolsky--Rosen explicitly distinguish the declared
smaller-instance oracle model and prove consequences for TFNP \cite{hmr}.
Their results do not convert the one-query construction above into a favorable
SAT compiler.  Chavrimootoo et al. give a directly relevant methodological
warning: imposing a particular downward-self-reduction structure on every SAT
algorithm is not a valid unrestricted lower-bound step \cite{chkln}.

FLMV transfers exactly only after one ordinary random-access realization
meets its simultaneous time and space hypotheses \cite{flmv}.  Here the
current-scale call retains $K$, so that endpoint is not reached.  VLSI
routing, control observability, distributed cuts, pebbling, proof search and
branching-program bounds are \textbf{FAILED TRANSFER}: each constrains a
declared interface, not every one-bit SAT computation.  Downward
self-reduction is the only \textbf{directly transferable theorem mechanism}
used here.  Local decoding and black-box reduction architecture are
\textbf{ANALOGY/CANDIDATE} until they provide strict scale reduction with all
costs charged.

The proof relativizes: with a common oracle, call the oracle-relative SAT
decider on the zero child and repeat the same logic.  Low-degree/algebraic
oracle access does not invalidate it.  Hence the result does not cross the
Baker--Gill--Solovay or Aaronson--Wigderson barriers \cite{bgs,aw}.  No large
constructive circuit property is used, so Natural Proofs is not the present
hinge \cite{rr}.  Nonuniform advice would add another acquisition/uniformity
obligation and does not remove the charged current-scale call.

\section{Post-quantum technique ledger}

Schur squares, puncturing, quadratic-relation rank, Hilbert functions,
syzygies and graded Betti numbers are \textbf{FAILED TRANSFER}: the selector
does not encode $H_x(F)$ as a code and no such object is forced in its
execution.  Lossiness/collision entropy is an \textbf{EXACT OBJECT
observation} only for the chosen two-valued selector map; its large fibers are
an exploitable compression, not a hardness theorem.  The LWE black-box lesson
is an \textbf{ANALOGY/CANDIDATE needing a new bridge}; the one-call reduction
is exact, but it is neither a worst-case/average-case reduction nor exponent
improving.  Collision extraction/special soundness and hash/random-oracle
methods are \textbf{FAILED TRANSFER} absent an unconditional conflicting-
opening witness theorem.  No cryptographic assumption is used.
