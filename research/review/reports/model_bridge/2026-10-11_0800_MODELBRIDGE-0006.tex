\section{Claim card and exact quantifiers}
Let $F(X,Y,Z)$ be a fixed CNF whose variables are partitioned into two
interface blocks $X=(x_1,\ldots,x_p)$, $Y=(y_1,\ldots,y_q)$ and auxiliary
variables $Z$.  Define the semantic compatibility function
\[
 H_F^{X\mid Y}(a,b)=1
 \quad\Longleftrightarrow\quad
 \exists z\;F(a,b,z)=1.                                                \tag{1}
\]
The rejected candidate was
\[
\tag{COMPAT-COMM-IMPLIES-SAT1}
\forall A\,[A\text{ uniform deterministic and exact for }\SAT]
\ \forall F\in\mathcal H_{2,2}:\quad
 \Dcc(H_F)\text{ large}
 \Longrightarrow
 \operatorname{Cost}(\tau_A(\enc(F)))\text{ comparably large}.
\]
Here $\mathcal H_{2,2}$ is the canonical proper Monotone 3-SAT-(2,2)
clean core: each clause has three distinct variables and one polarity, no
duplicate clause occurs, and every variable occurs exactly twice positively
and twice negatively.  The bit length $N=|\enc(F)|$ includes
self-delimiting counts, signs and binary variable identifiers.

There are two different possible objects in this slogan:
\begin{enumerate}[leftmargin=*]
\item the fixed-formula function (1), whose inputs are assignments $a,b$;
\item a split-input language $g(x,y)$, such as satisfiability of a formula
whose source representation is divided between Alice and Bob.
\end{enumerate}
An execution $A(\enc(F))$ computes only one SAT bit for one source formula.
It does not compute all entries of (1).  A trace simulation can transfer a
lower bound for the second object, but not for the first without a separate
compiler.  SAME\_REALIZATION requires the actual source reads, input split,
machine state, word width, oracle access, output convention, time and peak
space to be the same declared objects in the transfer.

\section{Exact fixed-formula counterfamily}
\begin{theorem}[SEMCOMP-DISJ1]
For every $n\ge1$, let
\[
 D_n=\bigwedge_{i=1}^n
 \bigl[(\neg x_i\vee\neg y_i\vee z_i)
 \wedge(\neg x_i\vee\neg y_i\vee\neg z_i)\bigr].                    \tag{2}
\]
Then $D_n$ is a proper Horn 3-CNF, its primal graph is a disjoint union of
triangles and has treewidth two, and
\[
 H_{D_n}^{X\mid Y}(a,b)=1\iff a\wedge b=0.
\]
The set
\[
 \mathcal S_n=\{(u,\overline u):u\in\{0,1\}^n\}
\]
is a $1$-fooling set of size $2^n$.  Hence
$\Dcc(H_{D_n}^{X\mid Y})\ge n$ in the standard deterministic two-party
model.  Nevertheless $D_n$ is satisfiable by the all-zero assignment and is
decidable in time linear in its explicit encoding by Horn propagation.
\end{theorem}
\begin{proof}
For fixed $a,b$, the two clauses at coordinate $i$ are simultaneously
satisfiable in $z_i$ unless $a_i=b_i=1$; in that case they reduce to $z_i$
and $\neg z_i$.  This proves the disjointness identity.  Every
$(u,\overline u)$ is disjoint.  For distinct $u,v$, either
$u\setminus v\ne\varnothing$ or $v\setminus u\ne\varnothing$, so at least
one crossed pair is not disjoint.  Thus $\mathcal S_n$ is a fooling set and
the standard rectangle argument gives the communication lower bound.  Each
clause in (2) has at most one positive literal, and the remaining syntactic
and satisfiability claims are immediate.
\end{proof}

The counterfamily is deliberately an easy hostile control rather than a
member of $\mathcal H_{2,2}$.  It falsifies the generic inference from
semantic-compatibility communication to one-bit SAT work.  More strongly,
for every fixed $F$ and every partition $X\mid Y$,
\[
 \Dcc(H_F^{X\mid Y})\le\min\{|X|,|Y|\}+1,                            \tag{3}
\]
because the shorter side can send its complete assignment and the receiving
side can send the answer bit back.  Equation (3) applies to clean-core
formulas too.  Consequently even a maximal compatibility communication
lower bound is only linear in the number of interface variables; it cannot
itself be a superpolynomial lower bound in encoded source length.

The equality 2-CNF
\[
 E_n=\bigwedge_i[(\neg x_i\vee y_i)\wedge(x_i\vee\neg y_i)]
\]
gives the parallel identity-matrix control: $H_{E_n}(a,b)=1$ iff $a=b$,
again with a $2^n$ fooling set, while $E_n$ is 2-SAT, has primal treewidth
one and is satisfied by the all-zero assignment.

\section{The exact universal transfer that does survive}
\begin{theorem}[SPLIT-TRACE-SIM1]
Let $g:\{0,1\}^p\times\{0,1\}^q\to\{0,1\}$ and let $M$ be a fixed
deterministic machine computing $g$ from two known read-only input regions.
In the bit-input-read model, let $R_M(x,y)$ be the number of input-bit reads
in the execution on $(x,y)$.  Then there is a deterministic two-party
protocol following that same execution such that
\[
 \operatorname{cc}_{M}(x,y)\le R_M(x,y)+1,
 \qquad
 \Dcc(g)\le \max_{x,y}R_M(x,y)+1.                                  \tag{4}
\]
For a word-RAM whose input read returns at most $w$ bits, the right side is
$w\max R_M+O(1)$.
\end{theorem}
\begin{proof}
Both parties store and simulate the complete deterministic control and work
state.  Before every input read, both therefore know the address and which
private region owns it.  The owner sends the requested bit (or at most $w$
bits for a word read), after which both update to the same next state.
Internal steps communicate nothing.  At halt, one final bit makes the output
common.  This is a faithful trace simulation with every private source read
charged.
\end{proof}

This is an arbitrary-algorithm transfer, but it has a hard ceiling.  The
trivial protocol in (3), now applied directly to $g$, always gives
\[
 \Dcc(g)\le\min\{p,q\}+1\le p+q+1.                                  \tag{5}
\]
Combining a communication lower bound with (4) can therefore force at most
linear input-read time (or linear divided by word width).  The protocol
allows unbounded local memory and local computation, so (4) supplies no
machine-space lower bound and no favorable time--space product.  It cannot
reach the known SAT time--space forbidden region.

For (1), the mismatch is more basic: $A(\enc(F))$ does not take $(a,b)$ as
input.  Using $A$ to answer entries of (1) requires an external residual
compiler and repeated calls, which is precisely MODELBRIDGE-0003's external
extraction setting and RT-0006's source-program service escape.  The unknown
SAT exponent $K$ reappears in those calls.

\paragraph{Relativization and algebrization.}
SPLIT-TRACE-SIM1 relativizes when both parties receive the same oracle access:
they compute the common query from shared simulated state and use the common
answer.  Algebraic-oracle access behaves the same way.  Thus the theorem does
not cross either barrier.  SEMCOMP-DISJ1 survives maximal semantic and
algebraic oracles because the one-bit SAT answer is already trivial.

\paragraph{Natural Proofs and nonuniformity.}
No constructive large circuit property is claimed.  Communication lower
bounds transfer to circuits only through a proved circuit-specific
correspondence such as Karchmer--Wigderson.  Per-formula nonuniform protocol
choices or partitions cannot be substituted for one uniform SAT machine.

\paragraph{Post-quantum technique ledger.}
The fooling-set collision pattern is an \textbf{EXACT OBJECT/THEOREM
TRANSFER} to deterministic communication complexity.  Collision entropy or
many incompatible pairs is a \textbf{FAILED TRANSFER} to SAT decision cost:
the Horn family realizes the full collision/fooling pattern while remaining
easy.  Schur-square, quadratic-relation, Hilbert-function and syzygy tools do
not address the split-to-centralized model gap in this candidate.  The
LWE-style black-box-reduction lesson is only an \textbf{ANALOGY/CANDIDATE};
SPLIT-TRACE-SIM1 is the available exact black-box transfer and its linear
ceiling is explicit.

\paragraph{Cross-domain transfer.}
Distributed cut and VLSI routing bounds are \textbf{THEOREM TRANSFERS} only
after the input placement, locality and cut capacity are imposed.  Treating
that cut as unavoidable for a centralized random-access SAT decider is a
\textbf{FAILED TRANSFER}.  The missing theorem would have to compile every
centralized solver into a communication interface with a resource whose own
maximum exceeds input length; ordinary two-party communication cannot do so.

\section{P=NP audit and surviving arrow}
Assume $\SAT\in\mathsf P$ through some uniform decider of time $N^K$.
SPLIT-TRACE-SIM1 gives a polynomial communication protocol for any declared
split SAT language, while the trivial source-send protocol already gives
$O(N)$ communication.  There is no contradiction.  Externally querying the
decider to materialize $H_F$ costs the residual compiler plus calls to the
$N^K$ decider, so $K$ survives.  A one-bit decision output does not expose the
matrix, fooling set, rectangle partition or protocol transcript.

The surviving target is therefore not a larger communication matrix.  It is
\[
\tag{JOINT-SPLIT-RESOURCE1}
\begin{gathered}
\forall A\in\mathcal A_{\SAT}^{\rm det,unif}\ \exists C_A\ \forall
F\in\mathcal H_{2,2}:\\
C_A\text{ is a $K$-independent predecision SAME\_REALIZATION compiler}\
\text{to a resource model with an unconditional superpolynomial endpoint,}\
\text{with source, construction, reads, replay, output, time and peak space charged.}
\end{gathered}
\]
Ordinary two-party communication fails the endpoint requirement by (5).
HEC/CRS-PPC, routed-store/reacquire and separator-message models remain
restricted-model candidates until their static compiler is proved.
