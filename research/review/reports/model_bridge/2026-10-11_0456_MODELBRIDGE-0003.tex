\paragraph{Result and strict status.}
This run tests the strongest standard black-box bridge from an arbitrary
uniform deterministic 3-SAT decider to the clean-core compatibility object.
The positive result is exact but weaker than the proposed universal-core
necessity: every such decider supports an \emph{external} extractor that
finds one satisfying assignment using at most $n+1$ calls on explicitly
pinned 3-CNF formulas.  An exact binary encoding ledger, a materialized-query
ledger, and a virtual-input ledger are given below.

The extractor reveals one $1$-entry of the compatibility matrix.  It neither
outputs the matrix nor proves that the decider internally exposes rows,
rank, residual states, a DAG, compatibility classes, provenance, or a chosen
representation.  Promoting one extracted edge to any such full object is
\textbf{FALSIFIED/RETIRED as a free transfer}.  The missing implication is
named \textbf{CORE-ACQUIRE1} and remains \textbf{OPEN}.  Under $P=NP$ the
theorem gives the familiar polynomial-time witness finder, not a
contradiction.  P versus NP remains \textbf{OPEN}.

\section{Clean-core object and exact input encoding}
\begin{definition}[Compatibility core]
Let $F$ be a 3-CNF on variables $z_1,\ldots,z_n$, and split the variables
into $X=(z_1,\ldots,z_r)$ and $Y=(z_{r+1},\ldots,z_n)$.  Define
\[
 H(F)_{u,v}=1 \quad\Longleftrightarrow\quad F(u,v)=1,
 \qquad
 u\in\{0,1\}^{r},\ v\in\{0,1\}^{n-r}.
\]
Thus $F$ is satisfiable exactly when $H(F)$ has a $1$-entry.  This definition
is semantic and independent of a solver.  A full explicit table has $2^n$
bits; a satisfying assignment is only the coordinates of one $1$-entry.
\end{definition}

Repeated literals are permitted, so a pin is an exact 3-clause
$(z_i,z_i,z_i)$ or $(\neg z_i,\neg z_i,\neg z_i)$.  Let
\(\ell_\gamma(q)=2\lfloor\log_2q\rfloor+1\) be Elias-gamma length and
\(w=\max\{1,\lceil\log_2(n+1)\rceil\}\).  The declared canonical binary
encoding has header $\gamma(n)\gamma(m+1)$ followed by three signed
fixed-width literals per clause.  Hence
\[
 N=|\Enc(F)|=\ell_\gamma(n)+\ell_\gamma(m+1)+3m(1+w).       \tag{1}
\]
Clause and literal order are canonical; invalid encodings return zero.
After at most $n$ pins, the largest query length is exactly bounded by
\[
 L=N+\ell_\gamma(m+n+1)-\ell_\gamma(m+1)+3n(1+w).          \tag{2}
\]
This is $N+O(n\log n)$, but the exact expression, not the asymptotic slogan,
is used in the resource ledger.

\section{The model-matched universal implication}
\begin{theorem}[EDGE-EXTRACT1, PROVED/EXACT]
For every total uniform deterministic decider $A$ that is correct on all
canonical 3-CNF encodings, there is an effectively constructed uniform
deterministic extractor $E_A$ such that, for every canonical $F$:
\begin{enumerate}
\item if $F$ is unsatisfiable, $E_A(F)$ returns UNSAT;
\item if $F$ is satisfiable, $E_A(F)$ returns an assignment $a$ with
      $H(F)_a=1$;
\item $E_A$ makes one initial call and at most one additional call per
      variable, hence at most $n+1$ calls, all of length at most $L$ in (2).
\end{enumerate}
The quantifiers are
\[
 \forall A\,[A\text{ decides 3-SAT}]
 \ \exists E_A\ \forall F\,[E_A(F)\text{ has the properties above}].
\]
They do not assert one implementation-independent internal state of $A$.
\end{theorem}

\begin{proof}
Call $A(F)$.  If it returns zero, return UNSAT.  Otherwise maintain a prefix
$b_1,\ldots,b_{i-1}$ known to extend to a satisfying assignment.  Query the
3-CNF obtained from $F$ by appending the accumulated pin clauses and the
candidate pin $z_i=0$.  If it is satisfiable set $b_i=0$; otherwise set
$b_i=1$.  In the latter case the invariant and Boolean exhaustiveness imply
that the one branch is satisfiable.  Induction preserves the invariant.
After $n$ stages the unique completion of the prefix is the returned
satisfying assignment.  Exactly one candidate branch is queried per stage.
Every appended condition is a repeated-literal 3-clause, giving (2).
\end{proof}

\paragraph{Materialized-query ledger.}
If $A$ takes time $T(q)$ and writable space $S(q)$ on length $q$, explicitly
constructing one query at a time gives
\[
 T_{E_A}(N)=O\!\left(n(T(L)+L)+N\right),\qquad
 S_{E_A}(N)=O\!\left(S(L)+L+n\right).                      \tag{3}
\]
All pins, copying, headers, output, and direct verification are charged.

\paragraph{Virtual-input ledger.}
On the read-only random-access model, a simulator can answer a queried bit
of the pinned encoding from the original input, the stage number, and the
$n$-bit prefix.  Header and address arithmetic cost $O(\log L)$ time and
$O(\log L)$ space per access.  Simulating $A$ separately for each stage gives
\[
 T_{E_A}(N)=O\!\left(nT(L)\log L+nL\right),\qquad
 S_{E_A}(N)=O\!\left(S(L)+n+\log L\right).                 \tag{4}
\]
Equation (4) is an upper bound for the combined extractor realization, not
a lower bound on $A$.  A different machine convention requires a new local
simulation proof.

\section{Why the bridge stops at one edge}
The decider's required output is
\[
 \SAT(F)=\bigvee_{u,v}H(F)_{u,v},                          \tag{5}
\]
one bit.  EDGE-EXTRACT1 recovers a coordinate of one nonzero entry by
making new calls on new inputs.  Nothing in the proof reveals $H(F)$ during
the original call.  It does not preserve the original execution trace, and
it does not output zero rows, all rows, matrix rank, residual classes, an
OBDD order, a d-DNNF, or a pebbling graph.

This distinction survives the hostile controls.  Equality 2-CNF has a
full-rank compatibility matrix but a linear direct algorithm and, by
PROOFMAP-0004, grouped and interleaved OBDD sizes
$3(2^k-1)$ and $3k$ respectively.  Affine pairs admit Gaussian elimination;
Horn formulas admit propagation; bounded-treewidth and independent products
admit compact dynamic programs.  Duplicate clauses and ignored padding can
increase $N$ without changing (5).  DEAD, COPY, DELAY and RECOMP wrappers
change internal traces without changing any query answer.  Therefore a
semantic table or a chosen representation is not a mandatory internal
resource merely because an external algorithm can recover a witness.

\begin{theorem}[No free core promotion, FALSIFIED/RETIRED]
The implication
\[
 \text{EDGE-EXTRACT1}
 \Longrightarrow
 \text{every execution of }A(F)\text{ materializes or pays the explicit
 size of }H(F)
\]
is false without an additional interface theorem.  In particular, the
query cost in (3) or (4) belongs to $E_A$, and cannot be reassigned to the
original one-bit execution of $A$.
\end{theorem}
\begin{proof}
The extractor calls $A$ on up to $n$ formulas other than $F$.  Charging those
separate computations to the single execution $A(F)$ changes the resource
being measured.  On the equality, Horn, affine and treewidth-one controls,
direct algorithms answer (5) without outputting the exponential table.
Equivalent wrappers further show that a representation-specific trace is
not fixed by correctness.  Thus the displayed promotion does not follow
from EDGE-EXTRACT1 or from decision correctness.
\end{proof}

\begin{definition}[CORE-ACQUIRE1, OPEN]
Find a solver-independent predicate and charged transformation such that
for every total uniform deterministic 3-SAT decider $A$ and every member
$F$ of one explicit infinite clean-core family, the \emph{same realization}
of $A(F)$ either exposes an invariant object $Q(F)$ or incurs a
model-matched resource cost lower-bounded from $Q(F)$.  The theorem must
survive equivalent wrappers and encodings, count compilation, local access,
replay, output, retained and transient workspace, and imply a bound on $A$
rather than on a new extractor.  $Q$ must support a known unconditional
lower bound in that exact model.
\end{definition}

\section{Assuming $P=NP$ and barrier audit}
Assume $P=NP$.  Choose a polynomial-time $A$ in EDGE-EXTRACT1.  Since
$L$ is polynomial in $N$, equations (3) and (4) produce a polynomial-time
witness finder.  This is the standard $FP=FNP$ consequence for SAT search.
It is consistent with the assumption, so there is no unconditional
contradiction.  The output assignment itself contains only $n$ bits and
does not encode the full compatibility table.

The construction relativizes: with one fixed oracle $O$, replace every
machine by its $O$-oracle version and perform the same syntactic pinning.
Hence Baker--Gill--Solovay forbids treating EDGE-EXTRACT1 alone as the
nonrelativizing hinge.  The argument also makes no use of a distinction
destroyed or created by low-degree oracle extensions; it supplies no
nonalgebrizing hinge.  FLMV-style time-space bounds remain valid only in
their declared model and parameter region.  Equations (3)--(4) do not place
$A$ in that forbidden region: they add a factor $n$, retain the unknown
$T,S$, and solve a search interface.

Natural-proofs considerations are not directly invoked by the witness
extraction.  They become relevant only if CORE-ACQUIRE1 is replaced by a
large unrestricted circuit property; no such circuit lower bound is proved.

\section{Bounded reproducible experiment}
The program
\path{experiments/review/model_bridge_edge_extract_test.py} constructs exact
repeated-literal 3-CNF instances for equality/2-SAT, affine complement,
Horn chains, treewidth-one independent products, duplicate padding,
contradictory pins, and seeded random formulas.  It runs the extractor
against DIRECT, DEAD, COPY, DELAY and RECOMP decider wrappers, checks every
returned witness directly, and checks (2) using exact integers.

The bounded run used $k\le4$ and 40 seeded random cases.  It passed 64
formula checks, 320 wrapper answer checks, 60 direct witness checks, 300
wrapper witness checks, 64 exact query-length checks, and 319 direct oracle
calls.  Runtime was 0.071 seconds under a 25-second cooperative alarm and a
30-second outer limit.  These finite checks validate the implementation and
hostile controls; they do not extrapolate an asymptotic lower bound.

\section{DUPLICATION / CONTRADICTION AUDIT}
Search-to-decision is standard and is not claimed novel.  MODELBRIDGE-0002
already proved the generic direct-call exponent ledger; the new contribution
is its exact instantiation for canonical repeated-literal 3-CNF, the clean
core $H(F)$, and the separation between one extracted edge and full-object
necessity.  CC-0005 and RT-0003 already supplied full-rank easy controls;
PROOFMAP-0004 supplied the exact order-sensitive OBDD counterfamily.  This
report adopts those results rather than renaming them.

No contradiction was found with main4/main5.  Their all-input successor and
fallback obligations remain OPEN.  EDGE-EXTRACT1 is an external query
procedure and does not satisfy their strict shrinking, descendant closure,
or joint time-space requirements.  No contradiction was found with LB-0004:
its fiber-type theorem is conditional on an exposed verifier interface,
which EDGE-EXTRACT1 does not force inside $A$.

access interface, execution being charged, representation equivalence, and
lower-bound model.
