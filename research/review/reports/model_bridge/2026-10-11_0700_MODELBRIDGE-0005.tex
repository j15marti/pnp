\section{Target and exact quantifiers}
Let $F$ be an encoded proper 3-CNF on named variables $x_1,\dots,x_n$.  Let
\[
R(F)=\{a\in\bits^n:F(a)=1\}.
\]
For $i<j$ and $b,c\in\bits$, define
\begin{align*}
u_{i,b}(F)&=1 \iff \exists a\in R(F)\; a_i=b,\\
p_{i,b,j,c}(F)&=1 \iff \exists a\in R(F)\; (a_i,a_j)=(b,c),
\end{align*}
and set $H_2(F)=(u,p)\in\bits^{2n^2}$.  The rejected bridge candidate was
\[
\forall A\,[A\text{ is a total uniform deterministic exact 3-SAT decider}]
\quad\Longrightarrow\quad
\text{a solver-independent }H_2(F)\text{ yields a strict bound-preserving successor.}
\]
This report separates its two arrows: extraction is exact; source-free global gluing and contraction are false.

The clean control class $H_{2,2}$ consists of proper 3-CNFs in which every variable occurs exactly twice positively and twice negatively and every clause is all-positive or all-negative.  Thus $m=4n/3$ and $n$ is divisible by three.  This is the same ordinary-CNF control used in the current review corpus; it is not silently substituted for the full 3-SAT language.

\section{External extraction theorem}
\begin{theorem}[SEMCOMP-EXTRACT1 --- \status{PROVED/EXACT}]
For every total uniform exact 3-SAT decider $A$, there is a uniform deterministic transducer $E^A$ which, on every encoded 3-CNF $F$ with $n$ named variables, outputs $(\SAT(F),H_2(F))$ using at most $2n^2+1$ calls to $A$.
\end{theorem}
\begin{proof}
First query $F$.  For each $(i,b)$ query $F\wedge(x_i=b)$; for each $(i,b,j,c)$ with $i<j$ query $F\wedge(x_i=b)\wedge(x_j=c)$.  The returned decision bits are exactly the coordinates above.  There are
\[
1+2n+4\binom n2=2n^2+1
\]
queries.  A pin can be represented as the repeated-literal 3-clause $(\ell\vee\ell\vee\ell)$.  If the target syntax requires three distinct literals, replace a unit pin $\ell$ by the four proper clauses
\[
(\ell\vee p\vee q)\wedge(\ell\vee p\vee\neg q)
\wedge(\ell\vee\neg p\vee q)\wedge(\ell\vee\neg p\vee\neg q),
\]
using two fresh variables.  This preserves satisfiability exactly and keeps each query length linear in the source length.
\end{proof}

For the length convention already fixed by MODELBRIDGE-0004, let
\[
w=\max(1,\lceil\log_2(n+1)\rceil),\qquad
L_t=N+[\ell_\gamma(m+t+1)-\ell_\gamma(m+1)]+t[5+3(1+w)]
\]
for $t\in\{0,1,2\}$ repeated-literal pins, and $L=\max_t L_t$.  If $A$ takes time $T_A$ and space $S_A$, a literal implementation costs
\[
O\!\left(n^2(T_A(L)+L)\right)\text{ time},\qquad
O(S_A(L)+L+\log n)\text{ streaming work space}.
\]
Materializing the $2n^2$ output bits additionally costs $\Theta(n^2)$ space.  The proper-pin adapter changes constants, not asymptotics.  Hence under $\SAT\in\mathrm P$, $H_2$ is in FP, but the extraction exponent still inherits the unknown exponent of $A$ (and adds the quadratic query loop).  This is external black-box extraction, not evidence that the same execution of $A$ exposes $H_2$.

\section{Fixed-arity projections do not glue}
\begin{theorem}[FIXED-ARITY-NOGLUE1 --- \status{PROVED/EXACT}]
For every $n\ge 3$ there are proper 3-CNFs $P_n^0,P_n^1$ whose projected solution sets on original variables $x_1,\dots,x_n$ are respectively the even- and odd-parity cosets.  They are disjoint, yet for every $k<n$ every assignment to every $k$ original coordinates extends to a solution of both formulas.  Therefore no source-free function of all arity-at-most-$k$ semantic projections can output an assignment valid for every source realizing those projections.
\end{theorem}
\begin{proof}
Encode a prefix-parity chain with the proper 3-CNF XOR gadget
\[
c=a\oplus b\quad\Longleftrightarrow\quad
(a\vee b\vee\neg c)(a\vee\neg b\vee c)
(\neg a\vee b\vee c)(\neg a\vee\neg b\vee\neg c).
\]
After $n-1$ gates, pin the final prefix bit to the desired parity with the four-clause proper pin gadget above.  Each formula has $2n+1$ variables and $4n$ clauses.  Its projection onto the $x$ variables is exactly one parity coset.  Given any setting of fewer than $n$ original variables and either desired parity, choose one unfixed bit to satisfy the parity equation.  Thus every proper projection is the full cube for both cosets, although the global relations are disjoint.  A function of the common projection data returns the same assignment on both inputs and therefore fails on at least one.
\end{proof}

This is also an exact coding-theoretic object transfer: the two cosets of the binary single-parity-check code have identical puncturings whenever at least one coordinate is deleted.  It is \emph{not} a transfer of a coding hardness theorem.  The same affine structure is exploitable by Gaussian elimination, so it is a warning against treating large local compatibility as hardness.

\section{Why the universal contraction still fails}
The complete accounting produces a trilemma.
\begin{enumerate}[leftmargin=2em]
\item Retain $F$ while using $H_2(F)$: the current-scale source remains present, so no charged strict contraction follows.
\item Discard $F$ and retain only $H_2(F)$: FIXED-ARITY-NOGLUE1 and the finite $H_{2,2}$ collision show that global source binding is lost.
\item Ask $A$ for enough information to decide or reconstruct globally and then emit a constant child: the expensive current-scale decision has already occurred, so the construction does not remove the unknown exponent $K$.
\end{enumerate}
Thus the implication
\[
\SAT\in\mathrm P\Longrightarrow\text{charged $K$-independent strict contraction from }H_2
\]
is \status{FALSIFIED/RETIRED}.  There is no unconditional contradiction and no inference from semantic-state count to runtime.

\section{Barrier-transfer literature preflight}
The two obstacles were (i) local-to-global gluing and (ii) turning black-box access into a model-matched lower bound.  Atserias--Bulatov--Dalmau prove that $k$-consistency is exact for bounded-treewidth structural regimes and provide a converse in their CSP model; Barto--Kozik characterize bounded-width constraint languages and emphasize affine/counting obstructions.  These are \status{KNOWN THEOREM} transfers only for their specified CSP objects.  They support the parity counterexample and reject a universal local-consistency claim; they do not supply a SAT time lower bound.

Baker--Gill--Solovay relativization, Aaronson--Wigderson algebrization, and the Razborov--Rudich natural-proofs barrier remain audit constraints.  SEMCOMP-EXTRACT1 is a relativizing black-box self-reduction and cannot by itself evade them.  No natural-proof largeness/usefulness claim is made.  Time--space lower bounds for restricted branching programs, circuits, proof systems, or VLSI do not automatically apply to an arbitrary uniform deterministic decider; the missing simulation/transfer theorem remains explicit.

Post-quantum ledger: puncturing parity cosets is an \status{EXACT OBJECT/THEOREM TRANSFER}; Schur squares, relation-rank spectra, higher syzygies, and collision entropy are \status{ANALOGY/CANDIDATE} here because no map from those invariants to arbitrary-decider time is proved.  Hash or random-oracle binding is a \status{FAILED TRANSFER} for an unconditional separation.

\begin{quote}
Find an explicit source-first object $J(F)$ such that (a) $J$ distinguishes every pair of clean-core sources with disjoint solution sets, including the $H_{2,2}$ pair above; (b) $J$ yields at least $n/3$ consistent variable decisions or strict ordinary-CNF children; (c) all construction, verification, and reconstruction costs are charged and independent of the assumed solver exponent $K$; (d) the child family is hereditary; and (e) the implication holds for every total uniform deterministic decider under equivalent wrappers.
