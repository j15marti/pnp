\begin{abstract}
The surviving synthesis asks for an externally fixed, predecision,
wrapper-covariant compiler from every hypothetical polynomial SAT decider to
one model-matched forbidden realization. This run identifies an exact
coverage boundary. Let \(X(A,F)\) be any extracted object associated with an
exact polynomial SAT implementation \(A\) and source formula \(F\). If the
allowed program transformations contain every constant replacement
\(\kappa_B:A\mapsto B\), and \(X\) is invariant under those transformations,
then \(X(A,F)\) is independent of \(A\): it factors as \(R(F)\).
More generally, \(X\) is constant on every component of the transformation
graph.

Therefore a purported wrapper-covariant but implementation-sensitive
universal resource has only two regimes. Include replacement coverage and
the resource becomes source-only; exclude it and a separate theorem must show
that every arbitrary polynomial SAT implementation lies in the covered
orbit. For a compiler landing in an FLMV-forbidden ordinary class, the
source-only implication is already the separation-strength endpoint
\(\SAT\in P\Rightarrow\SAT\in\mathcal G\), not an intermediate internal
obligation. The theorem is elementary and unconditional, with independent
red-team promotion review pending; its application
under \(P=NP\) gives no contradiction without the still-open favorable
compiler. A finite exhaustive audit passed 586,010 labelings and 1,177
assertions. P versus NP remains open.
\end{abstract}

\section{Clean core, target, and claim card}
Use the current clean core
\[
 \mathcal H_{2,2}=\{F:\ F\text{ is duplicate-free proper Monotone }
 3\SAT\text{-}(2,2)\}.
\]
Every variable occurs twice positively and twice negatively. A formula on
\(n\) variables has \(4n/3\) clauses, and its canonical fixed-width indexed
encoding has
\[
 N=|\operatorname{enc}(F)|=\Theta(n\log n).
\]
Writing \(F=C_1\wedge\cdots\wedge C_m\), define the semantic compatibility
matrix
\[
 H(F)_{\alpha,j}=1\quad\Longleftrightarrow\quad\alpha\models C_j.
\]
The one-bit problem asks only whether \(H(F)\) has an all-one row. It does
not require a decider to expose \(H(F)\), a witness, a trace, memory image,
communication transcript, circuit, branching program, or proof.

Let \(\PolySAT\) be the set of codes of total uniform deterministic
polynomial-time machines deciding the same canonical SAT language. Under
the counterfactual \(P=NP\), this set is nonempty; no common polynomial
exponent is assumed. The exact attacked prefix is
\[
 \exists X\ \forall A,B\in\PolySAT\ \forall F\in\mathcal H_{2,2}:
 X(\kappa_B(A),F)=X(A,F)
 \quad\land\quad X\text{ depends nontrivially on }A,
 \tag{1}
\]
where \(\kappa_B\) is the uniform constant program transformer returning
the code \(B\) and ignoring its input program. Since
\(\kappa_B(A)=B\) syntactically, (1) is inconsistent.

The SAME\_REALIZATION object is the particular pair \((A,F)\) on which
\(X\) is declared. The theorem below does not identify \(X\) with machine
state or runtime. Its weakest useful consequence is a precise choice:
source factorization or an open coverage theorem.

\section{Exact wrapper-orbit theorem}
\begin{definition}[Transformation covariance]
Let \(\mathcal P\neq\varnothing\) be a class of program codes and let
\(\mathcal W\) be a family of total maps \(\mathcal P\to\mathcal P\).
For a source set \(\mathcal F\), an object map
\(X:\mathcal P\times\mathcal F\to\mathcal O\) is
\(\mathcal W\)-invariant when
\[
 X(W(A),F)=X(A,F)
 \quad\text{for all }W\in\mathcal W,\ A\in\mathcal P,\ F\in\mathcal F.
 \tag{2}
\]
Put an edge \(A\to W(A)\) in the transformation graph.
\end{definition}

\begin{theorem}[\texttt{REPLACEMENT-COVARIANCE-FACTORIZATION1}]
If \(X\) satisfies (2), then for every fixed \(F\), \(X(\cdot,F)\) is
constant on every weak component generated by transformation edges. In
particular, if for each \(B\in\mathcal P\) the constant transformation
\(\kappa_B(A)=B\) belongs to \(\mathcal W\), then there is a unique map
\(R:\mathcal F\to\mathcal O\) such that
\[
 X(A,F)=R(F)\qquad
 \text{for every }A\in\mathcal P,\ F\in\mathcal F.
 \tag{3}
\]
\end{theorem}

\begin{proof}
Equation (2) equates the values at the endpoints of every transformation
edge. Equality is symmetric and transitive, so the value is constant on the
undirected component generated by those edges. Under the replacement
hypothesis, for any \(A,B\in\mathcal P\),
\[
 X(B,F)=X(\kappa_B(A),F)=X(A,F).
\]
Fix \(A_0\in\mathcal P\) and define \(R(F)=X(A_0,F)\). The displayed equality
proves (3), and uniqueness is immediate.
\end{proof}

\begin{corollary}[\texttt{WRAPPER-ORBIT-COVERAGE-DICHOTOMY1}]
A covariance proposal that includes all exact polynomial constant
replacements is source-only. A proposal that excludes even some replacement
orbits may remain implementation-sensitive, but covariance alone says
nothing about an arbitrary SAT program outside the covered component.
A load-bearing universal claim therefore needs an independent theorem
placing every \(A\in\PolySAT\) in a covered component.
\end{corollary}

The conclusion is not a runtime lower bound. It forbids a claimed middle
ground: simultaneously implementation-sensitive, invariant under every exact
language-preserving polynomial program transformation, and universal over
all polynomial SAT implementations.

\section{Compiler application and endpoint equivalence}
Let \(\mathcal G\) be a fixed ordinary-machine resource class for which a
model-matched theorem proves \(\SAT\notin\mathcal G\); an FLMV simultaneous
random-access time--space region is the intended example. Suppose a proposed
compiler theorem states
\[
 \SAT\in P\quad\Longrightarrow\quad
 \forall A\in\PolySAT\ \mathcal T(A)\in\mathcal G
 \text{ and }\mathcal T(A)\text{ decides SAT}.
 \tag{4}
\]
If \(\mathcal T\) is invariant under all replacements, it factors through the
program-independent choice: fix any \(A_0\in\PolySAT\) and obtain the single
ordinary decider \(\mathcal T(A_0)\in\mathcal G\). Thus (4) implies
\[
 \SAT\in P\Longrightarrow\SAT\in\mathcal G.
 \tag{5}
\]
Together with \(\SAT\notin\mathcal G\), (5) proves \(\SAT\notin P\), hence
\(P\ne NP\). The compiler implication is therefore separation-strength.
Replacement covariance does not supply a smaller internal necessity.

If the compiler instead depends on code, trace, timing, memory layout, query
scale, representation, or a selected proof, it can avoid factorization only
by excluding transformations that replace those data. It must then prove
that every arbitrary polynomial SAT decider is captured despite that
exclusion, with compilation, inspection, source access, replay, transport,
output and peak workspace charged. No such theorem is present.

For per-source objects \(X(A,F)\), efficient factorization means that after
fixing one \(A_0\), \(R(F)=X(A_0,F)\) is an external source computation. It
does not show that the original run \(A(F)\) materializes or pays for
\(R(F)\). This agrees with LB-0011's implementation-quotient theorem; the new
result identifies a concrete generating transformation family.

\section{Hostile controls and one-bit output}
Horn closure, 2SAT strongly connected components, affine Gaussian
elimination and bounded-treewidth dynamic programming give semantic
shortcuts. Hidden structure is an algorithmic advantage here, not a hardness
resource. Replacement acts on program codes and is unaffected by padding,
redundant clauses, independent products or alternate encodings; those
operations can still change encoded lengths and endpoint exponents.
DEAD/COPY/DELAY/INTERP/RECOMP may preserve behavior while changing traces,
times, states and representations. REPLACE is stronger: it connects
different exact algorithms. If included, invariants become source-only; if
excluded, it witnesses the missing coverage. A decider may output only one
bit and discard every candidate object. Requiring a witness, compatibility
matrix or canonical program changes the interface.

\section{Barrier and cross-domain transfer audit}
Baker--Gill--Solovay exhibit oracle worlds with both \(P^O=NP^O\) and
\(P^O\ne NP^O\), so this relativizing program-transformation argument cannot
be the final separation hinge \cite{BGS75}. Aaronson--Wigderson's
algebrization barrier remains untouched \cite{AW09}. Natural Proofs is not
triggered because no constructive large circuit property is proposed.

Rice supplies classical semantic-program-property context \cite{Rice53},
while Blum emphasizes the distinction between extensional functions and
machine-indexed measures \cite{Blum67}. Neither is needed for the finite
graph proof. FLMV is a \textbf{DIRECTLY TRANSFERABLE THEOREM} only after one
actual ordinary random-access SAT decider lands in its simultaneous forbidden
region \cite{FLMV05}. Jahanjou--Miles--Viola locality supports an external
local reduction, not internal exposure \cite{JMV14}.

Certified compilation, full abstraction, bisimulation and minimal automata
are \textbf{ANALOGY/CANDIDATE}: arbitrary-SAT coverage and model-matched
costs are missing. VLSI routing, distributed cuts, proof-system size,
circuit/branching-program width and observability are \textbf{FAILED
TRANSFER} without a compiler. Schur squares, quadratic-relation ranks,
Hilbert functions, syzygies, collision entropy and special-soundness binding
are also \textbf{FAILED TRANSFER}: replacement can discard the chosen
representation. LWE-style external extraction is only
\textbf{ANALOGY/CANDIDATE}; the missing theorem is universal orbit coverage
plus a favorable ordinary endpoint. No cryptographic assumption is used.

false to infer internal exposure, memory, time or communication cost from
source factorization.
