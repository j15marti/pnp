\paragraph{Result and strict status.}
The new COST\_CERTIFICATES theorem correctly separates an already explicit
shared input from a recopied or implicit input, but its proof does not restore
the verifier's writable tapes to their required blank initial state between
witness trials.  Resetting only finite control and address registers is not
enough.  Therefore the exact displayed $O(2^w(q+w+\log M))$ implementation
and its \textbf{PROVED/EXACT} label are \textbf{not established as written}.
The exponent conclusion $\kappa+v$ is salvageable: add a reset cost $r(M)$,
or require a tidy/resettable verifier.  In the declared FLMV tape model, an
explicit computable space/time envelope permits a prefix-clearing simulation
with only a polylogarithmic time factor, so the polynomial exponent remains
$\kappa+v$.  This is a narrow implementation repair.  It supplies no PFCERT
verifier, implicit-child accessor, strict SAT successor, or lower bound.
P versus NP remains \textbf{OPEN}.  These proofs are not machine checked.

\section{Selected implication and counterexample}
Let $y$ be an explicit read-only input tuple of encoded length $M$.  Let one
fixed deterministic verifier $V(y,\pi)$ run for at most $q(M)$ steps and use
at most $s(M)$ writable tape cells when every writable tape begins blank.
Let $w(M)$ bound $|\pi|$.  CC-0003 asserts that a single acquirer can reuse
one verifier workspace over all $2^{w+1}-1$ candidates while resetting only
finite control and addresses.

That reset is insufficient.  Consider a verifier with one writable cell
$z$, initially blank.  On every invocation it reads whether $z$ is blank,
writes $1$ to $z$, and accepts exactly when the candidate is a fixed target
and the old value was blank.  Every standalone invocation has the specified
semantics.  When the first rejected candidate leaves $z=1$, the target is
rejected by the reused dirty workspace.  Resetting finite control and input
addresses does not restore the standalone verifier computation.

The peer harness cannot detect this counterexample.  Its ``peak-space
reuse'' test assigns
\[
 \texttt{peak}=\texttt{verifier\_space}+w+\texttt{addr}
\]
and immediately compares \texttt{peak} with the identical expression.  It
never executes a stateful verifier or checks a blank-workspace invariant.
The peer acceptance test is likewise a pure set-membership enumeration with
no writable verifier state.

\section{Smallest mathematical repair}
Introduce an explicit reset routine.  If it uses time $r(M)$ and no more
than the already charged verifier space plus $O(\log M)$ bits, the correct
generic bound is
\[
 O\!\left((2^{w(M)+1}-1)
       (q(M)+r(M)+w(M)+\log(M+2))+w(M)\right)
\]
time and
\[
 O(s(M)+w(M)+\log(M+2))
\]
writable bits.  Alternatively, include reset in the definition of $q$ or
require $V$ to be tidy: after every halt, its writable tapes are blank except
for the one-bit decision copied to a designated output register.

The FLMV random-access tape convention measures auxiliary space on a tape by
the largest visited index and assumes space is bounded by time
\cite{flmv,diehl}.  If a computable bound $b(M)\ge s(M)$ is supplied, one may
zero every cell in the visited prefix of each fixed writable tape.  Literal
binary-address generation gives the conservative reset bound
\[
 r(M)=O(b(M)\log(b(M)+2)).
\]
When $b(M)\le q(M)$ and $q(M)=M^{v+o(1)}$, this is
$M^{v+o(1)}$.  Hence for
$w(M)=\kappa\log_2M+o(\log M)$ the repaired exponent is still
$\kappa+v$.  The original exact big-O formula nevertheless needs the reset
premise or this polylogarithmic term.

This repair is model-specific.  Word-RAM initializable-array theorems give
constant-time logical initialization with small redundancy
\cite{hagerupkammer,katohgoto}, but they use word operations and data-structure
representations not present for free in the FLMV bit-tape model.  They are a
useful structural analogy, not a direct zero-cost transfer.

\section{Primary literature and transfer classification}
FLMV's JACM paper is the endpoint source and its random-access convention
uses read-only input plus charged index/work tapes \cite{flmv}.  A detailed
source-compatible exposition states that auxiliary tape space is the largest
visited index and that the analysis assumes space bounded by time
\cite[Section 2.1]{diehl}.  This directly supports the prefix-clear repair;
it does not justify omitting reset.

Hagerup--Kammer prove constant-time initialization with a time--space tradeoff
for word-RAM arrays \cite{hagerupkammer}; Katoh--Goto prove an in-place
initializable array using one extra bit and constant-time word-RAM operations
\cite{katohgoto}.  The exact object correspondence is verifier workspace as
an initializable array.  The missing transfer is an implementation using the
FLMV bit-tape instruction set and space convention with all address and
metadata costs charged.  Therefore this is an \textbf{ANALOGY/CANDIDATE},
not a theorem transfer.  Generic ORAM results are a failed shortcut because
distributional access-pattern hiding is not the deterministic tape-reset or
schedule property required here.
