\paragraph{Result and strict status.}
TESTS-0002 left open a lower bound for a succinct multi-restriction service
after showing that explicit batch output is merely an interface cost.  This
run attacks the strongest representation class demanded there: source reread
and RECOMP.  The exact generic representation is the source itself together
with a fixed evaluator that constructs the requested residual and runs the
supplied exact SAT decider.  It has instance payload exactly $N$ bits; if the
decider is supplied as data rather than fixed, the payload is $N+|\langle
A\rangle|+O(1)$.

\textsf{SOURCE-PROGRAM-SERVICE1} is \status{PROVED/EXACT}.  Consequently any
version of \textsf{SUCCINCT-SERVICE-LB1} asserting superlinear description
size, or superlinear acquisition merely to possess a service representation,
over a class broad enough to include source plus program is
\status{FALSIFIED/RETIRED}.  The evaluator can be slow: with a hypothetical
$N^K$ SAT decider and residual length $N^a$, its exponent is at least $aK$
up to the declared simulation.  Thus the surviving joint acquisition/use
lower bound is not refuted; it is the original computation lower-bound
problem with its arbitrary exponent still present.  \textsf{SAT-MERGE-FORCING1},
a $K$-independent compiler, a matched time--space endpoint, and P versus NP
remain \status{OPEN}.

\section{Claim card and exact quantifiers}
Let $\mathrm{Enc}$ be a fixed injective encoding of proper 3-CNFs, and let
$N=|\mathrm{Enc}(F)|$.  Let $\mathcal Q_N$ be a uniformly decidable query
set.  A uniform residual compiler $R$ maps $(F,q)$ to a legal proper 3-CNF
$R(F,q)$ and preserves the intended query semantics.  Define
\[
 g_F^A(q)=A(R(F,q)).                                      \tag{1}
\]
The attacked description claim was, in its strongest useful form,
\[
 \forall A\ \exists^\infty F\quad
 \bigl[ A\text{ total uniform exact for }\SAT\bigr]
 \Longrightarrow
 \text{every representation of }g_F^A\text{ has }N^{1+\Omega(1)}
 \text{ size/acquisition}.                               \tag{2}
\]
Here ``every representation'' must include circuits, branching programs,
affine evaluators, retained source, source reread, and RECOMP, as required by
TESTS-0002.  The SAME\_REALIZATION ledger contains the exact source encoding,
query, residual compiler, evaluator code, SAT decider, acquisition, query
construction, query evaluation, output bit, and peak workspace.

The target is \emph{not} the false stronger assertion that every one-bit run
of $A(F)$ already answers all counterfactual queries.  That additional
necessity is precisely \textsf{SAT-MERGE-FORCING1} and remains open.

\section{Generic source-program representation}
\begin{theorem}[SOURCE-PROGRAM-SERVICE1 --- \status{PROVED/EXACT}]
Fix a total deterministic exact 3-SAT decider $A$ and a total uniform residual
compiler $R$.  For every source formula $F$, the indexed service (1) has a
representation
\[
 Q_{A,F}=\mathrm{Enc}(F)                                  \tag{3}
\]
of exactly $N$ instance bits and a fixed evaluator $E_{A,R}$ satisfying
\[
 E_{A,R}(Q_{A,F},q)=g_F^A(q)\qquad(\forall q\in\mathcal Q_N).  \tag{4}
\]
Copy-acquisition costs $O(N)$ time and $N+O(1)$ writable bits; a read-only
handle to the already-present source costs $O(1)$ handle bits in a model that
permits such handles, with every later source read charged.  If $R$ takes time
$C_R(N,|q|)$ and emits length at most $L_R(N,|q|)$, then
\[
 T_E(N,q)\le C_R(N,|q|)+T_A(L_R(N,|q|))+O(1),             \tag{5}
\]
apart from the explicitly declared universal-simulation overhead, and peak
space is bounded by the live source/residual/decider workspaces in that same
realization.  If $A$ is not fixed, a universal evaluator uses payload
$\mathrm{Enc}(F)\Vert\langle A\rangle$ of length
$N+|\langle A\rangle|+O(1)$.
\end{theorem}
\begin{proof}
The evaluator decodes $Q$ as $F$, computes $R(F,q)$, and runs $A$ on the
result.  Exactness is equation (1).  Storing $\mathrm{Enc}(F)$ verbatim proves
the size statement.  A sequential copy proves the copy-acquisition bound;
retaining the existing read-only source proves the handle alternative.
Equation (5) is direct sequential composition.  When a universal interpreter
is used, its fixed code is outside the instance payload and the code of $A$
is included explicitly.  No satisfiability assumption is used.
\end{proof}

The quantifier order matters.  For each fixed $A$, its evaluator code is a
constant as $N\to\infty$.  There is no assertion of one constant independent
of arbitrarily long program descriptions.  Conversely, placing $A$ in the
payload yields the exact additive $|\langle A\rangle|$ term rather than hiding
it.

\begin{corollary}[Description-only service lower bounds fail]
No family can have a superlinear lower bound on representation size or
representation-acquisition time against every class containing (3), unless
the service contract forbids retaining the source or charges a different
operation.  An exponentially long explicit truth table may still have an
$N+O_A(1)$-bit indexed description.
\end{corollary}

This corollary specializes the corpus's older \textsf{DESCRIPTION-CAP1},
which already observed that a continuation truth table is described by $F$
plus brute force.  The new contribution is the exact arbitrary-decider
evaluator, its acquisition/use split, and its application to the current
\textsf{SUCCINCT-SERVICE-LB1} repair.  It does not rename the older theorem.

\section{The arbitrary-exponent trilemma}
Suppose, counterfactually, $\SAT\in\Pclass$ through one fixed decider with
\[
 T_A(M)=M^{K+o(1)}.
\]
If query construction takes $N^{c+o(1)}$ time and
$L_R(N,|q|)=N^{a+o(1)}$, then (5) gives
\[
 T_E(N,q)=N^{\max\{c,aK\}+o(1)}.                           \tag{6}
\]
For ordinary linear-size restrictions $a=1$, the unknown exponent $K$ is
retained.  Polynomially many queries add their query-count exponent rather
than remove $K$.  This yields an exact trilemma.
\begin{enumerate}[leftmargin=2em]
\item If the service lower bound allows source plus arbitrary programs and
measures description/acquisition only, (3) falsifies it.
\item If it measures evaluation but permits arbitrary polynomial degree,
the representation is compatible with $\Pclass=\NPclass$ and gives no
contradiction.
\item If it requires a fixed degree independent of $K$, or forbids the
source/program representation, then the missing theorem is a cost-preserving
self-improvement/compiler forcing every $A$ into that narrower interface.
That is separation-strength and may not be assumed.
\end{enumerate}

Pippenger--Fischer give a model-specific corroborating transfer: $t$ steps
of a one-dimensional-tape transducer have a combinational-network simulation
of cost $O(t\log t)$ and depth $O(t)$~\cite{pf}.  Hardwiring $F$ therefore
turns a polynomial source-program evaluator into polynomial-size query
circuits in that declared model, but the degree still depends on $K$.
This is a \status{KNOWN THEOREM} transfer, not a uniform circuit constructor
for an arbitrary RAM and not a fixed-exponent improvement.

\section{Hostile controls and wrappers}
Affine/Tseitin instances admit Gaussian elimination, Horn admits forward
reasoning, 2-SAT admits implication-graph algorithms, and the path controls
have bounded treewidth.  Their source descriptions and restriction services
remain present but cheap, so semantic service richness cannot be a hardness
measure.  Independent products give exponentially many query coordinates
without defeating blockwise factorization.  COPY, redundant clauses,
padding, and alternate source encodings change $N$ and constants but not the
source-program escape.  INTERP composes the query decoder with a variable
renaming/complementation.  RECOMP is exactly the generic evaluator.  DELAY
can inflate the supplied program's trace without changing its service.

The one-bit decision output is decisive: ordinary SAT correctness requires
only $A(F)$.  A wrapper that requests all coordinates creates a new interface.
Until \textsf{SAT-MERGE-FORCING1} independently forces that interface, its
batch or random-access cost cannot be charged to the original one-bit run.

\section{Barrier and cross-domain transfer audit}
The source-program construction relativizes: with a fixed oracle $O$,
$E_{A^O,R}$ computes the residual and invokes $A^O$.  Baker--Gill--Solovay
therefore blocks promoting this black-box composition into a P-versus-NP
separation~\cite{bgs}.  Giving algebraic-extension access likewise does not
break the construction; no nonalgebrizing hinge is supplied~\cite{aw}.
No constructive, large, useful circuit property is proved, so Natural Proofs
is not the immediate failure, but any future general-circuit lower-bound
repair must audit its hypotheses~\cite{rr}.

Fortnow--Lipton--van Melkebeek--Viglas prove simultaneous SAT time--space
lower bounds in a declared general-purpose random-access model~\cite{flmv}.
That theorem is directly transferable only after the same evaluator is shown
to satisfy its simultaneous time and space premises and the encoding/reduction
costs are matched.  It does not bound description length and does not remove
an arbitrary $K$ from (6).

\begin{description}[leftmargin=3.2cm,style=nextline]
\item[THEOREM TRANSFER.] Pippenger--Fischer machine-to-network simulation for
its exact tape/network models.  Correspondence: query evaluator computation
to a hardwired-$F$ circuit.  Missing for the desired conclusion: a
$K$-independent size bound, uniform acquisition, and a matched RAM simulation.
\item[ANALOGY / CANDIDATE.] Cell-probe, VLSI, data-structure, and communication
lower bounds can constrain an indexed service only after its memory cells,
queries, preprocessing, and access operations are fixed.  The missing bridge
forces an arbitrary SAT decider into that interface.
\item[FAILED TRANSFER.] Output-size, restricted OBDD/DAG, physical routing,
or explicit-vector lower bounds do not constrain an unrestricted one-bit
uniform decider without the bridge.
\end{description}

\section{Post-quantum technique ledger}
The LWE lesson of external black-box extraction is an
\status{ANALOGY/CANDIDATE}: (4) is an exact external evaluator, but no
worst-case/average-case reduction or hardness amplification follows.
Collision entropy, Schur squares, quadratic-relation rank, Hilbert functions,
and syzygies do not obstruct storing the source and rerunning a program; as a
universal service-size transfer they are \status{FAILED TRANSFER} here unless
a new representation-independent evaluation theorem is proved.  Hash or
random-oracle binding is also a \status{FAILED TRANSFER} for an unconditional
separation.  Hidden algebraic structure remains exploitable by algorithms,
as the affine control demonstrates.

\section{STALE OR OVERSTATED CLAIMS FOUND}
The name \textsf{SUCCINCT-SERVICE-LB1} is too broad unless its representation
class and cost vector are explicit.  A size-only reading is false by (3); an
``acquisition plus use'' reading remains open but must state the number and
adaptivity of queries, allowed source rereads, preprocessing, amortization,
workspace, and whether the exponent may depend on $A$.  Calling the remaining
target representation-independent without including source plus program is
overstated.  No stale claim was silently promoted or deleted.

\section{Weakest repair and next exact target}
Replace the ambiguous service target by
\textsf{FORCED-JOINT-SERVICE-LB1}:
\begin{quote}
Fix one non-product clean-core family, one query distribution or adversarial
query protocol, and one ordinary random-access model.  Prove (i) SAT
correctness forces every total uniform exact decider, in the same charged
execution and before current-scale decision work, to support that service;
and (ii) even the representation $Q=(\mathrm{Enc}(F),\langle A\rangle)$ with
source reread, adaptive recomputation, batching, affine elimination, and
arbitrary preprocessing violates a simultaneous time--space bound whose
threshold is independent of $A$'s polynomial exponent $K$.
\end{quote}
Both conjuncts are \status{OPEN}.  If (ii) is proved unconditionally for all
polynomial $A$, it is already a genuine SAT lower bound; if (i) is omitted,
the wrapper has invented a counterfactual service.  P versus NP remains
\status{OPEN}.
