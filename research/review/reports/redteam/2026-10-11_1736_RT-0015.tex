\begin{abstract}
TESTS-0010 correctly proves that actual reached SAT-query scale is a gauge of
one program, not an extensional resource.  It suggests either an externally
fixed source compiler or minimization over equivalent implementations.  This
report red-teams the latter repair.  For a one-bit function $g$ computed by a
uniform polynomial-time SAT-oracle transducer, define its normalized query
scale as the infimum over all extensionally equivalent polynomial
transducers.  Under $P=NP$, $P^{\SAT}=P$, so an equivalent oracle-free
machine exists and the normalized scale is exactly zero.  Thus this semantic
infimum cannot be the positive resource that derives a contradiction from
$P=NP$.  Moreover, there is no total computable canonicalizer whose outputs
are equal exactly for extensionally equal clocked polynomial-time Boolean
programs: a direct halting reduction proves this even without SAT.  The first
statement is an exact conditional implication; the second is unconditional.
Neither bounds the ordinary runtime of the no-query replacement, whose
polynomial exponent remains arbitrary.  A bounded audit passed 270,556
checks.  The surviving repair is a source-specific, externally fixed,
fully charged compiler into a model-matched forbidden region.  P versus NP
remains open.
\end{abstract}

\section{Claim card and exact quantifiers}

Let $\Htwo$ be the duplicate-free proper Monotone $3$SAT-$(2,2)$ family in
the current synthesis, with canonical encoded bit length
$N=\Theta(n\log n)$.  The argument below applies to every binary input
language and therefore also to $\Htwo$.

An extensional SAT-oracle transducer is one uniform deterministic machine
$E^{\SAT}$ which, on every input $x$, halts in time $|x|^{O(1)}$, asks at most
$|x|^{O(1)}$ explicitly written SAT queries of polynomial length, and returns
one bit.  Let
\[
 q_E(N)=\max\bigl(2,\max\{|Q|:Q\text{ is reached by }E(x),\ |x|=N\}\bigr)
\]
and
\[
 \sigma(E)=\limsup_{N\to\infty}\frac{\log q_E(N)}{\log N}.
 \tag{1}
\]
The constant 2 makes an oracle-free program have scale zero.  For a Boolean
function $g$ define the semantic normalization
\[
 \underline\sigma(g)=
 \inf\{\sigma(E):E^{\SAT}(x)=g(x)\text{ for every }x,
 \ E^{\SAT}\text{ is a uniform polynomial transducer}\}.
 \tag{2}
\]
The target attacked here is
\[
 P=NP\quad\Longrightarrow\quad
 \exists g\in P^{\SAT}\ [\underline\sigma(g)>0],
 \tag{NS}
\]
or any universal clean-core lower bound that requires such positivity.
The exact quantifier prefix in the negation is
\[
 P=NP\quad\Longrightarrow\quad
 \forall g\in P^{\SAT}\ \exists B\in P\ \forall x:
 B(x)=g(x)\ \land\ B\text{ asks no SAT query}.
 \tag{3}
\]
The SAME\_REALIZATION object in (3) is the replacement program $B$, including
all source reads, work, space and its one-bit output.  Equation (3) does not
claim that $B$ has a favorable time--space exponent.

\section{The conditional collapse theorem}

\begin{theorem}[\texttt{PNP-QUERY-SCALE-COLLAPSE1}]
If $P=NP$, then for every Boolean function $g$ computed by a uniform
deterministic polynomial-time SAT-oracle transducer,
\[
 \underline\sigma(g)=0.
 \tag{4}
\]
In particular (4) holds for the SAT decision bit restricted to $\Htwo$.
\end{theorem}

\begin{proof}
Under $P=NP$, SAT has a fixed uniform deterministic polynomial-time decider
$A_0$.  Given a transducer $E^{\SAT}$ for $g$, replace each oracle call on an
explicitly written query $Q$ by the ordinary computation $A_0(Q)$.  The
number and lengths of queries are polynomial, so this composition is one
uniform deterministic polynomial-time ordinary machine $B$ with
$B(x)=E^{\SAT}(x)=g(x)$ for every $x$.  Machine $B$ asks no SAT queries, so
$q_B(N)=2$ and $\sigma(B)=0$.  Nonnegativity of (1) and the definition (2)
give $\underline\sigma(g)=0$.
\end{proof}

This theorem is stronger than deleting TESTS-0010's particular DEAD or
CANCEL shell.  It says that under the very hypothesis used by a contradiction
proof, the full extensional equivalence class contains an oracle-free
representative.  It is also deliberately weaker than a useful endpoint:
if $A_0$ runs in time $M^K$, then direct substitution may run in
$N^{b+aK+o(1)}$.  The unknown fixed exponent $K$ survives exactly as in the
project's polynomial-query composition ledger.  Zero query scale is not
near-linear time or sublinear space.

\begin{corollary}[Easy-family control]
If $g\in P$ unconditionally, then $\underline\sigma(g)=0$ without assuming
$P=NP$.  Hence Horn SAT, 2SAT, affine systems, bounded-treewidth SAT and every
other polynomial source island defeat a universal positive normalized-scale
claim immediately.
\end{corollary}

\section{No complete computable extensional canonicalizer}

One might try to make (2) effective by canonicalizing program code first.
The next theorem formalizes the obstruction anticipated by RED-0003 and the
static-normalizer trilemma of MODELBRIDGE-0010.

\begin{definition}[Complete polynomial-program canonicalizer]
Let $\mathcal P_{\rm clock}$ be a decidable syntax of clocked deterministic
programs, each carrying an explicit polynomial clock and returning one bit on
every binary string.  A complete extensional canonicalizer is a total
computable function $C:\mathcal P_{\rm clock}\to\{0,1\}^*$ such that
\[
 C(P)=C(Q)\quad\Longleftrightarrow\quad
 \forall x\in\{0,1\}^*\ P(x)=Q(x).
 \tag{5}
\]
\end{definition}

\begin{theorem}[\texttt{POLY-EXTENSIONAL-CANONIZER-NOGO1}]
No complete polynomial-program canonicalizer exists.
\end{theorem}

\begin{proof}
Suppose $C$ exists.  Given an arbitrary Turing machine $M$ and word $w$,
construct a clocked program $P_{M,w}$.  On input $x$ of length $n$, it
simulates $M(w)$ for $n$ steps and returns 1 iff the simulation halted within
those $n$ steps.  A standard universal simulation with an explicit
polynomial clock makes $P_{M,w}\in\mathcal P_{\rm clock}$.  Let $Z$ be the
clocked program that always returns 0.  Then
\[
 \forall x\ P_{M,w}(x)=Z(x)
 \quad\Longleftrightarrow\quad M(w)\text{ never halts}.
 \tag{6}
\]
Computing $C(P_{M,w})$ and $C(Z)$ and testing finite-string equality would
therefore decide whether $M(w)$ halts, contradicting undecidability of the
halting problem.
\end{proof}

The proof is a promised polynomial-time-program version of the semantic
undecidability phenomenon in Rice's theorem \cite{rice}.  It does not say
that every restricted normal form is impossible.  A finite automaton, bounded
circuit class, proof-carrying compiler IR, or declared wrapper monoid may have
an effective quotient.  Such a restricted quotient needs a separate coverage
theorem for arbitrary SAT implementations and must charge certificate
production, transport and checking.

There is also a crucial distinction between theorems.  The infimum (2) is a
well-defined semantic number even when no minimizing code can be found.
The first theorem makes that number zero under $P=NP$; the second blocks a
generic algorithm for producing complete canonical forms.  Neither theorem
uses the other.

\section{Hostile controls and one-bit output}

\paragraph{Easy semantic shortcuts.}
Horn closure, 2SAT strongly connected components, affine Gaussian
elimination and bounded-treewidth dynamic programming compute their one-bit
answers without a positive normalized SAT-query scale.  Hidden algebraic or
graph structure is an algorithmic advantage here, not a hardness resource.

\paragraph{Padding and alternate encodings.}
Polynomial padding can change the displayed exponent of one implementation,
and redundant clauses can change bytes without changing semantics.  Neither
operation removes the oracle-free representative from an extensional class.
Thus the zero in (4) is invariant under these presentation changes.

\paragraph{Wrappers and compact representations.}
DEAD and CANCEL generate irrelevant positive-scale calls; COPY and DELAY
alter size or time; INTERP and RECOMP alter trace and retention.  Complete
semantic minimization ignores all of them, but under $P=NP$ it also ignores
every necessary SAT call by replacing the whole program.  Compact circuits
or branching programs may represent particular source functions, but their
restricted size lower bounds do not constrain an arbitrary uniform SAT
machine without a transfer theorem.

\paragraph{One-bit contract.}
The output may be only $\SAT(F)$.  Requiring a compatibility table, proof,
witness, canonical trace or minimum program changes the output/interface.
No theorem here or in TESTS-0010 forces those objects to appear in every
one-bit execution.

\section{Barrier, uniformity and transfer audit}

Baker--Gill--Solovay construct relativized worlds with both equality and
separation, so a black-box relativizing query normalization cannot by itself
settle P versus NP \cite{bgs}.  Theorem 1 is an implication inside the
counterfactual $P=NP$; it does not provide a nonrelativizing hinge.  Theorem 2
is oracle-free computability theory and also does not separate the classes.
Low-degree extension access cannot restore a positive extensional query
scale after an ordinary no-query representative exists; this gives no escape
from the algebrization barrier \cite{aw}.  Natural Proofs is not directly
triggered because no constructive large property against general circuits is
proposed.

Nonuniform advice could name one representative per input length or encode
noncomputable semantic facts.  That is not the required one uniform
deterministic compiler; the advice, its uniform generation, and every access
must be charged.  Similarly, minimization over all codes is not acquisition.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{DIRECTLY TRANSFERABLE THEOREM.}
The direct halting reduction transfers exactly to complete canonicalization
of clocked polynomial-time programs.  FLMV transfers only after one ordinary
random-access SAT realization meets its simultaneous time--space hypotheses
\cite{flmv}; zero oracle-query scale does not meet them.
\item[] \textbf{USEFUL STRUCTURAL ANALOGY REQUIRING A NEW TRANSFER THEOREM.}
Certified compilers, abstract interpretation, bisimulation quotients, minimal
automata and LWE-style external extraction suggest restricted quotients or
black-box source compilers.  Coverage of every uniform SAT implementation,
uniform acquisition and endpoint bounds are missing.
\item[] \textbf{MISLEADING ANALOGY / FAILED TRANSFER.}
VLSI routing, physical locality, proof-system size, branching-program width,
Schur squares, quadratic-relation rank, Hilbert functions, syzygies, collision
entropy, special soundness and cryptographic binding do not compute a complete
program quotient or force arbitrary one-bit SAT work.
\end{description}

The post-quantum classification is ANALOGY/CANDIDATE only for external
black-box extraction and FAILED TRANSFER for every proposed algebraic repair
to complete program normalization.  No hardness, random-oracle or
collapse-binding assumption is admissible or used.

\section{STALE OR OVERSTATED CLAIMS FOUND}

Any statement that a semantic query-scale minimum remains a positive resource
under $P=NP$ is false.  Any statement that the minimum is automatically
computable by canonicalization is also false for complete polynomial-program
equivalence.  It would be equally overstated to say wrapper normalization in
every restricted representation is impossible, or to infer favorable time
and space from the zero-query replacement.  The safe surviving statement is
source-specific external compilation with every cost and endpoint exponent
proved directly.

\section{Smallest repair and precise handoff}

Do not minimize over all extensionally equivalent solver programs.  Fix an
external source transformation $\mathcal T$ and prove, under $P=NP$, that for
every input $F$ it constructs one ordinary SAT realization satisfying an
independently known forbidden simultaneous time--space bound.  The theorem
must charge source access, discovery, failed routes, normalization, query or
child construction, replay, reconstruction, output and peak workspace; it
must be uniform, hereditary where recursion is used, and independent of the
unknown polynomial exponent $K$.  Alternatively, restrict canonicalization
to a typed proof-carrying representation and prove a coverage compiler from
every relevant SAT implementation.  Both targets remain \OPEN{} and are
separation-strength.
