\begin{abstract}
Independent review accepts TESTS-0005's pre-output delay theorem in its
declared model.  Its proposed repair fixes a source/interface checkpoint
before any current-scale decision.  This report attacks the simplest
operationalization of that repair.  For every fixed checkpoint budget
$\tau(N)\le N^r$ and every exact polynomial-time decider $A$, a uniform
extensionally equivalent decider $D_r[A]$ can execute $N^{r+1}$
input-independent dummy transitions before invoking $A$.  Every trace-prefix
observer at the checkpoint sees the same dynamic prefix, independent of the
source and embedded implementation.  Any nontrivial checkpoint object must
therefore come from external source/code analysis, not from paid work in the
observed execution.  Waiting until the child begins or finishes instead costs
$N^{\max\{r+1,K\}+o(1)}$ for an $N^{K+o(1)}$ child.  This proves a restricted
prefix-delay trilemma, not an impossibility theorem for arbitrary white-box
normalization.  A bounded audit passed $16{,}736$ checks.  P versus NP remains
open.
\end{abstract}

\section{Claim card and exact target}

The clean core is the duplicate-free Monotone $3$SAT-$(2,2)$ family $\Htwo$
under a complete canonical indexed encoding of length $N=\Theta(n\log n)$.
The desired separation-strength target is
\[
 \forall A\ \forall d\ \forall N_0\ \exists F\in\Htwo:\quad
 |\operatorname{enc}(F)|\ge N_0
 \quad\land\quad T_A(F)>|\operatorname{enc}(F)|^d,       \tag{1}
\]
where $A$ ranges over total correct uniform deterministic deciders.  Statement
(1) is \OPEN and is not assumed.

The attacked claim is restricted and explicit.  A prefix compiler has a fixed
constant $r$ and may inspect the dynamic transition prefix of a supplied
decider through a source-fixed checkpoint $\tau(N)\le N^r$.  It may also read
the source and program text using separately charged local work.  The proposed
inference was that a useful object visible by this checkpoint certifies work
performed by every supplied SAT execution.  The SAME\_REALIZATION objects are
the source, supplied code, wrapper code, transition prefix, checkpoint state,
extracted object, all external analysis, and every local/source-access cost.

This model deliberately distinguishes dynamic observation from static program
analysis.  The theorem below closes only the former route.  A compiler that
parses, normalizes, or replaces arbitrary program text needs a separate
correctness and resource theorem.

\section{Polynomial prefix-delay theorem}

\begin{definition}[Delay shell]
For an integer $r\ge0$ and total deterministic machine $A$, define $D_r[A]$
on an $N$-bit source to execute exactly $N^{r+1}$ dummy transitions.  Those
transitions do not inspect source bits and do not execute a transition of
$A$.  The shell then simulates $A$ and returns its bit.
\end{definition}

\begin{theorem}[\texttt{FIXED-PREFIX-DELAY1}]
Let $A$ be a total correct uniform deterministic $3$SAT decider with
$T_A(N)\le N^{K+o(1)}$, and fix $r\ge0$.
Then:
\begin{enumerate}[label=(\roman*)]
\item $D_r[A]$ is total, correct, uniform, and computes exactly the same
one-bit language as $A$;
\item
\[
 T_{D_r[A]}(N)=N^{\max\{r+1,K\}+o(1)};                  \tag{2}
\]
\item for every checkpoint $\tau(N)\le N^r$, the projected dynamic trace
through $\tau(N)$ consists only of the common delay shell and is independent
of both $F$ and the embedded execution of $A$;
\item the same statement holds for any two embedded deciders $A,B$ inside
the identical shell.
\end{enumerate}
Consequently a trace-prefix extractor at that checkpoint receives no dynamic
evidence that the child execution acquired, retained, or used its output.
\end{theorem}

\begin{proof}
The shell changes no input and discards no child output, proving semantic
equivalence, totality, and correctness.  Its loop bound is computed uniformly
from $N$, so the wrapped machine is uniform.  The dummy phase and child phase
are sequential, giving
\[
 N^{r+1}+N^{K+o(1)}=N^{\max\{r+1,K\}+o(1)}.
\]
Because $N^r<N^{r+1}$ for $N\ge2$, no checkpoint transition reaches the
child.  By construction no dummy transition reads a source bit.  The dynamic
prefix is therefore the same common shell prefix for every source and every
embedded child.  This proves all four items.
\end{proof}

\begin{corollary}[Prefix-checkpoint trilemma]
A fixed-budget predecision compiler using the supplied solver has three
routes.
\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{Trace route.}  It observes only the bounded dynamic prefix;
Theorem 1 removes all child-dependent work from that prefix.
\item[] \textbf{External route.}  It derives the service by reading the source
or statically transforming the code; then the compiler's own acquisition,
normalization, validation, and output costs must be proved and cannot be
charged to the original child execution.
\item[] \textbf{Wait route.}  It waits for the shell or child; then (2) imports
the arbitrary delay exponent and, upon completion, the child exponent $K$.
\end{description}
This trilemma does not rule out a new static, cost-preserving compiler.  It
rules out fixed dynamic prefix observation as its justification.
\end{corollary}

The result is compatible with $P=NP$.  If $A$ is polynomial, so is $D_r[A]$.
No contradiction and no lower bound is obtained.  Closure of polynomial-time
programs under polynomial delay is elementary; Blum's axiomatic complexity
theory is relevant only as broader context that complexity depends on the
program and machine representation.  Blum's speedup theorem is not needed in
the proof and does not specialize automatically to SAT.

\section{Padding guard for fractional channels}

Strictly fractional query length must use an honest source scale.  Let an
$n$-bit semantic core be padded to length $N=\Theta(n^p)$ for a fixed $p>1$.
Recovering and querying the core has apparent length
\[
 n=\Theta(N^{1/p}),                                      \tag{3}
\]
which is strictly fractional in the padded $N$.  But merely scanning the
presented source costs $\Theta(N)=\Theta(n^p)$.  Therefore (3) does not yield
a faster algorithm for the original $n$-bit family.  The channel exponent,
local work, source normalization, and recursive descendants must all be
translated to the same unpadded realization.

This is the scale-laundering guard already present in the route manuscripts;
the present audit retains it because a checkpoint repair that advertises only
$a<1$ can otherwise pass vacuously on padded inputs.

\section{Independent review of TESTS-0005}

TESTS-0005's theorem is sound at its written scope.  A universal wrapper can
simulate a total exact decider, intercept its output bit, compute the two-pin
service with two further current-scale calls, and release the retained bit.
The order is genuinely post-decision and pre-output, and its bound
\[
 T_A(N)+2T_A(cN+O(1))+O(N)=N^{K+o(1)}
\]
charges the added work.  Correctness of the decider makes renaming covariance
exact and global complementation swaps the two pin coordinates.  Thus
\texttt{PREOUTPUT-SERVICE-GUARD1} is independently promoted to \EXACT.

The theorem does not prove that every source-defined checkpoint is movable.
The present result adds only that a fixed polynomial trace prefix cannot force
child-dependent work across delay-equivalent implementations.

\section{Barrier, wrapper, and transfer audit}

DEAD and COPY add optional or shared state; DELAY is the exact obstruction;
INTERP changes raw exposure; RECOMP avoids retention.  Horn propagation,
2SAT SCCs, Gaussian elimination for affine/Tseitin systems, bounded-treewidth
dynamic programming, and compact branching programs show that a checkpoint
object may be easy or omitted.  One-bit output does not require an explicit
service vector.

Theorem 1 relativizes verbatim: the shell delays the same $A^O$.  Algebraic
extension access can only strengthen an external compiler, so the theorem
exposes rather than crosses the relativization and algebrization barriers.
Li--Tell's 7 October 2026 plasticity simulations rely on explicit
range-avoidance hardness and derandomization assumptions; Huang--Li--Zhong's
range-avoidance equivalences fix the search object, circuit class, and
$\mathsf{FP}^{\mathsf{NP}}$ model.  Chen--Hu--Ren show that several circuit
lower-bound methods overcoming relativization still algebrize.  None supplies
an arbitrary-SAT checkpoint normalizer.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{THEOREM TRANSFER.}
Polynomial delay and the direct exponent ledger transfer exactly to the
declared deterministic machine model.  FLMV transfers only when one matched
machine satisfies its simultaneous time-space bounds.
\item[] \textbf{ANALOGY / CANDIDATE.}
Chronograms, online communication, control-theoretic observability cuts, and
VLSI latches enforce externally declared interfaces.  The missing theorem
compiles every static SAT decider into such an interface despite preprocessing,
rereading, recomputation, and arbitrary polynomial delays.
\item[] \textbf{FAILED TRANSFER.}
Physical time, a first visible answer register, trace-prefix state, and online
cut lower bounds do not constrain an unrestricted static SAT program without
that compiler.
\end{description}

For the post-quantum ledger, Schur-square, quadratic-relation, Hilbert-function,
and syzygy invariants are source-side objects and do not make a delayed child
execute before the checkpoint; they are \textbf{FAILED TRANSFER} for this
target.  LWE-style external extraction and special-soundness collision
extraction are \textbf{ANALOGY / CANDIDATE}; both still need an unconditional
cost-preserving compiler.  Cryptographic binding and random-oracle assumptions
remain inadmissible.
