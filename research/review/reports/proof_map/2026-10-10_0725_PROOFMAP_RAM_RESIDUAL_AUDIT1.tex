\paragraph{Status.} P versus NP remains OPEN. This is a scoped model audit, not an unrestricted SAT lower bound.
\section*{Recovered prior results}
BRTHRESH1 proves $2^{k-x}\le N^d$ iff $x\ge k-d\log_2N$ for the raw residual-enumeration interface. WRAPPED-SELFRED1 constructs an answer-preserving restriction path using $k+1$ SAT decision calls. The cost retains the unknown current-scale decider exponent. LB-0002 proves an $\Omega(r)$ clause-slot probe floor for a self-contained transporter and an $O(r)$ scan with $O(\log r)$ workspace; the proof relativizes.
\section*{New adversarial model}
In the clause-slot promise family, all-zero input and each one-hot variant differ in one designated slot. Every exact deterministic slot-probe algorithm must inspect all $r$ slots on the zero input. A direct scan uses $r$ probes. Thus the lower bound is tight and does not yield exponential runtime.
For the indexed Boolean-data task $f(z,i)=z_i$, the $2^k$ distinct semantic response rows are stored in a read-only source. A RAM answers each query by one indexed read, using $O(\log k)$ address bits. Consequently semantic multiplicity alone gives neither exponential time nor large writable workspace.
\section*{Precise surviving candidate}
For an explicit SAT family, fix a physical random-access machine, word width, input encoding, and same-execution query contract. Seek a bound on total unavoidable nonshareable information transfers across computation epochs, after charging source reads, caching, recomputation, and all ancestor/transient state. The required transfer from a forced interface to arbitrary SAT deciders is OPEN. A circuit or resolution lower bound alone cannot establish it.
\section*{Experiment}
A bounded Python harness tested $r=1,\ldots,16$ one-hot indistinguishability and indexed-access controls for $k=1,\ldots,16$ (32 parameter rows). All assertions passed. Finite tests are COMPUTATIONAL only.
