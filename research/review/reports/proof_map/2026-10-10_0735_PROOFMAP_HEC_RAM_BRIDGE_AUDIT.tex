\section*{Exact bypass}
For a read-only static $K$-bit input $X$ and a future index $j$,
an ordinary random-access algorithm stores no copy of $X$,
and after seeing $j$ reads $X_j$ with one input probe and
$O(\log K)$ address work. The same task without reread
requires $K$ state bits to answer every possible future index,
or at least $K-r$ in the worst fiber with $r$ bits of free side information.
Thus the no-reread state bound does not transfer to unrestricted static RAM.
\section*{Hostile controls and interpretation}
Source rereading, direct semantic SAT calls, memoization and
preprocessing invalidate any automatic assertion that each distinct
continuation class requires a new executed Boolean operation.
Fresh randomness and delayed permutations enforce order, not
superpolynomial post-revelation work. A literal $K$-bit payload has
encoded input length at least $K$, so its information bound is at most
linear in the input size. A succinct payload requires explicit
decompression and query-generation accounting.
\section*{Experiment}
Fourteen parameter cases, $K=1,\ldots,10,16,64,256,1024$,
with exhaustive INDEX semantics for $K\le8$.
All assertions passed. This is COMPUTATIONAL validation, not a
new asymptotic lower bound.
\section*{Literature and transfer}
Pătraşcu--Demaine dynamic cell-probe tradeoffs, online
communication bounds, and pebbling results are model-specific
and cannot be promoted to static SAT RAM bounds without a
source-visible, same-realization compiler. The previously proved
LB-0002 clause-slot probe floor is linear-sharp and relativizing.

that preserves input encoding, permits full rereading and arbitrary
