\section*{Selected dependency and exact quantifiers}
The selected dependency is the smallest correction to acquisition, not the
separation-equivalent all-input successor.  Fix one deterministic
random-access verifier $V$, complete encoded input $x$ of length $M$, and a
computable visitation bound $b(M)$.  Every invocation of $V(x,y)$ is specified
to begin with blank writable verifier tapes; $x$ is shared read-only; the
witness $y$ has length at most $w(M)$; the invocation takes at most $q(M)$
steps and uses at most $s(M)$ writable cells.  The enumerator, verifier,
counter, reset routine and output are one declared realization.  Input probes,
address generation, clearing, verification and peak workspace are charged.

\begin{theorem}[Reset-aware exhaustive acquisition]
Assume a fixed number of verifier work tapes and that every writable verifier
cell visited on inputs of encoded length $M$ has address at most $b(M)$.
Before each candidate, explicitly write blank to every such cell, at cost
$r(M)$.  Lexicographic enumeration of all witnesses of length at most $w(M)$
returns the first accepted witness, if one exists, in
\[
 O\!\left((2^{w(M)+1}-1)
   (q(M)+r(M)+w(M)+\log(M+2))+w(M)\right)
\]
time and $O(s(M)+w(M)+\log(M+2))$ writable space.  In a literal binary-address
implementation one may conservatively take
$r(M)=O(b(M)\log(b(M)+2))$.
\end{theorem}
\begin{proof}
The candidate set has exactly $2^{w+1}-1$ strings.  Clearing the known visited
prefix restores precisely the blank writable start condition before each
simulation; read-only $x$ is never copied.  Thus each invocation has the same
semantics as an independent run of $V$.  Candidate maintenance and address
generation cost $O(w+\log(M+2))$ per trial.  The verifier work tapes are reused,
not multiplied across trials, so peak writable space is additive.  Generating
each binary address separately gives the conservative reset bound.
\end{proof}

\begin{corollary}
If $w(M)=\kappa\log_2M+o(\log M)$,
$q(M)=M^{v+o(1)}$, and $b(M)\le q(M)$, then the theorem's time is
$M^{\kappa+v+o(1)}$ and its writable space is
$O(s+w+\log M)$.  The conclusion fails to follow from this proof if no
computable $b$ is supplied or if implicit-child access/reset costs exceed the
declared ledger.
\end{corollary}

\section*{Falsification and bounded test}
The hostile verifier reads one initially blank cell, writes one, and accepts a
late target only when the old value was blank.  Persistent work state loses
the target; explicit reset finds it.  The new bounded test passed 18 dirty-state
counterexamples, 18 reset controls, 108 exact-integer exponent rows, and one
invalid $b>q$ premise control in under one second.  The program uses a
25-second cooperative alarm and a 30-second shell limit.  This finite test
checks implementation bookkeeping; it does not establish an asymptotic lower
bound.
