\paragraph{Executive result and status.}
A minimal DAG can yield exact time, space, or size lower bounds after the DAG
model and query interface are fixed.  It does not by itself lower-bound an
arbitrary SAT decider.  This run gives an exact separating family.  The
treewidth-one 2-CNF
\[
 E_n=\bigwedge_{i=1}^{n}
 ((\neg x_i\vee y_i)\wedge(x_i\vee\neg y_i))
\]
has a reduced ordered BDD with exactly $3(2^n-1)$ nonterminal nodes under the
grouped order $x_1,\ldots,x_n,y_1,\ldots,y_n$, but exactly $3n$ nodes under
the interleaved order $x_1,y_1,\ldots,x_n,y_n$.  As a fixed SAT instance it
is satisfiable, so its decision-only zero-input DAG is one constant node.

Therefore the free implication
\[
 \text{large minimal DAG in a declared representation}
 \Longrightarrow
 \text{large cost for every exact SAT decider}
\]
is \textbf{FALSIFIED/RETIRED}.  Pebbling, OBDD, d-DNNF, resolution, treewidth
and communication lower bounds retain their declared restricted meanings.
The missing theorem is an unavoidable-interface compiler from every uniform
deterministic SAT decider to the same representation, with acquisition,
access, replay and simultaneous workspace charged.  P versus NP remains
\textbf{OPEN}.  The proofs are human-readable, not proof-assistant checked.

\section{Exact target and quantifier prefix}
Let $\mathcal A$ be the class of total uniform deterministic random-access
SAT deciders on canonical CNF encodings of complete bit length $N$.  A
candidate reduction--DAG frontier chooses a compiler $R$, constructs a DAG
$G_R(F)$, retains $S_R(F)$ bits, and evaluates it with at most $S-S_R(F)$
additional storage.  Write
\[
 \mathcal F_F(S)=
 \inf_{R\in\mathcal R}
 \left(
   \operatorname{Acq}(F,R)+P_{G_R(F)}(S-S_R(F))
 \right),                                                   \tag{1}
\]
where $P_G(s)$ is the minimum declared pebbling/evaluation time with space
$s$.

For (1) to prove a lower bound for arbitrary SAT algorithms, the required
quantifier prefix is not merely ``for every generated DAG.''  It is
\[
 \forall A\in\mathcal A\ \exists\Gamma_A\ \forall F:
 \begin{cases}
 G_{\Gamma_A(F)}\text{ is in the exact lower-bound DAG model},\\
 \Gamma_A\text{ is extracted from the same execution of }A,\\
 \operatorname{cost}(\Gamma_A)+P_G\le
       \operatorname{cost}(A)\,N^{o(1)},\\
 \text{source, output, access, replay and peak workspace are charged.}
 \end{cases}                                                \tag{2}
\]
The inequality direction and overhead must be strong enough that a lower
bound on $G$ transfers back to $A$.  If $A$ is only assumed polynomial with
unknown exponent $K$, a P-vs-NP contradiction additionally needs a
model-matched contraction that removes $K$ or lands directly in a forbidden
time--space region.  Statement (2), called \textsf{DAG-ACQUIRE1} below, is
\textbf{OPEN}.

The SAME\_REALIZATION objects are $A$'s actual execution, the compiler
$\Gamma_A$, the produced DAG, its local accessor, the pebbling schedule and
all retained/transient storage.  A DAG built independently from $F$ or from
the already known answer is not the same realization.

\section{Decision-only DAG triviality}
\begin{lemma}[DECISION-DAG-TRIVIALITY1, PROVED/EXACT]
For every language $L$ and fixed input $z$, the minimum zero-input Boolean
DAG whose output is $L(z)$ has at most one constant node.  Hence a per-instance
decision-DAG size lower bound greater than one is false unless the interface
requires additional inputs or queries.
\end{lemma}
\begin{proof}
Use the constant node labelled by the bit $L(z)$.
\end{proof}

The lemma is nonuniform and existential.  It does not provide an algorithm
that discovers $L(z)$.  It shows instead that the object being minimized must
be a length-indexed function, uniform execution, or independently justified
multi-query representation.  Otherwise the minimum forgets the very
computation whose cost is supposed to be bounded.

If the class $\mathcal R$ in (1) contains the plan ``run $A(F)$ and emit its
constant answer DAG,'' then
\[
 \mathcal F_F(S)\le T_A(F)+O(1).
\]
Any lower bound proved through this plan is merely a lower bound on $A$
written into the acquisition term.  If the plan is excluded by demanding a
source-first answer-oblivious compiler, then (1) is a legitimate restricted
model but no longer quantifies over all SAT algorithms without (2).

\section{An exact OBDD order separation on an easy clean core}
The formula $E_n$ above is a conjunction of independent equivalences.  Its
primal graph is a matching, so it has treewidth one.  It is 2-CNF, is Horn
after treating each implication separately, and is solvable by the all-zero
assignment.  It is therefore a required hostile control for a universal
clean-core claim.

\begin{theorem}[OBDD-ORDER-SEPARATION1, PROVED/EXACT]
The reduced OBDD for the equality function represented by $E_n$ has exactly
$3(2^n-1)$ nonterminal nodes in grouped variable order and exactly $3n$
nonterminal nodes in interleaved order.
\end{theorem}
\begin{proof}
In grouped order, after assigning the first $i$ variables $x_1,\ldots,x_i$,
the $2^i$ prefixes induce distinct remaining functions, giving
$1+2+\cdots+2^{n-1}=2^n-1$ $x$-nodes.  Once all $x$ values are fixed, the
remaining function tests whether $y$ equals one specified $n$-bit word.  At
successive $y$ levels there are $2^n,2^{n-1},\ldots,2$ distinct nonterminal
nodes, totaling $2^{n+1}-2$.  Reduction cannot merge nodes representing
different residual functions.  The sum is $3(2^n-1)$.

In interleaved order, each pair contributes one $x_i$ node and two distinct
$y_i$ nodes requiring $y_i=0$ or $y_i=1$; every mismatch goes to the zero
terminal and every match continues.  Thus there are exactly three nodes per
pair, for $3n$ total.
\end{proof}

Variable complementation gives the affine relation $y=x\oplus1^n$ with the
same sizes.  Duplicate clauses, DEAD subgraphs and COPY/DELAY/RECOMP wrappers
change a syntax or implementation without changing the canonical Boolean
function for a fixed order.  Reordering variables changes the OBDD model and
can change size exponentially.  This is why a ``minimal DAG'' must state
whether minimization is over nodes, orders, representations, or physical
implementations.

\section{The $2^k/2^x$ normalization}
If a declared DAG has $D$ reusable residual states, defining
\[
 x_{\rm DAG}=k-\log_2 D
 \quad\text{gives}\quad
 2^{k-x_{\rm DAG}}=D.                                      \tag{3}
\]
Equation (3) is an exact normalization, not a runtime theorem.  A DAG node
may stand for exponentially many assignments, its acquisition may dominate
evaluation, and a different representation may have a different $D$.
For grouped equality, $D=3(2^n-1)$ is exponential even though interleaved
OBDD size is $3n$ and fixed-instance SAT decision size is one.  Therefore
neither $D$ nor $x_{\rm DAG}$ is representation-invariant computational
state.

A restricted reduction-versus-solving theorem may posit an acquisition law
$A(x)$ and residual cost $2^{k-x}$.  For example,
\[
 A(x)=2^{\alpha x},\qquad
 T(x)=2^{\alpha x}+2^{k-x}
\]
is minimized near $x=k/(1+\alpha)$ and yields exponential cost within that
architecture.  The acquisition law and the claim that every solver uses the
architecture are the load-bearing premises.  They are not consequences of
(3).

\section{Primary literature and exact transfer classification}
Bryant's reduced ordered BDDs are canonical once the variable order is fixed,
and may require exponential size in the worst case \cite{bryant}.  This is a
\textbf{THEOREM TRANSFER} to fixed-order OBDD size and manipulation.  It is a
\textbf{FAILED TRANSFER} to unrestricted SAT time without (2).

Darwiche's DNNF compilation makes several queries tractable after compilation
and provides structure-sensitive compilation guarantees \cite{darwiche}.
This is an exact representation theorem.  A large d-DNNF or expensive
compiler is not a one-bit SAT lower bound because a SAT decider need not
support the compiled query set.

Classical pebbling work proves genuine time--space tradeoffs for evaluating a
fixed DAG \cite{tarjan}.  The object correspondence is a stored intermediate
value as a pebble and recomputation as repeated pebbling.  The missing bridge
is that an arbitrary SAT computation must evaluate the selected DAG rather
than another circuit, algorithm, or semantic shortcut.  Thus pebbling is a
\textbf{THEOREM TRANSFER} only after a faithful execution-to-DAG map, and an
\textbf{ANALOGY/CANDIDATE} before it.

Samer and Szeider give fixed-parameter algorithms for model counting using
incidence treewidth \cite{samerszeider}.  Lokshtanov--Marx--Saurabh obtain
tight treewidth-base lower bounds for several graph problems under SETH
\cite{lms}.  These results validate exponential-in-width algorithms and
conditional optimality in their declared parameterized models.  SETH-based
lower bounds cannot be inserted into an unconditional P-vs-NP proof, and
bounded-treewidth SAT remains an easy hostile control.

The new RT-0003 audit proves a stronger local warning: even compatibility
rank $2^n$ coexists with $O(n)$ unrestricted Boolean circuits on equality,
Horn subset, affine complement and treewidth-one products.  Natural Proofs,
relativization and algebrization therefore remain active barrier checks for
any proposed positive general-circuit property.  The present negative
counterexample relativizes and survives algebraic-oracle replacement; it is
not the missing hinge.

\section{P=NP consequence audit}
Assume $P=NP$ and fix the resulting uniform polynomial-time SAT decider $A$.
Then decide-then-emit constructs a constant answer DAG in $T_A(N)$ time, and
standard simulation gives polynomial-size uniform Boolean circuits for the
length-indexed SAT function.  P=NP does not imply that every fixed-order OBDD,
d-DNNF, resolution proof, or selected residual DAG is polynomial size; those
objects answer different or richer interfaces.  Conversely, a
superpolynomial general-circuit lower bound for $\SAT_N$ would already give
$\SAT\notin\mathsf{P/poly}$ and hence P$\ne$NP.  It cannot be assumed as a
premise inside the contradiction.

To derive an unconditional contradiction from P=NP, the project still needs
one of two model-matched mechanisms:
\begin{description}
\item[] a charged transformation taking the unknown exponent $K$ to a
strictly smaller exponent and repeatable to a known forbidden endpoint; or
\item[] a direct theorem that every P=NP decider yields an ordinary-machine
realization inside a known unconditional time--space lower-bound region.
\end{description}
Minimal DAG size supplies neither mechanism without \textsf{DAG-ACQUIRE1}.

\section{STALE OR OVERSTATED CLAIMS FOUND}
The project documents already label the general DAG transfer OPEN.  The
phrase ``minimal DAG'' remains under-specified unless it names the function
interface, variable order, representation language, reduction rules and
uniform acquisition process.  Any current or future claim lacking these
fields should be read as a restricted-model candidate, not a lower bound for
SAT.

\paragraph{Highest-value target and peer handoffs.}
The single target is \textsf{DAG-ACQUIRE1}: for a nontrivial length-indexed
query interface independently forced by SAT correctness, prove or falsify a
uniform same-execution transformation from every SAT decider to a DAG whose
pebbling cost transfers back with endpoint-compatible overhead.
MODEL\_BRIDGE should attempt the compiler under P=NP without current-scale
calls.  LOWER\_BOUND should state a fixed-DAG theorem and identify the exact
line needing inevitability.  COST\_CERTIFICATES should charge compilation,
order search, local access, replay and peak storage.  REDTEAM should test
direct decision, interleaved order, affine elimination, padding, and
INTERP/RECOMP.  Until this target and a model-matched lower bound are proved,
the arbitrary-algorithm arrow and P versus NP remain \textbf{OPEN}.
