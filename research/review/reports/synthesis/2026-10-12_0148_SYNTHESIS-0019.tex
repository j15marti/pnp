\begin{abstract}
The latest specialist cycle closes the proposed unpointed fork quotient.
Replacement covariance removes implementation identity; full invariance under
independent satisfiable padding, together with disjoint-union commutativity,
then removes source identity.  Hence every such quotient is constant on the
satisfiable clean-core domain.  Pointing the padded source by an injection
\(\iota_F:F\hookrightarrow F\sqcup G\) avoids this collapse only by carrying
external provenance; it does not show that an arbitrary one-bit SAT decider
exposes that pointer.  If the remaining pointed fork is a total polynomially
balanced polynomial-time relation, then under \(P=NP\) it is searchable from
the source.  The missing step is therefore one model-matched ordinary-machine
forbidden endpoint, not semantic multiplicity.  P versus NP remains \OPEN.
\end{abstract}

\begin{theorem}[\texttt{WRAPPER-PADDING-QUOTIENT-COLLAPSE1} --- \EXACT]
Assume:
\begin{enumerate}[leftmargin=1.7em]
\item \textbf{replacement covariance:} for all extensionally equivalent
deterministic exact implementations \(A,B\in\mathcal D\) and all
\(F\in\mathcal S\), \(q(A,F)=q(B,F)\);
\item \textbf{full unpointed padding invariance:} for all
\(A\in\mathcal D\) and \(F,G\in\mathcal S\),
\(q(A,F\sqcup G)=q(A,F)\);
\item \textbf{isomorphism invariance:} canonical variable renaming and
component permutation do not change \(q\).
\end{enumerate}
Then \(q\) is constant on \(\mathcal D\times\mathcal S\).
\end{theorem}

\begin{proof}
Replacement covariance makes \(q(A,F)\) independent of the implementation
for each fixed \(F\); write it as \(r(F)\).  For arbitrary
\(F,G\in\mathcal S\), padding invariance and commutative isomorphism give
\[
 r(F)=r(F\sqcup G)=r(G\sqcup F)=r(G).
\]
Thus \(r\), hence \(q\), is constant.  No runtime inference is used.
\end{proof}

The theorem composes FORKFACTOR1's implementation factorization with
PADQUOT1's source collapse.  The two-line composition is new to this
synthesis; the ingredients are adopted, not re-claimed as new.

\begin{lemma}[Pointed escape and conditional search]
Replacing the second premise by invariance of a pointed pair
\((F\sqcup G,\iota_F)\) avoids the commutativity step only because
\(\iota_F\) distinguishes the retained source.  This pointer is compiler
provenance.  If the resulting fork relation is polynomially balanced,
polynomial-time decidable, and total on the promise, then under \(P=NP\) its
lexicographically first member is computable in polynomial time.
\end{lemma}
\begin{proof}
Swapping the components changes which injection is designated, so the
unpointed equality no longer follows.  Nothing in a one-bit answer supplies
the injection; it is part of the enriched input or compiler state.  For the
second claim, prefix extendability is in NP.  Under \(P=NP\), polynomially
many prefix decisions recover the first relation member.
\end{proof}

\section{Falsification and finite audit}
\texttt{NONTRIVIAL-UNPOINTED-FORK-QUOTIENT1} is \RETIRED.  Raw fork count,

shows that \(k\) independent paired-\(K_{3,3}\) padding blocks multiply
canonical openings by \(2^k\) while preserving the original decision and

The deterministic audit instantiated 12 semantic sources from H22, Horn,
affine, 2SAT, bounded-treewidth, and independent-product controls; three

class; the pointed version retained 12 root classes; wrapper-sensitive traces
failed covariance as expected; and padding changed raw opening counts from
1 to 256.  All assertions passed.  This evidence is \COMP, exhaustive only
on the declared finite domain, and supplies no asymptotic lower bound.
