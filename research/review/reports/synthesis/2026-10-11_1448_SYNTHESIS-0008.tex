\begin{abstract}
Four successive clean-core constructions now give easy canonical subclasses
with high treewidth or compatibility rank, surviving disconnected, connected,
paired, and nonpaired repairs.  This report extracts their common exact
quantifier obstruction.  If a language $L$ is constant on an infinite set
$S$ recognized in time $r(N)$, then every total exact decider $A$ has a
uniform exact guard wrapper that returns the constant on $S$ and runs $A$
elsewhere.  Its cost is $O(r(N))$ on every input of $S$.  Hence no
formula-intrinsic property containing such an island can by itself imply a
super-$r(N)$ pointwise cost for every decider.  This retires an entire
unqualified structural-necessity schema, but not the worst-case target
$\forall A\,\forall d\,\forall N_0\,\exists F$.  Lynch complexity cores do
not repair the argument: their existence assumes the language is already
outside P.  The finite audit exhaustively checked all 256 languages on an
eight-point universe, all 12,610 nonempty monochromatic subsets, and six
wrapper styles (605,280 agreement checks, zero failures).  The single
concrete external target is now the OPEN bit-local FLMV first leg into
Monotone 3-Sat*-(2,2); the arbitrary-exponent bootstrap, barrier crossings,
and P versus NP remain open.
\end{abstract}

\section{Exact quantifier theorem}

\begin{theorem}[\texttt{RECOGNIZABLE-ISLAND-BARRIER1}]
Let $L\subseteq\{0,1\}^*$ be any decidable language.  Let
$S\subseteq\{0,1\}^*$ be uniformly recognizable by $R$ in time $r(N)$ and
space $s(N)$, and suppose there is $b\in\{0,1\}$ such that
\[
 \forall x\in S,\qquad \mathbf 1_L(x)=b.                 \tag{1}
\]
For every total uniform exact decider $A$ for $L$, the program
\[
 A^{S}(x)=
 \begin{cases}
 b,&R(x)=1,\\
 A(x),&R(x)=0
 \end{cases}                                             \tag{2}
\]
is a total uniform exact decider for $L$.  On every $x\in S$ it uses
$O(r(|x|))$ time and $O(s(|x|)+\log |x|)$ writable space.  If $R$ and $A$
are polynomial-time, so is $A^S$.
\end{theorem}
\begin{proof}
If $R(x)=1$, then $x\in S$ and (1) makes the first branch correct.  If
$R(x)=0$, exactness follows from $A$.  Both branches halt.  On $S$ the
fallback is never invoked, giving the stated resource bounds.  The source,
recognizer, branch, fallback, and output are parts of one actual program, so
no foreign-execution cost is imported.
\end{proof}

\begin{corollary}[Pointwise structural schema fails]
Let $\mathcal P$ be any formula property containing an infinite island $S$
as above.  For any $f(N)=\omega(r(N))$, the implication
\[
 \forall F\,[\mathcal P(F)\Rightarrow
   \forall A\in\mathrm{Dec}(L),\ T_A(F)\ge f(|F|)]       \tag{3}
\]
is false.  If the quantifier over $A$ is restricted to polynomial deciders,
the same conclusion holds under the contradiction hypothesis $L\in P$.
\end{corollary}

The theorem does \emph{not} refute the worst-case target
\[
\tag{UCORE-TIME1}
 \forall A\ \forall d\ \forall N_0\ \exists F\in\Htwo:
 |\operatorname{enc}F|\ge N_0\ \land\
 T_A(\operatorname{enc}F)>|\operatorname{enc}F|^d.
\]
The quantifiers have changed: one easy island defeats ``every formula with
property $\mathcal P$ is hard for every decider,'' but it cannot defeat
``every decider has some hard formula.''  UCORE-TIME1 remains \OPEN.

\section{Relation to complexity cores and barriers}

Lynch proves that if a recursive language is not in P, then it has an
infinite recursive complexity core on which every decider exceeds every
polynomial almost everywhere \cite{lynch}.  This is a direct theorem in its
declared model, but using it for SAT would assume the desired conclusion
$\SAT\notin P$.  The present theorem gives the complementary guard: no
uniformly polynomial-time recognizable monochromatic island can itself be a
Lynch polynomial complexity core, because (2) constructs a decider that is
polynomial on every member.  Complexity-core language is therefore not an
unconditional bridge from clean-core structure to P versus NP.

Williams' SAT time--space lower bound is model matched and explicitly
transfers to problems with simultaneous quasi-linear, polylog-space,
bit-local reductions \cite{williams}.  It is an
\textbf{EXACT OBJECT/THEOREM TRANSFER} once that reduction exists.  D\"ocker
supplies the H22 NP-completeness theorem and fixed enforcer
\cite{doecker}; MODELBRIDGE-0012 converts the final enforcer leg into a
bit-local linear-size map, but the FLMV-source first leg remains open.

VLSI routing congestion, distributed cuts, control observability, pebbling,
proof space, Schur squares, quadratic relation spaces, Hilbert functions,
syzygies, graded Betti numbers, and collision entropy are
\textbf{ANALOGY/CANDIDATE} unless an exact object correspondence and an
arbitrary-decider SAME\_REALIZATION compiler are proved.  Importing their
lower bounds directly is a \textbf{FAILED TRANSFER}.  LWE-style external
reduction architecture is useful precisely because it avoids internal
materialization claims, but no unconditional NP worst-case/average-case
bridge is supplied.  Cryptographic binding and random-oracle assumptions
remain inadmissible.

The wrapper theorem relativizes: an oracle is forwarded only to the
off-island fallback.  It also survives algebraic-oracle forwarding.  Thus it
identifies no nonrelativizing or nonalgebrizing hinge; Baker--Gill--Solovay
and Aaronson--Wigderson remain barriers \cite{bgs,aw}.  Natural Proofs is not
the immediate hinge because no general-circuit property is constructed
\cite{rr}.

\section{Shortest surviving chain and single target}

The structurally honest chain is now
\[
 \text{FLMV source}
 \xrightarrow[\OPEN]{\substack{\text{bit-local first leg}\\
                               \texttt{MONOTONE22STAR1}}}
 \mathcal M^*_{2,2}
 \xrightarrow[\EXACT]{\texttt{FIXED-BLOCK-H22-LOCALIZER1}}
 \Htwo
 \xrightarrow[\OPEN]{\text{favorable endpoint or bootstrap}}
 \text{same-model contradiction}.                         \tag{4}
\]
The middle leg has linear encoded size and polylogarithmic bit access.  The
first leg must start from the exact FLMV nondeterministic-linear-time source,
produce $N\log^{O(1)}N$ encoded length, and support every output bit in
$\log^{O(1)}N$ time and $O(\log N)$ workspace.  This is the single concrete
next target: it is externally defined and survives DIRECT/RECOMP wrappers.
Closing it would establish a quantitative H22 endpoint transfer, not P
versus NP by itself.

The final arrow still needs either an independently favorable H22 algorithm
or a nonvacuous transformation from an arbitrary polynomial exponent $K$ to
a forbidden simultaneous time--space pair.  RT-0011 shows that an extensional
compiler directly into the forbidden class is separation-equivalent.  No
wrapper-covariant intensional premise, nonrelativizing hinge, or
nonalgebrizing hinge is known.  Those arrows, UCORE-TIME1, and P versus NP
remain \OPEN.
