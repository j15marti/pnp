\begin{abstract}
TESTS-0011 proves that the declared child-preserving typed wrapper grammar
has one orbit per terminal implementation.  That theorem is correct and is
independently accepted.  This report attacks the proposed richer repair:
allow a core-changing compiler whose outputs vary covariantly but are
equivalent in a typed or observational quotient.

The repair has no implementation-sensitive invariant middle.  If
\(X(W(A),F)\) is equivalent to \(X(A,F)\) on every transformation edge,
then its equivalence class is constant on each weak component.  Universal
connected coverage makes that class a function of the source \(F\) alone.
Every resource that respects the declared equivalence therefore also factors
through the source.  A resource that does not respect the equivalence cannot
be transferred by covariance; DELAY gives an exact counterexample because
semantics are unchanged while time is arbitrary.

This quotient statement is \EXACT{} but not mathematically new: it is the
equivalence-relation formulation already implicit in LB-0011 and
MODELBRIDGE-0016, now reconciled with TESTS-0011 and RT-0015.  Moreover,
if the repaired compiler is required to output a SAT decider in an
unconditionally forbidden FLMV resource class, its existence implication is
logically equivalent to \(\SAT\notin P\).  Thus
\texttt{TYPED-COMPILER-AS-INTERMEDIATE1} is \RETIRED.  The favorable
source compiler itself remains \OPEN{} and separation-strength.  A bounded
audit passed 1,353,627 graph labelings, 1,536 semantic checks, affine and
easy-family controls, and 256 cost-noninvariance witnesses.  P versus NP
remains open.
\end{abstract}

\section{Claim card and exact quantifiers}
Use the current duplicate-free proper Monotone \(3\SAT\)-(2,2) clean core
\(\mathcal H_{2,2}\).  If \(F\) has \(n\) variables, its canonical
fixed-width indexed encoding has
\[
 N=|\operatorname{enc}(F)|=\Theta(n\log n).
\]
Writing \(F=C_1\wedge\cdots\wedge C_m\), define
\[
 H(F)_{\alpha,j}=1\quad\Longleftrightarrow\quad\alpha\models C_j.
\]
SAT asks only whether \(H(F)\) has an all-one row.  No one-bit decider is
required to expose this matrix or any chosen representative.

Let \(\mathcal P\) be program codes and \(\mathcal W\) total program
transformations.  Let \(X:\mathcal P\times\mathcal F\to\mathcal O\)
be a compiler/extractor output and let \(\simeq\) be a declared typed,
observational or representation equivalence on \(\mathcal O\).  The
attacked repair has the exact prefix
\[
 \forall W\in\mathcal W\ \forall A\in\mathcal P\ \forall F:
 X(W(A),F)\simeq X(A,F),
 \tag{COV}
\]
together with connected coverage of the relevant \(\PolySAT\) programs.
The desired inference is that an implementation-sensitive resource
\(R(X(A,F))\) is nevertheless universal and uniformly bounded.

The SAME\_REALIZATION objects are the actual source \(F\), program
\(A\), transformed program \(W(A)\), compiler outputs, and the machine
whose time and space are claimed.  Quotient equality cannot silently replace
one realization by another.

\section{Exact quotient theorem}
\begin{definition}[Transformation graph and resource compatibility]
Put an undirected edge between \(A\) and \(W(A)\) for every declared
transformation.  A resource map \(R:\mathcal O\to\mathcal R\) respects
\(\simeq\) when
\[
 o\simeq o'\Longrightarrow R(o)=R(o').
 \tag{1}
\]
\end{definition}

\begin{theorem}[\texttt{QUOTIENT-COVARIANCE-FACTOR1}]
Assume (COV).  For every fixed \(F\), the quotient class
\([X(A,F)]_{\simeq}\) is constant on every weak component of the
transformation graph.  If the graph is connected on \(\mathcal P\), there
is a unique source functional \(Q:\mathcal F\to\mathcal O/{\simeq}\)
such that
\[
 [X(A,F)]_{\simeq}=Q(F)
 \qquad(A\in\mathcal P).
 \tag{2}
\]
If \(R\) respects \(\simeq\), then \(R(X(A,F))\) also depends only on
\(F\).  If \(R\) does not respect \(\simeq\), (COV) implies no equality
of resources across an edge.
\end{theorem}

\begin{proof}
Condition (COV) equates the quotient classes at the endpoints of every
transformation edge.  Equality in the quotient is symmetric and transitive,
so the class is constant along every undirected path.  Connectedness gives
one class for each fixed source; define it to be \(Q(F)\).  Uniqueness is
pointwise.  Equation (1) gives the resource conclusion.  When (1) fails,
there exist equivalent \(o,o'\) with different resources, so quotient
covariance alone cannot equate their resource values.
\end{proof}

This is exactly LB-0011's implementation-quotient factorization combined
with MODELBRIDGE-0016's component propagation.  The present report does not
rename it as novel.  Its synthesis contribution is the shortest surviving
chain: TESTS-0011 defeats child-preserving orbit coverage; connected typed
covariance then triggers source factorization.

\begin{corollary}[Runtime is not a semantic/type invariant]
Let \(A\) be any exact SAT program and let \(D_d[A]\) execute
\(|F|^d\) dummy steps before running \(A(F)\).  Then \(D_d[A]\) is
extensionally equivalent to \(A\), while its charged time is at least
\(|F|^d\).  Therefore an equivalence broad enough to identify ordinary
semantics does not preserve runtime uniformly over polynomial wrappers.
\end{corollary}

The same counterexample applies to trace length, chosen memory layout and
communication transcript.  Conversely, refining \(\simeq\) so those
details are preserved makes coverage fail on the corresponding wrappers.

\section{Endpoint-equivalence theorem}
Let \(\mathcal G\) be a fixed ordinary-machine resource class for which a
model-matched unconditional theorem proves
\[
 \SAT\notin\mathcal G.
 \tag{3}
\]
An FLMV-forbidden deterministic random-access time--space region is the
intended example.  Consider the complete repaired compiler claim
\[
 \mathsf{TCOMP}_{\mathcal G}:\quad
 \SAT\in P\Longrightarrow
 \exists C\ \forall A\in\PolySAT:
 C(A)\text{ decides SAT and }C(A)\in\mathcal G.
 \tag{4}
\]

\begin{theorem}[\texttt{TYPED-COMPILER-ENDPOINT-EQUIV1}]
Under (3),
\[
 \mathsf{TCOMP}_{\mathcal G}
 \quad\Longleftrightarrow\quad
 \SAT\notin P.
 \tag{5}
\]
\end{theorem}

\begin{proof}
If \(\SAT\notin P\), the antecedent of (4) is false, so (4) is true.  If
\(\SAT\in P\), then \(\PolySAT\neq\varnothing\).  Choose any
\(A\in\PolySAT\).  Equation (4) gives an ordinary SAT decider
\(C(A)\in\mathcal G\), contradicting (3).  Hence (4) is false.  The two
cases prove (5).
\end{proof}

This specializes RT-0011's empty-target-class guard.  A typed compiler
without the favorable resource conclusion does not reach a contradiction.
Adding the favorable conclusion makes the claim separation-equivalent.
Therefore it is not a smaller intermediate lemma that follows routinely from
\(P=NP\).

\section{Hostile controls and one-bit output}
Horn closure, 2SAT implication graphs, affine Gaussian elimination and
bounded-treewidth dynamic programming compute their one-bit outputs without
a universal extracted representative.  Independent products do not force a
shared cross-component state.  Padding and alternate encodings alter code,
input length and observed cost while leaving semantics unchanged.  Compact
circuits and branching programs can represent particular functions without
showing that an arbitrary uniform SAT algorithm instantiated that
representation.

DEAD, COPY, DELAY, INTERP and RECOMP sharpen the quotient dilemma.  A broad
equivalence identifies their SAT behavior but not their costs; a narrow
equivalence that preserves costs splits their orbits and owes coverage.  The
one-bit contract gives no obligation to output the quotient representative,
compatibility matrix, witness, proof or canonical trace.

\section{Primary literature and barrier audit}
Fortnow--Lipton--van Melkebeek--Viglas prove lower bounds for SAT on declared
deterministic random-access machines and resource regions \cite{flmv}.
Their theorem is a direct endpoint only after one actual ordinary
SAME\_REALIZATION machine meets its hypotheses; typed covariance does not
construct it.  Leroy's verified compiler work proves semantic preservation
for specified source, intermediate and target semantics \cite{leroy}; it
does not give a compiler from every arbitrary SAT implementation into a
forbidden complexity class.

Baker--Gill--Solovay construct relativized worlds with opposite answers to
P versus NP \cite{bgs}.  The graph and quotient proofs relativize.  Giving
the compiler low-degree extension access does not invalidate factorization,
so no nonalgebrizing hinge is supplied; Aaronson--Wigderson remains active
\cite{aw}.  Natural Proofs is not triggered because no constructive large
property against general circuits is proposed.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{DIRECTLY TRANSFERABLE THEOREM.}
Quotient propagation transfers exactly from graph connectivity.  FLMV
transfers only after an ordinary machine satisfies its stated time--space
model.  Verified compilation transfers semantics only for the proved
language relation and compiler.
\item[] \textbf{ANALOGY / CANDIDATE.}
Certified compilation, bisimulation, abstract interpretation and LWE-style
external extraction suggest restricted covariant representations.  The
missing theorem is all-program coverage plus favorable resource preservation
on one actual realization.
\item[] \textbf{MISLEADING ANALOGY / FAILED TRANSFER.}
VLSI routing, distributed cuts, proof-system size, branching-program width,
Schur squares, quadratic-relation rank, Hilbert functions, syzygies,
collision entropy, special soundness and hash/random-oracle binding do not
turn semantic equivalence into runtime equivalence for arbitrary SAT code.
\end{description}

The PQ classification is ANALOGY/CANDIDATE for construction-specific
certified extraction and FAILED TRANSFER for generic algebraic or
cryptographic binding.  Cryptographic hardness and random-oracle assumptions
are not used.

\section{STALE OR OVERSTATED CLAIMS FOUND}
It is overstated to call \texttt{QUOTIENT-COVARIANCE-FACTOR1} novel; LB-0011
already proves the quotient form.  It is also stale to suggest that merely
allowing outputs to vary inside a typed equivalence class avoids source
factorization for any equivalence-respecting resource.  Conversely, it would
be overstated to claim all typed compilation impossible: a specified
semantics-preserving compiler can exist, but proving that its outputs always
occupy an FLMV-forbidden region would settle the separation.

monolithic typed-coverage target by one concrete source-level

composition remains \OPEN{} and separation-strength.
