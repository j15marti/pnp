\begin{abstract}
QGUARD1 correctly prevents a recognizable easy island from refuting the
worst-case target $\forall A\,\forall d\,\forall N_0\,\exists F$.  A tempting
repair is therefore to delete or quotient all polynomial-time recognizable
constant-answer islands and call what remains the hard residual.  This report
proves that repair vacuous.  If singleton islands are allowed, every input is
itself such an island.  Even if islands must be infinite, any canonically
paddable clean family is covered by the source-indexed islands
$I_F=\{F\sqcup T^k:k\ge0\}$ for one fixed satisfiable block $T$; this applies
to duplicate-free proper signed Monotone $3$SAT-$(2,2)$.  Hence the residual is
empty.  The theorem does not contradict Lynch complexity cores: their
existence assumes the language is already outside P.  A bounded audit checked
all 256 languages on eight source points, 32 padding levels and six wrapper
controls: 919,808 assertions, zero failures.  The surviving target is still a
single externally fixed quantitative two-way compiler with all costs in the
same ordinary machine.  P versus NP remains open.
\end{abstract}

\section{Definitions and exact collapse}

Let $C\subseteq\{0,1\}^*$ be a decidable promise domain and let
$b:C\to\{0,1\}$ be its decision function.  Put
\[
 \mathfrak E(C,b)=\{S\subseteq C:
 S\text{ is polynomial-time recognizable and }b|_S\text{ is constant}\}.
\]
The proposed residual is
\[
 \operatorname{Res}(C,b)=
 C\setminus\bigcup_{S\in\mathfrak E(C,b)}S.             \tag{1}
\]

\begin{theorem}[\claim{ALL-EASY-ISLAND-RESIDUAL-COLLAPSE1}]
For every $C$ and $b$, $\operatorname{Res}(C,b)=\varnothing$.
\end{theorem}

\begin{proof}
Fix $x\in C$.  The singleton $\{x\}$ is recognized by comparing the input
with the fixed string $x$, in linear time and logarithmic control space, and
$b$ is constant on it.  Thus $x$ belongs to the union in (1).  Since $x$ was
arbitrary, the union is all of $C$.
\end{proof}

This is not a runtime lower bound and does not require SAT to be easy or hard.
It is a quantifier theorem: allowing every source-specific recognizable
island makes the deletion rule absorb its entire domain.

\section{Infinite-island repair also collapses under canonical padding}

One may try to forbid finite islands.  The following exact hypothesis states
the padding actually used throughout the clean-core corpus.

\begin{theorem}[Infinite padding cover]
Suppose $C$ has a polynomial-time computable padding map
$P:C\times\mathbb N\to C$ such that
\begin{enumerate}[label=(\roman*)]
\item $P(x,0)=x$ and $|P(x,k)|\to\infty$ with $k$;
\item $b(P(x,k))=b(x)$ for all $x,k$; and
\item for every fixed $x$, $I_x=\{P(x,k):k\ge0\}$ is polynomial-time
recognizable.
\end{enumerate}
Then the union of all infinite polynomial-time recognizable constant-answer
subsets of $C$ is $C$.
\end{theorem}

\begin{proof}
Each $I_x$ is infinite by (i), monochromatic by (ii), recognizable by (iii),
and contains $x=P(x,0)$.  Therefore $C=\bigcup_{x\in C}I_x$.
\end{proof}

\begin{corollary}[Clean-core realization]
Let $\Htwo$ be the duplicate-free proper signed Monotone
$3$SAT-$(2,2)$ family.  Fix one satisfiable paired-incidence $K_{3,3}$ block
$T\in\Htwo$.  Under the canonical disjoint-product encoding, define
\[
 P(F,k)=\operatorname{canon}(F\sqcup T^{\sqcup k}).      \tag{2}
\]
Then the infinite padding islands $I_F=\{P(F,k):k\ge0\}$ cover $\Htwo$ and
are constant for satisfiability.
\end{corollary}

\begin{proof}
Fresh-variable disjoint union preserves proper clauses, clause uniqueness,
sign-monochromaticity, and exactly two positive and two negative occurrences
of every variable.  Since $T$ is satisfiable,
$F\sqcup T^{\sqcup k}$ is satisfiable exactly when $F$ is.  The encoded
length grows with $k$.  For fixed $F$, the input header determines the only
possible $k$ from $n=n_F+k n_T$ (or rejects).  The recognizer generates the
declared canonical string $P(F,k)$ and compares it with the input.  This is
polynomial time and avoids any graph-isomorphism or semantic-canonicalization
oracle.  Finally $P(F,0)=F$.
\end{proof}

The smallest nonvacuous repair must therefore fix an external island class
before seeing $F$---for example one uniformly indexed family with a shared
recognizer, explicit description bound and source-independent resource bound.
That repair no longer follows by ``delete every easy island.''  Proving that
its complement is nonempty and carries an arbitrary-machine lower bound is a
new load-bearing theorem, not a definition.

\section{Quantifier reconciliation with QGUARD1}

QGUARD1 distinguishes
\[
 \exists A\,\forall x\in I:\neg R(A,x)
 \quad\text{from}\quad
 \forall A\,\exists x\in C:R(A,x).                      \tag{3}
\]
An easy island $I$ establishes only the first form and is compatible with the
second.  The present theorem does not reverse that conclusion.  Instead it
shows that replacing $C$ by $C\setminus\bigcup I$ while quantifying over
\emph{all} recognizable monochromatic $I$ makes the new domain empty.  Thus:
\begin{itemize}
\item island counterexamples do not refute the worst-case target;
\item deleting every island does not repair the proof;
\item the only meaningful route is a direct worst-case theorem on an
externally fixed full domain or externally fixed complexity core.
\end{itemize}

The active target remains
\[
 \forall A\in\operatorname{Dec}_{\rm uniform}(\SAT)\cap\mathsf P\;
 \forall d\;\forall N_0\;\exists F\in\Htwo:
 N_F\ge N_0\land T_A(F)>N_F^d,                           \tag{4}
\]
or a solver-independent implication from $P=NP$ to one fully charged machine
in an unconditional forbidden region.  Both remain \OPEN.

\section{Primary-literature and barrier preflight}

The two obstacles were the possible use of a residual complexity core and
the transfer from a semantic/promise subset to arbitrary SAT computation.
Lynch's primary theorem states that every recursive language outside P has an
infinite recursive set on which every decider exceeds every polynomial almost
everywhere \cite{lynch}.  This is a \textbf{directly transferable theorem} in
its own Turing-machine model, but the hypothesis $A\notin P$ is precisely the
missing SAT separation.  It cannot define an unconditional SAT residual.
Orponen--Sch\"oning strengthen density/recognizability properties of such
cores, again under intractability hypotheses \cite{os}.  Importing either as
an unconditional clean-core theorem is a \textbf{FAILED TRANSFER}.

FLMV gives a model-matched deterministic random-access SAT time--space lower
bound: for every $c<\varphi$ some $d>0$ forbids simultaneous
$\mathrm{DTISP}(N^c,N^d)$ \cite{flmv}.  This is an
\textbf{EXACT OBJECT/THEOREM TRANSFER} only after one actual compiler places
the same ordinary computation at a forbidden pair.  No island deletion does
that.

The analogies to removing observable modes in control, puncturing/shortening
in coding theory, quotienting local sections in topology, VLSI routing cuts,
and proof-complexity restrictions are \textbf{useful structural analogies
requiring a new transfer theorem}.  They become misleading if their residual
object is selected separately for each source or if a representation lower
bound is charged to arbitrary computation.

\section{Hostile controls and SAME\_REALIZATION}

Horn, 2SAT, affine/Tseitin, and bounded-treewidth families have direct
polynomial algorithms; each also admits the singleton cover and, when closed
under a satisfiable product, the infinite padding cover.  Independent
products therefore create more source-indexed islands rather than a hard
residual.  Redundant clauses, variable renamings, alternate encodings, COPY,
DEAD, DELAY, INTERP and RECOMP may cause the canonical recognizer to reject;
the recognize-first machine then invokes its exact fallback.  This changes
the trace, not the one-bit semantics.

All parsing, canonicalization, component testing, source comparison, fallback
dispatch, output, time and peak workspace belong to the same wrapper
execution.  No semantic-state count is converted into runtime.  The theorem
does not require extraction or reconstruction, and the audit records both as
zero rather than hiding them.

The collapse relativizes and algebrizes because it uses only equality and
padding syntax.  It supplies no escape from Baker--Gill--Solovay or
Aaronson--Wigderson and defines no large useful constructive circuit property
for Natural Proofs.  Arbitrary polynomial exponents remain unbounded.

\section{Post-quantum ledger}

Schur squares, shortening, puncturing, dualization, quadratic relation ranks,
Hilbert functions, syzygies and graded Betti numbers are
\textbf{FAILED TRANSFERS} here: no such representation is forced by an
arbitrary SAT execution, and recognizable algebraic structure is often an
algorithmic weakness.  Collision entropy is an \textbf{EXACT OBJECT
TRANSFER} for a fixed padding/source map, but its collision distribution does
not prevent the source-indexed cover.  LWE-style external black-box reduction
architecture remains an \textbf{ANALOGY/CANDIDATE needing a new bridge}; no
unconditional NP worst-case/average-case theorem is supplied.  Special
soundness requires two actual openings to one commitment, and cryptographic
binding or random-oracle assumptions are inadmissible for an unconditional
P-versus-NP proof.
