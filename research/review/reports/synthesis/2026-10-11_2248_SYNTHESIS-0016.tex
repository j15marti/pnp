\begin{abstract}
Four verified tag reports now close the proposed explicit-tag detour.  Free
tags erase, consistent promised tags expose the root answer, and locally
glued arbitrary tags admit a linear validator.  The only suggested escape was
an answer-oblivious source-local tag not computable by that validator.  This
report proves the exact composition guard: if a total uniformly generated
explicit tag is answer-readable and correct on every source input, then its
generator and reader already decide the source language with their fully
charged resources.  If the tag is only existential, it is not acquired; if it
is only promised or locally checkable on a recognizable island, it gives the
existing shortcut rather than worst-case hardness.  Hence
\texttt{SOURCE-LOCAL-NONCOMPUTABLE-TAG1} is retired as an intermediate in its
explicit readable form.  The externally bounded source-pass theorem and P
versus NP remain \OPEN.
\end{abstract}

\section{Primary-literature and barrier preflight}

Cook's machine-to-formula theorem makes verification and reduction explicit,

not a lower bound \cite{Tseitin}.  Buss places Boolean formula value in

Baker--Gill--Solovay construct relativized worlds on both sides of the
P-versus-NP question \cite{BGS}; Aaronson--Wigderson extend the technique
barrier to algebrizing arguments \cite{AW}.  The composition theorem below
relativizes and algebrizes, so it supplies no barrier escape.  VLSI routing,
distributed cuts, proof labeling, and cryptographic binding are
\CAND{} analogies only: their locality, communication, or adversarial-opening
hypotheses are absent from an unrestricted ordinary machine.

\section{Exact no-bootstrap theorem}

Let $L\subseteq\{0,1\}^*$ be any language.  A tag compiler is a total
deterministic uniform transducer $E$ and a total deterministic reader $R$.
On input $x$, $E$ produces one explicit string $E(x)$; $R$ receives that
actual string and returns one bit.  Let $r(n),s(n)$ bound the fully charged
time and space of $E$, and let $q(m),u(m)$ bound those of $R$ on an $m$-bit
compiler output.  Let $w(n)=|E(x)|$ be the worst output length.

\begin{theorem}[\texttt{EXPLICIT-ANSWER-TAG-COMPOSITION1}]
\EXACT, independent review pending.  If
\[
 \forall x\in\{0,1\}^*\qquad R(E(x))=\mathbf 1[x\in L],              \tag{2}
\]
then one deterministic uniform machine decides $L$ in time
\[
 O\bigl(r(n)+q(w(n))\bigr)
\]
and peak writable space
\[
 O\bigl(s(n)+w(n)+u(w(n))\bigr),                                    \tag{3}
\]
or with the explicit-output term replaced by the proved charged streaming
interface when $R$ reads $E$ online.
\end{theorem}
\begin{proof}
On $x$, run $E(x)$ in the declared realization and then run $R$ on the actual
result; output the reader bit.  Equation (2) proves correctness.  Sequential
composition gives the time sum.  Retaining the explicit output gives (3);
any smaller streaming charge requires an independently proved interface and
does not alter correctness.  No extraction from a foreign implementation is
used.
\end{proof}

\begin{theorem}[\texttt{EXPLICIT-TAG-ARCHITECTURE-FORK1}]
\EXACT, independent review pending, under the displayed interfaces.
\begin{enumerate}
\item If tag clauses are satisfiable and variable-disjoint, the tag is
semantically erasable (TESTS-0015).
\item If a correct answer tag is promised and locally addressable, reading it
is an answer side channel (REDTAG1/TAGGLUE1).
\item If arbitrary pinned tags are accepted exactly when a polynomial-time
local consistency predicate holds and the root bit is true, the recognizable
tagged island has that polynomial classifier (TAGGLUE1).
\item If a total compiler emits a correct readable answer tag for every
source input, Theorem 1 says the compiler-reader composition already decides
the source language.
\item If the tag is merely existential and is neither generated nor obtained,
it does not instantiate a source pass.  Its existence alone forces no machine
state, exposure, memory, communication, or time.
\end{enumerate}
\end{theorem}
\begin{proof}
The first three items are the cited exact semantic theorems.  Item four is
Theorem 1.  Item five is the permanent acquisition guard: existence is not an
algorithm for acquisition, and a one-bit decision output need not expose a
witness or annotation.
\end{proof}

Thus \texttt{SOURCE-LOCAL-NONCOMPUTABLE-TAG1} is \RETIRED{} as a new
intermediate when ``tag'' means a total explicit answer-readable output.  If
its producer uses a hypothetical $N^K$ SAT decider, the composition retains
that unknown exponent.  If its producer instead has the simultaneous bounds
needed for an unconditional forbidden endpoint, then
\texttt{BOUNDED-SOURCE-PASS-ENDPOINT1} says the endpoint has already been
reached.  If the tag is implicit or existential, the missing acquisition
arrow returns unchanged.

\section{Counterfactual $P=NP$ consequence}

Assume $\SAT\in\Pclass$ via a total uniform decider $A$.  A tag compiler may
run $A(F)$ and emit that one bit.  This proves the conditional existence of a
polynomial compiler, but its exponent and workspace are precisely those of
$A$ plus output overhead.  It yields no unconditional contradiction and no
arbitrary-exponent elimination.  Conversely, a compiler with externally
proved forbidden simultaneous bounds would itself be the forbidden SAT
decider by Theorem 1.  No premise equivalent to $P\ne NP$ is smuggled into the
argument.

\section{SAME\_REALIZATION, wrappers, and barriers}

DEAD, COPY, DELAY, INTERP, and RECOMP can change traces and storage without
changing the compiler-reader composition.  Padding only weakens bounds stated
in padded length.  Alternate encodings require charging recognition and
locators.  A semantic oracle makes the tag immediate; algebraic access can
only make local gate validation easier.  The theorem therefore relativizes
and algebrizes.  It uses no large constructive circuit property, so Natural
Proofs is inactive.  No solver-to-protocol or solver-to-tag theorem is proved.
