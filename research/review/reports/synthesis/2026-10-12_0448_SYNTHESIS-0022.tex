\section{Exact clean core and quantified target}
Let $K=\mathcal H^{\pm}_{2,2}$ be the duplicate-free proper signed monotone
three-CNF family in which every variable occurs twice positively and twice
negatively, under one canonical indexed encoding.  Let
$N=|\operatorname{enc}(F)|$.  For a total deterministic uniform ordinary
machine $A$, let $T_A(F)$ and $S_A(F)$ be charged time and peak writable space.
The final time target is
\begin{equation}
\tag{WT}
\forall A\;\forall d\;\forall N_0\;\exists F\in K:\quad
N\ge N_0\ \land\ T_A(F)>N^d.
\end{equation}

\section{UNIVERSAL-RESOURCE-AXIS-PENTACHOTOMY1}
\begin{theorem}
For the canonical full decision problem and the NP-complete core $K$:
\begin{enumerate}[label=(\roman*),leftmargin=1.7em]
\item (WT) is equivalent to $\SAT\notin\mathsf P$, hence to $P\ne NP$.
\item The formally analogous cofinal superpolynomial-workspace target is
false: one full-language exhaustive decider uses $O(N)$ writable space.
\item No positive universal lower bound on ordinary decision-interface
communication, declared compatibility-extractor calls, or declared witness-
reconstructor calls holds over all exact deciders.
\item For any finite set of named internal APIs, every fixed finite-control
program has an extensionally equivalent single-dispatcher realization with
zero host calls to those APIs and only constant-factor time/space overhead.
Consequently, if $\SAT\in\mathsf P$, a zero-named-call polynomial SAT decider
exists.
\item A lower bound in a fixed external/online/split model applies to ordinary
SAT only after a model-preserving compiler from every arbitrary static SAT
decider is proved and every cost is charged in the same realization.  That
transfer and a solver-exponent-independent forbidden landing remain \OPEN.
\end{enumerate}
\end{theorem}

\begin{proof}
For (i), (WT) rules out every polynomial SAT decider.  Conversely, if (WT)
fails, one total $A$ is polynomially bounded on every sufficiently long core
input.  Compose $A$ with D\"ocker's polynomial many-one reduction to $K$;
the finite exceptional outputs contribute a constant maximum because $A$ is
total.  The composition decides SAT in polynomial time.

For (ii)--(iii), enumerate all assignments while reusing one $n$-bit counter,
input indices, and flags.  Parsing is linear, peak writable space is $O(N)$,
and the program emits one decision bit.  It has no channel, compatibility
extractor, or witness reconstructor in the declared ordinary interface.
Exponential time is fully charged, so this does not affect (i).

For (iv), number every instruction in every procedure of a fixed program.
One dispatcher loop stores the current instruction and simulated call stack.
A guest call pushes a return counter and branches; no host call to the named
API occurs.  Induction on program steps preserves output, and finite control
gives a program-dependent constant overhead.  Flatten any hypothetical
polynomial SAT decider to obtain the conditional consequence.

Part (v) is the typing boundary: an external protocol's resource is defined
only after its parties, chronology, allowed reads, and output obligations are
fixed.  Without a compiler relating each ordinary SAT execution to that
model, the restricted theorem has a different quantified domain.  No current
corpus theorem closes that implication.
\end{proof}

Thus \texttt{GENERIC-RESOURCE-AXIS-AS-INTERMEDIATE1} is \RETIRED.  This does
not retire simultaneous time--space work, external communication after a
valid compiler, or the final time target.  It prevents silent switching among
inequivalent resources.
