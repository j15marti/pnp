\begin{abstract}
LB-0016 proves exponential output for an all-branch strict-contraction pass;
MODELBRIDGE-0017 proves that a one-variable answer-preserving selector is
endpoint-equivalent but makes only current-scale progress.  This run closes
the exact quantitative gap for a single pruned child.  On a proper exact-
$(2,2)$ clean-core source of encoded length $N=\Theta(n\log n)$, any literal
restriction whose explicit residual has length at most $N^h$, fixed $h<1$,
must assign at least $n/3-o(n)$ variables.  On a satisfiable source, exact
answer preservation makes those bits an extendable partial witness.  Thus an
explicit pruned pass avoids exponential branch volume only by selecting a
linear-size witness fragment.  This is a theorem about the declared source
pass, not an arbitrary SAT decider: a one-bit program need not expose the
fragment, and under $P=NP$ ordinary self-reduction finds it in polynomial time
while retaining the unknown exponent $K$.  The audit passed 7,127 checks.
P versus NP remains open.
\end{abstract}

\]

\section{Single-child incidence theorem}

\begin{theorem}[\texttt{PRUNED-CHILD-LINEAR-ASSIGNMENT1}]
Fix $0<h<1$.  Let $F_n\in\Htwo$ have $n$ variables and encoded length $N_n$.
If a partial assignment $\rho_n$ on $q_n$ variables gives an explicit
canonically indexed residual of length
\[
 |\operatorname{enc}(F_n\upharpoonright_{\rho_n})|\le N_n^h,
\]
then
\[
 q_n\ge \frac n3-o(n).                                  \tag{2}
\]
This conclusion is independent of how $\rho_n$ is selected.
\end{theorem}

\begin{proof}
At most four source clauses meet each assigned variable, so at most $4q_n$
clauses are touched.  At least
\[
 r_n=\frac{4n}{3}-4q_n                                  \tag{3}
\]
proper three-clauses avoid $\operatorname{dom}(\rho_n)$ and survive verbatim.
Their $3r_n$ literal occurrences involve at least $3r_n/4$ live variables,
because restriction cannot increase residual degree above four.  Even after
compact renaming, an explicit indexed residual therefore needs
\[
 \Omega(r_n\log(r_n+2))                                 \tag{4}
\]
bits.  Since $N_n=\Theta(n\log n)$ and (4) is at most $N_n^h$, we have
$r_n=O(N_n^h/\log N_n)=o(n)$.  Rearranging (3) gives (2).
\end{proof}

\begin{corollary}[\texttt{PRUNED-YES-PARTIAL-WITNESS1}]
If additionally $F_n$ is satisfiable and
\[
 \SAT(F_n)=\SAT(F_n\upharpoonright_{\rho_n}),           \tag{5}
\]
then $\rho_n$ extends to a satisfying assignment of $F_n$ and fixes
$n/3-o(n)$ witness bits.  An interface explicitly serializing $\rho_n$ emits
$\Omega(n)=\Omega(N_n/\log N_n)$ bits before residual solving is charged.
\end{corollary}

\begin{proof}
By (5), the residual is satisfiable.  Any satisfying residual assignment,
combined with $\rho_n$, satisfies the source.  Theorem 1 supplies its size.
An explicit Boolean partial assignment uses at least one value bit per
assigned variable; addresses can only increase volume.
\end{proof}

For UNSAT sources every restriction remains UNSAT, so there is no analogous
selection burden.  This YES/NO asymmetry is essential.  The theorem also does
not charge $\Omega(n)$ output when an interface emits only a residual and
neither exposes nor reconstructs $\rho$; that case needs a separate physical
access theorem.

\section{Consequence for the pruned-source route}

The all-branch/pruned dichotomy is now exact within literal restrictions:
\begin{enumerate}[leftmargin=*]
\item emitting every block assignment costs
$2^{n/3-o(n)}=2^{\Omega(N/\log N)}$ by LB-0016;
\item emitting one strict-power child avoids fanout but selects an extendable
$n/3-o(n)$-bit partial witness on YES sources;
\item MODELBRIDGE-0017 shows that, under $\SAT\in P$, a single exact child can
be selected bit by bit using current-scale SAT calls, so polynomial existence
is not contradictory and the arbitrary exponent $K$ remains.
\end{enumerate}

Accordingly \texttt{PRUNED-WITNESS-FORCES-DECIDER-WORK1} is \RETIRED{} as an
unqualified arbitrary-machine claim.  The semantic existence of a large
extendable prefix does not mean the original one-bit execution constructs it.
The useful remaining arrow is \texttt{IMPLICIT-PREDECISION-ACCESS1}: prove one
source-checkable rule that supplies the necessary bits or the residual's
local accessor in a fixed $K$-independent favorable budget, recurs
hereditarily, and does not first decide SAT.

\section{Hostile controls and barriers}

Paired cubic-bipartite clean cores are satisfiable by perfect matching and
provide explicit extendable restrictions cheaply.  Horn, 2SAT, affine/Tseitin
and bounded-treewidth families likewise expose polynomial semantic shortcuts;
the incidence theorem applies to the declared explicit restriction geometry
but does not make those controls hard.  Independent products allow component-
wise selection.  Padding, redundant clauses and alternate encodings change
physical length and must charge parsing, de-padding, translation and access.
Compact circuits, BDDs or affine bases leave the explicit-child model and need
a model-preserving decoder theorem.

DIRECT/DEAD/COPY/DELAY/INTERP/RECOMP wrappers preserve the one SAT bit while
changing trace, time, space and representation.  A universal extraction claim
must exhibit a qualifying object for each implementation in the same
execution; optional external self-reduction does not suffice.  The final
output may be one bit, so witness reconstruction is not automatically charged.

The incidence proof relativizes and algebrizes because it is syntactic; the
missing arbitrary-machine transfer does not arise from it.  Thus no
Baker--Gill--Solovay or Aaronson--Wigderson barrier is crossed
\cite{bgs,aw}.  Natural Proofs is not the immediate hinge because no large
constructive circuit property is used \cite{rr}.  FLMV is an exact endpoint
only after one ordinary random-access machine satisfies its simultaneous
resource bounds; it supplies neither $\rho$ nor its accessor \cite{flmv}.
Chavrimootoo et al. directly warn against assuming that arbitrary SAT
algorithms follow a chosen downward-self-reduction structure \cite{chkln}.

\section{Post-quantum and cross-domain transfer ledger}

Schur squares, quadratic relation rank, Hilbert functions and syzygies are
\textbf{FAILED TRANSFER}: no code representation is forced by the theorem.
Lossiness/collision entropy can measure how many partial assignments map to
one residual but gives no acquisition-time lower bound.  LWE-style black-box
architecture and special-soundness collision extraction are
\textbf{ANALOGY/CANDIDATE needing a new bridge}; no unconditional SAT
worst-case/average-case or conflicting-opening theorem is supplied.  Hash and
random-oracle methods are \textbf{FAILED TRANSFER}.  The same hidden
structure may be exploitable by matching or Gaussian elimination.

The incidence bound itself is a \textbf{direct theorem transfer} from bounded
occurrence counting to the explicit clause-list pass.  VLSI routing,
observability, distributed cuts, branching programs, proof systems and
pebbling are \textbf{FAILED TRANSFER} to unrestricted SAT without a compiler.
