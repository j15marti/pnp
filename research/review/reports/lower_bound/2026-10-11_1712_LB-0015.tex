\section*{Executive result}

This run closes the query-scale loophole left by MODELBRIDGE-0015, but not in
the direction of a SAT lower bound.  For an extensional deterministic
transducer that asks polynomially many exact SAT questions, there are only two
asymptotic query-scale regimes:
\begin{enumerate}[leftmargin=1.5em]
\item if a positive polynomial query scale occurs infinitely often, arbitrary
      delay wrappers prevent any one fully charged exponent from holding for
      every polynomial-time SAT implementation; but
\item if every reached query has length $N^{o(1)}$, then under the assumption
      $P=NP$ any one fixed polynomial SAT solver evaluates every query in
      $N^{o(1)}$ time and space.  The full transducer becomes an ordinary
      uniform source algorithm with time exponent equal to the larger of its
      local-work and query-count exponents, independently of the solver's
      fixed exponent.
\end{enumerate}
This is \texttt{BLACKBOX-QUERY-SCALE-DICHOTOMY1}, \status{Proved/Exact}
pending independent review.  The vanishing-scale half is the exact $c=0$
specialization of the repository's earlier wrapper accounting; the new
contribution is the exhaustive dichotomy obtained by combining that fact with
MODELBRIDGE-0015's delay-wrapper gate.

Consequently \texttt{SUBPOLY-BLACKBOX-IS-INTERMEDIATE1} is
\status{Falsified/Retired}: subpolynomial exact SAT queries do not define a
third oracle-relative lower-bound regime.  They give a genuine ordinary
algorithm under $P=NP$.  Constructing such an algorithm in a forbidden
time--space region is still \status{Open} and is separation-strength.
P versus NP remains \status{Open}.

\section{Clean core and semantic compatibility}

Fix a canonical self-delimiting binary encoding of proper 3-CNF and write
$N=|\operatorname{enc}(F)|$.  The explicit clean-core universe is
\[
 \mathcal C_N=\{F:|\operatorname{enc}(F)|=N,
   \ F\text{ is canonical proper width-three CNF}\}.
\]
For $F=C_1\wedge\cdots\wedge C_m$ on $n$ variables define
\[
 H(F)_{\alpha,j}=1\iff \alpha\models C_j,
 \qquad H(F)\in\{0,1\}^{2^n\times m}.
\]
SAT asks only whether $H(F)$ contains an all-one row.  The theorem below is
representation neutral: the transducer's output may be the SAT bit, a
witness, selected entries of $H(F)$, an occurrence structure, a residual
graph, or any other charged finite string.  Output length is included in
local work.  Nothing requires a one-bit decider to materialize $H(F)$.

\section{Exact model and quantifiers}

Let $E^{\SAT}$ be one uniform deterministic extensional oracle transducer.
On every source input $F$ of encoded length $N$, it constructs at most
$N^{\eta+o(1)}$ adaptive SAT queries, performs $N^{r+o(1)}$ charged local
work, and uses $N^{p+o(1)}$ charged local/retained workspace.  Query
construction, source access, serialization, suspension, resumption,
combining, storage and output are included.  The oracle interface consists
only of a query string and its exact SAT bit.

Because SAT is a fixed language, every exact implementation induces the same
adaptive transcript.  Define the actual worst reached query length
\[
 q_E(N)=\max_{\substack{|\operatorname{enc}(F)|=N\\
                        Q\text{ reached by }E^{\SAT}(F)}}
       \max\{2,|\operatorname{enc}(Q)|\}
\]
and its scale
\[
 \sigma_E(N)=\frac{\log q_E(N)}{\log N}.
\]
The maximum is taken over actual transcripts, not over a loose declared
upper bound.  Empty query sets use $q_E(N)=2$.

\paragraph{BLACKBOX-QUERY-SCALE-DICHOTOMY1 (\status{Proved/Exact}).}
Assume $\SAT\in P$.  Exactly one of the following holds.
\begin{enumerate}[leftmargin=1.5em,label=(\Alph*)]
\item $\sigma_E(N)\to0$.  For every fixed uniform polynomial-time exact SAT
      implementation $A$,
      \[
       T_{E[A]}(N)\le N^{\max\{r,\eta\}+o(1)},\qquad
       S_{E[A]}(N)\le N^{p+o(1)}+N^{o(1)}.
       \tag{1}
      \]
      In particular, fixing one such $A$ produces an ordinary uniform source
      algorithm for the output of $E$ whose leading exponents do not contain
      the solver's polynomial exponent.
\item $\sigma_E(N)\not\to0$.  For every proposed common exponent $c$ there is
      a uniform polynomial-time exact SAT implementation $A_c$ and infinitely
      many source inputs on which the fully charged execution of $E[A_c]$
      exceeds $N^c$ time.
\end{enumerate}

\paragraph{Proof.}
For (A), fix an exact solver $A$ with time $m^{K+o(1)}$ and space
$m^{s+o(1)}$, where $K,s$ are fixed constants.  Write
$q_E(N)=N^{\delta(N)}$ with $\delta(N)\to0$.  Each call costs
\[
 q_E(N)^{K+o(1)}=N^{\delta(N)(K+o(1))}=N^{o(1)}
\]
time and $N^{o(1)}$ workspace.  Bounded query lengths cause only a fixed
constant cost.  Summing at most $N^{\eta+o(1)}$ sequential calls and adding
local work gives (1); sequential reuse gives the workspace maximum.  All
objects belong to this same execution.

For (B), failure of convergence to zero gives some $\varepsilon>0$ and
infinitely many $N$ with an actual reached query of length at least
$N^\varepsilon$.  MODELBRIDGE-0015's delay-wrapper argument applies: from any
polynomial exact solver $A_0$, choose an integer $d>c/\varepsilon$ and delay
for $|Q|^d$ steps before running $A_0(Q)$.  Exact answers and hence the
adaptive transcript are unchanged, while the reached query costs at least
$N^{\varepsilon d}>N^c$.  The two alternatives are exhaustive and mutually
exclusive. \hfill$\square$

\section{What the theorem does and does not transfer}

Under $P=NP$, the vanishing-scale branch is not merely an oracle program: it
is an ordinary uniform algorithm after fixing one polynomial SAT solver.
Thus any lower bound claimed for an extracted resource $R(F)$ must apply to
that ordinary source computation.  Oracle terminology supplies no extra
hardness.  If $E$ itself decides SAT and the parameters of (1) enter a
published forbidden random-access time--space region, then $P=NP$ yields an
unconditional contradiction.  Proving that such an $E$ exists from every
polynomial SAT decider would therefore establish the separation; it is not a
routine intermediate.

The theorem does not prove that a vanishing-scale extractor exists, does not
lower-bound source computation of $H(F)$, and does not force an arbitrary
decider to expose any transcript or compatibility object.  An intensional
compiler reading program code, traces or timing lies outside the extensional
model and still owes wrapper covariance and all construction/transport costs.
Unit-cost semantic-oracle calls are also a different model.

\paragraph{Exact surviving target (\status{Open}).}
\texttt{SUBPOLY-SOURCE-COMPILER1}: assuming $\SAT\in P$, construct one
ordinary random-access SAT decider obtained from a uniformly charged
vanishing-scale extensional transducer with
\[
 C=\max\{r,\eta\}<\varphi,
 \qquad
 p<\frac12\left(\frac{C+2}{C^2}-C\right),
\]
or another exactly matched published forbidden region.  Query construction,
source reads, output, buffers and solver workspace must be included.  The
FLMV theorem supplies the endpoint, not this compiler.

\section{Primary-literature and barrier-transfer preflight}

The two obstacles checked before promotion were whether bounded/small SAT
queries carry a known unconditional lower bound and whether their cost can be
matched to an ordinary-machine endpoint.  Fortnow--Lipton--van Melkebeek--
Viglas prove SAT time--space lower bounds on specified random-access machine
regions; they do not force a query transducer or compatibility object.
Beigel--Gasarch--Kinber study exact bounded-query/frequency phenomena and give
SAT consequences under $P\ne NP$; those conditional SAT bounds cannot be
inserted into a proof whose counterfactual premise is $P=NP$.  Yesha's and
the sparse-set literature's bounded truth-table reductions concern sparse
target sets and collapse consequences, not short query strings to SAT itself.

Baker--Gill--Solovay's relativization barrier and Aaronson--Wigderson's
algebrization barrier remain fully active: both halves of the present
dichotomy are black-box accounting statements.  No Natural-Proofs-style
constructive circuit property is defined.  Communication/query-complexity
``answer bandwidth'' is a \status{Analogy/Candidate}: answer bits are counted,
but the transducer also constructs queries from the source and no theorem
turns bandwidth into arbitrary SAT decision time.  VLSI locality and routing
are \status{Failed Transfer} here because an unrestricted RAM can synthesize
short queries without physical wire constraints.  The only direct theorem
transfer is the model-matched FLMV endpoint after an actual ordinary
time--space realization has been constructed.

\section{Encoding, padding, and one-bit output audit}

All exponents use the actual encoded input length $N$.  A fixed polynomial
padding $N'=N^a$ rescales a positive query exponent $\lambda$ to
$\lambda/a>0$ and therefore cannot enter branch (A).  Superpolynomial padding
can make a semantic query appear subpolynomial in the padded length, but is
not a polynomially equivalent local encoding; reading the padded parent is
itself charged.  Renaming, complementation and linearly or polynomially
related self-delimiting encodings preserve the stated dichotomy after the
corresponding exponent conversion.

One-bit output does not help or hurt the accounting theorem.  If the output
is only $\SAT(F)$, the composed source algorithm returns that bit.  If a
larger compatibility object is demanded, its writing cost is charged and the
problem has changed.  Semantic state count, rank, communication matrices and
representation size do not imply runtime for either output contract.

\section{Post-quantum technique ledger}

\begin{itemize}[leftmargin=1.5em]
\item Schur squares, quadratic relation spaces, Hilbert functions and
      syzygies: \status{Failed Transfer}.  They describe selected algebraic
      representations; the query-scale theorem neither forces nor needs them.
\item Lossiness/collision entropy: \status{Analogy/Candidate}.  The exact
      Cauchy--Schwarz image bound applies to a declared extraction map, but no
      such source-bound map is forced by one-bit SAT.
\item LWE-style external black-box extraction: \status{Analogy/Candidate}
      narrowed by an exact theorem.  Positive-scale calls retain arbitrary
      wrapper exponents; vanishing-scale calls compile to an ordinary source
      algorithm under $P=NP$.  The missing bridge is now source-level.
\item Collision extraction/special soundness and hash/random-oracle methods:
      \status{Failed Transfer} absent a construction-specific forbidden
      witness theorem that survives removal of cryptographic assumptions.
\end{itemize}

\section{DUPLICATION / CONTRADICTION AUDIT}

length exponent zero, and root MAIN's 2026-10-02 simulation already records
