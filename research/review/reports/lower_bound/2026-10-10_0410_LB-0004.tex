\section{Selected implication, quantifiers and model}
Fix one deterministic polynomial-time verifier $V$ on ordinary binary
strings.  At length $n$ and program $p$, let $\Pi_{n,p}$ be the finite set
of permitted witnesses, and define
\[
 R_\pi=\{x\in\{0,1\}^n:V(1^n,p,x,\pi)=1\}.
\]
The PFCERT list premise needs
\[
 \forall n\ \forall p\quad
 \left|\bigcup_{\pi\in\Pi_{n,p}}R_\pi\right|\le L(n),
\]
after taking the existential union over every permitted witness.  The same
verifier, encoding and witness polynomial must also accept the actual output
of the fixed ordinary universal program whenever it halts in the declared
time window.  The SAME\_REALIZATION objects are the verifier, its witness
fibers, the true universal-program endpoint and the ordinary input encoding.

The weakest useful theorem would prove, for this construction, a polynomial
bound on distinct fiber types and a truth-preserving binding between the
accepted quotient and the actual endpoint.  A generic path-count or
canonicalization assertion is weaker.

\section{Exact quotient and collision theorems}
\begin{theorem}[FIBER-TYPE-QUOTIENT1]
Let $\Pi$ and $X$ be finite, $R\subseteq X\times\Pi$, and
\[
 b=\max_{\pi\in\Pi}|R_\pi|,
 \qquad
 c=\bigl|\{R_\pi:\pi\in\Pi\}\bigr|.
\]
Then
\[
 \left|\bigcup_{\pi\in\Pi}R_\pi\right|\le bc.
\]
The bound is tight.  Duplicating witnesses or appending ignored witness bits
preserves both $c$ and the endpoint union.
\end{theorem}
\begin{proof}
Choose one representative from each distinct fiber.  Their union is the
original union, and there are $c$ representative sets of size at most $b$.
Pairwise disjoint representatives of size $b$ attain equality.  Duplicate
witnesses create no new fiber set and no new endpoint.
\end{proof}

Let the $c$ distinct types have multiplicities $a_1,\ldots,a_c$, let
$W=|\Pi|$, and put $\operatorname{Coll}=\sum_i a_i^2$.
Cauchy--Schwarz gives
\[
 W^2=\left(\sum_i a_i\right)^2\le c\operatorname{Coll},
 \qquad
 c\ge\frac{W^2}{\operatorname{Coll}}.
\]
Thus the post-quantum collision-entropy object transfers exactly, but its
automatic inequality is a lower bound on the number of fiber types.  It
does not give the required upper bound.  If a construction additionally
proves $a_i\ge\mu$ for every type, then $c\le W/\mu$ and the union is at
most $bW/\mu$.  Ignored padding can inflate $\mu$, so a valid theorem must
normalize witness representations or prove semantic, construction-specific
overlap.  Treating raw collision mass as compression is a \textbf{FAILED
TRANSFER}.

\section{Truth binding is separate from refinement}
Let $F_z$ be a permissive accepted endpoint set and let
$T_z\subseteq F_z$, $|T_z|\le1$, be the actual universal-machine endpoint.

\begin{lemma}[TRUTH-PRESERVING-SELECTOR-GATE1]
Any selector that sees only $F_z$ and returns a strict subset of some
$F_z$ fails to contain $T_z$ for one admissible singleton
$T_z\subseteq F_z$.
\end{lemma}
\begin{proof}
Choose $x\in F_z\setminus C(F_z)$ and set $T_z=\{x\}$.
\end{proof}

Hence even a single-valued refinement of the accepted multivalued function
can select a false accepted endpoint.  Completeness requires a separate
binding theorem that recognizes or structurally forces the actual program
output.  Hemaspaandra--Naik--Ogihara--Selman prove that a generic NPSV
refinement for every NPMV function has polynomial-hierarchy collapse
consequences \cite{hnos1996}.  That is a direct literature guard against
treating refinement as cost-free.  It still does not solve the present
problem: inside a $P=NP$ contradiction argument the qualitative hierarchy
collapse is already available, while the truth-binding predicate and its
quantitative verifier bounds remain uncontrolled.
