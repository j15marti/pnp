\section*{Executive result}

\textbf{P versus NP remains OPEN.}  This run tests one concrete realization
of \texttt{SOURCE-PASS-ACCESS1}: fix a block of variables, generate every
restriction, and OR the child decisions.  On the exact-occurrence clean core,
a power-size contraction forces exponentially many children.  The statement
is exact for this declared source pass and does not lower-bound an arbitrary
SAT decider.

The new theorem is \texttt{ALL-BRANCH-ENCODED-FANOUT1} (\EXACT).  If every
explicit child has canonical indexed length at most $N^h$, $0<h<1$, then the
block has size at least $n/3-o(n)$ and the pass emits
\[
  2^{n/3-o(n)}=2^{\Omega(N/\log N)}
\]
children.  Therefore \texttt{ALL-BRANCH-SOURCE-PASS1} is \RETIRED{} as a
polynomial-cost realization of the current source-pass target.  A pruned,
source-dependent pass remains \OPEN; proving that an arbitrary decider must
enumerate the block compatibility set is false at the one-bit interface.

\section{Exact family, encoding, and target}

Let $\mathcal C_n$ contain duplicate-free proper $3$-CNFs in which every
variable occurs exactly twice positively and twice negatively.  Hence
$m=4n/3$ and $n$ is a multiple of three.  The active project family is the
monotone-clause subfamily when that promise is imposed; the theorem below
uses only the exact four-occurrence promise and therefore applies to that
subfamily as well.  A child is encoded as an explicit clause list after
deleting satisfied clauses, deleting false literals, and compactly renaming
its live variables.  Each live literal contains one sign bit and an indexed
variable address.  Thus the source length is $N=\Theta(n\log n)$.

For a block $S\subseteq[n]$, define the semantic compatibility set
\[
 H_S(F)=\{\alpha\in\{0,1\}^{S}:F\!\upharpoonright_\alpha
 \text{ is satisfiable}\}.
\]
The exact decision identity is
\[
 \SAT(F)=1\quad\Longleftrightarrow\quad H_S(F)\ne\varnothing
 \quad\Longleftrightarrow\quad
 \bigvee_{\alpha\in\{0,1\}^{S}}
 \SAT(F\!\upharpoonright_\alpha)=1.
\]
The unrestricted lower-bound target remains
\[
 \forall A\in\operatorname{Dec}_{\rm uniform}(\SAT)\ \forall d\ \forall N_0\
 \exists F\in\mathcal C:\ |\operatorname{enc}(F)|\ge N_0
 \ \wedge\ T_A(F)>|\operatorname{enc}(F)|^d .
\]
Nothing proved here establishes this target.

\section{The declared all-branch pass}

\paragraph{Definition.}
For a chosen $S$, the all-branch pass emits all $2^{|S|}$ explicit residuals
$F\!\upharpoonright_\alpha$, with acquisition, residual construction,
addressing, solver calls, aggregation, and peak storage charged.  It is a
specific algorithmic interface, not a necessary normal form for SAT.

\begin{theorem}[ALL-BRANCH-ENCODED-FANOUT1 --- \EXACT]
Fix $0<h<1$.  Let $F_n\in\mathcal C_n$ and $N_n=|\operatorname{enc}(F_n)|$.
If a block $S_n$ has the property that every canonically encoded residual
$F_n\!\upharpoonright_\alpha$ has length at most $N_n^h$, then
\[
 |S_n|\ge \frac n3-o(n),\qquad
 2^{|S_n|}\ge 2^{n/3-o(n)}=2^{\Omega(N_n/\log N_n)}.
\]
Consequently the explicit all-branch pass has superpolynomial acquisition or
output volume before child solving is charged.
\end{theorem}

\begin{proof}
Write $t=|S_n|$ and $m=4n/3$.  A fixed variable occurs in four clauses, so at
most $4t$ clauses meet $S_n$.  At least
\[
 r=m-4t
\]
clauses avoid $S_n$ and survive unchanged in every residual.  Those $r$
proper three-clauses contain $3r$ literal occurrences.  Since every live
variable has residual degree at most four, they involve at least $3r/4$
distinct live variables.  Even after compact renaming, the explicit indexed
clause list therefore uses
\[
 \Omega\!\left(r\log(r+2)\right)
\]
bits.  If this is at most $N_n^h$ and $N_n=\Theta(n\log n)$, then
$r=O(N_n^h/\log N_n)=o(n)$.  Hence
$4n/3-4t=o(n)$, so $t\ge n/3-o(n)$.  The pass contains exactly $2^t$
branches, giving the claimed volume.  No assumption about child
satisfiability or solver behavior is used.
\end{proof}

\paragraph{Scope.}
The proof is representation-robust only within explicit indexed clause-list
encodings up to ordinary compact renaming.  It does not apply to a circuit,
BDD, affine basis, implicit generator, or a one-bit endpoint unless the cost
of its accessor is separately transferred to the same machine.  This is the
SAME\_REALIZATION boundary.

\section{Why compatibility does not become an arbitrary-algorithm cost}

The theorem charges generation of the full cube, not $H_S(F)$ and not the
one-bit predicate $[H_S(F)\ne\varnothing]$.  Three attempted promotions fail.

\begin{enumerate}[leftmargin=1.6em]
\item \textbf{Enumerate every branch.}  This is exactly the theorem and costs
  $2^{\Omega(N/\log N)}$ for strict power-size children.
\item \textbf{Choose a branch using a SAT decider $A$.}  Standard
  self-reduction queries $A(F\!\upharpoonright_{x=0})$ and fixes a satisfying
  bit.  The first queries have length $N-O(\log N)=N^{1-o(1)}$.  If
  $T_A(M)=M^{K+o(1)}$, these current-scale calls retain the arbitrary exponent
  $K$.  This is the prior \texttt{PRECONTRACTION-A-GUARD2} and
  \texttt{BLACKBOX-QUERY-SCALE-DICHOTOMY1}, not a new universal lower bound.
\item \textbf{Choose one branch without semantic work.}  A fixed branch rule
  fails even for Boolean functions supported on a different branch.  A
  formula-dependent exact rule may succeed, but computing it is precisely
  the still-open source semantic compiler.  Calling it hard would smuggle
  $P\ne NP$ into the premise.
\end{enumerate}

Large $|H_S(F)|$, large compatibility rank, or many semantic states do not
force materialization.  Affine/Tseitin systems can have exponentially many
compatible block assignments while Gaussian elimination stores a compact
linear description and decides consistency in polynomial time.  Horn, 2SAT,
bounded-treewidth formulas, independent products, and formulas with padding
or redundancy similarly separate semantic multiplicity from decision cost.
DIRECT, COPY, DEAD, DELAY, INTERP, and RECOMP wrappers preserve the language
while changing intensional traces and resource ledgers.  The SAT interface
returns one bit, so no transcript, witness, branch index, or reconstruction
is universally required.

\section{Counterfactual $P=NP$ audit}

Assume a uniform deterministic SAT algorithm $A$ runs in time $N^K$ for an
unknown fixed $K$.  Ordinary self-reduction obtains a satisfying assignment
using $O(n)$ current-scale calls and time $N^{K+O(1)}$; it yields no
contradiction.  An all-branch pass pays the exponential volume above.  A
source pass that, before any positive-scale call to $A$, emits only
bit-local hereditary children in a model-matched FLMV-forbidden region would
give the desired contradiction, but constructing that pass remains \OPEN{}
and separation-strength.  FLMV supplies a simultaneous time--space endpoint
for its declared random-access model; it does not prove that arbitrary SAT
programs expose $H_S(F)$ or use this pass.

\section{Finite reproducible audit --- \COMP}

The dependency-free Python program completed in $0.791$ CPU seconds with
526,426 assertions and zero failures.  It exhaustively checked all 65,812
Boolean truth tables on at most four inputs and 262,948 block-restriction OR
identities, together with 262,948 fixed-branch counterexamples.  It generated
proper duplicate-free exact-$(2,2)$ cores for
$n\in\{6,12,24,48,96,192\}$, verified the untouched-clause bound, and tested
$h\in\{1/2,2/3,4/5\}$.  At $n=192$ the finite fanout-log lower bounds were
64, 61, and 54 respectively.  These numbers are evidence for the
implementation only; the asymptotic theorem is the proof above.

Hostile controls covered Horn, unsatisfiable 2SAT, bounded treewidth,
independent products, padding, redundancy, alternate clause/literal order,
tautological extension, and six wrappers.  The affine control
$x_i\oplus x_{i+4}=0$ has rank four, sixteen solutions, and all sixteen block
assignments compatible, yet four Gaussian rows represent it exactly.  This
directly falsifies any inference from $|H_S(F)|$ to decision work.
