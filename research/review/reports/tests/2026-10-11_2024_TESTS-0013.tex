\begin{abstract}
LB-0017 proves that an explicit literal restriction shrinking an exact-$(2,2)$
clean core to encoded length $N^h$, fixed $h<1$, assigns
$n/3-o(n)$ variables; on a satisfiable child it is an extendable partial
witness.  This run tests the next promotion: that the semantic witness volume
forces every polynomial SAT decider, or even every locally accessible
restriction realization, to store or serialize that many bits.  The promotion
is false on canonical products of paired $K_{3,3}$ blocks.  The diagonal
perfect-matching restriction has $n=9k$ bits, but bit $i$ is computed from its
address by one quotient/remainder test; the residual is TRUE and has a local
constant accessor.  A canonical recognizer scans the source in $O(N)$ time
and $O(\log N)$ workspace and accepts without materializing the witness.
The exact result is pointwise and representation-sensitive.  It leaves the
worst-case all-input implicit-access lower bound, SAME\_REALIZATION transfer,
and every P-versus-NP load-bearing arrow \OPEN.  P versus NP remains open.
\end{abstract}

\section{Exact family and local accessor}
Let $B$ be the paired-incidence formula of $K_{3,3}$.  For block $b$, row
$r\in\{0,1,2\}$ and column $c\in\{0,1,2\}$, let $x_{b,r,c}$ denote the
corresponding edge variable.  At every row and column vertex include both the
positive clause on its three incident edges and the negative clause on the
same edges.  Let $F_k$ be the conjunction of $k$ variable-disjoint copies.
Then
\[
 n_k=9k,\qquad m_k=12k,\qquad N_k=\Theta(k\log k),
\]
and $F_k$ is a duplicate-free proper Monotone $3$SAT-$(2,2)$ formula.

Define the full restriction
\[
 \rho_k(x_{b,r,c})=1\quad\Longleftrightarrow\quad r=c.
 \tag{1}
\]
It selects the diagonal perfect matching in every block.  Each positive
vertex clause contains exactly one true literal and each negative vertex
clause contains exactly two true literals.  Hence
$F_k\upharpoonright\rho_k=\top$.

\begin{theorem}[PAIRED-IMPLICIT-RESTRICTION-ACCESS1 --- \EXACT]
For the canonical indexed encoding of $F_k$, there is one uniform
deterministic implementation with the following charged bounds.
\begin{enumerate}[leftmargin=1.6em]
\item It recognizes the source in $O(N_k)$ time and $O(\log N_k)$ writable
bits by comparing the input stream against the block template.
\item Given a variable address $i$, it returns $\rho_k(i)$ using
$O(1)$ word operations and $O(\log N_k)$ bits: reduce $i$ modulo nine and
test whether its row and column digits are equal.
\item Given a residual-clause request, it returns the TRUE/empty marker
without storing the $9k$ restriction bits.
\item On a recognized input, a one-bit SAT decider returns YES after the
charged recognition scan and never materializes $\rho_k$.
\end{enumerate}
The uniform program is fixed; its instance descriptor contains only $k$, so
the non-input data are $O(\log k)$ bits.
\end{theorem}
\begin{proof}
The source syntax and satisfaction calculation were established above.
For variable number $i=9b+3r+c$, quotient/remainder arithmetic recovers
$(r,c)$ and (1) returns the correct bit.  Since every canonical source clause
is satisfied under (1), simplification emits no residual clauses.  Streaming
template comparison needs only the input position and $k$.  The recognize-first
one-bit program may therefore accept immediately after the comparison.
\end{proof}

If an external caller requests all $9k$ restriction bits, answering all
requests costs $\Theta(k)$ time and the output channel carries $\Theta(k)$
bits.  That is an interface charge, not an intrinsic stored-state lower
bound.  The theorem does not compress an explicitly required output; it
falsifies the inference that semantic length forces materialization even
when only local access or one-bit decision is required.

\section{Exact quantifier falsified}
The invalid promotion has the pointwise form
\[
 \forall A\ \forall F\in\mathcal H_{2,2}:
 \bigl[\text{$A$ decides $F$ or locally realizes a strict restriction}\bigr]
 \Rightarrow \text{$A$ stores or writes $\Omega(n)$ witness bits}.
 \tag{2}
\]
The theorem gives a direct counterexample to (2) on infinitely many encoded
lengths.  Under the counterfactual $\SAT\in P$, if $S$ is any uniform
polynomial exact SAT decider, the wrapper
\[
 A(F)=\begin{cases}
 1,&F\text{ is the canonical }F_k\text{ for some }k,\\
 S(F),&\text{otherwise}
 \end{cases}
\]
is a uniform polynomial exact decider and uses the small recognizer state on
the island.  This is model-matched and creates no contradiction.

The surviving worst-case quantifier is different:
\[
 \forall A\in\mathrm{uP\text{-}SAT}\ \exists F:
 \text{$A$ pays a charged implicit-access or time--space cost on $F$}.
 \tag{3}
\]
No experiment or theorem here refutes or proves (3).  In particular, the
fallback path can retain an unknown polynomial exponent $K$.

\subsection*{Hostile controls and all costs}
Reversed clause order, one redundant duplicate, and tautological padding
preserved satisfaction under the same assignment but were rejected by the
canonical recognizer.  This exposes representation sensitivity; the wrapper
falls back instead of silently normalizing.  DIRECT, DEAD, COPY, DELAY,
INTERP and RECOMP wrappers returned the same SAT bit while having different
traces.  The audit also recorded 2SAT/SCC, Horn forward chaining, affine
Gaussian elimination, width-one dynamic programming and independent-product
controls.  Their large semantic state spaces did not equal stored state.
No runtime or memory lower bound was extrapolated from those controls.

Recognition reads $N_k$ source bits up to encoding constants.  The position,
$k$, quotient/remainder temporaries and output bit fit in $O(\log N_k)$
writable space.  There is no preprocessing table, matching object, witness
buffer or reconstruction pass.  A request for an alternate encoding either
charges a map/normalizer or reaches the fallback; neither option strengthens
the pointwise theorem.

\section{Barrier-transfer and post-quantum audit}

access obligation immune to recognizable islands and address-local
generators; and (ii) transfer it to the same ordinary uniform machine in an
unconditional forbidden time--space region.  Primary sources were checked
before this construction: D\"ocker for the exact clean core and paired
matching shortcut; FLMV for the model-specific SAT time--space endpoint;
Baker--Gill--Solovay, Razborov--Rudich and Aaronson--Wigderson for the
relativization, Natural Proofs and algebrization barriers.  Downward
self-reducibility and recent exact search-to-decision work permit external
query constructions but do not force an arbitrary solver to expose a chosen

\section{DUPLICATION / CONTRADICTION AUDIT}
The paired block, perfect-matching witness, high compatibility rank and
recognizable-island barrier are established in earlier reports.  They are
adopted, not relabeled as new discoveries.  TESTS-0012 already emits one
explicit full restriction.  The new theorem removes its $n$-bit assignment
buffer and gives an address-local accessor plus a direct one-bit recognizer.
LB-0017 is not contradicted: its explicit restriction has linear semantic
length.  The falsified step is exactly the promotion from semantic length to
necessary storage/output by every realization.

\section{STALE OR OVERSTATED CLAIMS FOUND}
Any summary saying that LB-0017 forces linear memory, linear output, or
explicit witness exposure by arbitrary SAT algorithms is overstated.  It
forces those costs only for an interface that materializes the literal
restriction.  Conversely, saying that the current accessor handles arbitrary
encodings or hard clean cores is also overstated; it is a canonical
recognizable-island counterexample.

\section{Precise handoff}
The remaining implication is
\[
 \boxed{\texttt{WORSTCASE-IMPLICIT-PREDECISION-ACCESS1}}
\]
with exact target: for every uniform deterministic polynomial-time 3SAT
decider $A$ (under the hypothesis such a decider exists), prove that for some
length-$N$ clean-core input, before its one-bit answer is determined, the
same execution must perform a model-specified charged operation whose
unconditional lower bound places that execution outside every polynomial
time exponent or in a model-matched FLMV-forbidden joint region.  The
operation must be invariant under recognize-first wrappers, address-local
generators, alternate encodings, padding, affine/Horn/2SAT/treewidth
shortcuts and one-bit output.  No such implication is known here; proving it
is separation-strength.
