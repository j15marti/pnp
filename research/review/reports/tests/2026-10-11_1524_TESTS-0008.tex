\begin{abstract}
LB-0013 isolated a linear raw-probe cost for occurrence rank in an unindexed
literal stream.  This report tests the weakest hostile repair: explicit
preprocessing.  For every explicit CNF with $L$ literal occurrences and
$O(\log L)$-bit identifiers, a deterministic stable sort constructs both
clause-to-occurrence ranks and occurrence-to-clause incidence lists using
$O(L\log L)$ comparisons and $O(L\log L)$ bits.  The index is linear in the
standard encoded input length and gives constant-word forward and inverse
access with exact reconstruction.  Thus \texttt{RAW-RESCAN-ONLY1} is false:
raw rescanning is not a representation-independent obligation.  Conversely,
this offline theorem materializes a linear-size index.  It does not provide
Jahanjou--Miles--Viola on-demand polylogarithmic access with logarithmic
workspace from their succinct clause generator, and it does not force an
arbitrary one-bit SAT decider to acquire the index.  The bounded audit covers
Horn, 2-SAT, affine/Tseitin Gaussian elimination, bounded treewidth,
independent products, padding, redundant clauses, two encodings and
DIRECT/COPY/INTERP/RECOMP controls.  The on-demand bi-local first leg,
UCORE-TIME1 and P versus NP remain OPEN.
\end{abstract}

\paragraph{Claim card.}
The exact prefix proved is
\[
 \forall F\ \exists I_F\ \exists B
 \quad B(F)=I_F,
\]
where $F$ is an explicitly stored CNF, $I_F$ is the two-way occurrence
index defined below, and the single uniform deterministic compiler $B$ uses
the declared comparison-RAM resources.  This is not
$\forall A\,\exists F_A$ lower-bounding a SAT decider $A$.
The model is a word RAM with word size $\Theta(\log L)$ and read-only input
plus charged writable workspace.  The resource measures are comparison
time, written index bits, query word accesses, and reconstruction accesses.
The SAME\_REALIZATION object is the one explicit $F$ scanned by $B$ and the
one indexed by $I_F$.  The theorem does not place $I_F$ in the execution of
an unrelated SAT decider.

\section{Primary-literature and barrier preflight}

The first obstacle is an interface mismatch.  Jahanjou--Miles--Viola
Theorem~1 produces a quasilinear-size 3CNF whose requested clause is given by
an explicit local circuit; it does not state reverse incidence or occurrence
rank access \cite{jmv}.  FLMV's time--space transfer needs a locally generated
formula in its random-access Turing-machine composition and cannot silently
receive a separately materialized linear-space table \cite{flmv}.

The second obstacle is preprocessing versus query cost.  Raman--Raman--Rao
give succinct indexable dictionaries supporting rank/select operations in
constant RAM time after the representation is supplied \cite{rrr}.
P\u{a}tra\c{s}cu's lower bound is a redundancy/query tradeoff in the
cell-probe model, again for a preprocessed representation \cite{patrascu}.
These are direct theorem transfers to the explicit index interface, not to
work performed inside every SAT decider.

The closest cross-domain analogue is a static inverted index: clause
records are the forward file and sorted incidence records are the inverted
file.  This is a \textbf{THEOREM TRANSFER} only for explicit construction and
lookup.  Treating storage or cell-probe bounds as unrestricted Turing/RAM SAT
lower bounds is a \textbf{FAILED TRANSFER}.  Routing-network locality in the
Jahanjou--Miles--Viola construction is an \textbf{ANALOGY/CANDIDATE}: a new
theorem must show that its particular gate/variable labels expose both
clause fields and sign-specific occurrence ports without global inversion.

\section{Exact offline compiler}

\begin{definition}[Bi-local explicit index]
Enumerate the literal positions of $F$ by $(c,s)$, clause number and slot.
For literal $\ell_{c,s}$ define
\[
 r(c,s)=\bigl|\{(c',s')<(c,s):
    \ell_{c',s'}=\ell_{c,s}\}\bigr|,
\]
where equality includes variable identifier and sign and the order is
lexicographic in $(c,s)$.  The forward table stores $r(c,s)$.  The inverse
table stores
\[
 J(v,\sigma,r)=(c,s)
\]
for the unique occurrence of signed variable $(v,\sigma)$ with rank $r$.
\end{definition}

\begin{theorem}[\texttt{OFFLINE-BILOCAL-INDEX1}]
Let $F$ have $L$ literal occurrences, variables normalized to $[V]$ with
$V\le L$, and a standard fixed-width encoding of bit length
$N=\Theta(L\log L)$.  One uniform deterministic compiler constructs the
forward and inverse tables with
\begin{enumerate}[nosep]
\item at most $O(L\log L)$ record comparisons;
\item $O(L\log L)=O(N)$ writable bits and output bits;
\item $O(1)$ word accesses for either $r(c,s)$ or $J(v,\sigma,r)$; and
\item exact reconstruction of $F$ in $O(L)$ table accesses after retaining
the signed literals, or by discarding the annotations when they are attached
to the original clause records.
\end{enumerate}
The compiler changes neither the clauses nor their satisfiability.
\end{theorem}

\begin{proof}
Create one record $(v,\sigma,c,s)$ for every literal occurrence and stably
sort the $L$ records lexicographically.  Within each maximal equal
$(v,\sigma)$ run, number records $0,1,\ldots$.  Write that number to the
forward cell addressed by $(c,s)$ and write $(c,s)$ to the next inverse cell
of the run.  Merge sort uses $O(L\log L)$ comparisons.  Every record and
address has $O(\log L)$ bits, so the records and both tables occupy
$O(L\log L)$ bits.  Array addressing gives the query bound.  Sorting and
annotation do not alter any literal, and reading the retained literal at
every forward position reconstructs $F$ exactly.  Hence the satisfying
assignments are identical.
\end{proof}

\paragraph{Why this does not close the active first leg.}
The compiler reads all $L$ occurrences and stores $\Theta(L)$ words.  A
Jahanjou--Miles--Viola source instead supplies a succinct clause circuit;
the requested target bit must be returned in polylogarithmic time and
logarithmic workspace without first materializing all clauses or their
inverse file.  Consequently \texttt{OFFLINE-TO-ONLINE-LOCAL1} remains OPEN.
The exact missing theorem is source-specific, not a generic sorting lemma.

\section{Hostile controls, costs and barriers}

The suite includes Horn implications, a 2-SAT implication graph, a proper
3CNF encoding of a cycle-Tseitin affine system checked independently by
Gaussian elimination, a path-like bounded-treewidth family, independent
products, a DEAD tautological padding clause, a duplicate clause, fixed and
token/record encodings, clause/slot permutations, variable-renaming INTERP,
COPY, and RECOMP.  Construction, comparisons, table writes, forward access,
inverse access and reconstruction are counted separately.  Python wall-clock
measurements are recorded but not promoted to asymptotic evidence.

DELAY does not change the source index and may arbitrarily inflate a solver's
trace.  INTERP requires reindexing the renamed explicit formula, while RECOMP
may rebuild the same index rather than store it.  A maximal semantic oracle
can answer SAT without this syntactic index.  An algebraic oracle can likewise
bypass occurrence order.  Therefore the index is neither a semantic
invariant nor a universal same-execution resource.

The theorem relativizes: an unrelated oracle does not affect sorting.
Algebraization is irrelevant to the positive indexing theorem and remains a
barrier to any later separation.  No constructive circuit property is used,
so Natural Proofs is not the immediate issue.  Baker--Gill--Solovay and
Aaronson--Wigderson still block unqualified promotion of a relativizing or
algebrizing chain \cite{bgs,aw}.

\paragraph{Post-quantum technique ledger.}
Schur squares, quadratic-relation ranks, Hilbert functions and syzygies have
no exact object correspondence to the occurrence permutation here; importing
them is a \textbf{FAILED TRANSFER}.  Lossiness/collision entropy is also
irrelevant because both tables are bijective on literal positions.  The
LWE-style lesson of external black-box extraction is only an
\textbf{ANALOGY/CANDIDATE}: external indexing demonstrates availability but
not work paid by the target decider.  No cryptographic assumption is used.

stronger than the offline theorem and strictly narrower than an
arbitrary-algorithm lower bound.
