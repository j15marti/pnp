\begin{abstract}
LB-0015 proves an exact dichotomy for the largest query actually reached by
one fixed extensional SAT-oracle transducer.  This report stress-tests the
tempting but stronger interpretation that positive query scale witnesses a
semantically necessary SAT resource.  It does not.  For every fixed rational
$\lambda>0$, a uniform wrapper may prepend an ignored satisfiable proper
3-CNF query of encoded length $\Theta(N^\lambda)$, or make its answer flow
through the cancellation $b\oplus b$, without changing the transducer's
extensional output on any source.  Erasing that wrapper restores the old
query scale.  All query writing and solver execution remain genuinely
charged; the point is non-invariance under extensionally equivalent programs,
not free computation.

Thus \texttt{QUERY-SCALE-WRAPPER-GAUGE1} is \EXACT, pending independent
review, while \texttt{POSITIVE-SCALE-SEMANTIC-NECESSITY1} is \RETIRED.
LB-0015's fixed-program accounting theorem survives unchanged.  A
wrapper-normalized, solver-independent source compiler into a model-matched
forbidden time--space region remains \OPEN.  P versus NP remains \OPEN.
\end{abstract}

\paragraph{Target and quantifiers.}
The falsification target was the universal implication
\[
 \forall E\ \bigl[\limsup_N\sigma_E(N)>0
 \Longrightarrow
 \text{some positive-scale SAT answer is semantically necessary for }E\bigr].
 \tag{PSN}
\]
Here $E^{\SAT}$ is one uniform deterministic extensional oracle transducer,
$N$ is the encoded source length, and $\sigma_E(N)$ is LB-0015's logarithmic
scale of the largest actually reached query.  The same-realization objects
are the source, the actual wrapper query, its exact SAT bit, the returned
output, and the fully charged composed execution.  One counterexample
transducer falsifies (PSN).

\section{Exact wrapper theorem}

Fix a canonical self-delimiting binary encoding of proper 3-CNF.  For a fixed
rational $\lambda>0$, let $m_N=\lceil
N^\lambda/(c\log(N+2))\rceil$, where $c$ is a sufficiently large encoding
constant, and define
\[
 T_{N,\lambda}=\bigwedge_{i=1}^{m_N}(x_i\vee y_i\vee z_i)
\]
using disjoint triples of fresh variables.  Every clause is proper, the
formula is duplicate-free, the all-$x_i$ assignment satisfies it, and
\[
|\operatorname{enc}(T_{N,\lambda})|=\Theta(N^\lambda).
 \tag{1}
\]

\begin{theorem}[\texttt{QUERY-SCALE-WRAPPER-GAUGE1}]
Let $E^{\SAT}$ be any uniform deterministic extensional SAT-oracle transducer
with one-bit output $g(F)$.  For every fixed rational $\lambda>0$ there are uniform
transducers $D_\lambda(E)$ and $C_\lambda(E)$ such that, for every source
$F$ of encoded length $N$:
\begin{enumerate}[nosep]
\item both wrappers return exactly $g(F)$;
\item each first constructs and queries $T_{N,\lambda}$;
\item $D_\lambda$ ignores the answer $b$, while $C_\lambda$ returns
      $g(F)\oplus(b\oplus b)$;
\item their largest actual reached query length is
\[
 q_{D_\lambda(E)}(N)=q_{C_\lambda(E)}(N)
 =\max\{q_E(N),|\operatorname{enc}(T_{N,\lambda})|\}
 =\max\{q_E(N),\Theta(N^\lambda)\};
 \tag{2}
\]
\item query construction and serialization add $\Theta(N^\lambda)$ work,
      and composition with a fixed exact solver $A$ adds
      $T_A(\Theta(N^\lambda))$ time plus the declared query-buffer cost.
\end{enumerate}
In particular, if $E$ has no queries or $q_E(N)=N^{o(1)}$, then the wrappers
have positive scale $\lambda$ while the erasure that deletes the first query
has the same extensional output and restores the old scale.
\end{theorem}

\begin{proof}
The construction of $T_{N,\lambda}$ is uniform and (1) follows because there
are $\Theta(N^\lambda/\log N)$ records whose fresh indices use
$\Theta(\log N)$ bits.  Both wrappers then run $E$ unchanged.  Ignoring $b$
proves the first equality of outputs, and $b\oplus b=0$ proves the second
even though the answer is syntactically data-dependent.  The set of reached
queries is exactly the old set together with $T_{N,\lambda}$, proving (2).
Writing that explicit query costs its length.  Replacing the oracle by $A$
executes $A$ on that same string, so the final cost statement is a direct
same-realization ledger.  Deleting the wrapper query does not alter $E$ or
its output. \qedhere
\end{proof}

The theorem is an exact program-transformation result.  It is not an
asymptotic inference from the experiment below.  It directly falsifies (PSN)
and also defeats a repair based only on syntactic answer dependence.

\section{What survives from LB-0015}

No line of \texttt{BLACKBOX-QUERY-SCALE-DICHOTOMY1} is contradicted.  That
theorem fixes one transducer and charges what it actually does.  The wrapper
really did write a polynomial-scale query and, after oracle substitution,
really did pay the chosen solver's cost.  Therefore its positive-scale branch
correctly admits delay-wrapper inflation.  The new theorem rules out only a
different inference:
\[
 \text{charged cost in one program}
 \not\!\Longrightarrow
 \text{semantic cost unavoidable in every output-equivalent program}.
\]

This distinction matters for the clean-core project.  Let
$\mathcal H_{2,2}$ denote the duplicate-free proper Monotone
3-SAT-$(2,2)$ source family used in the current synthesis, with canonical
encoded length $N=\Theta(n\log n)$.  The wrapper may be placed before any
transducer on this family and does not change one source answer.  Hence its
query scale cannot by itself lower-bound compatibility extraction, memory,
communication, or decision time on $\mathcal H_{2,2}$.

\paragraph{Smallest repair.}
A load-bearing theorem must quantify over an externally fixed source
compiler and prove its total ordinary-machine cost, or define a
wrapper-normalized resource with a proved lower bound over every equivalent
implementation.  Merely requiring a reached query, positive scale, or a
syntactic dataflow edge is insufficient.  Taking an infimum over all
equivalent programs does not solve the problem by definition: the project
must still prove the lower bound and connect the minimizing resource to a
model-matched FLMV endpoint.  That is \texttt{WRAPPER-NORMALIZED-SOURCE-
COMPILER1}, \OPEN.

\section{Hostile controls, encoding, and one-bit output}

\paragraph{Affine, Horn, 2-SAT, and bounded treewidth.}
All four admit direct polynomial algorithms, yet can be used for the padded
query.  The answer is known and still irrelevant.  Hidden algebraic or graph
structure therefore makes the wrapper easier, not harder.

\paragraph{Independent products, redundancy, and padding.}
Disjoint clauses give exact size control.  Duplicates and unused comments can
change bytes without changing SAT semantics; the theorem avoids relying on
them by using distinct proper clauses.  Fixed polynomial source padding
rescales $\lambda$ to $\lambda/a>0$ and does not restore invariance.

\paragraph{Alternate encodings and wrappers.}
Variable reversal, clause reversal, DIMACS-like and compact text encodings
were checked.  Constants change, not the polynomial scale.  DEAD gives direct
irrelevance; CANCEL defeats a syntactic-dependence repair; COPY, DELAY,
INTERP, and RECOMP preserve the output while changing trace, call count,
reconstruction operations, or timing.

\paragraph{One-bit decision.}
The returned object may be just $\SAT(F)$.  The wrapper adds a query bit but
does not alter that output.  Requiring a larger compatibility table changes
the output contract and its writing cost must be charged.

\section{Primary literature and barrier-transfer audit}

Fortnow--Lipton--van Melkebeek--Viglas prove time--space exclusions for one
ordinary deterministic random-access SAT machine and explain the need for a
locally computable, model-matched reduction \cite{FLMV}.  They do not turn a
query used by one wrapper into work common to all equivalent programs.
Baker--Gill--Solovay formulate relativized polynomial query machines and
construct both equality and separation oracle worlds \cite{BGS}.  The present
wrapper theorem is black-box and relativizes.  Aaronson--Wigderson's
algebrization barrier remains active \cite{AW}; giving low-degree extension
access does not make the ignored bit semantically necessary.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{DIRECTLY TRANSFERABLE THEOREM.}
FLMV transfers only after an actual ordinary-machine time/space realization
has been constructed.  BGS and AW transfer as barrier audits for this
relativizing/algebrizing wrapper argument.
\item[] \textbf{USEFUL ANALOGY REQUIRING A NEW TRANSFER THEOREM.}
Honest/length-controlled reducibilities, communication bandwidth, VLSI
routing, data-provenance slicing, and program dependence analysis all stress
that size and relevance are interface properties.  None forces arbitrary SAT
deciders to use this query.
\item[] \textbf{MISLEADING ANALOGY / FAILED TRANSFER.}
Physical fanout, proof-system size, branching-program width, Schur squares,
quadratic-relation rank, Hilbert functions, syzygies, collision entropy, and
cryptographic binding do not repair wrapper invariance or give an unrestricted
one-bit SAT lower bound.
\end{description}

The post-quantum classification is therefore FAILED TRANSFER for all selected
algebraic invariants as an explanation of this wrapper cost.  LWE-style
external extraction is an ANALOGY/CANDIDATE only; it still needs the missing
uniform source compiler.  No cryptographic or random-oracle assumption is
used.  Natural Proofs is not directly triggered because no constructive
large property against general circuits is proposed.
