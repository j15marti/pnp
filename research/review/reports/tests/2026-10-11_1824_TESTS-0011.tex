\begin{abstract}
MODELBRIDGE-0016 proves that covariance under all constant program
replacements makes every extracted invariant source-only; it leaves typed
wrapper covariance as the proposed repair.  This run tests the obvious typed
grammar.  Programs are distinct tagged base implementations closed under
DIRECT, DEAD, COPY, DELAY, INTERP and RECOMP constructors, each of which
retains one child.  The terminal base tag is an exact invariant of every
wrapper word.  Hence the transformation graph has one component per base and
cannot cover arbitrary polynomial SAT implementations.  Assuming
\(\SAT\in P\), inert syntactic tags produce arbitrarily many exact uniform
polynomial SAT bases, so the failure occurs inside \(\PolySAT\).  Adding
constant replacement joins the components, but then the factorization
theorem of MODELBRIDGE-0016 applies.

Thus \texttt{TYPED-WRAPPER-ORBIT-SEPARATION1} is \EXACT{} in the declared
grammar, pending independent review, and
\texttt{CHILD-PRESERVING-TYPED-COVERAGE1} is \RETIRED.  This does not rule
out a richer non-retractable typed compiler; proving its coverage and
resource preservation for every uniform SAT decider remains \OPEN{} and is
separation-strength.  A bounded audit checked 12,440 programs, 3,184,640
semantic evaluations, all preprocessing/extraction/reconstruction ledger
events, easy-family controls and the replacement collapse in 6.46 seconds.
P versus NP remains open.
\end{abstract}

\section{Clean core and exact attacked target}
Let \(\mathcal H_{2,2}\) be the duplicate-free proper Monotone
\(3\SAT\)-(2,2) family used by the current synthesis.  On \(n\) variables it
has \(4n/3\) clauses and canonical indexed bit length
\[
 N=|\operatorname{enc}(F)|=\Theta(n\log n).
\]
For \(F=C_1\wedge\cdots\wedge C_m\), set
\[
 H(F)_{\alpha,j}=1\quad\Longleftrightarrow\quad \alpha\models C_j.
\]
SAT asks only whether \(H(F)\) has an all-one row.  A one-bit decider need
not expose \(H(F)\), an assignment, trace, state, proof, memory image or
communication transcript.

Let \(\PolySAT\) be the codes of total uniform deterministic polynomial-time
machines deciding the same canonical SAT language, with no common exponent.
The exact typed-coverage proposal attacked here is
\[
 \SAT\in P\Longrightarrow
 \forall A,B\in\PolySAT\ \exists u,v\in\mathcal W^*:
 u(A)=v(B),
 \tag{TC}
\]
where \(\mathcal W\) contains only the declared single-child constructors
DIRECT, DEAD, COPY, DELAY, INTERP and RECOMP.  Literal code equality in (TC)
can be weakened to membership in the same undirected transformation
component; the theorem still refutes it.

The SAME\_REALIZATION object is the actual tagged program code together with
its source formula and executed wrapper chain.  The argument is syntactic
orbit bookkeeping.  It does not infer time, memory or communication from an
orbit count.

\section{Typed wrapper grammar}
\begin{definition}[Child-preserving grammar]
For distinct terminal symbols \(B_i\), define
\[
 P::=B_i\mid W(P),\qquad
 W\in\{\mathrm{DIRECT},\mathrm{DEAD},\mathrm{COPY},
 \mathrm{DELAY},\mathrm{INTERP},\mathrm{RECOMP}\}.
\]
Every constructor contains its child code as a distinguished syntactic
subtree and returns the same SAT bit as its child.  Define
\[
 \operatorname{core}(B_i)=i,
 \qquad \operatorname{core}(W(P))=\operatorname{core}(P).
 \tag{1}
\]
DEAD may execute and discard an auxiliary computation; COPY may duplicate a
bit; DELAY may add polynomial waiting; INTERP may interpret the child; RECOMP
may recompute its answer.  All construction, execution and output work is
charged.  None is allowed to discard its child and return an unrelated base
program, since that is replacement rather than a child-preserving wrapper.
\end{definition}

\begin{theorem}[\texttt{TYPED-WRAPPER-ORBIT-SEPARATION1}]
For every wrapper word \(w\in\mathcal W^*\) and every base \(B_i\),
\[
 \operatorname{core}(w(B_i))=i.
 \tag{2}
\]
Consequently two distinct bases are in different weak components of the
wrapper transformation graph.  If \(\SAT\in P\), then for every \(m\ge2\)
there are \(m\) exact uniform polynomial-time SAT programs
\(A_0,\ldots,A_{m-1}\) in pairwise distinct components.
\end{theorem}

\begin{proof}
Equation (2) follows by induction on the word length.  The empty word fixes
\(B_i\).  If it holds for \(w\), then (1) gives
\(\operatorname{core}(W(w(B_i)))=\operatorname{core}(w(B_i))=i\).
Every transformation edge therefore has endpoints with the same core, so no
undirected path joins distinct cores.

Under \(\SAT\in P\), fix one uniform polynomial SAT decider \(A\).  For each
\(i<m\), form a program \(A_i\) whose code contains an inert distinct tag
\(i\), ignores it and runs \(A\).  These are exact uniform polynomial SAT
deciders with distinct base terminals.  The first paragraph places them in
pairwise distinct components.  No common polynomial exponent is used.
\end{proof}

\begin{corollary}[Coverage/factorization boundary]
The child-preserving typed grammar fails universal orbit coverage.  Adding
every constant replacement \(\kappa_B(A)=B\) makes the graph connected, but
any invariant under those maps factors through the source by
\texttt{REPLACEMENT-COVARIANCE-FACTORIZATION1}.  Therefore this grammar gives
no middle object that is both implementation-sensitive and universal over
\(\PolySAT\).
\end{corollary}

This corollary does not prove that every possible typed transformation has
the same defect.  A core-changing but nonconstant certified compiler is not
excluded.  It must, however, be uniformly defined on every relevant program,
preserve exact SAT behavior, charge code inspection and certificate
generation, and land the \emph{same} ordinary realization inside a published
forbidden resource region.  That is \texttt{NONRETRACTABLE-TYPED-COVERAGE1},
which remains \OPEN.

\section{Semantic shortcuts, padding and one-bit output}
Horn closure, 2SAT implication graphs, affine elimination and bounded-
treewidth dynamic programming all show that large compatibility descriptions
can coexist with cheap one-bit decisions.  Independent products make the
same point componentwise.  Padding, redundant clauses and recodings change
syntax and measured input length but do not force a particular internal
object.  They therefore cannot repair (TC).

The inert-tag construction is deliberately hostile to source semantics: all
bases compute exactly the same bit on every input.  An extensional quotient
would identify them, but under \(\SAT\in P\) that quotient also contains an
ordinary source decider and cannot by itself deliver favorable time--space
exponents.  An intensional quotient retains tags but owes coverage.  This is
the same boundary isolated by MODELBRIDGE-0016, now tested on the proposed
typed repair.

\section{Primary literature and barrier-transfer audit}
Fortnow--Lipton--van Melkebeek--Viglas prove simultaneous SAT time--space
lower bounds on specified random-access machines \cite{flmv}.  Their theorem
transfers only after one actual ordinary machine meets the endpoint bounds;
wrapper-orbit separation supplies no such machine.  Baker--Gill--Solovay
construct relativized worlds with opposite P-versus-NP outcomes
\cite{bgs}, and Aaronson--Wigderson show that the central problem also
requires methods beyond algebrization \cite{aw}.  The present syntactic
invariant relativizes and supplies neither missing hinge.  Blum's
machine-indexed complexity framework \cite{blum} supports explicit program
and cost accounting, but does not identify extensionally equal program
codes or force a canonical representative.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{DIRECTLY TRANSFERABLE THEOREM.}
FLMV applies only after a model-matched ordinary SAT realization has been
constructed with every cost charged.  The graph-invariant proof itself is a
direct elementary transfer from transformation actions to orbit partitions.
\item[] \textbf{USEFUL STRUCTURAL ANALOGY REQUIRING A NEW TRANSFER THEOREM.}
Certified compilation, bisimulation quotients, abstract interpretation and
LWE-style external extraction suggest nonconstant core-changing maps.  The
missing theorem is total coverage of every uniform polynomial SAT program,
uniform certificate acquisition and favorable SAME\_REALIZATION bounds.
\item[] \textbf{MISLEADING ANALOGY / FAILED TRANSFER.}
VLSI routing, distributed cuts, proof-system size, branching-program width,
Schur squares, quadratic-relation ranks, Hilbert functions, syzygies,
collision entropy, special soundness and hash/random-oracle binding do not
connect program orbits or lower-bound arbitrary one-bit SAT computation.
\end{description}

The post-quantum verdict is ANALOGY/CANDIDATE for externally certified
core-changing extraction and FAILED TRANSFER for algebraic invariants used
without an all-program compiler.  Hidden algebraic structure remains an
algorithmic shortcut on the affine control.
