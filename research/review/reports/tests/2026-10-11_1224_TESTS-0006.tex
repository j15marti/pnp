\begin{abstract}
MODELBRIDGE-0010 retires static normalization and leaves a source-only,
$K$-independent, hereditary fractional successor as the live repair.  This
report tests the weakest unrestricted meaning of that repair.  For any
language with one fixed yes-instance and one fixed no-instance, and any
declared deterministic time--space resource class closed under constant
postprocessing, a source-only compiler that emits one constant-size,
decision-equivalent child in that resource class exists if and only if the
language already has a decider in the class.  The forward direction reads
which constant child was emitted; the reverse direction decides first and
emits the matching constant.  Hence source-only construction, a nonempty
ordinary-CNF child, strict contraction, heredity, and one-bit reconstruction
do not define an intermediate bridge unless a separately formalized
construction restriction excludes decision-dependent acquisition.  Under
$\SAT\in\mathsf P$ the construction is polynomial but inherits some unknown
exponent $K$, so no contradiction follows.  A bounded hostile audit passed
$6{,}142$ checks.  P versus NP remains open.
\end{abstract}

\section{Claim card and explicit clean core}

The input is a complete canonical indexed encoding of length $N$.  The clean
core $\Htwo$ is duplicate-free Monotone $3$SAT-$(2,2)$: every clause contains
three distinct variables with one sign, and every variable occurs exactly
twice positively and twice negatively.  Thus $m=4n/3$ and
$N=\Theta(n\log n)$.  D\"ocker proves this family NP-complete
\cite{doecker}; NP-completeness supplies no runtime lower bound.

The desired all-algorithm target remains
\[
 \forall A\ \forall d\ \forall N_0\ \exists F\in\Htwo:\quad
 |\operatorname{enc}(F)|\ge N_0
 \quad\land\quad T_A(F)>|\operatorname{enc}(F)|^d,       \tag{1}
\]
where $A$ ranges over total correct uniform deterministic random-access
deciders and all source reads, output, preprocessing, reconstruction, and
workspace are charged.  Statement (1) is \OPEN and is not assumed.

The tested implication was that the following conditions already define a
weaker bridge: the compiler depends only on the source, emits at least one
ordinary-CNF child, preserves the decision exactly, has fixed child-size
exponent $\lambda<1$, and is hereditary.  The SAME\_REALIZATION contains the
source encoding, compiler, any decision procedure it invokes, child bytes or
accessor, reconstruction bit, recursion, final output, and peak workspace.

\section{Exact endpoint equivalence}

Fix proper three-CNFs $Y$ and $U$ of constant encoded length with
$\SAT(Y)=1$ and $\SAT(U)=0$.  For example, $Y=(z_1\vee z_2\vee z_3)$,
while $U$ contains all eight proper clauses on $z_1,z_2,z_3$.

\begin{definition}[Terminal successor compiler]
For a language $L$ and a deterministic resource class $\mathcal R$, a
terminal successor compiler is a uniform machine $C\in\mathcal R$ such that
for every input $x$,
\[
 C(x)\in\{Y,U\},\qquad x\in L\iff C(x)=Y.              \tag{2}
\]
The unique child has constant length, is an ordinary proper 3-CNF, and is
terminal; hence its scale exponent is $\lambda=0$ and heredity is automatic.
All construction costs are part of $C$'s resource bound.
\end{definition}

\begin{theorem}[\texttt{SOURCE-SUCCESSOR-ENDPOINT-EQUIV1}]
Let $L$ be any language.  Let $\mathcal R$ be a deterministic time--space
class in one fixed machine and encoding model, closed under emitting and
comparing a constant string.  Then the following are equivalent:
\begin{enumerate}[label=(\roman*)]
\item $L$ has a decider $D\in\mathcal R$;
\item $L$ has a source-only terminal successor compiler $C\in\mathcal R$.
\end{enumerate}
The statement continues to hold with arbitrary supplied implementation code
present but ignored.
\end{theorem}

\begin{proof}
For (i)$\Rightarrow$(ii), run $D(x)$ and emit $Y$ on answer one and $U$ on
answer zero.  Constant output and postprocessing preserve membership in
$\mathcal R$.  For (ii)$\Rightarrow$(i), run $C(x)$ and accept exactly when
its constant output equals $Y$.  Again only constant postprocessing is added.
The construction reads no supplied implementation code, proving the final
sentence.
\end{proof}

\begin{corollary}[Fixed-exponent form]
For every fixed declared pair $(c,\rho)$, a terminal successor with fully
charged time $N^{c+o(1)}$ and space $N^{\rho+o(1)}$ exists exactly when $L$
has a decider with those bounds, up to constant postprocessing.  Therefore a
theorem putting the compiler inside an FLMV-forbidden time--space region is
already the forbidden endpoint theorem, not a weaker extraction result.
\end{corollary}

\begin{corollary}[P equals NP audit]
Assume $\SAT\in\mathsf P$ and fix a polynomial SAT decider with exponent
$K$.  The theorem gives a uniform source-only, nonempty, hereditary,
$\lambda=0$ successor on every 3-CNF, including $\Htwo$, but its acquisition
time is $N^{K+o(1)}$.  This is consistent with $\mathsf P=\mathsf{NP}$ and
does not enter any fixed forbidden region.  No premise below assumes
$\mathsf P\ne\mathsf{NP}$.
\end{corollary}

The theorem is deliberately narrow.  It does not refute a construction-
specific identity whose control flow and child bits are proved within a
fixed favorable bound without first obtaining the source decision.  It shows
that ``source-only,'' ``strict,'' and ``hereditary'' do not express that
missing restriction.  TESTS-0005 and RT-0009 already show that external
output time and fixed trace prefixes do not supply a robust decision boundary.

\section{Shannon and output-volume controls}

Full Shannon terminalization emits one leaf for each of $2^n$ assignments.
It achieves constant child size, but explicit acquisition/output is
$\Omega(2^n)$ and therefore is not a polynomial source compiler for
$N=\Theta(n\log n)$.  A one-variable split emits only two restrictions, but
on $\Htwo$ it leaves at least $m-4$ untouched clauses.  Thus the residual
indexed length is $N-O(\log n)$ before proper-3-CNF re-expansion and exceeds
$N^\lambda$ for every fixed $\lambda<1$ for all sufficiently large $N$.
Assigning a block of $q$ variables leaves at least $m-4q$ untouched clauses;
forcing a sublinear clause residual requires $q\ge n/3-o(n)$ in this crude
worst-case certificate, while exhaustive emission has $2^q$ branches.

These are construction-accounting guards, not universal lower bounds.  A
semantic selector may avoid exhaustive emission only by supplying the very
acquisition theorem at issue, and an arbitrary decider may use a different
representation or shortcut entirely.

\section{Literature, barrier, and transfer audit}

FLMV gives unconditional simultaneous time--space lower bounds for SAT in a
declared random-access model \cite{flmv}; it applies only after the compiler
and recursive evaluator inhabit that same model with all costs charged.
Fortnow--Santhanam, Drucker, and Dell--van Melkebeek give powerful conditional
compression/sparsification consequences \cite{fs,drucker,dvm}.  They cannot
be used as an unconditional contradiction under $\mathsf P=\mathsf{NP}$,
because their polynomial-hierarchy-collapse conclusions are already
compatible with that counterfactual.

The endpoint equivalence relativizes: run the same $D^O$ before emitting a
constant child.  Algebraic-oracle access also forwards through the
construction.  Hence the result identifies, rather than crosses, the
Baker--Gill--Solovay and Aaronson--Wigderson barriers \cite{bgs,aw}.  No broad
constructive property of general circuits is used, so Natural Proofs is not
the immediate hinge.

\begin{description}[leftmargin=0cm,labelwidth=0cm]
\item[] \textbf{THEOREM TRANSFER.}
FLMV transfers only to a fully charged same-model evaluator.  The elementary
endpoint equivalence transfers exactly to every resource class closed under
constant postprocessing.
\item[] \textbf{ANALOGY / CANDIDATE.}
Kernelization, compiler refinement, control-theoretic observability, online
communication, and LWE-style black-box reduction architecture suggest
restricted structural interfaces.  Each still needs a theorem excluding
decision-dependent source acquisition for the actual SAT realization.
\item[] \textbf{FAILED TRANSFER.}
Compression output length, VLSI locality, separator messages, pebbling,
explicit child volume, and physical chronology do not lower-bound an
unrestricted one-bit SAT decider without a model-preserving compiler.
\end{description}

For the post-quantum ledger, Schur squares, quadratic relation spaces, Hilbert
functions, syzygies, and collision entropy may classify a proposed source
identity.  They do not exclude decide-then-emit and are \textbf{FAILED
TRANSFER} for this target absent a charged structural construction theorem.
Special-soundness/collision extraction and worst-case/average-case reduction
architecture remain \textbf{ANALOGY / CANDIDATE}; cryptographic or
random-oracle assumptions are inadmissible.
