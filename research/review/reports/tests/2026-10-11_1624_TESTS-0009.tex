\begin{abstract}
For a forward-locally addressed Boolean circuit with constant fan-in,
constant fanout, and a fixed finite gate alphabet, the standard Tseitin
gate relation can be emitted as proper 3CNF using only a gate's type and
children.  No parent query, inverse-incidence table, or dense occurrence
rank is needed.  The output has linear size, constant variable occurrence,
exact witness extension and projection, and an on-demand clause accessor
with the source child-access costs.  This is
\texttt{FORWARD-WIRE-LOCALITY-BYPASS1}, \EXACT\ at the declared interface.
It retires parent enumeration as a necessary condition for locally
generating a bounded-occurrence circuit CNF.  It does not construct the
exact Jahanjou--Miles--Viola (JMV) source circuit, does not normalize the
result to tagged Monotone 3-SAT-$(3,3)$, and does not force any resource
inside an arbitrary one-bit SAT decider.  Those arrows and P versus NP
remain \OPEN.
\end{abstract}

\section{Primary-literature and barrier preflight}

The two obstacles were (i) whether JMV child locality itself supplies
parent ports and (ii) whether parent ports are necessary even for a weaker
bounded-occurrence circuit CNF.  Jahanjou, Miles, and Viola's Theorem~1
gives an addressed 3CNF clause generator; their local-uniformity theorem
returns a gate's type and children, not its parents \cite{jmv}.  Thus the
source paper supports the forward interface used here but does not prove
the missing JMV parent enumerator.

Darmann and D\"ocker prove NP-completeness for exact Monotone
3-SAT occurrence regimes including three positive and three negative
occurrences \cite{dd}.  That result identifies a legitimate eventual
target language.  It does not provide a local, model-matched normalizer
from the JMV generator, so it cannot close the present bridge.

FLMV-style SAT time--space lower bounds require one actual random-access
realization with the reduction bits generated within the stated time and
space costs \cite{flmv}.  A linear-size formula theorem by itself does not
supply that realization.

The exact cross-domain correspondence is a bounded-degree netlist: gate
records name their input wires, and a local CNF record is owned by the
receiving gate.  This is a \textbf{THEOREM TRANSFER} from fixed-template
netlist compilation to the declared circuit interface.  VLSI reverse
netlists and static inverted indexes are only \textbf{ANALOGY/CANDIDATE}
for parent access.  Turning routing congestion, fanout, or index storage
into an unrestricted SAT lower bound is a \textbf{FAILED TRANSFER}.

\section{Forward-wire theorem}

For clarity use $\Gamma=\{\mathrm{AND},\mathrm{OR},\mathrm{NOT},
\mathrm{XOR}\}$.  Give gate $g$ a Boolean variable $y_g$.  Emit the usual
constant CNF for
\[
 y_g=\operatorname{op}_g(y_{c_1(g)},\ldots,y_{c_k(g)}).
\]
For example $y=a\wedge b$ is represented by
\[
 (\neg a\vee\neg b\vee y)\wedge(a\vee\neg y)
 \wedge(b\vee\neg y).
\]
Replace every two-clause $u\vee v$ by
\[
 (u\vee v\vee z)\wedge(u\vee v\vee\neg z)
\]
using a fresh template-local $z$.  Assert the output $o$ by the four proper
clauses $o\vee p^{\epsilon}\vee q^{\eta}$ for
$(\epsilon,\eta)\in\{+,-\}^2$.  Each clause address is
$(g,\text{template slot},\text{padding branch})$ or one of four output
addresses.

\begin{theorem}[\texttt{FORWARD-WIRE-LOCALITY-BYPASS1}]
\label{thm:bypass}
Let $C$ satisfy the exact prefix above.  The formula $P(C)$ has:
\begin{enumerate}[leftmargin=1.5em]
\item $|P(C)|=O(s)$ clauses and variables;
\item $P(C)$ satisfiable iff the asserted output of $C$ is one;
\item extension of every accepting circuit valuation and projection of
      every satisfying CNF valuation in $O(s)$ time;
\item a requested-clause accessor using one type query and at most $d$
      child-label queries, zero parent queries, $O(\log s)$ address space,
      and only constant work beyond the source accessor;
\item maximum occurrence at most $\beta+\alpha\Delta$, where $\alpha$ is
      the maximum number of template occurrences contributed by one
      parent edge and $\beta$ is the maximum own-template/output count.
      For the displayed library, $\alpha=4$, $\beta=9$ is valid.
\end{enumerate}
\end{theorem}

\begin{proof}
Every gate relation uses only its gate label, type, and child labels, so the
addressed compiler never asks which gates use $g$ as a child.  The padding
identity is exact because both padded clauses can hold for some (indeed
every) $z$ exactly when $u\vee v$ holds.  The four-clause output gadget is
satisfiable exactly when $o=1$.  Induction in topological order proves that
all gate clauses force $y_g$ to the circuit value; conversely the circuit
valuation, with arbitrary padding bits, satisfies all templates when the
output is one.  There are constantly many clauses and auxiliaries per gate.
A variable appears constantly often in its own template and in at most
$\Delta$ parent templates, each contributing at most $\alpha$
occurrences.  These facts prove all five items.  The construction, clause
address, source accessor, and output formula are one realization.
\end{proof}

\paragraph{Exact scope.}
The theorem weakens the current requirement from parent enumeration to
forward child access plus bounded fanout.  It does not show that JMV's
exact labels satisfy the fanout premise, nor that the proper 3CNF can be
locally normalized to the exact Monotone $(3,3)$ target.  Parent ports may
still be useful for that normalization; they are simply not necessary for
the bounded-occurrence CNF endpoint proved here.

\section{Hostile controls, costs, and barriers}

Preprocessing is $O(s)$ source queries and output work; local extraction is
one requested template record; witness extension/projection is $O(s)$;
serialization, parsing, copying, delaying, and recomputation are separately
exercised.  The affine control is checked both by circuit evaluation and
GF$(2)$ parity elimination.  Easy controls remain easy; the theorem makes
no semantic-state-to-runtime inference.

The theorem relativizes and algebrizes: an unrelated oracle or algebraic
extension does not invalidate fixed local template expansion.  It supplies
no nonrelativizing or nonalgebrizing hinge.  No constructive property of
hard Boolean functions is used, so Natural Proofs is not the immediate
issue.  A maximal semantic oracle can decide the one output bit without
constructing $P(C)$; hence arbitrary-algorithm acquisition remains OPEN.
DEAD, COPY, DELAY, INTERP, and RECOMP wrappers do not change the theorem's
external compiler and do not make it unavoidable inside a solver.

\paragraph{Post-quantum ledger.}
The LWE lesson of external, construction-defined infrastructure is an
\textbf{ANALOGY/CANDIDATE}: it suggests compiling from forward source
labels rather than forcing a target solver to invert incidence.  It gives
no worst-case/average-case theorem for NP.  Schur squares,
quadratic-relation rank, Hilbert functions/syzygies, collision entropy, and
special-soundness extraction have no exact object map to this local
netlist compiler and are \textbf{FAILED TRANSFER}.  Hidden algebraic label
structure could make the remaining JMV task easier, not harder.
