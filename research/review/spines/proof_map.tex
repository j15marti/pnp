\section*{Reset-aware direct acquisition}
Fix a deterministic verifier $V$, a read-only encoded input $x$ of length $M$,
and witness bound $w(M)$.  Each invocation is specified to start with blank
writable verifier tapes, takes at most $q(M)$ steps and uses $s(M)$ writable
cells.  Suppose a computable bound $b(M)$ covers every writable verifier-cell
address visited, on a fixed number of work tapes.

\begin{theorem}
If the enumerator writes blank to the bounded verifier workspace before every
candidate, at cost $r(M)$, then the first accepted witness, if any, is found in
\[
 O\!\left((2^{w(M)+1}-1)
 (q(M)+r(M)+w(M)+\log(M+2))+w(M)\right)
\]
time and $O(s(M)+w(M)+\log(M+2))$ writable space.  Literal binary address
generation permits the conservative choice
$r(M)=O(b(M)\log(b(M)+2))$.
\end{theorem}
\begin{proof}
There are exactly $2^{w+1}-1$ candidates.  Clearing every possibly visited
verifier cell restores the declared blank start state, while $x$ is shared
read-only.  Every trial therefore has independent-run semantics.  The verifier
tapes are reused, and the counter and address buffers are additive, giving the
displayed peak space.  Writing the blank symbol at each binary-addressed cell
gives the conservative reset cost.
\end{proof}

\begin{corollary}
If $w=\kappa\log_2M+o(\log M)$, $q=M^{v+o(1)}$ and $b\le q$, then time is
$M^{\kappa+v+o(1)}$.  This corollary does not apply without a computable $b$,
to persistent verifier state, or to implicit inputs lacking a charged local
decoder.
\end{corollary}

\section*{Minimal-DAG interface guard}
For
\[
E_n=\bigwedge_{i=1}^{n}
((\neg x_i\vee y_i)\wedge(x_i\vee\neg y_i)),
\]
the reduced OBDD has exactly $3(2^n-1)$ nonterminal nodes in grouped order
$x_1,\ldots,x_n,y_1,\ldots,y_n$ and exactly $3n$ nodes in interleaved order.
The primal graph is a matching, so this is a treewidth-one 2-CNF hostile
control.  As a fixed SAT instance its decision-only DAG is a constant YES
node.  Hence a large minimal DAG in a specified representation does not
lower-bound arbitrary SAT decision without a theorem forcing every decider
to realize that representation.

Fixed-order OBDD canonicity, DNNF compilation and fixed-DAG pebbling remain
valid restricted-model theorems.  The normalization
$x_{\rm DAG}=k-\log_2D$ and $2^{k-x_{\rm DAG}}=D$ is exact but is not a
runtime theorem.  If a reduction frontier permits decide-then-emit, the
constant DAG merely places the original decider time into acquisition; if it
forbids that plan, it is restricted until G2 is proved.
