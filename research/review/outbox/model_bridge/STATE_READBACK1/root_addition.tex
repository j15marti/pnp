\paragraph{STATE\_READBACK1: data-dependent state and later source access.}
For a fixed encoded source domain $X\subseteq\{0,1\}^N$, query set
$\mathcal A$, and exact Boolean relation $H(x,a)$, suppose preprocessing
before receipt of $a$ leaves at most $2^B$ possible source-dependent states.
If every later query makes at most $q$ original-source bit probes, then
\[
 \operatorname{rank}_{\mathbb R}H
 \le 2^B\sum_{j=0}^{\min(q,N)}\binom Nj.
\]
This scoped PROVED/EXACT implication has a complete elementary proof;
independent review is pending. State-fiber query trees have degree at most
$q$, and stacking their row blocks gives the rank bound. It allows arbitrary
data-dependent state encodings and adaptive addresses, rather than demanding
a special invariant trace projection.
The stronger guess $B+q\ge\log_2\operatorname{rank}H$ is FALSIFIED/RETIRED:
a Hamming-code scheme answers equality on seven selector bits with five
retained bits and one later source-bit probe. The implementation lifts this
to 128 actual signed Monotone 3-SAT-$(2,2)$ product formulas, all satisfiable,
and checks all 16,384 selected fully pinned compatibility queries.
Checkpoint bits are not total peak workspace; preprocessing reads the entire
source, and all context-side computation is separate charged work.
The four bounded audits passed 1,138,949 assertions, with no failures.
An ordinary one-bit SAT decider is not thereby required to implement a later
compatibility service. The actual same-execution interface transfer and
