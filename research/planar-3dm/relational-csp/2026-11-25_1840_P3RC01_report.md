## 1. Universal pin-zero gadget
For any original tuple t=(a,b,c), replace t by four tuples using new private elements x,y,z:
 h=(x,y,z), p=(a,y,z), q=(x,b,z), r=(x,y,c).
Internal exact-one constraints are h+q+r=1, h+p+r=1, h+p+q=1 over integers. Subtraction gives p=q=r, hence h+2p=1 implies p=q=r=0, h=1. Conversely that state is feasible. The gadget therefore implements exactly t=0 on all three exterior wires, with unique local lift. Erase the selected private h and gadget IDs to decode. This is valid for any element degree; old degrees unchanged, new elements degree 3, +1 per color, +3 tuples, no duplicates. Incidence drawing: six-cycle of the three new elements and three peripheral tuple vertices, center h joined to the three elements; all three external ports on rim. Rotation/reflection realizes either cyclic order of three labeled ports, so replace the original triple in its embedding disk.
Arbitrary unary guards compile simultaneously: if requested 1-triples collide or also have a zero guard, reject. Otherwise add zero guards on every other triple sharing an element with a requested 1-triple. Apply pin-zero gadget independently to each zero-guarded original tuple. Original exact-one then forces each requested 1. All new private IDs distinct. At most m replacements, linear combinatorial growth, O(N^2) bit encoding conservatively. Witness bijection, deterministic source reconstruction. This avoids treating pins as unsupported native oracles; does not make guarded or unguarded decision polynomial. Even a single forbidden tuple may destroy satisfiability. Gauge or affine hull is unnecessary.

## 2. Cubic small-cut taxonomy
Assume all element degrees 3, hence both vertex classes cubic; G connected. For region R, let T_R number of internal triple vertices, A_c internal element count of color c, p_c outgoing (triple inside) boundary edges of color c, q_c incoming (element inside). Count internal incidences by color: T_R-3A_c=p_c-q_c. For a regional exact assignment, let K selected internal triples and P_c,Q_c active outgoing/incoming boundary counts. Then K-A_c=P_c-Q_c. This is signed integer conservation, not a mod-two relaxation.
For a 1-edge cut, summing degree incidence counts across bipartition forces p-q divisible by 3, impossible. For 2-cut, one outgoing and one incoming; the per-color differences must be congruent mod3, so they have same color. Other colors force K=A_c; counts imply all A_c equal; the two bits agree. For 3-cut all edges same direction (p-q=+/-3). The color counts must be congruent mod3. Therefore either rainbow (1,1,1), or monochrome (3,0,0) up to permutation. Rainbow implies all A_c equal; three active bits agree, permitted mask {000,111}. Monochrome gives K fixed by absent colors and signed count +/-1 on present color: permitted mask {100,010,001}. These are necessary masks only; actual mask may be any subset including empty. For any given exact acquired mask, rainbow restriction is empty/full/one pin; monochrome restriction is empty/full or forbid missing one-hot positions; two-cut equality restriction similarly pins. No independent matching projection suffices.

## 3. Constructive cap lemma, including duplicate protection
Use constant planar cubic fixture Q={001,010,011,100,101,110}. Its incidence is the octahedron vertex/face incidence with two opposite triangular faces removed: octahedron vertices are +/- coordinate axes, triangular faces the 8 choices of signs. All element degrees 3 after opposite removals. Three complementary tuple pairs are perfect matchings; each tuple can be selected or omitted, and every element can be covered by any of its three incident tuples in some matching.
Deleting a triple vertex gives three element-ended rainbow ports with exact full EQ3 mask; complete the missing triple to see both directions. Deleting an element vertex gives three triple-ended monochrome ports with exact full one-hot mask. Deleting one incidence edge gives one triple-ended and one element-ended same-color port with exact equality mask {00,11}: restoration proves both states; signed conservation excludes the others. Each deletion exposes ports on one face. For a cut whose sides are connected, contract the complementary side to one vertex in a plane embedding, replacing that vertex by a suitable cap in a disk. A 2-cut can be capped by the deleted-edge Q relay. For a 3-cut, use a single tuple vertex (rainbow, external endpoints element-side), single element vertex (monochrome, external endpoints triple-side), or the relevant deleted-vertex Q cap when the opposite endpoint type is required. Use a fresh copy of the two-port Q relay on each connection to avoid duplicate tuples created by reusing a cap element or attaching a cap tuple to old elements. Every original boundary triple then obtains its own fresh element for each cut incidence; internal cap/relay tuples have distinct fresh coordinates. The cap is genuinely plane with same port cyclic order (<=3 arbitrary permutations by dihedral symmetry); each element degree 3, each tuple exactly one of each color, thus closed counts equal by cubic incidence counting. All attachments retain source edge/tuple mapping. Each cap is constant size, implements exactly full necessary mask, and any acquired subset is enforced by tuple-bit pins on the cap connection wires; section 1 compiles these unary guards. Verify actual state and erase cap/relay IDs in reverse lift. No need to assume full mask in an arbitrary region. Capping algorithm and embedding gluing are theorem-level, not executed in this run.
This makes local exact mask acquisition a finite number (<=3) of calls to the guarded source solver on the capped side, but those calls are not free. Acquiring them on large prime pieces remains open.

## 4. Polynomially many laminar 3-cut jobs on 3-edge-connected cubic source
Root at one original vertex. In a 3-edge-connected graph, distinct 3-edge cuts oriented away from root have laminar sides. Proof: crossing sides split into four nonempty quadrants. Apply cut submodularity to both opposite pairs: each quadrant has cut >=3 and sums <=6, hence each cut exactly 3 and no opposite-quadrant edges. The four adjacent edge multiplicities then alternate a,b,a,b with a+b=3. A crossing cut has size 2a or 2b, contradicting 3. All nontrivial cuts can be discovered by deleting every edge triple and checking components, O(M^3*(V+M)) graph operations; laminar inclusion tree has O(V) members. Contract child sides and the complement to port factors on each torso. Any nontrivial cut in torso lifts to original and hence is in laminar family; after maximal contraction only trivial three-cuts remain. The local torso retains all original vertices assigned to it plus cap factors, count total O(V); original edge IDs and masks retained. At each node compute its actual boundary table by solving the torso for each of <=3 admissible parent states, enforcing already acquired child masks. For an empty mask reject. Child and parent pins are ordinary guards, not unconditional global deductions. Keep one witness per attainable state and links to child witnesses. A bottom-up pass computes root decision and recursively restores actual original triple IDs. Different guards at one child share its precomputed exact table. No multiplication of all child-state combinations is necessary if a local terminal handles the full torso. With maximum torso size b counting port factors, direct enumeration of O(b) wires costs 2^O(b) poly(N) total; logarithmic b is polynomial. Alternatively a uniform polynomial solver for guarded prime torsos would complete this 3-edge-connected cubic lane. No universal bound on b, nor solver for all prime torsos, is proved. Relay-expanded capped source may itself contain small cuts; do not claim reduction to UNGUARDED cyclically 4-edge-connected P3DM. The laminar tree algorithm is symbolic, not implemented here; 2-cut global decomposition not claimed.
