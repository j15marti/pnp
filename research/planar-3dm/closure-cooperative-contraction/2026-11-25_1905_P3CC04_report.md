## 3. Guard-cover theorem (PROVED)

Let G be any indexed bipartite graph with a perfect matching, m edges, n vertices on each side, and labels in F2^d. Let S be the actual XOR signature support. Suppose H is a certified subspace of Per(S) = {p:S+p=S}; initially H=0. Write r_H for the linear quotient map implemented by elimination. Choose a row x. For each indexed incident edge e which belongs to a perfect matching, let G_e be the guard class of all perfect matchings containing e. These classes are nonempty and partition the perfect matchings. Obtain one matching M_e by pinning e and ordinary bipartite matching. Find F_e = intersection of all matchings in G_e: for every f in M_e other than e, test perfect matching existence under e and deletion of f. An absent alternative makes f forced. The remaining candidates outside M_e cannot be forced. At most n+1 matching tests per incident e, including failed guard support. F_e is an actual disjoint partial matching.

Construct a directed multigraph on F_e's matched pairs. For every original indexed edge (x_i,y_j) connecting the endpoints of pairs i,j in F_e, include arc i->j carrying its ID, excluding the original matched edge of pair i as a trivial replacement. Parallel alternative at i is a loop. Every simple directed cycle C of k distinct pair indices corresponds to rematching those k forced pairs cyclically. The old edges O_C are contained in EVERY matching under guard e. The alternate edges A_C are disjoint and cover exactly the same X and Y vertices. They need not retain e: e is only an exposure guard, not a permanent source pin.

Define D_e(H,L) as zero together with every r_H(signature(O_C) XOR signature(A_C)) from such cycles of length <= L. Retain an actual (O_C,A_C) for each direction. Fixed L permits explicit enumeration in polynomial time. If

    p in intersection over supported e at x of D_e(H,L), p != 0,

then p is a true period of r_H(S). Indeed, take ANY actual perfect matching M, find its unique incident guard e at x, and use that guard's stored cycle for p. Its entire old edge set is present. Replace it by its alternative. The result M' is a genuine matching of the original graph and r_H(sig(M')) = r_H(sig(M))+p. Translation is involutive, so this inclusion proves equality. Different guards can use different, overlapping cycles and even different lengths; no simultaneous activation or Cartesian product is assumed.

Scan every row and all its supported indexed guards. Enlarge H by any nonzero certified quotient direction, store that step's guard-to-cycle dictionary, repeat until exhausted. Every update increases rank, at most d successful updates. Candidate acquisition is target-free, uses only ordinary matching and short directed cycle enumeration. No matching-signature enumeration is required. This differs from P3CC03's parallel-only certificate and from FG04's restricted product charts; the entire relaxed matching universe is covered by a certified partition into guard classes, and each class has its own actual repair. It is also complementary to MF02's height-lattice neutral flip certificate. Planarity is not needed for this particular exchange lemma.

Canonical least fixed point for the stated certificate family: forced sets and candidate cycles depend on the original matching graph and the chosen guards, not on H. If H⊆H', any common direction maps to zero or remains a common direction in the coarser quotient; each stored cycle projects accordingly. Therefore the closure operator (add the spans of all common directions across all rows) is extensive and monotone. Any exhaustive sequential one-direction process reaches the same least fixed point starting at zero. This proves order independence for this certificate family only, not completeness for all semantic periods. Can combine monotone P3CC03 parallel certificates as well.

## 4. Reverse lift, arbitrary forced-block rematches and exact constant test (PROVED)

A source target t is in S iff r_H(t) is in r_H(S) because H is a true period subspace. To lift, start with an actual quotient-target matching, undo updates in reverse. At a step H_old -> H_old+<p>, the residual target difference modulo H_old is zero or p. If p, locate the current matching's guard e and apply its stored exchange (always recompute e: a previous exchange may change it). This reduces the residual to H_old and preserves actual matching. At H=0, exact target restored; verify integer occupancies and original permanent guard RHS. Arbitrary XOR of feasible matching words is never treated as a feasible matching. Intermediate words need not meet the full appended affine target. Since all steps act on the permanently filtered original matching graph, permanent graph pins remain preserved.

Generalization: replace one pivot row by a fixed set of r rows and enumerate jointly supported indexed selections with at most m^r branches. Same theorem with F_guard. For each branch, the entire graph induced by the endpoints of F_guard may be rematched in ANY way. If its actual signature support can be acquired with cap K using P3CC03B signed sparse determinant method (local graph remains planar), subtract signature(F_guard), project, intersect these actual shift sets across all supported branches. Every common shift again gives a true period, with actual local matching lifts; can handle cycles of arbitrary length and coupled disjoint cycles. Cap overflow can fall back to the bounded-cycle certificate or UNKNOWN, never a source rejection. This generalized sparse rematching implementation was not executed this run. A single reference chart of independent disjoint cycles is another valid lower bound on each branch's actual attainable shifts; intersection of actual span directions from such charts is valid only because each chart supports all combinations of its independent cycles, not because arbitrary overlapping cycle shifts span a vector space.

After a period contraction, exact quotient constancy can be recognized without any support enumeration (related to FG04's affine-span backend). Acquire any reference perfect matching M0, contract its matched pairs and orient every edge x_i-y_j as i->j, weight by quotient label(edge) XOR quotient label(reference edge at i). Restrict to arcs inside SCCs. All actual matching differences decompose into directed cycles. Conversely each simple cycle gives one actual alternative to M0, including indexed parallel loops. Thus quotient support is a singleton iff every directed simple cycle has XOR weight zero. Inside an SCC this is equivalent to existence of vertex potentials a_i satisfying w(i,j)=a_i XOR a_j: zero on directed cycles implies zero on all closed walks by decomposition, so path sums from a root are independent (append a return path). Conversely potentials telescope. Acquire potentials by any spanning tree of the underlying SCC and check every arc including loops. If test passes, the quotient support equals {r_H(sig(M0))}; compare target and reverse-lift as above. If it fails, invoke the P3CC03B capped sparse support acquisition or other exact terminals; no rejection from nonconstant support. Supplement executes this test on constant-size fixtures with an enumerated reference matching; production reference acquisition uses the ordinary matching algorithm already executed in primary audit.
