## 3. Robust periods and bonds (PROVED)

Partition indexed edges with the same X,Y endpoints into disjoint classes of size one or two; choose any fixed pairing. A two-label class with labels u,v has actual independent switch direction e_u+e_v, singleton has zero. A class skeleton Q is a perfect matching of the bipartite multigraph of classes (one class per matched pair). Every indexed matching belongs to exactly one Q. Its possible signatures are precisely a_Q+H_Q, where a_Q chooses one actual index in every class and H_Q is the binary span of selected class directions. Indeed toggle each selected two-index class independently; all binary combinations are actual matching changes, not arbitrary XORs of unrelated full matchings.

Define H*=intersection over all Q of H_Q. It is a subspace of semantic support periods: if p∈H*, ANY actual matching in its current Q can toggle a suitable subset of selected classes to shift by p while keeping Q. Gaussian elimination with provenance obtains the toggles in polynomial time. H* may be a strict subset of all semantic periods, which may also change skeleton. If no class perfect matching exists reject by ordinary matching.

Potential switch graph J on Z: one undirected edge type uv per distinct pair direction; multiple classes realizing it are retained in dictionary. For Q, J_Q activates an edge type iff some class in Q realizes it. H_Q is the space of binary vectors of even parity on each connected component of J_Q. For every connected component C of J add row 1_C. A bond B=δ_C(U) of J[C] is a minimal nonempty cut, equivalently both induced shores connected. Delete from the class matching graph ALL classes having pair type in B. If an ordinary perfect matching still exists, call B avoidable and add row 1_U (either shore, modulo 1_C). Then

    H* = nullspace({1_C} ∪ {1_U : B=δ_C(U) avoidable}).

Necessity: avoidable B has a witness skeleton Q with no crossing active pair, so every H_Q vector has even U parity. Sufficiency: H_Q^perp is spanned by component indicators of J_Q. For any such shore U⊆C the full cut δ_C(U) contains only absent types. A nonempty binary cut is an edge-disjoint XOR of bonds contained in it: select a nonempty cut of inclusion-minimal support inside it, XOR and repeat. Such minimum supports are precisely bonds. Every bond so obtained is avoidable using this SAME Q, so its shore indicator is a retained row. The cut map on connected C has kernel span{1_C}; thus 1_U is in retained row span. Isolated tags have row e_z. This proves equality by orthogonal complements. No enumeration of skeletons, target matching, or exponential support is required when the bonds are cheaply listed.

This strictly extends P3CC03 single-switch certificates: common span can be nonzero even if NO individual pair direction occurs in every skeleton. It also differs from P3CC04 guarded rematches: all selected parallel switches in a class chart are independent, and the intersection is acquired through polynomial ordinary matching calls, not by listing the guards. It does not supersede CC04's nonparallel cycles.

## 4. Additive block factorization (PROVED and executed)

Decompose J into ordinary biconnected edge blocks B (bridges included; isolated tags separately). Let W_B be the span of its edge directions. The ambient switch span W=⊕_B W_B: the block–cut incidence forest admits leaf-block elimination, since every W_B vector is even and a leaf block meets the remainder at at most one vertex. Equivalently all graphic dependencies are cycles internal to blocks. For every Q, H_Q=⊕_B H_{Q,B}. Intersection commutes with this FIXED direct sum, even when choices in distinct blocks are strongly correlated:

    H* = ⊕_B (intersection over Q of H_{Q,B}).

For each block independently apply §3 to its pair types, testing avoidance in the FULL class graph, not merely a marginal or induced matching. Thus each block gets its exact common shift space without Cartesian product. A bridge has one bond; a cycle of l edges has binom(l,2) bonds. Fixed/logarithmic-size blocks can enumerate shores; general connected blocks can use the cited polynomial-delay algorithm with cap K. At overflow discard that block's incomplete annihilator computation and certify local space zero (safe). Continue all other blocks. One can also safely stop a block early when accumulated rows span the entire local dual, since additional rows cannot enlarge it.

For cactus J, the algorithm is uniform polynomial regardless of cycle lengths and number of global skeletons. General per-block polynomial bond cap gives a sound partial period solver. With K fixed polynomial, total charged tests O(sum_B min(b_B,K+1)) plus polynomial-delay work; b_B is actual bond count. Implemented backend: bridges, cycles and exhaustive connected shores for blocks with <=9 vertices; it skips other blocks, no external bond enumerator executed. Direct-sum rank is at most n. Empty J gives zero shifts, not NO.

## 5. General binary affine-class / matroid cocircuit extension (PROVED, not implemented beyond graphic case)

For arbitrary explicit full binary labels (e.g. append guard columns), group parallel indexed edges into classes whose actual label support equals an affine space a_c+L_c. All classes of size one or two satisfy this automatically; larger groups require verifying the actual support, not assuming its affine hull is realized. Verification for an explicit list: row rank and distinct count=2^rank, plus membership; actual label-to-index dictionary gives lift. Any class skeleton realizes exactly a_Q+sum_{c∈Q}L_c. Use D with a basis of every L_c as columns, W=im D. For a nonzero functional α on W, codeword αD has support on exactly the basis columns it sees. Minimal nonzero supports in this binary row code are matroid cocircuits; a general codeword is XOR of disjoint such minimal supports by inclusion-minimal support subtraction. For every cocircuit α, delete all classes c with α|L_c nonzero and test ordinary matching. The annihilator of the span of all avoidable cocircuit functionals in W is exactly intersection_Q sum_{c∈Q} L_c, by the same proof as §3: a functional annihilating one Q is decomposed into cocircuits supported inside its own support, and all are avoidable by that Q.

More generally decompose the represented column matroid into its connected components via fundamental circuits of any acquired column basis. Their spans form a fixed direct sum. A class basis may occupy several components, but its span decomposes across them. Each local avoidability test removes the full relevant class; other components' choices remain free within the full matching graph. Thus exact blockwise intersection also holds here. Bounded component rank r gives <=2^r functional tests per block, independent of its number of columns; no general polynomial cocircuit enumeration bound asserted for arbitrary represented matroids. The graphic specialization compresses rank-unbounded cycles through their small bond lists. This extends the earlier MFC finite interaction summaries to an actual attainable affine-class family. Do not substitute a basis of an affine HULL for a class response set.

Combine any certified H with earlier CC03/04 semantic periods by addition, since period directions form a subgroup. If a quotient target matching is acquired, express difference in stored period basis and reverse actual repairs. For a robust shift, solve the linear system using selected classes' bases and choose each actual new label from its dictionary. Original guard targets restored before verifying exact coverage. When a prior certificate is conditional on quotient, reverse steps in its original order, updating actual guards. Across distinct projection lanes share only authenticated source deductions/IDs, not raw syndrome directions in different tag coordinate systems.
