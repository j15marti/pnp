## 2. Conserved block compression theorem
Form graph on labels z by joining two labels whenever both have nonzero coefficient in some same non-root height coordinate. Connected components C are obtainable by support scan/union-find. Since all nonzero entries of any column belong to one C, sum_{z in C} a_z=0. If sum_{z in C} b_z !=0, reject exact feasibility. Otherwise for each C choose either direction d_C in {+1,-1} and impose only d_C*(a_z dot h-b_z)>=0 for every z in C. The sum is identically zero, so every summand is exactly zero. Thus this is an exact replacement of bilateral occupancy equalities, even over rationals. Different components may independently choose direction, while edge constraints still link heights globally. Singleton zero-support rows handled as constant consistency. Direction discovery for each block tests two signs; if a chosen direction gives every row at most one strictly positive coefficient, retain it. Every edge bound and source pin already has at most one positive coefficient per inequality in the unchanged height coordinates. This certifies one admitted class without a guessed decomposition or branching. For a row with at least three nonzero coefficients, requiring BOTH signs to be one-positive is impossible under any sign flips; one-sided conservation can admit such a row.

## 4. Integer least-fixed-point theorem
For ANY finite integer inequality system with at most one strictly positive coefficient per row and explicitly bounded integer domains [L_i,U_i], start at L. For violated row with unique positive coefficient a_i>0, set u_i to ceil((b + sum_{j!=i}(-a_j)*u_j)/a_i). If no positive coefficient and row violated, reject. If raised value exceeds U_i, reject. Otherwise repeat until all rows hold. Proof invariant: every feasible u* is coordinatewise >= current vector. The update is a monotone necessary lower bound since other coefficients nonpositive; a no-positive violated row cannot be improved by increasing coordinates. Thus a rejection is exact, and termination at a feasible point gives coordinatewise least solution. Strict integer increases at most sum_i(U_i-L_i) <=2mF. Full scans including failed tests cost O((1+2mF)*L) arithmetic operations for L explicit inequality size; polynomial for height domains, not arbitrary binary-encoded huge domains. No floating rounding. This solves all admitted charts, returning YES or NO. Reconstruct original s_e, verify all three exact-one rows and guards. For guarded calls one can rerun same admitted terminal with pin inequalities; if one guard is proved NO force opposite and reclose. Each region's least-closure operator on a given shared lower bound (private coordinates reset to their lower bounds) is monotone and sound, returning necessary shared increases or NO.
