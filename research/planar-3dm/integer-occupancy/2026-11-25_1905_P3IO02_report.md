## 2. Relay insulation theorem (main new result)
Let Q={001,010,011,100,101,110}. It has planar incidence: octahedron vertex/face incidence with opposite triangular faces removed. Each color has two elements and each element degree3. Q covers are exactly the three complementary pairs. For an incidence from triple r to element v of color c, introduce a private Q with colors permuted so X is c; cut X0--A=001, connect r to private X0 and A to v. Both ports cofacial by deleting the edge from a planar embedding. Repeat L>=1 times in series, always connecting outgoing A to next private X0, last A to v. Distinct private IDs, old tuple identities retained, no duplicate triples; preserve source incidence embedding by disk/strip replacements. Adds 6 triples and 2 elements of EACH color per relay; full expansion of all 3m incidences has m'=(1+18L)m, n'=n+6Lm. Original element degrees unchanged; private elements degree3. Hence degree-2/3 NP-hard restriction maps into itself; exact3 preserved if supplied. Connectedness preserved when present.

Integer exactness: in a relay, internal selected triple count is 2 by either unchanged color, and by the changed color counting it is 2 + outgoing(A) - incoming(r); equality gives A=r. Restoring removed incidence gives Q cover, exactly one of three states. For r=1 choose A=001,F=110; for r=0 choose B=010,E=101 or C=011,D=100. Conversely these patterns solve relay. Thus any source cover lifts, every expanded cover projects to original by retaining original triple bits, all original element occupancies exactly one. No claim of unique lift; q=0 has two choices per relay. This is uniform polynomial source reduction for polynomial L, including constructive lift/verification, not a solver for all sources.

**Theorem (exact LP projection).** For every rational x in P0 of ANY source, set r_i=A_i=F_i=q=x_r along each original incidence, and B_i=C_i=D_i=E_i=(1-q)/2 in every relay. This extends x to a point of P+ of the expanded source. Conversely every P+ point of expanded source projects to P0, since the same integer conservation identity holds over rationals. In particular the projection is exactly P0, not just a containment. Original tuple pins may be retained under this projection/extension; arbitrary private pins not claimed.

Proof: all exact-one rows hold by conservation and convex mixture of the three actual local states, weights q,(1-q)/2,(1-q)/2. Conflict graph is the union of relay blocks (six local triples and incoming r) and original element cliques on terminal A ports. Blocks intersect only at single shared vertices. Bipartite block--shared-vertex incidence is a subdivision of original incidence, with no short cycles. All cliques and every simple odd wheel lie within a block: neighbors of each vertex separate by its incident blocks, with no cross edges between these groups (a cross edge would give a mixed triangle, impossible in subdivided block graph). Each block vector is in its actual stable-set polytope by local mixture or original element simplex. So all clique and simple wheel cuts hold. All local edge lengths ell=1-x_i-x_j nonnegative. A simple mixed cycle must visit an original element clique and have an external path from two distinct ports of that clique (without this, relay blocks form trees about original triples, so a cycle is local). Each path from a terminal A through its relay to incoming r must pay at least 1-q: r has only B,C as local neighbors, all neighbors of A internal (apart from exterior) have weight (1-q)/2 except F which is nonadjacent; first and last edges thus each cost (1-q)/2. They are distinct since r,A nonadjacent. At the two distinct terminal ports q_i+q_j<=1 by original exact-one; the two paths are disjoint as portions of simple cycle and cost >=2-q_i-q_j>=1. Hence every mixed odd cycle satisfies its inequality. Local odd cycles already valid by actual block mixture. Q choice and port order are explicit; no fake projected edges, no rounding.

**Corollary (arbitrary bounded-support cuts).** Given any fixed k choose L>k. For every subset S of <=k expanded conflict vertices, the induced local block-interface graph retaining only shared vertices in S is a forest: every cycle of full interface graph crosses a full relay chain and uses at least L distinct shared vertices. The local stable-set distributions restricted to S agree on each shared singleton marginal. Glue along each tree by conditioning on separator bit; zero-probability states irrelevant. The resulting probability distribution on independent sets of C[S] has exactly the extended marginals. Thus EVERY valid stable-set inequality supported on <=k vertices holds, not just rank cuts or triangles. If S contains all neighbors of an element, its exact-one row holds almost surely since at most one and expected one. This does not establish consistent joint marginals across ALL S (not a Sherali--Adams proof), or unbounded-support inequalities beyond named simple cuts. L=k+1 even polynomial in input is a polynomial blowup if k polynomially bounded in ORIGINAL size; cannot infer hardness for a support threshold defined as arbitrary fraction of expanded size.
