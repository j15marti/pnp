## 1. Exact signed phase compiler

For valid explicitly encoded source with degree 2 or 3, repeatedly reject empty elements, select singleton triples and delete competitors; retain forced IDs and source witness map. Repeat all three bipartite pair projection allowed-edge checks, deleting only triples whose indexed edge cannot belong to a projected perfect matching. Ordinary matching with each candidate edge forced is sufficient; no pairwise matching asserted sufficient for source. Repeat after deductions and at stagnation, at most O(m) triple changes. Connected incidence components may be solved independently; count imbalance rejects.

Use spins sigma_t=2s_t-1. Degree-two element requires opposite spins. The graph of such pairs must be bipartite; otherwise reject. On each connected component P of this graph, choose a sign eta_t in {+1,-1} and spin x_P so sigma_t=eta_t x_P. Degree-two clauses are then exactly satisfied, including all parity relations. The remaining degree-three element v has three incident triples i,j,k, possibly sharing phase IDs. Its nonnegative exact penalty is
4 (s_i+s_j+s_k-1)^2 = (1+sigma_i+sigma_j+sigma_k)^2 = 4+2(sigma_i+sigma_j+sigma_k)+2(sigma_i sigma_j+sigma_i sigma_k+sigma_j sigma_k).
Sum over all remaining degree-three elements. Obtain integer E4=C+sum_{uv} J_uv x_u x_v+sum_u h_u x_u. Fold same-phase pairs into C and aggregate signed parallel interactions; delete zero couplings. E4>=0 for every phase word and E4=0 iff the word is a source exact cover. The interaction graph is planar: replace each degree-three element star by a triangle in its small embedded disk, suppress degree-two elements to edges, then contract the connected degree-two phase components. Delete loops and aggregate parallel edges. This is a graph-minor/local embedding argument, not an assertion that arbitrary variable identification preserves planarity. An inconsistent phase graph is a real NO; a chart with too many field groups is UNKNOWN. Isolated phase vertices retained. All integer coefficient magnitudes and sum of absolute values O(m).

## 2. Face group theorem (new scoped terminal)

For ANY planar embedding of the phase interaction graph, if the nonzero field support is covered by k faces, assign every field vertex to exactly one of these faces. Insert anchor a_f in each face with edges a_f-u of coupling h_u for its assigned vertices. This is planar even for nonsimple face boundaries (choose one incidence occurrence per vertex). One may connect disconnected interaction components first by neutral bridges and recompute an embedding; alternatively solve independently. Let G be the resulting connected graph; if there are no fields, no anchor needed. Require all anchors to have equal spin. Then on the agreement subspace, relative spins x_u = spin(u)*spin(a_1) recover the original E4 exactly, with two extensions per original phase word. If k=0 use x_u directly. No common external anchor apex is needed, hence no crossing between face groups.

For each edge e of G with signed integer coupling j_e, let c_e(z)=|j_e|+j_e z for z=spin(u)spin(v). Nonnegative costs 0 or 2|j_e|. Then E4=C-sum|j_e|+sum c_e on agreed anchors. Define target d=sum|j_e|-C. If d<0 or exceeds total cost reject. Let B=2^{|V(G)|+1}; evaluate the exact integer
Q=sum_{spin words with anchor agreement} product_e B^{c_e(spin_u spin_v)}.
Its base-B digit at d counts zero-penalty words; no carries because every coefficient <=2^{|V(G)|}<B. Divide by 2 when k>0. This is exact counting for the admitted class, not an inference from counting parity. All exponents O(m), and all integers have polynomial bit length.

For each anchor a_i other than a_1 choose a path P_i from a_1 to a_i. Indicator of agreement is product_i (1+spin(a_1)spin(a_i))/2. Expand into 2^{k-1} terms. A subset of path factors multiplies an edge factor by z on its XOR path set, because internal vertex spins telescope and z^2=1. Thus every term is a zero-field planar partition function with possibly signed edge weights w_e(+), w_e(-). The expansion division by 2^{k-1} is exact. k=0/1 uses one term.

## 3. Exact signed planar evaluator, no hidden oracle

For each edge write w_e(z)= (A_e+B_e z)/2 with A_e=w_e(+)+w_e(-), B_e=w_e(+)-w_e(-). Spin sum over all words is 2^{|V|-|E|} times the weighted even-subgraph sum: sum over F with even degree everywhere of product_{e not in F} A_e product_{e in F} B_e. Multiplying w_e(z) by z swaps A_e and B_e. Zero and negative weights are valid, no divisions by A/B and no probabilistic argument.

Explicit planar perfect-matching gadget for this even-subgraph sum: split high-degree vertex parity into a chain of ternary parity nodes with auxiliary parity wires, respecting cyclic order, unique internal XOR bits for each even external word. Degree 1/2/3 parity node represented by respectively one port, two ports connected by an edge, or a triangle of ports. For each wire joining two ports u,v add path u-a-b-v with distinct new a,b; weights (A, B, 1) on the three edges. Either both outer edges are selected (wire bit 0, weight A), or inner edge is selected (wire bit 1, weight B). In every degree-d city, remaining unmatched ports are exactly its bit-1 wires and must number 0 or 2; each such even pattern has exactly one internal matching. Auxiliary wires have both weights 1. This gives bijective weighted matching expansion, size O(|E|), planar. The empty even subgraph is a known reference matching, so calibrate Pfaffian sign from its orientation. Kasteleyn odd-clockwise face conditions, omitting one face per connected component, are binary linear equations; orientation plus exact Pfaffian (fraction-free elimination) gives signed sum in polynomial bit work. Use same sign for all probes, including negative values. For no-edge graph evaluator directly gives spin factor 2^|V|.

## 4. Lift without increasing anchor count

If zero-energy digit positive, choose root a_1 when anchors exist and assign its spin +1; otherwise root arbitrary and +1 by global flip symmetry. Along a spanning tree of G, test each edge product +1 by setting its opposite edge weight to zero; if zero-energy count becomes zero, choose -1. Maintain previous pins in all probes. This constrains relative spins and retains positivity of the target count, never introduces a field or a new anchor. At most |V|-1 tests, determine all spins, verify anchor agreement and source exact-one, then restore selected singleton IDs. The same exact signed partition function proof allows zero-weight edges. Source witness verification linear in explicit incidences. This is an actual target-free deterministic lift; no free target assignment or semantic oracle.
