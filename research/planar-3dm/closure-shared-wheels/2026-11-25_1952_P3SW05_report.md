## 1. Signed phase compilation and color conservation
Let m be live triples and n live elements per color after sound exact-one closure. Reject empty rows; select singleton and delete conflicting triples, recording original IDs. All three pairwise projections retain indexed triples; reject absent perfect matching and remove only edges in no perfect matching, repeat at most O(m) strict changes. A matching support test uses one bipartite matching and SCCs in its alternating digraph (parallel actual IDs with same endpoints can substitute). The audit instead uses equivalent reachability. It does not accept independent matchings as a source witness.

Every degree-two element requires s_t+s_u=1. Make a graph on triple IDs with those edges. A nonbipartite component certifies NO. Otherwise each connected phase i has a bit x_i with s_t=x_i or 1-x_i on its two sides. Let p_i,q_i count the two sides, choose the gauge so p_i>=q_i, and d_i=p_i-q_i>=0. Each triple contributes exactly one port of each color. A degree-two element of any color removes one positive and one negative port from its phase. Thus for EACH color separately, among the remaining element rows, positive port count minus negative port count for phase i equals d_i. This is an integer identity, not an affine-hull inference. Retain all remaining port occurrences, including duplicates at one row. Phase balanced means d_i=0.

For each color c, arbitrarily but deterministically pair every negative occurrence of phase i with a distinct positive occurrence of the same phase and color. Leftover d_i positive occurrences are tokens of x_i. Make a multigraph G_c whose vertices are the remaining elements of that color, each pair is an edge between its two element rows, and each token is placed at its actual row. Allow loops and parallel edges. Each pair has exactly one active endpoint for EVERY phase word; different pair edges controlled by the same phase are NOT independently choosable. Graph is explicit of O(m+n) size, pairing by source order. Arbitrary pairings need not be topologically drawable inside a phase; this auxiliary graph is only for algebraic aggregation, not claimed a plane source graph. Original incidence graph and IDs retained.

## 2. Exact color-component quota theorem
For connected component C of G_c let v_C,e_C denote vertices and edges (loops count one), t_C(x)=sum of its token occurrences x_i with their actual multiplicities. Total selected incidences at rows in C is identically e_C+t_C(x). In any source cover it must equal v_C. Hence t_C(x)=v_C-e_C. Since C connected, e_C>=v_C-1, so the only possible groups are:
* e_C=v_C-1: tree (including isolated vertex); exactly one active token.
* e_C=v_C: unicyclic (including loop or parallel 2-cycle); all tokens inactive.
* e_C>v_C: certified NO without any Boolean search.

Let A x=b over GF(2) impose odd occupancy at every remaining element (degree-two elements already exact by phase chart). Then the following is an equivalence for EVERY x, not merely existence:
   source exact cover under x iff A x=b and t_C(x)=v_C-e_C for every color component.
Necessity is immediate. Sufficiency: within each C every row has odd, hence positive integer occupancy; their sum is exactly v_C, so all are one. This retains arbitrary coupling, overlaps, repeated phases and mixed signs through ONE actual common phase word. There is no Cartesian product over region masks, and no free selection of pair orientations.

All token constraints involve only unbalanced phases U={i:d_i>0}. Gaussian eliminate balanced columns of A once to obtain exact projected affine equations H u=h, u=x_U. Store echelon rows to back-substitute any admitted u. Thus P3DM reduces uniformly to an exact affine guard on U plus nonnegative one-hot/zero token constraints (integer multiplicities). A token repeated twice in a tree, or appearing in a unicycle, forces its phase to zero. Empty tree with no remaining token is NO. The quotient is sound under prior pins: append them to A, or substitute before rebuilding source. Arbitrary nonlinear guards must remain explicit; not silently absorbed by parity.

All three colors have the SAME total tree count when no overfull component: for color c, if a_c degree-two elements were removed, remaining vertices n-a_c and ports m-2a_c, number of pair edges=(m-2a_c-sum d_i)/2. Difference r=n-(m-sum d_i)/2=n-sum q_i independent of c. Thus every feasible u has weighted token mass sum d_i u_i=r. This is also the exact count of selected original triples minus the fixed baseline sum q_i. The local quota theorem is consistent with AB02 minimum-weight parity criterion, strengthens its explicit factoring/pin acquisition, and does not claim that affine feasibility suffices. In fact on ANY parity-feasible x, selected cardinality>=n; equality iff source cover. Therefore weighted minimization of sum d_i u_i on H u=h is another exact formulation (if affine set empty reject; otherwise optimum equals r iff SAT). No weight on balanced phases. ## 4. Neutral two-port hub contraction, with geometric lift
If a balanced phase has exactly two remaining ports globally, conservation forces them to have the same color and opposite signs. Its one paired edge can be independently oriented: no other external row observes that phase. Form graph using ONLY these single-pair balanced phases, with all remaining elements of each color as vertices. Every connected tree absorbs all its internal phase variables into a single exact-one equation on the external port occurrences. Given its unique active exterior port, choose its row as root and orient edges away from root, each nonroot gets one active endpoint. Unique lift for tree, including arbitrary repeated exterior phase labels. A unicycle instead forces all exterior ports inactive; orient its unique cycle consistently, then orient attached trees away from cycle; two possible directions (loop case either phase value). Overfull components reject. Tree contraction is exact even when arbitrary higher-degree phase hubs are shared among many trees. Since each single-pair phase is an original connected subgraph touching only the two same-color elements, the row identification can be realized by contracting a connected subgraph in the original plane incidence graph; preserve remaining actual port identities. Loops/repeated entries remain explicit or trigger sound pin propagation. No such planarity claim for arbitrary multiport pairings.

If after this contraction all other live phases have exactly three ports, conservation forces one port of each color, all same sign (choose positive). Remaining tree rows are same-color super-elements; no synchronization of eliminated single-pair phases remains. Unicyclic components force external bits zero. Reclose and reject unequal super-element color counts (every retained rainbow triple uses one of each). Then residual is a smaller ordinary planar P3DM (duplicate tuples may be deduplicated for decision, storing a representative and setting the others to zero) with explicit witness lift. More general higher-port hubs retain exact signed equations, not a free P3DM reduction. Degree-four phase has d=0 and opposite-signed pairs, degree-five has d=1 and one extra opposite pair, by total-port parity and 3d<=port count. These give finite low-port classes but not universal bounded number of ports.
