## 3. Theorem A: paid mixed-sign recognition with forced-half hubs

Let explicit clean CNF C have n variables (arbitrary arity but polynomial explicit length), no tautological clauses, and designated shared bits H. Use doubled q-Horn weights w(l) in {0,1,2}, w(l)+w(not l)=2, sum w(l)<=2 for every clause. Require w(l)=w(not l)=1 for every H variable.

For each pair of distinct literals l,k in a clause, construct directed arcs l -> not k and k -> not l. These express weight order w(l)<=w(not k), not SAT implications. Add both arcs between l and not l for every forced-half variable. All arcs have complementary reverse arcs. Compute SCCs and topological numbering c increasing along arcs. Any valid weight is constant in SCCs; if l and not l in same SCC, forced weight 1. Define canonical w(l)=1 when equal SCC, otherwise 2 if c(l)>c(not l), 0 if smaller. This is monotone on arcs: if l->k, also not k->not l. A weight-2 predecessor cannot precede a weight-0 successor by these two order inequalities. If either endpoint is self-complementary SCC, same two paths imply predecessor outside has weight0 or successor outside weight2. Thus all pair inequalities hold. A clause violating sum<=2 must contain at least three self-complementary-SCC literals: if any weight2 all others weight0; otherwise only 0/1. Such triple is forced weight1 in any certifying weight, so no solution. If no violating clause, canonical weights are exact certificate. Complexity O(n+sum |C|²); for threshold arity<=3 linear in explicit CNF size. This is the direct quadratic pair graph orientation-reversed relative to known q-Horn quadratic cover; not a new foundational classification result. Extra forced-half arcs are exact classification constraints, not added Boolean restrictions. No LP or randomization.

Decision/lift: integral variables orient weight2 literals as positive. Clauses with no half literals are Horn. Compute least Horn model via forward chaining, reject if impossible. For any clause containing a half literal, all integral literals have weight0 (negative); at most two half literals. Least Horn assignment makes each such negative literal at least as true as any other Horn model. Hence if any solution exists it extends this least integral model, after replacing its integral part. Residual is exact 2-CNF on half variables. Solve with ordinary implication SCC, reconstruct actual original Boolean word and verify. Unit restriction and variable deletion preserve q-Horn. Actual binary SCC substitution also preserves q-Horn after restriction because implication u->v yields w(v)<=w(u) and both directions force equal weight; collapsing duplicates only decreases clause weights.

## 5. Theorem C: weighted grouped deletion discovery and aggregate exception entropy

For ordinary q-Horn recognition (no forced-half requirements in this backdoor algorithm), a violating clause has three literal vertices each mutually reachable with complement in pair graph. Use six BFS paths (both directions for all three) as explicit witness. Let W be the set of original variables on these paths, including the triple. Every deletion backdoor intersects W: if none deleted, surviving literal pairs in each clause retain their arcs, paths remain, violating triple remains, impossible. This is the direct-pair version of known separator obstruction. No unrestricted runtime consequence.

For threshold variables grouped by actual owning face f, replace W by its face-owner set. Deleting a face means removing all its threshold literals from every clause, not dropping the clause. Any deletion face-backdoor must intersect each such witness. Use weights a_f=ceil(log2(hi_f-lo_f+1)) >=0, integer bit lengths. Fixed domain faces have no variables and need not be selected. Define optimum K=sum of a_f over cheapest face deletion backdoor. We do not compute optimum.

Primal-dual algorithm:
1. Start empty selected face set, residual slack a_f, no dual weights.
2. Recognize residual q-Horn after deleting selected faces. If admitted stop. Otherwise acquire explicit witness W avoiding all selected faces.
3. Raise its dual weight by minimum residual slack on W; subtract from each slack in W; choose one now-tight face and delete its thresholds.
4. Repeat at most F rounds. Retain exact original clause IDs/path witnesses and chosen faces for check. Zero-slack ties choose deterministically.

Dual feasibility: sum of witness dual weights incident to f <=a_f. Each witness from a residual formula also obstructs original deletion unless intersected, since remaining literal pairs survive additional deletions disjoint from W. Therefore for every feasible deletion face set S, sum dual <=sum_{f in S} a_f, so sum dual <=K. Every chosen face is tight, and later witnesses avoid it. Thus if b=max acquired witness owner-set size, sum chosen costs = sum_W dual_W * |W intersect chosen| <= b sum dual <= bK. All discovery, failed attempts and graph/path verification polynomial, no enumeration. Unweighted disjoint-packing variant deleting all witness variables yields number of disjoint witnesses as lower bound and union size as upper bound. A fixed-size variable-deletion search can enumerate all subsets up to fixed cap 2 (O(n²) checks in audit); no claim that this enumeration is polynomial for variable cap.

After acquiring face set B, enumerate only its actual integer heights, not arbitrary assignments to all its thresholds. Number of branch guards product_{f in B}(hi_f-lo_f+1) <=2^{sum a_f} <=2^{bK}. For each height word assign its complete threshold pattern, simplify original CNF and solve admitted q-Horn, because restriction is a subformula of deletion and q-Horn is closed under removing literals/clauses. Include initial and conditional source closure, retain actual guards and witness lift. YES if any actual branch witness; NO only if all exhaustive branches fail. Can cap discovered total cost at c log2 N (fixed c), otherwise return UNKNOWN. If b bounded by fixed constant and optimum face deletion entropy K=O(log N), uniformly polynomial including discovery. More generally polynomial whenever acquired sum cost is O(log N), regardless optimum. This avoids counting multiple threshold bits of one face as independent branching dimensions. General q-Horn backdoor FPT approximation from Gaspers et al has size k²+k, not an all-source log-entropy bound; our scoped b-factor weighted lemma supplies a different route when witness size controlled. Neither b nor K universally bounded here. Separate incidence components, independent exact regions, and factorable threshold components sum their independently charged costs, not a common product. On genuinely interacting hubs a single combined budget is required.
