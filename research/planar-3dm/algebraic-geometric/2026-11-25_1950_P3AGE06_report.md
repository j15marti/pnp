## 1. Local adaptive sign lemma
A disk region has four ordered ports, exact feasible mask S, and stored actual local source witnesses. Normalize fixed odd parity by complementing bit 0; a leaf implements this. Empty S => NO; mixed parity => decline this terminal. On even parity, bit3 is XOR of first three bits. Any degree-at-most-two Boolean phase q_i on these independent bits has seven coefficients (constant, three linear, three pair products). Write f_i(x)=(-1)^{q_i(x)} w_i(x), with w_i>0 precisely on S. The only nontrivial four-port MGI is f0*f15+f5*f10-f3*f12-f6*f9=0. Let active pair be (a,a xor 15) with both entries supported. Let c=0 for left terms, c=1 for right terms, so the sign of an active summand after moving all terms left is (-1)^(c+q_i(a)+q_i(a xor 15)).
No active pairs: no additional restrictions. Exactly one: no signed realization over Q (AGE05). At least two: choose two distinct active anchor pairs (a,a',c),(b,b',d), impose
q_i(a)+q_i(a')+q_i(b)+q_i(b') = 1+c+d (mod 2).
This is one affine linear equation in seven unknown phase coefficients. It ensures at least one positive and one negative active summand. If there are P positive and M negative active terms, set one endpoint magnitude of each positive pair to M and of each negative pair to P; set all other magnitudes to 1. Complementary pairs disjoint, so assignment is well-defined; both sums PM, satisfying MGI. Every magnitude is 1..3. Conversely any feasible real nonzero magnitudes force both signs if any active pairs; some anchor pair is opposed. For exactly two active pairs the constraint is necessary and sufficient for a prescribed quadratic phase. With three/four active pairs, predetermined anchors are sufficient, not necessary. Constant size signed rational planar realization follows from Cai-Gorenstein, Matchgates Revisited, Theory of Computing 10(7), 167-197 (2014), DOI 10.4086/toc.2014.v010a007, Theorem 5.1, O(k^4) nodes, arbitrary field, parity and MGI. Read primary PDF §5 and screenshot p183. Construction uses normalized nonzero entry, planarized K4 with signed crossover, leaves for bit flips, and isolated scalar edge. Negative internal weights are allowed; no unweighted matching witness or source count claim.

## 2. Global rank-zero acquisition (new exact terminal)
Let b be actual shared incidence-wire bits of a verified disjoint disk partition, with every original constraint assigned once. Local tables include all active guards, not independent per-lane assignments. For each exact local table acquire its affine annihilator by checking at most 15 nonzero linear forms; lift equations to original wire IDs. Append any other sound affine consequences valid under the same guard. Solve for b=b0+B y, or reject if inconsistent. Every globally feasible boundary word is in this affine relaxation, not conversely.
Treat all local phase coefficients as unknowns. Total Q(b)=sum_i q_i(normalized local b) is quadratic in b and linear in coefficients. For each pair of distinct basis directions B_j,B_k, impose
Q(b0)+Q(b0+B_j)+Q(b0+B_k)+Q(b0+B_j+B_k)=0.
These equations are linear in local unknowns, and they are necessary and sufficient for Q(b0+By) to be affine on the whole relaxed space: the left hand side is precisely the coefficient of y_j y_k. Combine with all chosen anchor equations and solve by GF(2) Gaussian elimination. Inconsistent gauge system means UNKNOWN, not NO. This is exact recognition of rank zero for quadratic gauges and fixed anchors on the acquired affine relaxation. If every mask has at most two active pairs, no anchor choice ambiguity. For a fixed number a of masks with >=3 active pairs, at most 6^a anchor choices suffice for exact recognition in that same restricted model; polynomial when a=O(log N). Arbitrary choice of anchors is not globally complete when a is large.
If feasible, construct magnitudes by §1. Total affine phase is Q(b0+By)=gamma+ell dot y; extend this to an affine form of b via a left inverse of B on its image (or free wire coordinates). Change signs of matching gluing edges according to its linear part. For every feasible boundary word, product of local signatures times this character has the same global sign (-1)^gamma and strictly positive absolute weight. Infeasible words have zero contribution. Thus the absolute value of ONE coherently oriented planar Pfaffian is positive iff the source is SAT. This is not a count-preserving reduction. No assumption of true-support affine closure or independent phase assignment.
Generalization: for a supplied subset J of the affine coordinates, constrain all polar coefficients except those with both indices in J to zero, using the same linear equations. Then residual polar rank <=|J|; apply AGE05's 2^r character expansion. Polynomial for logarithmic |J|. This does not give free acquisition of a suitable J or solve general rank minimization. Disconnected factor components can use independent gauges.
Proof of reconstruction: evaluate signed partition function after forcing or excluding one original gluing edge at a time (remove endpoints and multiply forced weight, or delete excluded edge), using original global character; constant sign persists on subset of feasible words. Recompute coherent planar Pfaffian orientation/calibration, no individual absolute values in multi-character sum. At most O(N) such pins find a compatible boundary word. Retrieve each actual local tuple witness, verify all original occupancy and guards. Guard-specific gauge cannot be exported as an unconditional logical deduction.
Complexity: O(N) wire bits, O(N) local unknowns, O(N^2) binary polar equations of O(N) bits, O(N^3) conservative matrix storage and O(N^4) bit arithmetic by ordinary elimination. Local exact masks for log-size disjoint regions via 16*2^b poly(N) enumeration with b<=c log N. Arbitrary partition choice/acquisition is not solved. Fixed bounded-cut enumeration, canonicalization, embedding, mask verification, failed gauge attempts and fallback caps all paid; never treat existence as acquisition. O(N) constant-size rational gadgets, coefficients bounded constants; exact Pfaffian arithmetic polynomial (minors have polynomial bit lengths), orientation via planar face constraints. Witness pins and original verification polynomial. Peak storage polynomial for rank-zero and streaming rank-r; cumulative memory <= T*S (or T^2 conservative), includes discovery, failed work, table witness storage, access, copies/recomputation and all branches. All time bounds deterministic uniform for stated caps.
