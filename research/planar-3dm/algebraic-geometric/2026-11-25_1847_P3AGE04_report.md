## 1. Exact four-port support criterion

For a disk region with four cyclically ordered Boolean ports, the mask S is the exact set of feasible boundary words; stored witness per word. Empty mask rejects. Any nonempty fixed-parity mask with <=3 ports has no nontrivial MGI and is realizable with unit nonzero signature entries. Four ports: if odd, toggle one port (attach a leaf and take leaf as the new external port; the removal bit is complemented). Write even mask as subset of the eight even words. Let f_A be entry indexed by subset A of removed external vertices. The only independent nontrivial MGI is

f_empty f_1234 + f_13 f_24 = f_12 f_34 + f_14 f_23.

This follows either from the 4x4 Pfaffian identity or direct expansion of MGI; all identities with difference set <=2 cancel and the difference-4 identities are this one up to sign. Let L count supported complementary pairs on the left (two possible pairs), R count those on the right (two possible). Claim there exists an exactly support-preserving nonnegative rational planar matchgate signature iff L and R are both zero or both positive, and all support has fixed parity. Necessity: every product supported on one side is strictly positive and no absent product contributes. Sufficiency: if both zero use 1 on all support. Otherwise on every active left pair set one endpoint weight R and the other 1; on each active right pair set one endpoint weight L and the other 1; remaining supported entries 1. Complementary pairs are disjoint, so both sums are LR. All nonzero weights 1 or 2. Apply Cai–Gorenstein Theorem 5.1 (weighted matchgate identities characterization) over Q. Odd-parity flip is reversible. No sign choice on local supported entries is allowed to make a forbidden support feasible. This is necessary/sufficient for NONNEGATIVE SIGNATURE support, not necessarily for any signed-valued tensor representation with global cancellation or larger representations.

Explicit gadget: choose a supported word a and flip bits 1111 XOR a to make f_1234 nonzero; normalize by it. In even parity flipping any even subset preserves the identity up to exchanging sides. Draw K4 with vertices in port order and edge ij weighted by normalized entry with only i,j unremoved. Replace the crossing diagonals by the six-vertex signed crossover of Cai–Gorenstein Fig.6, with inner cycle/ladder whose removal signature at 0000,0101,1010 is +1, at 1111 is -1, zero elsewhere; connect its four ports to corresponding outer K4 vertices, place crossing weight on one endpoint connection. Then local matching sum equals required Pfaffian principal minor. Undo flips with leaf attachments and restore normalization by a disjoint edge. Rational weights bounded by 2 or 1/2 in magnitude except sign -1; gadget size constant. The code explicitly enumerates each local graph's weighted perfect matchings with exact Fraction arithmetic and checks planarity. The prescribed geometric construction, not a generic planarity test alone, preserves external port cyclic order.

Of 255 nonempty masks per parity, 129 admissible, 126 inadmissible: for each side two disjoint complementary pairs have 3 non-full possibilities each (9 inactive) or 7 active possibilities; both inactive 81, both active 49, total 130 incl empty. Thus 258 nonempty parity-definite masks across both parities admit positive reweighting. One complementary pair only is an exact counterexample, even with nonzero rational reweighting.

## 2. Exact global composition and deterministic witness recovery

Partition original incidence vertices into connected regions, at most 4 ports each, all boundary stubs on a single boundary component of the inherited embedding. Contract each region using a regular neighborhood; because source component connected, any other boundary components enclose no remaining vertices with edges to the region if all external edges are on the same component. Preserve cyclic order; substitute disk gadgets. Check embedding and port order explicitly. For each original crossing edge connect its two corresponding external vertices by unit-weight matching edge. Selecting that edge removes its endpoints from the two internal matching subproblems. Expanding weighted sum over the selected crossing edges gives exactly the sum over globally compatible masks of the product of local signature values. Every term in the latter is nonnegative, and positive iff every local word is feasible. Therefore nonzero weighted perfect-matching sum iff source SAT. Counts generally changed; no #P3DM claim. Signed internal matchings can cancel; an arbitrary unweighted matching witness is NOT a source witness.

Use any planar Pfaffian orientation of the expanded graph; as polynomial identity the Pfaffian equals the weighted matching sum up to one global sign even for signed edge weights. Zero-testing may use the determinant of the skew matrix (Pfaffian squared), computed exactly over Q, avoiding sign calibration for decision. Never sum absolute values of individual contributions. For reconstruction, self-reduce on the original crossing edges: delete an edge (bit0) or force it (bit1, delete its endpoints and multiply its unit weight). Recompute planar signing after deletions; each count test remains the nonnegative mask sum up to global sign. Keep a branch with nonzero value. After all crossing bits fixed, look up one stored actual regional witness and glue identical original incidence bits. Verify original integer occupancies and distinct triple IDs. For weighted counts one would need a coherent global sign; not required here. Global production FKT and self-reduction are theorem-level in this run, not executed; local signed gadgets and actual cut-glue witnesses executed.

## 3. Cubic four-edge-cut taxonomy

Use the original cubic incidence graph (both types degree3); masks may already be restricted by guard pins, so keep source wires and degrees. For region, t triple vertices, a_c element vertices color c; p_c outgoing triple-to-exterior element edges and q_c incoming exterior triple-to-element edges. Degree count t-3a_c=p_c-q_c. For each feasible regional assignment, k selected internal triples and active outgoing/incoming P_c,Q_c satisfy k-a_c=P_c-Q_c. A four-edge cut must have p=q=2 (3 divides p-q, possible even differences -4,-2,0,2,4). All three differences p_c-q_c congruent mod3, sum 0, each in [-2,2]. Up to colors and global sign, only (0,0,0) or (1,1,-2). Thus:

A. Balanced monochrome: one color carries all four ports, two incoming/two outgoing. Missing colors fix k=a_c for all c. Active outgoing count equals incoming count; allowed envelope has six words. Fixed even parity; apply exact signature criterion to acquired subset, not the envelope.
B. Balanced two-color: each present color has one incoming and one outgoing. Their bits must agree; allowed envelope is the product of two equality pairs. Any subset is a Boolean binary relation on the two phase bits, hence 2-CNF. It need not be a matchgate (especially cyclic crossing).
C. Three-color: singleton outgoing ports of distinct colors carry bits u,v, and two incoming ports of third color carry bits w,z (reverse all directions analogous). Then a_first=a_second=a, a_third=a+1, u=v=k-a and w+z=1-u. Allowed envelope {1100,0010,0001} in that order. This is mixed parity, but pinning either singleton u or v makes the other singleton fixed and the pair either 00 or one-hot. Every slice has fixed parity and at most three free ports. Acquired mask may be any subset; not automatically all words.

Together with RC01 2/3-cut taxonomy, all nonempty masks on cubic regions of <=4 ports are either direct matchgate-admissible or have at least one single-port pin whose two slices are fixed parity with <=3 free ports. For 3-port rainbow EQ3, pin any port. Balanced masks already fixed parity. Cubic 1-cut impossible; arity0 true/false. For general degree P3DM, check the single-port property explicitly, decline if no eligible port. Theorem does not presume all regions cubic after simplification.

## 4. Polynomial acquisition of a shared-class strong backdoor for a fixed acquired partition

Compute exact unary restrictions and signed equalities b_i XOR b_j = epsilon holding in every allowed regional word (<=16 words). Merge along common original wires using parity union-find; inconsistent constraints or empty exact table reject. Propagate fixed bits to all occurrences, repeat while any restriction/equivalence changes. No quotient rewiring is needed; retain the original planar graph. Each iteration deletes a table entry, fixes a class or merges classes, so polynomial aggregate. If a factor's current mask is not directly gate-admissible, form a set of eligible unfixed signed classes: a class eligible when pinning one of its incident ports makes both slices parity-definite with <=3 free ports. Test this by enumerating its two restrictions. In cubic <=4 regions all bad factors have an eligible class. On general regions with none, this particular lane declines. If class is pinned at several ports the result remains a restriction of the admitted slice. Good factor conditioned on any ports remains gate-admissible: restrict any matchgate signature using unary pin gadgets, or note a fixed bit precludes all complementary products and leaves constant parity.

Seek set B of at most k distinct signed classes hitting every defect's eligible-class set. Bounded search: pick unhit defect, recurse on its at most four eligible classes, depth k. <=O(4^k) nodes, polynomial work each. Complete for this defined sufficient class-cover property, not all possible adaptive backdoors. Once B acquired, enumerate 2^k class valuations, apply pins with correct signs across all occurrences (no nonplanar identification), restrict actual masks, compile/reweight, FKT zero-test, and if YES reconstruct. Every source solution corresponds to one branch; every positive branch lifts. If all branches reject then NO. Failure to acquire a cover within cap UNKNOWN. Time additive acquisition O(4^k poly(N)) plus evaluation O(2^k poly(N)), not a multiplicative bound on local defects. For any fixed c, k<=c log2 N makes this polynomial. Class count can be far smaller than count of defective factors. Note ordinary minimum edge cover would solve the weaker situation of each pin covering at most two regions; signed classes can cover arbitrarily many. No lower bound from failure of this sufficient cover.
