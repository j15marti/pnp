## A. Four-port signed support classification
Use deletion convention: bit 1 means external vertex removed, equivalently occupied inter-region matching edge. Let S be a nonempty fixed-parity mask. Normalize odd parity by toggling the first bit (a leaf realizes this). In even parity, MGI is f0 f15 + f5 f10 = f3 f12 + f6 f9, integers denote masks, port 0 is low bit. Let A and B be active complementary pair sets on respective sides. A pair is active iff both words supported. If exactly one active pair, no signed (even complex) nonzero weights can satisfy identity. If neither side active all supported entries may be +1. If both sides active assign positive product |B| to each active left pair and |A| to each active right pair, feasible entries otherwise +1. If both active pairs lie on only one side (necessarily exactly two), assign f(b)=(-1)^(b0*b1) on S and zero elsewhere. This monomial flips exactly one product on either side: among even words it is nonzero at 3 and 15. Undo odd normalization, so q_i=(b0 xor p)*b1. In all cases the signature has exact support and rational weights of magnitude 1 or 2. ## B. Affine-restricted quadratic phase
Glue exact signed regional signatures f_i, with positive absolute local weights, along actual incidence wires. Each bridge choice is a common bit b_e. Let W(b)=product_i f_i(b|ports_i). It is zero off the exact feasible boundary set, and on that set W(b)=(-1)^Q(b)|W(b)| where Q is sum of the local quadratic phases. The desired positive reweighted partition function Z=sum_b |W(b)|, NOT the original number of solutions. Thus Z>0 iff the source is SAT.

Compute each local affine hull via annihilator enumeration of <=16 words; lift its equations to global wire IDs, append only sound guarded affine equations. If inconsistent => NO. Otherwise solve by GF(2) elimination, b=b0+By. Every feasible boundary word lies in this affine space, not conversely. Set q(y)=Q(b0+By). Its polar bilinear form beta(a,c)=q(a+c)+q(a)+q(c)+q(0) is alternating. Let r=rank beta (even). Symplectic elimination gives r/2 hyperbolic pairs: q(y)=ell(y)+sum_j u_j(y)v_j(y), ell affine. Each form extends to a wire-affine form by taking a left inverse of B on the affine space (or using free wire coordinates); all acquisition polynomial. Subtracting the hyperbolic products leaves zero polar form, hence affine. Exact sign expansion (-1)^(uv)=(1+(-1)^u+(-1)^v-(-1)^(u+v))/2 produces at most 2^r linear characters, common denominator 2^(r/2), coefficients with O(r) bits. Absorb affine constants into signed coefficients. For each linear wire character chi_a(b)=(-1)^(a dot b), compute F_a=sum_b chi_a(b) W(b). Realize each by sign-flipping the corresponding gluing edge weights in the same planar matchgate graph. Then Z=sum_a c_a F_a EXACT, because off-support W=0 and on-support expansion equals (-1)^Q.
