## 1. Exact source partition and paid mask acquisition
After necessary singleton/zero support and all-three indexed allowed-edge matching closure, form XY multigraph (one edge per actual triple labelled z). Its connected components i have disjoint X_i,Y_i, each balanced with size a_i if perfect matching exists. Distinct triples retain IDs even with parallel XY endpoints. Define P_i as labels appearing only in component i and S_i as labels appearing in i and at least one other component. E is union of S_i. Every valid source solution restricts to a local XY perfect matching covering all P_i once, selecting no repeated Z, and selecting exactly r_i=a_i-|P_i| distinct shared labels. If r_i outside [0,|S_i|], reject. Thus sum r_i=|E| (all original Z must occur; otherwise reject at closure). Let B_i be the exact set of such shared-label masks with one local source witness per mask. Source YES iff a mask from every B_i is selected, all masks pairwise disjoint. Necessity follows from exact occupancy. Sufficiency: masks total |E| by conservation; union is E, private labels covered exactly once and X,Y local, so the stored actual witnesses are jointly valid. No independent marginal projections are substituted for common triples.

Paid sufficient acquisition: certify local label injectivity, meaning EVERY local XY perfect matching has distinct labels. For every pair of distinct edges with the same label, force both indexed edges in a local matching; if feasible, decline this acquisition rule, not NO. Shared endpoint pins impossible. At most O(m²) calls across regions, on explicit graphs. If all tests fail, duplicate labels impossible. Now for fixed constant k and min(r_i, |S_i|-r_i)<=k, enumerate all r_i-subsets Q of S_i via the smaller subset/complement. Retain only edges labelled in P_i union Q and test ordinary XY perfect matching. If feasible, exactly a_i distinct labels selected from a_i permitted labels, so every permitted label used once; store actual matching. Conversely every valid local witness appears in this test. Empty exact table gives NO; cap/label-injectivity failure UNKNOWN. At most sum_i binom(|S_i|,r_i) <= O(N^{k+1}) calls. This certificate includes large local matching regions, not merely small components. Other exact peer acquisitions (e.g. CC03 sparse support with exact private occupancy) can provide B_i, with their own costs charged; do not use parity supports as integer masks absent cardinality and occupancy proof. For local labels repeated in some XY matchings, optional exhaustive search is NOT a polynomial production rule.

## 2. Matroid union eliminates all exchange-admitted components simultaneously
Each nonempty B_i has fixed cardinality r_i. It is exactly the basis family of a matroid iff for each A,B in B_i and x in A minus B there exists y in B minus A with (A-x)+y in B_i (basis exchange axiom). Explicit recognition by enumeration and set lookup polynomial in table size. Extend to E by loops outside S_i. Independence oracle: test whether query set is contained in some listed base. Let M denote the current collection of matroid regions, H the remaining exact nonmatroid tables. Put r=sum_{i in M}r_i, q=sum_{i in H}r_i=|E|-r.

Use the union matroid U=union_{i in M} M_i, whose independent sets are unions of independent sets; overlap can always be removed from individual sets by heredity, giving disjoint allocation. Its rank on any A⊆E is the maximum cardinality of a disjoint allocation of independent sets in A, attained by deterministic matroid union augmentations. Equivalently apply ordinary matroid intersection on copies (i,z), direct sum of local matroids and partition matroid with capacity one per z. If rank_U(E)<r reject: no disjoint choice of full bases even before selecting H. Otherwise rank_U(E)=r. Any base of U has exactly r elements and can be decomposed into disjoint local full bases, since each allocation size <=r_i and the sum equals r. Store or recompute the allocation and then the original witnesses. This is the pure matroid terminal already related to I07.

## 3. NEW: exact dual interface to nonmatroid regions
Let D=U*, the dual matroid on E. For any A⊆E,
A independent in D iff rank_U(E minus A)=r.
For any choices of masks in H, denote their union A. Then the original global compatibility problem is equivalent to:
(i) H masks are pairwise disjoint; (ii) A is independent in D.
Proof: Necessity since the complement consists of disjoint local matroid bases. For sufficiency, |A|=q by disjointness; rank_D(E)=|E|-r=q, so A is a base of D. Its complement is a base of U; allocate disjoint full bases to M, retrieve local witnesses and join with H. This avoids enumerating any product of matroid masks. Independence and lift are polynomial oracle computations, no linear representation assumed.

### Exact dual unary closure and promotion
For every candidate mask A in each remaining H table, if rank_U(E minus A)<r remove A: any valid completion would have to supply full M bases avoiding A, impossible. Empty table is NO. Reclassify every changed exact table by basis exchange; a newly matroidal table moves into M. Recompute U, r, q. All removals globally impossible under the fixed current guard; moves preserve remaining exact compatibility. Every nonterminal round deletes at least one explicit mask; number of rounds <= initial total masks+1. No new source triple is asserted forced merely because a single stored representative was chosen. All source-local witnesses retain provenance. Repeat at stagnation. This is a true source-feasible deduction rather than speculative matroid completion.

### Exact polynomial binary compatibility under a recognizable dual certificate
After closure, suppose every residual nonmatroid table has exactly two masks. Let F be the union of all masks of H and restrict D to F. Detect loops by singleton independence and parallel pairs by pair independence among nonloops. Parallelism is an equivalence relation in a matroid (circuit elimination); let c be the number of nonloop parallel classes. Compute rank_D(F)=|F|+rank_U(E minus F)-r. If this rank is below q, reject because every H solution requires q independent elements in F. If rank_D(F)=c, D restricted to F is exactly the partition matroid allowing one element per nonloop parallel class. Proof: replacing an element by a parallel representative preserves rank; rank c of F means all c representatives are independent. Any subset without loops and with at most one element per class therefore independent, and all other subsets dependent. All tests polynomial in |E|, no enumeration of large circuits.

For each two-mask region introduce one Boolean choice. Ban options containing loops or two elements of the same class. For two different regions ban a pair of options if their sets of classes intersect. Each ban is a unit or binary clause. Selecting the same actual label twice also shares a class, so pairwise disjointness is enforced. Every satisfying 2-CNF assignment therefore produces independent union A of size q; the dual theorem constructs disjoint M bases on E minus A. Conversely every source solution avoids each ban. Thus exact deterministic polynomial algorithm even when the number of binary and matroid regions is linear and they interact cyclically. Failure of binary or rank-equals-classes admission is UNKNOWN, not UNSAT. If M empty, D is free and the criterion is automatic; any number of two-mask regions, arbitrarily large masks and label multiplicities, reduce to 2-SAT by fixed total occupancy and at-most-one alone. No bound on number of groups is required.

### Matroid island interface (theorem-level extension)
Any collection of matroid regions may be joined before all other groups. On its label ground L, form its union matroid U_I of rank R=sum local ranks; reject if rank<R. Let J be labels of L unavailable outside the island and require them covered. If rank_U_I(J)<|J| reject; otherwise exact outward feasible masks are bases of U_I/J on L minus J. Indeed each full solution covers J and is a union base, and every contracted base extends by J to a union base and local witness allocation. This is an oracle-compressed interface with possibly exponentially many bases, no explicit combined table. Independent queries use rank or independence on J union query. Contraction does not solve arbitrary nonmatroid atoms or assert planarity of the auxiliary matroid graph. No execution of this implicit-island extension in this audit.
