## 2. Fiber interval theorem (load-bearing result)
Let labels be reduced modulo an already acquired elimination subspace H, and p a nonzero current candidate label. Mark S={v:label(v)=p}, include zero-label nodes in marked set W; U=V(D)\W. Fix a truth word J on U satisfying all reachability implications restricted to U. Define L=J plus its entire forward closure, and R=V(D) minus the backward closure of U\J. Then L and R are admissible assignments, agree with J, L subset R, and every admissible extension A lies between L,R. Conversely any outgoing-closed A in [L,R] is a feasible extension. Proof: propagation forces the forward closure of true and backward closure of false; they cannot intersect since a path would violate the restricted implications. Both endpoints closed. This handles neutral intermediates.

Within a fixed fiber all syndrome differences lie in span(p). A p-labeled g is free iff g in R\L. If some is free, every A admits an opposite signature: if g not in A, move upward toward R by adding false nodes in reverse topological order (all successors true); otherwise move downward toward L by deleting true nodes in topological order (all predecessors false). Stop at first p-node flip, all preceding moves have zero label. Valid actual matching at every step by exact compiler. At most |D| flips. If no p-node free, all p contributions fixed, every extension has same signature. Thus exact support per fiber is either one value or two values differing by p. Not necessarily a single alternating cycle; recomputing s from heights at each step is polynomial and preserves actual IDs. The symmetric difference between consecutive actual matchings decomposes into alternating cycles, with total label change as claimed.

Construct Avoid_p formula on U: all restricted reachability implications AND for every g in S, C_g=(OR of b_u over u in U reaching g) OR (OR of NOT b_v over v in U reachable from g). These clauses express forced true or forced false; empty clause is contradiction. Delete dominated literals: keep reachability-maximal predecessors and reachability-minimal successors (in arrow direction). Avoid_p satisfiable iff a feasible fiber has no free p node. If UNSAT, p is a global period of current signature support. Solve 2-CNF, Horn, dual-Horn avoidance when admitted, not arbitrary SAT. ## 3. Stronger exact target-fiber criterion
Do not need a global period. Let t be current target offset (desired sigma XOR base) and rho_p linear quotient modulo p, lambda linear bit functional with lambda(p)=1. For a feasible J, define sigma_L as XOR of labels of L. Only U and forced-true p-nodes contribute, as zero nodes contribute zero. For each g in S, its contribution to lambda(sigma_L) is OR over b_u for unmarked predecessors; acquire exact OR gates via implication plus one reverse OR clause. The bad-fiber condition is
  Avoid_p(J) AND rho_p(sigma_L)=rho_p(t) AND lambda(sigma_L) != lambda(t).
The coarse equation uses only U, because marked labels are 0 or p. This condition is EXACT: if a fiber meets coarse target but cannot realize fine target, it must be frozen and wrong, and conversely. If no bad fiber exists then any actual assignment meeting coarse target can be retained if already fine-correct or lifted by the neutral repair theorem. This is target-specific, not a support-period claim. A true semantic period need not satisfy the stronger every-fiber free criterion, and a target-specific certificate can hold even for nonperiod directions.
