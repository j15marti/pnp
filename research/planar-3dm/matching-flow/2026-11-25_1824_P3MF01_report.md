## 2. Main theorem: overlapping cycle moment certificate
Let G be an indexed plane bipartite multigraph with nonempty perfect matching set M, labels l_e in F2^d, and H a certified period subspace of the attainable signature set S. Work modulo H. Let C_1,...,C_q be distinct simple even indexed cycles (digons allowed), not necessarily edge- or vertex-disjoint, all with the same nonzero quotient XOR p. An event A_i means that M contains one entire alternating half of C_i. For a matching M, write a(M)=number of activated cycles. For r>=1 compute the exact integer B_r=sum_M binom(a(M),r).

For every fixed even truncation order 2h, define L=sum_{r=1}^{2h}(-1)^{r+1} B_r. The identity for integer a>=1,
sum_{r=1}^{2h}(-1)^{r+1} binom(a,r)=1-binom(a-1,2h),
and value 0 at a=0 show L<=|M|. Equality holds iff every matching activates between 1 and 2h cycles. Thus L=|M| is a deterministic certificate that every matching activates at least one cycle, regardless of cycle overlaps. Failure is UNKNOWN, not a refutation of the period. At order 2, L=B1-B2, exact iff activity is 1 or 2 for every matching. No cancellation can conceal uncovered matchings because deficits are nonnegative pointwise.

When certified, take any actual M and find an activated C by scanning the original cycle IDs. M symmetric-difference C is again a perfect matching, changes quotient signature by p and uses no synthetic filled edges. Hence S/H+p subset S/H; translation is involutive, so equality. No requirement that the chosen flip is a globally invertible map on matchings, only existence for each M; no statement about matching multiplicities or exact counting of P3DM. Add a lift representative of p to H; old periods plus the quotient period imply the enlarged subspace is a true period of S. Store old basis and cycle group. Reverse in acquisition order reversed: if needed quotient discrepancy is p, flip one currently active actual cycle; previously established periods finish the lift. Each strict addition increases rank, at most d. This extends P3CC03 parallel switches and P3IO01 edge-disjoint flow to overlapping long cycles.
