## 2. Theorem: all target states at a seam are solved in one nested recursion
Let A be any explicit weighted binary columns in common ambient coordinates, with nonnegative integer weights. Let B be a basis of a target subspace H of rank <=2 (root H=span(t)). Return exact C(A,q) and actual subset witness for EVERY q in H. An infeasible q has infinity and no witness. This is a table problem, not repeated marked queries down the tree.
Partition current selectable columns into L,R, with |L|>=4, |R|>=1. Define W=span(L) intersect span(R union B). Require rank W<=2. Crucial: B consists of formal UNS E L E C T A B L E target columns, pinned on R side. If using a single parent target for discovery, its sibling targets may be lost; use the whole parent target space.
Recursively compute ONCE the complete table f(w)=C(L,w) for w in W. Every w is attainable by definition; f(0)=0. Replace L by all nonzero w in W as weighted selectable columns with weight f(w) and stored actual subset. At most three columns. Recursively compute ONCE the entire H table of R plus these virtual columns. Return it.
Proof for each q in H simultaneously: any original subset has left syndrome w=q+XOR(right) in W. Its replacement with one virtual w costs no more. Conversely, any subset of multiple virtual columns lifts by symmetric difference of their stored left subsets. XOR is the sum of their syndromes, and nonnegative weights ensure cancellations never increase cost. Right subset is unchanged. Both optimum inequalities hold, including infinity; this is not an assertion of exact feasibility of every individual synthetic witness as an exact cover. By induction all table entries preserve exact minimum. Store leaf subset indices and XOR original-ID bitsets to expand nested witnesses, no exponential proof-tree expansion. At top-level optimum expanded original cost equals reported cost; if it were smaller it contradicts equality. This corrects ES04's restriction that nested rank-two table acquisition must be delegated only to rank-one/regular/small subsolvers. Parent table is maintained as one state, eliminating repeated evaluation per target.

## 3. Deterministic acquisition and aggregate bound
For a node of s selectable columns, use connectivity lambda(L)=rank(L)+rank((A minus L) union B)-rank(A union B). This is a symmetric submodular function on the full indexed ground set A union B restricted to B outside L. Rank computed by GF2 elimination (duplicates are separately indexed). Enumerate four distinct selectable IDs forced in L and one distinct selectable ID forced in R, and minimize lambda over remaining free indices using deterministic submodular minimization. If optimum <=2, use that cut. Every productive cut is included in at least one of these pin tuples, so failure of ALL O(s^5) minimizations certifies no cut meeting the size/rank requirements at that node. This does NOT certify no alternative earlier cut sequence works. All current columns and target directions are explicit; no SAT or semantic oracle.
If no productive cut, use one of admitted exact terminals: bounded local enumeration (s<=c log_2 N), or test [A|q] regular and solve ES04 signed TU LP for each q in H (at most three nonzero queries). Can attempt these terminals earlier too. Failure to admit returns UNKNOWN, not NO. Choose deterministic greedy cut order without backtracking; if child UNKNOWN propagate UNKNOWN. Do not claim global coverage.
Size: left child s_L=|L|<s, right child s_R=|R|+(2^rankW-1)<s, because |L|>=4. For P(s)=max(s-3,0), P(s_L)+P(s_R)<=P(s). If right child size<=3, left positive and potential drops at least |R|>=1. In tree of positive nodes unary internal nodes spend >=1, binary internal nodes <= number of positive leaves minus one. Thus O(s) total nodes, including zero-potential terminal children. At most 4 states per node and O(m) total nodes. No multiplying number of local calls by depth. More generally fixed k>=1, use H rank<=k, cuts rank<=k and |L|>=2^k, |R|>=1. Replace by <=h=2^k-1 columns. Potential max(s-h,0) same proof; pinned minimization O(s^(h+2)), hence polynomial for each FIXED k, not for variable/log k. ## 4. New source-specific color-balance bound
At any raw incidence-column cut L,R let D be the set of element rows appearing on both sides, b=|D|, and P_L the rows occurring only on L. For w in W=span(L) intersect span(R,t), w on P_L equals alpha*t on P_L for alpha in F2. Outside the support of L, w=0. Thus w described by b shared bits x and alpha. Every column has equal total parity across the three colors, so every w in span(L) satisfies two equations
sum_{v in D_X}x_v + alpha*sum_{v in P_L,X}t_v = sum_{v in D_Y}x_v + alpha*sum_{v in P_L,Y}t_v,
and the analogous equality X=Z. Let H_D be their 2 by (b+1) binary coefficient matrix. Then rank W <= b+1-rank H_D, because w is an image of that equation kernel (alpha may be redundant). For b=2, at least one equation has a nonzero shared-bit coefficient, giving rank<=2. For b=3 with one boundary element of each color, the shared-bit coefficient rows are independent, giving rank<=2. These exact bounds do not require each side to be balanced in cardinality. They also hold for a shifted single target after source pins, but additional independent guard rows may increase interface rank; compute actual rank then. At nested nodes, original cuts can still be used when all current virtual columns on the opposite side and the current target span lie in span of original complement plus root target; prove this invariant by tracing actual provenance, not by assuming every arbitrary cut survives.
Consequently a raw source region with at most two shared elements, or a three-element rainbow boundary, has an exact at-most-three-column weighted interface once its table is obtained. Candidate element separators of size<=3 can be enumerated and incidence components inspected polynomially; use the exact rank test before each contraction. This supplies a mathematical bridge from SW/FG/AGE three-port regions and IO02 relays to ES weighted matroid seams. No assertion that every planar incidence graph has a productive such separator or that every cut of rank2 has small boundary.
