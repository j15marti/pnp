## 3. Virtual common-flat contraction (PROVED)
Theorem for any finite rank-oracle matroid D on explicit Z and explicit nonempty equal-size row families H_i of individually independent sets of size r_i. For every region i form F_i = intersection over B in H_i of cl_D(B), with cl_D(B)={z:rho(B+z)=rho(B)}. Acquire K_i, a basis of F_i, by greedy rank tests, k_i=|K_i|. This is virtual common information: K_i need not be contained in any actual row. For every B choose a deterministic extension E_i(B) subset B of size d_i=r_i-k_i such that cl_D(K_i union E_i(B))=cl_D(B). Acquire greedily by adding rank-increasing members of B; feasible because K_i subset cl_D(B) and rank B=r_i. Store all row preimages. Set C=union_i K_i, K=sum_i k_i.
For every row selection, closure of union B_i equals closure of C union all E_i(B_i), because each local pair spans precisely the same flat. Consequently
rho(union B_i)=rho(C union_i E_i(B_i)).
If rho(C)<K, then rho(union B_i)<=rho(C)+sum d_i < sum r_i, universally; exact NO without any global row enumeration. This includes rank deficiency from overlapping K_i, not just literal overlap.
Otherwise rho(C)=K. Contract C in D, giving rank rho'(S)=rho(C union S)-K. The original choice is jointly independent iff rho'(union E_i(B_i))=sum d_i. If a row extension E_i has rho'(E_i)<d_i, it is impossible in any complete selection, so delete all its actual preimage rows, rerun closure, and restart. The equivalence holds for every choice, not only a particular assignment or one representative per original region. Virtual labels do not consume physical tags: never select K_i as source tuples.
