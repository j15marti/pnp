## Exact local families and matroid intersection (PROVED)
After paid exact-one and all-three matching-support closure, choose a lane XY (or permute colors). Retain triples with original IDs as parallel-capable edges labelled z. Perfect matching existence can be checked on underlying simple graph; each indexed edge individually has support iff deleting its endpoints leaves a perfect matching. Forced singleton owner requires its sole triple and deletes every other conflicting triple. Iterate after deletions; at most m proper changes. Reject empty owners or unmatched lane. These necessary reductions preserve all source solutions, not every lane assignment; conditional pins require guard provenance. No embedding-dependent transformation: deleting unused color and smoothing triple vertices retains planarity, but algorithm does not need cyclic order. Keep original tuples for reconstruction.

Each connected lane component i has equal numbers r_i of X and Y if a perfect matching exists. B_i consists of all distinct-tag sets of size r_i realized by an actual local indexed perfect matching. Enumerate all local matchings if r_i<=fixed constant c, by choosing one tuple per local X and checking Y and Z uniqueness; time O(m^c poly(N)) for explicit encoded length N. Keep one actual witness per tag set, optionally all local support IDs for later closure. Empty B_i certifies NO. Every exact global solution splits into these local witnesses and its tag sets are disjoint; conversely disjoint choices cover all Z since sum r_i=n. Thus exact compilation and lifting. This does not require that local tags be disjoint between different components.

Test basis exchange on explicitly acquired nonempty equal-cardinality B_i: for every B,C in B_i and x in B minus C, some y in C minus B satisfies B-x+y in B_i. If true, B_i is bases of a matroid on Z with loops outside its union. Independence oracle checks containment in some stored base, polynomial. Take ground set E={(i,z): z in union B_i}. M1 is direct sum of component matroids on copies; M2 partition matroid permitting at most one copy of each z. Edmonds deterministic matroid intersection returns maximum common independent set; size n iff exact cover since rank M1=sum r_i=n and all tags distinct. Each block then a base, lift stored actual tuples, verify integer one-coverage. If a component fails exchange, decline this terminal rather than accept or reject, try alternate lanes. More generally arbitrary polynomially acquired complete base lists suffice even if r_i large; no free enumeration or oracle assumption. Min-max condition equivalently for all S subset Z, |S| <= sum_i rank_i(S) (matroid union theorem); a violated set is a precise cross-lane Hall obstruction.

## Rank-one/two specialization (PROVED and executed)
For r=1 all active tags form one capacity-one class. For r=2 let active tags be vertices; edges are feasible pairs in B_i. A rank-two matroid's nonloops are partitioned into parallel classes, with any pair from distinct classes a base. Test nonadjacency (including reflexivity) for equivalence by computing complement graph components and checking every component is a clique. This is iff basis exchange; sufficient by partition matroid truncated to rank two, necessary by matroid parallelism (dependent pairs among nonloops are equivalence). Create source -> block capacity r_i; block -> each parallel class capacity 1; class -> each member tag capacity 1; tag -> sink capacity 1. For r=1 one class. Integral flow n iff feasible allocation. Retrieve chosen tags and actual matching from dictionary. Flow<n gives exact NO if every block recognized; failure of recognition UNKNOWN unless another lane succeeds. All capacity values integers <=n. Standard augmenting paths or Edmonds–Karp polynomial; n unit augmentations suffice with residual BFS because every source-to-sink path has tag capacity1. Graph size O(N^2) conservatively. This is a target-free global simultaneous exchange of local choices, not an assumption that ordinary separate matchings synchronize.

Further exact deductions: for each locally acquired matching/base, condition on its actual selection, remove its occupied X/Y/Z or reserve those tag capacities, and rerun exact-one/all-lane closure plus the allocation test. A certified NO removes that candidate under its guard. A cheap necessary relaxation for nonmatroid blocks is the rank-r uniform matroid on their active tags; even if all block supports aren't matroids, a failed relaxed allocation for a pinned local base proves that base impossible. A positive relaxed flow does not give a witness unless each selected tag set belongs to its actual table. Recompute at stagnation, after every deletion or certified guard deduction. At most polynomially many candidate bases for fixed c; candidate filtering sound even if different witnesses for same base exist, provided no ID-specific guard discarded. To delete an original tuple, prove no surviving local base containing a local matching using that ID (store all supports or re-enumerate); one representative per base alone is not sufficient. This guarded filtering extension is symbolic, not executed in this iteration.
