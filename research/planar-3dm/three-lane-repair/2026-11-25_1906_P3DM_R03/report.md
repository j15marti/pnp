## 3. New dual-matroid hybrid theorem (PROVED)
Split acquired exact local tables into matroidal groups G and remaining groups H. On Z, M = union of the local matroids of G, with rank oracle via direct-sum/partition matroid intersection of copies as R02. Theorem of matroid union gives an actual matroid. R=sum of G quotas. If r_M(Z)<R then NO. Otherwise rank M=R. Given disjoint choices of H with union B, there exists a complete G allocation iff r_M(Z minus B)=R iff r_{M*}(B)=|B|, by dual rank formula r_{M*}(S)=|S|-R+r_M(Z minus S). If full rank, disjoint independent sets from each G attain all their local ranks, hence actual stored base witnesses. With |B|=n-R this covers every tag. This is exact for arbitrary acquired matroidal tables, not an affine hull relaxation.

Let U be union of H-accessible tags; D=M* restricted to U. Query singleton ranks (loops), pair ranks (parallel nonloops), and r_D(U). Parallelism is an equivalence relation on nonloops; choose one representative per class. If their count equals r_D(U), they form an independent basis (they span U, and size equals rank). Thus D independent sets exactly avoid loops and take <=1 tag per parallel class. If rank is smaller there can be higher circuits; e.g. U_{2,3}, all pairs independent but triple not, abstract matroid example, not claimed genuine source hardness.

Suppose every H table is majority-closed on its membership bits (all two-row families automatically so). Exact 2-CNF from forbidden unary/pair patterns: necessity immediate. For sufficiency, any word consistent with all unary/pair projections can be matched on any subset of coordinates by induction; for subset of size >=3, use three table rows matching all but three different coordinates respectively, take coordinatewise majority, obtaining agreement on entire subset. Hence matching word in table. Closure recognized by at most |W|^3 majority tests. Encode membership bit b_{i,z} for each active tag; impose local exact 2-CNF, loops force zero, at most one membership bit across each nonloop parallel class (including multiple copies of same tag from different regions). These are ordinary 2SAT clauses. If D rank test passes, 2SAT is exact; if it fails, all clauses remain necessary. 2SAT UNSAT is then sound; SAT candidate accepted only if actual rank of available complement is R, otherwise UNKNOWN. Reconstruct exact row witnesses and verify all source occupancies. No use of target assignment. General higher rank matroid union oracle theorem-level; implemented rank-one/two flow specialization. Rank test need not pass for success if concrete checked assignment lifts.

## 4. Collaboration with CPS04: planar face quotas yield a new unbounded-size cycle terminal (PROVED)
Use CPS04 original component-global-face tree theorem. Independently justify: per connected original incidence component, acquire planar rotation embedding. Remove Z vertices/spokes, keep indexed triple nodes subdividing XY edges. For each connected component C of remaining embedded H, its local faces correspond injectively to global faces of H incident to C; a sufficiently small boundary collar avoids every other disjoint component, so each local face gives exactly one incident global face. Euler for H gives total faces 1+sum_C(f_C-1). Component-face incidence graph Q connected by generic paths crossing H edges and has sum_C f_C edges, equal to vertices minus one. It is a tree. For each z, its spokes all lie in one face of H; acquire face IDs by traversing original darts and unioning faces on either side of deleted spokes. Preserve original indexed edges and cyclic order. Counts a_C=#X in C and b_f=#Z in face f. Any exact source witness induces integer quota r_Cf>=0 with sum_f r_Cf=a_C and sum_C r_Cf=b_f. Tree equations uniquely solved by leaf elimination. Negative/oversized quotas, nonzero root demand or unbalanced original components reject. Delete every triple in a zero-quota component-face pair; reclose and if needed recompute embedding and quotas. At most m strict rounds. We use quotas only as necessary restrictions, not as standalone completeness claim.

For C with one X and one Y, its indexed paths X-t-Y are parallel. Each local face has at most two such paths on boundary (one if single bridge). Since a_C=1, exactly one global face has positive quota, so <=2 actual triple IDs remain. A second result: if all matroidal regions are rank1 with <=2 tags (after quota closure), represent each region by undirected edge joining the two available tags, or a loop on singleton. Distinct representative selection is an injective edge-to-endpoint assignment. Each connected component with e edges and v vertices must have e<=v; otherwise NO. Connectedness gives e>=v-1, including isolated tag vertices. If tree e=v-1, leave any specified vertex unused by choosing for every edge the endpoint farther from that root. If unicyclic e=v, orient choices around its unique cycle (loop or parallel 2-cycle allowed) and away from cycle on attached trees; all tags used. Thus the dual matroid is partition capacities 1 (trees) and 0 (unicyclic). No higher circuit. This proof is symbolic; dual graph orientation itself not separately implemented.

Acquire by fixing one of the two edges at a chosen X and ordinary matching of remaining graph; for singleton take <=2 actual tuples. Discard any matching with repeated tags. Encode one binary phase per component, unit for singleton alternative, and forbid every colliding pair of local choices by a binary clause. 2SAT exact; quotas ensure n selected and distinct tags, source lift direct. Unbounded cycle lengths, no enumeration of general tag subsets or interface truth tables. Class membership and admission polynomial. General cycle components with parallel choices are not included unless reduced to the stated class; no claim of NP-hardness of this restriction.
