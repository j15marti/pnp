## 1. Paid necessary closure and packing relaxation (EXACT)
Maintain original tuple IDs. Under coordinate guards, propagate owner exact-one: selected tuple removes all competitors and covers its three owners; empty owner rejects; singleton selects. In each of XY, XZ, YZ project live triples as edges with distinct original IDs (parallel edges permitted). Missing perfect matching rejects; an edge absent from every perfect matching implies delete its tuple. Matching support by forcing edge or by SCC of alternating digraph; parallel IDs with same endpoints have same individual support. Reapply closure after deletions and at stagnation. At most m tuple removals/commitments. No guarded deduction exported unconditionally.
For all live triples create Boolean s_t; every pair sharing any element gives at-most-one clause, every owner of degree two also gives positive binary at-least-one clause, singleton pins already processed. Let F be this 2-CNF. Every full source witness satisfies F. Every F model is an actual packing. Including selected prefix p, objective p+sum s_t <= n, equality iff each of three colors is fully covered by distinct actual triples. Thus source SAT iff maximum objective n. Inconsistent F rejects. Compute exact 2SAT backbone by implication reachability (literal l forced iff neg(l) implies l in satisfiable formula); propagate those pins back to original owner closure, repeat. This closure is necessary, not full semantic P3DM inference.

## 2. Balanced mixed-color phases (PROVED)
Collapse implication SCCs and pair each with its complement SCC. Each original variable is fixed or equals phase z_j or its complement. Hence objective C+sum w_j z_j, w_j integer difference of multiplicities of positive and negative occurrences; prefix included. If all w_j=0, every feasible model has same size C, so exact decision by C=n and 2SAT reconstruction. Unlike lane-specific alternating cycle charts, this phase quotient uses degree-two and derived implications across all colors. May solve genuine inputs with every color having a degree>2 owner at initial all-lane matching closure. No need to enumerate charts. If one entire lane has only isolated matching edges and even cycles after support closure, it is an immediate special case (each cycle has two perfect matching choices; either exact 2SAT pairwise exclusion on choices or balanced phases suffice). No equivalence for arbitrary charts inferred.

## 3. Exact projected weighted minimum-cut terminal (PROVED)
Let J be nonzero-weight free phase classes. Project F existentially to J. A 2-CNF projection is 2-CNF by resolution/elimination; explicit polynomial construction using all pairwise inconsistent literal pins on J. After backbone, unary pins are individually consistent. Two pins a,b incompatible iff implication reachability a -> not b: if combined propagation conflicts, either one pin alone conflicts or a implies l and b implies not l, hence a implies not b by contraposition. Conversely implications certify conflict. Any larger consistent set of pins with no incompatible pair is extendible: if closure under implications conflicts, some pair already conflicts; otherwise fix closure and assign remaining SCC pairs in topological order. Thus forbid exactly those pairs. O(m^2) possible pairs and poly graph reachability. Zero-weight phases eliminated only from objective; reconstruct by guarded original 2SAT with retained phase assignments.
For forbidden pair (z_i=a,z_j=b), choose orientation bits h_i,h_j so a xor h_i differs from b xor h_j, i.e. h_i xor h_j=1 xor a xor b. Solve simultaneous XOR conditions by graph BFS; inconsistent cycle gives UNKNOWN not NO. In new coordinates u_j=z_j xor h_j each pair forbids (1,0) or (0,1), hence is a directed implication. Rewrite objective C'+sum g_j u_j. Max-weight closed set of this digraph: source arc capacity g_j if positive, sink arc -g_j if negative, implication arc capacity 1+sum |g_j|. Minimum cut never cuts implication arc (empty closed set finite smaller). Optimum C'+sum positive g_j - cut. Read source-side phases, extend by SCC assignment of full F under guard, then verify integer occupancy and actual IDs. NO iff optimum<n. ## 4. Three-lane synchronized cycle batches (PROVED)
For any three supplied perfect pair-lane matchings M_XY,M_XZ,M_YZ of original indexed edges and any common P3DM witness Q, each M_l symmetric difference Q is a disjoint union of alternating even cycles in that lane multigraph, including length-two digons for parallel IDs. Build a graph of these cycles across lanes, connecting cycles sharing a triple ID. Each connected component is a synchronized batch. Every lane remains a perfect matching when toggling a whole batch (each cycle independent in that lane). All changes at a particular ID lie in one batch, so after toggling it that ID is unanimous at Q's bit. IDs not changed remain as before. Therefore mismatch set D=union M_l minus intersection M_l never increases and precisely loses those initial mismatch IDs touched by a batch. Skip batches touching no mismatch: all their IDs remain unanimous even without toggles. At most |D| nonneutral batches give common perfect triple matching, not necessarily Q, with strict decrease. Extraction and application polynomial GIVEN Q (at most 6n total changed lane edges; union-find and verification polynomial). This does not acquire Q from anchors. Two-ID mismatch case actually has direct target-free solution: equal cardinalities force n-1 common triples and each lane selects one of the two other IDs. Two lanes must choose same ID, hence same whole set, which covers all three colors. A single mismatched ID is impossible. For |D|=3 and n-1 common triples, freezing common may fail even on SAT.
