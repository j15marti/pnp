## 1. Exact pin-refinement theorem
For any region U of original incidence vertices, let a_c be the number of its elements of color c, K number of its selected triples, and let each cut wire e carry its actual source bit b_e. Sign + if inside endpoint is a triple (T port), - if an element (E port). Counting selected incidences yields K=a_c+sum_{e of c} sign_e*b_e for each c. Normalize b'_e=1-b_e at T ports, b'_e=b_e at E ports. Then K=d_c-sum_{e of c} b'_e, with d_c=a_c+#T ports of color c. Envelope E is the set of binary words for which these three integers agree.

For k<=3 ports:
* If some color absent, it fixes K, so each occupied color has a specified Hamming weight. With total <=3 ports, all but at most one color group have <=1 port. The sole potentially nontrivial group has 2 or 3 bits of weight 1, or 3 bits of weight 2. It has at most three rows. Every nonempty subset is obtained by forbidding individual one-hot positions, or forbidding individual zero positions in weight 2, via unary pins. Degenerate weight 0/full fixes all bits.
* If all colors present, k=3, one each. K fixes all bits; at most two K values. If both occur, all d_c equal and normalized relation is {000,111}. Any nonempty subset is obtained by unary pins.
Thus every nonempty exact regional support, including under arbitrary original internal pins, is exactly E intersect a conjunction of unary wire pins. Empty support is explicit contradiction. This is a structural bound, not an efficient way to know which rows are present. Acquisition requires exact local evaluation. Envelope can be constructed from counts without solving, and tested over at most eight words. Complement back to physical wire bits for lifting.

## 2. Constant-size planar P3DM caps (PROVED construction, full compiler not executed)
A fragment has internal triple vertices each with one incidence of each color (including stubs), internal element vertices of one color, and typed T/E boundary stubs. T bit is its triple selection; E bits contribute to exact-one occupancy. Glue stubs of opposite types and same color. For normalized E-type ports:
- A single internal element with r incoming stubs implements exactly one among r bits (r=1,2,3).
- An E port forced zero: internal triple using that element plus one private degree-one element in each other color, so its selection forced. Forced one: single element with only stub.
- Three E ports of one color with weight two: base B={000,111,001,110,010,101} on two elements per color, delete the element of that color with label 0. Its three incident triple stubs are T ports; exact one selected follows from conservation and all three options extend via B's three complementary covers. Convert each to E using a fresh same-color element with two E stubs, joining one to old T port: bit flips, so weight two. Base planar by explicit NetworkX check and also subgraph of cube vertex–face radial incidence; deleting one element puts the three ports on a common face. Rank 0/full can use separate unary caps.
- Three distinct-color E ports with equality: one internal triple connects three elements, one each color, each also has an E stub. Each external bit equals complement of the internal triple. Both options feasible.
- Flip any E port to a T port by joining to one of two T stubs of a fragment consisting of two triples sharing the same two private elements of the other colors. Exactly one of the two triples selected, so the surviving T bit is complemented. The reverse flip uses the two-E-stub element. Both gadgets planar with both stubs on exterior. Attach independently to restore physical orientations.
- If multiple colors and one absent, independent color caps occupy disjoint sectors; with <=3 ports any prescribed cyclic order can be achieved by rotation/reflection. All gadgets use constant vertices; pins refine the exact envelope as in §1. No four-port gadget claim.

Replace a contracted exterior region by such cap with its exact support, not just necessary envelope. Result is a genuine planar P3DM fragment/closed instance with actual selected-triple semantics. Pin physical edges by pinning corresponding triple, then enforce exact-one forced selections/deletions; can solve unguarded residual if desired. When closed unequal color totals, reject (no exact cover). Duplicate identical tuple nodes may be produced by contractions; after honoring pins, merge identical unpinned triples with a representative lift, since they have identical incidence and cannot both be selected. Alternatively use distinct-endpoint relays: two triples A,B sharing two private other-color elements; A uses private c element with an E stub, B has T stub of c. A+B=1 and A+input=1 imply output=input. Insert at each port to ensure private endpoints if needed. Degree restrictions on elements not assumed. Local replacement preserves planarity by contracting connected removed side to marker in a plane graph and placing cap in its disk; <=3 port order arbitrary via reflection/rotation. Planarity can be verified afresh polynomially. Store only original wire identities, never treat synthetic selected tuples as original source witness.

## 3. Automatic small-edge-cut atom tree, source-preserving evaluation (PROVED conditional coverage)
For each connected original source graph, reject isolated uncovered elements or unequal color totals. On current connected multigraph atom enumerate subsets of at most three edges and test whether removal yields exactly two connected vertex sides each with >=2 vertices, with these and only these crossing edges. If found, split and replace opposite side in each child by a fresh marker vertex with one edge per cut wire (indexed parallel edges retained). Continue greedily. When an old marker lies on one side it remains whole there. Connect final atoms by paired marker identities. Each split replaces a tree node with two nodes joined by one edge, distributing earlier neighbors by marker ownership, hence final adjacency tree. A marker represents precisely the union of original vertices on the opposite tree side: induction on splits, expanding its connected contracted region recovers that cut in original graph. An original wire may occur in multiple atom copies along a tree path; retain actual ID and enforce its same bit at every interface. Marker-marker edges carry one common bit. All cut sides connected by construction; contractions planar. No assumption of canonical decomposition or success for every greedy order.

If initial vertex count v>=2, potential s-2 for atom size s is additive: children sizes u+1,v'+1, u+v'=s, u,v'>=2; both children positive potential and strictly smaller. Therefore <=v-2 leaves (trivial small cases separately) and O(v) splits. Sum of final atom vertices = v+2*#splits, edges = m+sum cut sizes <=m+3*#splits. Simple enumeration O(N^5) graph-operation upper bound (O(N) nodes, O(N^3) subsets per node, O(N) connectivity tests per subset); explicit bit cost polynomial including labels and access. May optimize with min-cut but not needed. Every tree edge corresponds to a real <=3-edge cut.

Root the tree. At each atom, first compute complete exact child tables ONCE, storing at most three rows and one internal witness/backpointer per row. For each of the at most three parent-envelope rows (root one query), replace all child markers by exact caps, and parent marker by cap pinned to that row. Original vertices and original guards retained. Solve this closed source instance by any independently certified local terminal (matching, parity/seam, q-Horn, 2-SAT, small exact enumeration, alternative chart, etc.). Exact NO excludes row, exact YES records local original selections and child boundary rows. If any needed row unresolved, conservatively mark UNKNOWN (unless sufficient sound YES at root, or certified NO independently). No combining Cartesian child products, no conditioning across ancestor paths. Proof by subtree induction: any original assignment restricts to exact caps; any local atom witness selects child-supported masks, whose stored witnesses combine along identical original wire bits. Lift original triple selections, verify every element exactly once. This is an exact source-preserving cap decomposition conditional on terminal coverage, stronger than requiring one shared computational language. It complements CPS04 component-face tree and ES05 rank-two seams; same-color three-port relations need not be affine.

Resource ledger: O(N) atoms, at most 3 calls each, sum capped atom sizes O(N) vertices/edges and polynomial bit size; guards and synthetic IDs explicit. ## 4. Sharp four-port failure (PROVED)
Genuine source with n=2, triples F={000,110,001,111}. Region consists of first two triples (z=0) and element z0; four outgoing ports, X,Y of each triple. Conservation requires one X and one Y selected, so physical envelope in bit order (X0,Y0,X1,Y1) is {1100,0110,1001,0011}. Exact support is {1100,0011} because each triple uses equal selection bits and z0 covered once. No unary pin removes either mixed row while retaining both valid rows, since every bit takes both values. The two global covers (000,111),(110,001) support every triple. Planar graph: square of four triples with subdivided parallel paths along two sides (X,Y) and Z vertices subdividing remaining sides. NetworkX verified. Thus threshold three is sharp for universal unary refinement of the color envelope, not a lower bound on arbitrary algorithms. This example itself is easy by 2SAT; pass larger interfaces to RC02/AGE/ES/FG lanes.
