## 1. Universal topological factorization
Fix a color, say Z. Separate original connected incidence components; each must have equal counts of X,Y,Z. Reject isolated elements; handle empty input separately. In each connected nonempty G acquire a plane embedding. Delete Z vertices and incident edges; retain actual triple nodes as subdivisions of indexed XY edges. The remaining plane graph H has components C; reject any |X_C| != |Y_C|. Let a_C=|X_C|. Each z lies in a unique global face f of H, and every incident triple node lies on its boundary. Let Z_f be the labels in f. Form Q on components C and global faces f, adjacency precisely when f touches C, including empty faces.
**Theorem 1: Q is always a tree.** A connected plane component with f_C local faces has a small regular-neighborhood boundary collar for each face. Other disjoint components cannot disconnect a collar; distinct local faces cannot merge. Hence exactly f_C distinct global faces touch C. Euler gives |F|=1+sum_C(f_C-1). Consequently |E(Q)|=sum_C f_C=|V(Q)|-1. A generic path between global face interiors crosses finitely many H edges, each giving a two-edge walk via its C. All faces and components thus connected. Tree follows. Acquire global faces by traversing half-edge rotations of G, then union the two incident faces across each deleted Z-triple edge. Deleting isolated Z points does not split or merge open regions. Assign each z its incident face union class. Verify Q and each actual triple incidence. No arbitrary projection drawing.

## 2. Integer quotas and exact masks
For any solution r_Cf counts selected actual triples in C labelled in f. Necessarily sum_f r_Cf=a_C and sum_C r_Cf=|Z_f|. The unique solution to these tree equations, if consistent, is acquired by leaf peeling with integer demand subtraction. Negative quotas, nonzero root demand, or r_Cf larger than number of distinct available labels L_Cf prove NO. For r=0 delete its triples and reclose. A single XY pair with d>=2 parallel indexed edges has at most two triple nodes on each local face boundary; exactly one face quota is 1, so at most two choices survive. d=1 trivial.
Each edge exports actual mask P subset L_Cf of size r_Cf. C factor: actual indexed XY perfect matching, all Z labels distinct, exact masks on every incident edge. Face factor: adjacent masks partition Z_f. Necessity follows from source solution. Sufficiency: combine one actual matching per C; X,Y disjoint by components and each Z is in one face and covered exactly once. Unary original triple pins are local to C; arbitrary nonlocal guards require exact encoding or decline. Universal exact factor graph, not universal polynomial evaluator.
