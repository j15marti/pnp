## A. Source-anchored exact conflict projection
Let B(s,u) be any explicitly acquired satisfiable 2-CNF on source triple bits s and optional auxiliary bits u, sound for all source solutions within the current guard: every such solution extends to a model. Require all at-most-one clauses on triples sharing any element in B. Include each live element's unit or two-literal at-least-one condition when available. If B is UNSAT, the guarded source is UNSAT. A guard fixes named actual triple bits or imposes separately certified compatible conditions; any auxiliary model lift must satisfy the guard (in particular pins included in B). For the claim about source equivalence below restrict guards to pins or B-implied conditions; otherwise enforce residual guard separately, no assertion that B enforces an arbitrary nonbijunctive guard.

Fix a color C, or use all three colors together. An anchor element v is covered automatically if B AND all incident bits zero is UNSAT (polynomial 2-SAT). Delete those anchor obligations. Let A be remaining anchors. Vertex set V consists of live triples meeting A for which B AND s_t=1 is satisfiable. Assign w(t)=number of elements of A contained in t (1 through 3). Edge tu iff B AND s_t=s_u=1 is UNSAT. All queries on original triple IDs, under same guard, no marginal witness substitution.

Lemma: for a satisfiable 2-CNF and any set S of prescribed unit literals, if every singleton and pair extends then all extend. Proof: the satisfying assignments of 2-CNF are closed under coordinatewise ternary majority (if a binary clause were false in the majority, each of its two literals would be false in at least two input models, so some model would falsify both). Induct on |S|: for |S|>=3 choose three distinct requirements and use the inductive models omitting one each; majority satisfies all. Works with auxiliary variables by taking full models, hence also existential projection.

Any independent set I in V lifts by a single 2-SAT query B AND (s_t=1 for t in I). Distinct selected triples cannot share an anchor because of at-most-one. Therefore sum w(I)<=|A|. Conversely any B-model's true vertices form an independent set and their weight equals the number of its covered anchors in A. The maximum weight is exactly the maximum possible covered-anchor count in B. Thus P3DM iff MWIS(V,E,w)=|A|. At equality the lifted model covers every anchor in the chosen entire color; because every triple has exactly one vertex of that color, at-most-one gives exactly n selected triples; the other two equal-sized colors are covered by pigeonhole and at-most-one. If all colors were anchors the same conclusion is direct. Any source solution is a model of B and yields weight |A|. Verify selected actual triple IDs against original source and pins. No need to solve auxiliary model optimally. This holds for nonplanar sources too; planarity is authenticated source promise, not a property claimed of the derived graph.

Sound acquisition of B: run exact singleton propagation plus all three pair-projection allowed-edge deletion until fixed point, rejecting empty element or missing projection matching. Can leave forced triples with units and remove competitors, as in audit. For every two distinct triple variables and each of four bit patterns, pin selected indexed edges and delete zero-pinned indexed edges in each bipartite projection; failure of any projection gives a valid binary clause excluding that pattern. Check all three projections; equality of projection endpoints does not merge parallel triple labels. These clauses are necessary, not sufficient by themselves. Additional peer-provided certified binary clauses can be joined, with guard provenance. Force closure before each guarded graph, after deductions and at stagnation. Graph is acquired by O(m²+n) calls to 2-SAT after O(m²) matching tests (per projection and fixed-point stage); input explicit m=|T|. All bit widths polynomial. A constant number of anchor alternatives suffices to test all three charts and all-color weighted chart.

## B. Cooperative decomposition and exact repair
Connected components of the conflict graph are independent as weighted optimization problems, even if they share auxiliary 2-CNF variables: union of selected stable sets is pairwise compatible, and the unit-pair lemma supplies joint lift. Sum the component optima; do not multiply their witness catalogues. Modular decomposition also permits exact weighted quotient: a module is seen uniformly by external vertices, replace its nonempty optimum by one quotient vertex of that weight; lift selected modules by stored internal optima. A prime quotient still needs an admitted terminal. An acquired claw-free graph is polynomial MWIS by Nobili–Sassano (2015 preprint, later literature); weighted integer inputs here <=3m, standard bit-cost overhead polynomial. No implementation of this backend in audit. Recognition by enumerating all four-vertex subsets suffices.
If a graph has a vertex deletion set D of size k whose complement is claw-free, acquire such a set by searching one of the four vertices of a detected induced claw (4^k poly(N)); any deletion set must hit the claw. Enumerate independent subsets J of D; delete D\J and the neighbors of J outside D; remaining graph is an induced subgraph of claw-free complement. Add weights of J, solve MWIS there; take max, lift via B. Cost (4^k+2^k) poly(N), deterministic; fixed k<=c log N admits polynomial cap. Across independent components, costs add, not multiply. This exact AND/OR structure does not require new forced information. At each residual, try all acquired charts and stop only at exact witness or certified optimum deficit; rejected admission or timeout is UNKNOWN. Uniform coverage remains open.

## C. Strong obstruction to universal claw-free 2-CNF projection
A 3-color anchor v with three distinct actually attainable incident triples cannot be covered by every model of ANY sound 2-CNF B, even with arbitrary auxiliary variables. Choose three source witnesses selecting different incident triples at v; majority of their full B-model extensions makes all incident bits zero. Each of the three witnesses selects exactly one, so no bit is true in two. Thus v is an unresolved anchor in every sound bijunctive relaxation. This uses actual integer source witnesses, not projected matching support.

Explicit planar 3×3×3 core T (digits are coordinates in separate sets):
000,001,011,012,020,022,100,101,110,111,210,212,220,222.
Construction: start all eight faces on a properly 3-colored octahedron with two vertices of each color (all binary triples). Remove face 010 and glue another octahedron minus one face using its three corresponding corners, introducing new index 2 in each color. Replace removed face by the seven mixed faces. Incidence planarity follows by placing triple vertices inside faces and drawing three radial edges to their corner elements; no crossing. Graph connected.

Four actual full source matchings:
M0={000,111,222}; M1={001,110,222}; M2={012,101,220}; M3={020,101,212}.
In their union, every one of nine original elements has >=3 distinct incident triples, checked explicitly. Let center=012 and leaves=000,111,222. Center individually extends (M2), leaves jointly extend (M0). Center shares one different element with each leaf, hence the three graph edges are forced by at-most-one; leaves have no edges since they jointly extend. All four graph vertices occur in every color anchor chart (and all-color chart), since their incident elements cannot be discharged by sound 2-CNF. Therefore every one of these four exact conflict graphs contains an induced claw for EVERY sound B that preserves all source solutions. Adding arbitrarily many certified pairwise implications cannot fix it. This is a representation counterexample, not a lower bound. Guards or solution-discarding exact reductions may remove it; no claim that modular or other terminals fail.

Scalable connected source family: glue successive fresh octahedra into any face unused by the four tracked matchings. Replace one face by seven; extend all four matchings with the new diagonal (k,k,k). There is always an unused face (6n-4 faces versus <=4n selected occurrences; for n>=3, 6n-4>4n). All old witnesses and their claw survive, source remains planar connected, m=6n-4. No solution-oracle required to construct it. Repeated disjoint copies of the 14-triple core yield b vertex-disjoint induced claws in each of the four global charts, even if B couples copies through sound clauses, because all products of source witnesses extend B. Any deletion modulator to claw-free must have size >=b; hence no universal O(log N) global claw-modulator bound. The disconnected products are easily factorable, so do not refute bounded modulator per prime block. The connected family proves persistent claw but not linear minimum modulator after factorization. Neither is an all-lanes adversary.
