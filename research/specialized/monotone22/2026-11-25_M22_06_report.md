## Theorem A: one-sided exact occupancy
For any subgraph retaining specified edge IDs of H_D (deleted edges assigned zero), use one bit x_e per edge. Impose odd vertex degree at every vertex and odd selected edge count on the two alternatives of each double label, all over GF(2). The latter enforces EXACTLY one of its two edges, hence exactly d C-C edges in every parity solution. Each vertex has selected degree 1 or 3 because maximum degree <=4 and odd. Let a_C,a_S count the degree-three vertices on each side. Count C and S edge endpoints in integers:
    m+2a_C = 2d + s+2a_S.
Since m=2d+s, a_C=a_S. Therefore enforcing degree-one on EITHER side alone is necessary and sufficient for an actual perfect matching with exact double-label occupancy. In particular any surplus defect on one side must have a counterpart on the other. No probabilistic or fractional inference. Also sum selected edges = n+2a_S, so equality to n suffices; optimizing integer weight over the affine relaxation is not assumed easy.
This is a specialized exact projection: parity acquisition is polynomial; only one side requires nonlinear one-hot clauses. It applies equally to the union of any number of actual anchor matchings, to a source-built full H_D and to a one-edge deletion/restoration guard. It never treats an arbitrary point of a matching affine hull as a matching.
