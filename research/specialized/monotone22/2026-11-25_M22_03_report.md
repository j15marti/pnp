## Theorem 1: matching compilation with two choices per double label
Use M22-02 normalization (every SAT word can be transformed into a representative cover using all n labels by alternating-path augmentation; exactly d=n/3 represent two same-sign clauses). Fix only a set D of d original labels declared double representatives, not their signs or pair endpoints. Other labels S=V\D are singleton representatives. Build loopless labelled multigraph H_D:
- one vertex per original clause, one additional vertex per singleton label;
- for each singleton label, connect it to each of its four incident clause vertices;
- for each double label v, add two separately identified clause-clause edges e(v,0),e(v,1) between its two negative and two positive occurrences respectively.
There are 2n vertices and O(n) edges. Parallel edge identities must not be collapsed semantically. A source guard x_v=b deletes mismatching incident representative edges. D itself is a representation guard, not an ordinary source pin.

Every perfect matching of H_D has exactly d clause-clause edges, since all n-d singleton vertices match one clause and the other 2d clauses match in pairs. It is a valid normalized D-track iff it chooses exactly one edge per double label (equivalently at most one, by count). A valid matching lifts to a source word by assigning each label the sign of its unique representative edge; direct clause verification. Conversely any normalized cover with double labels D gives such a matching, preserving guards. Thus exact source decision is OR over D; fixed D is not presumed polynomial in general. Ordinary matching is a relaxation, not a SAT decision. A failed D-track is not necessarily a failed source sign guard.

## Theorem 2: exact allowed-edge boundary factorization
Use deterministic general-graph perfect matching (Edmonds) with forced edge e implemented by removing its endpoints and banned IDs removed first. A forced list requires pairwise disjoint endpoints. Keep parallel IDs in the wrapper, using simple adjacency only for existence after restrictions. Delete every edge not occurring in any perfect matching (one query per edge). Every perfect matching uses only allowed edges; each connected component of the allowed-edge graph has a perfect matching and the Cartesian product of component matchings is exactly the original relaxed family. No cross-component edges remain. If either sign of a double label is impossible, the other sign is forced within D; if neither, reject D. Reclose source guards and repeat allowed-edge computation. At most n newly fixed signs. No source-wide claim without discharging D.

For each component K, let c_K be its clause vertices and s_K its singleton vertices. Every local perfect matching uses exactly (c_K-s_K)/2 double edges. Enumerate the *indicator patterns of the double edges*, not all perfect matchings, using binary prefix DFS and matching feasibility with force/ban. With h local edge IDs and cap L, at most O(h(L+1)) oracle queries until exhaustion or L+1 distinct patterns acquired. Each feasible visited prefix extends to a distinct enumerated leaf or the current frontier; charge failed children. This is polynomial for fixed L=N^a, even if the number of full matchings is exponential.

A double label is internal to K when its two allowed sign edges are both in K or its sole allowed edge is in K. Enforce exactly one for these labels locally, discard patterns violating it, and project onto the remaining boundary edge IDs B_K. Store one original pattern for each projected vector and reconstruct a local matching by force/ban. Each cross-label has exactly two boundary occurrences in distinct components. Empty exact local relation rejects D. Do not infer exclusions from a truncated list. A complete local list may have complex internal patterns yet a one-element boundary relation. Each boundary relation R_K has constant weight r_K=(c_K-s_K)/2 - number of internal labels in K; sum r_K equals number q of cross-labels. This is exact, not an independence assumption: the only cross-component constraints are exactly one selected occurrence of each label. Conversely any compatible boundary vectors lift independently to local matchings and then to a source word.

## Theorem 3: two heterogeneous polynomial compatibility terminals
(A) If each complete projected R_K is majority-closed, it equals its unary/binary projection formula. Proof: for any word with every pair present, every subset of positions admits a matching tuple by induction. For size k>=3, take three tuples matching that subset except one distinct position each; their coordinatewise majority matches the full subset and belongs to R_K. Base cases one/two positions. Thus add all missing unary/binary patterns as clauses; add exact-one clauses for each cross-label. SCC 2-SAT decides and lifts, using a stored preimage per component and actual matching queries. Majority closure is checked by all triples in the explicit table. If not majority-closed, the binary envelope remains necessary; an envelope contradiction is exact D-NO, a candidate is verified against actual tables/matchings or returns UNKNOWN.

(B) If each nonempty complete R_K, as a family of subsets of B_K, obeys the matroid basis-exchange axiom (for any bases A,B and e in A\B some f in B\A yields A-e+f in R_K), it defines a local matroid. Verify every exchange directly from the explicit table. Independence oracle: subset of some listed base. Form direct sum M of these matroids on all boundary incidences, and a partition matroid P allowing at most one occurrence of each cross-label. Deterministic cardinality matroid intersection obtains a largest common independent set. Its maximum is q iff compatible boundary vectors exist: size q saturates every partition class and the rank sum, hence each local selection is a base. Conversely compatible selections form a size-q common independent set. Lift with the stored full pattern and actual matching. This is a different exact polynomial method that handles e.g. one-of-three boundary constraints (uniform matroid U(1,3), not bijunctive). Classical shortest exchange-path algorithm uses O(N^3) independence-oracle calls, each explicit table scan polynomial in N,L. If any relation violates basis exchange, decline this terminal, not source UNSAT. Mixed matroid/bijunctive clusters can be processed separately if their cross-label incidence components are disconnected (immediate from exact factorization); not implemented. Neither backend is assumed universally complete.

## Strict counterexample and limit
The 18-variable connected strict source below, D={1,...,6}, has 4,559 SAT words. Positive clauses are three copies of K4 stars on disjoint six-edge label sets:
[1,2,3],[1,4,5],[2,4,6],[3,5,6],
[7,8,9],[7,10,11],[8,10,12],[9,11,12],
[13,14,15],[13,16,17],[14,16,18],[15,17,18].
Negative clauses (all entries negative):
[1,7,12],[1,18,7],[2,9,18],[2,15,9],[3,8,15],[3,10,8],[4,17,10],[4,11,17],[5,16,11],[5,14,16],[6,13,14],[6,12,13].
All twelve double sign edges occur in some relaxed matching, independently checked by forcing each. K4 positive component has no singleton vertices, all six boundary edges allowed. Its exact base patterns in positive-label order 1..6 are 001100,010010,100001 (the three perfect matchings). The majority of all three is 000000, absent; a one-element exchange between distinct bases is impossible. Thus universal boundary matroid/bijunctive claim for every fixed D is FALSE even for a connected satisfiable strict source; this is not a counterexample to existence of some other good D. Exact K4 enumeration and grammar/connection checked. The binary envelope nevertheless gives a candidate verified on this instance, showing the admission failures do not prove algorithm failure. Separately X12 D={1,2,3,7} has a relaxed matching but no valid normalized D-cover; reference exhausts all 16 sign choices. This falsifies ordinary matching alone. X12 D={3,4,7,9} has exact boundary 100,001,010 and matroid intersection succeeds with 3 augmentations, despite majority failure.
