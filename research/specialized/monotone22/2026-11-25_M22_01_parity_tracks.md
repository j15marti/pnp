## Lemma 1: exact signed parity compilation
Let A be the m-by-n unsigned clause-variable incidence matrix over GF(2), b_i=1 for a negative clause and 0 otherwise. For an assignment x, the parity of the count of true literals in clause i is (Ax)_i+b_i. Define a track s in GF(2)^m, with s_i=1 when true-literal count is even. The complete exact track imposes Ax=1+b+s. In a consistent fiber x=x0+Kz, with K full column rank, every s_i=0 clause is automatically satisfied because its occupancy is 1 or 3; every s_i=1 clause has occupancy 0 or 2 and requires at least one literal true. Write its three literal truth values as affine forms f_ij(z)=l_ij z+c_ij. Their sum is zero on the fiber. The constraint is that they are not all zero, equivalently at least one of any two distinct occurrence positions is true. Thus it is an affine avoidance constraint of rank at most two, not an arbitrary 3-CNF residual. Inconsistent affine systems are rejected by Gaussian elimination; constants, identically true literals, forced false clauses and tautological opposite forms are handled exactly. A successful z reconstructs x and is checked against the original signed clauses and the complete parity signature. No semantic oracle.

Equivalent graph compile: positive and negative clause vertices respectively form two loopless cubic multigraphs on the same edge-label set of original variables, each variable an edge on each side. True labels must edge-cover the positive graph, false labels edge-cover the negative graph; disjoint edge covers are sufficient since unused labels may be assigned arbitrarily. Each label has two incidences per side. This gives the signed occupancy interpretation and linear-size bidirectional source map. Neither ordinary matching nor the fractional x=1/2 solution enforces joint cover.

## Theorem 2: canonical independent algebraic blocks of a fixed track
After constant/tautology closure, let U_i be the span of all nonconstant literal coefficient rows of surviving owner i. Choose a linear basis B of their total span by greedily selecting actual rows. Express each literal coefficient in B coordinates using Gaussian elimination. For each owner join all basis coordinates occurring in any of its coefficients. Connected components C_j of this coordinate hypergraph have dimensions r_j=|C_j|. Every owner belongs to exactly one component. Because B is linearly independent, the map z -> (B_k z)_k is surjective: ALL block choices may be combined. Each block is solvable independently by enumerating its r_j evaluation bits, and a successful combination is lifted by solving Bz=y, then x=x0+Kz. Thus exact time poly(N)*(1+sum_j 2^r_j), polynomial peak storage with sequential enumeration (including all failed attempts, source map, Gaussian elimination, reconstruction and verification). Cumulative live-memory cost <= time times polynomial peak storage; no parallel span substituted for work. Naive bit-matrix implementations and explicit source indexing cost polynomial, including on an ordinary deterministic TM with polynomial simulation overhead. Code uses BigInt exact arithmetic, capped enumeration returns UNKNOWN, not UNSAT, when the cap is exceeded. The uncapped mathematical terminal is polynomial when every block has O(log N) rank with a fixed constant. This holds even with many algebraic blocks and dense original variable overlap.

The owner partition is the finest direct-sum decomposition of the **declared surviving observation spaces**: if owners are partitioned into groups with independent spans, each chosen actual basis row lies in one such group, and the subset of B inside each group spans that group (otherwise B could not span the total direct sum). Hence the unique basis representation of each owner's coefficient uses only its group's basis coordinates. No coordinate hyperedge crosses the proposed partition. Our components refine every such partition, and themselves have direct-sum spans. This is basis-independent at the level of owner blocks. Not a claim of finest semantic decomposition after arbitrary deductions.

Optional polynomial terminal inside a block: if a distinct independent representative coefficient can be selected from each surviving owner's nonzero literal forms, choose those literals true and solve the resulting independent equations. Linear matroid intersection with partition matroid finds the representatives, or certifies this sufficient criterion fails. Rado condition is rank(sum U_i for i in S)>=|S| for every owner subset. Failure alone is not UNSAT. This optional backend is proved as an application of standard matroid intersection, **not implemented** in today's audit.

## Theorem 3: minimum parity-exception portfolio is incomplete
Every valid source has even exception count separately on each sign: summing literal truth parities over that sign gives 0 (each variable occurs twice), and m+ and m- are even. This is necessary, not sufficient.

The following connected, strict, 12-variable source (clauses numbered 1..16 in this order) is SAT, but every globally minimum-exception assignment is UNSAT.

Positive:
[2,6,11], [3,8,9], [3,7,9], [4,5,10], [1,5,10], [1,2,7], [4,8,12], [6,11,12].
Negative:
[-1,-10,-12], [-2,-6,-11], [-6,-7,-9], [-4,-5,-10], [-1,-3,-4], [-8,-11,-12], [-5,-7,-9], [-2,-3,-8].

Proof: opposite-sign pairs (1,10) and (4,12) have equal underlying triples, so each forces exactly one even-parity clause. Minimum exceptions >=2. If exactly two, even count per sign excludes the mixed alternatives {1,12},{10,4}. The unsigned 16x12 incidence matrix has rank 12; independent row indices 1,2,3,4,5,6,7,9,11,13,14,15 (Gaussian reduction). For exceptions {1,4}, the unique solution is integer bitmask 3020 (bit i-1 gives x_i), falsifying clause 1. For exceptions {10,12}, the unique solution is 825, falsifying clause 12. Both are realizable, so optimum exactly 2, but both fail. Mask 62 (true variables 2,3,4,5,6) satisfies all 16 clauses with occupancies [2,1,1,2,1,1,1,1,3,1,2,1,1,3,2,1], hence four exceptions. No intermediate odd exception count possible. This independently specifies an elementary finite proof, corroborated by full enumeration. For k disjoint copies, minima 2k vs SAT minima 4k; even searching every globally minimum track fails, and any constant additive tolerance fails eventually. Disjoint copies can themselves be solved separately, so this is not a connected-family or unrestricted runtime lower bound. No assertion of new literature priority.
