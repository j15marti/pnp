## Theorem 1 (exact local support/sign factoring)
Given a strict instance F, a supplied near-word a satisfying all owners except d, consider the GUARDED chart x_i=a_i+delta_i mod5 with delta_i in {-1,0,+1}. This is a radius-one cyclic-color chart, not ordinary Hamming distance. Full-domain GAC initially is vacuous on valid full lists: each color has support in every owner by cyclic translation. Within the radius-one guard perform exact GAC, including the defective owner. Enumerate at most 27 allowed displacement tuples for d, pin one tuple per track, and reclose. For every protected owner there is a unique role ordering (l,m,r) with a_m=a_l+1, a_r=a_l+2 mod5. In that order the complete displacement table is:
(-,-,-),(-,-,+),(-,+,+),(0,0,0),(0,+,-),(+,-,0),(+,+,+).
Proof: direct 27-case scan, independent of base rotation; code checks all five rotations. The support s_i=[delta_i != 0] satisfies exactly s_m=s_l OR s_r. Conversely each support pattern allowed by this equality has sign completions locally. If all three active, encode minus=0 plus=1; signs must satisfy z_l<=z_m<=z_r. If l alone inactive, z_m=1,z_r=0; if r alone inactive, z_l=1,z_m=0; if all inactive no sign condition. These four cases exhaust the table. Current allowed domains add support pins (only zero or zero absent) and sign pins conditional on activity (if one nonzero sign absent). The fixed d tuple is retained throughout.

Thus global support feasibility is dual-Horn: implications l->m, r->m, and m->(l or r), plus pins. Its greatest possible support S is computable by starting from every variable with an allowed nonzero value, deleting l,r if m absent and deleting m if both endpoints absent, to fixed point. Reject if any required-active variable is removed. Every deleted support variable is absent in every feasible support by induction, and if all required pins survive the fixed point satisfies all equalities. Soundly pin these zeroes, reapply GAC, repeat to saturation. At most 3n domain deletions. For a given feasible support, sign feasibility reduces to ordinary directed implication reachability with unit pins (a special 2-SAT/Horn problem). Seed all forced-plus vertices, propagate along all-active arcs, reject iff a forced-minus vertex reached. If no clash, set all unreached active vertices minus and inactive vertices zero. Every original owner holds by the table and d pins. Witness lift x=a+delta and original verification cost polynomial. These are exact, no numerical LP or hidden solver.

## Theorem 2 (failure-path comparison and exact capped tracks)
At maximal support S, if sign propagation fails, retain an actual implication path from a forced-plus vertex to a forced-minus vertex. Form H as the union of all three active variables of each owner generating an arc on the path, plus the active variables of the owners giving its two endpoint signs, or just the endpoint for a unary domain pin. All H lie in S. An arbitrary feasible support S' under the same guard is contained in S. If S' includes H, every path arc remains active and every mixed endpoint-sign owner has exactly its original active variables (its inactive variables cannot turn on). Domain pins persist. The same contradiction follows. Hence the guard entails OR_{i in H}(delta_i=0). This deduction is valid even when the maximal support itself is not realizable, and is not an unconditional full-source implication without the radius/defect/branch guard. Certificate is checkable from stored domains, roles, support closure and actual path.

Branch ONLY on the alternatives delta_i=0 for i in H that permit zero. Reapply paid closure initially, after every pin/zero deduction and at stagnation. If no permitted alternative exists, guarded NO is exact. Otherwise each branch strictly decreases maximal active support and covers every actual solution. Exhaustive recursion is an exact local decision and witness algorithm, possibly exponential. For fixed cap b and maximum permitted certificate size h, stop with UNKNOWN on an exceeded cap, never NO. At most 27*(1+h+...+h^b) nodes, each polynomial; for h>=2 this is O(27*h^b poly(N)), and h=1 is O((b+1)poly(N)). In particular fixed h and b<=c log_2 N yield a uniform polynomial terminal if caps checked before expansion. Even if unrelated branches exceed caps, a witness with <=b missing active coordinates relative to its root greatest support has a compatible branch of length <=b, provided certificate-size cap holds on that branch. Reason: each branch along witness path zeros a distinct coordinate not in witness. No product of all possible sign selections. This is a genuinely different alternative-track architecture from fixed 2-lists: entire sign family optimized exactly per support. It is not a proof that h or b is universally bounded. Certificates may be exchanged with other support tracks only after checking the complete guard or deriving a valid guard-discharge proof.
