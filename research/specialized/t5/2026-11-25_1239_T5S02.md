## Theorem 1: complete finite two-list classification
For an ordered two-element list L, write its sorted entries L[0],L[1]. Type A if pair is consecutive on Z5, D otherwise. For each of 10^3 ordered triples of lists enumerate eight bit triples and retain those whose colors form C. To classify a relation T, form K(T) from every missing unary bit value and missing binary pair, forbidding each by a unary/binary clause. T is bijunctive iff all eight bit triples have identical membership in T and K(T). This is an exact finite proof: every unary/binary implicate is one of the tested clauses (or tautological); any 2-CNF representation therefore contains only implications already entailed by T. For empty T, K(T) is inconsistent. The following table is reproducible by the nested loops above, with no input-dependent enumeration beyond constant 1000*8 and 18 candidate clauses per relation. The audit also checks majority closure separately.

Types | empty | 2-tuple bijunctive | 4-tuple bijunctive | 4-tuple nonbijunctive
AAA | 5 |120|0|0
AAD |30|330|15|0
ADD |75|240|0|60
DDD |35|60|30|0
TOTAL |145|750|45|60

For every exceptional relation the unique A coordinate is a function of both D bits, all four input pairs occur and the A bit occurs with frequency 1 or 3 among the four tuples. Thus complementing appropriate inputs and possibly output makes it an AND gate. This follows because a Boolean function of two bits with precisely one true (or false) input is a conjunction (or negated conjunction) of two signed inputs. Test of all 60 is part of the finite proof; pseudocode: for each exceptional T find A coordinate, check |projection_DD T|=4 and sum(A bits) in {1,3}. Singleton restrictions of any relation are always binary relations plus pins. Hence any instance with lists of size <=2 and no surviving exceptional owner has an exact 2-SAT solver with linear number of clauses. Mixed A/D types alone do not guarantee tractability.

## Theorem 2: exact binary projection and component parameter
On a fixed list guard, apply GAC (all eight tuples per owner), and encode every bijunctive residual owner by its exact K(T), adding forced singleton domains. Call resulting binary formula B, remaining nonbijunctive owners E. Sound unconditional within-guard closure includes B feasibility and both polarities of every bit via 2-SAT; retain forced bits and rerun GAC. Reclassifying after each deduction is permitted; keeping stale larger owner relations plus original pins is also sound and complete.

Let U be union of scopes of E. Existentially eliminate from B every variable outside U by Davis-Putnam resolution. Elimination of v combines (v or P) with (not v or Q), retaining P or Q and all clauses not involving v. For any word on remaining variables, the resolvents exclude exactly the case where both values of v are prohibited; hence projection is exact. Width remains <=2, and canonicalizing/deduplicating at each elimination leaves O(n^2) distinct clauses (including units and empty). Detect empty clause. This is a polynomial uniform projection, not a guessed boundary. Build graph on U with edges for each projected binary clause and a triangle for every exceptional owner. Different connected components have disjoint projected variables and no shared clause. For each component j choose one bit from each exceptional owner, deduplicate choices to a set S_j (could use a greedy hitting set). For each of 2^|S_j| words, guarded GAC and exact substitution render every owner binary; solve component 2-SAT. Keep one successful component word or reject if all alternatives exhausted. Combine successful component words then solve original B with all their U coordinates pinned. Exact projection guarantees extension; the extension satisfies every exceptional owner because their scopes are all in U. Verify original list clauses, then lift the strict source as applicable. If B is contradictory, or any exhaustively tested component has no witness, return UNSAT for the guard only. If any budget cap prevents exhaustive component processing return UNKNOWN, not UNSAT. No global inference from failure under a proper guard.

Time <= poly(N)*(1+sum_j 2^|S_j|), without multiplying independent component costs. In particular uniform polynomial decision and witness recovery for |S_j| <= c log_2 N for every component, fixed c; check admission and charge failed discovery. A complete track can use exact resolution or implication SCCs. All other nonadmitted cases may be solved by independent tracks; neither global admission nor logarithmic cap is established. The binary projection is crucial; components built only from exceptional scopes are not exact. Direct single-clause restoration: if all other guarded residual owners are bijunctive, enumerate at most eight allowed bit triples of the deleted owner and query B under their pins. Both labels exact; no need for an assumed complete relaxed witness basis. For unrestricted 5-valued C the analogous restoration uses 30 tuples if a tractable guarded residual solver actually supports those pins. A single relaxed word, or affine span of sampled words, is not such an oracle.

## Theorem 3: disjoint exceptional scopes, acyclic circuit flow, and known one-deletion witness still NP-complete
A separate explicit two-list C language with exactly two colors per name, vertex-disjoint exceptional owners, a designated clause d and supplied near-model violating exactly d is NP-complete. All clauses use distinct names. Proof by guarded OR/NOT CircuitSAT; the following is a new compact two-list implementation of the handoff gates.

A=(0,1), Y=(0,3), Z=(2,4), H=(3,4), K=(2,4), P=(0,2). Ordinary Boolean wires have list A. A NOT gate between A wires p,x uses C(p,x,h) with fresh list K; its binary projection is x=1-p, and the full relation has 4 bijunctive tuples. For OR gate with p,q list A, fresh x list A and fresh y,z lists Y,Z, add C(p,y,h), C(q,z,j), C(x,y,z), with fresh h,j list H. First two clauses project exactly to y_bit=1-p, z_bit=1-q; their full relations have two tuples. Last has precisely bit tuples (0,1,1),(1,0,0),(1,0,1),(1,1,0) in (x,y,z) order. Consequently x=p OR q. All local witnesses obtained by scanning two helper colors; conversely every model obeys the gates. Each exceptional owner consists of a fresh gate output and two fresh private input copies, so no exceptional scopes intersect, even when circuit inputs repeat or wires fan out. NOT and binary converter clauses can link these different scopes. Directed circuit dataflow is acyclic by construction, but this is not acyclicity of the projected binary interaction graph.

Given arbitrary Boolean circuit J, add fresh input g and compute O=g AND J using NOT/OR. Final pin d=C(O,u,v) with u,v fresh list P=(0,2); its only two bit tuples are (1,0,1),(1,1,0). Thus the whole list CSP is SAT iff J is SAT. Take source inputs all zero and g=0, forward evaluate every gate, extend helpers and set (u,v) bits (0,1). This is a known full near-word violating exactly d, even for UNSAT sources. Both-label uniform compilation and witness decode/lift polynomial; language in NP because syntax/list types, disjoint exceptional scopes, near-word, and candidate assignment are checkable in polynomial time. This falsifies the universal *sufficiency* of disjoint exceptional scopes or acyclic gate direction for the proposed 2-SAT component terminal (a universal polynomial solver on this promise would imply P=NP, not ruled out). It does not assert that every hard circuit has large component width after all allowed reductions or any unrestricted runtime lower bound.

Strict-C compilation: introduce anchors a0..a4 with five cyclic consecutive triple clauses. Every pair co-occurs so distinct; allowed triple complements are consecutive pairs, forcing frame a_i=s±i. For each list variable v and each of the three excluded anchor indices j add C(v,a_j,h_vj), private full-domain head. Existence of head iff v!=a_j since every unequal pair extends to a consecutive triple. Thus in a fixed frame projected v has exactly its specified two-list. This is an ordinary strict C instance without explicit list syntax; for any frame both projection and lift preserve every gate, and helper extension uses five tests. Known near-model lifts to strict input with exactly same designated violated d. Decoder reads anchor indices, ignores private heads and obtains Boolean witness. No clauses repeat names; repeated pair occurrences allowed in this compiler (S01 offers optional degree-nine linearization but not asserted to preserve the displayed two-list residual structure). Unrestricted strict C already NP-complete by this compiler alone, independently of the historical count reduction. Decision remains distinct from counting. The two-list/exceptional promise applies to the exact contracted list chart, not unpinned full strict-C domains (global color symmetry). If a deletion touches a frame or list-exclusion clause, the chart no longer follows and must be rederived or retain its guard.
