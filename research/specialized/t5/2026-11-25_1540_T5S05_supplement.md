# T5S05 supplementary correction and additive-basis decision track
2026-11-25 15:40 PT. Additive, preserves original report. Scoped PROVED; witness acquisition for rank-unbounded basis packing OPEN.

Resource clarification: the main report's 5^k N^5 DP time term uses directly indexed syndrome tables in k independent coordinates, with base-5 index of O(k) bits. On a bit-RAM, coordinates are acquired by Gaussian elimination; store actual witness words with each occupied index, allocate/scan 5^k positions, each transition O(poly(N)). If instead using naive linear-search dictionary, replace that term by 5^(2k) N^5 (and analogously 5^d by 5^(2d) in the discovery time bound). Both are polynomial for fixed d and fixed logarithmic k cap; no change to proof or audits. JS Map implementation is finite computational evidence, not a physical resource measurement.

Subsequent primary paper inspection: Alon, Linial, Meshulam JCTA 57 (1991) 203-210, Proposition 3.1, pp.205-206, original author PDF https://www.cs.tau.ac.il/~nogaa/PDFS/Publications2/Additive%20bases%20of%20vector%20spaces%20over%20prime%20fields.pdf (rendered pages checked). For p=5, l indexed disjoint bases of a rank-r space suffice for all binary subset-sum targets if r*(3/4)^(l-3)<1. Translate via t_i=2 epsilon_i-1; hence the same condition certifies every signed target. Additional columns can be assigned arbitrary signs. Greedily extract and verify independent bases from the remaining indexed columns, remove each extracted basis before the next, test exact integer inequality r*3^(l-3)<4^(l-3), l>=3. Polynomial access, rank verification and bit arithmetic; if packing succeeds, exact existential decision certificate of saturation in arbitrarily high rank. This is a sufficient condition, not complete packing acquisition; greed may fail. The paper's existence proof does not supply a paid witness algorithm here, so this is decision-only and not an unconditional constructive lift. If used to eliminate a group it preserves decision, but reconstructing its signs remains an open separate obligation. Do not use certificate as a solver of arbitrary guarded subsets.

The same paper p.204 explicitly refutes the tempting four-bases sufficiency conjecture for p=5. Three copies of standard basis e1,e2 and one basis e1+e2,e1-e2 omit subset-sum target -e2. Exhaustive 2^8 binary words independently checked below. Indeed writing diagonal inclusion bits a,b, x-coordinate u+a+b=0 mod5 with u in 0..3: if a+b=0 then u=0, if a+b=1 impossible, if a+b=2 then u=3. Thus a=b; y-coordinate v+a-b=v in 0..3 cannot equal 4. For signs convert target to 2(-e2)-sum of columns; full span and four bases are not sufficient saturation. The theorem is a known result transferred to our syndrome representation, not claimed novel. General witness acquisition and universal coverage remain OPEN.
