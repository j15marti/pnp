## Lemma 1: hereditary density from cographic basis packing
Write r(H)=|E(H)|-|V(H)|+c(H), the cycle rank, with parallel edges allowed and isolated vertices counted consistently. Orient G and take a fundamental cycle matrix B, one row per chord of a spanning forest, over F5. Its r(G) rows form a cycle-flow basis. An indexed column set J of cardinality r(G) is a basis iff its complement is a spanning forest: rank deficiency iff a nonzero cycle-flow row combination vanishes on J, i.e. a nonzero circulation supported by the complement; acyclic supports admit none by leaf deletion and a cycle supplies one. Size then forces a spanning forest. This applies over F5, not only F2.

If J_1,...,J_9 are disjoint bases, each complement is a forest. For any subgraph H of G, J_i intersect E(H) must contain at least r(H) edges because deleting those edges leaves a forest on V(H). The nine intersections are disjoint, giving
  |E(H)| >= 9 r(H)   for every H subset G.  (D9)
No basis packing acquisition is required by the solver. Given bases, verification of disjointness and forest complements is polynomial. Exact packing via matroid union is a possible separate recognition method, not executed or required.

## Lemma 2: exact difference-set series elimination
For an oriented edge uv keep a set A_uv subset F5; reverse orientation negates it. Initial edge labels have two distinct residues (e.g. h_e +/-1). Feasibility is x_v-x_u in A_uv. Remove isolated v, storing arbitrary lift. At degree 1, remove v and its edge (nonempty relation always has a lift for any remaining endpoint). At degree 2 with incident edges a-v and v-b, replace them by a-b with
  A_ab=A_av+A_vb={p+q:p in A_av,q in A_vb}.
If a=b check 0 in A_ab; if false, exact NO; if true discard loop. If A_ab=F5 discard edge; otherwise retain it. Every step is exact existential projection for each remaining potential. Save eliminated vertex and its two original current difference masks, reconstruct backward by testing the five possible values of v, and verify all original edges and C owners. This is also a deterministic witness algorithm for saturated path regions with arbitrary endpoint values.

Provenance invariant: each remaining edge represents a path of original edges, with eliminated interiors pairwise disjoint and endpoints current; paths are edge-disjoint. No merged parallel edges or unjustified intersections. For a path of length k, its difference set is the iterated sum of k two-element sets. A nonempty proper subset of F5 cannot be invariant under a nonzero translation, so adding two distinct residues grows size by >=1 unless full. Thus any retained non-full edge represents at most three original edges. Loops arising from a degree-two cycle are processed before further graph operations. All guards/offsets remain on the original edge IDs. No nonempty proper domains or externally pinned vertices are included in this claim.

## Theorem: D9 implies uniform polynomial full syndrome saturation and witness
Assume the elimination has not finished. If it stagnates, residual graph K has minimum degree >=3 (degrees count parallel edges), v>0 vertices, e edges and c>0 components. Then v<=2e/3, so
  r(K)=e-v+c >= e/3+c > e/3.
Expand each residual edge back to its recorded original path, forming a subgraph H of G. Subdivision preserves cycle rank, so r(H)=r(K); all paths have length <=3. Hence
  |E(H)| <= 3e < 9 r(H),
contradicting D9. This argument accounts for all deleted edges by retaining only the actual expansion of K; it does not incorrectly infer density from total graph size. Therefore D9 guarantees no stagnation. A failed loop test would expose a cycle of total original length <=3 (length >=4 has all residues, including zero). Such a cycle violates D9 too. Initial graph has no loops; no empty sumsets occur. Consequently every allowed edge-difference choice under D9 has a feasible potential, and reverse elimination constructs it.

For arbitrary syndrome target b of a fundamental cycle matrix B, choose offsets h on non-tree edges with B h=-b and h=0 on forest (orient each cycle row so its chord coefficient is +1). Solve x_v-x_u=h_e+t_e, t_e in {+1,-1}, by the algorithm above. The cycle equations give B(h+t)=0, so B t=b. Conversely any t with B t=b yields a potential by forest integration. Thus nine disjoint cographic bases suffice for ALL syndrome targets, with deterministic polynomial witness acquisition. Row-equivalent cycle representations and nonzero column scalings are handled by invertible row operations and two-distinct-residue labels; this generalization is symbolic, not separately implemented. ALM's logarithmic-many-bases existence bound for general matrices is not being strengthened in general, only on a graphic-source dual structure.

The graph algorithm actually needs neither a supplied packing nor a D9 oracle: greedily eliminate degree <=2, and at stagnation output H with |E(H)|<9r(H). Return UNKNOWN, never UNSAT on that basis. This yields a polynomially recognizable sufficient terminal containing all D9 graphs and other peelable graphs. A whole graph with m>=9r(G) need not satisfy D9: a zero-offset triangle with 100 private leaves has m=103,r=1 but triangle sums of three +/-1 never yield zero mod5; it is UNSAT. K4 zero-offset gives a separate UNSAT graph where series solver honestly declines. A four-cycle has fewer than nine bases yet solves. These demonstrate both the hereditary requirement and nonnecessity of the certificate. In the strict source the triangle claim is guarded by adjacency (or the exact adjacency gadget), not arbitrary plain private C clauses.
