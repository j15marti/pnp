## 2. Main theorem CEC02 (PROVED)
Fix a graph G, actual perfect matching M, and a registry of pairwise vertex-disjoint even M-alternating simple cycles, with original edge IDs. A chart means all simultaneous binary switches of these cycles. Guards pin a subset of choices; apply them first, remove their cycles from registry. Partition remaining cycles into squares Q and longer cycles L. Any combination is a perfect matching. CEC01 proves for fixed long choices that square completion succeeds iff every component of the host graph retaining all edges on unpinned squares and all chosen complementary edges elsewhere has even order. Proof recap: a square whose two current complement edges lie in different cycles merges them by switching; at most n merges, at stagnation all host edges lie within complement components. No dependence on square assignment enumeration.

Remove ALL edges belonging to unpinned longer cycles from this host before choosing them. Also remove fixed matching edges, while retaining both choices of every square. The remaining base graph B is independent of all unpinned choices. Contract each connected component U of B to a vertex with weight w(U)=|U| mod 2. For longer switch i, let P_i^0,P_i^1 be the two sets of quotient edges corresponding to the two possible COMPLEMENTARY alternating pairings (opposite to its matching). Preserve loops and original occurrence provenance, or discard loops for connectivity only. For a choice word z define K_z to be the quotient graph containing P_i^{z_i} for every i.

**Exact equivalence:** chart SAT iff there exists z such that every connected component C of K_z has XOR weight zero. Indeed the pre-square host components are exactly the unions of base components connected by the selected longer complement edges. Their orders mod 2 equal the quotient component weights. CEC01 solves square choices polynomially and lifts. No approximation by counting odd cycles in a fixed reference.

### 2a. Two safe normalization rules
For a switch i, write pi_b for its connectivity partition on current quotient vertices using only P_i^b (other vertices singleton).
* Common partition contraction: if u,v are connected in both pi_0 and pi_1, contract them, XOR their weights, and update all quotient incidences. Any completion contains that connectivity; component weights and feasibility are unchanged. The intersection relation is computed by grouping equal pairs of partition labels. It can be contracted simultaneously across switches because every legal completion contains all these connections. This is chart-conditional, not a fact about arbitrary source matchings.
* Dominance: if pi_0 refines pi_1, select choice 1 and contract its components (and vice versa). Replacing 0 by 1 only merges components of ANY completion using the other switches. A union of even-weight components is even. Thus there exists a successful completion with choice 1 whenever one with 0 exists. This is satisfiability-preserving normalization, NOT a proof that 1 is forced in every successful word. Keep chosen bit and reconstruction provenance. Guarded choices applied first. At least one vertex or switch disappears each strict normalization, at most O(N) rounds per local job.

### 2b. Exact articulation factoring with parity-adjusted weights
Build the support graph K^+: for every remaining switch, add a clique on all quotient vertices incident to either option; isolated vertices remain. Cliques may be represented by support lists and spanning stars for connectivity, rebuilding the stars after vertex deletion. This graph overapproximates all possible selected connections. If any K^+ component has odd total weight, chart infeasible. Its disconnected components are independent.

For a connected even-weight support component and an articulation vertex a, deleting a gives disjoint regions V_j. Each switch's support is contained entirely in V_j union {a} for some j, because its support was made a clique. A singleton support has no effect and may be normalized away. Partition switches accordingly. Make one child per region with a retained. For x in V_j keep w(x); replace articulation weight in that child by
    w_j(a) = XOR_{x in V_j} w(x).
The total child weight is zero. Then the parent is feasible iff ALL children are feasible under these changed weights.

Necessity: in any successful parent choice, all components in a child not containing a are also parent components and hence even. The unadjusted XOR weight in its a-component excluding a equals XOR of the entire V_j, since all other components are even. Adjusted a-component is therefore even too.
Sufficiency: pick any feasible choice independently for each child. Components not meeting a remain even. Their a-components glue into a single component of weight w(a) XOR (XOR_j w_j(a)) = total parent weight = 0. Thus exact. Each source switch belongs to precisely one child; witnesses concatenate without compatibility enumeration. Artificial duplicated articulation weights are boundary summaries, not duplicated physical graph vertices; the final original-edge witness is verified.

Recursively apply normalizations and cuts. For a terminal support job with b_j remaining longer switches, enumerate its 2^b_j assignments only, checking weighted component parity. The chart's exact runtime is poly(N)*(1+sum_j 2^b_j), not poly(N)*2^(sum_j b_j). Can cap each terminal at fixed c log_2 N: if exceeded return UNKNOWN unless another exact child certifies chart NO. If all terminal jobs admitted, exact decision and original witness lift. This is a stronger terminal than CEC01's bound on total longer switches. Arbitrarily many long switches may be solved even with b_j=1. No restriction on their lengths. Source graph need not have articulation vertices: quotient cuts are computed after actual matching/host contraction. For a chain of long cycles with each neighboring pair attached through one square host block by two outside paths each, and all other ports paired internally, distinct switch support cliques meet only at their shared square blocks. This gives a family of source-authenticated charts with b_j<=1 before optional normalization (decompose first if desired). Both labels of chart can occur; the construction need not be an NP-hard reduction image.

### 2c. Independent affine-bijunctive interface (PROVED)
For fixed choice z, even weighted components iff there exists a subset of selected quotient edges with incidence parity w: in every component, summing vertex rows cancels every edge twice, so necessity; for sufficiency choose a spanning tree and eliminate leaves, assigning the parent edge the residual weight, leaving zero at the root. This gives an exact alternative polynomial-size formula for arbitrary chart choice: private variables y_{i,b,e} for each option edge occurrence, vertex GF(2) rows sum incident y=w (loops cancel), and implications y_{i,b,e}=1 -> z_i=b. Use a distinct copy of z_i in every implication and affine equality tying it to z_i. Thus each 2-CNF clause uses two private endpoints, matching AB01's literal-disjoint binary layer. Wide vertex parity rows can be split by private affine chains. Projection: active y edges certify weighted parity; inactive y forced zero; recover z and square completion. Lift: use spanning trees, copy z, set inactive edges zero. All size and bit costs polynomial; no assumption that AB01's whole NP-complete language is tractable. This is an exact cross-agent interface rather than an analogy. Not implemented in this run; graph-equivalence backend tested instead. For a complete actual witness basis in this chart's relaxed affine-bijunctive representation, AB01's restoration theorem applies only after charged acquisition.

## 3. Edge punctures: a different exact source-level track
Answer to AB01's deletion transfer request: ordinary source edge deletion behaves unusually in cubic graphs. If any nonempty subset of the three edges incident to a single vertex v is temporarily deleted, EVERY proper <=3-coloring of the remaining graph extends to G. Count for each color c the deficits over all vertices: n - 2|E_c| is even since n is even. At v, the missing colors are distinct and exactly k in number; the k distinct other endpoints have one deficit each. Even parity of every total forces the other endpoint deficit multiset to equal precisely the missing colors at v, once each. Restore the deleted edges with their other endpoints' missing colors; verify. Includes one edge, two adjacent edges and full star. Thus ordinary one-edge relaxed SAT is equivalent to source SAT, not a uniformly supplied easier witness family for snarks. This does NOT apply to deleting a selected-pair edge in a chart or arbitrary constraint relaxations.

For two vertex-disjoint deleted edges e=(a,b), f=(c,d), any relaxed proper coloring either restores directly (both endpoint pairs equal) or both edges have different missing colors, using the same unordered pair {p,q}, each color twice. In the p-q subgraph, all four deficit vertices have degree one and every other vertex degree two. Exactly two paths pair the terminals (plus closed cycles). If a path pairs endpoints of DIFFERENT deleted edges, swap p and q along it: either the two originally equal deficits both change, making all four equal, or the two differing deficits exchange, making each deleted edge's endpoints equal. Restore and verify in polynomial time. If the paths pair a-b and c-d, no combination of these p-q path flips restores the two edges. This is a scoped obstruction for the given coloring and that color pair, not source NO or no other Kempe sequences. Explicit SAT counterexample triangular prism in puncture results; Petersen relaxed words all blocked by this test. This provides a second independent source-level track with exact guarded failure information.
