## A. Matching equivalence, source closure
A proper 3-edge coloring partitions E into three perfect matchings. Conversely M is extendible to a coloring with M as one color iff every connected component of G-M is an even cycle; alternate the other two colors on each. This is exact for all cubic graphs (not merely bridgeless). Validate input, detect bridges: in a proper coloring each color appears across a cut with the same parity as the number of vertices on its side, by counting incidences. A bridge cannot satisfy this condition. Bipartite cubic components are YES by Hall, repeated matching and cycle alternation; disconnected components factor independently. Acquire any perfect matching by a deterministic polynomial general-graph matching algorithm; absence certifies NO, presence alone does not. Test complement parity immediately. Sound necessary matching pins may be acquired with paid deletion/forcing matching queries; no free full semantic closure. A reference matching is not an unconditional pin.

## B. Square-switch chart theorem (PROVED)
A chart consists of G, an actual perfect matching M and a supplied family C of pairwise vertex-disjoint M-alternating 4-cycles, each retaining original edge IDs. Toggle any subset of C via symmetric difference; all resulting edge sets are perfect matchings, and switches commute. Let R be the subset of M not contained in any supplied square. Let H=(V,E minus R), the host retaining BOTH local alternating matchings at every square and all fixed complement edges. Then
    there exists a chart matching with an even complement
    iff every connected component of H has even order.

Necessity: all candidate 2-factors are spanning subgraphs of H, and a disjoint union of even cycles has even order. Sufficiency: start at M. In the current complement F, each square contributes two opposite edges. If those lie in two distinct F-cycles, toggling the square deletes one edge from each of those cycles and reconnects their two paths using the other opposite edges. They become one cycle, never split. This uses vertex disjointness so every available square is still alternating. While possible, perform such a merge. Each iteration reduces the number of F-cycles by exactly one. At a fixed point, every square's four vertices lie on a single F-cycle; every host edge outside F is a square edge, hence connects vertices of that same F-cycle. Thus F-components equal H-components. Their orders are even by assumption. Color M' with color 0, alternate 1 and 2 on its complement cycles, and verify every original incidence. At most |V|/3 merges in a simple cubic graph, or conservatively |V| merges. There is no enumeration of the 2^|C| matchings and no claim that this is an exhaustive representation of arbitrary perfect matchings.

Guarded version: pin any set of supplied square choices, apply their toggles, remove them from the available registry and rebuild H. The same iff theorem holds for that precise guard. Test both possible values of each remaining square by this host criterion; a branch with odd host component is impossible in the chart. When one branch is impossible, retain the other with its authenticated guard and repeat until no new forced coordinate. This obtains all chart-local forced single-switch values without free SAT calls. Do not project these facts as unconditional facts of G unless portfolio coverage is independently established. If the chart rejects, return UNKNOWN for G, not NO. Initial, post-deduction and stagnation checks use these exact necessary or chart-exact facts; no full semantic closure assumed.

Corollary: for a vertex-disjoint family of alternating even cycles with b cycles longer than four, enumerate only the b long-cycle choices; for each, invoke the square theorem on the remaining squares. Complete chart decision in 2^b poly(N), uniform polynomial if b <= c log N for one fixed c. Long cycles may have unbounded length. Supplied choices checked, original edge provenance retained. A portfolio can serially run many independent such charts; only one needs a witness, but all-input positive coverage remains OPEN.

## C. Two explicit limitations
The Petersen graph has perfect matchings whose complements consist of two pentagons. The audit gives an alternating 8-cycle switch for which H is connected on 10 vertices (even), yet both possible complements have orders 5,5. Thus substituting arbitrary alternating cycles for squares in the iff theorem is false. Exact edge-ID counterexample in results.json.
The dodecahedral graph has 36 perfect matchings, 30 with even complements, but an explicit bad reference has complement orders 5,10,5. Its girth is 5; no square chart starting from this reference can repair it. This does not preclude finding a different reference or an arbitrary alternating-cycle repair. The tested corpus did not produce a strict oddness local minimum under all single alternating-cycle flips; no general descent claim follows.

## D. Explicit hardness-preserving girth-six compiler (PROVED)
Take H0 with two parts indexed i in Z7; connect left i to right i+d for d in {0,1,3}. Each part has degree 3, edge type d gives a proper 3-edge coloring. All six ordered nonzero differences between the three offsets are distinct mod 7, so no two left vertices have two common neighbors; no 4-cycle. Bipartite implies no odd cycles; girth at least 6. Delete the edge e0=(left 0,right 0). In any input loopless cubic graph G, replace each edge uv by a fresh copy of H0-e0, with ports u-left0 and v-right0. The resulting graph G* is simple cubic, even if G had parallel edges. Any cycle wholly inside a template has length >=6. Any cycle traversing a template from port to port uses an internal path of length >=5 (otherwise with e0 would create a shorter cycle); together with the two port edges it has length >=7. No cycle can use exactly one port of a copy. Thus girth >=6.

Projection and lift: the two ports of each template are a size-2 edge cut around its 14 internal vertices. The cut parity identity forces the two port colors to agree. Decode that common color as the original edge color. Conversely, for each original edge of color c, permute the three explicit offset colors so deleted e0 has color c, and use c on both ports; the gadget lifts independently. Both labels and witnesses are preserved. n* = n + 14m = 22n for cubic G, m*=22m, with polynomial ID bits; parser, source maps and verification polynomial. If desired require bridgeless target: reject inputs containing bridges and map them, loops and malformed input to a fixed NO (expanded Petersen); if source is bridgeless, any template internal edge lies on a cycle of H0, and a cycle using e0 can replace that edge by a path outside the template along an original cycle containing uv. Port edges also lie on such cycles. H0 is bridgeless (its explicit three-coloring implies no bridges). Therefore the expanded graph is bridgeless. This proves NP-completeness for simple bridgeless cubic graphs of girth >=6, not necessarily planar, bipartite, or cyclically highly connected. A connectedness promise is not needed. The Petersen graph is uncolorable, as witnessed by its six perfect matchings all with two pentagon complements (finite explicit audit).

Stronger reference preservation: for any actual source matching M, if uv belongs to M choose both port edges and the type-0 internal matching with e0 deleted; otherwise choose no port edges and the type-1 internal matching. This is a perfect matching M* of G*. For selected source edges the internal complementary components are even cycles. For unselected edges there is exactly one internal complementary path between the two ports, with all other components even cycles. The path has odd length because the endpoints are on opposite bipartition sides. Adding two port edges preserves its odd parity. Therefore each source complementary cycle expands to a cycle of the same parity; only extra even cycles are introduced. The number of odd complement cycles is exactly preserved for EVERY supplied source M. The girth-six compiled dodecahedral counterexample is a SAT source with a bad reference and no available square switches. This excludes the square-only repair of that reference, even after a uniform hardness-preserving expansion; it is not a lower bound against arbitrary reference acquisition, long-cycle switches, source-aware inverse contraction or a general solver. The compiler's 2-edge interfaces are intentionally transparent.
