## 1. Fixed-intersection theorem (PROVED)
Let M be a supplied verified reference perfect matching, F=G-M its disjoint cycles, and S a proposed exact intersection M∩L for a candidate target perfect matching L (the edges receiving color 2). This is a guard, not an unconditional deduction. Authenticate S subset M. On each F-cycle mark the endpoints of S. A marked vertex already has its target matching edge and cannot use any cycle edge. Every unmarked vertex must be matched by an edge of its own F-cycle because all other M edges are forbidden. If a cycle has at least one mark, deleting marked vertices leaves disjoint paths (including zero-length gaps). A path on an odd number of vertices has no perfect matching; an even path has exactly one, pairing successive vertices from its endpoint by induction. Thus each hit cycle either certifies guard infeasibility or uniquely determines all its target matching edges. An unhit odd cycle is infeasible; an unhit even cycle has exactly two matchings. In particular if every cycle is hit, L is uniquely determined or nonexistent, and the original coloring under this exact S is decided by checking evenness of every cycle of G-L. If YES color L with 2 and alternate 0/1 on each complement cycle. This is polynomial source-authenticated decision and lift under S; NO does not reject other intersections.

More generally after these deductions the only switches are independent alternating unhit even cycles. If all are squares, CEC01 solves the entire residual by host-component parity and cycle merging. With b unhit cycles of length>4, enumerate their two choices, then square closure; time 2^b poly(N). If b<=c log N, a polynomial terminal. This is an exact transition into CEC01/03, not a universal guarantee on discovery of S. In an all-odd F, every feasible S must hit every cycle, so no residual ambiguity survives once S is known.

## 2. Seven-cycle source compiler (PROVED; finite witness table supplied)
For each vertex v of an arbitrary cubic source H replace it by a disjoint seven-cycle 0-1-2-3-4-5-6-0 with chords (2,5),(3,6). Three ports at vertices 0,1,4 are matched to the three original incident edge IDs in deterministic sorted order. Join corresponding ports for every source edge. Let G' be the result; M consists of both internal chords in every gadget plus all exterior edges. M is a perfect matching; G'-M consists exclusively of disjoint seven-cycles. Each gadget is triangle-free (chords have cycle distance 3; they are disjoint), and external edges are a matching, so no exterior triangle. Graph simple even for distinct parallel source edges, since each uses distinct ports. Connectedness preserved if source connected. n'=7n, m'=21n/2. No claim of girth>=5 or cyclic connectivity. A loop in the source is immediately rejected, and malformed encodings can be mapped to a fixed negative instance.

Every coloring of G' restricts on each gadget's three exterior ports to three distinct colors: for each color c, 7 = 2*(number of internal edges with color c) + number of ports with color c, hence each port count is odd and all three equal 1. Decode exterior colors as a source coloring.

Conversely every ordered distinct port triple can be extended with both internal chords avoiding color 2. The following table gives explicit internal color vectors in edge order (01,12,23,34,45,56,60,25,36); boundary order (0,1,4):
012 : 2 0 2 1 0 2 1 1 0
021 : 1 0 2 0 2 0 2 1 1
102 : 2 1 2 0 1 2 0 0 1
120 : 0 1 2 1 2 1 2 0 0
201 : 1 2 0 2 0 2 0 1 1
210 : 0 2 1 2 1 2 1 0 0
Each row is checked by the three distinct incidences at each of the seven vertices; chord values are always 0/1. This is a constant-size explicit witness lift, not a search oracle. In particular there is exactly one color-2 incidence of M per gadget. Thus both ordinary 3-edge-colorability on the promise 'supplied 2-factor consists entirely of seven-cycles, simple triangle-free cubic graph' and existence of a color-2 matching with minimum intersection |M∩L|=n/2 are NP-complete by uniform many-one reduction, including malformed input handling and direct witness map. This is a derived restriction, not attributed to Holyer or claimed novel in literature.

## 3. Minimum-intersection barrier (PROVED)
In any graph with a supplied all-odd F, every perfect matching L intersects M at an odd positive number of incidences on each F-cycle: count vertices covered by L internally in pairs. Therefore |M∩L|>=k/2 for k cycles, counting each intersection edge twice even if internal to one cycle. In the compiler k=n. For ANY source perfect matching P, select S to be its exterior edge copies. Each gadget has exactly one marked vertex. The six remaining vertices on its seven-cycle form an even path, which has a unique matching. Hence L exists with |M∩L|=n/2, regardless of source colorability. Conversely any minimum L in the compiled graph has exactly one marked incidence per gadget, so no internal chord can be in S (it would contribute two). Its S therefore corresponds to an actual source perfect matching P. Its even-complement condition is equivalent to the even-complement condition of P in H: if L extends, decode the coloring; if P extends, assign color 2 to P and use the explicit table, which yields the unique L determined by S. The minimum L family is in bijection with source perfect matchings, with exact YES/NO for every corresponding guard.

Consequences: a polynomial min-weight perfect matching optimizer (cost 1 on M and 0 otherwise) can attain the lower bound on all compiled sources with a perfect matching, including both colorable graphs and snarks. Neither optimal intersection cost nor individual odd-cycle parity detects the missing compatibility. The existential acquisition of a successful minimum S is NP-complete on this source-authenticated family. This falsifies sufficiency of minimum-cost intersection and per-cycle hit closure, not an unrestricted lower bound. Even fixed cycle length seven and one selected reference edge incidence per cycle do not by themselves make the acquisition problem tractable. Triangle contraction does not apply directly, although this construction has obvious three-port reductions and does not defeat all heterogeneous tracks.
