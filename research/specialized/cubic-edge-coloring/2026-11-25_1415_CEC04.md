## 1. Four-pole states and one-exchange reachability
Split at an actual four-edge cut with exactly four ordered incidences on each side (use distinct original edge IDs even for repeated endpoint vertices). A pole consists of internal cubic vertices and four semiedges with free leaf endpoints. No boundary pins unless explicitly stated. The number of internal vertices is even by 3n=2m+4. In every proper coloring each port color occurs an even number of times by summing its incidences. Modulo one global permutation there are four possible equality types:
A=0000, P=0011, Q=0101, R=0110.
Let S(X) be the actual attainable type set. Global gluing iff intersection nonempty, since each orbit is precisely one equality pattern; permute colors on one side and join matching port IDs.

KNOWN structural fact: every nonempty S has size at least 2, and two-state 4-poles are the color-open iso/heterochromatic cases of Chladny and Skoviera, Factorisation of Snarks, EJC 17 R32 (2010), Proposition 3.1–3.5, DOI 10.37236/304. Their Prop 3.4 gives exactly the incompatibility classification. We do not claim priority. The constructive strengthening used here is: given ANY coloring, one alternating-path color exchange produces a different type. Proof: if A, choose its common color x and any other y; otherwise choose the two colors x,y present on the four ports. The x-y subgraph, with free ends materialized as leaves, consists of cycles and paths. Every internal vertex has degree 2, each of the four port leaves degree 1, so the path starting at port 0 ends at another port. Exchange x and y on that entire path. In A the two endpoints change and two do not, giving a pair type. In a pair type, endpoints either have equal colors (swap gives A) or unequal colors (swap gives a different pairing). Every internal incidence stays proper. Cost O(N) graph operations, no search for a prescribed target type. This proof is for unguarded coloring and cannot preserve arbitrary edge pins.

## 2. Main theorem: one residual, at most four new vertices
Given a complete exact type table S for one side X (one witnessed actual coloring per admitted type), remove X and replace it by a cap:
* S empty: source NO.
* S={A,P_i}: join the two pairs of external stubs of pairing P_i, giving zero new vertices. This cap admits exactly A and P_i.
* S contains precisely two pair types: let P_i be the missing pairing. Insert two adjacent vertices, attach each of the two pairs of P_i to a distinct new vertex. Properness requires differing colors within each pair and parity of the four ports makes the two allowed types exactly the other two pairings; the third internal color is the same at both vertices. Thus exact.
* |S|>=3: use any fixed four-cycle cap with one ordered port per vertex. It admits A and two adjacent-pair patterns (e.g. A,P,R for cyclic order 0,1,2,3). Explicit alternating internal coloring for A; for P use internal colors 1,2,0,2; R by rotation. The opposite-pair pattern Q cannot occur since each internal edge would have to take the third color. Thus its size is 3.

For the first two nonempty cap cases, equality-type sets coincide. In the large-set case BOTH S and cap have >=3 states; any feasible outside pole Y has >=2 states and intersects each. Hence G colorable iff capped G' colorable. This uses decision equivalence, not exact preservation of all boundary states. Stronger lift from ANY coloring of G': remove the cap and retain the outside coloring. If its type belongs to S, glue stored actual X witness after permutation; otherwise |S|>=3, so the current type is the only type missing in S. Perform the single alternating path exchange of Section 1 on the outside. Its new type is different, hence belongs to S. Glue. Verify every source edge and incidence. This is an actual source-level witness transformation with at most one Kempe path, not a search over all outside assignments.

A single arbitrary constant cap does NOT preserve feasibility for all nonempty tables. E.g. complementary two-state iso {A,P} and hetero {Q,R} join to a NO graph despite both sides locally colorable. For >=3 types replacement also need not preserve exact state: audit has 21 outside/cap state incidences absent from original X table. Therefore never apply relaxed cap to preserve precolored guards or chart choices. With boundary guards use the exact full type/color table instead; no Kempe repair assertion. At reverse reconstruction of successive unguarded caps, each current coloring is valid for the then-current graph; changes to still-contracted caps are allowed and are checked at their later reverse expansion.

## 3. Polynomial admission and discovery
Fix constant c. At every unguarded cubic residual enumerate all subsets of four current edge IDs, remove them and compute connected components. A component with exactly four boundary edges, order >4 and <=c log2(N+2) is a candidate side X (N is ORIGINAL encoded length). Verify cut and provenance. Search also ordinary bridges (NO by parity), connected components, and bipartite components (YES via repeated perfect matching). For each candidate acquire four exact table entries by canonical boundary pins and exhaustive color assignment or local GAC+DPLL on X. There are O(|X|) edge variables, so 3^{O(|X|)} poly(N) time. Canonical pin queries retain their guards; not global pins. After every local deduction, reclose all incident three-color all-different constraints until fixed point; before branching at stagnation, use the complete available local closure. Empty domain NO for guarded local query only. Exact cap replaces at least six vertices by <=4 (even order), so at most n/2 strict reductions. No branching between caps. If reduced residual admits an existing polynomial terminal (bipartite, bounded width, authenticated CEC03 chart), run it and reverse reconstruct; if no terminal and no cut, return UNKNOWN, not source NO. For guarded downstream tracks keep exact source maps and final verification; unguarded cap reduction not sound as a semantic pin. Finding a suitable small cut is not assumed; O(m^4) cut tests per stage plus local table work. The complete reduction loop and graph cut discovery are mathematically specified, not implemented in this audit. Source forced matching probes can be performed by ordinary matching under a chosen color-0 convention; not executed this iteration. No claim of full semantic closure, and no universal guarantee of admitted cut or terminal.

Alternative acquisition theorem: each two-element subset of {A,P,Q,R} has a zero- or two-vertex cap as above. Six ordinary cubic coloring queries on X with these caps give YES iff the chosen pair intersects S. If one query NO and S nonempty, its complement is exactly S (size at least 2); if all YES, |S|>=3. With witnesses, collect their actual types. If fewer than min(3,|S|) are collected, choose an unrepresented 2-element query containing at least one true type and avoiding the collected types, contradiction. This yields all 2-state witnesses or >=3 actual witnesses, sufficient for the unguarded reduction. It does not distinguish every 3-state from 4-state table and does not acquire them for free. Six calls on arbitrary large sides can be NP-hard; no recursive polynomial bound from this oracle identity. Local log-sized acquisition avoids that circularity.
