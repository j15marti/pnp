## 1. Source language and exact compilation
Explicit finite simple undirected 3-regular graph, asking if a proper three-edge coloring exists; malformed encodings negative. Holyer, SIAM J Comput 10(4), 718–720 (1981), DOI 10.1137/0210055, publisher abstract explicitly gives NP-completeness for cubic graphs. Full original proof not retrieved; do not claim a stronger original promise. To cover even a loopless multigraph convention, CEC01's 2-port Heawood compiler gives simple cubic output: replace every source edge by a fresh bipartite cubic 14-vertex template (left i to right i+d, d=0,1,3 mod7), deleting the 0-offset edge at index 0 and attaching its two endpoints to the two source endpoints. Boundary parity around 14 internal vertices forces equal port colors. Decode this color on the source edge; conversely permute the offset colors so the removed edge has the required color, and attach ports. Uniform linear object growth n'=n+14m, polynomial ID bits, both-label preservation and forward/backward witness maps. Loops are immediate NO and can map to Petersen. This also yields girth>=6 but no planar promise is used. NP membership by checking three distinct incident colors. Source decision iff some perfect matching has all-even complement: color 0 on it, alternate 1/2 on each cycle; converse immediate. Finding ordinary matching alone does not solve this.

Paid source closure: validate graph, factor connected components, bridges certify NO by cut parity; bipartite cubic components YES by repeated matching. Deterministic general-graph matching with each edge forced/deleted can certify necessary matching pins, not pins in every arbitrary color name without choosing a color-0 convention. ## 2. Sparse event compilation (PROVED)
Take valid reference perfect matching M and pairwise vertex-disjoint M-alternating even cycles, with original edge IDs. Check all incidence, parity, alternation, disjointness and matching conditions. Retain both square options if applying CEC01; otherwise treat squares as ordinary switches. Remove fixed matching edges and both alternatives of all explicit switches. Contract connected components of the retained base, giving weighted quotient vertices v with w(v)=order mod2. CEC02 proves existence of a successful chart iff there exists switch word z with all components of the quotient selected by z of even weight (then square merges lift if retained). If no squares retained, the selected complement is already a 2-factor and quotient components exactly its cycles. For each nonloop option-edge occurrence e=(u,v,i,b), choose y_e in GF(2), with y_e=1 only when z_i=b. Require XOR of incident y_e at every v equals w(v). Parallel occurrences retain distinct IDs; loops cancel and can be discarded. This is exact: summing rows over any selected component forces even weight; conversely on its spanning tree assign edge bits from leaves toward root, satisfying the rows when total weight is zero. Thus y certificate is not a guessed connectivity partition. Original-edge reconstruction needs only z, then CEC01 square merging if used, cycle alternation and full source verification.

Define event interaction graph J on one vertex for each quotient row v and one vertex for each switch i, distinct types. Each event contributes a triangle on (u,v,i). Isolated rows and switches retained. Unlike CEC02's support clique graph, J does not clique all the ports of a long switch. Multiple events in one triangle are separate occurrences. The size is polynomial in encoded chart length N, with all event and source provenance explicit. AB02's private binary endpoint compilation remains valid; this direct graph avoids introducing equality copies just for an implementation.

## 3. Tree-decomposition parity theorem (PROVED)
For any valid chart and any tree decomposition of J of width t, exact chart decision and original coloring lift are possible in 2^{O(t)} poly(N) deterministic bit work (including decomposition validation and reconstruction; decomposition representation length charged if supplied). Proof: every event triple is a clique and is contained in a bag, by the Helly property of connected subtrees of a tree. Assign each event once to an actual bag, verify assignment. Root the decomposition and convert to a standard nice decomposition with introduce/forget/join nodes (or use bag-to-bag transitions). Add event-processing nodes at the assigned bags. At a bag retain exactly one bit per vertex: a switch node stores z_i, a row node stores XOR of processed incident y_e. At switch introduction choose allowed z_i, including any coordinate guard. At row introduction set partial parity 0. For an event (u,v,i,b), choose y=0, or y=1 if z_i=b; XOR y into both row bits. At a forget-row node require the accumulated bit to equal w(v), as no future event can touch that row by running intersection. Forget-switch simply drops its bit. At a join require identical shared switch values, XOR the shared row bits from the two child subtrees; the disjoint event ownership prevents double counting. Keep one actual predecessor record for each reachable bag state. Empty root accepts iff reachable. Induction on processed subtree proves the table is exactly the set of partial assignments satisfying all interior row equations and implications with recorded boundary data. Equal states have the same legal continuations; no connectivity-partition information is needed. An isolated odd row fails; isolated switch may choose any permitted bit. Guards restrict choices without increasing width. Reconstruct one consistent z and optionally y by backtracking; verify source. This is a decision theorem, not counting.

At most 2^{t+1} states per bag; naive pairwise join costs at most 4^{t+1}; number of bags/events after normalization polynomial in input/decomposition size. Source-authenticated compilation, source maps, all transitions, sorting/deduplication, pointers, reconstruction and verification polynomial overhead. Use Bodlaender et al., SIAM J Comput 45(1), 317–378 (2016), DOI 10.1137/130947374: given graph and integer h>0, deterministic 2^{O(h)} |V| time either certifies tw>h or returns decomposition of width <=5h+4. For fixed c, h=ceil(c log_2(N+2)); verify returned decomposition and evaluate. If tw<=h, success guaranteed. If width test rejects, decline UNKNOWN for chart (not source NO). This charges discovery, unlike simply assuming a supplied small separator. The external discovery algorithm and general nice-tree DP are mathematically specified, not executed in current code. Bit simulation incurs polynomial overhead in admitted regime. Graphs of zero width handled directly. Source chart acquisition itself remains OPEN.

## 4. Executable ordered variant and exact regional compression
For a chosen ordering of event occurrences, each row/switch lives from first to last occurrence. At each event introduce new endpoints/switch, branch on its permitted switch value if first seen and legal y, update parities, verify final row parities, forget closed variables. Keep one prefix per active-bit word. The frontier size f counts active row and switch bits INCLUDING introduced vertices; this is a path decomposition with width at most f-1. Exact 2^f poly(N) bit work and space, even if total switch count is arbitrarily large. Choose order by original switch sequence or other bounded portfolio; exact width computable in polynomial scans. Can cap at f<=c log N before allocating; every failed order charged. Do not drop z before its last event, and do not merge prefixes merely because their row bits agree when active z differs. This is the direct counterpart of AB02's syndrome trellis, but uses sparse physical row support rather than computing linear-span intersections. Neither width dominates the other universally.

## 5. Authenticated biconnected ring family (PROVED)
For k>=3, make k disjoint alternating 6-cycles with three consecutive left ports and three consecutive right ports, options (01)(23)(45) vs (12)(34)(50). Connect each right port to a distinct left port of the next switch cyclically by a path of length 1 or 2 (arbitrary permutations). Pair all subdivision vertices by fixed matching edges, requiring an even number; each source vertex has degree 3, all edges distinct, source connected. Base quotient consists of 3k path components (weights 0 or 1 according to subdivisions), each switch sees six distinct components. Every switch's option partitions have no common nonsingleton blocks and neither refines the other; no CEC02 common contraction/dominance. Support-clique graph is a ring of six-vertex cliques, consecutive intersections of size three; connected after any single vertex deletion, no articulation factorization. Thus it has one unresolved block of k switches, even though the event frontier in switch order has at most ten bits (first/last ring boundary three, incoming three, outgoing three, current switch one). This family is outside CEC02's logarithmic-local-switch admission test, but the new terminal is polynomial. This does not say no other CEC02 or direct source track could solve it.

Independent ring transfer: let l in GF(2)^3 be the three flow bits arriving at left ports. For each chosen switch option assign one shared bit to each of its three pairs (8 possibilities), requiring its left bits equal l. Right bits XOR each path's weight, permuted to the next switch's left ports. Enumerate the eight possible initial l values, propagate at most eight states at each stage, require return to same l at closure. Guards restrict local choices. Correctness follows directly from the event incidence rows on each two-port base path. O(k) transition count with constant factor, full prefix copying/reconstruction polynomial (implemented with array copies, not claimed linear physical time). Both independent implementations verify reconstructed proper coloring of the actual cubic graph, not merely quotient parity.
