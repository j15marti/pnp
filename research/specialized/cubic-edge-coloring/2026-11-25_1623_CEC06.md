## 1. Kempe-consistency fixed point (PROVED)
For an actual ordered k-edge cut (both sides cubic poles after adding private leaves at ports), let U be the canonical boundary words over {0,1,2}, modulo global color permutation, satisfying each color count congruent to k mod2. Source and exterior may be disconnected. For state s and pair of colors a,b, form I={j:s_j in {a,b}}. Its size is even. Enumerate ALL perfect pairings P of I, with empty pairing allowed. For each P form orbit O(s,a,b,P) consisting of canonical words from interchanging a,b on the two endpoints of any subset of P. Do not impose a planar/noncrossing restriction. These are abstract path pairings, not asserted physically realizable.

For allowed state set D define monotone filter F(D)={s in D: for each color pair a,b there exists P with O(s,a,b,P) subset D}. Iterate from D until stable, producing K(D). Every actual unguarded exterior state set S is consistent: choose an actual coloring for s, trace its two-color paths pairing the active ports (all internal vertices have degree two in this two-color subgraph; cycles irrelevant). All path subsets can be exchanged independently, so the full abstract orbit under that particular pairing lies in S. Thus F(S)=S. Monotonicity gives S subset K(D) whenever S subset D. K(D) is greatest abstract consistent subset, not necessarily realizable as an actual pole.

For a set of target types T, if K(U minus T) is empty, every colorable exterior has a state in T. More strongly, every actual starting coloring can be converted constructively: record the parallel round r when each non-target type was deleted. If current s has rank r, some color pair has NO orbit wholly contained in the previous survivor set. Trace actual paths for that pair and enumerate their at most 2^(k/2) subsets; one yields a target or a smaller rank. Swap those paths and repeat. At most |U|-|T| rounds, each preserving proper coloring. This is constructive forced-information elimination on abstract state types under the guard 'avoid T'; NOT a proof that deleted types are unattainable in the original pole. No actual coloring acquisition is assumed free. If K nonempty, decline universal certificate, not global UNSAT and not proof that a physical counterexample exists.

General relative cap criterion: if S(B) subset S(X) witnessed, and certified upper set D_X contains S(X), then K(U minus S(B)) intersect D_X empty suffices for unguarded decision equivalence for ANY exterior. Otherwise an exterior colorable with X but not B would have S(Y) subset U minus S(B), hence S(Y) subset K, contradicting its shared state in D_X. Exact outside-preserving reverse lift from ANY reduced coloring follows from S(B) subset S(X). Universal cap case K empty uses D_X=U, no negative queries about X. Forward Kempe changes may break pins; arbitrary guarded equivalence not claimed. Under exterior pins only use individually certified safe path exchanges or full exact guarded tables; unguarded fixed point is invalid as guarded authority.
