## 4. Exponential witness coverage and oblivious portfolio barrier (PROVED restricted)

A fully fixed reference-compatible chart determines q_i0 for each source variable. Hence X_i=q_i0 xor s0 and at most two source assignments (a complement pair) can occur in its projection. This statement depends on using anchored minority-majority pairs; permitting arbitrary opposite pairs such as (X_i,Y_i) without reference compatibility changes the representation and is not covered by this bound.

Take k disjoint original triples with n=3k. Exactly 6^k source witnesses exist, each lifts to genuine one-mismatch geometry by Section 2. Every full chart covers at most two source witnesses. Thus any explicit complete witness-cover by these charts has >=6^k/2 charts, exponential in M, or 2^{Omega(N/log N)} with usual binary index encoding. This is a representation-size bound, NOT a decision lower bound: the family is itself easy.

For a hybrid chart whose j=0 entries are free at f source variables and fixed elsewhere, the same argument bounds projection by 2^{f+1}. An explicit family of hybrids with only O(log N) such freedoms cannot cover all witnesses in this example with polynomially many members. A hybrid allowing all necessary freedoms is not ruled out.

A different obstruction applies to an oblivious fixed-chart portfolio, meaning its j=0 patterns are chosen without looking at the source clause incidence (even if all other choices depend on it). For even n>=6 choose any balanced source word w, and let F_w contain every distinct-position triple mixed under w. All balanced choices have the same m. A valid coloring's larger color class has >=3 vertices and must be contained in a single w-color class (otherwise contains a mixed triple of F_w). As that w-class has n/2 vertices, the larger class has exactly n/2 and equals it. Thus F_w has exactly w and its complement. At least binom(n,n/2)/2 distinct fixed j=0 patterns modulo complement are required to guarantee one common witness across these sources. Any polynomial oblivious portfolio misses some SAT instance, even with dense encoded input N=poly(n). This does not apply to source-aware chart discovery, adaptive hybrids, general affine charts, or arbitrary algorithms.

Discard a mode if any B_i empty; singleton B_i pins X_i, doubleton leaves X_i free. This is exact: q_ij=X_i xor s_j.
