## 3. Fixed-side acyclic chart contains all canonical lifts (NEW, PROVED)

Retained wire owners (including wire attachments) have all three bits flipped together between y and any canonical source lift, since each wire's terminal values are opposite and determine template orientation. Hence both opposite pairs of every retained B wire owner remain opposite in every canonical lift. Internal filler owners have fixed words, so both opposite pairs likewise remain valid. Attachments have fixed private opposite pair regardless of old value. External owners all lie in A, none in B. These choices are available from y alone and are not claimed necessary for all ordinary models.

The selected graph maximum degree two, edges alternate partition colors on cycles; any cycle contains a non-completion-attachment edge because each private filler vertex belongs to at most one completion attachment and all selected attachment edges join private vertices. At such an owner switch to its other anchor-opposite pair. New pair shares one endpoint and uses the third vertex, which cannot belong to any existing cycle: it is missing a selected edge of this owner color. Thus opening a cycle cannot create a new cycle and preserves ALL canonical lifts. ## 4. Circulation interpretation (NEW, PROVED)
At B anchor y, the difference to its complement toggles every variable arc and every quota arc. Every clause node has two residual arcs in, two out (one quota, three variables). Pair the selected opposite variable arcs through that node; pair the leftover variable arc with the quota arc (opposite residual directions). At hub connect the quota endpoints along each selected-graph path. More explicitly, the nonhub transitions form directed paths from the hub back to the hub, each containing exactly the variables of one path component: two variables sharing a chosen pair are consecutive at their common clause node. Since the selected graph is acyclic no closed nonhub transition component occurs. A path cannot revisit a clause node: its selected pair can only occur once, and its unselected occurrence/quota transition is a path endpoint; if the same clause were both an internal transition and endpoint (or both endpoints), split at that repeated node, preserving directed closed walks and arc-disjointness. We therefore obtain arc-disjoint directed CLOSED WALKS (not necessarily simple directed cycles), each hub-to-hub, with no repeated arcs and with quota endpoints. They partition all residual arcs. Toggling an entire walk preserves conservation and unit bounds; their subsets independently feasible. If a walk repeats a node, its simple-cycle decomposition can be acquired in linear time but its pieces must share the same phase to preserve this chart. In fact a path may revisit a clause node via its other pairing, so do not assume that each component is one simple cycle. Exactly n'/3 independent WALK BATCHES; their variable projections are precisely C_B. This is a fixed supplied partition of B residual arcs into legal batches, with no unknown target. All canonical source lifts correspond to subsets. The same NP-completeness holds for the fixed-batch joint acquisition model allowing such batches; we do not claim it for arbitrary simple-cycle decompositions or a requirement of one simple cycle per side.
