## 3. Guarded colored frontier lemma (PROVED)
Let D be any explicit support DAG with each owner R(v; a,b) or singleton support, possibly multiple owners centered at v. Let P0 be the supplied coordinate pins. Fix a topological order v1,...,vn. At layer i keep a set P of colored pending vertices in the unprocessed suffix, at most one color per vertex. A state has a realizable prefix certificate: each explicitly assigned processed center has at least one selected same-color successor per centered owner, either already processed or required by P. Processed centers without explicit values are unpinned, unmarked, and have at most one centered owner; no selected edge from an explicitly assigned earlier vertex requires them. They can be assigned later in reverse order. All prefix pins were honored. Future explicit pins are separate fixed constraints, injected when reached.

Run sound local truth-table domain closure to fixed point on all suffix owners, the future original pins, and P. Each removed value lacks a local supporting tuple, so rejection is sound. At most 2n value removals; O(N^2) crude bound per closure (constant-size local truth tables). Recompute at every retained state, initially and after deductions before further choices. Domain deductions are conditional on P and original guards, not exported. No full semantic closure assumed.

Process v_i:
- If unmarked/unpinned and centers at most one owner, defer it; remove no obligation on any future variable. Any suffix solution extends by copying one successor (or arbitrary color if no owner).
- Otherwise assign the marked/pinned color, or both alternatives for an unmarked multi-owner center; honor closure domains. Remove v_i from pending. Select at least one successor of the chosen color for every centered owner, and mark that successor. Reject opposite requirements or conflicts with local closure.
- Canonicalize the successor pending map; retain one parent pointer for each distinct map. At a common cut P subset Q as colored literal sets implies P dominates Q for existential decision, not counting or full witness enumeration. Any Q-suffix solution extends the retained P-prefix, irrespective of discarded prefix assignments.
This is exact by induction: every actual solution has a sequence of compatible choices, or is replaced by another solution on a weaker dominated prefix; every accepted empty terminal state has a valid explicit prefix. Fill all deferred vertices in reverse topological order. Every deferred vertex has <=1 owner and was not selected as support by an earlier explicit center; its reverse assignment cannot invalidate a previously selected support. Verify all original owners and pins, then chart/NAE/circulation/source lift. No target used in acquisition.

## 4. Bounded frontier transitions without a hidden 2^degree factor (PROVED)
Fix cap k on pending cardinality. At a marked center with assigned color c, skip any owner already supported by a pending successor of color c. Find an uncovered owner; branch on at most two available successors, insert a new colored pending vertex, then repeat. Each branch inserts a previously absent vertex; no branch removes a pending vertex during this local transition. A branch exceeding cap is recorded as overflow and stopped. Thus depth <= k+1 and <=2^(k+1) branch leaves per center/color even for arbitrarily many owners, with polynomial scans per node. A solution inducing a within-cap transition has a successor set containing one available member of every uncovered owner; following these choices produces a subset of that set. Dominance can only weaken pending requirements; a future capped sequence for Q can be followed from P subset Q using the same colors/choices where needed and deferring extra single-owner centers if unmarked. Therefore the cap algorithm is exact for existence of a within-cap witness sequence (may return UNKNOWN on negative within-cap tests). Return SAT only after full witness verification, UNSAT only if all states exhausted AND no overflow, else UNKNOWN. An overflow can be irrelevant but cannot justify UNSAT.

There are at most S_k=sum_{j=0}^k binom(n,j)2^j distinct maps per layer; naive dominance O(S_k^2 poly(N)) and generation O(S_k 2^(k+1) poly(N)) including closure, sorting, checking all failed choices and reconstruction. Total deterministic time N^{O(k+1)}; storing all parent layers has peak O(n S_k poly(N)) bits, cumulative memory <=(T+1)S on this same serial realization. No big integer arithmetic beyond bounded counters and indices, no free oracle or isomorphism. This is XP in k, not FPT; k constant yields polynomial, k=O(log N) yields quasipolynomial bound. A stronger structural bound uses topological vertex separation: every pending vertex lies in future neighborhood of processed prefix, so k<=max such boundary size for a supplied order. Uniform cap test can decline; exact within a known bound. The original 2-root single-owner DAG case is better solved by A5's flow algorithm.

Uniform uncapped width bound B = p + sum_{v:d(v)>=2} d(v) <= p+2h, where p=#distinct pinned coordinates, h=sum_v max(d(v)-1,0). Each unmarked pinned center creates at most one new token (charge one for pin and d-1 for multi obligations), each already marked single-owner propagates at most one, multi-owner creates at most d(v) new tokens even when unmarked. Bound holds with future pins injected, including pins on sinks. Hence exact polynomial terminal for constant p+h, without needing to enumerate complete topologies. Can use min(B,n) as cap. It is a polynomial algorithm on a stated subclass, not on the NP-hard DS17 image universally.

## 5. Strong limitations on the exact source spine (PROVED)
A. The raw DS17/A4 signed skeleton has all three selectors as predecessors of every pair X_i,Y_i. At the first selector in ANY topological order, the n pairwise-disjoint obligations R(s_j;X_i,Y_i) need at least n distinct pending successors. In the two-opposite-selector guard, local single-coordinate domain closure gives neither X_i nor Y_i a forced bit: the selector pair enforces X_i != Y_i but either marginal is possible locally. On satisfiable cyclic tripartite NAE4 sources with n=3p, there are at least 2^p extendible choices (fix two groups opposite, third arbitrary). For the raw first-selector step, all 2^n selected-support maps have equal size n and are incomparable under literal-subset dominance; at least 2^p are extendible even under exact semantic filtering. Thus neither constant explicit pending width nor a universally polynomial table of all such literal maps follows from fixed selector count or from local closure. This is not a decision lower bound: an easy SAT family, parity quotient and symbolic factorization can bypass it. In particular an affine closure infers X_i != Y_i under opposite selectors and can remove selector owners; that changes the representation, so the raw-width obstruction does not apply to every sound preprocessing pipeline. After that substitution the remaining signed source NAE constraints retain NP-hardness; no claim of irreducibility.
B. Even a DAG with one owner per center and all pins at sources is NP-complete if there are unbounded pins. For each original NAE(a,b,c), create private s,t,u,v with pins s=1,t=0; constraints R(s;a,u), R(u;b,c), R(t;a,v), R(v;b,c). First pair projects to a OR b OR c, second to not(a AND b AND c). This is exact: if a has target color choose u/v to copy either b or c; otherwise choose target color and require b or c to have it. Every NAE source witness lifts independently; all feasible auxiliary words project. All owners have a unique center, the DAG has longest directed path at most two, each private pinned root has indegree zero, and original source sinks have indegree <=8 because four partitions and two support occurrences per source owner. Explicit O(n+m) objects, polynomial input validation, NP membership and witness lift. Thus bounded center surplus alone cannot justify a universal algorithm after arbitrary pin-generating closure. This is auxiliary pinned DAG hardness, not a claim that this new graph itself satisfies the original positive four-perfect-partition promise. DS17 already establishes genuine compiled hardness. No unrestricted lower bound.
