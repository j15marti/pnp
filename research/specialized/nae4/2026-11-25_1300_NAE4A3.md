## 2. Opposing-pair path charts (PROVED)
For two selected perfect partitions P,Q choose exactly one unordered pair of distinct variables in each owner, enforce x_u XOR x_v=1 on that pair. This is a sufficient chart, not an unconditional source deduction. Keep actual owner IDs. Each variable has at most two selected edges, at most one of each partition color. Graph is a simple disjoint union of paths (isolated vertices included) and even cycles: at any cycle vertex the colors alternate. Each chart is a nonempty affine family and every word satisfies P,Q. Conversely every feasible side word belongs to at least one chart (each NAE triple has two opposing pairs).

Allow a nonempty list L_i of permitted pairs per owner. If a selected cycle contains a flexible owner with another permitted pair, switch that owner's pair. The new pair shares one endpoint with the removed edge, and its third variable is outside the entire cycle: that vertex is unused at this owner and has selected degree <=1, whereas each cycle vertex has degree 2. Removing the old edge opens the cycle into a path; inserting the alternative joins that path to a different path or singleton, so cannot create a cycle. Each switch strictly reduces cycle count. Choose any allowed edge initially, repeatedly open flexible cycles; at most n switches, polynomial scan/DFS. Remaining cycles consist entirely of singleton-list edges; they are forced cycles of the mandatory-edge subgraph, present in every chart. Hence achieved cycle count c is the exact minimum over all allowed charts, computable without enumerating charts. Since selected edges number 2n/3, number of independent path/cycle phases equals n/3+c.

Corollary 1: unguarded side admits a uniformly discoverable acyclic chart of exactly n/3 independent binary phase variables. More strongly, EACH actual feasible side word x lies in some acyclic chart: restrict L_i to its two opposing pairs then apply the construction. Thus these charts give an exact existential cover, not a claim of polynomial many charts. This is a one-third reduction for both sides separately, not a universal full-source polynomial decision bound.

Corollary 2: for two supplied feasible words x,z on a side, each L_i consists of their common opposing pairs and has size 1 or 2. Both words belong to every such chart. The exact minimum number of cycles of a chart containing both equals the number of cycles in the graph of unique common pairs. Hence exact minimal phase dimension n/3+c(x,z). This uses the target z only for analysis or lift; cannot assume it in production. The same works for any nonempty lists, including externally certified pair restrictions; empty list rejects that chart guard, not source UNSAT unless restriction entailed.

## 3. A single-hole exchange theorem (PROVED, target-supplied)
For ANY two acyclic charts S,T on identical owner set obeying permitted lists, there is a sequence of forests each missing at most one owner edge from S to T, all edges in S union T, with <=m target-edge insertions, <=m hole openings, m=2n/3. Never remove an edge already equal to its target edge. Proof: open a hole at any owner with differing edge. If target edge of hole connects distinct current components, insert and close hole. Otherwise insertion would form unique cycle C in forest plus that edge. Since target forest acyclic, C contains a current edge not in T. Atomically replace that differing edge by the target edge of the hole, transferring the hole to its owner. Forest preserved, target-agreement count strictly rises. Continue until hole closed, then repeat. <=m insertions. Atomic transfer is a two-edge update (delete then add may transiently store two holes; compared states have <=1 hole, no claim of one primitive edge edit). If both charts contain a common anchor, all intermediate selected pairs remain compatible with anchor; holes are relaxed obligations and cannot be treated as original SAT. Final restoration checks every owner. BFS path and owner-ID lookup suffice, O(m(n+m)) word operations with straightforward adjacency rebuilding, polynomial bit cost. This is reconfiguration with supplied target, not target-free discovery. A short path in an implicitly exponential chart graph does not give polynomial search; no monotone progress relative to unknown target asserted.

## 4. Comparing two sides (PROVED)
For fixed acyclic charts on A=(P,Q), B=(R,S), choose one root bit per component, known per-vertex phase offsets. Every original coordinate v gives one binary synchronization equation between A-component(v) and B-component(v). There are n edges on 2n/3 phase nodes (parallel edges retain actual IDs). Gaussian/parity union-find or ordinary bipartite signed-graph propagation gives exact common chart feasibility and reconstructs actual source word. Coordinate guards imposed on component roots; incompatible guards reject chart only. Reverify all original owners, quotas, and actual guard. If charts contain supplied anchors x,y, use each anchor as offset; RHS of synchronization edge v is x_v XOR y_v. For one mismatch d, all labels zero except d, so feasibility iff edge d is a bridge in this comparison multigraph: every cycle must have even label XOR. Bridge discovery linear in graph size. No branch through phase values necessary.

Even if no anchor-compatible acyclic chart pair exists, unrestricted acyclic charts still cover every actual common witness by Corollary 1, with arbitrary offsets; comparison uses general parity instead of the single-edge bridge criterion. For anchor-compatible target z, Corollary 2 gives exact cycle necessity c_A(x,z)+c_B(y,z). Universal existence of a common target with both c=0 for genuine one-mismatch/one-blocker geometry is OPEN; even proving it would not provide polynomial acquisition. ## 5. Exact coordinate closure for two-partition side (PROVED)
Under arbitrary consistent coordinate pins (not arbitrary affine or quota guards), perform NAE unit propagation: two pinned equal bits force third opposite; all equal conflict. If no conflict at fixed point, skip owners already containing opposite pinned bits; each remaining owner has >=2 free variables. Select any pair of free variables there and enforce them opposite. This selected graph has degree <=2, cycle edges alternate the two partition labels, hence all cycles even. Color alternately. All protected owners satisfied; flip EVERY unpinned bit to get a second feasible word, because each chosen pair remains opposite and already satisfied owners retain their pins. Thus UP is complete for guarded side feasibility AND for all forced individual coordinates: no free coordinate can be forced, with two explicit witnesses showing opposite values. No flow computation needed. A queue of owners gives O(n) word operations; audit uses repeated scans (O(n^2)), source IDs and bits paid. Does not assert complete quota/parity closure, arbitrary signed constraints or three partitions.

Exact two-CNF envelope: for each free v and b, run side UP under actual guard plus v=b. Contradiction gives unit forbidding b; otherwise every forced u gives implication (v=b => u=value). By above exactness these are ALL valid unary/binary clauses over free coordinates (a binary forbidden word is exactly a failed pin then forced coordinate). O(n) UP probes and O(n^2) rows suffice. Union across all six pairs is a sound 2-CNF relaxation of source, not exact generally. Run whole-source UP initially, after deductions; acquire envelope, SCC test, probe 2-CNF for forced coordinates and reclose. At stagnation probe both values of each coordinate in full source UP, take common forced values or opposite of failed branch; reclose on strict deductions. All guards explicit. Try deterministic 2-CNF witness, verify source; if not valid, test omitted owner redundancy via both monochromatic pin queries, return UNKNOWN if relaxation nonexact. 2-CNF infeasibility is sound UNSAT. At most n strict coordinate increases.

New universal stagnation barrier for raw unguarded linear four-partition instance: normalize one variable r=0 by complement symmetry. For ANY pair side, a second coordinate pin can force at most the third variable of the unique owner shared by r and that coordinate, and only when both pins equal. By linearity every other owner shares at most one vertex with that owner, so no further propagation. If no shared owner no forces. Thus exact pairwise envelope of all six sides under this guard contains exactly the four positive binary clauses (a OR b) from the four owners containing r, up to tautologies and already-fixed r. No additional nontrivial binary constraints on free coordinates. Same argument for full-source single-coordinate UP probes, which cannot force any unconditional free coordinate. Every free coordinate has both values in the binary envelope; all free=1 satisfies envelope but violates every owner not containing r (there is at least one in nonempty genuine geometry, n>=9). Therefore this root closure never proves UNSAT or exposes new forced coordinates, even though it is exact on each side for unary/binary information. It may happen to find a verified witness, or higher-order algorithms can add information; no general lower bound. This complements A2's full affine-hull stagnation and establishes a reason to pursue correlations beyond binary envelopes, rather than repeat side-only coordinate probing.
