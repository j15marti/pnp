## A. Exact guarded Hall-core localization
Let live owners forbid one of the four affine-value pairs of two independent homogeneous forms. On a normalized chart V=GF(2)^d (dual), P_i=span(a_i,b_i), U_S=sum_{i in S} P_i and r(S)=dim U_S. Assume the unguarded family J is rank-Hall: r(S)>=|S| for all S subset J. Every owner is a disjunction of three possible affine equalities (any two suffice) whose homogeneous rows are the three nonzero members of P_i. Rado's theorem gives an independent representative per owner, so the unguarded family is SAT for all signs. The representative choice is obtained by ordinary partition/linear matroid intersection, and Gaussian elimination supplies a witness.

For a nonzero target row h and target sign t, impose h*z=t. Quotient ranks are r_h(S)=r(S)-[h in U_S]. The only deficient sets are precisely tight sets S (r(S)=|S|) containing h in U_S. Tight sets are closed under union and intersection, by submodularity and Hall; moreover U_(S intersect T)=U_S intersect U_T for tight S,T (dimension equality). Thus deficient sets have a unique smallest member C_h, if any. Find it with at most |J|+1 ordinary matroid intersection calls on quotient vectors: test for any deficient subset by whether a full independent transversal exists; greedily delete an owner while that failure persists. If no deficient set, solve either guard sign by an independent quotient transversal plus the guard. If C_h exists, enumerate or solve the guarded owners C_h in r(C_h)-1 effective coordinates. For any outside subset X, rank(U_X+U_C)-rank(U_C) >= |X| by tightness and Hall. Rado therefore supplies independent representatives modulo U_C for every outside owner. Every satisfying core word lifts, retaining all its U_C observations including the guard, via Gaussian elimination. Exact both labels, no synthetic hull word, no sign-dependent rank oracle. Costs polynomial for discovery and lift, O(2^max(0,|C_h|-1) poly(N)) for core enumeration; no supplied decomposition. This is a target-specific admitted terminal, not an all-input P algorithm. Hall is tested by matroid intersection. If a chart is not admitted, return UNKNOWN, not NO.

Corollary: acquire an actual complete affine witness basis of rank-Hall family by start witness and repeat testing opposite values of a basis of the annihilator of current witness differences. Each successful target adds rank; if all fail the hull is exact. At most O(d^2) guard calls; polynomial if each required C_h has O(log N) owners (or another exact polynomial solver). Rank slack >=1 for all nonempty subsets implies all guards SAT and complete ambient hull, no nonlinear-degree claim. For multiple target equations, rank decreases by at most their rank, but uniqueness of positive-deficiency-one core does not automatically transfer to arbitrary deficiency.

Strict deficiency-one transfer (RT39): root I has |I|=d+1, rank d, all proper subsets rank-Hall. Delete i, J=I\{i} tight. Every nonzero h in P_i has C_h. For independent h,k in P_i, C_h union C_k is tight and contains P_i. If proper subset of J, adjoining i violates Hall on a proper root subset. Therefore C_h union C_k=J for any two distinct directions; the three complements are pairwise disjoint. This identity localizes overlap, but cannot give universal geometric shrink. Explicit UNSAT example on 3-bit integers: forbidden lines {0,1},{2,4},{3,6},{5,7}. Planes given by (a,b,forbidden values): (2,4,0,0),(1,6,0,1),(2,5,1,1),(1,4,1,1). Distinct planes imply any pair rank3, any triple rank3. All twelve C_h equal the three-owner J. The four forbidden lines partition the cube. This falsifies universal immediate proper-core contraction, not polynomial aggregate via other terminals. Brouwer 1986 theorem/lemma imply for any minimal UNSAT affine-flat cover I, r(I)<=|I|-1, and proper nonempty S satisfies |S|-r(S)<=|I|-r(I)-1. This validates a necessary strict deficiency geometry for arbitrary minimal covers but does not bound their size or global deficiency.

## B. Degree-preserving source compilation obstruction
Use existing disjoint matching compiler: for each source clause with truth literals l1,l2,l3, private selectors s1,s2,s3 satisfy XOR=1, private copies o_i=l_i, and each binary clause (not s_i OR o_i). Polynomial source construction, membership, projection and existential lift: any legal selector activates a true literal, any source model selects a true occurrence. Not count preserving. Distinct private endpoints make matching. No DET-SYNC assumption.

Define a degree-2 polynomial substitution over GF(2):
o_i=l_i; s1=l1; s2=(1+l1)l2; s3=(1+l1)(1+l2). The parity equation becomes identically zero as a formal polynomial, the first two clause falsifiers s_i(1+o_i) become Boolean-axiom multiples, and the third becomes exactly the original clause falsifier (1+l1)(1+l2)(1+l3). Source variables unchanged. Target Boolean axioms map to polynomials derivable at degree <=4: for s=uv, s^2+s=v^2(u^2+u)+u(v^2+v). Source l and 1+l Boolean axioms equal the original variable Boolean axiom. Every degree-D ordinary polynomial-calculus proof on target maps to a degree <=max(4,2D) proof on source: linear combinations commute; replace multiplication by one variable by multiplication by its degree<=2 image, expand monomials and sum. All intermediate degrees <=2D for nonzero multiplication steps. Thus any source 3-CNF family requiring degree Omega(n) over GF(2) yields matching-layer target families requiring Omega(n) degree; target variables n+6m, linear for m=O(n). Alekhnovich–Razborov 2003 and later Miksa–Nordstrom framework establish the requisite random 3-CNF lower bound. This is a scoped impossibility for universal fixed-degree PC closure, not P != NP. No inference that arbitrary Gaussian reparameterization, matroid/flow, semantic deductions or extensions can be simulated by bounded-degree PC absent proof. Pang arXiv:2610.00837v1 (2026-09-30), Remark 1.2 and Corollary 1.3 claim exponential DAG size for constant-degree polynomial clauses given linear PC degree; if valid, apply directly to the target affine-unit and binary polynomial-clause axioms. Conditional on external preprint correctness and faithful compilation of a given solver to that proof system; not independently reviewed. Beame–Sun SAT2026 Xorcle provides an actual related affine-resolution CDCL algorithm and proof logging, not universal discovery.
