## Theorem A: deterministic acquisition of actual monomial bases for 2-CNF
Let B be any explicit ordinary 2-CNF, including genuine coordinate pins as unit clauses. First solve by SCC; an inconsistent B has certified empty model set. Otherwise acquire an actual model a, and write x=a+z over GF(2). The transformed B' admits z=0, so after deleting tautologies and simplifying repeated literals every clause is either a negative unit, an implication z_i -> z_j, or a negative pair not(z_i AND z_j). Each model is an implication-closed set with no forbidden singleton or pair.
For any set S of variables let C(S) be its reachability closure in the positive implication graph, including S. A model containing S exists iff C(S) contains no forbidden singleton/pair. If so C(S) is itself a legal word, and is the unique smallest such word. This remains true under supplied pins because the anchor satisfies the guarded B and the transformation retains all clauses.
Take ANY explicit family M of squarefree monomials z^S (include S=empty if the constant is wanted). For each monomial discard impossible closure (its evaluation column identically zero), and identify equal feasible closures (identical columns). Let Q be the distinct feasible closures. Evaluate monomials on the actual words a+1_C for C in Q. After identifying duplicate columns and ordering Q by increasing size, the matrix has entry 1 iff C_j subseteq C_i, and is lower triangular with ones on the diagonal. Thus the retained actual words span the complete evaluation space of those monomials, with rank |Q|. Proof of equality: every evaluation vector lies in the subspace defined by discarded zero columns and equality of duplicate columns; this subspace has dimension |Q| and the actual triangular minor attains it. All closure discovery, checks, bit comparisons, duplicate detection and witness verification polynomial in encoded input plus explicit monomial family length. Deterministic identity test for any GF(2) sparse polynomial expressed in anchor-relative monomials: evaluate at these actual words. No general circuit PIT claimed; expanding arbitrary products or changing anchor for sparse high degree can cost exponentially many monomials and must be charged.
For M all subsets of size <=d, |M|=sum binom(n,j), generate combinations directly (not a full 2^n loop); the feature span is complete also in x coordinates since affine coordinate translation acts invertibly on degree<=d multilinear polynomials. Actual basis acquisition therefore costs n^{O(d)} poly(N). This resolves AB01's witness acquisition for a pure ordinary 2-CNF relaxation with fixed number d of omitted affine rows or OR obligations: the product of their true affine indicators (choose one satisfied literal per omitted OR at any actual extension) is degree <=d. If any extension exists, some actual chart word restores all obligations. Evaluate full source on each actual word. For NAE deletion a satisfied unequal pair supplies its true affine literal, as in AB01. If affine rank r is small, Gaussian row reduction preserves solution set and d=r suffices, so decision/lift n^{O(r)} poly(N), polynomial for fixed r. This is not FPT and is not polynomial for logarithmic r in general. General mixed deletion chart is not pure B; cannot silently drop remaining affine equations.
Target-only forced-information consumer: add a real pin to B, recompute guarded anchor and basis, test original omitted constraints. In admitted fixed-r scope every coordinate probe is exact; successful contradiction forces opposite bit, reclose with guard provenance, and verify source. At most n accepted pins, O(n^2) probes even if restarted. Initial exact probes, after deductions, at stagnation are charged. A certified empty target is UNSAT; an incomplete capped computation is UNKNOWN.

## Theorem B: genuine matching layer syndrome trellis, arbitrary total affine rank
Partition variables into disjoint binary clause blocks and free singletons; incorporate any actual coordinate pins into allowed local assignments. Let a_j be columns of A; at cut i between blocks, U_i is the span of processed columns, V_i span of remaining columns. For a prefix define syndrome s=A_prefix x_prefix. For completion one needs s in U_i intersect (b+V_i). This is empty or an affine coset of U_i intersect V_i; at most 2^{w_i} states, w_i=dim(U_i)+dim(V_i)-dim(U_i+V_i). Discover these ranks, suffix echelon bases and the width w=max_i w_i in polynomial bit work for an explicit chosen block order. Start with syndrome zero. For each of at most four legal local assignments in each block, XOR its column contribution, discard states with b+s not in V_i via Gaussian membership, and retain one actual prefix per resulting syndrome. Prefixes with equal syndrome have EXACTLY the same suffix feasibility because B and coordinate pins have no crossing block edges and affine rows depend on the prefix only through its syndrome. Induction gives all extendible-in-linear-relaxation actual prefix syndromes (may not be extendible in B). At final cut accept b iff reachable. Retained prefix is a complete witness; verify all rows, clauses, guards. No counting asserted. No need to enumerate the whole suffix span or any affine coset.
Time and peak space <=poly(N)(1+2^w) with full bit arithmetic, prefix storage and linear search or sorted dictionaries charged. For conservative serial implementation using sorting O(log state count) comparisons and copying actual O(N) bit prefixes, both T,S <= O(N^8)(1+2^w); CM <=(T+1)S. Prefix/suffix Gaussian preprocessing and width calculations paid; invalid encodings and inconsistent affine rows handled. For prescribed polynomial state cap, stop on overflow with UNKNOWN; each attempt, including failed work, polynomial. Can try a polynomial number of deterministic block orders under a fixed cap; OR for independent successful tracks, exact UNSAT if any complete decision track returns UNSAT, otherwise UNKNOWN. Discovery of a universally good order remains OPEN. Unlike total rank, w can be zero or one for rank growing linearly. In particular genuine disjoint matching plus r independent affine rows is solvable in 2^r poly(N), polynomial at r=O(log N); more broadly any supplied or acquired order of width O(log N) suffices even at arbitrary rank. This is a concrete arbitrary-rank transfer ONLY within an exact matching-block representation. Applying exact guarded pin queries to this terminal does not increase w (pin restricts local options rather than adds a row), hence full coordinate forced-information closure with paid O(n^2) tests preserves the same admission. For pure matching relaxation with a fixed number of restored affine/Boolean obligations, local monomial basis theorem A also applies. DA21 direct-sum indicator span is different: here we maintain joint exact syndromes, not individual packet indicator sums.

## Barrier: copy contraction is not a free low-rank transfer
For any k-partite graph with nonempty color classes, introduce a Boolean selector for each vertex. Forbid selecting any two in the same class or any nonadjacent cross-class pair with negative 2-CNF. Impose one odd parity row per class. Exactly one vertex must be selected in every class; a legal word is exactly a multicolored k-clique. Rows independent, rank k; compilation and both maps polynomial. Therefore an f(r)poly(N) algorithm for arbitrary ordinary 2-CNF plus affine rows of rank r would give an FPT algorithm for k-Clique (via k colored copies); standard W[1]-hardness consequence, not unconditional P!=NP or unconditional time lower bound. In the matching promise, private copies of every binary endpoint are joined to its original selector by affine equalities, with unique lift; this preserves NP-completeness and decision but may add linearly many independent rows. After contracting these equalities, the residual affine rank is k, but clause graph is no longer a matching; the above hardness applies to that residual-rank parameter. Thus the genuine matching trellis's FPT rank bound cannot simply be transferred after arbitrary equality contraction while keeping the same independence assumption. Conversely no obstruction to other low-width or source-aware algorithms is implied. Simple two-variable control B=(not x or not y), x=y=1: full first-degree hull but empty joint target, although each individual pin is feasible before the other. Degree two acquisition resolves this; affine span alone does not.
