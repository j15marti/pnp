## A. Model and exact compilation
Input is n explicitly indexed Boolean coordinates, a consistent or inconsistent affine guard G: Ax=b, and m indexed affine rejection systems E_i: A_i x=b_i over F2. Every row and source identity is explicit, N includes their encoded length and coordinates; unused variables may be compacted for decision but exact count/witness size must be charged. A legal point belongs to G and to NONE of the E_i. Arbitrary CNF compiles by taking the unique conjunction of falsifying literal assignments for each clause; tautologies yield empty events, empty clauses yield whole G. Signed singleton-exclusion tetrahedral edge (u,v,s) compiles as two affine equations x_u+x_v=s; NAE triple as x_u=x_v=x_w (rank two), or the two original owner clauses separately, retaining budget identity. Source evaluation and witness projection are exact in both directions. Nonaffine masks may be compiled only from actual explicit rejection guards, with their acquisition and size charged. No general E4/B4 physical transfer or unacquired relation is assumed.

For an affine system H, Gaussian elimination gives C(H)=0 if inconsistent, else 2^(n-rank H). Integer lengths are O(n+log m). Let M=C(G), c_i=C(G intersect E_i), c_ij=C(G intersect E_i intersect E_j). Treat M=0 as exact UNSAT.

Local forced closure: if c_i=M reject; if c_i=M/2>0 the restriction of E_i to G is a nonempty affine hyperplane, choose one independent defining row a.x=b and impose a.x=1-b, which exactly removes that event. If 0<c_i<M/2, its complement has more than M/2 points and spans G, so that single constraint entails no new affine equation. If c_i=0 ignore that event. Recompute closure until no rank increase, at most n strict insertions; guard every insertion by its actual context. This is complete for individual-event affine consequences, NOT complete semantic closure of their conjunction. Executed before terminal discovery, after each deduction and each witness pin; other portfolio closure channels are not implemented in this run.

## B. Tree coverage theorem (PROVED)
For any tree T on event indices define K_T(x)=sum_i 1[E_i](x)-sum_{ij in T} 1[E_i intersect E_j](x). This equals the number of connected components of the induced tree on the violated events at x. Empty active set yields zero. Hence
  1[union E_i](x) <= K_T(x),
  U_T=sum_i c_i-sum_{ij in T} c_ij >= |G intersect union E_i|.
This is the classical Hunter spanning-tree union bound in count units (not a novelty claim for the inequality). Compute the minimum U_T by a maximum-weight spanning tree with exact weights c_ij, including zero edges. For m=0 or 1 use empty edge set. Lower bound L=sum_i c_i-sum_{i<j} c_ij is ordinary second Bonferroni, may be negative.

**Exactness certificate:** T gives exact coverage iff for every pair i,j and every intermediate vertex k on their T path,
  G intersect E_i intersect E_j subset E_k.
Proof: if the inclusion holds, the active indices at any x form a connected subtree or empty, so K_T is exactly the union indicator. Conversely if an inclusion fails, some x activates i,j but not k, giving >=2 components and strict overcount. Uniform finite counting has no cancellation because the excess is nonnegative at every point. Each inclusion is verified by Gaussian inconsistency of G,E_i,E_j plus the negation of EACH defining equation of E_k (empty intersections vacuous). This is a polynomial check without model enumeration. No appeal to a semantic coverage oracle.

**Discovery completeness in this structural class:** If any exact tree exists, every maximum-weight spanning tree is exact, since all trees are upper bounds and the minimum attains the true count. Thus one maximum tree plus the path test recognizes the existence of an exact tree, not just a supplied certificate. When no exact tree exists, the method declines exact counting; U_T may nevertheless certify SAT. The number of legal assignments when exact is M-U_T, so both labels are decidable. If L=M, UNSAT even without exact tree. If U_T<M, SAT even without exact tree. If neither and no exact tree, UNKNOWN; never certify UNSAT from an upper bound >=M.

## C. Guarded deterministic witness and complete affine facts (PROVED)
For any fixed tree define the credit D(H)=C(H)-U_T(H) on a subguard H. It is additive under disjoint affine slices, even if negative. If D(H)>0, at least one slice of any next coordinate pin has positive credit. Choose such a slice by exact Gaussian counts. Reapply rank-one closure: removing points that violate a known E_i preserves positivity, because each removed point contributes 1-K_T(x)<=0. Repeat for at most n coordinates; at a singleton positive credit forces K_T=0, an actual legal point. Check every original constraint and guard. This is deterministic conditional expectation (integer count form). A numeric certificate at the parent does NOT certify every child; only the chosen branch carries the positive credit. No branch-specific deductions leak.

If T is exact on G, it remains exact on EVERY affine subguard by the same path inclusions. This gives exact arbitrary joint linear probes, decision, count, and witness without increasing the number of event pairs, even if high original syndrome rank. For complete affine hull, get anchor a, maintain witnessed difference span W. Test a basis of W-perp with opposite affine equalities; if SAT, lift a new independent direction and repeat; if all UNSAT, W is the exact direction space. At most n rounds of n probes plus reconstruction, using the same T, all polynomial; this backend is proved, not executed as a full hull implementation. General dominance alone does not give every probe; if M>2U_T then legal set spans G, but otherwise do not infer hull completeness. Exact joint probes here do not solve I10 arbitrary higher-rank matching unless its residual is independently compiled into this eligible explicit event domain.

## D. Strict improvement over first-order dominance: infinite both-label example (PROVED)
Let g=2^k, k>=1, with k selector bits choosing j=0..g-1, and disjoint private bit pairs (u_j,v_j). Define three rejection events for each j:
  selector=j AND u_j=0;
  selector=j AND v_j=0;
  selector=j AND u_j+v_j=0.
All events have rank k+1>=2, so no single-event affine closure fires at root. Within a group any pair intersects exactly the common zero pair; across groups intersections are empty. Connect each group by any tree, then connect the groups with zero-weight edges. Path criterion holds, so optimum tree exact. Every selected pair has at least one of u=0,v=0,u+v=0, so the root UNSAT. Removing any one event yields SAT: selector must choose that group, its private pair has exactly one allowed assignment, and every other pair is arbitrary. Thus legal fraction =1/(4g). There are n=k+2g coordinates, 3g events, global observation rank n; explicit size polynomial in g.

The first-order bound sum_i c_i/M=3/2 on root, 3/2-1/(2g)>=1 on every neighbor. It cannot prove SAT on any such neighbor, whereas our exact tree returns count 2^(n-k-2) and a witness in polynomial time. This is not a hardness example and does not require low global rank, sparse independent guards, or exponentially many guard contexts. Test arbitrary affine cross-group probe on small scales; exactness is hereditary by proof.

## E. Simultaneous structural failure on DO04's raw high-girth graph families (PROVED)
Consider a simple triangle-free signed graph on n tetrahedral vertices with m>=6 edges, no pins; events are equalities x_u+x_v=s_e, with full Q=F2^2 ambient. Each event has M/4 points, any distinct two have M/16 because their two distinct incidence vectors are independent over F2. Thus all spanning trees have U_T/M=(3m+1)/16>1, and Bonferroni L/M=m(9-m)/32<=5/8<1. No rank-one closure fires.

Every tree on m>=3 event indices has a nonadjacent pair. In a triangle-free simple graph no third distinct edge incidence row belongs to the span of that pair: their sum would be a third edge only if they form a triangle. Therefore the intersection of the pair does not imply any intermediate edge equation, independently of signing. Exact path criterion fails on every tree. Both labels of DO04, including the single-edge SAT neighbors once sufficiently large, defeat this new terminal at the raw unpinned root. This extends the simultaneous *restricted* obstruction list, NOT a lower bound against a solver, arbitrary transformed representations or future paid closure. Even Fano and K5 controls show UNKNOWN despite correct independent reference labels; dispatch them to other terminals rather than infer hardness. Three independent codim-two events are a separate counterexample to exact-tree universality with SAT certified by strict dominance.

## F. Resource ledger and diagonal proof spine
All counts by exact Gaussian elimination. At most m(m-1)/2 intersections, O(m^2 log m) comparisons, O(m^2 * total defining rows) path implications, each polynomial. For one witness, at most n pins; closure <=n strict rank insertions per call, O(m) event tests per pass, per-row rank-one witness discovery paid; fixed-tree counts use O(m) intersections. All integer values have O(n+log m) bits. A deliberately loose deterministic bound for a supplied explicit source including complete hull probes when eligible is O(N^10) bit time and O(N^4) peak bits; stream query systems and witness reconstruction. These exponents are conservative analytical bounds, not measured wall-clock performance. CM <=(T+1)S on that same execution. Canonicalization may use explicit row-reduced guard plus original event IDs; equality of keys is checked exactly, no hash-only merging. Fixed-tree reuse does not give free per-guard counts; charge them anew, or reuse only identical fully authenticated queries. Rejected eligibility and lower/upper calculations are polynomial. No source acquisition outside explicit domain, physical compiler or complete joint matching implementation is hidden in the bound.

Within this eligible terminal, reserve polynomially many elementary count/path/closure/reconstruction jobs (e.g. a sufficiently large fixed polynomial cap). A monotone job counter is a valid c=1 aggregate credit for the actual deterministic execution. In the exact-tree case the n-coordinate witness construction selects one feasible child; in the dominance case it selects one positive-credit child. No recursive sum over all affine slices is required. This is an actual paid terminal, not a claim that counting unknown source rows is polynomial. For general branching, a fixed positive integer potential with root polynomial in N and sum_i mu(child)^c <= mu(parent)^c-1 bounds all occurrence nodes by mu(root)^c; shared DAG nodes can only reduce repeated work if their equivalence, guard, access and reconstruction are paid. A polynomial per-node bound and polynomial encoded state size are separate indispensable premises.

Fix a uniform exact portfolio A with a fair bounded-overhead scheduler for certified root terminals and a complete fallback, and assume no polynomial bound for A. For every j choose F_j of increasing encoded length with T_A(F_j)>|F_j|^j (finite lengths cannot witness failure for all constants; increase exponent/constant as necessary). For any fixed finite collection of truly accessible polynomial terminal domains, all sufficiently late F_j must lie outside their union; include polynomial acquisition, certificate discovery and scheduling cost in the exponent. This is not a simultaneous obstruction over every algorithm, and does not guarantee both labels on the sequence for a particular A. If a fixed exact A has a polynomial bound on all inputs of one label, a clocked simulation returning the other label on timeout gives a polynomial decision algorithm (distinct from a bound on A's own runtime). Do not infer both-label diagonal hardness from mere A failure.
