## Theorem DS17
The language of genuine positive linear 3-uniform four-perfect-partition instances with a fixed pairing (0,3)|(1,2), supplied feasible side words x,y differing on exactly one actual variable d=0, and exactly one minority blocker at d on each side, asking whether there is a common feasible word, is NP-complete by a uniform many-one reduction. Equivalently for this input, existence of a strict S21 monotone batch is NP-complete (S21 cycle lemma). The promise is efficiently checkable; define invalid encodings as negative. No external guards, fixed graph hardness, or unrestricted time lower bound asserted.

Proof:
1. Start with NP-complete positive NAE-3SAT (Darmann–Döcker–Dorn). For each variable use X_i,Y_i, introduce selectors s0,s1,s2. Add the exceptional positive NAE(s0,s1,s2) FIRST; for every i,j add signed NAE(not s_j,X_i,Y_i). Add signed NAE(not Y_a,X_b,X_c) for each original owner (a,b,c). These are BH15's R constraints. Under the exceptional owner the selectors have both values, so X_i != Y_i; the last signed clauses then equal the source. Any source model lifts with complementary reps and nonconstant selector bits. All-zero underlying word violates exactly the exceptional owner. This is a polynomial signed near-model, not a solver.
2. Replace each literal occurrence by a distinct positive terminal (its literal value); all external owners have color 0. For consecutive occurrences of a variable use an inequality wire if their signs differ and two inequality wires with one private intermediate if their signs agree. Assign wire colors alternately 1,2 along the full path. Use I23's exact inequality gadget: nine-point affine plane minus two parallel lines (0,3,6),(1,4,7), followed by attachments (a,0,3),(b,1,4) in missing color, all other colors cyclically relabeled. Every model has the missing lines monochromatic and opposite: monochromatic pair count at least 16, while if six points shared a bit it would be at least 18; the remaining ten owners legal implies exactly 16. Attachments force a != b and each orientation lifts by the explicit G word 010010011 or its complement. Each occurrence terminal uses one external color0 and at most two distinct wire colors; intermediate uses two wire colors. Each wire has private nine vertices and fresh pairs. Distinct external triples are disjoint. Thus linear partial partitions, and signed consistency and both SAT directions follow along paths. The near-word lifts as literal signs, with only owner 0 bad. Since owner 0 comes first, its first occurrence d=0 of s0 is a path endpoint (s0 occurs in other owners for n>=1). It has one wire color1; colors2,3 missing. Pad 0–2 isolated bits to reach a multiple of three. Explicit size O(n+m).
3. Apply DS16 transparent completion independently for each missing color: paired 21-vertex templates with opposite fixed bits at each attachment. All added owners legal for either value of each old bit; exact projection. Let y be the completed near-word and x=y xor e_d. Only color0 owner containing d was bad; its color3 partner is transparent, hence x is feasible for A=(0,3). y is feasible for B=(1,2). Exactly one minority blocker at d on A (the repaired owner) and on B (the wire attachment with two equal private bits), and neither transparent partner blocks. Both S21 circulation flows are explicit: each unit variable arc equals its bit, each quota arc is the sum of its three bits, in [1,2]; total in/out hub balances by counting each variable once. Thus x,y have exactly one mismatch, no search. Common feasibility iff completed NAE SAT iff signed near-registry SAT iff old source SAT. Decode via occurrence paths and verify, or lift a model via the explicit constant templates. NP membership by common-word verification. At one mismatch a strict S21 improvement is exactly a common endpoint; given a common word S21 computes a batch in polynomial time. Neither a fixed-d two-stage mask nor a polynomial acquisition algorithm is assumed.

This strengthens DS16 and is different from MS23's target-negative known-SAT result. The compiled ordinary source has either label. Hence skipping optional repair in favor of direct decision avoids the additional target problem but not the underlying NP-complete joint feasibility. No assertion that a particular family evades all terminals, no P!=NP implication, and no claim of solving P=NP.
