## DS08-A: exact local-syndrome tree contraction (PROVED)
Input m authenticated independent local word blocks y_i in F2^{a_i}, with legal sets R_i and explicit matrices P_i. Decide whether y_i in R_i for all i and XOR_i P_i y_i=t. All shared constraints must be represented by these equations; any nonaffine correlations must remain as local factors with synchronized copies. The uniform leaf contract is a deterministic paid procedure that, for any explicit affine constraint B y_i=b, decides whether R_i intersects that fiber and returns a witness or exact NO. Its worst-case time/space is polynomial in total explicit input length N on the claimed domain. Arbitrary compact circuits do NOT meet this contract automatically.

First run paid closure. Check global linear consistency. For each block, its globally linearly extendable local words are those with t+P_i y_i in span(P_other). This is an affine constraint via a quotient basis. Query local feasibility, and both values of any active local coordinate; if one impossible, the other is forced for EVERY globally legal tuple. Reject if both impossible; pin by removing its column and substituting the value into t and the local predicate. Reclose after each pin and at stagnation before any source branching. The local oracle is called polynomially many times (at most sum a_i strict coordinate pins; each pass polynomial). This is restricted certified closure, not complete global semantic closure. Explicit-domain pruning against the same unchanged affine chart is also valid. No conditional pin is detached from its guard. Every pin shrinks column spans, so cannot increase cut intersection ranks on a fixed tree. Witness choices made later are conditional, not forced.

At stagnation, solve the unconstrained linear equation for a baseline y^0, not necessarily legal. Set b_i=P_i y_i^0. For a rooted full binary tree on the m block IDs, write U_J=sum_{i in J} im P_i, I_J=U_J intersect U_outside, k_J=dim I_J. A legal global tuple has shifted partial syndrome s_J=XOR_{i in J}(P_i y_i+b_i) in I_J because the total shifted syndrome is zero. Store Boolean support T_J subset I_J, with one local lift or child-pair backpointer per retained value.

Leaf i: enumerate the 2^k_i words of I_i by Gaussian basis, query the leaf oracle on P_i y_i=b_i+s, store witness iff YES. No enumeration of the full block image, private assignments, or global syndrome space is required. If the leaf domain is explicitly listed, scanning it and filtering against the outside span is an equivalent implementation.
Join L,R: for each retained pair (s_L,s_R), retain s_L+s_R iff it belongs to I_J. Since it is already in U_J, outside-span membership suffices. Deduplicate exact vectors; store one generating pair. At root I=0; SAT iff 0 retained.
Proof: inductively, T_J contains exactly the shifted partial syndromes attained by legal local words in J that are linearly extendable outside. For completeness, suppose an attained parent value lies in I_J. Each child partial value belongs to the child's outside span because it equals the parent value plus the other child's partial value; it also belongs to its own span. Thus outside filtering cannot discard the needed child entries. For soundness, retained child witnesses involve disjoint block IDs, so their concatenation has precisely the joined syndrome. No shared physical variable is independently assigned without its equality rows. Backtracking the root yields actual local words; reinsert pins, reverse DR08 or other authenticated existential projections, then verify all original source rows. This is Boolean existential composition, NOT generally physical model counting. A counting semiring may count local tuples when multiplicity is intended; auxiliary cut-label choices would overcount selector assignments, so do not use that semiring for GD14.

## DS08-B: exact guarded nonreachability adapter and hybrid rank (PROVED)
GD14/DA08: optional directed arc e=(u,v) enabled iff y_e=h_e, with joint protected syndrome XOR P_e y_e=t. Nonreachability iff there exist cut labels c_s=1,c_t=0 such that no enabled arc goes from label 1 to label 0. Necessity choose the actual reachable set; sufficiency any putative path crosses the cut. Give each arc local copies of its endpoint labels, synchronize all copies of a vertex with a chain of binary equalities, and keep terminal pins. Local relation accepts all y_e unless the cut crosses the arc, in which case y_e != h_e; mandatory crossing forbidden. Leaf oracle: enumerate at most four endpoint labels; for each solve the requested affine system by Gaussian elimination; on a disabled arc reject a singleton forbidden fiber, otherwise pick an actual word distinct from h_e. Arbitrarily wide local observation blocks are allowed. No free global reachability identity. The P columns and copy-equality columns are separate syndrome coordinate blocks. For any tree cut J, the equality-copy block for a vertex with q occurrences has q columns with exactly one dependence (sum all columns zero), for q>=2, and rank q-1. A cut splitting the copies therefore contributes exactly one dimension of intersection; a nonsplit vertex contributes zero. Direct sums give k_J = lambda_P(J)+b(J) before terminal pins, where lambda_P(J)=rank P_J+rank P_out-rank P and b(J) is the number of vertices with incidences on both sides. Removing pinned label columns can only decrease width; terminal pins may be handled first. This treats topology and algebra on the SAME tree, rather than independently optimizing incompatible decompositions. DA08-B charged global delta and graph width; DS08 can instead charge the maximum joint cut rank, even if global delta is linear.

If P describes exact dependencies of a common affine observation chart with local coefficient spaces W_i of dimensions a_i, then lambda_P(J)=dim(sum_J W_i intersect sum_out W_i). Proof: let A be the stacked full-column chart map after dropping invisible free directions; rank A=R, ker P=im A. Kernel of P_J is the part of im A supported on J, dimension R-R_out. Thus rank P_J=sum_J a_i-R+R_out; add the analogous complement formula and subtract rank P=sum_i a_i-R to obtain R_J+R_out-R. The identity is valid before pins or after recomputing a correct chart. Hence GD13/DO08 raw observation-width theory is relevant to DS08, but the added cut labels cannot be erased. It is not a claim that low separate optimum widths guarantee one low joint tree.
