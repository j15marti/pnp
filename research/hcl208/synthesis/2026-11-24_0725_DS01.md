## 1. Source and signed cycle model (exact)
An explicit signed NAE-3 formula F has n variables, m clauses (three indexed incidences per clause, repeats permitted). Write z_v=(-1)^x_v, introduce private hub spin y_e and w_a=(-1)^s_a omega with omega^2=-1/3. For each clause, summing prod_a(1+w_a z_v y_e) over the two hub spins gives 2(1-(1/3)sum_{i<j} signed_z_i signed_z_j). This is 0 for monochromatic literals and 8/3 otherwise. For a subset P of original variables let M(P)=sum_{x models F} prod_{v in P} z_v. Expanding the products and summing spins yields
M(P)=2^(n-2m) 3^m E_P(G,w), where E_P=sum_{Y: boundary(Y)=P} prod_{a in Y} w_a.
All hub boundaries are zero. This holds with isolated variables, parallel incidence edges and repeated signed literals. No numerical approximation is needed.

## 2. New paid boundary acquisition lemma (PROVED restricted)
Find a spanning forest and use leaf elimination to obtain a T-join J with boundary J=P, or certify that a component has odd P parity and E_P=0. Every Y with boundary P is uniquely J symmetric-difference X for an even subgraph X. Because every w_a is nonzero, set w'_a=1/w_a on J and w'_a=w_a off J. Then
E_P(G,w)=prod_{a in J} w_a * E_empty(G,w').
This is an exact polynomial-size transformation on the SAME graph, with no extra edges, handles, or nonlocal crossover gadgets. Edge weights remain in Q(sqrt(-3)). For a supplied verified orientable rotation embedding of genus g the classical even-subgraph Pfaffian formula evaluates each moment in 4^g poly(N) bit work. The Fisher expansion and orientation generation have polynomial overhead per character; exact field arithmetic can use rational elimination with bounded minors; input coefficients have constant bit size and the products, sums and Pfaffian values have polynomial bit lengths (including the 4^g sum for g<=O(N)). No assumption of free genus minimization.

For a boundary B and assignment a,
C_B(a)=2^(-|B|) sum_{P subset B} (-1)^(sum_{v in P} a_v) M(P).
This is Fourier inversion of the original model counts and hence a nonnegative integer. The fast Walsh-Hadamard transform gives all entries using O(|B|2^|B|) arithmetic operations. Total time 2^|B| 4^g poly(N), streamed Pfaffian workspace plus 2^|B| poly(N) stored table. Extra guard pins can be included in B and conditioned; count b includes all distinct pinned and shared variables. The algebraic signs can cancel, but C is semantic. Unlike virtual-edge augmentation, the T-join reweighting never increases the original genus.

## 3. Witness lemma (PROVED restricted)
If a pinned region has positive count, reconstruct a real Boolean witness without increasing genus or accumulating one pin for every variable. Pick two distinct variables u,v in a clause. The two corresponding incidences at the degree-three hub are adjacent in cyclic order. Add a temporary u-v edge in the wedge alongside them, then contract the temporary edge (not the original incidence edges). This is an embedded graph operation preserving an embedding of no greater genus; keep all indexed clause ports and allow parallel edges. For each relative value d=0,1 substitute x_v=x_u xor d, flip its literal signs when d=1, transfer and check existing pins, then count. The two cases partition original models; each substitution is bijective on its guarded cell. At least one case is positive. Choose one positive case for witness recovery; this is not counting by single-branch selection. Every contraction removes a variable and does not increase the number of pinned representatives. If no clause contains distinct variables, each satisfiable clause is tautological, so choose remaining unpinned bits freely. Recover contracted bits in reverse and verify the original assignment and pins.

Before each such choice perform unary support probes (one extra temporary pin) and relative probes on clause-local pairs. Record forced unary values with their guard; contract forced pair relations and repeat. If all pairs are two-valued, choose a known-positive case. The unary deductions need not be reinserted as fresh pins because they are already consequences and are checked against the recovered witness. The guard is retained, not promoted to an unconditional assertion about another cell. There are at most n contractions and polynomially many probes per contraction, so total bit work still 2^(b+1)4^g poly(N). All topological updates and source reconstruction are charged. The reference tests below used exact counts by cycle enumeration, not a Pfaffian backend or embedded-graph update implementation; the genus preservation and faster bound are symbolic.

## 4. Mixed semantic tree composition (PROVED restricted)
Let the clauses be partitioned into t regions, each with variable scope V_i. A supplied tree on regions must satisfy running intersection: regions containing any given variable induce a connected subtree. Verify the partition, variable identities, embedding(s), tree and running intersection by scans. Let B_i be the variables shared with other regions plus local guard pins. At a leaf or internal region acquire exact feasible rows indexed by B_i, with a witness algorithm under any feasible pin. The NAE terminal above supplies such rows; I07/S06/DA01 can participate only after their actual source, pin-support and lift hypotheses have been checked and their acquisition paid. Existence of a local decision procedure on unpinned inputs alone is not sufficient.

For each row in a region, check the messages of all children on their exact separator projections. Project supported rows to the parent separator; the root has empty parent separator. This is exact by induction because running intersection prevents private-variable collisions or inconsistent shared assignments. Recover one consistent row at each node and lift each region; verify globally. If all tables are exact counts, multiply child counts and sum over locally feasible rows, accounting once for free variables absent from all regions; if any table is merely feasibility, use Boolean support only and make no counting claim. Table processing is O(sum_i 2^b_i(deg(i)+1)poly(N)), not a Cartesian product. A fixed tree gives each row/message a canonical source/guard key; no semantic-equivalence oracle. On admitted NAE regions we can compute complete unary support on the global guard by filtering shared rows or recomputing one private-variable pin table and rerunning messages, for polynomially many queries; mixed regions must separately justify such probes. This is certified unary closure, not complete semantic closure of all relations.

Bound for all-NAE regions:
T <= poly(N) sum_i 2^(b_i+1) 4^g_i.
S <= poly(N)(1+sum_i 2^b_i) with streamed Pfaffian work.
CM <= T*S (same execution; include encodings, witnesses, messages, topology, arithmetic and discarded calls).
An exact mixed terminal has the analogous sum of actual paid acquisition/lift costs plus row and message processing. Many large cycle ranks and large total regional genus can be harmless. If max_i (b_i+2g_i)=O(log N), t polynomial and decomposition acquisition polynomial, then this is polynomial. No universal availability is asserted. Arbitrary pairwise small overlaps do not imply a join tree; global cyclic joins need separate exact algorithms. A three-variable parity interface gives four parity states per connected region, but semantic spin rows, not individual signed terms, are the safe support objects.

## 5. Counterexample: nonzero signed parity products do not certify SAT
On three variables take four signed NAE clauses with sign masks 0,1,2,4. Their excluded complement pairs partition the Boolean cube. Split the first two from the last two. In little-endian assignment order, the exact regional tables are
L=(0,0,1,1,1,1,0,0), R=(1,1,0,0,0,0,1,1).
Both regions have models but no common boundary row. Their Fourier inner product has two nonzero terms (+16 and -16), so selecting a nonzero signed product as a witness is false. The Fano split has 32 nonzero signed products and zero glued count. Both controls are executed. This falsifies a tempting shortcut in multisign DAG support extraction, not a polynomial decision theorem.

## 6. Exact portfolio and minimal-counterexample ledger
Fix finitely many sound modules, each operating on the same encoded source and guard with a verified interface, returning SAT/UNSAT or UNKNOWN; include a total exhaustive fallback. Dovetail them on the original input with charged polynomial simulation, verification and translation overhead. Before branching use the explicitly implemented sound prepass (e.g. interval/unit or scoped support), repeat it after each accepted deduction and at stagnation; no semantic closure oracle. Independent simulation suffices for a bound; cross-channel deductions may be shared only with exact provenance, guards, and paid replay. Do not silently require a conversion to an unsupported representation. For arbitrary 3SAT, OR(a,b,c) with a common reference bit f=0 becomes NAE4(a,b,c,f); split into NAE(a,b,y) and NAE(c,f,not y). Global complement symmetry permits f=0 in reconstruction. This is a uniform polynomial decision reduction, not a low-genus guarantee. BW01 gives an exact separate wheel representation but does not supply a low-genus decomposition.

If the exact total portfolio A has no uniform polynomial bound, then for every d,K some input takes >K N^d. Since finitely many smaller encoded inputs all halt, choose K large enough to force increasing sizes N_j and T_A(F_j)>N_j^j. For each fixed constituent module, a sound answer within a fixed polynomial would contradict this via the polynomial simulation overhead (for all sufficiently large j). Thus the sequence simultaneously evades fast answers from every fixed module. UNKNOWN is not an expensive computation; time-to-sound-answer for an inapplicable module is infinity. This does not exclude a certificate that exists but is undiscovered, nor any algorithm outside the portfolio.

The sufficient aggregate inequality sum_i mu(child_i)^c <= mu(parent)^c-1 yields a polynomial bound if root mu, intermediate size, discovery, local step cost and reconstruction are uniformly polynomial. DP01 supplies a fixed-count-domain tree credit and a separate canonical-DAG credit, not arbitrary overlapping-branch credit. For the DS01 admitted tree, use a fixed task ledger: acquire each region table, process every row/child check once, write every message once, and pay witness/support probes with a predetermined polynomial-in-N multiplier on the explicit parameter sum. A remaining-task credit decreases per charged operation. This is not a universal structural potential: its root bound is conditional on the discovered certificate. Treat preprocessing and rejected representations as paid portfolio work. A minimal-counterexample induction fails first at the **universal paid discovery/coverage lemma**: for each residual either a sound polynomial terminal is uniformly acquired, or a bounded-credit exact contraction is discovered with full charged representations and branch aggregation. Nothing in DO01/DR01 or the new twist lemma proves this. Raw large parameters are not hardness, and mere existence of small decompositions is not an algorithm.

Falsifiers: (i) nonzero signed term as witness is disproved above; (ii) low genus or low row width of individual regions without running intersection is insufficient; (iii) universal small genus/credit or universally discoverable exact representations remains a conjecture; (iv) uniform portfolio bound cannot follow from a different nonuniform algorithm per input. Relativization: finite-portfolio diagonal argument is black-box and relativizes; NAE geometry is explicit non-black-box but no unrestricted separation or oracle barrier is overcome. DISJ: no unrestricted lower bound; guarded disjoint tree and shared DAG charged separately. DTISP/configuration: same-execution bounds only, no forbidden region crossed. Natural proofs/algebrization: no unrestricted lower bound asserted.
