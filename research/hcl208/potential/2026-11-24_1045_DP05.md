## A. Partition quotient identity (PROVED)
Let explicit nonempty local tag sets R_i lie in V=GF(2)^D; independent choices, exact total XOR b. Any additional keys may be retained only if they are locally fixed or all global key correlations are separately evaluated; the pure syndrome tree terminal below has no omitted joint budgets. Choose anchors a_i, U_i=span(R_i+a_i). For any partition into s groups G_j, put U_j=sum_{i in G_j} U_i and a_j=sum anchors. Let R=dim(sum U_j). If b is in sum(a_j+U_j), the affine tuple set
  C={ (p_j): p_j in a_j+U_j, sum p_j=b }
has cardinality 2^e, e=sum dim U_j-R. Otherwise it is empty.
Let H be the sum of attributed local period subspaces (for protected keys use their common exact periods). Each local period is in U_i. Thus H=sum_j(H intersect U_j); H is contained in sum U_j. Under quotient pi by H, the new tuple set C' is precisely the image of C. Indeed choose local group representatives of a compatible projected tuple. Their sum differs from b by h in H. Decompose h across H intersect U_j and correct group representatives. This is affine tuple lifting, not a claim all affine tuples have actual witnesses. Actual row lifting follows independently from BA04's attributed periods.
Exact dimension drop:
  e-e' = sum_j dim(H intersect U_j) - dim H >= 0.
Proof: dim pi(U_j)=dim U_j-dim(H intersect U_j), and total rank decreases by dim H. The right side is the dimension of the kernel of the sum map from the group intersection spaces to H. It measures repeated repair directions across groups. The identity holds simultaneously for EVERY partition, not only a chosen order, and after every valid cascading period quotient. Empty groups have U=0. Inconsistency is preserved by this quotient. An arbitrary nonattributed quotient need not have this monotonicity. Two-group case gives cut state rank w; three-group case gives BD04 transition rank tau. In particular all fixed tree state/transition volumes are nonincreasing, irrespective of global rank.
Certified row deletion without changing ambient space also cannot increase compatible affine tuple sets, since each factor affine hull can only shrink even if its anchor changes. Closure: delete a row t only if b+t lies outside the sum of all other affine hulls; restart after each strict deletion; empty set rejects; run before quotient, after quotient and at stagnation. These are necessary-condition deductions, not complete semantic closure. A quotient is a decision/witness-preserving operation, not a certificate that discarded original row IDs were unsupported.

## C. Guard extension: positive one-stage bound (PROVED)
Append q observation bits f_i(t)=c_i+L_i t, with a fixed linear map L_i for each factor (same map across protected keys if present). Every local period h lifts to (h,L_i h), and every lifted period projects to a base period. Thus the sum of lifted period spaces H' projects ONTO H. Quotient ambient map from (V x GF(2)^q)/H' onto V/H has kernel dimension at most q. Group affine hulls project to the base quotient group hulls. For any s-group compatible tuple, its lifts have differences in that kernel in each component and sum zero, so at most 2^{q(s-1)} lifts. Hence e'_guard <= e'_base + q(s-1) on consistent guards (cut +q, ternary transition +2q). One-stage result, not an assertion for arbitrary later guards after a cascade; recertify every layer. This is complementary to GD10's single-parity matching result. Affinity in ORIGINAL ROW INDICATORS alone is not sufficient for this theorem.
