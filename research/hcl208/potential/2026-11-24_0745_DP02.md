## 2. Triple-cut rank and exact coset convolution
At an internal node partition factors into L,R,C (outside S). Set I=V_L intersect V_R, k=dim I, h=dim(I intersect W_S), w=w_S. For each parent p in C_S, solve a in A_L and p+a in A_R by Gaussian elimination. All decompositions are exactly (a+i,b+i), i in I. Hence raw affine-compatible pair capacity is 2^(w+k). Distinct parent states modulo I number exactly 2^(w-h). The map from a pair of child affine cosets modulo I to parent coset is injective: if a+b and a'+b' differ by i in I, then a+a'=b+b'+i belongs to I, so both child cosets coincide. For each parent coset choose one actual affine candidate p0 and a corresponding decomposition a0+b0=p0. Define f(i)=T_L(a0+i), g(i)=T_R(b0+i), zero for absent rows. For p=p0+j in the same parent coset, T_S(p)=sum_{i in I} f(i)g(j+i). Compute this XOR convolution by three Walsh-Hadamard transforms and componentwise multiplication, exact integer division by 2^k. Only retain entries for C_S. Signed intermediate terms must not be interpreted as witnesses. This computes every needed parent entry, with O((k+1)2^(w-h+k)) arithmetic work after polynomial per-state linear algebra and key overhead. The number of enumerated parent states 2^w is no larger than 2^(w-h+k). Also I lies in each child W, because each child's complement contains the other, so k<=min(w_L,w_R). No enumeration of 2^d is required. Counts and WHT intermediates have polynomial bit length (bounded by products of indexed row counts times powers of 2^d). Compared with direct compatible-pair enumeration, the convolution slot factor is 2^h smaller; arithmetic includes the k+1 overhead. No claim of universal speedup versus all other algorithms.

Witness reconstruction: on a positive parent count solve one affine decomposition; scan I for a pair of positive child counts. A pair must exist by nonnegative exact convolution. Recurse through disjoint children; at a leaf choose an actual indexed row matching its tag, verify source target and all encoded guards. Per join scan <=2^k, paid by the same local slot bound. Retain source IDs and lift descriptions; no witness is selected from a signed Fourier term.
