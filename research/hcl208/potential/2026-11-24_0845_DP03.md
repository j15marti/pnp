## 2. Fixed exact compatibility circuit (PROVED)
For every fixed guarded input F of length N, let M distinct row IDs index explicit finite local candidate universes. A mask z has one Boolean availability bit per row ID. Assume a verified independent factor product with exact global compatibility and lifts; all correlations, identities, guards, costs and protected tags must be encoded. Let G be an explicitly acquired acyclic monotone AND/OR circuit computing J(z), the existence of a compatible tuple from enabled rows, for EVERY mask z, not just one initial mask. Require that each accepting proof tree (one child at OR, all children at AND) yields a compatible tuple and that every compatible tuple has such a proof tree using exactly its row IDs. Constant leaves allowed. For a sufficient construction, AND children have disjoint source factor sets and exact join keys; OR alternatives are same-factor-set compatible alternatives. A hash, same geometry, or equal unprotected cost is not a proof of source equivalence.

For DP02 explicit XOR row products, freeze the initial upper universe after sound affine row-support closure. Let S be a supplied binary factor-tree node, C_S its initial target-conditioned affine cut set and w_S its dimension. Create one OR node per candidate tag p, with a binary AND alternative for each pair (a,b) of child tags satisfying a+b=p. Leaves OR together distinct original row IDs of the same tag. Parent candidates restricted by initial complement affine hull are sound for every submask, since actual completions remain in that initial hull. Induction establishes exactness and tuple lifts for every mask. Enumerating affine-compatible pairs using DP02 linear algebra costs poly(N) times
  M + sum_v [2^w_v + 2^(w_v+k_v)],
where k_v is rank of the intersection of child difference spans. Leaf rows are scanned explicitly. Nodes with empty alternatives are false. This uses raw pair slots, not DP02 WHT slot count; the Fourier circuit has signed arithmetic and is NOT automatically an exact monotone support circuit. Can select either terminal with paid discovery; no claim this circuit is always the cheaper one. For bounded logarithmic cut widths, k_v <= max child widths, hence polynomial circuit construction; finding such a tree is not assumed. Test implementation uses simpler attempted Cartesian child-key pairs and complement-affine filtering, charging all attempts.

## 3. Exact global row support in one augmented circuit (PROVED)
Let f_v(z) be the forward value of node v. Introduce context value b_root=1. In reverse topological order, b_u is OR of all incoming context contributions:
- For parent v an OR node, contribution to child u is b_v.
- For parent v a binary AND node with other child w, contribution is b_v AND f_w.
- A node with no contributions has b_u=0.
For larger ANDs first binarize with linear overhead. Distinct parallel arcs retain incidence multiplicity. All forward nodes precede all context nodes in the combined DAG, and context dependencies are reverse-topological. Size of augmented DAG A including one AND support output s_r=z_r AND b_r per original row is O(|V(G)|+|E(G)|+M).

Claim: s_r(z)=1 iff some globally compatible enabled tuple uses row r. Proof: b_v=1 iff there is a path from root to v whose off-path AND siblings have accepting proof trees. This follows by reverse induction. If f_v=1, choose one proof tree at v and one for each sibling; concatenate along the path, using the same mask throughout. The assembled root proof tree is accepting and contains v. Conversely a root proof tree containing v yields such a path and all required siblings. Apply to row input and use exact tuple/lift hypotheses. A shared child may have many contexts; OR all of them, never count them as independent copies. This argument also works for a semantically authenticated shared circuit with repeated contexts; it does not license inventing one with incompatible caller constraints.

With L subset R subset U, evaluate forward and context circuit on both L and U. J(L)=1 implies SAT with a witnessed tuple, J(U)=0 implies UNSAT. If s_r(U)=0, retire its acquisition as globally irrelevant; this is NOT a certificate of local UNSAT. All future U are subsets, so this retirement is permanent in this fixed phase. If J(U)=1 and a factor has exactly one globally supported row, that row is forced in every true model (if any); more generally common protected features of supported rows are forced. A global forced row need not be locally acquired: it can be the only optimistic option even when the original F is UNSAT. Do not export it as a witnessed lower row. No arbitrary private feature inferred from a projected row. Maintain factor support counts via support-output events, and report only after queue drainage. Upper support pruning preserves J for all remaining monotone submasks; can keep globally unsupported U bits as dormant rather than deleting. Initial affine closure and exact upper global support at initialization, after every acquisition, and at stagnation are paid. Other certified closure channels may be scheduled separately; complete all-channel or semantic closure not assumed. All deductions stay in the fixed guard, not exported unconditionally to a different guard.

## 4. Aggregate amortized potential and sharing (PROVED)
Let A have V gates and E directed incidence arcs (fanout counted by incidences), including context and support gates. Lower bits only increase, upper bits only decrease. Use for each gate a count of true child incidences. When a child's value flips, enqueue its outgoing incidence notifications; on delivery adjust count by +1 or -1 and flip parent exactly when its AND/OR threshold changes. Queue can use any order; after drainage values are exact by DAG induction. Every gate flips at most once per direction, even through shared reconvergent paths, because the entire process is monotone. Every arc notification is delivered at most once per direction. This is a Boolean-support invariant, not an arithmetic count invariant. Counts of true models could change much more often.

Define at quiescent state the positive integer credit (allow zero when no work remains)
  P = #unprocessed row jobs
      + sum_{v: lower(v)=0}(1+outdeg(v))
      + sum_{v: upper(v)=1}(1+outdeg(v)).
Within an event add the number of already reserved pending arc notifications. Resolve/retire a row job at most once, consuming its unit. When a gate flips, transfer its outdegree tokens to its queue and consume its own unit. Deliver one arc by consuming one pending token. Thus each charged primitive decreases P by at least one; initial P <= M+2(V+E). Credit is directly computable by scanning stored bits/degrees, or maintained incrementally. Fixed initialization (both valuations and adjacency construction) is charged separately. A constant polynomial multiplier covers bit/index/queue arithmetic and event processing, including retirement and forced-row detection via changed-factor counters. For DAG fanout, charge every attempted use/arc; a shared gate is not charged anew at every incoming call. In contrast, summing independent child-subtree credits double counts shared descendants; use the union of obligations with arc multiplicities, not the per-child tree inequality. This proves an actual aggregate work bound for a dynamic acquisition sequence rather than just one evaluation. It gives c=1 on the global ledger. It is not a residual-only universal potential. New guards, new circuit stages or nonmonotone changes require new paid credit; no unrestricted credit creation.

Total outer update operations, including all forward/backward support maintenance, are O(M+V+E), after compilation and initial closure. The whole solver costs
  T <= T_compile + T_initial_closure + T_acquisition + T_verify + poly(N+M+V+E) + T_lift.
For polynomial acquired circuit, fixed polynomial source bit lengths, and a bounded number of active acquisition jobs of polynomially bounded execution cost (or DS02 fair scheduling up to a polynomial decisive deadline), this is polynomial. Even if one unresolved row costs exponential time, the outer ledger remains small; that does not pay for the row. Use separate per-job deadline credits for channel steps; fair round robin across polynomial jobs and fixed channels costs O(M K tau) simulated steps up to decisive deadline tau plus simulation/verification overhead. Do not assume tau computable or bounded. When doubling deadlines, preserve the fixed circuit and monotone facts; charge all abandoned and unfinished work. No free whole-portfolio scheduling asserted.

S <= poly(N+M+V+E) plus simultaneous backend states and retained certificates; queue <= E per direction, each counter O(log(E+1)) bits. Witness extraction chooses one positive OR child, both AND children, and actual source lifts, verifying original constraints. On the factor-tree construction at most O(number of factors) selected ANDs, with <=E total child scans; output and source reconstruction charged. For a general shared circuit, avoid exponentially unfolded outputs only with a verified polynomial witness lift; that is a separate hypothesis. CM <= (T+1)S on the same realization, including scheduler memory. No comparison of disjoint realizations or hidden parallel work. Actual program is JS, not a native bit-machine benchmark.

## 5. Counterexample and repair: persistence of BA02 quotient
An upper-only saturation test is NOT persistent under selective acquisition. Let A=B={00,01,10}, target 11 and H=GF2^2. Upper fibers satisfy 3+3>4 and quotient removes H. After acquiring negative rows, A=B={00} may be the actual support. Quotient still reports feasible whereas target 11 is impossible. Thus optimizing once on optimistic masks without a witnessed guarantee is unsound.

Persistent decision repair: for each nonempty projected upper fiber in the two independent factors, lower witnessed fiber counts must satisfy the BA02 strict density inequality for all potentially feasible quotient pairs. Then for every intermediate mask M_i between L_i and U_i, every such nonempty quotient fiber has the witnessed density lower bound. BA02 discrepancy repair proves equivalence of unprojected and projected decisions for all such masks. As lower grows and upper shrinks, the condition persists within the fixed protected guard/cost keys. This is a sound way to reserve a normalized circuit for a fixed acquisition phase. It does not automatically preserve per-original-row support: a repair may change a particular row. Keep original unquotiented support probes or prove a protected row-specific lift before retiring/forcing an original row. This symbolic repair is not executed. Similar caution for exact minimum costs and synchronized duplicates; no counting claim.
