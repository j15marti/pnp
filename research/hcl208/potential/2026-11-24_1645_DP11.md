## A. Exact sensitivity of canonical cores (PROVED)
Use a consistent affine guard G, equation rowspace H, complete protected exterior W. Each distinct owner i forbids E_i={z:A_i z=b_i}; rowspace U_i (actual tagged supplied rows). For Q=H+W define r_Q(J)=dim(Q+sum_{i in J} U_i)-dim Q, D_Q(J)=|J|-r_Q(J), d_Q=max_J D_Q(J), and C_Q the unique least maximizing owner set (DY10/BA10/MS16, supermodularity). Keep source IDs, guard and all external consumers; this is existential decision support, NOT model counting.

1. Owner deletion monotonicity: for R subset of original owners, C_Q(R) subset C_Q(F) intersect R. Write C=C_Q(F), B=C_Q(R). Supermodularity gives D(C intersect B)+D(C union B)>=D(C)+D(B); D(C union B)<=D(C), so intersection attains the restricted maximum. Minimality of B yields inclusion.
2. Guard rowspace monotonicity for UNCHANGED registry: for Q'=Q+P, h=dim Q'-dim Q, D_Q'(J)=D_Q(J)+dim((Q+U_J)/Q intersect Q'/Q). The added term is inclusion-monotone in J and lies in [0,h]. Hence d_Q<=d_Q'<=d_Q+h. If B=C_Q', C=C_Q and C not subset B, D_Q(C)>D_Q(C intersect B) by least-maximality. Supermodularity implies D_Q(C union B)>D_Q(B). Added term is monotone, hence D_Q'(C union B)>D_Q'(B), contradiction. Thus C_Q subset C_Q'. This does not imply monotonicity for physical closure that also removes owners or adds new equations.
3. Matching repair: maximum tagged independent transversal cardinality t=m-d_Q, by Rado (add d_Q independent dummy directions to each owner for sufficiency, and any deficient subset bounds t for necessity). Start from any maximum matching, reproject its rows after h new independent guard rows, retain a maximal independent subset, losing at most h. If additionally deleting a owner IDs, lose at most a more. New optimum <=t (deletion/contraction never increases it); at most h+a successful augmentations plus final failed search recover maximum. Each search may touch the whole registry; no locality claim. For exact least core compute d_Q(F without i) for every owner: i belongs to C iff that deletion strictly lowers d. Warm start each such test from the maximum transversal, discarding at most one row; at most one successful augmentation and one failed search each. This gives an alternative elementary polynomial discovery route; implementation uses cold starts for the core-membership tests. Standard shortest-path exchange for partition/linear matroid intersection on actual supplied rows, Gaussian rank oracles, no enumeration of implicit vectors.

## D. Sharp rank-one core avalanche (PROVED restricted counterexample)
Let n>=4 even, cyclic coordinate rejection events E_i={x_i=0,x_{i+1}=0}, indices modulo n. Parent has m=n, full transversal by selecting x_i, d=0, C empty. Add one observation/guard x_0+x_{n/2}=b, for either b=0 or b=1. The quotient identifies two nonadjacent coordinate rows, yielding two cycles joined at one vertex. Full rank n-1, deficiency one. Any proper owner subset in the quotient graph has at most one cycle per connected component (both cycles require all n edges), so edges<=incident vertices in each component and D<=0. Thus least maximum-deficiency core contains ALL n owners, for BOTH RHS. All individual rejection events remain consistent rank two; affine single-row closure stagnant. Both fibers SAT: all ones for b=0, all ones except x_0 for b=1. A rank-one change causes linear core growth even if deficiency increases by at most one and maximum matching repair loses exactly one row.

Connect this tail to the fused Fano root with one extra owner E={t=0,x_0=0,a=0}, where a is a core coordinate and t fresh. The connector has its own private complement t=1, so does not affect deficiency core (adding it increases rank >=1). Tail and Fano have disjoint row supports without connector. Parent least core size7, children size7+n; after single Fano monochrome-clause relaxation, parent least core empty and children size n. Opposite labels preserved for both guards: original Fano has no coloring; neighbor has one and can extend to tail with t=1. Closure remains stagnant for the original root on the tested guards. For n unbounded, any positive power of owner-core size (even +1) increases across this prescribed rank-one branch; total-size measure with both children of size N-O(1) also violates fixed-c sum contraction if it counts live owners/rank and uses fixed positive powers. This falsifies unconditional small-rank=>small-core-change and an automatic core-size branch reserve, not the existential claim that a better operation/terminal exists.
