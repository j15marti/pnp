## 2. New rank-one local acquisition theorem (PROVED)
Model: independent explicit R_i of one, two, or three distinct tags in GF(2)^D, target total XOR b, all protected XOR observations included in the tag. No omitted integer budgets, no signed counting semantics. A regional repair line H=<h> with h nonzero is certified by testing that every remaining triple has a pair differing by h. For a region with no triple set rank cap r=0. General rank-r eligibility and discovery use BA05 only where its hypotheses apply.

For a triple, designate its singleton a_i outside the h-pair, and a pair endpoint a_i+d_i. Its tags are exactly a_i+s_i d_i+e_i h with e_i<=s_i. For two rows use a_i+s_i d_i; for one row set d_i=0. For a fixed regional target t the XOR is:
  XOR a_i + XOR s_i d_i + (XOR e_i) h = t.
All repairs can be zero, or the total repair can be assigned to just one enabled triple (since every repair has identical h). Therefore exact local SAT is equivalent to the disjunction of:
(A) the affine system XOR s_i d_i=t+XOR a_i, and
(B_i) for each triple i, s_i=1 and XOR s_j d_j + p h=t+XOR a_j, p a free bit.
Each is one Gaussian solve, at most 1+#triples solves total. If (B_i) succeeds, set e_i=p, all others zero; the row lift is actual and immediately checkable. Conversely any satisfying original selection with total repair 1 has an enabled i, so it satisfies B_i; if total repair 0 it satisfies A. This gives a deterministic polynomial acquisition without selector enumeration or a finite-field hitting routine. It works after arbitrary row deletions (remaining triples unchanged; pairs/singletons affine). Appended observations require full tag certification; no budget/count transfer.

Closure: before evaluation and after every strict row deletion, delete t in R_i only when b+t is outside the sum of the other affine hulls; restart after each deletion; an empty table rejects. The implementation applies this globally, then independently under each exact regional demand guard before the local terminal. No semantic closure oracle, no dropping the regional target. The B_i tests are linear systems under their activation equation, not unconditional row deletions or source branching.

## 3. Regional acquisition and paid tree credit (PROVED conditional)
Partition all factor IDs exactly once into regions; each region has an authenticated repair separator of rank <=r_I (or BA05's paid 3^r_I discovery on the explicit rows). Fix an authenticated rooted binary tree whose leaves are regions. For any group I of factors let A_I be the sum of their affine hulls (affine sum). Set A_empty={0}. For any node I with outside O, D_I = A_I intersect (b+A_O). For internal I with children L,R define E_I={(l,r,o) in A_L x A_R x A_O: l+r+o=b}. If global affine inconsistency, reject immediately. Otherwise |D_I|=2^w_I and |E_I|=2^tau_I, exact Gaussian intersection/kernel dimensions. All ranks and their powers are computable in polynomial bit time before enumerating any state; their *numerical values* may be exponential. Generate affine compatible tuples by enumerating a kernel basis of the joint sum map, not by scanning a Cartesian ambient space. Each group basis is independent, so each tuple is generated exactly once.

At a leaf query each t in D_I through the local exact rank-one solver above or BA05 general-r terminal, storing a verified witness on positive answers. At an internal node enumerate E_I. Insert l+r in its table iff both exact child entries l,r exist. Store one pair of child pointers (the executed checker uses actual row-selection arrays, a polynomial factor overhead). Root has D_root={b}. Induction gives exact attainable sums among D_I: any global solution induces compatible tuples; conversely if a parent demand is attainable, its actual child sums are in their D sets because the affine outside can complete the parent. Every retained entry has an actual regional witness; root lifts all original rows. All guards remain in the full tag. No hidden source query or signed-zero inference.

Define the integer job credit
  P(T,F) = sum_nodes |D_I| + sum_internal |E_I|
          + sum_leaves (3^r_I + 4^r_I |D_I|).
The rank cap is part of the fixed certificate; a leaf with no triples can use r_I=0. BA05's discovery and per-target hitting costs are bounded by 3^r_I poly(N), 4^r_I poly(N); rank-one variant has at most N+1 Gaussian tests per target. Every job is paid by a fixed polynomial factor in original explicit N, including rank preprocessing, closure, source authentication, row/guard verification, enumeration, canonical key comparisons and lift. Cap r_I <= ambient dimension; powers have polynomial bit lengths. Total time <= poly(N)(1+P), peak space <= poly(N)(1+P) on the same serial stored-table realization; cumulative memory <= (T+1)S. These are analytical bounds, not measured bit time or memory. If max local r_I and all w_I,tau_I are O(log N), this is a polynomial terminal even if sum r_I is linear or larger. Also it suffices to bound the total P by one fixed polynomial, including decomposition discovery. Supplied tree verification is polynomial; universally finding a good tree is OPEN.

For a fixed certified tree and caps, row deletions only shrink A_I, D_I and E_I. Original <=3-row factors retain separator eligibility after deletion, so P cannot increase; this does not assert arbitrary quotient/guard changes preserve the certificate. Use the full current row masks when evaluating. If P is used as subtree credit, define P_I as the sum of the listed jobs belonging to the subtree, with the globally computed D and E fixed. The child subtrees are disjoint sets of jobs and the parent reserves a positive demand/transition job. Hence sum_children P_child <= P_I-1 (c=1). This is aggregate contraction of the batched evaluation, NOT a claim about arbitrary assignment branches. Within a fixed authenticated registry, each completed job consumes its credit once. Exact shared local query identity includes original region/factor IDs and row masks, target and actual full guard semantics (or a paid certified source bijection), not ranks or statistics. Every attempted transition and every consumer incidence is charged even if a child acquisition is cached. A source-independent exterior may be omitted from the local query key only because its entire contribution is the fixed exact demand.

## 4. Counterexample to weighted pin-branch contraction (PROVED)
Take k independent two-factor regions, each two binary factors {0,e_i}, with independent e_i and total target zero. Each region has actual attainable target 0; all node D and E have size one and every rank cap is zero. Exhaust affine closure first: all rows remain. Pin one row in one region, obtaining two guarded alternatives. Closure pins its partner; the other k-1 regions retain their complete tables. With the original fixed region tree, all D and E remain singleton, and P(F_0)=P(F_1)=P(F). Thus for every c>0, sum P(F_i)^c=2P(F)^c>P(F)^c-1. Even adding a positive factor proportional to total residual row count cannot repair this for a fixed c as k grows: both children retain a fraction tending to one of the parent's total credit. Exact context-aware DAG sharing or direct component solving can avoid the duplicate work; they are legitimate escapes. This is not a counterexample to a potential tailored to a different algorithm. Do not charge an unaffected region twice merely because two branch paths consume its result, and do not assume distinct guarded acquisitions share without checking. There is no unrestricted branch contraction theorem here.

## 5. Disjoint rank-one repairs with tiny exact leaf profiles are NP-complete globally (PROVED)
For an arbitrary 3-CNF with three distinct variable indices per clause, introduce an independent repair coordinate h_j for clause j and an independent occurrence coordinate u_{ji} for each literal occurrence. For every occurrence create a triple {0,u_{ji},u_{ji}+h_j}. Select its literal truth s_{ji} and optional repair e_{ji}<=s_{ji}. For every nonisolated variable x create an affine two-row factor {0, XOR_{occ(x)}u_{ji}}. Put each clause's three triples in one region and each variable factor in its own region. All local repair lines <h_j> are mutually independent, rank one. Set the target to XOR_j h_j + XOR_{negative occurrences}u_{ji}.

Occurrence coordinate compatibility enforces s_{ji}=x_var XOR neg_{ji}. Clause repair requires XOR_i e_{ji}=1, equivalent to at least one true literal. Forward lift: choose any one true literal per clause and give it repair 1. Reverse lift: decode the variable-factor selection and use the forced occurrence relation; every clause has a repair, hence is satisfied. Size polynomial in CNF encoding, all rows explicit. The decision class is in NP by source-row verification; hardness follows from ordinary 3-SAT. For distinct-variable clauses, D_clause has eight actual affine demand candidates, exactly seven realized local profiles. Each variable region has two. Every affine support row survives root closure: choose its requested literal truth through x, and because each clause has at least two occurrences, choose unconstrained affine repair bits at other occurrences to attain total repair one. A variable pin also has an affine completion. This uses the affine hull, not global SAT support in an UNSAT instance. Local acquisitions and certificates are uniformly polynomial; arbitrary global gluing remains NP-complete even without costs or external guards. The result narrows BA05's proposed independent separator composition: disjoint repair directions alone do not discharge selector synchronization. I11's triple hardness is compatible; this adds the regional rank-one and tiny acquired profile guarantees.

## 6. Exact raw rank formula and an all-region-tree actual-state obstruction (PROVED)
For the compiler in section 5, for ANY partition of region IDs into groups, global affine-compatible group sums depend only on the original variable bits x. The h_j total is fixed within its single clause region; each occurrence coordinate is split between its variable factor and clause factor or cancels within one group, leaving only the fixed sign offset. For each variable, its contribution across groups is zero as a direction iff its variable region and ALL occurrence clause regions lie in one group. Otherwise it contributes one independent direction, because the coordinates of distinct variables are disjoint. All x are permitted in the affine relaxation (e bits independent). Hence the exact affine tuple dimension equals the number of variables whose region stars meet more than one group. For a two-group cut this is exactly w, for three groups exactly tau. No source solver needed to compute these dimensions.

For an unconditional all-tree counterexample, take n original variables x_1,...,x_n. For each pair u,v introduce a private y_uv and two clauses enforcing NAE(x_u,x_v,y_uv): the all-positive and all-negative 3-clauses. Every assignment to all original x extends (if equal, choose y opposite; if different, choose either y). This is an easy SAT family; not a complexity lower-bound family. In the compiled system every single row has a real global witness: variables can take either value; for a triple's false row choose its literal false, for the true repair-on row choose it true and repair it, for the true repair-off row choose another true literal within that clause and repair that one. Any prescribed nonmonochromatic local tuple at an edge extends by choosing other y independently. Thus even complete unary support closure removes no row.

In every binary region tree there is an edge splitting original variable-region leaves between n/3 and 2n/3 (weight each original variable leaf one and all others zero; descend into a child of weight >2n/3 until none; then a child has weight between n/3 and 2n/3). If some original variable on each side were unsplit, their pair's positive clause region would have to be on both sides, impossible. Therefore every original variable on at least one side is split, so w>=ceil(n/3). Moreover every assignment to the split original x bits extends to a GLOBAL source solution. Distinct such assignments induce distinct boundary tags by the cut formula. Thus the cut has at least 2^ceil(n/3) ACTUALLY globally supported states, not just affine candidates, in every tree respecting these region leaves. Encoded size is polynomial in n (even dense tags), so raw explicit-state credit is superpolynomial on this family irrespective of tree discovery. A different grouping, NAE pair fusion, symbolic messages, source elimination or other terminal may bypass it. Indeed this source family is easily solved by construction. No unrestricted hardness or actual portfolio time bound follows.
