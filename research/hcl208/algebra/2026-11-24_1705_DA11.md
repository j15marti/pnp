## A. Domain and local theorem (PROVED)
K=GF(2)^2. Let G be any connected simple loopless private graph, with every private vertex incident to at most four exclusions total, including boundary occurrences. Edge uv forbids x_u+x_v=s_uv(z); each boundary occurrence forbids one affine color word at its private endpoint. Signs and boundary words are affine functions of a common explicit selector chart z, under any supplied affine guard. Repeated protected IDs and their actual correlations are preserved. All private lists start full; no hidden observations, quotas, tags, or non-edge private consumers. Fixed topology. Multiple private-private edges, loops, extra nonaffine side constraints and strict global E4/B4 adapters are not presumed.

For each z, boundary exclusions leave a list of size >= private degree. If one vertex has total degree <4, the component is always colorable by a spanning-tree greedy order rooted at that slack vertex. If a private block is neither a clique nor a cycle, the component is always colorable by the DP-degree-colorability theorem (Bernshteyn, Kostochka, Pron, arXiv:1609.00763v1, Theorem 9; simple k=1 case). The DP cover has a matching between lists for each edge (translation restricted to lists), exactly the theorem's hypotheses. This holds for every z independently; no selector enumeration or sign consistency needed. Otherwise every block is a clique K2..K5 or a simple cycle, with arbitrary articulation-sharing. The singleton graph is allowed. We prove constructively that its exact support is an OR of O(|V|) affine events, each of at most eight scalar equations. Thus the same local support theorem holds for ALL connected simple degree-bounded regions in the stated domain (constant true represented by the full chart event).

## B. Affine list complement (new elementary ingredient)
A hypothetical list of t distinct forbidden colors is represented by t affine words, t<=4. Its complement can be represented by 4-t affine words without case splits. t=0: all constants; t=1: add each of the three nonzero constants; t=3: XOR all three words (sum of all four colors is zero); t=4: empty. For t=2, with words a,b and d=a+b nonzero, choose the linear order-three automorphism J(u,v)=(v,u+v), which permutes the three nonzero colors cyclically. Then the complement is exactly {a+Jd,b+Jd}. The offset is neither zero nor d. On a word with duplicated inputs the candidate need not be correct, but a collision escape event has already been emitted. No nonlinear choice of representative is made.

## C. Tight block messages, root at a vertex (PROVED)
Root the block-vertex incidence tree at any vertex. At each nonroot vertex v with parent block B, take the union of actual boundary forbidden colors and forbidden sets from child blocks. The expected total number of occurrences is 4-deg_B(v). At root it is four. For any child block with parent vertex p, its forbidden set F_B(p) consists of colors of p that do not extend through that child subtree, without imposing any other restriction at p. Always |F_B(p)|<=deg_B(p): greedily color B-p with the available lists (>= degree in B), including child completions, then exclude at most one root color per incident edge. Equivalently fix any one coloring of B-p; this exists by slack at a neighbor of p. All subtrees are disjoint except for their actual articulation vertex.

The vertex is tight if all child blocks are tight and all expected forbidden occurrences are distinct. If not, its available list has strict surplus relative to deg_B(v). Any such surplus makes every color of the parent p feasible through B: after fixing p, remove at most one color from each neighbor, retain the surplus in B-p, which is connected, and apply spanning-tree greedy coloring. Thus any descendant escape propagates a strict deficit in the forbidden message all the way to the root, which then has a legal color.

On the no-escape chart, complement the candidate forbidden list by B above to get a tight affine list L_v of size deg_B(v). For child block B at p choose any neighbor t of p and set candidate F=L_t+s_pt. Any color outside F extends, since its forbidden image misses L_t, leaving a surplus at t in B-p. Therefore the block's actual forbidden set is contained in F. It equals F precisely when B has no coloring with the artificial list L_p=F. If this test fails the message is strictly smaller, i.e. an escape. Hypothetical candidate F can still be used upstream, because the earlier escape already guarantees support. This removes the old requirement that blocks be vertex-disjoint and linked by single bridges.

Local full-list rejection tests:
* Clique K_r, lists size r-1: rejection iff signs gauge to zero and the gauge-transformed lists are equal. Gauge root incident edges to zero. If no coloring, pin any root list color c. Every other vertex must lose an available color or residual clique admits greedy slack coloring. Hence all transformed lists are the same set L. Each edge not incident to root must preserve every L minus {c}: if a translation fails, choose a color at one endpoint whose forbidden image misses the opposite endpoint's list, color other vertices next, and opposite endpoint last. Since intersection of these punctured sets except the one omitting a given element singles out that element (or directly for r=3), any translation preserving them all fixes a color, hence is zero. K2 is immediate by its singleton lists. Conversely equal lists of size r-1 forbid a proper r-clique coloring. This covers K5, which can only be a whole degree-four component.
* Cycle of length l, two-element lists: rejection iff translated lists align on every edge and XOR of edge signs = (1+(l mod 2))d, where d is the nonzero difference of the two colors in one list. If an edge translation does not align lists, start coloring at its first endpoint with a color whose forbidden image misses the last endpoint's list, walk the other way around the cycle and color last with slack. Otherwise all directions coincide, each legal step is translation by s_e+d, and cycle consistency is exactly zero XOR of those steps. Alignment forces total sign in {0,d}; its nonzero complement is the stated rejection condition.

For each vertex emit all pair collisions between expected forbidden words. For each block emit escape events for failure of the corresponding local rejection test. Failure of equality between two same-size lists of at most four affine words is the union over a in the first list of a not belonging to the second. For each such a, enumerate nonzero values for at most four differences a+b; each term has <=8 scalar affine equations and <=3^4 alternatives per a. Gauge or holonomy mismatch is at most three affine events, each two equations. Degenerate direction zero can also be emitted as a single event. Number of local word operations/events is O(|V|), since maximum degree is four; long cycles use one affine XOR and constant-size per-edge checks. Root has no remaining available colors iff every expected forbidden occurrence is distinct and every block is tight. Hence exact support g(z)=OR_j [E_j(z)], with O(|V|) events of rank <=8. This is an exact existential support statement, not count preservation. It extends DA10 and BW10 to overlapping articulation blocks, including two cycles sharing a single degree-four vertex, and to arbitrary simple private components using the structural theorem in A.

## D. Paid reconstruction, closure and syndrome tradeoff (PROVED)
Discover actual connected components and biconnected blocks with graph search; verify scope, signs, all boundary IDs, degrees and absence of hidden consumers. For a fixed accepted z, one can reconstruct via self-reduction: try four colors at any private vertex, turn its incident constraints into fixed boundary exclusions, and reapply the same decision theorem to all remaining components. At most four choices per vertex; each residual remains a simple degree-at-most-four region with full unpinned lists and boundary exclusions. This includes nonbrick components, so constructive witness acquisition does not rely on an unimplemented DP-coloring search oracle. For brick graphs, constant-color block tables and cycle path DP provide a faster alternative.

For a supplied affine guard Q, all feasible words are the union of Q intersect E_j. Gaussian elimination provides exact local feasibility and witnesses without exterior enumeration. The full affine hull is obtained from each nonempty event's representative and nullspace basis, plus differences of representatives. Certified necessary affine equations are valid only within Q and the actual retained constraints; reapply closure after every deduction and at stagnation before any branch. No global complete semantic closure is claimed.

In coordinates of Q, let W be the full exterior observation rowspace and U_j the RREF rowspace of a nonempty consistent event E_j. Its image under the exterior map is exactly an affine event with equation rowspace corresponding to U_j intersect W; derive its RHS from any point in E_j, then Gaussian-lift every accepted exterior word. Let e_j=dim(U_j intersect W), delta_j=rank(U_j)-e_j. In contrast to DA10's single rejection event, this is a POSITIVE escape: any consistent E_j with e_j=0 certifies universal deletion of the whole component. Every projected event has e_j<=8 even if W is huge. If all e_j<=1, universal deletion is decidable by one Gaussian consistency test on the complements of the projected hyperplanes (zero-rank event accepts all; no events accepts none). If all e_j<=2 and RT16's common-coordinate criterion is certified, coverage reduces to exact 2SAT of the complements; recertify under new guards. More generally a supplied h-dimensional control yielding these properties on every fiber gives 2^h poly(N) paid coverage, not free discovery of a backdoor. These tradeoffs concern actual postprojection observations, not raw width or an intrinsic unrestricted complexity invariant. Symbolic, not executed beyond coordinate-guard closure.

A complementary cross-region certificate: if each region has an available consistent rank-one escape event on Q with independent rows modulo W, their conjunction has a Gaussian lift on every exterior fiber. A full transversal is discoverable by partition/linear matroid intersection on actual event rows (dual polarity of BD10). Regions with an escape of rank zero may first be deleted. The certificate applies only with disjoint private regions and a common actual selector chart; failure is UNKNOWN. No independence claim for arbitrary rank-eight event selection.
