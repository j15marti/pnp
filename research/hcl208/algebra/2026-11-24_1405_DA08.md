## 2. DA08-A: W[1]-hardness of GD14's general FPT target (PROVED)
Input a k-partite graph G with classes V_i, each size >=2 (duplicate each vertex as a twin if needed, without adding same-class edges). Create two copies L,R of all vertices. Directed graph has source s, sink t, optional s->L_v and R_v->t arcs, mandatory L_u->R_v exactly if u,v are incompatible: different vertices of the same class, or different classes lacking the source edge. No other arcs. Each optional guard is enabled iff its bit is 1. Protect independent odd-parity equations XOR_{v in V_i} y_{L,v}=1 and XOR_{v in V_i} y_{R,v}=1, for all i. Explicit free chart obtained by replacing the final bit of each group by 1 XOR the others. The chart is surjective on each bit, all optional guards rank one, M=2|V|, R=M-2k, delta=2k. Each of 2k disjoint dependency components has nullity 1. All paths have length exactly 3.
GD14 closure: no mandatory s-t path, no one optional arc with mandatory arcs suffices, every optional guard can hold or fail. Since the within-class incompatibility arcs exist, the all-possible graph has a path. Hence this closure stagnates with no forced pin (apart from the empty-class-free trivial k=0 case); stronger nonlinear closure not claimed stagnant.
If G has a multicolored clique choose precisely its k vertices in each copy. Both parities hold, no incompatible pair is selected, so t unreachable. Conversely any safe word has nonempty selected sets in BOTH copies of every class. Any selected left/right pair within the same class must be identical. Thus both selected sets are the same singleton per class; cross-class compatibility forces a multicolored clique. Both directions reconstruct in polynomial time; in fact every safe word has exactly delta enabled optional arcs.
Construction time/size polynomial in |G| (O(|V|^2) arcs, explicit affine chart polynomial). Parameterized many-one reduction delta=2k. Multicolored Clique is W[1]-complete by standard clique copying. Hence FPT in delta for arbitrary affine-guarded nonreachability would imply FPT=W[1], even on depth-three DAGs with rank-one guards, disjoint parity equations, component nullity one. No separation assumed; no ETH dependence. This is a conditional parameterized-complexity barrier, not an unconditional runtime lower bound. In the broader depth-three disjoint parity-group conflict subclass (groups may differ on the two sides), safe selections can be reduced to one per group by deleting all other selected vertices; odd parities remain. Make a multipartite compatibility graph, one class per group, all same-side interclass pairs allowed and cross-side nonconflicts allowed. A clique is equivalent to a safe word. Thus this subclass is W[1]-complete in number of groups.
Physical directed graph can have high treewidth; bounded degree can be obtained with mandatory binary fanout and fanin trees (and source/sink distribution), maintaining exact directed reachability and optional registry, but not depth three simultaneously. No undirected parity transfer: simply forgetting arc orientation creates extra paths through unselected intermediate vertices. Duplicating an optional arc's guard as many separate observations may increase delta. Both are forbidden uncharged transfers.

## 3. DA08-B: joint cut-width/dependency terminal (PROVED)
For arbitrary GD14 directed graph after the certified closure, write optional guard e as local independent observations y_e with unique enabling word h_e. Let P be an explicit dependency matrix on concatenated local words, Py=0 iff jointly realizable in the common affine chart. Nonreachability is equivalent to existence of a Boolean cut label c with c_s=1,c_t=0 and no enabled edge going from 1 to 0. Necessity take the reachable set; sufficiency follow any putative path. For each optional arc, the allowed syndrome contributions are P_e(all words) if it does not cross from 1 to 0, otherwise P_e(all words except h_e). The latter equals the whole image if ker P_e nontrivial, otherwise the image minus P_e h_e. Gaussian elimination and at most 2^delta values give exact lists and actual local word lifts. Mandatory crossing disallowed.
Given a validated width-w tree decomposition of the underlying graph, make a nice decomposition with each edge processed once and terminal labels checked where introduced. Table entries are (bag labels, accumulated delta-bit syndrome), Boolean existence. Introduce vertex extends label; forget existentially removes it; introduce edge filters allowed labels and XORs an allowed syndrome; join combines equal bag labels and XORs child syndromes, counting each edge once. Root requires syndrome zero and empty bag. Induction proves exactness. Backpointers choose local words, Gaussian lift returns a common selector, and actual graph traversal verifies. The dependency rows are global; no independence assumption across the join.
T<=2^{O(w+delta)} poly(N), S<=2^{O(w+delta)} poly(N), CM<=(T+1)S, same serial realization. More explicit given a nice decomposition with B nodes: <=B*2^{w+1}*4^delta poly(N) attempted table operations including incompatible pairs, <=B*2^{w+1+delta} poly(N) stored entries/backpointers. Include all discovery, preprocessing, source verification, row/rank computations, guard charts, canonicalization, failed transitions, reconstruction. Standard deterministic 5-approximation to treewidth (Bodlaender et al., SIAM J Comput 45(2) 2016, DOI 10.1137/130947374, arXiv:1304.6321) either certifies tw>k or returns width<=5k+4 in 2^{O(k)}n; try increasing k up to cap, validate returned decomposition. Hence true w+delta=O(log N) supplies a polynomial terminal with discovery paid, not just a guessed small decomposition. ## 4. DA08-C: FPT in delta alone for authentic two-bit signed difference geometry (PROVED)
This is the constructive distinction that prevents DA08-A from being misused against the physical research route.
Input a signed graph with colors (a_v,b_v) in F2^2, forbidden edge difference (p_e,1+q_e); equivalently if a_u+a_v=p_e then b_u+b_v=q_e. The first-bit words are explicitly affine in a common free selector z: a_v=A_v z+c_v, with any consistent affine first-bit guard already substituted. No constraints on second bits except the signed edge exclusions; no unverified budget/occupancy tags or mixed a/b guard. Graph degree arbitrary, includes four-valent subclass. This is DA06's exact conditional parity model, now arbitrary q, not one frustrated edge only.
Closure: compute each first-bit difference observation row. Drop rank-zero impossible activation; mandatory rank-zero true edges impose parity equations on b, checked by parity union-find (or Gaussian). Inconsistent mandatory parity rejects. Contract mandatory components keeping parity offsets on every vertex. All A_v in such a component are equal because every mandatory edge has zero coefficient row; thus every intra-component optional difference would have zero row and was already handled. Keep all original first-bit expressions and parity offsets, and original edges for verification. After any additional certified affine pin, reparameterize and restart; no complete semantic closure presumed. In this restricted explicit chart the rank-zero/mandatory parity closure suffices for this theorem. At stagnation use the terminal, not generic source branching.
Let H be the resulting undirected optional multigraph, m edges, n vertices, c components. Each optional edge observation y_e=(A_u+A_v)z has rank one and h_e=p_e+c_u+c_v (use correct original constants on its endpoints). Adjust q_e by contracted parity offsets. Write incidence matrix B over F2, vertex observation matrix A, edge rows BA. Hence
rank(BA)<=rank(B)=n-c,
delta=m-rank(BA)>=m-n+c=beta(H).
This is an unconditional geometry-specific structural tradeoff. It survives arbitrary affine first-bit guards and mandatory contraction, but not arbitrary compiled guard registries.
Construct spanning forest; for every nonforest edge choose one endpoint, obtaining a feedback vertex set K of size f<=beta<=delta. H-K is a forest, including multiedges accounted for. Thus tw(H)<=f+1<=delta+1, with actual decomposition cheaply discoverable.
Direct terminal: enumerate 2^f assignments to second bits on K (conditional labels only, never assert as unconditional). On remaining forest, bottom-up tables indexed by root b bit and delta-bit syndrome. Each edge contributes 0 or P_e according to observation bit y_e; if b parity matches its adjusted q, both observations allowed; otherwise only disabled y_e=1+h_e allowed. Edges touching fixed vertices use their fixed labels; edges with two fixed endpoints processed once outside trees. Merge child tables by XOR, combine components by XOR, retain target zero. Recover b labels, y bits and actual common z by Gaussian; lift all mandatory offsets and verify every original edge and guard. The forest DP invariant gives iff exact feasibility. No arbitrary directed cut or full coverage oracle is needed. A conditional DP choice only records a label and its own syndrome; no unguarded deduction escapes it.
T<=2^f*4^delta poly(N)<=8^delta poly(N), S<=2^delta poly(N) with serial FVS enumeration, CM<=(T+1)S. Include source acquisition/validation, closure, dependency basis, FVS discovery, all attempted syndrome pairs (not just unique retained outputs), backpointers, failed label assignments, witness construction and verification. A fixed polynomial cap returns UNKNOWN. For delta<=a log N (fixed a), this is a uniform deterministic polynomial terminal even with high observation/interface rank. The local closure precedes all label enumeration; label DP is a terminal computation, not an uncharged SAT-branch oracle. The executed implementation copies witness lists rather than optimal backpointers (polynomial overhead).
For DA06 one-frustrated-edge graph this terminal is equivalent to the nonreach formulation but the incidence constraint is stronger than GD14's arbitrary DAG model. Thus we obtain a positive FPT theorem precisely in a domain where the W[1] reduction does not preserve the source parameter. If a strict physical compiler or matching quotient preserves this edge-incidence representation and guards, this theorem transfers; not otherwise. DO08's large dual ranks on two-coordinate raw factor registry are not automatically the same as this first-channel delta; a transfer requires comparing actual matrices.
