## A. Exact actual matching syndrome hull (PROVED)
For every finite explicitly encoded balanced bipartite multigraph G with tags g_e in GF(2)^k and target b, find a perfect matching M by deterministic augmenting paths; if none, UNSAT. Number the left vertices, naming right partner M(i). Each nonanchor edge e=(i,M(j)) gives a directed arc i->j with tag a_e=g_e+g_{M(i)}. Parallel edges retain IDs (a parallel alternative to M(i) gives a loop). Let C range over SCCs of this digraph. Every alternative perfect matching corresponds to a vertex-disjoint collection of simple directed cycles, with fixed points retaining anchor edges. Every such collection gives a perfect matching. Hence cross-SCC arcs can never occur, and matching choices in distinct SCCs are independent. In a block C, let S_C be attainable tag differences from its anchor (0 belongs to S_C). Let V_C=span of tags of all simple directed cycles in C. Then span(S_C)=V_C: one direction is decomposition into disjoint cycles, the other uses a single cycle flip as an actual matching. Thus the exact affine hull of global matching syndromes is g(M)+sum_C V_C, with no tagged matching oracle.

Paid acquisition of each V_C: select root r and directed simple paths P_v:r->v and Q_v:v->r (within C). Form closed walks P_v Q_v and P_u e Q_v for every internal arc e:u->v. Split each walk into simple directed cycles by a stack. The tags of these cycles span V_C. Indeed, a linear functional annihilating all these walks gives phi(P_v)=phi(Q_v) and phi(a_e)=phi(P_u)+phi(P_v); its sum telescopes to zero on every directed cycle. By annihilator duality the generated span is exact. Each walk has O(n) arcs, O(n+m) walks; retain independent cycle tags with their edge lists by Gaussian elimination. No enumeration of all matchings or simple cycles. The algorithm also computes full untagged matching affine hull by appending designated edge selection observations to the tag vector, with polynomial added dimension. This hull is before target conditioning; it is not the affine hull of target-feasible matchings unless separately established. Target outside the exact hull is an unconditional UNSAT certificate. All annihilators of sum V_C give certified stable linear syndrome equations. No claim that satisfying those equations alone suffices.

## B. Quotient rank-one absorption (PROVED)
Maintain W, initially 0, equal to the exact attainable difference set of already absorbed independent blocks. Let pi_W be quotient mod W. If some unabsorbed block has dim pi_W(V_C)<=1, then pi_W(S_C)=pi_W(V_C): the projected support contains 0 and, if rank one, a nonzero actual cycle tag. Consequently W+S_C=W+V_C, a linear space. Remove C and replace W by W+V_C. In the rank-one case store a witnessed cycle with tag outside old W; in rank zero use its anchor. The invariant is exact, including correlations between tag coordinates. Iterate to stagnation. Eligibility is monotone in W; any greedy order reaches the same maximal set of peeled blocks (simulate each step of any other sequence in the final fixed point). At most n block removals and k strict rank increases. The selected cycles lie in distinct SCCs, so all chosen subsets are actual compatible matching flips.

Let d=b+g(M). At any stage exact remaining feasibility is pi_W(d) in sum of pi_W(S_C) over unabsorbed C. If d in W, return SAT by solving for the independent stored tags and flipping the corresponding disjoint cycles; all other blocks retain the anchor. If all blocks peel, Gaussian membership is a complete decision for arbitrary k, even k linear in N. If d is outside W+sum_remaining V_C, return UNSAT. Otherwise at stagnation return UNKNOWN or call an exact paid residual solver on the projected tags; do not equate the remaining hull with support. If the residual solver returns a witnessed set of block matchings with total t, reconstruct the absorbed contribution d+t in W by the same linear basis. ## D. Interface tradeoff (PROVED symbolic)
For remaining block span sums X,Y and absorbed W, quotient interface dimension is exactly
 dim(pi_W X intersect pi_W Y) = dim(X intersect Y)+dim(W intersect (X+Y))-dim(W intersect X)-dim(W intersect Y).
This follows by applying rank-nullity to X,Y,X+Y and using the dimension formula. Thus absorption can INCREASE interface width despite nonincreasing total residual syndrome rank: X=<a>,Y=<b>,W=<a+b> gives 0->1; X=Y=W=<a> gives 1->0. These are linear interface examples, realizable by independent tagged two-cycle blocks. At most dim W increase or decrease. Recompute actual width after each quotient, not a monotone-width claim. This concerns syndrome interfaces between independent complete blocks, not the full occupancy/guard cut of arbitrary owner subsets; for those retain DA13 joint occupancy/syndrome identity and I19 native transfer.
