## 3. Three geometry-specific reductions (PROVED)
A. Universal extension: take a connected component C of G-Q and fix any boundary word. Its remaining lists satisfy |L(v)| >= internal multidegree, because each external exclusion removes at most one color. If some total degree is <4 there is strict slack. Reverse spanning-tree greedy coloring ending at the slack vertex proves universal extension. Otherwise if an internal block is not a uniformly multiplied clique or cycle, the DP-degree theorem (BKP Theorem 9, arXiv:1609.00763v1; Kim/Ozeki Theorem 2, arXiv:1709.09807) guarantees extension for every such degree-list cover. Translated differences yield one matching per excluded shift, so the theorem applies to this loopless multigraph with actual multiplicities. Delete C and retain its complete local reverse manifest. If b_C=0 instead, decide the closed component exactly and reject if UNSAT, otherwise delete and save a witness. A uniformly multiplied clique/cycle is only a possible obstruction, not necessarily UNSAT.

B. Triple-bundle absorption: if a private component contains an internal pair u,v with exactly three distinct forbidden differences, then the component universally extends. For every boundary word, greedily color all other private vertices in reverse order of distance along a spanning tree rooted at the connected pair; each such vertex has an uncolored neighbor and at most three incident exclusions to already colored vertices. Endpoints u,v each have at most one incident exclusion outside the bundle, hence each retains at least three colors. Let d be the unique allowed difference. L(u) intersect (L(v)+d) is nonempty (indeed size >=2) in the four-element group. Choose the corresponding pair. This uses actual translations, not arbitrary three-matchings. A pair with four distinct exclusions is immediately impossible for all colors. Thus triple interior bundles can be removed even though the general DP-degree structural test alone would not classify them universally colorable.

C. Double-bundle path fusion: let a private v have exactly two distinct neighbors u,w, each linked to v by two distinct exclusions and no other constraints. Let A=K minus S_uv and B=K minus S_vw, both size two. For fixed x_u,x_w, there exists x_v iff x_u+x_w belongs to A+B. Each two-element subset of K is a translate of a one-dimensional linear subspace. Hence A+B is an affine line (parallel directions) or all of K (distinct directions). Replace v and its four exclusions by the relation A+B on u,w (two forbidden differences or none), intersecting with any existing u,w relation by union of forbidden sets. Endpoints' degrees cannot increase; b cannot increase even if one or both endpoints are protected. Store the two original masks; each legal new endpoint pair lifts by testing the four possible x_v. This is an exact existential projection, not merely two marginal constraints. If a double output lies entirely on Q, write it as the exact affine equation h dot (x_u+x_w)=h dot d0, where d0 is any allowed difference and h is the unique nonzero vector orthogonal to the line direction. Feed this to Gaussian closure, preserving guard/source IDs. Output full K has no restriction. Existing Q-Q constraints remain enforced. Fusion of a chain gives an allowed XOR sumset; different directions anywhere make it universal, and equal directions yield one line. This provides a concrete low-rank relation without enumerating boundary assignments.

Fixed-boundary lift for A/B or closed components: after substituting actual protected colors, solve degree-list feasibility. Slack accepts; non-GDP accepts by theorem; GDP components are exact block-cut-tree DP with 4-color articulation messages. Each clique has size <=5, enumerate <=4^5 tuples; each cycle uses four-state path masks and closing-edge tests. Multiple shifts on a pair are tested jointly. Self-reduce using at most four trial colors per vertex, each time deleting the pinned vertex, pruning its neighbor lists by at most the edge multiplicity and rerunning the same degree-list decision. The degree-list inequality persists, so no general SAT oracle is used. Verify all original exclusions. Can also use direct greedy construction for slack/triple cases. All lifts are in reverse reduction order; saved external vertices are therefore already assigned.

## 4. DA09-A boundary-linear graph kernel (PROVED)
Exhaust reductions A/B/C and remove every closed component, returning exact UNSAT if needed. Each step removes at least one private vertex; merged edges are never more numerous in multiplicity. All surviving private components have nonempty boundary, every vertex total degree four, all internal blocks uniformly multiplied cliques or cycles, no internal triple bundle, and no private vertex incident to two double bundles. A uniformly multiplied block with internal degree four would saturate every vertex and thus constitute a whole closed component, already removed. The remaining possible internal blocks: simple bridges, simple cycles (including triangles), simple K4, and double K2. Isolated private vertex is allowed.

For a surviving component write n_C=|C|, m_C=internal exclusion multiplicity, b_C=boundary exclusion multiplicity, a=#K4 blocks, d=#double K2 blocks, t=#simple bridge blocks. Block sizes obey sum_B (|B|-1)=n_C-1. A simple cycle on l>=3 contributes l<=3(l-1)/2; simple bridge contributes 1=3/2-1/2; K4 contributes 6=3(4-1)/2+3/2; double K2 contributes 2=3/2+1/2. Thus
  m_C <= 1.5(n_C-1)+1.5a+0.5d-0.5t.
The K4 blocks are vertex-disjoint by degree four. No vertex in a K4 can be in a double K2, and two double K2 blocks sharing a private vertex would trigger C. Hence 4a+2d<=n_C. Every K4 can attach to other internal blocks only through a simple bridge, again by degree. After deleting simple bridges, distinct K4 blocks lie in distinct components; connectedness implies t>=a-1 (also valid for a=0). Consequently
  m_C <= 1.5 n_C -1 +a+0.5d <= 1.75 n_C -1.
Since 4n_C=2m_C+b_C,
  **n_C <= 2b_C-4.**
For all surviving components (count q), n_private <=2 b_res-4q <=2b. This is a vertex kernel with unchanged protected IDs and only ordinary signed difference exclusion relations, rather than an arbitrary dense compatibility oracle. It is exact for every original protected assignment, with polynomial reconstruction. The proof also covers singleton components. For simple graphs alone C and double blocks are absent. Bound is tight: a chain of a disjoint K4 blocks joined by a-1 simple bridges, filling every unused degree port with a protected exterior vertex, has n=4a, b=2a+2 and equality. Before fusion, a chain of arbitrarily many doubled edges with two protected endpoints has b=4 and unbounded private size, falsifying the same raw bound; C repairs it. No universal bound on b itself is asserted.

If all protected vertices have degree <=4, b<=4|Q| and residual graph has <=9|Q| vertices (indeed <=|Q|+2b-4q). The incidence-based first-channel optional registry in DA08 on edges touching residual private vertices now has at most 4n_private <=8b individual rows before further closure; pure Q-Q rows and all external coupling remain charged. This bounds only the contribution of the private interior, not total unstable rank. Raw duplicated bundle observations can have linear dependency nullity on a long chain (at least one dependency per pair); after fusion only one affine line or no relation remains. Do not equate this raw parameter with post-closure DA08 delta. This is an exact structural escape from large nominal rank/width, not a lower bound.
