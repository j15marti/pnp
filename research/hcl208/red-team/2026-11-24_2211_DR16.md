## Guard-weakening DAG theorem
Fix the original Boolean polynomial ring over F2, a common source axiom set P, and a finite acyclic refutation graph. Root guard is true. Every node has a consistent affine guard G of rank <=r; each internal node queries an affine form q and for each consistent branch B=G intersect {q=b}, has a child C with B subset C as affine subspaces (check by Gaussian elimination on actual original coordinates, not only on source models). Children may be shared and may forget earlier guard rows. Each leaf has an actual BPC refutation from P and its own guard of degree <=D, D>=1, including all used preprocessing derivations in the original ring. Then P has a BPC refutation of degree <=D+r, independent of graph size, depth and number of unfolded paths.

Proof: for consistent guard G with independent affine equations g_j=0 let I_G=product_j(1+g_j) in the Boolean ring. It is the unique multilinear indicator of G, degree <=rank G, independent of row basis. For a leaf multiply every proof line by I_G. Each original axiom times I_G can be derived by sequential affine multiplications, expanded using variable multiplications and XOR, and each guard axiom times I_G is zero. The inference rules commute with multiplication. Every transformed line has degree <=D+r (Boolean reduction after each multiplication). This derives I_G=0. In reverse topological order, B subset C implies that the independent affine equations of C lie in the affine-equation span of B. Extend that basis to one for B by adding rank(B)-rank(C) affine equations h=0. Thus I_B=I_C product(1+h), and from I_C=0 derive I_B=0 by sequential affine multiplications at degree <=rank B<=r+1. Inconsistent branches have zero indicator. XOR the two branch indicators, which partition G, obtaining I_G=0. At the root I_true=1. Previously derived child indicators can be reused at every consumer; no unfolding. D+r>=r+1. This is a proof degree bound, not a polynomial bound on the number of monomials at growing r. At fixed D,r a supplied polynomial-size DAG with explicit polynomial-size leaf proofs has a polynomial-cost expanded BPC trace using O(n^(D+r)) monomials per line; discovering a successful DAG is not provided. If leaf degree is bounded and guard rank is logarithmic, the degree bound is logarithmic, while explicit expansion can be quasipolynomial.

Consequence: on DA16's degree-hard signed linear bounded-degree NAE family, D+r>=Omega(n) for any such DAG, even with unlimited graph size, arbitrary affine forms and sound weakening/sharing. This extends DA16's tree argument to this specific genuinely shared model; it is not a general DAG size lower bound. Exact full-path guards cannot merge two different feasible paths of a deterministic decision tree, since first divergence implies opposite values of the same affine form; weakening or a separately justified quotient is required. Non-PC certificates, extension variables, non-affine state interfaces, guarded rewrites whose lift lacks this degree cap, and semantic implication modulo P are outside theorem. No simultaneous hardness claim for MS21, DO16 or M22 families.
