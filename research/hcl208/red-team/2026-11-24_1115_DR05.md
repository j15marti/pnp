## 1. Exact two-row compiler (PROVED)
For any simple loopless unweighted graph G=(V,E), with n vertices and m indexed edges, let e_i be the unit vector for edge i in F2^m, and h_v the incidence column of vertex v (one at each incident edge). For every vertex choose a bit x_v from two rows (0,0),(h_v,0), where each row consists of (base tag, integer cost). For every edge choose t_e in {0,1}, with rows (0,1),(e_i,0) respectively. No other owners, no public parity bits, no hidden constraints. Require total XOR of tags zero. The i-th equation is x_u+x_v+t_e=0 over F2. Thus base solutions are in bijection with all 2^n source cuts (labeled vertex words), with t_e=x_u XOR x_v. The sole public cost is C=sum_e(1-t_e)=m-cut(x). Costs are nonnegative unit integers. A threshold K is feasible iff MaxCut(G)>=m-K; exact attainable profile S is precisely all attainable uncut-edge counts. Hence fixed budget feasibility in this explicit class is NP-complete by Simple Max Cut [1], with easy polynomial verification. Computing even just the minimum of S is NP-hard; full exact S (at most m+1 entries) with witnesses is polynomial-time computable iff P=NP: if P=NP, ask polynomially many NP exact-cost questions and self-reduce each witness. No assumption P!=NP and no unconditional superpolynomial bound. This is a special case of cost optimization on affine codes [2], not a new claim about general coding complexity.

A single exact-cost membership query (not just an inequality or minimum) is also NP-complete in the same two-row model: append K independent zero-tag factors with costs 0 and 1, and ask for exact total cost K. A source word of cost c extends iff c<=K, by choosing K-c of those factors; K<=m, so size and output capacity remain polynomial. All padding rows have base witnesses under the loose all-profile cap m+K. This exact-key reduction is symbolic, not separately executed.

Every base tag factor is affine; indeed even a two-row (tag,cost mod 2) relation is affine over F2. Integer budget is NOT an affine equation. Base feasibility and all base affine identities are computable by elimination. Every row has a constructive base witness: x_v arbitrary; for an edge fix endpoints equal or unequal, others arbitrary, then compute t. All rows and any mutually base-consistent combination have actual base extensions. At all-profile root K=m, the complete unary support closure (including costs under that cap) is stagnant. The source is always SAT under this loose cap and all-zero x is an explicit witness. An exact profile adapter must nonetheless decide the hard minimum. Small cardinality H=m+1, q=0, no private budgets, local rows exactly two, and a cheap base terminal are insufficient to establish paid acquisition.

## 2. Both-label threshold controls and closure (PROVED)
For K>=1, the affine support and affordability rules at the raw root delete nothing: base row support as above, independent cost minima zero, each row cost at most one. This is NOT complete semantic closure under K, whose rejection of an UNSAT instance already solves the hard query. NP-hardness persists with K>=2 and connected graph: join all original components by bridge edges, attach two disjoint triangles by bridges to the connected graph. Independent component flips satisfy all bridges; each triangle contributes exactly one unavoidable uncut edge. Thus new minimum is old minimum+2; adjust K to K+2. Trivial empty/threshold cases handled separately. No claim of hardness for a specific complete graph.

For G=K_(2r+1), r>=2, C_min=r^2, attained by r versus r+1 partition. K=r^2 and K=r^2-1 are same-graph opposite-label neighbors; both raw closure-stagnant. Under the SAT optimum every row remains supported even by exact unary closure: by permutation any chosen edge can be cut or uncut, and by global complementation any chosen vertex bit attained. On UNSAT no complete semantic support can remain. This explicitly separates cheap closure from semantic closure. K5 here is a Boolean cut benchmark, NOT the tetrahedral 4-color K5 benchmark. The clique family is easy by the closed formula and is a control, not a hard sequence.

## 3. Guard-preserving quotient and an exact constructive escape (PROVED)
With protected integer cost, every zero-cost vertex factor permits period h_v; edge rows have distinct protected cost so their local common period is zero. BA04 quotient by H=span{h_v}, the binary cut space, is exact for every attainable cost. H has rank n-c(G) (including isolates), since the kernel of x -> (x_u+x_v)_e is exactly componentwise constants. Remaining dimension beta=m-n+c(G). Quotient map Q can be constructed from a spanning forest's fundamental cycles: Q(t)_j is parity of t on cycle j. The cycles are independent since each contains its own unique nonforest edge; ker Q=H by assigning along forest and checking each chord. Therefore original compatibility is exactly XOR_e t_e Q(e)=0. For all-profile calculation, start D[0]={0}; for each edge and each retained (s,c) add (s XOR t Q(e), c+1-t), t=0,1; store one actual edge word per key. Final D[0] is exact cost profile. Lift t by assigning arbitrary forest roots and following edges; verify every chord and cost. With fixed threshold one may truncate costs above K or store just minimum and a witness per syndrome. For signed preferences replace the cost with 0/1 disagreement; same proof. This is polynomial if beta=O(log N), and an alternate enumerator over n-c(G) independent vertex bits is also exact. Neither parameter universally small.

Complete graphs with n>=4 have distinct nonzero quotient edge columns: a triangle can be chosen containing either of any two distinct edges but not the other, hence their cycle-incidence vectors differ. The raw count grouping of DP01 then has 2^m possible edge-count choices after removing vertex periods; yet symmetry gives the easy cut minimum and profile. Again no inference from group volume to unrestricted runtime. For BS04, before quotient choose all e_i as basis: each vertex factor connects the incident edge factors; hence connected source graphs form one base component despite zero private owners. Exact affine feasibility is cheap inside that component, but augmented cost acquisition is not guaranteed cheap. Quotienting all periods while ignoring cost would erase the very target distinction.
