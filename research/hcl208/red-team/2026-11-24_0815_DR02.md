## 2. Exact two-port SAT switch (PROVED)
For arbitrary proper 3-CNF F on n variables with m>=1 clauses (distinct variables per clause, standard NP-complete restriction), construct signed NAE-3 region H with ports a,b. Original variables and fresh t,u for each clause are private. For each clause (l1 OR l2 OR l3) insert
  NAE(not b,l1,t), NAE(not t,l2,u), NAE(not u,l3,a).
The elementary identity NAE(s1,...,sk) iff exists z [NAE(s1,s2,z) AND NAE(not z,s3,...,sk)] for k>=4 follows by cases: equal s1,s2 force z opposite, otherwise z free and can make the second predicate true. Iterate to obtain NAE(not b,l1,l2,l3,a). When a=0,b=0 this is always true; when a=0,b=1 it equals the original clause. Complement every variable simultaneously to handle a=1, preserving signs and every NAE. Thus in the unequal-port branch F is evaluated on x_i XOR a, including signed literals. Add a chain of NAE(s_i,s_(i+1),fresh_i) over all original and split private variables: each fresh bit always extends any pair, so these clauses do not restrict any previously assigned bits. They make the private primal subgraph connected after deleting a,b. All triples distinct within each scope and touch the private region. There are O(n+m) variables and factors, O((n+m) log(n+m)) bits in an ordinary indexed encoding. All compiler operations and SAT lifts are polynomial (constant-size row searches). Both ports occur; optionally attach an outside NAE(a,b,c) with fresh c, which always extends and makes the boundary a genuine separator.
Hence the exact binary support is
  R_H = {00,11} if F is UNSAT,
  R_H = {00,01,10,11} if F is SAT.
Both relations are affine. The region is ALWAYS SAT, and equal-port witnesses are constructed without deciding F. Every variable has both values by complement symmetry. The single relative port bit a XOR b is the only information needed at the interface; its support is nevertheless NP-hard to acquire. The unequal branch is exact, not an overapproximation. A single exact supported-row test for 01 is NP-complete on this promise (certificate is a full extension); deciding forced equality is coNP-complete in the promise sense. Conversely under P=NP, four SAT probes plus polynomial self-reduction give exact row support and actual witnesses for any explicitly encoded bounded-arity region. This proves equivalence, not an unconditional superpolynomial lower bound.

## 3. Monotone, linear and fixed-high-girth strengthening (PROVED)
Use DO02's Fano-minus-line gadget on ports v,w,p, with four private vertices and six edges (v,3,4),(v,5,6),(w,3,5),(w,4,6),(p,3,6),(p,4,5). All ports equal in any model by Fano non-2-colorability; for equal ports assign four private bits opposite. For each literal occurrence create its private occurrence variable o. For a positive occurrence use the gadget with v,o,p ports. For a negative occurrence use v,w,p and add NAE(w,p,o); then o=not v. In both cases exactly the intended two-port relation, all source assignments lift uniquely enough by local construction, and any compiled model projects correctly. Insert each original signed NAE as a monotone NAE on its three occurrence variables. All gadget interiors fresh. Fano-minus-line is linear, no pair of its three ports co-occurs, so the negative wire's extra triple preserves linearity. Different gadgets intersect in at most their original variable. Core triples have unique occurrence variables. The full output is a linear 3-uniform monotone hypergraph. The wire minus either terminal is connected to its other terminal (check the six edges), so the entire private region remains connected after deleting a,b. Both exact boundary relations and the known SAT witness survive. Size linear in source occurrence count; no external guard is lost.
For each FIXED girth g>=2, use DO01/DO02's fixed two-terminal equality gadget K_g, a minimal equality-enforcing subformula of a high-girth non-2-colorable hypergraph with an edge removed. It is SAT; both equal values extend; its terminal-to-terminal path requires at least g hyperedges, and its internal Berge girth exceeds g. For completeness of the connected-private promise: after removing either terminal, any component not containing the other terminal could attach only to the removed terminal. Its projected one-port relation is full by complement symmetry and satisfiability, so its constraints could be deleted without changing forced equality, contrary to minimality. Discard isolated nonterminal vertices. Therefore K_g minus either terminal remains connected to the other. Stretch EACH incidence of the monotone linear output through a private K_g and a fresh occurrence bit. Any cycle not confined to one gadget must traverse a gadget between its terminals and at least one other hyperedge; hence its length exceeds g. The connected-private property and exact projection persist. For fixed g the finite gadget and an equal-port witness can be hardcoded; no uniform polynomial bound in g or efficient construction of growing K_g asserted. This strengthens the promise to arbitrarily prescribed fixed girth. The high-girth reduction is symbolic, not executed here. DR01's local extension family then applies with g>=w for any fixed closure width w: local overlap closure cannot eliminate all support for any pair, including the forced-equal ports on the UNSAT-source side. It remains possible to recover the inserted equality wires by DA02/BW02 and solve the residual through another terminal. No simultaneous all-portfolio hardness is inferred.

## 4. Consequence for certification and affine closure (PROVED)
Positive supported rows have polynomial witnesses. An exact table with absent rows needs negative evidence. If all equality tables in this promise class had polynomial-length certificates accepted by one uniform polynomial verifier sound for the absence of 01, then UNSAT would belong to NP and NP=coNP. Polynomial verification of an arbitrary-length supplied certificate is not enough; length and discovery matter. No such certificate-size theorem assumed.
Even on SAT-promised, complement-invariant sources, complete affine identity extraction in polynomial time would solve arbitrary SAT via checking whether a XOR b=0 is entailed. This is stronger than absence of unary forced bits. A paid constructive upper bound: obtain one actual model or reject; maintain its witnessed affine hull. Find a model outside that hull by an exact SAT call on the formula AND the disjunction of violations of the current basis of affine equations (polynomial XOR-to-CNF encoding). Each success increases dimension; stop on full space or a certified negative call. At most n+1 exact calls including initial model search and possible final rejection, plus polynomial linear algebra and SAT witness extraction (if decision-only oracle, add polynomial self-reduction). This is an exact interface for GD08, not a polynomial unconditional solver. Under guard G, export only G implies the identity; for a parent unguarded projection use all feasible guarded rows. All full affine/semantic closure must be paid. Implemented closure is only repeated exact local row-support filtering at the frozen guard, with root pass and fixed point after pins/branch assignments and before further branching.

## 5. Potential, aggregate branching, and diagonal audit (PROVED conditional)
A strictly decreasing live-variable count across a two-port projection is legitimate after acquisition, but cannot bound acquisition itself: the two-port switch has at most four output rows and a rank-one relative interface regardless of F, yet acquisition is SAT-complete. Thus the proposed sufficient condition cannot omit the cost of identifying supported rows, missing-row certification, or guard/key construction. It is circular to assert a paid universal two-port terminal by assuming polynomial complete semantic closure. For ordinary binary guard branching, even n^c is not universally a conserved budget: 2(n-1)^c>n^c for all sufficiently large n for every fixed c. Concrete legal branch: NAE(x_0,x_1,x_i) for i>=2, branch x_0. Both children retain n-1 variables, no unary/affine forced identity on those live variables (one branch contains all ones and each single-bit flip; the other all zeros and each single-bit flip), though both children are easy 2-SAT. This falsifies an all-legal-branches contraction claim, not the existential claim that another paid terminal can avoid branching.
Sufficient corrected theorem: fix one uniform exact normalization schedule, all produced state/key/certificate sizes bounded by root N^d, nonnegative integer credit B(F)=mu(F)^c with root B polynomial and each nonterminal expansion paying at least 1 plus the sum of ALL child credits (each child occurrence in a tree, credit >=1). Every node costs at most one fixed polynomial in root N including source acquisition, failures, discovery, guards, closure, verification, canonicalization, aggregation and reconstruction. Then total unfolded nodes <=B(root) by telescoping; total T<=poly(N)B(root). On a deterministic bit machine, S<=O(N+T), CM<=O((T+1)S), hence polynomial on the same realization. No double count of shared physical storage. A DAG improvement needs an explicit credit for newly created distinct exact keys AND attempted edges/uses, including re-expansions if evicted. Deduplicating a child per parent is not a proof of global cost conservation. Sharing exact decision values does not justify merging counting multiplicities or context-specific reconstruction records.
For fixed total exact portfolio A, assuming no polynomial bound means for each j there are arbitrarily large input lengths with some F having T_A(F)>|F|^j (otherwise eventual bound plus finite exceptions). Select increasing-length F_j. If a fixed channel i is simulated with polynomial overhead in root size and its actual charged work, i cannot succeed on that sequence in any fixed polynomial time for all sufficiently large j. This simultaneous exclusion requires a fair/capped simulation guarantee; an unbounded preceding channel can stall a sequential portfolio, and an uninvoked adaptive region is not a failed query. The sequence is not a constructive uniformly hard family, need not be UNSAT, and gives no hardness for an unrepresented algorithm. Even if P=NP a poorly chosen A can have no polynomial cap. To contradict it one needs a universal coverage theorem for A, not a list of sufficient terminals or a polynomial representation. No quantifier swap.
