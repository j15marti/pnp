## 2. The full-affine punctured four-port construction (PROVED)
For every proper 3-CNF F on n variables, m clauses, use Q=GF(4) as a two-dimensional GF(2) vector space. Write z=l+alpha*h, alpha^2=alpha+1; let r be a free reference color. Construct an always-satisfiable connected child region B(F), with distinct boundary vertices y_a for a in Q, such that y_0=r and its exact port relation is
    (y_a)_(a in Q)=(r+a*z)_(a in Q),
    r in Q, z in Z_F;
    Z_F=Q if F SAT, Q minus {0} if F UNSAT.
Source variables are relative to r, represented by the two colors 0,1 in the normalized frame.

For every source clause (L1 OR L2 OR L3) add three Boolean clauses
    (l OR h OR A), (not A OR L1 OR B), (not B OR L2 OR L3)
with private A,B. Existentially these clauses equal (l OR h OR L1 OR L2 OR L3). If z is nonzero, choose A=B=0 and any x. If z=0, A=1, and choose B=0 if L1 true, B=1 otherwise; extension exists exactly when the source clause holds. Add w=l XOR h using its four forbidden-triple clauses. Then port low/high bits relative to r are y_1=(l,h), y_alpha=(h,w), y_(1+alpha)=(w,l). These equations are multiplication by the three nonzero field elements. The exact normalized port relation follows in both directions.

## 3. Explicit signed graph compiler (PROVED, executed multigraph version)
Only primitive edges x_u XOR x_v != s are used; multiple signed exclusions on the same pair permitted and indexed. Normalize r=0 without loss by uniform translation.
- To restrict a vertex to D subset Q, connect it to r with one exclusion for each color outside D. All Boolean nodes have D={0,1}.
- Binary recoding: for x in {0,1}, y in {f,t} with f!=t, require y=f at x=0, y=t at x=1. Exclude differences 0 XOR t and 1 XOR f. Neither forbidden difference equals either desired difference, since comparison shares one endpoint; duplicate labels may be merged. Swap f,t for a negative literal.
- For a Boolean clause use a hub c with D={0,1,2}, and three occurrence nodes o_j with D={j,3}, j=0,1,2. Recoding forces o_j=j on a false literal, 3 on a true literal. Add exclusions c XOR o_j != 0. If all false all three hub colors forbidden; if any true the corresponding j is available. Both directions are exact, with a direct lift choosing a true occurrence index.
- For a port p with low bit u and high bit v, impose p XOR u in {0,2} (exclude 1,3). Recoding v into t in {0,2}, impose p XOR t in {0,1} (exclude 2,3). These are exactly the required bit relations in the reference frame.
All constraints are invariant under uniform Q-translation. Each restricted node connects to r; each unrestricted port connects to its bits, so B is connected. Explicit compiler as executed has n+14m+26 vertices and 2n+49m+90 signed edge occurrences, including the 4 XOR clauses and three nonreference ports. Source construction, authentication, and lifts are linear in counts, O(poly(N)) bit cost including indices, renumbering and input parsing. For every nonzero z, every x, construct an actual graph witness by the above local rules. In particular three nonzero selector witnesses are supplied in polynomial time without deciding F. Conversely a zero-selector graph witness decodes a source model.

Simple signed graph variant: for each primitive exclusion u-v, introduce a fresh copy u' of u and a private K5-e equality gadget on terminals u,u' with three clique interior vertices adjacent to both. Any ordinary four-coloring forces u=u'; each equal pair extends by the other three colors. Use only one signed exclusion u'-v. Each gadget and edge has private indices, so the resulting graph is simple; exact two directions and linear blowup. Keep four boundary vertices and the parent crossing edges as originally defined. This variant is proved symbolically, NOT executed. No strict physical E4/B4 transfer or maximum-degree bound claimed.

## 4. All affine identities and single-parity boundary observations are identical (PROVED)
Fix r=0. The linear injective map z -> (a*z)_a has a two-dimensional image L. For an UNSAT source the support is L minus {0}; for SAT it is L. In GF(2)^2 the three nonzero vectors affinely span the whole space (their pairwise differences span), so both supports have identical affine hull L. With arbitrary translation the affine hull is the same four-dimensional subspace for either label. This is the *joint entire boundary hull*, not only the six independent pair hulls. Every linear functional of the entire port word has identical attainable one-bit values on both labels, including all cross-port linear observations. No claim for arbitrary interior observations.

For every distinct a,b, y_a XOR y_b=(a+b)z, and a+b nonzero makes multiplication invertible. Thus all six exact pair masks are Q on SAT, Q minus {0} on UNSAT. Three nonzero witnesses give the exact complete affine hull and all one-parity supports in polynomial time on both labels. Every zero-bit query is equivalent to source SAT. This is stronger than DR02: even *complete* boundary affine identities do not distinguish the missing word.

## 5. Actual four-edge gluing equivalence (PROVED)
Let parent region A consist of one vertex p, known SAT and translation invariant. Join it by four unsigned exclusions p != y_a, one per port. This is a DP04 region tree with exactly two regions and exactly four crossing edges. If z nonzero the four y_a exhaust Q, so no parent color exists. If z=0 all y_a coincide, leaving three parent colors. Consequently the whole graph is SAT iff F is SAT, even though both individual regions come with actual SAT witnesses, a complete authenticated affine boundary hull, and witnesses for every nonzero pair-mask entry.

The promise decision problem “glue two such always-SAT regions with supplied witnesses, supplied partition and exact boundary affine hull, using four signed singleton crossings” is NP-hard under uniform many-one reductions and lies in NP in the promise sense (verify complete graph assignment). Hardness persists with the symbolic simple-graph replacement. Polynomial deterministic solution for all promised inputs is equivalent to P=NP (converse: general signed graph SAT is in NP and reduces to 3-SAT). Computing one zero support entry is likewise equivalent to 3-SAT; polynomially bounded verifiable certificates of missing zero on all such inputs would imply NP=coNP, but efficient discovery is a separate requirement.

This is not a contradiction to DP04: its local calls must evaluate the *actual augmented and guarded regional problem*. It is not a claim that two-bit constrained perfect matching is NP-hard, because no BS03/GD10 graph/flow-domain adapter has been established.

## 6. Partial acquisition and potential audit
For the fixed parent, each of DP04's six collision tests asks whether zero belongs to its pair mask. Initially DS02 lower supports contain all nonzero entries (actual witnesses), upper supports additionally permit zero, so lower rejects and upper accepts. These are exact possible bounds, not proof of UNSAT or SAT. Any one certified zero YES gives a lift; any one zero NO suffices if the authenticated source manifest establishes equivalence of all six bits. Thus arbitrary sharing and cancellation of equivalent zero jobs are explicitly permitted; even the single remaining exact job is SAT-complete on this promise domain. Alternative source-solving methods are allowed.

Counterexample to the candidate inference: a fixed number (even one) of unresolved interface jobs and a polynomial credit decrement does NOT establish polynomial computation unless each job is uniformly paid. The DP04 regional job potential is 28R-25=31 here, but there is no universal per-job polynomial bound proved. Correct ledger charges compilation, discovery/verification of the manifest and affine witnesses, all attempted acquisitions, closure, guarded context keys, retained witnesses, aggregation, and source reconstruction. For a fixed number of calls, T <= poly(N)+sum actual T_query+T_lift, S <= poly(N)+max S_query+S_lift for streamed sequential calls, CM <= (T+1)S. This is not a lower bound on T_query unless P!=NP is separately established; it states an exact complexity implication. No free semantic negative-row certificate, no double-counting shared queries.

## 7. Diagonal quantifiers and gates
For a fixed total exact cooperative algorithm A with a fair actual simulation of certified channels, assume no polynomial bound. Then for each integer j choose a legal F_j at strictly increasing encoded lengths with T_A(F_j)>|F_j|^j (finite shorter inputs can be covered by a constant multiplier). For each fixed accessible polynomial channel with actual total discovery, evaluation, verification and lift cost <=K N^c, sufficiently late F_j cannot lie in its decisive domain if fair simulation overhead is polynomial for that channel. This gives simultaneous avoidance of each fixed paid terminal, not a single uniform exponent for an unbounded family, not an effective construction of F_j, and not an unrestricted algorithm lower bound. The current wrapper does not show its generated instances are that sequence. It only shows that excluding small boundary/low affine rank or counting jobs is insufficient as a proof spine. If P=NP, a paid SAT oracle implemented as an ordinary polynomial algorithm would solve the wrapper and all explicit probes, consistent with every result here.
