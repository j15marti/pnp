## 1. Source family and exact closure (PROVED)
Let b>=1. Take b monotone NAE blocks, each the complete tripartite 3-uniform hypergraph K_(2,2,2) with two A, two B and two C variables, all eight triples. For block i let its B variables be B_(i-1), B_i, shared with adjacent blocks only; its two A and two C variables are private. The connected source has n=5b+1 variables, m=8b NAE owners (16b strict ordinary 3-CNF clauses after expanding NAE), maximum incidence degree 8. Each owner rejects the affine event x_a+x_q=0 AND x_a+x_c=0. All variable and owner identities are retained. No physical E4/B4 compiler is asserted.

F is SAT: set B=0 and C=1, arbitrary A. More strongly, for ANY single coordinate x and either RHS, the satisfying set affinely spans that entire hyperplane. For any other coordinate y, choose its tripartite class free and the other two classes uniformly opposite. If x is in the free class, fix it; if x is in a fixed class, choose its orientation to satisfy the guard. This gives two satisfying words differing only at y. Differences span all n-1 directions. Before a branch the same argument gives full affine hull. Thus even complete semantic affine closure would add no necessary affine equation; we prove this structurally, not assume an oracle is free.

Now prescribe P to observe the first A variable of each block. For k<=b and p in F2^k, keep the exact guard on the first k such variables. Every guard is feasible, and the satisfying set in EVERY guard fiber has affine hull exactly the guard:
* A coordinates: globally set B=0,C=1, leave A free except guard.
* B coordinates: in each block set both A equal to its prescribed bit (or 0 if unpinned), and both C opposite A; all B independently free, including shared B.
* C coordinate in block i: choose both A in i equal to its pin (or 0), set all B opposite that value, permit both C in i freely. In other blocks set C opposite the common B and honor A pins freely.
Each unpinned coordinate thus has a verified flip pair. All factor events retain codimension two because at most one of their three variables is pinned. The rank-one unconditional closure rule has no deductions, initially and after each conditional guard at stagnation. Guarded assignments are not exported as unconditional facts. This proves absence of any additional affine consequence on the SAT family, not absence of nonlinear deductions, symmetry or other terminals.
