For m>=2, Boolean h_0,...,h_{m-1}, X subset [m] containing 0, and 1<=j<m, set
A_X(h)=(OR_i h_i) AND (AND_{i notin X} NOT h_i).
B_j(h)=h_j AND (AND_{i != j} NOT h_i).
Attach an existentially satisfiable filler (h_0 OR y OR p) to each bundle with fresh p. Proper-3CNF compilation uses a four-clause unit gadget (ell OR +/-p OR +/-q), padded 2-clauses, and Tseitin OR gates, all with distinct variable indices per clause and fresh auxiliaries. Each source has O(m) clauses and O(m log m) encoded bits.

Theorem 1: Each exact projection onto y of A_X and B_j accepts both y values, yet their shared-witness conjunction is SAT exactly when j belongs to X. Thus the pair X={0}, j=1 is a valid UNSAT join even though both exact marginals are total; X={0,1}, j=1 is a SAT join. Independently quantifying the shared h selector is invalid.

Theorem 2 (detached summary): Any deterministic context-independent summary M(X) of the left bundle from which a fixed reconstructor correctly decides all joins with singleton B_j, without reading the left source again or receiving other X-dependent data, requires >=m-1 bits in the worst case. Distinct X and X' differ at some j>=1 and require opposite answers. There are 2^(m-1) choices X, but only 2^(m-1)-1 binary strings shorter than m-1 bits.

Corollary: A restricted preprocessing architecture that retains ONLY Q SAT/UNSAT labels, with no source-dependent query descriptions or metadata, needs Q>=m-1. Since N=O(m log m), Q<=N^(0.6+o(1)) fails for sufficiently large m. This says nothing about unrestricted source-aware solvers.

Binary-selector variant: for m=2^k, use just k shared bits b, forbid each b=bin(i) for i not in X using a proper-3CNF encoding of a k-literal blocker, and let B_j fix b=bin(j). Sources have O(m log^2 m) encoded bits. The same m-1-bit detached-message theorem holds despite only log2(m) shared bits.

Constructive escape: in the canonical unary grammar, a one-pass O(N)-time O(log N)-scratch parser recognizes four consecutive clauses that enforce NOT h_j. Once j is known, this source-aware parser decides the joint SAT label without SAT calls. Therefore the detached information bound does not imply an unrestricted SAT time lower bound. O(N) source rereads for each of N^0.6 children would instead cost N^1.6 and fail the candidate N^1.1 generation budget.
