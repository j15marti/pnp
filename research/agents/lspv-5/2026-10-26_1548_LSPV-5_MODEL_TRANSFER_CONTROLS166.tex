\section{Claim card and falsifiers fixed before source review}
\textbf{Target.} Audit every numerical model-conversion arrow used in the
formal circuit/adaptive-certificate/ARC spine.  The quantified object is one
fixed uniform total exact machine per simultaneous time--space pair, on all
inputs in its declared encoding.  M1 is a deterministic one-head read/write
single tape whose initial $N$ cells count in footprint.  Mk is a deterministic
fixed-$k$ machine with one sequential read-only input head and fixed sequential
work tapes; input is excluded from work space.  RAT is the FLMV/Williams
indexed read-only-input random-access TM, where writing an address costs
$O(\log T)$.

Before reading the two new governance notes and primary papers, four hostile
controls were registered:
\begin{enumerate}
\item A work-content-only crossing snapshot may merge configurations whose
input heads scan different symbols.
\item An indexed equality comparison may cost $O(\log N)$ per requested
address while a sequential input head travels $\Omega(N)$ for one request.
\item M1 necessarily has $P_1\ge N$ even when the corresponding read-only-input
machine uses zero work cells.
\item Any RAM $t+s\ge2$ import may hide an unbounded word, unit-cost oracle,
promise restriction, or space convention mismatch.
\end{enumerate}
All four attacks succeed in their stated scope; none proves a SAT lower bound.

\section{Exact conservative simulation theorem}
\begin{theorem}[Fixed-$k$ rescan simulation; PROVED/EXACT]
Let $M$ be one fixed deterministic Mk machine.  On an input of length $N$,
suppose its actual run has $T_k$ transitions and visits $S_k$ work cells in
total.  A deterministic M1 machine can reproduce that run using
\[
 P_1=O(N+S_k+\log(T_k+2)),\qquad
 T_1=O\!\left(T_k(N+S_k+\log(T_k+2))\right).
\tag{1}
\]
For polynomial ceilings this gives only
$t_1\le t_k+\max\{1,s_k\}$ and $p_1\le\max\{1,s_k\}$.
\end{theorem}
\begin{proof}
Copy the immutable input, delimit the fixed many active work-tape intervals,
and mark every virtual head.  A simulated transition rescans the active
representation, reads the marked cells, performs the original finite
transition, and restores the head markers.  Sequentially visited work cells
form intervals of aggregate length $O(S_k)$; coordinates and delimiters need
$O(\log(T_k+2))$ conservative slack.  Thus each source transition costs one
scan of the displayed footprint.  The scan already includes cell probes,
head movement and traffic, so adding those counters again would double-count.
This is an existence upper bound.  It supplies no converse lower bound.
\end{proof}

Hennie--Stearns concerns a \emph{two-tape} $O(T\log T)$ simulation of
multitape computation, not a one-tape theorem.  Equation (1) must not be
replaced by that faster bound.  Nor does a space-only simulation retain the
source time exponent unless a separate theorem says so.

\begin{counterexample}[Footprint is not work space; PROVED/EXACT]
The Mk machine that outputs the first input bit uses $S_k=0$ work cells.
Under the directive's M1 convention, the same $N$-bit instance has
$P_1\ge N$ before computation starts.  Therefore $p_1\ge1$ is definitional
and cannot be substituted for an FLMV writable-space lower bound.
\end{counterexample}

\section{Crossing records: a falsification and the minimal repair}
\begin{counterexample}[Weak snapshots do not splice; PROVED/EXACT]
Take input $01$ and a machine state whose next action is to output the
currently scanned input symbol.  Two configurations can have identical
finite control, empty work contents and identical work-head data, but input
head positions $0$ and $1$.  Their next outputs are respectively $0$ and $1$.
Thus ``same work snapshot'' without the input-head/boundary information is
not a Markov state and cannot justify splicing.
\end{counterexample}

For one \emph{fixed} input boundary the repair is economical.  A crossing
record must contain the finite state, crossing direction, every visited work
cell value, and every work-head position.  The input-head position is fixed
by the boundary; in the exact22 middle gap the scanned boundary symbols are
fixed as well.  Such a record takes $O(S_k+\log(T_k+N)+1)$ bits for fixed $k$.
Equal complete crossing sequences then support the standard deterministic
cut-and-paste argument.

\begin{lemma}[Abstract exact22 counting, conditional on the published locality
family]
Assume the claimed family $E_m(a,b)$ has length $N=\Theta(m\log m)$, a fixed
$\Theta(N)$ gap, and accepts exactly when $a=b$.  For each fixed gap boundary,
crossing sequences on the $2^m$ accepting inputs $E_m(a,a)$ are injective;
otherwise equal complete sequences splice to an accepting unequal hybrid.
The number of variable-length words over an alphabet of
$2^{O(S_k+\log(T_k+N)+1)}$ configurations implies average sequence length
$\Omega(m/(S_k+\log(T_k+N)+1))$.  Averaging over $\Theta(N)$ gap boundaries
gives one input satisfying
\[
 T_k\bigl(S_k+\log(T_k+N)+1\bigr)=\Omega(N^2/\log N).
\tag{2}
\]
For polynomial ceilings, (2) yields the native sequential-input condition
$t+s\ge2$ (with polylogarithmic slack).  This is not a RAT inequality.
\end{lemma}

The logical counting/splicing schema is therefore not falsified after the
complete-record repair.  The exact CNF generator scripts named by the
governance note were not published at the cited path, so this run does not
independently promote their properness/locality audit beyond
\textbf{CONDITIONAL / independently reviewed proof pending}.

\section{Indexed-access and word-cost countercontrols}
\begin{counterexample}[INDEX locality gap; PROVED/EXACT]
Let the input contain a binary address $i$ followed by an $N$-bit array $x$.
Williams's RAT writes $i$ on an index tape and accesses $x_i$ in
$O(\log N)$ transitions.  A sequential input head initially at the left end
must make $\Omega(N)$ moves on the instance $i=N-1$.  Hence no reverse
polylogarithmic RAT-to-sequential-tape time transfer follows.  Conversely a
sequential machine can be simulated on a bounded-word bit-cost RAM with
polylogarithmic overhead, so a model-matched RAT lower bound can transfer to
the weaker tape model in that direction.
\end{counterexample}

A word-RAM comparison is admissible only with word length
$\Theta(\log N)$, polynomially bounded addresses, and a fixed operation set
whose operations compile into polylogarithmic bit time and space.  If an
$N$-bit word or a semantic SAT primitive costs one unit, one operation may
move or decide $N$ bits and no cited RAT exponent follows.  This is a failed
model transfer, not a theorem about realistic hardware.

\section{Promise/full-SAT firewall and current proof DAG}
On the canonical equality promise, indexed access can compare the left and
right sign records in $O(N\,\mathrm{polylog}N)$ bit time and $O(\log N)$
workspace; two independent sequential input heads also give linear motion.
Therefore the exact22 tape stripe is access-transport hardness on an easy
promise.  It neither lower-bounds RAT SAT nor yields a full SAT algorithm.
Conversely, an easy promise subclass does not refute a worst-case full-SAT
lower bound.  Any use inside ARC must additionally provide an ordinary
all-input reduction preserving physical length, bit-local access, and one
same machine's simultaneous resources.
