\section*{Status and executive result}
P versus NP remains \status{OPEN}.  This run repairs a load-bearing type error
in the adaptive-certificate discussion.  An existentially accepted UNSAT
proof is an \emph{NTIME verifier for UNSAT}, not a conondeterministic verifier
for UNSAT.  It yields the conondeterministic SAT machine required by van
Melkebeek's Theorem~1.3 only after every branch outcome is complemented.
Consequently malformed records and verifier clock expirations reject in the
UNSAT verifier but must accept in the complemented SAT machine.

The second correction is quantitative.  Nondeterministic and
conondeterministic time is bounded on \emph{every} computation path.  The
cost of the cheapest valid proof is therefore not a coNTIME upper bound.
One malformed branch may preserve the recognized language while making the
machine exponentially slow.  A usable certificate theorem needs one uniform
clock for valid, invalid, accepting, and rejecting records.

\section*{Claim card and preregistered falsifiers}
\textbf{Target:} transport an adaptive UNSAT proof verifier into the
conondeterministic SAT premise of van Melkebeek's Master Theorem.  The exact
quantifier prefix sought is
\[
 \forall F\,[F\in\UNSAT\iff\exists\pi\ V(F,\pi)=1]
 \quad\Longrightarrow\quad
 \forall F\,[F\in\SAT\iff\forall\pi\ C(F,\pi)=1].
\]
The SAME\_REALIZATION pair is $C=1-V$: identical source, guesses, work tapes,
index tapes, and branch clocks, with only the final decision bit reversed.

Before literature and corpus search, four falsifiers were fixed.
\begin{enumerate}
\item The project may call an existential UNSAT proof a conondeterministic
      UNSAT verifier, reversing the class orientation.
\item Malformed records may reject on both sides instead of being complemented.
\item Timeouts may be treated as nonhalting or rejecting in the SAT co-machine,
      violating totality or universal acceptance.
\item The ledger may charge only a successful certificate path while coNTIME
      charges the longest path over all guessed records.
\end{enumerate}
All four occur as live risks; the first occurs explicitly in historical Role-5
report \texttt{ORACLE-POLARITY158}.  The latest Role-3 report avoids a
near-boundary claim, but its certificate cost cannot become a Theorem~1.3
$c$-exponent by minimizing over accepting backdoors.

\section*{Primary theorem and model audit}
Van Melkebeek defines machine types $N$ and their complementary types $coN$,
then states Theorem~1.3 for satisfiability: one conondeterministic random-access
machine of time $n^c$ and a separate deterministic random-access machine of
time $n^d$ and space $n^e$ cannot coexist in the stated strict parameter
region \cite[Sec.~2.2, Thm.~1.3]{vm}.  The theorem does not ask for an
existentially accepted UNSAT proof object.  Such an object is useful only
through the exact language-complement construction proved below.  Machine time
is a bound on the computation, hence on every nondeterministic path, not on a
chosen successful path.

\section*{Exact polarity-and-clock theorem}
Fix a proof-length bound $g(n)$.  Let $V(F,\pi)\in\{0,1\}$ be a deterministic,
total verifier for every $F$ and every $\pi\in\{0,1\}^{g(|F|)}$.  Malformed
records are ordinary strings in this universe.  Let
\[
T_V(n)=\max_{|F|=n}\max_{|\pi|=g(n)}T_V(F,\pi),
\]
including parsing, source access, proof access, verification, and the explicit
clock.

\begin{theorem}[POLARITY-CLOCK160, \status{PROVED/EXACT}]
The following are equivalent.
\begin{enumerate}
\item $V$ is an existential UNSAT verifier:
\[
 \forall F\quad F\in\UNSAT\iff\exists\pi\ V(F,\pi)=1.
 \tag{1}
\]
\item The branch machine $C(F,\pi)=1-V(F,\pi)$ is a conondeterministic SAT
decider:
\[
 \forall F\quad F\in\SAT\iff\forall\pi\ C(F,\pi)=1.
 \tag{2}
\]
\end{enumerate}
Moreover $C$ has the same worst-branch time and peak space as $V$ up to the
constant final-bit flip.  Thus a rejected malformed record or verifier timeout
for $V$ becomes an accepting branch for $C$.
\end{theorem}
\begin{proof}
Complement (1):
\[
F\in\SAT
\iff\neg\exists\pi\,[V(F,\pi)=1]
\iff\forall\pi\,[V(F,\pi)=0]
\iff\forall\pi\,[C(F,\pi)=1].
\]
The converse is the same calculation backwards.  The machines have identical
executions until a constant-time final output flip, so maxima over all branches
and peak simultaneously live storage are unchanged.  Totality is necessary:
a nonhalting timeout branch is neither a bounded reject of $V$ nor a bounded
accept of $C$.
\end{proof}

\paragraph{Correct timeout convention.}
Implement a branch-independent clock.  At expiration, $V$ halts and rejects;
the complemented machine halts and accepts.  A verifier that instead rejects
timeouts on both sides fails (2) on every SAT input possessing such a branch.

\section*{Best-proof time is not NTIME}
Define the successful-proof cost
\[
B_V(F)=\min_{\pi:V(F,\pi)=1}T_V(F,\pi)
\]
when an accepting proof exists.  This is not the resource used by NTIME.

\begin{lemma}[Slow-invalid wrapper, \status{PROVED/EXACT}]
For any total existential verifier $V$ whose proof alphabet contains a
designated invalid record and any total time function $h(n)$, there is a
verifier $V_h$ for the same language such that every old valid accepting proof
has unchanged cost, while
\[
T_{V_h}(n)\ge h(n).
\]
\end{lemma}
\begin{proof}
On the designated invalid record, perform exactly $h(n)$ dummy steps and
reject.  On every other record simulate $V$.  No new accepting proof is
created and none is removed, so the existential language is unchanged.  The
maximum over branches is at least $h(n)$.
\end{proof}
Taking $h(n)=2^n$ gives a verifier with a linear-time valid proof on selected
UNSAT inputs and exponential nondeterministic time.  Therefore a certificate
ledger based on $\min_{\pi\text{ accepts}}T(F,\pi)$ cannot instantiate the
conondeterministic $n^c$ premise.

\section*{Application to current certificate candidates}
The Role-3 backdoor/SCC theorem is sound in its stated restricted form.  Given
$B$, it deterministically enumerates all $2^{|B|}$ assignments and accepts iff
the source is UNSAT.  If a nondeterministic machine guesses $B$, the exact
Theorem~1.3 route is:
\[
\exists B\ V_{\rm UNSAT}(F,B)=1
\quad\stackrel{\text{flip every branch}}{\Longrightarrow}\quad
\forall B\ C_{\rm SAT}(F,B)=1.
\]
But the time exponent is controlled by the largest allowed guessed $B$, not
the smallest accepting backdoor.  Allowing $|B|=n$ ensures completeness but
gives exponential worst-branch time.  Restricting $|B|\le k(N)$ can give a
polynomial clock only after proving every UNSAT input has an accepting proof
within that restriction.  That bounded all-UNSAT coverage theorem remains
\status{OPEN}.

The same correction applies to adaptive proof DAGs.  All malformed nodes,
cyclic ranks, bad source names, failed strategies, cache misses, and timeout
paths must halt within the claimed $N^{c+o(1)}$ bound.  One may reject them in
the existential UNSAT verifier, but the conondeterministic SAT machine accepts
those complemented branches.  Neither branch may be left uncharged.

for P versus NP.  Algebraic access likewise does not change the quantifiers.

\section*{Single next target}
Prove or falsify one explicit bounded-coverage theorem:
there exist a uniform proof-length bound $g(N)$ and a total verifier $V$ such
that every UNSAT ordinary input has an accepting proof, every SAT input has
none, and \emph{every} record of length $g(N)$---valid or malformed---halts
within $N^{c+o(1)}$ time and the claimed peak space, with $c$ inside the strict
