\section{Falsifiers fixed before source inspection}
\begin{enumerate}
\item Query addresses might carry uncharged nondeterministic information.
\item A cap written only as $(a+o(1))\log N$ might not define a uniform abort
threshold.
\item Per-seed answer strings might be mutually incompatible even when every
seed has an accepting transcript.
\item Reset tags, address dictionaries, and threshold counters might exceed
the asserted simultaneous space.
\end{enumerate}
The first is false when an address is a deterministic function of the source,
public seed, charged state, and earlier stable answers.  The second is a real
uniformity qualification.  The third is exactly why all seeds must share one
physical map.  The fourth contributes only polylogarithmic factors in the
subpolynomial-space cosine regime, provided address width is charged.

\section{Exact model and corrected theorem}
Fix one total uniform deterministic indexed random-access verifier
$V(F,\pi,z)$.  The proof is immutable and binary.  Its physical address
register is part of charged workspace; the public seed set has size
$R(N)\le N^{\rho+o(1)}$; every seed run has time
$\tau(N)\le N^{v+o(1)}$ and workspace $S(N)\le N^{s+o(1)}$ on the same
machine.  For constants $0\le\sigma<c\le1$ assume
\[
 \forall F\in\SAT\ \forall\pi:\ A(F,\pi)\le\sigma R,
 \qquad
 \forall F\in\UNSAT\ \exists\pi:\ A(F,\pi)\ge cR,                 \tag{1}
\]
where $A(F,\pi)=\sum_zV(F,\pi,z)$.  Each run is uniformly clocked;
malformed proofs and timeouts reject.  A physical cell returns the same bit
on every repeated read, across all seeds and hereditary children.

\begin{theorem}[Adaptive physical-map enumeration]
Let $\widehat q(N)$ be a public total computable cap.  Suppose every ordinary
$\UNSAT$ source has a proof satisfying (1) whose all-seed physical query union
has size at most $\widehat q(N)$.  Then one uniform deterministic total decider
exists with
\[
 T=O\!\left(2^{\widehat q}R\tau\,
       \operatorname{poly}(\widehat q,A_N,\log R)\right),\qquad
 S=O\!\left(S+\widehat q(A_N+1)+\log R\right),                    \tag{2}
\]
where $A_N$ is the charged maximum bit width of a proof address.  If nominal
proof length is polynomial then $A_N=O(\log N)$.
\end{theorem}
\begin{proof}
Run all seeds sequentially and compare the integer acceptance counter with
$k_N=\lfloor\sigma R\rfloor+1$.  Whenever the master run first reads physical
address $u$, branch on its bit and store $(u,b)$; a later read of $u$ receives
the stored bit.  Abort upon the $(\widehat q+1)$st distinct address.  This is
a binary decision tree of first reads, of depth at most $\widehat q$ and hence
at most $2^{\widehat q}$ leaves.  Rerunning the deterministic master from its
start for each leaf costs (2), including address comparisons and resets.

Every accepting leaf is a consistent partial physical proof and extends
arbitrarily to a full immutable proof.  SAT soundness in (1) therefore rules
it out.  On UNSAT, the promised proof selects one nonaborted branch and its
count is at least $cR>\sigma R$, so the branch accepts.  Flipping the final
bit decides SAT with identical resources.  Exact physical keys handle aliases;
addresses themselves add no guessed entropy because they are deterministic
outputs of the charged execution.
\end{proof}

\begin{theorem}[Effective-cap repair of ARC201]
If a public computable cap obeys
$\widehat q(N)\le(a+o(1))\log_2N$, ARC201's one-machine bound follows:
\[
T=N^{\max\{1,\rho+v+a\}+o(1)},\qquad S=N^{s+o(1)}.                \tag{3}
\]
If instead one knows only the existential witness statement
$Q_{\rm all}\le(a+o(1))\log_2N$, then for every fixed $\delta>0$ there exists
a uniform total $D_\delta$ with
\[
T_{D_\delta}=N^{\max\{1,\rho+v+a+\delta\}+o(1)},
\qquad S_{D_\delta}=N^{s+o(1)}.                                  \tag{4}
\]
Consequently, when $s=o(1)$, Williams' theorem still implies
$\rho+v+a\ge2\cos(\pi/7)$.
\end{theorem}
\begin{proof}
The effective case is (2).  For the bare asymptotic statement and fixed
$\delta$, there is an $N_0$ after which the witness union is at most
$(a+\delta)\log_2N$.  Hard-code the finite truth table for strings of length
below $N_0$ and use the computable cap
$\lceil(a+\delta)\log_2N\rceil$ thereafter.  This is one finite uniform
program for that $\delta$ and yields (4).  If
$\rho+v+a<\gamma=2\cos(\pi/7)$, choose $\delta>0$ smaller than the strict
gap; (4) contradicts the native subpolynomial-space SAT lower bound.

A single generic vanishing slack cannot repair (3): for any chosen
$d(N)\downarrow0$ with $0<d(N)<1$, the hidden rate $\sqrt{d(N)}$ also tends to
zero but exceeds $d(N)$.  Thus the public-cap hypothesis is genuinely needed
for the exact one-machine $o(1)$ display, even though it is unnecessary for
the limiting necessary inequality.
\end{proof}
