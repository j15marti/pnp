\section{Declared elementary model and vector ledger}

Fix an input $x$ and a fixed uniform program $M$.  The input is read-only.  Every mutable work, address, head, and finite-control bit is represented injectively in a canonical complete writable state; a compound update is decomposed into elementary bit events.  Program size and generated-representation size are separately recorded.  An operation that writes an already present value is still a write and still costs work.

For a terminating execution with $U$ elementary charged operations and configurations $C_0,\ldots,C_U$, record
\[
 \mathcal L(M,x)=
 (U,R_{\rm src},R_{\rm work},W_{\rm work},\Delta,S,BT,P_{\rm rep}),
\]
where $\Delta=\sum_i d_H(C_i,C_{i+1})$ counts actual complete-state flips, $B_i$ is the number of live writable bits after event $i$, $S=\max_iB_i$, and $BT=\sum_iB_i$.  Source/workspace reads, unchanged writes, addressing, selection, failed trials, conversion, cache operations, child generation, and rule switching all contribute to $U$.  This is an accounting vector, not a scalar hardness measure.

If each elementary event changes at most one encoded state bit, then
\[
 \Delta\le W_{\rm work}\le U,
 \qquad S\le BT\le(U+1)S.
\]
The first inequality does not identify writes with flips: unchanged writes contribute to $W_{\rm work}$ but not $\Delta$.  A source read can change address or control bits even when an algorithmic accumulator does not flip.

\section{Exact schedule bridge}

\begin{lemma}[online schedule simulation]
Suppose a uniform online controller produces a bounded-fan-in evaluation schedule using identifiers of $O(\log N)$ bits.  On length-$N$ inputs it performs $A_T(N)$ generation work, emits $L(N)$ evaluation/access commands, keeps at most $P(N)$ Boolean values live, and uses $A_S(N)$ generator-state bits.  Then the same uniform random-access machine can evaluate the schedule in
\[
 T(N)=\widetilde O(A_T(N)+L(N)+1),\qquad
 S(N)=\widetilde O(A_S(N)+P(N)+1).
\]
\end{lemma}

\begin{proof}
Each command, operand identifier, or source access costs polylogarithmic overhead in the declared random-access simulation.  The live table contains at most $P$ values and their identifiers; the generator state contains $A_S$ bits.  The controller is fixed and uniform.  Summing commands and generator work gives time, while simultaneously live generator and value-table storage gives space.  Conversion buffers and headers are included in the soft factors.  The argument supplies neither a schedule nor all-input SAT correctness.
\end{proof}

Thus if $A_T=N^{\gamma+o(1)}$, $L=N^{\ell+o(1)}$, $A_S=N^{\sigma+o(1)}$, and $P=N^{p+o(1)}$, then any $c>\max\{1,\gamma,\ell\}$ with $\max\{\sigma,p\}<\beta(c)$ would land in the quoted FLMV-forbidden box.  This is a valid receiving test, not the missing constructor.

\section{Global potential ceiling}

\begin{theorem}[Hamming-Lipschitz ceiling]
Fix an input and program and encode every complete writable state in $\bits^B$ (padding unused cells canonically).  If $\Phi:\bits^B\to\mathbb R$ satisfies
\[
 |\Phi(u)-\Phi(v)|\le Ld_H(u,v)
 \quad\text{for all }u,v,
\]
then
\[
 \max\Phi-\min\Phi\le LB.
\]
Consequently, a lower bound obtained solely as endpoint potential gap divided by the maximum $L$ change per one-bit transition is at most $B$.
\end{theorem}

\begin{proof}
The Hamming diameter of $\bits^B$ is $B$.  For states attaining the maximum and minimum,
\[
 \max\Phi-\min\Phi\le Ld_H(u,v)\le LB.
\]
If every elementary legal transition changes at most one encoded bit, its potential change is at most $L$.  Dividing any endpoint gap by $L$ therefore yields at most $B$ transitions.  This bounds the proof template, not the running time of an arbitrary computation, which may revisit states or follow a much longer legal path.
\end{proof}

The repair options are sharply delimited: prove a long-path or bottleneck property of the \emph{legal} transition graph; independently force a large complete representation; or use a history-sensitive/non-global potential while charging the history, recomputation, and transition selection.  Defining the potential from the unknown optimal remaining running time would be circular.

\section{Hostile controls and adaptive-state ledger}

\paragraph{Parity-chain control.}
Take $z_0=z_q=0$ and constraints $z_i=z_{i-1}\oplus b_i$.  All-zero $b$ is SAT; changing one bit makes the chosen odd-parity control UNSAT.  A streaming parity algorithm reads all $q$ source bits on the hard all-zero input while its accumulator flips zero times; on the single-one control it flips once.  Finite tests used $q=1,2,\ldots,4096$ and included 13 SAT and 13 UNSAT cases.  This separates source acquisition from accumulator flips.  It does not claim zero complete-state flips, because addresses and control also move.

\paragraph{Quiescent child reuse.}
For a valid supplied scoped CNF event stream, a block body and FORCE gadgets can be materialized once and boundary assignments can be traversed in Gray order.  Exactly four target sign fields change per Gray transition.  The independently reviewed construction obtained
\[
 T\le\widetilde O(N+Q+QT_A(L_{\max})),\qquad
 S\le\widetilde O(b+2^\omega+S_A(L_{\max})),
\]
and $W_{\rm gen}\le\widetilde O(N+Q)$.  Its 400-instance audit (386 SAT, 14 UNSAT) matched rebuild and reuse decisions.  Nevertheless $W_{\rm gen}$ excludes solver and parent writes, and the four target flips exclude controller/address/solver state.  It is not a total write or complete-state-flip exponent.

\paragraph{Circuit-energy warning.}
The energy complexity of a circuit counts gates outputting one on an input, not temporal complete-state flips of a uniform decider.  Dinesh--Otiv--Sarma show that every Boolean function has linear energy if exponentially large circuits are permitted.  Therefore active-gate energy cannot be imported as a temporal lower bound while hardware/representation size is omitted.
