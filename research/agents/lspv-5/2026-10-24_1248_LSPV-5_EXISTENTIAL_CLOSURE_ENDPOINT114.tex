\section{Question audited and exact model}
The current spine proposes a simultaneous time--space contraction for SAT and
then invokes Fortnow--Lipton--van Melkebeek--Viglas (FLMV).  The relevant
machine is the random-access multitape Turing machine used by FLMV: an indexed
read-only input tape, counted work and index tapes, and an uncounted write-only
output tape.  Fix one ordinary SAT encoding.  Let $\E$ be the set of pairs
$(t,s)$ for which there exists \emph{one fixed} total uniform exact SAT decider
$A_{t,s}$, correct on every encoded input, with simultaneous bounds
\[
 T_{A_{t,s}}(N)\le N^{t+o(1)},\qquad
 S_{A_{t,s}}(N)\le N^{s+o(1)}.
\]
Each pair is a same-realization statement.  Different pairs need not have the
same witnessing program.  The exponent pair is an analysis object and need not
be known to, or computable by, the witnessing machine.

FLMV Theorem 3.1 states, in this model, that a simultaneous SAT algorithm with
time $t(N)$ and space $s(N)$ yields for every language in $\mathrm{NTIME}[n]$
a deterministic simulation with the corresponding polylogarithmic inflation.
FLMV Corollary 5.8 states
\[
 \mathrm{NTIME}[n]\not\subseteq
 \mathrm{DTISP}\bigl[n^c,o(n^{d(c)})\bigr],\qquad
 d(c)=\frac12\left(\frac{c+2}{c^2}-c\right),
\]
for the stated range of $c$.  These are model-specific, not model-free,
claims.  The primary source is
\url{https://lance.fortnow.com/papers/files/tst.pdf}.

\section{The exact endpoint theorem}
Put
\[
 f(t)=\max\left\{\frac{11}{10},\frac35+\frac t2\right\},
 \qquad
 g(s)=\max\left\{\frac12,\frac s2\right\}.
\]

\begin{theorem}[EXISTENTIAL-CLOSURE-ENDPOINT114]
Assume:
\begin{enumerate}
\item $P=NP$ implies $\E\ne\varnothing$; and
\item for every $(t,s)\in\E$ there exists $(t',s')\in\E$ satisfying
      $t'\le f(t)$ and $s'\le g(s)$.
\end{enumerate}
Then $P\ne NP$.
\end{theorem}

\begin{proof}
Suppose $P=NP$.  A uniform polynomial-time SAT decider in the matched model
uses at most its running time in work space, so some finite $(t_0,s_0)$ lies in
$\E$.  Repeated finite use of existential closure gives pairs
$(t_j,s_j)\in\E$.  No effective selector is used here: for each already chosen
finite witness, ordinary existential instantiation chooses a successor witness.

The affine branch has fixed point $6/5$, while the other branch is lower, and
hence
\[
 f(t)\le \frac65+\frac12\left(t-\frac65\right)_+.
\]
Induction gives
\[
 t_r\le \frac65+2^{-r}\left(t_0-\frac65\right)_+,
 \qquad
 s_r\le \max\left\{\frac12,2^{-r}s_0\right\}.
\]
Choose finite $r$ so that
\[
 2^{-r}\left(t_0-\frac65\right)_+<\frac1{200},
 \qquad 2^{-r}s_0\le\frac12.
\]
Then the same terminal machine witnesses
$t_r<241/200$ and $s_r\le1/2$.

At $c_*=241/200$, exact arithmetic gives
\[
 d(c_*)=\frac{11642479}{23232400}
 =\frac12+\frac{26279}{23232400}>\frac12.
\]
The strict time slack absorbs the polylogarithmic overhead in FLMV Theorem 3.1,
and $n^{1/2+o(1)}=o(n^{d(c_*)})$.  The terminal same-realization algorithm
would therefore put all of $\mathrm{NTIME}[n]$ in the class forbidden by FLMV
Corollary 5.8, a contradiction.
\end{proof}

\paragraph{Quantifier consequence.}
The sufficient statement is closure of the achievable set $\E$.  It does
\emph{not} logically require a computable program transformer, discovery of
$t$ or $s$, a universal selector, or preservation of one program identity over
all iterations.  Those are extra obligations only for a proposed proof that
uses them.  The all-input, uniform, exact, joint-resource, matched-model
requirements remain indispensable at every point of $\E$.
