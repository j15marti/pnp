\section{PROPOSE: falsifiers fixed before search}
The current missing lemma is a uniform polynomial-cost moving-summary
construction for arbitrary ordinary SAT, with closed physical re-entry and a
single child of length at most $N^\lambda$. Before inspecting the new peer
sources, this run fixed four attacks:
\begin{enumerate}
\item a same-sign cyclic splice may preserve exact occurrence counts and
connectedness while changing satisfiability;
\item the U/S selector may expose the answer class rather than being decided by
one uniform program;
\item a connected two-answer family assembled from one constant gadget may
still have a constant-state transfer algorithm and hence say nothing about
arbitrary-SAT hardness;
\item a streamed verifier may omit source-head replay, address generation,
or physical child storage, and the term Pareto may overstate two upper
construction points as an optimal frontier.
\end{enumerate}

\section{BUILD I: corrected fixed-module transfer theorem}
Let a cyclic source contain $k$ modules. Each module has $p$ private Boolean
variables, two boundary tuples of $b$ variables, and at most $c$ clauses. No
clause joins nonadjacent modules. For module $i$, define its exact relation
\[
 R_i(a,d)=
 [\exists z_i\in\{0,1\}^p\ M_i(a,d,z_i)],
 \qquad a,d\in\{0,1\}^b.
\]
\begin{theorem}[Fixed-module exact transfer]
For fixed $p,b,c$, one uniform deterministic program decides every canonical
source in this ring grammar in
\[
 O\!\left(kc2^{p+2b}+k2^{3b}\right)
\]
Boolean operations, plus charged source parsing and numeric-index costs. It
uses $2^{2b}$ relation bits per explicit layer if a full trace is retained,
and $O(2^{2b})$ live transfer bits if only the decision is required.
\end{theorem}
\begin{proof}
For each of the $2^{2b}$ boundary pairs, enumerate all $2^p$ private
assignments and check at most $c$ clauses. This computes the complete
relation, including all failed candidates. Boolean composition of two
$2^b\times2^b$ relations costs $O(2^{3b})$. Associativity and the cyclic
diagonal condition give exact SAT and UNSAT correctness. A SAT path recovers
one private witness per selected pair; an UNSAT trace is checked by
recomputing the same relations from authenticated source clauses. Both
answers are produced by one program, so no side bit is free.
\end{proof}

For W1-RING149, $p=14$, $b=1$, and $c=20$. Direct enumeration independently
gives
\[
 R_U=0100_2,\qquad R_S=1111_2.
\]
Thus $U$ permits only $(1,0)$ and $S$ permits every pair. Every cyclic U/S
word is satisfiable iff it contains no adjacent U pair. This proves both
answers on identical scopes, while also showing why the family is easy:
its private width is fixed forever. With canonical physical length
$N=\Theta(k\log k)$, the program runs in polynomial bit time. After deciding
the promise class it may output a fixed SAT base or the fixed W1 UNSAT base.
That is a genuine restricted single-child shrinker, but the class does not
contain arbitrary SAT.

\section{BUILD II: an explicit splice falsifier}
For distinct padding variables $r,s$, define the proper-3CNF unit gadget
\[
 \operatorname{Force}_1(v;r,s)=
 \bigwedge_{\epsilon,\delta\in\{+,-\}}
 (v\vee \epsilon r\vee\delta s),
 \qquad
 \operatorname{Force}_0(v;r,s)=
 \operatorname{Force}_1(\neg v;r,s).
\]
Let
\begin{align*}
 A&=\operatorname{Force}_0(a;p,q)\wedge
    \operatorname{Force}_0(b;r,s)\wedge(x\vee a\vee b),\\
 B&=\operatorname{Force}_0(y;u,v)\wedge
    \operatorname{Force}_1(e;w,t)\wedge(y\vee e\vee f).
\end{align*}
$A\wedge B$ is satisfiable with $x=e=1$ and $a=b=y=0$. Swap the two
\emph{positive} occurrences $x$ and $y$ in the displayed final clauses. The
new first clause is $(y\vee a\vee b)$, which is false under three forced
zeros, so the switched conjunction is UNSAT. The second switched clause
$(x\vee e\vee f)$ is harmless. All 18 clauses remain proper ternary
clauses, and the complete signed occurrence multiset of every variable is
unchanged.
\begin{proposition}[Occurrence-switch firewall]
Same-sign occurrence switching, even when it preserves every signed degree
and joins two components, is not an answer-preserving transformation on
proper 3CNF.
\end{proposition}
The counterexample is not exact-$(2,2)$, so it does not refute the exact
W1-ring theorem. It does refute any attempted arbitrary-CNF promotion based
only on occurrence quotas, connectedness, or the label \emph{splice}. The W1
construction survives because it recomputes the exact post-splice relations.

\section{BUILD III: certificates and answer-side query costs}
The supplied Resolution checker reads actual CNF source bytes, uses original
source clause IDs, validates every pivot and parent, and derives the empty
clause. It accepted 76 W1 rows and 168 ring-8 rows. This is
\textbf{PROVED/EXACT finite verification} by an independently inspected
checker, not kernel verification and not a theorem that arbitrary UNSAT has a
short proof.

Fix odd ring positions to U and allow $m$ even positions to be U or S. The
answer is SAT exactly when all $m$ variable positions are S. The all-S input
forces any deterministic block-query tree to query every position. Replacing
the last queried S by U preserves the transcript until the final query and
gives an UNSAT input with the same cost. The report's same-program,
both-answer-side depth-$m$ claim is therefore upheld in this restricted oracle
model. It is only input sensitivity: a linear scan attains the bound.

\section{STREAM-REPLAY-PARETO211 referee result}
The peer reproducer reran 88 canonical relation-chain cases, 166 tamper
rejections, 24 brute path comparisons, and 272 width-four/eight translation
truth assignments. Its $m=256$ control produced four child matrices and
charged 4,823,589 source-head moves. The mathematical upper constructions are
consistent with the code:
\[
\begin{array}{c|c|c}
\text{native fixed-$k$ RO-input model}&T&S\\\hline
\text{store-stream}&O(N\log^2N)&O(N)\\
\text{compact replay}&O(N^2\log^2N)&O(N^{1/4}\log N).
\end{array}
\]
The second bound includes repeated source-head travel and the physical child.
It does not include a free row-offset table. The child grammar is closed and
has $O(N^{1/4}\log N)$ bits.

\textbf{Scope correction.} Two incomparable achievable points are not an
optimal Pareto frontier. No matching lower bound excludes intermediate
implementations, and this restricted class can be decided directly and
replaced by a fixed answer base. Hence Pareto is descriptive only; any
optimality reading is \textbf{FALSIFIED/RETIRED}. The implementation remains
a valid restricted upper-construction witness.

\section{Separate machine ledgers}
\paragraph{Fixed-$k$ multitape, read-only input.}
The preceding upper bounds charge each source read, head movement, matrix
product, child bit, and live output cell. Input cells are not work space.
\paragraph{2-OFF: one read-only input and one work tape.}
Simulating a fixed number of work tapes by sweeps over one encoded work tape
gives conservative polynomial upper bounds. For the two displayed points the
peer bounds $O(N^2\operatorname{polylog}N),O(N)$ and
$O(N^{9/4}\operatorname{polylog}N),O(N^{1/4}\operatorname{polylog}N)$
are safe constructions, not lower bounds.
\paragraph{One read/write tape containing the input.}
The initial $N$ cells count in footprint. Applying the conservative simulation
\[
 T_1=O(T_k(N+S_k+\log(T_k+2))),\qquad
 P_1=O(N+S_k+\log(T_k+2))
\]
gives polynomial upper bounds only. No Hennie--Stearns two-tape result is
substituted, and no crossing lower bound is transferred in reverse.
\paragraph{Fixed universal machine and indexed RAM.}
A fixed interpreter incurs charged polynomial simulation overhead; no exact
exponent is asserted. An indexed RAM can scan the explicit source and compute
the same constant-width relations directly. Sequential-head travel penalties
are not RAM lower bounds.

\section{Hostile controls and barriers}
Bounded treewidth is an easy-family control: exact transfer is expected there.
Affine/XOR, Horn, 2-SAT, caching, BDD/SDD sharing, and direct decision can all
bypass explicit CNF projection growth. The occurrence-splice falsifier blocks
one syntactic shortcut but is not a runtime lower bound. A maximal semantic
oracle trivially returns each relation; removing that oracle reopens acquisition.
Algebraic access can cheaply summarize affine modules but does not cover an
arbitrary non-affine core. Padding and succinct circuits can change physical
size, so only the declared canonical grammar supports the reported recurrence.
No Natural-Proofs claim is used.

programming and must not be presented as new general complexity theory. It

\section{Single next target}
Increase private width with input length and demand one uniform constructor
whose charged relation acquisition, decomposition discovery, physical
re-entry, and second recursive level remain polynomial. Quantitatively, for
private width $p(N)$ and boundary width $b(N)$, the direct compiler pays
$2^{p+2b}$ candidates per module and stores $2^{2b}$ relation bits. The next
falsifiable target is an arbitrary-SAT decomposition with these costs and the
retained suffix simultaneously below one fixed $N^\lambda$ budget. A
polynomial-bit description of a rank or oracle table is not enough; its value
must decrease and every entry must be effectively computed.
