\section*{Reachable namespace theorem}
Let
\[
\mathcal N=\{[e_0,e_1,e_2]:e_i\in\mathbb Z_{\ge0},\ e_i\ne e_j\}.
\]
Let $\mathcal C_s$ be three-UTF-16-code-unit Strings whose iterator has three
distinct one-code-unit values, and let $\mathcal C_a$ be Arrays of three
distinct one-code-unit Strings.  Put
$\mathcal C=\mathcal C_s\cup\mathcal C_a$.

For parent supports $a,b$, the checker forms their SameValueZero union $U$
and accepts proposed support $s$ only when
\[
|U|\le3,\quad |s|=|U|,\quad |\mathrm{Set}(s)|=|U|,
\quad \forall x\in U:\ s.\mathrm{includes}(x).
\]
String \texttt{includes} uses substring membership after coercion; Array
\texttt{includes} uses SameValueZero.

\begin{theorem}[Independent /612 closure audit]
Starting in $\mathcal N$, every accepted AND3 support lies in
$\mathcal N\cup\mathcal C$.  The only transitions are
\[
\mathcal N+\mathcal N\to\mathcal N\text{ or }\mathcal C,\qquad
\mathcal C+\mathcal C\to\mathcal C.
\]
No mixed $\mathcal N+\mathcal C$ pair passes, and C cannot return to N.
\end{theorem}
For numeric parents, a three-entry output Array containing the union is its
permutation; a String can enter C through decimal-substring membership.
For character parents, cardinality and membership force an exact character
permutation.  Mixed types give six SameValueZero elements.  A valid surrogate
pair consumes two UTF-16 code units but one iterator element, so cannot meet
both cardinality tests.

Set $K(x)=\mathrm{String}(x)$.  If $s$ is the child support and $m$ its local
assignment, define $b_s(k,m)$ as the bit at the unique $j$ satisfying
$K(s_j)=k$, or zero if absent.  Parent $p$ is indexed by
\[
I_p(s,m)=\sum_i2^i b_s(K(p_i),m).
\]
\begin{lemma}[Reachable-key injectivity]
For every reachable $s\in\mathcal N\cup\mathcal C$, $K$ is injective on
$s$.  No reachable key is \texttt{length}, \texttt{\_\_proto\_\_}, or
\texttt{-0}.
\end{lemma}
Distinct nonnegative integers have distinct decimal Strings; distinct
one-code-unit Strings are distinct keys.  ASCII digit characters may address
Array indices, but remain distinct within the support.
