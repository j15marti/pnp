\section{Normalizer theorem and proof}

For a parsed packet $p$, and every non-array \texttt{deleted} container $D$
with integer $m=D.\texttt{length}\ge 0$, define
\[
  \alpha(D)=[D[0],D[1],\ldots,D[m-1]].
\]
Let $N(p)$ replace every such $D$ by $\alpha(D)$ and leave all other parsed
values unchanged.

\paragraph{Theorem 513.1.}
If the pinned checker accepts $p$, then it accepts $N(p)$ with byte-for-byte
identical stdout.  $N$ is idempotent.  It preserves the authenticated SOURCE,
goal, proof DAG and paid logical work.  For the compact serialization used by
the reproducer,
\[
 |\operatorname{JSON.stringify}(N(p))|
 \le |\operatorname{JSON.stringify}(p)|,
\]
with strict inequality whenever an observed container is a genuine JSON
object with explicit index keys and \texttt{length} rather than an array.

\paragraph{Proof.}
Acceptance forces $D.\texttt{length}$ to equal the source-clause count and every
$D[i]$ to satisfy exactly the same witness tests as the corresponding array
entry.  The source audit enumerates all reads of \texttt{deleted}; each read has
the same value after $N$.  No other field is altered, so every assertion and
the emitted JSON object are identical.  Arrays are fixed points, hence
$N^2=N$.  Compact arrays omit the object's explicit numeric member names,
colons and \texttt{length} member; ignored extra members are also removed.
Thus serialization cannot grow and is strictly shorter for the tested genuine
objects. \hfill$\square$

\paragraph{Restricted abstract interpretation.}
Take concrete states to retain the parsed container and abstract states to
retain only its length and ordered numeric member sequence.  Concrete-step
inclusion holds for every deletion-witness check because those are precisely
the observations made by the checker.  Accepted terminal preservation follows
from Theorem 513.1.  The abstract logical cost equals, hence does not exceed,
the concrete logical cost.  This is a complete quotient only for this field of
this checker; unknown historical transitions remain in conservative MAY.
