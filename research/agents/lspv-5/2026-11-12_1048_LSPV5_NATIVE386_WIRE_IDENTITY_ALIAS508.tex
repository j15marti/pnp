\section*{Restricted concrete semantics and cost-sound abstraction}
For this checker fragment, a concrete state is
\[
 C=(b,P,i,D,I,K,S,R,G),
\]
where $b$ is the raw byte string, $P=\operatorname{JSON.parse}(b)$, $i$ is the
record cursor, $D$ maps each parsed safe-integer output wire to its gate tuple
and signed clean facets, $I$ maps parsed safe-integer owner IDs to outputs,
$K$ is the chronological vector of already checked clauses, $S$ is the exact
seen-SOURCE set, and $R,G$ are paid Resolution and owner counts.  A transition
parses one gate or record, checks the source/facet/resolvent rule, signed literal
domain, parents and chronology, and advances the corresponding maps and
counters.  Acceptance additionally requires an empty last clause, all required
sources, and the exact summary $W=R+G$.

Define $\alpha(C)$ by discarding raw numeric lexemes but retaining: every
\emph{parsed safe integer} wire and owner; signed clause polarity; the exact
gate dependency order and declared-output set; chronological parent indices;
SOURCE provenance; the terminal flag; and $(R,G,W)$.  On the authenticated
SOURCE/DEF/RES subset, inspection of every checker branch proves the restricted
simulation lemma
\[
 C\to C'\quad\Longrightarrow\quad \alpha(C)\to^{\#}\alpha(C'),
 \qquad W^{\#}(\alpha(C'))=W(C').
\]
All accepting final concrete states map to abstract states retaining the empty
sink and exact source/summary obligations.  Therefore completed-refutation
preservation and abstract cost no greater than concrete cost hold here with
equality.  This proof does \emph{not} cover absent AND3, GF(2), LOCAL-CONVERT,
branching, weakening, contexts, discharge, joins, deletion, or a unified
historical dispatcher.

The accepted hostile proves that wire identity in this executable is an
identity class of parsed safe integers, not raw token identity.  If a canonical
raw grammar is intended, it must lex and bind canonical number tokens before
JSON Number coercion.  That would define a repaired language; it is not a
verdict-preserving refinement of the archived checker.

\section*{Primary-source and transfer audit}
ECMAScript specifies that JSON parsing returns Number values and that Map keys
use parsed value equality; safe integers are the integers with unique Number
representations.  See
\url{https://tc39.es/ecma262/2024/multipage/structured-data.html} and
\url{https://tc39.es/ecma262/2024/}.  RFC 8259 defines the broader JSON number
syntax and identifies the interoperable exact integer range
$[-(2^{53})+1,2^{53}-1]$:
\url{https://www.rfc-editor.org/rfc/rfc8259.html}.  JSON Canonicalization Scheme
RFC 8785 is a relevant encoding repair, not evidence that the archived checker
already enforces canonical bytes:
\url{https://www.rfc-editor.org/rfc/rfc8785.html}.

The concrete/abstract obligation follows the original abstract-interpretation
discipline of Cousot and Cousot, POPL 1977,
\url{https://cs.nyu.edu/~pcousot/COUSOTpapers/POPL77.shtml}.  The replay policy
follows Clarke--Grumberg--Jha--Lu--Veith CEGAR: a real counterexample is retained,
while only an invalid concretization licenses refinement.  These methods
transfer directly at the semantic level; none supplies a proof-complexity lower
bound.  Knot/link reductions and the SIL/M22 ladder remain structural analogies
or exact restricted rewrites, not native-calculus or machine lower bounds.
