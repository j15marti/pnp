\section{The anytime geometric-block theorem}
Let $G$ be one fixed deterministic total transducer.  On a particular input it
emits $M\ge1$ self-delimited scoped records in order and then an explicit EOF.
Each record has $N^{o(1)}$ bits; all output production, source reads, gaps
between emissions and EOF work are included in $G$'s time.  No bound on $M$,
no exponent $\mu$, and no output-count header is available to the consumer.

Number records starting at one.  Epoch $k\ge0$ contains positions
\[
I_k=[2^k,2^{k+1}-1].
\]
Within epoch $k$, start a new block after
\[
b_k=\left\lceil2^{k/2}\right\rceil
\]
records, and forcibly close any nonempty current block at the epoch boundary.
EOF closes the last partial block.  Both $k$ and the seen-record counter are
ordinary charged binary registers.

\begin{theorem}[Anytime balanced stream partition]\label{th:anytime}
For every finite stream of $M\ge1$ records, the algorithm above is one-pass,
uses no replay and no future-length information, and creates contiguous blocks
$B_1,\ldots,B_q$ satisfying
\[
\boxed{\max_i|B_i|\le\sqrt M+1},                            \tag{1}
\]
\[
\boxed{q\le(2+\sqrt2)\sqrt M+\lfloor\log_2M\rfloor+1}.     \tag{2}
\]
Its scheduling state uses $O(\log(M+2))$ live bits and
$O(M\operatorname{polylog}(M+2))$ charged bit work.  If
$M=N^{\mu+o(1)}$ for analysis, although the program does not know $\mu$, both
the maximum block and number of blocks are $N^{\mu/2+o(1)}$.
\end{theorem}
\begin{proof}
Let $K=\lfloor\log_2M\rfloor$.  Every record is consumed once and belongs to
exactly one epoch and block.  A block in epoch $k\le K$ has at most
$b_k\le 2^{k/2}+1\le\sqrt M+1$, proving (1).  If $L_k\le2^k$ records of the
stream lie in epoch $k$, the epoch contributes at most
\[
\left\lceil\frac{L_k}{b_k}\right\rceil
\le 2^{k/2}+1
\]
blocks.  Therefore
\[
q\le\sum_{k=0}^{K}(2^{k/2}+1)
=\frac{2^{(K+1)/2}-1}{\sqrt2-1}+K+1
\le(2+\sqrt2)\sqrt M+K+1,
\]
which is (2).  The consumer increments a binary counter, detects powers of
two, and maintains $b_k$ by shifts and one parity bit.  These operations have
polylogarithmic bit cost and $O(\log M)$ state.  Taking logarithms of (1)--(2)
gives the exponent statement.  The empty stream is the separate constant case.
\end{proof}

The online-learning ``doubling trick'' is a useful analogy for removing an
unknown horizon, but its regret/restart theorems do not prove
Theorem~\ref{th:anytime}; the displayed geometric sum is the direct
model-matched proof.  In particular this construction does \emph{not} restart
$G$ between epochs.

\section{Scoped semantics survive arbitrary epoch boundaries}
At the start of a block, record the currently live source-name set $L$; after
its last record, record the live set $R$.  Enumerate assignments to $L,R$ and
create the same fully serialized ordinary children as FUSION164.  A boundary
can occur after any complete record: the invariant ``every name is opened at
its first occurrence and closed at its last'' makes $L,R$ exact regardless of
why the boundary was chosen.

\begin{lemma}[Partition-oblivious exact join]\label{lem:join}
For every contiguous partition of a valid closed scoped stream, composing the
per-block boundary relations in order accepts exactly when the original CNF is
satisfiable.  The statement holds on both SAT and UNSAT inputs and for the
geometric partition of Theorem~\ref{th:anytime}.
\end{lemma}
\begin{proof}
If a global satisfying assignment exists, its restrictions to successive live
boundaries give a compatible accepting path.  Conversely, compatible accepting
block assignments agree on every name shared across a boundary.  A name's live
interval intersects every intervening boundary, so the block assignments glue
to one assignment satisfying every clause.  The proof uses neither block size
nor knowledge of the final record count.
\end{proof}

At fixed recursive depth, apply the same online scheduler independently to each
ordinary child stream.  While a child is processed, cooperative suspension
retains the parent's full producer configuration, block state and $O(\log M)$
counter.  A fixed number of such states adds bit counts but does not change the
largest exponent.  Names, ordinary child headers/bodies, source access,
validation, guest calls, caches, compatibility and ancestors remain charged.
