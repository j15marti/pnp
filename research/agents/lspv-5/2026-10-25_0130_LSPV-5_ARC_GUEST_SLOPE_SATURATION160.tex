\section{Claim, quantifiers, and pre-search falsifiers}
Let $E$ denote pairs $(t,s)$ achieved \emph{simultaneously by one fixed}
uniform deterministic total exact ordinary-$\SAT$ decider, correct on \emph{all}
encoded inputs of length $N$, in the indexed read-only-input random-access
Turing-machine model of Fortnow--Lipton--van Melkebeek--Viglas (FLMV)
\cite{flmv}. Under $P=NP$ some fixed finite diagonal $(K,K)\in E$ exists.
A fully charged finite route from cofinally many achievable integer diagonals
into the strict box
\[
 t< c_0=\frac{241}{200},\quad
 s<d_0=\beta(c_0)=\frac{11642479}{23232400},\quad
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right)
\]
would contradict FLMV by its SAT transfer. Existence of such a route is
\OPEN{}. The old $t+s<2\cos(\pi/7)$ landing is RETIRED, not an alternate
universal endpoint. Finite routes may be existential and depend on a fixed
$K$; a universal source compiler is not logically necessary.

Four falsifiable claims were registered before targeted literature and project
source review:
\begin{enumerate}
\item An extra $N^{\varepsilon}$ completed guest calls at the nominal
leaf length can be absorbed by a fixed-depth favorable affine recurrence.
\textbf{FALSIFIED for actual padded-guest execution.}
\item A guest call at a power-larger leaf size can fit for all polynomial
base exponents if the controller changes adaptively. \textbf{FALSIFIED when
its claimed size exponent stays uniformly above the product shrinkage.}
\item Keeping a full frontier of independent guest work tapes can still meet
the claimed simultaneous successor space. \textbf{FALSIFIED for the literal
all-live policy on space-padded guests.}
\item These restrictions rule out an A-dependent existential or code-aware
all-input ARC successor. \textbf{REJECTED}: that much stronger inference is
not proved by the actual-call premise.
\end{enumerate}

\section{Padded polynomial guest family and machine semantics}
This section is conditional on $P=NP$ only to obtain one unknown fixed
uniform polynomial-time, polynomial-space ordinary-$\SAT$ decider $B$ with
joint finite exponents $(K_0,S_0)$. For any fixed integers
$D>\max\{K_0,S_0,2\}$ and $S\in[S_0,D]$, construct a genuine uniform total
exact guest $A_{D,S}$ which: (i) initializes $\lceil n^S\rceil$ writable/index
cells, (ii) retains them and performs at least $n^D$ \emph{charged}
input-independent machine steps, then (iii) executes $B$ and returns its
one-bit answer. A fixed-code counter adds at most polylogarithmic overhead.
Hence it has joint upper exponents $(D,S)$ and an actual guest execution on
\emph{every} ordinary $n$-bit query takes $n^{D-o(1)}$ time. During the delay
it occupies $n^{S-o(1)}$ bits for $n^{D-o(1)}$ steps. Its answer remains
correct on SAT, UNSAT, and malformed inputs.

No one is forced to run that slow code. A compiler may inspect and remove
its syntactic padding or choose an entirely different SAT algorithm. The
bounds below therefore apply only to procedures that \emph{actually execute
and await} the specified padded guest, charging its steps, with the additional
simultaneously-live premise only where explicitly stated. Distinguish these
implementation-level cost statements from existential membership in $E$.

\section{General affine guest-work frontier}
Fix a finite depth $d$ independent of input length. At stage $i$ use a
numerically proposed time map $q_i(t)=a_i+\lambda_i t$ with
$a_i\ge0$ and $0<\lambda_i<1$. Define
\[
 \Lambda_d=\prod_{i=1}^d\lambda_i,\qquad
 B_d=\sum_{i=1}^d a_i\prod_{j<i}\lambda_j.
\]
The root-to-leaf affine composition is $Q_d(D)=B_d+\Lambda_dD$.
A `max' with constant overhead changes this formula only in a range where an
overhead term dominates. For each fixed depth, the canonical ARC map below
has no such issue for every sufficiently large $D$.

\begin{theorem}[Actual-guest necessary inequality, PROVED/EXACT restricted]
Suppose that for each fixed sufficiently large integer $D$ a proposed
root-input total machine $C_D$ claims time $N^{Q_d(D)+o(1)}$ on every ordinary
input, and that on \emph{one common input of each of infinitely many lengths}
$N$ its actual execution completes at least $N^{b-o(1)}$ \emph{sequential}
calls to the original padded guest $A_{D,S}$, each on an ordinary input of
length at least $N^{\theta-o(1)}$. Here $b,\theta$ are fixed lower exponents,
not properties secretly selected after seeing the input label. Then
\[
 \boxed{b+\theta D\le B_d+\Lambda_dD.} \tag{1}
\]
If the same $b,\theta$ assertion is made for arbitrarily large fixed $D$,
necessarily $\theta\le\Lambda_d$. If $\theta=\Lambda_d$, also $b\le B_d$.
For $\theta<\Lambda_d$, (1) permits larger $b$ when $D$ is sufficiently
large; no stronger exclusion follows.
\end{theorem}
\begin{proof}
Every completed guest call pays at least the explicit $n^D$ delay, regardless
of whether its SAT answer is useful. The same source input must incur all
$N^{b-o(1)}$ completed executions, so their sequential work is at least
$N^{b+\theta D-o(1)}$. Comparing it with the claimed one-machine upper
exponent gives (1). If $\theta>\Lambda_d$ by a fixed positive amount, choosing
$D>(B_d-b)/(\theta-\Lambda_d)$ makes (1) false; if
$\theta=\Lambda_d$, (1) reduces to $b\le B_d$. This argument uses actual
charged instructions, not any hardness assumption on SAT.\end{proof}

\paragraph{Heterogeneous adaptive rules.}
The identity for $B_d,\Lambda_d$ holds for \emph{each fixed root-to-leaf
word}, even if the different edges use different rules. The theorem applies
to a common-input path whose actual completed-call count and sizes meet its
premises. It does not sum calls made on different sources, require a finite
menu of all possible SAT algorithms, or forbid caching, early termination,
source re-reading, or code analysis that invalidates the completed-call
premise.

\section{Canonical ARC map and a zero-slack leaf frontier}
Consider the illustrative but \OPEN{} all-input map
\[
 q(t)=\max\{11/10,3/5+t/2\},\qquad
 h(s)=\max\{1/2,s/2\}.
\]
For every $D>6/5$ and fixed positive integer $d$,
\[
 \boxed{q^{\circ d}(D)
 = \frac65\left(1-2^{-d}\right)+2^{-d}D.} \tag{2}
\]
The complete nominal depth-$d$ sequential frontier has $N^{B_d+o(1)}$
original guest calls of length $N^{2^{-d}+o(1)}$, where
$B_d=(6/5)(1-2^{-d})$. Its \emph{actual padded guest work} already has
exponent $B_d+2^{-d}D$, exactly equal to (2). Therefore an additional
$N^{\delta}$ distinct completed calls of the same size cannot fit for
\emph{any} fixed $\delta>0$ without an additional speedup or reuse theorem.
This is exact exponent saturation for the implementation, \emph{not} a
claim that complete branching or a particular guest call graph is obligatory.

\begin{corollary}[Two-level quantitative diagnostic]
At depth two, a controller that actually completes $N^{9/10+\delta}$
original padded-guest calls of size $N^{1/4}$ violates the proposed time
exponent $9/10+D/4$ by $\delta$. A single original padded-guest call of size
$N^{1/4+\varepsilon}$ cannot fit the same target for every sufficiently

exponent is zero. In contrast, a shorter $N^{1/5}$ call with fanout
$N^1$ is not excluded for sufficiently large $D$.
\end{corollary}

\section{Same-machine all-live space and bit-time are separate}
Retain the padded guest $A_{D,S}$ with $D\ge S\ge S_0$. If $N^{b-o(1)}$
independent padded work-tape configurations at input size
$N^{\theta-o(1)}$ are \emph{simultaneously live and separately stored},
their peak writable/index space is at least
$N^{b+\theta S-o(1)}$. This does not apply to depth-first serial guest calls
or compressed common state, as the peer's \texttt{FANOUT-ADVICE-SURCHARGE110}
correctly emphasizes. For canonical depth $d$ the claimed space recurrence
would allow only $s_d(S)=\max\{1/2,2^{-d}S\}$. At the complete leaf frontier,
fully retaining all $N^{B_d}$ guest states instead costs exponent
$B_d+2^{-d}S > s_d(S)$ for sufficiently large $S$. Thus depth-first reuse
or another explicitly paid compression is required \emph{in that policy}.

Since the padded guest retains $n^S$ work cells during $n^D$ real steps,
$N^b$ completed calls also incur cumulative live-bit-time
$N^{b+\theta(D+S)-o(1)}$ if charged in the stated occupancy definition.
Bit-time, peak workspace, actual changed bits, unchanged writes, primitive
bit work, gate/wire hardware and physical switching are not interchangeable.
The earlier two-level independent-workplace bound is accepted, not claimed
as a new invention; the \emph{combined arbitrary-depth guest-slope and
bit-time accounting} is the current extension.

\section{Two genuine ordinary-CNF levels and hostile bypasses}
A standalone standard-library reproducer generates $p$ disjoint blocks
of signed proper three-literal clauses. Seven of the eight polarity patterns
on each private three-variable block give a unique SAT assignment; inserting
the eighth pattern into the final block makes a matched UNSAT source. Every
parent, child, and grandchild is physically serialized and parsed with two
fixed-width header fields and four fixed-width words per clause. Each child
is reindexed to consecutive \emph{named} local variables; two genuine levels
are built, parsed and independently solved using the exact block recognizer.

For $p=64$ SAT blocks, the ordinary parent is $28,704$ bits, eight
first-level children total $23,504$ emitted bits, and 24 grandchildren total
$20,240$ emitted bits. One level-one child has at most $2,938$ bits and one
grandchild at most $946$ bits; the two live readable buffers sum to at most
$3,884$ bits, excluding all controller, parser, cache and guest work tapes.
For the matched UNSAT member, the corresponding figures are $28,768$,
$23,556$, $20,284$, $2,990$, and $946$ bits. All twelve SAT/UNSAT instances
preserved both AND joins exactly. A paid direct per-block recognizer also
solves them, so they provide \emph{no mandatory-work lower bound} and no
all-input ARC edge. They test serialized objects and two-level compatibility,
not the hypothetical padded guest's true machine performance.

The audit checks exact rational exponent recurrences for $d=1,\dots,6$,
$363$ heterogeneous channel words, simultaneous padded-space arithmetic,
the FLMV fraction, two-level ordinary-CNF semantics, malformed input
rejection and the direct bypass: $27,379$ checks and zero failures.
This is \textbf{COMPUTATIONAL} support, not an asymptotic proof; the two
symbolic theorems above have independent algebraic proofs.

\section{Disjoint BIT-RESOURCE1 ledger and source provenance}
Every actual guest instruction, delay counter operation, query and output
is paid. Categorize each work operation exactly once as guest execution;
source-bit acquisition/reacquisition; workspace read; workspace write
\emph{including unchanged-value writes}; arithmetic/address/control;
adaptive choice and failed trials; child header/body emission; semantic
compatibility and optional witness/reconstruction; cache/replay; or model
conversion. These are distinct cost buckets even if an instruction has
multiple physical effects: its charged base operation is not double-counted,
while traffic, changed-state flips and cumulative bit-time are recorded as
separate \emph{metrics}. Peak simultaneously-live writable/index bits include
query buffers, caller descriptors, ancestors and all active guest workspaces.
A one-way write-only output channel is not a free readable child input.

The code counts emitted and parsed \emph{logical encoded bits}, not
calibrated FLMV machine steps, full-state flips, physical transistor
switches, exact physical peak cells, hardware size or cumulative bit-time.
Absence of these measurements means UNMEASURED, never zero.

\section{Adoption, rejection, remaining implication}
\textbf{ADOPT:} the strict FLMV box, same-machine simultaneous pairs, the
cofinal finite-hit sufficiency, one-step padded guest call condition, actual
completed-call charging, and the depth-first-versus-all-live distinction.
\textbf{PROVED/EXACT restricted new link:} the arbitrary fixed-depth
heterogeneous guest-work frontier (1) and canonical tight guest-slope
saturation (2), with a separate explicit bit-time diagnostic.
\textbf{FALSIFIED/RETIRED in the declared execution model:} extra polynomial
complete guest-call multiplicity at nominal leaf size without extra work;
parent-scale padded-guest calls within the proposed contracting exponent;
and free independent live frontier memory. \textbf{NOT FALSIFIED:} code-aware
unpadding, genuinely intensional trace compression, state reuse, earlier
return, arbitrary source-dependent SAT simplification and existential
achievable-pair closure.

\textbf{The exact remaining implication is OPEN:} construct a uniform exact
total all-ordinary-input ARC successor, or another fully charged cofinal finite
route, that preserves both SAT and UNSAT and joint time/space without
unjustified parent-scale guest calls, free child answers, hidden live state or
unaccounted alternate representation. No current result proves $P\ne NP$.
