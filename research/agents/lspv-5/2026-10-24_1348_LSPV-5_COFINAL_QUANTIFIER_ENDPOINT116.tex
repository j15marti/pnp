\section{Claim card and three falsifiable mechanisms}

Let $N$ denote ordinary encoded input length.  In the deterministic
random-access Turing-machine model of Fortnow--Lipton--van Melkebeek--Viglas
(FLMV), let $\EE$ be the set of pairs $(t,s)$ for which one fixed uniform,
total, exact SAT decider, correct on every ordinary input, simultaneously uses
time $N^{t+o(1)}$ and counted work space $N^{s+o(1)}$.

This run tested three precise alternatives.

\begin{enumerate}
\item \textbf{M1: the old Williams constant is a general product endpoint.}
Falsifier: the primary theorem assumes $N^{o(1)}$ work space rather than an
arbitrary polynomial-space exponent.  Result: \RET.
\item \textbf{M2: ``there exists an unbounded set of achievable diagonals with
finite routes'' is the cofinal target.}  Falsifier: if $P\ne NP$ then $\EE$ is
empty, so no such unbounded set exists.  Result: \RET{} as a literal
formulation; repaired below.
\item \textbf{M3: a fixed unbounded set $U$ and the conditional assertion
``if $(K,K)\in\EE$, then it has a finite route through $\EE$ into a forbidden
region'' is a weaker abstract lower-bound lemma.}  Falsifier: upward closure
and endpoint disjointness make this assertion true exactly when $\EE$ is
empty.  Result: \EXACT{} separation-equivalence.  It is constructionally more
modular than a universal compiler, but not logically weaker than $P\ne NP$.
\end{enumerate}

\section{Primary endpoint and model}

\paragraph{Matched model.}
FLMV uses deterministic random-access Turing machines with indexed access to
a read-only input; work and index tapes count toward space.  Theorem~3.1
transfers a SAT algorithm to nondeterministic linear time with polylogarithmic
time/length overhead and logarithmic additional space.  Corollary~3.2 permits
strict exponent margins.  Corollary~5.8 states, for every fixed $c>1$,
\[
  \NTIME[n]\not\subseteq
  \DTISP\!\left[n^c,o\!\left(n^{\beta(c)}\right)\right],
  \qquad
  \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
These are \KNOWN{} statements in that model.  A free output tape is not a
reusable uncharged child-input store.

\begin{lemma}[Curved FLMV forbidden region, \EXACT]
For nonnegative exponents define
\[
 \BB=\{(t,s):\exists c>\max\{1,t\}\text{ with }s<\beta(c)\}.
\]
Then $\BB\cap\EE=\varnothing$, and $\BB$ is coordinatewise downward closed.
Moreover $\beta$ is strictly decreasing on $(1,\infty)$; consequently
\[
\begin{array}{ll}
0\le t\le1:&(t,s)\in\BB\iff 0\le s<1,\\
1<t<c_0:&(t,s)\in\BB\iff 0\le s<\beta(t),\\
t\ge c_0:&(t,s)\notin\BB\quad(s\ge0),
\end{array}
\]
where $c_0>1$ is the root of $c^3-c-2=0$.
\end{lemma}
\begin{proof}
If $(t,s)\in\EE$ and $c>\max\{1,t\}$ witnesses membership in $\BB$, the
strict gaps give time $N^{c-\epsilon}$ and space
$o(N^{\beta(c)})$ for some fixed $\epsilon>0$ after absorbing the FLMV
polylogarithmic transfer.  Corollary~5.8 contradicts this, so
$\BB\cap\EE=\varnothing$.  The same witness $c$ works after either coordinate
is decreased, proving downward closure.  Finally
\[
 \beta'(c)=-\frac12\left(1+c^{-2}+4c^{-3}\right)<0.
\]
Also $\lim_{c\downarrow1}\beta(c)=1$ and $\beta(c)>0$ precisely before the
positive root of $c^3-c-2=0$.  Continuity gives the displayed cases.
\end{proof}

At $c_*=241/200$,
\[
 \beta(c_*)=\frac{11642479}{23232400}
 =\frac12+\frac{26279}{23232400}>\frac12.
\]
Thus the familiar box $t<241/200$, $s\le1/2$ is forbidden, but is not the
whole endpoint.  For example $(121/100,9/20)\in\BB$ using $c=61/50$, and
$(13/10,3/10)\in\BB$ using $c=131/100$.  The exact margins are recorded in
the accompanying raw JSON.

\paragraph{Williams endpoint repair.}
The primary Williams paper states deterministic RAM lower bounds with
$n^{o(1)}$ space; later summaries state the $2\cos(\pi/7)$ time exponent in
that same subpolynomial-space regime.  This does not imply that every pair
with $t+s<2\cos(\pi/7)$ is forbidden.  In particular a theorem excluding
$(n^{\gamma-\epsilon},n^{o(1)})$ does not exclude an algorithm using
$n^s$ work space for a fixed $s>0$.  Therefore the historical product-region
use is \RET.  Only abstract finite-route algebra may be reused, after its
terminal test is replaced by $\BB$ or a verified subregion.

\section{The exact cofinal quantifier repair}

\begin{lemma}[Basic achievable-region facts, \EXACT]
\begin{enumerate}
\item $\EE$ is coordinatewise upward closed.
\item $\EE\ne\varnothing$ if and only if $\SAT\in P$, hence if and only if
$P=NP$.
\end{enumerate}
\end{lemma}
\begin{proof}
The same machine witnessing $(t,s)$ witnesses every $(t',s')$ with
$t'\ge t,s'\ge s$.  A finite pair gives a polynomial-time SAT decider.
Conversely a polynomial-time decider has polynomial space after a standard
model-compatible polynomial simulation, so it supplies a finite pair.  SAT
is NP-complete under the standard reductions.
\end{proof}

Fix once and for all an unbounded set $U\subseteq\mathbb N$.  Define
$\mathsf H_U$ as follows:
\[
 \forall K\in U:\quad (K,K)\in\EE\Longrightarrow
 \exists r\ge0\ \exists x_0,\ldots,x_r
 \bigl[x_0=(K,K),\ x_i\in\EE,\ x_r\in\BB\bigr].
\tag{H$_U$}
\]
An intended proof must additionally justify every edge by a finite uniform
all-input machine construction or a mathematically explicit existence
theorem, with one simultaneous machine at each point.  Those proof-method
requirements do not change the semantic assertion displayed above.

\begin{theorem}[Cofinal conditional route equivalence, \EXACT]
For every fixed unbounded $U\subseteq\mathbb N$, assuming the matched FLMV
endpoint,
\[
 \mathsf H_U\quad\Longleftrightarrow\quad\EE=\varnothing
 \quad\Longleftrightarrow\quad P\ne NP.
\]
\end{theorem}
\begin{proof}
If $\EE=\varnothing$, every antecedent in $(\mathsf H_U)$ is false, so the
assertion holds vacuously.  Conversely suppose $\EE\ne\varnothing$ and pick
$(t_0,s_0)\in\EE$.  Upward closure puts $(K,K)$ in $\EE$ for every integer
$K\ge\max\{t_0,s_0\}$.  Since $U$ is unbounded, choose such a $K\in U$.
Then $(\mathsf H_U)$ supplies a route whose terminal point lies in both
$\EE$ and $\BB$, contradicting $\EE\cap\BB=\varnothing$.
The preceding lemma identifies emptiness with $P\ne NP$.
\end{proof}

This independently verifies the logical-strength theorem in Role~3's
ARCHIVE-ARC-SEMANTIC82.  It is not a new proof of $P\ne NP$: rather, it
identifies why proving $\mathsf H_U$ is already the missing separation.

\paragraph{The non-equivalent literal reading.}
Let $\mathsf H_{\exists}$ assert that there exists an unbounded
$U\subseteq\{K:(K,K)\in\EE\}$ and that every $K\in U$ has such a route.
Then $\mathsf H_{\exists}$ is false when $\EE=\varnothing$ because no such
$U$ exists, and false when $\EE\ne\varnothing$ because no route can terminate
in $\BB$.  Hence $\mathsf H_{\exists}$ is simply false under the established
endpoint.  The sufficient proof architecture must instead be one of:
\begin{itemize}
\item prove $\mathsf H_U$ for a fixed unbounded $U$;
\item under the assumption $P=NP$, construct an unbounded family of
achievable starting diagonals and their finite routes; or
\item start from an arbitrary witnessed pair and prove enough finite charged
edges to hit $\BB$.
\end{itemize}
The first two are logically separation-strength; their advantage is only that
they allow different finite rules at different $K$ and do not demand a single
compiler or recurrence.
