\section*{Status}
\textbf{PROVED/EXACT, restricted extensional grammar.}
Complete binary separator relations compose associatively by Boolean matrix
multiplication. On a path the product is the exact endpoint relation; on a
cycle satisfiability is exactly the presence of a diagonal product entry.
Consecutive products can be grouped into one smaller child recursively.

\textbf{FALSIFIED.} Unary marginals or an arc-consistency fixed point do not
authenticate a cyclic join. Equality on two edges and inequality on the third
edge of a Boolean triangle leaves both values locally supported but is UNSAT.

\textbf{OPEN.} The positive result assumes each complete $2\times2$ relation
is supplied extensionally. Acquiring it from arbitrary CNF modules contains
NP/coNP-hard extension tests, and no useful all-input decomposition or
ordinary-SAT re-entry is known. P versus NP and ARC-EDGE-90 remain OPEN.

\section{BUILD: relation algebra and corrected lemma}
For $R,S\subseteq\{0,1\}^2$, define
\[
 (R\circ S)(a,c)=\bigvee_{b\in\{0,1\}}R(a,b)\wedge S(b,c).
\]
For a chain $R_1,\ldots,R_k$, put $H=R_1\circ\cdots\circ R_k$.

\begin{theorem}[Exact path, cycle and context law]
$H(a,c)=1$ iff the path has an internal assignment extending endpoints
$a,c$. The cyclic join is satisfiable iff $H(0,0)\vee H(1,1)=1$.
Composition is associative, so replacing any consecutive block by its complete
product preserves every external context on its two endpoints.
\end{theorem}
\begin{proof}
Expanding the Boolean product quantifies exactly the internal path variables.
Closing the path identifies endpoints, selecting the diagonal. Associativity
is reassociation of the finite existential quantifiers.
\end{proof}

\begin{theorem}[Acyclic correction]
For a binary CSP whose constraint graph is a tree, arc consistency with
nonempty domains implies satisfiability.
\end{theorem}
\begin{proof}
Root the tree. Every retained parent value has a supported child value.
Choose a root value and recurse outward. Distinct child subtrees have no
cross-edge, so the choices combine without backtracking.
\end{proof}

\begin{theorem}[Smallest cyclic firewall]
Let $E=\{00,11\}$ and $X=\{01,10\}$. Then
$E(x_0,x_1)\wedge E(x_1,x_2)\wedge X(x_2,x_0)$ is UNSAT, although every
unary projection is $\{0,1\}$ and AC-3 deletes nothing. An $E/X$ cycle is SAT
iff it contains an even number of $X$ edges.
\end{theorem}
\begin{proof}
The equalities force all values equal, contradicting $X$. Each value has
local support. Traversal flips the bit once per $X$ edge, so closure requires
even parity.
\end{proof}

\section{Restricted single-child closure and acquisition firewall}
Encode a fixed-order chain by four bits per relation and a self-delimiting
length. Group consecutive blocks of $\lceil\sqrt{k}\rceil$ relations and output
one complete product per block. This one physical child has
$O(\sqrt{k})$ records, preserves the complete external relation, remains in
the same grammar and can be regrouped. Above a fixed threshold it satisfies
an $N^{3/4}$ physical bound; sufficiently large sources have two actual
above-threshold calls, followed by directly decidable bases.

The assumption doing the work is \emph{extensional relation availability}.
For hidden $F(X,B)$, testing one row of $\exists X\,F$ can encode SAT and
testing absence can encode UNSAT. LSPV-3's four fixed fibers prove expressive
availability, not uniform acquisition on an unbounded NP-complete class.
Thus the corrected architecture is
\[
\boxed{\text{acyclic complete summaries compose cheaply, but
source-to-summary acquisition is the load-bearing open edge.}}
\]
No unconditional procedure obtains all relations, chooses a bounded-width
moving decomposition, and emits a power-short ordinary-SAT child on arbitrary
instances.
