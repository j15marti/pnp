\section{Claim card and preregistered falsifiers}
\textbf{Target.}  Audit the last step from large source-cell perturbation transversal to a small/large downstream ordinary-SAT child, repeated source charge, or simultaneous time--space contraction.

\textbf{Quantifiers.}  For every fixed source layout and one fixed total exact (or explicitly bounded-error) machine execution, charge the union of original source cells it actually reads.  Do not quantify over a restricted proof system in place of every ordinary-SAT decider.  A countercontrol needs only one legal function/interface to refute the claimed \emph{generic implication}; it does not refute worst-case SAT hardness.

\textbf{Models.}  Decision-tree/source-cell access first; then separate M1 one shared read/write tape, $M_k$ fixed-tape sequential read-only input, and FLMV indexed read-only-input RAT.  No resource coordinate is borrowed across machines.

Before source/literature search the following attacks were fixed.
\begin{description}
\item[H1.] Global preprocessing may read the entire source once and emit a one-bit sufficient statistic.  \textbf{PROVED/EXACT as a countercontrol}; Theorem~\ref{th:or}.
\item[H2.] Repeated guest requests may be answered from one cached bit, so the initial transversal cannot be recharged at every recursive level.  \textbf{PROVED/EXACT}; Lemma~\ref{lem:cache}.
\item[H3.] Source sensitivity may force many reads while permitting streaming $O(\log N)$ writable/index space.  \textbf{PROVED/EXACT}; the same OR control.
\item[H4.] A guessed local UNSAT locator may avoid deterministic discovery, but only if its rejecting branch is source-authenticated and SAT inputs make every branch accept.  \textbf{UPHELD as a polarity guard}; it does not restore a global backdoor or transversal charge.
\end{description}

\section{Constant-child counterexample}
For $r\ge1$, let
\[
D_r=\{0^r,e_1,\ldots,e_r\},\qquad f_r(x)=\bigvee_{i=1}^r x_i.
\]
Use one physical input cell per bit initially.  The baseline $0^r$ has $r$ disjoint singleton sensitive blocks, so its integral and fractional cell transversals both equal $r$.

\begin{theorem}[One-shot concentration; restricted but exact]\label{th:or}
There is one uniform deterministic preprocessor $P$ which, on every $x\in D_r$, reads exactly $r$ source cells, keeps one accumulator bit (plus $O(\log r)$ addressing bits in an indexed implementation), and emits an ordinary CNF $Y_x$ of exactly two unit clauses such that
\[
Y_x\in\SAT\quad\Longleftrightarrow\quad f_r(x)=1.
\]
The physical child length is $O(1)$, independent of $r$.  Therefore no implication of the forms
\[
\tau_{\mathcal P}(x)\le O(|Y_x|),\qquad
\tau_{\mathcal P}(x)\le O(S_{\mathrm{post}}),
\]
or ``large $\tau_{\mathcal P}$ forces a power-large ordinary-SAT child'' is valid without an additional compiler/interface theorem.
\end{theorem}
\begin{proof}
Scan the input and retain $b=\bigvee_i x_i$.  For $b=1$ emit $(z)\wedge(w)$; for $b=0$ emit $(z)\wedge(\neg z)$.  Both children have two unit-clause records under a fixed-width literal encoding, and their SAT labels are respectively true and false.  The source-query lower bound is met exactly during preprocessing and is not contradicted.  Its information has simply been concentrated into $b$ before child emission.
\end{proof}

Packing $W$ source bits per physical source word changes the singleton hyperedges to $\lceil r/W\rceil$ disjoint word edges and the preprocessor reads exactly that many words.  The child still has constant size.  Thus the conclusion is layout-aware and does not rely on pretending bit probes are word probes.

\begin{lemma}[Cache nonadditivity and residual checkpoint]\label{lem:cache}
Suppose a first phase has read the source cells $Q_0$ and stored a sufficient statistic $b$.  Any number $q$ of later requests for $b$ can be answered with zero new source reads and $O(q)$ ordinary transitions.  The same legal interface may instead recompute $b$ on every request, using $q|Q_0|$ source reads and smaller retained state.  Hence the only unconditional source count is the actual union
\[
\left|\bigcup_j Q_j\right|,
\]
not a sum of cold-start transversals at every level.  At a checkpoint state $\sigma$, a further perturbation argument may charge only edges $E$ for which the complete checkpoint states on $x^0$ and $x^E$ are identical.  For the cached OR control that residual edge family is empty.
\end{lemma}
\begin{proof}
The cached implementation returns the stored bit.  The recomputing implementation rescans.  Both compute the same answers.  After the first complete OR scan, the baseline cache contains $0$ and every singleton mutant cache contains $1$, so those paired executions are already distinguished before any guest request.  Coupling from the initial state cannot be restarted at the checkpoint while discarding this state difference.
\end{proof}

\paragraph{Consequence for LSPV-4 report 146.}
Its theorem
\(\mathbb E|Q_\omega|\ge(1-2\epsilon)\tau^*\)
is independently correct for one complete baseline execution under the stated coupled coins.  Its two-layer displayed expression is likewise a sound \emph{upper accounting} of actual original probes when $p_i,q_i$ are actual cold/warm service caps.  It must not be read backwards as requiring every request to pay $q_i$, nor as a lower bound on child length or downstream guest work.  A cached warm request has zero further original probes.  This is a scope repair, not a falsification of report 146.

\section{Path polarity, peer audit, and same-machine ledger}
\paragraph{coNTIME polarity.}
For co-nondeterministic SAT, SAT inputs require all paths to accept and an UNSAT input requires at least one rejecting path.  Freeze a rejecting branch on a NO baseline.  If the same valid branch transcript missed a sensitive support leading to a SAT neighbor, it would reject that SAT neighbor and violate soundness.  Thus report 146's pathwise integral statement is correct.  Malformed guesses and timeouts must accept, as LSPV-3 specifies.  Conversely, disjoint $W_1$ products permit a branch to guess one unsatisfiable component and verify it locally; that is a legitimate source-authenticated local certificate and shows why global hitting-backdoor size is not an adaptive refutation lower bound.

\paragraph{Role 1.}
ARC-CANONICAL-SELECTOR-AUTH184 correctly proves that checking totality of $J_F$ is the parent UNSAT question; compact wiring does not authenticate it.  ARC-PACKED-SOURCE-REFUTATION193 is a source-authenticated exponential \emph{upper} tree with exact packing, not polynomial all-UNSAT coverage.  A full-parent guest $A$ call remains charged and cannot be advertised as contraction.

\paragraph{Role 2.}
The fixed-record witness circuit and inverse Rank/Select results are local source/gate access theorems.  Existentially hiding the witness does not give the full decision circuit required by van Melkebeek.  Output serialization and the explicit signed regularizers expand physical length; the constant OR child above is only a promise countercontrol, not a repair for that compiler.

\paragraph{Role 3.}
The streamed SCC verifier's declared time/space bounds are verifier upper bounds for supplied source-authenticated proofs.  BACKDOOR-SCC-CERT130 supplies complete but potentially exponential coverage; current guarded-DAG/PCR evidence is proof-system scoped.  Neither forces arbitrary deterministic SAT work.

\paragraph{M1, $M_k$, and RAT.}
On a sequential read-only input, OR scans once in $\Theta(r)$ transitions and constant accumulator work space; on indexed RAT it uses $\Theta(r)$ indexed probes and $O(\log r)$ index bits.  On M1 the same run has physical footprint $\Theta(r)$ because the initial writable input is counted.  This difference is purely the declared space convention.  The conservative
\[
T_1=O(T_k(N+S_k+\log(T_k+2))),\qquad
P_1=O(N+S_k+\log(T_k+2))
\]
remains an upper simulation, never a necessary lower bound.  HEADMOVE-1 crossing/reversal surfaces and the exact22 tape diagonal remain restricted to one sequential input head; the indexed OR control has no crossing-sequence implication.  No $t+s\ge2$ tape bound is imported into RAM, and no one-tape footprint lower bound is called FLMV writable space.

\paragraph{Write and traffic counters.}
The OR accumulator can be kept in finite control; source reads need not cause work-tape writes.  If a work bit is used, repeated overwrite can be removed by the polynomial write-once simulation at large polynomial workspace/time overhead.  Reads, head moves and probes already counted in transitions are not charged again as an independent time lower bound.

\section{Corpus reconciliation and role-addressed handoff}
\paragraph{Duplication/contradiction audit.}
The source-layout transversal is inherited from LSPV-5 report 172; the fractional randomized repair is inherited from and independently checks LSPV-4 report 146.  The new result is the exact checkpoint/cache/output firewall. \paragraph{What changes relative to root main.}
Add that integral/fractional perturbation transversals lower-bound only actual source acquisition in one complete execution.  Remove any implication to emitted-child size, post-acquisition space, or additive per-level costs absent a checkpoint-relative unresolved-edge theorem.  Preserve every peer's restricted theorem and all OPEN labels.

\paragraph{Adopted/rejected/retired.}
Adopt actual union of source reads, cold/warm service distinction, complete checkpoint state and native machine ledgers.  Reject recharging cached source information, treating one-bit semantic compression as free acquisition, and converting source query complexity to unrestricted TM space/output/runtime without a transfer theorem.  No valid peer theorem is retired.

\paragraph{To LSPV-1.}
Keep ARC193 as a source-authenticated exponential upper bound.  Any selector/packed-tree successor must expose the complete checkpoint state and prove that a large family of opposite-label sources remains unresolved; a parent-size $A$ validation does not contract.

\paragraph{To LSPV-3.}
For SCC/guarded-DAG leaves, separate guessed local proof verification from deterministic component discovery.  Charge only actual source reads on the accepting/rejecting path, orient malformed/timeout branches to accept, and do not require a global hitting set when one authenticated UNSAT component suffices.

\paragraph{To LSPV-4.}
Report 146's fractional theorem is independently upheld.  Refine the two-level interface to state cold initialization probes and warm cached probes separately; call the inequality an actual-request upper ledger, not an additive lower potential.  The next smallest candidate is a complete-state unresolved-edge potential with a noncircular transition decrement theorem.

\paragraph{Next decisive target.}
Either prove a checkpoint-relative unresolved-perturbation potential that survives semantic compression, caching, recomputation and arbitrary direct decisions with every transition charged, or exhibit another legal compiler that collapses it.  Until that theorem exists, ARC-EDGE-90 and $P\ne NP$ remain \OPEN.
