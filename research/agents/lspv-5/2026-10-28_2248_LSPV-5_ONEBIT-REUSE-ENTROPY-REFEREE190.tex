\paragraph{Executive status.}
The current constructive bottleneck remains OPEN: no unconditional uniform polynomial-time map is known here that sends every ordinary SAT instance to one answer-equivalent child of length at most $N^\lambda$, $0<\lambda<1$, inside a closed class.  This report proves a narrower red-team theorem.  LSPV-3's exact one-boundary-bit projection can be composed with LSPV-4's fixed-length scalar source so that the current projection has only two values, while exact no-reread reuse under $h$ authenticated source overwrites has
\[
 E(m,h)=
 \begin{cases}
 1+\sum_{j=0}^h {m\choose j},&h<m,\\
 2^m,&h\ge m
 \end{cases}
\]
pairwise distinguishable behaviors.  Thus a compact current answer table is not, by itself, a compact reusable state or a proof of hereditary second-level closure.  This is an exact restricted dynamic-memory theorem, not a static SAT time lower bound and not a separation result.  P versus NP and ARC-EDGE-90 remain OPEN.

\section{PROPOSE: falsifiable mechanisms before search}
The missing lemma was stated as follows: can a compact exact interface summary be constructed unconditionally and then reused through the next hereditary transformation without rereading or retaining a large source description?  Before searching, four falsifiers were fixed.
\begin{enumerate}[leftmargin=*]
\item \textbf{Hindsight-bit falsifier.} A one-bit table may encode the current answer class while omitting which source coordinates must change before the answer flips.
\item \textbf{Authenticated-support falsifier.} A summary with constant semantic range may still have $\Omega(m)$ physically distinct source supports; an updater must authenticate which support was overwritten.
\item \textbf{Update-horizon falsifier.} Under a horizon of $h$ edits, sources that currently share one table value may split into $1+\sum_{j\le h}\binom mj$ future behaviors.
\item \textbf{Second-level-closure falsifier.} A first exact projection may be answer-preserving but cease to be a valid child representation when the next transformation needs omitted source identities or an UNSAT proof object.
\end{enumerate}
Each is falsifiable by an explicit fixed-width family and a common update stream.  None assumes the answer-class bit is supplied to the algorithm.

\section{BUILD: fixed-width composition}
\subsection{The scalar source}
For $b=(b_1,\ldots,b_m)\in\{0,1\}^m$, let $\Phi_m(b)$ be LSPV-4's fixed-length proper 3CNF.  It has $6m+5$ variables and $9m+8$ clauses, is connected, and satisfies
\[
 \Phi_m(b)\in\mathsf{SAT}\quad\Longleftrightarrow\quad \bigwedge_{i=1}^m b_i=1.
\]
Each $b_i$ controls the common sign of one source literal in four proper ternary clauses.  Therefore changing one authenticated scalar bit changes four literal signs while preserving the number of variables, clauses, and fixed-width encoded bytes.

For every source clause $C_i=(a_i\vee b_i\vee c_i)$ introduce a fresh $t_i$ and one common boundary variable $z$, and set
\[
 G_b(z,X,T)=\bigwedge_i
  (\neg z\vee a_i\vee t_i)\wedge(\neg t_i\vee b_i\vee c_i).
\]
The lift is uniform and linear in the source encoding; it is proper and connected on this family.

\begin{lemma}[Exact current projection]
For every $b$,
\[
 \exists X,T\;G_b(z,X,T)\equiv
 \begin{cases}
 \TOP,&b=1^m,\\
 \neg z,&b\ne1^m.
 \end{cases}
\]
\end{lemma}
\begin{proof}
Eliminating $t_i$ from its two clauses gives
$(\neg z\vee a_i\vee b_i\vee c_i)$.  Conjoining and existentially quantifying the source variables yields $\neg z\vee\exists X\Phi_m(b)$.  The scalar-source equivalence gives the two cases.
\end{proof}

Thus the current exact summary has one semantic bit.  Importantly, this proof computes the table from the already-known source family; it does not furnish a general polynomial projection algorithm for arbitrary SAT.

\subsection{Exact reuse entropy}
Fix one deterministic updater.  After preprocessing it may retain state but may not reread the source.  It then receives a sequence of at most $h$ authenticated point overwrites $(i,v)$ and must output the exact current projection after each prefix.  Let $Z(b)=\{i:b_i=0\}$.

\begin{theorem}[One-bit projection is not reusable state]
Two initial sources have identical response behavior under every authenticated overwrite stream of length at most $h$ exactly when either their zero sets are equal and have size at most $h$, or both zero sets have size greater than $h$.  Consequently the number of behaviors is $E(m,h)$ above, and every exact no-reread updater requires at least $\lceil\log_2E(m,h)\rceil$ retained bits.
\end{theorem}
\begin{proof}
If $|Z|>h$, no stream of at most $h$ overwrites can repair every initial zero, so the projection remains $\neg z$; overwriting a one by zero cannot help.  Hence all such sources form one overflow class.

If $|Z|\le h$, the stream that sets exactly the positions in $Z$ to one reaches $1^m$, hence produces $\TOP$.  For two distinct small zero sets $Z\ne Z'$, choose the stream that repairs one set not containing the other; one source reaches $\TOP$ and the other retains an unrepaired zero.  If one set is small and the other is overflow, repairing the small set likewise distinguishes them.  These witnesses use only set-to-one overwrites, a subfamily of the allowed authenticated overwrites.  There are $\sum_{j=0}^h\binom mj$ small sets and one overflow class when $h<m$; if $h\ge m$, every zero set is small.  Deterministic states with different future behaviors must be distinct, giving the information bound.
\end{proof}

For $h=1$ this already needs $\lceil\log_2(m+2)\rceil$ retained bits, not one.  For $h\ge m$ it needs $m$ bits.  A matching representation stores the zero set sparsely until it exceeds $h$, using $O(\min\{m,h\log m\}+\log m)$ bits.  This matching upper control prevents overclaiming: the theorem concerns the declared dynamic no-reread interface, not intrinsic static SAT hardness.

\paragraph{Specific falsifier.}
All sources with $b\ne1^m$ expose the same current table $\neg z$.  Take $Z=\{i\}$ and $Z'=\{j\}$ with $i\ne j$.  The single authenticated update $(i,1)$ changes the first table to $\TOP$ and leaves the second at $\neg z$.  Therefore the current one-bit table alone cannot determine the next table.  This falsifies the unrestricted implication
\[
 \text{``compact exact current projection''}
 \Longrightarrow
 \text{``compact reusable hereditary state.''}
\]
It does not falsify a static immutable-input one-child recursion, which does not promise future source edits.

\section{SAT/UNSAT sides and proof-object polarity}
One fixed program handles every $b$; it is not told whether the current projection is $\TOP$ or $\neg z$.  On the SAT side $b=1^m$, the current table is $\TOP$.  On the UNSAT-source side $b\ne1^m$, many distinct zero sets share $\neg z$, but authenticated future updates separate them.  The lower bound concerns the one program's future response behavior, not independently optimized $A_{\rm SAT}$ and $A_{\rm UNSAT}$ solvers.

Moreover, $\neg z$ is only a semantic table entry.  Supplying it does not authenticate $\Phi_m(b)\in\mathsf{UNSAT}$ for an arbitrary source.  Incremental proof checkers validate a supplied derivation; their existence does not supply a uniformly short derivation or discover one.  Any recursive construction that needs certified UNSAT must charge proof discovery, proof length, source identities, and verification, or else state an additional proof-system hypothesis.

\paragraph{Decisive remaining gap and next target.}
The next LSPV-5 target is a two-level source-authenticated stress test for any proposed moving/hierarchical summary: require the first child to expose every source dependency needed to construct and certify the second child, then charge discovery, failed rule selection, proof objects, updates, and total physical encoded size.  A successful construction must work on arbitrary ordinary SAT inputs; a failure on the restricted dynamic family is not a separation theorem.

\paragraph{Conclusion.}
The constructive route survives only in its correctly scoped form: a compact representation may be useful when it comes with an unconditional acquisition algorithm, closure, and a paid update/proof interface.  The present composition shows why the semantic size of the current answer alone cannot supply those obligations.  Conversely, the matching sparse cache and the cyclic moving-interface control show why this result cannot be promoted to a general SAT runtime lower bound.  Both constructive and separation questions remain open.
