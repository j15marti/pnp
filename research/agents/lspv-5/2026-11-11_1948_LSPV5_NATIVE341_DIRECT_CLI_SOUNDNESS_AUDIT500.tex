\section{Soundness theorem and repaired gate}

Let $A_{341}(b)$ mean exit-status-zero acceptance of the pinned checker on byte
string $b$, and let $\mathsf{Refutes}(E,b)$ be the intended mathematical claim
that $b$ is a sound completed refutation of exact source $E$.

\paragraph{Validation theorem (\COMP, exact finite witness).}
There exists a published byte string $b_\star$ and explicit source $E_\star$
such that
\[
 A_{341}(b_\star)=1,
 \qquad E_\star\text{ is satisfiable},
 \qquad \neg\mathsf{Refutes}(E_\star,b_\star).
\]
The witness is the hybrid artifact above.  Consequently the implication
$A_{341}(b)\Rightarrow\mathsf{Refutes}(E,b)$ is \RET{} for this recovered
checker.

Raw parser acceptance must therefore be separated from trusted proof
semantics.  A minimally adequate repaired predicate has the form
\[
\begin{split}
\mathsf{ProofOK}(E,b):={}&\mathsf{RawParseAccept}(b)\wedge
\mathsf{ExactCallerRoot}(E,b)\\
&\wedge\mathsf{TypedSupport}(b)\wedge\mathsf{SourceSound}(E,b)
\wedge\mathsf{InferenceSound}(b).
\end{split}
\]
No conjunct is free: each requires source-authenticated bytes and an actual
rule-by-rule proof.  This report proves no such theorem for SOURCE, Resolution,
AND3, GF(2), LOCAL-CONVERT, paid DEF facets, freshness, private/exported wires,
branch contexts, discharge, join, weakening, or deletion in the full historical
system.

\section{CEGAR polarity and cost firewall}

Clarke--Grumberg--Jha--Lu--Veith refine an abstraction only after a reported
path is shown spurious by concrete replay.  Here concrete replay succeeds, so
the path is genuine in the recovered checker and must remain in every
acceptance-complete abstraction.  Excluding it by adding semantic typing or
source rules changes the concrete language unless those rules are proved to be
part of the actual historical caller/checker composition.

For a cost-sound abstraction $\alpha$ of concrete states $c$, the obligations
remain:
\[
 c\to c'\Longrightarrow \alpha(c)\leadsto\alpha(c'),\qquad
 \mathsf{Complete}(c)\Longrightarrow\mathsf{Complete}^{\#}(\alpha(c)),
 \qquad W^{\#}(\alpha(c))\le W(c).
\]
The 47 parsed proof records in this fixture establish none of: minimum proof
work, certificate construction time, shared-DAG span, peak live space, machine
time, or machine space.  They cannot support P2-C3 or P2-B1.

\section{Primary-literature and transfer audit}

The relevant ECMAScript specification defines the coercions used by string
search and 32-bit bitwise operations; these are a \textbf{directly
transferable specification} for the pinned JavaScript body, not evidence about
an absent caller or other calculus rules.  Cook--Reckhow's proof-system notion
requires a polynomial-time computable map whose range is exactly the
tautologies; that soundness requirement makes this accepted SAT-source packet
a genuine obstruction to treating raw acceptance as a proof system.  The
Cousots' abstract-interpretation framework and CEGAR are
\textbf{structurally transferable} only after concrete semantics and a
simulation/cost theorem are fixed.  VLSI, coding, topology, and post-quantum
analogies are \textbf{failed transfers} here: none authenticates the missing
byte grammar or source binding.
