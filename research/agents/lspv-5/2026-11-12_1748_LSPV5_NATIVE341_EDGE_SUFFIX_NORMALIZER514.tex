\section*{Theorem 514.1: exact parsed-packet quotient}

Let \(C\) be the pinned /341 checker and let \(P\) be any parsed packet in its domain with every
edge an array of length at least two.  Define \(\Aedge(P)\) by applying the displayed map to every
edge and leaving every other parsed value unchanged.  Then
\[
  C(P)=C(\Aedge(P)),\qquad
  \Aedge(\Aedge(P))=\Aedge(P),
\]
including equality of the accepted/rejected verdict, assertion count and stdout.  For accepted
\(P\), the effective graph, generated signed SOURCE factors, every AND3/GF(2) node, parent relation,
terminal contradiction and checker logical charge are identical.  Under compact JSON serialization,
\(\lvert\Aedge(P)\rvert\leq\lvert P\rvert\).

\textbf{Proof.}  Each checker use of an edge binds only indices zero and one.  Replacing the array by
those two values therefore preserves all values observed by the checker.  The rest of the packet is
unchanged, so the checker follows the same control path, executes the same assertions and prints the
same output.  A second application sees only two-element arrays, proving idempotence.  Removing suffix
elements and their separating commas cannot increase compact JSON length.  The conclusion follows.
\(\square\)

This is a theorem about parsed checker observations and a chosen compact reserialization.  It does
\emph{not} preserve the original input byte string, whitespace, lexical aliases, an external file hash,
or provenance that some other consumer might attach to suffix bytes.  In particular, a suffix object
spelling \texttt{source\_hash}, a false endpoint, a parent or a private wire is inert data here, not
authenticated evidence.

\section*{Concrete semantics, cost-sound abstraction and CEGAR}

For this restricted checker define a concrete state to contain the parsed packet, current fixture and
checker program counter.  Define the abstract state by replacing each edge with its endpoint pair and
retaining all remaining fields.  Every concrete checker transition has an abstract transition with the
same observed operands and same logical charge.  Consequently concrete-step inclusion holds,
completed acceptance/refutation is preserved, and
\[
       \operatorname{cost}^{\#}(\Aedge(P))
       =\operatorname{cost}(P)
       \leq\operatorname{cost}(P).
\]
The explicit canonical packet realizes the abstract path, so this is not merely a cheap symbolic path.
