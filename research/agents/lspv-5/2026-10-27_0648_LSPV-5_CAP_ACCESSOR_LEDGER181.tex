\section{Falsifiers fixed before targeted search}
\begin{enumerate}
\item A computable cap might require more time than the enumeration it is
claimed to control.
\item Computing the cap might use more peak space than the verifier.
\item CAP180's finite-exception table might be changing-length advice rather
than one uniform program.
\item Early stopping or a different seed order might invalidate the physical
union charged by GAP--STOP156.
\end{enumerate}
The first two expose a real missing ledger.  The third is false: for each
fixed $\delta$, one fixed threshold $N_0$ and one finite table are constants
in one program; no advice changes with the live input length.  The fourth is
repaired exactly by fixing the public seed order and charging the union of
the seeds actually executed by that order.

\section{Corrected resource theorem}
Let $R(N)$ be the public seed count, $\tau(N)$ the charged time of one seed,
$S(N)$ the verifier's peak workspace, and $A_N$ the maximum physical proof
address width.  Fix the public seed order and the exact GAP--STOP156 rule.
Let an upper-cap algorithm $E_q$ output $\widehat q(N)$ in worst-case time
$C_q(N)$ and peak workspace $S_q(N)$, including input-length acquisition,
finite arithmetic, comparisons, and output bits.

\begin{theorem}[Resource-effective adaptive enumeration]\label{th:ledger}
Assume every ordinary $\UNSAT$ source has a successful stopped run whose
actual all-executed-seed physical query union has size at most
$\widehat q(N)$.  With the CAP180 soundness and stable-proof hypotheses, one
uniform deterministic total ordinary-SAT decider has
\begin{align}
T_D(N)&=O\!\left(C_q(N)+2^{\widehat q(N)}R(N)\tau(N)
 \operatorname{poly}(\widehat q,A_N,\log(R+2))\right),\tag{1}\\
S_D(N)&=O\!\left(\max\{S_q(N),
 S(N)+\widehat q(N)(A_N+1)+\log(R+2)\}\right).\tag{2}
\end{align}
If cap evaluation and enumeration overlap, the displayed sum/max remain
valid conservative upper bounds.  They must not be reversed into lower
bounds.
\end{theorem}
\begin{proof}
First run $E_q$ once and retain its $O(\log(\widehat q+2))$-bit result.
Then execute CAP180's binary first-read DFS, aborting on the
$(\widehat q+1)$st distinct exact physical key.  The cap phase and DFS phase
are sequential, hence their times add and their simultaneous spaces take a
maximum.  Within DFS, every new physical key contributes its address and
stable value to the persistent dictionary; all seed execution, resets,
failed branches and counter comparisons are already included.  CAP180's
soundness/completeness proof is unchanged.  This gives (1)--(2).
\end{proof}

\begin{corollary}[What effectiveness is actually needed]
The exact bound
\[
T_D=N^{\max\{1,\rho+v+a\}+o(1)},\qquad S_D=N^{s+o(1)}
\]
follows if there exists a public \emph{upper} cap with
$\widehat q\le(a+o(1))\log_2N$, $C_q=N^{o(1)}$, and
$S_q=N^{o(1)}$ (with the already charged address terms).  Merely saying
``total computable'' does not supply these resource ceilings.

If only the semantic witness bound $Q_{\rm good}\le(a+o(1))\log_2N$ is
known, then for every fixed $\delta>0$ the direct cap
$\lceil(a+\delta)\log_2N\rceil$ after a fixed $N_0$ and a finite table below
$N_0$ yields CAP180's $D_\delta$ family.  Therefore any strict native
subpolynomial-space exclusion can still be applied after choosing $\delta$
inside the strict margin.  This is existential uniformity for each fixed
$\delta$, not changing-length advice.
\end{corollary}
