\section{Four preregistered attacks and outcomes}
\begin{description}
\item[F1: mixed witnesses.] The head-move and reversal products use different hard inputs. \textbf{FALSIFIED}: double averaging first selects one SAT input with large total central-gap crossings; one cut on that same run then supplies the reversal bound.
\item[F2: incomplete labels.] A crossing label has only work contents. \textbf{FALSIFIED/REPAIRED}: include finite control, crossing direction, every visited work cell, all work-head positions and interval delimiters. For fixed tapes and alphabets this is still \(O(S+1)\) bits.
\item[F3: uncharged saturation.] Buffering obtains a factor \(J\) without physical addressing or retained bits. \textbf{FALSIFIED AS A FREE CLAIM; PROVED AFTER CHARGING}: each radius-\(J\) jump is a command whose offset costs polylogarithmic bit work, the \(B\)-bit buffer and \(O(\log N)\) counters remain live, and an ordinary simulation pays every skipped cell.
\item[F4: RAM/two-head transfer.] The resulting products hold for multiple input heads or RAM. \textbf{FALSIFIED/RETIRED}: the explicit two-head control below violates both products; indexed RAM is more capable still.
\end{description}

\section{Exact family and declared resources}
The reconstructed module \(H(a,b)\) is the 15-variable, 20-clause signed exact-(2,2) \(W_1\) gadget with the two A sign slots and two B sign slots used in BINARY-WORK-SAT4. Exhaustive model counts are
\[
(\#H_{00},\#H_{01},\#H_{10},\#H_{11})=(772,272,272,0).
\]
Take \(m\) disjoint renamed modules and physically order all \(2m\) A-controlled clauses, then the \(16m\) fixed clauses, then all \(2m\) B-controlled clauses. With fixed-width literal records,
\[
N=\Theta(m\log(m+2)),\qquad G=\Theta(N),
\]
where every cut in the fixed middle block separates all A fields from all B fields. The promise satisfies
\[
F_m(a,b)\in\SAT\quad\Longleftrightarrow\quad a\wedge b=0^m. \tag{1}
\]

The machine has one two-way sequential read-only input head and fixed \(k\) sequential work tapes. \(S\) counts every visited work cell, blank or not, and excludes input. \(H\) is the number of unit input-head moves; \(R\) counts sign changes among nonzero input-head moves; \(T\) counts all transitions. These are simultaneous worst-case ceilings of one total deterministic promise decider.

\section{Same-run crossing theorem}
\begin{lemma}[Average transcript length]
For \(2^m\) distinct finite words over an alphabet of size at most \(2^B\), allowing one empty word, their mean length is \(\Omega(m/(B+1))\).
\end{lemma}
\begin{proof}
At most \(1+A+\cdots+A^L\) words over alphabet \(A\le2^B\) have length at most \(L\). Choose \(L=\lfloor m/(2(B+1))\rfloor\). For all sufficiently large \(m\), fewer than half of the \(2^m\) words have length at most \(L\), so the mean is at least \(L/2\). Small \(m\) are absorbed in the constant.
\end{proof}

\begin{theorem}[Head movement and reversal products]\label{th:head}
Every declared decider satisfies, on infinitely many canonical lengths,
\[
H(S+1)=\Omega(N^2/\log N),\qquad (R+1)(S+1)=\Omega(N/\log N). \tag{2}
\]
\end{theorem}
\begin{proof}
For each \(a\), use the SAT input \(F_m(a,\neg a)\). Fix a cut \(c\) in the central fixed block and record the complete work configuration whenever the input head crosses \(c\). A label needs \(O_k(S+1)\) bits: fixed control/direction, \(S\) fixed-alphabet work symbols, and \(O(k\log(S+1))\) bits for fixed-many work-head positions and interval endpoints.

The \(2^m\) crossing transcripts at \(c\) are pairwise distinct. If \(a\ne b\) shared a transcript, standard deterministic splicing would accept the relevant mixed input \(F_m(a,\neg b)\) or \(F_m(b,\neg a)\). At least one is UNSAT because \(a\ne b\), contradicting correctness. The lemma gives
\[
2^{-m}\sum_a q_c(a)=\Omega(m/(S+1))
\]
for every central cut. Sum over the \(G=\Theta(N)\) cuts, interchange the finite sums, and choose one common \(a_*\):
\[
\sum_c q_c(a_*)=\Omega(Gm/(S+1)).
\]
Every unit input-head move crosses at most one adjacent cut, so \(H(S+1)=\Omega(Gm)\), proving the first inequality using \(m=\Theta(N/\log N)\).

On that same run, some central cut has \(q_c(a_*)=\Omega(m/(S+1))\). Consecutive crossings of one cut alternate direction, so between them the input head reverses at least once. Hence \(R+1\ge q_c(a_*)\) up to an absolute endpoint constant, proving the second inequality. No per-cut maximum and no second input witness is used.
\end{proof}

For polynomial ceilings \(H=N^{h+o(1)}\), \(R+1=N^{r+o(1)}\), \(S=N^{s+o(1)}\), and \(T=N^{t+o(1)}\), (2) gives
\[
h+s\ge2,\qquad r+s\ge1,\qquad t+s\ge2,
\]
all for the same machine.

\section{Charged saturation and bounded jumps}
With a live \(B\)-bit buffer, process \(B\) coordinates per pass. A pass reads the relevant A fields, traverses the fixed block, reads corresponding B fields, and returns or alternates direction. With ordinary movement,
\[
H=O\left(N\left\lceil\frac mB\right\rceil\operatorname{polylog}N\right),\quad
R=O(\lceil m/B\rceil),\quad S=O(B+\log N).
\]
Thus \(B=m^{s+o(1)}\) realizes \(h=2-s\), \(r=1-s\) and \(t=2-s\), saturating (2) up to subpolynomial factors on this easy promise.

Now declare a different model \(M_J\): the sole input head may execute a charged binary-offset command of reach at most \(J\), reading only its target symbol; work tapes remain sequential. An ordinary head simulates one jump with \(O(J+\operatorname{polylog}N)\) transitions and \(O(\log N)\) extra live bits. Therefore
\[
T_0=O(T_J(J+\operatorname{polylog}N)),\qquad S_0=O(S_J+\log N).
\]
Applying (2) to this actual ordinary simulation gives, for \(J=N^{j+o(1)}\),
\[
t+s+j\ge2. \tag{3}
\]
This implication direction is essential: (3) is a necessary condition in the declared augmented model because of an explicit simulation, not a native RAM lower bound.

The charged buffered itinerary uses
\[
T_J=O\left(\frac mB\left(\frac NJ+B\right)\operatorname{polylog}N\right),
\]
so its exponent is \(\max\{1,2-s-j\}\). The independent \(t\ge1\) floor follows from the base input \(a=0^m,b=1^m\): each A sign is pivotal, and a deterministic one-symbol-per-step algorithm must inspect all \(m=\Theta(N/\log N)\) groups. This proves the claimed promise optimum, including \(J=1\) and \(J=N\).

\section{Explicit two-input-head falsifier}
Give the machine two independent sequential read-only heads on the same encoded input. Park head 1 at the A block while moving head 2 once to the B block. Both controlled blocks use the same coordinate order, so advance the heads together, compare the two selected signs, and stop on an overlap. This decides (1) using
\[
H_{\rm total}=O(N),\qquad R_{\rm total}=0,\qquad S=O(\log N).
\]
Consequently both normalized one-head products tend to zero:
\[
\frac{H_{\rm total}(S+1)}{Nm}=O(\log N/m)=o(1),\qquad
\frac{(R_{\rm total}+1)(S+1)}m=o(1).
\]
This is not a contradiction to Theorem~\ref{th:head}; it is a smallest model-transfer countercontrol. A fixed-\(k\) work-tape machine still has only one input head, so the theorem allows independent work heads but not a second input head.
