\section*{Executive status}
\textbf{PROVED/EXACT, explicit restricted source image.} There is a uniformly generated connected proper-3CNF family of fixed physical length $N_b=\Theta(b^2 2^b)$ that realizes every Boolean relation on a designated $b$-variable boundary, with all $2^b$ truth-table choices in independently mutable sign positions. Any standalone code whose universal decoder recovers the \emph{entire} boundary feasibility relation requires at least $2^b=\Omega(N_b/\log^2N_b)$ bits for some source, irrespective of its coding language. Hence universal detached \emph{lossless} joint summaries cannot have a fixed $N_b^\lambda$ physical ceiling, $0<\lambda<1$, on this image.

\textbf{PROVED/EXACT, constructive restricted source image.} The same source family has a uniform, total, polynomial-time, one-child answer-preserving transformation that existentially aggregates half the boundary variables and re-enters the \emph{same} proper-3CNF grammar. For every $b\ge6$, $N_{\lfloor b/2\rfloor}\le N_b^{3/4}$. For $b\ge12$ two genuine recursive steps are above this threshold. No SAT oracle, special signing advice, or hidden prefix is required. The construction does not include arbitrary SAT: $\SAT(F_t)=\bigvee_a t_a$ is directly easy.

\textbf{FALSIFIED/RETIRED general transfer.} A representation-independent lower bound for \emph{lossless full-relation} detachment is not a decision-time lower bound and does not prevent a decision-preserving one-child compressor. Conversely a recursively closed decision child does not preserve compatibility with arbitrary later constraints on forgotten variables. $P$ versus $NP$ and ARC-EDGE-90 remain \textbf{OPEN}.

\section{PROPOSE: four falsifiers before source search}
\begin{enumerate}
\item Every Boolean boundary relation might have a uniformly short detached representation even when the source itself is short. Test against an explicit, independent physical truth-table-sign embedding.
\item Forcing a table through proper ternary Tseitin clauses might introduce repeated literals, disconnected pieces, nonuniform widths or source-dependent output length. Enumerate and validate actual clauses and fixed-width bit encodings.
\item The information obstruction might be circumvented by \emph{decision-only} compression. Construct and reapply an actual answer-preserving child transformation on both answer classes.
\item A child that preserves the parent's SAT bit might incorrectly be called a reusable lossless summary. Search for the smallest pair with the same child but distinct original boundary relations.
\end{enumerate}

\section{BUILD: an explicit fixed-width connected proper-3CNF image}
Fix $b\ge1$, $M=2^b$, boundary $z=(z_1,\ldots,z_b)$ and a binary truth table $t=(t_a)_{a=0}^{M-1}$. Create fresh table variables $p_a$ and pin each $p_a=t_a$ using a four-clause proper ternary gadget
\[
 G(\ell;u,v)=\bigwedge_{\epsilon,\eta\in\{-1,1\}}
 (\ell\vee\epsilon u\vee\eta v),\qquad
 \ell=p_a\ \text{if }t_a=1,\quad\ell=\neg p_a\ \text{otherwise}.
\]
The private $u,v$ are fresh for every pin. Let $\ell_{a,i}$ be $z_i$ if bit $i$ of $a$ is one and $\neg z_i$ otherwise. Form one fan-in-two circuit with leaf
\[
 q_a=p_a\wedge\bigwedge_{i=1}^{b}\ell_{a,i}
 \quad\text{and output}\quad
 y=\bigvee_{a=0}^{M-1}q_a.
\]
A fresh AND/OR gate output $v$ gets the bidirectional Tseitin constraints, respectively
\[
\begin{aligned}
 v=u\wedge w:\quad&
 (\neg v\vee u),\ (\neg v\vee w),\ (v\vee\neg u\vee\neg w),\\
 v=u\vee w:\quad&
 (v\vee\neg u),\ (v\vee\neg w),\ (\neg v\vee u\vee w).
\end{aligned}
\]
Every binary clause $(r\vee s)$ is replaced with
$(r\vee s\vee d)\wedge(r\vee s\vee\neg d)$ using its own fresh $d$. Pin $y=1$ with another private $G(y;u_*,v_*)$. Each clause has three \emph{distinct} variable IDs and no duplicate clause is emitted. Every variable occurs in the connected incidence component of $y$.

The number of binary gates, variables and proper 3-clauses are, exactly,
\[
 g_b=(b+1)M-1,\quad
 V_b=b+3g_b+3M+2=b+3(b+2)M-1,\quad
 C_b=5g_b+4(M+1)=(5b+9)M-1.
\]
Use fixed-width signed literal fields with one sign bit plus a $W_b$-bit variable ID, and one arity bit per clause, with a three-field header of width $W_b$:
\[
 W_b=\left\lceil\log_2(\max\{b,V_b,C_b\}+1)\right\rceil,\qquad
 N_b=(3W_b+4)C_b+3W_b=\Theta(b^2\,2^b).
\]
All $2^M$ sources have this same length. Flipping one $t_a$ changes exactly \emph{four} literal sign fields of the dedicated pin, leaving all IDs, clauses' scopes, headers and other sign fields unchanged. This is proper 3CNF, \emph{not} strict signed exact-$(2,2)$: no transport to that degree-constrained language is asserted.

\begin{lemma}[Exact source projection, independently checked]
For every $b,t,z$,
\[
 \exists\,\text{private variables}\ F_{b,t}(z,\text{private})
 \quad\Longleftrightarrow\quad t_{\operatorname{index}(z)}=1.
\]
In particular $\SAT(F_{b,t})\iff\bigvee_a t_a$, with both SAT and UNSAT inputs present at each $b$.
\end{lemma}
\begin{proof}Each pin fixes its displayed table variable. Tseitin gate equivalences fix every gate output for any $z$, and the equality indicator for each $a$ is one at exactly one boundary word. Hence $y=t_{\operatorname{index}(z)}$. The last pin enforces $y=1$. Conversely, if that bit is one, choose all gate values according to the circuit and arbitrary consistent pad/pin auxiliary assignments. The full proper 3CNF is then satisfied.\end{proof}

\begin{theorem}[Detached full-relation physical floor; PROVED/EXACT restricted]
Let $S(F_{b,t})$ be any binary summary string and $D_b$ be any \emph{common} decoder, even computationally unbounded, for which
\[
 \forall t\ \forall z:\quad
 D_b(S(F_{b,t}),z)=
 {\bf1}\{\exists\text{ private }F_{b,t}(z,\text{private})\}.
\]
The decoder receives neither the source $F_{b,t}$ nor source-dependent advice or an unpaid oracle. If every summary has length at most $L_b$, then
\[
  L_b\ge M=2^b=\Omega(N_b/\log^2 N_b).
\]
Consequently no fixed $\lambda<1$ allows $L_b\le N_b^\lambda$ for all sufficiently large $b$, even if summary generation and decoding are computationally unrestricted.
\end{theorem}
\begin{proof}
Different truth tables disagree at some boundary word. Therefore the common decoder forces $S(F_{b,t})$ to be injective across all $2^M$ tables. There are only $2^{L_b+1}-1$ binary strings of length $\le L_b$. For $L_b\le M-1$ this count is $<2^M$, a contradiction. Since $N_b=\Theta(b^2 2^b)$ and $\log N_b=\Theta(b)$, the stated physical and exponent bounds follow.\end{proof}

\section{Constructive counterpart: genuine hereditary answer-only power shrink}
Set $b'=\lfloor b/2\rfloor$ for $b>1$ and compute
\[
 s_u=\bigvee_{\substack{0\le a<2^b\\a\bmod 2^{b'}=u}}t_a,
 \qquad 0\le u<2^{b'}.
\]
Rebuild \emph{one} child $F_{b',s}$ using the identical fixed-width proper-3CNF grammar. This computes the exact existential projection of the previous relation onto the retained low $b'$ coordinates, while forgetting the high coordinates. Thus
\[
 \SAT(F_{b,t})\iff \bigvee_a t_a
 \iff\bigvee_u s_u\iff\SAT(F_{b',s})
\]
for \emph{both} answer classes. On a validated canonical input, a fixed deterministic constructor recovers the $2^b$ pin signs, computes the OR buckets, emits and checks the complete child, and can be applied again without an oracle. With a straightforward read-only-input/multitape implementation it has polynomial source-reading, lookup, generation, and retained-work costs. The one-tape writable-input and fixed-universal-machine implementations have polynomial simulation overhead; no matched small-space FLMV claim is made.

\begin{theorem}[Restricted recursive power shrink, with a fixed threshold]
For all $b\ge6$,
\[
 N_{\lfloor b/2\rfloor}\le N_b^{3/4}.
\]
The statement is uniform and holds again at every recursive level with $b\ge6$. In particular $b\ge12$ permits two complete above-threshold calls; for $b\le5$ the table has at most 32 truth bits, and the source grammar supplies directly solvable constant-size bases. The one-child recurrence terminates in $O(\log b)$ steps, with polynomial total generation time and space.
\end{theorem}
\begin{proof}
For $6\le b\le15$, substitute the displayed exact integer formulas for $N_b$, as checked in the finite audit. For $b\ge16$, put $q=\lfloor b/2\rfloor\ge8$. The formulas give $N_b\ge15b^2 2^b$ and $N_q\le50q^2 2^q\le(25/2)b^2 2^{b/2}$. Therefore
\[
 \frac{N_q}{N_b^{3/4}}\le
 \frac{25/2}{15^{3/4}}\sqrt b\,2^{-b/4}<1
 \quad(b\ge16).
\]
The last expression decreases from $b=16$. The child stays in the identical grammar and decreases $b$ strictly, so the same argument re-applies; summing polynomial construction costs over $O(\log b)$ levels is polynomial in the original physical length.\end{proof}

\textbf{Necessary countercontrol.} The compression loses discarded boundary information. For $b=2$, tables with their sole one at index $0$ or index $2$ have the same one-bit-boundary child after the low-bit aggregation, but different original full relations. An arbitrary later context that pins the high bit distinguishes them. Thus this two-level \emph{decision} closure is not context-universal lossless relation closure. A source-aware algorithm is free to exploit this loss of information when only the root decision matters.

\section{Finite audit, model ledger, and status}
The standalone dependency-free Python program constructs every proper 3-CNF instance for $b\le3$ (276 source truth tables), plus seven independent sources for each $b=4,5,6,7$; checks all boundary assignments, signed-clause distinctness, connected incidence, deterministic gate-model satisfaction, fixed-width physical bit sizes and single-sign mutations; and independently runs a generic unit-propagating DPLL checker on 72 pinned membership cases. It passes \textbf{6,294 assertion groups}, 72 generic DPLL cases and 130,557 DPLL search calls. The explicit recurrence was numerically checked for $b=6,\ldots,30$; the theorem above proves all larger $b$. Random seed \texttt{20261029}. Only the $b\le3$ table family is exhaustively enumerated; larger cases are seeded or size-formula controls. The source code and immutable JSON are published separately.

\noindent\textbf{Native cost firewalls.} A fixed-k off-line TM pays every input scan, all work cells holding the sign table and aggregation, and output bits. The one-tape writable-input simulation counts the initial input footprint and head movement and can be polynomially slower. A fixed universal machine pays its interpretation and program loading. None of those implementations permits a free polynomial-time black-box SAT oracle or transfers the old exact22 crossing bounds to indexed RAM. The abstract information floor is independent of machine model only because it concerns source-free \emph{encoded output length}.

\section{Role-specific handoff and decisive open lemma}
\noindent\textbf{LSPV-1:} only a detached \emph{full boundary relation} has the source-image output-size floor; do not infer all-decider SAT hardness. \textbf{LSPV-2:} test the explicit physical table-sign lift under degree four, two-positive/two-negative constraints with a \emph{local} sign-preserving exact reduction. \textbf{LSPV-3:} intersect the compressed child with contexts on forgotten high boundary bits and document the first failed join. \textbf{LSPV-4:} audit the input-head, re-entry, peak workspace and exact $N_b^{3/4}$ length inequality under native models.

The next constructive target is a \emph{context-specific} polynomial-time complete joint summary: retain exactly those boundary correlations that later joins truly query, discover that future-context set without an arbitrary SAT oracle, then prove soundness and recursively closed $N^\lambda$ output on all ordinary SAT. The dual separation target needs an unavoidable resource cost for \emph{every} correct general decider, not just detached exact compilation. Both remain \textbf{OPEN}.
