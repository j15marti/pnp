\section{One target and precommitted falsifiers}

\paragraph{Target claim.} The archived /386 checker authenticates paid-owner
identity consistently across a \texttt{gate\_defs} declaration and every DEF
record's \texttt{gate} reference over the full accepted raw-JSON domain.

\paragraph{Falsifiers.}
\begin{enumerate}
\item Distinct raw owner-ID lexemes alias after parsing and are accepted.
\item Owner identity is checked in the declaration but omitted or differently
interpreted at a DEF facet port.
\item A declared owner can be reused under a different parsed type without a cost change.
\item A cheap abstract path collapsing freshness, order, or once-paid ownership
concretely replays in the authoritative checker.
\end{enumerate}

Falsifier 1 occurs.  The checker rejects the tested cross-type and noninteger
cases, so falsifiers 2--3 do not occur on the tested fields.  No proof-shortening
path was found; falsifier 4 is therefore not established as a cost shortcut.

\section{Accepted-byte counterexample}

Starting from the exact W39 packet, replace only owner 1's declaration token by
\texttt{1.0} and both references to that owner by \texttt{1e0}.  The resulting
3,707-byte packet has SHA-256
\texttt{493a071472c35e7c93ff29abe05b3495084cd241d3b1cb570200785757265178}.
It contains the literal raw fragments
\[
  [\texttt{1.0},9,8,8]
  \qquad\text{and}\qquad
  \texttt{"gate":1e0}
\]
twice at the corresponding DEF records.  The unchanged checker accepts it with
exactly 39 paid nodes, three paid owners, 36 RES rows, 59 records, 17 SOURCE rows,
zero odd-charge models, eight even-charge models, eleven negative tests, and
3,981 accumulated assertion groups.

The following differential was executed.  Every accepted row retained the same
logical outcome and cost.

The underflow row is stronger than a spelling-only example: the mathematical
decimal values $\pm10^{-324}$ are nonzero, while ECMAScript binary64 parsing maps
them to signed zeros; \texttt{Number.isSafeInteger} accepts those parsed zeros and
Map key equality identifies them.  This is consistent with RFC 8259 permitting
fractional and exponent syntax while allowing implementation precision limits,
and with ECMAScript's specified Number and Map equality behavior.

\paragraph{Restricted parsed-owner lemma.}
Fix any /386 packet accepted by this checker.  If every raw token at one owner
declaration and all of its DEF references is replaced by a JSON number token
that parses to the same safe integer $i$, while all other bytes decode to the
same values, then every owner lookup, facet check, SOURCE/RES transition, terminal
condition, and summary equality follows the original execution.  Consequently
the modified packet is accepted with the same paid work.  For $i=0$, the class
also contains $+0$ and $-0$ because Map key equality treats them identically.
This is a theorem about this program's decoded-value trace, not a claim that raw
spellings are historically intended to be interchangeable.

\section{Concrete semantics, abstraction, and CEGAR polarity}

A byte-complete concrete state for this replay must contain at least
\[
 c=(b,p,F,G,R,K,A,\Sigma,W,M,O),
\]
where $b$ is the immutable raw byte string; $p$ is parser cursor, stack, token
span, exact decimal spelling and decoded Number; $F$ is the internally generated
signed SOURCE table; $G$ is the ordered paid-owner map including fresh wire and
signed ports; $R$ is the chronological typed record list; $K$ is the checked
clause table; $A$ is terminal ancestry; $\Sigma$ is the summary; $W$ is the
once-per-owner plus once-per-RES cost; $M$ is transient parser/checker state; and
$O$ is rejection or accepted output.  This state authenticates the source,
owner/facet join, parent typing, order, exact Resolution, final empty clause, and
cost.  It does not invent AND3, GF(2), LOCAL-CONVERT, branching, context,
discharge, join, weakening, or deletion transitions absent from this checker.

For the proved alias family define $\alpha$ to retain $F,G,R,K,A,\Sigma,W$ but
map each owner token to its parsed safe-integer identity class.  Define
$\gamma(a)$ as all raw byte configurations whose historical JSON parse produces
that same retained trace.  Parser consumption and every subsequent checker step
have a matching abstract successor; completed empty-clause acceptance is
preserved; and
\[
  W^{\#}(\alpha(c))=W(c)=39.
\]
Thus this local quotient has concrete-step inclusion, completed-refutation
preservation, and abstract cost no greater than concrete cost.  An abstraction
that instead demands raw spelling equality omits the concretely accepted
\texttt{1.0}/\texttt{1e0} path and is not an overapproximation of this checker.

CEGAR therefore cannot declare the alias path spurious: it was replayed in the
authority and accepted.  A canonical raw-owner lexer is a useful \emph{repaired
language}, but rejecting this witness changes the accepted language unless
independent historical authority first requires canonical bytes.  For the full
calculus, all unauthenticated operations remain MAY transitions at safe charge;
the local quotient does not complete P2-C3.
