\section{Authenticated layout and exact semantics}

Let the source-bound formula have the supplied form
\[
 F(z,y_1,\ldots,y_B)=\bigwedge_{i=1}^{B}F_i(z,y_i),
\]
where the private variable sets of the $y_i$ are pairwise disjoint after $z$ is fixed.  The source parser must authenticate that partition; overlap is a rejection, not an optimization opportunity.  With $Z$ the explicit set of shared rows,
\begin{align}
 F\in\SAT &\iff \exists z\in Z\;\forall i\;\exists y_i\;F_i(z,y_i),\label{eq:sat}\tag{SAT}\
 F\in\UNSAT &\iff \forall z\in Z\;\exists i\;\forall y_i\;\neg F_i(z,y_i).\label{eq:unsat}\tag{UNSAT}
\end{align}
The bad-block index may depend on $z$.  Equation~\eqref{eq:sat} uses the disjointness assumption to glue the private witnesses; without that assumption the formula is not the claimed product layout.

\begin{theorem}[charged deterministic row scan]
Suppose $R=|Z|\le n^{.195+o(1)}$, $B\le n^{.65+o(1)}$, each residual has encoded length at most $m\le n^{.35+o(1)}$, and $A$ is one fixed uniform total exact SAT decider with time $T_A(m)$ and writable workspace $S_A(m)$.  A source-validating deterministic scan decides the supplied layout with
\begin{align}
 T'(n)&\le n^{1.195+o(1)}+n^{.845+o(1)}T_A(n^{.35+o(1)}),\label{eq:time}\tag{1}\\
 S'(n)&\le n^{.35+o(1)}+S_A(n^{.35+o(1)}),\label{eq:space}\tag{2}
\end{align}
provided rows and residuals are streamed and no larger persistent table is retained.
\end{theorem}

\begin{proof}
Enumerate every authenticated $z$.  For a row, run $A$ on all blocks until a NO is found.  Record that source block index and continue.  If every block is YES, equation~\eqref{eq:sat} makes the global formula satisfiable; if every row obtains a NO, equation~\eqref{eq:unsat} makes it unsatisfiable.  All calls of either polarity and all failed block attempts are included: at most $RB=n^{.845+o(1)}$.  Writing or validating a complete row of residuals contributes at most $n^{1.195+o(1)}$.  Keeping only one residual and one child execution live gives~\eqref{eq:space}; simultaneous retention of rows, transcripts, or witnesses must instead be added.  No semantic NO is treated as a short externally checkable proof: independent verification reruns $A$ or supplies and verifies a separate proof object.
\end{proof}

If $T_A(m)=m^{t+o(1)}$ and $S_A(m)=m^{s+o(1)}$, the reproduced exponents are
\[
 t'=\max\{1.195,\ .845+.35t\},\qquad
 s'=\max\{.35,\ .35s\}.
\]
Consequently a one-step $t'\le1.33$ needs
\[
 t\le\frac{1.33-.845}{.35}=\frac{97}{70}=1.385714\ldots,
\]
and $s'\le.5$ needs $s\le10/7$, together with the streaming premise.  The statement ``$\SAT\in\mathrm P$'' supplies some fixed polynomial exponent, not either numerical gate.

\section{Conditional hereditary contraction and its exact missing premise}

If the \emph{same fully charged, source-authenticating transformation} can be compiled on every arbitrary child produced at every generation, then
\[
 t_{j+1}=\max\{1.195,.845+.35t_j\},\qquad
 s_{j+1}=\max\{.35,.35s_j\}.
\]
The fixed point is $(t_*,s_*)=(1.30,.35)$.  From $(t_0,s_0)=(100,100)$ the eighth iterate is
\[
 t_8=1.32222601010546875\ldots,\qquad s_8=.35.
\]
This arithmetic is exact, but it is not an algorithm construction.  The missing theorem is a uniform, solver-dependent, all-input hereditary splitter that pays for solver-code access, parsing, every descendant, materialization, replay, output, and peak live storage.  A seed-independent source-only splitter with these guarantees would already yield an unconditional $n^{1.30+o(1)}$-time, $n^{.5+o(1)}$-space SAT algorithm, contradicting the known deterministic tradeoff.  Thus the solver dependence must be essential and proved, not merely named.

\section{Correct-path semantics: outputs and wrong paths}

The following interfaces are sound and keep the two polarities separate.

\paragraph{SAT path.}  A certificate is one common row $z$ and a private witness $y_i$ for every block.  The verifier checks every original-source constraint and returns $\SAT(z,y_1,\ldots,y_B)$ or $\UNKNOWN$.  It never returns UNSAT.  The full witness, source reads, and output verification are charged.  With read-only certificate access it can be replayed using small writable workspace; an ordinary space-bounded nondeterministic machine cannot reread guess bits unless it writes them to its work tape.

\paragraph{UNSAT path.}  A certificate names, for every explicit $z$, a block $i_z$ and a source-bound local refutation $\pi_z$.  The verifier checks every $\pi_z$ against $F_{i_z}(z,\cdot)$ and returns $\UNSAT$ only if all rows verify; otherwise it returns $\UNKNOWN$.  Index bits alone are not refutations of arbitrary CNFs.  Alternatively, a deterministic total seed can be rerun on each named block, but then all seed computation is paid.

\paragraph{Free polarity.}  A supplied bit saying which branch is correct is the answer bit.  It is advice.  A uniform deterministic algorithm may interleave two sound partial branches only after proving that, on every input, at least one completes with a verified answer within the claimed resources.  Soundness alone does not give completeness or a runtime bound.

\paragraph{A supplied $k$-bit path.}  For a monolithic verifier of time $V$ and space $W$, deterministic enumeration costs at most $2^kV$ time and $W+O(k)$ writable bits (or repeated streaming access), not $V$.  If the certificate decomposes into independently verifiable row-local strings of lengths $k_z$, enumeration may cost $\sum_z2^{k_z}V_z$ rather than $2^{\sum_z k_z}$; this improvement requires a proof that no global consistency constraint was lost.  A depth-$k$ adaptive strategy may contain $2^k$ leaves.  Supplying one favorable path neither bounds nor implements the whole strategy.  In an alternating reading of~\eqref{eq:unsat}, every universal $z$ and every universal private assignment $y_i$ remains charged; the prefix $\forall z\exists i\forall y_i$ is not an existential nondeterministic path.

\section{Arbitrary-CNF extension barrier}

\begin{proposition}[singleton-layout certificate barrier]
If every UNSAT block in arbitrary CNF admits a polynomial-length, polynomial-time verifiable local certificate of the kind required above, then $\mathrm{NP}=\mathrm{coNP}$.
\end{proposition}
\begin{proof}
Take the allowed special case $R=B=1$ and empty shared assignment $z$.  The single block is an arbitrary CNF.  Completeness gives a polynomial certificate for every UNSAT CNF, while soundness gives an NP verifier for UNSAT.  Hence $\mathrm{coNP}\subseteq\mathrm{NP}$; complementing gives the reverse inclusion.
\end{proof}

This proposition does not bar restricted specialists such as implication-path certificates for 2-CNF, source-aware T5 path masks, or replay of a hypothetical deterministic SAT decider.  It bars silently treating route indices as complete arbitrary-CNF refutations.

\section{Matched SAT-witness cost}

The row scan is a decision procedure given a decision seed; it does not automatically output the $y_i$.  Ordinary bit-pinning over $B=n^{.65+o(1)}$ blocks with $n^{.35+o(1)}$ private bits each uses $n^{1+o(1)}$ seed queries.  Rewriting a length-$n^{.35}$ residual per query costs $n^{1.35+o(1)}$ materialization even with zero-cost calls.  With a seed exponent $t=1.30$, direct query time is
\[
 n^{1+.35(1.30)+o(1)}=n^{1.455+o(1)}.
\]
This falsifies the \emph{naive} matched-$1.33$ witness claim, not all possible incremental, batched, algebraic, flow, dynamic-programming, alternate-order, or compact-circuit witness algorithms.
