\section{Finding and repaired lemma}
\textbf{FALSIFIED/RETIRED:} ``raw numeric identifier lexemes are authenticated injectively by native-/341 acceptance.''  They are not: JSON parsing precedes the checker's identity test, and ECMAScript Number is non-injective on JSON numeric lexemes.

\textbf{Restricted repair (PROVED/EXACT at the language boundary).}  Before constructing identifier maps, require either (a) identifier tokens to be strings in a fixed canonical lexical grammar, compared byte-for-byte, or (b) numbers satisfying
\[
  \operatorname{Number.isSafeInteger}(x)
\]
and additionally bind the external canonical source bytes.  Under choice (b), numeric value equality is injective only over the admitted safe-integer domain; it does not authenticate the original raw number spelling.  The full mixed checker must state which of these two semantics is historical.

This counterexample is genuinely accepted and therefore remains in every sound CEGAR concrete semantics.  It may not be removed as ``spurious.''  A sound abstraction must include identifier lexical type/range, source-byte binding, parent typing, context and cost; refinement is justified only for paths whose exact OS replay rejects.
