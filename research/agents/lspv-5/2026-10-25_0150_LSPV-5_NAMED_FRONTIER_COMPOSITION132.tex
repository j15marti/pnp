\section{Endpoint and model audit}
Let $\mathcal E$ be the set of pairs $(t,s)$ simultaneously realized by one
fixed uniform total exact ordinary-SAT decider on every input of bit length
$N$, with time $N^{t+o(1)}$ and counted work/index space $N^{s+o(1)}$ in the
indexed read-only-input random-access Turing-machine model.  The original
FLMV model has a read-only indexed input tape and counts work and index tapes;
its Corollary 5.8 states, for every $c>1$,
\[
 \operatorname{NTIME}[n]\not\subseteq
 \operatorname{DTISP}\left[n^c,
 o\!\left(n^{\beta(c)}\right)\right],\qquad
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
At $c=241/200$, $\beta(c)=11642479/23232400>1/2$.
The strict forbidden box therefore has positive slack around the candidate
fixed point $(6/5,1/2)$.  FLMV also proves other tradeoffs, but it does not
prove that the historical expression $2\cos(\pi/7)$ is a universal
time--space \emph{product} threshold.  The project correctly retired that
misuse.  The missing theorem is still an all-input, same-machine, fully
charged favorable edge, or a finite cofinal route of achievable pairs into a
verified forbidden region.

The user-directed bit ledger treats one declared elementary bit operation as

\section{Exact matched pair and compatibility theorem}
For literals $\ell_1,\ell_2,\ell_3$, let
$X(\ell_1,\ell_2,\ell_3)$ assert that exactly one literal is true.  It is
compiled to the five proper ternary clauses excluding truth rows of weights
$0,2,3$.  On variables $a,b,c,d$ define
\begin{align*}
 U={}&X(a,b,c)\wedge X(a,b,d)\wedge X(a,c,d)\wedge X(b,c,d),\\
 V={}&X(a,b,c)\wedge X(a,b,d)\wedge X(a,c,d)\wedge X(\neg b,c,d).
\end{align*}
Then $U$ is UNSAT and $V$ has the unique source assignment
$(a,b,c,d)=(1,0,0,0)$.  Every proper subset of the four modules is SAT on
both sources.  Hence every partition into at least two proper module blocks
has the same all-YES SAT-status vector on $U$ and $V$.

Given any clause order, open each variable at its first occurrence and close
it after its last occurrence.  At event cut $i$ let $S_i$ be the set of live
\emph{original source names}.  For a block $(i,j)$ and assignments
$u:S_i\to\{0,1\}$, $v:S_j\to\{0,1\}$, construct the ordinary child by
pinning $u$, replaying every source clause in the block under an injective
local renaming, pinning $v$, and rejecting an inconsistent value on
$S_i\cap S_j$ before a child call.

\begin{theorem}[Named-frontier composition; PROVED/EXACT restricted]
For every valid closed scoped stream and every legal block path
$0=i_0<i_1<\cdots<i_r=L$, the dynamic program that propagates exactly the
reachable assignments to each named set $S_{i_j}$ accepts if and only if the
source CNF is satisfiable.  Replacing each block relation by its nonemptiness
bit is not sound in general; the matched pair $U,V$ is an explicit
counterexample.  Before clause satisfiability or reachability pruning, the
number of compatible assignment pairs on edge $(i,j)$ is exactly
\[
 2^{|S_i\cup S_j|};
\]
the product proxy $2^{|S_i|+|S_j|}$ overcounts by
$2^{|S_i\cap S_j|}$.
\end{theorem}
\begin{proof}
A satisfying source assignment restricts to a consistent boundary tuple and
satisfies every pinned block child.  Conversely, adjacent reachable tuples
agree on every shared original name.  Since each name has one contiguous live
interval, these equalities glue the local witnesses into one global value per
source variable; every source clause is replayed in exactly one block, so the
global assignment satisfies the source.  For $U,V$, all proper module-block
status bits are YES although the parent labels differ, proving the status-only
failure.  A compatible pair is equivalent to one assignment on the union:
values on the intersection are shared and every other value is free.  This is
a bijection with $\{0,1\}^{S_i\cup S_j}$.
\end{proof}

This theorem proves a correct restricted algorithm and a sharper scheduling
objective.  It does not prove that an arbitrary decider materializes any
boundary relation, that the relation lacks a compact representation, or that
named-frontier enumeration is unavoidable.

\section{Reproducible two-level audit}
The independent standard-library executable builds the two ordinary proper
3CNFs, validates the closed scopes, computes fixed, union-optimal and
product-optimal schedules, creates fully serialized pin children, memoizes
identical children, and recursively repeats the construction once.  Each
individual run completed in under four seconds.  There is no randomness.
Eighty-two assertion groups completed with zero failures, including all truth
rows of the exact-one compiler and brute compatible-pair counts on every
tested top-level schedule edge; a second
run was byte-identical.

Both sources have 28 events, source width four and encoded length 1,078 bits.
All top-level unpinned blocks are locally SAT under every tested schedule.
The exact named two-level solver nevertheless rejects $U$ and accepts $V$.

SAT and UNSAT success invariants are deliberately asymmetric.  SAT preserves

free true-label bit.

The strongest defensible proof spine remains ARC/FLMV because its endpoint is
verified and the finite-hit arithmetic is sound.  The exact missing arrow is
\[
 \boxed{\text{arbitrary ordinary SAT input and one achievable }(t,s)
 \Longrightarrow
 \text{one uniform all-input exact successor on a genuinely favorable pair}.}
\]
The successor may be existential and state-adaptive, but the same machine must
simultaneously realize its time and space guarantees.  A certified
low-width-stream join, a cheaper schedule for one implementation, or a source
family that is easy after affine/factor recognition does not fill this arrow.
