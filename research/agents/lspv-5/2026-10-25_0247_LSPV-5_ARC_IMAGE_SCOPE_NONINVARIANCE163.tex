\section{The easy grid padding}
For $q\ge2$, let $V_q=\{u_{i,j}:1\le i,j\le q\}$.  For every horizontal or
vertical grid edge $e=\{u,v\}$ introduce one private variable $z_e$ and the
proper positive ternary clause
\[
 C_e=(u\vee v\vee z_e).
\]
Let $G_q=\bigwedge_e C_e$.  It has $q^2$ grid variables,
$2q(q-1)$ private variables and clauses, is a dual-Horn formula, and is
satisfied by the all-one assignment.  Its canonical fixed-record encoding
has $\Theta(q^2\log(q+2))$ bits.  The clause and any addressed bit are
computed from the record index using $\operatorname{polylog}q$ arithmetic
and $O(\log q)$ index/work bits.

For $M=M(n)$ take
\[
 q(n)=\left\lfloor\sqrt{\frac{M}{\log_2(M+2)}}\right\rfloor
\]
for all sufficiently large $n$, and define the disjoint conjunction
\[
 K(F)=J(F)\wedge G_{q(n)},
\]
renaming the grid variables above the fixed $J(F)$ variable range.  Headers,
record boundaries, renaming offsets and every output bit are paid.  Let
$\mathcal K=\{K(F):F\text{ any ordinary string}\}$.

\begin{theorem}[Scope width is not invariant under local complete recoding]
\label{th:main}
The fixed image $\mathcal K$ satisfies all of the following.
\begin{enumerate}
\item $\SAT(K(F))=\SAT(F)$ on both labels and
$|K(F)|=n^{1+o(1)}$.
\item $K$ has an $n^{o(1)}$-work addressed-bit accessor using
$O(\log n)$ extra counted writable/index space; hence
$E_{\mathcal K}=E$ in the same FLMV model.
\item Every valid OPEN/CLAUSE/CLOSE scoped presentation of the clauses of
$K(F)$ \emph{as written}, under every clause order, has maximum live-name
width
\[
 w(K(F))\ge q(n)=|K(F)|^{1/2-o(1)}.
\]
The same lower bound survives any fixed number of restrictions that touch
only variables of the $J(F)$ component.
\end{enumerate}
\end{theorem}

\begin{proof}
The grid component is independently satisfiable, proving the exact SAT and
UNSAT equivalence.  Its encoded length is
$\Theta(q^2\log(q+2))=\Theta(M)$, so the total remains
$n^{1+o(1)}$.  An addressed output request first decodes the combined header
and record range.  A $J(F)$ request invokes the fixed local accessor; a grid
request computes its horizontal/vertical edge, private auxiliary ID and bit
field by arithmetic on $O(\log n)$-bit indices.  Thus a promised solver on
$\mathcal K$ can be simulated on every ordinary $F$ with multiplicative
$n^{o(1)}$ time and additive $O(\log n)$ space.  Restriction of an all-input
solver gives the reverse inclusion, hence $E_{\mathcal K}=E$.

It remains to prove width.  At every clause event take the set of live names
as a bag.  Each primal-graph edge has both endpoints live at its clause, and
each variable is live on one interval.  These bags are therefore a path
decomposition of the primal graph.  The primal graph contains the
$q\times q$ grid on the $u_{i,j}$ as a subgraph.

For each row $i$ and column $j$, let $B_{i,j}$ be their union.  Each
$B_{i,j}$ is connected and any two such crosses touch.  A set of fewer than
$q$ vertices misses some row and some column, hence misses their cross; so
every hitting set for these crosses has size at least $q$.  In any path
decomposition, bags meeting a fixed connected cross form an interval.
Pairwise-touching crosses give pairwise-intersecting intervals, and intervals
have the Helly property, so one bag hits every cross.  That bag contains at
least $q$ names.  Removing or assigning variables only in $J(F)$ leaves this
grid subgraph unchanged, proving the last claim.
\end{proof}

The path-decomposition correspondence is an \textbf{EXACT THEOREM TRANSFER}
from graph width to the declared raw scoped-stream object.  It is a
\textbf{FAILED TRANSFER} to SAT decision work: the padding is public,
dual-Horn, independently satisfiable and source-readable.

\section{What the theorem does not prove}
A fixed normalizer for this deliberately padded image can delete every grid
record after a charged header/range calculation and feed only $J(F)$ onward.
Equivalently, the project may select another locally complete image.  Thus
Theorem~\ref{th:main} proves no lower bound on normalization, no compulsory
time or space, no obstruction to an $A$-dependent intensional compiler, and
no favorable successor.  It proves the following logical firewall only:
\[
 \boxed{\text{local indexed completeness}}
 \not\Longrightarrow
 \boxed{\text{low raw scope width of the chosen formula representation}}.
\]
Consequently, the Role-3 contractor requires a separate theorem that either
selects a fixed FLMV endpoint image already satisfying its promise or
constructs a paid strict-box-preserving normalizer.  Complexity-equivalence
of image promises does not supply that structural fact.
