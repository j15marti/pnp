\section{One target, quantifiers, and preregistered falsifiers}
Let \(E\) be the set of exponent pairs jointly achieved by one fixed,
uniform, deterministic, total, exact ordinary-SAT decider \(A\) on every
ordinary \(N\)-bit input in the indexed read-only-input random-access
Turing-machine model of Fortnow--Lipton--van Melkebeek--Viglas (FLMV):

\[
T_A(N)\le N^{t+o(1)},\qquad S_A(N)\le N^{s+o(1)}.
\]
Under \(P=NP\), a finite diagonal \((K,K)\in E\) exists.  A sufficient but
still \OPEN{} result would be a fully charged finite route for cofinally many
achievable integer diagonals into
\[
t<c_\star=\frac{241}{200},\qquad
s<d_\star=\frac{11642479}{23232400},\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
The illustrative map with fixed point \((6/5,1/2)\) remains unconstructed.
The old universal \(t+s<2\cos(\pi/7)\) endpoint remains
\textbf{FALSIFIED/RETIRED}.

The single target here is narrower: determine whether an all-input one-pass
ordinary-CNF-to-scoped-stream normalizer must be fully materialized before
the already proved fixed-depth named-block contractor can run.  Before the
source search, four falsifiers were fixed.
\begin{description}
\item[H1.] The outgoing boundary of a block is unknown when the block begins,
so online fusion is impossible.  \textbf{FALSIFIED}: buffer one block, retain
its incoming live set, and read its outgoing live set at the last event.
\item[H2.] One-pass fusion silently replays the stream.  \textbf{FALSIFIED}
for the declared pause/resume interface; each event is consumed once.
Without pause/resume or equivalent bounded backpressure this repair fails.
\item[H3.] A second recursive level requires rerunning the unknown normalizer
on a nonordinary representation.  \textbf{FALSIFIED} for the declared
construction: the first child is a fully serialized ordinary proper 3CNF,
and its next scoped order is construction-derived.  No second call to the
source normalizer is free or needed.
\item[H4.] Removing the full normalized-stream buffer already proves an ARC
successor.  \textbf{FALSIFIED}: the paused normalizer's live state and time
remain in the same-machine ledger, and the normalizer itself is still
\OPEN{}.
\end{description}

\section{Declared fusion interface}
Fix a total uniform transducer \(G\), allowed to depend on the fixed program
of \(A\), with the following specification on every ordinary input string
\(F\) of length \(N\).  It either rejects an invalid encoding according to
the total SAT convention, or emits a validated closed sequence of
\(\mathrm{OPEN}(v),\mathrm{CLAUSE}(C),\mathrm{CLOSE}(v)\) events for an
ordinary proper-3CNF \(H_F\) such that
\[
\SAT(H_F)=\SAT(F).
\]
Each name is opened and closed once; a clause is emitted only while all of
its names are live.  The header declares its clause count \(m\), the total
stream length is \(M\le N^{\mu+o(1)}\), and its maximum live width is
\[
w\le\delta\log_2 N+O(1).
\]
The complete charged transducer cost is \(N^{r+o(1)}\) elementary bit
operations and \(N^{\eta+o(1)}\) simultaneously live writable/index bits.
It supports deterministic pause/resume while its entire current state stays
live.  The stream is write-once/read-once: no output tape is reused as an
uncharged random-access input.

This is an interface assumption, not an established all-input construction.
It includes parsing, validation, source reads and rereads, unchanged and
changed writes, control, addressing, arithmetic, rule selection, failed
attempts, and emitted header/body bits.  Program code is fixed and finite.
Any \(A\)-assisted discovery calls made by \(G\) must already be included in
\((r,\eta)\), with their own same-machine simultaneous cost.

\section{Exact online semantic composition}
Split the emitted clauses into consecutive blocks of
\(b=\lceil\sqrt m\rceil\) clauses, except possibly the last.  For a block
\(i\), let \(L_i\) be the live original-name set immediately before its first
event and \(R_i\) the live set after its last event.  Given consistent
assignments \(\alpha\) on \(L_i\) and \(\beta\) on \(R_i\), form the ordinary
proper-3CNF child consisting of the block clauses, four-clause proper
pin gadgets for \(L_i\), and pins for \(R_i\setminus L_i\).  Private pin
names are fresh.  Define
\[
Q_i(\alpha,\beta)=\SAT(\mathrm{Child}_i(\alpha,\beta)).
\]

\begin{lemma}[One-pass exact join]
The parent is satisfiable exactly when the online dynamic program beginning
with the empty assignment can traverse all blocks through relations \(Q_i\)
and finish at the empty assignment.  One pass over the scoped event stream
is sufficient.  At block \(i\), the machine retains the current reachable
row on \(L_i\), buffers only that block, learns \(R_i\) at its end, evaluates
all consistent \(Q_i\), replaces the row, discards the block, and resumes
\(G\).
\end{lemma}
\begin{proof}
Every variable whose clause occurrences cross a cut is live at that cut.
Thus agreement of adjacent boundary assignments gives one consistent value
to every name shared by multiple blocks.  Each private or nonboundary name
occurs in one block and is existentially witnessed by that block's exact SAT
call.  Gluing the local witnesses proves the forward direction; restricting
a parent witness to each boundary proves the reverse.  The open/close
contract exposes both boundary sets by the time the current block finishes,
so no earlier event is reread.
\end{proof}

The same proper pin syntax gives each constructed child a known valid scoped
order with width at most \(w+2\).  Therefore the block operation itself may
be repeated for any fixed depth \(d\), without rerunning \(G\).  Each leaf is
a fully serialized ordinary input to the same \(A\); it is not a descriptor,
oracle answer, or implicit circuit.

\section{New fused same-machine resource theorem}
\begin{theorem}[One-pass fusion envelope; PROVED/EXACT restricted]
Under the preceding interface, for every fixed integer \(d\ge1\), there is
one uniform total exact machine \(B_{A,G,d}\) with
\[
\boxed{\begin{aligned}
t_d&\le\max\left\{r,
 \mu+2d\delta,
 \mu(1-2^{-d})+2d\delta+\mu 2^{-d}t\right\},\\
s_d&\le\max\left\{\eta,
 \frac\mu2,\delta,\mu 2^{-d}s\right\}.
\end{aligned}}
\tag{1}
\]
All displayed exponents have \(o(1)\) slack.  In particular, a separate
\(N^{\mu+o(1)}\)-bit readable buffer for the entire normalized stream is not
required.
\end{theorem}
\begin{proof}
At recursion level \(i\), an ordinary child has
\(N^{\mu 2^{-i}+o(1)}\) encoded bits.  Original sparse names and fresh helper
names still use only \(O(\log N)\) bits per literal, so headers and complete
ordinary bodies preserve this exponent.  A node creates at most
\[
N^{\mu2^{-(i+1)}+2\delta+o(1)}
\]
children: the first term is its balanced block count and the second charges
all consistent assignments to the union of its two boundaries.  Multiplying
at fixed depth \(d\) yields at most
\[
N^{\mu(1-2^{-d})+2d\delta+o(1)}
\]
leaf calls.  Each call to \(A\) costs
\(N^{\mu 2^{-d}t+o(1)}\), proving the third time term.  Complete construction,
serialization, parsing, compatibility checks, rejected pairs, headers,
cache operations, and row updates across all nodes cost at most the same
node count times the applicable child length, bounded by
\(N^{\mu+2d\delta+o(1)}\).  The one-pass normalizer contributes the separate
\(N^{r+o(1)}\) term.

Depth-first scheduling pauses \(G\), keeping its
\(N^{\eta+o(1)}\)-bit state live.  It buffers at most one root block/child of
\(N^{\mu/2+o(1)}\) bits, retains the current boundary row and names in
\(N^{\delta+o(1)}\) bits, and runs one leaf guest using
\(N^{\mu 2^{-d}s+o(1)}\) bits.  Descendant and ancestor buffers form a fixed
geometric stack dominated by the first child.  Taking the maximum gives the
second line of (1).  The same schedule realizes the time and space bounds;
no coordinate is borrowed from another program.
\end{proof}

\paragraph{Two genuine levels.}
For \(d=2\),
\[
t_2\le\max\{r,\mu+4\delta,3\mu/4+4\delta+\mu t/4\},
\quad
s_2\le\max\{\eta,\mu/2,\delta,\mu s/4\}.
\tag{2}
\]
For the illustrative \(\mu=1,(t,s)=(6/5,1/2)\), (2) enters the strict
FLMV box whenever
\[
r<241/200,\qquad \eta<11642479/23232400,\qquad
\delta<31/800.
\tag{3}
\]
This arithmetic identifies a sharp missing interface target.  It does not
prove that such \(G\) exists.  Role~2's current scope-toll results and
Role~5's image-scope noninvariance show why unconditional or raw-order
normalizers cannot simply be assumed; an \(A\)-dependent all-input
normalizer remains a \textbf{CANDIDATE}.

The theorem fails as stated if \(G\) cannot pause, if its output count/header
is unavailable without replay, if it emits a nonvalidated/nonclosed grammar,
if a child is only a virtual descriptor rather than an ordinary string, or
if second-level name compatibility is not construction-derived.  In those
cases the replay, acquisition, buffer, or adapter cost must be added.  A
parent-length \(A(F)\) fallback preserves exactness but not contraction.

\begin{itemize}

Chen--Lou--Papakonstantinou--Tang give SAT algorithms parameterized by
treewidth and time--space tradeoffs; bounded-width dynamic programming is a

give locally indexable reductions; local output-bit access is a
\textbf{useful structural analogy requiring a new transfer theorem}, not a
low-width or low-space normalizer.  Circuit common-subexpression elimination,
stream backpressure, and cache fusion are likewise analogies; no VLSI or
physical switching lower bound transfers to FLMV bit work.

PQC prompts do not yield a model-matched theorem here.  Schur squares,
quadratic-relation rank, syzygies, collision entropy, and cryptographic
binding are \textbf{FAILED TRANSFERS} for this specific streaming acquisition
question absent a new exact correspondence.  The LWE-style black-box lesson
is only an \textbf{ANALOGY/CANDIDATE}: allow \(G\) to depend on black-box
behavior of \(A\), while charging every query.  Hash/random-oracle assumptions
are inadmissible.
