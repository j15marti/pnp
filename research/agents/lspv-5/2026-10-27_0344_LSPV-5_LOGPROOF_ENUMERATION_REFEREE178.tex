\section{Falsifiers fixed before source review}

\begin{enumerate}
\item Candidate runs that share writable state can accept a SAT input even though every isolated verifier call is sound.
\item Per-input selection among short verifiers need not produce one globally sound verifier or a uniformly enumerable sound portfolio.
\item A separate proof head can distinguish proof strings only through the cells it reaches; nominal suffix length cannot be charged as observed information.
\item A certificate-enumeration consequence in FLMV's indexed model cannot import a sequential-head crossing or reversal lower bound, nor can a simulation upper bound be reversed.
\end{enumerate}

All four controls fire.  The first two require explicit theorem hypotheses; the third sharpens a finite coefficient without changing the exponent face; the fourth remains a model-transfer prohibition.

\section{Native verifier semantics}

Let $F$ range over every ordinary encoded CNF of physical length $N$.  Fix one deterministic, uniform, total indexed-bit-Turing interpreter $I(F,j,\pi)$.  Its source tape is the genuine read-only input in the FLMV/Williams random-access model; all address generation, proof-bit service, work-tape traffic and the one-bit result are charged.  The interpreter starts from its prescribed blank work state on every call.  Malformed indices, malformed proofs and clock expirations return zero.

For constants $a,b,r,s\ge0$, suppose that for all sufficiently large $N$:
\begin{align*}
  0\le j&<M(N)\le N^{b+o(1)},\\
  |\pi|&\le (a+o(1))\log_2N,\\
  T_I(F,j,\pi)&\le N^{r+o(1)},\qquad
  S_I(F,j,\pi)\le N^{s+o(1)}.
\end{align*}
The common interpreter supplies the required uniform indexing of the portfolio.  Its semantic obligations are
\begin{align}
 F\in\SAT &\Longrightarrow \forall j,\pi\quad I(F,j,\pi)=0, \tag{S}\label{sound}\\
 F\in\UNSAT &\Longrightarrow \exists j,\pi\quad I(F,j,\pi)=1. \tag{C}\label{complete}
\end{align}
Thus every portfolio member is globally SAT-sound and the whole portfolio is UNSAT-complete.  No true-label oracle selects $j$.

\begin{theorem}[Uniform verifier-portfolio enumeration]
Under \eqref{sound}--\eqref{complete}, one fixed uniform deterministic total ordinary-SAT decider exists in the same indexed model with
\[
 T_D(N)\le N^{\max\{1,r+a+b\}+o(1)},\qquad
 S_D(N)\le N^{\max\{0,s\}+o(1)}.
 \tag{1}
\]
The case $b=0$ independently proves LSPV-1 ARC-LOGPROOF-ENUMERATION-FRONTIER199's main enumeration lemma.
\end{theorem}

\begin{proof}
First parse the physical input in $N^{1+o(1)}$ time and $N^{o(1)}$ indexed space, rejecting invalid encodings according to the language convention.  Enumerate every $j<M(N)$ and every binary $\pi$ of length at most $L(N)=(a+o(1))\log_2N$.  The number of proof strings is
\[
             \sum_{\ell=0}^{L}2^\ell=2^{L+1}-1=N^{a+o(1)},
\]
so the number of calls is $N^{a+b+o(1)}$.  Run $I$ from its genuine blank state on each pair.  Return UNSAT after the first accepting call and SAT after all calls reject.  Equations \eqref{sound}--\eqref{complete} prove both labels.

Fresh reset can be implemented without retaining all previous configurations.  Simulate indexed writable cells with an address-keyed dictionary containing only the cells touched in the current call, with blank as the default.  There are at most $\min\{T_I,S_I\}$ relevant positions under the native maximum-address convention; address comparison, lookup and clearing cost only polylogarithmic factors.  Candidate counters, $j$, and $\pi$ occupy $O((a+b+1)\log N)$ bits.  Clearing the current dictionary before the next call costs at most its already bounded call time and reuses the same storage.  Hence call times add while peak storage does not, proving (1).
\end{proof}

Using the project's verified strict exclusion box
\[
 c_\star=\frac{241}{200},\qquad
 s_\star=\frac{11642479}{23232400},
\]
the immediate same-machine consequence is
\[
 s<s_\star\quad\Longrightarrow\quad
 \max\{1,r+a+b\}\ge c_\star.                    \tag{2}
\]
The inequalities are strict: equality with $c_\star$ is not excluded, and an $o(1)$ term cannot be used to erase a missing constant margin.

\section{Two exact counterexamples}

\begin{counterexample}[No-reset enumeration]
Maintain a persistent bit $d$, initially zero.  On proof $0$, set $d=1$ and reject.  On proof $1$, accept exactly when either the source is UNSAT or $d=1$.  Every \emph{fresh} call on a SAT source rejects, while proof $1$ freshly accepts every UNSAT source.  But a purported enumerator that runs proofs $0,1$ without resetting accepts every SAT source on its second call.  Thus fresh blank state or a proved equivalent reset discipline is load-bearing.
\end{counterexample}

\begin{counterexample}[Input-selected unsound verifiers]
Take one SAT source $S$ and two UNSAT sources $U_0,U_1$.  Let verifier $V_0$ accept exactly $S,U_0$, and $V_1$ accept exactly $S,U_1$.  Each UNSAT source has a one-symbol certificate under an input-selected verifier, but neither verifier is globally SAT-sound, and enumerating the portfolio labels $S$ UNSAT.  An input-dependent choice that avoids this error already knows semantic information not supplied by a uniform verifier theorem.
\end{counterexample}

These controls separate a genuine all-UNSAT proof system from a per-instance relation, a nonuniform circuit, or free hindsight advice.

\section{Exact visible-prefix coefficient for a sequential proof head}

LSPV-4 UTM-PROOF-REACH-ACTIVITY153 considers proof strings of at most $P$ content bits and a proof head reaching coordinate at most $J$, with a visible endmarker.  The exact number of observational equivalence classes is
\[
 \Gamma_{\rm exact}(P,J)=
 \begin{cases}
   2^{J+2}-1,&J<P,\\
   2^{P+1}-1,&J\ge P.
 \end{cases}                                             \tag{3}
\]
Indeed, when $J<P$, strings ending at positions $0,\ldots,J$ contribute $\sum_{\ell=0}^{J}2^\ell$, while longer strings contribute their $2^{J+1}$ visible prefixes.  When $J\ge P$, every capped string is fully visible and there are $\sum_{\ell=0}^{P}2^\ell$ of them.

The published safe factor uses $A=\min(P+1,J+1)$ and $2^{A+1}-1$.  It equals (3) when reach binds, but overcounts when the physical cap binds:
\[
  2^{P+1}-1 < 2^{P+2}-1.
\]
This is a finite coefficient repair, not a falsification of any published inequality or exponent face.  The splice still requires proof-head coordinate, endmarker semantics, fixed event order, and equality of every reachable proof bit.  Oscillation can make proof moves much larger than proof reach, so activity and reach remain distinct parameters.
