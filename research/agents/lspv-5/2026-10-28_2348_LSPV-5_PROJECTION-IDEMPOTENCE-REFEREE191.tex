\paragraph{Executive status.}
\textbf{PROVED (restricted):} exact componentwise private projection, fixed-boundary idempotence, and an unbounded two-answer fixed-point family.  \textbf{FALSIFIED:} the inference that the same componentwise projection automatically supplies a strictly smaller second child, and separate deletion of a shared variable.  \textbf{COMPUTATIONAL:} 143,026 finite assertions pass.  \textbf{OPEN:} a uniformly discovered moving boundary or joint summary giving one $N^\lambda$ child for arbitrary SAT.  Nothing here proves either $\mathsf P=\mathsf{NP}$ or $\mathsf P\ne\mathsf{NP}$; ARC-EDGE-90 remains open.

\section{PROPOSE: falsifiers fixed before search}
The present missing lemma is not the first small interface.  It is a \emph{repeatable}, answer-preserving, physically shorter successor in a representation closed under the same compiler.  I fixed four falsifiers before inspecting implementations and peer updates:
\begin{enumerate}
\item the exact interface projection may be a closure operator, so the second call is identical;
\item reducing the boundary may silently delete a variable shared by two component languages, destroying compatibility;
\item the first child may be succinct only as a circuit or oracle while its evaluated table, provenance, or next-child encoding is parent-sized;
\item a purported single call may branch into two recursive children or invoke a parent-size solver while selecting the child.
\end{enumerate}

\section{BUILD: corrected theorem and smallest counterexample}
Let $C(X,B)$ be a 2CNF component and $A(Y,B)$ an affine $\mathbb F_2$ component.  Assume $X\cap Y=\varnothing$ and that $B$ contains \emph{every} variable occurring in both syntactic components.

\begin{lemma}[Private quantifiers distribute exactly]
\[
 \exists X\,\exists Y\,[C(X,B)\wedge A(Y,B)]
 \equiv (\exists X\,C(X,B))\wedge(\exists Y\,A(Y,B)).
\]
\end{lemma}
\begin{proof}
The forward implication is immediate.  Conversely, for any fixed assignment $\beta$ to $B$, let $x$ witness the first conjunct and $y$ witness the second.  Disjointness of $X,Y$ makes $x\cup y\cup\beta$ a well-defined joint witness.  No compatibility information was lost because every shared name is fixed in $B$.
\end{proof}

Let $P_B$ compute the two canonical projected components: resolution elimination and duplicate/tautology removal for 2CNF, and reduced row echelon form for the affine system.

\begin{theorem}[Fixed-boundary idempotence]
After $P_B$ has eliminated all variables outside $B$,
\[
   P_B(P_B(C,A))=P_B(C,A).
\]
Thus the same boundary cannot by itself justify a second strict length decrease.
\end{theorem}
\begin{proof}
The second call has no private variable to eliminate.  Canonical clause-set normalization and reduced row-echelon normalization are individually idempotent.  Their ordered pair is therefore idempotent.
\end{proof}

\begin{proposition}[Smallest shared-drop falsifier]
Let the 2CNF component be the unit clause $(z)$ and the affine component be $z=0$.  Their joint existential projection onto the empty boundary is false, while separately projecting each component onto the empty boundary gives $\mathsf{true}\wedge\mathsf{true}$.
\end{proposition}
\begin{proof}
No value of $z$ satisfies both constraints.  Each component separately has a satisfying value, so independent existential forgetting loses their incompatibility.
\end{proof}

\paragraph{Unbounded two-answer fixed point.}
For $b\ge3$, define
\[
 C_b=\bigwedge_{i\in\mathbb Z/b\mathbb Z}(z_i\vee z_{i+1}),
 \qquad A_{b,r}=\bigwedge_{i=0}^{b-1}(z_i=r),\quad r\in\{0,1\}.
\]
The $r=1$ instance is SAT and the $r=0$ instance is UNSAT.  Every $z_i$ is shared.  With boundary $B=\{z_0,\ldots,z_{b-1}\}$, $P_B$ is exactly the identity for both labels.  Adding disjoint private 2CNF and affine copies tied to each $z_i$ creates a larger parent whose first projection is exactly $(C_b,A_{b,r})$; the next call is unchanged.  Hence this is not a favorable-input or free-side-bit artifact: one fixed compiler handles both answer classes and stalls on both.  If instead it independently deletes the shared $z_i$, it returns SAT on the UNSAT member.
