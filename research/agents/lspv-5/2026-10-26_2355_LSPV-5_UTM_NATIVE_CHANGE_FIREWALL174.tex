\section{Simulation noninvariance and formal writes}
\begin{theorem}[Actual-change noninvariance]\label{th:noninv}
There exist a language $L$, a fixed native deterministic machine $M$, and a fixed deterministic interpreter $U$ simulating a fixed code $p_M$, such that on the same binary inputs $x$ of length $n$,
\[
T_M(x)=\Theta(n),\quad D_M(x)=0,
\qquad
T_U(p_M,x)=\Theta(n),\quad D_U(p_M,x)=|x|_1.
\]
Both machines use fixed finite alphabets and a fixed number of tapes and return identical answers.
\end{theorem}
\begin{proof}
Let $L$ be odd parity.  Machine $M$ scans once and retains the parity bit in one of two finite-control states; it never writes a work symbol.  Define a conventional fixed interpreter $U$ whose representation of the simulated control state is a designated binary work cell.  For the fixed parity program, $U$ reads each input bit and rewrites that state cell with the XOR.  A zero input bit causes a formal self-write and a one bit toggles the cell.  Therefore the output agrees with $M$, the interpreter remains linear-time, and the actual-change counts are as displayed.
\end{proof}

The theorem does not say every universal machine behaves this way: a specially optimizing $U$ could recognize this program.  That is exactly the point.  $D$ is a property of a complete implementation, not of the computed language or even of a program's extensional behavior.  Consequently a lower bound on $D_U$ for one pinned $U$ cannot be read as a lower bound on $D_M$ for every native machine.  A transfer needs an explicit simulation theorem in the direction and metric actually used.

\begin{lemma}[Formal writes versus actual changes]\label{lem:writes}
Let $W$ count formal work-tape write commands and $D$ count commands that change the scanned symbol.  In any run $0\le D\le W\le kT$ under the usual at-most-one write per work tape per transition convention.  Neither converse asymptotic bound holds: a machine may issue $T$ self-writes and have $D=0$, or toggle a cell every step and have $D=W=T$.
\end{lemma}
Thus a proof based on actual changes must not charge unchanged writes again, while a hardware/write-traffic theorem must not silently replace $W$ by $D$.  Reads, moves, and writes already included in $T$ are not separate additive time lower bounds.

\section{Common input, program advice, and splicing}\label{sec:common}
For a length cap $b$, the exact number of binary programs is
\[
P_b=\sum_{\ell=0}^b2^\ell=2^{b+1}-1<2^{b+1}.
\]
Fix a program $p$.  The governance proof's accepting-transcript injection is within that one deterministic machine/input-prefix pair: two distinct fooling YES inputs with the same full transcript yield a crossed NO input accepted by the standard deterministic rectangle splice.  Summing the per-$p$ counts over at most $P_b$ programs produces a common YES input outside every fast portfolio member if the displayed capacity is $<2^m$.

Three guards are essential.
\begin{enumerate}
\item \emph{Global soundness:} an accept-all one-bit program covers all YES inputs in constant time but also accepts every NO input.  Excluding it requires correctness on the full declared promise, not success only on the fooling set.
\item \emph{Same program:} crossing records from $p$ and $p'$ do not share the same left program-prefix data.  Equality across different programs does not authorize a hybrid run.  The governance union bound is sound because it does not make that splice.
\item \emph{Charged advice:} any initial program, read-only advice, or nonblank work marker must be counted once in $b$ or in a separate declared parameter.  It cannot be hidden in the universal machine while varying with $N$ or the input.
\end{enumerate}

Accordingly, Theorem A of UTM-CROSS-WRITE1 is independently upheld only as a fixed-$U$ universal-time common-input theorem.  It is not a UWI theorem (eligible programs there may be selected with input hindsight under different requirements), a native-time theorem, or an unrestricted ordinary-SAT lower bound.

\section{Parameter-growth and multihead countercontrols}
Put $h=2S+3$.  With fixed $k$ work tapes, work alphabet size $g$, state count $q$, and $I_0$ initially nonblank visited work cells, a safe generalization of the current-configuration count is
\begin{equation}\label{eq:ai0}
A_{I_0}(S,D)\le 2q h^k
\sum_{j=0}^{\min\{D+I_0,kh\}}{kh\choose j}(g-1)^j.
\end{equation}
For $I_0=0$ this is the governance formula.  Each cell nonblank at the checkpoint is either initially nonblank or acquired its nonblank value through at least one actual change, proving the support bound.  This independently confirms LSPV-2 report 175's marker correction.

\begin{theorem}[Fixed-parameter firewall]\label{th:params}
The simplified exponent faces of UTM-CROSS-WRITE1 require $q,g,k,I_0=O(1)$ and one sequential input head.  If any is silently relaxed, the stated faces need not follow.
\end{theorem}
\begin{proof}
Taking logarithms of~\eqref{eq:ai0} retains explicit terms
\[
\log q+k\log(S+2)+O\!\left((D+I_0+1)
  [\log(k(S+2))+\log(g-1)]\right).
\]
They are constants/polylogarithmic only under the declared bounds.  A nonuniform family with $q_N=2^m$ states can remember an $m$-bit Alice block in finite control with $S=D=0$.  If the physical input alphabet and work alphabet grow to $g_N=2^m$, one packed symbol names an $m$-bit block; that changes the input length and bit-cost model.  With two independently moving read-only input heads, one head can be positioned at Alice's block and one at Bob's block, after which a finite-control machine scans the pairs synchronously and decides separated DISJ with work $S=D=0$.  Each construction lies outside the theorem but falsifies the corresponding silent generalization.
\end{proof}

The blank-work $D=0,S=O(1)$ one-head machine remains a two-way finite automaton and hence cannot decide unbounded separated DISJ.  LSPV-2's one-change marker construction, $D=1$ and $S=\Theta(m)$, is compatible with the theorem and demonstrates why large work-head displacement must remain in the count.

\[

P_1=O\bigl(N+S_k+\log(T_k+2)\bigr)

is an upper construction for simulating one fixed-$k$ machine by one shared writable tape.  It is not a lower bound on $T_k$ or $S_k$, and it gives no control of actual changes in either direction. Conversely, a one-head reversal/crossing lower bound does not transfer to two heads, fixed-$k$ work tapes, RAM, or FLMV indexed access without a charged simulation.
