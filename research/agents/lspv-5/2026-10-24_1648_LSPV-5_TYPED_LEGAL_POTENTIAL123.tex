\section{Accepted correction to BIT-LEDGER-CEILING120}

Fix disjoint coordinate sets for work-memory cells, source/work heads,
addresses and indices, finite control, and all other mutable state.  Let $U$
count charged elementary bit events, including reads, selection and unchanged
writes.  Let $W_{\rm work}$ count one-bit work-memory writes, and let
$\Delta_j$ sum the actual Hamming changes in coordinate type $j$.

\begin{theorem}[typed flip ledger, PROVED/EXACT]
For every execution,
\[
 \Delta_{\rm work}\le W_{\rm work}\le U,
 \qquad
 \Delta_{\rm total}=
 \Delta_{\rm work}+\Delta_{\rm head}+\Delta_{\rm addr}
 +\Delta_{\rm ctrl}+\Delta_{\rm other}.
\]
If each elementary event changes at most one bit of the canonical complete
state, then $\Delta_{\rm total}\le U$.  There is no finite function $g$ such
that $\Delta_{\rm total}\le g(W_{\rm work})$ for all terminating read-only
finite-control scans.
\end{theorem}
\begin{proof}
A work bit changes only on a changed write to that cell, proving the first
inequality.  Hamming distance is additive across the disjoint coordinate
sets.  A scanner can use no work-memory cells while moving its input head
through arbitrarily many positions; its head/control configurations change
while $W_{\rm work}=0$.  Hence no finite $g(0)$ works.
\end{proof}

The displayed inequality $\Delta_{\rm total}\le W_{\rm work}$ in
BIT-LEDGER-CEILING120 is therefore retired.  That report's independent
theorem
\[
 \operatorname{osc}(\Phi)\le LB
\]
for a globally $L$-Hamming-Lipschitz function on $B$ state bits is unchanged.
Append-only provenance is preserved: the historical report is not silently
rewritten; this report and root reconciliation carry the correction.

\section{Exact legal-transition-graph ceiling}

For fixed input $x$ and program $M$, let $G_{M,x}$ be the graph whose vertices
are canonical complete writable configurations and whose undirected edges
join configurations related by one legal primitive transition in either
direction.  Write $d_G$ and $\operatorname{diam}_G$ for graph distance and
component diameter.

\begin{theorem}[legal-edge Lipschitz range, PROVED/EXACT]
If $|\Phi(u)-\Phi(v)|\le L$ on every edge of one connected component of
$G_{M,x}$, then
\[
 |\Phi(u)-\Phi(v)|\le Ld_G(u,v),\qquad
 \operatorname{osc}(\Phi)\le L\operatorname{diam}_G.
\]
For a deterministic halting trajectory
$C_0\to C_1\to\cdots\to C_T$, all $C_i$ are distinct, so if at most $B$
writable bits are live under a fixed canonical encoding,
\[
 T\le 2^B-1.
\]
The path-rank function $\Phi(C_i)=i$ is one-Lipschitz on the trajectory and
has endpoint gap $T$.
\end{theorem}
\begin{proof}
Sum the edge inequalities along a shortest path.  A repeated configuration
in a deterministic run on fixed input repeats the entire future and cannot
later halt, so a halting trajectory is simple.  At most $2^B$ binary states
are available.  The rank statement is immediate on consecutive trajectory
edges.
\end{proof}

This theorem identifies exactly how legal geometry can escape the previous
$LB$ global-Hamming ceiling: graph distance can be exponential in $B$.
However, $\Phi(C_i)=i$ or $T-i$ is defined from the very trajectory length it
is meant to prove.  It is the prohibited ``optimal remaining runtime''
potential in another notation unless an independent structural definition
and lower-bound proof are supplied.  The same issue survives if the
potential is analysis-only and the solver need not compute it: the analyst
must still prove the endpoint gap without assuming the runtime conclusion.

\paragraph{Uniform long-path control.}
Reflected Gray order visits all $2^B$ cube vertices with one state-bit change
per edge.  A uniform generator can traverse it with $O(B)$ additional live
bits and charged arithmetic.  Thus a small program and $O(B)$ state can
produce an exponential legal path.  This is optional counter work, not
unavoidable SAT work: a different exact solver can omit the tour.  Program,
transition selection, arithmetic scratch and representation are never free.

\section{Barrier, wrapper and cross-domain audit}

The typed and graph-distance theorems relativize: an oracle transition can
change the legal graph or answer the root bit, and no line forces an ordinary
trajectory.  Affine/XOR, Horn and SCC controls give cheap direct algorithms,
so syntactic cover size, witness order or child count cannot serve as the
universal invariant.  DEAD/DELAY wrappers can create arbitrarily long legal
paths without changing the SAT decision; RECOMP and virtual-child wrappers
can remove storage/write floors while paying time.  Algebraic access makes
the affine controls easier, not harder.  No constructive large circuit
property is asserted, so Natural Proofs do not provide a positive transfer.

Bennett's reversible-simulation pebbling results are a
\textbf{KNOWN THEOREM} about transforming a specified computation, with
explicit time and space overhead.  They confirm that legal-path history and
recomputation have model-dependent tradeoffs, but they do not force every
SAT decider to realize one prescribed computation DAG.  Accordingly this is
an \textbf{analogy only}, not an ARC theorem transfer.
