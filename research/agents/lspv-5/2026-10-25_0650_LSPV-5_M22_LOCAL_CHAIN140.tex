\section{Imported exact lemmas and compatibility}

Let $\mathcal M_{3,3}^{\rm tag}$ contain valid tagged clausewise-monotone
proper 3-CNFs in which every variable has three occurrences of each sign,
with tags $1,2,3$ once per sign.  Such an instance with $n$ variables has
$2n$ clauses.  The original report bodies prove:
\begin{enumerate}
\item \texttt{TAGGED-DD22STAR-LOCALIZER1}: the corrected odd-positive,
even-negative clone map sends a valid source to $(15n,20n)$ in monotone
star-$(2,2)$, equisatisfiably, with $O(1)$ source-field reads per target bit,
polylogarithmic time, and $O(\log N)$ space.
\item \texttt{FIXED-BLOCK-H22-LOCALIZER1}: D\"ocker's 99-variable,
133-clause enforcer maps $(n_1,m_1)$ to
$(n_1+99m_1,133m_1)$ in proper unique $\mathcal C_{\rm M22}$ with the same
asymptotic access bounds.
\item \texttt{M22-TRANSPARENT-TOTAL-ANCHOR99}: append a fresh satisfiable
six-variable, eight-clause $Y$ with positive supports
$123,145,246,356$ and negative supports $124,136,235,456$.  The result is
valid iff the source is valid, lies in $\mathcal C_\star$ when valid, and
preserves SAT.  The exhaustive fixture has 20 models and witness $111000$.
\end{enumerate}

D\"ocker supplies the enforcer semantics; Darmann--D\"ocker supplies the
equality construction, with its printed occurrence map corrected in
MODELBRIDGE-0013.  These are external syntactic reductions and require no
witness, proof, DNNF, context table, or trace from the target decider.

\section{Composed theorem}

\begin{theorem}[M22-TAGGED-TO-NONPAIRED-LOCAL1]
There is one uniform deterministic valid-promise map
\[
R:\mathcal M_{3,3}^{\rm tag}\longrightarrow\mathcal C_\star
\]
such that for every valid source $F$ with $n$ variables,
\[
F\in\mathsf{SAT}\Longleftrightarrow R(F)\in\mathsf{SAT},\quad
n(R(F))=1995n+6,\quad m(R(F))=2660n+8.
\]
Output length is $N^{1+o(1)}$, and every addressed output bit is computed in
$N^{o(1)}$ time and $N^{o(1)}$ writable/index space in the read-only-input
random-access model.
\end{theorem}

\begin{proof}
The first leg gives $(n_1,m_1)=(15n,20n)$.  The enforcer leg gives
\[
n_2=n_1+99m_1=1995n,\qquad m_2=133m_1=2660n,
\]
and $3m_2=7980n=4n_2$.  The anchor gives
$n_3=1995n+6$, $m_3=2660n+8$, and $3m_3=4n_3$.
Fresh $Y$ has no complementary partner, so the union is not fully paired.
Equisatisfiability composes; conjunction with satisfiable $Y$ preserves the
answer.

For a requested final bit, the anchor decoder emits a fixed $Y$ bit or asks
for a shifted source bit.  The enforcer decoder performs one division by
133 and a constant number of requests to the tagged decoder.  The latter
uses one fixed template and $O(1)$ original fields.  Three fixed layers
preserve polylogarithmic work; $O(\log N)$ address registers are reused depth
first.  No output formula or incidence table is retained.
\end{proof}

\section{Bit-resource ledger and endpoint test}

For each requested output bit the tagged layer charges header/address reads,
source-versus-gadget control, identifier/sign/tag reads, clone arithmetic and
the emitted write.  The enforcer layer charges header/address reads, division
by 133, template selection, one nested request, namespace arithmetic and the
write.  The anchor charges width comparison, old-versus-fixed-record
selection, identifier recoding or fixed-$Y$ selection, and the write.
Unchanged-value writes and all source rereads are charged.  The accessor uses
$O(\log N)$ live registers per fixed layer; target-solver work tapes, caches,
failed strategies and output coexist in the same execution.

Materializing any intermediate also charges every payload/header bit and a
readable $\Theta(N)$-bit buffer, so it is not used.  Complete-state flips,
physical switches, gates, wires and logical bit work remain distinct.
Cumulative bit-time is actual live storage along the actual trace.  There is
no recursive SAT call here; the executable tests two nested access-cost
levels without calling them an ARC contraction.

MB3 sends reduction parameters to
\[
(t,s)\mapsto
\left(\max\{r,\lambda t+\alpha\},
\max\{\beta,\lambda s\}\right).
\]
The three downstream legs have $\lambda=1$ and
$\alpha=\beta=r=0$ at exponent scale.  Raw occurrence rank, however, needs
$\Omega(L)$ field probes in MODELBRIDGE-0013.  With
$N=\Theta(L\log L)$ it has $\alpha=1$, sending boundary time $241/200$ to
$441/200$.  A stored linear index has $r=1$ and retained-space exponent
$\beta=1$, exceeding $11642479/23232400\approx0.50113$.  These are scoped
implementation rejections, not a lower bound on all local Cook reductions.
A native parent-port enumerator could still have zero exponents.
