\section{Exact adaptive-collapse theorem}
Fix actual source boundary names $Y=(y_1,\ldots,y_k)$ and
$B=\{0,1\}^k$.  An ordinary prefix $D(Y,U_D)$ has support
\[
 S_D=\{b\in B:\exists u_D\ D(b,u_D)\}.
\]
A compatible ordinary suffix $Q(Y,V)$, with disjoint private names, has
support $S_Q$, and the exact named join is
$\SAT(D\wedge Q)\iff S_D\cap S_Q\ne\varnothing$.
Role~3 correctly proved that a single fixed quotient $h:B\to H$ reused for
every $D$ in a declared descendant family $\mathcal D$ must refine the
complete membership signature
$(\mathbf1[b\in S_D])_{D\in\mathcal D}$.

\begin{theorem}[Node-dependent semantic collapse and transition firewall]
For every individual prefix $D$, define
\[
 h_D:B\to\{0,1\},\qquad h_D(b)=\mathbf1[b\in S_D].        \tag{1}
\]
Then for every compatible ordinary suffix $Q$,
\[
 h_D(S_D)\cap h_D(S_Q)\ne\varnothing
 \quad\Longleftrightarrow\quad
 S_D\cap S_Q\ne\varnothing.                              \tag{2}
\]
Thus each node separately needs at most two quotient labels, for both SAT
and UNSAT.  If $C$ is a descendant with
$\varnothing\ne S_C\subsetneq S_D$, there is no function
$f:\{0,1\}\to\{0,1\}$ satisfying $h_C=f\circ h_D$ on $S_D$.
Moreover, the useful output test
\[
 1\in h_D(S_Q)                                             \tag{3}
\]
is exactly the predicate $\SAT(D\wedge Q)$.
\end{theorem}
\begin{proof}
If $S_D=\varnothing$, both sides of (2) are false.  Otherwise
$h_D(S_D)=\{1\}$, while $1\in h_D(S_Q)$ exactly when some
$b\in S_Q$ lies in $S_D$.  This proves (2), including both labels.
For the transition claim choose $b\in S_C$ and
$c\in S_D\setminus S_C$.  Then $h_D(b)=h_D(c)=1$, but
$h_C(b)=1\ne0=h_C(c)$, so no label-only $f$ exists.
The last assertion is the same equivalence with $S_Q$ expanded by its
definition.  No runtime assumption is used.
\end{proof}

\begin{corollary}[Quantifier separation on the full pin tree]
Let a full depth-$d$ tree pin $d$ distinct boundary coordinates of a
full-support root.  One fixed quotient valid simultaneously for the whole
tree needs $2^d$ labels, as in ARC-HEREDITARY-KERNEL118.  In contrast, the
family $(h_D)_D$ uses at most two labels at every node.  Nevertheless every
proper parent--child edge loses information needed to translate labels.
Hence the fixed-reusable label count is not a lower bound on an adaptive
normalizer's instantaneous interface width.
\end{corollary}

This does not refute Role~3's theorem: it refutes only the stronger,
quantifier-swapped use of that theorem.  Role~3 fixes one $h$ before
quantifying over all descendants.  An ARC policy may select a new
representation after seeing the current state.  Such selection is allowed,
but its discovery and translation costs are not free.

\section{Ordinary-CNF both-label realization and finite audit}
The deterministic audit realizes the two-level control with proper signed

\[
 \operatorname{PIN}(\ell)=
 \bigwedge_{\epsilon,\zeta\in\{-1,1\}}
 (\ell\vee\epsilon a\vee\zeta b),                         \tag{4}
\]
on fresh distinct private names.  This has existential projection exactly
$\ell$.  The full-support root
$(y_1\vee a\vee b)\wedge(y_2\vee c\vee d)$ is extended first by
$\operatorname{PIN}(\neg y_1)$ and then by
$\operatorname{PIN}(\neg y_2)$.  Its root, child, and grandchild supports
are respectively $\{00,01,10,11\}$, $\{00,01\}$, and $\{00\}$ (under the
displayed coordinate order).  A $00$ suffix gives a true SAT join; a $01$
suffix gives a true UNSAT join.  Formula truth is independently brute-forced
from the proper clause bodies.

For every $1\le d\le10$, the program builds the complete pin tree, verifies

It exhausts every suffix support through $d=3$ (3,964 join checks) and uses a
deterministic empty/full/singleton/parity battery thereafter (81,140 checks).
Total: 97,362 assertions, zero failures.  This is \textbf{COMPUTATIONAL}
finite evidence only; the all-$d$ result is the preceding proof.

\section{Charged ARC interpretation}
Equation (1) is extensional, not a cheap machine state.  On an arbitrary
prefix $D$, evaluating one entry $h_D(b)$ can be implemented by asking
whether $D\wedge\operatorname{PIN}(b)$ is SAT.  If ONE fixed solver $A$
is called $N^{b+o(1)}$ times on queries of length $N^{\rho+o(1)}$, guest
time is
\[
 N^{b+\rho t+o(1)},                                      \tag{5}
\]
plus parser, child generation, source reads, index/control, writes including
unchanged values, failed attempts, cache and ancestor costs.  At original
scale $\rho=1$, this implementation cannot certify exponent contraction.
Most sharply, requesting only the useful label in (3) is already a direct
SAT query for $D\wedge Q$.  Treating it as a free quotient operation is a
decide-first oracle seam.

The transition failure proves only an information statement about this
representation.  A real algorithm may retain original boundary bits, use a
larger table, reread the source, recompute, switch to Horn/SCC/affine or graph
factor algorithms, learn clauses, cache results, or directly decide the
instance.  Each option must be charged by its actual bit work and peak
simultaneously live writable/index state.  No lower bound against all such
choices follows from (1)--(3).

For an already certified executable scoped stream of actual length
$N^{\mu+o(1)}$, producer time $N^{r+o(1)}$, producer state
$N^{\eta+o(1)}$, and touched-live width at most
$\delta\log_2N+O(1)$, direct one-pass frontier DP remains the weakest exact
receiver:
\[
 t_{\rm DP}\le\max\{r,\mu+\delta\},\qquad
 s_{\rm DP}\le\max\{\eta,\delta\}.                       \tag{6}
\]
The phrase \emph{touched-live} incorporates the independently accepted
restricted content of ARC-DEFERRED-OPEN-WIDTH119: on a valid stream, an
unused OPEN can be deferred until first clause use, while CLOSE remains the
original one.  This is not a validator; malformed reopenings and premature
closures require explicit detection.  For $\mu=1$, strict entry still asks
for the simultaneous \OPEN{} conditions
\[
 r<\frac{241}{200},\qquad
 \eta<\frac{11642479}{23232400},\qquad
 \delta<\frac{41}{200}.                                  \tag{7}
\]
Adaptive semantic quotients do not weaken (7) until a charged translator or
direct quotient-DP implementation is supplied.

\section{Barrier-transfer literature preflight and PQ ledger}

semantic quotient that changes with descendants.  FLMV and Williams were

future-context equivalence is not by itself an acquisition algorithm.

The quadratic-form, Schur-square, Hilbert/syzygy, collision-entropy and

support partition, not a linear code or quadratic evaluation map.  No
matched theorem converts those invariants into a charged adaptive SAT
quotient.  Classification: \textbf{FAILED TRANSFER} for this barrier.
Conversely, a hidden algebraic structure may make recognition easier and
must remain an algorithmic control.  Random-oracle, hash and cryptographic
binding assumptions are inadmissible here.
