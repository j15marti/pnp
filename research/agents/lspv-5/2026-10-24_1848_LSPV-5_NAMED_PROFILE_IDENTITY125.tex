\begin{enumerate}
\item Retaining original variable identifiers with every local profile
creates a smaller compatibility problem.  \textbf{FALSIFIED as a semantic

ordered 3CNF.
\item A second complete pin-profile level contributes new information that

\item Discarding identifiers while retaining all local truth tables remains
exact on connected proper formulas.  \textbf{FALSIFIED} by Role~3's

\end{enumerate}
The exact dichotomy is therefore: dropping names loses correctness; keeping
names leaves the original compatibility problem.  This is a representation
firewall, not a deterministic SAT lower bound.

\section{Named profiles and the identity theorem}
Let $F=(C_1,\ldots,C_m)$ be an ordered proper 3CNF over declared variables
$x_1,\ldots,x_n$.  Write
\[
 C_i=(\ell_{i1}\vee\ell_{i2}\vee\ell_{i3}),\qquad
 V_i=(|\ell_{i1}|,|\ell_{i2}|,|\ell_{i3}|),
\]
where the three identifiers in $V_i$ are distinct.  In lexicographic row
order $000,001,\ldots,111$, define
\[
 p_i(b)=C_i(b),\qquad
 \nu(C_i)=(V_i,p_i),\qquad
 \nu(F)=(n,m,\nu(C_1),\ldots,\nu(C_m)).
\tag{1}
\]
This is exactly the named version of the eight-pin answer vector in
PIN-PROFILE-JOIN-FIREWALL89: its one zero is the unique row falsifying the
clause.

\begin{theorem}[Named-profile identity; PROVED/EXACT]
For every ordered proper 3CNF $F$:
\begin{enumerate}
\item $\nu$ is injective and has a uniform linear-record inverse.  If the
unique zero of $p_i$ is $b^*=(b_1^*,b_2^*,b_3^*)$, then
\[
 \ell_{ij}=(-1)^{b_j^*}|\ell_{ij}|.
\tag{2}
\]
\item If $R_i=\{b\in\{0,1\}^3:p_i(b)=1\}$, then
\[
 \SAT(F)=1\quad\Longleftrightarrow\quad
 \exists a\in\{0,1\}^n\ \forall i\quad a|_{V_i}\in R_i.
\tag{3}
\]
Thus named-profile compatibility is literally the original Boolean CSP
join, not the conjunction of independently satisfiable children.
\item In the natural ordered-list encoding, both $F\mapsto\nu(F)$ and
$\nu(F)\mapsto F$ are uniform linear-record transformations.  Consequently
the named-profile consistency language is NP-complete by the exact
many-one equivalence with proper 3SAT.  NP-completeness alone supplies no
time lower bound.
\end{enumerate}
\end{theorem}
\begin{proof}
A proper three-literal disjunction has exactly one falsifying row.  A
positive literal is false at zero and a negative literal is false at one,
which proves (2) and reconstructs every ordered signed clause.  Equation
(3) expands the definition of satisfying all clauses under one shared
assignment.  The transformations scan or emit one constant-arity record
per clause, preserve order and repetitions, and store $(n,m)$, proving the
final statement.  No SAT decision is hidden in either transformation.
\end{proof}

With $q=\lceil\log_2(n+1)\rceil$, a materialized transcript stores
$m(3q+8)$ payload bits plus headers and framing.  For the connected
$(n,m)=(51,36)$ control this is 936 payload bits, versus 288 bits after
anonymizing scopes and 1898 bits in the project's deliberately padded
fixed-width ordinary encoding.  A shorter serialization does not make the
compatibility computation disappear; re-emitting the fixed-width source
also incurs its output cost.  Virtual access can avoid materialization but
must charge every source-ID/profile probe and the join solver's state.

\section{Two-level idempotence and matched-family controls}
For a signed clause $C$ and $b\in\{0,1\}^3$, let $H(C,b)$ be Role~3's
13-clause, nine-variable canonical pin child.  It canonically renames the
three source positions, preserves their signs, and adds three four-clause
proper unit gadgets fixing them to $b$.

\begin{theorem}[Two-level profile idempotence; PROVED/EXACT restricted]
The complete named clause-profile transcript $\nu(H(C,b))$ reconstructs
$H(C,b)$ exactly.  Moreover $H(C,b)$ is already a fixed uniform function
of $(\Prof(C),b)$, and its first clause recovers $\Prof(C)$ while its three
unit-gadget polarities recover $b$.  Hence a complete second local level is
information-equivalent, up to fixed formatting, to the first anonymous
clause profile plus the chosen pin row.  It supplies no original
cross-clause identifier relation and no parent SAT bit.
\end{theorem}
\begin{proof}
Apply Theorem~1 separately to the 13 proper clauses of $H(C,b)$.  Conversely
the displayed construction of $H$ uses only the three source signs and
$b$; its auxiliary names are canonical.  The copied first clause exposes
the signs, and each four-clause block is equivalent to its displayed unit,
which exposes the pin.  These two transformations are syntax-directed and
contain no compatibility test between different source clauses.
\end{proof}

Three hostile pairs locate the exact boundary.
\begin{itemize}
\item \textbf{Connected anonymous collision.}  Role~3's 36-clause pair has
identical ordered anonymous profiles but labels UNSAT/SAT.  Adding scopes
separates the pair and reconstructs both sources, so the remaining join is
the original connected CSP.
\item \textbf{Periodic same-count collision.}  On Role~4's periodic pair,
all isolated length-$K$ child model-counts agree, but the $C_7$ versus
$C_6$ named profile differs at its source position.  Names/profiles recover
the opposite-label parents; they do not give a cheaper general join.
\item \textbf{Minimal-UNSAT pair.}  The two 16-clause sources differ at
named-profile index 12.  The three pins $x_m=1,a_m=b_m=0$ still yield
UNSAT/SAT, independently confirming PINNED-CHILD-SEPARATOR124.  Directly
reading the changed source field is cheaper under the promise.
\end{itemize}

The database/CSP correspondence is exact: (3) is a natural join of named
relations.  Yannakakis's efficient algorithms apply when the relation
hypergraph is acyclic.  That is a \textbf{THEOREM TRANSFER only for the
acyclic restricted class}; arbitrary 3CNF incidence hypergraphs need not be
acyclic.  Treating ``join'' as automatically cheap on general instances is
a \textbf{FAILED TRANSFER}.  This agrees with SCC, Horn, affine and bounded-
width controls: recognizable structure can improve an algorithm, but does
not establish an all-input ARC edge.

The tested policy receives only the read-only ordinary source and charged

For the discriminating test it selects profile extraction.  State $S_0$

The resource vector is
\[
(U,R_s,R_w,W_w,\Delta_{\rm work},\Delta_{\rm head},
\Delta_{\rm addr},\Delta_{\rm control},S_{\rm peak},BT,|P|).
\tag{4}
\]
$U$ charges primitive bit work, unchanged writes, parsing, addressing,
profile rows, policy selection, switching, failed recognizers, compatibility
tests, child headers, regeneration and fallback.  Actual complete-state
flips are separate from writes.  Peak live bits include source indices,
buffers, join/DPLL state, caches and live ancestors; $BT$ sums actual live
writable bits at actual steps.  Materializing (1) uses the transcript size
above; streaming can use $O(\log N)$ controller bits plus the selected
solver, but does not improve that solver by definition.  The finite policy
menu is a tested control, never all-decider coverage.
