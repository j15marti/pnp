\section{Exact recovered-code theorem}
The pinned checker is \path{experiments/arc/lspv2_341_independent_verify.js}, Git blob
\texttt{fcb7d4ced8f922de14c0bda16263a8cc7853e8e0}, SHA-256
\texttt{0a8167fc65f324860f60abd2a0e0176d0def968cb6ee7055b6aa1bfd43c255ae}.
It parses a packet by ordinary \texttt{JSON.parse}.  At an AND3 step it forms the numeric union $S$ of the two parent supports and requires
\[
 |s|=|S|,\qquad |\mathrm{Set}(s)|=|S|,\qquad (\forall e\in S)\;s.\mathrm{includes}(e).
\]
For an Array, equality in the last display is numeric membership and the gate makes $s$ a permutation of $S$.  For a String, \texttt{includes} converts $e$ to its decimal String, while \texttt{Set} iterates Unicode code points and \texttt{length} counts UTF-16 code units.  The checker's assignment loop nevertheless executes \texttt{bits[s[j]]=...}.  A one-code-unit ASCII digit \texttt{'0'} through \texttt{'9'} therefore writes numeric array slots $0$ through $9$; every other single code unit writes a named object property and a multi-digit decimal coordinate is never a single loop index.  Hence for String support $s$ and local mask $m$,
\[
 \beta_s(e,m)=
 \begin{cases}
 (m\mathbin{\gg}j)\mathbin{\&}1,&0\le e\le 9\text{ and }s_j=\texttt{String}(e),\\
 0,&\text{otherwise}.
 \end{cases}
\]
Parent tables, the derived AND table, and the optional affine-row parity all read this same $\beta_s$.  Row-mask \emph{eligibility}, however, uses decimal-substring membership.  In particular coordinate 10 can be admitted to the row scope yet is identically zero in the evaluated assignment.  JSON values other than Array and String cannot supply the required pristine iterable/method combination: objects have no JSON-constructible symbol iterator, while primitives fail a required length, Set, or \texttt{includes} operation.  This proof is source-level and restricted to the recovered /341 block.
