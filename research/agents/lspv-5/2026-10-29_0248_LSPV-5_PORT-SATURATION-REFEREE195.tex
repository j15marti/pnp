\section{Claim card and PROPOSE}
The target is the missing physical re-entry arrow between complete two-port
relation algebra and a recursively closed strict signed exact-$(2,2)$ ordinary
3CNF child. The exact question is whether one fixed deterministic polynomial
program can compose every pair of disjoint strict modules, preserve the SAT
answer on both answer classes, and remain in the class without first computing
SAT-hard interface data. Signed counts, semantics, time, output and recursion
must refer to the same physical realization.

Four mechanisms were proposed before search:
(1) identify ports; (2) repair degree by same-sign occurrence permutation;
(3) justify the repair by gauge symmetry; (4) compute full puncture relations.
The first three are falsified as general syntax-only rules below. The fourth is
an exact restricted rule whose acquisition and physical re-entry remain open.

\section{BUILD I: port saturation}
\begin{theorem}[Identification overflow]\label{t:saturation}
Let $F_1,F_2$ be disjoint strict signed exact-$(2,2)$ formulas with ports
$p_1,p_2$. Rename both ports to $p$ while retaining every clause. Then $p$
occurs four times positively and four times negatively. Identification
followed only by clause addition or sign complementation cannot restore
strict exact-$(2,2)$.
\end{theorem}
\begin{proof}
Each port contributes two occurrences of each sign, so identification adds to
four and four. Clause addition cannot decrease counts, and complementation
only exchanges them. Some original occurrence must be deleted, replaced or
re-routed.
\end{proof}

The exact equality module
\[
E(a,b,u)=(\neg a\vee b\vee u)(\neg a\vee b\vee\neg u)
(a\vee\neg b\vee u)(a\vee\neg b\vee\neg u)
\]
is strict exact-$(2,2)$. Conjoining $E(a,b,u)$ and $E(b,c,v)$ identifies $b$
and gives it four occurrences of each sign. The equality chain is easy, but it
has already left the class.

\section{BUILD II: one balance-preserving rewire flips SAT}
Take the connected 15-variable strict exact-$(2,2)$ source $U$ used in
D\"ocker's $W_1$ control and LSPV-3:
\begin{align*}
&(-1,3,-14),(2,-8,9),(10,-13,14),(3,7,-13),(-4,-9,-11),\\
&(5,8,-14),(4,-8,-11),(1,7,13),(1,-7,10),(-5,-6,-15),\\
&(-2,-6,12),(-4,9,-10),(-2,5,-12),(-3,6,-15),(6,-7,11),\\
&(2,-9,11),(4,8,-10),(-3,12,15),(-5,-12,15),(-1,13,14).
\end{align*}
Its source-ID Resolution refutations for the two values of $x_{13}$ replayed
successfully; all $2^{15}$ assignments were also checked and none satisfies it.

Swap the same-sign occurrences $-x_1$ in the first clause and $-x_8$ in the
second. Only those clauses become
\[
(-8,3,-14),\qquad(2,-1,9).
\]
Every variable still has two occurrences of each sign, clauses remain proper
and distinct, and the incidence graph remains connected. Yet
\[
x_6=x_7=x_8=x_{10}=1,\qquad x_i=0\text{ otherwise}
\]
satisfies all clauses. Thus this occurrence-preserving rewire changes UNSAT to
SAT.

The reproducer tried all 840 same-sign source-slot pairs on different
variables. Of these, 669 swaps retained strict exact-$(2,2)$ properness; all
669 remained connected and 643 were SAT. Fifteen variable-wide gauge flips
retained UNSAT, separating the valid gauge theorem from the invalid rewire
inference. These finite counts are \COMP.

\section{BUILD III: corrected semantic splice theorem}
Let disjoint modules be
\[
M_i=A_i\wedge(\ell_i\vee D_i),
\]
with selected literals $\ell_i$ of one sign, and define
\[
P_i=\{(a,d):\exists\text{ private assignment satisfying }A_i,\
\ell_i=a,\ D_i=d\}.
\]
Replace the selected occurrence of $\ell_i$ by predecessor $\ell_{i-1}$
cyclically.

\begin{theorem}[Exact cyclic puncture criterion]\label{t:puncture}
The rewired conjunction is satisfiable exactly when bits $a_i,d_i$ exist with
\[
(a_i,d_i)\in P_i,\qquad a_{i-1}\vee d_i=1
\]
for every $i$. Equivalently, with Boolean matrices
\[
T_i(u,v)=\bigvee_{d:(v,d)\in P_i}(u\vee d),
\]
the Boolean product $T_1\cdots T_k$ has a true diagonal entry. Same-sign
rewiring preserves signed occurrence counts but preserves SAT only when this
criterion says so.
\end{theorem}
\begin{proof}
A satisfying assignment induces local values $(a_i,d_i)\in P_i$ and the
rewired selected clause is exactly $a_{i-1}\vee d_i$. Conversely, witnesses
for disjoint private modules combine whenever these clause conditions hold.
Boolean matrix multiplication existentially sums intermediate $a_i$ values;
closing the cycle requires equal initial and final values, hence a diagonal.
\end{proof}

This theorem is constructive once every complete $P_i$ is supplied. It does
not produce them. Guard220 shows that even a four-bit profile can encode an
arbitrary source's SAT label. The repaired architecture has three arrows:
\[
\boxed{\text{acquire authenticated }P_i}\longrightarrow
\boxed{\text{compose complete relations}}\longrightarrow
\boxed{\text{compile a balanced physical child}}.
\]
Only the middle arrow is currently cheap in general.

\section{Constructive and separation consequences}
On the constructive side, a promised grammar with polynomially discoverable
puncture relations and a certified balanced splice supports exact path/cycle
composition and grouping. An all-SAT theorem still needs one physical
ordinary-3CNF child of length $N^\lambda$, closure and a second genuine level.

On the separation side, these falsifiers do not force an arbitrary SAT
algorithm to use ports, puncture relations or a particular compiler. They give
no RAM or Turing-machine lower bound. NP-hard profile acquisition is a
conditional barrier: a polynomial general extractor would imply $P=NP$, but
failure to exhibit one is not evidence for $P\ne NP$.

\section{Native resource ledgers}
On an indexed RAM, parsing, signed-count validation, connectivity and a
specified swap take $O(N\operatorname{polylog}N)$ bit work; exhaustive
checking costs $O(2^n m\operatorname{polylog}N)$. A fixed-$k$
read-only-input multitape implementation can validate and emit the rewire in
polynomial transitions and $O(N)$ work cells; exhaustive truth checking
remains exponential. On one shared read/write tape, input cells count in the
footprint. The conservative
\[
T_1=O(T_k(N+S_k+\log(T_k+2))),\qquad
P_1=O(N+S_k+\log(T_k+2))
\]
is an upper simulation only. A fixed universal machine incurs polynomial
interpreter overhead with a fixed program prefix. No one-tape crossing lower
bound is transferred to fixed-$k$ tapes or RAM, and Python loops are not native
machine exponents.
