\section{The output-use trilemma}
Let $C$ be a fixed uniform transducer that maps an $N$-bit source $F$ to an
$L$-bit ordinary child $G=C(F)$.  Let $A$ be a fixed deterministic total
algorithm whose declared input interface permits reads of arbitrary child
positions, including adaptive repeats.  Parsing, addresses, source reads,
writes, movement, failed probes, caches, and replay are charged.

\begin{theorem}[Materialize--virtualize--stream trilemma]\label{th:tri}
Every faithful composition of $C$ with $A$ in an ordinary finite-alphabet TM
model falls into at least one of the following charged cases.
\begin{enumerate}
\item \emph{Materialize.}  Store the $L$ child bits as a readable input/work
representation.  Literal materialization uses $\Omega(L)$ simultaneously
readable cells and at least $L$ write transitions.
\item \emph{Virtualize.}  Answer each requested child position $j$ from
$(F,j)$ without storing all of $G$.  Every address construction, source
probe, arithmetic step, cache operation, and recomputation is part of the
same machine's time and peak workspace.  A bound for $C$'s sequential output
does not by itself bound this random-position accessor.
\item \emph{Stream.}  Fuse $C$ with a separately proved consumer whose query
order is compatible with the stream and whose retained state is charged.
This does not simulate an arbitrary random-access $A$.
\end{enumerate}
A never-reread write-only port is therefore not a fourth case that can later
serve as $A$'s read-only random-access input.
\end{theorem}
\begin{proof}
At each child read by $A$, the requested bit must come either from a retained
readable representation, from a computation using the source and current
query, or from the current stream position/state.  These are the three cases.
If none applies, the composed transition has no information from which to
determine that bit.  Output-only cells that the model forbids reading cannot
be cited as a fourth source of information.  The resource statements are
then definitions of the charged interfaces: writing $L$ literal cells costs
$L$ transitions and cells; virtual computation charges its real trace; a
stream consumer is valid only for its proved access discipline.
\end{proof}

\begin{lemma}[Reverse-query hostile control]\label{lem:reverse}
Consider the identity stream $C(x)=x\in\{0,1\}^L$.  After the stream has
ended and the source is unavailable, a consumer required to answer the
positions $L,L-1,\ldots,1$ exactly must retain at least $L$ bits of state.
If it retains less, it must instead reread or recompute, moving to the
virtualized case.
\end{lemma}
\begin{proof}
The complete reverse answer transcript is the injective map $x\mapsto
x^{\mathrm{rev}}$, so it has $2^L$ possibilities.  Fewer than $L$ state bits
give fewer than $2^L$ post-stream states, forcing two sources to share a state
and hence the same answers, a contradiction.  This is an interface control,
not a SAT lower bound.
\end{proof}

\paragraph{Two levels.}
For $G_1=C_1(F)$ and $G_2=C_2(G_1)$, materialization costs readable space for
the live level(s); a nested virtual accessor charges the full $G_2$-to-$G_1$
and $G_1$-to-$F$ computation per actual query, including caches; and streaming
composition is legal only when both $C_2$ and the final consumer accept the
provided order.  A write-only $G_1$ cannot later be reread by $C_2$.

\section{Independent audit of ARC-OUTPUT-LEDGER190}
Let $Q=\Theta(N+S_k+\log(T_k+N+2))$.  ARC190's materializing one-tape
simulator keeps the simulated active region at length $Q$ and a chronological
output prefix of length $L$.  Each emitted bit shifts the active region by
$O(Q)$ cells.  Because every emission is already a source transition,
$T_k\ge L$, hence
\[
 T_1=O(T_kQ),\qquad P_1=O(Q+L)
\]
is sound in the declared physical-output convention.  For Boolean decision
output $L=O(1)$ this reduces to the governance bound
\[
T_1=O(T_k(N+S_k+\log(T_k+2))),\qquad
P_1=O(N+S_k+\log(T_k+2)).
\]
These remain construction upper bounds, not machine lower bounds.

For ARC190's copy compiler
\[
\Phi_r(F)=\bigwedge_{j<r}F(x_{jn+1},\ldots,x_{jn+n}),
\qquad \SAT(\Phi_r(F))\iff\SAT(F),
\]
the dense child length is $L\ge N$ for every $r\ge1$ (up to the declared
header normalization).  If $L=N^{\ell+o(1)}$ with $\ell\ge1$ and only the
all-input ceiling $T_A(M)=M^{t+o(1)}$ is known, calling $A$ on the child gives
$N^{\ell t+o(1)}$, never a smaller exponent than $t$.  A virtual copy
accessor can avoid $L$ storage but does not shrink the input scale.  Two
levels satisfy $\Phi_{r_2}(\Phi_{r_1}(F))\cong\Phi_{r_1r_2}(F)$ and remain
expansions.  Thus the compiler is a useful output-accounting control but not
an ARC successor.
