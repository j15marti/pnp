\section{Canonical model}
The target $\CS$ consists of duplicate-free proper three-distinct-variable
clauses, each all positive or all negative, every active variable occurring
twice positively and twice negatively, excluding only fully
complementary-paired formulas.  Partial pairs, disconnected formulas and easy
instances remain allowed.  Invalid strings are rejected.

Fix one source variable split into $r$ named ports
$z_1,\ldots,z_r$, each already used once in a source clause.  Let exactly $p$
of those source occurrences be positive.  A \emph{standalone pure-sign
completion block} introduces $a$ fresh auxiliary names and uses only unique,
proper, all-positive or all-negative ternary clauses.  No auxiliary occurs
outside the block.  After adding the block, every port and every auxiliary is
required to have signed degree $(2,2)$.  For semantic equality, existential
projection over the auxiliaries must satisfy
\[
 \{z:\exists y\,G(z,y)\}=\{0^r,1^r\}.
 \tag{1}
\]
The theorem below uses only syntax and therefore applies before (1) is tested.

\section{Exact signed-quota congruence}
\begin{theorem}[Standalone auxiliary port congruence]
If a standalone pure-sign completion block as above exists, then
\[
                 a\equiv0\pmod3,
        \qquad   p\equiv2r\pmod3.                 \tag{2}
\]
These conditions are necessary regardless of the block's semantics.
\end{theorem}
\begin{proof}
Each port has three unused literal slots after its one source occurrence,
while each auxiliary has four.  Hence the block contains exactly
$3r+4a$ literal occurrences.  Proper ternary clauses partition these slots
into triples, so $3\mid(3r+4a)$, which gives $a\equiv0\pmod3$.

There are $2(r+a)$ positive quota slots in the final formula.  The source has
already consumed $p$ of them, so all-positive block clauses must contain
$2(r+a)-p$ positive occurrences.  This is three times their number, hence
$3\mid 2(r+a)-p$.  Substituting $a\equiv0\pmod3$ gives
$p\equiv2r\pmod3$.  The negative count gives the same condition.
\end{proof}

\begin{corollary}[Mixed three-port firewall]
For $r=3$, a standalone exact-quota block is syntactically possible only when
$p=0$ or $p=3$.  Thus no number of fresh internal auxiliaries repairs an
independent three-clone group having a mixed source-sign pattern.
\end{corollary}
This is a stronger scope statement than the earlier clone-only floor, but it
does not exclude a compiler that first controls sign patterns, shares clauses
or auxiliaries across source variables, adds contextual ports, or uses a
different exact reduction.

\section{Contraction and bit-resource ledger}

records and charges parsing, source-bit reads, address arithmetic, sign
counting and validation.  A streaming congruence check uses
$O(r\log(r+2))$ elementary bit work and $O(\log(r+2))$ live counter/address
bits.  The output itself, if it existed, would have
$(3r+4a)/3$ ordinary clauses and costs
$\Theta((r+a)\log(r+a+2))$ bits to serialize, including headers and variable
IDs.  An eager representation pays every write, including unchanged values,
and keeps the payload live; lazy access must pay rule selection and every
source reread.  Control, failed sign-pattern trials, caches, ancestor buffers,
full-state flips, cumulative bit-time, program size and physical

The exhaustive enumerator is a discovery experiment, not a claimed SAT
algorithm or FLMV instruction simulation.  No legitimate first-level equality
