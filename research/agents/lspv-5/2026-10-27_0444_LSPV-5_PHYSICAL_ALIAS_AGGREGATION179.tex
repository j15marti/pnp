\section{Physical proof cells and the exact quotient}
Let $\Omega_N$ be the public finite set of physical binary proof cells.
A cell key contains both physical store identity and physical bit address.
During a run the verifier emits logical events $e_1,\ldots,e_m$. A uniform
charged layout function
\[
 \kappa_F(e_j,\text{current state})\in\Omega_N
\]
returns the cell actually read. Computing a child base offset, parsing a
header or decoding a virtual address remains charged. Define $e_i\sim e_j$
exactly when their physical keys are equal.

\begin{theorem}[Physical-alias enumeration]
\label{th:alias}
Fix one total deterministic verifier whose proof reads are stable one-bit
reads. Suppose each accepting execution used for \UNSAT completeness
observes at most $q(N)$ distinct physical keys, and malformed or over-cap
executions reject. A deterministic simulator enumerates all consistent
accepting transcripts with exactly $2^{q(N)}$ binary answer maps. Its
dictionary key must be $\kappa$, or a canonical key with exactly the same
equality relation.
\end{theorem}
\begin{proof}
For each $z\in\{0,1\}^{q(N)}$, freshly restart $V$. Maintain a map $M$ from
physical keys to bits. On the first query of $u$, assign the next bit of $z$
to $M[u]$; on every repeat return $M[u]$. Abort at the $(q+1)$st distinct
key. Every accepted simulation is a partial function on $\Omega_N$ and
extends to a genuine fixed proof. Conversely, the first-read answers of
every genuine accepted proof occur among the enumerated words. Global
soundness and completeness therefore transfer exactly. Addresses,
dictionary operations, verifier work, source reads, failed candidates and
reset remain charged.
\end{proof}

\begin{counterexample}[Too fine: invented acceptance]
One physical bit $p$ is queried under child labels zero and one. Accept iff
the answers differ. No fixed proof accepts because both reads of $p$ agree.
A simulator keyed by child ID and local position enumerates $01$ and $10$
and falsely accepts. Child names are sound keys only for genuinely separate
stores or an injective charged map to disjoint global offsets.
\end{counterexample}

\begin{counterexample}[Too coarse: lost completeness]
Two independent stores $P_0,P_1$ are each queried at local position zero;
accept iff the answers are $0,1$. This is a genuine proof. Keying only by
local position forces equality and misses it. Store identity is part of the
physical key.
\end{counterexample}

\section{Hereditary aggregation: unions, not maxima}
Let an accepted execution visit local components $\mathcal L$, with component
$\ell$ observing physical keys $Q_\ell$. The exact global count is
\[
 q_{\rm total}=\left|\bigcup_{\ell\in\mathcal L}Q_\ell\right|,
\qquad
\max_\ell |Q_\ell|\le q_{\rm total}\le\sum_\ell |Q_\ell|. \tag{1}
\]
Both extremes occur. Sharing reduces the count only when physical equality
is real and verifier soundness survives that sharing.

\begin{theorem}[Two-level aggregation firewall]
If level one visits $B_1$ components and each visits $B_2$ level-two
components, each reading at most $a\log_2N+O(1)$ cells, the unconditional
bound is
\[
q_{\rm total}\le B_1B_2(a\log_2N+O(1)),
\]
not $a\log_2N+O(1)$. Disjoint ranges attain equality up to the additive
term. Polynomial deterministic enumeration from Role 1's frontier therefore
requires a separate proof that the \emph{complete accepted run} satisfies
$q_{\rm total}=O(\log N)$.
\end{theorem}
\begin{proof}
Equation (1) gives the upper bound. Allocate disjoint ranges to every leaf.
A complete binary tree of height $h$ with one distinct proof bit per leaf has
local cap one, $B=2^h$, global count $2^h$, and $2^{2^h}$ realizable
transcripts. A globally sound control rejects every proof on SAT sources and
accepts the declared UNSAT source iff all leaf bits are one. Thus the error
is cap composition, not soundness. Shared-by-parent ranges instead give
$q=B_1$; one fully shared cell gives $q=1$.
\end{proof}

For $B=N^{\beta+o(1)}$ disjoint leaves, a constant local cap gives
$q=N^{\beta+o(1)}$ and enumeration
$2^{N^{\beta+o(1)}}$, not a polynomial. A claimed shared layout must survive
both alias counterexamples and all source-authentication checks.

\section{Model and hostile-control firewalls}
The theorem is about information consistency, not tape crossings. On one
read/write tape the initial source contributes $N$ cells to footprint and
proof/output placement costs movement and space. On fixed-$k$ tapes with
one sequential read-only input head, source travel, proof-head motion and
visited work cells are native. On indexed RAT, address construction is paid
but physical distance is not. The conservative construction
\[
T_1=O(T_k(N+S_k+\log(T_k+2))),\qquad
P_1=O(N+S_k+\log(T_k+2))
\]
is an upper simulation, never a reverse lower bound. Hennie--Stearns is not
used as a one-tape transfer.

Horn, 2SAT, affine/Tseitin, bounded width, products, caches, source rereads
and direct recognition remain legal. A cheap source-specific decider can
bypass proof enumeration. The theorem only compiles away a proof oracle
after the complete all-input verifier and cap are proved.
