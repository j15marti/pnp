\section{Audited claim and disposition}
This report independently audits LSPV-3's
\texttt{EXACTONE-JOIN-CYCLE95}.  The load-bearing restricted result is
accepted: positive exact-one SAT admits a linear source-named compilation
into modules having exactly three explicitly enumerable local signatures,
affine-hull dimension two, and equality-only cross-module links, while the
global compatibility problem remains NP-complete.  A same-support SAT/UNSAT
pair survives complete binary arc consistency without deleting one local
signature.

Three falsifiable readings were separated.
\begin{enumerate}
\item Constant local support and affine rank might make the global join easy.
\textbf{FALSIFIED as an unconditional algorithmic inference}: the compiled
class is NP-complete by a linear reduction from positive 1-in-3-SAT.
\item Full pairwise arc consistency might decide the compiled class.
\textbf{FALSIFIED}: a matched four-module pair has opposite labels and the
same no-pruning fixed point.
\item This NP-complete join might furnish an ARC/FLMV transition or an
unconditional decision-time lower bound.  \textbf{FALSIFIED/RETIRED}: no
power-short ordinary-child service or improved all-input machine is
constructed, and the matched pair itself has a cheap source recognizer.
\end{enumerate}

\section{Exact local relation and source-named compilation}
For Boolean literal values $\ell_1,\ell_2,\ell_3$, let $E$ require exactly
one true value.  Exhaustive truth-table calculation gives
\[
 E(\ell_1,\ell_2,\ell_3)equiv
 (\ell_1\oplus\ell_2\oplus\ell_3=1)
 \land(\neg\ell_1\vee\neg\ell_2).                                  \tag{1}
\]
Its three feasible signatures have affine-hull dimension two; the odd-parity
affine hull also contains $111$, which the final binary clause removes.

Given a positive exact-one instance with $m$ triples and $n_+$ occurring
source variables, make one private occurrence copy for each of its $3m$
positions.  Consecutive copies of each source name are linked by equality,
so the number of equality links is
\[
 L=\sum_x(\deg(x)-1)=3m-n_+.                                       \tag{2}
\]

\begin{theorem}[Three-state equality join; PROVED/EXACT restricted]
The resulting compatibility instance has $m$ pairwise-disjoint local
three-state domains and only source-name equality links.  It is satisfiable
exactly when the original positive 1-in-3-SAT instance is satisfiable.
Consequently this restricted compatibility language is NP-complete.
\end{theorem}
\begin{proof}
A source witness copies its value to every named occurrence and selects the
corresponding local exact-one signature.  Conversely, equality chains make
all occurrence copies of each source name identical; a globally compatible
signature choice therefore induces a source assignment satisfying every
exact-one triple.  The construction is linear in occurrence and equality
records.  Schaefer's positive 1-in-3-SAT theorem supplies NP-hardness and a
selected signature per module is a polynomial witness.
\end{proof}

For ordinary proper 3CNF, encode the parity equation with its four
falsifying-assignment ternaries, properize the one binary NAND clause with
one fresh variable and two ternaries, and encode each equality with two
padded implications.  The exact counts are
\[
 n'=4m+2L,qquad m'=6m+4L.                                          \tag{3}
\]
Every emitted clause has three distinct variable identifiers.  Source reads,
occurrence grouping, name comparison, fresh identifiers and all output bits
remain charged; (3) is a linear-size compiler, not an improved SAT decider.

\section{Matched pair and independent arc-consistency proof}
Use modules on unsigned triples
\[
 (abc),\quad(abd),\quad(acd),\quad(bcd).
\]
The UNSAT source applies positive $E$ to all four.  The SAT source changes
only the fourth module to $E(\neg b,c,d)$.

\begin{theorem}[Arc-consistent opposite labels; PROVED/EXACT restricted]
Both sources compile to connected proper-3CNFs with
\[
 m=4,quad L=8,quad n'=32,quad m'=56,quad
 w=13,quad N'=(4m'+2)w=2938.                                      \tag{4}
\]
They have identical unsigned clause supports and the same module-interaction
edges $(12),(13),(23),(24),(34)$.  Complete binary arc consistency leaves all
three signatures in every module for both labels, yet the positive member is
UNSAT and the signed member is SAT.
\end{theorem}
\begin{proof}
In the positive member, adding the four integer exact-one equations yields
$3(a+b+c+d)=4$, impossible over Boolean values.  In the signed member,
$(a,b,c,d)=(1,0,0,0)$ is a witness.

Equality chains create two-coordinate interfaces on edges $(12),(23),(34)$;
both endpoints project to $\{00,01,10\}$.  The one-coordinate interfaces on
$(13),(24)$ project to $\{0,1\}$.  Hence every local signature has a support
at each neighboring module and no arc revision prunes a value.  Exact
enumeration of the two halves $(1,2)\mid(3,4)$ gives relations of size three;
their intersection has size zero for UNSAT and one for SAT.  Thus named
global gluing, not independent local feasibility, recovers the label.
Equation (3) yields (4).
\end{proof}

The choice is deliberately adversarial rather than generic.  Exhausting all
eight signings of the fourth triple produced three SAT and five UNSAT
instances.  Arc consistency reduced some variants to a singleton witness and
some to empty domains.  Only the positive all-UNSAT member and the selected
$E(\neg b,c,d)$ SAT member retained the full $(3,3,3,3)$ domain vector.  This
refinement prevents overclaiming that arc consistency always fails on the
family.

\section{Parameterized consequence and surviving bypasses}
The theorem rules out a scalar analysis based only on maximum local support
$r_i=3$, local affine-hull dimension two, local feasibility, or arc
consistency.  A polynomial-time algorithm whose only exponential factor were
a function of these constants would solve the entire compiled NP-complete
class in polynomial time; this is a \emph{conditional implication}, not an
unconditional lower bound.

A valid parameter vector must retain global interaction information such as
named interfaces, decomposition width, feedback sets and the changing
relation state.  With a supplied tree decomposition of width $w_G$, standard
finite-domain dynamic programming gives $3^{w_G+1}\operatorname{poly}(N)$
time.  This is an upper bound.  Raw cycle rank or width is not a universal
lower bound: the concurrent NONAFFINE-WINDOW131 and CYCLE-AFFINE-SWITCH123
families have growing cycles but source-aware polynomial algorithms.

The four-module control itself is recognizable in source-linear work; reading
the fourth sign distinguishes the matched templates.  A general solver may
also change representations, learn clauses, branch, run affine/Horn/SCC
tests, cache, reread the source or decide directly.  It need not enumerate all
local signatures, emit a DNNF, reconstruct every witness, or run arc
consistency.  Constant-false representations of recognized UNSAT members and
decide-first compression remain legitimate when their discovery cost is paid.
