\section{BUILD I: the classical oracle-compiler firewall}
\begin{theorem}[Target-dependent oracle quantifiers are vacuous for decision]
Let $L\subseteq\{0,1\}^*$ be any language.  There is a fixed deterministic
one-query skeleton $S$ such that
\[
 \forall x\ \exists f_x:\{0\}\to\{0,1\},\qquad S^{f_x}(x)=L(x).
\]
Consequently this quantifier pattern, without an effective restriction on
$f_x$, implies no upper bound on $L$.
\end{theorem}
\begin{proof}
The skeleton ignores $x$, queries address $0$, and returns the reply.  For a
given $x$, choose the constant oracle $f_x(0)=1$ exactly when $x\in L$.
This construction works for every language, including undecidable languages.
\end{proof}

The stronger pattern $\exists f_L\ \forall x\ S^{f_L}(x)=L(x)$ also gives only
an oracle algorithm: choose $f_L(x)=L(x)$.  It establishes $L\in P^{f_L}$,
not $L\in P$.

\begin{theorem}[Effective-oracle composition]
Let a deterministic classical skeleton $S$ run in time $p(|x|)$ and make at
most $p(|x|)$ adaptive queries of length at most $p(|x|)$.  If one fixed
deterministic algorithm $E$ computes every required bit
\[
 f_x(q)=E(x,q)
\]
in time polynomial in $|x|+|q|$, then the oracle can be inlined and the
language decided in deterministic polynomial time.  The same holds when a
uniform polynomial-time compiler physically produces a polynomial-size oracle
circuit and its evaluation and storage are charged.
\end{theorem}
\begin{proof}
Simulate $S$ and replace each oracle transition by a call to $E$.  The product
of the polynomial query count and polynomial evaluation cost is polynomial;
adaptivity does not change this bound.  Physical circuit generation and each
evaluation are included in the same execution ledger.
\end{proof}

This theorem is classical.  Inlining a classically evaluable oracle into the
OpenAI quantum skeleton would still produce a quantum computation, not an
efficient classical simulation.  The missing SAT bridge is therefore stronger:
one needs a deterministic classical, answer-preserving, recursively closed
constructor, not merely existential oracle contents.

\section{BUILD II: representation-closure trichotomy}
For pairwise disjoint variables define
\[
 A_i=a_i\vee b_i,\qquad B_j=c_j\vee d_j,
\]
and
\[
 S_t(z)=\bigwedge_{i=1}^t(z\vee A_i)\wedge
        \bigwedge_{j=1}^t(\neg z\vee B_j).
\]
Then
\begin{equation}\label{eq:projection}
 \exists z\,S_t(z)
 =\left(\bigwedge_i A_i\right)\vee\left(\bigwedge_j B_j\right)
 =\bigwedge_{i,j}(A_i\vee B_j).
\end{equation}
The first equality follows by evaluating $z=0$ and $z=1$; the second is
distributivity.

\begin{proposition}[Three honest re-entry choices]
For the family in \eqref{eq:projection}:
\begin{enumerate}
\item an auxiliary-free CNF over the original variables needs $t^2$ clauses;
\item a fan-in-two circuit has exactly $4t-1$ gates; its full Tseitin
      equivalence encoding with a pinned root has $12t-2$ clauses,
      $28t-6$ literal occurrences, and $4t-1$ fresh variables;
\item retaining the circuit changes the recursive language to Circuit-SAT and
      still has indexed physical length $\Theta(t\log t)$, the same exponent as
      the $2t$-clause selector $S_t$.
\end{enumerate}
Thus this family exhibits a quadratic auxiliary-free expansion and a linear
compact representation, but no power shrink from the already compact selector.
\end{proposition}
\begin{proof}
The monotone function in \eqref{eq:projection} has the $t^2$ clauses
$A_i\vee B_j$ as its prime implicates.  Each is prime: deleting an $A_i$
literal is falsified by an assignment satisfying the full $A$ conjunction;
deleting a $B_j$ literal is handled symmetrically.  Replacing each clause of
any equivalent CNF by a contained prime implicate cannot increase its clause
count, and omitting any pair $(i,j)$ accepts an assignment that falsifies that
pair while satisfying every other pair.  Hence at least $t^2$ clauses are
required.

Build $2t$ OR gates for the $A_i,B_j$, two fan-in-two AND trees using
$2(t-1)$ gates, and a final OR gate: $4t-1$ total.  Each two-input gate
equivalence uses three clauses and seven literal occurrences; pinning the root
adds one unit clause, giving the claimed counts.  Every indexed gate or literal
reference needs $\Theta(\log t)$ bits, so both the selector and circuit/Tseitin
representations have physical length $\Theta(t\log t)$.
\end{proof}

\paragraph{Pass-through context control.}
If an untouched context $R_k$ is copied to both parent and child, then
\[
 \frac{|S_t\wedge R_k|}{|P_t\wedge R_k|}\longrightarrow 1
 \quad(k\to\infty)
\]
for fixed $t$.  Therefore a local rewrite cannot establish a fixed global
power shrink unless it also contracts arbitrary context.  This falsifies only
pass-through transformations, not all possible SAT algorithms.

\section{Hostile controls and barrier audit}
\paragraph{Compact representation.} The example is deliberately easy: its
linear circuit is a shortcut.  It refutes any claim that $t^2$ resolvents are
inherent semantic information.  It does not refute a worst-case all-input
shrinker.
\paragraph{Auxiliary variables and re-entry.} Tseitin variables restore linear
CNF size but not a power improvement over $S_t$.  A recursive proof must choose
and close one representation rather than count the smallest description at
each level for free.
\paragraph{Padding/context.} Untouched context destroys fixed-power shrink for
the local rewrite.  An all-input map may inspect or transform the context, so
this is not a universal lower bound.
\paragraph{Affine/Horn/2-SAT/direct recognition.} Nothing here forces an
arbitrary solver to enumerate resolvents; direct recognition solves the test
family.  Restricted proof-system or representation lower bounds do not
transfer to all algorithms.
\paragraph{Relativization.} A maximal semantic oracle makes the target-dependent
oracle theorem trivial; this pinpoints the acquisition/evaluation line that a
constructive classical proof must cross.  Conversely, the firewall does not
separate P from NP.
\paragraph{Algebrization.} Algebraic-oracle access can only strengthen the
semantic-oracle control; no nonalgebrizing hinge is established.
\paragraph{Natural Proofs.} No constructive circuit property is used to derive
a general circuit lower bound, so that barrier is not invoked.
\paragraph{Machine models.} All byte counts are physical encodings.  No
one-tape, two-tape, RAM, FLMV, or Williams exponent is transported.  The earlier
tape-crossing results remain restricted model statements and are orthogonal to
this constructive test.

The valid sufficient constructive chain is
\[
 \boxed{\text{uniform closed physical child }|G(F)|\le |F|^\lambda}
 \Longrightarrow
 T(N)\le N^c+T(N^\lambda)
 \Longrightarrow T(N)=O(N^c)
 \Longrightarrow \mathrm{SAT}\in P.
\]
The sum is $N^c+N^{c\lambda}+N^{c\lambda^2}+\cdots=O(N^c)$ and the
depth is $O(\log\log N)$.  This is a sufficient criterion, not a new SAT
algorithm.  If SAT were already in P, a decider could output fixed encoded YES
or NO bases, so unrestricted existence of such a map is itself equivalent in
difficulty to the decision problem.
