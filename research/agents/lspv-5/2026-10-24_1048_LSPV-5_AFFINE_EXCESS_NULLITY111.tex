\section{Target, claim card, and mechanisms}
The ultimate target remains
\[
\forall A\ {\rm(total,uniform,deterministic,exact)}\ \forall c>0\ \forall N_0\
\exists F\quad |F|\ge N_0\ \land\ T_A(F)>|F|^c                       \tag{1}
\]
for one fixed NP-complete encoding.  The present SAME\_REALIZATION object is
the explicitly encoded mixed language $E\wedge B$, where $E$ is a system of
$\mathbb F_2$ equations and $B$ is unit/binary CNF.  Runtime includes parsing,
Gaussian elimination, parameter discovery, interaction-graph construction,
policy selection, every child, SCC, switching, reconstruction, source replay,
and peak live space.  Structural nullities are defined from $E$, independently
of measured runtime.

Three falsifiable mechanisms were tested.
\begin{itemize}
\item \PROVED{}: if affine component $i$ has nullity $d_i$, fixing
$d_i-1$ basis bits leaves at most one bit, so SCC gives an exact
$2^{\sum_i\max(d_i-1,0)}\poly(N)$ algorithm.
\item \PROVED{} stronger adaptive form: components coupled by $B$ factor into
interaction clusters.  The cost is governed by the \emph{profile}
$(K_1,\ldots,K_s)$ and is $\poly(N)+\sum_j2^{K_j}\poly(N_j)$, not by
$2^{\sum_jK_j}$.
\item \textbf{FALSIFIED/RETIRED as a universal lower-bound rule}: large total
excess nullity $K$ does not force large work.  SAT and UNSAT families with
$K=q$ but $q$ independent clusters are decided in $O(q)$ local work.
\end{itemize}

\section{Exact clustered excess-nullity theorem}
Build affine incidence components $U_1,\ldots,U_t$ by joining variables that
occur in one equation.  A variable absent from $E$ is a singleton component.
If $E|_{U_i}$ is consistent, set
\[
d_i=|U_i|-\operatorname{rank}(E|_{U_i}),\qquad
e_i=\max(d_i-1,0).                                                   \tag{2}
\]
Gaussian elimination writes every source variable $x\in U_i$ as
\[
x=a_x\oplus\bigoplus_{r=1}^{d_i}b_{xr}y_{ir}.                       \tag{3}
\]
Make the interaction graph $H$: its vertices are the affine components and
an edge joins $U_i,U_{i'}$ when a clause of $B$ contains variables from both.
Let $C_1,\ldots,C_s$ be its connected components and define
\[
K_j=\sum_{U_i\in C_j}e_i,qquad K=\sum_jK_j.                         \tag{4}
\]
The vector $(K_1,ldots,K_s)$ is analysis-visible only after paid parsing and
elimination; the solver is not given it as advice.

\begin{theorem}[Clustered affine-excess algorithm; \PROVED]\label{th:main}
There is a total uniform deterministic exact algorithm for mixed affine plus
unit/binary CNF instances with running time
\[
P_{\rm parse+GE}(N)+
\sum_{j=1}^{s}2^{K_j}P_{\rm sub+SCC}(N_j)+P_{\rm replay}(N),          \tag{5}
\]
where the $P$ are fixed polynomials and $N_j$ is the encoded size of cluster
$C_j$.  A depth-first implementation uses polynomial peak space.  In
particular, $K=O(\log N)$ is polynomial, and more generally
$\max_jK_j=O(\log N)$ is polynomial even when $K=\Theta(N)$.
\end{theorem}
\begin{proof}
An inconsistent affine component immediately makes the conjunction UNSAT.
Otherwise compute (3).  In each cluster, enumerate the first $d_i-1$ basis
bits for every component with $d_i\ge2$.  Exactly $K_j$ bits are fixed.
For a fixed enumeration, every source variable is a constant, the one
unfixed bit $y_{i,d_i}$, or its negation.  Substitution therefore turns every
clause of $B$ into a satisfied clause, a contradiction, a unit, or a binary
clause on the surviving component bits.  SCC decides this child exactly.

The affine equations share no variables between components, and a binary
clause crosses components only along an edge of $H$.  Thus different
connected components $C_j$ share neither variables nor clauses.  The whole
conjunction is SAT iff every cluster is SAT; costs add instead of multiply.
For SAT, retain one successful child and back-substitute (3), then replay all
source equations and clauses.  For UNSAT, all children of at least one
cluster fail; no particular proof object is required.  Processing children
and clusters serially retains one child state plus the source/elimination
data, hence polynomial peak live space.  Every operation in (5) is charged.
\end{proof}

The scalar $K$ gives the weaker immediate bound $2^K\poly(N)$.  The profile
form is essential: replacing it by a scalar before factorization silently
models a fixed policy and can be exponentially pessimistic.

For the endpoint, vertex $v$ has
$x_{v,1}\oplus x_{v,2}\oplus x_{v,3}=1$, three local NANDs, and every graph
edge has three colour-conflict NANDs.  Odd parity permits
$001,010,100,111$; local NANDs delete $111$, leaving exactly one-hot colours.
Every affine component has $d_i=2$, so $e_i=1$.  This independently checks
Role~4's parsimonious graph-colouring reduction.  In the declared four-clause
CNF encoding of each XOR, for $v=|V|,e=|E|$,
\[
n=3v,\quad m_2=3v+3e,\quad k=4v,\quad M=7v+3e.                      \tag{6}
\]
Theorem~\ref{th:main} gives $2^v\poly(N)$ on a connected endpoint, only an
upper bound.

\section{Baseline, transport, and coverage ledger}
For the fixed-width implication chain with forced $z_0=1,z_q=0$ and
$C_i=(\neg z_{i-1}\vee z_i)$ when $b_i=1$, otherwise
$C_i=(\neg z_{i-1}\vee\neg z_i)$, induction gives UNSAT iff $b=1^q$.
On the all-one input, skipping orientation $i$ leaves the same transcript
after its fixed-length sign flip, which makes the formula SAT.  Hence all
$q$ fields are queried.  This is exactly $q$ field probes, at least $q$
orientation-bit probes, between $q$ and the record width times $q$ bit reads
depending on access granularity, and $\lceil q/w\rceil$ to $q$ machine-word
reads under a stated packing convention.  It is not an unrestricted time
lower bound.  Both labels have identical identifiers, headers, record counts
and length.

For any attempted reduction, the only valid transport remainder is
\[
L_{\rm old}(n)\le R(n)+H(n)+Q(n)\tau(n)T_{\rm new}^{\le}(g(n)),
\quad
T_{\rm new}^{\le}(g(n))\ge
\frac{L_{\rm old}(n)-R(n)-H(n)}{Q(n)\tau(n)}                         \tag{8}
\]
when the numerator is positive and models match.  Here the source bound is
linear in fields and explicit target construction is linear, so no positive
superlinear remainder follows.  Direct inclusion preserves only the same
input-acquisition order.

The broader class ``2-CNF plus at most $k$ ternaries'' still has the certified
$2^k\poly(N)$ upper bound, is polynomial for $k=O(\log N)$, and contains
3-SAT when $k$ is unrestricted.  The excess-nullity profile is a different,
representation-specific upper parameter; neither is a lower bound.

\section{Barrier audit and first missing lemma}
The result relativizes as an upper algorithm; a SAT oracle only makes it
easier.  Algebraic access can solve the affine core and does not create a
lower bound.  DEAD/COPY/DELAY padding can inflate $N$, nullity or source size
without comparable decision work.  Independent products change the profile
from one large $K$ to many small $K_j$ and therefore refute multiplication of
independent costs.  Tseitin parity sources and Role~3's Resolution/DNNF
firewall show that hard explicit proof/representation output is not mandatory
for one-bit decision.  No Natural-Proofs claim is made.

The exact surviving chain is
\[
\begin{gathered}
\boxed{\text{defined obstruction}}\\[-2pt]
\Big\downarrow\ {\OPEN}\\[-2pt]
\boxed{\text{charged acquisition/compression/continuation dichotomy}}\\[-2pt]
\Big\downarrow\ {\OPEN}\\[-2pt]
\boxed{\text{every adaptive exact decider}}\\[-2pt]
\Big\downarrow\ {\OPEN}\\[-2pt]
\boxed{\text{superpolynomial contradiction}}
\end{gathered}                                                       \tag{9}
\]
The highest-value missing lemma is a representation-neutral theorem for one
explicit connected NP-complete family: after charging all source recognition,
Gaussian/SCC/Horn shortcuts, decomposition, branching, learning, caching,
restarts, recomputation and direct decision, every total uniform exact policy
must incur superpolynomial acquisition, compatibility, or continuation work.
It must survive the cluster-profile collapse above.  No such lemma is proved.
