\section{Proposals and recovered construction}
Three falsifiable options were fixed before primary-source review: rebuild each child, regenerate its fields lazily, or retain a common ordinary block body and update boundary pins only between completed calls. The last succeeds for the mathematical candidate in INTERFACE-PROJECTION8. Its earlier full implementation was not recovered; the new auditor is an independent implementation, not a rerun of the archived experiment. EAGER-LAZY-FRONTIER34 remains a correct upper-bound ledger. This result changes one implementation of its generation charge, not its semantic scope.

Let a supplied valid scoped proper-3CNF stream of bit length N contain OPEN(v), CLAUSE(l1,l2,l3), CLOSE(v). OPEN names are consecutive; clauses use three distinct live variables; every lifetime is contiguous and closes once. Let omega be maximum live width. Partition into J=O(N/b+1) contiguous blocks of b bits, up to one record of rounding. I_j is the ordered live set at cut j, with empty exterior boundaries; F_j is the actual block CNF. Put U_j=I_{j-1} union I_j, p_j=|U_j|<=2 omega, Q=sum_j 2^{p_j}, and L_max=tilde O(b+omega). These are structural parameters, not definitions from runtime.

\section{Stable ordinary-child construction}
For a literal l and fresh a,b, define
\[
\operatorname{FORCE}(l;a,b)=\bigwedge_{\epsilon,\delta\in\{+1,-1\}}
(l\vee\epsilon a\vee\delta b).
\]
This is equivalent to l: if l is false, each assignment of a,b violates a clause; if true every clause holds. Densely rename the block and boundary variables once and create
\[
H_{j,\gamma}=F_j\wedge\bigwedge_{x\in U_j}
\operatorname{FORCE}(x^{\gamma(x)};a_x,b_x).
\tag{1}
\]
Here x^1=x and x^0=not x. Every child is an ordinary proper 3CNF, with v_j+2p_j variables and m_j+4p_j clauses. Its header, length, names and unsigned supports are independent of gamma.

\begin{lemma}[PROVED/EXACT: quiescent updates]
Binary reflected Gray enumeration of gamma changes exactly four signed-literal fields between consecutive children. Holding the full buffer immutable during each exact solver call and modifying it only after return produces exactly the same child as fresh serialization.
\end{lemma}
\begin{proof}
Gray neighbors differ in one boundary bit x. Its literal appears once in each of four FORCE clauses. All remaining fields are identical. Equation (1) supplies the exact pinned semantics. The child solver is restarted with clean state; no stale learned clause or uncharged incremental interface is used. Mutation while a prior simulation is live is disallowed.
\end{proof}
The full ordinary child buffer is counted parent work memory, not a free read-only output. A simulated child may reread it arbitrarily. Workspace reset can use a compact sparse-store arena and charge clearing to the records created, with logarithmic overhead; it does not allocate an uncounted history of old calls.

\section{Exact boundary compatibility}
Maintain two packed frontier bitsets. Initially R_0 contains only the empty assignment. For each gamma on U_j whose left restriction lies in R_{j-1}, call one fixed exact ordinary SAT decider A on H_{j,gamma}. On a SAT answer insert its right restriction into R_j. Empty R_j gives UNSAT; nonempty final R_J gives SAT. Full grammar validation precedes early termination.

\begin{theorem}[PROVED/EXACT on the scoped class]
The procedure decides the conjunction of all source clauses on both labels.
\end{theorem}
\begin{proof}
By induction R_j is the exact projection of all satisfying prefix assignments onto I_j. A global model supplies feasible children. Conversely, a satisfying child extending a reachable left boundary glues with its prefix witness: every source shared with earlier clauses is live at the cut and pinned consistently. Closed variables cannot recur. At the final empty boundary, reachability is exactly satisfiability. Independent child SAT bits without these common assignments would be unsound.
\end{proof}

\section{Charged schedule and endpoint}
All identifiers have O(log N) bits. Use deterministic sorting and lookup structures in the mathematical construction. Let T_A(L),S_A(L) be simultaneous worst-case time/space bounds of the same fixed ordinary child decider. The implementation obeys
\[
T\le\widetilde O(N+Q+Q T_A(L_{\max})),\qquad
S\le\widetilde O(b+2^\omega+S_A(L_{\max})),
\tag{2}
\]
with child-generation writes W_gen<=tilde O(N+Q). W_gen is not all solver or parent writes.

\begin{proof}
Validation stores active names and the OPEN counter, in tilde O(omega) bits and tilde O(N) time. A second pass keeps one block body, a local naming map, pin offsets and one ordinary child buffer. Their simultaneous size is tilde O(b+omega); no full-source variable directory is used. Summed initialization costs are tilde O(N+J omega), hence tilde O(N) when omega=O(log N). Every Gray transition uses four field writes. Mapping assignments to frontier coordinates costs O(omega) word operations, absorbed by the tilde. Skipped candidates are included in Q. Two frontier bitsets occupy at most 2^{omega+1} bits. Calls run sequentially. Charge every failed call, reset, operand access and source reread. Adding the generator, buffer, bitsets and solver workspace proves the same-execution bound.
\end{proof}
For b=N^{1/2+o(1)} and omega<=log_2(N)/20, Q<=N^{3/5+o(1)}, L_max<=N^{1/2+o(1)}, and
\[
t'\le\max\{1,3/5+t/2\},\qquad s'\le\max\{1/2,s/2\}.
\tag{3}
\]
This is still a restricted recurrence. Compared with rebuilding every child, generation drops from tilde O(Q L_max) to tilde O(N+Q). For t>=1 the solver term already dominates the old generation exponent, so this alone does not improve the total worst-case exponent. It removes avoidable repeated writes, not the all-input gap. Initial materialization still makes input-order cumulative writes on nondegenerate sources; it does not meet a total-write exponent 1/2.

FLMV's counted work/index tapes, SAT transfer and Corollary 5.8 were checked in the original PDF, including screenshots of model and endpoint pages. With beta(c)=((c+2)/c^2-c)/2, beta(241/200)-1/2=26279/23232400>0. An ordinary all-input route achieving the target would contradict that endpoint. Supplied low-width streams are already easy by direct frontier DP, so no contradiction follows here. A full-length fallback or a freely stored normalized stream does not repair this gap.
