\section{PROPOSE: falsifiers fixed before search}
The current missing lemma is not ``some equality gadget exists.''  It is a
uniform, context-correct, physically nonexpanding transport or compiler that
applies on arbitrary SAT encodings and survives recursive re-entry.  Before
searching, this run fixed four falsifiable attacks:
\begin{enumerate}
\item \textbf{Cofactor attack.}  The two swapped source clauses might leave an
uncharged source cofactor, so the claimed equality could fail on a source
assignment even if the guard's uncontextualized port table looks correct.
\item \textbf{Coverage attack.}  The proof might work only for the finite
sources tested by LSPV-2 rather than every connected strict exact22 source.
\item \textbf{Composition attack.}  A valid single port might not support
fanout, either because the transported occurrences become unusable or because
signed counts/connectivity fail after a second use.
\item \textbf{Contraction attack.}  Exact transport might remain physically
saturated and expansive, so interpreting it as a single-child contraction
would be false.
\end{enumerate}

\section{BUILD I: source-indexed guard certificates}
Let \(G\) be the fixed 15-variable, 20-clause guard from
TWO-SWAP-EXACT-PORT-TRANSPORT223.  Its port is \(p=x_4\).  Write
\[
 g^+=(p\vee A),\qquad A=(x_8\vee\neg x_{10}),
\]
\[
 g^-=(\neg p\vee B),\qquad B=(\neg x_9\vee\neg x_{11}),
\]
and let \(G^\circ=G\setminus\{g^+,g^-\}\).

\begin{lemma}[Fixed guard implications]\label{lem:guard}
\[
 G^\circ\wedge p\ \models\ \neg A,\qquad
 G^\circ\wedge\neg p\ \models\ \neg B.
\]
Moreover \(G\wedge p\) and \(G\wedge\neg p\) are satisfiable.
\end{lemma}
\begin{proof}
The reproducer emits four source-indexed Resolution refutations:
\[
\begin{array}{c|r|r}
\text{pinned branch}&\text{proof rows}&\text{derived rows}\\ \hline
p=1,\ x_8=1&39&23\\
p=1,\ x_{10}=0&55&36\\
p=0,\ x_9=0&48&31\\
p=0,\ x_{11}=0&90&71
\end{array}
\]
Each non-source row is replayed as the unique nontautological resolvent of
two earlier rows at the recorded pivot, and the last row is empty.  The first
two branches prove \(p\Rightarrow\neg x_8\) and
\(p\Rightarrow x_{10}\), hence \(p\Rightarrow\neg A\).  The last two
prove \(\neg p\Rightarrow x_9\) and
\(\neg p\Rightarrow x_{11}\), hence
\(\neg p\Rightarrow\neg B\).
For totality, explicit satisfying true-variable sets for the complete guard
are
\[
 \{3,8,9,11,12,13,14\}\quad(p=0)
\]
and
\[
 \{3,4,10,12,13\}\quad(p=1).
\]
The checker directly evaluates every guard clause on both assignments.
\end{proof}

\section{BUILD II: corrected universal transport theorem}
Let \(H(X)\) be any connected proper strict signed exact-$(2,2)$ 3CNF,
and select a source variable \(x\).  Choose one positive occurrence in
\(C^+=(x\vee D)\) and one negative occurrence in
\(C^-=(\neg x\vee E)\).  Rename the guard privately except for its port
\(p\).  Replace the four literals
\[
\begin{array}{c|c}
\text{source}&\text{guard}\\ \hline
x\text{ in }C^+ \mapsto p&
p\text{ in }g^+ \mapsto x\\
\neg x\text{ in }C^- \mapsto\neg p&
\neg p\text{ in }g^- \mapsto\neg x .
\end{array}
\]
Call the result \(\mathcal T(H,x,p)\).

\begin{theorem}[Pointwise two-swap transport]\label{thm:transport}
Under Lemma~\ref{lem:guard}, for every complete assignment \(\xi\) to
the original variables and every \(e\in\{0,1\}\),
\[
 \exists Z\ \mathcal T(H,x,p)(\xi,e,Z)
 \quad\Longleftrightarrow\quad
 H(\xi)\wedge(e=\xi(x)).
\]
The output is connected, proper, strict signed exact-$(2,2)$ 3CNF and is
uniformly constructible by a deterministic scan.
\end{theorem}
\begin{proof}
The swap is a permutation of two positive and two negative literal
occurrences.  It therefore preserves every variable's positive and negative
counts, clause width, and properness.

Fix \((x,p)\).  If \(x=p=0\), the modified guard requires \(A=1\), and the
explicit \(p=0\) guard support supplies such an extension; the modified
source clauses evaluate exactly as the original clauses.  If \(x=p=1\),
the modified guard requires \(B=1\), and the explicit \(p=1\) support
supplies an extension.  Thus every satisfying source assignment extends on
the diagonal.

If \(x=0,p=1\), the guard clause \(x\vee A\) requires \(A=1\), contradicting
\(G^\circ\wedge p\models\neg A\).  If \(x=1,p=0\), the guard clause
\(\neg x\vee B\) requires \(B=1\), contradicting
\(G^\circ\wedge\neg p\models\neg B\).  Thus both off-diagonal fibers are
empty, independently of \(D,E\); no source cofactor was discarded.

For connectivity, the source and guard remain internally connected after
their selected incidence edges are exchanged, and the two cross-incidences
join them.  The fixed guard also contains alternate incidence paths, so a
selected guard edge is not the unique bridge.  A linear scan can locate the
first positive and negative \(x\)-occurrences, shift guard names, and emit the
new DIMACS stream.
\end{proof}

\paragraph{Why the finite source tests are not the proof.}
The proof above quantifies over arbitrary source clauses \(D,E\).  The finite
tests below are hostile regression controls only.  They do not extrapolate a
truth table over sources.

\section{BUILD III: the exact fanout corollary}
\begin{corollary}[Occurrence-replacement equality fanout]\label{cor:fanout}
For every integer \(r\ge1\), there is a deterministic uniform construction
\(\mathcal F_r(H,x;p_1,\ldots,p_r)\) in the same connected strict exact22
class such that
\[
 \exists Z\ \mathcal F_r(H,x;p_1,\ldots,p_r)
 \equiv H(X)\wedge\bigwedge_{j=1}^{r}(p_j\leftrightarrow x)
\]
pointwise over all original source variables and all new ports.  It has
\[
 n_r=n+15r,\qquad m_r=m+20r.
\]
\end{corollary}
\begin{proof}
Induct on \(r\).  Theorem~\ref{thm:transport} gives the base case.  After
one use, the original name \(x\) occurs in the two exchanged guard clauses,
once positively and once negatively.  The entire current formula is again a
connected strict exact22 source.  Apply Theorem~\ref{thm:transport} to those
occurrences and a fresh guard.  Existential quantification of the fresh
private guard variables conjoins the new equality without changing the
previous pointwise relation.  Repeat.
\end{proof}

\paragraph{What this corrects.}
The statement in OPEN-PORT-DEFICIT-REFEREE196 that \emph{fanout remains open}
is stale if fanout means occurrence-replacement copying inside an already
exact22 source.  It remains correct for a \emph{free dangling port} that can
be conjoined without source occurrence replacement, and it remains open for
a charged arbitrary-3CNF-to-exact22 compiler with the required contextual
semantics.

\section{SAT/UNSAT polarity and one-program uniformity}
The construction never receives a free answer-class bit.  One deterministic
program performs the same two swaps on SAT and UNSAT sources.  The pointwise
identity implies that an UNSAT source stays UNSAT and a SAT source has exactly
the diagonal port extensions.  Side-specific execution restrictions therefore
share the same acquisition and construction program; favorable SAT witnesses
do not establish worst-case all-UNSAT coverage for any unrelated solver.

\section{Relativization, algebraization, wrappers, and PQ transfer}
The transport proof is elementary and syntactic.  An arbitrary oracle attached
to a SAT instance does not make the missing arbitrary-instance compiler
uniformly evaluable; a target-dependent oracle table is still hidden advice.
The fixed guard is not an algebraic lower bound, and affine elimination solves
the recognized quartet island.  Wrapping a general formula inside a guarded
always-SAT instance can make exact port acquisition NP/coNP-hard without
making decision-only compression hard.  Schur-square, quadratic-relation,
collision-entropy, and cryptographic binding ideas are therefore
\textbf{ANALOGY/CANDIDATE} only here; no exact PQ theorem transfer closes the
missing compiler.
