\paragraph{Status.}
\textbf{PROVED/EXACT (scope stated):} a designated puncture-profile bit is NP-complete to acquire on arbitrary proper-3CNF modules, and two linear-size proper-3CNFs can have identical exact projections on every strict subset of a named boundary while their full boundary relations are disjoint.  \textbf{FALSIFIED:} exact local marginals, even all proper marginals, determine global compatibility.  \textbf{COMPUTATIONAL:} 90,643 deterministic assertions pass.  \textbf{OPEN:} a uniformly acquired joint moving summary that contracts arbitrary SAT and remains recursively closed.  These results are compiler firewalls, not a SAT runtime lower bound or a resolution of P versus NP or ARC-EDGE-90.

\section{PROPOSE: falsifiers fixed before search}
The missing constructive lemma after report 191 is a repeatable joint projection: given an arbitrary surviving core, discover in polynomial charged time a complete compatibility summary and emit one physical $N^\lambda$ child.  Four failure mechanisms were fixed first.
\begin{enumerate}
\item A constant puncture profile is cheap only because the peer grammar uses fixed 15-variable modules; acquiring the same bit for an arbitrary module can encode SAT.
\item Individually exact summaries of small boundary subsets can lose a correlation visible only on the full boundary.
\item A moving algorithm can retain that lost information in a readable source/update log, invalidating a source-free state lower bound while still failing to produce a smaller recursive child.
\item An easy signing chosen from an unsigned support need not preserve the answer of the adversarial signed input.
\end{enumerate}

\section{BUILD I: profile acquisition contains SAT}
Write a punctured module as $M=A\land C$, with selected clause
$C=(p\lor q\lor r)$, selected literal $\ell=p$, and $D=q\lor r$.  Its profile contains $(1,0)$ precisely when
\[
 \exists\theta\quad A(\theta)\wedge p=1\wedge q=0\wedge r=0.
\]

\begin{theorem}[One profile entry is NP-complete]
Given an arbitrary proper 3CNF $F(X)$, one can construct in linear time a proper 3CNF punctured module $M_F=A_F\land(p\lor q\lor r)$ such that
\[
 (1,0)\in P(M_F)\iff F\in\mathsf{SAT}.
\]
Consequently profile-entry membership is NP-complete and profile-entry absence is coNP-complete for this unrestricted module language.
\end{theorem}
\begin{proof}
Use fresh $p,q,r$.  Put $F$ in $A_F$, force $p=1$, $q=0$, $r=0$, and leave the displayed selected clause outside $A_F$.  A unit literal $s$ can be forced using four proper ternary clauses with fresh $u,v$:
\[
 (s\vee u\vee v)\wedge(s\vee u\vee\neg v)
 \wedge(s\vee\neg u\vee v)\wedge(s\vee\neg u\vee\neg v).
\]
Use $s=p,\neg q,\neg r$ with disjoint fresh auxiliaries.  The resulting clauses are proper and distinct.  Every model of $F$ extends by the forced values and arbitrary consistent pin auxiliaries to a profile witness for $(1,0)$; conversely such a profile witness restricts to a model of $F$.  A complete assignment is a polynomial certificate, proving membership in NP.  Complementing the bit gives the coNP statement.
\end{proof}

This theorem does not say fixed-template profiles are expensive: PUNCTURE218 legitimately enumerates $2^{15}$ assignments as a constant.  It says the same operation cannot be imported to arbitrary growing modules without supplying the missing SAT algorithm.

\section{BUILD II: parity twins defeat every proper marginal}
For $b\ge2$ and $r\in\{0,1\}$ define the boundary relation
\[
 R_{b,r}=\{x\in\{0,1\}^b:x_1\oplus\cdots\oplus x_b=r\}.
\]
Let $E_{b,r}$ be the ordinary proper 3CNF obtained by a linear XOR Tseitin chain: each gate $z=x\oplus y$ uses the four standard proper ternary clauses, and the final parity bit is forced to $r$ by the four-clause pin gadget above.  Thus $E_{b,r}$ has $2b+1$ variables and $4b$ clauses, and existential projection of its auxiliaries onto the named $b$ variables is exactly $R_{b,r}$.

\begin{theorem}[All strict marginals agree, full relations conflict]
For every strict subset $S\subsetneq[b]$,
\[
 \pi_S R_{b,0}=\pi_S R_{b,1}=\{0,1\}^{S}.
\]
But $R_{b,0}\cap R_{b,1}=\varnothing$.  Hence $E_{b,0}$ and $E_{b,1}$ have identical exact existential projections onto \emph{every} strict boundary subset, while their conjunction (with shared boundary and disjoint auxiliaries) is UNSAT.
\end{theorem}
\begin{proof}
Fix any assignment to a strict subset $S$.  At least one boundary coordinate is unassigned.  Set all but one omitted coordinate arbitrarily, then choose the last coordinate to make the total parity $0$ or $1$, respectively.  This proves both strict projections are full.  No complete boundary assignment has both even and odd parity, proving disjointness and UNSAT of the conjunction.
\end{proof}

For $b=2$ the relations are equality and disequality: each unary projection is full, yet the full relations are disjoint.  The family shows that local exactness is not compositional exactness.  It remains an easy affine family: Gaussian elimination stores one global parity bit and decides the conjunction immediately.  Therefore the theorem falsifies marginal-only summary architectures, not all semantic representations or algorithms.

\section{Finite controls and physical ledger}
The dependency-free reproducer emits actual proper 3CNFs for $b=2,\ldots,7$, checks every full assignment and every one of the $2^b-1$ proper boundary subsets, and brute-forces the joint UNSAT conjunction through $b=5$.  It also checks the extension argument through $b=12$ and exhausts every Boolean source truth table on at most four variables for the profile-bit reduction.  It passed 90,643 assertions, covering 65,814 source truth tables and 1,050,698 source assignments.  At $b=7$, each parity chain has 15 variables and 28 clauses; its ASCII DIMACS size is 320 bytes for even and 316 for odd.  The four-byte difference is merely the four printed minus signs in the final pin, not a semantic size claim.

On an indexed RAM, the parity chain and pin gadgets are generated in $O(b)$ word operations with charged $O(\log b)$-bit addresses.  A fixed-$k$ read-only-input TM can scan and generate them in polynomial time and $O(b\log b)$ physical output bits.  A single-tape machine additionally pays for the initial input footprint and head travel; a fixed universal interpreter pays polynomial simulation overhead.  No crossing-sequence or write lower bound is transferred to RAM or to arbitrary SAT.  The result concerns information discarded by a specified marginal representation, independent of these machine simulations.
