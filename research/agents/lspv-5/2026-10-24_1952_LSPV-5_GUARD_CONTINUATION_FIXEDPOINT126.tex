\section{Question and verdict}
The highest-priority shared gap is still an achievable-pair edge: from one
fixed uniform exact all-input SAT machine with simultaneous exponents
$(t,s)$ in the matched Fortnow--Lipton--van Melkebeek--Viglas (FLMV)
random-access model, obtain another such machine with a charged favorable
pair.  This run tests whether the exact guarded boundary family of
GUARDED-BOUNDARY-ACQUISITION90 becomes an ARC contraction after repeated
scoping.

Three falsifiable mechanisms were considered.
\begin{enumerate}
\item Fixed-depth exact boundary tables might expose progressively smaller
continuations.  \textbf{FALSIFIED}: one corner is an ordinary child of
asymptotically the same encoded size as its parent.
\item Repetition might amplify the parent bit into many independent hard
continuations.  \textbf{FALSIFIED for this transform}: exactly one of the
$2^d$ boundary words carries the source SAT bit; every other word is
unconditionally feasible.
\item A source-aware adaptive solver might have to acquire this boundary
relation before deciding the root.  \textbf{FALSIFIED}: every guarded root
is SAT, so a uniform solver can return a direct outer-guard-zero witness
without learning the hard corner.
\end{enumerate}
The result is a precise continuation fixed point and ARC no-contraction
ledger for this mechanism.  It is not a lower bound against unrelated
compilers or all deterministic SAT deciders.

\section{Guard transform}
Let $F=\bigwedge_{i=1}^m(\ell_{i1}\vee\ell_{i2}\vee\ell_{i3})$ be an
ordered proper 3CNF.  With a fresh guard $x$ and fresh $a_i$, define
\[
 \Gam(F)=\bigwedge_{i=1}^m
 \bigl[(\neg x\vee\ell_{i1}\vee a_i)\wedge
       (\neg a_i\vee\ell_{i2}\vee\ell_{i3})\bigr].                 \tag{1}
\]
All variables in every displayed clause are distinct.  Iterate with fresh
guards $x_1,\ldots,x_d$ to obtain $\Gam^d(F)$.

\begin{lemma}[One-layer projection; PROVED/EXACT]
For every proper 3CNF $F$, $\Gam(F)[x=0]$ is satisfiable and
\[
 \exists a_1\cdots a_m\;\Gam(F)[x=1]\ \equiv\ F.                 \tag{2}
\]
\end{lemma}
\begin{proof}
If $x=0$, set every $a_i=0$; the first clause in each pair is then true and
the second contains $\neg a_i$.  If $x=1$, one pair becomes
$(\ell_{i1}\vee a_i)\wedge(\neg a_i\vee\ell_{i2}\vee\ell_{i3})$.
Existentially eliminating $a_i$ gives precisely
$\ell_{i1}\vee\ell_{i2}\vee\ell_{i3}$: choose $a_i=0$ when the first
literal is true, choose $a_i=1$ when one of the other two is true, and if
all three are false the two clauses demand both values of $a_i$.
\end{proof}

\section{Exact depth-$d$ boundary relation}
Let
\[
 \Sigma_F^{(d)}=\{b\in\{0,1\}^d:
   \Gam^d(F)[x_1=b_1,\ldots,x_d=b_d]\text{ is satisfiable}\}.
\]

\begin{theorem}[Guard continuation fixed point; PROVED/EXACT]
For every ordered proper 3CNF $F$ and every fixed integer $d\ge1$,
\[
 \Sigma_F^{(d)}=
 \begin{cases}
  \{0,1\}^d,&F\in\SAT,\\
  \{0,1\}^d\setminus\{1^d\},&F\notin\SAT.
 \end{cases}                                                     \tag{3}
\]
In particular $\Gam^d(F)$ itself is always satisfiable, while exact
membership of $1^d$, the exact cardinality of $\Sigma_F^{(d)}$, and any
complete boundary table determine the original SAT bit.
\end{theorem}
\begin{proof}
Induct on $d$.  At the outermost layer, $x_d=0$ is feasible by Lemma~1,
regardless of the inner formula or other guard values.  When $x_d=1$,
existential elimination of the fresh auxiliaries recovers
$\Gam^{d-1}(F)$ without changing its inner guards.  Thus a boundary word
can be infeasible only if every guard is one, and that corner is feasible
exactly when $F$ is satisfiable.
\end{proof}

This faithfully extends the prior depth-one guard result.  It also explains
why a constant-false representation for an UNSAT residual is irrelevant:
the outer parent is SAT and may be decided directly, whereas a component
claiming to expose the exact feasible-boundary relation must still answer
the $1^d$ corner.  A one-bit parent decider is not required to compile that
relation.

\section{Ordinary child size and transport ledger}
Force each guard $x_j$ true with the proper four-clause unit gadget
\[
 (x_j\vee p_j\vee q_j)\wedge(x_j\vee p_j\vee\neg q_j)\wedge
 (x_j\vee\neg p_j\vee q_j)\wedge
 (x_j\vee\neg p_j\vee\neg q_j).                                  \tag{4}
\]
Call the resulting ordinary proper 3CNF $P_d(F)$.  Lemma~1 applied $d$
times proves $P_d(F)\in\SAT$ iff $F\in\SAT$.  If $F$ has $m$ clauses and
$n$ declared variables, exact counts are
\[
\begin{array}{c|cc}
 &\text{clauses}&\text{variables}\\\hline
 \Gam^d(F)&2^dm&n+(2^d-1)m+d\\
 P_d(F)&2^dm+4d&n+(2^d-1)m+3d.
\end{array}                                                       \tag{5}
\]
For every fixed $d$, both are linear-record encodings of $F$.  Under the
project's fixed-width proper-3CNF encoding
$N=(4m+2)\lceil\log_2(64(n+m+1))\rceil$, the pinned child satisfies
\[
 N(P_d(F))=N(\Gam^d(F))\,(1+o(1))                                \tag{6}
\]
along growing bounded-density families.  Thus its child exponent relative
to the guarded parent is $\lambda=1$, not $1/2$.  Allowing $d$ to grow only
introduces the explicit $2^d$ expansion unless a separate uniform sharing
representation and compatible endpoint simulation are proved.

Suppose a proposed ARC edge constructs one pinned corner and calls a base
solver of time exponent $t$.  With construction/recognition exponent $r$,
the honest recurrence is
\[
 t'\le\max\{r,\lambda t\}=\max\{r,t\}.                            \tag{7}
\]
No strict time contraction follows.  Materializing the full table makes
$2^d$ calls; for fixed $d$ this is a constant multiplier but still includes
the same full-size corner.  For growing $d$, table generation, addresses,
headers, compatibility and live storage are additional charged costs.
Virtual generation avoids output materialization but does not change
$\lambda$ or make corner selection free.  Equation (7) is an
\textbf{exact counterexample to this proposed transport}, not an
unrestricted time lower bound.

\section{Adaptive-state and BIT-RESOURCE1 ledger}
The tested policy begins with a read-only ordinary formula and state
$(\text{source address},n,m,\text{budget},\text{representation tag})$.
It may first try Horn, SCC/2SAT, affine, decomposition or cached
representations, charging recognition and failed trials.  On recognizing
the guard syntax it considers: direct root decision, one-corner
continuation, or a complete boundary table.  No true label is supplied.

The direct rule selects $x_d=0$ and appropriate outer auxiliaries; it
certifies SAT without inspecting the hidden source label.  The exact-table
rule changes state to a boundary-index controller.  All indices except
$1^d$ terminate by the zero-guard invariant; at $1^d$ it obtains the
source-equivalent child $P_d(F)$.  SAT needs one compatible witness if
requested, while UNSAT of the hard corner need not emit a fixed proof.
Switching back to the source, rereading it, caching a layer, or regenerating
clauses is allowed and charged.

The resource vector is
\[
 (U,R_s,R_w,W_w,\Delta_{\rm state},S_{\rm peak},BT,|P|),           \tag{8}
\]
where $U$ counts declared elementary bit operations, unchanged writes,
control, addressing, rule selection, failed recognizers, conversion,
generation and solver work; $R_s,R_w,W_w$ count source/workspace traffic;
$\Delta_{\rm state}$ counts actual complete-state flips separately;
$S_{\rm peak}$ includes buffers, caches, live ancestors and child headers;
$BT$ is cumulative live-bit time; and $|P|$ records program/representation
size where relevant.  The direct rule is a legitimate adaptive bypass.
Therefore an argument that requires every solver to acquire (3) silently
substitutes a stronger compilation task for SAT decision.
