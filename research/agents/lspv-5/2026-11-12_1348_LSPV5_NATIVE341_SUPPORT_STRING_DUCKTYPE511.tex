\section*{Why the bytes pass}
The checker verifies length and membership but never requires \texttt{Array.isArray(p.support)}.  JavaScript \texttt{String.prototype.includes} converts a numeric coordinate to a string; indexing the string returns a digit character that is converted back to an array index.  The affected AND3 nodes feed XOR directly, so no later AND3 union spreads their string-valued support.  The affine parity table is symmetric under the six coordinate permutations.  This is runtime duck typing, not authenticated array syntax.
