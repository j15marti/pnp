\section{Machine model and exact sparse-write simulation}
Fix input bit length $N$.  A \emph{charged log-word RAM} has read-only random
access to its ordinary explicit SAT input, blank random-access work memory,
$O(1)$ registers, a fixed finite instruction set, and address/value words of
$w(N)\le C\log(N+2)$ bits, where $C$ depends only on the fixed machine.
Let $T_M(N)$ be worst-case time and let $W_M(N)$ count every write event to
mutable work memory.  All caches, tables, auxiliary memories and mutable
address structures outside the $O(1)$ registers are included.  Input reads
and the final one-bit answer are not work-memory writes.  There is no free
polynomial cache.

\begin{theorem}[Sparse-write FLMV simulation]
\label{thm:sparse}
Let $M$ be one fixed uniform total exact SAT decider in the charged log-word
RAM model.  If
\[
 T_M(N)=N^{t+o(1)},\qquad W_M(N)+1=N^{u+o(1)},
\]
for fixed finite $t,u\ge0$, then one fixed uniform total exact decider
$M^{\#}$ in the FLMV random-access Turing-machine model has
\[
 T_{M^{\#}}(N)=N^{t+o(1)},\qquad
 S_{M^{\#}}(N)=N^{u+o(1)}.
\]
Both bounds hold for the same execution of $M^{\#}$ on every ordinary input.
\end{theorem}

\begin{proof}
Maintain a balanced search dictionary containing precisely the nonblank
work-memory cells of $M$.  A read of an absent address returns the blank word.
A write updates, inserts, or removes one dictionary item.  At every time the
number $D$ of stored items is at most the number of distinct addresses ever
written, hence $D\le W_M(N)$.  An item stores one $O(\log N)$-bit address, one
$O(\log N)$-bit value and $O(\log W_M)$ structural bits.  Since $W_M\le T_M$
and $t$ is fixed, the entire dictionary and the simulated registers occupy
$O((W_M+1)\log N)$ bits.  Index tapes and tree-navigation scratch use only
polylogarithmic additional space.

Each RAM instruction is simulated by a constant number of word operations
and dictionary operations.  A balanced-tree lookup or update takes
$O(\bigl(\log(W_M+2)\bigr)\operatorname{polylog}N)$ Turing-machine time.
Thus the total time is $T_M(N)\operatorname{polylog}N$ and the space is
$O((W_M(N)+1)\log N)$.  Polylogarithmic factors are $N^{o(1)}$.  The simulator
uses the same read-only ordinary input and returns exactly $M$'s answer, so it
is uniform, total, all-input correct, and the time and space bounds belong to
one machine $M^{\#}$.
\end{proof}

The blank-memory and bounded-word hypotheses are load-bearing.  The theorem
is not asserted for a machine with a free polynomial mutable cache, for
unbounded words, or directly for arbitrary long FLMV index tapes.  It is an
explicit model translation into FLMV, not an identification of the models.

\section{The time--write shadow of the published endpoint}
For $c>1$ define
\[
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
FLMV Theorem 3.1 and Corollary 5.8, with their SAT transfer, exclude one
uniform all-input machine simultaneously having time exponent below $c$ and
work-space exponent below $\beta(c)$ (with the usual strict slack).

\begin{corollary}[PROVED/EXACT restricted endpoint transfer]
No charged log-word RAM exact SAT decider has exponents $(t,u)$ satisfying
\[
 \exists c>\max\{1,t\}\quad u<\beta(c).
\]
In particular, $(t,u)=(6/5,1/2)$ is forbidden: at $c=241/200$,
\[
 \beta(c)=\frac{11642479}{23232400}>\frac12,
 \qquad c-\frac65=\frac1{200}.
\]
\end{corollary}
\begin{proof}
Theorem~\ref{thm:sparse} would put $(t,u)$ in the FLMV simultaneous
time--space set via the single simulator $M^{\#}$, contradicting the primary
endpoint.  The displayed rational inequalities provide strict exponent
slack and absorb the polylogarithmic simulation overhead.
\end{proof}

This corollary is a \emph{shadow} or inverse image of FLMV.  It does not add a
forbidden point for the original machine set $\mathcal E$, and it does not
produce any favorable route from a polynomial-time SAT algorithm.  A useful
new ARC proof would still need an all-input construction whose jointly
charged time and writes enter this shadow; by Theorem~\ref{thm:sparse}, doing
so would already create the missing FLMV route.

\section{Hostile control: label sensitivity with zero work writes}
For $b\in\{0,1\}^q$, use variables $z_0,\ldots,z_q$, force $z_0=z_q=0$, and
for each $i$ encode
\[
 z_i=z_{i-1}\oplus b_i
\]
by the two corresponding binary clauses.  The unsigned clause template,
record count and metadata are fixed; only the orientation field $b_i$
changes.  The formula is satisfiable exactly when
$\bigoplus_i b_i=0$.  Flipping any one orientation field flips the label.

Nevertheless, a uniform promise-family policy scans the orientation fields
sequentially, stores parity in one finite-control state, and accepts at the
end iff that state is even.  It performs $q$ input reads and zero work-memory
writes.  SAT and UNSAT instances occur equally often.  Thus
\[
 \text{many necessary source reads}\;\not\Rightarrow\;
 \text{many work-memory writes}.
\]
On malformed or non-template inputs a correct all-input solver needs a
charged recognizer and fallback.  The control proves only the failure of the
proposed universal implication; it is not a fast all-input SAT algorithm.

\section{Entropy and circuit-resource audit}
An exact information contract remains valid: if a deterministic procedure,
given side information $K$, retains $S$ bits and receives $q$ replies of at
most $w$ bits before reconstructing a specified random object $Y$, then
\[
 H(Y\mid K)\le S+qw.
\]
The transcript and retained state take at most $S+qw$ bits and determine
$Y$.  But an exact SAT decider need output only one bit and need not
reconstruct a witness, DNNF, proof, context table or history.  Taking $Y$ to
be such an optional object silently adds an output contract.  Therefore this
is \textbf{FALSIFIED/RETIRED as an unrestricted SAT-decision transfer} unless
a new theorem forces the chosen $Y$ in the same execution.

Likewise, circuit size, depth, gate basis, fan-in/out, sharing and wiring
layout define useful forbidden regions only after the circuit model and an
embedding theorem are fixed.  A parity-to-SAT substitution can transfer a
parity lower bound to SAT circuits in the same circuit class.  It does not
bound arbitrary sequential SAT time, and evaluation-circuit wires are not
SAT-solving circuit lower bounds.  VLSI routing and asymmetric-memory results
are exact within their physical/memory models; without the simulation above
they are analogies, not ARC endpoints.
