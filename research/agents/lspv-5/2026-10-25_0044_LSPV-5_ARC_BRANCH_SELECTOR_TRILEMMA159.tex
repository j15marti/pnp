\section{Mixed-channel telescoping certificate}
Suppose a total uniform extensional controller makes, for channel
$i\in\{1,\dots,q\}$, at most $N^{a_i+o(1)}$ ordinary SAT-bit queries of length
at most $N^{\lambda_i+o(1)}$, where every $\lambda_i<1$.  All local work is
$N^{r+o(1)}$ and all simultaneously live counted storage is
$N^{h+o(1)}$.  Define
\[
 M=\max_i\frac{a_i}{1-\lambda_i}.
\]

\begin{theorem}[Exact mixed-path certificate]
For every finite adaptive channel word $i_1,\ldots,i_d$,
\[
 \sum_{j=1}^{d}a_{i_j}\prod_{\ell<j}\lambda_{i_\ell}
 \le M\left(1-\prod_{j=1}^{d}\lambda_{i_j}\right)\le M.
\]
Consequently recursive oracle elimination yields one uniform total exact
ordinary-SAT machine with
\[
 \tau\le\max\{1,r,M\},\qquad
 \sigma\le\max\{h,\lambda_1,\ldots,\lambda_q\},
\]
when query strings are actually materialized on counted tapes; if $h$ already
includes them the explicit $\lambda_i$ terms are redundant.
\end{theorem}
\begin{proof}
Since $a_i\le M(1-\lambda_i)$, each summand is at most
\[
 M(1-\lambda_{i_j})\prod_{\ell<j}\lambda_{i_\ell}.
\]
The sum telescopes to the displayed expression.  Strong induction on ordinary
input length replaces every strict-short SAT oracle call by this same recursive
decider, preserving the entire adaptive transcript on SAT, UNSAT and malformed
inputs.  Depth-first execution and the geometric size stack give the space
bound.  Every query byte, read, write and address remains charged.
\end{proof}

For LSPV-4's two channels this proves, rather than assumes,
\[
 \tau=\max\left\{1,r,\frac{a}{1-\lambda},
                  \frac{b}{1-\rho}\right\},\qquad
 \sigma=\max\{h,\lambda,\rho\}.
\]
At $(r,a,\lambda,h)=(11/10,3/5,1/2,1/2)$, an added selector class is forbidden
by the strict FLMV box whenever
\[
 b<\frac{241}{200}(1-\rho),\qquad
 \rho<\frac{11642479}{23232400}.
\]
This is \textbf{PROVED/EXACT model-scoped}, not an all-algorithm lower bound.

\section{Raw branch/fanout dichotomy}
Let $F$ be a dense indexed $C_{\mathrm{M22}}$ instance with $k$ variables,
$m=4k/3$ clauses and $N=\Theta(k\log k)$.  A raw pin-and-copy descendant fixes
$q$ distinct source variables, removes satisfied clauses and false pinned
literals, and retains every clause disjoint from the pins.  Because every source
name occurs four times, every such descendant retains at least
\[
 u\ge m-4q
\]
untouched clauses.

\begin{theorem}[Complete raw-branch dichotomy]
Consider any fixed-depth complete independent pin tree whose accumulated paths
fix $q$ distinct source variables and represent all $2^q$ settings.
\begin{enumerate}
\item If total fanout is $N^{a+o(1)}$ for a fixed $a$, then
$q=O(\log N)$ and every leaf has encoded length $N^{1-o(1)}$; hence
$\lambda=1$.
\item If every leaf has length $O(N^\lambda)$ for a fixed $\lambda<1$, then
\[
 q\ge k/3-o(k)=\Omega(N/\log N),
\]
so the complete fanout is
\[
 2^q=2^{\Omega(N/\log N)}=N^{\omega(1)}.
\]
\end{enumerate}
The conclusion survives every fixed number of real pin levels because only the
accumulated distinct source pins matter.
\end{theorem}
\begin{proof}
Polynomial fanout gives $q=\log_2 N^{a+o(1)}=O(\log N)$.  The occurrence floor
then leaves $\Theta(k)$ untouched clauses on $\Theta(k)$ source names, requiring
$\Theta(k\log k)=N^{1-o(1)}$ indexed bits.  Conversely, a power-short complete
child has only $O(N^\lambda)$ untouched clauses, so
$m-4q=O(N^\lambda)$ and $q\ge k/3-o(k)$.  Complete independent branching has
exactly $2^q$ represented settings.
\end{proof}

This theorem permits neither semantic pruning nor merging.  It is a constructor
obstruction, not a claim that arbitrary SAT algorithms enumerate assignments.

\section{Restricted hybrid trilemma}
For a wrapper built only from complete raw pin-and-copy branching and
extensional strict-short SAT-bit selectors, at least one of the following holds:
\begin{enumerate}
\item raw children remain parent-scale ($\lambda=1$), so a base-machine call
does not contract its time exponent and eager materialization costs space
exponent one;
\item raw children are power-short but total complete fanout is
$N^{\omega(1)}$, outside every fixed ARC edge exponent;
\item strict-short extensional selectors replace missing branches, but recursive
elimination applies and, inside the displayed wedge, contradicts FLMV.
\end{enumerate}
Therefore this restricted hybrid cannot supply ARC-EDGE-90.  This does
\emph{not} close the general edge: propagation, learning, symbolic elimination,
cache merging, direct recognition, algebraic factorization, and a genuinely
polynomial-promise-sensitive $A$-dependent compiler are outside the theorem.

\section{Disjoint charged ledger}

workspace reads; changed and unchanged writes; input parsing and validation;
address arithmetic; adaptive selector discovery and switching; failed trials;
all guest-machine instructions and clocks; child names, headers and bodies;
ordinary grammar adapters; query materialization or every virtual bit probe;

parent-length string costs exponent $t$, while $N^b$ calls at length $N^\rho$

cumulative bit-time remain distinct from logical bit work and peak writable

Hostile controls include SAT and UNSAT direct recognizers, Horn, SCC/2-SAT,
affine/Gaussian solvers, graph factors, learned clauses, identical-child cache
reuse, one-bit grammar mutations that trigger fallback, source rereading and a
parent-length $A$ query.  Easy controls refute universal per-instance claims,
not worst-case statements beyond the declared architecture.
