Output counts are in [0,5^n], padded to 3N bits. There is no claim about the behavior of the Boolean test outside the two promised orbits.

Each strict clause uses three distinct variable names over Z/5. C consists of all 30 orderings of the triples 012,123,234,340,401. Permuting the slots therefore preserves every clause. The ordered 40-tuple R has distinguished first position and has no such blanket slot permission. Neither historical S nor Q enters the proof. The target length is always

    N = n + 2 + 2 floor(log2(m+1)) + 3m ceil(log2(n+1)).

The fields are unary n with terminator, gamma(m+1), then one-based fixed-width IDs. All domains start full. No planted assignments or orientation bits are supplied. Our scrambling operation changes only presentation, so n,m,N, Z and the decision label are identical before and after it.

Four ways to disprove the result would be (i) one ordered clause revealing the source bit in the specified uniform experiment, (ii) a legal split presentation with spurious or missing recovered links, (iii) equal numbers of length-three paths for the two audited inputs or a missing real-access cost in the stated circuit bound, or (iv) a differing full path histogram in the claimed NOR/implication sharpness control.

The counts are positive and distinct. The splitter's local fiber is checked below. We use the published unsplit circuit compiler under its stated hypotheses.

## Recovering actual equality links

Before splitting, give each occurrence of a variable its own copy and retain each original clause once using its occurrence copies. Between consecutive copies u,v the splitter appends, with four fresh private names a,b,c,d, exactly

    (u,a,b) (a,b,c) (b,c,d) (c,d,u) (d,u,a) (d,v,a).

There are three cases for the occurrence copies on a path of at least two vertices. The first has degree 4 (one core clause and three frame clauses), a middle copy has degree 5, and the last has degree 2. An isolated copy has degree 1. Among private names a,d have degree 4, and b,c have degree 3. Hence the degree-3 vertices are *exactly* the two middle private names of each gadget. Each has just one degree-3 partner in a common clause. The two clauses containing both yield a,d as their third names. The two clauses containing both a,d yield precisely the endpoint copies u,v as their third names. Checking the six triples gives an orientation, if needed: u also touches the middle private portion and v does not. Private names never occur outside that packet. These statements hold regardless of any coincidences in the *unsplit* source degrees. The actual sets of names and triples supply the certificate.

On a split image the resulting edge graph on copies is precisely one path per original variable with as many vertices as occurrences, including singleton paths. Collapsing each path and retaining the core triples recovers the unsplit source up to order and relabeling, provided the source has no declared unused variables, as is true of the generator. To use this outside a promise, check private disjointness, complete packet coverage, one core occurrence per copy, directed disjoint paths and strict distinct-name quotient clauses. Failed structural recognition returns UNKNOWN. Successful recognition certifies the local contraction identity even if the bytes came from another producer. It need not certify the compiler's historical production order or the original names.

Each frame forces five different colors since every pair co-occurs. The assignment therefore permutes the five colors and takes the five distinct cyclic triples to themselves as a set. The adjacent pairs are exactly the pairs of codegree two in that set, so the permutation preserves the 5-cycle and is dihedral. For fixed color at u there are two orientations. The two nonadjacent colors at d,a admit only u's color as the third color of the pin. There are exactly two extensions if u=v in color and zero otherwise. Private packets are disjoint, so Z(split)=2^E Z(quotient), with one independent twofold fiber per actual link. In particular decision is preserved by this contraction on both SAT and UNSAT sources.

## Input-aware distinguishing budget

Let h3 count path components with exactly three vertices. Before splitting, each input wire occurs in three domain clauses plus one occurrence per use as a gate input. In H0 the x0,x1 wire degrees are 5,3. In H1 they are 4,4. All other occurrence degrees agree. More explicitly, the p−1 (respectively p−2) unused Boolean inputs have degree three, and the two OR gadgets in the lifted circuit each add two private Boolean-compiler auxiliaries of degree three. Exclusion auxiliaries have degree two, the anchors have degree above three and the remaining Boolean wires have degree above three. Thus h3=p+3 for H0 and p+2 for H1. Full scans can compute h3, but even a local test suffices.

On the promised images mark a copy when it is the middle of a two-edge path whose two neighbors are distinct link-graph endpoints of degree one. There is exactly one mark per three-vertex component. Discovery of an incident link and both endpoints is a constant-radius operation in the input variable/clause incidence graph: read the two shared side names, private partner and port clauses, and the occurrence degrees. The endpoints of any one link are at incidence distance at most four. All clauses of a packet and its private degrees can be checked within eight hops of either endpoint. Testing the two neighbors' link degrees at most one further link away fits within radius 32. On these images variable degrees are at most five, clause degrees three.

Here is a uniform gate construction to charge these reads. For each p, verify the fixed header, fetch the 3m ID fields and range-check them. Emit records of O(log N) bits for both directions of each incidence edge. Group by ID to produce bounded adjacency lists. Unroll 32 rounds of neighborhood requests retaining each root and path-slot address: there are at most a fixed constant times n+m records per round on the promised degrees, even when paths meet. Sort keyed requests with the records supplying their lists, copy the list to requesters and return by root/slot. The number of requests to any one vertex is bounded by a constant depending only on the radius and maximum degree (count reverse walks); fixed neighbor windows after sorting suffice. Pad missing slots with invalid flags, bound group lengths, and choose any default output on malformed or off-promise data. Repeated IDs are compared as actual bit strings. Constant-many equalities and local incidence checks per fixed-radius neighborhood suffice. Count the marks by binary addition and compare with p+2; alternatively their parity suffices since the two values differ by one.

Pad each sort to a power of two, P. A bitonic sort uses (log2 P)(log2 P+1)/2 stages of P/2 compare-exchanges; each stage merges bitonic blocks by recursively comparing opposite halves. Each record compare-exchange costs O(log N) Boolean gates including key comparison and all payload bits. Since (n+m) log N=O(N) on this slice, the circuit has at most c N log²(2N) gates for an absolute constant c, for the structural selector, header and mark count together. The constant can be large in this simple radius construction. The bound is symbolic, not the gate count of the Python experiment. Circuit descriptions, including wire addresses, require O(g log(2g)) bits for g gates, and the fixed schedules are uniformly constructible in polynomial time from p. The slice lengths increase strictly with p; one can find p by enumerating up to N, or use a default on other lengths. There is no nonuniform count advice: compute y0,y1 by the displayed integer formulas.

With ell=3N, test whether the supplied z equals the selected true constant. The two equality tests and selector combine in at most 4ell+3 additional gates. For B ≥ c N log²(2N)+12N+3 this yields Pr[D(X,Y)=1]=1 and Pr[D(X,Y')=1]=1/2. This remains exact for every presentation law on the two orbits, with L independent. No pair can pass this budget for epsilon<1/2. At p=2, the smallest legal p for the published pair, N=21594 and the path counts are 5 versus 4. Under the original fixed presentation we retain the sharper peer bound of 12N+3. We do not transfer that linear bound to keyless shuffled inputs.

## A limitation with a concrete new input pair

On p≥2 inputs take two circuits, each with one OR and one NOT, in the indicated order:

    A = NOT(OR(x0,x1))
    B = OR(NOT(x0),x1).

Both inputs are used once, each intermediate wire is produced once and used once, and the final wire is produced once and used once by the lift. Each of these occurrences adds one clause containing the wire for either gate type. The anchors and gate-private variables have identical degree multisets because the two circuits use the same gate inventory and lift. Thus the **entire path-length histogram** agrees, also following any scramble. The positive strict-C counts are 5M'·2^(p−2) and 7M'·2^(p−2), by source truth counts 1 and 3 on two bits. Here E'=98+14p, M'=10·2^E', n'=515+74p and m'=629+90p. The header, exact N and multiplier match within this new pair. Both formulas are SAT. A test receiving only that histogram, the header and the proposed output has zero advantage against its independent fair count fake. This example invalidates histogram-based semantic merging. It makes no assertion that the pair hides higher-order incidence information.

The pointwise proof needs no uniform sampler time bound; exact uniform shuffles can use bounded-mean rejection per index with an unbounded worst-case random-bit tail. |
| Discover and authenticate | Read and parse the header, fields and repeated IDs. The promise distinguisher uses the bounded neighborhoods above. The separate certifying implementation groups incidences, tries both port orders and orientations, compares six-clause multisets and checks all paths and quotient clauses. A constant number of failed template orientations per packet is included. Off the split promise only checked contractions are certified. |
| Access, retention, sharing and output | Sort records include payload, addresses, keys and flags. Wires can fan out, repeated requests and path slots are accounted for. Counts and constants use O(N) bits. One output bit for the test. The Python reference retains source, indices and quotient for its own run. Equality checks use exact objects even when dictionaries use hashing internally. No free source read, residual query, SAT call, hardwired solution table, speculative branch, or hidden replay is required. |
| Bit implementation of the certificate | On valid split inputs there are O(n+m) IDs, clauses and adjacency/index records with O(log N)-bit fields and constant incidence degree. Indexed lists plus a visited bit and path label per vertex suffice; explicit quotient emission is ≤O(N) bits here. Deterministically implement visited marks and map lookups by scanning an indexed table in O(N) bit travel per request on a sole tape with linear occupied bits; O(N) requests, allowing an extra logarithmic factor for counters/record comparisons and head bookkeeping, give a coarse O(N² log²(2N)) time and O(N) occupied bits on these images. Carry a short lookup key along the tape by shifting its O(log N)-bit scratch window from record to record, allowing O(log² N) local steps per record. Store arrays in sequential records and mark actual traversals; do not infer this bound from Python timing. The circuit need not perform the full quotient sort or path traversal. |
| Counter A, same input and execution | Under T_A≤K N^a, S=O(N^a), physical CM=O(N^(2a)), self-contained minimum-description CM=O(N^(a+1)), including input. Its all-input count-map circuit ceiling is O(N^a log N). For a=2 the new test fits asymptotically inside an N² log N distinguishing budget. The same holds for each fixed a>1; this construction alone gives no constant-factor N log N test for a=1. These are upper bounds in their respective models. No exponent is excluded. |
