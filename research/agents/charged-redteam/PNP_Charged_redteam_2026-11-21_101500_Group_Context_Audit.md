## Reconstructed invariant and proof

For a Boolean assignment alpha on [v], define (alpha pull p)_i = alpha_{p(i)}. If f_u is the predicate of record u, the invariant is

Eval(Expand(u,p),alpha) = f_u(alpha pull p), with declared scope p(S_u).

A literal x_i becomes x_{p(i)}. Constants retain truth value and map their full declared scopes; thus a true constant on k declared free variables still has count 2^k. NOT commutes with substitution. Every native binary operation applies the same p to both children, preserving disjointness because p is injective. For a decision, its label and both children use p, preserving absence of the tested variable below it. These observations prove the native induction cases without merging merely equivalent predicates.

For a view u=(b,h), by its definition f_u(alpha)=f_b(alpha pull h). Substituting p gives (alpha pull p) pull h = alpha pull (p composed with h), so the recursive call must be Expand(b,p composed with h). Record IDs decrease, giving termination irrespective of view depth. Starting at identity, closure of G puts every accumulated p in G. Memoize by the exact pair (u,p). There are at most gM such pairs, and a view contributes only a pointer alias; a native record contributes at most a fixed number of ordinary DLDD nodes after literal normalization. The scope annotation is metadata and its bit cost is separately charged.

For each producing or final-closure event, expanding its entire prefix from scratch is an upper bound on the closed extension cost relative to any already available library. It costs O(gM) nodes using the final execution's g,M as upper bounds. There are at most M such normalized events by hypothesis. Hence sum_j kappa_j <= O(gM^2), and for c>=0,q_j>=1,

sum_j max(kappa_j-c q_j,0) <= sum_j kappa_j <= O(gM^2).

This proof bounds a constructed representation, not physical storage residence. It never adds hypothetical expansion work to A's actual work. Deleted histories can be used in the mathematical existence argument; a physical compiler must receive or reconstruct them at charged cost. If final closure is not a typed record, or its construction lies outside this architecture, the theorem does not apply to that run.

For dihedral maps i -> s+epsilon*i mod v, composition gives (s,e)*(t,d)=(s+e*t,e*d), so g<=2v. For v>=3 this yields O(vM) nodes and O(vM^2) defect. Small generator count alone does not bound g polynomially; the test includes the cycle/transposition generators of S_4, order 24, rather than only the dihedral example.

## Small failures of weakened rules

**Record-only caching, minimum nontrivial universe v=2.** Let u=x_0, let h swap 0 and 1, and let w=View(u,h). The node AND(u,w) is decomposable because its child scopes are {0} and {1}. It denotes x_0 AND x_1. Caching u only by ID can reuse x_0 for the second context, producing x_0 AND x_0; at assignment (1,0), the correct value is false and the wrong value true. It also destroys decomposability. Applying native NOT gives a complete NAND edge predicate with correct count 3 and wrong count 2. Thus this error occurs inside the actual NAND architecture, not just an unrelated function class. With one variable every unsigned permutation is identity, so this kind of context collision is impossible.

**Composition order, minimum noncommuting universe v=3.** Use outer p=(01), inner h=(12), and base x_0. Correct p(h(0))=1, but h(p(0))=2. Assignment (0,1,0) separates them. On one or two variables the permutation groups commute, so they cannot reveal this particular reversal. This is a control for the implementation, not a published-proof error.

**Free scope, v=1.** A true predicate declared on {0} has two assignments, although its essential support is empty. Counting only support gives one. This shows why scope transport cannot be replaced by tracking only syntactically mentioned or essential variables.
