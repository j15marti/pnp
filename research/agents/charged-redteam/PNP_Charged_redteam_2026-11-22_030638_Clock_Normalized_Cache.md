## Quantified normalization lemma

Fix a deterministic correct Boolean decision machine A with one finite-alphabet writable tape and one head. Suppose explicitly fixed integer polynomial bounds p(N)>=N and s(N)>=N bound its running time and tape span, respectively, on every member of a class F of N-bit inputs. Both p and s and the machine are fixed before choosing an input. These are constructive bounds of the algorithm, not advice depending on a sampled input. Then there is a fixed globally correct solver B such that every x in F reaches READY at the same absolute transition number tau(N), with head at origin, common control state, and all tape cells blank except its decision bit. Its costs on F satisfy

T_B=O(L²+p(N)L), S_B=O(L),
L=O(N+s(N)+log(p(N)+2)).

Outside F, B may invoke a correct fallback after a bounded failed simulation. No claim that F itself is recognized by a free oracle is needed.

First scan to the encoded end to obtain N. This traversal and all subsequent length arithmetic depend only on N. Allocate a fixed interval large enough for the retained immutable original, a bounded virtual tape, two configuration tracks, boundary markers and the binary step counter. A constant number of tracks is a single fixed product alphabet. Copy the input on a schedule fixed by N and initialize the virtual machine. Initialize the counter to p(N). Simple marked sweeps and length-based arithmetic suffice within O(L²) time and O(L) span. For the concrete polynomials below their binary arithmetic costs are polynomial in log N and fit this allowance.

Encode each virtual cell by its tape symbol and, at the unique virtual head, its finite-control state. One virtual transition is a local update of a radius-one neighborhood. A cell's next contents depend on its own symbol and any head marker at itself or its two neighbors. A halting configuration is made absorbing. A move beyond the allocated virtual interval sets an overflow status, also absorbing. These conventions avoid data-dependent early termination.

Perform a fixed number of complete physical sweeps per virtual tick. Read the old track with a three-cell sliding window and write the new value one cell behind the read position. A fixed left-one/right-two movement pattern per interior cell supplies the necessary delayed write, with fixed endpoint handling. Return across the entire interval to commit the new track and clear temporary markers. A further fixed sweep decrements the little-endian binary clock, carrying borrow in finite control and traversing every counter position even when borrow has cleared. It also resets finite auxiliary flags. Choose a common constant number of elementary transitions per cell for each local operation by inserting stay moves where necessary. The physical route, number of sweeps and per-cell transition count are then independent of virtual symbols. If a machine convention forbids stay moves, replace them uniformly by fixed excursions with a larger constant.

After exactly p(N) ticks, inspect the simulated status with one fixed sweep. A completed valid decision is remembered in finite control. An incomplete or overflowed simulation requests fallback after the same sweep. On successful inputs erase every track and the immutable original by a full predetermined traversal, preserving only the decision in finite control. Clear the clock, length and boundary markers as the sweep passes them. At the origin write that bit and enter a common READY state. The last endpoint marker is erased when departing it, so there is no input-dependent remnant. Different answer values select writes of equal duration. Every path through this success cleanup has identical physical movement and duration for the given N.

On F, A's stated bounds guarantee completion without overflow. Hence B answers correctly and tau(N) depends only on N. Outside F, any completed A answer is still correct because A is globally correct. If the bounded simulation fails, use the retained original for exhaustive decision. The original is erased only after the success flag is established. Discovery and recognition work are included inside the simulated p(N) budget. It is never permissible to use an unchecked early guess as a completed answer.

There are p(N) ticks of O(L) transitions plus setup and cleanup. All storage shares this single execution. Thus physical CM<=O(T_B L). Independently input and transition index describe every configuration in O(N+log(T_B+2)) bits, giving CM_min<=O(T_B(N+log(T_B+2))). Equality of these conventions is not required by the proof.
