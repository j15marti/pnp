\section{PROPOSE: falsifiable targets, before source search}

\item[] \textbf{M3, matched strict source:} cyclically swapping an affine shell and finite W1 modules produces connected strict signed exact-$(2,2)$ instances with both labels and identical unsigned supports. \textbf{PROVED/RESTRICTED}: one four-sign mode switch reverses the answer; actual sources and witnesses are checked below.
\item[] \textbf{M4, universal summary acquisition:} these two-state transitions can be constructed cheaply for arbitrary modules, including NP-complete cores. \textbf{OPEN}: computing a module profile is an existential SAT problem, not free.
\end{description}

\section{BUILD I: exact puncture profile and cyclic transport}
Let $F_i=A_i\land C_i$ be CNF modules on disjoint name sets $X_i$. Write $C_i=(\ell_i\lor D_i)$ with $\ell_i$ a designated occurrence of a literal of one fixed polarity, and $D_i$ the remaining two-literal disjunction. Define the \emph{puncture profile}
\[
P_i=\{(a,d)\in\{0,1\}^2: \exists\,\theta_i:X_i\to\{0,1\},\quad \theta_i\models A_i,\quad \ell_i(\theta_i)=a,\quad D_i(\theta_i)=d\}.
\]
In the cyclic occurrence splice, replace the designated $\ell_i$ in $C_i$ by $\ell_{i-1}$, indices modulo $k$; call the resulting conjunction $F^{\rm cyc}$. Matching polarities preserve both signed occurrence counts per original variable.
\begin{theorem}[Exact two-state cyclic transport]\label{th:transfer}
Let $T_i\in\{0,1\}^{2\times2}$ be the Boolean matrix
\[
T_i(u,v)=\bigvee_{d\in\{0,1\}}\bigl[(v,d)\in P_i\bigr]\wedge(u\vee d).
\]
Products are over the Boolean semiring. Then
\[
\boxed{\quad F^{\rm cyc}\in\SAT\iff\operatorname{tr}_{\lor}(T_0T_1\cdots T_{k-1})=1.\quad}\tag{1}
\]
Given the exact profiles, equation (1) is evaluated with constant workspace and $O(k)$ Boolean matrix operations. This is \emph{not} a theorem that the profiles can be acquired in polynomial time for arbitrary modules.
\end{theorem}
\begin{proof}
Every satisfying assignment to $F^{\rm cyc}$ restricts to assignments satisfying every $A_i$. Set $a_i=\ell_i(\theta_i)$ and $d_i=D_i(\theta_i)$. The remaining cross-clause at module $i$ is precisely $a_{i-1}\vee d_i=1$. Conversely, disjoint variable sets make arbitrary selections of realizing assignments for $(a_i,d_i)\in P_i$ mutually compatible, and those cross-clauses are the entire remaining formula. The matrix product records all transitions from the preceding chosen $a$ to the next chosen $a$; closing the cycle means the start and end $a$ coincide. Boolean trace implements exactly this condition. At most four entries are processed per factor.\end{proof}

For two components $A\land(\ell_x\lor D)$ and $B\land(\ell_y\lor E)$, the original answer is
\(\exists (a,d)\in P_A:\,a\vee d\;\land\;\exists(b,e)\in P_B:\,b\vee e\),
whereas one matching-polarity exchange gives
\[
\exists(a,d)\in P_A,\,(b,e)\in P_B:\quad (b\vee d)\wedge(a\vee e).
\tag{2}
\]
All $16^2=256$ abstract pairs of four-bit profiles were enumerated independently using equation (2) and the matrix theorem: 44 remained NO, 188 remained YES, \emph{16 changed from NO to YES}, and \emph{eight changed from YES to NO}. Matching literal degrees is therefore insufficient to preserve the answer even abstractly.

\begin{corollary}[Puncturing a minimally UNSAT module]\label{cor:puncture}
If $B\land(\ell_y\lor E)$ is minimally UNSAT, then $P_B=\{(0,0)\}$; a single same-polarity exchange with module $A\land(\ell_x\lor D)$ produces SAT precisely when $(1,1)\in P_A$. If two minimally UNSAT modules are consecutive in a cyclic splice, the resulting formula is UNSAT, independently of all other modules.
\end{corollary}
\begin{proof}
Minimality gives $B$ satisfiable. UNSAT of the original entails $B\models\neg\ell_y\land\neg E$, so its profile is exactly $(0,0)$. Formula (2) then reduces to the requirement $(1,1)\in P_A$. For consecutive minimally UNSAT modules $i-1,i$, the cross-clause $a_{i-1}\vee d_i$ is $0\vee0$, a contradiction. This recovers the earlier Role-3 cyclic-UNSAT result as a special case, without rewriting or weakening it.\end{proof}

\section{BUILD II: explicit strict exact22 source and matched sign switch}
For odd $p\ge5$ use the prior affine shell $R_p$ on $A_i,B_i,C_i$ with clauses
\[
(A_i^{\alpha_s}\lor B_{i+s}^{\beta_s}\lor C_{i+2s}^{\gamma_s}),\quad
\begin{array}{c|rrrr}s&0&1&2&3\\\hline
\alpha_s&-&-&+&+\\\beta_s&+&+&-&-\\\gamma_s&-&+&-&+
\end{array},\qquad i\in\mathbb Z/p\mathbb Z.
\]
Choose $C_R=(-A_{p-1}\lor B_0\lor C_1)$, $\ell_R=-A_{p-1}$ and $D_R=B_0\lor C_1$. After removing $C_R$, the four assignments obtained from $0^{3p}$ by independently setting $A_{p-1}$ and $C_1$ to one satisfy the remaining clauses (at most the removed $s=1$ clause loses its last negative literal when $A_{p-1}$ flips; every surviving clause involving $\neg C_1$ retains a separate negative literal). They realize all four $(a_R,d_R)$ pairs; thus $P_R=\{0,1\}^2$ with explicit uniform witnesses.

For $k\ge3$ define the cyclic splice of one $R_p$ module followed by $(k-1)$ identifier-disjoint W modes. Define $Z^+_{p,k}$ using modes $(11,00,00,\ldots,00)$ and $Z^-_{p,k}$ using $(11,11,00,\ldots,00)$. Both are actual ordinary 3CNFs with $3p+15(k-1)$ variables and $4p+20(k-1)$ distinct proper clauses.
\begin{theorem}[Matched connected strict signed exact-$(2,2)$ families]\label{th:matched}
For every odd $p\ge5$ and integer $k\ge3$, the two formulas $Z^+_{p,k}$ and $Z^-_{p,k}$ are connected proper signed exact-$(2,2)$-3CNF. They have the \emph{same unordered unsigned ternary clause scopes}, the same canonical physical ASCII DIMACS length, and differ in exactly four signed literal occurrences. Nevertheless,
\[Z^+_{p,k}\in\SAT,\qquad Z^-_{p,k}\in\UNSAT.\tag{3}\]
One uniform polynomial-time source-authenticated program decides every such cycle, including arbitrary sequences of the four W modes, by computing the exact two-state transfer and writes one ordinary 3CNF YES/NO child of a fixed $1{,}808$ bits. For a sufficiently large fixed input threshold $N_0$, its output obeys $N_{\mathrm{child}}\le N_{\mathrm{parent}}^{3/4}$; those two fixed children are directly solvable bases and form a closed restricted recursive class.
\end{theorem}
\begin{proof}
Each source module has exactly two positive and two negative occurrences of each name, and every exchanged occurrence is negative. Each variable therefore keeps its entire signed degree. Each module remains connected after deletion of the selected occurrence: for $R_p$, the $s=0,1$ layer ring loses at most one edge and remains a connected path, with all $C$ variables attached. For the fixed $W_1$ scope, a spanning tree after deleting selected $-y_5$ has edges
\((1,3),(1,7),(1,10),(1,13),(1,14),(3,6),(3,12),(3,15),
 (6,2),(7,11),(10,4),(10,8),(10,9),(14,5)\).
The cyclic borrowed literals connect these internally connected modules. Fresh modules prevent repeated variables within a clause; the source scopes guarantee uniqueness. Switching $W_{00}$ to $W_{11}$ reverses exactly two pairs of signs, retaining the total number of minus signs and therefore the physical byte length; unsigned clause scopes do not change.

For $Z^+$, choose the affine puncture state $(a_R,d_R)=(1,1)$, $W_{11}$ state $(0,0)$, and $(1,1)$ for every $W_{00}$. Every cyclic cross-clause is then true, so Theorem~\ref{th:transfer} and the explicit realizing assignments prove SAT. For $Z^-$, the adjacent $W_{11}$ modules have $a=d=0$, and Corollary~\ref{cor:puncture} proves UNSAT even if every other variable is chosen adversarially.

To decide an \emph{arbitrary authenticated cycle}, parse the complete ordinary source, check all signed clauses and identifiers, search the possible odd $p$, and identify each constant-size module's two switch bits by comparing all four signed templates. Candidates are rejected by full-source checks; no answer or decomposition oracle is supplied. The affine profile is generated by the four explicit witnesses; for each W template the $2^{15}$ possibilities can be enumerated uniformly, a fixed constant cost, rather than read from instance-specific advice. Multiply the resulting $2\times2$ matrices and output the fixed $W_{00}$ or $W_{11}$ ordinary DIMACS source. This one program handles both answers. A recognizer can rescan the input instead of storing its parsed arrays, use $O(\log N)$ counters/work bits, and spend a conservative polynomial number of native tape steps. The complete child source has $226$ ASCII bytes, hence $1808$ bits. For $N\ge N_0=32768$ bits, $1808\le N^{3/4}$; smaller recognized instances may be decided directly by the same polynomial profile procedure. The child is a fixed base and there is no uncharged recursive call.\end{proof}

\section{Resource-model firewall, barriers and next smallest step}
Let $N$ denote physical \emph{input bits}. A sequential read-only-input fixed-$k$ deterministic TM may try $O(N)$ possible affine prefix sizes, reparse the full source for each candidate, compute the necessary modular addresses with $O(\log N)$-bit counters and multiply the $2\times2$ matrices using constant state. A conservative native upper ledger is $T_k=O(N^3)$, $S_k=O(\log N)$ \emph{work bits}, with $O(N^3)$ head steps and an explicitly written constant-size child. This is a generous theoretical upper bound, not an interpreter measurement. A separate one-read/write-tape simulation with input included in the scanned footprint obeys the safe project bound
\[
T_1=O\bigl(T_k(N+S_k+\log(T_k+2))\bigr)=O(N^4),\quad
P_1=O(N+S_k+\log(T_k+2))=O(N),
\]
under standard product-track fixed-alphabet simulation. A fixed universal TM also charges its finite program encoding and polynomial interpreter overhead; no cross-model time or space maximum is borrowed as a SAME-RUN resource. An indexed RAM parser can pay all source probes and word-address formation and still remain polynomial; no sequential-head restriction is transported to unrestricted random access.

This grammar has potentially linear total syntactic backdoor and unbounded n, but a \emph{particular supplied/recognized moving one-bit interface} admits exact, cheaply acquired constant-state summaries. Such easy families demonstrate both why static coverage obstructions are not decision lower bounds and why general profile acquisition is the missing lemma. Indeed the general profile predicate
\(\exists\theta\;[A(\theta)\wedge\ell(\theta)=a\wedge D(\theta)=d]\)
is itself an existential SAT query in the module variables; a uniform polynomial algorithm for all arbitrary module profiles would already require a new SAT tractability result. Adding a uniform polynomial-bit rank alone does not bound recursion count; this construction terminates because it emits a directly solved fixed base.
