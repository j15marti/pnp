\section{Canonical exact22 code}
Take the original 15-variable, 20-clause W1 exact signed-(2,2) UNSAT source. For control $a$, complement both literal signs at zero-based positions $(6,0),(11,0)$ iff $a=0$; for control $b$, complement both at $(17,2),(9,2)$ iff $b=0$. Exact exhaustive counts of solutions for $(a,b)=00,01,10,11$ are respectively $772,272,272,0$. For $m$ disjoint copies, order all $2m$ $a$-dependent clauses, all $16m$ fixed clauses and all $2m$ $b$-dependent clauses. Therefore
\[
V=15m,\quad C=20m,\quad {\rm SAT}(F_m(a,b))\iff \bigwedge_{i=1}^m \neg(a_i\wedge b_i).
\]
All clauses have three distinct names, all physical clauses are distinct and each variable has exactly two occurrences of either polarity. The construction is \emph{signed}, not clause-monotone. Encode a fixed 16-bit magic header plus variable and clause counts each of width $w=\lfloor\log_2(20m)\rfloor+1$, followed by three polarity/identifier fields of width $w+1$ per clause, yielding
\[
N_m=16+2w+60m(w+1).
\]
The first controlled sign locations are
\[
p_A(i)=16+2w+6i(w+1),\quad
p_B(i)=16+2w+(18m+2i)3(w+1)+2(w+1).
\]
The second sign in each pair is its complement; all other fields and headers are constants computable in $O(\log^2N)$ bit time and $O(\log N)$ index bits.

\begin{theorem}[Minimum-distance canonical parser floor, restricted]
Let $\mathcal C_m=\{{\rm enc}(F_m(a,b)):a,b\in\{0,1\}^m\}$. For all $a,b,a',b'$,
\[
d_H({\rm enc}F_m(a,b),{\rm enc}F_m(a',b'))=
2d_H(a,a')+2d_H(b,b').
\]
Hence the minimum distance is two; every one-bit mutation of a canonical word is outside $\mathcal C_m$. Every deterministic total \emph{bit-probe} recognizer of $\mathcal C_m$ must inspect all $N_m$ bit positions on every accepted canonical input.
\end{theorem}
\begin{proof}
Each source control affects precisely two disjoint physical sign positions and no identifier or header; thus the distance formula follows. If an accepting recognizer leaves position $p$ unqueried, its deterministic transcript is identical when just $p$ is flipped. It wrongly accepts a noncanonical word. This proves the bit-query lower bound and does not lower-bound SAT decision on arbitrary encoded formulas or $O(\log N)$-bit word accesses.
\end{proof}
The direct promise SAT comparator reads $2m$ input sign anchors in $O(m\log N_m)$ binary-index bit writes and $O(\log N_m)$ index/work space. Strict canonical membership additionally checks all $N_m$ bits. With a word-RAM of $\Theta(\log N)$-bit prepacked input words, the appropriate operation counts instead divide bit scans by the word width; any initial packing must be charged.

\section{HEADMOVE-1 same-machine audit and jump simulation}
For one sequential two-way read-only input head and fixed $k$ sequential work tapes, let $H$ count input-head unit moves, $R$ changes of direction on nonzero input-head moves, and $S$ all visited work cells. Under the previously published HEADMOVE-1 construction, each fixed gap cut has $2^m$ different complete crossing transcripts on the SAT pairs $(a,\bar a)$. A record includes state, crossing direction, all visited work contents and all work-head positions, hence $O_k(S+1)$ bits. Counting transcript lengths and averaging first over each fixed cut, then over the same SAT inputs, chooses one accepted run with
\[
H(S+1)=\Omega(N_m^2/\log N_m).
\]
On this same run some cut has $\Omega(m/(S+1))$ crossings, whose directions alternate; therefore
\[
(R+1)(S+1)=\Omega(N_m/\log N_m).
\]
These are native to ONE sequential input head and do not transfer to a two-head input tape or indexed RAM.

\begin{theorem}[Charged bounded-jump transfer]
For a separate machine $M_J$ whose source head can jump by a charged signed binary displacement no greater than $J(N)$ while reading only the target bit, ordinary sequential-input simulation satisfies
\[
T_{\rm seq}=O(T_J(J+\log N)),\qquad S_{\rm seq}=O(S_J+\log N).
\]
Combining with the preceding native result gives the necessary exponent condition $t+s+j\ge2$ when $T_J=N^{t+o(1)},S_J=N^{s+o(1)},J=N^{j+o(1)}$.
\end{theorem}
\begin{proof}
Simulate each jump using at most $J$ unit head moves and an $O(\log N)$-bit countdown, leaving the sequential work tapes unchanged; feed the final target symbol into the simulated source transition. This charges construction, bit writing and movement on one machine. At $j=1$, the resulting diagonal is vacuous for $t\ge1$, consistent with the indexed-RAM shortcut.
\end{proof}
A $B$-bit batching algorithm needs $\lceil m/B\rceil$ left/right visits, $O((m/B)N)$ one-head unit movements, $O(m/B)$ reversals and $O(B+\log N)$ work. Replacing movements by radius-$J$ target-reading jumps gives $O((m/B)N/J+m)$ commands plus index/offset bit time. The claimed tightness is only for the logically easy promise.

\section{Four-sweep tape simulation and explicit ledger}
Represent the read-only input and fixed $k$ sequential work tapes on product-alphabet tracks of one writable tape, each virtual head encoded by a marker. With $L=O(N+S_k+\log(T_k+2))$ visited cells, one simulated transition uses four full sweeps: read all marked symbols; apply the finite transition, update the old work cell and left-moving markers; move right markers; return the single head to origin. For a Boolean decision output,
\[
T_1=O(T_kL),\quad P_1=O(L).
\]
Input bits count toward $P_1$ and are excluded from $S_k$. Probe and crossing counters are included in time, not added again. Hennie--Stearns' $O(T\log T)$ construction is for TWO tapes, not this ONE tape.

A separate compact equal-witness function $W_m(a,b)=\bigwedge_i\neg(a_i\oplus b_i)$ has $2m$ primary input wires, $m$ XOR and $m-1$ AND gates, but these gates are NOT charged twice as source TM transitions. A one-input-head/one-work-head streaming verifier copying $a$ and comparing $b$ was tracked step by step against a product-alphabet one-tape simulator. On $m=1,2,3,4$, the exhaustive source/one-tape steps had worst $(T_k,T_1,P_1)$ values $(14,617,11),(19,1141,15),(24,1825,19),(29,2669,23)$; $9320$ state transitions were verified. On a tape span of $n$ cells the displayed four-sweep implementation has exact $T_1=4nT_k+1$ and $H_1=4(n-1)T_k$; the final unit writes one decision bit over an input cell. The compact verifier is not a full ordinary-SAT parser.
