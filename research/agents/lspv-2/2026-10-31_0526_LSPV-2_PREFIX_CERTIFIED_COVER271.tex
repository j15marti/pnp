\section{Exact theorem and complete proof}
Let $F(B,P)$ be any source CNF with ordered interface $B=(x_1,\ldots,x_b)$ and private variables $P$. For a prefix $\rho\in\{0,1\}^d$ define its cylinder $[\rho]$ and exclusion clause
\[
D_\rho=\bigvee_{i=1}^{d} \begin{cases}x_i&\rho_i=0,\\ \neg x_i&\rho_i=1.\end{cases}
\]
A BLOCK leaf is admitted only after a source-indexed ordinary resolution DAG derives $C_\rho\subseteq D_\rho$ from original source clauses. An ACCEPT leaf is admitted only with a private assignment $\pi$ satisfying every original clause for \emph{every} boundary extension of $\rho$; at depth $b$ an individually checked witness suffices. Branch deterministically on the next interface bit otherwise, with exact proof-carrying DPLL fallback for unfinished attempts. Two BLOCK siblings can merge using ordinary resolution on their pivot, or reuse a child conclusion omitting the pivot. Collect maximal disjoint BLOCK prefixes $\mathcal L$ in deterministic tree order and physically emit ordinary CNF $G(B)=\bigwedge_{\rho\in\mathcal L}D_\rho$.

\begin{theorem}[Same-source YES/NO and proof transport]
For every complete authenticated tree and every boundary word $\beta$,
\[
G(\beta)=1\iff \exists P\,F(\beta,P)=1.
\]
Thus $\operatorname{SAT}(F)\iff\operatorname{SAT}(G)$, every child SAT witness lifts to a checked original-source witness, and if the root is BLOCK its original-source resolution certificate derives the empty clause. Every permanently learned BLOCK clause is source-entailed and survives policy switching.
\end{theorem}
\begin{proof}
Every original-source resolution step is sound. Hence any BLOCK certificate $C_\rho\subseteq D_\rho$ excludes all boundary extensions of $\rho$, not merely the suffixes actually inspected. Every ACCEPT prefix has one private model making all original clauses true independently of remaining boundary variables; complete-boundary ACCEPT words have individually checked models. The deterministic tree partitions all boundary words into disjoint cylinders; exactly the BLOCK cylinders falsify some emitted prefix clause. This establishes the pointwise equivalence and witness lifting. To merge two BLOCK branches, use clauses $x\lor U$ and $\neg x\lor V$, resolve to $U\lor V$, or reuse a conclusion lacking the branch literal, proving the parent's exclusion clause. Inductively a fully blocked root derives the empty clause from original source leaves. A budget-exhausted partial tree yields no accepted child and invokes the exact original-source fallback. \qedhere
\end{proof}

\section{Restricted family and parity countercontrol}
For $b\ge3$, let $B=\{x_1,\ldots,x_b\}$ and private variables $p,q,r,s$. Define
\[
F_b=\bigwedge_{\epsilon,\eta=\pm1}(x_1\lor\epsilon p\lor\eta q)
\ \land\!\!\bigwedge_{i=2}^b[(x_i\lor r\lor s)\land(\neg x_i\lor r\lor s)].
\]
The four indexed clauses derive $x_1$ by exactly three ordinary resolutions, so the entire prefix $x_1=0$ is one BLOCK. For $x_1=1$ the private model $r=1$ works for every suffix, so the tree has three nodes and ordinary child $(x_1)$. Adding the corresponding four clauses on $\neg x_1$ yields a matched UNSAT source with an ordinary empty-clause proof and child $\bot$. This is a structurally recognizable, repetitive family; its source recognition and original-clause reads are paid.

\begin{lemma}[Restricted parity prefix obstruction]
An auxiliary-free prefix-exclusion encoding of even parity on $b$ free boundary bits needs at least $2^{b-1}$ maximal rejected BLOCK cylinders.
\end{lemma}
\begin{proof}
Every nonfull prefix has a free bit whose flip changes parity, so it includes both accepted and rejected boundary words. Thus every rejected BLOCK is a complete word. Exactly half of $2^b$ words have odd parity. \qedhere
\end{proof}
This is a property of that specific prefix-only representation, not a lower bound on XOR-GE or arbitrary SAT solvers. Previous LSPV-2 run268 already established the related auxiliary-free parity CNF exponential size bound; there is no novelty claim.
