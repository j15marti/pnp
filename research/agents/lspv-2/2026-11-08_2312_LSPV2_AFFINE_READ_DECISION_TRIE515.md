## ITERATE: exact restricted theorem and proof

Let a single authenticated immutable original parent $p$ define **same-length** virtual input bits

$$
y_i(d)=p_i\oplus c_i\oplus\langle v_i,d\rangle,\qquad d\in\mathbb F_2^k.
$$

Assume the SAME deterministic guest has the same initial non-input state and output semantics for every child. Let $r$ bound the rank of affine coefficient rows at **all** input reads in each actual completed guest execution, including input reads feeding write-only OUTPUT actions. Construct an online cache as a binary trie. A TEST node stores one coefficient row $v_i$, original constant $p_i\oplus c_i$, two child pointers and the actual guest-read address. KNOWN leaves store the completed classification; UNKNOWN leaves trigger a FULL fresh guest execution.

After fresh execution at an UNKNOWN leaf, replay its genuine INPUT-read events in order. Maintain the affine row basis implied by preceding path tests. Skip a read only if its coefficient row lies in that basis, so its value is already fixed on that path. Otherwise replace the current UNKNOWN leaf with a new TEST of that genuine read, place UNKNOWN on the unobserved value, and continue insertion under the actually observed value; finish with KNOWN. Every inserted independent test is a read performed by the source-authenticated guest itself, not an external semantic oracle.

**Correctness induction.** At each TEST node, all descriptors arriving there agree with a single genuine guest prefix on all its previously encountered input reads. The next independent input query is determined by that identical guest prefix, so the branch test is legal and genuine. Any read omitted as dependent is affine-determined by prior tests and has the same value as in the anchored trace. Hence reaching KNOWN implies equality of ALL actually observed input values, guest transitions and output, including malformed classification if the guest is an all-input decider. At UNKNOWN, a fresh actual guest run supplies the missing trace, without assuming an input-decomposition theorem. The property is stable under insertion and arbitrary descriptor order. Test rows on each root-to-leaf path are independent and form a subset of the corresponding actual guest read rows, so depth is at most $r$; binary tree leaves and internal nodes are respectively at most $2^r$ and $2^r-1$. Fresh executions satisfy $K\le\min(q,2^r)$. This proof is a restricted deterministic affine decision-tree construction, not a new complexity lower bound.

At most $r$ parity decisions are needed per descriptor. Direct $k$-bit parity evaluation gives $O(qrk)$ lookup bit operations, replacing the $O(qKk^2)$ linear-scan bound of LSPV-2/514. At most $O(Kk)$ test/pointer/equation bits are stored if $k=O(\log N)$ and node pointers use $O(\log K)$ bits. Streaming per-guest row independence checks can be made polynomial in $k$ per actual guest input read, but their entire cost and guest computation belong to the guest-time ledger, not to free preprocessing. The designated guest output is only a finite decision label, not a free large witness or certificate.

For $q\le N^{a+o(1)}$, child length $m\le N^{\lambda+o(1)}$, rank $r\le b\log_2N+o(\log N)$ and $k=O(\log N)$, put $\kappa=\min(a,b)$. **Conditional on a genuinely supplied sound all-input child constructor, polylogarithmic paid affine port and basis operations, original-source authentication, a faithful SAME-FLMV-machine realization, full peak-space reset and suitable $N^{\rho_T},N^{\rho_S},N^\eta$ acquisition/simulation bounds**, the trie yields the symbolic envelope

$$
t'\le\max\{\rho_T,a,\kappa+\lambda t\},\qquad
s'\le\max\{\rho_S,\eta,\kappa,\lambda s\}.
$$

For $(a,\lambda,b)=(3/5,1/2,1/2)$, if $\rho_T\le11/10$ and $\rho_S,\eta\le1/2$, then $t'\le\max(11/10,1/2+t/2)$ and $s'\le\max(1/2,s/2)$. Unlike /514, **$a+b$ is no longer a necessary lookup term**. This is an improvement to a *conditional and restricted implementation bound*. It supplies neither the ALL-INPUT constructor, nor the universal rank premise, nor same-machine physical realization. Per-run source authentication and recursive-child construction might dominate. No general SAT speedup follows.
