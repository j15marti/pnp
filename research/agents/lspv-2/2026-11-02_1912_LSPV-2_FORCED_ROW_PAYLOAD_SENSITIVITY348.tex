\section{Exact infinite-family theorem}
For $n\ge2$ define
\[
F_n=(x_1)\land(\neg x_1)\land\bigwedge_{i=2}^n(x_i).
\]
Every named original variable appears, and $F_n$ is UNSAT with a two-clause minimal UNSAT core. Its source length in textual decimal DIMACS is $N_n=\Theta(n\log n)$. In the diagnostic ENUM\_ARITY proof with only the two contradictory unit clauses as premises, pack a one-bit index $b_a$ for every assignment $a\in\{0,1\}^n$; $b_a=0$ for $x_1=0$ and $b_a=1$ otherwise.

\begin{theorem}[Sensitive proof payload]
For every $n\ge2$,
\[
W_{R_{\rm mix341}}(F_n)=W_{R_{\rm cover347}}(F_n)=1.
\]
However, the specified valid ENUM\_ARITY proof has $2^n$ row bits and \emph{every one is individually sensitive}. Every deterministic exact verifier that accepts that literal proof format and rejects each single-bit corruption must inspect all $2^n$ row bits on its accepting run. With indexed word access of at most $w$ bits per probe this requires at least $\lceil 2^n/w\rceil$ word probes. Thus for this particular explicit proof the bit-probe verification requirement is
\[
2^n=2^{\Omega(N_n/\log N_n)},
\]
superpolynomial in the input length plus the unit logical node weight.
\end{theorem}
\begin{proof}
Resolution of $(x_1)$ and $(\neg x_1)$ yields the empty clause with one paid inference; zero-cost refutation is impossible. When $x_1=0$, exactly the first selected unit is falsified; when $x_1=1$, exactly the second is falsified. Changing any row bit therefore selects the clause \emph{satisfied} by that row's assignment, invalidating the proof. Suppose an accepting deterministic checker never queried the bit at position $a$. Its entire execution transcript would remain unchanged if that bit alone were flipped, so the checker would accept an invalid proof, contradiction. The source size includes all $n-1$ additional positive units and their indices, hence $N_n=\Theta(n\log n)$.
\end{proof}

This lower bound is for \emph{verification of this literal supplied certificate}, not for SAT decision, not for proof search, not for the minimum checking work across all possible certificates, and not for $W_R$. In fact, the normal one-node Resolution refutation has constant-sized justification. Thus the proposed general domination $T_{\rm verify}(\pi)\le p(N+\operatorname{cost}_R(\pi))$ for \emph{every} valid $\pi$ is falsified in the diagnostic uncharged-payload system, while B3 remains logically untouched.
