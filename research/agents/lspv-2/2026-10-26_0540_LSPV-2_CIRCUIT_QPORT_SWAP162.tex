\section{Target, hypotheses, and four falsifiable proposals fixed before search}
Use ordinary encoded proper signed exact-$(2,2)$ $3$-CNF: each active variable
appears twice in each polarity and each clause uses three distinct names;
clause-monotone exact-$(2,2)$ is separately stricter. The user-supplied
\emph{SAT resource extension}, dated October 26, 2026, proposes a
length-regular source-local literal projection and a hypothetical
near-boundary seed
\[
A\colon\SAT\in {\rm DTISP}(N^{d+o(1)},N^{o(1)}),\quad
d=901/500=1.802,\quad C(d)=651000/361301.
\]
This seed is an \emph{additional assumption}, not a consequence of $P=NP$.
The job is to inspect exact gadgets, gate access and what would be required
for a \emph{full length-$N$ SAT decision circuit} with $o(N^d)$ gates.

Before literature/repository searching, the four falsifiers were:
\begin{description}
\item[] H1: the older $15$-variable $19$-clause forced-false three-port $Q_{15}$
can replace the asserted $348$-variable $463$-clause $Q_{348}$ in the
new signed regularizer, with unchanged output semantics, exact $(2,2)$
occurrences and strictly better numerical constants.
\item[] H2: a fixed sorting network \emph{executed on unknown input keys}
has output bits that are literal projections. We seek a smallest
counterexample, and distinguish this from \emph{encoding} the sorting
network as a fixed verifier circuit.
\item[] H3: two genuine iterations of the source incidence-fixed signed
regularizer preserve literal/constant dependence on independent
source-sign controls and actual SAT/UNSAT semantics.
\item[] H4: a single-instance gate trace, or a $q=1.29$ child-relation
representation, yields a small circuit deciding all length-$N$ SAT strings.
We seek equal-length opposite-label controls.
\end{description}
H1 is \textbf{FILLED/RESTRICTED} with the existing verified $Q_{15}$ finite
dependency and the theorem below. H2 is \textbf{FALSIFIED} for an executed
sort and \textbf{not an objection} to the paper's fixed verifier approach.
H3 is \textbf{FILLED/RESTRICTED} algebraically and tested at two actual
levels, with polylogarithmic index access still conditional on a specific
layout generator. H4 is \textbf{FALSIFIED as an inference}.

\section{Three-port forcing gadget and substitution theorem}
For signed clauses \(C\) let \(\#_+(x),\#_-(x)\) denote incidences.
Call a \(q\)-variable \(m\)-clause proper 3-CNF \(Q\)
a \emph{zero-extension three-port} when three distinguished ports
\(p_1,p_2,p_3\) have profile \((1,2)\), all other variables have
\((2,2)\), \(Q\models\neg p_1\land\neg p_2\land\neg p_3\), and
the all-zero assignment satisfies \(Q\).
\begin{lemma}[Port deficit and constant substitution]
Every such gadget obeys \(4q-3m=3\).
The original \(Q_{15}\) and the claimed \(Q_{348}\) have deficits
\(4(15)-3(19)=3=4(348)-3(463)\), respectively.
The numerical difference
\[
348-15=333,\qquad463-19=444,\qquad
(333,444)=111(3,4)
\]
does \emph{not} prove that the larger gadget is the smaller one plus
\(111\) disjoint filler gadgets; it records only the compatible
incidence counts.
\end{lemma}
\begin{proof}
Every interior variable supplies four internal literals. Each port
supplies three, and there are three ports. Hence
\(3m=4(q-3)+3\cdot3=4q-3\).
\end{proof}
\begin{lemma}[Historical \(Q_{15}\), finite certified dependency]
Deleting \((1,7,13)\) from the exact \(20\)-clause \(W_1\) of
PCRETRACT1 gives a proper, clause-distinct \(Q_{15}\) with port set
\(\{1,7,13\}\), exactly \(244\) satisfying assignments, all of them
setting those ports to zero, and an all-zero satisfying assignment.
Its nonport variables have profile \((2,2)\);
its ports have \((1,2)\). These finite claims were independently
exhaustively checked in this run; the construction has a prior
reported bounded-width resolution certificate.
\end{lemma}
The small port model is precisely the interface needed in the new
signed regularizer; port \emph{indices} may be renamed, but one may not
silently substitute the older gadget into an unrelated use requiring
unique extension or monotone internal clauses.

\begin{theorem}[Exact \(Q_{15}\)-substituted signed regularizer]
Fix a source ordinary proper 3-CNF \(F\) with \(n\) declared variables
and \(m\) ternary clauses, including unused declared variables.
Make one occurrence clone per literal, three dummy clones per
declared variable, directed implication cycles for each source name,
one \(J\)-gadget with the missing sign on each occurrence clone,
two opposite \(J\)'s on each dummy, and group directed implications in
threes using \(Q_{15}\)'s forced-false ports. Let \(R_{15}(F)\)
be the resultant \emph{ordinary proper signed} 3-CNF. Then
\[
\SAT(R_{15}(F))\iff\SAT(F),
\]
every resulting variable occurs \emph{exactly} twice positively
and twice negatively, and
\[
\boxed{v_{15}=33m+48n,\qquad
m_{15}=44m+64n,\qquad3m_{15}=4v_{15}.}
\]
The output uses distinct proper clauses. The reduction does not claim
that the clauses are monotone. It may be applied again to its own
ordinary proper output.
\end{theorem}
\begin{proof}
The ring for each source name has at least three vertices, even
when the name does not occur. Every directed implication
\(\neg a\vee b\vee p\) uses a separate port of \(Q_{15}\).
All \(Q_{15}\) ports are forced false, hence the cycles imply all
clones of each original variable are equal. The unchanged source
clauses on occurrence clones therefore yield a source model
whenever the output is SAT. Conversely, copy a satisfying source
assignment to its occurrence and dummy clones and set all \(J\)
and \(Q_{15}\) auxiliary variables zero; every source, ring, and
auxiliary clause is satisfied. One cycle incidence of each sign
plus the original source literal and one opposite \(J\)-port literal
gives each occurrence clone profile \((2,2)\);
each dummy gets one \(J\) of each sign. Each \(J\) private variable
has \((2,2)\); each \(Q_{15}\) interior variable has \((2,2)\);
each \(Q_{15}\) port receives the one additional positive
padded-implication occurrence, completing \((2,2)\).

There are \(3m+3n\) cycle clones, \(3m+6n\) \(J\)-copies
(each with \(5\) fresh variables and \(7\) clauses), and \(m+n\)
\(Q_{15}\)-copies (each with \(15\) variables and \(19\) clauses).
Counting the \(m\) source ternaries and \(3m+3n\)
padded implications gives
\[
v=(3m+3n)+5(3m+6n)+15(m+n)=33m+48n,
\]
\[
m'=m+(3m+3n)+7(3m+6n)+19(m+n)=44m+64n.
\]
Properness follows from distinct clones in each source clause,
ring length at least three, and private fresh port/auxiliary
names. Distinct source copies and gadget namespaces rule out
repeated signed clauses.
\end{proof}

The former \(Q_{348}\) coefficients stated in the PDF were
\(v_{348}=366m+381n\), \(m_{348}=488m+508n\).
For a downstream \emph{separately verified} \(131\)-fold
monotone adapter, this substitution would algebraically replace
\[
(v_M,m_M)=(47946m+49911n,\ 63928m+66548n)
\]
by
\[
\boxed{(v_M,m_M)=(4323m+6288n,\ 5764m+8384n).}
\]
The monotone adapter's already-monotone arm is independently checked
here: three source-clause copies and 16 disjoint \(H\) gadgets use
exactly 96 fresh variables and \(3+16\cdot8=131\) clauses.
Its \(H\) has 18 satisfying assignments and each of the \(512\)
port assignments extends exactly when all three copied monotone
clauses hold. The full \emph{mixed} \(M_j\) adapter's 512 port
relations and 169 negative RUP proofs were not available and are
not newly certified by this theorem.

\section{Two actual levels, names, signs, and local-access firewall}
For a fixed-incidence source family \(F_x\), every clause position has
a source variable \emph{name} independent of \(x\), and each literal
sign is either fixed or a literal of at most one \(x_j\).
\begin{proposition}[Fixed-incidence literal preservation]
On this restricted input family, the \(R_{15}\) construction above
can be assigned a fixed output-clause and identifier ordering
independent of \(x\). Each output bit is a constant, an \(x_j\),
or its negation. The property survives any \emph{fixed number}
of \(R_{15}\) iterations. This statement does \emph{not}
give a polylogarithmic-time function computing the index \(j(N,i)\)
unless a local occurrence-list, inverse-index and variable-offset
arithmetic algorithm is also exhibited.
\end{proposition}
\begin{proof}
Clones and private J/Q names are allocated from source variable and
clause indices, not their signs. The ring topology and grouping
depend only on the \emph{fixed} signed-occurrence positions.
The sole input-dependent output slots are the rewritten
literal signs and opposite J-port signs, each of which is
a literal of the corresponding source sign. All internal
gadget signs, headers and name bits are fixed. Induction
repeats the argument after each level, because the output
incidence topology remains fixed.
\end{proof}
For \emph{arbitrary} source CNF encodings, constructing the
lists of occurrences per named variable may require source-dependent
sorting or prefix sums. The above result does not prove the
October 26 document's end-to-end polylog-time
indexed-read-only-input accessor. The fixed sorting network proposed
there \emph{encodes} data-dependent swaps as Boolean verifier gates;
it does \emph{not execute a data-dependent sorting permutation}
during reduction. The latter would be nonlocal even for
two one-bit keys, whose minimum and maximum are AND and OR.

Our independent Python 3 implementation wrote and checked
complete \emph{actual} two-level ordinary CNF descendants.
For the two-clause SAT source, \(210\) variables and \(280\)
clauses at level one grow to \(19{,}320\) variables and \(25{,}760\)
clauses at level two; a source witness extends and satisfies every
literal in both actual files. For the all-eight-clauses UNSAT
source, \(408,544\) grow to \(37{,}536,50{,}048\).
The second UNSAT label is justified by the exact projection
theorem plus the exhaustively verified \(Q_{15}\) relation, not
by pretending to run brute force on \(2^{37536}\) assignments.
Other SAT controls include a seven-clause deletion neighbour,
a parity-style four-clause source and a Horn control.
All generated clause rows were checked for properness, uniqueness
and occurrence profiles.

Four fixed-incidence source sign choices, independently controlling
two signs, were \emph{actually} serialized through two levels.
At level two there were \(77{,}280\) checked sign slots, of which
\(77{,}272\) were constants and the other eight were literals
of one of the two source bits; no nonlocal coordinate appeared.
The first level had \(840\) slots, with exactly four dependent
sign slots. This is a finite test, not an asymptotic random-access
indexing implementation.

\section{Full decision circuits, instance traces, and charged frontier}
\begin{lemma}[Single-trace is not a full decision circuit]
Let \(A\) decide all source inputs of one encoded length \(N\).
Let \(C_{A,N}\) be a fixed circuit accepting an \(N\)-bit source
as input and computing \(A\) on \emph{every} length-\(N\) string.
A circuit obtained by specializing all input wires to a single
\(x\) computes the constant \(A(x)\). If there exists \(y\) of the
same length with \(A(y)\ne A(x)\), the specialized circuit
is \emph{not} \(C_{A,N}\).
\end{lemma}
The proof evaluates both inputs. In the checker, the full
fixed eight-slot source family with clause-presence mask
\(u\in\{0,1\}^8\) has SAT function
\(\neg\bigwedge_{i=1}^8u_i\): 255 masks SAT, one UNSAT.
The all-eight-clause UNSAT formula and the seven-clause
SAT formula with one duplicated clause are valid \emph{ordinary}
proper-three-literal CNFs of the \emph{same record count};
their labels are opposite. A constant gate trace can
represent only its own instance.

The hypothesis of the PDF is \emph{one fixed} deterministic exact
SAT machine \(A\) with \(T(N)\le N^{d+o(1)}\) and
\(S(N)\le N^{o(1)}\). A model-qualified multitape
TM-to-circuit compiler may yield
\(G_{A,N}\le N^{d+o(1)}\) gates, with \emph{all} source-input
wires symbolic. Pippenger--Fischer's theorem concerns
one-dimensional storage-tape machines and does not by itself
establish a near-linear simulator of an indexed read-only-input
RAM. The full symbolic circuit is different from the Cook
\emph{verifier circuit} with witness-input wires and different
from a source-\(x\) gate trace or boundary relation.

For a \emph{particular} materialize-then-compress construction that
first writes \(\Omega(N^{d-o(1)})\) gates or gate records,
the writing step alone takes \(\Omega(N^{d-o(1)})\)
charged bit operations (at least that many records); since
\[
d=\frac{901}{500}=1.802,\quad
C(d)=\frac{651000}{361301}
\simeq1.801821749732,\quad d-C(d)>0,
\]
that architecture cannot construct the desired smaller
full decision circuit within \(N^{C(d)-\epsilon}\) time.
A \emph{different} source-aware compiler that never writes the
original network is not excluded. Pure replacement of the
\(Q_{348}\) gadget by \(Q_{15}\) changes only constants:
it cannot contract exponent \(d\) to \(C(d)\).

\paragraph{Simultaneous resource ledger.}
For \(R_{15}\) on a fully materialized source with \(m,n\) and
\(M=44m+64n\) output clauses, generation, headers, sparse IDs,
source-variable lists, sorting if needed, all writes including
unchanged bits, the \(M\) clause positions, and identity reconstruction
are charged; the output has \(\Theta(M\log(M+2))\) bits under dense IDs.
A full eager builder has linear-or-larger writable space in
the output size. A \emph{virtual} accessor may use \(O(\log M)\)
workspace and polylogarithmic time per requested bit
\emph{only if} occurrence inverses and offsets are explicitly
locally computable. Adaptive repeated requests must be charged
every time. Our Python test measured rows and assigned
truth values, \emph{not} FLMV primitive bit operations,
peak index/work tapes, physical flips, or gate/wire electricity.
The full circuit output has at least one written record per
gate and two predecessor indexes per bounded-fan-in gate;
there is no right to set its writing cost to zero.

The other paper's \(q=1.29\) block/interface designs are
\emph{instance-specific} projected relations, not established
full all-input SAT decision circuits. A favorable
co-nondeterministic UNSAT certificate verifier still
requires universal UNSAT coverage and all verifier/child
costs, not a fast finder. A \(c<C(d)\) companion would
contradict the published two-algorithm resource theorem
under the additional seed, but no such companion was
constructed. In particular the stronger seed \(d=1.802\),
\(S=N^{o(1)}\) is \emph{not} implied by \(P=NP\).
