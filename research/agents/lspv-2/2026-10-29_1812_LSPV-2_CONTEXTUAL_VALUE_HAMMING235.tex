\section{Model, finite physical accounting, and SAT embedding}
Fix $b$ and a secret $a\in\F^b$. The canonical $A_a(X)$ consists of $b$ unary clauses $x_i=a_i$ in index order. There is no hidden source-assignment oracle: $a$ is encoded in the sign fields of the read-only source $A_a$, all acquired through charged reads. A later query supplies an arbitrary mask $w\in\F^b$ and target $t\in\F$, implemented by
\[
 B_{w,t}(X,Z)=[w\cdot X=t],\qquad
 F_{a,w,t}=A_a(X)\land B_{w,t}(X,Z).
\]
A two-input XOR $z=u\oplus v$ has four standard width-three clauses; chaining them and applying one terminal unit gives an existential 3CNF $B_{w,t}$ with $O(b)$ clauses, variables and encoding bits up to identifier width. For every $a,w,t$,
\begin{equation}\label{eq:sat}
 \operatorname{SAT}(F_{a,w,t})\iff w\cdot a=t.
\end{equation}
The resulting mixed 2CNF/3CNF construction is \emph{not} claimed strict exact-$(2,2)$ and has no asserted grammar closure. The ordinary fully encoded source size is $N=\Theta(b\log b)$ with fixed-width unary records; indices and sign-field positions are arithmetically recoverable. If the source is discarded, the model is the source-free online model; otherwise a continuation may issue raw sign-bit probes.

\noindent\textbf{Specific machine.} Preprocessing and query execution are deterministic \emph{indexed bit-RAM} routines with $O(\log N)$-bit addresses; a raw sign-field access is one cell probe and actual address arithmetic and source-bit traffic are separately charged in total bit operations. A fixed linear preprocessing operator $H\in\F^{L\times b}$ stores exactly $L$ bits $Ha$ with no free advice or uncounted access table. Any known fixed code generator is part of the uniform program, not a source-specific oracle. A query may adaptively examine coordinates $a_i$ of the read-only original source. It must return the parity $w\cdot a$ for every $a,w$. In the abstract bit-probe coordinate $Q$, reading a known sign bit counts one probe; \emph{total time} additionally includes parsing, address computation, code search, and output. Summary storage $L$ is counted writable memory; peak writable space, original read-only source footprint, query input and all physical intermediate records are reported separately. Single-tape access movement is not equated to RAM probes.

\section{An exact independent linear-summary distance theorem}
\begin{theorem}[exact source probes for a fixed linear summary]\label{th:distance}
Fix any matrix $H\in\F^{L\times b}$ and put $C=\mathrm{rowspace}(H)$. For every fixed query mask $w\in\F^b$, the least worst-case number of raw source-coordinate probes among deterministic, always-correct (even adaptive, nonlinear) query procedures that know $Ha$ is exactly
\[
 q_H(w)=d_H(w,C)=\min_{c\in C}\operatorname{wt}(w+c).
\]
Consequently the minimum worst-case number across all masks is the covering radius $Q_H=\max_w d_H(w,C)$. The statement places \emph{no} lower bound on the total running time of a general SAT solver.
\end{theorem}
\begin{proof}
For the upper bound, find $c=\lambda^\top H$ achieving minimum weight and probe precisely the coordinates $D=\operatorname{supp}(w+c)$. Then $w\cdot a=\lambda^\top(Ha)\oplus\bigoplus_{i\in D}a_i$ exactly. The search for $c$ is not free; direct enumeration takes $2^{\operatorname{rank}(H)}$ candidates, though the fixed seven-bit construction below uses only constant-size blocks.

For the lower bound, fix any deterministic adaptive decision-tree leaf on an actual source $a$ and a fixed query $w$, with probe-coordinate set $D$ and recorded source values. The consistent sources at this leaf are precisely the nonempty affine fiber of $H$ and those coordinate equalities: $a+\ker(H)\cap\bigcap_{i\in D}\ker(e_i^\top)$. If $w$ is not in the row span of $H$ together with $\{e_i:i\in D\}$, elementary linear duality produces $h\in\ker(H)$ with $h_i=0$ for $i\in D$ and $w\cdot h=1$. Then the two sources $a$ and $a+h$ yield the same stored $Ha$, the same probed answers and therefore the same adaptive transcript, yet their required outputs differ. Thus the protocol must have $w\in C+\mathrm{span}\{e_i:i\in D\}$ at every leaf, requiring $|D|\ge\min_{c\in C}\operatorname{wt}(w+c)$. Repeated probes cannot reduce this lower bound.
\end{proof}

\begin{lemma}[sphere covering constraint]
For any rank-$L$ linear summary of $b$ bits with worst probe budget $Q$, necessarily
\begin{equation}\label{eq:sphere}
2^L\sum_{j=0}^Q {b\choose j}\ge 2^b.
\end{equation}
This is a bound on the declared \emph{linear-summary bit-probe} architecture, not on all semantic preprocessing.
\end{lemma}
\begin{proof}
Every $w$ must lie in at least one radius-$Q$ Hamming ball around a codeword of the size-$2^L$ rowspace. The union of those balls covers $2^b$ query masks, while its cardinality is at most the left-hand side of \eqref{eq:sphere}.
\end{proof}

\section{No-source firewall and the general composition distinction}
\begin{proposition}[source-free exact parity continuation]
Any deterministic fixed-length source-free summary allowing exact response to every future parity query $w$ must store at least $b$ bits in the worst case. In contrast, for the already supplied \emph{single} full instance $F_{a,w,t}$, its SAT decision output is just one bit and can be computed directly by scanning $a$ and $w$ in polynomial time.
\end{proposition}
\begin{proof}
Singleton query vectors $e_i$ reveal each $a_i$, so distinct source vectors require distinct fixed-length summaries, giving $2^L\ge2^b$. This proves a reusable online representation requirement; it neither prevents a one-bit decision for a fixed pair nor constrains an algorithm allowed to see both $A$ and $B$ before preprocessing.
\end{proof}
A more general $F=A(X,Y)\wedge B(X,Z)$ requires comparing or joining boundary relations $f_A(x)=\exists y\,A(x,y)$ and $f_B(x)=\exists z\,B(x,z)$; the current $A_a$ has a singleton boundary profile and $B_{w,t}$ is affine. Their efficient structure cannot be imported to arbitrary CNF or connected strict22 without a reduction paying conversion, validation and profile discovery.

\section{Contextual $x\mid_v$ interpreter, acquisition, and nonadditivity}
The executable defines records $(\texttt{proposition},\texttt{source\_slot},\texttt{certificate},\texttt{provenance},\texttt{target},\texttt{score\_scale},\texttt{costs})$. A certificate consists of an authenticated exact equality with the corresponding source row; verification reads all charged source-record bytes and the index. The current epistemic state $K$ comprises only previously verified rows. Its task target $W$ is explicitly named. Let
\[
 \Omega_{K,W}=\{\pi_W(a):a\in\{0,1\}^{n},\ a\models K\},
 \qquad \Phi(K;W)=\log_2\max\{1,|\Omega_{K,W}|\}.
\]
For a newly certified source fact $I$, the contextual score is
\[
 v_\Phi(I\mid s,K,W)=\Phi(K;W)-\Phi(K\cup\{I\};W).
\]
Write the scored datum as $(I)\mid_{v}$; this bar denotes a contextual score, \emph{not} conditional probability. $\Phi$ is Hartley support ambiguity, not Shannon entropy and not an independently justified machine-runtime potential. The score computation enumerates all $2^n$ states in the small interpreter, and that enumeration is charged separately; it is \emph{not} a polynomial-time score oracle. If $K\cup\{I\}$ is inconsistent, the interpreter also records a separate contradiction flag rather than regarding a zero-support projection as a completed SAT certificate.

\noindent In the two-variable example $x,r$, the trusted source stores the two verified equations $I_1=(x\oplus r=1)$ and $I_2=(r=1)$. For target $x$,
\[
 v_\Phi(I_1\mid\varnothing)=0,\quad
 v_\Phi(I_2\mid\varnothing)=0,\quad
 v_\Phi(I_2\mid\{I_1\})=1,
 \quad v_\Phi(I_1\mid\{I_2\})=1.
\]
The joint gain is one bit despite zero singleton gains, proving nonadditivity by explicit XOR synergy. Repeating a previously known fact has value zero. Under the \emph{specified} net score $v_{\rm net}=v_\Phi-0.01(C_{\rm acquire}+C_{\rm apply})$, the one-bit high-value second fact has negative net score $-0.11$ because source authentication and application cost $111$ counted units. A separate work-obligation potential $\Phi_{\rm obligation}=\#\{\text{known unresolved verification obligations}\}$ can \emph{increase} by one upon adding a newly discovered unverified obligation, giving signed raw value $-1$; this is not a monotone solved-progress potential. No negative raw value is claimed for monotone, consistent projected-support refinement. The interpreter emits a separate source read, record-index, application, and score-computation ledger rather than treating discovery as free. Scores at different targets, states, and scales cannot be summed.
