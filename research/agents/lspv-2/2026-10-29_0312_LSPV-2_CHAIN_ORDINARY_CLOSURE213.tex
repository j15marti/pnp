\section{Independent audit of the supplied structural proof}
A connected proper 3CNF with exactly four signed occurrences per variable has $3m=4n$. If a source-authenticated global boundary $Y$ contains $b>0$ variables and every nonempty private module is disjoint from every other except at $Y$, connectedness forces each private module to touch a boundary clause. Each boundary name has four original occurrences, giving $k\le4b$. The union of $Y$ and per-module syntactic clause-hitting sets $B_i$ hits all original ternary clauses. Thus
\[
\frac{4n}{3}=m\le4\left(b+\sum_i|B_i|\right)\le4(b+4bq),
\quad b+q\ge\sqrt{n/3}-\frac14.
\]
At $b=0$, connectedness forces $k=1$ and $q\ge n/3$. Boundary-only source clauses are already hit by $Y$ and do not evade the count. If both $b$ and $q$ are $O(\log N)$ under canonical unpadded $N=\Theta(n\log n)$, this hypothesis cannot cover an unbounded family. The obstruction is solely to this \emph{fixed syntactic decomposition}. The local 3-way hitting-set branching search costs $O(3^q\operatorname{poly}(N))$ after the \emph{global partition is supplied}; no free separator discovery is assumed. The polynomially bounded adaptive-rank proposition in the source is valid only for a rank with polynomial \emph{numeric value}, per-step charged costs, and polynomial complete-state size.

\section{BUILD: 16-state exact summaries and a fully counted 3CNF child}
Fix $n=3r\ge3$. The authenticated source class consists of canonical proper strict signed exact-$(2,2)$-3CNF with the cyclic clauses $C_i$ on $(x_i,x_{i+1},x_{i+2})$ and block clauses $Q_j$ on $(x_{3j},x_{3j+1},x_{3j+2})$, clauses and literal order fixed and all signed occurrences checked. It is not the class of all ordinary SAT formulas. The more permissive internal signed bitstream is tested separately but is not an admitted original-3CNF source of the claimed strict subclass.

Choose the initial values $u=x_0,v=x_1$ and represent a moving state by
\[
 s=(u,v,a,b)\in\{0,1\}^4, \qquad a=x_{j-2},\ b=x_{j-1}
\]
prior to introducing $c=x_j$ for $2\le j<n$. The 16-state relation $R_j$ has precisely the transitions
\[
 (u,v,a,b)\longrightarrow(u,v,b,c),\quad c\in\{0,1\},
\]
that satisfy $C_{j-2}(a,b,c)$ and also $Q_{(j-2)/3}(a,b,c)$ when $j-2\equiv0\pmod3$. The initial-state mask $I$ contains exactly the four tuples $(u,v,u,v)$; the terminal mask $F$ requires the two wrapped source clauses $C_{n-2}(a,b,u)$ and $C_{n-1}(b,u,v)$. Every original source clause is tested exactly once. The formula is satisfiable iff some path from $I$ to $F$ crosses $R_2,\ldots,R_{n-1}$. This equivalence holds for \emph{all signs}, and thus for the exact balanced subfamily.

A general canonical relation-chain state consists of two 16-bit masks $I,F$ and $m\ge1$ matrices $R_1,\ldots,R_m\in\{0,1\}^{16\times16}$. It is accepted iff
\[
 I\,R_1\,R_2\cdots R_m\,F\ne0
\]
with Boolean relational composition. Let $k=\max(1,\lfloor m^{1/4}\rfloor)$ and $L=\lceil m/k\rceil$. Partition the $m$ matrices into blocks of length at most $L$ and replace each by the Boolean product of its members. The successor has at most $k$ matrices. At most 256 membership tests and 256 16-bit ORs are charged per multiplication, not an unaccounted oracle. The interface size stays exactly four bits regardless of how many blocks are combined.

\begin{lemma}[Actual ordinary proper-3CNF encoding]
For $m$ matrices there is a canonical equisatisfiable proper 3CNF with at most $1284m+36$ variables and $1536m+64$ clauses, plus a self-authenticating comment carrying the full explicit matrices. The comment is counted in the physical length. The encoding and its recognition both run in polynomial time and never solve SAT.
\end{lemma}
\begin{proof}
Allocate four Boolean state bits at each of the $m+1$ endpoints. For every disallowed source/target pair of four-bit states, emit the eight-literal clause forbidding exactly that pair; there are at most $256m$ such pairs. For each disallowed state of the initial and final masks, emit a four-literal forbidding clause; there are at most 32. Translate each width-$8$ clause to six ternary clauses using five fresh auxiliary variables, and each width-$4$ clause to two ternary clauses using one auxiliary. The standard implication-chain translation is existentially equivalent to its original broad clause for every assignment of the original bits. The formulas are proper, since every new auxiliary is fresh and the original endpoint bits are distinct. Counts are $4(m+1)+5(256m)+32=1284m+36$ variables and $6(256m)+2(32)=1536m+64$ ternary clauses. Include an explicit hexadecimal 64-character encoding per 16-row matrix and initial/final masks in a DIMACS comment; parse that metadata and \emph{regenerate and byte-compare the entire following DIMACS CNF}. This prevents free, unchecked non-semantic side information. The metadata contains only $O(m)$ physical characters and is entirely charged.
\end{proof}

\begin{theorem}[Closed power-short ordinary-3CNF child on the restricted grammar]
Let $\mathcal C$ be the union of the canonical strict balanced cyclic clause lists above and the canonical matrix-chain 3CNFs just defined, with syntactic parsing and exact regeneration required. This is a self-contained, polynomially recognizable class of \emph{ordinary three-literal SAT formulas} (with optional authenticated DIMACS comments). There exist a fixed threshold $N_0$, a fixed $\lambda=3/4$, and one deterministic polynomial-time map $G$ such that for every $x\in\mathcal C$ of physical length $N\ge N_0$, the single child $G(x)\in\mathcal C$ is equisatisfiable with $x$ and has physical length at most $N^\lambda$. Directly solvable bounded bases terminate the recursion. No SAT-answer oracle or free static table is used.
\end{theorem}
\begin{proof}
Parse and authenticate the input. If it is cyclic, construct its $n-2$ transition matrices and masks; if it is a canonical chain, read its explicit matrices and regenerate the source 3CNF to verify its exact syntax. Partition and compose matrices as above, then emit \emph{one} canonical proper-3CNF child with all auxiliaries and metadata. Boolean relational associativity proves that a path from $I$ to $F$ exists before iff it exists after, regardless of SAT/UNSAT answer. The child belongs to the same canonical matrix-chain subgrammar, so repeated closure follows.

For either parent type, denote its scope/matrix parameter by $h$, equal to $n$ or $m$. The physical parent length $N=\Omega(h)$, because canonical cyclic formulas explicitly contain all $4n/3$ source clauses and canonical chain comments contain 64 characters per matrix. The successor has $k\le h^{1/4}$ matrices, at most $O(k)$ ternary clauses/auxiliaries, and maximum numeric literal width $O(\log(k+2))$. Therefore the \emph{fully formatted} successor is $O(h^{1/4}\log(h+2))=O(N^{1/4}\log(N+2))$ physical bits. For all sufficiently large $N$, this is at most $N^{3/4}$. All smaller valid inputs have bounded physical length and are solved directly by the explicit exact relation checker. Full input parsing, unsuccessful source-format checks, matrix composition, metadata regeneration, clause construction, number writing, and output storage cost a polynomial in $N$. The unique recursive chain terminates in $O(\log\log N)$ levels. This theorem is a \emph{restricted control}; the grammar does not contain unrestricted SAT, so it does not satisfy the user's NP-complete-class hypothesis.
\end{proof}

At $n=30$, the 132-bit compact cyclic sign grammar yields a 550-bit matrix-chain grammar, but \emph{full ordinary 3CNF re-entry uses 274,960 bits} before adding its self-authenticating metadata, 2,068 variables, 2,480 ternary clauses and 2,056 auxiliaries. This directly falsifies any finite-size claim that circuit/BDD compactness automatically gives a smaller ordinary 3CNF. The earlier project's four-end guard compiler is substantially more practical; the current alternative is a correctness and closure control, not an efficiency improvement at small sizes.

\paragraph{Separate resource ledgers.} In an indexed RAM model, 16-bit matrix operations are constant-word operations; source parsing and regeneration, numeric addresses, failed syntax tests, full output bits, and all stored intermediate matrix tables are charged. The simple standalone Python holds $O(N+N')$ bits and takes polynomial RAM work, without claiming its operation count equals a TM transition count. On a fixed read-only-input plus writable-work two-tape TM, a conservative implementation stores the source encoding and one child on the work tape, uses $S_2=O(N+N')=O(N)$ work cells, and can perform each source lookup by charged sequential scans, with $T_2=O(N^c)$ for a fixed finite $c$ (for instance a coarse quadratic/cubic upper bound under explicit alphabet coding). Output writes and head moves are included. For a deterministic \emph{one-tape read/write} simulator, the original input is included in total visited footprint, and conservative sweep simulation charges $T_1=O(T_2(N+S_2+\log(T_2+2)))$ and $P_1=O(N+S_2+\log(T_2+2))$, including virtual output. A fixed efficiently universal interpreter can simulate this fixed algorithm with an explicitly polynomial overhead; no universal-machine or Hennie--Stearns exponent is transferred into a native SAT lower bound. There are at most $1536m'+64$ output Boolean ternary clauses, exactly three literal references per such clause, and separately $O(m)$ constant-width relation-composition operations; these are \emph{different} accounting units, never added as if all were gates or all were time steps. Both SAT and UNSAT restrictions are of the same fixed program; no answer-class indicator is supplied.

\paragraph{Computational audit.} The original archive's raw output reproduced byte-identically. The new standalone code passed 140 brute-force cycle-sign comparisons (70 strict balanced), 64 arbitrary matrix-chain SAT/UNSAT controls with single-child and repeated-closure checks, 14 full canonical ordinary-3CNF re-entry/closure controls, 70 exact22 source-DIMACS parses, 280 malformed-format rejections, and 272 exhaustive truth assignments of the width-four/eight auxiliary gadget.
