\section{Exact source identity, compatible pairs, and optimized enumeration}
Fix one \emph{valid closed source-named scoped stream} consisting of OPEN(v), CLAUSE(three signed distinct currently live sources), CLOSE(v). Every source name opens once, closes once, and all its clause occurrences fall between. Let \(L\) be the event count, \(S_i\) the live named set after event \(i\), \(w_i=|S_i|\), \(w_0=w_L=0\), and \(W=\max_i w_i\). The true SAT label is not provided to the solver. Assume a legal partition edge \((i,j)\) of event length at most \(b\), with minimum nonfinal length \(d=\max\{1,\lfloor b/2\rfloor\}\).

\begin{theorem}[Exact compatible entry/exit assignment count; PROVED/EXACT]
The number of pairs \((\alpha:S_i\to\{0,1\},\gamma:S_j\to\{0,1\})\) that agree on every original source variable in \(S_i\cap S_j\) is precisely
\[
 \boxed{Q(i,j)=2^{|S_i\cup S_j|}
 =2^{w_i+w_j-|S_i\cap S_j|}.}
\]
Consequently, an \emph{eager policy that tests every source-consistent pair} has the exact candidate-count objective
\[
 \boxed{\widehat C(P)=\sum_{(i,j)\in P}Q(i,j).}
\]
This is not a lower bound for an arbitrary SAT decider, nor even for a reachability-filtered or memoized named-pinning solver.
\end{theorem}
\begin{proof}
An assignment on \(S_i\cup S_j\) restricts to a unique compatible pair. Conversely, two assignments agreeing on the intersection glue to a unique assignment on the union. The two maps are inverse. A candidate using opposite values for the same persistent source can be rejected without constructing a child. A global satisfying assignment still requires the source-named compatibility across \emph{all} successive cuts, as independently established by SCOPED-BLOCK-REBUILDER92.
\end{proof}
The older quantity \(C_{\times}(P)=\sum2^{w_i+w_j}\) is a valid \emph{upper proxy}, but may overcount by \(2^{|S_i\cap S_j|}\) on an individual edge. This corrects the metric used in OPTIMAL-WINDOW-CUT126 and LINEAR-SPACE-CUT-REPLAY127 when the intent is to count actual consistent pin candidates. It does not invalidate those papers' exact optimization theorems for their expressly declared \(C_{\times}\) proxy.

\begin{theorem}[Identity-aware optimal schedule; PROVED/EXACT, restricted]
For a fully validated named source, the minimum \(\widehat C\) over legal partitions is obtained exactly by
\[
 D_0=0,\qquad
 D_j=\min_{\substack{\max(0,j-b)\le i<j\\ j=L\ {\rm or}\ j-i\ge d}}
 \left[D_i+2^{|S_i\cup S_j|}\right].
 \tag{1}
\]
Storing the actual cut sets and a predecessor table gives an \(O(LbW)\)-word-operation upper bound and \(O(L(W+1))\) live word entries, after source validation, with comparison/arithmetic costs on integers of \(O(W+\log L)\) bits. A conservative bit work bound is \(O(N\operatorname{polylog}N+Lb(W\log N+\log L))\), with \(O(L(W+1)\log N)\) writable bits, including all stored named sets and predecessor/cost arrays. Costs of generating/querying children are separate.
\end{theorem}
\begin{proof}
An optimal path to \(j\) ends in one eligible predecessor \(i\), and its earlier path must itself minimize the additive objective. This establishes (1) by induction. Full source validation pays header/field decoding and global name freshness. Store \(S_i\) as sorted source-ID lists, each of length at most \(W\). A sorted merge computes \(|S_i\cup S_j|\) in \(O(W)\) word comparisons. There are \(O(Lb)\) candidate edges; the integer maximum is at most \(L2^{2W}\). Source-name comparisons use \(O(\log N)\)-bit identifiers and costs use \(O(W+\log L)\) bits. The listed conservative time and live-memory accounting follows. Outputting an actual schedule requires paid predecessor storage. This algorithm is not claimed to have the earlier \(O(b+W)\) writable-space guarantee.
\end{proof}
\paragraph{Why the width-only fast algorithm cannot simply be inherited.}
Two predecessors with equal cardinality can have different intersection with a fixed successor. The exact edge cost depends on \emph{which} original names survive. A queue retaining only the cheapest predecessor for each width can discard a more expensive predecessor with a much cheaper compatibility-aware edge. The original certified stream enforces interval persistence, so a supposed proof must respect monotone survivor sets; merely using two arbitrary set snapshots is not enough. Equation (1) avoids this issue. The possibility of a faster source-aware specialized minimizer is OPEN.

\section{Explicit both-label exponential overcount construction}
For every integer \(h\ge3\), create \(h\) OPEN events for persistent sources \(x_1,\ldots,x_h\), then \(10h\) proper ternary CLAUSE events, and finally \(h\) CLOSE events. The first eight clauses are the eight signings of \(x_1\vee x_2\vee x_3\). This is UNSAT. The matched SAT version replaces the all-negative clause with a duplicate all-positive clause; setting every original source TRUE satisfies its clauses. Insert one positive clause \((x_1\vee x_2\vee x_v)\) for each \(v\ge4\), and fill the remaining slots with \((x_1\vee x_2\vee x_3)\). Both labels use the same source names, unsigned ordered clause supports and event widths. Ordinary proper CNF permits duplicate clauses.

Take \(L=12h\), block limit \(b=4h\), minimum nonfinal block length \(d=2h\). A partition needs at least three edges. Exactly three edges forces cuts \((0,4h,8h,12h)\). Both internal cut sets equal all \(h\) persistent sources. A partition with four or more edges has its first two cuts inside the all-live middle, and necessarily adds another positive-cost edge, so cannot improve either three-edge objective. Hence
\[
 \boxed{\min C_{\times}=2^{2h}+2^{h+1},\qquad
 \min\widehat C=3\cdot 2^h.}
\]
The ratio is \((2^h+2)/3\), exponentially large in \(h\). Because \(N=\Theta(h\log h)\), this family has \(W=\Theta(N/\log N)\); it is \emph{outside} the sublogarithmic-width promise used for ARC restricted contraction. On a promised \(W=o(\log N)\) family, overlap improvements are at most \(2^W=N^{o(1)}\) per edge and cannot alone improve an exponent. The result improves a truthful enumeration ledger, not an all-input achievable pair.
