\section{BUILD I: a connected properization that does not inspect SAT}
Let $F$ be any canonical signed ordinary $3$CNF on the \emph{active}, densely numbered source variables $x_1,\ldots,x_n$ with $m$ clauses of width $0$--$3$ (empty formula permitted only for $n=0$). Repeated literals and complementary tautologies are normalized; duplicate clauses removed. Empty clauses are represented by all eight polarity patterns on three fresh variables; a unit $(\ell)$ by the four clauses $(\ell\vee\pm a\vee\pm b)$; a binary $(\ell_1\vee\ell_2)$ by $(\ell_1\vee\ell_2\vee a)\wedge(\ell_1\vee\ell_2\vee\neg a)$; proper ternary clauses are left alone. If the source has no variables and no surviving clause, introduce one satisfiable fresh ternary clause. Each step preserves the full source-variable truth relation under existential quantification of fresh variables. Call the result $P(F)$.

Discover the connected components of the unsigned variable--clause incidence graph of $P(F)$, including isolated source variables. If there is more than one component, choose one variable $z_i$ in each component. Introduce a shared fresh hub $h$ and fresh $s_i,t_i,w_i$ for each component, and add
\[
 (z_i\vee s_i\vee t_i)\ \land\ (s_i\vee h\vee w_i).
\tag{1}
\]
Setting $s_i=1$ always satisfies both clauses, independently of all old variables. Every previously disconnected component is now joined through $h$. The clauses remain proper and distinct and do not introduce new restrictions on old assignments. If the graph was connected, add nothing. Denote the result $H(F)$.

\begin{lemma}[Neutral connectedness and exact projection]\label{lem:hub}
$H(F)$ is a connected proper distinct-clause 3CNF, uniformly constructible from $F$, with
\[
 \forall \xi\in\{0,1\}^{n}:\quad
 \exists u\ H(F)(\xi,u)\ \iff\ F(\xi).
\]
If $m\ge1$, the number $M$ of $H(F)$ clauses satisfies $M\le14m+2n+7$, hence $M\le20m+7$ for the canonical active source with $n\le3m$.
\end{lemma}
\begin{proof}
All four clause-width transformations are standard Boolean identities by quantifying their fresh variables. For the new hub clauses, assigning each $s_i=1$ makes them true, so the projection is identically true over all preexisting variables. The component graph becomes connected via the shared $h$, whose new incident clauses also contain each anchor's $s_i$. Distinctness follows from fresh auxiliary IDs. The first transformation emits at most $8m+1$ clauses and introduces at most $3m+3$ fresh variables; there are at most $n+3m+3$ variable-containing components, and at most two new clauses per component. The displayed loose bound follows. The $n\le3m$ statement uses dense active source IDs, not an uncharged enormous unused-DIMACS header.\end{proof}

\section{BUILD II: exact balanced-degree compiler with named input ports}
Use the \emph{previously established} seven-clause pad
\begin{align*}
J(\ell)={}&(\ell\vee\neg a\vee\neg b)
\land(a\vee c\vee\neg d)\land(a\vee d\vee\neg e)
\land(b\vee e\vee\neg c)\\
&\land(b\vee\neg d\vee\neg e)
\land(\neg a\vee c\vee d)\land(\neg b\vee\neg c\vee e).
\end{align*}
The new auxiliary $a,b,c,d,e$ each have signed occurrence counts $(2,2)$ and setting all five to zero satisfies $J(\ell)$ regardless of the input literal. For each variable $z$ of $H(F)$ with positive/negative counts $p_z,q_z$, put $r_z=\max\{p_z,q_z,2\}$ and insert $r_z-p_z$ copies of $J(z)$ and $r_z-q_z$ copies of $J(\neg z)$. Denote the balanced formula $B(F)$; $g=\sum_z(2r_z-p_z-q_z)$ counts inserted pads, and its clause count is $M+7g$.

Split each balanced variable $z$ into $r_z$ clones $z_1,\ldots,z_{r_z}$, pairing its $j$th positive and negative occurrence to the same clone, and insert the directed implications $\neg z_j\vee z_{j+1}$ cyclically. Each clone now has exactly one occurrence of each sign in the source and one of each sign in its two cycle links. Partition the $R=\sum_z r_z=\tfrac32(M+7g)$ implication clauses into triples, and pad the triple with the three missing positive literals $1,7,13$ of an independent $15$-variable, $19$-clause copy of
\[
 Q=W_1\setminus\{1\vee7\vee13\}.
\]
The preceding project compiler uses a fixed 15-variable $W_1$ that is UNSAT, while $Q$ has a zero-valued satisfying assignment. Consequently $Q$ forces its three missing positive ports all false. The present independent enumeration checks all $2^{15}$ assignments: $Q$ has exactly 244 models, all with the three ports $000$. Every new padded implication is therefore logically equivalent to the intended directed implication. The clone cycle forces all copies of $z$ to agree.

Finally, for each original source variable $x_i$, choose its first clone and deterministically rename that clone back to the physical ID $i$. Rename the remaining target variables densely using IDs $n+1,n+2,\ldots$. Original names $x_1,\ldots,x_n$ are therefore \emph{actual free output variable names}, not externally supplied lookup-table labels.

\begin{theorem}[Connected all-port exact signed $(2,2)$ lift]\label{thm:allport}
For every canonical source $F$ in the declared grammar, a fixed deterministic polynomial-time compiler $C$ outputs a \emph{connected, proper, distinct-clause, strictly signed exact-$(2,2)$} $3$CNF. The original $n$ source variables are distinct physical output variables with the same names, and
\[
 \boxed{\forall\xi\in\{0,1\}^{n}:\quad
 F(\xi)\iff\exists Z\ C(F)(\xi,Z).}
\]
The final target contains exactly $v=9(M+7g)$ variables and $c=12(M+7g)$ clauses, and satisfies
\[
 v\le576M,\qquad c\le768M,\qquad
 M\le20m+7\quad(m\ge1).
\]
All parsing, component discovery, signed balancing, cycle indexing, Q gadgets, and renaming are charged; there is no SAT-solver or oracle call in the compiler.
\end{theorem}
\begin{proof}
Lemma~\ref{lem:hub} establishes the first projection and connected proper source. Each $J$ pad is always extendable for any old assignment, giving the second projection. After cloning, the $Q$ ports force every cycle implication. Their conjunction makes all clones of each balanced variable equal; conversely a constant assignment along each clone cycle satisfies the implications, and zeroing all $Q$ auxiliaries satisfies their internal clauses. Hence the final existential projection is the balanced formula. Renaming a single representative of each original variable fixes its physical value to the desired source assignment; the other clones remain quantified but are forced to agree. The three projection identities compose, proving the boxed equality on SAT and UNSAT source assignments under one uniform algorithm.

For every clone, the two source and two implication occurrences give one pair of each sign; the 15-variable $Q$ has three positive deficits completed by the padded implications, with all remaining occurrence quotas already balanced. No clause repeats a variable and no two clauses coincide, by fresh gadgets and distinct clone occurrences. Connectivity follows from $H(F)$: its variable cycles join every occurrence in the same original variable group; every old clause is attached to its three corresponding cycles, and the connected incidence graph of $H(F)$ is thus preserved. Each $J$ and $Q$ gadget intersects that connected graph through its own literal-bearing clauses. Thus the output is connected even when $F$ was not.

Counting $R=\frac32(M+7g)$ gives $v=6R=9(M+7g)$ and $c=8R=12(M+7g)$. For each active balanced-source variable of total degree $d\ge1$, $2\max(p,q,2)-d\le3d$; summing gives $g\le9M$, since the source has $3M$ literal occurrences. The output bounds follow.\end{proof}

\paragraph{Composing the independent two-swap guard.} On a selected original $x_i$ in $C(F)$, use the authenticated fixed positive/negative occurrence exchanges of TWO-SWAP-EXACT-PORT-TRANSPORT223. The result contains an additional new physical port $p$ and satisfies
\[
 \exists Z'\ T(C(F),x_i,p)(\xi,p,Z')\iff
 F(\xi)\land(p\leftrightarrow\xi_i).
\]
This is valid for \emph{both} answer classes, and remains connected proper strict exact22. Each guard adds 15 variables and 20 clauses rather than eliminating any source information. The required fixed guard's four puncture signatures were independently reenumerated in this run: multiplicities $85,153,85,119$.

\section{BUILD III: unavoidable all-port output-length floor}
\begin{theorem}[Physical named-port obstruction]\label{thm:floor}
Suppose an output is strict signed exact-$(2,2)$ 3CNF with at least $n$ distinguished \emph{distinct physical variable names} retained as freely assignable ports. In ordinary ASCII DIMACS, its encoded length obeys
\[
 \boxed{N_{\rm out}\ge 32\sum_{j=1}^{n}\bigl(1+\lfloor\log_{10} j\rfloor\bigr)
 =\Omega(n\log n)\text{ bits}.}
\]
On any bounded-occurrence canonical source family with $n$ active variables and $N_{\rm in}=\Theta(n\log n)$, no output of this type can satisfy $N_{\rm out}\le N_{\rm in}^{\lambda}$ eventually for a fixed $0<\lambda<1$.
\end{theorem}
\begin{proof}
Each of the $n$ distinct named ports occurs exactly four times. The total number of ASCII decimal-digit bytes devoted to their four occurrences is minimized by taking the $n$ smallest distinct positive integer names $1,\ldots,n$. Each name $j$ requires $1+\lfloor\log_{10}j\rfloor$ decimal digit bytes in each occurrence, regardless of sign; multiplying by four occurrences and eight bits per byte gives the exact displayed bound. Clause framing, signs, headers, and all other variables only add bits. The sum is $\Theta(n\log n)$. For the explicit connected signed exact22 affine source $R_p$ with $n=3p$, $m=4p$ and odd $p\ge5$, canonical unpadded input size is $\Theta(n\log n)$, so the output floor is $\Omega(N_{\rm in})>N_{\rm in}^{\lambda}$ for all sufficiently large $p$.\end{proof}

\paragraph{Interpretation.} This lower bound concerns \emph{a fully port-preserving output architecture}, not the time complexity of SAT. A semantic compiler seeking $N^\lambda$ contraction must forget/quantify most source ports or encode their effect in a smaller, genuinely correct representation. Proving that such a representation can be found polynomially for arbitrary SAT remains open. If a DIMACS header advertises exponentially many unused variables in a short input, retaining each one as a separate output port is itself non-polynomial; our canonical source grammar rejects such malformed-for-this-purpose headers before allocating storage.

A fixed universal machine simulates the fixed constructor with polynomial overhead, but no asserted exact exponent without its instruction compiler. These are \emph{upper bounds for transformation}, not time-space lower bounds for SAT, and each same-run ledger is kept separate.
