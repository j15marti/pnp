\section{BUILD I: one strict signed exact22 source with realized static geometry}
Fix integers $a\ge1$, $h\ge2$ and $n=3ah\ge6$. Identify source variables $x_i$ with $i\in\mathbb Z_n$ and define
\begin{equation}\label{eq:source}
F_{a,h}=\bigwedge_{i=0}^{n-1}(x_i\vee x_{i+1}\vee\neg x_{i+2})\ \wedge\
\bigwedge_{j=0}^{n/3-1}(\neg x_{3j}\vee\neg x_{3j+1}\vee\neg x_{3j+2}),
\end{equation}
where all variable subscripts are modulo $n$ and the signs are literal signs.
\begin{theorem}[Exact realizable static modular curve]\label{thm:static}
$F_{a,h}$ is incidence-connected, proper, distinct-clause, signed exact-$(2,2)$-3CNF with $n=3ah$ variables and $m=4ah$ clauses. With private boundary
\[
 Y=\bigcup_{j=0}^{h-1}\{x_{3aj},x_{3aj+1}\},\quad
 Z_j=\{x_{3aj+2},\ldots,x_{3a(j+1)-1}\},
\]
we have $k=h$ disjoint nonempty private modules, $b=|Y|=2h$, no clause meeting private variables in two modules, and exact minimum private syntactic clause-hitting parameter $q=a-1$, under the convention that a clause touching $Y$ is already hit. In particular
\begin{equation}\label{eq:realizable}
 n=3ah=\tfrac32b(q+1),\qquad b=2h,\qquad q=a-1. 
\end{equation}
The original formula is satisfiable by the all-zero assignment.
\end{theorem}
\begin{proof}
Every $x_i$ appears positively in cyclic clauses $C_i,C_{i-1}$ and negatively in $C_{i-2}$ and exactly one negative block clause $D_{\lfloor i/3\rfloor}$; every clause has three distinct variable names since $n\ge6$. The cyclic triples overlap consecutively, hence the incidence graph is connected. The two clause types cannot coincide as signed clauses, and within each type the supports are distinct. Each $Z_j$ is a consecutive interval bordered by two source-boundary variables at both ends; a width-three consecutive scope cannot meet two different $Z_j$, since the intervening boundary interval has length two. Within $Z_j$, $a-1$ internal disjoint negative triple clauses
$D_{aj+1},\ldots,D_{a(j+1)-1}$ require at least one private hit each. Selecting $x_{3aj+3},x_{3aj+6},\ldots,x_{3aj+3(a-1)}$ hits these and all cyclic triples not already touching $Y$, since any three consecutive internal names meet a selected position divisible by three. Thus $q=a-1$ is exact. In the $a=1$ case there are no private-only clauses and $q=0$. The all-zero assignment satisfies every clause because each cyclic clause has a negative literal and each block clause is fully negative.
\end{proof}
\begin{lemma}[Small actual treewidth]\label{lem:tw}
For $n\ge6$ the primal graph of $F_{a,h}$ is the square $C_n^2$ of the $n$-cycle and has treewidth exactly four.
\end{lemma}
\begin{proof}
Consecutive cyclic triples create exactly all edges of cyclic distance at most two; every block clause is already such a triple. The graph has minimum degree four, so its treewidth is at least four by $k$-degeneracy of any graph of treewidth at most $k$. An explicit path decomposition consists of the bags $\{x_0,x_1,x_{i-1},x_i,x_{i+1}\}$, $i=2,\ldots,n-2$, with the obvious duplicate omissions at the ends. Every cyclic-distance-one or -two edge is covered; $x_0,x_1$ stay in all bags and every other vertex occurs in consecutive bags. The maximum bag size is five, so width at most four.
\end{proof}

\begin{theorem}[Authenticated transfer solver; restricted class]\label{thm:transfer}
For every input with the exact cyclic-block \emph{unsigned scope multiset} of~\eqref{eq:source}, under arbitrary literal signs (including all valid strict exact22 signings), SAT is decided by an explicit uniform deterministic Boolean $4\times4$ transfer algorithm. Its output equals the Boolean trace of $\prod_{j=0}^{n/3-1} M_j$. After checking the signed quotas, scope multiplicities, literal distinctness and source uniqueness, a materialized indexed word-RAM implementation has $O(N\,\operatorname{polylog}N)$ charged bit time and $O(N\,\operatorname{polylog}N)$ writable bits. A repeated-read fixed-$k$ multitape implementation has $O(nN\,\operatorname{polylog}N)$ charged time and $O(\log N)$ writable bits, keeping input read-only. Both charge full source parsing and method selection; neither uses a supplied SAT/UNSAT answer bit.
\end{theorem}
\begin{proof}
For arbitrary local signs, enumerate the 16 choices of left and right pair and existentially quantify the middle bit, testing all four local source clauses, to produce each $M_j$ in constant state. Every input variable is either exactly one block's middle variable or belongs to two adjacent endpoint pairs. The cyclic equality of adjoining pairs enforces shared values across the whole source. The Boolean matrix product therefore sums existential assignments to all internal and endpoint names, and its Boolean trace enforces the final wraparound pair equality. This establishes exact soundness and completeness for SAT and UNSAT. Scope multiplicities are checked either with a materialized occurrence dictionary, or by sequentially rescanning each block's expected scopes and each source variable's positive/negative quotas; an additional nested source scan compares each clause to earlier clauses to reject signed duplicates. The streaming program retains only a constant number of clauses, one 4-row accumulator, three counters/indices and source-head positions, using $O(\log N)$ writable bits. Its $O(n)$ scans cost $O(nN)$ read-only input-head steps and at most $O(nN\,\operatorname{polylog}N)$ charged bit operations; there is no hidden matrix list, occurrence array, witness search, or free source index. Materialized parsing and source validation cost $O(N\,\operatorname{polylog}N)$ bit operations on a word-indexed RAM for the canonical grammar; the program gives a direct $O(N\,\operatorname{polylog}N)$-bit representation. A sequential multitape implementation is polynomial but is not assigned the RAM linear exponent without a separate sorting/indexing simulation. Conversion to arbitrary encodings or literal ordering requires separately charged parsing and permutation discovery, not assumed by this theorem.
\end{proof}
\noindent\textbf{Interpretation.} At fixed $h$, $q=a-1$ grows linearly with $n$, and static enumeration's count is $2^{\Theta(n)}$, while an \emph{actual correct solver} performs polynomial work. The same module's exact message uses just 16 bits of relation content.
