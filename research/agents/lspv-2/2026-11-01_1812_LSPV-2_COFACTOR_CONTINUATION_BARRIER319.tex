\section{Language and obstruction}
Valid originals only are duplicate-free proper monotone 3-SAT-(2,2), exactly two positive and negative occurrences per variable, malformed strings rejected. Residual pinned formulas may be noncanonical. For a source original F, coherent pin p excluding x, and complete assignments z to every other unpinned original, define
\[
I(F,p,x)\Longleftrightarrow\forall z\;\;F(p,z,x=0)=F(p,z,x=1).
\]
This is all-future-pin \emph{decision continuation} equivalence: a complete future pin context distinguishes the cofactors exactly when their Boolean functions differ. It is not the same as equality of current existential SAT labels, and it does not demand storing witnesses, variable assignments or injective pin keys.
\begin{theorem}[Exact canonical-language acquisition barrier]
The language CONT-INDEP22 of valid canonical pairs (F,x) for which I(F,empty,x) holds, rejecting malformed strings, is coNP-complete. This is a specialization of classical formula-variable independence and does not establish any unconditional superpolynomial lower bound.
\end{theorem}
\begin{proof}
Non-independence has an NP certificate: a complete z for which both original-source cofactor evaluations disagree. Malformed inputs are recognized in polynomial time. CoNP hardness follows from canonical UNSAT using the explicit disjoint gadget Y6, with positive source triples (123),(145),(246),(356) and negative triples (-1,-2,-4),(-1,-3,-6),(-2,-3,-5),(-4,-5,-6). It is valid 2P2N with unique proper monotone clauses. Fix (y2,y3,y4,y5,y6)=(0,0,0,0,1): Y6 is false for y1=0, true for y1=1. Given any valid original F, form H=F disjoint-union Y6, renaming Y6 variables beyond those of F. H preserves the entire target grammar and has O(N) explicit binary length, including any index-width jump. If F is UNSAT, H is identically false and I(H,empty,y1) holds. If F is SAT, combine one F solution with that fixed pivotal Y6 context to refute independence. Malformed source strings map to the fixed canonical no-instance (Y6,y1). Thus I(H,empty,y1) iff UNSAT(F). \end{proof}
\noindent\textbf{Scope firewall.} This coNP-completeness is for \emph{universal continuation-semantic acquisition}, not for directly deciding F; a correct general decider may entirely avoid the equivalence test. A constant answer bit and exponentially many syntactic states are neither upper nor lower bounds on general decision work.
\section{UP-entailment certified source guard}
Let H_x consist of original clauses not incident on x; every one of x's four original clauses C_j has an x-free two-literal remainder R_j. Use the coherent pins p throughout.
\begin{lemma}[Proof-carrying continuation-safe guard]
If for each of the four source clauses either R_j is already true under p, or a checked source-indexed unit-propagation derivation refutes H_x and the assumptions falsifying R_j, then I(F,p,x) holds. A failed trial returns UNRESOLVED, not a claim of dependence.
\end{lemma}
\begin{proof}
Each checked UP refutation proves H_x entails R_j. Hence all four x-incident source clauses are true under every H_x completion, for either x value, and every other clause is exactly H_x. The two full original-source cofactors are pointwise identical. The proof DAG stores initial assumptions, original source IDs and forced literals, and a terminal falsified original clause. If H_x is inconsistent the certificate is valid but makes no SAT-witness claim. \end{proof}
The guard makes one paid original grammar/index prepass, then examines four incident source records, 12 signed occurrences and at most eight other-pin fields plus up to four failed-assumption UP attempts.
