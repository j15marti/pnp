\section{Single target, quantifiers, and preregistered attacks}
The sole science target is an assumption-dependent, all-ordinary-input,
fully charged finite favorable route into the strict FLMV forbidden region.
For $(t,s)\in E$, one fixed, uniform, total, correct ordinary-SAT decider
$A$ must work on every encoded ordinary input of $N$ bits with simultaneous
$T_A(N)\le N^{t+o(1)}$ and writable/index
$S_A(N)\le N^{s+o(1)}$ in the FLMV indexed-read-only-input model.
Under $P=NP$, one unknown finite diagonal $(K,K)$ exists.
A finite cofinal route from achievable integer diagonals into
\[
t<c_*=\frac{241}{200},\qquad
s<d_*=\frac{11642479}{23232400},\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right)
\]
is sufficient but OPEN. The illustrative unproved all-input successor is
$t'\le\max(11/10,3/5+t/2)$,
$s'\le\max(1/2,s/2)$. The old universal cosine bound is RETIRED.

Four falsifiable constructions were posed before reviewing the archive and primary literature:
\begin{description}
\item[] \textbf{H1 (positive).} A deterministic sequential child emitter with
indexed read-only original source can be converted to an exact arbitrary-index
ordinary child accessor by taking checkpoints after every $h$ real machine
transitions, even when output spacing is irregular.
\item[] \textbf{H2 (restoration).} Replaying a complete saved configuration
requires $S_G$ new writable bits of copying per guest input probe.
Test full copy versus immutable tape snapshots with sparse write overlays.
\item[] \textbf{H3 (two genuine levels).} A second ordinary child generator can
query a first virtual child without free source bits. Verify actual second-level
ordinary encoding, both labels, compatibility, and nested replay charges.
\item[] \textbf{H4 (favorable ARC).} Such generic checkpointing alone provides a
power-short all-input ordinary-SAT successor. Attempt the exact exponent test,
and retire that implication if raw restrictions or ancestor access prevent it.
\end{description}
We establish H1, reject H2 when charged copy-on-write is permitted, verify H3
computationally and by a composition lemma, and leave H4 OPEN, not proved.

\section{Exact complete-configuration time-checkpoint theorem}
Let $G$ be one fixed, uniform, deterministic, total transducer on
an indexed read-only input $x$ of $N$ bits. It emits a finite ordinary
binary output $y$ on a write-only tape; it may reread $x$ by charged
addresses. Suppose its execution has at most
$T=T_G(N)=N^{r+o(1)}$ native machine transitions and at most
$S=S_G(N)=N^{\eta+o(1)}$ simultaneously live work/index bits,
with $T,S$ polynomial and $T\ge |y|$.
Complete machine configurations (control, work/index tapes, head
positions, output count, and relevant source-access state)
have an explicit indexed binary representation of at most
$O(S+\log(T+2))$ bits. Both copying an entire snapshot and
indexing into it are charged. The fixed program description is not advice.

\begin{theorem}[Source-indexed time checkpoints with paid COW replay]
For any $1\le h\le T$ there is one deterministic, uniform ordinary-indexed
accessor for every bit $y_j$ of the output of $G$ with preparation and total
$Q$-probe resources, up to $\operatorname{polylog}(N+2)$ factors,
\begin{align}
W_{\rm indexed}
 &\le O\left(T+\frac{T}{h}(S+\log T)+Qh\right)
       \operatorname{polylog}(N+2), \label{eq:work}\\
S_{\rm indexed}
 &\le O\left(\frac{T}{h}(S+\log T)+S+h\log(T+S+2)\right)
       \operatorname{polylog}(N+2). \label{eq:space}
\end{align}
All mutable and index bits, checkpoint-write traffic (including unchanged
bits), source reads/replay, address/control and retained configurations
are charged. The output is not silently made into a free indexed tape.
The bound holds for arbitrarily irregular output-event gaps.
\end{theorem}
\begin{proof}
Run $G$ from its initial configuration. Save its complete configuration
and emitted-output counter after every $h$ \emph{machine transitions},
not every $h$ outputs, and save a final checkpoint. A checkpoint stores
$O(S+\log T)$ explicitly addressable bits, and recording it costs the
same order of bit work; thus $\lceil T/h\rceil$ records have the work
and storage costs in (\ref{eq:work})--(\ref{eq:space}).

For the $j$th output bit, binary-search the nondecreasing checkpoint
output counters, taking the \emph{last} checkpoint with count $<j$.
The next occurrence of output bit $j$ is at most $h$ transitions later:
if $t_j$ is its emission time, the selected checkpoint is at
$h\lfloor(t_j-1)/h\rfloor$. This statement includes long intervals
of no output.

Naively restoring a mutable snapshot costs $O(S)$ per query.
Instead, retain the checkpoint's tape image as immutable indexed memory.
Copy only the $O(\log T)$ finite-control/address fields. Replay each
transition with an initially empty \emph{write overlay}: for each accessed
work/index address consult the overlay if written since the checkpoint,
otherwise the immutable base. A transition modifies $O(1)$ tape cells,
so at most $h$ addresses are modified in $h$ steps. An indexed balanced
dictionary with full address keys costs
$O(h\log(T+S+2))$ live bits and polylog bit work per lookup/update.
The host simulates each original input-indexed source probe explicitly.
No original work tape is regenerated free. The original output bit
is produced exactly after at most $h$ replay steps, and all temporary
overlay bits are released before the next query. This yields the bounds.

All resource coordinates describe \emph{one} implementation.
A fixed transducer $G_A$ selected under $P=NP$ is still finite uniform
source code; its full work/index state and actual solver calls must be
included in $T,S$. The theorem does not grant a SAT oracle.
\end{proof}

\paragraph{Necessary accounting caveats.}
This is an \emph{upper bound for the declared generic checkpoint scheme},
not a lower bound on random-access generation: direct output-bit
decoders, compressed checkpoints, algebraic powering, caching and
representation changes may be superior. A purely stateless
restart-from-beginning strategy has $O(QT)$ time and
$O(S)$ workspace, and can win when the $\Theta(h)$ COW overlay is too
large. If $G$ depends on a derived virtual input, the cost of \emph{each}
such input access is composed recursively; it is not included as a
unit-time free input query.

\begin{corollary}[All ordinary guest accesses, conditional ledger]
Suppose $G_A$, on an ordinary $N$-bit source, produces one \emph{valid
complete ordinary-SAT child} of length $L=N^{\lambda+o(1)}$,
using $T=N^{r+o(1)}$ time and
$S=N^{\eta+o(1)}$ space as above; all semantic correctness of the
child construction is an \emph{additional} hypothesis.
Let a correct total guest $A$ on child length $L$ have joint
$(t,s)$ and at most $L^{t+o(1)}$ input probes.
Taking $h=N^\theta$ and holding one child at a time yields the
\emph{same-machine} upper bounds
\[
\boxed{
t'\le\max\{r,\ r-\theta+\eta,\ \lambda t+\theta\},\quad
s'\le\max\{\eta,\ r-\theta+\eta,\ \theta,\ \lambda s,\ \kappa\}
}
\tag{3}
\]
for one child, where $\kappa$ counts retained ancestor buffers/states.
With $B=N^{a+o(1)}$ sequential children, add $a$ to each child-work
exponent in the time maximum, but \emph{not} to the depth-first peak-space
exponent. All output header/body, recognition, gluing, failed branches
and guest calls must be included in $G_A$ and its total local ledger.
These inequalities are CONDITIONAL and do not establish an ARC edge.
\]
\end{corollary}

\section{A decisive, exact two-level source-access toll}
Suppose the first emitter has child length $L_1=N^{\lambda_1+o(1)}$,
native time $N^{r_1+o(1)}$, live work $N^{\eta_1+o(1)}$
and checkpoint interval $h_1=N^{\theta_1}$.
A second emitter acts on the \emph{first virtual ordinary input},
producing length $L_2=N^{\lambda_1\lambda_2+o(1)}$;
its native time on length $L_1$ is
$L_1^{r_2+o(1)}$ and work is $L_1^{\eta_2+o(1)}$;
set $h_2=L_1^{\theta_2}$.
One G2 native transition makes at most one G1 virtual source-bit request.
The parent/child programs have fixed finite recursion depth, and
output parsing, ordinary headers, and source-name consistency are paid.

\begin{theorem}[Two-level virtual ordinary-child composition]
For a \emph{single} two-level path, one full first checkpoint preparation,
a full second checkpoint preparation and one correct guest $A$ on the
second ordinary child have conservative joint exponents
\begin{align}
t_2 \le \max\{&
r_1,\ r_1-\theta_1+\eta_1,\
\lambda_1r_2+\theta_1,\
\lambda_1(r_2-\theta_2+\eta_2),\
\lambda_1\lambda_2t+\theta_1+\lambda_1\theta_2\},
\tag{4}\\
s_2 \le\max\{&
r_1-\theta_1+\eta_1,\ \theta_1,\ \eta_1,\
\lambda_1(r_2-\theta_2+\eta_2),\
\lambda_1\theta_2,\ \lambda_1\eta_2,\
\lambda_1\lambda_2s,\ \kappa\}.
\tag{5}
\end{align}
For genuinely executed fanout, multiply each associated path's work
by its fully counted call multiplicity and retain all relevant
checkpoints only for their actual live lifetimes.
\end{theorem}
\begin{proof}
The first preparation uses time exponents $r_1$ and
$r_1-\theta_1+\eta_1$. Running $G_2$ to construct its checkpoints
costs at most $L_1^{r_2}$ virtual G1 accesses, each of at most
$N^{\theta_1+o(1)}$ replay work, plus the bit-copy time for
$L_1^{r_2-\theta_2}$ saved second configurations of size
$L_1^{\eta_2+o(1)}$. Every guest input probe replays at most $h_2$
second transitions, each possibly requiring an $h_1$ replay of
the first child, giving the last time term. Simultaneous workspace
contains both checkpoint libraries, both ephemeral write overlays,
the ancestor state and the guest's entire writable/index state;
their finite sum has the maximum exponent in (5).
The parent uses one exact ordinary binary child encoding at each
level, not a SAT-label oracle. All other primitive parsing,
selection, construction, gluing and source-access costs remain
in the displayed charged time parameters.
\end{proof}

\paragraph{No fixed-power raw reduction.}
For the explicit Shannon restriction wrapper used in the finite
audit, the parent answer is exactly
\[
\operatorname{SAT}(F)=
\bigvee_{b,c\in\{0,1\}}
\operatorname{SAT}(F|x=b,y=c).
\]
At every level, the generated string is an independently valid
ordinary DIMACS CNF with copied original variable IDs and exact
SAT/UNSAT decisions; the next level is eligible even if the source
entered as $C_\star$ and leaves it. Nevertheless bounded-occurrence
sources lose only $O(1)$ clauses from two pins, so the child encoded
length is $N^{1-o(1)}$, not $N^\lambda$ for fixed $\lambda<1$.
The total malformed-input wrapper rejects after paid grammar checking.
Two real recursion levels therefore establish semantic exactness
without the missing power-size improvement.

\section{Numerical ARC window: when checkpointing consumes all slack}
For the \emph{hypothetical} available power-short local child profile
$a=3/5$, $\lambda=r=1/2$, $\eta=\kappa=0$, use interval
$h=N^\theta$, $0\le\theta\le1/2$. The conditional joint successor
upper envelope reduces to
\[
t'\le \max\left\{\frac{11}{10},\frac35+\frac t2+\theta\right\},
\qquad
s'\le \max\left\{\frac12-\theta,\theta,\frac s2\right\}.
\tag{6}
\]
Its limiting \emph{upper envelope} is
\[
t_\infty^{\rm bound}=\frac65+2\theta,\qquad
s_\infty^{\rm bound}=\max\{\tfrac12-\theta,\theta\}.
\tag{7}
\]
For strict $c_*=241/200$, (7) can certify forbidden time only if
$\theta<1/400$.
At $\theta=1/400$ equality $t_\infty^{\rm bound}=241/200$ is
\emph{not} strict. This sharp conditional accounting window does not
construct the assumed child compiler, and a failed upper-bound test
does not prove that no faster algorithm exists.

For a \emph{global} $N$-step streaming normalizer with $\eta=0$, saving
$N/h$ complete checkpoints and a $h$-step COW overlay imposes, within
this implementation, a peak exponent at least
$\max\{1-\theta,\theta\}\ge1/2$.
Reducing stored output does not eliminate the generator's initial
$N$ source steps or produce an ordinary power-short child.
Direct sequential frontier DP on an already certified low-width stream
may dominate this random-access conversion, as lead
\texttt{ARC-DP-DOMINANCE167} has established.

\section{Reproducible experiments, assumptions, and audit}
\textbf{Experiment A, true recursive ordinary inputs.}
A deterministic reference program parses/reemits actual complete
ordinary DIMACS CNFs. Level-1 input is the indexed original
source; level-2 input is a \emph{virtual indexed access to the first
checkpoint stream}, not an already materialized source shortcut.
Every chosen residual is independently parsed and compared against
literal restriction, then actually decided by exact brute-force SAT
at the level-2 leaf. On 36 sources (18 SAT, 18 UNSAT), including
M22 $Y_6$ SAT, the all-eight-clause UNSAT core, Horn, affine,
2SAT, connected and disconnected controls and seeded both-label
random sources, the program constructed 72 first-level and 142
second-level ordinary child streams, made 142 actual exact leaf
decisions, checked 642 extra indexed byte reads, rejected six
malformed source encodings, and had zero semantic discrepancies.
The $h_1=4,h_2=16$ run counted 8,118 native emitter steps,
298,107 virtual replay steps, 53,251 Python-state snapshot-copy
bytes, 104,502 on-demand virtual source-character reads and 6,540
emitted child bytes. Alternative $h$ values were independently
tested. The second-level naive DIMACS parser repeatedly rescans
its parent stream and is intentionally a high-cost charged control.

\textbf{Experiment B, full-state COW replay.}
A source-dependent deterministic toy transducer runs 600 steps,
changes one location of a 257-bit writable tape at each transition,
and emits 200 bits. For each checkpoint interval
$h\in\{1,4,16,32,64,128\}$,
500 seeded random output-index probes were checked against a
separately materialized expected transcript using both naive full-tape
restoration and an \emph{immutable checkpoint plus write overlay}.
All 3,000 COW probes and 3,000 naive controls matched.
COW overlays changed at most $h$ source-tape positions, with exact
maximum replay steps at most $h$. At $h=32$ the implementation held
20 full checkpoint images, replayed 8,298 COW transitions across
500 queries, and used no more than 32 overlay tape cells per query.
The naive alternative copied 128,500 tape bytes for those 500 probes
regardless of $h$.

The reference programs run in ordinary Python and count logical
events and serialized bytes. They are \emph{not physical FLMV bit
traces} and do not measure peak physical index/writable tape,
bit-time, transistor count, physical flips or wire length.
The mathematical FLMV construction charges complete state-copy
and indexed overlay cost separately. No finite experiment proves a
new complexity lower bound.

\item[] \textbf{CONDITIONAL:} resource recurrences (3)--(7) presuppose
real, valid, source-consistent, all-input power-short ordinary-SAT
children and successful paid guest-access routing.
\item[] \textbf{FALSIFIED/RETIRED:} checkpoint bit accesses are free;
restoring a huge snapshot is free by copying it; streaming output
is already an ordinary random-access child tape; raw constant-depth
pins establish power-short descendants; old universal cosine landing.
\item[] \textbf{OPEN:} construct a uniform \emph{assumption-dependent}
all-input correct total normalizer $G_A$ whose semantic output is a
finite compatible cover by genuine power-short ordinary-SAT children,
with $r,\eta,a,\lambda,\kappa$ satisfying strict FLMV simultaneously
and persisting through two real descendants. A single full-parent
$A(F)$ call or a free label does not close this implication.
