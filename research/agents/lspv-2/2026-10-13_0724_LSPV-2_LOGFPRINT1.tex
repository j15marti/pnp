\section{Exact family and output contract}
For a CNF \(F\) and partial assignment \(\alpha\), write
\[
 H_F(\alpha)=\mathbf 1[\alpha\text{ extends to a model of }F].       \tag{1}
\]
Adopt BALCOMP1's explicit family
\[
 E_{b,u}=B_b\sqcup G_{u_1}\sqcup\cdots\sqcup G_{u_k},
 \quad b\in\{0,1\},\quad u\in\{0,1\}^k,                           \tag{2}
\]
inside duplicate-free proper signed Monotone
\(3\mathrm{SAT}\text{-}(2,2)\).  Here \(B_0\) is D\"ocker's fixed
198-variable, 264-clause UNSAT instance, \(B_1\) is the equal-size union of
33 satisfiable six-variable blocks, and \(G_0,G_1\) are equal-size
satisfiable six-variable blocks.  Every member has
\[
 n_k=198+6k,\qquad m_k=264+8k,\qquad N_k=\Theta(k\log k).            \tag{3}
\]
There are exactly \(2^k\) YES and \(2^k\) NO formulas.  BALCOMP1 proves that
all NO formulas have the constant-zero compatibility function, while fixed
partial assignments \(\alpha_i\), supported on payload block \(i\), obey
\[
 H_{E_{1,u}}(\alpha_i)=1-u_i.                                      \tag{4}
\]
Consequently there are exactly \(2^k+1\) distinct functions \(H_F\).

Define the promised-family signature
\[
 \sigma_k(F)=
 \begin{cases}
 (0,0,\ldots,0),&F\text{ is unsatisfiable},\\
 (1,H_F(\alpha_1),\ldots,H_F(\alpha_k)),&F\text{ is satisfiable}.
 \end{cases}                                                       \tag{5}
\]
The output contract is deliberately narrow.  It identifies \(H_F\) within
the finite family (2).  It does not enumerate the \(3^{n_k}\)-point truth
table of an arbitrary compatibility function.

\section{Theorem: logarithmic identification and black-box extraction}
\begin{theorem}[\texttt{LOG-FINGERPRINT-EXTERNAL-EXTRACTION1}]
For every \(k\ge1\):
\begin{enumerate}
\item \(\sigma_k\) is injective on
\(\{H_F:F\in\mathcal E_k\}\) and has length \(k+1\), which is the minimum
fixed binary descriptor length for \(2^k+1\) objects.
\item A uniform syntax-directed algorithm computes \(\sigma_k(E_{b,u})\) in
\(O(N_k)\) time and \(O(k)\) output bits with zero SAT-oracle calls.
\item For every total exact uniform 3SAT decider \(A\), there is a uniform
black-box extractor \(X^A\) such that
\[
 \forall F\in\mathcal E_k:\quad X^A(F)=\sigma_k(F),                 \tag{6}
\]
using one call on a NO member and \(k+1\) calls on a YES member.  Every call
has \(O(N_k)\)-bit proper 3-CNF input, and local construction plus output
cost is \(O(kN_k)\).
\item If \(A\) runs in time \(T_A(N)\le C N^c\), then
\[
 T_{X^A}(N_k)=O\!\left(kT_A(O(N_k))+kN_k\right)
             =O(N_k^{c+1}+N_k^2),                                 \tag{7}
\]
so the extractor is polynomial time.
\end{enumerate}
\end{theorem}

\begin{proof}
All NO formulas induce one constant-zero function, hence the first line of
(5) correctly names that quotient element.  On YES formulas, (4) makes the
last \(k\) bits equal \(1-u\), so they distinguish all \(2^k\) remaining
functions.  Thus \(\sigma_k\) is injective.  Any fixed binary encoding of
\(2^k+1\) objects needs at least
\(\lceil\log_2(2^k+1)\rceil=k+1\) bits by the pigeonhole principle, and (5)
meets the bound.

The canonical block grammar explicitly contains \(b\) and each payload type
\(u_i\).  One left-to-right validation pass therefore emits (5) in
\(O(N_k)\) time without invoking a solver.

For the black-box construction, call \(A(F)\).  If the answer is zero, the
promised-family lemma makes \(H_F\) constant zero, so emit the first line of
(5).  If the answer is one, query each restriction \(F\upharpoonright
\alpha_i\).  To remain in proper 3CNF, replace a pin literal \(\ell\) by the
fresh-variable gadget
\[
 (\ell\vee a\vee d)\wedge(\ell\vee a\vee\neg d)\wedge
 (\ell\vee\neg a\vee d)\wedge(\ell\vee\neg a\vee\neg d).          \tag{8}
\]
If \(\ell=1\) the gadget is satisfied; if \(\ell=0\), its four residual
binary clauses are jointly inconsistent.  Hence adjoining (8) for every pin
is satisfiable exactly when the requested restriction is extendible.  Each
\(\alpha_i\) pins three payload variables, so it adds only six fresh
variables and twelve proper clauses.  Copying and pinning each of the \(k\)
queries costs \(O(kN_k)\), each query has length \(O(N_k)\), and (7) follows.
\end{proof}

The exact positive quantifier is
\[
 \exists(\mathcal E_k)_{k\ge1}\ \forall A\in\mathsf{Dec}(3\mathrm{SAT})\
 \exists X^A\ \forall F\in\mathcal E_k:
 X^A(F)=\sigma_k(F),\quad Q_A(F)\le k+1.                           \tag{9}
\]
It does not say that one execution of \(A(F)\) internally exposes
\(\sigma_k(F)\), and it does not quantify over compatibility functions
outside the promise family.

\section{Falsified implication and smallest repair}
The construction falsifies the scoped inference
\[
 \#\{H_F:F\in\mathcal E_k\}=2^{\Theta(N_k/\log N_k)}
 \Longrightarrow
 \text{superpolynomial external identification cost}.             \tag{10}
\]
It also retires any claim that the logarithm of compatibility-family
cardinality alone exceeds the ordinary polynomial output budget.  The exact
information content here is \(k+1=\Theta(N_k/\log N_k)\) bits.

There are two important nonconsequences.  First, requiring the explicit full
truth table of \(H_F\) creates a trivial output-size lower bound, but a
one-bit SAT decider need not print that table.  Second, the multi-call
extractor (9) is not the \same{} original execution.  Its solver calls,
formula copies, pins, validation, and output belong to \(X^A\), not to the
tested run \(A(F)\).

The smallest credible repair must name a representation-independent output
whose shortest sufficient description is superpolynomial, prove that every
polynomial SAT decider yields it without merely demanding an exponentially
large presentation, and land the resulting cost in a model with an
unconditional matching lower bound.  That entire transfer remains \OPEN.

\section{Primary literature and barrier-transfer preflight}
Angluin's query-learning framework is an \textbf{EXACT OBJECT/THEOREM
TRANSFER} after fixing the concept class: here a concept is one promised
function \(H_F\), a membership query is a compatibility value
\(H_F(\alpha)\), and the learner's output is an identifier~\cite{Angluin88}.
The information lower bound is exactly the binary decision-tree leaf count.
It is not a lower bound for an algorithm also given revealing formula syntax;
indeed the parser route is cheaper.

Cook reductions and classical self-reducibility justify using decision calls
on pinned formulas as an external computation pattern~\cite{Cook71,Schnorr76}.
This is a \textbf{DIRECTLY TRANSFERABLE CONSTRUCTION} for the stated queries,
but it supplies no internal-work theorem.  D\"ocker's proper
Monotone-\((2,2)\) construction transfers exactly at the formula level and
supplies the fixed UNSAT block, not a computation lower bound~\cite{Doecker21}.

Bogdanov--Trevisan's limitation on nonadaptive worst-case-to-average-case
reductions for NP is a \textbf{DIRECT BARRIER IN ITS DECLARED MODEL}; it warns
against promoting the cheap extractor into average-case hardness without a
new reduction~\cite{BT06}.  Knowledge compilation, OBDD residual-state
counting, communication cuts, VLSI routing, and proof-system size are
\textbf{FAILED TRANSFERS} unless every arbitrary ordinary SAT computation is
compiled into the same restricted realization with all costs preserved.

\section{Barrier and SAME\_REALIZATION audit}
\paragraph{Relativization and algebrization.}
The signature proof and black-box extractor work relative to any exact SAT
oracle and survive algebraic oracle access.  They are negative guards, not a
nonrelativizing or nonalgebrizing hinge.  Baker--Gill--Solovay and
Aaronson--Wigderson therefore remain active barriers~\cite{BGS75,AW09}.

\paragraph{Natural Proofs, nonuniformity, and representations.}
No large constructive circuit property is produced.  The family fingerprint
is uniform and explicit, but it says nothing about general circuit size.
Nonuniform advice could only make family identification easier.  Compact
circuits, branching programs, BDDs, and syntax descriptors remain admissible
representations; counting semantic functions does not lower-bound their size.

\paragraph{One-bit output and all costs.}
The original decider returns one bit.  The external extractor returns
\(k+1\) bits across multiple executions.  It charges family parsing, all
input copies, 12 pin clauses and six fresh variables per restricted query,
every invocation of \(A\), and signature output.  Reconstruction is zero
because the contract is identification, not witness or truth-table recovery.

\paragraph{P=NP counterfactual.}
Assume 3SAT has a uniform polynomial-time decider \(A\).  Equation (7) then
makes \(X^A\) polynomial time and the syntax parser is already linear time.
There is no contradiction.  Declaring the descriptor itself hard would be
false on this family; requiring a different unconditionally hard descriptor
is precisely the missing theorem and cannot be assumed.

\section{Post-quantum technique ledger}
Lossiness/collision entropy is an \textbf{EXACT OBJECT TRANSFER}.  On the
\(2^{k+1}\) formulas, the zero signature has fiber \(2^k\) and each of the
\(2^k\) YES signatures has fiber one, so
\[
 \operatorname{Coll}(\sigma_k)=2^{2k}+2^k.                        \tag{11}
\]
The Cauchy--Schwarz image bound is valid but very loose here; the large NO
fiber masks the many singleton YES fibers.  The explicit fingerprint exploits
rather than suffers from the structure.

The LWE lesson of external black-box extraction is a \textbf{USEFUL
ANALOGY/CANDIDATE}: (9) is an unconditional toy extraction, but it extracts an
easy identifier and supplies no worst-case/average-case bridge.  Schur-square,
quadratic-relation, Hilbert/syzygy, and special-soundness ideas are
\textbf{FAILED TRANSFERS} for this output contract because no code relation or
conflicting opening is forced.  Hash/random-oracle methods remain
inadmissible for an unconditional separation.
