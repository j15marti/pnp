\paragraph{Theorem 602.1 (fixed-body global gap normal form).}
Let a checker-accepted finite \emph{fixed} chronological paid inference sequence have $r$ distinct true defining facet values, with value $f$ consumed at strictly increasing paid-step indices $t_{f,1}<\cdots<t_{f,m_f}$. Reemission is freely permitted but every emitted facet view must have at least one consumer and all signed native Resolution inference records and paid owners are held fixed. Store each true DEF view from its first to its last consumer, inclusive, and count one slot at each paid inference checkpoint. Suppose exactly $K$ total views are used, $r\le K\le\sum_fm_f$. Set
\[
 B=\sum_{f=1}^r(t_{f,m_f}-t_{f,1}+1),\qquad
 g_{f,j}=t_{f,j+1}-t_{f,j}-1\ge0.
\]
Then the exact minimum of the stated last-use facet-slot area is
\[
 \boxed{A^*(K)=B-\sum_{j=1}^{K-r}g_{(j)},}
\]
where $g_{(1)}\ge g_{(2)}\ge\cdots$ is the combined sorted multiset of all consecutive-use gaps. For a fixed $K$, sorting gaps costs $O(U\log U)$ time and $O(U)$ storage for $U=\sum_f(m_f-1)$; the full rewriter additionally costs linear time in the explicit record/pointer count after the gaps are computed. A value-specific slot weight $b_f\ge0$ replaces $g_{f,j}$ by $b_fg_{f,j}$ if the objective is weighted total area; this does \emph{not} model exact JSON certificate bits or physical RAM.

\paragraph{Proof.}
Reemission immediately before each copy's first use never increases its live interval and preserves every dependency: the copy has no parents, its facet is already true of a globally declared paid owner, and each consumer's signed RES parent index is remapped to the earlier copy. For one facet, let its uses be sorted. Any assignment of $m_f$ uses to $k_f$ nonempty views can be uncrossed: crossing or nested live intervals can be replaced by $k_f$ consecutive, nonempty blocks of uses without increasing the sum of interval lengths (equivalently, for the optimum group, assign each use to one of the views covering it and then move interval boundaries outward to consecutive first/last uses). An elementary lower-bound argument avoids relying on the uncrossing phrasing: an interval partition into $k_f$ contiguous nonempty groups is no more expensive than any other $k_f$-view interval cover of the same ordered uses, since an optimal cover of points on a line can be partitioned into nonoverlapping consecutive clusters without increasing interval length. Relative to one view spanning $t_{f,1}$ through $t_{f,m_f}$, each cut after use $j$ removes exactly the $g_{f,j}$ strict-between-checkpoint slots. Thus, with $k_f-1$ cuts, the best objective selects the largest gaps for $f$. Since cuts do not interact between distinct facet values and only total $K-r$ is constrained, globally choose the largest $K-r$ gaps. Every step preserves all original RES clause values and chronological parent dependencies, SOURCE occurrences, one-time owner declarations, paid total and empty terminal. This proves the formula and an explicitly realizable normalized packet for the restricted checker. Source provenance and context/port types outside this sibling calculus are not inferred.
