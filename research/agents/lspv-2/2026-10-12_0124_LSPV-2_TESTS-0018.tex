\section{Exact padding theorem}

Let $B$ be the paired-$K_{3,3}$ formula on variables $x_{ij}$,
$i,j\in\{1,2,3\}$, with, for each row and column triple, both its all-positive
and all-negative clause.  Thus $B$ has nine variables and twelve distinct
proper clauses.  Each variable occurs twice in each sign.  Direct enumeration
gives 102 satisfying assignments; only the existence of two distinct fixed
witnesses $b_0,b_1\models B$ is needed below.

\begin{theorem}[Clean-core fork-padding gauge]
\label{thm:gauge}
For every $F\in\mathcal H_{2,2}^{\pm}$ and $k\ge1$, define
\[
 T_k(F)=F\wedge B_1\wedge\cdots\wedge B_k,
\]
where the $B_i$ are variable-disjoint copies of $B$.  Then:
\begin{enumerate}
\item $T_k(F)\in\mathcal H_{2,2}^{\pm}$ and
      $T_k(F)\in\SAT\iff F\in\SAT$;
\item its encoded length is
\[
 N_k=N+O\!\left(k\log(n+k)\right);
\]
\item with common commitment $c=\operatorname{enc}(T_k(F))$, challenge
$e=(e_1,\ldots,e_k)$ and response
\[
 z(w,e)=w\,\|\,b_{e_1}\,\|\cdots\|\,b_{e_k},
\]
the fixed verifier accepting exactly these canonical forms has, for every
$w\models F$, all $2^k$ distinct challenge openings;
\item projection $\pi(z)=w$ extracts an ordinary witness of $F$ from one
opening.  Two distinct-challenge openings yield no stronger object;
\item if $A_F$ is the set of canonical openings and $L:A_F\to\{c\}$ is the
constant proof-to-commitment map, then
\[
 |A_F|=|W(F)|2^k,qquad
 \operatorname{Coll}(L)=|W(F)|^2 2^{2k},
\qquad
 \frac{|A_F|^2}{\operatorname{Coll}(L)}=1.
\]
\end{enumerate}
For $k=\Theta(n)$, $N_k=\Theta(N)$ while there are
$2^{\Theta(n)}=2^{\Theta(N/\log N)}$ canonical challenges per source witness.
\end{theorem}

\begin{proof}
All variables of the $B_i$ are fresh.  Hence no new clause duplicates a
source clause or a clause in another block, and every source occurrence count
is unchanged.  Each new variable inherits exactly two positive and two
negative occurrences.  This proves clean-core closure.  Since every $B_i$ is
satisfiable and variable-disjoint, conjunction with them preserves
satisfiability.

Writing one block adds nine indexed variables and twelve clauses, so explicit
renumbering and serialization cost $O(k\log(n+k))$ bits beyond copying the
source.  For any $w\models F$ and challenge $e$, the displayed concatenation
satisfies every independent conjunct.  Distinct challenges differ in at
least one block because $b_0\ne b_1$.  The verifier checks the source witness,
the selected fixed block witnesses and the written formula in time linear in
the represented input/opening; projection discards the suffix.  The counting
identities follow because there is one canonical response for each pair
$(w,e)$ and $L$ is constant.  Finally, bounded occurrence gives
$N=\Theta(n\log n)$; taking $k=\Theta(n)$ preserves this order while producing
$2^k$ challenges.
\end{proof}

\paragraph{Status consequence.}
\texttt{CLEAN-CORE-FORK-PADDING-GAUGE1} is \textbf{PROVED/EXACT}

\section{Primary literature and transfer audit}

\paragraph{Special soundness.}
Cramer--Damg\aa rd--Schoenmakers introduced the standard partial-knowledge
and witness-hiding protocol framework \cite{CDS94}; modern formal definitions
state that two accepting transcripts with a common first message and distinct
challenges permit extraction of a witness for the declared relation.  That is
an \textbf{EXACT OBJECT/THEOREM TRANSFER} only after the interactive relation
and both transcripts exist.  The extracted object is a relation witness, not
an unconditional contradiction.  Theorem~\ref{thm:gauge} realizes precisely
this benign case.

\paragraph{Time--space endpoint.}
Fortnow--Lipton--van Melkebeek--Viglas give a deterministic random-access SAT
time--space lower bound in encoded input length \cite{FLMV05}.  This is a
\textbf{directly transferable theorem} only after the same ordinary machine,
with every construction and extraction cost, lies in its stated forbidden
region.  Fork count alone supplies no such placement.

\paragraph{Worst-case/average-case architecture.}
The LWE-style hope of externally extracting structure from black-box solver
behavior is an \textbf{ANALOGY/CANDIDATE needing a new bridge}.  Known barriers
to generic NP worst-case/average-case reductions reinforce the need for an
explicit, model-matched compiler; they do not prove the desired SAT transfer.

\paragraph{Cross-domain comparison.}
Direct sums in coding theory and replicated challenge ports in circuit/VLSI
design correspond to the independent blocks $B_i$.  Their exact transfer is
only the additive representation cost and multiplicative response set.  No
physical fan-out, routing or locality constraint applies to an unrestricted
random-access SAT decider.  Promoting those restrictions is a
\textbf{misleading analogy / failed transfer} without a compiler.

\section{Barrier and post-quantum ledger}

The padding theorem relativizes and algebraizes: a semantic or algebraic
oracle does not alter its combinatorial identities.  It is therefore a route
retirement, not a nonrelativizing hinge.  It defines no constructive large
property of truth tables, so Natural Proofs supplies no direct theorem.

Collision entropy is an \textbf{EXACT OBJECT/THEOREM TRANSFER}: the
Cauchy--Schwarz image bound is exactly tight for the constant map above.  Its
promotion to computation time is a \textbf{FAILED TRANSFER}.  Special
soundness is also exact at the declared relation level, but extracts only
$w\models F$ here.  Schur squares, quadratic-relation ranks, Hilbert functions
and syzygies are \textbf{FAILED TRANSFER} for this claim because the verifier
and one-bit decision output require no code representation.  Random-oracle or
cryptographic binding assumptions would be inadmissible in an unconditional
P-versus-NP proof.

\section{SAME\_REALIZATION audit}

The construction reads and writes an explicit formula; the verifier reads an
explicit response; projection reads/writes the source assignment.  No cost is
hidden in a succinct descriptor.  However, obtaining $w$ from $F$ is not part
of the padding transformation.  Under $P=NP$, self-reduction can acquire it in
