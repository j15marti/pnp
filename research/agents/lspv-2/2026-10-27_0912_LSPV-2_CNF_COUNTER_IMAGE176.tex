\section{Exact four-mode source and physically indexed three-zone grammar}
Let $W_1$ be the fixed clause-distinct 15-variable, 20-clause
proper signed exact-$(2,2)$ source with zero models. Opposite-sign
two-position switches
$A=\{(6,0),(11,0)\}$ on name $4$ and
$B=\{(17,2),(9,2)\}$ on name $15$
give $H(a,b)$ for $a,b\in\{0,1\}$ by reversing each pair
when its control equals zero. The complete finite $2^{15}$
truth tables have $(772,272,272,0)$ models in mode order
$00,01,10,11$. The little-endian assignment masks $616$
and $4742$ satisfy respectively both $H(0,0),H(0,1)$
and $H(1,0)$. These are independent finite gadget checks,
not an asymptotic lower bound.

For every $m\ge1$ and $a,b\in\{0,1\}^m$, make $m$
variable-disjoint copies of $H(a_i,b_i)$ and place all
$2m$ Alice-controlled clauses first, the $16m$ fixed
clauses in the middle, and all $2m$ Bob-controlled
clauses last. All names are shifted by $15i$ within
block $i$; there are $V=15m$ names and $C=20m$ clauses.
Consequently
\[
 \SAT(F_m(a,b))\iff\bigwedge_{0\le i<m}\neg(a_i\land b_i).
 \tag{1}
\]
For physical bits take the fixed 32-bit magic
\texttt{10100110111100000011110010101010},
three $w=(20m).\operatorname{bit\_length}$-bit
header integers $V,C,m$, and for each literal one sign
bit followed by its $w$-bit positive identifier.
Write
\[
 h=32+3w,\quad L=3(w+1),\quad
 N_m=h+20mL=32+3w+60m(w+1),\quad
 G=16mL=48m(w+1).                                   \tag{2}
\]
The sequence $N_m$ is strictly increasing.
The first Alice control of module $i$ is the sign bit at
$A_i=h+2iL$. The first Bob control is the sign bit at
$B_i=h+(18m+2i)L+2(w+1)$.
The companion A/B sign occurs in the other controlled
clause with opposite original sign.
All other literal signs and all IDs come from a fixed
20-row ROM with offset $15i$.

\begin{theorem}[Direct canonical-image parser]
Let $\mathcal E$ be the language of precisely the
physically encoded $F_m(a,b)$ satisfying (1), and reject
strings not matching the above canonical grammar.
There is one uniform total deterministic indexed-input
bit program that decides $\mathcal E$ for every binary
string of every length, using $O(\log N)$ combined live
work/index bits, at most $O(N)$ indexed source-bit reads,
and a conservative $O(N\log^3N)$ bit-operation bound.
On the \emph{canonical promise} alone it decides the
SAT label with exactly $2m$ signed-source anchor reads
and $O(\log^3N)$ arithmetic overhead per anchor.
\end{theorem}
\begin{proof}
Recover the unique $m$, if it exists, by binary search on
(2), calculating $w$ arithmetically; otherwise reject.
For each $i$, read the physical A and B anchor bits,
and reject the disjointness test if both are one.  Do not
store those $2m$ bits.  To verify image membership,
stream positions $p=0,\ldots,N_m-1$. Decode $p$ into
header, clause row, literal slot and within-literal bit
using division by $L$ and $w+1$. In the controlled
rows, reread just the appropriate A or B anchor on
demand; in all rows look up the fixed clause triple
and add its $15i$ name offset. Construct the expected
polarity bit or one binary ID bit, and compare with the
actual source bit at $p$. This uses only a constant
number of $O(\log N)$-bit registers. Each source lookup
charges its binary address, and each arithmetic
division and multiplication uses standard polylogarithmic
bit algorithms. There are $O(N)$ bit checks and at
most a constant number of authentic anchor reads per
check; the stated bound is conservative. The program
rejects at the first mismatch and otherwise decides
(1). Both the positive and negative source labels
follow from the fixed finite $H$ relation.
\end{proof}

\begin{lemma}[Exact parser sensitivity, restricted]
Every accepted canonical encoding has the property that
flipping any \emph{single} physical bit produces an
input outside the canonical image. Hence a deterministic
raw bit-probe acceptor for exact $\mathcal E$
must read every one of its $N$ input positions before
accepting a canonical input.
\end{lemma}
\begin{proof}
Header, ID and all fixed literal-polarity fields are
determined by $m$ and the fixed template. Each variable
A/B polarity occurs in two different clause fields
of opposite sign, so changing one sign without its
partner violates the template. For each unread position
an adversary flips only that position; the decision-tree
transcript is identical to the accepted original
but the changed string is outside $\mathcal E$.
Thus every position must be read on acceptance.
\end{proof}
This is an input-image validation lower bound. It is
\emph{not} a lower bound for deciding arbitrary SAT;
a noncanonical input may encode another satisfiable
ordinary 3CNF.

\section{Actual symbol changes: counter-head compilation lemma}
Use one \emph{sequential, two-way, read-only} input head
and a fixed number $k$ of sequential read/write work
heads, each on its own tape. Each work tape is initially
entirely blank with a distinguished starting cell,
but the transition function is not allowed a free
numeric head-position oracle or preinstalled marker.
Write the symbol $\mathtt{@}$ at the starting cell of
each used work tape \emph{once}. This changes exactly
$k$ work-cell symbols. Thereafter, leave every symbol
unchanged forever. Encode each nonnegative integer
register $r$ as the distance between its head and
the readable $\mathtt{@}$ origin. $\mathrm{INC}$ and
$\mathrm{DEC}$ move one physical work head, and
$\mathrm{ZERO?}$ reads the origin symbol. On a separate
input head, an indexed read at address $u$ is simulated
by a full return to the left input boundary and $u$
one-cell steps, with the address copied into a
temporary counter and decremented step by step.

\begin{lemma}[Unary marked-head compilation, fixed programs]
Fix any uniform deterministic indexed-input program
$P$ with a \emph{constant} number of $O(\log N)$-bit
registers, polynomial time, and only bit-implementable
integer/Boolean operations. There exists a fixed $k_P$
and a deterministic one-sequential-input-head
fixed-$k_P$ work-tape program $P^\sharp$ recognizing
the same total language, for which
\[
 D_{P^\sharp}(N)\le k_P,\qquad
 S_{P^\sharp}(N)=N^{O_P(1)},\qquad
 T_{P^\sharp}(N)=N^{O_P(1)}.                         \tag{3}
\]
Here $D$ is \emph{actual} work-cell symbol changes
including origin-marker creation, $S$ counts
\emph{every visited blank cell}, and $T$ counts
all finite-alphabet input/work-head transitions
and output. There is no numerical position oracle.
\end{lemma}
\begin{proof}
A constant collection of $O(\log N)$-bit registers
takes values bounded by $N^{c_P}$ for some constant
$c_P$. Represent each with one unary head counter
and reserve a constant number of initially zero
scratch counters. For COPY$(x,y)$, clear $y$ by
decrements; loop decrementing $x$ and incrementing
both $y$ and an empty scratch counter, then restore
$x$ by reversing the scratch. ADD and comparison use
such preserving copies. Multiplication is repeated
addition with two loop counters, and Euclidean division
is repeated subtraction and comparison. Bit extraction
is repeated division by two; a power of two is
repeated doubling. Source bit reads are implemented
by the charged physical input-head itinerary above.
All macros consist of a finite controller with only
INC, DEC, ZERO?, and input-head movements. Their
intermediate counter maxima and transition counts
are polynomial in the largest represented integer;
each original $P$ operation incurs only polynomial
overhead. Only finitely many registers and scratch
counters exist because the source program is fixed.
The only work-symbol changes are the initial markers.
Every visited blank location is included in $S$.
A final one-bit answer is emitted explicitly.
\end{proof}
A standard deterministic logspace machine, including
the parser in Theorem 1, has a constant-size
bounded-register implementation: encode its
$O(\log N)$-cell finite-alphabet work tape contents
as an integer at most $N^{c}$, store its work-head
index and the indexed address in additional counters,
and implement each simulated work-bit read/write
by power-of-two arithmetic. Thus this lemma covers
the entire canonical-image recognizer. In
particular a \emph{native} fixed-$k$ machine for
$\mathcal E$ can have $D=O(1)$ with polynomial
time and visited blank space. It does \emph{not}
establish $D=1$ with $S=O(m)$ for the raw physical
parser; Run 175 already proved that only for its
separate explicitly tagged language.
Nor does (3) preserve $D$ when a new fixed universal
interpreter $U$ simulates $P^\sharp$: every interpreter
write, decoding step and workspace cost must
be independently charged. This is a crucial
same-machine UTM-CROSS-WRITE1 firewall.

\section{Finite evidence and instrumented physical access}
The exact self-contained Node.js source creates a fixed
W1 ROM and all signed physical records, reconstructs
the four $2^{15}$ truth tables, checks little-endian
source-only masks 616/4742, and compares every
signed literal bit against the \emph{streaming} template
reader. It independently checks genuine properness,
distinctness, exact signed degree, and an explicit
SAT witness on every satisfiable tested source.
The $m=1,\ldots,4$ exhaustive $4^m$ cases total
$340$ original physical formulas ($120$ SAT and
$220$ UNSAT), $604{,}796$ physical data bits,
and $724{,}082$ charged logical indexed input probes,
counting source-anchor rereads and full validation.
An accepted $m=2$ formula underwent all $890$
possible single-bit mutations; every mutation
was rejected. Flipping \emph{both} Alice companion
signs retained canonical membership and changed
the logical mode. The corrected source replaces
an earlier $O(m)$-bit cached control array with
on-demand authentic input reads; this is a
scientifically material audit repair, not a hidden
workspace assumption.

For work-head behavior, a separate primitive counter
emulator executes 20 \emph{independent} physical sign-anchor
seek trials, each initializing two marked work tapes. The quoted
$D=2$ is a \emph{per-trial} actual-change count, not the
sum of changes across freshly initialized test objects.
The mathematical reusable-counter construction keeps the two
markers across successive requests, resets head positions by
uncharged-in-symbols but fully charged head moves, and thus
need not install additional marks. The harness does not itself
execute that combined reuse protocol. Each trial uses
work-head INC/DEC/ZERO tests and an input head traveling
one cell per step. The run charged 128,094 finite
primitive simulation units. On the $m=4$ sample with
$N=1{,}973$, it incurred $71{,}808$ units over
eight sign reads, at most $3{,}884$ visited cells on
the two counters, and exactly two initial symbol
changes. \emph{Limitation:} the finite seek-core
program is provided externally computed addresses;
the proof's general unary arithmetic compiler was
not materialized and executed as a full finite-state
CNF parser. Therefore the finite numbers are
\textbf{COMPUTATIONAL} controls of the crucial
no-fake-head-position mechanism, not an experimental
bit-TM timing certificate for the entire abstract
compiler. In total 1,279,894 assertion-accounted
checks passed, none failed.

For contrast, the physical single-input-head
round-trip itinerary uses $\Theta(mN)$ head moves;
two simultaneously placed sequential input heads
can walk the A and B anchor columns in $O(N)$ total
head travel, while indexed RAM uses $2m$ sign probes
under the canonical promise. These are \emph{different
machines}; no tape crossing bound is imported into
FLMV indexed RAM. The complete M$_k$-to-M$_1$
conservative simulation remains
\[
 T_1=O(T_k[N+S_k+\log(T_k+2)]),\quad
 P_1=O(N+S_k+\log(T_k+2)),                             \tag{4}
\]
where $P_1$ includes the initially present input.
This is an upper construction arrow, not a SAT lower
bound. Hennie--Stearns' $O(T\log T)$ simulation is
for \emph{two} tapes, not a substitute for (4).
Previous Run 171 independently verified a complete
single-tape simulation on an equality-witness
example with 340 exhaustive cases and 9,320
same-step state checks; these old results are
retained, not counted as new checks in this run.
Actual gate/wire counts belong to the fixed verifier
of Run 166; no new all-input SAT decision circuit
is synthesized here.
