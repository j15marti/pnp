\section{A structured tree of local 2CNF-plus-one-parity components}
Let $T$ be an explicit undirected tree on $B$ block vertices. Block $j$ has source variables $V_j$, a 2CNF $H_j$ and at most one affine parity row $A_j$ over $V_j$. An edge $(i,j)$ satisfies $V_i\cap V_j=\{x_{ij}\}$; no variable occurs in more than two blocks, and a shared variable occurs only across the corresponding tree edge. Private variables are disjoint. The explicitly supplied decomposition must be validated, not presumed from an arbitrary source. Put $L=\sum_j(|V_j|+|H_j|+1)$, where source clauses and variable-ID fields are actually counted.

\begin{theorem}[Exact singleton-interface join; PROVED/EXACT in this declared representation]
Assume a uniform exact 2CNF-plus-one-parity subsolver returning a satisfying assignment when one exists. The tree instance is decidable exactly by a bottom-up computation that performs at most $2B$ pinned local subsolver calls, where each child communicates a unary feasibility set in $\{\varnothing,\{0\},\{1\},\{0,1\}\}$. The global decision is SAT iff the root's feasible set is nonempty. In the RAM word model, using the explicit SCC-orbit rank-one implementation from SCC-ODD-ORBIT120, one conservative joint upper bound is $O(L^2)$ word time and $O(L)$ working words, including decomposition validation, failed probes, cached unary messages and optional witness reconstruction.
\end{theorem}
\begin{proof}
Root $T$. For child $j$ with parent interface variable $x_{pj}$, let $M_j\subseteq\{0,1\}$ contain precisely those values extendible to a satisfying assignment for the entire subtree below $j$. Inductively calculate $M_j$ by testing the two assignments $x_{pj}=0,1$ in local $H_j\land A_j$, pinning any child interface whose received message is a singleton and rejecting immediately if a child message is empty. A child message with both values adds no constraint. The constraints involving distinct children mention their separate private variables and separate interface variables; therefore independently found child witnesses glue to one source assignment. Conversely, any satisfying assignment must induce every reported pinned local feasibility event. At the root, solve once without a parent pin. This proves both directions and witness reconstruction with no independent-witness ambiguity. Each non-root block is probed at most twice and the root once. The rank-one SCC-orbit subsolver costs $O(v_j(v_j+c_j+1))$ time and $O(v_j+c_j+1)$ words on a block of size $v_j,c_j$. Local recognition/mapping and tree traversal have polynomial costs dominated by $O(L^2)$ after straightforward source-ID indexing. Storing at most two block witnesses/messages plus source records uses $O(L)$ words. A machine simulation pays the appropriate $\operatorname{polylog}L$ overhead in elementary bit operations; this is not a measured FLMV bit-TM execution.
\end{proof}
This is a constructive specialization of classical acyclic-join dynamic programming and the prior project's rank-one 2SAT/parity subsolver. It is \emph{not} a novel general CSP dichotomy. The affine rank of the union is unrestricted by the theorem, provided each row remains inside its own certified tree block.

\section{Explicit connected both-label ordinary 3CNF controls without a fixed core}
Choose any $b\ge1$ and a parity vector $p\in\{0,1\}^b$. Use boundary variables $t_0,\ldots,t_b$ and private $u_j,w_j$ for $0\le j<b$. For each block introduce
\[
(u_j\leftrightarrow t_j)\land(\neg w_j)\land
(u_j\oplus t_{j+1}\oplus w_j=p_j).
\]
Globally pin $t_0=0$ and $t_b=d$. These are explicit tree blocks with singleton shared $t_j$. Unit propagation and equivalence give $u_j=t_j,w_j=0$, so exact elimination yields
\[
t_{j+1}=t_j\oplus p_j,\qquad
\mathrm{SAT}(F_{b,p,d})\iff d=\bigoplus_{j=0}^{b-1}p_j.
\]
Every local block, even with either of its individual cut variables pinned, is satisfiable, but a globally inconsistent endpoint is UNSAT. The $b$ parity equations have rank exactly $b$ over $\mathbb F_2$, since each has the unique private column $u_j$.

For an ordinary proper three-literal CNF with no tautological clauses, encode each binary $(a\lor b)$ by $(a\lor b\lor z)\land(a\lor b\lor\neg z)$ with fresh $z$; encode each unit $(a)$ by the four ternaries $(a\lor\pm z_1\lor\pm z_2)$; encode XOR3 by the four ternaries forbidding the four wrong parity assignments. These are existentially exact gadget compilations. With canonical source IDs and ordered records,
\[
\boxed{n=7b+5,\quad m=12b+8,\quad
N=(4m+2)\lceil\log_2(64(n+m+1))\rceil.}
\]
The ordinary clause incidence graph is connected. The SAT/UNSAT controls have identical unsigned ordered clause supports; changing only the terminal unit pin changes their label.

\begin{theorem}[Growing core-span and inexpensive source-aware decision]
For every $b$ and $p$, the UNSAT member $d\ne\bigoplus p_j$ has no UNSAT subformula avoiding all four clauses of any one parity gadget. Hence every UNSAT subformula contains at least $b$ clauses, one from each distinct parity gadget. Nevertheless a uniform canonical-template recognizer followed by one parity accumulation decides this entire both-label family in $O(N\operatorname{polylog}N)$ elementary bit work and $O(\log N)$ writable bits, counting source reads and control, when given the canonical ordered representation on a read-only random-access input.
\end{theorem}
\begin{proof}
Remove all four ternary clauses encoding any parity row $j$. The block no longer constrains the relation between $t_j$ and $t_{j+1}$, while all other local rows and the two endpoint pins can be satisfied by choosing left and right boundary values independently. Thus the remaining ordinary CNF is SAT, with valid choices of every private gadget auxiliary. Any subformula omitting the $j$-th parity gadget lies inside this satisfiable formula and is SAT. This holds for each $j$. The recognizer reads the header and reconstructs the unique canonical clause sequence, extracting each $p_j$ by matching the four XOR3 records and extracting the terminal pin from the last unit gadget. Only counters of $O(\log N)$ bits and one parity accumulator are needed; comparison of $O(N/\log N)$ records each of $O(\log N)$ bits gives the displayed conservative bit bound. It rejects unsupported grammar, rather than supplying an uncharged SAT label. The recognized formula is SAT exactly when its terminal bit agrees with the extracted XOR sum. The general-purpose exact fallback outside the promise is not polynomial.
\end{proof}
The theorem is a control against treating connectedness, global affine rank or a growing minimal UNSAT subformula as unavoidable decision work. It does not claim that arbitrary connected exact-(2,2) instances are easy, nor that an arbitrary formula can be recognized as this template.
