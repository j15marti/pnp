\section{Canonical source-factor translation}
Let $F$ have $n$ occurring variables, $m$ nonempty CNF clauses and $E$ signed literal occurrences; repeated literal records are counted. Construct the bipartite incidence multigraph $G_F$ with one variable node and one clause node per source record, and one labelled edge $e$ per signed occurrence. Its Boolean edge label $y_e$ is the \emph{truth value of the signed literal}. At clause node $j$ demand $\bigvee_{e\in\delta(j)}y_e=1$. At variable node $x$ demand a common $x\in\{0,1\}$ with
\[
y_e=x\oplus[e\text{ is negative}]\quad(e\in\delta(x)).
\]
These local predicates are source-consistent: a satisfying original assignment induces all occurrence bits, and every feasible factor labelling reconstructs one assignment to every original source variable. This is a direct equivalence proof, not an assumption of independently compatible local witnesses. Any empty input clause is rejected immediately by the uniform parser.

Let $\kappa$ be the number of connected components of $G_F$. Its cyclomatic number
\[
\boxed{c(F)=E-(n+m)+\kappa}
\]
depends only on the acquired source incidence structure, not on SAT/UNSAT or measured runtime.

\begin{theorem}[Uniform exact occurrence-factor cutset solver, known method instantiated exactly]
For arbitrary ordinary CNF inputs there is one total, uniform, exact deterministic algorithm that chooses between cycle-cutset conditioning on $G_F$ and original-variable enumeration according to the observed comparison $c(F)<n$. With the original input read-only, a conservative joint elementary-bit implementation satisfies
\[
T_F(N)=O\!\left(2^{\min\{c(F),n\}}N\operatorname{polylog}N\right),
\quad S_F(N)=O(N\operatorname{polylog}N)
\]
in writable bits, including parsing, graph construction, DFS, all failed candidate assignments, message storage, memory and addressing. The source-factor branch alone uses $O(E\log(E+2)+2^{c(F)}(E+n+m))$ word operations and $O(E+n+m)$ working words.
\end{theorem}
\begin{proof}
Choose a DFS spanning forest $T$. Precisely $c(F)$ occurrence edges lie outside $T$. Enumerate each vector $a$ of their truth bits and pin \emph{both endpoint predicates} of each omitted edge to the same chosen bit. The remaining interaction graph is a forest. Bottom-up, for every directed tree edge, store the subset of $\{0,1\}$ admitted by the child subtree. A clause node admits a proposed parent-edge bit iff all child domains are nonempty and some incident literal can equal one; a variable node admits it iff some common original source bit is compatible with every incident literal's sign and permitted truth-value set. Each child subtree has no other source connection to the parent, so induction establishes exact extension semantics. Every global model gives a cut assignment whose forest accepts. Conversely, accepted messages and cut pins glue to one globally consistent satisfying source assignment. DFS, signed incidence construction and message processing are charged. If $n\le c$, brute-force $n$ original source bits and replay every clause instead; this exact alternative has $2^n$ assignments. A fixed dispatcher comparing computed integers uses no label oracle. The conservative bounds follow from ordinary explicit records with logarithmic addresses. One-bit decision does not require materializing all witnesses.
\end{proof}
