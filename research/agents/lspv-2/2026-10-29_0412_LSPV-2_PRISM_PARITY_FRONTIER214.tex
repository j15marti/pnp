\section{BUILD: canonical signed prism clause-list grammar}
For integer $r\ge3$, let $G_r$ be the cubic prism on top vertices $t_0,\ldots,t_{r-1}$, bottom vertices $u_0,\ldots,u_{r-1}$, top-cycle edges $T_i=(t_i,t_{i+1})$, bottom-cycle edges $U_i=(u_i,u_{i+1})$, and spoke edges $A_i=(t_i,u_i)$, with indices modulo $r$. Name its $3r$ edges in order $T_i,U_i,A_i$ by three consecutive indexed ranges. Give vertex $v$ a charge bit $b_v$. For every vertex impose the ternary parity equation
\[
  \bigoplus_{e\ni v}x_e=b_v.
\]
Encode this equation by four ternary clauses, in lexicographic order of the excluded wrong-parity triples, using a positive literal to forbid source bit zero and negative to forbid one. Serialize the $2r$ vertex groups and DIMACS header canonically as exact ASCII bytes (the full bytes, not a virtual promise handle). Each group has four clauses. The source language $\mathcal P_r$ comprises exactly these $2^{2r}$ signed source strings. A complete streaming recognizer checks the header, each source variable name, each ordered sign triple, all separators and end-of-file. A nonmember is rejected as malformed, not answered using an unchecked promise.

\begin{theorem}[Exact incidence and clause-hitting number]
Every $F_{r,b}\in\mathcal P_r$ is connected proper signed exact-$(4,4)$-3CNF, with $n=3r$ variables, $m=8r$ clauses, $24r$ literal occurrences, and
\[
 \tau(F_{r,b})=r.
\]
This source language is \emph{not} strict signed exact-$(2,2)$.
\end{theorem}
\begin{proof}
Every edge variable participates in the parity group of each of its two endpoints. In each four-clause group, every coordinate is positive twice and negative twice, hence four occurrences of each sign in total. Every clause has exactly the three distinct edge variables at one cubic vertex. The prism is connected. A variable can meet at most eight source clauses, so hitting all $8r$ clauses needs at least $r$ source variables. All $r$ spoke variables hit every clause: each vertex has exactly one spoke and every one of its four clauses contains it. Therefore equality holds.
\end{proof}

\begin{theorem}[Same one-program parity decision on both answer sides]
$F_{r,b}$ is satisfiable if and only if $\bigoplus_v b_v=0$. For even charge, its number of satisfying edge assignments is $2^{r+1}$; for odd charge, it is zero. The complete source-authenticated decision map that emits one fixed satisfiable proper 3CNF or the eight-clause unsatisfiable proper 3CNF is uniform, polynomial-time, uses no auxiliary SAT oracle, and outputs at most $688$ bits in the declared ASCII format. On the closed class $\mathcal C=\bigcup_r\mathcal P_r\cup\{\mathrm{YES},\mathrm{NO}\}$, outputs are directly decidable bases, and for any fixed $\lambda=3/4$ every nonbase input of bit size $N\ge N_0=6074$ has a child of length $\le N^\lambda$.
\end{theorem}
\begin{proof}
Summing all vertex equations over $\mathbb F_2$, every edge is counted twice. A connected graph's vertex-edge incidence matrix has rank $|V|-1=2r-1$, since a nonzero subset of dependent vertex rows would have no crossing edge. Thus the only consistency requirement is even total charge, and the nullity is $3r-(2r-1)=r+1$. A streaming deterministic recognizer checks the complete canonical 3CNF byte sequence, retaining only the current vertex number, three edge identifiers, a row number and one XOR accumulator; each register has $O(\log N)$ bits. It then emits either \texttt{p cnf 3 1} with clause $(1\vee2\vee3)$, or \texttt{p cnf 3 8} with all eight signed ternary clauses. Both are syntactically ordinary proper 3CNF and are direct bases; the output length bound includes the header, spaces, signs, digits and newline bytes. Since $N^{3/4}\ge688$ whenever $N\ge6074$, this is a restricted single-child $N^{3/4}$ map. The earlier CYCLE-AFFINE-SWITCH123 already established the source-aware affine decision idea; the physical recurrence is only a restricted illustration, not an embedding of arbitrary SAT.
\end{proof}

\begin{theorem}[Exact side-dependent residual spectrum at the spoke-first cut]
Consider the variable order that reads all $r$ spokes first, followed by all $2r$ rim edges. Let $\mathcal R_{r,b}$ be the set of distinct Boolean functions of the remaining rim variables obtained by setting the spokes in all $2^r$ ways. Then
\[
 |\mathcal R_{r,b}|=\begin{cases}
 2^{r-1}+1,&\bigoplus_v b_v=0,\\
 1,&\bigoplus_v b_v=1.
 \end{cases}
\]
For SAT inputs, $2^{r-1}$ residuals are nonempty, pairwise distinct and have disjoint satisfying assignments, while the remaining $2^{r-1}$ spoke settings all give the same identically false residual. For UNSAT inputs every residual is identically false. Therefore a reduced deterministic OBDD with the spoke-first prefix needs width at least $2^{r-1}+1$ on SAT inputs, but the UNSAT function is the one-node constant zero.
\end{theorem}
\begin{proof}
Fix a spoke word $a\in\mathbb F_2^r$. The top rim cycle is a connected cycle with one incidence-row dependence; its parity equations have a rim-edge solution iff $\oplus_i a_i=\oplus_i b_{t_i}$. Independently, the bottom rim cycle has a solution iff $\oplus_i a_i=\oplus_i b_{u_i}$. When total charge is even these conditions agree, leaving exactly $2^{r-1}$ feasible spoke words. Each such word yields nonempty rim solutions. If two distinct feasible spoke words shared a rim assignment, an endpoint's parity equation would force the two incident spoke values equal at every vertex, contradiction; thus their residual functions are distinct and have disjoint supports. Infeasible spoke words all leave the zero residual. When total charge is odd the top and bottom conditions conflict for every spoke word, so the full function is identically false. An equivalent linear-algebra check uses ranks $\mathrm{rk}(M_A)=r$, $\mathrm{rk}(M_B)=2r-2$, $\mathrm{rk}(M)=2r-1$ and intersection dimension $r-1$. This is a \emph{fixed-order representation} lower bound, not a decision-time or arbitrary-order OBDD lower bound.
\end{proof}

\begin{theorem}[Tight source-bit acquisition, separately on SAT and UNSAT]
In the deterministic indexed bit-probe model, under the valid canonical $\mathcal P_r$ promise, every correct program queries at least one physical bit in each of the $2r$ contiguous vertex clause groups on every input. Thus both answer-side worst-case and per-input query counts satisfy $Q_+,Q_-\ge 2r$. There is one fixed address-computing program that decides both labels with exactly $2r$ physical sign-bit queries, $O(r\log r)$ bit address work and $O(\log N)$ writable workspace, yielding $Q_+=Q_-=2r=\Theta(N/\log N)$.
\end{theorem}
\begin{proof}
The four canonical clauses of either charge at one vertex contain exactly six negative literal signs, two per source edge. Hence the two possible complete ASCII vertex-group encodings have identical byte lengths, and block starts are independent of all earlier charge choices. If a correct deterministic bit-probe program ignored every bit of one group on some execution, flip that vertex's charge. The input remains canonical with identical total length, every bit probed on that execution stays unchanged, but the SAT answer flips. This contradicts determinism and correctness, independently for an original SAT or UNSAT execution.

For the upper bound, the first lexicographic forbidden row is $001$ for charge zero, giving the first clause signs $(+,+,-)$, and $000$ for charge one, giving $(+,+,+)$. The first two source variable identifiers and separators are fixed and positive in either case, so the start address of the third literal's first byte is computable from the current block start using source IDs and decimal widths. Its ASCII bit of weight $16$ is zero for '-' and one for every decimal digit '0' through '9'. One indexed bit therefore reveals the charge. Update the next block start using the same, charge-independent, four-clause block length. All address arithmetic is computed, not granted as an occurrence table. This algorithm is only promise-correct: arbitrary malformed sources require the separate fully charged streaming recognizer.
\end{proof}
