## PROVED/RESTRICTED: actual-input-read simulation lemma

Fix a deterministic machine A with fixed program, an indexed read-only binary input tape, fresh initial work tapes on each call, no external changing oracle/environment, and a finite output alphabet (SAT, UNSAT, MALFORMED). For a fixed input x, let R_A(x) be the set of positions in [0,|x|) that A actually reads during its completed run on x. Then for every y of the **same length**, if x[i]=y[i] for all i in R_A(x), the complete control/work/index-head execution of A(y) is identical to that of A(x), including output and charged time/space. This follows by induction on machine transitions: each read-only input symbol encountered on the x trace is identical on y; every work symbol and transition therefore remains identical. The equal-length condition covers end-of-input observability. No assumption about SAT hardness or program equivalence is used.

**Online footprint-cache algorithm.** For each of q virtual children, maintain only the latest *anchor* child reference, its output label, and an L-bit read mask. Run A on the first child while instrumenting all read-only input accesses. For a later same-length child y, scan the stored mask and compare y against anchor at marked addresses. If equal, reuse the label. If unequal or length differs, run A on y, replace the anchor and clear/rebuild its mask. Emit labels sequentially; do not retain the complete q-vector. Every reused label is justified by the exact lemma. Every fallback is A itself, so the scheme preserves SAT, UNSAT and MALFORMED outcomes assuming A is total and correct. The checker does NOT need a proof of A's SAT correctness to justify transcript identity; correctness of labels is conditional on A.

## Conditional fully charged same-machine bound

Assume the **missing child generator already exists** and supplies q<=N^(3/5+o(1)) ordinary SAT/MALFORMED children, length L<=N^(1/2+o(1)), via a source-authenticated indexed child-bit/length port. Assume child-port setup, source validation and join cost at most N^(11/10+o(1)) time and N^(1/2+o(1)) all-phase peak, and each indexed port call uses N^o(1) time and N^o(1) highest-position writable space (including index-tape clearing). Assume fixed A has T_A(L)<=L^(t+o(1)), S_A(L)<=L^(s+o(1)); instrumented same-machine simulation charges all guest operations with polylog overhead and contiguous tape frames.

Resetting and recording an L-bit bitmap costs O(L polylog N) per guest execution. Comparing every later child costs at most O(qL polylog N) local operations; at most q guest calls execute. Thus the stage has

$$
T_{\rm stage}(N) \le N^{\max\{11/10,3/5+t/2\}+o(1)},\qquad
S_{\rm stage}(N)\le N^{\max\{1/2,s/2\}+o(1)}.
$$

Logical reuse count = q-u where u actual guest calls. Work/span are NOT identified: this is a sequential actual execution bound. Simultaneously live objects are a contiguous L-bit mask, one constant-size anchor index/label, one instrumented guest workspace and charged port frames. Inputs and emitted results are read-only/write-only streams in the FLMV sense, **not** hidden writable arrays. High-water usage, not just nonblank payload, is charged. Cache searches, source bit retrieval, failed comparisons, mask resets, outputs and index/head operations are included. The length port must be proven for the particular child generator; arbitrary large work-tape seeks invalidate the space premise, per peer LSPV-4/427.

This lemma supplies **only a resource-preserving solver-dependent sharing stage**, not an all-input contraction: no universal compiler producing these q recursively valid children or sound SAT join is constructed here. The trivial worst case has u=q, so the lemma alone yields no speedup over invoking A on every child. Neither B1/B2/B3 nor a mixed proof-system lower bound follows.
