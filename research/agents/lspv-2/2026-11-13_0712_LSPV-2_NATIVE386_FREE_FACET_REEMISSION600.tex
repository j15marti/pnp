\paragraph{Candidate and four falsifiers.}
Construct the exact same charged Resolution occurrence DAG twice: a certificate that reuses two free defining-facet records across independent repeated refutation blocks, and a certificate that reemits byte-valid free facets immediately before each block's use. F1: the original checker rejects a reemitted facet. F2: SOURCE, signed RES parents, paid identities or $W$ change. F3: facet-retention peak/area does not decrease. \paragraph{Theorem 600.1 (cost-preserving DEF reemission).}
Fix a checker-core-accepted /386 proof packet with a globally declared owner bank and a particular zero-additional-paid DEF record $d$ satisfying the native defining facet test. Replace any selection of subsequent parent references to $d$ by references to newly inserted identical DEF records at earlier legal positions. Rebase all chronological parent indices, retain every original SOURCE occurrence, signed RES clause, signed pivot, RES dependency (up to identity-preserving leaf clones), owner tuple, and final empty RES. Then the unchanged \emph{mathematical checker core} accepts and the logical charge
\[
W=N_{\mathrm{RES}}+\lvert\mathrm{owners}\rvert
\]
is unchanged. The full original CLI also accepts for the executed positive corpus, which retains the original gate owner and original wrapper negative-test preconditions. The statement is not a theorem about arbitrary possible CLI packets or the missing historical mixed calculus.

\noindent\emph{Proof.}
The actual DEF checker requires a parentless record whose signed clause belongs to a declared owner's correct defining facet set, with no rule enforcing uniqueness. Every clone satisfies the same check and refers to the same owner. Rewriting a RES parent from $d$ to its earlier clone leaves the actual clause value identical, and hence preserves both complementary pivot signs and the computed resolvent. A consistent chronological reindexing preserves earlier-parent restrictions. No SOURCE is deleted or repeated. The checker charges DEF records zero additional work and gate owners exactly once by declaration; Resolution count is fixed. The terminal RES stays final. Each original check therefore passes. QED.

\paragraph{Theorem 600.2 (restricted memory versus certificate-size trade-off).}
Take the accepted /599 W32 proof with 17 mandatory original SOURCE records, 2 distinct true DEF facets of one paid owner, and 31 paid RES records. Repeat its RES occurrence body $M$ times with a common original SOURCE and a single unchanged gate bank. In the \emph{shared} variant retain only one record of each facet, reused by each body. In the \emph{reemitted} variant emit a fresh true facet before its one use in each copy. Both preserve the same $31M$ signed RES occurrences, owner identity, terminal refutation, source and logical work $W(M)=31M+1$.
Count only the live DEF clause payload slots at each RES checkpoint, holding a DEF slot from its first to its last consumer and releasing after last use. Since the original two facet uses occur in distinct RES steps in each 31-step body:
\[
 A_{\mathrm{shared}}(M)=62(M-1)+2,\qquad
 A_{\mathrm{reemit}}(M)=2M.
\]
For $M\ge2$, the facet-slot peak changes from 2 to 1; for $M=1$ both peaks equal 1. This is an \emph{exact restricted resource model}, not checker RSS, because actual checker records the complete input in \texttt{known[]} and the source slots remain shared over repeated bodies. Reemission increases certificate bytes, parent-index storage, source parsing and verifier labor. Physical resource improvement is neither measured nor claimed.

\paragraph{CEGAR and soundness consequence.}
An abstract cost/space transformer must distinguish logical payment of an owner from its physical facet-view occurrences. If it canonicalizes duplicate DEF views for a work-only normal form (as LSPV-2/579 permits) and then assumes one DEF emission while proving a space lower bound, the $M\ge2$ reemission packets are legitimate concrete counterexamples. A sound MAY space abstraction must either keep facet reemission alternatives or use a demonstrated resource-safe normal-form theorem, charging all replica bytes, indexing and reconstruction. This does not refute LSPV-2/599: its theorem explicitly assumed \emph{one emission and no recomputation}. Unauthenticated historical rules remain conservatively admissible, not rejected.
