\section{Deterministic logspace pivot selection}
\begin{lemma}[Bounded-degree independent set from exhaustive short seeds]
For any fixed $D\ge1$, an indexed simple graph on $n$ named vertices, degree at most $D$, and an $O(\log n)$-space neighborhood enumerator, admits one deterministic uniform $O_D(\log n)$-space, $n^{O(D)}$-time algorithm outputting a seed for a set $I$ satisfying
\[
|I|\ge\lceil n/(D+1)\rceil,\quad I\text{ independent},\quad
[v\in I]\text{ recomputable using }O_D(\log n)\text{ writable bits}.
\]
\end{lemma}
\begin{proof}
Let $B_D=\binom{D+1}{2}$ and $C_D=(D+1)B_D+1$. Compute by trial division the first prime $p>C_Dn$; Bertrand's postulate gives $p=O_D(n)$ and all counters have logarithmic size. For each of the $p^{D+1}$ coefficient strings $a=(a_0,\ldots,a_D)$, evaluate
\[
h_a(v)=\sum_{j=0}^{D}a_jv^j\pmod p,\qquad
I_a=\{v:(h_a(v),v)<(h_a(u),u)\quad\forall u\sim v\}.
\]
Lexicographic local minima form an independent set, including collisions. A uniform random degree-$D$ polynomial over $\mathbb F_p$ yields $(D+1)$-wise independent uniform hash values. For every closed neighborhood, collision probability is at most $B_D/p$; without collisions all rank orders are exchangeable. Hence
\[
\mathbb E_a|I_a|\ge n/(D+1)-nB_D/p>(n-1)/(D+1).
\]
An integer-valued random variable with this strict expectation must reach $\lceil n/(D+1)\rceil$ for some seed. Enumerate seeds lexicographically, counting the local minima by repeated graph scans and retaining the first successful seed. Seed, arithmetic scratch, primal-neighbor addresses, prime and counters all occupy $O_D(\log n)$ bits. Every unsuccessful candidate and all input scans are charged. No advice or randomized guarantee is used. Compare bounded-degree polylogarithmic-space independent-set methods \cite{biswas}.
\end{proof}

\section{Two-round source-replayed exact Davis--Putnam}
\begin{theorem}[Logspace source-backed two-round projection, restricted exact]
One fixed deterministic uniform algorithm on valid indexed $F\in\CM$ computes descriptors for two independent pivot sets
\[
F\xrightarrow{\exists I_1}F_1\xrightarrow{\exists I_2}F_2,\qquad
|I_1|\ge\lceil k/9\rceil,\quad
|I_2|\ge\lceil v_1/25\rceil,
\]
where $v_i$ is the \emph{occurring} variable count. Exact pointwise semantics and size bounds are
\[
\begin{gathered}
F_2(z)=\exists_{x\in I_1\cup I_2}F(x,z),\quad
v_1\le8k/9,\quad v_2\le64k/75,\\
|F_1|\le m,\quad\operatorname{width}(F_1)\le4,\quad
|F_2|\le |F_1|+8|I_2|=O(k),\\
\operatorname{width}(F_2)\le6,\quad
|\operatorname{enc}(F_i)|=O(N)\ (i=1,2).
\end{gathered}
\]
It can compute any declared indexed output bit of either fully specified ordinary-CNF child $F_i$ in polynomial $N^{O(1)}$ bit-work from the original \emph{read-only} input with only $O(\log N)$ simultaneously live writable/index bits. Alternatively it emits each bit on a distinct \emph{write-only output stream} with all bits charged. If the child must be a materialized writable query tape, its $\Theta(|\operatorname{enc}(F_i)|)$ bits are \emph{additional} workspace.
\end{theorem}
\begin{proof}
Each source variable cooccurs with at most eight others, so select $I_1$ by the lemma for $D=8$. No original clause contains two selected pivots. Each $x\in I_1$ has two positive and two negative parents; its cross-product gives at most four resolvents after deleting exactly four parents, with width at most four and pointwise $\exists x$ semantics. No count increase occurs. Every signed occurrence of a surviving name is replicated at most twice. The intermediate $F_1$ has at most eight occurrences per name and primal maximum degree at most $8(4-1)=24$. Select $I_2$ with $D=24$. Each second-round variable has at most four positive and four negative parent clauses, creates at most sixteen resolvents while deleting at most eight, so $|F_2|\le |F_1|+8|I_2|$, and resolvent width at most six. Independence makes each round noninteracting on pivot names. Ordinary Davis--Putnam existential projection composes for both SAT and UNSAT. The active-variable and indexed-body size bounds follow.

To realize logarithmic writable bits, use a deterministic source-record order. For a requested $F_1$ output bit, regenerate on demand every untouched source clause and the at most four resolvents for each selected original pivot, testing tautologies and duplicates by rescanning source and earlier candidates, using only record ordinals, the first seed, literal names, comparison counters and bit positions. A source-backed virtual indexed $F_1$ results, with polynomial work per output bit and logarithmic state. Enumerate its clauses by repeated calls, compute its primal neighbors, and run the second seeded selector on that virtual graph. For a requested $F_2$ bit, replay at fixed depth the $F_1$ record generator and enumerate second-round resolvents, testing duplication by replay. A fixed nesting of logarithmic-space computations is logarithmic-space, with a larger fixed polynomial running exponent. Even the seed counts alone are $O(N^9)$ and $O(N^{25})$. No zero-cost SAT solver, child tape, witness bit or free parameter selection is assumed. A zero-variable/empty-clause terminal is handled explicitly by stopping the corresponding round and writing TRUE/FALSE in the declared ordinary-CNF terminal encoding.
\end{proof}
