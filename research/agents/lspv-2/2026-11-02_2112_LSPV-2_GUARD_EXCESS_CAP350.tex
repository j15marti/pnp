\section*{Model}
Original named CNF clauses are free source nodes. Each distinct paid inference in an acyclic refutation DAG costs one. The fixed sound, complete conservative at-most-two-premise $R_{\rm mix341}$ includes ordinary binary Resolution, exact local Boolean AND3, GF$(2)$ row addition, paid conversions and charged source-independent auxiliary-variable definitions. Minima grant free best-proof selection; machine discovery/checking/encoded length are separate resources.
For any tautology-free UNSAT $F(x)=\bigwedge_{i=1}^m C_i$, introduce fresh $z_1,\ldots,z_t$. Write $L_\epsilon=\bigvee_j(z_j\text{ if }\epsilon_j=0,\;\neg z_j\text{ otherwise})$ and $G_t(F)=\bigwedge_{\epsilon\in\{0,1\}^t}\bigwedge_{i=1}^m(C_i\vee L_\epsilon)$. Every assignment $(x,z)$ activates precisely the guard block $\epsilon=z$; thus $G_t(F)(x,z)\equiv F(x)$ pointwise. Let $\mu(F)$ be smallest UNSAT source-core cardinality and $W_R(F)$ minimum paid DAG node count.
\begin{theorem}[universal guard core and upper-cost transport]
For all UNSAT tautology-free general CNFs $F$ (arbitrary clause width), all integers $t\ge0$, and every optimal $R_{\rm mix341}$ refutation $\pi$ using $q=W_R(F)$ paid nodes and $s$ distinct original source clauses,
\[
\boxed{\mu(G_t(F))=2^t\mu(F),\qquad
2^t\mu(F)-1\le W_R(G_t(F))\le q+s(2^t-1).}
\]
For CNFs containing tautological source clauses, the core identity and source-count lower bound still hold, but the upper construction may require a tautological Resolution conclusion forbidden by the declared strict syntactic rule. A separate source-normalization and proof-cost comparison is required; do not claim the same upper in that broader grammar. This upper translation preserves arbitrary shared subderivations, exact mixed operations, temporary growth, and conservative auxiliary definitions without guarding any non-Resolution inference.
\end{theorem}
\begin{proof}
A selected set of guarded clauses is UNSAT iff its clauses from every guard block $\epsilon$, after setting $z=\epsilon$, contain an UNSAT original subformula. Therefore each block has at least $\mu(F)$ clauses, and repeating a minimum original core realizes $\mu(G_t(F))=2^t\mu(F)$. Every sound conservative at-most-binary-premise proof of an UNSAT source must depend on an UNSAT original source subset. Connectedness of the authenticated source-ancestry graph with $r$ sources and $q$ paid nodes gives $r+q-1\le E\le2q$, hence $q\ge r-1\ge\mu(G_t(F))-1$.
For each of the $s$ distinct original source identities actually used by $\pi$, independently resolve its $2^t$ guarded copies by a full guard-pivot binary tree, exactly $2^t-1$ legal Resolution nodes, obtaining that original clause verbatim. Replace each source occurrence in $\pi$ with this one derived clause; keep every original internal proof node, its type, and its sharing unchanged. Consistently rename original auxiliary variables away from guard variables. The constructed proof has exactly $s(2^t-1)+q$ distinct paid nodes and is complete. No semantic answer rule or hidden uncharged conversion is used.
\end{proof}
\begin{corollary}[nonamplification of source-floor excess]
For every clause-minimally UNSAT $F$ with $m$ indispensable clauses, define $e_R(F)=W_R(F)-(m-1)\ge0$. Then for every $t\ge0$,
\[
\boxed{0\le e_R(G_t(F))\le e_R(F),\qquad
m2^t-1\le W_R(G_t(F))\le m2^t-1+e_R(F).}
\]
\end{corollary}
\begin{proof}
All $m$ original clauses must occur in every sound refutation of minimally UNSAT $F$, so $s=m$. The guard core theorem yields $\mu(G_t(F))=m2^t$. Subtract the source-count floor $m2^t-1$ from both inequalities.
\end{proof}

\section*{Four falsifiers}
\begin{description}
\item[] F1 (\textbf{FALSIFIED}): repeated full guarding necessarily multiplies the source-floor excess of a hard input. The corollary proves excess never grows.
\item[] F2 (\textbf{FALSIFIED}): an optimal mixed proof must have AND3, XOR and DEF individually lifted into guarded form. Resolve guard copies of each source first and replay the mixed DAG unchanged.
\item[] F3 (\textbf{OPEN}): an arbitrary guarded mixed proof restricts at no cost to a proof of the original. Pure-Resolution restriction closure is known, but exact retyping after guard-pivot bypass and source-independent DEF gate-slot substitutions have not been fully checked in the common R. This report proves \emph{no} lower hardness-transport direction beyond the source core bound.
\item[] F4 (\textbf{FALSIFIED AS INFERENCE}): source count exponential in $t$ implies superpolynomial proof hardness relative to the input bits. The input itself contains $m2^t$ clauses.
\end{description}
