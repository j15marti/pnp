\paragraph{Target and obstruction.} D\"ocker's NP-complete canonical target consists of duplicate-free three-distinct-literal same-sign clauses, with exactly two positive and two negative occurrences per variable. A total decider must reject malformed strings. The precise question is whether deletion of complete original clauses and forgetting unused variables yields smaller recursive children still within this strict target language.
\begin{theorem}[Component-closure rigidity]
For every valid canonical formula $F$ with bipartite clause-variable incidence graph $G_F$, select any nonempty subset $J$ of original clauses, retaining their exact literal signs and source occurrences, and possibly densely renaming surviving variables. The resulting subformula is valid canonical Monotone 3-SAT-(2,2) if and only if $J$ is a union of entire connected components of $G_F$. In particular a connected valid source has no nonempty proper source-faithful deletion child.
\end{theorem}
\begin{proof}
If a clause is retained, each of its variables occurs in the child, which requires all two positive and two negative occurrences. The source already contains precisely these four occurrences, so all incident clauses must be retained. Propagating this obligation over incidence paths retains entire connected components. Conversely a union of components retains all original occurrences for each included variable, each original proper same-sign triple and clause uniqueness. Dense renaming preserves all required properties.
\end{proof}
\begin{theorem}[Hereditary both-label component solver]
If $F_1,\ldots,F_c$ are densely renumbered incidence components of a valid formula, then $\operatorname{SAT}(F)\iff\bigwedge_{i=1}^c\operatorname{SAT}(F_i)$. All child SAT witnesses reconstruct a complete parent witness by inverse coordinate maps. An original-source resolution refutation of any UNSAT child lifts under clause-index mapping to a parent refutation.
\end{theorem}
\begin{proof}Variables of distinct components are disjoint. All child clauses are unchanged parent clauses, so satisfaction factors and every source-indexed resolution step remains valid in the parent.\end{proof}
