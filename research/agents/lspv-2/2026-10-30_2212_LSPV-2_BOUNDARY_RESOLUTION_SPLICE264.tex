\section{Exact same-source theorem}
Let $F=\bigwedge_{i=1}^qF_i(B,X_i)$ be a finite original signed CNF whose original clause indices partition into authenticated owners, with disjoint private variable sets $X_i$ and a common original-variable interface $B$. Obtain that partition by scanning and checking the actual source, not by trusting separately indexed literal occurrences. Completely eliminate every variable in $X_i$ by Davis--Putnam resolution, retaining all non-tautological resolvents and all untouched clauses, to produce $R_i(B)$. Index each derived clause by original source leaf or an ordered pair of earlier clause nodes and a pivot. Define the physically serialized DIMACS child $G(B)=\bigwedge_i R_i(B)$.
\begin{theorem}
For every coherent assignment $\beta:B\to\{0,1\}$,
\[
G(\beta)\ \Longleftrightarrow\ \exists X_1,\ldots,X_q\,F(\beta,X_1,\ldots,X_q).
\]
Thus $\operatorname{SAT}(G)\iff\operatorname{SAT}(F)$. A child YES assignment extends to a full coherent source witness, checked against every original clause. Any complete ordinary resolution refutation of the child can be inlined with the corresponding source-axiom derivations of each child clause to produce a complete resolution refutation using only original source clauses. An exhausted bounded elimination cannot commit an incomplete projected child and must retain the parent for a total exact fallback.
\end{theorem}
\begin{proof}
Write the pivot-bearing clauses of a component as $(x\vee A_p)$ and $(\neg x\vee B_q)$. At any assignment to the other variables, a compatible value of $x$ exists precisely when no $A_p$ and $B_q$ are simultaneously false, which is exactly the conjunction of all $A_p\vee B_q$. Repeating gives $\exists X_i F_i\equiv R_i$ pointwise on $B$. Because the private variable sets are disjoint, the existential quantifiers distribute across the owner conjunction. Each DP-derived resolvent is a source-entailed clause with a fully indexed ordinary resolution derivation. Substituting these sub-DAGs for the child axioms in a child empty-clause proof yields an original-source empty-clause proof, independent of SAT versus UNSAT status. Conversely, for a satisfying $\beta$, solve each source owner with that fixed $\beta$, unite the disjoint private witnesses, and check every original source clause. A partial elimination cannot justify removing all parent clauses unless all pivot combinations were processed, so a timed-out transaction makes no UNSAT assertion and falls back to a complete exact source solver.\end{proof}
\paragraph{Limits.} This is classical bucket/Davis--Putnam elimination and source proof composition. Complete DP may have exponential clause growth; separator acquisition is not free. The emitted child is ordinary CNF, not necessarily width-three or strict signed exact-(2,2). Source proof size and work can be very large. It is not a universal contraction.
