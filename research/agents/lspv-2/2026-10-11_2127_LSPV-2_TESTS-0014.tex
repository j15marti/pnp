\section{Primary-literature barrier preflight}

The two blocking obstacles are (i) transfer out of the query model and (ii)
conversion of a polynomial access floor into a model-matched forbidden
endpoint.  Jain, Klauck, and Santha prove optimal direct-sum theorems for
deterministic and randomized \emph{decision trees}, where cost is the number
of queried input positions \cite{JKS2010}.  That theorem is directly
transferable only to the declared query model.  Mande, Sanyal, and Sherif show
that non-adaptive decision-tree and one-way communication measures can have
exponential gaps for AND composition \cite{MSS2021}; this is direct evidence
against an automatic query-to-communication lift, although their function
class is not this SAT family.  Fortnow--Lipton--van Melkebeek--Viglas give
genuine SAT time-space lower bounds in a specifically defined computational
model \cite{FLMV2005}; no theorem located converts LB-0018's promise query
bound into their hypotheses.

\section{Exact promise family and quantifiers}

Let $Y$ be the satisfiable equal-size H$_{2,2}$ macroblock and $U$ the
unsatisfiable equal-size macroblock from LB-0018.  Their fixed local encodings
have a differing position $d$.  For $k\ge1$ and $s\in\{0,1\}^k$, let
\[
 F_{k,s}=B_{s_1}\wedge\cdots\wedge B_{s_k},\qquad B_1=Y,\ B_0=U,
\]
with disjoint variables and block-concatenated indexed encoding.  Then
\[
 F_{k,s}\in\SAT\quad\Longleftrightarrow\quad \AND(s)=1,
 \qquad N(k)=\Theta(k\log k).
\]
LB-0018 proves
\[
 \forall A\ \forall k\ge1:\quad
 A\text{ total exact deterministic bit-probe SAT decider}
 \Longrightarrow T_A(F_{k,1^k})\ge k.                 \tag{1}
\]
The statement below uses the same family, encoding, and local differing
positions; no semantic family is substituted.

\section{The separation theorem}

\paragraph{Theorem (\texttt{BLOCK-PROBE-STATE-COMM-SEPARATION1}).}
For every $k\ge1$ there is a deterministic exact decider $D_k$ for the promise
set $\{F_{k,s}:s\in\{0,1\}^k\}$ such that:
\begin{enumerate}
\item $D_k$ probes only the position corresponding to $d$ in successive
blocks and stops at the first $U$;
\item on $F_{k,1^k}$ it performs exactly $k$ probes, meeting (1);
\item it uses one semantic accumulator bit and $O(\log k)$ bits for its block
index and random-access address;
\item across every two-party partition of the blocks, the value is computed
with one communicated bit; and
\item it constructs neither a satisfying assignment nor a compatibility,
reconstruction, or proof object.
\end{enumerate}

\paragraph{Proof.}
The queried local bit distinguishes the two fixed templates.  Maintain
$a\leftarrow1$ and replace $a\leftarrow a\wedge s_i$ after querying block
$i$.  Output zero immediately if $a=0$, else output one after block $k$.
Correctness is the displayed AND identity.  The all-YES input forces all $k$
queries, while $a$ is one bit and the counter/address needs $O(\log k)$ bits.
For a partition $S,\bar S$, Alice sends $\bigwedge_{i\in S}s_i$ to Bob, who
ANDs it with $\bigwedge_{i\in\bar S}s_i$.  This is one bit.  The algorithm's
only semantic update is the accumulator, so the claimed extracted-object
counts are zero. \hfill$\square$

This is a SAME\_REALIZATION result: the $k$ probes and small state occur in
the same direct program on the same encoded inputs.  The communication claim
is a separate declared block-partition interface, not a hidden inference from
the execution trace.

\paragraph{Corollary (\texttt{STATIC-RECOGNIZER-WRAPPER1}).}
Assume there is a uniform deterministic polynomial-time total SAT decider
$A$.  Then there is such a total decider $W$ that, on this promise island,
uses $O(N)$ recognition time, $O(\log N)$ working space, and no compatibility
object: stream-compare each block with the constant templates $Y,U$; if every
block matches, compute their AND; otherwise invoke $A$.  The recognizer is
exact and uniform because the templates are fixed.  This is a conditional
construction under $\SAT\in P$, not an unconditional SAT algorithm.  It
falsifies any purported implication
\[
 \SAT\in P\Longrightarrow
 \forall A\in\mathrm{PolySAT}\ \exists k:\
 \operatorname{space}_A(F_{k,1^k})=\Omega(k)
\]
or its compatibility-extraction analogue.

\section{Collision/lossiness audit}

For the decision map $L(s)=\AND(s)$,
\[
 |L^{-1}(1)|=1,\qquad |L^{-1}(0)|=2^k-1,
\]
so the exact collision count is
\[
 \operatorname{Coll}(L)=(2^k-1)^2+1.
\]
The Cauchy--Schwarz image bound from the project ledger yields only
\[
 |\operatorname{im}L|\ge
 \frac{|\{0,1\}^k|^2}{\operatorname{Coll}(L)}
 =\frac{4^k}{(2^k-1)^2+1},
\]
which approaches one, while the actual image has size two.  Thus the full
collision distribution certifies extreme lossiness: $k$ independently
discriminated blocks collapse to one decision bit.  This is an
\textbf{EXACT OBJECT/THEOREM TRANSFER} of the ledger's lossiness object, not a
cryptographic assumption.

Schur squares, quadratic relation ranks, Hilbert functions, and syzygies are
\textbf{FAILED TRANSFER} for this barrier: the selector AND is already exposed
and the missing theorem concerns arbitrary computation, not hidden code
structure.  Worst-case/average-case and special-soundness ideas remain
\textbf{ANALOGY/CANDIDATE needing a new bridge}; neither supplies an
unconditional solver-to-resource compiler.  Random-oracle and binding
assumptions are inadmissible here.

\section{Hostile controls}

The same selector AND was checked for labels corresponding to 2SAT, Horn,
affine/Tseitin Gaussian-elimination, bounded-treewidth, and independent-product
controls.  These labels are semantic controls, not claims that all encodings
share an implementation: in every case independently solvable blocks compress
to one accumulator bit.  DIRECT, COPY, DEAD, DELAY, INTERP, and RECOMP wrappers
all preserve the decision; a wrapper may inflate trace state, but the direct
program witnesses the failure of a universal lower bound.

Block and within-block permutations preserve one discriminating location per
block after the locator is changed.  Padding and redundant clauses can enlarge
$N$ without adding selector information, so a representation-invariant
$\Omega(N)$ claim is false.  A trusted answer annotation collapses the promise
decision to one probe; an untrusted annotation must be verified by a total SAT
decider, so no total-SAT collapse is claimed.  Affine elimination and other
semantic shortcuts reinforce, rather than repair, the missing transfer.

\section{Barrier, relativization, and proof-system audit}

The proof relativizes because it is a fixed-template promise argument.  Hence
it cannot by itself evade the Baker--Gill--Solovay barrier.  It neither
arithmetizes nor supplies a non-algebrizing step, and it establishes no circuit
lower bound, proof-system lower bound, or Natural-Proofs-sensitive property.
The one-bit output prevents any inference from the number of semantic inputs
to the number of exposed internal states.

The remaining load-bearing arrow is exactly:
\[
 \begin{array}{c}
 \boxed{\text{every uniform polynomial-time total SAT decider}}\\[3pt]
 \Downarrow\\[3pt]
