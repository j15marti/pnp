\section{Two explicit exact normalizers}
A valid \emph{closed scoped stream} opens a named variable exactly once, emits its original signed clauses while the names are live, then closes each name exactly once. Its SAT status is the existence of one compatible global named-variable assignment. All output bytes, source access, index arithmetic, recognition, changed and unchanged writes, control and caches count toward work; output streamed to a consumer cannot be reread for free.

\begin{theorem}[Source-order scope compilation]
For any properly encoded ordinary proper 3CNF $F$ in its given clause order, open each variable immediately before the first clause in which it appears, emit every original clause, and close each variable immediately after its last containing clause. This yields a closed event stream $E(F)$ with exactly $m+2k$ events, encoded length $\Theta(N)$, and $\SAT(E(F))=\SAT(F)$. Its maximum width is the maximum number of first-to-last source occurrence intervals crossing any event boundary. There is a uniform eager transducer with $O(N\operatorname{polylog}N)$ bit work and $O(k\log(m+2)+\log N)$ writable bits; a uniform source-replay transducer emits exactly the same stream with $O(N^2\operatorname{polylog}N)$ bit work and $O(\log N)$ writable bits.
\end{theorem}
\begin{proof}
Every occurrence lies between its unique open and close events, and every original clause is copied with exactly the same signed named variables. A satisfying source assignment induces compatible frontier valuations, while a compatible event valuation satisfies every copied clause. The event count is one per clause plus two per occurring variable. In a dense indexed encoding each name, sign and tag occupies $O(\log(k+m+2))$ bits, giving linear-order encoded length. Eager mode scans all literal positions to store each name's first/last clause indices and streams its events. Replay mode, for each current literal position, rescans all prior clause fields to determine first appearance and all later fields for last appearance, holding only a constant number of $O(\log N)$ counters/identifiers. At most $O(m^2)$ indexed field visits and polylogarithmic bit-level arithmetic are needed. The output is one-way; a delayed output tape is not an uncharged guest input. A reference Python implementation uses more memory than the claimed streaming machine because it materializes the event list for auditing.
\end{proof}

\begin{theorem}[Sign-sorted M22 full frontier]
If all positive clauses of any $F\in\CM$ precede all negative clauses, the source-order event stream has maximum width
\[
\boxed{w(E(F))=k=\Theta(N/\log N).}
\]
\end{theorem}
\begin{proof}
Every active variable appears in two positive clauses before the cut and two negative clauses after it, hence each original name must be simultaneously open at that cut. No stream can have more than the $k$ available source names. This holds independently of SAT/UNSAT label.
\end{proof}
\noindent This theorem is specific to the named source order and compiler, \emph{not} a lower bound on every clause order, representation, decision algorithm or rewriting.

\section{A model-matched no-go corollary, not an all-input contraction}
A valid supplied closed stream of encoded length $M$ and live width $w$ has a direct frontier dynamic program with $O(M2^w\operatorname{polylog} M)$ bit work and $O(2^w\operatorname{polylog}M)$ writable bits: opening duplicates the assignment coordinate, a clause filters rows, and closing existentially projects a coordinate. Source-name compatibility is exact by construction. This is a positive restricted upper bound.

\begin{theorem}[FLMV streaming-normalization firewall]
Suppose one fixed uniform total exact SAT-preserving transformer processes \emph{all ordinary SAT inputs} of length $N$, rejects invalid encodings, and generates a \emph{valid closed scoped ordinary 3CNF stream} directly to the frontier DP, without free advice, semantic oracles, output storage or preprocessing. Suppose generator and consumer use the same FLMV indexed read-only-input random-access Turing model and jointly satisfy generator work $N^{a+o(1)}$, generator writable/index space $N^{s+o(1)}$, emitted stream length $M\le N^{b+o(1)}$, and maximum width $w\le \gamma\log_2N+o(\log N)$. Then one fixed exact total ordinary-SAT machine has simultaneous exponents
\[
\boxed{(t,s')\le\bigl(\max\{a,b+\gamma\},\,\max\{s,\gamma\}\bigr)}
\]
up to $o(1)$ terms. Therefore such a transformer cannot satisfy jointly
\[
\boxed{\max\{a,b+\gamma\}<241/200,\qquad
\max\{s,\gamma\}<11642479/23232400.}
\]
\end{theorem}
\begin{proof}
Run the generator and interrupt its one-way emission to update the frontier DP immediately. Both retained states coexist; generator work plus $M2^w\operatorname{polylog}N$ DP operations bounds total time, while generator space plus $2^w\operatorname{polylog}N$ DP cells bounds simultaneously live writable/index bits. The exact final DP bit is the SAT label on \emph{every} ordinary input by hypothesis. Strict simultaneous inequalities would contradict FLMV \cite{flmv}, Theorem 3.1 and Corollary 5.8, where $\beta(c)=((c+2)/c^2-c)/2$ and $\beta(241/200)=11642479/23232400>1/2$.
\end{proof}
\noindent The theorem recovers an impossibility already implied by the known endpoint. It does \emph{not} prove that an arbitrary decider must read, store, enumerate or materialize such a stream. A $\CS$-only improvement does not enter the ordinary-SAT FLMV region absent a paid fine-grained transport. No original HEREDITARY-SCOPED10 all-input contractor is inferred.
