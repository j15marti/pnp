Falsify by adversarial permutations of proper exact22 components. \textbf{FALSIFIED as a universal claim}, via Theorem~\ref{th:oracle}.
\item[] \textbf{H2.} The canonical fixed-incidence disjointness source should evade H1 with an arithmetic locator that uses no stored occurrence array and only two signed input reads. \textbf{PROVED/EXACT, image-scoped}, Lemma~\ref{lem:fixed}.

\section{The original gadget and the two distinct physical representations}
Use the authentic 15-variable, 20-clause proper signed exact-$(2,2)$ UNSAT source $W_1$ in \path{experiments/review/early22_compiler_redteam_audit.py}.  The two \emph{separate} opposite-sign swaps in the project's \texttt{BINARY-WORK-SAT4} source are $A=\{(6,0),(11,0)\}$ on source name 4, and $B=\{(17,2),(9,2)\}$ on source name 15, with zero-based clause/literal coordinates.  Let $H(a,b)$ flip both $A$ occurrences iff $a=0$ and both $B$ occurrences iff $b=0$.  Direct exhaustive enumeration gives
\[
\#\mathrm{models}(H(0,0))=772,\quad
\#\mathrm{models}(H(0,1))=272,\quad
\#\mathrm{models}(H(1,0))=272,\quad
\#\mathrm{models}(H(1,1))=0.
\tag{1}
\]
Each $H(a,b)$ has 15 names and 20 distinct, three-name clauses, with exactly two positive and two negative occurrences of every name.  It is generally \emph{not} clause-monotone.  The separately published $Q=W_1\setminus\{(x_1\vee x_7\vee x_{13})\}$ has 19 clauses and three forced-false ports; it is \emph{not} used as the complete 20-clause component here.

Fix the bit representation: $w=(20k).\mathrm{bit\_length}$, sixteen constant magic bits, a $w$-bit variable count $15k$, a $w$-bit clause count $20k$, followed by three literals per clause, each using one sign bit and $w$ identifier bits.  Both physical families below have exactly
\[
N_k=16+2w+60k(w+1)=\Theta(k\log k)
\tag{2}
\]
bits, including the complete header. A malformed bit string is not silently equated to an UNSAT formula. Literal identifiers are distinct inside each clause and dense over all $15k$ names.

\paragraph{Unknown block-order input.}
For a permutation $\pi$ of $\{0,\ldots,k-1\}$ and one chosen $H\in\{H(0,0),H(1,1)\}$, define
\[
F_{k,\pi,H}=\bigwedge_{p=0}^{k-1}
   H[x_j\mapsto x_{15\pi(p)+j}],
\tag{3}
\]
with the 20 clauses of block $p$ serialized consecutively.  The header does not contain $\pi$. Every $F_{k,\pi,H(0,0)}$ is SAT; every $F_{k,\pi,H(1,1)}$ is UNSAT.  Signed exact quotas, properness and distinctness are invariant under the permutation.  No SAT-hardness inference follows from these deliberately easy products.

\paragraph{Fixed three-zone input.}
For $a,b\in\{0,1\}^k$, define $D_k(a,b)$ as the same 20 clauses per component but ordered in three physical zones: first all two $A$-controlled clauses from each component, then all sixteen fixed clauses from each, finally all two $B$-controlled clauses from each.  Exactly as in HEADMOVE-1,
\[
\SAT(D_k(a,b))\iff\bigwedge_{i=0}^{k-1}\neg(a_i\land b_i).
\tag{4}
\]
The middle fixed zone contains $16k$ of $20k$ clauses.  This ordering is special and is part of the promise; it cannot be assumed for an arbitrary exact22 string.

\section{No-preprocessing inverse lower bound}
Write $\Sel_F(v,r)$ for the $r$th physical occurrence $(c,\mathrm{slot},\mathrm{sign})$ of name $v$ in clause-list order, $0\le r<4$.  Grant an algorithm a generous \emph{block identity oracle}: one query to any physical block $p$ reveals all 20 clauses in that block and hence its labeled component identity $\pi(p)$.  This oracle is at least as informative per touched block as arbitrary indexed \emph{bit} probes to the original encoding.

\begin{theorem}[Unordered exact22 occurrence inversion; \textbf{PROVED/EXACT, restricted}]\label{th:oracle}
For each $k\ge2$ and each fixed $H\in\{H(0,0),H(1,1)\}$, every deterministic total algorithm that, on all inputs $F_{k,\pi,H}$, outputs $\Sel_{F_{k,\pi,H}}(x_1,0)$ must on some input inspect at least $k-1$ distinct physical component blocks, even when a whole-block identity is returned in one unit-cost oracle call.  Thus an indexed bit-query algorithm without preprocessing or supplied permutation/incidence metadata needs $\Omega(k)=\Omega(N_k/\log N_k)$ physical source-bit probes in the worst case for this single inverse-location request. This holds separately with every formula SAT and with every formula UNSAT.
\end{theorem}
\begin{proof}
The target name $x_1$ occurs exactly four times, all in the unique physical component whose label is $0$.  Its first occurrence's physical clause address varies with that component's position.  Give the algorithm the maximum-information block oracle described above.  An adversary answers the first $k-2$ distinct queried blocks with distinct labels from $\{1,\ldots,k-1\}$.  If the algorithm now stops, at least two unqueried block positions remain.  Complete the unobserved permutation in two ways by exchanging the positions carrying label $0$ and one other remaining label. Both valid inputs have identical headers and agree \emph{bit for bit} in every inspected block, yet the required physical $\Sel(x_1,0)$ differs.  Therefore the algorithm cannot halt correctly.  In the worst case it must inspect $k-1$ blocks; the final unqueried label may then be inferred.  The proof applies separately to either fixed local gadget $H$, so it does not mix SAT and UNSAT complexity.

Every physical bit probe lies either in the fixed header or in one block. Simulate an arbitrary bit-query algorithm with the stronger block oracle, querying a block the first time any bit of it is requested and answering all subsequent probes from that block's content. If fewer than $k-1$ distinct blocks had been touched, this would contradict the block-oracle bound.  Since $N_k=\Theta(k\log k)$, the stated bit-query lower bound follows. No assumption on writable workspace or an output circuit family was used.
\end{proof}

The matching sequential full-block search has worst-case $k-1$ queries.  Under a uniformly random permutation its mean number is exactly $(k-1)(k+2)/(2k)$ for $k\ge2$, because it stops upon finding label zero or infers the last label. These are \emph{inverse-access} costs. They do not lower-bound SAT decision time: the all-SAT and all-UNSAT family restrictions above are trivially classified once the family choice is known.

\section{An exact uniform exception with a canonical source}
For a local name $j\in\{1,\ldots,15\}$ let the fixed 20-row ROM list
\[
L(j)=\{(h,q): 0\le h<20,0\le q<3,
       |W_1[h,q]|=j\},\qquad |L(j)|=4.
\tag{5}
\]
Write $v=15i+j$. In the fixed three-zone representation, the zero-based physical clause index of original local row $h$ is
\[
 c(i,h)=\begin{cases}
 2i+\operatorname{rank}_{(6,11)}(h),&h\in A,\\
 2k+16i+\operatorname{rank}_{\mathrm{FIXED}}(h),&h\notin A\cup B,\\
 18k+2i+\operatorname{rank}_{(17,9)}(h),&h\in B.
 \end{cases}
\tag{6}
\]
The sign comes from the authentic pair-flip $H(a_i,b_i)[h,q]$. Its physical sign-bit address is
\[
 p(i,h,q)=16+2w+3(w+1)c(i,h)+(w+1)q.
\tag{7}
\]

\begin{lemma}[Four-occurrence arithmetic Rank/Select; \textbf{PROVED/EXACT under the image promise}]\label{lem:fixed}
For every $k\ge1$, every canonical signed source $D_k(a,b)$, every name $v\in[15k]$ and every $r\in\{0,1,2,3\}$, the ordered signed $\Sel(v,r)$, its inverse $\Rank(v,c,q)$, and its physical polarity-bit location can be produced from (5)--(7) with \emph{at most two} indexed input-bit probes, $O(\log^3 N_k)$ bit operations, and $O(\log N_k)$ live work/index bits.  The fixed ROM has only 20 rows and 60 literal fields.  No incidence array, W1 assignment search, generated child string, or source-solving call is allowed or required.
\end{lemma}
\begin{proof}
Use logarithmically sized arithmetic registers to find $i=\lfloor(v-1)/15\rfloor$ and $j=1+(v-1\bmod15)$.  Scan the fixed 60 literal fields to enumerate $L(j)$ and map each row to its physical position via (6), then sort the four triples by the physical clause/slot pair.  Read precisely the $A_i$ and $B_i$ anchor polarity bits.  They determine both corresponding paired sign flips, while all other signs are fixed by the W1 ROM.  Emit the chosen quadruple and address (7), writing each output bit, and return the position of a queried pair or $\bot$ for Rank.  The ROM occupies fixed program control; a constant number of $O(\log N_k)$-bit registers are live.  Schoolbook arithmetic and index writing cost at most $O(\log^3N_k)$ bit operations.  At most two physical input source bits are read, and each read writes its $O(\log N_k)$-bit index.  The proof depends on the source being in the declared fixed layout, unlike Theorem~\ref{th:oracle}.
\end{proof}

The promise cannot be extended by simply declaring noncanonical physical strings UNSAT.  Checking exact canonical membership may require examining every position: the previously established image-code distance is $d_H(D_k(a,b),D_k(a',b'))=2d_H(a,a')+2d_H(b,b')$, so any single bit flip of a valid encoding is noncanonical.  A total deterministic bit-query image recognizer therefore must inspect every physical bit of an \emph{accepted} canonical input. An explicit streaming full-template validator takes $O(N_k\operatorname{polylog}N_k)$ bit time and $O(\log N_k)$ writable/index bits.  Neither result handles an arbitrary well-formed ordinary-SAT source outside this image.

\section{A small full-length promise circuit is not a SAT decision circuit}
On the \emph{canonical-image promise only}, equation (4) has a direct typed netlist: $k$ AND gates on the $2k$ anchor inputs, then $k-1$ OR gates joining those AND outputs, and one final NOT gate.  The exact count is
\[
 G_k=2k,\qquad W^{\mathrm{primary}}_k=2k,\qquad
 W^{\mathrm{signal}}_k=4k,\qquad E^{\mathrm{operand}}_k=4k-1,
 \qquad L_{\mathrm{output}}=1.
\tag{8}
\]
Here $W^{\mathrm{signal}}$ denotes distinct primary and gate-output \emph{nodes}, and $E^{\mathrm{operand}}$ is the number of gate-input references.  Neither count is identified with the number of physical tape cells.  A gate descriptor is computed arithmetically from its index in $O(\log^3 N_k)$ bit operations and logarithmic index space. If the fixed-width operand-reference description is \emph{explicitly emitted}, it already writes at least
\[
(4k-1)\left\lceil\log_2(4k+1)\right\rceil
=\Theta(k\log k)=\Theta(N_k)
\tag{9}
\]
bits, and retaining those descriptors consumes that many cells. A virtual indexed accessor saves \emph{storage} but every call/bit read is charged; evaluating the boolean disjointness directly by a streaming accumulator instead uses $O(\log N_k)$ index bits and $2k$ actual source-anchor probes.  These are different implementations and must never share the favorable time bound of one with the space bound of another.

The netlist (8) agrees with SAT only \emph{on the stated canonical promise}. It is not $C_{A,N}$, the deterministic full ordinary-SAT decision circuit for all $N$-bit encoded inputs. The fixed $(2,2)$ padding/regularizer under current study enlarges the output and retains the specific Role-4 pinned floor $m_2\ge33856B$; nothing here is an ARC contraction or a $q=1.29$ full-decision compressor.

\section{HEADMOVE-1 jump firewall and dual TM resource ledgers}
A target-only radius-$J$ input jump can pass over the entire fixed middle gap without ever landing in an interior gap cell. Its no-visit crossing trace cannot be spliced as an ordinary one-cell crossing sequence.  This does \emph{not} invalidate the original sequential-input crossing theorem; it invalidates its direct transfer to a different augmented instruction set.

\begin{lemma}[Charged interpolation; \textbf{CONDITIONAL on the HEADMOVE-1 sequential theorem}]\label{lem:jump}
Let $M_J$ have one read-only input head capable of a charged jump of radius at most $J(N)$, reading only its landing-cell symbol, and fixed $k$ sequential work tapes. A uniform compiler simulates any such run of $T_J$ steps and visited-work-cell space $S_J$ on an ordinary one-sequential-input-head machine in
\[
 T_{\rm seq}=O\!\left(T_J(J+\operatorname{polylog}(N+T_J))\right),\qquad
 S_{\rm seq}=O(S_J+\log(N+T_J)),
\tag{10}
\]
including the offset bits and step-by-step head movement.  Provided the native sequential theorem $T_{\rm seq}(S_{\rm seq}+1)=\Omega(N^2/\log N)$ applies to the same fixed easy exact22 SAT-promise family, polynomial exponents $T_J=N^{t+o(1)}$, $S_J=N^{s+o(1)}$, $J=N^{j+o(1)}$ necessarily satisfy $t+s+j\ge2$.
\end{lemma}
\begin{proof}
Store the signed offset and remaining-distance counter in $O(\log(N+T_J))$ work bits and replace a jump by at most $J$ ordinary source-head moves plus polynomial-logarithmic bookkeeping.  Read only the intended target bit; work tape operations and all simulated decisions remain unchanged. Charging all transitions yields (10). Apply the model-specific native lower bound to this \emph{one simulated run}, and substitute the resource ceilings.  The logarithmic factor is $N^{o(1)}$.  Nothing in (10) conserves a native $M_J$ gap-crossing sequence or an $M_J$ reversal count, and no indexed-work RAM theorem follows.
\end{proof}
