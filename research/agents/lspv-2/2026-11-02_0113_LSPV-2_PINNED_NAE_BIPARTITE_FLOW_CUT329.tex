\section*{Exact theorem and proof}
Suppose every positive source triple $(a,b,c)$ has exactly the negative counterpart $(-a,-b,-c)$. The positive clause IDs become vertices of a cubic multigraph $G_F$; an original variable is the graph edge joining its two positive occurrences. Assigning that variable true means selecting the edge. At each dual vertex, the complementary original pair is satisfied exactly if its selected true-edge degree is 1 or 2. With a coherent original pin map $p$, write $t_v$ for pinned true incident edges and $r_v$ for unpinned incident edges. Set $\ell_v=\max(0,1-t_v)$ and $u_v=\min(r_v,2-t_v)$.

\begin{theorem}
For every canonical complemented-pair original $F$ with a bipartite dual graph, and for every coherent original-variable pin map $p$, $F|p$ is SAT iff the following integral lower-bounded circulation exists. Send $s\to v$ with interval $[\ell_v,u_v]$ to each left vertex, free original edges left-to-right with interval $[0,1]$, each right vertex $v\to t$ with $[\ell_v,u_v]$, and $t\to s$ with $[0,n]$. The algorithm either checks an original-source SAT witness, returns a source-clause-local contradiction when $\ell_v>u_v$, or supplies a finite directed node subset $S$ satisfying
\[
 \sum_{a\in\delta^-(S)}\ell_a>
 \sum_{a\in\delta^+(S)}u_a
\]
as a complete UNSAT certificate. All acquisition, flow construction, maximal-flow failures, source reads and checking are polynomial. A Dinic realization on its $O(n)$-node and $O(n)$-arc network has $O(n^3)$ word-operation upper bound and $O(n\log n)$ explicit logical-bit storage. Machine-index/head and guest time may add polynomial overhead.
\end{theorem}
\begin{proof}
At each positive-clause source vertex the positive original clause needs at least one true incident edge, while its exact negative counterpart needs at least one false incident edge. Thus $1\le\deg_{\rm true}(v)\le 2$ is necessary and sufficient. Subtract pinned true edges and keep only free edges to obtain $[\ell_v,u_v]$. An integral circulation assigns one true bit to each selected original-variable free arc, and conversely each original satisfying completion yields such a circulation with a return flow. Integrality of network flows supplies integral variables. The standard lower-bound feasible-circulation reduction to maximum flow is complete. If it fails, super-source residual reachability yields $S$ with the strict lower-incoming versus upper-outgoing inequality. Any circulation has equal inflow and outflow on $S$, which contradicts that inequality. The certificate can be checked from signed source IDs without a SAT-label oracle.
\end{proof}
