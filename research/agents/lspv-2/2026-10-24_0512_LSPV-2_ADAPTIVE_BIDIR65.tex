\section{Question and falsifiable mechanisms}
We test whether a state-adaptive SAT solver may repeatedly change representations while retaining exact shared source variables, and whether the work of one reverse-DP representation must transfer to all deterministic SAT deciders. It need not. Three explicit mechanisms: M1, binary source implications release an affine residual (PROVED/EXACT restricted and tested); M2, an affine subsystem in which each variable occurs in exactly two parity equations admits linear graph continuation (KNOWN THEOREM, implemented with complete source compatibility); M3, a fixed-policy DPLL or complete residual-service cost forces every decider to pay the same (FALSIFIED/RETIRED as an inference, not as a formal complexity hypothesis).

Fix a uniform computable policy over state
\[
S_i=(F_i,\alpha_i,L_i,\mathcal C_i,\mathcal M_i,B_i,\mathcal R_i).
\]
These denote the source-preserved residual CNF, original-source partial assignment, learned information, component structure, cache, remaining budget, and current representation. A structural parameter trajectory
\[
p_i=(n_i,m_i,k_i,b_i,h_i,a_i,c_i,\rho_i)
\]
counts residual variables, clauses, genuine ternaries, binary clauses, recognized Horn and affine flags, components, and acquired parity rank. No parameter is defined by runtime. A flag/rank is available to the policy only after its recognition/computation has been charged. SAT and UNSAT may terminate at different stages; the label is not a policy input.

Backward circuit output TRUE implies all clause ORs TRUE. It suffices to select one true literal occurrence per clause, consistent on each original source variable; the original clause is not an exactly-one relation. Source assignments and final witness occurrences are reconstructed only when useful. The total forward/reverse ledger is the sum of charged source access, recognition, failed tests, policy evaluation/switching, representation construction, continuation, memory and verification. This accounting identity does not itself imply any lower bound.

\section{Exact parity graph theorem and proof}
\begin{theorem}[PROVED/EXACT for the declared equation representation]
Consider equations $\bigoplus_{e\in\partial v}x_e=b_v$ over $\mathbb F_2$, where every original source variable $x_e$ appears in exactly two \emph{distinct} equations. Regard equations as graph vertices and variables as graph edges. The system is satisfiable if and only if
\[
\boxed{\bigoplus_{v\in C}b_v=0\quad\text{for every connected component }C.}
\]
A source-coherent solution, when it exists, is constructible in $O(|V|+|E|)$ word operations after equation acquisition.
\end{theorem}
\begin{proof}
XOR all equations in one connected component: every original variable occurs twice and cancels, so the component charge XOR must be zero. Conversely choose a spanning forest, set all non-tree variables zero, process nonroot vertices from leaves to roots, and set the parent-edge variable to satisfy each processed row, updating the parent charge. The remaining root charge is the XOR of the initial component charges and hence vanishes. No variable can be assigned inconsistently because every edge is assigned once. Adjacency construction and forest processing are linear.
\end{proof}
In proper 3-CNF, a \emph{complete} parity quartet comprises exactly four distinct signed clauses on the same three original variables; their four forbidden assignments share one parity, and the opposite parity is enforced. The recognizer must check all four source clause records before replacing them by an equation. Failed quartets remain source CNF and cause the general exact fallback, not an unsound shortcut. If graph-incidence recognition fails, verified affine equations can instead be solved by Gaussian elimination.

\section{Scalable adversarial SAT/UNSAT family}
For $q\ge4$ define a 3-regular bipartite graph with vertices $L_i,R_i$, $i$ modulo $q$, and edges $(L_i,R_i)$, $(L_i,R_{i+1})$, $(L_i,R_{i+\lfloor q/2\rfloor})$. There are $2q$ equation vertices and $3q$ edge variables. Encode each 3-edge parity equation with its four proper ternary clauses. For $F_q^+$ set every charge zero. For $F_q^-$ flip exactly the charge at $L_0$. Their source identifiers, unsigned supports, clause counts and bit lengths match. Include two binary clauses $(g\vee x_1),(g\vee\neg x_1)$, which force the original source variable $g=1$ with no root unit clause. Also include an independent Horn component
\[
(\neg h_1\vee\neg h_2\vee h_3)
\wedge(\neg h_3\vee\neg h_1)\wedge(\neg h_3\vee\neg h_2)
\]
and 2-SAT component $(u\vee v)\wedge(\neg u\vee\neg v)$. All displayed variables are original sources, with no SAT auxiliary variables. With $w=\lceil\log_2(64(n+m+1))\rceil$ and fixed four-word clause records,
\[
\boxed{n=3q+6,\quad m=8q+7,\quad k=8q+1,\quad m_2=6,\quad N=(32q+30)w.}
\]
An assigned-source evaluator needs $16q+8$ OR2 gates, $8q+6$ AND2 gates, and $48q+28$ directed gate-input wires. These are evaluation-circuit counts, not SAT-solving circuit lower bounds.

\begin{theorem}[PROVED/EXACT restricted family, peer review pending]
For all $q\ge4$, $F_q^+$ is SAT and $F_q^-$ is UNSAT. A uniform adaptive source-aware solver performs binary implication closure, exact component separation, parity-quartet recognition, and graph-incidence forest solving, then where necessary Horn least-model and SCC-based 2-SAT. On these inputs it makes zero search branches and uses $O(N)$ word time and $O(N)$ live logical words, including source checks and final SAT witness replay.
\end{theorem}
\begin{proof}
The guard pair implies $g=1$, discharging both binary clauses. The remaining residual has exactly the graph parity, Horn and Krom components. The parity system is inconsistent precisely when the XOR of its vertex charges is odd. Therefore $F_q^-$ is UNSAT. In $F_q^+$ all edge variables may be zero, with $g=1$, all Horn variables zero, and $u=1,v=0$. Exact group recognition, graph traversal, Horn propagation, SCC and source replay are linear in this explicit canonical family; no branching is called. The policy does not know the label before performing its recognitions.
\end{proof}
Each parity edge source occurs four times positively and four times negatively across its two quartets. Thus these formulas are \emph{not} strict signed exact-$(2,2)$ 3-CNF. In that distinct NP-complete language, each source occurs twice per sign; its occurrence conflict graph has $4n=3m$ vertices and $4n$ edges forming $n$ disjoint $K_{2,2}$ cycles. No hardness transfer between these classes is asserted.

\section{Adaptive ledger, comparator, and finite evidence}

A charged component test detects 32 parity clauses on twelve edge sources, three Horn clauses, and two Krom clauses. A quartet check yields eight equations, each source in two rows, and the spanning-tree graph solver returns SAT or an odd-syndrome UNSAT. The SAT path then visits Horn and SCC, and verifies all 39 original source clauses. The UNSAT path terminates on parity before those other components. The source-consistency and reconstruction costs are not omitted.
