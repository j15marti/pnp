\section{The exact reverse circuit and occurrence graph}
Let $F=\bigwedge_{j=1}^m(\ell_{j1}\vee\ell_{j2}\vee\ell_{j3})$ be proper 3-CNF over named original source variables $x_1,\ldots,x_n$. Build two OR2 gates per clause and an AND2 tree of the clause outputs. It has $g=3m-1$ binary gates and $2g=6m-2$ directed gate-input wire references, including $3m$ signed source occurrences.

A backward selector $s:[m]\to\{1,2,3\}$ chooses \emph{one witness occurrence} per clause. It is source-consistent if none of its chosen literals demands both signs of an original source variable. This does \emph{not} assert exactly one original literal in a clause is true.

\begin{theorem}[Source-coherent reverse selector, classical equivalence]
$F$ is satisfiable iff there exists a source-consistent selector. Given one, an actual satisfying source assignment can be reconstructed in $O(n+m)$ word operations, plus a complete source replay.
\end{theorem}
\begin{proof}
A satisfying assignment supplies one true occurrence per clause. Conversely, source-consistent selected literals specify noncontradictory values for their source variables; complete the remaining variables arbitrarily. Every clause contains its selected true occurrence.
\end{proof}

Functional Tseitin equivalences for all $g$ gates, with one output unit, use $g$ auxiliary trace variables and $3g+1=9m-2$ clauses of widths at most three. For each accepted primary-source assignment the gate traces have precisely one valid extension. Replacing binary clauses with independent free-literal padding can destroy that uniqueness and must be counted separately.

\begin{theorem}[Exact $(2^+,2^-)$ occurrence graph]
Assume that every original source variable occurs exactly twice with each sign. Then $4n=3m$. The complement-occurrence graph has $4n$ vertices and $4n$ edges and is precisely $n$ disjoint four-cycles $K_{2,2}$. Adding the $m$ clause triangles gives exactly $8n$ edges and degree four at every occurrence vertex. The resulting graph has an independent set of size $m$ iff $F$ is satisfiable. Every size-$m$ independent set contains one occurrence per clause.
\end{theorem}
\begin{proof}
Each variable's two positive and two negative occurrences form a $K_{2,2}$ with four complement edges. Each occurrence belongs to exactly one clause triangle. An independent set contains at most one occurrence per clause, so size $m$ picks precisely one from each; excluding complement edges is exactly the source consistency condition.
\end{proof}
This restricted graph family is \emph{not} arbitrary degree-four independent set. The classical 2-literal block analogue is solvable by 2-SAT SCC. The ternary exact-$(2,2)$ monotone class remains NP-complete by D\"ocker (2019); no running-time lower bound follows from degree counts.

\section{Constructive polynomial algorithm for paired monotone supports}
Define the \emph{paired monotone} grammar: every all-positive support triple occurs exactly once and the identical support occurs exactly once with all negative signs. Every original variable occurs in two \emph{distinct} paired supports. The paired supports are cubic-graph vertices and original variables are the edges connecting their two support vertices. Each vertex requires at least one and at most two incident TRUE edges, the NAE condition.

\begin{theorem}[Elementary maximal matching plus Hall; restricted PROVED/EXACT]
For every input in this explicitly recognized grammar, a uniform deterministic algorithm constructs a satisfying assignment in $O(n^2)$ word operations and $O(n+m)$ working words, including source replay.
\end{theorem}
\begin{proof}
Greedily take a maximal matching $M$ of the cubic source graph. Let $U$ be unmatched vertices and $W$ matched vertices. By maximality $U$ is independent. Every $u\in U$ has three incident edges to $W$, while every $w\in W$ has at most two edges to $U$, since one incident edge belongs to $M$. Hence for every $Z\subseteq U$, $3|Z|\le 2|N(Z)|$, so Hall's condition holds. An augmenting-path bipartite matching $D$ assigns each vertex of $U$ one incident edge ending at a distinct vertex of $W$. Mark exactly the original variable edges in $M\cup D$ TRUE, all other original variable edges FALSE. Each unmatched vertex has exactly one TRUE incident edge; each matched vertex has its one $M$ edge and at most one $D$ edge, thus one or two. The positive and negative signed support clauses are both true. Greedy matching and Hall augmentations require at most $O(n^2)$ time and linear memory. The algorithm reads and verifies actual original source identifiers and clauses.
\end{proof}

\paragraph{Hostile control.} Orienting each variable edge and treating its incoming endpoint as TRUE and its outgoing endpoint as FALSE is unsound: the endpoints share the \emph{same} variable and may not receive opposite values. The $K_4$ cubic graph supplies a six-variable, eight-clause proper paired input on which this defect is explicit; the matching algorithm instead produces a single coherent source assignment. Cube relabellings in the executable require actual Hall augmentation beyond the initial nonmaximum greedy matching.

\section{Mismatched supports and bipartite degree circulation}
For exact-$(2^+,2^-)$ inputs with $t$ unpaired signed clauses, let $S$ be all source variables mentioned in them. Then $|S|\le3t$. Enumerate its $2^{|S|}$ truth assignments, checking all unmatched clauses. Retain the correctly paired supports. Each support vertex $v$ has $p_v$ fixed TRUE incident variables and $d_v$ remaining variable edges. Its exact allowed number of TRUE free edges is
\[
 L_v=\max(0,1-p_v),\qquad U_v=\min(d_v,2-p_v).
\]
Every remaining variable outside $S$ occurs at exactly two paired supports, so remains one \emph{shared} edge, not two independent occurrence choices.

\begin{theorem}[Executable bipartite defect case, PROVED/EXACT restricted]
When the free-variable paired-support graph is bipartite, residual SAT is equivalent to an integral feasible circulation with vertex degree intervals $[L_v,U_v]$. Consequently these checked inputs admit a uniform source-replayed $O(2^{3t}\mathrm{poly}(N))$ decision algorithm, including all failed branches, construction and verification.
\end{theorem}
\begin{proof}
For left support vertices create source-to-left arcs with interval $[L_v,U_v]$, each shared free source-variable edge a left-to-right arc of capacity one, and right-to-sink arcs with interval $[L_v,U_v]$. Close with a sink-to-source arc of capacity at most the number of free edges. Standard lower-bound circulation transformation and integral max flow test exact feasibility. Every flow unit on an edge represents ONE global TRUE assignment to that same original variable at both endpoints. Source replay checks a recovered witness. A failed flow rejects that boundary assignment. Exhaustive enumeration of $S$ gives the stated upper bound.
\end{proof}
For nonbipartite residual support graphs, the same condition is a classical degree-interval $(g,f)$-factor problem, for which polynomial matching-theoretic algorithms exist. \emph{A general-factor implementation was not part of this run}; the included script reports NON\_BIPARTITE rather than claiming coverage. The separate fully paired matching theorem above works on nonbipartite graphs.

\section{Resource ledger and controls}
Let $N$ be the original fixed-record signed-CNF input length in bits, $w=\lceil\log_2(16(n+m+1))\rceil$ the RAM word width and $t$ the defect clause count. Parsing and literal-source reads cost $O(N/w)$, support sorting $O(m\log m)$, paired matching/augmentations $O(n^2)$, output/witness reconstruction and signed source replay $O(n+m)$; peak simultaneously live space is $O(n+m)$ words. Bipartite circulation branches cost at most $2^{3t}\mathrm{poly}(N)$, with streamed working storage linear in the graph size. Failed matching probes, flow branches, source rereads, certificate construction and output all count. Larger retained certificates consume correspondingly larger output space. This is an \emph{upper bound for specified procedures}, not a lower bound for arbitrary SAT deciders.

Independent stdlib audit \texttt{audit.py} with seed 202610231912 recorded 353 assertion groups and no failures. Controls included paired prisms and bipartite cubic circulants $q=3,4,5,6,8,12,20,40$, a $K_4$ source-sharing instance, a nonmaximum greedy matching requiring Hall augmentation, signed occurrence-preserving mismatched clause swaps, 320 random independently brute-forced 2-CNFs, SCC both-label formulas, and an impossible flow branch. For $q\le5$, 74,752 source-assignment cases were exhaustively checked against the functional circuit and gate-trace conversion. Accounting recorded 4,289,824 logic gate evaluations, 8,579,648 directed gate-input reads, 36 defect branches and 17 flow augmentations. At $q=40$, $n=120$, $m=160$, occurrence vertices $480$, conflict edges $480$, augmented edges $960$, gates $479$, functional trace clauses $1438$.

An all-sign 8-clause cube over three fresh variables supplies a scalable UNSAT proper 3-CNF hostile control but is \emph{not exact} $(2^+,2^-)$. A genuine 198-variable monotone exact-$(2,2)$ UNSAT example appears in D\"ocker's published appendix; it was \emph{not} machine-extracted or independently reconstructed this run. No false claim of a verified both-label exact-regular family is made.
