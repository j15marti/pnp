\section{Literature and barrier-transfer preflight}
The two obstacles are (i) the absence of a forced interface from an ordinary
one-input/one-bit SAT decision computation, and (ii) the absence of a
model-preserving transfer from any declared split/online lower bound to the
same ordinary random-access realization.

Yao's original two-party communication model fixes distributed inputs and a
protocol, and minimizes bits exchanged in that model \cite{Yao79}.  This is a
\textbf{directly transferable theorem} only after parties, the input
partition, output owner, and protocol are fixed.  It supplies no communication
meter for an ordinary single-machine SAT decider.

Fortnow--Lipton--van Melkebeek--Viglas give simultaneous time--space lower
bounds for SAT on their declared random-access model \cite{FLMV05}.  This is a
\textbf{directly transferable theorem} only to a machine with the required
simultaneous pair in that same model.  It does not separately lower-bound
communication, compatibility extraction, or witness reconstruction.
D\"ocker proves NP-completeness of proper duplicate-free signed Monotone
3-SAT-(2,2) \cite{Docker20}; that theorem validates the current hard family
but does not prescribe a solver trace.

HEC/chronogram, VLSI-routing, control-observability, proof-system, and
distributed-cut results are \textbf{useful structural analogies requiring a
new transfer theorem}.  Treating internal memory traffic as Yao
communication, or treating semantic compatibility as a forced trace object,
is a \textbf{misleading analogy / failed transfer} without an explicit model
correspondence.

\section{Candidate tested: ZERO-INTERFACE-DECISION1}
Fix the ordinary decision interface
\[
  \Gamma_{\rm dec}:\quad
  \operatorname{enc}(F)\longmapsto
  \mathbf 1[F\in\SAT],
\]
with one read-only canonical indexed-CNF input and one output bit.  No parties,
message channel, compatibility extractor, or witness reconstructor are part
of \(\Gamma_{\rm dec}\).  For a machine \(A\), let
\(C_A^{\Gamma},E_A^{\Gamma},R_A^{\Gamma}\) count, respectively, transmitted
bits, calls to a declared compatibility extractor, and calls to a declared
witness reconstructor in one execution.

\paragraph{ZERO-INTERFACE-DECISION1 (PROVED/EXACT).}
There is a deterministic uniform exact SAT decider \(D\) such that, for every
well-formed CNF formula \(F\) of encoded length \(N\),
\[
 C_D^{\Gamma_{\rm dec}}(F)=E_D^{\Gamma_{\rm dec}}(F)
 =R_D^{\Gamma_{\rm dec}}(F)=0,
 \qquad |\operatorname{out}_D(F)|=1,
\]
while parsing is \(O(N)\), peak work space is \(O(N)\), and
\[
 T_D(F)=O(2^{n(F)}m(F)w(F)),
\]
where \(m(F)\) is the number of clauses and \(w(F)\) the maximum clause
width.  Invalid encodings are rejected during the charged linear scan.

\paragraph{Proof.}
Parse and validate the input.  Enumerate the \(2^{n(F)}\) assignments in
lexicographic order and scan all clauses under each assignment; output one on
the first satisfying assignment and zero after the final assignment.  The
input, current assignment, and scan counters use \(O(N)\) bits.  The program
contains no transmit, extractor, or reconstructor transition, so the three
declared interface meters are identically zero on every input.  The current
trial assignment is charged as ordinary work space; it is not emitted as a
witness.  This proves the displayed resource bounds. \(\square\)

\paragraph{Exact falsification.}
For each \(Q\in\{C^{\Gamma_{\rm dec}},E^{\Gamma_{\rm dec}},
R^{\Gamma_{\rm dec}}\}\), the unqualified claim
\[
  \forall A\in\operatorname{Dec}_{\rm uniform}(\SAT)\;
  \exists F\quad Q_A(F)>0
\]
is false, since \(D\) is one counterexample for all \(F\).  The same
counterexample refutes any stronger positive lower bound on these meters.
It does \emph{not} refute a theorem after a split protocol, online chronology,
or extraction relation has been externally fixed.  Such a theorem is about a
different interface and still needs an all-decider compiler back to ordinary
static SAT.

This result also does not refute the cofinal time target.  The counterexample
uses exponential time.  Its \(O(N)\) work-space upper bound independently
agrees with RESOURCEAXIS1's retirement of a superpolynomial-space necessity.
Nothing here converts a semantic-state count into runtime.

TESTS-0014, QGUARD1, COREEQUIV1, and RESOURCEAXIS1.

future-challenge no-reread model.  The contradiction would arise only by
silently identifying either restricted interface with
\(\Gamma_{\rm dec}\), which is precisely the missing transfer.

\section{Post-quantum technique ledger}
Schur squares, shortening, quadratic relation spaces, Hilbert functions, and
syzygies are \textbf{FAILED TRANSFER} here: the direct decider need not expose
a code representation, and detectable algebraic structure may be an
algorithmic shortcut.  Collision entropy is an \textbf{EXACT
OBJECT/THEOREM TRANSFER} only after a map is fixed; it cannot create an
extractor call in \(\Gamma_{\rm dec}\).  LWE-style external extraction and
special-soundness/collision extraction are \textbf{ANALOGY/CANDIDATE needing
a new bridge}: the external black-box procedure, relation, queries, and all
costs must be stated.  Cryptographic binding and random-oracle assumptions
remain inadmissible and are a \textbf{FAILED TRANSFER} to an unconditional
separation.
