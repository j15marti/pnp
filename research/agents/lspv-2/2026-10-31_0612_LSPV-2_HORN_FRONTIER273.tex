\section{Exact indexed source and both labels}
For $k\ge1$ let private variables $q_0,\dots,q_k$ and boundary variables $a_1,b_1,\dots,a_k,b_k$ be distinct. Let
\[
R_k=(q_0)\wedge(\neg q_k)\wedge\bigwedge_{i=1}^{k}
[(\neg q_{i-1}\lor\neg a_i\lor q_i)\wedge
 (\neg q_{i-1}\lor\neg b_i\lor q_i)],
\]
and the matched opposite-label source be
\[
U_k=R_k\wedge\bigwedge_{i=1}^k(a_i\lor b_i).
\]
The $2k+2$ clauses of $R_k$ are Horn; $U_k$ combines Horn and positive two-clauses. Every original literal retains its clause index, source variable, and sign. The source has $n=3k+1$ variables and $2k+2$ or $3k+2$ clauses respectively. Each $R_k$ is SAT (take $a_i=b_i=0$, $q_0=1$, $q_i=0$ for $i>0$). Each $U_k$ is UNSAT: each $(a_i\lor b_i)$ forces the transition $q_{i-1}\Rightarrow q_i$, from $q_0$ to the forbidden $q_k$. This is a complete same-source-core YES/NO control, not a hardness claim.

\begin{theorem}[Exact Horn-interface projection and arbitrary-width auxiliary-free lower bound]
For all $k\ge1$ and every boundary assignment $\beta$, define
\[
P_k=\bigwedge_{\epsilon\in\{0,1\}^k}
\left(\bigvee_{i=1}^k\neg t_{i,\epsilon_i}\right),
\qquad t_{i,0}=a_i,\quad t_{i,1}=b_i.
\]
Then
\[
\exists q_0\cdots q_k\ R_k(\beta,q)
\iff\bigvee_{i=1}^k(\neg a_i\wedge\neg b_i)
\iff P_k(\beta).
\]
Any ordinary CNF on \emph{only the $2k$ boundary variables}, with arbitrary clause width, equivalent to this projection requires at least $2^k$ distinct non-tautological clauses. $P_k$ achieves equality. Moreover $U_k$ is UNSAT and its projected child is $P_k\land\bigwedge_i(a_i\lor b_i)$, preserving the NO label.
\end{theorem}
\begin{proof}
If each pair has a true member, $q_0=1$ forces $q_1=\cdots=q_k=1$, violating $\neg q_k$. If some pair $i$ has both false, let $q_0,\dots,q_{i-1}=1$ and $q_i,\dots,q_k=0$. Every implication is satisfied. Distributing the displayed disjunction of conjunctions yields exactly $P_k$.

For each $\epsilon\in\{0,1\}^k$, let $\alpha_\epsilon$ set precisely the $k$ variables $t_{i,\epsilon_i}$ to $1$ and the other $k$ boundary variables to $0$. This assignment is infeasible. Turning any one of its $k$ true variables false makes a pair entirely false, hence makes the projection true. In an equivalent CNF, some clause $D_\epsilon$ must be false at $\alpha_\epsilon$. For each selected variable $t_{i,\epsilon_i}$, the one-bit satisfying neighbor differs only in its value. Thus $D_\epsilon$ must contain the literal $\neg t_{i,\epsilon_i}$, which becomes true at that neighbor. It follows that $D_\epsilon$ cannot also be false at a different $\alpha_{\epsilon'}$, since some $\epsilon'_i\ne\epsilon_i$ gives $t_{i,\epsilon_i}=0$ there. The $2^k$ distinct rejected assignments therefore require $2^k$ distinct clauses. This allows any mixture of other positive and negative literals in $D_\epsilon$ and any clause width.\qedhere
\end{proof}

\section{Source-indexed ordinary resolution and symbolic access}
For a choice word $\epsilon$, start from the original unit $(q_0)$. Resolve it successively with the original indexed clause $(\neg q_{i-1}\lor\neg t_{i,\epsilon_i}\lor q_i)$ on pivot $q_{i-1}$ for $i=1,\ldots,k$, then with original $(\neg q_k)$ on $q_k$. This creates precisely the $\epsilon$-th clause in $P_k$, with $k+1$ ordinary resolution steps and original-source parent indices. A complete UNSAT refutation for $U_k$ uses each $(a_i\lor b_i)$ to resolve the two corresponding transition clauses, deriving $(\neg q_{i-1}\lor q_i)$ in two steps, and then resolves the $k$ transitions from $(q_0)$ and finally $(\neg q_k)$. It has $3k+1$ steps, with no exponential subcube enumeration. All generated proof pivots, parents, derived clauses and final clauses are independently replayed.

For a canonical DIMACS serialization of $P_k$, enumerate choice words lexicographically. Let $L(r)$ be the number of characters in the first $r$ projected clauses, excluding the header. For boundary identifier pair $(2i-1,2i)$, let $z_i(r)$ count the first $r$ binary words whose $i$-th most significant choice bit is $1$; explicitly, with $h_i=2^{k-i}$,
\[
z_i(r)=\left\lfloor\frac{r}{2h_i}\right\rfloor h_i +
\max\{0,(r\bmod 2h_i)-h_i\}.
\]
Writing $d(t)=\lfloor\log_{10}(t)\rfloor+1$ for positive integer digit length, the exact prefix length is
\[
L(r)=r(2+2k)+\sum_{i=1}^k\big[(r-z_i(r))d(2i-1)+z_i(r)d(2i)\big].
\]
The extra $(a_i\lor b_i)$ rows and header have directly calculable lengths. Given character index $j$, binary-search the smallest prefix bracketing $j$ and format only that row. This uses $O(k^2)$ arithmetic-word operations per address, and $O(k)$ stored machine words, independent of $2^k$ physical output characters. In a bit-cost model, arithmetic on the $O(k)$-bit counters is also charged; the experiment does not assert the FLMV tape bound.

\noindent\textbf{Physical firewall.} Under explicit DIMACS the source length is $N=\Theta(k\log k)$, while the minimal auxiliary-free projected child has $M=\Omega(k2^k)$ characters, and therefore $M>\sqrt N$ for all sufficiently large $k$. A computed indexed output character is not the same as a short ordinary SAT input. Reintroducing $q$ produces a linear-size extended encoding, and direct Horn propagation solves $R_k$ without projection. Neither shortcut transfers the auxiliary-free representation bound to unrestricted SAT.
