\section{Precise target and preregistered falsifiers}
The missing constructive arrow is a fixed deterministic total uniform polynomial-cost map on a closed encoded class containing all ordinary SAT, preserving both answer labels and generating \emph{one} physical child of length at most $N^\lambda$ with $0<\lambda<1$. Repeated closure and bounded bases would give $P=NP$ by the elementary recurrence $T(N)\le N^c+T(N^\lambda)$. We neither assume a polynomial SAT solver nor read an answer-class oracle.

The following four concrete proposals preceded the external code and literature inspection in this run. \textbf{H1:} a four-layer affine signed exact-$(2,2)$ shell can be joined by a nontrivial equality constraint to an arbitrary connected 3CNF core while preserving the \emph{entire} core function under existential projection. \textbf{H2:} all original shell pivots other than the connector continue to have four non-tautological, unsubsumed width-four resolvents, and an exact local rectangle re-entry can stagnate for two levels. \textbf{H3:} a source-aware global recogniser can nonetheless strip the shell, yield one correct ordinary 3CNF child and repeat when another shell is exposed. \textbf{H4:} this operation automatically gives a fixed-power-short child even for a core occupying almost all input bytes. H1--H3 are proved below for their specified grammar; H4 is falsified by a connected bounded-degree 3-colouring sequence. These are architectural, not all-algorithm, statements.

\section{Original affine signed exact-$(2,2)$ shell}
For odd $p\ge5$ let $X=\{A_i,B_i,C_i:i\in\mathbb Z_p\}$, $|X|=3p$. Put
\[
R_p=\bigwedge_{s=0}^3\bigwedge_{i\in\mathbb Z_p}
 (A_i^{\alpha_s}\lor B_{i+s}^{\beta_s}\lor C_{i+2s}^{\gamma_s}),
\quad
\begin{array}{c|rrrr}s&0&1&2&3\\\hline
\alpha_s&-&-&+&+\\\beta_s&+&+&-&-\\\gamma_s&-&+&-&+
\end{array}.
\]
The notation $v^+=v$, $v^-=\neg v$ is used. Report AFFINE-RESOLVENT-FIXEDPOINT216 already established this family and its linear incidence graph. We independently reconstruct it here; it is not renamed as a new lower-bound family.

\begin{lemma}[Both-polarity flexibility and first-pivot obstruction]
Every $R_p$ is connected and proper, has $4p$ distinct clauses, exactly two positive and two negative occurrences for each variable, and any two clauses intersect in at most one variable. It is satisfied by $0^{3p}$ and $1^{3p}$. Eliminating any one variable by exact Davis--Putnam resolution produces precisely four distinct non-tautological width-four resolvents; no surviving original clause subsumes them.
\end{lemma}
\begin{proof}
Each layer uses every variable once; each sign row has two of each sign. Every clause contains at least one negative and one positive literal, proving both uniform assignments satisfy it. Layers $0,1$ connect neighbouring $A$ indices, hence the incidence graph, and the affine-index intersection calculation shows two distinct clauses share at most one variable for odd $p\ge5$ (the three coordinate-difference equations would otherwise force identical $(s,i)$). For a pivot $x$, its two positive and two negative clauses have disjoint non-pivot literal pairs, even across different clauses, giving a $2\times2$ rectangle of four distinct width-four clauses without complementary literals. No other ternary source clause can be a subset of these four group-crossing clauses. A complete finite audit independently tests every pivot for five source sizes.
\end{proof}

\section{An arbitrary connected SAT core, joined with a real equality}
Let $H(Y)$ be any connected proper distinct-clause 3CNF with dense variable names and at least one variable $y\in Y$. Assume $X\cap Y=\varnothing$. Choose $x=A_0\in X$ and fresh $u,v$. Replace the two binary equivalence clauses by their exact proper-3CNF padding:
\[
\begin{split}
E(x,y;u,v)={}&(\neg x\lor y\lor u)\land(\neg x\lor y\lor\neg u)\\
&\land(x\lor\neg y\lor v)\land(x\lor\neg y\lor\neg v).
\end{split}
\]
For every assignment to $x,y$, there exist $u,v$ satisfying $E$ if and only if $x=y$. Define $F_{p,H}=R_p(X)\land E(x,y;u,v)\land H(Y)$. The actual test serialization is ordinary canonical DIMACS with one header and no hidden advice or free label bit.

\begin{theorem}[Exact pointwise connected embedding]
For every odd $p\ge5$ and every such $H$, $F_{p,H}$ is connected, proper and distinct-clause 3CNF, with $3p+|Y|+2$ variables and $4p+|H|+4$ clauses, and satisfies
\[
\boxed{\ \forall\eta:Y\to\{0,1\},\quad
\bigvee_{\xi:X\cup\{u,v\}\to\{0,1\}}
 F_{p,H}(\xi,\eta)=H(\eta).\ }
\]
Hence $\mathrm{SAT}(F_{p,H})\iff\mathrm{SAT}(H)$, both for satisfiable and unsatisfiable cores. Each of the $3p-1$ shell variables other than $x$ retains four non-tautological width-four first-step resolvents unsubsumed by any clause of $F_{p,H}$.
\end{theorem}
\begin{proof}
Fix $\eta$. If $H(\eta)=0$, $F_{p,H}$ is false for every extension. Otherwise choose the \emph{uniform} $R_p$ witness $X=\eta(y)^{3p}$, possible by the preceding lemma, so $x=y$; both padded equivalence clauses are then true for either $u,v$. The two directions establish equality of Boolean functions, not just the final SAT label. The four bridge clauses share both components, so the full primal graph is connected. Properness follows from fresh, disjoint names and distinct widths. Only $x$ receives extra shell occurrences; for any other shell pivot, its incident clauses remain precisely the four originals. Their resolvents mention only shell variables, while every bridge clause mentions $y$ and one new pad and every core clause contains a core variable, so no bridge/core clause subsumes them.
\end{proof}

\paragraph{Hostile test for the flexibility hypothesis.}
Merely knowing that the shell is satisfiable is not sufficient. Four proper clauses $\{(\neg x\lor a^\epsilon\lor b^\delta):\epsilon,\delta\in\{+,-\}\}$ force $x=0$, while the four positive-$y$ versions force $y=1$. Linking these two satisfiable gadgets by the same $E(x,y)$ produces an UNSAT formula. An exact finite DPLL run rejected the join after 715 recursive calls. Thus the proof genuinely uses \emph{both} uniform shell witnesses, not an uncharged blanket deletion of arbitrary satisfiable subformulas.

\section{One source-aware physical child and two real levels}
A single deterministic program parses the entire ordinary DIMACS body, checks proper three-literal clauses, variable ranges, header, clause distinctness and dense IDs, and searches for a leading prefix equal up to independent variable complements to $R_p$ followed by the \emph{exact} four-clause $E$ pattern. It verifies that no removed shell/pad variable occurs in the remaining input. The search tries candidate odd $p$ and explicitly checks every associated signed occurrence; even a malicious candidate cannot be accepted from a header hint alone. On success it discards the authenticated prefix, renumbers every surviving original variable in sorted source-ID order, and writes \emph{all} ordinary DIMACS child bytes. On failure or malformed bytes it returns a defined status, but \emph{does not purport to decide general SAT}.

\begin{proposition}[Sound source-aware stripping and recursive closure on a restricted grammar]
For every input of the form $F_{p,H}$, the above constructor outputs a single well-formed ordinary 3CNF $H'$ isomorphic by a computable renaming to $H$, with identical satisfiability. If $H=F_{q,K}$ with an independently authored next shell, the same fixed program recognizes $H'$ and outputs $K$. More generally, write $F_{p,q;H}$ for the \emph{star-connected} conjunction $R_p(X_1)\land E(x_1,y)\land R_q(X_2)\land E(x_2,y)\land H(Y)$, with two independent affine shells joined to the same core variable $y$. The actual two-level implementation generates these star-connected instances. For the closed class
\[
\mathcal C=\{F_{p_1(t),p_2(t);W_{ab}}:t\ge t_0,\ a,b\in\{0,1\}\}
\ \cup\ \{F_{p_2(t),W_{ab}}:t\ge t_0,\ a,b\in\{0,1\}\}
\ \cup\ \{W_{ab}:a,b\in\{0,1\}\},
\]
where $p_1(t)=2t^4+1$, $p_2(t)=2t^2+1$ and $W_{ab}$ are the four fixed 15-variable W1 sign-switch formulas, the two recursive steps, for a fixed sufficiently large integer $t_0$, have encoded byte lengths satisfying $N_{j+1}\le N_j^{3/4}$. The final $W_{ab}$ are directly decidable constant-size bases. The same program, without a SAT/UNSAT-side hint, handles all $a,b$ and all valid instances in this restricted class.
\end{proposition}
\begin{proof}
The theorem permits the first exact projection. Source syntax and the isolation check make the deletion safe, and renumbering is an injective variable substitution. Repeating this proof inductively establishes closure. A fixed-layout DIMACS encoding of a shell of parameter $p$ has $\Theta(p\log(p+2))$ bytes. Consequently, the three successive sizes are $N_0=\Theta(t^4\log t)$, $N_1=\Theta(t^2\log t)$ and $N_2=\Theta(1)$. Since $t^2\log t=o((t^4\log t)^{3/4})$, the first strict power inequality holds for all sufficiently large $t$. The second holds because $N_2$ is fixed and $N_1$ grows. The recogniser does not need to know $t$ or the SAT label: it authenticates each proposed source shell, and bases are decided by fixed 15-variable exhaustive search. Finitely many smaller members may instead be included among fixed bounded-size bases; this is not a polynomial bound for arbitrary SAT.
\end{proof}

\paragraph{Why this does not yield a general shrinker.}
Let $H_q$ be a connected proper 3CNF encoding the 3-colouring of a $q$-vertex path (SAT) or a graph containing a $K_4$ connected to a path (UNSAT). These cores have $\Theta(q)$ variables and clauses, bounded variable incidence and $\Theta(q\log q)$ DIMACS bytes. For fixed $p$, appending $R_p$ and the bridge changes only $O(p\log q+\log q)$ physical bytes compared with the child $H_q$ (bounded incidence controls decimal-ID width changes). Thus
\[
\frac{|H_q|}{|F_{p,H_q}|}\longrightarrow 1.
\]
It follows that stripping this fixed shell cannot satisfy $|H_q|\le |F_{p,H_q}|^\lambda$ for any fixed $\lambda<1$ for all large $q$. This counterexample is about \emph{this stripping architecture}; it does not rule out a different polynomial SAT decider or compression map.

The program pays \emph{all} input parsing, failed guesses of $p$, clause-scope comparisons, sign-complement checks, source rereads, variable renumbering, output headers, output body and live parser tables. For a length-$N$ encoded input, a deliberately conservative implementation gives $O(N^3)$ elementary bit operations and $O(N\log N)$ writable/index bits, including the complete child, with \emph{zero} SAT oracle calls during stripping. A fixed-k read-only-input tape implementation can use at most polynomially larger time, while a conservative single read/write tape simulator obeys
\[
T_1=O\bigl(T_k(N+S_k+\log(T_k+2))\bigr),\quad
P_1=O(N+S_k+\log(T_k+2)).
\]
The one-tape footprint includes input; the indexed model must pay address writing; a fixed universal TM has its own explicit polynomial interpreter overhead. An ordinary two-writable-tape model is not silently identified with the read-only-input model. No sequential crossing result is imported as a SAT-hardness theorem.
