\section{Source language and independently defined parameters}
The input is an explicit signed width-at-most-two CNF $B$ on $n$ named Boolean variables with $m$ clauses, plus one non-repeated index set $S\subseteq[n]$ and a bit $d$. We ask
\[
 B(x)\land\bigoplus_{i\in S}x_i=d.
 \tag{1}
\]
This is a \emph{restricted mixed representation}, not automatically one ordinary proper-3CNF in the target machine model. Parsing, normalization, parity indices, polarity, and workspace are charged. Let $G_B$ be the ordinary $2n$-vertex implication graph, $\mathcal C$ its SCCs, paired by literal complementation. For each original variable $i$, define the structural group
\[
 P(i)=\{C(x_i),C(\neg x_i)\},\qquad
 W_P=|\{i\in S:P(i)=P\}|\bmod2.
 \tag{2}
\]
The group is \emph{flexible} iff there are two models of $B$ with the group in opposite orientations. $W_P$, SCC reachability and flexibility are properties of the input, defined independently of observed running time. They are acquired by paid graph computation and 2-SAT calls. The true SAT label is never supplied to select a method.

\section{The new constructive proof step}
\begin{lemma}[Single-paired-SCC path; PROVED/EXACT in the declared graph]
For any two satisfying assignments $a,b$ of $B$, there is a path of satisfying assignments from $a$ to $b$ in which every move flips exactly the source variables belonging to one paired SCC group $P$. The moves can be selected by reversing a topological order in the condensation DAG induced by SCCs false in $a$ and true in $b$.
\end{lemma}
\begin{proof}
Put $D=\{C:a(C)=0,b(C)=1\}$. SCC consistency in every model forces all literals in one SCC to share a truth value, and the complement SCC has the opposite truth value. The implication condensation is acyclic. Choose a sink $C$ in $D$ and flip all variables whose positive or negative literal lies in the pair $\{C,\bar C\}$. No implication newly leaving TRUE $C$ can point to a still false literal: because $b$ satisfies that implication, such a consequent would itself lie in $D$, violating sinkhood. Nor can an implication from another still TRUE literal point to the newly FALSE complement $\bar C$: contraposition would yield an outgoing edge from $C$ to a still FALSE-in-$a$, TRUE-in-$b$ literal, also contradicting sinkhood. Implications not incident to the pair are unaffected. Remove $C$ from $D$ and repeat. Every move is a satisfying assignment and reduces the number of groups differing from $b$.
\end{proof}
\begin{theorem}[Explicit one-syndrome dispatcher; PROVED/EXACT restricted]
There is a uniform deterministic algorithm that decides (1), reconstructs and verifies a satisfying assignment on YES instances, and uses
\[
 O(n(n+m+1))\ \text{word operations},\qquad O(n+m+1)\ \text{live working words}.
 \tag{3}
\]
No particular UNSAT proof output is required. At most $n+1$ ordinary 2-SAT SCC calls are needed.
\end{theorem}
\begin{proof}
Run SCC on $B$ first. If inconsistent, reject. Otherwise obtain model $a$. If its parity equals $d$, accept and replay it. Compute the paired SCC groups $P$ and weights $W_P$. Only odd-weight groups can change the parity of a model along the preceding lemma's path. For each odd-weight group not yet rejected, choose a source variable $i$ in that group and test $B$ with the unit forcing $x_i=1-a_i$. An UNSAT result proves this group has its orientation fixed relative to $a$. If all odd groups are fixed, the lemma connects any two models through even-weight flips only, so every model has the parity of $a$; reject. If some test is SAT, take its witness $b$, build $D$ and a reverse topological order, and traverse the preceding lemma's valid path from $a$ to $b$. That path flips this flexible odd group, so at least one intermediate model has parity $d$; return and verify the first such model. Each SCC run costs $O(n+m+1)$ words. There are at most $n$ candidate groups and at most $n$ flips. Condensation construction/topological order is linear in the graph; source replay after each flip costs $O(m)$, yielding (3). Working graph, assignment vectors, SCC maps and live path buffers have $O(n+m)$ words, with no accumulation of completed alternative branches.
\end{proof}

This is a constructive refinement of a \emph{known tractable rung}, not a new fixed-rank complexity classification. A full source/parity-record grammar check remains necessary when this solver is a branch of a general adaptive SAT policy.

\section{Both-label audit and comparison}
The published standard-library reproducer independently compares its answers with complete enumeration on 2,100 seeded width-two instances with $1\le n\le7$ and both SAT and UNSAT outcomes. It found 957 backbone-UNSAT cases, 254 parity-fixed UNSAT cases, 567 immediate satisfying parity witnesses and 322 requiring the SCC-orbit switch. There were 2,743 charged SCC calls and zero answer or witness discrepancies. Sixteen additional scalable controls with $n=16,64,128,256$ tested both labels of equivalence chains and both feasible parities of implication chains. Every original clause and the parity condition were replayed for positive answers. An extended local independent audit tested 3,520 small instances (1,111 SAT and 2,409 UNSAT) and 16 growing cases, again without discrepancies, but its separately uploaded full script is not claimed to be present on GitHub.

Fixed exhaustive assignment enumeration can require $2^n$ cases on the tested parity-inconsistent equivalence chain. The SCC-orbit algorithm is polynomial there; conversely the observed immediate witness branch avoids orbit construction when unnecessary. These are \emph{algorithm-specific comparisons}, not a lower bound against any alternative SAT decider.
