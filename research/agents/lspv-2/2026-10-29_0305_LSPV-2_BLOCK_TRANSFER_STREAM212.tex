\begin{proposition}[Static clause-hitting coverage, independent audit]
Let $F$ be a connected strict signed exact-$(2,2)$ proper 3CNF with $n$ original variables, hence $m=4n/3$ clauses. For a fixed original boundary $Y$, $|Y|=b>0$, suppose all other variables are partitioned into $k$ nonempty private modules, no source clause meets private variables in different modules, and every clause meets $Y\cup B_i$ for its assigned module, where $|B_i|\le q$. Then
\[
 k\le4b,\qquad n\le3\bigl(b+\textstyle\sum_i|B_i|\bigr)\le3b+12bq,
 \qquad b+q\ge\sqrt{n/3}-\tfrac14.
\]
If $b=0$ and the incidence graph is connected, $k=1$ and $q\ge n/3$.
\end{proposition}
\begin{proof}
Every private module must meet an original boundary variable in some clause, or the connected incidence graph splits; the touches are distinct across modules. There are exactly $4b$ boundary literal incidences, so $k\le4b$. The authenticated set $H=Y\cup\bigcup_i B_i$ meets every clause, while any original variable meets at most four clauses, so $4n/3=m\le4|H|$. Thus $n\le3b(1+4q)$ and $b(q+1/4)\ge n/12$. AM--GM gives $b+q+1/4\ge2\sqrt{n/12}=\sqrt{n/3}$. Boundary-only clauses are already hit and do not defeat this argument. For $b=0$, connectedness forces one private module, giving the stated $q$ bound.
\end{proof}
This excludes both $b,q=O(\log N)$ for unbounded canonical $N=\Theta(n\log n)$ under this exact static architecture, but it is not a runtime lower bound. Adaptive moving separators, nonlinear semantic shortcuts, and different graph representations are not covered.

\section{BUILD II: authentic cycle-block streaming transfer}
Let $n=3r$ and define blocks $X_j=(x_{3j},x_{3j+1},x_{3j+2})$, with subscripts modulo $n$. There are exactly four proper signed original source clauses per $j$:
\[
 C_{3j}\bigl(x_{3j},x_{3j+1},x_{3j+2}\bigr),\quad
 C_{3j+1}\bigl(x_{3j+1},x_{3j+2},x_{3j+3}\bigr),\quad
 C_{3j+2}\bigl(x_{3j+2},x_{3j+3},x_{3j+4}\bigr),\quad
 Q_j\bigl(x_{3j},x_{3j+1},x_{3j+2}\bigr).
\]
The \emph{typed language} uses canonical ASCII DIMACS, fixed block-major clause order $C_{3j},C_{3j+1},C_{3j+2},Q_j$, increasing absolute names within each clause and exactly one space between tokens. A promised strict signed exact-$(2,2)$ member has two positive and two negative occurrences of each original name. This scope order is an explicit input promise with complete source-byte validation, not a free permutation of arbitrary SAT.

For each $j$ define an $8\times8$ Boolean compatibility matrix $M_j$ indexed by assignments $a\in\{0,1\}^{X_j}$ and $b\in\{0,1\}^{X_{j+1}}$. Let $M_j(a,b)=1$ precisely when the four original clauses in block $j$ are satisfied by the joint assignment. Use Boolean-semiring matrix multiplication: $(A\circ B)_{a,c}=\bigvee_b(A_{a,b}\wedge B_{b,c})$.
\begin{theorem}[Certified one-pass constant-transfer calculation]
There exists a single fixed deterministic length-aware indexed-input program that reads the canonical block-major signed cycle exactly once, checks complete literal source structure, signs, header counts and a required exact-$(2,2)$ polarity quota, and computes its SAT value with $O(N)$ source-byte accesses, $O(N)$ constant-word Boolean operations, and $O(\log(N+2))$ live writable bits. It accepts no malformed input as a SAT member. The same transfer without quota checks decides the syntactically valid arbitrary-sign cycle class. A conservative sequential read-only-input multitape simulation uses polynomial time and $O(\log N)$ work cells after a length-counting pass.
\end{theorem}
\begin{proof}
A global assignment is a cyclic sequence $s_0,\ldots,s_{r-1}\in\{0,1\}^3$ with $M_j(s_j,s_{j+1})=1$ for every $j$, interpreting $s_r=s_0$. This is equivalent to
\[
 \bigvee_{s\in\{0,1\}^3}\left(M_0\circ\cdots\circ M_{r-1}\right)_{s,s}=1.
\]
Hence one eight-by-eight accumulator suffices. Each update is at most $8^3=512$ constant-size Boolean candidate operations. Every clause of a block refers only to its block and its cyclic successor, so the current block's four source records can be discarded after its matrix update. Only a constant number of signs and $O(\log N)$ header/index counters remain live.

For the strict signed quota, $x_{3j+2}$ has all four occurrences in block $j$, so count its positives immediately; $x_{3j}$ and $x_{3j+1}$ appear only in block $j$ and its predecessor, so save their two tiny partial counts in a two-name carry. To authenticate wraparound, retain the first block's two partial counts and add the last block's contributions. All counts are in $\{0,1,2,3,4\}$. Reject a source name, source sign quota, clause length, terminator, count, grammar, or trailing-byte error. Scan integers with early upper bounds by physical $N$ to prevent a fabricated enormous decimal header from consuming more than $O(\log N)$ arithmetic bits. An input-length-aware indexed RAM obtains $N$ from its input interface; the sequential-input TM counts length in an initial pass, rewinds at charged cost, then streams the data. This establishes the claimed work bound without an occurrence table or full clause list.
\end{proof}

\section{BUILD III: connected degree-six exact OBDD order obstruction}
For $k\ge1$ use free pairs $(a_i,b_i)$ and distinct private $u_i$ and, for $i<k$, fresh $(t_i,p_i,q_i)$. Define
\begin{align*}
 E_i={}&(\neg a_i\vee b_i\vee u_i)\wedge(\neg a_i\vee b_i\vee\neg u_i)
 \wedge(a_i\vee\neg b_i\vee u_i)\wedge(a_i\vee\neg b_i\vee\neg u_i),\\
 T_i={}&(t_i\vee p_i\vee q_i)\wedge(t_i\vee p_i\vee\neg q_i)
 \wedge(t_i\vee\neg p_i\vee q_i)\wedge(t_i\vee\neg p_i\vee\neg q_i)
 \wedge(t_i\vee a_i\vee a_{i+1}),\\
 F_k={}&\bigwedge_{i=1}^kE_i\wedge\bigwedge_{i=1}^{k-1}T_i.
\end{align*}
\begin{proposition}[Connected bounded-occurrence grouped-order barrier]
$F_k$ is incidence-connected proper 3CNF with $6k-3$ variables, $9k-5$ three-literal clauses and maximum original variable incidence six. Its full free-variable projection satisfies
\[
 \exists_{u,t,p,q}F_k(a,b)\equiv\bigwedge_{i=1}^k(a_i\leftrightarrow b_i).
\]
Any exact fixed-order reduced OBDD that reads every $a_i$ before every $b_i$ has width at least $2^k$ at that cut, whereas the interleaved order $(a_1,b_1,\ldots,a_k,b_k)$ has width at most three. There is a linear-size circuit and an ordinary proper 3CNF with $4k$ clauses for the same projected function (allowing fresh existential local auxiliaries). These facts do not imply a lower bound for SAT decision or arbitrary circuit compression.
\end{proposition}
\begin{proof}
The pair $(A\vee u_i)\wedge(A\vee\neg u_i)$ is equivalent to $A$. Thus $E_i$ forces the two binary equivalence implications, hence $a_i=b_i$. Likewise the four signed clauses in $T_i$ force $t_i=1$, making its connecting fifth clause automatically true. For each $i$, every private variable is attached through its clauses and the bridge containing $a_i,a_{i+1}$ connects successive components. Every clause has three distinct names, and each $a_i$ occurs at most four times in $E_i$ plus twice in bridges, proving degree at most six. The count is direct.

After fixing $a=(a_1,\ldots,a_k)$, the residual on $b$ is the point function $[b=a]$. The $2^k$ choices of $a$ induce pairwise distinct residual functions, forcing at least $2^k$ grouped-order OBDD states. In the interleaved order only three statuses are needed after an $a_i$: violation, pending $a_i=0$, or pending $a_i=1$; after $b_i$ only the violation and successful prefix states remain. The projection is a conjunction of $k$ binary equivalences; padding each implication with an existential fresh $u_i$ uses four proper 3CNF clauses per pair. No free source-function compression assumption follows, and the connected input itself is satisfiable for every common pair assignment $a=b$.
\end{proof}

Under direct decimal DIMACS, the original and the $4k$-clause proper-3CNF reentry both require $\Theta(k\log(k+2))$ encoded bits, despite a constant-factor size saving. Thus this reentry does \emph{not} provide $N^\lambda$ contraction for any fixed $\lambda<1$. The $2^k$ OBDD lower bound is only for the specified poor order and exact residual-function semantics, not the size of the interleaved circuit or the decision problem. The present gadget is \emph{not} signed exact-$(2,2)$.
