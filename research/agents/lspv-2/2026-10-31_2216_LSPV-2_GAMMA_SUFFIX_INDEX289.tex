\begin{proof}
The final six variables use their complete two positive/two negative occurrences inside the eight trailing clauses. Thus no original prefix clause can touch them, and deleting the suffix preserves all quotas, properness, distinctness and uniqueness. The fixed source witness $001011$ extends any $H$ witness; any $F$ witness restricts to $H$. An original-source refutation of $H$ remains valid in $F$.
Set $h_P=|\gamma(n)\gamma(m)|$, $h_C=|\gamma(n-6)\gamma(m-8)|$, $w_P=w(n)$, $w_C=w(n-6)$, $r_P=1+3w_P$ and $r_C=1+3w_C$. A child output bit $q<h_C$ is computed from its header. Otherwise put $j=\lfloor(q-h_C)/r_C\rfloor$, $t=(q-h_C)\bmod r_C$, and $b=h_P+jr_P$. If $t=0$ return source bit $b$. Otherwise define $k=\lfloor(t-1)/w_C\rfloor$ and $u=(t-1)\bmod w_C$; return source bit at
\[
\boxed{b+1+k w_P+(w_P-w_C)+u}.
\]
The prefix variable names do not change. Their unused leading $w_P-w_C$ source bits are zero, so the output name bits are the stated contiguous suffix. Arithmetic uses logarithmic counters. Full validation checks gamma-header magnitude against input length, total length, pairs of clauses for duplicates and each variable's two signed occurrence counts through rescans. These repeated scans use logarithmic counters and polynomial time.
\end{proof}
