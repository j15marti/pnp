\section{Declared input and charging model}
An input is an explicit signed $F=B\wedge T$, where $B$ is 2-CNF and $T$ contains at most $k$ genuine ternary clauses; all signed variable names are globally coherent. Let $n$ be syntactic-variable count, $m$ clause count, $p=n+m$, $X=\operatorname{Var}(T)$, $s=|X|\le3k$, and $Y=\operatorname{Var}(F)\setminus X$. Use the explicit four-word clause-record encoding with word width $w=\lceil\log_2(64(n+m+1))\rceil$ and input length $N=(2+4m)w$ bits. Original source variables, functional gate-trace variables, and free auxiliaries must be distinguished and never independently equated. The compiler retains source name maps and reconstructs any needed $Y$ assignment by a charged SCC solve.

We record separately $C_{\rm discovery}$, $C_{\rm normalization}$, $C_{\rm verification}$, $C_{\rm continuation}$, $C_{\rm reconstruction}$ and $C_{\rm replay}$. Their sum is only an accounting identity.
\section{Direct executable backdoor}
Scan each ternary clause and select its first variable if no previously selected variable occurs in it. The selected set $S$ has $b=|S|\le k$. Every assignment to $S$ deletes or shrinks every ternary clause into at most two literals; solve the resulting 2-CNF by SCC and reconstruct a witness under the same original source names.

\begin{theorem}[Direct charged upper bound]
Every such input is decided exactly, for both SAT and UNSAT, in $O((n+m)+2^b(n+m))$ word operations and $O(n+m+b)$ live workspace words when restricted children are processed sequentially. A SAT witness is checked by replaying the original $m$ clauses. An explicit UNSAT leaf transcript may be exponential in $k$ and is not presented as an unrestricted polynomial-length proof.
\end{theorem}
\begin{proof}One selected variable hits each genuine triple. Existential disjunction over the $2^b$ assignments agrees with the parent SAT label. Each residual is 2-CNF, and SCC is exact. All failed child constructions and SCC calls are counted.\end{proof}

\section{Reachability kernel with polynomial verification}
For each binary $(a\vee b)$ add implication edges $\bar a\to b$ and $\bar b\to a$; for each unit $(a)$ add $\bar a\to a$. First check $B$ by SCC. If UNSAT, output a fixed FALSE kernel with SCC-checkable status. Otherwise run one graph traversal from $\bar a$ for each signed boundary literal $a\in\{\pm x:x\in X\}$. Construct $Q_B(X)$ by adding unit $(a)$ if $\bar a\leadsto a$, and proper binary $(a\vee b)$ if $\bar a\leadsto b$ for distinct boundary variables. Redundant binary consequences arising only from forced units need not be emitted.

\begin{lemma}[At most two boundary assumptions cause any conflict]
If satisfiable $B$ is inconsistent with a boundary assignment $\alpha$, either an assumed literal $t$ reaches $\bar t$, or two distinct literals $t,u$ assumed true satisfy $t\leadsto\bar u$.
\end{lemma}
\begin{proof}Implication closure of the assumed literals must contain a complementary pair $v,\bar v$: under assumptions, inconsistency of a satisfiable 2-CNF is detected by implication propagation, equivalently by binary resolution. If $t\leadsto v$ and $u\leadsto\bar v$ are their respective assumptions, contraposition of the latter path and concatenation give $t\leadsto\bar u$. When $t=u$, the path forces $\bar t$ directly.\end{proof}

\begin{theorem}[Exact source-compatible projection]
For every boundary assignment $\alpha$,
\[
\alpha\models Q_B\quad\Longleftrightarrow\quad
\exists\beta\in\{0,1\}^{Y}\ B(\alpha,\beta).
\]
Thus $\operatorname{SAT}(F)=\operatorname{SAT}(Q_B\wedge T)$, preserving both labels, and the kernel has at most $s\le3k$ variables and $k+2s^2$ clauses.
\end{theorem}
\begin{proof}Every emitted implication-path clause is entailed by $B$. If a boundary assignment satisfies all emitted clauses but has no extension, the lemma yields either a violated emitted unit or a violated emitted binary, contradiction. There are $2s$ possible units and $2s(s-1)$ distinct-variable binary clauses, totaling $2s^2$.\end{proof}

For each of the $2s$ roots, provide the reached vertex set, BFS distance array and predecessor \emph{edge indices}. The verifier checks that the root is present, that every reached nonroot has an actual predecessor edge decreasing distance by one, and that the reached set is closed under every graph edge. These checks jointly establish exact reachability, including \emph{absence} of omitted consequences. Recompute and compare all $O(s^2)$ output clause decisions. Verification is deterministic polynomial time and does not rely on a SAT oracle.

\begin{theorem}[Charged compiler and kernel continuation]
The multi-source compiler and independent certificate verifier each use $O((1+s)(n+m)+s^2)$ word steps. A complete certificate uses $O(sn)$ words plus the kernel. A subsequent $b\le k$-variable hitting-set branch on the kernel, including witness reconstruction on the original $B$ and source replay, costs $O(2^b(s^2+k)+n+m)$ additional steps. Thus the combined charged bound is
\[
O((1+s)(n+m)+s^2+2^b(s^2+k)),
\]
with $O(n+m+sn+s^2)$ peak live words if the full certificate is buffered. Streaming a certificate may reduce live workspace but does not erase its output-write charge.
\end{theorem}
\begin{proof}An implication graph has $2n$ literal vertices and at most $2m$ arcs. One SCC computation and $2s$ graph traversals, together with $O(s^2)$ clause tests and a repeated full-edge verification, give the compiler and verifier bounds. The new kernel has $O(s^2+k)$ clauses. Each leaf is 2-CNF and takes linear time in kernel size. For a successful leaf, SCC on the original $B$ under the boundary assignment reconstructs its $Y$ values, and original-source replay checks them. All failed branches and auxiliary accesses are charged.\end{proof}

\section{Hostile controls and explicit results}
The opposite-label pair uses $B=\bigwedge_{v\in\{x,y,z\}}[(\bar v\vee a_v)\wedge(\bar v\vee\bar a_v)]$ and respectively $T_-=(x\vee y\vee z)$ (UNSAT) and $T_+=(\bar x\vee y\vee z)$ (SAT). The same six syntactic variables, six binary and one ternary clauses differ in exactly one literal sign. $B$ forces $x=y=z=0$; the projection is the three units $\bar x,\bar y,\bar z$. The direct backdoor takes two SCC calls for UNSAT and one for SAT. A second hostile join uses $F_1=(z\vee a)\wedge(z\vee\bar a)$ and $F_2=(\bar z\vee b)\wedge(\bar z\vee\bar b)$. Each is SAT but the conjunction is UNSAT. If $z$ is dropped from the shared source interface, an otherwise plausible component-join method is wrong.

A four-row XOR cycle with 16 ternary CNF clauses and five variables has matched SAT and UNSAT signings; syntactic four-clause parity recognition followed by GF(2) elimination decides both, recording five row XORs and an explicit four-equation $0=1$ certificate for UNSAT. Fourteen disjoint equivalent components gave one solver call, thirteen memoized hits, and fully charged witness replay. \begin{theorem}[Restricted expander separator obligation]
Let $H$ be a $D$-regular graph on $h$ vertices with $|\partial U|\ge\epsilon|U|$ for each $1\le|U|\le h/2$. Partition whole one-hot vertex gadgets of $\Gamma(H)$ into blocks each of size at most $h/2$, and insist on an exact source-coherent SMALL-INTERFACE64 canonical block representation. If $S$ is its declared shared source-variable interface, then
\[
|S|\ge\frac{3\epsilon h}{2D}.
\]
A specified procedure that explicitly materializes \emph{all} $2^{|S|}$ interface assignments has an exponential record count for fixed $D,\epsilon>0$. No unrestricted SAT time lower bound follows.
\end{theorem}
\begin{proof}There are at least $\epsilon h/2$ cross-block graph edges, hence three times as many color-incompatibility clauses. Each such cross-block clause requires at least one endpoint variable in the shared interface or violates canonical source compatibility. Any one source color variable participates in at most $D$ crossing clauses, so $D|S|\ge 3\epsilon h/2$. The full-enumeration claim is by its declared semantics.\end{proof}

For the $K_4$ split into two blocks of two vertices, twelve cross-edge color clauses require a minimum of six shared color variables, checked by 1,587 increasing-cardinality candidate sets. This is only a restricted separator result: alternative source-aware algorithms can avoid the full interface enumeration.
