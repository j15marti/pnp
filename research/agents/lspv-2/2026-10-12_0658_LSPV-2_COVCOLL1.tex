\section{Exact two-axis theorem}

\begin{definition}[Program replacement and source collapse]
Let $\mathcal P\ne\varnothing$, let $b:K\to\{0,1\}$ have two nonempty
fibers, and fix $y_a\in b^{-1}(a)$ for $a\in\{0,1\}$.  Define
\[
 \rho_B(A)=B\quad(A,B\in\mathcal P),
 \qquad
 \kappa(x)=y_{b(x)}\quad(x\in K).                         \tag{1}
\]
For $X:\mathcal P\times K\to\Omega$, program-replacement invariance and
source-collapse invariance mean
\[
 X(\rho_B(A),x)=X(A,x),
 \qquad
 X(A,\kappa(x))=X(A,x)                                   \tag{2}
\]
for every typed argument.
\end{definition}

\begin{theorem}[\texttt{TWO-AXIS-COVARIANCE-COLLAPSE1}]
Under the preceding hypotheses, the following are equivalent.
\begin{enumerate}[label=(\roman*),leftmargin=1.7em]
\item $X$ satisfies both identities in (2);
\item there is a unique map $g:\{0,1\}\to\Omega$ on the attained answers
such that
\[
                 X(A,x)=g(b(x))
                 \quad\text{for all }A\in\mathcal P,\ x\in K;              \tag{3}
\]
\item $X$ is invariant under every constant program replacement and every
decision-preserving source endomorphism.
\end{enumerate}
Consequently $|X(\mathcal P\times K)|\le2$.
\end{theorem}

\begin{proof}
Assume (i).  Fix $A_0\in\mathcal P$.  Program replacement gives
$X(A,x)=X(A_0,x)$ for every $A,x$.  Source collapse then gives
\[
 X(A,x)=X(A_0,x)=X(A_0,y_{b(x)}).
\]
Define $g(a)=X(A_0,y_a)$.  This proves (ii), and the nonempty fibers make $g$
unique.  If (ii) holds, constant program replacement changes neither $b(x)$
nor $g(b(x))$, while every decision-preserving endomorphism $\tau$ satisfies
$b(\tau(x))=b(x)$.  Thus (iii) follows.  Statement (iii) includes the
specific maps in (1), so it implies (i).  Equation (3) proves the range bound.
\end{proof}

The proof is finite and model-independent at the level stated.  It does not
infer runtime from the number of quotient classes.

\begin{corollary}[Signed clean core under $P=NP$]
Let $K=\Hsigned$ use its canonical indexed encoding and let
$\mathcal P=\PolySAT$.  Under the \COND{} premise $\SAT\in\mathsf P$,
every $\rho_B$ and $\kappa$ in (1) is a uniform polynomial-time exact
transformation.  Hence any resource invariant under all polynomial exact
program replacements and all polynomial SAT-preserving source endomorphisms
has the form $X(A,F)=g(\SAT(F))$.
\end{corollary}

\begin{proof}
A constant program transformer emits the fixed finite code of $B$.  The
source transformer runs one assumed polynomial SAT decider and emits one of
two fixed clean-core representatives.  If that decider has time $T_A(N)$ and
space $S_A(N)$, the complete source transformation costs
\[
 T_\kappa(N)=T_A(N)+N^{O(1)},\qquad
 S_\kappa(N)=S_A(N)+N^{O(1)},                             \tag{4}
\]
including recognition, parsing, and output.  D\"ocker's NP-completeness
theorem for the signed Monotone $3$SAT-$(2,2)$ core and the explicit YES/NO
blocks in the corpus supply the two representatives.  Apply the theorem.
\end{proof}

Equation (4) inherits the unknown polynomial exponent.  The corollary is
compatible with $P=NP$ and yields no FLMV contradiction.

\section{Coverage--collapse trilemma}

The theorem sharpens the repair left by SATQUOT1.
\begin{enumerate}[leftmargin=1.6em]
\item A child-preserving grammar such as DIRECT/DEAD/COPY/DELAY/INTERP/RECOMP
preserves an inert base-program tag.  TESTS-0011 proved that distinct tagged
bases occupy distinct components.  Such a grammar can retain program detail,
but does not cover every program: \textbf{coverage is OPEN}.
\item Adding all constant program replacements covers the program coordinate,
but MODELBRIDGE-0016 and LB-0011 show that every invariant factors through the
source.  No internal materialization theorem follows.
\item Under $P=NP$, adding all polynomial SAT-preserving source endomorphisms
includes $\kappa$ and collapses the remaining source coordinate to the SAT
bit by the present theorem.
\end{enumerate}

Therefore \texttt{FULL-TWO-AXIS-COVARIANCE-OBSTRUCTION1} is \RETIRED.  The
smallest repair is not ``more invariance.''  It is one explicitly defined,
nonconstant, core-changing compiler $C$ with a proof that
\[
 \forall A\in\PolySAT\ \exists\text{ one fully charged ordinary
 realization }M_A
\]
lands in the \emph{same} cited unconditional forbidden region, with fixed
parameters independent of $A$'s polynomial exponent.  This is
\texttt{RESTRICTED-NATURALITY-COMPILER1}, still \OPEN and separation-strength.

\section{Literature and transfer audit}

Baker--Gill--Solovay's oracle theorem is a \KNOWN{} barrier: opposite
$P$--$NP$ outcomes occur relative to different oracles~\cite{BGS75}.  The
present factorization relativizes: replace $b$ by $b^O$ and use the same
constant maps and fiber representatives.  Therefore it cannot itself be the
missing nonrelativizing separation.

Aaronson--Wigderson strengthen the warning to algebraic oracle
access~\cite{AW09}.  The present proof uses only equality and composition and
survives low-degree extension access; it supplies no nonalgebrizing hinge.
Blum's axiomatic complexity framework~\cite{Blum67} concerns declared
complexity measures for indexed programs.  It does not force a chosen
compatibility resource to appear inside every SAT computation, so importing
it here is a \textbf{FAILED TRANSFER}.

Fully abstract and robust compilation makes the need for an explicit
compiler relation precise in programming-language semantics~\cite{Abate18}.
Object correspondence: SAT programs are source/target programs and the
proposed resource is an observation.  What transfers is only the proof
discipline: preservation is a theorem about a specified translation and
observation model.  What does not transfer is an unrestricted SAT
time/space lower bound.  Status: \textbf{ANALOGY/CANDIDATE} requiring the
missing compiler and resource theorem.

In the post-quantum ledger, Schur squares, quadratic relation ranks, Hilbert
functions, syzygies, collision entropy, and special-soundness are
\textbf{EXACT OBJECT/THEOREM TRANSFER} only after a specific code or opening
relation is fixed.  They do not defeat (3), and no such object is forced by a
one-bit decider.  LWE-style worst-case/average-case architecture is an
\textbf{ANALOGY/CANDIDATE}; the missing bridge is an unconditional,
worst-case, all-decider extractor.  Hash/random-oracle binding is a
\textbf{FAILED TRANSFER} for an unconditional proof.

\section{Barrier and hostile-control audit}

\paragraph{One-bit output.}
The quotient's two possible values match the answer alphabet.  This is a
ceiling on an invariant, not a lower bound on exposed machine state.

\paragraph{Wrappers and alternate representations.}
Constant program replacement is stronger than the six child-preserving
wrappers.  If a resource excludes replacement to retain implementation
detail, its all-program coverage requires a separate theorem.  Padding,
renaming, complementation, compact circuits/branching programs, and
re-encodings do not change the abstract proof; they remain controls on any
proposed restricted compiler.

\paragraph{Easy languages.}
Horn propagation, 2SAT implication graphs, affine Gaussian elimination, and
bounded-treewidth dynamic programming show that rich semantic compatibility
can coexist with polynomial shortcuts.  The theorem correctly collapses only
the declared invariant and makes no cost claim for these families.

\paragraph{Natural Proofs and nonuniformity.}
No constructive large circuit property is used, so Razborov--Rudich is not
the direct reason the theorem stops.  Allowing nonuniform programs does not
repair universal coverage: constant replacements still factor the program
coordinate, while the project target explicitly requires uniformity.

\paragraph{\same.}
The transformations are separate computations with costs (4).  Their
existence does not prove that the original run $A(F)$ computed $\kappa(F)$ or
materialized $X$.  Any promotion to execution cost would violate
\same{} unless an explicit model-preserving compiler is supplied.
