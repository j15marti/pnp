\section{Target, four falsifiers, same-source semantics}
We study a single component of the universal state-dependent parameterized residual-SAT controller: an independently checked learned source clause from an affine contradiction \emph{under source-variable guards}. The original CNF $F$ is immutable. Every occurrence $x_{i,j}$ has its original signed polarity and clause ID $j$; guards, private split variables, and source variables never become independent occurrence assignments. The controller may retain the learned clause across policy switches but cannot delete the parent without a separately proved equivalent encoding. All failed recognizers and recognition/source/proof costs are paid.

\begin{enumerate}
\item[] \textbf{F1 (falsified as a general rule):} Pooling conditional XOR rows without checking guard consistency always produces a nontrivial source blocker. A pair with guards $g$ and $\neg g$ yields only the tautology $g\lor\neg g$.
\item[] \textbf{F2 (proved for authenticated blocks):} A GF(2) dependency with zero total variable incidence and odd total RHS exports a source-valid clause formed from its guards; the checker can validate the proof without visiting all global flip assignments.
\item[] \textbf{F3 (falsified):} Three of four canonical XOR3 forbidden patterns suffice to authenticate an entire parity equation. Omitting a source parent removes the row certificate and the producer refuses export.
\item[] \textbf{F4 (falsified on the implementation):} A shorter learned source blocker automatically generates an $N^{1/2}$ ordinary-SAT child and fits the $N^{1/2}$ writable-space target. The explicit $F\wedge D$ output retains the entire parent, and the Python implementation retains the full source in memory.
\end{enumerate}

\section{Exact reconstruction from indexed signed source clauses}
For three distinct data variables $u,v,w$ and parity $b\in\{0,1\}$, let $\mathcal P_b(u,v,w)$ contain the four proper width-three clauses, each excluding exactly one triple $(a_u,a_v,a_w)$ whose parity differs from $b$. For a signed guard literal $g$ disjoint from $\{u,v,w\}$, define the guarded block
\[
 Q_{g,b} \;=\; \bigwedge_{C\in\mathcal P_b(u,v,w)}(g\lor C).
\]
If $g$ is false, this enforces $u\oplus v\oplus w=b$; if $g$ is true, all four clauses are vacuous. Every four-literal member $g\lor\ell_1\lor\ell_2\lor\ell_3$ is replaced by two \emph{original proper 3CNF} clauses with a fresh private split bit $z$:
\[
 (g\lor\ell_1\lor z)\land(\neg z\lor\ell_2\lor\ell_3).
 \tag{1}
\]
For every setting of the four outer variables,
\[
 \exists z\,[(g\lor\ell_1\lor z)\land(\neg z\lor\ell_2\lor\ell_3)]
 \ \Longleftrightarrow\ g\lor\ell_1\lor\ell_2\lor\ell_3.
 \tag{2}
\]
The source clauses in (1) resolve on $z$ to the displayed four-literal clause. The recognizer obtains original source-parent indices by scanning the signed incidence list and testing private variables with one positive and one negative occurrence. It groups the resulting authentic four-literal resolvents by signed guard and three-variable support, and accepts \emph{only} the complete four-pattern parity truth table. It does not trust a promised variable-occurrence link, guessed splitter, signed-name convention, or the declared generator metadata. Distinct source blocks are source-index disjoint in this implementation; rejecting a valid overlapping block is allowed because the exact DPLL fallback remains.

\begin{theorem}[Guarded affine dependency yields a source-only blocker]
Let $F$ be any finite original CNF, and suppose source-indexed local-resolution checks authenticate guarded parity blocks $Q_{g_i,b_i}$ for row indices $i\in J$. Write $v_i\in\mathbb F_2^X$ for each block's three-variable incidence vector. If a nonempty index set $I\subseteq J$ satisfies
\[
 \bigoplus_{i\in I}v_i=0,\qquad \bigoplus_{i\in I}b_i=1,
 \tag{3}
\]
then, writing $G_I=\{g_i:i\in I\}$,
\[
 \boxed{F\models D_I:=\bigvee_{g\in G_I}g,\quad F\wedge D_I\equiv F.}
 \tag{4}
\]
If $G_I$ contains complementary literals the clause is a tautology, not a useful learned blocker. Otherwise it prohibits exactly the original-variable guard cube setting every $g\in G_I$ false. This implication holds on the same original source for SAT and UNSAT cases, and its validation requires only the original parent-pair resolutions, four-row parity truth tables, and the explicit GF(2) row-combination witness. It does \emph{not} assert that the learned clause has a short ordinary resolution proof.
\end{theorem}
\begin{proof}
Every source parent pair implies its resolved four-literal clause. The four checked patterns for row $i$ therefore force $v_i\cdot X=b_i$ whenever $g_i$ is false. If an original-source model falsified $D_I$, it would falsify each $g_i$ in the dependency and satisfy all equations. XOR of their left sides would be $0$ by (3), while XOR of the right sides would be $1$, a contradiction. Hence every source model satisfies $D_I$, and conjoining it leaves precisely the same models. This argument never frees source literal occurrences or assumes that an unrecognized part of $F$ is affine.\qed
\end{proof}

\paragraph{Typed proof provenance.} A source clause is an axiom. A local split parent pair justifies its four-literal resolvent by the ordinary resolution rule. A complete quartet of these justifies a conditional XOR3 equation by an eight-case finite truth table. An XOR-combination node has two authenticated rows as parents and records exact bitmask/RHS XOR. A zero-mask, RHS-one node exports the guard union. This \emph{hybrid GF(2)/resolution certificate} must be checked as such, not mislabeled pure resolution or RUP. All other original clauses remain present. A SAT answer requires a full source assignment checked against every original clause. On UNSAT control instances below, source-only resolution also derives each forced guard unit, and the typed learned blocker plus these units has an explicit empty-clause refutation. The verified implication in (4) makes that mixed proof sound.

\section{Cycle family, complete both-label controls}
Fix even $r\ge4$. Let $x_1,\ldots,x_r,a$ be data variables, and let $g_1,\ldots,g_r$ be fresh guard variables. Encode for $i=1,\ldots,r$ the parity rows
\[
 x_i\oplus x_{i+1}\oplus a=b_i,\qquad x_{r+1}=x_1,\quad b_1=\cdots=b_{r-1}=0,\quad b_r=1,
 \tag{5}
\]
using four signed forbidden patterns and the eight proper ternary split clauses per row, all guarded by $g_i$. Each $x_i$ appears twice, and $a$ appears $r$ times, so for even $r$ the XOR of every left side vanishes but the RHS XOR is one. Deleting any single parity row leaves a satisfiable linear system; all guards true also trivially satisfies the source parity blocks.

For a SAT parent, force $g_1=1$ and all $g_{i>1}=0$. For an UNSAT parent force all $g_i=0$. Every force is encoded in original proper 3CNF by the four clauses $(\ell\lor\pm p\lor\pm q)$, with two fresh auxiliary variables. The quartet entails $\ell$ through three standard resolution steps. Consequently the UNSAT parent has a mixed certificate ending in the empty clause; the SAT parent has a complete checked source witness. Independently rename/complement original variables, including a split private bit and a guard: the same authenticated rule survives.
