\section{Mandatory indexed signed-occurrence extrema and coherent inversions}
Fix the \emph{original} proper ternary CNF $F=\bigwedge_{j=1}^m C_j$. Every source occurrence $x_{i,j}$ denotes the signed occurrence of the \emph{same} variable $x_i$ in original clause $C_j$; no occurrence is a separately assignable variable. For each $C_j$, $S_j$ sets each source literal TRUE, and $U_j$ sets each source literal FALSE. If the original occurrence is positive, $S_j(x_i)=1,U_j(x_i)=0$; if negative, $S_j(x_i)=0,U_j(x_i)=1$. Inverting $S_j$ yields $U_j$ and inverting $U_j$ yields $S_j$, each recorded separately in the full raw results. Such targets for different original clauses may be mutually inconsistent. A clause is ordinarily SAT when it has at least one TRUE literal; it need not be in local extreme $S_j$.

For two distinct original clauses $C_j,C_k$, their exact matrix $(SS,SU,US,UU)$ satisfies $SS=UU=1$ precisely when no shared source variable has opposite literal signs; $SU=US=1$ precisely when no shared source variable has the same sign. If both types occur, all four mode assignments are impossible and at least one original clause is in a middle truth-count state (one or two true literals) under any coherent complete assignment. This does not establish formula UNSAT. The reproducibility program constructs the full indexed matrix and checks it against complete enumeration of each pair's shared original-variable support, separately from all algorithmic cost measurements.

For any coherent complete assignment $a\in\{0,1\}^n$, $t_j(a)$ is the number of TRUE original literals of $C_j$, and $N_q(a)=|\{j:t_j(a)=q\}|$ for $q\in\{0,1,2,3\}$. The genuine globally consistent endpoint assignments $0^n$ and $1^n$, their complete complements, and one-, two-, three-, four-, and six/seven-variable flip trails are recorded with every source clause's $t_j$ and all four categories. The complement identity
\[t_j(\bar a)=3-t_j(a),\qquad \vN(\bar a)=(N_3,N_2,N_1,N_0)(a)\]
is checked for every proper ternary source. The proof-carrying source-parent resolution audit also records legitimate $(x\lor A),(\neg x\lor B)\vdash(A\lor B)$ consequences (when non-tautological), their original clause indices, opposite unit demands, and the original-variable cube forbidden by the resolvent. \section{Conservation and exact rank-two quotient}
\begin{theorem}[Rank-two four-category conservation, every coherent assignment]\label{thm:two}
Let $F$ be any proper ternary CNF for which each original source variable has equally many positive and negative signed occurrences. The number $m$ of source clauses is even. For \emph{every} complete coherent assignment $a$, including SAT and UNSAT candidates,
\begin{equation}\label{eq:conservation}
\boxed{N_1(a)=\frac m2-2N_0(a)+N_3(a),\qquad N_2(a)=\frac m2+N_0(a)-2N_3(a).}
\end{equation}
Consequently the full four-category vector is recovered exactly from $(N_0,N_3)$ and known $m$. If $a$ is a base assignment and $S$ is any set of original variables, its count-change vector satisfies
\[\boxed{\Delta N_1=-2\Delta N_0+\Delta N_3,\qquad \Delta N_2=\Delta N_0-2\Delta N_3.}\]
The representable difference vectors form a subset of a rank-two integral lattice. Full inversion acts by $(N_0,N_3)\leftrightarrow(N_3,N_0)$.
\end{theorem}
\begin{proof}
If original variable $x_i$ has $d_i$ positive and $d_i$ negative occurrences, then exactly $d_i$ of its $2d_i$ occurrences are TRUE under any complete assignment, independently of its Boolean value. Therefore the total number of TRUE literal occurrences is $\sum_i d_i=3m/2$, so $m$ is even. Counting TRUE occurrences by original clause gives
\[N_0+N_1+N_2+N_3=m,\qquad N_1+2N_2+3N_3=3m/2.\]
Eliminating $N_1,N_2$ gives (\ref{eq:conservation}). Subtraction for $a\oplus S$ and $a$ yields the change identities. The complement statement follows independently from complementing every source literal's truth value. No source-SAT answer bit is used.\end{proof}

\begin{corollary}[Two exact Laurent generators]\label{cor:laurent}
For any formal signed-count monomial associated with a coherent flip $S$,
\[z_0^{\Delta N_0}z_1^{\Delta N_1}z_2^{\Delta N_2}z_3^{\Delta N_3} = U^{\Delta N_0}V^{\Delta N_3},\quad U=z_0z_1^{-2}z_2,\quad V=z_1z_2^{-2}z_3.\]
Therefore the complete four-category radius-$r$ generating function of sign-balanced proper source 3-CNF factors exactly through the Laurent ring $\Q[U^{\pm1},V^{\pm1}]$. No clause or assignment is lost by this algebraic specialization, and the original four counts are reconstructible. If each original variable has at most $d$ occurrences, the allowed degree-$r$ Laurent shift labels lie in an $O((dr)^2)$ box, versus a naive $O((dr)^3)$ box after only the universal sum-of-counts conservation is used.
\end{corollary}
\begin{proof}
Substitute the exact difference identities of Theorem~\ref{thm:two} and collect powers of $\Delta N_0$ and $\Delta N_3$. Flipping $r$ original variables can affect at most $dr$ distinct source clauses, so $|\Delta N_0|,|\Delta N_3|\le dr$. The resulting monomials are indexed by at most $(2dr+1)^2$ integer pairs. This is a bound on potential \emph{labels}, not a count of actual realized outputs, nor a SAT runtime lower bound.\end{proof}

\noindent\textbf{Two coordinates are genuinely necessary for a linear rank representation across the full strict22 class.} For the authenticated connected strict22 W1 source at base $0^{15}$, direct source evaluation gives $\vN=(1,10,7,2)$. Flipping only original variable $x_3$ changes $(N_0,N_3)$ by $(1,1)$, whereas flipping only original $x_7$ changes it by $(1,0)$. These two realizable vectors are linearly independent over $\Q$. Thus no \emph{single linear coordinate} can recover all such full clause vectors by a linear invertible map on this source. This is not an information-theoretic lower bound for arbitrary nonlinear encodings or for a SAT-only query.

\section{Exactly compiled radius spectra, explicit source charges}
\begin{lemma}[Quotient specialization of the connected-log compiler]\label{lem:log}
On a proper original ternary source with maximum original-variable occurrence degree $d$, for any complete source assignment $a$ and fixed flip radius $r$, the source-indexed connected-log method constructs the full radius-$r$ four-category histogram in $f(r,d)(n+m)$ exact ring operations and working ring words. If the signed source is balanced, every Laurent arithmetic operation can be performed with only the two variables $U,V$ of Corollary~\ref{cor:laurent}; the final count vector is reconstructed from $(N_0,N_3)$ using Theorem~\ref{thm:two}. For the narrower task of testing whether any radius-$r$ assignment satisfies $F$, a \emph{one-coordinate} Laurent specialization tracking only $N_0$ suffices even without balance. These three representations compute the same SAT count, but only the two- and four-coordinate representations return the full four-category histogram.
\end{lemma}
\begin{proof}
Let $G$ be the graph joining original source variables that co-occur in an original clause; its degree is at most $2d$. Define $D(S)=\vN(a\oplus S)-\vN(a)$ and the multiactivity source generating polynomial
\[Z(\boldsymbol u,\boldsymbol z)=\sum_{S\subseteq[n]}\Bigl(\prod_{i\in S}u_i\Bigr)\boldsymbol z^{D(S)}.\]
If a variable subset $T$ is disconnected in $G$, all original clauses affected by distinct components are disjoint, so $Z_T$ factorizes and $\log Z_T$ is additive. Hence every coefficient of $\log Z$ whose multiactivity monomial has disconnected support vanishes. Enumerate connected supports $T$ of size at most $r$, at most $n(1+2d)^{O(r)}$; each local $Z_U$ for $U\subseteq T$ is obtained from at most $2^r$ coherent original-variable flip subsets and at most $dr$ touched source clauses. Evaluate the truncated local formal logarithm and perform Moebius inclusion-exclusion on $U\subseteq T$ to retain exactly support-$T$ terms. Sum these terms to construct $L_k$, the coefficient of uniform flip activity $t^k$ in $\log Z$, for $k\le r$. Recover $E_0=1$ and $kE_k=\sum_{j=1}^k jL_jE_{k-j}$. The coefficient $E_r$ counts all coherent radius-$r$ assignments by full clause-status differences. This procedure is exact in any homomorphic image of the Laurent coefficient ring, including the two-coordinate quotient when balanced and the one-coordinate $N_0$ specialization for the SAT-only query. Every source scan, support discovery, local enumeration, polynomial multiplication, and exponential join is an actual operation, not an oracle. The number of arithmetic terms is bounded by a computable $f(r,d)$ per original source variable. Exact coefficient bit lengths can grow with $r\log n$; RAM word counts require a declared word size and bit costs on a physical tape or UTM are larger.\end{proof}

\noindent\textbf{Scope and falsification firewall.} Sparse four-coordinate maps on a balanced formula already have rank-two support, so simply replacing 4-tuples with 2-tuples does \emph{not} remove an asymptotic number of occupied sparse keys. It reduces index width and the bound for naive dense coefficient arrays, and may alter constant-time performance. The one-coordinate query intentionally discards the $N_3$ information and may not be used as a full four-category histogram. For $r$ growing with $n$, $f(r,d)$ can be exponential; the result does not decide unrestricted SAT in polynomial time. Any witness from a positive SAT count must be explicitly reconstructed and checked. The source-weighted derivative method of DERIVATIVE-WITNESS248 supplies one such charged restricted construction; the simple current hybrid deliberately falls back to standard DPLL instead of treating the count as a free witness.

\section{Machine-specific accounting, barriers and handoff}
The mathematical operation count is for uniform exact indexed-word arithmetic with a read-only original source of $N=\Theta((n+m)\log n)$ bits, explicit source parsing and all unsuccessful algebraic paths charged. For fixed $r,d$, arithmetic coefficients have $O_{r,d}(\log n)$ bits and fit in $O_{r,d}(1)$ logarithmic words. If $r$ grows, word packing, rational denominators, CPU memory bandwidth, tape head crossings and bit-complexity must be separately accounted for. The implementation records construction work, source clause/literal accesses, unsuccessful DPLL branches, true same-call peak Python traced allocations, and exact endpoint/full-sphere comparisons; its measurements do not charge absent-native machine quantities as zero. Input scans and representation conversions are in the implemented profiles; a controller that also builds the $O(m^2)$ compatibility audit must add that full cost.

No all-algorithm lower bound follows from these coefficient representations. Gaussian elimination can solve affine XOR controls, ordinary implication graphs can solve 2SAT, and unit propagation handles Horn controls. Recognizable easy structural subfamilies may bypass every generating-function step. Neither automatic differentiation nor a shorter coefficient vector supplies a missing polynomial-time unrestricted SAT bridge. This work does not invoke an oracle, assume unknown SAT witnesses or change any repository agent/task schedule.
