## IDEA and four falsifiers set before searching

Hypothesis: a verified completed suffix of a deterministic SAT guest can be reused across two DIFFERENT checkpoint memory states when the second state agrees only on (a) actual input bits observed by the anchor suffix and (b) WORK/INDEX cells first read before any suffix write. This is a strict improvement in *eligibility* over the identical-snapshot condition in LSPV-2/501 and does not require all checkpoint memory to match. The guest's program, program counter, control state, relevant head positions, input length and branch-local assumptions must still match. Potential falsifiers: (F1) a difference at a cell overwritten before its first read changes the observed execution; (F2) an adaptive read accesses an initially differing cell omitted from the dependency set; (F3) a different input bit or forged untrusted anchor trace permits false reuse; (F4) a giant anchor trace or high-address guest snapshot is charged as free or silently declared FLMV-compliant.

## ITERATE: exact theorem, proof, and falsifier outcomes

**Theorem 505.1 (PROVED/RESTRICTED, sufficient live-in quotient).** Let M be any fixed deterministic transition machine with read-only input and mutable WORK/INDEX cells. Two checkpoints C and C' have the same control state (including program counter, all non-memory registers, INDEX/head state, length and branch assumptions) but may differ arbitrarily in WORK/INDEX contents. Let tau be a complete internally trusted halting suffix of M from C on input x. Define I(tau) as the set of INPUT bits read during tau, and L(tau) as the set of WORK/INDEX cells read *before their first write during tau*. If x' has the same length and agrees with x on I(tau), and C' agrees with C on every cell in L(tau), then the suffix from (C',x') has the identical sequence of observed control transitions, input/WORK reads, writes and output label as tau. Untouched memory cells need not be equal.

**Proof:** Induct over successive transitions. Every INPUT read obtains the same recorded bit by I(tau). Every WORK/INDEX read either precedes the first write to that cell (equal by L(tau)) or reads a value from an identical previous write (equal by induction); indexed head moves and index erasures are writes accounted for in the inductive state. Finite control and active head positions remain identical, so the next instruction and all writes match. The deterministic machine therefore reaches the same HALT label. QED. This is not proof-system inference and does not make different final memory snapshots equal.

**Corollary 505.2:** The criterion strictly extends full snapshot equality: arbitrary changes to unused cells and cells overwritten before their first read are harmless. It is sufficient, NOT necessary: a differing live-in bit might be ignored semantically, but certification conservatively rejects. A guest that copies all child bits into a marker and later reads them defeats this quotient, consistent with LSPV-2/502. No source-local case assumptions may leak between branches.

**Revision after the tests and literature:** This is *not* a small universal sharing certificate. The anchor future-read set is not known before the guest actually runs. An untrusted externally supplied trace is not enough; full replay/source authentication or an independently proved trusted trace constructor is necessary. Its construction may cost the full guest time and huge storage, and might fail the native FLMV space envelope. Only the restricted semantic trace criterion is established, NOT a portable physical compressor.

## Fully charged resource ledger and limitations

Let T be anchor suffix length, p distinct INPUT read positions, d distinct WORK/INDEX live-in cells, and a maximum address-bit length a. An explicit live-in record of addresses and bits needs O(p log(N+2)+d a) bits; verifying another checkpoint costs O((p+d) polylog(N+2) + checkpoint-cell access) machine time **conditional** on a physically realizable indexing interface. A naive anchor execution trace requires Theta(T a) bits, and determining whether a cell was written before reading can require a separate write-set of up to T distinct addresses. Checkpoint construction, input parsing, guest/work/index memory, trace authentication, retention/recomputation, fallback guest calls, output, erasure and full simultaneous peak MUST be charged. For q=N^(3/5+o(1)) and child length L=N^(1/2+o(1)), checking all L child input bits costs qL=N^(11/10+o(1)), exactly the local time budget but does not improve guest time or produce children. The VM's sparse Map at address 1,000,000 is not a native space bound: FLMV WORK high-water counts that address. Thus neither t'<=max(11/10,3/5+t/2) nor s'<=max(1/2,s/2) is proved by this experiment.

The trace is a computational execution DAG; it does not modify native R_mix341 grammar, weights or SOURCE/AND/OR inference obligations. Sound sharing among SAT branches does not discharge both UNSAT sides of a split by fiat, and a free best-derivation proof minimum does not entitle an implemented algorithm to free discovery. Work, critical-path depth and realizable time/space scheduling remain separate quantities.
