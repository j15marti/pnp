\section{Exact statement and proof}
Represent the original formula $F=\bigwedge_{j=1}^{m}C_j$ by indexed proper clauses and let $\rho$ be a coherent partial assignment to original variables. Let $\overline\rho$ be the clause containing precisely the literals falsified by $\rho$.
\begin{theorem}
Complete source-clause DPLL on $F|_\rho$ returns either a full verified original-source SAT witness extending $\rho$, or an ordinary binary resolution DAG, using only indexed original clauses as axioms, that derives $D\subseteq\overline\rho$. In the NO case $F\models D$ and $F\wedge D\equiv F$, so $D$ remains valid through arbitrary policy switches. If $\rho$ is empty, a NO result derives the empty clause. This has no polynomial time guarantee.
\end{theorem}
\begin{proof}
Maintain by induction: at each search state $\tau\supseteq\rho$, a NO result has a source-only resolution proof of a clause $D_\tau$ falsified by $\tau$. A false original clause is a proof leaf. If every original clause is true, verify and return a complete witness. Otherwise branch on an unassigned original variable $x$. A NO from the $x=0$ branch has $D_0\subseteq\overline\tau\cup\{x\}$ and a NO from $x=1$ has $D_1\subseteq\overline\tau\cup\{\neg x\}$. If the first blocker omits $x$, it already blocks both branches and permits skipping the sibling. Likewise if the second omits $\neg x$. Otherwise resolve on $x$, obtaining a nontautological clause using only $\overline\tau$, hence falsified at the parent. All derivations use original-source clauses and valid resolution steps. At the root this gives the claimed blocker, and original-source entailment follows from the soundness of resolution.
\end{proof}
