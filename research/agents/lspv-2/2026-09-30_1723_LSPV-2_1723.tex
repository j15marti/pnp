\section*{LSPV-2 typed-domain product-span audit}
\textbf{STATUS: OPEN.} P versus NP remains open.

\textbf{Reviewed.} Root main.tex; verified MAIN 54501-R1; LSPV-1 1707; LSPV-2 50201; LSPV-3 42301-R1; LSPV-4 104601; CLAUDE-0266. Primary literature: Shaltiel--Umans, SIAM J. \textbf{Exact typed coordinate adopted from LSPV-1.} For fixed SAME\_REALIZATION polynomial $\widehat g$,
\[
g_j(\sigma,L,y)=\pi_j(E^{\widehat g_{\sigma,L}}(y)),\quad 1\le j\le m.
\]
The source domain is $U=\{(\sigma,L,y)\}$. Adaptive query addresses are internal to deterministic oracle computation $E$, not free source coordinates.

\textbf{PROVED/EXACT: typed pullback identity.} Define
\[
\Phi_2(u)=(1,g_i(u),g_i(u)g_j(u))_{i<j}.
\]
For $H=g(U)$ and $M=1+m+\binom m2$,
\[
\rho(E_H)=\operatorname{rank}_{\mathbb F_2}\{\Phi_2(u):u\in U\}
=\dim_{\mathbb F_2}\operatorname{span}\{1,g_i,g_i g_j\}
\le\min\{|H|,|U|,M\}.
\]
This is the strongest rank bound justified by the currently exposed interface alone.

\textbf{OPEN.} The checked primary statements give an oracle local extractor, parameters, and RM/MV restrictions, but not the Boolean ANF or Schur-product law of $[E^X(y)]_j$ after $X=\widehat g_{\sigma,L}$. Thus no bounded Boolean degree $d$, common affine dimension $r$, or $O(m)$ product span is verified for the actual map. RM linearity in polynomial coefficients is typed to the wrong varying domain: here the variables are $(\sigma,L,y)$.

\textbf{CONDITIONAL sparse-Q ledger.} If architecture-specific work proves $\rho=r_2<M$, Singleton for $K_2(H)=\ker E_H$ yields a nonzero degree-at-most-2 annihilator with ANF weight at most $r_2+1$. Monomial-list description costs $O((r_2+1)\log m)$ bits and direct fan-in-2 evaluation costs $O(r_2+1)$ gates. For $r_2=O(m)$ these are $O(m\log m)$ and $O(m)$. Any nonzero Boolean quadratic has density at least $1/4$. Acquisition, normalization, census/output, and reconstruction quantifiers remain separately charged.

\textbf{Falsification boundary.} No $\Omega(m^2)$ minor is proved. Retirement requires an independent quadratic-feature minor inside the fixed canonical extractor, not arbitrary relabeling or arbitrary efficient orbit labels. Short source, list decodability, field degree, locality, canonicity, and Left/Right syntax remain invalid generic shortcuts.

\textbf{Restriction compatibility.} Local low-rank restrictions do not suffice unless annihilators descend from one root $Q$ or obey a proved canonical compatibility map. Unrelated existential $Q_\rho$ are forbidden.

\textbf{Hostile audit.} A maximal semantic/algebraic oracle can reveal rank or $Q$, so this step is not a nonrelativizing hinge. DEAD/COPY/DELAY/INTERP/RECOMP, padding, affine/Tseitin, Horn, 2-SAT, and bounded-treewidth controls forbid interpreting product span as unrestricted runtime. TransportCert remains an obligation interface.

\textbf{Handoffs.} LSPV-1: recover the explicit local-extractor implementation and expose each oracle query/binary projection. LSPV-3: use $|Q|_{ANF}\le r_2+1$ only after actual $r_2$ is proved. LSPV-4: an architecture-preserving falsifier must produce an independent minor inside fixed canonical $E$.
