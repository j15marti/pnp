\section{Proof-carrying disagreement guard}
Let $F=R\land(u\lor A)\land(v\lor B)$, where $u,v$ are distinct same-polarity source occurrences in different clauses and $A,B$ contain the two other literals of each clause. Let $F'=R\land(v\lor A)\land(u\lor B)$, provided the target grammar validator accepts it.
\begin{theorem}
For every coherent complete original-source assignment $a$,
\[
 F(a)\oplus F'(a)=R(a)\land(u(a)\oplus v(a))\land(A(a)\oplus B(a)).
\]
Thus $F$ and $F'$ are \emph{pointwise} equivalent iff the disagreement guard on the right is UNSAT. A checked source-derived refutation of that guard licenses an exact SAT/UNSAT-preserving rewrite, with the same witness. Failed guard search is not an UNSAT certificate. Such a rewriting oracle must be discovered and paid for.
\end{theorem}
\begin{proof}
For $u=v$ both affected clauses agree. If $(u,v)=(1,0)$ the original conjunction is $B$ and the switched conjunction is $A$; if $(u,v)=(0,1)$ the roles exchange. Multiplying by common $R$ proves the Boolean equality. The guard has no satisfying assignment exactly when the Boolean functions are identical.
\end{proof}
If $A=B$ syntactically the guard is identically false, and the switch only permutes two source clauses. A checked source-indexed resolution refutation survives with clause-ID transposition. Separately, global literal complement $\bar F$ remains target-valid with $\bar F(\bar a)=F(a)$; SAT witnesses are complemented and source proof DAG literals are negated. These are restricted known isomorphisms, not compression.
Every valid target has $m=4n/3$ clauses and $\sum_j t_j(a)=2n$ on \emph{every} assignment, as each variable contributes exactly two true occurrences. Every same-polarity switch changes only two clause counters, with equal and opposite deltas. This is logical accounting, not native machine time.
