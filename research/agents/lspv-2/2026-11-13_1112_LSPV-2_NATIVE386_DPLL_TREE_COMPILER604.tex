\section*{Theorems and derivation}
\begin{lemma}[Strict Resolution extraction from a contradiction-search tree]
Let $F$ be any finite unsatisfiable CNF without empty source clauses. Consider a finite binary decision tree assigning Boolean variables. Every leaf must name an \emph{original clause of $F$} all of whose literals are falsified by that leaf's partial assignment. Then there is a chronological, weakening-free, source-only Resolution DAG $\tau(D)$ deriving $\bot$ from $F$ with no more than $I(D)$ strict Resolution nodes, where $I(D)$ is the number of internal decision nodes. The same source node can be shared freely across many leaves, and each distinct new RES inference is paid once.
\end{lemma}
\begin{proof}
By induction on a subtree rooted at partial assignment $\alpha$, associate an existing original SOURCE or a previously compiled RES index whose clause $C_\alpha$ has every literal false under $\alpha$. This holds at each conflict leaf by construction. For an internal query $x$, let $A$ and $B$ be the already compiled clause indices for $\alpha\cup\{x=0\}$ and $\alpha\cup\{x=1\}$. The first returned clause cannot contain $\neg x$ and the second cannot contain $x$, since those literals would be satisfied. If the first clause lacks $x$, it is already false under $\alpha$ and may be reused. Otherwise if the second lacks $\neg x$, reuse the second. In the remaining case both clauses contain $x$ and $\neg x$ respectively. Emit the strict resolvent $C=(A\setminus\{x\})\cup(B\setminus\{\neg x\})$. Every remaining literal is false under $\alpha$, so $C$ cannot be tautological and is a genuine clause consequence of $F$. Each internal vertex thus contributes zero or one RES; parent references are chronological. At the root $\alpha=\varnothing$, a clause all of whose literals are false under an empty assignment must be the empty clause. No branch assumptions enter as SOURCE rows, and no explicit discharge operation is assumed.
\end{proof}

\begin{theorem}[Authenticated /386 realization of the restricted tree compiler]
For every odd-charge guarded cubic source accepted by the archived /386 source grammar, and every DPLL decision order, the foregoing algorithm produces a source-bound signed SOURCE+RES packet accepted by the original mathematical \texttt{checkProof} core. Including an explicitly paid, unused fresh conservative owner gives the exact logical charge
\[
\boxed{\quad W_{/386}(\tau(D))=1+R(D)\le 1+I(D),\quad
|\mathrm{records}|=4|V|+1+R(D).\quad}
\]
The bundled original OS CLI additionally invokes hostile self-tests whose syntactic mutations may sometimes be no-ops, depending on the packet. We have verified complete CLI acceptance for the nine concrete cases below, but make no unconditional all-graph or all-order \emph{CLI} acceptance claim; universal acceptance above refers only to the original mathematical \texttt{checkProof} core.\par
The implementation costs $O((mw+n\log(n+1))\,|D|)$ word operations up to the output-serialization cost, where $n$ is the total number of variables, $m$ the number of source clauses, $w$ their maximum width, and $|D|$ the number of visited search nodes; this accounts for signed-clause scans, assignment copying and canonical resolvent sorting. Certificate serialization, source/checker execution, bit costs and peak memory remain separate. This does not bound the certificate by the runtime of an \emph{arbitrary different} correct SAT decider.
\end{theorem}
\begin{proof}
The original-source rows are individually the signed forbidden local parities; their external byte vectors and vertex labels match the parser's generated rows. Every emitted derived record is exactly the strict RES case of the lemma with index-rebased parents and unit tariff, and the terminal record is empty. The real unused gate owner is fresh, acyclic, conservative and has no facets or derivation inputs. The original mathematical core's mandatory counters therefore match. The full CLI also applies mutation self-tests that need not reject when a mutation is a no-op; each of our nine concrete CLI executions separately passes those tests. The bound follows by the lemma. Scanning at most $mw$ source-literal occurrences per visited search node, copying at most $n$ assignments and sorting at most $n$ signed literals per emitted strict inference yields the stated word-operation bound, before writing or checking the proof. Certificate bytes and peak storage are not equated with logical work.
\end{proof}

\section*{What this does and does not establish for the complete chain}
The proof is a concrete positive answer to one narrow B2/B3 feasibility question: \emph{a fully accounted source-bound DPLL tree can be compiled into actual accepted records of a fixed archived native fragment}. LSPV-2/356 already proved a separate proposed-grammar DPLL-to-Resolution translation, LSPV-2/368 proved a falsified-premise-tree lemma, and LSPV-1/568 produced a native original-/386 K4 28-RES elimination. This run supplies a different \emph{executed source-bound DPLL machine compiler} across K4, K3,3 and cube, plus nine verified original-CLI packets and exact guard-order costs. It is not claimed as new general proof complexity theory or a K4 minimum.

There is no authenticated /386 GF(2) opcode. The same odd-parity source is recognizable as contradictory by a simple parity sum, but this \emph{different algorithm's} short computation has not been converted by this construction into a comparably cheap original-/386 derivation. A complete B3 transfer must take an arbitrary correct deterministic SAT decider $A$ and prove, using only authenticated operations of the \emph{same fixed full mixed calculus},
\[
W_R(F)\le c_A(|F|+T_A(|F|))^{r_A}
\]
with $c_A,r_A$ independent of $F$. This run supplies neither an arbitrary-$A$ compiler nor a conversion of a parity machine's output trace to a native GF(2) inference. A source-domain promise does not establish all-input soundness or coverage. Polynomial-time source recognition does not imply polynomial-size Resolution certificates; standard expander-Tseitin Resolution hardness is a warning, but auxiliary definitions and XOR can invalidate such a bound in stronger systems. A cheaper \emph{genuine} mixed shortcut is a falsifier, not a transition to exclude. No proof of [P2-B1] or [P2-C3] follows from the accepted examples.
