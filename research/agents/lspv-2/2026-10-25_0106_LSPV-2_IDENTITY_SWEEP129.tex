\section{Declared source model and mathematical invariant}
A valid closed event stream $e_1,\dots,e_L$ has events OPEN$(v)$, CLAUSE$(\ell_1,\ell_2,\ell_3)$ and CLOSE$(v)$. Each source name opens once, closes once, and every clause uses three different currently live original-source variables. Its live set after position $i$ is $S_i$, with $S_0=S_L=\varnothing$ and $W=\max_i |S_i|$. This validity is a \emph{formal input promise} unless separately checked with charged source reads and a mutable name dictionary. The stream is not an arbitrary ordinary SAT encoding.

Let block budget $2\le b\le L$ and $d=\max(1,\lfloor b/2\rfloor)$. A path $P:0=i_0<\cdots<i_q=L$ is legal when $1\le i_{r+1}-i_r\le b$ and every nonfinal edge has length at least $d$. For $i<j$, let
\[
U(i,j)=|S_i\cup S_j|,\qquad
\widehat C(P)=\sum_{(i,j)\in P}2^{U(i,j)}.
\]
This is the number of candidates \emph{a particular eager method} would enumerate before filtering on block SAT, not necessary work of arbitrary algorithms.

\begin{lemma}[Reverse event union sweep]
For a fixed terminal cut $j$, the entire vector
$U(j-1,j),U(j-2,j),\dots,U(\max(0,j-b),j)$
can be generated from $w_j=|S_j|$ by one backward source-event scan, with no stored $S_i$ sets. Start $u=w_j$ and an empty set $P_{\rm close}$. Crossing one event backwards:
\[
\begin{array}{c|l}
{\rm CLOSE}(v)&u\leftarrow u+1,\quad P_{\rm close}\leftarrow P_{\rm close}\cup\{v\}\\
{\rm OPEN}(v),\ v\in P_{\rm close}
&u\leftarrow u-1,\quad P_{\rm close}\leftarrow P_{\rm close}\setminus\{v\}\\
{\rm OPEN}(v),\ v\notin P_{\rm close}&u\text{ unchanged}\\
{\rm CLAUSE}&u\text{ unchanged}.
\end{array}
\]
After crossing event $e_{i+1}$, $u=U(i,j)$.
\end{lemma}
\begin{proof}
Initially $u=|S_j\cup S_j|$. When reversing CLOSE$(v)$ at or before $j$, the source $v$ is absent from $S_j$ but newly enters $S_i$, so the union grows by one. It is marked as a close already traversed. Reversing OPEN$(v)$ removes $v$ from the earlier boundary. If the same close was crossed, $v\notin S_j$, so the union shrinks by one and its mark is removed. Otherwise its close occurs after $j$ and $v\in S_j$, so removing it from $S_i$ does not change the union. CLAUSE changes no live set. Induction proves every update; the closed-name marks have at most $b$ members.
\end{proof}

\begin{theorem}[Exact true-candidate optimum in a bounded backward window]
For a promised valid indexed named stream, the recurrence
\[
D_0=0,\quad
D_j=\min_{\substack{\max(0,j-b)\le i<j\\
j=L\ \mathrm{or}\ j-i\ge d}}
(D_i+2^{U(i,j)})
\]
computes $\min_P\widehat C(P)$ exactly. A forward scan maintaining $w_j$, a cyclic $b+1$-entry DP array, and the reverse union sweep compute the \emph{optimum value} with $O(b)$ numerical/index and pending-name entries. Using a deterministic balanced name dictionary, the algorithm uses $O(Lb\log(b+1))$ name comparisons and $O(Lb)$ $B$-bit integer operations with
$B=\lceil\log_2(L+1)\rceil+2W+2$.
With paid compression of source names to $1,\dots,V$, a $V$-entry epoch-stamp array gives $O(Lb)$ word operations and $O(V+b)$ live word entries after preprocessing. Storing a full predecessor list for path reconstruction uses an \emph{additional} $O(L)$ entries. None of these bounds includes unpaid validation or ordinary SAT child construction.
\end{theorem}
\begin{proof}
For each $j$, the lemma generates exactly the edge exponents $U(i,j)$ for all eligible predecessors, charging every reread. At step $j$ only predecessors with $j-b\le i<j$ are needed, so a $b+1$-cell cyclic array safely overwrites older DP values. Every eligible last-edge predecessor is examined, so shortest-path induction proves the recurrence. The backward scan makes at most $b$ dictionary updates per $j$, and its pending set has size at most $b$. A balanced dictionary yields the comparison bound. With dense source-name IDs, one may instead mark a CLOSE by stamp $j$ and test/clear that stamp when crossing its OPEN, making updates constant-word-time and using $V$ stamp cells. Every DP number is at most $L2^{2W}$; this gives the displayed $B$-bit bound. The external indexed source remains read-only and all its rereads are counted.
\end{proof}
A conservative elementary-bit implementation bound for the balanced-dictionary version is
\[
O\bigl(N\operatorname{polylog}N+
Lb(B+\log(b+1)\log N)\operatorname{polylog}N\bigr),
\]
and a value-only workspace bound \emph{after valid-source acquisition} is
$O(b(B+\log N)+\log N)$ bits. A general all-input recognizer may require additional $O(V\log N)$ writable bits for full name validity, which is not hidden in the promised workspace claim. Unchanged-value writes, control, addressing and table allocation are charged elementary work. The epoch-stamp variant trades that extra writable memory for $O(Lb)$ word comparisons. Actual complete-machine bit flips and cumulative live-bit-time were not measured.

\section{Sublog-width approximation: a cheap exact mathematical bridge}
\begin{theorem}[Product-optimal schedule approximates named-compatible enumeration]
Write
$C_\times(P)=\sum_{(i,j)\in P}2^{w_i+w_j}$,
and let $P_\times$ minimize $C_\times$ (CUT126), while $P_\cup$ minimizes $\widehat C$.
For \emph{every} valid stream and legal partition class,
\[
\boxed{\widehat C(P_\times)\le 2^W\widehat C(P_\cup).}
\]
Consequently, when $W=o(\log N)$, the near-linear-width-bucket planner preserves the \emph{same polynomial exponent} in this eager compatible-pair enumeration count as exact identity-aware scheduling, because $2^W=N^{o(1)}$.
\end{theorem}
\begin{proof}
For any cut edge,
\[
2^{U(i,j)}
\le 2^{w_i+w_j}
=2^{U(i,j)+|S_i\cap S_j|}
\le2^W2^{U(i,j)}.
\]
Summing over each legal path and using the optimality of $P_\times$ for the product cost gives
\[
\widehat C(P_\times)
\le C_\times(P_\times)
\le C_\times(P_\cup)
\le2^W\widehat C(P_\cup).
\]
\end{proof}
This is more useful near the desired FLMV endpoint than deploying the exact $O(Lb)$ optimizer indiscriminately. For $b=\Theta(\sqrt L)$, exact identity scheduling can itself cost $L^{3/2+o(1)}$ operations, potentially exceeding the target time exponent $241/200$. Existing CUT126/REPLAY127 width-bucket planning costs $L^{1+o(1)}$ for $W=o(\log L)$, while losing only $N^{o(1)}$ in \emph{candidate enumeration}, provided their independently declared streaming/replay preconditions hold. It is not a guarantee for the number of actual SAT calls under early stopping, nor a resource improvement for arbitrary ordinary SAT.
