\section{A connected, unbounded minimally UNSAT proper-3CNF family}
For every integer $n\ge3$, put
\[
H_n^0=(x_1)\wedge\bigwedge_{i=1}^{n-1}(\neg x_i\vee x_{i+1})\wedge(\neg x_n),\qquad
H_n^1=(x_1)\wedge\bigwedge_{i=1}^{n-1}(\neg x_i\vee x_{i+1})\wedge(x_n).
\]
Use fresh, distinct auxiliary names for each clause. Replace a binary clause $(u\vee v)$ by
\[
(u\vee v\vee z)\wedge(u\vee v\vee\neg z)
\]
and a unit clause $(u)$ by the four proper ternary clauses
\[
(u\vee a\vee b),\ (u\vee a\vee\neg b),\
(u\vee\neg a\vee b),\ (u\vee\neg a\vee\neg b).
\]
Call the resulting ordinary \emph{proper} three-distinct-variable CNFs $U_n$ and $Y_n$. They have $2n+6$ unique 3-clauses, distinct auxiliary blocks, original-variable names preserved, a connected incidence graph and encoded length $N=\Theta(n\log(n+2))$ in the declared indexed format. They are \emph{not} asserted to lie in the separate monotone exact-$(2,2)$ target $\mathcal C_\star$.

\begin{theorem}[Minimality and clause-deletion oracle firewall]
For every $n\ge3$, $U_n$ is minimally unsatisfiable: $U_n$ is UNSAT and removing any one of its $2n+6$ ternary clauses makes it SAT. $Y_n$ is SAT. Thus every proper clause subset of \emph{either} $U_n$ or $Y_n$ is SAT.

Consider a deterministic controller receiving the common size $n$, the indices of its own clause-subset queries and the SAT/UNSAT bit returned for any strictly proper set of source clause records, but receiving no source-clause contents or other source-dependent side channel. Even an arbitrary adaptive sequence of such bit queries cannot correctly distinguish $U_n$ from $Y_n$.
\end{theorem}
\begin{proof}
Each gadget is pointwise equivalent under existential quantification of its private auxiliaries to its original clause. The first unit and the implications force $x_n=1$, contradicting the last unit of $H_n^0$. All-one satisfies $H_n^1$. For a deleted gadget clause, choose an original-variable assignment violating \emph{only} its source clause: for the first unit use all-zero; for the final negative unit use all-one; for implication at $i$, use $x_1,\ldots,x_i=1$ and $x_{i+1},\ldots,x_n=0$. All other source clauses are true and all their gadgets can be satisfied independently. A violated binary source clause leaves two complementary unit conditions on its auxiliary $z$; after deleting either ternary condition, satisfy the remaining one. A violated unary source clause leaves all four sign-pattern clauses on $a,b$; deleting any one permits choosing the assignment falsifying precisely that deleted clause. This proves minimality. All proper subsets are then satisfiable by monotonicity of CNF under clause deletion. The comparator $Y_n$ is SAT, so all of its subsets are SAT. Both sources return the same bit $1$ to every permitted query; induction on an adaptive transcript makes the controller's complete transcript identical, forcing the same output on opposite-label sources. This does not constrain algorithms that inspect the actual source syntax or construct new, non-subset SAT queries.
\end{proof}

This is an explicit all-ordinary-input \emph{candidate failure}, not a lower bound for arbitrary SAT deciders. In particular the inputs are Horn at the underlying implication level and easily recognizable.

\section{Pinned-interface exact repair with two genuine recursive solver levels}
For $1\le a<b\le n$ and boundary bits $u,v$, define the complete ordinary proper-3CNF child
\[
Q_{a,b}^{u,v}:=\operatorname{proper3}\left(
 (x_a=u)\wedge\bigwedge_{i=a}^{b-1}(\neg x_i\vee x_{i+1})
 \wedge(x_b=v)\right).
\]
All original $x_i$ keep their source names. Each fresh auxiliary is local to its child (and must be alpha-renamed if two children are materialized into one formula). Let
\[
R_{a,b}(u,v):=\SAT(Q_{a,b}^{u,v})\in\{0,1\}.
\]
\begin{theorem}[Exact two-level source-consistent relation]
For $a<b<c$,
\[
R_{a,c}(u,w)=\bigvee_{v\in\{0,1\}}
 \bigl(R_{a,b}(u,v)\wedge R_{b,c}(v,w)\bigr).
\]
The original root labels are
\[
\SAT(U_n)=R_{1,n}(1,0)=0,\qquad
\SAT(Y_n)=R_{1,n}(1,1)=1.
\]
Consequently, dividing the implication path into consecutive groups, dividing each group into consecutive leaves, and computing each leaf entry by a \emph{real, total, exact ordinary proper-3CNF SAT solver} gives a correct two-level decision algorithm for both parent labels. Each group is itself materialized as an independently parseable ordinary proper-3CNF pinned child before its relation is recursively computed; the leaf inputs are also complete ordinary proper-3CNFs. No SAT answer is supplied gratis.
\end{theorem}
\begin{proof}
A satisfying assignment for the whole segment gives the same value to the sole common boundary name $x_b$ on both halves, proving the forward direction. Conversely select one common value $v$ and satisfying witnesses on each segment. Their original variable sets meet exactly at $x_b$ and agree there. Renaming their private gadget auxiliaries independently permits the witnesses to glue; all original implication clauses are covered. Iterating relation composition over contiguous partitions proves both levels. A chain implication permits $(0,0),(0,1),(1,1)$, but not $(1,0)$; transitive composition has the same relation for every nonempty interval. The root endpoint unit clauses supply the pair $(1,0)$ for $U_n$ and $(1,1)$ for $Y_n$.
\end{proof}
\noindent\textbf{Eligibility warning.} These are ordinary SAT children, not necessarily members of $\mathcal C_\star$. They are eligible for the assumed \emph{all-ordinary-input} $A$; no target-specific solver is invoked without an adapter.

\section{Charged resource ledger and unconditional fallback firewall}
Write $N=\Theta(n\log n)$ for the complete proper3 parent. First-level groups contain $\Theta(n^{1/2})$ implication edges and their ordinary encoded length is $L_1=N^{1/2+o(1)}$; second-level leaf segments contain $\Theta(n^{1/4})$ edges and their complete pinned proper3 length is $L_2=N^{1/4+o(1)}$. There are $O(n^{1/2})$ groups. For all four endpoint pairs per group and four endpoint pairs per leaf, the total number of \emph{actual} second-level SAT calls is
\[
B\le 16\,O(n^{3/4})=N^{3/4+o(1)}.
\]
No assumption of any source-only easy decision bit is included. The controller validates the \emph{rigid chain gadget grammar} and its final-sign tag by exact source scans/regeneration, and it emits/reads complete ordinary child headers and bodies. Sum of group and leaf serialization is $N^{1+o(1)}$ bits, including repeated emission, failed pins, unchanged writes, index arithmetic, local control, child validation and source rereads. We assume a standard indexed random-access simulation with $N^{o(1)}$ bit overhead per primitive access; a formal bound uses straightforward sequential walks and logarithmic counters, not a free writable copy of the source.

Under a fixed all-input base decider $A$ of joint exponents $(t,s)$, the \emph{restricted promised-family} implementation has the conditional upper ledger
\[
t'_{\mathrm{chain}}\le\max\{1,3/4+t/4\},\qquad
s'_{\mathrm{chain}}\le\max\{1/2,s/4\}.
\]
Here $N^{1/2+o(1)}$ represents one writable \emph{group} buffer, $N^{1/4+o(1)}$ one writable leaf buffer and $N^{s/4+o(1)}$ the live guest machine work/index tapes. Group buffer and leaf solver workspace can coexist; the maximum exponent accounts for their sum. Each group return is one bit that is computed, never assumed. Root, group, leaf counters and ancestor metadata use logarithmic bits. The bound concerns charged logical bit operations and maximum indexed writable positions in a compiled model, not measured physical flips. Cumulative bit-time, active-one circuit energy, wires, switches, program size and clocked snapshots are separate metrics, not substitutes for machine work.

There is an exact total \emph{all-input} wrapper: check the rigid grammar, use this nested algorithm if recognized, otherwise run $A$ on the complete source. Its verified upper ledger is only
\[
t'_{\mathrm{all}}\le\max\{t,1,3/4+t/4\},\quad
s'_{\mathrm{all}}\le\max\{s,1/2,s/4\}.
\]
An intentionally DELAY-padded correct $A_K$ makes the obligatory fallback spend $\Omega(N^K)$ time on infinitely many malformed, nonchain and other ordinary inputs. Therefore \emph{this precise wrapper} does not establish a strict all-input improvement. Removing the fallback requires a new proof that \emph{every} ordinary SAT source has a semantically complete, compatible, cheaply discoverable, fractional-length interface representation. The chain grammar does not supply that missing theorem.

The restricted fixed-point envelope is $(1,1/2)$, inside the strict FLMV box. There is no contradiction because this procedure handles only a certified easy class; the all-input wrapper retains the original exponent. The source-blind subset-query firewall also does not exclude an $A$-dependent \emph{non-subset} semantic compressor.
