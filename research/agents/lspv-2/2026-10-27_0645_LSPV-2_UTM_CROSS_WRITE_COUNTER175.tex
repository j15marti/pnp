\section{Exact signed gadget and bit-level source split}
Let $W_1$ be the verified 20-clause proper ternary formula on 15 variables. Define $H(a,b)$ by negating both literals at zero-based clause/slot positions
\[
   A=\{(6,0),(11,0)\}\ \text{when }a=0,\qquad
   B=\{(17,2),(9,2)\}\ \text{when }b=0.
\]
The two pairs modify opposite signs of two different names, so each of the four variants remains proper, clause-distinct, and exactly two-positive/two-negative per name. Direct exhaustive truth-table evaluation gives
\[
 \#\mathrm{Mod}(H(0,0))=772,\quad
 \#\mathrm{Mod}(H(0,1))=272,\quad
 \#\mathrm{Mod}(H(1,0))=272,\quad
 \#\mathrm{Mod}(H(1,1))=0.                 \tag{1}
\]
Write an assignment mask in little-endian variable order, with bit $j-1$ representing variable $x_j$. Direct evaluation also gives
\[
 616\models H(0,0),H(0,1),\qquad
 4742\models H(1,0),                                    \tag{2}
\]
while neither of these masks satisfies $H(1,1)$. For $a,b\in\{0,1\}^m$, rename the $m$ copies disjointly and concatenate \emph{all} two Alice clauses per copy, then all 16 fixed clauses per copy, then all two Bob clauses per copy. The resulting
\[
 F_m(a,b)\in\mathrm{3CNF},\qquad V=15m,\quad C=20m,
 \qquad \SAT(F_m(a,b))\iff \bigwedge_{i=1}^m\neg(a_i\land b_i). \tag{3}
\]
A width-$w=(20m).\mathrm{bit\_length}$ literal encoding (one sign bit and $w$ identifier bits), an explicit 32-bit magic and three $w$-bit header fields yield
\[
 N_m=32+3w+60m(w+1),\qquad G_m=48m(w+1),                \tag{4}
\]
where $G_m$ is the exact fixed-middle-clause length, excluding header. Thus $N_m=\Theta(m\log m)$ and $G_m/N_m\to4/5$.

\begin{lemma}[An Alice-only candidate witness, not a sound acceptor]
For every $\SAT$ input in the displayed promise, the 15-bit-per-module witness
\[
  w(a)=\mathop{\|}_{i=1}^m
  \begin{cases}616,&a_i=0,\\4742,&a_i=1\end{cases}
\]
satisfies the complete signed formula, without inspecting Bob's bits. The same printer can output an invalid witness on every $\UNSAT$ promise input. An unchecked write-only output string therefore does not violate any sound-acceptance crossing lower bound.
\end{lemma}
\begin{proof}Equation (2) handles $a_i=0$ for both $b_i$; for $a_i=1$, satisfiability requires $b_i=0$, where mask $4742$ works. An unsatisfiable $H(1,1)$ component admits no assignment, so concatenation fails there.\end{proof}

\section{One-counter model fork and a sharp write threshold}
Fix a \emph{single two-way sequential read-only input head} and one sequential work head. Finite control sees the input symbol and the work-tape symbol, but \emph{not} either head's numerical coordinate. Let $S$ count all visited work cells even if blank; $D$ count actual work-symbol changes, not movements or redundant writes; $T$ count transitions; $R$ count input-head direction reversals; $L$ count emitted output bits.

\begin{theorem}[No readable origin, no positional counter; \textbf{PROVED/EXACT}]
Suppose every work tape is bi-infinite, initially entirely blank, has no readable left-endmarker, and provides no head-position or head-collision primitive. If a single deterministic finite-control machine has the uniform worst-case ceiling $D(N)=0$ on every input, then its accepted input language is regular, irrespective of $S,T$, and the number of fixed work tapes. In particular it cannot accept the complete separated-disjointness language
\[
\mathcal{D}=\{\,\hat{}a\#0^g\#b\$:|a|=|b|\ge1,\ g\ge1,
\ a_i b_i=0\text{ for all }i\,\}.                       \tag{5}
\]
\end{theorem}
\begin{proof}Every work-head read returns blank. Work-head coordinates therefore never influence the transition function, and projecting the control state and input-head movement produces an equivalent deterministic two-way finite automaton. Its language is regular by the standard two-way-to-one-way finite-automaton conversion. For each $m$, the $2^m$ prefixes $\hat{}a\#$ are pairwise distinguishable by suffixes consisting of the same $0^g$ middle block, the opposite-side delimiter, and $\neg a$ or $\neg a'$; at least one cross-pair has a positive overlap when $a\ne a'$. Myhill--Nerode therefore excludes regularity.\end{proof}

\begin{theorem}[One marker is enough on the \emph{tagged} language; \textbf{PROVED/EXACT}]
On the same initially unmarked blank work tape, change the initial work-cell symbol once to a marker $\mathtt{@}$; do not subsequently alter a single cell. A deterministic finite-state program decides \(\mathcal D\) with
\[
   D=1,\quad S\le m+1,\quad T=O(m(N+m)),\quad R=O(m),\quad L=1,     \tag{6}
\]
where $N=m+g+m+4$. On a \emph{different} work-tape convention with an immutable initially distinguishable origin marker supplied without charging a work-cell write, the same program has $D=0$ and the same remaining bounds.
\end{theorem}
\begin{proof}First make a forward validation pass: increment the unary work-head displacement once for every Alice bit, scan the zero gap, then decrement the displacement for every Bob bit, rejecting unequal lengths, malformed symbols or separators. Return the input head to the left sentinel; the work-head is now at the marked origin. Maintain the loop invariant: at the left sentinel, the work-head displacement is $i$. Walk $i$ input positions into Alice while moving the work head left once per position until its \emph{symbol read} encounters $\mathtt{@}$; read and remember $a_i$ in one control-state bit. Reverse the walk, restoring the displacement $i$. Scan to the second separator without moving the work head, walk $i$ Bob positions while decrementing to the marker, and read $b_i$. If both bits are 1, reject; otherwise reverse the walk to restore displacement, return the input head to the left sentinel, increment displacement once, and repeat. When Alice's $i$th bit is its separator, accept. No arithmetic position oracle or source-dependent table is used. Each of $m$ rounds travels $O(N+m)$ one-cell moves, work-head positions lie in $[0,m]$, and only the planted origin symbol differs from blank.\end{proof}

\begin{counterexample}[Model-definition discontinuity]
One extra work-head coordinate is \emph{not readable} merely because it exists. Theorem 2's $D=0$ shortcut needs a supplied origin marker. If the original theorem counts $D$ from an \emph{initially blank} tape, installing that marker costs $D=1$. Importing a free marker invalidates the intermediate assertion ``at most $D$ cells are nonblank'' in the UTM-CROSS-WRITE1 counting proof unless the initial nonblank cells are charged separately.
\end{counterexample}
For $I_0$ initial nonblank work cells, a safe configuration-count replacement uses $D+I_0$ in the occupancy term:
\[
  A_{I_0}(S,D)\le 2q(2S+3)^k
  \sum_{j=0}^{\min(D+I_0,\,k(2S+3))}
  {k(2S+3)\choose j}(g-1)^j.                            \tag{7}
\]
The original governance statement assumes initially blank work cells ($I_0=0$), where its proof remains applicable. With $D=1,S=\Theta(m),k=1$, the new machine satisfies its strict exponent inequalities $d+ks+\min(s,d)\ge1$, $r+\min(s,d)\ge1$, and $t+\min(s,d)\ge2$ on the easy tagged language (indeed $d=0,s=1,r=1,t=2$). No contradiction arises.

\section{The original physical CNF is not the tagged comparator input}
The proven counter program reads explicit $\hat{},\#,$ and $\$$ zone delimiters. Equation (4) serializes \emph{binary clause data} and a header, not that tagged word. It is not established that the same fixed finite-control program can extract its source-control bits from variable-width literal fields while retaining only the planted marker and its reported $(S,D,T,R)$ bounds. The code \emph{independently} reconstructs every actual CNF clause and its physical bit length, and then separately executes the explicit tagged-word machine. The tagged word can have a gap of the \emph{same physical length} $G_m$ but that does not by itself prove a cost-preserving reduction. The proper signed exact-$(2,2)$ formulas are not clause-monotone; mixed-sign clauses remain.

The supplied source-only candidate printer, standard indexed RAM oracle, two-read-only-input-head scanner, and a sound deterministic source decoder are four different interfaces. The $D=1$ comparator cannot be promoted to a full ordinary-SAT decision circuit or to a shortened ARC child. A fixed source witness verifier $V(F,w)$ differs from $\exists_wV(F,w)$ implemented as one uniform SAT decision circuit on every ordinary $N$-bit input. Report 174's arithmetic inverse gate/source Rank/Select closes a substantial \emph{verifier} interface but not this gap.

Formula (8) is an \emph{upper simulation} not an all-algorithm lower bound.
