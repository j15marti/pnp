\section*{ITERATE: proved theorem}
Let \(\operatorname{Ess}(C)\) be the set of input coordinates \(i\) for which some assignment \(a\) satisfies \(C(a)\ne C(a\oplus e_i)\).
Define \(\mathrm{ESUP}_3=\{C:|\operatorname{Ess}(C)|\le3\}\), where C is an explicit well-formed acyclic binary Boolean gate DAG with original input coordinates, all gates paid and conservative; malformed strings are rejected.

\begin{theorem}[PROVED: extensional support complexity]
The language \(\mathrm{ESUP}_3\) is coNP-complete under polynomial many-one reductions. It remains so if all gates are separately paid, conservative, two-input DEF nodes and the original CNF source is the fixed satisfiable clause \((w)\), independent of the circuit.
\end{theorem}
\begin{proof}
The complement has an NP certificate consisting of four distinct input positions \(i_j\) and four assignment pairs \((a_j,a_j\oplus e_{i_j})\) showing different circuit outputs. Eight circuit evaluations and well-formedness checks are polynomial in the encoded evidence length.

For hardness start with arbitrary CNF UNSAT instance \(G(x_1,\ldots,x_n)\). Compile its evaluation by a polynomial number of Boolean gates, introduce four fresh independent input variables \(y_1,\ldots,y_4\), and build
\[
 H_G(x,y)=G(x)\land y_1\land y_2\land y_3\land y_4.
\]
Every gate is a distinct paid conservative two-input definition; no answer axiom is used. The declared-variable header includes all x and y inputs even when they do not occur in source clauses. If a proposed original-variable grammar instead requires each original to occur in some source clause, append the tautological source clauses (xi OR NOT xi) and (yj OR NOT yj); these preserve SAT and increase N only polynomially, without changing the reduction. Take source \(F=(w)\), which is SAT for \emph{both} labels of G. If G is UNSAT, H is identically zero and its essential support is empty. If G is SAT, fix one satisfying x assignment and set all four y's to one. Changing any one y to zero changes H from one to zero, so the four fresh variables are essential. Therefore \(G\in\mathrm{UNSAT}\) iff \(H_G\in\mathrm{ESUP}_3\).
\end{proof}

\begin{lemma}[PROVED: static support versus functional support]
The transitive original-variable dependency cone of each acyclic gate can be computed by polynomial-time bitset unions. It may properly contain the essential support.
\end{lemma}
\begin{proof}
Union the original-input bitsets of each parent gate in topological order, using \(O(tn)\) bit positions for \(t\) gates and \(n\) used originals (or \(O(E^2)\) in total serialized description E). But
\[
 x_1\oplus x_2\oplus\cdots\oplus x_k\oplus x_k\oplus\cdots\oplus x_2=x_1
\]
has an explicit left-associated implementation with \(2(k-1)\) paid XOR gates and transitive syntactic support k, yet extensional essential support one.
\end{proof}

\noindent\textbf{Conditional checker firewall:} A total polynomial-time algorithm which accepts \emph{exactly} the output circuits with extensional essential support at most three would imply P=NP. This is a coNP-completeness consequence, not a proof P differs from NP. A static-cone checker is polynomial but conservatively rejects some extensionally local circuits. Separately authenticated equivalence evidence is an alternative, but requires actual native rules, charged nodes and a typed proof compiler.

\section*{Physical costs and main transfer}
Let N be original-source bits, t separately paid definitions and E the entire serialized circuit/proof evidence. The original source contains the fixed satisfiable clause (w), but its variable-bound header grows with n; N is O(log(n+6)) bits in a binary header, or O(log(n+6)) decimal digits in DIMACS, not a literal constant. The separate paid-gate evidence t and E grows polynomially with the input CNF G. Brute semantic essential-support checking takes \(O(n2^nE)\) gate-evaluation time and \(O(E+n)\) scratch bits with a materialized gate array; static cone checking is polynomial in E but need not be exact. The compact paid-gate DAG is a valid alternative encoding to its exponential expanded truth table. Source reading, construction, indexes, transformations, validation, output and peak memory must all be accounted for. A semantic rewrite to constant zero is possible if G is UNSAT, but its discovery and certification cannot be assumed free.
