\section{Single receiving obligation and source preflight}
Let \(\mathcal E\) denote the upward-closed set of pairs \((t,s)\) for
which \emph{one fixed, uniform, all-input, total, exact ordinary-SAT decider},
with the indexed read-only input and charged random-access work/index tapes
of the Fortnow--Lipton--van Melkebeek--Viglas (FLMV) machine model,
simultaneously achieves \(N^{t+o(1)}\) time and \(N^{s+o(1)}\)
counted space. The endpoint is the genuine forbidden box
\[
 t<\frac{241}{200},\qquad
 s<\beta(241/200)=\frac{11642479}{23232400},\qquad
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
The previously used universal product landing
\(t+s<2\cos(\pi/7)\) is \textbf{FALSIFIED/RETIRED};
it must not be used for SAT. Under \(P=NP\), a finite \((K,K)\in\mathcal E\)
exists for all sufficiently large fixed integers \(K\). A proved
finite charged route of jointly achievable pairs from every \(K\) in
an unbounded set to the displayed forbidden box would yield a
contradiction. No such all-input route has been proved.
This report investigates whether recovering \emph{batched right-context
summaries} from previous ARC work supplies one route edge. It does not.

Three hypotheses were fixed before the comparison.
\textbf{H1}: predeclared right contexts admit an exact compact output
according to the number of distinct attainable batch responses.
\textbf{H2}: such outputs remain sufficient for arbitrary new
intersection joins at the next recursive level.
\textbf{H3}: that context-profile contraction supplies a fully charged
all-input favorable successor in \(\mathcal E\).
H1 is exact, H2 is false unless a precise singleton-completeness
condition holds, and H3 is \OPEN.

\section{Fixed-public-menu interface model}
Fix a finite set \(U\) of complete assignments to a shared \(h\)-bit
interface, with \(M=|U|\le 2^h\).
A left component has a feasible assignment relation \(A\subseteq U\).
A public, \emph{fixed before \(A\) is processed}, finite menu is
\(\mathcal B=(B_1,\ldots,B_q)\), where \(B_j\subseteq U\) is the
feasibility set of one right context. Empty and repeated contexts
are permitted. Define
\[
 \phi_{\mathcal B}(A)_j
 ={\bf1}\{A\cap B_j\neq\varnothing\},
 \qquad
 v_u=\bigl({\bf1}\{u\in B_j\}\bigr)_{j=1}^q.
\]
The public menu is not a free computational oracle. We first study
only its \emph{information-theoretic} detached behavior. Building the
menu, recognizing a component's feasible relation, computing
\(\phi\), an indexing dictionary, selecting the next contexts,
answering SAT on source-generated children, and storing their
ordinary headers and bits all require separate machine charges.

\begin{theorem}[Finite-menu OR-closure; PROVED/EXACT, detached model]
For every finite public menu and every \(A\subseteq U\),
\[
 \boxed{\quad
 \phi_{\mathcal B}(A)=\bigvee_{u\in A}v_u,\qquad
 \mathcal R_{\mathcal B}
 :=\{\phi_{\mathcal B}(A):A\subseteq U\}
 =\left\{\bigvee_{u\in A}v_u:A\subseteq U\right\}.
 \quad}
\]
Empty OR is the zero vector. Every deterministic fixed-length detached
summary that, together with this public menu, answers \emph{all}
the \(q\) prescribed intersection-nonemptiness questions
on \emph{every} \(A\subseteq U\), must use at least
\[
 \boxed{\,\left\lceil\log_2|\mathcal R_{\mathcal B}|\right\rceil\,}
\]
bits in the worst case. This bound is information-theoretically tight
when an arbitrary public decoder/codebook is allowed; its encoding,
construction and lookup costs are \emph{not} thereby bounded.
An explicit source-independent alternative stores the \(q\)-bit
response vector itself.
\end{theorem}
\begin{proof}
For coordinate \(j\), the nonempty intersection predicate equals
the OR of the membership indicators of elements of \(A\), proving
the identity and the equality of the two image sets.
If distinct response vectors received the same detached summary,
some query \(j\) would have different required answers for identical
stored code and public menu, which is impossible for a deterministic
decoder. Thus there are at least \(|\mathcal R_{\mathcal B}|\)
different codes. A fixed-length binary code requires the displayed
number of bits. Enumeration of the distinct response vectors gives
an existential optimal codebook, without any efficiency claim.
\end{proof}

\paragraph{Calibrating three menus.}
If \(q=M\) and \(B_j=\{u_j\}\), then every subset produces a
different vector, \(|\mathcal R|=2^M\), requiring \(M\) bits.
If every \(B_j=U\) with \(U\ne\varnothing\), then
\(|\mathcal R|=2\), requiring one bit regardless of repetitions.
For ordered \(U=\{u_0,\ldots,u_{M-1}\}\) and
\(B_j=\{u_0,\ldots,u_j\}\), \(0\le j<M\), the profile records
only the first included position and
\(|\mathcal R|=M+1\), requiring
\(\lceil\log_2(M+1)\rceil\) bits.
The last two savings are for the fixed public menu, not arbitrary
right contexts or all future recursive uses.

\section{The new two-level hereditary-join test}
A proposed intermediate profile needs a compositional guarantee if a
second recursive level may intersect \emph{arbitrary} feasible relations
without reopening the original left source.

\begin{theorem}[Exact meet-congruence criterion; PROVED/EXACT,
detached all-relations model]\label{thm:meet}
Put \(V=\bigcup_{j=1}^q B_j\). There exists a binary map
\[
 H:\mathcal R_{\mathcal B}\times\mathcal R_{\mathcal B}
 \longrightarrow\mathcal R_{\mathcal B}
\]
such that
\[
 \boxed{\qquad
 \phi_{\mathcal B}(A\cap C)=
 H\bigl(\phi_{\mathcal B}(A),\phi_{\mathcal B}(C)\bigr)
 \quad\text{for every } A,C\subseteq U
 \qquad}
\]
\emph{if and only if}
\[
 \boxed{\qquad
 \text{for each }u\in V,\quad
 \{u\}\text{ is one of the public }B_j .
 \qquad}
\]
The quantifiers range over \emph{all} subsets \(A,C\), not merely
some promised set of source-generated relations.
\end{theorem}
\begin{proof}
For sufficiency, one public coordinate for each singleton
\(\{u\}\), \(u\in V\), exactly gives the membership indicators of
\(A\cap V\) and \(C\cap V\).
For each \(j\) take the OR over \(u\in B_j\) of the AND of those
two singleton membership bits. This is exactly the \(j\)th bit of
\(\phi(A\cap C)\), defining \(H\).

For necessity, suppose \(u\in V\), but no context in the menu
equals \(\{u\}\). Compare \(A=U\) and
\(A'=U\setminus\{u\}\). For every public \(B_j\), the two
nonemptiness answers agree: if \(u\notin B_j\), nothing changes;
if \(u\in B_j\), the absence of singleton \(\{u\}\) guarantees
that \(B_j\setminus\{u\}\ne\varnothing\).
Thus \(\phi(A)=\phi(A')\). But for \(C=\{u\}\),
\(\phi(A\cap C)=\phi(\{u\})\ne 0\), as \(u\in V\), whereas
\(\phi(A'\cap C)=\phi(\varnothing)=0\).
No deterministic \(H\) can map identical input pairs to these
different outputs. Contradiction.
\end{proof}

\begin{corollary}[Exact price of arbitrary intersection closure]
A menu satisfying Theorem~\ref{thm:meet} has
\(\left|\mathcal R_{\mathcal B}\right|=2^{|V|}\), and its
lossless detached fixed-length profile costs \emph{at least}
\(|V|\) bits. Exactly \(|V|\) singleton-membership bits suffice
as a summary, with public context evaluation charged.
If existing public contexts contain \(r\) \emph{distinct}
singletons of \(V\), making the menu meet-complete by adding
contexts requires adding every one of the other
\(|V|-r\) singleton contexts. Coarse repeated or nested
batch queries do not eliminate that requirement.
\end{corollary}
\begin{proof}
Singleton menu coordinates recover exactly \(A\cap V\);
all \(2^{|V|}\) choices occur over \(A\subseteq U\).
Theorem~\ref{thm:meet} also characterizes which singleton
contexts are compulsory after augmentation.
\end{proof}

\paragraph{Smallest two-level SAT/UNSAT control.}
Let \(U=\{0,1\}\), \(B_1=U\),
\(A=\{0\}\), \(A'=U\), and \(C=\{1\}\).
Both \(A,A'\) answer the only first-level question YES:
\[
 \phi(A)=\phi(A')=1.
\]
Yet the next consistent source-name join has opposite outcomes:
\[
 \phi(A\cap C)=0,\qquad
 \phi(A'\cap C)=1.
\]
Each individual component is satisfiable, but the first left and
right pair is jointly UNSAT. A source-visible ordinary proper-3CNF
realization uses a shared bit \(x\): left \(\neg x\), right \(x\),
versus an unrestrictive left block. A pinned literal \(L\) is
properized with fresh \(a,b\) by the four clauses
\[
 (L\vee a\vee b)\wedge(L\vee a\vee\neg b)
 \wedge(L\vee\neg a\vee b)\wedge(L\vee\neg a\vee\neg b),
\]
whose existential projection is exactly \(L\).
A source-reading SAT decider can inspect these signs directly;
this is \emph{not} a SAT runtime lower bound.

\paragraph{Prior art and exact novelty boundary.}
CUTSET-TABLE-TRILEMMA58 already proves the worst-case

INTERFACE-ADAPTIVITY-BARRIER73 already proves exact

The exact receiving obligation would require a new all-input,
uniform, same-realization construction that, given an arbitrary

Theorem~\ref{thm:meet} proves neither a general failure
of that existential implication nor a universal hardware
space bound. Its antecedent demands a detached reusable
summary of an arbitrary interface relation for all later
intersections. It excludes a particular \emph{uncharged}
use of highly compressed coarse status menus as though
they were hereditary exact interfaces. A source-aware solver
may scan source bits, perform Gaussian elimination or SCC,
cache a function, recognize an easy family, produce new
children, or decide directly. Each such escape must be
allowed, with costs charged; some are polynomial.
Nor does a one-bit decider have to produce every pinned
answer, witness, table, or DNNF.

\section{Adaptive state, work and space}
A plausible adaptive controller begins with the ordinary
indexed read-only source, unknown SAT label, a declared
interface \(U\), a public-menu construction plan and one
joint time/space budget. It may choose:
recognize/verify a direct SAT witness or UNSAT explanation;
run Horn propagation, 2-SAT SCC or affine elimination;
derive source-coherent blocks; build a batched profile;
add missing singleton contexts; recompute selected values;
cache or reread indexed source; construct ordinary children;
perform explicit named-variable joins; switch methods after
failed recognition; or call an exact general fallback.
All decisions are source- and state-dependent, not label-oracle
dependent. Original-source names and compatibility must be
preserved at each actual child interface.

The proposed BIT-RESOURCE1 vector is
\[
 (W,R_{\rm src},R_{\rm wk},W_{\rm wk},\Delta_{\rm state},
 S_{\rm peak},BT,|P|,|{\rm repr}|),
 \qquad BT=\sum_\tau \text{live writable bits at step }\tau.
\]
Charged work includes input access and indexing, control,
unchanged writes, switching, failed attempts, public-menu
discovery, dictionary construction, source rereads,
serialization of ordinary child headers/bits and auxiliaries,
pin verification, gluing, reconstruction, caches, live
ancestors, and all workspace buffers. \(\Delta_{\rm state}\)
measures actual state changes separately. An abstract
intersection of sets or a lookup returning the correct SAT bit
is not a free primitive. The finite audit below counts
mathematical comparisons only and does \emph{not} measure
this machine vector; therefore no FLMV exponent is inferred.
