\section{Model and charged exact factor theorem}
Input is signed width-at-most-three CNF, $n$ original source variables, $m$ clauses, $k$ genuine ternaries. Four-word clause records of $w=\lceil\log_2(16(n+m+1))\rceil$ bits give encoded $N=(4m+2)w$ bits. Word RAM accesses are charged by word; source and certificate field reads are counted. $d$ denotes eliminated original variables; $r=n-d$ only for an actual syntactic residual.
Take a named genuine-source interface $Y$ of size $b$. Remove $Y$ from the incidence graph and form connected components $X_1,\ldots,X_J$ of other variables. Verify the complete original signed-clause partition
\[
F=B_0(Y)\wedge\bigwedge_{i=1}^J F_i(Y,X_i),
\qquad X_i\cap X_j=\varnothing.
\]
Let block $i$ have $k_i$ genuine ternary clauses, $m_i$ total clauses and $n_i=|X_i|$.
\begin{theorem}[Certified additive local backdoors]
There is a uniform exact SAT algorithm, including full source-witness recovery and source-labelled UNSAT certificates, with
\[
O\left(n+m+2^b m_0+
2^b\sum_{i=1}^{J} 2^{k_i}(n_i+b+m_i+1)\right)
\]
word-work upper bound once $Y$ is supplied. The source-complete Boolean profiles
$M_i(\alpha)=[\exists\beta_i:F_i(\alpha,\beta_i)]$
satisfy
\[
SAT(F)\Longleftrightarrow
\exists\alpha\in\{0,1\}^b:
B_0(\alpha)\wedge\bigwedge_i M_i(\alpha).
\]
The theorem is an explicitly charged specialization of known exact small-interface joins and component-backdoor methods, not an all-input separator theorem or lower bound.
\end{theorem}
\begin{proof}
For each $\alpha$ and block, choose at most one remaining original variable from every still-genuine ternary, obtaining a strong 2-CNF backdoor of size at most $k_i$. Enumerate its assignments, build residual 2-CNF, run implication-graph SCC, and check a successful local witness or an UNSAT pair of source-labelled implication paths (or falsified clause) for every rejecting branch. Every source clause is assigned exactly once to a block or $B_0$, and all local models share the identical $\alpha$, so their union is a valid parent model exactly when every component accepts. Replay all parent clauses. The displayed cost charges all $2^b$ boundary assignments, $2^{k_i}$ local branches, failed trials, proof writes/checks, and complete source replay.
\end{proof}
For a supplied interface, $C_{\rm discovery}=O(n+m)$, $C_{\rm normalization}$ is bounded by the main sum, $C_{\rm verification}=O(n+m+\mathrm{proof\ length})$, and $C_{\rm continuation}=O(2^b J+\mathrm{source\ replay})$ after profiles. A streaming implementation uses $O(n+m+J2^b)$ live words plus the current SCC stack; retaining all branch proofs and full local models can use exponential output memory. Discovering a good unknown $Y$ is not free: enumerating size-$b$ candidates may cost $\binom nb$ trials. A uniform highest-occurrence heuristic gives a valid, not necessarily optimal, $Y$ in $O(n+m)$ work; if one block holds all $k$ ternaries, the bound is still exponential. Constant TRUE/FALSE output after decide-first preprocessing is not evidence of inexpensive discovery.
\section{Three-step resolution normalizer}
\begin{theorem}[Source-labelled four-clause projection]
For original local bits $a,b,c$ and actual shared source $y$,
\[
G_y=(a\vee b\vee c)\wedge(\neg a\vee y)
\wedge(\neg b\vee y)\wedge(\neg c\vee y)
\]
satisfies $\exists a,b,c\,G_y\equiv y$.
\end{theorem}
\begin{proof}
Three charged source-labelled resolution steps produce
$(b\vee c\vee y)$, then $(c\vee y)$, then $(y)$.
Conversely $y=1$ admits the functional lifting $(a,b,c)=(1,0,0)$.
Checking all four actual signed clause IDs, intermediate resolvents,
and the extension independently certifies the projection.
\end{proof}
A recognized factor costs three resolution events and four original-clause comparisons. A rejected grammar signature triggers the complete general algorithm. No auxiliary source variables or unchecked hash equivalence are introduced.
\section{Connected matched SAT/UNSAT pair and graph-width gap}
Let $p,q\ge1$, $k=p+q$, $Y=\{z,w\}$, with pairwise disjoint original triples $(a_i,b_i,c_i)$. Set $L_p=\bigwedge_{i=1}^{p}G_z(a_i,b_i,c_i)$ and $R_q=\bigwedge_{i=p+1}^{p+q}G_w(a_i,b_i,c_i)$, and define
\[
F_{p,q}^{+}=L_p\wedge R_q\wedge(\neg z\vee w)\wedge(z\vee\neg w),
\quad
F_{p,q}^{-}=L_p\wedge R_q\wedge(z\vee w)\wedge(\neg z\vee\neg w).
\]
Both inputs have $n=3k+2$ original variables, $m=4k+2$ clauses, equal encoded $N$, and $k$ disjoint ternaries. Both binary backbones are SAT; there are no unit clauses, pure variables, duplicate clauses or disconnected source components.
\begin{theorem}[Exact both-label counterexample]
The minimum syntactic strong direct-restriction 2-CNF backdoor has size $k$ but
\[
\#SAT(F_{p,q}^{+})=7^k,\qquad
\#SAT(F_{p,q}^{-})=0.
\]
Both original CNF primal graphs have treewidth exactly three. The Role-1 PAIRHELLY67 literal-choice conflict graph for $F^{-}$ is $K_{3p,3q}$ with exactly $9pq$ edges and treewidth $3\min(p,q)$; for $F^{+}$ it has no edges. Still, a uniform source-checking normalizer derives $z$ and $w$ with $3k$ resolution events, then decides the two-bit core using one SCC call, in $O(n+m)$ word operations.
\end{theorem}
\begin{proof}
Each ternary has disjoint local support and requires a selected variable in a strong syntactic 2-CNF backdoor. Every block entails its attached positive core literal by the preceding theorem, so $z=w=1$. The equality core is SAT, with seven nonzero assignments per triple; the disequality core is UNSAT. Any left ternary literal choice forces $z$, and any right choice forces $w$, making every cross choice incompatible precisely under the disequality core. Same-side choices coexist. Each triple and core node induce a $K_4$ in the primal graph, and these $K_4$ bags attach to the core edge in a clique tree. This proves primal treewidth exactly three. Source reads, all source IDs, witness lifting, and proof verification are included in the normalization cost.
\end{proof}
A still stronger UNSAT shortcut is an eight-resolution-event proof: three steps to derive $z$ from one left block, three to derive $w$ from one right block, then two against $(\neg z\vee\neg w)$ to obtain the empty clause. Outputting all $9pq$ conflict edges is never mandatory for SAT decision.
