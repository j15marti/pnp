## ITERATE: exact same-parent XOR-port cylinder theorem (PROVED/RESTRICTED)

Fix an **immutable** trusted physical parent binary source `x` of length `m`, one deterministic guest program `M`, and the *same full initial non-INPUT configuration* (including all WORK, INDEX and head/control state). For each authenticated finite descriptor set `D ⊆ {0,...,m-1}` define a guest-visible virtual child `y_D[i] = x[i] XOR 1_{i∈D}`. All descriptors preserve length. Let `tau_a` be the **genuine completed** execution trace of M on `y_A` and let `R_a` be its set of in-range guest INPUT positions observed, retaining their actual observed values and instruction history.

Then, **for this fixed parent, code, input length and entry configuration**, the candidate child `y_B` lies in the completed-trace input cylinder *if and only if*

$$
R_a\cap(A\mathbin{\triangle}B)=\varnothing.
$$

If the condition holds, the execution, output label and complete WORK/INDEX effect history of M are identical. If it fails, at least one guest-visible INPUT observation differs, so the **identical execution trace cannot be replayed**, even when the two final labels happen to agree. This is a trace-equivalence criterion, **not** a necessity for every other legitimate semantic deduction or computation-sharing strategy.

**Proof:** For the same parent `x`, `y_A[i]=y_B[i]` iff `i∉A△B`. Therefore exactly the queried guest positions agree iff the displayed intersection is empty. Starting from identical non-input configurations, deterministic transition induction through every actual input/index/work operation makes each successive configuration and each INPUT observation identical. The guest halts with the same label, writes and visited index/high-water. Conversely if the intersection is nonempty, the recorded observation at that position is changed; no identical trace replay is possible. QED.

**Critical scope guards:** If the physical parent differs, `D` alone is not an authentication key; the correct observation test is `x'[i] XOR 1_{i∈B} = x[i] XOR 1_{i∈A}` for every actual anchor query. A **trusted immutable parent capability** may certify same identity; otherwise source equivalence/provenance must be checked at its full cost. Guest INPUT *virtual* coordinates and values, not merely original parent read addresses, determine equivalence. Guest entry register/WORK states must match; if they do not, use only a separately validated frame/live-in/effect replay theorem and charge it. Forged trace R cannot be trusted. Branch assumptions are part of the child descriptor/context. The result adds NO case-split, weakening or assumption-discharge rule to historical R_mix341.

**Resource qualification:** With a sorted trusted R and sparse authenticated descriptors, an abstract lookup can compute intersection in O(|R|+|A|+|B|) comparisons with sorted streams or maintain a bitset of |m| read coordinates and inspect |A△B| flips, but the storage/INDEX/tape costs must be physically charged. A retained R as explicit positions costs O(|R|log(m+1)) bits, and the trace's full caller effects and historical WORK high-water can be much larger. The parent is read-only only in the *host model*; actual FLMV source access, INDEX erasure, virtual-port evaluation, raw descriptor generation, cache retention, misses and failed policies remain unpaid until a native same-machine proof. No result here establishes q≤N^(3/5+o(1)), child m≤N^(1/2+o(1)), all-phase local time ≤N^(11/10+o(1)), or space ≤N^(1/2+o(1)) for arbitrary sources.

**Finite exact packet, independent of any historical R_mix341 grammar:** 8-bit magic `10100101`, six-bit nvars=6, twelve-bit clause count=20; 20 proper 3-literal clauses, each literal recorded as six-bit ID plus one polarity bit. Total packet 26+20·21=**446 bits**. The first 16 original clauses encode odd-charge K4 Tseitin (6 edge variables, UNSAT). Four additional original proper width-three clauses use IDs (1,2,3), each satisfied by all-zero assignment after changing the vertex-0 charge to even. The trusted symbolic guest first reads all header and ID fields to reject malformed packets, then reads the original 16-core sign fields; for authenticated odd K4 core it safely returns UNSAT without reading any of 12 tail sign bits; otherwise it exhaustively checks all assignments.
