\section{Source-matched cyclic block joining}
Let $F=\bigwedge_{j=1}^{B}(B_j\wedge A_j)$ with explicitly identified block vertex sets $V_j$, where $B_j$ is 2-CNF and $A_j$ is at most one parity equation. Every variable belongs either to one block or \emph{exactly two} blocks. When it belongs to two, it creates one labelled edge of a possibly multigraph $H$ on the blocks. All input fields, source names, local constraints, edge incidence and decomposition are part of the supplied \emph{validated} instance; recognition is charged. Put $L$ equal to the total word size of the block description including occurrences and edge records. Let $c$ be the number of connected components of $H$ and
\[
q=|E(H)|-|V(H)|+c.
\]
This is the ordinary cyclomatic number, defined structurally, not from observed search time.

\begin{theorem}[Chord-conditioned block join, PROVED/EXACT restricted]
There is one uniform algorithm, on the declared validated block language, that decides satisfiability exactly in $O(2^qL^2)$ word operations and $O(L+q)$ working words, up to standard word-indexing factors. Under ordinary bit-machine simulation the respective bounds gain explicit polynomial logarithmic overhead in $L$; they are \emph{not} an FLMV all-input achievable exponent pair.
\end{theorem}
\begin{proof}
Compute and charge a spanning forest $T$ of the \emph{edge-labelled multigraph}. Its $q$ omitted edges correspond to $q$ distinct source variables. For each assignment $\alpha\in\{0,1\}^q$, pin its value identically in \emph{both} incident blocks. This converts every omitted-edge compatibility condition into two consistent local unit constraints. The only remaining interblock sharing is along the forest, with exactly one shared variable on each retained edge. Apply the singleton-interface bottom-up algorithm of TREE-AFFINE-JOIN122 to the pinned instance. The child-to-parent message is the set of extendible values in $\{\emptyset,\{0\},\{1\},\{0,1\}\}$. The earlier 2-CNF-plus-one-parity routine handles each pinned block in quadratic total source-word work; at most two tests per nonroot block and one at each root are required. SAT is witnessed by one compatible $\alpha$ and a global reconstruction; UNSAT means every $\alpha$ gives no extendible root. Conversely, any global satisfying assignment induces its unique omitted-edge word $\alpha$ and therefore survives one branch. Because the true source variables on both ends have been pinned to one shared bit, no independent-witness ambiguity remains. Construct the tree and its index once, and serially recycle all per-branch tables, witnesses and buffers. Enumeration plus exact joining takes $O(2^qL^2)$ word operations with $O(L+q)$ working words; all pins, source reads, edge headers, failed branches, caches, restoration and control are included. The original source is not silently erased. \end{proof}
This is a specialization of classical cycle-cutset conditioning and the existing Role-2 tree join, not a novel CSP dichotomy. Its theorem includes supplied structure, charged recognition and one-edge/one-source identity. It does \emph{not} assert $2^q$ is required by every algorithm or that an optimal decomposition is available for free.

\section{An explicit affine bypass with both labels and growing minimal UNSAT core}
Let $P_r$ be the connected cubic prism with vertices two cycles of length $r$ and $r$ matching spokes ($r\ge3$), hence $|V|=2r$, $|E|=3r$. Name one Boolean variable $x_e$ per edge. At every vertex impose
\[
  \bigoplus_{e\ni v}x_e=b_v.
\]
Encode its single ternary parity constraint by the four proper three-literal CNF clauses forbidding the four opposite-parity edge assignments. The resulting ordinary proper-3CNF has exactly
\[
 n=3r,\quad m=8r,\quad
 N=(32r+2)\left\lceil\log_2(64(11r+1))\right\rceil
\]
bits in the declared 2-header/4-fields-per-clause word encoding. Each original edge variable has four positive and four negative occurrences; \emph{this is not signed exact-(2,2)}. Its occurrence-incidence graph is connected. Define $F_r^+$ with all $b_v=0$ and $F_r^-$ by flipping only $b_0$ to one. Their unsigned clause supports and encoded lengths agree.

\begin{theorem}[Parity obstruction to cycle-rank taxation]
For every $r\ge3$,
\[
 \SAT(F_r^+)=1,\qquad \SAT(F_r^-)=0,\qquad q=r+1.
\]
The UNSAT formula has no UNSAT subformula omitting every clause of any one vertex parity gadget, so every UNSAT clause core has at least $2r$ clauses. Yet a uniform source-grammar recognizer followed by an XOR-of-charges check decides \emph{both labels} of this canonically encoded family in $O(N\,\mathrm{polylog}\,N)$ bit work and $O(\log N)$ writable bits. General, source-validated affine equations admit Gaussian elimination in polynomial time on arbitrary interaction graphs. Thus growing $q$, growing affine rank $2r-1$, and growing UNSAT core span do not force superpolynomial exact SAT decision.
\end{theorem}
\begin{proof}
Sum the parity equations over all prism vertices. Every edge occurs exactly twice, so the left side vanishes. Thus SAT requires $\bigoplus_v b_v=0$. For connected $G$, the incidence matrix over $\mathbb F_2$ has row rank $|V|-1$: a dependency among vertex rows would be a subset of vertices with no crossing edge, hence either empty or all of $V$. Therefore this parity condition is also sufficient and removing \emph{any} one vertex equation makes the others independent and consistent. Each XOR3 gadget uses all four of its own clauses to encode its equation. Deleting all four clauses at any vertex yields a SAT formula, so an UNSAT subformula must include at least one clause from each of the $2r$ distinct gadgets. The graph has cycle rank $3r-2r+1=r+1$. Source reading, ordered gadget signatures, parity accumulation, header checks and the required source identity matching are all paid; no correct-label oracle or exponential compatibility table is used. The canonical recognizer rejects unsupported sources and a complete exact fallback is required to make a total ordinary SAT decider; that fallback is not polynomially bounded. \end{proof}
This prism is a Tseitin-type affine system. The parity satisfiability criterion and Gaussian method are known; the intended contribution is the \emph{exact matching against the new cycle-cutset algorithm and ARC resource gate}, not a newly discovered affine decision method.

\section{Adaptive state and BIT-RESOURCE1}
