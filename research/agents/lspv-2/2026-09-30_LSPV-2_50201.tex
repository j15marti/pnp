STRONGEST THEOREM THIS RUN
LINEAR-COORDINATE PRODUCT-SPAN LEMMA.
Let g_1,...,g_m be affine Boolean functions on a common source domain F_2^s. Let
L=span_F2{1,g_1,...,g_m}, and let r=dim(L)-1 after quotienting constants, equivalently the dimension of the linear parts of the g_i. Then
rho(E_H)=dim span{1,g_i,g_i g_j}
<= 1+r+binom(r,2).
Proof: choose independent affine coordinates ell_1,...,ell_r spanning all g_i modulo 1. Every g_i is affine in ell. Every product g_i g_j is a Boolean polynomial of degree <=2 in ell. Because ell_a^2=ell_a, the degree-<=2 Boolean monomials are contained in {1,ell_a,ell_a ell_b:a<b}, whose dimension is at most 1+r+binom(r,2). This is invariant under invertible affine relabeling of the source and output linear recombination.
EXACT SPARSE-Q THRESHOLD
The degree-2 output feature space has M=1+m+binom(m,2) columns. If
1+r+binom(r,2) < M,
then K_2(H) is nonzero. Singleton then gives a nonzero Q with at most
2+r+binom(r,2)
ANF monomials. Its monomial-list description costs O((r^2+1) log m) bits and direct fan-in-2 evaluation costs O(r^2+1) Boolean gates.
Hence r=O(sqrt(m)) is sufficient for an O(m)-size Q. The stronger r=O(log m) gives O(log^2 m) monomials. By RM(2,m), any nonzero Q has density >=1/4, so the team's separately verified constant-density reconstruction retuning applies, subject to size normalization and acquisition.
IMPORTANT FALSIFICATION
The condition “field operation is F_2-linear” is not enough. It only helps if the FINAL Boolean coordinates are affine functions of one common low-dimensional source vector. A deterministic local extractor E^X(y) may adaptively choose oracle queries based on previous answers. Even if each oracle answer is a linear functional of an underlying coefficient vector, adaptive query selection can make the resulting output an arbitrary decision-tree composition, with high Boolean degree/product span. Thus:
linear oracle answers + local deterministic access != affine final g_i.
This blocks an invalid transfer from Reed-Muller linear evaluation to the final rank bound.
