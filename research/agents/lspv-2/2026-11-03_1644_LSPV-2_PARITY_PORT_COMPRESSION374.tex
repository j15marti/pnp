\section*{Portwise exact two-rail encoding theorem}
Let $P_{k,c}(X)$ be the complete width-$k$ CNF expressing $\bigoplus_{i=1}^k x_i=c$: for each assignment $a\in\{0,1\}^k$ of parity $1-c$ it has the unique clause
\[
C_a=\bigvee_{i=1}^k\begin{cases}x_i,&a_i=0,\\ \neg x_i,&a_i=1.\end{cases}
\]
Thus each side has $2^{k-1}$ source clauses and the UNSAT union $F_k=P_{k,0}\wedge P_{k,1}$ contains all $2^k$ complete-assignment blockers.

Construct $G_{k,c}(X,Z_c)$ from a fresh private chain of $k-1$ two-input XOR gates: $s_{c,2}=x_1\oplus x_2$ and $s_{c,j}=s_{c,j-1}\oplus x_j$ for $3\le j\le k$. Encode each gate using its four standard proper three-literal source clauses; include two \emph{distinctly source-labelled} copies of the terminal unit $s_{c,k}=c$, so a two-parent AND3 may authenticate the unit GF$(2)$ row without an implicit free conversion. The two rails share only boundary $X$. Let $G_k=G_{k,0}\wedge G_{k,1}$.

\begin{theorem}[Exact portwise semantics and quantified proof-cost gap]
For every integer $k\ge2$, every $c\in\{0,1\}$ and every $a\in\{0,1\}^k$,
\[
P_{k,c}(a)=1\iff (\exists Z_c)\;G_{k,c}(a,Z_c)=1,
\]
and a satisfying boundary assignment has exactly one extension to each rail. For the UNSAT unions, in \emph{one unchanged} $R_{\rm mix341}$,
\[
\boxed{W_R(F_k)=2^k-1,\qquad W_R(G_k)\le 8k-5.}
\]
The respective clause counts are $2^k$ and $8k-4$; the compact circuit uses $3k-2$ variables. For ordinary explicit signed-literal/DIMACS encodings,
$N_F=\Theta(k2^k\log(k+2))$ bits and $N_G=\Theta(k\log(k+2))$ bits.
\end{theorem}
\begin{proof}
Each complete-assignment blocker is falsified by exactly one assignment, hence the two parity sides impose the declared nonconstant functions. Every four-clause XOR gate defines its output uniquely, and evaluating the acyclic rail enforces the same boundary parity. For $F_k$, deletion of any one clause permits exactly its formerly excluded assignment; all $2^k$ sources are essential. The already established binary-premise source-ancestry lower bound gives $q\ge2^k-1$, irrespective of adaptive choices, shared nodes, charged conservative auxiliaries or temporary growth. A full binary Resolution elimination tree over $x_k,\ldots,x_1$ derives the empty clause in $\sum_{j=0}^{k-1}2^j=2^k-1$ paid steps. This is the \emph{prior} LSPV-2/344 exact result.

For $G_k$, three AND3 nodes conjoin each of the four authentic clauses of one XOR gate, with a locally checked 3-variable affine annotation. There are $2(k-1)$ gates, hence $6(k-1)$ nodes. One AND3 for the two labelled copies of each terminal unit gives two unit GF$(2)$ rows. Finally XOR-add all $2(k-1)+2$ rows, using $2(k-1)+1$ paid nodes. Every boundary $x_i$ and every internal nonterminal wire cancels, leaving $0=1$ because the two outputs impose opposite parity. Total: $6(k-1)+2+2(k-1)+1=8k-5$. No uncharged semantic oracle or new rule is used.
\end{proof}

\section*{The physically charged transfer, and its limit}
A fixed uniform preprocessing routine authenticates an \emph{explicit} $F_k$ by checking that every clause lists each $x_i$ exactly once, deriving its excluded assignment, and marking a $2^k$-entry occupancy array; it rejects missing, duplicate or malformed blockers. It can then emit $G_k$ with $O(k\log k)$ bits. Its $k2^k$ literal reads, $\Theta(2^k)$ marker bytes and $\Theta(N_F)$ input access are \emph{polynomial in the original exponentially large explicit input length}. It does not grant a free $R_{\rm mix341}$ proof transformation. Reverse expansion of the explicit blocker CNF from $G_k$ costs $\Omega(N_F)$ physical output bit operations and is exponential in the compact input length. Therefore there is no asserted polynomial-time \emph{bidirectional} translation measured against $N_G$.

A virtual blocker can be indexed by $j\in[0,2^{k-1})$: write $j$ as the low $k-1$ bits of its falsifying assignment and set the high bit to $\operatorname{parity}(j)\oplus(1-c)$. One requested clause is computed with polynomial bit work; emitting all $2^k$ clauses is not free. This virtual object is \emph{not} the fully materialized CNF source that $W_R(F_k)$ measures. The compact proof has $O(k)$ logical nodes and polynomial encoded proof size/checking work, e.g. $O(k^2\log k)$ bits with straightforward dense row serialization.
