\section{Exact source-indexed guarded-implication theorem}
Let $F(X)$ be an arbitrary finite original CNF, with distinct original clause indices $j$ and signed occurrences, and let $B\subseteq X$ be a syntactically discovered guard set. Build a directed multigraph on hidden-variable literals $u,\neg u$ for variables $u\notin B$. For every original source clause $C_j=G_j\vee\neg p\vee q$, where every literal of $G_j$ uses a variable in $B$ and $p,q$ are literals on variables outside $B$, include an edge $p\to q$ labeled $(j,G_j)$ and its contrapositive $\neg q\to\neg p$. A hidden unit consequent can be handled using $\neg q\to q$, with its source guard, if the producer explicitly authenticates that clause. Only edges actually justified by an original clause are permitted. \emph{All original ternary or longer clauses not represented by an edge remain in $F$; the graph need not be a complete 2-CNF replacement.}

\begin{theorem}[Coherent guarded-SCC blocker]
Suppose there are directed source-authenticated paths $P_+:p\leadsto\neg p$ and $P_-:\neg p\leadsto p$, and the set $G$ of guard literals printed on their edges is \emph{coherent}, i.e. it contains no complementary pair $b,\neg b$. Then $F$ entails the original-source clause
\[
 D_G=\bigvee_{g\in G}g.
\]
Every source assignment falsifying $D_G$ has no extension satisfying $F$, and a valid ordinary-resolution DAG from the cited original source parents proves $D_G$. Hence $F\land D_G\equiv F$ on \emph{both} SAT and UNSAT inputs. If no coherent such two paths are discovered, this test returns UNRESOLVED and a complete exact fallback is required; it never exports an UNSAT answer from failure.
\end{theorem}
\begin{proof}
Let an original-source assignment falsify every guard literal in $G$. Each labeled original clause then reduces to its asserted binary implication. The first path yields $p\Rightarrow\neg p$ and the second $\neg p\Rightarrow p$, which is impossible for either Boolean value of $p$. Thus $F\models D_G$. More explicitly, resolve the source parents along $P_+$ successively on their shared hidden literals to obtain $\neg p\vee G_+$ and along $P_-$ to obtain $p\vee G_-$, with intermediate clauses carrying the union of all contributing guards (tautological intermediates may be skipped only with a separate valid proof). Resolve those two non-tautological path clauses on $p$ and deduplicate to yield $D_G$. The implementation validates each actual resolution node against its signed parent clauses and original source indices; this constructive argument does not assume a free 2-SAT oracle, nor does it delete any original clause. Since $F\models D_G$, adding it preserves every source model and therefore the SAT/UNSAT label. A complete satisfying assignment is checked against all original clauses; UNSAT is supplied only by a full checked DPLL tree or a genuine contradiction certificate.\qed
\end{proof}

The graph/path method has the same classical ingredients as 2-SAT implication SCC and resolution. The earlier ANCHORED-INVERSION-SCC1 already constructed the anchored triple instance. The present incremental claim is an \emph{automatically discovered, arbitrarily long coherent guard union with an original-source resolution DAG}, usable as a transactionally retained, non-RUP learned clause. It is not a new proof system. In particular, choosing a minimal coherent path pair or always finding a useful one is not asserted or charged away.
