\section{Declared circuit, syntax and machine endpoint}
For $q\ge3,m\ge1$, put $w=\lceil\log_2(q+1)\rceil$ and $B=m[1+3(w+1)]$. The primary input is $m$ fixed-width ternary records (active flag and three name/sign pairs), and an independent $q$-bit proposed assignment. The total, fixed-record verifier outputs
\[
 V_{q,m}(x,z)=\bigwedge_{c<m}\left(\neg a_c\vee\left[\operatorname{Valid}(c)\wedge\bigvee_{j=0}^2(z_{v_{cj}}=s_{cj})\right]\right).
\]
Active malformed names or repeated variables fail the verifier; inactive clauses contribute true. This is a \emph{witness verifier}, not a deterministic all-input SAT decision circuit $C_{A,N}$, and does not parse arbitrary variable-width DIMACS. Both SAT and UNSAT source cases remain within the stated verifier semantics.

Set
\[
 K=2^{\lceil\log_2(q+3m)\rceil},\quad h=\log_2K,\quad J=h(h+1)/2,\quad D=w+3,\quad F=13w+32.
\]
There are $G_f=J(K/2)F$ forward gates, and $G_s=19+(K-1)(4w+18)$ scan gates. Reverse gates number $G_r=3KJ$, and final checker gates $G_c=m(36w+15)+(m-1)$. The full circuit has $G=G_f+G_s+G_r+G_c$ AND/OR gates. Each gate ID is a \emph{gate index}, distinct from a wire ID, and every signed Boolean reference is retained. The total compiler uses one fixed thirteen-row proper-CNF block per Boolean gate, plus charged primary and constant/output pins. The indexed source-interface theorem below concerns only the scan gate-block sector.

\section{Streaming construction of the balanced EqBits reduction tree}
In the exact emitter, a call $\operatorname{EqBits}((a_i)_{i<L},(b_i)_{i<L})$ emits the $3L$-gate signed XOR expansion
\[
 u_i=a_i\wedge\neg b_i,\quad v_i=\neg a_i\wedge b_i,\quad e_i=u_i\vee v_i,
 \qquad \operatorname{Eq}(a_i,b_i)=\neg e_i,
\]
then invokes \texttt{andmany} on the $L$ negative $e_i$ wires. At round $j\ge0$ let $\ell_j=\lceil L/2^j\rceil$. Round $j$ emits exactly $\lfloor\ell_j/2\rfloor$ AND gates and carries a last unpaired source wire forward \emph{unchanged} when $\ell_j$ is odd. The sum of emitted AND gates is $L-1$ (so total $4L-1$), with zero new gates for carried leaves. The input of round-$j$ pair $r$ at side $\epsilon\in\{0,1\}$ is source $(j,2r+\epsilon)$; this source is recovered with the following iterative rule:
\[
 (j,t)\longrightarrow\begin{cases}
 \text{gate from round $j-1$, index $t$},&t<\lfloor\ell_{j-1}/2\rfloor,\\
 (j-1,\ell_{j-1}-1),&t=\lfloor\ell_{j-1}/2\rfloor\text{ and }\ell_{j-1}\text{ odd}.
 \end{cases}
\]
At $j=0$, return the signed wire $-e_t$. A fixed number of $O(\log G)$-bit registers suffice, since the algorithm updates $j,t$ in place and never recursively stores a stack. All gate offsets are the prefix sums of round counts and are calculated afresh. The source of each of the $4L-1$ gate slots is therefore obtained without retaining any layer array.

\begin{counterexample}[Naive even-pair source indexing is wrong]
For $L=3$, the first AND round emits $a=(-e_0)\wedge(-e_1)$, then carries $-e_2$ unchanged. The final round emits $a\wedge(-e_2)$. A false rule that regards both first-round outputs as fresh gates would invent an extra gate for the odd $e_2$ and return the wrong physical predecessor. Our bit-at-address program uses the exact carried-leaf case.
\end{counterexample}

\section{Uniform all-scan inverse theorem}
The scan processes sorted record positions $p=0,\ldots,K-1$ with gate-block start
\[
 b_p=\begin{cases}G_f,&p=0,\\G_f+19+(p-1)(4w+18),&p>0.\end{cases}
\]
The first $7$ gates of each block compute $\mathsf{isassign}_p=\operatorname{EqBits}(\mathsf{kind}_p,00)$, the next $7$ compute $\mathsf{isquery}_p=\operatorname{EqBits}(\mathsf{kind}_p,01)$. For $p>0$, the next $4w-1$ gates compute $\mathsf{same}_p=\operatorname{EqBits}(\mathsf{id}_p,\mathsf{id}_{p-1})$. Finally five gates, in physical order, compute
\begin{align*}
 k_1&=\mathsf{same}_p\wedge\mathsf{carry}_{p-1},&k_2&=\neg\mathsf{isassign}_p\wedge k_1,\\
 c_1&=\mathsf{isassign}_p\wedge\mathsf{payload}_p,&
 \mathsf{carry}_p&=c_1\vee k_2,\\
 \mathsf{scanout}_p&=\mathsf{isquery}_p\wedge\mathsf{carry}_p.
\end{align*}
At $p=0$, $\mathsf{same}_0=\mathsf{carry}_{-1}=0$ and no $w$-bit equality is constructed. Previous record keys, payloads and bitonic outputs are obtained from the already proven \emph{final forward record-output} arithmetic accessor, never identified with gate IDs without applying the explicit base shift. The scan-output gate has two signed consumers in the first reverse stage, according to report 173.

\begin{theorem}[All scan gates have uniform inverse consumers; architecture-restricted]\label{th:scan}
For every fixed $q\ge3,m\ge1$ and each gate index $G_f\le g<G_f+G_s$, a single deterministic uniform \texttt{ScanGateAt(q,m,g)} procedure returns its exact operator and both signed operand wire IDs in $O(\operatorname{polylog}G)$ bit operations and $O(\log G)$ total live index/work bits. A \texttt{ScanSelect(g,r)} and inverse \texttt{ScanRank(g,a,slot)} list every signed direct consumer, sorted by physical gate and slot, using $O(\log^6G)$ elementary bit operations and $O(\log G)$ live index/work bits. No stored gate table, occurrence table, or live fanout index is used. Every scan gate has between one and two signed direct uses, counting the reverse-layer uses of $\mathsf{scanout}$.
\end{theorem}
\begin{proof}
Recover $p$ and its local offset by subtracting the first 19-gate block and dividing by $4w+18$ for $p>0$. The EqBits arithmetic above yields every within-block descriptor. The final five descriptors follow from the displayed formulas, with the previous carry at the known final OR slot of block $p-1$. The resulting \texttt{GateAt} stores a constant number of $O(\log G)$-bit IDs and at most a constant number of loop indices. Inspect every operand of the $O(w)$ gates in block $p$ and (when it exists) block $p+1$. No gate in any block $r\ge p+2$ reads a scan result from block $p$: it reads the immediately previous carry, and previous-\emph{key} wires originate in the final sorting layer rather than the scan. No prior block can read a future gate because the netlist is acyclic and emitted in increasing gate-ID order. Only $\mathsf{scanout}_p$ is read outside the scan, by the two signed reverse-MUX operands specified by the fixed reverse-layer layout. These cases exhaust the direct consumers. All scans are re-generated arithmetically; at most two consumer triples are retained. The worst-case $O(\log^6G)$ bit-operation bound safely dominates the local $O(w)$ descriptor visits, schoolbook integer division and the $O(h^2)$ layer/stride lookup; workspace is $O(\log G)$ because no $O(w)$ descriptor array is retained. The gate's own five-row defining CNF occurrence list is independent of its fanout. Every intermediate EqBits gate feeds its own XOR or reduction tree; other nonoutput gates feed the next displayed five-gate operation; each scanout feeds the reverse MUX, proving the fanout bounds.
\end{proof}

\section{Exact source occurrence and bit-at-address interface}
In the actual thirteen-clause gate compiler each output gate variable $y_g$ has exactly five own-block occurrences. If gate $g$ is an AND, own clause-row $8$ has $(y_g,+)$ at slot 2 and rows $9,10,11,12$ have $(y_g,-)$ at slot 1; OR reverses those polarities. Each signed use in operand slot $k$ of consumer gate $c$ contributes four clone-identity rows with signed polarities $(\tau,\tau,-\tau,-\tau)$ at literal slot 1:
\[
  (13c+4k+j,1,\,\tau(-1)^{[j\ge2]})\qquad (j=0,1,2,3).
\]
Thus, with $f\in\{1,2\}$ exact signed gate uses,
\[
             \#\operatorname{Occ}(y_g)=5+4f\in\{9,13\}.
\]
For source module gate $g$, the six private names/rows and signed operand copies are obtained by the fixed compiler equations; a source operand $\pm u$ with $u$ an earlier gate is mapped to $\pm(\mathsf{base}+9(u-\mathsf{base})+2)$, preserving gate-to-source-variable identity. Pins/constants and private output-variable declarations are distinct. For the declared canonical binary wrapper, let
\[
 n_0=9G+3B+q+8,\quad m_0=13G+4B+12,\quad W=\lceil\log_2(\max(n_0,m_0)+1)\rceil.
\]
The wrapper header contains fixed magic, a self-delimiting width length, $W$, $n_0$ and $m_0$. A data bit of physical clause row $c$, literal slot $s$, and bit position $j$ has address
\[
     \mathsf{headerlen}+(3c+s)(W+1)+j.                 \tag{*}
\]
The same local \texttt{GateAt} produces its signed literal ID, then its sign bit or its $j$th magnitude bit in $O(\operatorname{polylog}G)$ time and $O(\log G)$ space. The exact physical output is not generated or stored in memory. It is nonetheless \emph{not} shorter: materializing it costs at least its own length in bit writes.

\begin{theorem}[Scan-sector proper-source Rank/Select and virtual bit getter]\label{th:cnf}
Under Theorem~\ref{th:scan}, every scan gate's ordered signed proper-CNF occurrence list, inverse occurrence rank, and every bit of its thirteen physical compiler clause records have uniform $O(\operatorname{polylog}G)$ time and $O(\log G)$ index/work bits. The implementation reconstructs a clause bit when queried and charges each such reconstruction. This theorem does not include the full R15 regularization incidence map, arbitrary input parsing or an all-input SAT decision circuit.
\end{theorem}
\begin{proof}
Combine exactly the five own-block occurrences with the four clone rows of each signed consumer from Theorem~\ref{th:scan}. At most 13 triples occur, so sorting or rank enumeration stores at most a constant number of $O(\log G)$-bit integers. Formula (*) maps row and literal slot to physical bit address by arithmetic; the canonical source gate 13-row template maps each query to one signed integer. Integer sign extraction and binary digit extraction require $O(\log G)$ workspace and polynomially many bit operations in $\log G$. All rows carry three distinct source variable names because the compiler uses private clones and padding. The proof concerns source access, not evaluation of the whole circuit or any guest solver's random reads.
\end{proof}

\section{UTM write-space, two machine ledgers, and barriers}
For a machine with a single two-way sequential read-only input head and $k$ fixed independent sequential work heads on initially \emph{unmarked} blank bi-infinite tapes, $D=0$ actual work-symbol changes means every visited work cell reads the same blank. Head coordinates are not readable, so the transition function reduces to a deterministic two-way finite automaton. By Rabin--Scott and Shepherdson its language is regular~\cite{RS,Shepherdson}. The separated DISJ fooling set has $2^m$ distinguishable Alice prefixes on a common fixed middle, so it is nonregular. Thus the pre-registered unmarked $D=0$ positional-counter mechanism fails, independent of how far blank work heads move. This result was already established by prior LSPV-2 reports 175/176, not claimed as new. One actual marker write ($D=1$), or an initially supplied marker counted as an initial resource $I_0=1$, permits a \emph{tagged-word} unary counter with $S=O(m)$, $T=O(mN)$, $R=O(m)$; the decoder for this \emph{raw physical binary CNF} remains \OPEN. Its source-only witness printer is not a sound acceptor on UNSAT, even when printing is cheap. For any $k$-head fixed-interpreter claim, source/proof input access, actual symbol changes, visited blank work cells and program length require explicit accounting.

 T_1=O\!\left(T_k(N+S_k+\log(T_k+2))\right),\qquad

\]
This is an \emph{upper} simulation arrow; the Hennie--Stearns $O(T\log T)$ theorem is for two simulation tapes, not the ordinary single tape. HEADMOVE-1's $H(S+1)=\Omega(N^2/\log N)$ and $(R+1)(S+1)=\Omega(N/\log N)$ are restricted to one sequential source head on the authenticated equality/DISJ promise. Bounded-jump $J=N^j$ produces a separately defined interpolation $t+s+j\ge2$, not a bound in the native FLMV indexed-input model. All data movement, failed strategies, circuit materialization and repeated virtual source-bit calls remain charged to the \emph{same} machine as any hypothetical SAT decider.

The prior explicit two-level signed regularization has $m_2=4048m_0+5888n_0$ and, in the fixed full-pin architecture, a physical floor $m_2\ge33856B$. Thus small local inverse GateAt does not create $N^\lambda$-size ordinary-SAT children with $\lambda<1$. Pippenger--Fischer applies to its specified one-dimensional tape compilation, not magically to arbitrary RAM operations~\cite{PF}; FLMV's random-access time-space exclusions require a single \emph{total deterministic all-input SAT decider} in their native model~\cite{FLMV}. Under $P=NP$ one obtains an unknown polynomial exponent $K$ for such a machine, not the extra $d=1.802$, $s=o(1)$ seed. None of the present theorem families supplies all-input ARC resource contraction.
