\section{Reverse Circuit-SAT and occurrence-graph audit}
Let $F$ be a proper signed exact-$(2,2)$ three-CNF with $n$ densely named original variables, $m$ unique proper clauses, each variable occurring twice per sign. Then $4n=3m$. The shared-source assignment evaluator has $n$ NOT gates, $2m$ OR2 gates and $m-1$ AND2 gates, totaling $n+3m-1$ gates and $n+6m-2$ directed references by the declared PAIRRIGID72 convention. This is an input formula evaluator, not a circuit deciding SAT encodings.
Backward output TRUE forces all clause outputs TRUE. One selected true occurrence per clause with no complementary original-source selections exists iff $F$ is SAT; several original literals may be true in a clause. The occurrence graph has $4n$ vertices and $4n$ conflict edges, forming $n$ disjoint $K_{2,2}$ blocks. Adding one triangle per clause adds $3m=4n$ edges. The resulting degree-four graph has an independent set of size $m$ iff $F$ is SAT, but such a graph need not be constructed by another SAT solver.
The fixed record input uses $w=\lceil\log_2(64(n+m+1))\rceil$ bits per word, $N=(4m+2)w$ encoded bits.

\section{Source conservation and Davis--Putnam cancellation}
Contract all certified complementary pairs
\[
(a\vee b\vee x)\wedge(a\vee b\vee\neg x)\equiv(a\vee b)
\]
into binary $B$, retaining unmatched ternaries $T$. Pair matching is forced by original exact occurrence regularity (PAIRRIGID72). If $t_x$ counts $x$-pivot pairs, $b_x^\pm$ signed appearances in $B$ and $u_x^\pm$ signed appearances in $T$, then
\[
 t_x+2b_x^++u_x^+=2,\qquad
 t_x+2b_x^-+u_x^-=2. \tag{1}
\]
\begin{lemma}[Original-source single-pivot trichotomy]
If $t_x=1$, then $b_x^+=b_x^-=0$ and $u_x^+=u_x^-=1$. Thus $x$ appears in exactly two unmatched ternaries in opposite signs and no binary clause.
\end{lemma}
\begin{proof}
For both signs, (1) becomes $1+2b+u=2$ with nonnegative integer $b,u$. Necessarily $b=0,u=1$.
\end{proof}
\begin{lemma}[Source-preserving existential projection]
If the only remaining occurrences of $x$ are $(x\vee A)$ and $(\neg x\vee D)$, then
\[
\exists x\,[(x\vee A)\wedge(\neg x\vee D)]\equiv A\vee D. \tag{2}
\]
If $A\vee D$ contains opposite literals $\ell,\neg\ell$, it is tautological and both parents disappear. A satisfying assignment extends by taking $x$ true when $A$ is false and false otherwise; if $\ell\in A,\neg\ell\in D$, the concrete lift $x=\neg\ell$ works.
\end{lemma}
\begin{proof}
When $A$ is true choose $x=0$; otherwise the resolvent forces $D$ true and choose $x=1$. For the complementary mate the two cases are verified directly.
\end{proof}
After a resolution step the live formula need not retain exact-$(2,2)$ counts, so a correct adaptive algorithm recomputes actual incidences. A non-tautological resolvent is of width three if the proper ternaries share one same-signed nonpivot variable, or width four if the remaining supports are disjoint. Width-four proposals are rejected by the declared width-three normalizer, not implicitly compressed.

\section{Connected $C_q$ construction and exact polynomial shortcut}
For integer $q\ge1$, let distinct module variables be $a_i,b_i,c_i,x_i,y_i,z_i$, with $a_q=a_0$ cyclically. Module $i$ consists of
\[
\begin{array}{rl}
(a_{i+1}\vee b_i\vee x_i),&(a_{i+1}\vee b_i\vee\neg x_i),\\
(\neg a_i\vee c_i\vee y_i),&(\neg a_i\vee c_i\vee\neg y_i),\\
(\neg b_i\vee x_i\vee z_i),&(\neg b_i\vee\neg x_i\vee\neg z_i),\\
(\neg c_i\vee y_i\vee z_i),&(\neg c_i\vee\neg y_i\vee\neg z_i).
\end{array} \tag{3}
\]
\begin{theorem}[Cyclic cancellation upper bound, restricted]
$C_q$ is incidence-connected, proper, duplicate-free, signed exact-$(2,2)$, and has $n=6q$, $m=8q$. It contains $p=2q$ certified complementary pairs and $\delta=m-2p=4q$ genuine unmatched ternaries. The minimum raw strong 2-CNF deletion-backdoor size of the unmatched clause set is exactly $h=q$. Nevertheless a total uniform source-aware policy uses $2q$ tautological pivot eliminations to remove all $4q$ unmatched ternaries, then solves the remaining $2q$ binaries and reconstructs an original satisfying assignment in $O(m\log(m+2)+n)$ addressed-word operations and $O(n+m)$ live words.
\end{theorem}
\begin{proof}
Direct socket enumeration of (3) gives exactly two occurrences of each sign for each of the six module sources. The cycle of shared $a_{i+1}$ sources connects the incidence graph. The first two rows contain the $2q$ complementary pairs, and direct inspection plus PAIRRIGID72 excludes others. Unmatched ternaries of distinct modules have disjoint supports; all four unmatched ternaries in module $i$ contain $z_i$. Therefore a hitting set must choose at least one variable from each module, and all $z_i$ give exactly $q$.
Resolve each $x_i$ across its two remaining parents: the resolvent is $(\neg b_i\vee z_i\vee\neg z_i)$, hence tautological. The corresponding $y_i$ resolvent is $(\neg c_i\vee z_i\vee\neg z_i)$, also tautological. Each correct inverse witness assignment can take $x_i=y_i=\neg z_i$. The remaining binary clauses are $(a_{i+1}\vee b_i)$ and $(\neg a_i\vee c_i)$; setting every $b_i=c_i=1$ satisfies them. A charge for input parsing, pair discovery, failed and successful local recognition, graph construction, source-reconstruction trace, SCC and complete original-clause replay is bounded by sorting plus linear work and storage.
\end{proof}
An explicitly prescribed full-backdoor leaf enumerator without pruning explores $2^q$ leaves. This comparison is confined to that restricted policy. A large $\delta$ or $h$ alone does not force superpolynomial SAT decision time.
