## Exact model, reduction, theorem

The *original source* consists of 4 consecutive proper signed ternary clauses per vertex of an authenticated connected simple cubic graph G=(V,E), H=|V|, |E|=3H/2. The source is reconstructed from occurrence supports, not from an unverified supplied graph. An intact packet is exactly all four parity-forbidding clauses for charge b_v; D is the set of all other four-clause packets, which may be arbitrary local ternary packets with repeated clauses. Set N=Theta(H log H) bits for conventional explicit indexed-identifier encoding.

Let c be the number of connected intact components of G[V\\D]. Let r be the cyclomatic number of G[D]:

$$
r=|E(G[D])|-|D|+\\operatorname{comp}(G[D]).
$$

Build any DFS spanning forest of G[D], choose one endpoint of every non-tree edge, and call their union S. Then |S|<=r, G[D\\S] is a forest, and the set U of all original edges incident to S has |U|<=3r.

**Theorem 477.1 (PROVED/RESTRICTED, independent review pending).** Satisfiability of the *original* signed 3-CNF, with witness recovery, is decidable by a deterministic cycle-cutset conditioning plus shared-syndrome forest DP in

$$
T=O\\left(2^{3r}(N+H4^c)\\operatorname{polylog}(N+H2^c+2)\\right)
$$

standard bit operations and

$$
S=O\\left((N+H2^c)\\operatorname{polylog}(N+H2^c+2)\\right)
$$

writable bits under a declared bit-RAM, for an implementable pointer/backpointer representation and sequential case enumeration. No FLMV-native time/space exponent is established. In particular if r,c=O(log N), the specified family has polynomial-time decision; it need not have a polynomial number of defective packets.

**Proof:** The DFS forest has exactly r non-tree edges, and deleting one endpoint of each removes every cycle. Enumerate each assignment to the <=3r original edges U. Check all original packets at S with the pinned values. For any intact connected component C_i define q_i=XOR_{v in C_i} b_v. After pinning, set q'_i=q_i XOR (XOR of the pinned edges from S into C_i). At each unpinned defective vertex require its actual 4-clause packet and all pins on its edges to S, then compute a bottom-up forest DP whose key is (parent original-edge bit, c-bit XOR boundary contribution). Each child contributes an AND obligation consistent with the same original edge; legal local assignments are OR alternatives; deduplicate identical states after every join. For any joint forest output q', all intact-component incidence systems have compatible right-hand sides. Choose nontree intact edges zero and propagate the remaining parity values over spanning trees, yielding an original-variable witness. Conversely every satisfying original assignment restricts to one enumerated U case and to valid tree DP witnesses. There are at most 2^{3r} cases, O(H4^c) joins per case and O(H2^c) resident states; sequential enumeration reuses writable storage. The input, syndrome tables, graph, extraction and witness are included in the bit-RAM accounting. Reference Python copies some trace lists and is **not** a measured realization of the claimed pointer-based bit cost.

**Hardness-family ledger:** For 3-regular *expander* G and odd charge, this original (unreduced) 4H-clause proper-3CNF has ordinary DAG Resolution refutation size 2^{Omega(H)}, Ben-Sasson-Wigderson Cor.4.5 / Urquhart; rule set is ordinary clause Resolution. There is no lower-bound-preservation step required to obtain this direct 3-CNF. The original all-intact case D=empty is efficiently decided by signed parity cancellation, and full mixed AND3/GF(2) may be short. The cycle-cutset algorithm is an **upper-bound control**, not a proof-size lower bound for R_mix341, not a restriction on every algorithm, and not a universal SAT decider. Graphs used in finite tests (K4/cube/prism/Petersen) are finite correctness controls, **not a certified asymptotic expander sequence**.
