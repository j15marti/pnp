\section{General certified pipeline}
Take an explicit CNF with \(n\) source Boolean variables, \(m\) clauses and four \(w\)-bit fields per clause, with \(w=\lceil\log_2(16(n+m+1))\rceil\) and \(N=4w(m+1)\) input bits. All source reads, shortcut attempts, certificates and source replays are charged.
\begin{theorem}[Arbitrary 2-CNF with at most \(k\) ternary clauses]
There exists an exact deterministic certified SAT/UNSAT algorithm in time \(O(2^h\operatorname{poly}(N))\) for some \(h\le k\), with polynomial streaming workspace.
\end{theorem}
\begin{proof}
Scan the ternary clauses, adding one variable from any uncovered ternary to a set \(S\). Then \(|S|=h\le k\) and every restriction to \(S\) leaves 2-CNF. Enumerate all \(2^h\) assignments and decide each child by SCC. For SAT replay the full source assignment. For UNSAT retain or stream empty-clause certificates or a pair of source-labelled paths \(x\leadsto\neg x\) and \(\neg x\leadsto x\) for each rejected child; the verifier checks those edges against the restricted clauses. Child construction, unsuccessful branches and verification are counted. Retaining all certificates may use exponential output memory. This is an upper bound, not a search lower bound.
\end{proof}
Alternative polynomial shortcuts include charged affine/XOR recognition plus Gaussian elimination, and exact source-separated component joining. Neither shortcut may omit cross-block shared source variables.

\section{Source-CNF quotient and exact table certificates}
For graph \(G=(V,E)\) use three original Boolean variables \(x_{v,0},x_{v,1},x_{v,2}\) per vertex and the formula
\[
F_G=\bigwedge_{v\in V}\left[(x_{v,0}\vee x_{v,1}\vee x_{v,2})
\wedge\bigwedge_{a<b}(\neg x_{v,a}\vee\neg x_{v,b})\right]
\wedge\bigwedge_{\{u,v\}\in E}\bigwedge_{a=0}^{2}
(\neg x_{u,a}\vee\neg x_{v,a}).
\]
Its satisfying assignments are in bijection with graph three-colorings. The normalizer independently checks the complete signed-clause multiset. Here \(q=|V|,\ e=|E|,\ n=3q,\ k=q,\ m=4q+3e\). There are no auxiliary variables in the original encoding.

Choose an explicit elimination order \(\pi\), verifying its induced width \(h\) by fill-in. Eliminate each three-valued vertex \(z\) by exact existential factor projection
\[
R_z(\alpha_U)=\bigvee_{c=0}^{2}\bigwedge_{H\ni z}H(\alpha_U,c).
\]
Store every projected truth table and one witness selector per accepting row; independently replay each row for verification. A false final empty-scope factor proves UNSAT; otherwise reverse selectors construct a coloring and replay all original clauses. The selectors preserve existential extension, not every original assignment.

\begin{theorem}[Restricted certified complexity]
With the explicitly scanned factor-header implementation, normalization and independent verification take
\[
O\bigl(m\log(m+2)+(h+1)q(q+e)+(q+e)(h+1)3^{h+1}\bigr)
\]
word operations and \(O(m+(q+e)(h+1)3^h)\) retained proof/storage words. Verifying an order and reading the source are charged.
\end{theorem}
\begin{proof}
Each step computes the exact existential projection of all factors mentioning the eliminated variable. Each such factor is absorbed once; at most \(h\) future neighbors yield \(3^h\) table rows with three possible eliminated colors. The stated bound includes factor-header rescans, scope processing, source multiset matching, proof rows and witness reconstruction. Checking every projected table independently verifies both labels. This is a particular charged implementation of established bounded-width CSP methods.
\end{proof}

\section{Matched ladder construction}
For \(t\ge3\), form two row vertices per column \(i=0,\ldots,t-1\), all vertical rungs, and consecutive horizontal row edges. Add the diagonal \((0,0)(1,1)\) in both cases. The UNSAT case adds \((0,1)(1,0)\), creating \(K_4\) in the first square. The SAT case instead adds \((1,1)(2,0)\). Both labels have
\[
q=2t,\quad e=3t,\quad n=6t,\quad k=2t,\quad m=17t,\quad
N=4w(17t+1).
\]
The minimum direct-restriction strong syntactic 2-CNF backdoor has size \(2t\), because every disjoint positive ternary requires a chosen source variable. There are \(\lfloor t/2\rfloor\) vertex-disjoint square cycles, so every feedback vertex set has that many vertices. Cycle rank equals \(e-q+1=t+1\).

\begin{theorem}[Project-specific hostile pair]
The canonical source vertex order has induced elimination width at most three on both inputs. The UNSAT graph has zero colorings; the SAT graph has exactly \(6\cdot3^{t-3}\) colorings.
\end{theorem}
\begin{proof}
Eliminating a vertex in a column leaves at most the other vertex in that column and the two vertices of the next column, including fill edges. Hence at most three later neighbors. The UNSAT graph contains \(K_4\). The first three columns of the SAT graph have six proper colorings, and each subsequent ordinary two-row column has three extensions for each properly colored preceding column. Induct on column count.
\end{proof}
Thus a strategy branching on a minimum feedback vertex set has a growing exponential parameter on this family, while certified bounded-width dynamic programming is polynomial. The UNSAT case also has a simple local four-clique shortcut, and no unrestricted hardness is inferred.

\section{No-local-\(K_4\) wheel pair}
For odd \(g\ge7\), form a rim cycle of \(g\) vertices and a hub. The UNSAT case joins every rim vertex to the hub. Once a hub color is chosen the odd rim would need two colors, impossible. The SAT case replaces the hub-to-\(v_0\) spoke by the rim chord \(v_1v_4\). Give the hub and \(v_0\) a third color and alternate the remaining rim colors. Both graphs are \(K_4\)-free with equal \(q=g+1,\ e=2g,\ n=3(g+1),\ k=g+1,\ m=10g+4\). The natural rim-then-hub order has induced width at most four. This matched control avoids attributing the earlier normalization solely to local \(K_4\) recognition.
