## IDEA before search: exact replay cannot erase genuinely distinct guest input markers

Hypothesis: For any *hypothetical* total polynomial SAT decider B, there are equally correct polynomial-time guests A_K whose fully charged, full-input-marker-preserving computation prevents **all** exact-state checkpoint reconvergence during an arbitrarily long padding interval. This should give a quantitative necessary *spectrum* bound on any wrapper that faithfully runs unmodified guest calls. It does not prohibit a code-aware compiler from stripping padding.

## Hard-family/theorem/encoding/shortcut ledger

For a connected cubic graph G=(V,E), h=|V|, |E|=3h/2, create one original variable x_e per edge and one charge c_v∈{0,1} per vertex. The parity equation at v is $\bigoplus_{e\ni v}x_e=c_v$. Encode its four forbidden 3-bit assignments as four **original strictly proper signed 3-clauses**, one three-literal clause for every assignment violating the required parity. Thus exactly 4h original clauses, no duplicate literals inside any clause, and binary fixed-width edge IDs give $M=\Theta(h\log h)$ bits. If $\bigoplus_v c_v=1$, summing equations gives 0=1, hence source UNSAT. If charges sum evenly, the connected incidence system is solvable. For a suitable expander G, original odd-charge Tseitin sources have published exponential lower bounds for *ordinary shared-DAG Resolution*, not for R_mix341, GF(2)-extended systems or general SAT algorithms. Distinct odd-charge configurations produce $2^{h-1}$ distinct, equally long UNSAT source strings. Algebraic GF(2) elimination is an actual polynomial-time shortcut for this recognizable family; it is retained as an upper-bound control. The finite instance below uses K4 (h=4, 6 edge variables, 16 clauses), not an asymptotic expander-hardness instance.

## ITERATE: Theorem 502.1, full-input marker faithful-execution spectrum (PROVED/RESTRICTED)

**Conditional premise:** There exists a deterministic, uniform, total, three-label correct SAT/UNSAT/MALFORMED decider B with polynomial worst-case time $T_B(m)\le(m+1)^{c+o(1)}$ and space $S_B(m)\le(m+1)^{s_B+o(1)}$. Fix an integer $K>c+1$. Define a single uniform fixed-code decider A_K: (1) copy *every* source bit, including complete length and syntactically encoded branch contexts, into a private immutable work tape; (2) execute an explicit counter with $(m+1)^K$ pairwise-distinct successive counter values while preserving the original copied source unchanged; (3) call B(x) and return precisely B's classification. A_K is total correct on every binary input, including malformed. Its time is $(m+1)^{K+o(1)}$ and its space exponent is $\max(1,s_B)$ (plus O(K log m) counter storage). K is fixed per constructed program; no unknown exponent is extracted by the wrapper.

Let $\mathcal{Q}=\{x_1,\ldots,x_q\}$ be *pairwise-distinct* complete guest input strings, of lengths $m_1,\ldots,m_q$. Consider an exact-configuration trace-replay wrapper that faithfully executes each unmodified A_K guest, perhaps reusing any identical machine configuration after the fact, reconverging freely, and counting each distinct actual guest transition once. The full copied-input marker differs across every pair of source strings (length is included). The counter does not repeat during its $(m_j+1)^K$ iterations. Therefore **no post-copy padding configuration or padding transition can be shared between different $x_j$**, and none repeats within a guest. The union of all actually executed padding transitions has cardinality at least

$$
W_{\mathrm{guest}}(\mathcal Q)\ \ge\ \sum_{j=1}^{q}(m_j+1)^K.
$$

This is a theorem about a specified *unchanged-guest, exact-machine-state replay* architecture, NOT a general lower bound for SAT, another fixed logical proof calculus, or every possible implementation of $\Phi(A_K)$. A code-aware optimizer may remove the artificial loop, a semantic Tseitin recognizer may bypass A_K, a different solver may process the queries, and repeated identical children can be cached; the claim deliberately excludes none of those legal shortcuts. This is a strengthened all-source-string version of LSPV-4/501's tag antichain, not a claim of a novel P-versus-NP theorem.

**Spectrum corollary.** If an attempted sequential contraction faithfully executes at least $N^{a-o(1)}$ *distinct* guest calls, each length at least $N^{\lambda-o(1)}$, its guest work is at least $N^{a+\lambda K-o(1)}$. The demanded FLMV stage exponent for this A_K is $f(K)=\max(11/10,3/5+K/2)$. A necessary condition *inside this exact-replay architecture* is

$$
a+\lambda K\ \le\ \max(11/10,\ 3/5+K/2).
$$

For large K and $a=3/5$, this requires $\lambda\le1/2$. When $a=3/5$ and $\lambda=1/2$, exact guest replay alone already costs $N^{3/5+K/2-o(1)}$: prefix sharing does not shave a positive fixed exponent off the dominant guest work. More generally the entire query-length $K$th moment, not merely the longest child, must fit the time budget. The argument places **no lower bound** on the number or lengths of queries that an actual successful all-input SAT compiler must choose, and supplies **no** such compiler.

**Work / depth / space ledger:** Work is the union of distinct padded guest transitions just shown. With *unbounded parallel guests*, its critical-path depth lower bound is $\max_j(m_j+1)^K$, not the sum; with the project's sequential guest schedule, the elapsed time includes the sum. A single guest physically stores at least $m_j$ work bits for the marker; checkpoint retention of q separate entire snapshots would naively use $\sum m_j$ bits, but we make **no** impossibility claim against compression, replacement, recomputation, different schedulers or source semantics. Guest parsing, copy, delay, B execution, output, index access, all-phase peak memory and code-aware preprocessing are paid in genuine algorithm upper bounds. There are zero external proof/certificate advice bits. The finite replay below uses host memory and is not a native FLMV-machine cost validation. For materialized children the unproved universal application still requires $\rho\le1/2$ in $s'\le\max(\rho,\eta,\lambda,\lambda s)$.

## Independent finite falsifiers (COMPUTATIONAL)

Python and independently written JavaScript tested 16 original signed, 16-clause K4 Tseitin binary encodings, each exactly 208 bits in the *finite fixture grammar*: 8-bit magic, 8-bit clause count, then 16×3 literal records with 3-bit positive variable ID plus 1 sign bit. Charge parity gives 8 SAT and 8 UNSAT sources; all 128 one-clause deletions of odd-charge sources are SAT. Seven corrupted/malformed source encodings are rejected. All 16 full-source markers are byte-distinct; 64 single-bit corruptions of purported marker packets are rejected by exact validation.

For all eight odd-charge complete-source strings and K=1,2, independently enumerated every pair (immutable marker, counter). Source classification uses exhaustive 64-variable-assignment masks on 6 edge variables, not a general polynomial SAT solver. Each independent implementation passed **348,054** finite assertions.
