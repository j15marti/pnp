\section{Exact two-switch source construction}
The fixed $W_1$ has 15 variables, 20 distinct proper three-clauses, and
exactly two occurrences of each polarity per name. Let
\[
A=\{(6,0),(11,0)\},\quad B=\{(17,2),(9,2)\},
\]
where positions are zero-indexed clause/literal indexes. Define $H(a,b)$ by
negating both $A$ entries iff $a=0$, and both $B$ entries iff $b=0$.
Each pair involves opposite signs of a single variable and different clauses;
properness and signed quotas survive every switch. Exhausting all
$2^{15}$ assignments for each mode gives model counts
\[
(\#H(0,0),\#H(0,1),\#H(1,0),\#H(1,1))=(772,272,272,0).
\]
Little-endian assignment integers $616$ and $4742$ satisfy, respectively,
$H(0,0),H(0,1)$ and $H(1,0)$. For $m$ disjoint renamed copies, place all $2m$
$A$-controlled clauses, then all $16m$ fixed clauses, then all $2m$
$B$-controlled clauses. The resulting signed exact-$(2,2)$ CNF has
$V=15m$, $C=20m$ and
\[
\SAT(F_m(a,b))\iff\bigwedge_{i<m}\neg(a_i\land b_i).\tag{1}
\]
The formulas contain mixed-sign clauses, hence are not asserted to be
clause-monotone. The $15m$-bit witness obtained by concatenating mask $616$
when $a_i=0$ and mask $4742$ when $a_i=1$ works for every \emph{SAT}
input without reading Bob. This is an \emph{unchecked candidate printer},
not a sound SAT acceptor, and confers no universal crossing shortcut.

\section{The explicitly declared clause-token language}
For this finite-state execution, encode each literal as sign $+/-$ and a
positive binary identifier, separate literals by comma, terminate clauses
with semicolon. Each Alice module occupies
\texttt{\{clause6;clause11;\}}, each Bob module
\texttt{\{clause17;clause9;\}}, and all 16 fixed clauses of each module are
in the literal-original order. Prepend zone symbols \texttt{L}, \texttt{G},
\texttt{R} and append \texttt{E}. The finite alphabet and declaration are
part of the PROMISE. Its size $N_{\rm tag}=\Theta(m\log m)$; the literal
identifiers are actual binary IDs with $15i$ offsets and never free symbolic
names. The central fixed gap accounts for $\Theta(N_{\rm tag})$ input cells.
The tags are \emph{not} part of the previously published fixed-width raw
binary CNF source; a format conversion needs a separate charged proof.

\begin{theorem}[One planted marker and an observable unary position;
\textbf{PROVED/EXACT, tagged promise}]
Fix one read-only two-way sequential input head and one two-way read/write
work head initially scanning a blank, unmarked, bi-infinite work tape. There
is one fixed deterministic finite-state program that on every legitimate
clause-token input computes (1), halts, and obeys
\[
 D=1,\quad S_k\le m+1,\quad R\le4m,
 \quad T_k=O(mN_{\rm tag}),\quad L_k=1.\tag{2}
\]
The only actual work-symbol change is writing a permanent origin mark in
work cell zero; all subsequent work-tape cells, including visited blanks,
remain unchanged.
\end{theorem}
\begin{proof}
Write the marker once. At the left zone delimiter, let the work-head's
nonnegative distance from that marker equal loop index $i$. In Alice's
section, bypass $i$ complete \texttt{\{clause6;clause11;\}} modules while
moving the work head LEFT once for each skipped module. When the work head
reads the marker, inspect the first sign after \texttt{\{} in the target
module; this is $a_i$. If the $G$ delimiter is reached with the work head
at the marker, all $m$ modules have been checked and accept. Otherwise
traverse left to zone $L$, moving the work head RIGHT on each preceding
module's opening brace, restoring displacement $i$. Traverse forward to
zone $R$ while holding $a_i$ as one finite-state bit. Bypass $i$ right modules
with the same decrement; in the selected right module scan two literal commas
and read the third sign of clause 17, exactly $b_i$. Reject iff both signs
encode 1. Restore the right-module displacement by traversing backward,
then return to $L$ and increment the work head by one. At all times only the
current input character, current work symbol and one of finitely many
control states influence a transition. No branch or scan uses Python's
integer loop index from the executable's \emph{external trace counters}.
All head movements are one cell, $S_k\le m+1$, and each iteration traverses
$O(N_{\rm tag})$ characters with at most four direction reversals; each
round has one output bit only on termination. Every possible SAT/UNSAT
pair is handled by this single total promise decider.
\end{proof}

\begin{lemma}[No write and no initially visible origin;
\textbf{KNOWN THEOREM application}]
On an initially unmarked two-way blank tape with no endmarker or head-position
oracle, if $D=0$ on all inputs, all work reads are blank and work-head positions
cannot affect the transition function. Projecting the machine's finite
control and single input head gives a 2DFA; its accepted language is regular
\cite{rabin,sh}. In contrast the unbounded canonical separated-DISJ
promise has $2^m$ distinguishable Alice prefixes for every $m$, by a
Bob-suffix complement crossing. Therefore a uniform $D=0$ machine in that
model cannot recognize it, \emph{regardless of its nominal visited blank
space}. If a readable origin marker is supplied initially for free, it is
an additional initial resource $I_0=1$; the program of the Theorem can then
use $D=0$, but the governance theorem's $D$-only occupancy count must replace
$D$ by $D+I_0$ to remain valid. This is already the principal result of
report 175, independently reconfirmed here.
\end{lemma}

\section{Full fixed-$k$ to ONE-tape simulation, including output}
Take the actual fixed-$k$ machine of the Theorem, including its finite-state
source parser. At every transition it inspects one input cell and one work
cell and moves each head by at most one position. Build a deterministic
\emph{single} read/write tape containing $N_{\rm tag}$ product-alphabet
cells with immutable source, simulated work symbol, input-head marker and
work-head marker tracks; compile the initial bare input into these tracks in
an initial forward-and-reverse pass. For each source transition, make four
complete source-length sweeps: forward to gather the two scanned symbols,
backward to write a changed work symbol and propagate left-moving head
markers, forward to propagate right-moving head markers, and backward to
restore the physical single head to cell zero. The finite control carries
only the scanned symbols, source transition state, head movements and
pending local marker shifts; there is \emph{no} random-access lookup.
Finally move to fresh cell $N_{\rm tag}$, write the one output bit and halt.
For this machine the declared construction gives
\[
 T_1=4N_{\rm tag}(T_k-1)+3N_{\rm tag}+1,
 \qquad P_1=N_{\rm tag}+1,\tag{3}
\]
up to fixed finite-control boundary-transition conventions. The $T_k-1$
counts exclude the one source output-only transition. Explicit input
normalization, head steps, rereads, overwritten product symbols and the
virtual output are included, not later added twice to the already charged
transition count. This verifies the conservative model bridge
\[
 T_1=O(T_k(N+S_k+\log(T_k+2))),\quad
 P_1=O(N+S_k+\log(T_k+2)),\tag{4}
\]
with $N=N_{\rm tag}$ and $k=1$ work tape. Equations (3)--(4) are
\emph{upper simulations}, not lower bounds on other algorithms.
Hennie--Stearns' $O(T\log T)$ theorem targets \emph{two} tapes, so is not
substituted for (3)\cite{hs}.

\section{Model boundaries, status and coordination}
The predecessor 176 supplied a native $O(\log N)$ indexed recognizer for
the actual original fixed-width source and a different constant-number-of-
markers unary-head \emph{macro compiler}. This run does not prove one-marker
exact fixed-width validation: its extra zone/group delimiters change the
input grammar, and its finite-state control assumes a promised, honestly
formed source. Syntactically malformed inputs may be accepted, by design.
The signed exact-$(2,2)$ class here is not the clause-monotone class.

The HEADMOVE-1 $H(S+1)=\Omega(N^2/\log N)$ and
$(R+1)(S+1)=\Omega(N/\log N)$ faces are necessary under their declared
one-source-head machine and matched same-run proof. Our construction's
$T_k=\Theta(mN)$, $S=\Theta(m)$, $R=\Theta(m)$ does not approach their
low-space boundary but remains legal. Bounds for the separately augmented
$J$-jump model are not imported into the native heads. Likewise none of
these results is a lower bound for the FLMV indexed-input random-access
machine: arbitrary probes require paid addresses but no physical gap
traversal. Under $P=NP$, an ordinary-SAT decider's exponent $K$ remains
unknown; neither a favorable near-boundary seed nor a shorter ordinary SAT
child follows. The fixed $O(N\log^3N)$-gate \emph{witness verifier} and its
inverse accessors from reports 166--177 are not uniform deterministic
\emph{decision} circuits for every $N$-bit SAT input. The pinned twice-
regularized output still has a linear physical-size floor. General certificate
coverage, all-input ARC contraction, ARC-EDGE-90 and $P\ne NP$ remain \OPEN.
