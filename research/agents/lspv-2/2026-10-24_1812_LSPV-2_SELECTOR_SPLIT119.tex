\section{Three falsifiable routes}

(M2) Can the shared-source relation nevertheless be compiled economically? Yes: a linear-record affine/2-CNF representation, but deciding the joint relation is NP-complete. \section{Exact all-input linear-record reduction}
Fix a proper three-literal CNF $F=\bigwedge_{i=1}^m(\ell_{i1}\vee\ell_{i2}\vee\ell_{i3})$ on $n$ source variables. Create one Boolean selector $y_{ij}$ per literal occurrence. Define $A_F=\bigwedge_i(y_{i1}\oplus y_{i2}\oplus y_{i3}=1)$. Define a 2-CNF $B_F$ containing each of the three pairwise clauses $(\neg y_{ij}\vee\neg y_{ik})$ for $j<k$, and one implication $y_{ij}\Rightarrow \ell_{ij}$ for every occurrence. These implications are ordinary binary clauses between its selector and the corresponding source variable or its negation.
\begin{theorem}[PROVED/EXACT for this construction]
$F$ is SAT if and only if $A_F\wedge B_F$ is SAT. The compiler produces $m$ independent ternary affine equations, $6m$ binary clauses and $3m+n$ Boolean variables, in linear source-record time plus bit-addressing and output costs. For every $F$, both $A_F$ and $B_F$ are independently SAT.
\end{theorem}
\begin{proof}
For any model of $F$, choose precisely one true literal occurrence per clause, set that selector to one and the others to zero, keeping the original source assignment. Parity, at-most-one, and the selected implication all hold. Conversely parity requires an odd selected count and the three binary clauses restrict it to at most one, so every clause has exactly one \emph{selected} occurrence, whose original source literal is forced true. Therefore $F$ is true in the same original assignment. For $A_F$ alone set the first selector of every clause to one and the others zero. For $B_F$ alone set every selector to zero. Both constructions work for every $F$, including UNSAT inputs.
\end{proof}
This is compatible with the known NP-hardness of 2-SUB-SAT (Arvind--Guruswami), but the specific all-input source-preserving encoding and its charges are explicitly supplied here. An original clause may have several true literals: an exactly-one \emph{witness selector} is not an exactly-one original truth constraint.
\section{Smaller atomic children do not supply the parent answer}
Separate each affine row and each binary clause into an individual named constraint. There are $7m$ atomic children, all individually satisfiable, each of ordinary record length $O(\log(n+m))$. Thus every atomic child has size at most $N^\lambda$ for any fixed $\lambda>0$ for sufficiently large source length $N$. Even calling total polytime algorithms on the full $A_F$ and $B_F$ supplies only two YES bits. Therefore an assembler receiving only these bits and fixed input-independent metadata cannot distinguish a SAT parent from an UNSAT parent. The source-coherent compatibility join is a separate computation, and its exact decision is NP-complete since it is equivalent to the original 3-SAT source under a polynomial reduction. This does \textbf{not} constrain an assembler allowed to read the original source, use alternate representations or directly decide SAT; all such operations remain legal and must be charged.
\section{Exact signed $(2,2)$ refinement}
For strict signed exact-$(2,2)$, source variables can be removed from the output: replace implications by clauses $(\neg y_u\vee\neg y_v)$ for every complementary occurrence pair of the same original variable. Each variable's two positive and two negative occurrences create one $K_{2,2}$ with four edges. As $4n=3m$, conflict edges number $4n=3m$. Adding three within-clause triangle edges per clause gives $6m$ binary clauses on $3m=4n$ selectors, all degree four. The same selector equivalence applies, without making source literals exactly-one TRUE.
