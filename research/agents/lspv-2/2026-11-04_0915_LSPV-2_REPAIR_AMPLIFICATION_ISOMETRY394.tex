\paragraph{PROVED/EXACT, restricted.}
Let $F=\bigwedge_{i=1}^{m}C_i$ be an arbitrary explicit signed CNF with distinct nonempty non-tautological clauses. Introduce $r\ge1$ fresh variables $z_1,\dots,z_r$ and define
\[
P_r(F)=\bigwedge_i\left(C_i\land\bigwedge_{j=1}^{r}
[(C_i\lor z_j)\land(C_i\lor\neg z_j)]\right).
\]
This contains $(2r+1)m$ pairwise distinct original source clauses, $(2r+1)L+2rm$ signed literal occurrences, and $n+r$ variables, where $L$ is the original number of literal occurrences.
\begin{theorem}
For every assignment $a$ to the old variables and every assignment $z$ to the new variables, the number of false padded clauses is exactly $(r+1)$ times the number of false source clauses. In particular,
\[
\delta(P_r(F))=d_{\mathrm{sign}}(P_r(F))=(r+1)\delta(F)=(r+1)d_{\mathrm{sign}}(F).
\]
For every UNSAT $F$, the globally minimum paid shared-DAG \emph{ordinary Resolution} inference count satisfies
\[
W_{\mathrm{Res}}(P_r(F))=W_{\mathrm{Res}}(F).
\]
If $F$ is a minimally UNSAT $m$-source formula already satisfying $W_{R_{\mathrm{mix341}}}(F)=m-1$ for the fixed unit-cost, at-most-binary-premise, source-authenticated conservative combined calculus of LSPV-2/341, then
\[
W_{R_{\mathrm{mix341}}}(P_r(F))=m-1.
\]
\end{theorem}
\begin{proof}
If an original $C_i$ is true, every member of its block is true. If false, its base copy is false and exactly one of each positive/negative pair is false. Hence the number of false sources multiplies by $r+1$ for every assignment, independent of guard choice. Minimum clause deletion distance is the minimum number of false clauses over assignments. Minimum individual polarity-flip distance is equal because each nonempty false clause needs and admits one flipped literal occurrence. The base clauses remain present, giving $W_{\mathrm{Res}}(P_r(F))\le W_{\mathrm{Res}}(F)$. Conversely restrict all guards to zero in any Resolution DAG. The true negative-guard clauses vanish, while base and positive-guard clauses restrict to the original sources. The standard restriction normalization drops or replaces every derivation node by at most one Resolution node with the empty sink retained. This gives the reverse inequality.

For the mixed corollary, partition padded sources into $m$ blocks. Every valid refutation must use at least one source from each block, since deleting any entire block leaves a satisfiable formula and all rules are conservative. If $q$ paid nodes have at most two premises and at least $m$ source leaves, the connected undirected ancestry graph has at least $m+q-1$ edges and at most $2q$, forcing $q\ge m-1$. The old $m-1$-node derivation remains available. No restriction-closure assumption for every mixed rule is made.
\end{proof}
\paragraph{Explicit controls and distinction.}
The odd XOR triangle on six original clauses has a five-node ordinary Resolution refutation, and all six clauses are indispensable. Thus for every $r\ge1$ its padded version has \emph{exactly} five paid mixed-calculus nodes but source deletion and sign-edit distances $r+1$. For connected simple bridgeless cubic odd-Tseitin sources, the original LSPV-2/341 exact mixed optimum $4h-1$ is preserved for all $r$, while the repair distance is $r+1$. Haken's ordinary Resolution lower bound for unary pigeonhole formulas also survives this padding \emph{only in ordinary Resolution}, by restriction closure. Cook and Buss demonstrate stronger proof-system shortcuts. No unrestricted algorithm hardness follows.
\paragraph{Verification and next gap.}
Two independent Python and JavaScript checkers tested all 256 two-variable subset CNFs (95 SAT, 161 UNSAT), $r=1,2,3$, including all padded assignments in the latter implementation; 8,032 and 31,237 assertions passed. Triangle controls used $r=1,2,3,4$, and five malformed payloads were rejected by JavaScript. The construction is uniform polynomial bit-time when $r$ is polynomial in source encoding length; construction, verification, proof encoding, access, output and peak space are not free.
