\begin{theorem}[Strict-target suffix peel]

\[
 \operatorname{SAT}(F)\iff\operatorname{SAT}(H).
\]
Every child SAT witness reconstructs a complete parent witness using a checked $Y_6$ witness. Every original-source resolution refutation of $H$ lifts without changing any parent clause index.
\end{theorem}
\begin{proof}
The suffix contains all four signed occurrences of its six variables and is disjoint from the prefix. The source occurrence quotas therefore force the prefix to retain two occurrences of each sign of every remaining variable. Source distinctness, monotone clauses and nonduplication are inherited. Since the suffix is SAT, the disjoint conjunction is SAT exactly when the prefix is. Each child UNSAT proof premise is an unchanged indexed parent clause. A rejected suffix recognition attempt returns FALLBACK and is never an UNSAT certificate.
\end{proof}
This is classical disjoint-factor reasoning and does not solve connected cases. \section{Event-sourced XOR identity with declared physical semantics}
The executable experiment uses one fixed blank $M$-cell work tape to materialize the child and one fixed blank binary input-index tape of width $\lceil\log_2(N+1)\rceil$. For each source query address $q$, it writes the one-bits of the positive address $q+1$ into the blank index tape, performs a single indexed source jump that clears the entire index tape, and charges head moves. It then writes each output bit once on the work tape, including zero-value writes. The read-only original input is excluded from writable-data XOR. Head positions remain a separately charged machine-state channel. Every event is recorded; a run-length head move represents a declared number of zero-data-XOR native movements.

\begin{theorem}[Exact identity for the specified compiler]
For actual output child bit string $B_H$ and chronologically indexed source bit requests $q_1,\ldots,q_R$, with full fixed-location physical states compared after every event,
\[
 \boxed{D_{\rm phys}=\operatorname{wt}(B_H)+2\sum_{r=1}^{R}\operatorname{wt}(\mathrm{bin}(q_r+1)),
 \quad d_{\rm endpoint}=\operatorname{wt}(B_H).}
\]
The counted primitive time includes $M$ output writes, $R$ indexed jumps, all the index-bit creations and all head moves. Thus the complete initially blank-index trace obeys $D_{\rm phys}\le 2T_{\rm declared}$ for this single local bit-write port model.
\end{theorem}
\begin{proof}
Every programmed one-bit is a physical $0\to1$ transition; its indexed jump erases that same bit in one possibly bulk-changing event. Between queries the index tape is blank. Every output work cell starts blank and is written once, so only output one-bits change physical content. Add these disjoint cell-edit events. Output-zero writes, unchanged writes, reads and head motion contribute time but no additional content XOR.
\end{proof}
The general index-recharge inequality belongs to earlier LSPV-1 ARC-INDEX-RECHARGE283. The new work here is exact original-target child construction with complete indexed source reads and independent per-event replay. No new universal physical lower bound is claimed.
