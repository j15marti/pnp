\section{One-variable raw-child theorem}
\begin{theorem}[Restricted exact counts]
Let $F$ be a proper signed exact-$(2,2)$ width-three CNF on $n$ occurring
variables, with each occurring twice positively and twice negatively.
Then $m=4n/3$ source clauses and $4n$ source literal occurrences. For any
variable $x$ and either value $b$, define the \emph{raw} restriction
$F[x=b]$ solely by deleting satisfied clauses and deleting falsified
pivot literals, without resolution, propagation, compression or renaming.
Its counts are
\[
m'=m-2,\quad \ell'=4n-8,\quad
\#\{\mathrm{untouched\ ternary\ clauses}\}=m-4,\quad
\#\{\mathrm{new\ binary\ clauses}\}=2.
\]
With per-literal width $w+1$, $w=\lceil\log_2(n+1)\rceil$, constant
clause-boundary control bits and an $O(\log n)$ header, ordinary explicit
serialization has
\[
N=4n(w+1)+O(n),\qquad N'=(4n-8)(w+1)+O(n),
\qquad \lim_{n\to\infty}N'/N=1.
\]
Consequently this \emph{uncompressed one-variable cofactor} cannot
satisfy $N'\le N^\lambda$ for any fixed $\lambda<1$ on
unbounded proper strict-$(2,2)$ inputs.
\end{theorem}
\begin{proof}
The pivot occurs in four different source clauses. Exactly two
occurrences have a satisfied sign, so exactly two clauses of width
three disappear, removing six literals. The remaining two occurrences
are falsified and deleted, each leaving a binary clause. Thus precisely
eight literal occurrences disappear and $m-4$ clauses are untouched.
Both parent and child use the same source identifier width and ordinary
per-clause length tags. The $O(n)$ boundary overhead is smaller than
$n\log n$ and the change in clause count is constant, proving the ratio.
Since $N^{\lambda-1}\to0$ for every fixed $\lambda<1$, the last claim
follows. This proof does NOT apply to any semantically compressed child.
\end{proof}

\begin{theorem}[Shallow raw restriction]
Fixing $k$ original variables touches at most $4k$ source clauses, leaving
at least $m-4k$ untouched ternary clauses and
$\max(0,4n-12k)$ untouched literals. For $k=o(n)$ the raw child
retains $1-o(1)$ of its original literal count.
\end{theorem}
\begin{proof}
Union bound the four source clauses incident on each fixed variable;
every untouched clause contributes three literals. The assertion
concerns only raw retained clauses, not semantic lower bounds.
\end{proof}

\section{Total exact controller and verification}
On each residual, the deterministic program first performs full unit
propagation and source-semantic restriction. It then attempts disjoint
component splitting, 2SAT SCC, Horn, dual-Horn, recognition of
\emph{complete} parity truth-table CNF blocks with Gaussian elimination,
min-fill graph discovery followed by bounded-width exact bucket
elimination with backpointers, and enumeration/verification of every
cofactor of a size-one strong backdoor to these base classes. Every failed
attempt is billed. The fallback branches on both Boolean values of an
occurring variable and records confirmed UNSAT residuals in a memo table.
Each SAT witness is extended and rechecked against every original clause.

\paragraph{Correctness.} Each recognized tractable solver is exact by
its standard invariant. The XOR recognizer demands \emph{all} forbidden
parity assignments rather than an incomplete subset. Exact variable
elimination projects each local constraint existentially; recovered
backpointers are checked. A purported strong backdoor is accepted only
after every cofactor is class-verified. Otherwise exhaustive binary
branching decreases the number of unassigned variables. Induction
gives termination and correctness on all CNF inputs. This is standard
algorithm composition and proves \emph{no} polynomial worst-case bound.
The Python program stores source-derived original occurrence targets
$S_j,U_j$ and inversions, complement endpoints, and source-parent
resolution cubes as \emph{adversarial diagnostics}, not as answer oracles.

for every policy path.
