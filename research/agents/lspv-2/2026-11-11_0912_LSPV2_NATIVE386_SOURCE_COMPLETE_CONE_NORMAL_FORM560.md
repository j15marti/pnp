## Theorem 560.1: source-complete native /386 terminal-cone normal form (PROVED/RESTRICTED)

For **every** parsed packet C genuinely accepted by the complete archived /386 checker, let S be its full set of SOURCE record indices, and A the least parent-closed set of records containing the terminal empty clause. Put K=S union A. Let D be the least set of gate-owner definitions containing (i) each owner of a DEF view among K, (ii) each gate output appearing in a literal of a K record, and (iii) all upstream gate owners feeding the definitions already in D.

Construct C* by retaining the K records and D owner definitions in their original orders, changing every retained parent record index to the corresponding new index, preserving every signed SOURCE occurrence with source tag, each clause/resolution pivot and gate owner identity, and recomputing six native summary counters.

**Acceptance and charging theorem:**

$$
\mathrm{Accept}_{386}(C)\Longrightarrow \mathrm{Accept}_{386}(C^*)
$$

and

$$
W_{386}(C^*)=N_{\mathrm{RES}}(C^*)+|D|
\le N_{\mathrm{RES}}(C)+|\mathrm{gate\_defs}(C)|=W_{386}(C).
$$

For each fixed original in-band /386 source for which accepted proofs exist, the minimum distinct-paid-node work over all accepted proofs **equals** the minimum over such normalized accepted proofs. This is a normalization equivalence for optimum proof choice in the restricted original checker, not a global SAT resource bound.

**Proof:** The archived checker validates every original source row against its graph-generated signed source set and requires exact coverage of the full original set. Retaining S preserves these requirements even for source rows outside the terminal ancestor cone. Parent ancestry closure keeps both antecedent record clauses of every retained RES. An order-preserving subsequence and explicit index remap preserves chronological parent legality, pivot signs and exact resolvents. Every retained DEF view has its original paid gate owner; every auxiliary literal used by a retained record is declared by a retained owner. Recursive owner input closure and retaining the original declaration order preserve freshness, uniqueness, acyclic conservative AND2 definitions and signed facet validity. The unchanged final record remains the empty clause. After recomputing the six checked summary fields, the same original acceptance conditions hold. The original /386 language has no branch, discharge or context operation to preserve. Every removed paid RES or unique gate owner decreases W by one; facets remain zero extra paid. Hence W cannot increase. The normalized family is a subset of the original accepted family and every accepted proof has a no-more-expensive normalized witness, giving the restricted equality of minimum work. QED.
