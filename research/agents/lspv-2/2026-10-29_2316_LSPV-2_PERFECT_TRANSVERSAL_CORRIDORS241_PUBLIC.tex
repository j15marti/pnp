\section{Syntactic strong 2-CNF backdoor and exact lower bound}
A set $B$ of original variables is a \emph{syntactic 2-CNF backdoor} when fixing any assignment to $B$ makes each source clause either disappear or retain at most two original literals, without semantic deletions, auxiliary gates or preprocessing. Its per-pin residual is exactly solvable by 2-SAT implication-graph SCC.
\begin{theorem}
For every proper signed exact-$(2+,2-)$ 3-CNF with $n$ variables, $m=4n/3$ original clauses, and four source occurrences per variable, any such $B$ hits every source clause and satisfies
\[
 |B|\ge m/4=n/3.
\]
Equality holds if and only if every source clause contains exactly one member of $B$. Each syntactic flip corridor fixes $\ge n/3$ variables and contains at most $2^{2n/3}$ assignments; therefore an architecture that insists on explicitly covering \emph{every full assignment} by such corridors needs at least $2^{n/3}$ corridors, even if the hitting set changes between corridors. Given $B$, enumerating its $2^{|B|}$ pins and deciding each binary residual costs $O(2^{|B|}(N+n+m))$ indexed-RAM operations. Minimum-$B$ discovery and all failed paths are extra costs.
\end{theorem}
\begin{proof}
A ternary source clause disjoint from $B$ remains a ternary clause for every pin, so $B$ must hit all $m$ clauses. Each variable hits four clauses, giving $4|B|\ge m$. Equality forces the $4|B|=m$ selected occurrences to cover distinct source clauses, precisely once each. A corridor fixes at least $n/3$ source bits, so it has at most $2^{2n/3}$ complete assignments; counting a full-universe cover proves the restricted covering inequality. If $B$ hits all source clauses, source scanning leaves only 0-, 1- or 2-clauses; one implication SCC computation decides each residual. This covers every pin and is exact. \end{proof}
\begin{theorem}[complementary partition, not complementary SAT answers]
At equality $|B|=n/3$, each pin $\beta$ satisfies exactly $m/2$ original clauses by the unique pinned literal and leaves exactly $m/2$ binary source clauses. If $R(\beta)$ is the retained source-index set, then
\[
 R(\beta)\cap R(\bar\beta)=\varnothing,\quad
 R(\beta)\cup R(\bar\beta)=\{1,\ldots,m\},\quad
 |R(\beta)|=|R(\bar\beta)|=m/2.
\]
Nevertheless the residual SAT answers need not be equal.
\end{theorem}
\begin{proof}
Each selected variable has two positive and two negative occurrences, exactly two of which are true under any pin; clauses have one pinned literal each. Thus $2|B|=m/2$ clauses disappear. Complementing the pin swaps which unique pinned literal is true in every source clause, partitioning the original indices. No equality of binary-residual SAT labels follows; the finite counterexample below provides unequal labels. \end{proof}
