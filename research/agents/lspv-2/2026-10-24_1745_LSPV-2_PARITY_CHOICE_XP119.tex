\section{Source language}
On indexed Boolean sources $x_1,\ldots,x_n$ let
\[
B=\bigwedge_{(i,j)\in Q}(\neg x_i\vee\neg x_j),\qquad
L=\bigwedge_{a=1}^k\left(\bigoplus_{i\in R_a}x_i=b_a\right).
\]
Rows $R_a$ are explicit subsets; let $q=|Q|$ and $B_0=\sum_a|R_a|$. The parameter $k$, the number of XOR equations, is derived from the input independently of runtime. Each component is separately polynomial-time decidable: all-zero satisfies negative 2CNF and Gaussian elimination decides the affine equations. The combined source language is not arbitrary SAT, and is not strict signed exact-(2,2).

\begin{theorem}[Sparse-support theorem, PROVED/EXACT]
If $B\land L$ is satisfiable, some satisfying assignment has at most $k$ TRUE sources. Hence exact deterministic source-aware enumeration of at most
\[
C(n,k)=\sum_{j=0}^{\min(k,n)}\binom nj
\]
subsets decides this entire declared language. A streaming indexed-input bit implementation can be arranged with conservative
\[
T=O(C(n,k)\,N(k+1)\log N),\qquad
S=O((k+1)\log N)
\]
where $S$ counts live writable bits, not the read-only source. This is an XP bound, not FPT.
\end{theorem}
\begin{proof}
For each $x_i$ form its $k$-bit column $v_i$ of coefficients in the XOR equations. A satisfying TRUE set $S$ has $\bigoplus_{i\in S}v_i=b$. If $|S|>k$ the selected columns are dependent, so there is a nonempty $D\subseteq S$ with $\bigoplus_{i\in D}v_i=0$. Deleting $D$ preserves every affine equation and cannot violate any negative binary clause. Repeat to get an independent set of columns of size at most $k$. Exhaustive subset enumeration is therefore complete for both SAT and UNSAT; every candidate is replayed on original records. The streaming implementation stores at most $k$ indices and $k$ syndrome bits, rereads source fields, and charges all comparisons, controls and failed attempts.
\end{proof}

\begin{theorem}[Certified group-choice switch, PROVED/EXACT]
Suppose all $k$ rows are nonempty, disjoint, cover the sources, have right-hand side one, and every pair in the same row occurs as a negative incompatibility clause. A paid recognizer may switch to testing at most $\prod_a|R_a|$ one-source-per-row choices, rather than $C(n,k)$ subsets. Failed certification triggers the exact sparse policy; an unsuccessful individual choice never implies UNSAT.
\end{theorem}
\begin{proof}
Within-row binary clauses forbid two TRUE variables; parity one requires an odd number. Thus exactly one source is TRUE per row. Checking every product choice with all original cross clauses is sound and complete, with no truth-label oracle. Recognition can use source rereads rather than storing a full pair table, paying additional polynomial work.
\end{proof}

\end{theorem}
\begin{proof}
For a graph with nonempty color classes $V_1,\ldots,V_k$, introduce one bit $x_v$ per vertex. Add XOR parity-one on each color class. Put a negative binary clause on every same-color vertex pair, and on every nonadjacent cross-color pair. Parity and same-color clauses force exactly one vertex per class, while cross clauses force a clique. Conversely any multicolored clique gives a satisfying assignment. The rows have disjoint nonempty supports and rank $k$. Negative clauses accept all-zero; affine equations accept one arbitrary chosen vertex per color.
