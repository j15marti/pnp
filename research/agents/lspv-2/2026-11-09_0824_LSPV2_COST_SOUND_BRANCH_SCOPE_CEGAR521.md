## Exact declared transition systems
Fix R_branch_res521, a **separate calculus, NOT historical R_mix341**. Source: canonical ASCII `T3|n|m|signed-literals...\n`, with 1..3 distinct-variable literals per original clause, exact source IDs and an immutable binary input. A configuration is (original source F, available clause DAG nodes, active consistent signed-assumption context Γ for each node, paid-ID set D, accumulated logical cost). SOURCE(i) yields original clause i, context empty, cost zero. ASSUME(l) yields unit clause l under Γ={l}, cost one. RES on correctly oriented pivots x/-x adds (C∨D) with Γ equal to the compatible union of premise contexts, distinct paid node cost one; reject tautological output or inconsistent Γ. Reuse costs zero, but a node is accessible in a target context only if its Γ is justified there. A global learned clause has Γ empty; goal is the empty clause with Γ empty. Deduction/unit propagation is the unit-premise instance; learning is paid Resolution; branching is ASSUME; AND discharge of both branches is **not a native rule in this model**. Arbitrary unrestricted joins, weakening, AND3, LOCAL-CONVERT, extensions and algebra are not allowed in this fixed mini-calculus. Their omission precludes any claim about mixed R_mix341.

Define alpha0 erasing Γ but keeping clause identities and paid history. Its may-transition system includes every concrete projected step with **equal** cost, plus a zero-cost ghost join of incompatible branch facts. Thus for every concrete path π, a projected abstract path exists with w#(π#) ≤ w(π), and every concrete goal projects to abstract goal. This is cost-sound may overapproximation, so *abstract nonreachability* within B implies concrete nonreachability, but abstract reachability can be spurious. alpha1 retains Γ, source indices and paid history and rejects incompatible joins. The reported checker is a finite transition replayer, not a complete arbitrary-state reachability or exact native-rule checker.
