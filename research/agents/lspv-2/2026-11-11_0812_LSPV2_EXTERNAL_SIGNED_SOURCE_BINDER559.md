Consequently no assignment satisfies `F`. ## Counterexample 559.2: one identical native packet, two external sources

The authentic signed K4 guarded source `F` has seven variables, 17 original clauses, exactly 215 ASCII bytes including terminal LF, and is UNSAT. Define `F^-` by removing the first signed clause `[1,2,3,-7]`, leaving a 16-clause 204-byte external signed CNF. This source is **SAT**: original variables 1 through 7 have assignment `0000001`, which satisfies every retained signed clause. The independently executed exhaustive 128-assignment enumeration found a satisfying assignment after deleting **each one of the 17 clauses**, establishing deletion-minimal UNSAT for this finite source. This is *not* an asymptotic hardness theorem.
