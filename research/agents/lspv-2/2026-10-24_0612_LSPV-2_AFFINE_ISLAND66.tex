\section{Exact source language and backward circuit specification}
A proper signed exact-$(2,2)$ three-CNF has unique signed 3-literal clauses with three distinct original variable names and each original variable appearing exactly twice positively and twice negatively. Repetition of an \emph{unsigned support} with different signs is allowed; if a stricter language forbids identical unsigned supports, the result below has no application. There are $4n=3m$ signed occurrences. An explicit four-word clause record representation has word width $w=\lceil\log_2(64(n+m+1))\rceil$ and encoded length $N=(4m+2)w$ bits. The source evaluation circuit has two OR2 gates per clause and an AND2 tree; requiring output TRUE is equivalent to requiring each clause OR to output TRUE. Select one literal occurrence as a TRUE \emph{witness} for each clause, with no original variable required in opposing signs. A clause may have more than one TRUE literal; these choices do not impose exactly-one source truth. The selector exists if and only if the original formula is satisfiable. Evaluation-gate counts are not SAT-decider circuit lower bounds.

\begin{theorem}[Balanced support classification, PROVED/EXACT restricted]
Suppose four \emph{distinct signed} proper clauses use the same three original source variables $x,y,z$, each appearing twice positively and twice negatively among the four. Their conjunction is equivalent to one equation
\[
a_xx\oplus a_yy\oplus a_zz=b,\qquad
(a_x,a_y,a_z)\in\{110,101,011,111\}.
\]
Exactly eight four-clause sign sets meet these hypotheses: two for each of the four masks. In six of eight sets, only \emph{two} of the three variables occur in the affine equation. All eight are satisfiable.
\end{theorem}
\begin{proof}
Each three-literal clause excludes one of the eight assignments to $x,y,z$. The four distinct excluded triples $u_0,u_1,u_2,u_3\in\mathbb F_2^3$ have XOR zero, because for each variable exactly two forbidden tuples have value 0 and two have value 1. Translate by $u_0$ to obtain $\{0,v,w,v\oplus w\}$. Distinctness makes the nonzero vectors $v,w$ linearly independent, hence the excluded set is an affine two-flat with unique nonzero normal $a$. A weight-one normal would fix one forbidden bit, contradicting coordinate balance. Thus the weight of $a$ is two or three. The four excluded values satisfy $a\cdot u=c$; the four permitted values satisfy $a\cdot u=1\oplus c$. Conversely each nonzero mask of weight two or three and each right-hand side gives exactly such a four-clause set, yielding $4\cdot2=8$ possibilities. Choose a source variable with coefficient one and assign it to the required parity to construct a satisfying assignment.
\end{proof}

\begin{lemma}[Safe original-source isolation and deletion, PROVED/EXACT restricted]
Within a proper signed exact-$(2,2)$ formula $F$, each saturated quartet $Q$ is one complete source-incidence component. Then $F$ is SAT if and only if $F\setminus Q$ is SAT. All such components can be recognized and deleted in $O(N)$ addressed-word work and $O(n+m)$ simultaneously live logical words, including grouping, signed-count validation and output construction. An assignment of the remaining original source variables extends via an independent affine witness for every removed quartet.
\end{lemma}
\begin{proof}
Each of the three variable names exhausts its full quota of two positive and two negative occurrences in $Q$ and cannot appear in any other clause. Thus $Q$ is source-disjoint from the remainder. Theorem 66A supplies its independent satisfying assignment. Both implications follow from conjunction over disjoint source sets. A grouping index and incidence scan touch each occurrence constantly often on fixed-width signed clause records; all candidate and rejected groups are charged.
\end{proof}
The polynomial recognizer is \emph{not} a polynomial algorithm for the entire NP-complete signed exact-$(2,2)$ class. In strictly monotone formulas, a four-pattern support quartet cannot occur.
