\section{Source-authenticated exact Boolean factor algebra}
For an original clause $C_j$ and coherent pin $p$, a satisfied clause is omitted and an uncovered clause contributes a Boolean factor $f_j$ over the original unpinned variables of $C_j$. The mask stores each row in fixed ascending variable-ID bit order, with immutable source clause index $j$. A completely falsified original clause yields the zero constant factor. No independent occurrence-bit assignment is permitted.

For free variable $x$, let $\mathcal B_x$ be all active factors whose scope contains $x$, and let $U_x=\bigcup_{f\in\mathcal B_x}\operatorname{scope}(f)$. Replace $\mathcal B_x$ by the exact factor on $U_x\setminus\{x\}$
\[
 g_x(y)=\bigvee_{b\in\{0,1\}}\bigwedge_{f\in\mathcal B_x}f(y,x=b).
\]
When $\mathcal B_x=\varnothing$, the replacement is the true constant. The original clauses and all source factor definitions remain immutable and available for proof replay.

\begin{lemma}[Exact source-preserving decision and proof replay]\label{lem:exact}
For every valid canonical original $F$, every coherent original-variable pin $p$ and every variable elimination order, repeated Boolean bucket elimination preserves whether $F\wedge p$ is satisfiable. A completed empty-factor output decides SAT or UNSAT exactly. Each table entry can be checked by enumerating its two predecessor-bit values and source-labeled active factor rows. If the final answer is SAT, reverse replay recovers an optional full assignment, checked against every original clause; if UNSAT, the complete table replay and constant-zero result certify the original-source refutation. Exact decision alone requires no recovered assignment and no lossless pin key.
\end{lemma}
\begin{proof}
Write the conjunction of active factors as $(\bigwedge_{f\in\mathcal B_x}f)\wedge H$, where $H$ is independent of $x$. Then $\exists x[(\bigwedge\mathcal B_x)\wedge H] = (\exists x\bigwedge\mathcal B_x)\wedge H =g_x\wedge H$. Induct through the variable order. Each $g_x$ is checked cellwise, including both $x$ choices and all incident factors, so a zero final row excludes all original completions. Reverse choices for satisfied table rows reconstruct the witness, which is independently source-clause checked. This is ordinary exact variable elimination, not a new SAT-complexity theorem.
\end{proof}

\section{Incremental paid selector with exact global tie agreement}
Define the current key for each free variable $y$ as
\[
 k(y)=\left|\bigcup_{f:y\in\operatorname{scope}(f)}\operatorname{scope}(f)\right|.
\]
The deterministic global selector chooses the least pair $(k(y),y)$ by scanning all active factors for every free variable at every step. The incremental selector stores incident factor IDs and a version-tagged min-heap. At a selected variable $x$ it removes $\mathcal B_x$, inserts $g_x$, and recomputes keys only for $y\in U_x\setminus\{x\}$; stale heap entries are discarded and \emph{charged}.

\begin{theorem}[Local scope-key invalidation]\label{thm:local}
For every finite active Boolean-factor collection, immediately after eliminating $x$, $k(y)$ is unchanged for every surviving variable $y\notin U_x$. Consequently the versioned incremental heap returns exactly the same elimination order, tie-breaking and resulting factor masks as a fresh global min-key rescan at every step. This holds on both SAT and UNSAT inputs, with no target-grammar or bounded-width assumption on the intermediate factors.
\end{theorem}
\begin{proof}
Every deleted factor includes $x$ and thus has all its variables in $U_x$. The inserted factor has scope $U_x\setminus\{x\}$. For $y\notin U_x$, no incident factor is deleted or inserted, so its incident-factor set and union-of-scopes key are unchanged. For every affected $y$, recomputation yields the exact current key. At each heap extraction the version test discards any obsolete key and the unique current entry at lexicographic minimum $(k(y),y)$ matches the global selector. Induct over elimination steps to obtain the same order and Boolean factors. This is a classical local-dependency/incremental-priority mechanism, not a new worst-case complexity lower bound.
\end{proof}

The active table for a width-$w$ elimination has at most $2^{w-1}$ result rows; each requires at most two bucket-conjunction evaluations, with all factor-table reads, row writes, address arithmetic, queue operations and source/proof provenance explicitly charged. The routine aborts with UNRESOLVED on encountering width exceeding the chosen cap; an independent exact fallback is necessary for all-input totality. The free-variable count decreases at each elimination, proving finiteness, not polynomial total work.
