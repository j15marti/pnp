\section{CONSTRUCTION OR PROOF ATTEMPT}
Let $P=\{x\in\mathbb R^n:A_jx\ge b_j,\ 1\le j\le m\}$ be a rational source with explicit Boolean box rows. For a supplied permutation $g$, let $A_j^g$ relocate coefficient $i$ to position $g(i)$. Require for every source row $j$ a list of exact nonnegative rational multipliers satisfying
\[
\sum_{\ell}\lambda^{j,g}_{\ell}A_{\ell}=A_j^g,\quad
\sum_{\ell}\lambda^{j,g}_{\ell}b_{\ell}\ge b_j.\tag{1}
\]
\begin{theorem}[Sound certified semantic permutation and coverage]
If all identities (1) check, $g(P)=P$. A finite acyclic binary branch-coverage DAG that maps both extended contexts to their child representatives only via such permutations and terminates in exact original-source-plus-context Farkas contradictions is a sound Boolean UNSAT certificate. An ordinary deterministic verifier uses time and space polynomial in the completely materialized input-plus-certificate bit length $N+B$.
\end{theorem}
\begin{proof}
Each transformed inequality follows over $P$, so $g^{-1}P\subseteq P$. Since a coordinate permutation has finite order, iterating inclusions back to the identity gives equality, hence $gP=P$. If a Boolean model existed, traverse each branch using its current pivot bit, applying the certified permutation each time. It remains a source model satisfying the stored context, eventually reaching a leaf with checked nonnegative Farkas sum $0\ge\epsilon>0$, a contradiction. Verifying permutations, rational multipliers, contexts, DAG acyclicity, leaf sums and explicit bit encodings is polynomial in $N+B$; this does not assert polynomial $B$ for arbitrary sources.
\end{proof}
For every odd $n=2k+1\ge3$, define
\[
P_n^\sharp=\left\{0\le x_i\le1,\quad 2\sum_i x_i\ge n,\quad -2\sum_i x_i\ge-n,\quad x_i+(i+1)\sum_{j\ne i}x_j\ge0\ (1\le i\le n)\right\}.\tag{2}
\]
\begin{theorem}[Syntactic asymmetry with polynomial semantic global cover]
The only coordinate permutation preserving the literal multiset of source rows of (2) is the identity, but every permutation preserves its real feasible region. Its Boolean solutions are empty. Any fresh-coordinate, no-cut, tree-only LP-conflict refutation requires exactly $2\binom{2k+1}{k}$ leaves in the optimum, independent of adaptive variable order. Nevertheless a Farkas-certified semantic-orbit DAG exists with $(k+1)(k+3)$ states, $2(k+1)^2$ edges and $O(n^4\log(n+2))$ explicit proof bits, generated and checked in polynomial time on the same ordinary machine.
\end{theorem}
\begin{proof}
Each added inequality is primitive, has coefficient $1$ uniquely at position $i$ and coefficient $i+1$ elsewhere; all $i+1$ differ. Therefore a literal row automorphism must fix every $i$. Each added inequality is a nonnegative sum of lower box bounds, so the real region remains the symmetric cube slice $\sum x_i=n/2$. The slice has no Boolean point. A partial context with $r$ fixed ones and $z$ fixed zeros is real-feasible iff $r,z\le k$: for the positive direction fill every free coordinate with $(n/2-r)/(n-r-z)$. The exact first-passage count of leaves is twice $\sum_{j=0}^k\binom{k+j}{j}=2\binom{2k+1}{k}$, independent of adaptive pivot choice. Canonical states are $1^r0^z*^{n-r-z}$, with internal $0\le r,z\le k$ and terminal $r=k+1$ or $z=k+1$. The first-free-coordinate zero branch is canonical; the one branch cycles the new one past the block of zeros. Each cycle is certified by (1): permuted box rows are box rows, the sum rows are invariant, and each transformed added inequality follows from a sum of lower box rows with coefficients at most $n+1$. Terminals combine the appropriate sum source row with twice each fixed-value or remaining box inequality, deriving $0\ge 2(k+1)-n=1$. Count states and edges as stated. Every edge contains at most $O(n^2)$ small Farkas multipliers, giving $O(n^4\log n)$ fully materialized bits.
\end{proof}
\begin{proposition}[Boolean symmetry does not imply LP symmetry]
For $Q=\{(x,y)\in[0,1]^2:2x+2y\ge1,\ x+2y\ge1\}$, the Boolean model set is exactly $\{01,10,11\}$ and is invariant under coordinate swap. But $(0,1/2)\in Q$ while its swap $(1/2,0)\notin Q$. Therefore no Farkas-certified real-polyhedron swap exists. Dimension two is minimal for a nontrivial coordinate permutation.
\end{proposition}
The same odd-knapsack source has a five-line ordinary syntactic CP refutation including two input axioms: divide both $\pm2\sum x_i\ge\pm(2k+1)$ by two and add their rounded consequences to obtain $0\ge1$. Thus the exponential LP tree is not a general CP or SAT time lower bound.
