**ITERATE:** Naive enumeration over all edges touching k defective vertices costs up to 2^(3k), useful only for logarithmic k. On recognizing that G[D] is a forest, use shared child-to-parent tables indexed by one parent-edge bit and a c-bit vector, where c is the number of connected intact components. The per-child XOR convolution must **deduplicate intermediate syndromes** after every join; without deduplication a three-child root can generate up to 2^(3c) intermediate traces. Python was revised to perform that deduplication, then completely rerun.

## Exact source and hardness model

Let G=(V,E) be a connected simple cubic graph with H=|V|, 3H/2 distinct edge variables x_e, and **four consecutive proper signed ternary original clauses per vertex**. Every clause in the vertex packet has exactly its three incident original edge variables. An original-edge variable belongs to exactly two distinct packets; the graph is reconstructed from *original source supports*, checked simple/connected/cubic, rather than accepted as a separate unverifiable promise. The usual parity packet forbids all four triples of one parity, representing XOR_{e incident v} x_e=b_v. An exceptional packet is any four signed proper 3-clauses on that same local triple (duplicates allowed); any packet coinciding with a full parity codebook is treated as ordinary.

Let D subset V be the packets that are not ordinary; assume induced G[D] is a forest. Let C_1,...,C_c be the components of G[V\D] (possibly c=0), with ordinary vertex charges b_v. For every component define q_i=XOR_{v in C_i} b_v. For an assignment a to all original edges incident to D, define sigma_i(a)=XOR of a_e over E(D,C_i).

**Theorem 475.1 (PROVED/RESTRICTED):** The original 3-CNF is SAT iff there exists an assignment a to E(D,V) such that (i) all four actual original clauses at every defective vertex are true and (ii) sigma_i(a)=q_i simultaneously for **every** intact component C_i. Moreover, on the forest-defect grammar, this predicate and a full original-variable SAT witness (if it exists) are computable with at most O((N+H 4^c) polylog(N+H2^c+2)) standard bit operations and O((N+H2^c) polylog(N+H2^c+2)) writable bits, for bit-encoded input length N=Theta(H log H), conditional on the declared ordinary bit-RAM representation. These are generous safe upper bounds, not native FLMV exponents. In particular **c=O(log N) with fixed constant** gives polynomial time, regardless of the number k=|D| of exceptional packets. The c=1 family is near-linear up to polylogs even for unbounded k.

**Proof of characterization:** XOR all retained vertex equations within C_i. Internal edges cancel twice, leaving exactly sigma_i(a)=q_i, proving necessity. Conversely, fix any a meeting these conditions. Remove its boundary contributions from each retained vertex charge. Their XOR over C_i is zero, so the incidence matrix of connected C_i over GF(2), with rank |C_i|-1, has an internal-edge solution. Set nontree edges to 0 and solve tree edges bottom-up; the root holds by parity. Combine all C_i extensions with a and the exceptional clauses. Thus every source clause is satisfied. No semantic SAT oracle is used.

**Proof of algorithm and counts:** Root each tree in G[D]. For each defective vertex u, store a Boolean table keyed by (parent-edge value in {0,1}, syndrome vector in GF(2)^c), with a backpointer to one legal set of subtree choices; root has a sentinel parent value. Enumerate at most eight actual local edge triples, check all four local clauses, and XOR the boundary vector contribution with the cached child messages. All child obligations are **AND** requirements; alternatives among local triples are **OR** choices. A child DP entry is reused only with the identical shared original-edge value and a justified syndrome; no incompatible branch conclusion is leaked. At every child join, deduplicate by resulting syndrome, so a table and each partial join hold O(2^c) states and each join costs O(4^c). Since a cubic vertex has <=3 children, total O(H4^c) basic table transitions plus graph source authentication and witness reconstruction; retained tables/backpointers use O(H2^c) entries. Across different defect trees, combine root vectors by the same XOR convolution. Recover a satisfying assignment with stored backpointers and spanning-forest parity propagation. A table is an algorithmic shared computation DAG, **not** an authenticated native R_mix341 proof DAG; R_mix341 rule costs, reference bits and assumption discharge remain unproved.

**Family/theorem/control:** On a suitable growing 3-regular edge-expander with odd vertex charge, 4H proper original signed 3-clauses, 3H/2 variables, N=Theta(H log H), Ben-Sasson/Wigderson Cor.4.5 gives 2^Omega(H) size against **ordinary DAG Resolution**. This does not apply to arbitrary SAT algorithms, this source-aware parity DP, extension proofs or full R_mix341. The exact original 3-CNF encoding is direct, not via an unproved hardness-preserving conversion. The algebraic shortcut is an upper-bound control, not evidence of all-machine hardness.
