\section{One-time projection and independent component decomposition}
Write $C$ for the union of free original variables on the authenticated cycles and $W$ for all remaining free originals. Every edge selection on an odd cycle fixes \emph{all} its cycle-variable values uniquely, by setting the selected edge's endpoints literal-true and alternating all other binary edges. Incompatible choices on overlapping cycle vertices must be rejected. Exterior uncovered original clauses and the source-certified signed-spill preferences yield one choice-independent system
\[
 A_Cz+A_Wy=b\pmod2.
\]
Take an exact elimination of $A_W$, preserving row-XOR provenance back to original source clause IDs and conditional preference IDs. If $L A_W=0$ spans the left nullspace, then for a completed compatible cycle assignment $z$, solvability is equivalent to $L A_Cz=Lb$. Eliminate redundant rows to obtain $q$ independent projected equations $Hz=d$ on $C$. Any authenticated zero-coefficient equation with right-hand side one is already an UNSAT certificate. Put $r=\operatorname{rank}(A_W)$.

Construct a finite \emph{cycle-factor interaction graph}: its vertices are authenticated cycle IDs. Join cycles whenever they share a free original variable or one projected equation contains variables from both cycles. This graph, including its edges and all failed candidate checks, is computed and charged. Let $G_1,\ldots,G_s$ be its connected components. In $G_i$ let $\nu_i$ be its cycle count, $q_i$ the number of independent projected equations supported there, and $\ell_j$ the number of edges in cycle $j$. For each component $i$ let $B_i$ be its number of compatible, projected-equation-satisfying cycle-choice tuples.

\begin{theorem}[Overlap-safe component syndrome factorization]
For every valid canonical original $F$, coherent $p$ without falsified source clause, and authenticated source-edge-disjoint odd-cycle packing with $\delta=0$, the original-source number of satisfying extensions is
\[
 \boxed{\#\mathrm{SAT}(F\mid p)=2^{|W|-r}\prod_{i=1}^s B_i.}
\]
For a factor $G_i$ with pairwise vertex-disjoint cycles, the exact integer $B_i$ and one compatible choice can be calculated by a \(\F^{q_i}\)-syndrome dynamic program requiring at most
\[
 O\!\left(\sum_{j\in G_i}\ell_j2^{q_i}\,\mathrm{poly}(N)\right)
\]
charged bit operations and $O(2^{q_i}\mathrm{poly}(N))$ writable bits, in addition to shared polynomial source validation, cycle discovery, matrix elimination, certificate storage, and source-witness checking. For a component with overlapping cycle vertices, exhaustive compatible-template enumeration is sound, with charged work $O(\prod_{j\in G_i}\ell_j\,\mathrm{poly}(N))$. On the greedy triangle policy $\ell_j=3$, all these operations are polynomial whenever $\max_i q_i=O(\log N)$ and the number of cycles in each overlapping-vertex component is $O(\log N)$. This is a \emph{parameterized terminal subclass}, not an all-input polynomial bound.
\end{theorem}
\begin{proof}
The inherited saturation theorem partitions all satisfying original-source completions by a unique selected original source edge per authenticated odd cycle, even when some cycles share variable vertices. Once a cycle-choice tuple is fixed compatibly, the original noncycle system requires $A_Wy=b+A_Cz$. Elimination supplies exactly $2^{|W|-r}$ solutions when $Hz=d$, and zero otherwise. A row of $H$ has all its cycle-variable support in one interaction component by construction. No variable is shared across distinct components. Therefore choices in distinct components are independent and the number of globally compatible choice vectors is exactly $\prod_iB_i$.

For a component of vertex-disjoint cycles, let $z_{j,e}$ be the complete Boolean template of cycle $j$ selected at edge $e$. Its contribution to the $q_i$ projected parity equations is the syndrome $\sigma_{j,e}=H_i z_{j,e}\in\F^{q_i}$. With $D_0(0)=1$ and $D_0(s)=0$ for $s\ne0$, update by
\[
 D_{t+1}(s)=\sum_{e\in\Gamma_{t+1}} D_t(s\oplus\sigma_{t+1,e}).
\]
Induction counts exactly the number of partial cycle selections of syndrome $s$; hence $B_i=D_{\nu_i}(d_i)$. Store one predecessor per reached syndrome to reconstruct a cycle-choice witness; Gaussian back substitution supplies the free $W$ values, then all original clauses are checked. If cycles overlap, their template contributions cannot be XOR-summed independently because a common variable could be assigned inconsistently, or effectively counted twice. Instead, enumerate choices within that connected overlap component, reject contradictory assignments, and check every original-source-derived parity equation. Each accepted choice contributes once by the inherited disjoint-union theorem. Returning UNSAT requires either a source conservation certificate, a source-row-XOR $0=1$ certificate, or exhaustively replayable zero-reachable-target DP tables for at least one factor. Thus neither parity-only SAT inference nor overlapping-template shortcuts are admitted.\qed
\end{proof}
