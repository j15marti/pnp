\section*{Exactly fixed interface and calculus}
Let \(E\) be the injective signed-CNF binary encoding of LSPV-2/399, with magic \(110101\), Elias-gamma \(n\) and \(m+1\), a gamma length \(k+1\) per clause, and for each occurrence a polarity bit followed by a fixed-width nonzero variable index of width \(\lfloor\log_2 n\rfloor+1\). The parser accepts \(n\ge1\), properly bounded indices, exact lengths and no trailing bits; malformed inputs receive a separate \({\rm MALFORMED}\) outcome. For any binary string \(x=x_1\cdots x_N\), define
\[
T(x)=x_1x_1x_1\,x_2x_2x_2\cdots x_Nx_Nx_N.
\]
The new canonical source encoding is \(E_3(F)=T(E(F))\). Its strict decoder requires every triple to agree, then parses the decoded source with the original parser; any failure is \({\rm MALFORMED}\). No unit-cost representation-conversion inference is added to \(R_{\mathrm{mix341}}\). Every proof is still a source-authenticated proof of the decoded \(F\) under the unchanged RES, AND3, XOR, LOCAL-CONVERT, DEF grammar of LSPV-2/341, with nonnegative unit cost per paid DAG inference and at most two premise nodes.

Write \(L_E\subseteq\{0,1\}^*\) for the \emph{total} SAT language, with malformed and UNSAT strings not in \(L_E\), and \(L_{E_3}=\{T(x):x\in L_E\}\). Let \(P_E(x)\) be the set of positions where toggling one bit preserves valid CNF syntax and switches its SAT/UNSAT label.

\begin{theorem}[Uniform coding firewall, all strings and all valid CNFs]
For all binary strings \(x,x'\), \(T\) is injective, \(|T(x)|=3|x|\), and \(d_H(T(x),T(x'))=3d_H(x,x')\) when \(|x|=|x'|\). The two total SAT languages \(L_E,L_{E_3}\), including their malformed-input convention, are interreducible by \emph{fixed uniform linear-time} many-one reductions: \(x\mapsto T(x)\) in one direction and strict decode or a fixed valid UNSAT source in the other.

For every valid encoded CNF \(x=E(F)\), \emph{every} one-bit mutation of \(T(x)\) is malformed. Thus the number of valid, opposite-SAT-label singleton neighbors of \(T(x)\) is zero, whether \(F\) is SAT or UNSAT. Under the ordinary two-label total SAT language, the single-bit sensitivity at \(T(x)\) is \(0\) if \(F\) is UNSAT and \(3|x|\) if \(F\) is SAT. Under the \emph{three-label} total classification SAT/UNSAT/MALFORMED, it is \(3|x|\) for either valid label.

For every deterministic uniform correct SAT decider on the \emph{promise of valid} \(E_3\)-codes, its execution on \(T(x)\) must read at least one bit of each of the \(|P_E(x)|\) pairwise-disjoint triples indexed by \(P_E(x)\). With randomized two-sided error at most \(\epsilon<1/2\) on each valid code, its expected number of distinct input-bit queries is at least \((1-2\epsilon)|P_E(x)|\). For a deterministic \emph{total three-label} correct decider, every valid \(T(x)\) requires reading all \(3|x|\) bits; for a total randomized three-label decider with error at most \(\epsilon\), the expected number is at least \((1-2\epsilon)3|x|\).
\end{theorem}
\begin{proof}
Tripling each bit proves injectivity, exact length and Hamming-distance multiplication. For the reverse many-one reduction, scan triples and output decoded \(x\) if all triples agree; otherwise output \(E((u)\land(\neg u))\). If the triples agree but \(x\) is malformed under \(E\), original \(L_E\) still rejects it. This gives linear-time, total, fixed-code reductions both ways. Flipping one position of a triple of \(000\) or \(111\) leaves a nonconstant triple and is therefore malformed; this proves the singleton statements. For every \(i\in P_E(x)\), the input \(T(x^{(i)})\) is valid and opposite-labelled, and differs from \(T(x)\) in precisely the three positions of triple \(i\). A correct deterministic adaptive query transcript must touch one of those positions or it is identical on two opposite labels. Distinct \(i\) give disjoint blocks. For randomized deciders couple the random coins on the two inputs: before reading any bit in the block the transcripts agree, so the block-hit probability is at least the output-distribution total-variation lower bound \(1-2\epsilon\). Sum over blocks. In the three-label case, each of the \(3|x|\) single-bit flips is a valid adversarial \emph{input string} with a different, malformed output label. The same transcript coupling applies to each singleton.
\end{proof}

\begin{theorem}[Exact worst-case minimum-cost rescaling for the unchanged fixed \(R\)]
Fix any sound, complete, effective proof calculus \(R\) on \emph{decoded authentic source CNFs}, in particular the preselected \(R_{\mathrm{mix341}}\), with its original inference-node weights. Let
\[
\overline W_{R,E}(N)=\max_{\substack{F\ {\rm UNSAT}\\|E(F)|\le N}} W_R(F),\qquad \max\emptyset=0.
\]
Then for every integer \(M\ge0\),
\[
\boxed{\overline W_{R,E_3}(M)=\overline W_{R,E}(\lfloor M/3\rfloor).}
\]
Moreover, for each \(F\), the globally minimum logical DAG \(W_R(F)\) is \emph{exactly the same object and cost} whether the external input is \(E(F)\) or \(E_3(F)\). This equality concerns logical cost after source decoding, not physical decoder execution or a new implicit rule.
\end{theorem}
\begin{proof}
The correspondence between valid source encodings is a bijection, \(|E_3(F)|=3|E(F)|\), and neither the authenticated source \(F\) nor any legal \(R\)-proof changes after decoding. Thus the sets whose maxima are taken are identical under \(N=\lfloor M/3\rfloor\).
\end{proof}

These are \textbf{COMPUTATIONAL} controls, not a finite minimum-\(R\) optimizer or an asymptotic hardness proof.

Producing \(E_3(F)\) explicitly requires \(3N\) output bits, \(\Theta(N)\) bit operations and \(\Theta(N)\) materialized output space; streaming can reduce writable working space but cannot remove output work or input validation.
