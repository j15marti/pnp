\section{CONSTRUCTION/PROOF ATTEMPT}
\begin{theorem}[Exact two-NAE clause identity]
For all Boolean $a,b,c$,
\[
a\vee b\vee c\quad\Longleftrightarrow\quad
\exists u\,[\operatorname{NAE}(a,b,u)\wedge
\operatorname{NAE}(\neg u,c,0)].
\]
\end{theorem}
\begin{proof}
The eight rows were checked directly.  More structurally, if $a=b=0$, the
first clause forces $u=1$, and the second becomes
$\operatorname{NAE}(0,c,0)$, equivalent to $c=1$.  If $(a,b)$ is mixed,
the first clause accepts both $u$ values and one can choose $u=0$; the second
then contains a true literal $\neg u$.  If $a=b=1$, the first clause forces
$u=0$, and the second is satisfied.  These cases are exhaustive.
\end{proof}

\begin{corollary}[Formula-level front end]
Let $F=\bigwedge_{i=1}^m(a_i\vee b_i\vee c_i)$ be proper.  Replacing clause
$i$ by the two displayed NAE clauses with a fresh $u_i$ preserves
satisfiability.  Every target model projects to a source model, and every
source model extends by choosing each $u_i$ independently from its nonempty
row-witness set.  With one shared variable $z$ fixed externally to false, the
front end has
\[
n+m+1\text{ variables},\qquad 2m\text{ clauses},
\]
each $u_i$ occurs twice, $z$ occurs $m$ times, and all clauses are proper.
\end{corollary}

\begin{theorem}[Self-dual no-unary-pin theorem]
Let $G(p,y)$ be any conjunction of signed NAE clauses, with no constants.
If $G$ is satisfiable with $p=0$, it is satisfiable with $p=1$, and conversely.
Hence
\[
\{p:\exists y\,G(p,y)\}\in\{\varnothing,\{0,1\}\};
\]
no satisfiable pure signed-NAE gadget existentially forces $p$ to false or true.
\end{theorem}
\begin{proof}
Complement every variable.  Every positive or negative literal value is
complemented.  NAE is invariant when all three inputs are complemented, so
every clause, hence $G$, remains satisfied while $p$ flips.
\end{proof}

\begin{corollary}[Pin-or-degree audit]
The displayed reduction has three sharply separated implementations.
\begin{enumerate}
\item A primitive constant $0$ makes the two-clause front end exact, but the
constant is part of the target language rather than a constructed NAE pin.
\item One externally fixed shared false variable gives the exact counts above
but has occurrence $m$, violating any uniform maximum-eight claim for $m>8$.
\item Replacing it by independent satisfiable pure signed-NAE local pins is
impossible by the theorem.
\end{enumerate}
Therefore the claimed $n+22m,36m$, maximum-eight construction must expose an
asymmetric non-NAE/FTNC pin resource, a relative reference plus a separately
fixed gauge, or a different target semantics.  The inaccessible construction
is not declared false; its missing asymmetric interface is now exact.
\end{corollary}

\paragraph{Boundary relation.}
For blocks $F_L(B,X)$ and $F_R(B,Y)$ with disjoint $X,Y$, define
$R_L=\{b:\exists X F_L(b,X)\}$ and similarly $R_R$.  Then
\[
\operatorname{SAT}(F_L\wedge F_R)\iff R_L\cap R_R\ne\varnothing.
\]
This retains TETRABOUNDARY68's exact gluing theorem.  A materialized Boolean
relation needs 64 bits at width six and 256 bits at width eight.  Moving from
six to eight therefore multiplies this direct table/branch bound by four; it
does not by itself contract child encoded length.
