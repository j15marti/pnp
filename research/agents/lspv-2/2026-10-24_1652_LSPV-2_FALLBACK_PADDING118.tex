\section{A theorem about full-length fallback}
Let $\mathcal C$ be a polynomial-time decidable set of ordinary encoded SAT instances, containing SAT and/or UNSAT inputs, with infinitely many valid sources outside $\mathcal C$ at unbounded input lengths. Define the \emph{black-box} hybrid $H[A]$: recognize $\mathcal C$ using source-visible polynomial rules, then correctly decide its members using certified polynomial specialists; otherwise invoke $A$ on the unchanged ordinary $N$-bit parent and wait for that answer. Code surgery on $A$ is not among the operations of this specified compiler.

\begin{theorem}[Conditional fallback padding firewall; PROVED/EXACT within model]
Assume $P=NP$ and let $D$ be any deterministic uniform exact SAT decider with time $N^{d+o(1)}$ and work space $N^{s+o(1)}$. For each sufficiently large fixed integer $K>d$, there exists a total uniform exact decider $A_K$ with joint bounds
\[
T_{A_K}(N)\le N^{K+o(1)},\qquad
S_{A_K}(N)\le N^{\max\{s,0\}+o(1)}
\]
such that for infinitely many growing input lengths,
\[
\max_{|F|=N} T_{H[A_K]}(F)\ge N^K.
\]
Thus no worst-case exponent improvement $K-\varepsilon$ for fixed $\varepsilon>0$ can be claimed uniformly for this specific black-box recognizer-plus-full-parent-fallback compiler.
\end{theorem}
\begin{proof}
Construct $A_K$ to execute at least $\lceil N^K\rceil$ charged deterministic counter steps on $O(K\log N)$ writable bits, then execute $D$ and return $D(F)$. Fixed $K$ permits a uniform machine, with a polylogarithmic factor for ordinary binary counter implementation and work/index space bounded by that of $D$ plus logarithmic overhead. On each source outside $\mathcal C$, $H[A_K]$ waits for an unmodified invocation of $A_K$ on that same full-length input. Along an unbounded sequence of such lengths the mandatory guest call costs $\Omega(N^K)$; hence a strictly smaller polynomial upper exponent fails. All preprocessing only adds work, and the original source remains read-only.
\end{proof}
\paragraph{Quantifier guard.}
This does not refute existential closure of $E$. Under the assumption $P=NP$ the faster machine $D$ itself exists, and an existential route need not invoke $A_K$. The firewall also does not cover code introspection, a verified different all-input algorithm, source-coherent power-size SAT children, or a compiler without parent-scale fallback. Its purpose is to reject a specific attempted proof of ARC-EDGE-90, not to impose a lower bound on arbitrary algorithms.

\section{Both-label infinite controls}
For each $q\ge0$ introduce $x_1,x_2,x_3$ and pairs $(a_j,b_j)$, $1\le j\le q$. Define
\[
G_q=(x_1\vee x_2\vee x_3)\land
(\neg x_1\vee\neg x_2\vee\neg x_3)
\land\bigwedge_{j=1}^q
[(x_1\vee a_j\vee b_j)\land
(\neg x_1\vee\neg a_j\vee\neg b_j)].
\]
Define $H_q$ by replacing the first two clauses by the eight possible sign patterns on $x_1,x_2,x_3$, retaining the $q$ attached clause pairs. Both source-incidence graphs are connected, every clause is proper ternary, and $n=3+2q$. The assignment $(x_1,x_2,x_3)=(1,1,0)$ and $(a_j,b_j)=(0,0)$ satisfies $G_q$. The eight clauses of $H_q$ exclude all eight core assignments, so $H_q$ is UNSAT. Both families fall outside the declared syntactic 2-SAT, Horn, dual-Horn and four-clauses-per-XOR-triple recognizers, at growing $N$. These are \emph{not} signed exact-$(2,2)$ hard families and retain an easy constant UNSAT core.
