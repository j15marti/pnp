\section*{Exact theorem in one declared TSC evaluator}
Let $k\ge1$ and $m=2^k$. Define the data-selection function $f_m(x,a)=x_a$. Construct a complete binary-tree tri-state router with two controlled request buffers and a response join at every internal node, one controlled leaf buffer per data bit, and $k$ XOR gates producing address-bit complements. On every input $x\in\{0,1\}^m$ and $a\in[m]$, exactly one request/response path is defined; the joins are legal and the root output equals $x_a$.

The static number of XOR/buffer/join gates is
\[
G(m)=3(m-1)+m+k=4m-3+k.
\]
Productive Z-to-bit assignments count $k$ XOR complements, $k$ selected requests, one leaf data output and $k$ joins:
\[
P(m)=3k+1.
\]
In the precisely declared \emph{eager notify} implementation of Heath--Kolesnikov--Ostrovsky, Figure~1, input-wire initialization notifies every subscriber, and each newly defined wire likewise notifies its subscribers. XOR gates receive $2k$ notification attempts; internal request buffers receive $2(m-1)+2k$; leaf buffers receive $m+1$; joins receive $k$. Thus
\[
\boxed{A(m)=3m+5k-1\ge m.}
\]
For $m=256$, $(G,P,A)=(1029,25,807)$. This is a lower bound on one \emph{specified eager evaluator}, not on arbitrary algorithms: direct native indexed lookup computes $f_m$ in $O(k)$ address operations and one source read without materializing the TSC.
\section*{Source model and FLMV firewall}
The primary source, \emph{Tri-State Circuits: A Circuit Model that Captures RAM}, ECCC TR23-095 (2023), uses unit-cost \emph{word RAM} of word length $\Theta(\log T)$. Its deterministic TSC bound in Theorem~3 is $O(T\log^4 T)$ static gates, whereas $O(T\log^3 T\log\log T)$ is obtained by a randomized/oblivious construction. Neither supplies a deterministic low-space SAT algorithm on the \emph{indexed-tape} model of Fortnow--Lipton--van Melkebeek--Viglas, JACM 2005.
Sources: \url{https://eccc.weizmann.ac.il/report/2023/095/download/}, \url{https://doi.org/10.1145/1101821.1101822}.
