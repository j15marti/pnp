\paragraph{Obstacles and primary source.}
The first obstacle is specification: vMS does not uniquely fix the bit-level code needed for one author-canonical Boolean product-span object. The second is rank: after a legal code is declared, full SAME\_REALIZATION rank must be computed rather than inferred from source length, field degree, locality, or list decodability. Shaltiel--Umans Lemma 4.16 converts a q-ary extractor using a binary list-decodable code
\[
C':\{0,1\}^{\log q}\to\{0,1\}^{N},
\]
applying one common code coordinate to each q-ary output symbol. This confirms that the binary code itself is a construction parameter relevant to product span.

\paragraph{PROVED/EXACT: arbitrary binary-code slice theorem.}
Fix one declared legal code \(c:\mathbb F_q\to\mathbb F_2^N\) and legal q-ary orbit tuples
\[
a(v)=(a_1(v),\ldots,a_m(v)).
\]
On \(D=V\times[N]\), define
\[
g_i(v,z)=c(a_i(v))_z,
\qquad
M=1+m+\binom m2.
\]
For each legal v define the \(N\times M\) matrix
\[
B_v=
\left[
\mathbf 1\;\middle|\;
c(a_1(v))\;\middle|\;\cdots\;\middle|\;c(a_m(v))
\;\middle|\;
c(a_i(v))\star c(a_j(v))\ (i<j)
\right],
\]
where \(\star\) is coordinatewise multiplication. Then
\[
\boxed{
\rho(H)=
\dim_{\mathbb F_2}\operatorname{span}\{1,g_i,g_i g_j\}
=
\operatorname{rank}_{\mathbb F_2}
\begin{bmatrix}
B_{v_1}\\
B_{v_2}\\
\vdots
\end{bmatrix}.
}
\]
Proof: on the fiber \(\{v\}\times[N]\), the columns for \(1,g_i,g_i g_j\) restrict respectively to \(\mathbf1,c(a_i(v)),c(a_i(v))\star c(a_j(v))\). Concatenating fibers is exactly the global evaluation matrix.

Hence
\[
\rho(H)\ge \operatorname{rank}B_v
\]
for every legal v. One slice of rank M proves \(\rho(H)=M\) and \(K_2(H)=\{0\}\), retiring quadratic annihilation for that declared realization. If stacked rank is \(r_2<M\), its common kernel is exactly the global quadratic-relation space; Singleton then yields a nonzero relation with at most \(r_2+1\) ANF features, \(O(r_2\log m)\) monomial-list bits, and \(O(r_2)\) direct evaluation gates. Acquisition and normalization remain separate charges.

\paragraph{PROVED/EXACT: coordinate-permutation robustness.}
If \(c'(a)_z=c(a)_{\pi(z)}\) for one fixed permutation \(\pi\) of codeword coordinates, every \(B'_v\) is a row permutation of \(B_v\). Therefore
\[
\boxed{\rho_{c'}(H)=\rho_c(H).}
\]
Thus encoder ambiguity is harmless under fixed codeword-coordinate permutation, matching monomial invariance of Schur-square dimension over \(\mathbb F_2\). Arbitrary nonlinear message recoding or arbitrary invertible coordinate mixing is not covered because it need not preserve componentwise multiplication.

\paragraph{Relation to STACK1.}
STACK1 was exact for a declared Hadamard realization. The theorem above removes the Hadamard restriction and is exact for every fixed legal binary code used in the SU conversion. The remaining task is to identify or explicitly declare c and compute the stacked matrices \(B_v\).
