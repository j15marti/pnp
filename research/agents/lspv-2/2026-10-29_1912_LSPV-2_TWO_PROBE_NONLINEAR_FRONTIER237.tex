A deterministic arbitrary-nonlinear preparer stores an exact \emph{fixed-length} summary of $b$ source bits before learning a subsequent arbitrary parity mask. \item[] \textbf{M3: two-block algebraic compression.} Two groups each containing all nonzero $m$-bit labels yield one charged source probe per group and a compact affine summary. \textbf{PROVED/EXACT} constructively; exhaustive controls at $b=2,6$ and complete query-mask controls for sampled $b=14$ sources.
\item[] \textbf{M4: unrestricted source/encoding transfer.} An exact bound on stored reusable parity summaries automatically restricts a direct SAT decider seeing both source and continuation or one using unrestricted source access. \textbf{FALSIFIED/RETIRED as an inference} by the explicit joint parity scan and original-source-retention controls.
\end{description}

\section{Declared two-stage model and quantifiers}
For every integer $b\ge1$, an adversary chooses a \emph{source} $a\in\F^b$ and, \emph{after source preparation}, a query mask $w\in\F^b$. The canonical unary-CNF source is $A_a(X)=\bigwedge_{i=1}^b(x_i=a_i)$; a future Boolean context is the parity predicate $B_{w,t}(X)=[w\cdot X=t]$. The decision is
\begin{equation}\label{eq:embed}
\operatorname{SAT}(A_a\wedge B_{w,t})\iff w\cdot a=t.
\end{equation}
The source $A_a$ is physically retained as read-only input, with $N=\Theta(b\log(b+1))$ bits under indexed fixed-width variable-name encoding. A deterministic preparer may perform arbitrarily expensive nonlinear computation but must persist \emph{exactly} $L$ source-dependent summary bits $\sigma(a)\in\F^L$ before $w$ is known; public source length/layout is not source-dependent advice. A deterministic continuation knows $w$, $\sigma(a)$ and the public encoding and may read at most $Q$ individual indexed source data bits $a_i$, adaptively based on prior reads. It must return $w\cdot a$ for \emph{every} $a,w$. All source-index computations, scanning of $w$, summary accesses, preparations, cache creation, and writes are separately charged as total time and space. Source-probe count $Q$ alone is not total time.

A fixed-length summary can always be zero-padded, so the theorem also covers deterministic preparations that use at most $L$ bits in a fixed $L$-bit slot. The proof does \emph{not} assert exact optimality for unrestricted, non-prefix, variable-length self-delimiting descriptions. If variable length $\le L$ is allowed with no prefix condition, up to $2^{L+1}-1$ messages exist, and only the weakened count in Remark~\ref{rem:varlength} follows directly. This is a deliberate distinction from the previous $Q=1$ theorem.

\section{Unrestricted nonlinear and adaptive lower bound}
\begin{lemma}[general exact degree-volume bound]\label{lem:general}
For every $b\ge1$ and $0\le Q\le b$, any fixed-length $L$-bit deterministic summary protocol with exact answers to every parity query and at most $Q$ subsequent raw source-bit probes, allowing arbitrary nonlinear preparation and adaptive continuation, must satisfy
\begin{equation}\label{eq:sphere}
\boxed{2^L V(b,Q)\ge2^b,\qquad V(b,Q):=\sum_{j=0}^Q\binom bj.}
\end{equation}
Equivalently, $L\ge b-\lfloor\log_2 V(b,Q)\rfloor$.
\end{lemma}
\begin{proof}
For each summary $s\in\F^L$ let $S_s=\{a:\sigma(a)=s\}$. Fix a query $w$. With $(s,w)$ held constant, the decoder is a binary decision tree of depth at most $Q$ in the raw variables $z_i=(-1)^{a_i}$. Its terminal output $(-1)^{w\cdot a}$ on $S_s$ is the restriction of a real multilinear polynomial of degree at most $Q$: at a node querying coordinate $i$, the two child polynomials combine as $(1+z_i)p_+/2+(1-z_i)p_-/2$. The induction also covers repeated coordinates and adaptive paths. The restricted Fourier character $\chi_w(a)=(-1)^{w\cdot a}$ consequently belongs to the span of the $V(b,Q)$ monomials $\chi_T(a)=\prod_{i\in T}z_i$ with $|T|\le Q$, restricted to $S_s$.

But the $2^b$ characters $\{\chi_w\}_{w\in\F^b}$ span \emph{all} real functions on $S_s$: for every $a_0\in S_s$, the point indicator on the full cube is $2^{-b}\sum_w\chi_w(a_0)\chi_w(a)$, which restricts to the coordinate delta function on $S_s$. Thus $|S_s|=\dim(\mathbb R^{S_s})\le V(b,Q)$. There are at most $2^L$ summary fibers and $\sum_s|S_s|=2^b$. Summing the fiber bound proves~\eqref{eq:sphere}. The argument never assumes a linear sketch, an affine fiber, or nonadaptive probe choices.
\end{proof}

\begin{proposition}[variable-length firewall]\label{rem:varlength}
If unrestricted summary strings have length at most $L$, but need not be prefix-free, the same proof yields
\[
(2^{L+1}-1)V(b,Q)\ge2^b,
\quad L\ge\left\lceil\log_2\!\left(1+\frac{2^b}{V(b,Q)}\right)\right\rceil-1.
\]
A prefix-free code with maximum length $L$ has at most $2^L$ codewords, so Lemma~\ref{lem:general} holds unchanged for it. The present theorem does not prove an exact variable-length, non-prefix $Q=2$ frontier.
\end{proposition}

\section{Tight two-probe infinite family}
\begin{theorem}[exact fixed-length nonlinear two-probe frontier]\label{th:tight}
For each integer $m\ge1$, let $b=2(2^m-1)$ and let the source, arbitrary parity query, preparation, and indexed bit-probe model be as above. The minimum fixed summary length that guarantees every query is answerable using at most \emph{two} raw source-bit probes is exactly
\begin{equation}\label{eq:exact}
\boxed{L_2\bigl(2(2^m-1)\bigr)=2(2^m-1)-2m.}
\end{equation}
This holds against all nonlinear, computationally unbounded deterministic preparers and all nonlinear adaptive continuation trees. A polynomial-time \emph{uniform} linear preparer and decoder attain the bound, using at most one read in each of two disjoint raw-source groups.
\end{theorem}
\begin{proof}
\emph{Lower bound.} Put $b=2^{m+1}-2$. Directly,
\[
 V(b,2)=1+b+\binom b2=1+\frac{b(b+1)}2
 =2^{2m+1}-3\cdot2^m+2.
\]
For $m\ge1$,
\[
2^{2m}\le V(b,2)<2^{2m+1},
\]
since $V-2^{2m}=(2^m-1)(2^m-2)\ge0$. Therefore $\lfloor\log_2 V(b,2)\rfloor=2m$. Lemma~\ref{lem:general} implies $L\ge b-2m$ without assuming a linear summary.

\emph{Upper bound.} Partition the $b$ source coordinates into two groups $g\in\{0,1\}$, each indexed by every nonzero label $z\in\F^m\setminus\{0\}$. In each group the $m$ positions labeled by standard basis vectors $e_j$ are left \emph{unwritten}; at every other label $z$, store the summary bit
\[
 s_{g,z}:=a_{g,z}\oplus\bigoplus_{j:z_j=1}a_{g,e_j}.
\]
There are exactly $2((2^m-1)-m)=b-2m$ stored bits. After receiving any query mask $w$, compute the two public labels $u_g=\bigoplus_{z:w_{g,z}=1}z$ and the stored parity $K=\bigoplus_{g,z:\,w_{g,z}=1,\,z\notin\{e_j\}}s_{g,z}$. Elementary cancellation gives
\[
 w\cdot a =K\oplus\bigoplus_{g:u_g\ne0}
 \left(a_{g,u_g}\oplus \mathbf1[u_g\notin\{e_j\}]s_{g,u_g}\right).
\]
Since each $u_g$ is either zero or one of the genuine original source labels, the decoder reads at most \emph{one} raw coordinate in each group, hence at most two. Both read addresses are computed before either source read and therefore require no hidden adaptive search. All choices are uniform public XOR/index operations. The preprocessing scans all source signs once, temporarily retains $2m$ basis values, and writes only $b-2m$ persistent bits. The query scans $w$, accesses its charged summary bits, computes its two labels and reads the two charged original bits. This proves the upper bound and equality.
\end{proof}

\begin{corollary}[exact discrete first three Pareto coordinates]
For $b_m=2(2^m-1)$, the optimal fixed lengths for at most zero, one, and two raw probes are exactly $b_m$, $b_m-m$, and $b_m-2m$, respectively. In particular each additional probe reduces the minimum storage by exactly $m$ bits at these realizable points.
\end{corollary}
\begin{proof}
The zero-probe bound is source injectivity. The one-probe exact theorem from NONLINEAR-ONE-PROBE236 gives $L_1(b)=b-\lfloor\log_2(b+1)\rfloor$; since $b_m+1=2^{m+1}-1$, its logarithm floor is $m$. Theorem~\ref{th:tight} gives two probes.
\end{proof}

\section{Charged construction, storage, continuation and communication}
Native model $C$ is a deterministic indexed \emph{bit-RAM} with $O(\log N)$-bit addresses, immutable canonical source $A_a$ of length $N=\Theta(b\log(b+1))$, and a separately supplied future mask/query encoding. The summary layout and machine program are uniform in $m$; no source-dependent metadata besides the $L$ persistent bits is free. The measured $Q$ coordinate counts only individual post-preparation raw source-data bit probes. All summary reads, mask scans, address arithmetic, verification, method-selection and output are charged in the time ledger.

A concrete upper ledger for $M$ future queries is
\[
P=O(N+bm),\qquad L=b-2m,
\qquad T_{\rm total}=O(N+bm+M(N+bm)),
\qquad Q_{\rm source,total}\le2M.
\]
Peak writable memory on the natural bit-RAM implementation is $L+O(m+\log N)$ bits for the summary, temporary basis/target labels, counters and sign scratch. Immutable original source $N$, query input and output channel are reported separately, not erased. Summary writes total $L$ plus $O(bm)$ temporary arithmetic changes in preparation; query decoding incurs $O(bm)$ bounded-bit register changes and reads per mask. The precise hardware bit-flip count is machine-implementation dependent and was not experimentally measured. The two source addresses are known before probing, so one batched source-fetch communication round is possible if the machine supports two ports; otherwise two serial fetches suffice. The summary is sent/stored before the future query. There is no failed-strategy search in this uniform construction.

For a fixed two-tape TM with read-only source/query tape and one writable summary tape, explicit sequential scans replace indexed bit probes: charge all intervening input symbols and head movements, with a conservative $O((N+b)^2)$ bound per query and $O(N+b^2)$ setup, $L+O(\log N)$ writable cells and the input footprint separately. The \emph{two-bit indexed probe} statement does not transfer to sequential tape accesses. Conservatively simulating a fixed-$k$ multitape machine on one read/write tape yields $T_1=O(T_k(N+S_k+\log(T_k+2)))$ and $P_1=O(N+S_k+\log(T_k+2))$ as \emph{upper} accounting envelopes, with head movement and input footprint included, not a SAT lower bound. No native physical head-crossing or universal-machine step count was measured. A fixed universal interpreter pays additional uniform interpretation overhead, never free instructions or source reads.

A source-free reusable summary for every parity query needs $b$ bits by singleton-mask distinguishability. Sending the original $N$-bit formula as the summary is another legal, nonoptimal control. A joint solver that sees both $A_a$ and $B_{w,t}$ can simply scan the source and query in polynomial time, or if $w$ is known in advance prepare the one-bit answer. Therefore Lemma~\ref{lem:general} and Theorem~\ref{th:tight} cannot be promoted to a lower bound for unrestricted SAT or for general single-child contraction.

\section{Contextual fact interpreter and exhaustive checks}
The standalone Python reproducer implements a \emph{finite observational} interpreter for records of the form $(x=1)\mid_v$ and parity facts $(w\cdot x=t)\mid_v$. Each record contains context $s,K$, score definition, provenance, a toy certificate, acquisition cost, verification/application costs, and explicit score-discovery enumeration. The independent score is $\Phi(K)=\log_2|\{w\cdot a:a\text{ satisfies }K\}|$, which counts possible target \emph{outcomes}, not SAT solver states. The value $v_\Phi(I\mid s)=\Phi(K)-\Phi(K\cup\{I\})$ is calculated \emph{after} a charged exhaustive enumeration of small possible worlds. A single $x=1$ share or $y=0$ share has value 0 for target $x\oplus y$, both together value 1, and a duplicate share has value 0. The records are not inference rules giving away unseen assignments. The separate Bayesian realized entropy example with prior $P(T=1)=0.1$ and observed conditional $P(T=1\mid E)=0.5$ has $H_2(0.1)-H_2(0.5)\simeq-0.5310$ bits, while its expected gain is positive. These are different scored contexts, and fact values cannot be added across correlated observations.

The raw JSON records $4,112$ completely exhaustive source/query comparisons for $b=2,6$, $70,216$ larger source/query checks including \emph{all} $2^{14}$ queries on each of four selected $b=14$ sources, $2,728$ independently enumerated two-stage SAT continuation decisions with $b\le5$, and $33$ combinatorial degree-volume identities. Independent SAT/UNSAT controls include 2SAT, XOR, mixed CNF, connected three-variable parity strict22 SAT (four models), and connected 15-variable W1 strict22 UNSAT (zero of $2^{15}$ assignments). Higher-$b$ controls are sampled and cannot stand in for the symbolic proof. Paired wall-clock and Python traced-peak observations are in one execution's raw ledger, not native TM measurements. Code is Python standard library, fixed seed 237; no external SAT solver or answer oracle was used.
