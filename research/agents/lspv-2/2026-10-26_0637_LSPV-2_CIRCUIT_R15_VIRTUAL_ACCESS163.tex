\section{Exact model, source interface, and hypotheses}
Let $F_x$ be a family of ordinary proper signed ternary CNFs with $n$ declared Boolean variables and $m$ ordered clauses. Every clause contains three \emph{distinct} variable names; duplicate clauses may occur in the source. Fix a template on the input length: the variable name in each source clause slot $(c,p)$ is independent of the source bit string $x$; only its polarity may vary, and each source sign is a constant, $x_j$, or $\neg x_j$ for a $j$ computable in polylogarithmic time.

The source has indexed functions $\operatorname{Lit}(c,p)$, $\operatorname{Count}(v)$, $\operatorname{Rank}(c,p)$, and $\operatorname{Select}(v,r)$, where each variable's occurrences are ordered lexicographically by $(c,p)$. Rank is zero-based; Select is its inverse. The latter two may return an occurrence of a variable with zero source occurrences only after explicit existence testing by Count. These source functions are assumed to use $\log^{O(1)}(n+m)$ deterministic \emph{bit operations and source probes} and $O(\log(n+m))$ scratch/work/index bits. They are a genuine constructional hypothesis, not a free oracle with no source-access charges.

A child's fixed-width binary format uses a constant prefix, the output variable and clause counts in a known $w_h$-bit width, and for every ordered clause, three records each consisting of one polarity bit and a $w=\lceil\log_2(v+1)\rceil$-bit variable identifier. The whole layout is fixed by $(n,m)$ and the regularization level, not by $x$. For output $M$ clauses and $v$ names its bit length is $4+2w_h+3M(1+w)$ with $w_h=\lceil\log_2(\max(v,M)+1)\rceil$.

\section{Source-normalized $R_{15}$ with explicit output addresses}
Adopt the \emph{historical} $15$-variable, $19$-clause three-port $Q_{15}$, deleting $(1\vee7\vee13)$ from the original $20$-clause minimally UNSAT $W_1$ in \cite{PCRETRACT1}. The ports $(1,7,13)$ each have profile $(1\text{ positive},2\text{ negative})$, all twelve interior names have $(2,2)$, and $Q_{15}$ is satisfied with every port false and all interior variables zero. Previous and current independent exhaustive checks give exactly $244$ models, all with ports false. Adopt the transparent seven-clause, five-auxiliary gadget $J(\ell)$ from the October 26 SAT resource extension and \cite{QSWAP}; it has exactly one appearance of the port literal and two of each sign of each auxiliary, and extends both values of $\ell$.

Set $L=3m+3n$, $B=m+n$ and $J_\#=3m+6n$. Allocate occurrence clone $u=3c+p+1$ for source slot $(c,p)$, and dummy clone $d(v,t)=3m+3(v-1)+t+1$, $t\in\{0,1,2\}$. On every source name, take its occurrence clones in $(c,p)$ order followed by its three dummies, and form one directed cycle. Order \emph{all implication edges by their tails} $u=1,\ldots,L$. The successor $\operatorname{Next}(u)$ is computable directly:
\[
\operatorname{Next}(3c+p+1)=\begin{cases}
 3c'+p'+1,&(c',p')=\operatorname{Select}(v,r+1),\quad r+1<\operatorname{Count}(v),\\
 d(v,0),&r+1=\operatorname{Count}(v),
\end{cases}
\]
where $v=|\operatorname{Lit}(c,p)|$ and $r=\operatorname{Rank}(c,p)$. Dummy $t=0,1$ advances to $t+1$; dummy $t=2$ returns to the first occurrence or dummy $t=0$ when the variable is unused. The predecessor is defined symmetrically with Rank/Select and the final dummy.

Allocate all $Q_{15}$ private variables in contiguous groups after clones. For tail $u$ put $b=\lfloor(u-1)/3\rfloor$ and $p=(u-1)\bmod3$. The $u$th implication clause is
\[
\boxed{\neg u\ \vee\ \operatorname{Next}(u)\ \vee\ \bigl(L+15b+q_p\bigr)},\quad(q_0,q_1,q_2)=(1,7,13).
\]
The three ports of every copy are forced false, so these clauses enforce the unpadded original implications. Put all $m$ source clauses first, then the $L$ padded implications, then the $19B$ internally fixed $Q_{15}$ clauses, then the $7J_\#$ copies of $J$. The $J$ copy for an occurrence clone has port $-\operatorname{sgn}(\operatorname{Lit}(c,p))u$, and each dummy has two $J$ copies with opposite ports. All namespace IDs and clause-record locations are arithmetic functions of $(n,m,c,p)$ and the fixed $J,Q$ tables.

\begin{theorem}[Source-coherent exact regularization, adopted gadget theorem]
For every ordinary proper signed ternary source $F$, the above $R_{15}$ is an ordinary proper signed exact-$(2,2)$-3-CNF with unique target clauses and
\[
 \SAT(R_{15}(F))\iff\SAT(F),\quad
 v_1=33m+48n,\quad m_1=44m+64n,\quad 3m_1=4v_1.
\]
It does not claim that the output is clause-monotone.
\end{theorem}
\begin{proof}
Each source clause slot uses a distinct occurrence clone. The ring's forced implications make all occurrence and dummy clones of one original name equal, and every satisfying assignment of the source extends with zero-valued $J,Q$ interior auxiliaries. Each occurrence clone has a source occurrence, one incoming positive implication, one outgoing negative implication, and one opposite $J$-port occurrence. Each dummy has two opposite $J$-port occurrences plus its two implications. A $Q$ port has three internal occurrences and one positive external occurrence; every other private variable already has two occurrences of each sign. Every clause is proper, each ring has length at least three, and private namespaces distinguish all target clauses. Counts follow from $3m+3n$ clones, $m+n$ copies of $Q_{15}$, and $3m+6n$ copies of $J$.
\end{proof}

\section{New exact local \emph{occurrence} enumeration and two-level closure}
\begin{theorem}[R15 indexed incidence closure, new restricted lemma]
For every fixed-incidence source family satisfying the source interface above, all three operations $\operatorname{Lit}_1$, $\operatorname{Rank}_1$, and $\operatorname{Select}_1$ of $R_{15}(F_x)$ are computable with $\log^{O(1)}(m+n)$ bit operations and $O(\log(m+n))$ workspace, without materializing $R_{15}(F_x)$ or an occurrence table. Every target name has \emph{exactly four} occurrences, which can be enumerated with a constant number of source interface calls and arithmetic operations. Consequently, for every fixed $h\ge1$, every bit of $R_{15}^{\,h}(F_x)$ is generated in $\log^{O_h(1)}(m+n)$ bit time and $O_h(\log(m+n))$ space, and is a constant or one source literal of $x$. For two levels,
\[
\boxed{v_2=3036m+4416n,\qquad m_2=4048m+5888n.}
\]
The statement gives no such guarantee for a source whose rank/select is not locally accessible.
\end{theorem}
\begin{proof}
For an original clone $u\le3m$, its four target occurrences are its source-clause slot, its outgoing implication tail, its incoming implication head (obtained from $\operatorname{Prev}(u)$), and the unique $J$ port slot. For a dummy clone the first two are the incoming/outgoing implications and the last two are its positive/negative $J$ ports. For a $Q$ private name, at most four positions come from the fixed nineteen-row table, with the distinguished ports having one additional padded-implication position. For a $J$ auxiliary, exactly four positions come from its fixed seven-row table. All four positions are computable from arithmetic block indices and at most constantly many source Count/Rank/Select/Lit operations, and can be sorted in constant-comparison time. This explicitly gives Count$_1=4$, Rank$_1$, Select$_1$ and each output clause literal.

A requested \emph{bit} is decoded by division into the constant header, clause index, literal slot and bit of the signed variable identifier. The child name bit depends only on indices and occurrence topology, which is independent of $x$. Source-dependent signs are only unchanged/complemented copies of original source polarities, including opposite $J$ ports. This proves literal-or-constant locality, not merely a row-level claim. Each arithmetic operation handles $O(\log(m+n))$-bit integers and is charged. Apply the same construction to the level-one virtual interface, using its just-proved four-occurrence interface, and induct for any fixed depth. Direct substitution in the count formulas yields $v_2,m_2$.
\end{proof}

\paragraph{Fully charged scope.} A level-$h$ virtual read requires the full nested source accesses and bit-address computation each time; its pointer/loop/count arithmetic is paid. With fixed $h$, nesting creates a constant number of simultaneous $O(\log N)$-bit registers, not an $N$-length index. No materialized output is retained in the virtual path. If an indexed target decider takes $T(M)$ physical time and $S(M)$ writable/index space, composing that decider with the virtual child costs up to $T(M)\log^{O_h(1)}N$ source/simulation bit operations and $S(M)+O_h(\log N)$ bits, \emph{provided} its original random-access steps and input-service model match the stated machine. Since $M=N^{1+o(1)}$ for standard dense source records, fixed exponents transport but do not improve. The implemented Python harness materializes both children \emph{independently for checking}; its peak Python heap is not a certified FLMV bound.

\section{New sharp raw source-access counterexample}
\begin{theorem}[A single regularizer output bit requires $\Omega(m)$ raw-ID probes, restricted no-index architecture]
Fix even $k\ge4$ and $m=(2^k-1)/3$, $n=3m$. Consider all-positive proper-three-CNF source rows initially containing every ID $1,2,\ldots,3m$ exactly once, in order. Keep the first clause $(1,2,3)$ unchanged. For any later literal slot, a valid alternate source replaces just that slot's identifier with $1$. Under the direct source-incidence $R_{15}$ construction above, there exists \emph{one fixed requested bit} of the first padded implication clause that is $1$ for the original source and $0$ for all $3m-3$ alternatives. Every deterministic no-index random-access algorithm computing that bit must probe at least one bit of \emph{each} of the $3m-3$ later source identifier records on the original input. Thus its worst-case source-bit query count is $\Omega(m)$.
\end{theorem}
\begin{proof}
The first occurrence clone of variable $1$ is $u=1$. If that is its only source occurrence, its successor is its first dummy, $d(1,0)=3m+1=2^k$. If another occurrence is inserted in later slot $j\in\{3,\ldots,3m-1\}$, the successor is the occurrence clone $j+1\le 3m<2^k$. Therefore the bit of value $2^k$ in the variable-ID field of the \emph{same fixed implication clause} is $1$ in the base input and $0$ after any single later-record edit. If the algorithm did not probe one candidate ID record on the base input, that record could be changed without altering its observations, contradicting correctness for that alternate input. All source clauses remain proper because the first original occurrence of $1$ is in a different clause and all other names are initially distinct. The source is not promised exact-$(2,2)$: this barrier concerns the \emph{arbitrary source first leg}, before regularization.
\end{proof}

This is a decision-tree lower bound on the \emph{specific direct raw-ID successor accessor without preprocessing}. It is not an all-algorithm SAT lower bound and does not refute the October 26 fixed-verifier sorting-network construction: the latter \emph{encodes} data-dependent sorting as a Boolean circuit of fixed incidence; it does not execute an input-dependent permutation while building the target.
