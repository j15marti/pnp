\item[] \textbf{M3.} Ordinary 3CNF re-encoding and equality-copy fanout might necessarily introduce unbounded variable incidence. \textbf{FALSIFIED for the specific port compiler}: the exact construction has maximum occurrence five and fully explicit 3CNF clause counts.

The present profile is a tiny output whose selection already encodes SAT; it is not an unconditionally constructed child decision instance.

\section{BUILD: a finite-port polynomial reduction with degree five}
Let $H(x_1,\ldots,x_n)=\bigwedge_{i=1}^m C_i$ be a nonempty proper 3CNF with three pairwise distinct variables per clause. Assume names are dense and used; standard polynomial normalization addresses malformed input and short clauses. Let $a,b$ be two exposed Boolean ports and let
\[
 G_H(a,b,x)=\bigwedge_{i=1}^m
 \bigl(a\vee b\vee C_i(x)\bigr)
 \wedge\bigl(\neg a\vee\neg b\vee C_i(x)\bigr).
\]
The displayed formula contains five-literal clauses, and ports appear many times. We now compile it to a \emph{connected proper width-three} formula with no shared high-degree signal.

\begin{lemma}[Constant-size clauses for disjunction and equality]
For distinct variables underlying $u,v$, the binary disjunction $u\vee v$ is equivalent under existential projection of a fresh $t$ to
\[(u\vee v\vee t)\wedge(u\vee v\vee\neg t).\]
For five literals on distinct variables, $\ell_1\vee\cdots\vee\ell_5$ is equivalent under existential projection of fresh $t,s$ to
\[(\ell_1\vee\ell_2\vee t)\wedge(\neg t\vee\ell_3\vee s)\wedge(\neg s\vee\ell_4\vee\ell_5).\]
In a directed implication cycle $\bigwedge_{j=0}^{d-1}(\neg z_j\vee z_{j+1\bmod d})$, $d\ge2$, every satisfying assignment has $z_0=\cdots=z_{d-1}$, and every common value extends to a satisfying assignment.
\end{lemma}
\begin{proof}
An unsatisfied binary disjunction forces both $t$ and $\neg t$; a satisfied binary disjunction permits either value. For the five-literal version, eliminate $t,s$ in that order by elementary resolution, yielding precisely the original disjunction; or choose $t$ and $s$ to match the first satisfied input. For the cycle, a nonconstant circular zero-one word has a $1\rightarrow0$ transition, violating its implication; constant words satisfy every implication.
\end{proof}

\paragraph{Uniform compiler.}
For each source clause $C_i=(\ell_{i1}\vee\ell_{i2}\vee\ell_{i3})$, create two separate clauses with fresh ports $a_i^{+},b_i^{+}$ and $a_i^{-},b_i^{-}$. Each of the six occurrences of $x$ in the two displayed five-literal source constraints is replaced by a fresh variable copy with the original sign. This creates $6m$ source occurrence copies, $2m$ copies of port $a$ and $2m$ copies of port $b$, for a total of $10m$ copies. Make a cycle of implications for each original source variable and each of the two ports; each copy participates in its predecessor and successor implication. Split each implication by the binary gadget above. Replace the $2m$ guarded five-literal clauses by the five-literal gadget above. Expose $a=a_1^+$ and $b=b_1^+$ and existentially quantify all other variables.

\begin{theorem}[Bounded-occurrence, two-port NP-complete profile acquisition]
There is a deterministic polynomial-time map $H\mapsto M_H(a,b,w)$ into \emph{connected proper 3CNFs} such that, for each nonempty proper 3CNF input with $m$ clauses,
\[
 n(M_H)=24m,\qquad c(M_H)=26m,\qquad \max_z\operatorname{occ}_{M_H}(z)=5.
\]
Each of the $10m$ input/port copies occurs exactly five times, and each of the $14m$ splitting variables exactly twice. More precisely,
\[
 \{(a,b):\exists w\ M_H(a,b,w)\}=
 \begin{cases}
 \{(0,1),(1,0)\},&H\text{ UNSAT},\\
 \{0,1\}^2,&H\text{ SAT}.
 \end{cases}
\]
Consequently deciding whether $(0,0)$ belongs to this profile is NP-complete, even for this restricted connected proper maximum-five-occurrence module language. Deciding its absence is coNP-complete. All one-coordinate marginal supports are $\{0,1\}$ on every input, so they do not reveal the answer.
\end{theorem}
\begin{proof}
There are $2m$ guarded five-clauses. Their splitting gadgets require $4m$ new internal variables and $6m$ ordinary ternary clauses. There are exactly $10m$ occurrence copies. Every copy belongs to exactly one guarded clause and to two directed implication-cycle constraints, one as consequent and one as antecedent. The equality cycles therefore contain exactly $10m$ binary implications, split into $20m$ ternary clauses and $10m$ internal variables. Hence the total is $10m+4m+10m=24m$ variables and $6m+20m=26m$ clauses. Each copy occurs once in its guarded clause and twice in each of two split implications, giving five occurrences; each splitting variable occurs once positively and once negatively, giving two.

All ternary clauses are proper because every copied literal belongs to its own fresh variable and each splitting variable is fresh. Each guarded clause connects one $a$-copy, one $b$-copy, and three original source-variable copies. All $a$-copies lie in a single implication cycle, all $b$-copies in another, and each original source-variable copy belongs to such a guarded clause. Thus the variable--clause incidence graph is connected even if the source $H$ is disconnected.

Eliminating all splitting variables restores the exact guarded disjunctions and equality implications. Eliminating equality-copy variables identifies them with the two exposed ports and their original source variables. If $a\ne b$, both $a\vee b$ and $\neg a\vee\neg b$ are true, so every $C_i$ is irrelevant and the profile contains both unequal pairs. If $a=b=0$, the first guard is false and $H$ is required. If $a=b=1$, the second guard is false and $H$ is required. This proves the exact profile. A witness for $(0,0)$ is a polynomially verifiable assignment to the remaining variables, so membership is in NP; the uniform many-one reduction from 3SAT proves NP-hardness. Complementation gives coNP-completeness of absence. The unary margins always contain both values because both unequal pairs exist.
\end{proof}

\section{Sharp qualification: storage is not acquisition and re-entry is not contraction}
The profile itself needs at most four Boolean bits. If $H$ is SAT, an exact ordinary-3CNF existential extension can be a trivially satisfiable proper ternary clause independent of $a,b$; if $H$ is UNSAT, the XOR profile has the two binary clauses $(a\vee b)$ and $(\neg a\vee\neg b)$, each expanded into two proper ternary clauses. \emph{However the choice between these two outputs is NP-complete to compute.} Calling the four-bit relation a free summary would import an uncharged SAT solver. Equivalently, adding the equality constraint $a=b$ to $M_H$ produces a formula satisfiable precisely when $H$ is satisfiable, but it may break the five-occurrence promise at the exposed ports. This is not claimed as a strict exact-$(2,2)$ reduction.

The construction is a \emph{source-expanded embedding}, not a contraction: for standard canonical source input length $N_H$, $m\le N_H$, the full output occupies $O(m\log(m+2))$ bits. It has $26m$ actual clauses, $24m$ actual variables, explicit headers, and fresh source occurrence identifiers. No polynomial-power shortening follows. The reduced four-bit relation is too cheap to \emph{store}, but its uniform computation is equivalent to SAT decision on the whole source class.

\paragraph{Answer classes and one-program uniformity.} One compiler builds $M_H$ for both SAT and UNSAT sources. For the profile extractor, $T_+$ and $T_-$ are simply restrictions of this \emph{same} program; neither receives an answer-class bit. The finite MILP controls do not imply a lower bound on deterministic post-input processing. The polynomial-time extractor hypothesis would imply $P=NP$ regardless of side-specific maxima. A polynomial-time selector for profiles is logically conditional on the unresolved question, not an implemented algorithm.

\section{Full native resource ledger}
Let $L$ be the physical bit length of dense, authenticated proper 3CNF source $H$. A deterministic indexed RAM implementation of the compiler can parse and validate the complete source, assign unique copy addresses, build equality cycles and output all $26m$ clauses in $O(L^{O(1)})$ word operations and $O(L\log L)$ writable bits. We charge full identifier size, output bits, source validation, and malformed-input rejection. The actual Python program uses linear-size arrays and dictionary grouping, with no advice or SAT calls in construction.

For the deterministic fixed-k read-only-input multitape TM, an elementary repeated-scan and sequential-output implementation permits the conservative explicit bounds $T_{\mathrm{multi}}=O(L^3)$, $S_{\mathrm{multi}}=O(L\log L)$ work cells, $Q_{\mathrm{multi}}=O(L^3)$ physical input probes and head movements, and $O(L\log L)$ output bits. These are safe upper bounds for the constructor, not tight lower bounds. The stipulated one-tape simulation gives
\[
 T_{\mathrm{one}}=O\big(T_{\mathrm{multi}}(L+S_{\mathrm{multi}}+\log(T_{\mathrm{multi}}+2))\big)=O(L^4\log L),
 \qquad P_{\mathrm{one}}=O(L\log L),
\]
where input and virtual output occupy the same single-tape footprint and head movements are counted. A fixed universal machine simulating either fixed constructor has polynomial overhead in the encoded runtime (a naive quadratic interpreter yields a conservative polynomial bound); no source-dependent machine description or free oracle is supplied. The port projection \emph{computation} is NOT included in these construction upper bounds. The finite MILP solver is an independently audited test implementation, not the claimed deterministic projection algorithm.

This model-typed upper accounting is compatible with all existing one-head and two-head crossing-sequence restrictions on special promise problems and with indexed RAM's different access model. It yields no FLMV-native forbidden-region contradiction and no unconditional SAT lower bound.
