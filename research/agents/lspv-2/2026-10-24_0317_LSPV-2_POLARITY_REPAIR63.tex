\section{Model and falsifiers}
Consider proper signed 3CNF with $n$ original variables, $m$ clauses and precisely two positive and two negative occurrences per variable. Thus $4n=3m$. Use $N=(4m+2)w$, $w=\lceil\log_2(64(n+m+1))\rceil$ addressed input bits. All input reads, parsing, failed matching searches, sign-field edits, output, verification and source replay are charged. Output TRUE from a fan-in-two AND-of-OR evaluator means one may select one true occurrence per clause, consistently across original variables. This does not require exactly one true literal in a clause. The occurrence graph has $4n$ vertices and $4n$ complementary edges as $n$ disjoint $K_{2,2}$; adding clause triangles yields $8n$ edges and degree four. Evaluating an assignment uses $3m-1$ OR2/AND2 gates and $6m-2$ gate-input wires when literal values are provided, not a SAT-solving circuit lower bound.

\section{Hall relaxation}
A capacity selector $M$ chooses one named occurrence from each clause while selecting no original variable more than twice. Build one left vertex per clause and two right clones per original variable; connect each left clause to both clones of its three variables. For any $Q$ of clauses, $3|Q|\le4|N(Q)|$ since each original variable occurs four times. Consequently $2|N(Q)|\ge|Q|$, so Hall's theorem yields a matching saturating the left clauses. Hopcroft--Karp finds one in $O(m\sqrt{n+m})$ word time, $O(n+m)$ live words. This matching exists even for UNSAT inputs.
\section{Main exact transformation theorem}
Let $\mathcal M(F)$ be all capacity selectors, with $\operatorname{mixed}(M)$ the original variables selected in both signs. Set
\[
\mu(F)=\min_{M\in\mathcal M(F)}|\operatorname{mixed}(M)|.
\]
A legal swap exchanges one positive and one negative source occurrence of the \emph{same} original variable. It changes the input signed formula, preserves all unsigned source positions and both occurrence quotas, and may introduce a duplicate signed clause unless unsigned source supports are distinct. Let $d_{\rm SAT}(F)$ be the fewest such swaps yielding a SAT signed formula.
\begin{theorem}[PROVED/EXACT, stated calculus]
\[
\boxed{\mu(F)=d_{\rm SAT}(F)\le\lfloor m/2\rfloor=2n/3.}
\]
For any capacity selector one can construct a SAT edited signing using exactly one swap per mixed original variable, together with a checkable source assignment, in $O(n+m)$ additional word work.
\end{theorem}
\begin{proof}
For a mixed variable $x$, the selector uses one positive occurrence $p$ and one negative occurrence $q$. Another positive occurrence $p'$ is unselected, since $x$ has exactly two positive occurrences. Swap signs at $q$ and $p'$, so both selected occurrences become positive. The operations on distinct source variables have disjoint positions. Assign selected sources according to their now coherent selected polarity, and every clause has a true witness occurrence. Thus $d_{\rm SAT}\le\mu$. Conversely take any SAT signing after $d$ swaps. Select one true literal per clause. No variable is selected more than twice because only two occurrences have its true polarity. Pull this selector back to the original signed formula. Only variables touched by a swap could be mixed, hence $\mu\le d$. Each mixed variable uses two distinct selected clause occurrences, yielding $\mu\le\lfloor m/2\rfloor$.
\end{proof}
The zero test $\mu(F)=0$ is exactly SAT, so minimization is not known polynomial in the full signed exact-$(2,2)$ language, which contains the known NP-complete monotone language. No separate support-simple NP-completeness claim is made.
