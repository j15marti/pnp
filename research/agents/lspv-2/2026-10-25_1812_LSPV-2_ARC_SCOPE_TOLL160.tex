\section{Exact question and falsifiable candidates stated before search}
The original achievable set $E$ consists of pairs $(t,s)$ bounded simultaneously on
\emph{every} ordinary SAT string by ONE fixed uniform, total, deterministic
exact SAT machine, with time $N^{t+o(1)}$ and writable/index workspace
$N^{s+o(1)}$ in the indexed-read-only-input model of
Fortnow--Lipton--van Melkebeek--Viglas (FLMV).
Under $P=NP$, some finite diagonal $(K,K)\in E$ exists.
The strict FLMV target is
\[
 c_*={241\over200}=1.205,\quad
 d_*={11642479\over23232400}=0.501131\ldots,\quad
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
The earlier universal cosine-sum/product endpoint is \textbf{RETIRED}.

\begin{description}
\item[] H1. A uniform \emph{unconditional} all-source cheap normalizer can
transform the one fixed FLMV-hard SAT image into a near-linear valid
$o(\log N)$-width scoped stream with simultaneously cheap bit work and
writable/index workspace. \textbf{FALSIFIED as a conjunction} by the
resource-toll theorem below, not by a representation-counting argument.
\item[] H2. A normalizer whose \emph{construction} genuinely depends on an
assumed polynomial SAT decider $A$ might satisfy the same favorable budget
on the hard image. \textbf{OPEN}; this would fill an ARC route, not
follow from $P=NP$ without a construction.
\item[] H3. Constructing named scoped views and doing two real pinned
ordinary-CNF recursive levels preserves SAT/UNSAT and ordinary
serialization. \textbf{PROVED elementary semantics / COMPUTATIONAL test};
small width on easy inputs is not universal width contraction.
\item[] H4. Normalization to a short or low-width representation can be
charged as only the DP continuation, omitting extraction. \textbf{FALSIFIED
as an accounting inference}; acquisition and output work must precede
the claimed continuation savings.
\end{description}

\section{Resource-toll theorem on the fixed hard reduction image}
By the FLMV class separation and its locally indexed completeness
reduction, fix one language
$L^\dagger\in\mathrm{NTIME}[n]$ and one ordinary-CNF SAT reduction
$Q^\dagger$ of length
$N(n)=n^{1+o(1)}$ with addressed bits computable in $n^{o(1)}$
time and $O(\log n)$ counted writable/index workspace, so a
simultaneous SAT decider inside $(c_*,d_*)$ on its entire image
would contradict FLMV.

A \emph{valid scoped stream} is a sequence of events
\texttt{OPEN}(v), \texttt{CLAUSE}$(C)$, \texttt{CLOSE}(v)$;
every active source name opens once and closes once, and each clause
is emitted while its variables are live. A normalized stream is
required to encode a CNF SAT-equivalent to the original source
on every image input. Its \emph{maximum live original or introduced
name count} is $w$; the event symbols, headers, name maps and
identifiers are all ordinary explicit bits.

\begin{theorem}[Hard-image scoped-normalizer toll; FLMV consequence]
Fix constants $r,\eta,\mu,\delta\ge0$. Suppose a single fixed uniform
deterministic \emph{streaming} normalization machine $G$ operates
on every $y\in\mathcal H^\dagger=\operatorname{im}(Q^\dagger)$
and emits a well-formed, SAT-equivalent scoped-CNF stream, with:
\[
T_G(N)\le N^{r+o(1)},\qquad
S_G(N)\le N^{\eta+o(1)},\qquad
M_G(N)\le N^{\mu+o(1)},\qquad
w_G(N)\le\delta\log_2N+o(\log N),
\]
where $M_G$ counts all event and identifier bits/records up to
polylogarithmic equivalence, and normalizer time includes every
source read, index operation, address/control/arithmetic step,
failed candidate, changed and unchanged write, and emitted event bit.
Then these four bounds cannot simultaneously satisfy
\[
\boxed{\quad
\max\{r,\mu+\delta\}<c_*,
\qquad
\max\{\eta,\delta\}<d_*.\quad}
\]
This is a conditional \emph{normalization architecture} obstruction,
not an unconditional $P\ne NP$ proof or a lower bound on all normalizers.
\end{theorem}
\begin{proof}
Given original $x$ of length $n$, simulate $G$ on the \emph{virtual}
ordinary SAT input $Q^\dagger(x)$. Each guest input-bit request is
implemented using the fixed FLMV local reduction, with a paid
$n^{o(1)}$ multiplicative time overhead and $O(\log n)$ additional
writable/index cells. Intercept emitted events as they are generated;
the guest's one-way output tape is not used as free readable memory.
On the fly, maintain the Boolean dynamic-programming relation on
assignments to live names. On \texttt{OPEN}, duplicate each surviving
assignment under both values; on \texttt{CLAUSE}, filter violating
assignments; on \texttt{CLOSE}, existentially project that variable.
At all times at most $2^w$ Boolean table entries and
$O(w\log N)$ source-name/index metadata are simultaneously live.
Each event is processed in $2^w\operatorname{polylog}N$ work.
The final empty-frontier table is nonempty iff the stream's formula
is SAT, which by normalization equals the SAT bit of
$Q^\dagger(x)$, and hence the membership bit of $L^\dagger$.
With $N=n^{1+o(1)}$, the composed ONE deterministic uniform
machine therefore has simultaneous bounds
\[
T(n)\le n^{\max\{r,\mu+\delta\}+o(1)},\qquad
S(n)\le n^{\max\{\eta,\delta\}+o(1)}.
\]
The strict inequalities would put the fixed language $L^\dagger$
inside the FLMV-forbidden DTISP class, contradiction.
\end{proof}

\begin{corollary}[Near-linear scope normalization barrier]
In the special case $M=N^{1+o(1)}$ and
$w\le\delta\log_2N+o(\log N)$, any unconditional
uniform streaming all-hard-image normalizer must exceed at least
one of the budgets $r<c_*$ and $\eta<d_*$ whenever
$0\le\delta<\min\{41/200,d_*\}=41/200$.
In particular, a cheap $o(\log N)$-width normalizer with near-linear
output cannot exist on the entire fixed hard image.
\end{corollary}
\begin{proof}
Substitute $\mu=1$ and note $1+\delta<c_*$ when
$\delta<41/200$; the space condition also holds for such $\delta$.
The preceding theorem applies.
\end{proof}

\paragraph{Quantifier and scope guard.}
The theorem does \emph{not} prohibit an expensive normalizer, one
using large simultaneous workspace, a wide or long output, a
non-streaming inaccessible succinct representation, a reduction that
fails on some hard-image inputs, or an implementation whose resource
advantage only exists conditional on a polynomial SAT solver. For a
random-access virtual scoped stream, every bit-generation probe must
instead be charged, including repeated probes. A program that
calls a full-scale SAT solver and then emits one constant clause
is semantically legitimate but retains the full-scale cost of that
solver. Ordinary child and grandchild promises remain separate.

\section{A precise assumption-dependent sufficient bridge, still OPEN}
Assume under $P=NP$ one fixed ordinary-SAT decider $A$ has joint
pair $(t,s)$. Suppose an actual uniform \emph{$A$-assisted}
normalizer for the entire fixed hard image has at most
$B=N^{a+o(1)}$ genuine ordinary SAT calls, each on fully
charged $L=N^{\lambda+o(1)}$ input bits, with total noncall
work $N^{r+o(1)}$, retained ancestors exponent $\kappa$,
normalizer peak state exponent $\eta$, and outputs a valid
stream of length $N^{\mu+o(1)}$ and width $\delta\log_2N$.
For eager materialized children, with per-output-bit cost
$N^{g+o(1)}$, the ONE-machine conditional profile is
\[
 t_{\rm out}\le
 \max\{r,\ a+\lambda+g,\ a+\lambda t,\ \mu+\delta\},\quad
 s_{\rm out}\le
 \max\{\eta,\kappa,\lambda,\lambda s,\delta\}.
\]
For fully lazy repeatedly regenerated child bit access, with
$g$ paid on every child-solver probe, replace the eager
emission term by $a+\lambda t+g$ and drop the explicit
$\lambda$ buffer term if the virtual-generator interface is
actually model-correct. All failure and switching costs belong
in $r,\eta,\kappa$; if the $N^{r}$ term already counts emission,
do not add it twice as a separate work charge.
Either profile inside the strict FLMV box for one actual fixed
source-qualified machine would yield the desired contradiction.
\textbf{The existence of such an $A$-assisted normalizer is OPEN}.
Numerical feasibility alone is not a machine-producing theorem.

\section{Two real ordinary-SAT levels: independent finite audit}
A standalone standard-library executable constructs ordinary CNF,
parses its own DIMACS encodings, derives true original-name scoped
events, and performs two \emph{actually executed} balanced binary
clause splits. At a split the parent shares an original-name set
$S$ between the left and right clause portions and uses
\[
\operatorname{SAT}(F)
\ \Longleftrightarrow\
\bigvee_{\alpha\in\{0,1\}^{S}}
\big(\operatorname{SAT}(F_L\wedge\mathrm{pins}(\alpha))
\land\operatorname{SAT}(F_R\wedge\mathrm{pins}(\alpha))\big).
\]
Both branches use ordinary serialized signed-unit pin clauses,
and the same original source identifiers. This identity is
elementary: consistent witnesses glue, and every global witness
restricts to a common boundary. The second recursive level
performs the same construction on the \emph{actual} pinned
children; exact exhaustive solvers decide actual leaves.
Each produced child is reparsed and independently checked by
on-the-fly scoped dynamic programming with real
\texttt{OPEN}/\texttt{CLAUSE}/\texttt{CLOSE} events.
