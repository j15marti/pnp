\section{Source-indexed exact both-label theorem}
Take boundary $B=(x_1,\ldots,x_b)$, $b\ge2$. Each original component $i$ is a complete proper 3CNF encoding of
\[
y_{i,2}=x_1\oplus x_2,\quad y_{i,j}=y_{i,j-1}\oplus x_j\ (3\le j\le b),
\quad y_{i,b}=r_i,\qquad r_i\in\{0,1\}.
\]
For each gate use all four original signed 3-clauses that encode its truth table, and for the final pin use four proper 3-clauses with two fresh private variables. Every original clause has a stable integer index and signed occurrence map; validate every clause against its declared gate/pin block. Components have disjoint private variables, but share the boundary. A claimed grouping or source-variable renaming is not trusted before complete validation. Discovering these groupings on arbitrary input is not supplied for free.

\begin{theorem}[Exact canonical parity child, both SAT and UNSAT]
For every boundary assignment $\beta$ and every verified original source $F_{b,\mathbf r}$,
\[
\exists P\,F_{b,\mathbf r}(\beta,P)\quad\Longleftrightarrow\quad
\bigwedge_i\left(\bigoplus_{j=1}^b\beta_j=r_i\right).
\]
Create a canonical ordinary 3CNF child $G$ consisting of one fresh-private copy of the chain for each \emph{distinct} value among $\{r_i\}$, with all contradictory requirements retained. Then
\[
\forall\beta\quad \exists P\,F(\beta,P)\iff\exists Z\,G(\beta,Z).
\]
SAT witnesses lift to the complete original source; the equivalence also preserves UNSAT.
\end{theorem}
\begin{proof}
Every four-clause XOR gate has exactly one output extension at fixed inputs. Induction along a component gives its cumulative XOR; the four-clause pin is extendible exactly when the final bit equals $r_i$. Disjoint private variable sets make the source projection the conjunction of those requirements. Repeated identical requirements can be removed, but two opposing ones cannot: if both parity values occur, source and child are UNSAT. Otherwise a satisfying child boundary assignment is copied to each removed component and all private XOR outputs are deterministically reconstructed; check each indexed original clause. For NO, unsatisfiability of the displayed conjunction gives no possible boundary/source completion. This is an authenticated typed parity proof, not automatically a pure resolution refutation. \end{proof}

\section{Exact auxiliary-free guard blowup}
\begin{theorem}[Parity requires full-width guards without auxiliaries]
Every CNF over \emph{only} $b$ source boundary variables whose models are exactly the even-parity assignments contains at least $2^{b-1}$ non-tautological clauses, each mentioning all $b$ variables. The bound is tight.
\end{theorem}
\begin{proof}
Every clause is entailed by even parity. If a non-tautological clause omits $x_j$, a falsifying assignment and its $x_j$-flip both falsify it, but one has even parity, contradiction. A clause mentioning all variables excludes only one full assignment. Each of the $2^{b-1}$ odd assignments requires a distinct exclusion. The full-width exclusions achieve equality.\end{proof}
This does \emph{not} constrain polynomial-size existentially equivalent definitional CNF with auxiliary variables, and is not a hard-SAT instance theorem.

\section{Computed exact ordinary-DIMACS character access}
Use canonical DIMACS with a literal space after every signed integer, signed integer zero and newline after every clause, and an exact header. Let $d(t)$ denote decimal digits and $D(t)=\sum_{v=1}^t d(v)$. A proper four-clause XOR gate with argument IDs $(a,v,z)$ has ASCII length $4(d(a)+d(v)+d(z))+26$. A terminal four-clause pin with IDs $(z,p,q)$ has length $4(d(z)+d(p)+d(q))+28$ when pin zero, and $+24$ when pin one. For a chain starting at private offset $u$, the cumulative length of gates $2,\ldots,t$ equals
\[
26(t-1)+4\{d(1)+d(2)+d(u+1)
+D(u+t-2)-D(u)+D(t)-D(2)+D(u+t-1)-D(u+1)\}.
\]
Empty ranges evaluate to zero. $D(t)$ is computed exactly by counting digit-length intervals. A child has at most two canonical chains; given an arbitrary requested output-character position, determine whether it is in the header, use chain offsets and binary search on gate prefix length, serialize just the selected 4-clause gate/pin, and return its character. Beyond the actual child length, return blank. Exhaustive local checks against fully materialized reference text passed. The child descriptor needs $O(\log N)$ bits and the accessor needs $O(\log b)$ digit-prefix evaluations, charged separately from source authentication and unknown guest-machine emulation.
