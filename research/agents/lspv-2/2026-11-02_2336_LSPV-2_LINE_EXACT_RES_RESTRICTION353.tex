\begin{lemma}[Previously established paid weakening, LSPV-2 352]

\end{lemma}
\begin{theorem}[All-line restriction compiler for arbitrary signed Resolution DAGs]

\]
For every processed original line with nontrue restriction, before the first empty conclusion, the translator constructs a named clause \emph{exactly equal} to that line's restricted clause, not merely a subsuming clause. A straightforward explicit signed proof stream has $O(N+qn^2\log(N+qn+2))$ bits, where $N=|\operatorname{enc}(F)|$, using the conventional signed variable and parent identifiers.
\end{theorem}
\begin{proof}
Map each original source to its specialized clause, dropping clauses made true by $\rho$. Any empty source already refutes $F|_\rho$. Now process the original derivation in topological order. For a Resolution step from $(p\vee A)$ and $(\neg p\vee B)$, its desired restricted output is $D=(A\vee B)|_\rho$. If $D$ is true, discard the line. When pivot $p$ is unassigned, both nontrue specialized premises retain complementary $p$, and a single ordinary Resolution inference yields exactly $D$. When $p$ is assigned, one antecedent becomes true by its pivot and the surviving premise restricts to a clause $C\subseteq D$. If $C$ is empty, stop. If $C=D$, reuse the existing source or derived reference. Otherwise $D\setminus C$ is a compatible nonempty extension, so the paid-weakening lemma reconstructs \emph{exactly} $D$. Writing $k=|C|$, $r=|D\setminus C|$, and $d=k+r=|D|\le n$, the local charge is $3k+2r-2=k+2d-2\le3n-2$. Each original inference incurs at most the displayed bound. Every fresh defining node is a conservative gate, every defining slot is explicitly referenced, and every Resolution pivot is checked. Sharing is preserved via the original-node map. Finally, the original last clause is empty, and so is its restriction. Each weakened step uses $d-1\le n-1$ new gates; intermediate signed clauses have $O(n)$ literals and node identifiers use logarithmic bits, proving the stated evidence bound.
\end{proof}
