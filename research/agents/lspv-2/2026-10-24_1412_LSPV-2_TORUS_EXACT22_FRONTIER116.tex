\section{Strict exact-(2,2) toroidal component}
Fix \(h\ge6\) divisible by three. Let \(x_{r,c}\) for \((r,c)\in\mathbb Z_h^2\) be \(h^2\) vertex variables. For every horizontal edge from \((r,c)\) to \((r,c+1)\) introduce one new \(z_e\), and likewise for each vertical edge from \((r,c)\) to \((r+1,c)\). There are \(M=2h^2\) edge variables. Introduce original proper ternaries
\[
(x_{r,c}\vee x_{r,c+1}\vee z_e)\quad\text{and}\quad
(\neg x_{r,c}\vee\neg x_{r+1,c}\vee z_{e'}).
\]
Index the \(M\) edge variables by alternating horizontal and vertical edges. For each \(g\in\{0,1,2\}\), cyclically group all \(M\) variables into consecutive disjoint triples with offset \(g\). At \(g=0\) add the all-positive clauses on its \(M/3\) triples. At \(g=1,2\) add all-negative clauses on their two disjoint triple partitions. No partition reuses a triple when \(h\ge6\). The component has
\[
 n_G=3h^2,\quad m_G=4h^2,\qquad
\operatorname{occ}^{+}(v)=\operatorname{occ}^{-}(v)=2.
\]
Every \(x\) has two positive horizontal and two negative vertical occurrences. Every \(z\) has one positive edge occurrence, one positive triple occurrence, and two negative triple occurrences. Every triple consists of distinct sources; no signed clause is duplicated. Choosing all \(x=1\), horizontal \(z=0\), vertical \(z=1\) satisfies all edge clauses and all three triple partitions, because any three consecutive alternating \(z\) sources contain both polarities of these model values.

\section{Connected opposite-label splice}
Let \(U\) be the original 198-variable/264-clause signed exact-(2,2) UNSAT source from DOECKER-CORE-CERT61, and \(V\) its two-sign-swap SAT neighbor. The unchanged first 254 U clauses have a separately verified local-projection UNSAT certificate. In the SAT witness for V, the balancing clause 254 is \((x_1\vee x_{33}\vee x_{65})\), with \(x_1=1,x_{33}=x_{65}=0\). Disjointly rename the toroidal source variables after the 198 fixed core identifiers. In the first horizontal edge clause, exchange the positive occurrence \(z_{\mathrm H,0}\) with the positive occurrence \(x_{33}\) from core clause 254. Hence core clause 254 becomes \((x_1\vee z_{\mathrm H,0}\vee x_{65})\), and that horizontal edge clause contains \(x_{33}\) in place of \(z_{\mathrm H,0}\).

\begin{theorem}[Strict exact-(2,2) opposite-label frontier, PROVED/EXACT under supplied core certificate]
For each \(h\ge6\) divisible by three there are connected proper signed exact-(2,2) 3-CNFs \(F_h^{\rm SAT},F_h^{\rm UNSAT}\) with
\[
n=3h^2+198,\qquad m=4h^2+264,\qquad 4n=3m,
\]
the same ordered unsigned clause supports and exactly two opposite sign fields, one SAT and the other UNSAT. Every permutation of their original three-literal clauses, interpreted as a valid single-interval \(\mathrm{OPEN}/\mathrm{CLAUSE}/\mathrm{CLOSE}\) source stream without rewriting an original clause, has maximum live original-source width
\[
w\ge\left\lceil\frac h2\right\rceil
=\Omega\!\left(\sqrt{\frac{N}{\log N}}\right).
\]
The bound remains true if source-preserving extra clauses and auxiliaries are inserted while the original grid clauses remain intact.
\end{theorem}
\begin{proof}
The positive-positive exchange preserves every signed occurrence quota and introduces no repeated clause or repeated variable within a clause. The torus incidence graph is connected, and the core is joined to it through two swapped source occurrences. The SAT witness extends the fixed V witness by \(x=1,z_{\mathrm H}=0,z_{\mathrm V}=1\): the changed core clause is still satisfied by \(x_1\), while the changed horizontal edge clause is still satisfied by its two vertex literals. The UNSAT member retains untouched all 254 source clauses of the independently refuted U subcore, hence is UNSAT. Both formulas differ only at the two fixed signs of core source \(x_3\).

For the width claim, expose the torus's \(2h^2\) distinguished edge clauses in the order induced by an arbitrary global clause permutation. Cut immediately after the first \(h^2\) such clauses. Color these edges A and the other \(h^2\) edges B. Let \(b\) denote the number of toroidal vertex sources incident to at least one edge of each color. Those \(b\) sources occur in clauses on both sides of the cut and are live. At least \(h-b\) complete rows and \(h-b\) complete columns contain no mixed vertex. Every edge in any such row or column has one common color, since differently colored adjacent edges would share a mixed vertex. Every intact row intersects every intact column, so \emph{all} such rows and columns share that same color. They contain at least \(2h(h-b)\) distinct grid edges. If \(b<h/2\), this number exceeds \(h^2\), contradicting that either color occupies only \(h^2\) edges. Hence \(b\ge h/2\). Added clauses cannot erase occurrences on either side; source renaming alone cannot break the shared identity of one toroidal vertex. Finally, the fixed four-word encoding with
\(w_{\rm rec}=\lceil\log_2(64(n+m+1))\rceil\) has
\(N=(4m+2)w_{\rm rec}=\Theta(h^2\log h)\).
\end{proof}

\section{No compulsory rich representation}
A \emph{different} total uniform exact policy performs canonical ordered-source recognition: infer \(h\) from header counts, generate and compare the expected \(O(m)\) clause records using counters and modular arithmetic, keep two Boolean flags for the U/V alternatives, then accept or reject the fully matched fixed-template input. The template core is finite, and its witness and refutation are checked by the included source certificates. This recognizer takes \(O(N\operatorname{polylog}N)\) time and \(O(\log N)\) counted work bits on recognized, canonically ordered members, without storing a separator table. If either template fails, select a complete general-purpose exact DPLL fallback. Correctness is all-input; the small resource bound is only on the recognized subfamily. A clause multiset/sorted recognizer could support shuffled sources at larger space. The selected method need not build the exponentially wide original-clause boundary relation.

The two standard initial restricted shortcuts also fail: all variables occur four times, no complementary-clause contraction pair exists, and there are \(m>n\) original clauses, so a clause-to-distinct-source Hall matching cannot cover the original clauses. The tests are only \emph{sufficient} shortcuts; their failure does not imply UNSAT or hardness.
