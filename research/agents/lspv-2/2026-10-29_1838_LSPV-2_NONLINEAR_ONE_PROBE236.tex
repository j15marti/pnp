\section{PROPOSE: target and falsifiable mechanisms}
The immediate missing lemma following CONTEXTUAL-VALUE-HAMMING235 is whether its $Q=1$ linear-code point remains optimal when the summarizer and the continuation use unrestricted deterministic nonlinear computation. Here $Q$ is a \emph{bit-probe coordinate}, not total running time. We test three mechanisms.
\begin{description}
\item[]\textbf{M1 (nonlinear escape).} A one-bit nonlinear encoding can beat the code-derived storage bound for a fixed $b$. \textbf{FALSIFIED/RESTRICTED} by Theorem~\ref{th:main}; exhaustive at $b=3,4$.
\item[]\textbf{M2 (adaptive one-probe escape).} An adaptive query can choose its only source address from a previously observed source bit. \textbf{FALSIFIED/EXACT}: before the first probe there is no observed source bit, and the address depends only on the stored summary and query.
\item[]\textbf{M3 (intrinsic or additive fact utility).} The value of a certified piece of information is intrinsic, always nonnegative on every plausible scoring scale, and additive across facts. \textbf{FALSIFIED for specified scores}: redundant and complementary XOR rows have different contextual values; a realized Shannon-entropy score can be negative, although its expected value is nonnegative.
\end{description}

\section{Exact two-stage task and full quantifiers}
Let $a=(a_1,\dots,a_b)\in\F^b$ be the source encoded as the canonical unary CNF
\[
 A_a(X)=\bigwedge_{i=1}^b (x_i=a_i).
\]
The future continuation, not known during preprocessing, is the affine predicate $B_{w,t}(X)=[w\cdot X=t]$, $w\in\F^b$, $t\in\F$. For all source/query pairs,
\[
 \operatorname{SAT}(A_a\wedge B_{w,t})\iff w\cdot a=t.
\]
The preprocessor is an arbitrary \emph{deterministic} map $\sigma:\F^b\to\{0,1\}^{\le L}$, possibly nonlinear, with all source-dependent persistent state charged in $\sigma$. After reading $(\sigma(a),w)$, the continuation may read at most $Q=1$ coordinate of the \emph{retained, read-only original source} $a$, adaptively as permitted, and must correctly output $w\cdot a$ for every $(a,w)$. Source addresses and query input are known to the algorithm but no a-dependent advice, unknown SAT label or additional uncharged access is allowed. The raw source is retained so an indexed bit probe is legal; no oracle table of future queries is supplied.

\begin{theorem}[arbitrary nonlinear one-probe summary, exact storage]\label{th:main}
For every integer $b\ge1$, the least worst-case maximum stored length $L$ among all deterministic preparers and continuations satisfying the preceding two-stage contract is
\[
\boxed{L_1(b)=b-\left\lfloor\log_2(b+1)\right\rfloor.}
\]
This exact bound allows arbitrarily expensive nonlinear preprocessing, adaptive continuation logic, and stored descriptions of variable length up to $L$. A uniform encoder and decoder attain it with $O(b\log b)$ Boolean operations apart from parsing and source-location arithmetic.
\end{theorem}
\begin{proof}
Put $d=\lfloor\log_2(b+1)\rfloor$. For any summary string $s$, let the nonempty fiber $S_s=\{a:\sigma(a)=s\}$. Choose $a_0\in S_s$, and set $V_s=\mathrm{span}_{\F}\{a+a_0:a\in S_s\}$, $r_s=\dim V_s$. Thus $|S_s|\le 2^{r_s}$. Consider the $2^{r_s}$ distinct restrictions to $S_s$ of the linear characters $a\mapsto w\cdot a$, \emph{modulo global bit complementation}. They are distinct precisely when the corresponding masks induce different linear functionals on $V_s$: the quotient $\F^b/V_s^\perp$ has size $2^{r_s}$.

Fix $s,w$. Before its only permitted raw-source probe, a deterministic decoder has seen no source-dependent information beyond $s$, so it chooses either no probe or some fixed coordinate $i=i(s,w)$. On $S_s$, its output is therefore either a constant or a Boolean function of one coordinate $a_i$. Up to complementation, the possibilities are only the constant class and the classes of $a_1,\dots,a_b$, at most $b+1$ classes. Since every parity mask must be supported, $2^{r_s}\le b+1$, hence $r_s\le d$ and $|S_s|\le 2^d$.

For fixed-length $L$, at most $2^L$ summary labels exist, so $2^b=\sum_s|S_s|\le2^{L+d}$, yielding $L\ge b-d$. Even allowing arbitrary binary strings of \emph{length at most $L$}, at most $2^{L+1}-1$ distinct labels exist. If $L\le b-d-1$, then
\[
2^b\le(2^{L+1}-1)2^d\le(2^{b-d}-1)2^d<2^b,
\]
a contradiction. Thus the lower bound holds even without a prefix-free convention. This argument applies to \emph{all} nonlinear summaries and all deterministic one-probe procedures; it does not assume a linear code, affine fibers, or efficient preprocessing.

For the matching upper bound let $h=2^d-1\le b$. Number the first $h$ raw coordinates by nonzero $d$-bit labels $1,\dots,h$, with basis labels $2^j$, $0\le j<d$. Store
\[
 \sigma_i=a_i\oplus\bigoplus_{j:\operatorname{bit}_j(i)=1}a_{2^j}
 \quad\text{for nonbasis }i\le h,
 \qquad \sigma_i=a_i\quad\text{for }i>h.
\]
There are precisely $(h-d)+(b-h)=b-d$ stored bits. For any mask $w$, XOR the relevant stored bits and compute the label $c=\bigoplus_{i\le h:w_i=1}i\in\F^d$. After this computation the only unknown contribution to $w\cdot a$ is $\bigoplus_{j:\operatorname{bit}_j(c)=1}a_{2^j}$. If $c=0$ this is zero. Otherwise the original coordinate $a_c$ has exactly this linear form, up to $\sigma_c$ if $c$ is not a basis label. Read \emph{only} $a_c$, apply the stored correction when needed, and output the exact parity. The labels, encoder and decoder are uniform in $b$; source parsing, stored-record construction, index arithmetic and mask scanning all take polynomial time. This proves equality.
\end{proof}

\begin{proposition}[two-stage context firewall]\label{prop:firewall}
Theorem~\ref{th:main} gives no lower bound for a joint solver that receives $a,w$ simultaneously, or for a preprocessor that knows $w$. The joint solver reads the $b$ source bits and computes $w\cdot a$ in polynomial time. If $w$ is known during preparation, a single stored result bit answers that one fixed query without any subsequent raw source probe. Conversely, if \emph{all future source access is forbidden}, $w=e_i$ for each coordinate recovers $a$ from the reusable state; hence at least $b$ fixed summary bits are necessary.
\end{proposition}
\begin{proof}
The joint upper and query-specific preprocessing are direct parity calculations. For the source-free reusable lower bound, if $a\ne a'$ share the same state, choose $i$ with $a_i\ne a'_i$. The unit-mask query $w=e_i$ would require different outputs without source access. Thus all $2^b$ source words require distinct summary states, which need $b$ fixed bits.\end{proof}

\section{Charged construction, storage and continuation ledger}
Native model: a deterministic indexed bit-RAM with $O(\log N)$-bit addresses. The canonical source formula has $N=\Theta(b\log(b+1))$ input bits, including variable identifiers and sign fields. The read-only source remains accessible. The protocol must parse source structure/validity, read the $b$ signs, compute $L_1(b)$ cached bits, subsequently scan each full query mask, compute index $c$ and any stored parity, and execute zero or one source-bit probe. The explicit algorithm has
\[
P(N)=O(N+b\log b),\quad L=b-d,\quad
T_{\mathrm{query}}(N)=O(b\log b),\quad Q_{\mathrm{source}}\le1.
\]
For $m$ future queries, a constructive amortized upper ledger is $O(N+b\log b+mb\log b)$ bit operations, including every query and every read and address calculation; no failed candidate-search policy is used. The peak \emph{writable} memory is $L+O(d+\log N)$ bits in a bit-addressed streaming implementation (the query and original source are read-only). The source footprint $N$ is separate. At fixed $L=b-d$, storing $L$ literal source coordinates would require $d$ probes for the parity mask supported on the other $d$ coordinates; the coded scheme uses one. This is a restricted storage/query dominance, not a claim that coding makes total time smaller.

A two-tape Turing implementation with sequential read-only input and one writable work tape additionally charges input scans and head motion. The one raw sign-field probe may require $O(N)$ physical head steps; a conservative per-query upper bound is polynomial in $N+b\log b$ with $L+O(\log N)$ writable cells, subject to the input/work head separation. A single read/write tape counts input plus summary in its footprint and requires transport, relocation and crossings; no RAM probe lower bound is imported into that machine. A fixed universal interpreter adds its own simulation overhead. The Python timer/\texttt{tracemalloc} measurements below are \emph{not} any of these native machine-space theorems. Symbol changes, output construction, retained source, and score discovery are not zero by convention.

\section{Certified contextual information-value records}
For a target $T$ and knowledge $K$ consisting of authenticated affine equalities, define the independently specified finite \emph{projected-support ambiguity} potential
\[
\Phi_T(K)=\log_2\big|\{T(a):a\text{ satisfies }K\}\big|,
\]
when $K$ is consistent. A fact $I$ with provenance, source-row certificate, acquisition cost and application cost receives the contextual notation $I\mid_{v}$, where $v=\Phi_T(K)-\Phi_T(K\cup\{I\})$. The pipe is a score annotation, \emph{not} probability conditioning or divisibility. The interpreter separately charges the full $2^n$ enumerations used to discover the score; it supplies neither a free satisfying assignment nor an UNSAT answer bit. Its certified facts are verified as exact input rows; a negative literal claim cannot be accepted merely by its appearance as a token.

With target $T=a\oplus b$, first source row $I_1=(a\oplus c=0)$ and second $I_2=(b\oplus c=0)$, the exact gain of either alone is zero but
\[
 I_1\mid_0,\quad I_2\mid_0,\quad
 I_2\mid_{1}\ \text{after }I_1,\qquad I_1\mid_0\ \text{after both}.
\]
This certifies synergy and redundancy under this one explicit, target-relative scale. The monotone ambiguity score does not become negative for any consistent refinement. Under a \emph{different} realized Bayesian entropy score, a biased target with prior $P(T=1)=0.1$ and a positively observed event with likelihoods $P(E\mid T=0)=0.1$, $P(E\mid T=1)=0.9$ yields posterior $P(T=1\mid E)=0.5$. Its raw realized entropy value is
\[
 h_2(0.1)-h_2(0.5)\simeq-0.5310044\ \text{bits},
\]
while expected information gain is positive ($\simeq0.2110815$ bits). This second score is a separate \emph{observational} control and not a SAT-certificate potential. Different scales and dependent facts cannot be added into a universal efficiency metric. Finally, cost $C_s(I)$ must include finding, checking, applying \emph{and computing the score}; the ratio $v/\max(1,C_s(I))$ remains heuristic absent a proved per-transition progress theorem.

\section{Independent tests, hostile controls, and residual gaps}
The dependency-free Python reproducer deterministically checked all $\sum_{b=1}^{9}4^b=349{,}524$ source/mask pairs and the exact zero/one probe bound. It exhaustively enumerated \emph{every} one-bit nonlinear preprocessing map for $b=3$ ($256$ maps, exactly two valid) and $b=4$ ($65{,}536$ maps, none valid). It independently checked 10,920 two-stage $A_a\wedge B_{w,t}$ SAT evaluations for $b\le6$ by enumerating the $X$ assignments; and checked exact two-positive/two-negative signed quotas, connectivity and labels for the three-variable parity SAT source (4 models) and the 15-variable $W_1$ UNSAT source (zero of $2^{15}$ models). Separate 2SAT, XOR and mixed CNF controls cover both labels. Seed 236 was used only for explicitly marked larger-instance samples and paired same-execution Python resource readings. No randomized benchmark establishes the theorem. Execution and raw results are in the companion Python and JSON files.

\noindent\textbf{Easy-family attacks.} Direct algebraic parity evaluation, Hamming/Tseitin encodings, original-formula retention, caching, duplicate facts, two-source joint preprocessing and source-free query injection all remain legal controls. Any unrestricted SAT algorithm could use a different representation or see $A$ and $B$ simultaneously; Theorem~\ref{th:main} does not constrain it. The proof is insensitive to SAT-versus-UNSAT labels because it distinguishes each $w\cdot a$ outcome for all $(a,w)$; nevertheless the source grammar is unary CNF plus XOR continuation, not connected strict22, so no reduction or closure is claimed. The lower bound uses an explicit restricted one-bit read model, hence is not an oracle-independent time lower bound; an oracle returning any queried parity in one action bypasses its primitive-bit budget. The construction is polynomial-time and requires no unknown witness, so no natural-proofs, algebrization or nonrelativizing separation statement follows.

\noindent\textbf{What's changed.} Unlike HAMMING235, whose matching $Q=1$ lower bound assumed a \emph{linear} summary, the present fiber argument covers \emph{all deterministic nonlinear, variable-length summaries}, without making the preprocessing polynomial-time for purposes of the lower bound. Prior sources and root conclusions are retained. \textbf{Next specific lemma (OPEN):} determine the optimal storage length $L_2(b)$ for arbitrary nonlinear summaries allowing \emph{two} adaptive post-preprocessing source probes, and construct an independent lower bound in that exact model; then attempt a charged reduction from nontrivial connected strict22 boundary profiles with original source retention and query-varying contexts. $P=NP$ and $P\ne NP$ remain OPEN.
