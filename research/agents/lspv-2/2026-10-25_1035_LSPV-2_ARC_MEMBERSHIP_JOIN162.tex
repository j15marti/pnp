\section{Source-named module relation and the exact signature}
Let $Y=(y_1,\ldots,y_k)$ contain identical ORIGINAL source identities
throughout $q$ modules, and let $U_1,\ldots,U_q$ be pairwise disjoint
private-name sets. Fix ordinary signed CNF modules $D_i(Y,U_i)$ and
put $F=\bigwedge_iD_i$. Each original signed source clause is assigned to
its actual module, with source identity and both labels preserved. Write
$X=\{0,1\}^k$ and
\[
P_i=\{u\in X:\exists U_i\,D_i(u,U_i)\},\qquad
\sigma(u)=({\bf1}_{u\in P_1},\ldots,{\bf1}_{u\in P_q}).
\]
The sets $P_i$ and the signature $\sigma$ are SEMANTIC, not free source
representations or guest answers. A common continuation $C(Y,W)$ uses
private $W$ disjoint from all $U_i$; define $S_C=\{u:\exists W C(u,W)\}$.

\begin{theorem}[Canonical minimal filter-commuting quotient]
For a map $h:X\to H$ the following are equivalent:
\[
\forall i,S\subseteq X:\ h(P_i\cap S)=h(P_i)\cap h(S), \tag{FC}
\]
\[
h(u)=h(v)\Longrightarrow \sigma(u)=\sigma(v)\quad(u,v\in X). \tag{REF}
\]
Thus $h=\sigma$ is, up to label renaming, the coarsest such quotient,
using at most $\min(2^k,2^q)$ realized labels. Further, for EVERY $S$,
\[
\bigcap_iP_i\cap S\ne\varnothing
\iff {\bf1}^{q}\in\sigma(S)
\iff \bigcap_i\sigma(P_i)\cap\sigma(S)\ne\varnothing .
\]
In particular this holds for the projected support $S=S_C$ of ANY
ordinary common-CNF continuation with fresh private auxiliaries.
\end{theorem}
\begin{proof}
For (FC)$\Rightarrow$(REF), if $h(u)=h(v)$ but $u\in P_i$ and
$v\notin P_i$, take $S=\{v\}$. The right side of (FC)
contains $h(u)$, the left is empty, contradiction.
For (REF)$\Rightarrow$(FC), if $c=h(u)=h(v)$ with $u\in P_i$
and $v\in S$, then (REF) implies $v\in P_i$, so
$c\in h(P_i\cap S)$. The other inclusion is automatic.
Every $h$-fiber satisfying (REF) lies in a single $\sigma$-fiber;
$\sigma$ attains that coarsest partition and has at most $2^q$ labels.
For the boxed join criterion, a word lies in all the $P_i$ iff
every bit of $\sigma(u)$ equals one. No free computation is claimed.
\end{proof}

\section{Pairwise checks sufficient for all module counts}
For a label $c$ put $C_c=h^{-1}(c)$ and $P_i^c=P_i\cap C_c$.
\begin{theorem}[Nested fibers compose under common filters]
If for every label $c$ and pair $i,j$ the two sets $P_i^c,P_j^c$
are nested by inclusion, then for every $S\subseteq X$,
\[
 [\bigcap_i(P_i\cap S)\ne\emptyset]
 =
 [\bigcap_i h(P_i\cap S)\ne\emptyset].
\]
This nesting condition is equivalent to exactness for each individual
two-module pair under EVERY common filter (the prior
ARC-CNF-CONTINUATION121 condition). It is sufficient but NOT necessary
for the full $q$-way condition when $q\ge3$.
\end{theorem}
\begin{proof}
The forward implication is trivial. If the quotient accepts on
color $c$, then every $P_i^c\cap S$ is nonempty. The finite
pairwise nested family is a chain. Its smallest set, say $P_j^c$,
has a word $u\in S$ and is contained in every $P_i^c$.
Hence $u$ is an actual common witness.
For a two-module pair, if neither set is contained in the other,
choose $u\in P_i^c\setminus P_j^c$ and
$v\in P_j^c\setminus P_i^c$; $S=\{u,v\}$ yields a false SAT quotient.
For non-necessity at three modules, take
$P_1=\{0,3\},P_2=\{1,3\},P_3=\{3\}$ and
$h(0)=h(1)=0,h(3)=1,h(2)=2$.
The triple filter-join is exact for every $S$, because the third
module only contributes color 1 of the true shared word 3, but
$P_1^0=\{0\}$ and $P_2^0=\{1\}$ are incomparable.
\end{proof}
The pairwise two-module theorem itself is PREVIOUS WORK of Role 3;
only the explicit composition and the stronger modulewise (FC)
scope are added here. Pairwise SAT-status bits alone DO NOT suffice
for three-way joins, as THREE-FACTOR-GLUE149 already established.

\section{Actual assumption-dependent all-input wrapper and charged ledger}
Fix ONE total exact ordinary-SAT decider $A$, polynomial only if $P=NP$.
The wrapper validates an explicitly supplied source-named decomposition:
every parent clause covered, identical boundary name map, disjoint
module-private names, and valid signed ordinary encodings. If validation
fails, or input is unsupported/malformed, call $A$ on the ORIGINAL full
input and return its exact result. On a valid source, enumerate every
boundary word $u\in X$. Construct the ACTUAL proper-3CNF child
$D_i\wedge\operatorname{PIN}(Y=u)$ for each module and execute $A$
on its ordinary encoded bits. Return SAT if all $q$ modules accept one
and the same $u$, else UNSAT after checking all words.
The pin for a literal $\ell$ is four proper ternaries with fresh
private $a,b$:
\[
(\ell\lor a\lor b)\land(\ell\lor a\lor\neg b)\land
(\ell\lor\neg a\lor b)\land(\ell\lor\neg a\lor\neg b).
\]
Its existential projection enforces exactly $\ell$. Hence $k$ pins
write $4k$ genuine ternaries and $2k$ new private names, with complete
headers and charged source identifiers. Parent SAT iff some common
boundary word makes every actual module-child SAT; UNSAT iff all
boundary words fail. No child is replaced by a free oracle bit.
Children need not satisfy any restricted M22 or scoped-input grammar.
A second level is correct as ordinary SAT but cannot be assumed
eligible for the same favorable decomposition.

Suppose $q\le N^{a+o(1)}$, $2^k\le N^{b+o(1)}$,
$L_{\max}\le N^{\lambda+o(1)}$ including pins and headers,

$g$, parent/generator live workspace exponent $\eta$, retained

\[

\begin{lemma}[Verbatim partition and full-table eager replay toll]
For a DENSE noncompressing indexed original formula of length
$N=\Theta(m\log m)$, suppose every original source clause, including
its original name fields and signs, appears verbatim in exactly
one of $q$ modules. Then $\sum_i L_i=\Omega(N)$.
Any declared full-table EAGER policy writing every module child
for all $2^k$ boundary words writes $\Omega(2^kN)$ bits
before guest execution. If $q\le N^{a+o(1)}$ and each
$L_i\le N^{\lambda+o(1)}$ this verbatim architecture
requires $a+\lambda\ge1$.
\end{lemma}
\begin{proof}
Summing verbatim clause-record body lengths across the modules counts
the full source once, giving $\Omega(N)$. Repeating these records for
all $2^k$ words emits $\Omega(2^kN)$ actual output bits.
Also $N=O(\sum_iL_i)\le qN^{\lambda+o(1)}$ forces
$a+\lambda\ge1$. The lemma is NOT a lower bound for arbitrary SAT
deciders, short-circuiting evaluators, lazy generators or semantic
source compressors; it is a precise restriction on the stated eager
verbatim architecture. In particular $L=N^{1-o(1)}$ never certifies
fixed-power shrinkage.
\end{proof}
The all-input wrapper's full-parent fallback consumes
$N^{t+o(1)}$ time and $N^{s+o(1)}$ indexed workspace when invoked.
It therefore provides NO favorable all-input ARC edge. Signature
construction from $A$ depends on the assumed correctness/existence
of $A$ and is not an unconditional source-only cheap splitter.

\section{Two actual ordinary-CNF levels falsify stale heredity}
Let ORIGINAL common source name be $x=1$. With private names
$a,b$ in $D$ and $c,d$ in $R$ define
\[
D=(x\lor a\lor b)\land(\neg x\lor a\lor b),\qquad
R=(x\lor c\lor d)\land(\neg x\lor c\lor d).
\]
Both modules project to the two boundary words $\{0,1\}$,
so the root membership signature gives both words the same
label $(1,1)$. Construct genuine source-preserving proper-3CNF
formulas
\[
F_0=D\land R,\quad
F_1=(D\land\operatorname{PIN}(\neg x))\land R,\quad
F_2=(D\land\operatorname{PIN}(\neg x))
       \land(R\land\operatorname{PIN}(x)).
\]
All pin auxiliary names are fresh and no original identity
is changed. An independent exact ordinary-CNF DPLL returns
SAT, SAT, UNSAT, respectively. The stale root signature
still reports SAT at level two because both boundary words
retain the original label $(1,1)$; recomputing the correct
second-level signatures $(1,0)$ and $(0,1)$ rejects.
This is a real second-level module-specific failure, not a
failure of the common-filter theorem, whose fixed-modules
hypothesis is expressly different.

For each of $F_0,F_1,F_2$ the program additionally executes
two actual proper-3CNF restriction levels on original $x$
and one original private name, serializes and reparses all
child headers/bodies, executes exact DPLL on all grandchildren,
and independently compares the OR join with the root answer.
There are 6 genuine children and 12 genuine leaf decisions.
Root encoded lengths are 352, 672, 968 ASCII bits, while
their emitted child-and-grandchild totals are respectively
5184, 7408, 9536 bits. Nothing power shrinks.
