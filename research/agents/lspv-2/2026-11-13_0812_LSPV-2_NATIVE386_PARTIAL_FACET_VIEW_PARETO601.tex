\paragraph{Declared concrete resources.}
The seed has 17 mandatory original signed SOURCE records, one distinct globally paid owner for $z=x_1\land x_1$, two truthful free DEF clause views, and 31 charged RES records. Each DEF value is consumed exactly once per RES block, at ordinal 29 or 30. Repeat the fixed, source-sharing signed RES body $M$ times and retain a terminal empty clause. A clone is an identical truthful DEF record with the same paid owner and is referenced by at least one legal RES parent; all views may be scheduled before their first use. All original signed RES conclusions, pivots, port clause values and SOURCE occurrence identities remain unchanged; the number of paid identities is \emph{not} the number of DEF views. Logical work is $W=31M+1$, with 31 RES per block and the paid owner counted once. In the declared last-use memory model, a DEF view is live from its first RES consumer to its last RES consumer inclusive, and contributes one slot at each RES checkpoint. Facet-slot area sums this count over all $31M$ checkpoints. This is \emph{not} actual checker RAM, nor proof-search time, certificate bits, or physical space.

\paragraph{Theorem 601.1: exact all-intermediate area envelope.}
For each of the two distinct facet values $i\in\{1,2\}$ fix $c_i\in\{1,\ldots,M\}$ nonempty clone identities, total $v=c_1+c_2$. The minimum area of all legal use-to-clone assignments, with the RES body and its fixed chronological block order preserved, is
\[
\boxed{A_{\min}(M,c_1,c_2)=31(2M-c_1-c_2)+(c_1+c_2)=62M-30v,\qquad 2\le v\le 2M.}
\]
It is simultaneously attainable with modeled peak 2 if $v<2M$, and modeled peak 1 if $v=2M$. \emph{Proof:} A clone used at $q$ distinct block positions has first-to-last consumer span at least $31(q-1)+1$ checkpoints. Summing over the $c_i$ clones, whose uses total $M$, gives at least $31(M-c_i)+c_i$ for each facet. Partition its $M$ consecutive block uses into $c_i$ nonempty contiguous groups. Reemit an identical DEF at the first group's first use and redirect each relevant RES parent; this attains each lower bound exactly. Such clones are accepted by the original DEF branch, which prohibits neither repeated facet values nor reuse of the already paid owner. The model's root views must be alive during each own use. If any view spans two blocks, the other facet has a use between them, forcing peak at least 2; contiguous groups attain 2. If all views are single-use ($v=2M$), the two usages are at distinct steps and peak is 1. QED.

\paragraph{Theorem 601.2: unbounded same-count identity-to-use scheduling gap.}
For each $k\ge2$ set $M=2k$, $c_1=c_2=k$, $v=2k$. In a contiguous assignment each clone is used at two consecutive blocks. The exact modeled area is $64k$ and peak is 2. In a legal interleaved assignment each clone of either facet is used in blocks $b$ and $b+k$, for $b=0,\ldots,k-1$. Every clone has an inclusive live interval $31k+1$, so
\[
\boxed{A_{\mathrm{interleaved}}=2k(31k+1),\quad P_{\mathrm{interleaved}}=2k;\quad A_{\mathrm{contiguous}}=64k,\quad P_{\mathrm{contiguous}}=2.}
\]
After $k$ blocks every interleaved view has been consumed once and no view has completed its second use. Thus peak $2k$ is attained. The area ratio is $(31k+1)/32=\Theta(k)$ and the peak ratio is $k$. Both have the \emph{same} signed RES occurrence body, $2k$ truthful DEF views, one paid owner, same SOURCE and paid $W=62k+1$. Therefore scalar counts of owners, views, clauses and RES steps cannot determine exact retained facet space; view-to-consumer identity is indispensable for any exact-space transformer. This does not preclude a coarser lower-bound MAY abstraction.
