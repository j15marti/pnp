\section{Frozen-code lemma: the precise new quantifier refinement}
Fix any \emph{actually existing known} exact total ordinary-SAT decider $A_0$, such as exhaustive assignment search. A finite offline transformation may inspect the \emph{entire fixed program text} of $A_0$, specialize its controller $Q[A_0]$, hardwire a different selection rule, and choose subsequent ordinary SAT queries adaptively. During online execution, however, each invocation of $A_0(y)$ exposes only $\SAT(y)\in\{0,1\}$, not runtime, internal state, clocks, traces or hardware.

\begin{theorem}[Static-code frozen downward elimination; scoped corollary of previous elimination]
Suppose this one fully specified $Q[A_0]$ decides SAT correctly on \emph{every ordinary encoding} (rejecting invalid encodings). Its online nonoracle bit work is $N^{r+o(1)}$; its number of ordinary SAT-bit queries is at most $N^{a+o(1)}$; each has actual encoded size at most $N^{\lambda+o(1)}$ with $\lambda<1$; and its peak simultaneous writable/index footprint is $N^{h+o(1)}$, including program-text-derived strategy work, discovery, switching, failed trials, source reads and writes, headers and bodies, control, query buffers, retained ancestors and caches. Then there is an \emph{unconditional}, single uniform total correct ordinary-SAT decider $B$ with
\[
T_B(N)\le N^{\tau+o(1)},\qquad S_B(N)\le N^{\sigma+o(1)},\qquad
\tau=\max\{1,r,a/(1-\lambda)\},\quad \sigma=\max\{h,\lambda\}.
\]
If $h$ already counts readable query tapes, the extra $\lambda$ is redundant. In particular a static-code-only contractor with $(r,a,\lambda,h)=(11/10,3/5,1/2,1/2)$ on all ordinary inputs is impossible.
\end{theorem}
\begin{proof}
Freeze the entire particular program $Q[A_0]$, including every constant derived offline from the known finite code of $A_0$. Replace each invocation $A_0(y)$ by a recursive invocation of $B(y)$. Since $\lambda<1$, recursion is well founded above a sufficiently large constant threshold. For smaller strings, a finite exact table is computed using the known exhaustive solver. Strong induction proves that all queried membership bits, adaptive rule choices, and root decisions agree with the original correct $Q[A_0]$, for SAT and UNSAT parents, including invalid-string convention. The program may differ for \emph{another} solver's static code; no cross-program equivalence is claimed.

Every executed recursive branch has $T(N)\le N^{r+o(1)}+N^{a+o(1)}T(N^{\lambda+o(1)})$, yielding the asserted $\tau$ by exponent induction. Depth-first simulation retains charged work/index/guest query buffers and ancestors over scales $N,N^\lambda,N^{\lambda^2},\ldots$, giving $\sigma$ with polylogarithmic index overhead. A virtual child requires charged per-bit indexed reconstruction, not free reuse of a write-only output. All one-machine resources are simultaneous. The numerical target would yield $(\tau,\sigma)=(6/5,1/2)$ in the FLMV forbidden strict box, contradicting FLMV's SAT transfer. Thus this precisely scoped object cannot exist.\qed
\end{proof}
\paragraph{Critical escape.} The known $A_0$ is not asserted polynomial time. A different compiler existing \emph{only when some unknown fixed polynomial-time} $A_\star$ exists under $P=NP$ need not instantiate at $A_0$; a full proof may exploit a charged global polynomial-time guarantee, actual program execution, or other legitimate nonextensional information. This lemma does NOT rule out that genuinely hypothesis-dependent mechanism. Merely reading the frozen code-tag without a promise-sensitive favorable budget cannot supply it.
