\section{Missing lemma and falsifiable mechanisms}
The preceding LSPV-2 SECOND-ORDER FLIP SPECTRUM243 established an exact $O(n+m)$ four-category histogram for every two-variable flip in signed exact-$(2,2)$ source 3-CNF. The missing lemma was whether the exact $\binom n3$ triple-flip histogram could be compiled without constructing those $\Theta(n^3)$ coherent complete assignments. The three candidates were: (i) source-clause third differences supported only where all three variables occur in an original clause; (ii) aggregate correction of exactly-one-edge triples using singleton signatures; (iii) explicit enumeration of the $O(n\Delta^2)$ connected three-vertex interaction clusters. A hostile control tests whether the result actually saves end-to-end SAT work after failed endpoint and radius-three attempts.

\section{Clause-indexed extrema come first}
Let $F=\bigwedge_{j=1}^m C_j$ be a proper original three-CNF with distinct variables within every clause. A signed source occurrence $x_{i,j}$ is \emph{not} an independent Boolean variable. For each $C_j$, let $S_j$ require all its signed literals to be true and $U_j$ require all to be false. For an occurrence $x_i$ in $C_j$, its $S_j$ value is $1$ if positive and $0$ if negative; its $U_j$ value is the complement. Inverting either local target swaps $S_j$ and $U_j$. These targets may conflict across original clauses even when both clauses are ordinarily satisfied (at least one true literal).

For distinct $C_j,C_k$, write $SS,SU,US,UU$ for the simultaneous local all-true/all-false modes. $SS$ and $UU$ are feasible precisely when no shared variable has opposite signs; $SU$ and $US$ are feasible precisely when none has the same sign. This is a \emph{pairwise local} condition, not a global SAT or UNSAT criterion. As a concrete source-connected strict22 control, the first two clauses of $H_1$ are
\[C_1=(x_1\lor x_3\lor x_5),\qquad C_2=(x_1\lor \neg x_3\lor x_6).\]
$S_1$ requires $(x_1,x_3,x_5)=(1,1,1)$ and $U_1=(0,0,0)$; $S_2$ requires $(x_1,x_3,x_6)=(1,0,1)$ and $U_2=(0,1,0)$. Both inversion operations are recorded independently. Shared $x_1$ has equal sign and $x_3$ opposite signs, so all four extreme pair modes are impossible. Nevertheless at the coherent assignment $1^6$, $t_1=3,t_2=2$, and both ordinary disjunctions are SAT. This certifies only that one of these clauses is in the middle state on any full assignment.

For any coherent $a\in\{0,1\}^n$, $t_j(a)$ counts its true original literals and $\vv N(a)=(N_0,N_1,N_2,N_3)$ counts clauses with $0,1,2,3$ true literals. Then
\[t_j(\bar a)=3-t_j(a),\qquad \vv N(\bar a)=(N_3,N_2,N_1,N_0)(a).\]
$F(a)$ is SAT exactly when $N_0(a)=0$; $F(\bar a)$ is SAT exactly when $N_3(a)=0$. Neither failure alone or both failures establish formula UNSAT. The raw machine-readable data gives every source clause index, $S_j,U_j$ and inverses, signed occurrence, $SS/SU/US/UU$ matrix, all coherent endpoint statuses, and each selected flip transition.

\section{Third-order original-clause finite differences}
Fix any coherent base assignment $a$. Write $\vv e_r$ for the unit vector in category $r\in\{0,1,2,3\}$ and $\vv N(S)=\vv N(a\oplus S)$. For a source clause $C_j$ and variable $i\in C_j$, define $\sigma_{ij}=+1$ if its literal is initially false and $-1$ otherwise. Let $t=t_j(a)$. Define the global first-, second-, and third-difference vectors
\begin{align}
\vv d_i&=\sum_{j\ni i}(\vv e_{t_j+\sigma_{ij}}-\vv e_{t_j}),\\
\vv h_{ik}&=\sum_{j\supseteq\{i,k\}}(\vv e_{t_j+\sigma_{ij}+\sigma_{kj}}-\vv e_{t_j+\sigma_{ij}}-\vv e_{t_j+\sigma_{kj}}+\vv e_{t_j}),\\
\vv g_{ik\ell}&=\sum_{j\supseteq\{i,k,\ell\}}
\sum_{R\subseteq\{i,k,\ell\}}(-1)^{3-|R|}
\vv e_{t_j+\sum_{v\in R}\sigma_{vj}}.
\end{align}
For any three distinct original variables, exact finite-difference expansion gives
\begin{equation}\label{eq:third}
\boxed{\vv N(\{i,k,\ell\})=\vv N(\varnothing)+\vv d_i+\vv d_k+\vv d_\ell
+\vv h_{ik}+\vv h_{i\ell}+\vv h_{k\ell}+\vv g_{ik\ell}.}
\end{equation}
The vector $\vv h_{ik}$ vanishes if variables $i,k$ never co-occur in an original clause; $\vv g_{ik\ell}$ vanishes unless an original clause contains the entire triple. Signed clauses, polarity renamings, and global complement are included, with no independent-occurrence assumption.

\section{Exact theorem and proof}
\begin{theorem}[Bounded-occurrence three-flip spectrum]\label{thm:main}
For every integer $n$, every proper source three-CNF $F$ on $n$ original variables with each variable occurring in at most $d$ original clauses, and every coherent complete assignment $a$, there is a deterministic exact algorithm returning the multiset
\[\mathcal H_3(F,a)=\{\vv N(a\oplus S):S\subseteq[n],\ |S|=3\}\]
as a compressed histogram, without enumerating $\binom n3$ flipped assignments. In an indexed $\Theta(\log N)$-word RAM, for fixed $d$ the time and working words are $O(n+m)$, including reading all source clauses and discovering interactions and signatures. The output stores exact integer multiplicities. The special class of connected proper signed exact-$(2+,2-)$-3CNF has $d=4$, $m=4n/3$, and interaction degree $\Delta\le8$.
\end{theorem}
\begin{proof}
Build the original-variable co-occurrence graph $G_F$: two original variables are adjacent if they share a source clause. Its maximum degree is $\Delta\le2d$; it has at most $3m$ edges. Scan the input once to compute $\vv N(\varnothing)$, $\vv d_i$ and the nonzero-possible $\vv h_{ik},\vv g_{ik\ell}$ from original clause IDs. Each variable has at most $d$ local singleton transition contributions, each drawn from the six possible unit-vector differences $\vv e_{t\pm1}-\vv e_t$; therefore at most $B\le6^d$ distinct signatures $\vv d_i$ exist, independent of $n$ when $d$ is fixed.

First form the \emph{baseline} aggregate histogram for all unordered triples from the signature multiplicities. Each multiset of three signatures $(u,v,w)$ contributes $\prod_s \binom{b_s}{r_s}$ to vector $\vv N(\varnothing)+u+v+w$, where $b_s$ is the number of source variables of signature $s$ and $r_s$ its multiplicity in the three chosen signatures. This takes $O(B^3)$ word operations and counts every original-variable triple exactly once, but omits pair and triple interactions.

Partition triples with at least one induced edge of $G_F$ by their number of edges. For a triple with \emph{exactly one} edge $ik$, its third vertex $\ell$ lies outside $\{i,k\}\cup N(i)\cup N(k)$. For each edge and each of the $B$ signature buckets, its exact number of such third vertices equals the bucket size minus the number in this explicitly bounded forbidden neighborhood. Move that entire count from the baseline vector to the corrected vector $\vv N(\varnothing)+\vv d_i+\vv d_k+\vv d_\ell+\vv h_{ik}$. The number of such aggregate corrections is $O(|E|B)$, with $O(\Delta)$ accounting per edge for forbidden signatures. No triple with at least two edges is touched here.

Every triple with at least two induced edges has a vertex adjacent to its other two vertices. Enumerate such connected triples as unordered pairs in each vertex's neighborhood, deduplicating their variable-index triples. There are at most $n\binom\Delta2=O(n\Delta^2)$ candidates. For each, replace its baseline vector by the exact expression (\ref{eq:third}); the latter includes every pair and any source-clause triple correction. These two correction passes are disjoint and exhaustive. No triple with zero edges needs correction. All negative temporary bucket entries cancel, leaving the exact multiplicities, which sum to $\binom n3$. The algorithm therefore takes $O(n+m+B^3+|E|(B+\Delta)+n\Delta^2)$ word operations and no more than the corresponding number of words for its original-clause incidence graph, signature list, temporary connected triples, and histogram. For fixed $d$, this is $O(n+m)$.
\end{proof}

\begin{lemma}[Source-checked witness extraction in the same fixed-degree bound]
If $\mathcal H_3(F,a)$ contains a vector with $N_0=0$ or $N_3=0$, a corresponding source-verified satisfying complete assignment within three flips of $a$ or $\bar a$, respectively, can be recovered with $O(n+m)$ word operations for fixed $d$.
\end{lemma}
\begin{proof}
For triples with two or three interaction edges, retain an explicit representative while enumerating them. For exactly one edge, select a matching third variable from the signature bucket outside the edge's forbidden neighborhood; only $2\Delta+2$ vertices are forbidden. For zero-edge triples, retain the first $3(\Delta+1)$ vertices of each signature bucket. If some independent triple realizes the required three signatures, replace its vertices one at a time by a retained vertex of the same signature. Each replacement avoids at most two other vertices and their neighbors, at most $2\Delta+2$ forbidden choices. Whenever a bucket is too small for this argument, all its vertices were retained. Thus one of the bounded representatives realizes the same noninteracting type. Verify the final original complete assignment against every source clause; if the histogram vector has $N_3=0$, complement the reconstructed assignment first.
\end{proof}

\noindent\textbf{Machine and source accounting.} Source size is $N=\Theta((n+m)\log(n+1))$ under an explicit indexed signed-literal encoding. One word holds $\Theta(\log N)$ bits; an exact multiplicity at most $\binom n3$ requires $O(\log n)$ bits and thus $O(1)$ words. The algorithm includes input parsing, clause-index lookup, signature/edge/triple construction, false leads, bucket updates, candidate selection and final witness verification in its asymptotic upper bound. The benchmark separately charges one original input scan to each method; its Python heap peaks and elapsed times are same-execution pairs, not multitape or single-tape physical head-crossing claims.

\section{Result and next specific lemma}
\noindent\textbf{PROVED/EXACT, RESTRICTED, independent review pending:} The exact four-category multiset of \emph{all} coherent three-original-variable flips can be compiled in $O(n+m)$ indexed-word-RAM time and working words on proper bounded-occurrence source 3-CNF, especially connected strict exact-$(2,2)$ instances. It avoids explicitly generating $\binom n3$ full assignments. A full source SAT witness can be reconstructed when one lies in that radius around either endpoint. The objective is histogram construction, not general SAT decision.

\noindent\textbf{FALSIFIED/RETIRED inference:} Smaller DPLL state count from this prepass does not imply smaller total work; the strict22 S15 and W1 controls explicitly disprove that unconditional claim for the specified implemented controller. The next missing lemma is a uniform fixed-radius-$r$ source-cluster compiler with a proved $f(r,d)(n+m)$ ledger and simultaneously bounded stored bits, allowing $r$ to grow and preserving exact witness/certificate reconstruction. The $r=3$ result alone leaves $P=NP$ and $P\ne NP$ open.
