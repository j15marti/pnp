## Precise source family and original encoding

For a connected cubic graph G with h vertices and 3h/2 edges, assign Boolean variable x_e to each edge and fixed vertex charge c_v in GF(2), with an **odd** total. Each vertex contributes the four signed **proper 3-CNF** clauses falsified exactly by parity-invalid incident-edge assignments. This is the **original source**; no equisatisfiable outside-CNF reduction is involved. It has n=3h/2 variables, m=4h clauses and N=Theta(h log(h+2)) canonical indexed binary encoding bits. The parity rows sum to 0=1, proving UNSAT. For a qualifying cubic expander family the established **ordinary general shared-DAG Resolution** lower bound is W_Res(F_h)=2^{Omega(h)} [1]. Finite K4, prism, cube controls are *not certified asymptotic expanders*.

## Exact concrete and abstract semantics

**Concrete class C_RUP-CDCL:** a total sequential Boolean SAT procedure, with original-variable-only databases D, can use arbitrary decision branches, unit propagation, learned-clause reuse/sharing, backtracking/backjump, restart and **legal deletion**. Every global learned clause C is explicitly licensed by a RUP check: unit propagation on active D plus all negated literals of C conflicts. Each conflict triggers at most one global RUP learning event; an UNSAT return is permitted only after a counted root-level RUP contradiction, including the final empty clause. All global learned clauses and the final UNSAT claim consume paid conflict events, with no other deductions, semantic shortcuts, RAT/PR/SR, GF(2), extended definitions, external proof systems or unlogged UNSAT test. On SAT the machine returns an original-source-checked model. A conflict/learn event consumes at least one sequential machine action. This class is deliberately **not all SAT deciders**. Our executable policy uses decision-nogood learning and root restart rather than 1-UIP, but the theorem includes every solver with the stated RUP-learning contract, including legal 1-UIP.

A concrete state includes immutable F, active clause database, branch assumptions and reason trail, source/learned node provenance, branch scope, chronological paid node history, deletions and resource counter q.

**Abstract MAY projection:** retain the original source and a global shared-DAG Resolution derivation with temporary weakening views, forget solver trail/branch policy and let each conflict/learn transition append *any* block of at most n binary Resolution inferences (possibly 0) plus a temporary interface weakening; decisions, UP, deletions, backjumps and restarts are abstract stutters. Its projected conflict cost never exceeds actual conflict count/machine cost. Every legal concrete UNSAT goal is represented. It may admit spurious cheap paths; this is intentional. Thus if an independently proved Resolution lower bound excludes the goal at cost <=nB, the concrete class cannot reach UNSAT in <=B conflicts.

**Theorem 530.1 (PROVED/RESTRICTED; established CDCL/Resolution connection specialized to this cost domain).** For every F on n original variables and every terminating UNSAT execution of C_RUP-CDCL with q paid conflict/learn events, including the final empty clause,

$$
W_{\mathrm{Res}}(F)\le nq,\qquad q\ge W_{\mathrm{Res}}(F)/n,\qquad T\ge q.
$$

**Proof:** Delete all deletion records *only in the mathematical witness*, retaining clauses already derived. RUP monotonicity preserves every original step. Reverse each UP conflict using the reason clauses: at most one propagation per variable, hence at most n oriented binary Resolution inferences derive a subclause C' of each RUP-learned C. Keep an interface weakening C' -> C temporarily. An induction on the chronological globally shared proof DAG removes weakening without adding Resolution inference nodes, strengthening any later resolvent or retaining a stronger parent when its pivot disappears. The last empty learned clause has no proper subclause. Reuse of a source or learned lemma does not repurchase its derivation. No branch-only assertion becomes a global premise because RUP itself discharges decision assumptions. Therefore an ordinary original-source-rooted refutation with at most nq distinct derived nodes exists. Each paid conflict is a distinct sequential solver event, so T>=q. This is a *potential proof of existence*; it does not require the machine to emit the offline refutation. QED.

**Corollary (restricted sequential time):** On the certified odd-charge cubic expander-Tseitin family, every procedure in C_RUP-CDCL needs q=2^{Omega(h)} conflicts and T>=q, despite outputting only an UNSAT bit. This is a consequence of established general Resolution hardness, not a new all-machine theorem.

**Shortcut controls:** Native Gaussian elimination on the authenticated h parity equations gives a polynomial-time UNSAT explanation; an algebraic CDCL(XOR) solver [5] falls *outside* the class. RAT, definitions/ER and arbitrary semantic decision procedures are also outside. Hence the corollary **cannot** imply FLMV or general SAT decision hardness, nor R_mix341 superpolynomial minimum. Arbitrary-machine transfer remains [P2-A2]/[P2-A4]/[P2-A5] OPEN.

A local full Python implementation performs original-source strict signed-CNF validation, SHA-256 authentication, decisions, UP, global RUP conflict learning, root restarts, optional single legal deletion, model checking and *reverse-UP oriented Resolution witness reconstruction*. A separately written complete Node.js implementation independently checks active RUP and labels, source hashes, counts and malformed controls. Malformed repeated/complementary/zero/oversized clauses and corrupted learned clauses were rejected by the local implementations.
