\begin{abstract}
P versus NP remains \OPEN.  The current synthesis leaves full realized-trace
semantic factorization as a possible repair after fixed checkpoints were
defeated.  This report proves an exact adverse wrapper theorem.  For every
total deterministic decider $A$, a uniform wrapper emits the input one symbol
at a time into a mutable register and then simulates $A$.  A fixed projection
of the full mutable trace reconstructs the entire encoded source, hence
factors every source-defined semantic object, while the wrapper adds only
$O(N)$ time and $O(\log N)$ peak auxiliary workspace and never holds the full
source in one mutable state.  If $A$ is a polynomial SAT decider, pointwise
compatibility can be extracted in polynomial time by reconstructing the
formula and making a second charged call to $A$ on a restriction.  That call
is not work performed by the original deciding execution.  Thus bare
full-trace factorization is \RETIRED{} as a resource bridge; a provenance-free,
paid same-execution semantic transfer remains \OPEN.  A bounded audit passed
6,040 assertions over 270 family/encoding/wrapper traces and 4,092 exhaustive
binary sources.
\end{abstract}

\section{Claim card and exact quantifiers}

\begin{description}[leftmargin=3.2cm,style=nextline]
\item[Claim ID.] \claim{BARE-FULL-TRACE-FACTORIZATION-AS-RESOURCE1}.
\item[Status before run.] \CAND{} as the weak reading of the current full-trace spine.
\item[Desired conclusion attacked.] If pointwise compatibility factors through the full mutable trace of every polynomial SAT decider, then the same execution must incur a superlinear, superpolynomial, or otherwise forbidden time/space resource.
\item[Input family.] A fixed self-delimiting CNF encoding; the NP-complete proper duplicate-free signed monotone $3$SAT-$(2,2)$ core is the hard control.
\item[Machine/model.] Uniform deterministic multitape machine with read-only input, mutable work tapes, and one decision bit.  Time counts every transition; space counts peak mutable work cells and excludes the read-only source.
\item[Resource.] Added wrapper time and peak auxiliary workspace; trace acquisition, extraction, reconstruction, and any semantic evaluation are charged separately.
\item[SAME\_REALIZATION.] $\operatorname{Tr}_{W[A]}(x)$ is the trace of the exact run producing $W[A](x)$.  A later run of $A$ by an extractor is explicitly a different realization and is not charged to $W[A]$.
\item[What falsifies the claim.] A language-preserving wrapper whose full trace factors the source semantics with small added cost but whose deciding run need not compute the extracted object.
\end{description}

Let $\operatorname{MTr}_M(x)$ be the sequence of mutable configurations of
$M$ on $x$, with the read-only input carrier deleted.  There exist one
effective uniform program transformation $\mathsf{Ser}$ and fixed computable
maps $P,D$, independent of the child program, such that
\[
 \exists\mathsf{Ser},P,D\;\forall A\;\forall x\in\{0,1\}^*:
 \quad D(P(\operatorname{MTr}_{\mathsf{Ser}(A)}(x)))=x.
\]
Here $A$ ranges over total deterministic deciders.  If $N=|x|$, then
\[
 T_{\mathsf{Ser}(A)}(x)\le T_A(x)+O_A(N+1),\qquad
 S_{\mathsf{Ser}(A)}(x)\le
 \max\{S_A(x),\lceil\log_2(N+1)\rceil+O_A(1)\}.
\]
Consequently, for every computable source semantic $H(x,\alpha)$ there is an
extractor $E_H$ with
\[
 H(x,\alpha)=E_H(P(\operatorname{MTr}_{\mathsf{Ser}(A)}(x)),\alpha).
\]
For residual SAT compatibility and polynomial $A$, one may choose $E_A$ to
decode $x$, form the restricted CNF $x\upharpoonright\alpha$, and run $A$;
thus $E_A$ is polynomial but its call is a second, fully charged execution.

\section{Explicit clean core and compatibility}

For encoded length $N$, let $\mathcal K_N$ contain the canonical encodings of
duplicate-free signed monotone $3$CNF formulas whose clauses contain three
distinct variables and in which every variable occurs twice positively and
twice negatively.  SAT on this family is NP-complete \cite{docker}.  For a
partial assignment $\alpha$, define
\[
 H(F,\alpha)=1\quad\Longleftrightarrow\quad
 \exists z\supseteq\alpha\;F(z)=1.
\]
The equal-length YES pair recorded by CUTGAP1 has opposite values of $H$ for
one fixed $\alpha$, so the answer bit does not determine compatibility.  The
serial trace distinguishes the pair only because it transports their source
encodings.  This is semantic factorization, not evidence that the original
solver computed or retained $H$.

\section{Serial wrapper theorem}

\begin{theorem}[serial mutable-trace source injection]
Fix a read-only input machine model as above.  For every total deterministic
decider $A$ there is a total uniform decider $W[A]=\mathsf{Ser}(A)$ such that:
\begin{enumerate}[leftmargin=*]
\item $W[A](x)=A(x)$ for every input $x$;
\item before simulating $A$, $W[A]$ scans $x=x_0\cdots x_{N-1}$ and, at one
distinguished transition per symbol, its mutable wrapper register contains
only $(\mathsf{emit},i,x_i)$;
\item the ordered sequence of distinguished states reconstructs $x$ exactly;
\item no distinguished state contains more than one source symbol and a
$\lceil\log_2(N+1)\rceil$-bit index;
\item the displayed time and space bounds above hold; and
\item after simulation, the wrapper may erase its registers and halt in one
of two fixed answer states.
\end{enumerate}
\end{theorem}

\begin{proof}
Scan the read-only input left to right.  Maintain a binary counter $i$ and one
symbol register.  On reading $x_i$, overwrite the register by $x_i$, expose
the phase tag $\mathsf{emit}$ for one transition, increment $i$, and continue.
After the end marker, erase the symbol register and counter, reposition the
input head in $O(N)$ transitions if the child convention requires it, and
run the inlined code of $A$.  The wrapper is uniform and language preserving.
At most one source symbol and the counter are simultaneously stored, proving
the auxiliary space bound.  The scan, increment operations, erasure, and
repositioning cost $O_A(N+1)$ time in the declared multitape model.

The fixed projection $P$ selects states tagged $\mathsf{emit}$ in temporal
order, and $D$ concatenates their symbol fields after checking indices
$0,1,\ldots,N-1$.  Hence $D(P(\operatorname{MTr}_{W[A]}(x)))=x$.  Cleanup
does not change the earlier full trace and collapses the terminal mutable
projection to the one-bit answer.
\end{proof}

\begin{corollary}[factorization is not paid semantic work]
For any computable $H$, define $E_H(\tau,\alpha)=H(D(P(\tau)),\alpha)$.
Then $H$ factors through the full mutable trace of $W[A]$ even though the
wrapper's serial phase performs only source transport.  If extracting $H$
requires a hard computation, that cost belongs to $E_H$, not to the original
run.  Therefore factorization alone cannot justify a same-execution resource
lower bound beyond the literal serial scan without an additional transfer
theorem.
\end{corollary}

This corollary does not prove a fast SAT algorithm.  When $H$ is pointwise
SAT compatibility, making $E_H$ polynomial by running a polynomial child
decider presupposes the counterfactual SAT in P.  Conversely, a theorem that
forces a superpolynomial resource in every such $W[A]$ would already be an
arbitrary-decider SAT lower bound.  The missing arrow has not been shortened.

\section{All-cost and SAME\_REALIZATION audit}

The wrapper charges $N$ source reads, $N$ symbol-register writes, counter
updates, erasure, input-head repositioning, the complete child simulation,
and the one-bit output.  The analytic full trace is not automatically an
explicit file.  An instrumented recorder must additionally scan or serialize
the relevant states; the selected serial subtrace contains $N$ symbols and
can be recorded in $\Theta(N)$ bytes when temporal order supplies indices.
Reconstruction costs $\Theta(N)$ reads and writes.  Parsing and restricting a
CNF are polynomial in $N$.  Running $A$ on the restriction costs
$T_A(N^{O(1)})$ time and $S_A(N^{O(1)})$ space in a second execution.  None of
these recorder/extractor costs may be reassigned to the original decision run.

The theorem therefore separates three statements:
\[
 \text{trace determines source}
 \quad\not\Rightarrow\quad
 \text{run computes semantic object}
 \quad\not\Rightarrow\quad
 \text{run violates a lower bound}.
\]

\section{Hostile controls and wrapper audit}

Horn, 2SAT, affine/Tseitin, and bounded-treewidth algorithms demonstrate that
rich source semantics may coexist with direct polynomial shortcuts.  The
serial theorem is language independent, so these easy controls neither rescue
nor weaken it.  Independent products do not force an answer vector or
additive peak state: their encodings are serialized with the same one-symbol
register.  Padding, redundant clauses, renamings, and alternate encodings
increase trace length but not the asymptotic auxiliary peak.  DEAD, DELAY,
INTERP, RECOMP, and cleanup change presentation without destroying the first
serial phase.  An explicit whole-source COPY only increases resources and is
therefore not an unavoidable lower-bound witness.

A maximal semantic oracle or low-degree algebraic oracle can make the
external evaluator cheaper, but cannot convert its work into work performed
by the original execution.  Conversely, refusing oracle states by definition
is not a nonrelativization theorem.

\section{Barrier audits}

\paragraph{Relativization.}
The wrapper commutes with an oracle child: serialize the ordinary input and
then simulate the oracle machine.  Thus the negative theorem relativizes.  It
cannot separate P from NP in view of Baker--Gill--Solovay.

\paragraph{Algebrization.}
No algebraic lower bound is used.  Algebraic oracle access can be passed to
the child and evaluator; serial source transport remains.  The missing
positive transfer must state the algebraic operation at which it fails.

\paragraph{Natural Proofs.}
No constructive large useful circuit property is asserted.  If a trace
predicate is converted into a circuit property, its circuit class,
constructivity, largeness, usefulness, and wrapper transfer must be audited
separately.

\paragraph{Uniformity, exponents, and one-bit output.}
The transformation is uniform and works for each fixed child program.  Its
quantifiers do not assume one polynomial exponent for all deciders.  If $A$
runs in $N^{k_A}$ time, both $W[A]$ and the second-call extractor retain
$k_A$ up to encoding overhead.  The original required output remains one bit.

\section{DUPLICATION / CONTRADICTION AUDIT}

DERIVEDLEAK1 already proved that an $N$-cell simultaneous mutable COPY makes
the input-erased trace source-injective in $O(N)$ time and $N+O(1)$ writable
cells.  SERIALTRACE1 does not rename that result: it strengthens the adverse
construction from one source-containing state to a temporally distributed
source-injective full trace using only $O(\log N)$ peak auxiliary state.
CUTGAP1 hides data from every fixed polynomial predeclared checkpoint
schedule; there is no contradiction because the present projection observes
all distinguished emission times.  MODELBRIDGE-0028 collapses data-free
schedule plus decision; the present trace is data bearing by construction.
PRODSTREAM1 supplies the compatible product-space lesson.

Repository searches for ``serial trace'', ``symbol-by-symbol trace'',
``streaming full trace compatibility'', and ``trace reconstructs the input''
found no prior $O(\log N)$ serial full-trace wrapper theorem.  Historical
full-trace factorization language existed, but its acquisition/resource arrow
was explicitly open.

\section{WHAT CHANGED RELATIVE TO ROOT MAIN}

The LSPV-2 specialty state is extended beyond PRODSTREAM1.  Full-trace source
factorization is now known to be realizable with only logarithmic peak
auxiliary workspace, even when no single mutable state holds the source.
Therefore the synthesis target must require paid semantic derivation or an
invariant provenance/noninterference condition; bare factorization through a
data-bearing full trace is insufficient.  No main4/main5 construction claim,

\section{STALE OR OVERSTATED CLAIMS FOUND}

Any root or historical wording that treats ``$H$ factors through the full
trace'' as already implying that the solver computed, retained, or paid for
$H$ is overstated.  The newest MAIN correctly kept the resource implication
open, but its weak factorization premise must now be read with an explicit
nontransport/provenance guard.  Likewise, the cardinality of a whole-trace
image is not a peak-space bound: temporal serialization realizes an
exponential length-layer image with logarithmic peak auxiliary storage.

\section{Highest-value missing implication and handoff}

\begin{quote}
For every uniform deterministic polynomial-time clean-core decider $A$,
