\section{Quantifiers, pre-source falsifiers and exact model}
The result here concerns a fixed-record \emph{total} SAT encoding and a
single explicit fixed verifier circuit, not a deterministic all-input SAT
decider. The larger objective is a transformation of a fixed uniform total
ordinary-SAT decider $A$ with one simultaneous time--space pair in the
indexed-read-only-input random-access model of Fortnow--Lipton--van
Melkebeek--Viglas (FLMV). The hypothesis $P=NP$ gives some unknown polynomial
exponent $K$, not a near-boundary $d=1.802$ with subpolynomial workspace.

\section{Total fixed-record language and its quantifier order}
Fix integers $q\ge3$, $m\ge1$, and let
\[
 w=\lceil\log_2(q+1)\rceil,\qquad N=m[1+3(w+1)].
\]
Every $x\in\{0,1\}^N$, without a malformed-input promise, decodes into
$m$ records. Record $c$ consists of an active bit $a_c$ and three pairs
$(v_{cj},s_{cj})$, with a $w$-bit unsigned variable name
$v_{cj}\in\{0,\ldots,2^w-1\}$ and a one-bit desired truth value $s_{cj}$.
An inactive record contributes true even when its names are malformed.
An active record contributes false if a name is outside $[1,q]$ or any
two names coincide. Otherwise it imposes the signed ternary clause
$\bigvee_{j=1}^3[z_{v_{cj}}=s_{cj}]$.
Write
\[
 \begin{split}
 \operatorname{Good}_c(x,z)
 &=\neg a_c\ \vee\ \left(
 \bigwedge_j 1\le v_{cj}\le q\ \land\
 \bigwedge_{i<j}(v_{ci}\ne v_{cj})\ \land\
 \bigvee_j[z_{v_{cj}}=s_{cj}]\right),\\
 L_{q,m}(x)&=\exists z\in\{0,1\}^q\;
 \bigwedge_{c=1}^m\operatorname{Good}_c(x,z).
 \end{split}\tag{1}
\]
Thus active valid inputs represent proper signed ternary SAT, and all
malformed inputs have declared total semantics. This is not yet a direct
implementation for arbitrary common variable-width ordinary-SAT encodings.
For the near-linear claim relative to physical input $N$, assume
$q\le N$ (as for a compact formula with at most $N$ declared variables).

\section{Fixed oblivious sort--join--inverse algorithm}
Let $R=3m$, $K=2^{\lceil\log_2(q+R)\rceil}$,
$h=\log_2K$, $D=w+3$. Allocate $K$ fixed-position records of exactly
$D$ Boolean wires: $q$ assignment records $(v,0,z_v)$, $R$ literal-request
records $(v_{cj},1,s_{cj})$, and $K-q-R$ padding records with kind $2$.
Here the kind is a two-bit integer, and the comparison key is the pair
$(v,\text{kind})$ in lexicographic order. In particular each assignment
record precedes all requests bearing its valid name. All assignment records
are present exactly once.

Use the standard bitonic network with loop parameters
\[
 \text{size}=2,4,\ldots,K;\quad
 \text{stride}=\text{size}/2,\ldots,1;\quad
 j=i\oplus\text{stride},\quad i<j.
 \tag{2}
\]
The direction of each comparison is fixed by the stage and
$i\mathbin{\&}\text{size}$, independent of $x$. Retain the Boolean
swap wire $\sigma_e$ for every comparator $e$. Sorting the records is
\emph{a Boolean computation within the verifier} rather than a source
rewriting step that changes output names or headers.

After sorting, scan the records from left to right. At position $i$,
let $k_i$ be the key, $d_i$ the kind, $p_i$ the record payload, and
write $u_0=0$ and
\[
 u_i=\begin{cases}
 p_i,&d_i=0,\\
 u_{i-1},&d_i\ne0\ \land\ k_i=k_{i-1},\\
 0,&\text{otherwise}.
 \end{cases}\qquad
 r_i=[d_i=1]\land u_i.
 \tag{3}
\]
(The executable uses the equivalent fully gated recurrence and harmless
padding behavior.) A valid query with key $v\in[1,q]$ receives exactly
$z_v$. An invalid query is irrelevant because the independent range
checker rejects any active record containing it.

Finally reverse the bitonic comparator stages. At each switch $e$ route
the \emph{one-bit} $r$-payloads using the \emph{same} stored $\sigma_e$.
This reverses the original permutation exactly, no second sorting network
and no stored permutation table. The resulting $R$ query positions are
recovered in their original $(c,j)$ order; the fixed gates then check (1).

\begin{lemma}[Exact inverse-switch join; \textbf{PROVED/EXACT}]
For all $q,m,x,z$, the reversed request payload in position $(c,j)$
equals $z_{v_{cj}}$ whenever $1\le v_{cj}\le q$. The final verifier
$V_{q,m}(x,z)$ equals $\bigwedge_c\operatorname{Good}_c(x,z)$ on
\emph{every} input string, including malformed active and inactive rows.
\end{lemma}
\begin{proof}
Every assignment key $v\in[1,q]$ appears in one kind-$0$ record and
precedes every kind-$1$ query for $v$ after sorting. The scan sets the
carry to $z_v$ at that assignment and preserves it across the equal-key
request group. Strict invalid-name and repeated-name checks are carried
out on the untouched source ID wires, so a missing assignment for an
invalid key cannot create a false accepting active clause.
Each compare-exchange is either identity or transposition of two records,
with the chosen transposition bit $\sigma_e$ retained. Its inverse on
attached payloads is the identical conditional swap. Composing the
inverses in reverse order recovers the source positions regardless of
the data-dependent permutation. The final equality with sign $s_{cj}$,
range, distinctness, active bypass and conjunction implement (1) exactly.
\end{proof}

\section{Exact gate counts, bit-local proper three-CNF, and computability}
Let $C_K=Kh(h+1)/4$, exactly the number of bitonic comparators in (2).
Use binary AND/OR gates, with a negative signed wire for negation.
The little-endian strict comparator uses seven AND/OR gates per key bit;
for the $(w+2)$-bit compound key it consumes $7(w+2)$ gates. A
conditional swap of the two $D=w+3$-bit records requires $6D$ gates.
The reverse payload switch requires six more gates. Each sorted scan
row requires $19$ gates for kind tests/carry/payload, and every row
except the first additionally requires $4w-1$ gates for key equality.
Each final active-clause checker uses $36w+15$ gates, followed by
$m-1$ binary AND gates to combine rows. The exact fixed gate count of
the executable's canonical gate template is therefore
\[
 \boxed{G(q,m)= C_K(13w+38)
 +19K+(K-1)(4w-1)
 +m(36w+16)-1.}\tag{4}
\]
For $q\le N$ and $m\le N$, $K=O(N)$ and $w,h=O(\log N)$, whence
\[
 G=O(N\log^3N),\quad\text{fixed Boolean wiring size}
 =O(N\log^4N)\ \text{bits}.\tag{5}
\]
The scan is permitted linear \emph{depth}; (5) is a gate-size claim,
not a polylogarithmic depth assertion or a space bound for evaluating it.

A source verifier output gate $y=f(a,b)$, where $f$ is AND or OR and the
signed inputs $a,b$ may be identical or opposite, is encoded in a proper
3-CNF by introducing two \emph{fresh} input copies $u,v$ and padding
every equality $u\leftrightarrow a$, $v\leftrightarrow b$ using two
widened binary clauses per equality. These produce four proper ternary
clauses per equality, even when $a$ and $b$ originally use one source
name. The final AND/OR relation on the distinct names $(u,v,y)$ is
one ternary and two binary clauses, with each binary clause widened by
a fresh private name into two ternary clauses. Hence each binary gate
adds exactly nine variables and thirteen proper ternary clauses.

For every physical source bit $x_i$, allocate a fresh $X_i$ and the
four-row pin
\[
 U(\ell_i;A_i,B_i)=\bigwedge_{\sigma,\tau\in\{+1,-1\}}
 (\ell_i\vee \sigma A_i\vee\tau B_i),\quad
 \ell_i=\begin{cases}X_i,&x_i=1,\\\neg X_i,&x_i=0.\end{cases}\tag{6}
\]
Two additional constant-wire pins set internal truth constants $0,1$,
and a final pin requires the verifier output $1$. Number source variables
and clauses in the fixed gate order, then the source-bit pins, then the
three other pins. Their exact counts are
\[
 \boxed{n_0=9G+3N+q+8,\qquad m_0=13G+4N+12.}\tag{7}
\]
Every source clause is proper, with three distinct variable names;
its variable IDs, clause order, count headers, and padding names depend
only on $(q,m)$, not on $x$.

\begin{theorem}[Total local-pinning reduction and fixed-size interface;
\textbf{PROVED/EXACT}]
For all $q\ge3$, $m\ge1$ and all $x\in\{0,1\}^N$, let $H_{q,m,x}$ be
the formula specified by (4)--(7). Then
\[
 \boxed{\SAT(H_{q,m,x})\iff L_{q,m}(x)=1,}\qquad
 H_{q,m,x}[i]\in\{0,1,x_j,\neg x_j\}.\tag{8}
\]
The only variable physical output fields are the $4N$ fixed source-pin
sign slots, four disjoint slots per source coordinate. Its fixed-width
serialization has length
\[
 M_0=4+2\lceil\log_2(\max\{n_0,m_0\}+1)\rceil
 +3m_0[1+\lceil\log_2(n_0+1)\rceil]
 =O(N\log^4N).\tag{9}
\]
An individual source clause or physical bit can be specified using the
integer gate index, the fixed thirteen-row local gate template, and the
input-pin row index. No data-dependent sorting of the source description
or input-dependent identifier allocation is performed.
\end{theorem}
\begin{proof}
Equation (6) holds exactly when $X_i=x_i$; every other pin has the
declared Boolean meaning. Each padded equality enforces $u=a$ or
$v=b$ and each padded gate relation enforces $y=f(u,v)$. Induction over
the acyclic gate list shows that the source formula is satisfiable
precisely if some assignment $z$ makes the explicit verifier output $1$.
The inverse-switch lemma identifies that output with (1). Every fixed
module uses private auxiliary IDs; thus all clause-variable triples are
proper even for aliased or negated input wires. A source bit $x_i$ is
consulted only to determine the four signs of its own pin's distinguished
literal. Each physical variable-ID field and count header is a constant
function of $(q,m)$, giving the literal projection and size bound.
\end{proof}

\paragraph{Uniform direct gate access, narrower than full Rank/Select.}
The comparator schedule (2) has exactly $h(h+1)/2$ layers of $K/2$
comparators. For stride $s=2^b$, the $r$th comparator pair is
\[
 i=2s\lfloor r/s\rfloor+(r\bmod s),\quad j=i+s,
 \quad0\le r<K/2.\tag{10}
\]
Thus a gate index within the \emph{forward comparator sector} decodes
arithmetically to its layer, pair, and one of $13w+32$ internal gates.
Its operands refer either to local earlier gates or to two fixed-position
wires from the preceding layer. The inverse sector uses exactly six
local gates per comparator and forward switch bits indexed by (10).
The scan sector has a fixed first-row size and fixed subsequent row
sizes, while final checking is by original source record position.
These formulas establish a uniform polylogarithmic \emph{gate descriptor}
for the fixed layout. The executable itself allocates the full gate
list before testing; it is not an independently executed logarithmic-space
\texttt{GateAt}/\texttt{Rank}/\texttt{Select} interpreter. In particular,
locating \emph{all consumers} of an arbitrary intermediate gate output,
including high-fanout constants and saved swap flags, and ranking their
CNF slots in the prescribed order, has not been implemented or fully
proved in this run. Source \texttt{Rank/Select} needed by the $R_{15}$
virtual regularizer remains a \textbf{separate OPEN interface}. Do not
replace it by a free occurrence table in a FLMV simulation.

\begin{theorem}[Exact signed two-level transport; \textbf{PROVED/EXACT}

\[
 \SAT(R_{15}^{2}(H_{q,m,x}))\iff L_{q,m}(x)=1.
 \tag{12}

\begin{proof}

a sign's distinct physical support, and separate source-slot supports
remain disjoint under the one-to-two slot map. Iterate twice and use
(11) for the arithmetic counts. The signed occurrence and properness
conditions follow from the Q15/J occurrence-ring interface, not from a
clauses-only sign projection.
