\begin{abstract}
\status{FALSIFIED/RETIRED} The nested-tag family introduced in LB-0019 does
not make tag consistency a semantic obligation of SAT.  Every tag gadget in
that construction is satisfiable and variable-disjoint from the leaf blocks.
Consequently all tag values, including inconsistent ones, can be erased
without changing satisfiability.  A bounded reproducible audit performed
$1{,}354{,}166$ checks with zero failures.  This refutes only the claimed
all-decider need to validate tag consistency; it does not refute the
leaf-probe lower bound.  P versus NP remains open.
\end{abstract}

\section{Claim card and exact target}

Let $b\ge2$, $d\ge1$, $L=b^d$, and
$I=(b^d-1)/(b-1)$.  Let $Y_i$ be a satisfiable proper 3CNF leaf block,
$U_i$ an unsatisfiable proper 3CNF leaf block, and let $T_{v,0},T_{v,1}$
be the two tag gadgets at internal node $v$.  All blocks use pairwise
disjoint variable sets.  LB-0019 uses tags as constructor metadata but
contains no shared variables or gluing clauses that force a parent tag to
equal a function of its children.

For $s\in\{0,1\}^{L}$ and $\tau\in\{0,1\}^{I}$ define
\[
 G(s,\tau)=
 \bigwedge_{i=1}^{L} B_{i,s_i}\ \wedge\
 \bigwedge_{v=1}^{I}T_{v,\tau_v},
 \qquad B_{i,1}=Y_i,\quad B_{i,0}=U_i .
\]
The tested universal claim was:
\[
\forall A\,[A\text{ decides 3SAT correctly}]
\ \forall(s,\tau)\quad
A(G(s,\tau))\text{ must validate the nested tag relations}.
\tag{NTCN}
\]
The input length $N$ is the length of a conventional explicit 3CNF
encoding.  The machine model is a deterministic uniform random-access
machine with read-only input, work tape, and one output bit; preprocessing,
recognition, extraction, reconstruction, and output costs are included.

\section{Literature and barrier preflight}

The two blocking obstacles are (i) the missing semantic coupling between
tags and leaves, and (ii) the absent transfer from a restricted structural
lower bound to every uniform deterministic SAT computation.  Direct-sum
theorems for decision trees are model-specific, as are branching-program
and resolution lower bounds.  The Fortnow--Lipton--van Melkebeek--Viglas
SAT time--space theorem reaches a random-access computation model through a
specific local-reduction framework; it is not a license to charge arbitrary
semantic annotations to every SAT decider.  Thus these are useful
model-boundary controls, not transfers proving (NTCN).

\section{Exact falsification}

\begin{theorem}[SATISFIABLE-COMPONENT-ERASURE1]
\status{PROVED/EXACT} Let $F$ be a CNF and let $C_1,\ldots,C_m$ be
satisfiable CNFs on pairwise disjoint variable sets, also disjoint from
$F$.  Then
\[
F\wedge C_1\wedge\cdots\wedge C_m\in\SAT
\quad\Longleftrightarrow\quad F\in\SAT .
\]
\end{theorem}
\begin{proof}
Restriction of a satisfying assignment proves the forward implication.
For the reverse implication, take one satisfying assignment for each
$C_j$ and combine them with a satisfying assignment for $F$; disjointness
makes the union well defined.
\end{proof}

\begin{theorem}[NESTED-TAG-GLUING-ABSENCE1]
\status{PROVED/EXACT} For every $s\in\{0,1\}^{L}$ and every tag vector
$\tau\in\{0,1\}^{I}$,
\[
G(s,\tau)\in\SAT\quad\Longleftrightarrow\quad
\bigwedge_{i=1}^{L}s_i=1.
\]
In particular, satisfiability is invariant under every tag mutation.
\end{theorem}
\begin{proof}
Each selected tag block is satisfiable and variable-disjoint from every
other component, so the preceding theorem erases all tags.  The remaining
independent product of leaves is satisfiable exactly when no selected leaf
is $U_i$.
\end{proof}

The smallest hostile control is $b=2,d=1$ with two satisfiable leaves and
an inconsistent root tag.  The CNF
\[
Y_1\wedge Y_2\wedge T_{0}
\]
is satisfiable.  Therefore any recognizer that rejects this formula merely
because the root tag disagrees with the leaf values is not a correct SAT
decider on the broad syntactic island.  Hence (NTCN) is
\status{FALSIFIED/RETIRED}.

\section{Conditional wrapper and full cost ledger}

Assume, only for the wrapper test, that a uniform deterministic polynomial
time 3SAT decider $A$ exists.  Define $W_A$ to recognize the broad island
\[
\mathcal I_{b,d}=\{G(s,\tau):s\in\{0,1\}^{L},
\tau\in\{0,1\}^{I}\},
\]
including arbitrary tag strings.  On this island it scans syntax once,
tests each leaf template, accumulates the AND of leaf bits, scans tag blocks
for syntax only, and ignores their values and their alleged consistency.
Off the island it calls $A$.

\begin{proposition}[FLAT-TAG-ERASURE-WRAPPER1]
\status{CONDITIONAL} If $A$ is a polynomial-time 3SAT decider, then $W_A$
is a polynomial-time 3SAT decider whose island path performs zero semantic
tag evaluations, zero compatibility extraction, and zero reconstruction.
Its explicit costs are $O(N)$ recognition time, $O(L)$ leaf-template tests,
one accumulator bit, $O(\log N)$ address state, and one output bit.
\end{proposition}
\begin{proof}
The previous theorem proves island-path correctness for every tag vector.
The fallback proves correctness elsewhere.  All recognition work is
charged, and the scan is linear in the encoded input length.
\end{proof}

This is not an unconditional polynomial-time algorithm for 3SAT and does
not assume its conclusion.  It is a model-matched counterexample to a
purported additional necessity under the hypothesis $\SAT\in\mathrm P$.

\section{Post-quantum technique ledger}

Let $\pi(s,\tau)=s$.  \status{EXACT OBJECT/THEOREM TRANSFER} Its collision
count is
\[
\operatorname{Coll}(\pi)=2^L(2^I)^2=2^{L+2I},
\qquad
|\operatorname{im}\pi|
=\frac{2^{2(L+I)}}{2^{L+2I}}=2^L .
\]
Thus collision-effective entropy exactly certifies loss of every tag bit.
The Schur-square, quadratic-relation, Hilbert/syzygy, and special-soundness

tag-to-leaf algebraic relation to expose.  Worst-case/average-case

black-box reduction and a barrier audit.
