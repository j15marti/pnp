\section*{Explicit growing opposite-label proper-3CNF}
For every $n\ge1$, let
\[
H_n=(x_1)\wedge\bigwedge_{i=1}^n(\neg x_i\vee x_{i+1})\wedge(\neg x_{n+1}).
\]
Replace every unit $\ell$ by four actual ternaries
\[
\operatorname{PIN}(\ell;a,b)=\bigwedge_{\epsilon,\zeta\in\{\pm1\}}(\ell\vee\epsilon a\vee\zeta b)
\]
with private fresh $a,b$. Replace every binary $\ell\vee m$ by $(\ell\vee m\vee z)\wedge(\ell\vee m\vee\neg z)$ with a fresh $z$. Call the resulting connected, unique-clause, signed proper 3CNF $U_n$. Counts are
\[
v_n=2n+5,\quad m_n=2n+8,\quad N_n=\Theta(n\log(n+2))
\]
with dense fixed-width source-name records. These are general ordinary proper 3CNFs, NOT members of the monotone exact-$(2,2)$ grammar; no child is silently declared to preserve that target-specific promise.

\begin{theorem}[Unbounded minimal UNSAT]
$U_n$ is UNSAT, and removal of ANY one ternary makes it SAT, for every $n\ge1$. Hence every strict clause-subformula is SAT.
\end{theorem}
\begin{proof}
The four signed PIN rows existentially enforce $\ell$: if $\ell$ is false, each $(a,b)$ violates one of the four rows. The two rows of each binary gadget existentially enforce $\ell\vee m$. The base $H_n$ is contradictory since $x_1=1$ forces $x_{n+1}=1$ contrary to the last unit. Removing the initial unit admits the all-zero assignment; removing the final unit admits all-one; removing implication $i$ admits prefix $x_1=\dots=x_i=1$, suffix $x_{i+1}=\dots=x_{n+1}=0$. If a single ternary is removed from a PIN gadget, assign its original unit false, all other base constraints true, and choose private auxiliary values falsifying precisely that omitted row. If one binary-gadget ternary is deleted, assign that binary false and choose the private $z$ to satisfy the surviving row. All other gadgets have disjoint auxiliaries and can extend a true base constraint. Deleting additional rows preserves SAT.
\end{proof}
Construct $V_n$ by changing only the sign of the original literal $\neg x_{n+1}$ in the FIRST final PIN ternary into positive $x_{n+1}$, leaving all other clauses, signed input fields and headers unchanged. In the exact ASCII encoding used in the accompanying experiment, positive and negative sign bits differ in exactly one binary position.
\begin{theorem}[One-bit opposite labels and all-YES strict-subset transcripts]
$U_n$ and $V_n$ have identical encoded bit length, clause/variable counts and source names, differ in exactly one input sign bit, but are respectively UNSAT and SAT. Every strictly proper indexed clause subset of EITHER formula is SAT. Hence an adaptive interface allowed to query only the SAT statuses of proper indexed clause subsets, with no direct source-bit inspection, receives the same all-YES transcript on these opposite-label inputs, regardless of number of queries.
\end{theorem}
\begin{proof}
On $V_n$ set all chain $x_i=1$. All previous clauses are satisfied. The modified final PIN has one automatically satisfied row; its other three false-base rows have a common private auxiliary assignment. Thus $V_n$ is SAT and any deletion remains SAT. Every proper subset of $U_n$ is SAT by the preceding theorem. Thus all permitted answer bits match, and so do deterministic adaptive query histories. This restricted source-oblivious transcript theorem says nothing about arbitrary derived SAT queries or source-aware normalizers.
\end{proof}
The family is deliberately EASY: recognize the fixed clause template and test the one exceptional sign in $O(N)$ or low-polynomial source work. It does not establish hardness for all deciders. Clause minimality is established classical theory, not a claimed new notion.

\section*{A real two-level all-input A-assisted algorithm}

It deletes only when the child has the same SAT/UNSAT label. It serializes a final ordinary child and runs $A$ again for replay verification. Applying the identical program to the emitted ordinary child is the second REAL recursive normalization level.
