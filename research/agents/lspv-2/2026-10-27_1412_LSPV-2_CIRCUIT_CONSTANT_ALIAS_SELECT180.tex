\section{Complete signed constant source Rank/Select}
\begin{theorem}[PROVED/EXACT for the stated fixed emitter]
For \(c\in\{c_0,c_1\}\), the exact number of physical
source occurrences is \(4U_c+4\). A fixed uniform
program returns the ordered signed source occurrence
Select and its inverse Rank with \(O(\log^6G)\) bit
operations and \(O(\log G)\) simultaneously live
writable/index bits per query, with no incidence array.
\end{theorem}
\begin{proof}
For any Boolean gate index, use the formulas above
to count all uses at earlier complete comparator,
scan and checker blocks. The current comparator's
key and MUX source fields, the current scan block's
two kind-equality XORs and carry setup, or the current
checker's three range-test bodies supply a streaming
list of at most \(O(w)\) local constant uses.
Record pair position and first-layer sort direction
determine the signed input operands. Each sector
is a formula in \(q,m,g\), not input values.
Binary-search over the nondecreasing use-count prefix
to locate the gate of any direct-use rank \(u\);
examine at most two input slots to obtain its
signed slot \(k,\tau\). The inverse counts preceding
uses and slots. For physical rank \(r<4U_c\), write
\(u=\lfloor r/4\rfloor\), \(j=r\bmod4\) and select
row \(13g+4k+j\), middle field 1, and sign
\(\tau\) for \(j<2\) or \(-\tau\) otherwise.
For the final four ranks use the independent
constant pins. The inverse checks the precise
gate-clone or pin row/slot class and returns
\(4u+j\), rejecting absent positions.
Only a constant number of logarithmic-size counters,
addresses, indices and temporary signs are live;
schoolbook bit arithmetic, logarithmic bit-count
loops and binary search yield the stated
conservative upper bound.
\end{proof}
