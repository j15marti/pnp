\section{PROPOSE: the missing resource implication and four falsifiers}
The target is the unproved claim that \emph{low-rank, short, statically described source-authenticated messages are necessarily cheap to discover}, and the competing unproved inference that a large static hitting exponent forces high \emph{true} decision cost. We preselected the following independently falsifiable mechanisms before testing.
\begin{description}
\item[]\textbf{M1.} A connected strict exact-$(2,2)$ source with $b+q=\Theta(\sqrt n)$ must require $2^{\Omega(\sqrt n)}$ work. \textbf{FALSIFIED as an inference}: a typed infinitely growing control has a width-35 certified tree decomposition and an explicit period-three witness.
\item[]\textbf{M2.} If each local exact boundary relation is just an eight-bit pattern and the matrix of such patterns has GF(2) rank at most one, every pattern can be uniformly found in polynomial time. \textbf{CONDITIONAL FALSE unless $P=NP$}: the distinguished pattern computes an NP-complete root answer.
\item[]\textbf{M3.} Attaching balanced exact-$(2,2)$ equality/AND connector gadgets repeatedly necessarily makes treewidth grow with the number of connectors. \textbf{FALSIFIED}: a decomposition gluing lemma bounds the resulting width by the larger input width and 35.
\item[]\textbf{M4.} A fully charged adaptive controller can recognize and use such compact messages on every arbitrary strict exact-$(2,2)$ root with bounded work. \textbf{OPEN}: the reduction gives a specific NP-hard message acquisition problem; it does not bound other representations or all SAT algorithms.
\end{description}

\section{Static interface geometry, with the precise quantifiers}
A \emph{typed static modular source} consists of a connected proper signed 3CNF with exactly two positive and two negative occurrences per variable, global boundary $Y$ of size $b>0$, and $k$ nonempty private modules $Z_0,\dots,Z_{k-1}$, with no clause meeting two private modules. Each module has a supplied private clause-hitting set $B_i\subseteq Z_i$ with $|B_i|\le q$: every clause owned by the module contains a variable of $Y\cup B_i$. All source syntax, ownership, and witnesses are checked rather than supplied semantically for free.

\begin{lemma}[Inherited static count \cite{arc211}]
For every typed static source, $k\le4b$ and $n\le3b+12bq$. For $b>0$, the relaxed lower envelope satisfies
\[
q\ge\max\left\{0,\frac{n}{12b}-\frac14\right\},\qquad b+q\ge\sqrt{\frac n3}-\frac14.
\]
\end{lemma}
\begin{proof}
Every private module touches the connected boundary via at least one of the boundary's $4b$ literal incidences. Each clause is hit by $H=Y\cup_iB_i$. Because the formula has $4n/3$ clauses and each variable hits at most four, $4|H|\ge4n/3$, hence $n\le3(b+kq)\le3b+12bq$. The relaxed bound follows by arithmetic--geometric mean. It is a necessary syntactic inequality, not a lower bound on all programs.
\end{proof}

\noindent The illustrative \emph{not necessarily realizable} proxies are $T_{\rm proxy}=2^{b+q}\,\mathrm{poly}(N)$ for literal interface enumeration and $S_{\rm proxy}=2^b\,\mathrm{poly}(N)$ for an explicitly stored boundary table. For $n=1200$, the rounded integer minimizers for $b+q$ are $b=9,10,11$, value 20; the first equality of the logarithmic proxies is $q=0$, permitted no earlier than $b=400$. Continuous stationary $b_*=\sqrt{n/12}$ yields $\sqrt{n/3}-1/4$. For $q>0$, derivative $d[b+n/(12b)-1/4]/db=1-n/(12b^2)$, the second derivative is $n/(6b^3)>0$, and $d(\log_2T_{\rm proxy})/db$ changes sign at $b_*$. As $b\to0^+$ the relaxed proxy diverges; as $b\to\infty$ the expression ultimately becomes the boundary size $b$. Equality of these bookkeeping proxies is neither an actual runtime/space Pareto intersection nor a lower-bound theorem.

\section{A strict exact-$(2,2)$ NP-hard constant-message image}
Start with ARC211's explicit source $F_r$ (we reproduce its grammar to fix quantifiers). Let $b=3r$, boundary $Y=\{y_j\}_{j\bmod b}$, and private module $Z_j=\{p_{j,i}:i\bmod b\}$. Its clauses are
\begin{align*}
C_j^Y&=(y_j\vee y_{j+1}\vee\neg p_{j,0}),\\
Q_h^Y&=(\neg y_{3h}\vee\neg y_{3h+1}\vee\neg y_{3h+2}),\\
C_{j,i}^P&=(p_{j,i}\vee p_{j,i+1}\vee\neg p_{j,i+2}),\\
Q_{j,0}^P&=(\neg y_{j+2}\vee\neg p_{j,1}\vee\neg p_{j,2}),\\
Q_{j,h}^P&=(\neg p_{j,3h}\vee\neg p_{j,3h+1}\vee\neg p_{j,3h+2})\quad(1\le h<r).
\end{align*}
Here $0\le j,i<b$, $0\le h<r$ in the $Q^Y$ type. For $j\ne0$ the only boundary names of module $j$ are $Y_j=(y_j,y_{j+1},y_{j+2})$, and the exact existential profile on $Y_j$ is the \emph{full} $\{0,1\}^3$: simply set every $p_{j,i}=0$. Its eight-bit truth table is $11111111$. Every $j$ has a private syntactic hitting set of size exactly $r$, by ARC211.

\begin{lemma}[Prior connected exact conjunction \cite{connector231}]
Given any two connected strict exact-$(2,2)$ proper 3CNFs $A,B$, a fixed uniform construction $J(A,B)$ adds 30 variables and 40 clauses, preserves connectedness, properness, and signed occurrence quotas, and satisfies
\[
\exists g\;J(A,B)(a,b,g)\ \longleftrightarrow\ A(a)\wedge B(b)
\]
for \emph{every} original source assignment $(a,b)$. The connector swaps one negative literal occurrence from each source with two fixed 15-variable regulator gadgets. It uses no SAT oracle or answer-class advice.
\end{lemma}
\begin{proof}
The full clause-by-clause gadget is in CONNECTOR231; our reproducer independently enumerates all $2^{15}$ regulator assignments for every legal port choice and all 16 external input cases. Substitution of the verified truth table gives the pointwise identity; each swapped occurrence is negative on both sides, preserving exactly two occurrences of each polarity per variable. All clauses remain proper and each regulator connects its two source portions. Thus the source-identity lemma applies to SAT and UNSAT without a supplied label.
\end{proof}

\begin{theorem}[NP-hard discovery of one constant-size strict22 module message]\label{thm:hard}
Let $H$ be an arbitrary strict signed exact-$(2,2)$ proper 3CNF, not assumed connected. There is a polynomial-time deterministic reduction $\rho$ returning a \emph{connected} strict signed exact-$(2,2)$ proper 3CNF $\rho(H)$ together with a complete authenticated static boundary/partition/hitting-set witness, such that:
\begin{align*}
 n&=9r^2+3r+h+30,& b&=k=3r,&q&\le r+h+30,\\
 r&=\max(2,\lceil h/15\rceil),& b+q&=\Theta(\sqrt n)\quad(h\to\infty),&&
\end{align*}
where $h=O(|H|)$ is the number of variables in a connectedification of $H$. Every private module has an exact local three-boundary-bit relation equal to the full eight-bit table, except distinguished module 0, whose relation is the full table iff $H$ is satisfiable and empty iff $H$ is unsatisfiable. If these eight-bit patterns are aligned as rows of a $k\times8$ binary pattern matrix, its rank over $\F$ is exactly \textbf{one} on both labels for every $r\ge2$. Consequently computing just module 0's eight-bit exact profile or deciding whether it is empty is NP-hard on this \emph{source-typed} family. No claim about arbitrary algorithms or an unconditional superpolynomial cost follows.
\end{theorem}
\begin{proof}
First construct the variable/clause incidence-connected components of $H$ by an $O(|H|^{O(1)})$ source scan. Rename each component to a consecutive set of variables, and apply the source-faithful conjunction connector successively. The resulting connected $K$ has $h=h_0+30(c-1)=O(h_0)$ variables for $c$ components and is satisfiable exactly when $H$ is. Each connector call is a fixed, charged constant-size transformation and all graph searches and source copies are polynomial.

Choose $r$ as displayed, construct $F_r$, and form $J(F_r,K)$ by selecting $\neg p_{0,0}$ from the boundary bridging clause $C_0^Y$ and a negative literal from $K$. Place all $h$ names of $K$ and the 30 new connector names into module 0. Every source clause still meets at most one private module: the connector's modified clause of $F_r$ belongs to module 0, and the other modified clause and all new regulator clauses use only original module-0 names, $K$ names and new private names. Modules $j>0$ are unchanged. Use $B_j=\{p_{j,3v}:0\le v<r\}$ for $j>0$ and $B_0$ equal to that set together with \emph{all} $h+30$ newly assigned private variables. This is a witnessed syntactic hitting family with cap $q=r+h+30$. The original untouched modules prove the minimum cap is at least $r$. The output has $n=9r^2+3r+h+30$ variables, and $m=4n/3$ clauses, while $b=k=3r$. Since $r=\Theta(h)$ and $n=\Theta(r^2)$ as $h\to\infty$, both $b$ and the exhibited $q$ are $\Theta(\sqrt n)$, which is not merely a point permitted by an inequality.

By the connector's \emph{pointwise} conjunction identity, for each fixed $Y_0$ the local existential relation on module 0 is the original module-0 relation intersected with the constant Boolean predicate $\SAT(K)$. The original relation is full by its private-zero witness. Thus the module-0 table is all-ones iff $H$ is SAT and all-zeros iff UNSAT, and all other local tables are all-ones regardless. Since at least one module $j>0$ remains, the pattern row matrix always has GF(2) rank one. NP-hardness follows from D\"ocker's strict exact-$(2,2)$ NP-completeness and a polynomial many-one reduction from any strict source $H$.
\end{proof}

\noindent\textbf{Rank firewall.} The pattern-matrix rank is \emph{not} the aggregate rank of embedded affine equations over original source variables, nor a bound on affine codimension $e$ in the Arvind--Guruswami 2CNF-plus-affine theorem. Every nonempty module profile is affine codimension zero, while the empty profile denotes inconsistency. Conflating binary representation length, pattern rank, affine row rank, and the \emph{time needed to acquire} the pattern would incorrectly promote a representation observation to a general SAT algorithm.

\section{The bounded-width easy control and an exact treewidth gluing lemma}
\begin{lemma}[A constant-width connector join]
Suppose tree decompositions of the primal graphs of connected $A,B$ have widths $w_A,w_B$ and contain bags covering the two three-variable clauses whose negative occurrences will be exchanged. Then the explicitly constructed $J(A,B)$ has a verified tree decomposition with
\[\operatorname{tw}(J(A,B))\le\max\{w_A,w_B,35\}.\]
This bound is independent of the number of earlier connector applications.
\end{lemma}
\begin{proof}
Keep all bags and edges of both trees, and shift the variable indices in $B$. Introduce a central bag consisting of the six (at most) source clause variables plus all 30 new gadget variables, size at most 36. Join the central bag to one bag containing the source clause on each side. All unchanged clauses remain covered by their previous bags. Both modified three-clauses and every gadget clause are contained in the central bag. Each source-port variable appears in the central bag and a previously connected subtree through the incident bag. No other source variable is introduced into new bags. Thus running intersection is preserved. Central width is at most 35, and the two source widths are unchanged.
\end{proof}
\noindent For ARC211's $F_r$, take boundary bags consisting of a fixed two-variable cycle anchor and up to three consecutive $y$ names; attach each private cyclic module with bags containing its fixed three boundary names and up to five ring names (including the private cycle anchor and up to three consecutive ring names). Every source clause is covered, all bag-index sets of each variable are connected, and every bag has size at most eight; hence $\operatorname{tw}(F_r)\le7$. The reproducer validates bag scope containment and connectedness on each finite control. A connected chain $K_t$ of $t$ fixed 15-variable SAT/UNSAT regulator sources has $\operatorname{tw}(K_t)\le35$ by induction, and therefore $\operatorname{tw}(J(F_r,K_t))\le35$. Its original static $b,q$ both diverge with $t$, while an explicit certified tree DP takes $O(2^{36}\operatorname{poly}(N))$ bit operations for this \emph{typed promised} family. The constant factor is crude, and a decomposition discovery/verification step must be charged. If $K$ is arbitrary, the bound becomes $\max\{35,\operatorname{tw}(K)\}$, so this lemma does \emph{not} make the NP-hard source image tractable.

\paragraph{Model-separated accounting.} \textbf{Indexed RAM} with word size $\Theta(\log N)$ may execute the explicit factor operations in polynomial time for the restricted width-35 easy chain, with all source parsing, incidence discovery, renaming, factor indexing, and cache space charged. \textbf{Read-only-input fixed multitape TMs} can simulate the explicit polynomial-time algorithms with polynomial time and polynomial visited work cells; their head movements and source rereads must be counted, not treated as indexed RAM accesses. \textbf{One shared read/write tape} includes the original $N$ input cells in its footprint and admits a conservative simulation bound $T_1=O(T_k(N+S_k+\log(T_k+2)))$, $P_1=O(N+S_k+\log(T_k+2))$ from a fixed-$k$ multitape machine under the corresponding convention. \textbf{Two fully writable tapes} must separately charge writes on both tapes and work-tape head position. \textbf{Fixed universal interpreter} must encode the source parser/controller and may incur polynomial simulation overhead, with no free oracle/profile table or answer-bit advice. No numerical FLMV/Williams forbidden point follows from host Python timings or from the static bound. The per-run algorithm is exact on both sides; independently attained worst-case time and space over different inputs are not used as simultaneous coordinates.
