\section*{Exact constructive transport}
For any finite CNF $F=\bigwedge_{i=1}^m C_i$ and fresh variable $t$ set
\[
G_t(F)=\bigwedge_{i=1}^m(\neg t\lor C_i).
\]
The guarded source is ALWAYS SAT (choose $t=0$) and $G_t(F)\models\neg t$ exactly when $F$ is UNSAT. If $F$ is SAT, a witness extended with $t=1$ disproves that entailment.
Fix strict ordinary Resolution with sources costing zero, each distinct derived DAG node costing one, and without weakening, extensions or semantic oracles. Let $D_{\rm Res}(F\vdash\bot)$ be the minimum paid refutation-DAG count and $D_{\rm Res}(G_t(F)\vdash\neg t)$ the minimum derivation count of that UNIT.

\begin{theorem}[Guarded proof-DAG isometry, PROVED/EXACT]
For every UNSAT $F$,
\[
\boxed{D_{\rm Res}(G_t(F)\vdash\neg t)=D_{\rm Res}(F\vdash\bot).}
\]
The proof correspondence preserves every source identifier, parent edge, pivot and shared intermediate lemma and counts each inference exactly once.
\end{theorem}
\begin{proof}
Define $\Phi_t(C)=C\cup\{\neg t\}$. Every original source $C_i$ maps to the guarded source $\Phi_t(C_i)$. No guarded source has positive $t$. By induction, all derived clauses contain negative $t$ but not positive $t$, so $t$ can never be a Resolution pivot. For every original pivot $x$ and clauses $A,B$,
\[
{\rm Res}_x(\Phi_t(A),\Phi_t(B))=\Phi_t({\rm Res}_x(A,B)).
\]
The inverse map deletes negative $t$ from each source and derived clause. These maps give a bijection on entire strict Resolution inference DAGs in both directions, taking the original empty clause precisely to the guarded unit. Taking minimum paid counts proves the identity.
\end{proof}
