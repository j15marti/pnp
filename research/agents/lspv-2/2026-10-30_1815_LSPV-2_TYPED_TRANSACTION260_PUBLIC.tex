\section{One-sided projection theorem}
Let $F(X)$ be any source formula, $E(X,Y)$ any auxiliary encoding, and $P_E(a)\equiv\exists y\,E(a,y)$. All cubes $\rho$ assign coherent original variables $X$, not independent occurrences. Set $B_\rho=\bigvee_{x\in\mathrm{dom}\rho}x^{1-\rho(x)}$, where $B_\emptyset=\bot$. A source-only clause $D$ may be empty.
\begin{theorem}
The following statements are equivalent:
\[
\begin{aligned}
\mathrm{COVER}&:\quad \forall a\in\{0,1\}^X,\ F(a)\Longrightarrow P_E(a);\\
\mathrm{UNSAT\mbox{-}EXPORT}&:\quad \forall\rho,\ \neg\mathrm{SAT}(E|_\rho)\Longrightarrow\neg\mathrm{SAT}(F|_\rho);\\
\mathrm{CLAUSE\mbox{-}EXPORT}&:\quad\forall\rho,D,\ E|_\rho\models D\Longrightarrow F\models B_\rho\lor D.
\end{aligned}
\]
Thus a source-model \emph{overapproximation} suffices for every source-only UNSAT/cube-clause export even if it is not exactly projection-equivalent on both labels.
\end{theorem}
\begin{proof}
If $F(a)=1$ and $a$ satisfies $\rho$, COVER produces $y$ satisfying $E(a,y)$. Hence an $E|_\rho$ contradiction excludes every such $F$ model. If $E|_\rho\models D$ but a source model falsifies $B_\rho\lor D$, it extends $\rho$, falsifies $D$, and COVER provides a contradictory $E$ extension. CLAUSE-EXPORT with $D=\bot$ implies UNSAT-EXPORT. If COVER fails at complete source assignment $a$ with $F(a)=1$ and $P_E(a)=0$, the complete cube $\rho=a$ contradicts UNSAT-EXPORT. QED.
\end{proof}
