\section{Canonical target, checkpoint and three falsifiable recoveries}
A valid \(\CM\) input is a duplicate-free ordinary OR-CNF whose every clause has exactly three distinct original source variables of one polarity, each active name occurring exactly twice positively and twice negatively. For a clause \(C\), \(\bar C\) flips signs while retaining OR. Let
\[
 \mathcal P_{\rm pair}=\{F\in\CM:\forall C\in F,\ \bar C\in F\},\quad
 \CS=\CM\setminus\mathcal P_{\rm pair},\quad
 L_\star=\{\operatorname{enc}(F):F\in\CS,\ \SAT(F)\}.
\]
Invalid encodings are rejected. Partial complementary pairs remain legal; neither connectedness nor minimum UNSAT is imposed. Let \(k\) be the active original variable count, \(m\) the clause count, and \(N\) the actual indexed input bits. Then \(3m=4k,\ m_+=m_-=2k/3,\ N=\Theta(k\log(k+2))\). D\"ocker's Theorem 1 proves \(\CM\)-SAT NP-complete and the fully paired special case satisfiable \cite{docker}. Previously proved M22-NONPAIRED1 sends paired inputs to fixed satisfiable six-variable \(Y\in\CS\), with positive supports \(123,145,246,356\), negative supports \(124,136,235,456\), witness \(111000\) and 20 of 64 satisfying assignments. Hence \(L_\star\) is NP-complete, but this is not a decision-time lower bound.

The three predeclared recovery hypotheses were:

\section{A sharp two-port signed-charge invariant}
Partition the \emph{original signed clause records} into two disjoint sets \(A\) and \(B\), and put \(S=\operatorname{vars}(A)\cap\operatorname{vars}(B)\). Define \(\delta_A(x)=\deg_A^+(x)-\deg_A^-(x)\).
\begin{theorem}[Separator sign charge, PROVED/EXACT in \(\CM\)]
For every \(F\in\CM\) and every original-record partition \(F=A\dot\cup B\),
\[
 3(|A_+|-|A_-|)=\sum_{x\in S}\delta_A(x),
 \qquad |\delta_A(x)|\le2,
 \qquad \big||A_+|-|A_-|\big|\le\left\lfloor\frac{2|S|}{3}\right\rfloor.
\]
For \(|S|\le1\) the two sides are separately sign balanced. For \(|S|=2\), local sign imbalance by one is permitted and attained by a connected \(\CS\) source.
\end{theorem}
\begin{proof}
Every source variable not in \(S\) has either all four original occurrences in \(A\) or no occurrences there, so its local signed excess is zero. All other excesses are supported on \(S\), where each local positive and negative occurrence count lies between zero and two. Sum local literal signs two ways: each positive ternary clause contributes \(3\) and each negative ternary clause contributes \(-3\). Divisibility by three yields the bound and the one-port consequence. The following construction attains \(3=2+1\) at two ports.
\end{proof}

Let \(H=\{123,145,246,356\}\), with each three-digit string an \emph{unsigned support} and positive/negative source signs assigned to the whole clause. Construct three original-record pieces:
\[
\begin{array}{ll}
P_A=(H\setminus\{123\})\cup\{(1,2,17),(3,17,18)\},& Q_A=H;\\
P_B=H+6,& Q_B=((H+6)\setminus\{789\})\cup\{(7,8,17),(9,17,18)\};\\
P_C=Q_C=\{(18,13,14),(13,15,16),(14,15,16)\}.&
\end{array}
\]
Here \(H+6\) increases all original indices by six. Their union \(F_{18}\) has \(k=18,m=24\), unique proper monotone clauses, every signed source occurrence count equal to two, a connected incidence graph, and \(F_{18}\in\CS\). Between \(A\) and \(B\cup C\) the interface is \(S=\{17,18\}\). The excesses \(\delta_A(17)=2,\delta_A(18)=1\) give \(|A_+|-|A_-|=1\). Directly \(A\) has two unmatched positive supports and one unmatched negative support; \(B\) has one unmatched positive and two unmatched negative supports. Thus the \(q^+_A=q^-_A\) cancellation from M22-DEFECT-ADAPTER131 and BLOCK-CUT-FACTOR139 cannot be imposed on arbitrary two-port pieces.

A satisfying original assignment sets \(1,3,4,7,8,9,13,14\) TRUE and every other original name FALSE. Exhausting all \(2^{18}\) assignments independently returns \(6{,}468\) models. This is an easy connected \(\CS\) source, not evidence of worst-case hardness.

\section{Exact factor continuation for locally unbalanced pieces}
Fix any certified tree \(T\) of original signed-clause \emph{pieces} \(G_v\), each parent clause assigned exactly once. The certificate lists original names, their membership in pieces, and for each name its pieces must induce a connected subtree (running intersection). The partition and certificate are checked with bit operations rather than trusted for free. For a piece \(v\), define
\[
 B_v=\{x\in\operatorname{vars}(G_v): x\text{ occurs in another piece}\},\
 b_v=|B_v|,\
 H_v=P_v\cap Q_v,\
 p_v=|P_v\setminus Q_v|.
\]
Unlike the globally balanced parent, \(p_v\) need not equal \(|Q_v\setminus P_v|\).

\begin{lemma}[One-sided degree-two residual without local signed balance]
For any \emph{globally valid} \(F\in\CM\), any original-clause piece \(G_v\), any fixed values of the original named boundary \(B_v\), and any choice of one TRUE original literal per positive-unmatched support in \(P_v\setminus Q_v\) with compatible pins, the remaining constraints consist of one interval \(1\le\sum_{x\in S}x\le2\) for each \(S\in H_v\) and one negative disjunction per \(S\in Q_v\setminus P_v\), under the pins. Every unpinned original source variable occurs in at most two of these surviving constraint \emph{records}.
\end{lemma}
\begin{proof}
The selected positive-unmatched disjunctions are satisfied. The paired positive/negative clauses on one support are equivalent to one not-all-equal interval record. An unpinned original name appears in precisely the surviving paired records and negative-unmatched records corresponding to \emph{its negative original literal occurrences inside \(G_v\)}. The entire \(\CM\) parent has only two negative occurrences of that name, so this local residual degree is at most two, regardless of sign imbalance in the piece. The selected pins remain common across all records with the same original name.
\end{proof}

The signed degree-two interval feasibility construction from INTERVAL-FACTOR134, using a polynomial \((g,f)\)-factor or matching algorithm, gives a source-coherent exact polynomial-time test for each such residual. Selecting witnesses in only the \(p_v\) unmatched positive clauses costs at most \(3^{p_v}\) attempts for each prescribed boundary valuation; no oracle supplies the correct one.

\begin{theorem}[One-sided named factor tree, PROVED/EXACT under supplied validated certificate]
There is one fixed uniform deterministic exact SAT/UNSAT decider on the accepted certificate-annotated \(\CM\) sources whose \emph{simultaneous} elementary-bit time and writable/index-bit peak space obey
\[
 T(F,T)\le \operatorname{poly}(N)
 \left(1+\sum_{v\in T}2^{b_v}3^{p_v}\right),\qquad
 S(F,T)\le\operatorname{poly}(N)+O\!\left(\sum_{v\ne r}2^{|S_{v,p(v)}|}\right),
\]
where \(S_{v,p}=\operatorname{vars}(G_v)\cap\operatorname{vars}(G_p)\), and the polynomial absorbs a polynomial-size certificate and bit-address overhead. Consequently \(b_{\max}+p_{\max}=O(\log N)\) yields a polynomial-time, polynomial-space decider \emph{on this certified class}. This does not provide such a certificate, or a favorable ordinary-SAT ARC transformation, for every input.
\end{theorem}
\begin{proof}
For every piece \(v\), enumerate its \(2^{b_v}\) boundary valuations and its at most \(3^{p_v}\) consistent choices of TRUE source witnesses. For each choice invoke the previously established degree-two signed interval factor algorithm and cache whether this local boundary valuation admits a feasible original-source extension. All candidate failures, graph construction, source replay and reconstruction are charged. Root the checked tree. For a child \(v\) with parent \(u\), calculate for each assignment on named separator \(S_{vu}\) whether there exists a locally feasible boundary valuation on \(B_v\), consistent with this separator and with the previously computed child messages. Write this one-bit exact message and an optional source-witness pointer; the message table has at most \(2^{|S_{vu}|}\) bits. At the root accept precisely if a compatible valuation exists. Induction from the leaves proves soundness and completeness because running intersection makes all occurrences of the same original name globally consistent. A top-down witness reconstruction, when requested, chooses only previously certified compatible extensions. Process branches and factor workspaces sequentially; the cached message tables and polynomial-size parser, proof of certificate validity, names, stack, indexes and graph workspace coexist, giving the displayed \emph{joint} bounds. The message-table term can be exponential for arbitrary large separators, and is not silently called polynomial. All entries are written/read with charged bit and address operations; source input remains indexed read-only. Neither a free table oracle nor an advance SAT/UNSAT label is used.
\end{proof}

This theorem specializes the established general tree-of-factor-cores method TREE-FACTOR-JOIN135 to a one-sided signed witness parameter, and generalizes the \emph{balanced articulation block} method BLOCK-CUT-FACTOR139 to locally imbalanced pieces. Classical factor algorithms and running-intersection dynamic programming are \textbf{KNOWN THEOREM} components, not new claims of priority.
