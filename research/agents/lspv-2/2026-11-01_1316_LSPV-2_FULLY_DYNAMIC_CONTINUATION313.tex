\section{New exact fully dynamic continuation lemma}
The online update alphabet consists of $\operatorname{SET}(\beta_i,v)$ and $\operatorname{SET}(\sigma_i,v)$, $v\in\{0,1\}$. The machine must answer the current SAT decision following any future sequence of SET commands. It receives no external rereadable pin array or update history, and a quiescent internal state must support all subsequent commands. This is NOT the static indexed-input FLMV machine model.
\begin{theorem}
For every $t\ge1$, all $4^t$ binary profile pairs $(\beta,\sigma)$ are inequivalent under fully retroactive SET continuations. Every exact deterministic online machine in this no-external-reread model therefore needs at least $2t$ retained quiescent state bits. An online algorithm stores the $2t$ profile bits and a $\lceil\log_2(t+1)\rceil$-bit intersection counter, uses constant indexed-word operations for each update and answers by testing the counter for zero.
\end{theorem}
\begin{proof}
Take two distinct $2t$-bit states. Choose a coordinate $i$ whose $(\beta_i,\sigma_i)$ pairs differ, and apply the SAME SET commands in both runs to zero both bits at every other coordinate. The four remaining possibilities $00,01,10,11$ are distinguishable by the current decision and at most one further common SET command: to distinguish a differing $\beta$ set $\sigma_i=1$, to distinguish a differing $\sigma$ set $\beta_i=1$, and for $01$ versus $10$ set $\beta_i=1$. The $00$ versus $11$ pair already has opposite labels. Thus every pair admits a distinguishing continuation of length at most $2(t-1)+1$. A deterministic exact machine cannot merge their quiescent states without giving identical future answers on distinguishable cases. The $4^t$ classes require $\log_2 4^t=2t$ bits. This derives from future decision behavior, not recovery of the original variable assignment or a syntactically injective pin key.

For the upper bound maintain $c=\sum_i\beta_i\sigma_i$. On a SET of one bit in coordinate $i$, read that pair, change the requested bit, and replace $c$ by $c-\beta_i\sigma_i|_{\rm before}+\beta_i\sigma_i|_{\rm after}$. The invariant and correct decision follow inductively. Two semantic bit reads, at most one changed semantic-bit write and one counter update suffice in an indexed-word RAM. Native bit-tape addressing, head motion, counter carries, and if materialized the two or three original-variable pin-slot changes must be charged separately.
\end{proof}
