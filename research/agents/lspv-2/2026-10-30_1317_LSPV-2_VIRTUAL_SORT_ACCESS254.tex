\section{The indexed source and exact output map}
Let $F=\bigwedge_{j=0}^{m-1}C_j$ be a nonempty proper 3-CNF with three
distinct variable IDs per original clause, and with dense active IDs
$1,\ldots,n$. Assume an indexed, read-only, fixed-width signed-occurrence
record encoding supplying a literal $\mathrm{Lit}_F(j,p)$, $p\in\{0,1,2\}$,
by a constant number of $O(\log N)$-bit-address source probes and
$\log^{O(1)}N$ indexed-machine steps, where $N$ is source bit length.
This is an explicit input-format hypothesis, not a free semantic oracle.

Set
\[
 L=3m,\quad P=2^{\lceil\log_2L\rceil},\quad
 d=\log_2P,\quad w=\lceil\log_2(n+2)\rceil,\quad
 Q=\frac{P d(d+1)}4.
\]
For each of $P$ initial records reserve $w$ key bits and one payload bit.
Records $r<L$ carry key $|\mathrm{Lit}_F(\lfloor r/3\rfloor,r\bmod3)|$
and an independent existential occurrence payload. Each remaining record has
sentinel key $n+1$ and payload zero. Each key bit is pinned by a unit; each
source clause constrains its three independent payloads with its original
literal signs. No occurrence payload is silently identified with another.

Run the fixed Batcher bitonic stages $(k,j)$, with
$k=2,4,\ldots,P$, $j=k/2,k/4,\ldots,1$. Each unordered pair
$(i,i\mathbin{\mathrm{xor}}j)$ is used once per stage, with $i\&j=0$.
The first indexed output wire is ascending when $i\&k=0$ and descending
otherwise. Its exact Boolean compare/swap circuit uses two pinned constants,
then five gates per key bit: XNOR, the strict directional comparison bit,
AND with the equality prefix, OR into the strict comparison flag, and
AND into the equality prefix. Two MUXes per record bit output the two
possibly swapped records. All gates have \emph{complete equivalence}
clauses, not one-way implications. After the final sorting stage, each
adjacent record pair receives key-XNOR and AND-chain gates and two guarded
implications ensuring payload equality when keys agree.

All units are converted to four proper 3-clauses using two fresh variables;
all binaries become two proper 3-clauses using one fresh variable. Ternary
gate clauses are unchanged. Variable identifiers are assigned to five
contiguous arithmetic blocks: original record bits; comparator gates;
final-adjacency gates; pin and gate binary-padding names. Each output clause
falls into exactly one of the following fixed-size blocks:
\[
\begin{array}{ll}
\text{original source constraints} & m,\\
\text{all fixed key/padding pins} &4(Pw+P-L),\\
\text{comparator block} &Q(32w+16),\\
\text{adjacent equal-key checks} &(P-1)(9w-3).
\end{array}
\]
Thus, writing $M$ for output clause count and $V$ for output named variables,
\[
 M=m+4(Pw+P-L)+Q(32w+16)+(P-1)(9w-3),
\]
\[
 V=P(w+1)+Q(7w+4)+(P-1)(2w-1)
 +2(Pw+P-L)+Q(4+8w)+2(P-1)(w-1).
\]
The declared binary output encoding is \texttt{0110}, followed by $V,M$
in fields of $h=\max(\mathrm{bitlen}(V),\mathrm{bitlen}(M))$ bits, then
$3M$ fixed-width signed literal slots of length $1+\mathrm{bitlen}(V)$.
Every bit has an unambiguous physical address in this encoding. This
format is precisely defined but has \emph{not} been proved identical to
every native FLMV SAT parser; such re-encoding must be paid separately.

\begin{theorem}[Direct intermediate indexed-bit emitter]
For every $F$ satisfying the stated source format, the indexed-bit algorithm
$\mathrm{Bit}_{E(F)}(t)$ described below produces exactly bit $t$ of the
fully materialized proper ternary output encoding, for every physical
address $0\le t<|\operatorname{enc}(E(F))|$. It needs no stored
$\Theta(P)$ source-occurrence index or sorted-key array. Relative to a
source-literal record read taking $q(N)$ time and $s(N)$ writable bits, an
output-bit request requires $\log^{O(1)}N+O(q(N))$ time and
$O(\log N)+s(N)$ writable bits. Moreover,
\[
 \mathrm{SAT}(E(F))\iff\mathrm{SAT}(F)
\]
for both YES and NO original sources.
\end{theorem}
\begin{proof}
For any requested output bit $t$, the header and fixed-width literal slot
arithmetically identify an output clause index $c$ and local literal
position $p$. The four contiguous clause blocks above identify its source
clause, pin, comparator, or equality guard by integer quotient and
remainder. For a comparator, the stage index $s$ and pair rank $r$ come
from $c$. The unique $h$ with
$h(h-1)/2\le s<h(h+1)/2$ yields
$k=2^h$, $j=2^{h-1-(s-h(h-1)/2)}$. The first wire of pair rank $r$ is
\[
 i=2j\lfloor r/j\rfloor+(r\bmod j),
 \qquad i'=i+j.
\]
For an output wire in the previous stage, mask away bit $j'$ of its wire
index and invert its pair rank by the same formula. This identifies the
exact previous-stage output \emph{variable ID}, without recursively
evaluating or materializing any gate. Local gate IDs, gate/padding clause
ordinal, signs and MUX selection directions are all elementary arithmetic.
A source literal record is read only for original source clauses and
input-key pins. Every other output literal is independent of source
\emph{values} because the comparator trace is existentially represented.
Thus the bit accessor uses logarithmically many index bits, a bounded
number of arithmetic inversions and at most one original literal-record
read, proving the local resource claim.

For semantic equivalence, a satisfying $F$ assignment sets every occurrence
payload to its original-variable value and thereby satisfies all original
clause constraints. Input key pins and dummy payload pins are fixed; the
complete comparator-equivalence gates uniquely determine the sorted trace.
All adjacent equal-key payloads agree, so all equality guards hold.
Conversely, any satisfying output assignment obeys all pins and comparator
gate equivalences. Batcher's network sorts a permutation of the original
records by source variable ID. Adjacent equal-key guards force all payloads
of a given source variable to agree. Reading the common payload value for
each original variable then satisfies every original source clause.
Fresh padding variables in the 1/2-to-3-clause expansions preserve
existential satisfiability exactly. This proves both labels. See
\cite{batcher1968} for the known fixed sorting-network component.
\end{proof}

\section{Counterexample and finite hostile controls}
\begin{lemma}[Counterfeit without authenticated adjacency]
For the eight clauses containing all $2^3$ signed sign-patterns on
$x_1,x_2,x_3$, the source is UNSAT, but deleting the two payload-consistency
guards for every adjacent sorted record pair produces a satisfiable
sorting-gate formula.
\end{lemma}
\begin{proof}
The eight original clauses jointly rule out all eight source assignments.
Without payload-consistency guards, set one original occurrence payload in
each clause so that its signed literal is true, independently of every other
occurrence. Assign all pinned keys correctly, execute every bitonic gate
according to its complete truth table, and satisfy all key equality
computation gates. No deleted guard enforces agreement among equal-key
payloads. This constructs a satisfying assignment for the weakened formula.
The independent checker constructs and validates it and finds seven
violated omitted guards. The counterexample is to the weakened compiler,
not to the complete theorem.
\end{proof}

An independent materializer walks genuine bitonic stages, creates the full
source-indexed variables, and emits all clauses. Its stage transitions and
clause ordering are implemented separately from the direct rank inverse.
Its results were compared clause-by-clause and output-bit-by-output-bit or

\section{Fully charged boundaries for ARC/FLMV}
The output has $M=\Theta(Pw\log^2P)$ proper ternary clauses and physical
bit length $\Theta(M\log V)$. For ordinary source encodings with
$N=\Theta(m\log n)$, the construction has length $N\log^{O(1)}N$ in
suitable polynomially related source sizes, \emph{not} $N^{1/2}$.
A complete physical output requires $\Omega(|\operatorname{enc}(E(F))|)$
bit writes even with a constant-space streaming tape. The measured
Python direct-bit streaming of the 1,262,194-bit eight-clause UNSAT
control took 4.528 seconds; source UP-DPLL took about $0.00005$ seconds,
seven search nodes and 104 instrumented literal tests. This comparison
includes all emitted output bits, excludes the independent oracle, and
is neither a native FLMV step count nor a universal SAT performance claim.

A hypothetical guest $A$ accessing the resulting virtual child would still
have its own time and writable-space costs, plus guest-index guarding,
source-index reconstruction, policy discovery, failed trials, input format
conversion, ancestor state and cache/replay. Existing LSPV-4 guarded-head
and high-water-allocator counterexamples remain applicable. The same
machine, simultaneous time/space FLMV forbidden region is a \emph{constraint}
\cite{flmv2005}, not achieved by this emitter. The proposed ARC recurrence
$K'\le\max(11/10,3/5+K/2)$,
$L'\le\max(1/2,L/2)$ remains a \emph{conditional contract}:
this intermediate normalizer expands, and its direct bit access says
nothing about the guest's $L$ exponent or about recursive hereditary
power-short children. Existing policy recognition, backdoor depth and
source-certification work \cite{dreier2024} can support a complete
controller only with their acquisition and unsuccessful trials charged.
