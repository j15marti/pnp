\section*{New exact spectrum theorem}
Let $A\in\mathbb F_2^{m\times n}$ have \emph{nonzero} rows $a_i$ with nonempty supports $S_i$, of widths $d_i=|S_i|$. Let $b\in\mathbb F_2^m$ and assume $Ax=b$ is \emph{inconsistent}. Expand each row into its full signed-CNF parity block, one distinct labelled clause $C_{i,w}$ forbidding each assignment $w\in\mathbb F_2^{S_i}$ with $\bigoplus w\ne b_i$. Preserve source labels even if syntactically identical rows or clauses occur. Then $M=\sum_i2^{d_i-1}$.

Write $U_i=\{x:A_{-i}x=b_{-i}\}$, the solution set with row $i$ removed. When $U_i\ne\varnothing$, set
\[
r_i=\operatorname{rank}([A_{-i};P_{S_i}])-\operatorname{rank}(A_{-i}),
\]
where $P_{S_i}$ selects the named coordinates in $S_i$; otherwise leave $r_i$ undefined. For labelled source $C$, say $C$ is \emph{indispensable} iff deletion of that single labelled record makes the expanded CNF satisfiable.

\begin{theorem}[Exact labelled source-clause spectrum, every inconsistent affine system]
For every $m,n,A,b$ as above, with no minimal-dependency or bounded-row-width promise, the number of indispensable clauses belonging to row $i$ is exactly
\[
\boxed{E_i=\begin{cases}0&U_i=\varnothing,\\ 2^{r_i}&U_i\ne\varnothing.\end{cases}}
\qquad E(F)=\sum_i E_i .
\]
If $U_i\ne\varnothing$, then $0\le r_i\le d_i-1$. In that row the indispensable forbidden local words are \emph{exactly} the affine image $P_{S_i}(U_i)$; consequently they form an affine subspace of cardinality $2^{r_i}$ inside the wrong-parity hyperplane. Moreover the number of individually indispensable \emph{signed literal occurrences} (those whose single sign reversal makes the complete formula SAT) is
\[
\boxed{L_{\mathrm{sign}}(F)=\sum_i d_i E_i.}
\]
All numbers and a satisfying assignment witness for every indispensable clause are deterministically computable in time polynomial in the \emph{fully expanded input encoding length} $N$.
\end{theorem}
\begin{proof}
Deleting a source clause $C_{i,w}$ still enforces every other row $j\ne i$. Within row $i$, it forbids every wrong-parity pattern \emph{except} $w$. Therefore the resulting CNF is SAT precisely when $U_i$ contains an $x$ with $x_{S_i}=w$. If $U_i$ is empty, none survives.

If $U_i$ is nonempty but some $x\in U_i$ satisfied the removed row equation, it would satisfy \emph{all} equations, contradicting assumed inconsistency. Hence every $x\in U_i$ has wrong parity on $S_i$. Its coordinate projection is a translate of $P_{S_i}(\ker A_{-i})$. The image dimension is
\[
\dim \ker A_{-i}-\dim(\ker A_{-i}\cap\ker P_{S_i})
=\operatorname{rank}([A_{-i};P_{S_i}])-\operatorname{rank}(A_{-i})=r_i.
\]
The projected image lies in one parity hyperplane, so $r_i\le d_i-1$. There is one labelled forbidden clause for each wrong-parity local word. The image contains exactly $2^{r_i}$ such words, proving the first formula.

Take the deletion witness $x$ for indispensable clause $C$. It falsifies $C$ and satisfies all other original clauses. Reversing the polarity of \emph{any} literal occurrence of $C$ makes that clause true under $x$, leaving the others true. Conversely a SAT witness after reversing one source occurrence cannot satisfy the original clause, since that would model the original UNSAT source. Therefore sign reversal is SAT iff the original clause is indispensable, proving the second formula.

For computation, sparse-relabel the at most $N$ input-mentioned variables; use GF(2) rank and consistency for each $i$, then rank the stacked matrix with coordinate selectors. For each image word $w$ solve $A_{-i}x=b_{-i}$ subject to $x_{S_i}=w$ by Gaussian elimination to recover an explicit witness. There are at most $M\le N$ such clauses in the \emph{expanded input}. Input parsing, matrix construction, bit access, consistency/rank checks, witness construction and output all have polynomial bit costs and polynomial peak space under a standard explicit encoding. This asserts a polynomial source-analysis \emph{upper bound}, not any lower bound on arbitrary SAT algorithms.
\end{proof}

\begin{corollary}[Correct scope of the prior mixed source floor]
Under the fixed source-transparent at-most-binary-premise $R_{\mathrm{mix341}}$ grammar, $W_R(F)\ge\max\{0,E(F)-1\}$. This is the earlier LSPV-1/378 ancestry theorem specialized using the \emph{new} exact affine $E(F)$ evaluator, not a new general lower bound. If every $E_i=2^{d_i-1}$ and every row width is at most three, the LSPV-2/389 AND3+XOR proof attains $M-1$. Otherwise $E-1$ need not be sharp, and no optimal mixed proof follows from this theorem.
\end{corollary}
