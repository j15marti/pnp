\section{Parameterized exact theorem}
Let $F$ be a canonical formula, $p$ an authenticated coherent original-variable partial assignment with no falsified original clause, $f$ the number of free variables, $u$ the number of uncovered clauses, and $\eta=\sum_x\min(s_x^+,s_x^-)$. Fix a polynomially acquired, source-clause-edge-disjoint set $\mathcal C=\{C_1,\ldots,C_\nu\}$ of odd residual binary cycles. Assume the authenticated saturated signed-spill equality
\begin{equation}\label{eq:delta}
\delta=2f-u-\eta-\nu=0.
\end{equation}
At this saturation the established theorem partitions satisfying completions into disjoint affine systems indexed by one doubly true edge on each cycle~\cite{pnpterminal}. Write $Z$ for the union of free variables appearing in the selected cycles, and $W$ for the other free variables. Preferred-value and exact-one exterior-clause rows have the form
\begin{equation}\label{eq:rows}
A_Zz+A_Ww=b\quad\text{over }\GF.
\end{equation}
Eliminating $w$ once gives the source-provenanced system
\begin{equation}\label{eq:proj}
Hz=h,
\end{equation}
with $r_W=\operatorname{rank}(A_W)$ and $q=\operatorname{rank}(H)$. An authenticated row of $H$ is a XOR combination of original outside-cycle parity/preference rows, not an unconditional CNF consequence outside hypotheses~\eqref{eq:delta}. For every compatible cycle assignment $z$ satisfying \eqref{eq:proj}, the number of $W$-extensions is precisely $2^{|W|-r_W}$.

Construct a graph on the $\nu$ cycles, linking two whenever they share an original variable or co-occur in an equation of $H$. Let $G_1,\ldots,G_t$ be its connected components. Assign each projected equation to the unique component containing its support; a zero-support equation with RHS $1$ is an immediate refutation. For each component $G_j$, take a concrete deterministic ordering of its cycles. Define $q_j$ as the number of projected equation rows assigned to it (after independent elimination), and $b_j$ as the largest number of already processed shared variables that occur in a later cycle in the same component.

\begin{theorem}[Overlap-aware component-frontier terminal]\label{thm:dp}
Under the exact source and saturation hypotheses above, an authenticated dynamic program computes the precise number of original-source satisfying completions, or a replayable exhaustion of all feasible original cycle-choice transitions, by the formula
\begin{equation}\label{eq:count}
\boxed{\#\operatorname{SAT}(F\mid p)=2^{|W|-r_W}\prod_{j=1}^{t} B_j,}
\end{equation}
where $B_j$ is the number of mutually compatible selected-edge templates in component $G_j$ whose XOR contributions meet that component's projected syndrome. For any stated cycle order it uses, in addition to polynomial acquisition/elimination and proof checking, at most
\begin{equation}\label{eq:cost}
\operatorname{poly}(N)\sum_{j=1}^{t}\left(\sum_{i\in G_j}|C_i|\right)2^{q_j+b_j}
\end{equation}
bit operations and peak writable space bounded by the full polynomial matrix/source-accounting workspace plus
$\operatorname{poly}(N)\max_j2^{q_j+b_j}$. In particular, if the acquired orders satisfy $\max_j(q_j+b_j)=O(\log N)$, the fully charged \emph{ordinary polynomial-time} terminal is exact on this recognized restricted class, including shared-variable cycles. If an explicit work cap is exceeded, the policy returns UNRESOLVED and invokes a correct exact fallback; it must never return UNSAT merely because the cap is exhausted.
\end{theorem}

\begin{proof}
For each original cycle variable $v$, fix one \emph{owner}, its first cycle in the component order. Its Boolean value is imposed by that owner's selected-edge template. Every later template mentioning $v$ must agree with the remembered value; otherwise that combination is discarded. An owned variable contributes its $H$-column multiplied by its assigned bit to the syndrome exactly once. A shared variable's later appearances contribute nothing, so the projected syndrome has neither omission nor repeated XOR charge.

After processing a prefix, retain only the XOR syndrome accumulated from owner variables and the Boolean values of assigned variables that occur in future cycles, the \emph{live frontier}. Two prefixes in the same state have identical compatibility and syndrome behavior against every suffix. Their numbers of selected-edge sequences therefore add; one representative predecessor path suffices for a witness. For a new cycle, try every authenticated selected-edge option, reject a mismatch on the overlap frontier, add the owner contribution to the syndrome, and discard variable values no longer needed in later cycles. Induction on the processed cycles proves that the table entry counts exactly the compatible template prefixes with its given state. The terminal frontier is empty, so the target-syndrome entry equals $B_j$.

Rows of $H$ cannot couple distinct components by the definition of the interaction graph. Thus compatible choices factor as $\prod_jB_j$. By the previously established disjoint-affine-union theorem~\cite{pnpterminal}, each full selected-edge vector describes a distinct source SAT-model class. Gaussian back-substitution reconstructs $2^{|W|-r_W}$ choices of $W$ per accepted vector. This proves \eqref{eq:count} without double counting. At each component stage there are at most $2^{q_j+b_j}$ states and $|C_i|$ candidate transitions per state, proving \eqref{eq:cost}. Matrix and counter arithmetic are charged, including bit lengths of large model counts. The row-XOR premises, original cycle IDs and complete original witness or exhausted table can be checked independently.\end{proof}

\paragraph{Proof scope.} The theorem specializes established variable-elimination/frontier and factor-graph dynamic programming methods~\cite{kschischang2001}; it is a derived restricted SAT terminal, not a claim of a novel universal model-counting algorithm. A constant $q_j+b_j$ is not guaranteed or supplied free. Greedy triangle acquisition is polynomial but the full matrix and table may exceed FLMV's very restrictive space budget.

\section{Four falsifiers and same-source computational tests}
\noindent\textbf{F1 (parity-only false positive).} On the valid nine-variable F9 source, the six-pin cube fixes $x_8=x_3=x_7=x_6=0$, $x_1=x_5=1$. Outside-cycle parity is consistent, but all three exact projected cycle options have syndromes $2,3,6$, whereas the required syndrome is $7$. The new frontier DP exhausts three original-clause choices and returns UNSAT. Independent enumeration finds zero completions among eight. Root F9 has 70 models, so the pinned cube's UNSAT \emph{cannot} be promoted to UNSAT for the whole original source.

\noindent\textbf{F2 (shared vertices are not independent).} In the canonical K5 fifteen-variable SAT control, the two authenticated triangle cycles share one original variable. Four of nine nominal choice pairs conflict on the shared value; there are exactly two satisfying source extensions. The new DP carries one frontier bit, rejects all four incompatible transitions, and correctly counts two models. Ignoring the frontier would be unsound.

\noindent\textbf{F3 (whole-product explosion is avoidable only with certified decomposition).} For 32 independent copies of the valid F15 control pinned to its two-model SAT cube, there are $64$ authenticated cycles and $3^{64}=3{,}433{,}683{,}820{,}292{,}512{,}484{,}657{,}849{,}089{,}281$ nominal choices. The authenticated interaction graph gives 32 components; the DP makes 384 recorded transition attempts, peaks at six states, and counts $2^{32}$ models. This is an \emph{easy disconnected control}, not evidence of hard connected-instance contraction.

\noindent\textbf{F4 (constant canonical output requires a solved label).} After a restricted residual $F\mid p$ is certified SAT or UNSAT, writing respectively the fixed canonical YES instance Y6 or certified canonical NO instance U198 preserves that \emph{residual query}'s label. But the compiler has already decided the query, and its fixed output length can be larger than the original. On a nonempty pin, this is not a parent-formula equivalence unless the other branches have separately been handled. In particular F9 is SAT at the root although its pinned F9 cube emits U198. A free all-input constant semantic compressor would circularly assume a SAT solver.

\section{Canonical semantic compression and the ARC firewall}
The gamma-header encoding has unbounded fields. Y6 occupies 92 bits and U198 occupies 6,632 bits in the declared format. A constant terminal output is genuinely power-short only when the parent length is at least $M^2$. For 32 independently pinned SAT F15 components the source length is 17,956 bits, so a Y6 output satisfies $92^2=8,464\le17,956$, but its label was already decided by an easy restricted terminal. This does not establish uniform children for connected hard inputs, nor any improvement of the actual FLMV forbidden region. For U198, even the verified fixed NO output is no shorter than the source. The fixed-output construction does not implement a generic arbitrary-$A\mapsto\Phi(A)$ compiler, a same-machine near-linear SAT-to-D\"ocker normalizer, or the numerical FLMV transport.

The current necessary conditional ARC recurrence remains
\[
 K'\le\max\{11/10,3/5+K/2\},\qquad
 L'\le\max\{1/2,L/2\}.
\]
Neither its hypotheses nor a valid all-input hereditary family of power-short children has been constructed. FLMV's time--space theorem~\cite{flmv2005} concerns a specified machine model and quantitative input measure; mere NP-completeness of D\"ocker's canonical language cannot import its numerical forbidden region. Falsification controls DELAY/COPY/RECOMP, lazy virtual state, guest input-access, cache retention and simultaneous peak space remain mandatory. \textbf{P versus NP is OPEN.}
