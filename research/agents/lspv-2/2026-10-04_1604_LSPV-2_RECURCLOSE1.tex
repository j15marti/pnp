\section*{PRIMARY LITERATURE}
Williams' 2024 self-improvement theorem for Circuit-SAT proves genuine bootstrapping: an algorithm for exponentially large circuits with exponent pair \((\alpha,\beta)\) yields a smaller-circuit algorithm with exponent \(\beta-\alpha\). Williams explicitly lists as an open problem whether self-improvement can reach the \(P=NP\) regime and states that the current argument encounters bottlenecks before that point.

Faliszewski--Ogihara study length-decreasing self-reducibility and show, for broad padded classes including NP, that if all complete languages have suitable length-decreasing self-reductions then the class collapses to P. SAT itself has its standard disjunctive length-decreasing self-reduction, but that ordinary two-way branching only shortens by a small amount per level.

Mahaney's theorem and the later Ogiwara--Watanabe sparse-hard-set work show how a sparse semantic image can prune the SAT self-reduction tree. Their mechanism is relevant because low image density is useful only together with a SAT-preserving reduction or selector; algebraic collisions by themselves are not enough.

Fortnow--Santhanam, Dell--van Melkebeek, and Drucker give strong conditional barriers to instance and OR-compression. Under the counterfactual \(P=NP\), the associated PH-collapse consequences are not terminal contradictions, but they show that a cheap answer-preserving compressor is already a powerful object.

Buss--Williams and Williams' earlier SAT time-space work give the known deterministic SAT forbidden region used below. In particular the prior Williams tradeoff implies, in exponent notation, that a SAT algorithm in \(\mathrm{DTISP}(n^{c+o(1)},n^{\varepsilon+o(1)})\) must satisfy
\[
c+\varepsilon\ge 2\cos(\pi/7)
\]
within the stated random-access model, with stronger numerical tradeoffs available for particular \(\varepsilon\).

\section*{DUPLICATION / CONTRADICTION AUDIT}
RETURNSQUEEZE1 proved the one-step composition
\[
K'\le C_T+\lambda\beta K
\]
and identified \(\lambda\beta<1\) as the scalar contraction condition. It also proved the full-input-carry obstruction \(\lambda b\ge1\) and retired generic Cook--Levin/Robson self-encoding as a contraction mechanism.

RECURCLOSE1 does not alter those results. Its new point is that if the composed return bridge is itself a fractional SAT oracle self-reduction, one need not repeatedly transform \(A\) into \(A'\). The same fixed reduction can be recursively substituted for its smaller SAT queries, eliminating dependence on the original exponent \(K\).

\section*{Exact model}
Fix one deterministic exact SAT decider \(A\), whose source code may be used as a fixed finite object. An \(A\)-derived fractional SAT shrinker is a deterministic oracle procedure \(R_A^{\mathrm{SAT}}\) such that, on every SAT instance \(x\) of length \(n\),
\begin{enumerate}
\item with correct SAT-oracle answers it outputs \(\mathrm{SAT}(x)\) exactly;
\item its non-oracle work is at most \(n^{r+o(1)}\);
\item it makes at most \(n^{\eta+o(1)}\) SAT-oracle queries;
\item every oracle query has length at most \(n^{\theta+o(1)}\) for one fixed \(0\le\theta<1\);
\item the same constants and procedure apply at every input length; and
\item outside those explicit oracle calls it does not invoke \(A\) as an uncharged semantic subroutine.
\end{enumerate}
The oracle queries may be adaptive.

The procedure may depend nonblackboxly on the fixed code of \(A\). That dependence does not itself give a nonrelativizing theorem.

\section*{PROVED/EXACT: recursive closure theorem}
\textbf{Theorem RECURCLOSE1.}
If an \(A\)-derived fractional SAT shrinker exists with parameters \((r,\eta,\theta)\), then SAT has a deterministic algorithm with
\[
\boxed{
T(n)\le n^{C+o(1)},
\qquad
C=\max\left\{r,\frac{\eta}{1-\theta}\right\}.
}
\]
The exponent \(C\) is independent of the original running-time exponent of \(A\).

\textbf{Proof.}
Simulate \(R_A^{\mathrm{SAT}}\) on \(x\). Whenever it asks a SAT query \(y\), answer it recursively using the same simulation. Query lengths decrease from \(n\) to at most \(n^{\theta+o(1)}\), so recursion reaches constant size after \(O(\log\log n)\) levels.

Ignoring lower-order terms, at depth \(j\) the maximum subinstance length is
\[
n^{\theta^j}.
\]
The number of active recursion nodes at depth \(j\) is at most
\[
n^{\eta(1+\theta+\cdots+\theta^{j-1})+o(1)}
=
n^{\eta(1-\theta^j)/(1-\theta)+o(1)}.
\]
Local work per node is at most
\[
n^{r\theta^j+o(1)}.
\]
Thus total work at depth \(j\) has exponent at most
\[
\frac{\eta(1-\theta^j)}{1-\theta}+r\theta^j+o(1).
\]
This is a convex interpolation between \(r\) and \(\eta/(1-\theta)\), so it is at most
\[
\max\left\{r,\frac{\eta}{1-\theta}\right\}+o(1).
\]
The \(O(\log\log n)\) depth contributes only \(n^{o(1)}\). \(\square\)

This is an exact conditional algorithmic theorem. The shrinker existence is OPEN.

\section*{PROVED/EXACT: recursive space closure}
Assume one invocation of \(R_A^{\mathrm{SAT}}\), excluding recursive oracle answers, uses
\[
n^{\sigma+o(1)}
\]
workspace and maintains at most one explicit oracle-query buffer of size
\[
n^{\theta+o(1)}
\]
at a time. Process recursive oracle calls depth-first.

Let
\[
\rho=\max\{\sigma,\theta\}.
\]
The recursion stack uses
\[
n^{\rho+o(1)}
+
n^{\rho\theta+o(1)}
+
n^{\rho\theta^2+o(1)}
+\cdots
=
n^{\rho+o(1)}.
\]
Hence
\[
\boxed{
S(n)\le n^{\rho+o(1)},
\qquad
\rho=\max\{\sigma,\theta\}.
}
\]

Therefore a sufficient conditional collision with the Williams tradeoff is
\[
\boxed{
\max\left\{r,\frac{\eta}{1-\theta}\right\}
+
\max\{\sigma,\theta\}
<
2\cos(\pi/7).
}
\]
No current source-certified parameters satisfy this inequality.

\section*{Composition with the existing reconstruction ledger}
Suppose a SAT input of length \(n\) is converted into at most
\[
n^{\eta_R+o(1)}
\]
reconstruction calls, each of instance length
\[
N=n^{\lambda+o(1)}.
\]
Suppose one direct reconstruction invocation has:
\[
\text{non-SAT work }N^{a+o(1)},
\qquad
\text{at most }N^{q+o(1)}\text{ SAT queries},
\]
with every SAT query of length at most
\[
N^{b+o(1)}.
\]
Let the outer return machinery itself cost \(n^{r_R+o(1)}\).

Then the composed SAT oracle self-reduction has
\[
\theta=\lambda b,
\]
\[
\eta=\eta_R+\lambda q,
\]
and local non-oracle exponent
\[
r_0=\max\{r_R,\eta_R+\lambda a\},
\]
provided the source-certified implementation makes no additional full-size invocation of \(A\).

If
\[
\boxed{\lambda b<1,}
\]
RECURCLOSE1 gives
\[
\boxed{
C_{\rm rec}
=
\max\left\{
r_R,\,
\eta_R+\lambda a,\,
\frac{\eta_R+\lambda q}{1-\lambda b}
\right\}.
}
\]
This removes the unknown SAT exponent \(K\) entirely.

This statement is \textbf{PROVED/EXACT conditional accounting}. The required source-matched composition remains OPEN.

\section*{Comparison with RETURNSQUEEZE1}
RETURNSQUEEZE1 requires a repeatable map on algorithm exponents. RECURCLOSE1 shows a potentially weaker sufficient object: one fixed \(A\)-derived SAT shrinker that can call itself recursively on smaller SAT instances.

Thus repeatability across an infinite sequence
\[
A\mapsto A'\mapsto A''\mapsto\cdots
\]
is not necessary if one can prove a single uniform fractional oracle self-reduction
\[
R_A^{\mathrm{SAT}}.
\]

The burden moves to a sharper condition:
\[
\boxed{
\text{derive }R_A^{\mathrm{SAT}}\text{ from }A
\text{ without invoking }A\text{ on full-size data.}
}
\]
If deriving the shrinker requires a current-scale call to \(A\), the unknown exponent \(K\) re-enters the local exponent \(r\) and the erasure fails.

\section*{PROVED/EXACT: semantic pruning gate}
The literature on sparse hard sets suggests a second formulation.

Consider the standard SAT self-reduction frontier. Suppose that for every residual formula \(F\) reachable from an \(n\)-bit input there is a polynomial-time computable signature
\[
\sigma(F)\in\Sigma_n
\]
with
\[
|\Sigma_n|\le n^{d}
\]
for some constant \(d\). Assume there is a polynomial-time collision selector such that whenever
\[
\sigma(F)=\sigma(G),
\]
it returns one of \(F,G\), denoted \(H\), satisfying
\[
\boxed{
\mathrm{SAT}(F)\vee\mathrm{SAT}(G)
\iff
\mathrm{SAT}(H).
}
\]
Then SAT is in P.

\textbf{Proof.}
At each variable-restriction level, expand every retained residual into its two children. Group children by signature. Repeatedly apply the selector within each group, retaining one residual per signature. The frontier width is at most \(n^d\) at every level. There are at most \(n\) restriction levels and only polynomial work per retained node, so the entire self-reduction tree is pruned to polynomial size. At the leaves, evaluate directly. \(\square\)

This is the abstract Mahaney-style pruning mechanism needed if product-span collisions are to contribute to a return bridge.

\section*{QUOTIENT1 / product-span consequence}
QUOTIENT1 gives algebraic equality classes of represented product-generator columns and exact rank invariance after loops and parallel columns are quotiented. EXCESS1, TURANEX1, and PAIRDEG1 add source-typed structural diagnostics.

None of these results currently proves the semantic selector condition above.

In particular,
\[
\text{equal quotient-normalized algebraic signature}
\]
does not imply
\[
\text{equal SAT truth value}
\]
and does not yet provide a polynomial-time selector preserving the OR of two residual SAT instances.

Therefore the exact structural handoff needed for Boundary-Squeeze is now:
\[
\boxed{
\text{quotient/product-span collision}
\Longrightarrow
\text{SAT-preserving collision selector}
}
\]
on one SAME\_REALIZATION source-transcribed family, with acquisition and evaluation fully charged.

This arrow is OPEN and is substantially stronger than a low-rank or small-signature theorem alone.

\section*{Literature transfer classification}
\textbf{KNOWN THEOREM.}
Williams 2024 proves self-improvement for Circuit-SAT and explicitly leaves extension to the \(P=NP\) regime open. Mahaney proves that a sparse many-one hard set for NP implies \(P=NP\). Ogiwara--Watanabe strengthen sparse-hard-set consequences for bounded truth-table reductions. Faliszewski--Ogihara analyze length-decreasing self-reducibility. Buss--Williams characterize the \(2\cos(\pi/7)\) small-space alternation-trading frontier. Drucker, Fortnow--Santhanam, and Dell--van Melkebeek give strong compression barriers under standard noncollapse assumptions.

\textbf{EXACT OBJECT/THEOREM TRANSFER.}
The recursion-tree accounting and semantic selector pruning theorem above are direct deterministic algorithmic arguments. They require no hardness assumption.

\textbf{ANALOGY/CANDIDATE.}
Mahaney-style sparse-image pruning is a candidate model for converting quotient-normalized product-span collisions into a fractional SAT shrinker. The missing semantic collision-selector theorem is new and source-specific.

\textbf{FAILED TRANSFER.}
Low algebraic rank, few quotient column classes, low-dimensional Schur square, or many algebraic collisions do not by themselves prune the SAT self-reduction tree. Compression lower bounds whose contradiction is only PH collapse cannot terminate a proof assuming \(P=NP\).

\section*{Hostile controls}
\textbf{Padding.}
The invariant parameter for the shrinker is the actual original-input query exponent \(\theta\), not an intermediate exponent \(b\) measured after padding. RETURNSQUEEZE1's full-input-carry guard remains in force.

\textbf{DEAD/COPY.}
QUOTIENT1 removes trivial product-coordinate multiplicity, but semantic self-reduction frontiers can still contain many formulas sharing one algebraic signature. That is harmless only if the collision selector is proved.

\textbf{INTERP/RECOMP.}
Alternative representations and recomputation can change the structural signature. A selector theorem must be representation invariant or explicitly tied to the declared source realization.

\textbf{Easy families.}
Horn, dual-Horn, 2-SAT, affine/Tseitin, bounded-treewidth formulas and independent products may all admit compact semantic selectors for reasons unrelated to general SAT hardness. Their existence is a control, not evidence for the general bridge.

\textbf{Semantic/algebraic oracles.}
RECURCLOSE1 and the pruning theorem relativize as abstract resource statements. They are not the nonrelativizing hinge. A semantic oracle could trivially implement the selector. The project still needs an unconditional source/solver obligation that cannot be replaced by such an oracle.
