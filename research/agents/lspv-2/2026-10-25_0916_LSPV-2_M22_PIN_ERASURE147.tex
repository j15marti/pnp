\section{Target, quantifiers, and proposed gap fills}
\(\CM\) contains duplicate-free ordinary OR-CNFs with clauses of three distinct original names, each wholly positive or wholly negative, and with each occurring variable appearing twice in each sign. The complement \(\bar C\) reverses the three signs, not the Boolean value of the disjunction. \(\mathcal P_{\rm pair}\) contains formulas for which every clause's partner is present. \(\Cs=\CM\setminus\mathcal P_{\rm pair}\) excludes \emph{only fully paired formulas}; partial pairs, disconnected and easy inputs remain allowed. \(L_\star=\{\operatorname{enc}(F):F\in\Cs,\ F\text{ satisfiable}\}\) rejects invalid strings. \section{Exact ordinary-restriction theorem}
For a partial assignment \(\rho:D\to\{0,1\}\), define \(F\!\restriction\rho\) by deleting every clause already satisfied by a pinned literal and removing falsified pinned literals from every remaining clause. Preserve the resulting empty clause if any; do not introduce fresh names, rebalance occurrence counts, learn additional clauses or solve a subproblem. The empty conjunction is the TRUE terminal, and is vacuously in \(\CM\) but fully paired, hence \emph{outside} \(\Cs\). The FALSE terminal contains an empty clause and is outside \(\CM\). Let \(F_1,\dots,F_c\) be the clause-containing components of the original bipartite variable--clause incidence graph, with \(k_i\) variables and \(m_i=4k_i/3\) clauses.

\begin{theorem}[M22-PIN-ERASURE147; restricted exact]
For every \(F\in\CM\) and every partial assignment \(\rho\), if \(G=F\!\restriction\rho\in\CM\), then \(G\) is an unchanged union of original incidence components \(F_i\). Each component meeting \(D\) disappears entirely and therefore has every one of its source clauses already satisfied by \(\rho\). Any such disappeared component contains at least
\[
\boxed{|D\cap\operatorname{vars}(F_i)|\ \ge\ \lceil m_i/2\rceil=2k_i/3}
\]
pinned original variables. Conversely, when each touched component has every source clause satisfied by \(\rho\), the residual is exactly the untouched component union, hence is in \(\CM\). The lower bound is sharp for a connected six-variable in-target component.
\end{theorem}
\begin{proof}
Suppose \(y\) occurs in \(G\in\CM\). Both of its signed residual degrees equal two and were two in \(F\); thus \emph{all four} original occurrences of \(y\) survive. Every original clause incident with \(y\) must survive \emph{unchanged}: a satisfied clause would erase an occurrence, while removal of a false pinned literal would leave a nonternary clause and contradict membership in \(\CM\). Hence no such clause can contain a pinned variable. Every variable connected to \(y\) by an original clause consequently survives, and the same argument propagates along all incidence paths. The entire original component containing \(y\) is therefore untouched and present. Any component containing a pin can contribute no surviving clause, so its clauses must all have been deleted as already TRUE. Each pinned original variable makes exactly two original clauses true by its chosen sign, because it has two positive and two negative occurrences; therefore at most \(2|D\cap\operatorname{vars}(F_i)|\) distinct source clauses can be deleted as TRUE. Deleting all \(m_i\) requires the stated threshold. Finally, if every touched component is clausewise satisfied, all its clauses disappear while no untouched component changes, proving the converse. Sharpness is witnessed below.
\end{proof}

\begin{corollary}[Connected-source recursive type firewall]
Let \(F\in\Cs\) have connected incidence graph. If \(0<|D|<2k/3\), then \(F\!\restriction\rho\notin\CM\), for every chosen pin values, regardless of SAT status. If \(F\) is UNSAT, then \(F\!\restriction\rho\notin\CM\) for \emph{every} nonempty pin assignment, including assignments of at least \(2k/3\) variables. Thus a connected UNSAT input cannot furnish an ordinary nontrivial \(\Cs\)-eligible restriction child without rewriting, auxiliary clauses, an adapter, or a different representation.
\end{corollary}
\begin{proof}
The connected theorem permits only the original untouched component or the empty conjunction. A nonempty pin touches that component, so the only possible \(\CM\) residual is TRUE. Under the threshold this is impossible. If \(F\) is UNSAT, TRUE under any consistent partial assignment would extend to a model of \(F\), also impossible.
\end{proof}

\noindent This applies only to the \emph{ordinary pin-and-simplify constructor}. It neither rules out generalized CNF solvers on malformed descendants nor prohibits a paid, correctly typed equivalent construction. It is a syntactic receiving-obligation failure, not a deterministic machine lower bound. The component-union argument was already present in Role~4's M22-COMPONENT-CLOSURE97 for pure clause subsets; the new explicit pin corollary and sharp coverage threshold are the added specialization, not a claim to rediscover that theorem.
