\section{Target obstruction and exact theorem}
A coherent partial assignment $p$ fixes \emph{original} variable names, not occurrence bits. Delete source clauses satisfied by $p$ and delete falsified literals in surviving original clauses, retaining immutable clause IDs. Consider ten distinct residual binary clauses supported by five free variables $B=\{v_1,\ldots,v_5\}$, with exactly one clause for each of the ten unordered pairs of $B$. Each binary clause is an original clause of width three before the pin, with its third literal pinned false. All five variables are still free.

\begin{theorem}[Canonical signed-$K_5$ residual obstruction]\label{thm:k5}
For \emph{every} valid duplicate-free proper monotone 3-SAT-$(2,2)$ source $F$ and \emph{every} coherent original-variable partial assignment $p$, if the uncovered residual contains the ten source-clause-indexed binary edges of a simple $K_5$, then $F\upharpoonright_p$ is UNSAT. The conclusion does not require the signed-excess parameter $\delta$ to be zero, a MaxCut oracle, or a separate complete-assignment search. Moreover the ten source clauses alone yield two directed implication paths $v\leadsto\neg v$ and $\neg v\leadsto v$ in their 2-SAT implication graph, constituting a source-ID-checkable UNSAT certificate.
\end{theorem}
\begin{proof}
Every free variable occurs exactly twice positively and twice negatively across the \emph{entire original source}. Each of the five chosen variables occurs in four different selected binary clauses, one for each other vertex. Thus these ten original clauses exhaust all four source occurrences for each chosen variable. Every selected binary clause is same-sign because of canonical monotonicity. In the positive-edge subgraph $G_+$, each of the five vertices has degree two; the same holds for the negative-edge subgraph $G_-$. The edges are simple because the selected $K_5$ has exactly one edge for each pair. A simple two-regular graph on five vertices must be one $5$-cycle. Thus $G_+\cong G_-\cong C_5$, and their five-edge sets partition $E(K_5)$.

Let $T$ be the true vertices and $Z=B\setminus T$ the false vertices of any purported satisfying completion. Every positive binary edge must have a true endpoint, hence $Z$ is an independent set of $G_+\cong C_5$ and $|Z|\le\alpha(C_5)=2$. Every negative binary edge must have a false endpoint, hence $T$ is independent in $G_-\cong C_5$ and $|T|\le2$. The partition $B=T\mathbin{\dot\cup} Z$ would give $5=|T|+|Z|\le4$, a contradiction. Every 2-CNF UNSAT instance has a variable whose positive and negative literal nodes occupy the same strongly connected component of its implication graph, yielding the two stated source-ID paths \cite{aspvall1979}. Here every arc is copied from one of the ten authenticated original clauses, so these paths can be checked independently.\end{proof}

\end{corollary}
