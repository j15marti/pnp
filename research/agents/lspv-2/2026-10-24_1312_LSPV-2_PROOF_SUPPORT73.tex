\section{Backward semantics and exact source accounting}
For $F=\bigwedge_{j=1}^m(\ell_{j1}\vee\ell_{j2}\vee\ell_{j3})$, backward output TRUE from the AND of clause-OR gates permits a choice of one true literal \emph{occurrence} per clause, with no selected complementary occurrences of an original source variable, iff $F$ is SAT. This never forces exactly one original literal true per clause. Proper signed exact-$(2,2)$ gives $4n=3m$ occurrence vertices, exactly $n$ disjoint $K_{2,2}$ complementary-conflict components and $4n$ conflict edges; clause triangles give a special degree-four graph. An evaluation circuit with shared source NOT gates has $n+3m-1$ gates and $n+6m-2$ directed inputs, not a lower bound on a general SAT-decision circuit.
For a source-verified $H=G(Y)\wedge\bigwedge_j H_j(Y_j,U_j)\subseteq F$ with pairwise disjoint private sources, all learned no-goods must use the same source identifiers, including all shared boundary names. Let a source-labelled DPLL tree refute $H_j$ under a partial boundary assignment $\alpha$.
\begin{theorem}[Source-supported refutation projection; PROVED/EXACT restricted]
Annotate initial assumptions $v=b$ with unique tokens $A_v$, and each binary DPLL split with a fresh token $B_t$. Every unit propagation records the union of supports of the currently falsified literals of its source reason clause; a conflict leaf records supports falsifying its named source clause. At each split, union the two child supports and erase the token for that very split. The root support contains only a subset $S$ of original assumption tokens. Writing $\beta=\alpha|_S$, the source entails
\[
H_j\wedge\beta\in UNSAT,\qquad
H_j\models D_\beta=\bigvee_{(v=b)\in\beta}(v\ne b).
\]
The operation and its independent source proof replay are polynomial in the \emph{explicit proof length} plus source and assumption lengths, but proof acquisition can be exponential in $N$.
\end{theorem}
\begin{proof}
At every unit, its cited original clause makes the derived literal necessary under the recorded falsifying conditions. At a checked leaf those conditions falsify an original clause. The two children of a split refute both source values under the union of the remaining conditions, so the split token can be discharged. Induction over the proof tree leaves only initial assumption dependencies; thus $\beta$ refutes the block. Independently replaying the complete source-labelled tree under $\beta$ is an additional fail-closed acceptance check. No minimality of the extracted core is asserted.
\end{proof}
The implementation charges every source scan, reason-support union, rule choice, failed approach, caching and final replay. Peak live memory includes the full certificate, assignment/support records, recursion stack, learned constraints and original source; only a polynomial bound in \emph{explicit proof size} is asserted. Bit-mask operations can require multiple addressed machine words. The input uses $w=\lceil\log_2(64(n+m+1))\rceil$-bit words and $N=(4m+2)w$ bits for this declared encoding.
\section{Connected growing SAT/UNSAT test}
For $r=6$ source inputs $z_1,\ldots,z_r$, two separate XOR-gate chains are constrained to compute inconsistent parities. An XOR gate is represented by four proper ternaries, and every gate clause $c_1\vee c_2\vee c_3$ is guarded by $x$ using
\[
(x\vee c_1\vee g)\land(\neg g\vee c_2\vee c_3),
\]
which projects exactly to $x\vee c_1\vee c_2\vee c_3$. The output constraints are similarly guarded using proper ternary pairs. Append $k$ boundary dummies $(y_i\vee z_1\vee q_i),(\neg y_i\vee z_1\vee q_i)$ \emph{before} the gate clauses. They keep the entire source connected but are irrelevant to its parity conflict. Four global ternaries force either $x=0$ (UNSAT) or $x=1$ (SAT). Both labels have exactly $n=61+2k,m=88+2k$ proper unique ternaries and interface size $k+3$. This is \emph{not} the strict exact-$(2,2)$ class.
Under $x=0$, the specified local DPLL generates 127 nodes. Proof-support extraction and one independent replay learn the unit $(x)$ after one local call; the older greedy procedure learns the same unit using $k$ successful replays plus one rejected attempt. These data \emph{include} rejected proof-checker work and exclude common local solve/parsing charges:

\section{Strict signed exact-$(2,2)$ negative control and adaptive-state ledger}
The canonical 198-variable/264-clause connected original UNSAT source and its two-sign SAT neighbor were checked against the expected signed quotas and source hash. The adaptive policy skips proof minimization when the observed boundary support is at most three and proof size exceeds 16; it uses 18 local calls and 725 local nodes, \emph{worse} than LAZY-BOUNDARY71's 16 calls and 688 local nodes.
