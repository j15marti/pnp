\section{Question, prior actual evidence, and falsifiable mechanisms}
The previous CONNECTED-LOG-FLIPS247, DERIVATIVE-WITNESS248, and BALANCED-TWO-COORD249 reports constructed exact fixed-radius flip histograms using bounded-degree connected supports and a two-dimensional Laurent specialization for sign-balanced original clauses. Their existing theorem compiles one base-assignment histogram in $f(r,d)(n+m)$ operations. The missing lemma here is whether moving to a neighboring coherent base assignment must pay that complete construction again, or whether all affected connected supports can be identified \emph{locally} and revised in $f(r,d)$ time independent of $n$. This is relevant to adaptive flip trails, although it does not imply that local exploration finds SAT.

Three falsifiable mechanisms were tested. First, changing one genuine variable $x$ modifies local flip differences only for candidate flip supports intersecting the closed co-occurrence neighborhood $N_G[x]$. Second, every connected logarithmic coefficient whose support avoids that neighborhood stays exactly unchanged, even when the base clause-count vector changes. Third, a reverse incidence index from source variables to cached connected supports makes the changed coefficients findable without scanning all $\Theta(n)$ cached supports. The hostile control tests whether the complete decision controller actually saves total work once preprocessing and failed SAT/UNSAT paths are charged. The first three mechanisms are \textbf{PROVED/EXACT} under the stated model; the general SAT-speedup inference is \textbf{FALSIFIED/RETIRED} by the tested controls.

\section{Mandatory original-clause experiment before dynamic algorithms}
Let $F=\bigwedge_{j=1}^m C_j$ be a proper original width-three signed CNF, each clause using distinct original variables. Each signed occurrence $x_{i,j}$ identifies the occurrence of original variable $x_i$ in \emph{original} clause $C_j$; it is never an independent variable. The local target $S_j$ fixes each occurrence's original variable so that its literal is TRUE, while $U_j$ fixes all three original literals FALSE. Thus for a positive occurrence $S_j(x_i)=1$, $U_j(x_i)=0$, and vice versa for a negative occurrence. The independent inversions $\overline{S_j}=U_j$, $\overline{U_j}=S_j$ are recorded for each occurrence, even when demands of different clauses conflict.

For distinct original clauses $(C_j,C_k)$ the exact extreme compatibility matrix has $SS=UU=1$ iff the pair has no opposite-sign shared original variable; $SU=US=1$ iff it has no same-sign shared original variable. Both types of sharing make all four extreme modes impossible, but both ordinary disjunctions may still be satisfied. The full original-index pair matrix and selected triple-mode constraints were checked by enumerating coherent assignments to their combined variable supports. This $O(m^2)$ matrix audit is \emph{separate} from the dynamic compiler and not free input to the measured SAT solver.

For example, source W1 has
\[
 C_1=(\neg x_1\lor x_3\lor\neg x_{14}),\quad C_2=(x_2\lor\neg x_8\lor x_9),\quad C_{20}=(\neg x_1\lor x_{13}\lor x_{14}).
\]
Here $S_1$ requires $(x_1,x_3,x_{14})=(0,1,0)$, $U_1$ requires $(1,0,1)$, $S_2$ requires $(x_2,x_8,x_9)=(1,0,1)$, and $U_2$ requires $(0,1,0)$; both inverted targets are explicitly recorded in the raw output. $C_1,C_{20}$ share $x_1$ with equal sign and $x_{14}$ with opposite sign, hence $SS=SU=US=UU=0$, so some clause must remain a middle-state clause on every coherent complete assignment. This local invariant is not an UNSAT certificate.

For any coherent $a\in\{0,1\}^n$, write $t_j(a)\in\{0,1,2,3\}$ for the count of TRUE original literals and $\vN(a)=(N_0,N_1,N_2,N_3)$. The code records genuine $0^n$, $1^n$, the complementary assignment to every recorded flip state, and single/multiple flips including a reversal of $x_1$. The source W1 endpoint vectors are

 \vN(0^{15})=(1,10,7,2),\qquad \vN(1^{15})=(2,7,10,1).

The trace flipping $x_1,x_2,x_3$, then reverting $x_1$, gives $(1,10,7,2),(1,10,7,2),(2,8,8,2),(2,9,6,3)$. For each assignment the raw record lists \emph{every} original $t_j$, not merely the aggregate. The complement identity $t_j(\bar a)=3-t_j(a)$ and $N_r(\bar a)=N_{3-r}(a)$ was rechecked independently. Ordinary source SAT means $N_0=0$, not $N_3=m$.

\section{The dynamic fixed-radius theorem}
Let $G$ be the original variable co-occurrence graph, with an edge between two distinct original variables if they share a source clause. When every original variable occurs in at most $d$ original width-three clauses, its maximum degree is $\Delta\le2d$. For coherent base $a$ and flip set $S$, define
\[
 \bdelta_a(S)=\vN(a\oplus S)-\vN(a),\quad
 Z_a(\mathbf u,\mathbf z)=\sum_{S\subseteq[n]}\Bigl(\prod_{i\in S}u_i\Bigr)\mathbf z^{\bdelta_a(S)}.
\]
Only degrees up to a user-specified fixed $r$ are retained in the formal $\mathbf u$ variables. As in CONNECTED-LOG-FLIPS247, if $\operatorname{supp}\alpha$ is disconnected in $G$ then $[\mathbf u^\alpha]\log Z_a=0$ because independent source-clause changes factor multiplicatively. Let $T$ be a nonempty connected original-variable subset with $|T|\le r$; let $Z_{a,U}$ be $Z_a$ restricted to $u_i=0$ outside $U$. Define the exact locally cached Laurent polynomial
\[
 W_a(T)=[\deg_t\le r]\sum_{U\subseteq T}(-1)^{|T|-|U|}\log Z_{a,U}(t,\mathbf z),
\]
where variables in $U$ are specialized to the same flip marker $t$. The sum isolates exactly those logarithmic monomials with distinct-variable support $T$, including repeated formal powers. Write
\[
 L_a(t,\mathbf z)=\sum_{T\subseteq[n],\,G[T]\text{ connected},\,1\le|T|\le r}W_a(T),\quad
 E_a(t,\mathbf z)=\exp L_a(t,\mathbf z)\pmod{t^{r+1}}.
\]
Then $[t^k]E_a=\sum_{|S|=k}\mathbf z^{\bdelta_a(S)}$ for every $k\le r$; shifting by $\vN(a)$ gives the exact four-category histogram.

\begin{theorem}[Exact local update of fixed-radius histograms]\label{thm:dynamic}
For every fixed nonnegative integer radius $r$ and fixed occurrence bound $d$, every proper original width-three CNF $F$ on $n$ variables and $m$ clauses with original occurrence degree at most $d$, and every sequence of coherent complete assignments in which each next assignment flips exactly one original variable, there exists a uniform deterministic source-preserving indexed word-RAM algorithm that initializes in $O(f(r,d)(n+m))$ arithmetic operations and words, then updates \emph{each full radius-0 through radius-$r$ aggregate histogram} in $O(f(r,d))$ indexed-word arithmetic operations and $O(f(r,d))$ temporary words per source-variable flip, without scanning all $n$ cached connected supports. The persistent storage is $O(f(r,d)(n+m))$ working words. Every coefficient has polynomially bounded bit length for fixed $r,d$; a bit-complexity implementation also charges this length. This includes original connected strict signed exact-$(2+,2-)$-3CNF with $d=4$.
\end{theorem}
\begin{proof}
Scan the original clauses once and build signed incidence lists, source-clause truth counts and all connected variable subsets $T$ of size $\le r$, together with $W_a(T)$. Enumerating such supports and their local clause contributions uses $O(f(r,d)(n+m))$ work because $\Delta\le2d$ and each connected support lies within a bounded-radius neighborhood of one original variable. For each original variable $v$, build a \emph{reverse support index} $I(v)=\{T:v\in T,\ G[T]\text{ connected},\ |T|\le r\}$. Each $I(v)$ has size bounded solely by $r,d$.

Suppose the base flips the original variable $x$. Only original clauses containing $x$ change truth counts. Let $H=N_G[x]=\{x\}\cup N_G(x)$. For every $S\subseteq[n]$ disjoint from $H$, no clause incident with $x$ contains a flipped variable of $S$; hence those clauses contribute exactly zero to both $\bdelta_a(S)$ and $\bdelta_{a\oplus\{x\}}(S)$. Every other original clause retains the same base values. Thus
\[
 S\cap H=\varnothing\quad\Longrightarrow\quad \bdelta_a(S)=\bdelta_{a\oplus\{x\}}(S).
\]
In particular, $W_a(T)$ can change only when $T\cap H\ne\varnothing$. All such connected supports appear in the \emph{union of reverse indices} $\bigcup_{v\in H}I(v)$, of size at most $f(r,d)$; it is unnecessary and incorrect for a claimed constant-update implementation to scan all cached supports. Recompute exactly these $W(T)$ by the displayed finite local logarithm and Moebius formula, subtract their old contributions from the cached coefficients $L_k=[t^k]L$, and add their new contributions. The original source-clause truth counts and base $\vN$ are updated from at most $d$ signed occurrences. Reconstruct $E_0=1$ and
\[
 kE_k=\sum_{j=1}^k jL_jE_{k-j}\qquad(1\le k\le r)
\]
using exact Laurent arithmetic. For fixed $r,d$, a radius-$r$ flip changes at most $rd$ original clauses, so its count-shift lies in a bounded box (two dimensions for sign-balanced ternary sources, and at most three effective dimensions otherwise). Hence the total number of stored coefficients and recovery operations for each $k\le r$ depends only on $r,d$. This proves the update bound. The coefficients count at most $\binom nr$ states, so require $O(r\log n)$ bits (and denominators of local logarithms depend only on $r$). Initialization and permanent source/cached-index storage obey the stated bounds. No SAT answer bit or external satisfying witness was supplied.\end{proof}

\paragraph{Resource-model and output firewall.} The bound is for an indexed word RAM with $\Theta(\log(n+m))$-bit words and fixed $r,d$. The original signed formula stays retained and source access is charged. The data structure emits \emph{aggregate counts} in a bounded number of histogram cells; explicitly printing all $m$ clause truth-count fields after every update costs $\Omega(m)$ outputs per step. The experiment nevertheless provides the full per-clause arrays as a separate, charged scientific audit. Physical tape head crossings, sequential input simulation, and large-$r$ extensions are not covered by the constant update bound. The bit model charges multiplication and coefficient bit complexity; it is not asserted to be $O(1)$ bits per update. Worst-case SAT decision, UNSAT certification, and model reconstruction remain separate obligations.

\section{Falsified overreach, applicability, and next lemma}
\textbf{FALSIFIED/RETIRED}: ``Maintaining the exact low-radius spectrum in constant update time makes unrestricted SAT easy.'' Fixed-radius coverage is a negligible fraction of the complete assignment space at large $n$. A spectrum reports aggregate candidate counts and is not itself an UNSAT certificate; no polynomial source-independent upper bound on useful $r$ is known. The hostile UNSAT controls require the full DPLL fallback, while two-SAT, Horn and affine controls are often already easy by established methods. Nor may the signed extreme matrix be treated as a global oracle: local $S_j,U_j$ targets may conflict despite both disjunctions being satisfied. There is no transfer from a bounded-degree connected-cluster representation to all-algorithm SAT lower bounds.

\textbf{OPEN next lemma}: Can a fixed-radius connected-support cache be augmented with \emph{source-weighted reverse-adjoint gradients} and a provably local \emph{per-selected-flip} update, such that a SAT witness within the radius is reconstructed in $f(r,d)$ additional work after each update rather than a separate $\Theta(n^r)$ reconstruction scan or global differentiation pass? Every changed output gradient must be correctly updated or lazily invalidated, with exact source proofs and fully charged total SAT decision costs. This is distinct from the prior fixed-base derivative theorem DERIVATIVE-WITNESS248.
