\section{Original-source resolution and exact reconstruction}
\begin{theorem}[The certified $(2,2)$ resolution rectangle, classical]
For every valid canonical source $F$ and original variable $x$, identify its original positive source clauses $C_{p_i}=(x\vee A_i)$, $i=0,1$, and negative clauses $C_{n_j}=(\neg x\vee B_j)$, $j=0,1$. Each $A_i,B_j$ is a positive/negative two-literal disjunction, respectively. Let $R_x$ be the unaffected original clauses. For every coherent assignment $a$ to the other original variables,
\[
 (\exists b\in\{0,1\})F(a,x=b)
 \iff R_x(a)\land\bigwedge_{i,j\in\{0,1\}}(A_i(a)\vee B_j(a)).\tag{1}
\]
A cross resolvent is tautological precisely when its two feet contain at least one original variable in opposite signs. Every other cross resolvent contains exactly four distinct literals. If there are $t_x$ tautological cross pairs, the raw exact projection has $m-t_x$ clauses, of which $4-t_x$ are width four. A non-tautological resolvent records the source IDs $(p_i,n_j)$ and a four-bit partial cube that is impossible under $F$. Satisfying assignments of the projected formula lift without searching leaves: set $x=0$ when both $A_i$ are true, and set $x=1$ otherwise.
\end{theorem}
\noindent\textit{Proof.} The two choices $x=0$ and $x=1$ reduce the four pivot clauses to $(A_0\land A_1)$ and $(B_0\land B_1)$, respectively. Distributivity gives \((A_0\land A_1)\lor(B_0\land B_1)=\bigwedge_{i,j}(A_i\lor B_j)\). The proposed choice of $x$ meets all original clauses: if either positive foot fails, every cross resolvent with that foot forces both negative feet true, so $x=1$ works; otherwise $x=0$ works. Cross feet have opposite signs and each source clause is proper, hence their overlap is exactly a tautological complementary pair; without overlap the four literals are distinct. Falsification of a source-indexed non-tautological resolvent is therefore a genuine prohibited cube.\hfill$\square$

\noindent\textbf{Important scope distinction.} Equation (1) proves both SAT and UNSAT preservation \emph{in ordinary CNF}; it does not make the output a valid instance of the chosen NP-complete grammar. To use it inside a hereditary target-language recursion, a separate signed-quota-correct, duplicate-free, semantically equivalent re-encoder is mandatory. Prior REF258 constructs one with $+201$ variables and $+268$ clauses. Unchanged-component deletion is target-valid but restricted to source components.

\section{An exact physical-bit-length firewall}
Encode the $n$ original variable IDs with $w=\lfloor\log_2n\rfloor+1$ bits; prefix positive integers by unbounded Elias-gamma code $\gamma$. The compact canonical source stores one sign per three-literal monotone clause:
\[
 N=|\gamma(n)|+|\gamma(m)|+m(1+3w),\qquad m=4n/3.\tag{2}
\]
A specifically declared \emph{ordinary} 3/4-CNF child encoding stores a 1-bit width tag per clause plus one sign and $w$ index bits per literal. With $c_3=1+3(w+1)$ and $c_4=1+4(w+1)$, this child has
\[
 M=|\gamma(n)|+|\gamma(m-t)|+(m-4)c_3+(4-t)c_4,
 \qquad 0\le t\le4.\tag{3}
\]
\begin{theorem}[Representation-matched length lower bound]
For every valid canonical source with $n\ge21$, all four cross-resolution choices obey
\[
 \boxed{M-N=3m+4(w+1)-t(4w+5)+\Delta_\gamma
 \ \ge\ 4n-12w-18>0,}\tag{4}
\]
where $\Delta_\gamma=|\gamma(m-t)|-|\gamma(m)|\ge-2$. Thus this exact \emph{one-pivot, noncanonical tagged-3/4-CNF} emission is physically longer than the compact canonical source for all sufficiently large target inputs, irrespective of the number of tautological pairs. It supplies neither a canonical hereditary child nor $M\le N^{1/2+o(1)}$.
\end{theorem}
\noindent\textit{Proof.} Subtract (2) from (3), use $m=4n/3$, and minimize the result at $t=4$. For $m\ge8$, removing at most four clauses crosses at most one binary-length boundary of the gamma header, so $\Delta_\gamma\ge-2$. For $n\ge21$, $4n-12(\lfloor\log_2n\rfloor+1)-18$ is strictly positive, including at every power-of-two word-width jump; between jumps it increases by four per variable. The bound concerns \emph{this declared encoding} only, not optimal semantic compression or another target compiler.\hfill$\square$

\section{Exact arbitrary-index accessor and charged acquisition}
Given a validated original source, the four indexed source pivot-clause IDs and their literal field positions, sorted deleted IDs $r_0<r_1<r_2<r_3$, and the at most four certified four-literal resolvents, the source clause index corresponding to the $j$th unaffected child clause is computed without storing a length-$m$ survivor list: initialize $s=j$ and, scanning deleted IDs in order, increment $s$ exactly when $s\ge r_i$. The header, width tag and literal fields then determine each child bit through fixed arithmetic and \emph{at most one indexed read of a bit of the compact original source}. Newly derived width-four source fields point to one of the two indexed parent clauses. With the descriptor supplied, one query uses $O(\log N)$ scratch and $\log^{O(1)}N$ arithmetic, assuming the specified read-only indexed-input model; the finite Python reference also materializes a complete input and therefore does not itself meet this physical workspace claim.

\noindent\textbf{Full acquisition is not free.} To choose a pivot uniformly, a controller may scan all $m$ clauses and $3m$ literal fields, build a four-clause descriptor, test all four cross pairs, and pay for every rejected pivot or switching/restart. A conservative repeated-scan implementation spends $O(N^2\operatorname{polylog}N)$ bit work with logarithmic writable workspace for global grammar validation and discovery; compact Python producer arrays are only an experimental reference. This conservative upper bound is \emph{above} the proposed ARC local-time exponent $11/10$. Per-child-bit access alone does not solve source discovery, guest random access, guest-A tape simulation, kept ancestors, re-encoding, or the simultaneous peak space bound.
