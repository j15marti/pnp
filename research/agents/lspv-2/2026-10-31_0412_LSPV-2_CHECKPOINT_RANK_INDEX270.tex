\section{Same-source, both-label ordinary child}
For a computed-and-checked component partition
\[
 F(B,P)=H(B)\land\bigwedge_i F_i(B_i,P_i),
 \qquad P_i\cap P_j=\varnothing\ (i\ne j),\ B_i\subseteq B,
\]
write $b=|B|$, $M=2^b$ and let $p(a)$ be the exact predicate
$\exists P\,F(a,P)$. Number child variables $1,\ldots,b$. Define
\[
 D_a=\bigvee_{i=1}^b
 \begin{cases} y_i,&a_i=0,\\ \neg y_i,&a_i=1,\end{cases}
 \qquad G=\bigwedge_{a:p(a)=0}D_a.
\]
\begin{theorem}[KNOWN existential projection, source proof transport]
For every coherent $a$, $G(a)\Leftrightarrow\exists P\,F(a,P)$.
Consequently $\operatorname{SAT}(F)\Leftrightarrow\operatorname{SAT}(G)$.
Accepted masks lift via private-component witnesses checked on all
original clauses. Every rejected mask is accompanied by an indexed
source DPLL proof, from which source resolution derives a boundary clause
false at that mask. The full-width emitted blocker is a sound weakening.
\end{theorem}
\begin{proof} A full-width $D_a$ is false exactly at $a$.
The factors have disjoint private variables, hence component witnesses
combine. A complete DPLL contradiction tree under $a$ discharges its
private branch literals using source-indexed resolution, returning an
entailed boundary clause. The emitted $D_a$ is its logical weakening.
\end{proof}

\section{Exact checkpointed indexed character accessor}
Serialize $G$ as ordinary ASCII DIMACS, header followed by the rejected
mask clauses in increasing mask order; let $w(a)$ be the exact number of
bytes of mask $a$'s clause line. Partition masks into consecutive blocks
$I_t$ of size at most $h$, $1\le h\le M$. Precompute
\[
 L_0=0,\qquad
 L_{t+1}=L_t+\sum_{a\in I_t}(1-p(a))w(a),\quad
 q=\sum_a(1-p(a)).
\]
Store these cumulative byte offsets and the exact
\texttt{p cnf b q} header, \emph{not the child text}. To read offset $i$,
first address header bytes; otherwise subtract header length, binary
search the rightmost $t$ with $L_t\le i'$ (correctly skipping zero-length
blocks), and scan only its $h$ masks to locate the precise signed
decimal character. Return a blank out of range.

\begin{lemma}[PROVED/EXACT, restricted]
Every indexed read returns exactly the physically serialized ordinary
child character. For a worst-case fully charged source-profile decision
of time $W$ and space $S_p$, preprocessing is
$O(M(W+b\log(b+2)))$, and an indexed query costs
$O(h(W+b\log(b+2))+\log(M/h+2)\log(Mb+2))$ in the declared
indexed-profile model. The persistent offsets occupy
$O((M/h+1)\log(|G|+2))$ bits. The simultaneous writable workspace must
ALSO charge source/decomposition descriptors, proof cache, $S_p$,
the guest and retained ancestors. A guest making $Q$ indexed reads
pays $Q$ query costs, without a free oracle.
\end{lemma}
\begin{proof} Cumulative offsets delimit the exact byte intervals of
consecutive output blocks. Rightmost-prefix search selects the
unique nonempty containing block. The block scan evaluates at most $h$
source profiles and subtracts exact line lengths. Every offset is in
$[0,|G|]$, so the declared bit and arithmetic bounds follow. No
polynomial bound on $W$, boundary size or descriptors is asserted.
\end{proof}

\begin{lemma}[PROVED/EXACT, black-box falsifier]
If $p:[M]\to\{0,1\}$ is supplied \emph{only} as a Boolean profile
oracle and the exact header must give $q=\sum_a(1-p(a))$,
every deterministic algorithm makes $M$ queries in the worst case,
even under the promise $q\in\{0,1\}$.
\end{lemma}
\begin{proof} On the all-one oracle, any unqueried position can be
changed to zero without changing the transcript, but the required
header changes from zero clauses to one clause. Thus all $M$
positions must be queried. This is NOT a SAT lower bound: a
source-aware compiler can exploit hidden structure, and a SAT
decider may avoid this canonical exact projection altogether.
\end{proof}

from 220 to 555 and 225 to 1099 DIMACS bytes. The prototype

fallback. Thus the index reduces repeated guest-access work
