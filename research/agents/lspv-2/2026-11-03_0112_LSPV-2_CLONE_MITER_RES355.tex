\section*{Fixed system and source grammar}
The preselected unchanged $R_{\mathrm{mix341}}$ contains zero-cost authenticated original CNF clauses and unit-cost binary Resolution, as well as AND3, GF$(2)$, charged conversions and conservative auxiliary definitions. We use \emph{only} source-authenticated strict Resolution, never any new rule or semantic shortcut. Distinct inference DAG nodes count once, even when reused. An optimal proof selector is granted for free.

Fix an ordered acyclic circuit $C$ with $v\ge2$ common inputs and $g\ge1$ signed gates, each AND or XOR, with two distinct absolute input-wire IDs, arbitrary signed pin polarities, arbitrary fanout/reconvergence, and a fresh output wire at every gate. Build two exact structural copies $A,B$: they share only their original input variables and use fresh disjoint wire IDs for all gate outputs. Encode each signed AND gate $q=a\wedge b$ by
\[
(\neg q\vee a),\quad(\neg q\vee b),\quad(q\vee\neg a\vee\neg b),
\]
and each signed XOR gate $q=a\oplus b$ by the four clauses forbidding the four incorrect input/output triples. Add source clauses $(o_A)$ and $(\neg o_B)$ on the two cloned final output wires. The result is $M(C)$. This is canonical general CNF, not a proof-time DEF operation. There are $2g+v$ source variables, at most $8g+2$ source clauses of width at most three, and $N=O((g+v)\log(g+v+2))$ binary-encoded bits in canonical decimal DIMACS. A malformed source is not a valid CNF.

\begin{theorem}[Explicit uniform linear upper bound]
For every $C$ as above, a uniform deterministic construction produces a refutation DAG using only legal strict binary Resolution nodes and obeying
\[
\boxed{\operatorname{cost}_{\mathrm{RES}}(\pi_C)\le14g+2,\qquad W_{R_{\mathrm{mix341}}}(M(C))\le14g+2.}
\]
For the degenerate zero-gate circuit whose output is the same original input wire on both sides, the two opposite unit sources refute in one node. Every emitted proof line has width at most four. Fully encoded evidence length and proof-checking work for the constructed proof are polynomial, with constant-width clauses and two indexed parents per step. This is an upper bound, not a shortest-proof lower bound.
\end{theorem}

\section*{Proof via eight independently checked gate macros}
For corresponding gates $y=f(a,b)$ and $z=f(c,d)$, a pair of inputs may be literally shared only when it is an original input. Otherwise suppose the two corresponding literals are already known equal by both previously proved clause directions. There are exactly four shared-input patterns for each of $f=\mathrm{AND}$ and $f=\mathrm{XOR}$. Eight explicit finite strict-Resolution DAGs derive both output equality clauses $(\neg y\vee z)$ and $(y\vee\neg z)$ from the source gate clauses and the already proved input equality clauses. The numbers of \emph{new genuine Resolution nodes} in these retained macro DAGs are
\[
\begin{array}{c|rrrr}
\mathrm{operator}\backslash(\mathrm{shared}_1,\mathrm{shared}_2)&00&01&10&11\\\hline
\mathrm{AND}&8&6&6&4\\
\mathrm{XOR}&14&10&10&6
\end{array}
\]
These are verified upper-certificate counts, not optimal macro costs. The Python producer explored only the fixed six-variable local clause bank, retained the exact target dependency ancestry, and independently written JavaScript checked all eight explicit source clauses, every pivot, and both conclusions. The same local proof works with signed pins because literal complementation is a Resolution-proof automorphism. No unchecked solver answer is treated as a proof line.

Prove by induction along $C$'s gate ordering. Shared original inputs need no equality clause. If an input derives from an earlier paired gate, its two directions of equality were already derived and named. Instantiate the corresponding one of eight local macros to prove two equalities for the next gate, using at most 14 new derived nodes. Retain the first proof line once for all later fanout. At the final outputs, resolve $(o_A)$ with $(\neg o_A\vee o_B)$ to get $(o_B)$, then resolve it with source $(\neg o_B)$ to obtain $\bot$. Hence $14g+2$. Every step is a concrete legal Resolution inference; the induction never assumes an equivalence oracle. \hfill$\square$
