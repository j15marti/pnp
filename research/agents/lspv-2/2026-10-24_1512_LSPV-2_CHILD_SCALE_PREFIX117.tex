\section{A missing denominator in width inheritance}
\begin{theorem}[PROVED/EXACT numerical/syntactic nonimplication]
Fix $0<\lambda<1$. The bounds $w(N)=o(\log N)$, $L\le N^{\lambda+o(1)}$ and $w_{\rm child}\le w(N)+O(1)$ do NOT entail $w_{\rm child}=o(\log L)$. In particular, a parent satisfying the ratio cap $w\le\alpha\log_2N$ does not imply an unchanged-width child of size $N^{1/2}$ satisfies the same cap.
\end{theorem}
\begin{proof}
Take $N_h=\Theta(2^{h^2})$ and width $w=h$. A self-delimited valid child stream opens $h$ variables, lists $h$ distinct cyclic proper ternary clauses over them and closes them, so $L_h=O(h\log h)$ with $w_{\rm child}=h$. Pad the parent by independent width-three event blocks. Then $w/\log N_h\to0$ but $w_{\rm child}/\log L_h\to\infty$. To falsify the fixed ratio $\alpha=1/20$, choose $N=2^{20h}$, parent width $h$, child size $L=2^{10h}$ and unchanged width $h$. The parent cap is $h$, the child cap $h/2$. Analogous rescaling works for any constant $\alpha>0$. None of these examples claims to be the output of the unrecovered specific compiler; they disprove the stated inheritance from an upper size bound alone.
\end{proof}
\begin{lemma}[Conditional fixed-depth repair, PROVED/EXACT]
If, for each actual descendant at a fixed level $j\le r$, $\log L_j\ge(\lambda^j-o(1))\log N$ and $w_j\le w_0+O(j)$ with $w_0=o(\log N)$, then $w_j=o(\log L_j)$ for fixed $r$. Alternatively the compiled child promise may be explicitly validated at each call.
\end{lemma}
\begin{proof} Since $r$ is fixed, every $\lambda^j$ is a positive constant, and $(w_0+O(j))/\log L_j=o(1)$. \end{proof}

\section{A constructive adaptive singleton boundary join}
Let $A(Y,U)$ and $B(Y,V)$ be ordinary CNFs with disjoint private sets $U,V$ and shared $w$-bit boundary $Y$. Write $P_A(y)=[\exists U\,A(y,U)]$, $P_B(y)=[\exists V\,B(y,V)]$.
\begin{theorem}[PROVED/EXACT restricted-source join]
There is one deterministic total adaptive policy using a fixed ordinary exact SAT solver that, using at most $2w+6$ ordinary SAT calls, checks whether both nonempty projected supports are singletons and, if so, decides $A\wedge B$ by comparing their unique source-coherent $Y$ strings. If a support is non-singleton, a correct general exact fallback is invoked. No advance SAT/UNSAT labels, full solution relation, or $2^w$ row enumeration are required.
\end{theorem}
\begin{proof}
Query SAT(A) and SAT(B). An empty support immediately proves the conjunction UNSAT. For each nonempty component construct an extendible boundary assignment by $w$ successive queries under a maintained feasible prefix and $y_i=0$, choosing 0 when SAT and 1 otherwise. This is ordinary SAT self-reduction, so the prefix remains feasible. Query the component together with $\bigvee_i(y_i\ne a_i)$; UNSAT proves the recovered $a$ is its unique projected string, while SAT proves nonuniqueness. The policy may separately query the fully pinned recovered assignment for replay verification. Both components together use $2(w+3)$ ordinary calls. If both unique, $\exists U,V(A\land B)$ iff their recovered $Y$ assignments agree, since private sources are disjoint. Nonuniqueness triggers an exact fallback, not a guessed answer. A pin literal $L$ compiles to four proper ternaries $(L\vee a\vee b),(L\vee a\vee\neg b),(L\vee\neg a\vee b),(L\vee\neg a\vee\neg b)$ with fresh variables $a,b$. A long blocking clause compiles by a linear-size existential Tseitin chain. Source parsing, construction of ordinary bitstrings, failed queries, comparisons, caching, output and peak live buffers are charged.
\end{proof}
\begin{lemma}[PROVED/EXACT oracle restriction]
If the ONLY access to two promised singleton subsets of $\{0,1\}^w$ is opaque point-membership queries, deterministic equality decision takes at least $2^w-1$ point queries in the worst case.
\end{lemma}
\begin{proof} After fewer queries an all-zero reply transcript leaves at least two boundary strings never queried to either oracle. Both equal and distinct singleton choices on those two strings remain consistent. \end{proof}
This lower bound does not apply to source-aware prefix-SAT queries or arbitrary algorithms. The singleton policy's ordinary SAT children have $\Theta(w\log w)$ bits, the same input-size order as its constructed sources. This is a different symbolic shortcut, not a $\lambda<1$ self-contractor or a new attainable joint exponent pair in $E$.
