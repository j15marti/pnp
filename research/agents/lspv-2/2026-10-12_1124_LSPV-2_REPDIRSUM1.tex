\subsection*{Executive result}

This run attacks the proposed universal implication
\[
 \text{many independent clean-core semantic factors}
 \Longrightarrow
 \text{many compulsory solves/extractions/reconstructions}.
\]
The implication is \textbf{FALSIFIED/RETIRED} without an additional
anti-sharing premise.  Repeating the \emph{same} connected formula on fresh
variables multiplies satisfying assignments and compatibility states, but a
total exact wrapper recognizes the repeated representation, solves one
component once, and returns the one-bit answer.  Recognition is fully charged.
This is an easy, syntactically recognizable subfamily and does not refute a
cofinal worst-case obstruction for general 3SAT.

\subsection*{Barrier-transfer literature preflight}

The two obstacles are: (i) a direct-sum theorem must match the one-output SAT
decision problem and unrestricted uniform algorithms, and (ii) any claimed
semantic multiplicity must survive algorithmic sharing.  Jain, Klauck and
Santha prove direct-sum results for deterministic and randomized
\emph{decision trees} computing independent outputs\footnote{R. Jain,
H. Klauck, and M. Santha, ``Optimal Direct Sum Results for Deterministic and
Randomized Decision Tree Complexity,'' arXiv:1004.0105, 2010,
\url{https://arxiv.org/abs/1004.0105}.}.  This is a directly transferable
definition of what a direct-sum statement means, but transfer of their lower
bound to arbitrary RAM/Turing SAT deciders or to a single conjunction bit is
a \textbf{FAILED TRANSFER}.  Biere and Sinz show that CNF connected components
are independent SAT problems and can be detected by graph traversal\footnote{
A. Biere and C. Sinz, ``Decomposing SAT Problems into Connected Components,''
JSAT 2 (2006), 201--208, DOI:10.3233/SAT190022.}.  Sang, Beame and Kautz
explicitly cache disjoint components so a repeated subproblem is solved only
once\footnote{T. Sang, P. Beame, and H. Kautz, ``Combining Component Caching
and Clause Learning for Effective Model Counting,'' SAT 2004,
\url{https://homes.cs.washington.edu/~beame/papers/cachet.pdf}.}.  These are
directly relevant algorithmic precedents, not arbitrary-algorithm lower
bounds.  Döcker's NP-completeness of Monotone 3SAT-(2,2) confirms the chosen
signed clean-core language is globally hard\footnote{J. Döcker, ``Monotone
3-SAT-(2,2) is NP-complete,'' arXiv:1912.08032,
\url{https://arxiv.org/abs/1912.08032}.}; it does not make every repeated-copy
subfamily hard.

\subsection*{Exact definitions and quantifiers}

Let \(F\) be a connected CNF over variables \(x_1,\ldots,x_n\).  For
\(k\geq1\), let \(\Rep_k(F)=\bigwedge_{i=1}^k F^{(i)}\), where the copies use
pairwise disjoint renamed variables and the clause/literal order may vary.
The bounded recognizer used here ranks variable identifiers inside each
connected component, sorts literals and clauses, and accepts exactly when all
normalized component strings agree.

\paragraph{REPEATED-COMPONENT-SEMANTIC-DIRECT-SUM-COLLAPSE1.}
\textbf{Status: \EXACT, independent review pending.}  For every connected CNF
\(F\), every \(k\geq1\), and every total exact deterministic SAT decider
\(A\), there is a total exact deterministic decider \(B_A\) such that
\[
 \SAT(\Rep_k(F))=\SAT(F),\qquad
 \#\SAT(\Rep_k(F))=\#\SAT(F)^k,
\]
and on every recognized repeated-copy input \(G=\Rep_k(F)\),
\[
 T_{B_A}(G)\leq T_{\rm rec}(G)+T_A(F)+O(1),\quad
 \#\text{calls to }A=1,
\]
while the declared compatibility-extractor and witness-reconstructor call
counts are both zero.  On all other CNFs, \(B_A\) falls back to \(A\) on the
original input.  With comparison sorting,
\(T_{\rm rec}(G)=O(|G|\log |G|)\); radix/canonical integer encodings can make
the scan linear.  The theorem needs only the former bound.

\paragraph{Proof.}
Assignments to disjoint copies are Cartesian products, proving the two
semantic identities.  Build the variable--clause incidence graph, enumerate
connected components, normalize each component by rank-renaming its variables
and sorting, and compare all normalized strings.  If all agree, run \(A\) on
the first normalized component and output its bit.  If they do not agree, run
\(A\) on the original CNF.  Recognition therefore never changes correctness.
Only one base call is made on the accepted island, and the program interface
contains no extraction or reconstruction procedure.  All input traversal,
normalization, comparison, retained first component, fallback, and decision
output are charged. \(\square\)

If \(F\) is proper, duplicate-free signed Monotone 3SAT-(2,2), then
\(\Rep_k(F)\) is also proper, duplicate-free and exactly (2,2)-occurrence:
fresh renaming preserves each occurrence count and creates no cross-copy
duplicates.  Hence the counterexample applies inside the declared clean core.
For a factorizing compatibility predicate,
\[
 H(\Rep_k(F),\alpha_1\sqcup\cdots\sqcup\alpha_k)
 =\bigwedge_{i=1}^k H(F,\alpha_i),
\]
so the compatible-object set is a Cartesian power even though the decision
path need not enumerate or reconstruct it.

\subsection*{Hostile controls and exact scope}

Padding and redundant clauses can destroy the exact repeated-component syntax;
the recognizer then falls back, so total correctness does not rely on a
promise.  Alternate clause/literal order is normalized.  Different variable
names are removed by within-component rank renaming.  Arbitrarily isomorphic
components under unrelated permutations are not required: a single infinite,
polynomially recognizable repeated-copy island suffices to refute the
unqualified universal direct-sum obligation.  Nonidentical independent
products remain a live case.  A total exact one-bit decision program may also
short-circuit UNSAT after one component; a universal \(k\)-solve claim is even
less tenable there.

This result does \emph{not} prove that arbitrary clean-core inputs admit such
sharing, does not improve an exact-SAT exponential base, and does not refute a
worst-case statement quantified as \(\forall A\,\exists F\).  The easy-island
quantifier guard from QGUARD1 is retained.
