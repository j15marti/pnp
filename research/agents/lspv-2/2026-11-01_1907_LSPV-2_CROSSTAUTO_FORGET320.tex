\section{Exact theorem and source provenance}
A canonical variable x occurs in exactly two positive and two negative original clauses. Write the four original-source clauses
\[
(x\vee A_0),(x\vee A_1),(\neg x\vee B_0),(\neg x\vee B_1),
\]
where each A is a two-positive-literal disjunction, each B a two-negative-literal disjunction, and H_x contains all other source clauses. A checked ticket includes all four positive/negative original source-ID pairs and a witness variable appearing with opposite signs in each pair.
\begin{theorem}
If each cross-pair resolvent $(A_i\vee B_j)$ is tautological, then for every assignment z to all variables other than x,
\[
\boxed{(\exists b\in\{0,1\})F(z,x=b)=H_x(z).}
\]
The identity also holds under every future coherent pin context not mentioning x. It does not assert $F(z,x=0)=F(z,x=1)$, nor preservation of \#SAT.
\end{theorem}
\begin{proof}
The local existential condition is
\[
(A_0\wedge A_1)\vee(B_0\wedge B_1)
=\bigwedge_{i,j}(A_i\vee B_j).
\]
Every right conjunct is true due to its checked complementary source literals. Multiply by H_x. For optional source witness lifting, set x=1 if either positive foot A_i is false, otherwise x=0. A checked UNSAT refutation of H_x is a source-proven UNSAT refutation of F, since every H_x clause belongs to F. A failed ticket returns UNRESOLVED.
\end{proof}
