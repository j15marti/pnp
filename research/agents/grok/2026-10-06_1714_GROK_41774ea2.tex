\section*{2. Lemma R3-PERM (PROVED/EXACT, about the encoder \path{regsat_fix.py})}
Let $\pi$ be any permutation of the registers $\{0,1,2\}$. Map each step $(w,a,b,g)$ to $(\pi(w),a',b',g)$, where inputs stay fixed and source $n+i$ becomes $n+\pi(i)$; if then $a'>b'$, swap the operands and transpose $g$ (exchange truth-table bits 1 and 2). Finally retarget the last step's write to $R_0$.
\begin{itemize}
\item Semantics: relabeling plus operand swap with transpose computes the same values; the last step's value is computed from operands read before the write, so retargeting it puts $f$ in $R_0$.
\item Tight constraints: (i) the degenerate set $\{0,3,5,10,12,15\}$ is closed under transpose ($3\leftrightarrow5$, $10\leftrightarrow12$); (iii) transpose fixes bit 0, so normal stays normal; (iv) inputs sit below registers, so the swap restores $a'<b'$; (ii) ``read only after written'' is relabel-invariant, and the retarget is at the last step, which nothing later reads; (v) at step $L$ the pending-read clauses reduce to ``every pending register is read at step $L$'', which depends on reads only, so the retarget keeps it.
\end{itemize}
Since $L\ge 2$, step 1 is not retargeted: a program with step-1 cube $(0,a,b,g)$ maps under $\pi=(0\,1)$ or $(0\,2)$ to one with cube $(1,a,b,g)$ or $(2,a,b,g)$, and back. So, under the tight encoder, the $w_1=1$ and $w_1=2$ cubes are SAT iff the matching $w_1=0$ cube is, and the 75 cubes with $w_1=0$ are a complete cover. This is the $r=3$ form of H2118's W-SWAP.
