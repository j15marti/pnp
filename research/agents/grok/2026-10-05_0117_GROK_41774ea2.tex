\section*{Test (scratch \texttt{/workspace/scratch\_h0117}; \texttt{peb.py}, \texttt{nerode.py}; all numbers computed this pass)}
\textbf{Pebbling.} $P_L$ is the pyramid with $L$ sources and $L(L+1)/2$ nodes, node $(i,j)$ fed by $(i-1,j)$ and $(i-1,j+1)$. Standard black pebbling without sliding; time counts placements. An exact 0--1 BFS over all pebble configurations gives, for $L=2,\dots,6$: minimum pebbles $L+1$ $(3,4,5,6,7)$, and at that minimum budget the least time equals the node count $(3,6,10,15,21)$. So no recomputation is ever needed at the minimum budget, and the forget-then-recompute price on these pyramids is $0$.

\textbf{Nonmergeability.} Each source gets a value in $[d]$ and each internal node applies one fixed table $g:[d]^2\to[d]$. For every prefix of sources in left-to-right order the script enumerates all inputs and counts distinct residual functions $K_j$ exactly; it also takes the best order over all $L!$ source orders for $L\le5$. Tables: XOR and NAND at $d=2$, a quasigroup at $d=2,3,4$, and three seeded random tables (seed $20261005+d$) at each $d=2,3,4$; $L\le6$ ($L\le5$ at $d=4$); 66 cases.

\section*{Reading}
\textbf{PYR-PEB: PROVED/EXACT (finite).} For $L=2,\dots,6$ the black-pebbling number of $P_L$ is $L+1$ and the least time at that budget is $L(L+1)/2$, by exhaustive search.

\textbf{NONMERGE-EQUALS-PEBBLE on pyramids: FALSIFIED/RETIRED.} The exact-reproduction hypothesis that H0056 set up fails on every tested finite case. The nonmergeability count is a property of the function; the pebble price is a property of one DAG. When $g$ is structured (XOR, quasigroup) the function collapses to $d$ classes no matter how tall the pyramid is. This confirms on finite cases the escape that TSR1 already flagged: a derived distinction in $G_F$ need not be indispensable. It is not a falsification of $T\ge\mathrm{PebbleTime}(G_F,S)$, which stays \textbf{OPEN}.

\textbf{PYR-NO-RECOMPUTE: COMPUTATIONAL ($L\le6$).} Because the minimum-budget time equals the node count, pyramids cannot test the time side of the charge at all. Any honest test of forget-then-recompute needs a DAG whose least time at the minimum budget exceeds its node count.
