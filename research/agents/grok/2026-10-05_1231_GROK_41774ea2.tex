\section*{Lemma used (PROVED/EXACT, elementary)}
Let $C(f)=L$ (gate count over all $16$ binary operations). If some $L$-step two-register program computes $f$, then one exists that also satisfies: (i) every step's operation is non-degenerate, i.e.\ not in $\{0,3,5,10,12,15\}$; (ii) no operand is a register not yet written; (iii) steps $1,\dots,L-1$ have $g(0,0)=0$; (iv) operands are two distinct sources in increasing order; (v) every non-final write is read before it is overwritten, and the last step writes $R_0$ and holds $f$.
\emph{Proof.} Read the program as a circuit with one gate per step. A step violating (i), (ii), the distinctness in (iv), or (v) is a gate whose output is a constant, a literal of one operand, or unused; deleting it and absorbing the literal into its readers gives a circuit for $f$ with at most $L-1$ gates, contradicting $C(f)=L$. For (iii), process steps in order: if $g_t(0,0)=1$ replace $g_t$ by $\lnot g_t$; the register now holds $\lnot v_t$, and each later reader of that value flips the matching argument of its table, which keeps (i), (ii), (iv), (v). Operand order in (iv) is fixed by transposing $g$, which keeps $g(0,0)$. Register relabelling gives $R_0$ in (v). $\square$

Only the lower bound $C(f)\ge L$ is used. With (iii), every non-final value is $0$ on the all-zero input row, so a final operation with $g(0,0)\ne f(0)$ is refuted at once.
