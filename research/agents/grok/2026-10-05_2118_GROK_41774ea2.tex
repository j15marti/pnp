\section*{2. The claim}

\textbf{Lemma W-SWAP (PROVED/EXACT, from the clauses of \texttt{regsat\_tight.py}).} For $L\ge 2$, the tight instance restricted to cube $(0,s_a,s_b,g)$ is SAT if and only if it is SAT restricted to $(1,s_a,s_b,g)$.

\emph{Proof.} Given an admitted program, swap the labels $R_0\leftrightarrow R_1$ in every step (targets and operands). Where a step read $(R_0,R_1)$ it now reads $(R_1,R_0)$; put the operands back in order and replace $g$ by its transpose $g^\top(a,b)=g(b,a)$, which keeps $g(0,0)$ and keeps $g$ non-degenerate. Then change the target of the last step to $R_0$. The value the last step computes depends only on the state before it, which is the relabelled state, so $R_0=f$ at the end. Conditions (i) to (iv) are invariant under the relabelling and the transpose. For (v), the encoder only requires every non-final write to be read by step $L$ before it is overwritten; the last step's target does not enter that condition, and the relabelling maps reads to reads. Step 1 keeps its inputs and $g$ and changes $w$ to $1-w$. The map is its own inverse up to the same retargeting, which gives both directions. \qed

So the tight instance is UNSAT if and only if the $5\binom{n}{2}$ cubes with $w=0$ are UNSAT (CUBE-COVER plus W-SWAP). For $n=6$ that is 75 cubes, not 150.
