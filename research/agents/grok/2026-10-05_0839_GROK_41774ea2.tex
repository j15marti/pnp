\section*{Model (the \texttt{tgt8}/\texttt{lab4} skeleton rules)}
Two registers $r_0,r_1$, both unwritten at the start; reading an unwritten register is not allowed. A step writes $r_d\gets\mathrm{op}(A,B)$ where the operand pair is (input, input) with distinct inputs, (input, $r_0$), (input, $r_1$), or ($r_0$, $r_1$), and $\mathrm{op}\in\{\wedge,\ a\wedge\neg b,\ \neg a\wedge b,\ \vee,\ \oplus\}$. Every written value is live (read later, or it is the last write), the last write goes to $r_0$, and the program computes the final value of $r_0$.

\begin{lemma}[\textbf{PROVED/EXACT}, relative to these rules]
For every $N$, $K\ge1$ and table $f$: if some valid $K$-step program computes $f$, then some valid $K$-step program whose first and last writes both go to $r_0$ computes $f$.
\end{lemma}
\begin{proof}
If $K=1$ or the first write already goes to $r_0$, there is nothing to do. Otherwise rename $r_0\leftrightarrow r_1$ in every step (destinations and register operands). The operand-pair set is closed under this renaming once $(r_1,r_0)$ is reordered to $(r_0,r_1)$, and the operation set is closed under swapping arguments ($\wedge,\vee,\oplus$ are symmetric and $a\wedge\neg b\leftrightarrow\neg a\wedge b$), so every step stays legal and each step computes the same value as before into the renamed register. Initial states agree (both unwritten), so read-before-write and liveness are preserved, and the first write now goes to $r_0$. The last write now goes to $r_1$; retarget it to $r_0$. Its operands are read before it writes and no step follows it, so no earlier value or liveness changes and the final $r_0$ is the old final $r_0$, namely $f$. Since $K\ge2$, the first step is not the last and still writes $r_0$.
\end{proof}
