## Theorem 8: genuine shared gates to original-input count (PROVED/EXACT RESTRICTED)

Let E be the set of DISTINCT root-reachable bipartite E-gate edges discovered by a paid DFS over original gate IDs. Then, pointwise on EVERY original n-bit input x,

C(x) = AND over (u,v) in E of (NOT x_u OR NOT x_v).

**Proof:** A topological induction assigns each E leaf its corresponding edge predicate. Each A gate is the conjunction of the predicates of the children; a repeated child and a repeated shared subDAG are idempotent for Boolean truth, not new independently quantified assignments. The output is therefore the conjunction of the distinct reachable edge predicates. It accepts precisely the independent sets of the recovered bipartite graph. This pointwise statement concerns the original-input circuit function, not the SAT decision function on circuit encodings.

**Complete executable pipeline:** inspect full ASCII input and source-sized header/count guards; check gate IDs, operand ranges, all variable uses, acyclicity and root reachability; collect distinct edges without expanding the shared DAG; construct original adjacency; compare BOTH shore neighborhoods to discover false-twin classes; check each quotient rectangle complete/empty; discover a unique spanning alternating quotient cycle with k>=3; construct group sizes alpha_i, beta_i; evaluate the exact integer 2x2 transfer M_i=[[2^beta_i,1],[2^alpha_i-1,2^alpha_i-1]]; output trace(product_i M_i). This counts every original accepting input ONCE. For a valid source with no qualifying quotient, enumerate the original n-bit input vectors and evaluate the actual shared DAG for each. Hence the whole algorithm is total and exact on the declared input language. Invalid strings are explicitly rejected. No decomposition oracle is used.

**Parsimonious strict proper 3-CNF compiler:** Introduce one distinct output-wire variable z_i per source gate and three fresh pins p,q,r; seven proper ternary clauses forbid all nonzero pin assignments. For E(u,v) use (-z_i,-x_u,-x_v), (z_i,x_u,p), (z_i,x_v,p). For A(j,k) with different gate identities use (-z_i,z_j,p), (-z_i,z_k,p), (z_i,-z_j,-z_k). For identical child references use (-z_i,z_j,p) and (z_i,-z_j,p). Finally require output true using (z_root,p,q). Each gate is constrained to its exact function and all pins to zero. Thus each original input has precisely ONE full auxiliary extension, satisfying exactly when C(x)=1. There are n+g+3 variables and at most 3g+8 clauses, all of width exactly 3 with distinct variable identities. No false equation of counts between unconstrained auxiliary wires and original inputs occurs.

**Exponential chosen-unrolling witness:** For the discovered twin cycle with k groups on each side, group size d, let m=2k d^2 distinct E gates. Define h_1=E_1, v_i=AND(h_(i-1),E_i), h_i=AND(h_(i-1),v_i). The true DAG contains 3m-2 gates and has genuine internal fan-out two, but the naive fully copied tree has exact gate-node occurrences U_1=1, U_i=2U_(i-1)+3, so U_m=4*2^(m-1)-3. Despite this exponential prescribed unrolling, the uniform source recognizer and weighted-register evaluator have polynomial complexity. For d=k, n=2k^2, original graph treewidth >=k and original-input left:right matrix rank >=2^floor(k/2) over every field, while actual count is polynomial time. The unrolling quantity is NOT a work lower bound.
