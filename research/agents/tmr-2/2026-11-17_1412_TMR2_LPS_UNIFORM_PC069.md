## Authentic input-to-output pipeline

Fix p=73, Sigma=Z/5Z, and R(a,b)=[b-a mod5 in {1,3}]. For every prime q>73^3 with q≡1 (mod292), make the nonbipartite Lubotzky–Phillips–Sarnak graph X^{73,q} on PSL_2(F_q). Number the group elements in the deterministic BFS order below, and direct each undirected edge from lower index to higher index. Emit exactly

    p t5 n m
    v 0
    ...
    v (n-1)
    a u v

with one explicit declaration per vertex and each arc distinct and lexicographically sorted. Here n=q(q²-1)/2 and m=37n, since degree=74. Every line is newline-terminated; complete source size L=Theta(n log(n+2)) bits. Each orientation is a legal ordinary T5-homomorphism instance. It is not a different promise language or an unspecified graph oracle.

To generate X, find the least i,s in F_q with i²=-1, s²=p. Enumerate all 74 four-square integral quaternions (a,b,c,d) of norm 73 with a>0 odd and b,c,d even, and map each to the projective class of

    s^{-1} [[a+bi, c+di],[-c+di,a-bi]]  mod q.

Its determinant is 1. Represent PSL_2(F_q) by the lexicographically smaller of the determinant-one matrix and its negative, then BFS from identity with sorted generators. Multiply actual 2x2 matrices modulo q and deduplicate true group elements; enumerate all vertices, generate all edges, sort them and serialize all L source bytes. The LPS connectedness theorem ensures the BFS covers exactly n elements. All arithmetic, least-root searches, generator enumeration, dictionary comparisons, failed lookups and physical source writing are charged.

Primality and congruence screening may use deterministic trial division. A uniform parameter enumerator scans q in increasing order, filters prime q≡1 mod292, q>73³ and emits the indexed family. Dirichlet's theorem supplies infinitely many primes in this progression. With cost measured **against the explicit output source length of the particular produced member**, even trial division and earlier rejected candidate generation are polynomial because there are at most q candidates before q, and q=O(L). This does not claim polynomial time in the binary representation of the family index k or in log q.

## Exact hard/cheap structure, with proofs

**Chromaticity and exact zero count, all eligible q.** Because p=73 and q≡1 mod292, quadratic reciprocity gives (73/q)=(q/73)=1. The nonbipartite LPS component is a connected 74-regular Ramanujan graph whose nontrivial eigenvalues have absolute value at most 2sqrt(73). Hoffman's chromatic inequality gives

    chi(X)>=1+74/(2sqrt(73)) = 5.330522446...,

hence chi(X)>=6. Every homomorphism of an orientation into the loopless tournament T5 would induce a proper 5-coloring of X. There is no such coloring, so **Z(G_q)=0** exactly, not just a failed heuristic search.

**Girth and full path consistency.** For nonbacktracking closed walks in the odd-prime LPS quaternion graph, the integral-quaternion argument in Knuth's Stanford GraphBase GIRTH notes gives 73^g >= 1+4q². For q>73³, no cycle of length g<=6 exists. Thus the underlying simple graph has girth at least seven. The TMR-5/071 proof shows that for *every orientation* of a graph with girth>=7, the nonempty binary relations determined by signed unique paths of length<=3 (full relation for distance>=4) form a post-fixpoint of standard full path consistency. Each four-edge signed T5 path already permits every endpoint difference in Z5. Therefore full arc/path consistency remains nonempty and reports UNKNOWN although the instance is UNSAT. The result does not claim that every stronger consistency algorithm fails.

**Expansion forces linear graph treewidth.** Set d=74, lambda=2sqrt(73)<d. The Ramanujan eigenvalue estimate implies, for every vertex set U of size <=n/2,

    e(U,V\U) >= (d-lambda)|U|/2.

A tree decomposition of width t yields a 1/2-balanced separator S with |S|<=t+1. If |S|>=n/4 it is already linear. Otherwise one may group connected components of X\S into a set U with n/4<=|U|<=n/2 and e(U,V\U)=e(U,S)<=d|S|. Hence

    t+1 >= (d-lambda)n/(8d).

So tw(X)=Omega(n). It is *not* a treewidth-based time lower bound.

**Critical semantic counterexample.** Since Z(G_q)=0, the complete Boolean indicator C_{G_q}(x) is **pointwise zero on all 5^n original-label inputs**. Every semantic partial-assignment cofactor is zero. Thus every fully reduced assignment tensor has rank 0 over every field, and the minimum pointwise 5-ary decision diagram has a single reject terminal. This is true *simultaneously* with treewidth Omega(n) and failure of full path consistency. The syntactic mask-state DP could still construct exponentially many unmerged states. Its state count is not a necessary resource for an unrestricted, source-aware solver. No theorem computes this zero semantic quotient for arbitrary inputs.

**Charged polynomial fast path for these indexed sources.** On an arbitrary canonical explicit T5 source, parse all lines, reject malformed records, count n and m, solve n=q(q²-1)/2 for integer q by bounded trial, verify prime, q≡1mod292 and q>73³, reconstruct the entire expected LPS canonical graph as above, and compare every original directed arc with the regenerated sorted list. Only on exact matching do we output UNSAT and exact integer zero. Every nonmatching valid source must use a correct general fallback, for example exhaustive original-label DFS, which may take exponential time. No graph-isomorphism oracle or supplied schedule is used. In the recognized family, the same deterministic locally headed machine has conservative joint bounds T_fast(L)=O((L+1)^8), S_peak(L)=O((L+1)^3), including all rejected checks, arithmetic bit lengths, source authentication, number-theoretic searches, BFS, matrices, sorting, caches, graph rereads and exact output. A source that is merely *isomorphic* but differently indexed need not take the fast path.
