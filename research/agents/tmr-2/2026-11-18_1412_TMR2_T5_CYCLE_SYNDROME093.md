# TMR-2/093: exact F5 cycle syndromes and high-girth multi-theta SAT theorem

**Date:** 2026-11-18 (America/Los_Angeles). **Owner:** TMR-2, PNP Information Necessity. **Template:** \(\Sigma=\mathbb Z_5\), \(R(a,b)\iff b-a\pmod5\in\{1,3\}\). **Statuses:** analytic exact formula and explicit source-aware upper bound; structural SAT lemmas proved by reduction to exact path supports; finite audits COMPUTATIONAL; \(P\) versus \(NP\) OPEN.

## Theorem 093-A: exact binary-cycle-syndrome representation

Let \(G=(V,E)\) be a finite loopless directed source with \(n\) vertices, \(m\) arcs and \(c\) weak components. Fix an orientation-respecting arc index, an undirected spanning forest, and the \(\beta=m-n+c\) fundamental cycles of its \(m-(n-c)\) nonforest arcs. Let \(H\in\mathbb Z_5^{\beta\times m}\) be the **signed** cycle-versus-source-arc incidence matrix; for each fundamental cycle, traverse its chord from tail to head and then the unique tree path back. The coefficients are \(0,+1,-1\) modulo five.

Every allowed edge difference is uniquely \(x_v-x_u=1+2b_e\pmod5\), with \(b_e\in\{0,1\}\). Hence the exact original-label solution count satisfies

\[
\boxed{Z(G)=5^c\left|\left\{b\in\{0,1\}^{m}:Hb=-3H\mathbf1\pmod5\right\}\right|.}
\]

**Proof.** All cycle sums of the differences \(d_e=1+2b_e\) must vanish. These constraints are exactly \(H(1+2b)=0\), or \(Hb=-3H\mathbf 1\), since \(2^{-1}=3\pmod5\). Conversely, choose any one root label per weak component, then integrate \(d_e\) along the forest. The fundamental-cycle constraints prove consistency on every nonforest arc. A valid binary vector therefore yields exactly \(5^c\) source assignments. This establishes the bijection, not merely an upper or lower bound. Empty components, leaf edges and cycles are included. Loops can be rejected immediately by \(R(a,a)=0\).

## Exact source-transition invariant 093-B

Set \(h_e=H_{\cdot,e}\), \(r=-3H\mathbf1\), and let \(D_0(0)=1\), with every other state zero. Process the **actual source arcs** in authenticated order:

\[
D_{k+1}(s)=D_k(s)+D_k(s-h_{e_k}),\qquad s\in\mathbb Z_5^\beta.
\]

After all \(m\) steps, \(Z(G)=5^cD_m(r)\). The vector \(D_k\) is an exact integer dynamic invariant, not a representation-rank heuristic. Its support is a legitimate, source-dependent width for the unreduced syndrome automaton; it is **not** the minimum OBDD width, a lower bound for arbitrary solvers, or a measure of work a source-aware algorithm is forced to perform.

An associative-array implementation uses at most \(5^\beta\) states, \(O(m(\beta+1)5^\beta)\) modular-coordinate operations and integer additions, plus construction of the fundamental cycles, \(O(\beta(n+m))\) with a basic per-chord BFS. Counters have at most \(m+1\) bits, so elementary bit operation costs are at most \(O(m^2(\beta+1)5^\beta)+\operatorname{poly}(n,m)\). Live storage is \(O(5^\beta m+m\beta)\) bits, not free unit-cost integers. This improves the previous \(O(5^{2\beta}\operatorname{poly}(N))\) pinned-feedback-edge counting upper bound as a function of \(\beta\). Ordinary treewidth, elimination, arc consistency, path contraction, branch-and-bound, and compact source-recognition remain available controls.

## Theorem 093-C: every girth-six multi-theta is SAT, at arbitrary cycle rank

Let the undirected two-terminal source skeleton consist of any number of internally vertex-disjoint terminal-to-terminal paths. If the undirected girth is at least six, **every orientation has a T5 homomorphism**, regardless of the number of paths. A source with exactly one such path is a forest and is trivially satisfiable.

Proof by exact endpoint support: a path of length \(1\) allows two terminal differences, a path of length \(2\) allows three, a path of length \(3\) allows four **including difference 0**, and a path of length at least \(4\) allows all five. Girth at least six means the two shortest path lengths sum to at least six. If a path has length 1, every other path has length at least 5; if one has length 2, every other has length at least 4. In either case, choose any terminal difference allowed by the short path, and all remaining paths extend independently. Otherwise every path has length at least 3, and **equal terminal colors** are simultaneously feasible on every path. This is an unconditional structural SAT theorem, not a claim about computational lower bounds.

The same argument permits any additional independent loops of length at least six attached at either terminal: each such loop extends at its fixed terminal color. Thus a connected girth-six 2-core with at most two degree-\(\ge3\) branch vertices is SAT, even for unbounded \(\beta\).

## Theorem 093-D: source-aware short-core forest certificate

Delete leaves and suppress maximal degree-two paths, retaining exact endpoint support. Mark each suppressed core edge **short** when its underlying source path has length at most three. If the graph formed by the short edges is a forest, the original source is SAT. Assign each tree of short edges from an arbitrary root, always choosing an allowed terminal label; every suppressed path of length at least four can then extend arbitrary chosen endpoint labels independently. All pruned trees also extend.

A useful corollary is a crude but analytic girth-versus-cycle-rank exclusion. For a connected, loopless, simple oriented source with \(\beta\ge2\), the nontrivial suppressed core has minimum degree three, hence at most \(3(\beta-1)\) core edges. If the source is UNSAT, the short-edge subgraph contains a cycle. That cycle expands to a closed original walk of length at most \(3\cdot3(\beta-1)\), so

\[
\boxed{\operatorname{UNSAT}(G)\Longrightarrow g(G)\le9(\beta(G)-1).}
\]

The statement extends componentwise. If \(g(G)>9(\beta(G)-1)\), then \(G\) is SAT for \(\beta\ge2\); loopless forests and single cycles are also SAT. This is a **polynomial-time YES certificate** under the stated condition, not a running-time lower bound. The constant nine is not claimed sharp.
