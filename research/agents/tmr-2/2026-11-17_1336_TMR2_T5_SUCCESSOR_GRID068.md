## First-principles exact gadget lemma

Consider three original source vertices x,z,w and exactly the directed arcs x->z, x->w, w->z. The first arc requires d=z-x in {1,3} modulo 5. The two-step path x->w->z requires d in {1+1,1+3,3+1,3+3}={2,4,1}. Their intersection is {1}. The only summand obtaining 1 modulo 5 is 3+3. Consequently

    R(x,z) R(x,w) R(w,z)=1  iff  z=x+1, w=x+3  (mod 5).

For every x,z there is exactly one witness w if z=x+1, and none otherwise. The original T5 assignment on w is counted exactly once, not existentially dropped with a varying multiplicity.

Take any finite undirected bipartite H=(B disjoint_union W,F) with no isolated vertices. Orient each base edge b->w from B to W. Introduce fresh h_e for every e=(b,w) and add arcs b->w, b->h_e, h_e->w, with no other arcs. This is an ordinary directed T5 instance G(H), not an advised oracle. By the gadget, all B labels in a connected H-component must agree, and each W label is their common value plus 1, each h_e their value plus 3, mod 5. Each connected H-component has exactly five original-variable assignments, and components multiply, proving

    #Hom(G(H),T5) = 5^{c(H)}.

The empty-base-graph case is excluded from the recognizer and handled by the ordinary exact solver. No extra powers of 5 or nonuniform auxiliary choices appear.

## Uniform source parser, positive certificate and fallback

Canonical ASCII bytes are:
  p t5 n m\n
  v 0\n ... v (n-1)\n
  a u v\n ... (strictly sorted, distinct arcs).

All records end with '\n'. Integers use canonical nonnegative decimal notation. The parser checks exact line counts, every explicit vertex declaration, m arcs, lexicographic order, range, duplicate rejection, absence of any trailing data and ASCII syntax. Valid loops/opposite arcs return exact zero. The existence of n explicit vertex lines implies n<=N, and the arc count also satisfies m<=N; a giant decimal n with no declarations is INVALID, not an underspecified trillion-variable instance.

For loopless/oriented sources, degree-scan every vertex: B has indegree 0 and outdegree>=2; W has outdegree 0 and indegree>=2; auxiliary candidates have indegree=outdegree=1. Require an exact partition. Construct all direct B->W arcs, require one-to-one correspondence with auxiliary candidates h_e whose single predecessor is b and single successor is w, and verify the complete original arc set equals precisely the three arcs per direct edge. On failure invoke a correct complete original-label DFS, not a guessed gadget interpretation. On success union-find the base edges and output 5^c exactly. A generic all-graph exact fallback may require exponential time, as expected for an NP-complete decision problem.

A conventional locally headed fixed-tape deterministic realization has, for the *certified subgrammar*, conservative same-run T_fast(N)=O((N+1)^7), S_peak(N)=O((N+1)^3) bits. Its disjoint paid phases are: complete input scan and canonical authentication; adjacency/degrees/arc indices; role discovery; unsuccessful pair checks and full witness-source authentication; union-find, with addresses/source-head movements; exact integer 5^c powering and output. Each phase fits the displayed bounds; peak space is taken over these phases of the *same run* rather than adding separately alleged per-worker memory. For nonmembers, a complete DFS yields T=5^n poly(N), S_peak=poly(N) with n<=N; code interpreter stack/resource limits are not a physical TM simulation.

## Grid family: arbitrarily large treewidth, constant exact count

Let H_l be the l-by-l square grid, l>=2, with checkerboard B/W classes. Then

    n(G(H_l)) = l^2+2l(l-1)=3l^2-2l
    m(G(H_l)) = 3[2l(l-1)]=6l(l-1)
    c(H_l)=1;  #Hom(G(H_l),T5)=5.

Every base grid edge remains a direct original arc of G(H_l). Its underlying undirected graph thus contains H_l as a subgraph, so tw(G(H_l))>=tw(H_l)=l. Source byte count N=Theta(l^2 log l). This invalidates any asserted necessary exact-count work lower bound based only on source treewidth or forced prescribed contraction width. It does not assert small optimal tensor width or derive any all-algorithm lower bound.
