## New theorem: bit-probe lower bound on every permutation diagonal
Original CHARGED-UNSAT-TRANSPORT1, source report at e71b388635cd817b4fd3f641a3ab938ccdca906c, research/main/Charged_UNSAT_Transport_2026-11-21.md eqs 8–23. For r=2^k, k>=2, proper 3-CNF target has n=8r-1,m=10r, literal width w+1 with w=ceil(log2(8r)); unary n, gamma(m+1), ordered clauses, adjacent witnesses alpha,beta, release field y. Exact N=3n+2+2 floor(log2(m+1))+3m(w+1)+w. Left and right map entries duplicated by binary-clause padding. B(pi,sigma) UNSAT iff pi=sigma: source constraints force every X_i=0 on diagonal, contradict OR. Off-diagonal choose differing i, set X_i=1 and Y_pi(i)=1 all others zero, lift OR chain, y=1 and z_C according to first literal; all target clauses checked. Both assignments alpha/beta each falsify one clause and differ one bit. No minimal-UNSAT assertion for compiled formula.

Fix any permutation diagonal. For each side and each low identifier bit b<k, pair values j,j xor 2^b within 1..r-1. Exactly r/2-1 unordered pairs for each b (remove the pair containing zero from full k-cube). Swap the two values on that side only. Since Y_j has ID r+j, the swap toggles exactly four physical input bits: one bit in each of two padded occurrences for each of the two entries. The map remains a permutation, differs from the other map, and the source is SAT. All support groups are pairwise disjoint: within one bit and side the pairs are disjoint; different bit positions or sides are different physical cells. This works for arbitrary permutation order because each value occurs once. Thus any deterministic exact adaptive bit-query algorithm, even under the promise that both maps are permutations and layout is valid, must query at least one position in every group on EVERY diagonal. Otherwise its transcript is identical on the corresponding SAT neighbor. The lower bound is 2k(r/2-1)=k(r-2)=Theta(N). For a randomized algorithm with error <=epsilon<1/2 on each input, couple its random coins on the diagonal and each neighbor: probability of reading that group's support is at least 1-2epsilon by difference of answer probabilities. Summing disjoint group indicators yields expected probes >=(1-2epsilon)k(r-2). If arbitrary maps are admitted, individual entry flips give 2k(r-2) disjoint two-bit groups. This is a physical input-bit query theorem, not a lower bound for one operation that may inspect all bits in parallel for free. It does not exclude polynomial time.

## Reconstructed single-tape crossing and CM firewall
Fixed deterministic one-head, fixed finite Q-state tape machine, local move, no external oracle or clock, fixed-left output. On each of D interior cuts of common middle block, diagonal crossing sequences inject over r! permutations by splicing equal transcripts into a SAT hybrid. h=log2(r!)=Theta(N), D=6(r-2)(w+1)-1=Theta(N). At most Q^j strings of length j; average crossings Omega(h/log Q) per cut. Each physical transition crosses at most one cut, so averaged T=Omega_A(Dh)=Omega_A(N^2). At crossing j, prefix of states plus full current configuration injects by the same splicing up to that crossing. At most (Q^j-1)/(Q-1)+Q^j(2^s-1) permutations either fail to reach crossing j or have a faithful code shorter than s. Choose j<=h/(4 log2 Q), s=floor(h/4); sum over distinct events, obtaining expected CM_min=Omega_A(Dh^2)=Omega_A(N^3). The same-run assertion follows by selecting q=floor((h-z)/log2 Q), s_j=floor(h-z-j log2 Q) and union bound Dq*2^-z with z=O(log N), guaranteeing both bounds with high probability. CM_phys dominates minimum configuration description up to constants because span encoding is faithful. This is worst case/almost all, not every diagonal (identity may have low K). Earlier matching multitape recognizer O(N) time/space (canonical layout, map extraction/authentication) yields sole-tape O(N^2), S=O(N), CM_phys=O(N^3) via full-span sweep simulation. No new full TM simulation executed; symbolic reconstruction only. Static separation ceiling: h<=min(L,R)<= (N-D)/2, so Dh<=N^2/8 and Dh^2<=N^3/27. No superpolynomial growth from this argument.

With exact random access, direct map extraction and full authentication including all clause IDs, witnesses and release field costs O(N polylog N) bit work, polynomial space, no growing exhaustive kernel. For fixed valid layout, bitwise equality and pattern checks use uniform polynomial-size bounded-fanin Boolean circuits with O(log N) depth (balanced AND, XOR, comparison; layout computable in polynomial time from N). This is an exact global-access circuit, not a claim about arbitrary floating-point transformer architectures. A free polynomial-dimensional attention primitive allowing global exact bit gathering can realize these comparisons; physical crossing assumption then fails. If attention remains implemented on the same single local-head tape, the old crossing proof still applies. Free GE/2SAT only on explicitly acquired data preserve input-bit probe theorem; an oracle reading input without charging queries violates that model. The Nov26 pure-function report's claim that any deterministic residual can be generated in the same paid pass is NOT established by determinism: replay of actual T steps costs poly(T+N), not necessarily poly(N); recoverability is not efficient recovery. No free semantic oracle or implicit advice. General proof replay on random access may be polynomial in packet size, single-tape simulation polynomial overhead, preserving polynomial-time class but not quantitative exponents.
