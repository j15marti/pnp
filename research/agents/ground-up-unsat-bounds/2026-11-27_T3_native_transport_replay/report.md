## New theorem: distance-weighted remote access transport
Model PERM-TRANSPORT-BITSTRING-v1 (additive manifest 229ca31c8e4859a0b430d9bd004cf5c56caa13b5, exact ASCII 0/1 serialization with no LF, logical tape N bits, not 8N serialized storage bits). Use previous CHARGED family: left and right maps permutations of r labels, UNSAT iff equal; exact proper 3CNF compiler and adjacent witnesses in earlier permutation.js. N=Theta(r log r); D=6(r-2)(w+1)-1 monitored middle cuts, h=log2(r!)=Theta(N). Fixed deterministic finite-state one-head read/write tape, with optional exact read-only random access to original input bits. Each remote address is computed by current active side from its local state/tape, with a=ceil(log2 N) bits; returned bit enters finite control or locally recorded state. No free external memory, cross-cut hidden state, arbitrary word operations, or oracle. If allowing B persistent register bits across cuts add B to state communication length. Use uniform distribution on diagonal permutations. C_c=#head crossings of cut c; J_c=#remote reads whose request source and target straddle c; Delta_j=#monitored cuts crossed by remote read j. T_local counts local steps (including crossings); s=ceil(log2 |Q|). Then
 (s+O(1)) E[T_local] + (a+O(1)) E[sum_j Delta_j] >= D h - O(D).
Proof: for each cut, two parties hold corresponding halves of initial tape and immutable original input. Simulate locally while head remains on their side. A crossing transmits state plus fixed tag, a remote read transmits address plus response and tag; termination transmits output. This is a deterministic communication protocol. Every diagonal transcript is distinct: otherwise the rectangle property implies a crossed off-diagonal SAT input is rejected. Terminated binary transcripts can be made prefix-free using fixed tags and fixed-size fields, so average transcript length is >=log2(r!). It is at most (s+O(1)) C_c+(a+O(1)) J_c+O(1). Sum over cuts, use sum C_c<=T_local and sum_c J_c=sum_j Delta_j. Same distribution and same weighted sum, so at least one diagonal achieves it. No arbitrary random-access separation follows. If remote distance at most R and J reads, substitute sum Delta<=RJ. With no remote access and fixed Q, worst-case time Omega(N^2). For input-inclusive physical memory (>=N each step), same execution CM Omega(N^3). For visited tape space only, choose a constant fraction of monitored cuts at locations Omega(N) from start and repeat: each crossing there has already visited Omega(N) cells, giving same worst-case order. No work-space-only CM lower bound claimed. If external persistent B-bit register is present, per crossing s+B+O(1); not single-tape finite control. Free random access may transport enough information without physical head motion; the inequality explicitly loses strength.

Full valid format authentication (including duplicates and permutation distinctness) is separately polynomial via full scan/pairwise comparison; not free. No arbitrary precision or semantic oracle. ## Full costs and limits
For the native bounded projection stage, fixed width and pair caps, O(N) variables and clauses, explicit sorted records, O(log N)-bit identifiers. At most O(N) sweeps with O(N) candidates each and bounded pair count, polynomial discovery and exact replay. A conservative ordinary multitape bit implementation using full scans instead of hash tables and explicit records is polynomial for the capped stages. Single tape can simulate with polynomial overhead; peak and cumulative memory polynomial on the same capped run. Actual host physical allocation/bit steps/CM not measured. No universal bound on complete branching tree or number of restarts. Each import has charged checking and reconstruction. The source-only exact DP stage does not supply a universal integer Phi over all children. First missing implication: an arbitrary residual where all permitted polynomial terminals and bounded elimination fail must have an acquired decreasing contraction or globally amortized branching bound. No evidence here proves this.

Gates: DISJ/equality control PASS for stated communication model, FAIL as unrestricted superpolynomial transfer (random access escape); relativization OPEN for general separation, no nonrelativizing argument; algebrization/Natural Proofs not invoked by scoped communication theorem, no barrier escape; simultaneous DTISP OPEN, fixed time/CM proof only for stated tape model; deterministic configuration counting consistent, not a lower bound on arbitrary deciders. November 26 deterministic replay: transcript function of source does not imply polynomial acquisition, replay time still depends on original computation. No proof of P=NP or P!=NP, no public pvsnp release. Independent review requested; no local checkout/preflight, native SAT reconstruction, industrial solver or Lean replay.
