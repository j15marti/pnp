## Three cooperative exact algorithms
1. Intersection graph G: edge ij iff F_i intersect F_j nontrivially, tested by Gaussian elimination. An index subset has nonempty common intersection only if it is a clique. Compute degeneracy delta by repeatedly deleting a minimum-degree vertex. Enumerate each clique by its first vertex in this order, recursively append later common neighbors, and prune inconsistent equation intersections. Inclusion-exclusion gives union cardinality sum over nonempty index subsets I of (-1)^(|I|+1) 2^(n-rank(A_I)); exact. At most m*2^delta cliques (each earliest vertex has at most delta later neighbors). If maximum multiplicity q is bounded, at most sum_{j<=q} binom(m,j) feasible intersections, and at most m times as many extension tests plus pair acquisition. In particular max multiplicity <=2 can be authenticated by all triples; union size S1-S2 exactly. If S1=2^n, cover iff all pair intersections empty, independently audits old nonparallel four-line example. No assumption that pairwise intersection implies joint intersection.
2. Signed RREF dictionary: start D empty; when inserting F, add coefficient +1 at F and add -c at F intersect G for each old entry (G,c) with nonempty intersection. Merge canonical keys and remove zeros. Pointwise identity new union=old union +1_F - old union*1_F. Count exact by weighted cardinalities. Work poly(N)*(1+sum prefix dictionary sizes), coefficient bits O(m) because each sums signed subsets. Space includes full dictionary; may be exponential. This is NOT a polynomial bound in general.
3. Connected components of intersection graph have pairwise disjoint unions. For each component compute H=affine hull of its union by spanning lifted points (x,1), using one feasible point plus direction basis per flat, then annihilator. If some member equals H, its union size is |H|. If every member has relative codimension one, write F_i=H intersect {a_i x=b_i}; complement inside H is exactly H intersect all opposite equations. Gaussian elimination gives |union|=|H|-|H intersect all opposite equations|. Thus dense overlaps may have a polynomial terminal even when algorithms 1/2 explode. Fall back on algorithm 1 for other components; sum counts across components. For SAT, fix one original coordinate at a time, recompute union count in each candidate fiber, select a fiber with uncovered word; verify final word. Restrictions only delete intersection graph edges; original easy guarded component remains easy on each nonempty restricted subcomponent (relative codim at most one in restricted original hull, hence also in its own hull). No hidden oracle or supplied construction history for explicit matrices. Native physical witness lift uses previous tree/capacity theorem, not a counted multiplicity claim.

## Sparse irredundant infinite family
Seed five lines on 3 bits, integer words 0..7: {0,1},{0,2},{3,4},{3,7},{5,6}. Directions 1,2,7,4,3 distinct. First two overlap only at 0, next two only at 3, last line disjoint. Each has a private point. Refine the last line by Cartesian product with the same five-line seed on a fresh triple; repeat t levels, always continuing only inside the disjoint last line. Result n=3t,m=4t+1, equation count R=4t^2+6t (four codim-2j side flats at j=1..t, one final codim-2t flat). Exact N formula above. Every side flat has a private point; final guard likewise. Removing any flat yields SAT. No rank-one, no parallel pair (different depth -> different codim; same depth -> different directions), S1/2^n=1+(1-4^-t)/3>1. Hence prior parallel/affine-unit/strict union bound closure stalls. Intersection graph exactly 2t isolated K2 components plus one isolated vertex, max multiplicity 2. Exactly 6t+1 nonempty intersections incl singleton flats; S2/2^n=(1-4^-t)/3; S1-S2=2^n. All overlaps paid polynomially; no growing exhaustive kernel. Guarded hyperplane lane handles all components (each pair hull is affine plane times earlier guard/future coordinates).

## Exact tree and DAG proof for the projected full-word CNF
For each flat on actual support of its equations, output one falsified-word clause per word in that support, deduplicate exact clauses. This encoding can be exponentially larger than the affine input. Previous continuation guard has 2^(j-1) prefix words on full 3(j-1) support. At level j the four side lines use respectively 1,1,2,1 clauses per prefix (three axis lines, one non-axis line). Final guard gives 2^t clauses. M=6*2^t-5. Exactly four indispensable side clauses per prefix: one each associated to the private point of each line; the second diagonal clause at shared word 3 is dispensable. All final guard clauses indispensable. Thus indispensable count L*=5*2^t-4. Query first bit of each triple; if bit0=0 query bit2, bit2=0 terminates on {0,2}; otherwise query bit1 (4 side,6 continue). If bit0=1 query bit1, bit1=1 terminates on {3,7}; otherwise query bit2 (1 side,5 continue). Exactly four side leaves and two continuation leaves; repeat in continuation and terminate at final guard. L(t)=4+2L(t-1), L(0)=1. This meets lower bound by indispensable input clauses. Binary resolution refutation DAG needs at least L*-1 inferences by connected fan-in-two graph and L* distinct indispensable premises; tree gives upper L*-1. Depth exactly 3t since final guard private assignments require all its support bits. Therefore exact projected L=5*2^t-4, R_min=L-1, D=3t. This is linear in the expanded CNF clause count, not an unrestricted superpolynomial lower bound in that encoding.
