## 2. New theorem: blind overlapping signed majority quotient with private-majority lift
Definitions: each block B_i is a set of distinct signed physical variables of odd size 5 or 7. Phase z_i is true iff a strict majority of its signed literals is true. For a negative phase literal use the complemented signed block. Let q_i=(|B_i|+1)/2. A positive majority has CNF all q_i-subsets of B_i, since failure means at least q_i false literals. An OR of two phase literals expands by taking all unions of the two local q_i-subsets (distributivity). Assume: (i) physical supports of blocks in any one phase clause are disjoint; (ii) distinct physical block supports intersect in at most one variable and their intersection graph is triangle-free; (iii) each block has at most q_i-2 shared physical variables, so every selected q_i-subset contains at least two private variables, and at least q_i physical variables are private; (iv) every phase occurs with both signs and phase clauses are proper distinct binary clauses, source is the complete expansion without duplicates. Source contains no supplied partition or phase variables. Signs can differ independently in shared occurrences.

Recognition: build exact sorted deletion keys C minus literal l for every clause occurrence; for equal keys add an edge between the deleted signed literals. All within-block signed replacements occur: pick q_i-1 other members, and hold other factor choices fixed. Conversely any two distinct rows differing one literal must originate from the same set of phase blocks and same orientations: deleting a single literal leaves at least one private literal per participating block; such literals cannot be in another block. Within the same phase clause the physical supports are disjoint and quotas fixed, so the replaced literals are from the same oriented block. Thus the signed replacement graph is the union of cliques of the two orientations of each block, with any pair of cliques intersecting in at most one signed vertex. No triangle uses edges from three distinct cliques (would require a triangle in the underlying intersection graph; opposite orientations of the same support are disjoint). A triangle with two edges in one clique and third in a different clique would require two common vertices. Consequently the endpoints of each edge plus their common neighbors are exactly that signed block. Extract all such cliques and pair complements; normalize orientation by the sign of smallest physical ID. Reject if candidate fails size, complement, distinctness or privacy check. This is not a general graph clique search.

Exact check: use private literals in each row to identify participating blocks. Verify disjoint supports in that phase clause, uniform signs, exact q_i quotas and that every source literal is assigned once. Deduplicate exact rows, count multiplicity for each recovered phase clause; it must equal product of binomial(|B_i|,q_i). Since every observed distinct row belongs to the Cartesian expansion and the expansion is injective for disjoint supports, equal cardinality establishes equality. Independent checker regenerates each Cartesian expansion row and compares full set. Thus even if the recognition heuristic errs, acceptance requires exact source equivalence to the recovered phase constraints. Phase quotient is 2-SAT, solve by SCC. NO proof two explicit implication paths, independently check each against quotient clauses. YES lift: choose shared physical bits arbitrarily; set every private physical bit to make its signed literal equal to its block phase. There are at least q_i private bits per block, so all desired phase values are realized simultaneously, regardless of shared-bit signs. Verify each original clause. Guard EMPTY only; arbitrary fixed private bits can destroy capacity, so guarded lift requires a separately checked capacity condition. The recovered phase clause family is exactly satisfiability-equivalent, not a relaxation.

Polynomial bound: fixed admitted sizes 5 and7, binary phase clauses, source explicit CNF of bit length N. Densely renumber occurring variables (or reject oversized sparse header before allocating), use deterministic sorting or balanced exact dictionaries, fixed-size tuple comparisons charged. At most O(N) deletion occurrences for admitted bounded-width source; each deletion key O(N) bits trivially, at most O(N^2) replacement pairs, O(N^3) edge-neighbor intersections by naive scans, at most O(N^2) candidate edges, constant combinatorial quotas. Row validation by scanning all recovered candidates and exact dictionary comparisons, full re-expansion accepted only if product counts equal explicit row count. A conservative O(N^6) bit bound suffices for recognition, checking, SCC and lift (can use straightforward deterministic scans to avoid relying on hash-table worst-case). ## 3. New theorem: basis-tagged direct-sum decomposition of explicit syndrome dictionaries
Given finite explicit dictionaries S_i subset GF(2)^d and target b, pick any offset a_i in S_i, D_i=S_i+a_i, t=b+sum a_i. Choose any maximal independent subset V of all difference columns by deterministic GE. Crucial: maintain elimination tags in the basis of original selected columns, not in transformed pivot rows. If t outside span V, NO. Otherwise represent every difference and t in V-coordinates. Build bipartite graph (block index, selected-column coordinate), edge when any difference in that block uses that coordinate. Its connected components separate every D_i into disjoint coordinate supports, hence the sumset feasibility is exactly the conjunction of component feasibility against target projections. Both directions: any global choice restricts; any independent local choices combine because coordinate subspaces are independent. The graph is exact, not a heuristic support projection. Each component may be solved by exact bounded-state trellis or dictionary joins; a witness records option indices and verifies XOR sum in original coordinates. Components can be ordered consecutively, giving zero rank cut between components. For component coordinate rank <=c log(N+2), explicit state DP at most 2^rank states; total bit work polynomial including basis extraction, tags, graph, all components, exact validation, witness storage and reconstruction. More generally measured state cap yields a sound partial solver returning UNKNOWN before discarding anything. No universal bound on component rank/live-state count.

This class extends the coordinator's rank-cut trellis: dense invertible mixing of syndrome coordinates cannot create intrinsic coupling between independent column subspaces. Proof that the constructed pairing is recovered for any selected-column basis: each selected column belongs to one original direct summand; a global basis must contain a basis of every summand. Thus coordinates of any difference in one summand use only that summand's selected columns.
