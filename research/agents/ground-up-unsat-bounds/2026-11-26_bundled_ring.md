## Exact recurrence
For positive bundle widths r on a path, P(empty)=1 and P(r)=min_i 2^(r_i-1)(P(r_before_i)+P(r_after_i)). This is attainable by first clearing a bundle. Induction proves lower bound for arbitrary interleaving: an optimal split tree for reduced width r_j-1, lifted to original width, increases only leaf weights descending from split j by factor 2, so P(r)<=2P(r-e_j); actual bridges give candidate sum. Ring C(r)=min_i 2^r_i P(cyclic sequence opened at i). Same induction: removing one edge at j either opens the ring or changes a single width, and lifted candidate grows at most 2. For n=2^h>=4 vertices with uniform k, balanced path tree minimizes sum over leaves of (2^(k-1))^depth by Kraft and Jensen (mean depth >= log2 n); P=n^k and C=(2n)^k. Balanced strategy depth k(1+log2 n), optimal by leaf count. Tree-like resolution clause-search equivalence in standard model (no extensions); not a machine lower bound.

## Compression and resources
k=log2 n -> log N=Theta(log n), log L=Theta(log^2 N). Thus exact quasipolynomial tree work despite polynomial shared resolution: eliminate bundles successively, retaining first boundary bundle; intermediate active supports involve at most 3k variables, at most 3^(3k) distinct non-tautological clauses, at most 9^(3k) parent pairs per pivot. O(nk*9^(3k)) inference upper bound, polynomial in N; not exact DAG minimum. Affine route: group clauses by support, check distinct forbidden parity patterns and completeness (count 2^(d-1)), verify each block, then sum charges when every variable appears twice. If not recognized, can use general SAT fallback, not claimed polytime on arbitrary CNF. Gaussian elimination provides exact SAT/UNSAT for recognized complete affine blocks. Single tape conservative construction: store O(N^2) bit matrix, O(N^3) bit operations with O(N^2) scans/access -> O(N^5) plus grouping and verification; safe O(N^6) time, O(N^2) space including input, O(N^8) cumulative memory on same execution. Not optimal bounds. Hidden grouping and charge permutations handled; arbitrary semantic equivalent encodings not guaranteed easy. DISJ: no reduction claimed; relativization/algebrization/Natural Proofs: no unrestricted separation claimed; DTISP: polynomial upper bound on same realization; deterministic configurations: no lower bound asserted. Exact counting kept distinct.
