## A. Threshold phases
For minimally UNSAT non-tautological CNFs F,G (possibly sharing variables), k fresh bits, 1<=t<=k, let a=binom(k,t-1), b=binom(k,t). H consists of C union P for each C in F and positive selector subset P of size k-t+1, and D union -Q for each D in G and selector subset Q of size t. H SAT iff F or G SAT. Removing one guard clause: assign selectors with exactly t-1 ones (or t ones), so only that guard among its type is false, then use a deletion witness of the corresponding base. Thus H MUS. n'=n+k, M=a*mF+b*mG, ell'=a*(ellF+(k-t+1)*mF)+b*(ellG+t*mG). Encoding N=n'+2M+2+ell'*(2+bit_length(n')): unary n',M and unary clause lengths, sign plus fixed-width index per literal.
Exact minimum clause-search leaves L(H)=a L(F)+b L(G). Each leaf determines its phase and covers at most one maximal false selector word or at most one minimal true word. Restriction to each such word gives a base tree with no overlap in surviving leaves. Upper: sequentially query selectors until t ones or k-t+1 zeros; hockey-stick identity gives precisely a false and b true leaves. Arbitrary interleaving cannot improve. Resolution R(H) <= a R(F)+b R(G)+a+b-1 by lifting each base proof with its fixed guard and refuting threshold guards using the selector decision tree. R>=M-1 by MUS, so exact if both bases attain their m-1 minima. Also R>=max(R(F),R(G)) by restriction. Fix some selectors with h ones, u unassigned: threshold shifts to t-h, guards simplify (duplicate/subsumed clauses can be dropped), same exact L identity: a leaf falsifying a remaining clause still requires threshold certificate; boundary restrictions and sequential upper still work even if redundant supersets retained. For t-h<=0 or >u, phase constant and L equals active base.
Balanced t: a+b=Theta(2^k/sqrt(k)), but M already of same order for fixed bases; no superpolynomial work in N. In fact fixed base arity d: enumerate all candidate sets of <=d original variable IDs and thresholds, verify exact guards by grouping and checking distinct supports and binomial counts; no need to guess construction history. On recognized class solve both bases by <=2^(d+1) assignments. For fixed d=2, repeated scans and comparisons on one tape with O(N^2) cells admit conservative O(N^8) time and O(N^10) CM including discovery. Correct on SAT and UNSAT in the recognized class; arbitrary nonmatching inputs require another solver. For compact circuit encoding with explicit free output s, guarded refutation ignoring gate clauses has L<=L(F)+L(G), so the direct CNF exponential in k is not representation invariant.
Executed exact clause DP (min leaves/depth independently), exhaustive single-clause witnesses and SAT neighbors, nine threshold cases, seven reverse restrictions. See separate raw and code if published. F=(x)&(!x), G=(x or y)&(!x or y)&(!y). Both attain m-1 via elementary resolution.

## B. Shared positive AND output compatibility
Given explicit subsets A_i of raw variables and target bits p_i, let U=union of A_i for p_i=1. Feasible iff no p_i=0 has A_i subset U. Necessity forced ones; sufficiency set exactly U to one. Arbitrary overlaps permitted. If gate outputs satisfy a graph of pairwise XOR equalities/inequalities, solve component parities and enumerate at most 2^c phase words (c free components); each check polynomial. An odd cycle is immediately contradictory; c=O(log N) gives aggregate polynomial, not a necessity lower bound. For signed ANDs target-zero gates are arbitrary clauses, so compatibility is NP-complete even at fixed target pattern. Positive ANDs with unpinned affine output pairs can also encode SAT.
## C. Paired monotone lift
For any n-used-variable CNF F, introduce pairs u_i,v_i and clauses (u_i or v_i); for every original C, add purely negative clause OR_{l in C} !w_l, where w_{x_i}=u_i and w_{!x_i}=v_i. No at-most-one constraint necessary. SAT iff F SAT: map a satisfying assignment to complementary falsifier bits; conversely shrink both-true pairs to exactly one, preserving all negative clauses, and decode. For MUS F, removing a negative clause uses its deletion witness; removing a pair allows both bits zero, satisfying all negative clauses involving variable i, and the remaining proper subset is SAT. Thus lift MUS. Exact size 2n vars, m+n clauses, ell+2n literals; N by above encoding. NP-complete even if negative widths <=3, all positive clauses disjoint pairs. Dual-Horn/Horn individually easy but mixed not covered by that argument.
For MUS F, L(F)+n <= L(lift) <= 2L(F)-1. Lower restrict to complementary assignments: replace queries to each pair by single consistent original variable, collapse repeated queries. At least L(F) leaves survive and n necessary pair-clause leaves vanish. Upper simulate each optimal original query by querying u: if 1, choose original x=0; if 0 query v, with v=1 choose x=1, v=0 refute pair. One extra leaf per original internal node, and every original falsified clause now has all corresponding w known true. Five tested bases match. R(F)+n <= R(lift) <= R(F)+sum_i min(pos_i,neg_i). Upper orient pair names to minimize number of literal replacements; resolve each occurrence requiring the alternate falsifier with its pair clause, recover original F, then replay proof. Lower substitute u_i=!x_i,v_i=x_i. Pair sources become tautologies. In trimmed DAG with s tautological derived nodes and c crossing steps (taut premise, non-taut conclusion), each taut node has outgoing edge to one of these; a crossing step has at most one taut premise, so n+s<=2s+c. Under literal identification, crossing steps collapse to other premise or subclause; non-taut steps simulate by resolution or subclause (if pivot absent); two taut parents cannot give non-taut mapped conclusion. Thus >=n steps lost. This lower bound is mathematical, no external shortest-DAG solver run.
Uniform reduction and recognition: pair clauses explicit and disjoint; recover signed CNF by arbitrary orientation of each pair, exact equivalence on both labels. O(N^4) time and O(N^2) space conservative single-tape scans, CM O(N^6) for conversion only, residual solver charged separately. No unrestricted lower bound.
