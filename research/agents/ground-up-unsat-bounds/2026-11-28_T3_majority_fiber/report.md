## New parametric obstruction
Replace every phase variable z_i by M_i=majority(x_i1,...,x_i(2d+1)). A positive occurrence of M_i is the conjunction of all positive (d+1)-subsets; a negative occurrence is analogous negative conjunction. Distribute each phase clause over these CNFs. For fixed d and bounded base width k, expansion at most binom(2d+1,d+1)^k per base row, hence polynomial and equisatisfiable; map both directions by majority and uniform blocks. This works for arbitrary bounded-width CNF, not just the experiment. It preserves NP-completeness for fixed d when base is NP-complete. No claim native proof degree preserved by compiler.

Fiber lemma: for either Boolean phase value, its fiber contains the radius-d Hamming ball centered at the uniform bit word. For any satisfiable collection of complete phase constraints, choose a satisfying phase word; its lifted solution set contains the full-cube Hamming ball of radius d centered at uniform blocks. A square-free degree<=d polynomial over GF2 vanishing there must be zero: translate center to 0, then evaluate points with support S of size<=d, triangular induction on S isolates every coefficient. Thus no nonzero degree<=d consequence can be derived semantically from any satisfiable complete region, irrespective of regional size. Applies also to affine (d>=1). Not a PC lower bound allowing high-degree premises/cancellation; global unsat region does entail 1=0. Any nonconstant function of the phase vector has lifted degree>d: it is constant on one such ball; subtract that constant and apply lemma. If original clauses have width>=2 and distinct variables, expanded width>=2(d+1)>=4, so UP under <=2 pins never takes a first step; complete width-two RUP agenda has no first admission on unchanged lifted encoding. Raw clause failure polynomials have degree>=4; a PC3 lane requiring all lines degree<=3 cannot admit them. Grouped high-degree identities need separate rules. For this family, grouped equality-failure polynomials are z_i+z_j, and each guarded end factor is (1+g)(1+z_first+z_last), g=s or 1+s. The two guarded factors have distinct private quadratic monomials s*z_first. To sum to constant requires both coefficients zero; remaining homogeneous equality forms cannot yield1. Therefore static grouped span contains no 1, and all nonzero nonconstant lifted combinations degree>d. This does not exclude degree-safe cancellation starting with high-degree rows, arbitrary PC, or alternative representations.

Base family two disjoint equality paths of m phase carriers share selector s. End constraints enforce inequality if the respective guard is false, first guard s, second not s. Each path forces equal endpoints; hence first forces s=1, second forces s=0. Change second guard to s gives YES with s=1 and all path bits0. Same ordered unsigned scopes, two phase literal changes repeated across lifted rows (not one raw literal). Every whole equality-link factor and guarded end factor is essential: remove one of 2m factors and the explicit witness in results satisfies all others. Thus every proper collection of whole factors is satisfiable, and all regional low-degree consequences from proper collections simultaneously trivial. This is a stronger obstruction than one hard local scope, but the phase quotient has a cheap terminal. Fractional local single-bit marginals 1/2 are feasible because each nonunit phase clause admits a complementary pair of satisfying words; not a joint occupancy/matching proof or arbitrary LP hierarchy lower bound.

## Blind recovery, exact interface
Pick one source clause containing each physical variable i. For each j not in that row, replace i by j preserving sign and test exact signed-clause dictionary membership. A replacement stays in the same true block: otherwise block quotas (d+1 per used block) violated. Every i has at least d valid replacements within its block. Undirected replacement graph on b=2d+1 vertices per block has minimum degree>=d, so connected (two components would each need >=d+1). Connected components recover exactly the original blocks, without block order, phase constraints, d, or source provenance. Check recovered blocks odd and equally sized, clause quotas and signs, distinct subset combinations and complete Cartesian product counts; any missing product fails. In theorem compute binomial counts by arithmetic, not enumerating nonexistent rows on malformed input; current fixed-d test implementation enumerates local subsets. The quotient is exactly equisatisfiable, lifting by uniform blocks; each valid input has each block represented. O(r^2) replacement dictionary queries plus sorting/indexing and O(L) incidence scan/check, polynomial bit work for explicit source; exact comparison not relying on hashes alone. On this family phase equality closure and two guarded ends refute in linear phase graph work, so all-decider transfer fails. On arbitrary lifted NP-hard base, quotient still NP-hard; no universal UCAC theorem.
