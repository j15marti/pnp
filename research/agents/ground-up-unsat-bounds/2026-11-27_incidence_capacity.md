## Target and exact input model
Previous report 764cef91394b12bd368b7ed2995cfd0fd80e0298 defined defects as locally nonseparable tables plus a minimum cover of disagreements between normalized nonlinear functions on shared blocks. The new dependency is eliminating *all* disagreement-cover work without guessing a common function. Input: four-state physical blocks (two bits), each appearing in at most two distinct vertex constraints, ordered scopes of bounded arity (<=3 for the parameter bound), explicit local forbidden indicator tables T. Allow parallel graph edges, constants and zero-degree constraints. A local table is separable iff T(z)=c XOR sum_j f_j(z_j) over F2, normalized f_j(0)=0. Acquire c=T(0), f_j(t)=T(0,...,t,...,0) XOR c, check every table row. For raw CNF of the families below recover pairs/scope groups and evaluate original clauses; otherwise return unsupported unless an exact partition is authenticated. All SAT and UNSAT labels decided on admitted inputs, no construction-history or promised-NO oracle. Falsifiers: brute mismatches, invalid reconstructed witness, failure on hidden renamings, three-incidence transfer.

## Exact incidence projection and graph criterion
Do not require f_{u,e}=f_{v,e}. For each shared block form its exact binary incidence image R_e={(f_{u,e}(t),f_{v,e}(t)): t in domain}, retaining a preimage for each word. Block independence proves both directions of the reduction to one Boolean incidence bit per endpoint, a parity equation at each vertex, and a binary relation per edge. Single-incidence blocks similarly give pinned or free bits. Empty domains reject. This is decision/witness, not exact counting.

Every nonempty binary relation has one of these forms:
(1) one word: pin both bits, subtract their values from charges;
(2) two words: either pin one bit and leave the other free, or y_u XOR y_v=delta; in the latter case shift the second by delta, subtract charge shift, and join the vertices by a correlated wire;
(3) three words: complement the appropriate incidence bits so the unique missing word is 11, subtract the shifts from charges; the edge is now a resource that may supply one unit to either endpoint or neither;
(4) four words: two independent free incidence bits, each a private resource.
All changes preserve exact realizability, with remembered shifts and preimages.

Contract connected components of correlated wires, taking XOR of their adjusted vertex charges. Any external assignment meeting the aggregate parity lifts inside a component: set non-tree correlated bits arbitrarily and successively satisfy leaves of a spanning tree, with root equation implied. Resource edges may become parallel edges or loops. Let Q be the quotient multigraph of capacity-one edges, with private resources at some vertices. Each odd-charge vertex needs at least one selected incident resource; even vertices need none. Feasibility iff a bipartite matching assigns a distinct resource to each odd vertex. Necessity: from any feasible assignment choose one contributing resource per odd vertex, which are distinct; sufficiency: activate exactly the matched resource at each odd vertex and none at even vertices. Lift through spanning trees and choose physical preimages. This does not require counting, global matching-compatible parity lifts, or uniform endpoint functions.

Stronger exact criterion: UNSAT iff some connected component of Q is a tree (including singleton, counting loops/parallel edges as cycles), every vertex odd, and no private resource. Such component needs q resources but has q-1. Otherwise choose a root with even charge or private resource (spanning-tree resources assigned to all nonroot odd vertices, root uses private resource if odd), or choose a cycle, assign cycle edges cyclically to odd cycle vertices, then assign spanning forest edges to odd off-cycle vertices. Unused resources stay off. This covers all cases. After tables acquired, graph decision and witness construction can be done by a linear number of adjacency-list operations; implementation also independently uses augmenting-path matching to compare with the tree criterion. A negative certificate is a tree component with all odd charges and no private resources, with normalized table/edge authentication and contraction check. No enumeration of disagreement cover necessary.

For a locally nonseparable set A and high-incidence blocks B (>=3 occurrences), let J=B union blocks touching A. Enumerate physical words jointly on J, test exceptional tables, subtract known contributions and apply the same solver to all remaining separable vertices; do not multiply incompatible endpoint choices independently. k=2|J| <= 6|A|+2|B|, T<=poly(N)4^|J|. Acquisition of A,B,J is polynomial and exact; no optimal vertex cover needed. Independent residual components after exact separation allow sum_i 4^|J_i|, not product. The bound is not a lower bound, and no guarantee k=O(log N) for arbitrary inputs.

## Ground-up minimal path obstruction
Take path h>=2 vertices, h-1 two-bit blocks. At left endpoint of every edge f(a,b)=a AND b; right endpoint g(a,b)=a AND NOT b. Use parity charge one at every vertex. Each edge can supply at most one endpoint, so h demands and h-1 resources make UNSAT. All tables separable, every edge is a disagreement. Old d=min vertex cover=floor(h/2); new residual bits zero. Delete any vertex constraint, or flip any charge: orient edges away from that root (towards all other vertices), which satisfies every remaining odd demand. Constraint-minimal, not claimed clause-minimal. Full forbidden-word CNF with n=2(h-1), M=10(h-2)+6, ell=40(h-2)+12 (for h=2 repeated axioms retained); N=n+2M+2+(w+2)ell, w=ceil(log2(n+1)), unary n,m,width fields with fixed-width signed IDs.

Exact L_min=3h-2, R_min=3h-3 (ordinary binary resolution inference count). Upper: query both bits on an end edge. Three states falsify the endpoint table; one satisfies endpoint, contributes zero to the next vertex, leaving a smaller path. Recurrence L<=3+L(h-1), L(1)=1 (one already false zero-arity table). Tree-to-resolution gives R<=L-1. Lower: build h physical assignments in which all edges are used and oriented away from a chosen vertex, so only that vertex fails. Add 2(h-1) assignments with one unused edge (two distinct physical states), all other edges oriented away from its two endpoints, so exactly those endpoints fail. Each of these 3h-2 assignments has a nonempty set of falsified full-word clauses, and the sets for distinct assignments are disjoint: used-edge critical words never contain an unused-edge state, and in each unused-edge case the location and state of the unused incident edge distinguish the local word. For h=2 duplicated clause labels cause no overlap across different assignments. Every refutation tree must have a distinct leaf for each assignment, and every resolution DAG must use a distinct input axiom for each (otherwise some assignment satisfies all used axioms). A connected binary DAG with a single sink and L distinct axioms requires >=L-1 inferences. Both bounds exact. D is at least ceil(log2(3h-2)) and at most 2 ceil(log2 h) via balanced edge queries, not claiming exact D beyond small DP.

## Positive-disagreement exponential-resolution hybrid
Start with simple connected cubic expander on v even vertices; subdivide one edge, attach h new vertices as a path to subdivision vertex. Internal region edges use f at both ends, path/bridge use f on left and g on right. One region vertex charge odd, all other region vertices even, all h path vertices odd. Contracting correlated edges gives an all-odd tree on h+1 quotient vertices. Therefore UNSAT, old disagreement cover floor((h+1)/2), new k=0. Delete any constraint or flip any charge: if path vertex, root the capacity path there and solve even aggregate in the region; if internal vertex, root at region and flip that vertex charge so the connected affine region has even total. Both give explicit witnesses. Constraint minimal only. Full truth-table CNF has n=3v+2+2h, M=28v+10h+29, ell=168v+40h+182. A degree-j singleton-function parity table has (4^j+2^j)/2 forbidden words if odd, (4^j-2^j)/2 if even. Use same N formula. For h=v, N=Theta(v log v), old d=v/2, new k=0. Restrict bridge/path physical states to supply each path vertex and no region vertex, and fix one physical bit to 1 in each internal block. The restricted CNF is exactly odd-charge Tseitin on the once-subdivided expander. Subdivision preserves constant expansion for small sets up to a constant fraction (compare original vertex set and note each cut original edge has >=1 cut subdivided edge). Known Tseitin width Omega(v) and width-size theorem give R>=2^Omega(v); resolution is monotone under restrictions. Exhaustive tree upper 2^O(v) for h=v. Thus both resolution DAG and tree leaf complexity 2^Theta(v)=2^Theta(N/log N), while polynomial decider has zero growing kernel. No unrestricted exponential lower bound.

## Hidden acquisition, uniformity and sharp boundary
Raw CNF full-word groups induce a blowup of the line graph by two-vertex cliques. In the hybrid graph distinct edges are not closed-neighborhood twins: adjacent uv,uw can be twins only if v,w both leaves or both degree2 and joined by vw (otherwise an additional edge distinguishes them). The graph has one leaf and no such degree2 triangle. Nonadjacent edges cannot be twins. Hence recover each block by grouping identical closed neighborhoods, then group clauses by exact recovered block scope (distinct for this graph). Evaluate every original local group on <=64 words. Renaming and bit complement preserve this process. Single-clause deletion leaves each scope present and thus same block graph; at most one nonseparable group then needs <=64 trials. Verify exact source grouping, no arbitrary equivalent CNF promise. Hidden acquisition and single-deletion experiments use a separate decision implementation. General explicitly structured inputs may include twins and need not be recovered from raw CNF.

Sharp scope boundary: with three incidences per four-state block, even if every vertex table is a separable parity of only two blocks, SAT is NP-complete. Reduce positive exact-one-in-three SAT. For each clause use one block whose three incidence outputs have image {100,010,001}, with one duplicated physical preimage. For each variable make an equality copy tree of blocks, each with <=3 ports and image {00...0,11...1}; degree-one and degree-two blocks allowed. Connect variable occurrence ports to clause ports and adjacent copy ports via binary XOR-zero vertex constraints. All vertex tables separable; image support at every block <=4. Correctness in both directions by copy consistency and exact-one clause support; linear-size incidence graph in source occurrences. Membership in NP immediate. Therefore replacing the at-most-two incidence hypothesis by at-most-three is not a universal polynomial theorem unless P=NP. This is not a proof of P!=NP.
