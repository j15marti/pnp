# Affine phase rank and paired nonlinear diamonds
Status: PROVED WITH SCOPE (independent review pending), COMPUTATIONAL (finite DP and matching tests), OPEN (P vs NP).

Source: explicitly encoded loopless cubic Boolean edge-CSP, parallel edges allowed, ordered incident ports, local eight-bit truth tables. The general language is NP-complete by equality fan-out and OR clauses. Both labels decided. Let B be vertices whose even parity lift is not matching-realizable, and P the incidence map extracting parity at B. Obtain all local affine-hull equations by checking the seven possible nonzero binary linear forms per ternary table; assemble Ax=a. If inconsistent reject; otherwise compute x0 and nullspace basis U. The image of the affine solution space under P is Px0+im(PU), rank r. Enumerate its distinct 2^r vectors, pin the bad parity ports, and invoke the previous parity-hub matching construction. Completeness: every genuine solution has one of these phase vectors. Soundness: any matching witnesses the original relations. The affine relaxation need not itself be sufficient. All basis acquisition and matching construction polynomial; streaming enumerator uses polynomial live space. For some common fixed C, time <=N^C*2^r, peak visited cells <=N^C and cumulative memory <=N^(2C)*2^r, including polynomial simulation overhead (choose C sufficiently large). Independent components sum work rather than multiply. No exponential lower bound follows from r.

## Infinite families
Core is NAE3 vs EQ3 on three parallel wires. Insert s serial diamonds on one wire, each two vertices sharing two distinct internal edges, with one external edge each. EQ diamonds both impose equality on all three ports; AND diamonds each impose output (external port) = AND(shared internal bits). Both project exactly to equality of the two external bits, with explicit extension for either equal bit. Each vertex constraint is indispensable: removal of the central EQ or either vertex on any diamond breaks the path between a NAE port and the others, and any differing external values extend across the damaged diamond; removing NAE trivially SAT. This is constraint-minimal, not claimed CNF-clause-minimal. Counts v=2s+2, e=3s+3, b=2s+1. Unary headers v+1,e+1, w=ceil(log2(e+1)) signed-free edge IDs, and 8 truth-table bits per vertex: N=v+e+2+v(3w+8). Direct forbidden-tuple CNF: 12s+8 clauses for EQ family, 8s+8 for AND family. EQ: all variables equal in affine hull, rank r=1. AND: each gate's affine hull is full; only central EQ imposes affine restrictions. With external bits t_0,...,t_s and h_i the parity of the internal bits of diamond i, phase pair is (t_{i-1}+h_i,t_i+h_i). For arbitrary pair phases and arbitrary central EQ phase t_s, solve backwards for t_{i-1} and h_i. Thus r=b exactly. Yet contract each diamond to equality in constant truth-table work, then equality union-find makes NAE impossible. Uniform recognition of diamonds via enumeration of vertex pairs and their two shared edges, no history needed. Both SAT/NO handled by exact contraction; on arbitrary residual UNKNOWN falls through to general solver. Rank full is not intrinsic hardness.
