## 1. Global gluing, not pairwise gluing
Over F2, let W_i be the row space used by component predicate f_i, choose a basis M_i, stack M, let L be its row count, r=rank M, n ambient dimension. h=L-r. Take full-row-rank Q with rows a basis of ker(M^T), partition Q into Q_i. A tuple y of local coordinates is realizable iff Qy=0, because im M = ker Q. Each realizable tuple has exactly 2^(n-r) preimages. Define C_i(s)=sum_{y_i:Q_i y_i=s} f_i(y_i). Starting D_0=delta_0, compute D_i(s)=sum_t D_(i-1)(s+t) C_i(t). #F=2^(n-r) D_k(0). Decision uses Boolean operations instead. This is exact with arbitrary local predicates, not a claim that their projected messages are free. Polynomial Gaussian discovery of h and Q. If h=O(log N) and all local messages are constructible in polynomial time, solve in polynomial time, including discovery, enumeration, verification and bit arithmetic. Direct convolution k*4^h; optional Walsh-Hadamard integer convolution O(k h 2^h) arithmetic ops; intermediate counts have O(L+h) bits per convolution (use inverse transform each step).

Counterexample: x=0,y=0,x+y=1. All 3 pairwise intersections zero and every pair SAT; global dependency charge odd. General k>=3: rows e_1,...,e_(k-1),sum e_i. Distinct rank-one spaces, zero pairwise intersections, every proper row subset independent, h=1, r=k-1. SAT iff XOR charges even; exactly one model in dimension k-1; every proper nonempty cut rank one. Either parity of k and r occurs, opposite by definition. In minimal dependency every coordinate has even incidence degree necessarily; append independent row on new coordinate for odd degree outside it; add unused variables for either nullity parity. Direct sum of such circuits realizes either parity of h, with SAT iff every circuit charge even. Thus no inference from exponential assignment counts or raw connectivity.

## 2. Tree compression in a GLOBAL syndrome space
For any cut A/complement, W_A=sum W_i in A, r_A=dim W_A; L_A=sum local ranks. Define U_A=im Q_A and I_A=U_A intersect U_complement. Rank Q_A = h - (L_complement-r_complement) = L_A-r+r_complement: the kernel of restriction of global dependency row vectors to coordinates A consists exactly of dependencies wholly in complement. Hence dim I_A = rank Q_A+rank Q_complement-h = r_A+r_complement-r. At each tree node retain only partial syndrome sums in I_A; any globally consistent tuple satisfies this necessary condition at every cut. Conversely a root sum zero enforces ALL global dependencies. Combine child messages by XOR convolution, keep only parent I_A; no loss of globally consistent tuples. Disjoint child leaf sets, so multiplication counts distinct local tuples exactly once. Root count times 2^(n-r). With supplied binary tree maximum cut rank w, at most 2^w states per message and 4^w candidate pairs per join; each syndrome length h<=L, membership by Gaussian basis. This improves the direct 2^(3w) join bound without claiming novelty of known coding-theoretic message passing. Local leaves may enumerate 2^(rank M_i) or use a charged certified message constructor; arbitrary large local predicates not magically tractable. Charge decomposition discovery D; fixed-parameter subspace branchwidth discovery from Jeong/Kim/Oum 2021 for constant w; do not extrapolate to logarithmic w without explicit uniform dependence. With N-bit explicit matrices/predicates/tree, polynomial overhead P(N), total T<=D+sum local-message T_i+k*4^w P(N), S<=S_D+max local workspace+ k*2^w P(N) retaining tables, CM<=T*S for same sequential execution; proof checking via deterministic recomputation has same asymptotic T, S and CM. All counts <=2^L and polynomial bit length. No actual physical CM measured. Separate exp-space claims from streaming. No free workers.

## 3. Quotient rank can INCREASE: exact monotonicity criterion
For A,B subspaces, H space of independent certified fixed linear forms (assume consistent affine restriction), restriction of forms is quotient by H. Let s=dim(A intersect B), h_A=dim(H intersect A), h_B likewise, h_AB=dim(H intersect(A+B)), h_I=dim(H intersect A intersect B). Then s'=s+h_AB-h_A-h_B=s-h_I+gamma, where gamma=h_AB-dim((H intersect A)+(H intersect B))>=0. Proof by rank-nullity for each of A,B,A+B. A=span(x),B=span(y), H=span(x+y): s=0 becomes 1, a certified bridge introduces coupling. H=span(x) with A=B=span(x): s=1 becomes 0. Thus arbitrary affine deductions need not decrease width. BUT if H generated by forms individually lying in A or B, H=(H intersect A)+(H intersect B), gamma=0. In particular if H is generated by certified fixed forms each belonging to some original leaf W_i, EVERY cut of a fixed decomposition is nonincreasing simultaneously. Exact identity s'=s-dim(H intersect W_A intersect W_complement). Inconsistent charges reject separately. This is a sufficient condition, not necessary for monotonicity, and does not show enough useful local deductions exist. Global bridge equations must be charged for their possible width increase. Local affine restrictions discoverable by Gaussian elimination for affine leaves; arbitrary semantic fixed-form discovery remains hard. New gate: can nonaffine residuals always yield polynomially discoverable locally supported useful forms OR another paid contraction? No such universal theorem established.
