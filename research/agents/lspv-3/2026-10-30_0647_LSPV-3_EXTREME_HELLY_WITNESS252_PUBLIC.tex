\section{Exact new project-scoped accounting lemma}
\begin{theorem}[PROVED/EXACT; degree-fixed obstruction-witness multiplicity]
For each original variable $x_i$ let $d_i$ be its number of original occurrences in \emph{distinct} clauses of proper CNF $F$. Count each tuple $(i,\{j,k\},M)$ in which that variable alone makes source-clause extreme mode $M\in\{SS,SU,US,UU\}$ impossible. Then
\[
\mathcal W(F)=2\sum_i\binom{d_i}{2}.
\]
It is independent of literal signs and satisfiability. Every proper strict signed exact-$(2+,2-)$-3CNF has $\mathcal W(F)=12n$.
\end{theorem}
\begin{proof}
For two occurrences of the same variable, equal signs forbid exactly $SU,US$; opposite signs forbid exactly $SS,UU$. In either case there are exactly two source-authenticated forbidden modes. Sum over the $\binom{d_i}{2}$ occurrence pairs per original variable. \emph{Multiplicities matter:} several variables can prohibit the same clause-pair mode, so these are not distinct eliminated assignments.
\end{proof}

\begin{theorem}[PROVED/EXACT; 2-Helly completeness for prescribed source extrema]
For any selection $\mathcal T=\{T_j\in\{S_j,U_j\}:j\in J\}$, a globally coherent full assignment realizes all selected extrema iff each pair of selected extrema is compatible. If feasible, precisely $2^{n-u}$ coherent complete assignments realize them, with $u=|\bigcup_{j\in J}\operatorname{var}(C_j)|$.
\end{theorem}
\begin{proof}
Each local extreme is a conjunction of unary equalities on original variables. Any inconsistent conjunction assigns both bits to one variable, and that contradiction appears in two source clauses. Otherwise each of the $u$ used variables receives a unique bit; the remaining $n-u$ are arbitrary.
\end{proof}
\noindent This is a classical 2-Helly subcube observation, not a claimed novel result and not an ordinary SAT algorithm. Ordinary disjunction satisfaction is $t_j\ge1$, not $t_j=3$. In W1, original $C_0=(\neg x_1\lor x_3\lor\neg x_{14})$ and $C_{19}=(\neg x_1\lor x_{13}\lor x_{14})$ share same-sign $x_1$ and opposite-sign $x_{14}$, so every extreme pair mode is impossible, while both \emph{disjunctions} are satisfied at coherent $0^n$. No UNSAT conclusion follows.

\begin{theorem}[PROVED/EXACT; collision correction and sparse representation]
Let $H$ count original clause pairs sharing at least one variable; let $M$ count such pairs sharing both a same-sign and opposite-sign variable; put $h_{jk}=|\operatorname{var}(C_j)\cap\operatorname{var}(C_k)|$. The number of \emph{distinct} forbidden clause-pair modes is
\[
B=2H+2M,\qquad \mathcal W-B=2\!\!\sum_{j<k:h_{jk}>0}\!\!(h_{jk}-1-\mathbf1[\text{both types}]).
\]
An indexed incidence-list scan can construct the sparse nondefault mode representation in $O(N+\sum_i d_i^2)$ word-RAM operations/words. Explicit output of all four modes for every clause pair takes $\Omega(m^2)$ output operations.
\end{theorem}
\begin{proof}
A pair with at least one shared variable prohibits two modes if all shared signs have one agreement type and four modes if both types occur. Aggregate and compare with witness multiplicity. Enumerating pairs of source occurrences per variable and OR-ing their prohibited mode flags constructs all nondefault entries.
\end{proof}
