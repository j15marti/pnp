\section{Source semantics and a fixed clause-order frontier}
Let $F=\bigwedge_{j=1}^m C_j$ be an original proper CNF with $n$ occurring variables, each original occurrence carrying its variable identity and sign. Fix a source-accessed clause permutation $\pi$; no optimum is supplied. Let $P_i$ be variables occurring among $C_{\pi(1)},\ldots,C_{\pi(i)}$ and $Q_i$ those occurring among $C_{\pi(i+1)},\ldots,C_{\pi(m)}$. Define
\[
 B_i=P_i\cap Q_i,\quad B_0=B_m=\varnothing,\qquad
 U_i=B_{i-1}\cup\operatorname{Var}(C_{\pi(i)}),\qquad
 w_\pi=\max_i|U_i|.
\]
Every $B_i\subseteq U_i$ and $B_{i-1}\subseteq U_i$; each variable shared between the old prefix and the new suffix appears in the appropriate cut. A source occurrence is never a distinct variable.

Define Boolean messages $L_i:\{0,1\}^{B_i}\to\{0,1\}$ and $R_i:\{0,1\}^{B_i}\to\{0,1\}$ for the first $i$ and final $m-i$ original clauses, respectively. A message is true exactly when its side has a satisfying assignment extending the given frontier bits. The precise recurrence enumerates assignments $a\in\{0,1\}^{U_i}$:
\[
\begin{split}
 L_0(\varnothing)&=R_m(\varnothing)=1,\\
 L_i(\beta)&=\bigvee_{a|_{B_i}=\beta}
 \Big[L_{i-1}(a|_{B_{i-1}})\land C_{\pi(i)}(a)\Big],\\
 R_{i-1}(\alpha)&=\bigvee_{a|_{B_{i-1}}=\alpha}
 \Big[C_{\pi(i)}(a)\land R_i(a|_{B_i})\Big].
\end{split}
\]

For $j=\pi(i)$ and local pattern $u\in\{0,1\}^{\operatorname{Var}(C_j)}$, define its \emph{global support bit}
\[
 H_{j}(u)=\bigvee_{\substack{a\in\{0,1\}^{U_i}\\a|_{\operatorname{Var}(C_j)}=u}}
 \Big[L_{i-1}(a|_{B_{i-1}})\land C_j(a)\land R_i(a|_{B_i})\Big].
\]
If $H_j(u)=0$, the entire source-coherent cube fixing the variables of $C_j$ to $u$ is forbidden by $F$. If it is one, the two message witnesses join into a global model. A source-literal $\ell$ can be globally supported at value $b$ exactly when one of its containing clause-patterns with $u_{\operatorname{Var}(\ell)}=b$ has support one.

\begin{theorem}[Two-sided support and charged width gate, known DP specialization]
For every proper CNF, every original clause order $\pi$, and every complete source model class, the recurrences above compute $F$'s exact SAT/UNSAT answer and every globally realizable local source-clause pattern. All variable backbones and forbidden corresponding partial cubes follow in the same forward/reverse/join computation. With $\ell$ literal occurrences and maximal clause width $k$, their enumerable-transition implementation uses
\[
 O\!\left(N+D_\pi+\sum_{i=1}^m 2^{|U_i|}(|U_i|+k+\log(m+n+2))\right)
\]
indexed-word operations, and at most
\[
 O\!\left(N+\sum_{i=0}^m 2^{|B_i|} (|B_i|+\log(m+n+2))\right)
\]
\emph{bits} for stored Boolean tables, backpointers and descriptors, with source access and candidate-order discovery $D_\pi$ charged. A table-based UNSAT certificate is verified by replaying these source-indexed recurrences at comparable cost; SAT requires an independently checked original-source witness.
\end{theorem}
\begin{proof}
The first clause has no inherited boundary. By induction, $L_{i-1}(\alpha)$ contains exactly the prefixes satisfying the first $i-1$ clauses with inherited variables fixed. Any variable used in both the processed and unprocessed sides is present in $B_{i-1}$. Thus joining any assignment on $U_i$ to a valid prefix cannot introduce an inconsistent shared variable; all other earlier variables are existential and never used again. Clause $C_{\pi(i)}$ is checked on its original signed variables, and variables leaving the boundary are existentially forgotten. This proves the forward recurrence. The identical argument in reverse proves the suffix recurrence. Each variable shared by a valid prefix and suffix at clause $i$ lies in $U_i$, so the displayed triple join is necessary and sufficient for a complete model extending $u$. A zero triple join therefore forbids the \emph{entire} partial cube, not merely a chosen complete assignment. At each step the finite loop considers at most $2^{|U_i|}$ rows, and every row reads a frontier mask and the original clause, producing the stated work; retaining two table sequences and one backward witness predecessor per state gives the bit bound. Recomputing the tables verifies UNSAT without assuming a short Resolution certificate. Polynomial access to a supplied or discovered logarithmic-width order yields a polynomial algorithm only for that restricted class.
\end{proof}

\section{Same-machine ARC and FLMV audit}
