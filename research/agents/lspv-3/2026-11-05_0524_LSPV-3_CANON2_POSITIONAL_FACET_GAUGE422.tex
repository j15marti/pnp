\section*{IDEA: falsifiable candidate before searching}
The earlier LSPV-3/420 covariance theorem was semantic: complementing conservative auxiliary
wires while consistently changing gates and relations preserves a mixed derivation. A repaired
finite-alphabet checker is now available in LSPV-5 REFEREE361. The new hypothesis was:
\emph{every} accepted CANON2 certificate can be transformed into another accepted certificate
with precisely the same external source, paid-node count, and references by a computable
\emph{positional DEF facet selector permutation}, even if gate inputs alias, a wire appears
through several reconvergent paths, or a RES premise is a tautological gate facet.

Falsifiers were an aliased gate whose transformed positional facet does not match the
signed substituted original facet; an oriented RES step whose declared resolvent changes
under signed coordinate substitution; an affine GF(2) right-hand side that does not commute
with auxiliary complementation; and a huge numerical DIMACS header that forces a dense
variable-index allocation or certificate-size increase. A concrete failure in the repaired
checker would retract, not silently broaden, the claim.

\section*{Fixed typing and new constructive transformation}
Let \(\pi\) be any \emph{accepted} CANON2 proof with external original
CNF source \(F\), input bit length \(N\), explicit certificate bit length \(E\),
\(q\) paid unit-weight nodes, and \(a\) sequential fresh conservative
two-input definitions. Source clause IDs and their literal signs are never
changed. The format permits original-only support-\(\le3\) AND3 and LOCAL
relations, exact GF(2) rows, signed oriented binary RES, and four
\emph{positional} facets per paid DEF. Private internal wires have no free
reference selector. The complete definition of the accepted-byte language
used here is \texttt{experiments/arc/lspv5\_361/rmix341\_canon2\_repair\_referee361.py},
not an inferred historical parser.

Choose an arbitrary gauge \(\delta:\{\text{DEF output variables}\}\to\{0,1\}\),
extended by zero on original variables. For every old assignment \(v\) define
\(v^\delta(x)=v(x)\oplus\delta(x)\). The signed literal transform is
\[
 \tau_\delta(x)=(-1)^{\delta(x)}x,\qquad
 \tau_\delta(-x)=-\tau_\delta(x).
\]
For every paid definition \(z=f(a,b)\) use the four-bit table
\[
 f^\delta(s,t)=f(s\oplus\delta(a),t\oplus\delta(b))
                 \oplus\delta(z).
\]
In the fixed positional facet enumeration \(j=2u+v\), \(u,v\in\{0,1\}\),
replace every reference to facet \(j\) of this paid gate with
\[
 \boxed{j^\delta=2(u\oplus\delta(a))+(v\oplus\delta(b)).}
\]
This is essential even when \(a=b\); positional input rows still have distinct
indices before alias simplification.

Apply \(\tau_\delta\) to every RES output signed-clause literal and every
RES parent relation (the latter is automatic using the transformed node views).
Do \emph{not} delete both pivot polarities from either parent; retain the
REFEREE361 oriented rule exactly. Transform any affine equation by
\[
 \bigoplus_{x\in M}x=r
 \quad\mapsto\quad
 \bigoplus_{x\in M}x^\delta
 =r\oplus\bigoplus_{x\in M}\delta(x).
\]
Only original variables can occur in CANON2's currently exported
AND3/LOCAL/GF(2) annotation masks, so this RHS correction is zero for
those existing records. It is written explicitly to prevent a false
generalization should the native grammar later authorize auxiliary GF(2)
ports. Keep every original-only AND3 truth table and LOCAL condition
unchanged, along with the externally supplied exact source, its source
hash, sequential node IDs, and final reference type. Topological parents,
sharing, and reconvergence remain unchanged.

\begin{lemma}[Authenticated paid-DEF facet permutation]\label{l:facet}
For each fixed original DEF facet numbered \(j=2u+v\), its signed-clause
substitution by \(\tau_\delta\) is \emph{identical}, as a set of signed
literals, to facet \(j^\delta\) of the newly paid table \(f^\delta\).
The identity holds if the two input coordinates alias, when the facet is
a tautology, and when an input is an earlier DEF output.
\end{lemma}
\begin{proof}
The old facet forbids the triple
\(a=u,b=v,z=f(u,v)\). The coordinate bijection maps this triple to
\(a^\delta=u\oplus\delta(a)\),
\(b^\delta=v\oplus\delta(b)\),
\(z^\delta=f(u,v)\oplus\delta(z)\).
The new table forbids precisely this triple in positional row \(j^\delta\).
Its three signed literals are the image of the old three signed literals.
Collapsing repeated signed literals after transformation commutes with
renaming; complementary pairs remain complementary, even for alias inputs.
\end{proof}

\begin{theorem}[CANON2 byte-level gauge compiler]\label{t:compiler}
For every accepted source-exact CANON2 certificate \(\pi\) and every
choice of \(\delta\) on its \(a\) paid fresh variables, the algorithm above
constructs an accepted CANON2 certificate \(\pi^\delta\) against the
\emph{same externally authenticated original source}, with precisely
\[
 \boxed{q(\pi^\delta)=q(\pi),\qquad
 W_{\mathrm{CANON2}}(\pi^\delta)=W_{\mathrm{CANON2}}(\pi).}
\]
The two proof DAGs have identical node and parent topology and exactly
the correspondingly transformed available public facets. An explicit
serializer can be implemented with polynomial bit time in \(N+E\);
under the stated fixed sparse ASCII JSON conventions the output has
\(O(N+E)\) bits. No semantic-equivalence oracle or certificate discovery
procedure is used. The transformation is an involution.
\end{theorem}
\begin{proof}
Induct in paid-node topological order.
Source relations are fixed. Lemma~\ref{l:facet} proves every DEF relation
and selector reference; each new gate is conservative since it is a
renaming of an old uniquely extending gate. For RES,
\(\tau_\delta((A\setminus\{\epsilon p\})\cup
(B\setminus\{-\epsilon p\}))
=(\tau_\delta A\setminus\{\tau_\delta(\epsilon p)\})
\cup(\tau_\delta B\setminus\{\tau_\delta(-\epsilon p)\})\).
Thus the same valid oriented inference is accepted with signed
output and unchanged positive pivot identifier. In CANON2,
AND3 factors and LOCAL conditions are restricted to at most three
original variables; their tables and implications are unchanged.
Each GF(2) XOR commutes with the affine RHS translation because parity
is linear. Hence every typed referenced output remains accepted.
The contradiction terminal has no satisfying assignment, so its
transformed terminal remains a contradiction of the same allowed type.
Source bytes and exact external source comparison are preserved.

The construction edits only already present identifier signs, four
fixed gate truth bits, two-bit facet selectors, and RHS bits, never
changing identifier magnitudes, number of nodes or dependencies.
One topological pass through explicitly stored data, with a sparse
coordinate-to-gauge dictionary, suffices. The serialized size grows by
at most a constant factor: each integer changes only sign, never
magnitude, and no field or table grows. General buffered construction,
source reads, checking, output writing and peak \(O(N+E)\) storage remain
separately charged. Applying the same gauge again restores the old
certificate, proving involutivity.
\end{proof}

\section*{Resource and B3 firewall}
The invariant preserves the \emph{logical paid-node minimum} across
gauge-equivalent proof representations, but it does not lower bound
an arbitrary SAT algorithm. Search for a derivation of minimum \(W_R\)
is free in its definition; actual construction, parsing, source
bit reads, factor checks, XOR writes, proof serialization,
external input comparison and peak memory are not free in a
physical implementation. No native-TM time-space or FLMV assertion
is made from the generated strings.

By Cook--Reckhow, if a polynomial-time correct SAT decider exists,
some polynomially balanced proof system can certify every UNSAT
instance. The outstanding system-specific B3 statement would require
an \emph{independently established polynomial size simulation}
into this same preselected mixed calculus, not merely an uncharged
minimum-proof selector, a rejecting machine trace, or an assumed
correctness axiom. A polynomial-time translation is sufficient but
strictly stronger than the weakest necessary B3 size statement.
The gauge compiler maps \emph{an existing} CANON2 proof to another
existing proof of the same size, so it makes no progress on whether
\(\overline W_{R_{\mathrm{mix341}}}\) is polynomial under SAT in P.
