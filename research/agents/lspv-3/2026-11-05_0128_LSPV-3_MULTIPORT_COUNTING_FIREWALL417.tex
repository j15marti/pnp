\section*{IDEA, four falsifiers}
Hypothesis: multiple externally demanded LOCAL circuit \emph{terms} are polynomially normalizable in their count when each globally depends on no more than three original inputs. Conversely, uncharged high-original-support private terms break any general short-encoding guarantee. F1: some three-input Boolean function needs over five two-input arbitrary gates. F2: repeated/reconvergent gates alter an exported result. F3: free uncounted exports invalidate the port budget. F4: arbitrary high-support free terms can all be encoded using only polynomially many bits. F1/F2 pass constructive and finite controls; F3 is a typing assumption; F4 is disproved by counting.

\section*{Theorem 1: conditional all-port normalizer}
For every source CNF F of encoded bit length N and every sound U3 proof DAG with q paid nodes and b demanded external term/root outputs, there exists an all-port- and all-inference-semantics-preserving representation using at most 5b uncharged internal two-input truth-table gates. Under U3's counted slot contract, b is at most 3q. A sparse explicit encoding of the whole resulting proof costs at most O((N+q+1)^3) bits. The number and source/proof ancestry of paid nodes, all public term truth functions and all globally exact GF(2) types are unchanged.

\textbf{Proof.} For a Boolean port f on inputs (x1,x2,x3), let f0=f(0,x2,x3) and f1=f(1,x2,x3). Then
\[
 f=f_0\oplus\bigl(x_1\wedge(f_0\oplus f_1)\bigr).
\]
The cofactors each use one arbitrary 2-input truth-table gate; XOR, AND, XOR add three. A smaller support pads to three. Replace each named port by its own five-gate representation and preserve the name and ALL-original-assignment semantics. No replacement introduces an original variable outside its declared support. U3's term-only, extensional paid consumers replay legally by topological induction; actual paid DEF records and exact GF(2) annotations are retained. There are at most 2q consumer-term slots and at most q named LOCAL roots. Represent original source indices as sparse decimal/binary labels of O(N) bits, new paid indices in O(log(q+2)) bits, and clauses/GF(2) rows as lists on O(N+q) distinct referenced IDs. A deliberately coarse cubic explicit-bit bound follows.

The theorem is \emph{existence}, not a polynomial search or equivalence procedure. If each old port cone syntactically uses only its declared triple, one can evaluate eight rows with fully charged O(poly(N+E+q)) bit work on an E-bit supplied circuit, including every input read and output. If support is merely promised semantically, discovering it may itself require difficult circuit equivalence checks. One cannot infer a polynomial-time compiler from q alone. All-phase peak memory includes temporary allocations and conversion buffers.

\section*{Theorem 2: conditional high-support free-export obstruction}
Suppose a DIFFERENT permissive completion Ufree permits one otherwise uncharged high-original-support private LOCAL term H to be externally demanded, despite the checked LOCAL root having constant original support. No polynomial p(N+q) bounds the bits of \emph{every all-exported-term-preserving self-contained} normal form in that completion.
\textbf{Proof.} For n original variables take the satisfiable DIMACS source
\[
 F_n=(x_1)\land\bigwedge_{i=2}^{n}(x_1\lor x_i),\qquad N_n=O(n\log(n+2)).
\]
From the two clauses (x1) and (x1 or x2), an AND3 derives x1. LOCAL can assert the unchanged root x1. Under Ufree only, its payload can additionally contain one demanded but unasserted private term H(x2,...,xn), for ANY Boolean function H, at constant paid prefix cost q=2. All 2^{2^{n-1}} functions H are representable by finite, possibly exponentially long, two-input circuits. A fixed uniquely interpreted normalized binary language using at most p(N_n+2) bits represents fewer than 2^{p(N_n+2)+1} functions, which is asymptotically smaller. Hence some demanded H needs superpolynomial bits. Hidden external tables or oracle references require separate charged access/storage. This proves no hardness for the final UNSAT refutation: a compiler could discard the irrelevant port. The free H export is NOT AUTHORIZED by native /341, so this is NOT a legal native counterexample.

For ordinary 2-input Boolean circuits with s gates, the number of n-input functions realizable by at most s gates is at most
\[
(s+1)(n+s)\bigl(16(n+s)^2\bigr)^s.
\]
Choosing s=floor(2^n/(100n)) for n at least 10 yields logarithm smaller than 2^n, proving that some functions need more than s gates even with sharing and reconvergence.
