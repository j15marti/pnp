\section*{Fixed grammar and restricted sharp result}
\noindent $R_{\mathrm{mix341}}$ has free original signed-DIMACS clause axioms; unit charged distinct derived DAG nodes with at most two premises; RES, original-support-at-most-three AND3, binary GF(2) XOR, unary locally checked LOCAL-CONVERT, and globally fresh conservative two-input arbitrary-truth-table DEF. Native serialization of individual DEF facets, LOCAL internal circuit exports and DEF-to-GF(2) equation exports remains underspecified. No invented export rule is used.
\begin{theorem}
For every CNF $F$ on exactly three original Boolean variables, every paid acyclic binary DEF circuit $D$, and every set $P=(p_1,\ldots,p_b)$ of $b\ge1$ distinct named old DEF outputs, there is a conservative fresh network $D'$ of at most $4b$ paid DEF nodes such that
\[
\forall a\in\{0,1\}^3,\qquad P^{D'}(a)=P^D(a).
\]
This assumes no external use of an old private circuit wire or defining facet. The constant four is sharp for $b=1$ (majority).
\end{theorem}
\begin{proof}
For every public $p_i$ its original circuit computes some three-variable truth table. An arbitrary binary truth-table gate basis constructs each such function with at most four gates \cite{Seidler}; our independent paid-operation exhaustive enumeration below also verifies this when all gates, including unary-like identities, are paid. Rebuild each output solely from original inputs using fresh intermediate names and name the last new gate $p_i$. If $p_i$ equals a source variable, insert one paid identity gate to ensure a globally fresh public output. Different public circuits need not reference each other. Acyclic conservative functional definitions give a unique extension for each original source assignment, and the public vectors agree. Sum the gate costs to get $4b$. The exact majority lower bound follows from the complete depth-three finite enumeration.
\end{proof}
