\section{Exact semantics: matched boundary names are indispensable}
Let $Y=(y_1,\ldots,y_b)$ be $b\ge1$ shared original names, and let $F_i(Y,Z_i)$ be ordinary finite CNFs with pairwise disjoint private name sets $Z_i$; no other names are identified. Define the \emph{actual} projection
\[
S_i:=\{y\in\Ftwo^b:\exists z_i\ F_i(y,z_i)=1\}.
\]
One global satisfying assignment exists if and only if
\begin{equation}
\SAT\left(\bigwedge_i F_i\right)\iff \bigcap_i S_i\ne\varnothing. \tag{J}
\end{equation}
The reverse implication pastes private witnesses only after choosing \emph{one identical} $y$ in every $S_i$. No sign-blind signature, incompatible local boundary choices, private-name alias, or unaudited projection claim can replace (J). Arbitrary 3CNF projections need not be cheaply recognizable, even if their true sets happen to be affine.

\begin{theorem}[Rank--exception core interpolation]\label{th:interpolate}
Partition the source modules into $p$ modules whose actual $S_i$ are affine (possibly empty) over $\Ftwo$, and $q$ other modules whose $S_j$ are completely arbitrary. If $\bigcap_i S_i=\varnothing$, the following hold.
\begin{description}
\item[] \textbf{Affine-inconsistent case:} if the intersection $A$ of the $p$ affine projected sets is empty, at most $b+1$ \emph{affine} modules already have empty intersection.
\item[] \textbf{Affine-consistent case:} if $A$ is nonempty and has affine codimension $r$ ($|A|=2^{b-r}$), at most
\[
\boxed{r+\min(q,2^{b-r})}
\]
\emph{whole original source modules} already have empty intersection, comprising at most $r$ affine modules and at most $\min(q,2^{b-r})$ exceptional modules.
\end{description}
Both statements use only the original source-module indices, not derived semantic equality labels. Neither bounds total proof lines, source bytes, acquisition, or peak storage of an arbitrary SAT decider.
\end{theorem}
\begin{proof}
If some affine projected set is empty, one module suffices. Otherwise intersect affine modules in source order, retaining an affine module only when it strictly reduces the current intersection. Before a contradiction each strict reduction lowers affine dimension by at least one. Thus an empty intersection is reached with at most $b$ dimension reductions followed, if necessary, by one final emptying constraint, so at most $b+1$ retained affine modules.
If $A\ne\varnothing$, every strict reduction remains a nonempty affine subspace, so there are at most $r$ retained affine modules. Their intersection \emph{equals} $A$ because every omitted affine projected set contained the current intersection at its processing step, and the current intersection only decreases thereafter. For every $y\in A$, the entire source conjunction is UNSAT, hence some exceptional module $j(y)$ excludes $y$. Retain one such module for each $y$, deduplicating original source indices. At most $|A|=2^{b-r}$ and at most $q$ distinct exceptional indices are retained. Their supports cover every $y$ of the retained affine intersection by exclusion, so the selected whole-module conjunction is UNSAT by (J).
\end{proof}

\begin{theorem}[Sharp rank/exception families]\label{th:sharp}
For every $r\ge0$ and $t\ge2$, set $b=r+t$. There exists a family of $r+2^t$ individually satisfiable boundary modules on $b$ shared variables that is jointly UNSAT and \emph{inclusion-minimal}: removing any single whole module makes the join SAT. Its affine portion has codimension exactly $r$, and all $2^t$ other module projections are nonaffine.
\end{theorem}
\begin{proof}
For $i\le r$ take affine module $y_i=0$. Let $A=\{(0^r,w):w\in\Ftwo^t\}$. For every $w\in\Ftwo^t$ take the exceptional module with boundary support $\Ftwo^b\setminus\{(0^r,w)\}$, equivalently one clause $C_{(0^r,w)}$ forbidding that word. The full intersection is empty. Removing exceptional module $w$ permits precisely the witness $(0^r,w)$. Removing affine pin $i$ permits an assignment with $y_i=1$ and all other pinned bits zero, which avoids all exceptional forbidden words. Each exception excludes exactly one boundary word and has $2^b-1$ models, not a power of two, hence is nonaffine for $b\ge2$. Every individual module is SAT. This meets $r+2^t=r+\min(2^t,2^{b-r})$, proving sharpness.
\end{proof}

\section{Uniformly acquired certificates on a deliberately narrower explicit grammar}
Consider the bounded-boundary \emph{typed, authenticated} subgrammar whose affine modules expose original source-indexed GF(2) rows on $Y$, and whose exceptional modules expose a literal point-exclusion clause $C_w$, with identical $Y$ names. A deterministic source recognizer must verify the grammar; each row and exclusion must be matched to actual source clauses or a complete fixed local CNF gadget derivation. Unit pins are certified by (P); width-$b$ clauses ($b\ge3$) may use the standard private-link proper-3CNF chain, whose existential projection is exactly $C_w$. General XOR rows are represented by audited XOR3 quartets and private parity chains. A \emph{claimed} projection for an arbitrary source module is not accepted as an axiom.

On correctly authenticated inputs, Gaussian elimination of $p$ rows uses $O(pb^2)$ elementary bit operations and $O(b^2+b\log(p+2))$ bits of pivot/source-ID state. If inconsistent, it emits at most $b+1$ original row IDs XORing to $(0,1)$. If consistent, it obtains rank $r$ and parametrizes the $2^{b-r}$ actual affine solutions. For each solution it scans the $q$ source exclusion records for a matching $C_w$; if all points are excluded it outputs a source-indexed covering certificate, with at most $r+\min(q,2^{b-r})$ named modules, plus authenticated row basis data. If a point survives, it is an explicit satisfying boundary assignment, and the typed source is SAT. Per-point scanning costs $O(2^{b-r}qb)$ bit tests plus actual source traversal/addressing; no hashing oracle is free. The streaming certificate contains
\begin{equation}
L_\pi=O\left((r+2^{b-r})(b+\log(N+2))+E_{\rm local}\right) \tag{C}
\end{equation}
physical bits, where $E_{\rm local}$ records the necessary authenticated source-to-row derivations (it may dominate). Malformed certificates, wrong source IDs, mismatched original boundary names, failed derivations, omitted boundary points, SAT inputs, and all timeout branches are rejected. The verifier rechecks all advertised rows and every excluded point, not just a claimed count.

These time and storage statements are for \emph{explicit audited row/exclusion records}, not arbitrary ordinary SAT sources. Recognition and any inverse mapping from original canonical CNF to the typed row grammar is charged separately. A conservative implementation may rescan the full $N$-bit physical clause list for each requested module, giving at most $O(N(pb^2+2^{b-r}qb)\operatorname{polylog}(N+2))$ bit-time in the sequential-head model with $O(b^2+b\log(N+2))$ work bits. With a proved direct uniform locator over fixed-width typed records an indexed-RAM implementation uses $O(N\operatorname{polylog}N+pb^2+2^{b-r}qb\operatorname{polylog}N)$ bit-time; this is a \textbf{CONDITIONAL} more efficient encoding-specific bound, not free random access to a generic CNF projection. Read/parse, unsuccessful searches, certificate assembly, and output are included. In the original single-tape machine total footprint starts at $P_1\ge N$ even if a multitape verifier streams in logarithmic work space.

A standard co-nondeterministic companion requires an \emph{a priori uniform proof-length clock} depending only on $N$ and exact orientation: for UNSAT source at least one guessed certified proof must be accepted by the UNSAT verifier, whereas for SAT source every guessed proof must be rejected. Complementing the latter yields coNTIME recognition only \emph{on the declared typed promise} after all malformed guesses and loops are bounded. Deterministic ARC instead pays construction of the same proof, failures and worst histories. Neither direction yields arbitrary-ordinary-SAT coNTIME here.

\section{Separate physical ledgers and why no near-boundary ARC implication follows}
\begin{description}
\item[] \textbf{M1, one shared read/write input/work tape.} $T_1$ counts literal transitions, $P_1\ge N$ initial source footprint plus all visited/output cells, $H_1$ head moves, $C_1$ physical boundary crossings, $I_1$ inspected original cells, and $L_1$ certificate output bytes/bits. Each source lookup can involve a full $N$-cell traversal. A one-tape crossing-sequence lower bound transfers to no other model without simulation.
\item[] \textbf{Mk, one sequential read-only input and fixed $k$ work tapes.} $T_k$ counts all work including strategy discovery, row arithmetic, failed scans, source authentication and output. $S_k$ includes every visited work cell (including blanks), $H_k,R_k$ count input-head movements/reversals, $C_k$ actual crossings, $Q_k$ work-cell probes, and $L_k$ proof output. Space is \emph{peak simultaneous} work, not a sum of historical modules. No SOURCE-QUERY or HEADMOVE-1 tape lower bound is transported to indexed RAM.
\item[] \textbf{RAT / fixed-width indexed RAM.} Charge address generation, each actual source read, derived child materialization or virtual dereference, exact Gaussian elimination, cache and policy states, guest calls, output and live indexed work. No physical input-head crossing bound applies to the indexed input promise. The earlier DISJ family has an $N^{1+o(1)}$ RAM algorithm and hence gives no superlinear RAM hardness.
\end{description}
For a fixed total uniform deterministic ordinary SAT guest $A$ of time $m^{d+o(1)}$, $d\ge1$, any genuine original-size child calls obey the purely arithmetic inequality
\[
\sum_i m_i^d\le (\max_i m_i)^{d-1}\sum_i m_i.
\]
The mixed-affine module theorem does not establish smaller ordinary SAT guest children, two hereditary levels, bounded $\sum m_i$, or a cheap source-to-projection compiler on \emph{every} UNSAT input. Under hypothetical $P=NP$ the initial SAT time exponent is an unknown finite $K$, not $d=1.802$. Source checks, all leaf sizes, parent/child encoding, simultaneous memory, and both labels remain unbounded for unrestricted instances. Cook--Reckhow's polynomial-proof issue is consistent with these restrictions and cannot be bypassed by granting a free polynomial SAT oracle.
