\section{Declared semantics and computation resources}
Fix a public finite collection $\mathcal L$ of distinct nonempty subsets $S\subseteq[m]$. All coordinate probes $\{i\}$ are available. The physical source stores an unknown $\theta\in\mathbb F_2^m$ and \emph{materialized} data values $p_S=\bigoplus_{i\in S}\theta_i$ for $S\in\mathcal L$ at a public indexed location. Each legal source probe yields exactly one such bit, at positive integer latency $w_S\ge1$; these prices are charged in addition to metadata and machine work. The public target $t\in\mathbb F_2^m$ is announced at continuation, and the answer is $t\cdot\theta\bmod2$. Both answer values must be correct for \emph{all} $\theta$; no answer or satisfying assignment is freely supplied. The menu is \emph{laminar} when any two masks are disjoint or one contains the other. Generality is retained among deterministic, arbitrary adaptive controllers observing the same declared source cells. Controllers can cache, change representation, keep the original raw bits and use unrestricted polynomial workspace. New unpriced measurements of arbitrary parity are \emph{not} legal primitives; computing them from raw bits incurs reads and XOR work.

Let $M=|\mathcal L\cup\{\{i\}:i\in[m]\}|$. The public metadata provides masks in explicit $m$-bit form, costs in binary, and physical addresses. A distinguished root $[m]$ may be added as a synthetic \emph{unavailable} probe. $N$ is the physical input bit length, including metadata, source cells and target; $M,m\le N$. For a polynomial total-work claim assume $w_{\max}\le N^c$ for a stated fixed $c$; otherwise the weights are prices, not a polynomial machine-step promise.

\begin{theorem}[Weighted laminar parity controller, restricted PROVED/EXACT]\label{th:laminar}
There is a deterministic uniform controller that recognizes the laminar family in polynomial time and, when recognized, produces an \emph{exact minimum total source-probe price} plan for the target among \emph{all} correct, deterministic, data-dependent, adaptive controllers using the declared menu. If $T$ is the laminar inclusion tree with singleton leaves, let $w_u=\infty$ for a synthetic unavailable node, and let $t_i$ be the target's $i$th bit. Then the exact optimal price is $D_{\mathrm{root}}(0)$, where
\[
D_i(a)=w_i(a\oplus t_i),\qquad
D_u(a)=\min_{z\in\{0,1\}\, :\, z=0\text{ if }w_u=\infty}
\left\{z w_u+\sum_{v\in\operatorname{child}(u)}D_v(a\oplus z)\right\}.
\]
The policy, its proof-checkable selected mask XOR, and its paid observations can all be reconstructed in $\operatorname{poly}(N)$ time, with no hidden branch-search oracle or restart.
\end{theorem}
\begin{proof}
The laminar intersection test is pairwise explicit, so it takes at most $O(M^2m)$ bit operations. Adjoin all singleton leaves and $[m]$, choose the unique minimal strict superset as each nonroot node's parent, and sort nodes by increasing cardinality. Laminarity ensures the children of every internal node partition its mask. Repeated copies of a probe cannot lower cost: two reads cancel over $\mathbb F_2$ and cost strictly more. Thus each available node is either chosen ($z=1$) or not ($z=0$). Conditional on the parity of all chosen strict ancestors being $a$, picking node $u$ toggles that parity for every leaf of its subtree. The two possible choices are exhaustive; their remaining child optimizations are independent, yielding the displayed recurrence by induction. A traceback selects the unique or tied-optimal choice at each node and the explicit XOR of its masks is exactly $t$.

To rule out adaptive improvements, fix any terminating transcript of any correct deterministic controller on a source $\theta$. Let $V$ be the linear span of masks whose source values have been probed. If $t\notin V$, select $d\in V^\perp$ with $t\cdot d=1$. The source $\theta+d$ yields the identical observed bit at every queried address, hence exactly the same adaptive branch and output, but its correct answer is complemented. Contradiction. Therefore \emph{every successful leaf}, independently of data, has a subset of queried masks XORing to $t$. Its source-probe price is at least the minimum such representation price, which the recurrence attains. The same fixed plan handles both answer labels. Selection of the optimal plan is charged, unlike a freely provided fastest-algorithm selector.
\end{proof}

\section{Certified value, synergy and a complete amortized ledger}
For a state $s$ with authenticated observation span $V(s)$ and known row target $t$, define the \emph{independent of computation time} uncertainty indicator $\Phi_t(s)=\mathbf1[t\notin V(s)]$, which equals conditional target entropy in bits under an explicitly declared uniform prior on $\theta$. For a certified new source datum $I_S$, label it $p_S\mid_{v_{\Phi}}$ with $v_\Phi(I_S\mid s)=\Phi_t(s)-\Phi_t(s+I_S)$; this pipe is contextual score notation and not a conditional probability. Its acquisition and verification fee $C_s(I_S)$ is separate. A score of zero may belong to an essential share.

For $m=4$, $t=1111$, let $S_1=\{1,2\}$ and $S_2=\{3,4\}$. Then $v_\Phi(p_{S_1}\mid\varnothing)=v_\Phi(p_{S_2}\mid\varnothing)=0$ but $v_\Phi(p_{S_2}\mid p_{S_1})=1$. A duplicate read has value zero. If the full mask is a directly materialized action costing $K\ge3$, and each sibling parity costs 1, the positive-singleton-score-over-cost greedy policy picks the full mask for price $K$, while the optimal paid plan costs 2. The ratio $K/2$ has no constant bound when $K$ is part of the model. This greedy falsification was already established in previous reports; the new result is the optimal \emph{non-disjoint weighted laminar} planner.

For a reconstructed plan $J_t$, independently define the \emph{certificate completion rank} $\Psi_t(s)=|J_t\setminus\mathrm{read}(s)|$, not the unknown optimal SAT runtime. Each \emph{distinct planned} observation reduces $\Psi_t$ by exactly 1, so the executed plan telescopes from $|J_t|\le M$ to 0. The controller validates $\bigoplus_{S\in J_t}\mathbf1_S=t$ before paid reads. Its total charged indexed-RAM work is at most
\[
T_{\mathrm{RAM}}\le O(M^2m\,\mathrm{polylog}(N))+\sum_{S\in J_t}w_S+O(Mm),
\qquad W_{\mathrm{peak}}=O(N^2)\ \text{bits conservatively}.

The first term pays all recognition, candidate-menu inspection, ranking/DP, traceback, metadata accesses and rejected nonlaminar attempts; the last term pays source-index calculation, mask XOR checking and final answer reconstruction. Each duplicate, failed exploratory branch or switching step in another implementation must additionally be charged; this controller performs no unbounded speculative restarts. A nonlaminar input is recognized and uses the always-correct raw-bit fallback, at most $m$ raw probes, which is not generally optimal. With $w_{\max}\le N^c$, both the actual worst-case time and simultaneous peak workspace are polynomial. \emph{PROVED/EXACT only for this source-probe task.}

\section{Construction, storage, continuation, and hostile controls}
Here the source construction is independent of the later target. If the parity-view values are already physically supplied, materializing them is not a free \emph{computation performed by the controller}: their physical source length is part of $N$. If only raw $\theta$ is supplied, a preparer can read its $m$ bits and compute all nodes' parity from children in $O(m+M)$ XOR operations, retaining $L=M$ bit values plus public tree metadata. This is a legitimate offline $P=O(m+M)$ indexed-RAM preparation bound, with actual input reads, writes and intermediate bit storage charged; on a general explicit mask menu a direct alternative costs $O(\sum_S|S|)$ XORs. If the original $m$ raw bits stay readable at continuation, $P=L=0$ is legal and a direct query reads $|\operatorname{supp}(t)|$ bits. Neither action is a general lower bound on stored length.

For an explicit two-stage SAT embedding, set
\[
A_\theta(X)=\bigwedge_{i=1}^m(x_i=\theta_i),\qquad
B_{t,z}(X)=[\bigoplus_{i:t_i=1}x_i=z],\qquad
\operatorname{SAT}(A_\theta\land B_{t,z})\iff t\cdot\theta=z.
\]
The boundary $f_{A_\theta}$ is a point function on $X$. If an offline summary must answer \emph{all} future $B_{t,z}$ after original-source access is removed, it needs at least $m$ fixed bits: future coordinate-pin contexts distinguish all $2^m$ possible $\theta$. Storing $\theta$ itself meets this exact bound, with $P=O(m)$, $L=m$, $Q=O(m)$. If access to $A$ is retained, the detached-summary counting proof does not apply. If $A$ and $B$ are jointly visible in the decision computation, one can simply evaluate the parity while scanning $\theta$. None of this requires or implies exponential compilation.
