\section{Authenticated original-clause grammar and exact projection}
Fix a boundary tuple of \emph{identical original names} $Y=(y_1,\ldots,y_b)$, $b\ge3$. For each $w\in\{0,1\}^b$, define the width-$b$ clause
\[
 C_w=\bigvee_{i=1}^b\ell_{w_i}(y_i),\qquad
 \ell_0(y)=y,\quad \ell_1(y)=\neg y.
\]
It is false on precisely the \emph{one} boundary tuple $w$. Encode it by source-original \emph{proper ternary} clauses $E_w$ with private original variable IDs never reused by another word or module. For $b\ge4$, let $z_1,\dots,z_{b-3}$ be fresh and set
\begin{align*}
E_w={}&(\ell_{w_1}(y_1)\vee\ell_{w_2}(y_2)\vee z_1)\\
 &\land\bigwedge_{j=2}^{b-3}(\neg z_{j-1}\vee\ell_{w_{j+1}}(y_{j+1})\vee z_j)\\
 &\land(\neg z_{b-3}\vee\ell_{w_{b-1}}(y_{b-1})\vee\ell_{w_b}(y_b)).
\end{align*}
For $b=3$ use two fresh names $z,u$ and the \emph{source-unique tagged fan}
\begin{equation}
E_w=(\neg z\vee\ell_{w_3}(y_3)\vee u)\land
(\neg z\vee\ell_{w_3}(y_3)\vee\neg u)\land
(\ell_{w_1}(y_1)\vee\ell_{w_2}(y_2)\vee z).\tag{1}
\end{equation}
The extra private variables in (1) ensure that \emph{identical excluded words in different modules still have distinct original clauses}. All clauses are proper and all module-private scopes disjoint; the total source contains no duplicate original clause.

\begin{lemma}[Source-visible exact projection and derivation]\label{lem:projection}
For all $b\ge3$ and $w$, $\exists Z_w\,E_w(Y,Z_w)$ is equivalent to $C_w(Y)$. Moreover $C_w$ has an explicit source-identified Resolution derivation using exactly $\kappa_b$ derived lines, where $\kappa_3=2$ and $\kappa_b=b-3$ for $b\ge4$.
\end{lemma}
\begin{proof}
For $b\ge4$ resolve the first two source clauses on $z_1$, then on $z_2$, etc.; the derived clause extends by one boundary literal per step and the last derived clause is exactly $C_w$. For $b=3$ resolve the first two source clauses on $u$ to $\neg z\vee\ell_{w_3}(y_3)$, then resolve against the third source clause on $z$. Every Resolution inference is sound. Conversely, if $C_w(Y)$ is true, choose the links in the usual sequential OR propagation: if the first two boundary literals are false, set $z_1=1$, then pass that value through every subsequent unsatisfied literal until a true literal lets the chain close. For $b=3$, when the first two literals are false choose $z=1$ and the third boundary literal must be true; otherwise $z=0$ and $u$ is arbitrary. Thus a private extension exists precisely when $C_w$ is true. All private indices are fresh and source-clause offsets can be checked individually against their actual literal signs.\end{proof}

A typed original \emph{module} $M_j$ is a conjunction $\bigwedge_{w\in E_j}E_{j,w}$ of these original encoded chains, with fresh private names even when a word is repeated in another module. The module header and line order are syntactic and source-verifiable, not an oracle-supplied semantic projection. For any selected module set $J$,
\begin{equation}
\SAT\left(\bigwedge_{j\in J}M_j\right)
\iff\exists y\in\{0,1\}^b:\ y\notin\bigcup_{j\in J}E_j.\tag{2}
\end{equation}
The witnesses for different chains may be pasted together \emph{only} after the same original shared tuple $y$ has been chosen; private names never collide. Changing boundary identities, trusting a claimed $E_j$ without reading source clauses, or substituting an output candidate for sound acceptance invalidates (2).

\section{All-UNSAT coverage and exact deterministic acquisition}
Let $c$ be the number of original \emph{point-exclusion chains} in all typed modules, including repetitions, and $N$ the complete physical original-3CNF source length. As each chain has at least two original clauses and each original literal has a positive encoded cost, $c=O(N)$. Set $q=2^b$.

\begin{theorem}[Uniformly sound, fully covered restricted Resolution grammar]\label{th:allcover}
For every syntactically valid input of the declared typed grammar, regardless of its SAT/UNSAT label, there is a deterministic exact recognizer deciding the label in $N^{O(1)}$ bit time. Every UNSAT input possesses a \emph{source-offset-authenticated} Resolution certificate with
\begin{equation}
q\le c\le O(N),\qquad
\underbrace{q\kappa_b+(q-1)}_{\text{derived Resolution lines}}
=O(qb),\qquad
L_{\mathrm{compressed}}=O(qb\log(N+2)),\quad
L_{\mathrm{expanded}}=O(qb^2\log(N+2)).\tag{3}
\end{equation}
Thus $b\le\log_2 O(N)$ whenever the typed source is UNSAT, and both proof encodings are polynomially bounded in the parent physical length. Soundness holds against \emph{every} SAT input, not just within the promise, for a verifier which actually checks each original source clause and every Resolution inference before accepting UNSAT. No finite certificate of the declared form can refute a SAT ordinary CNF.
\end{theorem}
\begin{proof}
An UNSAT typed source has $\bigcup_jE_j=\{0,1\}^b$ by (2); thus for every $w$ select one actual original chain whose $w$ is excluded. There are $q$ distinct words, requiring $c\ge q$. Authenticate the $O(b)$ actual clause offsets for that chain and derive $C_w$ by Lemma~\ref{lem:projection}. Next pair $C_{v0}$ and $C_{v1}$ for each $(b-1)$-bit prefix $v$ and resolve on $y_b$, leaving the width-$(b-1)$ clause which excludes $v$. Repeat on $y_{b-1},\ldots,y_1$. Exactly $q-1$ additional Resolution inferences derive the empty clause. Every step is a source-checked standard Resolution inference; no semantic totality or private projection claim is accepted as a free axiom. There are $q\kappa_b+(q-1)=O(qb)$ derived lines of width $O(b)$, with $O(\log N)$ bits per literal name. The compressed certificate need list only the $q$ source-chain pointer tuples and use the deterministic canonical tree-resolution schedule; the fully expanded proof states each derivation line.

For both input labels, first validate the strictly ordered tagged grammar, source header, all clause IDs and fresh-private numbering. If $q\le c$, enumerate $w=0,1,\ldots,q-1$; otherwise enumerate only $w=0,\ldots,c$. For each candidate perform an explicit sequential source scan to find a source chain excluding that exact $w$. If a candidate is missing, return SAT: its full boundary $y=w$ avoids every original exclusion, and each chain has a satisfiable private extension. Otherwise $q\le c$ and all $q$ candidates are covered, so return UNSAT and print the certificate. If $q>c$, the pigeonhole principle guarantees some missing candidate among $c+1$ values, so this procedure terminates without enumerating $q$ possible tuples. One stored candidate counter of $O(\log N)$ bits suffices: any bits beyond its most significant bit are implicitly zero, even if $b$ itself is large. The source grammar and membership in each chain are always validated against actual clause strings, not an uncharged module-projection lookup. Parsing, reset traversals, all missed searches, source authentication, output generation, and malformed inputs are included.\end{proof}

\paragraph{Clock, polarity and space ledger.}
Let $K=\min(q,c+1)\le c+1=O(N)$ and let $L$ be the emitted certificate bits. One sequential read-only input head with a fixed number of writable work tapes and a physically distinct \emph{write-only output sink} admits the conservative bound $T_{\mathrm{off}}=O(KN\operatorname{polylog}(N+2)+L)$, visited work space $S_{\mathrm{off}}=O(\log^2(N+2))$ bits for counters and a depth-$O(b)$ canonical Resolution cursor on an UNSAT input (where $b=O(\log N)$). On a SAT input, no proof tree is needed and $O(\log N)$ work bits suffice for the missing $w$. If the certificate is stored on a \emph{readable work tape}, its physical length must also be included in peak visited work cells, i.e. $S_{\mathrm{off}}\ge\Omega(L)$ for that implementation. In the one-shared-read/write-tape model M1, initial input consumes $N$ cells and an appended proof consumes $L$ further cells, so $P_1\ge N+L$ for this physical output convention and a simple repeated-scan realization has $T_1=O(K(N+L)\operatorname{polylog}(N+2))$; we make \emph{no} claim that its tape footprint is $O(\log N)$. Input-head crossings, reversals, switches and failed scans are subsumed in the transition counts; $R=O(K)$ and $H=O(KN)$ hold for a streaming print sink. On a unit-cost indexed RAM with a fully charged bitset and authentic source offsets, $O(N\operatorname{polylog}(N+2)+L)$ bit time with $O(N\log N)$ bits of writable pointer/flag storage is available for the \emph{typed} input; this faster bound trades workspace for indexed access and does not imply a sequential-head result.

A co-nondeterministic companion recognizes restricted $\SAT$ by complementing a fixed bounded $\UNSAT$ verifier branchwise: for UNSAT some bounded guessed proof accepts; for SAT every guessed proof rejects; malformed, out-of-range and overtime records reject on the UNSAT-verifier side. A uniform length-only bound $r(N)=O(N\log^3(N+2))$ and polynomial clock exist \emph{for this typed promise}; no deterministic acquisition may be treated as free for ARC. The same family already has an explicit deterministic polynomial recognizer. Neither conclusion supplies an ordinary-SAT coNTIME exponent near the FLMV threshold.
