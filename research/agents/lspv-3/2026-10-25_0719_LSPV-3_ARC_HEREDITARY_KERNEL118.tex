\section{Exact same-source-name semantic joins}
Fix an ordered tuple of ACTUAL source boundary variable identifiers
$Y=(y_1,\ldots,y_k)$ and $B=\{0,1\}^k$. Each prefix $D(Y,U_D)$
and compatible suffix $Q(Y,V)$ is a completely ordinary proper
signed-ternary CNF with disjoint private-name sets $U_D\cap V=\varnothing$.
Unchanged original names carry identical truth values across the two
modules; do not conflate names, detached private witnesses or
unrecorded renamings. Define
\[
 S_D=\{b\in B:\exists u_D\,D(b,u_D)\},\quad
 S_Q=\{b\in B:\exists v\,Q(b,v)\}.
\]
Correct gluing is $\SAT(D\land Q)\iff S_D\cap S_Q\ne\varnothing$.
For a fixed map $h:B\to H$ a proposed quotient instead joins
$h(S_D)\cap h(S_Q)\ne\varnothing$. Let $\mathcal D$ be a
declared family of ACTUAL ordinary prefixes including whatever real
children/grandchildren are claimed eligible, and write
\[
 \sigma_{\mathcal D}(b)=
 \bigl(\mathbf1[b\in S_D]\bigr)_{D\in\mathcal D}.       \tag{1}
\]
This is an extensional feasibility signature, not a promised
cheaply readable machine state.

\begin{theorem}[All-descendant, universal-suffix quotient iff]\label{th:all}
The fixed $h$ preserves both SAT and UNSAT labels for EVERY
$D\in\mathcal D$ and EVERY compatible ordinary proper-3CNF suffix $Q$
if and only if
\[
 h(b)=h(c)\quad\Longrightarrow\quad
 \sigma_{\mathcal D}(b)=\sigma_{\mathcal D}(c)
 \qquad(\forall b,c\in B).                             \tag{2}
\]
Equivalently every $S_D$ must be saturated on all $h$-fibers.
The exact minimal number of reusable fixed quotient labels is
\[
 L_{\min}(\mathcal D)=
       |\{\sigma_{\mathcal D}(b):b\in B\}|.               \tag{3}
\]
The statement is about semantic partitions, not algorithmic
time, counted workspace or syntactic representation size.
\end{theorem}
\begin{proof}
If quotient supports meet, choose $b\in S_D$, $c\in S_Q$ with
$h(b)=h(c)$. By (2), $c\in S_D$, proving true named-boundary
witness compatibility. The converse is immediate, so both
SAT and UNSAT labels are correct. If (2) fails, there are
$b\in S_D$, $c\notin S_D$ with $h(b)=h(c)$.
A compatible suffix with $S_Q=\{c\}$ forces the exact
join UNSAT and the quotient join SAT. Such a suffix
is a fully ordinary proper signed 3CNF: to pin a literal
$\ell$ of one original boundary variable, use fresh
distinct private names $a,b$ in
\[
  \mathrm{PIN}(\ell)=
  \bigwedge_{\epsilon,\zeta\in\{-1,1\}}
     (\ell\vee\epsilon a\vee\zeta b).                  \tag{4}
\]
Its existential projection is exactly $\ell$. A
conjunction of these gadgets pins every boundary name
and retains disjoint private suffix names. Therefore (2)
is necessary. Every valid $h$-fiber is contained in a
single signature fiber, giving the lower label count.
Choosing $h=\sigma_{\mathcal D}$ attains it. This completes
the proof without assuming a representation or evaluator
for the signature.
\end{proof}

\section{Quantified two-level inheritance in ordinary pin trees}
Fix an ordered subset $I=(i_1,\ldots,i_d)$ of distinct original
boundary coordinates, $d\le k$, and root $P(Y,U)$
with support $S=S_P$. For EVERY binary prefix
$\alpha\in\{0,1\}^j$, $0\le j\le d$, generate the
actual ordinary proper-3CNF prefix
\[
 P_{\alpha,j}=
  P\wedge\bigwedge_{r=1}^j
   \mathrm{PIN}(y_{i_r}=\alpha_r).                      \tag{5}
\]
All clauses, headers, original-name maps and fresh private
auxiliary names must be generated and checked at EACH of
two real levels when $d=2$. The family $\mathcal T_I(P)$
contains every root, first child, and subsequent node.
Its exact support is $S\cap
\{b:b|_{I[1..j]}=\alpha\}$. True child-label OR
joins are the standard exact all-input Shannon identity.
The original source names never change.

\begin{corollary}[Sharp fixed interface cost of hereditary pins]
Writing $\pi_I$ for projection onto the pinned coordinates,
\[
 \boxed{L_{\min}(\mathcal T_I(P))=
          |\pi_I(S)|+\mathbf1[S\ne B].}                 \tag{6}
\]
When the root has full boundary support $S=B$, one fixed
quotient needs $2^d$ labels. Its root needs one, its
complete first pin level needs two, and its complete
second pin level needs four.
\end{corollary}
\begin{proof}
Every infeasible $b\notin S$ has the all-zero signature.
Each feasible $b\in S$ has root bit one and occurs in
exactly one depth-$d$ leaf indexed by $\pi_I(b)$.
Thus two feasible boundary words have identical complete
descendant signatures iff their $I$-projections coincide.
An infeasible word, when present, forms one additional
class because its root bit is zero. Theorem~1 now
gives (6). None of these observations supplies a
lower bound on machine steps or makes the family hard.
\end{proof}
