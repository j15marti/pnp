\begin{abstract}
This run attacks the proposed repair that hides a superpolynomial clean-core
code behind random access and charges only the polynomially many coordinates
actually queried.  The repair is exact but gives no intermediate lower-bound
resource.  If one fixed deterministic accessor computes every requested bit
in polynomial time and one fixed deterministic evaluator makes polynomially
many adaptive requests with polynomial local work, literal inlining gives one
uniform polynomial-time decider.  If access is superpolynomial, no polynomial
bridge has been proved; if bits are supplied for free, the model has changed
to an oracle/advice interface.  This strengthens UGENCOMP1 from explicit
per-length generation to input-dependent, exponentially long virtual objects
and adaptive queries.  It does not construct the missing favorable accessor
for arbitrary SAT deciders.  The finite audit made 2,098,198 assertions with
zero failures.  P versus NP remains \OPEN.
\end{abstract}

\section{Claim card and exact quantifiers}
Fix a language $L\subseteq\{0,1\}^*$.  A \emph{uniform lazy-access
realization} consists of two fixed deterministic machines:
\begin{itemize}
\item an accessor $A(x,i)$ returning one bit $c_x[i]$ for every legal binary
address $i$; and
\item an evaluator $E^{c_x}(x)$ whose oracle requests may depend on all prior
answers.
\end{itemize}
All parsing, address formation, saved evaluator state, repeated queries,
accessor calls, caches, and the final one-bit output are charged.  The virtual
length $M(x)$ may be as large as $2^{p(|x|)}$; no complete codeword need be
materialized.

The attacked claim was that such a virtual object could be a weaker
P-versus-NP bridge even when $E$ makes only polynomially many polynomial-cost
accesses.  Its exact repaired form is
\[
\begin{split}
&\exists A,E\;\exists\text{ polynomials }p,q,a\;\forall x:\qquad\\
&E^{c_x}(x)=\mathbf 1_L(x),\quad
T_E^{\rm local}(x)\le p(n),\quad Q_E(x)\le q(n),\\
&|i|\le p(n)\text{ for every query }i,qquad
T_A(x,i)\le a(n+|i|),\qquad n=|x|.
\end{split}\tag{1}
\]
The machines precede all input lengths.  This is uniform, deterministic and
exact; no advice string, semantic oracle, random oracle or uncharged hardware
table is present.

\section{Adaptive lazy-access composition theorem}
\begin{theorem}[LAZY-ACCESS-INLINING1]
Condition (1) holds for a language $L$ if and only if $L\in\Pclass$.
More precisely, the forward direction has one deterministic uniform decider
$D$ satisfying
\[
 T_D(x)\le p(n)+q(n)\,a(n+p(n))+O(q(n)),                 \tag{2}
\]
and, for standard sequential subroutine simulation,
\[
 S_D(x)\le S_E(x)+\max_i S_A(x,i)+p(n)+O(\log q(n)).     \tag{3}
\]
The bound permits arbitrary adaptive query choice and arbitrary finite
virtual length addressable with at most $p(n)$ bits.
\end{theorem}

\begin{proof}
Simulate $E$ step by step.  Whenever $E$ produces address $i$, retain its
current configuration, run the fixed machine $A(x,i)$ to completion, return
that bit, and resume the same configuration.  Induction on the query number
shows that the simulated transcript, all later adaptive addresses and the
final bit are identical to the oracle-style execution.  Summing local work
and at most $q(n)$ accessor calls gives (2); reusing the accessor workspace
sequentially gives (3).  All bounds are polynomial.  Conversely, for any
$D\in\Pclass$, let $E$ run $D$ and make zero queries; choose any constant
accessor.  Thus (1) is equivalent to $L\in\Pclass$.
\end{proof}

\paragraph{SAME\_REALIZATION.}
The saved evaluator configuration and every accessor execution occur in the
single machine $D$.  There is no transfer from a structural object to an
unrelated algorithm, no inference from semantic-state count to runtime, and
no uncharged reconstruction.  Repeated requests are charged repeatedly
unless the same execution builds and charges a cache.

\begin{corollary}[VIRTUAL-CODE-BRIDGE-TRILEMMA1]
For an input-dependent or per-length implicit code, exactly one of the
following applies.
\begin{enumerate}
\item Polynomially many adaptive accesses and polynomial accessor/local cost
inline to an ordinary polynomial decider.
\item Some required query count, accessor, construction or local evaluation
is superpolynomial, so the claimed polynomial bridge is absent.
\item The bits are externally supplied without their generation/access cost,
so the model is oracle/advice/nonuniform rather than ordinary uniform SAT.
\end{enumerate}
Hence \texttt{LAZY-SUPERPOLYNOMIAL-CODE-AS-INTERMEDIATE1} is \RET.
\end{corollary}

\section{What is and is not new}
UGENCOMP1 proved that a fully charged uniform per-length generator followed
by a polynomial evaluator is exactly uniform decision.  STREAMCOMP1 and
VIRTUAL-CHILD-SPACE1 already charge a supplied bit generator inside recursive
composition.  TESTS-0016 proved that a small residual does not itself provide
cheap local access.  The new increment is limited but exact: Theorem 1 removes
whole-code generation entirely, allows $c_x$ to depend on the particular
input, allows exponentially many potential coordinates, and permits adaptive
random access.  Even in that stronger interface, polynomial charged access
inlines.  This report neither renames the earlier composition results nor
constructs a favorable all-input child accessor.

The actual \path{main4.tex} and \path{main5.tex} say that virtual aliases,
streaming, and locally addressable descendants are conditional constructions
and that all-input acquisition remains open.  The theorem here is consistent
with those texts: it closes only the proposed claim that a supplied
polynomial lazy accessor is itself a weaker intermediate.

\section{Representation, hostile-control and one-bit audit}
Horn, affine/Tseitin, 2SAT and bounded-treewidth virtual families may have
very large nominal code spaces while their requested bits remain cheaply
computable.  They therefore demonstrate that large implicit semantic extent
does not force materialization, memory or time.  Padding and redundant clauses
can enlarge the virtual address space without changing the evaluator.  COPY,
DEAD and DELAY alter implementation presentation; INTERP relabels addresses;
RECOMP regenerates requested bits.  The inlining proof survives each wrapper
because it charges the realized accessor calls.  The only required output is
one bit; no witness, compatibility table, branching program, circuit, proof
or codeword must be exposed.

Compact circuits and branching programs fit the theorem when their bit
evaluation and the caller's accesses are polynomial.  A lower bound for the
size of one chosen representation remains a representation lower bound until
an arbitrary-algorithm acquisition theorem forces that representation in the
same execution.

\section{Relativization, algebrization, Natural Proofs and nonuniformity}
The proof relativizes when $A$ and $E$ share an oracle: their oracle calls can
be preserved under composition.  It also survives algebraic access when each
algebraic subroutine is charged.  It therefore supplies no nonrelativizing or
nonalgebrizing hinge.  No largeness/constructivity property of Boolean
functions is used, so the Natural Proofs barrier is not crossed.  A separate
access table $c_n$ for each length, supplied without one uniform constructor
or accessor, is advice/nonuniformity; treating it as a uniform SAT algorithm
would silently change the quantifiers.  Arbitrary polynomial exponents are
retained: if local, query and access exponents are fixed constants depending
on the fixed machines, (2) is polynomial but need not enter any unconditional
forbidden regime.

\section{Post-quantum technique ledger}
\begin{itemize}
\item Schur squares, quadratic-relation ranks, Hilbert functions, syzygies and
graded Betti numbers are \textbf{FAILED TRANSFERS} here: they may distinguish
a fixed code, but no theorem forces an arbitrary one-bit decider to acquire
or query that code.
\item Collision entropy is an \textbf{EXACT OBJECT/THEOREM TRANSFER} for a
fixed accessor map.  The Cauchy--Schwarz image bound remains correct, but a
lossy or injective map does not lower-bound the time of the inlined decider.
\item Worst-case/average-case black-box extraction is an
\textbf{ANALOGY/CANDIDATE needing a new bridge}.  It would need to extract a
source-matched virtual object from every SAT solver while charging all calls;
known NP worst-case/average-case barriers must then be audited.
\item Collision extraction/special soundness is a \textbf{FAILED TRANSFER}
for one deterministic transcript.  A second conflicting opening is not
created by adaptive reads of one fixed code.
\item Hash/random-oracle access is a \textbf{FAILED TRANSFER} if treated as
free.  With a charged uniform hash it inlines; with a random oracle the model
has changed.  Hidden algebraic structure may make access easier, not harder.
\end{itemize}

\section{STALE OR OVERSTATED CLAIMS FOUND}
Any claim that ``the virtual code has exponentially many coordinates, so the
solver must pay exponential cost'' is overstated: unqueried coordinates are
irrelevant when queried bits are uniformly cheap.  Conversely, any claim
that local decoding makes the encoder/codeword free is also overstated.  The
current root and manuscripts mostly preserve these distinctions; no verified
root theorem required downgrading beyond making the adaptive inlining guard
explicit.

\section{Precise synthesis handoff}
The smallest surviving repair is not another representation.  It is an
external, solver-independent relation with a proved compiler
\[
\forall D\in\mathrm{Dec}_{\rm poly}(\SAT)\;\exists x:
D(x)\text{ in the same execution incurs a charged event }R(D,x),
\]
where $R$ is invariant under DEAD/COPY/DELAY/INTERP/RECOMP, cannot be answered
by a polynomial uniform accessor, and the fully charged composed machine
lands in one model-matched unconditional lower bound.  The relation,
compiler, forbidden endpoint and nonrelativizing/nonalgebrizing hinge are all
\OPEN.  One open load-bearing arrow suffices: P versus NP remains open.
