\section{Exact projected-boundary theorem}
Let $F=E\wedge B$ be an explicitly encoded conjunction of GF$(2)$
affine equations $E$ and arbitrary width-at-most-two CNF $B$
(units permitted), encoded length $N$. Form the components
$C_1,\ldots,C_g$ of the incidence hypergraph of $E$, making each
$E$-free variable a singleton. Detect affine inconsistency by
charged elimination. In a consistent component write
\[
x|_{C_i}=a_i+L_i z_i,\qquad z_i\in\mathbb F_2^{d_i}. \tag{2}
\]
Let $P_i$ include \emph{every} variable in $C_i$ occurring in $B$,
including within-component clauses. Set
\[
t_i=\operatorname{rank}_{\mathbb F_2}(\pi_{P_i}L_i),
\qquad t=\max_i t_i. \tag{3}
\]
Let $H$ connect different components exactly when a binary clause
of $B$ meets both. These measures are independent of runtime; a
solver may use them only after paid recognition.

\begin{theorem}[BOUNDARY-RANK-SWITCH80, PROVED/EXACT restricted]
If $H$ is a forest, a uniform deterministic exact algorithm decides
$F$ and produces and verifies one source assignment on SAT, using
\[
T(F),S_{\rm peak}(F)\le\operatorname{poly}(N)2^{2t}. \tag{4}
\]
After polynomial normalization, the number of enumerated local
signature states and binary compatibility entries is at most
\[
\sum_i2^{t_i}+\sum_{ij\in E(H)}2^{t_i+t_j}. \tag{5}
\]
For $t=O(\log N)$, the entire procedure is polynomial even when all
$d_i$ and the sum of affine nullities grow rapidly.
A total exact solver can use this method after its sound recognizer
accepts and use exhaustive exact fallback on unsupported inputs.
\end{theorem}
\begin{proof}
Gaussian-eliminate $E_i$ to obtain (2). Let
$M_i=\pi_{P_i}L_i$. Pick a set $J_i$ of $t_i$ linearly
independent columns spanning $\operatorname{im}M_i$, by paid
column elimination. Every feasible boundary value has exactly
one representation
\[
y_i=\pi_{P_i}a_i+\sum_{j\in J_i}u_{ij}M_i^{(j)},
\qquad u_i\in\mathbb F_2^{t_i}. \tag{6}
\]
A constructive valid lift is
$x|_{C_i}=a_i+\sum_{j\in J_i}u_{ij}L_i^{(j)}$.
All unused free coordinates are set to zero. This is a \emph{single}
lift per boundary value, not a complete model representation.
Every literal in $B$ depends only on $y_i$ for its component.
Build $U_i(u_i)$ by checking all internal $B$ clauses, and
$R_{ij}(u_i,u_j)$ by checking all crossing clauses. Therefore
\[
F\in{\rm SAT}\iff\exists(u_i)\,
\bigwedge_i U_i(u_i)\wedge
\bigwedge_{ij\in E(H)}R_{ij}(u_i,u_j). \tag{7}
\]
The exact forest message from child $i$ to parent $j$ is
\[
Q_{i\to j}(u_j)=\bigvee_{u_i}
[U_i(u_i)\wedge R_{ij}(u_i,u_j)\wedge
\bigwedge_{c\text{ child of }i}Q_{c\to i}(u_i)]. \tag{8}
\]
Induction on subtree size proves exactness. Recover compatible
root and child signatures, lift by (6), then replay every
original source constraint. UNSAT needs no mandatory Resolution
or full DNNF output. All input reads, Gaussian rows, matrix
factorizations, failed recognitions, lookup indices, tables, messages,
source replay, witness bytes, and peak live data are charged;
their cost is polynomial in $N$ times (5). If $H$ is cyclic
the recognizer declines, and no restricted polynomial assertion applies.
\end{proof}

\section{Matched high-nullity path and explicit proper-3CNF transport}
For $q,h\ge2$, block $i$ has free input variables
$a_{i,1},\ldots,a_{i,h}$ and functional prefix variables
$p_{i,1},\ldots,p_{i,h-1}$. Encode
\[
p_{i,1}=a_{i,1}\oplus a_{i,2},\qquad
p_{i,j}=p_{i,j-1}\oplus a_{i,j+1}\quad(2\le j<h) \tag{9}
\]
with four proper ternary clauses per XOR3.
Write $s_i=p_{i,h-1}$, enforce $s_{i+1}=s_i\oplus\eta_i$
by a pair of binary clauses, and add units $s_1=1,s_q=b$.
Then
\[
{\rm SAT}(F_{q,h,\eta,b})\iff
b=1\oplus\bigoplus_{i=1}^{q-1}\eta_i. \tag{10}
\]
Every SAT member has exactly $2^{q(h-1)}$ source assignments;
all prefix variables are functional. Each affine component is
connected and has $d_i=h$ but $P_i=\{s_i\}$ and $t_i=1$.
The binary interaction graph is a connected path, so (4)
is polynomial while the earlier $2^{2h}$ upper estimate may be
exponentially pessimistic.

Exact mixed counts are
\[
n=q(2h-1),\quad m_3=4q(h-1),\quad m_2=2(q-1),\quad
m_1=2,\quad m=4qh-2q. \tag{11}
\]
Replace each binary $(a\vee b)$ by
$(a\vee b\vee t)\wedge(a\vee b\vee\neg t)$
with a fresh variable, and each unit $\ell$ by
the four $(\ell\vee\pm u\vee\pm v)$ with fresh $u,v$.
These gadgets preserve the SAT label under existential extension,
with every added variable and clause charged. The proper-3CNF has
\[
n'=q(2h+1)+2,\quad m'=4qh+4,\quad
N'=(16qh+18)\left\lceil
\log_2(64(q(6h+1)+7))\right\rceil. \tag{12}
\]
On $b=0,\eta=0^{q-1}$ the canonical target is UNSAT.
Flipping any single $\eta_i$ gives SAT with identical unsigned
supports, metadata and length, modifying only a disjoint
signed-record group. Hence every deterministic exact addressed-word
decider for full proper-3CNF must read at least $q-1$ different
orientation groups on the UNSAT target. This is an exact
\emph{input acquisition} lower bound, matched by polynomial source
recognition; with $h=q$ it is only
$\Omega(\sqrt{N'/\log N'})$, not superlinear.
