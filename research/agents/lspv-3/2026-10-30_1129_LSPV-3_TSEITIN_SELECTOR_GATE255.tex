\section{Connected cubic Tseitin source and exact theorem}
Let $G=(V,E)$ be connected, simple and cubic with $v=|V|$ even and $e=|E|=3v/2$. Give each edge $q$ a variable $x_q$. At each vertex $t$, the three incident edge variables satisfy $x_{e_1(t)}\oplus x_{e_2(t)}\oplus x_{e_3(t)}=b_t$, with $b_t\in\{0,1\}$. Encode this equation by all four proper source clauses $C_{t,a}$ forbidding assignments $a\in\{0,1\}^3$ of parity $\bigoplus a\ne b_t$. If $a_j=0$, the $j$th literal of $C_{t,a}$ is positive; if $a_j=1$ it is negative. The resulting connected 3CNF $F(G,b)$ has $n=e$ variables, $m=4v$ clauses and \emph{four positive and four negative occurrences per variable}. It is NOT original signed exact-$(2+,2-)$.

\begin{theorem}[Both-label consistency and local-source obstruction]
For every $G,b$ as above, $F(G,b)$ is satisfiable if and only if $\bigoplus_{t\in V}b_t=0$. When satisfiable it has exactly $2^{e-v+1}$ assignments. Every conjunction of a proper subset $S\subsetneq V$ of complete four-clause vertex blocks is satisfiable for \emph{every} charge vector $b$. Moreover,
\[
F(G,b)\text{ SAT}\quad\Longleftrightarrow\quad N_0(0^e)\equiv0\pmod2,
\]
provided the original source is first verified to belong to this cubic-Tseitin grammar.
\end{theorem}
\begin{proof}
The four clauses of one block exclude exactly the four parity-incorrect triples. Their conjunction is its one XOR equation. Let $M$ be the $v\times e$ vertex-edge incidence matrix over $\mathbb F_2$. Any linear dependence among its rows is the indicator of a vertex subset with no boundary edges. Connectivity makes the only nonzero dependence the all-ones vector. Thus $\operatorname{rank}M=v-1$, and any \emph{proper} subset of the rows is linearly independent. Therefore $Mx=b$ is soluble if and only if $\mathbf1^Tb=0$; its solution space then has dimension $e-v+1$. Every proper row submatrix has full row rank and so admits every restricted charge vector. Finally, at $0^e$, a block has exactly one false all-positive source clause precisely when $b_t=1$; for $b_t=0$ it has none. Therefore $N_0(0^e)=\sum_t b_t$, proving the endpoint rule. This endpoint rule is not valid for arbitrary 3CNF.
\end{proof}
A constructive SAT witness sets all nontree edges zero, then solves each parent-edge variable in reverse spanning-tree order to satisfy its nonroot vertex equation; the root equation follows from total even charge. In the UNSAT case XOR of all authenticated vertex equations gives $0=1$. This is a linear-size original-source certificate after verifying each four-clause block. The procedure receives no answer-class bit.

\begin{theorem}[Per-block source-acquisition lower bound, canonical promise only]
Fix a known connected cubic $G$ and a canonical fixed-width encoding storing all four signed clauses of vertex $t$ contiguously, with only the charge $b_t$ varying in that block. Every deterministic exact bit-probe promise decider, on \emph{every} $b$, must read a bit distinguishing the two possible encodings in \emph{every} one of the $v$ vertex blocks. Thus the worst-case and per-input read count is at least $v=\Omega(N/\log N)$ when $N=\Theta(v\log v)$.
\end{theorem}
\begin{proof}
If an execution reads no charge-dependent position in some block $t$, flip $b_t$ and retain every other block. The deterministic input-read transcript, including the entire control path and answer, stays unchanged, whereas the previous theorem toggles SAT versus UNSAT. Contradiction, for every $b$ and every $t$. A single designated sign bit in each canonical block suffices, so the input-probe bound is tight.
\end{proof}
