\section*{Two source-indexed signed families}
Fix any integer h>=2, original variables x\_0,...,x\_h and a sole interface bit b=x\_h. Put \(D=\neg x_h\) and
\[
 L_h^A=(x_0)\land\bigwedge_{i=1}^{h}(\neg x_{i-1}\vee x_i),\qquad
 L_h^B=(x_h)\land\bigwedge_{i=0}^{h-1}(\neg x_i\vee x_{(i+1)\bmod h}),
\]
and A\_h=L\_h^A\land D, B\_h=L\_h^B\land D. The projection at the cut is \(\mathcal I(L;b)=\{a(b):\exists a(x_0,...,x_{h-1})\ L(a)=1\}\).
\begin{theorem}
For every h>=2, both left interfaces have exactly the same feasible boundary image and satisfy the same downstream queries:
\[
 \mathcal I(L_h^A;b)=\mathcal I(L_h^B;b)=\{1\},
 \qquad \forall Q:\{0,1\}\to\{0,1\},\quad
 \mathrm{SAT}(L_h^A\land Q(b))\iff\mathrm{SAT}(L_h^B\land Q(b)).
\]
Both full formulas are UNSAT Horn 2-CNF with h+1 appearing variables, h+2 source clauses (two unit, h binary), 2h+2 signed literal occurrences, exactly one positive and one negative occurrence of \emph{each} variable, and exactly equal canonical ASCII DIMACS byte lengths N\_h=Theta(h log(h+2)). \[
 \boxed{W_{R_{\mathrm{mix341}}}(A_h)=h+1,\qquad W_{R_{\mathrm{mix341}}}(B_h)=1.}

\end{theorem}
\begin{proof}
The chain's positive initial unit and implications force all x\_i=1. The cycle admits all-zero or all-one internal assignments while its separate unit forces b=1. Thus both projected images equal the singleton \{1\}; every downstream query Q(b) has the same SAT response. The negative unit D contradicts the left in both cases.

For A\_h, deleting x\_0 admits the all-zero assignment, and deleting D admits all ones. Deleting the i-th binary link admits the step assignment x\_0=...=x\_{i-1}=1 and x\_i=...=x\_h=0. The same witness satisfies the formula if either one sign of that link is reversed; the old false literal becomes true. Likewise either unit sign reversal admits the corresponding all-zero/all-one assignment. Therefore every original source is indispensable, with each polarity independently pivotal.

In B\_h the unit x\_h resolves directly with D in one step and zero is impossible because no source is empty. These are exact global minima, not finite-search optima.

Both have identical numbers of unit and binary clauses. For each named variable one positive and one negative signed token occur in \emph{both}, so the total ASCII digit, sign, space, clause terminator and header counts are equal, including at decimal digit changes. The encoded strings need not be identical.
\end{proof}
