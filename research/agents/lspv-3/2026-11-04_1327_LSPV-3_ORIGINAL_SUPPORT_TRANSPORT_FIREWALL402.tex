\paragraph{Exact preselected calculus.} Original DIMACS source clauses cost zero; each strict RES, AND3, XOR, LOCAL-CONVERT and conservative signed two-input DEF node costs one; distinct DAG nodes count once. AND3 is permitted for two conditions only when their combined support uses at most THREE ORIGINAL input variables and returns the exact conjunction factor. Gate definitions exposed as free original clauses in the input evaluator become paid DEF facets in the source-retracted proof. The variable-origin distinction must not be silently erased.

\begin{theorem}[Failure of unchanged typed replay]
There are an UNSAT source CNF F, its explicit private OR/AND evaluator T(F), and a valid four-node mixed refutation of T(F) containing an AND3 inference that cannot be copied identically as a legal AND3 node when evaluator source gate names become paid conservative gate outputs over the original variables of F.
\end{theorem}
\begin{proof}
Let F=(x_1)\wedge(x_2)\wedge(x_3)\wedge(x_4)\wedge(\neg x_4). Define four conservative signed AND2 gates
\[
g_1=x_1\land x_2,\quad
g_2=g_1\land x_3,\quad
p=g_2\land x_4,\quad
r=p\land\neg x_4.
\]
The evaluator source T(F) consists of all 12 defining clauses and the original positive source unit (r), using gate names as ORIGINAL evaluator input variables. The following three strict binary RES steps are valid:
\[
\begin{array}{rl}
(r),(\neg r\lor p)&\vdash(p),\\
(r),(\neg r\lor\neg x_4)&\vdash(\neg x_4),\\
(\neg x_4),(\neg p\lor x_4)&\vdash(\neg p).
\end{array}
\]
One AND3 step combines (p) and (\neg p) to derive the constantly false eight-row factor. In T(F), the combined conditions involve only the single original evaluator variable p, so AND3 is legal. Under REFEREE341 source replay, p is a paid DEF output computing x_1x_2x_3x_4. This function depends essentially on all four original source variables: flip any one all-ones input bit and p changes. Therefore the identical AND3 step no longer meets the <=3 original-variable support precondition. The changed provenance, not Boolean soundness, defeats type preservation.

Ordinary strict RES on (p),(\neg p) proves the empty clause in one node, so this particular bad copy is repairable. The example disproves only the universal literal-copy argument, not every possible polynomial charged proof translation.
\end{proof}
