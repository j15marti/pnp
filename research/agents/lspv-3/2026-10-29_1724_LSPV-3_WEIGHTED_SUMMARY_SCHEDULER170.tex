\section{BUILD I: optimal weighted explicit-table schedule}
Fix a read-only, authenticated CNF source of length $N$ with an explicitly supplied verified binary decomposition tree $T$. Each clause has exactly one owner; bag intersections satisfy running intersection; all local bags are explicitly enumerated. The exact subtree message on the \emph{complete} parent separator of node $t$ contains $s_t=2^{|S_t|}$ Boolean entries (at the root one may retain a designated exposed interface). During a subtree computation, its completed child table cannot be overwritten until the parent join, and an entire child subtree must be evaluated contiguously without recomputation. At a join all child output tables remain live and an independently allocated parent output plus any order-independent scratch of $j_t=s_t+K_t$ bits is required. We count \emph{explicit logical table bits}, not Python object sizes, and later add index, input, work, and certificate costs separately.

Let $M_t$ be the minimum peak number of live table/join bits during evaluation of subtree $t$, \emph{including its final $s_t$ output bits}. A leaf with zero extra scratch has $M_t=s_t$; for a unary child $a$,
\[M_t=\max\{M_a,\ s_a+s_t+K_t\}.\]
For two children $a,b$ the two feasible peaks are
\begin{align}
 P_{a\rightarrow b}&=\max\{M_a,\ s_a+M_b,\ s_a+s_b+s_t+K_t\},\\
 P_{b\rightarrow a}&=\max\{M_b,\ s_b+M_a,\ s_a+s_b+s_t+K_t\}.
\end{align}
\begin{theorem}[Weighted whole-subtree ordering]
Under exactly this execution model, recursively evaluate child $a$ before child $b$ iff $M_a-s_a\ge M_b-s_b$ (ties arbitrary). This minimizes peak \emph{explicit-table and join-buffer bits} among all uninterrupted whole-subtree evaluation orders with no recomputation.
\end{theorem}
\begin{proof}
Assume $d_a=M_a-s_a\ge d_b=M_b-s_b$. Because $M_b=s_b+d_b$, both the first and second terms of $P_{a\to b}$ are at most $s_a+s_b+d_a=s_b+M_a\le P_{b\to a}$. The third term is order independent and appears in $P_{b\to a}$. Hence $P_{a\to b}\le P_{b\to a}$. The same argument applied inductively to every child proves global optimality for the specified subtree-contiguous schedule class. No claim is made for arbitrary interleaving, compression, spilling, shared DAGs, or recomputation.
\end{proof}
The $M_t$ and $s_t$ are computable in postorder using $O(m)$ arithmetic operations on $O(\log(mB))$-bit integers, with a standard metadata upper bound $O(m\log(mB))$ bits. Storing all source constraints in RAM adds $O(N)$ bits, or use explicit read-only input with charged indexed accesses. Recognition/discovery of a useful tree on arbitrary SAT is \emph{not} included for free.

\section{BUILD II: infinite counterfamily and its first crossing}
Fix $B=2^w\ge2$. Define $T_0$ to be a leaf whose output table contains 2 bits. For $h\ge1$, define $T_h$ with 2-bit output, two children, and order-independent join allocation of the parent 2-bit output. Its \emph{left} child is a unary chain $L_h$ of size $|T_{h-1}|$ whose root output has $B$ bits and whose other nodes output 2 bits. The right child is $T_{h-1}$. Consequently both children have identical \emph{node count}, and a node-count heavy-first algorithm breaking ties to the left selects $L_h$ first. The family has
\[m_h=|T_h|=2^{h+1}-1.\]
For $h\ge2$, the unary chain has $M(L_h)=B+2$ (when its length is 1, $M(L_1)=B$). Direct substitution into the proved peak recurrence gives, for every $h\ge1$,
\[\boxed{M_{\mathrm{node\ heavy}}(T_h)=hB+4,\qquad M_{\mathrm{weighted}}(T_h)=B+4.}\]
Exactly $h$ modules have $B$-bit outputs, so full memoization stores
\[S_{\mathrm{all\ tables}}=hB+2(m_h-h).\]
The policies tie at $h=1$, $m=3$, and their \emph{first strict difference} is at $h=2$, $m=7$:
\[M_{\mathrm{node\ heavy}}=2B+4>B+4=M_{\mathrm{weighted}}.\]
For fixed $B$, the discrete derivatives are $\Delta_h M_{\mathrm{node\ heavy}}=B$ and $\Delta_h M_{\mathrm{weighted}}=0$; since $h=\log_2(m+1)-1$, the wasted retention is $\Theta(B\log m)$. For $B=2^{2(h+1)}=\Theta(m_h^2)$, the \emph{same-instance} ratio grows as
\[\frac{M_{\mathrm{node\ heavy}}}{M_{\mathrm{weighted}}} = \frac{hB+4}{B+4}=h+O(h/B)=\Theta(\log m).\]
The metadata $O(m\log(mB))$ and encoded source $O(N)$ are $o(B)$ in the explicitly encoded construction below. Thus the logarithmic difference remains after full per-run memory accounting, not merely in table-only notation. Both schedules evaluate every local table once; in a read-only indexed-RAM model with order-independent local kernels, they perform the same bag-assignment candidates, source tests, joins and output writes, plus $O(m)$ additional order arithmetic for weighted scheduling. Tape head movement may differ, so identical native tape time is \emph{not} asserted.

\section{BUILD III: source-owned connected CNF realization and proof/verification costs}
To show that the output dimensions can arise as authentic full separators, for every tree node $t$ create a fresh tuple $X_t$ of exactly $\log_2 s_t$ Boolean variables. Give $t$ the bag $X_t\cup\bigcup_{c\in\operatorname{child}(t)}X_c$, assign each source constraint to exactly one owner, and add the positive unit $x$ for each $x\in X_t$. To make the incidence graph connected, for each child port variable $y\in X_c$ add the binary clause $(x_t\lor y)$ in the parent $t$, using a designated $x_t\in X_t$. For the NO control, add the contradictory unit $\neg x_{\mathrm{root}}$. Every shared variable occurs in exactly its own bag and its parent's bag, so running intersection and source authentication are immediate. The SAT control is witnessed by the all-one assignment; the UNSAT control has the pair of contradictory root units. These are \emph{ordinary connected CNFs with units and binary clauses}, not strict signed exact-(2,2)-3CNFs, and they are easy by unit propagation. Their purpose is to realize the weighted table sizes, \emph{not} to establish semantic SAT hardness. A compressed representation would defeat the explicit-table storage cost.

For $m$ nodes and $B=2^w$, the maximum bag has at most $w+2$ variables, so the baseline explicit-table decision enumerates at most $4mB$ bag assignments, each requiring a polynomially charged source-constraint/lookup check. Reconstructing one SAT witness by recomputing the child summaries on demand at all nodes uses at most $O(m^2)$ subtree visits and at most $O(m^2 2^{w+2}\operatorname{poly}(N))$ operations; verify every original clause before output. On NO, record a streamed child-before-parent exact-table transcript with all source-owner identifiers and recompute it for independent source-authenticated checking. Its length is $O(\sum_t s_t\operatorname{polylog}N)$ bits, and full replay costs polynomial time; these are semantic certificates, not automatically Resolution/LRAT certificates. The same deterministic program handles both answer classes, with no supplied side bit.

\begin{proposition}[Charged sufficient rank, restricted]
For this recognized tree grammar with $m\le N^{O(1)}$, $w\le c\log_2N$, source validation in polynomial time, and a \emph{fixed polynomial number} of explicitly budgeted alternate strategy attempts satisfying $\sum_j B_j\le N^c$ for a fixed $c$, reserve
\[U(N)=C\bigl(N^3+m^2 2^{w+2}N^2+\sum_j B_j+N^2\bigr)\]
elementary work credits, where each $B_j$ is the fully charged bound for one failed strategy or representation conversion and $C$ is a sufficiently large fixed integer for the specified implementation. If $z$ is the number of consumed credits, the complete-controller rank $\Phi=U(N)-z$ is a nonnegative integer of \emph{polynomial numerical value} and decreases at each charged elementary action until correct termination. This is a sufficient bounded-work certificate, not an independently derived universal SAT potential.
\end{proposition}
\noindent\textbf{Model ledger.} Let $A(N)=N^{O(1)}m^2 2^w$ denote the actual verified indexed-RAM operation upper bound, including recognition and replay, and let $W(N)=M_{\mathrm{weighted}}+O(N+m\log(mB)+m\log N)$ be peak RAM work bits including metadata and reconstruction stack. For a read-only-input fixed two-tape deterministic TM, a straightforward sequential simulation gives $S_2=O(W+\log N)$ and conservative $T_2=O(A(N)(N+W)^2)$; a one-tape deterministic TM storing the explicit source gives $S_1=O(N+W)$ and conservative $T_1=O(A(N)(N+W)^3)$; a fixed universal TM adds its explicitly charged polynomial simulation overhead. These are \emph{nonoptimal upper bounds on distinct native models}, not a transfer of communication or crossing-sequence lower bounds. Output-tape usage and certificate length are counted separately in time and transcript size.

\section{Curves, comparisons, and limitations}
For fixed $m=2^{h+1}-1$ and $B$ varying, the exact tabular memory slopes satisfy
\[\lim_{B\to\infty}\frac{\log M_{\mathrm{weighted}}}{\log B}=
\lim_{B\to\infty}\frac{\log M_{\mathrm{node\ heavy}}}{\log B}=1.\]
Their apparent common exponent hides the unbounded $\Theta(\log m)$ factor when $B=\Theta(m^2)$. The time envelope for any one schedule must include recognition, all failed choices, source reads, joins, reconstruction and proof output; taking the minimum of unrelated per-input $T_+$, $T_-$ or $S$ maxima is not a valid simultaneous machine frontier. The improved weighted order changes an \emph{achievable scheduling upper bound}, not an NP hardness lower bound.

The separate shared structural inequality $n\le3b+12bq$ is a necessary bound for \emph{static} syntactic modular coverage. The illustrative $2^{b+q}$ time and $2^b$ space proxies have continuous time-exponent minimum near $b=\sqrt{n/12}$ and their first $q=0$ equality at $b\ge n/3$; neither is a measured lower bound. For bounded bag width $w$, exact tree DP uses $N^{O(1)}2^{O(w)}$ time with scheduling-dependent peak space. For polynomially recognizable 2CNF/XOR modules, algebraic elimination can be better than enumerating $2^w$ tables. For 2CNF plus bounded affine codimension $e$, Arvind--Guruswami's known algorithm has $N^{O(e)}$ time. For unconstrained interfaces, proof-system acquisition and universal separator discovery remain OPEN. Combining these solvers in a uniform controller is polynomial only after globally charging failed attempts and a common polynomial-value rank or total budget.
