\[
\forall A\ \forall c>0\ \forall N_0\ \exists F:
|F|\ge N_0\land T_A(F)>|F|^c,
\]

\section{Construction and exact resources}
Let $t\ge3,h\ge2$ and $X=\{x_{ji}:j\in[t],i\in[h]\}$. Define the contextual relation
\[
Q_{t,h}(X)=\bigvee_{j=1}^t\bigwedge_{i=1}^h\neg x_{ji}.
\]
Introduce selector variables $y_j$, enforce $\bigvee_j y_j$ by a proper 3-clause OR chain using $t-2$ clauses and $t-3$ fresh chain variables, and for every $j,i$ encode $(\neg y_j\vee\neg x_{ji})$ into the two proper ternaries
\[
(\neg y_j\vee\neg x_{ji}\vee p_{ji})\wedge
(\neg y_j\vee\neg x_{ji}\vee\neg p_{ji}),
\]
each $p_{ji}$ fresh. Call the resulting ordinary proper-3CNF $H_{t,h}(X,Y)$.
It has exactly $n=2th+2t-3$ variables and $m=k=2th+t-2$ ternary clauses. A fixed two-header/four-word-per-clause encoding uses
\[
w=\lceil\log_2(64(n+m+1))\rceil,\quad N=(2+4m)w=(8th+4t-6)w.
\]
One addressed $w$-bit word read/write costs one. Parsing, validation, reduction discovery, auxiliary construction, write output, failed attempts, source replay and peak workspace are charged. No evaluation-gate count is interpreted as a solver lower bound.

\begin{theorem}[PROVED/EXACT, full-boundary equivalence]
For every complete boundary assignment $\alpha$,
\[
\alpha\models Q_{t,h}\quad\Longleftrightarrow\quad \exists Y\,H_{t,h}(\alpha,Y).
\]
The parent $H_{t,h}$ is SAT, $Q$ has an explicit $t$-term DNF, and every contextual query is decided in $O(th)$ word operations after paid grammar recognition.
\end{theorem}
\begin{proof}
An existentially quantified padding pair enforces precisely $(\neg y_j\vee\neg x_{ji})$. The OR chain enforces at least one selector TRUE. Any true selector forces its entire boundary group to zero; conversely a zero group supplies a true selector with valid chain and padding completions. A scan for such a group is linear.
\end{proof}

\begin{theorem}[PROVED/EXACT, sharp restricted compilation lower bound]
Every CNF over the boundary variables $X$ alone, with arbitrary widths and signed literals, logically equivalent to $Q_{t,h}$ contains at least $h^t$ distinct non-tautological clauses. Equality is attained by
\[
\bigwedge_{(i_1,\ldots,i_t)\in[h]^t}
(\neg x_{1,i_1}\vee\cdots\vee\neg x_{t,i_t}).
\]
For $t\ge4$ there is no auxiliary-free width-three CNF representing $Q$.
\end{theorem}
\begin{proof}
For each tuple $a=(a_1,\ldots,a_t)\in[h]^t$ let $\omega_a$ set precisely $x_{j,a_j}=1$ in each group $j$, all other boundary bits zero. Every $\omega_a$ falsifies $Q$, so an equivalent CNF contains a clause $D_a$ false there. Because $Q$ entails $D_a$, $D_a$ must contain a negative literal from every group. Otherwise changing the group omitted from its negative literals to all-zero makes $Q$ true while every literal of $D_a$ stays false. As only $x_{j,a_j}$ is true in group $j$ under $\omega_a$, $D_a$ contains $\neg x_{j,a_j}$ for all $j$. Distinct $\omega_b$ cannot falsify this same clause because any $b\ne a$ sets at least one such negative literal true. Hence $h^t$ distinct required clauses, each of width at least $t$. The displayed CNF is equivalent because $Q$ fails iff every group contains a TRUE bit.
\end{proof}
For fixed $h=2$, the source has $5t-2$ clauses and $N=\Theta(t\log t)$, whereas any explicit auxiliary-free CNF output requires $2^t$ clauses and at least $t2^t$ literal records. A streaming generator need not use exponential peak space. This output-size bound is \emph{not} a lower bound on exact one-bit SAT decisions, DNF, circuits, existential CNF, static source-retaining services, or lazy contextual queries.

\section{Opposite-label controls and real source access}
Using fresh proper-three forcing gadgets
\[
G(\ell;a,b)=\bigwedge_{\epsilon,\delta\in\{-1,1\}}
(\ell\vee\epsilon a\vee\delta b),
\]
force $x_{j1}=1$ for $j\ge2$, $x_{1i}=0$ for $i\ge2$, and two fresh variables $u=v=0$. Add one pivot clause $(\lambda\vee u\vee v)$, with $\lambda=\neg x_{11}$ on the SAT source and $\lambda=x_{11}$ on the UNSAT source. This appends $4(t+h)+1$ clauses and $2(t+h)+2$ variables. The matched valid proper-3CNF sources have identical length/metadata and differ in exactly one sign bit. Their labels are opposite and are decidable by an $O(th)$-word source recognizer. A deterministic exact indexed-bit decider must inspect that distinguishing bit on the pair, but no expensive continuation is forced.

\section{Independent Roles 4--5 reduction audit}
The 2SAT chain has $q$ sensitive orientation-field reads, matched by $O(q)$ SCC/scan. Adding $k$ ternaries permits a charged $2^k\operatorname{poly}(N)$ upper bound, not a lower bound. Role 4's connected cubic prism Tseitin proper-3CNF has $n=3t$, $k=8t$, minimum syntactic strong-2CNF backdoor $t$, clause-minimal UNSAT variants, and $2t$ sensitive source-word groups. Nevertheless parity rank/recognition decides it in $O(t)$ words. Role 5's degree-four NP-complete graph-coloring language includes the directly input-sensitive degree-three subfamily, itself linear-time decidable by Brooks. The only valid reduction ledger with charged construction $R$, preprocessing $H$, target calls $Q$, model overhead $\tau$, and size $g$ is
\[
L_{\rm source}(N)\le R(N)+H(N)+Q(N)\tau(N)T_{\rm target}^{\le}(g(N)).
\]
Materialization may already consume the input-order lower bound; identity inclusion preserves its order but does not amplify it. No source-to-ARC/FLMV/MKTP transport is asserted.
