\paragraph{Two obstacles and literature preflight.}
The first obstacle is quantitative model matching: SGLALT1 improves the symbolic ledger only if amplification, shifted executions, SAT-query count, and formula length are all charged in the same oracle-time model. The second is structural: any attempt to beat SGL's quadratic two-alternation overhead by another black-box relativizing $\Sigma_2$ simulation confronts Viola's oracle lower bound. Primary literature checked: Lautemann's BPP-in-$\Sigma_2^P$ theorem; Viola's quantitative $\mathrm{BPTime}(t)\subseteq\Sigma_2\mathrm{Time}(t^2\log t)$ and $\Sigma_3$ quasilinear simulations plus oracle lower bound; and van Melkebeek--Mocelin Sdroievski for the reconstruction architecture.

\paragraph{KNOWN THEOREM: quantitative SGL and oracle barrier.}
Viola records
\[
\mathrm{BPTime}(t)\subseteq\Sigma_2\mathrm{Time}(t^2\log t)
\]
from Sipser--G\'acs/Lautemann and proves
\[
\mathrm{BPTime}(t)\subseteq\Sigma_3\mathrm{Time}(t\,\mathrm{polylog}\,t).
\]
The paper also proves that relative to some oracle
\[
\mathrm{BPTime}(t)\not\subseteq\Sigma_2\mathrm{Time}(o(t^2)).
\]
All of the positive simulations above relativize. Therefore the quadratic SGL overhead is optimal up to logarithmic factors for relativizing $\Sigma_2$ simulation in this oracle sense. This is a barrier to a class of proof techniques, not a SAT lower bound.

\paragraph{PROVED/EXACT: amplification/query-count audit.}
Let the original probabilistic oracle reconstructor $M^{\mathrm{SAT}}$ have oracle time $t$, use at most $O(t)$ random bits, and make at most $q(t)$ SAT queries per execution. Standard independent repetition to reduce constant error to at most $1/\mathrm{poly}(t)$ uses $O(\log t)$ executions, so the amplified acceptance test uses
\[
O(q(t)\log t)
\]
SAT queries and $t\,\mathrm{polylog}(t)$ oracle work. The SGL covering predicate uses $O(t)$ shifts (up to logarithmic factors in the quantitative implementation), hence the total number of original SAT queries appearing in the $\Sigma_2$ matrix is
\[
\boxed{O(t\,q(t)\,\mathrm{polylog}(t)).}
\]
If $q(t)=O(1)$, this is $t^{1+o(1)}$, while the nonoracle matrix work is $t^{2+o(1)}$.

If each query formula has length at most $t^{b_0+o(1)}$ and the assumed exact SAT decider runs in $S^{\kappa+o(1)}$, substituting it for all oracle calls costs
\[
t^{1+b_0\kappa+o(1)}
\]
when $q(t)=O(1)$. Therefore the SGL matrix exponent is exactly the SGLALT1 symbolic value
\[
\boxed{c_0=\max\{2,1+b_0\kappa\}}
\]
under these hypotheses. Thus SGLALT1 did not omit a hidden extra power of $t$ from amplification; amplification contributes only polylogarithmic overhead in this regime.

More generally, if
\[
q(t)=t^{\delta+o(1)},
\]
then the oracle-substitution term becomes
\[
t^{1+\delta+b_0\kappa+o(1)}
\]
and
\[
\boxed{c_0(\delta)=\max\{2,1+\delta+b_0\kappa\}.}
\]
This generalization is exact bookkeeping and exposes the query-count hypothesis that must be source-matched.

\paragraph{CONDITIONAL project ledger.}
After conservative elimination of the remaining $\exists\forall$ blocks with compiler exponents $b_1,b_2$,
\[
\boxed{
\alpha_{\rm SGL}
\le
\alpha_0 b_1b_2\kappa^2
\max\{2,1+\delta+b_0\kappa\}+o(1).
}
\]
For the constant-query case $\delta=0$ and unit compilers,
\[
\alpha_{\rm SGL}\le\alpha_0(\kappa^3+\kappa^2)+o(1)
\qquad(\kappa\ge1).
\]
The Viola route remains
\[
\alpha_{\rm V}\le\alpha_0(b_0b_1b_2b_3)\kappa^4+o(1).
\]
Thus, when common factors are positive, SGL is symbolically smaller precisely when
\[
\boxed{
\max\{2,1+\delta+b_0\kappa\}<b_0b_3\kappa^2.
}
\]
This is a comparison of conditional upper bounds, not an optimality or necessity theorem.

\paragraph{Barrier bifurcation.}
There are now two distinct optimization targets. One may (i) keep two alternations and accept SGL's quadratic relativizing overhead, then improve compiler/query parameters; or (ii) seek a subquadratic $\Sigma_2$ simulation. Viola's oracle theorem implies that route (ii), if valid in a sufficiently general form, cannot be proved by a fully relativizing black-box simulation that survives the oracle used in the lower bound. This identifies where a nonrelativizing ingredient would have to enter, but does not provide that ingredient. The quasilinear $\Sigma_3$ route remains relativizing and trades the quadratic matrix for one extra alternation.
