\section{Exact construction and encoding}
Let $b=(b_1,\ldots,b_h)$ and define
\[
 \mathrm{HWB}_h(b)=\begin{cases}0,&t=\sum_i b_i=0,\\b_t,&t>0.\end{cases}
\]
A polynomial circuit computes this using a unary count-state dynamic program
\[
p_{0,0}=1,\qquad p_{0,j>0}=0,\qquad
p_{i,j}=(p_{i-1,j}\land\neg u_i)\lor(p_{i-1,j-1}\land u_i),
\]
where negative-index terms are zero, and output
$y=\bigvee_{j=1}^h(p_{h,j}\land u_j)$.
Each binary gate $v=a\land c$ is encoded by
$(\neg v\lor a)\land(\neg v\lor c)\land(v\lor\neg a\lor\neg c)$;
OR uses its dual, NOT uses two binary clauses.
For every binary $(a\lor c)$ append a fresh variable $z$ and use
$(a\lor c\lor z)\land(a\lor c\lor\neg z)$.
To force any literal $\ell$, use the four proper clauses
\[
G(\ell;s,t)=\bigwedge_{\epsilon,\eta=\pm1}
(\ell\lor\epsilon s\lor\eta t)
\]
with fresh distinct variables $s,t$.
Introduce globally forced zero $z_0$, forced one $z_1$,
fresh forced zeros $f_i$ and the independent pivot
\[
 (\ell_i(b_i)\lor z_0\lor f_i),\qquad
 \ell_i(1)=u_i,\quad\ell_i(0)=\neg u_i.
\]
Force final $y=1$ with $G$. All emitted clauses have exactly three distinct variables.
The code uses $h$ NOT gates, $3h(h+1)$ unary-count AND/OR gates and $2h$ selection gates; the full count including forcing and private binary pads is
\[
 n_h=9h^2+22h+8,\qquad m_h=15h^2+34h+12.
\]
A source has two header words and four words per clause (arity and three signed literal IDs). An ID $v$ is encoded by $2|v|+[v<0]$,
\[
w_h=\lceil\log_2(64(n_h+m_h+1))\rceil,\qquad
N_h=(4m_h+2)w_h=\Theta(h^2\log h).
\]
The only variable output-sign words are the $h$ pivot signs.
Here $k=m_h$ for the construction relative to the empty source;
there is no elimination $d=0$ and no inferred semantic residual $r$.
An explicit output writes $N_h$ bits; machine word width is $\Theta(\log N_h)$; constructor reads all $h$ source bits and uses polynomial time and peak words.

\begin{lemma}[Local sign lift; PROVED/EXACT]
For every $b\in\{0,1\}^h$, the constructed source $F_h(b)$ is valid proper-3CNF of encoded length $N_h$, and
$\operatorname{SAT}(F_h(b))=\mathrm{HWB}_h(b)$.
Changing a single $b_i$ changes exactly one fixed literal-sign bit, at a position disjoint from every $b_j$ with $j\ne i$.
\end{lemma}
\begin{proof}
Existentially eliminating each fresh binary pad recovers the binary gate equivalence. Eliminating the private four-clause forcing gadgets recovers their forced literals. The pivot forces $u_i=b_i$ because $z_0=f_i=0$. Induction over the gate DAG forces every gate's output to the circuit evaluation, and the last forcing gadget requires $y=1$. Input-sign changes affect only their pivot word's low bit; grammar, lengths, identifiers, and all other records are unchanged. The all-zero input is UNSAT while $b_1=1$ and every other bit zero is SAT.
\end{proof}

\begin{theorem}[All-order restriction transport; KNOWN THEOREM + PROVED/EXACT]
For some absolute $c>0$ and all sufficiently large $h$, any ordered deterministic binary decision diagram, regardless of variable order, that computes SAT on all encoded proper-3CNF inputs of length $N_h$ (or only on all $F_h(b)$) has at least $2^{ch}$ nonterminal nodes.
\end{theorem}
\begin{proof}
Fix all $N_h-h$ non-pivot bits to the template constants and retain the $h$ independent pivot bits. Restriction cannot increase OBDD size and leaves an OBDD computing $\mathrm{HWB}_h$, in the inherited order. The all-order exponential OBDD lower bound for HWB is proved in Bollig--L\"obbing--Sauerhoff--Wegener [1]. Thus the original OBDD has at least $2^{ch}$ nodes. Explicitly writing node labels and two outgoing references costs at least that many output words and directed wires. This restricted lower bound is superpolynomial in $N_h$.
\end{proof}

\begin{theorem}[Fast total decider on the hard-representation image; PROVED/EXACT]
There is a single uniform, total, deterministic exact proper-3SAT decider $A_\star$ whose running time is polynomial in $N_h$ on \emph{every} $F_h(b)$.
\end{theorem}
\begin{proof}
Parse and validate the source. Try all candidate $h$ compatible with its header, regenerate canonical $F_h(0^h)$, compare all records other than the $h$ designated pivot sign positions, and recover $b$ from those positions. If the full template check succeeds, count $t=\sum_i b_i$ and answer $[t>0]\land b_t$. Otherwise run an ordinary exhaustive exact SAT algorithm. Every step of recognition, reconstruction, reads, and temporary storage is polynomial in the input length; the fallback is total and exact on every other source. No OBDD is constructed. Therefore an exponential OBDD lower bound cannot force large single-input running time for this decider on the displayed family.
\end{proof}
