\section{Sharp fixed-path capacity theorem}
Let $F_0$ be any ordinary CNF source, with original source names retained
under each compatible continuation. Fix in advance $d$ ordinary CNF
continuations $C_1,\ldots,C_d$ whose private auxiliary names are fresh
and pairwise disjoint, while intended common original names are identical.
Let $F_i=F_0\wedge C_1\wedge\cdots\wedge C_i$ ($0\le i\le d$)
be ACTUAL ordinary encoded children, including complete revised headers and
literal bodies. Set $v_i=\mathbf1[\SAT(F_i)]$.
A \emph{path synopsis} is required to answer only these $d+1$
precommitted queries, not all future potential continuations, and is
computed with full access to $F_0$ and the same fixed $A$.

\begin{theorem}[Exact fixed-path transcript capacity]\label{th:path}
For any ordinary $F_0$ and any compatible fixed conjunctive path,
\[
 (v_0,\ldots,v_d)=(\underbrace{1,\ldots,1}_{k},
       \underbrace{0,\ldots,0}_{d+1-k})
 \quad\text{for some }0\le k\le d+1.
\]
Thus the integer $k=\sum_i v_i$ encodes the complete both-label path
using $\lceil\log_2(d+2)\rceil$ binary bits. If the projected boundary
context sets form a strict nonempty chain and each successive difference
is nonempty, all $d+2$ traces occur for ordinary proper-3CNF sources;
therefore this binary storage bound is sharp for a source-erased synopsis
that answers precisely these precommitted queries.
\end{theorem}
\begin{proof}
Every satisfying assignment of $F_{i+1}$ satisfies $F_i$ by
restriction; consequently $v_{i+1}\le v_i$. Binary monotonicity is
exactly the claimed normal form. The decoder outputs $v_i=\mathbf1[i<k]$.

For sharpness, let $Y$ be the shared original boundary, and let $Q_i$
be the nonempty strictly nested boundary-feasibility sets of the
precommitted continuations ($Q_0=\{0,1\}^b$). Choose one singleton
source support in $Q_{j}\setminus Q_{j+1}$ for every $j<d$,
choose a singleton in $Q_d$, and additionally the empty source support.
The resulting $d+2$ roots have all distinct stopping indices.
Every singleton/empty support is realizable by an ordinary proper-3CNF:
force each specified original literal with the standard four-clause
proper PIN gadget on two fresh private variables, and for the empty
support force one original literal and its negation with two separate
fresh-auxiliary PIN gadgets. Hence any exact synopsis for these
sources must distinguish $d+2$ cases. Counting binary strings gives
the asserted worst-case fixed-length lower bound.
\end{proof}

\paragraph{Quantifier firewall.} This is not the prior
ARC-BOUNDARY-CAPACITY122 theorem with a smaller numerical constant.
CAPACITY122 fixes a capsule that must answer EVERY POSSIBLE compatible
ordinary continuation after permanently losing source access. It needs
$\Omega(2^b)=\Omega(N/\log^2N)$ bits on a balanced support family.
The present synopsis answers only a prescribed chain of length $d$;
future context requests are not allowed. Its two bits do not encode
boundary supports, cannot answer a new branch or arbitrary suffix,
and cannot construct the next source-named child from the synopsis alone.
An adaptive solver's full future policy is NOT silently equated with a
fixed precommitted path. The two statements have distinct quantifiers
and are compatible.

\section{All-input exact acquisition by the same fixed $A$}
Given any ordinary $F_0$ and a predetermined compatible continuation
sequence, an eager uniform compiler constructs and validates the complete
ordinary $F_i$ strings and calls that same exact $A$ on each.
It stores $k=\sum_i A(F_i)$, then can discard $F_0$ and all children
only because no future query beyond these precommitted labels is permitted.
This is correct for SAT and UNSAT on EVERY ordinary input, regardless
of Horn, SCC/2SAT, affine, graph factors, DP, branching, caching,
learning or other internal strategies used by $A$.

For the two-level experiment $C_1=\mathrm{PIN}(\neg x_1)$ and
$C_2=\mathrm{PIN}(\neg x_2)$, each proper PIN is
\[
 (\ell\lor a\lor b)\land(\ell\lor a\lor\neg b)
 \land(\ell\lor\neg a\lor b)
 \land(\ell\lor\neg a\lor\neg b),
\]
with two genuinely fresh private names and exactly identical original
$x_1,x_2$ in both actual descendants. If $F_0$ is canonical DIMACS
of length $N$ with at least two original names, each $F_i$ contains its
unaltered source body, correctly regenerated variable/clause headers and
at most eight extra proper 3CNF clauses. Hence the PHYSICAL ordinary
child lengths are $N+O(\log N)=\Theta(N)$, not $N^{\lambda}$ for
$\lambda<1$. The short two-bit synopsis is NOT an ordinary SAT child.

The eager fully charged $d=2$ implementation has three actual A calls
on $\Theta(N)$-bit inputs, $O(N\operatorname{polylog}N)$ preprocessing,
$\Theta(N)$ readable child storage, and a simultaneous upper envelope
\[
 t'\le\max\{1,t\}+o(1),\qquad s'\le\max\{1,s\}+o(1).
\]
On canonical single-header DIMACS, each A guest read of $F_i$ can
instead be simulated by a virtual byte accessor to the revised header,
the source's read-only body, or one of the at most eight computed PIN
clauses. The header and PIN bits require $O(\log N)$ index/writable
metadata and polylogarithmic elementary work per requested guest bit.
The source is retained read-only through both levels, and all actual
input/workspace reads, changed/unchanged writes and per-request address
work are paid. The virtual upper certificate is
\[
 t'\le\max\{1,t\}+o(1),\qquad s'\le\max\{s,0\}+o(1),
\]
with at least $O(\log N)$ actual index bits. The simulator is not
claimed to use low space on malformed/noncanonical inputs without a
normalization audit; an exact eager fallback is available, but also
noncontractive. Any full parent-scale $A$ call and especially an
artificially padded exact $A_D$ can consume $\Omega(N^D)$ bit work,
precluding the suggested $D/2$ time exponent for THIS compiler.
The original two-level children are generated and labeled before the
source is discarded; the 2-bit synopsis has NO descendant eligibility.

\paragraph{FLMV and physical-resource accounting.}
