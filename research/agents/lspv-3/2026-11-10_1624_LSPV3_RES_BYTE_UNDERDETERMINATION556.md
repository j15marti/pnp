## Theorem 556.1: identifiability barrier under fixed semantics

Let S be **any fixed effective, sound, refutationally complete mathematical rule relation** implementing the original declared five families with the same immutable source, acyclic sharing and one unit charge for each new derived node. Pick one common effective and faithful serialization for all non-RES rules. Define two entire effective source-bound byte grammars that differ only in the exact RES opcode spelling: grammar A uses JSON string `"RES"`, while grammar B uses `"R2"`; every other attribute, original-source commitment, parent reference, pivot, clause, defining facet, scope, freshness condition and weight is encoded identically.

Both encode and decode **the same mathematical proof relation**, and thus are sound and complete for the same UNSAT formulas and have the same optimum W_S(F) for every F. Nonetheless, they accept different byte packets whenever a proof uses RES. This follows by constructing the encoders and their inverse typed decoders; each is polynomial-time and cost-preserving, while the parser's opcode equality test differs. Every correctly typed core-only packet has identical status under A and B. Thus even exhaustive evidence restricted to the correctly typed core cannot select one historical RES byte grammar. **This is not an impossibility of specifying a new grammar, or proof that the historical grammar did not exist elsewhere. It is nonidentifiability from the surviving artifacts reviewed.**
