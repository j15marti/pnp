\section{Formal original-source construction}
Fix $r\ge1$, $t\ge2$, set $b=r+t$, and let the
\emph{globally identical} shared boundary be
$Y=(y_1,\ldots,y_b)$. Each module's auxiliary variables
are fresh and disjoint from all other modules.
For $i\le r$ use a named pin $P_i$ consisting of:
\[
(\neg y_i\lor z_i\lor w_i),\
(\neg y_i\lor z_i\lor\neg w_i),\
(\neg y_i\lor\neg z_i\lor w_i),\
(\neg y_i\lor\neg z_i\lor\neg w_i).       \tag{1}
\]
Existentially eliminating $z_i,w_i$ gives exactly
$y_i=0$. For every word $a\in\{0,1\}^t$ let
$\ell_0(x)=x$, $\ell_1(x)=\neg x$ and set
\[
D_a=y_1\lor\cdots\lor y_r\lor
\bigvee_{j=1}^{t}\ell_{a_j}(y_{r+j}).             \tag{2}
\]
This clause is false at exactly one shared assignment,
$Y=(0^r,a)$. If $b=3$, use $D_a$ itself as
module $E_a$. If $b>3$, with literal sequence
$\lambda_1,\ldots,\lambda_b$, replace it by
a named three-CNF chain with fresh private
$z_{a,1},\ldots,z_{a,b-3}$:
\[
(\lambda_1\lor\lambda_2\lor z_{a,1})
\ \land\
\bigwedge_{j=2}^{b-3}
(\neg z_{a,j-1}\lor\lambda_{j+1}\lor z_{a,j})
\ \land\
(\neg z_{a,b-3}\lor\lambda_{b-1}\lor\lambda_b).
\tag{3}
\]
The middle conjunction is empty when $b=4$.
Sequential elimination of private variables proves
$\exists Z_a E_a\equiv D_a$.
The entire source is
\[
F_{r,t}=\bigwedge_{i=1}^r P_i
\ \land\ \bigwedge_{a\in\{0,1\}^t}E_a.            \tag{4}
\]
All clauses contain three distinct names, no two source
clauses are duplicates, and the clause--variable incidence
graph is connected. Each $E_a$ shares the \emph{same}
boundary $Y$, not independently renamed copies.
The number of source modules, variables and clauses is
\[
k=r+2^t,\quad
n=b+2r+2^t(b-3),\quad
m=4r+2^t(b-2).                                   \tag{5}
\]
Equation (4) is proper ordinary three-CNF; the boundary
variables have occurrence counts generally exceeding
two positive and two negative appearances. It is NOT
a strict signed exact-$(2,2)$ source.

\begin{theorem}[Exact minimal whole-module support]
For every $r\ge1,t\ge2$, $F_{r,t}$ is UNSAT,
and deleting any one whole original source module makes
the remainder SAT. Thus every UNSAT subcollection of
complete modules contains all $r+2^t$ modules, attaining
the rank--exception bound $r+2^{b-r}$.
\end{theorem}
\begin{proof}
Because private scopes are pairwise disjoint,
the conjunction is satisfiable iff the existential
projections of all modules intersect \emph{at one common}
$Y$. Pins force $y_1=\cdots=y_r=0$.
For every remaining assignment $a$ of the last $t$
bits, its corresponding module $E_a$ is false.
So (4) is UNSAT.

If $E_a$ is deleted, use $Y=(0^r,a)$, which satisfies
all remaining modules. If $P_i$ is deleted, assign
$y_i=1$ and all other pinned coordinates zero;
then every exception $D_a$ is true, and surviving
pins are true. All private witnesses exist independently.
Deleting additional modules cannot reintroduce
unsatisfiability. Hence the full module set is the unique
unsatisfiable subcollection.
\end{proof}

\begin{theorem}[Fully sourced uniform Resolution certificate]
The source (4) has a standard Resolution refutation
with exactly
\[
\boxed{R(r,t)=3r+2^t(b+r-2)-1}                  \tag{6}
\]
derived lines. Every premise is indexed by an original
source clause ID, every derived line records its two
earlier parents, the opposite-sign pivot and the exact
resolvent. For fixed $r$, $R=\Theta(m)$.
\end{theorem}
\begin{proof}
From each pin's four original source clauses,
resolve the first pair on $w_i$, the second pair on
$w_i$, then these two results on $z_i$ to derive
$\neg y_i$, using $3r$ Resolution steps.
Resolve the $b-2$ clauses of the $E_a$ chain
consecutively on its $b-3$ private names to derive
$D_a$ (zero such steps for $b=3$).
Resolve the resulting $D_a$ against all $r$ pin
units to derive
\[
K_a=\bigvee_{j=1}^t\ell_{a_j}(y_{r+j}).         \tag{7}
\]
In lexicographic order, each adjacent pair of
$K_a$ differs in the last remaining bit and resolves
to the clause on the preceding $t-1$ bits.
Iterate to the empty clause, using $2^t-1$
more steps. Total:
$3r+2^t[(b-3)+r]+(2^t-1)$, equal to (6).
Each stage is a legal Resolution inference; a
sound checker cannot accept an empty-clause
derivation on a SAT source.
\end{proof}

\paragraph{Quantitative falsification.}
Large minimum whole-module support is NOT a bound
on Resolution proof \emph{complexity relative to the
encoded source length}. A proper and connected
formula may require every module for contradiction,
yet admit an explicit near-linear number of proof lines.
No superpolynomial lower bound for Resolution,
polynomial calculus, cutting planes, adaptive branching
or guest $A$ follows.

\section{Physical bit/space/acquisition ledgers}
Use canonical fixed-width encoded literal IDs, with
$w=\lceil\log_2(n+1)\rceil$ and physical parent length
$N=\Theta(m\log(n+1))$.  A line containing at most
$b$ literals, chronological parent IDs and a pivot has
$O(b\log(n+m+R))$ bits. The whole explicit certificate has
\[
L=O((m+R)b\log(n+m+R)).
\tag{8}
\]
For fixed $r$ and growing $t$, this is $O(N\log N)$.
The family-specific deterministic source constructor can
parse each actual named clause, reject malformed sources,
and write the authentic transcript in
$O((N+L)\operatorname{polylog}(N+L))$ bit time with
$O(\log(N+L))$ working bits in a \emph{fixed-$k$}
sequential-input multitape model, output-only tape
excluded from reusable work space and never reread.
It charges source reads, all output bits, arithmetic,
control, source authentication, and peak work cells.
The input head can make one forward scan;
work-head traffic remains charged in $T_k$.

An indexed read-only-input RAT with a finite standard
word-operation set admits the corresponding charged
$O((N+L)\operatorname{polylog}(N+L))$ bit-time
constructor and $O(\log(N+L))$ index/work bits.
This is a constructive \emph{upper} bound, not an
indexed-RAM lower bound.
For one ordinary shared writable tape initially
containing all $N$ source bits, a conservative
output-aware simulation gives
$T_1=O((N+L)^2\operatorname{polylog}(N+L))$,
$P_1=O(N+L+\operatorname{polylog}(N+L))$;
physical tape crossings, movement and initial input
footprint are not discarded. This is also an
\emph{upper} bound, not a claimed direct lower bound.
No one-tape or sequential-head equality/DISJ
crossing theorem is transferred to indexed RAM.
The generic (not specially canonical) Resolution
checker may require different time/space bounds.

There is no branching ($h=0$), no guest $A$ call
($m_i,M,V$ are not active), and no source-to-child
ARC compression. To exercise two \emph{actual}
hereditary ordinary proper-3CNF levels, append
one redundant $y_1=0$ four-clause pin with fresh
private variables at each level. Parent UNSAT
and deletion-of-an-exception SAT sources retain
their respective labels at both levels.
Clause counts increase $m\mapsto m+4\mapsto m+8$;

This is explicitly not two power-short

\section{Scope of the unresolved ARC implication}
This restricted theorem realizes and authenticates the
rank--exception source modules, but does not solve
projection extraction for \emph{arbitrary} CNF.
Even with zero shared boundary bits, extracting the exact
projection of an unrestricted source distinguishes SAT
from UNSAT. Under strict signed exact-$(2,2)$, the
underlying SAT decision language remains NP-complete
by D\"ocker~\cite{DOK}; no inexpensive universal
projection constructor can be assumed without new work.
The all-ordinary-UNSAT certificate size/existence cap,
fully charged deterministic acquisition, same-instance
two-level ARC successor from unknown $K$,
ARC-EDGE-90 and $P$ versus $NP$ remain \textbf{OPEN}.
