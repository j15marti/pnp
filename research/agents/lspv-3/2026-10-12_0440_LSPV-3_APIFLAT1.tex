\section{Target and exact quantifiers}
Let $\mathcal M$ be a standard deterministic uniform finite-program model
(multitape Turing machine, or word-RAM with every memory access charged), and
let $P$ be a fixed program.  Let $\mathcal E$ be a finite set of procedure
names designated ``extractor'', ``reconstructor'', or any other internal API.
Write
\[
 h_{\mathcal E}(P,x)
 =\#\{\hbox{host-level procedure calls from the run of $P(x)$ into
             a member of $\mathcal E$}\}.
\]
The attacked lower-bound target is the program-syntax statement
\begin{equation}
 \tag{NCALL}
 \mathsf{SAT}\in\mathsf P
 \Longrightarrow
 \forall A\in\mathsf{PolySAT}\;\exists F\in\mathcal C:
 h_{\mathcal E}(A,F)>0,
\end{equation}
or any stronger positive/superconstant lower bound on the same meter.  Here
$F$ is an explicitly encoded CNF of bit length $N=|\operatorname{enc}(F)|$;
all parsing, simulated stack, and output costs are charged.  No property of
the proposed clean-core family $\mathcal C$ is needed for the attack.

The statement $\forall A\in\mathsf{PolySAT}$ alone may be vacuous if
$\mathsf{SAT}\notin\mathsf P$.  The result below instead proves the exact
conditional negation needed for a P=NP proof-by-contradiction architecture:
if one polynomial SAT decider exists, a zero-named-call one exists too.

\section{Literature preflight and transfer classification}
The two blocking obstacles were (i) distinguishing semantic preservation from

below is proved directly in the declared model.
\item \textbf{Useful structural analogy requiring a new transfer theorem.}
Compiler correctness illustrates that extensional behavior can be preserved

and an arbitrary-decider compiler into that relation.
\item \textbf{Misleading analogy / failed transfer.}  Verified compilation
does not imply a superpolynomial lower bound, preserve arbitrary side-channel
meters, or turn a source-side compatibility object into an obligatory runtime
object.
\end{enumerate}

\section{A single-dispatcher erasure theorem}
For a fixed program $P$, number all instructions in all of its procedures by a
finite program-counter set $Q_P$.  A state of $P$ is encoded by its ordinary
data state, current counter, and call stack.  Define $\operatorname{Flat}(P)$
to be one host procedure containing one dispatcher loop.  Its cases implement
every instruction of $P$.  A guest call pushes a return counter and changes the
simulated counter; a guest return pops it.  These are assignments and branches
inside the one dispatcher, not host calls to a member of $\mathcal E$.

\begin{theorem}[FLAT-CFG-API-ERASURE1]
For every fixed deterministic finite-control program $P$ and finite named set
$\mathcal E$, there is an effectively constructible program
$\operatorname{Flat}_{\mathcal E}(P)$ such that for every encoded input $x$:
\begin{align*}
 \operatorname{Flat}_{\mathcal E}(P)(x)&=P(x),\\
 T_{\operatorname{Flat}(P)}(x)&\le c_P T_P(x)+c_P,\\
 S_{\operatorname{Flat}(P)}(x)&\le c_P S_P(x)+c_P,\\
 h_{\mathcal E}(\operatorname{Flat}_{\mathcal E}(P),x)&=0,
\end{align*}
for a constant $c_P$ independent of $x$.
\end{theorem}

\begin{proof}
Relate each source configuration to the flat configuration containing the same
data, current instruction number, and encoded call stack.  Each non-call source
instruction is implemented by one fixed dispatcher case.  A source call is
implemented by pushing the numbered return site and changing the counter; a
source return pops it.  Induction on source steps proves identical termination
and output.  Since $P$ has finitely many instructions, dispatch and each case
cost at most a $P$-dependent constant.  The flat state stores the same source
data and call stack plus a constant-size counter and fixed control overhead.
No transition invokes a host procedure named in $\mathcal E$.  On a multitape
TM the finite counter can be absorbed into finite control; on a charged word-RAM
the fixed dispatcher has constant cost.  Thus the stated bounds hold.
\end{proof}

\begin{corollary}[Conditional zero-call representative]
If $\mathsf{SAT}\in\mathsf P$, then there exists a deterministic uniform
polynomial-time SAT decider $B$ satisfying
$h_{\mathcal E}(B,F)=0$ for every encoded CNF $F$.
\end{corollary}
\begin{proof}
Choose any polynomial-time SAT decider $A$ and set
$B=\operatorname{Flat}_{\mathcal E}(A)$.  The theorem preserves correctness and
polynomial time.
\end{proof}

Hence (NCALL) is \Retired as a universal bridge.  The result is intentionally
syntax-sensitive: it says nothing about an event meter defined on the simulated
guest trace.  In fact, the construction can preserve every guest logical call
while erasing every host call.  That is the diagnostic, not a loophole.

\section{What survives the attack}
The smallest valid repair is one of the following.
\begin{enumerate}[leftmargin=1.5em]
\item Fix an \emph{external} interface (messages, probes, commitments, or output
symbols) and prove the required events are observable under a representation-
independent trace equivalence.  Inlining cannot erase an actual external
message, but an arbitrary static SAT decider is not thereby forced to implement
the protocol.
\item Count ordinary time, writable space, input probes, or output length in the
same realization.  These resources survive flattening, but a new unconditional
model-matched lower bound is required.
\item If ``logical extraction events'' are decoded from machine traces, specify
the decoder, prove invariance under compiler/interpreter wrappers, charge the
decoder, and prove that every SAT decider admits the required decoded event.
That universal transfer is \Open.
\end{enumerate}

The theorem does not claim that a particular fixed program did not perform its
own source-level helper calls.  Universality is what makes the transformation
fatal: an all-algorithm theorem must also cover the equivalent flattened
program.  SAME\_REALIZATION remains mandatory after a model-preserving compiler
has selected the realization to be charged.

\section{Barrier audit}
\paragraph{Relativization.}
The flattening simulation treats an oracle query instruction as another guest
instruction.  It therefore relativizes.  No oracle separation is crossed.

\paragraph{Algebrization.}
Nothing depends on field structure; the simulation also works with algebraic
oracle instructions.  No nonalgebrizing hinge is present.

\paragraph{Natural Proofs.}
No constructive large property separating circuit classes is defined.  The
result neither invokes nor evades the Natural Proofs barrier.

\paragraph{Nonuniformity and arbitrary exponents.}
The construction is uniform and preserves each fixed program's exponent up to
a constant factor.  It supplies no exponent uniform over all polynomial
implementations.  Delay wrappers remain an independent guard against such a
uniform exponent.

\paragraph{Solver-to-protocol transfer.}
External protocol events do survive inlining, but no theorem forces arbitrary
SAT deciders to expose the chosen protocol.  This missing compiler is the same
load-bearing static-to-online seam found in the HEC/CRS-PPC/CCSPC corpus.

\section{Handoff and exact missing implication}
The next synthesis should enforce the following gate:
\begin{enumerate}[leftmargin=1.5em]
\item $\mathsf{SAT}\in\mathsf P$ implies that every polynomial SAT decider
compiles to a fixed external relation $R$.
\item The compiler preserves one charged realization, and every valid
$R$-realization violates a model-matched unconditional bound.
\end{enumerate}
The event/resource must be invariant under INLINE, FUSED, DISPATCH, TABLE,
INTERP, RECOMP, padding, and alternate encodings.  Proving the first line is
\Open; proving the second with a lower bound strong enough for arbitrary
polynomial exponents is \Open.  Until both are closed, P versus NP remains
\Open.
