\section{Exact construction}
Let the authenticated F9 source have positive supports
\[
(156),(238),(135),(469),(247),(789)
\]
and negative supports
\[
(468),(167),(234),(358),(129),(579)
\]
with all literals negated in the latter six clauses. It has nine variables, twelve distinct proper monotone clauses, exactly two positive and negative occurrences per variable, and exactly 70 models.

Use same-domain coherent source pins
\[
P=\{x_2=1,x_3=0,x_5=1,x_6=0,x_8=0\},\quad
Q=\{x_2=0,x_3=1,x_5=1,x_6=1,x_8=0\},
\quad R=\{x_1=1,x_7=0\}.
\]
Both local residuals have four models. For every remaining variable $(x_1,x_4,x_7,x_9)$, the exact $(\#0,\#1)$ model counts are respectively $(3,1),(1,3),(2,2),(2,2)$ in both P and Q. But $\#(F9|P,R)=0$ and $\#(F9|Q,R)=1$.

For $t\ge2$, form $t$ numbered, disjoint F9 copies with variables $x_{i,j}$, indices $i$ modulo $t$. Replace the original positive occurrence of $x_{i,1}$ in the first positive clause $(x_{i,1}\lor x_{i,5}\lor x_{i,6})$ by $x_{i+1,1}$. All other original source clauses remain unchanged. Call the result $H_t$, and put $H_1=F9$.

\begin{lemma}
Every $H_t$ is connected, valid, duplicate-free proper Monotone 3-SAT-(2,2), with $n=9t,m=12t$. For every coherent word $B\in\{P,Q\}^t$, its pinned residual factors exactly into the product of the corresponding untouched F9 block residuals.
\end{lemma}
\begin{proof}
The cyclic occurrence exchange removes and reintroduces exactly one positive occurrence of each $x_{i,1}$, preserving all signed quotas. Every modified clause has three distinct variables and crosses two blocks, preventing duplication. The F9 within-block primal graph remains connected after deleting its first positive clause; the new clauses join successive blocks, proving connectedness. Since every modified clause contains pinned $x_{i,5}=1$, it is satisfied for either P or Q and imposes no residual restriction. All other clauses remain block-local.
\end{proof}

\begin{theorem}[Connected exponentially many two-pin classes, but linear decision work]
For every $t\ge1$ and $B\in\{P,Q\}^t$,
\[
\#\mathrm{SAT}(H_t|B)=4^t,\qquad
\#\mathrm{SAT}(H_t|B,R_i)=
\begin{cases}
0&B_i=P,\\
4^{t-1}&B_i=Q,
\end{cases}
\]
where $R_i=\{x_{i,1}=1,x_{i,7}=0\}$. All $2^t$ residuals have exactly the same first-order integer marginal signature, but every pair differs on some two-pin SAT continuation. Thus there are $2^t$ distinct two-pin decision-continuation classes. For $R_{\rm all}=\bigcup_i R_i$, exactly $Q^t$ has a satisfying extension, and it has one model. On the fixed-source promised P/Q input model with fixed future $R_{\rm all}$, deterministic exact marker-bit query complexity on the accepting $Q^t$ input is exactly $t$, not exponential.
\end{theorem}
\begin{proof}
Covered-clause factorization multiplies the four-model base counts and their one-variable marginals. Applying $R_i$ changes precisely one factor, whose remaining count is zero for P and one for Q, proving the displayed identities. Different profile words differ at some coordinate and are separated by that coordinate's $R_i$. The all-$R$ count multiplies the local zero/one counts, so the only SAT word is $Q^t$. Compare accepting $Q^t$ to each of $t$ UNSAT words having exactly one P block. Their physical differing pin-bit positions are pairwise disjoint across blocks. On the accepting transcript every exact deterministic bit-query decider must query at least one discriminator per block, or it also accepts the corresponding UNSAT neighbor. Reading $x_{i,2}$ once for every block achieves $t$ queries under the declared P/Q promise. No variable-value recovery, injective memo key, or SAT-label oracle is required for this promise.
\end{proof}

\paragraph{Same-original SAT/UNSAT proof provenance.}
In a P block with $R_i$, original local $C_6=(x_7\lor x_8\lor x_9)$ reduces to $(x_9)$ and original local $C_{11}=(\neg x_1\lor\neg x_2\lor\neg x_9)$ reduces to $(\neg x_9)$, a complete contradiction. With all Q and all R, the repeated original nine-bit assignment $(1,0,1,1,1,1,0,0,1)$ satisfies every original clause, including the covered interblock clauses.

\section{Fully charged decision-work scope}
The theorem applies to a recognizable explicitly numbered connected source family, not arbitrary canonical originals, arbitrary variable renamings, or arbitrary pin sets. A grammar validator and recognizer must scan the actual source and validate each promised pin profile before using a one-bit-per-block discriminator. Complete source bit lengths in the tested gamma-header and one-sign-bit plus three fixed-width-ID record encoding are $N(1)=170,N(2)=402,N(3)=596$. There are $12t$ clause records, $36t$ signed occurrence positions, $5t$ profile values and $2t$ future-pin values to authenticate; SAT witness printing uses $9t$ bits and original checking scans $12t$ clauses. A rejected promise invokes sound exact fallback, which may be exponential.

For an arbitrary typed all-input controller $D$ the still-open recurrence is
\[
W_D(R)\le W_{\rm grammar}+W_{\rm source/index/head}
+W_{\rm discover}+W_{\rm select/switch/failed}
+W_{\rm proof/GE/matroid/cache/replay}
+W_{\rm child/output/guest}+\sum_{R'\in\mathcal C(R)}W_D(R').
\]
Every term includes the actual executed work and concurrently live peak writable/index/ancestor/cache/proof/guest memory. On one branch the free-variable potential decreases, but this does not bound the number of child branches; the signed defect $\delta$ can increase. No free policy discovery or semantic quotient is assumed. Full binary/Gray logical XOR is an \emph{offline diagnostic}, not a lower bound on native physical writes. The Python DPLL counts are not same-machine FLMV time-space measurements. Guest DELAY/COPY/RECOMP, source rereads, and output checks are not omitted.
