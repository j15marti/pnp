\section{Exact wrapper theorem}
\begin{theorem}[\texttt{RECOGNIZABLE-EASY-ISLAND-UNIT-DENSITY-NOGO1}]
Let \(L\subseteq\{0,1\}^*\) be recursive, let \(C\in\mathsf P\) satisfy
\(C\subseteq L\), and let \(A\) be any total exact deterministic decider for
\(L\). There is a total exact uniform deterministic decider
\[
 W_A(x)=\begin{cases}1,&x\in C,\\ A(x),&x\notin C.\end{cases} \tag{2}
\]
On every \(x\in C\), the complete execution consists of recognition and a
constant answer. If recognition costs \(R_C(n)\), then
\[
 T_{W_A}(x)\le R_C(|x|)+O(1),\qquad
 S_{W_A}(x)\le S_{R_C}(|x|)+O(1).                        \tag{3}
\]
It need not invoke \(A\), construct a witness, enumerate a solution relation,
extract or communicate a compatibility object, or reconstruct one. For every
measure \(\nu\) with \(\nu(C)=1\), the fast-path and non-invocation events
have probability one. If \(A\in\mathsf P\), then \(W_A\in\mathsf P\)
globally. The statement for \(C\subseteq\overline L\) holds with output zero.
\end{theorem}
\begin{proof}
Run the polynomial recognizer for \(C\). If it accepts, output the known
constant truth value; otherwise simulate \(A\). The first branch is correct
because \(C\subseteq L\), and the second is correct because \(A\) is total and
exact. Equations (1)--(3), the measure statement, and global polynomiality
when \(A\) is polynomial follow directly. \qed
\end{proof}

This is the monochromatic corollary of PROMFAST1's more general promise-fast-
path equivalence. This report does not re-claim that theorem. Its increment is
to apply it to the exact density repair retained by DENSNOGO1/TAGDILUTE1 and
record the resulting unit-density no-go with all costs and the explicit
semantic object below.

\section{Literature and barrier-transfer preflight}
The obstacles were converting a fixed distribution into hardness for an
arbitrary algorithm and transferring detected semantic structure to ordinary-
machine total cost. Levin fixes both a problem and distribution
\cite{Levin86}; Impagliazzo--Levin make completeness robust across samplable
distributions~\cite{IL90}. These are \textbf{DIRECTLY TRANSFERABLE
DEFINITIONS/THEOREMS} only after a distribution, reduction, and probability-
domination bounds are supplied. They do not say an arbitrary clean-core
distribution is hard; \(D_k\) is a unit-mass easy island.

Impagliazzo's hard-core theorem assumes a quantitative failure rate against a
declared nonuniform model and extracts a hard subdistribution for slightly
smaller circuits~\cite{Imp95}. It is a \textbf{USEFUL STRUCTURAL ANALOGY
REQUIRING A NEW TRANSFER THEOREM}; importing the premise would assume
hardness. Bogdanov--Trevisan limit nonadaptive worst-case-to-average-case
reductions for NP problems unless PH collapses~\cite{BT06}. This is a
\textbf{DIRECT BARRIER IN ITS DECLARED REDUCTION MODEL}, not a theorem against
all possible transfers.

Property-testing queries, communication cuts, VLSI routing, proof size,
branching programs, streaming, pebbling, and control observability are
\textbf{FAILED TRANSFERS} without an all-decider compiler. HEC/CRS-PPC/CCSPC/
RCCN isolate the same missing static-to-online compiler.

The wrapper theorem relativizes and algebrizes: replace \(A\) by an exact
oracle/algebraic-oracle decider and retain the recognizable constant path. No
large constructive circuit property is proposed, so Natural Proofs supplies
neither a proof nor an escape. Nonuniform circuit fallbacks can also be
wrapped by recognition circuits, but do not yield a uniform contradiction.
The arbitrary fallback exponent is preserved off the island. Baker--Gill--
Solovay and Aaronson--Wigderson remain barriers, not premises
\cite{BGS75,AW09}.
