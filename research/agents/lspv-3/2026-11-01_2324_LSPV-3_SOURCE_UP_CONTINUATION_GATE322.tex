\section*{Three exact restricted theorems}
Let R(F,a) delete original clauses already satisfied by a and remove pinned false literals from the other original clauses, preserving source clause IDs. A completely false clause yields DEAD. Let A(F,a) be the inclusion-minimal nonempty residual literal-set antichain, ignoring source IDs only in its semantic cache key and retaining source-proof provenance in a sidecar. Let U(F,a) saturate this antichain by the pointwise identity u\wedge(\neg u\vee D)\equiv u\wedge D, retaining every derived unit clause, deleting satisfied clauses, and removing redundant supersets; contradictory units yield DEAD.
\begin{theorem}
For all valid originals F, all coherent a and every future variable pin sequence in any order, R, A and U denote the same pointwise Boolean cofactor. For a new pin (v=b), applying it to a stored antichain/unit key and renormalizing produces the same literal-set key as recomputing from the source. Neither method needs restoration of earlier pinned values. Proof provenance IDs are separate: a previously discarded clause with a smaller source ID can become textually identical to a retained one, so a unique source-ID representative need not commute.
\end{theorem}
\noindent\emph{Proof.} Clause subsumption C\subseteq D implies C\wedge D\equiv C, and the identity persists under every substitution. Unit simplification is pointwise correct only while retaining the forcing unit. Unit-closure is a confluent least fixed point, or reaches a contradiction. These identities imply cofactor and future-pin preservation, with a source-indexed derivation sidecar.
\begin{theorem}[Source-local antichain record bound]
If both predecessor and successor residuals are non-DEAD, a one-original-variable pin can change at most 16 original source clause IDs in the recomputed subsumption antichain. This is a bound on logical source records, NOT on physical indexed-tape time, writes, or unit-propagation cascades.
\end{theorem}
\noindent\emph{Proof.} Each original variable occurs in exactly four original clauses. An unaffected clause can change antichain membership only via subsumption/equality with one of those changed clauses. Comparable nonempty residual clauses share an original signed literal. Each signed literal occurs in exactly two source clauses, and a changed source clause has three distinct signed literals, hence at most three other comparable source IDs. The affected neighborhood has size at most 4+4(3)=16. DEAD and new resolution/Tseitin clauses are explicitly outside this bound.
