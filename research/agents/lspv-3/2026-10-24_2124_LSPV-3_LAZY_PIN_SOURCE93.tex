\section{Exact ordinary encoding and pin semantics}
Fix valid proper-3CNF $F$ with variables $[n]$ and $m$ clauses, read-only indexed source. Encode two header fields $(n,m)$ and four fields per clause (three signed literal identifiers plus zero delimiter), each of
\[
h(n,m)=\lceil\log_2(64(n+m+1))\rceil\text{ bits},\quad N=(4m+2)h(n,m).
\]
Signed literal $\ell$ is coded by $2|\ell|+[\ell<0]$. An original-variable pin descriptor $P=((v_1,b_1),\dots,(v_p,b_p))$ has strictly increasing distinct $v_j\in[n]$ and bits $b_j$. This descriptor must be generated/validated and kept at $O(p\log N)$ live writable bits in the simple implementation.
For each pin introduce fresh $u_j,z_j$ and all four proper ternaries
\[
 (L_j\vee u_j^{\epsilon}\vee z_j^{\delta}),\quad
 \epsilon,\delta\in\{0,1\},\quad
 L_j=v_j\ (b_j=1),\quad L_j=\neg v_j\ (b_j=0).
\]
Here superscript $1$ is positive and $0$ negated. Reserve $k=4p$ for added ternary clauses. The independent direct-copy ordinary child has
\[
 n'=n+2p,\quad m'=m+k,\quad
 N'=(4m'+2)h(n',m').
 \tag{1}
\]
\begin{lemma}[Exact pins; PROVED/EXACT in declared calculus]
For every assignment $x$ of original variables,
\[
 \exists u,z:\operatorname{Pin}(F,P)(x,u,z)
 \Longleftrightarrow F(x)\land\bigwedge_j[x_{v_j}=b_j].
 \tag{2}
\]
\end{lemma}
\begin{proof}
If $L_j$ is true, all four clauses are true for every $(u_j,z_j)$. If false, the four clauses on $u_j,z_j$ collectively reject every assignment. Eliminating the pair gives precisely $L_j$, independently across pins.
\end{proof}
\begin{theorem}[Charged indexed virtual-input simulator; PROVED/EXACT restricted]
There is a single uniform bit generator $g(F,P,i)$ that returns bit $i$ of the completely serialized ordinary child, for any $0\le i<N'$, in $\operatorname{polylog}(N+2)$ elementary bit steps and $O(\log(N+2))$ writable controller bits \emph{in addition to the charged descriptor $P$}, using the original indexed read-only source. It does not store the full child.
For any fixed exact ordinary SAT decider $A$ with simultaneous time and work-space bounds $T_A,S_A$, intercepting all its virtual input reads gives a correct source-backed pinned-child simulation with
\[
 T_{\rm virt}=O((N+T_A(N'))\operatorname{polylog}(N+2)),\qquad
 S_{\rm virt}\le S_A(N')+O(p\log(N+2)+\log(N+2)).
 \tag{3}
\]
Both bounds apply to the same implementation, with its index tapes, discovery, source access, selection, and retained state counted.
\end{theorem}
\begin{proof}
For output bit $i$, compute the $h(n',m')$-word ordinal and within-word position using logarithmic-bit arithmetic. Header words are $(n',m')$. A word from an original clause is fetched from its old $h(n,m)$-bit source field and re-encoded at the new width. A pin word is derived from the source variable and polarity in $P$, pin-number arithmetic, and the fresh IDs $n+2j+1,n+2j+2$. Each request uses only $O(\log N)$ bits beyond $P$ and polynomially many logarithmic-bit steps. Compile the fixed $A$ into a single simulator, replacing virtual input-head probes by $g$; retain the simulated work/index tapes, and charge full parsing and descriptor preparation within the stated $N\operatorname{polylog}N$ term. The original source remains read-only, not an uncharged writable child buffer. This is an indexed simulation, not a change of virtual input length.
\end{proof}
\begin{theorem}[Two-level pin flattening and length firewall; PROVED/EXACT restricted]
For pin sets $P,Q$ referring to \emph{original source variable identifiers} and agreeing on overlaps, two-level pinning is equisatisfiable to pinning the union:
\[
 \operatorname{SAT}(\operatorname{Pin}(\operatorname{Pin}(F,P),Q))
 =\operatorname{SAT}(\operatorname{Pin}(F,P\cup Q)).
 \tag{4}
\]
Disagreeing overlaps yield UNSAT. With $p\ge1$, the direct-copy ordinary child has strictly greater encoded bit length than its parent:
\[
 \boxed{N'>N}.
 \tag{5}
\]
Any eager complete direct-copy child serialization costs at least $N'$ primitive bit writes. No pin-only child of this form satisfies the ARC $N^{\theta+o(1)}$ ordinary-child length target for $\theta<1$.
\end{theorem}
\begin{proof}
By (2), consistent source pins commute and combine; inconsistent source pins cannot be satisfied. All pin auxiliaries are free when their pin literals hold, so they disappear from the source-named semantic relation. For length, $m'=m+4p>m$ and $h(n',m')\ge h(n,m)$ imply $(4m'+2)h(n',m')>(4m+2)h(n,m)$. This claims no bound for arbitrary equisatisfiable rewrites outside this named direct-copy calculus.
\end{proof}
\section{ARC compatibility and adaptive escape}
A source-backed descriptor $(P,\text{pointer to }F)$ can be short because the entire original $F$ remains available through indexed reads. It is \emph{not} an independently encoded ordinary short SAT child. Conversely requiring all adaptive solvers to materialize the child is unjustified, since the generator in (3) uses no $N'$-bit buffer. This separates SIL semantic equivalence (S0) from charged representation/acquisition (S2), and a BOOL native relation from its foreign/source representation.
SCOPED-BLOCK-REBUILDER92 creates $N^{1/2+o(1)}$ fully serialized children of \emph{local event blocks on a promised low-frontier stream}; it is not contradicted by the whole-source pin-only firewall.
