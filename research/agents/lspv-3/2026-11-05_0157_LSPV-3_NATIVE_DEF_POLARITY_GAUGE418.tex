\section*{Theorem: exact source-fixed output-value gauge}
Let $F$ be any finite valid original CNF over original variables $X$ and let $D$ be ANY native legal acyclic prefix of $a$ separate globally fresh paid definitions
\[
D:\qquad z_i=f_i(u_i,v_i)\quad (i=1,\ldots,a),
\]
where each input occurrence is an original variable or an earlier defined output and $f_i:\{0,1\}^2\to\{0,1\}$ is an arbitrary binary Boolean truth table, including functions independent of one argument. Repeated input occurrences and reconvergent sharing are permitted. Set $\delta(x)=0$ for every original $x\in X$, and assign arbitrarily chosen bits $\delta(z_i)=\delta_i$ to the paid output names. Define
\[
\boxed{f_i^\delta(s,t)=f_i(s\oplus\delta(u_i),t\oplus\delta(v_i))\oplus\delta_i}.
\]
Use these truth tables with the same source $F$, same gate names and input slots, and same $a$ paid native DEF nodes to obtain $D^\delta$.

\begin{theorem}
For every $F,D,\delta$, $\Phi_\delta(x)=x$ on original variables and $\Phi_\delta(z_i)=z_i\oplus\delta_i$ on paid gate values induces a bijection
\[
\operatorname{Mod}(F\wedge D)\cong\operatorname{Mod}(F\wedge D^\delta).
\]
Every original assignment still has a unique gate extension, and the source projection and DEF charged count are unchanged. For a fixed original assignment, all $2^a$ values of $\delta$ produce distinct fully labelled vectors of internal output values. This is a source-FIXED representational symmetry, not a signed permutation of original source literals.
\end{theorem}
\begin{proof}
Induct over the unchanged topological gate order. Original input values coincide. If a gate input value in the transformed run is $b\oplus\delta(u)$, then the defining formula applied to both transformed inputs returns $f_i(b,c)\oplus\delta_i$, exactly the flipped old output. Each new table remains a total two-input function and preserves the fresh output identity. Applying the same coordinate flip twice is the inverse; thus the correspondence is bijective. For different $\delta$ at least one named output value differs on any fixed original valuation. No SAT oracle or optimization search occurs.
\end{proof}

\boxed{\bigoplus_{v\in S}v'=b\oplus\bigoplus_{v\in S}\delta(v)}.
\]

\begin{proof}
A signed literal is preserved when its polarity is XOR-shifted by its wire's polarity bit. Substitute $v=v'\oplus\delta(v)$ in the affine row and collect its constant terms on the right. All these facts are syntactic/algebraic consequences of bijective coordinate substitution.
\end{proof}
