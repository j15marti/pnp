\section{Declared source semantics and exact child construction}
A valid closed scoped stream has events OPEN(v), CLAUSE(three signed distinct live variables), and CLOSE(v). Each variable is opened once, remains live at all intervening uses, and is eventually closed. With n opened variables, m clauses, live width w and event count L=2n+m, fix the bit encoding
\[
 h(n,m)=\lceil\log_2(64(n+m+1))\rceil,\qquad
 N=(2+4n+4m)h(n,m).
\]
Partition the L events into consecutive blocks of at most \(b=\lceil\sqrt L\rceil\) events. At boundary i let \(S_i\) be the set of \emph{named} live source variables and let \(u_i:S_i\to\{0,1\}\) be one complete shared assignment.

For a block and entry/exit assignments \(u,v\), first open every entering variable under a compact local identifier and pin it to the indicated entry bit. Replay the source events, preserving every clause and renaming freshly opened local variables. A source CLOSE is postponed only when the same variable remains active across the exit cut. Pin all exit variables, and finally close every remaining local variable. A pin \(z=1\) is encoded by four clauses
\[
(z\vee a\vee b),(z\vee a\vee\neg b),
(z\vee\neg a\vee b),(z\vee\neg a\vee\neg b)
\]
using two fresh locally opened and closed auxiliary variables. To pin \(z=0\), replace \(z\) with \(\neg z\). Any inconsistent value on \(S_{i-1}\cap S_i\) is rejected at the parent without a child call. Each child is a valid closed scoped stream and also determines an \emph{ordinary, independently serialized} proper 3CNF by forgetting event tags and emitting its numbered clauses and header.

\begin{theorem}[Source-name-preserving scoped child and join]
For every valid closed source stream E, every block i and each consistent pair (u,v) of boundary assignments, the generated ordinary child is satisfiable if and only if the clauses of block i admit an internal extension respecting u and v. Its live width is at most w+2. With
\[
 R_i(u,v)=[u|_{S_{i-1}\cap S_i}=v|_{S_{i-1}\cap S_i}]
          \land \operatorname{SAT}(\operatorname{Child}_i(u,v)),
\]
one has
\[
 \operatorname{SAT}(E)
 \iff \exists u_0,\ldots,u_q\;
          \bigwedge_{i=1}^q R_i(u_{i-1},u_i),
 \qquad u_0=u_q=\emptyset.
\tag{1}
\]
At most \(q2^{2w}\) ordinary child SAT calls are needed.
\end{theorem}
\begin{proof}
The child renaming is injective, and existentially eliminating the private pin auxiliaries enforces exactly the assigned entry/exit values. During left pins at most w boundary variables plus two auxiliaries are active; source replay has exactly the original live variables; right pins again add at most two. Thus width is at most w+2. A global source witness yields a compatible tuple of local child witnesses. Conversely adjacent cuts agree on each original variable spanning a cut; contiguous live intervals propagate a unique value across all its blocks. Every source clause is satisfied, proving (1). Each cut has at most \(2^w\) bit assignments, bounding the candidate pairs.
\end{proof}

\section{Joint resource accounting and fixed-depth recursion}
For a growing family with \(w=o(\log N)\), the number of blocks is \(N^{1/2+o(1)}\), the number of pin pairs per block is \(2^{2w}=N^{o(1)}\), and an ordinary child including every header, literal, local name and pin gadget has \(N^{1/2+o(1)}\) bits. A paid initial source pass computes boundary names and source offsets. Storing all cut sets and offsets takes \(N^{1/2+o(1)}\) writable bits. Sequential child construction uses one charged readable child buffer and releases it after the query. Source reads, candidate selection, failed tests, skips, caches, gluing and live ancestor buffers are included. For one ordinary all-input SAT decider A with simultaneous bounds \((t,s)\), the restricted scoped wrapper has
\[
 T_{\rm scoped}\le N^{\max\{1,\frac12+\frac t2\}+o(1)},\qquad
 S_{\rm scoped}\le N^{\max\{\frac12,\frac s2\}+o(1)}.
\tag{2}
\]
These two bounds concern the same composed implementation and incur polylogarithmic random-access machine overhead, not a free output tape. They are promised-stream bounds, not points in the ordinary all-input SAT achievable region.

The serialized child also has a valid scoped-event presentation, permitting a second generation under the same theorem. If a child is extremely short, a promised \(w_j=o(\log N_j)\) denominator may fail; Role 4 PAD-FLOOR-SCOPED87 supplies a \emph{separately proved} charged padding of a valid \emph{closed} child with independent satisfiable triples, placing its encoded length at \(N_j^{1/2+o(1)}\) while changing live width by at most a constant. The accompanying code checks actual unpadded two-level semantics and reports actual child lengths; it does not implement or independently verify that padding repair.

\section{Independent source-checkable experiment}
The stdlib reproducer validates source scopes; produces exact ordinary pin children; compares their labels with an independent brute-force extension check on a full set of tested boundary pairs; performs a dynamic-programming named join; and tests two levels of construction. It uses an independent exact DPLL leaf procedure, never an answer oracle. There are 21 source controls, 14 SAT and 7 UNSAT, covering affine/XOR, Horn, padded 2SAT, disconnected components, the eight-ternary minimal UNSAT core and its SAT deletions, and a connected pair of shared-variable contradictory/equal pin blocks. On the first twelve examples, 1,462 individual boundary-pair child semantics were checked against independent enumeration; no discrepancy was observed. Largest two-level run: 1,643 distinct memoized leaf calls.

Repeated-three-variable-clause scaling inputs with 100, 1,000 and 10,000 source clauses had respectively (source bits, child bits, source width, child width)
\[
 (5382,2376,3,5),\quad(64224,3666,3,5),\quad
 (800280,7812,3,5).
\]
Small children can exceed their parent length because pins dominate; these are finite checks, not an asymptotic complexity proof.
