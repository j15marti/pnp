\section{Exact local extremes and experiment}
Let $F=\bigwedge_{j=0}^{m-1}C_j$ be a proper width-$r$ CNF with distinct variables inside each clause. Original signed occurrence $x_{i,j}$ is not a separately assignable variable. With negative sign bit $\nu_{i,j}$, local $S_j$ (all literals TRUE) requires $a_i=1\oplus\nu_{i,j}$, local $U_j$ (all literals FALSE) requires $a_i=\nu_{i,j}$; $\overline S_j=U_j$ and $\overline U_j=S_j$. Actual disjunctive SAT only requires at least one TRUE literal. For original clauses $j,h$ with shared same-sign set $I_=$ and opposite-sign set $I_{\ne}$, the exact four-way compatibility matrix is
\[
 SS=UU\iff I_{\ne}=\varnothing,\qquad SU=US\iff I_==\varnothing.
\]
This already-known clause-indexed theorem was independently checked, not claimed as new. Under one globally coherent full assignment $a$, $t_j(\bar a)=r-t_j(a)$; for $r=3$, $N_h(\bar a)=N_{3-h}(a)$. Endpoints $0^n,1^n$ and multi-flip trails are diagnostics, not formula UNSAT certificates.
\section{Exact signed-clause conflict cover}
Let $H(F)$ have one vertex per original clause and an edge between clauses with an opposite-sign shared original variable. The following is a direct signed backdoor to unate SAT, using familiar graph vertex cover, not a general SAT improvement.
\begin{theorem}[Exact projection to exception-variable support]
Suppose $M$ is a vertex cover of $H(F)$ with $|M|=k$, and let $T=\bigcup_{j\in M}\mathrm{Var}(C_j)$, so $|T|\le rk$. All clauses outside $M$ are jointly local all-literals-TRUE ($S$) on some globally coherent assignment. In particular, every variable outside $T$ has a unique sign among all its source occurrences. Assign every such variable its literal-satisfying value. Then
\[
 F\in\mathrm{SAT}\iff F|_{a^*}\in\mathrm{SAT},\qquad
 \mathrm{Var}(F|_{a^*})\subseteq T.
\]
Every projected assignment $b\in\{0,1\}^T$ that fails has an original source clause $C_j$ supported entirely in $T$ and falsified by $b$. Its source index certifies that the whole subcube with fixed $T$ values is impossible. With supplied cover, exact SAT/UNSAT decision by enumeration and original-source checking costs $O(2^{rk}N)$ indexed-RAM time, plus source storage and optional $O(2^{rk}rk)$ output bits for recorded failed cubes.
\end{theorem}
\begin{proof}
Were a source variable assigned both signs among undeleted clauses, the corresponding pair would form an edge whose endpoints avoid $M$, contradicting vertex cover. A variable outside $T$ never occurs in a deleted clause, so its sign is uniform throughout $F$. Assigning it its preferred value can only satisfy additional source clauses and cannot destroy a true one. Every clause that survives has all its support inside $T$. The exact equivalence follows, as does the original-clause whole-cube certificate for every failed projected pattern.
\end{proof}
\begin{corollary}[Charged FPT decision, fixed width]
Compute $H(F)$ by enumerating indexed opposite-sign occurrence pairs and find a $k$-vertex cover by exhaustive two-way edge branching. A conservative uniform indexed-RAM upper bound, including failed cover branches, is
\[
 O\bigl(N+\sum_i d_i^+d_i^-+2^k|E(H)|+2^{rk}N\bigr).
\]
The input and adjacency storage are $O(N+|E(H)|\log m)$ bits up to index costs. Explicitly emitting every $SS/SU/US/UU$ pair matrix and the endpoint/flip traces adds $O(m^2r+nmr)$ operations and $O(m^2)$ or more output bits. For fixed $r$ and a fixed constant $c$, instances whose minimum clause-conflict cover has $k\le c\log_2N$ admit uniform polynomial-time exact decision. If the budgeted cover search fails, use a complete fallback solver; it does not infer UNSAT.
\end{corollary}
\section{Constructive SAT repair and sharp obstruction}
\begin{theorem}[Protected literal repair for $k<r$]
If proper width-$r$ CNF has a clause conflict cover of size $k<r$, the formula is SAT. Start at the coherent assignment making every undeleted core clause all-$S$. Sequentially process each of the $k$ exceptional clauses. When one is already true, protect the variable of an actually true literal; when false, flip one unprotected variable in that clause and protect it. Every step preserves earlier protected exceptions, and at most $k<r$ flips cannot falsify any initially all-TRUE width-$r$ core clause. This constructs an original-source-checkable SAT witness after at most $k$ flips. For width three, $k\le2$ guarantees SAT.
\end{theorem}
\begin{proof}
At the $j$-th exception, at most $j-1<r$ variables are protected, so a false width-$r$ clause has an unprotected variable to flip. Once a true literal is protected, that clause stays true. Every core clause began with $r$ true literals and at most $k<r$ distinct variables can flip, so it remains true.
\end{proof}
\begin{theorem}[Sharp UNSAT family at $k=r$]
For $r\ge2$, partition $r^2$ variables into $r$ disjoint $r$-element sets $B_1,\ldots,B_r$. Include all $\binom{r^2}{r}$ positive width-$r$ clauses and the $r$ negative clauses $\bigvee_{x\in B_i}\neg x$. The result is UNSAT and the minimum vertex cover of $H(F)$ is exactly $r$.
\end{theorem}
\begin{proof}
Every negative clause demands at least one zero; disjoint supports force $r$ different zeros, which falsify one of the all-positive $r$-clauses. Deleting the $r$ negative clauses makes the rest unate and conflict-free, giving cover size at most $r$. The $r$ disjoint edges matching each negative $B_i$ to its positive $B_i$ clause force every vertex cover to contain at least $r$ vertices. Thus a proposed extension of the $k<r$ SAT theorem to $k\le r$ is \textbf{FALSIFIED}.
\end{proof}
\section{Strict signed exact-(2,2)-3CNF firewall}
For each original variable in a strict exact-(2+,2-) 3CNF, any unate retained core must delete at least its two positive occurrences or its two negative occurrences. A size-$k$ exception cover deletes only $3k$ literal occurrences, so $3k\ge2n$. With $m=4n/3$, $k\ge m/2$. Thus this particular logarithmic-cover method does not give an all-input polynomial algorithm for the growing strict22 class. A signed-extreme conflict is not an UNSAT rule: true disjunctions with mixed 1/2 literal counts can satisfy both originals.
