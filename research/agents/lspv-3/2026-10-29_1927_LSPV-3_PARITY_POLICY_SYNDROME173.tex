\begin{theorem} Every terminating exact transcript of linear bit probes spans the requested target parity. \end{theorem}
\begin{proof} If not, choose a kernel vector orthogonal to all queried rows but not to the target row. This creates two indistinguishable input vectors with opposite answers, contradicting correctness. A spanning set suffices by XOR of queried values. \end{proof}

\section{Source model, contextual values and costs}
Fix a public family $\mathcal E\subseteq\binom{[m]}3$ and unknown data $\theta\in\mathbb F_2^m$. The physical read-only input contains each raw bit $\theta_i$ and a previously materialized parity bit $p_E=\bigoplus_{i\in E}\theta_i$ for every triple $E\in\mathcal E$. Original coordinate source reads are legal and are charged. Each indexed probe of one available bit costs one \emph{data probe} and corresponds to a public measurement vector $a=e_i$ or $a=\mathbf1_E$, of weight one or three. Building the parity image from raw data is a separate construction task and is not free if undertaken during the measured computation. The target $t\cdot\theta$ has public $t\ne0$ but no supplied answer. Deterministic adaptive methods, caching, representation switching and polynomial workspace are permitted.

For a consistent observed transcript $S$ with queried row span $V(S)$ define two \emph{independent of runtime} functions:
\[
\Phi_t(S)=\mathbf1[t\notin V(S)],\qquad
\Gamma_t(S)=\left|\operatorname{supp}(t)\setminus
\bigcup_{a\in S}\operatorname{supp}(a)\right|.
\]
The first is certified target uncertainty, equal to one bit of conditional Shannon entropy under a \emph{declared} uniform prior. The second is uncovered target support, a necessary but insufficient condition for being able to compute the answer. Neither is the unknown optimal remaining SAT runtime. Gaussian rank and bitset calculations evaluate these functions in polynomial time, but the calculation cost must be charged. Use the user's contextual annotation
\[
a\mid_{v_\Phi},\quad v_\Phi(a\mid S)=\Phi_t(S)-\Phi_t(S+a),\quad
v_\Gamma(a\mid S)=\Gamma_t(S)-\Gamma_t(S+a).
\]
The pipe is a value label, not probability conditioning or divisibility. Acquisition, authentication, verification, score discovery, application and switching constitute a distinct cost $C_S(a)$. The ratio $v_\Phi/\max(1,C_S(a))$ is a heuristic, not a proven policy.

\begin{theorem}[Exact all-adaptive probe-depth equality, PROVED/EXACT]
Let $\mathcal A=\{e_1,\ldots,e_m\}\cup\{\mathbf1_E:E\in\mathcal E\}$. The optimal worst-case number of data probes, even among arbitrary deterministic adaptive exact controllers, equals
\[
D_{\mathcal E}(t)=\min\{|J|:J\subseteq\mathcal A,\ \bigoplus_{a\in J}a=t\}.
\]
\end{theorem}
\begin{proof}
The initial theorem establishes span necessity on every actual leaf. The set of leaf rows contains an XOR representation of $t$ and thus at least $D_{\mathcal E}(t)$ rows. Conversely query any minimizing XOR representation without adaptation and XOR the observed data bits. Its correctness holds for both possible output labels. Determining the minimizing set is a \emph{separate} planning cost.
\end{proof}

\begin{theorem}[Required endpoint and bounded primitive progress, PROVED/EXACT]
For every correct adaptive execution including any data-dependent preprocessing, the initial support potential is $\Gamma_t(S_0)=|\operatorname{supp}(t)|$, its terminal value is zero, and every source probe decreases it by between zero and three. Hence
\[
P_{\rm data}+Q_{\rm data}\ge\left\lceil|\operatorname{supp}(t)|/3\right\rceil.
\]
\end{theorem}
\begin{proof}
At termination the observed span contains $t$, so the union of observed row supports necessarily contains all target-one coordinates. Each row touches at most three coordinates. Summing the \emph{actual} contextual decreases telescopes from the initial gap to zero, including repeated probes and strategies that fail to progress. If discovery reads data it belongs to $P$. A newly supplied global parity probe would invalidate the maximum-three premise and the resulting floor; this is a deliberately restricted probe lower bound, not a RAM or SAT lower bound.
\end{proof}
