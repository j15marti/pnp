\section*{Published hardness and the unchanged proof model}
Urquhart (1987) and Ben-Sasson--Wigderson (2001) establish exponential ordinary unrestricted DAG-Resolution size on odd Tseitin CNFs over bounded-degree expanding graphs. For a cubic expander family with $h$ vertices, the signed CNF has $n=3h/2$ original edge variables, $m=4h$ width-three original clauses, and ASCII DIMACS encoded bit length $N=\Theta(h\log h)$. The established Resolution bound is $W_{\rm Res}(F_h)\ge 2^{\Omega(h)}$; it is not a bound on unrestricted SAT decision time.

Keep the fixed original $R_{\mathrm{mix341}}$ of LSPV-2 report 341 (blob c87acd11d32ccfc3b7acd3667ef11daeb60079cb). Every authenticated source clause costs zero; strict Resolution, local AND3, GF$(2)$ XOR, paid conservative signed two-input DEF, and checked LOCAL-CONVERT are each unit-cost binary-or-unary inference nodes. The paper's previously certified exact full-system optimum on bridgeless cubic odd Tseitin sources is $W_{R_{\mathrm{mix341}}}(F_h)=4h-1$: $3h$ local AND3 nodes extract all vertex parity equations, then $h-1$ XOR nodes derive $0=1$. This is prior mathematics, not a new hardness theorem.

\section*{New rigorous width invariant of the pure-XOR phase}
Let $G=(V,E)$ be any connected graph with $h=|V|\ge4$ and odd charges $b_v$ such that $\bigoplus_v b_v=1$. Let $R_v$ be the authentic vertex equation $\bigoplus_{e\ni v}x_e=b_v$. Define the edge expansion
\[
\beta(G)=\min_{\varnothing\ne S\subsetneq V}
\frac{|\delta(S)|}{\min(|S|,h-|S|)} .
\]
A pure-XOR proof is an arbitrary shared binary DAG with sources precisely $R_v$, all internal nodes obtained by GF$(2)$ row addition, and root $0=1$. Its row width is the number of original edge variables with nonzero coefficient.

\begin{theorem}[Unavoidable balanced cut, including arbitrary sharing]
Every such pure-XOR refutation $\pi$ has an intermediate row with
\[
\operatorname{width}(\pi)\ge \frac{\beta(G)h}{3}.
\]
Its minimum number of paid XOR operations is exactly $h-1$. Consequently on a constant-expansion cubic family,
\[
\min_{\pi}\operatorname{width}(\pi)=\Theta(h)=\Theta(N/\log N),
\qquad
\min_{\pi}\#\mathrm{XOR\ nodes}=h-1.
\]
These minima refer to different statistics; no assertion that the same proof minimizes both is needed.
\end{theorem}
\begin{proof}
Let $B$ be the $h$ by $|E|$ vertex-edge incidence matrix over $\mathbb F_2$. Connectedness gives $\ker(B^T)=\langle\mathbf1_h\rangle$. As $\mathbf1_h^Tb=1$, the augmented row matrix $[B\mid b]$ has rank $h$. Therefore each derived affine equation uniquely identifies a coefficient vector $c\in\mathbb F_2^h$ of original vertex rows. Sources have vectors $e_v$ and every XOR step takes the symmetric difference of its predecessors' supports, regardless of DAG sharing or canceling duplicate ancestors. The root $0=1$ has coefficient vector $\mathbf1_h$.

Take the earliest root-ancestor node in any topological order with support size strictly above $h/3$. Each parent has support size at most $h/3$, so this node has coefficient support $S$ satisfying $h/3<|S|\le2h/3$. Its edge-variable support is precisely the boundary $\delta(S)$, since summing incidence rows cancels internal edges. Hence its width is at least $\beta(G)\min(|S|,h-|S|)\ge\beta(G)h/3$. The node is not the root, whose affine width is zero.

For node count, any proper subset of the vertex incidence rows is independent, so every one of the $h$ source equations is indispensable to a contradiction. The connected binary-source ancestry graph has at least $h-1$ paid nodes. An arbitrary binary tree sums all vertex equations in exactly $h-1$ steps, attaining the bound.
\end{proof}

\section*{What the theorem does not transfer}
This exact cut-width invariant covers every XOR-only DAG, with shared subderivations, canceled paths, redundant operations and free after-the-fact optimal selection. It does \emph{not} cover alternative full-$R_{\mathrm{mix341}}$ refutations using Resolution, conservative definitions, named LOCAL-CONVERT circuit wires or other switches. One unit-cost XOR of two wide rows is still one charged logical node. Explicit row output, verification work, memory and proof discovery are additional costs, not lower bounds on the logical minimum without a separate model-preserving theorem. The width lower bound therefore does not establish a superpolynomial lower bound on $\overline W_{R_{\mathrm{mix341}}}$.
