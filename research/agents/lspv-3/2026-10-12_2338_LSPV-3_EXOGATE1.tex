\begin{abstract}
P versus NP remains \OPEN.  MODELBRIDGE-0026 leaves an exogenous online
challenge as a possible repair for fixed-cut hiding.  This report proves a
model trilemma.  If a challenge-augmented protocol is an exact SAT decider for
every legal challenge string, a uniformly constructible canonical challenge
can be fixed and internally supplied, yielding an ordinary uniform
deterministic polynomial-time decider.  Freshness is then not invariant under
equivalent implementations.  If correctness holds only with bounded error
over fresh challenges, the protocol is randomized; RANDCLOSE1 already places
the polynomial-depth staticized version in $\mathsf P$ under the $P=NP$
counterfactual, and the deterministic FLMV endpoint does not directly apply.
If correctness or timing depends on one privileged external sequence, the
sequence/timer is advice or oracle/environment access, again a different
model.  Thus exogenous freshness alone cannot supply the missing deterministic
static-SAT bridge.  The full causal compiler remains open only in a strengthened
form that survives canonical fixing and reaches a matched endpoint.
\end{abstract}

\section{Exact model and quantifiers}

For each input length $n$, let $\Gamma_n\subseteq\{0,1\}^{q(n)}$ be a
nonempty legal challenge set, where $q$ is polynomial.  Assume a uniformly
constructible canonical member $g_0(n)\in\Gamma_n$ and a polynomial reveal
schedule.  A challenge protocol is a uniform deterministic machine
\[
                 C(x,g)\in\{0,1\},                            \tag{1}
\]
running in time and space polynomial in $|x|+|g|$.  Online revelation means
that prefixes of $g$ are withheld until their declared reveal events; it does
not make $g$ disappear from the machine model.

Exact static-SAT correctness has the quantifier order
\[
 \forall x\ \forall g\in\Gamma_{|x|}:\quad C(x,g)=\SAT(x).   \tag{2}
\]
Bounded-error correctness instead states
\[
 \forall x:\quad
 \Pr_{g\leftarrow D_{|x|}}[C(x,g)=\SAT(x)]\ge 2/3.            \tag{3}
\]
A privileged-sequence rule states correctness only for one external
$G=(g_n)_n$, possibly unavailable to a uniform program.  These are different
computational objects and may not be interchanged in one SAME\_REALIZATION
ledger.

Charged costs include challenge generation or acquisition, timing/reveal,
input scans, preprocessing, retained state, response generation, rereading,
recomputation, validation, reconstruction, and the decision output.  A
physical wall clock, random beacon, hidden table, or environment callback is
not free ordinary-machine state.

\section{Canonical fixing theorem and trilemma}

\begin{theorem}[\claim{EXOGENOUS-CHALLENGE-MODEL-TRILEMMA1}]
Let $C$ and $(\Gamma_n,g_0(n))$ satisfy the explicit uniform polynomial model
above.
\begin{enumerate}[label=(\roman*)]
\item If (2) holds, then
\[
                    B(x)=C(x,g_0(|x|))                       \tag{4}
\]
is an ordinary uniform deterministic exact SAT decider with polynomial
overhead.  Its implementation may generate the canonical challenge and its
reveal events internally.
\item If only (3) holds, the resulting language computation is randomized
(in $\mathsf{BPP}$, or $\mathsf{BPP}^{\mathsf{NP}}$ when adaptive NP calls
are present), not an ordinary deterministic exact decider.
\item If correctness is guaranteed only for one external nonuniform sequence
$G$, then $G$ is advice/oracle/environment information unless a uniform
polynomial generator is supplied.  With such a generator the construction
returns to case (i).
\end{enumerate}
\end{theorem}

\begin{proof}
For (i), uniform construction of $g_0(n)$ and its reveal schedule adds only
polynomial work.  Equation (2) evaluated at $g=g_0(n)$ proves (4) exact.
Because the value and schedule are generated inside $B$, no future challenge
is unpredictable to that implementation.  All work is charged in the one
simulation.

Statement (ii) is the definition of a bounded-error probabilistic machine
after regarding $g$ as its coin string.  Fixing one arbitrary $g$ need not
preserve correctness for every $x$.  Statement (iii) follows from whether the
external sequence can be uniformly generated.  If not, the machine receives
information not produced by the ordinary program/input; if yes, substitute
the generator as in (i).
\end{proof}

\begin{corollary}[Freshness is not an extensional deterministic invariant]
Suppose a compiler maps every ordinary deterministic SAT decider to an exact
challenge protocol satisfying (2).  Fixing $g_0$ and internalizing its reveal
schedule yields an extensionally equivalent ordinary program.  Therefore a
resource claim justified only by the unpredictability of the challenge to the
compiled presentation does not cover every equivalent implementation.
\end{corollary}

The corollary does not falsify all possible causal lower bounds.  A surviving
theorem may impose an online interface as part of its declared problem, or
prove an all-challenge lower bound that still holds for $g_0$.  What fails is
the silent transfer from that interface to unrestricted deterministic static
SAT.

\section{Primary-literature and barrier-transfer audit}

Gill's probabilistic Turing-machine model formalizes computation with unbiased
coin outcomes\footnote{J.~Gill, ``Computational complexity of probabilistic
Turing machines,'' \emph{SIAM J. Comput.} 6(4), 1977, 675--695,
\url{https://doi.org/10.1137/0206049}.}.  This is a
\textbf{directly transferable model classification}: a polynomial fresh
challenge string used with bounded error is randomized input, not a
deterministic exact run.

Sipser and Lautemann place BPP in the polynomial hierarchy\footnote{M.~Sipser,
``A complexity theoretic approach to randomness,'' STOC 1983, 330--335,
\url{https://doi.org/10.1145/800061.808762}; C.~Lautemann, ``BPP and the
polynomial hierarchy,'' \emph{Information Processing Letters} 17(4), 1983,
215--217, \url{https://doi.org/10.1016/0020-0190(83)90044-3}.}.  Their
theorems transfer exactly to RANDCLOSE1's class-level conditional closure,
not to a deterministic SAME\_REALIZATION lower bound.

Fortnow--Lipton--van Melkebeek--Viglas prove a deterministic random-access
SAT time--space exclusion in their stated model\footnote{L.~Fortnow,
R.~Lipton, D.~van Melkebeek and A.~Viglas, ``Time-space lower bounds for
satisfiability,'' \emph{J. ACM} 52(6), 2005, 835--865,
\url{https://doi.org/10.1145/1101821.1101822}.}.  This is a
\textbf{direct theorem transfer only after model matching}; it does not cover
a machine reading a random beacon, advice sequence, or physical timer.
Interactive challenges, VLSI clocking, distributed communication cuts, and
control-system observability are \textbf{useful structural analogies requiring
a new transfer theorem}.  Treating a random oracle, cryptographic beacon, or
proof-system challenge as an unconditional ordinary-SAT obstruction is a
\textbf{misleading analogy / failed transfer}.

\section{Hostile controls and exact scope}

Horn propagation, 2SAT implication SCC, affine Gaussian elimination, and
bounded-treewidth dynamic programming can answer their controls after a
challenge without retaining a chosen compatibility representation.
Independent products can stream component answers into one bit.  Padding and
redundant clauses can alter timing/reveal alignment.  Alternate encodings and
compact circuit/branching-program implementations can replace the named audit
object.  DEAD/COPY/DELAY change elapsed time; INTERP and RECOMP change
representation and replay.  A valid universal compiler must survive all of
these and may not infer runtime from semantic-state count.

The theorem relativizes: an oracle challenge tape remains an oracle tape.  It
also survives algebraic oracle access, so it supplies no nonalgebrizing hinge.
Natural-Proofs largeness/constructivity is not invoked.  Nonuniformity is
explicitly separated in case (iii).  Arbitrary polynomial exponents remain
machine-dependent; no single hidden exponent is assumed.  The one-bit output
is charged and is the only static SAT semantic obligation.

 |\operatorname{im}L_x|\ge

are an \textbf{EXACT OBJECT/THEOREM TRANSFER}.  The finite audit exhibits

\section{Stale or overstated claims found}

Any claim that ``the solver cannot know the future random block, therefore it
must use superpolynomial time/space on static SAT'' is overstated.  Under exact
all-challenge correctness, the canonical block may be fixed; under bounded
error the computation is randomized; under a privileged stream the model is
nonuniform or oracle-like.  Calling a wall-clock or beacon event ``free'' in
the deterministic FLMV ledger is likewise stale.  Freshness can enforce
causal order in a declared online model, but does not itself transfer that
model's lower bound to ordinary SAT.

\section{Smallest repair and handoff}

Replace \claim{EXOGENOUS-CHALLENGE-COMPILER1} by the sharper target
\claim{FIXING-ROBUST-EXOGENOUS-COMPILER1}:
\begin{quote}
For every uniform deterministic polynomial-time exact SAT decider $A$, build
one fully charged causal protocol $C_A$ that is exact for every legal
challenge.  Prove an unconditional resource lower bound for $C_A$ that holds
also for a uniformly constructible canonical challenge and its internally
generated reveal schedule.  Then place that same ordinary deterministic
realization in a cited forbidden endpoint, with exponents independent of
$A$'s unknown polynomial degree.
\end{quote}
If the lower bound is only distributional over challenges, the repair must
instead supply a randomized endpoint with matching error, time, space and
machine conventions.  No such transfer is currently verified.
