\section{Exact obstruction, target and prior research}
The exact obstruction is the attempted use of complete-state checkpoint XOR as a \emph{policy-selection invariant} for a uniformly charged adaptive controller. A metric cannot select among policies if it gives exactly the same cumulative score to all their source-correct actions while their actual source-probe, head-move, and policy-acquisition costs differ. Worse, source-correct SAT and UNSAT fixtures can have identical complete logical checkpoint traces. The one canonical complete target is D\"ocker's duplicate-free proper clausewise-monotone 3-SAT-(2,2), with three distinct same-sign literals in each clause and exactly two occurrences of each variable of each sign, including rejection of malformed strings. Ordinary proper strict-2P2N remains a comparison superset, not a separate hardness target.

The earlier project XOR-STATE-DIFFERENCE-REFEREE249 and ARC-XOR-INDEX-RESET281 already separated logical state from physical tapes, and LSPV-1 ARC-INDEX-RECHARGE283 established $D_{\rm all}\le2qT$ on initially blank FLMV index tapes under its explicit model. This report does \emph{not} claim those results. It proves a more specialized exact order-invariance identity and tests what that identity says about source-aware policy selection. Primary literature D\"ocker \cite{docker}, FLMV \cite{flmv}, and SAT backdoors \cite{backdoors} is consulted; no prior-literature novelty is claimed for classical Gray codes or SAT endpoints.

\end{enumerate}

\section{New exact trajectory lemma and proof}
For a source $F$ with $n$ variables and $m$ proper same-sign three-literal clauses, let $a\in\{0,1\}^n$, and $t_j(a)\in\{0,1,2,3\}$ count TRUE literals in \emph{original} clause $j$. Define the fully aligned logical vector
\[
 S_g(a)=a\;\|\;\big\|_{j=1}^m\left(g_0(t_j(a)),g_1(t_j(a)),[t_j(a)>0]\right),
\]
where $g(t)$ is the ordinary two-bit binary code of $t$ or the two-bit reflected Gray code $t\oplus(t\gg1)$. This is an \emph{offline} source-indexed logical vector; the notation is not the native FLMV writable configuration.

\begin{theorem}[Order-independent source logical XOR]
For every proper clausewise-monotone width-three CNF $F$ (SAT or UNSAT) and every permutation $\pi$ of its $n$ variables, let $a^{(0)}=0^n$ and let $a^{(r)}$ result by flipping $\pi(r)$ from zero to one. Then for ordinary binary clause counts
\[
 \boxed{\sum_{r=1}^{n}d_H(S_{\rm bin}(a^{(r-1)}),S_{\rm bin}(a^{(r)}))=n+5m,\qquad
 d_H(S_{\rm bin}(0^n),S_{\rm bin}(1^n))=n+3m.}
\]
For reflected Gray clause counts,
\[
 \boxed{\sum_{r=1}^{n}d_H(S_{\rm Gray}(a^{(r-1)}),S_{\rm Gray}(a^{(r)}))=n+4m,\qquad
 d_H(S_{\rm Gray}(0^n),S_{\rm Gray}(1^n))=n+2m.}
\]
For each valid canonical (2,2) source $m=4n/3$, hence the four values are $23n/3$, $5n$, $19n/3$, and $11n/3$ respectively. The result holds regardless of SAT label and clause topology.
\end{theorem}
\begin{proof}
Every variable changes exactly once, adding exactly $n$ assignment-bit transitions. In each positive original clause, the three flips of its variables increase its local true count along $0,1,2,3$, in an order irrelevant to the sequence of counts; in each negative original clause they decrease its count along $3,2,1,0$. Binary count transitions have Hamming lengths $1,2,1$, totaling four. Gray count transitions have lengths $1,1,1$, totaling three. The clause satisfaction flag changes once and exactly once on either monotone path. Thus each of the $m$ clauses contributes respectively five or four adjacent bit changes. Endpoints use binary $00\leftrightarrow11$, of Hamming length two, or Gray $00\leftrightarrow10$, of Hamming length one, plus one changed satisfaction bit per clause. All cells are disjoint in the fixed aligned vector. This proves every expression. The 2P2N grammar has $4n$ signed occurrences and $3m$ occurrences per clause, so $m=4n/3$.
\end{proof}
\paragraph{Physical interpretation.} If a particular controller \emph{explicitly} maintains this entire fixed-location vector and physically rewrites each changed bit, its data writes equal the adjacent XOR total, excluding initialization. Another controller can store only an assignment mask, paying one physical data-bit write per flipped variable and extra source reads to recompute $t_j$. Even an eager source-indexed updater needs occurrence-list construction, address/tape-head moves, valid source and index access, and retained ancestor state. Full XOR measurement has computational cost if performed online; it is free only to an \emph{offline auditor}. Native FLMV index tapes admit atomic whole-index erasures, so an unrestricted per-transition $d_{\rm all}/k$ transfer is false without the LSPV-1 recharge correction. This theorem proves neither a universal physical write requirement nor SAT hardness.

\section{Exact two-source switch lemma}
\begin{lemma}[Equality-subcube invisibility of a legal source-occurrence switch]
Suppose a source has two same-polarity clauses $C_p=(x_a\lor R)$ and $C_q=(x_b\lor Q)$ and the second source swaps $x_a$ and $x_b$ between those same clause IDs, leaving all other signed occurrences untouched and retaining properness. For every coherent complete assignment $z$ satisfying $z_a=z_b$, all \emph{original indexed clause true-literal counts} agree between the two sources. Consequently any deterministic policy receiving only original-indexed clause-status observations along a sequence entirely within $z_a=z_b$ receives an identical sequence, even when the two whole formulas have opposite SAT labels. This is not a barrier against source-bit inspection or queries outside that subcube.
\end{lemma}
\begin{proof}
The two replaced positive literals have the same truth value when $z_a=z_b$, so their respective clauses retain precisely the same number of TRUE literals, while all other clauses are unchanged. The negative-polarity case is symmetric. Any deterministic observation-based controller receiving the same initial state and same answers follows the same trace by induction. Direct source reading can detect the differing original clause records and is outside the observation-only restriction.
\end{proof}

For the original Döcker $U_{198}$ UNSAT source, swapping positive variables $196$ and $197$ at zero-based clause IDs $2$ and $44$ gives the still-valid $V_{198}$ SAT instance. The full 198-bit $V$ witness in the machine-readable archive satisfies all 264 original $V$ clauses and falsifies original $U$ clause $2$. Both sources are valid same-target inputs. The independent prior original-source $U$ refutation is rerun: six exhausted module cofactors (3,666 total DPLL proof nodes), followed by the exact 64-row six-variable boundary contradiction. The equality-subcube identity was independently checked at 500 random assignments, and the producer checked 1,024 additional coherent assignments. Therefore a status-only algorithm limited to this subcube cannot distinguish the labels; source inspection or a relevant unequal query may distinguish them, and its cost must be charged. No unconditional lower bound follows.
