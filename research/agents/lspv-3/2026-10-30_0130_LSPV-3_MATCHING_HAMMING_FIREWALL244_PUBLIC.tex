\section{Polynomial matching control in strict signed exact-(2+,2-)}
Fix any coherent complete anchor $a$, let $H_a=\{j:t_j(a)=0\}$ and $q=|H_a|$. Let $\tau_a$ be the minimum cardinality of an original-variable set hitting all supports of $C_j$ for $j\in H_a$. Build graph $G_a$ with vertices $H_a$ and an edge between $j,k$ for every source variable appearing in both falsified clauses. A source variable incident to one falsified clause acts as a singleton cover. In strict signed exact-(2+,2-)-3CNF, each original variable appears in at most two falsified clauses at \emph{any} anchor: only its two same-polarity original occurrences can be false.

\begin{theorem}[Matching endpoint repair, restricted]\label{thm:matching}
If every source variable occurs in at most two anchor-falsified original clauses, and $\nu(G_a)$ denotes maximum matching cardinality, then
\[
\boxed{\tau_a=q-\nu(G_a).}
\]
A variable set attaining this number can be constructed with Edmonds matching and explicit original-source edge labels in polynomial time. Every complete SAT witness $b$ satisfies $d_H(a,b)\ge\tau_a$.
\end{theorem}
\begin{proof}
Repairing an originally false clause requires flipping a variable in its support. One variable covers at most two graph vertices, so the task is minimum edge/singleton cover. A maximum matching covers $2\nu$ vertices with $\nu$ variables; selecting one source variable for each of the other $q-2\nu$ vertices covers all in $q-\nu$ flips. Conversely the elementary edge-cover/matching identity yields the lower bound $q-\nu$. Flipping these variables makes each originally false clause true; other clauses need not remain true. Every full model must repair all originally false clauses. A polynomial maximum matching algorithm is known (Edmonds, 1965).
\end{proof}

\section{Falsification: Hamming-subcube certificates cannot beat source UP}
\begin{theorem}[Ordinary partial-cube UP dominance, any CNF]\label{thm:UP}
Let $F$ be any CNF, $a$ a coherent full assignment, and $\tau_a$ the exact support-hitting number of original clauses falsified at $a$. If every full completion of an ordinary original-variable partial assignment $\rho$ lies inside $d_H(a,b)<\tau_a$, then some original $C_j\in H_a$ is already falsified by $\rho$. Therefore the corresponding Hamming-ball exclusion rejects no UP-surviving original-variable DPLL partial cube.
\end{theorem}
\begin{proof}
Write $D=\{i\in\mathrm{dom}(\rho):\rho_i\ne a_i\}$ and $U=[n]\setminus\mathrm{dom}(\rho)$. The largest possible Hamming distance among completions is $|D|+|U|$, attained by flipping every free coordinate. The hypothesis implies $|D\cup U|<\tau_a$. Thus $D\cup U$ is not a hitting set of the anchor-falsified source clauses. Some $C_j\in H_a$ has support disjoint from $D\cup U$, so its variables are pinned as in $a$, where $C_j$ is FALSE. This source clause is already empty under $\rho$. \end{proof}
\noindent The theorem also holds for any certified lower bound $r\le\tau_a$, not merely the exact matching value. It does NOT exclude other proof-carrying resolvent, failed-literal, 2SAT, Horn or XOR prunes, cardinality-constrained search, nor a direct verified SAT witness. It is a negative statement about this one proposed mechanism, not a universal SAT lower bound.
