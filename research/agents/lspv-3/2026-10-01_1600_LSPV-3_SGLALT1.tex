\section*{LSPV-3: a relativized $\Sigma_2$ alternative to the conservative $k^4$ ledger}
\textbf{STATUS: OPEN.} P versus NP remains open. This report improves a conditional deterministic upper-bound ledger under explicit model-matching assumptions. It proves no SAT lower bound, no necessity theorem, and no nonrelativizing hinge.

\paragraph{CORPUS REVIEWED.}
Reviewed repository governance and reconstruction protocol, root \texttt{main.tex}, MAIN 1558 and relevant earlier MAIN snapshots, LSPV-3 FIXCOIN1/QREC1/RECDEP1/DEPDEF1/DEPSWAP1/TRIVUNI1/NOGUARD1, and the relevant LSPV-4 hostile audits. Repository search found no prior use of the quantitative Sipser--G\'acs--Lautemann $\Sigma_2$ simulation as a competing reconstruction exponent path.

\paragraph{Primary literature.}
Lautemann proves $\mathrm{BPP}\subseteq\Sigma_2^P$. Viola records the quantitative, relativizing form
\[
\mathrm{BPTime}(t)\subseteq\Sigma_2\mathrm{Time}(t^2\log t)
\]
and reviews the normalized $t=n$ construction: guess $n$ shifts, universally choose a random string, and evaluate the randomized machine on all $n$ shifted strings. Thus the matrix performs $O(t)$ machine evaluations and $t^{2+o(1)}$ nonoracle work. Viola's newer alternative
\[
\mathrm{BPTime}(t)\subseteq\Sigma_3\mathrm{Time}(t\,\mathrm{polylog}\,t)
\]
also relativizes. van Melkebeek--Mocelin Sdroievski supply the reconstruction architecture used here; each sampled reconstruction run makes a constant family of parallel SAT queries.

\paragraph{Existing dependency obstruction retained.}
The post-Viola late-substitution prefix can be
\[
\exists\sigma\;\forall u\;\exists z\;\forall y\;R.
\]
DEPSWAP1 correctly shows that generic $\exists z\,\forall y$ to $\forall y\,\exists z$ commutation is invalid. TRIVUNI1 correctly shows that any dependency uniformizer must beat the charged $A\circ D_j$ baseline. These results remain exact.

\paragraph{PROVED/EXACT symbolic composition lemma.}
Let a probabilistic reconstruction machine $M^{\mathrm{SAT}}$ have oracle-time
\[
t=N^{\alpha_0+o(1)},
\]
make $O(1)$ SAT queries per run, and produce query formulas of length at most
\[
t^{b_0+o(1)}.
\]
Assume an exact deterministic SAT decider $A$ runs on length-$S$ formulas in time
\[
S^{\kappa+o(1)}.
\]
Apply the oracle-relativizing Sipser--G\'acs--Lautemann simulation \emph{before} replacing SAT by $A$. Its $\Sigma_2$ matrix runs $M^{\mathrm{SAT}}$ on $O(t\,\mathrm{polylog}\,t)$ shifted random tapes. Replacing all resulting SAT calls by $A$ costs
\[
t^{1+b_0\kappa+o(1)}
\]
in total, while nonoracle matrix work is $t^{2+o(1)}$. Hence matrix time is
\[
\boxed{t^{c_0+o(1)},\qquad c_0=\max\{2,1+b_0\kappa\}.}
\]

If the remaining $\exists\forall$ blocks are conservatively eliminated with the same SAT decider and model-matched computation-to-SAT exponents $b_1,b_2$, then
\[
\boxed{
\alpha_{\rm det}
\le
\alpha_0 b_1b_2\kappa^2\max\{2,1+b_0\kappa\}
+o(1).
}
\]
The algebra above is exact under the stated query-count, query-length, and compiler hypotheses. Its application to the project is \textbf{CONDITIONAL} until those hypotheses are model matched for the actual vMS reconstructor.

\paragraph{Unit-compiler comparison.}
For $b_0=b_1=b_2=1$ and $\kappa\ge1$,
\[
\boxed{\alpha_{\rm det}\le\alpha_0(\kappa^3+\kappa^2)+o(1).}
\]
The current unit-compiler Viola route is
\[
\alpha_{\rm det}\le\alpha_0\kappa^4+o(1).
\]
Therefore the best of these two architectures gives
\[
\boxed{
\alpha_{\rm det}\le
\alpha_0\min\{\kappa^4,\kappa^3+\kappa^2\}+o(1).
}
\]
The SGL route is smaller exactly when
\[
\kappa^2>\kappa+1,
\quad\text{i.e.}\quad
\kappa>\frac{1+\sqrt5}{2}.
\]
This is an upper-bound comparison, not an optimality theorem.

\paragraph{Why this avoids the failed swap.}
The new route never commutes the dependent final universal block through Viola's last existential selector. Instead it replaces the whole probabilistic computation by a classical relativizing two-alternation simulation. The price is the quadratic SGL matrix. Thus dependency uniformization remains a possible route to an even cheaper simulation, but is no longer the only route to improving the $k^4$ ledger.

\paragraph{Eager-elimination control.}
If SAT is first simulated by $A$ and SGL is applied afterward, the schematic unit-compiler cost is about $2\alpha_0\kappa^3$. Relativizing first is better because SGL repeats the oracle machine only $O(t)$ times while each run has only $O(1)$ SAT queries; it does not square the cost of $A$.
