\section{Exact source, prior results, and model conventions}
Use the earlier independently generated source
$E_m(a,b)$ with $m\ge1$, $a,b\in\{0,1\}^m$, $168m$
original variable names, $224m$ unique proper ternary original clauses,
each variable having exactly two positive and two negative occurrences.
The layout is LEFT$(a)$, a fixed bit-independent GAP, RIGHT$(b)$.
Each side uses $m$ copies of a 106-clause unit gadget:
the 19-clause source $Q=W_1\setminus\{(p\vee q\vee r)\}$
forces $p=q=r=0$, and the side's clause $(s x_i\vee p\vee q)$
forces signed $x_i$; its immediately following dummy clause uses the
opposite sign of $x_i$. Remaining $J$-padding and $K_{3,3}$ GAP clauses
do not depend on $a,b$. Consequently
\begin{equation}
\SAT(E_m(a,b))\Longleftrightarrow a=b. \tag{1}
\end{equation}
SOURCE-LOCAL-RAM-TAPE-CERT136 already supplies a 343-record
source-authenticated resolution refutation for each mismatch using
40 \emph{distinct original clauses} (19 $Q$ clauses and one sign clause
from each shore) and source-name-preserving actual descendants.
The new result is the \emph{indexed RAM acquisition lower bound},
which report 136 did not claim, and its exact adversarial quantifier.
We inherit, without relabeling as new, the $Q/J$ construction,
40-clause proof, and sequential-input crossing-sequence results.

Write $w=\lfloor\log_2(168m)\rfloor+1$.
For the declared fixed-width indexed binary encoding, there are
$3w+3$ header bits and three records of $(w+1)$ bits per clause, hence
\begin{equation}
N_m=3w+3+672m(w+1)=\Theta(m\log(m+2)). \tag{2}
\end{equation}
The first bit of each literal record is its sign, followed by the
unchanged $w$-bit positive original-variable identifier.
The header, source length, clause count, variable identifiers,
and clause positions are independent of $a,b$.
This is a valid canonical promise encoding, \emph{not} arbitrary DIMACS
or an all-ordinary-input machine without normalization.

RAT-bit means a deterministic indexed-input Turing machine whose
\emph{informative source probes} return individual input bits,
and whose address preparation, instruction control, writes, and reads
are separately counted in its bit time. In a log-word RAM,
a probe reads a contiguous word of at most $C\log_2 N_m$ bits,
for one fixed constant $C$; arbitrary-width unit-cost words are excluded.
M1 is a one-head read/write-input one-tape TM, and Mk has one sequential
read-only input head plus fixed $k$ sequential work tapes.
No crossing-sequence theorem is transplanted to RAT.

\begin{lemma}[Two and only two changing positions per shore/coordinate]
\label{lem:locality}
For fixed $m$ and all $a,b$, toggling only $a_i$ or only $b_i$
changes exactly two binary source bits: the sign of $x_i$ in that shore's
authentic sign-forcing clause and its immediately following dummy clause.
Every other input bit is identical. The changing-position sets for
different (shore,coordinate) pairs are disjoint; consecutive coordinate
groups on the same shore start $106\cdot3(w+1)$ input bits apart.
\end{lemma}
\begin{proof}
The unit source $Q$, its name allocation, dummy auxiliaries and all $J$
clauses depend on the index $i$ and the shore but not on the bit value.
The literal sign in $(s x_i\vee p\vee q)$ is precisely $s$.
The dummy clause contains $-s x_i$, and no other clause depends on $s$.
All other clauses, identifiers, offsets, GAP rows and headers remain fixed.
Each source side occupies 106 consecutive ternary rows per coordinate;
the two first-literal sign fields are distinct, proving the location
claim and disjointness. \qed
\end{proof}

\begin{theorem}[RAM indexed-probe floor, restricted exact-$(2,2)$ promise]
\label{th:yes}
Fix $m\ge1$ and \emph{any} deterministic, total, exact indexed
bit-probe algorithm $D$ correctly returning both SAT and UNSAT on
\emph{every} $E_m(a,b)$, with no secret $a,b$ supplied as advice.
On each YES input $E_m(a,a)$ the executed trace must inspect
at least one changing bit in LEFT coordinate $i$ and one changing
bit in RIGHT coordinate $i$, for \emph{every} $i$. In particular
\begin{equation}
\boxed{Q_{\rm RAT,bit}(E_m(a,a))\ge2m.} \tag{3}
\end{equation}
The same promise language on a RAM with word width
$O(\log N_m)$ requires $\Omega(m)$ source-word reads on every YES
input. Neither claim implies a superlinear random-access bit-time
exponent: there is an exact promise algorithm with
$T_{\rm RAT}=O(m\,\mathrm{polylog}N_m)=N_m^{1+o(1)}$
and peak index/writable $S_{\rm RAT}=O(\log N_m)$.
\end{theorem}
\begin{proof}
Fix an arbitrary $a$ and execute $D$ on $E_m(a,a)$.
Suppose the trace never reads either of the two variable sign bits in
RIGHT coordinate $i$. Change only $b_i$, producing
$E_m(a,a\oplus e_i)$, which is UNSAT by (1).
Lemma~\ref{lem:locality} says every queried input bit has precisely
the same value in the two physical inputs. By induction on deterministic
steps the complete machine trace, including all adaptive addresses and
output, is identical, a contradiction. Therefore one changing RIGHT
sign bit must be inspected for each $i$. Independently toggling
$a_i$ yields the analogous LEFT requirement. All $2m$ sets are
disjoint. This proves (3) on \emph{every} equality input, not merely
an averaged or existential instance.

For a word RAM, each length-$O(\log N_m)$ contiguous word intersects
at most $O(1)$ of the $2m$ sign-field groups: adjacent groups on a
shore are separated by $\Theta(\log N_m)$ times the fixed 106-clause
block, while the two shores are physically separated.
One read can satisfy only $O(1)$ distinct mandatory groups,
so $\Omega(m)$ word reads are needed for fixed word-width constant.
Conversely a uniform indexed comparator generates each sign-field
address from $m,i$ and the fixed 106-clause layout, reads the LEFT and
RIGHT signs, and stops on the first mismatch. Bit-index construction
and comparison cost $\mathrm{polylog}N_m$ per coordinate, with
$O(\log N_m)$ live indexes. On the fixed canonical promise (1)
guarantees correctness for both labels. \qed
\end{proof}

\begin{theorem}[UNSAT-only unique-mismatch locator lower bound]
\label{th:no}
Fix LEFT $a=0^m$, and promise that RIGHT $b=e_i$ for an unknown
$i\in\{1,\ldots,m\}$, so \emph{every} input is UNSAT.
Any deterministic indexed bit-probe locator that must output
the index $i$ of an authentic two-shore 40-clause contradiction
has worst-case at least $m-1$ independently tested coordinate groups.
The bound is attained by probing $m-1$ RIGHT sign fields and inferring
the last index if all observations are zero. With $O(\log N)$-bit
contiguous RAM words, the corresponding bound is $\Omega(m)$ word reads
for fixed word-width constant.
\end{theorem}
\begin{proof}
All input records except RIGHT sign groups are identical on the
$m$ promised inputs. One right-group probe reveals only whether that
single candidate coordinate equals $i$; querying any other source
bit yields no information about $i$. On an all-zero observation path,
with two or more unqueried candidates, a deterministic locator cannot
output either candidate correctly on both inputs. Thus it must test
at least $m-1$ different candidate groups in the worst case.
Testing $m-1$ candidates sequentially and using the exactly-one
promise gives equality. The proof concerns an \emph{index-returning
local-certificate selector}, not every possible proof DAG finder
or unrestricted SAT decider. \qed
\end{proof}

\section{Certificate polarity, exact 40-clause join, and genuine levels}
An UNSAT input has an index $i$ with $a_i\ne b_i$.
The 19 original $Q$ clauses on each shore imply both local
$-\!p$ and $-\!q$, and the two authentic original sign clauses then
force complementary truth values of THE SAME original name $x_i$.
This is a 40-clause UNSAT original-source subcollection,
and the prior 343-record resolution transcript supplies
individually checkable source IDs, parent lines, pivots and the
empty final clause. Both YES and NO labels are exact.
For SAT input $E_m(a,a)$ no valid source-authenticated UNSAT
resolution certificate can exist because every valid source subset
is satisfiable under the exhibited whole-source model.
For every NO input one such accepted certificate exists.

Thus nondeterministically \emph{guessing} $i$ and its O$(\log N_m)$-bit
constant-record resolution proof is allowed for a correctly clocked
coNTIME verifier on this \emph{promise subfamily}. With a full syntax
scan and proof replay, a total ordinary-CNF verifier rejects malformed
certificates and timeouts, and must never accept a SAT source.
On a validated exact22 canonical promise, direct indexed
authentication of a constant number of source records can cost
$\mathrm{polylog}N_m$ bit time and $O(\log N_m)$ space; without the promise,
full canonical-format checking costs $N_m^{1+o(1)}$ time.
Deterministically discovering $i$ is the separate task constrained by
Theorems~\ref{th:yes}--\ref{th:no}. In particular a guessed coordinate
and an executed, charged search are \emph{not} interchangeable.

For $m\ge3$ and a unique mismatch at coordinate $i$, choose
distinct $j,k\ne i$ with equal source bit values. Append
an authentic four-clause proper ternary PIN of $x_j$ to make
a real ordinary SAT child, and a fresh PIN of $x_k$ to make
its real grandchild. Preserve literally identical original names
and all original source clauses, update actual bit headers and
auxiliary identifiers, and reauthenticate the same 40 source rows.
Both descendants remain UNSAT. Their source sizes \emph{grow},
so neither is eligible as an $N^\lambda$ child for fixed $\lambda<1$;
this supplies semantic inheritance, not ARC contraction.

\paragraph{Duplication and contradiction audit.}
SOURCE-LOCAL-RAM-TAPE-CERT136 already proved O$(\log N)$
source-local Resolution certificates and a RAM
$N^{1+o(1)}$ \emph{upper} bound; it did not establish the matching
indexed source-probe lower bound or the no-only promised index-finder
minimax theorem. That distinction is this report's new result.
CONNECTED-SPLICE133 previously falsified the inference
that connectedness and a global large backdoor force long proofs;
this report does not revive it. A-LEAF-SPECTRUM135's lower
bound is only for its explicit source-subformula $A$ grammar and
does not transfer to cutting planes, unrestricted DAG/semantic
children, or arbitrary SAT deciders. SOURCE-CUT-QBF-BARRIER128
forbids free generic source-to-child lifts.
Previous single-head transport statements remain model-local.

\paragraph{Relativization, algebraization, and representation.}
The adversary uses only literal changing source fields and is a
classical deterministic decision-tree argument; it relativizes,
cannot itself exclude stronger SAT oracles, and has no
Natural-Proofs/circuit lower-bound consequence. An oracle delivering
the mismatch index would invalidate the query lower bound because
it changes the model. Clause projection, compact proof length,
Schur squares, PC degree or hardware switches are not promoted
into general RAM bit-time lower bounds. Nor can a scan-before-solve
wrapper be treated as a necessary behavior of an arbitrary solver.
