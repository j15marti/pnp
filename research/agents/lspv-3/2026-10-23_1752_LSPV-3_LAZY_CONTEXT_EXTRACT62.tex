\section{Three falsifiable constructions}
\noindent \textbf{A. A source-accessible conditional query compiler.}
Given any proper-3CNF and arbitrary boundary assignment, append fresh ordinary proper-3CNF forcing gadgets and query the original, possibly DELAY-padded, exact SAT decider. The exact all-input transport succeeds; the calls remain at parent-comparable size and give no ARC time-exponent contraction.
\par\noindent \textbf{B. External witness extraction.}
Use the same compiler to turn any total exact one-bit SAT decider into a witness finder on YES inputs, with at most $n+1$ charged invocations and no promised UNSAT proof on NO inputs. The construction succeeds without assuming the original decider internally constructs a witness.
\par\noindent \textbf{C. Large exact residual quotient with easy root and online contexts.}
Exhibit ordinary proper-3CNF with $2^{h-1}$ distinct nonempty projected residual Boolean functions, SAT and UNSAT partial contexts, and a source-verified $O(N)$ recognizer followed by a one-bit context decision. This refutes any universal implication from residual-function diversity to superpolynomial decision time.

\section{Exact all-input proper-3CNF contextual transport}
Fix a canonical densely named ordinary proper-3CNF input $F$ with $n$ occurring variables, $m$ clauses and actual encoded bit length $N$. Let $I$ be any set of $h\le n$ source-variable indices with specified Boolean assignment $\alpha$. Define, with fresh pairwise disjoint variables $a_i,b_i$,
\[
G(\ell;a,b)=\bigwedge_{\epsilon,\delta\in\{-1,+1\}}
(\ell\lor\epsilon a\lor\delta b).
\]
Each gadget comprises four proper ternary clauses and $\exists a,b\,G(\ell;a,b)\leftrightarrow\ell$.
Set
\[
C(F,I,\alpha)=F\wedge\bigwedge_{i\in I}G(\ell_i(\alpha);a_i,b_i),
\quad
\ell_i(\alpha)=\begin{cases}x_i&\alpha_i=1\\\neg x_i&\alpha_i=0.\end{cases}
\]
All $F$ clauses and their original variable identifiers remain unchanged. The child has exactly $n'=n+2h$ variables and $m'=m+4h$ clauses, with $k=4h$ newly added ternaries and no eliminated original variables ($d=0$). This uses $k$ only for added ternaries and $d$ only for eliminated variables; no residual-work bound is asserted.

\begin{theorem}[All-input source-coherent contextual simulation: PROVED/EXACT]
For every valid $F,I,\alpha$,
\[
\mathrm{SAT}(C(F,I,\alpha))\iff
\exists\beta\;F(\alpha,\beta).
\]
For \emph{every} total uniform deterministic exact proper-3SAT decider $A$, irrespective of its internal strategy or DELAY padding, an external uniform algorithm produces the exact answer to that restriction by one fully charged call to $A$ on $C(F,I,\alpha)$.
\end{theorem}
\begin{proof}
If $F$ has a satisfying assignment extending $\alpha$, then each gadget's designated literal is true, and all its four clauses hold regardless of the fresh variables. Conversely, the conjunction of four clauses in a gadget is inconsistent when its designated literal is false (the four possible truth assignments to the fresh pair are all excluded). Hence every satisfying child assignment respects $\alpha$ and satisfies the unchanged $F$. Calling any correct $A$ gives the exact answer. No property of $A$'s code, output trace, witness reconstruction, or internal state is assumed.
\end{proof}

For a fixed-width signed-literal source representation with
$w=1+\lceil\log_2(\max\{n,m\}+1)\rceil$ bits per signed literal and two header words, $N=(3m+2)w$ and
\[
N'=(3m+12h+2)\left[1+\left\lceil
\log_2(\max\{n+2h,m+4h\}+1)\right\rceil\right].
\]
The numerical formula uses the same declared fixed-width convention at source and target. The independent Python audit instead also records \emph{actual ASCII DIMACS byte counts}; those must not be substituted into this fixed-width identity.

A safe bit-time charge for parsing, rewriting and output is
$P(N,N',h)=O((N+N'+h)\log(N+N'+2))$ on a deterministic bit machine, with one complete original-source read per call and one fully written child. Peak storage is $O(N'+h\log(n+2))+S_A(N')$ bits if the child is materialized and the supplied decider uses $S_A$ workspace. The child's write length, every failed SAT child call, source rereads and original-variable mapping are included. Running time per query is at most $P+T_A(N')$ (where $T_A$ is a worst-case bound at child length); on a particular execution the \emph{actual} time of $A$ is charged. For $T_A(L)=L^D$ a DELAY-padded solver incurs its full $(N')^D$ term. No $N^{t/2}$ invocation follows.

\begin{theorem}[Charged decision-to-witness simulation: PROVED/EXACT]
For every exact proper-3SAT decider $A$, there is a uniform exact external SAT witness finder making one root call and, only on SAT inputs, at most $n$ further calls to $A$ on source-preserving proper-3CNFs of length at most
\[
L=O((m+n)\log(m+n+2)).
\]
Its time is
$O\bigl((n+1)[(N+L)\log(N+L+2)+T_A(L)]\bigr)$
and peak space is $O(L+n\log n+S_A(L))$, besides the model's read-only source and A's call stack.
\end{theorem}
\begin{proof}
Query $A(F)$ first and stop on UNSAT. Otherwise process source variables in fixed order. Given a prefix known extendible, test its extension with the next variable fixed to zero using $C$. If SAT, retain zero; if UNSAT, retain one, which must be extendible because the original prefix was. Continue, retaining only a current prefix and a reusable child buffer. After $n$ steps, output and replay-check the original assignment. Every queried child is exactly source-coherent, including failed branches. On UNSAT sources only the root decision is returned; no short UNSAT proof is asserted. The bounds charge $n$ source scans, $n$ child rewrites and $n+1$ full decider runs, not the resources of the original single run.
\end{proof}

\section{A large quotient with elementary root and contextual decision}
For $h\ge1$ take boundary variables $X=(x_1,\dots,x_h)$ and interior variables $Y=(y_1,\dots,y_h)$, and fresh disjoint $p_i,q_i,a,b$. Construct
\[
\begin{split}
E_h(X,Y,D)=\bigwedge_{i=1}^h[&
(\neg x_i\lor y_i\lor p_i)\wedge
(\neg x_i\lor y_i\lor\neg p_i)\\
&\wedge(x_i\lor\neg y_i\lor q_i)\wedge
(x_i\lor\neg y_i\lor\neg q_i)]\wedge G(y_1;a,b).
\end{split}
\]
This is a genuine ordinary proper-3CNF with $n=4h+2$ variables and $m=4h+4$ clauses. Each duplicated binary pair enforces $x_i\leftrightarrow y_i$. The final gadget enforces $y_1=1$.
\begin{theorem}[Exponential residual diversity, linear acquisition: PROVED/EXACT]
For every $\alpha\in\{0,1\}^h$, the projected residual function on $Y$ is
\[
f_\alpha(Y)=[\alpha_1=1]\cdot\prod_{i=1}^h [y_i=\alpha_i].
\]
There are exactly $2^{h-1}$ pairwise different nonempty residual functions and one empty residual function, and exactly half the boundary assignments have SAT extensions. Nevertheless, $E_h$ itself is SAT. A complete source-aware canonical recognizer validates $E_h$ in $O(N)$ word/bit-input-order work and, following validation, answers each SAT context by reading just $\alpha_1$. It can produce the unique projected $Y$ witness by copying $\alpha$ in $O(h)$ time.
\end{theorem}
\begin{proof}
Existentially eliminating each $p_i,q_i$ leaves the equality $x_i=y_i$, and eliminating $a,b$ leaves $y_1=1$. Restriction $X=\alpha$ therefore forces $Y=\alpha$ and is consistent exactly when $\alpha_1=1$. These singletons are pairwise distinct. The source pattern can be checked against its full explicit ordinary clause sequence in a single charged scan. The specialized algorithm may fall back to exhaustive exact 3SAT on any noncanonical source, yielding a total uniform exact decider. It is polynomial on this family without storing a table of contexts.
\end{proof}
This does \emph{not} contradict MAIN85's static, source-closed state lower bound: the query explicitly carries $\alpha$, the source may be retained or reread when charged, and the entire family of functions is succinctly parameterized by $\alpha$. Nor does it establish that arbitrary formulas have cheap contextual semantics. A static complete truth-table output would incur its own output charge, whereas an online evaluator need not emit every context.

For an independent global UNSAT control, add $G(\neg x_1;c,d)$ with new $c,d$, conflicting with $y_1=1$ and $x_1=y_1$. The resulting valid proper-3CNF has $n=4h+4,m=4h+8$.
