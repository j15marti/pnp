\begin{abstract}
P versus NP remains \OPEN.  This run attacks the surviving proposal that a
``paid provenance'' or typed causal slice can distinguish semantic SAT work
from the cheap source transport exposed by SERIALTRACE1.  For every total
deterministic decider $A$, a uniform same-realization wrapper computes source
parity $p$, copies it to $q$, runs $A$ to obtain $a$, and returns
$y=(a\oplus p)\oplus q=a$.  Every source bit is a pointwise causal ancestor of
the output; intervening on either live parity path alone flips the output; and
the wrapper really pays a linear scan.  Nevertheless the two paths cancel,
the terminal view contains at most $(a,p)$, and the full prefix trace merely
serializes the source.  Thus path ancestry, liveness, full sensitivity, and
``some paid input-dependent work'' do not certify compatibility computation.
The exact repair must be $H$-specific and construction-specific, which is the
missing universal transfer rather than a consequence of causal terminology.
A bounded audit passed 188,668 assertions over 8,190 binary sources, 65,520
interventions, seven SAT/control families, three encodings, and 126 wrapper
checks.
\end{abstract}

\section{Exact model, compatibility object, and target}
Let $x=\langle F,\alpha\rangle\in\{0,1\}^N$ be a fixed self-delimiting
encoding of a 3-CNF $F$ and partial assignment $\alpha$.  Define
\[
 H(F,\alpha)=\{\beta:\alpha\cup\beta\models F\},\qquad
 h(F,\alpha)={\bf 1}[H(F,\alpha)\ne\varnothing].
\]
Let $\mathcal C_N$ contain all well-formed encoded 3-CNF/partial-assignment
pairs of length $N$.  It includes Horn, 2SAT-encoded, affine/Tseitin,
bounded-treewidth, independent-product, padded, redundant, and signed proper
3CNF controls; a universal theorem may not silently discard them.

Fix any uniform total deterministic decider $A$ with read-only input and one
answer bit $a=A(x)$.  Its exact mutable trace is
$\operatorname{Tr}_A(x)$.  Every scan, reset, copy, XOR, intervention
observation, extraction, reconstruction, and later semantic evaluation is
charged in encoded length $N$.  The candidate attacked is the implication
\[
 \begin{split}
 &\text{a retained trace cell lies on a source-to-output causal path, is}\\
 &\text{individually intervention-live, and costs the run nonzero work}
 \quad\Longrightarrow\quad
 \text{the run paid for an $H$-specific semantic object.}
 \end{split}
\]
The conclusion is stronger than mere source dependence.  Without it, a
source transport or checksum is incorrectly promoted to SAT-semantic work.

\section{The cancellation theorem}

\begin{theorem}[\claim{CAUSAL-LIVENESS-CANCELLATION1}]
For every uniform total deterministic decider $A$ there is a uniform total
decider $W[A]$ such that, for every $x\in\{0,1\}^N$:
\begin{enumerate}[label=(\roman*)]
\item $W[A](x)=A(x)$ in the same realized execution;
\item $T_{W[A]}(N)\le T_A(N)+cN+c$ and
      $S_{W[A]}(N)\le S_A(N)+c$ for a machine-dependent constant $c$;
\item every source bit is an ancestor of the returned bit in the wrapper's
      structural dataflow graph, and the two parity-path variables are each
      individually intervention-live at the output;
\item the terminal wrapper view is determined by the pair $(A(x),p(x))$,
      where $p(x)=\bigoplus_{i=1}^N x_i$, so it need not determine the full
      compatibility relation $H$;
\item retaining the whole prefix-parity trace makes the view source-injective,
      but only by serial source transport: $x_i=p_{i-1}\oplus p_i$.
\end{enumerate}
\end{theorem}

\begin{proof}
On a first left-to-right scan set
\[
 p_0=0,\qquad p_i=p_{i-1}\oplus x_i\quad(1\le i\le N),
 \qquad p=p_N,qquad q=p.
\]
Reset the input head, run $A$ once to obtain $a$, and execute
\[
 z=a\oplus p,\qquad y=z\oplus q.
\]
Because $p=q$, $y=a$ identically.  The added work is one scan, one head reset,
one copy and two XORs; $p,q,z$ occupy constant auxiliary bits.  Thus (i) and
(ii) hold with all wrapper costs charged.

In the structural equations, for each $i$ there is a directed path
$X_i\leadsto p\to z\to y$, and a second path
$X_i\leadsto q\to y$.  For every source and every coordinate, toggling $x_i$
toggles both $p$ and $q$.  If $a$ and $q$ are held fixed, the intervention
$\mathrm{do}(p\leftarrow p\oplus1)$ flips $y$; symmetrically, holding $a,p$
fixed and intervening on $q$ flips $y$.  Hence the paths are not dead state,
proving (iii).  Under a natural source change both paths toggle and cancel.

The tuple $(a,p,q,z,y)$ equals
$(a,p,p,a\oplus p,a)$, proving (iv).  For an explicit collision family,
take the eight satisfiable 3CNFs on variables $u_1,u_2,u_3$ that force each of
the eight assignments by clauses $(\ell_i\vee\ell_i\vee\ell_i)$.  They have
eight distinct solution relations and the same decision bit.  The parity bit
has only two values, so two formulas have the same terminal view and different
$H$.  Finally, consecutive prefix parities recover each encoded source bit,
proving (v).
\end{proof}

\begin{corollary}[P versus NP counterfactual]
If $\SAT\in\mathsf P$ and $A$ is any fixed polynomial-time SAT decider, then
$W[A]$ is another uniform polynomial-time SAT decider with the live causal
structure above.  If $T_A(N)=N^{k+O(1)}$, the wrapper remains
$N^{k+O(1)}+O(N)$; the unknown exponent $k$ is not reduced and no
unconditional time, space, circuit, branching-program, or communication lower
bound is contradicted.
\end{corollary}

\section{Why the natural repairs still miss the bridge}
The theorem gives a three-way audit.
\begin{description}[leftmargin=3.7cm,style=nextline]
\item[Path/ancestry semantics.]
The wrapper passes: every input bit has a live path to the answer, even under
individual interventions.  This criterion is therefore \RETIRED{} as a
certificate of $H$-specific work.
\item[Net input--output influence.]
Cancellation is removed, but the resulting object is exactly the sensitivity
of the one-bit language decision $A(x)$.  It is constant within every
same-answer fiber and does not expose the compatibility relation.
\item[Whole causal trace.]
The prefix trace recovers the source, agreeing with SERIALTRACE1.  Any external
algorithm can then evaluate $H$ only by additional charged work; that work was
not performed by the original deciding execution.
\item[$H$-specific causal type.]
Requiring a retained variable to be sound and complete for $H$, invariant or
covariant under cancellation, COPY, INTERP, and RECOMP, states the missing
\claim{CANCELLATION-ROBUST-H-SPECIFIC-TRANSFER1}.  It is \OPEN{}, not supplied
by generic causal ancestry.
\end{description}

This also closes a possible ``paid'' loophole.  The parity scan really costs
$\Theta(N)$, but its charge is affine source processing.  A positive charge
without a model-matched lower bound on an $H$-specific task cannot be promoted
to a superpolynomial contradiction.

\section{Barrier and primary-literature preflight}
The two obstacles identified before substantive work were (1) distinguishing
semantic provenance from canceling affine dataflow under equivalent wrappers,
and (2) transferring any surviving trace notion to a model-matched
unconditional lower bound for every uniform SAT decider.

Huang's sensitivity theorem polynomially relates sensitivity to other Boolean
function measures \cite{huang}; it does not turn sensitivity into unrestricted
machine time or space.  Parity has pointwise sensitivity $N$ and the wrapper
computes it in one streaming bit.  Classification: \textbf{direct theorem,
failed resource transfer}.  Communication, VLSI, pebbling, observability, and
streaming lower bounds require declared interfaces or access restrictions;
no source-to-model compiler is obtained from causal vocabulary alone.

Baker--Gill--Solovay give oracles with opposite P-versus-NP outcomes
\cite{bgs}.  This negative wrapper relativizes: run the same parity shell
around $A^O$.  Aaronson--Wigderson's algebrization barrier and the newer
communication-based algebrization barriers of Chen--Hu--Ren do not supply the
missing $H$-specific compiler \cite{aw,chr}.  The wrapper itself is degree-one
over $\mathbb F_2$ and survives algebraic access.  Razborov--Rudich applies to
large constructive circuit properties under its cryptographic hypothesis
\cite{rr}; the present elementary wrapper is not a circuit lower-bound
property.  Any future large constructive property would need a separate
Natural-Proofs audit.  None of these barriers is claimed as a proof of
P$\ne$NP.

\section{Post-quantum technique ledger}
\begin{itemize}
\item \textbf{EXACT OBJECT/THEOREM TRANSFER.}  The parity state is a
one-dimensional linear-code syndrome.  Its global support is exploitable by a
one-pass accumulator, so hidden affine structure is a weakness rather than a
hardness source.
\item \textbf{EXACT OBJECT/THEOREM TRANSFER.}  For the terminal map
$L(x)=(A(x),p(x))$, $|\operatorname{im}L|\le4$ and Cauchy--Schwarz gives
$\operatorname{Coll}(L)\ge |D|^2/4$ on every finite domain $D$.  Large
collision mass proves lossiness, not expensive computation.  The full prefix
trace instead has $\operatorname{Coll}=|D|$ because it is injective, yet is
still cheap transport.
\item \textbf{ANALOGY/CANDIDATE needing a new bridge.}  LWE-style external
black-box extraction suggests querying arbitrary solvers instead of requiring
internal state.  Here every extra SAT query inherits $A$'s unknown polynomial
exponent and is not work of the original realization.
\item \textbf{FAILED TRANSFER.}  Schur squares, quadratic relation ranks,
syzygies, special soundness, collapse binding, and random-oracle analogies do
not distinguish the two canceling affine paths or yield an unconditional SAT
lower bound in this model.
\end{itemize}

\section{Handoff and exact missing arrow}
The next synthesis should require the following before any trace claim is
P-vs-NP relevant:
\[
 \boxed{
 \begin{gathered}
 \forall A\,[A\text{ uniform deterministic polynomial-time}\\
 \text{SAT decider}]\\
 \exists Q_A,E_A\ \forall x\in\mathcal C_N:\quad
 H(x)=E_A(Q_A(\operatorname{Tr}_A(x))),\\
 Q_A\text{ is invariant/covariant under source transport,}\\
 \text{paired causal cancellation, and equivalent wrappers,}\\
 \text{all observation and extraction costs belong to that same execution,}\\
 \text{and the resource lands in a model-matched unconditional}\\
 \text{forbidden region.}
 \end{gathered}}
\]
No such theorem is proved here.  If $Q_A$ is the full trace, source injection
is cheap; if it is the terminal live view, $H$ does not factor; if it is
defined by $H$-sufficiency, the universal transfer is the premise still to be
proved.  P versus NP remains \OPEN.
