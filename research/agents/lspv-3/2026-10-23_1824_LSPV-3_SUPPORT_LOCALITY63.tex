\section{Support-locality simulation}
Let \(e:\{0,1\}^q\to\{0,1\}^N\) be uniform, and \(f(b)=P(e(b))\). For each target bit \(j\), assume a computable support \(S_j\subseteq[q]\) and local function \(\phi_j\) such that \(e(b)_j=\phi_j(b|_{S_j})\), \(|S_j|\le w\). Write \(D(f)\) for source-field deterministic decision-tree depth and \(D(P|_{\mathrm{im}(e)})\) for target indexed-bit depth.

\begin{theorem}[Support locality: PROVED/EXACT]
For \(w\ge1\),
\[
D(f)\le w D(P|_{\mathrm{im}(e)}).
\]
On a source \(b^*\) whose root label changes under each of \(q\) one-coordinate flips, the support sets of target bits queried in any exact target execution on \(e(b^*)\) must cover all \(q\) coordinates. Therefore the execution queries at least \(\lceil q/w\rceil\) bits. For several reduction layers, support sizes multiply as an upper bound.
\end{theorem}
\begin{proof}
Simulate each target bit request \(j\) by querying the source coordinates \(S_j\) and computing \(\phi_j\). This costs at most \(w\) source probes per target probe and computes \(f\) exactly. For the pointwise claim, if source coordinate \(i\) is outside every queried support set, flipping it leaves every target observation and the entire deterministic execution unchanged, contradicting the root label change. Support composition follows by repeated union.
\end{proof}
This is a \emph{query} theorem, not a machine-time theorem: computing each support, evaluating each local function, handling target addresses, constructing output, replaying and rereading source data must be charged. BITLIFT58 is the \(w=1\) case.

\section{Actual fixed-length proper-3CNF counterexample}
Let \(f_q(b)=\bigwedge_{i=1}^q b_i\). It has deterministic source-field query complexity \(q\), attained on the all-one input. For any literal \(\ell\), define
\[
G(\ell;a,b)=\bigwedge_{\epsilon,\delta\in\{\pm1\}}
(\ell\lor \epsilon a\lor\delta b).
\]
The gadget forces \(\ell\). With nine variables \(s,u,v,a,b,c,d,e,f\), define
\[
Q_\eta=G(\neg s;a,b)\land G(\neg u;c,d)
\land G(\neg v;e,f)\land(\lambda_\eta\lor u\lor v)
\]
where \(\lambda_1=\neg s\) and \(\lambda_0=s\). All clauses are proper width three with distinct variables. The first three gadgets enforce \(s=u=v=0\), so \(Q_1\) has exactly \(64\) models and \(Q_0\) has none. Both have \(n'=9,m'=13\).
Let \(e_q(b)=Q_{\neg f_q(b)}\). Then \(\mathrm{SAT}(e_q(b))=\neg f_q(b)\). In the fixed-width signed-literal encoding, \(W=1+\lceil\log_2(14)\rceil=5\) and \(N'=(3m'+2)W=205\) bits. These two valid target sources differ in exactly one pivot-literal sign bit. Every other target coordinate is constant, hence the promise-target predicate has deterministic target-bit depth exactly one. The informative bit has source support all \(q\) positions, so \(w=q\).

\begin{theorem}[Reduction consumes the source query bound: PROVED/EXACT]
The uniform reducer uses one source scan, \(q\) field reads on the all-one input, \(O(q+205)\) bit-time, \(O(\log q+205)\) working/output-buffer bits, and 205 written target bits. Every exact deterministic implementation that emits the correct distinguishing target sign must read all \(q\) fields on the all-one input. A target algorithm restricted to the two-source image reads one target sign bit.
\end{theorem}
\begin{proof}
An unread source coordinate can be changed from one to zero without affecting the reducer's observations, but the correct target sign must change. This contradicts deterministic correctness. Conversely a streaming AND computation performs exactly the stated charged work. The forcing-gadget calculation establishes the target truth labels.
\end{proof}
A total exact 3SAT algorithm can recognize the constant target template and read its sign, using a general exact fallback on any non-template proper-3CNF. The promised reduction is not a general algorithm that compresses arbitrary NP-complete 3SAT to constant length: it first decides the explicitly tractable source predicate.
