\section{Exact theorem and acquired normalization}
Let $G_+$ be the source-indexed positive clause-dual multigraph: positive original clauses are vertices and each original variable is the edge between its two positive occurrences. Similarly define $G_-$. Both are loopless cubic multigraphs with $2n/3$ vertices and $n$ edges. A complete original-variable assignment $a$ satisfies $F$ iff its TRUE edges form a vertex-covering edge set in $G_+$ and its FALSE edges form a vertex-covering edge set in $G_-$; this correspondence was established in the earlier project GATE280.
\begin{theorem}[Central-layer interpolation, PROVED/EXACT]
For every valid canonical $F$ and each full satisfying assignment $a$, there exists a fully satisfying source-variable single-bit flip path containing an assignment of weight $\lfloor n/2\rfloor$ and an assignment of weight $\lceil n/2\rceil$. From a supplied checked $a$ and a paid original-source incidence index, a deterministic construction makes at most $2n$ attempted flips and $O(n+m)$ word counter updates after grammar/index acquisition. This does not discover $a$.
\end{theorem}
\begin{proof}
From $a$, scan currently TRUE variables and change each to FALSE only when both incident positive original clauses remain true. All negative clauses only improve. After one scan the selected edges give an \emph{inclusion-minimal edge cover} of $G_+$: any rejected removal stays invalid as other TRUE edges are removed. In a minimal edge cover every selected edge has a selected-degree-one endpoint; otherwise it could be deleted. Each selected-edge connected component is therefore a star $K_{1,d}$, $1\le d\le3$ (including $K_2$). Its $d$ edges cover $d+1$ vertices, so $d/(d+1)\le3/4$. Summing gives at most $(3/4)(2n/3)=n/2$ remaining TRUE variables. Call the resulting SAT assignment $a^-$.
Starting at $a^-$, scan FALSE variables and change each to TRUE only when the two incident negative clauses remain true. Positive original clauses only improve. At the end the remaining FALSE edges form an inclusion-minimal edge cover of $G_-$, so there are at most $n/2$ FALSE variables, or at least $n/2$ TRUE variables. Call this SAT assignment $a^+$. Every accepted second-phase flip increases TRUE weight by exactly one while preserving every original clause. It visits both central integer weights. At each attempted flip, the source-indexed relevant clause counts, failed checks, fixed-name indices, and all changes are charged.
\end{proof}
\begin{corollary}[Identity NP-completeness]
The set of canonical source strings having a satisfying original-variable assignment with weight exactly $\lfloor n/2\rfloor$ is \emph{identical} to D\"ocker's NP-complete canonical SAT language (and likewise for $\lceil n/2\rceil$). Invalid strings are rejected in both. Hence this central-slice language is NP-complete under the identity polynomial reduction.
\end{corollary}
\begin{proof}
The theorem establishes the direction SAT $\Rightarrow$ central witness, and the converse is immediate. Checking the witness is polynomial. D\"ocker supplies the NP-completeness of the full canonical language.
\end{proof}
