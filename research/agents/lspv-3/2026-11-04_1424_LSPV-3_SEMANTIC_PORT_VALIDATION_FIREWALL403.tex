\paragraph{IDEA.} Test whether a circuit of arbitrary compact size can be verified to depend essentially on at most three ORIGINAL variables with only a constant-size local truth-table check. Prediction: the semantic-support check is coNP-complete. Falsifiers: SAT circuits with four fresh guards but three essential variables; syntactic input union complete under Boolean cancellation; unconditional strict proof replay after support changes.
\paragraph{Definition.} For a Boolean circuit Q on n input variables, define its essential support
\[
\operatorname{Ess}(Q)=\{i:\exists a\in\{0,1\}^n,\ Q(a)\ne Q(a\oplus e_i)\}.
\]
The circuit is explicitly given as a finite acyclic AND/OR/XOR/NOT gate DAG of binary-index encoded wires. Let SUPPORT-k be the language of valid circuits with essential support of cardinality at most k.
\begin{theorem}
For each fixed nonnegative integer k, SUPPORT-k is coNP-complete under polynomial-time many-one reductions.
\end{theorem}
\begin{proof}
The complement is in NP: provide k+1 distinct input indices, together with one witness assignment for each showing that flipping the designated input changes the output. All witnesses and gate evaluations are polynomial. For hardness, take an arbitrary circuit C(x) and construct
\[
Q_C(x,z_1,\ldots,z_{k+1})=C(x)\wedge z_1\wedge\cdots\wedge z_{k+1}.
\]
If C is UNSAT then Q_C is identically zero with empty support. If C is SAT, fix an x satisfying C and put all z_j=1. Flipping any single z_j changes Q_C, so at least k+1 of its inputs are essential. Hence C is UNSAT iff Q_C is in SUPPORT-k. Circuit-UNSAT is coNP-complete.
\end{proof}
\paragraph{Corollary.} A polynomial-time verifier for exact semantic support at most three for every arbitrary compact circuit would imply P=NP. A polynomially bounded NP-checkable support certificate for every positive circuit would imply NP=coNP. This is a conditional complexity barrier, not an unconditional time lower bound.
\paragraph{ITERATE.} Syntactic dependency labels, propagated by union through an explicit gate DAG, provide an efficiently checkable sound OVER-approximation of essential support. They are not complete: the circuit (x_1 XOR x_1) AND x_2 AND ... AND x_n has syntactic support n and semantic support zero. An explicit true three-port truth table is easily checked. Promoting opaque circuit ports to conservative auxiliary variables requires an independent source-authenticated type-preserving translation, not a free semantic support oracle.
