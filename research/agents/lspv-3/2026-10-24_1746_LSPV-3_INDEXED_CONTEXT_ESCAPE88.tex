\section{Complete ordinary proper-3CNF multiplexer source}
For $h\ge1$ let $m=2^h$. Let data bits $x=(x_0,\ldots,x_{m-1})$ and selector bits $y=(y_0,\ldots,y_{h-1})$, and put
\[
 I(y)=\sum_{j=0}^{h-1}2^jy_j,\qquad
 \operatorname{INDEX}_m(x,y)=x_{I(y)}.
\]
Create $m$ distinct data variables $u_0,\ldots,u_{m-1}$ and $h$ selector variables $v_0,\ldots,v_{h-1}$. A complete binary MUX tree has $m-1$ fresh internal output variables. At level $j$, every gate uses selector $v_j$, left input $a$, right input $b$, and output $z$, enforced by exactly four proper ternary clauses
\[
(v_j\vee\neg a\vee z)\land
(v_j\vee a\vee\neg z)\land
(\neg v_j\vee\neg b\vee z)\land
(\neg v_j\vee b\vee\neg z).
\tag{1}
\]
This says $z=a$ if $v_j=0$, and $z=b$ if $v_j=1$. The final root is forced to one.

For any literal $\ell$, with fresh private $p,q$, define the exact four-clause unit block
\[
U(\ell;p,q)=\bigwedge_{\epsilon,\delta\in\{+,-\}}
(\ell\vee\epsilon p\vee\delta q).
\tag{2}
\]
It is logically equivalent to $\ell$. All gate clauses and the root unit block are PUBLIC. Append $U(u_i)$ for each data bit $x_i$ using the appropriate sign, then append $U(v_j)$ for selector bit $y_j$ using its sign. All variable names and support locations, including auxiliary variables, are fixed independent of $x,y$. The public MUX tree connects all components through shared selector/gate variables and hence the incidence graph is connected. Every clause has three distinct noncomplementary literals. With source variables $n$, clause count $M$ and the project's fixed four-word encoding,
\[
\boxed{n=4m+3h+1,\qquad M=8m+4h,}\quad
w=\lceil\log_2(64(n+M+1))\rceil,\quad N=(4M+2)w.
\tag{3}
\]
The ordinary formulas $F_{h,x,y}$ satisfy, with no promise on their SAT labels,
\[
\boxed{\SAT(F_{h,x,y})=x_{I(y)}.}\tag{4}
\]
They are proper 3-CNF sources of the fixed NP-complete \emph{language}, but the recognizable subfamily is easy. The grammar itself fixes a deterministic source-order split PUBLIC, X pins, Y pins.

\begin{lemma}[Root-SAT continuation quotient; PROVED/EXACT in the declared source model]
For the source prefix consisting of PUBLIC and all X pins, define $P_x\sim P_{x'}$ when $\SAT(P_xC_y)=\SAT(P_{x'}C_y)$ for every legal suffix $C_y$. Then
\[
Q_{\rm INDEX}=2^m,\qquad \log_2 Q_{\rm INDEX}=m=\Theta(N/\log N).
\]
Every deterministic one-way source-stream exact SAT decider on the entire indexed family has at least $m-O(1)$ complete writable configuration bits at the PUBLIC/X-to-Y cut on some input.
\end{lemma}
\begin{proof}
For $x\ne x'$, pick an index where their bits differ. The common suffix encoding that index separates the two exact SAT labels by (4). Therefore all $2^m$ X prefixes require pairwise distinguishable configurations at the cut. With the common input-head position and no rereadable prefix, $S$ writable bits and fixed control support at most $O(2^S)$ states. The prefix quotient is exactly $2^m$ since there are that many data words.
\end{proof}

\begin{theorem}[ONE charged indexed reread defeats the quotient-to-space implication; PROVED/EXACT restricted]
A deterministic uniform \emph{source-aware} algorithm validates the entire canonical proper-3CNF grammar with $O(\log N)$ live writable bits and $N\operatorname{polylog}N$ bit work, then reads the $h$ selector pin orientations, computes $I(y)$ and makes exactly \emph{one} out-of-order indexed source lookup of data pin $x_{I(y)}$. It decides the family exactly with $O(\log N)$ peak writable bits, on both SAT and UNSAT inputs.
\end{theorem}
\begin{proof}
All expected variable IDs, clause headers, MUX gate clauses, pin auxiliary IDs and fixed signs except the pin orientation bits are uniform functions of $h$ and the record offset. A counter-driven scanner checks every public record and the four signed clauses of each pin block, comparing their common orientation and required alternating private-literal signs without retaining any earlier data orientation. The single public source format permits computing every expected offset in $O(\log N)$ bits, and indexed bit acquisition charges its address/index tape. After the final Y block, retain only the binary integer $I(y)$; compute the X-pin record address from $I(y)$ and read its sign bit. Formula (4) supplies exact correctness. Total grammar validation is linear in encoded source bits up to logarithmic arithmetic overhead. Outside this recognized source class, an arbitrary total exact fallback maintains global correctness but not a polynomial all-input bound.
\end{proof}

For the \emph{same} $Q_{\rm INDEX}=2^m$ context quotient, a one-way algorithm must store $m$ bits while an indexed algorithm needs only $O(\log N)$ mutable bits and ONE contextual data read. Therefore the proposed general lower bound
\[
 S+q\log N\ge\log_2 Q_{\cal C}
\tag{5}
\]
is \textbf{FALSIFIED/RETIRED} as a universal statement with $q$ counted indexed cross-prefix probes and arbitrary context family. The one requested \emph{address} carries $h$ bits of context and selects the relevant source bit. This is the established communication INDEX gap expressed in a model-matched SAT grammar. A user of a virtual source bit service must charge that address and its read, not assume the source is unavailable.

\section{Equality remains different: hybrid query communication tradeoff}
Use the earlier connected proper-3CNF equality source $G^=_{h,x,y}$ from CONTEXT87: $n=8h+3$, $M=13h+3$, $\SAT(G^=_{h,x,y})=[x=y]$. Consider a deterministic hybrid source machine making at most $p$ complete forward PUBLIC/X/Y passes and at most $q$ \emph{additional} indexed single-bit probes, in any adaptive order, into a portion of the source owned by the other party in the associated communication simulation. Complete mutable state (heads, indices, counters, flags, program control when not fixed) fits $S$ bits; source-bit addresses have $\lceil\log_2 N\rceil$ bits. A remote query sends the address and returns the bit. Query outcomes and rule switches are part of the real state, never a free oracle.
\begin{theorem}[Hybrid equality access firewall; PROVED/EXACT within this restricted model]
There is a universal constant $C$ for the declared simulation such that every exact hybrid equality decider satisfies
\[
\boxed{
 h \le (2p-1)(S+C\log(N+2))
       +q(\lceil\log_2N\rceil+1)+C(p+q+1).
}\tag{6}
\]
There is a uniform matching-up-to-log-factors family of algorithms using $p$ complete sequential passes, $q\le h$ fixed indexed X-bit rereads on the final pass and
\[
S=O\!\left(\left\lceil\frac{h-q}{p}\right\rceil+\log N\right)
\]
mutable bits with $O(pN\operatorname{polylog}N+q\operatorname{polylog}N)$ bit work.
\end{theorem}
\begin{proof}
Alice holds X orientations, Bob Y, with PUBLIC grammar known to both. Simulate each complete sequential pass with Alice executing the PUBLIC/X segment, sending the complete configuration to Bob for Y, and Bob sending it back before the next pass. There are $2p-1$ such complete-state transfers, each of at most $S+O(\log N)$ bits. For an indexed request into the other party's source region, the requester communicates the $\lceil\log N\rceil$-bit address and receives one answer bit. All local queries cost no communication but still incur charged machine work. Variable-length requests, halting flags and pass headers cost $O(p+q)$ protocol bits with explicit delimitation. This is a correct deterministic two-party protocol for equality. Its $2^h$ accepting diagonal pairs form a fooling set, so its worst-case communication is at least $h$ bits, proving (6).
For the upper bound partition $h-q$ data positions into $p$ fixed groups and compare each group's X bits with the corresponding Y bits during its full pass, retaining only that group's X bits. On the final pass also compare the remaining $q$ positions by individually indexed rereads of their X bits after reaching Y. Abort only on an observed mismatch; otherwise accept after all comparisons. Charge every pass, indexed address computation, failed group, cleanup and peak simultaneous state. This proves the upper bound.
\end{proof}
The communication proof is \emph{not} a lower bound on every random-access SAT decider. Unlike INDEX, equality has full two-party deterministic communication complexity $h$, while INDEX has only $O(\log m)$ interactive communication despite its $2^m$ one-way quotient. The relevant contextual parameter therefore changes with source-access rights and interaction budget, not merely the number of distinct future response rows.

\section{BIT-RESOURCE1: adaptive state and cumulative bit-time}
For the MUX one-way scanner, at the cut after the first $j$ X pins, all $2^j$ orientation prefixes have different possible future SAT continuation responses (fix remaining X to zero, choose a Y index below $j$ where two prefixes differ). Thus at some such cut at least $j-O(1)$ complete mutable bits are live. Averaging over uniformly distributed X prefixes, a variable-length state code uses at least $j-O(1)$ live bits. Summing actual designated input checkpoints gives some X stream with $\Omega(m^2)$ cumulative \emph{checkpoint} live-bit-time; elapsed primitive operations between checkpoints only increase this cost. A simpler source-aware streaming representation initially retains the entire X vector, then after each revealed selector bit discards the half inconsistent with that selector; its actual retained data-bit trajectory is
\[
 (m,m/2,m/4,\ldots,1).
\tag{7}
\]
The indexed policy instead stores the $h$-bit selector and rereads one X bit. Both rules depend on observed evidence, never the true root label.

The typed real-execution resource vector is
\[
 (U,R_{\rm src},R_{\rm work},W_{\rm work},
 \Delta_{\rm work},\Delta_{\rm head/addr/ctrl},
 S_{\rm peak},BT,|\mathrm{representation}|).
\]
Every source bit read, head/index operation, unchanged write, branch, failed attempt, rule switch, virtual-child address calculation, auxiliary gadget, buffer, and peak ancestor is charged. The proven bit-time checkpoint bound is specific to a sequential source channel and is not a FLMV forbidden-region endpoint; flip counts are not substituted for work steps. TYPED-LEGAL-POTENTIAL123 correctly requires $\Delta_{\rm work}\le W_{\rm work}\le U$ but does not bound total complete-state flips by work-only writes.
