\section{NP-complete optimal whole-module subcollection selection}
\begin{theorem}[Connected proper-3CNF source-module selection]\label{th:setcover}
The following decision problem is NP-complete under polynomial many-one reductions: input is a syntactically authenticated typed \emph{ordinary proper 3CNF} source that is promised globally UNSAT, with shared boundary width $b=O(\log N)$ and pairwise private module names, and a positive integer $k$; determine whether there are at most $k$ \emph{whole original named modules} whose conjunction is UNSAT. Hardness holds even when the clause-variable incidence graph of the full source is connected and each individual module is SAT.
\end{theorem}
\begin{proof}
Reduce SET COVER \cite{karp}. Let $U=\{0,\dots,u-1\}$ be the universe and let $S_1,\dots,S_s\subseteq U$ be the proposed sets; in polynomial time reject or map the trivial uncovered-universe cases to a fixed NO instance. Without loss, $\bigcup_jS_j=U$. Take $b=\max(3,\lceil\log_2(u+1)\rceil)$ and regard $U$ as those $u$ low-valued boundary assignments among $\{0,1\}^b$. Make the \emph{mandatory source module} $M_0$ exclude precisely all $w\notin U$, and for each original set create $M_j$ excluding precisely $S_j$. Encoding each excluded point with the original, fresh-private proper-3CNF chain above takes polynomial time and produces a source of size $O((2^b+\sum_j|S_j|)b\log(N+2))$. Because $2^b\le8(u+1)$, this is polynomial in the SET COVER instance size. The full source is UNSAT because $M_0$ excludes the complement of $U$ and the $M_j$ collectively exclude $U$. No choice of original set modules without $M_0$ is UNSAT, since every boundary point outside $U$ satisfies all of them. With $M_0$ present, a chosen subcollection is UNSAT exactly when its corresponding original sets cover $U$ by (2). Therefore
\[
 \exists\text{ cover of }U\text{ using at most }k\text{ original sets}
 \iff
 \exists\text{ UNSAT subcollection of at most }k+1\text{ named source modules}.\tag{4}
\]
Every source module is SAT: $M_0$ accepts all $w\in U$, while each other $M_j$ accepts every outside point $w\notin U$. At least one encoded $E_w$ links all $b$ boundary names by its fresh private chain, and each nonempty module's clauses link into the same original $Y$, so the full incidence graph is connected. Its source has at least $2^b$ encoded chains and thus $b=O(\log N)$. All original ternary clauses are proper and pairwise distinct by the source-unique private tags. If the optional selected set of modules is presented, UNSAT of its conjunction is checked in polynomial time by scanning its source-authenticated exclusions and covering the at most $2^b=O(N)$ boundary tuples. Thus the promised selection decision problem belongs to NP, proving NP-completeness.\end{proof}

\paragraph{Crucial negative inference.}
This is a restricted \emph{optimization} hardness theorem, not a lower bound on the time to acquire \emph{some} valid UNSAT certificate: the construction in Theorem~\ref{th:allcover} gives one in polynomial time without solving SET COVER. It also does not imply every adaptive branching, affine, Horn, polynomial-calculus, cutting-planes or Resolution portfolio has hard acquisition on ordinary CNF. The minimum \emph{whole-module count} is not minimum proof length, and NP-completeness by itself gives no unconditional superpolynomial lower bound on deterministic computation. This explicit acquisition-versus-optimal-selection distinction is the intended challenge for ARC strategies that quietly optimize local-module subsets.

\section{Two-RW and source-only model-witness falsifier audit}
Let the project signed proper exact-$(2,2)$ gadget $H(a,b)$ have $15$ variables, $20$ authentic source clauses, and exact satisfying-model counts
\[(\#H_{00},\#H_{01},\#H_{10},\#H_{11})=(772,272,272,0).\]
An Alice-only candidate printer emits the 15-bit assignment $w_0=616$ when $a=0$, and $w_1=4742$ when $a=1$. The first satisfies both $H(0,0)$ and $H(0,1)$, and the second satisfies $H(1,0)$ but no model exists for $H(1,1)$. On $m$ copies the printer succeeds on every SAT promise input without inspecting Bob, and emits a false model on every UNSAT promise input. Thus it is \emph{not a sound SAT acceptor}, much less a UNSAT decider; this is the previously proved UWI-PROOFTAPE-CROSS141 firewall, independently retested on the true original W1 clauses.

For native TWO-RW, an actually materialized binary model on an initially blank writable second tape changes at least five cells per copy of $w_1$ because $4742$ has five one bits. Hence on $F_m(1^m,0^m)$ this particular output representation incurs $D_2\ge5m$, $S_2\ge15m$, independent of whether a Bob check has yet occurred. An external write-only output stream may evade a writable-work-tape change count \emph{but is not readable evidence for the source acceptor}. Upgrading it to a reusable independent proof head changes the machine model and counts its physical proof length, as UWI-PROOFTAPE-CROSS141 explicitly formalizes. On a verified accepting path for $F_m(1^m,0^m)$, changing an unread Bob selector to $1$ creates an UNSAT source indistinguishable on that path. Hence $m$ Bob-sensitive source regions must be read, even on indexed RAM, although no superlinear RAM lower bound follows.

The proposed TWO-TAPE-FRONTIER1 \emph{native two-writable-tape} chronology counts $D_1+D_2$ actual symbol changes, not just $D_2$, together with all tape2 head coordinates and CROSS state. In a no-change epoch the whole tape1/tape2 content is static; repeated direction, finite control, and tape2-head position at a fixed tape1 input cut would repeat a complete machine configuration and loop. Thus its advertised \emph{necessary} event-count bound $(D_1+D_2+1)(S_2+1)\log(S_2+2)=\Omega(N/\log N)$ survives this witness-printer countercontrol only when the machine is a \emph{sound halting acceptor} on the cited source promise and all transitions are charged. The present run finds no native 2-RW counterexample; independent formal referee review of that theorem remains pending. This argument does not import the bound to a read-only source + proof head, $k\ge3$ tapes, or indexed RAM. Single-tape input-inclusive footprint $P_1\ge N$ and separate read-only-input fixed-$k$ work space $S_k$ remain disjoint ledgers. No WRITE-TIGHT2 or TWO-TAPE-FRONTIER1 bound is a general SAT hardness theorem.
