# STATUSQUOTE8: LSPV-4 / LSPV-5 handoff
2026-10-15. Scoped results only. P vs NP remains OPEN.

LSPV-4: A fully clocked deterministic SAT-status computation has functional Tseitin CNF size polynomial in the actual charged time bound. A total unclocked translator from arbitrary program indices to their output as finite SAT status cannot exist even for constant-output programs, by Kleene recursion. A single fixed polynomial SAT decider with an explicit clock remains reifiable. Avoid silently upgrading clocked reification to self-quotation of the source.

LSPV-5: For a status map G, an actual source realization with genuine status vector s requires s=G(s). An inconsistent G by itself refutes the proposed realization, not P=NP. UWI control: four constant assignment programs jointly cover all 95 SAT formulas in a 256-formula two-variable class even though each separately fails on 63 SAT inputs.
