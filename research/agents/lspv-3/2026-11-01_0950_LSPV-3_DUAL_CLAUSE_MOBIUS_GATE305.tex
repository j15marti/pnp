\section{Original-source signed-M\"obius rank theorem}
Let $F$ be any valid duplicate-free proper D\"ocker Monotone 3-SAT-(2,2) original. Every original clause has three distinct equally signed variables; each original variable has exactly two occurrences of each sign; reject malformed binary encodings. Let $p$ coherently pin original variables, and let $C_1,\dots,C_q$ be the original clauses not already covered by a pinned true literal. An original clause with no remaining literal yields a direct UNSAT leaf. Let $f$ be the number of free original variables. Optionally let $E$ be an affine GF(2) system whose rows are \emph{proved consequences of the original residual}; taking $E=\varnothing$ always suffices. For each $S\subseteq[q]$ let $E_S$ add the individual equations falsifying every remaining literal of every $C_j$ with $j\in S$. Set $\chi_S=1$ if consistent and $0$ otherwise, and let $r_S=\operatorname{rank}(E_S)$.
\begin{theorem}[Exact model count, both-label decision, and terminal cost]
\[
\boxed{\#\mathrm{SAT}(F|p)=\sum_{S\subseteq[q]}(-1)^{|S|}\chi_S2^{f-r_S}.}
\tag{305.1}
\]
The sum is nonnegative. A positive value gives SAT, recoverable by sequential conditional counting followed by checking every original clause. Zero gives UNSAT with a complete independently replayable rank/cancellation certificate, not necessarily a DRAT/LRAT certificate. For explicit source length $N$, bit-time is $O((f+1)2^q\operatorname{poly}(N))$, and an on-line evaluator retains polynomial space plus any elected proof-output transcript. Hence an authenticated $q=O(\log N)$ residual is an exact polynomial-time terminal, even with $f=\Theta(n)$.
\end{theorem}
\begin{proof}
For any original-variable assignment satisfying $E$, the indicator that all original uncovered clauses hold equals $\prod_{j=1}^q(1-\mathbf1[C_j\text{ false}])$. Expanding yields one signed summand per subset $S$, whose surviving affine assignments number exactly $\chi_S2^{f-r_S}$. Since $E$ is source-entailed, intersecting it with the original residual does not change the model set. Sequentially fix each free original bit to a value with positive conditional count; this must exist because the two counts sum to the current positive count. Recheck the final full source witness. At most $f$ stages and $2^q$ rank systems per stage prove the bound. Every unit row retains original clause and signed occurrence provenance; all row reductions, source reads, accumulator bits, output and checking are charged.
\end{proof}
\begin{theorem}[Universal onset obstruction for this particular terminal]
For $a$ pins TRUE, $b$ FALSE, $t=a+b$, the number of uncovered original clauses satisfies
\[
\boxed{q\ge\max(0,2n/3-2a)+\max(0,2n/3-2b)\ge4n/3-2t.}
\tag{305.2}
\]
Consequently $q\le c\log N$ requires $t\ge2n/3-(c/2)\log N$; it does not lower-bound arbitrary algorithms.
\end{theorem}
\begin{proof}
There are exactly $2n/3$ original clauses per sign. A pinned true variable covers at most its two positive occurrences and a pinned false variable at most its two negative occurrences. Count uncovered clauses separately and add.
\end{proof}
