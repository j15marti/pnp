\section*{Theorem: exact semantic locality in a succinct circuit}
For $f:\{0,1\}^n\to\{0,1\}$, put
\[
\operatorname{Ess}(f)=\{i:\exists a\in\{0,1\}^n,\ 
 f(a)\ne f(a\oplus e_i)\}.
\]
Use valid topologically encoded acyclic circuits of binary AND gates and signed input/output wire views, with distinct original input bits. All gates can be introduced by total, conservative, paid signed two-input DEF operations. The circuit size and all wire indices belong to the explicit input length.

\begin{theorem}
For each \emph{fixed} integer $k\ge0$, the following language of signed fan-in-two circuits is coNP-complete under uniform polynomial-time many-one reductions:
\[
\mathsf{SmallEss}_k=\{\operatorname{enc}(D):
 D\text{ is a well-formed signed AND2 circuit},
 |\operatorname{Ess}(f_D)|\le k\}.
\]
In particular, exact semantic support at most three original variables is coNP-complete.
\end{theorem}
\begin{proof}
The complement is in NP. A certificate supplies $k+1$ distinct original input indices and for each index two assignments differing at that position only, on which the circuit outputs differ. A deterministic verifier checks the gate syntax and evaluates these $2(k+1)$ assignments in polynomial bit time.

For coNP-hardness, map any ordinary CNF $C(x_1,\ldots,x_n)$, with malformed inputs rejected separately, to a signed AND2 circuit computing
\[
f_C(x,y)=C(x)\wedge y_1\wedge\cdots\wedge y_{k+1}
\]
on $k+1$ fresh \emph{original} input bits. AND, OR and NOT are realized by signed wire views and binary AND gates, via De Morgan, with a linear increase in gate count; an empty conjunction can be represented by $x_1\vee\neg x_1$ (or a separately handled empty-variable constant). Every DEF is conservative and its output has a unique value on each original assignment. If $C$ is UNSAT, $f_C\equiv0$ and $\operatorname{Ess}(f_C)=\varnothing$. If $C$ is SAT, fix any satisfying $x$, set all $y_j=1$ and flip each $y_j$ in turn. All $k+1$ variables are essential. Thus
\[
 C\in\mathrm{UNSAT}\quad\Longleftrightarrow\quad
 |\operatorname{Ess}(f_C)|\le k.
\]
This is a uniform polynomial-time reduction, not a hardcoded family or semantic oracle.
\end{proof}

\noindent\textbf{Consequence, conditional on an unverified interpretation of the original rules.} If LOCAL-CONVERT or AND3 may inspect arbitrary paid conservative named-wire circuits and interpret its three-original-variable restriction as \emph{exact essential semantic support}, then checking this support guard is coNP-complete. Only three visible named wires do not guarantee three original inputs. A constant-size truth table over three arbitrarily selected names cannot certify that all other originals are irrelevant. A sound efficient grammar could instead demand a syntactic transitive input cone of at most three, or a paid and verifiable semantic-equivalence witness. Neither rule is silently substituted into $R_{\mathrm{mix341}}$. A syntactic cone is an overapproximation: $x\wedge\neg x$ has one syntactic input but zero essential inputs; switching definitions can change the set of permitted proofs and the shortest-DAG minimum. The result does not assert that the authoritative LOCAL-CONVERT checker uses the coNP-hard interpretation or that any such locality guard independently yields an UNSAT certificate.
