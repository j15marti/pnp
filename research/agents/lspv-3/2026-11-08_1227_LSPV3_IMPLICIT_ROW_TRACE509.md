## ITERATE: theorem and explicit, fully attributed scope

Let G be any connected simple cubic graph on h vertices with 3h/2 edge variables x_e and an **odd** vertex-charge vector chi. Encode each vertex parity constraint as the four unique signed strict three-literal clauses prohibiting wrong parity; the original external source F(G,chi) has m=4h clauses and N=O(h log h) ASCII DIMACS bytes under its indexed presentation. For the expander subfamily of Urquhart/Ben-Sasson-Wigderson, ordinary Resolution has an exponential size lower bound. This theorem uses that established family as an *easy mixed-system upper control*, not a candidate all-mixed-hard family.

Define a **separate trace-only presentation** C_509 of the recoverable SOURCE/AND3/XOR fragment. SOURCE carries only the exact positional index of an authenticated original signed CNF clause; AND3 carries two earlier factor-node indices and is allowed only when the union of original-variable supports has size at most three; its 8-bit truth table is **recomputed by the checker**, and it becomes an XOR row only on **exact** truth-table equality with one affine parity equation; XOR carries two earlier affine-row indices and is interpreted as binary GF(2) row addition. Every paid AND3 and XOR node has weight one; SOURCE is free. No RES, CAST, DEF, LOCAL-CONVERT, branching or other historical native rules are claimed as accepted bytes. The parser requires canonical JSON and exact integer types and binds all source-position references to an independently provided original CNF. SHA-256 is auxiliary provenance metadata; soundness uses the actual external clause bytes to replay every inference and does not depend on assuming collision resistance.

**Theorem 509.1 (PROVED/RESTRICTED, explicit mathematical construction):** In C_509, for every such odd-charge G, an original-source-authenticated proof tree can be represented with m=4h SOURCE records, 3h binary AND3 nodes, and h-1 binary GF(2) XOR nodes, without encoding **any** factor table or affine mask in the certificate. Thus q=4h-1 paid nodes, weighted depth D=2+ceil(log2 h) for balanced XOR grouping, and original-source-plus-proof evidence length O(h log h) bits. The proof tree is a special permitted DAG; there is no exclusion of shared/reconvergent alternatives in any lower-bound minimum. On bridgeless G, the existing indispensable-source binary-premise lemma separately proves q>=m-1 *within this declared positive-unit-weight binary calculus*, so this constructed value is exact there. **No claim of native historical full-R exact minimum arises from C_509.**

*Proof:* The four original clauses at a vertex have conjunction exactly equal to the vertex's three-input parity relation (check the eight assignments). Combine them pairwise using two AND3 nodes and conjoin the two results using a third AND3 node. With all parents carrying exact truth-table semantics on the same three original edge variables, the final AND3 is an exactly checked affine row R_v. XOR the h vertex rows in a balanced binary tree. Each edge variable occurs twice and cancels, whereas the odd total charge yields the empty-mask contradictory row (0,1). All rule semantics can be **recomputed** from original source clauses and earlier nodes; explicit masks or truth tables do not have to be transmitted. Each node carries at most two references with O(log h) bits; there are 8h-1 nodes (4h free plus 4h-1 paid). The actual external input has 4h constant-width clauses with O(log h)-bit literal indices. Hence total evidence O(h log h). All nodes are topologically ordered and the proof is a tree with no reconvergent nodes. SOURCE indices reference exactly the original source positions, not an equisatisfiable rewritten formula.

**Theorem 509.2 (PROVED/RESTRICTED, explicit schedule):** A deterministic verifier for this *balanced, tree-shaped* C_509 proof uses O(h^2) bit operations under naive h-bit mask XORs, and can process rows depth-first with at most O(log h) simultaneously live masks of n=3h/2 bits. Including the externally provided indexed source and explicit proof packet, its bit-level peak storage is O(h log h), without counting arbitrary Python interpreter overhead as a same-machine bound. A cached generic shared DAG can instead take O(qn) row bits; reusing a shared parent does NOT justify a free tree-streaming schedule. A semantic-width Omega(h) row in an expander-instance XOR proof is therefore compatible with O(h log h) total explicit trace/source bits and O(h log h) peak streamed bits. **Expanded semantic width alone is not a superlinear paid-node-work or explicit-evidence-bit lower bound.**

*Proof:* Recompute each constant-support source/factor truth table in at most eight assignments, and perform h-1 vector XORs of length n=Theta(h). Depth-first tree evaluation retains the finished left affine row while descending into the right child; at each balanced XOR level at most one completed sibling row is retained. This is O(log h) live n-bit masks plus the O(h log h)-bit input and DAG packet, giving the stated worst-case bit-level asymptotics. This schedule is NOT proved for arbitrary reconvergent graphs; memoization/recomputation is charged separately. Note that for small h actual JSON packet bytes can exceed dense-row payload bytes because JSON has substantial constant overhead; the result is asymptotic and not a claim of measured compression on every finite fixture.
