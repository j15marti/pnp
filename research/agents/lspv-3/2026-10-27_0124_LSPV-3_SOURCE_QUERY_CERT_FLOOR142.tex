\section{Authentic signed source and exact quantifiers}
Use the source-identified $W_1$ proper 15-name/20-clause
minimal UNSAT gadget, literal source copied into the executable.
Construct $H(a,b)$ by flipping both Alice sign occurrences at
zero-based $(6,0),(11,0)$ iff $a=0$, and both Bob sign
occurrences at $(9,2),(17,2)$ iff $b=0$. Each variable
remains twice positive and twice negative. Exact exhaustive
assignment counts are
\[
\begin{array}{c|rrrr}
(a,b)&00&01&10&11\\\midrule
\#\mathrm{models}&772&272&272&0 .
\end{array}
\]
Use disjoint variable translations $H_i$ to construct
\[
F_m(a,b)=\bigwedge_{i=1}^m H_i(a_i,b_i),\qquad
\SAT(F_m(a,b))\iff a\wedge b=0^m. \tag{1}
\]
A canonical fixed-width ordinary CNF source lists the $2m$
Alice-dependent clauses, $16m$ unchanged clauses and $2m$
Bob-dependent clauses. All original clause IDs and source
variable names are preserved. Each literal has a sign plus
$w=\lceil\log_2(15m+1)\rceil$ identifier bits and
\[
N=60m(w+1)+20m+O(\log m)=\Theta(m\log m).
\]
One source-selector observation means an actual input-sign
read that determines one $a_i$ or $b_i$ on this \emph{promise};
a fixed literal read or an unaudited proof claim is not
such an observation. Any native implementation still pays
the cost of producing each source address and accessing it.

A computation may make adaptive decisions, fail earlier
strategies, read untrusted certificate bits and run a single
fixed deterministic exact ordinary SAT guest $A$ on constructed
ordinary children. Hold the \emph{entire} certificate and
selected branch fixed when perturbing input. Charge every
source read, every source-dependent bit of a materialized
child and every virtual-input dereference by $A$.
There is no free source-status oracle. Parsing, switching,
output, head traffic, ordinary child size and live memory
are charged in the appropriate native model.

\begin{lemma}[Exact transcript-invariance contract]\label{l:trace}
If two canonical sources agree on every selector coordinate
actually read during one accepted run, the run's entire trace
and verdict are unchanged, including all replies from
the fixed deterministic guest $A$, provided guest child strings
are computed only from already observed source bits and constants.
\end{lemma}
\begin{proof}
Induct over actual transitions. The next source read returns
the same bit, every internal or nondeterministically fixed
decision has the same state, and an explicitly constructed
guest child has the same complete bytes. Therefore the same
deterministic $A$ returns the same answer. Any virtual guest
access to the parent is included in the source read set.
This covers multiple source queries, child levels, failed
probes and repeated calls. A free oracle for the
unread full parent violates the premise and is excluded.
\end{proof}

\begin{theorem}[Exact signed-source every-input floors]\label{t:floor}
For every $m\ge1$ and $a,b\in\{0,1\}^m$, let $C_v(a,b)$
be the minimum number of actual selector-coordinate
values fixing the correct answer $v$ across every
canonical completion. Then
\[
\boxed{
a\wedge b=0^m\ \Longrightarrow C_{\SAT}(a,b)=m,\qquad
a\wedge b\ne0^m\ \Longrightarrow C_{\UNSAT}(a,b)=2.
} \tag{2}
\]
Every globally sound accepted SAT branch in
Lemma~\ref{l:trace}'s model must physically inspect at
least one selector \emph{zero} from each module.
Every globally sound accepted UNSAT branch must
inspect two selector \emph{ones} in one common module.
\end{theorem}
\begin{proof}
If an accepted SAT trace has no inspected zero in module
$i$, complete any uninspected selectors in that module
as ones. Every observed selector remains unchanged but
the resulting canonical source contains $H_i(1,1)$ and
is UNSAT; by Lemma~\ref{l:trace} the frozen accepting
branch would remain accepting, contradicting soundness.
Thus $m$ module zeros are necessary. Choosing any one
actual zero from each module certifies SAT, proving tightness.

For an accepted UNSAT trace with no module where both
selectors were observed one, complete each module with
at least one zero while preserving all its already observed
values. This is possible independently in every module
and yields a SAT completion with identical trace, a
contradiction. Conversely observing $a_i=b_i=1$
in one module forces the UNSAT subformula $H_i(1,1)$.
Hence exactly two values are necessary and sufficient.
\end{proof}

\begin{theorem}[Optimal worst-case deterministic selector depth]
Every deterministic exact source-selector decision tree
for (1) has worst-case depth $D=2m$, attained by
querying $a_i$ and querying $b_i$ only when $a_i=1$.
On each SAT source this adaptive algorithm makes
exactly $m+\mathrm{wt}(a)$ selector queries.
\end{theorem}
\begin{proof}
For an adversarial decision path, answer one on the first
distinct selector queried in each module and zero on the
second. Until both selectors are examined in a module,
an UNSAT completion of that module is consistent with
the transcript. An exact algorithm cannot halt SAT until
all $2m$ distinct bits are read; the final source is SAT.
The stated short-circuit scan uses at most $2m$ queries,
and on SAT precisely one extra Bob query per Alice one.
\end{proof}

\section{Semantic RAM floor and sound UNSAT source leaves}
Equation (2) forces $m=\Omega(N/\log N)$ distinct
\emph{selector groups} on every accepted SAT branch.
A bit-probe indexed RAT therefore needs at least $m$
source-bit reads, but contiguous word reads of
$O(\log N)$ bits may cover multiple groups; the
safe generic word bound is $\Omega(m/\log N)$.
A correct indexed comparator on the easy promise
has $O(m\operatorname{polylog}N)$ bit time and
$O(\log N)$ writable/index memory.
This is not a superlinear all-ordinary-SAT lower bound.

Two selector ones are a correct UNSAT certificate only
on the canonical promise. For \emph{globally sound ordinary
CNF} acceptance, the verifier instead source-authenticates
the twenty genuine $W_1$ clauses under one injective
translation of fifteen original names, checking each
source clause offset, correct signed literals, distinct
records and a fixed audited SCC/resolution contradiction.
An accepting such subset makes the whole ordinary formula
UNSAT despite unrelated surviving ternaries. Thus every
SAT formula rejects \emph{every} certificate. Every UNSAT
\emph{promised} $F_m(a,b)$ contains a copy of the entire
$W_1$ and has a source-authenticated certificate with
\[
|\pi|\le35\lceil\log_2(N+1)\rceil+O(1). \tag{3}
\]
In the inherited authenticated grammar a fixed expansion
has $B=31$ branches, $L=32$ leaves and $E=600$ SCC
path edges. Actual source reads and output are charged.
A uniform proof-length and branch clock reject malformed
proofs, conflicting source names and timeouts.
Branchwise complementation therefore gives only a
\emph{promise SAT} co-nondeterministic companion:
every SAT promised input has all complemented branches
accepting, every UNSAT promised input has some rejecting
branch. It is not a coNTIME theorem for all ordinary SAT.
