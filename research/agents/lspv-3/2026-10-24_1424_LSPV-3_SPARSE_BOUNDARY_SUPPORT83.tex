\section{Exact source-typed feasible-signature theorem}
Let \(F\) have disjoint affine components \(E_i\), local
(non-affine allowed) binary clauses \(B_i\), and binary clauses
\(B_{ij}\) whose variables lie in different components \(i,j\).
Let \(P_i\) be the \emph{declared full} set of component variables
observed by the local and cross constraints. Define the joint relation
\[
\Sigma_i=\bigl\{\alpha\in\{0,1\}^{P_i}:
 \exists z_i\ [E_i(z_i,\alpha)\wedge B_i(z_i,\alpha)]\bigr\},
\quad r_i=|\Sigma_i|.
\]
The definition is semantic: neither \(\Sigma_i\), its membership oracle,
nor its enumeration comes free. Suppose a fixed total
\emph{source-validating} uniform procedure actually enumerates each
\(\Sigma_i\), with explicit full-component witness lifts, in time \(D_i\)
and declared live storage \(S_i\). Let \(G\) be the paid-computed graph
of cross constraints.

\begin{theorem}[Paid finite-support tree join; PROVED/EXACT restricted]
If \(G\) is a forest, an exact deterministic procedure decides \(F\)
and, in the SAT case, reconstructs a global satisfying assignment, in
word operations bounded by
\[
O\left(\operatorname{poly}(N)+\sum_iD_i+
  \sum_{\{i,j\}\in E(G)}r_i r_j\,C_{ij}\right),
\]
where \(C_{ij}\) includes reading/evaluating \emph{all} cross clauses of
\(B_{ij}\) on a pair of explicit boundary assignments.
A valid conservative peak-storage bound includes source parsing,
all retained \(\Sigma_i\) and lifts, dynamic-programming messages,
backpointers, live enumeration workspace \(\max_i S_i\), and reconstruction.
The theorem does not certify sublinear FLMV work space.
\end{theorem}
\begin{proof}
For edge \(ij\), evaluate the entire fixed relation
\(K_{ij}(\alpha,\gamma)=
[B_{ij}(\alpha,\gamma)=1]\). Root every tree.
Define \(M_{i\to p}(\alpha)\) as the existence of jointly compatible
assignments to all components in \(i\)'s subtree when the
\(i\)-signature is \(\alpha\). For each \(\alpha\in\Sigma_i\), intersect,
for each child \(j\), the existential condition
\(\exists\gamma\in\Sigma_j:
 K_{ij}(\alpha,\gamma)\wedge M_{j\to i}(\gamma)\).
A true root entry is equivalent to a single globally consistent
assignment because all interactions cross only the explicitly
tested edges, and all component interiors are disjoint.
Store one compatible child signature per successful condition;
the paid component lifts recover a complete witness.
Every pair is tested at most once per edge (up to source-clause
evaluation \(C_{ij}\)); discovery, parsing, tables, messages, and
reconstruction are counted. If validation fails, the restricted
procedure makes \emph{no} correctness claim outside its promise.
\end{proof}

For a paid elimination order with bags \(S_j\), general factor
elimination similarly has table size bounded by
\(\sum_j\prod_{i\in S_j}r_i\), times polynomial per-entry work,
\emph{provided} each complete joint local relation is available.
A small marginal or a source-free ideal feasibility oracle is not
a substitute. This is an upper-bound trajectory, not a lower bound.

\section{Matched non-affine sparse-support family}
For integers \(q\ge2,k\ge2,h\ge1\), let \(L=k+h\).
In component \(i\) create \(k\) boundary variables
\(x_{i,1},\ldots,x_{i,k}\), \(h\) private variables \(a_{i,1},\ldots,a_{i,h}\),
and \(L\) running parity variables \(y_{i,1},\ldots,y_{i,L}\).
Set \(v_i=(x_{i,1},\ldots,x_{i,k},a_{i,1},\ldots,a_{i,h})\);
enforce \(y_{i,1}=v_{i,1}\) and
\(y_{i,r}=y_{i,r-1}\oplus v_{i,r}\) for \(2\le r\le L\).
The \(L\) independent affine equations on \(2L\) coordinates have
\(d_i=L\) free degrees, and the projection to \(x_i\) has full
affine rank \(t_i=k\).

Add local genuine binary exclusions
\((\neg x_{i,j}\vee\neg x_{i,\ell})\) for every \(j<\ell\).
They restrict the actual boundary relation to
\[
\Sigma_i=\{0,e_1,\ldots,e_k\},\quad
r_i=k+1,\quad
\operatorname{rank}(\operatorname{affspan}\Sigma_i)=k.
\]
Between adjacent components require
\(x_{i,1}\oplus x_{i+1,1}=\eta_i\) and
\(x_{i,j}=x_{i+1,j}\) for \(2\le j\le k\).
Pin \(x_{1,1}=x_{q,1}=1\). Source labels obey
\[
\SAT(F_{q,k,h,\eta})=1\quad\Longleftrightarrow\quad
\bigoplus_{i=1}^{q-1}\eta_i=0.
\]
The first pin and local exclusions force all secondary
coordinates to zero in a witness; the first coordinate propagates
by the displayed edge equations. The second pin supplies the parity
test. Every SAT member has a complete witness by choosing arbitrary
private \(a\)'s and lifting the parity prefix.

\begin{lemma}[Exact proper-3CNF compilation, PROVED/EXACT]
Encode each XOR3 equation by four exclusion clauses;
each binary clause \(u\vee v\) by
\((u\vee v\vee z)\wedge(u\vee v\vee\neg z)\)
with fresh \(z\); each unit \(u\) by all four clauses
\((u\vee\pm z\vee\pm w)\) on fresh distinct auxiliaries.
With \(C={k\choose2}\), the resulting proper three-literal CNF has
\[
n'=2qL+2q+qC+2k(q-1)+4,\quad
m'=4qL+2qC+4k(q-1)+8.
\]
Its fixed-record bit length may be set to
\(N=(4m'+2)\lceil\log_2(64(n'+m'+1))\rceil\).
For all \(\eta\), its unsigned clause supports, \(n',m',N\)
are identical and its SAT label is the parity above.
\end{lemma}
\begin{proof}
The first affine link uses two binary clauses per component, each
padded to two ternaries. Each of \(L-1\) XOR3 links contributes
four ternaries. Each of \(qC\) local exclusions contributes two;
each of the \(2k(q-1)\) edge binary clauses contributes two,
and both units contribute four ternaries each.
The original components contain \(2qL\) variables;
one fresh padding variable per binary clause and two per unit give
the displayed count. Truth tables verify the logical equivalences,
and each clause has three distinct noncomplementary variable IDs.
Only signs of a fixed pair of edge clauses change with \(\eta\).
\end{proof}

For fixed \(k\) support enumeration here is plainly source-computable;
for varying \(k\) the canonical recognizer can generate the \(k+1\)
signatures in \(O(qk^2+qh)\) word operations after charged source reading,
whereas enumerating the full projected affine basis visits \(2^k\)
possible interface strings. The full canonical CNF itself contains
\(\Theta(qk^2+q h+qk)\) clauses before encoding.
This construction has a still cheaper source-recognizing parity scan.
A complete arbitrary-language exact fallback retains correctness
outside this recognizable family but no useful general worst-case
polynomial guarantee. No all-input ARC successor follows.

\section{Adaptive rank is not a monotone obstruction}
\begin{lemma}[Change-of-observation-channel firewall, PROVED/EXACT]
For fixed affine solution relation \(E\) and fixed observed set \(P\),
adding constraints to \(E\) cannot increase its projected affine
dimension. However, if observed sets are allowed to change with the
algorithmic state, the projected affine rank may \emph{increase}
while the feasible interface support \emph{decreases}.
\end{lemma}
\begin{proof}
For fixed \(P\), intersecting an affine solution space with further
affine equations shrinks its direction subspace; projection cannot
increase rank. For the second assertion let
\(E=\{(s,a,b):s=a\oplus b\}\). Initially observe \(P=\{s\}\), whose
projection dimension is one and feasible support has two values.
Add the source-visible unit constraints \(a=0,b=0\), and let
\(P'=\{s,a,b\}\). The projection of the unchanged affine
space \(E\) to \(P'\) has rank two, but the feasible relation
\(E\land(a=0)\land(b=0)\) contains only \((0,0,0)\).
The two quantities describe different objects. No runtime lower
bound may sum or compare these ranks as though they were one
monotone adaptive potential.
\end{proof}
