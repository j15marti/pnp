\section*{Semantic-separation lemma}
\paragraph{LOCALSEM1.}
For canonical CCSPC-1 as written, correctness on the realized challenge stream does not logically imply that the current response is winning for every possible future challenge continuation. Equivalently,
\[
\operatorname{CorrectRealizedPath}(A,X,G)\Longrightarrow W_i(X,t_i,w_i)
\]
is not supplied by CCSPC semantics alone.

\paragraph{Proof.}
CCSPC-1 defines the actual transition using the fresh realized block \(B_i\), and explicitly states that only one path is realized. A machine correct on that stream is required to return correct local transition values along that stream. The predicate \(W_i\), by contrast, universally quantifies over every legal next challenge and recursively demands a response for every continuation. Thus \(W_i\) is a strengthened game objective. Moving from realized-path correctness to \(W_i\) adds universal future-challenge obligations absent from the original correctness condition. No implication follows without an additional compiler or robustness theorem. \(\square\)
