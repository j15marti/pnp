\section{An exact two-read program for hidden weighted bit}
For $b\in\{0,1\}^h$, put $c=\sum_{i=1}^h b_i$ and
\[
\operatorname{HWB}_h(b)=
\begin{cases}
0,&c=0,\\ b_c,&1\le c\le h.
\end{cases}
\]
A deterministic \emph{two-pass ordered branching program} is a finite acyclic Boolean decision DAG in which each root-to-terminal path queries variables in the order $b_1,\ldots,b_h,b_1,\ldots,b_h$, possibly terminating before the end of the second pass. Distinct nodes are charged; each nonterminal node queries one indexed input bit and has two directed outgoing arcs. No arbitrary conditional jump or SAT oracle is free.

\begin{theorem}[Read-twice construction, PROVED/EXACT]
For every integer $h\ge1$, there exists a deterministic ordered two-pass branching program computing $\operatorname{HWB}_h$ on \emph{all} $2^h$ inputs with
\[
V_{\mathrm{internal}}=h(h+1),\qquad
V_{\mathrm{total}}=h(h+1)+2,\qquad
E_{\mathrm{directed}}=2h(h+1).
\]
Every run reads exactly $h+c$ source bits when the input has Hamming weight $c>0$, and exactly $h$ when $c=0$. Hence at most $2h$ bit-read operations are performed; the live counter/index description needs $O(\log(h+2))$ bits.
\end{theorem}
\begin{proof}
In the first pass create one node $(1,i,c)$ for each $0\le i<h$ and $0\le c\le i$. This node reads $b_{i+1}$ and transitions to $(1,i+1,c+b_{i+1})$, except at $i=h-1$ when it enters the second stage with final count $c+b_h$ (or outputs zero for count zero). There are
$\sum_{i=0}^{h-1}(i+1)=h(h+1)/2$ first-stage nodes.

For each possible final positive count $c\in\{1,\ldots,h\}$, create nodes $(2,c,j)$ for $j=0,\ldots,c-1$. Each reads $b_{j+1}$; if $j<c-1$ both arcs go to $(2,c,j+1)$, and if $j=c-1$ the outgoing arc labelled $a$ goes to terminal $a\in\{0,1\}$. Thus the second stage reads exactly $b_1,\ldots,b_c$ and outputs $b_c$. It contains $\sum_{c=1}^h c=h(h+1)/2$ nodes. The union is an acyclic two-pass DAG with exactly $h(h+1)$ nonterminal nodes and two terminals; each nonterminal has exactly two directed outgoing arcs.

Induction on $i$ proves the first-stage counter equals the Hamming weight of the bits already read. The second stage then returns the $c$-th input bit, as required. The first-stage counter and second-stage pair $(c,j)$ use $O(\log h)$ bits on a uniform algorithmic implementation. \qed
\end{proof}

\begin{theorem}[General count-selected-bit upper bound, PROVED/EXACT]
Let $g:\{0,\ldots,h\}\to\{0,\ldots,h\}$ be a fixed efficiently computable selector, with output zero when $g(c)=0$, and set
$f_g(b)=b_{g(|b|)}$ otherwise. A deterministic two-pass ordered branching program for $f_g$ has at most
\[
2+\frac{h(h+1)}2+\sum_{c=0}^{h}g(c)
\]
nodes and needs at most $h+\max_c g(c)$ input-bit reads. The construction is uniform when $g$ is computable from $(h,c)$ in polynomial time.
\end{theorem}
\begin{proof}
Retain the counting first pass and build one second-stage chain of $g(c)$ queries for each terminal count $c$, omitting the chain for $g(c)=0$. At the last query output its value; preceding queries advance along both arcs. The displayed node count is explicit and the stage-one/second-stage invariants prove correctness. For $g(c)=c$, this recovers the preceding theorem. \qed
\end{proof}

\section{Comparison with all-order OBDD hardness}
Bollig, L\"obbing, Sauerhoff and Wegener review and sharpen the known \emph{exponential} OBDD-size lower bound for $\operatorname{HWB}_h$ for \emph{every fixed variable order}. An OBDD reads variables at most once in one fixed order. This is a \textbf{KNOWN THEOREM} in a restricted representation model, not a uniform SAT decision-time lower bound.

The above read-twice construction proves the exact contrast
\[
\operatorname{OBDDsize}(\operatorname{HWB}_h)=2^{\Omega(h)}
\quad\text{(all one-pass orders)},\qquad
\operatorname{2OBDDsize}(\operatorname{HWB}_h)\le h(h+1)+2.
\]
An extra pass allows previously seen source bits to be reread after the data-dependent index is calculated. The terminal SAT label is unchanged; the required representation model changes.

HWB-OBDD68 supplies the canonical proper-3CNF source family $F_h(b)$ with
\[
n_h=9h^2+22h+8,\quad m_h=15h^2+34h+12,\quad
N_h=(4m_h+2)\left\lceil\log_2(64(n_h+m_h+1))\right\rceil.
\]
Every $b_i$ controls exactly one independent signed-literal input bit, all other source bits are fixed, and
$\operatorname{SAT}(F_h(b))=\operatorname{HWB}_h(b)$.
Restriction of a full-input SAT OBDD to these independent sign bits yields an OBDD for HWB, so the exponential lower bound transfers to that \emph{OBDD representation task}.

For deciding only the \emph{promised canonical family}, validate the source grammar and all fixed words in a complete charged scan, then read its $h$ sign-bit addresses in two passes using the program above. Under the declared fixed-word representation, $w=\lceil\log_2(64(n_h+m_h+1))\rceil$ and $N_h=\Theta(h^2\log h)$; source validation plus the two reads uses $O(N_h/w+h)$ word operations, assuming the canonical generator's fixed-record addressing, and polynomial time even under conservative bit-level accounting. This does not omit parsing or certificate validation. On unrecognized ordinary proper-3CNFs, a total exact decider can instead use exhaustive SAT search. Hence all-order OBDD representation hardness is compatible with a total uniform exact SAT decider running polynomially on \emph{every member} of this family.

This bypass also applies to DAG merging and memoization: their presence is optional, and the two-pass program is already an explicit DAG. It does not require witness history, clause learning, DNNF compilation, or a solver's internal-state hash.

Thus source SAT and target SAT are equivalent, but the map is generally \emph{not parsimonious}. Proof-system/witness counts must not be silently transported.
