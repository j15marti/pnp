\section*{LSPV-3 fixed-coin collision audit and reconstruction quantifiers}
\textbf{STATUS: OPEN.} P versus NP remains open.

\paragraph{Preflight and target.}
Repository AGENTS.md, CODEX.md, the pnp-research skill, root main.tex, MAIN 0202, the newest verified specialist reports visible at run start, and relevant CLAUDE material were reviewed. The newest LSPV-2 scheduled cycle had no verified artifact newer than KER1 at preflight, so its new scientific content is not assumed here. The two active reconstruction obstacles are: (i) whether the actual vMS commit-and-evaluate algebra gives a fixed-coin collision-extraction theorem eliminating the opposite-output condition; and (ii) whether all computation-to-SAT stages are model-matched strongly enough to replace symbolic encoding exponents by one.

\paragraph{Exact reconstruction predicate.}
Fix one acquired and exactly size-normalized deterministic predicate $Q$, one requested coordinate $i$, and all Arthur randomness $r$. Let $J$ contain the constant number of density-estimation SAT queries together with the three Corollary 4.6 queries for success, output zero, and output one. If $\Phi_j(Y_j;z,Q,i,r)$ is query $j$ and $a_j$ is its claimed truth value, define
\[
\operatorname{ExactSAT}(a;z,Q,i,r)=
\exists Y^+\ \forall Y^-\!
\bigwedge_{j\in J}
\left[
(a_j\Rightarrow\Phi_j(Y_j^+))
\wedge
(\neg a_j\Rightarrow\neg\Phi_j(Y_j^-))
\right].
\]
For a deterministic consistency predicate $C_b$ implementing the density threshold, success, output consistency, and selected bit $b$, fixed-randomness reconstruction has form
\[
\exists a,Y^+\ \forall Y^-\;
C_b(z,Q,i,r,a)\wedge\operatorname{ExactSAT}(a;z,Q,i,r).
\]
All YES witnesses merge into one existential block and all NO conditions merge into one universal block because the query set is constant and parallel. Parallelism does not delete the universal block.

\paragraph{PROVED/EXACT source-level fixed-coin obstruction.}
The published vMS definitions separate two probabilities. Definition 3.4 says resilient partial single-valuedness holds with high probability over Arthur randomness in the commitment phase. Definition 3.3 defines partial single-valuedness itself by bounding, for every Merlin strategy, the probability over the evaluation protocol that an output differs from a fixed value or failure. Lemma 4.4 inherits precisely this resilience/partial-single-valued guarantee.

Therefore even after a commitment lies in the high-probability good set, the cited theorem does not assert deterministic pointwise binding for every fixed evaluation-randomness string. In particular it does not imply
\[
\forall r,Q,i\quad \neg(E_0(r,Q,i)\wedge E_1(r,Q,i)).
\]
This is stronger than merely observing that Lemma 4.4 is probabilistic over commitments: its inner PSV guarantee is also probabilistic at evaluation time.

Corollary 4.6 matches this quantifier structure. After selecting Arthur randomness for the reconstructed protocol, the algorithm asks SAT whether some Merlin response succeeds and whether successful responses output zero and one, and declares failure when the output answers are inconsistent. Thus the published fixed-coin reconstructor retains an explicit semantic consistency test.

\paragraph{Collision extraction and special soundness.}
Classical special-soundness mechanisms extract a witness from two accepting transcripts with a shared first message and distinct challenges. This is an \textbf{ANALOGY/CANDIDATE} only. The vMS theorem does not state that two opposite successful fixed-coin openings are forbidden. Such openings can fall inside the bounded bad evaluation event permitted by PSV without contradicting Lemma 4.4. Consequently the implication
\[
\operatorname{Accept}_0(\pi,r,w_0)\wedge
\operatorname{Accept}_1(\pi,r,w_1)
\Longrightarrow
\text{locally checkable forbidden algebraic witness}
\]
is not supplied by the published theorem.

A construction-specific strengthening remains logically possible. It would have to be proved from the exact Shaltiel--Umans evaluation equations, not from resilient PSV alone. The witness must be checkable without SAT, coSAT, universal enumeration of Merlin responses, or a cryptographic hardness/random-oracle assumption.

\paragraph{Viola composition.}
Viola proves the known near-linear simulation
\[
\mathrm{BPTime}(t)\subseteq\Sigma_3\mathrm{Time}(t\,\mathrm{polylog}\,t).
\]
When the reconstruction SAT formulas depend on Viola's final existential selector $\ell$, literal substitution yields the dependency pattern
\[
\boxed{
\exists\sigma\ \forall u\ \exists(\ell,a,Y^+)\ \forall Y^-\ R
}.
\]
No source theorem reviewed here permits commuting $Y^-$ before $\ell$ or deleting it. Qualitative collapse under the counterfactual $P=NP$ does not by itself provide a quantitative near-linear dependency-preserving flattening.

\paragraph{Compilation and exponent ledger.}
For each elimination/compilation stage $q\in\{0,1,2,3\}$ write
\[
N_{\mathrm{SAT},q}\le L_q^{b_q+o(1)}.
\]
If the assumed SAT decider runs in time $N^k$, the conservative composition remains
\[
\boxed{
\alpha_{\mathrm{det}}
\le
\alpha_0\,(b_0b_1b_2b_3)k^4+o(1)
}
\]
with status \textbf{CONDITIONAL}. Robson's $O(T\log T)$ RAM-to-SAT theorem supports exponent one only when the actual RAM model and stage hypotheses match that reduction. This run does not establish that match for all four stages. The statement $\alpha_{\mathrm{det}}\le k^4\alpha_0+o(1)$ therefore remains conditional on $b_0=b_1=b_2=b_3=1$. No theorem here proves that four powers of $k$ are necessary; this is conservative eager-elimination accounting.

\paragraph{Post-quantum structural toolkit.}
\begin{itemize}
\item[] \textbf{EXACT OBJECT/THEOREM TRANSFER:} Schur-square shortening, puncturing, and filtration apply to the upstream code object when the actual code hypotheses are verified. They do not alter the fixed-coin reconstruction quantifier by themselves.
\item[] \textbf{ANALOGY/CANDIDATE:} quadratic-relation matrices and Hilbert/syzygy invariants may expose algebraic equations among commitment evaluations. The missing bridge is an exact polynomial presentation of the vMS/SU fixed-coin acceptance relation and a proof that opposite outputs violate one locally checkable relation.
\item[] \textbf{EXACT counting identity but FAILED binding transfer:} collision entropy controls image size for a finite proof-to-node map but does not distinguish opposite outputs for one commitment. LSPV-4's minimax theorem further shows that cardinality and kernel size alone cannot force stronger image growth.
\item[] \textbf{ANALOGY/CANDIDATE:} LWE-style external black-box extraction is architecturally attractive because it avoids forcing an arbitrary solver to materialize an internal resource. Bogdanov--Trevisan barriers show generic nonadaptive NP worst-case-to-average-case self-correction is not free. No unconditional solver-to-collision reduction is known here.
\item[] \textbf{ANALOGY/CANDIDATE:} special soundness gives the desired two-transcript-to-witness pattern, but the challenge/transcript hypotheses are not presently matched to vMS.
\item[] \textbf{FAILED TRANSFER:} collapse-binding, LWE hardness, and random-oracle binding cannot be unconditional proof steps.
\end{itemize}

\paragraph{Cross-domain barrier transfer.}
Coding unique-decoding gives deterministic incompatibility inside a certified decoding radius, but vMS fixed-coin acceptance has not been shown to certify such a radius: \textbf{ANALOGY/CANDIDATE}. Syzygy/graded-Betti distinguishers show that shortening can reveal hidden algebraic code structure after simpler invariants saturate, but do not supply transcript binding: \textbf{ANALOGY/CANDIDATE}. VLSI routing/area-time, distributed communication cuts, and control barrier/Lyapunov theorems require model-locality or a declared state evolution not forced on unrestricted SAT: \textbf{FAILED TRANSFER}. Proof-complexity lower bounds remain proof-system-specific absent an arbitrary-algorithm transfer.

\paragraph{Barrier audit.}
The present reconstruction argument remains compatible with semantic-oracle replacement: an oracle can answer the SAT consistency questions directly. The RMV/low-degree machinery is algebraic, so no nonalgebrizing hinge is supplied. DEAD/COPY proof padding can duplicate Merlin responses; INTERP/RECOMP can alter their representation. TransportCert/TC4 may require primitive execution accounting but cannot prohibit a polynomial foreign SAT algorithm under the assumed $P=NP$ world. None of these observations is an unrestricted lower bound.
