\section{Precise original-source-authenticated TEST calculus}
Source $F$ is an independently supplied, syntactically validated proper strict 3-CNF with a declared finite variable universe. Each record carries an arbitrary-length canonical ASCII decimal ID; a sorted, duplicate-free list $\Gamma$ of signed assignments; a tag; and exact references to \emph{earlier} IDs. Neither ID nor variable name must fit a floating-point number.

\textbf{LEAF$(j,\Gamma)$} costs zero and asserts $F\wedge\Gamma\models\bot$ only if the original source clause $C_j$ exists and every one of its three literals is false under $\Gamma$. \textbf{WEAKEN$(u,\Gamma')$} costs zero and requires the previous node $u$ to prove contradiction under $\Gamma\subseteq\Gamma'$ with consistent assignments. \textbf{CASE$(x,u_0,u_1,\Gamma)$} costs one, requires $x\notin\Gamma$, distinct preceding parents with contexts precisely $\Gamma\cup\{x=0\}$ and $\Gamma\cup\{x=1\}$, and concludes contradiction under $\Gamma$. The final record must have empty context. Every record ID is globally unique; sharing references an existing ID and never pays for that node twice. Zero-cost LEAF/WEAKEN may occur arbitrarily often subject only to the explicit certificate length.

These are \emph{NOT} authenticated historical $R_{\mathrm{mix341}}$ rules: no free native CASE, WEAKEN, LOCAL-CONVERT, DEF, RES-to-AND3 view, GF(2), private/exported interface or DISCHARGE is asserted.

\begin{theorem}[Constructive canonical-ID/context local logspace checker, restricted scope]
For the explicitly encoded topological TEST grammar above, there is a uniform deterministic read-only-source/read-only-certificate checker for $(F,P)$, where $N=|F|$ and $B=|P|$, satisfying
\[
S_{\mathrm{native}}(N,B)=O(\log(N+B)),\qquad
T(N,B)=(N+B)^{O(1)}
\]
on a dense-work-storage implementation of the random-access model specified in Fortnow--Lipton--van Melkebeek--Viglas (2005), Section 2.1. The theorem permits canonical decimal node IDs and explicit assumption contexts of arbitrary length bounded only by $B$, and unbounded numerical values; it is not conditioned on a fixed word width or a bound on proof depth.
\end{theorem}
\begin{proof}
Choose a flat token-delimited representation in which fields, context lists and signed literals are read-only substrings with indexed start/end positions. The parser validates delimiter and token syntax by repeated rescanning. At most a fixed number of $O(\log(N+B))$-bit counters and offsets are kept in a \emph{contiguous} work region. Compare arbitrary canonical integers by first comparing their token lengths and then their digits lexicographically; compare ID equality by character-by-character scans. Thus no huge decimal token is converted to a machine integer, and e.g.\ \texttt{9007199254740992} and \texttt{9007199254740993} remain distinct. For each record, search every earlier ID to authenticate parents and search all preceding IDs to reject duplicates, re-reading earlier records rather than retaining a map. Context sortedness and contradiction checks are positional comparisons/merges of explicit sorted token lists; original source clause falsification uses three literal lookups with rescans. Every operation has a polynomial bound on nested input scans and keeps $O(\log(N+B))$ writable bits. After verifying all records, check the empty-root scope. A topological induction proves each LEAF, WEAKEN and CASE source-sound: the last uses exhaustive dichotomy on its pivot. Reuse is by identity and context compatibility, not recomputation or a second paid derivation. The checker writes only to dense low-index work positions, making the high-water measure $O(\log(N+B))$. Parsing and final goal checks are charged.
\end{proof}

\section{A useful anti-transfer corollary}
This is a checker of \emph{the pair} $(F,P)$ on two separately supplied read-only tapes, not a uniform SAT decider on input $F$ alone. If $B$ is exponential in $N$, then $\log(N+B)$ can be $\Theta(N)$. Generating, discovering, acquiring, writing or embedding $P$ is not covered by pair checking. An NP machine existentially accepting on a true SAT witness is different from deterministic UNSAT: a rejecting NP path proves nothing by itself. The abstract configuration set size, the full proof DAG size and proof-paid work do not independently lower-bound native peak work space.
