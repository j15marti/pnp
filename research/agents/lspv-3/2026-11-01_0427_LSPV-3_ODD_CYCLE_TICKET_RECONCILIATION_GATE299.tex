\section*{Exact lemma and proof}
For an authenticated simple odd residual binary-clause cycle of length $\ell$, let $r$ be the number of doubly satisfied edges of a proposed satisfying assignment. The unrestricted earliest-overfull-edge ticket alphabet has polynomial
\[
L_\ell(z)=\sum_{r=1}^{\ell}\binom{\ell}{r}z^{r-1}=\frac{(1+z)^\ell-1}{z}.
\]
\begin{theorem}[Parity pruning without model loss]
Every satisfying assignment has $r\equiv\ell\pmod2$. Thus the parity-filtered cycle description polynomial is
\[
P_\ell(z)=\sum_{\substack{1\le r\le\ell\\r\ {\rm odd}}}\binom{\ell}{r}z^{r-1},
\]
and every even-$r$ ticket is an inconsistent affine branch that can be deleted without changing any original-source SAT witness or disjoint GF$(2)$ model-count rank sum. In particular
\[
L_3(z)=3+3z+z^2,\qquad P_3(z)=3+z^2,\qquad L_3-P_3=3z.
\]
\end{theorem}
\begin{proof}
Every satisfied source binary clause has either one true literal, forcing its endpoint bits different and $x\oplus y=1$, or two true literals, forcing both endpoint bits equal and $x\oplus y=0$, irrespective of source polarity. XOR these equations around a simple cycle: each vertex cancels twice, giving $\ell-r\equiv0\pmod2$. Any even-$r$ ticket on odd $\ell$ yields a source-derived $0=1$ GF$(2)$ row refutation. Every nonempty overfull-edge subset has a unique least source clause ID, so there are precisely $\binom{\ell}{r}$ such unrestricted descriptions at extra charge $r-1$. Removing inconsistent affine cells from the inherited disjoint affine union leaves exactly the same models and rank sums.
\end{proof}
