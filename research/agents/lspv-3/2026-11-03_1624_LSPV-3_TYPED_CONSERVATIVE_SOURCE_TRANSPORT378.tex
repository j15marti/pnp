\section*{Published hardness and fixed calculus}
Urquhart (1987) and Ben-Sasson--Wigderson (2001) prove exponential \emph{ordinary DAG Resolution} refutation-size lower bounds on odd Tseitin CNFs over suitable bounded-degree expanders. Cubic instances with $h$ vertices have $n=3h/2$ edge variables, $4h$ three-literal source clauses and $N=\Theta(h\log h)$ input bits. This is not a lower bound on unrestricted SAT machines or on any stronger proof system. LSPV-2/341 establishes the exact $W_{R_{\rm mix341}}=4h-1$ on every connected bridgeless cubic odd-Tseitin source using local AND3 parity extraction and binary GF(2) additions. Rmix341 has unit-cost distinct RES, AND3, XOR, LOCAL-CONVERT and paid two-input conservative DEF nodes; sources are free, DAG sharing is charged once. Logical node count, proof evidence bits, checking work and machine memory are different measures.

\section*{Tagged source-extension lifting}
Let $F(X)$ be any valid UNSAT CNF and $D=(y_i=g_i(u_i,v_i))_{i=1}^{k}$ any acyclic list of fresh conservative two-input gates from the unchanged Rmix341 DEF library. Set $G=F\wedge\Gamma(D)$, with $\Gamma(D)$ the gate defining CNF. Define $\operatorname{supp}_X(x)=\{x\}$ for original variables, and recursively $\operatorname{supp}_X(y_i)=\operatorname{supp}_X(u_i)\cup\operatorname{supp}_X(v_i)$. This overapproximates functional dependency, and is used for guards, not as an arbitrary-machine cost lower bound.

Define $R^{\rm tag}(G;X,D)$ with the additional gate clauses offered as tagged free source views, but its local AND3/LOCAL-CONVERT original-support guards measured against base $X$. Assume two precise syntax properties of the installed Rmix341: (V) each paid DEF exposes each defining CNF clause as a citable typed view; (T) substituting these paid views into any tagged-legal inference preserves original-support guard and rule legality. They must be authenticated against the actual checker before claiming an unconditional Rmix341 transfer.

\begin{theorem}[Scoped additive lifting]
Under (V) and (T), for all UNSAT $F$ and all acyclic $D$ of $k$ gates,
\[
W_{R^{\rm tag}}(F\wedge\Gamma(D);X,D)
\ \le\ W_{R_{\rm mix341}}(F)
\ \le\ W_{R^{\rm tag}}(F\wedge\Gamma(D);X,D)+k .
\]
Given a fully explicit input proof of $B$ encoded bits, the constructor and checking of the transported proof can be bounded polynomially in $B+|F|+|D|$ if explicit local validators run in polynomial time. No bound on arbitrary-algorithm SAT time or proof-discovery complexity is asserted.
\end{theorem}
\begin{proof}
The first inequality ignores the new defining clauses: every $F$ refutation is also valid in tagged $G$. For the second, take a minimum tagged proof DAG, insert the $k$ paid DEF nodes in topological order and replace each used gate-source-clause occurrence by the appropriate view of its one paid DEF node. By (V),(T) every resulting inference is legal, its base support is unchanged and all original input clauses remain identical. Each old shared node is replayed once and at most $k$ additional distinct nodes are charged. The proof ends in contradiction, yielding the bound. Explicit remapping and serialization are polynomial in provided evidence length under the stated checker condition.
\end{proof}

\section*{Explicit original-support guard counterexample}
Use the already certified odd-charge $K_4$ Tseitin CNF on six original edge variables $x_1,\ldots,x_6$. Append three conservative gate definitions
\[
z_1=x_1\land x_2,\qquad z_2=z_1\land x_3,\qquad y=z_2\land x_4.
\]
The expanded CNF contains the two source clauses $C_1=(\neg y\lor z_2)$ and $C_2=(\neg y\lor x_4)$. In an \emph{untagged new parse} of $G$, their exact conjunction has lexical original-variable support $\{y,z_2,x_4\}$ of cardinality 3, permitting one AND3 node. After restoring the base-variable type map in $F$, the same literal node has base support $\{x_1,x_2,x_3,x_4\}$ of cardinality 4 and fails AND3's guard. This \textbf{falsifies direct node-for-node legality replay}. The eight-row local truth-table mask is 143 in $y,z_2,x_4$ order. After substituting the definitions the example factor is tautological, so a clever translator can delete it: this does NOT establish any minimum proof-cost separation or disprove a general polynomial compiler.
