\section*{Exact target and quantifiers}
Retain the reconstruction predicate
\[
\Psi(x,Q)=\exists\sigma\,\forall u\,\exists z\,\forall y\,R(x,Q,\sigma,u,z,y).
\]
FULLSKOLEM1 and PHABSORB1 allow fixed-level semantic absorption under the counterfactual \(P=NP\), subject to their declared balance, totality and uniformity conditions. The question here is quantitative: when the absorption is implemented using the fixed hypothetical SAT decider \(A\), what exponent remains charged?

Fix one deterministic SAT decider \(A\) such that on ordinary model-matched SAT inputs of written length \(S\),
\[
T_A(S)\le S^{K+o(1)}
\]
for one fixed but unknown constant \(K\). Consider any deterministic absorption procedure \(D^A\) on original scale \(n\) that makes at most
\[
q(n)=n^{\alpha+o(1)}
\]
sequential calls to \(A\), each on an explicitly constructed SAT instance of length at most
\[
S(n)=n^{\beta+o(1)},
\]
and otherwise uses \(n^{\gamma+o(1)}\) time. Charge construction/writing separately by an exponent \(\omega\), setup/classification by their declared exponents, and workspace separately.

\section*{PROVED/EXACT: black-box SAT-substitution upper ledger}
For the declared implementation,
\[
T_{D^A}(n)
\le
n^{\max\{\gamma,\omega,\alpha+\beta K\}+o(1)}
\]
before any additional independently declared setup/classification branches are added.

\paragraph{Proof.}
The nonoracle work and explicit writing contribute the first two branches. The total time spent in the \(q(n)\) sequential oracle substitutions is at most
\[
q(n)\,T_A(S(n))
\le
n^{\alpha+o(1)}
\left(n^{\beta+o(1)}\right)^{K+o(1)}
=
n^{\alpha+\beta K+o(1)}.
\]
Taking the maximum gives the stated upper ledger. This is an accounting identity for this implementation, not a lower bound on all implementations.

\section*{Corollary: qualitative PH collapse does not erase \(K\)}
If \(\beta>0\), the above implementation retains explicit dependence on the unknown starting exponent \(K\). Therefore the implication
\[
P=NP\Longrightarrow PH=P
\]
does not by itself justify replacing a fixed-level reconstruction predicate by a \(K\)-independent polynomial-time branch in the project's exponent recurrence. A \(K\)-independent exponent requires an additional theorem: for example a construction whose relevant SAT substitutions have \(\beta=0\), a non-\(A\) algorithm with independently bounded exponent, or a genuine recursive contraction in which the resulting \(K\)-dependence is subsequently closed by a proved recurrence.

This is one-way accounting. It does not prove that every possible PH-collapse implementation must pay \(\alpha+\beta K\), because a different algorithm might avoid these calls entirely.

\section*{Typed fixed-point insertion}
For a reconstruction edge whose local deterministic work is \(r_i\), total classification cost is \(\chi_i\), grouped setup/acquisition cost is \(\delta_i+p_i\), and recursive child work is \(\eta_i+g_i+\theta_i C_j\), retain
\[
C_i\ge
\max\{r_i,\chi_i,\delta_i+p_i,\eta_i+g_i+\theta_i C_j\}.
\]
If a PH-absorption branch is concretely realized by the above SAT substitution, add it as its own branch:
\[
C_i\ge
\max\{r_i,\chi_i,\delta_i+p_i,\alpha_i+\beta_iK,
\eta_i+g_i+\theta_iC_j\}.
\]
Do not merge \(\alpha_i+\beta_iK\) into \(r_i\) and then call \(r_i\) a \(K\)-independent polynomial constant. Do not add classification to setup unless the implementation actually multiplies those costs.

\section*{Hostile and barrier audit}
DEAD/COPY/DELAY can inflate the implementation cost but do not improve the ledger. INTERP/RECOMP can change representation and must be model matched. A maximal semantic SAT oracle can erase the explicit \(K\)-charge, showing that KABSORB1 is not a nonrelativizing lower-bound hinge; it is an implementation ledger. Horn, 2-SAT, affine/Tseitin and bounded-treewidth controls may admit independent algorithms and therefore reinforce the warning that this lemma is not a universal lower bound.

Viola's \(BPTime(t)\subseteq\Sigma_3Time(t\,\mathrm{polylog}\,t)\) simulation is explicitly relativizing, and his oracle lower bound shows limits of relativizing second-level simulations. This literature is consistent with, but does not itself prove, the present SAT-substitution ledger. No Natural-Proofs claim is involved.
