\section*{Exact theorem}
Let $C$ be a finite acyclic Boolean circuit with $n$ original inputs and $s$ total wires. Each gate is an explicitly given at-most-binary Boolean truth table defining a fresh output. Let $H(C)$ be its primal graph with all wires of each gate relation mutually adjacent. Suppose a supplied and verified tree decomposition $(T,B_t)$ of $H(C)$ has width at most $w$.
\begin{theorem}[Two-copy support test]
For every original input $i$ and named gate/input wire $v$, one can construct a Boolean-CSP instance $M_{i,v}$ such that
\[
M_{i,v}\text{ SAT}\iff\exists x\ f_v(x)\ne f_v(x\oplus e_i).
\]
Its primal treewidth is at most $2w+3$. All essential inputs of $f_v$ can therefore be computed exactly, given the decomposition, in $n\operatorname{poly}(s,|T|,w)2^{2w+4}$ time by standard Boolean-CSP dynamic programming. Every positive response permits reconstruction of a one-bit-flip witness.
\end{theorem}
\begin{proof}
Duplicate all original input and internal wires as $a^0,a^1$ and enforce each gate relation in both copies. Assert $x_j^0=x_j^1$ for $j\ne i$, $x_i^0\ne x_i^1$, and $v^0\ne v^1$. Circuit functional uniqueness proves the satisfiability equivalence.

For every decomposition bag $B_t$, use $\widehat B_t=B_t^0\cup B_t^1\cup\{v^0,v^1\}$. Copied gate scopes are covered by an original covering bag. Every input-pair equality/inequality scope occurs in a bag containing the original input; both outputs occur in every bag. Wire bags are connected because the original ones are. Thus each lifted bag has at most $2(w+1)+2$ wires, establishing width at most $2w+3$. Standard finite-domain tree-decomposition DP has at most $2^{2w+4}$ assignments per bag and polynomial per-bag operations. Repeat for each input and backtrack for witnesses.
\end{proof}
\noindent\textbf{Limits.} This is a certified-width diagnostic upper bound, not a general representation-independent hardness invariant. Equivalent circuits may have different treewidth; decomposition discovery, source authentication, reading and checking explicit definitions, tables, evidence output and peak memory are separate charged costs. Opaque LOCAL-CONVERT payloads do not qualify for a free gate rule. All legal $R_{\rm mix341}$ proofs need not visit this named wire, and no lower bound on $W_{R_{\rm mix341}}$ follows.
