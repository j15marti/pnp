\paragraph{Exact object.}
Let $P$ and $Q$ denote original positive and negative unsigned triple supports. Set $H=P\cap Q$, $B=\bigcup_{T\in H}T$ and $U$ the original indexed unpaired clauses, $r=|U|$. Every $T\in H$ imposes $\mathrm{NAE}(T)$, equivalently $1\le\sum_{i\in T}x_i\le2$. A selected-literal branch picks one satisfied literal from each $C_j\in U$. Discard opposing assignments to the same \emph{original} variable; otherwise a coherent partial map $p$ certifies all $U$ clauses true. Let $p_B=p|_B$.

\begin{theorem}[Two-sided dominance with complete-language correctness]
For every valid canonical $F$ and all coherent selected-literal branches $p,q$ of $F$:
\begin{description}
\item[(S)] If a complete $B$-assignment $w$ satisfies all paired NAE constraints and agrees with all pins of $q_B$, combining $w$ on $B$ with $q$ outside $B$ and filling other variables arbitrarily produces a complete SAT assignment of $F$.
\item[(U)] If $K_H\wedge p_B$ is genuinely UNSAT and $q_B\supseteq p_B$, no original-source SAT assignment extends $q$.
\end{description}
A total controller that authenticates the grammar, examines all $3^r$ selected-literal vectors, discards inconsistent choices, applies only certified factor results or a sound fallback, checks every accepted full witness against every original clause, and returns UNSAT only after exhaustive certified exhaustion or refutation decides every well-formed input correctly.
\end{theorem}
\begin{proof}
All paired constraints use variables in $B$; the selected unpaired original clauses are already satisfied. Any compatible $w$ therefore combines without changing a selected true literal. Any model extending $q$ would restrict to a model of $K_H\wedge p_B$ when $q_B\supseteq p_B$, contradicting certified UNSAT. Conversely every SAT model chooses at least one true original literal in every unpaired clause, yielding a coherent enumerated branch and a feasible paired core. Failure of a bounded prefix never certifies UNSAT.
\end{proof}
These are standard monotone assumption-subsumption facts, not a novel general SAT algorithm. An UNSAT cache record needs a correct factor decision/proof, not a timeout. Conflict-subcube minimization requires additional charged calls.
