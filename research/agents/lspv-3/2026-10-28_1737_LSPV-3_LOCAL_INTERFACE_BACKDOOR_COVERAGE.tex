\section{PROPOSE: four falsifiable mechanisms fixed before the search}
The missing lemma is polynomial uniform acquisition of complete, reusable UNSAT projections when ordinary source clauses share names across adaptively selected modules. We examined four mechanisms:
\begin{description}
\item[] \textbf{H1, local projection coverage.} If every variable shared by two source modules belongs to an authenticated $b$-bit interface and each module has a locally authenticated $q$-bit strong 2CNF backdoor, enumerate interfaces and \emph{only the selected rejecting module's} local backdoor to obtain all-UNSAT certificates in $2^{b+q}\operatorname{poly}(N)$. \textbf{RESTRICTED PROVED/EXACT.}
\item[] \textbf{H2, connected global hitting.} Even a connected, module-wise satisfiable proper-3CNF with minimal \emph{global} clause-hitting backdoor $\Omega(m)$ can have a constant-leaf adaptive UNSAT proof with paid deterministic acquisition. \textbf{RESTRICTED PROVED/EXACT.}
\item[] \textbf{H3, hidden-private merge.} Exact projections onto a purported separator can be conjoined safely even if the supposedly private names are secretly shared. \textbf{FALSIFIED}, including by an eight-clause proper-3CNF counterexample.
\item[] \textbf{H4, universal reusable syntax.} Small source CNFs and circuits necessarily have small exact OBDDs under every fixed summary order, or a small projection implies unconditional one-child power shrinking. \textbf{FALSIFIED} in the fixed-order OBDD model; the one-child universal target remains \textbf{OPEN}.
\end{description}

\section{BUILD: typed modular source and exact grammar}
For a proper three-CNF input of physical encoded length $N$, let $Y$ be an explicitly source-authenticated set of $b$ original boundary names. Its original clauses are partitioned by source IDs into modules $M_i(Y,Z_i)$ for $i=1,\ldots,k$, where $Z_i$ are pairwise disjoint private original name sets and no name outside $Y$ appears in two modules. A certificate header supplies a local private set $B_i\subseteq Z_i$ of size at most $q$. Authenticate all source clause IDs, literal signs, naming and coverage. The \emph{syntactic backdoor condition} is
\begin{equation}\label{eq:hit}
\forall i\;\forall C\in M_i:\quad |C|=3\implies \operatorname{Var}(C)\cap(Y\cup B_i)\ne\emptyset.
\end{equation}
After fixing all $Y$ and $B_i$, every source clause residual has width at most two. Modules of widths one/two are also permitted; all examples below use exactly three distinct variables per clause. Source modules and all private names must be verified from the actual original input bytes, not claimed semantic projection labels. Fix a constant $c>0$ and require $b,q\le c\log_2(N+2)$ for the claimed polynomial subclass; malformed headers or out-of-bound inputs are \emph{outside the declared typed language}.

For each boundary assignment $y\in\{0,1\}^Y$, the deterministic finder visits modules in original index order. For module $i$, it enumerates $\beta\in\{0,1\}^{B_i}$, forms \emph{actual} original-clause residuals $M_i|_{y,\beta}$, and computes exact 2SAT via implication SCC. If any residual is SAT, it retains an assignment to that residual and treats module $i$ as extendible at $y$. If \emph{all} residuals are UNSAT, it selects that module as a rejecting source for this $y$, and records for each $\beta$ either a falsified original clause or two actual source-ID-labelled implication paths $x\leadsto\neg x$ and $\neg x\leadsto x$. For each $y$ it stops scanning modules once a rejection is identified, but scans every module otherwise. If one $y$ admits every module, it reconstructs a global SAT model by disjoint private-name concatenation. If no such $y$ exists, it emits a full boundary tree whose leaves consist of the selected module's complete local-backdoor subtrees.

The UNSAT verifier independently checks the entire typed source, exact global $Y$ branching, both values of each selected $B_i$ variable, matching original names and ancestor assignment consistency, original source clause offsets, the residual width, and every 2SAT implication edge. An empty-clause terminal must be actually falsified by the branch. A path terminal must have correct signed endpoints, contiguous edges and source identities. Invalid source, grammar, branches, timeouts or proof offsets reject on the \emph{UNSAT}-verifier side. Any guest $A$ child calls would be charged separately and are \emph{not used} in this construction.

\begin{theorem}[Polynomially acquired complete modular source-SCC certificates]\label{th:modular}
For a fixed recognizable typed modular source satisfying \eqref{eq:hit}, the above \emph{single uniform deterministic program} decides both SAT and UNSAT correctly. On every UNSAT source it constructs a sound accepted source-ID-authenticated adaptive proof; on every SAT source it constructs a satisfying assignment, and \emph{no} source-authenticated UNSAT certificate accepts. With $2$-CNF decision costs charged, the number of tested residuals is at most $k2^{b+q}$, the branch depth of the resulting UNSAT proof at most $b+q$, and its emitted proof length is
\[
 L_{-}(N) = O(2^{b+q}N\log(N+2)).
\]
The SAT model has $O(N\log(N+2))$ bits under an explicit name/value encoding. Thus for $b,q\le c\log_2(N+2)$ both labels have polynomial deterministic acquisition and verification bounds with a uniform length-only proof cap.
\end{theorem}
\begin{proof}
For fixed $y$, because all original nonboundary names are disjoint between modules,
\[
  \exists_{Z_1,\ldots,Z_k}\bigwedge_i M_i(y,Z_i)
  \quad\Longleftrightarrow\quad
  \bigwedge_i \exists_{Z_i}M_i(y,Z_i).
\]
For each $i$, enumerating all $\beta$ exactly computes the truth of its existential projection, because every $M_i|_{y,\beta}$ is a 2CNF and SCC decides its satisfiability and produces a satisfying private extension when one exists. If a common $y$ supports every module, paste its extensions to obtain a satisfying original assignment. Otherwise for every $y$ at least one real module $i(y)$ rejects every local-backdoor assignment. All those 2CNF residuals are UNSAT, hence each yields an original-clause-labelled empty terminal or reciprocal implication paths. Complete boundary branching and then $B_{i(y)}$ branching proves UNSAT with depth $\le b+q$.

For soundness, suppose a SAT source admits such a certificate. Restrict a globally satisfying assignment to its boundary branch $y$. The chosen module's $B_i$ assignment must occur in the complete subtree. Its residual is satisfiable by the same global assignment, contradicting the claimed authenticated empty clause or contradictory SCC paths. Source-name equality is essential; omitted assignment branches reject. The choice of a different selected module at different boundary values is legal because each subtree proves that boundary restriction UNSAT. Each SCC proof requires at most $O(N)$ implication edges and $O(\log N)$ physical ID bits per edge. With at most $2^{b+q}$ leaves and smaller headers, the displayed $L_-$ bound follows. The finder tests at most $k2^{b+q}$ honest 2CNF residuals, including all unsuccessful attempts and every side-specific worst history; no correctness bit is free.\end{proof}

\section{Connected hostile source with global backdoor exactly $m$}
Introduce one shared original boundary variable $y$ and for each $i=1,\ldots,m$ fresh private original names $a_i,t_i,c_i,d_i$. Choose a sign $\sigma_i\in\{+1,-1\}$, and put $\ell_i=y$ for $\sigma_i=+1$, $\ell_i=\neg y$ otherwise. The $i$th module consists of the following \emph{five} original proper ternary clauses, all with distinct names:
\begin{align}\label{eq:five}
 &(\ell_i\vee a_i\vee t_i),\quad
 (\ell_i\vee a_i\vee\neg t_i),\quad
 (\ell_i\vee\neg a_i\vee t_i),\\[-2pt]
 &(\ell_i\vee\neg a_i\vee\neg t_i),\quad
 (a_i\vee c_i\vee d_i).\nonumber
\end{align}
Every clause and its precise original source ID is physically present; there are $4m+1$ original variables and $5m$ clauses, so $N=\Theta(m\log(m+2))$ in a conventional delimited encoding. The incidence graph is connected because all modules share $y$ and their last clauses attach to $a_i$.

\begin{theorem}[Exact global-backdoor versus local-adaptive separation]\label{th:connected}
If at least one $\sigma_i=+1$ and another $\sigma_j=-1$, formula \eqref{eq:five} is UNSAT although every individual module is SAT. Its minimum \emph{global syntactic strong 2CNF clause-hitting backdoor} has size exactly $m$, while it has a full sound source-ID-authenticated adaptive UNSAT certificate of exactly four contradictory 2CNF leaves, branch depth two, and $O(\log(m+2))$ emitted bits. Both certificate acquisition and SAT/UNSAT decision on the \emph{whole signed family} are deterministic polynomial time. The result applies to connected ordinary proper 3CNF; it does \emph{not} claim strict signed exact-$(2,2)$ occurrence balance.
\end{theorem}
\begin{proof}
The first four clauses are equivalent to $\ell_i$: if $\ell_i$ is false, they become the four possible pair clauses on $a_i,t_i$ and are jointly UNSAT; if $\ell_i$ is true, they impose nothing. The fifth clause is satisfiable independently by $a_i=1$. Therefore the module projects precisely to the one-bit requirement $\ell_i$, proving individual satisfiability and global UNSAT for opposing signs. With all signs equal the global source is SAT. The private triple $\{a_i,c_i,d_i\}$ in the fifth original clause is disjoint from every other module's private triple, so any global clause-hitting set chooses at least one private name per module, hence size at least $m$. Choosing all $a_i$ meets \emph{every} clause, proving equality.

For the adaptive certificate branch on $y$. In the $y=0$ branch choose any source module demanding $y=1$; in the $y=1$ branch choose one demanding $y=0$. In either branch, assign $a_i=0$ or $a_i=1$ and the first four source clauses yield the two opposite residual unit literals $t_i$ and $\neg t_i$, with original source IDs. The two one-edge unit implications $t_i\to\neg t_i$ and $\neg t_i\to t_i$ form an authenticated SCC contradiction, giving exactly four leaves total. Only constantly many original clause IDs, names and edges are written, each costing $O(\log m)$ bits. Finding two opposing signs costs at most one full source scan plus output and parsing. Thus a linear-sized globally compulsory hitting set does not impose exponential adaptive proof size, nor even on a connected globally inconsistent source lacking any UNSAT individual module.\end{proof}

\section{Exact interface is necessary for context-independent reuse}
\begin{lemma}[Context-complete summaries and the hidden-name counterexample]\label{lem:interface}
Let $M(Y,Z)$ be a source with private names $Z$, and let $S(Y)$ be a proposed reusable exact summary. If for \emph{every} context $C(Y,W)$ with $W$ disjoint from $Z$ the formulas $M\wedge C$ and $S\wedge C$ have the same SAT status, then $S(Y)$ agrees pointwise with $\exists_Z M(Y,Z)$. Conversely this exact projection composes with all such contexts. The disjointness proviso cannot be dropped: there are two source-authentic proper 3CNF modules each of which projects to TRUE over $Y=\{x\}$, yet their conjunction is UNSAT because they secretly share one variable $u$ outside $Y$.
\end{lemma}
\begin{proof}
For each boundary tuple $y$, choose the context $C_y$ forcing $Y=y$. It has a satisfying extension with $M$ exactly when $\exists_ZM(y,Z)$ is true. Thus contextual equivalence implies $S(y)=\exists_Z M(y,Z)$ for every $y$. Conversely the private variables may be quantified independently of a context sharing only $Y$, giving the equality for all contexts. For the counterexample set $M_1=(u\leftrightarrow x)$ and $M_2=(u\leftrightarrow\neg x)$. Each permits both values of $x$ after quantifying $u$, but the conjunction is contradictory for each $x$. Pad the four binary equivalence clauses separately with fresh private $z$ variables using $(A\vee B\vee z)\land(A\vee B\vee\neg z)$; this produces eight proper ternary original clauses, and the pointwise argument survives. The now-shared $u$ must be moved into the separator or a proof must authenticate a stronger interface.\end{proof}

A related representation-dependent caution is $E_b(X,Y)=\bigwedge_{i=1}^b(x_i\leftrightarrow y_i)$. A fixed-order exact OBDD reading $x_1,\ldots,x_b$ before any $y_i$ must have at least $2^b$ distinct states at that cut: each different $X=x$ leaves a distinct residual function $[Y=x]$. Nonetheless $E_b$ is a linear-size 2CNF/circuit and admits an $O(b)$-size interleaved-order OBDD. Its standard private-variable clause padding gives linear-size proper-3CNF whose projection remains equality. Hence an exponential \emph{fixed-order compiler} cost is not an arbitrary adaptive algorithm or SAT hardness lower bound.

No one-head crossing lower bound or two-tape write/frontier inequality is transferred to indexed RAM or ordinary SAT. In the native two-writable-tape model, output physically printed on a writable tape contributes to that tape's visited cells and symbol changes. If a fixed universal machine requires another alphabet or head encoding, that implementation must additionally be charged; the displayed simulation is a coarse upper, not a tight head-movement theorem. The positive ordinary-family construction makes no claims about such lower bounds.

For $b,q\le c\log_2(N+2)$, a length-only cap $r(N)=C N^{1+2c}\log(N+2)$ with a sufficiently large fixed $C$ bounds every accepted UNSAT certificate in the typed promise. A fully clocked deterministic checker guesses/reads at most $r(N)$ symbols and rejects malformed, oversized or overtime UNSAT proofs. Its co-nondeterministic complement accepts SAT inputs on \emph{every} branch and has at least one rejecting branch for each UNSAT input; this uses no free deterministic proof finder. The deterministic ARC version \emph{does} pay finder costs above. The argument establishes no favorable coNTIME exponent for all ordinary SAT and no near-FLMV seed. SAT-side and UNSAT-side maxima are restrictions of the \emph{same fixed program}; favorable proof lengths and worst-case discovery costs cannot be substituted for one another.

For the strict proposed constructive criterion on an encoded class containing \emph{all ordinary SAT}, one must construct a uniform deterministic, answer-preserving, recursively closed map to one physical child of length at most $N^\lambda$, $0<\lambda<1$. Our boundary truth table or adaptive certificate does \emph{not} satisfy this: it may output $\Theta(2^bN\log N)$ bits, may be longer than its parent, and applies only to a recognizably tractable modular subclass. The role-2 cross-product one-step shrink applies to an NP-hard grammar but its compact child is not recursively in the same expanded grammar. Even a fully paid polynomial UNSAT proof finder on a restricted class is not the missing universal single-child construction.
