\section*{Exact implicit-interface model}
Fix finitely many deterministic exact procedure types \(P_1,\ldots,P_m\). Type \(i\) on length \(n\) uses charged local time \(n^{r_i+o(1)}\) and local workspace \(n^{\sigma_i+o(1)}\).

A channel \(e:i\to j\) has multiplicity at most \(n^{\eta_e+o(1)}\) and defines a child string \(y_e(x)\) of logical length
\[
m_e(n)\le n^{\theta_e+o(1)},\qquad 0\le\theta_e\le1.
\]
The child string need not be materialized. Instead there is a deterministic random-access bit generator \(G_e\) such that, on parent input \(x\) and index \(p\), it returns the exact bit \(y_e(x)_p\) in time
\[
n^{g_e+o(1)}
\]
and workspace
\[
n^{s_e+o(1)}.
\]
The generator description and any preprocessing needed by it are charged in local work or explicit channel costs. The child procedure accesses its input only through the declared random-access interface. SAME\_REALIZATION requires the generated bits to be exactly the source-defined child instance used by the return construction.

Same-scale edges \(\theta_e=1\) are allowed only when the source construction proves a nonexpanding encoded-length rule and a finite well-founded rank for consecutive same-scale recursion, as in CYCLEGAIN1.

\section*{PROVED/EXACT: implicit time composition}
Suppose type \(j\) runs in time \(m^{C_j+o(1)}\) on a materialized length-\(m\) input. In the implicit simulation, every child input-bit access can be answered by \(G_e\). Therefore one invocation through edge \(e:i\to j\) costs at most
\[
n^{g_e+o(1)}m_e(n)^{C_j+o(1)}
\le n^{g_e+\theta_e C_j+o(1)}.
\]
With \(n^{\eta_e+o(1)}\) invocations, the exact exponent inequality is
\[
\boxed{C_i\ge \eta_e+g_e+\theta_e C_j.}
\]
Together with local work,
\[
\boxed{
C_i\ge
\max\left\{
r_i,\max_{e:i\to j}(\eta_e+g_e+\theta_e C_j)
\right\}.
}
\]
This is a conservative black-box simulation bound: it charges one generator evaluation for every possible child input access and assumes no beneficial caching.

For a directed cycle \(\gamma=(e_1,\ldots,e_d)\), put
\[
\Theta_\gamma=\prod_{q=1}^d\theta_{e_q}
\]
and define
\[
J_\gamma=
(\eta_{e_1}+g_{e_1})
+\theta_{e_1}(\eta_{e_2}+g_{e_2})
+\cdots+
\left(\prod_{q=1}^{d-1}\theta_{e_q}\right)(\eta_{e_d}+g_{e_d}).
\]
Composition gives \(C_i\ge J_\gamma+\Theta_\gamma C_i\). Hence if \(\Theta_\gamma<1\),
\[
\boxed{C_i\ge\frac{J_\gamma}{1-\Theta_\gamma}.}
\]
CYCLEGAIN1 is recovered when \(g_e=0\) for all edges. If \(\Theta_\gamma=1\) and \(J_\gamma>0\), this exponent-erasure simulation has no finite solution. Thus streaming does not make current-scale computation free: it trades explicit representation space for charged bit-generation time.

\section*{PROVED/EXACT: implicit space composition}
Assume depth-first simulation and no persistent materialization of the child string. If type \(j\) uses workspace \(m^{\rho_j+o(1)}\), then its simulated workspace on edge \(e\) is
\[
n^{\theta_e\rho_j+o(1)}.
\]
A generator invocation uses \(n^{s_e+o(1)}\) workspace, and the parent uses \(n^{\sigma_i+o(1)}\). Reusing generator workspace between child accesses gives
\[
\boxed{
\rho_i\ge
\max\left\{
\sigma_i,\max_{e:i\to j}\{s_e,\theta_e\rho_j\}
\right\}.
}
\]
The logarithmic child-address register is absorbed in \(n^{o(1)}\). Persistent caches, preprocessing tables, retained parent frames, simultaneous child buffers, generator state, output staging, and recomputation must be added explicitly when present.

Therefore a same-scale edge \(\theta_e=1\) does not by itself force linear space if the child input is supplied through a proved implicit random-access generator with \(s_e<1\) and the child realization itself has \(\rho_j<1\). This sharpens CYCLEGAIN1's explicit-materialization gate without weakening it: explicit materialization of a length-\(\Theta(n)\) child still costs linear representation space.

\section*{PROVED/EXACT: space-floor criterion}
The space inequalities have no additive exponent analogous to \(\eta_e+g_e\); they are max-compositions. Along a cycle, inherited child workspace is multiplied by \(\Theta_\gamma\), while local/generator workspace floors remain. Thus cycle contraction can lower inherited child-space exponents, but never below \(\max\{\sigma_i,s_e\}\) encountered on the cycle. A subpolynomial-space target therefore requires every local and generator workspace exponent on the realized recursive graph to be \(o(1)\), not merely a contracting time recurrence.

\section*{Hostile controls}
\textbf{RECOMP:} recomputing child bits is exactly what \(g_e\) charges; repeated accesses multiply that cost through the child's time bound.

\textbf{DELAY/COPY:} delaying does not alter \(\theta_e\); copying calls changes \(\eta_e\).

\textbf{INTERP:} an interpreter may provide an implicit representation, but its bit-evaluation time and workspace become \(g_e,s_e\).

\textbf{Padding:} scale is measured against the unpadded source input; padding cannot manufacture a favorable \(\theta_e\).

\textbf{Memoization:} cached child bits can reduce repeated generator time but retained cache space must be charged. STREAMCOMP1 deliberately uses the no-cache upper bound.

\textbf{Easy controls:} Horn, dual-Horn, 2-SAT, affine/Tseitin, bounded-treewidth formulas, and independent products may admit cheap implicit residual generators. That is an upper-bound phenomenon and supplies no unrestricted SAT hardness.

\textbf{Semantic/algebraic oracle:} an oracle can answer generated semantic bits or algebraic summaries without obeying the ordinary generator cost. The theorem relativizes under consistent oracle replacement and supplies no nonrelativizing or nonalgebrizing hinge.
