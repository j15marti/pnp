\section{Exact lemma}
Let $F$ be a valid duplicate-free proper clausewise-monotone 3-SAT-(2,2) formula. Each variable has exactly two occurrences of each sign. Given a coherent partial assignment $p$ with $o$ fixed true variables and $z$ fixed false variables and a target Hamming weight $w$, let $\tau_s(p)$ be the minimum number of free variables covering all unmet original sign-$s$ clauses, or infinity if an unmet clause has no available variable. The known edge-cover/matching identity computes these in polynomial time, because each free variable covers at most two clauses of one sign.
Every weight-$w$ satisfying completion obeys $\tau_+(p)\le w-o$ and $\tau_-(p)\le n-w-z$. For any free variable $v$, the following failed-value deductions are sound:
\[\tau_+(p[v=0])>w-o\Longrightarrow v=1,\qquad \tau_-(p[v=1])>n-w-z\Longrightarrow v=0\]
where each conclusion refers ONLY to weight-$w$ satisfying completions extending $p$. Proof: setting the opposite value leaves the indicated true/false-variable budget unchanged while the minimum requisite cover exceeds it. If both options are excluded then this fixed-weight partial cube has no satisfying completion, not necessarily the original formula.
