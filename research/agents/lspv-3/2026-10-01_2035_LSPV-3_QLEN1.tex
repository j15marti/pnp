\paragraph{PROVED/EXACT in the declared query-writing model: query-length substitution lemma.}
Let \(M^{\mathrm{SAT}}\) be a multitape oracle Turing machine branch with total ordinary running time \(T\), where writing a query symbol to the oracle query tape costs one ordinary machine step. Let the SAT queries on that branch have lengths
\[
s_1,\ldots,s_m,\qquad S_{\max}=\max_i s_i.
\]
Then
\[
\boxed{\sum_{i=1}^m s_i\le T.}
\]
Assume a deterministic exact SAT decider \(A\) has running time
\[
A(s)\le s^{\kappa+o(1)},\qquad \kappa\ge1.
\]
For every fixed \(\varepsilon>0\), for all sufficiently large \(s\),
\(A(s)\le s^{\kappa+\varepsilon}\). Sequentially replacing all oracle calls on the branch gives
\[
\sum_i A(s_i)
\le
\sum_i s_i^{\kappa+\varepsilon}
\le
S_{\max}^{\kappa-1+\varepsilon}\sum_i s_i
\le
T S_{\max}^{\kappa-1+\varepsilon}.
\]
Letting \(\varepsilon\to0\) in exponent notation,
\[
\boxed{
\sum_i A(s_i)\le T\,S_{\max}^{\kappa-1+o(1)}.
}
\]
This is machine accounting, not a lower bound. It relies on charging explicit query writing. It does not apply unchanged to a unit-cost oracle interface that can name an exponentially long query without writing it.

\paragraph{Combined count/length bound.}
If an independent source-level census gives \(Q\) calls, then also
\[
\sum_i A(s_i)\le Q S_{\max}^{\kappa+o(1)}.
\]
Hence
\[
\boxed{
\sum_i A(s_i)
\le
\min\!\left\{
Q S_{\max}^{\kappa},
T S_{\max}^{\kappa-1}
\right\}S_{\max}^{o(1)}.
}
\]
If
\[
T(t)=t^{a+o(1)},\quad Q(t)=t^{\gamma+o(1)},\quad
S_{\max}(t)=t^{b+o(1)},
\]
the substitution exponent is at most
\[
\boxed{
\min\{\gamma+b\kappa,\;a+b(\kappa-1)\}+o(1).
}
\]
The first term is SGLCOST1's count bound; the second is the new query-writing bound.
