\item[] H2: This communication constraint forces a superlinear \emph{time} exponent on an indexed random-access machine. \textbf{FALSIFIED as an implication}: a source-validated indexed batching algorithm uses near-linear bit time at every declared buffer size.

\item[] H4: These facts imply uniformly affordable all-ordinary-UNSAT proofs or a joint same-machine ARC contraction from an arbitrary unknown polynomial SAT exponent. \textbf{OPEN}; no such implication follows.
\end{description}
All claims refer to one declared machine and one actual input. A hypothetical $P=NP$ yields only a finite unknown polynomial exponent $K$, not a deterministic SAT seed at $d=1.802$.

\section{Literal original sources and exact polarity}
Take the actual original 15-variable, 20-clause, proper signed exact-$(2,2)$ minimally UNSAT formula $W_1$ in \texttt{BACKDOOR-SCC-CERT130}. Its full clauses are given in the executable source, and its five-variable source-audited 2CNF backdoor is $\{2,4,7,14,15\}$. Flip both opposite-polarity occurrences at zero-based clause/slot positions $A=\{(6,0),(11,0)\}$ when $a=0$, and at $B=\{(9,2),(17,2)\}$ when $b=0$. Call the result $H(a,b)$. The exhaustive truth-table counts are
\[
(\#H(0,0),\#H(0,1),\#H(1,0),\#H(1,1))=(772,272,272,0).
\tag{1}
\]
The two sign flips preserve all signed occurrence counts and all supports. For each coordinate $i$ use genuinely private 15-name copies of $H_i^U(a_i,1-b_i)$ and $H_i^V(1-a_i,b_i)$, with disjoint variables across all $2m$ modules, and set
\[
D_m(a,b)=\bigwedge_{i=1}^m\left(H_i^U(a_i,1-b_i)\land H_i^V(1-a_i,b_i)\right).
\tag{2}
\]
By (1) and disjointness,
\[
\boxed{\operatorname{SAT}(D_m(a,b))\iff a=b.}\tag{3}
\]
Every source is an actual proper signed exact-$(2,2)$ three-CNF with $30m$ variables, $40m$ clauses, and $120m$ occurrences. In the canonical fixed-width binary signed clause-list encoding the $4m$ Alice-controlled rows occur first, the $32m$ public unaffected rows next, and the $4m$ Bob-controlled rows last. Literal identifiers and full header widths depend only on $m$, not the bit vectors. $N=\Theta(m\log(m+2))$; the public middle has $\Theta(N)$ physical bit length. All variables use authentic stable source names. Ordinary ASCII DIMACS renderings and two genuine ordinary PIN descendants were separately generated and parsed; the physical crossing argument is confined to the fixed-width layout.

\section{Indexed source-owner information transfer}
A source-bit probe is \emph{informative} if its literal sign depends on Alice's vector $a$ or Bob's vector $b$; all other bits are public. From a deterministic execution remove public source probes and coalesce consecutive informative probes to the same owner. Let $X(F)$ be the number of remaining switches between owners. Each probe, even public ones, still costs source-access bit time; $X$ is an \emph{additional} information/synchronization axis, not a physical head crossing, elapsed time, or memory usage.

Let $B_D(F)$ be a self-delimiting bit bound for the \emph{complete} transient work configuration of a single deterministic program $D$ on its actual input $F$: finite control, all visited writable cells, contents, addresses, tape/head locations, index registers, pending query state, and any readable output/cache. No distinct hidden per-input advice is allowed. For fixed $k$ sequential work tapes with indexed read-only input and $S(F)$ visited work cells, $B_D(F)=O_k(S(F)+\log(N+2)+1)$. For directly indexed sparse work storage whose visited addresses are polynomially bounded in $N+T$, conservatively $B_D(F)=O((S(F)+1)\log(N+T+2))$.

\begin{theorem}[Same-run indexed input-owner alternation/space tradeoff]\label{th:exchange}
Fix $m$ and an arbitrary total uniform deterministic decider $D$ correct on every $D_m(a,b)$ in the declared source encoding. Even when it uses arbitrary direct indexed \emph{input} probes, there is a single satisfying source $F=D_m(a,a)$ whose actual accepting run satisfies
\[
\boxed{(X(F)+2)\,B_D(F)\ge m-O(1).}\tag{4}
\]
Hence, on the fixed-$k$ sequential-work/one-indexed-read-only-input model,
\[
(X(F)+2)(S(F)+\log N+1)=\Omega(m),
\tag{5}
\]
and on a direct indexed work model with chargeable polynomial addresses,
\[
(X(F)+2)(S(F)+1)\log(N+T+2)=\Omega(m).
\tag{6}
\]
These restrictions hold on the \emph{same accepting input}, not by combining different solvers' time/space. They are not unrestricted-SAT machine lower bounds.
\end{theorem}
\begin{proof}
Partition the physically fixed source sign locations into the $a$-dependent rows and $b$-dependent rows; every other bit is a publicly computable function of $m$. Alice and Bob each know the deterministic program, public format, variable names and its machine convention. One party simulates it through any number of public probes and probes to its own rows until the next informative source probe belongs to the other party. It transfers the entire current configuration. At most $X+2$ configurations suffice, including initialization and final outcome. Each message describes its actual work contents, all index/head state, query state, and output control, so no unspecified semantic information is given for free.

This is an exact deterministic two-party protocol deciding $\mathrm{EQ}_m(a,b)$ by (3). All $2^m$ accepting diagonal pairs $(a,a)$ must have distinct full deterministic communication transcripts. Indeed, if $(a,a)$ and $(b,b)$ with $a\ne b$ had the same accepting transcript, deterministic rectangle/induction on message rounds would give that same transcript to $(a,b)$, incorrectly accepting an unequal pair. Counting self-delimiting finite binary transcripts forces one accepting diagonal transcript to carry at least $m-O(1)$ bits. Choose that actual input, bound each message by its actual complete configuration ceiling, and conclude (4). The stated encodings of finite-tape or indexed-work configurations give (5)--(6). No lower-bound assertion is made on a nondeterministic proof guess.
\end{proof}

\section{Matched upper control and distinct machine ledgers}
An indexed exact-source promise comparator first checks the complete source header, literal identifiers, occurrence balance, and all fixed row templates, paying $N^{1+o(1)}$ source-bit time. Using a buffer of $1\le B\le m$ bits, it reads Alice's data in batches of $B$, stores those values in charged writable cells, reads the corresponding Bob signs, and checks equality. It outputs an authentic module index at the first mismatch and otherwise correctly declares SAT on \emph{all promise inputs}. The same-machine bounds are
\[
X\le2\lceil m/B\rceil+O(1),\quad
S=O(B+\log N),\quad
T=N^{1+o(1)}.\tag{7}
\]
Thus $B=1$ gives logarithmic workspace and $\Theta(m)$ informative switches; $B=m$ gives $O(1)$ switches and a linear buffer. Informative transfer remains, but physical cross-gap \emph{distance} does not survive indexed access. It would be incorrect to infer $t+s\ge2$ for ordinary indexed RAM from any one-head tape crossing proof.

For \textbf{M1}, one single writable read/write tape begins with all $N$ input bits. Count time $T_1$, all physical head moves $H_1$, source-boundary crossings $C_1$, inspected positions $I_1$, output $L_1$, and total visited footprint $P_1\ge N$. The previous one-tape near-quadratic crossing theorem for this easy encoding is \emph{native M1}, not a random-access theorem. For \textbf{Mk}, one physical sequential read-only input head and fixed finite $k$ work heads, count $T_k$, visited work cells $S_k$ excluding input, input moves $H_k$, reversals $R_k$, physical crossings $C_k$, true transferred bits where definable, and output. On the associated fixed-gap equality family the earlier same-run bounds $(R_k+1)(S_k+1)=\Omega(N/\log N)$ and $H_k(S_k+1)=\Omega(N^2/\log N)$ apply only under their full model hypotheses. \textbf{RAT} uses directly indexed read-only input and charged address construction, with indexed writable memory separately charged. The switch/space theorem above remains as a \emph{new axis}, not as a transplanted physical crossing inequality. The conservative M1 simulator of Mk has upper construction $T_1=O(T_k(N+S_k+\log(T_k+2)))$ and footprint $P_1=O(N+S_k+\log(T_k+2))$; its direction cannot be reversed without a new proof. In an augmented \emph{single physical input head} jump-radius-$J=N^j$ machine, the separate conditional native interpolation $t+s+j\ge2$ does not transfer to unrestricted RAT.

\section{Supplied UNSAT certificates, same-instance soundness, coNTIME clock}
\begin{lemma}[All-UNSAT coverage on the declared equality promise only]\label{lem:cert}
Every UNSAT $D_m(a,b)$ has an actual module $H_i^U(1,1)$ or $H_i^V(1,1)$ which is literally the original, name-shifted $W_1$ source with twenty authentic source clause IDs. A nondeterministically supplied module index and shore bit uses $O(\log N)$ certificate bits. A one-pass deterministic verifier parses all $40m$ original rows, authenticates the twenty selected clauses at their physical offsets, retains no unrelated source clause body, and checks a fixed 32-leaf source-identified two-CNF implication-path refutation under all five-variable backdoor assignments. Therefore it accepts no SAT ordinary proper-three-CNF source and accepts at least one supplied certificate for each UNSAT source of the declared promise. On one sequential read-only-input head and fixed finite work tapes,
\[
P_{\rm cert}=O(\log N),\quad T_V=N^{1+o(1)},\quad S_V=O(\log N),\quad H_V=O(N),\quad R_V=0.\tag{8}
\]
On the one-tape M1 source-bearing machine, the footprint instead includes the $N$ initial source bits: $P_1=N+O(\log N)$. The verifier's low workspace does not bound deterministic \emph{discovery} of the certificate.
\end{lemma}
\begin{proof}
For $a_i=1,b_i=0$, the shifted $U_i$ module is $H(1,1)=W_1$; for $a_i=0,b_i=1$, the $V_i$ module is $W_1$. Its original source IDs occur at publicly known clause-record offsets across the Alice/public/Bob sections. A single forward scan authenticates all source rows and saves exactly the selected twenty originals, each with logarithmic-size original variable IDs/offsets. The previously proved W1 backdoor $\{2,4,7,14,15\}$ hits all twenty clauses, and every one of its 32 truth assignments leaves an authentic contradictory width-at-most-two residual, independently verifiable through original source-clause implication paths or an actual empty clause. Fixed-size proof structure plus $O(\log N)$ source IDs fits the stated bound.

If some SAT formula passed, its satisfying assignment would satisfy every selected actual original source clause, contradicting the checked W1 UNSAT refutation. This proves the universal SAT-side certificate rejection, without assuming the equality promise. The existence of a witnessing mismatched module proves completeness only on the declared NO promise. Correct parser orientation and full input validation are charged.
\end{proof}
A uniformly clocked \emph{co-nondeterministic SAT} machine may guess the $O(\log N)$ module pointer within its input-length budget. It \emph{rejects} iff the entire UNSAT certificate validates, and \emph{accepts} on an invalid guess or timeout. Thus on each promised SAT input all branches accept, while on each promised UNSAT input at least one branch rejects. This exact polarity is a correct coNTIME \emph{promise} companion, not a universally bounded coNTIME ordinary-SAT result. Deterministic ARC must additionally pay discovery, unsuccessful strategies, policy switches, child construction, source rereads, caches and peak ancestors.
