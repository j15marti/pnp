\section{CONSTRUCTION OR PROOF ATTEMPT}
Fix an explicit polynomially evaluable encoding of acyclic Boolean circuits and a universal simulation with polynomial overhead. Set $b(N)=b_0+\lfloor\log_2(N+2)\rfloor$ and let $T$ range over fixed polynomial bounds.
\begin{theorem}
$P\neq NP$ if and only if for every $T,N_0$ there exists a satisfiable circuit $C$, $|C|\ge N_0$, for which no program of length at most $b(|C|)$ returns a satisfying primary-input assignment within $T(|C|)$.
\end{theorem}
\begin{proof}
If $P=NP$, a fixed polynomial witness finder exists by circuit-input restriction and search-to-decision, and its constant-length program becomes eligible for large $N$. Conversely if the quantified obstruction fails, some fixed $T,N_0$ give a successful eligible program for every sufficiently long satisfiable circuit. Enumerate at most $2^{b(N)+1}-1=O(N)$ programs, run every one against the identical input under the fixed clock, and verify all outputs by direct circuit evaluation. Short inputs can be handled finitely. This decides Circuit-SAT in polynomial time, so $P=NP$.
\end{proof}
Circuit DAG compression does not force high computational cost or a common hard input. One explicit satisfying OR branch defeats an optional hard branch.
