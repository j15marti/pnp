## Theorem 597.1: original /341 source-coupled gauge action

Let G=(V,E) be one of the archived checker's connected cubic graphs, B its vertex-edge incidence matrix over GF(2), b in GF(2)^V a binary odd vertex-charge vector, and P a **well-typed** /341 accepted fixture with canonical clause patterns, supported AND3 factors and in-range correctly interpreted affine rows, valid deleted-clause evidence, globally distinct native parsed node IDs, and a chronological whole shared proof DAG.

For **every** t in GF(2)^E construct T_t(P) by:

* **Source:** negate literal x_e in every original signed source clause iff t_e=1, update its local forbidden-pattern bookkeeping, retain its original source identifier, and set b'=b+Bt.
* **Factor:** for every AND3 table f on ordered support S, replace by f'(u)=f(u+t restricted to S); keep the support order and both parent references unchanged.
* **Affine row:** for each row m dot x=r, retain mask m and set r'=r+(m dot t) in GF(2).
* **Deletion:** every non-null assignment a witnessing source-clause essentiality becomes a'=a+t. Keep null evidence null. Keep the archived fixture's independent even-charge-system witness unchanged.
* **Shared DAG and price:** leave node IDs, rule names, parent IDs, chronology, each paid node and all original weights unchanged. Preserve the final zero-mask, RHS-one contradiction.

Then, for the unchanged archived /341 **fixture** acceptance predicate A341,

    A341(P)=true  ==>  A341(T_t(P))=true,

and W341(T_t(P))=W341(P). On this typed domain, T_0 is the identity and T_t after T_u equals T_(t+u). Each nonzero edge flip changes at least one original signed clause occurrence, so a well-typed packet gives exactly 2^E distinct accepted packet presentations along its orbit. This is an action across **different signed source formulas**: a fixed externally supplied ordered CNF must be transported and reauthenticated separately.

**Proof.** Each edge has two endpoints, so the XOR of the transformed charges is unchanged: the columns of B each have two 1s. Under the Boolean substitution x'=x+t, the transported forbidden assignments and the four distinct local source patterns are precisely those for b'=b+Bt. The graph's topology, connectedness, bridgelessness and the number of source occurrences do not change. Each original source clause is satisfied by a' iff its transported clause is satisfied by a'+t; hence every deletion witness retains its exact falsified-source/other-sources-satisfied property. At each AND3 node, coordinate substitution commutes with binary conjunction, so the transported truth table is exactly the new conjunction of transported parents and still fits the same at-most-three support. Affine alias equality is preserved because m dot (x'+t)=m dot x'+m dot t. For XOR nodes, (m1+m2) dot t=(m1 dot t)+(m2 dot t), so the transformed child row is exactly the XOR of the transformed parent rows. The terminal row m=0,r=1 is unchanged. Node chronology, IDs, every source's terminal ancestry, and all binary parent references are unchanged. Thus every original positive checker condition and bundled negative control has the same truth value, proving acceptance for this typed domain.
