\section{The SAT-side-only selector obligation}
For every ordinary CNF $F$ with at least one active variable, let a total deterministic algorithm $S$ return an active variable $x$ and bit $b$. Assume ONLY the SAT-side promise
\[
  F\in\mathrm{SAT}\ \Longrightarrow\ F\restriction(x=b)\in\mathrm{SAT}.
\]
No selection promise is imposed on UNSAT inputs. Require the same property on every residual, polynomial-time computation and ordinary polynomially bounded source-preserving restriction.
\begin{theorem}[Classical self-reducibility sharpened to a one-sided selection hypothesis]
A uniformly polynomial-time $S$ with these properties exists on ALL ordinary CNFs if and only if $\mathrm{SAT}\in\mathrm P$. The equivalence also holds when $S$ fixes a nonempty consistent partial assignment rather than a single literal.
\end{theorem}
\begin{proof}
Repeatedly run $S$, committing at least one previously active variable per step, restrict, and verify the final original-source assignment. At most $n$ steps are needed, and restriction does not increase original clause/literal occurrences, giving polynomial total work. On SAT sources the promise preserves a satisfying extension at every step, so the final assignment is a valid witness. On UNSAT sources every cofactor remains UNSAT irrespective of the selector's behavior, so the final verification rejects. The latter correctness uses the proved selector promise and induction, NOT the invalid rule that a single failed assignment proves UNSAT. Conversely, a polynomial SAT decider chooses $x=0$ if $F\restriction(x=0)$ is SAT and $x=1$ otherwise. If $F$ is SAT this choice necessarily preserves an extension. Any bit is allowed on UNSAT inputs.
\end{proof}
This is a classical self-reducibility equivalence, not an all-algorithm lower bound and not a proof of $P\ne NP$. Importantly, allowing separate SAT and UNSAT parameter measures does not give away the SAT-side selector for free.
