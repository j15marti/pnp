\section{One receiving gap and three falsifiable mechanisms}
Let \(\mathcal E\) be the region of simultaneous exponents \((t,s)\) achieved by ONE fixed uniform, exact SAT machine on EVERY ordinary input in the random-access read-only-source Turing model of Fortnow, Lipton, van Melkebeek and Viglas (FLMV). The known forbidden region contains
\[
\mathcal B=\{(t,s):\exists c>\max\{1,t\},\
s<\beta(c)\},\quad
\beta(c)=\tfrac12((c+2)/c^2-c).
\]
A fully charged all-input achievable-pair successor or a finite cofinal charged route into \(\mathcal B\) remains \OPEN. The old \(t+s<2\cos(\pi/7)\) universal product region remains \textbf{FALSIFIED/RETIRED}.

The testable mechanisms were fixed before the targeted literature/archive audit.
\paragraph{M1: source-aided exact projection.} Under the contradiction hypothesis \(\SAT\in P\), determine whether every validated module has not only a compact exact boundary \emph{decision} circuit, but a uniform source-accessible \emph{witness lift}. Prediction: yes, with an unknown solver-dependent polynomial exponent.
\paragraph{M2: source-name-preserving gluing.} Determine whether those circuits and lifts can form an exact all-input join through two levels without independent incompatible child witnesses. Prediction: yes for explicitly validated disjoint private sets, but without a favorable output length or machine-space bound.
\paragraph{M3: ARC entry.} Determine whether polynomial uniform semantic compilation implies a better jointly achievable SAT exponent pair. Prediction: no; the identity and zero-boundary partitions expose where the original SAT computation is paid.

\section{Typed source decomposition and exact semantics}
A valid input is an ordinary proper-3CNF
\[
F=\bigwedge_{i=1}^m F_i(B_i,Y_i),
\]
with a polynomial-time verifiable partition of source clauses, original variable names, declared shared sets \(B_i\subseteq X\), and pairwise disjoint private sets \(Y_i\), where no private name appears outside its own module. Every original occurrence must be covered and source-name consistency checked; failure of validation never asserts the theorem. The union \(X=\bigcup_i B_i\) contains all variables shared across modules. It is permitted that the decomposition has only one module, or that \(X\) is empty.

Define the exact local feasible boundary predicate
\[
Q_i(u)=[\exists y_i\ F_i(u,y_i)].
\]
When true, define the lexicographically first local lift \(L_i(u)\) as the least \(y_i\) satisfying \(F_i(u,y_i)\); when false output \(\bot\).

\begin{lemma}[Exact source-name gluing; PROVED/EXACT]
For every validated decomposition, without assuming \(P=NP\),
\[
\boxed{\SAT(F)\iff
\exists x\in\{0,1\}^{X}
\bigwedge_{i=1}^m Q_i(x|_{B_i})}.
\tag{1}
\]
If \(x\) satisfies the right-hand side, the joined assignment
\(x\cup L_1(x|_{B_1})\cup\cdots\cup L_m(x|_{B_m})\)
is a globally valid satisfying assignment. If modules are grouped, existentially eliminating variables internal to each group and then applying (1) gives the same root label. The same assertion therefore holds through two or any fixed finite number of typed grouping levels.
\end{lemma}
\begin{proof}
Restrict any global witness to the named boundaries and private variables to obtain the forward direction. For the reverse direction, local lifts have disjoint domains \(Y_i\) and agree with the \emph{same source assignment} \(x\) on every shared boundary variable, hence their union is a well-defined satisfying assignment. Grouping simply reassociates existential quantifiers over disjoint private variables; shared names are retained instead of anonymously copied. No claim of independent satisfiability of incompatible children is used.
\end{proof}

\section{Recovered conditional circuit and witness-lift construction}
Fix ONE total uniform exact ordinary SAT decider \(A\), correct on every input, with \(T_A(L)\le L^{K+o(1)}\), \(K\ge1\). The program text of \(A\) is fixed, not input-length advice. Such an \(A\) exists if \(P=NP\); its \(K\) is unknown but finite.

For a boundary assignment \(u\), construct or virtually generate an ordinary proper-3CNF \(\operatorname{Pin}(F_i,u)\) using four genuine ternary clauses and two fresh variable names for each pinned unit. The encoded length is \(N^{1+o(1)}\) when the source has \(N\) bits (we use conservative polynomial indexing/encoding). Then
\[
Q_i(u)=A(\operatorname{Pin}(F_i,u)).
\tag{2}
\]
On \(Q_i(u)=1\), assign the private names in increasing source-name order. For each private bit, call \(A\) once with the accumulated prefix and a trial zero pin. Choose zero if satisfiable, one otherwise. One initial query plus at most \(|Y_i|\) subsequent queries yields a lexicographically first satisfying lift. All child pin clauses, source lookup, state conversions, verification and replays are charged.

\begin{theorem}[Conditional P-uniform circuit and lift; PROVED/EXACT conditional on the fixed \(A\)]
There exists ONE finite-description uniform compiler \(G_A\), depending only on the fixed machine \(A\), which on every valid ordinary source decomposition outputs bounded-fan-in unrestricted Boolean circuits \(C_i\) and vector-output circuits \(W_i\) such that for every \(u\),
\[
C_i(u)=Q_i(u),\qquad
C_i(u)=1\Rightarrow W_i(u)=L_i(u).
\]
All circuit descriptions, construction work and peak construction workspace are bounded by \(N^{O(K)}\), independent of the number \(2^{|X|}\) of boundary assignments. The whole output is generated uniformly from the actual source; there is no nonuniform input-length advice, no hidden SAT-label oracle, and no uncharged boundary table. Combining the \(C_i\)'s according to (1) produces an exact source-name-preserving Boolean-circuit SAT instance, transformable to an ordinary SAT instance of \(N^{O(K)}\) bits. The composed lifts recover one root witness on SAT instances.
\end{theorem}
\begin{proof}
For each \(i\), equation (2) gives a fixed deterministic evaluation program running in \(N^{K+O(1)}\) time. Lexicographic self-reduction adds at most \(N\) ordinary SAT calls, so the vector-valued lift runs in \(N^{K+O(1)}\) time as well. Standard deterministic time-unrolling into unrestricted Boolean gates, after a polynomial-overhead simulation of the indexed TM if needed, yields circuit size \(N^{O(K)}\). A fixed deterministic generator emits the full gate descriptions in polynomial time in their size using the actual \(F_i\), typed source addresses and the fixed code of \(A\). There are at most \(N\) nonempty modules; summing sizes preserves \(N^{O(K)}\). Wire \(C_i\) at exactly the same named \(X\)-coordinates, form their conjunction, existentially quantify \(X\) by the usual SAT semantics and introduce Tseitin auxiliaries. Equation (1) proves the root equivalence; lexicographic lifts supply compatible witnesses. A second grouping level uses the same equation with its own source-validated internal variables. No SAT output, proof system, DNNF or exhaustive marginal table is mandated on the original run \(A(F)\).
\end{proof}

\paragraph{Crucial model note.}
The constructed circuits are unrestricted bounded-fan-in Boolean circuits, not d-DNNFs, OBDDs, an affine quotient, or a guaranteed small-space random-access SAT decider. A polynomial-size, P-uniform \emph{circuit family} here is a generated finite representation; it is not nonuniform advice. The compiler/generator may use \(N^{O(K)}\) time and workspace. If an implementation stores the circuits to evaluate them, this storage is counted; streamed gates are not a free readable workspace.

\section{Two-extreme cost firewall for ARC}
\begin{theorem}[No contraction follows from semantic gluing alone; exact countercontrols]
The conclusion of the conditional circuit-and-lift theorem supplies no uniform bound of the ARC form
\[
t'\le\max\{1.1,\tfrac35+\tfrac t2\},\qquad
s'\le\max\{\tfrac12,\tfrac s2\}.
\]
\end{theorem}
\begin{proof}
First take the legitimate one-module decomposition with \(X=\varnothing\) and \(Y_1\) the entire original variable set. Then \(Q_1(\emptyset)=\SAT(F)\). The above compiler computes that zero-input constant by running \(A\) on a source-scale instance; its charged computation inherits the old exponent \(K\). Second take one module with \(X\) equal to all original variables and \(Y_1=\varnothing\). Then \(Q_1(x)=F(x)\) is a small directly readable circuit, but the root \(\exists x\,Q_1(x)\) is exactly the original SAT problem. The first extreme hides the old cost in discovery; the second leaves it in the root existential join. Neither offers a general \(N^{\lambda}\), \(\lambda<1\), ordinary child. Even on useful partitions, compiling the \(C_i\)'s can cost \(N^{O(K)}\) and the resulting SAT instance can be \(N^{O(K)}\) bits, so running \(A\) on it gives at best an uncontrolled \(N^{O(K^2)}\) upper bound. An alternative representation could do better on particular inputs, but no guaranteed all-input improvement is proved.
\end{proof}
The theorem does \emph{not} assert that such a favorable compiler cannot exist by some other mechanism; it falsifies only the deduction of favorable costs from exact gluing or polynomial circuit existence alone.

\section{Adaptive state and BIT-RESOURCE1 ledger}
For any actual implementation record
\[
\mathbf R=(U,R_{\rm src},R_{\rm work},W_{\rm work},
\Delta,S_{\max},BT,D_{\rm prog},L_{\rm out}).
\]
Here \(U\) counts elementary bit operations, including unchanged-value writes and control; \(R_{\rm src}\) counts indexed read-only source-bit accesses; \(R_{\rm work},W_{\rm work}\) are writable-tape reads/writes; \(\Delta\) counts actual complete-state bit flips; \(S_{\max}\) is peak live writable/index bits, \(BT=\sum_{\tau}S_{\rm live}(\tau)\), \(D_{\rm prog}\) includes the fixed solver and representation generator, and \(L_{\rm out}\) is actually emitted child/circuit data. For the conditional compiler, \(U,S_{\max},L_{\rm out}\le N^{O(K)}\), \(\Delta\le W_{\rm work}\le O(U)\), and \(BT\le U S_{\max}\) for a specified implementation. These are \emph{upper} bounds, not post-acquisition lower bounds. Original input is read-only; tape addresses and indices are counted. State-dependent selection among affine, Horn, SCC, branching, decomposition, cached bits, source rereading or direct root SAT is permitted, but every strategy test, failed candidate, switch, generated ordinary child byte, witness verification, live ancestor and buffer is charged if executed.

A source-aware policy need not build these circuits at all: it can simply run \(A(F)\). Conversely a method claiming favorable time \emph{and} space must exhibit the same complete uniform machine and meet the verified FLMV endpoint with strict slack. Time from one implementation and space from another cannot be combined.
