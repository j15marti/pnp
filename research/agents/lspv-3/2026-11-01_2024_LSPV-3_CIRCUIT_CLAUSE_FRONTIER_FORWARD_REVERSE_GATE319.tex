\section{Exact suffix-equivalence theorem}
\noindent Let $F$ be any valid canonical original, with $n$ variables, $m=4n/3$ distinct signed source clause IDs and an explicit order $\pi$. Let $P_k=\{\pi_1,\ldots,\pi_k\}$, $Q_k=V\setminus P_k$, and
\[
\Gamma_k=\{j:\operatorname{vars}(C_j)\cap P_k\ne\varnothing,\ \operatorname{vars}(C_j)\cap Q_k\ne\varnothing\},\quad c_k=|\Gamma_k|.
\]
For an assigned prefix $a$, mark DEAD if any clause entirely within $P_k$ is false. Otherwise let
\[
M_k(a)=\{j\in\Gamma_k:\text{an original literal of $C_j$ in $P_k$ is already TRUE under $a$}\}.
\]
\begin{theorem}[Exact source-authenticated continuation quotient]
For all valid canonical originals $F$, orders $\pi$, cuts $k$, and non-DEAD coherent prefix assignments $a,b$ on the SAME $P_k$, if $M_k(a)=M_k(b)$ then
\[
\forall z\in\{0,1\}^{Q_k},\qquad F(a,z)=F(b,z).
\]
DEAD has identically false continuation. There are at most $2^{c_k}+1$ continuation functions at any cut. A deterministic source-clause-indexed frontier DP with complete transition verification decides SAT/UNSAT exactly, sums model-count multiplicities, recovers an original-clause checked witness on SAT, and can emit an exhaustive replayable UNSAT DP certificate otherwise.
\end{theorem}
\begin{proof}
Each original clause lies wholly in the prefix, wholly in the suffix, or crosses. Prefix-only clauses are satisfied for both non-DEAD states. Suffix-only clauses are literally unchanged. For a crossing clause its ID is in both $M$ sets if a prefix literal satisfies it, and in neither otherwise; in the latter case it reduces to the SAME suffix disjunction under both assignments. Thus every clause, and hence the Boolean function of $z$, agrees pointwise. At step $k\to k+1$, for each state and each allowed bit of the next original variable, update the previously open clause statuses and source clauses incident to that variable, reject every newly completed false clause, and reindex surviving crossing clauses. Merge identical signatures and add their prefix multiplicities. Induction gives the exact number of viable prefixes at every signature; a retained representative yields a checked complete witness if one survives. When none survive, recorded exhaustive transitions and falsified original-clause IDs certify UNSAT and are independently replayable.
\end{proof}
\begin{theorem}[M22 source occurrence bound and forward/reverse symmetry]
For each $k$, $c_k\le\min(4k,4(n-k),m)$. Moreover $c_k(\pi^{\mathrm{rev}})=c_{n-k}(\pi)$. Thus the peak crossing width $w=\max_k c_k$ and envelope $\sum_k 2^{c_k}$ are invariant under reversing an order, although the reachable signature counts, exact OBDD size and actual charged work need not agree.
\end{theorem}
\begin{proof}
Each crossing clause consumes at least one occurrence from each side of the cut, and each M22 variable has exactly two positive and two negative source occurrences. Reversal exchanges the sides of the same cut. These facts bound possible signatures but do not identify the sets reached by assignments.
\end{proof}
