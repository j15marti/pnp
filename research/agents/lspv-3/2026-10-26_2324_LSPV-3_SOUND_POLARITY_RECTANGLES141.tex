\section{The exact rectangle-cover polarity theorem}
Write
\[
R_{\SAT}=\{(a,b):a\mathbin{\&}b=0\},\quad
R_{\UNSAT}=\{(a,b):a\mathbin{\&}b\ne0\}.
\]
For a Boolean relation $R$, $\operatorname{cov}_{\square}(R)$ denotes the minimum number of Cartesian rectangles $X\times Y\subseteq R$ covering $R$. This is the standard deterministic local acceptance and monochromatic-rectangle notion, not an arbitrary global SAT verifier \cite{KarchmerKushilevitzNisan1995}.
\begin{theorem}[Exact opposite-polarity covers]\label{th:rect}
For every $m\ge1$,
\[
\boxed{\operatorname{cov}_{\square}(R_{\SAT})=2^m,\qquad
\operatorname{cov}_{\square}(R_{\UNSAT})=m.}\tag{3}
\]
A front-loaded fixed-length common certificate $z\in\{0,1\}^{\ell}$ checked by one local Alice predicate and one local Bob predicate, with acceptance their conjunction and no other communication, therefore requires $\ell\ge m$ to cover \emph{all SAT} instances soundly, while $\ell=\lceil\log_2m\rceil$ suffices and is optimal for \emph{UNSAT} instances. A sound deterministic interactive protocol with at most $c$ transmitted bits after the front-loaded $\ell$-bit certificate requires $\ell+c\ge m$ on the SAT side in the standard prefix-free transcript model.
\end{theorem}
\begin{proof}
For the SAT upper bound use one rectangle per Alice string:
$\{a\}\times\{b:a\mathbin{\&}b=0\}$. For the lower bound, consider the $2^m$ SAT fooling pairs $(a,\bar a)$. If a rectangle contained both $(a,\bar a)$ and $(a',\bar a')$ with $a\ne a'$, it would contain both crossed pairs $(a,\bar a')$ and $(a',\bar a)$. At least one is UNSAT, since otherwise $a\subseteq a'$ and $a'\subseteq a$. Thus each accepted rectangle contains at most one fooling pair and $2^m$ are required.

For UNSAT, the $m$ rectangles
$\{a:a_i=1\}\times\{b:b_i=1\}$ cover precisely $R_{\UNSAT}$. Conversely the $m$ UNSAT pairs $(e_i,e_i)$ are a fooling set: if one rectangle contained distinct pairs $i,j$, it would contain the SAT cross pair $(e_i,e_j)$. Hence at least $m$ rectangles are necessary. An explicit binary index $i$ witnesses the UNSAT side. For the communication clause, fix $z$ and an accepting deterministic transcript: its input pairs form a rectangle. A binary protocol of worst-case cost $c$ has at most $2^c$ leaves after padding a front-loaded length-$\ell$ certificate to a fixed length; there are at most $2^\ell$ certificates. Therefore the SAT side has at most $2^{\ell+c}$ accepted rectangles, establishing $\ell+c\ge m$. All input-dependent proof bits and transcript bits are counted. The bound does \emph{not} apply to a centralized indexed-RAM verifier capable of reading both inputs locally.
\end{proof}

\section{Authenticated UNSAT certificates, both quantifiers, and all-input firewall}
A certificate $\pi_i$ lists twenty source clause-start byte offsets in row order (and optionally the original module index). The verifier first rejects malformed ordinary input, malformed/truncated proof or out-of-range offsets. It authenticates each actual original clause line, complete signed literals, original name identities and distinctness of the twenty offsets, and compares the resulting clauses to a consistently translated $W_1$ template. The fixed template's contradiction is independently proved by exhaustive $15$-bit substitution; equivalently its prior source-ID-authenticated SCC tree may be included and checked. No unverified child lift is accepted. A full scan of an arbitrary ordinary input to authenticate its syntax is \emph{charged}; reading twenty source offsets on an already well-formed declared promise is a different, cheaper contract.
\begin{theorem}[Source-authenticated exact restricted coverage]\label{th:cert}
There is one fixed uniform verifier $V_{W_1}$ such that for every well-formed ordinary proper $3$CNF $F$ and every proof string $\pi$,
\[
F\in\SAT\implies V_{W_1}(F,\pi)=0,\tag{4}
\]
and for every $m$ and $a,b$ with $a\mathbin{\&}b\ne0$,
\[
\exists i,\pi_i\quad V_{W_1}(F_m(a,b),\pi_i)=1.\tag{5}
\]
There is a uniform certificate-length cap $|\pi_i|=O(\log N)$ on the declared promise. In particular the certificate contains at most twenty source offsets, a constant-size template and a logarithmic index. All ill-formed and timed-out branches reject. The bound is existence/verification, \emph{not deterministic discovery}. Ordinary total-input syntax validation takes $O(N\operatorname{polylog}N)$ bit time and $O(\log N)$ indexed/work bits on an appropriately implemented random-access or sequential-input fixed-tape machine. Direct indexed verification on the already validated canonical promise uses $O(1)$ source records and $\operatorname{polylog}N$ bit-time address arithmetic.
\end{theorem}
\begin{proof}
An accepting source contains twenty actual signed source clauses identical, modulo one consistent injective original-name translation, to $W_1$. Their conjunction is UNSAT, so the entire $F$ is UNSAT. This proves (4) for \emph{all} ordinary SAT inputs, regardless of extra ternary clauses, branch strategy or future context. For (5), pick $i$ with $a_i=b_i=1$; by (1) that module contains exactly the authentic twenty $W_1$ clauses. Its physical offsets supply a valid accepted certificate. Since twenty is constant, each offset uses $O(\log N)$ bits. Parsing is done with a fixed clock, and any unsuccessful parse/check returns reject; a universal complement may be used as a \emph{promise-only} co-nondeterministic SAT companion since both quantifiers hold on that declared family. There is no claimed small-cert coverage on arbitrary ordinary UNSAT inputs.
\end{proof}

\section{A universal sound-branch query-sensitivity theorem}
Fix $i$, and let $a=b=e_i$. This instance has exactly one contradictory module $H(1,1)$; the two inputs obtained by flipping either $a_i$ to $0$ or $b_i$ to $0$ are SAT. Let $A_i$ and $B_i$ denote the two disjoint physical source-bit regions representing these toggles. Prior preprocessing, source reads, virtual accesses and guest operations are part of the same run; a guessed input-dependent certificate is fixed while comparing two source inputs.
\begin{theorem}[Every accepted UNSAT branch must inspect both halves]\label{th:two}
For \emph{any} deterministic verifier $V$ sound for all SAT inputs in the family, if some fixed proof string $z$ leads $V$ to accept $F_m(e_i,e_i)$, its entire accepting run must read at least one bit of $A_i$ and one bit of $B_i$. Thus the accepted run makes at least two independent source-sensitive region probes on an indexed-input RAM, while on a machine with exactly one physically sequential input head, the same accepted run travels at least the middle-gap distance $G=\Theta(N)$, hence $H\ge G$ and $T\ge G$. There is no resulting superconstant input-reversal bound for this \emph{one accepted branch}.
\end{theorem}
\begin{proof}
Suppose the accepting run never reads a bit of $A_i$. Flipping $a_i$ changes only source bits inside $A_i$, so deterministic execution with the \emph{same} $z$ has identical reads, internal configurations, guest calls, and accepting outcome on the flipped SAT source, contradicting soundness. The symmetric argument applies to $B_i$. When the physical input head is unique and sequential, reaching a bit in both regions requires moving across all intervening fixed middle cells in that same run. On a direct-indexed input these accesses require only separately charged addresses, not sequential movement; two source probes are a lower bound rather than the exact number of reads made by an implementation. The proof remains valid for adaptive selection, failures and switching because the entire accepting execution history is compared, not an assumed static strategy.
\end{proof}

\paragraph{Sharp model distinction.}
A fixed certificate that identifies $i$ can inspect the two selected signs with O(1) indexed probes and a fixed authenticated $W_1$ check on the canonical promise. By contrast an exact \emph{deterministic decision/certificate acquisition} algorithm must inspect $\Omega(m)=\Omega(N/\log N)$ disjoint Alice-controlled source regions on the SAT input $(a,b)=(0^m,1^m)$: flipping any unread $a_i$ creates UNSAT with identical observation history. Taking the last inspected region gives a singleton-overlap UNSAT instance requiring $\Omega(m)$ probes as well. This tight promise-specific contrast extends INDEXED-LOCATOR-GAP140 to the one-module DISJ polarity, and does not lower-bound a general SAT decider by more than input sensitivity.

\section{A short SAT witness printer is not a sound SAT acceptor}
