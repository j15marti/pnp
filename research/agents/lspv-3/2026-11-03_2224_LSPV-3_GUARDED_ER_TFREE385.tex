\section*{Exact established lower-bound anchor and its scope}
Write $P_h=\mathrm{PHP}_{h+1}^{h}$ for unary signed pigeonhole CNF
with $h(h+1)$ variables $p_{ij}$, $h+1$ length-$h$ totality clauses and
$h\binom{h+1}{2}$ negative pairwise collision clauses.
The explicit signed ASCII DIMACS input uses
$N_h=\Theta(h^3\log(h+2))$ bits. Haken (1985) proves that
\[
 \exists c>0\ \exists h_0\ \forall h\ge h_0\

 \quad |\pi|\ge 2^{ch},
\]
where $\mathrm{ResRef}$ ranges over unrestricted ordinary
shared-DAG Resolution refutations and $|\pi|$ counts proof lines.
This is \emph{not} a lower bound against Extended Resolution,
$\mathrm{Res}(\oplus)$, $R_{\mathrm{mix341}}$, or general uniform SAT algorithms.
Cook (1976) supplies polynomial-size Extended Resolution PHP refutations.
The previously verified cubic odd-Tseitin short paid-GF(2) refutations
are the mandatory affine countercontrol.

\section*{The fixed typed source and cost model}
For a finite explicit CNF $F=\bigwedge_{i=1}^m C_i$ over variables $X$
and a fresh guard variable $t\notin X$, define
\[
 G_t(F)=\bigwedge_{i=1}^m(\neg t\vee C_i).
\]
$G_t(F)$ is always satisfiable with $t=0$; it entails $\neg t$
if and only if $F$ is unsatisfiable. Work in the \emph{predeclared
subgrammar} $E$ of the inherited $R_{\mathrm{mix341}}$: source-indexed
clauses cost zero; ordinary signed binary RES costs one derived node;
an acyclic conservative two-input Boolean DEF introduces a fresh
output variable at cost one and makes its exact defining CNF clauses
available as \emph{views of the same paid node}; no independently
free definition axioms or semantic consequence oracle occur. Each
derived DAG node is charged once irrespective of sharing.
Only \emph{guard-independent} DEF circuits are admitted for $E_t$:
no gate antecedent mentions $t$ directly or transitively. The
guarded task is deriving the literal $\neg t$, not refuting the
satisfiable formula $G_t(F)$. Let $D_E(F\vdash\bot)$ be its minimum
number of charged inference/definition nodes and let
$D_{E_t}(G_t(F)\vdash\neg t)$ be the analogous guarded minimum.

\begin{theorem}[Exact guard-isometry for $t$-free Extended Resolution]
For every finite UNSAT CNF $F$, including formulas containing an empty
source clause, the tagged, signed, shared-DAG proof systems above satisfy
\[
 \boxed{D_E(F\vdash\bot)=D_{E_t}(G_t(F)\vdash\neg t).}
\]
The correspondence preserves each source ID, pivot, paid DEF,
definition-clause view, inference edge, and shared inference node.
In particular, the minimum is attained whenever $E$ is complete and
every charged node has positive integer weight.
\end{theorem}
\begin{proof}
Take any acyclic $E$-refutation DAG of $F$. Tag source clauses with
value $1$, charged DEF nodes and their defining clause views with
value $0$, and each Resolution child with the Boolean OR of the
tags of its two antecedents. A node has tag $1$ precisely if some
original source clause is in its ancestry. Transport every tag-$1$
clause $C$ to $\Phi_t(C)=C\vee\neg t$; leave tag-$0$ clauses unchanged.
Copy each DEF and its entire earlier t-free gate dependency DAG
unchanged. Because $t$ is fresh, no original Resolution pivot equals
$t$. If both parents are tag-$1$, their guarded resolvent is the
guarded original resolvent; if exactly one is tag-$1$, the guard
propagates; if neither is tag-$1$, the original resolvent is unchanged.
Thus every transported inference is legal, has the same parent IDs
and pivot, and has the same unit cost. The final contradiction cannot
have tag $0$: an acyclic collection of conservative gate definitions
alone has a satisfying extension, so its clauses cannot soundly
derive $\bot$. The root therefore becomes $\neg t$. This proves
$D_{E_t}\le D_E$.

Conversely, take any $E_t$ derivation of $\neg t$ from $G_t(F)$.
Its defining clauses contain neither sign of $t$ by guard
independence. Each guarded source has $\neg t$ and no clause has
positive $t$. Consequently no legal RES pivot can be $t$.
Every derived clause either contains $\neg t$ or contains no $t$;
the latter can depend only on t-free definition clauses.
Erase $\neg t$ from each occurrence, map guarded sources back to
their original source IDs, leave all t-free DEF clauses unchanged,
and replay every signed RES and DEF node. Resolution on every pivot
$x\ne t$ commutes exactly with this erasure. The root $\neg t$
becomes $\bot$, with identical charged nodes. Hence $D_E\le D_{E_t}$.
Together the inequalities prove equality.
\end{proof}

\noindent\textbf{Scope restriction is essential.}
If a conservative DEF is allowed to depend on $t$, such as
$z=t\wedge x$, its valid definition clause $\neg z\vee t$
contains \emph{positive} $t$. Resolving it with the guarded source
$\neg t\vee x$ yields $\neg z\vee x$, which contains no guard and
has no corresponding step under simple guard erasure.
This is an explicit legal step-level counterexample to the
\emph{transport argument}; it is not a proof that a shortest proof
becomes smaller, nor a disproof of any full-system cost equivalence.
Similarly, full $R_{\mathrm{mix341}}$ AND3, GF(2) and
LOCAL-CONVERT operations have not been shown to commute with guard
adjoining or erasure. No full-system isometry is asserted.
