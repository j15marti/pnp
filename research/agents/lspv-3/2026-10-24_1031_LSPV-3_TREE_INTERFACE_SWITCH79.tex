$\forall A$ (total uniform deterministic exact), $\forall c>0,\forall N_0,\exists F$
with $|F|\ge N_0$ and $T_A(F)>|F|^c$. An upper bound on one adaptive

\noindent\textbf{M1, PROVED/EXACT restricted.}
After paid affine-component normalization, a connected component-interaction
graph may be a forest even when the sum of local excess nullities is linear.
Exact finite-domain tree joining can replace exponential enumeration.

cutset is not free.

Find a semantic post-acquisition obstruction forcing expensive continuation
for every possible uniform state-adaptive exact decider. Neither a high
raw ternary count, large $K$, a connected coupling graph, nor failure of
a finite strategy portfolio suffices.

\section{Exact charged affine-component forest theorem}
Let $F=E\wedge B$ have $N$ encoded bits, where $E$ is a system of
Boolean affine equations over $\mathbb F_2$ and $B$ is 2-CNF
(units allowed). Partition variables into the connected components
$C_i$ of the affine-equation incidence graph, treating variables
not present in $E$ as singleton components. For each consistent
component obtain by charged Gaussian elimination
\[
x|_{C_i}=a_i+L_i z_i,\qquad z_i\in\mathbb F_2^{d_i}.
\tag{1}
\]
The interaction graph $H$ has these components as vertices and
edge $ij$ precisely when some binary clause of $B$ involves one
variable from each component. Write $h=\max_i d_i$.
The original source, exact affine maps, input records and
component identifiers remain retained and all reads are charged.

\begin{theorem}[TREE-INTERFACE-SWITCH79, PROVED/EXACT within model]
If the observed graph $H$ is a forest, a uniform deterministic exact
algorithm decides $F$ and reconstructs one satisfying assignment,
if any, using $\operatorname{poly}(N)2^{2h}$ bit time and
$\operatorname{poly}(N)2^{2h}$ peak space, including parsing,
recognition, Gaussian elimination, tables, source replay and output.
For $h=O(\log N)$ this is polynomial regardless of the total
$\sum_i\max(0,d_i-1)$ or the number of components.
For $h\le2$, after source indexing and paid Gaussian normalization
the complete table/message/replay stage needs
$O(L_E+|B|+|V(H)|+|E(H)|)$ logical
$\Theta(\log N)$-bit word operations, where $L_E$ is the total
length of affine equation occurrences.
\end{theorem}
\begin{proof}
For each $D_i=\{0,1\}^{d_i}$ construct $U_i:D_i\to\{0,1\}$
by evaluating all $B$ clauses internal to $C_i$ at the
parametrized assignment. For each edge $ij$ form
$R_{ij}:D_i\times D_j\to\{0,1\}$ by evaluating all crossing
binary clauses. Every local source constraint is represented,
so satisfiability is equivalent to
\[
\exists(z_i)_i\ 
\bigwedge_i U_i(z_i)\ \land\
\bigwedge_{ij\in E(H)}R_{ij}(z_i,z_j).
\tag{2}
\]
Root each tree and compute bottom-up messages:
\[
M_{i\to j}(z_j)=
\bigvee_{z_i\in D_i}
\left[U_i(z_i)\land R_{ij}(z_i,z_j)
\land\!\!\bigwedge_{u\ {\rm child\ of}\ i}M_{u\to i}(z_i)\right].
\tag{3}
\]
Induction on the subtree proves each message is true precisely
when that subtree has a compatible completion for the parent's
specified state. A root with no supported state makes its tree
UNSAT; every tree must have a supported root state for SAT.
Record compatible child states, recover all affine variables
and verify every source constraint before outputting a witness.
UNSAT does not require Resolution or any complete solution
representation.

The tables have at most
$\sum_i2^{d_i}+\sum_{ij\in E(H)}2^{d_i+d_j}
\le O(N2^{2h})$ Boolean entries, since a forest has at most
$|V(H)|-1$ edges. Each table entry checks the relevant paid
source clauses through affine coordinate maps. Gaussian
elimination, building $H$, forest recognition and source
verification are polynomial in $N$ in a standard bit-machine
model. They include all discovery and failed checks. A
properly total algorithm invokes any exact fallback if the
grammar, consistency, or forest test does not authorize the
restricted procedure. The algorithm receives no SAT/UNSAT
answer in advance. For $h\le2$, each table has at most 16
entries and evaluation/replay is linear in source-record count
after normalization.
\end{proof}

\begin{lemma}[Supplied feedback-cutset extension, PROVED/EXACT restricted]
If $Z\subseteq V(H)$ is supplied and $H-Z$ is a forest, enumerating
the at most $2^{\sum_{i\in Z}d_i}$ assignments to $z_Z$ and
absorbing each boundary condition into the remaining unary
tables yields exact time
$2^{\sum_{i\in Z}d_i}\operatorname{poly}(N)2^{2h}$ and
$\operatorname{poly}(N)2^{2h}$ peak space under serial execution.
If $Z$ is not supplied, its discovery must also be charged.
\end{lemma}
\begin{proof}
Each fixed $z_Z$ determines all original variables in its
components. Check constraints internal to $Z$ and turn every
crossing edge to an unfixed component into a unary condition.
The remaining interaction graph is a forest and Theorem 1
applies. Branches are processed serially. SAT stops on one
successful branch; UNSAT means all branches fail. No particular
proof-system refutation is assumed.
\end{proof}

\section{Connected two-label controls with $K=q$}
For $q\ge2$, let $G_q$ be a path with vertices
$0,\ldots,q-1$. At vertex $v$, introduce
$x_{v,0},x_{v,1},x_{v,2}$ and enforce
\[
x_{v,0}\oplus x_{v,1}\oplus x_{v,2}=1
\]
using four proper ternary clauses, together with three
local NAND binary clauses
$(\neg x_{v,a}\vee\neg x_{v,b})$ for $a<b$.
For path edge $uv$, add three crossed NANDs
$(\neg x_{u,a}\vee\neg x_{v,a})$ for $a=0,1,2$.
These constraints encode ordinary graph 3-coloring:
odd parity permits $001,010,100,111$, and the three
NANDs remove $111$, leaving exactly one selected color.

Add two units $x_{0,0}$ and $x_{1,0}$ for $F_q^-$,
or $x_{0,0}$ and $\neg x_{1,0}$ for $F_q^+$.
The first is UNSAT because adjacent vertices are
both forced to color zero. The second is SAT
by a proper path coloring with vertex 0 color zero
and vertex 1 a different color. Thus both labels exist
with equal-length signed input records and the second
unit's sign as the sole changing mixed-language field.

Every affine component is one XOR3 with
$d_i=2$. The component graph $H=G_q$ is connected,
there are $q$ components and Role~5's original
cluster-excess parameter is
\[
K_1=\sum_{i=1}^{q}(d_i-1)=q.
\tag{4}
\]
Its valid restricted upper bound $2^{K_1}\operatorname{poly}(N)$
is dramatically pessimistic here: the exact three-color
tree join processes three color states per vertex and at most
nine ordered color pairs per edge, with linear post-recognition
word cost. The global source is connected; this is not the
prior disconnected-cluster factorization.

The mixed input has
\[
n=3q,\quad m_3=4q,\quad m_2=6q-3,\quad m_1=2,
\quad m=10q-1,\quad L=24q-4.
\tag{5}
\]
A uniform paid compiler maps a binary $(a\vee b)$
to $(a\vee b\vee t)\wedge(a\vee b\vee\neg t)$
with fresh $t$, and a unit $\ell$ to four
ternary clauses $(\ell\vee \pm p\vee\pm r)$
using all four sign combinations and two fresh
auxiliaries. Both gadgets are equivalent under
existential quantification of the fresh auxiliaries.
Thus the proper width-three targets have
\[
n'=9q+1,\quad m'=16q+2,\quad
N'=(48q+8)\left\lceil\log_2(64(25q+4))\right\rceil.
\tag{6}
\]
In both labels the target has the same unsigned
support layout, variable count, clause count, and
bit length; precisely four forced-unit sign
occurrences change. A source-aware recognizer
must read the complete target, validate the
gadgets, recover the original mixed source, and
then solve the forest. This is polynomial on the
canonical family while preserving exactness
on all proper-3CNFs through a total exact fallback.
The NP-completeness of the full target language
does not make its polynomial-time recognized image
hard.
