\section{Precise capacity model}
Let $H=(V,E)$ be a proper $r$-uniform occurrence hypergraph with $n$ sources and $m$ clauses, $r$ distinct original sources per clause. Variable $v$ occurs $d_v$ times, with prescribed positive-occurrence quota $0\le p_v\le d_v$. Fix any Boolean assignment $a:V\to\{0,1\}$. The required number of literal occurrences that must evaluate true at $v$ is
\[
c_v(a)=\begin{cases}p_v,&a_v=1,\\d_v-p_v,&a_v=0.\end{cases}
\]
For any $Q\subseteq E$, define $d_Q(v)=|\{C\in Q:v\in C\}|$. All signs are on original occurrences. Neither added clauses ($k=0$), eliminated variables ($d=0$), auxiliary witnesses, nor hardcoded answers occur in this construction.
\begin{theorem}[Exact fixed-witness capacity criterion, PROVED/EXACT]
A signing with precisely $p_v$ positive occurrences at each $v$, in which at least $t$ literals per clause are true under the \emph{specified} assignment $a$, exists if and only if
\[
\tag{1}\forall Q\subseteq E:\quad \sum_{v\in V}\min\{c_v(a),d_Q(v)\}\ge t|Q|.
\]
For $0\le t\le r$, a feasible signing, or a violated-cut witness if none exists, is constructible in polynomial time.
\end{theorem}
\begin{proof}
Form a directed $s$--$z$ network with source-to-clause capacity $t$, one unit of capacity on each clause-to-variable occurrence, and variable-to-sink capacity $c_v(a)$. For a cut whose clause vertices on the source side are $Q$, minimizing over the side chosen independently for each variable gives capacity
$t(m-|Q|)+\sum_v\min(c_v(a),d_Q(v))$.
Thus every cut has capacity at least $tm$ exactly under (1). Integral maximum flow of value $tm$ chooses $t$ distinct true incidences per clause and no more than $c_v$ at each variable. For each variable add any $c_v$ minus the already selected number of additional incidences and mark them true under $a$; mark its other incidences false. The corresponding polarity has exactly $p_v$ positives and retains at least $t$ true occurrences in every clause. Conversely, selecting $t$ true incidences from each clause in any feasible signing yields at most $\min(c_v,d_Q(v))$ choices attributable to each variable within a clause subset $Q$, proving necessity.
\end{proof}
\begin{theorem}[Sharp balanced even-degree signing, PROVED/EXACT]
If every original degree $d_v$ is even and $p_v=d_v/2$, then for \emph{every} fixed source assignment $a$, there is a polynomial-time constructible signing with at least $\lfloor r/2\rfloor$ true literals in \emph{every} clause. For even $r$, every clause has exactly $r/2$ true literals. The guaranteed threshold cannot be raised by one for any nonempty support.
\end{theorem}
\begin{proof}
Here $c_v=d_v/2$ independently of the bits of $a$. Since $d_Q(v)\le d_v$, one has $\min(d_v/2,d_Q(v))\ge d_Q(v)/2$. Summing gives at least $(r/2)|Q|$, proving (1) with $t=\lfloor r/2\rfloor$. The total number of true literal occurrences is $\sum_vd_v/2=rm/2$, so it cannot supply $\lfloor r/2\rfloor+1$ true literals in every clause. For even $r$, exactly $r/2$ in each clause follows from equality of total true incidences.
\end{proof}
\begin{corollary}
Any simple three-uniform support with each source degree four admits, for \emph{every} chosen assignment, a distinct-clause proper signed exact-$(2^+,2^-)$ 3-CNF on exactly the same unsigned source records that this assignment satisfies. The sign builder is deterministic under a fixed flow tie-breaking rule; no step solves the original signed SAT problem.
\end{corollary}
\section{Arbitrary-decider countermodel and quantifier audit}
For each unsigned simple degree-four support $H$, canonically run the preceding flow with $a=1^n$ to produce a signed source $S_H$. A total, uniform exact SAT decider may parse any signed source $F$, reconstruct its unsigned support $H$, build $S_H$ in polynomial time, compare all original signed records, and return SAT with the all-true witness if $F=S_H$; otherwise it performs exhaustive SAT search. Every pass, source read, flow operation, output write, comparison and fallback is charged. The decider is exact on all inputs and polynomial on every member of the possibly structurally complicated image $\{S_H\}$. It need not construct any static residual relation, DNNF, resolution proof, or witness history.
MAIN102 and DOECKER61 exhibit an imported signed UNSAT instance with 198 sources, 264 clauses, and a support-simple exact-$(2,2)$ unsigned support. CAPACITY70 constructs a SAT signing on precisely that unsigned support, preserving all unsigned incidence invariants. The original UNSAT certificate was not rerun here. Thus unsigned graph width, matching deficiency, expansion and clause incidence alone cannot distinguish the two SAT labels, much less force high time on \emph{every} signing. No claim about the worst-case signed NP-complete language follows.

\section{Roles 4--5 transport and machine ledger}
Role 4 REGULAR-DEFICIENCY63's exact $\delta^*=n/3=m/4$ is independent of signs. Role 2 DUALPAIR61 computes two distinct source-based parameters with independent polynomial discovery and exponential-only \emph{upper} bounds. Neither is necessary computation by every solver. Role 5 MAIN102 independently proves the all-true special case and explicitly shows direct-sum sensitivity is only input-order. Source-to-target reductions preserve lower bounds only under the fully charged inequality
\[
L_{\mathrm{source}}\le R_{\mathrm{construction}}+H_{\mathrm{preprocess}}+
Q\,\tau_{\mathrm{conversion}}\, T_{\mathrm{target}}^{\le}(g(N)).
\]
The $q$ field-query lower bound of 2-SAT chains is already consumed by $\Omega(q)$ output writes on a linear target. The new signing changes the SAT label intentionally and is \emph{not} a SAT-hardness reduction.
On the project's four-record-word proper-3CNF representation $N=(4m+2)w$ and $w=\lceil\log_2(64(n+m+1))\rceil$. One indexed word read costs one and bit-tape simulation carries its conversion charge. The flow has $V_f=m+n+2$ vertices, $E_f=3m+m+n$ arcs at arity three, polynomial $O(V_f^2E_f)$ time, $O(V_f+E_f)$ memory, and explicit $3m$ sign writes. Parsing, witness verification, source replay, failed attempts, and the total fallback are charged. $k=0$, $d=0$. No gate, wire or switch counts are repurposed as solver lower bounds.
