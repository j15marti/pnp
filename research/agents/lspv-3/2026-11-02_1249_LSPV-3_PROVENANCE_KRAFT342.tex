\paragraph{Two noninterchangeable costs.}
The preserved base metric has one unit per charged inference and freely selects the best derivation:
\[
 W_{\mathrm{unit}}(F)=\min_{\pi:F\vdash_{R_{\mathrm{mix341}}}\bot}|\pi|_{\mathrm{inference}}.
\]
For the new \emph{explicit-source-list audit only}, give each source node $s_j$ the singleton provenance list $\supp(s_j)=\{j\}$, each zero-source conservative definition the empty set, and each inference $v$ the exact union of its premise lists. Let
\[
 c_{\mathrm{src}}(v)=\max\left\{1,\sum_{u\in\mathrm{parents}(v)}|\supp(u)|\right\},
 \quad
 C_{\mathrm{src}}(\pi)=\sum_{v\in\pi}c_{\mathrm{src}}(v).
\]
Each item of each premise's \emph{fully enumerated} source-ID list is charged when that premise is accessed. Set unions and representation conversions do not get free provenance scanning. This is a fixed, effectively checkable, strictly positive cost convention on the \emph{same} rules, not a theorem about lazy pointer encodings. The associated weighted proof minimum is $W_{\mathrm{src}}(F)=\min_\pi C_{\mathrm{src}}(\pi)$. A stricter fixed-width ID-scan convention uses $b(m)=\lceil\log_2(m+1)\rceil$ bits per source ID and $c_{\mathrm{bits}}(v)=b(m)c_{\mathrm{src}}(v)$; it is an \emph{encoding-restricted} bit-inspection model, not a general Turing-machine lower bound.

\begin{lemma}[Private-source ancestry]
If $F$ is clause-minimally UNSAT with $m$ labelled clauses, then the contradiction ancestry of \emph{every} sound conservative $R_{\mathrm{mix341}}$ derivation includes all $m$ source labels, even if auxiliary definitions, adaptive rules, temporary growth, representation switches and shared nodes are used.
\end{lemma}
\begin{proof}
If the root omits source $s_j$, every rule in its ancestry is justified using only $F\setminus\{C_j\}$ and source-independent conservative definitions. Minimal unsatisfiability supplies a satisfying assignment of that subset, extendible to the fresh definitions. Sound inference cannot yield false, a contradiction.
\end{proof}

\begin{theorem}[Universal binary-DAG support-read lower bound]
For every $m\ge2$, every minimally UNSAT $m$-source instance and every finite sound, conservative, at-most-two-premise refutation DAG in the fixed calculus,
\[
 C_{\mathrm{src}}(\pi)\ \ge\
 L(m):=m\lfloor\log_2m\rfloor+
 2\bigl(m-2^{\lfloor\log_2m\rfloor}\bigr).
\tag{1}
\]
The result permits free best-order choice and arbitrary DAG sharing. It does not require the intermediate representation to shrink.
\end{theorem}
\begin{proof}
Write $\supp(u)$ for the source labels in the ancestry of node $u$. For each $j\in\{1,\ldots,m\}$, start at the contradiction, which contains $j$ by the lemma. Repeatedly choose a premise whose provenance contains $j$, until reaching the unique source leaf $s_j$. This gives a root-to-leaf path of length $d_j$; a binary inference offers at most two named branches. These $m$ paths have distinct terminal leaves, so their binary branch strings are prefix-free \emph{even when different paths rejoin in the DAG}. Kraft's inequality gives $\sum_j2^{-d_j}\le1$. The exact minimum of $\sum_jd_j$ for $m$ binary prefix words is $L(m)$, achieved by leaf depths $\lfloor\log_2m\rfloor$ and $\lceil\log_2m\rceil$ in the Huffman-optimal nearly balanced tree \cite{Huffman1952}.

For each selected path and each of its edges $(v,u)$, label $j$ belongs to $\supp(u)$. Therefore one unit of the charged input-list length $|\supp(u)|$ can be assigned to that use of the edge by label $j$. Distinct $j$ use distinct source IDs, so for each edge the number of assigned labels is at most $|\supp(u)|$. Consequently
\[
 C_{\mathrm{src}}(\pi)\ge
 \sum_{v}\sum_{u\in\mathrm{parents}(v)}|\supp(u)|
 \ge\sum_{j=1}^m d_j\ge L(m).
\]
No unfolding charge is silently substituted for the shared-DAG charge: each actual edge is charged once per distinct source label in its premise list. Extra derivations can only add nonnegative cost.
\end{proof}

\begin{theorem}[Attained infinite mixed-calculus optimum]
Let $G_h$ be $K_4$ when $h=4$, and the simple bridgeless cubic prism on $h=2k$ vertices for every $k\ge3$. Let $F_h$ encode an odd-charge Tseitin equation at each vertex using its four forbidden-triple 3-CNF clauses. Then $m=4h$, $n=3h/2$, $F_h$ is clause-minimally UNSAT, and in the \emph{same} fixed rule system
\[
 \boxed{W_{\mathrm{unit}}(F_h)=4h-1,\qquad
 W_{\mathrm{src}}(F_h)=L(4h),\qquad
 W_{\mathrm{bits}}(F_h)=b(4h)L(4h).}
\tag{2}
\]
In particular $W_{\mathrm{src}}(F_h)=\Theta(h\log h)$ while $W_{\mathrm{unit}}(F_h)=\Theta(h)$.
\end{theorem}
\begin{proof}
The previously proved bridgeless-cubic source-deletion lemma applies: deleting any one of the four forbidden-pattern clauses at vertex $v$ permits the wrong-parity local pattern there, while the remaining vertex equations have a solution because $G_h-v$ is connected. The preceding theorem gives the weighted lower bounds. The standard binary-premise ancestry bound gives $W_{\mathrm{unit}}\ge m-1$.

For attainment, at each vertex conjoin its four local source clauses in a balanced pair--pair--join tree using three legal two-premise AND/normalization nodes. Its final 8-row table is \emph{exactly} the incident-edge parity equation, locally certified without an extra semantic step. The local source-list input volume is $2+2+4=8$, with a four-source provenance set at each final local node. Then combine the $h$ affine rows using a Huffman-optimal balanced binary XOR tree. Every row merge has disjoint source supports, and since all edge variables appear in exactly two vertex rows the final affine equation is $0=1$. This uses $h-1$ further binary gates. The global proof is a read-once tree with all $4h$ original sources at depths differing by at most one, so its cost is precisely $L(4h)=8h+4L(h)$, and its inference count is $3h+h-1=4h-1$. Multiplying the fixed-width ID-scan cost by $b(4h)$ proves the final equality. These are \emph{attained minima over all legal derivations}, not an optimizer-depth cutoff.
\end{proof}

\paragraph{Bit-length and lower-bound interpretation.}
For the declared ASCII DIMACS serialization, the family has $N(h)=\Theta(h\log h)$ encoded input bits. Hence even the strengthened source-list audit gives $W_{\mathrm{src}}(F_h)=\Theta(N(h))$; the fixed-width explicit-ID bit-scan variant gives $W_{\mathrm{bits}}(F_h)=\Theta(N(h)\log N(h))$, a genuinely superlinear \emph{representation-restricted} certificate-reading bound. This \emph{does not} imply an $\Omega(N\log N)$ lower bound on an unrestricted SAT decider, since one can store compressed provenance as DAG pointers, use a lazy symbolic support, or detect the affine system without reading source ancestry at each inference. The unit-cost mixed system itself has the linear proof in (2). Any sound unbounded-premise rule violates the binary prefix assumption; a four-source one-step AND changes local prefix depths; a free semantic SAT oracle is excluded. Dense mask and sparse list materialization have different physical costs. Machine work, proof bytes, checking, recomputation and all-phase peak space remain separate quantities. Nothing establishes a square-root-space FLMV contraction or a computational lower bound for all SAT deciders.

\paragraph{Falsifiers audited.}
\begin{enumerate}
\item[] \textbf{DAG sharing and repeated source appearances.} The proof charges the number of \emph{distinct source IDs} carried on each actual operand edge. Selected paths remain prefix-free even with reconvergence; no tree-unfolding inference count is assumed.
\item[] \textbf{Compact pointer, XOR and equality escapes.} The same graph has $4h-1$ unit inferences; pointer-based cached ancestry avoids the new explicit-list read charge. High-rank equality, Horn and 2-SAT remain compact alternative representations. Therefore the bit-scan bound does not apply to all legal encodings or all SAT algorithms.
\item[] \textbf{Higher fan-in and semantically powerful rules.} A direct four-source XOR extractor, if added, violates the binary-input prefix model; with a separately charged arity-aware source-access metric a different bound must be proved. Arbitrary semantic one-step jumps are never authorized.
\item[] \textbf{Opposite charge, clause deletion, corrupted rules and temporary growth.} Even-charge models and 416 minimality witnesses were independently checked. Corrupting a parent, a parity row, a literal, a witness or an output is rejected; adding intermediate nodes or conservative gates cannot reduce the weighted lower bound when all source uses remain charged.
\end{enumerate}
