\section{BUILD I: a native exact-$(2,2)$ many-one guard}
Call an encoded 3CNF \emph{strict signed exact-$(2,2)$} when every clause has three distinct variable IDs and every variable appears in exactly two positive and two negative literals. Take the standard proper-clause convention of no duplicate signed clause; connectivity is explicitly stated when required.

\begin{lemma}[Balanced two-fiber guard]\label{guard}
For three fresh variables $y,u,v$, let
\begin{equation}\label{eq:guard}
H(y,u,v)=
(\neg y\vee u\vee v)\wedge(y\vee\neg u\vee v)\wedge
(\neg y\vee u\vee\neg v)\wedge(y\vee\neg u\vee\neg v).
\end{equation}
The guard is proper strict signed exact-$(2,2)$, has four distinct clauses, is connected, and satisfies
\[\exists u,v\ H(y,u,v)\equiv\top.\]
Indeed both all-zero and all-one assignments satisfy it.
\end{lemma}
\begin{proof}
The four occurrences of $y$ are two positive and two negative; the same holds for $u$ and $v$. Each clause has one or two negative literals, so both all-zero and all-one assignments satisfy each clause. The incidence graph is connected because all clauses use all three variables. Distinct sign vectors make the clauses distinct.
\end{proof}

\begin{theorem}[Two-bit exact-summary recognition on strict exact-$(2,2)$]\label{thm:hard}
Let $F(X)$ range over proper strict signed exact-$(2,2)$ 3CNFs, including the NP-complete monotone subclass. Define $G_F(X,y,u,v)=F(X)\wedge H(y,u,v)$ on disjoint variables. This map is deterministic, polynomial-time, source-record preserving, and preserves strict signed exact-$(2,2)$. Then
\[
\proj_{y}(G_F)=\begin{cases}
\varnothing,&F\text{ UNSAT},\\
\{0,1\},&F\text{ SAT}.
\end{cases}
\]
On this \emph{disconnected image family}, deciding whether the proposed exact table is $\{0,1\}$ is NP-complete and deciding whether it is $\varnothing$ is coNP-complete (ordinary many-one completeness). A polynomial-time deterministic exact table producer or verifier for all such inputs would imply $P=NP$. A universally polynomially bounded sound, polynomial-time-checkable certificate for the empty table would imply $NP=coNP$.
\end{theorem}
\begin{proof}
As variable sets are disjoint, $G_F$ has a model with prescribed $y=b$ iff $F$ is satisfiable and $H(y=b)$ has a model. The latter holds for $b=0,1$ by Lemma~\ref{guard}. Exact signed occurrences, properness and clause uniqueness are unaffected by juxtaposing disjoint formulas. The transformation adds three variables and four clauses, so source encoding remains polynomial. Recognition of the full (resp. empty) table is exactly SAT (resp. UNSAT) of $F$ and belongs to NP (resp. coNP). The cited monotone strict-occurrence NP-completeness yields hardness under many-one reductions.

Given a hypothetical deterministic checker for an \emph{exact} proposed table, call it on $\{0,1\}$, deciding SAT. Given polynomially bounded sound completeness proofs for empty tables, an UNSAT input $F$ has a nondeterministically guessable polynomial proof that $G_F$ projects to empty; verifying it places coNP-complete UNSAT in NP. Hence $NP=coNP$. The theorem does not show that such an exactness proof must be long unconditionally. Importantly, $G_F$ is disconnected, not an always-SAT connected parent; it may itself be UNSAT.
\end{proof}

\begin{theorem}[Connected component firewall; weaker reduction type]\label{thm:connected}
Suppose one uniform deterministic polynomial-time procedure computes the entire exact two-entry projection table \(\proj_y(C)\) for every \emph{connected} proper strict signed exact-$(2,2)$ CNF $C$ and any variable $y$ in $C$. Then $P=NP$. The implication holds without supplying the answer class and only uses a polynomial-time \emph{nonadaptive Turing reduction} from general exact-$(2,2)$ SAT. The same consequence holds if a polynomial-time deterministic checker accepts exactly the correct table for every such $(C,y)$.
\end{theorem}
\begin{proof}
Given any strict signed exact-$(2,2)$ input $F$, find its connected incidence components $C_1,\ldots,C_s$ in polynomial time. Every component retains exactly two positive and two negative appearances per variable and proper clauses. Choose any member $y_i$ of each component and compute its two-entry table. Then
\[F\text{ SAT}\iff\bigwedge_{i=1}^s(\proj_{y_i}(C_i)\ne\varnothing).\]
All queries can be generated before receiving answers. If instead an exact-table checker is provided, enumerate the four possible two-entry tables for each component, select the unique one accepted, and use the same test. The number of candidates is constant per component. The known NP-completeness of the original strict-occurrence SAT class proves the conditional conclusion. This is \emph{not} a many-one hardness proof for one prescribed fiber of a connected formula.
\end{proof}

\paragraph{Certificate polarity.} For each fixed boundary $y$, a proof that $b$ is \emph{feasible} is an ordinary SAT witness of $F\wedge(y=b)$, verifiable in polynomial time. A proof that $b$ is \emph{infeasible} is an UNSAT refutation of $F\wedge(y=b)$, and no uniform polynomial bound on its size or acquisition is known. An exact two-entry table must authenticate both entries. On connected exact-$(2,2)$ components, polynomial-length efficiently checkable UNSAT-fiber certificates for \emph{every} empty fiber would place the entire class's UNSAT complement in NP, again implying $NP=coNP$. This asserts a conditional implication, never a lower bound under unknown complexity assumptions.

\section{Resource ledgers, hereditary controls, and limitations}
For the finite 15-variable support, direct source checking visits 20 original ternary clauses per tested assignment and at most $2^{15}$ assignments per signing. The recorded $201,201,261,293$ Resolution candidate-pair counts include failed tautological or duplicate candidates; the four complete proofs are retained simultaneously only in the published trace bundle, not during one run of the generation algorithm. Source clauses and assumptions are counted distinctly. Frontier width six and at most 25 simultaneously active clauses refer only to the tested elimination procedure and do not imply low-space polynomial acquisition on arbitrary exact-$(2,2)$ formulas. The two inherited ordinary-3CNF child levels in earlier BUCKET-PROVENANCE153 expanded, rather than establishing fractional-length contraction; none is silently counted as a successful recursive step here.

\paragraph{Single-tape deterministic TM.} The read/write input tape initially contains $N$ physical bits and the footprint includes those bits. A direct compiler can simulate the finite algorithm using repeated scans, storing clause records and traces on the same tape; time includes all input traversals, head crossings, sign checks and emitted bits. The explicit Python assignment counts are \emph{not} head movements or one-tape time exponents. For general $n$, the brute-force control takes at most $2^n\operatorname{poly}(N)$ time, with polynomial tape footprint when streamed.

\paragraph{Two-tape and fixed-$k$ deterministic TM.} With read-only sequential input and finite work tapes, the work footprint excludes the source input. Source IDs are re-read by charged head movement or copied into work storage. A naive compiler has polynomial overhead for the finite trace verifier and up to $2^n\operatorname{poly}(N)$ time for the exhaustive generator. No one-tape crossing sequence is imported as a numerical multitape lower bound. The 2-RW model, where both tapes are writable, is distinct again and is not claimed to have the same ledger as read-only-input 2-OFF.

\paragraph{Indexed RAM and fixed universal interpreter.} An indexed-RAM implementation pays for address computation, parsing, each logical source lookup and every derived clause, using ordinary logarithmic-sized words; it does not inherit sequential tape crossing penalties. A fixed universal TM may simulate any fixed interpreter with a charged polynomial overhead in time and workspace; no particular exponent is asserted. Machine-state side labels $A_{\SAT}$ and $A_{\UNSAT}$ are restrictions of the \emph{same} program, not independently granted oracles. The exact-table conditional hardness results are native to ordinary polynomial-time reductions and do not require a tape-transport argument.

\paragraph{Hardness and positive route.} The guard is a native strict-occurrence hardness transfer but disconnected. The four connected tables are an explicit finite family, not a hardness reduction. The connected case uses a nonadaptive Turing reduction, and a many-one connected fiber reduction remains open. Polynomially checking an explicitly supplied short Resolution/BDD/LRUP object does not provide its deterministic discovery. A single-child answer-preserving shrinker for arbitrary SAT is not constructed; the OpenAI unitary-synthesis paper's one-recursive-call quantum slot architecture does not supply the requisite classical oracle values. Both possible $P=NP$ and $P\ne NP$ directions remain research hypotheses.
