\section{Exact source-name conflict graph}
Let Y be the ordered tuple of all genuinely common original variable identifiers and \(B=\{0,1\}^Y\). Let D and Q be finite families of proper ordinary signed-ternary CNFs D(Y,U) and Q(Y,V), with disjoint private sets U,V for EACH declared pair. Every actual root, child, grandchild claimed eligible belongs to D. Define the extensional (not free) named supports
\[
S_D=\{b\in B:\exists u\ D(b,u)\},\qquad S_Q=\{b\in B:\exists v\ Q(b,v)\}.
\]
Exact both-label gluing is SAT(D and Q) iff \(S_D\) intersects \(S_Q\).
Build the undirected graph G on B with edge {b,c} when SOME declared UNSAT parent (D,Q) has b in \(S_D\) and c in \(S_Q\), or vice versa.
\begin{theorem}[Actual-context quotient iff and optimal fixed palette]
For every fixed map h:B to H, all declared parent SAT AND UNSAT labels are preserved by the coarsened join h(\(S_D\)) intersects h(\(S_Q\)) iff h separates every edge of G. Its exact minimum number of fixed reusable semantic labels equals the chromatic number chi(G).
\end{theorem}
\begin{proof}
A true common source-name witness always yields a coarsened common label. If a coarsened join accepts an UNSAT pair, disjointness of its supports gives two distinct boundary words b,c of the SAME h-label, with b in the prefix support and c in the suffix support. By construction {b,c} is an edge, violating proper coloring. Conversely, a collapsed edge supplies exactly that false-SAT declared parent. Thus safe maps are precisely proper colorings. Minimizing color count gives chi(G). This characterizes supports, not the computational expense of computing a coloring.
\end{proof}
\noindent\textbf{Prior theorem recovered.} If Q contains EVERY ordinary singleton boundary pin suffix, G connects precisely pairs of boundary words with different descendant feasibility signatures. It is complete multipartite and chi(G) equals the number of distinct signature vectors. This is the prior LSPV-3 HEREDITARY-KERNEL118 universal-suffix theorem, not a new result.
