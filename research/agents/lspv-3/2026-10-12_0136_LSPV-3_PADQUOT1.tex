\section{Exact family, object, and quantifiers}

Let \(\mathcal H_{2,2}^{\pm}\) be the repository's duplicate-free proper
3CNF clean core: every clause has three distinct literals of one sign and
every variable occurs exactly twice positively and twice negatively.  Let
\(\mathcal S=(\mathcal H_{2,2}^{\pm})_{\mathrm{sat}}\).  For formulas on
disjoint variable sets, \(F\sqcup G\) denotes their conjunction, considered
up to variable renaming and clause permutation.  Then \(\mathcal S\) is
closed under \(\sqcup\).

Let \(Y\) be an arbitrary set.  An \emph{unpointed full-padding invariant}
is a function \(J:\mathcal S\to Y\) satisfying the exact prefix
\[
 \forall F,G\in\mathcal S:\qquad J(F\sqcup G)=J(F),                 \tag{1}
\]
and isomorphism invariance
\[
 F\cong F'\quad\Longrightarrow\quad J(F)=J(F').                    \tag{2}
\]
No complexity assumption is made about \(J\).  It may be a scalar, graph,
code, transcript class, circuit, branching program, algebraic relation,
distribution, or arbitrary mathematical object.  The theorem is therefore
about the quantifiers in a proposed normalization, not about how an algorithm
represents the output.

\section{Full-padding quotient collapse}

\begin{theorem}[FULL-PADDING-INVARIANCE-COLLAPSE1]
\label{thm:collapse}
Every unpointed full-padding invariant \(J:\mathcal S\to Y\) is constant.
Equivalently, the equivalence relation generated by adjoining satisfiable
independent clean-core components has one class on \(\mathcal S\).
\end{theorem}

\begin{proof}
Fix arbitrary \(F,G\in\mathcal S\).  Closure gives
\(F\sqcup G\in\mathcal S\).  Equation (1) gives
\(J(F\sqcup G)=J(F)\).  Applying (1) with the source and padding reversed
gives \(J(G\sqcup F)=J(G)\).  Disjoint union is commutative up to variable
renaming and clause order, so (2) gives
\(J(F\sqcup G)=J(G\sqcup F)\).  Hence \(J(F)=J(G)\).  Since \(F,G\) were
arbitrary, \(J\) is constant.
\end{proof}

\paragraph{Encoded length.}
If \(F\) and \(G\) use \(n_F,n_G\) variables in the bounded-occurrence
encoding, then
\[
 |\operatorname{enc}(F\sqcup G)|
 =O\!\left((n_F+n_G)\log(n_F+n_G)\right).
\]
The collapse does not infer a runtime from this size and does not require the
union to be free.  It is an exact semantic consequence after every writing,
renumbering and canonicalization cost is charged.

\begin{corollary}[No nonconstant unpointed normalized endpoint]
If a proposed padding-normalized endpoint distinguishes two satisfiable
clean-core sources, then it must fail at least one of: full invariance under
all satisfiable independent padding, invariance under alternate encodings and
summand order, or unpointedness.
\end{corollary}

\paragraph{Smallest repair.}
Replace the unpointed formula by a pointed pair
\((F\sqcup G,\iota_F)\), where \(\iota_F\) names the source summand.  A
pointed invariant may obey
\[
 J_\bullet(F\sqcup G,\iota_F)=J_\bullet(F)
\]
without also equating it to \(J_\bullet(G)\).  This avoids
Theorem~\ref{thm:collapse}, but it changes the object: the root injection,
component boundary, or equivalent provenance is now explicit input.  A
compiler can carry that pointer.  Nothing in a one-bit SAT answer forces an
arbitrary decider to expose or pay for the pointed object.

\section{Transfer and barrier audit}

\paragraph{Directly transferable theorem.}
The coproduct/disjoint-union correspondence is exact: \(F\sqcup G\) carries
two summand injections, and forgetting which injection is the source creates
the unpointed object.  The collapse proof itself is elementary and transfers
exactly to any class of YES instances closed under a commutative independent
sum.

\paragraph{Useful structural analogy requiring a new transfer theorem.}
Database provenance semirings preserve lineage by symbolic input tokens
\cite{GKT07}.  Such a token is analogous to \(\iota_F\).  The missing theorem
would have to show that every arbitrary SAT decider must create, expose, or
pay for the same lineage token.  The database theorem does not say this.
Likewise, direct-sum code invariants, puncturing/shortening, and Schur-square
filtrations can preserve a chosen coordinate set only when that set is part of
the declared code interface.

\paragraph{Misleading analogy / failed transfer.}
Cryptographic domain separation, collision binding, or random-oracle tags can
identify a source summand only under their construction or hardness
assumptions.  They are inadmissible as unconditional P-versus-NP premises.
VLSI routing and fan-out lower bounds constrain physical layouts, not an
unrestricted random-access decider.  Neither transfers here.

\paragraph{Relativization, algebrization, Natural Proofs.}
Theorem~\ref{thm:collapse} holds unchanged relative to every oracle and after
algebraic oracle access.  It is therefore a route retirement, not an escape
from the Baker--Gill--Solovay or Aaronson--Wigderson barriers
\cite{BGS75,AW09}.  The argument defines no large constructive truth-table
property and proves no circuit lower bound, so Razborov--Rudich is not a
direct theorem here.  This absence is not progress toward a nonnatural proof.

\section{SAME\_REALIZATION and hidden-premise audit}

The pointed repair distinguishes three objects that must not be conflated:
the input formula, a compiler-supplied source injection, and an arbitrary SAT
decider's execution.  A pointer attached by the external compiler is not an
internal state of the decider.  Requiring the decider to reveal it is exactly
the missing arbitrary-algorithm transfer.  Requiring a pointed endpoint to be
unconditionally hard for all ordinary machines would already supply the
separation-strength lower bound.  Neither may be assumed.

Under \(P=NP\), the compiler may solve SAT and carry arbitrary polynomial
metadata, but its exponent is unknown.  Theorem~\ref{thm:collapse} supplies no
fixed exponent-independent contraction and no placement in the FLMV forbidden
region.  FLMV remains applicable only to a single ordinary random-access
machine whose full time and space costs meet its hypotheses \cite{FLMV05}.

\section{STALE OR OVERSTATED CLAIMS FOUND}

``Padding invariant'' is overstated unless it declares (i) the allowed
padding class, (ii) whether summand order/renaming is forgotten, and (iii)
whether the source injection remains available.  Full invariance plus
unpointed commutativity erases all satisfiable-source distinctions.  Merely
renaming a compiler-carried pointer as an intrinsic invariant would silently
violate SAME\_REALIZATION.  No verified source-pass or lower-bound claim was
silently strengthened.
