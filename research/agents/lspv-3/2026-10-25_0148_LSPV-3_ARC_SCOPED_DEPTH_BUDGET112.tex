\section{Exact source grammar and named block relation}
The restricted input is a \emph{validated, read-only closed scoped stream} of an ordered ordinary proper 3CNF, with one OPEN and one CLOSE event per active variable, and every clause emitted when its three distinct named variables are live. OPEN introduces names in increasing canonical order; CLOSE only removes live names. The stream represents the same ordinary formula but is an \emph{additional input contract}, not a freely acquired view of an arbitrary unannotated CNF. Let $m$ be its clause count, $N=\Theta(m\log(m+2))$ its fixed-record bit length, and $w$ its maximum live named-variable width.

Split the ordered original \emph{clauses} into $B=\lceil\sqrt m\rceil$ balanced nonempty consecutive blocks. At cut $j$, $S_j$ is the set of names live on both sides. For a block with entering boundary $L$, exiting boundary $R$, and assignments $\alpha,\beta$, reject inconsistent values on $L\cap R$ at the parent. Otherwise form a genuine ordinary proper 3CNF child: pins for $L$ at the left, every original block clause with an injective local name map, then pins for $R\setminus L$ at the right. A pin of literal $\ell$ is the four clauses
\[
(\ell\vee a\vee b),(\ell\vee a\vee\neg b),
(\ell\vee\neg a\vee b),(\ell\vee\neg a\vee\neg b)
\]
with private fresh $a,b$. The parent separately retains the original-name maps. All generated ordinary child headers, bodies and pin auxiliaries count as real bit work.

\begin{lemma}[Restricted exact semantics and width, previously established]
For the stated valid scoped source, $\operatorname{SAT}(\mathrm{Child}_j(\alpha,\beta))$ equals existence of a satisfying internal assignment respecting the two named cuts. The global parent SAT bit is
\[
\exists\alpha_0,\ldots,\alpha_B\
\bigwedge_{j=1}^B
\left([\alpha_{j-1}|_{S_{j-1}\cap S_j}
=\alpha_j|_{S_{j-1}\cap S_j}]
\wedge\operatorname{SAT}(\mathrm{Child}_j)\right).
\]
The ordinary child has $m_j\le\lceil m/B\rceil+8w$ ternary clauses and a valid scoped presentation of width at most $w+2$, with at most $2^{|L\cup R|}\le2^{2w}$ consistent pinned queries per block.
\end{lemma}
\begin{proof}
Eliminating the two private variables of a pin gadget forces $\ell$. Every source clause is copied with the same original-name correspondence. Adjacent cut agreements make the witnesses jointly consistent on variables spanning several blocks. Pin gadgets at the left/right ends extend only the lifetimes of variables already live at the corresponding original boundary; at most two private pin variables are simultaneously live. The four gadget clauses contribute at most $4|L\cup R|\le8w$ clauses. The query count is the number of assignments to the union, not the Cartesian count of possibly overlapping boundary names.
\end{proof}

\section{Fixed-depth quantified resource lemma}
Fix an integer $d\ge1$ independent of source length and a constant $\delta>0$. Assume the \emph{already validated} original scope width satisfies
$w\le\delta\log_2 N$; balanced clause blocks are generated with fully charged source addresses and per-block name maps. At each level repeat the same block-and-pin construction, until depth $d$, when every ordinary leaf is decided by the ONE fixed uniform exact SAT machine $A$ with joint exponents $(t,s)$.

\begin{theorem}[Restricted fixed-depth source-compatible contraction; PROVED/EXACT]
For every fixed $d$, the true scope width on every depth-$i$ descendant is at most $w+2i$, and its ordinary encoded size is $N^{2^{-i}+o(1)}$ for $0\le i\le d$, provided source clauses are balanced into $\lceil\sqrt{m_i}\rceil$ nonempty blocks at each level. The number of executed leaf calls is at most
\[
N^{1-2^{-d}+2d\delta+o(1)}.
\]
There is a depth-first implementation, in the declared indexed-input model on the promised validated stream, with simultaneous resource bounds
\[
\boxed{
t_d\le\max\{1+2d\delta,\ 1-2^{-d}+2d\delta+2^{-d}t\},\quad
s_d\le\max\{1/2,2^{-d}s\}
}
\]
up to $o(1)$ exponent slack and explicitly charged metadata and ancestor buffers. These are \emph{promised-source} bounds, NOT points in the all-ordinary-SAT achievable set $E$.
\end{theorem}
\begin{proof}
Balanced nonempty clause blocks have $\Theta(\sqrt{m_i})$ original clauses, while the extra $O(w+2i)$ pin clauses are asymptotically smaller for fixed $i$ and $m_i=N^{2^{-i}+o(1)}$. Dense name renumbering, the fixed record headers, and the auxiliary gadgets give encoded size $N^{2^{-(i+1)}+o(1)}$. By the preceding lemma, width grows by at most two per level.

At depth $i$, there are at most $N^{2^{-(i+1)}+2\delta+o(1)}$ child calls per node because $2^{2(w+2i)}=N^{2\delta+o(1)}$. Multiplying along a fixed $d$-level path gives the claimed leaf count. Materializing and validating each leaf costs its actual $N^{2^{-d}+o(1)}$ encoded bits, so the cumulative generation and DP work across all levels is $N^{1+2d\delta+o(1)}$; source parsing and indexing are included, not free. Calling $A$ on the leaves gives the other time term.

The implementation reads the original validated scope stream from indexed read-only input, stores $O(\sqrt{m_0}\,w\log N)$ cut metadata and offsets, maintains live row DP, and materializes at most one first-level child of $N^{1/2+o(1)}$ bits, its descendants, and one $A$ state of $N^{s/2^d+o(1)}$ writable/index bits simultaneously. It reuses space between sibling calls and charges copies, unchanged writes, all accesses, remapping, generator buffers, and retained ancestors. All other controller objects fit $N^{1/2+o(1)}$ bits. A write-only output is not used as free readable memory. The source promise and its validation cost are not erased by this upper bound.
\end{proof}

\paragraph{Two levels and relative-width erosion.}
For $d=2$,
\[
(t_2,s_2)\le
\left(\max\{1+4\delta,3/4+4\delta+t/4\},
\max\{1/2,s/4\}\right).
\]
At each depth $i$, the ratio $w_i/\log_2 N_i$ may approach $2^i\delta$ even though absolute width changes only additively. If $\delta<1/80$, every depth-$0,1,2$ formula eventually satisfies the canonical $(\log_2N_i)/20$ width promise. This statement is for fixed depth two. It does \emph{not} establish indefinitely hereditary fixed-ratio entry when the depth increases with $N$. Child scope syntax is always valid; the stronger relative-width size promise is not automatic.
