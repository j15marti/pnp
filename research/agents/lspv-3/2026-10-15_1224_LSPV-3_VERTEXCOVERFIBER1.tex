\section{CONSTRUCTION OR PROOF ATTEMPT}
A source instance has unary three-bit domains, oriented nine-bit pair masks on ternary variables and encoded length $N$. A regular edge permits exactly a permutation of three colours. Spanning-forest transport yields for every regular component a root variable and bijections $\theta_v$; checking non-tree edges, unary masks and internal exceptional edges filters its three root values exactly. For a cross exceptional edge $uv$, its correct quotient relation is $R_{uv}(\theta_u(c),\theta_v(d))$.

\begin{theorem}[Exact source algorithm]
Let $Q$ be the graph of cross exceptional quotient relations after the regular components are collapsed, and let $h=\tau(Q)$ be its minimum vertex cover. One ordinary deterministic machine counts all solutions and reconstructs a witness in
\[
T(N,h)=O((N+1)^8(2^{h+1}+3^{h+1})),\qquad S(N,h)=O((N+1)^3).
\]
The algorithm is uniformly polynomial when $h\le c\log_2(N+2)$ for fixed $c$, and returns OUTSIDE safely when no cover within a declared smaller cap is found.
\end{theorem}
\begin{proof}
Branch on endpoints of an uncovered quotient edge, exploring the full binary cover-search tree; no favorable cover is assumed. For each of at most $3^h$ cover colourings, reject any violating internal cover edge, then independently intersect allowed root colours for each uncovered vertex, since the uncovered side has no edges. The exact number of extensions is the product of domain sizes. Sum products and map a surviving root assignment through the $\theta_v$ to a full witness. Parsing, unsuccessful branches, big integers, materialized masks, state and output are charged in the displayed simultaneous bounds.
\end{proof}

\begin{theorem}[Dense easy-family control]
For every $n\ge6$, partition $K_n$ into $A,B$ of sizes $p=\lfloor n/2\rfloor,q=n-p$. Within each part put equality on every edge. On each of the $pq$ cross edges permit all nine colour pairs except one chosen pair. In the YES version, the excluded pairs cover exactly eight of nine possible ordered pairs; in the NO version, all nine. All unary domains are full. Then
\[
k=pq=\Theta(n^2),\quad h=1,\quad
\#\operatorname{Sol}(I_n^+)=1,\quad \#\operatorname{Sol}(I_n^-)=0,
\quad \operatorname{tw}(K_n)=\kappa(K_n)=n-1.
\]
The result is invariant under vertex relabeling and independent local permutations of colours.
\end{theorem}
\begin{proof}
Equality forces one constant colour on each part, so the solution set is precisely the nine ordered part-colour pairs minus the excluded pairs. All cross masks are nonpermutation. They connect only two quotient vertices, with cover number one. The original graph is complete.
\end{proof}

\noindent\textbf{Actual UWI control.} One-hot Boolean variables $X_{v,a}$, one width-three positive clause per source variable, the three pairwise at-most-one clauses, and unary/binary forbidden-pair clauses give a polynomial-size 3-CNF with a bijection of models. A single fixed partial program can parse this canonical grammar, run the cap-one source algorithm, and output a verified Boolean witness on every satisfiable encoded YES source. Consequently the free-hindsight cost $H(F_n^+)$ is polynomial in $|F_n^+|$ on that family. This does not establish any uniform upper bound on $H$ over ALL satisfiable formulas.

\noindent\textbf{Oblivious fiber lemma.} A fixed omitted-colour vector accepts exactly $2^n$ of $3^n$ possible witnesses. An input-independent portfolio covering all possible unique witnesses has size at least $\lceil(3/2)^n\rceil$. An algorithm reading explicitly supplied singleton unary masks needs no portfolio search at all. This counting lower bound is not a bound against arbitrary programs.
