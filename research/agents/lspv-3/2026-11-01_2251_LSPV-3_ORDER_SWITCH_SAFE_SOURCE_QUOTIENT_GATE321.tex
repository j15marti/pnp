Let $S$ be the already assigned original-variable set and $a:S\to\{0,1\}$. Let $\Gamma(S)$ be crossing source-clause IDs, those containing both an assigned and a free variable. Define $B(S,a)\subseteq\Gamma(S)$ as the crossing clauses containing at least one literal made true by $a$. Let $K(S,a)=\mathsf{DEAD}$ if a fully assigned source clause is false, and $(S,B(S,a))$ otherwise.
\begin{theorem}[Sound future-pin cache and uniform paid transition]
For EVERY valid original $F$, assigned set $S$, coherent $a,a'$ on $S$, and arbitrary future pin sequence, $K(S,a)=K(S,a')$ implies identical full Boolean cofactors and hence identical current and future SAT/UNSAT decisions. If $v\notin S$, then $K(S\cup\{v\},a\cup\{v=b\})$ is computable from $K(S,a)$, $(v,b)$ and the authenticated source alone, with no recovery of earlier pin values. At most FOUR source clause IDs change logical satisfaction status in any such transition, because each original variable occurs twice positively and twice negatively. Acquiring/indexing the source, cache copying, equality checks, physical source/index/head operations and all actual writes remain CHARGED.
\end{theorem}
\begin{proof}
For nondead $K$, fully assigned clauses are already true and drop out; clauses disjoint from $S$ remain unchanged; crossing clauses in $B$ are already true and drop out; every other crossing clause retains exactly its unassigned literals. Thus
\[
F|a(z)=\bigwedge_{j:V(C_j)\cap S=\emptyset}C_j(z)
\wedge\bigwedge_{j\in\Gamma(S)\setminus B(S,a)}
\bigvee_{\ell\in C_j:\operatorname{var}(\ell)\notin S}\ell(z).
\]
This depends only on the original source and $K$. When assigning $(v,b)$, only incident clauses may become newly satisfied or lose their last free literal; a completely false completed clause gives $\mathsf{DEAD}$. All other source clauses retain their status. The four-occurrence quota yields the change bound, with an indexed source implementation. \end{proof}
