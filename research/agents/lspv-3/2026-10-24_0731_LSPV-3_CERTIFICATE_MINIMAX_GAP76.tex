\section{Mechanisms proposed, then literature checked}
\noindent\textbf{M1 (PROVED/EXACT in the query model).} All inputs of one growing SAT-label family can have certificate complexity $q$, while the optimal fully adaptive deterministic worst-case decision depth is $q^2$, on both SAT and UNSAT inputs. The hard inputs are policy-dependent.

\par\noindent\textbf{M2 (PROVED/EXACT in the declared encoding).} A source-sign construction embeds the family directly in the full language of proper exactly-three-literal CNF without assuming mandatory witness extraction or static representation.

\par\noindent\textbf{M3 (FALSIFIED/RETIRED).} The quadratic gap itself gives a superlinear unrestricted SAT time bound. A polynomial-time recognizable encoding has a matching $O(q^2)$ source-aware algorithm.

\par\noindent\textbf{LITERATURE AND DUPLICATION.} The relation of certificate complexity and deterministic decision-tree depth, and the adversarial minimax recurrence, are \textbf{KNOWN THEOREM} material surveyed by Buhrman--de Wolf (2002). The preceding project FULL-DIFFERENCE-CERTIFICATE65 established pointwise certificates; ADAPTIVE-COVER75 and MAIN WEIGHTED-TRANSCRIPT-COVER108 established unit and weighted conditional-read hypergraphs. MAIN AGGREGATION-CEILING91 already embedded monotone AND/OR label trees in CNF and showed input-order query bounds. None is superseded. This report adds an explicit all-input pointwise-versus-policy gap, a two-label adversary, exact proper-3CNF grammar and a complete resource audit. SCC and backdoor methods are known restricted upper bounds, not universal lower-bound mechanisms. No cryptographic, oracle, hashing, timing or restricted-proof-system theorem is imported into arbitrary SAT time.

\section{Exact state-dependent minimax theorem}
For $q\ge3$, let $b=(b_{ij})\in\{0,1\}^{q\times q}$, with $M=q^2$, and
\[
f_q(b)=\bigwedge_{i=1}^{q}\bigvee_{j=1}^{q}b_{ij}.
\tag{1}
\]
An input-field query reveals one $b_{ij}$ at unit acquisition cost. Internal computation, source-aware adaptation, method switching, caching, rereads and continuation are unrestricted but separately charged. $C(f,b)$ is the minimum number of observed field values forcing $f(b)$ against all opposite-label completions, and $D(f)$ is the minimum worst-case number of field reads across all deterministic exact adaptive policies.

\begin{theorem}[PROVED/EXACT]\label{th:gap}
Every input $b$ has $C(f_q,b)=q$, yet $D(f_q)=q^2$. In fact, for each deterministic exact policy $A$, there are policy-dependent SAT and UNSAT inputs $b_A^+$ and $b_A^-$ on which $A$ reads all $q^2$ distinct fields.
\end{theorem}
\begin{proof}
On a SAT input, observing one true field per row certifies the label; fewer than $q$ rows so certified permits setting an unprotected row entirely false. On an UNSAT input, a full zero row of $q$ observed fields certifies the label. Without observing all fields of some all-zero row, complete each row with one true field to reverse the label. Thus both labels have pointwise certificate complexity exactly $q$.

For an arbitrary adaptive policy, answer zero to the first $q-1$ \emph{distinct} queries in each row and answer one to the last field of each row. At every strict prefix of all $q^2$ distinct field queries at least one row is unfinished. Setting all its unobserved fields zero yields an UNSAT completion, while setting one remaining field in every unfinished row true yields a SAT completion. An exact policy cannot stop at that prefix. At the final queried field, answer one to obtain a SAT hard input or zero to obtain an UNSAT hard input; the earlier transcripts are identical. Both require $q^2$ reads. Reading all $q^2$ fields is an upper bound.
\end{proof}

At partial state $\sigma$, let a row be resolved true if a one is observed, resolved false if every field is observed zero, and active otherwise. For an ambiguous transcript let $t_i$ be the number of unobserved fields in active row $i$. The exact adaptive minimax remaining depth is
\[
W(\sigma)=\sum_{i\ {\rm active}}t_i.
\tag{2}
\]
The same adversary proves the lower bound; querying all active fields proves the upper. More generally the external policy recurrence is
\[
W(\sigma)=1+\min_{a\ {\rm unread}}\max_{v\in\{0,1\}}W(\sigma[a=v])
\tag{3}
\]
with $W=0$ on fixed-label states. This is a mathematical characterization, \emph{not} an object the machine must compile. It allows the parameter vector to change after each observation. Pointwise $C=q$ and adaptive worst-case $D=q^2$ have different quantifier order; this is the exact correction to a pointwise-cover-only audit.

\section{Ordinary proper-3CNF transport and resources}
For each input field create variable $x_{ij}$ and two new variables $a_{ij},t_{ij}$. Let $\ell_{ij}=x_{ij}$ if $b_{ij}=1$ and $\ell_{ij}=\neg x_{ij}$ otherwise. Insert the exact forcing gadget
\[
U(\ell;a,t)=
(\ell\vee a\vee t)\wedge(\ell\vee a\vee\neg t)\wedge
(\ell\vee\neg a\vee t)\wedge(\ell\vee\neg a\vee\neg t).
\tag{4}
\]
It is logically equivalent to $\ell$. Thus every $x_{ij}=b_{ij}$ is forced. Changing one source field changes four disjoint literal-sign words, and no other record.

For $q=3$, impose each row with one ternary $(x_{i1}\vee x_{i2}\vee x_{i3})$. For $q>3$, impose each row with the standard equisatisfiable OR chain:
\[
(x_{i1}\vee x_{i2}\vee y_{i1}),\
(\neg y_{i,j-2}\vee x_{ij}\vee y_{i,j-1})_{3\le j\le q-2},\
(\neg y_{i,q-3}\vee x_{i,q-1}\vee x_{iq}).
\tag{5}
\]
The $q-3$ row auxiliaries are fresh. All clauses have three distinct variable names, and all signed clauses are unique. The resulting $G_q(b)$ has SAT label exactly $f_q(b)$ and
\[
n=4q^2-3q,\quad m=5q^2-2q,\quad
w_q=\lceil\log_2(64(n+m+1))\rceil,\quad
N_q=(20q^2-8q+2)w_q.
\tag{6}
\]
These are full target bit lengths using two header words and four fixed-width record words per ternary clause. The compiler reads $q^2$ source fields, outputs exactly $4m+2$ target words, and uses $O(q^2)$ word time and peak space if materialized. The $2q^2$ unit-gadget auxiliaries remain free on a satisfying forced literal; row-chain witnesses are existential, and no original source variable is eliminated ($d=0$).

\begin{theorem}[PROVED/EXACT addressed-input lower bound]
For every total uniform deterministic exact proper-3CNF SAT decider $A$, and every $q\ge3$, there exist encoded equal-length SAT and UNSAT inputs $G_q(b_A^\pm)$ such that both executions contain at least $q^2$ distinct source-orientation sign-group probes. In the declared addressed-bit or fixed-record-word model,
\[
T_A(G_q(b_A^\pm))\ge q^2=\Omega(N_q/\log N_q).
\tag{7}
\]
\end{theorem}
\begin{proof}
Restrict the arbitrary full-language machine's input to $G_q(b)$. All template/metadata records are independent of $b$. Every charged read of a literal-sign word reveals at most one source field, even though it has four occurrences. Simulate that observation via one field query, cache repeated observations, and apply Theorem~\ref{th:gap}. The restriction is to a fixed family inside the full proper-3CNF language, not a promise used by the decider to skip validation. The bound counts actual source access; it does not suppose that the original algorithm emits a decision tree.
\end{proof}
A total exact full-language algorithm can validate every canonical record in $O(q^2)$ word time, inspect the signs, evaluate (1), and use an exact exhaustive fallback on every noncanonical input. Thus both labels are decidable in $O(q^2)$ word time on this family. Paid source-to-target construction work consumes an old $\Theta(q^2)$ query lower bound under
\[
L_{\rm old}\le R+H+Q\tau T_{\rm new}^{\le}(g);
\tag{8}
\]
(7) instead proves target acquisition \emph{directly}. No new continuation lower bound transfers.

\section{Adaptive-state ledger, computational controls, peer audit}
The certified policy first validates the source and acquires actual signed records; the analytical parameters $(t_i)$ do not require computation by the unrestricted solver. Its next rule is chosen from observations, may inspect any active field, and updates row status on receipt. An observed all-zero row supports UNSAT; a one in every row supports SAT. Failed recognition invokes a full exact fallback. Template discovery, switching, rereads, witnessing, verification, output and peak space are charged. SAT and UNSAT labels are never pre-disclosed.

\textbf{COMPUTATIONAL.} A deterministic standard-library auditor (seed 202610240824) checked 21,943 assertions with zero discrepancies. All 512 sources at $q=3$ were built as actual proper-3CNFs and checked by an independent exact DPLL: 343 SAT and 169 UNSAT. All 512 exact pointwise certificates had size three. Independent three-valued-state minimax DP visited 79 states at $q=2$ and 19,261 states at $q=3$, returning depths four and nine. Another 64 $q=4$ proper-3CNF cases and 192 sign-flip groups were checked. For each $q=3,4,8,16$, 24 query permutations had both SAT and UNSAT completions at every proper prefix. Finite tests validate the implementation only; symbolic proofs above establish the unbounded statements.

\textbf{INDEPENDENT ROLE-4 AUDIT.} QUOTIENT-PIVOT-SWITCH71 uses $2(q+4)$ source-clause gadgets, each with three fresh equality/pivot variables, six binary links and one proper ternary. Direct counting confirms $(n,m_2,k,M)=(8q+31,12q+48,2q+8,14q+56)$. The source switch activates one chain and leaves $q+3$ variables in the other arm free, giving $\#\SAT=2^{q+3}(s(b^0)+s(b^1))$. After charged binary SCC quotient, every ternary still has width three, but they all share one signed pivot variable. Thus its raw backdoor $h_0=k$ and discovered $h_1=1$ are compatible and provide an adaptive bypass of static enumeration. These are symbolic checks of the actual construction, not a rerun of Role 4's numerical audit.
