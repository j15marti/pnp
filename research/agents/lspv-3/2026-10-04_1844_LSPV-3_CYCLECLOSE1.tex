\section*{Exact typed recursive model}
Fix finitely many deterministic exact procedure types
\[
P_1,\ldots,P_m.
\]
Type \(i\), on an input of length \(n\), performs nonrecursive local work at most
\[
n^{r_i+o(1)}
\]
and may invoke type \(j\) through finitely many charged channels \(e=(i,j,k)\). Channel \(e\) makes at most
\[
n^{\eta_e+o(1)}
\]
calls, each on an explicitly constructed input of length at most
\[
n^{\theta_e+o(1)}.
\]
All constants are uniform across input lengths. Every recursive call has exactly the semantics declared for its target type. Construction, normalization, census/output, amplification, indexing, compilation, route work, query construction, writing, transport, rereading, recomputation, recursion-stack space, and live buffers are charged. SAME\_REALIZATION means that recursive substitution answers exactly the calls made by the declared source construction.

For the closure theorem assume
\[
0\le \theta_e<1
\]
for every recursive edge.

Let \(C_i\) denote a candidate time exponent for type \(i\). The exact exponent inequalities are
\[
C_i\ge r_i
\]
and, for every edge \(e:i\to j\),
\[
C_i\ge \eta_e+\theta_e C_j.
\]

\section*{PROVED/EXACT: finite typed-cycle closure}
\textbf{Theorem CYCLECLOSE1.}
For a finite typed recursive system satisfying the model above, there is a finite vector \(C=(C_1,\ldots,C_m)\) satisfying all exponent inequalities. Recursive substitution then yields
\[
T_i(n)\le n^{C_i+o(1)}
\]
for every type \(i\), independently of any original polynomial exponent used to motivate or derive the procedures.

Moreover the least valid exponent vector is the least fixed point of the monotone max-affine map
\[
(\mathcal F(C))_i=
\max\left\{
r_i,\,
\max_{e:i\to j}(\eta_e+\theta_e C_j)
\right\}.
\]

\textbf{Proof.}
Unroll a recursive execution into its typed call tree. Along a path
\[
e_1,e_2,\ldots,e_t
\]
the exponent accumulated before terminal local work is
\[
\eta_{e_1}
+\theta_{e_1}\eta_{e_2}
+\theta_{e_1}\theta_{e_2}\eta_{e_3}
+\cdots
+\left(\prod_{h=1}^{t-1}\theta_{e_h}\right)\eta_{e_t},
\]
and terminal local work of type \(v\) contributes
\[
\left(\prod_{h=1}^{t}\theta_{e_h}\right)r_v.
\]
Because the type graph is finite and every edge has \(\theta_e<1\), let
\[
\theta_*=\max_e\theta_e<1,
\qquad
\eta_*=\max_e\eta_e,
\qquad
r_*=\max_i r_i.
\]
Every path contribution is at most
\[
\eta_*\sum_{q\ge0}\theta_*^q+r_*
=
\frac{\eta_*}{1-\theta_*}+r_*,
\]
so the supremum over all finite paths is finite. Taking, for each start type, the supremum of its path contributions gives a vector satisfying the inequalities. Standard monotone iteration from the local-work vector \(r\) increases to the least such fixed point. Strong induction on input length then proves \(T_i(n)\le n^{C_i+o(1)}\); strict fractional shrinkage guarantees termination. \(\square\)

\section*{PROVED/EXACT: explicit cycle equation}
For one directed cycle
\[
i_1\xrightarrow{e_1}i_2\xrightarrow{e_2}\cdots
\xrightarrow{e_d}i_1,
\]
define
\[
\Theta_\gamma=\prod_{h=1}^{d}\theta_{e_h}
\]
and
\[
H_\gamma=
\eta_{e_1}
+\theta_{e_1}\eta_{e_2}
+\cdots+
\left(\prod_{h=1}^{d-1}\theta_{e_h}\right)\eta_{e_d}.
\]
Repeated traversal contributes
\[
H_\gamma+\Theta_\gamma H_\gamma+\Theta_\gamma^2H_\gamma+\cdots
=
\boxed{\frac{H_\gamma}{1-\Theta_\gamma}}
\]
when \(\Theta_\gamma<1\).

Thus a recursive cycle is not itself an obstruction. A fully charged cycle of genuinely fractional calls is absorbable. The relevant quantity is the weighted cycle contraction, not the mere existence of feedback.

For a self-loop this reduces to
\[
C\ge \eta+\theta C
\quad\Longrightarrow\quad
C\ge\frac{\eta}{1-\theta},
\]
recovering RECURCLOSE1 and MULTICHANNEL1.

\section*{Current-scale failure mode}
The strict fractional hypothesis is load-bearing. If a cycle has
\[
\Theta_\gamma=1
\]
and
\[
H_\gamma>0,
\]
then its inequalities imply
\[
C_{i_1}\ge H_\gamma+C_{i_1},
\]
which has no finite solution. This does not prove that SAT is hard. It proves only that this recursive exponent-erasure argument cannot absorb that declared cycle.

In particular, a hidden current-scale call to the original SAT decider is not neutralized by routing it through auxiliary procedure types. Renaming a current-scale dependency or sending it around a cycle does not erase its charge.

\section*{SAME\_REALIZATION and hostile audit}
\textbf{RECOMP.} On-demand recomputation is part of local work or an explicit edge. If it invokes a current-scale SAT computation, the corresponding edge is not fractional.

\textbf{DELAY.} Delaying a query changes chronology, not its original-input scale. A delayed scale-one edge remains scale one.

\textbf{COPY.} Duplicating an edge changes multiplicity \(\eta_e\); it cannot create contraction.

\textbf{INTERP.} Replacing a procedure by another representation may change the graph. CYCLECLOSE1 then applies only to the new fully charged graph and gives no representation lower bound.

\textbf{Compact representations.} A compact strategy circuit, memoized table, preprocessing object, or algebraic representation must be charged where acquired, evaluated, and stored. Semantic existence is not acquisition.

\textbf{Easy controls.} Horn, dual-Horn, 2-SAT, affine/Tseitin, bounded-treewidth instances, and independent products can possess efficient recursive decompositions for reasons unrelated to unrestricted SAT. CYCLECLOSE1 correctly treats such decompositions as upper-bound mechanisms, not hardness evidence.

\textbf{Semantic oracle.} The recurrence theorem relativizes under consistent oracle replacement. A sufficiently strong oracle can answer declared semantic calls. Therefore CYCLECLOSE1 is not the required nonrelativizing hinge.

\textbf{Algebraic oracle.} Low-degree or algebraic access may expose collisions or compact intermediate objects without supplying the SAT-semantic source-matched channels required here. No nonalgebrization conclusion follows.
