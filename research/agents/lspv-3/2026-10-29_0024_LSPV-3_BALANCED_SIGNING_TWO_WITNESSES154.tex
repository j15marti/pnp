\section{BUILD: a universal easy balanced signing}
Let $\mathcal H=(V,\mathcal C)$ be an \emph{unsigned} clause-scope system. Each scope $C\in\mathcal C$ contains exactly three distinct variables; each variable occurs in exactly four indexed clause occurrences. Clauses are indexed so even repeated scope triples remain distinct source entries. Set $n=|V|$ and $m=|\mathcal C|$. Counting incidences yields $3m=4n$, hence $n=3r$ and $m=4r$ for some integer $r$.

\begin{theorem}[Two-witness balanced signing]\label{thm:two}
For every such scope system $\mathcal H$, connected or disconnected, a uniform deterministic algorithm computes a sign for each literal occurrence such that:
\[
 \forall v\in V:\quad d^+(v)=d^-(v)=2,\qquad
 \forall C\in\mathcal C:\quad 1\le d^-(C)\le 2.
\]
The produced proper strict signed exact-$(2,2)$ 3CNF formula $F_{\mathcal H}$ is satisfied by both $0^n$ and $1^n$. A straightforward augmenting-path implementation has $O(m^2)$ elementary graph edge examinations, plus input parsing and output encoding; it maintains $O(m)$ graph records and produces $O(m\log(m+2))$ output bits. The construction preserves the unsigned scopes and incidence connectedness.
\end{theorem}
\begin{proof}
Group the $m=4r$ indexed clauses into $r$ groups of four. Add $r$ auxiliary \emph{graph-only} vertices $d_1,\ldots,d_r$, one per group, and connect each $d_j$ to its four clauses. The bipartite graph $G$ now has $n+r=4r=m$ vertices on the left, $m$ clauses on the right, and degree four at every vertex. These dummy vertices are part of the graph construction, \emph{not} variables or clauses added to the output CNF.

By Hall's theorem, every regular bipartite graph with equal part sizes has a perfect matching. After removing one perfect matching, the remaining graph is three-regular; repeat four times. Color each edge $0,1,2,3$ according to its matching. Make an original literal occurrence negative precisely for colors $0$ and $1$, and positive for colors $2$ and $3$. Since every original variable meets every color once, it has exactly two occurrences of each polarity. Every clause has one edge of each color among its \emph{three original incidences plus one dummy edge}. If the dummy edge is negative, one original edge is negative; if it is positive, two original edges are negative. Thus each original clause has one or two negative literals and also one or two positive literals.

The all-zero assignment satisfies every clause via a negative literal, and the all-one assignment satisfies every clause via a positive literal. Each matching can be computed by augmenting paths: for each of $m$ left vertices search a path that inspects at most $4m$ remaining incidences, giving $O(m^2)$ examinations per matching. Four rounds preserve that bound. The graph arrays, matchings and signed output contain $O(m)$ records with $O(\log m)$-bit indices. No SAT subroutine is used. Source clause IDs can be retained through the graph transformation and output signing.\end{proof}

\begin{proposition}[Exact two-witness certificate and quantifier firewall]\label{prop:firewall}
The output formula has an $O(n)$-bit positive witness consisting of $0^n$ or $1^n$, checked against source-ID-authenticated signed clauses in $O(N)$ bit-level scan work, modulo indexing conventions. Its four matchings provide an $O(N)$-bit construction transcript, checkable by validating every source incidence and the one-edge-per-vertex-per-color property.

However, the theorem has quantifiers
\[
 \forall\mathcal H\ \exists\sigma\ \exists a_0,a_1\quad
 F_{\mathcal H,\sigma}(a_0)=F_{\mathcal H,\sigma}(a_1)=1,
\]
with an efficient algorithm computing $\sigma,a_0,a_1$. It does \emph{not} say that \emph{every} signing $\sigma$ is satisfiable, and it does not preserve the answer of a \emph{given signed} input formula. In particular it cannot be applied as an unconditional SAT one-child reduction.
\end{proposition}
\begin{proof}
Output $a_0=0^n$, $a_1=1^n$ and the four edge-color matchings from the theorem. A deterministic checker validates original variable indices and scope identities, the dummy grouping, four perfect matchings and the sign/color correspondence, then directly tests both assignments. This is polynomial and does not require proof search. The logical quantifier distinction is literal: the signing is \emph{chosen} by the constructor, not imposed by an adversarial SAT instance.\end{proof}

\section{Matched connected strict exact-$(2,2)$ SAT/UNSAT control}
For a connected 15-variable, 20-clause proper $W_1$ unsigned support, the previous LSPV-3 data supplies balanced signings $U$ and $S$ on exactly the same indexed unsigned clause scopes, with $U$ UNSAT and $S$ SAT. This run independently brute-forced all $2^{15}$ assignments for these two formulas. The deterministic four-matching algorithm constructed a third signing $E$ of the \emph{identical} connected scope, with $0^{15},1^{15}\models E$.

Retain any one source variable $y$, and write its exact one-variable projection relation
\[
 R_F(y)=\{\eta\in\{0,1\}:\exists\,X\setminus\{y\}\ F(X)\wedge(y=\eta)\}.
\]
The audit found $R_U=\varnothing$, whereas $R_S=R_E=\{0,1\}$. Thus the one-bit boundary table may be empty or full on \emph{the same connected unsigned scopes}, despite all instances having identical strict $(2,2)$ occurrence budgets. This is a finite matched control, not an NP-hardness theorem for a fixed unsigned graph.

\paragraph{Complexity distinction.} Deciding emptiness of $R_F$ for arbitrary signed strict $(2,2)$ inputs is exactly UNSAT on that NP-complete signed promise class~\cite{docker}. Its table takes two truth values, but correct deterministic acquisition of the table for \emph{all inputs} in polynomial time would imply $P=NP$. A uniform polynomial-length sound and complete certificate system for the empty table would imply $NP=coNP$. These are immediate standard implications and not independent separations. Connectedness of the arbitrary-source NP-hardness reduction is not asserted here. A source-only positive witness on $E$ cannot be recycled as an UNSAT proof of $U$.
