\section{BUILD I: a connected two-answer strict exact-$(2,2)$ grid family}
Let $U$ and $S$ be the two 15-variable, 20-clause signed templates from W1-RING149, reproduced literally in the accompanying independent Python source. The first $U$ clause is $(\neg x_1\vee x_3\vee\neg x_{14})$; the first $S$ clause is $(\neg x_1\vee\neg x_3\vee x_{14})$. Their ordered \emph{unsigned} scopes coincide. Every variable has two positive and two negative appearances. Replacing the first negative literal of the first clause in block $i$ by $\neg x_{i+1,1}$, cyclically, creates a connected ring. Direct 14-private-variable enumeration establishes the local $U$ projection $\{(1,0)\}$ and the local $S$ projection $\{0,1\}^2$. For $S$ the all-zero private assignment works for each boundary pair.

For any integer $H\ge2$, use $K=H^2+2H$ modules. Set block $2j$ to $U$, and block $2j+1$ to $U$ if selector $\sigma_j=1$ and to $S$ otherwise, for $0\le j<H$. All remaining $H^2$ blocks are $S$, indexed in row-major order by $(r,c)\in\{0,\dots,H-1\}^2$. In each final $S$ block choose four \emph{negative} literal positions (zero-based source-clause and literal indices):
\[
 N=(1,2),\qquad S=(2,0),\qquad E=(3,1),\qquad W=(4,0).
\]
For every horizontal grid edge swap left $E$ with right $W$; for every vertical grid edge swap upper $S$ with lower $N$. No port is used twice. There are $2H(H-1)$ swaps, all between negative literal occurrences. Thus signed degrees and proper ternary clauses are preserved, and the unsigned scopes are independent of the selector word. We never modify the $2H$ control blocks.

\begin{lemma}[Exact signed counts, connectedness, and a grid minor]
The family has $n=15K$ variables and $m=20K=4n/3$ clauses, is connected and proper, and every variable appears exactly twice positively and twice negatively. Its primal graph contains the $H\times H$ grid as a minor. Every global syntactic clause-hitting 2CNF backdoor has at least $m/4=n/3=5K$ variables.
\end{lemma}
\begin{proof}
Swapping two negative occurrences preserves each variable's sign counts. The original ring's first source clauses are untouched, so it remains connected. The final $S$ block's 15 variables induce a connected primal subgraph even after removing all four grid-port incidences and the incoming ring literal. An explicit authenticated local 14-edge spanning tree, with entries (child,parent,original clause ID), is recorded in the raw results. Each swapped port now creates an inter-block primal edge, so contracting each connected 15-variable tail block gives the required grid. Since every variable meets at most four clauses, hitting all $m=4n/3$ clauses requires at least $m/4=n/3$ variables.
\end{proof}

\section{BUILD II: structural frontier is necessarily large}
A processed variable is \emph{syntactically live} at a variable-order cut if it shares an original clause with an unprocessed variable. This does not assert that its assignment survives semantic projection.
\begin{theorem}[Every-order syntactic live-variable lower bound]
For every $H\ge4$, every variable ordering of the above clause scopes has a cut with at least $H/16$ live processed variables.
\end{theorem}
\begin{proof}
Consider the first point of a complete ordering where $\lfloor H^2/2\rfloor$ distinct grid branch sets have at least one processed variable. Let $S$ be these started grid positions. A started branch set incident to an unstarted one contributes a processed live variable: when partially processed, its connected internal primal graph crosses between processed and unprocessed vertices; when fully processed, the inter-block grid edge itself crosses. Different branch sets contribute different live variables.

Let $r$ be the number of mixed rows of the $H\times H$ grid, each containing both $S$ and its complement. If $r\ge H/4$, every mixed row has a horizontal crossing edge, yielding at least $H/4$ crossing grid edges. Otherwise the mixed rows contain fewer than $H^2/4$ positions, while both $S$ and its complement have at least $H^2/4$ positions for $H\ge4$. Hence some all-$S$ row and some all-complement row exist. Every grid column then has a vertical crossing edge, so there are at least $H$ crossing edges. In either case $|\partial_E S|\ge H/4$. Grid degree is four, giving at least $H/16$ different started boundary positions. Each supplies a different processed live variable by the first paragraph.
\end{proof}

\noindent This is an architectural width lower bound only. A program that has recognized the easy selector promise may ignore the grid's syntactically live state entirely. No $2^{\Omega(H)}$ lower bound on \emph{reachable} semantic relations or actual computation is asserted.

\section{BUILD III: complete source-ID 2CNF contradiction tree}
\begin{theorem}[Uniform deterministic both-answer acquisition]\label{thm:cert}
One uniform polynomial-time deterministic program parses every canonical promised input, discovers its selector word $\sigma$, decides both SAT and UNSAT correctly, emits a satisfying assignment on SAT, and constructs a source-authenticated, complete, ancestor-consistent $2$CNF contradiction tree on UNSAT. The tree branches on exactly ten original variables, has $1024$ leaves, and uses only the original source clauses from two adjacent $U$ blocks. Its encoded length, including source pointers and output, is $O(\log N)$ for canonical unpadded input length $N=\Theta(K\log(K+2))$, while discovery and full input authentication take polynomial time. No free answer-side advice or guessed certificate is used.
\end{theorem}
\begin{proof}
The parser checks the header, exact block count $K=(H+1)^2-1$, all $20K$ ordered source literal triples, the $2H$ U/S control templates, and the arithmetic grid-port substitutions. It infers each flag only after matching an entire signed source block. There is no oracle call. On all-zero selectors, use the fixed original ring witness: the $U$ modules set their entering boundary to one and exiting boundary to zero, while all $S$ private variables are zero. Every swapped grid literal is negative and refers to a zero-valued grid $S$ variable, so this very same witness still satisfies all changed clauses.

Otherwise find the first $j$ with $\sigma_j=1$. Original blocks $2j$ and $2j+1$ are adjacent $U$ modules and were never modified by grid swaps. The 39-clause contradiction core consists of all twenty original source clauses in block $2j$ and original clauses numbered 2 through 20 in block $2j+1$. Define the ten-variable source-name set
\[
 B_j=\{x_{2j,v},x_{2j+1,v}:v\in\{2,4,7,14,15\}\}.
\]
Every one of those 39 ternary clauses contains at least one variable from $B_j$. Use a fixed full binary branch tree in this order, with $2^{10}=1024$ leaves. For each branch assignment, simplify the \emph{actual original clauses}: a satisfied clause disappears and every false assigned literal is removed. Every surviving clause has at most two literals, so it is genuine $2$CNF. The algorithm constructs its directed implication graph, with a source clause ID on every implication edge. For each of the 1024 residuals the fixed producer finds a literal $p$ and paths $p\leadsto\neg p$ and $\neg p\leadsto p$. All attempts are charged and the producer fails closed if no such pair is found. An independent checker reads each source clause indexed by the edge, recomputes its simplification from that leaf's ten ancestor values, checks the claimed implication and path endpoints, and verifies that all branch masks from 0 through 1023 occur exactly once. Thus each leaf is sound and the complete both-branch tree excludes every assignment.

The producer and checker are fully specified in the accompanying Python file, whose 1024-leaf control template is a \emph{constant-size, independently replayable finite witness} for the all-$H$ claim, not a table of answers for arbitrary SAT instances. In one complete local refutation it emitted 1024 implication-path pairs, comprising 18,880 authenticated implication edges, with paths of combined length between 12 and 26. The current proof is an explicit source-ID $2$CNF-SCC tree, not merely an abstract Resolution proof or an unchecked signed hash. The generated certificate and its deterministic discovery remain valid for any grid size because all used source clauses are confined to two unchanged control blocks.
\end{proof}
