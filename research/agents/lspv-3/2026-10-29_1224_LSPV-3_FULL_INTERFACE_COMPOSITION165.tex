A fixed-codimension local solver is KNOWN (Arvind and Guruswami, IPEC 2021,

establishes W[1]-hardness in $e$, not an unconditional non-FPT bound.
The case $e=2$ is already polynomial. LSPV-5's MAIN-AFFINE-INTERFACE-REFEREE203
previously proved the path version. This report extends to branching trees.

Let a polynomially verified rooted tree own each explicitly encoded
2CNF-plus-affine source constraint exactly once. Each shared variable
occurs in a connected subtree (running intersection). The local
affine rank at bag $V_t$ is $e_t$. Let $B_t$ comprise ALL bag variables
shared with any other bag, not merely the current parent separator,
and let $b_t=|B_t|$. The separator toward the parent is $S_t$.

The same uniform deterministic program exactly constructs projected
feasibility tables bottom-up. For each of $2^{b_t}$ full-boundary
assignments it looks up child tables on their full overlaps,
pins the current 2CNF and affine rows, and calls the known
fixed-codimension 2SUBSAT solver. Pinning cannot increase affine
row rank, while 2CNF remains 2CNF. One concrete local witness
and child pointer per feasible parent-separator signature suffice.
Running intersection guarantees global witness gluing.

Total charged time is
\[
D(N)+\operatorname{poly}(N)\sum_t 2^{b_t}(|V_t|+1)^{O(e_t)},
\]
including discovery, verification, source access, all negative calls,
compatibility checks, output and reconstruction. For polynomial
discovery, bounded $e_t$, and ALL $b_t=O(\log N)$ this restricted
mixed-language class is in deterministic P. On NO, the same program
produces replayable exact-table computations, not necessarily
original-3CNF Resolution certificates.
