\section{BUILD I: the graph and source classes}
Let $\W$ be the proper 3CNF on $x_1,\dots,x_{15}$ whose 20 ordered signed source clauses are the literal triples in \texttt{W1\_STR} of the accompanying standalone reproducer. Its first clause is
\[
 C_1=(\neg x_1\vee x_3\vee\neg x_{14}).
\]
Each original variable has exactly two positive and two negative occurrences, and the incidence graph remains connected after deleting $C_1$. The finite statements are certified by enumerating $2^{15}=32{,}768$ assignments and independently checking the supplied 76-step source-identified Resolution proof. The latter is a verifiable finite proof, not a conjectural hardness claim.

For every integer $k\ge2$, take $k$ numbered copies $\W^{(0)},\ldots,\W^{(k-1)}$, with variables $x_{i,v}$ ($0\le i<k$, $1\le v\le15$). In copy $i$ replace only the first literal of its first clause $\neg x_{i,1}$ by $\neg x_{i+1,1}$, with block indices modulo $k$. Leave all other source scopes in that copy unchanged. Call the resulting \emph{ordered unsigned} clause-scope graph $\mathcal G_k$ and write $\mathcal C_k$ for \emph{all} proper strict signed exact-$(2,2)$ signings of this verified scope graph, with clauses in their canonical block order.

\begin{lemma}[Authenticated connected two-polarity family]\label{lem:scope}
For every $k\ge2$, the canonical input class $\mathcal C_k$ has $n=15k$ distinct variables, $m=20k=4n/3$ proper ternary clauses and a connected incidence graph. Every source has exactly two positive and two negative occurrences of each variable. Its minimum global syntactic clause-hitting backdoor is at least $n/3=5k$.
\end{lemma}
\begin{proof}
Each original unsigned variable has degree four, and the definition of $\mathcal C_k$ requires precisely two positive and two negative incidences. For the explicit $\U/\V$ templates, the first literal in each block is negative, and cyclic permutation of these $k$ negative occurrences preserves the two-positive/two-negative quotas: each $u_i$ loses one negative occurrence in its own block and gains one in the predecessor block. The unswapped 19 original clauses in each copy induce a connected component containing all fifteen private names, checked once in the constant original gadget. Its first clause joins that component to the successor component, making the union connected. Every variable hits at most four original clauses. A set meeting all $m=4n/3$ clauses must therefore contain at least $m/4=n/3$ variables. These are syntactic properties of the supplied source, not semantic computational lower bounds.
\end{proof}

\section{BUILD II: uniform complete exact transfer for arbitrary signings}
For each actual signed source $F\in\mathcal C_k$, module $i$ contains its 20 original clauses $M_i$. Define the shared boundary names $u_i=x_{i,1}$ and $u_{i+1}=x_{i+1,1}$ and the other fourteen local private names $P_i=\{x_{i,2},\ldots,x_{i,15}\}$. Set
\[
 R_i(a,b)=[\exists P_i\ M_i(u_i=a,u_{i+1}=b,P_i)]\in\{0,1\},\qquad a,b\in\{0,1\}.
\]
Each $R_i$ is a four-bit $2\times2$ Boolean matrix. The verifier constructs it from actual authenticated source clauses, not an unchecked proposed summary.

\begin{theorem}[One-program all-answer transfer and certificate acquisition]\label{thm:transfer}
There is one uniform deterministic source parser, exact relation generator, decision algorithm, SAT witness constructor, and independently replayable UNSAT relation-trace verifier correct on every $F\in\bigcup_{k\ge2}\mathcal C_k$. In Boolean matrix arithmetic,
\[
 F\in\SAT\quad\Longleftrightarrow\quad
 \bigvee_{a\in\{0,1\}}
 (R_0\odot R_1\odot\cdots\odot R_{k-1})_{a,a}=1.
\]
Each $R_i$ is generated by checking at most $4\cdot2^{14}=2^{16}$ complete local assignments against 20 original clauses. Relation generation, transfer multiplication, witness reconstruction, and source reading together cost $O(2^{16}\cdot20\cdot k\,\mathrm{polylog}(k))$ bit operations. Canonical $N=\Theta(k\log k)$, so the bound is polynomial in $N$. A trace records each actual $R_i$, the four-bit prefix product, and original source IDs. With explicit pointers its length is $O(k\log k)=O(N)$ bits, and independent verification performs the same charged bounded local enumeration. If unsatisfiable, the replay ends with zero diagonal; if satisfiable, a complete $15k$-bit source assignment is deterministically reconstructible. No result of either polarity is presupposed.
\end{theorem}
\begin{proof}
Each module mentions only its private variables and the two adjacent shared names. Thus for a fixed cyclic boundary word $(u_i)$, the private existential quantifiers separate exactly. The conjunction is satisfiable iff every chosen adjacent boundary pair belongs to its module relation. Boolean matrix multiplication exactly expresses existence of the intermediate boundary values; equality between the start and end boundary is exactly the nonzero diagonal condition. Enumerating all fourteen private bits and both boundary bits is exhaustive and is uniformly bounded because the local scope size is a fixed constant. To reconstruct SAT, try both initial boundary bits, propagate backward feasible states through the $k$ two-state relations, choose an admissible cyclic path, and use the first recorded local private witness for each selected pair. For UNSAT, output the relation and prefix tables. The checker reparses all original clauses, reestablishes each authenticated source ID and degree/scope promise, recomputes all four relation entries, and checks every prefix update. It rejects a malformed source or trace rather than accepting a fabricated relation. This proves completeness for both answer classes within the promised graph class, not unrestricted SAT.
\end{proof}

\section{BUILD III: exact U/S contrast and constant Resolution refutation}
Define signed template \(\U\) as the original $\W$ literal signs, and \(\V\) as the explicitly listed 20 signed clauses in \texttt{S\_STR} of the executable. In both templates the occurrence of $\neg x_1$ selected for cyclic swapping has the same sign. Every original variable remains $2$-positive/$2$-negative when different templates are mixed. The exact local matrices are
\[
 R_{\U}=\begin{pmatrix}0&0\\1&0\end{pmatrix},
 \qquad R_{\V}=\begin{pmatrix}1&1\\1&1\end{pmatrix}.
\]
\begin{lemma}[Local relation proof]\label{lem:local}
The $\U$ module allows exactly the boundary pair $(u_i,u_{i+1})=(1,0)$. The $\V$ module allows all four pairs, with all fourteen local private variables set to zero.
\end{lemma}
\begin{proof}
Because $\W$ is unsatisfiable, any assignment satisfying $\W\setminus\{C_1\}$ must falsify each literal of $C_1$; otherwise it would satisfy the full $\W$. Hence every such assignment forces $x_1=1$, $x_3=0$, $x_{14}=1$. The modified first clause becomes $(\neg u_{i+1}\vee x_{i,3}\vee\neg x_{i,14})$, requiring $u_{i+1}=0$. The private 14-bit mask $4104$ (bit $v-2$ representing $x_v$) is an explicit satisfying witness for the pair $(1,0)$. For $\V$, direct inspection of the 20 listed clauses shows that every clause contains a negative private literal among $x_2,\ldots,x_{15}$; therefore the all-zero private assignment satisfies the module regardless of the two boundaries. This is an exact finite clause check, also reproduced by source enumeration.
\end{proof}

\begin{theorem}[Both polarities on the same connected strict exact-$(2,2)$ scopes]\label{thm:two}
For each $k\ge2$ and each cyclic word $w\in\{\U,\V\}^k$, form $F_k(w)$ by selecting the corresponding signs in the canonical scope graph $\mathcal G_k$. Then
\[
 \boxed{F_k(w)\in\UNSAT\quad\Longleftrightarrow\quad
 \exists i\ (w_i=\U\ \wedge\ w_{i+1}=\U)}.
\]
If SAT, an original-variable assignment is generated by setting $u_i=1$ at $\U$ positions and $u_i=0$ at $\V$ positions, setting local private bits to mask $4104$ on $\U$ positions and to zero on $\V$ positions. If UNSAT, 168 or fewer source-authenticated Resolution derived lines yield the empty clause, using source clauses from only two consecutive $\U$ blocks, no matter how large $k$ becomes. Thus the proof has $O(\log N)$ encoded bits when full source pointers and derived literal names are binary, whereas deterministic acquisition still parses and authenticates the source at cost $O(N)$.
\end{theorem}
\begin{proof}
By Lemma~\ref{lem:local}, each $\U$ position forces $u_i=1$ and $u_{i+1}=0$, while each $\V$ position restricts neither. Two adjacent $\U$ positions impose contradictory values on their shared variable. Conversely, in the absence of adjacent $\U$ positions, the stated boundary assignment satisfies every allowed pair and the stated private assignments satisfy all original clauses.

For the original 19 clauses of $\W$ other than $C_1$, the accompanying finite resolution templates derive original-variable units $(x_1)$, $(\neg x_3)$, and $(x_{14})$, in respectively 64, 47, and 54 derived lines. Every step is an elementary Resolution inference from original source clause IDs or earlier derived clauses, checked with its exact pivot and both parent pointers. For consecutive $\U$ blocks $i,i+1$, derive $(x_{i,14})$ and $(\neg x_{i,3})$ from the 19 unmodified original clauses of block $i$, and derive $(x_{i+1,1})$ from the 19 unmodified clauses of block $i+1$. Resolve the actual first source clause of block $i$ three times to get, in succession, $(\neg x_{i+1,1}\vee x_{i,3})$, $(\neg x_{i+1,1})$, and the empty clause. Total derived lines are $54+47+64+3=168$. The checker does not trust this clause or its source digest; it reads the actual source and validates every derivation. The 76-step independent original-$\W$ refutation and 168-step eight-module source example are furnished as separate raw proof objects.
\end{proof}

\section{SAT-versus-UNSAT source-query contrast}
\begin{corollary}[Both-side worst-case deterministic block probes]\label{cor:query}
Restrict $k=2m$ and fix all odd cyclic positions to type $\U$. Allow the $m$ even positions to vary independently between $\U$ and $\V$. Every correct deterministic decision tree in this block-type access model has a satisfiable input on which it must query all $m$ variable positions, and an unsatisfiable input on which it must also query all $m$ variable positions. The worst-case block-query depth is exactly $m$ on both answer classes. Yet every UNSAT input admits a certificate specifying just one $\U$ at an even position adjacent to a fixed $\U$; it has the original-clause Resolution proof of Theorem~\ref{thm:two}.
\end{corollary}
\begin{proof}
The decision is SAT iff all $m$ unfixed positions have type $\V$. A correct deterministic algorithm must query all $m$ on the all-$\V$ input; otherwise changing one unread block to $\U$ changes the answer. Change instead the last queried even block to $\U$; before that last query the deterministic transcript is unchanged, so the resulting UNSAT input also costs $m$ queries. A left-to-right scan achieves $m$. At least one literal sign differs between the two templates in each block, giving the analogous $\Omega(m)$ lower bound in a coordinate-probe model that exposes source bits. This is merely an indexed input-sensitivity lower bound, not a hard SAT runtime or space bound. It uses \emph{one} fixed solver restricted to two answer classes, not two solvers receiving a free answer-class bit.
\end{proof}

\section{Quantitative ledger and proper limitations}
\paragraph{Input, acquisition and checking.} In the canonical unpadded encoding $N=\Theta(k\log(k+2))$. The general all-signings exact trace uses at most $2^{16}$ local assignment trials and $20$ clause tests per trial per block, four-bit transfer matrices, $k$ prefix updates, original source scans, and a complete SAT witness reconstruction where appropriate. Failed local candidates are charged, as is the ordered source validation. No external SAT guest calls or hidden advice are used. In the $\U/\V$ subfamily, a fixed-pattern source scan classifies the blocks; the UNSAT Resolution certificate contains 168 derived steps independent of $k$, with pointer bit length $O(\log N)$. The generic trace may require $\Theta(k)$ four-bit records and $O(N)$ bits once source IDs are explicit. Semantically verified relations are not assumed free, and an unchecked candidate output is never treated as sound acceptance.

\paragraph{2-tape read-only-input/work ledger.} A read-only sequential input-head and one writable work tape can read the canonical source in order, retain the current 20 clause signs and counters, and perform the constant-size local enumeration using $O(\log N)$ work cells for decision and relation construction. An append-only output port can stream the trace/witness with all output bits charged in time. If the output must physically reside on the one writable work tape instead, its occupied cells must also be charged: $O(N)$ for a generic explicit trace or SAT witness, $O(\log N)$ for the short template UNSAT Resolution proof. The input footprint is not counted as \emph{work space} in this model, but every input read and all head movements are charged.

\paragraph{Single writable tape with initial input.} The initial $N$ input cells remain part of the occupied footprint. A conservative standard simulation of the two-tape procedure yields polynomial time, for example $O(N^2)$ for the linear-input-time bounded-module streaming version with ordinary fixed-symbol encoding, and $O(N)$ visited initial/input-plus-output cells. Any tighter head-reversal, crossing, or write-change statement requires its own machine proof; a two-tape communication argument is not silently imported.

\paragraph{Universal machine and RAM.} A fixed efficiently universal machine simulates the explicit fixed two-tape program with charged polynomial overhead and program description, not a free oracle. An indexed RAM independently reads the $O(N)$ canonical source encoding and evaluates each constant module; no tape-transport lower bound is claimed for it. All claims use one uniform deterministic program, and resource maxima on the SAT and UNSAT sides are not conflated with simultaneous per-input maxima.

\paragraph{Construction versus shrinkage.} Since the entire promised connected scope class is explicitly in P, a polynomial decision procedure can output a fixed YES or NO base formula and thereby form a \emph{restricted} single-child, $N^\lambda$ length-shrinker above a fixed threshold for any fixed $0<\lambda<1$. This is not a new general SAT shrinker: the 15-variable private module width is constant by construction. An arbitrary SAT formula does not come with such a decomposition, and finding bounded semantic interfaces for it may be hard. Moreover, merely compressing successive pairs of four-bit transfer matrices produces $\Theta(k)$ bits and does \emph{not} meet $N^\lambda$ for any fixed $\lambda<1$ as $N=\Theta(k\log k)$.
