\section{Target and theorem}
The one canonical NP-complete target is D\"ocker's duplicate-free proper clausewise-monotone 3-SAT-(2,2), with malformed inputs rejected. For an original monotone width-three formula F with n variables and m clauses, define a fixed aligned logical state as the assignment bits, the two-bit count of true literals in each original clause, and its satisfied indicator. For every one-variable-at-a-time monotone path from the all-zero to the all-one assignment, flipping every variable exactly once:
\begin{theorem}
The cumulative adjacent XOR for ordinary binary clause counts is n+5m, and its endpoint XOR is n+3m. For reflected Gray clause counts the quantities are n+4m and n+2m. These identities are independent of the variable order, formula topology, and SAT/UNSAT label.
\end{theorem}
\begin{proof}
Every variable bit flips once. Each positive clause visits true-counts 0,1,2,3; each negative clause visits 3,2,1,0. Ordinary binary count changes have bit distances 1,2,1, totaling 4; Gray count changes have distances 1,1,1, totaling 3. Each clause satisfaction bit changes once. At endpoints binary 00 and 11 differ in two bits, while Gray 00 and 10 differ in one. Add n assignment-bit changes and the m clause contributions.
\end{proof}
For canonical exact-(2,2), m=4n/3. The result concerns logical original-source vectors, not arbitrary FLMV physical tapes or mandatory SAT work.
