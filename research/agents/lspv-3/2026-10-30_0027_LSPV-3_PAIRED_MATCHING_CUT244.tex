\section*{PAIRED-MATCHING-CUT244: source-certified complement repair}
\noindent\textbf{PROVED/EXACT restricted, referee pending.} P versus NP OPEN. Coordination: \url{https://github.com/j15marti/pnp/issues/3}.
\begin{theorem}
Let $\alpha$ be a partial original-variable assignment with $f$ free coordinates. Let $a^0,a^1$ be coherent full completions extending $\alpha$, complementary on their free coordinates. Let $B_h$ be the original source clauses falsified by $a^h$, and let $\tau_h$ be the minimum number of free variables hitting all $B_h$ clause supports, or infinity if impossible. If $\tau_0+\tau_1>f$, no satisfying extension of $\alpha$ exists.
\end{theorem}
\begin{proof}
Any satisfying extension $b$ differs from $a^0$ on a set $T$ hitting each false source clause, so $|T|\ge\tau_0$. Because the two references complement exactly on the free set, $b$ differs from $a^1$ exactly on its complement, forcing $f-|T|\ge\tau_1$. Contradiction.
\end{proof}
If each original variable occurs twice positive and twice negative, a fixed reference assignment falsifies each variable on only two occurrences. On the graph whose vertices are falsified clauses and whose edges are free variables covering two false clauses, use singleton coverage for variables covering one. If all vertices are coverable, the minimum repair size equals $|B_h|-\nu(G_h)$, with $\nu$ a maximum general-graph matching. This follows from the classical minimum edge-cover identity; Edmonds' polynomial matching algorithm computes it, including source verification. Otherwise the minimum is infinity. Cost for one reference pair: conservative $O(N+m^3)$ indexed-RAM time; adaptive repeated trials are additional and can be exponential.

\section*{Source-indexed extreme states and duplicate audit}
For every original signed occurrence $x_{i,j}$, write its sign bit $\nu_{i,j}=1$ for a negative literal. A local $S_j$ mode makes \emph{all three} source literals true, requiring $x_i=1\oplus\nu_{i,j}$, whereas $U_j$ makes them all false, requiring $x_i=\nu_{i,j}$. Inversion exchanges $S_j$ and $U_j$. These local targets are not independently assignable shared variables. An ordinarily SAT clause only requires one true literal. For any globally coherent complete $a$, $t_j(\bar a)=3-t_j(a)$ and $N_r(\bar a)=N_{3-r}(a)$. Pair modes SS/UU are feasible iff no shared variable has opposite sign; SU/US are feasible iff none has the same sign. These are already known from the project EXTREME-DUALITY1, LSPV-1 SIGNED-CYCLE240 and LSPV-5 FIREWALL214. A pair compatibility guard alone cannot reject a coherent source DPLL node.

\section*{Proof audit of matching reduction}
On a fixed coherent reference, a variable has at most two occurrences of the sign that is FALSE in the source, hence covers at most two false clauses. A covering variable meeting two false clauses is an edge of their graph; one meeting only one is a singleton cover option. If a false clause has no available free variable, its hitting number is infinite. Otherwise a maximum matching of size $\nu$ covers $2\nu$ clauses; any unmatched vertex can be individually covered and no two unmatched vertices share an edge, giving $|B|-\nu$. The reverse inequality is the standard general-graph minimum edge-cover identity with singleton options. Thus the \emph{exact} minimum can be computed by Edmonds' algorithm. A mere maximal matching is insufficient. The model is indexed RAM, with source and verification charged, not a promised multitape bound. A fixed single check costs polynomial time; exponentially many adaptive attempts are possible.
