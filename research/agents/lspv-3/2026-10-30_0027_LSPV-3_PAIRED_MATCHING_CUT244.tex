\section*{PAIRED-MATCHING-CUT244: source-certified complement repair}
\noindent\textbf{PROVED/EXACT restricted, referee pending.} P versus NP OPEN. Coordination: \url{https://github.com/j15marti/pnp/issues/3}.
\begin{theorem}
Let $\alpha$ be a partial original-variable assignment with $f$ free coordinates. Let $a^0,a^1$ be coherent full completions extending $\alpha$, complementary on their free coordinates. Let $B_h$ be the original source clauses falsified by $a^h$, and let $\tau_h$ be the minimum number of free variables hitting all $B_h$ clause supports, or infinity if impossible. If $\tau_0+\tau_1>f$, no satisfying extension of $\alpha$ exists.
\end{theorem}
\begin{proof}
Any satisfying extension $b$ differs from $a^0$ on a set $T$ hitting each false source clause, so $|T|\ge\tau_0$. Because the two references complement exactly on the free set, $b$ differs from $a^1$ exactly on its complement, forcing $f-|T|\ge\tau_1$. Contradiction.
\end{proof}
If each original variable occurs twice positive and twice negative, a fixed reference assignment falsifies each variable on only two occurrences. On the graph whose vertices are falsified clauses and whose edges are free variables covering two false clauses, use singleton coverage for variables covering one. If all vertices are coverable, the minimum repair size equals $|B_h|-\nu(G_h)$, with $\nu$ a maximum general-graph matching. This follows from the classical minimum edge-cover identity; Edmonds' polynomial matching algorithm computes it, including source verification. Otherwise the minimum is infinity. Cost for one reference pair: conservative $O(N+m^3)$ indexed-RAM time; adaptive repeated trials are additional and can be exponential.
