\section{Declared machine and the conditional-read theorem}
Fix a language $L$ on valid encoded inputs $D_N\subseteq\{0,1\}^{N}$.
The algorithm is a deterministic total exact decider with an addressed
read-only input. A source bit becomes available only through an explicit
charged bit probe. Work-memory computations, cached reads, adaptive
branches, arbitrary learned invariants, restarts, and symbolic method
changes are unrestricted; their physical time is separately charged.
There is no input-dependent initial advice, free input hash, or external
oracle. Let $x\in D_N$ be fixed. After the $t$-th distinct source-bit
probe on $x$, let $Q_t$ be all already read source coordinates, independent
of the algorithm's internal representation.

For each legal $y$ with $L(y)\ne L(x)$ and
$y|_{Q_t}=x|_{Q_t}$, set
\[
D(x,y)=\{j\in[N]:x_j\ne y_j\}
\]
and let $\mathcal H_t(x)$ be the hypergraph of these nonempty
difference sets. Let $\tau_t(x)$ be its minimum vertex-cover/hitting-set
cardinality; $\tau(\varnothing)=0$.

\begin{theorem}[PROVED/EXACT, adaptive conditional-read potential]\label{th:potential}
For any such exact deterministic adaptive decider and any reachable
state on $x$, its remaining execution must contain at least
$\tau_t(x)$ \emph{new distinct source-bit probes}. In particular
\[
Q_{\rm total}(A,x)\ge\tau_0(x),\qquad
0\le\tau_t(x)-\tau_{t+1}(x)\le1
\tag{1}
\]
at every new bit read. Internal computation, representation switches,
and rereads do not decrease $\tau_t$.
Moreover $\tau_t\le N-|Q_t|$. These are bit-query lower bounds;
they are not superpolynomial time lower bounds.
\end{theorem}
\begin{proof}
If the decider halts while some opposite-label $y$ agrees with all
observed bits, determinism gives an identical observed execution and
root answer on $x$ and $y$, contradicting exactness. Its eventual new
read positions must therefore hit every edge of $\mathcal H_t$.
If the next distinct read is coordinate $j$, the only opposite-label
inputs eliminated are those whose difference edge contains $j$.
Thus $\mathcal H_{t+1}$ consists of edges of $\mathcal H_t$ not
containing $j$. A hitting set of $\mathcal H_{t+1}$ together with
$\{j\}$ hits all of $\mathcal H_t$, giving
$\tau_t\le1+\tau_{t+1}$. Deleting edges never increases hitting
number. A computation or a repeated read supplies no new input bit,
so its consistent-alternative hypergraph is unchanged. Every edge
is contained in the set of as-yet-unread positions, proving the
last bound. This holds for an adaptive policy even if it switches from
SCC to affine elimination to direct decision mid-run.
\end{proof}
\noindent\textbf{Word model.} The same proof applies verbatim to a
fixed partition into $w$-bit addressed words, replacing coordinates
by word addresses containing a changed bit. Different packing, wide
SIMD reads, indexed circuit-oracle access, or input-dependent advice
need a new charge. An algorithm's physical time is at least its
charged input probes in the stated model, not vice versa.

\section{Exact NP-complete target and two-bit local lift}
Let $q\ge1$ and $b=(b_1,\ldots,b_q)\in\{0,1\}^q$.
Let $F_b$ be the Role~4 binary implication chain
\[
\begin{split}
F_b={}&(z_0\lor u)\land(z_0\lor\neg u)
\land(\neg z_q\lor v)\land(\neg z_q\lor\neg v)\\
&{}\land\bigwedge_{i=1}^q C_i(b_i),\\
C_i(1)={}&(\neg z_{i-1}\lor z_i),\qquad
C_i(0)=(\neg z_{i-1}\lor\neg z_i).
\end{split}\tag{2}
\]
It has $q+3$ original variables and $q+4$ binary clauses.
The endpoints force $z_0=1$, $z_q=0$. An all-one chain is
inconsistent; if the first zero is at $i$, setting $z_j=1$
for $j<i$ and $z_j=0$ for $j\ge i$ satisfies every chain
clause. Thus $F_b\in\SAT$ iff some $b_i=0$.

For each binary clause $D_j=(a_j\lor c_j)$ introduce a fresh variable
$t_j$ and replace it by
\[
P(D_j)=(a_j\lor c_j\lor t_j)
\land(a_j\lor c_j\lor\neg t_j).\tag{3}
\]
Let $P_q(b)$ be the conjunction of these pairs in source-clause
order. All clauses contain three distinct variable identifiers;
different pairs use distinct $t_j$. Each $t_j$ is \emph{free}
when $D_j$ is true, and cannot satisfy both clauses if $D_j$ is
false. This is an assignment-wise exact SAT-preserving lift,
\emph{not} a parsimonious lift.

Use a fixed explicit encoding: header words $[n,m]$, followed by
four words per ternary clause, consisting of length tag 3 and three
signed literal records $2\operatorname{var}+[\text{negative}]$.
All words have
\[
w_q=\left\lceil\log_2(64(4q+16))\right\rceil\ \text{bits}.
\]
The target ledger is
\[
n'=2q+7,\quad m'=2q+8,\quad
N'=(8q+34)w_q=\Theta(q\log(q+2)).\tag{4}
\]
There are $q+4$ new free auxiliary variables; no original
variable is eliminated ($d=0$). Every original satisfying
assignment has exactly $2^{q+4}$ target extensions.
Target construction performs $\Theta(q)$ source-word reads,
$8q+34$ encoded-word writes, and $O(q)$ peak logical words
including source and output streams. Witness projection and
extension are $O(q)$ words; complete source validation is charged.

The target language is all well-formed proper 3-CNF in this encoding.
It is NP-complete by the standard CNF-to-3CNF transformation:
normalize repeated/tautological literals, pad each binary clause by
two opposite fresh-literal ternaries as in (3), each unit by four
ternaries on two fresh auxiliaries, and preserve existing proper
ternaries. The transformation and witness extension are polynomial.
We never infer hardness of a particular easy promise image from
NP-completeness of the entire target.

\begin{theorem}[PROVED/EXACT, target sensitivity under any adaptive decider]\label{th:lift}
For every $q\ge1$, the canonical all-one target
$X_q=P_q(1^q)$ is UNSAT. For each $i$, the canonical
$Y_{q,i}=P_q(1^{i-1}01^{q-i})$ is SAT and differs from $X_q$
in exactly \emph{two literal-sign bits}, at a pair of addresses
$D_i$, where the $D_i$ are pairwise disjoint. Hence every total
uniform deterministic exact decider of the \emph{full proper-3CNF
language} must read at least $q$ literal-sign word addresses on
$X_q$, irrespective of its adaptive strategy:
\[
T_A(X_q)\ \ge\ Q_{\rm words}(A,X_q)\ \ge\ q
=\Omega(N'/\log N').\tag{5}
\]
At any intermediate state, if $c$ of these $q$ disjoint
orientation blocks have been touched, at least $q-c$
additional distinct block reads are required before an UNSAT halt.
The statement remains a linear input-acquisition bound, not
a superpolynomial SAT lower bound.
\end{theorem}
\begin{proof}
Each chain orientation occurs only as the second literal of its
source $C_i$. Its padded pair places that literal into two
separately addressed ternary records. Changing $b_i$ changes
exactly their sign bit, leaving headers, lengths, variable names,
all other literals, and all other sign bits unchanged. Different
$i$ use disjoint pairs of records. Labels follow (2)--(3).
A decider reading neither member of $D_i$ on $X_q$ would have
identical execution on $Y_{q,i}$, a contradiction. Hence its actual
read-set meets all $q$ disjoint $D_i$. After touching $c$
blocks, the remaining $q-c$ SAT neighbors are still
indistinguishable. No clause-learning, graph decomposition,
Gaussian calculation, memoization, representation switch or
direct one-bit decision can invalidate this elementary
read-address accounting.
\end{proof}
\noindent On the \emph{promised canonical image}, the exact
conditional-read certificate number is $q$ for all-one UNSAT
and $1$ for any SAT $b$: the unique opposite-label image is
$P_q(1^q)$. On the unrestricted proper-3CNF language more
opposite-label neighbors may exist, increasing the certificate
number. The solver is not given canonicality or the SAT label
for free; a full $O(q)$ grammar/template check makes a uniform
full-language algorithm safe and exact.

\section{A precise adaptive-trajectory summation failure}
On $X_q$, consider the legal sequential image strategy that
reads one sign field from each $D_i$ and only then returns
UNSAT. Its analytical unresolved-block parameter has
\[
\phi_t=q-t,\qquad0\le t\le q.
\]
Thus $\phi_0=q$ and $\sum_{t=0}^{q-1}\phi_t=q(q+1)/2$,
but the number of necessary field probes is precisely $q$.
Any proposed work estimate $T\ge\sum_t\phi_t$ is
\textbf{FALSIFIED/RETIRED}. The correct guaranteed telescoping
account is
\[
T_{\rm read}\ge\sum_t(\phi_t-\phi_{t+1})=q.\tag{6}
\]
The same source read can discharge many future alternative
histories; counting each unresolved future at every intermediate
stage is double charging. A decider still pays its actual
internal processing and switching costs, but those costs are
not lower-bounded by the mere sequence of certificate potentials.

On the SAT side, a zero field can terminate the \emph{promised}
image decision immediately; a full-language algorithm must first
validate the template or use another sound exact criterion.
This is genuine SAT/UNSAT asymmetry without an answer oracle.

\section{Charged ladder transport and current theorem coverage}
The original $F_b$ input has $(4q+18)$ record words under the
binary encoding; explicit target materialization has $(8q+34)$
writes and width $w_q$. In a same-model paid reduction,
\[
L_{\rm old}(q)\le R(q)+H(q)+Q(q)\tau(q)
  T_{\rm target}^{\le}(g(q)).\tag{7}
\]
With $L_{\rm old}=q$ and $R\ge8q+34$, the transferred
lower-bound remainder is \emph{negative}.
Theorem~\ref{th:lift} establishes the target $q$ bound
\emph{directly} from actual target sign sensitivity, not by
subtracting a free reduction. This distinction is essential.
The output formula has growing ternary count and $n'$ but
is still recognizable and decidable in $O(q)$ word time on
the canonical image by a fully charged source-aware check.
There is no $2^{\Omega(n')}$ or $2^{\Omega(k)}$ time conclusion.
