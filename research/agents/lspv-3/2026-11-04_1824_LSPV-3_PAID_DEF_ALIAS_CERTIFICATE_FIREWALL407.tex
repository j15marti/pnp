\section*{Exact fixed fragment and theorem}
In the native paid DEF fragment, $z_i=g_i(\ell_{i1},\ell_{i2})$ is fresh and functional, with earlier signed inputs and an exact four-bit gate table. Every original valuation uniquely extends to the whole acyclic gate DAG $D$. Every gate costs one logical node; no definition asserts that its output is true. Let $E(F,D,p,q)$ assert that two designated output references have equal values for all original models of $F$.

\begin{theorem}[Contextual equality of paid ports]
Deciding $E(F,D,p,q)$ is coNP-complete for well-typed paid two-input DEF networks, even under the promise that the original CNF source $F$ is satisfiable.
\end{theorem}
\begin{proof}
If equality fails, one original assignment satisfying $F$ and giving different output values is a polynomially checkable certificate. For coNP hardness reduce CNF-UNSAT. Given any CNF $C(x_1,\ldots,x_n)$ with $n\ge1$, introduce source variable $s$ and the always-satisfiable source
\[
 F_C=(s)\land\bigwedge_{i=1}^n(s\lor x_i).
\]
Every $x$ assignment extends to a source model by taking $s=1$. Pay for ordinary fresh two-input AND/OR gates, using signed inputs, to compute $p=C(x)$. Pay for $q=x_1\land\neg x_1=0$ separately. All gates are fresh, acyclic and conservative. Then
\[
 E(F_C,D_C,p,q)\iff \forall x\ C(x)=0\iff C\in\mathrm{UNSAT}.
\]
There are $O(|C|)$ paid gates and $O(|C|\log(|C|+2))$ explicit encoding bits. No LOCAL-CONVERT or semantic oracle is assumed.
\end{proof}
An unrestricted free rule accepting arbitrary semantic identifications of paid wires with a deterministic polynomial checker would therefore imply P=NP. This does not assert such a rule exists in the original calculus.

\begin{lemma}[Structural alias certificate]
Take an acyclic network of $g$ paid DEF gates. Process it in order and assign each gate a signature consisting of its exact four-bit operation and previously canonicalized signed input references. Sort inputs only for a symmetric gate table. Reuse a prior representative with the identical signature, or pay one new fresh gate. This yields a network with at most $g$ paid definitions that preserves every designated output value for every original assignment. Construction and certificate checking require polynomial bit time and space.
\end{lemma}
\begin{proof}
By induction, each canonical input computes the value of its original reference. Identical truth tables on identical inputs (or swapped inputs for symmetric tables) compute the same output. Reused representatives are therefore equal for every original valuation; retained fresh gates remain conservative and paid. Inductively the entire output vector is unchanged, including reconvergent dependencies. A finite list of $g$ logarithmic-length signatures can be sorted or hashed in polynomial time.
\end{proof}
The lemma is not a complete semantic quotient. Associativity, distributivity and XOR cancellations can escape structural identification. It only translates conservative DEF subcircuits. Every downstream RES, AND3, XOR and LOCAL-CONVERT consumer must still be retyped and checked, so this is not an all-rule proof translation.
