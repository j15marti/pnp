\section{Pairwise exact iff for hereditary consistent shared pins}
Let $Y=(y_1,\ldots,y_k)$ be the \emph{same ordered original-source
boundary names} on two ordinary CNF modules $D(Y,U)$ and $Q(Y,V)$,
where $U\cap V=\varnothing$. Their extensional feasibility supports
\[
 P=\{b\in\{0,1\}^k:\exists u\ D(b,u)\},
 \qquad
 R=\{b\in\{0,1\}^k:\exists v\ Q(b,v)\}
\]
are \emph{not given for free}. Correct gluing is
$\SAT(D\wedge Q)\iff P\cap R\ne\varnothing$.
Fix any reusable label map $h:\{0,1\}^k\to H$.
For $u,v$ put
\[
 E(u,v)=\{i\in[k]:u_i=v_i\},\qquad
 C(u,v)=\{w:w_i=u_i\ (i\in E(u,v))\}.
\]
A consistent shared pin pattern $p$ is a partial assignment of
a subset $J\subseteq[k]$, applied to \emph{both} modules with
fresh independent PIN auxiliaries. Write $P_p,R_p$ for the surviving
named supports. Its true join accepts iff $P_p\cap R_p\ne\varnothing$;
the reused quotient accepts iff
$h(P_p)\cap h(R_p)\ne\varnothing$.

\begin{theorem}[Universal shared-pin compatibility, exact restricted]
For all finite $P,R\subseteq\{0,1\}^k$ and all fixed $h$, the following
are equivalent:
\[
 \begin{split}
 &\forall\text{ consistent shared partial pins }p,\quad
 [P_p\cap R_p\ne\varnothing]
 \Longleftrightarrow
 [h(P_p)\cap h(R_p)\ne\varnothing];\tag{A}\\
 &\forall u\in P\ \forall v\in R,\quad
 h(u)=h(v)\Longrightarrow
 (P\cap R\cap C(u,v)\ne\varnothing).\tag{B}
 \end{split}
\]
This is an exact \emph{semantic} certificate. It is not a polynomial
algorithm for producing the supports or for deciding ordinary SAT.
\end{theorem}
\begin{proof}
Assume (A), fix $u\in P,v\in R$ with $h(u)=h(v)$, and pin
\emph{all} their equal coordinates $E(u,v)$ to the common values.
Both $u$ and $v$ survive, so the quotient accepts. Exactness in
(A) forces a jointly feasible $w\in P\cap R$ that survives these
pins; by definition $w\in C(u,v)$. This gives (B).
Conversely assume (B). An accepting true join always gives an
accepting quotient. If a pinned quotient accepts, take
$u\in P_p$, $v\in R_p$ of the same $h$ label. Their coordinates
agree on every pinned name, so the cylinder $C(u,v)$ lies within
the pinned cylinder. By (B), some $w\in P\cap R\cap C(u,v)$
survives the pins, and the true join accepts. This proves (A)
for both SAT and UNSAT labels.
\end{proof}

\begin{corollary}[Precise two-level eligibility gate]
If (B) holds for the original source-named pair and one \emph{fixed}
$h$, the quotient remains correct after every one-step, two-step,
or longer chain of \emph{consistent shared source-variable pins}
that keeps the same underlying two modules. An adaptive replacement
of either module, a new suffix context, change of source-name map
or existential deletion of a shared name is \emph{not} licensed by
this result; it needs an independently verified new compatibility
certificate.
\end{corollary}
\begin{proof}
Every such descendant chain realizes a single consistent partial
pin pattern. Apply (A); its quantifier includes every pattern.
\end{proof}

This is a direct refinement of the already documented
\texttt{ARC-CONTEXT-CONFLICT119} graph-coloring characterization:
its graph on the \emph{entire closed family of shared-pin pairs}
would encode exactly the same obstruction. The new contribution

It is different from the \texttt{HEREDITARY-KERNEL118}

\section{Two physically generated ordinary-3CNF levels}
Let the original boundary names be $(x,y,z)=(1,2,3)$, interpreted
in this order from most significant to least significant bits.
Choose
\[
 P=\{000,011,111\},\qquad
 R=\{001,011,111\},\qquad h(xyz)=(x,y).
\]
Each support is realized by an ordinary \emph{proper ternary CNF}
with exactly five clauses, namely one signed three-literal
clause falsified by each of the five omitted assignments.
These two modules share \emph{exactly} the original names $1,2,3$.
Private pin auxiliaries are separately allocated to the two sides.
The correct proper-ternary pin gadget is
\[
 \mathrm{PIN}(\ell;a,b)=
 \bigwedge_{\epsilon,\zeta\in\{-1,1\}}
 (\ell\vee\epsilon a\vee\zeta b),
\]
where $a,b$ are fresh and different from every original name.
Its existential projection enforces $\ell$.

At level one both sides append $\mathrm{PIN}(\neg x)$ using
fresh private pairs $(4,5)$ and $(6,7)$.
At level two both append $\mathrm{PIN}(\neg y)$ using
distinct fresh private pairs $(8,9)$ and $(10,11)$.
All source names remain correctly identified; the pair modules
are physically serialized and reparsed at each actual level.
The exact support and label trajectory is
\[
\begin{array}{c|c|c|c|c}
 \text{Level}&P_j&R_j&\text{true SAT}&h\text{-join SAT}\\\hline
 0&\{000,011,111\}&\{001,011,111\}&1&1\\
 1&\{000,011\}&\{001,011\}&1&1\\
 2&\{000\}&\{001\}&0&1
\end{array}
\]
Thus the quotient is correct at both earlier levels and becomes
\emph{UNSAT-to-false-SAT} on the actual grandchild, even though
both pieces remain satisfiable and \emph{both sides receive the same
consistent pins}. The dangerous pair $u=000,v=001$ has
$E(u,v)=\{x,y\}$ and no common witness in its agreeing cylinder;
condition (B) correctly rejects the quotient from the start.
Renaming only the source $z$ on the second side to a fresh private
name makes the level-two conjunction SAT, illustrating the
incorrect gluing caused by forgetting a common source identifier.

The auditable self-delimiting encoding uses
$h_0=\lceil\log_2(\max\{n,m\}+1)\rceil$-bit variable and clause
counts, a unary prefix for $h_0$, one sign bit plus $h_0$ index
bits per literal and three literals per clause:
\[
 N=3h_0+1+3m(h_0+1).
\]
The materialized parent lengths are respectively
$163\to340\to484$ bits; each module has lengths
$70\to148\to208$ bits. The toy tree \emph{expands}; its
descendant exponent cannot be represented as a validated
$\lambda<1$. Appending a growing number of source-valid,
independent satisfiable clauses makes both parent and these
fixed-pin descendants $\Theta(N)$ in ordinary encoded length,
so this raw architecture remains $\lambda=1$ asymptotically.
This is not a bound against arbitrary $A$-assisted re-encoding.

\section{Why the ARC arrow is still OPEN}
The pair criterion quantifies over extensional support sets that
need not be available cheaply. A direct $A$-assisted test of
membership $b\in P$ by $A(D\wedge\mathrm{PIN}(b))$
issues ordinary parent-scale instances with length
$N^{1+o(1)}$; testing all words or dangerous pairs can cost
exponential multiplicity and requires named-witness preservation.
Any $N^b$ tests on ordinary $N^\rho$ children cost a
charged guest term $N^{b+\rho t+o(1)}$ for the one fixed $A$.
An original-scale solver-assisted lookahead has $\rho=1$
and certifies no favorable power shrink.

For a \emph{separately established} all-input procedure
making $N^{a+o(1)}$ calls to eligible ordinary children
of length $N^{\lambda+o(1)}$, the conditional eager ledger is
\[
 t'\le\max\{r,a+\lambda+g,a+\lambda t\},\qquad
 s'\le\max\{\lambda,\lambda s,\eta,\kappa\},
\]
and the fully lazy repeated-probe ledger is
\[
 t'\le\max\{r,a+\lambda t+g\},\qquad
 s'\le\max\{\lambda s,\eta,\kappa\}.
\]
Only a verified implementation can assign these parameters.
The physical charge must include input/workspace bit reads,
changed and unchanged writes, index/control operations,
adaptive policy switching and failure, cache/replay,
source rereads, source-name tables, child headers and bodies,
eager materialization or \emph{every} virtual read,
reconstruction, guest calls, and simultaneous parent/child/
ancestor workspace. Temporal flips, circuit hardware and
cumulative bit-time remain separate metrics.
A one-pass Horn/SCC/affine/graph-factor/DP or source-aware
direct solver is allowed; the quotient obstruction is
\emph{not} an unrestricted decider time/space lower bound.
No parent-scale fallback is hidden under a claimed favorable
same-machine bound. If the source is not in a promised class,
