\section{All-YES source-exact reduction}
Let $F=\bigwedge_{j=1}^m(\ell_{j1}\vee\ell_{j2}\vee\ell_{j3})$ be a proper-3CNF over $n$ original source variables. Introduce three fresh selector variables $y_{j1},y_{j2},y_{j3}$ per source clause. Define
\[
A_F=\bigwedge_{j=1}^m (y_{j1}\oplus y_{j2}\oplus y_{j3}=1),
\quad
B_F=\bigwedge_{j=1}^m
\left[\bigwedge_{a<b}(\neg y_{ja}\vee\neg y_{jb})
\wedge\bigwedge_{a=1}^3(\neg y_{ja}\vee\ell_{ja})\right].
\]
There are $m$ three-variable affine equations, $6m$ binary clauses, and $n+3m$ variables. Both descriptions retain the \emph{same original literal names}.
\begin{theorem}[All-YES compatibility: PROVED/EXACT]
For every $F$, both $A_F$ and $B_F$ are individually SAT, but
$F\in\mathrm{SAT}$ if and only if $A_F\wedge B_F\in\mathrm{SAT}$.
For each source assignment $\sigma$, let $t_j(\sigma)$ be the number of true literals in clause $j$. The exact number of selector extensions is
\[
E_F(\sigma)=\prod_{j=1}^m t_j(\sigma).
\]
The affine-plus-2CNF joint satisfiability language is NP-complete even on the promise that both components are separately satisfiable.
\end{theorem}
\begin{proof}
The affine system is satisfied by setting $(y_{j1},y_{j2},y_{j3})=(1,0,0)$ for all $j$. The binary system is satisfied by all $y=0$ and arbitrary source variables. In the intersection, odd parity allows one or three true selectors; the three negative pairwise clauses forbid more than one. Exactly one selected indicator therefore forces a true literal of the corresponding original clause. Conversely a satisfied clause permits choosing any one of its $t_j(\sigma)$ true literals. Choices across clauses are independent, proving exact equivalence and the count. NP membership and the linear-size reduction from 3SAT give NP-completeness.
\end{proof}
\begin{lemma}[Root-label-only aggregation is insufficient: PROVED/EXACT]
No fixed Boolean function of the two exact answers
$(\mathrm{SAT}(A_F),\mathrm{SAT}(B_F))$ correctly decides every $F$.
\end{lemma}
\begin{proof}
The answer vector is identically $(1,1)$ for both SAT and UNSAT source formulas. The source labels nevertheless differ. This excludes a detached two-root-bit aggregator, not an algorithm allowed to read the full source.
\end{proof}

\section{Ordinary proper-3CNF and exact resource ledger}
Encode each affine XOR3 equation by the four proper ternaries
\[
(y_1\vee y_2\vee y_3),\
(y_1\vee\neg y_2\vee\neg y_3),\
(\neg y_1\vee y_2\vee\neg y_3),\
(\neg y_1\vee\neg y_2\vee y_3).
\]
Convert each binary clause $(a\vee b)$ into
$(a\vee b\vee z)\wedge(a\vee b\vee\neg z)$ with a new variable $z$.
The fully converted ordinary proper-3CNF has exactly
\[
n'=n+9m,\qquad m'=16m,\qquad
\#\mathrm{SAT}(R(F))=
2^{6m}\sum_{\sigma\in\{0,1\}^n}\prod_j t_j(\sigma).
\]
On a fixed-word encoding with $w=1+\lceil\log_2(\max(n,m)+1)\rceil$ bits per signed literal, the source has $N=(2+3m)w$ bits. With $w'=1+\lceil\log_2(\max(n+9m,16m)+1)\rceil$, the target has $N'=(2+48m)w'$ bits. Source-to-target construction uses a single sequential source pass, $O(n+m)$ word writes and operations, and $O(1)$ additional live words on a streaming read/write model with both header counts supplied. Explicit source/target materialization takes $O(n+m)$ live words. Witness reconstruction and signed-clause verification cost $O(n+m)$ further word work. All six padding variables per original clause, signs, source reads, target writes, buffers and parsing are charged. The compiler makes no SAT calls, failed calls, or recursive invocations. The audit solver's DPLL failures and memory are separate measured verification resources, not a FLMV workspace claim. In mixed 2CNF-plus-ternary form, the genuine added ternary count is $k=4m$; after binary padding there are $16m$ proper ternaries total. No eliminated-variable $d$ or residual-work lower bound is asserted.
