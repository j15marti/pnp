\section{Exact same-source theorem and proof}
For arbitrary CNF blocks whose private variables are pairwise disjoint and whose only shared variable is $x$, let
\[
F(x,Y_1,\ldots,Y_k)=\bigwedge_{j=1}^{k}B_j(x,Y_j),\qquad
M_j(b)=[\exists Y_j\ B_j(b,Y_j)].
\]
\begin{lemma}[Bidirectional one-bit separator, known]
For every such \emph{verified} partition, with no guessed or omitted shared source variable,
\[
\operatorname{SAT}(F)\iff\bigvee_{b\in\{0,1\}}\bigwedge_{j=1}^{k}M_j(b).
\]
If $M_j(b)=0$, then $F\models(x\ne b)$, provided the certificate for $B_j\land(x=b)$ is authenticated from original source clauses. If one $b$ passes all modules, their private witnesses glue into a full original-source witness. If both $b$ values are rejected, the two certified blocked cubes are a complete UNSAT argument.
\end{lemma}
\begin{proof} Restriction of any global model supplies a common $x=b$ and all local witnesses. Conversely, the private domains are disjoint, so witnesses agreeing on $x$ merge without conflicts. If a module has no extension at a given $b$, no global model can have that $b$. This covers both labels and requires no semantic oracle.\end{proof}

For explicit authentication, write $\operatorname{XOR}_p(u,v,w)$ for the \emph{four} proper signed three-literal clauses excluding precisely the four assignments with $u\oplus v\oplus w\ne p$. Write $\operatorname{PIN}_r(c;s,t)$ for the four proper three-literal clauses $(\ell\vee\pm s\vee\pm t)$, where $\ell=c$ if $r=1$ and $\ell=\neg c$ if $r=0$. Every PIN forces $c=r$ by standard resolution and conversely is satisfied by any assignment with $c=r$.

For integer $k\ge2$, source variable $x$, and pairwise private variables $a_j,b_j,c_j,s_j,t_j,d_{jh},e_{jh}$, define $k$ ordered blocks
\[
 B_j=\operatorname{XOR}_{p_j}(x,a_j,b_j)\wedge
      \operatorname{XOR}_{q_j}(a_j,b_j,c_j)\wedge
      \operatorname{PIN}_{r_j}(c_j;s_j,t_j)\wedge
      \bigwedge_{h=1}^{k}\operatorname{XOR}_{\eta_{jh}}(x,d_{jh},e_{jh}).
\]
All original clauses have width three and distinct variables, and the blocks intersect only in $x$. The canonical grammar fixes the order of the four-clause groups, places each block's private variable IDs in consecutive source ranges, and assigns $x=1+k(5+2k)$ (the last variable). The parser verifies \emph{all} original signed clauses, equations, pins, block boundaries and headers before accepting the structure. Metadata merely proposes a candidate; it is not accepted as an oracle.

\begin{theorem}[Canonical star projection and charged short ordinary children]
For every authenticated block, its exact feasible boundary relation is the singleton
\[
\{b:M_j(b)=1\}=\{\tau_j\},\qquad \tau_j=p_j\oplus q_j\oplus r_j.
\]
Therefore the complete canonical source is SAT iff all $\tau_j$ agree. An SAT instance has an explicit full original-source witness. If any two $\tau_j$ disagree, the authenticated equation rows and PIN proofs derive opposite units on $x$, giving a complete UNSAT certificate. A fully cofactored, densely reindexed $B_j\mid_{x=b}$ is an actual ordinary CNF, SAT iff $b=\tau_j$; it is not a mere semantic pointer to the parent.

The source contains $n=1+k(5+2k)$ variables and $m=k(12+4k)$ proper 3CNF clauses. With standard indexed numeric literal serialization its length is $N=\Theta(k^2\log k)$. Each physical ordinary child has $10+2k$ clauses and length $M=\Theta(k\log k)=N^{1/2+o(1)}$, and at most $2k=N^{1/2+o(1)}$ sequential guest decisions suffice. In a \emph{separately declared} random-access bit-buffer model where a guest may read the child buffer with constant or polylogarithmic overhead, source recognition, boundary selection, emission and verification cost $N^{1+o(1)}$ local time and $N^{1/2+o(1)}$ peak buffer bits; for fixed guest exponents $(K,L)$ the conditional whole-broker envelope is
\[
 T= N^{\max(1,(K+1)/2)+o(1)},\qquad
 S= N^{\max(1,L)/2+o(1)}.
\]
No transfer of this bit-buffer envelope to the precise FLMV random-access-input TM, no all-input result, and no hereditary stability is claimed.
\end{theorem}
\begin{proof}
XOR of the two authenticated parity rows eliminates $a_j,b_j$, yielding $x\oplus c_j=p_j\oplus q_j$. PIN forces $c_j=r_j$, so $x=\tau_j$. Conversely for $x=\tau_j$, choose $a_j=0$, $b_j=x\oplus p_j$, $c_j=r_j$, $s_j=t_j=0$, $d_{jh}=0$ and $e_{jh}=x\oplus\eta_{jh}$. These values satisfy every original source clause. Thus both directions and every cofactor label hold. The algebraic UNSAT certificate consists of original indexed four-clause XOR/PIN groups and two conflicting derived units; an independent checker exhaustively authenticates each truth-table group. Assigning $x$ removes or reduces its clauses. Each of the $(k+1)$ four-clause XOR groups involving $x$ leaves two width-two clauses; the one XOR group not involving $x$ and the PIN leave eight width-three clauses, hence $2(k+1)+8=10+2k$ ordinary child clauses. A child retains $5+2k$ private variables. Physical bit lengths and sequential volume follow by counting variable identifier widths. Canonical syntax is recognized by an ordered scan with a logarithmic counter and constant-size current group; a rejected source is passed to a separately charged complete fallback, which preserves logical correctness but not the displayed resource upper bound. At most one physical child is retained during a guest call in the declared buffer model. The $K,L$ bounds follow by summing at most $2k$ guest calls of length $M$ and retaining the maximum guest workspace, the current $M$-bit buffer and logarithmic control state. \end{proof}
