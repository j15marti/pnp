\section{Source-named signed-$(2,2)$ equality compilation}
The original $W_1$ is the explicitly sourced 15-variable 20-clause, distinct proper signed exact-$(2,2)$, minimally UNSAT three-CNF of BACKDOOR-SCC-CERT130; its full 20 source clauses are reproduced literally in the executable. Choose zero-based positions
\[
 A=((6,0),(11,0)),\qquad B=((9,2),(17,2)),
\]
which respectively carry opposite signs of original names $4$ and $15$. Define $H(a,b)$ by reversing both $A$ signs if $a=0$ and both $B$ signs if $b=0$. The finite exhaustive 15-bit truth table, fully reproducible from the original clauses, has model counts
\[
\bigl(\#H(0,0),\#H(0,1),\#H(1,0),\#H(1,1)\bigr)=(772,272,272,0).
\tag{1}
\]
Each $H(a,b)$ retains exactly two occurrences of either polarity of every original name and exactly the same clause supports. For two bit vectors $a,b\in\{0,1\}^m$ construct two fully variable-disjoint shifted $H$ modules per index,
\[
 D_m(a,b)=\bigwedge_{i=1}^{m}\bigl(H_i^U(a_i,1-b_i)\wedge H_i^V(1-a_i,b_i)\bigr).
\tag{2}
\]
By (1), $H_i^U$ is UNSAT iff $(a_i,b_i)=(1,0)$ and $H_i^V$ is UNSAT iff $(a_i,b_i)=(0,1)$. Therefore
\[
 \boxed{\SAT(D_m(a,b))\iff a=b.}\tag{3}
\]
The original source has exactly $30m$ names, $40m$ physically distinct proper ternary clauses and $120m$ literal occurrences; every name occurs twice positively and twice negatively. We order the four $A$-controlled rows per $i$ first, all 32 fixed rows per $i$ next, then the four $B$-controlled rows per $i$. The exact independent $H$-module aliases persist in all sections.

For the physical-head results we declare a fixed-width ordinary signed three-CNF \emph{binary clause-list encoding}, with header \texttt{p b3 n c w}, followed by one record per clause comprising three pairs of a one-character sign and an exactly $w=\lfloor\log_2 n\rfloor+1$-character binary original variable identifier plus newline. All printed sign fields and clause boundaries have fixed positions for fixed $m$, regardless of $a,b$. Thus $N_m=\Theta(m\log(m+2))$ input characters (and the same asymptotic bit count), and the unchanged central gap occupies exactly $32m(3(w+1)+1)=\Theta(N_m)$ characters. The separate executable also produces and reparses proper ordinary ASCII DIMACS sources and descendants, but \emph{variable-length DIMACS is not silently substituted into this fixed-cut crossing proof}. The declared binary grammar is uniform and translates to ordinary DIMACS in $N_m^{1+o(1)}$ bit time. This normalization by itself does not transport lower bounds between arbitrary input formats.

\section{A deterministic, authenticated $q$-sparse UNSAT locator}
Define the difference support $\Delta(a,b)=\{i:a_i\ne b_i\}$, $k=|\Delta|$, and signs $e_i=a_i-b_i\in\{-1,+1\}$ for $i\in\Delta$. For a fixed positive integer $q$, collect exactly $2q$ integer moments
\[
 M_r=\sum_{i=1}^m(a_i-b_i)i^r=\sum_{i\in\Delta}e_i i^r,
 \qquad 0\le r<2q.\tag{4}
\]
The fixed-width template allows the first source block to contribute $a_i i^r$ and the last to contribute $-b_i i^r$ in monotonically increasing source-address order. The 32$m$ intervening rows are independently checked as literal source records, not ignored as an unverified promise. Each moment has $O(q\log(m+2))$ bits. Arithmetic, grammar, source indexing and control are all charged.
\begin{theorem}[One-pass sparse-difference source locator]\label{th:locator}
For every \emph{fixed} $q\ge1$, there is one deterministic sequential-read-only-input-head, fixed-finite-work-tape program $L_q$ that scans the entire declared $D_m$ binary source, checks all variable IDs, signs, headers and source-row templates, computes (4) and, on every valid $D_m(a,b)$ with $1\le|\Delta(a,b)|\le q$, outputs the index of an actually UNSAT original $H$ module. For $\Delta=\varnothing$ on the valid promise it emits no UNSAT certificate. For any other syntactically valid source outside this promise it is permitted to return \textsf{UNKNOWN}, but never an unauthenticated UNSAT witness. A supplementary source-record recheck can authenticate the two selected shore signs before accepting on arbitrary syntactically well-formed inputs, without an unverified label. In the $q$-fixed promise, $T_k=N_m^{1+o(1)}$, visited work cells $S_k=O(\log N_m)$, input-head moves $H_k=N_m^{1+o(1)}$ and at most two nonzero input-head reversals with the optional recheck. Parsing and output are charged; the displayed upper bounds exclude no later work from a deterministic all-SAT discovery algorithm.
\end{theorem}
\begin{proof}
If $k\le q$, the $q\times q$ rational Hankel matrix $K=(M_{r+s})_{0\le r,s<q}$ factors as $K=V\operatorname{diag}(e_i) V^{\mathsf T}$, with $V_{ri}=i^r$ on the $k$ distinct support coordinates. The $k\times k$ leading square Vandermonde block has full column rank; the leading $k\times k$ Hankel determinant equals $(\prod_{i\in\Delta}e_i)\prod_{i<j}(j-i)^2\ne0$. Thus $\operatorname{rank}(K)=k$ even though signed moments can cancel in individual entries. The monic annihilator
\[
 P(z)=z^k+\sum_{j=0}^{k-1}c_jz^j=\prod_{i\in\Delta}(z-i)
\]
is uniquely determined by the $q$ equations $\sum_{j<k}c_jM_{r+j}=-M_{r+k}$, $0\le r<q$. Indeed the first $k$ equations form the nonsingular leading $k\times k$ Hankel system; the remaining equations check consistency. Integer root enumeration $1\le i\le m$ returns exactly $\Delta$. For every recovered mismatch, (1)--(3) identify which shifted original $H(1,1)=W_1$ module is UNSAT. Its 20 actual original source clause IDs, signs and original name-offsets are checked. For $\Delta=\varnothing$, $M_r=0$ and $K$ has rank zero. On malformed input the full parser rejects; outside the promised $k\le q$ class the locator must source-check every proposed conflict before emitting any UNSAT claim, returning \textsf{UNKNOWN} if no conflict is authenticated. This preserves soundness without asserting completeness outside the promise.
For fixed $q$, moment powers and each integer moment have $O(\log N_m)$ bits, rational Gaussian elimination has a fixed number of such arithmetic registers with polynomial-bit intermediates, and root enumeration holds one candidate index. A fixed finite number of sequential work-tape heads executes each $\operatorname{polylog}N_m$-bit arithmetic operation in polynomial-logarithmic transitions. One monotone input scan handles all ordered rows. At worst the optional recheck reverses at the far end, moves left to a named earlier source record and then resumes right, costing $O(N_m)$ additional head moves and two direction changes. Every return or emitted record is clocked.
\end{proof}

Each claimed binary edge and clause address is checked against the source bytes, not accepted by status. Full proof output, even if it has a large fixed absolute constant, occupies $O(\log N_m)$ bits for fixed $q$ and W1.\end{proof}

\section{A precise coverage counterexample from Prouhet cancellation}
\begin{theorem}[No all-UNSAT coverage from a fixed moment synopsis]\label{th:collision}
For every fixed $q\ge1$ there are SAT and UNSAT valid source pairs $D_m(a,a)$ and $D_m(a,b)$ of the \emph{same physical length and layout} for which all first $2q$ moment registers (4) are identical zero. Hence no terminal rule depending only on these registers and fixed public length/format metadata can soundly and completely decide equality on all $D_m$. This remains true on infinitely many lengths by appending equal coordinates.
\end{theorem}
\begin{proof}
Set $m=2^{2q}$ and use $i=1,\ldots,m$ with $a_i=1$ if $\operatorname{popcount}(i-1)$ is even and $a_i=0$ otherwise; let $b_i=1-a_i$. Then $a_i-b_i=(-1)^{\operatorname{popcount}(i-1)}$ and $a_i\ne b_i$ for every $i$. The identity
\[
 \sum_{i=1}^{2^{2q}}(-1)^{\operatorname{popcount}(i-1)}e^{(i-1)x}
 =\prod_{j=0}^{2q-1}(1-e^{2^jx})
\tag{5}
\]
has a zero of order $2q$ at $x=0$. Therefore the power sums of $(i-1)^r$ vanish for every $0\le r<2q$. Translating the argument from $i-1$ to $i$ preserves vanishing in those degrees by the binomial theorem, so every moment $M_r=0$, as on $D_m(a,a)$. But (3) makes $D_m(a,b)$ UNSAT and $D_m(a,a)$ SAT. A synopsis-only receiver given equal data must return equal answers, contradiction. Padding preserves all moments and gives infinitely many counterexamples. Any additional source rereading/adaptive verification is an extra, charged resource, and this theorem does not prohibit it.
\end{proof}
