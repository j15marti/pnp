\section{Source-identity, complete branching, and SCC terminal grammar}
Let $F=\bigwedge_{i=1}^m C_i$ be an ordinary proper 3CNF with original source clause IDs $i$, original variable names and complete encoded bit length $N$. The certificate header is a list $B$ of variable identifiers meeting each three-literal clause. The verifier authenticates this property by inspecting the original clauses, then enumerates both values of every variable in $B$. For $\sigma\in\{0,1\}^B$, delete clauses made TRUE and false assigned literals in the remainder, retaining original clause IDs in sidecar provenance; the resulting $F|_\sigma$ is an ordinary CNF with clauses of width at most two and complete regenerated headers. The verifier rejects missing children, incompatible aliases, malformed encodings, repeated branches and timeouts.

Every remaining unit clause $a$ gives the implication edge $\neg a\to a$; each binary clause $(a\vee b)$ gives $\neg a\to b$ and $\neg b\to a$. Each edge is annotated with its original source ID and actual residual literals. A terminal is accepted iff an authenticated empty clause exists or a variable $x$ has authenticated directed paths $x\leadsto\neg x$ and $\neg x\leadsto x$. The paths may be supplied explicitly and checked edge by edge or discovered by a deterministic SCC routine. No guessed UNSAT status bit, semantic source lift, or unverified oracle output is accepted.
\begin{theorem}[Exact soundness, completeness, and resource cost]
For every ordinary proper 3CNF $F$ and every valid clause-hitting $B$,
\[
V(F,B)=1\iff F\in\mathrm{UNSAT}.
\]
Consequently every certificate on a SAT source rejects, while every UNSAT source admits at least one accepting certificate: taking $B=\operatorname{Var}(F)$ suffices. If $k=|B|$, a straightforward streaming verifier has
\[
T_V(N,k)\le 2^kN^{1+o(1)},\qquad
S_{V,\mathrm{peak}}(N,k)\le N^{1+o(1)}
\]
in a charged indexed read-only-input bit model. The certificate header costs $O(k\log N)$ bits; optional complete explicit cycle paths have length $O(2^kN\operatorname{polylog}N)$ bits. Small header size is not small verification time.
\end{theorem}
\begin{proof}
Since $B$ meets every ternary clause, each residual is a 2CNF, possibly with an empty clause. The implication-graph SCC criterion gives exactly the stated UNSAT terminals, and source-checked edge labels prevent unsound substitutions. The source formula is satisfiable iff some residual is satisfiable:
\[
\operatorname{SAT}(F)\Longleftrightarrow
\bigvee_{\sigma\in\{0,1\}^B}\operatorname{SAT}(F|_\sigma).
\]
This proves both quantifiers. Parsing the complete original formula, building each ordinary residual and computing/checking SCC and paths costs $N^{1+o(1)}$ bit operations per branch, including input/workspace reads, indexing, control, child headers and bodies, source ID lookup, changed and unchanged writes. One reusable $N^{1+o(1)}$-bit workspace includes source identifiers, graph edges, buffers and ancestor metadata; prior branch graphs are released. Fixed per-branch clocks reject invalid or unfinished proofs. The verifier cannot obtain free labels from guest $A$.
\end{proof}
\section{Sharp incidence obstruction and signed exact-$(2,2)$ witness}
If every name occurs exactly twice positively and twice negatively in distinct proper ternary clauses, then $3m=4n$. A name meets at most four distinct clauses, so any hitting set must satisfy
\[
|B|\ge m/4=n/3.
\]
This is an architectural floor for the \emph{explicit complete syntactic backdoor tree}, not a SAT decision lower bound. The original minimally UNSAT fifteen-variable, twenty-clause $W_1$ of PCRETRACT1 has the \emph{unique} minimum hitting set
\[
B=\{2,4,7,14,15\}.
\]
Every selected name covers exactly four clauses and the selected clause-incidence stars partition the twenty original clauses. The exhaustive 5-combination check found only this one five-set. There are exactly $2^5=32$ actual signed-source branch residuals, all UNSAT; each admitted independently checked original-ID implication paths. Root DIMACS size is 226 bytes, a genuine first descendant restricting $(x_2,x_4)=(0,0)$ has 173 bytes, and its second ordinary descendant restricting $(x_7,x_{14},x_{15})=(0,0,0)$ has 93 bytes. The children need not preserve the original signed-$(2,2)$ occurrence promise.

CUBICCOVER75 had already proved a stronger polynomially discoverable \emph{upper} bound for the matching-cover construction: $|B|\le\lfloor5\delta/8\rfloor$, where $\delta$ is the number of unmatched ternaries after valid complementary-pair contraction. BACKDOOR-PRODUCT-FIREWALL97 had already established the hitting-set characterization; these are adopted \emph{without novelty claims}. The present checked-certificate instantiation gives
\[
T_V(F)\le 2^{\lfloor5\delta(F)/8\rfloor}N^{1+o(1)}.
\]
For the restricted promise $\delta(F)\le\alpha\log_2N$, this is $N^{1+5\alpha/8+o(1)}$ time with $N^{1+o(1)}$ peak space. It is not a general near-boundary SAT algorithm, and its peak space is not $N^{o(1)}$.
\section{A definite counterexample to compulsory backdoor enumeration}
Let $F_q$ be the conjunction of $q$ variable-disjoint copies of the same proper signed exact-$(2,2)$ minimally UNSAT $W_1$. Clause hitting sets decompose over components, hence $\tau(F_q)=5q$. The fully explicit fixed-backdoor architecture uses $2^{5q}$ assignment leaves. However one source-identified twenty-clause $W_1$ copy already implies UNSAT of the whole conjunction. A single completed call to the \emph{same fixed exact ordinary SAT decider} $A$ on this selected ordinary subformula, plus source-ID containment checking, certifies the root UNSAT with one guest of $O(\log N)$ encoded bits when global identifiers use $O(\log N)$ bits. The root scan and indexing are charged separately. Thus an exponential compulsory cost for \emph{arbitrary adaptive certificates} does not follow from the syntactic backdoor minimum, even on UNSAT exact-$(2,2)$ sources.
