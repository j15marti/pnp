\section*{Established starting bound and exact model}
For \(h\ge1\), let \(P_h\) be the standard unary pigeonhole CNF with \(h+1\) pigeons, \(h\) holes and variables \(x_{ij}\), positive clauses \(\bigvee_{j=1}^h x_{ij}\), and binary collision clauses \(\neg x_{ij}\vee\neg x_{kj}\) for \(i<k\). It has \(h(h+1)\) variables, \(m=(h+1)+h\binom{h+1}{2}\) source clauses, and \(\Theta(h^3\log(h+2))\) encoded bits in decimal-indexed signed DIMACS. It is UNSAT. Haken (1985) establishes constants \(c>0,h_0\) such that \emph{for every} \(h\ge h_0\), \emph{every ordinary unrestricted shared-DAG Resolution refutation} of \(P_h\) requires at least \(2^{ch}\) lines. Subtracting \(O(h^3)\) original clauses leaves \(2^{\Omega(h)}\) paid derived nodes. The lower bound does NOT concern Extended Resolution, \(R_{\mathrm{mix341}}\), Res(\(\oplus\)) or arbitrary uniform SAT algorithms. Cook (1976) gives polynomial Extended Resolution PHP proofs.

Fix \(R_{\mathrm{res}}\) with original signed clauses free, one paid node per ordinary binary resolvent, and arbitrary shared-DAG proofs. A source empty clause gives a zero-paid-node refutation. Let \(W_{\mathrm{res}}(F)\) be the minimum number of paid nodes, attained by completeness and integer costs.

\section*{Theorem: polynomial-time invertible semantic collapse}
\begin{theorem}
There exist two fixed, uniform deterministic polynomial-bit-time programs \(E,D\), independent of instance size, such that for every raw finite byte string \(s\): \(E(s)\) is valid explicit signed DIMACS, \(D(E(s))=s\), and \(|E(s)|=O((|s|+1)\log(|s|+2))\). For every \emph{valid} original CNF \(F\), the projection of the models of \(E(F)\) onto the renamed even-index original variables is exactly the model set of \(F\). Nevertheless, for all sufficiently large \(h\),
\[
W_{\mathrm{res}}(P_h)\ge2^{c'h},\qquad W_{\mathrm{res}}(E(P_h))=0 .
\]
The polynomial-time recoder \(E\) is NOT a legal \(R_{\mathrm{mix341}}\) inference or a checked Resolution proof translation.
\end{theorem}
\begin{proof}
Choose a canonical signed DIMACS byte serialization of the standard PHP clauses with IDs \(x_{ij}=(i-1)h+j\), positive rows first and negative collision clauses in lexicographic order. A uniform parser recognizes these strings in polynomial time by recovering a possible \(h\) from the quadratic header variable count and comparing the exact reconstructed byte sequence. Every recognized string is UNSAT by the elementary pigeonhole argument. Recognition uses neither a SAT oracle nor per-size advice.

Let \(N=8|s|\) be the number of raw input bits. For each \(0\le i<N\) and duplicate index \(r\in\{0,1\}\), set \(j=2i+r\), \(z_j=4j+1\) and \(a_j=4j+3\); insert the \emph{tautological genuine signed CNF clause}
\[
z_j\vee\neg z_j\vee \ell_{i,r},\qquad
\ell_{i,r}=\begin{cases}a_j,&\text{bit }i=1,\\\neg a_j,&\text{bit }i=0.\end{cases}
\]
The two copies encode each raw bit redundantly. All tag IDs are odd. If \(s\) parses as a valid CNF and is not a recognized canonical PHP, emit all its original clauses under \(x_i\mapsto y_{2i}\), followed by all tags. If \(s\) is recognized canonical PHP, emit a single \emph{empty source clause} followed by the tags. If \(s\) is malformed, emit tags only. Correct DIMACS headers, variable bounds and clause counts are generated in all cases.

To decode, find the uniquely indexed \(z_j,\neg z_j,\pm a_j\) tags, read the sign of \(a_j\), check duplicated pairs agree, and reconstruct the original bytes in 8-bit groups. The original non-tag clauses use only even variable IDs, so cannot be confused with the odd-index tags. This yields \(D(E(s))=s\) even for malformed raw bytes. Each tag is a tautology; for a valid non-PHP source, its model projection remains the original formula on even variables. For the recognized PHP sources, both old and new formulas have empty model sets, so projection equivalence holds as well.

There are \(2N\) constant-width tags whose maximum indices are \(O(N)\); their explicit serialization uses \(O((N+1)\log(N+2))\) bits. Doubling the original variable indices increases decimal width by at most one. The uniform encoder, recognizer and inverse use polynomial bit time and workspace. A recognized PHP output contains an input empty clause, hence \(W_{\mathrm{res}}(E(P_h))=0\), while Haken lower-bounds the ordinary Resolution cost of the untransformed original \(P_h\).
\end{proof}

\begin{lemma}[Representation-invariance firewall]
For any \(I\ge0\) on CNFs and fixed polynomial \(p\), if \(I(F)=I(E(F))\) for every valid \(F\) and \(I(F)\le p(W_{\mathrm{res}}(F))\), then \(I(P_h)\le p(0)\) for all \(h\).
\end{lemma}
\begin{proof} Substitute \(E(P_h)\), whose source empty clause yields \(W_{\mathrm{res}}=0\).\end{proof}
