\section{Exact restricted theorem: implicit one-variable separators}
Fix a standard, length-decodable indexed read-only encoding of proper CNFs of width at most three, where each variable index and clause is accessible by a logarithmic-space scan and the complete instance has length $N$. The active variable domain has size $n\le N$. Let $G(F)$ denote the \emph{undirected primal graph}: $u\ne v$ are adjacent if both occur in an original clause. For a candidate pivot $x$, let $V_1,\ldots,V_r$ be the components of $G(F)-x$. A clause with non-$x$ variables belongs to their unique component; a clause containing only $x$ belongs to the boundary formula $B_x$. For $b\in\{0,1\}$, $F_{i,b}$ contains the clauses from component $i$, simplified by setting $x=b$, with satisfied clauses discarded and falsified $x$ literals deleted. No new Boolean variable is assigned to an occurrence.

\begin{theorem}[Uniform logspace acquisition and bit emission, restricted]\label{thm:L}
For every such original CNF $F$, a single deterministic uniform machine uses $O(\log N)$ auxiliary writable bits and polynomial time in $N$ to (i) decide whether a candidate $x$ disconnects the primal graph and list the component representatives, (ii) search all candidates $x$ and select one minimizing the maximum \emph{physically encoded} $|F_{i,b}|$ over both $b$ and all components, and (iii) on input $x,b,i,q$, return the $q$-th physical encoding bit of $F_{i,b}$, or reject out-of-range requests. The uniform machine may also reject all candidates whose physical child sizes exceed any fixed rational-power bound such as $M^2\le N$. Its asymptotic exponent for local time is not asserted to meet ARC.
\end{theorem}
\begin{proof}
The predicate $E_F(u,v)$ is computable using logarithmic work space: sequentially scan the source for an original clause containing both $u,v$ and compare indices using $O(\log N)$ counters. To compute connectivity in $G(F)-x$, provide a virtual graph of $n$ vertices with the $x$ vertex isolated and use the undirected $s$-$t$-connectivity algorithm of Reingold~\cite{reingold}. Its virtual adjacency input is supplied on demand by $E_F$; deterministic-logspace procedures are closed under logarithmic-space composition. Each predicate is thus in $\mathbf L$, with at most polynomial time because all constituent machines run in polynomial time.

A vertex $r\ne x$ is a canonical representative of a component precisely when no smaller vertex $u<r$, $u\ne x$, is connected to $r$ in $G(F)-x$. Enumeration of all vertices in increasing order with repeated connectivity tests requires $O(\log N)$ counters. Whether $x$ is a genuine articulation follows by comparing component counts before and after deletion. For each $(x,b,r)$, a source clause is selected iff its non-$x$ variables are nonempty and the first such variable is connected to $r$ after deletion of $x$. All remaining non-$x$ variables belong to that same component since they co-occur in the original clause. Clauses made TRUE by $x=b$ are omitted; the remaining source literals are streamed in their original order. By a preliminary counting scan the child clause count and serialized length are known using logarithmic-bit counters. Any indexed output bit $q$ can be found by rescanning the source, advancing the output-bit counter without retaining the output. We can repeat the procedure over all $x,b,r$ to find the minimum maximum physical length, comparing counters; fixed rational-power thresholds can be tested by fixed-degree integer arithmetic on $O(\log N)$-bit integers. A deterministic tie-breaking rule yields one uniform policy. All counters and virtual-connectivity work are reused rather than stored for every candidate. The space is $O(\log N)$ and time polynomial.
\end{proof}

\begin{lemma}[Both-label same-source correctness]\label{lem:join}
For every source $F$ and correctly computed separator partition,
\[
\operatorname{SAT}(F)\iff\bigvee_{b\in\{0,1\}}\left[B_x(b)\land\bigwedge_{i=1}^r\operatorname{SAT}(F_{i,b})\right].
\]
If the right side is TRUE, component witnesses and $x=b$ combine into a complete original-source witness. If the right side is FALSE, for each $b$ some boundary constraint is false or some cofactor is UNSAT; the two labels may be certified independently by complete child solvers. No failed repair, unsatisfied endpoint or incompatible clause extrema alone certifies UNSAT.
\end{lemma}
\begin{proof}
Every original clause either has no variable outside $x$ or belongs to exactly one component, since its distinct non-$x$ variables are mutually adjacent. Fixing $x=b$ eliminates all cross-component dependencies. Restriction of any model of $F$ satisfies every corresponding cofactor and boundary constraint. Conversely, because the private variable sets are pairwise disjoint, union of the cofactor models together with $x=b$ satisfies every original clause. Negation of this equivalence gives the exhaustive both-$b$ UNSAT condition.\end{proof}

\section{ARC/FLMV resource gate and next experiment}
The theorem removes a particular \emph{space} objection from GATE278: for the one-vertex-source-primal-interface policy, storing an $\Omega(N)$ explicit graph is unnecessary. It does \emph{not} remove the time overhead of repeatedly evaluating Reingold USTCON over a virtual adjacency source. Neither the theorem nor the Python reference proves a per-source selector time $N^{11/10+o(1)}$.
