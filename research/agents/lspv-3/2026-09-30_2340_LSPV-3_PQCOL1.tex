\paragraph{Exact reconstruction predicate.}
Fix one acquired and exactly size-normalized deterministic $Q$, Arthur randomness $r$, requested coordinate $i$, and the constant set $J$ of SAT queries, including the density-estimation queries and the three vMS queries for success, output $0$, and output $1$. For SAT formula $\Phi_j$ and claimed answer bit $a_j$, exact oracle semantics are
\[
\operatorname{ExactSAT}(a)=
\exists Y^+\forall Y^-\!
\bigwedge_{j\in J}\left[(a_j\Rightarrow\Phi_j(Y_j^+))\wedge(\neg a_j\Rightarrow\neg\Phi_j(Y_j^-))\right].
\]
Hence fixed-randomness output $b$ has the form
\[
\exists a,Y^+\forall Y^-\;C_b(z,Q,r,i,a)\wedge\operatorname{ExactSAT}(a).
\]
Constant parallelism bundles YES witnesses and NO assignments but does not delete the universal block.

\paragraph{Primary-source collision audit.}
The 2025 van Melkebeek--Mocelin Sdroievski definition of commit-and-evaluate resilience is probabilistic over Arthur's commitment randomness. For every Merlin commitment strategy, with probability at least $1-r(n)$ the resulting commitment $\pi$ has the property that every evaluation input induces a protocol with partial single-valuedness $s(n)$. Thus the construction guarantees a high-probability set of good commitments; it does not state pointwise binding for every fixed commitment.

Corollary 4.6 strengthens resilient soundness by using parallel SAT access. After sampling Arthur randomness for the reconstructed protocol, it makes three SAT queries asking whether a successful Merlin response exists and whether successful responses output $0$ and $1$. A negative success answer or inconsistent output answers causes failure. This is direct evidence that the published reconstructor retains an explicit consistency test rather than invoking a deterministic local collision identity.

\paragraph{PROVED/EXACT source-level conclusion.}
The published vMS resilient-PSV theorem does \emph{not} by itself imply
\[
\forall r,Q,i\quad \neg(E_0(r,Q,i)\wedge E_1(r,Q,i)).
\]
Its quantifiers instead permit a bounded bad set of Arthur commitments/random strings. Therefore the existing theorem cannot be substituted as a pointwise predicate $C(r,Q,i)$ eliminating the opposite-output universal condition. This is a statement about what follows from the cited theorem, not a proof that no stronger construction-specific identity exists.

\paragraph{Collision-extraction / special-soundness transfer.}
In a Sigma protocol, special soundness is an algebraic/extraction property: from two accepting transcripts sharing the first message and carrying distinct challenges, an extractor recovers a witness for the underlying relation. This mechanism is an \textbf{ANALOGY/CANDIDATE} for vMS only if the actual commit-and-evaluate acceptance equations admit an extractor
\[
(\pi,\tau_0,\tau_1)\mapsto W
\]
such that opposite successful openings yield an explicitly forbidden $W$, and validity of $W$ is locally checkable without SAT or universal search. The current vMS resilient-PSV statement supplies no such extractor.

Collapse-binding quantum commitments are a \textbf{FAILED TRANSFER} for an unconditional P-vs-NP proof: collapse-binding is a computational cryptographic security notion and known constructions use cryptographic/random-oracle assumptions. Its conceptual lesson is useful; its hardness assumption is inadmissible here.
