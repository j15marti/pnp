\section{CONSTRUCTION OR PROOF ATTEMPT}
Let $s$ be global semantic status bits and $z_i$ private SAT variables;
$g_i(s)=1$ iff $\exists z_i\,\Phi_i(s,z_i)$.
\begin{theorem}
Every Boolean circuit map $B:\{0,1\}^k\to\{0,1\}^k$ of size $S$
has a uniform polynomial-size SAT-status encoding satisfying
$g_i(s)=B_i(s)$. The encoding has at most $O(k(S+k))$ clauses.
\end{theorem}
Proof: functionally encode each NOT, AND and OR gate with standard Tseitin
clauses and force each output bit to one. Given $s$, gate values are unique.
Consequently the trivial map $B(s)=\neg s$ gives an inconsistent cyclic status
equation without any complexity consequence. The ordinary formula
$\Phi(s)=\neg s$ is independently satisfiable as an open CNF, but
$s=\operatorname{SAT}(\Phi(s))$ has no solution.
\begin{theorem}
For syntactically unate CNFs whose signed directed status-dependency graph
has no negative directed cycle, a consistent status assignment can be found
using at most $\sum_C|C|(|C|+1)\le k(k+1)$ SAT calls.
\end{theorem}
Proof: compute signed strongly connected components. Within each component
negative-edge parity is a coboundary $b_u\oplus b_v$, since an inconsistent
directed pair of paths would yield a negative directed cycle. Complement
inputs and outputs by $b$, making each component map monotone. Iterating
from zero stabilizes within $|C|+1$ rounds; solve the condensation DAG in order.
The component SAT-query count is $\sum_C|C|(|C|+1)$.
