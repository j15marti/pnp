\section{Exact source-version-aware certificate theorem}
Let $F_v$ be a finite indexed CNF source with stable clause identifiers and exact signed literal contents. A coherent cube $\rho$ is a partial Boolean assignment. An UNSAT certificate is a complete binary DPLL decision tree whose every leaf is a conflict witnessed by original-source unit-propagation steps. Write $R(\pi)$ for the indexed source clauses actually used as unit reasons or conflicting clauses; checking $\pi$ on those clauses and $\rho$ proves $F_R\wedge\rho$ UNSAT.

\begin{theorem}[Certificate migration and untrusted-source read firewall]\label{thm:delta}
For every pair of source versions $F,F'$ and cubes $\rho,\rho'$:
\begin{enumerate}
\item[] If $a$ is a complete SAT witness for $F\wedge\rho$, then $a$ is a valid SAT witness for $F'\wedge\rho'$ precisely if $a\models F'$ and $a$ extends $\rho'$. With an authenticated edit log that supplies every added/modified clause and stable identifiers, unchanged satisfied clauses need not be rescanned; the edits and new cube must be checked and edit-log acquisition charged.
\item[] If $\pi$ is an indexed unit-propagation/DPLL refutation of $F_R\wedge\rho$, $\rho\subseteq\rho'$ and each $(\mathrm{id},\mathrm{signed\ clause})$ in $R(\pi)$ remains identical in $F'$, then $F'\wedge\rho'$ is UNSAT. Without these conditions, the old proof is not automatically transferable; a complete fallback remains sound. The conditions are sufficient, not necessary for the new formula to be UNSAT.
\item[] Fix an all-TRUE assignment $a=1^{3m}$ and $m$ disjoint proper clauses $C_i=(x_{3i-2}\vee x_{3i-1}\vee x_{3i})$. Promise that an untrusted physical current source equals $F=\bigwedge C_i$ or differs by replacing at most one clause by $(\neg x_{3i-2}\vee\neg x_{3i-1}\vee\neg x_{3i})$. Any deterministic exact validator that decides whether \emph{this particular} $a$ satisfies the current source requires at least $m$ indexed clause inspections in the unchanged-source worst case. Every source in this family is itself SAT.
\end{enumerate}
\end{theorem}
\begin{proof}
The first assertion is the definition of a checked complete model. If a trusted incremental edit sequence has been acquired, clauses untouched by it have their previously checked truth values; each new or modified clause and cube value is directly tested. For the second assertion, replay each UP reason and final conflict using only $R(\pi)$, then induct upwards through both decision branches. Thus $F_R\wedge\rho$ is inconsistent. The new source includes $F_R$, and the new cube implies $\rho$, so $F'\wedge\rho'$ is inconsistent as well.
For the third, execute the claimed validator on unchanged $F$. If it fails to inspect clause index $i$, the alternative source changing only $C_i$ produces the same complete query transcript and hence the same output, although all-TRUE now falsifies $C_i$. Both sources are satisfiable: for the altered clause choose e.g. $(1,0,0)$ on its disjoint triple, while assigning TRUE everywhere else. Thus an exact validator must inspect every $i$. This is a \emph{certificate-validation query} lower bound, not a SAT-decision lower bound.\end{proof}

\noindent The lower bound does not apply to a trusted edit address, to the task of finding a different witness, to a semantic SAT oracle, or to unrestricted SAT algorithms. Maintaining a trusted edit index requires a charged storage/update mechanism. A bare unverified hash cannot replace checking exact indexed content.
