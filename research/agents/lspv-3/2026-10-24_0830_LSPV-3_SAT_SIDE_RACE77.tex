\section{Machine, language, and force-gadget ledger}
Fix the NP-complete language of all well-formed proper exactly-three-literal CNFs, with three distinct variable identifiers in every clause and canonical fixed-width binary literal records. Let $F$ have $n$ variables, $m$ clauses, and encoded length $N=\Theta((n+m)\log(n+m+2))$. Let $A$ be any fixed total deterministic exact decider on a charged multitape Turing-machine model with read-only inputs. Two simulations of the same $A$ use separate read-only copies, work tapes, and input heads, with a fixed extra number of tapes and constant step overhead for this fixed $A$; use an explicit interpreter penalty in other machine models.
For original literal $\ell$ and two fresh variables $a,b$ define
\[
\operatorname{FORCE}(\ell;a,b)=
(\ell\vee a\vee b)\wedge(\ell\vee a\vee\neg b)
\wedge(\ell\vee\neg a\vee b)\wedge(\ell\vee\neg a\vee\neg b).
\tag{1}
\]
This is equivalent to the unit $\ell$, since with $\ell$ false the four assignments of $a,b$ each violate one clause; with $\ell$ true all clauses hold. Every clause is proper ternary. Each forced variable creates exactly two auxiliary variables and four clauses.
For any satisfying prefix $\sigma$ of $i-1$ original variables, let $G_{i,v}$ be $F$ with $i$ forcing gadgets, the last enforcing $x_i=v$. It has $n+2i$ variables, $m+4i$ clauses, and encoded length at most
\[
M=O((n+m)\log(n+m+2)).
\tag{2}
\]
Constructing both children, source reads, headers, and writing the added literal records costs $O(M)$ bit time at each stage. Let $T_A^+(M)$ be the \emph{analytical} maximum runtime of $A$ on satisfiable proper-3CNFs of length at most $M$. The solver does not compute or receive this parameter.
\section{Universal label-asymmetric witness simulation}
\begin{theorem}[PROVED/EXACT: SAT-side fair-race extraction]\label{th:race}
For each total uniform exact proper-3SAT decider $A$, a total uniform deterministic machine $W_A$ returns UNSAT on UNSAT sources and otherwise outputs and verifies one original satisfying assignment. For SAT input $F$,
\[
T_{W_A}(F)=O_A(nM+(2n+1)T_A^+(M)).
\tag{3}
\]
More precisely, at stage $i$ the race after child construction needs at most
\[
2\min_{v:G_{i,v}\in\mathrm{SAT}}T_A(G_{i,v})
\tag{4}
\]
guest steps up to a fixed constant scheduling factor. At its maximum simultaneous stage, peak space is $O(M+S_A(G_{i,0})+S_A(G_{i,1}))$, where the two $S_A$ values measure the actually reached guest states; the initial $A(F)$ phase occurs separately. The output witness has $n$ bits. The algorithm does \emph{not} construct a context-complete service or require UNSAT certificates.
\end{theorem}
\begin{proof}
First decide $F$ with $A$, returning UNSAT if needed. On a SAT input keep a prefix known to be extendible. Build $G_{i,0}$ and $G_{i,1}$, and alternate one instruction of each exact simulation until one returns SAT. At least one child is SAT because the prefix is extendible, so the race terminates. Choose the label of a SAT child only: an earlier UNSAT answer from the other child does not terminate the race. By induction the prefix remains satisfiable. After $n$ stages the chosen original assignment satisfies $F$; check it explicitly. The winning SAT child gets one instruction every two guest steps, while the other gets no more instructions than that, proving (4). The initial SAT decision and $n$ charged constructions prove (3). Source rereads, discarded losing work, full child materialization, scheduling, copies and verification are included.
\end{proof}
This is an \emph{external} Turing self-reduction. It is not a proof that $A$ performs these queries internally, that any $T_A^+(M)$ is polynomial, or that SAT necessarily emits a witness history.
\section{Label-conditioned worst-case quantifiers}
\begin{theorem}[PROVED/EXACT: timeout dualization]
If a total deterministic exact decider $A$ for the fixed NP-complete language takes polynomial time on all sufficiently long SAT inputs \emph{alone}, then $P=NP$. The same conclusion holds if it is polynomial on all sufficiently long UNSAT inputs \emph{alone}. Equivalently,
\[
P\ne NP \iff \forall A\,\forall c\in\mathbb N\,\forall N_0:
\begin{cases}
\exists F^+\in\mathrm{SAT},\ |F^+|\ge N_0,\ T_A(F^+)>|F^+|^c,\\
\exists F^-\notin\mathrm{SAT},\ |F^-|\ge N_0,\ T_A(F^-)>|F^-|^c .
\end{cases}
\tag{5}
\]
This equivalence is not a proved separation.
\end{theorem}
\begin{proof}
Suppose $A$ halts within $|F|^c$ steps on all sufficiently long SAT instances. Simulate $A$ for that many steps, use its exact output if halted, and output UNSAT on timeout. This is correct on both labels: no SAT instance can time out, and a timed-out UNSAT instance is correctly rejected. Hardwire a finite short-length lookup. Thus SAT is in P. With a polynomial cutoff for all UNSAT inputs, output SAT on timeout instead. Conversely, if $P=NP$, some decider has a polynomial runtime on both labels, contradicting the right side. Constants may depend on the fixed $A$, and the timeout exponent is built into the constructed machine. No input answer label is supplied in advance.
\end{proof}
\section{Concrete adaptive escape and computational audit}
Let $F_q$ consist of $q$ independent $\operatorname{FORCE}(x_i;a_i,b_i)$ gadgets, hence $n=3q$ and $m=4q$. All TRUE satisfies $F_q$. Let the total exact algorithm $A_*$ first test all TRUE, accepting immediately if it satisfies the source; otherwise exhaustively test assignments in a fixed order. In a sequential self-reduction that first tries to force $x_i=0$, each such child is UNSAT and has $3q+2i$ variables, so waiting for its exact answer costs $2^{3q+2i}$ enumerated assignments. The SAT child forcing $x_i=1$ passes the all-TRUE check in $O(q+i)$ operations. The fair race therefore uses polynomial work on the first $q$ steps, while sequential negative-first waiting costs
\[
\sum_{i=1}^{q}2^{3q+2i}=\Omega(2^{5q}).
\tag{6}
\]
These are upper-algorithm comparison costs for an easy recognizable family, \emph{not} SAT lower bounds.
