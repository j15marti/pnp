\begin{abstract}
P versus NP remains \OPEN.  MODELBRIDGE-0027 correctly retired bare full
trace factorization because the initial configuration already carries the
input.  DERIVEDLEAK1 then showed that merely deleting the initial input
carrier does not suffice: a semantically inert wrapper can copy source bits
through ordinary mutable trace events.  This run tests the smallest proposed
repair---retain only selected event fields that appear to describe derived
work.  For the explicit mutable-event schema
\[
 \mathcal E=\{\mathsf{kind},\mathsf{channel},\mathsf{address},
               \mathsf{value},\mathsf{state},\mathsf{output}\},
\]
every fixed coordinate-subset projection satisfies an exact trilemma.  If it
retains \(\mathsf{value}\), a same-schema COPY wrapper exposes an arbitrary
source bit.  If it drops \(\mathsf{value}\), two traces differing only in a
designated derived compatibility-bit write collide.  Retaining only the
one-bit decision cannot repair the collision: \((x_1)\) and
\((\neg x_1)\) are both satisfiable but have opposite compatibility under
\(x_1=0\).  Thus a field mask is not a representation-invariant bridge.
The theorem is deliberately restricted to fixed field masks; it neither
rules out a typed causal/noninterference projection nor yields any SAT time
or space lower bound.
\end{abstract}

\section{Claim card: exact quantifiers, encoding, and costs}

Fix an ordinary self-delimiting CNF encoding \(\operatorname{enc}(F)\).
Let an ordered execution trace be a finite sequence in
\(\prod_{f\in\mathcal E}D_f\), and, for any fixed
\(M\subseteq\mathcal E\), let \(\pi_M\) delete all event coordinates outside
\(M\) while preserving event order and multiplicity.  COPY and derived writes
use the same generic work-write event schema; the mask is not permitted a
hidden provenance tag.  All trace construction, projection reads, and
reconstruction reads are charged.

The attacked universal proposal is
\begin{multline}
 \exists M\subseteq\mathcal E\ \forall A\ \forall F:\quad
 \pi_M(\operatorname{Tr}_A(F))\text{ excludes every recoverable source copy,}\tag{P}\label{eq:P}\\
 \text{yet retains a nonconstant designated derived compatibility bit and is
 more informative than the final decision.}
\end{multline}
The theorem below falsifies \eqref{eq:P} in the stated field-mask model.  It
does not quantify over arbitrary semantic projections, arbitrary event
schemas, or all ways to define ``derived.''

\paragraph{SAME\_REALIZATION.}
The COPY attack is one extensionally equivalent implementation: it copies the
read-only input into ordinary work writes and then runs the original decider.
The source decode uses those writes from that same execution.  The derived
collision compares two legal one-write traces under the same mask and schema.
No resource value from one realization is assigned to another.

\section{Primary-literature and barrier-transfer preflight}

The first obstacle is semantic: complete canonicalization of all equivalent
programs is not a computable preprocessing step.  Rice's theorem is a
\textbf{directly transferable theorem} for nontrivial semantic properties of
program-computed functions\footnote{H.~G. Rice, ``Classes of Recursively
Enumerable Sets and Their Decision Problems,'' \emph{Transactions of the
AMS} 74(2):358--366, 1953,
\url{https://www.ams.org/journals/tran/1953-074-02/S0002-9947-1953-0053041-6/S0002-9947-1953-0053041-6.pdf}.}.
The corpus had already instantiated this point as
\claim{POLY-EXTENSIONAL-CANONIZER-NOGO1}; it is not new here.
Translation validation instead checks each concrete compilation against a
source/target semantics\footnote{A.~Pnueli, M.~Siegel and E.~Singerman,
``Translation Validation,'' TACAS 1998, pp.~151--166,
doi:10.1007/BFb0054170.}.  It is a \textbf{useful structural analogy requiring
a new transfer theorem}: validation does not certify coverage of every
extensionally equivalent SAT program.

The second obstacle is provenance.  Information-flow type systems and
noninterference distinguish source-labelled from derived data only relative
to a declared operational semantics and security lattice\footnote{D.~E.
Denning, ``A Lattice Model of Secure Information Flow,'' \emph{Communications
of the ACM} 19(5):236--243, 1976, doi:10.1145/360051.360056.}.  This is again
an \textbf{analogy/candidate}, not a theorem about arbitrary Turing/RAM
implementations: an untyped machine may compute, copy, encode, erase, and
recompute values without preserving a source/derived label.

Baker--Gill--Solovay relativization and Aaronson--Wigderson algebrization are
direct barrier controls for any claimed P-versus-NP endgame\footnote{T.~Baker,
J.~Gill and R.~Solovay, ``Relativizations of the P=?NP Question,'' \emph{SIAM
J. Comput.} 4(4):431--442, 1975, doi:10.1137/0204037.}
\footnote{S.~Aaronson and A.~Wigderson, ``Algebrization: A New Barrier in
Complexity Theory,'' \emph{ACM TOCT} 1(1), 2009,
doi:10.1145/1490270.1490272.}.  The elementary trilemma below relativizes and
algebrizes; it is a guard, not an escape from either barrier.  Circuit,
branching-program, VLSI, communication, pebbling, proof-complexity, and
Natural-Proofs lower bounds remain \textbf{failed transfers} unless an
arbitrary SAT decider is first placed in their declared model.

\section{Exact field-mask trilemma}

\begin{theorem}[\claim{TRACE-FIELD-MASK-TRILEMMA1}]
For every fixed field mask \(M\subseteq\mathcal E\), at least one of the
following holds.
\begin{enumerate}[label=(\roman*)]
\item \(\mathsf{value}\in M\), and a uniform extensionally equivalent COPY
wrapper makes one arbitrary encoded source bit recoverable from
\(\pi_M(\operatorname{Tr}(F))\) per generic work-write event;
\item \(\mathsf{value}\notin M\), and there exist two traces differing only
in one designated derived-bit write whose projections are identical;
\item restricting the retained information to the final SAT bit cannot
recover compatibility for all formula/partial-assignment pairs.
\end{enumerate}
Consequently no such mask simultaneously guarantees source-copy exclusion,
nonconstant derived compatibility retention, and information beyond the
decision bit.
\end{theorem}

\begin{proof}
If \(\mathsf{value}\in M\), prepend to any decider the loop that, for each
bit \(b_i\) of \(\operatorname{enc}(F)\), emits the ordinary event
\[
 e_i=(\mathsf{write},\mathsf{work},0,b_i,\mathsf{step},\bot).
\]
The wrapper then simulates the original decider and preserves its answer.
Fixed input length and event order identify the prefix; the retained value
coordinate recovers every \(b_i\).  Already one source bit and one event are
enough for the claimed leakage.

If \(\mathsf{value}\notin M\), take two one-event traces with all coordinates
equal except that the generic work-write value is respectively zero and one.
The coordinate deletion maps them to the same projected trace.  Therefore no
decoder of \(\pi_M\) can recover a designated compatibility bit stored in
that write on both traces.

Finally let \(F=(x_1)\), \(G=(\neg x_1)\), and
\(\alpha=\{x_1=0\}\).  Both formulas have SAT decision one, but
\(F\!\upharpoonright\!\alpha\) is unsatisfiable while
\(G\!\upharpoonright\!\alpha\) is satisfiable.  Hence the common output bit
does not determine compatibility.  The three cases exhaust every fixed
field mask.  All writes and reads used in the argument are explicit.
\end{proof}

\begin{corollary}
\claim{FIELD-MASK-SUFFICES-FOR-INVARIANT-DERIVED-TRACE1} is \RETIRED.
Deleting the initial input carrier and then choosing fields by name is not a
solver-independent definition of ``derived trace.''
\end{corollary}

\section{Hostile-control and representation audit}

Polynomial algorithms for Horn propagation, 2SAT implication graphs,
Gaussian elimination on affine/Tseitin instances, and bounded-treewidth
dynamic programming remain decisive easy-island controls.  Their existence
prevents any inference from the number of semantic compatibility states to
runtime.  Independent products stream through one accumulator; padding and
redundancy inflate the trace without adding hardness.  Compact circuits,
BDDs or branching programs may represent the same derived relation without
ever issuing this event schema.  The one-bit decision interface exposes
neither a compatibility table nor a witness.

COPY is the load-bearing counterwrapper.  DEAD and DELAY change length and
timing; INTERP changes representation; RECOMP trades storage for repeated
work.  A fixed field mask does not quotient this equivalence class.  A hidden
``derived'' tag would merely relocate the obligation: one must prove that
every arbitrary implementation admits a sound, complete, charged tagger and
that equivalent wrappers cannot forge or erase tags.

The exact quantifier of the surviving direct target remains
\[
 \forall A\,[A\text{ is a uniform deterministic exact decider for the fixed
 NP-complete clean core}]\ \exists^\infty F:
 T_A(F)>|F|^c
\]
for every constant \(c\), or an equivalent all-decider implication into a
model-matched unconditional forbidden region.  Any premise strong enough to
assert this conclusion without an independent bridge is simply a hidden form
of \(P\ne NP\).

\section{Relativization, algebrization, Natural Proofs, and nonuniformity}

The trilemma uses only syntactic copying and coordinate deletion, so it
survives semantic and algebraic oracle augmentation.  It cannot be the
nonrelativizing/nonalgebrizing hinge.  It is not a circuit lower bound and
therefore does not itself trigger the Razborov--Rudich largeness/usefulness
conditions; any later efficiently recognizable large property separating
SAT circuit truth tables would need an explicit Natural-Proofs audit.

Nonuniform advice can hard-code masks, decoders or per-length conventions but
does not change the dichotomy on \(\mathsf{value}\).  Conversely, a
program-specific semantic quotient supplied as free advice is outside the
uniform model and cannot support a uniform P-versus-NP proof.  Arbitrary
polynomial exponents also remain unbounded: a pointwise extractor that simply
recomputes compatibility may inherit the hypothetical solver's exponent and
does not land in FLMV or any other fixed forbidden region.

\section{Post-quantum technique ledger}

The collision object transfers exactly for value-dropping masks: the two
derived traces form one projection fiber, so
\(
\operatorname{Coll}(\pi_M)\ge4
\)
on that two-element domain and the image has size one.  This is an
\textbf{EXACT OBJECT/THEOREM TRANSFER} of the lossiness/collision ledger, but
it diagnoses information destruction rather than hardness.  When the value
field is retained, the projection is injective on the one-bit COPY pair and
the same structure is exploitable by a source decoder.

Schur squares, shortening, puncturing, quadratic-relation rank spectra,
Hilbert functions, syzygies and Betti numbers are \textbf{FAILED TRANSFERS}
for this claim because no linear-code or graded-algebra object is forced by a
field mask.  LWE-style black-box external extraction is an
\textbf{ANALOGY/CANDIDATE}; it needs a worst-case solver-independent reduction
and must survive known NP worst-case/average-case barriers.  Special-soundness
or collapse-binding would require two valid openings under one declared
commitment, absent here.  Hash/random-oracle provenance remains a
cryptographic analogy and is inadmissible as an unconditional bridge.
