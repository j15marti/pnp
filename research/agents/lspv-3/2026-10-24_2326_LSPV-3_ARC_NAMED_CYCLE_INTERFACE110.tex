\section{Exact opposite-label source family}
For an ordinary Boolean pair \(u,v\) and \(d\in\{0,1\}\), define
\[
D_0(u,v)=(\neg u\vee v)\wedge(u\vee\neg v),\qquad
D_1(u,v)=(u\vee v)\wedge(\neg u\vee\neg v).
\]
Thus \(D_d(u,v)\) is the relation \(u\oplus v=d\).
For each binary disjunction \(c=(\ell_1\vee\ell_2)\), introduce one private new name \(z\) and replace it by
\[
\operatorname{lift}(c;z)
=(\ell_1\vee\ell_2\vee z)\wedge
(\ell_1\vee\ell_2\vee\neg z).
\]
These are two distinct proper ordinary ternary clauses, with no repeated variable in any clause, and \(\exists z\,\operatorname{lift}(c;z)\equiv c\). For each \(D_d\), the two binary clauses receive separate auxiliaries, producing one module \(M_d(u,v)\) of four proper ternary clauses with two private names. For \(r\ge3\) let original boundary names be \(x_1,\ldots,x_r\), indices cyclic, and define
\[
F_r^{\rm YES}=\bigwedge_{i=1}^r M_0(x_i,x_{i+1}),
\qquad
F_r^{\rm NO}=\left(\bigwedge_{i=1}^{r-1}M_0(x_i,x_{i+1})\right)\wedge M_1(x_r,x_1).
\tag{1}
\]
Each contains \(3r\) active names (including \(2r\) auxiliary names), \(4r\) unique proper ternary clauses and the same unsigned incidence, ordinary encoding length and recursive child sizes. The pair differs in four literal-sign fields of its final module. Its ternary clauses have mixed signs and unconstrained auxiliary occurrence counts, so these are \emph{outside the M22 target} but \emph{inside the ordinary-SAT all-input ARC domain}. Consequently they validly falsify a universally stated ordinary-SAT status-only compiler claim, not any stronger theorem expressly restricted to \(\mathcal C_\star\).

\begin{theorem}[Exact cycle, all proper subjoins SAT, two levels]\label{thm:cycle}
For every \(r\ge3\): (i) \(\SAT(F_r^{\rm YES})=1\) and \(\SAT(F_r^{\rm NO})=0\); the first source has exactly \(2^{2r+1}\) satisfying complete assignments; (ii) every strict subset \(I\subsetneq[r]\) of whole named modules has satisfiable conjunction \(\bigwedge_{i\in I}M_{\delta_i}(x_i,x_{i+1})\), for either choice in (1); (iii) each module's exact two-name boundary predicate has cardinality two and full unary projections, but the boundary predicates distinguish equality from disequality and compose to the correct full-root SAT bit; (iv) when \(4\mid r\), the equal-halves parent, its two serialized half-children, and the four serialized quarter-grandchildren have matching YES/NO encoded lengths and every \emph{proper} descendant is SAT, even while the NO root is UNSAT.
\end{theorem}
\begin{proof}
Projecting each pair of lift auxiliaries gives \(x_i\oplus x_{i+1}=\delta_i\), exactly and with original-name identity intact. XOR around the cycle yields \(0=\bigoplus_i\delta_i\). The all-zero vector is feasible in the YES case, whereas the NO case has odd parity, proving (i). A complete YES boundary assignment has exactly two choices (all \(x_i=0\) or all \(x_i=1\)); for each, every lifted binary clause is already true and all \(2r\) independent auxiliaries are unrestricted, giving \(2\cdot 2^{2r}\) models. Every proper edge subset is a forest of paths. Choose an arbitrary starting value for each component, propagate the signed equalities/disequalities, then set each omitted auxiliary arbitrarily; this proves (ii) even for noncontiguous subsets. For (iii), the source-consistent local relation is
\[
R_i(a,b)=[a\oplus b=\delta_i],
\qquad R_0=(1,0,0,1),\quad R_1=(0,1,1,0)
\]
in boundary order \(00,01,10,11\); the root is
\[
\SAT(F_r) \iff
\exists a_1,\ldots,a_r\;\bigwedge_{i=1}^r
R_i(a_i,a_{i+1}),\quad a_{r+1}=a_1.
\]
These are exact compatible named joins, not independent SAT bits.
For (iv), restrict to consecutive half or quarter sets of \emph{whole} modules. They omit at least one cycle edge and so are SAT by (ii). Serialize clauses with an injective local name-renumbering and a correct ordinary header; decoding and retaining the local-to-original name map preserves all original clauses and the compatibility relation at both recursive levels.
\end{proof}

\begin{proposition}[Status-only SAT-oracle indistinguishability]\label{prop:status}
A deterministic adaptive combiner whose only formula-dependent observations are the SAT/UNSAT bits of arbitrarily selected \emph{strict unions of the designated whole source modules}, and whose next query depends only on its prior such answers and fixed public module indices, cannot decide both \(F_r^{\rm YES}\) and \(F_r^{\rm NO}\) correctly. This remains true if every strict subset is available, not merely one binary partition.
\end{proposition}
\begin{proof}
By Theorem~\ref{thm:cycle}(ii), every permitted query returns SAT on both inputs. Induction on the deterministic query transcript gives the same next query and final output on both. Their root labels differ. Thus the specified status-only interface is insufficient.
\end{proof}
This \emph{does not} exclude a source-aware combiner reading the distinguishing signs, pinned/modified SAT queries, exact boundary predicates, symbolic affine/SCC methods, or direct decision. In fact a charged parity-DSU scan decides both families with polynomial bit work and \(O(\log N)\) writable scratch. No arbitrary-SAT runtime lower bound follows.

\section{Source-name-preserving ordinary encoding and actual two-level audit}
