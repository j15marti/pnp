\section*{Same unsigned incidence hypergraph, varying unit signs}
For all $n\ge2$ and $a\in\{0,1\}^{n\times n}$ let $x_{ij},p_{ij}$ be independent Boolean variables. The mask $a_{ij}=1$ disables edge $(i,j)$. Form ordinary CNF
\[
\begin{split}
F_{n,a}={}&\bigwedge_i(\bigvee_jx_{ij})\wedge\bigwedge_j(\bigvee_ix_{ij})
\wedge\bigwedge_{i;\,j<k}(\neg x_{ij}\vee\neg x_{ik})\\
&\wedge\bigwedge_{j;\,i<k}(\neg x_{ij}\vee\neg x_{kj})
\wedge\bigwedge_{i,j}(p_{ij}\vee\neg x_{ij})
\wedge\bigwedge_{i,j}\ell_{ij}(a),\\
&\ell_{ij}(a)=\begin{cases}p_{ij}&a_{ij}=0\\\neg p_{ij}&a_{ij}=1.\end{cases}
\end{split}
\]
All $2^{n^2}$ formulae have the same clause IDs, absolute literal lists, and unsigned signed-hypergraph incidence; only $n^2$ unit polarities differ. There are $v=2n^2$ variables, $m=n^3+n^2+2n$ clauses, $L=2n^3+3n^2$ literal occurrences and $N=\Theta(n^3\log n)$ explicitly encoded CNF bits. This is GENERAL CNF, not an asserted strict 3-CNF hard family.

\begin{theorem}[Exact source-sign semantics and restricted hardness counterexample]
For every $n\ge2$ and mask $a$, satisfying assignments of $F_{n,a}$ biject with perfect matchings of the bipartite graph whose adjacency matrix is $b=1-a$. Thus
\[
U_n(a)={\bf1}[F_{n,a}\ \mathrm{UNSAT}]
=1-\operatorname{PM}_n(1-a)
=\bigwedge_{\pi\in S_n}\bigvee_i a_{i,\pi(i)}.
\]
Every monotone AND/OR shared circuit computing $U_n$ on all sign masks has size
\[
2^{n^{1/3-o(1)}}=2^{(N/\log N)^{1/9-o(1)}}.
\]
Nevertheless one uniform deterministic algorithm recognizes the formula template and decides all its SAT labels in polynomial bit time by bipartite matching. Therefore large monotone semantic source-sign profile complexity is NOT a representation- or algorithm-independent SAT runtime lower bound.
\end{theorem}
\begin{proof}
The row/column positive clauses and pairwise at-most-one negatives force $x$ to be a permutation matrix. Each unit forces $p_{ij}=1-a_{ij}$, so the gate clause rules out exactly the disabled selected edges. Every perfect matching determines one assignment of all $x,p$. An AND/OR circuit for $U_n$ dualizes at the same gate count by interchanging $\wedge,\vee$ and constants to a circuit computing $1-U_n(1-b)=\operatorname{PM}_n(b)$. Apply the cited monotone theorem. For the unrestricted upper bound, uniformly parse and authenticate all source clauses and signs, recover $b$ and run a deterministic augmenting-path matching algorithm. A total correct general SAT decider can use this shortcut on recognized formulas, exhaustive SAT elsewhere and explicitly reject malformed strings. Its global worst case may be exponential. No short mixed refutation is asserted.
\end{proof}
