\section{Typed stream definitions and encoding}
Fix a proper-3CNF
\[
F=\bigwedge_{j=1}^{m}
(\ell_{j1}\vee\ell_{j2}\vee\ell_{j3}),\qquad
|\{|\ell_{j1}|,|\ell_{j2}|,|\ell_{j3}|\}|=3.
\]
It uses $m\ge1$ clauses, $n$ declared names and $\nu\le n$
actually occurring names. In the fixed-width record model let
\[
h=\lceil\log_2(64(n+m+1))\rceil,\qquad N_F=(4m+2)h.
\]
A globally valid named scoped stream permits OPEN($v$) exactly once
over the entire stream, CLAUSE only on live identifiers, and permanent
CLOSE($v$). A \emph{locally valid reopening stream} requires
well-nested local OPEN/CLOSE and only live clause references but allows
a closed source name to OPEN again later. The maximum local live width
can therefore differ from the width of the globally named problem.

For every source clause $j$ concatenate the seven-event block
\[
\begin{gathered}
\mathrm{OPEN}(|\ell_{j1}|),\
\mathrm{OPEN}(|\ell_{j2}|),\
\mathrm{OPEN}(|\ell_{j3}|),\\
\mathrm{CLAUSE}(\ell_{j1},\ell_{j2},\ell_{j3}),\\
\mathrm{CLOSE}(|\ell_{j3}|),\
\mathrm{CLOSE}(|\ell_{j2}|),\
\mathrm{CLOSE}(|\ell_{j1}|).
\end{gathered}
\]
Denote the concatenation $E(F)$. With four fixed-width fields per
event, its length is
\[
N_{E(F)}=(2+28m)h\le7N_F.
\]

\begin{theorem}[Reopening-stream completeness; PROVED/EXACT in the declared language]
Every $E(F)$ is locally valid with peak live width three.
Erasing event tags gives exactly $F$ with all original signed names.
Thus SAT on the locally valid width-three reopening language is
NP-complete by a uniform linear-size reduction from ordinary
proper-3CNF SAT. However the naive scope DP that projects names at
each CLOSE and treats subsequent re-OPEN as new variables
returns SAT on \emph{every} $E(F)$, including UNSAT sources.
\end{theorem}
\begin{proof}
Each block opens three distinct identifiers, checks one clause on
those identifiers, and closes them all. Signed source literals and
global name identity are copied unchanged, so the erased formula is
the exact original conjunction. The target is in NP by guessing the
one assignment to the original global names. The local scope DP
mistakenly forgets them after each block; every proper ternary clause
separately has seven satisfying assignments, so projecting each block
never empties the final truth table.
\end{proof}

\section{Exact occurrence-alias repair, and why it is not free}
Use distinct occurrence variables $u_{ji}$ in the preceding stream
instead of old global names. This yields a genuinely globally valid,
width-three stream $E_{\rm fresh}(F)$. Its detached clauses use disjoint
triples and are always SAT. For each old source name with $d_v$
occurrences, connect its copies by any spanning tree of $d_v-1$
binary equalities. The total number of links is exactly
\[
r=\sum_v(d_v-1)=3m-\nu.
\]
Call the fresh-clause conjunction plus these links $G_F$.

\begin{theorem}[Named-alias repair; PROVED/EXACT restricted]
$\SAT(G_F)\iff\SAT(F)$. Every equality $u=v$ has the independent
proper-three-clause gadget
\[
(\neg u\vee v\vee p)\wedge(\neg u\vee v\vee\neg p)
\wedge(u\vee\neg v\vee q)\wedge(u\vee\neg v\vee\neg q),
\]
for two fresh auxiliaries $p,q$. The ordinary independent 3CNF
compilation has the exact record counts
\[
\boxed{n'=3m+2r,\qquad m'=m+4r.}
\]
\end{theorem}
\begin{proof}
A satisfying source assignment copies the value of each old
variable to all its occurrence variables and satisfies the
fresh clauses and equalities. Conversely the spanning-tree
equalities identify all copies of each old name and their
local clauses become the original clauses. Each pair of
opposite-sign auxiliary clauses eliminates to its binary
implication, so the four-clause gadget is existentially
equivalent to $u=v$. The two auxiliaries per edge and four
clauses per edge give the exact counts.
\end{proof}
A detached width-three stream plus an external equality table is
not a valid width-three \emph{ordinary} SAT representation
without charging the table and its global compatibility.
Appending equalities after all names have CLOSED causes
illegal reopening unless the intervals/representation change.
No sublinear ordinary SAT child follows from this source-linear
compiler or from a short source-indexed handle.

\begin{lemma}[Every original occurrence can be essential]
Take the eight signed clauses over $a,b,c$, one for each falsifying
assignment. Their conjunction $U_3$ is UNSAT. Freeing \emph{any one}
of its $24$ original variable occurrences by substituting a fresh
independent variable makes the resulting proper-3CNF SAT.
\end{lemma}
\begin{proof}
For the altered clause $C$, choose the unique old assignment
that falsifies $C$. It satisfies all seven other distinct signed
clauses. Choose the new variable value to make the altered
literal true. This proves all 24 cases by symmetry.
\end{proof}
This concerns one occurrence's source identity, not deletion
of exactly one edge in an arbitrarily chosen equality tree.

\section{Model-matched forbidden-region check}
On a \emph{trusted globally valid} scoped stream of $L$ events
and live width $w$, exact existential frontier DP uses
$O(L2^w\mathrm{polylog}(N))$ elementary work and
$O(2^w+w\log N+\log N)$ writable bits.
Suppose hypothetically there were a uniform all-input
transducer taking every locally valid stream $E(F)$ to a
semantically equivalent \emph{globally valid} width-three stream,
with emitted bit length $N^{1+o(1)}$, total time
$N^{1.1+o(1)}$ and peak space $N^{.5+o(1)}$.
All source access, naming validation, output parsing, buffering,
failed paths and work/index tapes must be charged on the same
random-access realization. Streaming the output online through
the width-three DP gives one all-input exact SAT decider in
simultaneous resources $(t,s)=(1.1,.5)$ at exponent scale.
FLMV forbids that point: for
\[
c_0=241/200>1.1,\qquad
\beta(c_0)=\frac12\left(\frac{c_0+2}{c_0^2}-c_0\right)
=\frac{11642479}{23232400}>.5,
\]
both gaps are strict and tolerate polylogarithmic transfer overhead.
This excludes the \emph{specified complete universal repair
contract}. It does not prove that arbitrary SAT algorithms must
emit scopes, relations, witnesses, or a designated history.
