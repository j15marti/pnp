## ITERATE: two exact restricted theorems

### Lemma 545.1: native indexed high-water destroys the live-cell-to-space substitution

**PROVED/RESTRICTED from the machine definition.** For every input length N>=1, a fixed deterministic indexed-tape machine H can, on every input of length N, construct the (N+1)-bit binary index `1` followed by N zeros, perform an indexed read and write at work-tape address `2^N`, and halt within O(N) native steps. The index tape and control require O(N) visited cells and only **one** far work-data cell is accessed, but the *native* space measure of FLMV is at least 2^N.

**Proof.** Scan the read-only input to learn its length, write N+1 index bits, perform the native indexed move, read and write at the target work position. The indexing operation erases the index tape by the paper's primitive. The work position visited is 2^N. A fixed number of scans and constant local operations per index bit suffice. No source-dependent advice, oracle, or nonuniform table is used. QED.

**Conditional SAT padding:** IF a uniform total correct deterministic SAT machine A0 with polynomial time exists, create a fixed machine H;A0 using a disjoint scratch indexed work tape for H. This new machine has worst-case polynomial time O(N+T_A0(N)), is correct on SAT/UNSAT/malformed sources, and uses at least 2^N native high-water space. Thus *a polynomial time upper does not imply a polynomial native-space upper for the same realization*. Sparse storage may give an algorithm on another implementation at polylog overhead; preserve both time exponent and machine semantics before FLMV application. The elementary high-address issue is consistent with and reuses LSPV-4/458, not claimed as a first discovery.

### Lemma 545.2: exact AND-coverage and streaming-space separation

Fix an explicitly parsed source CNF F of binary length N with v variables. A **separate typed audit calculus** (NOT an authenticated R_mix341 extension) has a complete binary case tree branching on each variable. Under full context Gamma_a, a leaf is certified rejecting only by a cited *original* clause C_i falsified by the complete assignment a. Internal AND joins require BOTH values of the pivot; a terminal SAT witness exists when some complete assignment satisfies all clauses. An OR operation may select one of multiple valid source-falsified leaves for that *same* assignment, but cannot replace the AND over assignments.

**PROVED/RESTRICTED.** The root AND is certified iff F is UNSAT. The complete explicit tree has L=2^v leaves and 2L-1 logical tree positions. A deterministic DFS may check the same universal property using O(v+log N) WORK bits (counter, current assignment and indexed clause parser with read-only input, under a reasonable explicit CNF grammar) and O(2^v poly(N)) time. Native sequential indexed tape moves can implement this with polynomial overhead; a byte-level tight bound is not claimed. Source identity and each leaf's original clause are checked, not an UNSAT oracle. Exact history uses the assignment counter, not a stored proof tree.

**Proof.** At each of the 2^v full assignments scan all source clauses. If a satisfying assignment is found, output SAT. Otherwise associate the first actually falsified source clause and proceed. Exhaustive binary increment covers every assignment once, so UNSAT is returned exactly when every leaf can authenticate an original failed clause. Only the current v-bit assignment, one clause and bounded source/index bookkeeping need to be live. The combinatorial tree is not resident. The result uses exponential time in v and therefore yields no uniform polynomial SAT decider on unrestricted v. QED.

**NP quantifier control.** A separate nondeterministic SAT witness machine has `exists`-accept semantics: a satisfying branch suffices for SAT; all branches reject on UNSAT. A read-only witness-tape verifier can scan the CNF using O(log N) additional work under compatible random-access witness conventions, whereas a machine generating and retaining choices on charged work tape may use O(v). Neither object is a total deterministic UNSAT decider merely from one rejected branch. Universal AND of branches cannot be silently substituted for NP existential acceptance.

### Typed complete-state abstraction and sound polarity

A concrete deterministic native state is `(fixed M, exact x, q, input head/index, all work/index tape content and head positions, high-water per non-index tape, output/parse status, elapsed steps, measured peak)`. Nondeterministic states add the branch history/choice policy. A *proof auditor's ghost annotation*, when in use, adds `(Gamma, original-source IDs, legal shared DAG, paid IDs, globally fresh DEF wires, exported/private interfaces, retained/discharged contexts)`; these annotations are not physically resident unless an implemented machine stores them.

For exact singleton collecting semantics, alpha is identity and gamma is singleton. For a coarse may reduced-product element a, alpha(X) retains **source/machine identification**, allowed output-label set, may-contexts, complete AND/OR obligation sets, native high-water and live-cell count as distinct interval components `[lo,hi]`, and t, peak records; gamma(a) is the set of concrete states consistent with those fields. Its collecting transformer is `Post#(a)=alpha(Post(gamma(a)))` with unknown/unauthenticated transitions widened, never deleted. Hence `Post(gamma(a)) subseteq gamma(Post#(a))` by definition. AND goals require verified universal coverage, OR goals only one legal successful child, and shared DAG payment is the size/cost of the **union of global paid IDs**. An R_mix341 budget nonreachability claim may use only an overapproximation of ALL native rules and no-greater-cost abstract paths; none is presently established.

**Resource polarity:** for a fixed run, any proven upper bound on supremal overapproximated peak bounds the actual maximum. A lower bound on infimal cost of an **undercharging, path-covering** abstract transition system lower-bounds concrete cheapest proof. Per-run lower/upper cost intervals require all transitions and all phases. A state set with 2^v members does not imply log2 of the set is allocated memory. The lower bound on native *high-water* of H does not imply an equal lower bound on physically nonblank live data cells. Cost-partition sums need an explicit nonoverlap tariff; no independent tree-component bounds are added without it.
