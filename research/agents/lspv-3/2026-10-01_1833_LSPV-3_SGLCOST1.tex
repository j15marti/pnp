The first obstacle is quantitative model matching: SGLAUD1 counted original reconstruction queries through the covering construction but did not prove the number of SAT-oracle invocations made by the \emph{fully relativized} quadratic SGL simulator. The second obstacle is barrier-level: Viola proves both the relativizing positive simulations
\[

\qquad
\mathrm{BPTime}(t)\subseteq\Sigma_3\mathrm{Time}(t\,\mathrm{polylog}\,t),

and an oracle relative to which no \(o(t^2)\) \(\Sigma_2\) simulation exists. Thus a generic subquadratic two-alternation improvement cannot be justified solely by a relativizing black-box argument. The vMS 2025 paper remains the source for the targeted AM/reconstruction architecture, but does not by itself provide the project-specific oracle-query census needed here.

\paragraph{PROVED/EXACT: sequential oracle-substitution accounting.}
Let an alternating oracle machine \(M^{\mathrm{SAT}}\), on inputs of scale \(t\), have ordinary non-oracle running time at most
\[
T(t)=t^{a+o(1)},
\]
make at most
\[
Q(t)=t^{\gamma+o(1)}
\]
SAT-oracle calls on each branch, and issue formulas of length at most
\[
S(t)=t^{b+o(1)}.
\]
Assume the counterfactual exact SAT decider \(A\) runs in
\[
A(N)=N^{\kappa+o(1)}.
\]
Replacing each oracle call sequentially by \(A\) gives deterministic matrix work bounded by
\[
\boxed{
T(t)+Q(t)A(S(t))
=
t^{\max\{a,\gamma+b\kappa\}+o(1)}.
}
\]
This is direct machine accounting. Query multiplicity and per-query SAT cost multiply before exponents are compared.

\paragraph{PROVED/EXACT: safe black-box specialization to SGL.}
The primary quantitative theorem gives an oracle-relativizing \(\Sigma_2\) simulator with total oracle-machine time
\[
T_{\mathrm{SGL}}(t)=t^{2+o(1)}
\]
(up to the stated logarithmic factor). Without a separate source-level query census, the only automatic bound is
\[
Q_{\mathrm{SGL}}(t)\le T_{\mathrm{SGL}}(t)=t^{2+o(1)}.
\]
If the largest SAT query emitted by the simulator has length \(t^{b_0+o(1)}\), sequential substitution therefore gives the safe bound
\[
\boxed{
t^{2+b_0\kappa+o(1)}.
}
\]
This is a conservative upper bound. It is not claimed optimal.
