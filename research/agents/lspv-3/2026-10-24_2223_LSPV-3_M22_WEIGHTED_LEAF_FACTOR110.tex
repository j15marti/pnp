\section{Polynomial source-named unary optimization}
\begin{theorem}[Exact minimum-cost boundary and hard-pin service]

\[
 \min_{\substack{a\in B_H\\a|_J=p}}\sum_{d\in D}c_d(a_d)
\]
together with an original-name extension $b:Z\to\{0,1\}$ in deterministic bit-polynomial time and polynomial writable/index space. No SAT/UNSAT label oracle, arbitrary boundary-word enumeration or encoding-changing variable complement is required. The claim is about the paired core only and does not decide $\SAT(F)$ in polynomial time.
\end{theorem}
\begin{proof}
Create one graph vertex $v_h$ for every original paired support $h\in H$. For each original variable occurring in two $H$ supports, make one separately indexed undirected edge between their \emph{distinct} support vertices. For each $d$ occurring in one $H$ support, make an edge from that support vertex to a private degree-one leaf $v_d$. Names occurring in no paired support are carried independently. Parallel edges are allowed and never silently identified; loops cannot occur because supports are unique and an original variable cannot occur twice in one support.

Select edge $e_x$ if and only if the corresponding source variable $x$ is TRUE. At every support vertex $v_h$, the paired OR clauses are jointly true exactly when
\[
  1\le\deg_{\mathrm{selected}}(v_h)\le2.
\]
At each unconstrained private leaf impose $0\le\deg_{\mathrm{selected}}(v_d)\le1$; at a hard-pinned leaf $d\in J$, impose lower and upper degree both equal to $p(d)$. Assign selected-edge weight $c_d(1)-c_d(0)$ to leaf edge $e_d$, zero to every internal edge, and add the known constant $\sum_{d\in D}c_d(0)$. An exposed name absent from all paired supports is optimized or pinned separately; it never enters a factor constraint.

Every legal degree-interval subgraph gives one globally coherent assignment on original names satisfying all paired clauses, and conversely; all costs agree term by term. Thus this is an exact min-cost $(g,f)$ degree-constrained subgraph problem on a loopless multigraph with $O(N)$ bit-indexed vertices/edges and binary weights. Polynomial deterministic optimization and witness construction are supplied by the classical degree-constrained subgraph/matching reductions \cite{gabow83,gabow18}; finite arithmetic and bit lengths are included. Restoring source names from edge indices yields the claimed original-name witness. This argument remains valid with $H=\varnothing$: boundary variables are unconstrained and individually optimized.
\end{proof}
\paragraph{Weighted Hamming consequence.} For arbitrary $a^0\in\{0,1\}^D$, $w_d\ge0$, set $c_d(b)=w_d[b\ne a^0_d]$. Then the algorithm returns an exact nearest boundary assignment under weighted Hamming distance, including optional frozen coordinates.
