\section{Exact full-difference root-certificate lemma}
Fix a total SAT-label-preserving encoding $e:\{0,1\}^q\to D_N$ into valid sources, and $f(b)=\operatorname{SAT}(e(b))$. For a fixed base $b^*$ and any opposite-label $b$, let $\Delta_b=\{j:e(b)_j\ne e(b^*)_j\}$. Define
\[
\tau_{\rm all}(e,b^*)=\min\{|Q|:\forall b\ (f(b)\ne f(b^*)\Rightarrow Q\cap\Delta_b\ne\varnothing)\}.
\]
Let $\tau_1$ be the POINTWISE64 parameter restricting the alternatives to sensitive \emph{one-coordinate} flips.
\begin{theorem}[PROVED/EXACT]
Every deterministic exact SAT decider on $e(b^*)$ reads at least $\tau_{\rm all}(e,b^*)\ge\tau_1(e,b^*)$ distinct target input bits. $\tau_{\rm all}$ is exactly the restricted pointwise certificate complexity on $\operatorname{im}(e)$.
\end{theorem}
\begin{proof}
If its actual read set misses $\Delta_b$ for an opposite-label valid source, deterministic adaptive execution sees identical read values, visits identical internal configurations and emits the same root decision, contradicting correctness. Therefore it hits every opposite-label change. One-bit changes are a subset. A set certifies the root label on the promise image iff no opposite-label image agrees on its selected coordinates, which is exactly the hitting condition. No contextual service or difference hypergraph is constructed by the original decider.
\end{proof}
Certificate complexity is a KNOWN concept (Buhrman and de Wolf); this project result sharpens POINTWISE64 and supplies an explicit valid proper-3CNF separation. The external hypergraph may require $\Theta(2^qN)$ bit operations to materialize naively; that cost is never silently attributed to the SAT decider.

\section{Source-exact proper-3CNF construction}
For $q\ge2$, encode $f_q(b)=[\sum_i b_i=2]$. The proper-ternary forcing gadget
\[
G(\ell;a,b)=\bigwedge_{s,t\in\{+1,-1\}}(\ell\lor sa\lor tb)
\quad\Longleftrightarrow\quad\ell
\]
uses two fresh helper variables. Force a zero variable $z$, and for each source bit $b_i$ force $u_i=v_i=0$ and add one pivot clause
\[
(\ell_i(b_i)\lor u_i\lor v_i),\qquad
\ell_i(1)=x_i,\quad\ell_i(0)=\neg x_i.
\]
Hence $x_i=b_i$, and flipping $b_i$ changes exactly the sign bit of this single pivot word, without changing any other source bit, clause ordering, header or target length.

The fixed functional circuit initializes $c_0^{(1)}=c_0^{(2)}=c_0^{(3)}=z=0$ and, with fresh gate variables, uses
\[
h_i^{(2)}=c_{i-1}^{(1)}\wedge x_i,\quad h_i^{(3)}=c_{i-1}^{(2)}\wedge x_i,
\]
\[
c_i^{(1)}=c_{i-1}^{(1)}\vee x_i,\quad
c_i^{(2)}=c_{i-1}^{(2)}\vee h_i^{(2)},\quad
c_i^{(3)}=c_{i-1}^{(3)}\vee h_i^{(3)}.
\]
Enforce all five gates per input with exact Tseitin equivalences, replacing each binary clause $(a\lor b)$ by $(a\lor b\lor y)(a\lor b\lor\neg y)$ with its own free padding variable. Force $c_q^{(2)}=1$ and $c_q^{(3)}=0$. Every source clause is proper width three with distinct variables, including all gadgets.
\begin{theorem}[PROVED/EXACT, both labels]
The resulting valid encoded formula $H_q(b)$ is SAT iff $\sum_i b_i=2$. Its exact fixed-record accounting is
\[
n=22q+7,\quad k=m=34q+12,\quad
w=\lceil\log_2(64(n+m+1))\rceil,\quad N=(136q+50)w.
\]
At the UNSAT base $0^q$, $\tau_1=0$ but $\tau_{\rm all}=q-1=\Theta(N/\log N)$. At every SAT base of Hamming weight two, $\tau_1=\tau_{\rm all}=q$.
\end{theorem}
\begin{proof}
The source pivots force $x=b$. An induction over gate equations gives $c_i^{(j)}=1$ iff the prefix contains at least $j$ ones. The final conditions are satisfiable exactly at weight two. There are one initial forced-zero gadget, two final gadgets, two forced-zero gadgets per selector, one selector pivot and five gates per selector, giving $n=3+q(3+4+5\cdot3)+4$ and $m=4+q(8+1+5\cdot5)+8$.
At $0^q$ all single-bit flips have weight one and are UNSAT, so $\tau_1=0$. All $\binom q2$ double flips have weight two and are SAT; they change exactly the corresponding two disjoint pivot signed-bit coordinates. A hitting set meeting all two-element subsets has size $q-1$, and selecting any $q-1$ pivots is sufficient on the restricted image. At a weight-two SAT base every one-coordinate change goes to weight one or three, making all $q$ coordinates necessary.
\end{proof}
