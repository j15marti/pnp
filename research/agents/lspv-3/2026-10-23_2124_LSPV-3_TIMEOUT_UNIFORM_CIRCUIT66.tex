\section{Theorem: total bounded-run circuit extraction}
For fixed $A$, $N$ and time cutoff $t$, define $H_{A,N,t}(x)$ as the predicate that $A$ halts within $t$ transitions and $B_{A,N,t}(x)$ as halts-and-accepts within $t$.

\begin{theorem}[PROVED/EXACT, uniform timeout staticization]
There is a deterministic uniform compiler that emits a NAND2 circuit $C_{A,N,t}$ such that for all binary $x$ of length $N$,
\[
C_{A,N,t}(x)=(H_{A,N,t}(x),B_{A,N,t}(x)).
\]
For $g=O_A((t+1)(N+2t+3))$, the circuit has at most $g$ NAND2 gates and $2g$ directed gate-input references; its binary description length is $O_A(g\log(g+2))$. The compiler takes $O_A(g)$ word operations of width $W=\Theta(\log(g+N+2))$ and $O_A(g)$ stored words. Timeouts yield $(0,0)$ rather than an asserted SAT/UNSAT label.
\end{theorem}
\begin{proof}
Encode each tape symbol and optional marked finite-control state in a finite per-cell alphabet $\Sigma=\Gamma\cup(Q\times\Gamma)$. In a legal configuration exactly one cell is marked. The new state of cell $j$ depends on the preceding three cells $j-1,j,j+1$ because the head writes locally and moves at most one cell. The local transition is a fixed Boolean function $\Phi_A:\Sigma^3\to\Sigma$ and can be compiled to $O_A(1)$ NAND2 gates per cell. An initial $N$-bit input and a run of at most $t$ steps occupy at most $N+2t+3$ padded tape cells. Initialize from named input wires, unroll $t$ layers, and OR the marked absorbing halt and accept states over final cells. Induction on time proves exactness for every input. The number of local gates is $O_A(t(N+2t+3)+N)$, with two input references per gate. Outputting each gate reference needs $O(\log(g+2))$ bits; a layer-wise generator is uniform and charges all written gates. No SAT label or proof system is assumed.
\end{proof}

\begin{theorem}[Conditional bridge with exact quantifiers]
If some exact deterministic SAT machine has $T_A^{\max}(N)\le N^c$ on all sufficiently large lengths, choosing cutoff $t=N^{\lceil c\rceil+1}$ yields a polynomial-time uniform, polynomial-size unrestricted NAND2 circuit family deciding the \emph{entire} proper-3SAT Boolean function at every length. Conversely a polynomial-time uniform generator of polynomial-size circuits for this function yields a polynomial-time SAT decider. Thus the resulting uniform-circuit existence condition is equivalent to $P=NP$.
\end{theorem}
\begin{proof}The bounded-run theorem yields an accepting output on every input once the cutoff dominates worst-case time. Conversely generate the stated circuit and evaluate it on the input in polynomial time. Proper 3SAT is NP-complete. \end{proof}

A short execution on a single Tseitin input cannot be promoted into a circuit for all SAT inputs of that length. A time-bounded circuit will emit timeout on inputs whose runtime exceeds the cutoff. Similarly, an exponential regular-resolution or full-DNNF lower bound on Tseitin does not constrain unrestricted NAND2 circuits that may implement Gaussian elimination. General nonuniform SAT-circuit superpolynomial lower bounds would imply $NP\not\subseteq P/\mathrm{poly}$, stronger than $P\ne NP$. Pippenger and Fischer established a sharper $O(t\log t)$ network simulation for the specified one-dimensional-tape model; the $O(t^2)$ local unrolling here is independently proved and does not borrow its precise constants.
