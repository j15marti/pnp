\noindent\textbf{PROVED/EXACT, restricted source-probe theorem; independent referee pending.}
A single deterministic planner finds a globally minimum-cost reusable set of materialized parity probes for an arbitrary announced batch of linear questions when their source masks are laminar. This extends the one-target policy174 to unrestricted batch rank and size without a $2^k$ factor. It does not imply a polynomial general SAT algorithm. Both P=NP and P$\ne$NP remain OPEN.

\section{Explicit two-stage model and exact theorem}
Fix a public family $\mathcal L$ of nonempty masks of $[m]$, including all singletons. It is laminar when every two masks are disjoint or nested. A physical source has unknown $\theta\in\F^m$ and explicitly \emph{materialized} parity cells $p_S=\bigoplus_{i\in S}\theta_i$ at public indexed addresses; probing $p_S$ has declared positive integer price $w_S$. The batch of $k$ public target rows $W\in\F^{k\times m}$ is announced before continuation. Output $W\theta$ must be exact for every possible source. Multiple targets share each acquired source cell. Other representations, adaptive choices, memoization, original-coordinate reads, and polynomial workspace are allowed, but unlisted parity probes are not free primitives. Public masks, prices, targets, addresses, and source cells are charged in physical input length $N$.
Let $c_i=W_{*,i}\in\F^k$ and let $\mathcal C=\{0,c_1,\ldots,c_m\}$, so $|\mathcal C|\le m+1$. Build the laminar inclusion tree; insert the full-set root if missing, marking that synthetic mask unavailable. Add a virtual parent of the root fixed at label $0$. For every node $u$ use a label $a_u\in\F^k$, with singleton leaf $a_{\{i\}}=c_i$. If the root was artificial, require its label to equal its parent, namely zero.
\begin{theorem}[Optimal reusable batch parity policy]
There is one uniform deterministic polynomial-time planner returning a verified source-mask set $J$ such that $\sum_{u\in J}w_u$ is the exact minimum paid probe cost over \emph{all} deterministic data-dependent adaptive controllers computing the full batch correctly for every $\theta$. The optimum equals
\[
 \min_a\sum_{u\ {\rm available}}w_u\mathbf1[a_u\ne a_{\mathrm{parent}(u)}],
 \qquad a_{\{i\}}=c_i,\quad a_{\rm virtual}=0,
\]
and an optimum always exists with every internal label in $\mathcal C$. Define $D_i(a)=w_i\mathbf1[a\ne c_i]$ on singleton leaves. For any real internal node,
\[
 G_u(b)=\sum_{v\in\mathrm{child}(u)}D_v(b),\qquad
 D_u(a)=\min_{b\in\mathcal C}\{G_u(b)+w_u\mathbf1[b\ne a]\}.
\]
For an artificial root use $D_u(0)=G_u(0)$. The answer is $D_{\rm root}(0)$. The explicit laminar check, inclusion tree and DP use $O(M^2m+Mm^2\mathrm{poly}(k,\log w_{\max},\log N))$ bit operations conservatively for $M=|\mathcal L|$, plus the separately paid selected source service $\sum_{J}w_u$ and polynomial coefficient verification and output. If $w_{\max}\le N^c$ for a fixed $c$, total time and simultaneous peak workspace are polynomial.
\end{theorem}
\begin{proof}
For a set $J$ whose span contains each target row, bundle the representation coefficients of mask $u$ across all $k$ rows as $z_u\in\F^k$ (zero if unused). Correctness for all sources is equivalent to $c_i=\bigoplus_{u\ni i}z_u$ for each original coordinate $i$. Since the masks are laminar, set $a_u=\bigoplus_{v\text{ ancestor of }u,\;v\text{ incl. }u}z_v$ from a virtual zero label. Then $z_u=a_u\oplus a_{\mathrm{parent}(u)}$ and $a_{\{i\}}=c_i$. A source probe is needed exactly when $z_u\ne0$, and its value may serve any number of rows. Thus the coefficient representation problem is precisely the displayed weighted tree minimum-change labeling problem.

It suffices to use the labels in $\mathcal C$, regardless of $k$. In any feasible labeling, recolor \emph{every} nonterminal node bearing a label outside $\mathcal C$ to $0\in\mathcal C$. Every edge with two endpoints outside $\mathcal C$ becomes equality, never increasing its change cost. Every edge with exactly one endpoint outside $\mathcal C$ was previously unequal and remains either unequal or equal; its cost cannot increase. All pinned leaves and the virtual root already have labels in $\mathcal C$. Hence an optimum has labels in this alphabet of cardinality at most $m+1$. The displayed finite-state bottom-up recurrence, traceback, and direct parity-mask checks construct the optimal certificate uniformly.

For any exact deterministic adaptive controller, fix an arbitrary terminating transcript on $\theta$ and let $V$ be the span of probed source masks. If some target row $t$ is not in $V$, linear duality supplies $d\in V^\perp$ with $t\cdot d=1$. The alternate physical source $\theta+d$ produces the same observed parity at every address and therefore the exact same adaptive transcript and output, but the correct target bit differs. Contradiction. Thus every terminal transcript spans the entire target row space and pays at least the minimum representation price. The static DP plan attains that price on every source, so even data-dependent adaptive or randomized-choice-free switching cannot lower it.
\end{proof}

\section{Information value and a fully charged ledger}
Set $R=\operatorname{rowspan}(W)$, authenticated observation span $V(s)$ and
\[
 \Phi_W(s)=\dim R-\dim(R\cap V(s)).
\]
This is a separately defined polynomial-valued integer in $[0,\operatorname{rank}W]$, not a renamed optimal SAT runtime. For certified $p_S$, use the requested notation $p_S\mid_{v_\Phi}$ with contextual decrease $v_\Phi(p_S\mid s)=\Phi_W(s)-\Phi_W(s\!+\!p_S)\in\{0,1\}$. Two half-XOR shares of the target $1111$ have initial scores $0,0$ and a second-share score $1$ after acquiring the first; for two independent half-parity targets both first scores are $1$. Duplicate shares have score $0$. Separately, $v^{net}=v_\Phi-\lambda w_S$ may be negative (a unit-price zero-gain share has net $-1$ for $\lambda=1$); it is not negative entropy. An expensive direct-answer mask can have rank gain one and cost $K$, while two zero-initial-rank-gain shares cost two. Initial values are not additive; score discovery and witness acquisition must be charged.

From the verified fixed optimal plan $J$, positive prices imply a linearly independent minimal mask set with $|J|\le m$. Define the second, independent \emph{execution account} $\Omega(s)=\sum_{u\in J\mathrm{\ unread}}w_u$. Each selected paid read decreases $\Omega$ by exactly its source latency. Rank potential $\Phi$ may remain unchanged across early useful probes; it does not pay for them. Complete RAM runtime is plan recognition, tree building, DP comparisons, backtracking, mask correctness checks, address calculation, all paid source reads, caching, XOR reconstruction and final output. A nonlaminar menu is rejected by a single charged recognition pass, followed by the correct (not generally optimum) singleton fallback. Peak bits may be bounded by $O(M|\mathcal C|(k+\log(w_{\max}+1))+Mm+mk+N)$. Single-machine communication rounds are inapplicable ($R_{\rm comm}=0$); a distributed one-request batch requires address bits and one response with $|J|$ observed source bits. Physical one-tape head crossings are not a RAM primitive; straightforward full-scan simulation gives a polynomial upper bound, with no machine-independent crossing or memory-change lower bound. RAM word writes and cumulative changed bits are at most word width times charged work.

When raw $\theta$ rather than materialized views is provided, construction of all view cells costs at most $O(\sum_{S\in\mathcal L}|S|)$ read/XOR operations and $L=M$ persisted parity bits, plus metadata. Retaining the original $\theta$ ($L=m$) is always legal and often cheaper. The exact SAT embedding $A_\theta(X)=\bigwedge_i(x_i=\theta_i)$, $B_{t,z}(X)=[t\cdot X=z]$ yields $\mathrm{SAT}(A_\theta\land B_{t,z})\Leftrightarrow t\cdot\theta=z$, where XOR predicates may be compiled to a polynomial-size circuit/CNF. An actual full SAT witness requires access to all of $\theta$, not a free answer bit. There is no general SAT hardness or detached-summary lower-bound transfer.
