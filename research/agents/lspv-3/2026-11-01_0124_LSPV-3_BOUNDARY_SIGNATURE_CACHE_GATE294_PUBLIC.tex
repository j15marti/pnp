\section{Known FPT continuation and exact boundary}
For unsigned positive/negative source triple sets $P,Q$, put $H=P\cap Q$, $r=m-2|H|$ (the unpaired original clauses) and $B=\bigcup_{T\in H}T$. The paired supports impose $\operatorname{NAE}(x_i,x_j,x_k)$, i.e., $1\le x_i+x_j+x_k\le2$. Select one true signed literal from every unpaired clause, at most $3^r$ choices; contradictory pin choices are discarded. If a paired support has $a_T$ pinned ones and $f_T$ unpinned variables, its selected-degree interval is
\[
\max\{0,1-a_T\}\le d_{\rm selected}(T)\le\min\{f_T,2-a_T\}.
\]
Every remaining variable occurs in at most two paired supports, so it is a graph edge, with a private leaf for an incidence-one variable. Classical degree-interval graph factor algorithms (Gabow 1983) decide and construct this residual in polynomial time. BLOSSOM-FACTOR60 and DUALPAIR61 already provided this continuation, so the $3^r$ theorem is NOT claimed new here.
\begin{theorem}[Exact source-preserving boundary-key cache]
Let $p,q$ be coherent selected-literal partial assignments satisfying every original unpaired clause through their selected literals. If $p|_B=q|_B$ as \emph{ternary} partial maps, including which source variables are unassigned, their paired-core degree-interval factor problems have identical feasibility labels. A feasible paired-core assignment can be reused with either branch's own pins on variables outside $B$ to produce its respective complete original-source SAT witness, after filling remaining free variables. An infeasible paired core excludes both original-variable cubes.
\end{theorem}
\begin{proof}
Every paired constraint uses only variables in $B$ and depends on a partial assignment only through its restriction to $B$. Hence both factor instances have identical constraints and feasible sets on $B$. Chosen unpaired literals remain true independently under each branch, and no additional unpaired clause needs to be enforced by the factor. Extending outside $B$ with each branch's separate pins preserves both types of source clauses. A purported model for either branch when its paired factor is infeasible would restrict to a feasible factor, contradiction.
\end{proof}
At most $\min(3^r,3^{|B|})$ distinct factor signatures arise. Caching $M$ explicit signatures with witnesses uses conservatively $O(Mn\log(n+2))$ bits and costs all source lookup, policy-selection, cache and replay operations. A no-cache version needs only polynomial factor workspace but may repeat $3^r$ polynomial computations. This is a standard projection/memoization principle, not a priority claim for a general complexity result.
