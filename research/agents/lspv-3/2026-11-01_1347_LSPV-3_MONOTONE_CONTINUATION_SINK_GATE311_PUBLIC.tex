\section{Minimal decision automaton for monotone strengthening}
The legal event alphabet is $\mathcal A_t=\{\operatorname{ADD}\beta_i,\operatorname{ADD}\sigma_i:1\le i\le t\}$. ADD sets the specified zero bit to one, is idempotent on a one, and never deletes any pin. The decision-only online machine answers after each event. Histories are equivalent if *every common future ADD-event word* gives the same sequence of SAT/UNSAT decisions, with no rereadable external pin array or event history.
\begin{theorem}
For every $t\ge1$, the exact number of reachable Myhill--Nerode continuation classes is
\[
\boxed{K_t=3^t+1.}
\]
The $3^t$ conflict-free vectors with per-coordinate states $00,10,01$ are all pairwise inequivalent. Every already-conflicting vector belongs to one absorbing UNSAT class. Two distinct currently SAT vectors are distinguished by \emph{one} common ADD event. Hence any deterministic exact quiescent representation in the specified no-reread model has at least
\[
\boxed{\left\lceil\log_2(3^t+1)\right\rceil}
\]
bits of total retained configuration information. This is not an unconditional native indexed read-only-input FLMV space lower bound.
\end{theorem}
\begin{proof}
Equation (1) makes any coordinate $11$ permanently UNSAT under ADD-only updates, so all $4^t-3^t$ such states are future-equivalent. Every pair of distinct safe vectors differs at coordinate $i$. The pairs $00/10$, $00/01$, and $10/01$ are separated respectively by ADD $\sigma_i$, ADD $\beta_i$, and ADD $\sigma_i$, while all other coordinates remain safe; hence the resulting decisions differ. Each safe vector is reachable by setting its one-bits from the empty profile, and the sink by adding both bits at one coordinate. Therefore these and only these $3^t+1$ classes occur. Counting distinguishable quiescent states gives the bit floor independently of pin-value recovery.
\end{proof}
\begin{lemma}
For effective ADDs on one history,
$\Phi=2t-\sum_i(\beta_i+\sigma_i)$ is a nonnegative integer that strictly decreases. At most $2t$ distinct ADD events can change a bit before the terminal UNSAT sink or full profile saturation. An exact implementation retains $2t$ profile bits and a conflict flag, requiring $O(1)$ indexed-word work per update and $O(r)$ total for $r$ events, including repeated idempotent events. Thus exponential quotient cardinality does not imply an exponential length for one actual execution.
\end{lemma}
\begin{proof}
Each effective ADD changes exactly one previously zero bit to one and lowers $\Phi$ by one. No event removes a bit. Once both bits of one coordinate are one, the UNSAT answer persists. The implementation checks the paired bit on each event and sets an absorbing conflict flag as needed. Every received command still incurs read/address work.
\end{proof}
