\section{Exact universal configuration-to-BP extraction}
Consider one fixed deterministic bit-query machine $A$ on a read-only $N$-bit input. A microstep reads at most one indexed bit or performs a source-independent instruction. Count work contents, program counter, all head positions, input addresses, caches, timers and other live machine state in a configuration code of $s$ bits. Every input read has unit cost in this \emph{indexed-bit} model; any word operation must be separately converted and charged. Fix cutoff $t$. A timeout is not classified as UNSAT.

\begin{theorem}[State-width extraction, PROVED/EXACT within model]
A uniform external compiler produces a three-output $(\mathsf{SAT},\mathsf{UNSAT},\mathsf{TIMEOUT})$ layered deterministic \emph{read-many} branching program $B_{A,N,t,s}$ that agrees with $A$ on every input of length $N$ through step $t$. Its node count is at most
\[
 (t+1)2^s+3,\qquad \text{its nonterminal arcs at most }2t2^s. \tag{2}
\]
The compiler takes $O_A(t2^s\operatorname{poly}(s+\log(N+t+2)))$ bit time and writes
\[
 O_A(t2^s(s+\log(N+t+2))) \tag{3}
\]
bits of graph encoding. It requires no actual input data during construction and can stream output using polynomial space in $s+\log(N+t+2)$ when one machine transition is locally computable.
\end{theorem}
\begin{proof}
At level $j\in\{0,\ldots,t\}$ create a node $(j,c)$ for each of the at most $2^s$ configuration codes. Label a source-read node by its requested input index and connect the two outgoing arcs to the exact configurations reached after reading zero and one. At a source-independent instruction both arcs go to the same successor. Make halting states absorbing and place the appropriate terminal result or timeout after the cutoff. Induction on $j$ shows the reached node has exactly the deterministic state of $A$ on the same $N$-bit source after $j$ microsteps, including repeated reads, recomputation, DAG reuse and arbitrary internal algorithmic choices. Enumerating layers and explicitly writing both successors proves the bounds. The compiler is \emph{external}; a one-bit SAT decider does not construct this graph.
\end{proof}

\begin{theorem}[Sharp generic time-only method ceiling]
If $B(N)$ is any \emph{unrestricted read-many} branching-program size lower bound for the same length-$N$ language, a decider with $t$ steps and $s$ configuration bits must satisfy
\[
 s+\log_2(t+1)\ge\log_2(B(N)-3). \tag{4}
\]
But every Boolean function on $N$ bits has a deterministic branching program of size at most $2^{N+1}+1$ (the full binary input decision tree). Thus $\log B(N)\le N+O(1)$. On a fixed-alphabet bit machine that can touch at most $O(t)$ new work cells in $t$ steps, $s\le O_A(t+\log(N+t+2))$. Consequently Equation (4), \emph{used alone with no independent space restriction}, can force at most an input-order $\Omega(N)$-scale running-time conclusion. In particular it cannot by itself prove $t=\omega(N)$ or $t=N^{\omega(1)}$ for SAT.
\end{theorem}
\begin{proof}
The first inequality is immediate from (2). A complete depth-$N$ decision tree has $2^N-1$ query nodes and at most $2^N$ leaves, which may be merged into two terminal nodes. The binary logarithm of any general branching-program size lower bound is therefore at most $N+O(1)$. As work and input-address state are fully accounted and no step can activate more than a constant number of new bit cells, substituting $s=O_A(t+\log(N+t))$ into (4) shows the \emph{particular size-transfer inequality} has no forcing capacity beyond input order. This ceiling applies to the argument, not to all possible lower-bound techniques.
\end{proof}
A lower bound for OBDDs, DNNF, resolution, read-once or bounded-pass programs cannot replace $B(N)$ in (4). The extracted program reads source bits in arbitrary order, possibly multiple times. General Boolean \emph{circuit} size has a different relationship to machine time, as TIMEOUT66 explicitly records; that remains a more appropriate unrestricted time route, but its required SAT lower bound is \OPEN.

\section{Independent signed-NAE token audit and exact width boundary}
Let $q$ signed NAE clauses contain at least three \emph{distinct} variables apiece, with each original variable occurring in at most two clauses. A clause is BAD iff all its signed literals have identical truth values.
\begin{theorem}[Arity-variable signed-NAE repair, PROVED/EXACT restricted]
For all such sources, a uniform deterministic token walk produces a satisfying original-variable assignment with at most $q^2$ flips, $O(L+q^2+n)$ word time and $O(L+n)$ working words, where $L$ is the number of literal occurrences. At width two, the same unconditional satisfiability assertion fails.
\end{theorem}
\begin{proof}
Start at any BAD clause; flip a variable other than the one through which its BAD token arrived. This repairs the clause. Only one other clause can change, because that variable occurs at most twice. If it becomes BAD, transfer the token to it; otherwise terminate the walk. Intermediate moves conserve the BAD count and terminating moves reduce it.

For nonrepetition, assume a first return to a previously repaired clause $C$. Immediately after $C$ was repaired, exactly the flipped departure literal was the minority among its at least three literals. Flipping any different single literal later leaves the departure minority and at least one unflipped majority literal, so cannot make $C$ BAD. The only possible first BAD return must flip that same departure variable again. Its only other incident clause is the immediate successor on the token path; that successor cannot depart along the incoming variable on its first visit and cannot do so subsequently without an earlier repeated clause. Contradiction. Each walk visits at most $q$ clauses and at most $q$ walks terminate. Maintain literal true-counts and incidence lists for constant-time flips after source parsing. In contrast, the width-two source
$\operatorname{NAE}(x,y)\wedge\operatorname{NAE}(y,z)\wedge\operatorname{NAE}(z,x)$ is an odd cycle of inequalities and is UNSAT, with every variable appearing twice.
\end{proof}
This independently validates Role 2's ternary token repair in its declared promise and extends its \emph{explicit trace argument} to mixed arity at least three. Broader tractability is previously known (Porschen--Speckenmeyer, 2007; Darmann--D\"ocker, 2020). If Role 2's source-certified complementary-pair extraction has $t_\pm=0$, every original CNF clause belongs to one NAE pair, so its constructed witness satisfies the \emph{unchanged} signed formula. No such claim holds at arbitrary $t_\pm>0$. Role 4's EULER65 signing algorithm instead deliberately changes the source signs and may change UNSAT to SAT, so it is not a label-preserving SAT reduction.
