\section{Exact theorem}
Let $F$ be an arbitrary valid source on $n$ variables and $m=4n/3$ clauses. Fix any coherent original-variable partial assignment pinning $a$ variables TRUE and $b$ FALSE; put $t=a+b$, $f=n-t$. Let $c_+,c_-$ count \emph{covered original} positive and negative clauses and $u=m-c_+-c_-$. For each free original variable $x$, let $s_x^\pm$ count its positive/negative signed occurrences within covered clauses; define $\eta=\sum_x\min(s_x^+,s_x^-)$.
Let $\nu$ count \emph{any} authenticated original-clause-ID-edge-disjoint family of odd binary-clause cycles in the uncovered residual, and set $\delta=2f-u-\eta-\nu$. No satisfiability, unit-propagation or nonempty-residual hypothesis is assumed.

\begin{theorem}[Polarity-resolved saturation gate]
Write
\[
D(a,b)=\max\left\{0,\left\lceil\frac{2a}{3}\right\rceil-2b,
\left\lceil\frac{2b}{3}\right\rceil-2a\right\}.
\]
Then every such source, pin and certified cycle family obey
\[
\boxed{\quad
\delta\ge\frac{2n}{3}-2t-\left\lfloor\frac{2t}{3}\right\rfloor
+|c_+-c_-|
\ge\frac{2n}{3}-2t-\left\lfloor\frac{2t}{3}\right\rfloor+D(a,b).
\quad}
\tag{304.1}
\]
Consequently a $\delta=0$ terminal is inaccessible unless
$2t+\lfloor2t/3\rfloor\ge2n/3+|c_+-c_-|$.
For one-sided pins (only TRUE or only FALSE),
\[
\boxed{\delta\ge\frac{2n}{3}-2t+
\left\lceil\frac{2t}{3}\right\rceil-
\left\lfloor\frac{2t}{3}\right\rfloor.}
\tag{304.2}
\]
Therefore one-sided paths need $t\ge n/3$ before saturation, and equality $t=n/3$ is also excluded whenever $3\nmid t$.
\end{theorem}
\begin{proof}
The $a$ pinned TRUE variables supply exactly $2a$ TRUE positive occurrences, all within covered positive clauses, hence
$\lceil2a/3\rceil\le c_+\le2a$. Likewise
$\lceil2b/3\rceil\le c_-\le2b$.
A covered clause has an assigned TRUE literal, leaving at most two free occurrences, so $h_+=\sum_xs_x^+\le2c_+$ and $h_-=\sum_xs_x^-\le2c_-$. It follows that
\[
\eta\le\min(h_+,h_-)\le2\min(c_+,c_-)
\quad\Longrightarrow\quad c_++c_--\eta\ge|c_+-c_-|.
\]
Every uncovered original binary clause consumes a distinct FALSE pinned signed occurrence. Each pinned variable has exactly two FALSE signed occurrences, so at most $2t$ uncovered binary clause IDs exist. Every edge-disjoint odd cycle consumes at least three different IDs, implying $\nu\le\lfloor2t/3\rfloor$ (the previously established LSPV-4 PIN-CYCLE-TICKET305 lemma). Since
$\delta=2n/3-2t+c_++c_--\eta-\nu$, the first inequality follows. The bounds on $c_\pm$ imply $|c_+-c_-|\ge D(a,b)$, proving the second inequality. With all pins of one value, only one clause polarity is covered and $\eta=0$, so $|c_+-c_-|=c\ge\lceil2t/3\rceil$, giving (304.2). A single pin covers exactly two same-sign clauses, produces only two uncovered binary clauses, and has $\eta=\nu=0$, so $\delta=2n/3$ identically.
\end{proof}
