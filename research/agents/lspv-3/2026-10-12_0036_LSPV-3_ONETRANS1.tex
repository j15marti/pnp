\section*{Executive result}

\st{PROVED/EXACT} (independent review pending): a deterministic black-box
interaction with a deterministic one-bit SAT decider has one transcript after
the source, extractor coins, and query policy are fixed.  Replaying the same
interaction cannot create the two accepting, same-commitment,
different-challenge transcripts required by special soundness.  A fork must
instead vary an external challenge/query, inspect implementation internals, or
change the source.  Those options respectively require a new interactive
compiler, violate black-box SAME\_REALIZATION, or violate same-source binding.
Thus \texttt{ONEBIT-SPECIAL-SOUNDNESS-TRANSFER1} is
\st{FALSIFIED/RETIRED} in its unqualified form.  This does not refute a future
source-matched interactive compiler.  That compiler remains \st{OPEN}, and P
versus NP remains open.

\section*{Exact theorem}

Let $A:\{0,1\}^*\to\{0,1\}$ be deterministic.  Let $E$ be a deterministic
oracle transducer after fixing source $F$, auxiliary input $a$, and coins
$\rho$.  Its transcript is
\[
 T(E,A;F,a,\rho)=
 (q_1,A(q_1),\ldots,q_s,A(q_s),z),
\]
where every next query and the final output are deterministic functions of the
fixed data and preceding query-answer pairs.

\paragraph{Theorem (fixed-replay uniqueness).}
For every $E,A,F,a,\rho$, the transcript $T(E,A;F,a,\rho)$ is unique.  Rewinding
and replaying from the same fixed state yields exactly the same transcript.

\paragraph{Proof.}
Induct on the oracle-call index.  Before the first call all fixed data agree,
so determinism gives the same $q_1$; determinism of $A$ gives the same answer.
If the first $i$ query-answer pairs agree, determinism of $E$ gives the same
$q_{i+1}$ and determinism of $A$ gives the same answer.  The halting decision
and final output therefore also agree. \hfill$\square$

\paragraph{Fork trilemma.}
Suppose two putative transcripts have the same commitment prefix but distinct
challenges.  By the theorem, they cannot both arise from fixed replay.  At
least one of the following must hold:
\begin{enumerate}
\item the extractor varies external coins/challenge/query, so the fork is
created by the extractor/compiler rather than forced by the one-bit decider;
\item the source or address changes, so the transcripts do not satisfy the
same-source premise;
\item the procedure reads or controls internal machine state, so it is
non-black-box and must survive DEAD/COPY/DELAY/INTERP/RECOMP covariance.
\end{enumerate}
This is exhaustive under the declared deterministic oracle interface.

\paragraph{Extensional corollary.}
All correct exact SAT deciders implement the same Boolean oracle.  Hence a
black-box transcript with fixed $E,F,a,\rho$ is independent of which correct
implementation is installed.  It can establish a source/extractor property,
not an implementation-specific exposure or cost, unless an additional charged
realization theorem is supplied.

\section*{Why cryptographic special soundness does not transfer directly}

In a standard $\Sigma$-protocol the prover first sends a commitment, the
verifier then sends a fresh challenge, and special soundness assumes two
accepting conversations with the same commitment and different challenges.
The theorem above does not dispute that cryptographic definition.  It shows
that a static deterministic one-bit SAT decision interface does not provide
its interactive premise.  Forking-lemma analyses explicitly rerun while
changing random-oracle/challenge behavior; that is an extractor-controlled
fork, not a theorem that a deterministic SAT decider exposes two openings.
Cryptographic hardness, random-oracle programmability, and collapse binding
remain inadmissible in an unconditional P-versus-NP proof.

\section*{Hostile controls and exact limits}

Horn, 2SAT, affine/Tseitin Gaussian-elimination, bounded-treewidth, independent
product, padding, redundant clauses, and alternative encoding controls do not
repair the missing interactive premise.  They may change the query language
or make the source easy, but a deterministic reply to an identical query
remains identical.  Wrapper variants can change arbitrarily much internal
trace while leaving the black-box transcript fixed.  A maximal semantic SAT
oracle makes this point exact; an algebraic oracle can only add source-derived
answers and still does not force an implementation-specific opening.

The theorem does \emph{not} say that no interactive proof can be compiled from
SAT.  It says such an interface is an added construction, not a free property
of an arbitrary one-bit decider.  Its complete costs and its relation to the
original static execution must be proved.

\section*{P=NP and exponent audit}

Assume SAT$\in P$ and let $A$ be any polynomial SAT decider.  The fixed-replay
theorem still holds, and a recognize-first or direct source algorithm may emit
only the answer bit.  A polynomial-time verifier relation for enriched
openings can itself be searched via SAT self-reduction under P$=$NP, so
canonicalizing one opening produces no contradiction.  Conversely, obtaining
two openings by running $A$ on distinct challenge-derived formulas incurs the
unknown exponent of $A$ at their actual sizes unless an exponent-independent
compiler theorem removes it.  Neither branch supplies an unconditional
model-matched contradiction.

\section*{STALE OR OVERSTATED CLAIMS FOUND}

Any text treating ``two conflicting openings'' as automatically available
from black-box replay of an arbitrary deterministic SAT decider is overstated.
Special soundness is a conditional extraction theorem once two appropriate
transcripts exist; it is not an acquisition theorem for those transcripts.
Likewise, external challenge diversity must not be charged as internal solver
state or as evidence of two solver-produced openings.

\section*{Smallest repair and handoff}

Define a source compiler $C$ and verifier $V$ with explicit transcript syntax
$(F,c,e,z)$ and prove all of the following on one realization:
\begin{enumerate}
\item $c$ is fixed before an independently selected challenge $e$;
\item for two challenges $e\ne e'$, both replies $z,z'$ are compelled by the
same arbitrary SAT execution or by a charged model-preserving simulation;
\item $V(F,c,e,z)=V(F,c,e',z')=1$ and $(e,z)\not\sim(e',z')$ imply an explicit
unconditionally forbidden object;
\item acquisition, challenge generation, rewind/replay, query construction,
normalization, validation, output, time, and workspace are fully charged;
\item the theorem survives one-bit output, alternative encodings, wrappers,
semantic/algebraic oracles, arbitrary polynomial exponents, relativization,
and algebrization audits.
\end{enumerate}
Absent this package, semantic-opening binding remains \st{OPEN}.
