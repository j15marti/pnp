\section{Maximum-defect factor family}
Let $G=(B_L\sqcup B_R,E)$ be any connected \emph{simple} four-regular bipartite graph with $r\ge4$ vertices in each part. Hall's theorem permits a decomposition into four disjoint perfect matchings $M_1,\dots,M_4$. Put $E_+=M_1\cup M_2$ and $E_-=M_3\cup M_4$, each a spanning two-factor with $2r$ edges. Introduce $r$ fresh original source names $A=\{a_1,\dots,a_r\}$. Independently pair the $2r$ edges of each signed factor, labelling the two edges in each pair by one $a_i$. For each $\{u,v\}\in E_+$ labelled $a_i$ add $(a_i\vee u\vee v)$; for each $\{u,v\}\in E_-$ labelled $a_i$ add $(\neg a_i\vee\neg u\vee\neg v)$. Denote the resulting \emph{ordinary source formula} by $F(G)$.

\begin{theorem}[Exact target grammar, complete boundary and easy decision]
For every $G$ above, $F(G)\in\CS$ is connected, has
\[
k=3r,\quad m=4r,\quad |P\cap Q|=0,\quad q=2r=2k/3,
\]
and satisfies the source-named projection
\[
Q_G(a)=\left[\exists b\in\{0,1\}^{2r}\,F(G)(a,b)\right]\equiv1
\quad\text{for every }a\in\{0,1\}^r.
\]
All $2^r$ boundary words are feasible, with an exact constant-true predicate.
\end{theorem}
\begin{proof}
Every $B$ vertex lies on exactly two edges per signed factor and hence occurs twice per literal polarity. The pairing gives every $a_i$ exactly two uses per sign. The $A$ names are distinct from all $B$ names, each graph edge has distinct endpoints, and the four matching edge sets are disjoint. Therefore clauses are proper, unique and pure-signed; opposite-sign clauses cannot have identical unsigned triples. The original variable co-occurrence graph contains $G$, so it is connected.

Set every $B_L$ variable to one and every $B_R$ variable to zero. Every edge crosses this bipartition, so every positive clause has a true $B_L$ literal and every negative clause has a true negated $B_R$ literal. This works independently of all $A$ values. Alternatively, $A=1$, $B=0$ is a direct satisfying certificate. These are paid source-readable algorithms, not free semantic SAT bits.
\end{proof}

A uniform total SAT decider can grammar-check its input, test a canonical three-block template (every clause has exactly one $A$ variable and two $B$ variables), and replay the $A=1,B=0$ witness. For inputs that pass, a repeated-scan validator can be implemented in polynomial bit work with $O(\log N)$ writable index/counter bits. For nonmatching ordinary SAT inputs, a separately charged exhaustive exact fallback keeps the machine correct, with no claimed polynomial worst-case bound. After \emph{any} $A$ pinning, the residual source constraints are 2-CNF on $B$; SCC yields another exact polynomial method, and the same bipartition certifies feasibility.
