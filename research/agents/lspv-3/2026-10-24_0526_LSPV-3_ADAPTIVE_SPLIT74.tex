\section{Declared source, model, and actual adaptive state}
Let $q\ge1$, $b\in\{0,1\}^q$, and let $F_b$ be Role~4's
fixed-width implication-chain 2-CNF with variables
$z_0,\dots,z_q,u,v$, four endpoint clauses
\[
(z_0\vee u)\wedge(z_0\vee\neg u)\wedge
(\neg z_q\vee v)\wedge(\neg z_q\vee\neg v)
\]
and $C_i=(\neg z_{i-1}\vee z_i)$ for $b_i=1$,
$C_i=(\neg z_{i-1}\vee\neg z_i)$ for $b_i=0$.
Then $n_F=q+3,\;m_F=q+4$. The two endpoint pairs force
$z_0=1,z_q=0$. Thus
\[
\operatorname{SAT}(F_b)=1\quad\Longleftrightarrow\quad b\ne1^q.
\tag{1}
\]
The addressable word encoding uses two header words and four words per
clause, each $w=\lceil\log_2(64(n_F+m_F+1))\rceil$ bits:
$N_F=(4q+18)w=\Theta(q\log(q+2))$.
A changed orientation occupies its own signed-literal field.
A complete grammar/template scan, including all headers and literal
identifiers, costs $O(q)$ word operations on a word-RAM with
$w=\Theta(\log N_F)$, addressed input and unit-cost $w$-bit operations.
This scan is charged even when the answer is subsequently immediate.
For bit-level single-tape access, simulate the scan with polynomial
bit-time overhead rather than silently treating a word as a bit.

The adaptive program state contains
$(\text{template-valid},\,b_1,\,i,\,\text{seen-zero},\,
\text{current-mode},\,\text{search-index},\,\text{cached source})$.
The parameters $q$, number of source variables, template grammar
and orientation bits are defined from the input, independently of its
runtime. At the initial state $d=0$, so the \emph{syntactic}
$r=n_F-d=q+3$ and $r/\log N_F\to\infty$.
The running policy can transition from template inspection to a
one-bit shortcut, a scan for the next zero, or exhaustive search.
It need not know the SAT label before choosing the rule.

\section{Exact complementary-hardness theorem}
Define two \emph{total uniform exact} CNF deciders $A_L,A_R$.
Both fully recognize the canonical family; on nonmembers both use
a complete deterministic exhaustive assignment search.
On members, $A_L$ returns SAT when $b_1=0$, and otherwise invokes
exhaustive search in lexicographic order on
$(z_0,\ldots,z_q,u,v)$ with $0$ before $1$.
On members, $A_R$ returns SAT iff some $b_i=0$ when $b_1=1$;
when $b_1=0$ it uses the identical exhaustive search.
Each algorithm is exact on every input because every shortcut is
correct by (1), and the fallbacks are exact.

\begin{theorem}[PROVED/EXACT, complementary hard sets]
For \emph{every} $q\ge1$ and \emph{every} $b\in\{0,1\}^q$,
one of $A_L,A_R$ decides $F_b$ after $O(q)$ word operations,
and the other tries at least $2^{q+2}$ complete candidate
assignments before termination. In fact
\[
\max\{T_{A_L}(F_b),T_{A_R}(F_b)\}\ge 2^{q+2},
\qquad
\min\{T_{A_L}(F_b),T_{A_R}(F_b)\}=O(q).
\tag{2}
\]
Both algorithms separately have $2^{\Omega(q)}$ worst-case
running time on the \emph{same} family, yet a single total exact
state-dependent chooser decides all of it in $O(q)$ word operations.
The family includes SAT and UNSAT inputs for every $q$.
\end{theorem}
\begin{proof}
The endpoint clauses enforce $z_0=1$ for every satisfying assignment.
Lexicographic exhaustive search tests all $2^{n_F-1}=2^{q+2}$
assignments with $z_0=0$ before a possible model. On an
UNSAT input it tests all $2^{q+3}$. If $b_1=0$, the first algorithm
is fast and the second slow; if $b_1=1$, their roles reverse.
All claimed branch outputs are correct by (1). Each is total on
nonmembers by its exact fallback. The chooser validates the source,
reads $b_1$, invokes the corresponding fast branch, and returns its
answer; the source validation and any scan for a zero take $O(q)$.
For each $q$, the all-one UNSAT input forces $A_L$ into complete
enumeration; the all-zero SAT input forces $A_R$ past the first
$2^{q+2}$ candidates. Both labels occur.
\end{proof}
\noindent\textbf{Logical scope.} The arbitrary-machine separation target
requires $\forall A\;\forall c\;\forall N_0\;\exists F$ that is slow
for the \emph{fixed} $A$. It cannot be obtained by demonstrating
$\forall i\;\exists F_i$ slow for separately chosen finite policies
and assuming a common $F$. Equation (2) is a falsification of that
\emph{combination inference}, not a claim that SAT is in P.
The family is a polynomial-time recognizable 2-CNF promise.

\begin{lemma}[PROVED/EXACT, admitted adaptive policy closure]
Given fixed $h$ total deterministic exact deciders of the same encoded
language in a checkpointable unit-cost indexed-step model, a fair
round-robin simulator is exact and halts in at most
$h\min_i T_i(F)+O(h)$ guest steps, with live memory bounded by
the sum of its simulated configurations plus scheduling state.
It can use different SAT-side and UNSAT-side certificate mechanisms,
since it does not need to predict the correct label.
\end{lemma}
\begin{proof}
In each complete round, every constituent receives one step.
After $h t$ guest steps each constituent has executed at least $t$
steps. The first to halt is correct. Saving $h$ complete states
bounds the live storage. On a physical interpreter, its instruction
dispatch, snapshots, source access and word-address overhead must
be added; this is not an unqualified $h$-factor machine-independent
time bound.
\end{proof}
This is the known MAIN101 portfolio mechanism specialized to
state-dependent certificate races, not a new universal fastest algorithm.

\begin{array}{rcl}

\end{array}
\tag{3}
\]

and all eight selector choices for a local priority gadget:
there is one extension iff at least one literal is true, and it
selects the first true literal. This verifies the local semantic
hinge, not the full published compiler implementation.

recognizer (Role~4). Composing that inverse with the adaptive chooser

has no positive superlinear remainder from the inherited $q$-field

\section{Proof spine, transfer classification and handoff}
The root decision has only SAT/UNSAT, even where full contextual
functions or solution histories distinguish exponentially many
objects. The proof spine remains
\[
\boxed{\text{source-defined obstruction}}
\ \underset{\mathrm{OPEN}}{\Longrightarrow}\
\boxed{\text{necessary charged work for each adaptive policy}}
\ \underset{\mathrm{OPEN}}{\Longrightarrow}\
\boxed{\text{coverage of every total uniform exact decider}}
\Longrightarrow \boxed{P\ne NP}.
\]
The strongest corrected universal target must quantify over
\emph{all computable adaptive policies}, including portfolios and
a changing vector of independent parameters, and prove an
unavoidable superpolynomial charged cost on a decider-dependent
growing input family. Merely proving each fixed rule has some
hard input is insufficient. Both SAT-side and UNSAT-side rules
may be run without advance label knowledge, with all attempts
and simultaneous live states charged.

\noindent\textbf{ADOPTED:} role-4 chain and priority-Horn semantics,
MAIN101 portfolio minimum, roles 2--3 original source/repair
firewalls, root85 two-label quotient, model-conserving
construction/output ledgers.
\textbf{RETIRED:} universal inference from one static parameter,
unique auxiliary witness, low-degree SOS obstruction, or
individually slow fixed rules to mandatory general SAT time.
\textbf{WHAT CHANGED RELATIVE TO ROOT MAIN:} an explicit
opposite-hardness \emph{same-input-family} counterexample,
with the parameters changing after source reads and exact
two-label controls; all previously proved restricted findings
retain their original scope.
\textbf{STALE/OVERSTATED CLAIMS:} none of these finite or family
results proves the universal separation; the priority-Horn
inverse for the \emph{full} compiler is imported rather than
independently reimplemented in this audit.
\textbf{CROSS-DOMAIN:} portfolio scheduling transfers exactly
to checkpointable guest-step machines; empirical SATzilla is
an analogy for practical selection, not a machine lower bound;
proof-complexity/coding/PQ-cryptographic structures have no
validated unrestricted-time transport here.
