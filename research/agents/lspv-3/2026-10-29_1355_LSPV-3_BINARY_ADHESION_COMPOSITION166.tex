\noindent\textbf{Status: RESTRICTED PROVED/EXACT, independent mathematical referee pending.}
We prove a sharpened sufficient theorem beyond FULL-INTERFACE-COMPOSITION165.
The supplied decomposition may have unbounded total shared interface at a node;
\emph{every edge intersection} need only have two variables. This is not an
unrestricted-SAT theorem and neither $P=NP$ nor $P\ne NP$ is resolved.
The result is a closure-based reformulation of familiar 2CNF and tree-DP facts,
not a claim of a novel general complexity separation.

\section{PROPOSE: one missing lemma and falsifiable alternatives}
\begin{description}
\item[]\textbf{M1: complete-interface enumeration is always necessary.}
FALSIFIED for the class below: instead of tabulating all assignments to the
union of child interfaces, insert each exact unary/binary child relation as
\emph{at most four ordinary 2CNF clauses} into the parent's locally tractable
formula. Even a star with $m$ separate two-bit child adhesions needs only
$O(m)$ derived clauses and a constant number of parent solver calls.
\item[]\textbf{M2: arbitrary branching with adhesive arity at most two closes
under local 2CNF plus bounded affine codimension.}
PROVED/EXACT, with polynomial source authentication, gluing, witness
reconstruction, and replayable negative table checks under the precise
hypotheses of Theorem~\ref{thm:binary}.
\item[]\textbf{M3: the same 2CNF-composition rule automatically extends to
three-port messages.}
FALSIFIED by the two children $a\oplus b\oplus c=0$ and
$a\oplus b\oplus c=1$. Their true join is empty, but both have
\emph{tautological} unary/binary projection consequences; replacing each by
its 2CNF closure incorrectly accepts.
\item[]\textbf{M4: the theorem provides a polynomial compiler from arbitrary
strict exact-(2,2)-3SAT.}
OPEN. An explicit finite-template strict22 chain satisfies the bounded-local
variant, but recognition of a suitable tree, conversion of arbitrary 3CNF
modules into tractable factors, and unbounded root-class coverage are not
proved. No branch assumes a hidden SAT decider.
\end{description}

\section{FORMALIZE: source-owned running-intersection trees}
Let a deterministic parser receive an encoded CNF/affine source $F$ and a
rooted tree $T$ of $q\le\operatorname{poly}(N)$ bags $V_t$. The parser must
authenticate every original source ID exactly once, assign each constraint to
a bag containing all its variables, reject duplicated, missing or fabricated
constraints, and verify the \emph{running-intersection} condition:
$\{t:x\in V_t\}$ induces a connected subtree for each variable $x$.
Write $S_t=V_t\cap V_{\mathrm{parent}(t)}$, with $S_{\rm root}=\varnothing$.
Unlike the previous report, the \emph{full union}
$B_t=\bigcup_{u\sim t}(V_t\cap V_u)$ may be arbitrarily large.

Each local conjunction $L_t$ is a recognized 2CNF $C_t$ plus an explicitly
authenticated GF(2) affine system $A_t$ of rank at most $e_t$. All source
costs, complete bags, and local equations are explicitly encoded: no
succinct pointer grants free source reconstruction. Let
\[ K_e(M)=M^{O(e)}\operatorname{poly}(M) \]
denote a deterministic sound complete local decision/witness procedure for
2CNF plus rank-$e$ affine constraints, with every failed call charged. The
uniform codimension bound $e_t\le e_0$ is for an \emph{absolute constant}
$e_0$. This work implements $e_0=1$ directly, and uses the published theorem
for general fixed $e_0$.

\begin{lemma}[Complete description of every binary Boolean relation]
\label{lem:binary}
For $|S|\le2$ and $R\subseteq\{0,1\}^{S}$, define
\[
 C_R=\bigwedge_{a\in\{0,1\}^S\setminus R}
       \left(\bigvee_{x\in S} \begin{cases}x,&a_x=0,\\\neg x,&a_x=1.\end{cases}\right).
\]
If $S=\varnothing$ and $R=\varnothing$, this is the empty clause.
Then the model set of $C_R$ on $S$ is exactly $R$ and $C_R$ has at most
$2^{|S|}\le4$ clauses, each of width at most two.
\end{lemma}
\begin{proof}
A clause indexed by $a$ is false on exactly $a$. Thus the conjunction
excludes every and only forbidden assignment, including the zero-variable
case. Every source bit appearing in $S$ is preserved; no missing-interface
variables are silently quantified away.
\end{proof}

\begin{theorem}[Branching exact-summary composition with binary adhesions]
\label{thm:binary}
For every explicitly presented source instance with the verified tree above,
if $|S_t|\le2$ on every edge and each $L_t$ is 2CNF plus an affine system of
rank $e_t$, then one deterministic, state-dependent uniform algorithm produces
an exact feasibility table $M_t\subseteq\{0,1\}^{S_t}$ for every node,
decides both SAT and UNSAT, and reconstructs a checked global assignment
whenever one exists. A valid negative result has a source-authenticated,
polynomially replayable table computation. If source parsing, tree discovery
and checking cost $D(N)$, the total deterministic time obeys
\[
 \boxed{T(N)\ \le\ D(N)+\operatorname{poly}(N)
             \sum_{t\in T}2^{|S_t|}(|V_t|+1)^{O(e_t)}.}
\]
No factor $2^{|B_t|}$ appears. With polynomial $D(N)$, a polynomial number
of explicit bags, and fixed $e_t\le e_0$, this recognized class is in $P$,
\emph{even when $|B_t|=\Theta(N^\alpha)$} at some nodes.
\end{theorem}
\begin{proof}
Orient the tree toward the root. Assume child messages $M_c$ have been
computed exactly. For every child $c$ of $t$, replace its relation by the
2CNF $C_{M_c}$ from Lemma~\ref{lem:binary}, on the \emph{complete} separator
$S_c\subseteq V_t$. Define
\[
 H_t(X_{V_t})=L_t(X_{V_t})\wedge
              \bigwedge_{c\in\mathrm{child}(t)}C_{M_c}(X_{S_c}).
\]
This remains 2CNF plus the original local affine system. For each of at most
four assignments $a$ to $S_t$, pin $X_{S_t}=a$ and invoke the deterministic
local solver on $H_t$. Record $a$ in $M_t$ exactly when the solver returns YES,
with one verified local assignment and the child separator projections needed
for reconstruction. Pinning fixed coordinates substitutes constants into the
existing affine equations; its residual rank is no larger than $e_t$.
The 2CNF part remains width at most two. Thus the local solver hypotheses
continue to hold even with arbitrarily many child messages.

For soundness, take a recorded local solution, and recursively join its child
witnesses on each complete separator. Running intersection guarantees that
an assignment chosen in two subtrees can disagree only on a variable also
present in their common ancestor, where both are forced to the same value.
All source constraints are thereby satisfied. For completeness, take an
arbitrary global satisfying assignment and restrict it to $V_t$. By the
inductive child-message hypothesis, every child separator tuple lies in its
exact table, so this local restriction satisfies $H_t$. It is accepted by the
complete local solver for its parent signature. This proves by induction that
$M_t$ is precisely the existential projection of the entire subtree onto
$S_t$; the root accepts iff $()\in M_{\rm root}$.

Parsing and running-intersection verification take polynomial time on an
explicit tree. At most $4q$ local calls, at most $4(q-1)$ derived child
clauses, and at most $4q$ table entries are constructed. Storing a local
witness per positive entry costs $O(\sum_t4|V_t|\log N)$ bits, and the full
source and auxiliary working storage are polynomial. All unsuccessful
calls, failed local 2SAT tests, compatibility lookups, and reconstruction
work are included in the displayed bound. For NO, source-authenticated
entries and absence records can be checked by polynomial-time \emph{replay}
of the deterministic local decision routine. This is not an assertion that
an ordinary-Resolution or LRAT refutation always has polynomial length.
\end{proof}

\begin{corollary}[General locally stable languages]
The theorem remains true when the local system is any polynomially solvable
language closed under adjoining arbitrary 2CNF clauses, provided all
required local solutions are constructible and each failed query is certified
by polynomial deterministic replay. In particular, local bags of an absolute
constant size $d$ can contain arbitrary proper 3CNF constraints and use
$2^d\operatorname{poly}(N)$ brute force without a hidden global SAT solver.
\end{corollary}

\begin{proposition}[Beyond two ports, a precise additional promise]
If each edge has size $O(\log N)$, the same algorithm remains polynomial on
a \emph{verified} subclass in which every exact child projection is a
bijunctive (majority-closed) relation. Enumerate the polynomial-size child
table, test agreement with all unary and binary consequences, and compile
those consequences as a 2CNF. A failure is reported as a recognition GAP,
not treated as UNSAT. No automatic bijunctivity claim holds at arity three.
\end{proposition}
\begin{proof}
For a relation $R\subseteq\{0,1\}^S$, the conjunction of all forbidden
unary/binary tuples agrees with $R$ exactly when $R$ is 2-decomposable, which
for Boolean relations is equivalent to majority closure. Enumeration and
checking cost $2^{O(|S|)}\operatorname{poly}(N)$, polynomial if
$|S|=O(\log N)$; the parent formula remains in the locally tractable class.
Without the successful equivalence check the construction does not use the
approximate 2CNF. This extension is a conditional structural theorem, not
a discovery algorithm for arbitrary large interfaces \cite{schaefer1978}.
\end{proof}

\section{BUILD: sharpness and hostile controls}
\begin{proposition}[Three-bit parity makes a false positive]
Take root bag $\{a,b,c\}$ with no constraints. Attach two children each
sharing all three variables. One child owns $a\oplus b\oplus c=0$, the
other owns $a\oplus b\oplus c=1$. Every unary/binary tuple extends to
a solution of either child, so both strongest 2CNF consequence sets are
$\top$. Their true relational conjunction is empty. Treating these
three-port messages as 2CNF would therefore report SAT incorrectly. The
exact arity-two closure in Lemma~\ref{lem:binary} cannot be naively
extended to arity three.
\end{proposition}

\begin{proposition}[Unbounded center interface is still easy]
For every $m$, a star with center bag $\{a_i,b_i:1\le i\le m\}$, and
leaf $i$ sharing $\{a_i,b_i\}$, has $|B_{\rm center}|=2m$. The leaf
owns an XOR parity $a_i\oplus b_i\oplus w_i=0$ and unit $\neg w_i$;
its exact projection is $a_i=b_i$, represented by two binary clauses.
The center owns the $2m$ positive units $a_i,b_i$. The instance is SAT;
flipping one center unit to $\neg b_1$ gives an UNSAT partner. A single
additional center parity provides a separate local $e=1$ control.
The algorithm invokes at most $4m+1$ local calls, while the earlier
\emph{full-union enumerator} would attempt $2^{2m}$ center assignments.
Neither count lower-bounds other SAT algorithms.
\end{proposition}

\paragraph{Signed exact-$(2,2)$ finite-template control.}
We independently reconstructed SOURCE-RUP-CHAIN164's signed 15-variable,
20-ternary-clause gadget $G$. For $k$ copies joined by exactly one prescribed
negative occurrence swap per adjacency, every original root has $15k$
variables and $20k$ clauses, is connected, has three distinct literals per
clause, and has two occurrences of each sign at every variable. Give bag
$i$ its own 15 variables plus the neighboring copies' designated $x_4$
variables. The bag width is at most 17; each adhesion has size exactly two;
all source clauses are assigned once. Hence this is an unbounded connected
strict22 subclass handled by the bounded-bag corollary. An unpinned root is
SAT in the tested cases. For the ordinary cofactors pinning the three exposed
variables of each module to tuple $t=1$, equal modes are SAT and mixed modes
are UNSAT, as checked by the exact DP. \emph{The pinned cofactors are not
strict22 roots and are not counted as such.} Arbitrary strict22 inputs do not
arrive with this decomposition or fixed source modules, and no universal
coverage conclusion follows.

\paragraph{Model-specific accounting.}
Let $P(N)$ denote the polynomial source/annotation parsing, table, 2SAT,
fixed-codimension solver, failed-call, and witness work on an indexed word RAM
with $O(\log N)$-bit words. Total RAM instructions, accessed words,
intermediate storage, and complete output are polynomial. A fixed two-tape
read-only-input/work-tape deterministic implementation can simulate explicit
RAM addresses by sequential scans with polynomial overhead, counting input
movement, work-cell writes, and peak work space. A fixed one-tape machine
additionally counts its initial input footprint and all head crossings, with
another polynomial standard simulation overhead. A fixed universal machine
simulates each specified fixed program with charged polynomial overhead.
No numeric tape exponent is asserted without an explicit simulation bound;
no tape communication lower bound transfers to unrestricted RAM. On both
answer sides, one program discovers the answer and constructs or replays
all necessary table decisions, rather than receiving a free label bit.

\section{Open boundary and next role-owned lemma}
\textbf{PROVED/EXACT, restricted:} exact child-message composition with binary
adhesions removes the $2^{|B_t|}$ enumeration requirement while preserving
SAT/UNSAT completeness, authenticated source IDs, witnesses and
polynomial replay. \textbf{FALSIFIED/RETIRED:} per-node full-interface size
is necessary for this particular class; and three-port parity automatically
admits exact 2CNF compression. \textbf{OPEN:} finding/recognizing these
decompositions on arbitrary strict22 roots, handling non-bijunctive
three-port messages at many joins without superpolynomial growth, polynomial
ordinary source-Resolution certificates for all UNSAT inputs, all-instance
single-child contraction, and either resolution of P versus NP.

connected, strict exact22} root family with both answer classes, whose

whether non-bijunctive three-port joins can be avoided by an adaptive
