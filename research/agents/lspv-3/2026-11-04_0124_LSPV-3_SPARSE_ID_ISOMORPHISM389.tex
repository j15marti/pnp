\section*{Published hardness, exact model and input encoding}
Haken (1985) proves that for the standard unary $\mathrm{PHP}_{h+1}^h$ with $h(h+1)$ variables and $(h+1)+h\binom{h+1}{2}$ clauses, constants $c>0,h_0$ exist such that for every $h\ge h_0$ and \emph{every} ordinary shared-DAG Resolution refutation $\pi$, $|\pi|\ge 2^{ch}$. Its explicit indexed signed DIMACS source has $N_h=\Theta(h^3\log h)$ bits. Cook (1976) gives polynomial Extended Resolution proofs for the same family. Braun (arXiv:2609.23015, September 2026) reports that for $n=2^\ell,\ell\ge32$ every extension-free unrestricted DAG Res$(\oplus)$ bit-PHP refutation has more than $\exp(n/(32768\ell^2))$ line nodes. That CNF has $n\binom{n+1}{2}$ clauses of width $2\ell$ and $\Theta(n^3\ell^2)$ fully indexed bits. Braun's preprint is not independently formalization-replayed here. Neither lower bound extends automatically to the combined calculus, conservative extensions, or arbitrary uniform SAT deciders. Our earlier LSPV-3/346 already provided full polynomial mixed-system bit-PHP proof certificates.

\begin{lemma}[Signed source-name equivariance]
Under a bijective renaming of original variable names respecting original-versus-auxiliary types, signed occurrence polarities and source-clause IDs, every legal shared $R_{\mathrm{mix341}}$ DAG translates nodewise to a legal DAG of identical paid-node count, and conversely. Thus $W_R(\sigma F)=W_R(F)$ for all UNSAT $F$. Machine bit costs may differ because the textual identifiers have different lengths.
\end{lemma}
\begin{proof} Signed RES pivots, GF(2) coefficient masks, original-support cardinalities, each exact truth-vector and implication check, and conservative fresh-gate definitions are invariant under a bijective symbol relabeling. Preserve every parent pointer and shared node, and rename all new gates freshly. Apply the inverse renaming for the reverse inequality. No SAT-label oracle or hidden proof step is used.\end{proof}

\begin{theorem}[Sparse-header exact minimum and encoding separation]
For each $d\ge4$, let $a_d=10^d$ and take the valid signed source $F_d=(x_{a_d})\wedge(\neg x_{a_d})$, with declared DIMACS header maximum $a_d$ and exactly two source clauses. Then
\[
\boxed{W_{R_{\mathrm{mix341}}}(F_d)=1,\quad N_d=\Theta(d)\ {\rm bits},\quad a_d=2^{\Theta(N_d)}.}
\]
The signed unlabeled hypergraph consists of the same two opposed singleton edges for all $d$; both individual source deletions and both single-literal sign reversals produce SAT controls.
\end{theorem}
\begin{proof} One genuine strict signed RES pivot derives the empty clause. No original source is empty, so zero paid derivation nodes cannot refute. The three copies of the decimal $(d+1)$-digit name (header, positive literal, negative literal) plus fixed syntax occupy $\Theta(d)$ bytes; $10^d=2^{\Theta(d)}$. The one-vertex two-edge incidence graph is unchanged under bijective renaming. Removing or reversing one unit leaves a satisfying Boolean assignment. This does not imply anything about arbitrary machine runtime.\end{proof}

\section*{Correction to a bounded-payload node-to-evidence theorem}
LSPV-4/342 correctly states a quadratic proof-bit bound under explicit bounded-line evidence, but its proof uses $n\le N$ for a DIMACS header maximum $n$, which is false on $F_d$. LSPV-4/359 already identified this same sparse-header pitfall for a naive QBF-query compiler; it is prior work, not newly discovered here. The appropriate count is the number $r\le N$ of \emph{appearing} original variable names.

\begin{lemma}[Explicit bounded-payload proof-local dictionary]
For a preexisting $q$-node proof in the bounded-payload fragment $R_{\mathrm{bp}}\subseteq R_{\mathrm{mix341}}$, where every output is an explicit clause, GF(2) row, at-most-three-original-variable factor or one paid fan-in-two gate with its defining views, and no node smuggles an unbounded circuit payload, the \emph{same} source-authenticated proof admits a dictionary serialization of $O((N+q+2)^2)$ bits, regardless of the declared header maximum.
\end{lemma}
\begin{proof}
Every source name has a first literal-token position in the original $N$-bit input, so $r\le N$. Each paid bounded-payload node can introduce only $O(1)$ fresh names; write $v\le r+cq$ for the entire proof's active names. A source-name dictionary stores input offsets in $O(r\log(N+2))$ bits; give newly used names canonical proof-local numbers with explicit original/auxiliary type and freshness checks. Each derived clause needs two $v$-bit signed-presence masks; each affine row needs $v+1$ bits; each local factor has three $O(\log v)$-bit IDs and eight truth bits; each DEF has bounded gate tags and three IDs. Add at most two antecedent references per node. Total source plus dictionary and $q$ records is $O(N+r\log(N+2)+q(v+\log(N+q+2)))=O((N+q+2)^2)$. Check every dictionary reference and derived record explicitly to preserve original signed semantics. Construction and checking take polynomial \emph{bit time in the serialized evidence}, not in the logical node count alone.
\end{proof}
\noindent\textbf{Scope limitation.} LSPV-4/363 and LSPV-5/315 previously warned about a circuit-valued LOCAL-CONVERT syntax U with arbitrarily long uncharged interior gate lists. No quadratic evidence bound for \emph{that} interpretation follows, and the exact original circuit payload syntax still requires authentication. Polynomial evidence does not imply a polynomial-time proof finder or B3.
