## Source-derived exact identity

For the fixed target R(x,y) iff y-x belongs to {1,3} modulo 5, authenticate the original directed graph. Opposed arcs and self-loops imply zero colorings. Let c be the number of weak components, t=n-c the number of selected forest arcs, and q=m-t the number of remaining arcs. Each forest edge has a binary increment b_j. Each actual chord imposes

    a_i + sum_j C_ij b_j in {1,3} (mod 5).

Here a_i and C_ij are exactly computed from directed forest paths, accounting for reversed arcs. Let zeta be a primitive fifth root of unity and define

    psi_i(xi_i) = zeta^(xi_i*(a_i-1)) + zeta^(xi_i*(a_i-3)),
    phi_j(xi) = 1 + zeta^(sum_i C_ij*xi_i).

An exact character-orthogonality expansion gives, for every original graph,

    Z(G) = (5^c/5^q) sum_{xi in F5^q} prod_i psi_i(xi_i) prod_j phi_j(xi).

All calculations are exact in Z[zeta]/(1+zeta+zeta^2+zeta^3+zeta^4), using four arbitrary-precision integer coefficients, and the final numerator is divisible by 5^q. This is an application of standard finite-group Fourier methods, not a new general harmonic-analysis result.

## New parameter: dual forest-overlap width

Construct a factor graph with one variable per chord. The unary psi_i factor has one variable; phi_j touches only chords i for which C_ij is nonzero. Join any two chords appearing in the same forest column. Compute the induced width by deterministic min-fill. Both source-derived BFS and DFS forests are considered; choose the candidate with smaller *certified* width w. This is not a claim of optimality over all forests.

Variable elimination over the exact cyclotomic ring computes Z(G) with conservative simultaneous bounds on one deterministic sequential tape:

    T(N) = O((N+1)^14 * 5^(2(w+1))),
    S_peak(N) = O((N+1)^6 * 5^(w+1)) bits.

The charged implementation includes graph authentication and access, both forest discoveries, min-fill search including failed candidates, all factor tables, sequential scans for indexed table access, source addresses, exact coefficient arithmetic, divisibility tests, and full output. Every intermediate factor has at most 5^(w+1) entries. Python reference execution uses dictionaries; the sequential-tape bound is symbolic, not a native TM microcode benchmark. For constant achieved w, counting is polynomial time and writable space even for linearly many independent chord constraints.

## Infinite-family result: forest choice changes width by a linear factor

Let P_k contain vertices v_0,...,v_{k+1}, forward arcs v_i->v_{i+1} (0<=i<=k), and backward two-step arcs v_{i+2}->v_i (0<=i<k). Then n=k+2, m=2k+1, q=k. Legal successive forward increments in {1,3} are forbidden to contain the adjacent pair (3,3); therefore

    Z(P_k) = 5*F_(k+3), F_0=0, F_1=1.

The deterministic DFS forest follows the backbone; each factor overlaps only its neighboring chord, giving w_DFS=1 for k>=2. BFS splits into even/odd root chains; every remaining forward chord joins the two branches and its fundamental path traverses both root tree edges, so all chord pairs overlap: w_BFS=k-1.

For k=100 the original graph has 102 vertices and 201 arcs, with q=rho=100, BFS width 99 and DFS width 1, and exact original-coloring count

    7502602681034480416385.

This falsifies interpreting the width of an arbitrary chosen cycle representation as an inherent lower bound on deterministic computation. It also strictly improves the *constructive upper bound* from /083's balanced 5^(1.5*rho) rank factor on this particular family. It is NOT a lower bound on the old method.

A second control is a chain of r directed triangles touching at a single vertex each: n=2r+1, m=3r, q=r, w=0 and Z=5*3^r. For r=101 the exact count is 7730662810980169965546916946484319090531612830015.
