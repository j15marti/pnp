## Exact signature theorem

A directed **module** M is a subset such that every outside vertex has the same ordered pair (outside-to-member, member-to-outside) of adjacency bits for every member. Internal edges inside M are unrestricted.

For any represented block B, define \`F_B(S)\` to be the number of genuine source colorings of B that respect all its internal arcs and use **exactly** the nonempty target-color subset S. For a quotient of represented blocks with uniform complete directed external arcs or no external arcs, its exact union-support count satisfies

\[
F(U)=\sum_{\substack{S_i\ne\varnothing\\\cup_iS_i=U}}
\left(\prod_i F_{B_i}(S_i)\right)
\left(\prod_{i\to j}[S_i\times S_j\subseteq R]\right).
\]

This is an identity on original assignments. Every original coloring induces exactly one support tuple and exactly one internal coloring counted by the corresponding product.

A proper module can be found **without an oracle**. For every vertex pair u,v, initialize M={u,v} and repeatedly add each external vertex distinguishing any pair already in M by directed adjacency. The fixed point is the least module containing u and v; every proper nontrivial module contains a pair whose closure is a proper subset. Pair searching and closures take at most O(n^4) adjacency queries per call; the complete source is already authenticated.

## Strengthening the five-state alphabet: exactly ten possible incident supports

Every target color a has outneighbors a+{1,3} and inneighbors a+{2,4} mod 5. Both are two-element pairs of difference ±2. Consequently, if an exact-support block is incident to any complete uniform quotient edge, its support must belong to the set

\[
\mathcal S_{10}=
\{\{a\}:a\in\mathbb Z_5\}\cup
\{\{a,a+2\}:a\in\mathbb Z_5\}.
\]

Proof: for an outgoing edge to any nonempty target block, all colors in the block must be among the two inneighbors of any target color. For an incoming edge, use the two outneighbors of any external source color. Therefore no three-color support and no adjacent-pair support can extend across an edge. All ten masks have a possible singleton external partner. This sharpens /070's **15** validly enumerated candidate supports to **10** for every nonisolated independent-twin class. Two two-color supports cannot be adjacent. This is upper-bound pruning only.

## Infinite positive witness not handled efficiently by the prior parameter bounds

For L>=4 take one center c and a zigzag path of L vertices v_0,...,v_{L-1}. Add c->v_i for all i and orient path edges from each even-index vertex to its odd-index neighbor. The path is an internally edged directed module, not an independent twin class.

For a fixed center color a, every path vertex lies in {a+1,a+3}. Since a+3 beats a+1, all even-index vertices must be a+3 and all odd-index vertices a+1. Thus exactly one path assignment per a:

\[
\boxed{Z(G_L)=5,\qquad n=L+1,\qquad m=2L-1,\qquad r=L-1.}
\]

Its path-interior vertices have underlying degree three (two path edges plus one center arc), so the 2-core high-degree parameter is Omega(L), while ordinary independent-twin count grows with L. Our module+path solver discovers one proper module and uses two path-DP leaves, with no nonpath prime node, so \(\kappa=0\) and polynomial physical time. The family is easy; it disproves a **necessary** exponential-work inference from those other structural parameters alone.
