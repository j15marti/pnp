## 3. Qualified fixed total machine and all-length cost bound
Define XOR3 as proper 3-CNFs whose clauses can be partitioned by **unordered sets of three distinct source variable identifiers**, each group containing *exactly four distinct clauses* representing one of the two parity equations over those variables. Allow arbitrary intersections, repeated occurrence of a variable across groups, and disconnected incidence structures.

The fixed total deterministic decider A_GF2 parses the exact source input (strict binary-encoded signed-decimal ternary-clause stream), rejects malformed byte grammar by the input convention, groups the authenticated clauses by their source identifiers, tests the exact four forbidding sign patterns for each triple, *densely renumbers the distinct observed identifiers*, and Gaussian-eliminates the corresponding GF(2) rows. If any valid input fails this special-source test, it exhaustively searches the **original formula**. Both labels are correct on all encoded inputs. No graph, charge, parity label or lookup table is supplied by advice.

**Theorem A (PROVED/RESTRICTED).** On every F in XOR3 with encoded length L, one fixed finite-alphabet multitape realization of A_GF2 takes O((L+1)^8) physical transitions, with O((L+1)^2) visited writable cells, counting parsing, index sorting, heads, row storage, all bit-XOR updates, rereads and output. Off class the fallback is exponential.

**Proof.** Each certified four-clause group is logically equivalent to the corresponding GF(2) linear equation. There are at most O(L) clauses and O(L) distinct source variables, even if the *numerical values* of their IDs are huge. Every source ID has O(L) bits. Pairwise source-name/triple matching involves O(L^2) comparisons of O(L) bits. Store at most O(L) rows of at most O(L) bits, i.e. O(L^2) writable cells. Up to O(L^2) Gaussian pivot/elimination operations each manipulate no more than O(L) bits. An explicit constant-tape implementation using repeated scans and at most O(L^3) physical head work per high-level comparison, row access or update, with O(L^3) such tasks including parsing/control, satisfies the intentionally loose O((L+1)^8) time bound and O((L+1)^2) workspace. Gaussian consistency is exact. A fixed exhaustive fallback makes the decider correct and total on all other inputs. No unit-cost unbounded-word operation is assumed. QED.

**Concrete cost falsifier and repair:** If one indexes a bitset directly at raw input variable ID v, a formula with identifiers 2^110+3, 2^110+99 and 2^110+431 induces an astronomically large allocated word despite a short input. This naive representation is **FALSIFIED** for bit-cost soundness. The executed independent program compresses IDs to the contiguous index set [0,v_distinct-1] before creating any row mask; row width stays O(L). The source variable-ID magnitude is never an allocation dimension.

The hard-for-Resolution cubic odd-charge expander F_H belongs to XOR3, hence A_GF2 decides it in polynomial physical work. That does **not** imply general 3-SAT is polynomial.
