## Interface and costs

An authenticated input parser accepts x in a declared language, rejects malformed inputs, and computes b,B,K and the candidate-index grammar at paid setup time A(N)+P(N), peak writable s_A(N)+s_P(N). The source is an ordinary read-only, locally moving input tape. G(x,c,h,j) yields the claimed active b-cell block identifier for tape h during time block j, not a checkpoint value. Its complete physically implemented invocation, including parameter decoding, source seeks, restoration of the simulated input-head location, arithmetic, and any retained generator setup, costs at most tau bit-machine steps and a additional writable bits. No preloaded word, guessed work value or free oracle is allowed. The candidate list is generated by c=1,...,K with O(log K) indices. p is fixed. At least one c equals the canonical actual sequence for the whole run, but all other c may have large arbitrary frontiers. Let

F_j(c)={(h,z_c(h,i)): 0<=i<=j, exists r>j with z_c(h,r)=z_c(h,i)},
w*=max_j |F_j(c_actual)|.

The **same machine** performs a series of capacity thresholds H=0,1,2,4,8,... up to pB. For each H, try candidate c=1,...,K from a freshly reconstructed blank start.

During candidate c at time block j: (1) call G for its p claimed active blocks and compare them with the actual simulated head positions **before** loading contents. A mismatch rejects immediately. (2) Fetch each present block from a sequential cache, or blank on first access, retaining p temporary active b-cell buffers, then simulate all b real finite-machine transitions, checking within-block head movement and source reads. (3) For each active (h,a), scan G(x,c,h,j+1),...,G(x,c,h,B-1) to decide whether a returns. Delete every dead active identity **before** inserting any surviving updated identities. When the insertion would exceed H retained blocks, abort without allocating an (H+1)-st cache block. (4) On a matching complete run, output its actual state/answer.

Importantly, an active buffer and an (H+1)-st attempted insertion are distinct: the procedure can detect the overflow from the scalar cache length before expanding writable storage. The p active buffers are always charged in addition to H cache slots. Work values come only from blank cells, real transitions and retained canonical blocks.

## Theorem and exact prefix invariant (PROVED/EXACT, restricted)

**Theorem.** Under the interface and coverage premise above, this online capacity-doubling procedure outputs the exact authentic Boolean answer. Its first successful threshold H obeys H<=2 max(1,w*), regardless of how large the false candidates' potential frontiers are. The procedure needs no supplied W and never keeps a complete candidate word.

**Proof.** At the beginning of a stage whose declared block indices agree with the genuine head positions, the retained cache and active buffers equal the corresponding canonical work-cell values. This holds initially because all work tapes start blank. If a candidate predicted no later occurrence of an active block after stage i, but the actual machine were to read that block again before any mismatch, the candidate's claimed block index at that later stage would have to equal the same tape/block identity, contradicting the prediction. Therefore deletion based on a false suffix cannot falsify a pre-mismatch work value. After the actual b-step transition, retained updated blocks reproduce all future-needed values. All matching, nonoverflowing candidates therefore have the original unique output; a wrong one either mismatches or overflows.

For the authentic candidate, the cache just after block j is exactly F_j for the genuinely visited blocks, since a block is retained if and only if the true movement word revisits it. Thus its cache size never exceeds w*. At the first threshold H>=w* the authentic candidate is simulated fully and succeeds, unless an earlier fully matching candidate has already returned the same correct output. The threshold list reaches w* no later than the first power of two at least w*, which is <2w* when w*>0; w*=0 succeeds at H=0. Every earlier false attempt has capacity <=this H and uses at most H cache blocks plus p temporary buffers. This proves both exactness and adaptive peak-space bound. The deletion-before-insertion ordering avoids artificial transient overflow. QED.

## Query partition and SAME-run ledger

At each candidate attempt and at each time stage j, exactly at most p active-index queries plus p(B-1-j) future-index queries are issued. No full-width certification pass is needed:

Q_one_candidate <= p B + p sum_(j=0)^(B-1)(B-1-j) = p B(B+1)/2.

Let R=2+ceil(log2(pB+1)) be a safe number of threshold levels. A complete execution, including every failed attempt and repeated input scan, satisfies

Q_G <= R K p B(B+1)/2 = O(K p B^2 log(pB+2)).

Let L=log(t+N+K+2) and H_max<=2 max(1,w*). With a sequential b-cell block dictionary, an explicit (loose) same-machine bound is

T_total = O(A(N)+P(N)+ R K[
     p B^2 (tau+L)
     + t polylog(t+N+2)
     + p B (H_max+p)(b+L)
     + N + (H_max+p)b
   ]),
S_peak = O(s_A+s_P+a+(w*+p)(b+L)+L).

Time partitions: source authentication and generator setup; candidate and threshold control/restart, which charges N for input-head resets; all active-index and future-revisit G calls and ID comparisons; all b-step physical machine transition simulation and input-head movement; sequential dictionary seeks, copies, deletes and insertions; output. No nested call is counted twice as elapsed time. The generator's own local-head seeks/restore and any arithmetic are included in tau. Simulated head coordinate registers, cache indices, input buffers, and the simultaneously live p blocks are covered. The peak is from this SAME execution, not a separate simulator. A network reinterpretation would still charge aggregate live workspace and total sequential work.

At b=Theta(t^(1/3)), fixed p, w*=O(1), polynomial K and tau and suitable authenticated source costs, the result is a conditional **restricted** polynomial-time, O(t^(1/3) polylog(t+N))-space simulation. It does NOT prove w*=O(1) or polynomial K for the actual general HPV/Williams converter; it does NOT implement an improved nonassociative Tree Evaluation evaluator. A separate evaluator requesting Q nodes or checkpoint bits would require its own Q-fold fully charged provider and reconstruction ledger, which remains OPEN. Direct algorithms, caching and source-derived motion remain admitted. The prior O(KpB^3) screen is **not necessary** for safe space even against high-width false candidates.

## Original-input finite witness and independent controls

A fixed source-driven, locally headed **two-work-tape, b=1** test machine accepts authenticated unary-length words 1^B 0 x, where x has B bits. At stage j it reads the current two canonical mutable cells v0,v1, writes v0'=v0 XOR x_j and v1'=v1 XOR v0', toggles an output bit by v1', and moves head 0 right on x_j=1 (otherwise one left unless at the left boundary); head 1 right on x_j=0 (otherwise one left unless at the boundary).
