## Source and one-vertex gluing theorem

The actual source format has header `n m`, a complete explicit roster `V 0 1 ... n-1`, and precisely m ordered endpoint pairs. This supplies N>=n,m for encoded source length N. Invalid roster, endpoints, or token counts are rejected. Duplicate identical arcs are idempotent. Self-loops and opposed directed arcs yield the *correct count zero*, not malformed-input rejection. The empty graph has one coloring.

Let H be the undirected shadow after the zero checks, c its number of connected components (including isolates), and B_1,...,B_q its edge-biconnected blocks (ordinary single-edge bridges are blocks of size 2). Each original directed arc lies in exactly one B_i. For each block, let Z_i be the number of assignments to its own vertices satisfying all original arcs whose endpoints belong to that block. Uniform rotation by t in Z5 carries each block coloring with any designated vertex color a bijectively to a coloring with that designated vertex color a+t. Consequently, the rooted count at ANY selected vertex color is

    M_i = Z_i/5, an exact integer.

The block-cut incidence graph is a forest. Root its component at any original vertex and expose the blocks away from the root. At each attachment the child block shares precisely one already colored cutvertex with the previously exposed part. The number of extensions of that fixed color is M_i and does **not depend on which of the five colors** was fixed. By induction each connected component contributes 5 times the product of its block M_i. Thus the exact all-input identity is

    Z(G) = 5^c * PRODUCT_{i=1}^q M_i.

This holds even with many overlapping articulation interfaces, disconnected inputs, and original arcs oriented in either direction. It is not a general statement for arbitrary non-vertex-transitive templates, pinned-color CSPs, or two-vertex gluing. If some block has zero local count then the global count is zero, as required. Original variables at cutvertices are identified, not duplicated or multiplied independently.

## Constructive local solver

For each block B with b=|V(B)|>=2, select a rooted spanning tree derived by a deterministic paid graph traversal; fix its root's symbol to 0. For every tree edge parent u to child v, make exactly the two choices:
* if the original arc is u->v, x_v=x_u+1 or x_u+3 (mod 5);
* if the original arc is v->u, x_v=x_u+4 or x_u+2 (mod 5).

Each of the 2^(b-1) branch sequences yields a **unique rooted tree-edge-consistent coloring**. Check all original block arcs to accept/reject that candidate. Every rooted satisfying assignment appears exactly once. Hence M_i is computable with at most 2^(b-1) candidate traces, no external oracle, no hidden factor-table storage. The counter is an exact arbitrary-precision binary integer. On forests, each block is a single edge, M_i=2 and Z=5^c 2^(n-c), recovering the earlier forest formula.

## Same-realization physical ledger

The parser scans the complete roster and source, checks n,m and all endpoints, deduplicates arcs, detects prohibited loops/opposed arcs and constructs the undirected shadow. A deterministic iterative DFS computes discovery/low-link numbers and the true block partition, with paid source-index/graph access, stack/cursor storage and edge-to-block ownership verification. For each block, the same machine constructs a rooted tree, streams one binary branch tuple at a time, computes its five-state colors and checks all assigned original directed arcs. It keeps its original source, the graph/blocks, one live color array, path counters, integer accumulator(s), and output tape. No parallel processors, preloaded checkpoint or unaccounted witness are assumed.

With N explicit source bits and b_i vertices per block, a deliberately conservative, simultaneously realizable ordinary multitape bound is

    T(N) = O( (N+1)^8 [1 + SUM_{i=1}^q 2^(b_i-1)] )
    S_peak(N) = O( (N+1)^3 ) bits.

The polynomial factor covers repeated linear-head source traversals, parsing, DFS bookkeeping, all edge checks, address/head motion, retained recursion/stack frames, bounded 3-bit colors, exact O(N)-bit integers, and writing all O(N) output bits. Counting Z cannot exceed 5^n, and every product of local rooted counts is bounded by 5^n, so all intermediate counts have O(N) bits. The number of block vertices counted with overlap is O(N^2) in the worst conservative ledger. All these are charges of ONE particular physical computation. This is an **upper bound**, not a minimum-work lower bound. The optimal block decomposition may be complemented by all previously legal treewidth, affine, twin, module, cover, Fourier and cache-based algorithms.

## Infinite family separating this from previous single-separator bounds

For each r>=1, take r copies of a four-hub, four-sink block. Every three-subset of the four hubs has one genuine private sink, with three original hub->sink arcs. Glue the blocks end-to-end by identifying exactly one hub between consecutive blocks; choose distinct left and right hubs in every intermediate block. Each original block is biconnected on 8 vertices, with 12 arcs; the whole graph has n=7r+1, m=12r, c=1, cycle rank 5r, minimum undirected degree >=3, and r 8-vertex original blocks. A direct local calculation gives rooted count M_i=38 for every block. Hence

    Z(G_r) = 5 * 38^r

exactly. In particular r=40 gives 281 original vertices, 480 arcs, 40 blocks of 8 vertices, and the 64-digit count

    7768083210295556550476299205621213685213818802955603986486394880.
