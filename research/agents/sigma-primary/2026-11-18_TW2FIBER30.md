## EXACT RESTRICTED THEOREM
Phi = EXISTS X FORALL I,B NOT G(X,I,B), with k=ceil(log2 t) selector bits, t<=poly(N) legal branches, b=poly(N) universal seed bits, illegal selector values forcing G=0. Each branch is G_i(X,B)=AND_c [NOT a_ic(X) OR D_ic(B)], where a_ic are arbitrary explicitly readable X-only nonlinear guard circuits and D_ic are normalized arbitrary-width universal clauses (empty allowed). Suppose each branch's universal variable-clause bipartite incidence graph has treewidth <=2.

A uniform deterministic polynomial-time algorithm recognizes width<=2 by repeatedly eliminating a filled-degree<=2 vertex (adding the edge between its neighbors), obtains bags of at most three vertices, verifies bag coverage, edge coverage and running intersection, and builds an X-only bounded-fan-in circuit H(X) satisfying FOR ALL original x: H(x)=EXISTS I,B G(x,I,B). Thus Phi IFF EXISTS X NOT H(X), with the same original X shared across all i. No SAT oracle, UNSAT certificate, or 2^b seed enumeration is needed. This is a source-restricted theorem.

Dynamic state per bag: variable assignment bits plus satisfied-so-far flags for clause vertices. Assign each incidence edge to exactly one containing bag. At child-parent joins, match shared variables, OR clause-satisfaction flags, AND child feasibility, OR over forgotten child-variable assignments, and for each forgotten clause c require NOT a_c(X) OR satisfied_c. State count <=2^(w+1), combination pairs <=2^(2(w+1))=64 per tree edge at w=2. Correctness is bottom-up induction on the partial-fiber invariant. Guard-disabled clauses do not excuse unsatisfied child subtrees. Supplied certificate compilation gate size O(M+SUM_i 64*(b+|C_i|+ell_i)); implemented straightforward decomposition discovery/certification and edge-home scanning are polynomial, conservatively O(M+SUM_i(b+|C_i|+ell_i)^3). Final functional X-only 3CNF serializes to O(S log S) bits.

## NP-HARD GUARD FIREWALL
