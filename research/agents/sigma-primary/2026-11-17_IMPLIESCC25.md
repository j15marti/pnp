## SOURCE-CERTIFIED THEOREM
Let X be n existential bits, I a k=ceil(log2 t)-bit universal selector with t legal values and illegal values G=0, B a b-bit universal challenge. Define
 G(X,I,B)=OR_{i<t} ([I=i] AND P_i(X) AND AND_{j<=c_i} (NOT a_ij(X) OR L_ij,1(B) OR L_ij,2(B))).
Each P_i and a_ij is an arbitrary but explicitly supplied X-only circuit; each guarded residual clause has at most two B literals (unit/empty also allowed). This is syntactically certifiable and does not say the unrestricted source can be transformed cheaply into this syntax.

Construct X-dependent implication adjacency and Boolean Floyd-Warshall reachability on the 2b signed literals. For each branch, let S_i(X) be P_i(X) AND no enabled empty clause AND no signed literal mutually reachable from its negation. By the standard 2SAT SCC criterion, for EVERY original x,
 S_i(x) iff EXISTS B G(x,i,B).
Therefore EXACTLY, candidate by candidate:
 EXISTS X FORALL I,B NOT G(X,I,B)
 iff EXISTS X [AND_{i<t} NOT S_i(X)].
The compiler produces an X-only circuit in O(M+t b^3+t b^2) gates, M including guard and source clause representation. Functional Tseitin yields a 3-CNF with O(S) gates/clauses and O(S log S) serialized bits. The same X enters every branch. No universal challenge enumeration.

The original gate-trace quantifiers remain EXISTS X FORALL I,B EXISTS T [Trace_C AND output_C] until G is eliminated semantically. Only the new X-only circuit trace is existential with X. Early hoisting of original B-dependent T is unsound.

## POLYNOMIAL UNIVERSAL RESPONSE
For each branch, the S_i(X) circuit also allows lexicographic 2SAT witness self-reduction: for j=1..b, test the same guarded 2SAT with earlier chosen bits and B_j=0, choose 0 if possible and 1 otherwise. Unroll these tests into X-only Boolean circuits, with total O(M+t b^4+t b^3) gates. Define f_i(X) as the resulting b-bit response. Then for every x,
 G(x,i,f_i(x)) iff EXISTS B G(x,i,B).
Thus the COVERMITER24 miter is identically UNSAT for this source-certified class by construction; no free SAT/UNSAT oracle is assumed.

## EXPONENTIAL BARRIER FOR CONCRETE CHALLENGES ONLY
For n=b, k=1, t=2, define G_n(X,I,B)=([I=0] AND [B=X]), with branch 1 disabled. This is guarded UNIT CNF in B: for each j the guarded unit clauses X_j => B_j and NOT X_j => NOT B_j. Every x has exactly one counterexample, (I,B)=(0,x), so the QBF is FALSE for every n. One linear response circuit f_0(X)=X suffices; the 2SAT compiler also handles it in polynomial size. But a CEGAR master that adds only concrete challenges NOT G(X,i_j,b_j) excludes at most one candidate per challenge, and requires exactly 2^n different challenges to refute the instance. This is NOT a lower bound against a solver allowed to inspect the source or synthesize candidate-dependent programs.

## NP-HARD OUTER-CORE FALSIFIER
Given arbitrary 3CNF F(X), set G(X,B)=NOT F(X) AND B. The B-fiber is a unit 2CNF, while EXISTS X FORALL B NOT G iff SAT(F). Therefore eliminating all universal variables does NOT decide arbitrary SAT faster, and this theorem cannot separate P and NP.
