## EXACT CANDIDATE-COVER MITER
For G(X,I,B) an explicit counterexample circuit, X shared existential input, k selector bits, b genuine universal seed bits, t<=2^k legal selectors, illegal indices G=0. Given t candidate-dependent b-bit response circuits f_i(X), form
  H_f(X) = OR_{i<t} G(X,i,f_i(X))
and the ordinary SAT miter
  M_f(X,I,B) = G(X,I,B) AND NOT H_f(X).
M_f is UNSAT if and only if FOR ALL original candidates x:
  [EXISTS I,B G(x,I,B)] iff H_f(x).
Only after an UNSAT audit is the original
  EXISTS X FORALL I,B NOT G(X,I,B)
candidate-preservingly reduced to SAT of the X-only circuit NOT H_f(X). The old original G gate trace remains after FORALL I,B; only the NEW H_f trace is existential in the final Tseitin CNF. One X is shared across ALL branches. No enumeration of long B challenges. With k=O(log N), t is polynomial, though b can be polynomially long.

Deciding soundness of a supplied cover is coNP-complete even for k=0,b=1,f_0(X)=0: from arbitrary circuit UNSAT(F), set G(X,B)=F(X) AND B, so H_f=0 and M_f=F(X) AND B.

## MAXIMUM-RANK POINT-FUNCTION COUNTEREXAMPLE
For any 3-CNF F(X)=AND_{i<t} D_i(X) and supplied polynomial-time response functions f_i(X), define
 G_F(X,I,B)=OR_{i<t}([I=i] AND NOT D_i(X) AND [B=f_i(X)]).
Every candidate-specific universal witness is a single long seed on an active selector branch. The cover is exact, H_f(X)=OR_i NOT D_i(X), hence the QBF is true iff SAT(F). Every active seed predicate is a point function with trivial translation-period space; its minimal affine observation rank is b. But responding to a losing x requires only finding a violated clause i and outputting (i,f_i(x)), a polynomial-time common-input universal strategy. High observation rank does not force long universal search. The family still contains NP-complete SAT in its outer X problem. Changing EXISTS X FORALL I to FORALL I EXISTS X incorrectly accepts F=(x) AND (NOT x).

A polynomial-size response list handling all SAT instance encodings X would imply SAT in P/poly; polynomial-time uniformly constructible/evaluable response lists would imply P=NP. Conversely standard decision-to-search self-reduction yields such witness circuits under those assumptions. No all-instance cover is presumed.
