## Exact compiler theorem and proof
Let Phi = EXISTS X FORALL I,B NOT G(X,I,B), where I has k bits, t<=2^k selectors legal and B has b bits. A legal branch is a supplied Boolean circuit C_i(X,B), with unique functional Boolean gate traces T_i. Treat X solely as symbolic coefficient inputs. Form factor tables for every gate equation over the B,T_i scopes (each arity <=3), plus a unit relation forcing branch output 1. Given an elimination ordering of primal width w_i on (B,T_i), eliminate Z using F_new(x,neighbor assignment)=OR_{z=0,1} AND_{f containing z} f(x,z,neighbor assignment). All intermediate factor table entries are X-only Boolean circuits.

Induction gives S_i(x) IFF EXISTS B C_i(x,B) for EVERY x. Saving z=0 and z=1 bucket tables and back-substituting in reverse elimination order, choose z=1 iff NOT F0 AND F1. This yields X-only response f_i(X) satisfying S_i(x) => C_i(x,f_i(x)); unavailable fibers have no satisfying response. Thus EXACTLY:
  Phi IFF EXISTS X AND_{i<t} NOT S_i(X).
All branches use the SAME X; illegal selector values have counterexample predicate 0. Circuit construction + response extraction costs O(SUM_i 2^(w_i+1)*(N_i+b+|T_i|)*poly(w_i)) X-only Boolean DAG operations, plus elimination-order discovery and O(log S) per serialized output reference. The implementation computes and checks a min-fill order of width 5; it does NOT claim min-fill finds an optimal treewidth decomposition. Fixed-w recognition algorithms are known, with additional charged complexity.

RESTRICTION HEREDITY: Fixing any subset of X changes only the values of symbolic guard/coefficient tables; it does not enlarge their B,T scopes, so the same certified variable-elimination ordering and bound survive all existential restrictions.

## Separate negative theorem: guarded ACTIVE width recognition
For every fixed w>=1, GIVEN arbitrary X-only guard circuits, deciding whether the activated B-constraint primal graph has width <= w FOR ALL X assignments is coNP-complete. Given arbitrary 3CNF F(X), use w+2 B-vertices and guard each pairwise equality [B_u=B_v] by F(X). When F(x)=0 the active graph is empty; when F(x)=1 it is K_(w+2), width exactly w+1. Therefore the global active-width promise is TRUE iff F is UNSAT. For constant w the complement has NP witness x, and fixed-width graph recognition is polynomial. All constraints are jointly satisfiable (B=0), so this is a structural-promise hardness result, NOT a SAT/QBF hardness theorem. IMPORTANT qualifier: the STATIC union graph always contains the clique; only the candidate-ACTIVATED graph carries the coNP-hard promise. Finite test: 256 truth tables on 3 X bits, w=1,2,3, all 6144 comparisons PASS.

## Hypothetical P=NP service and strict cost firewall
A hypothetical SAT solver running O(L^d) time on L-bit inputs could decide the fixed-candidate universal counterexample existence using one SAT query of L=O(N log N), then extract one B,I response via at most q+1 SAT calls (q=k+b), for charged O((q+1)(N log N)^d+poly(N,q)) per candidate.
