## Exact lemma and quantifiers

There exists a single fixed uniform algorithm producing a read-once ordered shared BDD with at most 2k+2 nodes (including terminals), without enumerating 2^k separator assignments. Every accepted cofactor P_k|_{s=a} is a product of unary x_i constraints. The number of separator assignments is 2^k, but the shared record count is O(k). Exact count is 3^k.

## Construction and proof
Build suffix handles B_{k+1}=TRUE and B_i=(s_i?B_{i+1}:(x_i?B_{i+1}:FALSE)), for i=k,...,1. Under order s_1,x_1,s_2,x_2,...,s_k,x_k this is an ordered read-once BDD. Each i introduces exactly one s_i decision and one x_i decision. Both branches share the same suffix B_{i+1}. Hence at most 2k+2 nodes including two terminals. On any (s,x), the recurrence accepts exactly when each (s_i OR x_i) is true. For each i, (s_i,x_i) has three accepted pairs, so count(P_k)=3^k. For a fixed s, x_i is forced to one if s_i=0, and is free otherwise, so the fiber count is 2^{sum_i s_i}. There are k+1 distinct scalar fiber counts, but the named cofactor relations themselves may all be distinct: their number is 2^k. This demonstrates that distinct cofactor roots, not only distinct counts, are the WRONG substitute for shared DAG records. No cofactor table is built.
