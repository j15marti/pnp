## Fixed model, quantifiers and decoder theorem

Fix any total deterministic decider A for all valid inputs of the declared Boolean decision language before selecting an input distribution. Use the sole writable finite-alphabet tape, one unit-speed head, read-before-write transitions, fixed origin and terminated Boolean output. Every mutable cache, address, source copy and clock is represented in the actual configuration. Fix a finite-support distribution over inputs and a reachable checkpoint on each execution. Let L denote remaining transition count. No uncharged access to retained tape is supplied.

First a universally valid full-record construction illustrates exactly what correctness supplies. Set U to the final Boolean verdict. Let B contain the fixed machine, checkpoint control state and head position, and the initial contents of the two designated output cells. It may also contain public parameters and the prior. B excludes every other sampled tape symbol. Let Pi contain every subsequently read symbol through halt, each in a fixed binary block of length b=ceil(log2|Gamma|). E is the set of all L subsequent transitions. Thus |Pi|=b|E|, h=0 and rho=1.

Given B and Pi, simulate the machine one transition at a time. Use the next symbol block as the scanned old symbol, compute the write, movement and next control, and update the known output cells whenever written. This yields the correct final output. A conceptual simulator may reject inconsistent repeated reads, but that is unnecessary on actual records. Conditional on B, two complete records cannot stand in a proper prefix relation. After the shorter record the simulated control has halted, so an actual longer continuation with that prefix is impossible. The empty record at an already halted checkpoint is also handled by B. Hence H(U|B,Pi)=0 and H(U|B)<=E|Pi|=b E[L]. Output entropy is at most one bit. This weak certificate holds after arbitrary paid preprocessing, including a cached decision.

B may disclose sample-dependent finite control, head position and output cells. The bound is explicitly conditional on that disclosure, and charges only the remaining execution. It asserts no cost for receiving B and does not infer a large residual entropy. In particular an answer already present there can give zero. For polynomial caps the head position has O(log N) bits, but no head-size estimate is needed for the conditional theorem.

**Sparse-record theorem.** For finitely many indices j on the same original execution, specify U_j independently as functions of the input and public parameters. Specify side information B_j and actual selected transition sets E_j. Suppose there is a fixed deterministic simulator which, given B_j and a conditionally prefix-free metadata word M_j, reproduces the relevant actual execution segment. At each step, either it determines the required transition from information already available, or it requests a fixed b-bit block representing the payload of the next actual selected event. It must determine which case holds, the event identity, and its own termination without looking at unavailable symbols, hidden elapsed time or an externally supplied stopping time. At termination it computes U_j. Assume this simulation succeeds for every input in the distribution's support.

Let Pi_j be M_j followed by the payload blocks in their actual requested order, and h_j=|M_j|. For a fixed B_j, different metadata words have no prefix relation. For the same metadata, deterministic requesting and stopping make the remaining completed payload words prefix-free. Thus the concatenations are conditionally prefix-free and decode U_j. Suppose every actual transition belongs to at most rho selected sets, with fixed rho>=1. Pointwise,

sum_j |Pi_j| <= sum_j h_j + b sum_j |E_j| <= sum_j h_j + b rho T.

The conditional entropy coding inequality applied separately at each j and then summed proves

E[T] >= (sum_j H(U_j|B_j) - sum_j E[h_j])/(b rho).

All entropies and event sets use the same input distribution and realization. Random metadata lengths are permitted. If the simulator already knows the event selection from B_j and previous payloads, M_j is empty. If it needs addresses, counts, gaps or a hidden control value, encode enough to satisfy the simulation premise and charge those bits in h_j. No specific generic amount of metadata is asserted sufficient.

The proof is a conditional accounting implication. For a general target U_j beyond the final decision, correctness alone supplies neither its decoder nor the sparse simulation premise. Full-state side information can collapse the demand. The common-path first-difference construction from the previous Bounds report passes this criterion because both public opponent configurations determine the entire path before their first difference. Arbitrary projections of a trace need not pass it. [Previous first-hit proof](PNP_Charged_bounds_2026-11-22_095619_Reachable_Cell_Opponents.md)

## A legal two-label counterexample after paid acquisition

Use Construction's triangle bundle over a quotient cycle with q>=5. Choose either all identity matchings or one transposition matching. These respectively give SAT and UNSAT. Each source has n=42q, m=30q and

N=n+2+2 floor(log2(m+1))+3m ceil(log2(n+1))=Theta(q log q).

This is the direct positive Boolean exact-one encoding. The previous authenticating solver verifies all rows and matching structure and computes cycle parity. Guard failure on any other valid source receives exhaustive decision. Fix a variant A that encodes SAT by D=0 and UNSAT by D=1, then places D at cell 3, zeros at cells 4 and 5, an origin marker at cell 0 and a blank at cell 1. All normalization and relocation are paid. It enters the same cache-reading control state at head position 3 on both inputs. Source and other work may remain on the same charged tape.

Its suffix reads D at transition 1. When D=0 it selects the zero at cell 4 at transition 2. When D=1 it passes cell 4 and selects the zero at cell 5 at transition 3. It then returns left using the fixed origin marker, writes D at the origin, writes the terminator at cell 1 and halts. This uses a fixed finite collection of states carrying D. The head never queries its numerical position to find the origin. The exact trace has seven transitions for D=0 and nine for D=1.

Let B be the public pair, q, solver, common starting control/head and initial output cells, without the selected input. Let U=D, let E contain just the selected zero-read, and let Pi be that read's payload. On the fair pair, H(U|B)=1, while Pi=0 on both runs and H(U|B,Pi)=1. The records are fixed-length and therefore prefix-free. Capacity b=1, reuse rho=1 and |Pi|=|E|=1 all hold. The required decoder fails. This is a counterexample to the implication that these properties and decision correctness establish compulsory decoding. It does not contradict the conditional entropy inequality.

Giving the decoder the selected event's relative time or address would reveal D. For this two-point support a one-bit metadata word distinguishing time 2 from 3 suffices. Taking Pi'=M followed by 0 gives h=1, making the claimed time numerator 1-1=0. Alternatively selecting the actual cache read at transition 1 yields payload D, h=0, rho=1 and the valid one-bit lower bound. The latter is the useful repaired ledger. Treating the selected address as freely known while using only its zero payload as the record would omit the entire answer-bearing information.

Four explicit falsifiers are identical selected payloads with opposite decisions, unavailable control determining which event is selected, an uncharged address or timing channel, and repeated selection of one physical read while asserting rho=1. This counterexample exhibits the first three. The reuse hypothesis handles the fourth. The earlier full-cycle collision remains a separate obstruction even when a stopped scan's selection is replayable.
