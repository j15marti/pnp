# Strict-C resource audit: delayed-index witness-first stream and child-encoding firewall

Date: November 19, 2026. P versus NP is OPEN.

**PROVED (restricted information order):** A strict-C family forces (n) bits of deterministic writable state for one-pass SAT-witness checking when the verifier reads the witness before it learns which of (n) selector clauses the source contains. This is a one-way INDEX result, not an unrestricted SAT time/space lower bound.

Take five palette variables (p_0,ldots,p_4). Add five clauses (C(p_i,p_{i+1},p_{i+2})) (indices modulo 5), which have exactly ten colorings (the dihedral frames). Add, for (0le i<n), the support (C(x_i,p_3,p_4)); in canonical palette (p_i=i) this forces (x_iin{0,2}). Finish with selector (C(x_j,p_1,p_2)); in the canonical frame it accepts (x_j=0), not (x_j=2). All clauses have distinct variable NAMES and use original C, 30 of 125 triples. For each (bin{0,1}^n), set (x_i=2b_i). The candidate satisfies all common clauses and the complete source iff (b_j=0).

If a deterministic verifier has read this witness as a one-pass nonrewindable stream before learning (j), distinct (b) must create distinct internal states: choose a (j) at which two strings differ. Consequently (ge 2^n) states and (ge n) writable bits are necessary. For each fixed (j), the source has (n+5) variables, (n+6) clauses and exactly (10cdot2^{n-1}) satisfying assignments. A usual verifier that sees (j) before the witness, can reread it, or can recompute colors is **not** covered by this lower bound.
