## 1. Exact Boolean algebra and semantic obstruction

For a CNF F on n Boolean variables define c_C(x)=1-∏_{l∈C}(1-v_l) and formal P_F(x)=∏_C c_C(x), with v_x=x and v_notx=1-x. For every Boolean a, P_F(a)=1 iff a satisfies F. The raw formal polynomial P_F is *nonzero* even for UNSAT proper CNFs (the polynomial ring is an integral domain).

Work instead in A_q=F_q[x_1,...,x_n]/(x_1^2-x_1,...,x_n^2-x_n). Every element has a unique multilinear representative, and evaluation on the Boolean cube identifies A_q with F_q^{2^n}. Thus the quotient image Ptilde_F satisfies

 Ptilde_F(y)=sum_{a models F} ∏_{j=1}^n (y_j if a_j=1 else (1-y_j)),

and Ptilde_F≡0 iff F is UNSAT. For q prime and uniform y∈F_q^n, if F is SAT the degree <=n Schwartz-Zippel bound gives Pr[Ptilde_F(y)=0] <= n/q. On UNSAT inputs every evaluation is exactly 0. These identities hold for every n; the probability bound is only informative for q>n.

**Polarity lemma (restricted, unconditional).** For any fixed map h:F_q→{0,1} and any deterministic points y(F,i) on which Ptilde_F is correctly evaluated, a target with bits G(F,i)=h(Ptilde_F(y(F,i))) is exactly h(0)^M on *every* UNSAT F. For an efficient indexed universal machine, KT_U(h(0)^M)=O(polylog M), hence it lies on the LOW side of p>=M^{1/241} for sufficiently large M. The preferred orientation SAT->LOW and UNSAT->HIGH fails even if the exact evaluations are supplied for free. An index-dependent h_i(0) is not covered unless h_i(0) itself has an inexpensive indexed program; merely making that sequence look pseudorandom does not prove HIGH KT.

**Evaluator firewall.** If deterministic polytime E(F,y) evaluates Ptilde_F(y) for every rational y and every ordinary F, then E(F,(1/2,...,1/2))*2^n=#SAT(F), so #SAT is in FP. More weakly, if E computes the F_q evaluation for all F and y uniformly in polynomial time over primes q>=8n, a polynomial-time one-sided-error verifier for SAT follows by picking uniform field points (using a polynomially bounded finite rejection budget to handle non-power-of-two q); this gives SAT∈RP and consequently NP=RP, *not* deterministic P=NP. Neither consequence is asserted unconditionally. Direct enumeration computes E, but generally takes 2^n time.

## 2. An explicit failed all-input candidate and physical costs

Fix k=241, source encoding length N=max(2,|enc(F)|), L=ceil(6 ceil(log_2 N)/5), M=2^L=N^{6/5+o(1)}, p=max(L,ceil(M^{1/241}))>=log_2 M. For valid ordinary CNF encodings let q be the first prime >=8 max(1,n); for malformed inputs output zero bits. Define y_j(i)=(i+j) mod q (indices i=0,...,M-1, variables j=1,...,n). Define G_241(F,i) as the least significant bit of Ptilde_F(y(i)) in its canonical residue in {0,...,q-1}; output the end marker for i>=M. The ordinary (not oracle-relative or promise) MKTP instance is the explicitly serialized gamma(M)||gamma(p)||G(F,0)...G(F,M-1), where gamma is fixed Elias-gamma integer coding and the bit target is literal, not a pointer, digest or circuit recipe.

This is deterministic, total and unambiguous after fixing a canonical parser and the malformed-input behavior. A straightforward evaluator enumerates 2^n assignments and checks m clauses per target coordinate, costing O(M*2^n*poly(N,log q)) arithmetic/bit operations plus M output bits, with potentially O(n+log M) live state even if the original source is reread on demand; source rereads are additionally charged each time a clause is consulted. Caching the entire input would cost Theta(N) bits of workspace, violating the N^(1/2+o(1)) bound in general. One can avoid caching by rescanning, but then the complete read/replay cost grows; neither option is uncharged. There is **no Σ3SAT oracle call** in this candidate; any hypothetical faster evaluator must be explicit. Hence the desired generation-time and workspace constraints are *not achieved*. Independently, the first semantic arrow fails: every UNSAT target equals 0^M and has LOW KT for sufficiently large N. This failure is robust to even a free quotient evaluator.

The randomized PIT family is a correct RP-style characterization if an exact efficient evaluator is assumed, but it is not a deterministic uniform SAT->ordinary-MKTP reduction.

## 4. Padding-invariance lemma and hostile controls

Each clause indicator c_C is idempotent in the Boolean quotient: c_C^2=c_C, because its Boolean values are only 0 or 1. Thus duplicate-clause padding does not change Ptilde_F *as a polynomial*, even when the literal raw polynomial product and total encoded source length change. On simple UNSAT sources the target remains identically zero for every padding length. On easy unique-SAT sources the quotient still equals a product of n elementary linear factors. This is a precise semantic fiber and prevents interpreting additional output length or raw-expression growth as increased KT.

The verifier additionally tests both SAT and UNSAT inputs padded with 2, 5 and 20 copies of an existing clause: source encodings lengthen, SAT assignment sets and quotient evaluations remain identical at 60 checked field points. These are deliberately hostile inputs, not claimed hard cases.

## 5. Linear RP digest vs. deterministic all-INDEX continuation (new exact restricted lemma)

This exploits the project RP digest portfolio without making a counting-only argument. Suppose a deterministic prefix summary of forced source bits x in GF(2)^n consists exclusively of q linear parity checks, A x in GF(2)^q, and a continuation-only decoder uses (A x,j) to decide the late positive-unit selector for variable j. If q<n, rank(A)<n; choose a nonzero kernel vector d. For any x, y=x+d has exactly the same digest but differs in some coordinate j with d_j=1. The proper-3CNF forced-gadget continuations F_{x,j} and F_{y,j} therefore share the same selector suffix yet have opposite SAT labels. No decoder receiving only (A x,j) can decide both. A portfolio of linear hash blocks is equivalent to stacking their matrices: the rank must be n to support ALL INDEX continuations, requiring at least n cumulative parity output bits. This remains an interface theorem, not an unrestricted memory or computation lower bound: a source-online reduction may emit those n bits, after which ordinary KT must be analyzed separately.

For q independent uniform GF(2) parity rows and a **fixed** difference d != 0, collision probability is exactly 2^(-q). However, for EVERY fixed q<n realization of A, some adversarial d collides. One may not swap the quantifiers to obtain a single deterministic universally collision-free sublinear digest. In particular, RP bounded error on individually fixed inputs does not yield an all-input deterministic SAT-to-MKTP semantic map. The theorem does not address nonlinear, source-adaptive sketches, extra formula reads, replay, timing, or other side channels.

**The first failed arrow for candidate A is semantic, not computational:** the exact Boolean-quotient indicator makes every UNSAT output constant and therefore LOW ordinary KT, whereas the selected MKTP orientation requires UNSAT->HIGH.
