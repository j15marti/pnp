## Theorem 1: under P=NP the semantic SAT-to-ordinary-MKTP map is uniformly polynomial-time (conditional)

Fix k=241 and a fixed efficient universal indexed ordinary-KT machine U. For any encoded F let N=max(2,|F|), L=ceil((6/5)ceil(log2 N)), M=2^L and p=max(L,ceil(M^(1/241))). Use integer k-th root to compute p exactly. For the finitely many small N where the standard universal-machine constants matter, raise M to one fixed machine-dependent minimum M0, preserving asymptotic M=N^(6/5+o(1)). Output canonical self-delimiting (M,p,T) with exactly M target bits.

LOW(M,p)={T: KT_U(T)<=p} is in NP: a witness program d and integer t, |d|+t<=p, is checked for every indexed bit plus terminator within t steps each. At most 2^(p+1)-1 programs can witness LOW. For sufficiently large M, p+1<M, hence at least one HIGH string exists. Also 0^M is LOW for sufficiently large M because a fixed indexed zero generator storing M has O(log M) description and O(log M) worst-case bit access, while p eventually exceeds every fixed multiple of log M.

Under P=NP, PH=P. Thus

    EXT(M,p,w) := exists z in {0,1}^(M-|w|) with KT_U(wz)>p

is in P: HIGH is coNP, so the extension question lies in Sigma_2^P. Choose each successive bit of H_(M,p), the lexicographically first HIGH M-string, by selecting 0 whenever EXT(M,p,w0) is true and 1 otherwise. This deterministically generates H in uniform polynomial time using one fixed P algorithm for EXT. Conditional next-bit function:

    G_241(F,i) = 0 if SAT(F), else H_(M,p)[i], 0<=i<M,

with correct terminator at i=M. Malformed SAT encodings count as NO. It is a total, deterministic, uniform, all-input SAT->LOW, UNSAT->HIGH **conditional** reduction. The unknown fixed polynomial exponents for SAT and EXT and the corresponding workspace are not bounded by the proposed sharp resource limits. This does not prove P!=NP.

## Theorem 2: literal-prefix high-string self-reduction violates the physical box

At stage j=1,...,M, the independent ordinary extension query literally carries the current length-j candidate prefix. Its **serialized query lengths alone** total at least

    sum(j=1..M) j = M(M+1)/2 = Omega(M^2),

even with a free query-answer oracle. Ordinary PH oracle calls do not implicitly share the previously emitted output or an uncharged source-table pointer. At least M-p of these literal queries have length greater than p for p<M.

As M=N^(6/5+o(1)), traffic is N^(12/5+o(1)), much greater than N^(241/200). Materializing a late query or retained arbitrary prefix costs Omega(M) workspace, much greater than N^(1/2+o(1)); streaming it repeatedly trades space for fully charged replay cost. This lower bound is restricted to **literal-prefix independent-query search**. It is not a lower bound on every possible succinct prefix representation, local source-aware oracle, or SAT-to-MKTP constructor.

For a hypothetical Sigma_3 query solver with time exponent C and space exponent D, the conservative MMW downstream ledger gives M p^(C+1+o(1)) time and p^max(1,D)+o(1) space. The desired strict time bound with a=6/5 requires k>240(C+1), and the strict space box requires k>(12/5)max(1,D). k=241 is not guaranteed to work for an arbitrary unknown solver exponent.

## Lemma 3: locally indexed short-seed outputs are LOW

If T_s has a b-bit seed and an ordinary, fixed source-independent indexed evaluator whose *actual worst-case time on the same universal U* (including terminator, seed decoding and all access charges) is t, then

    KT_U(T_s) <= b + t + O(log M).

Thus b+t+O(log M)<p makes T_s LOW. If the evaluator runs on another machine model, include the explicit simulator overhead in t. This defeats proposed HIGH strings built from short PRG/hash/RP seeds with inexpensive random-access output evaluation. It does not assume every iterative hash has inexpensive indexed evaluation.

## Actual finite test

Local complete executable: prefix24_audit.py. Raw artifact: PREFIX24_raw.json. **8272 assertions, zero failures**. Seven finite *toy* indexed-program systems, M=4,5,6,7,8,10,12: exact lex HIGH string and prefix-existence search against enumerated LOW outputs, explicit query length counts. These toy program semantics do NOT determine actual universal-machine ordinary KT.

Connected proper-3CNF minimally UNSAT chains Q_r for r=1..4, with 2r+8 clauses and 2r+5 variables, all verified UNSAT; every single clause deletion SAT; replacing one deleted clause by a duplicate yields a SAT companion of the same clause count. Exhaustive checks of 8194 abstract two-pass INDEX cases n=1..9: first pass learns a trailing selector, second pass rereads the chosen source bit with O(log n) live state. This shows why the one-pass *proof* cannot simply be transferred to two passes; it does not refute a possible two-pass KT lower bound and does not produce HIGH targets. Symbolic literal-prefix arithmetic checks for M=2^L at L=12,20,40,100,1000.
