## 3. EXPLICIT SEMANTIC CONTROL FAMILY

For x in {0,1}^n and j in {1,...,n}, let F_{x,j} encode all unit constraints `y_i = x_i`, together with the final requirement `y_j = 1`. A unit literal l is encoded by four proper three-literal clauses `(l OR a OR b)`, `(l OR a OR NOT b)`, `(l OR NOT a OR b)`, `(l OR NOT a OR NOT b)` using fresh a,b. Thus F has exactly 4(n+1) proper 3-clauses, 3n+2 variables and fixed-width source encoding of N=Theta(n log n) bits independent of x and j (for n>=2). The exact equivalence is SAT(F_{x,j}) iff x_j=1.

The pair F_{0,j} and F_{v,j}, for v_j=1, has opposite SAT label and identical encoded length. The source prefixes encode distinct forced assignments; the late suffix selector j is shared. All clauses satisfy properness; source decoding and family membership are deterministic O(N) time, O(log N) work on canonical encodings.

## 4. RESTRICTED THEOREM A: RANDOMIZED FINGERPRINT IS NOT AN ALL-INPUT CONTRACTOR

Let H be any fixed q by n matrix over F_2 with q<n. Rank-nullity gives a nonzero vector v in ker(H). Choose j with v_j=1. Then H0=Hv although SAT(F_{0,j})=0 and SAT(F_{v,j})=1. Thus *any* completed target that depends on the forced-assignment prefix **only** through Hx, and thereafter on a common suffix j, maps an opposite-label pair to the same output. This falsifies both possible ordinary-KT polarities without computing KT.

For a uniformly random q by n matrix H and *any fixed* nonzero v, each row has independent dot product 0 with probability 1/2, giving Pr[Hv=0]=2^-q. This is a legitimate one-sided RP fingerprint for inequivalence, but the bad v may depend on the fixed H. Swapping `for all fixed v, most H` with `there exists H, for all v` is unjustified. The language of string inequality is itself in P; no P/RP separation follows.

Interface limitations are essential: if the suffix can cause rereads of x, if independent source bits were already output, or if the compressor uses data beyond Hx, the hypothesis fails. This is a diagnostic for proposed RP-to-MKTP constructions, not a universal algorithm lower bound.

## 5. RESTRICTED THEOREM B: DETERMINISTIC PORTFOLIO AND KT INFORMATION FORK

Let A stack h public q-bit linear sketches H_1,...,H_h. To distinguish all forced-prefix/late-suffix INDEX pairs by their stacked sketch alone, ker(A) must be {0}, hence rank(A)=n and hq>=n. Conversely full rank makes x recoverable from the concatenated sketch A x.

Suppose a proposed ordinary MKTP target *literally contains a uniformly recoverable encoding of Ax* with the fixed matrices and n known from a short header. Fix j=1 and all x with x_1=1. There are 2^(n-1) satisfiable sources; their targets are all distinct. At most 2^(p+1)-1 distinct strings possess KT_U<=p, since a witness has description length <=p and determines one exact indexed string. For any p+1<n-1, some satisfiable source must produce a target with KT_U>p. Equivalently, plain Kolmogorov incompressibility of x and recoverability imply description lower bound n-O(log n) for at least one x. With M=N^(6/5+o(1)), p=max(ceil(log2 M),ceil(M^(1/241))), p=o(n) for N=Theta(n log n), so SAT->LOW fails asymptotically for this architecture.

This theorem concerns a **recoverable** concatenation; it does *not* exclude nonlinear aggregation B(Ax,j) that destroys x after extracting the SAT-relevant bit. If A is rank deficient, no postprocessing B can repair collisions using only Ax and common j. A successful general reduction must avoid both the short-sketch collision and recoverable-high-information pitfalls, or use additional source access, exact semantics, and charged replay.

## 6. AN ACTUAL DETERMINISTIC TOTAL GENERATOR THAT FAILS

Fix k=241, N=max(|F|,2), a=ceil(log2 N), L=ceil(6a/5), M=2^L, p=max(L,ceil(2^(L/241))). Ordinary MKTP is the canonical self-delimiting pair (T,p) where T consists of exactly M bits and the language accepts iff KT(T)<=p.

For fixed r in {1,...,n}, define a complete, total, source-accessible target-bit predicate:

G_{241,r}(F,i)= x_{i+1} if F is a canonically encoded F_{x,j} and 0<=i<r; otherwise G_{241,r}(F,i)=0 for 0<=i<M; and the standard terminator for i>=M.

On any malformed source or ordinary formula not in the recognized pattern, output 0^M. The r=n variant is a full-rank identity portfolio; r<n is an underdetermined coordinate portfolio. To **stream** the target, first scan and validate F while computing N, n, j using O(log N) working bits; then reset source, stream the selected forced literal signs as the first r target bits; finally append M-r zero bits. Count the full first and second source passes, serialized M,p header, streaming output, and all work. Total time O(N+M+polylog N)=N^(6/5+o(1)), peak work O(log N), randomness 0, ordinary PH queries 0, side tables 0. If independent random-access calls to G each restart the parser, each may cost O(N); **the charged resource guarantee is for the stateful one-pass-output generator, not M independent calls**.

This real contractor meets the target length and resource constraints but fails the all-input SAT/UNSAT semantic property. For r<n, take j=r+1 and x=0 versus x=e_j: output collision. For r=n, the UNSAT formula F_{0,1} maps to 0^M, which has polylog(M) KT on efficient universal indexed machines and is eventually LOW; additionally, incompressible satisfiable x yield HIGH targets because the prefix exposes x. On generic satisfiable inputs outside the syntactic family, output is also 0^M. This is a falsifier rather than a completed reduction.

Strict exponent comparison: 6/5=1.2 <241/200=1.205, so N^(6/5+o(1)) lies below N^(241/200) for large N. O(log N) working memory lies under N^(1/2+o(1)). Canonical target and threshold serialization adds O(log M) header bits; it is counted in output time and workspace. N includes all source encoding, not an uncharged formula pointer.

## 7. RP/PIT TRANSFER: THE FIRST COMPUTATIONAL BOTTLENECK

For n Boolean variables and formal coordinate variables y over an odd modulus Q, define the *globally compatible witness polynomial*

W_F(y) = sum_{a in {0,1}^n: F(a)=1} product_{i=1}^n (a_i y_i + (1-a_i)(1-y_i)).

It is identically zero iff F is UNSAT; on the Boolean cube W_F(a)=1 exactly for satisfying a and 0 otherwise. Over a field of cardinality at least 2n, a uniformly random evaluation detects nonzero W_F with probability >=1/2 by Schwartz--Zippel, hence suggests a one-sided RP procedure *if an efficient exact evaluator exists*.

But the exact evaluator is load-bearing. Choose odd Q=2^(n+1)+1 (not necessarily prime) and y_i=2^(-1) mod Q for all i. Then W_F(y)=#SAT(F)*2^(-n) (mod Q), so #SAT(F)=2^n W_F(y) (mod Q), with the result an unambiguous integer <Q. Thus a polynomial-time evaluator valid for all inputs would compute #SAT exactly. Randomness cannot bypass that evaluation cost. Evaluating instead the raw product of clause polynomials at non-Boolean field points gives false nonzero values on minimally UNSAT formulas, as already observed in RP-QUOTIENT21 controls. This approach is CANDIDATE for a deeply different representation, not an existing SAT-in-RP algorithm.

## 10. COROLLARY FROM :12 RP UNIQUE-WITNESS FAMILY (ESTABLISHED, RESTRICTED)

The RP agent's original 2026-10-21 17:12 DIGEST-PORTFOLIO8 handoff constructs for each n divisible by three an explicit connected proper-3CNF F_a with unique satisfying assignment a in {0,1}^n, exactly 8n/3-1 clauses, bounded variable occurrence and fixed-length N=Theta(n log n) encoding. This family strengthens the information-source guard beyond verbatim linear fingerprints.

**Witness-recoverability barrier.** Let R be any deterministic reduction producing ordinary target T(F_a) and p=o(n). If one uniform computable extractor E, given only n and indexed access to the entire target T(F_a), reconstructs a for every a, then R cannot map *every* F_a to KT<=p. Proof: E makes a -> T(F_a) injective; there are 2^n distinct outputs and fewer than 2^(p+1) ordinary-KT descriptions at threshold p. Alternatively, a target indexed program plus n and the fixed extractor encodes a with |program|+O(log n) bits. Both contradict incompressibility for some a when p=o(n). External access by E to F_a would invalidate this premise because F_a itself encodes a; no such access is permitted here. This is an exact necessary condition only for **source-free witness-recoverable target interfaces**, not a refutation of arbitrary SAT-to-MKTP.

Together with DIGEST-PORTFOLIO8's different restricted RP result (a q-bit preprocessing summary plus h whole-witness tests has some F_a with success probability <= h*2^(q-n)), this imposes complementary guards: a full witness-recoverable output violates the SAT=>LOW objective, while a small digest + too few witness trials cannot provide uniform one-sided RP success in its specified interface. The missing possibility is a lossy quotient that determines the SAT label without reconstructing arbitrary unique witnesses, and produces genuine high ordinary KT on UNSAT inputs. Both complexity questions remain OPEN.
