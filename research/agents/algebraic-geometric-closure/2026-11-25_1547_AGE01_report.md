## Lemma AGE01-A (exact planar matching height chart)
For any choice of omitted clause partition C, keep the other two partitions A,B. Suppress each variable's two incidence edges to a separately identified multiedge e oriented A to B, retaining the embedding (or keep degree-two subdivision for parallel edges). Every satisfying assignment gives a perfect matching of this cubic bipartite graph. A baseline matching m exists by Hall's theorem (3-regular bipartite multigraph); find it by ordinary matching. For each connected component fix one face height zero. Any perfect matching x differs from m by an integer circulation on the oriented graph. On a connected plane graph these are exactly the differences of integer dual face potentials, unique after fixing the root: x_e = m_e + h_right(e) - h_left(e). Indeed dual cycle sums vanish because the corresponding primal cuts have zero net circulation; path integration defines h, and the converse telescopes around vertices. This also holds with bridges, parallel edges, and disconnected components separately. Bounds -m_e <= h_right-h_left <= 1-m_e enforce Boolean edge occupancies. An original edge pin changes the corresponding interval to a singleton. Conservation then ensures one selected edge at each A/B vertex. All heights have absolute magnitude O(number of edges) using dual paths, even under valid pins. Negative cycles in the resulting difference-bound graph certify infeasibility.

Introduce a fixed zero vertex linking all rooted faces. Let d(i,j) be all-pairs shortest upper bounds on h_j-h_i. In the feasible base system the projection to any subset S of faces (plus zero) is EXACTLY the inequalities h_j-h_i <= d(i,j) for i,j in S plus zero. For pinned values meeting these inequalities, h_v = min_{u in S plus zero}(h_u+d(u,v)) extends them, satisfies each original arc by triangle inequality, and is integer. Thus local table acquisition does not require enumeration of perfect matchings.

Each omitted clause touches at most six distinct faces, counting the two faces per edge. Do not assume four for arbitrary disconnected pair graphs. Acquire its explicit table by enumerating the bounded height domains on its scope, retaining only tuples consistent with the projected base and sum of its three edge occupancies equal to one. Include root constants and source edge IDs. The global conjunction of base and all tables is bijective to original satisfying assignments; this is exact and guards are preserved. All three pair partitions can be tried. The chart itself is polynomially acquired but solving the conjunction may remain hard.

## Lemma AGE01-B (threshold interface and polynomial saturation)
Represent h_f by threshold bits t[f,k]=[h_f>=k] between its integer bounds. Chain implications enforce legal words. Difference constraints h_j-h_i<=b become implications t[j,k] -> t[i,k-b], with constant sentinels and k ranging from the minimum to maximum of h_j. Hence the base and all edge/face pins are exact 2-CNF. Threshold encoding commutes with coordinatewise median. A Boolean majority-closed relation equals the conjunction of its unary/binary projections: if a missing word satisfies those projections, choose a minimal inconsistent set of pins; at least three, and three witnesses each omitting a different one yield a majority agreeing with all pins, a contradiction. Empty relations handled separately. Thus median-closed local tables can be compiled exactly by all forbidden unary/binary threshold assignments.

Run the same compiler without assuming median closure. The resulting global 2-CNF is necessary. If contradictory, reject; if a returned assignment lifts to an original witness, accept. Otherwise for each explicit local table row ask whether it is feasible in the global 2-CNF. A row pins at most two thresholds per face (at most 12 total); in a satisfiable implication graph the pins are jointly feasible iff no pin reaches the complement of any pin, including itself. Delete precisely infeasible rows. Rebuild projections and repeat. All true source solutions survive by induction. If some table empties or 2-CNF contradicts, UNSAT; a verified source witness is SAT; if no deletion and candidate invalid, OPEN. Monotone row deletion gives at most the number of initially acquired rows plus one rounds. No hidden exponential search, no free semantic recognition, no wrong UNSAT on stagnation. This is a polynomial three-valued partial algorithm; completeness holds if every table becomes median-closed. Cooperative fixed point is a different lane from individual pairwise phase closure because matching conservation is enforced globally before checking local rows.

## Lemma AGE01-C (efficient strong median backdoor acquisition with actual domain product)
Fix the chart and its explicit tables. A set B of faces is a strong median backdoor if every assignment to B in initial domains yields median-closed slices of every local table (empty slices allowed). Define cost Q(B)=product of domain cardinalities. For every fixed c>=0, existence of a strong backdoor with Q<=N^c can be decided and such a set found in polynomial time; the admitted source instance then solved exactly in polynomial time.

At each search node test all local slices for median closure by triples of table rows in a common slice. A failed slice has three rows with median absent. Every strong extension of B must pin at least one coordinate on which these rows differ: otherwise the three remain in the same further slice and their median remains absent. Branch on those at most six coordinates, dropping singleton domains and branches exceeding product budget. Depth <= c log2 N because every additional nonconstant face multiplies Q by at least two. At most 6^(c log2 N+1) nodes, polynomial for fixed c. Local triple tests are polynomial in explicit table size. If found, enumerate <=N^c assignments to B, compile each sliced relation exactly using B, impose actual pins and solve global 2-CNF; recover and verify source witness or reject after all branches. This is deterministic acquisition plus evaluation, not merely existential backdoor discovery. Static sufficient property only: it can miss easier guarded saturation or alternative charts.

General bounded-cardinality pin-cover variant: enumerate sets of at most fixed k faces (O(N^k)), each with O(N^k) joint assignments, run AGE01-B under each guard. A set all of whose branches are definitive is a full decision cover; any single verified SAT branch suffices to accept. Never reject unless a complete cover rejects. This variant found a one-face cover on the genuine fixture.

Barrier: any static strong backdoor intersects every initially nonmedian scope, hence a packing of p pairwise disjoint such scopes implies Q>=2^p. This is a lower bound only for the static parameter and explicit enumeration strategy, not unrestricted SAT. An alternative pair chart or saturation may escape, as the actual audit does.
