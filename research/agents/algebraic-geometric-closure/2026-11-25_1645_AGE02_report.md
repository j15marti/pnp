## 1. Parity restoration is exact
Keep two partitions A,B and suppress each variable to an individually indexed edge e between its A and B clauses. H is a cubic planar bipartite multigraph; use a planar embedding of the original subdivided graph to preserve parallel edges. Hall gives a baseline perfect matching m. Let C be the omitted partition, q=|C|=|A|=|B|. Label e by its unit vector l_e in GF(2)^q indexed by the omitted clause. Define Lx=sum_e x_e l_e over GF(2). Each perfect matching x has exactly q selected edges. If Lx=1^q, every omitted clause contains an odd positive number of selected edges. Their sum is q, so each contains exactly one. Conversely any source model is such a matching. Hence a bijection, including under original edge-bit pins. This is not equivalence of parity equations alone: matching remains mandatory.

## 2. Direct-sum factorization (PROVED)
Compute a fundamental GF(2) cycle basis v_1,...,v_r of H using spanning forests with edge IDs. Matching differences x+m lie in the cycle space (even incidence). Write y in GF(2)^r for the unique coefficients and D_j=L v_j. Target b=1^q+Lm. If b is outside span(D), reject. For each matching component i, let J_i be the cycle columns within it.

Choose a column basis of D by Gaussian elimination; express each nonbasis column as a unique combination of basis columns. Join the matching-component owners of each fundamental dependency (nonbasis column plus its expressing columns) by union-find, leaving zero columns as singleton dependencies. Each resulting block B is a union of whole matching components. Every column belonging to B lies in the span of basis columns belonging to B. The chosen global basis is independent, so the block images form a direct sum; no uncharged interface or Cartesian product of incompatible exterior solutions. Split b uniquely into b_B via basis coordinates. Each block has local rank d_B, cycle dimension r_B and kernel dimension h_B=r_B-d_B. A matching is globally feasible iff its restriction in every block is a perfect matching with L(x_B+m_B)=b_B. The source model count is the product of the independent exact block counts; witness concatenation uses disjoint original edge IDs. Arbitrary original pins factor by those IDs. No replacement of actual relation by affine hull: matching is tested on every retained affine candidate or via weighted determinant.

The decomposition is the finest direct-sum split coarsening the matching-component partition: any direct-sum split cannot separate the support of a fundamental dependency, because independent block images imply each nonzero summand of that dependency vanishes separately, contrary to the minimality of the circuit. This does not claim optimality over different matching representations or refinements within a component.

## 3. Two complementary exact terminals
AFFINE lane: solve D_B y=b_B and enumerate the 2^h_B distinct coefficient solutions. Map x_B=m_B+sum_j y_j v_j, verify exactly one incident selected edge at each matching vertex and all local pins. Exact count and witness. Distinct coefficient vectors yield distinct matchings.

FOURIER lane: choose a linear coordinate map T_B from GF(2)^q to GF(2)^d_B, injective on block image (extend a basis coordinate projection linearly, or use Gaussian reduction with remainder ignored). Set a_e=T_B l_e, t_B=T_B(b_B+L m_B). On any matching the syndrome difference lies in block image, so sum_e a_e x_e=t_B iff original local syndrome holds. Orthogonality of binary characters gives exact block count
    Z_B=2^(-d_B) sum_{s in GF(2)^d_B} (-1)^(s dot t_B) prod_{i in B} Z_i(s),
where Z_i(s) is the signed matching partition function of component i with edge weight (-1)^(s dot a_e), or zero on excluded edges. Force a pinned-one edge by deleting all other incident edges; detect conflicting forced edges. For each component acquire planar bipartite Kasteleyn signing sigma_e: each bounded face of length 2k has product sigma_e=(-1)^(k+1); solve face-incidence equations over GF(2) with one face omitted. Face rows independent except total (dual graph connected), so solvable. Digons and bridge multiplicities are retained. If two perfect matchings differ on an alternating cycle of length 2k, the number of internal vertices is even (the matching saturates cycle vertices and matches interior internally). Multiplying face conditions and Euler gives cycle product (-1)^(k+1), which cancels the permutation sign (-1)^(k-1). Therefore every determinant monomial of a matching has one common sign normal_i, computed from baseline m. Summing signed edge weights of parallel edges in the matrix preserves separate terms. Then Z_i(s)=normal_i det K_i(s). Do NOT take absolute value of individual signed evaluations. The final Fourier sum is nonnegative integral after exact division. No randomness/PIT oracle. Pins are zero weights in the original signing, so common sign remains valid. To obtain a witness, try pinning each edge to zero and retain that pin if exact count positive, otherwise set one; each step preserves at least one matching, then verify original constraints. Count may exceed fixed machine word length, use exact integers.

Optional stronger acquisition (proved, not implemented here): after pins, find baseline or reject, delete edges in no perfect matching using directed alternating SCCs (unmatched edges A->B, matched edges B->A; a nonbaseline edge is allowed iff on an alternating directed cycle). Keep the resulting matching components. In an allowed component, matching differences span the full GF(2) cycle space: contract baseline matched edges; allowed arcs lie in strongly connected digraph components; directed cycle vectors span the unoriented binary cycle space, since a linear functional vanishing on directed cycles is a vertex potential difference (path-independence follows by closing two directed paths using a common return path). Lifting directed cycles is an alternating matching flip; contraction of disjoint baseline edges is an isomorphism of cycle spaces. Thus d_B is actual affine syndrome dimension after allowed-edge pruning. The executed implementation uses the original cubic graph and original signing even for pins, a safe upper parameter.
