## Theorem: paid sound adaptive portfolio
Let F be any explicitly encoded 3-CNF of length N. Fix finitely many deterministic partial decision modules M_i with:
(a) polynomial-time recognizers R_i and explicit sound, complete YES/NO verdicts on recognized instances;
(b) polynomial-time sound equivalence-preserving reductions to residual CNFs or a finite set of children with explicitly specified AND/OR aggregation, and exact lifting of any SAT witnesses;
(c) a canonical encoding with polynomial construction and equality-check cost; and
(d) exhaustive binary branching as fallback.
Define SOLVE(F): canonicalize and simplify; return UNSAT for empty clause, SAT for no clauses; try R_i in fixed order; apply a selected exact reduction only if a well-founded measure strictly decreases; otherwise branch on a present variable and recursively OR the two restricted residuals. Memoization is optional and only merges byte-equal canonical residuals. For any finite F, SOLVE terminates and returns SAT iff F is satisfiable.

Proof: induct on the number of unassigned variables, using a lexicographic secondary measure for nonbranching reductions. Recognized leaves are correct by (a). Exact child semantics and induction yield parent semantics. Branching gives SAT(F)=SAT(F|x=0) OR SAT(F|x=1). Finite reductions and strict measure prevent cycles. Cache reuse is correct only for equal residual semantics. All module discovery and checks are charged.

Let V be number of distinct expanded residuals, E total child edges, L total bits read/written during transformations, and P(N) a uniform polynomial bound on the per-visit recognizer, canonicalizer, cache, and compatibility work for residuals of polynomial length. Then T=O((V+E)P(N)+L) for a RAM implementation with explicit bit-cost conventions, plus any additional certificate validation. Peak memory O(V P(N)+L) is a loose bound for full caching; DFS can use less. CM <= T * peak-space. This is NOT a polynomial bound unless V+E and L are polynomial. If every input admits a uniformly discoverable execution DAG of polynomial size with polynomially sized residuals, the portfolio is polynomial; existence of an uncomputable or expensive DAG does not suffice.

## Stronger parameterized corollary
If a set B of k variables is found in time D(N,k) such that every assignment to B produces a class recognized and solved in N^c time, then SAT is decidable in D(N,k)+O(2^k N^{c+O(1)}), including residual construction and compatibility. Thus k=O(log N) and D polynomial suffice. More generally, components or articulation blocks may yield sum_j 2^{k_j} poly(N), not necessarily 2^{sum k_j}. This matches the distinction highlighted by Accounting's block-cutset work.

## Two refutations of naive progress lemmas
1. Large Gaussian nullity does not force branching: the empty affine system on n variables has nullity n yet SAT is immediate. Conversely an inconsistent linear system with a zero row 0=1 is immediately UNSAT. Rank/nullity are useful algorithmic parameters, not unrestricted hardness measures.
2. An existential backdoor of size zero does not imply fast discovery without a specified, polynomial recognizer. For any CNF F, a semantic terminal classifier 'SAT formulas' or 'UNSAT formulas' gives a zero-step existential classification but encodes the original decision question. Thus an uncharged semantic selector is circular.

## Module interfaces
2-SAT: implication SCC, exact both-label decision, O(N) graph work after encoding.
Affine XOR: recognize a conjunction of explicit parity equations, Gaussian elimination O(N^3) bit operations under a conservative polynomial bound; output witness or contradiction. Extraction of hidden XOR structure from arbitrary CNF is not free.
Components: split variable-disjoint factors; SAT is conjunction; independent witnesses concatenate. Discovery via incidence graph.
Treewidth: given a verified decomposition of width w, dynamic programming O(2^{w+1} poly(N)); constructing the decomposition is charged.
Backdoor: verify each restricted residual is in a tractable class, then branch on all 2^k assignments; discovery cost must be added.
Symmetry: only use certified automorphisms preserving the formula and its branch conditions; finding a full automorphism group is not free.
Clause learning: add only logically entailed clauses with checked resolution/RUP-like evidence; runtime is not known polynomial for all inputs.
Matching: only use for exact recognizable reductions with proved bidirectional decision semantics.
Canonicalization: syntactic sorting and tautology/duplicate removal is polynomial; semantic equivalence canonicalization is not assumed polynomial.
Polymorphisms: tractability of a fixed constraint language does not establish a cheap algorithm for arbitrary mixed 3-CNF; class recognition and conversions must be paid.
Kernelization: a polynomial-time equivalence-preserving kernel of polynomial size is insufficient alone because original F already has polynomial size; require a stronger decreasing parameter or polynomial solvable terminal.

## Reproducible finite checks
Companion script meta_test.py: independent exhaustive assignment oracle versus sound recursive branching with 2-SAT implication reachability. Executed locally on Python 3: UNSAT eight-clause full three-variable cube; seven-clause SAT neighbor; XOR contradictory conjunction; four-clause 2-SAT UNSAT; two-component SAT. All five match exhaustive oracle. This verifies only finite correctness, not universal polynomial runtime. The script is deliberately simple and does not implement all proposed modules.

## Charged resources
For each run log N, parsed clauses, all failed recognizers, chosen reductions, canonicalization comparisons, branch nodes, duplicate cache hits, generated bytes, peak live bytes, and sum of live bytes per step. Physical CM and minimal-description CM are distinct. No sole-tape exponent follows from a RAM pseudocode ledger. Time cap T<=K N^a implies polynomial peak space and CM but cannot be contradicted merely by 2^n assignments.

## Comparison and next dependency
Discovery's cutset algorithm gives O(3^s poly(N)) for its restricted gain instances, and Accounting's block theorem yields a sum of local costs. Our generic Boolean backdoor theorem has analogous O(2^k poly(N)) behavior. Neither proves that every 3-CNF has polynomially discoverable logarithmic backdoor, bounded-width decomposition, or polynomial-size shared residual DAG.

Next target: specify a fully polynomially checkable decomposition certificate with AND/OR child semantics and polynomial total cost, then prove an ALL-INPUT polynomial-time discovery procedure or construct an adversarial family defeating the specific selector. Do not infer P=NP from existence alone; unrestricted P versus NP remains OPEN.
