## Theorem A: exact complete deterministic cycle-rank algorithm (PROVED)
For any strict-C source on n named variables and m clauses, form its bipartite variable-clause incidence multigraph, with t components. The incidence cyclomatic rank is b=3m-(n+m)+t=2m-n+t. In a spanning forest there are b non-tree edges. Choose Z to be the **variable endpoints** of these non-tree edges; k=|Z|<=b. Removing all variables Z leaves a bipartite incidence forest, since every off-forest edge was incident to Z.

Enumerate all 5^k color assignments to Z. For each, perform exact tree-factor dynamic programming on the residual incidence forest. Variable messages are 5-bit feasible-domain intersections, factor messages enumerate the exact 30 C tuples, including clauses with zero, one, two or three pinned Z variables. If a row succeeds, reconstruct all colors and verify every original physical C clause, then output SAT with a full labeled witness. If all 5^k rows fail, return UNSAT by complete enumeration. This is sound and complete for both polarities on **arbitrary labels and clause orders**, without supplied path, free polarity advice, optimistic local witnesses or oracle children.

Including source parsing, graph/feedback construction, failed rows, factor tests, witness reconstruction, physical-clause verification and full output, the algorithm runs in O((n+m) 5^k) time and O(n+m) writable words for explicit graph, masks and one witness. The read-only source is not counted as writable space; the implementation materializes its incidence representation, and this IS counted. The original C predicate is used for final replay. The primal constraint graph has a tree decomposition of width at most k+2: after deleting Z the incidence forest gives width-2 factor bags; adding all Z to each bag raises width at most k+2. No assertion is made that k is small on unrestricted C inputs.

## Theorem B: smallest physical UNSAT strict-C control (PROVED)
The 3 physical clauses F3 = C(a,b,c) AND C(a,b,d) AND C(a,c,d) are UNSAT. By translation fix a=0. If b=0, first clause fails; if b in {1,2,3,4}, the common allowed c,d values in the first two clauses are H(0,b)={2,4},{1},{4},{1,3}, respectively. No pair c,d in the relevant H satisfies C(0,c,d), checked also directly with both original R and independent GF(5) quadratic formula. Every physical deletion is SAT, with ordered witnesses (a,b,c,d): deleting clauses 1/2/3 gives (0,1,1,2), (0,1,2,1), (0,1,2,2). Every deleted clause is FALSE and both retained clauses TRUE. Each deletion has exactly 50 satisfying assignments among 5^4. The incidence graph has 4 variables, 3 factor nodes, 9 incidences, girth4, b=3. Any 1- or 2-clause strict-C formula is SAT by direct completion, so 3 is the exact smallest number of physical UNSAT clauses. This control has no growing-girth/hardness implications.

## Theorem C: arbitrary-relabeling Mycielski upper bound (PROVED)
For every odd L>=5, consider G_L=M^3(C_L), previously used as an easy-to-generate graph-critical private-head C source. A width-2 path decomposition for C_L has bags {0,i,i+1}, 1<=i<=L-2. Given a tree decomposition of H of width w, replace each bag B by B union its clone copies B' union {new root} for M(H). The bag-tree property is preserved and the new width is at most 2w+2. Three applications yield w<=30. Each edge uv of G_L is replaced by C(h_uv,u,v) with a fresh private head, whose primal triangle is covered by a new leaf bag {u,v,h_uv} attached to a bag containing u,v. The full primal width remains <=30. Removing any physical C clause, permuting every variable name, or permuting clauses cannot increase treewidth. Combining this with fixed-k tree decomposition discovery (Bodlaender 1996) and exact finite-domain CSP DP yields a **uniform theoretical linear-time full SAT/UNSAT + witness algorithm** on the entire arbitrarily relabeled family, with an astronomically large fixed width-30 constant. This is NOT the prior canonical-index O(log N)-space implementation, nor a measured practical bound; the generic width-30 solver was not implemented in this run.
