# Strict T5 witness: minimal exceptional-variable anchor and D5-streamed proofs
**2026-11-19 Pacific.** PROVED on a restricted parameterized class, COMPUTATIONALLY VERIFIED finite instances, OPEN unrestricted lower bounds and P versus NP.

## Exact canonical source
Colors Z5, R(a,b) iff (b-a) mod5 in {1,3}, C(x,y,z) iff either directed 3-cycle orientation. Three distinct variable **names** per physical clause, no global injectivity. Exactly 30/125 triples accepted. Equivalent GF5 predicate: (a-b)^2+(b-c)^2+(c-a)^2 = 1 mod5. Q/P/S historical relations are different; none substituted.

## Theorem A (PROVED): deterministic O(n+m) minimum exceptional-variable anchor
For an n-name, m-clause source and each active name a, define E_a = clauses not containing a, U_a = union of names appearing in E_a, k_a=|E_a|, r_a=|U_a|. Let h be the number of active names, d(x) its clause incidence degree, c(a,x) the number of clauses containing both a and x. Then, for x != a, x not in U_a iff c(a,x)=d(x), giving
r_a=h-1-sum_{x != a} [c(a,x)=d(x)].
Each physical clause generates exactly six ordered co-occurrence pairs. Stable counting sorts by the two indexed coordinates count all c(a,x) in deterministic O(n+m) word operations and O(n+m) writable words. Choose a minimizing (r_a,k_a,a) lexicographically. The implementation has no expected-time hashing dependence. The bound r_a <= 3k_a is immediate.

## Theorem B (PROVED): both-polarity witness and explicit UNSAT transcript
For every valid strict-C source and arbitrary partial color pins, choose the above a and enumerate every pin-compatible assignment xi to U_a. A physical exceptional clause contradicted by xi yields a source-indexed failure. Otherwise the residual clauses all contain a, so call the previously proved **fully pinned common-anchor** solver, which handles every anchor color, bipartition phase and 2SAT consequence and returns either a complete assignment or a checkable odd cycle/implication-path UNSAT certificate. If it returns SAT, replay every original physical C clause and pin. If all branches fail, stream each branch's original-clause or pinned-2SAT certificate and return UNSAT. An independent verifier reconstructs **every** row and its failure without calling a SAT oracle. This is a complete deterministic decider and witness producer, with worst-case O((n+m)5^r) time and O(n+m) live writable words (direct-index RAM), proof output up to O((n+m)5^r log(n+m)) bits fully charged. Explicit user leaf cap instead yields UNKNOWN, never unsound polarity. Arbitrary labels entail separately charged canonicalization.

## Theorem C (PROVED): D5 orbit reduction if and only if no pins
For an unpinned source and r>=1, the ten automorphisms v-> +/-v+t preserve the original C relation. Assign the first U name color zero; retain the lexicographically smaller of each remaining (r-1)-tuple w and -w. This enumerates exactly K_r=(5^r+5)/10 distinct D5 orbits. Burnside: identity fixes 5^r tuples, four nontrivial translations fix none, and each of five reflections fixes one. Every full solution can be translated/reflected to a representative; row-by-row UNSAT proofs are exhaustive up to symmetry. Pinned cases enumerate every compatible assignment without pretending the symmetry survives. For r=1..6, orbit counts 1,3,13,63,313,1563.
