## A growing subfamily of the balanced images

Use only symmetric C over Z5, the 30 ordered permutations of 012,123,234,340,401. All clauses have distinct names and full initial domains. The ordered tournament R has 40 tuples. The circuit description is a generator for ordinary strict-C strings. Its Boolean symbols, including NOT, are absent from the target signature.

Start with one free Boolean input x and c_0 = x OR (NOT x), realized by one NOT and one OR. For i=1,...,k choose a bit s_i, append four NOT gates with fresh outputs in the following topological order, and expose c_i as the next output.

    l_i = NOT c_(i-1)                     r_i = NOT l_i
    c_i = NOT (l_i if s_i=0 else r_i)     d_i = NOT (r_i if s_i=0 else l_i)

The operand choice is made while emitting the input. The second output d_i is private. For each fixed incoming c, every hidden gate value is determined. Thus in SIL's ordered two-port semantics the module is equality for s_i=0 and disequality for s_i=1. Joining the stages on the same wire identities and hiding only private wires gives c_k=1 XOR s_1 XOR ... XOR s_k. This is a semantic proof that permits contracting the entire chain to one bit. Each x has a unique Boolean gate assignment.

Feed this circuit and output c_k to the exact balanced twin generator at the recovery revision. It appends three NOTs and chooses the accepting or rejecting pin. The strict-C gate compiler contributes ten anchor frames and one local lift per gate in a given frame. The equality splitter contributes two private lifts per link. These multiplicities come from the source proof, not from existential SIL projection. With accepting pin, even parity gives count 20·2^E and odd parity zero. The rejecting pin reverses the two. Thus switching any s_i changes both the decision and the first count digit. A positive count corresponds to both choices of x. No witness or deletion oracle is supplied.

## Actual decoder and accounting

For each of the L cuts j let U_j be the first digit of A's correct answer. Its externally sampled source is the uniform s, so U_j is a fair bit conditional on B_j. Here B_j consists of the fixed program/model, public family specification, k, pin, cut index and the initial tape on the left of j. The latter can be synthesized from the public parameters. It contains no switch-dependent bit. On replay the decoder retains the entire evolving left tape, including any caches or code A actually moves there. Right-side state is hidden; a decoder handed the full configuration or an authenticated parity cache would already know the output.

For the actual execution, assign one token to **each left-to-right crossing of j**. If the head later returns across j before halt, the token is the finite control state immediately after that first right-to-left crossing. Otherwise the token is the special terminal value ⊥. Let Pi_j be this ordered token stream in fixed-width blocks of b_event=ceil(log2(|Q|+1)) bits. Each departure pays for its own token. The return state is physically carried by the returning head. The terminal value records the absence of a return in a complete halted trace. Charging its encoding to the matched departure is an offline accounting convention, not an online signal sent by a halted machine.

The decoder simulates A on the known left prefix and initially blank exterior to its left, as appropriate to the tape convention. On a departure it commits A's last write on the left and consumes one token. On a return-state token it resumes with that state on the left cell adjacent to the cut. The return transition wrote on the right, so the saved left tape is current. A terminal token leaves that tape final. Direct halting on the left also ends replay. If the departure itself halts on the right, consume its terminal token. By induction on excursions this reconstructs the actual first output digit. The same rule handles a solver that erased the original code, transferred a cache, or earlier guessed the default digit. The distinction between no return and an explicit return matters. Local halting/terminal tokens make the admissible streams conditionally prefix-free with B_j known. No right-side timing, random source query or unreturned head register is exposed.

Let D_j and R_j count physical departures and returns. Every input requires D_j≥1: otherwise changing one switch leaves all visited cells and the final output digit identical, against correctness. D_j,R_j interleave, with R_j possibly one smaller. At the first departure the provisional first output cell has the **same** value on every input in the distribution because only the fixed prefix could have been scanned. With probability at least 1/2 it differs from the required digit. On each such run A needs an inward crossing to change it. Thus E[R_j]≥1/2. Each unit head transition crosses at most one cut in one direction, and departure and return transitions are disjoint. On the identical distribution,

    H(U_j | B_j) = 1,      H(U_j | B_j, Pi_j) = 0,
    L ≤ sum_j E[|Pi_j|] = b_event sum_j E[D_j] ≤ b_event E[T],
    E[T] ≥ sum_j E[D_j + R_j] ≥ 3L/2.

The last inequality uses direction and the output contract. It does not add the entropy lower bound to the movement lower bound. Event capacity in the token inequality is b_event, r=1, with zero source-dependent header bits conditional on B_j. There is one token per departure and one predetermined cut per transition, even when the solver shares a cache. The decoder reconstructs an answer digit for any solver; no solver is required to issue residual queries or store its crossing history. The separate address and code costs below make explicit how that record can be used.

**What is compulsory after relocation.** The original program may copy everything to the right and compute there. To change a provisional output digit it then physically returns. If it can determine the final digit during its first scan, the same prefix coupling still applies. The argument does not compel a second visit to the original splitter fields or a prescribed event *after* semantic contraction. On authenticated switches the exact two-port relation is specified by one parity bit and can be composed with a running XOR. The left side needs only the resulting digit for this decoder. Multiplying the entropy per cut by k by requesting k latent answers has no justification. DeltaSIL concerns a changed constraint occurrence. A solver answering the original instance owes no such counterfactual output. In the unrestricted program a stronger post-acquisition obligation stays OPEN.

## Resource ledger and limits

- A receives all N actual input bits on its sole tape at time zero. Scans, validation, address arithmetic, parser and recognizer trials, failed candidates, conversions, switches, queries, caching, retained maps, copying, recomputation, all writes and emission of the binary result and terminator count in its own T and peak storage. The lower bound selects a disjoint subset of moves. It gives no free parser or representative.
- A physical crossing needs no explicit address word because it is a unit move of the head. The cut is fixed for its one decoder. Randomly selecting an unspecified cut, or logging raw events out of order, would require identifiers. A straightforward offline instrument counts head position and time from the moves, using O(log(N+T+2)) bits each, compares the current location with the chosen coordinate, pairs excursions, and outputs its tokens. A simple materialized trace may cost O(T log(N+T+2)) bits with such fields. k and j cost O(log N) bits each if sent as separate requests. These costs are not fresh solver traffic. Sharing a known family description avoids sending it once per cut.
- Left replay for one decoder uses the charged initial prefix (at most N bits), its own tape expanding by at most T cells, the control and token sequence. Uniformly generating that prefix costs polynomial work in N, even by regenerating a zero-switch template, and can use O(N) bits with serial scans. The direct simulated left transitions number at most T. If an explicit one-head decoder keeps the token list and tape separately, repeated travel for at most T tokens costs at most O((N+T)^2) time for replay after setup and O(N+T) cells for fixed A. This is an external decoder ledger. Jointly replaying all cuts is unnecessary for A and incurs its own costs if performed.
- Family generation is separate. The published compiler's O(V^4) conservative sole-tape time and O(V) physical storage construction bound applies with V the source-plus-output length, here Θ(N) for a fixed pin and the explicit source program. Emitting an entire distribution is not preprocessing supplied to A. On the canonical promise there is also an authenticated polynomial shortcut: infer candidate k from n, generate the baseline and each single-switch encoding, read one differing coordinate per switch, regenerate the proposed codeword and compare the whole source exactly. All these scans, addresses, copies and mismatches cost polynomial work. For either fixed pin, masks are disjoint as proved above. A total solver can fall back on full strict-C search when authentication fails (UNKNOWN as a recognition result); a uniform polynomial bound on that fallback is not assumed. A matched input admits exact parity evaluation and output 0 or 20·2^E, whose bit length is at most E+5. A solver need not build the implementation used by the external decoder.
- For the same fixed A,K,a and N, b_event r K N^a would have to be exceeded by the conditional-entropy demand net of headers to defeat the cap via this inequality. Here it is L=Θ(N). This asymptotic rate excludes no polynomial exponent a≥1; exact movement constants can constrain small K at a=1. The handoff ceilings remain S=O(N^a), physical CM=O(N^(2a)), minimum-description CM=O(N^(a+1)), count-map circuit size O(N^a log N). Input plus time index can describe a full deterministic configuration by replay, even when replay is slow. Physical residence and minimum-description CM are distinct. This proof establishes no extra lower demand on either. Counting and decision have separate solvers and executions.

**Controls.** Identity/negation is an affine, bounded-width, forced-output control. Private variables admit the stated unique Boolean lift, the ten frame choices and splitter orientations remain count factors, and either pin permits complement reuse. These cheap scalar computations survive. The named result holds for arbitrary reorganization during execution; a free pre-permutation of the written input can destroy the common prefix. Uniform global ID renamings preserving a common source-independent prefix yield the same cut proof where such cuts exist. Hash equality cannot authenticate the candidate. Full-state entropy H(answer | complete configuration)=0 is compatible with the partial-state decoder. SAT and UNSAT executions above have no witness-output obligation. Matching, private-leaf and Tseitin controls do not force retained boundary tables. DISJ is inapplicable as a source theorem here; no DISJ lower bound is imported. The argument uses deterministic causality and geometry, gives no nonrelativizing or algebrizing barrier breakthrough, no Natural Proofs claim, no configuration-count lower bound and no simultaneous DTISP tradeoff derived from another execution.
