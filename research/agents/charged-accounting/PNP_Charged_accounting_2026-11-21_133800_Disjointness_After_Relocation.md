## Universal entropy account with a real decoder

Draw D uniformly among masks of weight floor(k/2), put A=complement D and B=D. P=binom(k,floor(k/2)). For each cut j let U_j=D. Let B_j consist only of public M, k, cut index j, compiler specification, fixed distribution and output convention. These items identify the physical cut coordinate c_j by the public layout. No actual source mask, input cell, arbitrary time index or receiver configuration is included. For this choice H(U_j|B_j)=log2 P. Write Pi_j for the ordered sequence of M-states immediately after actual crossings at c_j through halt. Direction alternates from left to right first. Tape addresses are physical neighboring cells: a move accounts for exactly one boundary. The state alphabet is finite. The machine has no jump, free address bus, second head or clock.

For distinct D,D' the two diagonals are positive and I(complement D,D') is negative, since equal weights imply D' has a bit outside D. If two complete state strings agreed, alternating the left excursions of the first computation and right excursions of the second would yield the actual deterministic hybrid run. Each excursion starts in the agreed state with the corresponding local tape; after the last crossing its halting continuation agrees on the final side. Thus the final left answer digit would still be positive. This contradicts correctness on the valid mixed input. Consequently Pi_j identifies D. This uses only the one-head splicing principle [3]. It does not assume an online request for the mask or demand that M itself reconstruct D.

An explicit offline decoder enumerates the P publicly describable masks, regenerates each complete canonical diagonal string, and simulates the fixed M to halt while recording transitions crossing c_j. Compare each record sequence by exact equality and return the unique matching mask. Termination follows from totality. This requires no access to the hidden input or virtual residual answers. It is deliberately expensive. On a bit-tape decoder one conservative budget under the cap is O(P (N^4+(N+KN^a+1)^4)) transitions and polynomial live space in N+KN^a for one candidate at a time: generate the compiler image, explicitly keep head index and cut address, simulate single steps with scans, save state records, compare two strings including lengths. Prefix copying/concatenation, candidate generation and output of k bits are absorbed. These are observer costs, separate from M's T. The decoder supplies a mathematical injection, not an efficient inversion or extra paid work by M.

Now split Pi_j=P_j S_j at any chosen phase boundary on this same run. P_j is the exact past sequence including its length. S_j collects only subsequent crossings. No timestamp or work tape is supplied for free. Decode as above from P_j concatenated with S_j. A self-delimiting code for S_j emits one symbol per state plus one end symbol, all of width b=ceil(log2(Q+1)). Concatenating fixed-width words with an end symbol is prefix-free. Conditional on B_j and P_j, its expected length bounds the conditional entropy of U_j: injectivity of the completed transcript gives H(U_j|B_j,P_j) ≤ H(S_j|B_j,P_j), and Kraft's inequality gives

    H(U_j | B_j,P_j) ≤ b (E |S_j| + 1).
    Σ_j H(U_j | B_j,P_j) − bL ≤ b r E T_suffix,    r=1.

The end symbol is an analyst's framing cost per cut, not an extra physical halt event charged L times. Equivalently the framing cost can be zero when the suffix is publicly known to be empty. For completeness the entropy bound follows from normalizing 2^(−code length) over possible codewords and nonnegativity of relative entropy; [4] gives the noiseless coding context. The cut address can be sent separately in ceil(log2(N+1)) bits if j is not public; our B_j already fixes it. The target execution pays each actual movement across intervening addresses. Stored indices, data and physical locations remain charged in the space ledger. The decoder must compute or read the public address when it runs. There is no per-event free address payload. r=1 because a one-cell move can cross at most one selected boundary, on that execution. Cutting a transcript never creates a new solver event.

With empty pasts the left side before framing is L log2 P. This yields E T_M ≥ L(log2(P)/b−1) for each solver and gives Ω_M(N²/log N) on growing k. For any checkpoint the corresponding budget test is Σ_j H(U_j|B_j,P_j)−bL > br K N^a to contradict the proposed cap from future crossings alone. If side information additionally includes a paid record R, replace the conditional entropy by H(U_j|B_j,P_j,R) throughout. For a cost attribution, distinguish past from future: the chain rule splits H(U_j|B_j) into I(U_j;P_j|B_j) plus the residual H(U_j|B_j,P_j). It does not license charging the full original entropy again. These entropies describe a public observer. A receiver already given either whole correct diagonal mask has zero conditional uncertainty about D from the promise alone. There is no assertion of log P fresh Shannon bits *unknown to that receiver*. Correctness on the off-diagonal inputs forces the distinct physical transcripts.

## An authenticated solver with no subsequent separator crossings

Read the unary header and total length, testing n=515+1476k for integer k≥1 and the prescribed m,w,N. Preserve the original bits on a fixed tape track for fallback. Build the all-zero canonical template. For each of the 2k mask coordinates build its single-one variant; compare the strings until their first differing bit. The varying selector swaps the arguments of its selected and dummy NOT gates. This changes the final incoming copy in the equality path for its l wire to a different clause-slot occurrence. Its recorded identifier therefore changes. No other selector changes any positions in that packet list. Fixed degrees fix all offsets, and the output of other selectors never changes these syntactic names [1]. Consequently each chosen address is a two-valued bit controlled solely by that coordinate on every canonical input. Read the real input bit at the discovered address and compare with the baseline to recover that coordinate. Serialize the recovered pairs in coordinate order. Regenerate the entire claimed canonical encoding and compare every bit and the length with the original before admitting the shortcut. An alternate clause or name order may carry identical semantics and still fail this test. Failure means UNKNOWN to this recognizer. It restores a clean initial tape and runs a total general solver. No hash establishes equivalence.

This algorithm is uniform. Templates, search failures and movement to an addressed cell all cost real work. The conservative one-tape O(N^4) generator of [1] applied O(k) times costs O(N^5) transitions even on a noncanonical candidate with a plausible header. Compare and erase templates between iterations; keep a constant number of O(N)-bit strings, k pairs, and O(k log N) bits of indices if saved. Indexed reads or copies implemented by repeated scans fit this budget. Test length before large expansions. Parsing invalid/truncated headers and restoring input and blank work cells on fallback fit the same bound on valid inputs. A counter can always use enumeration as its total fallback. If given a correct global fallback of time at most K_0 N^a, the combined solver has time O(N^5+K_0 N^a) globally, retaining the exponent for a≥5 with a possibly larger constant. The counterexample gives no unconditional global polynomial cap or guarantee of preserving a specified small K. The universal transcript inequality applies to *any* fixed solver satisfying its proposed cap.

At admission, put the two mask bits for each coordinate in one finite product-alphabet cell on a work track, consecutively from the left origin; put an end marker after the last pair. Return the head to the origin in a fixed control state. The suffix uses no saved scalar answer. It can ignore or erase other work data as needed to emit the canonical binary word and terminator. On the tested image the time to reach this checkpoint may dominate. The original source and scratch space remain physically charged while resident.

For decision, scan k pairs and use a one-bit flag recording whether some pair is (1,1). Return left and emit the correct bit and terminator. This costs O(k) transitions. For counting, scan the same pairs, maintaining that flag and an integer initially 98. Add 282+(1−B_i) on each pair. At the end the integer is E+k−|B|. Carry its little-endian binary representation alongside the moving head on another fixed track, using a nearby start marker. Scanning a register to add a fixed constant, shifting its digits one cell, and returning to its marker each cost O(log(k+2)). On conflict return to the origin and print 0 and a terminator. Otherwise slide the register back to the origin and emit 1010 followed by its value in zero digits and the terminator. A zero test, decrement and one-cell register shift per emitted zero cost O(log(k+2)). No variable-width word is a primitive operation. There are O(k) output digits. All suffix work, including head returns and local register maintenance, costs O(k log(k+2)) = O(N) transitions for counting.

The suffix stays inside the original unary header. For example its maximum head position is bounded by max(k,103+283k)+ceil(log2(100+283k))+4: the register starts over the current pair or current output position, holds at most 98+283k, and its scans inspect at most one end cell beyond its digits. This fits before n=515+1476k for all k≥1. Every separator boundary lies strictly to the right. Output cleanup of local auxiliary symbols can be done by one scan over this left region with a delimiter if the chosen tape alphabet requires untagged final output symbols. The single first digit suffices for the crossing proof. No selection of head positions depends on uncharged data, and address or counter movement costs actual transitions.

For these machines S_j is empty for every admitted input. Each full transcript equals P_j on the diagonal distribution, so H(U_j|B_j,P_j)=0 **even without giving the observer the relocated masks**. If the actual checkpoint pairs are supplied as side information this also follows immediately. The closed-form product and the ability to relocate jointly falsify any universal positive *second* service at these old cuts. Real work to assemble the record stays in the prefix. This is stronger than bounding output entropy or assuming that the receiver can answer a family of hypothetical residual queries.
