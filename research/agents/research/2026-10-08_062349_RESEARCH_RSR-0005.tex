\section{Primary literature and transfer classification}
Feigenbaum, Kannan, McGregor, Suri, and Zhang define a graph stream as an
edge sequence and a semi-streaming algorithm as using
$O(n\operatorname{polylog}n)$ bits with sequential passes; their Definitions
1 and 2 also charge per-edge time and pass count \cite{rsr0005Semistream}.
The present negative clauses are exactly an edge stream and the post-gate
arrays have that space form.  Classification: \textbf{directly transferable
model definition}, not a theorem that recognizes this SAT language.

Reingold proves deterministic undirected $s$--$t$ connectivity in logspace
and hence $\mathrm{SL}=\mathrm L$ \cite{rsr0005Reingold}.  One could invoke
connectivity repeatedly instead of retaining union--find arrays.  The paper
guarantees polynomial time under random-access graph representation, not
two near-linear file scans.  Classification: \textbf{KNOWN THEOREM} for
connectivity and a \textbf{FAILED TRANSFER} to the joint near-linear-time
ledger.

Beame proves $TS=\Omega(n^2)$ for finding unique elements in an $R$-way
branching program and states the same tradeoff for sorting, with scope that
includes offline multitape Turing machines and log-cost RAMs
\cite{rsr0005Beame}.  Classification: \textbf{direct theorem transfer} to an
implementation that literally solves arbitrary-order duplicate detection by
generic sorting in that model.  It is not a lower bound for the whole
recognizer.  The new accepted encoding instead requires the negative edges in
strict lexicographic order, so duplicate rejection uses one previous pair.
Canonical order is therefore a load-bearing restriction, not free power on
arbitrary DIMACS.

Recent streaming work on special classes such as tournaments gives further
near-linear-space graph decompositions, but the directed-complete tournament
promise is not the undirected disjoint-clique object here.  Classification:
\textbf{structural analogy requiring a new transfer theorem}.  No Schur-square,
quadratic-relation, collision-entropy, cryptographic binding, or random-oracle
idea supplies this syntactic certificate or all-CNF coverage.  For this run
the post-quantum prompts are \textbf{FAILED TRANSFER}; the exposed algebraic
structure is algorithmically helpful rather than a hardness source.

\section{The realized accepted language}
The header declares $n$ variables and $m$ clauses.  The body has first a block
of $p\ge2$ all-positive clauses, each with $h\ge2$ distinct increasing
literals.  It then has a block of negative binary clauses whose positive edge
pairs are strictly lexicographically increasing.  The first pass verifies
\[
 n=ph,\qquad m=p+e,\qquad e=h\binom p2,
 \qquad h\le2p,\quad p\le2h.
\]
It rejects oversized numeric tokens before integer conversion.  The strict
edge order proves both simplicity and duplicate-freedom while retaining one
pair.  Since $p,h\ge2$,
\[
 e=\frac{n(p-1)}2\ge\frac{n^{3/2}}{4\sqrt2},
 \qquad 32e^2\ge n^3.
\]
Only after this test does the procedure allocate parent, component-size,
degree, and positive-row arrays.

On the second pass, union--find consumes every negative edge without keeping
an edge list.  At the end there must be exactly $h$ connected components,
each of size $p$, and every vertex must have degree $p-1$.  Because the graph
is simple, each component is a $p$-clique.  Sorting the $n$ pairs
(component,positive-row) must give each row $0,\ldots,p-1$ exactly once in
each component.  Every variable must occur in exactly one positive row.

\begin{theorem}[FILE-DENSITY-PHP1]
The source-visible procedure is total and exact on its declared immutable-file
model.  Every VALUE input is satisfiable if and only if $p\le h$.  Every
attempt, including a post-gate semantic failure, uses
\[
 T(M)=M^{1+o(1)},\qquad S(M)=M^{2/3+o(1)}.
\]
\end{theorem}
\begin{proof}
The parser either rejects or reaches an explicit terminal branch; both passes
are finite.  On VALUE, the positive rows are pigeons and the negative cliques
are holes, with exactly one variable at every row--component intersection.
Any model chooses at least one variable per row and at most one per component,
so $p\le h$.  Conversely, when $p\le h$, inject rows into components and set
the unique intersection variables true.

Before the gate, the tokenizer retains a fixed 4096-byte chunk, at most one
bounded token, counters, the prior positive literal, and the prior edge.  This
is $O(\log M)$ bits apart from the fixed chunk.  After the gate,
$e\le M$ and $n^3\le32e^2$ imply $n=O(M^{2/3})$.  All arrays, roots, degrees,
and incidence pairs therefore use $O(n\log M)=M^{2/3+o(1)}$ bits.  Two scans
cost $O(M)$ token work; union--find costs $O(e\alpha(n))$ operations and the
$n$-pair sort costs $O(n\log n)$ comparisons.  Logarithmic-bit parsing and
word operations contribute only polylogarithmic factors.  Thus the displayed
bounds hold on the same code path for success and failure.
\end{proof}

The proof uses the canonical token and edge order, immutable reread, and
density-before-allocation order.  Removing any one requires a new theorem.
