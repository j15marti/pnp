## Source semantics, exact compiler and proof

The finite implementation uses canonical ASCII JSON version=1 with n, s, init, exactly n stage records and a terminal accept record. Each stage contains a topologically ordered arbitrary binary-truth-table gate list (a,b,tt), a fixed input-index integer or a list of selector-bit wire references, and s next-register output wire references. Wires reference s register bits, hypothetical current bit z, constant 0/1 or earlier gates. All 16 truth tables are allowed; repeated predecessors and arbitrarily many consumers per gate are allowed. Terminal logic is a separate shared-gate DAG. Source bit length L=8B where B is its canonical encoded byte length. Invalid encodings, an input-dependent selector before the read, and reachable repeated reads are rejected as outside the declared class.

The compiler starts with history (t=0,r=init,mask=0). At every reachable triple (t,r,mask) it evaluates the same stage DAG on hypothetical z=0 and z=1, checks that both selector outputs choose the SAME j<n and j is absent from mask, and explores successors (t+1,r_z,mask union {j}). These hypothetical evaluations are paid gate computations, not SAT oracles. On stage n it evaluates the actual final output gate. For the target BP, quotient actual nonterminal nodes by (t,r), not by mask: both outgoing arcs and selected index are functions of (t,r), independently of the history mask. The compiler explicitly verifies this consistency.

**Lemma 1 (semantic/all-step transfer, PROVED/EXACT restricted).** For every accepted source A and every x in {0,1}^n, induction on t proves equality of source register r_t and target node (t,r_t), equality of chosen input index j_t, and equality of the branch after inspecting x_j. Exhaustive validation of all reachable history triples ensures every input is inspected at most once on every path. At t=n the same terminal DAG determines both labels. Two different masks may be merged because subsequent control and updates are completely determined by (t,r) and the just-read value; every merged history was actually explored for the read-once property. Thus B_A(x)=A(x) pointwise. The shared target has at most 2^s states at each of n nonterminal stages, so V<=n2^s and exactly 2V outgoing arcs. Distinct checked history triples H<=2^s(2^n-1). No prescribed exponentially unfolded decision tree is asserted.

**Lemma 2 (source lower-bound transfer, PROVED/EXACT restricted).** Under a fixed public variable order, each prefix assignment leaves one of at most 2^s persistent registers r_t, and the suffix function is uniquely determined by r_t and t. Its assignment matrix therefore has rank at most 2^s over every field K, yielding s>=ceil(log2(rank_K M_prefix)). This lower bound concerns SOURCE bits retained across stages, not its total intra-stage live gate workspace or general Boolean-circuit size. Under adaptive read-once ordering, fix any X:Y partition and maximum number of changes between an X-owned and Y-owned input test on a real path, b. The node-ID transcript of each accepting path at side switches defines a rectangle, because every X-only segment constrains only X given public boundary IDs, and likewise Y. These deterministic rectangles partition the 1-cells, so rank_K M_XY <= number of accepting transcripts <= sum_{j=0}^b V^j <= sum_{j=0}^b(n2^s)^j. For b>=1, log2 R<=log2(b+1)+b(log2 n+s); for b=0, R<=1. This reproduces TMR-4/053 through an ACTUAL source compiler, with no rank-to-unrestricted-circuit inference.

## Single-realization resource ledger

Let G_t be shared gate records at stage t including terminal, Gmax their maximum, H the actually reachable (round, register, mask) history triples, V the shared BP nonterminal node count, L source bit length, and D=L+O(H(n+s+log(H+2))+V(n+s+log(V+2))) live bits. D covers parsed source DAGs, sequential queue, all histories and masks, target ID directory, shared transitions, address registers, buffers and compiled output. Compiler authentication and any failed legal histories are paid. Each stage DAG is evaluated twice at each history triple and final gate DAGs are evaluated for terminal links. No gate is replicated in the SOURCE encoding because of fan-out; repeated evaluations in the compiler are charged. No hash-table constant-time lookup assumption is needed.

A fixed deterministic multitape implementation with naive sequential table scanning achieves conservative, simultaneous upper bounds T_total=O((H(Gmax+n+s+1)+1)D^2+nD+n^2) and S_peak=O(D) for the SAME compiler-and-evaluator execution. O(D^2) covers each address/wire lookup with bit arithmetic and parser scans, nD covers up to n compiled-node accesses and n^2 covers n possibly distant read-only source-input head moves. Outputting the O(V(log n+log(V+2))) bit packed BP is included. The source itself uses s persistent register bits, at most Gmax intermediate gate bits plus addresses within a stage, and its explicit gate code as immutable read-only input or an additional L live bits if copied. The compiler is generally exponential in n+s; it is NOT a polynomial circuit-to-OBDD reduction or an FLMV contradiction. Concrete source step -> abstract BP step is a semantic exact simulation with one queried bit per step, not a claim that offline compilation costs zero. Lower bounds on BP evaluation TIME do not follow just from the smaller compiled graph.
