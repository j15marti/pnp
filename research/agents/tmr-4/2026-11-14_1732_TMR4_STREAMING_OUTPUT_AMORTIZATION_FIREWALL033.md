# TMR-4/033: hard-MCSP-output amortization falsifier

**Time:** 2026-11-14 17:32 PST (America/Los_Angeles). **Role:** TMR-4 Cost-Sound Abstraction. **Status:** STREAMSHARE047 PROVED/RESTRICTED elementary symbolic counterexample, independent TMR-1/TMR-5 review OPEN. Finite checks COMPUTATIONAL. P versus NP OPEN.

## What is new

Previous TMR-4/031-032 and TMR-1/031 derive upper bounds on Boolean circuit complexity of a function generated by individually indexed evaluation. For fixed locally moving evaluator E, the candidate bound is $CC_n(Y_{E,F,n})\le K_E(t+2)\log_2(2(t+2))$ with $t$ maximum execution time over indices. Its contrapositive bounds the **worst indexed generator** for an MCSP NO output, not the elapsed time to generate the whole table with shared computation.

**New here:** a formal non-implication and an explicitly charged, all-length uniform counterexample: even when a target is an ordinary MCSP NO at any fixed $s=\lfloor N^\mu\rfloor$, $0<\mu<1$, a generic fixed transducer emits that full table in linear time if the source already contains the table. Restarting another fixed transducer to obtain each bit separately uses quadratic source ingress. There is no valid universal multiplication of a per-bit or worst-index bound by the number of bits. This strengthens the earlier $L=N$, source bit-indexing control by quantifying the amortization gap **on NO instances**.

## Exact model and theorem

Let $N=2^n$, with $n$ the circuit input arity and $L=N$ the source length. The source $x\in\{0,1\}^N$ is an explicit full truth table, not a succinct SAT formula. Exact ordinary MCSP at gate cap $s=\lfloor N^\mu\rfloor$ asks whether fan-in-two AND/OR/NOT circuit complexity $CC_n(x)\le s$, with free constants and unrestricted fanout.

**STREAMSHARE047 (PROVED/RESTRICTED, review OPEN).** Two fixed deterministic total finite-alphabet transducers, with ordinary locally moving tape heads and one fixed program each across all lengths, satisfy the following.

1. Whole-table transducer $G$ reads each $x_j$ once left-to-right and writes the same bit to a sequential output. A charged EOF check finishes the computation. Total transitions are $\Theta(N)$; writable work storage is $O(1)$.
2. Indexed transducer $E(x,i)$ reads a separately supplied binary index, then scans the source from its left end to position $i$, emitting $x_i$. A finite-alphabet counter charges every position update. Its source reads are exactly $i+1$, and its total execution takes at least $i+1$ transitions and at most $O((i+1)(n+1)+n+1)$. Invalid indices and malformed lengths can be rejected by the same fixed finite program.
3. Reinitializing $E$ for each of the $N$ indices requires source ingress
   $$
   Q_{\mathrm{restart}}=\sum_{i=0}^{N-1}(i+1)=\frac{N(N+1)}2,
   $$
   whereas the actual $G$ uses $Q_{\mathrm{shared}}=N$ source reads. Thus
   $$
   \frac{Q_{\mathrm{restart}}}{Q_{\mathrm{shared}}}=\frac{N+1}{2}=\Omega(N).
   $$
   Counting index parsing, intermediate counters, state, input rereads and output can only increase actual independent-evaluator time. It does not force any extra charge on $G$.
4. For **every sufficiently large $n$**, there exists a table $x_n$ with $CC_n(x_n)>\lfloor N^\mu\rfloor$. The *same fixed* generic $G$ emits that ordinary MCSP NO table in $\Theta(N)$ time. The existential $x_n$ is not hardcoded into $G$ and need not be efficiently discoverable from $n$.

**Proof of item 4.** A crude upper bound on the number of truth tables realizable by circuits of at most $s$ gates is
$$
D(n,s)=(s+1)(n+s+2)\,[3(n+s+2)^2]^s.
$$
The factors overcount gate count, output-wire selection, gate type and ordered input-wire selection. At $s=\lfloor N^\mu\rfloor$ with $0<\mu<1$,
$$
\log_2 D(n,s)=O(s\log(n+s))=O(N^\mu\log N)=o(N).
$$
Since there are $2^N$ possible full tables, some are MCSP NO. Items 1 to 3 are explicit physical source traversals and a single streaming copy; their programs depend on neither the chosen $x_n$ nor its circuit complexity.

**Precisely falsified implication:** Even if every fixed indexed evaluator needs $\Omega_E(N^\mu/\log N)$ time on at least one index of a NO table, it does **not** follow that whole-output production needs $\Omega(N^{1+\mu}/\log N)$ time. Our particular indexed evaluator costs at least $\Omega(N^2)$ to run from scratch at every index, yet a different, shared, correctly charged generator costs $\Theta(N)$. Different machines are intentionally compared only to invalidate a transfer, never to claim a lower bound for any one machine.

## Restrictions and hostile controls

This is a copying/representation counterexample, not a SAT-to-MCSP reduction. The source is of length $L=N$ and is itself the full table. It does not transform a 3-CNF encoding of length $L$ into an MCSP table with $N=\mathrm{poly}(L)$ while preserving SAT and UNSAT labels. A purported such reduction would still have to pay every output bit, preserve the specified threshold and both labels, and prove its own compilation interface. No MCSP classifier, circuit-minimization oracle, hardwired per-length program or nonuniform advice is built. The existence of a hard $x_n$ by counting does not provide a uniform efficient algorithm to find it.

The model also permits an algorithm to retain or reread all input, cache answers, perform global algebra or share evaluation; in fact $G$ is a maximally simple shared-output control. Horn/2-SAT, GF(2) elimination, bounded-treewidth DP, disjoint products, padding, auxiliary variables, index reordering, compact Walsh summaries and native signed-source checker failures remain separate previously established falsification requirements, not consequences of the counting proof. Original accepted-byte R_mix341 counterexamples are preserved as genuine.
