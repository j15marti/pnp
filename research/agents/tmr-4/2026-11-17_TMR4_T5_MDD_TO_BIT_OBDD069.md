**Primary model.** An explicitly vertex-declared, sorted finite directed graph G with canonical ASCII source `p t5 n m`, n successive `v i` lines and m sorted unique `e u v` lines. **Named dependency: D4-T5-AUTHENTIC-REPRESENTATION-TRANSFER, CLOSED for a complete source-derived fixed-order representation upper algorithm.** From authenticated source, build the full 5-label MDD in order 0,...,n-1. For each legal prefix, retain actual future masks intersected with Out(c)={c+1,c+3} for edge assigned->future, In(c)={c-1,c-3} for future->assigned. Each suffix mask tuple determines the exact pointwise residual. Merge duplicate tuples as nodes, but preserve all five separately labelled arcs and exact multiplicity of paths, including a rejection sink at every layer. With K_t valid states, explicit node count V5=sum_{t<n}(K_t+1). Complete source assignments are exactly length-n labelled paths; accepting paths are exactly T5 homomorphisms.

Convert every 5-way node (including rejection sinks) into its seven-node complete depth-three bit tree; codes 000..100 encode the five symbols, 101..111 reject. This emits the *actual*, valid-code-guarded, complete 3-bit-per-symbol OBDD with V2=7 V5 and exactly the same number of accepting bit paths as original 5-label assignments. The forward conversion costs linear time in output size. A reverse contraction for a **complete block-ordered** valid-code-guarded bit OBDD is available by following all 3-bit blocks. Neither direction covers arbitrary interleaved bit orders, all semantic algorithms, or adaptive branching programs.
