# TMR-4/087: Exact T5 clique-phase holonomy on authenticated sources

Date: 2026-11-18 PT. Owner: TMR-4 / PNP Cost-Sound Abstraction. Restricted exact upper bound only. P vs NP OPEN.

**Theorem:** Enumerate oriented K5 subgraphs from canonical source G and identify each with T5 (120 constant bijection checks). A non-T5 K5 is a sound UNSAT certificate. If the clique-vertex incidence graph is connected and covers every source vertex, its original assignment count is 0 or 5. Each T5 K5 is rigid up to the five cyclic translations, so along any shared vertex the relative clique phases satisfy t_j-t_i=theta_i(v)-theta_j(v) (mod 5). Propagate phases, reject inconsistent cycles, check every original arc. If a base map passes, exactly its five translations pass. This is a charged polynomial-time source recognizer.

**Complete OBDD:** Query first source color to fix a global phase. Subsequent queried values must equal the corresponding translated chart color; otherwise enter a shared depth-indexed reject chain that still queries all remaining original variables. Width <=6, nodes <=6n. If UNSAT use an n-node complete reject chain. Each full source assignment has exactly one complete path, yielding exact accept/reject multiplicities Z and 5^n-Z. Since the corresponding 3n-bit source has at most five satisfying Boolean words, every arbitrary interleaved bit order also has a complete Boolean OBDD of width <=6, nodes <=18n, by retaining <=5 accepting prefixes plus one reject state.

**Family:** For n>=13 orient the 4th power of cycle C_n: edges i,i+d (d=1..4 mod n) oriented forward iff d in {1,3}. Each consecutive K5 is T5, and they connect via overlaps. However cyclic phase holonomy is consistent iff 5 divides n. Hence Z=5 when 5|n, otherwise 0. Graph parameters: n vertices, m=4n, cycle rank q=3n+1, vertex connectivity 8, degree 8, minimum vertex cover n-floor(n/5). The complement/nonadjacency graph is connected and false twins absent for n>=13. Treewidth <=8. Every source is fully arc consistent with all 5 unary colors, including UNSAT examples. This is a high-q, high-connectivity source-aware cheap-algorithm counterexample, not a lower bound.

**Four falsifiers:** Disjoint T5 cliques have 25 solutions and a one-arc bridge yields 10; connected source is insufficient without connected K5 incidence. All local K5s can pass while their global phases conflict. A non-T5 K5 orientation is a sound local UNSAT witness; loops/digons are retained. High q, cover size, connectivity and hard-looking diagrams do not certify intrinsic computational hardness given this source-aware exact counter and width-six OBDDs.
