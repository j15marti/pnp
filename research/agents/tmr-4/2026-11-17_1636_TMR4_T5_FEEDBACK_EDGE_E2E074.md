## Constructive theorem
Let E' be the underlying distinct unordered nonloop source edges, c the number of connected components, and f=|E'|-n+c. A deterministic lexicographic spanning forest has exactly f non-tree edges. Put S equal to the endpoints of those edges, g=|S|<=2f. Every edge of the induced graph on U=V\S lies in the spanning forest, hence G[U] is a forest.

Query S in increasing ID order. Query the residual forest in recursive centroid order, processing every child component contiguously. The maximum centroid depth is h=ceil(log2(|U|+1)). Every already queried vertex with a neighbor still unqueried belongs to S or to the current centroid ancestor chain. Prefix-equivalent states store only the colors of that live frontier, with a dedicated reject-completion state. On querying a new vertex, check **all original oriented arcs** whose second endpoint is now known; every original arc is checked precisely once, including self-loops. Future cofactor semantics depend only on live boundary colors and whether any earlier arc failed. Therefore the complete original-assignment 5-ary OBDD has width <=5^(g+h)+1, at most n(5^(g+h)+1) internal nodes and 5n(5^(g+h)+1) outgoing labeled edges. All valid/invalid original assignments retain their own multiplicities and #YES+#NO=5^n.

For a separate exact count-only algorithm, enumerate the 5^g assignments on S, check arcs within S, turn S-U arcs into unary 0/1 factors, and eliminate each tree component of U using five-state sum-product. Count=#YES exactly; all factors are from the authenticated source. This runs in O(25^f poly(L)) deterministic bit time and poly(L) peak space with streamed pinned assignments and exact O(n)-bit integer counts. In particular f=O(log L) gives uniform polynomial-time exact counting, as well as polynomial-size OBDD construction. The OBDD bound is not an all-FBDD lower bound.

A complete seven-node three-bit decoder for each 5-way node yields <=7 times as many Boolean OBDD nodes while invalid bit codes reject. An explicit parsimonious no-auxiliary CNF has 3n Boolean variables and exactly 3n+15m listed clauses of width <=6, including optional tautological forbiddance records for self-loop pairs. These are constant-factor recodings, not free computational speedups.
