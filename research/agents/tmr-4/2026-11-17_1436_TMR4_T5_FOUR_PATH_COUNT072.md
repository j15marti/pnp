## The exact theorem

Let A be the 5-by-5 T5 adjacency matrix, B=A^T. For each skeleton edge u<v use a private chain u,t1,t2,t3,v, each step directed either way. Its pinned-endpoint extension count equals A^f B^r where f+r=4. Since A and B are circulant they commute; the five row-zero coefficient vectors for r=0,1,2,3,4 are:

- (4,4,1,6,1)
- (1,4,4,1,6)
- (6,1,4,4,1)
- (1,6,1,4,4)
- (4,1,6,1,4)

Every entry is positive. Thus every core-vertex coloring admits an extension regardless of all arc orientations. A polynomial recognizer checks N=k+3e, M=4e, index-aligned private interior triples, four unique oriented arcs per edge and exact canonical reconstruction. Assign all core vertices 0 and search at most 125 internal triples per edge for a valid witness, giving a polynomial-time decision program on the recognizable family.

The independent internal path variables allow exact count marginalization:
Z_T5(G)=sum_{sigma:V(H)->Z5} product_{uv in E(H)} W_uv(sigma(u),sigma(v)).
No pointwise equivalence on marginalized internal variables is claimed.

With exactly two forward/two backward arcs, every edge uses the same symmetric positive matrix with row-zero vector (6,1,4,4,1), i.e.
W=[[6,1,4,4,1],[1,6,1,4,4],[4,1,6,1,4],[4,4,1,6,1],[1,4,4,1,6]].
Direct integer determinant gives det(A)=2, det(W)=16. Because W is everywhere positive, nonbipartite, and rank five, Bulatov-Grohe's nonnegative symmetric partition-function dichotomy implies exact Z_W(H) is #P-hard [1]. The bounded-degree simple-H strengthening is due to Govorov-Cai-Dyer [2]. The explicit subdivision H->G is linear size on bounded-degree simple H, keeps bounded degree and satisfies #Hom(G,T5)=Z_W(H), so restricted T5 exact counting is #P-complete under polynomial-time Turing reductions. This does NOT make the identically-YES decision problem NP-hard or prove P != NP.

The shortest length yielding positive pinned-endpoint transfer for every arc orientation is 4. Lengths 1--3 have zero entries for every orientation; all longer paths are positive. Exact counts are distinct from Boolean existential path support: replacing W with the all-ones matrix preserves SAT but destroys #Hom and rank.
