\begin{abstract}
This run independently audits BDNF-WRAPPER-GATE1, the newest load-bearing
claim in the WRAPPER spine.  The claimed $M^{1-o(1)}$ raw residual size is
correct and survives local variable reindexing; an explicit source map only

in its explicit restriction-emission scope.  Universal favorable coverage,
the joint WRAPPER implication, ARC closure, and P versus NP remain open.
\end{abstract}

\section{Primary literature and transfer limits}
The source family was checked in Ordyniak, Schidler, and Szeider,
\emph{Backdoor DNFs}, IJCAI 2021, Theorem~2 proof sketch
\cite{ordyniak2021bdnf}, at
\url{https://www.ijcai.org/proceedings/2021/0194.pdf}.
The paper states the variables and clauses used below, the $s+2$-term

parameter is the number of terms; FPT by itself gives no fixed polynomial
exponent when that parameter grows with input length.

Dowling and Gallier give a linear-time algorithm for explicit Horn
satisfiability \cite{dowling1984horn}.  This is a theorem transfer for an
already available explicit Horn residual, not a theorem that acquires a
backdoor DNF, avoids all residual access, or covers arbitrary CNFs.
The cross-domain source-map analogy from compilers is therefore only an
\textsc{Analogy/Candidate}: provenance maps matter for witness-preserving
outputs, but decision SAT permits semantic quotienting when correctness is
proved.  No compiler theorem forces a decision-only child to retain source
variable identities.

\section{Local-reindexing theorem}
For $s\ge1$, let $r=2^s-s$ and use variables
$p,a_1,\ldots,a_s,q_1,\ldots,q_r$ with clauses
\[
 (a_i\vee p)\quad(1\le i\le s),\qquad
 (a_1\vee\cdots\vee a_s\vee q_j\vee\neg p)
 \quad(1\le j\le r).
\]
The source DNF has terms
\[
 p=0;\qquad p=1,a_1=\cdots=a_s=0;\qquad
 p=1,a_i=1\quad(1\le i\le s).
\]

\begin{lemma}[BDNF-WRAPPER-GATE1, independently reviewed]
In an ordinary explicit indexed-CNF representation, the second term produces
a raw residual of length $M_s^{1-o(1)}$ under either global or local
reindexing.  An explicit local-to-source map cannot improve the bound.
\end{lemma}
\begin{proof}
The parent has $\Theta(2^s s)$ literal occurrences and
$\Theta(2^s)$ variables, so
\[
 M_s=\Theta(2^s s^2).
\]
The residual is exactly the $r$ distinct unit clauses $(q_j)$.  Global
indices use $\Theta(s)$ bits.  After local reindexing, $r$ distinct
identifiers still need $\lceil\log_2 r\rceil=\Theta(s)$ bits in the
declared ordinary indexed list.  Hence in either case
\[
 L_s=\Theta(r\log r)=\Theta(2^s s)
     =M_s^{1-o(1)}.
\]
An explicit source map contains $r$ local/source pairs and only increases
the representation.  Since
\[
 \frac{\log L_s}{\log M_s}
 =\frac{s+\log s+O(1)}{s+2\log s+O(1)}\longrightarrow1,
\]
every fixed $b<1$ eventually fails.
\end{proof}

This theorem concerns the literal restricted formula.  A succinct range of
unit clauses is a different encoding and needs an access/return theorem.
More importantly, a decision-only child need only preserve satisfiability,
not syntax or witness coordinates.

\section{Small decision-only countermodel and repair}
\begin{lemma}[BDNF-VALUE-ESCAPE1]
There is one uniform exact partial procedure that accepts every displayed
source-family input, runs in $O(M)$ time and $O(\log M)$ work space, emits
no children, makes no call to the hypothetical SAT decider, and returns TRUE.
\end{lemma}
\begin{proof}
Use the fixed ordinary variable identifier $p=1$.  Scan the input once.
For each clause, syntactically compute its cofactor under $p=0$.  If the
clause is satisfied by $\neg p$, discard it.  Otherwise require the residual
clause to be nonempty and contain only positive literals.  If every clause
passes, return TRUE; otherwise return \textsc{fail}.  Soundness is immediate:
set $p=0$ and every other variable to one.  The scan needs only input
addresses, the identifier $p$, and constant-many flags.

Every source-family input passes.  Its long clauses contain $\neg p$, and
each $(a_i\vee p)$ becomes the positive unit $(a_i)$.  Thus a short-circuit
OR procedure may stop at the first backdoor-DNF term.  In fact all displayed
residuals are satisfiable: the second is the positive-unit set $(q_j)$ and
each remaining term satisfies every clause outright.
\end{proof}

Thus RSR-0002's raw-emission theorem is correct, but the phrase
\emph{favorable charged direct solve} must not remain open for this
particular family.  It remains open for arbitrary supplied backdoor DNFs and,
more importantly, as part of a uniform favorable cover of all CNFs.
