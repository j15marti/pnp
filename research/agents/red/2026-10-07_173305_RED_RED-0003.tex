soundness, sink-SCC orientation, class-completeness corollary, and charged

complete semantic implication oracle.  Thus ``class-complete implication

selector theorem itself is \textsc{Proved/Exact}.  The remaining original-
scale realization, ARC closure, and P versus NP remain \textsc{Open}.

\section{Primary literature and exact transfer}
Gwynne and Kullmann define the reductions $r_k$, the classes
$\mathrm{UC}_k$, and the generalized local-search classes
$\mathrm{SLUR}_k$ \cite{gwynne2014nested}.  Their Theorem~5.7 gives the
nested-input-resolution characterization used by RSR-0003, and their main
identification $\mathrm{SLUR}_k=\mathrm{UC}_k$ supplies the direct-search
interpretation.  The paper also states that fixed-$k$ membership is
coNP-complete.  These are direct theorem transfers for fixed explicit CNFs;
they do not give a cheap recognizer, favorable portfolio density, a
sublinear encoding, or a growing-depth uniform algorithm.

The cross-domain transfer is exact order theory, not an analogy.  Associate
to each CNF its model set.  Semantic implication is set inclusion, so a
selector based on any sound implication test is a directed comparison graph
in this poset.  Singleton model sets form an arbitrarily large antichain.
Consequently even a complete comparison oracle does not bound width.  The
control-theoretic language of a stronger Lyapunov test is only an
\textsc{Analogy/Candidate}: a more complete local certificate gives no
contraction unless it also proves a decrease of the actual frontier
potential.

\section{Independent audit of NESTED-IMPLICATION-SELECT1}
For ordinary CNFs $A,B$, define $A\Rightarrow_kB$ when $r_k$ detects
contradiction after every clause of $B$ is falsified in $A$.  Reduction
soundness gives
\[
 A\Rightarrow_kB\quad\Longrightarrow\quad A\models B.
\]
Thus an edge $A\to B$ points from the smaller model set to the larger one.
If a condensation component is discarded in favor of a reachable sink,
every model represented by the discarded component remains represented by
that sink.  Retaining one vertex of each sink SCC therefore preserves the
OR.  This confirms the direction used in the manuscript.

With $T_1(m)=O(m)$ and a direct depth-first implementation,
\[
 T_{k+1}(m)=O(m^2T_k(m)+m^2)=O(m^{2k+1}),
 \qquad T_k(m)=O(m^{2k-1}).
\]
There are $O(m)$ target clauses and $O(q^2)$ ordered pairs, so the stated
$O(q^2m^{2k})$ time follows.  The explicit frontier, graph, and one reduction
state per fixed level use $O(qm+q^2+km)$ live space.  These are safe upper
bounds, not optimality claims.

The strict witness also survives.  For
\begin{align*}
A={}&(x\vee a\vee b)(x\vee a\vee\neg b)
(x\vee\neg a\vee b)(x\vee\neg a\vee\neg b)(y),\\
B={}&(x),
\end{align*}
falsifying $x$ leaves an unsatisfiable binary core with no unit clause, while
one failed-literal level detects it.  Hence $A\Rightarrow_2B$ but not
$A\Rightarrow_1B$; $B\not\models A$ because of $(y)$.  This is a genuine
strict extension, not a density result.

\section{Direct-decision dominance}
\begin{theorem}[UCk-DIRECT-SOLVE-DOMINANCE1]
Fix $k\geq1$.  Given an explicit OR frontier $R_1,\ldots,R_q$ with
$|R_i|\leq m$ and the promise $R_i\in\mathrm{UC}_k$ for every $i$, one
uniform deterministic algorithm decides
$\bigvee_i\SAT(R_i)$ in
\[
 O(qm^{2k})\text{ time}
 \quad\text{and}\quad
 O(qm+km)\text{ live space}
\]
in the charged explicit-frontier model, with zero recursive children and
zero SAT-oracle calls.  Thus the $\mathrm{UC}_k$-completeness regime of
NESTED-IMPLICATION-SELECT1 is asymptotically dominated by direct decision of
the same sources before the $O(q^2)$ implication graph is built.
\end{theorem}
\begin{proof}
Process the residuals sequentially.  On one residual $F$, first apply $r_k$;
if it derives contradiction, return UNSAT for that residual.  Otherwise
choose the least remaining variable $x$.  Test $F[x=1]$ with $r_k$.  If the
test derives contradiction, commit $x=0$; otherwise commit $x=1$.  Repeat.

The class $\mathrm{UC}_k$ is closed under partial assignments, and every
unsatisfiable restriction of a member is detected by $r_k$.  Since the
current formula is satisfiable whenever the initial test did not refute it,
at least one branch is satisfiable.  If the positive branch is rejected, the
negative branch is satisfiable; if it is not rejected, the $\mathrm{UC}_k$
promise rules out its being unsatisfiable.  Induction therefore reaches a
satisfying total assignment.  This is the fixed-choice form of the exact
identity $\mathrm{SLUR}_k=\mathrm{UC}_k$.

There are at most $O(m)$ commitments.  Each invokes one $r_k$ test costing
$O(m^{2k-1})$, giving $O(m^{2k})$ time per residual and $O(qm^{2k})$ for the
frontier.  Depth-first reduction uses $O(km)$ scratch; storing the explicit
frontier contributes $O(qm)$.  Stop immediately when one residual is
satisfiable.  No child is emitted and no unknown SAT solver is called.
\end{proof}

The promise need not be cheaply recognized for this comparison: it is the
same promise under which the selector's class-completeness corollary is
invoked.  If only some sources are certified members of $\mathrm{UC}_k$,
each certified source can instead be decided directly: a satisfiable one
settles the whole OR, and an unsatisfiable one can be deleted.  Implication
edges discovered outside the class-complete promise may still be useful;
the base selector theorem is not retired.

\section{Minimal density countermodel}
For each $a\in\{0,1\}^n$, let
\[
 U_a=\bigwedge_{i=1}^n (x_i)^{a_i},
 \qquad (x_i)^1=(x_i),\quad (x_i)^0=(\neg x_i).
\]
Every $U_a$ is a conjunction of units and hence lies already in
$\mathrm{UC}_1$.  Its model set is the singleton $\{a\}$.  Therefore for
$a\ne b$, neither $U_a\models U_b$ nor $U_b\models U_a$.  All $2^n$
residuals survive not merely every fixed $r_k$ selector but a complete
semantic implication oracle.  In the ordinary indexed encoding each member
has $m=\Theta(n\log n)$ bits, so the retained width is
$2^{\Theta(m/\log m)}$, far beyond every fixed polynomial in $m$.

This countermodel is minimal in mechanism: no missing implication
certificate can help because the semantic order itself has no edge.  It is
not a SAT-machine lower bound.  Each unit conjunction is directly solvable,
and the parent generating the assignments may have an independent
structural shortcut.

\section{Hostile controls, oracles, and algebraic replacement}
\begin{description}
\item[] \textbf{Easy families:} Horn is handled at $k=1$ and 2-CNF at
$k=2$, but precisely these completeness facts activate direct decision.
Bounded-treewidth and componentwise families likewise admit direct dynamic
programs; selector width is not decision hardness.
\item[] \textbf{Source carry and current-scale calls:} neither theorem
queries the hypothetical $N^K$ solver.  Carrying source coordinates can only
add representation cost.  No unknown exponent is silently removed.
\item[] \textbf{Padding:} normalized tautological padding disappears;
nonsemantic padding cannot create comparable singleton model sets.
\item[] \textbf{Independent products:} products of distinct complete
assignments remain singleton and incomparable.  Direct component solving is
an explicit escape from materializing their Cartesian frontier.
\item[] \textbf{Oracle replacement:} a semantic implication oracle still
retains the singleton antichain.  A SAT oracle directly decides each node,
showing that selector width is not an oracle lower bound.  Both positive
theorems relativize and supply no nonrelativizing hinge.
\item[] \textbf{Algebraic replacement:} opposite affine parity classes are
nonempty and incomparable as CNFs, while Gaussian elimination or direct
parity evaluation decides each without selector edges.  The test checked
this through six variables.
\item[] \textbf{Finite versus asymptotic:} bounded tests validate exact
small instances only.  The fixed-$k$ proofs provide the polynomial bounds;
taking $k=k(m)$ would produce a different, generally superpolynomial
machine.
\end{description}

The post-quantum collision and Schur-square prompts are a
\textsc{Failed Transfer} for this arrow.  Collision statistics do not orient
model-set inclusion, and singleton antichains persist under perfect labels.
A construction-specific conflicting-openings theorem could verify an edge,
but verification completeness alone cannot reduce semantic poset width.
