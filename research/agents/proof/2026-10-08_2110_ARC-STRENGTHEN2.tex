\section{Infinite counterfamily and exact backdoor scope}
For $m\ge2$ let distinct variables be $x,y_1,z_1,\ldots,y_m,z_m$.
For $b\in\{0,1\}$, let $P_b(a,c,d)$ contain the four width-three clauses forbidding exactly the assignments of parity $1-b$. Consequently it is equivalent to $a\oplus c\oplus d=b$.
For any vector $\beta\in\{0,1\}^m$ define
\[
 F_{m,\beta}=\bigwedge_{i=1}^m P_{\beta_i}(x,y_i,z_i),\qquad
 G_{m,\beta}=F_{m,\beta}\wedge P_{1-\beta_1}(x,y_1,z_1).
\]
$F$ is satisfiable: choose $x=0,y_i=0,z_i=\beta_i$.
$G$ is unsatisfiable because its first triple must have both parities.
Both are connected, contain only proper width-three clauses, have no units or pure variables, and are neither Horn nor 2-CNF.

\begin{proposition}
The exact original portfolio returns FAIL on every $F_{m,\beta}$ and $G_{m,\beta}$, $m\ge2$. The least strong Horn backdoor of $F_{m,\beta}$ has size $m+1$, also under the original empty-clause shortcut semantics.
\end{proposition}
\begin{proof}
In each parity block every pair of its three variables occurs positively together in a clause. A strong syntactic Horn backdoor must hit each such positive pair. Conversely hitting every positive pair ensures each remaining clause has at most one positive literal, under every assignment. The resulting obstruction graph is $m$ triangles sharing $x$. Its minimum vertex cover has size $m+1$: with $x$ included one leaf per triangle is necessary and sufficient; without $x$ both leaves of every triangle are required.

For the satisfiable star this lower bound survives the implementation's empty-clause shortcut. If a positive pair is unhit, choose a full satisfying assignment that falsifies every assigned literal in a clause containing that pair. This is possible: there is at most one third literal, and each star variable can take either value in some satisfying assignment; complete its own block, then complete all remaining disjoint leaf pairs. Restrict this satisfying assignment to the proposed backdoor. No clause becomes empty, but the selected clause retains its two positive literals. The residual is non-Horn.

For the contradictory family we claim only absence of a backdoor of size at most two under the executable semantics. Such an assignment cannot empty a width-three clause, so the early-empty shortcut never fires. The positive-pair obstruction therefore applies; $m+1>2$. Constants, Horn and 2-CNF members fail by syntax, and components fail by connectivity. Therefore every original member fails on both families.
\end{proof}
Do not extend the $m+1$ claim to $G$ under executable semantics: assigning all three variables of its contradictory block produces an empty clause for every assignment, and the implementation replaces the entire formula by that clause. For $m>2$ this is a size-three operational backdoor, despite the larger syntactic obstruction graph. The distinction between syntactic Horn and Horn plus empty-clause detection is load-bearing.

\section{Constructive repair with explicit UNKNOWN}
The new partial algorithm reads the source clauses and returns TRUE, FALSE or UNKNOWN. Empty input returns TRUE. Nonproper or non-width-three input returns UNKNOWN. For each clause's unordered triple, scan all clauses and collect the eight-bit mask of sign patterns on that same triple. Duplicate patterns do not change the mask. A full mask of eight patterns gives FALSE immediately, since every assignment to that triple is forbidden. Otherwise every triple must have exactly the four forbidden assignments of one parity, or the answer is UNKNOWN.

Finally try each of the at most three variables in the first triple as a common hub. Check that every triple contains that hub, and that any two distinct triples share no other variable. If some hub passes, return TRUE; if none passes, return UNKNOWN. The check is performed by repeated source scans, not an uncharged table of triples.

\begin{proposition}[Sound partial decider and strict coverage extension]
Every Boolean answer of this algorithm is the correct SAT answer. It answers every $F_{m,\beta}$ and $G_{m,\beta}$, so prepending it to the original portfolio strictly extends that portfolio's successful domain.
\end{proposition}
\begin{proof}
Eight patterns on one triple form a contradictory subformula, independently of all other clauses. In the TRUE case every clause is part of a checked parity block, and distinct blocks share only the hub. Choose the hub arbitrarily and complete each independent leaf pair to its checked parity. This satisfies all clauses. UNKNOWN carries no semantic assertion. The displayed families pass the respective checks, whereas the previous proposition proves their original failures.
\end{proof}
Completeness is only for this declared star family and the checked contradictory triple. A cyclic overlap of parity triples, incomplete parity blocks and arbitrary connected CNFs need not pass. No current-scale SAT query occurs in acquisition or verification. No proof object is assumed freely supplied; masks and overlap relations are computed from the actual source.

\section{One-machine bit ledger and actual all-input composition}
Let $N$ be original encoded input bit length, with a fixed self-delimiting canonical encoding of signed binary variable identifiers and clause boundaries. The input is read-only. For source pointers of $O(\log N)$ bits, identifiers can be compared bit-by-bit without storing their values. Finding the sorted order of the three identifiers, checking equality of triples, and comparing literal signs needs only constantly many such pointers and counters. The eight-bit mask and three hub candidates are constant-sized descriptors with pointers to source substrings.

There are $O(N^2)$ clause-pair comparisons; a deliberately conservative $O(N\log N)$ time budget per source comparison, including copying input-address counters gives $O(N^3\log N)$ time. Parsing and duplicate handling fit that bound. All loops retain only constantly many source positions and counters, so additional workspace is $O(\log N)$. Trying three hubs multiplies time by a constant. Input address tapes are included. The Python prototype uses ordinary integer/tuple objects and does not certify physical logarithmic memory; the pointer-based bit-machine realization described here is the stated symbolic implementation. Its time bound is deliberately loose, not a claim of near-linear recognition.

For every fixed uniform exact SAT decider $A$ with joint bounds $(T_A(N),S_A(N))$, build one machine $H_A$: run this scanner; output any Boolean answer; on UNKNOWN release its state and start $A$ on the unchanged read-only input. Then
\[
 T_{H_A}(N)=O(N^3\log N+T_A(N)),\qquad
 S_{H_A}(N)=O(\log N+S_A(N)).
\]
All rejected scans are included. No parent or sibling computation is suspended, no derived input copy is retained, and the dispatch address/counter state is charged. If this scanner is instead nested inside WRAPPER, all ancestors and retained interfaces must additionally be counted; this top-level composition theorem does not erase them.

Thus an achievable pair $(t,s)$ supplies the actual joint witness
