\section{Why separate per-type asymptotics are insufficient}
Suppose countably many types $\tau_k$ were allowed.  On type $\tau_k$, let a
controller binary-expand to two exact children of length $N-1$ while
$N<2k$, and use a zero-child decision or a genuine square-root shrink for
$N\ge2k$.  For each fixed $k$, the bad lengths are finite, so a separate
statement $|Q|\le N^{1/2+o_k(1)}$ is true.  But choosing the root type
$\tau_N$ yields a binary tree of depth $\Theta(N)$ and exponential executed
multiplicity.  Rank in a recursively defined promise domain proves
termination, not a size-uniform resource bound.  A fixed finite type set and
one common modulus close this escape.

\begin{theorem}[uniform least-covered-domain closure]\label{thm:closure}
Fix a finite type set $\mathcal T$ and one total deterministic random-access
controller $A$ with finite dispatch on $\tau\in\mathcal T$.  It returns
UNKNOWN, an exact zero-child DECIDE, or an immutable exact PLAN with typed
ordinary-SAT child occurrences $(Q_i,\sigma_i)$ and an exact combiner.  No
child is executed during discovery.

There are constants $r,p,v$, $0\le h<1$, and one common
$\rho(N)\to0$ such that, on every type and complete length-$N$ encoding,
phase time is at most $N^{r+\rho(N)}$, and peak transient phase workspace
and retained continuation/generator state are each at most
$N^{p+\rho(N)}$.  Every PLAN obeys
\[
 \max_i\max\{2,|Q_i|\}\le N^{h+\rho(N)},\qquad
 \sum_i\max\{1,|Q_i|\}\le N^{v+\rho(N)},                \tag{2}
\]
with occurrences counted with multiplicity and one-child materialization and
replay charged.  Install an exact zero-child base for $N\le N_0$, choosing
$N_0$ so $h+\rho(N)\le\bar h<1$ above it.

Let $D_\tau^{(0)}$ be the zero-child inputs and define
\[
D_\tau^{(d+1)}=D_\tau^{(0)}\cup
\{X:A(\tau,X)=\operatorname{PLAN}((Q_i,\sigma_i)_i),\
 Q_i\in D_{\sigma_i}^{(d)}\ \forall i\},
\quad D_\tau^\star=\bigcup_dD_\tau^{(d)}.                \tag{3}
\]
Then one fixed depth-first machine $M$, not given $d$ and arbitrary off the
promise, decides $\SAT$ on $D^\star$ with promise worst-case bounds
\[
 T_{M,D^\star}(N)=N^{C+o(1)},\quad
 S_{M,D^\star}(N)=N^{P+o(1)},\quad
 C=\max\left\{1,r,\frac{v-h}{1-h}\right\},\quad
 P=\max\{p,h\}.                                         \tag{4}
\]
\end{theorem}
\begin{proof}
Correctness follows by rank induction in (3).  The common strict cap above
$N_0$ gives termination and depth $O(\log\log N)$.

Fix $\epsilon>0$ and pass one common threshold.  Use
\[
C_\epsilon=\max\left\{1+3\epsilon,r+2\epsilon,
 \frac{v-h+2\epsilon}{1-h-\epsilon}\right\}.
\]
Counting multiplicity and absorbing constant children into (2),
\[
\sum_i|Q_i|^{C_\epsilon}
 \le(\max_i|Q_i|)^{C_\epsilon-1}\sum_i|Q_i|
 \le N^{v-h+(h+\epsilon)C_\epsilon}
 \le N^{C_\epsilon-2\epsilon}.                           \tag{5}
\]
Strong induction absorbs the local phase and all smaller exceptional inputs.
As $\epsilon\downarrow0$, $C_\epsilon\to C$, giving one uniform $o(1)$.

For space, continuation frames and one-child buffers along a live path form
a geometric scale sequence under $N_{j+1}\le N_j^{\bar h}$.  Their sum is
$N^{P+O(\epsilon)}+N^{\bar h(P+O(\epsilon))}+\cdots$.
When $P=0$, the polylogarithmic frames over $O(\log\log N)$ levels are still
$N^{o(1)}$.  This charges all ancestors and proves (4) on the same machine.
\end{proof}

For the current numerical ledger
$(r,v,h,p)=(6/5,11/10,1/2,1/2)$, (4) gives $(C,P)=(6/5,1/2)$ only for
$\SAT\upharpoonright D^\star$.  It is not a point in $\A(\SAT)$ and yields no
FLMV contradiction unless $D^\star$ covers every root and completed
ordinary-SAT successor.  ARC6's claim that Construction8's family reaches a
fixed encoded-length base also needs care: its components have bounded active
variable count but logarithmically growing identifiers unless they are
renamed.  Nevertheless every four-clause component
$(\neg a\vee b\vee\pm c)\wedge(a\vee\neg b\vee\pm d)$ has the size-two
strong Horn backdoor $\{c,d\}$.  The already defined zero-child backdoor
member therefore places those examples in $D^{(0)}$ without assuming bounded
encoded length.  This repairs nonvacuity only; it gives no general coverage.

\section{Fallback construction: semantic audit and accessor repair}
Let $\widehat G(K)$ be ARC6's proper amplifier: replace each of the two binary
equivalence clauses in $G(K)$ by its two $\pm z$ ternary lifts.  If
$L=q_K+m_K\ge4$, then
\[
 q_{\widehat G}=2L+4,\qquad c_{\widehat G}\le5L+4.       \tag{6}
\]
Every non-hub pivot leaves $L-1$ intact parity blocks in one hub component,
giving at least $128(L-1)$ encoded bits.  The hub pivot creates eight
distinct non-tautological width-four resolvents per block, connected through
$r$.  With
\[
 \ell=1+\lfloor\log_{128}(5L+4)\rfloor,qquad
 U(L)=8[5L+8+(15L+14)\ell],                              \tag{7}
\]
the parent has at most $U(L)$ bits.  Direct substitution handles $L=4,5$;
for $L\ge6$, $U(L)\le160L\log_2L$ and ARC5's decreasing ratio proves
\[
128(L-1)>\sqrt{U(L)}\log_2(U(L)+2).                      \tag{8}
\]
Thus the PIVOT cap proof is exact.  Sign balance defeats iterative pure
elimination.

Clause isolation is load-bearing when arbitrary $F$ itself contains all
eight sign patterns on a triple.  Clone each literal occurrence to a private
$y$ and enforce $y=x$ with
\[
 (\neg x\vee y\vee\pm z),\qquad(x\vee\neg y\vee\pm w).  \tag{9}
\]
The four clauses are exactly equivalent to $x\leftrightarrow y$ after
existentially quantifying $z,w$.  Isolation uses $13m$ proper clauses and
prevents a full-eight mask.

The ARC6 accessor sentence is incomplete if only $y,z,w$ are shifted: (9)
still contains variable-width old identifiers $x$.  The exact repair is a
global injective renaming.  Choose a power $R=128^a>2(q+9m)$, map every old
$x$ to $R+x$, and allocate all $9m$ fresh identifiers consecutively above
$R+q$.  Every isolation literal code then lies in one ULEB-width bucket, so
each record has fixed length and direct clause-index arithmetic.  The map is
SAT-isomorphic, has $O((q+m)\log(q+m))$ encoded bits and $O(\log N)$ accessor
state.  ARC5's bucket-prefix accessor handles the amplifier suffix.  This is
claimed only on the authenticated clause-indexed/fixed-record proper-3CNF
interface; no free locator for raw variable-length sequential input is used.

Set
\[
 T(F)=\widehat G(\mathsf{Iso}_R(F)),\qquad H(F)=G(T(F)).  \tag{10}
\]
The masks in $T(F)$ have sizes one, two or four, every variable is
sign-balanced, the hub is connected, and the marker and exact-strip grammars
are absent.  Hence every named root member declines on $T(F)$.  On $H(F)$,
ARC5 defeats the outer prefix, exact GUARD-STRIP recovers $T(F)$ uniquely,
and the actual post-strip pair PIVOT/pure both decline without executing a
child.  Therefore, for the exact controller
\[
U_2=\operatorname{UNKNOWN}(\text{ARC5 root prefix};
 \text{GUARD-STRIP};\{\text{PIVOT,pure}\}),
\]
the repaired local reduction proves
\[
 \boxed{\A(U_2)=\A(\text{proper-3SAT})=\A(\SAT).}        \tag{11}
\]
The empty valid proper formula is handled as a direct TRUE base case and
malformed encodings return NO through the total parser; the embedding above
is applied only to nonempty valid proper inputs.
This theorem does not cover an unspecified future or affine member.  It
shows that the present fallback is SAT-hard, not that every future wrapper
must fail.

\section{Literature, barriers and proof-spine effect}
Promise-problem definitions permit arbitrary behavior off the promise; that
does not convert (4) into a total-language SAT algorithm.  See Goldreich,
\emph{On Promise Problems}:
\url{https://www.wisdom.weizmann.ac.il/~oded/PSX/prpr-r.pdf}.
E\'en--Biere bounded variable elimination deliberately applies exact
projection under growth controls, not a universal shrinking theorem
(DOI \href{https://doi.org/10.1007/11499107_5}{10.1007/11499107\_5}).
The primary endpoint remains Fortnow--Lipton--van Melkebeek--Viglas on the
deterministic random-access model:
\url{https://lance.fortnow.com/papers/files/tst.pdf}.  Nothing in this report
enters that forbidden region for all SAT inputs.

The closure and fallback proofs relativize: a semantic oracle does not
supply universal controller coverage, and algebraic access does not repair
the missing causal compiler.  No constructive circuit property is used.
Horn, 2-SAT, affine/parity, bounded-active-variable, padding, full-mask,
mixed-width, DEAD/COPY and compact-access controls either lie in declared
easy subdomains or are absorbed by the explicit guard; none transfers to an
arbitrary all-input SAT contraction.
