\section*{Result and exact scope}
P versus NP remains open. This run implements a concrete source-side
special case of the implicit-access obligation left by RECOVERY-STRENGTHEN2.
The declared LOCALBIT1/ORBITBATCH1 restrictions and orbit steps can be
evaluated by composing their coordinate maps, followed by one invocation
of the original field evaluator. Nested coordinate layers do not themselves
force nested invocations of that evaluator. This result is PROVED/EXACT
for supplied affine descriptors over one fixed field and an already
available evaluator; its application to a favorable all-input SAT wrapper
remains CONDITIONAL/OPEN.

The improvement is local: it removes avoidable repeated evaluation through
these address layers. It neither acquires the parent representation nor
turns an extractor output into an ordinary SAT instance. Conditional
$K$ elimination is retained exactly where RECURCLOSE1 and FORMAL-SPINE1
already establish it. No retired general sum-of-exponents endpoint is used.

\section*{Exact objects and quantifiers}
Fix a prime $p$, its ordinary binary residue representation,
$\ell=\lceil\log_2p\rceil$, and positive dimensions
$D=d_0\ge d_1\ge\cdots\ge d_k$. For every supplied collection
\[
 B_j\in\mathbb F_p^{d_{j-1}\times d_j},\quad
 c_j\in\mathbb F_p^{d_{j-1}},\quad
 E_j(z)=B_jz+c_j,
\]
every function $F:\mathbb F_p^D\to\mathbb F_p$ with an exact supplied
evaluator, and every $z\in\mathbb F_p^{d_k}$, consider
\[
 F_k(z)=F(E_1(E_2(\cdots E_k(z)\cdots))).
\]
Descriptors may vary from one executed request to another, but must be
available before evaluating that request. Their discovery, acquisition,
checking and retention are not supplied by the quantifier ``for every.''
There is one uniform evaluator taking the actual descriptors as input.

For the original block restrictions, $L_b(z)=(z,b)$ or $(b,z)$.
An orbit query $L_b(A^iz)$ is affine, with $B$ obtained by embedding
$A^i$ in the appropriate block and $c$ containing the fixed block $b$.
Invertibility of $A$ is required for ORBITBATCH1's full-domain address
identity, but not for the affine composition identity proved here.

The binary output considered here is only a final Hadamard coordinate
\[
 H(z,u)=\langle\operatorname{bin}_\ell(F_k(z)),u\rangle_{\mathbb F_2}.
\]
Intermediate layers remain field-valued. An intervening Hadamard encoding,
new low-degree extension, change of field, or reconstruction of a new
polynomial is not an affine address layer and is not covered.

\section*{Exact construction and proof}
\begin{proposition}[One root evaluator call]
The function $F_k$ can be evaluated by computing one root address and
then invoking the supplied evaluator of $F$ once. Alternatively its
address map can be precomposed into one affine pair $(M_k,b_k)$ with
$F_k(z)=F(M_kz+b_k)$.
\end{proposition}
\begin{proof}
Starting at $z$, apply $E_k,E_{k-1},\ldots,E_1$ in that order; this
computes the displayed nested address exactly and does not request any
field value of $F$ until the final address is known.
For precomposition put $M_0=I_D,b_0=0$, and update
\[
 M_j=M_{j-1}B_j,\qquad b_j=M_{j-1}c_j+b_{j-1}.
\]
Both right-hand sides use the old $M_{j-1}$. Induction shows
$E_1\circ\cdots\circ E_j:z\mapsto M_jz+b_j$.
The final mask is computed from the returned field element in $O(\ell)$
bit operations. No coefficient vector or complete evaluation table is
needed by this address transformation.
\end{proof}

\paragraph{Source eligibility guard.}
This identity holds even for arbitrary functions $F$. It does not imply
that a newly represented polynomial satisfies the degree, entropy or
reconstruction hypotheses of an extractor. Affine substitution does not
increase total degree but can increase individual degree. Nor does it
identify LOCALBIT1's declared Hadamard branch with the implicit vMS
invocation. Those are separate source obligations, retained as OPEN.

\section*{Charged time and simultaneous workspace}
Assume halving dimensions, allowing at most a fixed number $H$ of
same-scale stages between halvings. Let
\[
 P=\sum_{j=1}^k d_{j-1}d_j=O(H D^2).
\]
With supplied $B_j,c_j$, reverse chain evaluation takes $O(P+D)$
field operations. It can discard each old coordinate vector after the
next is formed, so coordinate scratch is $O(D\ell)$ bits. This excludes
neither the descriptors nor the live parent evaluator: they are added
explicitly below. Storing every dense descriptor requires
$O((P+D H)\ell)$ bits in this halving model. A streamed descriptor
alternative must charge its reads and regeneration instead.

Schoolbook modular arithmetic supplies a conservative $O(\ell^2)$
bit-operation cost per field multiplication/reduction, with $O(\ell)$
scratch; additions are cheaper. Hence supplied-descriptor coordinate
work is $O((P+D)\ell^2)$ bit operations, plus ordinary address and loop
costs. These can be absorbed in an explicit factor
$\operatorname{polylog}(D+\ell+k+2)$ on the stated bit-machine model.
This factor is never a unit-cost large-integer instruction.

Naive matrix precomposition costs
$O(DP)$ field operations and $O(D^2\ell)$ additional working storage
under the same bounded-stage hypothesis. A final composed query costs
$O(Dd_k)$ field operations. Precomposition is optional; it can be worse
than streaming when few addresses are requested. Its cost is charged
once per actual composed descriptor, not once per logical name reused
without stored state.

If instead the supplied descriptor is $(A,i,b)$, construction of $A^i$
by repeated squaring costs $O(d^3\log(i+1))$ field operations and
$O(d^2\ell)$ matrix storage. Finding a special matrix $A$ with the
source-required order, finding the field, selecting $b$, or determining
the path is additional acquisition, not part of a free supplied object.

\paragraph{Root SAT normalization.}
Let $N$ now denote the original SAT input's encoded bit length, which is
different from $D$, $p^D$, and the number of oracle evaluations. Suppose
the actual parent evaluator is acquired in time $A(N)$ and peak workspace
$S_A(N)$, retains $R(N)$ bits and evaluates one field value in time
$E(N)$ with additional workspace $W(N)$, uniformly over all requested
addresses. Take $P$ to be the maximum per-request dimension sum when
different requests have different descriptors. Let $C_{\rm desc}$ include
all executed descriptor construction, discovery and failed attempts;
let $B_{\rm desc}$ bound all simultaneously live descriptors; and let
$Q$ count field requests with multiplicity. With $C_{\rm outer}$ other
work and $S_{\rm outer}$ all suspended controller/ancestor state, a safe
streaming ledger is
\[
 T\le A+C_{\rm desc}+C_{\rm outer}
       +Q\bigl(E+\widetilde O((P+D)\ell^2)\bigr),
\]
\[
 S\le S_{\rm outer}+\max\{S_A,S_{\rm desc},
 R+W+B_{\rm desc}+\widetilde O(D\ell)\}.
\]
Here $S_{\rm desc}$ includes all other simultaneously live state while
constructing descriptors, and $S_A$ includes any descriptors retained
during acquisition or reacquisition. If $A$ is repeated, each execution belongs in
the total; a parent that cannot remain live cannot be called shared for
free. The outer work includes consuming all outputs and storing or
regenerating the next descriptor. One field value may service several
masks if that reuse is actually implemented; the no-cache code below
intentionally charges one field call per requested mask.

This supplies a concrete part of STREAMCOMP1's access ledger. It does not
erase $E$, $A$, or a hidden $N^K$ solver call inside either. Coordinate
fusion can make the address work cheap while the semantic value remains
expensive. These are bounds for one execution, not separate time and
space witnesses.

\paragraph{Useful original-parameter specialization.}
Under the checked NORMBLOW1 parameterization with fixed $\eta>0$,
$D=r$ is bounded independently of underlying computation time $T$,
$\log p=O(\log T)$, and polynomially bounded orbit indices have
$\log(i+1)=O(\log T)$. Given the required matrices and descriptors,
the coordinate routing and powering above take $\operatorname{polylog}T$
time and space even though $p^r=T^{\nu+o(1)}$ has large $\nu$.
The large ambient table is not materialized. This is positive cheap
address routing, not cheap acquisition of the root evaluator and not a
SAT-return length bound. If $T=N^K$ for fixed $K$, the routing remains
$N^{o(1)}$; any actual $T$-scale evaluation/acquisition charge remains.

\section*{Generic nested access: what cannot be silently removed}
For arbitrary implicit generators let $a_i$ bound the number of parent
probes per requested bit and $w_i$ all local work. If $Q_0$ is the charged
root access cost, a no-cache bound obeys
\[
 Q_i\le w_i+a_iQ_{i-1},\qquad
 Q_k\le Q_0\prod_{i=1}^k a_i+
       \sum_{j=1}^k w_j\prod_{i=j+1}^k a_i.
\]
The affine chain is the special case of one field-valued parent request
per level, which can also be evaluated iteratively. A general extractor
or re-encoding need not have $a_i=1$. If $k=O(\log\log N)$ and all
$a_i,w_i$ are bounded by a fixed power of $\log N$, the overhead is
$\exp(O((\log\log N)^2))=N^{o(1)}$, but the factor multiplying $Q_0$
does not eliminate $Q_0$. Generator stacks and caller state remain live
space charges. This identity is accounting, not a lower bound or a
claim that every source interface has polylogarithmic probes.

\section*{Primary literature recovery and correction}
Hoza's \emph{Typically-Correct Derandomization for Small Time and Space},
CCC 2019, Theorem 5 and Appendix A, explicitly establish a small-space
implementation of a Shaltiel--Umans extractor. The theorem gives
polynomial time in the supplied source length and space linear in seed
length under its entropy/error hypotheses. Appendix A handles field
representation, matrix construction and Hadamard conversion. This
supports the earlier observation that local extractor evaluation has a
real streaming implementation; it does not give a near-linear SAT
acquisition algorithm. Its characteristic-two construction is not a
drop-in proof for our supplied prime-field descriptors.

\url{https://eccc.weizmann.ac.il/report/2022/063/download}.

identity, not a transfer of field-operation counts as unit-cost bit time.

Fortnow's \emph{Time-Space Tradeoffs for Satisfiability}, Corollary 3.3
and Section 3, is the matched endpoint: one deterministic SAT machine
cannot have simultaneous $N^{1+o(1)}$ time and $N^{1-\epsilon}$ workspace
for fixed $\epsilon>0$ on the stated random-access Turing-machine model,
subject to the paper's constructibility conditions. This run builds no
machine meeting those resources. An eventual CNF route also needs the
charged conversion from the endpoint's encoded SAT language.

\section*{Falsification and computational validation}
The main runner implements block restrictions, powers of invertible
matrices, reverse address evaluation, affine precomposition and final
Hadamard masks over prime fields. It checks 1,928 paths and 12,112 bits:
1,728 paths exhaust the specified $p=2$, $4\to2\to1$ grid of matrices,
fixed blocks, orientations and short orbit indices; another 100 paths
each over $p=3,5$ use seed 3102 and exhaust their bottom points and masks.
All identities pass, with exactly 12,112 main-test parent calls and seven
additional calls for seven repeated identical requests. These tests
exercise the algebraic interface, not extractor quality or legal vMS
parameters. The runner records its SHA-256 and enforces a 25-second alarm.

Independent review tests 680 affine chains, including same-scale stages,
and 550 exact unrollings of the probe recurrence. The independent runner
uses seed 3058 and the same 25-second cap. Its proof review confirms the
address and resource statements within their stated scope. Logical
counts and conservative symbolic bit bounds are not Python RSS or
measured machine-complexity certificates.

The first attempted overextension is rejected: nonlinear re-encoding
cannot be folded into an affine address. Over $\mathbb F_3$, the map
$z\mapsto z^2$ has values $0,1,1$ and is not affine, since the first
two values force $az+b=z$. A code change or new LDE must expose its own
access graph. Likewise field changes have no declared affine meaning.
Reversing composition order or updating the affine shift with the new
matrix would be incorrect; the independent formulas use the old matrix.

DEAD/COPY/RECOMP controls retain actual repeated requests, acquisition
and descriptors. No full child table is forced. An easy quadratic
polynomial serves as the test evaluator; that is an upper-bound control,
not evidence of SAT hardness. Horn, affine, 2-SAT and bounded-treewidth
SAT remain unseparated by this argument. No SAT invariant is proposed
that could falsely declare these easy inputs hard.

The coordinate identity relativizes and remains true with an algebraic
oracle for $F$. Such an oracle can remove $E$ but does not prove an
ordinary-machine acquisition bound. Thus this is neither a
nonrelativizing nor a nonalgebrizing hinge. No Natural-Proofs circuit
property or cryptographic hardness assumption is used.

\section*{What is now reusable, and the next target}
Reuse this implementation wherever the source trace consists entirely
of the same-field affine restrictions followed by one supplied evaluator.
Do not reopen the claim that such layers necessarily cause multiplicative
semantic reevaluation. However, source identification, parent acquisition,
the total number of executed requests, descriptor discovery, all-input
coverage and an ordinary-SAT return are still OPEN.

The single next target is the first non-affine or re-encoding transition
in the actual reconstruction-to-SAT return trace: identify its input and
output types and prove its charged bit-access graph, or record precisely
that the ordinary SAT-return object is still undefined. Optimizing the
now-cheap coordinate segment cannot substitute for that transition.
