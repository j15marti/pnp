\section{Hostile re-audit of the guard}
The SAT extension is exact: set $h=r=0$ and, for every parity block, set the
third variable equal to the second.  Conversely $F$ is a conjunct.
Unit/pure, Horn, 2CNF, marker, component and parity-star members remain inert:
the equivalence pair is binary, all variables are sign-balanced, the hub
connects the instance, and every $P_0$ supplies the forbidden positive-pair
triangle.  The strong-Horn-backdoor-$\le2$ member fails because at least
$L-2$ disjoint parity triangles survive; for deletion set $\{h,r\}$, choose
$h=r=1$ and the $L$ triangles survive.

For a Davis--Putnam pivot $z\ne h$, at most the single $P_0$ block containing
$z$ is damaged, leaving $L-1$ blocks joined through $h$.  For $z=h$, the two
binary equivalence clauses reproduce all $L$ blocks around $r$.  Tautology
and exact-duplicate deletion do not remove those blocks; the current member
does not perform subsumption.  Thus every completed pivot has a component
containing at least $4(L-1)$ ternary records, hence at least $128(L-1)$ bits.
A prior charged acquisition abort also returns UNKNOWN.  Executed child-call
multiplicity is zero on this path.

The full parent obeys, with
$\ell=1+\lfloor\log_{128}(5L+2)\rfloor$,
\[
 |G(F)|\le8[6+5L+(15L+6)\ell]\le160L\log_2L.
\]
Consequently
\[
 \frac{\sqrt{160L\log_2L}\,
  \log_2(161L\log_2L)}{128(L-1)}<1\quad(L\ge4).

The left side is decreasing and equals $0.962526\ldots$ at $L=4$.
Therefore the maximum-child cap fails universally.  This proof is symbolic;

\section{Repairing the achievable-region transfer}
ARC5 cited a ``local clause-splitting adapter'' from arbitrary CNF to proper
3CNF.  REDTEAM4 actually supplied a fixed-width serializer from an already
indexed exactly-three-literal stream and allowed repeated variables.  The
following fixed five-clause block repairs the final properization step.

Give source clause occurrence $j$ three private variables $a_j,b_j,c_j$.
After deleting duplicate literals, let $C$ be its simplified clause.
If $C$ is a tautology, output five copies of $(a_j\vee b_j\vee c_j)$.
If $|C|=3$, output $C$ and four such fillers.  If
$C=(x\vee y)$, output
\[
 (x\vee y\vee a_j),\quad(x\vee y\vee\neg a_j)
\]
and three fillers.  If $C=(x)$, output all four clauses
$(x\vee \pm a_j\vee\pm b_j)$ and one filler.  Each output clause is proper,
each block has exactly five clauses, and existentially quantifying its private
variables gives exactly the original clause.  Blocks do not interact.
For a clause-indexed stream with header $q$ and $C_0$ clauses, the resulting
header is attained at $q+3C_0$, the count is $5C_0$, and any output record is
located by quotient and remainder in polylogarithmic time and logarithmic
workspace.

For a total DENSE-CNF1 input, first run the canonical parser, mapping malformed
strings to NO.  The standard random-access Cook construction for its
$N\operatorname{polylog}N$-time nondeterministic verifier produces a locally
indexed exactly-3-literal stream of $N^{1+o(1)}$ length; apply the fixed block
above and REDTEAM4's repaired serializer.  Every virtual input bit is then
generated in polylogarithmic time and logarithmic workspace.  Repeated reads
are charged, so a proper-3SAT machine with joint pair $(t,s)$ yields total SAT
time $N^{t+o(1)}$ and space $N^{s+o(1)}$ for $t\ge1,s\ge0$ (polylogarithmic
overhead is $N^{o(1)}$ even at $s=0$).  Restriction supplies the reverse
inclusion.  Composing with $G$ proves
\[
 \boxed{\mathcal A(U)=\mathcal A(\text{proper-3SAT})=
        \mathcal A(\SAT)}.
\]
This is an existence-region statement, not a favorable transition.

\section{Endpoint and the still-open causal link}

\[
 \NTIME[n]\not\subseteq
 \DTISP[n^c,o(n^{d(c)})],\qquad
 d(c)=\frac12\left(\frac{c+2}{c^2}-c\right).

For $c=1201/1000$,
$d(c)=1468676399/2884802000=0.509108\ldots$; hence $(6/5,1/2)$ has strict
