\paragraph{Result and strict status.}
\textbf{PROVED/EXACT partial-wrapper theorem; COMPUTATIONAL audit; joint
WRAPPER implication OPEN.}
The positive-clause family in the predecessor's exact clause-first fanout
guard has a cheaper portfolio route: the all-true assignment certifies SAT
in one source scan.  This run formalizes the more general
FIXED-PHASE-VALUE1 member.  A uniformly enumerable family of
$M^{u+o(1)}$ complete assignments whose bits cost $M^{v+o(1)}$ time to
regenerate gives a safe zero-child partial wrapper in
$M^{1+u+v+o(1)}$ time.  It returns TRUE only after direct verification and
returns \textsc{fail}, never UNSAT, when the family misses.  The member
therefore enlarges the certified portfolio and prevents a real
easy-family false alarm, but it does not prove favorable all-CNF coverage.
P versus NP remains open.

\section{Exact partial wrapper}
Let $F$ have encoded length $M$.  For every $P\in\mathcal P_M$ and every
literal $\ell$ encountered during a clause scan, evaluate the referenced
variable under $P$.  Reject the candidate as soon as one clause has no true
literal.  Return TRUE only if one candidate passes all clauses.

\begin{theorem}[FIXED-PHASE-VALUE1]
Assume $|\mathcal P_M|\le M^{u+o(1)}$, and assume one assignment bit of one
enumerated member is computable in $M^{v+o(1)}$ time and $M^{s+o(1)}$ work
space.  The declared procedure is an exact forward partial wrapper with no
SAT calls, no recursive children,
\[
 T(M)=M^{1+u+v+o(1)},\qquad S(M)=M^{s+o(1)},
\]
apart from read-only input and streaming output.  Its failure answer is only
\textsc{fail}.
\end{theorem}
\begin{proof}
There are at most $M^{u+o(1)}$ candidates.  One verification performs at
most $M$ literal visits and one $M^{v+o(1)}$ bit computation per visit, so
the total time has the stated exponent.  The machine retains one clause flag,
input addresses, enumerator state, and assignment-bit scratch, giving the
stated work space.  If a phase passes, the direct clause check proves that it
is a model of $F$, hence returning TRUE is exact.  An assignment-program
index is a checkable certificate and its witness bits can be streamed by
regeneration.  If no phase passes, the machine makes no claim about SAT, so
no missed model can make the partial member unsound.
\end{proof}

For $\mathcal P_M=\{\text{all true},\text{all false}\}$, assignment bits are
constant-time and the two phases require only one combined literal scan plus
logarithmic addressing state.  Every CNF in which each clause has a positive
literal is accepted by all-true; dually, every clause having a negative
literal is accepted by all-false.  The positive product of ARC-0004 is in the
first domain.  The pure-literal rule in DPLL is an exact adjacent mechanism,
but its occurrence discovery and state are different resources and it does
not furnish an all-input coverage theorem \cite{davis1962dpll}.

When $v=s=0$, the partial member's own joint exponent is $1+u$.  It lies
strictly below the Williams endpoint for
$u<2\cos(\pi/7)-1\approx0.8019377358$.  This numerical fact applies only to
the member's successful domain.  It is not a SAT algorithm on failed inputs
until the remaining charged portfolio covers them.

\section{Hostile controls and transfer limits}
\begin{description}
\item[] \textbf{Easy families.}  Positive/negative products and parity-zero
XOR are intentionally accepted.  They cannot support a branching-hardness
inference against the combined portfolio.
\item[] \textbf{UNSAT and missed SAT.}  Contradictory units and PHP return
\textsc{fail}; so does a satisfiable formula whose model is neither constant
phase.  Failure is not silently promoted to UNSAT.
\item[] \textbf{Source carry/current-scale calls.}  The member scans the
ordinary source directly, creates no child pointer, and invokes no
hypothetical SAT solver.  There is no hidden exponent $K$.
\item[] \textbf{Padding and renaming.}  Tautological padding is removed by
the declared normalization.  Signed renaming may change whether a fixed phase
works; the algorithm verifies each renamed source and remains sound.
\item[] \textbf{Independent products.}  Complete assignments verify a product
without enumerating its clause-first branches when one phase satisfies every
factor.  This is an algorithmic escape, not a product lower bound.
\item[] \textbf{Oracle and algebraic replacement.}  The direct evaluation
identity relativizes and survives algebraic access.  It is useful
infrastructure and supplies no nonrelativizing or nonalgebrizing hinge.
\item[] \textbf{Post-quantum transfer.}  Collision entropy, Schur squares,
and binding analogies do not improve phase coverage here.  Classification:
FAILED TRANSFER for this barrier.
\item[] \textbf{Proof-search transfer.}  DPLL's pure-literal rule is an
adjacent exact simplification, not a theorem that every CNF has a favorable
fixed phase.  Classification: useful structural analogy; no missing
all-input theorem transfers.
\end{description}
