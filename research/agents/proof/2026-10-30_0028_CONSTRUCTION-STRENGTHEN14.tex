\section{Exact counting certificates and uniform loop}
Let $F$ be the current residual CNF and $H$ a selected conjunction of its
clauses. Set $U=\operatorname{vars}(H)$ and count on the same universe:
\[
 Z(H)=\sum_{a\in\{0,1\}^U}\mathbf1[H(a)],\qquad
 Z(H;v=b)=\sum_a\mathbf1[H(a)\land a_v=b].
\]
When omitting a clause from $H$, keep the original universe $U$.
Otherwise equal-count comparisons need not be valid.

One fixed deterministic program enumerates groups of at most four residual
clauses and rejects scopes larger than six. It enumerates local assignments,
obtaining both conditional counts and counts after deleting each local clause.
It applies the first available rule and restarts after each rewrite:
\begin{description}
\item[] If $Z(H)=0$, return UNSAT.
\item[] If $Z(H)>0$ and $Z(H;v=b)=0$, retain the forced bit $v=1-b$,
substitute it globally, and simplify.
\item[] If $C\in H$ and $Z(H\setminus\{C\})=Z(H)$, remove $C$ globally.
\item[] If no certificate is found, return UNRESOLVED with the exact
residual and retained assignment map. An empty residual returns SAT.
\end{description}
There is no input-dependent advice, answer-side bit, full-source count oracle,
or free successful choice of a group.

\begin{theorem}[Model-preserving feedback]
Every accepted rewrite preserves the original model set when interpreted
with the retained assignments. Zero local counts certify global UNSAT;
positive local counts alone do not certify global SAT.
\end{theorem}
\begin{proof}
Every residual solution satisfies $H$. Therefore a zero count excludes all
residual solutions. A zero conditional count forces the opposite value in
every residual solution, so substitution with that retained bit gives a
bijection of solutions on the unfixed variables.
For deletion,
$\operatorname{Mod}_U(H)\subseteq\operatorname{Mod}_U(H\setminus\{C\})$.
Equal finite cardinalities imply equal sets. Thus the remaining local
clauses entail $C$, and deletion preserves the complete residual model set
even in the presence of all outside clauses. Induction gives the invariant.
If no clauses remain, every extension of the retained bits satisfies the
source. Otherwise absence of a local certificate gives no answer.
\end{proof}

\begin{theorem}[Bounded discovery]
With $n$ original variables, $m$ clauses, fixed group cap $k$, and width cap
$w$, there are at most $n+m$ accepted rewrites. Discovery and rewriting take
\[
 (n+m+1)\left(\sum_{j=1}^{k}\binom mj\right)2^w
                   \operatorname{poly}(N,k)
\]
bit operations and $\operatorname{poly}(N,k,2^w)$ workspace on the same
machine. These bounds are polynomial for fixed $k$ and $w=O(\log N)$.
They do not bound solving the unresolved residual.
\end{theorem}
\begin{proof}
A pin fixes a previously unfixed residual variable and a deletion removes
a clause. Substitution introduces no new variables or clauses. Hence
unfixed-variable count plus residual-clause count strictly decreases at
each accepted rewrite. Every complete search round charges all groups,
failed counts, scope checks, assignment trials and source scans.
Each accepted rewrite also charges its full substitution and restart.
At most $2^w$ local assignment rows coexist; discarded groups do not stay
in memory. Counts, source clauses and assignment maps have polynomial
descriptions. These observations give the stated bounds.
\end{proof}

would decide SAT directly; we do not assume that operation is cheap.
