\section{Exact density and semantic certificate}
Let the accepted source have $p$ positive rows of width $h$, exactly
$n=ph$ variables, and
\[
 e=h\binom p2=\frac{n(p-1)}2
\]
distinct negative binary clauses.  Assume $p,h\ge2$ and
$h/2\le p\le2h$.

\begin{theorem}[DENSITY-GATE-ARITH1]
The declared balance and count checks imply
\[
 e\ge \frac{n^{3/2}}{4\sqrt2},
 \qquad\text{equivalently}\qquad 32e^2\ge n^3.
\]
If the negative-clause graph is subsequently verified to be $h$ disjoint
$p$-cliques and every positive row meets every clique in exactly one
variable, the CNF is satisfiable if and only if $p\le h$.
\end{theorem}
\begin{proof}
The inequality $h\le2p$ gives $n=ph\le2p^2$, hence
$p\ge\sqrt{n/2}$.  Since $p\ge2$, also $p-1\ge p/2$.  Therefore
\[
 e=\frac{n(p-1)}2\ge\frac{np}{4}
   \ge\frac{n^{3/2}}{4\sqrt2}.
\]
For the semantic statement, interpret positive rows as pigeons and negative
cliques as holes.  Every model selects at least one variable per row, while a
clique permits at most one selected variable; thus $p\le h$ is necessary.
If $p\le h$, inject rows into cliques and select their unique intersections,
which satisfies every positive row and every negative binary clause.
\end{proof}

This promotes the arithmetic and semantic implication, not the unsynchronized
implementation.  The $M^{2/3+o(1)}$ failed-attempt bound additionally needs
a total first pass that stores no variable-indexed object before checking the
counts and balance, rejects oversized tokens, and rereads one immutable
source.  Those operational hypotheses are CONDITIONAL until the exact code
and raw output are synchronized and independently inspected.  Removing the
balance gate breaks the inference: $(p,h)=(2,128)$ has $n=256$, $e=128$, and
$32e^2<n^3$.

\section{Exact orbit-saturation theorem}
Fix an $r\times q$ signed-literal matrix with distinct variables.  Row
permutations commute with complementation and fix outside variables.  For a
clause $C$, retain the outside literals and the multiset of its nonempty row
profiles.  If profile type $\tau$ occurs $m_\tau$ times and
$k=\sum_\tau m_\tau$, then
\[
 |\operatorname{Orb}(C)|=
 \frac{r!}{(r-k)!\prod_\tau m_\tau!}.
\]

\begin{theorem}[ORBIT-SATURATION1-PROOF]
Two clauses have the same declared signature if and only if a row
permutation maps one to the other.  For a duplicate-free CNF, invariance
under every row permutation holds if and only if, for every observed
signature, the CNF contains exactly the displayed number of clauses.
\end{theorem}
\begin{proof}
A row permutation preserves outside literals and only reassigns complete row
profiles.  Conversely, equality of the profile multisets gives a
profile-preserving bijection between occupied rows; extend it arbitrarily to
empty rows.  This is a row permutation taking one clause to the other.  The
stabilizer permutes the $r-k$ empty rows and independently permutes the
$m_\tau$ rows of every equal type.  Orbit--stabilizer gives the formula.
All clauses with one signature therefore form one orbit.  A duplicate-free
subset is invariant precisely when it is empty or is the full orbit; for an
observed signature it is nonempty, so equality with the orbit cardinality is
equivalent to saturation.
\end{proof}

Duplicate-freedom, preservation of literal signs, and outside-variable
fixing are load-bearing.  Dropping any of them invalidates the cardinality
test.  This proves the mathematical criterion.  It does not by itself prove
the total byte parser, comparison primitives, or endpoint transport.

\section{Exact sequential-prefix ledger}
\begin{theorem}[GLOBAL-PREFIX-LEDGER1]
Let a uniform exact partial member $P$ use time $\softO(M^c)$ and space
$\softO(M^u)$ on every outcome, including FAIL.  It may emit one ordinary
REDUCE child of length at most $M^b$, where $b<1$ and its retained
state and child representation are included in $u$.  Let an exact fallback
$W$ use time $M^{t+o(1)}$ and space $M^{s+o(1)}$.  The recursive sequential
implementation that runs $P$, recurses on its sole REDUCE child, and discards
failed state before running $W$ on FAIL has
\[
 T(M)\le M^{\max\{c,t\}+o(1)},\qquad
 S(M)\le M^{\max\{u,s\}+o(1)}.
\]
Exact VALUE and REDUCE outcomes preserve correctness when their declared
combiner is used; FAIL is not a Boolean answer.
\end{theorem}
\begin{proof}
At recursion level $j$, the local time is at most
$M^{cb^j+o(1)}$ and a fallback call costs at most
$M^{tb^j+o(1)}$.  The geometrically shrinking one-child chain has
$O(\log\log M)$ nonconstant levels, so its sum changes only the $o(1)$ term
and is dominated by exponent $\max\{c,t\}$.  Simultaneously retained frames
have sizes $M^{u+o(1)},M^{ub+o(1)},\ldots$ and are dominated by the root;
a fallback contributes exponent $s$ at its own scale.  Failed local state is
discarded before fallback.  Correctness is the disjoint case analysis VALUE,
REDUCE, or FAIL; no truth value is inferred from abstention.
\end{proof}

For the density-gated ARC-0005-ORBIT member, the proposed source-level ledger
has $(c,u)=(1,2/3)$.
Thus a globally prefixed fallback has
\[
 (t',s')=(\max\{1,t\},\max\{2/3,s\}).
\]
The bound supplied by this composition has baseline sum
\[
 1+\frac23=\frac53>\phi,
\]
where the strict comparison is exact because
$(7/3)^2=49/9>5$.  The same prefix also does not certify $s'=0$.
It therefore supplies neither the general product endpoint nor the
subpolynomial-space endpoint.  If $t\le1$ and $s<1$, however, the resulting
pair is still $(1,\max\{2/3,s\})$ with space exponent below one, so the
Fortnow strip remains available.  This is compatibility, not construction of
the fallback.

The statement is deliberately about the certified same-realization ledger.
The balanced pigeonhole path materializes $\Theta(n)$ indexed cells with
$n=M^{2/3+o(1)}$, matching exponent $2/3$ up to logarithms;
so the present array realization cannot simply be relabeled
$M^{o(1)}$-space.  A different implementation could improve the ledger only
after a new proof.
