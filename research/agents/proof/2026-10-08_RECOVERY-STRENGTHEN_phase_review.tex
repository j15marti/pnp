\paragraph{Independent recurrence check.}
Every actual executed recursive entry must appear in the child multiset,
including repeated executions of identical logical children. For a fixed
$\epsilon>0$, choose a sufficiently small $\delta>0$ so that
$h\epsilon+\delta(2+\epsilon)<\epsilon$. Uniformity of the stipulated
$o(1)$ bounds gives, above one fixed threshold,
\[
 q(n)\le n^{1-h+\delta},\qquad
 m_j\le n^{h+\delta},\qquad L(n)\le n^{1+\delta}.
\]
Choose also $\delta<\min(\epsilon,1-h)$. Strong induction on encoded
length, absorbing the finite base region in a constant, gives
\[
 \sum_j T(m_j)\le C n^{1+h\epsilon+\delta(2+\epsilon)}.
\]
The strict exponent slack absorbs both this sum and $L(n)$ in
$Cn^{1+\epsilon}$ for sufficiently large $n$. Thus $T(n)=n^{1+o(1)}$.
This is independent of any fixed polynomial exponent used by the finite-base
decider.

For space, depth-first execution retains the local frame at each active
entry, one explicit current-child input, and all live evaluation scratch.
Sizes decrease by a fixed fractional power above the base threshold, so the
number of active entries is $O(\log\log n)$. Summing their stipulated bounds
gives $n^{\max(p,h)+o(1)}$. The premise concerning scratch must bound the
whole phase peak, not merely the moment of suspension. Same-scale typed
chains must have the stated fixed bound, with no uncharged internal recursion.
The original lemma expressly includes all typed frames and scratch in one
simultaneous bound, which supplies this requirement.

\paragraph{Exact two-type algebra.}
For fixed $0<h<1$, consider the sufficient inequalities
\[
 C_P\ge r_P,\quad C_P\ge u+C_Q,\quad
 C_Q\ge r_Q,\quad C_Q\ge v+hC_P.
\]
Here $u,v\ge0$ and $r_P,r_Q$ are local exponent floors. Substitution forces
\[
 C_P\ge r_P,\quad C_P\ge u+r_Q,\quad
 C_P\ge u+v+hC_P.
\]
Hence every feasible pair dominates
\[
 C_P^*=\max\left(r_P,u+r_Q,\frac{u+v}{1-h}\right),\qquad
 C_Q^*=\max(r_Q,v+hC_P^*).
\]
Conversely $u+C_Q^*\le C_P^*$ by the two last bounds defining $C_P^*$,
so this pair satisfies all four inequalities and is the componentwise least
feasible pair. This is an exact solution of the stated exponent envelope,
not an equality theorem for an actual solver's running time.

\paragraph{Space and access qualifications.}
A same-scale edge is compatible with a contracting two-edge cycle. It is
not compatible with a sublinear local-workspace premise if it allocates a
fresh $\Theta(n)$-bit derived child buffer. Aliasing an already supplied
read-only entry input is different: it introduces no fresh length-$n$
allocation, while a nonroot entry input remains charged to its caller.
Implicit derived input requires a proved evaluator and accounting for
every nested access and suspended frame. No part of the algebra constructs
that evaluator or validates treating a derived parent as freely accessible.

\paragraph{Status.}
Conditional flattening and the least-envelope algebra pass this independent
review. Existing conditional elimination of $K$ is preserved. The implication
from $P=NP$ to a uniform favorable all-input implementation remains OPEN.
No computational experiment is needed for these elementary symbolic checks.
