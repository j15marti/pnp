\begin{abstract}
This run tests a concrete forward-only double-wrapper candidate: expose a
Shannon frontier, then quotient exactly equal residual functions before
recursive solution.  The semantic transformation is exact.  A monotone
2-CNF independent-product family proves that equality quotienting does not
simultaneously give polynomial fanout and fixed-power encoded shrinkage.
The implementation is therefore retired as a universal general-SAT
shrinker, without asserting a representation-independent lower bound.
P versus NP remains open.
\end{abstract}

\section{Primary literature and transfer audit}
Williams's STACS 2010 Theorem 3.9 states the deterministic SAT product
endpoint
\[
 t(n)s(n)=\Omega(n^{2\cos(\pi/7)-o(1)})
\]
for polynomially bounded time and space under the paper's RAM conventions
\cite{williams2010}.  The paper defines simultaneous DTISP bounds and uses
big-$\Omega$ in the infinitely-often sense.  This supports the endpoint in
the live manuscripts, but supplies no inner transformation.  The ITCS 2021
paper of Mudigonda and Williams describes the corresponding state of the art
as excluding SAT time $n^c$, $c<2\cos(\pi/7)$, simultaneously with
$n^{o(1)}$ space; this is the small-space specialization, not a replacement
for the product statement.

Darwiche and Marquis compare compiled Boolean representations, their
succinctness, and supported transformations \cite{darwiche2002}.  This is a
relevant cross-domain model for why exact quotient representations can be
useful.  Classification: analogy only.  Their map does not assert that every
ordinary CNF has a small cheaply acquired canonical representation, nor that
a compiled object is an ordinary smaller SAT instance.  No knowledge-
compilation theorem is transferred to the wrapper spine.

\section{The exact two-phase candidate}
For a CNF $F$ and variable set $H$, the first phase emits all restrictions.
Before any recursive child answer is read,
\[
 \SAT(F)=\bigvee_{\alpha\in\{0,1\}^{H}}
 \SAT(F\upharpoonright\alpha).
\]
The second phase groups residuals by equality as Boolean functions and keeps
one representative per class.  This is semantically safe for the OR.  It is
also forward-only: the quotient predicate concerns the residual functions,
not the eventual SAT bits.  What remains to be proved is cheap acquisition
and favorable size.

Consider the monotone 2-CNF family
\[
 F_m=\bigwedge_{i=1}^{m}(x_i\vee y_i),
\]
with ordinary indexed-CNF length $M_m=\Theta(m\log m)$.  Restrict the
designated variables $x_1,\ldots,x_h$ in all ways.

\begin{lemma}[SHANNON-QUOTIENT-GATE1]
The exact residual-function quotient has $2^h$ classes.  Polynomial frontier
size forces residual encoded length $M_m^{1-o(1)}$.  Conversely, raw
restriction leaving fixed-power residual length has a superpolynomial
quotient frontier.
\end{lemma}
\begin{proof}
Under assignment $\alpha$, clause $i\le h$ is deleted if
$\alpha_i=1$ and becomes the unit clause $y_i$ if $\alpha_i=0$; the
$m-h$ untouched clauses remain.  Let $\alpha\ne\beta$ and select a
coordinate $j$ on which they differ.  Set $y_j=0$, satisfy every other unit
appearing in either residual, and set each untouched $x_i=1$.  One residual
is false and the other true, so their Boolean functions differ.  Hence all
$2^h$ classes survive exact equality quotienting.

If $2^h\le M_m^{a+o(1)}$ for fixed $a$, then
$h=O(\log M_m)$.  The untouched clauses occupy
$\Theta((m-h)\log m)=\Theta(m\log m)=M_m^{1-o(1)}$ bits, which is not
$M_m^{b+o(1)}$ for fixed $b<1$.  To leave only $M_m^{b+o(1)}$ bits by this
raw restriction requires $m-h=o(m)$, and then the exact quotient still has
$2^{m-o(m)}$, superpolynomially many, representatives.
\end{proof}

This is an easy-family obstruction, not a hardness argument.  The family is
monotone 2-CNF.  It shows that the candidate fails its own resource contract
before any hardness assumption is used.  A semantic re-encoding, a different
variable-selection policy, or a source-dependent macro generator is outside
the lemma and remains possible only with a new proof of ordinary-SAT return
and charged acquisition.

\section{Bounded executable model}
The command
\[
\texttt{timeout 30s python experiments/proof\_spines/
shannon\_quotient\_gate\_test.py}
\]
used seed 20261007 and an internal 25-second budget.  It completed 187 checks
in 0.00264 seconds in the preserved run.  For $m\le6$ it exhaustively checked
that the number of syntactically distinct residuals is $2^h$.  For $m\le4$
it independently compared complete truth tables and again found $2^h$
semantic classes.  Six larger encoding samples checked the polynomial-
frontier and residual-size trends; 64 seeded cases checked unit and untouched
clause counts.

At $m=16384$, the declared encoding has $M=606208$, polynomial exposure with
$h=19$ leaves residual ratio about $0.94485$, and the residual already exceeds
$M^{0.9}$.  This finite number illustrates the proved asymptotic statement;
it does not prove it.

\begin{description}
\item[] \textbf{Source-carry and padding control:} padding the parent to
$M^2$ makes the original source look like a square-root object, but a virtual
child retaining that source is not a standalone smaller ordinary-CNF input.
Decoder and nested access costs remain charged.
\item[] \textbf{Current-scale-call control:} if equality acquisition invokes
the hypothetical SAT decider on the parent scale, local exponent $c$ is at
least the unknown $K$; the wrapper has not eliminated it.
\item[] \textbf{Independent-product control:} the family itself is a product
of independent clauses and gives no quotient collapse.
\item[] \textbf{Easy-family control:} the counterfamily is monotone 2-CNF,
so the result cannot be misread as a lower bound based on SAT hardness.
\item[] \textbf{Oracle/algebraic replacement control:} an oracle returning
the SAT bit collapses the frontier by answer, but uses the target output and
changes the model.  The restriction/equality argument otherwise relativizes
and survives symbolic coefficient labels; it supplies no nonrelativizing or
nonalgebrizing hinge.
\end{description}
