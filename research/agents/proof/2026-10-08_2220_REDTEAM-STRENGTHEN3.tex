\item[Model.] FLMV deterministic random-access Turing machines, with work and

\item[Same realization.] One fixed uniform exact machine has both time and
space bounds on every input length and every input.
\item[Falsifier.] A legal phase that satisfies the contract without
performing any recursive contraction.
\end{description}

Let $\PHASE(W)$ denote exactly the concrete ARC-STRENGTHEN3 contract:
$W$ is a fixed uniform exact SAT-oracle transducer, its full nonchild time is
$N^{6/5+o(1)}$, its full peak nonchild workspace is $N^{1/2+o(1)}$, it
executes at most $N^{3/5+o(1)}$ calls, and each issued immutable child has
encoded length at most $N^{1/2+o(1)}$ and is strictly shorter.  The bounds
hold on every true adaptive transcript, calls count with multiplicity, and
all acquisition, failures, replay, buffers, indexes, summaries and ancestors
are charged.  ``At most'' permits zero calls.

Let $\ALG(A)$ mean that $A$ is one uniform exact oracle-free SAT machine on
the same language and model with simultaneous bounds
\[
 T_A(N)=N^{6/5+o(1)},\qquad S_A(N)=N^{1/2+o(1)}.
\]

\section{PROVED/EXACT: endpoint equivalence}

\begin{theorem}[Zero-child equivalence]
On the same encoded language and machine model,
\[
 \boxed{\exists W\;\PHASE(W)
 \quad\Longleftrightarrow\quad
 \exists A\;\ALG(A).}
 \tag{1}
\]
\end{theorem}

\begin{proof}
The forward implication is the valid ARC-STRENGTHEN3 composition theorem.
Recursively inline every issued child down to a fixed base.  Its exact
time exponent is
\[
 \max\left\{\frac65,
 {3/5\over1-1/2}\right\}=\frac65,
\]
and its exact streamed-space exponent is
$\max\{1/2,1/2\}=1/2$.  Exactness follows by induction on encoded length.

For the reverse implication, fix $A$ witnessing $\ALG$.  Define $W_A$ to run
$A(x)$ locally, issue no child calls, and return that bit.  Every child,
strict-descent, immutability and transcript condition is vacuous.  The query
count $0$ is at most $N^{3/5+o(1)}$.  All actual work and state are exactly
those of $A$, hence fit $r=6/5$ and $p=1/2$.  Take the maximum of the two
size-only $o(1)$ envelopes and absorb finite sizes into one constant.  This
is one fixed uniform machine, so it satisfies $\PHASE$.
\end{proof}

This is an existential equivalence.  It does not say that an arbitrary given
$N^K$ SAT decider itself has the displayed phase resources.  It says that
the present existential phase target has exactly the same witnesses as the
endpoint class, after recursive inlining in one direction and the zero-child
specialization in the other.

FLMV excludes the right side of (1).  Consequently, after using FLMV and
the standard equivalence $\SAT\in P\Longleftrightarrow P=NP$, the proposed
bridge
\[
 \SAT\in P\Longrightarrow\exists W\,\PHASE(W)
 \tag{2}
\]
is classically equivalent to $P\ne NP$: if SAT were in P, (2) and (1) would
contradict FLMV; if SAT is not in P, (2) is vacuously true.  Thus (2) is a
correct possible final theorem, but it is not yet a decomposed intermediate
lemma.

\section{Positive-query and syntactic repairs do not suffice}

Requiring $q\ge1$ does not block the reverse implication.  The phase may
issue a fixed constant-size tautology, receive its answer, ignore it, and run
$A(x)$.  If children must be source-derived, fully restrict $x$ under a fixed
assignment and issue the resulting constant formula.  If the answer must be
used syntactically, return
$A(x)\wedge(b\vee\neg b)$ or another identity involving the child bit.
None of these creates recursive information flow.

The weakest accurate manuscript repair is therefore to state (1) explicitly
and describe the four parameters as an endpoint-compatible accounting
presentation, not as a logically weaker existential target.  A genuinely
decompositional construction claim needs additional intensional data, for
example:
\begin{quote}
One explicit fixed compiler transforms the code and clock of every assumed
polynomial SAT decider $A$ into $W_A$; every SAT-dependent bit used to decide
the parent is obtained through essential, strictly smaller, source-checkable
children; no direct parent decision or hidden endpoint algorithm occurs; and
the full source-level execution satisfies the joint ledger.
\end{quote}
The precise compiler body and its allowed black-box uses must be stated.
``Source-derived,'' positive query count, or syntactic dependence alone is
not enough.  Even a correct compiler theorem remains separation-strength;
its benefit is that it exposes a concrete arrow that can be audited rather
than restating endpoint membership.

This causal guard is recovered rather than invented here.  The repository's
CHARGED STRICT SUCCESSOR and PRE-A-MACRO-SHRINK1 formulations already require
a genuine contracted ordinary-SAT child or macro-decomposition \emph{before}
the first parent-scale semantic invocation of the assumed solver.  Those are
the appropriate construction targets.  ARC-STRENGTHEN3's numerical phase
contract omitted that guard.

\section{Independent checks that survived}

\subsection*{Uniform $o(1)$ recursion}
The ARC time proof is sound when one size-only envelope $e(n)\to0$ applies
uniformly over all inputs, true transcripts and recursive depths.  For each
$\delta>0$, choose $\epsilon$ with
\[
 6/5+\epsilon<6/5+\delta,
 \quad 3/5+\epsilon+(1/2+\epsilon)(6/5+\delta)<6/5+\delta.
\]
A strong induction absorbs additive constants.  Space admits the same
$\delta$-induction; merely saying ``geometric'' is insufficient unless the
error is uniform.  A different depth-dependent error $e_j(n)$, pointwise
$o(1)$ for each fixed $j$ but large at moving depth $j\asymp\log\log n$,
can permit near-unit shrinkage and break the claimed depth bound.  The report's
``same $W$/common envelope at every level'' guard blocks this counterexample;
future formulations should say ``uniform across recursion depth'' literally.

For exact notation define monotone envelopes
\[
 \overline T(N)=\max_{|x|\le N}T(x),\qquad
 \overline S(N)=\max_{|x|\le N}S(x),
\]
since an exact-length worst-case function need not be monotone.  A complete
machine proof should implement recursive frames on fixed indexed tapes or
charge a polylogarithmic segmented-address overhead.  Materialized children
avoid a linear scan per access, but literal constant overhead was not proved.
These are proof-writing repairs, not counterexamples to the intended
$N^{o(1)}$ bounds.

\subsection*{Endpoint arithmetic}
FLMV Corollary~5.8 gives
\[
 d(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
At $c=1201/1000$,
\[
 d(c)=\frac{1468676399}{2884802000}
 =\frac12+\frac{26275399}{2884802000},
 \qquad c-\frac65=\frac1{1000}.
\]
Thus the strict numerical endpoint is correct.  Their Section~2.1 charges
work and index tapes; Theorem~3.1 and Corollary~3.2 supply the local SAT
transfer with polylogarithmic time and logarithmic-space overhead:
\url{https://lance.fortnow.com/papers/files/tst.pdf}.

\subsection*{Encoding repair still required}
The phrase ``fix a canonical SAT encoding'' is formally insufficient because
padding or compression can alter exponents.  Either the phase must decide the
exact Boolean-formula SAT language underlying FLMV, or the manuscript must
prove a local encoding lemma for its exact CNF/3CNF syntax:
\begin{enumerate}
\item define the language on every bit string and reject malformed strings
within the displayed bounds;
\item map every relevant nondeterministic-linear computation to a
satisfiability-equivalent wrapper instance of length
$n\log^{O(1)}n$; and
\item generate any requested output bit in $\log^{O(1)}n$ time and
$O(\log n)$ workspace on the FLMV machine.
\end{enumerate}
Cook--Levin plus definitional/Tseitin clauses is a plausible route for 3CNF,
but the output-bit locator must be proved local.  Materializing the whole
reduction would consume near-linear workspace and would not preserve the
claimed half-space bound.

Faliszewski and Ogihara's primary technical report distinguishes ordinary
autoreducibility from length-decreasing self-reducibility and shows that the
latter is a strong property for complete languages.  It supports the need to
state the exact reduction notion; it does not supply this project's compiler:
\url{http://hdl.handle.net/1802/4042}.
