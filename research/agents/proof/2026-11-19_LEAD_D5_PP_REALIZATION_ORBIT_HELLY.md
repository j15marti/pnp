# Strict C: D5-invariant obstruction matrices have native physical realizations
Date: 2026-11-19. Role: lead proof-chain synthesis. **PROVED** structure and construction, **COMPUTATIONALLY VERIFIED** finite example; **OPEN** unrestricted resource lower bounds and P versus NP.

## Theorem 1, exact polymorphism classification (PROVED)
For every arity k>=1, every f: (Z5)^k -> Z5 preserving the canonical strict directed-triangle C has the form f(x)=sigma(x_i) for a coordinate i and sigma(a)=+a+t or -a+t modulo 5.

Proof: the binary disequality relation is pp-definable as (exists h) C(x,y,h), so f preserves coordinatewise disequality. It is a proper 5-coloring of the tensor graph K5^tensor k (two tuples adjacent when they differ at every coordinate). This graph has 5^k vertices, degree 4^k and least adjacency eigenvalue -4^(k-1). The Hoffman bound gives maximum independent-set size 5^(k-1); five color fibers partition the vertices, so each attains equality. Indicators of maximum independent sets lie in the constants plus the least-eigenvalue eigenspace, i.e., have form c+sum_i g_i(x_i). A Boolean-valued additive function cannot depend nontrivially on two coordinates, so each fiber is a coordinate hyperplane x_i=a. Disjointness forces the same i for all five colors, yielding a permutation of x_i. The five original C unordered triples are the consecutive triples modulo 5, whose complements are precisely edges of C5, so their automorphism group is exactly D5. Conversely all D5 dictators preserve C. QED.

## Theorem 2, finite explicit pp-realization (PROVED)
For any q>=1 and D5-invariant relation A subset (Z5)^q, there is a formula H_A(z,w) made *only* of original physical strict-C clauses with three distinct variable names each, with disjoint fresh private names w, such that (exists w) H_A(z,w) iff z in A.

Constructive proof for nonempty A: choose one representative t^(s) of each D5 orbit inside A, for s=1,...,r. Make private variables y_u for each u in (Z5)^r, and add C(y_u,y_v,y_w) whenever C(u_s,v_s,w_s) holds for every coordinate s. This is exactly 5^r power names and 30^r/6 original C clauses. Each satisfying coloring of these names is a polymorphism h:(Z5)^r -> Z5, so Theorem 1 gives h(u)=sigma(u_s). Define p_i=(t_i^(1),...,t_i^(r)). Link each public terminal z_i to private y_{p_i} using the native four-clause equality gadget C(z_i,p,q), C(y_{p_i},p,q), C(p,a,b), C(q,a,b), with four fresh names. The gadget forces equality and admits an extension for every common color. Thus the possible public tuples are precisely sigma(t^(s)), which are exactly A. An empty A uses an independent three-clause original-C contradiction.

Size for r>=1: at most 5^r+5q named variables, 30^r/6+4q physical clauses. With r up to K(q)=(5^q+5)/10, this is double-exponential in q, NOT resource preserving.

Corollary: every D5-invariant abstract refutability matrix D(z,j) has a *finite physical strict-C realization* with private blocks disjoint after z, by implementing each allowed relation A_j={z:D(z,j)=0}. This eliminates only the objection that abstract matrices might be logically unrealizable. It does NOT justify a source-aware query lower bound, low-girth or critical promise transfer, polynomial gadget size, or any deterministic general-machine lower bound.

## Theorem 3, sharp block Helly/orbit capacity (PROVED)
Let F(z,w_1,...,w_B)=AND_j F_j(z,w_j), with q shared named variables and mutually disjoint private names. Each compatibility set A_j={z:(exists w_j)F_j(z,w_j)} is D5-invariant. There are exactly K(q)=(5^q+5)/10 simultaneous D5 shared-assignment orbits (Burnside). If F is UNSAT, for each orbit choose one block incompatible with that orbit; the chosen <=min(B,K(q)) blocks already form an UNSAT subformula. Hence an individually indispensable BLOCK-critical family has B<=K(q).

Tightness for every q: choose B=K(q) and A_j=(Z5)^q minus orbit j. Theorem 2 builds each as original strict C with private disjoint names. All blocks together are UNSAT, but deleting any one block permits the shared tuple in its excluded orbit. The construction is physical BLOCK-criticality, not original-CLAUSE criticality, and its size is not bounded by N^.35.

## Unrestricted P-vs-NP firewall and coordination
The single most promising attempted bridge remains a **solver-dependent, hereditary, all-input self-improvement**. The hypothesized charged recurrence t'=max(1.195,.845+.35t), s'=max(.35,.35s) contracts any finite seed time/space exponents toward (1.30,.35), but **NO such uniform all-input transformation has been constructed**. It must handle SAT witnesses and UNSAT covers, both polarities of recursive children, unsuccessful paths, full source authentication, complete output and verification, and peak live writable space. The full row-block scan R=N^.195, B=N^.65, private *encoded child size* p<=N^.35 requires local exponent a<=97/70 to attain time N^1.33. Re-reading a full N-bit input once per row-block costs N^1.845; B simultaneously held offsets consume N^.65 logN bits. A locally indexable arbitrary 3-CNF-to-C reduction is documented, but it does not preserve criticality, girth or the low-row/block promises.
