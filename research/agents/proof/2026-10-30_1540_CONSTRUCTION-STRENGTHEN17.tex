\section{Explicit construction and all-input semantics}
Let $F$ be any nonempty ordered proper 3CNF with $m$ clauses,
dense active-variable identifiers, and fixed-width indexed records.
Let $L=3m$, $P=2^{\lceil\log_2 L\rceil}$, and let
$w=\lceil\log_2(n+2)\rceil$ encode a reserved sentinel above every real ID.
For each literal occurrence $i$, create an independent existential payload
bit $v_i$. Its record is $(\operatorname{id}_i,v_i)$, with every identifier
bit fixed by a unit clause. Pad to $P$ records with sentinel keys and zero
payloads. Original clauses constrain the three occurrence payloads with
the original signs.

Use the fixed bitonic network generated by
$k=2,4,\ldots,P$ and $j=k/2,k/4,\ldots,1$.
Each layer compares wire $i$ with $i\mathbin{\mathrm{xor}}j$ once;
direction is ascending when $(i\mathbin{\&}k)=0$.
A comparator's ripple Boolean circuit computes the ordered key comparison
from most significant to least significant bit and multiplexes both full
records accordingly. Every Boolean gate is encoded by its complete
truth-table equivalence, not a one-way implication.
The current prototype uses AND, OR, equality and three-input multiplexer
gates, so clauses have width at most four.
After the final layer, for each adjacent record pair with key-equality
indicator $e$ and payloads $a,b$, add
\[
 (\neg e\vee\neg a\vee b)\ \land\
 (\neg e\vee a\vee\neg b).
\]
The compiler never evaluates the comparator outcomes to choose its wiring.

\paragraph{Semantic claim and proof.}
For every proper source $F$, the resulting CNF $E(F)$ is satisfiable iff
$F$ is satisfiable. Fix the input payloads. All keys are fixed and complete
gate equivalences determine one and only one internal gate trace.
The fixed sorting network preserves the multiset of full records and places
keys in order. Thus adjacent equal-key consistency forces all occurrences
of each original variable to have one common payload value. Original
clause constraints then give a satisfying assignment of $F$.
Conversely, a satisfying source assignment gives all its occurrences equal
payloads; its uniquely determined sorting trace satisfies every adjacency
constraint and original clause. Dummy keys exceed real IDs and their
payloads are all zero, so padding neither merges real variables nor creates
a conflict. Duplicate source clauses, arbitrary literal polarity and
unbounded source occurrence counts cause no exception.
This is a standard circuit-encoding argument, not a new SAT algorithm.

\section{Size, locality and the remaining emitter obligation}
There are $P\log_2P(\log_2P+1)/4$ comparators.
Each uses $O(w)$ gates and bounded-width clauses, hence
\[
 |E(F)|_{\rm gates,clauses}=O(Pw\log^2P),\qquad
 |\operatorname{enc}(E(F))|=O(Pw\log^3P).
\]
This is $N^{1+o(1)}$ for the declared ordinary source encoding.
All identifiers in a comparator are local gate or neighboring-layer wire
identifiers. Original occurrence payloads occur in their own source clause
and their first comparator. Source keys occur only in their fixed units
and their first comparator. There is no high-fanout original-variable node:
consistency is enforced by routing constraints.
Comparator decision fanout is $O(w)$, not constant; local copy trees could
make it constant but are not implemented here. The prototype's maximum
clause-occurrence count grows with key width as shown below.

Width-four clauses can be split locally:
$(a,b,c,d)$ becomes $(a,b,z),(-z,c,d)$.
Binary clauses become $(a,b,z),(a,b,-z)$, and units use four signed
combinations of two fresh variables. With fresh padding variables these
are exact existential proper-3CNF replacements. They preserve
quasilinear size and locally describable incidence. Feeding this structured
source into run16 suggests that successor occurrences can be enumerated
from fixed gate templates rather than from the original source's variable
occurrence lists.

This last paragraph is an implementation target, not a completed emitter
theorem. The present program builds explicit arrays of gates and clauses
and uses memory proportional to the generated instance. It does not yet
answer arbitrary output-bit addresses of the final strict22 encoding in
logarithmic workspace. A full emitter must give exact numbering and reverse
incidence formulas for every layer, gate, clause split, padding gadget,
selector copy and cycle edge, including headers, constants, unused slots
and boundary layers. Small fanout alone does not prove cheap inversion of
an arbitrary incidence encoding.

\section{Same-machine and barrier accounting}
A future exact local emitter would remove reduction overhead while preserving,
not lowering, the target solver's own space:
\[
 T_{\rm composed}\le T_A(N^{1+o(1)})N^{o(1)},\qquad
 S_{\rm composed}\le S_A(N^{1+o(1)})+N^{o(1)}
\]
only after all generator, index, replay, buffer and ancestor bounds are proved.
There is no inferred $S_A=N^{o(1)}$ from $A\in P$.
FLMV excludes the same uniform deterministic SAT machine with
time $N^{c+o(1)}$, fixed $c<\varphi$, and space $N^{o(1)}$ after matched
reduction slack. This remains the target, not a result of this construction.

The record circuit works also for easy Horn, Krom encodings and affine
sources; its large trace is not an intrinsic hardness measure.
The reduction is syntactic and does not supply a new nonrelativizing or
nonalgebrizing hinge. No circuit lower-bound property or cryptographic
assumption is used. Batcher's hardware-network idea transfers as exact
Boolean wiring and record conservation; physical area/time lower bounds
do not transfer. Conditional K elimination and charged aggregate child
volume remain unchanged.
