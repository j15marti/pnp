\paragraph{Status.}
The decision identities and cache validation rule are
\textbf{PROVED/EXACT}.  The implementation and bounded tests are
\textbf{COMPUTATIONAL}.  Favorable joint bounds on every general SAT input
remain \textbf{OPEN}.
The construction removes retained residual CNFs and the retained formula DAG
from the earlier double wrapper.  It does not prove a $P$ versus $NP$
separation.  The remaining obstacle is narrower: neither the implementation
nor Williams's 2024 self-improvement theorem supplies a uniform contraction
of polynomial input size with all source, construction, branching and
workspace costs included.

\section{Construction in one realization}
The immutable input is a CNF source $F=(C_0,\ldots,C_{m-1})$.  A recursive
state is
\[
  X=(I,M,V),
\]
where $I$ is either the full source or a tuple of active source-clause
identifiers, $M$ is an assignment mask, and $V$ gives its Boolean values.
No state or cache entry contains a residual clause.  Every residual clause is
regenerated by reading the indicated source clauses and applying $(M,V)$.

After one complete inspection pass, the realization proceeds in this order.
It first attempts the block-batched frontier dynamic program.  If the frontier
exceeds its declared width cap, it follows a forced unit when one exists.  It
then finds connected components of the residual primal graph and evaluates
them sequentially by AND.  A connected, nonterminal residual is split by a
variable and evaluated by short-circuit OR.  Thus the source-backed frontier,
AND/OR double wrapper and recursive fallback are parts of one actual solver,
rather than bounds borrowed from different programs.

The answer cache has a fixed bit budget.  Its hash selects candidates only.
Before reusing an answer, the solver regenerates both residuals, renames
variables by first occurrence, and compares the resulting streams exactly.
Consequently a hash collision cannot change an answer.  Cache eviction affects
work only and never correctness.  This implements the shared-setup lesson of
ORBITBATCH1 while charging cache descriptors, signatures and replay
\cite{orbitbatch1}.

\section{Correctness}
\paragraph{Lemma 1: frontier.}
After processing a clause prefix, the frontier table contains exactly the
assignments to variables occurring on both sides of the cut that extend to an
assignment satisfying the processed clauses.  The transition enumerates the
old boundary plus variables of the current clause, tests that clause, and
projects to the next boundary.  Induction on the clause position proves that a
completed table returns $\operatorname{SAT}(F\mathbin{|}X)$.  A cap exit returns
UNKNOWN and is never interpreted as UNSAT.

\paragraph{Lemma 2: AND and OR.}
After the current assignment is applied, distinct connected components of the
primal graph share no unassigned variable.  Their conjunction is satisfiable
if and only if every component is satisfiable.  If there is one component and
an unassigned variable $x$, Shannon expansion gives
\[
 \operatorname{SAT}(G)=
 \operatorname{SAT}(G\mathbin{|}x=0)\lor
 \operatorname{SAT}(G\mathbin{|}x=1).
\]
Unit restriction is the one-child special case.

\paragraph{Lemma 3: sharing.}
Equality of the complete first-occurrence-normalized residual streams gives a
literal-sign-preserving variable bijection between the two residual CNFs.
They therefore have the same satisfiability value.  Because exact stream
equality is checked after hashing, correctness is independent of collision
resistance.

\paragraph{Theorem.}
The combined realization terminates and returns the exact satisfiability value
of every finite input CNF.  Termination follows because a completed frontier
returns, each unit or OR child assigns a previously unassigned variable, and
each proper AND child has fewer residual clauses than its parent.  Lemmas 1--3
prove each return rule.  This is a correctness theorem, not a favorable
complexity theorem.

\section{Charged resource ledger}
Let $L$ be the number of source literals, $B$ the frontier block size, $w$ the
frontier cap, $q$ the maximum clause width, and $E$ the cache budget.  For one
residual state with $m_X$ clauses, the frontier uses at most
\[
 O\!\left(\left\lceil\frac{m_X}{B}\right\rceil L_X
   +m_X2^{w+q}\operatorname{poly}(w+q)\right)
\]
direct source work, before cache signatures and other recursive calls.  Its
temporary payload includes $Bq$ literals, last-occurrence records, two frontier
tables and projection lists.  Component discovery retains union-find records,
pending clause/root pairs, grouping lists and clause-identifier scopes.  The
cache retains at most $E$ declared bits.  Recursion retains ancestor state
descriptors and any component scope list still required by the parent.

The implementation now computes a conservative joint logical peak by summing
the simultaneously live recursion descriptors, cache, frontier or component
payload, and normalization maps.  Exact residual comparison charges two
renaming maps at once.  These logical counters are not Python RSS measurements.

Two input-access models are recorded.  Direct clause access charges every
clause and literal read and also charges an explicit clause-boundary index.
A strict sequential-input interpretation omits that index but charges one
whole-source clause replay for every residual pass, including passes over a
sparse component scope.  This implements STREAMCOMP1's rule that regenerated
input access is not free \cite{streamcomp1}.  The parsed source itself is the
read-only input; treating Python tuple pointers as free workspace without one
of these two ledgers would be invalid.

The bounds remain unfavorable in general.  Component scopes can contain
$\Theta(m)$ identifiers.  Ancestor descriptors can accumulate.  A frontier cap
exit can expose exponentially many Shannon branches.  The implementation
therefore supplies a source-checkable realization and full categories of
charges, but no endpoint-compatible exponents.

\section{Experiment}
The 25-second guarded batch tests 286 formulas: all 256 subsets of the eight
full-width signed clauses on three variables; seeded random instances; narrow
chains; interleaved isomorphic components; delayed contradictions; unique
full-width controls; and pigeonhole formulas through PHP$(7,6)$.  All 286
answers pass.  Sharing-disabled runs match 261 answers.  Three runs force every
cache entry into one hash bucket; 125 unequal candidates are rejected by exact
replay and all answers remain correct.  The final batch takes about 1.63 seconds.
Across the observed recursion edges, all 4,906 children had smaller semantic
residual encodings than their parents.  This finite strict decrease proves
termination for the run; it does not establish a uniform power contraction
$N\mapsto N^b$ for any fixed $b<1$.

\section{Williams Theorem 1.1 in the polynomial-input regime}
Williams proves that for fixed positive constants $\alpha\le\beta$, an
algorithm solving Circuit-SAT on circuits of size
$2^{\alpha n+o(n)}$ in time $2^{\beta n+o(n)}$ yields an algorithm for
$2^{o(n)}$-size circuits in time
$2^{(\beta-\alpha)n+o(n)}$ \cite{williams2024}.  The proof uses
\[
 f_0=\beta,
 \qquad
 f_{k+1}=\beta\frac{f_k}{f_k+\alpha},
 \qquad
 \lim_k f_k=\beta-\alpha.
\]
It constructs a circuit $D$ that hard-codes the source circuit $C$, evaluates a
restriction, and simulates the preceding-stage SAT algorithm.  For fixed
$\alpha>0$, the source size $2^{o(n)}$ is absorbed by the allowed
$2^{\alpha m+o(m)}$ size of $D$.

Suppose a polynomial-size source has $S=n^d$ and a $P=NP$ algorithm runs in
$S^K$.  Writing
\[
 \alpha_n=\frac{d\log_2 n}{n},\qquad \beta_n=K\alpha_n
\]
and formally substituting these vanishing quantities gives, in polynomial
coordinates, the tempting recurrence
\[
 p_{k+1}=K\frac{p_k}{p_k+1},
 \qquad p_0=K,
 \qquad \lim_kp_k=K-1.
\]
This is not an application of Theorem 1.1.  Its quantifiers fix $\alpha$ and
$\beta$ before $n$ tends to infinity.  More concretely, after a nonzero split
the allowed hard-coded size would be
\[
 2^{\alpha_n(1-\delta)n}=S^{1-\delta}<S,
\]
while $D$ still contains or evaluates the $S$-size source.  The term absorbed
as $2^{o(n)}$ for fixed $\alpha$ becomes the dominant source floor.

If $p$ is the prior polynomial exponent, a source-retaining self-encoding has
size exponent at least $\max\{1,\delta p\}$ relative to $S$.  Calling the
$S^K$ algorithm therefore gives the guarded recurrence
\[
 p_{k+1}\ge K\max\{1,\delta p_k\}\ge K.
\]
Variable-density splitting cannot remove that floor.  If an independently
proved compiler reduced the source term to $S^b$ with $b<1$, the corresponding
expression would become $K\max\{b,\delta p_k\}$.  This identifies the possible
bridge, but proving such a $b$ uniformly with its construction and access costs
is the project’s open compression theorem.

The bounded audit checks 25 published recurrences, 24 source-floor grids and
12 vanishing-$\alpha$ substitutions.  It also uses unique bounded-degree
3-CNFs.  With a polynomial branch budget, assigning $O(\log S)$ variables
touches only $O(\log S)$ clauses, leaving $S-O(\log S)=S^{1-o(1)}$ clauses.
Every clause in these controls is unique, so duplicate deletion has compression
exponent one.  Achieving $S^b$, $b<1$, by this variable restriction alone would
require assigning $\Omega(S)$ bounded-degree variables and hence exponentially
many branches.  Code and data are
\texttt{williams\_polynomial\_bridge.py} and
\texttt{williams\_polynomial\_bridge\_results.json}.

Section 5 of Williams's paper explicitly asks whether self-improvement can go
down to the $P=NP$ regime and says the current argument has bottlenecks below
subexponential time \cite{williams2024}.  The audit locates the relevant one
for this project: the fixed-positive-$\alpha$ quantifier and the hard-coded
source-size term.  CNF duplicate compression and ordinary variable-density
splitting do not remove it on general inputs.

\section{Literature transfer and present status}
Width-parametrized SAT validates the frontier method on restricted structural
classes, while supplying no unrestricted width reduction
\cite{allender2014}.  Reingold's logspace undirected-connectivity theorem could
reduce the working space of component membership in a formal implementation,
but it does not remove clause-scope access, exact cache replay, or Shannon
branching \cite{reingold2008}.  It is therefore a useful implementation bridge,
not the missing general contraction.

Relative to the prior bound-matching audit, this run closes the concrete
realization mismatch: source replay, frontier work, exact AND/OR composition,
bounded sharing and fallback now execute in one program with joint counters.
It also rejects an automatic transfer of Williams's fixed-$\alpha$ theorem to
polynomial input length.  The current strongest statement is
\[
 \boxed{\text{Exact wrapper; favorable general-SAT contraction OPEN.}}
\]
