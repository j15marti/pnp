\section{Exact signed-affine terminal}
Use a fixed deterministic indexed read-only-input machine with finite
binary strings. Input bit length is $N$, including explicit affine rows,
clauses, and any supplied module annotation. Variables are densely indexed,
$n\le N$; no exponentially large unused-variable header is allowed.
All derived matrices, coefficients, sort buffers, indexes and counters
are writable workspace. Arithmetic uses charged bit operations.

Let
\[
 F(x)=[Ax=b]\ \land\ \bigwedge_{j=1}^d C_j(x),
 \qquad x\in\F^n.
\]
For each clause $C_j$, let $E_j$ be the affine system pinning each literal
to false. Opposite literals in a tautological clause give inconsistent pins.
An empty clause has the whole cube as its violation event. Let
$L_J=\{x:Ax=b,\ E_j(x)\text{ for }j\in J\}$.

\begin{theorem}[Uniform signed reconstruction]\label{thm:count}
There is one uniform deterministic algorithm, for every $n,A,b,C_1,\ldots,C_d$,
that computes
\[
 \#F=\sum_{J\subseteq[d]}(-1)^{|J|}|L_J|,\qquad
 |L_J|=\begin{cases}0,&L_J=\varnothing,\\
 2^{n-\operatorname{rank}(A_J)},&\text{otherwise}.
 \end{cases}                                                   \tag{1}
\]
Subset replay takes $2^d\operatorname{poly}(N)$ time and
$\operatorname{poly}(N)$ space on that same machine.
In particular $d=O(\log N)$ gives polynomial time even with unrestricted
affine rank.
\end{theorem}
\begin{proof}
Pointwise,
$\mathbf1_F=\mathbf1_{Ax=b}\prod_j(1-\mathbf1_{E_j})$.
Expand the finite product and sum over $x$. Each summand is an explicitly
given affine system, so Gaussian elimination gives its consistency and rank.
Enumerate a $d$-bit subset counter, reconstruct its rows, eliminate, add its
signed count, and discard its workspace before the next subset. There are
exactly $2^d$ elimination attempts, including inconsistent systems and repeated
identical systems. Intermediate absolute sums are at most $2^{n+d}$, hence
need $O(n+d)$ bits. Dense matrix and replay buffers have polynomial size.
No SAT oracle or uncharged choice of a subset is used.
\end{proof}

\paragraph{Coalescence implementation.}
A canonical reduced row-echelon matrix, including right-hand sides, names
each nonempty affine set $L$. Maintain a sorted list of integer weights.
Initially the sole record is $(\{Ax=b\},1)$, unless inconsistent. At stage $j$,
replace each record $(L,w)$ by $(L,w)$ and $(L\cap E_j,-w)$, discard inconsistent
intersections, sort exact canonical descriptions, sum identical keys, and
discard zero weights. Let $W_j$ be the number of surviving records after stage
$j$, $W_*=\max_jW_j$, and
\[
 V=1+\sum_{j=0}^{d}W_j.                                        \tag{2}
\]
These are execution-dependent quantities for the declared source order,
not minimum representations supplied for free.

\begin{proposition}[Aggregate volume with multiplicity]\label{prop:volume}
The coalescing algorithm computes the same count as (1) and admits the
conservative simultaneous bounds
\[
 T=O(N^4 V),\qquad S=O(N^2(1+W_*))                             \tag{3}
\]
on the indexed bit model, after polynomial source decoding.
It makes exactly $1+\sum_{j=0}^{d-1}W_j$ Gaussian calls in the prototype,
including the initial system and every failed intersection.
\end{proposition}
\begin{proof}
Inductively the weighted sum of affine indicators equals the product of
the first $j$ clause indicators with the base indicator. Grouping identical
sets preserves that function; final integration gives (1).
At each stage at most $2W_{j-1}$ records are generated before coalescing.
Weights have magnitude at most $2^j$, since they collect signs of at most
that many original subsets. Each canonical matrix has $O(n^2)$ bits and
each coefficient $O(d+1)$ bits. Gaussian elimination and comparison use
polynomial bit work; deterministic sorting has at most
$O(W_{j-1}\log(2W_{j-1}))$ comparisons, with
$\log(2W_{j-1})\le d+1\le O(N)$.
A conservative $O(N^4)$ budget per input record covers all of these operations,
including exact key comparison, allocation, source replay and coefficient
arithmetic. During a transition the previous list, generated list and new
list occupy $O(N^2(1+W_*))$ bits, with a constant factor for sorting buffers.
The final rank-weight sum has the same polynomial arithmetic allowance.
Records are charged at every stage where executed, even if the same set
occurred earlier. Signed cancellations are not a refund for producing terms.
\end{proof}

The implementation's record cap returns UNKNOWN before oversized candidate
allocation. It is a representation cap, not a measured physical bit/time
certificate. A complete algorithm may instead choose subset replay; it
cannot combine the coalescing time with the replay space without paying for
an actual schedule. Polynomial $V$ is sufficient for polynomial time,
not proved for every input and not necessary for other algorithms.

\section{Concrete source acquisition beyond isolated XOR blocks}
A Boolean support may be counted instead of the original witnesses when only
decision is needed, but these two counts must remain explicitly typed.

Partition the original clause IDs into modules $M_i$, each with scope $V_i$.
Authenticate every original clause exactly once and all literal names.
Let $B$ be all variables appearing in more than one module; all remaining
variables are private to one module. Let
\[
 R_i=\{a\in\{0,1\}^{V_i\cap B}:
           \exists y\in\{0,1\}^{V_i\setminus B}\ M_i(a,y)\}.
\]
There is no requirement that the module incidence graph be a tree.
Every shared variable is kept in $B$.

\begin{theorem}[Charged source-module compiler]\label{thm:modules}
Given such an authenticated explicit partition with $|V_i|\le w_i$, compute
$R_i$ by exhaustive local assignment enumeration. For each affine $R_i$,
produce exact GF(2) equations on its original boundary names. For each
nonaffine $R_i$, produce a clause forbidding each missing tuple.
Let $d$ be the total number of these forbidden tuples. Then
\[
 F\in SAT\quad\Longleftrightarrow\quad
 \exists x_B\ [A_Bx_B=b_B\land\bigwedge_{j=1}^d C_j(x_B)].       \tag{4}
\]
The terminal counts feasible \emph{boundary assignments}, not full source
models. With discovery cost $D(N)$, total cost is bounded by
\[
 D(N)+\operatorname{poly}(N)\sum_i2^{2w_i}
       +2^d\operatorname{poly}(N')                            \tag{5}
\]
using subset replay, where $N'$ is the actual compiled bit length.
The same implementation uses
$\operatorname{poly}(N+N'+\sum_i2^{w_i})$ workspace.
Alternatively use (3) on $N'$ and charge its coalescing storage.
If $D(N)$ is polynomial, every $w_i=O(\log N)$ with one fixed constant,
and $d=O(\log N)$, (4) is a uniform polynomial-time terminal.
\end{theorem}
\begin{proof}
Enumeration produces the exact support. For nonempty support choose $a_0$
and row-reduce the difference vectors $a+a_0$. The support is affine exactly
when its size equals $2^r$, where $r$ is the rank of those differences:
the support lies in that affine hull, which has exactly $2^r$ points.
Equations for the hull can be found by a nullspace calculation.
The prototype instead enumerates all boundary linear forms and keeps the
ones constant on the support; the displayed $2^{2w_i}$ allowance covers
this deliberately simple implementation. Empty support gives an inconsistent
equation. Each missing nonaffine tuple has one exact excluding clause.
Every source solution yields a boundary assignment satisfying every compiled
relation. Conversely, for a feasible boundary assignment select a local private
extension in each module. Private scopes are disjoint, and all shared names
agree by construction, so these extensions glue into a source solution.
Cycles cause no ambiguity because no shared coordinate is forgotten.
Enumeration, authentication, support storage, equations, forbidden tuples and
their actual encoding are charged. Apply Theorem~\ref{thm:count} to the result.
\end{proof}

This is an implemented source check and compiler, not merely an existential
decomposition. The supplied partition still costs its full annotation and
verification. An all-input baseline partition with one clause per module is
available cheaply, but can have $d=\Theta(N/\log N)$.
The difficult unproved improvement is a uniformly cheap better partition.
No hidden successful partition search is included in $D(N)=\operatorname{poly}(N)$.
Affine support replacement preserves feasibility, not multiplicity of
private extensions; using it to report original \#SAT would be incorrect.

\section{Falsifiers and the exact strict22 boundary}
\begin{proposition}[Signed information cannot be replaced by SAT bits]
For $F=(x)\land(\neg x)$ with no base equations, the nonempty affine records
have signed counts $2,-1,-1$, summing to zero. Each record is individually
satisfiable.
\end{proposition}
\begin{proof}
The records are the full one-bit cube, $x=0$, and $x=1$.
Their coefficients are respectively $1,-1,-1$.
\end{proof}
Thus Boolean OR of the child answers fails. Assuming a polynomial SAT decider
does not by itself supply the exact weighted arithmetic used by the paper.
We prove no general reduction of that arithmetic to a favorable SAT wrapper.

\begin{proposition}[Exponential coalescing state on easy formulas]
For $d\ge1$ let
\[
 F_d=\bigwedge_{i=1}^d(z\vee x_i\vee y_i).
\]
The source-order coalescing algorithm has $W_j=2^j$ and
$\#F_d=4^d+3^d$. These are connected dual-Horn proper 3CNFs, satisfied
by the all-one assignment. Complementing all variables gives Horn controls
with the same state counts.
\end{proposition}
\begin{proof}
For every nonempty subset $J$, its violation intersection fixes $z=0$ and
precisely the pairs $x_i=y_i=0$ for $i\in J$. Distinct subsets give distinct
nonempty affine sets. The empty subset gives the whole cube. Coefficients
are $\pm1$, so no exact-key coalescence occurs. If $z=1$, all $4^d$ pairs
are free; if $z=0$, each pair has three allowed assignments.
\end{proof}
This is not a strict22 family and is not a lower bound on arbitrary solvers.
A one-variable split on $z$ or a factored representation handles it cheaply.
Repeated identical clauses instead leave only two coalesced records.
Representation and source order therefore matter.

\begin{lemma}[Literal XOR3 blocks saturate strict22 occurrences]
Suppose a proper ternary CNF has exactly two positive and two negative
occurrences of every variable. If four of its clauses are the complete
standard CNF encoding of $a\oplus b\oplus c=\epsilon$, then $a,b,c$ occur
in no other clause. The block is an isolated incidence component.
Consequently no connected strict22 formula with more than three variables
contains such a complete literal block.
\end{lemma}
\begin{proof}
The four excluded assignments have one parity on three coordinates.
On each coordinate exactly two of these assignments have value zero and two
have value one. The corresponding four clauses therefore contain each
variable exactly twice positively and twice negatively. This exhausts its
entire source occurrence budget, so no other clause touches the block.
\end{proof}
Our literal-block extractor is source-syntactic and exact, but on every
connected strict22 source with $n>3$ it leaves $d=m=4n/3$ clauses.
Thus its $2^d$ guarantee yields no polynomial bound there.
This obstruction applies only to intact four-clause recognition, not to
semantic module projections, elimination, or RING160's source splices.
The module compiler in Theorem~\ref{thm:modules} is a concrete way to seek
the missing nonlocal acquisition without pretending that it is already cheap.

\section{WRAPPER and ARC reconciliation}
The typed route is
\begin{gather*}
 \text{authenticated source}\ \longrightarrow\
 \text{boundary CNF+affine}\ \longrightarrow\
 \text{signed affine records},\\
 \text{signed affine records}\ \longrightarrow\
 \text{integer}\ \longrightarrow\ \text{SAT bit}.
\end{gather*}
It is a terminal, not a recursive cycle of smaller ordinary-SAT children.
Gaussian calls and repeated intersections are local work, so they cannot
be hidden in favorable SAT child volume. The aggregate is (2), rather than
a worst child count times a maximum guessed size. Discovery, failed
intersections, source scans, exact sorting, coefficient buffers and simultaneous
old/new state are charged. If called inside WRAPPER, add the terminal's
workspace to retained ancestor state. A source-size assumed $N^K$ SAT
fallback retains $K$; no unconditional elimination follows from this terminal.

The primary FLMV model is the indexed read-only-input random-access Turing

 NTIME[n]\not\subseteq DTISP[n^c,o(n^{\beta(c)})],\qquad
 \beta(c)=\tfrac12((c+2)/c^2-c).

Its transfer to the project's SAT encoding must retain the charged local

\section{Reproducible evidence}
All suites use the adjacent stdlib Python file; each invocation is externally
capped by \texttt{timeout 25s}. They are split into four independently saved
JSON checkpoints. Each result embeds the exact code SHA-256.
\begin{description}
\item[] \textbf{small:} 1,204 differential cases, 831 SAT and 373 UNSAT;
all 256 subsets of the eight proper clauses on three variables with four
affine backgrounds, plus 180 seeded mixed cases. An additional 256 extraction
checks preserve exact source counts. Random cases compare coalescence,
subset replay and independent truth tables; reversed input order preserves counts.
\item[] \textbf{strict22:} 72 signed exact22 samples on 3,6,9 variables,
seed 122911; all counts match exhaustive assignments. All 48 connected
samples with more than three variables have no extractable complete XOR3
block. Rejection sampling discarded 1,618 malformed draws, recorded as
generator work, not solver complexity.
\item[] \textbf{hostile:} stars through $d=10$ reach 1,024 coalesced states;
their Horn complements agree. Thirty identical clauses use two states but
still incur 60 Gaussian calls. Contradictory units test signed cancellation;
a record-cap overflow returns UNKNOWN. Four disjoint strict22 affine
products have the predicted counts.
\item[] \textbf{modules:} 120 seeded source partitions compare the computed
boundary count with independent projection of every source solution.
There are 30 SAT and 90 UNSAT cases (seed 122912).
The opposite-parity cyclic example is correctly UNSAT although each module
is SAT. Duplicate source ownership is rejected.
\end{description}
Tests do not cover every strict22 instance, validate the ETH manuscript, or
measure native machine exponents. The record counters are semantic execution
counters, not bit-instruction instrumentation. The proof supplies the
conservative bit bounds. No independent external referee is claimed.

\paragraph{Barrier audit.}
These are upper algorithms for explicit objects. No arbitrary SAT solver is
forced to build the signed representation. A semantic oracle can bypass its
work; low-degree extension access likewise does not create a lower bound.
No nonrelativizing, nonalgebrizing or Natural-Proofs escape is established.
The coding-theory transfer is exact GF(2) rank/nullspace computation, not a
cryptographic hardness assumption. Padding, replay and duplicated constraints
are charged; changing the representation may remove the exhibited blow-up.
