\section{Claim card and target}
The current fixed language is
\[
 \Ltwo=\{\enc(G):G\text{ is a nonempty proper distinct-clause signed
 exact-$(2,2)$ 3-CNF and }G\in\SAT\},
\]
with malformed and out-of-domain strings rejected.  IMAGE22COMP1 and its
independent review establish the ordinary NP-completeness interface.  The
desired conclusion is still
\[
 \forall A\in\operatorname{Dec}(\Ltwo)\ \forall k\ge1\ \forall C>0\
 \forall N_0\ \exists x:\quad |x|\ge N_0\ \wedge\
 T_A(x)>C|x|^k.                                             \tag{1}
\]
One fixed NP-complete language is sufficient, but one easy or hard-looking
instance is not.  The inputs witnessing (1) may depend on $A,k,C,N_0$.

The selected falsification target is weaker and local.  It asks whether
conditioning one source variable and allowing an arbitrary existential
exact-$(2,2)$ repair always yields a strictly smaller recursive $\Ltwo$
child.  The quantifiers attacked are
\[
 \forall B\in\mathcal C_{22}\ \forall x\in\operatorname{var}(B)\
 \forall b\in\{0,1\}\ \exists G_b\in\mathcal C_{22}:\quad
 B|_{x=b}(u)\equiv\exists z\,G_b(u,z),\quad |G_b|<|B|.       \tag{2}
\]
The model is the declared dense ordered encoding; no SAT oracle, advice,
hash, succinct formula, or unit-cost large integer is supplied.  The SAME
REALIZATION objects are the source function, conditioned residual, repaired
target formula, and its complete serialized bytes.  The weakest useful
result is one infinite counterfamily to (2).

\section{A tight exact-occurrence obstruction}
For variables $a,b,c$, let $X(a,b,c)$ be the four proper clauses forbidding
the assignments of odd parity, so that $X$ computes
$a\oplus b\oplus c=0$.  Every variable occurs twice positively and twice
negatively.  For $k\ge1$ let
\[
 B_k=\bigwedge_{j=0}^{k-1}X(x_{3j+1},x_{3j+2},x_{3j+3}).   \tag{4}
\]
Then $B_k$ has $n=3k$ variables and $m=4k$ clauses, is proper, has distinct
clauses, and lies in the exact-$(2,2)$ domain.

Fix $x_1=\beta$.  The residual Boolean function $f_{k,\beta}$ depends
essentially on every one of the remaining $3k-1$ source variables.  Indeed,
the first block becomes XOR or XNOR on $x_2,x_3$ and every other block remains
an independent three-variable parity equation.  Holding the other blocks at
satisfying assignments supplies a sensitivity witness for each variable.

\begin{theorem}[\texttt{EXACT22-ONE-PIVOT-MODULAR-FIREWALL1}]
Let $G(u,z)$ be any proper distinct-clause exact-$(2,2)$ 3-CNF such that
\[
 f_{k,\beta}(u)=1\quad\Longleftrightarrow\quad
 \exists z\ G(u,z)=1                                      \tag{5}
\]
for every assignment to the named residual variables $u$.  Then
\[
 v(G)\ge3k=v(B_k),\qquad M(G)\ge4k=M(B_k).                 \tag{6}
\]
Both bounds are attained.  Under the compact dense JSON encoding used by
IMAGE22DECODE1, an attaining child has exactly the same encoded byte length
as the parent.
\end{theorem}

\begin{proof}
If an essential source variable does not occur in $G$, the right side of
(5) is independent of it, a contradiction.  Hence $G$ has at least $3k-1$
active variables.  In every proper exact-$(2,2)$ 3-CNF, double-counting
literal occurrences gives
\[
                         3M(G)=4v(G).                      \tag{7}
\]
Since $\gcd(3,4)=1$, $v(G)$ is a multiple of three.  Therefore
$v(G)\ge3k$, and (7) gives $M(G)\ge4k$.

For tightness, retain the last $k-1$ parity blocks.  Replace the conditioned
first block by one of
\begin{equation}
 (y\vee z\vee q)\wedge(y\vee z\vee\neg q)\wedge
 (\neg y\vee\neg z\vee q)\wedge
 (\neg y\vee\neg z\vee\neg q),                         \tag{8}
\end{equation}
\begin{equation}
 (y\vee\neg z\vee q)\wedge(y\vee\neg z\vee\neg q)\wedge
 (\neg y\vee z\vee q)\wedge
 (\neg y\vee z\vee\neg q),                            \tag{9}
\end{equation}
according to whether the residual relation is XOR or XNOR.  Existentially
quantifying $q$ leaves precisely the required binary relation.  Each of
$y,z,q$ occurs twice with each sign, so the repaired product has exactly
$3k$ variables and $4k$ clauses.

For compact dense JSON, every exact-$(2,2)$ formula with $v=3k$ has four
occurrences of each dense identifier, exactly two negative signs per
identifier, $4k$ three-entry clause records, and the same punctuation.
Thus the parent and the attaining child have identical serialized length.
\end{proof}

\begin{corollary}
No theorem asserting strict one-variable target shrinkage on every
exact-$(2,2)$ input can hold, even when arbitrary auxiliaries and arbitrary
existentially equivalent target formulas are allowed.
\end{corollary}

This strengthens SOURCEARC-NOCONTRACT1.  That report proved expansion for a

\section{Why this is not a lower bound}
The family (4) is affine.  Gaussian elimination, or direct blockwise parity
assignment, decides it in polynomial time and linear work in the displayed
representation.  Hidden algebraic structure is an algorithmic weakness here.
The theorem therefore falsifies a recursive shape claim; it does not prove
that any $B_k$ is hard for an unrestricted decider.

COPY, DEAD and DELAY wrappers can add cost but cannot force an arbitrary
solver to recurse.  RECOMP returns to a size-neutral child.  A semantic SAT
oracle answers immediately.  Low-degree algebraic access exposes the parity
equations rather than preserving a hardness claim.  The theorem relativizes
and algebrizes because it is a syntactic counting statement; it supplies no
nonrelativizing hinge and defines no Natural-Proofs property.

For a hypothetical batch fixing $t$ variables while retaining all remaining
variables as essential, the smallest exact target has
\[
 v_{\min}=3\left\lceil\frac{3k-t}{3}\right\rceil.          \tag{10}
\]
If a controller emits all $2^t$ branches as nonterminal children, the tested
$c=6/5$ moment $2^t(v_{\min}/3k)^c$ exceeds one over the audited range.
This is a conditional recurrence diagnostic only.  Pruning, terminal
recognition, component factoring, or a different hard family can change the
recurrence and must be charged separately.
