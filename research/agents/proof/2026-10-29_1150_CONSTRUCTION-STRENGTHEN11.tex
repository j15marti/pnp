equations, using at most $B_e(n)=\sum_{j=0}^{\min(e,n)}\binom nj$ least-model

\section{Small-pin interpolation: a complete construction}
Identify Boolean vectors with their supports. Let $R\subseteq 2^{[n]}$ be
a nonempty intersection-closed family. A pin set $S$ is feasible when some
$x\in R$ contains $S$. Define
\[
 c(S)=\bigcap\{x\in R:S\subseteq x\}.
\]
For a feasible $S$, $c(S)\in R$ and is its unique least extension.
Infeasible sets have no closure and are skipped.

\begin{lemma}[Degree-$e$ hitting by small-pin closures]
Let $P\in\F[x_1,\ldots,x_n]$ have Boolean multilinear degree at most $e$.
If $P$ is nonzero on some member of $R$, then it is nonzero on $c(S)$ for
some feasible $S$ with $|S|\le e$.
\end{lemma}
\begin{proof}
On $R$, a monomial $x_S=\prod_{i\in S}x_i$ vanishes if $S$ is infeasible;
otherwise
\[
 x_S(x)=1\quad\Longleftrightarrow\quad c(S)\subseteq x.
\]
Group coefficients of monomials having the same closure. Then the
restriction of $P$ is a linear combination of the functions
$z_C(x)=\mathbf1[C\subseteq x]$, for the distinct feasible closures
$C=c(S)$ with $|S|\le e$. Order those closures by a linear extension of
inclusion. The matrix with rows $D$, columns $C$ and entry
$\mathbf1[C\subseteq D]$ is triangular with diagonal one. It is invertible
over $\F$. If $P$ vanishes on every such $D$, all grouped coefficients
vanish, so $P$ vanishes throughout $R$, a contradiction.
\end{proof}

\begin{theorem}[Fixed-parity Horn terminal]
Let $H$ be Horn and let $L$ consist of $e$ equations
$\ell_j(x)=b_j$. There is an exact deterministic algorithm that decides
$H\land L$ by enumerating the $B_e(n)$ pin sets and testing their feasible
least Horn extensions. On YES it returns an original witness; on NO it
returns NO only after exhausting this complete family.
\end{theorem}
\begin{proof}
Horn models are closed under intersection. If there are none, every pin
trial fails. Otherwise apply the lemma to
\[
 P(x)=\prod_{j=1}^{e}(1+b_j+\ell_j(x)).
\]
This polynomial has degree at most $e$, and equals one precisely when all
equations hold. It need not be expanded or stored. A least Horn extension
is acquired by monotone forward propagation from the pins. A negative
clause becoming false rejects that trial. At most $n$ new bits become true;
one final unchanged scan verifies the fixed point. Thus at most $n+1$
full scans suffice. The empty pin set is included, also when $e=0$.
\end{proof}

\begin{corollary}[2CNF terminal]
Find a model $a$ of the 2CNF, or reject if none exists. Substituting
$x=a\oplus y$ yields a 0-valid 2CNF. Every non-tautological clause then has
a negative literal, and hence is Horn. Transform each parity right-hand
side to $b_j+\ell_j(a)$ and apply the preceding algorithm. Undo the shift
and verify the source witness. This is an exact construction for every
fixed $e$, not a collection of independent marginal parity tests.
\end{corollary}

The implementation supplies the base model through a dense implication
reachability matrix, not a SAT oracle. A separate low-space rescanning
variant is described below. For two parities, the closure budget is
$1+n+\binom n2$. Two pins can be necessary: with empty Horn formula and
requirements $x_1=x_2=1$, the empty and singleton closures all fail.
Separate marginal acceptance is unsound: $(\neg x_1\vee\neg x_2)$ allows
each requirement separately and forbids their conjunction.

\section{Application to the actual observed-affine interface}
Start from the source-authenticated mixed instance of ARC227: an explicit
affine system and a 2CNF over the same original variables. Paid elimination
either rejects the affine system or yields
\[
 x_i=a_i+\langle v_i,t\rangle.
\]
Let $V$ be the distinct nonzero forms $v_i$ observed in the 2CNF, let
$k=|V|$, and let $e=k-\operatorname{rank}(V)$. Substitute a variable
$u_v=\langle v,t\rangle$ for each form; constants simplify clauses. The
result is a 2CNF $C(u)$. An explicitly acquired basis of dependencies among
the rows of $V$ yields $e$ homogeneous parity equations on $u$.

\begin{proposition}[Bounded observed dependency terminal]
For every fixed $e_0$, there is one exact partial algorithm on this declared
mixed input language which decides every input with $e\le e_0$. It checks
affine consistency, constructs $C$ and the complete dependency basis, uses
the small-pin terminal, and reconstructs and checks an original witness.
It returns UNKNOWN for $e>e_0$ unless affine inconsistency already proves NO.
\end{proposition}
\begin{proof}
The image of $t\mapsto(\langle v,t\rangle)_{v\in V}$ is exactly the common
kernel of its row-dependency equations. Hence the projected problem is
equivalent to $C(u)$ conjoined with those equations. The corollary decides
that problem. A satisfying $u$ lies in the image, so Gaussian solving
recovers $t$ and thus $x$. None of these steps chooses a parameter using an
unknown truth label. Failure of the cap proves nothing about satisfiability.
\end{proof}

The supplied prototype implements this projection and witness lift, including
the $e=2$ case. It takes explicit rows and clauses. It does \emph{not}
implement a new raw-CNF quartet parser, a source authentication service, or a
strict exact-$(2,2)$ source compiler. To invoke it from ordinary CNF, the
existing source-authenticated extraction must be verified and its time,
space and replay added. This distinction prevents calling a supplied matrix
a freely acquired native SAT input.

\section{Same-machine resource ledger and falsification}
For explicit read-only Horn clauses and parity rows, a scan implementation
has simultaneous conservative bounds
\[
 T_H=O\bigl(B_e(n)(n+1)N\operatorname{polylog}(N+2)\bigr),\qquad
 S_H=O\bigl(n+(e+1)\log(N+2)\bigr).
\]
It stores one $n$-bit assignment, pin indices, loop counters and one parity
accumulator; it rereads source rows. Resets, failed trials, final scans and
witness checking are included. No occurrence table, memoization or closure
deduplication is assumed. Equal closures reached by different pin sets are
computed again and charged again.

A dense bit-matrix base-model procedure adds $O(N+n^3\operatorname{polylog}N)$
time and $O(n^2+\log N)$ bits. It computes all implication reachability,
rejects mutually reachable complements and greedily extends a consistent
closed set of true literals. Its shift can be applied on each source scan
without storing another formula. Alternatively, repeated reachability scans
and $n$ self-reduction queries cost $O(n^3N\operatorname{polylog}N)$ time
and $O(n+\log N)$ work bits. These are two alternative realizations; their
best coordinates may not be combined as if one machine achieved both.

The Python prototype retains clause tuples, shifted clauses and explicit
projection data. Its physical memory is therefore not the low-space scan
implementation just described. For the full mixed prototype, a deliberately
loose same-machine bit upper envelope, with original variable bound $n\le N$,
is $O((N+1)^{e_0+5})$ time and $O((N+1)^3)$ workspace for fixed $e_0$.
These bounds cover Gaussian matrices, dependence provenance, dense
reachability, witnesses and failed attempts; they are polynomial correctness
bounds, not favorable ARC exponents. Python big-integer operations and
instrumented counters are not unit-cost FLMV steps.

There are no recursive ordinary-SAT calls in this terminal, so executed
child count and volume are both zero. All the computation is terminal work.
An optional constant YES/NO child after decision adds constant volume but
does not reduce acquisition cost. A parent using this terminal must retain
and charge its suspension and ancestors in addition to these bounds.

\begin{proposition}[Exact replay-cost counterexample]
For the specified unindexed Horn scan implementation, take
$H_n=\bigwedge_{i=1}^n\neg x_i$ and the single parity
$\bigoplus_i x_i=1$. In the natural clause order and empty-then-singleton
pin order it performs exactly $n+1$ trials and $n(n+3)/2$ clause reads.
\end{proposition}
\begin{proof}
The empty closure scans all $n$ clauses and fails the odd parity test.
The singleton $\{i\}$ contradicts precisely at clause $i$, after $i$ reads.
Their sum is $n+\sum_{i=1}^n i=n(n+3)/2$.
\end{proof}
With explicit binary identifiers the input has $N=\Theta(n\log(n+2))$
bits. This execution is already $\Omega(N^2/\log^2N)$ in clause reads,
so it is not an all-input $N^{6/5+o(1)}$ terminal. The control itself is
easy by direct propagation. It refutes only this implementation's cheapness,
not every implementation or SAT algorithm. Recognizing and bypassing it is
legal but does not establish a global bound for all other inputs.

The cap in the executable limits closure trials only. It does not claim
to meter total bit time or memory, and it may not be treated as a native
WRAPPER budget gate. A genuine joint-budget controller must also cap all
parsing, matrices, acquisition, switching and live state, returning UNKNOWN
before violating its budget. Such a cap preserves soundness but leaves
all-input coverage OPEN.

\section{Why fixed dependency coverage does not close the hard image}
The recovered selector reduction is explicit. For each proper source
3-clause $(l_1\vee l_2\vee l_3)$ introduce $s_1,s_2,s_3$, impose
$s_1+s_2+s_3=1$, the three pairwise at-most-one binary clauses, and
$s_i\Rightarrow l_i$. Existential selector extension is equivalent to the
original clause. For $m$ source clauses the parity rows have disjoint
supports and are independent. In the observed-form representation every
selector is observed; each triple gives three distinct nonzero forms of
rank two. Source-variable forms are independent of those private free
coordinates. Thus the observed dependency excess is exactly $e=m$.
The fixed-$e_0$ terminal cannot certify this entire reduction image.
The proposition gives no hardness lower bound on its own: under $P=NP$
this growing-parameter language would also be in P, with unknown exponent.

This also generalizes PARITY-CHOICE-XP119's at-most-$e$ sparse support
algorithm. Pure negative 2CNF is downward closed, so its feasible pin closure
is the pin set itself. General Horn implications may force additional true
variables; least closure, rather than raw support enumeration, is necessary.
This is the precise new constructive extension relative to that predecessor.
