\paragraph{Exact domain and algorithm.}
For every finite bounded-width CNF encoded in a read-only random-access
array of fixed-width clause records, every fixed consistent partial
assignment, and positive integer run cap R, normalize residual literals
using fixed variable labels, discard satisfied and tautological clauses,
and retain empty clauses. Scan surviving clauses in source order.
Partition greedily into disjoint weakly monotone runs; the first unequal
pair chooses direction. An incompatible next clause begins a new run.
Retain source endpoints and direction only. If more than R runs are needed,
return UNKNOWN. Otherwise use one cursor per run and a heap of current
clauses. Read descending runs backwards. Merge in ascending order,
discarding duplicate outputs. Compare two resulting streams exactly.

\paragraph{Correctness argument.}
Each discovered interval contains a monotone surviving sequence by the
direction invariant. Reversing a descending run makes that sequence
ascending. The intervals partition all surviving occurrences, so heap
merging enumerates precisely their sorted multiset. Adjacent duplicate
removal yields their exact clause set. Empty clause and empty conjunction
are distinguished. Equal streams therefore justify SAT decision reuse.
Different streams do not imply different SAT answers.
Cap failure makes no SAT assertion. Assignments and input remain immutable.
No first-occurrence renaming dependent on traversal direction is permitted.

\paragraph{Joint resource accounting and model.}
Let N be encoded source bits, d assignment entries, w constant width,
and r the total runs of the two children. Use sparse sorted assignment
records for deterministic lookup in a formal implementation.
For a single completed comparison, discovery reads the source once per
child, and recovery visits disjoint source intervals at most once per
child. Endpoints, run tables, heap keys, cursors, parser buffers,
assignment records and counters use O((r+d+1) log(N+2)) logical bits.
There are O(N/log(N+2)) heap operations for full-width records,
each with O(log(r+2)) comparisons of O(log(N+2))-bit keys.
A conservative deterministic bound is N times a polylogarithmic factor
on a random-access bit-cost model with charged address arithmetic.
Python dictionaries and heaps are an executable functional model, not
a certified deterministic bit-cost implementation.
No complete child or clause-offset table is retained.
The fixed-width source assumption is material: variable-width input
requires charged offsets or an explicitly analyzed accessor.
Recursive ancestors and repeated comparisons are not free:
sum all simultaneously retained tables, or discard and charge rediscovery.
The module supplies sequential canonical access, not constant-cost
arbitrary child access. No endpoint/model transfer is asserted.
