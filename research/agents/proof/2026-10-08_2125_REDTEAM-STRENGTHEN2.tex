prepass. The scanner rejects non-width-three input before checking masks.

The satisfiable formula
\[
 (x_1\vee x_2\vee x_3)\wedge(x_1\vee x_2\vee x_4)
 \wedge(x_1\vee x_3\vee x_4)
\]
lies in $U$. It is connected and non-Horn; its positive-pair graph is

\section{A uniform general-SAT embedding into the failure domain}
Let $P_0(u,v,w)$ be the four proper clauses encoding
$u\oplus v\oplus w=0$. For every proper exactly-width-three CNF $F$
on its occurring variables $[n]$, introduce distinct fresh variables
$h,r,a,b,c,d,w_1,\ldots,w_n$ and define
\[
 G(F)=F\wedge(h\vee r)\wedge P_0(h,a,b)\wedge P_0(h,c,d)
       \wedge\bigwedge_{v=1}^{n}(h\vee v\vee w_v).
\]
The two parity blocks and binary clause are fixed guards; the last
clauses connect every source component. There is no SAT query in this
construction.

\begin{theorem}[All-input embedding for the declared domain]
For every such $F$, $\operatorname{SAT}(G(F))=\operatorname{SAT}(F)$
and $G(F)\in U$. In dense fixed-width binary literal encoding,
$|G(F)|=\Theta(|F|)$, and the transformation is a uniform logspace
transduction. Its output bits have a polylogarithmic-time,
$O(\log |F|)$-workspace random-access generator.
\end{theorem}
\begin{proof}
Any satisfying assignment of $G(F)$ satisfies $F$. Conversely extend
any satisfying assignment of $F$ by $h=r=a=c=1$, $b=d=0$ and arbitrary
$w_v$. Every added clause is satisfied.

The binary clause forces the new scanner to return UNKNOWN. The
formula is nonconstant, connected, non-Horn and not 2-CNF, ruling out
four original members. Consider any backdoor candidate $B$, $|B|\le2$.
If $B\ne\{h,r\}$, no clause can become empty under any assignment to
$B$: the sole binary clause has an unassigned variable and every other
clause has width three. The positive-pair graph of the two parity guards
contains two triangles meeting at $h$; its minimum vertex cover is three.
Some positive pair is unhit. Choose a guard clause containing that pair
and falsify its third literal if that literal's variable belongs to $B$.
The clause remains non-Horn. (For $P_0$, the third literal is negative,
so falsifying it means assigning its variable TRUE.) No empty-clause
shortcut can hide the obstruction. If $B=\{h,r\}$, use $h=1$.
The binary clause is satisfied and the first parity block leaves the
positive clause $(a\vee b)$. Thus this $B$ also fails. The original
portfolio returns FAIL on every image.

For encoding, let $m$ be the source clause count and require dense
identifiers $1,\ldots,n$, each occurring, with $n\ge3$. Hence $n\le3m$.
Encode the $n,m$ header self-delimitingly, each clause arity in a fixed
two-bit field, and each literal by one sign bit plus
$\lceil\log_2(n+1)\rceil$ identifier bits. Then
$N=\Theta(m\log(n+1)+\log(m+1))$. The output has
$n'=2n+6$ variables and $m'=m+n+9$ clauses. The sole binary clause is
at known position $m+1$; all other records have width three. Therefore
$N'=\Theta(N)$. An emitter copies the source literals at the new bit
width and emits guards/connectors using counters, in $O(N\log N)$
conservative bit time and $O(\log N)$ workspace, excluding its
write-only output.

The stronger access statement is separate from streaming. Given an
output bit position, parse the logarithmic header and compute whether
the position lies in the copied-source block, the binary record, one
of eight fixed parity records, or a connector. Fixed-width record
arithmetic uses $O(\log N)$ bits. A source-block output bit is either
a padding bit, an arity bit, or a directly indexed original literal
bit. Other blocks use only counters and fixed signs. Schoolbook
arithmetic and input-address copying give $\operatorname{polylog}N$
time and $O(\log N)$ space per request, with at most one source-payload
bit read in addition to the header. No output array or renaming table
is retained.
\end{proof}

This theorem uses dense occurring-variable encoding. Arbitrary long
names or an enormous declared unused-variable universe require a
separate renaming/normalization ledger. The theorem is not silently
transferred to every SAT encoding.

\section{Same-machine consequence and its limit}
Suppose a fixed uniform machine $A_U$ correctly decides every formula
in $U$, with simultaneous bounds $T_U(N),S_U(N)$ there. It need not
recognize $U$ itself. On proper 3-CNF input $F$, simulate $A_U$ on the
virtual input $G(F)$ using the proved bit generator. Every request,
including repeated reads, is serviced and charged. For monotone resource
envelopes and some fixed constant $C$, one actual simulation gives
\[
 T(F)\le \operatorname{polylog}N\,(1+T_U(CN)),\qquad
 S(F)\le O(\log N)+O(S_U(CN)).
\]
This avoids retaining a linear output buffer. Finite control of $A_U$
is fixed; its tape state and all input-address registers are counted.
No ancestor is suspended in this top-level reduction. An application
inside another wrapper must add its retained ancestors and interfaces.
In exponent notation the same pair transfers to general proper 3-SAT.
Thus bounding the residual domain is a general-SAT obligation for this
portfolio, rather than merely handling a few exceptional examples.
It remains possible to improve the portfolio or use another route.
This result does not forbid a polynomial fallback under $P=NP$.

Removing the added guard simply exposes the unchanged $F$. A recognizer
for this image can reverse the padding cheaply, but that is not a
fixed-power reduction of the arbitrary core. Pure-literal elimination
also bypasses the particular guard; the theorem concerns the exact
published portfolio, not every possible preprocessing extension.
