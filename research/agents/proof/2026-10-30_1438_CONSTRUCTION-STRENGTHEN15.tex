\section{Primary endpoint and certified optimization}
FLMV equation (14) and Theorem 5.7 give
\[
 f_0(c)=1,\quad f_{k+1}(c)=\frac{cf_k(c)}{1+f_k(c)},\qquad
 d_k(c)=\min\left\{\frac{1/f_k(c)-c}{k},c^{-k}\right\}
\]
and, for each fixed integer $k\ge2$,
\[
 \mathrm{NTIME}[N]\not\subseteq
 \mathrm{DTISP}[N^c,o(N^{d_k(c)})].
\]
Set $D(c)=\max_{k\ge2}d_k(c)$ on $1<c<\varphi$.
To certify a finite search, maintain its positive incumbent $b$.
After inspecting $k=K$, stop once $c^{-(K+1)}<b$.
For every $j>K$, $d_j(c)\le c^{-j}\le c^{-(K+1)}<b$;
therefore no uninspected integer improves the incumbent.
A positive incumbent exists in this range because
$f_k\to c-1$ and $c(c-1)<1$. The tail tends to zero, so
the stopping rule terminates. This is a complete certificate, not a
finite truncation asserted to be optimal.
The independent expression
\[
 f_k(c)=\frac{c-1}{1-(2-c)c^{-k}}
\]
checks every recurrence value using exact fractions.

\section{Concrete strict22 context and the transfer gate}
The recovered six-variable example in Construction12 has eight proper
clauses, each variable twice positive and twice negative, and 16 models.
Its literal payload is 96 bits under three-bit identifiers plus a sign bit,
excluding headers. This does not imply any asymptotic lower bound for that
one source. In a strict22 family $3m=4n$; standard fixed-width literal
encoding gives $N=\Theta(n\log(n+2))$ for unbounded $n$.

Let a uniform reduction produce length $M\le N^{q+o(1)}$ and use
time $N^{r+o(1)}$, workspace $N^{u+o(1)}$.
A target solver with exponents $(t,s)$ yields, by materializing the target,
\[
 T_{\rm total}\le N^{\max(r,qt)+o(1)},\qquad
 S_{\rm total}\le N^{\max(u,q,qs)+o(1)}.
\]
The displayed $q$ is a conservative buffer upper-bound exponent, not a
lower bound on all possible implementations. If the actual target has
length $\Theta(N^{q+o(1)})$ and is materialized, it really occupies that
many writable bits. A linear-size explicit target therefore cannot
certify a sublinear-space FLMV point by this implementation.

A possible repair is an exact random-access output-bit service:
preprocessing exponents $(a,b)$, per-request time $N^{g+o(1)}$,
temporary workspace $N^{h+o(1)}$, and no stored full output.
Assuming a model-matched step simulation and charged address handling,
the composed bounds become
\[
 T_{\rm total}\le N^{\max(a,qt+g)+o(1)},\qquad
 S_{\rm total}\le N^{\max(b,h,qs)+o(1)}.
\]
This is a conditional accounting contract. Repeated requests are charged
with multiplicity; a logarithmic-space output transducer does not itself
give small $g$, because locating each requested output bit can replay
the whole generation. Failed attempts, indexing, preprocessing and any
suspended caller frames remain in the ledger.
The supplied CP22LIFT1 report recovers a stronger source interface:
for any nonempty ordered proper three-clause list with $m$ clauses,
including duplicates, its selector-and-duplication compiler has
$72m$ target variables and $96m$ distinct exact22 clauses, with binary
length $\Theta(m\log(m+2))$. Its intermediate list pairs opposite
occurrences in source order and uses forced-zero ports of a fixed gadget.
PC22\_TRANSFER1 alone has the narrower balanced distinct-source hypothesis
$r_x\ge2$. These documents assert polynomial construction/proof transport,
not a fast small-space output-bit accessor. The fixed gadget and full
compiler semantics are dependencies, not re-proved here.
With $q=1$, naive full-source replay per output request has $g=1$,
so its generic time certificate is $t+1\ge2$ when $t\ge1$.
Materialization gives a linear buffer instead. Neither generic certificate
enters the displayed sublinear-space envelope; this does not prove that a
better accessor is impossible.
The exact22 reduction and accessor meeting favorable exponents remain
OPEN here. Mere NP-completeness does not supply their quantitative costs.
