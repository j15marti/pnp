\section{Single target and exact quantifiers}

The target of this run is narrower than a wrapper-invariant compiler.  Under
the contradiction hypothesis, there is at least one fixed uniform exact SAT
decider.  It is enough to select one such machine and exploit its code.  The
logical target is
\begin{equation}
 \bigl(\exists B\; B\text{ is a uniform polynomial-time SAT decider}\bigr)
 \Longrightarrow
 \exists A\,\exists W_A\; \Good(A,W_A),                 \tag{1}
\end{equation}
where $A$ may be a clocked normal form obtained from $B$.  Equation~(1) does
not require $W$ to work for every extensionally equivalent DEAD, COPY, DELAY,
INTERP, or RECOMP wrapper around $A$.

The favorable interpretation of this relaxation is exact but limited.  A
property inferred solely from SAT correctness must still survive equivalent
machines.  A property proved from the particular selected source code need
not.  What remains necessary is a proof that a favorable selected $A$ exists
under $P=NP$, or that a normalization $B\mapsto A$ forces the property.  Merely
announcing a convenient $A$ does not satisfy the existential implication.

We use ordinary explicitly materialized CNF as the recursive language.  The
input length is $M$.  The selected deterministic machine $A$ has certified
bounds
\begin{equation}
 T_A(n)\le n^{K+o(1)},\qquad S_A(n)\le n^{\sigma+o(1)},  \tag{2}
\end{equation}
for fixed finite constants $K,\sigma$.  It rejects malformed encodings.  A
clock and the constants in (2) may be hardwired once.  Classical existence of
a polynomial bound is sufficient for this choice; there is no claim that
polynomial boundedness can be decided from arbitrary program text.

\section{What finite code can and cannot contribute}

\begin{theorem}[FIXED-CODE-ERASURE1]
Fix a finite program $A$.  Let $U(\langle A\rangle,F)$ be a uniform procedure
whose use of $\langle A\rangle$ consists of ordinary computation, calls to
$A$, and finite preprocessing independent of $F$.  Then there is a uniform
procedure $U_A(F)$ with the same asymptotic time and space, up to constants,
obtained by hardwiring $\langle A\rangle$ and every finite input-independent
preprocessing result.  Any preprocessing that varies with $|F|$ must be
charged; supplying an externally computed object for every length is advice
and changes the uniform model.
\end{theorem}

\begin{proof}
The string $\langle A\rangle$ and every finite function of it have constant
length after $A$ is fixed.  Substitute those constants into the transition
table of $U$.  Input-dependent steps and calls to $A$ remain unchanged.  A
length-indexed external table is not one finite constant and therefore is
either generated at charged cost or is nonuniform advice.
\end{proof}

The theorem has status \PROVED.  It does not say that tailoring is useless.
It says that ``uses the code of $A$'' is not itself a resource bound.  A useful
tailoring must materialize as a particular uniform algorithm $U_A$ with a
proved source-dependent shortcut.

\begin{proposition}[OUTPUT-QUOTIENT-CIRCULARITY1]
For a total deterministic machine $A$, let $v_A(c)\in\{0,1\}$ be the eventual
output from configuration $c$.  The equivalence
\[
 c\equiv_A d\quad\Longleftrightarrow\quad v_A(c)=v_A(d)
\]
has at most two classes.  Any exact routine that returns the class of $c$, with
the two halting-class labels fixed, computes $v_A(c)$.
\end{proposition}

\begin{proof}
The class map is precisely the Boolean map $v_A$, up to a fixed relabeling of
the two classes.  Querying the class and applying that relabeling returns the
eventual output.
\end{proof}

Thus a tiny semantic quotient always exists, but its cardinality does not
make its acquisition cheap.  This is \PROVED, not a lower bound excluding a
machine-specific faster continuation algorithm.  Finding such an algorithm
would itself be the desired speedup.

\section{One circuit copy for an entire disjunctive family}

For each padded input length $m$, standard uniform circuitization of the fixed
machine gives a bounded-fan-in circuit $C_{A,m}$ computing $A$ on $m$ input
bits, with
\begin{equation}
 |C_{A,m}|=m^{K+o(1)}.                                  \tag{3}
\end{equation}
Pippenger and Fischer give an $O(T\log T)$-cost simulation in their declared
machine/network model; here this is used only as an upper bound for explicit
unrolling, never as a lower bound on all representations
\cite{pippengerfischer1979}.  Clocking and model transport contribute only
subpolynomial factors at exponent level.

\begin{theorem}[OR-MUX-COMPILE1]
Fix $A$ and $m$.  Given $q$ explicit padded encodings
$x_1,\ldots,x_q\in\{0,1\}^m$, one can construct a bounded-fan-in circuit $D$
and an ordinary 3-CNF $Q$ such that
\begin{align}
 D(z)&=C_{A,m}(x_z),\\
 \SAT(Q)&=1\quad\Longleftrightarrow\quad
 \exists i\le q:\ A(x_i)=1,                            \tag{4}\\
 |Q|&=O\bigl(m^{K+o(1)}+qm\bigr).                       \tag{5}
\end{align}
The construction does not execute $A$ on any $x_i$.
\end{theorem}

\begin{proof}
Pad $q$ to a power of two and map every unused selector value to a canonical
malformed encoding rejected by $A$.  A binary multiplexer with selector $z$
chooses one of the $q$ strings using $O(qm)$ bounded-fan-in gates.  Feed its
$m$ outputs into one copy of $C_{A,m}$.  Constrain the output gate to one and
apply the gate-by-gate Tseitin transformation.  Each bounded-fan-in gate adds
only constantly many variables and clauses, so the resulting 3-CNF has the
size in (5) and is satisfiable exactly when some selector makes the unique
circuit evaluation accept.  The circuit topology is generated from the code
of $A$; no evaluation of $A$ occurs during construction.
\end{proof}

This is \PROVED.  Separate unrollings would cost $qm^{K+o(1)}$ gates.  The
multiplexer replaces that product by the sum in (5).  It is a real shared
BatchAcquire mechanism for an OR aggregate.

It does not yet contract the original source.  If $m=M^b$ and explicit cover
volume is $qm=M^{v+o(1)}$, then
\begin{equation}
 |Q|=M^{\max\{bK,v\}+o(1)}.                              \tag{6}
\end{equation}
At the previously attractive equality-volume point $v=1$, (6) is still
parent-scale even when $bK<1$.  The exact sharing of machine computation does
not remove the explicit source volume.

\section{The compact multi-output generator route}

The previous limitation disappears if the family is supplied by one genuinely
sublinear, source-specific multi-output circuit, rather than by $qm$ listed
bits.  This is the strongest constructive refinement of the shared-$H$ target
found in this run.

\begin{definition}[Generated exact OR cover]
For a source CNF $F$ of length $M$, a circuit $E_{A,F}$ has selector input
$z\in\{0,1\}^{\ell(M)}$ and exactly $m(M)$ output bits.  Every output string
$E_{A,F}(z)$ is a padded ordinary CNF encoding, with invalid selector values
mapped to a fixed UNSAT encoding.  It is an exact generated cover when
\begin{equation}
 \SAT(F)=1\quad\Longleftrightarrow\quad
 \exists z:\ \SAT\bigl(E_{A,F}(z)\bigr)=1.              \tag{7}
\end{equation}
Circuit size counts all gates, input terminals, output terminals, embedded
constants, and wiring-description bits.  The parent is not available to the
recursive consumer through an undeclared oracle.
\end{definition}

\begin{theorem}[GENERATED-OR-SHRINK1]
Fix the clocked exact machine $A$ satisfying (2).  Suppose there are constants
$0<b\le h<1$, $r\ge h$, and $p\le h$ and a uniform constructor $G_A$ such
that, for every ordinary CNF $F$ of length $M$, $G_A(F)$ produces an exact
generated cover $E_{A,F}$ satisfying
\begin{align}
 |E_{A,F}|&\le M^{h+o(1)},&
 m(M)&\le M^{b+o(1)},                                   \tag{8}\\
 \operatorname{time}(G_A,F)&\le M^{r+o(1)},&
 \operatorname{space}(G_A,F)&\le M^{p+o(1)},            \tag{9}\\
 bK&\le h.                                               \tag{10}
\end{align}
All failed construction work is included in (9), and $G_A$ makes no
parent-scale call to $A$.  Then there is a uniform map
$\operatorname{Shrink}_A$ from ordinary CNF to ordinary 3-CNF such that
\begin{align}
 \SAT(\operatorname{Shrink}_A(F))&=\SAT(F),              \tag{11}\\
 |\operatorname{Shrink}_A(F)|&\le M^{h+o(1)},            \tag{12}\\
 \operatorname{time}(\operatorname{Shrink}_A,F)&
     \le M^{r+o(1)},                                    \tag{13}\\
 \operatorname{space}(\operatorname{Shrink}_A,F)&
     \le M^{h+o(1)}.                                    \tag{14}
\end{align}
No succinct-SAT oracle is used.
\end{theorem}

\begin{proof}
Generate $E_{A,F}$.  Construct one uniform circuit $C_{A,m}$ and connect its
$m$ input terminals to the $m$ outputs of $E_{A,F}$.  Leave the selector bits
existentially free, constrain the output of $C_{A,m}$ to one, and materialize
the entire composed circuit by the Tseitin transformation.  By (7) and
correctness of $A$, the resulting CNF satisfies (11).  Its circuit and CNF
size is
\[
 O\bigl(|E_{A,F}|+|C_{A,m}|\bigr)
 =M^{\max\{h,bK\}+o(1)}=M^{h+o(1)}.
\]
The constructor time is the maximum of the charged generator work and the
linear output/unrolling work, which is (13).  Variable indices and circuit
wiring add only logarithmic factors already absorbed by $o(1)$.  Streamed gate generation plus
one materialized output formula uses the maximum of $M^p$ and $M^h$ live
bits, proving (14).  The output is the explicit Tseitin 3-CNF itself, not a
pointer to $E$ or to the computation of $A$.
\end{proof}

The theorem has status \PROVED as an implication from its displayed
hypotheses.  The existence of $G_A$ is \OPEN.

\section{Finite reapplication and the Williams landing point}

The same fixed map $\operatorname{Shrink}_A$ applies to every ordinary CNF it
produces.  It need not be rebuilt from the code of a successor machine.  For a
fixed integer $d$, define
\[
 F_0=F,\qquad F_{j+1}=\operatorname{Shrink}_A(F_j),
 \qquad B_d(F)=A(F_d).
\]
Finite composition preserves uniformity.  From (12)--(14),
\begin{align}
 |F_j|&\le M^{h^j+o(1)},                                 \tag{15}\\
 T_{B_d}(M)&\le M^{\max\{r,h^dK\}+o(1)},                \tag{16}\\
 S_{B_d}(M)&\le M^{\max\{h,p,h^d\sigma\}+o(1)}.        \tag{17}
\end{align}
The geometric sum of construction times is dominated by the first level.  A
depth-first implementation retains at most the first generated formula plus
smaller descendants, so the generated-input storage is $M^{h+o(1)}$; the
original source remains on its ordinary read-only input tape.

\begin{conditionalbox}
\textbf{FINAL-LINK2 conditional landing.}
Set
\[
 h=\frac23,\qquad r=1,\qquad p\le\frac23,
 \qquad b=\frac{1}{3K}.
\]
Then $bK=1/3<h$.  Select the fixed composition depth $d$ large enough that
$(2/3)^dK\le1$ and $(2/3)^d\sigma\le2/3$.  Equations (16)--(17) give
\[
 (t,s)=\left(1,\frac23\right),\qquad
 t+s=\frac53<2\cos(\pi/7)=1.8019\ldots.
\]
Subject to the already stated endpoint encoding and machine-model transport,
the generated-cover premise would therefore contradict the Williams
time-space lower bound.  This implication is \COND; the premise is \OPEN.
\end{conditionalbox}

The constants $K,\sigma,b,d$ are fixed once with $A$.  They are not input
advice.  A proof from the mere source string of an arbitrary program would
need an effective resource certificate, but the classical contradiction
argument may choose a clocked version of the assumed polynomial machine with
hardwired certified constants.

\section{Why computation-tableau slicing does not instantiate the premise}

Suppose an explicit tableau for $A(F)$ has $T=M^{K+o(1)}$ materialized local
cells.  Split it into children of size $M^{b+o(1)}$, $0<b<1$.  Even before
charging boundary configurations, there are
\[
 q=M^{K-b+o(1)}
\]
pieces.  Treating those pieces as recursive children yields time fixed point
\begin{equation}
 C_{\rm slice}=\frac{K-b}{1-b},
 \qquad
 C_{\rm slice}-K=\frac{b(K-1)}{1-b}\ge0.                \tag{18}
\end{equation}
Thus explicit partitioning cannot remove $K$ and is strictly worse for
$K>1$.  This is \PROVED for the declared materializing construction.  It is
not a lower bound against a nonmaterializing semantic shortcut.

The same point appears at a cut.  Let $L_F(c)$ mean that boundary
configuration $c$ is reachable from the start, and let $R(c)$ mean that an
accepting suffix begins at $c$.  The correct join is
\begin{equation}
 \exists c\,[L_F(c)\wedge R(c)].                         \tag{19}
\end{equation}
Replacing (19) by $\SAT(L_F)\wedge\SAT(R)$ is invalid: for a one-bit boundary,
$L=\{0\}$ and $R=\{1\}$ are both nonempty but disjoint.  Determinism makes the
reachable boundary unique, but then an exact separated implementation must
acquire that unique configuration or retain the shared existential interface.
Keeping the interface in one materialized formula recreates the join; merely
solving the halves independently loses it.  No claim is made that these are
the only possible representations.

Standard bitwise search-to-decision has a separate scale problem.  Fixing one
variable often leaves an explicitly encoded residual of length
$M-O(1)$, so the early calls are parent-scale.  Shared source pointers change
the recursive language unless their decoder and access cost are included.
This rejects the standard schedule, not every possible machine-specific batch
search.

\section{Hostile controls and barrier audit}

\begin{itemize}
\item[] \textbf{Every recursive source.}  The generator hypothesis is
universal over ordinary CNFs, including every Tseitin formula $F_j$ produced
by the previous level.  A promise only for the original benchmark family does
not justify (15).
\item[] \textbf{Uniformity.}  The algorithm contains one fixed $A$, one fixed
constructor $G_A$, and one fixed depth $d$.  Per-length externally supplied
generators are prohibited.  The generated circuit description is produced
and charged on the current input.
\item[] \textbf{No hidden parent call.}  The construction unrolls $A$ only on
an $m=M^b$-bit child.  Calling $A(F)$ first and then emitting a constant child
would satisfy the size condition but violates (9) and the no-parent-call
condition.
\item[] \textbf{Ordinary SAT return.}  All gates of $E_{A,F}$ and $C_{A,m}$
are expanded into the returned Tseitin 3-CNF.  The successor does not receive
oracle access to $F$, $E$, a bitstream, or a succinct computation.
\item[] \textbf{Description accounting.}  Circuit size includes outputs,
embedded constants, and wiring.  A nominally small circuit with $M$ uncounted
source constants has size at least $M$ in this model.
\item[] \textbf{SAT/UNSAT symmetry.}  Equation (7) is an exact OR cover, so a
SAT child proves SAT and the absence of every accepting selector proves UNSAT
through the materialized circuit.  No successful-route predictor is assumed.
\item[] \textbf{Easy families.}  Horn, 2-CNF, affine, bounded-treewidth, and
component formulas may admit direct zero-child or compact generators.  Their
success does not prove the all-CNF premise.  Conversely, transparent DELAY
code may be statically skipped, so delay examples do not establish a general
lower bound.
\item[] \textbf{Randomness and hashes.}  Random selector hashing may reduce a
witness set, but without deterministic exact coverage it cannot replace (7).
Execution hashes and prime labels refine histories rather than construct the
sublinear multi-output circuit.
\item[] \textbf{Relativization.}  Multiplexing, circuitization, and Tseitin
encoding relativize in their natural forms.  Since relativized worlds can
separate the relevant hypotheses and conclusions, the proof of the universal
generator premise would have to contain the nonrelativizing hinge.
\item[] \textbf{Algebrization and Natural Proofs.}  No algebraic extension or
large constructive circuit property is used here.  The missing generator is
not supplied by an algebraic analogy, and no Natural-Proofs conclusion is
claimed.
\end{itemize}

Ladner's P-completeness result for Circuit Value calibrates why a generic
``skip to the next observable event'' transformation cannot be treated as a
routine parallel shortcut \cite{ladner1975}.  It supplies no unconditional
fine-grained lower bound, especially after fixing one machine.  Cook's
computation-to-SAT paradigm and the Pippenger--Fischer simulation support the
explicit encodings used above, not a claim that every encoding must have the
same size \cite{cook1971,pippengerfischer1979}.

\section{Sharpened next theorem}

The new final link is no longer the vague request ``find a shared $H$.''  It
is the following source-checkable statement.

\begin{openstatusbox}
\textbf{GENERATED-COVER-$2/3$ (OPEN).}
Under $P=NP$, select a clocked uniform exact SAT decider $A$ with certified
time exponent $K$.  Put $b=1/(3K)$.  Construct one fixed uniform algorithm
$G_A$ which, for every $M$-bit ordinary CNF $F$, in $M^{1+o(1)}$ time and
$M^{2/3+o(1)}$ space, without executing $A$ on an $M^{1-o(1)}$ input, emits a
multi-output circuit $E_{A,F}$ of size $M^{2/3+o(1)}$.  On selector $z$, the
circuit must output a complete ordinary CNF encoding of at most
$M^{b+o(1)}$ bits, and
\[
 \SAT(F)\iff\exists z\;\SAT(E_{A,F}(z)).
\]
The same guarantee must hold when $F$ is a Tseitin successor produced by this
construction.
\end{openstatusbox}

If this theorem is proved, OR-MUX-COMPILE1 materializes the required ordinary
successor, finite reapplication removes the unknown $K$ and $\sigma$, and the
verified endpoint yields the contradiction.  If it is falsified in an exact
restricted model, the counterexample will identify whether the obstruction is
source-description size, generator acquisition, recursive closure, or
workspace.  Hash-length changes do not alter any of these four obligations.

Williams' representation-specific self-improvement is the closest positive
precedent, but it does not supply GENERATED-COVER-$2/3$ in the polynomial SAT
regime \cite{williams2024}.  Dell--van Melkebeek remains useful calibration for
multi-query sparsification; its standard collapse consequence does not refute
the present contradiction-hypothesis setting and it does not construct the
generator \cite{dellvanmelkebeek2014}.

\section{Reproducibility and limitations}

All experiments are deterministic after seed $20261008$.  They use toy
bounded-fan-in circuits and terminating transition DAGs.  They verify Boolean
