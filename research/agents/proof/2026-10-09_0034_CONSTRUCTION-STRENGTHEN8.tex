\section{Exact guard decoding without a same-size buffer}
For a proper 3CNF $F$ with attained source maximum $q$ and $m\ge1$ clause
occurrences, ARC5 defines
\begin{equation}
\begin{split}
G(F)=F&\wedge(h\vee\neg r)\wedge(\neg h\vee r)\\
&\wedge\bigwedge_{v=1}^{q}P_0(h,v,q+2+v)
 \wedge\bigwedge_{j=1}^{m}P_0(h,2q+2j+1,2q+2j+2),
\end{split}
\tag{1}
\end{equation}
with $h=q+1,r=q+2$ and fixed-order four-clause even-parity block $P_0$.
Its header and clause count are
\begin{equation}
 q_G=2q+2m+2,\qquad c_G=5m+4q+2.                         \tag{2}
\end{equation}
Conversely, (2) determines
\begin{equation}
 L=(q_G-2)/2,\qquad m=c_G-4L-2,qquad q=L-m.              \tag{3}
\end{equation}
The recognizer rejects unless these are positive integers, the first $m$
records are proper clauses on $[q]$ attaining $q$, and every remaining
record is exactly the ordered suffix in (1).  One sequential source scan,
polylogarithmic counters, and no SAT call suffice.

After recognition, the virtual encoding of $F$ is not materialized.  Its
header bytes are synthesized from $(q,m)$.  Every later body bit maps by one
offset translation to the contiguous first-$m$-record body already present
in the read-only parent.  Thus adaptive repeated input reads cost
$N^{o(1)}$ time and $O(\log N)$ scratch each.  This detail is essential: a
fresh $\Theta(N)$ buffer would violate the half-power space target, whereas
rescanning the parent for each bit would violate the saturated time ledger.

\begin{lemma}[alias composition]\label{lem:alias}
Let $T$ recognize an input $X$ of length $N$ and expose a read-only virtual
ordinary-SAT input $F$ with $|F|\le N$ using $N^{1+o(1)}$ total recognition
time, $N^{o(1)}$ workspace and $N^{o(1)}$ overhead per adaptive bit access.
Let a fixed source-first partial member $M$ on $F$ have local time
$|F|^{r+o(1)}$, peak state $|F|^{p+o(1)}$, maximum child
$|F|^{h+o(1)}$ and executed aggregate child volume $|F|^{v+o(1)}$.
Then the flattened phase $M\circ T$, with every dry run and replay performed
through the alias, has on accepted $X$ the ledger
\begin{equation}
 r'=\max\{1,r\},\qquad p'=p,qquad h'=h,qquad v'=v.       \tag{4}
\end{equation}
It has no semantic call on the same-scale internal edge.
\end{lemma}
\begin{proof}
Replace every input read of $M$ by $T$'s accessor.  The multiplicative
polylogarithmic overhead is absorbed into $o(1)$.  No virtual source buffer
is retained, so only the accessor scratch is added to $M$'s state.  Since
$|F|\le N$, all four bounds relative to $F$ imply (4) relative to $N$.
Correctness and executed multiplicity are unchanged.  The internal type edge
is acyclic and is flattened before recursion; only $M$'s explicit ordinary
children form the completed phase boundary.
\end{proof}

\section{The completed double-WRAPPER}
\textsc{GUARD-STRIP-PIVOT2} first performs the exact recognizer above.  If it
fails, the member returns UNKNOWN before any SAT call.  If it succeeds, it
runs the complete charged dry run of \textsc{PIVOT-FACTOR1} on the aliased
$F$.  Only if that member accepts does it replay the accepted pivot,
materialize one component child at a time, execute every occurrence, and AND
the answers.  Otherwise it returns UNKNOWN with zero child calls.

\begin{theorem}[actual two-stage PRE-A phase]\label{thm:phase}
There is one uniform implementation such that every input is source-validated
before any semantic call and every accepted input has
\begin{equation}
 T_{\rm local}(N)\le N^{6/5+o(1)},\quad
 \max_i|Q_i|\le N^{1/2+o(1)},\quad
 \sum_i|Q_i|\le N^{11/10+o(1)},\quad
 S_{\rm peak}(N)\le N^{1/2+o(1)}.                         \tag{5}
\end{equation}
Moreover
\begin{equation}
 \SAT(G(F))=\SAT(F)=\bigwedge_i\SAT(Q_i).                 \tag{6}
\end{equation}
Discovery, rejected parsing, the failed/accepted pivot scans, raw resolution
pairs, component finding, byte dry runs, replay, headers, indices, buffers
and executed duplicates are included.
\end{theorem}
\begin{proof}
ARC5 proves the first equality in (6); Davis--Putnam projection and component
independence prove the second.  The guard accessor meets Lemma~\ref{lem:alias}.
Apply that lemma to the already verified
$(r,v,h,p)=(6/5,11/10,1/2,1/2)$ PIVOT member.  All decisions before the child
boundary are syntactic or follow from the fixed projection identity; no
parent-scale SAT answer or assumed polynomial SAT decider is consulted.
\end{proof}

This is a genuine use of a same-scale inner edge: $|F|=\Theta(|G(F)|)$ is
allowed inside the phase, while the ordinary recursive return boundary in
(5) contracts.  It is not a scale-one cycle and cannot be iterated by
alternating guard creation and removal.

\paragraph{Infinite nonvacuous domain.}
For $s\ge1$, take source variable $x=1$ and four fresh variables
$a_i,b_i,c_i,d_i$ per block.  Include
\begin{equation}
 (x\vee a_i\vee b_i),\quad
 (\neg a_i\vee b_i\vee\pm c_i),\quad
 (a_i\vee\neg b_i\vee\pm d_i).                           \tag{7}
\end{equation}
These are five proper clauses per block.  The source is connected through
$x$.  Eliminating the pure-positive $x$ removes the first clause of every
block and leaves $s$ variable-disjoint four-clause components.  Hence
PIVOT accepts all sufficiently large sources in (7), and the new completed
phase accepts every corresponding $G(F_s)$.  This guarded family was outside
the old PIVOT member itself, so the composition strictly enlarges the
concrete source-first portfolio.

\section{Exact mixed-core noncoverage}
The construction does not approach all-input coverage.  Let
\begin{equation}
 X_s=\bigwedge_{i=1}^s(x\vee a_i)\wedge
     \bigwedge_{j=1}^s(\neg x\vee b_j),                  \tag{8}
\end{equation}
and make the proper lift $T_s$ by replacing each binary clause $C$ with
$(C\vee z_C)\wedge(C\vee\neg z_C)$ using a private variable.  Then
$q(T_s)=4s+1$ and $T_s$ has $4s$ proper clauses.  Set $Y_s=G(T_s)$.

\begin{theorem}[mixed affine/non-affine residual]\label{thm:miss}
For all sufficiently large $s$, \textsc{GUARD-STRIP-PIVOT2} returns UNKNOWN
on $Y_s$ with zero SAT calls.  A pure semantic affine solver also cannot
decide the residual as an affine relation.  Removing the affine guard exposes
one child of size $|Y_s|^{1-o(1)}$, which fails every fixed $h<1$ cap.
\end{theorem}
\begin{proof}
The guard parser returns exactly $T_s$.  Eliminating $x$ produces the complete
cross-product of positive and negative lifted clauses, a connected
$\Omega(s^2)$ residual.  Eliminating any $a_i,b_j$ or private lift variable
leaves a connected formula with $4s-O(1)$ clauses and complete encoded size
$|T_s|-O(\log s)$.  Thus every PIVOT exceeds the square-root maximum-child
cap when $s$ is large.

The model set of (8) is not affine.  Restricted to $(x,a_1,b_1)$, the three
models $(1,0,1),(1,1,1),(0,1,0)$ have ternary XOR $(0,0,0)$, which violates
$x\vee a_1$.  Affine relations are closed under ternary XOR and under
projection.  Since $T_s$ projects to $X_s$ and $Y_s$ projects to $T_s$,
neither is affine.  Finally the guard adds only a linear number of
constant-width records, so $|T_s|=\Theta(|Y_s|)=|Y_s|^{1-o(1)}$.  Shell
stripping is therefore only the internal scale-one edge, not a completed
contracting boundary.
\end{proof}

This control is stronger than a syntactic XOR-parser failure.  Even perfect
Gaussian removal of the recognizable parity shell leaves an arbitrary
near-parent non-affine core.  Native CNF+XOR systems in the literature use
Gaussian reasoning as a module beside a CNF master, not as an all-input
contraction theorem.

\section{Literature and the closest alternate route}
E\'en--Biere bounded variable elimination is the exact source operation used
by PIVOT, but is deliberately applied only under a growth bound; it supplies
no universal favorable trace
(DOI \href{https://doi.org/10.1007/11499107_5}{10.1007/11499107\_5}).
Laitinen--Junttila--Niemel\"a treat parity reasoning as a separate module for
mixed CNF/XOR solving, consistent with Theorem~\ref{thm:miss}
(\url{https://arxiv.org/abs/1207.0988}).

The closest implication from SAT in P is a P-selector applied to SAT's exact
disjunctive self-reduction
$F\equiv F[x=0]\vee F[x=1]$.  It can keep one satisfiability-preserving child,
but the known selector is obtained by solving near-parent children.  Its cost
therefore retains the unknown exponent $K$; reaching $N^h$ by repeated
selection is not a PRE-A improvement.  Ordinary instance compression is
also causally too weak: under SAT in P one may decide the parent and output a
fixed YES/NO formula, exactly the endpoint-equivalent move PRE-A forbids.
Fortnow--Santhanam/Drucker compression and Dell--van Melkebeek sparsification
barriers have collapse hypotheses that already hold in a P=NP world and do
not supply the missing compiler.  These are warnings, not theorem transfers.
