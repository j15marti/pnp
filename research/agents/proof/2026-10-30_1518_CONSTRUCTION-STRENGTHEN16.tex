\section{A concrete local-pair compiler}
Let $F$ be a nonempty ordered list of $m$ proper 3-clauses
$C_j=(a_j,b_j,c_j)$ on densely encoded active variables; repetitions are allowed.
For each $j$, use selector $s$ and private $y_j,z_j$ to form
\[
(s,a_j,y_j),\quad(-y_j,b_j,c_j),\quad
(-s,-a_j,z_j),\quad(-z_j,-b_j,-c_j).
\]
Each of its six underlying variables has one positive and one negative
occurrence inside this block. Duplicate each block, keeping duplicates adjacent.
Assign clone IDs
\[
 \operatorname{cid}(j,d,k)=12j+6d+k+1,\qquad
 d\in\{0,1\},\quad k\in\{0,\ldots,5\},
\]
where kinds are $(s,a,b,c,y,z)$. Each clone replaces its two local
opposite occurrences, preserving the original literal sign.
There is no global positive/negative occurrence rank or pairing lookup.

For every clone in copy 0, its equality-cycle successor is copy 1 of the
same kind and source clause. From copy 1, selector successors go to the
next clause's copy-0 selector cyclically; private $y,z$ return to their
same-clause copy-0 clone. A source-variable occurrence goes to the
copy-0 clone of that variable's next source occurrence in cyclic
clause-slot order. This defines one directed cycle for each original variable.
All cycles have length at least two because of duplication.

There are $R=12m$ clones and $R$ implications.
Group consecutive implications in triples. For each triple append a fresh
copy of $Q$, the 15-variable, 19-clause gadget from the recovered source;
its ports $(1,7,13)$ are forced zero, each missing one positive occurrence.
Pad each implication $(-u,v)$ with one corresponding positive port.
The gadget's remaining variables already have degree $(2,2)$.
The output has $72m$ variables and $96m$ clauses.

\paragraph{Correctness argument.}
The zero ports enforce every cycle implication, hence equality around
each entire cycle. A clone has one positive and one negative source
occurrence and one of each cycle occurrence, giving exact $(2,2)$.
All clauses are proper. Distinct local blocks use private clone IDs;
implication clauses have distinct tails and distinct gadget ports;
gadget copies are private, so clauses are distinct.
With $s=0$, existential elimination of $y_j,z_j$ leaves $C_j$.
With $s=1$ it leaves the clause on the three complemented source literals.
Thus existentially the selector construction is satisfiable iff $F$ is:
a satisfying complemented branch can be globally complemented to satisfy $F$.
Any satisfying selector assignment lifts to all clones and the all-zero
model of Q. Conversely, every target model projects through its single
cycles to a selector model. SAT, not model count, is preserved.
The finite Q truth-table certificate is a fixed dependency, checked anew.

\section{Three exact access implementations}
The tested serialization is Elias-gamma headers for $(V,M)$ followed by
$3M$ sign-plus-fixed-width-identifier records with
$w=\lceil\log_2(V+1)\rceil$. Its length is $\Theta(m\log(m+2))$.
Every output bit can be classified arithmetically.
Source-block literals require at most one source literal read;
private and selector successors and every gadget literal are arithmetic.
Only source-variable copy-1 cycle successors need occurrence lookup.

\paragraph{Materialized.}
An independent grouping implementation writes the complete target bit string.
Its storage is exactly the output length in this encoding, apart from
builder state. Treating that derived string as uncharged read-only input
would violate the same-realization ledger.

\paragraph{Rescanning.}
Keep the source occurrence and current position in counters. Scan cyclically
until the next equal underlying source variable is found. Each request uses
$O(\log N)$ scratch bits and at most $3m$ source-record comparisons.
The constant number of $O(\log N)$-bit arithmetic operands and fixed Q table
give $O(N\operatorname{polylog}N)$ time per output-bit request, with no
retained index. The Python prototype stores its test source and audit outputs;
the logarithmic-workspace claim is for this explicit counter algorithm,
not Python's physical memory footprint.

\paragraph{Supplied successor links.}
If the immutable source representation also supplies the correct successor
slot for each original occurrence, the same routine answers every output
bit in $\operatorname{polylog}N$ time and $O(\log N)$ scratch space.
No bounded-occurrence hypothesis is needed. The index has
$3m\lceil\log_2(3m)\rceil$ bits up to the usual power-of-two coding choice.
If constructed or retained by the solver, it is charged writable memory.
It is free input only for the explicit promised augmented representation.
Checking links by comparison with rescanning costs quadratic record work
in this direct verifier. A fast small-space ordinary-source construction
or validation is not established.

\section{A semantic hostile control for supplied links}
Correct labels and permutation degree do not suffice.
The source consisting of all eight signed clauses on three variables is
UNSAT. Give each of its 24 source occurrences a self-successor.
The compiled target then separates every source occurrence into its own

literal to true, with $y=z=0$ and all gadget variables zero.
This is a verified SAT assignment to the malformed target.
Every link preserves its variable label, yet the links form multiple cycles.
Therefore the promise must require one cycle containing all occurrences
of each variable, or a fully charged equivalent certificate.
The malformed-index example falsifies silent trust in a merely local index.

\section{Consequence for the subpolynomial-space target}
Suppose a target exact22 solver uses time $M^{c+o(1)}$ and
space $M^{s+o(1)}$. Since $M=N^{1+o(1)}$, supplied valid links let the
virtual compiler preserve these exponents, with logarithmic added scratch.
The rescanning implementation instead gives the conservative certificate
$T\le N^{c+1+o(1)}$, while keeping added space logarithmic.
Materialization charges $\Theta(M)$ writable bits.
These bounds do not exclude a better ordinary-source accessor.

Even perfect access does not reduce the solver's own workspace:
\[
 S_{\rm composed}=O(S_A(M)+\log N)
\]
under the supplied-link interface, plus any separately retained source index.
Thus $P=NP$ does not imply $S=N^{o(1)}$, and this compiler is not an
exponent-contraction wrapper. FLMV's $c<\varphi$ and subpolynomial-space
endpoint remains a contradiction target, not an achieved algorithm.
Conditional $K$ elimination, aggregate child volume and paid failed attempts
remain unchanged. No oracle answers or cross-machine resource borrowing occur.
This syntactic reduction is not a new nonrelativizing or nonalgebrizing
argument; no Natural Proofs circuit property is claimed.
Memory-indexing is an engineering analogy only until acquisition is charged.
