# THRES-AUTOMATICSECTION15 | 2026-10-19 01:02 KST

Status: scoped theorem pending independent review. P versus NP OPEN.

Let N=2^n. A deterministic Q-state one-way source transducer uses a clock value c(i) generated by an A-state DFA reading the binary address i. If the transducer emits at most B bits on source f, then the same output has a source preimage g with Boolean circuit size at most poly(n,log(AQ+2)) (A Q^2+B+1).

Proof: For silent transitions define Boolean reachability matrices M[k,a], indexed by dyadic block height k and clock state a. They satisfy M[k+1,a]=M[k,delta(a,0)] o M[k,delta(a,1)]. Preserve at most B emitting transitions of f, partition silent gaps into O(Bn+n) dyadic blocks, and substitute their canonical feasible paths using these matrices. A source-bit circuit decodes any position via at most n midpoint selections and O(Bn+n) hardwired interval records.

If the source MCSP YES threshold exceeds the circuit bound, every NO output collides with some YES output, so this class of deterministic semantic quotients fails exact two-sided promise preservation. A fixed finite family of independent public seeds admits an analogous product-DFA and product-transducer section matching all seeds simultaneously.

Finite audit: 112 machine families; 2,016 source inputs; 8,873 matrix tests; 2,022 output comparisons; 448 simultaneous two-seed reconstructions; 896 per-seed equalities; zero failures. Full local report and executable preserved in THRES_AUTOMATICSECTION15_2026-10-19.zip.

This is NOT a one-tape runtime lower bound, and no threshold/slope descent map has been proved. CHMY source bound remains model-specific. Next investigate full-sweep stateful generators with clock semantics outside small automatic sequences.
