\section*{New sharp theorem: fixed redundant additive ports}
Let $r\ge 2$, $h=r-1$, and independently sampled bit-vector masks $T_1,\ldots,T_h$. Fix a nonempty, \emph{seed-independent} set $J\subseteq\{1,\ldots,h\}$. Modify each selected additive term by $D_j\mapsto D_j\oplus f$ for the same arbitrary $N$-bit source $f$; leave the other seeds, including the initial state, unchanged. Define $j_*=\max J$, $t=h-j_*$ and
\[
 B_j=\bigwedge_{i=j+1}^{h}T_i,\qquad
 Q_J=\bigoplus_{j\in J} B_j
\]
(pointwise; an empty product is the all-ones vector). If for each coordinate $a$ and layer $i$ its one-bit marginal $p_{i,a}=\Pr[T_i(a)=1]$ lies in $[1/2-\gamma,1/2+\gamma]$ with $0\le\gamma<1/2$, then for every $f$, every coordinate $a$,
\begin{equation}
\label{eq:exposure}
(1/2-\gamma)^{t+1}
\le \Pr[Q_J(a)=1]
\le (1/2+\gamma)^t.
\end{equation}
For exactly unbiased masks,
\[
\boxed{\,2^{-(t+1)}\le\Pr[Q_J(a)=1]\le2^{-t}\,}.
\]
Both bounds are attained: a single latest port attains the upper bound, and two adjacent ports $J=\{j_*-1,j_*\}$ ($j_*\ge2$) attain the lower bound. When $\gamma=o(1/r)$, the ratio to $2^{-t}$ belongs to $[1/2-o(1),1+o(1)]$, uniformly across all fixed port sets.

\begin{proof}
Linearity of the XOR/AND recursion in the source difference gives
$G_{h+1}^{(J)}=G_{h+1}^{(0)}\oplus (Q_J\wedge f)$, exactly for every full seed. Every earlier $B_j$, $j<j_*$, has the factor $B_{j_*}\wedge T_{j_*}$; hence $Q_J=B_{j_*}\wedge(1\oplus(T_{j_*}\wedge R))$ for some Boolean function $R$ of the earlier layer-mask bits. Therefore $Q_J(a)=1$ implies $B_{j_*}(a)=1$, proving the upper bound using independence \emph{across} layers. Conversely the event $B_{j_*}(a)=1$ and $T_{j_*}(a)=0$ forces $Q_J(a)=1$ regardless of $R$. By independence across layers this event has probability at least $(1/2-\gamma)^{t+1}$. The sharp unbiased cases follow directly. No assumption of coordinate-wise independence \emph{within} a layer is required. QED.
\end{proof}

\noindent\textbf{Consequence (PROVED/EXACT, narrow).} Repeating the same source in any fixed set of independent-mask additive slots cannot obtain an extra \emph{exponential-in-layer-count} source-erasure improvement over the latest slot by XOR cancellation. This does NOT prove the source or target MCSP label, exact error, threshold, source sweep, output serialization, or one-tape simulator cost, and it does NOT close the beta-width critical band from the 00:59 report. It only retires the \emph{redundant-port cancellation as exponent-improvement mechanism} under the stated conditions.

\section*{COMPACT-HISTORY20: explicit affine trajectory falsifier}
For an explicitly supplied $d$-bit affine transition $F(v)=Av\oplus b$ over $\mathbb F_2$, form the $(d+1)\times(d+1)$ homogeneous matrix
\[
 H=\begin{pmatrix}A&b\\0&1\end{pmatrix}.
\]
Compute $H^{2^j}$ by repeated squaring for $0\le j<\lceil\log_2(t+1)\rceil$. On input binary index $i$, multiply $H^{2^j}$ into the state when bit $i_j=1$. This constructs a \emph{uniform standard-model} indexed-trajectory circuit with $O((d+1)^3\log(t+1))$ fixed-fan-in Boolean gates (a coarse safe bound), accepting explicit $(A,b,v,i)$ as inputs. It yields the exact $F^i(v)$ even when $i$ is exponentially larger than $d$. Thus the value-oracle exact $t$-query lower bound is not a proof of work for explicit affine transitions. \textbf{OPEN:} whether actual succinct diagonal clock transitions admit, or force, a sufficiently compact satisfying-assignment history circuit. The existential common-history quantifier $\exists W\forall i$ cannot be replaced by $\forall i\exists W_i$.
