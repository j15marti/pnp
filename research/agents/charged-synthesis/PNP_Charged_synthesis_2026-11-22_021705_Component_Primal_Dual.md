## Fixed solver, input and theorem

Fix one deterministic machine A before choosing the input. A has a finite alphabet, finite control and one writable tape with one head moving at most one cell per transition. Input, retained source, indexes, workspace, copies, caches and fixed-origin terminated output share this tape. Physical storage means charged occupied span, including retained input. There is no online arrival restriction or mandated clause-processing order.

An admitted source consists of homogeneous parity equations on three distinct variables and pairwise-disjoint unsigned exact-one triples. A parity equation is compiled into its four forbidden Boolean rows; an exact-one constraint into its five forbidden rows. Let c be the number of proper source clauses and d the number of occurring source names; d<=3c. A uses the existing canonical adjacent-witness compiler, not an assumed layout-preserving rewrite:
r=max(3,2 floor((c+1)/2)+1),
n0=d+(10c+1)r+2, m0=(20c+4)r,
n=n0+m0+3, m=2m0+4, w=ceil(log2(n+1)).
The physical input comprises unary n and a delimiter, gamma(m+1), m ordered signed width-w literal triples, two n-bit assignments and the w-bit release identifier. Its exact length is
N=3n+2+2 floor(log2(m+1))+3m(w+1)+w=Theta(c² log(c+1)).

A parses, extracts the candidate source, regenerates the complete canonical image and compares every field, including supplied witnesses and identifiers. It checks exact relation tables and factor disjointness. The inherited authentication tariff is O(N³) time and O(N) span; no hash equality substitutes for comparison. These compiler semantics and the authentication implementation specification are inherited from the pinned Construction report. The new proof below concerns composition after this verified admission step. Invalid encodings are rejected; failure of admission on a valid input invokes exhaustive decision of the retained original formula, not UNSAT. The fallback is at most O(2^n N³) time and O(N) span. Thus A is a total, all-input-correct SAT solver under this encoding, although the useful runtime theorem concerns its admitted path.

On an admitted source perform the following deterministic preprocessing. Repeatedly choose the smallest-numbered variable which belongs to no exact-one factor and occurs in exactly one current parity equation. Delete that equation and variable. Then compute connected components of the residual constraint-variable incidence graph. Remove isolated variables and parity-only components. For each remaining component i, let P_i be its factor ports, p_i=|P_i|, and let V_i be the projection to P_i of the nullspace of all its parity equations. Compute
s_i=dim V_i, k_i=p_i-s_i.
Define R=max_i min(s_i,k_i), with R=0 if no factor components remain, and M=2^R. These parameters are computed, not supplied as advice.

**Claim.** For every admitted input, A correctly decides its Boolean label by selecting primal Gray evaluation when s_i<=k_i and dual syndrome evaluation otherwise, separately for each component. There is one execution with
Q=O((c+1)^4(1+M)), L=O(N+M),
T=O(N³+Q L²), S=O(L),
CM_phys=O(TL), and CM_min=O(T(N+log(T+2)))=O(TN).
For every fixed real constant C>=0, the restriction to admitted inputs satisfying R<=C log2 N is polynomial time in the total encoded length. The same fixed A works for all C; C is only an analysis parameter. No statement here bounds R by O(log N) on all admitted sources.

## Proof of semantics and paid composition

If x occurs in exactly one parity equation x XOR f(y)=0 and in no factor, every assignment to the other variables has exactly one extending x satisfying this equation. Therefore existentially quantifying x deletes precisely that equation and leaves all remaining constraints unchanged. This is an exact Boolean projection even when the other variables occur elsewhere. No table of all assignments is built. Repeating the rule terminates after at most d eliminations. It is invalid to apply this rule to a variable participating in an exact-one factor.

Residual graph components have disjoint variable sets and every constraint lies within one component. Consequently the full residual formula is satisfiable exactly when every component is satisfiable. A homogeneous parity-only component admits the all-zero assignment. Isolated variables impose no decision obligation. This is a source-level equivalence; A need not materialize a newly compiled target image after each deletion.

In component i, Gaussian elimination gives a nullspace basis. Project it onto P_i and row-reduce again to get an independent basis of V_i. Deleting internal columns of the equation matrix would not accomplish this projection. A factor assignment extends to a satisfying assignment of the parity constraints if and only if it belongs to V_i.

For the primal branch, enumerate all 2^s_i coefficient vectors in reflected Gray order. Start at the zero port vector. The transition changes one coefficient, so XOR the corresponding independent basis row into the current port vector; test all factor triples. This visits V_i exactly once and accepts exactly when a visited vector satisfies every exact-one factor.

For the dual branch, compute a full annihilator matrix H_i with k_i independent rows and ker H_i=V_i. An exact-one choice selects one column of H_i from each triple. Initialize the reachable syndrome set to {0}; replace it for each factor by the union of the three XOR translates obtained from that factor's columns. The induction invariant is the set of all sums from exactly one column in each processed factor. Membership of zero after the last factor is equivalent to an exact-one vector in V_i. Two histories with the same syndrome have exactly the same possible suffix syndromes; their merge is a semantic equivalence. Clear the new table before writing each layer.

Both algorithms decide SAT and UNSAT, including s_i=0, k_i=0 and the empty factor family. Computing both dimensions before selecting a branch incurs only polynomial preprocessing. A executes only the selected exponential branch per component. It reuses workspace sequentially, conjoins the answers and may stop on the first UNSAT answer. No unspecified solver race, repeated residual service or free oracle is involved.

## One-execution ledger

Parsing and authentication include all attempted candidates, failed admission and full comparison. Retain the input throughout. The source has O(c) names/constraints and a dense matrix uses O(c²) bits; indexed records with O(log(c+1))-bit names fit O(c² log(c+1))=O(N) cells. Complete rescans for the leaf rule, including failed candidates, exact component discovery, three linear-algebra reductions per component, address construction and branch choice fit the deliberately loose polynomial part of Q. Summing component cubic matrix work is no greater than a cubic bound on their total sizes; a fourth-power allowance covers identifier/counter bit work and simple rescan implementations.

For primal components, a visit requires polynomially many bit operations in c, including the Gray counter, basis access and factor checks. For dual components, two M_i=2^k_i tables suffice, with counters of k_i+1 bits, clearing, exact XOR addressing, testing each old entry and setting the three corresponding new entries. The bound O((t_i+1)M_i(k_i+1)^2) from Discovery applies. In the selected branch every enumerated set or table has size at most M. Summing over at most O(c) components is dominated by Q above. This intentionally sacrifices tight exponents to make counter, metadata, discovery and sharing costs explicit.

Only a constant number of size-M bit tables is live. Save the small component descriptions and current answers within O(N) polynomial scratch and reuse table cells, charging clearing. Hence L=O(N+M). A bounded indexed bit access can be implemented on this single tape by explicit cursor/counter movement in O(L²) transitions, as in Discovery's unary address-marking implementation. Every address is bounded by O(L); no random access at unit cost is assumed. Q counts individual bit operations and counter/address work. Initialization, table writes, retained storage, relocation, recomputation of addresses, mode switches, clearing and returning to the output origin are covered by N³+QL². There is no uncharged parallelism or output enumeration.

At every instant the span is O(L), giving CM_phys<=O(TL) on this same run, not a product of unrelated maxima. Independently the fixed machine, its original N-bit input and a self-delimiting step counter describe the current configuration, giving CM_min<=O(T(N+log(T+2))). Since R<=O(c), this explicit upper bound has log(T+2)=O(N), including exponentially large tables, so CM_min=O(TN). These two cumulative conventions must not be identified.

If R<=C log2 N, then M<=N^C. For example c<=O(N) yields the coarse fixed bounds T=O(N³+N^(4+C)(N+N^C)^2), S=O(N+N^C). Discovery, elimination, addresses and output are included. On inputs outside this condition the algorithm remains exact but this analysis gives an exponential bound. No polynomial bound for general SAT has been established.

## Consequences for the connected control and compulsory decoding

Redteam's connected extension has d=30J+1,c=96J,p=12J,s=11J,k=J. Its added equations x XOR g XOR a_x=0 have private leaves a_x absent from factors. The rule above eliminates every such leaf equation, leaving the old independent constant-size blocks and an isolated g. Each block has p_i=12,s_i=11,k_i=1, so R=1. A therefore decides the entire family in polynomial time even though its original source graph is connected and both global dimensions grow linearly. Redteam's tighter O(N^4) time/O(N) span/O(N^5) cumulative specialized bound is preserved; the coarse general bound here does not replace it.

This refutes the sufficiency of connectivity plus large global primal and dual dimensions as a proposed compulsory-work premise. It does not refute a statement about all coupled residuals, and it does not establish a uniform polynomial-time bound on the NP-complete admitted class.

Fix A and any finite distribution of same-length admitted inputs. After its charged computation A can retain just the Boolean answer at a fixed origin and enter READY. For the suffix choose U=D, the decision bit; B consists of the public solver, distribution and READY protocol, excluding sampled input, timing and cached answer. Let E contain the actual transition reading that answer; Pi is the one-bit symbol. The identity decoder is exact, both possible one-bit records are prefix-free, b=1, h=0 and rho=1. Thus H(D|B)<=E|Pi|=1<=E[T]. Earlier costs remain charged.

No component-answer vector is forced by this suffix observation. Bounds' fiber criterion gives the obstruction precisely: an exact decoder must be constant on each fiber of (B,Pi). An UNSAT cached answer may correspond to many distinct component vectors. Including the full retained answer or source in B can reduce the entropy to zero; assigning the same event to several obligations raises rho. This one-bit instantiation is not a lower bound exceeding any fixed polynomial cap, and the algorithm's voluntarily computed tables do not define compulsory obligations for every solver.

For any proposed fixed cap T<=K N^a, compare demand with b rho K N^a on the same encoding and execution. The internally reviewed permutation transport theorem remains single-tape only, with its quadratic-time/cubic-cumulative matching control and static ceilings. Strict T5 counting, symmetric C and ordered R are unchanged.
