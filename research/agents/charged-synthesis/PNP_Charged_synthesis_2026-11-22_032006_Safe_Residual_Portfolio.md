## Model, encoding and quantified claim

Fix one uniform deterministic SAT machine A, independent of the input and of the constants in the polynomial restrictions below. It uses one finite-alphabet writable tape and one head moving at most one cell per transition. Input, source copies, matrices, relation tables, indexes, caches, address scratch and terminated output at a fixed origin all share the charged tape. No online arrivals, compulsory clause order, prescribed evaluation DAG or uncharged access is imposed.

Admitted sources consist of homogeneous parity equations on three distinct Boolean names and pairwise-disjoint unsigned exact-one triples. Their canonical source CNF has four forbidden rows per parity equation and five per exact-one factor. Let c be its clause count and d<=3c its occurring names. Use the established compiler with
q=max(3,2 floor((c+1)/2)+1),
n0=d+(10c+1)q+2, m0=(20c+4)q,
n=n0+m0+3, m=2m0+4, and w=ceil(log2(n+1)).
The physical fields are unary n plus delimiter, gamma(m+1), m ordered triples of signed width-w identifiers, two n-bit adjacent-witness assignments, and the width-w release ID. Thus
N=3n+2+2 floor(log2(m+1))+3m(w+1)+w=Theta(c² log(c+1)).
Small empty cases can be handled directly. No layout preservation is inferred from source order.

A retains the original image, extracts candidate source records, verifies the exact factor types and disjointness, regenerates the complete canonical compiled image and compares every field. The pinned admission tariff is O(N³) time and O(N) span, including failed candidates, witness fields, lengths and source identifiers. Hash equality is insufficient. Valid nonmatches use exhaustive decision of the retained original formula; malformed inputs follow the language's reject convention. Compiler semantics and this explicit implementation tariff are inherited assumptions of the machine-level composition, not newly kernel-verified results.

On the authenticated original source let P be the p factor-port coordinates and V the projection to P of the nullspace of all its parity equations. Compute s=dim V and k=p-s by Gaussian elimination and projection of a nullspace basis, followed by rank reduction. Merely deleting internal columns of the equation matrix is not projection.

Independently group each exact-one triple into one domain-three variable and keep the other occurring variables as Boolean. Run the fixed smallest-ID degree-at-most-two elimination described below, to exhaustion or stall, without declaring a stall UNSAT. Let r be the number of remaining grouped/Boolean variables. This r is unrelated to the compiler copy parameter q. Define
M=min(3^r,2^s,2^k).

**Claim.** For every admitted input, this fixed A correctly decides both SAT and UNSAT. The same execution satisfies the conservative bounds
Q=O((c+1)^4(1+M)), L=O(N+M),
T=O(N³+Q L²), S_phys=O(L),
CM_phys=O(TL), CM_min=O(T(N+log(T+2)))=O(TN).
For every fixed C>=0, its restriction to admitted inputs with M<=N^C is polynomial in total encoded length. A itself does not depend on C. Neither a uniform C for all admitted inputs nor a general polynomial-time SAT bound is established.

## Exact semantics and safe selection

For every original parity equation construct the table on its distinct grouped identifiers. Enumerate at most 27 local tuples and evaluate every original port term, including two different terms belonging to the same group. Deduplicate only the scope IDs, not the parity terms. Grouping is a bijection between assignments satisfying all exact-one factors and assignments of these mixed domains. The tables therefore preserve the Boolean decision in both directions.

Choose the smallest current vertex v with at most two distinct neighbors in the live table-scope graph. Its bucket contains every live table using v. For each assignment to its at most two neighbors, the new table is true if and only if there exists ONE value of v satisfying the entire bucket. Replace the bucket by this table and delete v. Tables not in the bucket omit v, so conjoining them commutes with existential quantification over v. This proves the invariant after each step. A new table has at most nine entries, including the zero-arity true/false case. Keep scalar constraints and neighbor fill. Remove isolated unconstrained variables by the same rule. Scopes remain bounded by three and the total number of original and generated records is O(c). Each accepted elimination removes a variable. Stop after no eligible vertex remains.

Now enumerate all assignments to the r remaining mixed-domain variables and test all live relations and scalars. There are at most 3^r assignments. The projection invariant proves that acceptance is exactly satisfiability of the original source, even if the residual has unbounded treewidth. With r=0 test the scalar conjunction. An empty false table can authorize early rejection, but is not needed for the bound. Reusing different witnesses of v for different bucket constraints would break the invariant.

Two independent exact evaluators operate on the RETAINED ORIGINAL source. In the primal evaluator, enumerate the 2^s vectors of V by Gray coefficients in an independent projected basis and test all original exact-one triples. Every vector in V extends to internal parity variables, by definition of projection. This decides precisely whether the mixed original source has a model.

In the dual evaluator, compute a k-row annihilator H with ker H=V. Start a reachable-syndrome bit table at {0}. For each original exact-one triple, replace the set by the union of its three XOR translates by the corresponding columns of H. Use distinct old/new tables and clear the new table before each factor. Inductively the table lists precisely sums obtained by selecting one column from each processed factor. Zero in the final set is equivalent to a one-hot port vector in V. Equal syndromes have identical possible continuations, which justifies sharing. At k=0 the singleton table works; when there are no factors the homogeneous system is satisfiable.

All three branches are complete decision procedures on the admitted class, including their zero-dimensional cases. A computes r,s,k by paid polynomial preprocessing, compares the exact binary integers 3^r,2^s,2^k and chooses a minimizing branch, with a fixed tie order. These integers have O(c+1) bits and can be constructed by repeated elementary multiplication/shifts. No exponential trial runs or advice are used to select the branch. Crucially, the residual tables need not belong to the homogeneous-XOR/exact-one syntax. Running the original-source algebraic methods on those arbitrary tables would require a separate correctness and size theorem. This composition avoids that unproved transfer.

Thus on admitted inputs the chosen branch visits at most M candidates or syndrome states per polynomial number of layers. On unrecognized valid inputs the original-formula exhaustive fallback still terminates correctly. Internal UNKNOWN from structural stalling is never an external SAT/UNSAT answer.

## Same-execution cost ledger and controls

The input and authenticated source remain resident while both parameter computations run. Dense matrices and row bases have O(c²) bits; indexed scopes, retained/deactivated tables, domain flags and address metadata occupy O(c² log(c+1))=O(N) cells. Full rescans over pivot candidates and live scopes pay for failed choices. Grouping, all local table construction, Gaussian projection, annihilator construction and exact branch comparison fit O((c+1)^4) logical bit operations under deliberately loose schoolbook/rescan implementations.

Residual enumeration keeps one mixed-radix counter and one current assignment, evaluating O(c) constant-size tables per candidate with charged ID comparisons and lookups. Primal enumeration keeps one port vector, basis and Gray counter. Dual enumeration keeps two 2^k-bit tables, clears each next layer, scans entries and computes exact XOR addresses. The chosen branch has exponential factor at most M; O((c+1)^4(1+M)) dominates these bit-level operations, including counters and initialization. The unused preprocessing and retained alternate representation are still charged. No assumption that candidate generation is free is used.

Only the dual branch needs exponential storage, and it is chosen only if 2^k=M. All other scratch is polynomial, hence L=O(N+M). The inherited explicit cursor/unary-address implementation provides an O(L²) one-tape tariff for each bounded indexed bit access. Addresses, movement, all copying, cache clearing, mode switching and fixed-origin output are charged in T=O(N³+QL²). There is no conversion to a unit-cost RAM. This is a symbolic implementation upper bound, not a measured transition count.

At every time of this same run the span is O(L), so cumulative physical span is at most O(TL). Independently, a fixed machine, its N-bit input and a self-delimiting transition index describe a configuration in O(N+log(T+2)) bits. Since r,s,k=O(c), our explicit bound has log(T+2)=O(N); consequently description CM is O(TN). This does not identify physical storage with minimum-description information or multiply maxima from unrelated inputs.

If M<=N^C for fixed C, one can use c=O(N) to obtain the coarse bound
T=O(N³+N^(4+C)(N+N^C)^2), S=O(N+N^C).
Every term, including unsuccessful preprocessing and source access, is polynomial on that restriction. The union over input-dependent exponents C is not a fixed polynomial-time theorem.

Construction's mixed cycles have r=0 under grouped elimination, while s=2t,k=t may grow. Bounds' equality cores stall immediately structurally, but s=2 gives M<=4. The portfolio therefore admits both constructive controls. The old component and private-leaf shortcuts remain valid and separately available. No completeness or rank argument makes these voluntary evaluations compulsory for arbitrary solvers.
