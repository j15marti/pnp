## Exact input, solver and quantifiers

Fix the following deterministic solver A once, before the input. The source is a positive exact-one formula F with v Boolean names and m ordered triples, three distinct names per row. The decision asks whether each triple has exactly one true name, not its number of models. A supplied certificate is a rooted tree of b nonempty bags, b<=m, partitioning all row indices once. A bag's variables are exactly those occurring in its assigned rows. The listed order of those rows is cyclic. Every variable's bag set must induce a connected subtree (running intersection), adjacent bag-variable intersections have size at most two, and each variable's occurrences within each bag form a circular interval. Empty F is handled as SAT.

Use dense IDs 1..v, unary v plus delimiter, a self-delimiting m, fixed-width row IDs, then a self-delimiting b, parent indices and length-delimited bag row lists. The lists partition [m], so the total certificate has O(m log(m+2)) bits. Let **N be the total encoded source-plus-certificate length**, O(v+m log(v+2)+m log(m+2)). This N is not the older padded compiled length N0. Malformed metadata is bounded against actual input length before allocation. Parse every field, check distinct row names and range, exact end, row partition, tree, intersections, occurrence connectedness and all cyclic supports. A certificate is evidence to verify, not an oracle for feasibility.

For every valid certificate and every source, A computes exact subtree feasibility tables by the algorithm below. Let C_t be the deterministically computed cover at bag t, using its actual incoming tables, and W=sum_t 2^|C_t|. With no budget cutoff, A decides both labels with the symbolic sole-tape bounds below. For each fixed integer c>=1 there is a uniform guarded version A_c that returns the exact label whenever it finishes with W<=N^c. Invalid certificates or budget overflow return UNKNOWN to a correct exhaustive fallback. UNKNOWN is never interpreted as UNSAT. The cap is fixed before inputs. Early empty tables can terminate with a proved UNSAT result without completing W.

The theorem is about supplied, verified certificates. To apply it to ordinary source inputs without certificates, their acquisition and all failed attempts must be paid separately. No polynomial acquisition theorem covering every source is supplied here.

## Algorithm and proof

Process bags from leaves to root. Each directed child-to-parent message is the set of assignments to their intersection extending to a solution of all rows in the child's subtree. Its bit mask has at most four entries, with the separator names retained explicitly. Empty intersections have a zero-arity true/false message. Keep every completed message. For each bag compute its entire outgoing mask once, before its parent uses it.

At a bag first reject an empty incoming table. Intersect unary tables into unary domains. For a binary table Q on distinct names x,y compute its coordinate projections P_x,P_y. Replace Q by unary domains only if Q=P_x times P_y, checked by its four possible entries. Otherwise retain Q as a correlation and put edge xy in a simple graph G_t. Parallel constraints remain as separate tables although their graph edge is shared.

Choose a maximal matching greedily in fixed name order. Its endpoint set C_t is a vertex cover: an edge with neither endpoint matched could have been added. Moreover |C_t|<=2 tau(G_t), since any vertex cover meets every disjoint matching edge. No minimum-cover oracle is used.

For each of the at most four parent-separator assignments, enumerate all assignments on C_t. Combine these pins with unary domains, rejecting conflicts. Every retained binary table has at least one fixed endpoint. After restricting to that endpoint it is empty, unary, or a satisfied constant; its remaining projection therefore loses no correlation. Intersect all resulting domains. Domain intersections suffice without a fixpoint: all nonproduct tables have a fixed endpoint, so any assignment in the final domains satisfies each restricted table. Empty domains reject the branch. Solve the local circular exact-one rows with these domains. Put the parent tuple in the outgoing mask iff any branch succeeds. At the root accept iff its zero-arity result is true.

For completeness, the pinned local solver is elementary. When a domain fixes a true variable, every other name in its rows must be false globally. Reject two true names in a row or conflicting pins. Delete satisfied rows and all fixed columns, reject an empty remaining row. Removing entire rows preserves circular intervals in the induced cyclic row order. Remaining rows have width at most three. Pick a remaining row: an exact cover must choose one of its at most three variable arcs. For each choice, discard every other arc intersecting it; its complementary row gap is linearly ordered. Disjoint contiguous arcs tile that gap exactly iff its start reaches its end in the directed graph of arc endpoints. A full-circle chosen arc leaves an empty gap. Free names with empty support cause no obstruction. This proves both existence and nonexistence decisions without enumerating assignments of the unpinned names. All pins, deletions, failed choices and endpoint tests are paid.

The outgoing table is exact by induction. For any assignment satisfying a subtree, its restriction appears in every child table and in an enumerated cover branch, so it is retained. Conversely, a successful local assignment extends to each child's subtree by the meaning of that child's table. If a variable occurs in two such subtrees, running intersection places it in their connecting bag and both separators. Thus the extensions agree. All rows have exactly one owner and are satisfied after gluing. Induction gives the root decision.

**Additive cost is the new integration point.** Each bag requires at most 4 times 2^|C_t| local calls, regardless of depth. Descendants are not rerun for different assignments of an ancestor: their at-most-four-entry masks already represent every possible separator value. The total number of local calls is at most 4W, not a product of branch factors down the tree. This extends Discovery's circular star guard to arbitrary verified trees of circular bags and includes the circular unary-message case. It does not subsume Construction's separate small noncircular-bag option. Standard tree messages are known; this result specializes their local cost to the correlation-cover/circular solver.

For a concrete failure of this fixed guard's universal budget, take Discovery's star for the complete graph K_h. Every one-triple leaf sends NAND {00,01,10}. The root correlation graph is three disjoint copies of K_h, one per color. Any maximal matching in each clique has floor(h/2) edges, so |C_root|=6 floor(h/2) and W>=2^(6 floor(h/2)), while the explicit source and star certificate have N=O(h^2 log(h+2)). Thus W is not polynomially bounded on this family. This is a failure of the chosen guard, not a lower bound on decision: recognizing the complete-graph family makes its coloring verdict immediate after verification. Preserve that fast bypass too.

## Complete conservative resource ledger

Model: one writable finite-alphabet tape, one read-before-write head with unit moves, input retained within the charged span, and a terminated Boolean answer returned to the origin. We give a deliberately coarse direct-source implementation, not an imported compiled tariff.

Dense occurrence, tree and local endpoint matrices, row ownership, explicit separator names, table masks, counters and one current branch fit O(N^2) bits. Sources and certificates are retained and copied inside this bound. Verification and each local call can be organized with at most O(N^4) indexed elementary bit operations: scan pairs of rows/names and graph adjacency, use queues for graph searches, and charge O(log^2(N+2)) bit arithmetic per word operation. Cubic word-operation bounds suffice and their logarithms fit this allowance. No array access is treated as free physically. Scan the O(N^2)-cell workspace to find each addressed bit, including address decoding and return moves, at cost O(N^2). Initialize it within the same allowance. Compute matching and all table projections once per bag. Parent trials reset the same workspace; they retain child masks without recursively recomputing them.

Thus the admitted execution has T=O((1+W)N^6), peak physical storage/span S=O(N^2), and physical CM=sum over actual transitions of occupied span =O((1+W)N^8). Every maximum used here bounds this same run. Since W<=m 2^v, log T=O(N); describing a configuration by this fixed program, its entire input and its time index independently gives CM_min=O(TN)=O((1+W)N^7). Physical storage and minimum-description information are different quantities.

For a fixed guard c, use capped arithmetic to reject before enumerating a cover whose branch count would make the accumulated budget exceed N^c. Constructing a counter does not enumerate its branches. Failed guards, validation, masks and processed branches cost O(N^(c+6)) time, O(N^2) space. The exact fallback enumerates source assignments and evaluates all original rows using polynomial scans, conservatively O(2^v N^6), with no certificate assumed true. It makes A_c globally correct but does not give a polynomial all-input bound. Extra certificate discovery is not included in these supplied-input bounds. If discovery uses G steps and Q span on the same machine, total time includes G and peak span includes Q plus retained data; its actual cumulative cost must also be included. Discovery on another input/run cannot be substituted.

No adjacent-witness compiler is used in this new theorem. Four concrete falsifiers:
1. Dropping running intersection permits inconsistent assignments to the same name in separated subtrees. Such a certificate must be rejected.
2. Replacing Q={00,01,10} by its unary projections accepts forbidden tuple 11. The product test must precede projection.
3. Storing only unary projections of an outgoing binary message similarly loses a correlation needed by its parent. Store the full four-entry mask.
4. Claiming all-input polynomial time from small separators or free certificate discovery is invalid. Discovery's coloring star satisfies the structural conditions, while the cover budget is unbounded by the theorem. A hard-looking large cover is also not a runtime lower bound on other algorithms.
