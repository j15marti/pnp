**Exact construction and encoding.** Fix a uniform deterministic all-input decider A for explicitly encoded positive Boolean exact-one triples. For every finite simple base graph H on explicitly represented terminals 0,...,q−1, q≥1, and k edges, assign each edge u<v a permutation p_uv in S3. Order edges lexicographically. For edge j add private quotient vertices a=q+2j and b=a+1 and five quotient edges ua, ub, ab, va, vb. Put identity matchings on ua,ub,ab and p_uv on va,vb, oriented from the terminal to the private vertex. Distinct diamonds share only terminals.

The resulting quotient has Q=q+2k vertices and K=5k edges. Replace each quotient vertex by its triangle, each quotient edge by its specified three-edge matching, then use Construction's direct graph-star exact-one generator. The expanded coloring graph has h=3Q and e=3Q+3K. Therefore

    n=8h+3e=33q+111k,
    m=4h+3e=21q+87k,
    w=ceil(log2(n+1)),
    N=n+2+2 floor(log2(m+1))+3mw=Theta((q+k)log(q+k+1)).

The fields are unary n and zero, gamma(m+1), then 3m incremented variable identifiers of width w. Source creation is polynomial in the explicit base description plus output length. A coloring of each triangle is a bijection f from places to colors. Accounting's local diamond proof gives precisely

    f_v = f_u composed with p_uv.

For completeness, at each left place the left terminal and two private triangles have all three different colors. The right place must avoid the two corresponding private colors, forcing the displayed relation. Conversely the two cyclic color rotations of f_u fill the private triangles whenever that relation holds. Private interiors of distinct diamonds extend independently. **The solver and proof.** Store both orientations of each base edge, using p_uv inverse on v to u. In each connected component choose a root and set its potential h_root=e. Traverse a spanning tree and set h_v=h_u composed with p_uv when v is first reached. For every encountered edge with both potentials assigned, check h_v=h_u composed with p_uv. Return UNSAT on a conflict. If every component passes, return SAT.

If all checks pass, assigning f_v=h_v satisfies every terminal equation, and therefore extends to every diamond and to the exact-one source. Conversely if terminal bijections f_v exist, along a tree path induction gives f_v=f_root composed with h_v. Substitution into any other edge equation and cancellation of f_root imply precisely the checked equality. A conflict is therefore a correct UNSAT certificate. This is uniform over all finite base graphs and all S3 labels, including noncommuting labels. At the normalized adjacency-list level it uses O(q+k) constant-size group operations and accesses, plus graph indexing. The physical source/tape implementation is charged separately below.
