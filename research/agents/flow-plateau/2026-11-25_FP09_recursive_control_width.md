# FP09: Recursive common-interval barrier and width-based collective compatibility
2026-11-25 Pacific. PROVED scoped; COMPUTATIONAL finite certificates; P vs NP OPEN. Continuation of FP07 (5c30efa154f4ca4305531325fdd5e92bdcb24a71) and FP08 (reviewed current report). No schedule or peer edits.

## Claim
For the three fixed binary projected cycle systems of FP06, even an unrestricted catalogue of common cyclic intervals (each confined to one triple-cycle signature class) need not contain a successful syndrome expressed using O(1) or O(log n) intervals. There is an explicit colorable simple cyclically 4-edge-connected cubic family with authenticated sole-zero flows and minimum number of such controls Theta(sqrt(n)). This holds even allowing even intervals as well as odd. It is a restriction on representations, not an unrestricted algorithm lower bound. Positive: that family has bounded treewidth, so all control-count barriers can coexist with polynomial-time graph-only decision/witness acquisition without module recognition.

## Recursive amplification
Base FP01 core E0 and START as FP06. Independent exhaustive proper coloring backtracking gives 12 proper targets; minimum branch count among ten good vertices is 2. Replace all ten good vertices by J-0, initial boundary relabeled to match original, recurse for d levels on all inserted vertices, never expand defective endpoints. n0(d)=10*9^d+2. At each proper target, each three-pole projects to a proper vertex with distinct colors, so each parent rotation forces >=3 child branches. Hence at least 2*3^d branches at deepest level; equality achieved by local minimum-branch extension for each boundary word. At least 2*3^(d-1) deepest rotated modules for d>=1; choose a private branch in each, belonging in some view to a cycle entirely inside its own module. No chosen pair from different modules can share triple-cycle signature. A projected common interval lies within just one signature class, so even an XOR of overlapping odd/even intervals must include at least one interval per occupied class. Thus q>=2*3^(d-1). Singleton intervals yield q<=2*3^d. For d=0, endpoint RHS sizes 2,4,2, while each column signature has size3; no zero/one control possible; two attained. For d>=1, q=Theta(sqrt(n0)). Proof is for fixed initial flow and the exact three FP06 views, not arbitrary newly acquired flow or general projection.

3-edge connectivity of recursive core: 3-sum at deleted vertices of two 3-edge-connected cubic graphs preserves >=3 edge connectivity. For a proposed cut<=2, if both three-poles split, each has >=2 internal cut edges (cap root on majority terminal side, losing <=1 in comparison). If just one splits, the other homogeneous side represents its missing vertex, and the cut size equals a nontrivial cut in original graph, >=3. If neither splits and sides differ, 3 joining edges cross. Thus contradiction. Base all 4094 cuts checked.

Couple two copies of recursive core as FP06: every nondefect edge replaced by one shared Petersen four-pole, same-pair terminals within each copy, keep sole potentially defective edge as ordinary edge in both. First copy near, second proper. Use proper Q extension; recolor first-pair wires via bichromatic paths preserving second pair, so no added branch vertices in modules. Any proper target projects to both core colorings. Each directional cycle through core vertices follows the corresponding core cycle, spliced through same-pair paths (only when its seam color is in that view); a path cannot exit another pair since swapping would violate proper pair equality. Thus private cycles for different deepest modules remain distinct. Lift has n=14*n0-8=140*9^d+20; min branches exact 2*3^d; min controls Theta(sqrt(n)). Graph cyclically 4-edge-connected: contract each Q to degree4 node. A skeleton cut<=3 cannot split both original copies (each split forces >=3 edge-disjoint path crossings). If one mixed, its >=3 crossings force no crossings in the homogeneous copy and hence all Q nodes on common side. For minority original set S, cut =3|S|-2*1[e0 internal to S], <=3 iff singleton. If neither mixed, opposite sides incur >=2 per Q; same sides all Q must agree. Thus skeleton cuts<=3 trivial. For split Q internal cut k>=2 and for k<=3 minority terminal count t<k; verified all254 proper subsets; k+t<=3 implies singleton/complement. At most one split Q in cut<=3; round to majority terminal side to lower by >=k-t, yielding skeleton cut<=2 (empty). Hence original cut singleton. No low-cut normalization removes the obstruction.

## Width rather than count
Exact generalized collective terminal: given any explicit candidate interval family I_1..I_q, represent h_v=XOR_{j:v in I_j}t_j. Use FP06 activation variables x_{e,c}. At good v and each view, impose XOR of its two incident activations = h_v; endpoint direction RHS determined by chosen new color r. For each edge forbid both permitted activations simultaneously. The result is a Boolean factor network with parity factors of arbitrary arity and binary clauses, exact for syndromes in span of supplied intervals. No assumption all syndromes have small interval count. Given a tree decomposition of its variable-factor incidence graph of width w, use standard nice decomposition DP: store each bag variable bit and each bag factor's accumulated XOR or clause-satisfaction bit over processed incident variables; combine parity by XOR and OR for clauses, account for bag assignments once, enforce forgotten factors, recover witness. O(2^{O(w)} poly(N+S)) work, where S is explicit interval incidence size; all decomposition, reconstruction, failed searches charged. Known single-exponential treewidth 5-approximation (Bodlaender et al. DOI 10.1137/130947374) gives affordable acquisition for w=O(log(N+S)), fixed constant. Singleton intervals cover all syndromes but may have high width. Need no semantic absorption or recognition of complete relation. No universal low-width claim. This width terminal is a proved consequence of ordinary incidence-treewidth DP, not a novel general graph algorithm.

The recursive counterexample family itself has constant original graph treewidth: form hierarchy of nested three-pole substitutions with singleton leaves. At each internal node put in bag the vertices inside each immediate child incident to edges leaving that child (include singleton leaves). Each child has <=3 boundary edges, each node <=9 children except root <=12. Bag size<=36; every edge appears at LCA and each vertex occurs on a connected initial segment of its ancestor path. Core treewidth<=35. Duplicate every bag for two copies; attach a bag containing 4 terminal endpoints and 8 internal Q vertices to a bag holding the corresponding original endpoints. Width<=71, no dependence on d. Thus known fixed-width decomposition acquisition (Bodlaender 1996 DOI 10.1137/S0097539793251219), then ordinary six-permutation vertex CSP DP, solves all these inputs without given target or semantic absorption. This is a theoretical algorithm, not executed full DP. The singleton-control FP06 factor graph also has constant width on family by replacing each graph bag by constant-size vertex and edge incidence variables/factors. Unrestricted logarithmic width conjecture false for arbitrary cubic graphs, e.g. expander graphs, so this is a complementary terminal, not a full closure proof. No claim of novel treewidth algorithm.

## Consequence
A fixed global GL(2,2) change of basis permutes the 3 views, and cyclic shifts/reversals of traversals do not change signature classes or cyclic interval sets. Thus simple global rotations cannot rescue this fixed catalogue. Need genuine new projected coordinates/near flows, or many-control compatibility via bounded frontier/rank/matching, not brute enumerate n^{O(q)} for q=Theta(sqrt(n)). No lower bound against algorithms using richer controls, including one union of multiple signature classes. Charge all work in original explicit encoded length N; exponential in width becomes polynomial at logarithmic width, unlike n^{O(log n)} interval enumeration. FP02 still open.
