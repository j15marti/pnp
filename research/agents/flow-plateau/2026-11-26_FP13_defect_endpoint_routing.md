## 1. Source and exact spanning slice
Let explicit simple cubic G have verified binary incidence D, a in ker D, A=supp(a), F=E-A, and proposed exact zero set Z subset F. Fixed-a chart requires b|F=1_F+1_Z and D b=0 (FP12 quotient T-join). To escape next along b, it must be a spanning 2-factor with only even cycles. At each vertex outside A its prescribed F bits must have degree exactly 2; otherwise no spanning partner in this chart. On each cycle of A the incidence equation determines its edge bits from one seed bit; check both words for degree exactly 2. If a cycle has a vertex incident to Z, that vertex needs both A edges in b, fixing the seed uniquely if feasible. If it has no such vertex, every vertex has its unique F edge in b and must have one A edge in b; only an even cycle permits this, with exactly two alternating matchings. Hence the spanning slice is either empty or an exact independent binary switch chart with base b0 and free disjoint even cycles C_i. No need to enumerate nonspanning phases. All b in slice have exact Z and conserve flow. This proof handles disconnected inputs, and arbitrary fixed Z, including no defects. Individual phase pins can be imposed by selecting/removing switches; general coupled affine guards may invalidate independence and are not covered.

## 2. Defect parity identity (new local routing reduction)
In any spanning chart partner b, mark each vertex incident to Z. Since b degree2 and every zero edge is outside A, no vertex can be incident to two zeros (at an A-vertex only one F edge exists; at an isolated A-vertex exactly two F bits must be 1). Thus Z is a matching. At an unmarked vertex on a b-cycle its two selected edges consist of one A and one F edge. A marked vertex has two A edges if it is on A, or two F edges if isolated in A. A binary word of edge types around a closed cycle has an even number of changes. Consequently the length parity of every b-cycle equals the parity of its marked vertices. For Z={st}, b is all-even iff s and t lie on the SAME b-cycle. This remains true if one/both defect endpoints are isolated in A. More generally every selected component must contain an even number of endpoints. This gives a precise two-terminal routing obligation instead of testing all cycles for each phase assignment.

For r=1 and min_y Psi(a,y)=1, enumerate singleton feasible Z by FP12 (at most m). For each chart test whether its spanning slice has an s-t-connected partner. If yes, acquire c by assigning 1 on E-support(b) and alternating 0/1 along each even b-cycle. Then (b,c) proper, and (a,b_initial)->(a,b)->(c,b) is a nonincreasing 1,1,0 trajectory retaining the indicated projection (up to permitted global coordinate swap). b and a+b are interchangeable in the unguarded fixed-a fiber, so this characterizes all escapes with a first retained direction a followed by either other direction. It says nothing about longer paths or first retaining another direction. If min(a)=0 use direct baseline.

## 3. Square absorption and component-local long parameter
For given phases of long free cycles (length>4), let host H be current b plus every edge of every free square. CEC01's square-switch theorem: if a square has its two current b edges on distinct b-cycles, toggling it merges those cycles, because deleting those two edges opens two disjoint paths and inserting the other two edges joins both paths. No other cycles change. At most n such merges occur; at stagnation every host edge joins vertices in the same b-cycle, so b-components equal H-components. The chart is feasible iff every H-component has even order. By section 2 for Z={st} this is iff s,t connected in H, including disconnected original graphs. No need to enumerate square phases.
For arbitrary Z, form H_all by including BOTH phases of every free cycle, and fixed edges. Independent H_all-components contain entire switches. Reject any odd-order H_all component. Components with no defect endpoints need no optimization: every candidate b-cycle there is already even. In each remaining component enumerate its k_i long free choices, independently, using square absorption on the resulting host. Time poly(N)*(1+sum_i 2^k_i), serial polynomial space. Only one such component is relevant for singleton Z; if endpoints lie in distinct H_all components chart rejects immediately. Thus logarithmic long count is needed only in the defect-bearing component, not globally. This extends matching-chart factorization to the exact deficiency-one active region. All graph/component construction and membership probes paid. At r=1 additionally multiply by at most m candidate singleton charts; no uniform polynomial bound for unbounded active k_i.

## 4. Adaptive phase-conflict routing (exact complete algorithm under no cap)
For a singleton Z={st}, retain square phases as freely switchable hosts and partially assign long cycles. Construct relaxed host containing both phases of every unassigned long cycle, fixed chosen phases of the assigned long cycles, and both square phases. Find a simple s-t path P by BFS. If none, reject this partial chart soundly. If P uses edges of both phase matchings in some unassigned long cycle C, branch on its two actual choices (both exhaustive). Otherwise P is phase-consistent: choose each unassigned long phase used by P, arbitrary phases for the others. In the resulting square host P remains, so the square theorem obtains a spanning factor with s,t in same cycle and hence a proper extension. Correctness by induction on remaining long choices, including cases where a failed path is not itself a proof of infeasibility. Branch only on source-authenticated conflicts in the path; no claim every candidate shortest path is conflict-free. With k active long cycles the tree has <=2^(k+1)-1 nodes; all BFS calls, failed branches and phase masks charged. A tighter bound is 2^(d+1)-1 for max executed conflict depth d in the uncapped complete tree, or O(L poly(N)) for actual L nodes. If universal d=O(log N) were established for a deterministic path selection, that chart terminal would be polynomial; not proved. With explicit polynomial clock, return DECLINE if exhausted, not NO. The same decision is expressible by CEC03's sparse parity-event DP (known scoped result); use that as complementary bounded-width terminal, not a universal discovery assumption.
A concrete continuation certificate is the s-t host path + chosen long phases + sequence of square merges + actual even factor; all independently checkable without solving the original graph. Nonexistence of a path in a guarded host is a sound chart-level rejection and can be represented as an s-t cut of disabled phase edges. It does not reject unrestricted source or prove equivalent continuation after phase merging.
