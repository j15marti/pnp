# FP02: One-defect repair is equivalent to P=NP (search, polynomial-time adaptive reduction)
2026-11-25 21:27 Pacific. PROVED/EXACT reduction, external referee pending. P versus NP OPEN.

## Named dependency
FP01 (blob 60152aebaaff4651109e721f59ab9245a8633377) falsified universal non-increasing escape on arbitrary cubic graphs, but left cut-normalized escape open. Here we prove that the apparently narrow one-defect witness-repair task, with no path restriction and with a supplied authentic conserved flow, already suffices for a general polynomial decision algorithm. No many-one NP-completeness claim for the promise decision problem is made.

Let R be a fixed uniform deterministic algorithm such that for every connected simple cubic 3-edge-colorable H and supplied F2^2-flow z with exactly one zero edge, R returns a nowhere-zero flow within p(L) bit steps for one polynomial p in total explicit input length L. On negative instances no behavior is required; the caller clocks p and checks witnesses. Then P=NP. Conversely P=NP supplies R by standard NP prefix-search self-reduction (verification is local). In particular no assumption about monotone routes, arbitrary initial defect counts, or plateau graph diameter is needed. Falsifiers checked: a false boundary equality relation, a crossed boundary needing more than one zero, a SAT source having an UNSAT intermediate, a hidden unknown witness needed to construct the repair input.

## Constant gadget
Colors are 1,2,3 in F2^2 with XOR; 0 is zero. Remove adjacent vertices 0,1 from the Petersen graph with outer cycle 0..4, inner star 5..9 and spokes i--i+5. Ports at (4,5,2,6) ordered as the two pairs corresponding to the removed vertices. Internal edges, in order:
(2,3),(2,7),(3,4),(3,8),(4,9),(5,7),(5,8),(6,8),(6,9),(7,9).
For any nonzero boundary with total XOR zero, exact minimum internal zero count is 0 for s1=s2 and s3=s4, otherwise 1. The proper relation is also the known isochromatic Petersen four-pole lemma (Allie et al. 2024, Lemma 3.1). Proof of necessity: if the first pair differs, XOR conservation implies the second pair has the same unordered colors; reinserting the removed vertices with the third color on their common edge would color Petersen, impossible. All possibilities up to global color permutation, with explicit internal witnesses:
1111 -> (2,3,3,1,2,2,3,2,3,1), zero 0;
1122 -> (1,3,3,2,2,2,3,1,3,1), zero 0;
1212 -> (0,1,2,2,3,3,1,3,1,2), zero 1;
1221 -> (0,2,2,2,3,3,1,3,2,1), zero 1.
Check local XOR at all 8 vertices. There are exactly 21 labeled balanced nonzero boundary words; 9 permit zero defects and 12 need one. Python direct 4^10 internal assignments independently checked the four representative minima; separate JS backtracking with degree-based closure checked all 21 words (5496 edge color trials after pruning). No free choice of a solution to the source is used in the gadget.

## Staged wrapper (constructive proof)
Input explicit simple cubic graph G with n vertices and m=3n/2 edges, malformed rejected. Components can be processed independently. Assign a nonzero color to each of the three halfedges at every vertex, all distinct locally. For active set S, impose equality across exactly the edges in S. This partial-constraint system is monotone in S and coincides with proper edge-coloring when S=E(G).

Construct H_S with two labeled copies of all source vertices. For each inactive edge uv, separately join the two copies of u's halfedge and the two copies of v's halfedge through K4-minus-edge two-poles; the two ports have the same color, any nonzero color extends. For each active edge uv replace these two two-poles by one Petersen four-pole, its first pair attached to u,v in copy 0, second pair to u,v in copy 1. Each edge uses 8 new vertices in either state. H_S is simple cubic, 14n vertices and 21n edges, with a deterministic explicit encoding O(n log n) bits for dense labels. From ANY proper coloring of H_S restrict to copy 0's terminal colors; active equalities hold by the gadget. Conversely from any satisfying partial halfedge assignment duplicate it to the second copy, extend all inactive two-poles and all active four-poles. Thus H_S colorable iff the partial constraint system is satisfiable.

Start from S empty, arbitrary locally distinct halfedge colors, and lift. For connected G one may instead start from a spanning tree S: choose colors greedily from root to leaves, with the incoming color fixed and the remaining two arbitrary distinct, then lift. This latter variant ensures all H_S queried subsequently are connected because each active four-pole is connected and joins the four source endpoints; a spanning tree reaches all source vertices and their copies. Empty start can also use only the single defective component as a repair query and retain the existing coloring elsewhere.

At a stage, extract a proper partial halfedge assignment from the already verified prior coloring (no source guess), duplicate it and construct H_(S+e) with the old local assignment. Only the new gadget can be defective; if endpoint colors agree it is already nowhere-zero, otherwise its ordered boundary is (a,b,a,b), with one zero internally by the fixed witness. The result is an actual conserved flow, verified by XOR. On a SAT source every partial system is satisfiable, so the newly constructed graph is colorable. Invoke R on the one-defect input, with polynomial clock and witness verification. If no verified coloring returns, reject: on a SAT source this cannot occur. If it returns, extract and continue. An UNSAT source cannot reach the final stage with a verified coloring, since projection supplies a coloring of G. On completing all stages output the verified source coloring. This is a deterministic polynomial-time Turing-style search reduction, not an algorithm that invokes a decision oracle on a promise without witness extraction. No future information, coloring of an UNSAT graph, or free route acquisition is used.

## Cut-normalized strengthening
The same sufficient R can be restricted to cyclically 4-edge-connected simple cubic graphs. On a connected graph with a one-defect flow, reject a bridge (its color must be zero and a proper coloring impossible). Split at 2-edge cuts by capping both sides with an edge, and at nontrivial 3-edge cuts by capping each side with a new cubic vertex. Two seams have identical flow colors; three sum to zero. Each capped child inherits at most one zero: a 2-edge cut cannot have a zero under this budget; at a 3-edge cut a single zero is copied once per child, and otherwise the unique zero is internal to at most one child. Feasibility equivalence holds because proper boundary signatures are respectively same color or all distinct, and a global color permutation glues any independently proper child witnesses. Capping a minimal 2-cut, or a 3-cut after all 2-cuts removed, keeps each side connected. Bridgelessness is preserved: any internal edge bridge in a capped child would have all boundary endpoints on one side (connected by cap) and hence was a bridge originally. Cap edges themselves have alternate paths inside connected sides. A loop in a bridgeless cubic connected graph is impossible (third incident edge would be a bridge); a pair of parallel edges in a graph with >2 vertices gives a 2-cut. Solve the two-vertex triple-edge terminal directly. All other irreducible children are simple, have no bridges, 2-cuts or nontrivial 3-cuts, hence cyclically 4-edge-connected. Cuts discovered by enumerating up to three edges and testing connectivity. Each nontrivial split makes child order strictly smaller. Measure n-2 is additive at 3-cut and decreases by 2 in aggregate at 2-cut; at each depth sum measure <= original, giving conservative O(n^2) total nodes including zero-measure two-vertex leaves. Zero-defect children are already solved. The clocked irreducible R plus witness gluing gives a polynomial general R. No claim of hardness at any specific large girth, nor of monotone escape after contraction.

## Cost and gates
At most m repairs, each size L=O(n log n), O(n log n) explicit construction/storage with indexed arrays on a RAM (conservative polynomial overhead on a bit machine), and polynomial source validation and projection, no need to retain historical flows, all failed work bounded by one fixed polynomial clock per call. If R uses time T_R(L) and space S_R(L), wrapper time O(m(poly(N)+T_R(O(N)))) and peak O(poly(N)+S_R(O(N))) on sequential same realization, with ordinary explicit encoding N and dense relabeling charged; CM <= total time times peak space. Cut-normalized variant adds polynomial cut discovery, O(n^2) conservative nodes per stage and reconstruction; do not claim same exponent.
