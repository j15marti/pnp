## 1. Exact two-move radius, independently of chart selection
For explicit cubic G let C=ker D over F2, P={x in C: exists y in C with Psi(x,y)=0}. By degree-three conservation, P is exactly the set of spanning 2-factors with all cycles even: nowhere-zero pairs imply two incident 1 bits at each vertex; conversely alternate companion bits along each even cycle and put companion bit1 off it. Define
mu(d)=min_{x in C} Psi(d,x);
m(d)=min_{M perfect matching} |M minus supp(d)|;
rho(d)=min_{x in P} Psi(d,x),
empty minimum=infinity. The ordinary spanning-factor relaxation is m because the complement of a perfect matching is a spanning 2-factor. Always mu<=m<=rho. Minimum T-join is mu (FP12 baseline).
For initial (a,b), write c=a+b. With global relabeling free (equivalently allow any common member of the unordered direction triples), a first move to (d,x) retains d in {a,b,c}; a final proper move must retain d, x or d+x in P. If d in P, rho(d)=0. Otherwise Psi(d,x)=Psi(d,d+x), so the least intermediate defect count for at most two moves to proper is rho_* = min(rho(a),rho(b),rho(c)); the minimum budget including initial state is max(Psi(a,b),rho_*). Converse by choosing minimizing x in P then its proper companion. Ordered implementation can require global color relabelings counted separately; these are realized by projection-retaining transpositions without changing potential. Statement concerns at most two substantive projection changes modulo relabeling. Does NOT bound longer sequences. We now refute universal constant, sublinear or constant-factor-over-matching two-move radius on a LINEAR-size explicitly constructible family, even with all three initial directions simultaneously considered.

## 3. Linear lower bound and exact radius
Any proper coloring of source projects through each Q to equal nonzero paired seam colors; entire serial chain constant. At each core original conservation then yields a proper core coloring. Every proper core projection x has at least one protected edge e with d_e=x_e=0, for d in START's three directions. Otherwise (d,x) is protected, shares d with START modulo permutation, and a proper companion of x gives a protected path to proper, contradicting certified core component. Also checked directly for all 12 core proper colors. Therefore every proper source direction x has at least L+1 shared zeros with each initial d, just from first replica's seams, so rho(d)>=L+1. In particular mu(d) cannot be zero (that would make d a proper direction and rho(d)=0). Combined with explicit spanning partners: mu(d)=m(d)=1 on ALL THREE directions.
Sharper exact formula for lexicographic initial module words:
rho(a)=2L+2, rho(b)=rho(a+b)=L+1.
Proof: for each of 144 ordered pairs of proper core colorings X,Y, every proper source lift consists exactly of the independent choices of internal words per Q. Minimize cost in each module independently for its fixed boundary, and add seam costs. For each d compute integer coefficients:
s = sum_{protected e} ([d0_e=0 and X_e bit1=0]+[d1_e=0 and Y_e bit1=0]),
h = sum_{protected e} minimal internal shared-zero cost for one Q given X_e,Y_e and initial word,
t = shared-zero cost at both bare e5 edges.
Then objective for pair X,Y equals (s+h)L+(s+t). Take minimum over all144. Independent direct enumeration certifies minimum coefficient and minimum intercept attained simultaneously: (2,2),(1,1),(1,1) for d=a,b,c. No other nondominated pair. Since L>=1 this is exact for all L, not extrapolation. Python builds full source and witnesses for each track and L=1,2,4,8,16,32,64,128; checks incidence, simplicity, connectivity, sole zero, proper target, matching partner degree and exact cost.
Consequently least two-substantive-move budget is L+1=(n+112)/136, while all T-join and matching relaxations report 1. This is a linear integrality/relaxation gap in vertex count (Omega(N/log N) for ordinary indexed edge-list bit length N=O(n log n)). It refutes any sublinear-in-n initial two-move radius bound, including best initial direction, or a constant-factor bound in the matching objective. No unrestricted time lower bound and no bound on radius of an arbitrary later direction.

## 4. Exact weighted four-pole interface, not additive
The unweighted equality-pair module relation factors completely across its two virtual edges. This need not be true of the weighted objective.
Let alpha,beta be the zero-indicators of the fixed initial direction d on its two seam pairs (each pair equal in the supplied proper local module). Let u,v be zero-indicators of a proper target direction on those seam pairs. The exact minimum internal shared-zero count for the Q module, optimizing over all its proper target lifts given actual colors, is:
alpha beta =00: 0;
alpha beta =01 or10: u*v;
alpha beta =11: u+v.
This formula holds for ALL 18 initial proper internal words, all 3 fixed directions and all 9 target boundary words (486 cases). Primary raw XOR enumeration and independent direct local coloring recursion agree; complete finite certificate. No dependence on whether target nonexcluded colors are 1 or3, so target direction bit suffices for this weighted interface. For 01 or10, mixed difference f(0,0)+f(1,1)-f(0,1)-f(1,0)=1. Thus no independent sum of functions of the two virtual edges, and not a submodular binary cost in those coordinates. Preserving feasibility alone does not preserve a nearest-witness objective. On a network of such modules, with fixed target core words, exact optimum lift is sum of unary seam terms and these pairwise terms, with independent actual local witness recovery. If constant-size cores, choose among finite even-factor options per core, giving a finite-domain pairwise objective; arbitrary number of interacting cores not claimed tractable. This is a new precise weighted handoff for binary/matching/affine tracks. The two-replica family uses enumeration of 144 options only, not exponential source-color enumeration. No arbitrary affine guards on target companion or phases claimed.

## 5. Cyclic four-edge connectivity proof and independent full small-cut audit
Contract each Q to a degree4 skeleton vertex. Every virtual core edge becomes a path, each path edge-disjoint from all others. Core cut audit all4094 proper subsets shows cuts >=3, equality only singleton/complement. Any skeleton cut<=3 splits originals of at most one replica, since each mixed core requires >=3 path crossings. If one mixed, other homogeneous and all its paths have no crossings; every Q also belongs to that other replica, so all Q vertices lie on its side. Opposite-side originals in mixed core form singleton or 11-set. An 11-set contains both endpoints of some protected virtual edge, whose path crosses twice in addition to 3 base-cut crossings; impossible. If none mixed, each path has even crossing count, so at most one exceptional path. All other paths constant. If original copies on different sides, take any Q not on exceptional path; its two replica paths would force opposite sides for same Q. Contradiction. If originals same side, every Q belongs to at least one nonexceptional path and so same side. Thus only singleton stars for skeleton cuts<=3.
For actual split Q, local exhaustive cut audit over254 proper subsets: internal cut k>=2, and for k<=3, k>r where r=min(number ports on either side); k+r<=3 only singleton/complement. At most one Q split for total cut<=3. Round split Q to majority port side, decreasing cut by at least k-r>=1, giving skeleton cut<=2, trivial. Then original cut equals k+r, isolates singleton. No other cuts<=3, hence cyclically4-edge-connected. Q pentagons remain, so no arbitrary-girth claim.
