## 1. Avoid whole-switch boundary pairing enumeration
Let explicit simple cubic G, incidence D, and a,b in ker D over F2 be authenticated. For fixed a and fixed zero set Z=E minus supp(a or b), FP12 gives all partners b'=b+sum_i x_i C_i, where C_i are the disjoint support(a) cycles and x_i binary. This formula holds at ANY defect count; no need to enumerate Z to solve the unguarded weighted target problem below. Let A x=t be an explicitly supplied affine guard on phase variables (relative to THIS b; change offset if rebase).
Use variables y_e in {1,2,3} interpreted as nonzero F2^2 colors, first bit y_e&1. Impose:
(1) all three incident y_e distinct at each original vertex;
(2) for e outside supp(a), first bit y_e=b_e; for e on C_i, first bit y_e=b_e+x_i;
(3) Ax=t.
These are exactly guarded extendible directions of the chart, with the second bit providing a proper companion. Proof: condition (1) is equivalent to nonzero conservation at a cubic vertex; both coordinates conserve. (2) is precisely the chart, and (3) the guard. Conversely any extendible partner satisfying chart and guard has a proper companion by definition, hence an assignment. No endpoint-parity, single-defect or spanning-slice assumption needed. Disconnected source allowed. Give each y_e any nonnegative binary-encoded integer unary cost w_e(y_e); minimize their sum. With no phase constraints and w_e(2)=1-d_e, w_e(1)=w_e(3)=0, optimum equals FP19 rho(d) for any conserved d; infinity if no proper source. Thus solve full weighted target at arbitrary cap without enumerating zero sets or even-factor cycles. Three independent runs give FP19 exact R2=max(Psi(a,b),min rho(d)) modulo relabeling, only in unguarded transition model. A chart NO is not source NO. Guards on arbitrary target color bits can also be represented as parity contributions from the relevant finite-domain variable, without changing the proof; executed implementation tests phase-only guards.

## 2. Mixed graph acquisition and exact min-plus/XOR DP
Build graph H with one vertex for each y_e, clique among the three edge variables at each original vertex (line graph), one phase vertex per C_i joined to each y_e on it, and one row vertex for EACH explicit affine equation joined to phases with coefficient1. No clique among phases of a long guard row, or among all edges of a long cycle. H is polynomial in original bit length N including the explicitly supplied matrix and costs. All local predicates and unary costs are owned by exactly one bag containing their scope; triangle scopes occur in a bag by subtree Helly property. Each individual row/phase incidence is owned by a bag containing both endpoints. Phase and color nodes are actual variables; row nodes are not variables, but partial XOR accumulators.
Given a tree decomposition of H of width w, process bags bottom-up. At separator between child and parent retain assignments of color/phase variables in separator and one bit for each row vertex in separator, its XOR contribution from all owned incidences in child subtree. Retain minimum attained cost and actual witness for each key. Combine children only with consistent shared variable assignments; XOR row contributions and add owned local costs, each counted once. When a row is forgotten check its accumulated bit equals its required RHS: connectedness of its occurrence subtree ensures ALL its incidences have been processed there. Empty rows are tested too. Forgotten variable assignments cannot appear outside subtree. Conversely any global solution restricts to matching messages, and any combination of actual witnesses agreeing on separator extends over their union, with row bits sufficient to preserve every outside continuation under THIS guard. Induction proves exactness and cost minimality. Store actual backmaps, not arbitrary linear combinations. At root all rows checked and source proper coloring reconstructed, chart, guard and cost verified. This is min-plus DP with XOR messages; no count oracle, no randomized cancellation. Same procedure works for any finite domain of constant size and bounded-arity local factors with scopes in bags, and for high-arity parity rows as above. No claim for arbitrary global constraint relations.
A bag has <=w+1 nodes, at most 3^(w+1) assignments/partial-row states, conservatively 2^O(w) pair work per child join. Use polynomial size decomposition; explicitly charge owner lookup, graph creation, all local assignments incl failures, joins, bit operations on row indices and binary costs, retained witnesses and final scan. T,S<=2^O(w) poly(N), cumulative <=(T+1)S. Cost comparison is exact; bit length of sums at most max input weight length+O(log m). No preloaded guard simplification. Acquisition: Korhonen, arXiv:2104.07463 abstract: deterministic time 2^O(k) n gives width <=2k+1 or certifies tw>k (Bodlaender et al. 2016 5-approx also sufficient). For a fixed constant C, set k=ceil(C log2(N+1)); if promise tw(H)<=k holds, obtain verified tree decomposition then exact terminal in poly(N). Otherwise DECLINE if acquisition fails; no NO from a width failure. The actual test code uses verified NetworkX min-fill, NOT the published approximation implementation; its capped heuristic has no completeness theorem. Row basis matters: duplicating a dense parity equation r times creates K_(r,q) in H, treewidth at least min(r,q), though solution set unchanged. ## 3. Strict separation from ordinary carving width of entire switches
Even h>=4 and odd d>=3. Make h disjoint cycles of length 2d, vertices v(i,j), i mod h, j mod 2d. For j=0..d-1 join v(i,d+j) to v(i+1,j). At last-to-first gap remove j=0,1 wires; introduce s,t and join their four endpoints, even j-indexed original vertices to s, odd to t, and add st. (Parity of original index 2di+j is j parity.) Simple connected cubic, bipartite since d odd and s opposite even, t opposite odd. Let a include all cycle edges. Let b include every wire except st plus alternating phase0 matching along each cycle. Every original vertex degree2 in a and b, s,t degree0 in a and2 in b; sole zero st. T-join quotient odd vertices s,t have unique singleton joining edge st, min defect1. Every one of 2^h phase assignments yields spanning b' and even cycles by bipartiteness. Thus every phase word has proper extension. Impose h/2 equalities x_(2i)=x_(2i+1), and the independent global parity sum_i x_(2i)=1. Rank h/2+1, exactly 2^(h/2-1) feasible phases. No need for a source solution in acquisition.
Contract whole cycles to switch nodes, all four terminal ends to root. For any nonempty proper subset of the h switches, the ring has >=2 crossing gaps with d wires each. Replacing two wires at last gap by root wires cannot decrease cut size: if endpoints on opposite sides, replacement preserves contribution, both inside adds4, both outside adds0. So all proper nonempty switch regions have >=2d ports, root-excluded full group has four. Min proper cut exactly2d via a singleton away from altered gap. FP18 ordinary carving width >=2d including leaves; even if allowing high-degree leaves, no first binary merge fits K<2d (h>=4). For h=Theta(d), n=2dh+2, this is Omega(sqrt n), with linearly growing (in h) guard rank. Whole-switch explicit table DP or enumeration not certified polynomial by its usual width bound.
Yet H has CONSTANT treewidth. Proof: view each gap as a two-rail ladder, right half of cycle i and left half of cycle i+1. Within ladder walk columns in order with bags containing endpoints of ladder and two consecutive columns. Between ladders insert a connector bag containing the four endpoints of each adjacent ladder. Keep endpoints of first ladder and s,t throughout, to handle wrap and altered wires. Each original-vertex bag size <=14; occurrences intervals, all original edges covered. Replace each original vertex in bag by all at most3 incident source edge variables. Occurrences of edge variable form union of endpoint intervals meeting in at least one bag; each local triangle covered. Add phases i,i+1 to every ladder i bag, phases i,i+1,i+2 to connector following ladder i (omit last connector), keep phase0 throughout to handle wrap. Every cycle edge/phase incidence covered and phase occurrences connected. Add equality row i to first bag of ladder 2i, and global row to every bag. Each guard incidence covered. Total bag size <=14*3+4+2=48, hence width<=47 for all h,d, and decomposition explicit polynomial. This proves exact arbitrary unary weighted guarded chart solution in poly(N) on this family, without requiring the decomposition supplied. Family bipartite, contains small cycles, no high-girth or cyclic4 claim; not a hardness result. This is a strict width-parameter separation, not a refutation of all possible FP16/18 implicit methods. Retaining local companion colors avoids representing full path pairings: useful for arbitrary multiple defects or final color guards, not sufficient for arbitrary future cross-direction continuation.
