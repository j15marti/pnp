## 1. Exact symbolic conflict acquisition
In an affine syndrome chart h=h0+Bt, each edge clause forbids simultaneously p_i=f(t),p_j=g(t), where f,g are affine over F2. Make a directed graph of affine literals (i,f), with edges (i,f)->(j,g+1) and (j,g)->(i,f+1). For an affine slice, reduce the functions modulo its equations, so equal functions at the same phase are the same node. Two paths between (i,f) and (i,f+1) in both directions certify infeasibility of the whole slice. Replay each edge using its original clause and exact reduced affine label. If a pair of implication paths has joining conditions of rank 1, the unique nonzero normal is a difference of coefficients of two incident affine signs at the same phase (including the path closing conditions). Thus enumerate the O(m^2) possible such differences, both RHS, and symbolic SCC. Complete for rank <=1 certificates of this uniform path type, not for all semantically infeasible hyperplanes. Rank0 rejects the current chart; rank1 excludes the certified hyperplane and retains its complement, reducing dimension by 1. With at most k contractions all search, chart substitution, SCC and lifts polynomial; DECLINE if no certificate and no witness.

If two distinct refuted cosets have identical normal space of dimension d, their union is one codimension d-1 affine cell (binary field). With fixed d, enumerate spans of at most d original joining normals, all 2^d cosets, test uniform paths and close under parallel-coset unions; any derived normal space stays in an original span of dimension <=d, so 2^O(d^2) possibilities per original span. Polynomial for fixed d, no proof of universal depth. Target sample z=[2,3,1,1,3,2,3,1,2,3,3,1,2,2,1,1,2,0] on FP01 E0: every r stalls under rank1; rank2 normal-span enumeration 7936 slices per r, certifies respectively 2,2,13 cells for r=1,2,3, no parallel merges in those cells. This is not an unrestricted barrier.

## 2. Joint affine implication saturation
Encode each literal by affine form L=p_i+f(t) (true iff L=0). At any point reduce forms modulo accumulated affine equations, include nodes 0,1 and implication 1->0. Mutual implication of L,M forces L+M=0; a path L->L+1 forces L=1; a path 0->L forces L=0. All sound on full joint (h,phase) domain. Gaussian elimination, preferring phase pivots, and repeat; each productive round strictly raises equation rank, at most number of variables. Test resulting representative h using original FP06 exact 2SAT; if not solved or refuted, decline. This directly exchanges equations among overlapping symbolic DAG paths, but not universal.

## 3. New positive terminal: common cyclic intervals
For every good vertex v define its source-aligned signature lambda(v)=(C_1(v),C_2(v),C_3(v)). Each class of equal signatures has three induced circular orders obtained by filtering the three projected cycles to the class. Candidate common interval I is a subset contiguous in all three circular orders. It need not be a semantic module and no equality on h is asserted. For odd |I|, its syndrome column sum is the shared column a_class. Any repair syndrome which is the XOR of <=2 odd common intervals is discoverable in polynomial time. Enumerate each class's O(s^2) cyclic intervals in view 1, check contiguity in other views (boundary crossing count <=2). Sum across classes <=n^2; enumerate compatible interval pairs by XOR of signatures against b(r), including zero and one interval. Test each syndrome by original exact fixed-h SCC and verify source coloring. At most O(n^4) candidates, each explicit and polynomial; O(n^5) conservative indexed operations with ordinary graph and candidate scans, plus bit indexing etc. Even intervals not covered by this particular terminal. General fixed number q of odd/even common intervals permits n^{O(q)} time, not FPT guarantee. Arbitrarily large branch count allowed in two controls. No contraction, module recognition, target witness or relaxation accepted as SAT.

## 4. The FP06 linear branch-count barrier is polynomially repairable by common intervals
For odd L, FP06 repeated triangle expansion replaces each good base vertex by L-vertex three-pole with unique proper extension for boundary. A bichromatic path for each color pair traverses ALL its vertices in one contiguous path: true for triangle and preserved under replacing a vertex on path by triangle. A base repair with exactly two cyclic-rotation vertices therefore has branch support equal to the union of two L-vertex groups. In FP06's two-copy isochromatic Petersen-four-pole lift, each bichromatic path entering a module from one replica exits at the other port of the same pair; otherwise swapping along path contradicts pair equality. Thus projected cycles through original vertices stay in one replica, with internal paths spliced through Q. No internal Q vertex has a triple signature equal to an original vertex of replica i: choose the projection excluding the color of its pair belonging to replica i; in that view no cycle through Q visits replica i (it is internal or in the other replica). The two expanded branch groups each have identical triple signature internally, and each forms a contiguous interval in every corresponding filtered circular order. They are odd (size L). Change paired wire colors using bichromatic paths as FP06, adding no internal branches. The graph-only interval catalogue includes the two groups, even if signatures coincide (XOR handles this), so exhaustive interval-pair search always recovers some coloring. This covers the entire FP06 barrier family, notwithstanding minimum branch count 2L and n=140L+20. Search ordering may prioritize half-class intervals and first pair per compatible signature stream; not relied upon in proof.
