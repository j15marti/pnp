## 2. Complete non-greedy cut-budget acquisition
Let J be rooted interaction multigraph, vertices q original free switches plus root identifying four terminal ends. Edges are indexed wires (loops harmless). Assume J connected, test explicitly. For S subset of switches, B(S) original port ends in S whose wire exits S; c(S)=|B(S)|=|delta_J(S)|. Root not in S. Define admitted binary merge tree: leaves any singleton primitive (may have many ports but at most two legal words), each nonsingleton internal node S is disjoint union of two children and c(S)<=K. K fixed positive integer. No minimum-cut premise and no confluence premise. Define T(S) complete attainable boundary-pairing table on B(S), retain one source phase witness per pairing (no guard yet). For child tables T(A),T(B), compose each pair of words with internal connecting wires and trace connected components. Every boundary component is a path between exactly two exposed ports; internal closed circuits unmarked and irrelevant. Thus parent relation exactly, by independence and disjointness. Different merge trees produce identical table (up to witness choice). Even singleton self-wires contracted exactly.
Discovery: initialize all singleton tables. Queue newly admitted sets; process each unordered pair of acquired sets once. For disjoint A,B whose union not yet considered, compute intrinsic c(A union B) (and rank criterion below). If admitted, construct exact union table, enqueue. If not admitted no alternative split can change its intrinsic tests; mark checked. Keep empty tables as exact tables, not silently prune. Induction on any admitted binary tree shows every node acquired unless goal already acquired. If root set never acquired, DECLINE (not NO). Root table covers every phase assignment satisfying chart and exact boundary relation, not only those compatible with a chosen derivation.
Key counting proof: in connected rooted J, delta(S)=delta(T) implies indicators differ by constant along every edge; root excluded in both, so S=T. Thus number of distinct nonleaf admissible sets <=sum_{i=0}^K binomial(M,i), M wire count. Leaves add q. For fixed K this is polynomial, even though 2^q sets exist. Each pair processed once, O(L^2), L=q+sum binomial(M,i). All failed unions cached as exact masks and charged. Leaf tables size <=2, admitted internal tables <=(K-1)!! for even K (use max over even boundary<=K and empty=1). This is a complete deterministic polynomial acquisition theorem for the stated width class, even if there is no unique greedy reduction order and no supplied tree. It is an elementary carving-like dynamic program; unlike ordinary carving-width, high-degree primitive leaves may be admitted at constant table cost. It is XP in K, NOT a universal FPT or logarithmic-K polynomial bound. For independent disconnected interaction components without guards, process separately/choose any phases outside active endpoint obligation; implemented solver explicitly DECLINEs on disconnected rooted J, including when guard correlations would make dropping components unsafe.

## 3. Affine guard cut-rank theorem
Let free phase vector x in F2^q, supplied guard A x=c; fixed original phase contributions absorbed into c, and original edge-linear guards translate to phase-linear guards. Let a_i columns of A, U_S=span{a_i:i in S}. Each partial word contributes syndrome u=sum_{i in S} a_i x_i. A necessary and sufficient condition for extension to the affine guard alone by outside phase bits is u in U_S intersect (c+U_complement). (Not sufficient for outside routing.) Test membership by Gaussian elimination. If c outside total column span reject chart guard exactly. If feasible, this affine intersection has dimension
lambda(S)=dim(U_S intersect U_complement)=rank(A_S)+rank(A_complement)-rank(A).
Retain exact table keys (boundary pairing P, syndrome u) with one full source phase witness per key, only for u satisfying extension test. The number of keys is at most maxpair(K)*2^lambda(S), not 2^rank(A). Singleton still <=2 words. For each child combination, compose pairings and XOR syndromes, filter u by parent's extension test. Induction: any retained parent word can be formed by retained child words, because an outside guard extension together with the other child's actual word proves each child is algebraically extendible. Conversely every accepted composition corresponds to real independent child phases and has exactly the stored signature. Guard correlations never dropped. At root U_complement=0, u=c. Reconstruct and verify complete phase and source witness. The interface equivalence (P,u) is sufficient for all fixed outside phase words and boundary routing contexts in this chart. It does NOT guarantee equality of future cross-direction continuations or unknown new guards.
Add intrinsic lambda(S)<=ell to nonsingleton tree admission. Same queue discovery complete (property intrinsic, not split-dependent). Number of acquired sets still bounded by cut count, and per pair work <=2^{O(K log(K+1)+ell)} poly(N). Overall time <=N^{O(K+1)} 2^{O(K log(K+1)+ell)}, peak storage <=N^{O(K+1)} 2^{O(K log(K+1)+ell)} bits, polynomial for fixed K and ell<=C log N for any fixed C, even rank(A)=Theta(N) in dimension terms. Exact source preprocessing, matrices, all failed probes, labels, pair composition, witnesses, output charged. No enumeration of total affine solution space. Can use explicit vector syndrome keys (polynomial bit length) rather than basis-coordinate bookkeeping. The implementation stores full bitmask witnesses, not an uncharged recursion. All input N original explicit bit length including guard matrix and graph.
Connection to literature: for each switch assign subspace span of unit coordinates of incident wire IDs in one direct-sum summand and a_i in disjoint guard summand; assign root incident wire units and no guard column. For any root-excluded S, intersection dimension of the two sums equals c(S)+lambda(S). Jeong, Kim, Oum (SIAM J Discrete Math 2021, DOI 10.1137/19M1285895) abstract gives FPT construction for subspace branch-decompositions of bounded intersection width. This supplies an exact representation for a possible alternative acquisition method if all leaf and internal cuts satisfy a fixed combined bound. No logarithmic-width polynomial guarantee imported from unspecified FPT dependence; no execution of that algorithm. Our self-contained count-based method admits high-degree leaves and log guard rank with fixed physical cut budget. Kashyap, Matroid Pathwidth and Code Trellis Complexity (2008, DOI 10.1137/070691152), abstract connects rank-state complexity and matroid pathwidth, not general routing. Carving-width precedent: Belmonte et al DOI 10.1016/j.dam.2013.02.036 definition inspected; He-Huang-Saranurak arXiv:2401.10856/SODA2024 minimum cut cactus abstract, not used as composition theorem.

## 4. Source-authenticated arity and width barriers, plus positive acquisition
For h>=3, d>=3 take h cycles of length 2d indexed cyclically. Between consecutive cycles i and i+1 join odd port 2j+1 of i to even port 2j of i+1 for j=0..d-1. At last-to-first gap remove two distinct wires, attach their freed odd ends to new vertex s and even ends to t, add z=st. For d>=4 take j=0,2 removed; for d=3 take 0,1. Graph simple, connected, cubic, bipartite by parity with s even/t odd. n=2dh+2. Let a all cycle edges; b all wires except z plus one alternating matching in each cycle. Both conserved, sole zero z; b spanning even by bipartiteness. Hence colorable, every phase assignment yields proper extension (no claim that graph is difficult).
Root-excluded whole switch set has boundary4. Every proper nonempty set of switches in original d-fold interaction cycle has at least 2d crossing wires. Replacing a wire by two root stubs leaves its cut contribution unchanged if one endpoint inside, increases by2 if both inside, unchanged if neither. Thus every proper nonempty switch set c(S)>=2d. Non-wrapping prefixes 1..j, j<h have c=2d because removed-gap endpoints split. Thus at K=2d binary prefix merge tree exists, complete acquisition theorem applies for fixed d. For ANY fixed merge arity r>=2, choose h>r. If K<2d no first nonsingleton merge is legal, as it cannot be the full set. In particular K=4 fails for arbitrarily many hexagonal switches, even allowing any fixed arity, while K=6 solves family by binary acquisition. At h=d growing, n=2d^2+2 and every fixed-arity derivation needs port cap >=2d=Theta(sqrt(n)); leaf exceptions do not help. Restricted structural acquisition barrier, not time lower bound or failure of other tracks. d>=4 sources also girth6: bipartite, each wire endpoint unique except s,t; same-gap wire endpoints have same local parity, no 4-cycle via two wires; s,t attach to nonadjacent same-parity vertices distance>=4; no 4-cycle using st since all its nonterminal neighbors have their sole wire to their endpoint. Two intact adjacent wires and length2 paths give a 6-cycle. No arbitrarily growing source girth claim.
Cyclic 4-edge connectivity for d>=4: any cut<=3 splits at most one cycle, since splitting each costs >=2 cycle edges. If none split, differing cycle sides force crossing two gaps each >=d-2 wires, sum>=4; all cycles then same side and only terminal singleton can have cut<=3 (both terminals opposite cut4). If one split, unsplit cycles form a path whose gaps carry >=d-2>=2 wires, so all unsplit cycles same side (only <=1 external crossing allowed). If neither terminal opposite, each minority vertex of split cycle has its wire crossing, hence at most1, singleton. If both opposite, at least one terminal attaches to unsplit cycle, forcing >=2 external crossings. If exactly one opposite, st consumes remaining allowance; both its other neighbors must be minority vertices of split cycle, and all other minority vertices would have wire crossing, so precisely those two same-parity nonadjacent vertices; their cycle cut is4, impossible. Thus no nontrivial cuts<=3. Independent finite check all C(51,3)=20825 edge deletions on d4,h4 confirms only singleton cuts; no exhaustive large source cuts.
Guard stress: impose x_0=x_1, x_2=x_3,... on consecutive switches, rank floor(h/2), free dimension ceil(h/2). Every prefix has affine cut rank at most1 (exactly one pair straddles boundary when prefix odd and not last). Thus exact polynomial acquisition for d fixed with ell1 despite exponentially many guarded phases and linearly growing total guard rank. In three-switch h3,d3 source, unguarded canonical pairing witness masks 0,4 in executed order. Guard x_0=1 excludes both; exact guarded table has same two boundary pairings with witnesses1,7. More generally for any two fixed representatives of its two boundary pairings there is a nonzero linear functional annihilating their difference and a target opposite their common value; all eight phases originally attainable, so guard-independent representative selection alone can discard all witnesses. Retaining original structure or syndrome avoids this. No claim that known guard cannot guide representative choice.
