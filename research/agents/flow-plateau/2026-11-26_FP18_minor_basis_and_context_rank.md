## 1. Setup and cofactor identity
Use FP13/17 normalization of authenticated conserved binary a,b, sole zero z=st. Outside support(a) partner edges are fixed except z; every spanning partner forces a degree-two pattern on each support cycle, with at most two alternatives, and fixed paths contract retaining source IDs. Free cycles are binary switches with two perfect-pairing words on their ports. Fixed wiring W pairs ports and four protected ends. A spanning partner extends to a proper coloring iff s,t share a selected cycle: its cycle parity equals number of defective endpoints mod 2 (count class changes between a edges and other edges). Split s,t into two ends each; success iff some pairing joins opposite endpoint classes. Reconstruct partner, then another binary flow selecting all outside-partner edges and alternating edges on each even cycle. Check conservation and union=E. Only the selected singleton chart and two-direction escape are decided; not arbitrary multi-step plateau or new guards on final companion.

For p exposed ports, actual boundary word P is a perfect matching, identified with its p-by-p symmetric permutation matrix P over F2. Let C be matrix of arbitrary partial matching on ports other than distinct i,j. Consider formal variable zeta and matrix P-zeta C. Its constant term P is invertible, P^2=I, so over F2[[zeta]]:
(P-zeta C)^(-1) = (I-zeta P C)^(-1) P = sum_{l>=0} zeta^l (P C)^l P.
Row i of this expression follows the unique alternating walk beginning with a P edge, followed by C, then P, etc. Because i,j are C-unmatched and graph P union C has degree at most two (parallel copies allowed), this walk starts at a path endpoint, terminates at another C-unmatched endpoint and cannot enter a cycle. The (i,j) entry is exactly zeta^l if the endpoints share a path, zero otherwise. Thus
F_{ij}(P,C) = adj(P-zeta C)_{ij} != 0 as a polynomial iff i,j are connected in P union C.
Multiplication by determinant preserves nonzeroness, since determinant has nonzero constant term. No random evaluation, cancellation assumption, or counting oracle. Works also for same edge in P and C, which is an irrelevant closed two-edge circuit. This is not the usual Hamiltonian matching matrix (which requires a single spanning circuit).

## 2. Universal single-exponential representative basis
For each actual word P define a binary feature vector v(P) indexed by all (R,S) row and column subsets of equal cardinality, entries det P[R,S] in F2 (empty minor=1). Dimension D_p=sum_{h=0}^p binomial(p,h)^2=binomial(2p,p)<=4^p. Permutation minor is 1 iff P maps R onto S, so direct construction is deterministic 2^{O(p)} work and space, even dense zero padding. The cofactor deleting row j, column i of P-zeta C expands by multilinearity into terms
det P[R,S] * det C[Rbar,Sbar] * zeta^{|Rbar|},
where complements taken inside retained cofactor row/column sets, signs vanish in F2. This follows by choosing P rows or C rows and Laplace expansion across chosen rows. Consequently F_{ij}(P,C) is an F2-linear function of v(P) into F2[zeta] for every context. Same features cover all i,j,C. Select a maximal independent subset of original feature vectors by Gaussian elimination, retaining the associated ACTUAL pairing and original witness for each independent row. At most D_p words. If some original word connects i,j in C, its cofactor is nonzero; if all basis rows had zero cofactor then their binary linear combination would too, contradiction. Conversely every retained row is a real word, so no false positive. Empty minor preserves nonempty relation even when p=0 or no terminal demand uses the region. Do not output arbitrary linear combinations as legal words. This is exact preservation of existential single-terminal compatibility, not full relation, simultaneous multiple path demands, counting, or arbitrary future cross-direction moves.
Cost for explicitly acquired r candidates: feature construction and elimination <=r*2^{O(p)} poly(N), storage <=2^{O(p)} poly(N), one full source bitmask per retained row. No need to enumerate all external contexts. A region with p logarithmic may have factorially many actual words; single-exponential representative cap is a genuine asymptotic improvement over FP17 complete pairing tables. The known rank-based connectivity DP literature motivates this; no priority claim and no Hamiltonian-specific rank imported.

## 3. Compositional guarded DP and exact logarithmic-width theorem
Let guard A x=c on independent original phases, columns a_i. For region S retain separate basis per syndrome u=sum_{i in S}a_i x_i that can extend to guard alone, i.e. u in im A_S intersect (c+im A_complement). Reject inconsistent total guard. As FP17, at most 2^lambda(S) such syndromes, lambda=rank A_S+rank A_complement-rank A. Each table has <=4^p*2^lambda actual witnessed words. When composing disjoint children, try pairs of retained words, join internal wires by tracing components, XOR syndromes, filter by outside span, and reduce parent rows separately by syndrome.
Exactness despite not retaining full child relations: fix any actual parent word and external context with a terminal connection. Its selected path visits a child zero or more times. Remove that child's transitions from the path. If visited, first entry and last exit are distinct child ports; all intervening exterior path segments define a partial matching of other child ports. If parent terminal itself is in child it is simply the corresponding endpoint with zero-length exterior prefix/suffix. Child representative of same syndrome preserves that single connection by theorem 2. Reinsert its actual word, keeping other child and exterior fixed; terminal path survives, guard contribution identical. Repeat for other child with the new path. If child unused, choose any representative of same syndrome (nonemptiness preserved by empty minor). Thus every actual YES context has a candidate pair of retained witnesses, and parent reduction preserves it; converse is direct. Internal unmarked closed circuits irrelevant. Any true parent guard-extendible assignment has guard-extendible child syndromes by using actual other child and outside word, so filtering cannot drop all witnesses. For p=0, retain existence per syndrome via same argument. At final four-end interface query opposite endpoint classes, recover stored actual source phase word, verify guard and complete proper flow. Exact chart NO only; failed width acquisition is DECLINE.

## 4. Acquire logarithmic physical width without supplied tree
Let rooted interaction multigraph J have switches and root (the four ends), wire edges distinguishable; normalize self-wires inside primitive words, then omit loops for width calculation. Ordinary carving decomposition has leaves all vertices incl root and degree-three internal nodes, each tree edge partitions leaves with at most K crossing wires (this bounds singleton degrees too). Form ordinary simple line graph L(J) with one vertex per indexed nonloop wire, adjacent iff wires share endpoint. Any carving tree gives a tree decomposition of L: at a tree node put all wires whose leaf-to-leaf path traverses node. Wire occurrence subtree connected; wires incident to same original vertex meet at its leaf. At internal node every traversing wire uses two of the three incident tree edges, so bag size <=3K/2; leaves <=K. Thus tw(L)+1<=max(K,floor(3K/2)). 
Conversely from any tree decomposition of L, each switch's incident wires form a clique, hence are contained together in some bag (connected-subtree Helly property). Assign switch to such bag, root similarly, root tree at root's assigned bag. Produce a binary merge tree bottom-up: at each bag combine all assigned nonroot switches and all nonempty child-subtree groups in any binary order. A wire crossing such a partial union has endpoint owners assigned to different components of the decomposition tree minus this bag, or one assigned at bag. Both assignments contain that wire, so its connected occurrence subtree includes this bag. Thus each cut <=max bag size, including leaves and final root-excluded set. Empty bags/isolated vertices and disconnected J can be handled with a joined tree decomposition; root remains separate. All transformations polynomial including O(M^2) line graph construction.
Use established deterministic 5-approximation of treewidth (Bodlaender et al., SIAM J Comput 2016 DOI 10.1137/130947374, abstract explicitly gives 2^{O(k)} n time, width<=5k+4 or tw>k). For promised ordinary carving width K=O(log N), apply with k=ceil(3K/2) (or a fixed log cap), convert result; obtained physical width O(log N). Then section3 gives uniform polynomial acquisition and exact chart decision WITHOUT supplied merge tree for unguarded case, and for guard total rank O(log N), or if acquired tree's actual guard cut rank O(log N). We do not prove simultaneous approximation of physical and guard rank if only existence of a joint low-rank tree is assumed; acquired tree can have high guard cuts. Also does not cover FP17 exceptional high-degree leaves unless an independent productive decomposition found. General high-width graphs/unsafe charts remain open. Executed code uses NetworkX heuristic min-fill on line graph, verifies each bag and cut, caps at 10 ports; does NOT implement guaranteed approximation. Asymptotic theorem uses published algorithm. No use of heuristic as a proof of uniform width.

## 5. Exponential lower bound for explicit witness dictionaries and separated linear feature dimension
For k>=1 construct connected region of 2k square switches, test squares A_i and backbone squares B_i. Each cyclic square has ports 0,1,2,3; phase0=(01)(23), phase1=(03)(12). Internal wires A_i.2--B_i.1 and B_i.2--B_(i+1).3 for i<k-1. Region connected, wire interaction tree; all switches individually safe. Exactly p=4k+2 exposed ports. Test entry A_i.0, two alternative exits A_i.1, A_i.3 exposed, spare A_i.2 internal. For bit word y of length k-1 define external partial context C_y joining exit (1 if y_i=0 else 3) of A_i to next test entry A_(i+1).0. Fix SAME query endpoints i=A_0.0 and j=A_(k-1).1 for all y. All other exposed ports unmatched. Path enters each test at port0, immediately exits via one of two exposed neighbors; wrong exit is unmatched, so cannot connect. Correct exits lead to next entry. Backbone cannot be entered from the designated test entry. Thus query YES iff test phases equal y followed by 0, regardless of backbone phases.
Choose actual row P_x with test bits x followed by0 and all backbone phases0. For the 2^(k-1) contexts C_y response matrix is identity. All rows necessarily distinct pairings. Moreover ANY actual pairing witnessing query y must come from test phases y0, so each actual pairing can answer at most one of these contexts (even allowing alternative backbone phases). Every context-equivalent dictionary of actual pairings must have >=2^(k-1) words, even if only fixed endpoint pair matters. Boolean response matrix rank >=2^(k-1) over EVERY field. Cofactor matrix over F2(zeta) similarly diagonal nonzero submatrix; exact bilinear factorization of either indicated matrix requires at least that dimension. This refutes universal polynomial-size explicit dictionaries and universal polynomial-dimensional separated linear features in physical port count/source size. No lower bound on arbitrary compact representations, query computation, total decision time or P!=NP.
Source authentication: mirror the region with reversed bipartition labels, connect all exposed ports to mirror counterparts except two backbone exposed ports. Replace those two mirror wires by attachments of odd endpoints to new s (even), even endpoints to new t (odd), add sole defective edge st. Both original regions connected, remaining mirror wires connect them. n=16k+2, simple connected cubic bipartite (girth4). a all square-cycle edges, b all other wires except st plus one alternating phase on each square (both regions). Each original vertex has degree2 in a,b, s,t degree0 in a and2 in b. Sole zero st, every b factor even by bipartiteness; hence explicit proper extension. Minimum fixed-a defect exactly1 since quotient isolated s,t have degree3 odd, st is unique singleton T-join. Every test-region phase combination extends to source-authenticated chart. Thus bound >=2^((n-18)/16) in vertex count, exponential in p; in explicit bit length N=O(n log n) still superpolynomial. Contexts C_y are arbitrary partial interface tests, NOT claimed to be actual exterior configurations in one fixed source. No high-girth or cyclic4 claim for this square construction. Positive control: every single query on this exact implicit region is deterministic polynomial via FP16 ordinary matching. Delete unused exposed ports; baseline W union C covers all except i,j; perfect matching iff symmetric difference gives augmenting path. Disjoint transitions used in a square must belong to common phase (either one edge or opposite edge pair). Choose remaining phases arbitrarily and trace actual word. Therefore the same exponential dictionary barrier coexists with easy query acquisition, including all source instances. It cannot be promoted to runtime hardness.
