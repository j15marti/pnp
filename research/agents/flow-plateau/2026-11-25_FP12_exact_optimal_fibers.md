## 1. Exact fixed-direction chart for every cap
Let G be an explicitly encoded simple cubic graph, D its binary incidence, fixed a in ker D, A=supp(a), F=E-A. For b in ker D the zero set Z is a subset of F, and b|F=1_F+1_Z in F2. Contract every connected component of (V,A), including isolated vertices, to obtain quotient multigraph Q. Retain all original F edge identities, including loops and parallel edges. Let T be odd-degree vertices of Q (loops count twice). Then Z admits a b exactly when boundary_Q Z=T. Necessity by summing vertex conservation over each contracted component. Sufficiency: place b=1_F+1_Z outside A, then solve the incidence equation on A using a spanning forest; process leaves towards roots. The component parity condition is exactly consistency. In cubic graph each nontrivial A component is a cycle (binary even subgraph). If C_1,...,C_c are their edge masks, every lift with the same Z is precisely b_Z + sum_j x_j C_j, x_j in F2. These disjoint cycles are a basis for flows supported on A. Thus fixed-a sublevel at cap r is a disjoint union of <=sum_{i=0}^r binom(|F|,i) affine cosets of one common phase space. A chart consisting of indexed defect sets, canonical forest lifts and one common basis is exact, not an affine hull of the union. For r=1, T empty allows empty defect set and every quotient loop, |T|=2 allows exactly individual nonloop edges joining those two odd vertices, larger |T| allows none. If |T|=2 with a feasible singleton then min is exactly1. At r=1 charts can be constructed in O(m^2) indexed work and O(m^2) bits for stored full masks (plus index overhead); streaming forest solve or conservative polynomial bit simulation. For fixed r, O(m^r poly(N)) time/storage, not uniform polynomial for variable r. No matching optimization needed to list singleton defect sets. Arbitrary nonnegative additive secondary cost of b bits on an unguarded fiber is independently minimized on each disjoint cycle; choose best over charts. Such cost is not a proved escape metric.

## 2. Sparse generator theorem, including guarded and disconnected cases
At state (a,b) with defect set Z, add generators (a,b+C_j) for each basis cycle and (a,b+b_Z+b_W) for every other feasible defect set W in chart. The latter has exactly W as zero set, retains all phase coordinates relative to the chosen forest lifts, and is conserved. These moves generate the entire fixed-a star: choose W, then toggle exactly the necessary basis cycles. Path length <=c+1; each intermediate has zero set Z or W. Consequently an r-cap global state graph with every arbitrary retained-projection move has precisely the same connected components as this sparse generated graph plus coordinate relabelings (or direct conjugation for the 3 directions). At r=1, O(m) candidate moves per state, polynomial acquisition, despite exponential original fanout. For a nonincreasing escape path, replace each equal-budget move by equal-budget generators and the first descent by one defect-set change; stop on descent. Do not allow cap-preserving increases when asserting monotonicity. GL(2,2) acts by swapping a,b and replacing b by a+b, both exact relabelings; with non-invariant guards only use permitted relabelings or directly retain desired projection via coordinate change and transformed guard. For linear guard L_a a+L_b b=g over F2, solve L_b C x=g+L_a a+L_b b_Z for each Z, discarding inconsistent cosets. Common homogeneous phase basis is C ker(L_b C); use chosen guarded lifts and this basis in same generator proof. Edge-nonzero guards are enforced by forbidding selected indices in Z; pin guards are affine. Arbitrary nonlinear guards not claimed tractable. Disconnected G included; solve local components and sum defect costs, global cap respected. A guarded empty star is not global UNSAT.

General optimum-face fact: for fixed a, let b and b' both minimize nonnegative weighted zeros outside A. Their difference decomposes into edge-disjoint simple cycles of G. For a cycle, toggling changes objective by sum of weights on formerly covered outside-A edges minus weights on formerly zero outside-A edges. Every such change is nonnegative by optimality of b. Total is zero, so each is zero; all cycles may be toggled sequentially within optimum face. For nonoptimal endpoints, ordering cycles by negative then zero then positive yields a path under max of the two endpoint costs, but not necessarily globally nonincreasing after first descent. This statement is unguarded; a cycle may violate extra guards. No claim that all simple cycles can be listed in polynomial time for arbitrary cap.

## 4. New falsifier: optimal union is not a binary affine space

Retain the disjoint indexed cosets or a one-hot selector with exact cardinality, not just linear span. Same issue appeared in Petersen and FP01.

## 6. Exact next-direction acquisition target
For unguarded fixed a of min1, a two-step escape retaining a then another direction exists iff some chart contains b which is a spanning union of even cycles. Reason: a binary flow x can occur in a proper pair iff it is a spanning 2-factor with only even cycles. Necessity: at every vertex the three nonzero colors appear, and the two colors on its support alternate. Sufficiency: put second bit1 outside support and alternate its bit on each even cycle. The chart is invariant under b->a+b, so both possible next directions are covered by the same search. Thus for each singleton Z solve the exact prescribed-membership even-2-factor problem: require all F-Z edges in b, forbid Z, and choose phases on A. This is an exact reduction, not a polynomial decision theorem. Enumeration costs O(m*2^c poly(N)); it is polynomial for c=O(log N), not generally. A verified proper witness bypasses plateau entirely; a failed two-step search is only a local obstruction.
