## Exact connected repair
Given a simple cubic graph and authenticated F2^2 flow z with sole zero e0, let w be ANY proper coloring. Edge disagreement support D={e:z_e!=w_e} has components in the edge-induced graph; different components have disjoint incident vertices. Replace z by w only on the component containing e0. Each incident triple is then either the original or target triple (unchanged edges agree). Both defective endpoints are repaired; other triples proper. This is an atomic simultaneous update, not a sequence of allowed single-direction moves.

Direct search for a repair touching <=s vertices: pin e0 to one of three nonzero colors; both endpoints pending. At each step choose a pending vertex deterministically. Each pending vertex has at least one already pinned changed incident edge, so at most two local permutations of 1,2,3 consistent with all pinned incident edges. Permanently assign the triple within that branch, enqueue unprocessed endpoints of newly changed edges, reject conflicting pins or >s distinct processed plus pending vertices. Stop when pending empty; all unprocessed vertices retain original triples and both defect endpoints processed. Verify output. A target restricted to its connected disagreement component supplies a surviving branch, every processed vertex touches a changed edge. At most 3*(2^(s+1)-1) search nodes, each polynomial in original explicit bit length including input validation, adjacency, branch undo, copies and witness checks. O(2^s poly(N)) time, polynomial per-branch storage; complete for support cap, failure UNKNOWN for original problem. No semantic absorption, module recognition, or monotonic physical replay.

## Application to high-girth FP04 family
Keep all replicas except distinguished one unchanged; choose a proper core coloring and extend only four-poles incident to distinguished copy. At most 12+8*17K touched vertices since each protected wire has K modules; unchanged other copy boundary values always extend with any nonzero paired colors by exact FP02 table. This witness exists without being known to direct search. Interaction graph has d=17K and girth>2K, so radius-K nonbacktracking paths from a vertex have distinct endpoints; |R|>=d(d-1)^(K-1)>=(d-1)^K. Thus K<=log2(n)/4, n lift order. Direct search with cap min(n,ceil(12+34log2(n))) is uniform and polynomial on displayed family, even though no bounded overshoot works universally in original single-direction model. Large exponent is not a practical guarantee. This is a family upper bound, not a general solver.

## Falsifier for universal logarithmic support
Use same serial equality four-poles for all 17 protected edges, L layers, interaction graph R=K_(17L,17L) with cyclic-shift edge matchings. No large girth needed here; FP04 small-cut proof uses core 3-edge connectivity and connectivity of R-v, plus exact four-pole internal cuts, so still cyclically 4-edge-connected. Lift order n=2*17L*(12+4*17L)=2312L^2+408L. Every proper coloring has equal colors along each protected chain by exact proper four-pole relation. Its distinguished projected core must differ from START at some protected edge: changing only e0 cannot conserve at its endpoints. Thus all L+1 wire segments of at least one chain differ from initial coloring, with distinct endpoints, so at least 2(L+1)=Omega(sqrt(n)) touched vertices in every repair. Upper bound O(L) above, so minimum support Theta(sqrt(n)). This does not assert any necessary overshoot in this dense variant or lower bound against unrestricted algorithms.

## Affine direction-palette terminal
For each edge choose nonzero direction d_e != z_e, and binary activation t_e. Set w_e=z_e XOR (t_e*d_e). Require t_e0=1 and D(diag(d)t)=0 in two binary coordinates. Every allowed edge output is nonzero except e0 if inactive, so solving these linear equations exactly decides and reconstructs a repair within supplied palettes. No target constraints removed. In cubic graph sparse solver: at vertex with three distinct directions all activations equal; with two equal directions, equal those two and pin singleton direction inactive; with all three equal, one parity equation remains. At proper vertex all directions cannot be equal because z incident colors are 1,2,3 and d_e != z_e. At most two parity equations (defect endpoints). Union-find equality classes and zero pins plus one active pin; enumerate at most six classes in residual parity equations, other classes default inactive. Polynomial bit cost, near-linear indexed operations. Long supports can be controlled by few bits. Every proper target induces a successful palette, but target-free discovery of a polynomial portfolio containing a successful palette remains open (equivalent in sufficiency to FP02's general repair). Do not use target-derived palette tests as blind discovery.
