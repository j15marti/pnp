# FP01: A protected-cut trap refutes universal monotone flow-plateau escape
2026-11-25 20:27 Pacific | PROVED/EXACT by finite certificate + symbolic lifting; independent external review pending. P versus NP OPEN.

## Target and result
For a simple connected cubic graph G, use its binary incidence matrix D and ordered pair (a,b) in ker D squared. Defect d(a,b)=|E|-|supp(a) union supp(b)|. A step preserves a, b, or a XOR b exactly; it may change the other coordinate by ANY cycle-space vector. Color permutations are permitted. Claim under test: every positive-defect state of every colorable cubic graph can reach a zero-defect state without ever raising defect count. **FALSIFIED**, even from defect 1, in a 60-vertex simple connected bridgeless colorable graph; a 180-vertex girth-6 variant also fails. These graphs have 2-edge cuts, so the cyclically 4-edge-connected version after exact preprocessing is OPEN.

## Symbolic lifting theorem
For each protected edge uv, remove it. Take a fresh copy of K4 with edge xy removed, and join u to x, v to y (a 2-pole). Every nonzero source color c extends over this two-pole by taking a proper K4 coloring with xy colored c, then removing xy and adding the two seams of color c. Thus the initial flow with one defect and the zero-defect witness lift. The expanded graph is simple connected cubic, has 12+4*12=60 vertices and 90 edges. No bridges: each inserted graph has an internal x-y path, each core edge lies on a cycle, and each internal gadget edge lies on a cycle either inside or via the core. 

For ANY conserved flow on the expanded graph of defect <=1, sum conservation over each inserted gadget: the two seam colors sum to zero, so are identical. If either seam is zero, both are zero, contradicting defect <=1. Replace each seam pair by its shared nonzero virtual edge to project back to a conserved source flow. All protected edges are nonzero; projected defect <=1. Every expanded step retaining any of a,b,a XOR b retains the corresponding projected coordinate, including virtual edges. An expanded successful path would project to a path from the certified start to some zero-defect pair in the restricted core state graph, impossible. Relabeling is harmless: the component is closed under coordinate permutations (swaps of the two nonretained colors preserve one projection). This argument quantifies over all possible cycle-space transformations and all lengths, not just local cycles, minimum T-join tie breaking, or a finite search budget.

High-girth variant: substitute the Heawood graph minus an edge for each K4 minus an edge. It is cubic bipartite before deleting the edge, with girth 6 and an explicit proper edge coloring (see checker). The unprotected edges form a forest, so every cycle traversing the core must use an inserted gadget, whose terminal distance is at least 5 before adding seams; internal cycles have length >=6. The result has 180 vertices, 270 edges, girth 6 and no bridges (verified with NetworkX separately). Same projection proof. More generally arbitrarily high girth can be obtained using connected cubic bipartite high-girth blocks (not needed for the finite counterexample).

## Impact on DOUBLE-WRAPPER
Fixed-a T-join optimization remains exact; non-increasing escape is not universally available before reduction. Equal-cost moves, exact immediate neighborhoods, larger simultaneous single-direction perturbations, hash-free memoization, and unbounded search cannot overcome this particular state-graph obstruction. The counterexample is NOT a lower bound for the unrestricted decision problem, nor a trap after exact 2-edge-cut contraction. Indeed the 2-poles can be contracted first; the unprotected 12-vertex core has a path to zero. A meaningful revised obligation is escape on small-cut irreducible graphs, or an outer operation that changes the feasible state graph (exact contraction, temporary defect-budget increase, or changing both independent projections). Do not infer UNSAT from plateau exhaustion. In particular the globally correct UNSAT/SAT result for the expanded graph is SAT even if its current one-defect basin is exhausted.

New next lemma: investigate whether every cyclically 4-edge-connected colorable cubic graph has an escaping one-defect component, or construct a 4-port analog of this protected seam. Any proposed 4-port gadget must address the possibility of an internal defect changing the boundary pairing; do not assume the 2-port parity proof survives. Also test whether minimum necessary defect overshoot can grow with nested gadgets, with independent search and source projection.
