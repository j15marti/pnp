# Strict-C critical obstruction constructor: Hajós witness amplification
Date: 2026-11-19, new independent agent. **P versus NP OPEN.**

## Status
**PROVED (restricted):** If two connected edge-minimal non-5-colorable simple graphs G1,G2 are joined by the Hajós operation (delete a1b1,a2b2, identify a1 with a2, add b1b2), the resulting graph J is connected, edge-minimal non-5-colorable and satisfies g(J)>=min(g(G1),g(G2)). Every deletion coloring of J is explicitly constructible from operand deletion colorings, via a Z5 color translation. Apply a fresh private-head **strict** C(h_e,u,v) to every J edge. It is clause-critical UNSAT with incidence girth 2g(J), and every original C clause deletion has a full strict-C witness. The primal graph contains triangles. This is a certificate-transport consequence of classical Hajós construction, not a machine-time lower bound.

**Proof:** Every coloring of Gi−aibi has ai=bi, otherwise it colors Gi. Therefore a five-coloring of J would force b1=a=b2, violating b1b2. For deleting the joining edge, combine both selected-edge deletion colorings and align their a-colors. For deleting any retained edge f of G1, combine a coloring of G1−f (which has a1!=b1 because edge a1b1 remains) with a coloring of G2−a2b2 (where a2=b2). A global translation aligns the roots and leaves only f monochromatic. The G2 case is symmetric. For girth, a cycle crossing copies must use the joining edge and has length at least g1+g2−1; otherwise its cycle lies in a single edge-deleted copy. Strict C heads have 0 legal values for equal endpoints and at least one for unequal ones; this lifts every certificate.

**PROVED criticalization ledger invariant:** A greedy exact graph five-color decider can retain a 5-coloring for every failed edge-deletion attempt. That coloring remains valid for the final graph minus the retained edge, because subsequent changes only remove edges. This saves *later* witness searches but not the complete exact SAT/UNSAT tests, which may cost O(m n 5^n) via naive enumeration. A complete materialized m-witness ledger costs Omega(m n) graph color records and Omega(m(n+m)) original-C records.

**COMPUTATIONAL:** For the Mycielski^3(C5) base (47 vertices, 236 edges, girth 4), k-fold Hajós joins have n=46k+1, m=235k+1, strict-C variables N=281k+2 and clauses m. For k=1..5 we verified respectively 236,471,706,941,1176 full clause-deletion witnesses (total **3,530**) against all original strict-C clauses, totaling **3,044,430** checks with both the original and an independent table-based strict-C evaluator. A separate independent source/ledger replay passed all 1,176 largest-source witnesses (1,382,976 physical clause evaluations) and measured actual incidence girth 8. The largest example has 231 graph vertices, 1,176 C clauses, 1,407 C variables, source SHA-256 `310f8239a7cbcba7916b5f703c86753eed260d79bc82e9aa2914cda91c72d96b`, and uncompressed full-witness ledger SHA-256 `604bc1f944214f4e5ca34fdccbb5b91844f691842ef16eedccb4916cb9204fa3`.

**SOURCE-SOUND restricted UNSAT specialist:** A program validates the *entire explicit source* against the canonical Hajós family, reads each core-color row, scans for a monochromatic source edge, and proves its private-head strict-C block unsatisfiable by testing all five head colors. It returns UNKNOWN for noncanonical sources or malformed rows. On four supplied rows it read 26,153 source bytes, made 10 edge comparisons and 20 local head checks, and returned four refutable blocks. A forged one-clause source yielded four UNKNOWN results. No polarity advice is used. These examples have B=Theta(N) and **do not satisfy** the separate B<=N^0.65 layout promise.

**HIGH-GIRTH candidate pipeline (PROVED conditional on published spectral results; extraction unexecuted):** Nonbipartite LPS graphs X(73,q), for q prime, q≡1 mod 4 and (73/q)=1, are 74-regular Ramanujan graphs, with girth Omega(log q) and smallest eigenvalue no smaller than -2sqrt(73). Hoffman gives chi>=1+74/(2sqrt(73))=5.3305...>5. Infinitely many such q exist (q≡1 mod 292 suffices). Greedy total exact criticalization produces some edge-minimal non-5-colorable H_q, keeping girth and acquiring all individual deletion colorings; then strict-C lifting and Hajós joining give computable critical families of increasing incidence girth. **Polynomial seed acquisition is OPEN**. Local Cayley-word tests found exact graph girth 3,4,5,6 for q=37,61,89,293 respectively, but none were criticalized. The q=293 *unmaterialized* Cayley candidate already has 465,339,084 implicit edges, so virtual access or materialization cannot be free.

**FALSIFIED as a lower-bound proxy:** Criticality, growing original-block cover rank, arbitrarily many indispensable blocks and constant-factor gadget translations do not themselves force costly witness construction: the Hajós test family has an O(m) row selector and constructive deletion witnesses. Its incidence girth remains 8 for a fixed seed. No unrestricted SAT/UNSAT lower bound was obtained.
