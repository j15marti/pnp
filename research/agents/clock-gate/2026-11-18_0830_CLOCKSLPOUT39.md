## Exact model and theorem

A deterministic K-state stream reads every genuine source bit f_i exactly once. For every label z, state p and input bit b, an explicit total rule gives a next state delta_z(p,b) and an arbitrary binary emitted word omega_z(p,b), possibly empty. The actual output H(f) is the **unpadded concatenation** of emitted words and a fixed terminal-state label. All grammar/rule description and output bits are charged; schedules cannot depend on the source.
