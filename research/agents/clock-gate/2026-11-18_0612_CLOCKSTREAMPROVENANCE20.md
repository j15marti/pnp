## Named end-to-end dependency and four falsifiers

Four proposed escapes to test: (A) ordered global nonlinear stream features enforce hard source sections; (B) short provenance copied from the actual source prohibits cheap alternative representatives; (C) global parity / EXACT-ONE prevents sparse canonicalization; (D) a near-linear explicit-source compiler guarantees a succinct NP/PH-low verifier under P=NP. The constructed single family refutes all four as *sufficient principles*, not as universal impossibility theorems.

## Construction
Fix m >= 3, n=m+3 and N=2^n. Interpret an authentic length-N truth table f as an n-input Boolean function. Its first m bits are a binary descriptor D of a completely quantified Boolean CNF instance (malformed descriptors receive value 0). Define v(D)=1 iff D is a true QBF. Let h be the remaining L=N-m source bits. Define a(h)=OR_{i<L-1}(h_i AND h_{i+1}) (ordered adjacency), p(h)=XOR_i h_i, and e(h)=[sum_i h_i=1] (global nonmonotone EXACT-ONE). Define J_m(f)=(D,v(D) XOR a(h),a(h),p(h),e(h)). This output contains m+4=n+1 bits, far less than N, and its m-bit provenance is copied from REAL source bits.

## Exact theorem 20.1: STREAM-EASY-FIBER20
For every f there exists g with J_m(g)=J_m(f) and CC(g)<=C(m+3)(n+1), using a fixed fan-in-two complete Boolean basis. Proof: preserve D. There are exactly five feasible suffix triples (a,p,e), with sparse canonical suffix supports:
(0,0,0)->empty; (0,1,0)->{0,2,4}; (1,0,0)->{0,1}; (1,1,0)->{0,1,3}; (0,1,1)->{0}. The table is exhaustive for L>=5 (EXACT-ONE forces the final triple). The substitute suffix has at most 3 ones, and the preserved header at most m ones. Point-indicator DNF realizes g in C(m+3)(n+1) gates. Therefore J_m(Y_s)=image(J_m) when s exceeds this circuit bound.

## Exact theorem 20.2: STREAM-EXISTENTIAL-PSPACE20
The existential image language image(J_m), and hence the circuit-budget image IM_s=J_m(Y_s) for s above the theorem's bound, is PSPACE-complete under polynomial-time many-one reductions. For a label y=(D,b,a,p,e), membership holds exactly when (a,p,e) belongs to the five feasible triples AND b=v(D) XOR a. PSPACE containment follows from the classical polynomial-space QBF evaluation algorithm. Given a valid QBF descriptor D, reduce D to y_D=(D,1,0,0,0). The all-zero suffix realizes (0,0,0), so y_D belongs to image(J_m) iff D is true. This is PSPACE-hard, including for the EXISTENTIAL image, not just supplied-circuit verification. A polynomial-size point-DNF source witness C_D, with header D and zero suffix, also makes checking J_m(TT(C_D))=y_D PSPACE-hard. These are standard TQBF reductions, not novel PSPACE-hardness claims.

## Exact theorem 20.3: MIXED-PROMISE-FIBER20
Fix 0<beta<gamma<1, set source YES threshold s=N^beta, and source NO threshold t=N^gamma. For every sufficiently large m and every D, there exist fY in Y_s and fN with CC(fN)>=t having J_m(fY)=J_m(fN). Fix header D and select suffixes with h_0=h_1=1 and even parity; all have (a,p,e)=(1,0,0) and there are exactly 2^(L-3) such suffixes. The canonical support {0,1} supplies fY. The number of n-input functions with circuits <=t is at most 2^{O(t log(n+t))}=2^{o(N)}, less than 2^(L-3) for large N. Some suffix with the same label therefore has CC>=t. Thus BOTH source promises collide under an authentic source-bound transcript.

## Explicit one-way-input one-work-tape resource ledger
The compiler copies m real source bits D to its one writable work tape. Then, while scanning suffix symbols once, it maintains previous source bit, adjacency, parity, and an EXACT-ONE count capped at 2. In parallel it enumerates every assignment to the k<=m QBF variables; one suffix symbol per assignment is sufficient since 2^k<=2^m<N-m. A depth-k pending-bit stack merges completed subtrees using AND/OR according to quantifiers. Matrix evaluation, input parsing, stack update, work-head movement and serializing D plus four bits are charged. The same deterministic locally headed realization uses O(N poly(m+n)) time, O(poly(m+n)) work bits and m+4 output bits; n=m+3 makes this N^(1+o(1)) time with poly(log N) work memory. There is NO outside QBF oracle, second work tape, source random access, or free seed.
