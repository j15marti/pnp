## Precise model

N=2^n, n>=1. A deterministic finite automaton with output (DFAO) D has A states, initial s0, transition delta:S x {0,1}->S and output t:S->[r], r<=A. At position i in 0,...,N-1, its output after reading the n-bit most-significant-first representation bin_n(i), including leading zeros, selects one of r source-bit transition rules F_z:Q x {0,1}->Q on K states. The genuine source bits f_i are read in order. The stream machine starts at q0 and ends at q*. The quotient output H(f)=ell(q*) is an arbitrary fixed terminal-state label.

The schedule D and rules F_z are independent of the source. Any source-adaptive provenance or seed must actually be retained in the charged K-state machine; additional off-machine transcripts are excluded.

## Theorem AUTOMATIC-ADDRESS-DYADIC-SECTION28

For every source f, there exists ONE consistent N-bit truth table g with exactly the same final K-state and output H(g)=H(f) such that

    CC(g) <= C n A K^2 (1+ceil(log_2(AK+2)))^2,

where CC is ordinary nonuniform n-input complete-basis fan-in-two Boolean circuit size and C is basis-dependent. Given explicit tables, n, q0 and an actually reachable terminal state q*, one uniformly constructs this circuit in time polynomial in n,A,K. The circuit generator is not supplied a way to compute q* from the original source without scanning it.

### Proof

For each DFAO state a and h>=0, let R[h,a](p,q) mean that some source word of length 2^h sends p to q while the address schedule traverses all h-bit suffixes lexicographically starting in a.

Base case:
    R[0,a](p,q) = OR_{b=0,1} [F_{t(a)}(p,b)=q].

With Boolean matrix product, the exact recurrence is:
    R[h,a] = R[h-1,delta(a,0)] * R[h-1,delta(a,1)].

The two halves of the dyadic interval have next address digit zero and one, respectively. Therefore induction proves the exact reachability semantics. Precompute all n A matrices by O(n A K^3) Boolean operations and O(n A K^2) bits of tables. For each reachable (h,a,p,q), choose the first valid midpoint r and record it; for h=0 choose one valid input bit. Recursively concatenate the two chosen subblock witnesses. This creates a single internally consistent source word W[h,a,p,q] with the declared endpoint.

Set g=W[n,s0,q0,q*]. To compute any bit g(i), traverse the n address digits from most to least significant; maintain the DFAO state a and the current endpoint pair p,q. Use the hardwired midpoint table indexed by h,a,p,q and choose the left or right subinterval based on the next address digit. At the leaf return the stored input bit. Every call computes a bit of the same W, not a separately chosen source. Hardwired K-by-K-by-A lookup can be built from comparisons/multiplexers using O(A K^2 log^2(AK+2)) gates per level, yielding the stated size. All tables are polynomially constructed. QED.

## Concrete nonperiodic schedule

The two-state DFAO delta(a,b)=a XOR b, t(a)=a emits Thue-Morse parity(popcount(i)) at address i, and is invariant under leading zeros. With a two-state match/reject-sink stream machine, the accepted fiber is exactly that nonperiodic N-bit word. Its source-bit circuit is simply parity of the n address bits, of size O(n). This is not the old bounded-period lift: the schedule has no fixed small period, yet A=2. The theorem also covers arbitrary source nonlinear effects of mixing DFAO-selected transition rules.

## Boundary and same-machine ledger

Only counting the number of distinct transition rules, with NO bound on the schedule description, is insufficient. An uncharged N-bit advice schedule lets a two-state match/sink automaton accept any hardwired source word, including a high-CC singleton. That is outside the DFAO model and cannot establish an efficient uniform compiler.

For headerless one-way physical execution, bin_n(i) may require knowing n before source EOF. If delta(s0,0)=s0, a schedule is invariant under padded leading zeros, so the scanning machine can evaluate the rule on the canonical binary index i without knowing n in advance. With A,K=poly(n), explicitly stored transition tables and a charged n-bit counter, a conservative one-way-input, one-work-tape scanner runs in O(N poly(n,A,K)) time, poly(n,A,K) workspace and paid terminal-output serialization. This is a valid upper bound with no source reread, not an optimized reduction. General padding-sensitive DFAOs have NO automatically justified headerless implementation.
