## Theorem REVERSIBLE-BASELINE-DEFECT-SECTION34

Fix n>=1 and N=2^n. A deterministic terminal-output stream has state set Q of size K, start p0, arbitrary source-independent indexed transitions delta_i(p,b), and output H(f)=F(p_N). Fix ONE source-independent baseline h in {0,1}^N with n-input circuit size u. Write B_i(p)=delta_i(p,h_i); suppose B_i is a permutation except on e addresses. Then for EVERY authentic source f, there exists an authentic source g satisfying

d_H(g,h) <= (e+1)(K-1)+e,

H(g)=H(f),

CC(g) <= u + C(n+1)((e+1)(K-1)+e+1),

with C independent of N,K,e and the transition-description complexity. No commutativity, stationarity, efficient indexed access, low algebraic degree, monotonicity, or small exact interval-reachability circuit is assumed.

**Proof.** First consider a contiguous interval [a,b) with no exceptional addresses. Let P_a be identity and P_(i+1)=B_i composed with P_i. Each P_i is a permutation. For actual physical state p_i, let q_i=P_i^(-1)(p_i). Reading baseline bit h_i acts as identity on q_i. Reading bit 1-h_i acts as an arbitrary indexed function. Inspect the q-state initially and after each nonbaseline source bit. If there are at least K nonbaseline bits, two of these K+1 checkpoint states coincide. Change every intervening nonbaseline bit to h_i. Identity steps connect the repeated equal states, so the physical endpoint at b is preserved. Iterate until at most K-1 deviations remain. Now partition the full original source into e+1 such regular intervals, separated by the e exceptional addresses. Perform the reduction in each regular interval preserving its physical endpoint; at exceptional addresses retain the original source bit. All subsequent physical states therefore agree at every interval boundary and finally at N. At most (e+1)(K-1)+e positions differ from h. The final correction set S is hardwired nonuniformly; g(x)=h(x) XOR OR_(i in S)[x=i], each equality costing O(n) ordinary gates. This proves the bound. QED.

**MCSP obstruction.** If YES_s={f:CC(f)<=s} and NO_t={f:CC(f)>t}, s<=t, then whenever

s >= u+C(n+1)((e+1)(K-1)+e+1),

we have H(YES_s)=im H. If NO_t is nonempty, every NO_t image collides with a YES_s image, so exact two-sided (including separated Gap-MCSP) promise purity FAILS. For s=N^beta, 0<beta<1, standard circuit counting implies NO_s nonempty for all sufficiently large n. If u<=N^(delta+o(1)), K<=N^(kappa+o(1)), and e+1<=N^(epsilon+o(1)) with max(delta,kappa+epsilon)<beta, purity fails. Equivalently, for u=o(s), purity within this model demands K(e+1)=Omega(s/n). ## Hostile controls and exclusions

**Sharpness at e=0:** with K states 0..K-1, zero input leaves state fixed and one input updates p to min(K-1,p+1). Reaching K-1 needs at least K-1 ones, and that many suffice. No sharpness claim is made for the defect coefficient e or circuit upper bound.

**High-degree/strongly nonlinear:** K=3, zero input acts as identity, one rotates state modulo 3, output 1 iff the number of ones is 0 modulo 3. For every N=2^n>=4, the output is globally non-unate in each original source bit: holding two other bits equal to 1 versus holding all others 0 yields opposite changes. Its top ANF coefficient is XOR_f H(f)=H(0^N) XOR H(1^N)=1, by Lucas parity (all interior binomial(N,k) are even), since N mod 3 is nonzero. Hence its original-source ANF degree is N, although each output label has a representative of weight <=2. An independently checked genuinely order-sensitive N=8, K=3 permutation-zero model has full degree 8 and is non-unate in all eight coordinates. Its indexed one maps at positions 0..7 are (2,0,1),(0,2,1),(1,0,2),(2,1,0),(0,2,1),(1,2,0),(2,0,1),(2,0,1); output 1 iff final state=0.

**Required guards:** A 2-state checker for exactly the input 1^N has a nonpermutation zero transition, and its accepting fiber needs N ones, refuting any K-1 support claim without invertibility. For arbitrary prescribed hard sources, the checker also hides substantial nonuniform advice in its transitions, and provides no uniform hardness construction. A 1-state copier that emits all original bits preserves an N-bit output without storing it in the terminal state: unretained output and source-dependent auxiliary data are outside the theorem. Any emitted provenance must instead be charged in K or tracked separately.
