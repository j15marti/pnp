## Theorem A: both-label oracle decision-tree evasiveness

Let x_{r,b}=1 iff F_b[z=r] is satisfiable, and G(x)=OR_{r=1}^R AND_{b=1}^B x_{r,b}. Every deterministic exact decision tree using ONLY individual x-cell queries has an UNSAT and a SAT input on which it makes RB queries, and the full scan achieves this bound.

**Proof.** Reply 1 to each queried cell unless it is the last unqueried cell of its row; then reply 0, except on the globally final unqueried cell. Before the global final query all completed rows contain a 0, while one incomplete row has only observed 1s. Both answers remain possible. Choosing the last reply 0 or 1 gives two authentic status matrices of opposite polarity with the same first RB-1 replies. This works against every adaptive deterministic query order.

This is **oracle query cost**, not physical CNF-solving time, and does not exclude source-aware inference, exact residual caching, or correlated child answers.

## Theorem B: arbitrary oracle matrices have easy source-authentic CNFs

Here Delta_r(z) is the disjunction of h mismatches from binary r. At z=r these become contradictory units; at other z the pair is tautologically satisfied.
