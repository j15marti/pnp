## Exact model and theorem

For every n>=1, N=2^n. A source-independent binary straight-line program (SLP) has G terminal and binary-concatenation production rules, topologically sorted. Its start symbol produces exactly N rule labels z_0,...,z_(N-1). Each label selects a total deterministic K-state transition F_z: Q x {0,1} -> Q. The **actual** N-bit truth table f is scanned once with q_(i+1)=F_(z_i)(q_i,f_i), q_0 fixed. The quotient H_n(f)=ell(q_N) is a function of the terminal K-state, with arbitrary fixed label map ell. This excludes extra uncharged output transcripts, source-selected rule schedules and oracle side information. G and K count all actual schedule/state descriptions.

**GRAMMAR-STATE-CANONICAL-SECTION29.** For every such machine and every source f there is ONE N-bit source g, representing a Boolean function on n inputs, with H_n(g)=H_n(f) and

CC(g) <= C G^2 K^2 [n+log_2(G+K+2)]^2.

This is ordinary nonuniform complete-basis circuit complexity. From an explicit SLP, transitions, and a specified *reachable* terminal state q_N, the circuit is constructible in poly(G,K,n) time; obtaining q_N from f is not free.

**Proof.** For every grammar node X define R_X(p,q) iff some source bits of length |X| take state p to q under X's schedule. For terminal X->z, set R_X(p,q)=OR_(b in {0,1}) [F_z(p,b)=q] and store the least valid bit. For X->YZ, set

R_X(p,q)=OR_(r in Q) [R_Y(p,r) AND R_Z(r,q)].

Store the least valid midpoint r for each reachable pair (X,p,q). Induction on productions proves exact reachability. Recursively concatenate the canonical child witnesses for each chosen midpoint. Starting at (start,q_0,q_N) defines a **single globally consistent** word W; different uses of a shared node are indexed by the *correct endpoint pair*, not an inconsistent local guess.

For requested source bit index i, traverse the grammar from its start symbol. At node X->YZ, retrieve the hardwired midpoint r and left-child length |Y|. If i<|Y| recurse on (Y,p,r,i), else recurse on (Z,r,q,i-|Y|); at a leaf emit its stored bit. Every path has at most G levels (acyclic grammar). The node ID uses log G bits, endpoint pair 2log K, length/index n+1. A guarded lookup among <=G K^2 entries, plus an n-bit comparison/subtraction and leaf gate, has size O(GK^2[n+log(G+K+2)]^2) per level under conservative multiplexing. Unrolling G levels yields the advertised bound. All choices are constants of one n-input circuit and every evaluated bit belongs to the same word W. QED.

**Sparse exceptional positions.** A source-independent schedule differing from the base SLP at r arbitrary fixed positions has an SLP of size G'=O(G(r+1)): clone only one root-to-leaf grammar path per patch, keeping unaffected shared subtrees. Depth is <=G. Hence the same conclusion holds with G' in place of G, without a regularity or DFAO assumption on exceptional addresses.

**MCSP collision.** Let Y_s={f: CC(f)<=s}, NO_s={f: CC(f)>s}. If s dominates the section bound, H_n(Y_s)=im(H_n). For s=N^beta, 0<beta<1, circuit counting supplies NO_s sources for sufficiently large n, so any such NO source collides with a YES_s preimage. Exact two-sided promise purity **fails**. For G_j<=N^(b lambda^j+o(1)), K_j<=N^(a lambda^j+o(1)), 0<lambda<1, a fixed clock-independent stage j with 2(a+b)lambda^j<beta necessarily saturates. The same excludes Gap-MCSP purity where genuine gap NO sources exist.

**Non-DFAO example.** Prefixes of length 2^n of the infinite Fibonacci word (F_0=0, F_1=01, F_k=F_(k-1)F_(k-2)) have O(n)-size SLPs by shared Fibonacci concatenations and one recursive prefix truncation. The infinite Fibonacci word is Sturmian and not automatic under a fixed binary-address DFAO. No lower bound for the nonuniform DFAO size at each individual n is claimed. Thus the result extends CLOCKDFAO28 in *structural scope*.

## Model-compatible headerless Fibonacci compiler (special case)

For **fixed** K, fixed transition tables F_0,F_1 and a fixed terminal-label function, the Fibonacci schedule admits a fully charged headerless one-way-input, one-work-tape compiler in **O(N log^4 N)** time and **O(log^2 N)** writable cells. At source offset i, build the list of Fibonacci word lengths (1,2,3,5,...) until its maximum exceeds i and descend the F_k=F_(k-1)F_(k-2) grammar by prefix-length comparisons/subtractions to compute schedule symbol z_i. This needs **no knowledge of final source length n**, no per-n advice and no input rereads. Store the i counter and one K-state, update while genuinely reading each input bit once, check length power of two at EOF, then serialize ell(q_N). The list has O(log N) O(log N)-bit integers; conservative one-work-tape arithmetic/motion is O(log^4 N) per bit. This is a concrete legal near-linear source-to-quotient compiler **inside the semantically ruled-out subclass**: cheap fibers defeat NO-image exclusion notwithstanding physical model compatibility. It is **not** a proof of joint fixed-PH succinct equality or a compiler for arbitrary SLP schedules.
