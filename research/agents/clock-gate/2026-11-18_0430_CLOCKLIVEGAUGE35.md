## LIVE-BASELINE-SECTION35, exact theorem

Let Q be K finite states, p0 a fixed start state, and delta_i: Q x {0,1}->Q arbitrary **source-independent**, deterministic, indexed transitions for i=0,...,N-1. The output H(f)=F(p_N(f)) depends ONLY on terminal state. Fix an n-input baseline truth table h with circuit cost u=CC(h). Let R_i be all states reachable from p0 by **any** i-bit source prefix (both 0 and 1 allowed at every index). Write B_i(p)=delta_i(p,h_i), and let E_live be the positions where B_i restricted to R_i fails injectivity; e=|E_live|.

**For EVERY authentic source f there EXISTS an authentic source g** with the same terminal state and

d_H(g,h) <= (e+1)(K-1)+e,

CC(g) <= u + C(n+1)[(e+1)(K-1)+e+1].

No stationarity, bounded-period schedule, cheap indexed-transition circuit, uniform witness discovery, low polynomial degree, or monotone feature is assumed. C is basis dependent but independent of N,K,e.

**Proof.** On a maximal nonexceptional interval [a,b), extend the injective partial map B_i|R_i to an arbitrary full permutation P_hat_i of Q by matching remaining unused domain and codomain states. Every actual physical prefix state lies in R_i, so P_hat_i agrees with the actual baseline transition on all physically realizable trajectories, including modified ones. Define cumulative permutations P_a=id, P_(i+1)=P_hat_i composed with P_i. Conjugate the physical state to q_i=P_i^(-1)(p_i); reading h_i then acts as identity. List the initial q-state and the q-state immediately after each nonbaseline source bit. If at least K deviations occur, K+1 q-checkpoints repeat. Replacing ALL nonbaseline bits between repeating checkpoints by h_i leaves q and the physical endpoint of that interval unchanged, because intermediate modified prefixes still lie in R_i. Repeat until no more than K-1 deviations remain. Retain the original source bit at each of the e exceptional positions, apply this reduction to the e+1 regular intervals, and preserve all interval boundaries. Hardwire at most d=(e+1)(K-1)+e correction addresses into g(x)=h(x) XOR OR_(i in S)[x=i], using u+O((n+1)(d+1)) gates. QED.

## Strict strengthening and hostile falsification

**Moving reachable support.** A three-state indexed stream has R_1={1,2}, R_2={0,1}, R_3={1,2}, etc.; all three states appear in some R_i. Each of its N baseline-zero transitions is globally noninjective, so e_global=N, but each acts injectively on the actual R_i, so e_live=0. Accordingly every terminal output is reachable with at most K-1=2 deviations. Maps and exhaustive control in the executable audit.

**False idea, FALSIFIED:** Count noninjectivity only on the ONE baseline trajectory, or on states co-reachable to a selected terminal. Take K=2, H(f)=1 iff f=1^N, h=0^N. The baseline-only set at every time, and the accepting co-reachable set at every time, are singletons and vacuously injective. But the baseline transition exits the accepting co-reachable set, so it cannot be substituted into an accepting path. The unique accepting source has N deviations, contradicting the false K-1=1 claim for N>=2. Correct all-prefix reachability gives e_live=N-1, so the proved theorem survives. Switching instead to the cheap baseline h=1^N gives e_global=e_live=0, exhibiting the baseline-choice guard.

**Emitted-output firewall:** A one-state stream copying every source bit to an unretained external output has 2^N outputs. This is NOT a terminal-state quotient. Emitted source-dependent provenance, seeds, auxiliary tapes and output volume must be charged, not deleted from the model.
