## UNPADDED-AUTOMATIC-SECTION38 (exact restricted theorem)
For every source f with emitted output y of length m, there exists an original-source truth table g such that H(g)=H(f) and

    CC(g) <= C n(n+1) A K^3 (m+1)^3 log(2+n A K(m+1)).

C is an absolute finite-gate-basis constant. This holds for arbitrary algebraic degree, arbitrary state-dependent/variable-length emission, and without preserving positions at which outputs were produced. It extends CLOCKDFAO28 (terminal state only) and is complementary to CLOCKOBSERVABLEGAUGE37 (state-independent baseline emission and padded traces).

**Proof.** Define R(d,a,p,q,l,r) to mean that a source block of length 2^d starting under address-DFA state a takes transducer state p to q and concatenates output **exactly** equal to y[l:r]. At d=0,

    R(0,a,p,q,l,r) iff exists b in {0,1}:
      delta_a(p,b)=q and omega_a(p,b)=y[l:r].

For d>0, writing aL=eta(a,0), aR=eta(a,1),

    R(d,a,p,q,l,r) iff exists t in [K], z in [l,r]:
      R(d-1,aL,p,t,l,z) and R(d-1,aR,t,q,z,r).

The recurrence is exact by splitting input and emitted output simultaneously. It contains at most T=(n+1) A K^2(m+1)^2 cells. For the attainable output y, choose one valid terminal q compatible with F(q), and recursively choose the lexicographically least feasible midpoint (t,z) at each dyadic address node. At a leaf select the least valid b. The resulting g(i) is globally consistent because every queried bit follows **the same canonical tree of midpoint choices**; induction gives the identical full output y and terminal q. Hardwire the Boolean R-table and one leaf-witness table. A literal indexed lookup takes O(T log(T+2)) gates; n levels test <=K(m+1) midpoints per level, giving the displayed conservative size bound. No degree, certificate size, or output-event count appears.

**Uniform corollary.** Given n, y, terminal label and all explicit rule tables, the entire DP, a polynomial-size Boolean circuit description for g, and its independent bit evaluator can be constructed in time polynomial in n,A,K,m,B and table length. This is NOT an inversion theorem for arbitrary indexed transition algorithms, and does not by itself yield a low-PH supplied-circuit *equality* verifier.
