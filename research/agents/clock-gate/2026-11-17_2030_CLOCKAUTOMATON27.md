## Theorem: STATIONARY-DYADIC-SECTION27

Let n>=1, N=2^n. Fix a source-independent and position-independent binary deterministic automaton with K>=1 states, initial state q0, transition delta: [K] x {0,1} -> [K] and arbitrary terminal output labeling ell: [K] -> {0,1}^m. Define H(f)=ell(delta*(q0,f)) on authentic N-bit source truth tables f.

**For every f there exists g of the same source length** with delta*(q0,g)=delta*(q0,f) and

CC(g) <= C n K^2 (1+ceil(log2(K+1)))^2,

for a basis-dependent absolute C and ordinary n-input nonuniform fan-in-two Boolean gate complexity. Given an explicit transition table, n, q0 and an actually reachable terminal state q*, a **uniform** algorithm builds such a circuit in poly(K,n) time. This generator is supplied the endpoint; it is NOT an uncharged method of evaluating H(f).

### Complete constructive proof

Let R_0[p,q] hold if delta(p,0)=q or delta(p,1)=q. For h>=0 define the Boolean matrix square

R_(h+1)[p,q] = OR_(r in [K]) (R_h[p,r] AND R_h[r,q]).

By induction, R_h is precisely length-2^h reachability. Precompute all R_h, h=0..n, in O(n K^3) Boolean operations. Whenever R_h[p,q] holds for h>=1, record a single *canonical* midpoint r_h(p,q) with R_(h-1)[p,r]=R_(h-1)[r,q]=1. At h=0 record one bit b(p,q) inducing the transition. Make arbitrary unused entries for unreachable pairs.

For each reachable pair (p,q) at level h define a binary word W_h(p,q) recursively: W_0(p,q)=b(p,q), and W_h(p,q)=W_(h-1)(p,r_h(p,q)) concatenated with W_(h-1)(r_h(p,q),q). Its length is 2^h, its endpoint is q when started at p, and all choices are fixed globally, independent of the eventual queried bit address. Thus g=W_n(q0,q*) is one consistent N-bit truth table with the exact same terminal state as the original f.

A Boolean circuit on input address i in {0,1}^n starts with state pair (q0,q*). From h=n down to 1 it looks up the hardwired midpoint r_h(p,q), reads address bit i_(h-1), and updates the pair to (p,r) for 0 or (r,q) for 1. At level zero it outputs the hardwired b(p,q). Each K-by-K midpoint lookup can be implemented by comparisons to constants and multiplexing in O(K^2(1+log(K+1))^2) gates over any fixed complete fan-in-two basis. Only n lookups are required, proving the stated bound. For K=1 a constant word suffices. All random-access evaluations of g agree with the single recursively defined W_n. QED.

This is a straightforward application of **classical Boolean matrix powering and straight-line-program witness compression** to the Clock Gate semantic-fiber obligation, not a claim of discovery of those finite-automaton techniques. ## Hostile high-degree genuinely non-unate ordered example

Define T_N(f)=1 exactly for the three ordered N-bit source words 0^N, 1^N and (01)^(N/2), for N>=4 a power of two. A stationary K=16-state DFA tracks phase parity and whether each of the three candidates is still possible, then emits their OR at EOF. It is **order-sensitive**: 01010101 is accepted at N=8, whereas 00110011, of identical Hamming weight, is rejected. For EACH original source coordinate, 0->1 can destroy acceptance from 0^N, and separately create acceptance from the one-bit-flipped neighbor of 1^N. Hence no input coordinate is unate. The full source-bit ANF top-monomial coefficient is XOR_f T_N(f)=3 mod 2=1, so degree(T_N)=N. Nonetheless the theorem gives a uniform O(n) gate section for each image. Maximal ANF degree and non-unateness do not imply MCSP promise-pure fibers.

## Periodic transition schedule extension

If the fixed transition at source position i depends only on i mod p, augment the state with phase in [p]. This produces a stationary Kp-state machine with precisely the same source-induced transitions and terminal label. Replace K by Kp throughout the theorem. A period growing to N or an arbitrary address-dependent transition circuit is **not** a small-state result. Source-derived seeds/provenance retained across the full scan must be accounted for in state cardinality and output behavior.

## Boundary: inhomogeneous singleton accepted fiber

Given a particular word t in {0,1}^N, a two-state machine with position-specific transition labels can accept **exactly t** by rejecting irrevocably at the first mismatched source bit. Choosing t to have large circuit complexity makes the accepted fiber hard. This invalidates any purported K-only section theorem for arbitrary inhomogeneous transition schedules. However, encoding a hard t into N transition instructions costs N bits and is NOT a legitimate near-linear *uniform* compiler unless the schedule generation and per-position reads are fully charged. A finite N=8 example uses word mask 22, independently verified not expressible by any 2-gate n=3 circuit over the complete 16-binary-function basis.
