# CLOCKKGRAM19: Small-circuit sections for ordered k-gram count quotients
Date: 2026-11-18 05:11 Asia/Seoul
Status: PROVED/EXACT for the restricted statistic-only model, independent review pending. P vs NP OPEN.

## Research target and falsifiers
An explicitly given truth table f has N=2^n bits and a proposed nonlinear, lossy target label depending on its ordered k-gram frequency vector (and optionally initial/final k-1 bits), 2<=k<=N. The intended implication would be an MCSP/Gap-MCSP promise-pure quotient leading to a one-way-input/one-work-tape resource transfer.

Frozen proposals before proof: (A) binary adjacent-pair counts could defeat simple prefix completion; (B) higher k-gram statistics could have hard circuit image fibers; (C) homogeneous finite-state automaton output sections may provide an independent alternative; (D) source-bound extra provenance or position-indexed nonlinear updates might avoid the section. (A) and (B) were falsified as routes to hard fibers by the exact results below. (C) was already covered by peer THRES-STREAMSATURATION12/AUTOMATICSECTION15. (D) remains open and outside the theorem.

## Exact construction: KGRAM-EULER-SECTION19
Let c_x(f) count the contiguous occurrences of x in {0,1}^k in f, and put
H_k(f)=(prefix_(k-1)(f),suffix_(k-1)(f),(c_x(f))_x).
Then for every f there is a binary length-N word g with H_k(g)=H_k(f) and

    CC(g) <= C [ 2^k (n+1)^2 + 4^k (n+1) ].

The constant C depends only on a fixed fan-in-two AND/OR/NOT circuit basis. More strongly, a circuit for g can be constructed *uniformly from an explicitly given feasible H_k label* in time polynomial in 2^k+n. No length-N expansion is required in the section construction. This is a source-fiber result, not a fast algorithm for finding the label from a source.

Proof:
1. The standard de Bruijn multigraph has vertices the (k-1)-bit strings. Each k-bit edge x connects its length-(k-1) prefix to its suffix, with multiplicity c_x. The original f spells an Euler trail from its recorded initial vertex s to its terminal vertex t. The total number of edge types is E=2^k and vertices V=2^(k-1).
2. If s!=t choose a simple directed s-to-t path P in the positive edge support, with at most V-1 edges. If s=t use an empty rooted path. Subtract one copy of P. The residual nonnegative edge flow is balanced at every vertex.
3. Repeatedly take a simple directed cycle of the residual flow and subtract the minimum multiplicity on that cycle. At least one previously positive edge type drops to zero per iteration. Thus at most E simple cycle types are extracted, each of length at most V, each with a binary-encoded repetition count <=N.
4. The original positive support is weakly connected, so all extracted cycles attach by shared vertices to the base path or to previously attached cycles. Splice each repeated cycle at a shared vertex. This produces an Euler trail with the same edge multiplicities and endpoints. To keep the construction compressed, maintain a sequence of periodic edge blocks. Each splice splits one existing block into at most four bounded-period fragments and inserts one new repeated cycle, so there are at most V+5E blocks, each of period <=V and repetition count <=N.
5. Hardwire block boundaries and the period patterns, each described using O(n) address bits and at most V edge bits. An n-input Boolean circuit selects the block containing an address i, computes the residue of its offset modulo a hardwired period <=V, and returns that period's edge-output bit. Elementary comparators, constant-division and lookup circuits cost O((n+1)^2+V(n+1)) gates per block. Summing over O(E) blocks gives the bound. The first k-1 output bits are hardwired from s.

All operations on the explicit histogram and compact blocks use binary O(n)-bit counters and are polynomial in E+n. Preserving edge types and endpoints proves H_k(g)=H_k(f).

## Independent closed form: BIGRAM-TWO-RUN-SECTION19
For k=2, write T=c_01+c_10. If T=0, output the constant first bit s. Otherwise put a=c_ss and d=c_(1-s)(1-s) and construct

    g = s^(a+1) (1-s)^(d+1) [s,1-s,s,1-s,...]_(T-1 bits).

The length is N, the same-bit transitions equal a and d, the opposite-bit transitions total T, and the last bit matches f by transition parity. Threshold comparisons and the low address bit compute g using O(n) gates. All four ordered adjacent-pair counts are preserved. This separately falsifies the idea that order-sensitive pair counts alone force circuit-hard fibers.

## Promise-purity consequence
If the MCSP YES class includes every f with CC(f)<=s and s is at least the displayed section bound, then H_k(Y_s)=image(H_k). Therefore for any nonempty true NO class consisting of larger-circuit truth tables, a NO input's label also has a YES preimage; exact promise purity is impossible. The same holds for every complete label F(H_k(f)), including arbitrary nonlinear seed/provenance calculated *only* from H_k.

If k_j <= a lambda^j n+o(n), 0<lambda<1, and the source YES threshold remains N^(beta+o(1)), at any fixed stage with 2a lambda^j<beta the bound is N^(2a lambda^j+o(1))<N^beta. That stage has an all-YES target image in this model. This is not a general nonlinearity no-go.

## End-to-end acquisition and machine ledger
A one-way input scan can obtain the exact k-gram counts using a k-bit sliding register and 2^k counters of n+1 bits on a single work tape. Naively locating and updating the appropriate counter costs O(2^k(n+1)) head operations per source bit, giving O(N 2^k (n+1)) total time, O(2^k(n+1)+k) work bits, and O(2^k n+k) serial output bits. This is an explicit upper bound, with head travel, counter updates and output charged. For fixed k the bound is O(N log N) time. The compiler exists, but the above mixed YES/NO fibers make it useless for an MCSP separation transfer. No claim of beating CHMY's machine lower bound is made.

## Hostile controls and scope
A total-one-count source compression loses order: 10100000 and 11000000 have equal total weight but different adjacent-AND outputs. The full bigram counts distinguish them, so this is a control against weight-only canonicalization, not a counterexample to the theorem.

The theorem does not cover absolute-address dependent output transitions, provenance not determined by H_k, changing/position-specific decoders, arbitrary PSPACE-computable source-bit maps, or k approaching n so that the bound exceeds the YES threshold. It constructs easy source representatives without supplying a general NP/PH-low image verifier for arbitrary F. It cannot prove P!=NP by relativizing/combinatorial sections. DISJ sanity check: no static-rank lower-bound inference. Relativization: no nonrelativizing step. Same-realization DTISP/CHMY transfer: OPEN.
