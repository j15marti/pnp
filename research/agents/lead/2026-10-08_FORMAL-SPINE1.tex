\section{Model and quantifiers}
Fix the uniform deterministic random-access machine model and SAT encoding
to which the endpoint theorem applies. Let $N$ denote encoded input bit
length, not variable count or hash length. Read-only original input is
excluded from workspace; every derived child, index, cache, suspended
frame, address buffer and retained summary is included. Any change of
encoding or machine must have an explicitly charged simulation preserving
the stated asymptotic bounds. For a CNF-only realization, the reduction
from the endpoint SAT encoding must likewise be supplied and charged.

\begin{definition}[Charged shrinking wrapper contract $\mathcal W(h,p)$]
There are fixed constants $0<h<1$, $0\le p<1$, a fixed base threshold,
one uniform algorithm $W$, and a common function $e(N)\to0$ such that the
following hold on every input and every recursively reached state above
the base threshold. All constants may depend on $W$, never on the input.
\begin{description}
\item[] \emph{Exactness.} $W$ decides directly or deterministically combines
answers to smaller SAT queries into the correct parent answer. Queries
may be adaptive. Correctness holds for every consistent sequence of true
child answers. Direct decisions, AND/OR composition and merges need
sound source-checkable justifications.
\item[] \emph{Volume and scale.} At most $N^{1-h+e(N)}$ child calls occur;
each child's full encoded length is at most $N^{h+e(N)}$.
\item[] \emph{Local time.} Total work outside child evaluation is at most
$O(N^{1+e(N)})$, including discovery, unsuccessful attempts, certification,
query construction, exact hash checks, scheduling and all access/replay.
The bound holds along every possible consistent execution, not just a
successful route. There are no uncharged parent-size SAT calls.
\item[] \emph{Space and resumption.} Children are evaluated sequentially.
The parent can suspend and resume using $O(N^{p+e(N)})$ bits besides the
current explicit child buffer of $O(N^{h+e(N)})$ bits. No sibling answers,
formula DAG, lookup index or ancestor state is omitted. All call-local
allocations fit these bounds simultaneously; the current derived input
buffer is charged by its caller. Implicit children require an equally
strong fully charged access simulation, not a free oracle.
\item[] \emph{Closure.} The same contract applies at every descendant.
Sizes strictly decrease above the base threshold. All smaller exceptional
sizes are handled by a fixed terminating exact procedure. The contract
uses the same implementation for every accuracy parameter in the proof.
\end{description}
\end{definition}

This is a sufficient contract. More general typed cycles, nonuniform
child sizes and shared schedules may prove the needed bounds through a
different charged recurrence. They are not excluded by this definition.

\section{Recursive composition and elimination of $K$}
\begin{theorem}[Fully charged composition]
If $\mathcal W(h,p)$ holds, recursive child evaluation produces one
uniform deterministic SAT decider $D_W$ with
\[
 T_W(N)\le N^{1+o(1)},\qquad
 S_W(N)\le N^{\max\{p,h\}+o(1)}.
\]
\end{theorem}
\begin{proof}
Exactness follows by induction on decreasing size. Termination follows
from strict decrease and the fixed finite base procedure. Let $T(N)$ be
the monotone worst-case time envelope of this one algorithm. Its recurrence
is bounded by local time plus the sum of child times.

Fix arbitrary $\delta>0$. Choose $\epsilon>0$ sufficiently small that
$h+\epsilon<1$, $\epsilon<\delta$, and
\[
 \epsilon(2+\delta)<\delta(1-h).
\]
Uniformity gives a threshold beyond which $e(N)\le\epsilon$. Assuming
$T(m)\le C m^{1+\delta}$ for smaller sizes, the child contribution is at most
\[
 C N^{1-h+\epsilon+(h+\epsilon)(1+\delta)}
 = C N^{1+h\delta+\epsilon(2+\delta)}.
\]
Its exponent is strictly below $1+\delta$, as is the local exponent
$1+\epsilon$. For sufficiently large $N$ these two contributions fit
$C N^{1+\delta}$. Increase $C$ to cover all remaining finite sizes and
induct. The algorithm does not change with $\delta$; only the analysis
threshold and constant do. Hence $T(N)\le N^{1+o(1)}$.

Let $s=\max\{p,h\}<1$. For every sufficiently small fixed $\epsilon>0$,
the total suspension, child-buffer and local-space contribution at a node
is $O(N^{s+\epsilon}+\log N)$. Along a depth-first path the next size is
at most $N^{h+\epsilon}$. The number of levels above a fixed threshold is
$O(\log\log N)$. Summing charged contributions, including ancestor-held
derived input buffers, gives $O(N^{s+\epsilon}\log\log N)$; the finite
bottom segment changes only constants. Since $\epsilon$ is arbitrary,
$S(N)\le N^{s+o(1)}$. Only one child is live at each node. There is no
assumption that all children can be stored for free.
\end{proof}

If a starting hypothetical SAT decider costs $N^K$, fixed-depth unfolding
has the ideal exponent sequence
\[
 K_0=\max\{1,K\},\quad K_{d+1}=\max\{1,1-h+hK_d\},\quad
 K_d=1+h^d(K_0-1).
\]
This explains the earlier elimination of $K$. The full recursive proof
above is stronger than taking a limit over different fixed-depth
algorithms: it gives the bound for one fixed algorithm and also charges
space. $K$ survives only in a finite base-case cost if that decider is
used there. A parent-scale invocation cannot be hidden in the base case.

\section{Endpoint and the remaining implication}
\begin{theorem}[Known endpoint, deterministic consequence of Fortnow]
For every fixed $\eta>0$, SAT has no uniform deterministic algorithm
simultaneously using time $N^{1+o(1)}$ and space $N^{1-\eta}$ on the
declared random-access model \cite{fortnow}.
\end{theorem}
The theorem concerns simultaneous bounds for a single algorithm. It
does not rule out polynomial-time SAT with larger time or space.

\begin{corollary}[Unconditional obstruction to the contract]
No uniform all-input SAT wrapper satisfies $\mathcal W(h,p)$ on the
matched endpoint model for fixed $h,p<1$ as specified above.
\end{corollary}
\begin{proof}
Set $s=\max\{p,h\}$ and $\eta=(1-s)/2>0$. Composition yields
$S_W(N)\le N^{1-\eta}$ for sufficiently large $N$, together with near-linear
time, contradicting the endpoint.
\end{proof}

\begin{hypothesis}[The unresolved bridge $\mathsf B$]
If SAT has a uniform polynomial-time decider, then there exist fixed
$h,p<1$ and one uniform wrapper satisfying $\mathcal W(h,p)$ on the
matched endpoint model.
\end{hypothesis}
This is an existence implication; an effective compiler for every
polynomial-time SAT program would be a stronger sufficient result.
The constants and program may depend on a fixed starting decider but may
not depend on each individual input or change with input length.

\begin{theorem}[Conditional separation]
If $\mathsf B$ is proved, then $P\ne NP$.
\end{theorem}
\begin{proof}
Assume $P=NP$. SAT then has a uniform polynomial-time decider.
By $\mathsf B$, the contract exists. The preceding corollary forbids it.
Therefore $P=NP$ is false.
\end{proof}

The missing premise is mathematically substantial. Since the contract is
already unconditionally excluded, in classical logic $\mathsf B$ is
equivalent to $P\ne NP$: the reverse direction is vacuous truth when
SAT is not in P. This equivalence does not make the constructive research
route useless, but it prevents calling $\mathsf B$ an established final
bookkeeping step. Establishing it would carry the separation itself.

\section{Alternative achievable-region route}
Define $\mathcal A$ to contain pairs $(t,s)$ for which one uniform exact
SAT decider has bounds $N^{t+o(1)}$ time and $N^{s+o(1)}$ space on the
same model. Membership requires both coordinates on the same machine.
Let $\mathcal F$ be any forbidden set justified by a matched known
time-space lower bound.

\begin{lemma}[Existence-level ARC contradiction]
Suppose, under SAT in P, a finite sequence of established implications
produces $z_0,\ldots,z_r\in\mathcal A$ with $z_r\in\mathcal F$. Then
$P\ne NP$.
\end{lemma}
\begin{proof}
SAT in P gives an initial jointly achievable polynomial pair, for example
a decider's polynomial time bound also bounds its visited workspace.
Apply the stated existence implications successively. The last pair is
both achievable and forbidden, a contradiction.
\end{proof}
This route need not improve every implementation of a pair. It must,
however, establish the existence of each next simultaneous pair, with
compatible representations and all construction costs included. A limit
of achievable exponent pairs is not automatically achievable by a single
machine. Either a finite iterate enters an open forbidden region or a
uniform limiting construction such as the recursive theorem is required.
Pure paid preprocessing with unchanged fallback supplies no strict
contraction merely from the envelope
$(t,s)\mapsto(\max\{t,c\},\max\{s,u\})$.

\section{Where the original division argument fits}
For positive $N$ and any fixed $c$,
\[
 \frac{2^k}{2^x}\le N^c
 \quad\Longleftrightarrow\quad x\ge k-c\log_2N.
\]
This is an exact required net reduction when $2^k$ and $2^{k-x}$ describe
the actual charged work being compared. It does not show such reduction
is constructible, or that distinct histories require distinct operations.
A common endpoint, prime labels, short hashes or a large history space
does not by itself identify runtime with history count. Discovery and
replay must be included before the inequality can certify an algorithm.

particular sufficient contract does not rule out other separation methods.
