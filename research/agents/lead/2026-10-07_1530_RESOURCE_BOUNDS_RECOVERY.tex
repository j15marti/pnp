\paragraph{Composition and branching already addressed.}
PRF3-0018 assumes uniform sequential generation, effective error control,
charged parent-local work and live state, exact composition, and a polynomial
base solver. It gives
\[
T(N)=N^{\max\{c,a/(1-b)\}+o(1)},\qquad S(N)=N^{o(1)}.
\]
This is a conditional resource result; cheap regenerated-input access must
actually fit the declared work/state interface. NEW\_UNSAT-0180 supplies
$N^{a/(1-b)+o(1)}$ total recursion-tree size under fixed-power shrinkage and
uniform fanout $M^{a+o(1)}$, hence subpolynomial tree size when $a=0$.
Neither supplies the generator for arbitrary SAT.

MULTICHANNEL1 allows finitely many charged recursive SAT-call channels:
\[
C=\max\{r,\max_j\eta_j/(1-\theta_j)\},\quad
\rho=\max\{\sigma,\max_j\theta_j\},\quad \theta_j<1.
\]
Its explicit space claim assumes sequential buffers and charged retained state.
Thus SAT-dependent construction calls are not categorically forbidden: smaller
calls can be absorbed by a valid recursively closed interface. The statement
does not absorb an unresolved original-solver call at current scale.

\paragraph{Implicit inputs and sharing already addressed.}
STREAMCOMP1 gives sufficient exponent budgets
\[
C_i\ge\max\{r_i,\max_{e:i\to j}(\eta_e+g_e+\theta_eC_j)\},\qquad
\rho_i\ge\max\{\sigma_i,\max_{e:i\to j}(s_e,\theta_e\rho_j)\}.
\]
These charge bit-generation time and workspace. They are conservative upper
budgets, not lower bounds requiring repeated independent work. Persistent
state and nested access remain explicit obligations.
ORBITBATCH1 records the corrected shared-setup ledger
\[
C_i\ge\max\{r_i,\chi,\delta+p,\eta+g+\theta C_j\}.
\]
Classification is a separate total cost. It need not multiply setup cost.
An acquired common parent evaluator can be shared when the declared realization
permits it. The orbit identity $\bigcup_i\{A^iv:v\in B\}=B$ deduplicates field
addresses for invertible $A$. The source report explicitly withholds transfer
from field-domain size to original SAT input length.

LEAD-0027's MACRO-LINEAGE-SPACE1 sums branch-index lengths along a fractional
recursion path: the leading bound is
$\eta(1-\theta)^{-1}\log_2N$, with appropriate uniform error and encoding
overhead. This bounds route indices, not all formulas, witnesses or caches.

\paragraph{Recovered portfolio scheduler.}
REV-0032 and PROOF-SYNTHESIS-0007 consider a computable all-exact family
containing a fixed member with time exponent $c_*<C$ and space exponent $d_*<D$.
Sequential restarted simulations, increasing time budgets, and rational caps
approaching $D$ from below yield a conditional scheduler with
$T_U=N^{c_*+o(1)}$ and $S_U=O(N^D)$, under the stated cap-enforcing simulation,
bookkeeping and generation assumptions. Only one configuration is retained.
The source's final status keeps the fully formal endpoint-machine implementation
conditional. This is an existing solution at the abstract scheduling level;
it does not construct the favorable member. Fixed-member existence is stronger
than an unbounded family whose good index changes arbitrarily with input length.
For an existential contradiction a fixed favorable algorithm can instead be
chosen directly, without implementing a universal selector.

\paragraph{Cap-selection defect in SIM-2-0008.}
That source claims that $\sigma<D$ permits an integer $j$ with
$\sigma<1/j<D$. This fails for $\sigma=2/5$, $D=9/20$: $j\le2$ gives
$1/j\ge1/2>D$, and $j\ge3$ gives $1/j\le1/3<\sigma$.
The rational $17/40$ lies in the interval. This exact arithmetic counterexample
invalidates that general selection step, not all capped schedulers.
When $\sigma=0$, reciprocal caps can work; the objection concerns the stated
general positive-space premise. Enumerating caps alone also does not prove a
global workspace bound. The sequential restart reports supply the relevant
separate construction. No historical document is overwritten by this audit.

\paragraph{Effect on the proof.}
The project already contains substantial time, space, fanout, lineage and
scheduling bounds. These are not all absent. What the inspected sources do not
establish is that one general-SAT wrapper, or an appropriate family containing
a fixed favorable member under the contradiction assumption, satisfies all the
required premises simultaneously at endpoint-compatible exponents.
The next target is an implementation-to-bound matching proof, including which
setup is shared, which states remain live, and what scale each recursive call has.
