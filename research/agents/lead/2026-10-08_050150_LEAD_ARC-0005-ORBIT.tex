\section{The symmetry rule and why context must move with it}
Let $F$ be an ordinary CNF. A signed permutation $\pi$ is a bijection of literals commuting with negation. The checker accepts it only when the entire transformed clause set equals $F$, not when fingerprints coincide. Let $G$ be the subgroup generated by accepted maps.

\begin{proposition}[Orbit representative cover]
Let $C\in F$, and choose one representative from each nonempty intersection of $C$ with a literal orbit of $G$. Call this set $R$. Then
\[
 \SAT(F)=\bigvee_{\ell\in R}\SAT(F\upharpoonright(\ell=1)).
\]
The same statement holds for the tautological cover $C=\{v,\neg v\}$.
\end{proposition}
\begin{proof}
If $F$ has a model, at least one literal $\ell\in C$ is true. A group element sends $\ell$ to its chosen representative $r$. Transporting the whole assignment gives another model of $F$ in which $r$ is true. Conversely, a model of any restricted child extends to a model of $F$. Every map in $G$ preserves $F$ because its generators do. The argument needs neither a SAT query nor the extra assumption that $G$ stabilizes $C$ as a set. The tautological case uses the fact that either $v$ or $\neg v$ is true.
\end{proof}

The single-orbit clause case is exactly the known clausal-fixing rule. A map sending $v$ to $\neg v$ gives the known negation-fixing rule. On several orbits, one child per orbit is retained; there is no license to keep an arbitrary single child.

For the earlier family
\[
 F_n=\bigwedge_{i=1}^n[(x_i\vee y_i)\wedge(\neg x_i\vee\neg y_i)],
\]
simultaneously flipping $x_i$ and $y_i$ is an automorphism. These $n$ generators act transitively on the $2^n$ complete $x$ assignments. The residuals are therefore one orbit under transported polarity, even though they remain an antichain under fixed-label implication.

This does not permit an unchanged future restriction to be reused. For example, $(y)$ and $(\neg y)$ have different answers after the same restriction $y=0$. Transporting that restriction to $y=1$ along with the sign flip restores agreement. The audit checked 18,434 such transported continuation identities for all assignments through $n=10$. Parent symmetries are rechecked on the current residual; stale parent maps are not accepted blindly.

\section{First build: orbit-first simplification inside the existing WRAPPER}
The candidate producer proposes at most three maps on each visited residual. One is a cyclic column permutation inferred from disjoint positive clauses and negative-binary matchings. The other proposals are a local cycle and a small-support polarity flip. Every proposal, including failed proposals, is checked against the full current formula. No family name, expected SAT answer, or trusted symmetry certificate is given to the producer.

A controlled local variant first compared ordinary clause-first generation with orbit-first generation while keeping pure-literal simplification in both. A streamed version then consumed a single certified choice immediately instead of retaining a chain of unary plan nodes. Each successful round removes at least one variable; if no single choice is justified, the prefilter returns the current equivalent formula to the old WRAPPER. It never interprets failure as UNSAT.

This is an explicit input-dependent loop with a decreasing integer rank, not an inference from fixed-depth asymptotics. Its termination follows from at most $n$ successful rounds. Its ordinary tuple implementation still materializes formulas and has no sublinear-space theorem. Finite existential ARC iteration remains a separate statement.

\section{Second build: a density-gated two-pass VALUE recognizer}
The first build still retained root-scale data. To address that limitation on the same family, a separate file-first implementation was built. It runs \emph{before} any materializing WRAPPER parser. It returns an exact VALUE result or FAIL. On FAIL the rest of the portfolio may continue, with the attempt's cost included.

\subsection{Exact accepted domain}
The recognizer reads a stable, read-only DIMACS file with bounded-width integer tokens. It safely declines comments and encodings outside its declared canonical subset. Accepted formulas have $p$ positive clauses of a common width $h$, and otherwise only distinct negative binary clauses. Variables are exactly $1,\ldots,n$, with $n=ph$, and
\[
 2\le p,h,\qquad \tfrac12h\le p\le2h,
 \qquad e=h\binom p2,
\]
where $e$ counts the negative clauses.

It then proves from the source that the negative-clause graph is a disjoint union of $h$ complete graphs on $p$ vertices. Each positive clause contributes exactly one variable to each graph component, and every variable belongs to one positive clause. Thus the formula is a rectangular pigeonhole encoding up to a positive variable renaming. No row/column naming convention is trusted.

\subsection{Implementation and failed-attempt accounting}
The first pass parses the complete file, checks literal order, excludes duplicate negative clauses, verifies the positive widths and counts, and applies the balance and density gate. It uses only counters, two-literal records, and a fixed-size byte buffer. \emph{No variable-indexed array is allocated before the gate.}

Only then does the second pass allocate parent, component-size, degree, and positive-row arrays. Union-find processes negative edges without keeping an edge list. At completion, every vertex must have degree $p-1$ and belong to a component of size $p$. The graph is simple by the first-pass check, so these components are cliques. Sorting $n$ pairs (component, positive-row) rejects any repeated incidence. With $p$ rows and a $p$-vertex clique, this proves one variable from every row per component.

The source must stay unchanged between passes, as in the read-only input model. The implementation does not defend against an external actor modifying its input file mid-computation. Malformed encodings, duplicate edges, wrong components, and wrong row incidence produce FAIL rather than a SAT answer.

\begin{proposition}[DENSITY-GATED-PHP-VALUE1: proposed exact member]
In the stated immutable-source indexed-CNF model, the recognizer halts on every input with FAIL or an exact zero-child VALUE. On every attempt it uses
\[
 T(M)=M^{1+o(1)},\qquad S(M)=M^{2/3+o(1)},
\]
where $M$ is encoded input length. It succeeds on the balanced rectangular pigeonhole domain just defined. A successful answer is TRUE exactly when $p\le h$.
\end{proposition}
\begin{proof}
After successful recognition, each positive clause is a pigeon, and each negative clique is a hole. Any model makes at least one variable true in each of the $p$ rows. A negative clique allows at most one true variable, so $p\le h$ is necessary. If $p\le h$, choose distinct components for the rows and set the corresponding variables true. This satisfies every clause, proving sufficiency.

For the resource bound, a first-pass rejection uses logarithmic working counters and a fixed byte buffer. A later allocation is permitted only after $n=ph$, the balance condition, and the edge-count check have passed. Since $p\ge\sqrt{n/2}$ and $p-1\ge p/2$,
\[
 e=\frac{n(p-1)}2\ge \frac{n^{3/2}}{4\sqrt2}.
\]
The encoded source has at least a constant number of bits per negative clause, so $n=O(M^{2/3})$ even when the later semantic checks fail. Arrays and incidence records therefore use $O(n\log M)=M^{2/3+o(1)}$ bits. Oversized integer tokens are rejected before their storage can defeat this bound.

Two source scans cost $\widetilde O(M)$. Union-find with path compression and union by size costs $O(e\alpha(n))$ operations; sorting $n$ incidence pairs costs $O(n\log n)$ comparisons. Charging $O(\log M)$-bit operations and parsing introduces only polylogarithmic factors. The result is $M^{1+o(1)}$ time. The callable recognition core is separate from the test runner: importing it does not install the experimental wall-clock alarm. The bounded runner installs the 25-second alarm and records incomplete runs separately. The mathematical bounds concern the complete deterministic recognition core. The returned record contains a Boolean and finitely many counters, not a source pointer, residual formula, or deferred SAT call. No recursive children are generated.
\end{proof}

This proposition is a restricted-domain implementation theorem submitted for independent review, not a new pigeonhole theorem or a global SAT lower bound. The early density gate is load-bearing: checking it only after allocating arrays would leave failed sparse inputs outside the claimed space contract.

\section{Hostile controls and what remains open}
Exhaustive checks of all $4!2^4=384$ signed permutations found one satisfiable and one unsatisfiable four-variable proper 3-CNF with identity as its only syntactic automorphism. Neither unit/pure simplification nor the symmetry prefilter changed either source. Thus there is a concrete failure of universal symmetry coverage, not merely an unspecified concern. These tiny formulas are not claimed hard for other solvers.

The invalid-map control $(x\vee y)\wedge(\neg x)$ shows why an unchecked swap is unsafe: forcing $x$ loses a satisfying $y$ branch. Non-bijective maps and stale parent maps were rejected. Fixed-label antichains remain distinguishable until their continuation is transported. Duplicate constraints and padding do not manufacture the scanner's simple-clique certificate. Independent components still combine by AND, not by a union of OR covers.

No random oracle or external random string is used. Replacing a proven syntactic map with an oracle assertion would require its own charged correctness interface. An affine solver can already decide the antichain family, so its orbit count is not a machine lower bound. A current-scale hypothetical SAT call still retains its unknown exponent; this run does not rename such a call as recognition.

The mixed ARC route remains available. If an all-input, pre-generation orbit cover reduced a fanout exponent from $a$ to $a-\eta$, the existing WRAPPER ledger could use that improved exponent only after adding discovery, certificate checking, replay, and space costs. This run supplies no uniform $\eta>0$ on general CNF. The two-pass VALUE member has a favorable resource cell on a verified domain, but neither it nor the symmetry prefilter covers arbitrary SAT.

The current endpoint discipline is unchanged: use the golden-ratio product endpoint where applicable, Fortnow for a verified near-linear-time/sublinear-space general SAT algorithm, and $2\cos(\pi/7)$ only with its separate small-space hypotheses. The repository protocol's older universal-$\gamma$ wording was observed but not used.
