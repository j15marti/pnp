\section{Primary literature and exact transfer}
Anders, Codel, and Heule define a unique-literal clause (ULC) as a clause whose
signed literals occur nowhere else in the formula. Their Definition 2 and
Theorem 3.1 permit orbitopal fixing when the columns of a literal matrix are
ULCs and all row permutations act as syntactic symmetries. The resulting unit
assignments preserve satisfiability \cite{anderscodelheule2026orbitopal}.
Our checker verifies the stronger special case in which off-matrix variables
are fixed. The code does not assume a supplied automorphism oracle and does
not emit the paper's substitution-redundancy proof format.

Satsuma is relevant primary work on detecting structured symmetries
\cite{andersbrennerrattan2024satsuma}. No universal near-linear detection or
SAT-shrinkage guarantee is borrowed from it. The cross-domain connection is
precise: orbitopal fixing originated in mixed-integer programming
\cite{kaibelpeinhardtpfetsch2006}, and the 2026 SAT theorem supplies the actual
transfer used here. The MIP preprint is context, not a transferred SAT
complexity theorem. No theorem number from its unread full text is asserted.

\section{One same-realization partial constructor}
The input is a read-only canonical indexed CNF $F$ of encoded bit length $M$.
Clauses and their literals are distinct and ordered; complementary pairs are
rejected by this member. Variable identifiers are bounded by the number of
literal occurrences. The finite Python tests begin with that read-only
structure already allocated. A total byte-level parser and the exact transport
to the endpoint's random-access model remain separate implementation checks.

Set
\[
 B=\lfloor M^{2/3}\rfloor.
\]
The integer cube root of $M^2$ is computed exactly. There is one deterministic
program, with three possible results: \texttt{VALUE}, \texttt{REDUCE}, and
\texttt{FAIL}. FAIL means no SAT conclusion, never UNSAT.

The member first checks the canonical representation without copying the
parent. Complement detection uses two indices rather than an unbounded
clause-sized set. Before allocating variable arrays it requires $n\le B$.
It counts literal occurrences, chooses one deterministic variable-disjoint
ULC family, and uses union--find on complementary binary conflicts to propose
rows. The matrix is discovered from the source, not supplied as free advice.
Discovery is deliberately incomplete.

For a proposed $r\times q$ matrix, capacity checking counts each pair of
columns only when the source contains its complementary binary conflict in
a common row. Pair storage is capped before allocation. If capacity does not
settle the input, the member verifies the full row action by the exact
orbit-saturation test below. Stored signature payload is capped by $B$ cells.
After verified fixing, source-scanning propagation is limited to eight passes.
Before emitting a residual, a separate charged scan verifies its ordinary
encoded length is at most $B$. Only then is the child materialized.

All profile, variable-array, propagation, and output cap exits abstain.
Caps are asymptotic cell controls, not promises that Python's heap consumes
at most $B$ bits. Each retained identifier/counter occupies logarithmically
many bits in the declared RAM realization. The adapter applies this member
at every recursive call and falls back to the unchanged exact wrapper on
FAIL. The fallback's formula caches and DAGs remain charged; they do not
inherit the partial member's bound.

\section{Orbit saturation without enumerating permutations}
Let the matrix entries be pairwise distinct signed variables. The symmetric
group $S_r$ permutes its rows, commutes with complementation, and fixes every
off-matrix variable. For each clause $C$, retain its outside literals and,
for each occupied matrix row, the signed column indices appearing in $C$.
Sort these row profiles and record each nonempty profile's multiplicity
$m_\tau$. The row names are discarded, but literal signs and outside
literals are not.

\begin{theorem}[Orbit-saturation criterion; proof supplied, RED pending]
This signature identifies exactly one clause orbit under the stated action.
If $k=\sum_\tau m_\tau$, its cardinality is
\[
 |\mathcal O(C)|=
 \frac{r!}{(r-k)!\prod_\tau m_\tau!}.
\]
A canonical duplicate-free CNF is invariant under this row action if and only
if each observed signature occurs in exactly this many distinct clauses.
\end{theorem}
\begin{proof}
A permutation can change the positions of the row profiles but cannot change
their multiset or the outside literals. Conversely, equal multisets admit a
bijection matching rows profile by profile; extend it arbitrarily to the empty
rows. This permutation maps one clause to the other. Permuting the empty rows
and the equal-profile rows is precisely the stabilizer, giving the displayed
orbit size. The distinct clauses with any one signature form a subset of that
finite orbit. Equality of cardinalities is equivalent to containing the whole
orbit. Applying this separately to every signature proves both directions.
\end{proof}

The implementation uses an AVL comparison tree, not a digest equality rule.
Orbit sizes are evaluated as capped binomial products; a count larger than
the source clause count is rejected without constructing factorial-sized
integers. Duplicate clauses must be rejected before the test: duplicates can
otherwise imitate the cardinality of missing orbit members. This is a
specialized application of elementary orbit--stabilizer accounting, not a
claim of a new general graph-isomorphism algorithm.

\section{Capacity VALUE and bounded resource accounting}
\begin{lemma}[Checked capacity]
Suppose the $q$ matrix columns are actual positive-in-the-matrix-orientation
clauses on disjoint variables. Suppose, for every row and every two columns,
the source contains the binary clause forbidding both entries from being
true. If $q>r$, the source is UNSAT. If $q\le r$, a proposed injective
assignment may establish SAT only after it satisfies \emph{every} source
clause.
\end{lemma}
\begin{proof}
Every column requires a true entry. The verified row conflicts prevent one
row from serving two columns. A satisfying assignment would therefore select
an injection from $q$ columns into $r$ rows, impossible when $q>r$. Extra
clauses cannot restore satisfiability. For the second statement, direct
verification of the complete source is the certificate; matrix dimensions
alone are not sufficient.
\end{proof}

Canonical uniqueness permits an inexpensive coverage check: for each column
pair, there are at most $r$ eligible distinct within-row binary conflicts.
Counting exactly $r$ therefore verifies every row. The candidate matrix must
already consist of distinct variables with the advertised column clauses.
The code checks those facts before using the count.

\begin{theorem}[Bounded partial interface; model-qualified CANDIDATE]
On the declared canonical read-only indexed-CNF domain, the comparison/array
realization of the member has local work $\softO(M)$ and live workspace
$\softO(M^{2/3})$, including FAIL outcomes. A successful REDUCE emits one
ordinary CNF of length at most $\lfloor M^{2/3}\rfloor$ and preserves SAT;
a successful VALUE is correct. This does not assert success on every input.
\end{theorem}
\begin{proof}
There are constantly many source scans before propagation, at most eight
propagation scans, and constantly many output/witness scans. Literal
occurrence arrays, the matrix, union--find, and candidate lists occupy
$O(n)$ cells after the pre-allocation $n\le B$ guard. Candidate ULCs contain
only uniquely occurring signed literals, so their total retained occurrence
count is $O(n)$. The pair counter is allocated only if its size is at most
$B$. Profile-tree payload is checked before each insertion. A temporary
signature has no more entries than its source clause, hence $O(n)$ cells.
The checked ordinary child and its sorting buffers occupy $O(B)$ cells.
Union by rank has logarithmic path depth. Sorting signatures and balanced
comparison-tree operations add polylogarithmic work to total source length;
capped binomial arithmetic uses logarithmic-size integers. Thus work is
$\softO(M)$ and space is $\softO(B)$. Temporary storage and cap failures are
included. Capacity soundness follows from the preceding lemma. Otherwise
verified row symmetry and ULCs justify the known fixing rule; propagation
and ordinary residual emission preserve its SAT answer.
\end{proof}

The theorem is a source-level RAM accounting proof, not a measured CPython
bit-machine theorem. The executable uses ordinary Python mappings for some
assignment/output bookkeeping; these have an array/comparison realization
with the stated bounds. Mechanical serialization, deterministic primitive
cost transport, and independent review are still required before using this
member in an endpoint proof. In particular, the unrestricted fallback solver
is not covered by this theorem.

For the standard dense pigeonhole family with $q=r+O(1)$,
\[
 M=\Theta(r^3\log r),\qquad n=rq=\Theta(r^2),
 \qquad \binom q2=\Theta(r^2).
\]
The capacity path naturally fits the proposed sublinear storage scale and
settles the instance without building any recursive DAG. This is an easy
recognizable family for the new certificate, not a lower bound against other
SAT algorithms and not a new point in the general-SAT achievable region.

\section{Barrier audit and remaining implication}
All permutation, capacity, and certificate reasoning is explicit. No SAT
oracle, random oracle, uncharged source evaluator, nonuniform advice, or
hypothetical solver is used inside the member. Neither relativization nor
algebrization is crossed by these local rules. Natural Proofs is not invoked;
no large constructive property of unrestricted circuits is proposed.

The key distinction is now sharper. The member can reject a costly attempt
without leaving its declared local envelope, and it demonstrably avoids
constructing the old DAG on certain sources. It has not shown that its
success domain, or a finite union of other comparably bounded domains,
covers every CNF. On uncovered inputs the adapter pays the unchanged
fallback's cost. That surviving coverage obligation is not solved by a
fixed hash, a large semantic orbit, or the existence of a polynomial seed.
Finite existential ARC iteration remains permitted. No input-dependent
unbounded iteration is inferred from these tests.
