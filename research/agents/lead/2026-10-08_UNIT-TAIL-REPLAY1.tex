\section{Existing work and concrete change}
The earlier source-backed solver already included iterative propagation and
trail undo. COMBINED-REPLAY1 integrated frontier processing, AND/OR recursion,
source replay and bounded exact sharing, but still recursively called itself
on each forced unit. The new subclass replaces only that unit call by a loop.
Frontier processing still occurs first; unit propagation begins after a
frontier-cap exit. Component AND and Shannon OR remain recursive. Cache
lookups still require exact normalized-stream agreement after hashing.

Pre-unit states are not saved for insertion into the answer cache on unwind.
Otherwise an auxiliary list could reproduce the removed storage cost.
The currently resolved state may still be cached within the original budget.
Omitting optional cache insertions preserves correctness but can change
future reuse, work and search behavior. No general speedup or monotonic
workspace improvement for all workloads is claimed.

\section{Correctness and descriptor accounting}
Fix an input CNF on labels $1,\ldots,n$ and state $X=(I,M,V)$.
If its residual contains a unit literal $\ell$, every satisfying extension
must assign $\ell$ true. Hence the residual at $X$ and the residual at
\[
 X'=(I,M\cup\{|\ell|\},V[|\ell|\leftarrow(\ell>0)])
\]
have identical satisfiability. The implementation realizes this operation
with bit masks. The variable is unassigned before the transition, so at
most $n$ such transitions occur without returning or entering another
branch. Induction proves that replacing the recursive single-child call
by the loop preserves every returned SAT value. Existing exact cache
entries remain sound; omitted insertions cannot manufacture an answer.

Let $d(I)$ denote a scope descriptor length. A retained state requires
$O(d(I)+n)$ logical bits under the dense-mask representation.
A chain of $u$ separately retained ancestor states has the conservative
upper bound $O(u(d(I)+n))$; this is not a claim that a physically shared
scope is copied $u$ times. The loop retains one current state instead.
Temporary old/new mask overlap remains $O(d(I)+n)$ and is charged.
Ancestors from genuine AND/OR calls, component structures, bounded cache,
normalization maps, parsing/indexing and source access remain separate.
This statement concerns state-descriptor payload, not total Python heap
or an endpoint machine-space theorem.

The method is ordinary iterative propagation/tail-call elimination.
MiniSat's original implementation supplies the related standard pattern of
a trail and rollback to decision levels; its \texttt{cancelUntil} code
does not supply any new unrestricted SAT bound [L]. The present change
integrates that memory-management lesson into our particular source-replay
realization; it is not a new general SAT technique.

240 seeded small random formulas under two cache budgets; forward,

with independent truth-table evaluation. Its separate executable and

\section{What advances and what remains}
This removes an avoidable descriptor multiplier along unit-only paths.
Source reads remain unchanged in the cache-free chain controls and grow
quadratically in the displayed variable count. General fallback branching,
scope lists and normalized-stream comparisons remain.
Even $O(n)$ variable-mask storage does not imply $N^p$ space for fixed $p<1$
when encoded input length is $N=\Theta(n\log n)$.

The current proof spine therefore retains the exact combined wrapper,
its concrete source-backed realization, its conditional charging and
$K$-elimination theorems, and adds this implementation improvement.
The OPEN implication remains favorable simultaneous resource bounds on
all required inputs, or a proved achievable-region improvement.
The next concrete target is to reduce repeated source access while retaining
the corrected joint storage ledger. Source indexing must be charged; it
cannot be treated as free read-only derived input.
