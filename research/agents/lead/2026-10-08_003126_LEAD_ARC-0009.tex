\section{Primary literature and transfer classification}
McConnell and Spinrad define graph modules by indistinguishability from
outside vertices and give adjacency-list partition data structures with
constant work per visited incidence, culminating in linear-time modular
decomposition \cite{arc0009McConnellSpinrad}.  The exact correspondence here
is a bipartite graph with variable vertices and feature vertices
$(C_j,+),(C_j,-)$.  Equal signed columns are equal open neighborhoods, hence
false-twin modules.  We need only the simpler feature-refinement fragment,
whose proof is included below.  Classification: \textbf{THEOREM TRANSFER}
for the data-structure mechanism, with a direct project proof.

Lyu and Zhu give low-space randomized element-distinctness algorithms for a
read-only list of word-size integers using pseudorandomness
\cite{arc0009LyuZhu}.  Our elements are implicit length-$m$ signed columns,
and exact SAT cannot inherit Monte Carlo error.  Exhausting their seed space
does not preserve the cited fine-grained bound.  Classification:
\textbf{FAILED TRANSFER}.  It remains an analogy for seeking a smaller-space
exact column representation.

\section{The exact refinement theorem}
For each clause $C_j$, define features
$P_j=\{x:x\in C_j\}$ and $N_j=\{x:\neg x\in C_j\}$.  Initialize one block
containing every declared variable and successively split every current block
$B$ into $B\cap X$ and $B\setminus X$ for
$X=P_1,N_1,\ldots,P_m,N_m$.

\begin{theorem}[SIGNED-TWIN-REFINE1]
The final blocks are exactly the signed-twin classes.  They can be computed
in $O(M)$ time and $O(n\log M)$ bits.  Conservative pre-deduplication lengths
for all three SIGNED-TWIN-MACRO1 children and one accepted triple can be
gated/generated within the same asymptotic bounds.
\end{theorem}
\begin{proof}
After the first $k$ features, two variables share a block if and only if their
membership bits agree on those features.  This induction is immediate from
the split operation.  At $k=2m$, agreement is equality of the full signed
clause-incidence columns.

Represent each block by a doubly linked list and keep a block pointer for
each variable.  For feature $X$, visit only $x\in X$, move it to a temporary
marked subblock, and record each touched old block once.  Each move and final
split costs constant word operations.  Every literal occurrence appears in
exactly one feature, so all refinement work is $O(M)$.  Blocks, pointers,
marks, touched lists, and counters use $O(n)$ words, or $O(n\log M)$ bits.

After refinement, a second source scan groups literal occurrences by class
within each clause.  For all-zero, delete negatively incident clauses and
remove class literals from positively incident clauses; all-one is symmetric.
A mixed class assignment satisfies every incident clause.  Adding clause
delimiters and remaining literal tokens yields exact pre-deduplication
lengths.  Canonical duplicate removal can only decrease them.  The number of
class--clause visits is at most the number of literal occurrences.  Finally,
one accepted class is restricted in one more scan.  The previously proved
SIGNED-TWIN-MACRO1 establishes the three-child OR identity.
\end{proof}

\section{Joint exponent ledger}
Suppose $n=M^{u+o(1)}$ and the accepted explicit children have encoded length
$M^{b+o(1)}$.  The procedure has
\[
a=0,\quad c=1,\quad s=u,\quad C=1,\quad
\sigma=\max\{u,b\}.
\]
The general Williams product region uses
$\phi=(1+\sqrt5)/2$, so this restricted cell is favorable exactly when
\[
1+\max\{u,b\}<\phi
\quad\Longleftrightarrow\quad
\max\{u,b\}<\phi-1.
\]
In particular $u=2/3$ fails.  A streaming generator does not automatically
remove $b$: the recursive child solver needs a model-matched random-access or
regeneration interface.  That interface is not proved here.

\section{Hostile controls and barriers}
\begin{description}
\item[] \textbf{Easy families.} Horn, 2-CNF, affine parity encodings, and
bounded-path formulas agree with direct profiles.  Fast discovery does not
turn these easy controls into hardness evidence.
\item[] \textbf{Near twins and products.} One differing occurrence breaks
the certificate.  Independent products preserve profile equality inside
each factor but carry the other factor into children, so the size gate must
still be checked.
\item[] \textbf{Renaming, complementation, padding.} Exact refinement is
equivariant under variable renaming and complementation.  Canonical duplicate
removal precedes measurement, blocking padding gains.
\item[] \textbf{Source carry/current-scale calls.} The source is read and
charged.  The member makes no SAT-oracle call.  On FAIL, an unchanged fallback
retains its exponent by PREFIX-FALLBACK-NOEDGE1.
\item[] \textbf{Oracle/algebraic replacement.} A semantic oracle could group
more formulas; algebraic fingerprints could compare columns probabilistically.
Neither supplies an exact deterministic all-CNF successor.  The theorem
relativizes and is not the nonrelativizing hinge.
\item[] \textbf{Post-quantum ledger.} Schur powers, quadratic relations,
syzygies, collision entropy, and binding do not improve this incidence
partition.  Hash/random-oracle methods are a \textbf{FAILED TRANSFER} unless
exact verification and its source costs are restored.
\end{description}
