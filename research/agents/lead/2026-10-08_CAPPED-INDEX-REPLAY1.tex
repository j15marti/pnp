\section{New construction}
The new solver subclasses BATCHED-UNIT-REPLAY1. At each propagation call
it attempts a complete index of signed source occurrences in the current
scope, storing clause references rather than residual formulas. This is
a complete-index-or-fallback implementation, not a partially retained
selective index. All scoped clauses initially enter a deduplicated queue.
On assigning literal $\ell$ true, only clauses indexed under $-\ell$ are
requeued. Clause probes read the original source against evolving masks.

No assignment occurs during acquisition. If the next index record would
exceed the cap, all index and queue contents are cleared before invoking
the previous sweep kernel on the unchanged state. Reads already incurred
remain in the totals. A failed attempt can therefore make a run slower.
On success the index lives through this propagation call and is rebuilt
if a later invocation needs it. There is no free cross-call reuse.

Let $m,n$ be source clause and variable counts, $c$ the clause-ID width,
$v$ the variable-ID width, and $p=\max(1,\operatorname{bitlength}(2nm+1))$.
The declared packed ledger reserves $m(c+1)$ bits for the entire possible
queue and its membership vector. Each signed key reserves $v+1+3p$ bits;
each occurrence record reserves $c+p$ bits. Thus for $d$ distinct signed
keys and $L$ indexed occurrences the fit test is
\[
 U=m(c+1)+d(v+1+3p)+L(c+p)\le B.
\]
The full source $m$ is used even for smaller scopes, conservatively.
Mask and scalar scratch, caller state, live ancestors, cache and inherited
source locator are charged simultaneously outside $B$. The scratch
reservation is $8\max(1,n)+12(c+v+p)+16$ bits. Fallback retains its own
frame scratch while the sweep kernel runs.

The prototype uses Python dictionaries, sets and a deque. These numerical
reservations describe a logical packed layout, not those containers'
physical allocation. Source reads and occurrence visits do not include
every dictionary operation or big-integer bit operation. A compiled packed
realization and a complete same-model time ledger remain separate work.
The event probes use random source access; a sequential replay counter
must not be interpreted as a full sequential-source implementation.

\section{Exact correctness and read bound}
\begin{proposition}
On proper scoped CNFs, a successful indexed call computes unit-propagation
closure or detects a conflict. For clause widths $w_C$, its acquisition
and event literal reads are at most
\[
 \sum_C w_C+\sum_C w_C(1+w_C).
\]
Clause events are at most $m_s+\sum_Cw_C$, where $m_s$ is the scoped
clause count. Including empty clauses, phase probe work is therefore
$O(m_s+\sum_C w_C(w_C+2))$ before data-structure and bit-operation costs.
\end{proposition}
\begin{proof}
Initially every scoped clause is queued, so preexisting units and empty
clauses are checked. Every assignment is a genuine residual unit and
preserves all satisfying extensions. A previously inspected clause can
become unit or empty only after a literal in it becomes false; that event
requeues the clause, unless it is already queued. Variables are assigned
at most once. A clause therefore has its initial queue insertion and at
most one additional insertion per literal. Each probe reads at most its
width. Index acquisition reads each scoped literal once. Termination of
the queue without conflict certifies closure. Failed acquisition changes
no assignment, so the inherited correct sweep fallback preserves this
property.
\end{proof}
For bounded-width CNFs the successful phase has linear source-probe work,
independent of clause order. For general width the displayed bound can be
quadratic in total occurrences. Neither statement bounds the number of
propagation calls, component discovery, cache normalization or branching.
On sparse chains this implementation retains order $n\log n$ logical
index bits, so its phase improvement does not yield a sublinear-space
SAT endpoint.

\section{Literature, proof-spine effect and next target}
Chaff describes both affected-clause propagation and two watched literals
\cite{chaff}. Our prototype uses the simpler complete occurrence index,
not the full watched-literal implementation. Sparse rank/select results
\cite{sparse} explicitly distinguish a read-only represented bit vector
from its additional index. A newly generated survival vector cannot be
silently reclassified as free input. These sources support engineering
and accounting choices, not an unrestricted low-space SAT compiler.

The existing charged recurrences and conditional elimination of the
source exponent $K$ remain intact. The new option removes a demonstrated
clause-order scanning bottleneck when its index fits. It adds no proved
all-input favorable ARC point: unsuccessful acquisition plus unchanged
fallback retains the original worst-case obligation, and even successful
propagation leaves branching and other phases. P versus NP remains OPEN.

The next concrete target is a packed block-local or genuinely partial
index with an explicit rescan schedule. It should report total acquisition,
reacquisition, event probes and simultaneous retained state across all
calls, including fallback. Compare it against the recovered survivor-list
and position-block tradeoffs on actual residuals; do not assume their
required shrinkage. A successful local time-space tradeoff must then be
composed with the existing whole-solver ledger.
