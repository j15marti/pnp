## Lemma and construction
For F:{0,1}^ell->{0,1}^b with each output depending on <=w input coordinates, query once at all addresses with weight<=w. Q=sum_{j=0}^w C(ell,j). For each i and S not containing i, |S|<=w-1, compare F(1_S) to F(1_{S union {i}}). A relevant i has a witness involving no more than w-1 other relevant coordinates, so a tested pair changes. Irrelevant i never changes. After support discovery all 2^{|R_j|} truth rows lie among the already queried addresses. Shannon reconstruction with a shared address-NOT pool and two paid constant gates uses G_D<=3b(2^w-1)+ell+2 actual binary gate nodes. No free support-location oracle or postdiscovery queries.

Each output triple is a v-bit name j and a Boolean polarity p. The real implicit assignment is a_A(j)=A(j), j in {0,1}^v. Literal falsity is a_A(j) XOR p, so B(z) is the AND of 3 such flags, including duplicated names and constant components. Given an arbitrary supplied v-input s-gate assignment circuit, G_B<=G_D+3s+11 gates is conservative; no 2^v-bit assignment table is materialized in this general-CIRCUIT variant. The finite grammar instead includes the complete A truth table, so it pays every one of its 2^v source bits.

For each binary gate, its four truth-table rows give four clauses (a !=u) OR (b !=v) OR (out=f(u,v)). Off-diagonal rows become tautologies if children are identical; the real row still forces the output. Induction gives one extension for each ell-bit address, even with fan-out. Pin B=1, add genuine unused-input tautologies, deduplicate only identical ordered clause lists, then add forced-zero fresh variables with d=max(1,4-n0,ceil((m0+1-4n0)/3)). The result has n'=n0+d>=4, 2<=m'<=4n', NoDup, AllOccur, and exactly one satisfying auxiliary extension for every B(z)=1. Therefore #CNF=#B, with duplicates of clause contents at DIFFERENT addresses each still charged in #B. This zero-count test is equivalent to satisfaction of every actual addressed clause.

Real pinned k=3 input: unary 1110, unary 1^{n'}0, then m' groups of three slots, each floor(log2(2n'))+1 bits low-first; code 0 is absent, 2i+1 negative, 2i+2 positive. Exact formal input length B_F=n'+5+3m'(floor(log2(2n'))+1). The pinned FinTM2 counting machine was NOT executed.
