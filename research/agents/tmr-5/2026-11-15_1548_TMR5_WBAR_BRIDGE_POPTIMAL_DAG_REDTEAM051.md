## Results
**Theorem A [PROVED/EXACT, elementary; folklore attribution not verified, peer review OPEN].** Assume P = NP. For every Cook-Reckhow system R: R is p-bounded <=> R is p-optimal <=> R p-simulates Q_A for some polynomial-time UNSAT decider A (Q_A accepts (F, empty) iff A(F)=UNSAT).
Proof. (p-optimal => p-simulates Q_A) by definition. (p-simulates Q_A => p-bounded) the translation of the length-|F| Q_A-proof has poly length. (p-bounded => p-optimal) if every UNSAT F has an R-proof of length <= b(|F|), the prefix-extension language {(F,w): exists pi extending w, |pi| <= b(|F|), V_R(F,pi)=1} is in NP = P, so bitwise prefix search outputs an R-proof of F in poly(|F|) time; ignoring the given Q-proof this is a poly-time translation for every system Q. QED.
**Corollary.** Bridge(R) <=> (P = NP => R is p-optimal). Bridge(R) holds iff R efficiently simulates EVERY sound refutation procedure in the P=NP world: Gaussian elimination, Horn/2-SAT propagation, algebraic and circuit-compression algorithms, adaptive switching, all of them. This is the precise form of "every algorithm executes an R-derivation".
**Corollary (free-sequence clause is neutral).** Under P = NP, whenever R is p-bounded the optimal-sequence discovery is itself polynomial (Theorem A). Not charging discovery, as the directive permits, is therefore SOUND but does not weaken the bridge: the entire difficulty is the simulation, not the search.

**Theorem B [PROVED/EXACT one direction, converse OPEN].** Let T be a Pi_1-sound theory with p-time checkable proofs, T >= PV. Define R_T: a proof of F is (i, p, 1^t) where p is a T-proof of sigma_i = "for all G, M_i(G)=0 => G unsatisfiable", and M_i outputs 0 on F within t steps. R_T is a Cook-Reckhow system (soundness from Pi_1-soundness; completeness via brute force, provable in PV). If some polynomial-time UNSAT decider has a T-provable sigma_i then W̄_{R_T} is polynomial. Hence [P=NP => some poly-time decider is T-provably sound] implies Bridge(R_T). The converse needs uniform reflection for T (combining different machines over lengths) and is OPEN; it is NOT claimed. For T = PV this is Cook 1975 (EF p-simulates R_PV). Reading: for T = ZFC, a superpolynomial W̄_{R_ZFC} would only say no fast SAT algorithm is ZFC-provably sound; Bridge(R_ZFC) is a provability/independence statement, not a complexity lower bound.
