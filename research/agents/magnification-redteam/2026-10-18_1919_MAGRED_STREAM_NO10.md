## THEOREM: ONE-PASS-NO-SAMPLE10 (restricted positive construction)

Fix constants 0<tau<beta<1, an error budget epsilon in (0,1/4), source input truth-table length N=2^n, s=floor(N^beta), t=floor(N^tau). Let C_t denote n-input circuits of at most t gates, M_t=|C_t|<=2^{O(t log(n+t))}. For every f with CC(f)>s, there is a randomized one-pass transducer meeting:

(1) It consumes the N input bits in increasing address order and independently retains each coordinate with probability p, where p is a suitable dyadic probability (binary power of 1/2) satisfying

    p= N^{tau-beta+o(1)}.

(2) The retained addresses and bits form an explicitly serialized partial truth table. With probability 1-o(1), its length is

    L= N^{1-beta+tau+o(1)} = o(N).

(3) With probability at least 1-epsilon-o(1), the output is a genuine NO instance of sparse-list Partial-MCSP[t].

(4) The sampling/transducer itself uses only one left-to-right read-only input head and one two-way read/write work tape; it can be implemented in T=O(N polylog N) transitions and O(L+log N) writable cells, **provided the resulting output is left buffered on that tape**. It need not first solve MCSP and does not reread the source. An optional write-only output stream is not used as a second work tape.

**Proof of NO soundness.** A size-t circuit g disagreeing from f at d input positions can be corrected by O(d n+n) extra gates with point indicators and an XOR correction mask. Thus CC(f)<=t+Ddn+Dn for a constant D determined by the circuit basis. Therefore CC(f)>s implies

    d_H(f,g) >= d_* := max(1,(s-t-Dn)/(Dn)) = Omega(s/n)

for all size-t g, for large N. The probability that independent Bernoulli sampling misses every disagreement with one g is at most exp(-p*d_*). By a union bound over at most M_t target functions,

    Pr[sample remains consistent with some size-t g] <= M_t exp(-p*d_*).

Set p at least (ln M_t+ln(1/epsilon))/d_*, rounding UP to the nearest dyadic reciprocal within a factor of two. Since ln M_t=O(t log(n+t)) and d_*=Omega(s/n), such p tends to zero with exponent tau-beta, so (3) follows.

**Proof of output size and machine charges.** Sample count M has binomial law Bin(N,p), with mean mu=Np=N^{1-beta+tau+o(1)}. By Chernoff, Pr[M>2mu]<=exp(-mu/3). On overflow, stop retaining points, count overflow as bad seed, and keep consuming input. Store output records in increasing order on the one work tape and maintain an n-bit binary source-address counter in the scratch region immediately after the current record prefix. At each input bit, draw O(n) fresh unbiased random bits to implement dyadic sampling, update the counter with O(n) tape moves; if retained, shift the O(n)-bit scratch region right by n+1 cells, insert its binary address and observed label immediately before the scratch region, costing O(n^2) additional moves. No traversal of the accumulated record prefix is required during the source scan. At completion the record prefix contains the target list and has O(Mn) bits. Final linear serialization, if desired, is O(Mn). Total time O(Nn+Mn^2)=N^{1+o(1)} and writable output/storage O(Mn+n)=N^{1-beta+tau+o(1)}.

**Tape-model caveat.** This only proves the source **transducer** implementation. Running an arbitrary target one-work-tape decider on that buffered list without altering the CHMY source machine model is an additional fusion theorem; do not infer additive composition automatically. Target parsing must distinguish this sparse-list encoding from a dense N-entry wildcard table.
