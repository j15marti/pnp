# REDTEAM35 | Randomized INDEX replay, scoped audit
2026-10-20 15:01 Asia/Seoul. P versus NP OPEN. Two routes: MCSP/MKTP, ARC/FLMV.

**PROVED in the one-way post-pass INDEX model (known information-theoretic method).** Let X be uniform in {0,1}^N; independent public coins R; a once-only reader retains at most s bits A(X,R), then loses access to X. A decoder receives independent uniform index J and must output X_J with average error at most epsilon <= 1/2. Then

s >= N (1 - h_2(epsilon)).

Proof: s >= I(X;A|R) = N - H(X|A,R) >= N - sum_j H(X_j|A,R) >= N - sum_j h_2(e_j) >= N(1-h_2(epsilon)). In particular error <=1/3 forces s >= 0.0817041659455 N. At zero error, s>=N.

**Scope matters.** J must be revealed only after the pass. Public randomness must be independent of X. All source-derived advice is retained data and charged. Random access to the original source defeats the lower bound, as does allowing queries during the original stream. Most importantly, a SAT decision label is not an arbitrary INDEX bit. Thus this does not imply a SAT lower bound, nor that any actual CHMY generator must retain linear space.

**Computational checks.** Exact exhaustive one-bit synopses for N=3 (256 maps) achieve optimal error 1/4; for N=4 (65536 maps) achieve optimal error 5/16. Majority-of-input summary attains both optima and outperforms storing one coordinate. A separate 256-case source-dependent seed control demonstrates that uncharged R=X gives exact recovery with no declared synopsis. 135 modular-clock controls fast-forward exactly. Zero assertions failed.
