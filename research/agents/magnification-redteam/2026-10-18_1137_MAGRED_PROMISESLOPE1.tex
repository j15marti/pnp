\section{INFLATION-SLOPE-NOGO1}
Assume a source lower-bound exponent $a=1+g>1$ on an $N$-bit MCSP input. Grant a fully valid reduction producing $N'=N^{q+o(1)}$ bits, $q>1$, threshold $s'=sN^{o(1)}$, and free lazy input access. Then $\beta'=\beta/q+o(1)$. A target algorithm running in $(N')^{1+g'}$ would induce source time $N^{q(1+g')+o(1)}$. Thus the source bound can exclude only $q(1+g')<1+g$, yielding
\[
g'_{\rm cert}\le (1+g)/q-1,\qquad
\frac{g'_{\rm cert}}{\beta'}\le \frac{g}{\beta}-\frac{q-1}{\beta}.
\]
This limits the strength of the inherited proof, not actual target hardness. For an iterated sequence with $Q_t=\prod_{i<t}q_i$, the certified nonnegative excess is at most
\[
\max\{0,(1+g_0)/Q_t-1\}.
\]
If $\beta_t=\beta_0/Q_t\to0$, then $Q_t\to\infty$ and the inherited positive margin vanishes at a finite step $Q_t\ge1+g_0$. Explicit output generation costs $\Omega(N^q)$, so no omitted overhead can improve this bound.
