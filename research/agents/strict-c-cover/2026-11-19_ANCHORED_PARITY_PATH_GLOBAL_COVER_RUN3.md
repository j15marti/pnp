## PROVED: anchored strict-C SAT iff bipartiteness
The exact primitive C uses R(a,b) iff (b-a) mod 5 in {1,3}; C(a,u,v) requires either orientation of a directed triangle. An independent 125-tuple check found exactly 30 accepted triples. For a fixed anchor value a, the graph on the other four colors with edge uv iff C(a,u,v) is the path P4, with bipartition W_a={a+1,a+3} and L_a={a+2,a+4} (mod 5).

Given any undirected loopless graph H, make the physical strict-C source F_a(H)=AND_{uv in E(H)} C(a,u,v), with three distinct variable NAMES per clause and no global value injectivity. F_a(H) is SAT iff H is bipartite. Any model maps H homomorphically to P4; conversely any 2-coloring of H extends using a=0 and side representatives 1,2. A source-uniform no-advice specialist intersects clause-name sets to discover a global anchor, runs BFS on the residual original-clause-indexed graph, and returns either a full original-C SAT witness or an original-clause-indexed odd-cycle UNSAT certificate. The SAT witness and UNSAT cited source clauses are verified. Other sources return UNKNOWN. Time O(m log m) dictionary comparisons with balanced indexing, peak writable O(m) words including source parsing, output and certificates, for O(log m)-bit IDs. This is not an unrestricted strict-C solver.

## PROVED: exact strict-C anchored path parity projections
Let P_r(a,u,v), r>=2, be an r-clause chain C(a,u,w1)&...&C(a,w_{r-1},v) with r-1 fresh named private variables. Define sigma_a(t)=0 for t-a in{1,3}, sigma_a(t)=1 for t-a in{2,4}, undefined if t=a. For every a,u,v in F5, exists private variables satisfying P_r iff u,v != a and sigma_a(u) XOR sigma_a(v)=r mod 2. Proof: the chain is a walk in P4; all same-side pairs admit a length-2 walk, all cross-side pairs admit a length-3 walk, and 2-step backtracks extend to all larger r. For r=3 the projection is designated-head S, but is NOT primitive C. For r=2 it is the same-side relation. This charges r original C clauses and r-1 fresh names per gadget.

## PROVED: critical odd-cycle, exact private-block resource layout, global all-z cover
For each odd L>=7, F_L=AND_{i=0}^{L-1}C(a,v_i,v_{i+1 mod L}) has N=L+1 variables and m=L physical clauses. It is UNSAT via link-path parity, and every physical-clause deletion has a full satisfying witness obtained by alternating rim colors 1 and 2 on the surviving path, with anchor 0; the deleted clause evaluates false. It is clause-critical, primal clique number 3, and exact INCIDENCE girth 4, NOT growing girth, because neighboring clauses share a and one rim variable.

Partition the odd cycle into a length-3 path and (L-3)/2 length-2 paths; their endpoints together with a are shared z, and all interiors are disjoint private sets. Exactly q=N/2 variables are shared and P=N/2 private. Group paths greedily by at most p=floor(N^0.35) private names per block. The number of blocks is B=ceil(N/(2p))<=floor(N^0.65) for every even N>=8. Proof: floor(x)>=2x/3 for x>=2 and floor(y)>=3y/4 for y>=3, giving N/(2p)<=3N^0.65/4<=floor(N^0.65). The XOR of all path parities around the odd cycle is 1, so every shared assignment z violates some projected path; hence some whole block has NO private extension. The global negative proof is the source-indexed odd cycle with constant-size link-P4 identity, not a sampled cover. A dynamic selector computes the first failed path and returns its block. Quantifiers: forall z exists j forall private x_j: NOT F_j(z,x_j).

Important: This is ONE compact symbolic global proof, NOT one literal shared-assignment row. Literal enumeration has 5^(N/2) rows and fails the N^0.195 row restriction. The source-indexed proof length and acquisition are Theta(N), not free. The implementation uses O(N) writable words, not N^0.5 polylog N. No unrestricted lower bound or P vs NP proof follows.
