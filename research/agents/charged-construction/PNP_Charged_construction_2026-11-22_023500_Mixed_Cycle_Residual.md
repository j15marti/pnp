## Exact SAT and UNSAT semantics

In a factor exactly one port is true, so a_i XOR b_i=1 XOR z_i. A C link therefore forces z_(i+1)=1-z_i. An A link forces a_(i+1)=1-z_i, allowing precisely the ordered pairs (z_i,z_(i+1))=(0,0),(1,1),(1,0). Given any closed sequence of allowed transitions, recover each factor independently. At an A destination a is prescribed and the allowed pair guarantees a+z<=1. At a C destination choose a=0. In either case set b=1-a-z. This proves exact extension in the reverse direction.

A C link flips the state and an A link permits identity plus the directed transition 1 to 0. If the number of C links is even, use identity on all A links. If that number is odd and an A exists, start at the source of one A in state 1, use its transition to 0, then use every other A as identity. The odd number of flips on the rest of the walk returns to 1. If all links are C and t is odd, the final state is the complement of the initial state, so no assignment exists. Thus SAT holds exactly when **t is even or w contains A**. For every odd t the all-C word and a single-A mutation give opposite answers at identical encoded length, both with R=t. The orientation matters when constructing the satisfying assignment.

An equivalent general-purpose evaluator on this cycle multiplies three-state factor compatibility relations, or composes the two-state transitions above and tests for a diagonal pair at closure. A fixed-size relation retains the initial and current states. The scalar test avoids even this table on the displayed alphabet. This explains why an enumeration lower bound from 2^s or 2^k fails here. Discovery of this shortcut on arbitrary mixed graphs remains open.
