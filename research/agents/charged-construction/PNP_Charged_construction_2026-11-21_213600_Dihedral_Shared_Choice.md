For every nonempty proper 3-CNF F on densely numbered occurring variables, a uniform polynomial-time generator produces a compatibility instance with adjacent Horn and dual-Horn witnesses. Its transitions are permutations. For every assignment x to the shared selectors, the product of the chosen transitions is a rotation by four times the number of clauses violated by x. The target is SAT exactly when at least one assignment gives the identity rotation. This closes the previous Construction handoff's request for genuinely shared unresolved choices. In the previous table family one numerical permutation product answered all endpoint queries. Here the input determines a *function of the common assignment*. Its compact description is the source formula itself. Whether that function ever gives the identity retains the full 3-SAT decision problem.

## 1. Quantifiers and falsifiers

Take c≥1 proper clauses on d occurring variables, indexed 1 through d, with three distinct names per clause. Clause repetition is allowed. For a valid explicit source use gamma(d+1), gamma(c+1), then three sign-plus-ID literals per clause with IDs of width ceil(log2(d+1)). Thus M equals the two gamma lengths plus 3c(1+ceil(log2(d+1))), and d≤3c. The target language is the repository's Boolean compatibility decision. For the compulsory-read statement fix *any* total correct deterministic solver A of that language first. Its sole writable tape, finite alphabet, one local head and fixed-origin output carry the input, workspace and caches. No free clock, address oracle, advice or original-input copy. A separately hypothesized cap is T_A(I)≤K N^a for all valid inputs I, K fixed and a≥1 fixed. The reduction and the explicit upper-bound solver below are uniform algorithms distinct from this arbitrarily quantified A.

Four falsifiers are a modular wraparound that accepts a positive violation count, inconsistent choices at two occurrences of one variable, compiler/witness metadata that changes outside a claimed private edit block, or a paid cache that answers the decision without any further stage visits. The first three are addressed below. The fourth is legal and limits the checkpoint conclusion.

## 2. The reduction

Let r be the smallest odd integer greater than c and at least 3. States are residues modulo r. Write T_e(z)=z+e and J(z)=-z. For literal l, b_l(x)=1 exactly when l is false. A controlled instruction applies its named permutation if b_l=1 and otherwise the identity. One selector x_i is used at every occurrence of i. No truth tables over assignments are emitted.

Execution order in words is left to right. Start the word for clause (l1,l2,l3) with W=[controlled T_1 on l1]. For each l=l2,l3, replace W by the concatenation W, controlled J on l, inverse(W), controlled J on l. Inversion reverses the instruction list and inverts the active permutations, retaining their controlling literals. Lengths are 1,4,10. If W acts as T_e and g=J^b, the four consecutive maps send z to z+e-(-1)^b e. Induction gives T_(4 b1 b2 b3). The c clause words therefore have total length L=10c and act as T_(4u) for u the number of violated clauses. Since gcd(4,r)=1 and 0≤u≤c<r, the trajectory from 0 returns to 0 exactly when u=0. The intermediate counter is a violation count for one proposed assignment. It is never a count of satisfying assignments. Replacing the existentially shared choice by a fresh bit per instruction would invalidate the reduction.

**Full clause and identifier generator.** Give x_i identifier i. Give Z_(j,v) identifier d+1+jr+v for 0≤j≤L, 0≤v<r. The two final source IDs p=d+(L+1)r+1 and q=p+1 are padding. First emit pins Z_(0,0), then negative pins ¬Z_(L,v) in order v=1,...,r−1. Expand each pin A into the four triples (A,±p,±q) in sign order ++,+−,−+,−−. For each instruction j=1,...,L, each residue v in order, then each selector value h=0,1, emit

    (¬Z_(j−1,v), x_i if h=0 else ¬x_i, Z_(j,f_(j,h)(v))).

Here f_(j,h) is the selected identity, rotation or reflection from the instruction definition. All rows have three distinct names. A target model restricted to the selectors must contain the trajectory of 0 by induction from the initial pin. The negative final pins exclude each possible nonzero endpoint. Conversely, for any assignment with endpoint zero, setting just its trajectory true in the state layers satisfies all transitions and pins, with p,q arbitrary. Extra positive state labels allowed by implications cannot rescue a bad trajectory. This avoids the earlier quadratic-per-layer exactly-one gadgets.

**Compiler and physical encoding.** Set y=n0+1, u=n0+2, v=n0+3. Emit (y,±u,±v) in the same sign order. For each ordered source triple (A,B,C) at index i starting at 1, place two consecutive triples (¬y,A,z_i),(¬z_i,B,C), with z_i=n0+3+i. The first four rows force y=true. Each remaining pair has an extension in z_i precisely when its source clause holds at y=true. Among rows with at most one positive literal, each has two distinct negative names, so alpha with only u=true satisfies them all. Beta with exactly u,v=true satisfies all source-derived target rows by ¬y or ¬z_i and all selector rows having two or more positive literals. The supplied assignments are adjacent; neither supplies the required global assignment. The construction proves existential projection in both directions, with no claim of parsimonious counting.

| Quantity | Exact value |
|---|---|
| Internal variables n0 | d+(10c+1)r+2 |
| Internal rows m0 | (20c+4)r |
| Target variables n | n0+m0+3 |
| Target clauses m | 2m0+4 |
| Identifier width w | ceil(log2(n+1)) |
| Full target bits N | 3n+2+2 floor(log2(m+1))+3m(w+1)+w |

The physical layout is unary n and zero delimiter, gamma(m+1), the ordered sign-plus-ID triples, alpha and beta each in increasing ID order, then the w-bit release ID y. The target begins with the four selector rows, then the expanded pins, then the expanded instructions in clause order. No satellite input or free table index. Each source clause owns a consecutive segment of 40r target triples for its ten instructions. Distinct clause segments are disjoint. Header and trailer are determined by d,c. N=Theta(c² log(c+1)) and is polynomial in M. This is a new layout; none of the static permutation-family lower bounds is transferred.

**Complexity consequence.** Ordinary proper 3-SAT is NP-hard even under stronger source restrictions [1]. Applying the explicit compiler gives NP-hardness under polynomial many-one reductions, including the promise of a canonical generated input. Membership on promised inputs follows by checking a guessed Boolean assignment. For the ordinary language consisting of exactly the satisfiable canonical outputs, polynomial image recognition is described below. Therefore a uniform deterministic polynomial decider on this whole promise would imply P=NP. Whether such a decider exists is open. For a *fixed assignment* the product is always cheap; enumeration is an upper bound with no necessity assertion.

## 3. Construction, recognition and same-execution costs

A generator validates source widths, ranges, proper triples, dense occurrence and the terminal length; a scan per name suffices. Bounded counters generate each transition image by modular unit addition, subtraction or negation. Target row numbers imply all helper names. Witnesses and release field are emitted explicitly. On a sole tape with copies, working counters and output in O(M+N)=O(N) occupied span, O(N) iterations suffice up to scans for input validation. Each iteration needs a constant number of scans and arithmetic on O(log N)-bit fields, conservatively O(N²) transitions. The same O(N³) bound covers setup, producing and relocating the N bits into the standard starting configuration, erasure of auxiliary tracks, and repositioning. Source reading and writing the reduction are paid. Composing a target solver gives source time O(N³)+T_A(I) on this setup. Composition alone does not transport CM lower bounds backwards.

One fixed globally correct solver first parses the full compatibility input. Search c≤m for the equation (m−4)/2=(20c+4)r(c), strictly increasing, then recover n0,d by the table. Reject inadmissible d or dimensions before allocating. At positions 0,1,4 within each ten-instruction word, decode the selector ID from its guard and the literal polarity from which branch moves residue 1: those instructions are controlled +1, reflection, reflection, respectively. Both active maps move 1 when r is odd and at least 3. Position 1 and position 4 refer to instructions, with vertex-1 rows at a known offset. Regenerate the complete input from the proposed formula and demand exact equality of every bit, including both witnesses, every helper ID and release. A parser or authentication failure is UNKNOWN for the fast path. A correct exhaustive Boolean decision procedure on the retained original follows. A recognized input can be decided by enumerating d-bit assignments on the decoded F and caching one decision bit. A solver may instead use any shared symbolic evaluator or verified SAT witness, including early exit on SAT.

| Phase on one canonical execution | Conservative one-tape cost | Charged storage |
|---|---|---|
| Parse, candidate search, extraction, regeneration and exact comparison | O(N³) | O(N) including original, candidate, counters, copy and metadata |
| Assignment enumeration and checking, including addressing and movement | O(2^d N³) | O(N) including F, current assignment, counters |

For the enumeration bound one can inspect each literal and its selector by a full scan per lookup. For the descriptive bound a self-contained description of the N input bits and transition index suffices, with log(T+2)=O(d+log N)=O(N). Alternatively encode the occupied interval directly. On unrecognized valid inputs exhaustive enumeration over n target variables gives O(2^n N³) time, O(N) span and O(2^n N⁴) upper bounds for either CM convention. No successful-admission assumption is used for global correctness. The reduction alone uses O(N³) time, O(N) span and O(N⁴) in each CM convention. Code below implements generation and independent finite tests; the one-tape upper bounds are algorithmic bounds, not timings of Python or Z3.

For a separately fixed cap T≤K N^a the valid ceilings are S=O(N^a), physical CM=O(N^(2a)) and minimum-description CM=O(N^(a+1)). The O(N^a log N) count-map circuit ceiling is a counting simulation, outside this Boolean claim. No new bound here exceeds the cap for all fixed exponents, and time and storage maxima from different runs have not been combined.

## 4. What must a decision execution actually observe?

Use a star of same-length inputs for each k≥1, with d=3,c=7+k. The first seven clauses forbid each of the seven assignments other than 000 (one proper triple per forbidden assignment). Append k copies of (¬x1,x2,x3). The center is SAT with sole source witness 000. Leaf j replaces the jth copy by (x1,x2,x3), which forbids 000 and makes the formula UNSAT. Let D_j be the exact physical bit difference set from center to leaf j. Section 2 puts it inside clause j's private instruction segment. It is nonempty by correctness and the opposite labels. All D_j are disjoint.

Fix A as above and run it on the center. At *every* checkpoint tau let V_tau be the j for which some site of D_j was scanned in the first tau transitions. For each j outside V_tau the leaf run has so far made exactly the same transitions. Tape contents may still differ on D_j; the head, control and all cells outside D_j agree. Every write requires scanning its cell. Until a scan in D_j, no relocation, cache or preprocessing can distinguish the two executions. If the center never scanned D_j later, both would halt with the same answer at the fixed origin, outside D_j, contradicting the two labels. Thus **at least k−|V_tau| distinct actual transitions remain** on that center execution. This is a reachable comparison with an explicit leaf, without a synthetic splice or virtual residual query. On a leaf its own differing block must likewise be touched. Other blocks need not be touched on that leaf. The bound concerns *first* visits; a full preprocessing scan can exhaust it.

For a concrete entropy ledger take the center with probability 1/2 and each leaf with probability 1/(2k). Let U_j be the input's edit flag at j and B_j the public family/encoding parameters, j and all other edit flags. B_j is analytic side information, not access supplied to A. If another flag is set, Pi_j is empty and U_j=0. Otherwise E_j is the first actual transition scanning D_j, which exists on both legal possibilities by the argument above. Pi_j is the W-bit absolute source offset (zero-based, W=ceil(log2(N+1))) and the bit originally read there. Prior writes to this cell are impossible before its first scan. For the empty case E_j is empty. The decoder regenerates the public center bit at that offset and tests for a difference. Its access is to the public template only; regeneration is an analytic decoder cost, not charged as work performed by A. Conditional lengths given B_j are 0 or W+1 and therefore prefix-free. h_j=0 since B_j selects the length. The per-event record bound b=W+1 explicitly allows the real address. Head movement to that address is already in T. E_j are disjoint, rho=1. This is not a claim that one primitive transition can freely *write* an address word.

Now H(U_j|B_j)=(k+1)/(2k) times H_binary(1/(k+1)). Conditional prefix coding and |Pi_j|≤b|E_j| give sum H≤b E[T] on this distribution. The direct event count gives the stronger E[T]≥(k+1)/2. On the center it gives T≥k. These first reads can all be prepaid. With the complete retained configuration free, its hidden source cells can already determine the flags; a postprocessing entropy claim must justify the actual decoder view. Adding checkpoint bounds without tracking reuse can count the same first read many times. No full-state entropy, width, witness-count or decision-circuit lower bound follows.
