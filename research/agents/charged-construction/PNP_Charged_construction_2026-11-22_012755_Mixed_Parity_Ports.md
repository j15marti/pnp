## Construction and proof

Fix any nonempty list of t positive one-in-three constraints over v occurring names. Repeated occurrences, including within a row, are allowed. Use dense IDs or renumber by exact comparison. For each of the 3t occurrences introduce a new Boolean port. On the three ports of each row impose unsigned exact-one. For each original name, order its ports by input position. Join consecutive ports x,y by two equations on fresh labels a,b unique to that join:

    x XOR a XOR b = 0
    y XOR a XOR b = 0.

Adding the equations forces x=y. Conversely given x=y, a=0,b=x satisfies both. Thus assignments to ports extend through every join exactly when all copies of each original name agree. Since the row triples are preserved, any satisfying original assignment extends, and every satisfying mixed assignment projects to a satisfying original assignment. This proves both labels. Each helper pair admits two extensions for equal ports, so the reduction as given is for decision.

Emit one proper ternary clause for each forbidden row of each relation, negating precisely the names whose forbidden bit is one. Order exact-one blocks first in input order, then joins by first appearance of each name and consecutive occurrence. Every triple uses distinct names. All factor supports are disjoint. Each port belongs to at most two parity supports, each helper belongs to exactly two. No variable has more than three distinct supports altogether. The syntactic split is recoverable by exact eight-row tables on unsigned supports. Five forbidden rows identify exact-one and four parity-odd forbidden rows identify the homogeneous parity equation. Neither classification needs hidden provenance or hashes.

Connectivity can be required. Before the construction, optionally append one row (x,z,u_x) for every original name x using one common fresh z and a private fresh u_x. Every old assignment extends by z=0 and u_x=1-x, while restriction preserves the old rows. The augmented incidence graph is connected, and replacing variable stars with connected copy chains preserves connectivity. Apply all subsequent formulas to the augmented t,v. The polynomial reduction and elementary witness verification establish NP-completeness even on this connected subclass. This uses Schaefer's exact positive ternary relation [1]. No novelty claim for variable copying or the complexity classification in isolation.

## Size, model and constructive algorithm

There are e=3t-v joins. Source sizes are exactly d=3t+2e variables and c=5t+8e proper clauses. The compiler [2] chooses r=max(3,2 floor((c+1)/2)+1). Its ten instructions per clause and r copies per layer give n0=d+(10c+1)r+2 and m0=(20c+4)r. The adjacent-witness wrapper gives n=n0+m0+3, m=2m0+4. With w=ceil(log2(n+1)), the physical length is

    N=3n+2+2 floor(log2(m+1))+3m(w+1)+w = Theta(t² log(t+1)).

The fields are unary n and delimiter, gamma(m+1), m ordered triples of sign plus w-bit literal identifiers, two n-bit assignments, and the w-bit release ID. The inherited compiler establishes existential equivalence and adjacent local witnesses. This layout supplies no requirement to execute in clause order. Join generation uses at most O(t²) source-record comparisons plus output on dense input. Including renumbering by repeated scans is polynomial in original input length L. For dense fixed-width source rows, the entire physical reduction including canonical compilation is conservatively O(N³) transitions, O(N) span, using the existing compiler tariff and bounded source scans. For arbitrary long external name strings add a conservative O(L³) parsing/renumbering cost and O(L) storage.

Fix the uniform deterministic A before input. One finite-alphabet head reads/writes one tape and moves at most one cell each transition. Source, copies, work, addresses, retained input and terminated Boolean output share the tape. Authenticate the compiled image by bounded parsing, extracting the candidate source, regenerating and comparing all fields including witnesses. On mismatch return internal UNKNOWN and use exhaustive decision on the retained valid input. On exact match group supports, test the two relation types and disjointness of exact-one triples. Failed tests also go to fallback. Malformed encodings are rejected at validation.

On admission, eliminate the homogeneous system over GF(2), construct a basis of its nullspace, restrict every basis vector to the union P of factor ports, and row-reduce again to remove dependencies. Write s for the resulting rank. Linear projection maps the full nullspace onto precisely the span of those s vectors. Enumerate their 2^s binary linear combinations, checking whether each vector has weight one on every factor triple. Return SAT at the first success and UNSAT after exhaustion. This proof covers every admitted source, even one outside the generator image. On generated instances the projected space consists exactly of vectors constant on each name's copies, hence s=v. The helpers introduce e extra free bits upstairs that need never be enumerated. Rank zero, no parity equations and no factor groups have the usual empty-basis/empty-conjunction semantics.
