## The one lemma

For every authenticated source with disconnected complement of G, let V1,...,Vk be the actual connected components of that complement, k>=2. All vertices in distinct parts are adjacent in G. The palettes used on different parts must therefore be disjoint. Conversely independently valid colorings with disjoint palettes glue. In particular the minimum number of colors needed is the sum of the parts' chromatic numbers.

For each part use value 1 if it contains no edge of G, 2 if it contains an edge and is bipartite, and 3 otherwise. These are exactly min(3,chi(G[Vi])). Detect bipartiteness by alternating two labels across edges, initializing each connected piece. A conflict violates the forced parity along two paths, and conflict-free labels certify all edges directly. Return SAT iff the sum of the values is <=3. Truncating at three is exact for this decision because any part demanding at least three colors already needs a fourth color in combination with another nonempty part. This proof works even if a part has arbitrarily complicated induced subgraphs. No cotree or root partition is supplied. The solver may cap the running sum at four.

**Explicit compact family.** For q>=3 use 3q vertices, the first 2q a rim cycle in increasing order, and the last q an independent set. Join every independent-set vertex to every rim vertex. Add one chord, either (0,3) or (0,2). Both variants have h=3q and e=2q²+2q+1, hence n=6q²+30q+3, m=6q²+18q+3 and N=Theta(q² log(q+1)). The first rim is bipartite with at least one edge. The second has triangle 0,1,2. An independent-set vertex requires a fresh color, so the first source is SAT and the second UNSAT. The complement is disconnected in both. The parameter expands polynomially in q, with explicit output length charged. If supplied only binary q, emission is output-sensitive, not polynomial in log q. For graph reduction use an explicit vertex/edge list or unary q.

For the fixed star representation in the Synthesis report, every leaf contributes NAND independently of its private name. The nonproduct correlation graph is three disjoint copies of G, one per color. In each copy q disjoint cross edges exist by matching the independent set to distinct rim vertices. Every vertex cover therefore has at least q vertices per copy, and any greedy maximal matching's endpoints cover the graph. The earlier root budget is at least 2^(3q) on each variant. The recovered join procedure avoids enumerating those assignments. Its proof applies to arbitrary admitted graphs without hard-coding the generator's chord position. A simple family-specific classifier would also be legal after full validation.

## End-to-end costs

One deterministic finite-alphabet writable tape, unit-speed read-before-write head, terminated decision at origin. All bounds below are conservative existence bounds for the specified direct-source procedure. They are symbolic. Use dense bit matrices for graph adjacency, one visited mask for complement connectivity, and part/queue/color arrays. Keep the source, one sorted copy of each row, marked row ownership, private-ID and per-edge/color flags, counters and active addresses. Total span O(N²). Initialization is charged. Source decoding rejects out-of-range declarations against the actual length before large allocation. Graph-complement neighbors can be enumerated by scanning full vertex lists and testing nonadjacency, excluding the vertex itself. In bipartite searches check only original edges inside the current part. Every component and label is retained once. No exponential table is built. The source remains available across guard failure.

One implementation uses at most O(N^4) indexed bit operations: compare each required root triple with every parsed triple, scan remaining rows for multiplicity and private-name checks, enumerate at most h² pairs per graph traversal with membership masks, and allow even a fresh full-matrix traversal for each of h parts. These cubic word-loop bounds include O(log²(N+2)) bit arithmetic per comparison or small index calculation. Simulate indexed access by scanning the O(N²) tape region with an explicit O(log N)-bit address counter carried/updated by shifts across a local track as the head sweeps. Even an O(log²(N+2)) overhead per visited cell fits O(N³) steps per indexed bit access. Initialization, rewinding, retained source, copies, all failed tests, allocation, relocation, cache accesses, arithmetic and output are included in T=O(N^7), S=O(N²) on the guarded run. Cumulative physical span is O(N^9). Independent input-plus-step replay gives minimum-description CM O(N^8) since log T=O(log N). On legal guard failures add O(2^n N^7) time for assignment enumeration with row scans, still using O(N²) span. This yields a total decider. Its proven polynomial worst-case bound applies to the admitted class.

Generating the explicit row stream from a dense, checked graph list needs only O(N²) workspace and fits O(N^7) sole-tape steps by the same pair scans and bounded index arithmetic (including ordering, output and rejecting duplicates). For the displayed family loops generate the edge predicate directly. No advice, decomposition discovery oracle, hash equivalence or hypothetical query access enters the reduction.
