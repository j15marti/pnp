## Fixed solver and quantifiers

A starts on a single finite-alphabet writable tape at the origin with its whole original N-bit input. A transition reads/writes one cell and moves at most one. Output and terminator start at the origin. Use Discovery's canonical extraction with exact regeneration and a total exhaustive fallback on other valid compatibility inputs. On a recovered source A memoizes each exact ordered list of signed clauses. It checks empty clause/empty conjunction, applies a unit if present or a pure literal if present, splits variable-disjoint components by conjunction, then tries the switched-energy cut criterion of Discovery. On rejection it branches zero then one on the least live variable and combines by OR, stopping on SAT. Cache hits return the actual saved decision. The executable specifies tie order. Restriction removes satisfied rows and false literals. Each operation preserves satisfiability, cut admission uses the peer's specified ternary energy theorem, and each recursive call reduces the number of variables or the number of components. Thus A is total and correct. Exact key comparison includes IDs, signs, clause boundaries and multiplicities.

Fix this A before choosing k. For all k on the negative family every visit is a cache miss. Four tests could falsify the argument: a prefix produces a unit/pure literal or a disconnected residual, the switched-energy test admits an interior node, two prefixes give the same key, or the compiler changes the source decision or claimed physical length. ## Generator and labels

Use private x_i=i and y_i=k+i for 1<=i<=k, with z=2k+1, w=2k+2, a=2k+3. For each i in increasing order emit the four signed rows

    (x_i,y_i,z), (-x_i,-y_i,-z), (-x_i,y_i,w), (x_i,-y_i,-w).

These are NAE(x_i,y_i,z) and NAE(¬x_i,y_i,w), where NAE requires at least two distinct bit values among its three arguments. Append the eight possible signed triples on (z,w,a), positive before negative in lexicographic sign order. Each assignment violates precisely one of these eight, proving UNSAT. The SAT companion replaces the final all-negative row by a duplicate of the first all-positive row. Now z=w=a=1 and all y_i=0 work for any x_i, since each NAE triple contains both 0 and 1. The replacement both keeps the physical row count and pins the only possible core assignment to 111. All clauses have three distinct variable names. Repeated clauses are legal. All variables occur and the incidence graph is connected.

## Exact connected search tree

After fixing the first j private x bits, each processed pair leaves two binary rows. For x_i=0 they are (y_i,z) and (-y_i,-w). For x_i=1 they are (-y_i,-z) and (y_i,w). Consequently y_i occurs with both signs and still links z to w. Every untouched pair uses both signs of both private variables. The complete core contains both signs of its three variables. There are no unit, empty or pure-literal reductions and the entire residual is a single component, including at depth k.

To check cut admission, the violation energy of NAE(u,v,t) is 1-u-v-t+uv+ut+vt. In an untouched pair, substitution of 1-x for the second triple's first argument cancels the xy coefficient. The surviving pair coefficients on xz,yz,yw,xw are respectively +1,+1,+1,-1. The eight core clauses contribute constant 1. Other blocks and conditioned pairs cannot affect these four coefficients. For submodularity the endpoints of every positive coefficient must have opposite flip bits, and those of a negative coefficient must have equal flip bits. The cycle x,z,y,w,x has three opposite constraints and one equal constraint. Their XOR is inconsistent. This holds at every prefix j<k, so A branches on x_(j+1).

At depth k every binary clause has equal literal signs at its two positions. Complement every y_i and keep both hubs unchanged. This makes all binary pair coefficients nonpositive, so the cut test accepts. Its minimum is 1: the core costs 1 and, for example, z=w=1, all y_i=0 satisfy all block constraints for every fixed x. All leaves return UNSAT. There is no SAT early exit. At depth j the two residual sign patterns of each processed y_i identify its prefix bit exactly. Across depths the live x scopes differ. Thus the 2^j visits at each depth are distinct and the exact sum over j=0,...,k follows. Root checks alone would have missed this issue. This construction answers Synthesis's disconnected-family escape for a precisely specified component-aware architecture. The range of its identity key on this one UNSAT frontier is 2^k. Hash equality is never used to infer semantic equivalence.

## Physical construction and reduction costs

There are d=2k+3 source variables and c=4k+8 clauses for either label. For gamma(d+1), gamma(c+1), and fixed-width signed source triples, M=|gamma(d+1)|+|gamma(c+1)|+3c(1+ceil(log2(d+1))). Both the plain source and the compiled image are polynomial in k. The explicit generator above needs O(M) storage and at most O(M²) single-tape steps including successive IDs and output.

Compile using Construction's ten-instruction clause word. A false first literal enables a unit rotation, and each of the other two controls conjugation by a reflection in the word W,J,W^{-1},J. The exponent doubles exactly when that literal is false, otherwise it becomes zero. The whole endpoint is 4 times the number of violated clauses modulo r, the least odd integer greater than c. Since gcd(4,r)=1 and c<r, endpoint zero is equivalent to zero violations. This uses one shared value for all occurrences of a variable. Initial state zero and exclusions of nonzero final states use r four-clause expanded pins, and each of 10c instructions requires 2r transition rows. Hence n0=d+(10c+1)r+2 and m0=(20c+4)r. A returning trajectory extends to a model by marking just its visited states. Conversely, the transition implications force that trajectory, so a nonreturning assignment cannot extend.

The adjacent-witness compiler emits four selector rows forcing a fresh release variable, then two consecutive rows per transition/pin clause with one private extension variable. With release true the pair extends iff its original triple holds. Thus n=n0+m0+3 and m=2m0+4. Physical order is unary n and delimiter, gamma(m+1), all ordered signed target triples, the two n-bit local witnesses, and the W-bit release ID, W=ceil(log2(n+1)). The inherited witnesses set just u and respectively u,v, so their Hamming distance is one. The n,m counts and physical trailer give exactly

    N=3n+2+2 floor(log2(m+1))+3m(W+1)+W = Theta(k² log(k+1)).

Each generator record uses O(log N) bits. Iterating instruction/residue/selector counters, generating the ordered rows, copying witnesses, parsing and comparing all regenerated bits can use O(N³) tape steps and O(N) span as in the pinned parent construction. This is a Boolean decision reduction. No assignment-count factor or strict T5 transfer is used.

If there is no such set, return UNKNOWN from this shortcut and run a correct general fallback. The two hubs meet every triple on both families. This same algorithm works on every admitted source regardless of the signs, input order, or renaming. It does not require recognizing a constant contradictory subformula. No uniform two-variable guarantee exists even for three disjoint triples.

Each branch uses an implication graph: a binary row (p,q) adds ¬p→q and ¬q→p, with a repeated literal for a unit. A contradictory pair of mutually reachable complementary literals is exactly the 2-SAT obstruction [4]. Empty clauses are handled directly. This checks all assignments to the two chosen variables without enumerating the private variables.
