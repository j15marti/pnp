\section{PUBLIC TWO-PROBE IMAGE AND SMALL NO CORES}
Fix a public map \(G:\{0,1\}^S\to\{0,1\}^Q\) whose output-coordinate functions are separately computed by arbitrary deterministic adaptive two-seed-bit-probe decision trees with no cross-coordinate state. All seed words are admitted. Each output coordinate with demanded bit \(y_j\) rejects at most four root-to-leaf paths, each fixing at most two seed bits. Forbid these paths with clauses of width at most two. The conjunction \(\Phi_{G,y}\) contains at most \(4Q\) 2CNF clauses and is satisfiable if and only if \(y\in\mathrm{range}(G)\). Standard 2SAT then decides explicit image membership in time \(O(Q+S+\sum_j T_{\rm tree}(j))\), with setup and address generation fully charged. CLOCKFEATURE5 already proved this 2CNF closure; it is prior work, not a novelty claim.

\begin{theorem}[SMALL-OFFIMAGE-CORE7]
For \(S\ge1\) and \(y\notin\mathrm{range}(G)\), some fixed output-coordinate set \(J\subseteq[Q]\), with \(|J|\le\min\{Q,4S-2\}\), satisfies \(\forall z\in\{0,1\}^S\ \exists j\in J: G_j(z)\ne y_j\).
\end{theorem}
\noindent Proof. If an empty clause occurs, retain its owner. Otherwise the unsatisfiable 2CNF implication graph on \(2S\) literals has a literal \(\ell\) and paths \(\ell\leadsto\neg\ell\) and \(\neg\ell\leadsto\ell\). Take simple paths of at most \(2S-1\) edges each, and retain the original output coordinate owning each edge's clause. These at most \(4S-2\) coordinates remain unsatisfiable. This is an OUTPUT-COORDINATE core, not a set of data-structure memory cells.
\begin{theorem}[LINEAR-CORE-NECESSARY7]
The worst-case minimum core size is \(\Omega(S)\), even for nonadaptive two-probe coordinates.
\end{theorem}
\noindent Proof. Use \(S+1\) outputs \(G_0(z)=z_1\), \(G_i(z)=\neg z_i\vee z_{i+1}\) for \(1\le i<S\), \(G_S(z)=\neg z_S\) and target \(y=1^{S+1}\). Their joint conditions contradict. Removing the initial condition permits all zeroes, removing the terminal condition permits all ones, and removing implication \(i\) permits the prefix-ones/suffix-zeroes assignment. Thus all \(S+1\) coordinates are needed.
\begin{theorem}[THREE-PROBE-IMAGE-NP-COMPLETE7]
Public nonadaptive three-probe generator-image membership is NP-complete.
\end{theorem}
\noindent Proof. Given a 3CNF on \(S\) variables with \(Q\) clauses, let coordinate \(j\) compute the \(j\)-th clause using at most three seed-bit reads and set target to \(1^Q\). Image membership is exactly 3SAT; a seed is an NP witness. This is a textbook reduction, not a new separation.
\section{KPI PRODUCT CONSEQUENCE AND THE QUANTIFIER GUARD}
In KPI-PRODUCT-PROBESEP6 the columns of a polynomial-evaluation product family on \(Q=bN\) queries admit \(k\)-wise independent bits for \(k\ge C\log Q\). KPI Theorem 1 in the even \(t=2,w=1\) bit-probe model gives \(S=\Omega(Q/\log Q)\) for an exact static data structure representing EVERY database with one fixed public decoder. Let \(S\) be strictly below the guaranteed bound.
\begin{theorem}[KPI-DECODER-SPECIFIC-CERT7]
For every public adaptive two-probe decoder \(G:\{0,1\}^S\to\{0,1\}^Q\), there exists a database \(a\) and one fixed coordinate set \(J_{G,a}\) of at most \(4S-2\) positions such that no memory state \(z\) matches the column \(F(\cdot,a)\) on all of \(J_{G,a}\).
\end{theorem}
\noindent Proof. If every product column were in the image of \(G\), choosing a preimage for each database would violate KPI's exact space bound. Hence some column is outside the image and SMALL-OFFIMAGE-CORE7 applies.
The actual quantifiers are \(\forall G\ \exists a\ \exists J_{G,a}\ \forall z\), NOT \(\exists a\ \forall G\). Identifying \(a\) may require infeasible search and is not charged as free. Nor is this one small fixed GLOBAL MEMORY CELL SET that resolves many complete blocks. A decoder hardwiring one particular column with a \(Q\)-bit public description illustrates the failure of a quantifier swap. The prior source-aware row-basis quotient reconstructs full blocks OFFLINE but may need many online probes.
\section{PROMISE, SUCCINCTNESS AND FALSIFICATION}
An arbitrary restricted seed-admissibility predicate \(R_D(z)\) can restore NP hardness even for constant-output \(G(z)=1\): with \(R_D(z)=F_D(z)\) for 3CNF \(F_D\), the promised image contains target \(1\) iff \(F_D\) is satisfiable. This moves all hardness into the seed promise, and is not valid against unrestricted alternative encodings.

If \(Q,S\le2^{\mathrm{poly}(m)}\), target bits and the uniform public coordinate trees are computable in \(\mathrm{poly}(m)\) space, then succinct two-probe image membership is in PSPACE. Scan implicit output constraints to answer implication-edge queries and use Savitch reachability on a \(2S\)-vertex graph with \(O((\log S)^2)\) recursion space. This does not prove a joint clock-independent semantic gate.
