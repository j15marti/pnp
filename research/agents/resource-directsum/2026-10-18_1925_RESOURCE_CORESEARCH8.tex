\section{KPI-LEX-SPACE8: an alternative low-space diagonal proof}
Let $M=2^m$, fix $\alpha+\beta<1$ with $\alpha,\beta>0$, and a fixed decoder-workspace exponent $\sigma\ge1$. Put
\[
D=\lfloor\alpha m\rfloor,\quad S=\lfloor M^\beta\rfloor,\quad
C(m)=\max\{1,\lfloor m/\log_2m\rfloor\},
\quad L=C(m)(2^{D+1}-1).
\]
Partition the first $LQ$ outputs into $L$ blocks of $Q=2^n$ bits, $n=\lfloor\log_2\lfloor M/L\rfloor\rfloor$. Thus $LQ\le M$ and $S=o(Q/\log Q)$. One block is reserved for each pair $(d,c)$ with $|d|\le D$, $1\le c\le C(m)$. Let a fixed universal decoder on $(d,c,i)$ prepare a deterministic adaptive two-seed-bit decision tree using at most $m^c$ steps and $m^\sigma$ writable cells, with invalidity/timeouts mapped to a fixed zero rule. No mutable state is carried between coordinate calls. The tree record is $m^{O(\sigma+1)}$-space generable.
Over $\mathbb F=\mathbb F_{2^n}$ take $k=2n$ and coefficient tuple $a\in\mathbb F^k$ of $kn=O(m^2)$ bits, with codeword
\[
T_a(x)=\operatorname{Tr}_{\mathbb F/\mathbb F_2}\left(\sum_{r<k}a_rx^r\right).
\]
For each pair $(d,c)$ let $G_{d,c}:\{0,1\}^{S}\to\{0,1\}^{Q}$ be the decoder restricted to its assigned block. The Vandermonde full-rank argument followed by balanced trace gives $k$-wise independent fair output bits for uniform $a$. KPI Theorem 1 ensures some $T_a$ is outside $\operatorname{range}(G_{d,c})$. Select the lexicographically first such $a_{d,c}$ and place $T_{a_{d,c}}$ on this block, with remaining unassigned positions set to zero.
\begin{theorem}[KPI-LEX-SPACE8, conditional only on cited known theorems and declared model]
The assembled $H_M$ defeats every such pair $(d,c)$ and every seed $z\in\{0,1\}^S$ on the block assigned to $(d,c)$. Every bit of $H_M$ is computable in $m^{O(\sigma+1)}$ writable space, with no dependence on a subsequently chosen fixed clock $c_0$. A direct Savitch implementation uses at most $2^{O(m^2)}$ time up to fixed polynomial factors in decoder tree preparation.
\end{theorem}
\noindent\emph{Proof.} For fixed $(d,c,a)$, the equation $G_{d,c}(z)=T_a$ is a conjunction of width-at-most-two clauses, one for each rejecting path of length at most two. There are at most $4Q$ clauses over $S$ seed bits. Their implication-graph adjacency is enumerable using $m^{O(\sigma+1)}$ work bits: loop over output positions and tree branches, simulate the bounded decoder, evaluate the trace word from the $kn$-bit coefficient tuple. Two-SAT unsatisfiability is detectable by mutual reachability of a literal and its complement, using Savitch on the graph of $2S$ literals and $O((\log S)^2)=O(m^2)$ additional space. Enumerate $2^{kn}=2^{O(m^2)}$ candidate tuples in that same space to find the first missing one. Recompute the tuple on each coordinate query instead of retaining the $Q$-bit block. KPI guarantees termination. If a program represented all of $H_M$, then its own diagonal block would be a missing column in its range, a contradiction. $\square$
\noindent\textbf{Scope and hostile control.} This is an alternative derivation of the already targeted low-space uniform KPI diagonal, not a new unrestricted lower bound. Fixed seed length $S$, two adaptive bit probes, description $O(m)$, a fixed $m^\sigma$ decoder workspace cap and exact deterministic outputs are mandatory. It does not cover decoder workspace $m^K$ for arbitrary $K>\sigma$, randomized decoders or source-specific public advice. The algorithm is PSPACE in its succinct index, not necessarily P or PH. Neither $P=NP$ nor $P=PSPACE$ alone produces a contradiction from this fixed-$\sigma$ diagonal.
\section{PROMISED-CYLINDER-COMPLETE8: one actual global cell set}
Let each complete block belong to a public linear code $\mathcal C_i\subseteq\{0,1\}^{Q_i}$ of dimension $d_i$ with determining coordinates $R_i$, $|R_i|=d_i$. Fix one public deterministic adaptive $t$-probe decoder $G$ on an $S$-cell table and a valid seed set $\mathcal Z\subseteq\{0,1\}^S$ such that all $G(z)|_{Q_i}\in\mathcal C_i$ for $z\in\mathcal Z$. Write $D_*=\sum_i d_i$.
\begin{theorem}[PROMISED-CYLINDER-COMPLETE8, elementary restricted model]
For every fixed valid seed $z$ there is one set $C(z)$ of actual memory cells of size at most $tD_*$ such that all valid seeds $z'$ agreeing with $z$ on the cells in $C(z)$ produce the SAME ENTIRE collection of complete blocks, even if the decoder recomputes different adaptive probe addresses at different queries.
\end{theorem}
\noindent\emph{Proof.} Let $C(z)$ contain every cell actually touched by the $D_*$ basis queries on $z$. Agreement on these cells forces equality of the first probe answer for each basis query, hence equality of every adaptively chosen next address and answer by induction through the query tree. Therefore the basis answers agree for $z,z'$. Each complete codeword is uniquely determined by its basis-coordinate values, hence every output coordinate in every block agrees. $\square$
\begin{corollary}[Cell-certificate counting]
If every product codeword is attained by some valid seed, then
\[
2^{D_*}\le\sum_{j=0}^{\min(S,tD_*)}\binom Sj\,2^j.
\]
\end{corollary}
\noindent Each output has a witness $(C(z),z|_{C(z)})$, and no one cylinder can certify two distinct valid outputs. Choosing and replaying all $D_*$ basis queries costs up to $tD_*$ actual probes and their full address-generation work. Storage of selected addresses and contents costs $O(tD_*(\log S+w))$ bits. Unselected outputs may require $\Omega(d_i)$ operations/reads from $C$ to reconstruct OFFLINE. Valid-seed membership is a promise, potentially computationally difficult, and cannot be treated as a free semantic gate.
\noindent\textbf{KPI hostile control:} the product trace-polynomial family has $d_i\le kn=O(\log^2 Q)$, so a global $O(t\sum_i d_i)$ cell certificate for all complete blocks can coexist with KPI's $S=\Omega(bQ/\log(bQ))$ TWO-PROBE ONLINE STORAGE bound. A small complete-block set is insufficient on its own for an online lower-bound contradiction.
