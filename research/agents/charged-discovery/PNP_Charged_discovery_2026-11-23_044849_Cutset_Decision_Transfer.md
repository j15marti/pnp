Fix a uniform deterministic solver A before choosing any input. For every authenticated triangle-bundle source with finite simple quotient Q, q vertices, k edges, c components and r=k−q+c, A checks permutation-sign consistency. A conflict gives UNSAT. In the consistent case the established affine reduction gives oriented constraints x_u−x_v≠g_uv over F3. A constructs a spanning forest using a fixed edge order. For each cotree edge, select one endpoint. Let S be the union of selected endpoints and s=|S|≤r. All edges of Q−S lie in the spanning forest, so Q−S is a forest. This is a computed sufficient cutset, with no minimum-cutset oracle.

For every assignment a:S→F3, test all edges internal to S. A failed test discards that assignment. Each edge from S to its complement removes one incompatible value from the other endpoint's domain. Root each remaining tree. In postorder, let L_v contain the values of v that survive its unary restrictions and have support in each child's retained set. Explicitly, b∈L_v if b survives the S-neighbor tests and, for each child w, some d∈L_w satisfies the actual oriented edge inequality. The inverse label is used on a reversed edge. The branch succeeds exactly when every root has a nonempty set. The empty forest succeeds whenever the internal S tests did.

Induction over a subtree proves that L_v is exactly the set of root values extendable to that subtree under the fixed S assignment. The subtrees have disjoint variables and share only v, so choosing one support per child gives a simultaneous extension. Every complete satisfying assignment appears in one enumerated S branch, and every successful branch extends to a complete coloring and then to the original source. Both directions hold for disconnected quotients, isolated vertices and every valid edge labeling.

A returns a single Boolean verdict and terminator. It does not construct a full witness relation or repeatedly solve the same rooted subtree for every possible full vertex assignment. Its table has three bits per remaining vertex, reused between S branches. This is an application of classical tree CSP and cycle-cutset conditioning [1], with the concrete discovery and machine charges below.

Four falsifiers are a cotree edge surviving in Q−S, omitted constraints internal to S, using a child's support without holding its parent's value fixed, and treating a large cutset as a lower bound. The endpoint construction, internal tests and induction exclude the first three. The last inference is expressly unsupported.

## A concrete failure of the prescribed computation graph

For each t≥0, let Q_t be K4 on vertices 0,1,2,3 with a path of t additional vertices attached at vertex 3. Then q=t+4,k=t+6,c=1,r=3. Process the six K4 edges in lexicographic order, then the path. The forest retains 01,02,03 and all path edges. Cotree edges 12,13,23 give S={1,2}, so s=2. The solver considers at most nine S assignments, using polynomial work along the forest even as q grows.

Both labels occur with all matching signs positive. With every gain zero, the K4 constraints are ordinary three-colorability and UNSAT. Set only g_01=1, keeping all other gains zero. Colors x_0=x_1=0,x_2=1,x_3=2 satisfy K4, and extend along the path by choosing a color different from the preceding one. Thus the second source is SAT. Both have n=42t+186 and m=30t+138, and N=Theta((t+1)log(t+2)). Every gain is realized by an actual rotation matching. This family uses the original compiler and a recognizable quotient, and has no all-UNSAT promise.

Consider the complete ternary assignment tree that evaluates every one of the 3^q colorings and aggregates the leaves into one OR. A computation required to pebble every dependency of this particular OR circuit has exponentially many prescribed leaf evaluations. Our A computes the same decision on Q_t within the polynomial bound above. Therefore the implication from SAT correctness to faithful evaluation of that fixed tree is false. This does not contradict any pebbling theorem, and the assignment tree size is not itself an I/O lower bound.

Hong and Kung [2, Theorem 3.1 and Lemma 3.1] study a specified computational DAG and a two-level memory with at most M red pebbles. Their load/store count obeys Q_IO≥M(P(2M)−1), where P is the minimum partition count under their dominator, boundary and acyclic-dependence conditions. Computing a vertex requires all predecessors in fast memory. The theorem quantifies over complete calculations obeying that DAG. It permits recomputation within those rules.

Applying it to arbitrary offline SAT still requires a theorem mapping every correct decision execution, including this cutset algorithm and paid algebraic preprocessing, to a legal complete calculation of the chosen DAG, with controlled overhead and a valid memory-model conversion. The displayed family refutes that mapping for the full assignment tree. A more appropriate DAG may describe this algorithm, but a lower bound for it would still concern that algorithm unless necessity is proved. A sole-tape transition cannot silently be identified with one arbitrary-word I/O.
