Every renaming view is the restriction to its full declared scope of a supplied permutation h of the SAME universe [v]. Let G be the subgroup of Sym([v]) generated by all these h on this execution, including adaptively selected ones, and g=|G|. No depth bound is imposed.

Then every target handle has a DLDD expansion with at most O(gM) nodes. The cumulative closed extension cost, hence the positive-part completion defect sum_j[max(kappa_j-c q_j,0)], is at most O(gM^2), for any c>=0 and disjoint charged actions q_j>=1. Constants are absolute up to record normalization. Final target closure is counted; untyped scalar-only termination is excluded.

Thus if g<=C(W+v+1)^c for fixed C,c independent of input, expansion is O_A,C((W+v+1)^(c+1)) and cumulative defect O_A,C((W+v+1)^(c+2)), **independent of nesting depth**. This settles a restricted subcase of T5-NESTED-RENAME-UNBOUNDED1, not arbitrary permutations or arbitrary scalar solvers.

Concrete subclass: v>=3 and all maps i -> s+epsilon*i mod v, epsilon in {-1,+1}. This dihedral group has2v elements. Arbitrarily deep cyclic/dihedral view nesting therefore has expansion O(vM) and cumulative defect O(vM^2). For v<=2 use the distinct maps, at most2v (v=0 use identity).

1. A legal expansion needs more than one native node per (record,group element) up to fixed normalization, despite memoization.
2. A view map changes cardinality/count because it omits declared free variables or is not bijective.
3. A scalar-only answer is accepted as a relation handle, or an uncharged template/group is used.
4. A claimed small global group actually grows under composition, or local maps lack the specified common-universe extensions.

## Proof and uniform expansion algorithm
Let p act on variable labels by substitution i -> p(i). Define Expand(u,p), initially p=id:
```
if (u,p) cached: return its stored expanded pointer
if u is a view (b,h):
    result = Expand(b,p compose h)
if u is native:
    expand each child under p
    replace each variable label i by p(i)
    keep the native operator and map its declared scope by p
    create the corresponding typed node (constant-size normalization)
cache (u,p) -> result; return result
```
A view contributes a pointer alias, not an extra Boolean operation. Dependency identities strictly decrease during recursive calls, so the algorithm terminates regardless of view depth. Starting at identity, every accumulated map stays in G by closure. Thus there are at most gM memo keys, and at most a constant number of native output nodes per key.

Induction on record identity proves semantic correctness. Constants and literals are immediate. For native records the same bijection applied to both children preserves disjointness, absence of decision variables, Boolean operations and scope cardinality. For a view, renaming first by h then p is renaming by p compose h. The argument also proves preservation of exact scoped count under views. Native shared subrecords with the same accumulated map use exactly one cached pointer. Different contexts may coincide semantically, but no unproved merge is required.

For an action producing a typed handle at any execution prefix, expand that prefix from scratch if necessary. It uses at most O(gM) nodes, so its extension cost relative to the currently available library is no larger. There are at most M producing/closure actions after constant-size normalization; joint-output actions can be charged by their total record count. Therefore sum kappa_j<=O(gM^2). This deliberately conservative bound does not assume repeated hypothetical copying is repeated physical work by A. The positive-part defect is no larger than sum kappa_j. Deleting caches cannot invalidate an upper bound obtained by reconstructing from authenticated earlier records in the charged derivation history; physical reconstruction by A, if performed, is charged separately. A history is an analytical object, not free workspace.

For the dihedral subclass, composition is explicit:
(s,e) compose (t,d)=(s+e*t mod v,e*d).
All compositions remain in the2v-element set. This proves the depth-independent bound even if the same two generators alternate on every level of a length-M view chain. Small generator count alone is not enough: two generators can generate a factorial-size symmetric group. The theorem bounds group cardinality, not merely generator description length.

These are ceilings for restricted witness expansion. They do not replace the original same-execution ceilings:

The coincidence of exponents in some rows does not identify the resources.
