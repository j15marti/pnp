## Reduction and inverse

For every nonempty conjunction of m positive exact-one triples on v occurring Boolean names, first give names dense identifiers. Entries in a triple may repeat. Number columns cyclically starting at zero. Write AA for the relation x≥y on consecutive z values, CC for x≠y and AC for (x,y)=(1,0), following the pinned projected semantics. Each admitted closed path extends to the full source by setting each destination a from its incoming A link or zero on C, b=1−a−z, and choosing rung helpers 0,z. The converse is obtained by reading each z. The appended rows impose exactly their three-bit XOR.

Concatenate v variable blocks of two AA edges and m clause blocks of three AA edges. **After each block**, including the last, insert CC,AC,CC. If u is the last vertex of a block, the separator follows the unique sequence (u,1,0,1) with u=0. It therefore pins the end of the preceding block at 0 and the start of the next at 1, including across the cyclic seam. No constant symbols or unary clauses are added.

A variable block reads 1,X,0, allowing either X. A clause block reads 1,B,C,0 with B≥C. The three successive edge differences modulo two are

    (1 XOR B, B XOR C, C).

Their possibilities are exactly 100,010,001. For a source triple (x,y,z), impose three homogeneous ternary rows: each row contains the corresponding variable block's interior vertex and both endpoints of its corresponding clause edge. XOR zero equates that variable to the edge difference. Each physical row references three distinct column indices, even if x=y=z, because variable blocks and clause blocks are disjoint and each edge has distinct endpoints. Shared variable occurrences reuse the same column deliberately.

Given a satisfying source assignment, set variable interiors accordingly and drop from 1 to 0 on the unique true occurrence of each triple. These choices satisfy every local edge, separator and parity row. In the reverse direction every local clause path has exactly one drop. Its three parity equations force exactly one of the three occurrence values to be 1, including multiplicities. Reading the variable interiors gives a source solution. Both implications survive the source extension and existential compiler. Thus an UNSAT source cannot acquire a satisfying assignment through auxiliary variables.

This also supplies a polynomial method to contract and invert this exact template. Recognize the fixed runs, separators and seam, index their vertices, verify the three endpoints and variable-column reference of every ordered parity row, and recover one exact-one triple per clause block.
