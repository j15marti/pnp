## One transfer tested

Fredman and Saks, STOC 1989, Theorem 3, prove that a cell-probe implementation supporting array additions and arbitrary prefix-sum queries modulo two requires amortized Ω(log n/(log log n + log b)) probes per operation with b-bit registers. Computation between probes is free. Here n is the array dimension. Their interface obliges the implementation to return each requested sum. The theorem concerns a data structure supporting the operation repertoire, so it gives no lower bound on a fixed sequence of writes followed by one total-parity query. [Original, pp. 345–346](https://doi.org/10.1145/73007.73040).

The attempted application is precise. In Construction's chain use identity or the swap of vertices 1 and 2 at each layer with start 1. The path at index j gives the prefix parity of the first j swap indicators. Does correctness for the endpoint force the solver to supply these prefix answers again after paid joint preprocessing? The counterexample below applies even with arbitrary permutations, which need not commute. It addresses one proposed decoder, without reversing a cell-probe theorem into a single-tape theorem.
