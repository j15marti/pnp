## The single added scalar rule

The native library follows the prior report: constants, literals, internal NOT, read-once decisions, binary Boolean operators with disjoint declared child scopes, and actual DAG sharing. A view (b,h) has an explicit permutation of V, exact scope S_u=h(S_b), and older base identity b. Native child scopes shrink; decision labels occur in neither child scope. New identities are used after physical deletion and reconstruction.

Add an extremal closure record with:
- exact source/residual identity and complete named Boolean scope S;
- an exact unweighted count Z and its authenticated derivation;
- the admitted constant handle (FALSE,S,0) or (TRUE,S,2^|S|).

An authenticated derivation means either an executed fixed correct counting module, with its actual work charged, or an accepted certificate under a stated sound verifier whose acquisition and verification are both charged. A scalar asserted by a caller is not a certificate. A stored hash may identify bytes but does not prove semantic equality. If checking is incomplete, the result is UNKNOWN for this rule. It is never treated as UNSAT.

Only Z=0 or Z=2^|S| creates a handle through this rule. Intermediate counts stay scalar values unless another legal rule supplies a relation handle. Exact count zero justifies UNSAT for this residual; a positive intermediate count may justify SAT but does not justify returning a complete witness relation. All count computation, including failed probes, is paid even when the rule does not fire.

For compiler pruning, a record's extremal certificate must be available **when that relation handle is admitted**. Keep a fixed birth flag on that record. A later certificate may create a new certified handle but cannot retroactively shorten an earlier prefix proof. This chronological condition matters for cumulative completion, not just final representation existence.

## Proof and sharp count-only boundary

Let U=2^|S|. Because g takes values in {0,1},
Z=sum_(alpha in {0,1}^S) g(alpha).
If Z=0, every summand is zero; if Z=U, every summand is one. A single native sink therefore represents g, with S retained as declared free scope. This proves kappa(g|K)<=1 for every currently available library K. It remains valid for S empty: U=1 and there are precisely two predicates on its singleton assignment space.

For h simultaneous extremal outputs, a joint extension uses at most h sinks. Reusing identical sinks can improve this upper bound; it is not required. Suppose a fixed implementation emits at most c_A typed handles per charged bit-machine action, or normalizes its disjoint producing blocks q_j so that h_j<=c_A q_j. With c>=c_A,
sum_(extreme j) [kappa_j-c q_j]_+=0.
A block may include arbitrarily costly exact scalar work before emission. That only increases q_j. Shared scalar work is counted once in the actual partition. If multiple rules produce outputs in one block, use their joint extension bound, never charge the same block separately to each output. For native-plus-extremal histories the usual constant native extension bound yields total defect zero after enlarging c. Deletions cannot decrease remaining completion potential.

Substitution into the handoff's completion inequality gives
R_F(K_before)-R_F(K_after)<=kappa_j.
The proof is representational: a constant node used many times is constructed once. Its scope annotation, identity, source evidence and count word still cost physical bits. No assertion that one node equals one bit is made.

This is sharp **for reconstruction from count and scope alone across all Boolean relations**. For every s>=1 and 1<=z<=2^s-1, choose a z-element set A of assignments, a in A and b outside A. The set (A minus {a}) union {b} is different with the same cardinality. Thus no function of (S,z) alone can select the correct truth table in both cases. The smallest example is S={x}, z=1: x and NOT x. Additional structural information may permit valid reuse at intermediate counts; this proof forbids no such algorithm. It is not a minimum-DLDD lower bound for either example.

## Extension of the previous context compiler

Consider every finite history with M identities, identity starts at all handles, and certificates available at admission as above. In the compiler of T5-CONTEXT-ORBIT1, before following a record's children:
1. If its birth flag certifies an extreme, return its constant sink on the mapped **full declared scope**.
2. Otherwise use the prior native/view expansion with cache key (record identity, ordered accumulated map restricted to full declared scope).

Let Q_E count the reachable keys in this pruned closure. The exact same scope congruence still applies: native descent restricts the current map; at a view, r_b(i)=r(h(i)) is defined because h(S_b)=S_u. A constant commutes with every injective renaming, and its full mapped scope remains attached. Consequently all expanded handles jointly use O(Q_E) nodes.

Assume every **unpruned view** has scope size at most fixed k. Certified constant views can have any size and any permutation group. Before the first traversed view, the context is identity; after it, scope size is at most k and can never grow along descent. Hence any reached node with scope larger than k has only identity context. Nodes of scope at most k have at most (v)_s<=max(1,v)^k restrictions. Therefore
Q_E<=M(1+max(1,v)^k),
and native expansion is O(M(1+max(1,v)^k)).

Every prefix has the same admission condition and cannot depend on a future certificate. Expanding a prefix from scratch bounds its producing block's joint extension by O(Q_E), even if no useful old library survives. There are at most M producing blocks after normalization. Thus the conservative cumulative closed-extension/positive-part-defect bound is
O(M Q_E)<=O(M^2(1+max(1,v)^k)).
This general mixed-view bound need not be zero. The exact zero-defect claim above applies to extremal producing blocks themselves, not arbitrary view blocks.

This strictly relaxes the syntactic condition “every view has scope at most k.” Redteam's already published growing-scope TRUE family qualifies with certificates obtained by its paid native constant propagation. Its exponential unpruned Q is irrelevant once each constant view is a certified leaf. This application uses the previous symbolic family/proof and recovered evidence, not a repeated empirical run or a claimed new family. Nonconstant large-scope views remain outside this corollary. Compact evaluators outside it remain legitimate.

For a fixed capped A and fixed k, the representation ceiling is O_A(N^(a+k)) and the mixed-history defect ceiling O_A(N^(2a+k)). These are upper bounds for a representation compiler, not lower bounds on A's physical work. A consequence using the baseline's separate hard-target DLDD theorem remains CONDITIONAL on that theorem and the architecture. No new hard-target theorem is established here.

## Complete cost ledger and same-execution comparison

Let s=|S|. Once an exact count has actually been authenticated, comparing it with zero or the full-count word takes O(s+1) local bit work; 2^s has s+1 bits. A named scope takes O((s+1)log(v+2)) explicit bits. Access to nonadjacent records adds actual tape travel. The local comparison is not a bound for computing Z.

For a finite emitted history/certificate string of B bits, Q_E keys, and
L=ceil(log2(M+Q_E+v+2)),
a conservative compiler workspace envelope is
H=N+B+(M+Q_E+1)(v+1)L.
Sequential dictionary scans, maps, scope checks and diagram emission can be implemented in O(H^6) bit time and O(H) physical span, hence O(H^7) physical CM, **after** semantic source/certificate authentication. If authentication is not already part of A's executed history, add its actual verification time and simultaneous storage; no polynomial bound in certificate length is presumed for an unspecified verifier. This is a separate uniform compiler, not a simulation claiming A uses this envelope.

## Controls tied to the exact rule

Five-ary/domain control: a full five-value relation has count5. Encoded by three Boolean bits with invalid codes rejected, it is not TRUE on eight assignments. Returning TRUE from count5 would be wrong. Even Z_T5=5^n means the binary witness relation is a validity-domain predicate, not a Boolean constant. Boolean normalization must be proved first. Likewise, a full projected count need not make the original relation tautological, and forced variables cannot be silently dropped from S.

Affine/Tseitin: an authenticated inconsistent linear system may legitimately produce FALSE. A consistent nontrivial affine system normally has an intermediate count; the rule supplies no relation handle from that scalar. Gaussian elimination and compact evaluators are allowed with their actual costs. This preserves the obstruction to a universal scalar-to-DLDD compiler.

Complement/renaming: exact complement count is U-Z, interchanging the two allowed extremes. Bijections preserve counts and constants; the scope travels with the relation. The earlier image-set/support-only cache errors remain forbidden. Private-leaf trees and matching families retain cheap scalar recurrences; intermediate answers do not become handles merely because those recurrences are cheap.

Sharing, relocation and recomputation are handled in the actual ledger and compiler proof. The rule forces no return to original cuts. Full-state conditional output entropy remains zero. Neither SAT witnesses nor answers to every virtual residual query are compulsory interfaces. Decision labels SAT, UNSAT and UNKNOWN remain separate.

Weighted counts with zero weights and counts modulo an integer are excluded: a true assignment of weight zero can produce weighted count zero; two satisfying assignments produce zero modulo two. Approximation, truncation and floating-point equality cannot authenticate either extreme.

DISJ: NOT APPLICABLE, no communication demand. Relativization: OPEN for unrestricted transfer; no nonrelativizing step claimed. Simultaneous DTISP: PASS for separate same-execution ledgers, OPEN for any compulsory cap violation. Deterministic configurations: PASS for scope, no runtime inference from state count. Natural Proofs and algebrization: no unrestricted circuit lower bound or barrier bypass.
