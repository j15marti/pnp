## What changes at two shared variables

Construction asked whether circular exact-one pieces still admit polynomial local decisions after child pieces send binary correlations. The unrestricted composition problem is NP-complete even with a supplied star decomposition, a supplied cyclic order, a biconnected root primal graph, and a single positive exact-one triple in each leaf. Every leaf sends the *same* binary relation. Computing and transmitting each four-entry table takes constant local work once its addresses are known. Joint root feasibility is the NP-complete step. A deterministic polynomial algorithm for it would give P=NP. This implication applies even if recognition and discovery are solved.

Formally the input is a list of positive triples on distinct Boolean names per triple, partitioned into an ordered root and single-row leaves. Each leaf shares two distinct root names and has a fresh private third name. The variables occurring in each root column must form one circular interval in the supplied row order. Different leaves may use the same root name. The decomposition has the running-intersection property since all leaves using any shared name are adjacent to the root. The partition is into **constraint lists**. No assumption requires leaf pairs to be edges of the root primal graph before the children are attached. An algorithm restricted to clique separators, disjoint pairs, bounded root degree in the decomposition, or a prescribed minimal split decomposition has different hypotheses.

Fix a uniform solver before inputs. The certificate syntax, distinct names, running intersection, circularity and root biconnectivity are polynomially verifiable (for the last condition remove each vertex and test connectivity). Feasibility is in NP by checking one assignment. The decision is exact for both labels.

## Reduction and proof

Start with a simple undirected graph G having h>=3 explicitly listed vertices and e edges. Graph 3-colorability is NP-complete [1]. Small graphs can be solved directly or padded by isolated vertices. Use 2h stations around a circle, alternating real and dummy stations. Each station i has names L_i, M_i, R_i. Emit the following two root rows in order, for i=0,...,2h-1 with cyclic index arithmetic:

    (L_i, M_i, R_i)
    (R_i, L_(i+1), F_i)

Each F_i is fresh. Each L_i and R_i occurs twice, on adjacent rows including the wraparound boundary. Each M_i and F_i occurs once. The supplied root order therefore works on every input graph. Its primal graph contains the cycle visiting successive L_i,R_i,L_(i+1). Each other vertex has two distinct neighbors on this cycle. Removing any single vertex leaves the graph connected.

At real station 2u interpret L,M,R as the three possible colors of vertex u. For every edge {u,v} and each color c add the leaf (X_(u,c),X_(v,c),Y_(uv,c)) with fresh Y. Its projection onto the two shared names is {00,01,10}: for those cases the private name can supply precisely the missing one, and 11 violates exact-one for either private value. Thus every leaf gives the binary NAND constraint, whose two individual unary projections are both full.

Every root solution chooses exactly one color at each real station. Every leaf then prohibits a monochromatic edge in that color. A solution supplies a proper coloring. Conversely, choose the colors of any proper coloring, choose the middle name at every dummy station, and set the two remaining station names false at each station. Each bridge touches one dummy endpoint, which is false, so its two existing names sum to at most one. Set its fresh F to the complement of that sum. Each leaf now extends uniquely. This proves both implications. Whole-row feasibility survives arbitrary input names under a consistent bijection.

There are exactly v=8h+3e names and m=4h+3e triples. A star certificate is encoded by the root row count and the row order followed by the leaves. The source size L is O((h+e) log(h+e+1)) with dense explicit IDs. Numbering the stations by input order and leaves by edge ordinal gives a deterministic streaming output on separate work/output tapes with polynomial bit cost, bounded conservatively by O(L^3) time and O(L) span on one tape for a dense explicit vertex/edge list including input checks, copies and return moves. No truth tables of assignments occur in the reduction.

For an equal-size worked pair use K4 plus one isolated vertex versus K_(2,3). Both have h=5,e=6, hence v=58,m=38 and identical compiler dimensions. Both have an identical satisfiable circular root and eighteen individually feasible leaf tables. The first full instance is UNSAT, the second SAT. Replacing leaf tables by their separate unary projections would accept both.

## Restricted constructive consequence and costs

For any validated such root with explicit binary tables (including the NAND leaves above), build the graph of shared pairs carrying a nontrivial table, over root variable names. Greedily construct a maximal matching. Its endpoints C cover every such edge because any edge disjoint from C could have been added. If the minimum cover size is tau, disjoint matching edges imply |C|<=2 tau. This proof also handles repeated pairs. Enumerate assignments to C. Each incoming table becomes a Boolean check or a unary restriction. Intersect repeated restrictions, reject empty domains and impose all singleton pins on the circular root. A row with two true pins rejects. In a satisfied row force all other names false globally, delete satisfied rows and whole pinned columns, reject a remaining empty row. The retained order preserves circular supports. Choose each possible true anchor in a remaining row and test a forward path of wholly contained arcs across its complementary gap as in the earlier Discovery report. Empty residual accepts. Both the pins and the matching endpoints are paid for. A parent query fixing two distinguished bits, where required, adds at most four trials. This yields 2^{2 tau} poly(L) work, even without a supplied cover. A fixed threshold |C|<=c log_2(L+2) gives a uniform polynomial guard; on failure use internal UNKNOWN and exact fallback. The algorithm can be fast for a graph with many pair constraints. A global logarithmic bound on these matching sizes is false, as disjoint input edges can give unbounded disjoint leaf pairs. Other decompositions or algorithms remain possible.

## Dynamic information-transfer test

Pătraşcu and Demaine's Theorem 2.4 [2] concerns a sequence of online edge insertions, deletions and Boolean connectivity queries. In the logarithmic-word cell-probe model its tradeoffs imply max(t_update,t_query)=Omega(log n) amortized even for a disjoint union of paths, including deterministic structures. The theorem also allows their stated randomization regimes. Preprocessing or retained data about the past is compatible with the data structure. A query must be answered in the graph current at its arrival. The hypothesis does not grant advance knowledge of the future operation sequence. We use only the deterministic corollary.

Test the direct transfer that maps operations to building the final pair-constraint graph and obtains intermediate connectivity answers from the final SAT decision. On three vertices start empty. History A inserts {1,2}, asks connected(1,2), deletes {1,2}. History B inserts {2,3}, asks the same query, deletes {2,3}. The online answers are opposite. Final source and ordered decomposition, the entire offline decision run of a fixed machine, and all of its charged events are identical. A decoder given common protocol and query with this run cannot distinguish the histories. If the reduction separately retains each history, it must justify and charge an online simulation delivering actual answers at deadlines. Allowing the decoder to use the distinguishing update for free would no longer prove compulsory observations of the SAT run. This is a counterexample to the final-graph transfer specifically. An indirect online reduction remains OPEN. Even a faithful transfer of one logarithmic factor could not exclude every polynomial cap.

A compulsory-execution theorem would need a reachable future observation on *every* fixed correct machine after its paid preprocessing and caching, together with a same-execution decoder, model simulation and bounded reuse.
