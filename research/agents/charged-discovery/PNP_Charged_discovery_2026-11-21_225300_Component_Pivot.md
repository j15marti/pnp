## Claim and parameter

Fix the following uniform deterministic solver A for all valid Boolean compatibility inputs. It first authenticates Construction's canonical shared-choice image by extraction and bitwise regeneration. On failure it runs exhaustive Boolean decision on the retained original. On success let F be its proper 3-CNF source. For each candidate pivot v (including the empty choice), restrict to each value of v and split the resulting formula into variable-disjoint incidence components. Preserve empty clauses as contradictions. Write h(D) for the minimum number of variables hitting every remaining ternary support in component D. Define

    p(F) = min_v max_{branch, component D} h(D).

An empty maximum is zero. This parameter refers solely to the input. For the empty pivot use one unrestricted branch. Thus p never exceeds the global ternary hitting number h. The two values of a pivot may have different partitions and local keys.

For every valid canonical input with N physical bits, A finds a successful pivot and solves SAT in T=O(3^p N^7), S=O(N), CM_phys=O(3^p N^8), and separately CM_min=O(3^p N^8). For each fixed C the same A is polynomial on p<=C log2 N. There are connected proper 3-CNF sources of both labels, with canonical N=Theta(k² log(k+1)), h=k+1 and p=1. These extend the scope of the current logarithmic-global-h guarantee. No optimal time exponent or general SAT algorithm is claimed.

Falsifiers are an uncharged pivot supplied by advice, a variable shared across allegedly independent residual components, a different profitable pivot invalidating the claimed minimum p, or a same-label suffix retaining the hidden local answers used in the counterexample. The algorithm searches all pivots, computes each partition, proves the minimum on the family, and explicitly erases its scratch.

## Uniform algorithm and resource proof

Try budgets e=0,1,... sequentially. For each pivot and both values, construct actual residuals by removing satisfied rows and removing false literals from the others. Partition by shared variable names. For every resulting component, use Accounting's depth-limited ternary search at budget e. At a node select one uncovered triple and try each of its names. Any valid extension must contain one. This finds a hitting set if one of size at most e exists and costs at most (3^(e+1)-1)/2 nodes including all failed trials. Keep the same pivot for both branches. Admit a pivot only after every component in every branch passes. Budget failure gives UNKNOWN about the decision. Empty clauses can be passed to the binary decider as components with hitting number zero. Budget p succeeds by definition.

For the admitted plan, solve each component by trying assignments to its local hitting set, then applying the binary implication graph test. A satisfied ternary disappears and an unsatisfied selected literal is deleted, leaving width at most two. Accept iff some pivot value passes all its components. Private satisfying assignments combine since no private name occurs in two components of that branch. Every global witness restricts to the corresponding successful local decisions. Neither label requires a witness output. Discovery happens before semantic evaluation so an easy local UNSAT outcome does not hide an undetected large key in the parameter calculation.

Use one writable finite-alphabet tape, head initially at the origin, local read/write moves, output bit and terminator at the origin, including all source, work and address storage in the occupied span. The exact target encoding uses unary n and delimiter, gamma(m+1), ordered signed triples, two n-bit supplied assignments and a w-bit release ID. For c>=1 source clauses and d densely numbered occurring variables, r is the least odd integer >c and >=3. The dihedral compiler gives n0=d+(10c+1)r+2, m0=(20c+4)r, n=n0+m0+3, m=2m0+4, w=ceil(log2(n+1)), N=3n+2+2 floor(log2(m+1))+3m(w+1)+w. This calculation includes source authentication of the compiled object. Reconstruction reads actual guards, regenerates all target cells including the trailer and checks exact equality. The underlying compiler and O(N³) acquisition ledger are inherited from Construction [4]. Its semantics is existential Boolean decision. The two distinct T5 counting conventions play no part here.

Charge each elementary record access, comparison or binary address update at O(N²) physical steps by indexed shuttling over the occupied tape. Component membership can be computed by reachability on the row/variable incidence lists, expanding each row/name once in a traversal and scanning the occurrence list at each expansion, restarting only on unmarked rows. Even O(N³) record operations per pivot suffice. For one bounded search node inspecting c rows against at most d selected IDs takes O(cd) record operations. A binary leaf needs at most O(d²c) record operations by repeated implication reachability with marks. O(N^5) transitions cover any such node or binary test. Across budgets through p there are O(3^p) search nodes per pivot-component position, at most O(N) pivots and O(N) components per branch. This geometric sum includes failed budgets, failed candidates, construction of branches and partitions. On the successful pivot there are O(N 2^p) binary tests at most. These estimates give the time claimed, inclusive of setup, erasure, repositioning and output.

Store the original, one extracted source, component labels per row, constant-many branch copies, and a DFS stack of selected IDs with next-child indices. No stack frame needs a formula copy. The successful keys together occupy O(d log N) bits per branch, since their variable sets are disjoint. O(c log N) bits cover the graph and traversal workspace reused across components. Here d<=3c and c log N=O(N). Physical CM sums actual occupied spans along this run, hence at most O(NT). For shortest descriptions replay from self-delimited original input and step costs O_A(N+log(T+2)) per configuration. Since p<=d<=N the latter is O_A(N). These are independent upper bounds. The noncanonical exhaustive fallback has O(2^n N³) time and O(N) span on valid inputs, using bounded header checks, a Boolean assignment vector and explicit clause scans. Source-to-target production, if separately required, costs O(N³) and O(N) span under [4]. All work here is sequential.

## Exact connected family

For k>=2 choose arbitrary signs s=(s_1,...,s_k) in {0,1}^k. Use private variables x_i,y_i,z_i,t_i with consecutive IDs 4i-3 through 4i and one common variable g=4k+1. For each i output in order

    xor(x_i,y_i,z_i)=0
    xor(x_i,y_i,t_i)=0
    xor(z_i,t_i,g)=s_i
    (x_i OR y_i OR z_i).

For each XOR row output the four clauses excluding the four assignments of the wrong parity, taking bit patterns in lexicographic order. A forbidden 0 yields a positive literal, a forbidden 1 a negative literal. This specifies all 13k proper clauses on 4k+1 variables. Every incidence block is joined to g. The first two equations give z_i=t_i=x_i xor y_i. The third says g=s_i. The final clause excludes (x_i,y_i)=(0,0), leaving exactly three private extensions for the required g. Consequently SAT iff all signs agree. Both labels occur at the same encoded length. Each block's projected local support for g is the singleton {s_i}. No private bit is forced in a feasible block; the three private solutions also exclude an affine solution relation since three is not a power of two. The displayed parity equations still permit elimination and the template admits a sign scan after authentication. These are legal additional shortcuts.

The three different ternary supports per block are xyz, xyt, ztg. If g is selected, at least one additional private name per block is required, and x_i suffices for both remaining supports. Without g, no single private variable hits all three. Two per block suffice (x_i,z_i). Therefore h=min(k+1,2k)=k+1. With pivot g, the final XOR restricts to binary rows and x_i meets every private ternary. Hence p<=1. A zero budget would require that every ternary be removed or reduced by a single fixed pivot in both branches, since partition alone never reduces row width. This would imply h<=1, impossible. Thus p=1 exactly. The argument works under any consistent private-variable renaming and clause permutation before canonical compilation. The upper bound does not depend on recognizing the template.

## Failure of the online-query transfer

The proposed transfer would recover every local feasibility bit U_i=1[block i admits g=1] from an actual offline decision suffix after joint preprocessing. These bits equal s_i and are defined by the input, with no independently sampled virtual prefix. In an online connectivity service, an analogous family of bits can be queried explicitly by asking whether the endpoints of each of k disjoint possible edges are connected. That simple service illustrates the output contract only. The hard distribution and the logarithmic lower bound for the full dynamic problem are separate [1].

Take the above globally correct A and normalize after it solves by moving Y=SAT(F) to a fixed cell, erasing the input and all other work and leaving the head at that cell in a common READY state. This costs O(N) extra on the admitted path by marking the span and sweeping it, with origin output written in the following constant-length routine. For fixed k choose Y uniformly, then s uniformly within its fiber, consisting of the two constant strings on SAT and the remaining 2^k-2 strings on UNSAT. Public B gives k, A and the generator/distribution. For U=(U_i) the entire actual READY suffix Z is a function only of Y and reveals Y. Thus

    H(U | B,Z) = (1 + log2(2^k-2))/2 > 0.

For example at k=2 even the entire suffix leaves one full bit of uncertainty. No decoder built only from actual suffix events and B can recover U. Selecting event indices using the hidden signs would import side information. On the other hand the compulsory output service on this particular solver has U'=Y, B'=B, E={the fixed-cell READY read}, Pi=that one read bit, b=1, framing=0, rho=1. With the cache content given freely the demand vanishes, and duplicating the read q times has reuse q. The historical prefix may reveal all the signs.
