# Completing a Boolean residual from its count and signed equalities

21 November 2026, 12:54 PST. PNP Proof Discovery. Source revision 35b0789267fe608b40b3d0135d2a1f7db2beb2af.

**T5-SIGNED-PARTITION-SATURATION1. PROVED/EXACT in the typed architecture below. Independent adversarial review pending.** For every finite named Boolean scope S and residual g, certify that all its solutions lie in a specified partition into fixed literals and blocks of coordinates equal up to sign. If its authenticated exact unweighted count equals the number of assignments in that partition, it has a read-once decision/decomposable diagram with at most 3|S|+2 nodes. This accepts intermediate counts on arbitrarily large scopes. Scanning explicit descriptions on admission gives zero cumulative positive defect for this shortcut, even with adaptively chosen blocks, arbitrary variable permutations, caching and deletion. It gives a uniform way to cover all final full-wire predicates on Accounting's canonical parity-switch images, including their nonconstant boundaries. The general coverage problem remains OPEN.

**Four falsifiers.** Omit the containment certificate and two different count-two predicates already disagree. A projected or weighted count can match the proposed capacity while leaving holes. A general parity constraint on three bits can escape all unary and signed-pair tests. A sequence of cheaply created lazy views can evade the per-admission scan premise. Each has a distinct disposition below.

## Exact rule and proof

Fix one total correct deterministic exact strict-C counter A, any valid encoded input X, and any prefix of its actual computation admitting the typed operations below. The target relation in this lemma is the authenticated Boolean residual on its *specified original named coordinates*. Record the map and fiber multiplicities when the five-valued input is projected. No arbitrary scalar counter need produce this structure. Fix K>0 and a≥1 independently of X for a proposed T_A(N)≤K N^a. A correct decision procedure is a different solver; only positivity of a verified exact count gives its decision answer.

Let s=|S|. Partition S into coordinates assigned explicit constant bits and disjoint, nonempty free blocks. Give every coordinate i in a free block c an offset e_i. Its allowed tuples are exactly x_i=t_c XOR e_i with one independent Boolean choice t_c for that entire block. Allow singleton blocks, empty S and no free blocks. All assignments consistent with this descriptor form P; |P|=2^d for d free blocks, since choosing the d bits and reading one representative per block are inverse maps. Componentwise flips act transitively on P. Simultaneously complementing all offsets in a block leaves P unchanged.

Admit the shortcut only with (i) a checked exact named scope and descriptor, (ii) a sound proof g⊆P, and (iii) a paid, exact integer Z=|g| on that same Boolean universe. For positive Z, accept precisely when Z=2^d. The finite subset and its containing set then have equal size and coincide. For zero use the existing FALSE rule. If the tests fail, the shortcut returns UNKNOWN. A positive count can still establish SAT. Counts of the raw input or of a different projection do not discharge (iii). The complement of a completed handle is available using native NOT; an interior scalar without the premises stays scalar.

The least such containing P for a nonempty g is well defined semantically. Pin all constant coordinates, then group remaining coordinate columns in the table of all models if they are identical or complementary. This is an equivalence relation. Any signed-partition consequence of g follows from those pins and within-class offsets. Thus the count test on this finest descriptor recognizes exactly the predicates definable in this class. Computing the table can be expensive. A uniform alternative, when paid residual counting is available, tests unary values and up to four pair assignments per unordered pair for zero via actual conditioned counts on the proper remaining scope. Forbidden opposite-sign patterns prove equality; forbidden equal patterns prove disequality. Reinsert fixed names on output. Charge all these calls including the failed tests and computation of Z. Neither a virtual query nor discovery of the finest descriptor is a premise of the cheaper admission test. Another verifier may prove containment directly.

**Sharp scope.** On two bits equality and disequality have the same count 2 and disjoint solution sets. Even parity on three bits has four solutions and each pair realizes all four rows, so its finest descriptor has capacity eight. The deficit correctly rejects saturation and permits an affine algorithm. Existence of one witness per generator flip does not certify a whole orbit under arbitrary combinations of flips. A Boolean exact count is essential: giving each model of equality weight two makes its weighted total four while the full two-bit cube has holes. These tests prevent treating an integer or hash as a semantic merge proof.

## Construction cost, sharing and cumulative defect

Use the handoff's native Boolean DLDD operations and reusable handle identities. To recognize a pinned set, check its specified literals in one decision chain, with failure going to FALSE. For a free block of length l≥2, branch on the first named bit. In each branch check the other l−1 variables in a chain using their required relative signs. This uses 2l−1 decision nodes. A singleton contributes no test, with its declared free scope retained. Conjoin the nontrivial block roots and pinned chain on disjoint names. Use two shared sinks. This is read-once along paths, and scopes of AND children are disjoint. Including all AND nodes costs at most 3s+2 nodes in total. A permutation just moves the names and their offsets. Arbitrary mapped images of a saturated relation can be constructed directly at this same bound without expanding nested renaming contexts. A name-set match by itself does not justify reuse of a previous diagram.

Partition the same history into disjoint charged producing blocks with cost q_j. This architecture issues each fresh saturated output via an explicit *current* descriptor listing its s names/entries, read or written on actual admission, plus actual handle emission. When a shared source certificate is used by several outputs it is charged once. For joint emission impose the precise implementation premise sum_outputs(s+1)≤c_A q_j on those fresh descriptors. It holds for a serial stream of explicit entries with one per named coordinate per fresh output, with fixed constant throughput. An already available identical handle can be referenced without rebuilding it. A new handle after deletion must be accounted for again. Source and count proofs must be available at birth. A later certificate can create a new handle but cannot repair a past prefix.

For a block with only the new admissions, the joint extension κ_j is bounded above by the sum of the diagram bounds, at most 3 c_A q_j. Sharing sinks, repeated roots or subgraphs may improve this. Thus sum_j [κ_j−c q_j]_+=0 for these blocks if c≥3 c_A. Disjoint native emissions add their ordinary constant bound under the same streaming partition; mixed blocks require a joint charge. Substitution into the completion potential bounds its decrease by the joint extension. This is not a node-to-bit identity. The upper bound measures an extension *available in principle*; the fixed solver need not write that diagram. A uniform compiler that actually writes it pays for traversals, scope and pointers. A cheap lazily renamed fresh view is still legal in a wider model. For such outputs the direct upper bound is O(sum(s+1)) over fresh views, at most O(M(v+1)) for M outputs over v names. Without the explicit-stream premise this reasoning gives no zero-defect guarantee for those blocks. No additional assumption on the behavior of unrestricted solvers follows.

There are just two possible full wire evaluations, obtained by executing the verified deterministic gate list once per x value. Apply the actual output pin to each. They either both pass or both fail. In the positive case every column is constant, x or its negation as a function of x. Nonconstant columns form exactly one free signed block (including x). The pin-preserving wire relation therefore saturates its descriptor with Z=2, strictly between zero and 2^s for every k. ## Physical ledger and boundaries

A canonical-image recognition attempt makes O(k+1) template compilations per pin and full-length comparisons or scans. With the published conservative bit-tape compilation bound O(N^4) time and O(N) occupied bits per template, streaming one singleton at a time, O((k+1)N^4) time and O(N) bits suffice on this image, including real seeks, input, output and indices. Malformed inputs with incompatible headers/lengths can fail early. Selecting k from an actual unary n bounds it by the actual source size. After authentication the two chronological gate evaluations, column grouping, offsets, pins and count require polynomial work in s; repeated scans of O((s+1)log(s+2)) bits suffice. The case with an arbitrary certificate of length B or general residual counter has no such fixed recognition guarantee. Charge acquisition/readback of B and every actual count/verification execution; a complete model enumeration can cost exponential work. For a given explicit descriptor, naive repeated scans and record writes construct the diagram within O(D^3) bit time and O(D) bits where D includes the input descriptor, output node table, mapped names and scope plus their full pointer widths. The scalar comparison costs O(s+1) local bit operations before travel. Maps discovered on the fly and failed candidate matches are charged even when no handle is admitted.

For the same fixed A, fixed K,a and hypotheses of the handoff: T≤KN^a implies S=O(N^a), physical CM=O(N^(2a)), minimum-description CM=O(N^(a+1)), and encoded count-map circuit size O(N^a log N). Total input remains charged, and the time index is part of a replay description. The recognition envelope is an upper bound for one algorithm, not the runtime of an arbitrary capped A. No cap is contradicted. On any one realization parsing, verification, failed recognizers, adaptive switching, physical reads, address bits, retained caches, compiler maps, shared work, recomputation and binary output belong to their actual executions. A physical compiler, a representational κ_j and a minimum configuration description are different resources.

Affine/Tseitin systems with higher-arity checks may have many nontrivial dependencies even with every pair unconstrained; parity above is a direct control. Forced variables and isolated/free names have different count contributions. Matching, private-leaf, width-based and global algebraic evaluators remain admissible. Counting complement within the full scope is legal, with proper subtraction and native NOT. The proof never asks the solver to move back across original cuts, output a witness or reconstruct one from a short scalar answer. Full-state entropy of the answer conditional on a complete deterministic configuration is zero. DISJ, relativization/algebrization, Natural Proofs and configuration counting supply no unrestricted transfer here. Simultaneous DTISP is used only for the same-execution cap ledger. No stronger UNSAT decision-time conclusion arises from a constant FALSE handle.
