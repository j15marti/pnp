## 1. Exact lifting to a signed option graph
Let F=B AND C, where B comprises all clauses of width <=2 and C is the list of remaining ternary clauses (generalize to lists of size <=3). Use explicit encoding length N, n<=N variables, m<=N clauses. Empty clause rejects immediately; delete tautologies/repeated literals if desired. Check B by 2SAT. If B is UNSAT, stop. For every literal occurrence in a C clause create a separate option vertex labelled with the original literal and clause index. Remove an option l if B AND l is UNSAT. A group is the surviving options of a clause. An empty group rejects. For distinct groups put an edge between options l,m iff B AND l AND m is UNSAT. No edges within groups. Retain original clause indices and literal signs. Build the graph by at most O(N^2) 2SAT tests (or reachability as below), never by a general SAT oracle.

Lemma (two-assumption completeness). If B is SAT, a set U of literal assumptions extends to a B-model iff all singleton and pair subsets do. Proof: let R(U) be the union of implication reachability sets from U, including their sources. If R(U) contains p and not-p, at most two source assumptions caused that conflict. If it is consistent, assign all reached literals true. Every clause involving a false assigned literal then has its other literal reached true. All residual clauses are unchanged clauses of B on unassigned variables, hence jointly satisfiable because B is. Unit clauses use implication not-l -> l. This proves the lemma. Moreover, for individually feasible l,m, joint conflict is equivalent to a path l -> not-m: any conflicting p,not-p reached from l,m yields such a path using contraposition of implication edges; the reverse is immediate. Thus one all-literal reachability table suffices.

Theorem: F SAT iff the option graph has an independent transversal, i.e. one option from every group with no cross-group conflict. Forward: select one true literal in each original clause. Reverse: pair lemma extends all selected literals to a common B-model, satisfying every C clause. This is exact simultaneous compatibility, not separate satisfaction of B and C. It preserves decision, not the number of models (a model can induce several transversals). The full graph, groups and original literal mapping, not only rank or component counts, are required for safe reuse.

## 2. Polynomial matching criterion
Call an option graph resource-structured when every connected component contains every edge between options of different groups in that component. There are never within-group edges, so each component is complete multipartite with parts given by group labels (singletons allowed). Test by components and pair scans. Make a bipartite graph from clause groups to component IDs; an edge exists when that group has an option in the component. A transversal cannot select two different groups in one component and options in distinct components never conflict. Hence SAT iff a matching saturates all groups. Recover an option per matched pair and a B-assignment via SCC with chosen unit assumptions. A Hall-deficient set of groups is a compact UNSAT certificate: its neighbor count is smaller than the group count. A checker reconstructs exact conflicts and structure and verifies the neighborhood. Both SAT and UNSAT certificates are polynomial at this terminal.

## 3. Group deletion backdoor with paid discovery
Define t(F) as minimum number of *whole groups* whose deletion leaves a resource-structured option graph. For root B-UNSAT or empty group stop directly. This is a parameter, not a claimed polynomial-time computable statistic. Prove fixed-parameter discovery instead.

The structural property is hereditary under arbitrary option deletions: within each original component the remaining cross-group edges are still complete, or all remaining vertices have the same group and split into isolated vertices. If it fails, take a shortest path between nonadjacent vertices in one component having different group labels. It is induced. If some length-two subpath has endpoints in different groups, that induced P3 is a witness involving at most 3 groups. Otherwise the group labels alternate between two distinct groups throughout the path; its length is at least 3, and its first four vertices form an induced alternating P4 whose endpoints are in different groups and nonadjacent. This witness involves 2 groups. Both witnesses alone violate the property; therefore any deletion solution must remove one of their groups. The alternating P4 is essential: a P3-only rule fails.

Search a budget k by finding a witness, branching on deletion of one witness group, decrementing k, and accepting as soon as the structure holds. If k=0 and a witness remains, reject this budget. Soundness is direct; completeness by induction because every feasible deletion set intersects the current witness. D(k)<=3 D(k-1)+poly(N), with D(0)=poly(N). Iterative deepening through k=t pays O(3^t poly(N)), including failed budgets. The graph and original labels are retained, with deleted groups represented by bit masks.

Fix the discovered set of t groups. Enumerate one selected option per deleted group (<=3 choices each), disallow mutual conflicts, remove their neighboring options in all other groups, and reject any empty group. For each assignment the remaining induced graph is still resource-structured by heredity, so solve it by matching. Inductively this explores all possible selections of the deleted groups and all possible compatible remaining transversals, without enumerating them individually. The second recurrence is E(k)<=3 E(k-1)+poly(N), E(0)=poly(N). Discovery plus execution is a SUM, not a product: discover one deletion set, then solve; no need to enumerate all deletion sets.

Thus one fixed uniform algorithm decides arbitrary 3-CNF in T(F)=O(3^t(F) poly(N)) bit time. t<=O(log N) suffices for polynomial time, and t=0 uses no branching. Peak space is poly(N) by depth-first search, including graph tables and O(N) stack depth. Charge all source scans, canonical ordering if used, reachability, option pair tests, witness searches, unsuccessful budgets, graph copies, matching and final assignment/proof checks. Conservative per-node bit cost is poly(N); no cache oracle or uncharged parallelism. A streamed UNSAT trace can record each exhaustive selection branch, incompatible pair or empty group, and Hall witness at each terminal; the verifier reconstructs the graph and checks exhaustive branching. Size and verification O(3^t poly(N)); if saved in memory this may consume exponential space. No polynomial UNSAT-certificate claim for unbounded t. On a faithful bit-RAM with polynomial workspace, CM=sum_t S_t <=3^t poly(N) with streaming; physical single-tape simulation adds polynomial factors per step using polynomial visited span. These are upper bounds, not measured physical CM or a lower bound on minimum-description CM.

Portfolio with the previous rational-nullity method (d free Boolean coordinates after certified equality quotient) gives T(F)<=poly(N) min(3^t,2^d). Fair time slicing of two fixed complete programs pays both workers and polynomial simulation overhead on polynomial workspace; do not first fully compute t if d is small. Independent components can be solved separately with sum of their bounds, provided variable separation and certificate assembly are checked. Optional further modules can be added with the same paid portfolio rule.

## 4. Infinite matching family with large nullity and width
For any connected simple 3-regular bipartite graph H=(L,R,E), |L|=|R|=s, add one extra left group adjacent to any three distinct resource vertices. Use one Boolean option per resulting incidence. Require exactly one per group (one ternary clause and 3 binary at-most-one clauses), and at most one per resource (all binary pair exclusions). B has all-zero witness, each disjoint group equation is independently integer-feasible, and the all-1/3 vector satisfies the usual LP inequalities and group equalities. Syntactic recognized rational equation rank=s+1, q=3(s+1), d=2(s+1). No SCC identifications from the pure negative binary clauses. B-implied cross-group conflicts are exactly the resource cliques, because setting two options true and all other variables false satisfies B whenever they do not share a resource. Therefore t=0. The root is UNSAT by Hall since s+1 groups use only s resources. Each positive group clause deletion is SAT, leaving its binary clauses intact: set the deleted group's bits false. Deleting the extra group leaves H, which has a perfect matching by regularity and Hall. Deleting an original group leaves a balanced instance: any nonempty proper subset U of original left vertices has |N_H(U)|>=|U|+1, because edge counting gives >= and equality would disconnect H. Subsets containing the extra group therefore satisfy Hall after deleting one original group; the singleton extra group also satisfies Hall. All other subsets satisfy Hall by regularity. Thus every single positive-group-clause deletion neighbor is SAT (not a claim of minimality over all binary clauses).

Exact sizes: q=3s+3, ternary=s+1, group binary=3s+3, resource binary=3(s-3)+6*3=3s+9, total clauses=7s+13. Incrementing s by one within the family changes (q,d,total clauses) by (3,2,7). Explicit bit size N=Theta(s log(s+1)); d=Theta(N/log N). Source H is a minor of the CNF incidence graph: keep each original group clause node as a branch set, and contract all option variables at each resource together using its resource binary clause nodes; distinct branch sets disjoint, group clause incidences give the original H edges. Choose connected 3-regular bipartite expanders to obtain linear treewidth in s (known existence from random regular bipartite spectral gap); no expander generator or width measurement is claimed by the finite tests, which use a circulant H. All variable occurrences bounded (one ternary + 2 group binary + at most 3 resource binary). Matching still decides the expander family in polynomial time; the explicit state budget 2^d grows exponentially in s but is not compulsory work. This family is distinct from the pure degree-two exact-one matching result: the resource exclusions are additional cross-group relations.

## 5. Peer comparison and exact limitations
Reviewed issue #324, the T5 2026-11-21 handoff opening/encoding and resource sections, the previous rational nullity report, and Decomposition Obstructions' 11:25 expander-integer-blind report (c56171e8...). The peer's post-quotient 3-coloring is exactly our option graph with groups (vertex colors) and conflict edges between equal-color options of adjacent vertices. For K4 the option graph has three resource cliques, hence t=0 and Hall 4>3 is a root certificate. For an odd wheel W5, conditioning on any hub color leaves two options per rim group. A general <=2-options independent transversal is 2SAT: choose one Boolean bit per group, require singleton choices by units, and translate each conflict to a binary clause forbidding its endpoints. The odd rim refutes all three hub branches by SCC. A branch-on-group hybrid recurrence can terminate either on resource structure or on <=2 options, but a logarithmic worst-case adaptive depth is not proved. This directly answers the peer's clique/odd-cycle request for these controls. Generic 3-colorability remains NP-complete, so universal polynomial coverage is unresolved.

In fact t can be linear even for connected EASY instances: for the color encoding of path P_(3a), each color is a copy of the path and the three copies share the group labels. There are a vertex-disjoint induced P3s, requiring >=a deleted groups; deleting vertices 3,6,...,3a leaves components of size <=2, so t=a exactly. Thus t alone is not universally logarithmic, and a treewidth/other module is essential. For arbitrary 3-CNF, independent transversals on the lifted graph remain NP-hard in general; the lift does not solve that last step. A graph component being connected, or its options having pairwise supports, is not sufficient for matching: the complete-cross-group condition must be checked. B's two-assumption lemma cannot be transferred to arbitrary affine or Horn conjunctions; e.g. an even parity row on three bits can allow each pair of assumptions yet forbid the triple. The T5 handoff's distinction between scalar decision, full witness relation and exact count remains respected.
