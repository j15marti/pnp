## 1. Model and exact cut lemma
Input is explicit 3-CNF (N bits, at most N variables/clauses), or a certified existential extension with polynomial encoded size and paid verification. Extract sound affine equations over GF(2), retaining all original constraints unless proved redundant; inconsistency rejects. Gaussian elimination gives x=x0+B u, u free in GF(2)^d. Any affine gate definition can be incorporated in this step. Each remaining factor i tests a specified relation on affine forms c_ij+a_ij u; ordinary 3-CNF, exact-one, bounded-size truth tables and bounded fan-in gates have at most a fixed constant r observed forms per factor. Bigger factors need separately charged exact local support computation or certified bounded-arity gate expansion. Fold constants into factor predicates. Write V_i=span{a_ij} as a subspace of the dual free-coordinate space, V_A=sum_{i in A} V_i, and W_A=V_A intersect V_{complement A}. k(A)=dim W_A=rank(V_A)+rank(V_notA)-rank(V_all). All computed via Gaussian elimination. This is intersection of *observable row spaces in a common quotient*, not intersection of raw equation rows.

A valuation on a subspace V means a linear functional V->GF(2). Any such functional extends to the ambient dual by basis extension and hence is realized by some u. For A define M_A to be precisely the set of valuations on W_A which extend to a valuation on V_A satisfying all A factors. For a cut A, the full system is SAT iff M_A and M_notA intersect: two functionals on subspaces extend jointly iff they coincide on their intersection. Proof: define f(l+r)=f_L(l)+f_R(r); alternative decomposition differs by an intersection vector, so it is well-defined iff restrictions agree. Extend by a basis to the ambient space. Necessity immediate. Constants were already absorbed. No raw shared-variable list, affine-hull approximation, or unverified reconstruction.

## 2. Globally consistent tree recurrence
Given a rooted binary factor tree with each factor exactly once as a leaf, set w=max_A dim W_A over node cuts. Root has W_emptyout={0}. For children L,R and outside O, set C=V_L intersect V_R. Then C is contained in both W_L,W_R, and W_parent=(V_L+V_R) intersect V_O is contained in W_L+W_R: for any p=l+r in W_parent, l=p+r lies in V_L intersect (V_R+V_O)=W_L and similarly r in W_R. Precompute coordinate maps for all these embeddings by Gaussian elimination.

Merge recurrence: for each pair alpha in M_L, beta in M_R agreeing on C, emit their induced valuation on W_parent, using p=l+r and alpha(l)+beta(r), deduplicate. Well-defined because two decompositions differ in C. Leaf enumerate valuations on V_i (<=2^r), check actual factor and restrict to W_i. Induction: a recorded pair extends to child satisfying valuations by the exact definition; agreement on C makes those valuations glue on V_L+V_R, with the emitted parent restriction. Conversely any satisfying parent valuation restricts to a compatible pair and emits its own boundary. Thus messages exactly implement simultaneous, not pairwise-only, compatibility and the root is SAT iff its zero-dimensional message is nonempty. A witness is reconstructed by backpointers plus linear extension, and original clauses checked. For UNSAT, recompute all leaf and merge tables including exhaustive pair coverage; a table listing without completeness checking is not enough.

Given tree, dense basis preparation, certificate checking, source parsing and coordinate conversions poly(N). Each leaf <=2^r, each merge <=4^w pairs (possibly fewer), total time T <= poly(N)(2^r+4^w), peak workspace S <= poly(N)2^w for fixed r, storing all tables and pointers, cumulative physical CM=sum live bits over bit steps <=poly(N)8^w, with a faithful bit-RAM and conservative polynomial overhead per pair. Explicit tables and proof checking included; no free parallel workers. If r grows charge 2^r; no memory claim for unbounded r without that term. This is decision, not a model-count theorem. Fixed tree with w=O(log N) gives polynomial. Invertible changes of free coordinates alone preserve these ranks; change the factorization or add certified relations to change the parameter. A non-affine auxiliary gate must be enforced by its defining factor(s); existential projections must be certified and any private variables actually private. No arbitrary semantic projection assumed free.

## 3. Discovery: a substantive literature connection
The exact parameter equals branch-width of the subspace arrangement V_i (Jeong, Kim, Oum, SIAM J Discrete Math 2021, doi:10.1137/19M1285895). The connectivity function f(A)=rank(V_A)+rank(V_notA)-rank(V_all) is integer, nonnegative, symmetric, normalized, and submodular by rank submodularity. Hence the 2026 Korhonen-Oum preprint "Branch-width of connectivity functions is fixed-parameter tractable" arXiv:2601.04756, https://arxiv.org/abs/2601.04756, gives a uniform oracle discovery algorithm in 2^{O(k^2)} gamma m^6 log m, where gamma is our polynomial rank-oracle cost. Exact oracle includes forming row bases, not just reading precomputed ranks. Iterative deepening until the first successful budget (with all failed budgets charged), then DP, gives 2^{O(w_opt^2)} poly(N) time, including discovery and verification (fixed r), with a conservative same-execution S<=2^{O(w_opt^2)}poly(N) and CM<=2^{O(w_opt^2)}poly(N) on a bit model: at most polynomial bits per simulated step or use faithful polynomial-overhead simulation, and S<=O(T+N) after charging writes. Consequently w_opt=O(sqrt(log N)) suffices for a uniform polynomial algorithm with discovery. At w_opt=Theta(log N) this bound is quasipolynomial (N^{O(log N)}), not polynomial. Exact discovery implementation is not executed; theorem used from abstract, no claim of independent proof or optimality. A computable tree of O(log N) width, or singly exponential discovery/constant-factor approximation in polynomial time for these arrangements, would suffice. Universal width bound remains unproved and is false for unrestricted supplied representations (see peer barrier).

## 4. Factored exact-one infinite family, parity controls
For t>=3 and k>=3 choose a connected simple graph H on t block vertices with a specified rim cycle; include cycle itself, cycle plus diameters for even t>=4 (cubic), or cycle plus distance-two edges for t>=5 (degree four). At each i,j introduce a_ij,b_ij,c_ij Boolean, j=1..k. For each graph edge iv impose a_ij xor a_vj=g_iv,j (two binary CNF clauses), where g=p_ij xor p_vj is a known potential difference for the consistent controls; arbitrary gain input checked by Gaussian elimination or spanning forest. Locally impose exact-one(a_ij xor p_ij,b_ij,c_ij) (one ternary and 3 binary clauses). The shifted bit is z_j everywhere after the affine quotient, independent of i. Each exact-one has private b,c with one extension for z_j=1 and two for z_j=0; no exponential relation construction. At first block require exact-one(z_1,z_2,z_3) in its own shifted a coordinates. At last block either repeat that exact-one (SAT), or forbid all three singleton masks 100,010,001 using three 3-CNF clauses (UNSAT). Every deletion of one of those three clauses is SAT: select precisely the formerly forbidden singleton; all other z_j freely chosen. Both labels have consistent chosen affine subsystem and identical rank/nullity; matched UNSAT/neighbor differ by one clause. Additional even/odd charge control flips one rim edge in coordinate 1, so rim cycle xor is 1 and global affine inconsistency occurs, independently of cycle length. For zero total gain on every fundamental cycle the coupling is consistent; zero on only one cycle need not suffice in multicycle graph. The SAT/UNSAT nonlinear pair has all cycle charges zero.

Optional fresh private bit d with clause (z_1 OR d) preserves decision and changes variable count and nullity by one, allowing both parities independently of k. Q=3tk+e (e=0,1); chosen affine rank k(t-1), affine nullity k+2tk+e; source CNF clause count 2k|E(H)|+4tk+4+(4 SAT or 3 blocked)+e, subtract one for deletion neighbors. Rank odd exactly when k odd and t even. Q parity equals tk+e mod 2, M parity in blocked root is 1+e mod 2; the extra bit and alternative controls account for these relationships. Odd degree regular graphs require even vertex count (handshake); degree-two and degree-four controls permit both. No impossible odd cubic t asserted. Inconsistent charge has no affine solution dimension; coefficient rank unchanged, augmented rank larger. Width of block-grouped tree is exactly k for this chosen affine subsystem: every proper whole-block cut shares precisely span(z_1..z_k) and any interior block cut shares at most this space since b,c,d each occur in one factor. Canonical balanced block tree found by sorting factor labels and grouping; direct source recognition can use the binary signed equality components, exact-one templates and provenance, not an oracle. Even without labels fixed-parameter subspace discovery applies. Increasing t by one increases Q by 3k, rank by k, nullity by 2k and base exact-one clauses by 4k, plus coupling cost from new edge counts. Full tree <=2m nodes; T(N,k) <= poly(N)4^k including factor grouping when supplied or recognized. If additionally feed exact-one parity rows to Gaussian worker, each private pair eliminates one coordinate and the first shared triple parity eliminates another; consistency persists on the nonlinear blocked root (take z_1=z_2=z_3=1 in affine subsystem). Rank increases by tk+1, nullity becomes k+tk-1+e, and the same tree width drops to k-1, since only k-1 independent shared forms remain. This latter refinement is symbolic, not implemented in the finite script.

For a cubic expander sequence (even t), raw primal graph contains H on any a coordinate (binary equalities); hence treewidth Omega(t) while algebraic width k is fixed or grows logarithmically for this explicit grouped representation. For odd t choose the previous even expander and subdivide one rim edge when such a rim is available, or use any connected expander with a cycle and choose that cycle for charge control; minor gives growing treewidth and one degree-two vertex, not cubic regular. No expander or width measurement in finite tests. Raw incidence graph also contains H as a minor via one binary clause node per edge. Fixed k gives sparse input N=Theta(t log(t+1)), so width compression is from Theta(t) raw treewidth to constant algebraic width. This is deliberate semantic compressibility, not computational hardness. Independent of graph topology, private extension counts and compatibility proof are exact.
