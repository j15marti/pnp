## 2. Exact cycle projection theorem
Private rim v_0,...,v_(r-1), r>=3, colors {0,1,2}. Each rim vertex i excludes exactly one color f_i (a function of its hub). Along directed edge i to i+1, forbid v_(i+1)=p_i(v_i) for a given permutation p_i in S3; reverse orientation uses inverse. Let P_0=id, P_i=p_(i-1)...p_0 and H=p_(r-1)...p_0. Transport excluded colors c_i=P_i^(-1)(f_i). The cycle has NO extension iff all c_i equal a color q, H(q)=q, and r mod 2 differs from the sign bit of the restriction of H to the two complementary colors.

Proof: after excluding each f_i each rim list has two colors. If any edge's restricted forbidden matching is not perfect, one target color is unmatched by either source color. Fix that target, greedily traverse all other edges until the source is colored (each step excludes at most one of two choices); closing edge is automatically valid. If all matchings perfect, along every edge the excluded colors must correspond, equivalently all c_i=q with H(q)=q. Each allowed edge is the other bijection between the two-element lists, i.e. flip composed with the forbidden bijection. Around the cycle this gives H restricted to complement composed with r flips. A fixed point exists iff this binary permutation is identity, equivalently r parity equals the sign bit. If the nonidentity permutation is a swap it has no fixed point. This proves necessity and sufficiency, and gives a linear-size witness reconstruction procedure (two initial values or the unmatched endpoint).
Classification: identity -> odd rim obstruction iff c_i all equal; transposition -> even rim obstruction iff all c_i equal its unique fixed color; 3-cycle -> never obstruction. Other parity/type pairs are always extendible. This is the signed/correspondence extension of the ordinary odd-wheel projection. No global parity conclusion from the parity of a single unrelated edge.

## 5. Explicit compatibility firewall and scaling
Any signed 3-CNF clause on distinct Boolean hubs can be encoded as a private even rim of length 4. Put the first hub on two rim vertices and the other hubs on one each. Identity edge maps except final transposition (1 2), fixed color 0. Each spoke sends its clause-violating bit to 0 and satisfying bit to 1. All transported excluded colors equal 0 exactly on the unique clause-violating hub assignment. Therefore this cycle projects to exactly the clause, rank 3. Arbitrary conjunctions of these private cycles reproduce arbitrary 3-CNF. A private odd triangle with identity edge maps also encodes a clause if two of its spoke maps have differing second colors (e.g. satisfying values map to 1,2,1, all violating values map to 0), so common eligible color is uniquely 0. Both rim parities can carry full compatibility hardness, not just the odd one. For same-image Boolean maps on an odd identity rim the forbidden set instead consists of the complementary equal-color patterns, general signed NAE; two independent hubs give rank 1. Nontrivial width remains arbitrary after projection. Thus compact, polynomially discoverable affine obstruction messages and polynomial forced rank-one closure do NOT by themselves establish global polynomial compatibility. This is a decision reduction, NOT a lower bound against unrestricted algorithms.
