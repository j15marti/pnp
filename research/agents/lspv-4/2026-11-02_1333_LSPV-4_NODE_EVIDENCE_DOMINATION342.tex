\section*{Concrete node-to-evidence domination theorem}
Fix the already declared $R_{\mathrm{mix341}}$ with unit-cost derived nodes: binary RES, AND3 of at most three-variable factors carrying eight-bit truth tables, binary GF(2) XOR, constant-support LOCAL-CONVERT, and a conservative two-input DEF that introduces exactly one fresh variable per charged node. Source clauses carry original IDs; all rule justifications are explicit and locally checkable. Ordinary RES makes the calculus complete.
\begin{theorem}
Write $q=W_{R_{\mathrm{mix341}}}(F)$ and let $L_R(F)$ denote the shortest self-contained bit encoding of the input and any valid refutation DAG in the fixed dense-line format. Then, for a universal $C$,
\[
\boxed{q\le L_R(F)\le C(N+q+2)^2.}
\]
Consequently $\overline W_R(N)\le \overline L_R(N)\le C(N+\overline W_R(N)+2)^2$, so polynomial boundedness of the two worst-case minima is equivalent for this declared calculus and encoding.
\end{theorem}
\begin{proof}
A $q$-node refutation introduces at most $q$ fresh names, so every clause, XOR row, factor or gate involves at most $v\le n+q\le N+q$ variables. Set $K=N+q+2$, $b=\lceil\log_2 K\rceil$. Encode a clause by two $v$-bit signed-presence arrays, an affine row by $v$ bits and its RHS, a local factor by three $b$-bit IDs and eight truth bits, and a DEF by bounded gate tags and at most three IDs. Each derived node additionally has a bounded tag, at most two earlier parent IDs and source indices. Its encoding is at most $B(K)=2K+8b+64$ bits. Thus the complete pair $(F,\pi)$ has length at most $N+O(\log K)+qB(K)\le C(N+q+2)^2$. Each charged derived node occupies at least one encoded bit, so $W_R(F)\le L_R(F)$. Maximize over all UNSAT strings with length at most $N$. A standard local proof verifier uses time polynomial in $N+q$, but its physical peak space depends on scheduling.
\end{proof}
\section*{Why a unit-node rule can be computationally misleading}
Define the fixed adversarial test calculus $R_{\mathrm{TT}}$ by adjoining to resolution a TABLEAU rule: supply, for each of the $2^n$ assignments $a$ to the declared $n$ variables, the ID $j(a)\in\{1,\dots,m\}$ of an original clause false on $a$. The checker reads every supplied ID, evaluates that source clause on that assignment, and accepts the rule only when all entries are correct. This is a uniform, sound, complete, certificate-backed rule with no SAT oracle and polynomial verification time \emph{in the encoded certificate length}, not in $N$.
\begin{proposition}
Every UNSAT $F$ has a one-TABLEAU-node contradiction refutation, with $E_{\mathrm{TT}}=2^n\lceil\log_2(m+1)\rceil$ explicit evidence bits. Thus $\overline W_{R_{\mathrm{TT}}}(N)\le 1$ although TABLEAU proof evidence can be exponential in $N$. A short inference count does not give a bound on actual machine work.
\end{proposition}
\begin{proof}
Each assignment violates some original clause exactly when $F$ is UNSAT. List one witnessing clause ID for each assignment. This certifies the inference. If $F$ is SAT, the satisfying assignment has no valid entry and the rule is rejected. The $n$-variable family $(x_1)\land(\neg x_1)\land\bigwedge_{i=2}^n(x_i\vee\neg x_i)$ has $O(n\log n)$ input bits but $2^n\lceil\log_2(n+2)\rceil$ tableau-evidence bits.
\end{proof}
\noindent\textbf{Important:} $R_{\mathrm{TT}}$ is a \emph{falsifier}, not the accepted unit-weight hardness calculus. It is precisely the sort of unbounded-evidence one-node semantic leap ruled out by the user's cost contract. Charging table bits/validation repairs its own accounting but yields no arbitrary-SAT lower bound.

\section*{Exact resource and transfer gap}
The theorem makes a $q$-node proof a polynomial-bit certificate in this \emph{specific} fixed calculus; it does not supply B3:
\[
\mathrm{SAT}\in P\ \Longrightarrow\ \overline W_{R_{\mathrm{mix341}}}(N)\le\operatorname{poly}(N).
\]
Polynomial local checking and compact evidence do not prove that every correct decider's work can be converted into such a derivation. LSPV-1 CLOCKED336 gives a conditional size-optimality route only. The recent Braun (2026) DAG Res($\oplus$) bit-PHP lower bound is for a restricted calculus and can be escaped by charged DEF/extended-resolution rules in the present mix. The actual all-phase machine-space envelope remains $s'\le\max\{\rho,\eta,\lambda,\lambda s\}$ with $\rho$ including source/index access, parsing, generation, conversion, verification, and temporary materialization. Allocating $N$ writable bits in any phase gives $\rho\ge1$. A proof checker that stores source plus whole DAG is not a square-root-space demonstration. No numeric FLMV transfer is claimed.
