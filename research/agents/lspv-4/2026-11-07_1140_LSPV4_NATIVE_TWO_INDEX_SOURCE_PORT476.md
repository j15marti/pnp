## Theorem 476.1: two-index source-port isolation (PROVED/RESTRICTED)
Fix a binary original source x of N bits on the read-only physical INPUT X. Let I_X be its associated native INDEX tape. Fix a guest logical INPUT-INDEX tape I_G and a particular guest trace whose INDEX head is at H and is **not operated on during q externally specified original-source bit retrievals**. Place I_G on a distinct native INDEX tape attached to an otherwise unused WORK tape; do not make indexed WORK jumps on that spare non-index tape. This uses one extra tape pair, a constant addition independent of N and of the unknown guest polynomial exponents. The original source address a_j in [0,N) for request j is *provided to the port by a separate, charged procedure*; its computation is NOT included in the theorem.

Under the head-preserving erasure convention and assuming I_X is returned to position 0 after each original-source access, source address a_j can be written in binary on I_X by at most ell_j=1+floor(log2(max(1,a_j))) sequential bit positions, followed by one native indexed read and erasure and a rewind of at most ell_j-1 steps. The guest INDEX head is never moved or modified. Thus the number of physical INDEX-head moves is at most

$$
J_{\rm dual} \le 2\sum_{j=1}^{q}(\ell_j-1) \le 2q\lceil\log_2(N+1)\rceil
$$

on I_X, and zero *additional* movement on I_G. Indexed instructions, source reads, INDEX-bit writes, answer delivery, source-address construction and tape restoration are separately charged; the source-port portion costs O(q log(N+2)) native operations plus paid address acquisition and O(log(N+2)) temporary bits/index span beyond the already-live guest configuration. For a_j=1 throughout, source INDEX head movement is zero and the source-port has O(q) native operations even when H=q tends to infinity.

**Proof.** FLMV's native INPUT X already has I_X. An additional dummy WORK tape has its own associated I_G, and never needs an indexed WORK move. An indexed read of X erases I_X but does not touch I_G. Initialize I_X at zero; write the binary digits of a_j in order, move the target INPUT head to a_j in one indexed instruction, read x[a_j], and rewind the I_X head. These operations exactly reconstruct the requested immutable source bit and take the stated steps. The source tape is not copied. At all times the logical guest I_G contents and head are unchanged. In the original /474 one-INDEX immediate-return protocol, the corresponding physical head movement would be 2Hq + J_dual, by necessity of moving the shared tape H->0->H each time. On the distinct physical I_X/I_G construction this 2Hq term is absent. The theorem does not lower bound or fully implement address acquisition, arbitrary guest input-head motion/jump, guest work tapes, ephemeral INDEX state, recursive child generation, malformed handling, guest reuse, output or global time/space contraction. QED.

**Qualifiers:** This lemma assumes a head-preserving or reset-to-zero INDEX erasure compatible with a <=ell_j source-index rewind; if a different INDEX-head convention is specified, its rewind must be audited. It accounts for the extra physical INDEX tape and its possible O(log N) live storage even if INDEX tapes count in the chosen resource metric. The guest's own H-position must still be charged consistently in its own model; no claim of free INDEX storage or free WORK high-water follows. Physical INDEX space is not an arbitrary zero-cost oracle. A request a_j must be **legally acquired** before access. No full generic virtual-input simulation is asserted.
