\section{Explicit source and encoding}
Fix $d\ge2$, two leaf sets $A=\{a_1,\ldots,a_d\}$ and $B=\{b_1,\ldots,b_d\}$, and a matrix $\tau\in\{0,1\}^{d\times d}$. For each set build a binary OR tree, with each internal gate $t=p\lor q$ encoded by its exact functional CNF
\[
(\neg p\lor t)\land(\neg q\lor t)\land(p\lor q\lor\neg t).
\]
If $r_A,r_B$ are the roots, force them with paired proper binary clauses $(r_A\lor u)\land(r_A\lor\neg u)$ and $(r_B\lor v)\land(r_B\lor\neg v)$, where $u,v$ are free. Add all pairwise negative binary clauses within each leaf set (at most one true leaf). For each $(i,j)$ add
\[
C_{ij}=\begin{cases}(\neg a_i\lor\neg b_j),&\tau_{ij}=1,\\
(\neg a_i\lor b_j),&\tau_{ij}=0.\end{cases}
\]
The total formula $\Phi_{d,\tau}$ contains exactly
\[
n=4d,\qquad m_2=2d^2+3d,\qquad k=m_3=2d-2,\qquad m=2d^2+5d-2.
\]
There are $2d$ original choices, $2d-2$ functional OR-gate variables, and two free auxiliaries. No initial unit or pure literal occurs. Every clause is proper. Source encoding uses two header words followed by four fixed words (width and three signed-literal slots) per clause, each word having
\[
w=\lceil\log_2(64(n+m+1))\rceil,\quad N=(2+4m)w=(8d^2+20d-6)w.
\]
A sign change affects one bit of one signed-literal word and no length or other metadata. All parsing, source reads, template verification, failed attempts, witnessing, replay, construction, output length and peak space are charged.

\section{Exact semantic and source-query theorems}
\begin{theorem}[Both-label criterion and counting]
If $h_i=|\{j:\tau_{ij}=0\}|$, then
\[
\Phi_{d,\tau}\in SAT\iff \exists i:h_i=1,\qquad
\#SAT(\Phi_{d,\tau})=4|\{i:h_i=1\}|.
\]
\end{theorem}
\begin{proof}
The root forcing plus functional gates and intra-group exclusions enforce exactly one true $a_i$ and one true $b_j$. If $a_i=b_j=1$, the $i$th row's $j$th clause requires $\tau_{ij}=0$ while every other entry in that row requires $\tau_{i\ell}=1$. Conversely any row with exactly one zero at $j$ gives the valid choice $(a_i,b_j)$, unique functional gate values, and four free $(u,v)$ settings. Clauses in other rows are automatically satisfied.
\end{proof}
\begin{theorem}[Input-word necessity]
On the all-one (UNSAT) source, every deterministic exact SAT decider working on the declared fixed-record addressed-word input model must read each of the $d^2$ sign-containing source words:
\[
D_{\mathrm{word}}(\Phi_{d,\mathbf 1})\ge d^2=(k+2)^2/4=\Omega(N/\log N).
\]
\end{theorem}
\begin{proof}
Flipping any unread sign creates precisely one zero in its row, producing SAT with exactly four complete assignments. The original and flipped source differ in no other addressed word; an exact deterministic algorithm with identical observations cannot give opposite answers. The lower bound is tight up to constants because a single $O(d^2)$ source scan determines all row zero counts. It is neither an encoding-independent $\Omega(N)$ theorem nor a superlinear computation-time lower bound.
\end{proof}
\begin{theorem}[Every ternary essential on the designated UNSAT source]
For every internal gate ternary $D=(p\lor q\lor\neg t)$, the formula $\Phi_{d,\mathbf1}\setminus\{D\}$ is satisfiable, although $\Phi_{d,\mathbf1}$ is not.
\end{theorem}
\begin{proof}
In the group containing the deleted ternary, set all leaves false, set $t$ true despite its false children, and propagate true values along the OR tree path to the root. Every other gate remains functional. In the opposite group set exactly one leaf true, compute all gate outputs normally, and satisfy its root. The within-group exclusions and all cross negative clauses hold because the first group's leaves are false. The deleted $D$ is the only violated original clause.
\end{proof}
