\section*{Exact shared-DAG theorem}
For authenticated $w$-bit GF(2) row vectors $r_0,r_1$, fix the uniform rule $r_i=r_{i-1}\oplus r_{i-2}$, $2\le i\le q$. Each node has explicitly encoded parent indices and all $w$ row bits. The number of distinct dependency \emph{walks} from $r_q$ to either source is $P_0=P_1=1$, $P_i=P_{i-1}+P_{i-2}$, hence $P_q=F_{q+1}=\exp(\Theta(q))$. The DAG has only $q-1$ charged XOR inference nodes, and $r_{i+3}=r_i$ over GF(2).

\begin{theorem}
One fixed uniform sequential verifier checks every source bit, parent reference, XOR result, output coefficient and record, in $O(M+qw)$ bit operations and $O(w+\log(M+q+2))$ peak writable bits, where $M=\Theta(q(w+\log q))$ is complete explicit evidence length, modulo fixed headers. All parsing, head movement, counters, output and live rows are paid; no oracle, nonuniform advice or hidden semantic step is used.
\end{theorem}
\begin{proof}
Read the first two $w$-bit rows and retain just these two registers. Check each succeeding record has parents exactly $i-1,i-2$ and its $w$ output bits equal the XOR of the retained rows; move both registers forward, increment an $O(\log q)$ index, and continue through the entire input. The arithmetic costs $O(qw)$ plus a full $O(M)$ scan. The number of source-root walks follows by disjoint last-edge choices in the Fibonacci recurrence, despite shared subnodes. Thus walk multiplicity is not a lower bound on native work.
\end{proof}
