\section*{Theorem 553.1 (strict restricted native work improvement)}
The /386 checker constructs an ordered map of paid gate definitions indexed by their \emph{declared ID} and output variable. It checks distinct, nonnegative IDs, not that the ID set is an interval. In the LSPV-3/579 packet gate \([0,20,1,4]\) has no DEF record, no use of output literal \(20\) anywhere, and no later gate input depending on \(20\). Thus removing this tuple leaves all record identities, signed SOURCE clauses, the 41 oriented Resolution deductions, the terminal empty clause, freshness and all gate-dependency predicates unchanged. Retaining gate IDs 1 and 2 is legal. Replacing summary fields \(\texttt{paid\_gates}=3,\texttt{paid\_total}=44\) with 2 and 43 exactly matches the checker's count:
\[
W_{\mathrm{original}}=41+3=44,\qquad
\boxed{W_{\mathrm{pruned}}=41+2=43}.
\]
The serialized compact newline-terminated packet shrinks from 6,023 to 6,012 UTF-8 bytes, although all 94 original proof records and 49 mandatory original signed SOURCE clauses remain byte-identical as structured values. This is an existential accepted-packet upper bound, \emph{not} a refutation-work minimum.
