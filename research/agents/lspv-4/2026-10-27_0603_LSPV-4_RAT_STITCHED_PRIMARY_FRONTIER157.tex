\section{A strict native-model exclusion certificate}
\begin{theorem}
For a \emph{single fixed uniform deterministic ordinary-SAT decider}
in the source-matched read-only indexed-input/indexed-work bit-machine,
if simultaneous worst-case resources are
$T=N^{t+o(1)}$, $S=N^{\sigma+o(1)}$ with $0\le\sigma<1$,
then existing published lower bounds imply
\[
\boxed{\displaystyle
 t\ge C_{\rm cert}(\sigma)=
\max\left\{1,\ \varphi-\sigma,\ f(\sigma),\
\max_{\substack{(\varepsilon,c)\in\mathcal B\\\sigma<\varepsilon}}
(c-10^{-4}),\quad\gamma\ {\rm if}\ \sigma=0\right\}.
}
\]
Here $\mathcal B$ is the nine successful rows above.
This is a conservative achieved exclusion envelope,
not a claim of an optimal algorithm frontier;
equality is not excluded.
\end{theorem}
\begin{proof}
If $t<C_{\rm cert}$, it falls strictly below an applicable
Williams product, FLMV, eligible Buss--Williams or
subpolynomial-space cosine bound. In the FLMV case choose
$t<c<f(\sigma)$ so that $\sigma<\beta(c)$.
The original source theorems are imposed on the same
indexed machine and same simultaneously measured resources.
\end{proof}
