\section{Exact bit-input sensitivity theorem}
Fix an ordinary signed proper-3CNF encoding in which each literal
sign is represented by one fixed bit, and changing that bit without
changing the other fields produces another valid ordinary formula.
Our executable grammar uses eight-bit ASCII \texttt{0}/\texttt{1}
sign bytes (the bytes differ in exactly one physical input bit),
unary counts in the header as decimal text, fixed-width literal IDs,
three distinct variables per clause, and fixed delimiter slots.
The encoding must be translated with paid time and space if another
input convention is used; no free equivalence to an unrelated
FLMV encoding is asserted.

For any such input $x$ of length $L$, define its set of
\emph{valid pivotal positions}:
\[
 \mathcal P(x)=\{j\in[L]:x\oplus e_j
  \text{ is another valid ordinary-CNF input and }
  \SAT(x\oplus e_j)\ne\SAT(x)\}.
\]
\begin{theorem}[Pivotal-input necessity]\label{th:pivot}
Every fixed deterministic total exact ordinary-SAT decider $A$,
globally correct on every ordinary input, must probe each indexed
read-only input bit $j\in\mathcal P(x)$ while computing $A(x)$.
Consequently its number of (possibly repeated) input-read events
on $x$ is at least $|\mathcal P(x)|$.
The same conclusion holds for a sound partial SAT-only recognizer
which positively terminates on $x$ when $\SAT(x)=1$, or a sound
partial UNSAT-only recognizer which negatively terminates on $x$
when $\SAT(x)=0$. In the partial cases the conclusion is about
the declared \emph{successful computation} only.
\end{theorem}
\begin{proof}
If $A$ never requests a pivotal bit $j$ on $x$, deterministic
induction over each complete charged machine transition gives an
identical state, index and input-read sequence on $x$ and
$x\oplus e_j$: every requested bit is equal in the two inputs.
The machine therefore issues the identical answer on both,
contradicting global exactness. For the partial one-sided version,
the accepting successful trace on $x$ is identical on the
opposite-label neighbor; the same one-sided output is then unsound.
All index calculations, work reads, control, unchanged writes,
and output processing can be arbitrarily complicated without
altering the argument. This proves a lower bound on \emph{input
probes in that declared guest}, not on every possible alternative
solver architecture.
\end{proof}

\section{Opposite-label proper-3CNF witness families}
For fresh pairwise distinct auxiliaries $u,v$ set
\[
 \operatorname{PIN}(\ell;u,v)=
  \bigwedge_{\epsilon,\zeta\in\{-1,1\}}
  (\ell\vee \epsilon u\vee\zeta v).
\]
Existentially over $u,v$, this proper-3CNF gadget enforces
exactly $\ell$.

\paragraph{SAT-centered family $F_m^+(z)$.}
For each $i=1,\ldots,m$, choose fresh names $x_i,a_i,b_i$
and fresh private PIN auxiliaries. Conjoin
\[
 \operatorname{PIN}(x_i)\wedge
 \operatorname{PIN}(\neg a_i)\wedge
 \operatorname{PIN}(\neg b_i)\wedge
 ((-1)^{z_i}x_i\vee a_i\vee b_i).
\]
Here $z_i=0$ denotes the positive $x_i$ literal and $z_i=1$
the negative literal. All clauses have three distinct variable
names, there are $9m$ variables and $13m$ clauses, and
\[
 \SAT(F_m^+(z))=1\quad\Longleftrightarrow\quad z=0^m.
\]
In particular the SAT center $F_m^+(0^m)$ has $m$ distinct
critical literal-sign bits; flipping any one makes it UNSAT.

\paragraph{UNSAT-centered family $F_m^-(z)$.}
Use chain variables $x_0,\ldots,x_m$, fresh $p_1,\ldots,p_m$,
and separate PIN auxiliaries. Conjoin
\[
 \operatorname{PIN}(x_0)\wedge
 \operatorname{PIN}(\neg x_m)\wedge
 \bigwedge_{i=1}^m
 \left[
 \operatorname{PIN}(\neg p_i)\wedge
 (\neg x_{i-1}\vee(-1)^{z_i}x_i\vee p_i)
 \right].
\]
This is proper-3CNF with $4m+5$ variables and $5m+8$
clauses. At $z=0^m$ the constraints require
$x_0\Rightarrow x_1\Rightarrow\cdots\Rightarrow x_m$,
contradicting the terminal pins. If any $z_i=1$, assign
$x_0,\ldots,x_{i-1}$ true, $x_i,\ldots,x_m$ false, and
all $p_j$ false: every chain clause is satisfied. Therefore
\[
 \SAT(F_m^-(z))=1\quad\Longleftrightarrow\quad z\ne0^m.
\]
At the UNSAT center every one of the $m$ literal-sign bits
is independently pivotal in the \emph{opposite} direction.

\begin{corollary}[Near-linear guest input reads on both labels]
For the explicit canonical fixed-slot grammar above, the
two center encodings $x_m^\pm$ each have
$L_m^\pm=\Theta(m\log(m+2))$ physical input bits and
$|\mathcal P(x_m^\pm)|\ge m$. Consequently any globally exact
deterministic guest $A$ performs at least
\[
 \Omega(L_m^\pm/\log(L_m^\pm+2))
 = (L_m^\pm)^{1-o(1)}
\]
indexed input reads at \emph{each center}. Thus a uniform
guest-image premise $R_A(y)\le |y|^{q+o(1)}$ with any fixed
$q<1$ is false for any eligible infinite family containing
all sufficiently large such centers. On the SAT centers the
same holds for successful sound SAT-only acceptors; on the
UNSAT centers for successful sound UNSAT-only rejectors.
\end{corollary}
\begin{proof}
Each one-bit sign flip remains in the same ordinary grammar,
preserves physical input length and reverses SAT status.
Apply Theorem~\ref{th:pivot}. The stated length formula follows
from a linear number of proper clauses and logarithmic-width
literal-ID fields. $m=\Omega(L_m/\log(L_m+2))$.
\end{proof}

\section{Actual two shorter ordinary-child levels and charged accounting}
Let $P_h$ consist of $h$ disjoint positive three-literal clauses
on fresh variables, independent of the hard-looking core.
Every $P_h$ is SAT. For $h=m^4,m^2,0$, let
\[
 R_m^\pm(z)=F_m^\pm(z)\wedge P_{m^4},\quad
 C_m^\pm(z)=F_m^\pm(z)\wedge P_{m^2},\quad
 G_m^\pm(z)=F_m^\pm(z).
\]
The fixed canonical record compiler actually parses/validates
$R_m^\pm(z)$, generates and re-parses $C_m^\pm(z)$, then
generates and re-parses $G_m^\pm(z)$. It checks headers,
all literal IDs and signs, and exact source family and mask.
No SAT bit is supplied by an oracle. Both SAT and UNSAT
are preserved at \emph{each} step because the discarded
padding has disjoint variables and remains satisfiable.
Their true encoded lengths are
\[
 |R_m|=\Theta(m^4\log m),\quad
 |C_m|=\Theta(m^2\log m),\quad
 |G_m|=\Theta(m\log m),
\]
giving first-level exponent $1/2+o(1)$ and second-level
$1/2+o(1)$ relative to the current level.
Thus $|G_m|=|R_m|^{1/4+o(1)}$.
This construction meets actual ordinary-child eligibility
\emph{only on this cheaply recognized padded subfamily}.
A direct core/sign recognizer reads its source and decides
the label in near-linear bit work and polylogarithmic
writable/index space, so this is not an FLMV-hard image or
an all-input source contractor.

For this restricted constructor, validating and scanning the
source is $N^{1+o(1)}$ bit work with $N^{o(1)}$ index/work
memory. Serializing one complete first child eagerly takes
$N^{1/2+o(1)}$ writable/index positions; serializing one
grandchild takes $N^{1/4+o(1)}$ additional positions.
If the first child is retained during the second stage,
its space remains simultaneously live and the composite
eager envelope with a final total guest of joint pair $(t,s)$ is
\[
 t_{\mathrm{toy}}\le \max\{1,t/4\}+o(1),\qquad
 s_{\mathrm{toy}}\le \max\{1/2,s/4\}+o(1).
\]
These are upper exponents for this already-easy,
fully recognized family, \emph{not} an all-input
machine transformation. They require the stated sequential
materialization, parse, head/index, buffer and generator
steps to be charged, including unchanged writes.
At the saturated GUEST-PROBE-QUOTIENT117 illustrative
cell $(a,H,\gamma_2)=(9/10,1/4,1/10)$,
its strict time inequality $a+Hq+\gamma_2<c_\star$
requires $q<41/50$. The present centers force $q\ge1$
for a globally exact guest \emph{if such centers occur
cofinally in the actual eligible guest input family}.
Substituting $q=1$ into the \emph{sufficient upper-envelope}
expression gives $5/4>241/200$; this does \emph{not}
prove an actual $N^{5/4}$ time lower bound, because
that envelope is not a lower bound, and an alternative
eager/cached implementation can do better.
The fixed hard-image source-to-padding expansion
is quartic; transporting a hard-source length $n$
to these roots reverses the apparent contraction and
invalidates any purported FLMV contradiction.

\section{DUPLICATION / CONTRADICTION AUDIT}
The information-theoretic input-bit sensitivity lemma is
elementary and not a new SAT algorithm lower bound.
GUEST-PROBE-QUOTIENT117 already proved that sparse
guest probes do not follow from $(t,s)\in E$:
globally correct padded programs can have identical upper
resource exponents but radically different input-read counts.
This new theorem instead supplies \emph{fixed proper-3CNF
SAT and UNSAT input families} where \emph{every} globally
correct guest must read almost every logarithmically dense
sign slot, without supposing $P=NP$.
NESTED-ACCESS-TAX113 already showed two syntactically
short ordinary descendants can incur severe repeated
virtual source reads in a declared lazy emulator.
The present witness establishes a \emph{guest-read
obligation} that nested access cannot avoid merely by
changing the guest program on the specified pivotal
centers, but it leaves unrelated caching and source
recognition shortcuts open.
ARC-SIDECAP-PORTFOLIO174's one-sided completion remains
compatible: such an acceptor has to read pivotal
sign positions on every successful center of its label.
ARC-PIN-HEREDITY120's named-support pin criterion
is a different exact semantic question; no low-width
interface is proved from input sensitivity.
ARC-SCOPE-TOLL160's fixed hard-image normalizer
toll is respected, not bypassed by removable padding.

\paragraph{STALE OR OVERSTATED CLAIMS FOUND.}
Treating $q<41/50$ as numerically achievable from
guest time $t=6/5$ alone is invalid.
Treating one restricted input-read lower bound as a
general SAT decision-time lower bound is equally
invalid. An arbitrary hypothetical machine might
recognize the easy family, merge source work,

statement relativizes (global oracle inputs
are not free ordinary SAT bits) and supplies no
nonrelativizing or algebrizing hinge by itself.

hash assumption, Schur-square theorem, VLSI
physical bound or communication theorem transfers
automatically to the same FLMV machine realization.
