\section{Primary-literature and obstacle preflight}
The two current obstacles are: (i) a one-bit deterministic run is not a proof
in the lower-bounded system; and (ii) eliminating or translating computation
extension variables can be expensive and requires an explicit simulation
theorem.

Cook--Reckhow define propositional proof systems and polynomial simulations;
their framework does not identify an arbitrary decision trace with a proof in
a preselected weak system \cite{cookreckhow,krajicek}.  G\"o\"os, Koroth,
Mertz, and Pitassi prove that finding Cutting Planes proofs can itself be
NP-hard even relative to the shortest proof, separating proof existence,
verification, search, and decision \cite{gkmp}.  Buss--Tur\'an record
generalized pigeonhole formulas with exponential Resolution lower bounds but
polynomial extended-Resolution proofs, so auxiliary definitions cannot be
silently eliminated from Resolution with polynomial overhead
\cite{bussturan}.  Fleming et al. give substantive translations between named
branch-and-cut systems under explicit hypotheses; this is evidence that such
translations are theorems to prove, not automatic consequences of a trace
\cite{fleming}.

\paragraph{Cross-field classification.}
Proof-complexity p-simulation is a \textbf{directly transferable framework},
but no cited theorem supplies the required arbitrary-run-to-\(\sCP\)
translation.  Circuit observability and VLSI trace ideas are
\textbf{misleading/failed transfers}: a software computation may add COPY,
DELAY, DEAD, or interpreter structure without changing its answer.  LWE-style
black-box extraction is an \textbf{analogy/candidate}; an unconditional
solver-to-proof reduction with its query and replay costs is still missing.

\section{Exact fixed-trace theorem}
Let \(C\) be a finite acyclic Boolean circuit with inputs fixed to a bit string
\(y\), output variable \(o\), and gates from
\(\{\mathsf{AND},\mathsf{OR},\mathsf{XOR},\mathsf{NOT},\mathsf{COPY}\}\).
Let \(b=C(y)\).  Write \(T(C,y)\) for the standard Tseitin CNF consisting of
the input unit clauses and constant-width equivalence clauses for each gate.
Let \(\bar o_b\) be the unit literal asserting \(o=1-b\).

\begin{theorem}[fixed-trace collapse]
For every \((C,y)\):
\begin{enumerate}
\item \(T(C,y)\wedge \bar o_b\) has a unit-Resolution refutation using
  \(O(|C|+|y|)\) clauses and propagation steps;
\item if \(\rho_{C,y}\) assigns every circuit variable its actual evaluated
  value, every clause of \(T(C,y)\) is true under \(\rho_{C,y}\), while
  \(\bar o_b\) alone becomes the empty clause;
\item the statement holds independently of whether \(y\) encodes a YES or a
  NO instance of any external decision language.
\end{enumerate}
\end{theorem}

\begin{proof}
Input units assign all input variables.  In topological gate order, the
constant-width CNF equivalence for each gate unit-propagates its output once
its inputs are assigned.  Hence all circuit variables, including \(o=b\),
are derived, contradicting \(o=1-b\).  This uses a constant number of clauses
and steps per gate.

For item 2, the actual evaluation satisfies every input unit and every gate
equivalence by definition.  The opposite-output unit is false and therefore
restricts to the empty clause.  No semantic property of the external input
language was used, proving item 3.
\end{proof}

\begin{corollary}[projection firewall]
The evaluation substitution \(\rho_{C,y}\) does not turn the fixed-trace
refutation into a derivation of unsatisfiability from the clauses of an input
formula \(H\).  It deletes all computation axioms as true and leaves only the
false output assumption.  In particular, the same construction on a
satisfiable input gives an equally short contradiction with the opposite
output.
\end{corollary}

This does not prove that no other machine-to-proof theorem exists.  It
falsifies the natural candidate that a short fixed computation trace, merely
Tseitin-encoded and evaluated, is already the required proof of \(H\).

\section{What an actual bridge must add}
Let \(z\) denote a putative assignment to the variables of \(H\).  A proof of
\(H\)'s unsatisfiability must connect the clauses of \(H\) to contradiction.
The fixed circuit \(C_{A,y}\), with \(y=\operatorname{enc}(H)\), has no free
\(z\)-variables and therefore contains no premise saying that \(z\) satisfies
\(H\).  A genuine transfer needs both:
\begin{enumerate}
\item \textbf{correctness internalization:} a sound, quantitatively bounded
  derivation connecting \(H(z)=1\) to the correct output of \(A(y)\), rather
  than trusting the terminal bit as an axiom; and
\item \textbf{extension elimination/model translation:} a proof that the
  resulting circuit/extension-variable derivation translates to the exact
  \(\sCP\)/triangle system carrying the unconditional lower bound, with size,
  depth, coefficients, construction time, replay, and joint workspace
  controlled.
\end{enumerate}
The first item is not supplied by transition checking, and the second is not
free: known Resolution versus extended-Resolution separations are a direct
hostile boundary.  This gives a three-stage proof map:
\[
 \underbrace{\text{fixed execution}\Rightarrow
 \text{wrong-output trace contradiction}}_{\EXACT}
 \quad\not\Rightarrow\quad
 \underbrace{\text{proof of }\neg H}_{\text{correctness }\OPEN}
 \quad\not\Rightarrow\quad
 \underbrace{\sCP\text{/triangle proof}}_{\text{translation }\OPEN}.       \tag{2}
\]

\section{Hostile controls and barrier audit}
\paragraph{Easy families and representations.}
Horn, 2-SAT, affine/Tseitin, and bounded-treewidth computations all receive
the same short wrong-output trace contradiction, showing that its size cannot
measure the semantic difficulty of the input language.  Independent products
and padding only concatenate more fixed evaluations.  COPY, DELAY, DEAD,
INTERP, and RECOMP may enlarge or reorganize the trace without supplying the
missing correctness derivation.  Compact circuits are explicitly allowed;
expanded-monomial PC/PCR size is not imported.

\paragraph{Oracle replacement.}
With oracle gates, fixing the realized oracle replies makes the same local
trace theorem go through.  Correctness of those replies relative to the input
language remains external.  The firewall therefore relativizes and cannot by
itself evade Baker--Gill--Solovay.

\paragraph{Algebrization.}
Replacing Boolean gate constraints by low-degree gate equations yields the
same evaluated-trace collapse: the actual values satisfy all gate equations,
and the false output equation supplies the contradiction.  No
nonalgebrizing hinge is obtained.

\paragraph{Natural Proofs.}
No constructive large circuit property is proposed; the Razborov--Rudich
framework is not the immediate obstruction.  The obstruction is the missing
model-matched proof translation.

\paragraph{Post-quantum ledger.}
Schur squares, quadratic-relation spaces, syzygies, and collision entropy are
not the object in (2), so their use here is \textbf{FAILED TRANSFER}.  The
LWE lesson of external black-box extraction is an
\textbf{ANALOGY/CANDIDATE}; it would require a new unconditional reduction
from an arbitrary \(\Ltwo\) decider to the lower-bounded proof object.  No
cryptographic assumption or random oracle is used.
