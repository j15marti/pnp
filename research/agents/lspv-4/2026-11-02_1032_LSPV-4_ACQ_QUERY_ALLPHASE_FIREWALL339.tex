\section{The exact combined acquisition--query theorem}
Let $F=\bigwedge_{i=1}^m(a_i\vee b_i\vee c_i)$ be a clause-minimally UNSAT proper 3-CNF, with $L=3m$ literal occurrence positions. For each occurrence, its sign is an independently addressable input field. Flipping that field preserves a valid formula encoding with the same clause skeleton. Set
\[
H_F(x,z,y)=\bigwedge_{i=1}^m \big[(\neg x\vee a_i\vee y_i)\land(\neg y_i\vee b_i\vee c_i)\big].\tag{1}
\]
Here $x,y_1,\ldots,y_m$ are fresh and $z$ is the original variable vector. The guarded region is always SAT, by $x=0$ and $y_i=0$. Its exact boundary relation is
\[
R_F=\{x\in\{0,1\}:\exists(z,y)H_F(x,z,y)\}=\begin{cases}\{0\},&F\text{ UNSAT},\\\{0,1\},&F\text{ SAT}.\end{cases}\tag{2}
\]
Equation (2) follows by existentially eliminating each $y_i$, yielding $(\neg x\vee a_i\vee b_i\vee c_i)$, then setting $x=0$ or $x=1$.

\begin{theorem}[Two-phase sign-probe barrier, including source-referencing descriptors]
Fix any deterministic, uniformly correct two-phase system $(C,Q)$ for the exact membership query $1\in R_F$. Compiler $C$ receives the encoded source $F$ and may emit \emph{any} representation $D$, including a source pointer, symbolic formula, shared DAG, short answer, caches, or an arbitrary program. The query algorithm $Q$ receives $D$ and may reread the original source. Both algorithms and all intermediate state are charged. On every clause-minimally UNSAT $F$ as above, the set of original occurrence-sign coordinates inspected in \emph{either} phase equals the entire set of $L$ sign coordinates:
\[
\boxed{\left|\mathcal R_C(F)\cup\mathcal R_Q(C(F),F,1)\right|=L.}\tag{3}
\]
Consequently, $P_C+P_Q\ge L$ for single-bit sign probes, or $P_C+P_Q\ge\lceil L/w\rceil$ for probes returning at most $w$ sign bits each. In particular, if the exact query has no source access, the compiler must inspect every occurrence sign field on $F$.
\end{theorem}
\begin{proof}
Clause-minimality gives, for each original clause $C_i$, an assignment $a^{(i)}$ satisfying every clause except $C_i$. That assignment falsifies all three literals of $C_i$. Flipping the sign at \emph{any one} occurrence of $C_i$ therefore gives a SAT formula $F^e$, with witness $a^{(i)}$. Equation (2) says that the required membership output is false on $F$ and true on every $F^e$. Suppose position $e$ is never inspected during the combined actual run on $F$. Because changing this one input field leaves all other input fields fixed, every deterministic step, every resulting descriptor bit, every adaptive query and every final output on $F^e$ is then identical to its counterpart on $F$. This contradicts exact membership correctness. Thus every position is inspected. A machine access revealing $w$ sign bits can cover at most $w$ positions. Original-variable identifier, grammar, index-head and output operations are additional nonnegative costs.\qed
\end{proof}

\noindent\textbf{Quantifier caveat.} The theorem is \emph{instancewise} on minimally UNSAT sources, but requires a solver correct on every valid source, including every SAT sign neighbor. It is a \emph{linear probe} bound, not a claim that the interface requires $\Omega(L)$ descriptor bits or that any later query must pay $\Omega(L)$ independently of compilation. It is not $\Omega(N)$ if $N=\Theta(L\log n)$; the input encoding and machine word width must be stated. An algorithm may solve during compilation, then answer with one bit. Equivalently, a delayed solver may return the raw source reference and do all the work during membership.

\begin{proposition}[Tight phase allocation in the fixed-skeleton source-probe model]
For every $p\in\{0,\ldots,L\}$, a \emph{concrete} total two-stage exact algorithm for a fixed public clause-variable skeleton can acquire exactly $p$ occurrence signs at compilation and acquire each of the other $L-p$ signs at query. Compilation caches the first $p$ bits. The query streams all remaining signs as required while performing exhaustive exact assignment evaluation; it uses no uncharged semantic oracle. On minimally UNSAT inputs, the union in (3) is exactly $L$.
\end{proposition}
\begin{proof}
The implementation is in \texttt{audit339.py}. With a read-only literal-support list, $C$ reads and caches the first $p$ signed-coordinate fields. The query enumerates all $2^n$ original assignments and checks every clause by fetching cached or live signs. The run is complete for all sign patterns of the support list; if a SAT assignment exists, it returns SAT, otherwise UNSAT. Equation (2) proves exact membership. Thus the two-stage sign-access split is realizable. The pre-existing unsigned skeleton and its metadata have to be parsed and moved on an actual machine, and any such operations are \emph{charged separately}, not declared free in a FLMV simulation.\qed
\end{proof}

\section{Exact resource ledger and a second, materialization obstruction}
Let $N=|\operatorname{enc}(F)|$, $M=|\operatorname{enc}(H_F)|$. The direct proper-3-CNF guard has $n+m+1$ variables and $2m$ clauses. Under the explicit fixed-width literal-ID encoding for proper 3-CNF with polynomially related $m,n$, $M=\Theta(N)$ (the finite audit counts only literal identifier records, with headers/delimiters separately charged). If a machine first writes the \emph{whole} guarded formula on a counted writable child-input tape, even if it later frees that buffer before any guest call,
\[
\boxed{S_{\mathrm{peak}}\ge M=\Theta(N),\quad \rho\ge1.}\tag{4}
\]
The exact statement is about \emph{that materialized-input implementation}; an on-demand bit-accessor representation can avoid storing $M$ but must charge each source/index access and all additional time. Furthermore $M=\Theta(N)$ does not provide any $N^{1/2}$ child shortening, even with a virtual accessor.

A general two-stage source-aware implementation must partition \emph{actual native work} as
\[
T=T_{\rm parse}+T_{\rm order/selection}+T_{\rm acquisition}
+T_{\rm conversion}+T_{\rm inference}+T_{\rm query}
+T_{\rm output/verification}+T_{\rm failed/replay/guest}.
\]
Peak writable/index-tape usage is \emph{the maximum over every instant of every phase} of the simultaneous live ancestor, parse/index, cache, child description, local workspace and guest workspace. On the indexed machine used by FLMV, input is read-only; index-tape contents and movement are paid, the index tape is erased upon the random-access jump, and the write-only output tape is not counted as work space. A materialized input stored on a counted work tape is different from a write-only output stream; turning the latter into a random-access child input requires a separate charged simulation.

For an iterable algorithm transformation with at most $N^{a+o(1)}$ sequential child calls of length $N^{\lambda+o(1)}$, aggregate local time $N^{r+o(1)}$, paid per-guest-step accessor overhead $N^{g+o(1)}$, local peak exponent $\rho$ over \emph{all} phases, retained parent $\eta$ and guest space $N^{\lambda s+o(1)}$, explicitly materialized children yield
\[
t'\le\max\{r,a+g+\lambda t\},\qquad
\boxed{s'\le\max\{\rho,\eta,\lambda,\lambda s\}}.\tag{5}
\]
This is a \textbf{sufficient upper-bound contract}, not an observed performance bound or a lower-bound theorem for arbitrary deciders. For virtual children, the explicit $\lambda$ workspace buffer may be absent, but the accessor's own all-phase peak belongs in $\rho$ and each access belongs in $g$. The correction $\rho$ is compulsory: a temporary $N$-bit preprocessing buffer violates the square-root-space hypothesis.

At baseline $(a,\lambda,r,\rho,\eta,g)=(3/5,1/2,11/10,1/2,1/2,0)$, repeated transformation would formally converge to $t_*=6/5$, $s_*=1/2$. By the \emph{known} FLMV Corollary 5.8 and its quasi-linear/logspace SAT transfer, $d<\beta(c)=\tfrac12((c+2)/c^2-c)$ is a forbidden simultaneous envelope with strict slack; $\beta(6/5)=23/45$ and the gap is $1/90$. An actual uniform, assumption-independent recursive decomposition with this contract would already contradict that theorem. No such implementation is constructed here. A conditional arbitrary-decider $A\mapsto\Phi(A)$ needs an explicit, noncircular use of the assumed solver rather than only its answers to smaller instances.
