## Theorem 463.A: exact incremental high-zero filter (PROVED/RESTRICTED)

Fix one guest *work* index tape, initial blank, its sequential head visiting at most T+1 tape positions during T native transitions. Let D>=1 be a **fixed allowed-address bit budget**; all indexed **work** moves in the trace under consideration must have target strictly below 2^D. The guest may visit and overwrite zero/blank index cells arbitrarily far above D without a work-space penalty.

Maintain (i) a D-bit low address register `low`, (ii) `high` = the exact number of numeric 1 bits in index positions i>=D, and (iii) a binary head-position counter for the guest index tape. When the guest writes at index position i, read the old symbol before overwriting, and update either low[i] or high by the signed change old->new. When the associated guest work-index jump occurs, its address is **exactly low** if and only if high=0. If high>0, that jump necessarily targets >=2^D and is incompatible with the declared guest work-space bound. Because the native jump erases the index-tape contents, set low=0 and high=0 as part of the instrumented transition.

**Proof:** Induct on guest index-tape transitions. Every position <D contributes its weight 2^i to low, every position >=D contributes one count when its bit is 1, and the sum of nonnegative high contributions is zero exactly when there are no high ones. Thus the integer address equals low when high=0; otherwise it is at least 2^D. Erasure sends both invariants to zero; the index head location is independently maintained. This proof includes high **zero** bits and arbitrarily long high-index head travel; no scan is needed to decide the target.

The summary has **additional charged workspace** O(D+log(T+2)) bits and can be maintained in O(T(D+log(T+2))) native transitions using a constant number of auxiliary work/index tapes and ordinary indexed access to the D-cell register/counters. This charges symbol reads, low-cell lookup, binary counter maintenance, resets of the D-bit summary on each work jump, and fixed-machine instruction overhead. The original guest's own native index tape and work high-water still count according to FLMV. For a *known fixed* polynomial guest space bound S_A(B)<2^D with D=O(log B), and T_A(B)<=B^t, this particular work-index filter costs T_A(B)*polylog B time and polylog B extra space. **This is not the full guest interpreter or an all-input wrapper:** D cannot be silently chosen from an unknown exponent s, other guest work-head positions/tapes, virtual SAT source reads and output/state restoration remain unimplemented.

## Theorem 463.B: precisely bounded naive rescan failure (PROVED/RESTRICTED under head-preserving erasure)

Use the concrete sequential-index semantics in the executed host checker, in which indexed work jumps erase index **contents** but do not relocate the index **head**. First move the index head from 0 to L, write numeric 0 there, then repeat q times: write 0 at index position L and execute a native work-index jump. Every work jump is to address 0, so the non-index work high-water remains at its starting position; the guest uses exactly T=L+1+2q primitive head/write/jump steps in the model.

A proposed emulator which literal-scans positions 0 through the historical index-head high-water L to decode each indexed address performs exactly q(L+1) probes. With q=L, this is Theta(T^2) decoder work on a constant-workspace trace, **not** O(T polylog T). The incremental summary of Theorem 463.A keeps low=high=0 and avoids the scans. This refutes **that specific repeated-full-scan decoder**, not arbitrary guest simulators or the project-wide FLMV recurrence.

**Head-position caveat:** FLMV Section 2.1 explicitly says index *contents* are erased but does not separately spell out index-head relocation in the cited paragraph. Therefore the q repeated jumps at fixed high index head constitute a native-model lower-control only if erasure preserves head position. If an alternate permissible machine convention resets the head, the quadratic witness is confined to the declared host-model semantics. Theorem 463.A's invariant and the peer LSPV-2/464 O(T) full index-sweep upper control do not depend on this illustrative quadratic native interpretation.
