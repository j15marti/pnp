\section{PROPOSE: falsifiable mechanisms fixed before searching}
The immediate missing lemma is not merely ``a small relational child exists.'' It is that a \emph{physical} child can be generated and authenticated with simultaneous peak-work and source-head costs that remain polynomial on every recursive level. We tested four falsifiable propositions.
\begin{description}
\item[]\textbf{H1, store-stream.} Materializing source-matrix metadata once enables a sequential verifier and child builder in near-linear multitape time, at $O(N)$ writable space. \textbf{RESTRICTED PROVED} for the declared canonical grammar.
\item[]\textbf{H2, compact replay.} Retaining only the child block products, but re-reading source metadata for each syntactic matrix block, reduces writable space to $O(N^{1/4}\log N)$ without free source indexing. \textbf{RESTRICTED PROVED}, with a deliberately conservative $O(N^2\polylog N)$ time bound.
\item[]\textbf{H3, uncharged canonical re-entry.} The specified explicit-matrix canonical reentry can preserve an unbounded matrix sequence in $O(1)$ physical bytes, without evaluating the decision. \textbf{FALSIFIED for this architecture}: each retained matrix requires its authenticated 64-hex-character record and may induce 1536 proper ternary clauses. This is not an output-size lower bound for arbitrary deciders.
\item[]\textbf{H4, unrestricted closure.} The same performance establishes a power-short, one-child compiler for arbitrary 3SAT. \textbf{OPEN}: no polynomially bounded acquisition of bounded interfaces for arbitrary SAT is established, and neither exact-(2,2) cyclic scopes nor arbitrary constant-width matrix chains contain a proved NP-complete SAT class.
\end{description}

\section{BUILD: complete physical canonical chain and child size}
Let $M_1,\ldots,M_m\in\{0,1\}^{16\times16}$ be arbitrary constant-size Boolean relations with initial and final 16-bit masks $I,F$. The decision condition is
\[
\exists s_0,\ldots,s_m\in\{0,\ldots,15\}:\quad I[s_0]\wedge \bigwedge_{j=1}^m M_j[s_{j-1},s_j]\wedge F[s_m].
\]
Encode the matrices in fixed 64-hex-character records, authenticating masks and matrix count. For every disallowed $4$-bit start/end state, issue a width-four clause; for every disallowed pair of consecutive four-bit states, issue a width-eight clause. Translate width $w\in\{4,8\}$ to $w-2$ proper ternary clauses using $w-3$ fresh auxiliaries. The complete canonical input explicitly contains \emph{both} source metadata and the resulting signed DIMACS clauses; a checker must regenerate the latter and compare every byte. Numeric names and physical metadata are not free.

\begin{lemma}[Endpoint/auxiliary counts]
For $m$ relations, the canonical formula requires at most
\[
 n_{\mathrm{vars}}=1284m+36,\qquad n_{\mathrm{clauses}}=1536m+64.
\]
Its physical length $N$ satisfies $\Omega(m)\le N\le O(m\log(m+2))$ in the fixed, unpadded ASCII grammar. The upper bounds include the authenticating metadata, numeric literal fields, spaces, delimiters, and headers.
\end{lemma}
\begin{proof}
There are $4(m+1)$ state variables. At most $256m$ forbidden transitions cost five auxiliaries and six clauses each. At most 32 disallowed endpoint states cost one auxiliary and two clauses each. Hence $4(m+1)+5(256m)+32=1284m+36$, and $6(256m)+2(32)=1536m+64$. Explicit 64-digit hexadecimal relation records force $N=\Omega(m)$. All names are at most $1284m+36$, using $O(\log(m+2))$ decimal digits. Every ternary clause has constant arity and the metadata uses $O(m)$ bytes, establishing the upper bound.
\end{proof}

Define $k=\max(1,\lfloor m^{1/4}\rfloor)$ and $L=\lceil m/k\rceil$. Partition the $m$ relations into consecutive blocks of length at most $L$, Boolean-multiply the matrices within each block, and produce exactly one authenticated canonical child. Boolean associativity preserves both SAT and UNSAT.
\begin{theorem}[Physical power-short re-entry on the restricted relation-chain grammar]
There exists a constant $C$ such that for every canonical relation-chain source of bit length $N$ the unique child has at most $k$ matrices and length
\[
 N'\le C k\log(k+2)\le O(N^{1/4}\log(N+2)).
\]
For a fixed threshold $N_0$, $N'\le N^{3/4}$ for $N\ge N_0$. The canonical chain grammar is closed under this contraction. Small sources can be decided by the direct constant-width relation product without SAT advice.
\end{theorem}
\begin{proof}
The number of blocks is $\lceil m/L\rceil\le k$. Every product is again a 16-state Boolean relation, and the original endpoint masks are retained. Every newly emitted relation has the same canonical properly ternary byte encoding. Apply the preceding size lemma with $m'=\lceil m/L\rceil$ and $m\le cN$. The quotient $N'/N^{3/4}$ tends to zero for unbounded $N$, so one fixed threshold suffices. Child recognition and subsequent multiplication use the same grammar and program.
\end{proof}

\section{Two native construction ledgers and the one-tape simulations}
Use a read-only sequential input head and three fixed sequential writable work tapes. The length-aware source header is checked against actual physical length; malformed indices do not induce unbounded counter storage. Every original byte is authenticated, and no oracle lookup is supplied for free.

\begin{theorem}[Store-stream versus replay-space implementation]
For the canonical matrix-chain class just defined, the same fixed decision-preserving child map has two explicit, uniform implementations:
\begin{align*}
\textbf{store-stream: }& T_{k}(N)=O(N\log^2(N+2)), & S_{k}(N)&=O(N);\\
\textbf{compact-replay: }& T_{k}(N)=O(N^2\log^2(N+2)), & S_{k}(N)&=O(N^{1/4}\log(N+2)).
\end{align*}
Here $k\ge3$ is the fixed number of work tapes, not the contraction block count above. In the compact implementation source-head movements are $O(N^2)$ and are included in time; the stored-child body and all address counters are included in peak space.
\end{theorem}
\begin{proof}
\emph{Store-stream.} Copy each authenticated 256-bit source relation once to a sequential work tape, verify the physical DIMACS body against the expected clauses while advancing through those saved relations in order, and compute block products sequentially. Numeric names and counters use $O(\log N)$ bits, and each printed/parsed number costs at most $O(\log^2 N)$ finite-tape operations by conventional binary/decimal conversion. Constant-width Boolean multiplication uses a fixed number of bit operations. A separate work tape holds the unique child, so peak work is $O(N+N')=O(N)$. Source reads and generated-output writes are fully charged.

\emph{Compact replay.} During the first metadata scan retain only the $k$ completed block-product matrices, a current 256-bit matrix and $O(\log N)$ counters. To authenticate the following DIMACS body, on demand move the \emph{single} read-only input head back to the metadata region, sequentially count to the appropriate matrix record, retrieve its fixed-width data, then return to the current body clause. For each source matrix this incurs at most $O(N)$ head moves. There are $m=O(N)$ matrices, and each yields at most 1536 ternary source clauses; the expected clause literals and all auxiliary indices are generated on the fly using $O(\log N)$ counters. Thus total travel $O(mN)=O(N^2)$, with safe conversion overhead $O(N^2\log^2 N)$. Keep the child products until the entire source has been validated, then physically emit the complete child on a work tape. Its $O(k\log(k+2))$ bits, products and counters fit $O(N^{1/4}\log N)$. There is no source-row offset table, free second input head or free output buffer.
\end{proof}

A two-fully-writable-tape machine can implement the corresponding 2-OFF construction while leaving its input tape unchanged; this is an upper construction only, with no transfer of a 2-RW lower bound. The two-work-tape-column upper bounds follow by deliberately sweeping a single work tape containing the fixed number of virtual work tapes at an $O(S_k+\log T_k)$ cost per simulated transition; they are \emph{conservative upper bounds}, not lower bounds. The one-read/write-tape rows independently apply
\[
 T_1=O\!\bigl(T_k(N+S_k+\log(T_k+2))\bigr),\qquad P_1=O(N+S_k+\log(T_k+2)).
\]
Do \emph{not} substitute the faster Hennie--Stearns two-tape overhead for the single-tape overhead, or infer any reverse lower-bound transfer. Space is counted simultaneously. At each recursive call the previous full child is retained until its successor has been authenticated; its size is charged, and old child buffers can be released afterward. Since $N_{i+1}\le N_i^{3/4}$ beyond a fixed threshold, total elapsed work is bounded by the root-scale polynomial, depth $O(\log\log N)$, and the peak work is bounded by the first implementation's respective root-scale ceiling. All these costs are \emph{upper} bounds for this restricted family.

\section{Exact scientific limits and handoff}
The class of authenticated constant-width relation chains is recognizably tractable. Indeed, one may instead calculate its SAT answer directly and output a fixed YES or NO base formula; therefore the physical canonical-reentry size is only an architecture-specific cost, never an unconditional output floor. Its contraction illustrates that a complete, self-contained power-short ordinary-3CNF reentry can coexist with source authentication and low-space replay, but provides \emph{no} unrestricted SAT compression. The independently audited $n\le3b+12bq$ theorem excludes only a fixed syntactic boundary architecture; it does not preclude moving interfaces or compact semantic summaries. A general constructive breakthrough would need a uniform polynomial-cost, all-input source-interface discovery and a closed one-child $N^\lambda$ ordinary-SAT compiler. A separation proof would need to exclude all uniform algorithms, not only the high-work explicit-table architecture. Fixed $P=NP$ hypothetical runtime exponent $K$ remains unknown. RAM-indexed SAT lower bounds require native hypotheses and strict margins, not sequential input-head transport penalties. Both $P=NP$ and $P\ne NP$ remain OPEN.
