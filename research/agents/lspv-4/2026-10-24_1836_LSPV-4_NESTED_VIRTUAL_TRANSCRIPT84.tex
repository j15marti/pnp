\section{Growing, fixed-length, opposite-label parents}
Fix \(d\ge16\), let \(M=8d\), and use six Boolean variables \(x_1,x_2,x_3,y_1,y_2,y_3\). For \(r\in\{0,\ldots,7\}\), let \(C_r\) be the proper ternary clause on \(x_1,x_2,x_3\) whose negation pattern is the three-bit binary representation of \(r\); every \(C_r\) excludes exactly one \(x\)-assignment. Let \(B=(y_1\vee y_2\vee y_3)\). At each distinguished position \(p_r=rd\), the UNSAT parent \(U_d\) stores \(C_r\); the SAT parent \(V_d\) stores \(C_r\) except that at \(p_7\) it stores \(C_0\). All other \(M-8\) clause positions in both ordered parents store the repeated filler \(B\). Clause duplication is permitted in the language. Every record is a proper three-literal clause with identical record-width metadata in both parents.

\begin{lemma}[Opposite labels]\label{lem:parents}
\[
\#\operatorname{SAT}(U_d)=0,\qquad \#\operatorname{SAT}(V_d)=7.
\]
\end{lemma}
\begin{proof}
All eight distinct \(C_r\) eliminate every \(x\)-assignment. Duplicating \(C_0\) instead of \(C_7\) leaves exactly one \(x\)-assignment. The independent repeated filler \(B\) has exactly seven satisfying \(y\)-assignments, giving the identity.
\end{proof}
Use fixed-width signed-literal words of
\[
w(n,m)=\lceil\log_2(64(n+m+1))\rceil
\]
bits. Two header words store \(n,m\), and each clause has one width-three tag and three signed-literal fields \(2|v|+[\text{negative}]\). Thus for both parents
\[
N=(4M+2)w(6,M)=\Theta(d\log d).
\]
Every ordinary leaf uses a \emph{new} header with its actual clause count and its own word width \(w(6,K)\). Its six-variable universe is preserved even if some variables do not occur in the leaf.

\section{Two nested exact ordinary-child interfaces}
Take odd \(3\le K_1<d\) with \(\gcd(K_1,M)=1\) and \(2\le K_2<K_1\). The first-level index map is
\[
s_1(j_1,u)=(j_1K_1+u)\bmod M,\quad 0\le u<K_1.
\]
A second-level selection of positions \((j_2K_2+i)\bmod K_1\), \(0\le i<K_2\), has exact source index
\[
\boxed{s_2(j_1,j_2,i)=
\left(j_1K_1+\big((j_2K_2+i)\bmod K_1\big)\right)\bmod M.}
\]
Both levels preserve ordinary clause bytes and exact encoding, not mere handles posing as ordinary SAT formulas.

\begin{theorem}[Two-level random-bit service]\label{thm:bits}
There is one uniform deterministic controller that, given a source read-only fixed-record parent, selectors \(K_1,K_2,j_1,j_2\), and a requested canonical second-level child bit position \(b\), returns that exact bit using \(O(\log^2 N)\) elementary bit operations and \(O(\log N)\) live writable bits, including address arithmetic, indexed source reads and header regeneration. It never stores an intermediate child, a selector array or a complete leaf. Any fixed depth \(r\) permits \(\operatorname{polylog}(N)\) work per bit and \(O(r\log N)\) workspace.
\end{theorem}
\begin{proof}
Divide the requested bit position by the child's width \(w(6,K_2)\) to determine header versus the four fields of clause \(i\). On a clause field calculate \(s_2(j_1,j_2,i)\) using binary additions, products and remainders on \(O(\log N)\)-bit registers. Read that field from the original source, convert its literal code to the correct child width and return the bit. Fixed-number long arithmetic, addressing and source reads take \(O(\log^2N)\) elementary bit work, \(O(\log N)\) writable bits. For fixed further depth, compose the analogous index maps with a fixed-length stack and count every operation. This is a \emph{bit-service} theorem, not a SAT-decision contraction.
\end{proof}

\paragraph{Conditional, not achieved, recurrence.}
Suppose a \emph{separate correct parent gluing theorem} makes at most \(N^{a+o(1)}\) first children, each having at most \(L_1^{a+o(1)}\) second children, \(L_1=N^{\lambda+o(1)}\), \(L_2=N^{\lambda^2+o(1)}\). If a supplied exact SAT machine has joint pair \((t,s)\), a faithful virtual source-tape simulation would have the candidate ledger
\[
t_2\le\max\{r_0,\ a(1+\lambda)+\lambda^2t\},\qquad
s_2\le\max\{p_0,\ \lambda^2s\},
\]
with \(r_0,p_0\) containing \emph{all} grammar discovery, parent reconstruction, failed calls, source access, caches, live ancestors, policy selection, addressing and headers. For \(a=3/5,\lambda=1/2\), the solver term would be \(9/10+t/4\). Because semantic gluing is false for the schedule below, \emph{no successor pair in \(E\) is established}.

\section{Complete adaptive SAT and \(\#\)SAT transcript collision}
\begin{lemma}[Every short window matches]\label{lem:window}
Every cyclic contiguous source window of length \(1\le W<d\) has the same exact six-variable model count in \(U_d\) and \(V_d\). For \(W\ge2\) the count is \(49\) if the window contains a distinguished position and \(56\) otherwise; for \(W=1\) the count is \(56\) regardless.
\end{lemma}
\begin{proof}
Distinguished positions are separated by \(d\), hence a shorter window has at most one. With a distinguished clause and at least one filler, there are \(7\cdot7=49\) assignments. Without one, the \(x\)'s are free and there are \(8\cdot7=56\). A single distinguished clause without a filler gives \(7\cdot8=56\). The sign pattern is irrelevant.
\end{proof}
\begin{theorem}[Adaptive oracle indistinguishability]\label{thm:adaptive}
Every allowed two-level leaf is SAT and has matching exact model count under \(U_d,V_d\) at the same indices. Further, \emph{every deterministic adaptive protocol} that can query the SAT label or exact model count of \emph{any} cyclic contiguous source window of length \(<d\), including any nested windows, but cannot read parent or returned child literals or witnesses, receives identical complete transcripts on \(U_d\) and \(V_d\). No such protocol can decide both parents correctly.
\end{theorem}
\begin{proof}
Every nested leaf is contained in a first-level window with \(K_1<d\), so has at most one distinguished position. Lemma~\ref{lem:window} gives the matched responses and positive counts. At step zero, identical public metadata leads to an identical query and response. If histories agree through step \(j\), a deterministic state-dependent rule chooses the same next query and receives the same response. Inductively the entire adaptive transcript and output coincide while the true parent labels are opposite by Lemma~\ref{lem:parents}. The restriction on source and child-bit reads is essential and is charged in any stronger model.
\end{proof}
\begin{proposition}[Exact content orbit at depth two]\label{prop:orbit}
Across all \(j_1\in\{0,\ldots,M-1\}\), \(j_2\in\{0,\ldots,K_1-1\}\), the number of distinct ordinary second-level child bitstrings is exactly
\[
D_U=1+8K_2,\qquad D_V=1+7K_2.
\]
\end{proposition}
\begin{proof}
Each leaf has either all fillers or one core clause at one of \(K_2\) positions. That gives the respective upper bounds. As \(\gcd(K_1,M)=1\), \(j_1K_1\bmod M\) visits all source starts. Taking \(j_2=0\) realizes every core type at every leaf position and the all-filler leaf, giving the matching lower bound. Different types/positions yield different serialized child literal fields.
\end{proof}

\section{Adaptive-state, bit-work and peak-space ledger}
\begin{description}
\item[] \textbf{State \(S_0\):} Read-only source; obtain \(N\), \(M\), word width by charged header reads. No true label is supplied. Select virtual arithmetic or optional eager buffer through a paid policy decision.
\item[] \textbf{State \(S_1\):} Query requested child bits via source-index arithmetic. Count every input/index/workspace read, unchanged write, changed-value flip, arithmetic step, failed query, leaf header, cache update and live ancestor. Count-only answers alone never resolve the pair, even after arbitrary adaptive switching of query indices.
\item[] \textbf{State \(S_2\):} A different, source-aware rule scans all canonical clauses, checks positions and signs, maintains an eight-pattern mask, and decides UNSAT iff all patterns appear. The grammar discovery takes \(O(N)\) bit work, \(O(\log N)\) live writable bits; malformed/off-family inputs go to an exact general-SAT fallback with no favorable universal time claim.
\end{description}
For one virtual requested bit, elementary work is \(O(\log^2N)\), peak writable space \(O(\log N)\), cumulative bit-time at most \(O(\log^3N)\) under a coarse maximum-live-bits bound. Actual bit flips are a separate activity channel and not a compulsory lower bound; unchanged-value writes, addressing and source access still cost work. A materialized second-level child would have \(L_2=(4K_2+2)w(6,K_2)\) writable bits when held, but the exact virtual service does not demand this storage. Source grammar recognition can outperform all leaf queries. A fixed menu of tested policies does not cover all deciders.
