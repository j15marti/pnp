\section{Target, previous results, and falsifiable proposals}

$(t,s)$ in the deterministic random-access Turing-machine model of
Fortnow, Lipton, van Melkebeek and Viglas (FLMV).

or a finite cofinal route to an independently established forbidden endpoint.
Three falsifiable claims were tested.
\textbf{M1:} a width-three event stream can have its global source-name

\textbf{M3:} an all-input near-linear small-space normalizer into

\section{Declared model and fixed-width stream representation}
A closed named-scoped proper-3CNF stream contains events
$\mathrm{OPEN}(v)$, $\mathrm{CLAUSE}(\ell_1,\ell_2,\ell_3)$, and
$\mathrm{CLOSE}(v)$. Each positive variable identifier is opened
\emph{once globally}, is live at each occurrence in a proper ternary
clause, and is eventually closed. Clause literals have three distinct
absolute identifiers. The maximal simultaneously live set size is $w$.
A \emph{one-pass} validator reads events in order with no rewind,
random reread or auxiliary oracle; its entire mutable configuration,
including control and registers, has at most $B$ bits.
This is narrower than the FLMV random-access model.

For $n$ declared variables, $m$ clause events, and $L$ events total,
set $h=\lceil\log_2(64(n+m+1))\rceil$.
A header consists of $(n,m)$ in $h$-bit fields.
Every event consists of four $h$-bit fields: a tag and three payload
fields (unused fields are zero), with signed literals coded by
$2|v|+[v<0]$. The encoded bit length is
\[
N_{\rm scope}=(2+4L)h.
\]
Different names and signs have equal-length records and headers.
Global identifiers may be opened in arbitrary order; the validity
condition requires that they are distinct. For the lower-bound family,
every valid stream opens exactly the identifiers $[n]$.

\section{A width-three one-pass validation lower bound}
For even $q\ge2$, put $k=q/2$, let primary names be $[q]$,
and reserve private names $a_j=q+2j-1$, $b_j=q+2j$, $1\le j\le q$.
At position $j$ define the seven-event block
\[
B_j(i):\quad
\mathrm{OPEN}(i),\mathrm{OPEN}(a_j),\mathrm{OPEN}(b_j),
\mathrm{CLAUSE}(i,a_j,b_j),
\mathrm{CLOSE}(b_j),\mathrm{CLOSE}(a_j),\mathrm{CLOSE}(i).
\]
For $S\subset[q]$, $|S|=k$, concatenate the blocks bearing
members of $S$ in sorted order at positions $1,\dots,k$,
then blocks bearing members of $[q]\setminus S$ in sorted order at
positions $k+1,\dots,q$. Call the result $E_S$.
Every $E_S$ is a valid closed stream with $n=3q$, $m=q$, $L=7q$,
$w=3$ and
\[
N_q=(2+28q)\left\lceil\log_2(64(4q+1))\right\rceil.
\]
Its underlying ordinary CNF has $q$ variable-disjoint positive proper
clauses and exactly $7^q$ satisfying assignments.

\begin{theorem}[One-pass global-freshness lower bound; PROVED/EXACT]
Every deterministic one-pass exact recognizer of the named-scope
validity predicate on these fixed-length streams needs at least
\[
\boxed{
B\ge\left\lceil\log_2\binom{q}{q/2}\right\rceil
\ge q-\log_2(q+1)
}
\]
bits of complete configuration at the midpoint.
Thus $B=\Omega(q)=\Omega(N_q/\log N_q)$ even though
the live width is constantly three.
\end{theorem}
\begin{proof}
For each $k$-subset $S$, consider the prefix $P_S$ of its first
$k$ blocks. Suppose distinct $S,S'$ led to the same complete
configuration at this common input position. Append the single
suffix $Q_S$ comprising the blocks for $[q]\setminus S$ at positions
$k+1,\dots,q$. The stream $P_SQ_S$ opens every primary name once and is
valid. But $P_{S'}Q_S$ duplicates each primary name in
$S'\setminus S$ and omits each name in $S\setminus S'$, while preserving
the same event count, bit length and maximum local live width.
It is invalid. From equal configurations and an identical suffix a
deterministic one-pass validator must answer identically, a
contradiction. Therefore all $\binom qk$ prefix configurations differ.
Since $\binom q{q/2}\ge2^q/(q+1)$, the numerical bound follows.
\end{proof}

The proof is a standard exact streaming distinguishability argument,
not a new communication-complexity paradigm. It concerns
\emph{validation}, not deciding the underlying SAT formula:
every valid member $E_S$ is trivially SAT.

\section{Reopening can reverse the ordinary SAT answer}
For a literal $L$ on primary identifier $v$ and distinct fresh
auxiliaries $a,b$, write
\[
\operatorname{PIN}(L;a,b)=
\bigwedge_{\epsilon,\delta\in\{-1,+1\}}
(L\vee a^\epsilon\vee b^\delta).
\]
It is equivalent to the unit literal $L$ after existentially
eliminating $a,b$. Emit each gadget as the closed event block:
open $v,a,b$, emit its four proper clauses, close $b,a,v$.

\begin{theorem}[Invalid-reopening semantic counterexample; PROVED/EXACT]
The valid stream
\[
E_{\rm good}=\operatorname{PIN}(x;a,b)
\ \Vert\ \operatorname{PIN}(\neg y;c,d)
\]
and the invalid-reopening stream
\[
E_{\rm bad}=\operatorname{PIN}(x;a,b)
\ \Vert\ \operatorname{PIN}(\neg x;c,d)
\]
have equal record length, eight proper ternary clauses, declared
$n=6$ names, 20 events, $w=3$ under local open/close counting,
and fixed encoded size $N_{\rm scope}=820$ bits.
The ordinary formula obtained by forgetting event tags has
$16$ models for $E_{\rm good}$ and $0$ for $E_{\rm bad}$.
A naïve frontier DP which forgets $x$ at its CLOSE and treats the later
OPEN($x$) as a fresh independent variable reports $16$ models for
\emph{both} streams, therefore reports the wrong SAT label on
$E_{\rm bad}$.
\end{theorem}
\begin{proof}
The first gadget forces $x=1$; the second forces respectively
$y=0$ or $x=0$. The four auxiliaries are free exactly when the pins
hold. Thus the good ordinary CNF has $2^4$ assignments and the bad
ordinary CNF has none. The local DP existentially projects the first
$x$ when closing it; a later reopening creates an independent
scope-local choice and loses the global equality of the two copies.
Both local gadgets are satisfiable, yielding $2^4$ local combinations.
The two signed-literal records differ only in variable fields, so
the declared fixed-width encoding preserves length.
\end{proof}
The example is a counterexample only to an \emph{unvalidated}
event-stream algorithm. A correct SAT algorithm seeing the original
ordinary CNF may identify the contradiction immediately, with
charged work. There is no all-decider lower bound here.

\section{Charged direct DP for a genuinely valid scoped stream}
For a promised valid stream with $L$ events and maximal live width $w$,
maintain a truth table indexed by current assignments to the ordered
live names. An OPEN doubles states, a CLAUSE filters states, and a
CLOSE existentially OR-projects its name. Every live table contains at
most $2^w$ bits; the name-to-slot map costs $O(w\log(N+2))$ bits.
Using two buffers and explicitly charged lookup/control/addressing,
\[
\boxed{
T_{\rm DP}=O(L\,2^w\operatorname{polylog}(N+2)),\qquad
S_{\rm DP}=O(2^w+w\log(N+2)+\log(N+2)).
}
\]
This is an exact decision algorithm on the \emph{promised valid}
source class, with SAT witness existentially represented and UNSAT
detected by an empty final table. It need not reconstruct witnesses
or compile all contexts. If $L\le N^{O(1)}$ and $w=o(\log N)$ then
the table costs $N^{o(1)}$ space and processing costs
$L\,N^{o(1)}$ time.

The validity promise is load-bearing. The earlier theorem forbids
a one-pass $o(q)$-bit \emph{validator} of arbitrary width-three streams
in this model, but a random-access checker can reread source data.
For example, repeated scans comparing every OPEN identifier
and verifying corresponding CLOSE positions yield an exact
$O(L^2\operatorname{polylog}(N+2))$-time,
$O(\log(N+2))$-space checker for the declared fixed-width grammar.
This observation blocks promotion of the one-pass result to the
unrestricted FLMV machine model.

\section{The forbidden universal low-width normalizer regime}
Let
\[
c_0=\frac{241}{200},\qquad
d_0=\frac12\left(\frac{c_0+2}{c_0^2}-c_0\right)
=\frac{11642479}{23232400}>\frac12.
\]
FLMV Corollary 5.8 plus its SAT-to-NTIME transfer (Theorem 3.1)
forbids one fixed deterministic exact all-input SAT decider
with simultaneous $T=N^{c_0-\epsilon}$ and
$S=O(N^{d_0-\epsilon})$ for some fixed positive slack $\epsilon$,
in the matched random-access Turing-machine model.

\begin{theorem}[Normalizer firewall; KNOWN-THEOREM consequence]
There is no fixed uniform all-input exact truth-preserving
\emph{streaming} normalizer $C$ in that matched model with all the
following simultaneous bounds on every ordinary proper-3CNF of bit
length $N$: (i) time $N^{\rho+o(1)}$, (ii) writable space
$N^{\sigma+o(1)}$, (iii) a \emph{valid closed} ordered named-scoped
stream of at most $N^{\lambda+o(1)}$ encoded bits, with
$w=o(\log N)$, such that
\[
\boxed{\max\{\rho,\lambda\}<c_0,\qquad \sigma<d_0.}
\]
The emitted event stream may be piped online to a decoder but must
preserve the original SAT bit exactly. No nonuniform advice or
unaccounted source channel is allowed.
\end{theorem}
\begin{proof}
Assume $C$ exists. Simulate it on the original read-only input in
the FLMV machine, feeding each completely generated event (one
$O(\log N)$-bit buffer) directly into the frontier-DP above.
The normalizer's output tape is not secretly used as readable free
workspace. The composed fixed uniform machine retains the source
index tapes, compiler workspace, two DP tables, name map, controller
and buffers; every input read, bit write, unchanged write, selection,
event generation and state transition is charged. The stated model
permits constant-program multitape composition with polylogarithmic
overhead. Consequently
\[
T(N)\le N^{\max\{\rho,\lambda\}+o(1)},\qquad
S(N)\le N^{\max\{\sigma,0\}+o(1)}.
\]
Since $w=o(\log N)$ and both displayed inequalities have strict
positive exponent margins relative to $(c_0,d_0)$, the resulting
\emph{one machine} decides SAT on every ordinary input inside the
FLMV forbidden box. Contradiction.
\end{proof}

This forbids one explicitly declared favorable \emph{normalizer}
architecture, not every possible existential ARC edge. Neither an
algorithm-specific source compiler nor a universally fixed parameter
formula is logically required for a different existential closure
proof. Relativization, nonuniform wrappers and cryptographic hashes
do not repair the contradicted premises.

\section{Adaptive state, BIT-RESOURCE1 and both-label controls}
At state $S_0$ the policy has the read-only event grammar, current
input address, live-name list, resource budget and no label oracle.
It may choose global validation, a trusted valid-stream DP,
literal propagation, SCC, Horn, affine/XOR, decomposition,
cached reuse, or a generic exact SAT fallback. Global validation
acquires/checks past names, not merely the current live set.
After each OPEN, CLAUSE or CLOSE the parameter vector changes:
live width, name-map size, feasible-table size, conflict flags,
remaining events and cached source evidence. A false attempt to
treat a reused name as fresh produces the explicit wrong UNSAT
answer above. Correctness conditions differ on SAT and UNSAT:
one source-consistent witness suffices on SAT; an empty exact
frontier suffices on UNSAT valid streams.

Charge the vector
$(U,R_{\rm src},R_{\rm work},W_{\rm work},
\Delta_{\rm full},S_{\rm peak},\sum_\tau S_{\rm live}(\tau),
|\text{program/representation}|)$.
Here $U$ includes unchanged-value writes, indices, control and
failed strategies; $\Delta_{\rm full}$ counts actual state flips,
not source-query or table-write counts. The Python audit records
abstract DP row updates and table occupancy, \emph{not} FLMV
machine steps, temporal flips, or cumulative bit-time.

\textbf{COMPUTATIONAL controls:} an independent standard-library
auditor tested every ordered pair of midpoint subsets for even
$q\in\{2,4,6,8\}$: all matching prefixes/suffixes pass global
validation, all mismatched ones fail despite local width three,

opposite-pin controls have identical 820-bit encodings and give

invalid local DP. Additional signed-eight UNSAT, signed-seven SAT,

The full local script completed \textbf{313,853}
assertion-accounted checks with zero discrepancies. These finite
checks do not prove any new asymptotic SAT lower bound.
