\section{A fully charged, model-relative cover lemma}
Fix a language $L\subseteq\{0,1\}^*$ and one ordinary deterministic machine
model with a read-only original input. Let $N=|x|+2$. The following are
hypotheses about actual uniform implementations, not semantic existence alone.

A fixed generator $G$ produces a finite sequence $J(x)$ of at most $M(N)$
parameter strings, each of length at most $b(N)$. Its total generation work is
at most $g(N)$ and its retained iterator workspace at most $w(N)$. Delays,
source scans, program construction and writes are included. Parameters may
depend on $x$ but are not advice. Generation finishes even if no trial succeeds.

One fixed bounded runner $R(x,p)$ returns a value in $\{0,1,?\}$ in at most
$t(N)$ native steps and uses at most $s(N)$ native workspace, uniformly for
all generated parameters and inputs. Its parameters are retained separately
and charged below. $R$ includes initialization, any simulated program and its
code, source access, clock/cap enforcement, and verification. In a capped
simulation, a cap exit returns $?$; it never fabricates a decision.

Assume soundness:
\[
 R(x,p)\in\{0,1\}\quad\Longrightarrow\quad R(x,p)=1_L(x).
                                                               \tag{1}
\]
No algorithm for recognizing arbitrary correct programs is assumed. Condition
(1) must follow from the construction or an explicitly charged verification
method. A short unsupported NO bit is not a certificate.

All runner work tapes can be reset in $O(s(N))$ steps, with $O(\log N)$
bookkeeping for polynomial bounds. For example, a fixed number of tapes with
known bounded ranges can be cleared sequentially. The same ranges are reused,
so even a largest-position-ever-accessed space convention does not accumulate
one arena per trial. Generator state stays on separate charged tapes.
Parameters and runner state are not archived by the decision controller.

\begin{theorem}[Pointwise sequential cover]\label{thm:cover}
There is one deterministic uniform partial decider $U$ which returns the first
bit produced by a trial, and returns $?$ if all trials return $?$.
It obeys
\begin{align}
 T_U(N)&=O\!\left(g(N)+M(N)[t(N)+s(N)+b(N)+\log(N+M(N)+2)]\right), \tag{2}\\
 S_U(N)&=O\!\left(w(N)+s(N)+b(N)+\log(N+M(N)+2)\right).           \tag{3}
\end{align}
If
\[
 \forall x\quad\exists p\in J(x):R(x,p)\ne ?,                 \tag{4}
\]
then $U$ is a total exact decider for $L$. No fixed $p$ need satisfy (4) for
all inputs, or even for all sufficiently long inputs.
\end{theorem}
\begin{proof}
Run $G$ and consume its outputs in sequence. Retain its iterator while running
one trial with a separate reusable workspace. On $?$ clear the trial ranges
and continue; on a bit, return it. Condition (1) proves soundness of every
returned bit; (4) proves that some trial returns. All parameter generation,
$M$ trial invocations, $M$ resets, parameter transfers and iteration counters
are included in (2). There is only one live trial arena, so space adds only
the iterator, current parameter, current runner and controller counters as in
(3), rather than summing over trials. These steps are a single fixed machine
construction. No oracle chooses the successful parameter.
\end{proof}

The theorem does not supply a universal simulator with these costs for an
arbitrary program collection. A proposed interpreter must establish the
uniform $t,s$ contract separately. Measuring unguarded candidate time and
then treating generation, cap testing or reset as free would violate the
premises. A positive bit-operation overhead can erase a narrow endpoint gap.
Hutter's general universal-algorithm result likewise uses proved correctness
and runtime information rather than trusting arbitrary programs \cite{hutter}.

\begin{corollary}[Exponent ledger]\label{cor:exponents}
Suppose, uniformly over the entire admitted family,
\[
 M\le N^{\lambda+o(1)},\quad g\le N^{\gamma+o(1)},\quad
 t\le N^{\tau+o(1)},\quad s\le N^{\sigma+o(1)},\quad
 w\le N^{\omega+o(1)},\quad b\le N^{\beta+o(1)}.
\]
For polynomial bounds, (2)--(3) give
\[
 T_U\le N^{\max\{\gamma,\lambda+\tau,\lambda+\sigma,
                         \lambda+\beta\}+o(1)},\qquad
 S_U\le N^{\max\{\omega,\sigma,\beta\}+o(1)}.             \tag{5}
\]
The logarithmic controller term is absorbed whenever the displayed exponents
are nonnegative, with the usual subpolynomial convention at exponent zero.
\end{corollary}
In the common case $b=O(\log N)$ and $s\le t$, the time exponent is
$\max\{\gamma,\lambda+\tau\}$. Enumerating all descriptions through length
$\ell(N)$ has at most $2^{\ell(N)+1}-1$ trials. Thus
$\ell=o(\log N)$ gives a subpolynomial number of trials, but the generation
and runner costs still require proof. Small parameter descriptions do not
make large generated code or advice tables free.

The $o(1)$ terms must be uniform in the moving parameter. Bounds with separate
constants or thresholds for each fixed $p$ cannot simply be evaluated at
$p=p(x)$. No time bound from one trial is paired with another trial's space.


\paragraph{Unknown winning time can also be accommodated.}
Suppose the same runner has a native, uniformly charged time-budget interface:
a call with budget $T$ costs $O(T+s+b+\log(N+T))$, retains the same space cap,
and returns every valid answer whose underlying capped run finishes by $T$.
Restart the whole generated list at budgets $1,2,4,\ldots$, resetting every
trial. If some admissible trial finishes in time $t_x$, then the first useful
budget is less than $2(t_x+1)$ and the sum of budgets is less than
$4(t_x+1)$. Including repeated generation and clearing gives
\[
 O\!\left(M(t_x+1)+
 [g+M(s+b+\log(N+t_x+2))]\log(t_x+2)\right).             \tag{8}
\]
There is still only one live trial. When $t_x$ is uniformly polynomial, these
logarithmic factors preserve (5)'s exponents. This extension assumes the
stated native budget interface; it does not infer it from an unmetered
interpreter. The fixed good index and winning runtime are both unnecessary
when quantitative pointwise coverage and the charging contract are proved.

\section{A strict example: no fixed favorable total member}
Consider parity of nonempty binary strings. For each integer $j\ge0$, define
one total correct program $B_j$ as follows. Determine input length $n$.
If $2^j\le n<2^{j+1}$, compute parity by a scan. Otherwise deliberately
execute at least $2^n$ steps, then compute parity. The family has a uniform
finite description; each fixed $B_j$ eventually takes exponential time.

Generate $j=0,\ldots,\lfloor\log_2 n\rfloor$. Use the sound bounded runner
that checks the band's condition, returns $?$ outside it and computes parity
inside it. It is a permitted correctness-preserving partial version, not a
claim to execute the long off-band delay quickly. Every input is covered by
$j(x)=\lfloor\log_2 n\rfloor$, there are $O(\log n)$ candidates, and all
scans and binary counters use $n\,\log^{O(1)}(n+2)$ time and $O(\log n)$ space.
Hence a uniform fast combined decider exists although no fixed original
$B_j$ is asymptotically fast. This is a strict counterexample to fixed-member
necessity in general, not to the hypothesis of the older restart theorem.

The finite test does not run exponential delays. The unbounded delay behavior
of the complete $B_j$ family is a separate mathematical definition and proof.
By contrast, a member storing all SAT answers through length $n$ needs
$2^{n+1}-1$ answer bits before interpretation overhead. A short index naming
that table cannot satisfy a cheap generator/runner contract merely because
looking up an answer is fast after the table is provided.

\section{What this gives at an unconditional endpoint}
FLMV prove that for every fixed $C<(1+\sqrt5)/2$, some $D>0$ satisfies
\[
 \mathrm{SAT}\notin\mathrm{DTISP}[N^C,N^D]               \tag{6}
\]
in their deterministic random-access model \cite{flmv}. Their section 2.1
and input conventions were read directly. No stronger product theorem is used.

\begin{corollary}[Common input escaping a bounded portfolio]\label{cor:failure}
Fix a generator and sound runner for native SAT in that exact model. If the
time exponent in (5) is strictly below $C$ and its space exponent strictly
below $D$, then for every $N_0$ there is an input $x$ with $|x|\ge N_0$ such that
\[
                   \forall p\in J(x):R(x,p)=?.         \tag{7}
\]
\end{corollary}
\begin{proof}
If (7) failed, the partial decider in Theorem 1 would be correct and complete
on every sufficiently long input. The finitely many shorter strings could
be hardwired with their correct answers in one finite program. This would
produce a total exact decider in (6)'s forbidden class, since strict exponent
margins absorb all constant and subpolynomial losses. Contradiction.
\end{proof}
This is a genuine common-input portfolio obstruction derived from an existing
joint-resource lower bound. Its inputs can be YES or NO; it does not supply
a satisfiable common-input UWI instance. It applies only to the declared
uniformly generated, sound, capped trials. It does not cover arbitrary
polynomial workspace or arbitrary polynomial exponents.

For one fixed assumed polynomial decider $A$, a contradiction route could
now attempt an explicitly charged pointwise cover $J_A(x)$ rather than demand
one fixed parameter that works on all inputs. To use (6), the actual runner
must decide native SAT, or a proved resource-preserving adapter must be
charged. Mere NP-completeness of signed or monotone exact-$(2,2)$ inputs does
not preserve a particular fine-grained exponent pair automatically. A direct
non-P proof for either fixed language needs no such adapter unless this
particular endpoint route is used.

This replaces an unnecessarily strong coverage requirement with a weaker
constructive one. It does not produce the cover. No known step makes an
arbitrary $N^k$ decider yield the exponents required in (5). In particular,
$N^\lambda$ trials of an $N^k$ decider give $N^{k+\lambda}$, not a speedup.

\section{The recovered vacuity warning}
Fix a certified endpoint. The claim that every polynomial SAT decider yields
an exact algorithm inside that forbidden endpoint implies SAT is not in P.
Conversely, if SAT is not in P, its quantifier over polynomial SAT deciders
has no members, so such a claim is vacuously true. This is precisely the
PROOF-SYNTHESIS-0008 warning \cite{syn8}.

The same warning applies to a final cover-existence assertion strong enough
to contradict (6). The controller lemma is a nonvacuous intermediate theorem;
the source-specific all-input covering premise remains separation-strength.
A proof must derive it from explicit local correctness, transformation and
resource statements, not treat it as a minor selector detail.
