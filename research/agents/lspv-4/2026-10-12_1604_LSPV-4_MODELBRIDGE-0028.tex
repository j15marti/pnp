\begin{abstract}
P versus NP remains \OPEN.  This run tests a minimal repair after full traces,
fixed field masks, and typed declassification failed: retain the complete
control/address schedule of the same deciding execution and its final SAT bit,
but no data values.  The repair is false even within the satisfiable slice.
Every time-$p(N)$ deterministic machine has an extensionally equivalent
uniform fixed-sweep implementation whose instruction/address schedule depends
only on $N$, with $O(p(N)^2)$ time and $O(p(N))$ work bits.  Two equal-length
satisfiable duplicate-free signed monotone $3$SAT-$(2,2)$ instances are
exhibited for which one fixed partial assignment has opposite residual
compatibility.  The retained views therefore coincide while compatibility
differs.  This is \claim{SCHEDULE-DECISION-COMPATIBILITY-COLLISION1},
\EXACT{} in the declared model.  Pippenger--Fischer already gave the sharper
oblivious-simulation theorem, and RT-0010 already used it against
decide-then-emit; those results are adopted, not renamed.  The new increment is
the same-YES-slice compatibility collision and its composition with the current
source-leakage/declassification trilemma.  A 1,200-check bounded audit passed.
No runtime lower bound, universal semantic projection, or model-matched
contradiction follows.
\end{abstract}

\section{Claim card: exact quantifiers, encoding and costs}
Let $A$ be a fixed total uniform deterministic multitape machine, let
$p(N)\ge N$ be a known time-constructible bound, and let $x$ be a
self-delimiting encoded CNF of length $N$.  For any machine $M$, define
$\Sigma_M(x)$ to be the ordered sequence of clock values, program locations,
operation names and work-tape addresses in one exact-clock run, explicitly
excluding every read/write data value and the read-only input contents.  Let
$b_M(x)$ be its one-bit decision.  The attacked proposal is
\[
 \forall A\in\mathsf{Dec}_{P}(\mathsf{SAT})\ \exists E_A\ \forall(F,\alpha):
 E_A\bigl(\Sigma_A(F),b_A(F),\alpha\bigr)
 =h(F,\alpha),                                           \tag{1}
\]
where
\[
 h(F,\alpha)=\mathbf 1\bigl[\exists\beta\succeq\alpha:
                         \beta\models F\bigr]             \tag{2}
\]
is pointwise residual compatibility.  Extraction, schedule serialization,
source reads, simulation and reconstruction are all charged.  Equation (1)
is refuted because its universal machine quantifier includes an equivalent
fixed-sweep implementation.

\paragraph{SAME\_REALIZATION.}
The countermodel uses one execution of the fixed-sweep machine $B$.  Both
$\Sigma_B(F)$ and $b_B(F)$ are projected from that execution.  No cost or
state from $A$ is assigned to $B$, and no resource value from one input is
assigned to another.  The equal-view pair is used only to prove that no
deterministic decoder of that view can equal (2) on both inputs.

\section{Primary-literature and barrier-transfer preflight}
The first obstacle is normalization: data-independent access does not imply
semantic ignorance.  Pippenger and Fischer prove that a $T$-step
one-dimensional-tape computation has an online oblivious two-tape simulation
in $O(T\log T)$ time, with head positions independent of input contents
\cite{PF79}.  This is a \textbf{directly transferable theorem} in their model
and was already correctly used by RT-0010.  The present proof uses a slower
elementary fixed-sweep simulator so that operation names as well as addresses
are fixed without importing an unstated RAM conversion.

The second obstacle is landing: even if a projection were forced, no theorem
transfers its size to a lower bound for arbitrary computation.  Fortnow,
Lipton, van Melkebeek and Viglas prove genuine SAT time--space lower bounds in
their stated random-access model \cite{FLMV05}.  This is directly usable only
after the same realization is placed in that model and forbidden simultaneous
resource region; it supplies no all-decider trace compiler.

Constant-time programming, oblivious RAM, VLSI routing and control-theoretic
observability are \textbf{useful structural analogies requiring a new transfer
theorem}.  They impose interfaces, leakage functions or physical costs that
an arbitrary SAT program need not preserve.  Treating data-independent
addresses as if all data values were independent is a \textbf{misleading
analogy / failed transfer}.  Baker--Gill--Solovay and
Aaronson--Wigderson remain barrier controls \cite{BGS75,AW09}; the theorem
below relativizes and algebrizes and therefore provides no escape.

\section{Exact fixed-sweep collision theorem}
\begin{theorem}[\claim{SCHEDULE-DECISION-COMPATIBILITY-COLLISION1}]
Let $A$ be a total deterministic multitape machine running in time $p(N)$.
There is a uniform total deterministic machine $B$ such that:
\begin{enumerate}[label=(\roman*)]
\item $B(x)=A(x)$ for every $x$;
\item $B$ runs in $O(p(N)^2)$ time and $O(p(N))$ work bits;
\item for every $x,x'\in\{0,1\}^N$, $\Sigma_B(x)=\Sigma_B(x')$; and
\item if $A(x)=A(x')$ but $h(x,\alpha)\ne h(x',\alpha)$, then no decoder of
$(\Sigma_B(\cdot),b_B(\cdot),\alpha)$ computes $h$ on both inputs.
\end{enumerate}
In particular, if $A$ is polynomial time then $B$ is polynomial time.
\end{theorem}

\begin{proof}
Encode the complete bounded configuration of $A$ in $O(p(N))$ Boolean work
cells: tape symbols, one-hot head indicators, finite control and a halt/output
register.  In each of exactly $p(N)$ rounds, $B$ scans every one of these
cells in a fixed order.  A fixed straight-line Boolean transition circuit
computes all candidate local updates, and multiplexers select the update from
the old data bits; the instruction sequence and addresses do not branch on
those values.  Double buffering makes the next configuration the following
round's input.  A halted configuration maps to itself, so the clock is exact.
The nested round/cell loops cost $O(p(N)^2)$ time and the two configuration
buffers use $O(p(N))$ bits.  Thus (i)--(iii) hold.  For (iv), equal schedules
and equal decision bits give equal decoder inputs, while exactness would
require opposite outputs.  Determinism makes that impossible.
\end{proof}

Pippenger--Fischer improves the time overhead in its tape model; it is not
needed for the theorem.  The $O(p^2)$ normalization preserves polynomiality
but not a favorable fixed exponent, so it is consistent with $P=NP$ and does
not land in FLMV's forbidden region.

\section{Explicit clean-core same-YES collision}
Let $F_0,F_1$ be the following duplicate-free signed monotone formulas on six
variables (each row denotes a clause):
\begin{align*}
F_0={}&(123)(124)(356)(456)
       (\bar1\bar2\bar3)(\bar1\bar2\bar4)
       (\bar3\bar5\bar6)(\bar4\bar5\bar6),\\
F_1={}&(123)(124)(356)(456)
       (\bar1\bar2\bar4)(\bar1\bar2\bar5)
       (\bar3\bar4\bar6)(\bar3\bar5\bar6).
\end{align*}
Every variable occurs exactly twice positively and twice negatively, every
clause is proper and monotone, and no signed clause is duplicated.  Exhaustive
evaluation verifies
\[
 \mathsf{SAT}(F_0)=\mathsf{SAT}(F_1)=1,
 \qquad
 h(F_0,111\star\star\star)=0,
 \quad h(F_1,111\star\star\star)=1.                     \tag{3}
\]
The encodings are padded only to equalize byte length, not to alter semantics.
For the machine $B$ above, (3) yields
\[
 (\Sigma_B(F_0),1)=(\Sigma_B(F_1),1)
 \quad\text{but}\quad h(F_0,\alpha)\ne h(F_1,\alpha).  \tag{4}
\]
Thus adding the final decision to a data-free control view does not repair
compatibility extraction, even on two YES instances in the intended core.

\section{Relativization, algebrization, Natural Proofs and nonuniformity}
The fixed-sweep construction runs oracle gates or algebraic gates at fixed
scheduled locations while allowing their returned values to remain data.  The
collision argument therefore relativizes and algebrizes.  It is a negative
guard, not the nonrelativizing/nonalgebrizing hinge required by a separation.
No large constructive circuit property is defined, so Natural Proofs is not
the immediate theorem; any later conversion to circuit lower bounds must audit
largeness, constructivity and usefulness.  The simulator is uniform and its
polynomial bound is program-specific.  No common exponent is assumed.  A
nonuniform schedule family would only weaken the sought universal statement
and would still not determine (2) on the collision pair.
