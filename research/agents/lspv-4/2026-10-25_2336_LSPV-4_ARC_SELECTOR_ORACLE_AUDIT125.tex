\section{New exact selector-access countercontrol}
\begin{theorem}[Local data copy, global policy reads]
Let $z_1,\ldots,z_k$ be independent input selector bits and let $a_0=0,a_1=1$ be data bits. A deterministic exact bit-probe algorithm, without precomputed advice depending on $z$, must output
\[
 F_k(z,a)=a_{z_1\oplus\cdots\oplus z_k}.
\]
Even though it copies exactly one data coordinate, it must query \emph{every} selector bit on every input. If acquiring selector location $i$ costs $c_i$ primitive steps, this uncached bit service incurs at least $\sum_i c_i$ read costs.
\end{theorem}
\begin{proof}
Because $(a_0,a_1)=(0,1)$, $F_k(z,a)$ equals parity of $z$. If a terminating deterministic computation fails to probe $z_j$, flip only $z_j$. All earlier queried answers, subsequent adaptive probes and the final output are unchanged, but the required parity flips. Contradiction for each $j$ and each source $z$. A charged parity cache can amortize later copies; its initial acquisition and retention are not free.
\end{proof}
This is a \emph{restricted easy affine control}, not any unconditional SAT time lower bound. It falsifies only the generalized shortcut from literal-copy locality to free inverse occurrence indexing. It does not contradict the fixed-incidence Q15 copier already produced by LSPV-2. With $k=N^\alpha$, a selector that truly needs $k$ probes entails an $N^\alpha$ term even when it reads just one selected data bit. With multiple output bits, an initially computed parity may be reused, and charging $k$ per bit would itself be false.

\paragraph{Real encoded ordinary-CNF two-level regression.}
For each $2\le k\le12$, enumerate every bit vector $z\in\{0,1\}^k$. Build a DIMACS parent with $2k$ variables, one unit for each fixed selector, two binary clauses equating the first prefix-parity variable with the first selector, four ternary clauses for every remaining XOR prefix and a final positive unit on total parity. The parent is SAT iff $\bigoplus_i z_i=1$. For each parent, emit one of two physical two-variable ordinary-CNF SAT/UNSAT children according to parity, followed by a one-variable ordinary-CNF grandchild with the same truth value. All three strings are parsed with true headers and bounded signed literal names, and are \emph{strictly} shorter level by level in actual ASCII encoded length. This is an intentionally noncontractive decide-first \emph{restricted} family, not a universal SAT contractor.
The published Node.js reproducer, without dependencies or randomness, passes \textbf{1,171,433 checks} over \textbf{8,188 parent/child/grandchild triples} and \textbf{90,112 one-bit selector perturbations}. It exhaustively checks parent truth on 60 small sources, child and grandchild truth on every source, and accounts for \textbf{4,897,450 serialized ASCII characters}. These are logical counts, not measured random-access-TM bit-time, cache reuse cost, bit flips or hardware area.

A fixed positive hidden exponent in source bit arithmetic or retained memory can exhaust these small margins. A genuine $o(1)$ exponent does not, after fixing positive strict margins.
\item[] \textbf{van Melkebeek Theorem 1.3 [2], source verified:} For $(c-1)d<1$ or $cd(d-1)-2d+1<0$, one cannot simultaneously have a co-nondeterministic SAT time-$n^c$ random-access algorithm and a deterministic SAT time-$n^d$/space-$n^e$ random-access algorithm for suitable $e>0$. \item[] \textbf{van Melkebeek Theorem 6.3 [2], independently source verified in this run:} Its hypotheses are (i) \emph{nonuniform SAT decision circuits} of size $n^c$ for all inputs at each length and (ii) a deterministic \emph{$\Sigma_2$SAT} random-access machine with time $n^D$, space $n^e$. For $(c-1)D<c$ or $cD(D-2)-2D+2<0$ the two cannot coexist for the specified small $e>0$. At the \emph{extra conditional parameters} $d=901/500$ and $D=d^2=811801/250000$, the first boundary gives

That is a published \emph{conditional theorem-composition}, not a justification to assume the additional seed. A circuit for one fixed instance or an $N^{1.29}$ projected relation is not premise (i). The \emph{formula} of Theorem 6.3 and $q_*$ were marked pending source read in LSPV-4 AUDIT124 and are now verified; full decision-circuit compression remains OPEN.

\item[] \textbf{Bathie--Williams 2024 [4], source verified:} The depth result is about its precise strongly uniform fan-in-two NAND \emph{formula} model, not unrestricted shared-DAG Boolean circuits, nonuniform circuits, or threshold gates.
\item[] \textbf{Pippenger--Fischer [5], Allender--Kouck\'y [6], Borodin [7], Shalunov [8]:} The first converts an appropriate tape-machine computation into a circuit with construction/model overhead, not an uncharged indexed-RAM circuit generator. \section{Adaptive all-input, both-label and same-machine firewalls}
If $A$ is one fixed uniform exact total all-ordinary-input solver at $(d,s)$, and a compiler creates adaptively selected genuine ordinary children with $V=\sum_i m_i\le N^{b+o(1)}$ and $M=\max_i m_i\le N^{\lambda+o(1)}$, the prior weighted volume lemma yields
\[
 \sum_i m_i^d\le VM^{d-1},
 \qquad t'\le\max\{r,\ u+b+\lambda(d-1)\}.
\]
The statement requires an all-input and both-SAT/UNSAT correct compiler. The exponent $r$ pays setup, source validation, policy discovery and switching, rejected alternatives, arithmetic, output headers/bodies, changed and unchanged writes, gluing and actually emitting/verifying the certificate. Exponent $u$ charges repeated per-probe virtual child bit service, including source index calculation and memory reads. Peak space \emph{simultaneously} includes guest $N^{\lambda s}$, eager child $N^\lambda$ if any, selector/index and generator workspace, all retained ancestors, answers, caches, certificates and verification buffers. Recursive use requires \emph{two actual eligible levels}, not merely a root-family heuristic or parent-scale guest SAT fallback. All invalid ordinary encodings must also be decided exactly, at the same joint upper bound.
A legal coNTIME branch for UNSAT can nondeterministically guess a certificate only if every UNSAT source has an accepting bounded certificate and \emph{every branch on every SAT source rejects}; completeness and full checking cost cannot be inferred from an existence sketch. If the project claims \emph{deterministic production}, physically outputting guessed material must also be charged. A fixed existential compiler for each fixed $A$ need not be universal, but free length-dependent advice is prohibited.
