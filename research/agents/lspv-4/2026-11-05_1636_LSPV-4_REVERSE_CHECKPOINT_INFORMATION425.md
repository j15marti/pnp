## PROVED/RESTRICTED theorem
For k>=2, M>=8k+32, let f:[M]->[M] be an arbitrary total opaque successor table. Define v_0=0, v_j=f(v_(j-1)), B_j=v_j mod 2. A deterministic algorithm correct for all f that must output B_k,B_(k-1),...,B_1 online, with at most k total table-entry queries and no free source read after k queries, requires at least 2^(k-1) distinguishable complete machine configurations immediately after the first output. Thus k-1 bits of complete configuration information are needed in this restricted near-minimal-query model.

Proof: the adaptive fresh-frontier adversary makes B_k undecidable until all k frontier entries have been queried; off-frontier queries waste a necessary query. The first k-1 newly discovered vertices can independently have either parity, and the final vertex can always be chosen fresh and even. M>=8k+32 supplies enough vertices. Complete unused entries by self-loops. Across 2^(k-1) total tables, B_k is always zero while the required remaining reverse suffixes differ. No more source access is permitted, so identical full configurations would force identical suffix outputs. Pigeonhole forces 2^(k-1) states. Complete configuration includes work/index/head information; this is NOT automatically k-1 written cells under an arbitrary encoding.

## Existing repair and physical ledger
Full parity cache: k entry probes, k-1+O(log M) retained bits. Balanced binary replay (LSPV-5/208): at most k*(1+ceil(log2(k))/2) entry probes, O(log k * log M) live bits. Pure replay: k*(k+1)/2 probes, O(log M+log k) live bits. All emit k output bits. On the indexed machine each entry probe separately charges address writing/erasure, source-bit reads, index-head operations, current vertex update and possible recomputation, with O(polylog N) native work per lookup, N=Theta(M log M). Input parsing/authentication and all-phase peak are additional. Materializing the immutable source on work tapes costs Theta(N) extra peak. f(v)=v XOR 1 as known white-box code permits immediate direct B_j and defeats any universal machine-hardness extrapolation. Balanced replay can fit N^(1+o(1)) local work, so this is not an N^1.1 no-go.
