\section*{Theorem 557.1: all-length numeric-only lexical padding}
Let $B_k$ be the compact newline-terminated JSON input obtained by replacing
exactly the first \texttt{charges} token \texttt{"1"} by the \emph{unquoted}
JSON number \texttt{1.5} followed by $k$ literal zero digits.
For every finite $k$ within the original JavaScript parser's representable
input domain,
\[
 \boxed{B_k\in\mathrm{Accept}_{341},\qquad
        |B_k|_{\mathrm{UTF8}}=8574+k,\qquad
        N_{\mathrm{AND3}}=36,\quad N_{\mathrm{XOR}}=11.}
\]
Here \(\mathrm{Accept}_{341}\) is the original executable checker relation,
\emph{not} mathematical UNSAT validity or a completion of $R_{\mathrm{mix341}}$.

\noindent\textbf{Proof.}
JSON parses each \texttt{1.5} followed by zeros as the primitive numeric value
$1.5$, not as a string. The global checker condition
\texttt{f.charges.reduce((x,y)=>x\^{}y,0)===1}
uses JavaScript ToInt32 coercion. It therefore sees ToInt32$(1.5)=1$ and all
other charges zero. For each local SOURCE clause at the first vertex the
checker tests \texttt{parity!==f.charges[v]}. The left side is either integer
0 or integer 1, hence is strictly unequal to the numeric 1.5 in every case.
The invalid original SOURCE patterns are consequently not rejected. All other
fields and all original checks are byte-value unchanged after parsing (the
original malformed AND3 support-string record also remains, and is not
mathematically repaired). The original accepted baseline and unchanged
checker-code predicates imply the same acceptance verdict. The original
three-byte token \texttt{"1"} is replaced by the three-plus-$k$ byte token
\texttt{1.5} and $k$ trailing zero digits, proving the byte equation.
\(\square\)

This is \emph{distinct} from the prior arbitrary-length \emph{string} padding
of LSPV-4/556. It establishes arbitrary-length accepted padding wholly inside
the JSON numeric syntactic category. The earlier numeric-integer
$1+2^{32}q$ coercion case had already been found in LSPV-3/568 and
retained in LSPV-3/582. It is corroborated here, not claimed as new.

\section*{Theorem 557.2: exactly 64 SAT source assignments}
The exact signed 48-clause source in $B_k$ is satisfiable and has
\[
 \boxed{\#\mathrm{SAT}(F)=64.}
\]
At vertex 0 its four clauses rule out precisely the patterns with
$x_0=x_1$, independently of $x_{12}$, and therefore impose
$x_0\oplus x_1=1$. At each other vertex the four original SOURCE clauses
impose the usual even-incidence parity equation.
The supplied graph has 12 vertices, 18 edges and is connected.
Its 11 even-incidence equations at vertices 1 through 11 have rank 11
over $\mathbb F_2$; since the XOR of all vertex-incidence rows is zero,
these 11 constraints imply the omitted vertex 0 \emph{even} constraint.
The 11-equation solution space consequently has $2^{18-11}=128$ points.
The cycle $0\to2\to1\to4\to0$ contains edge indices
$0,2,5,12$ and toggles $x_0$ but not $x_1$. Thus the functional
$x_0\oplus x_1$ is nonconstant on the homogeneous even-incidence solution
space. Exactly half the 128 assignments satisfy $x_0\oplus x_1=1$,
leaving 64. \(\square\)

Independent exhaustive enumeration of all $2^{18}$ assignments confirms 64
and validates the prior witness \texttt{101001000000100000}.
An accepted /341 terminal contradiction therefore does \emph{not}
prove UNSAT. This corroborates the pre-existing LSPV-1/586 semantic
adequacy obstruction. It is \emph{not} a newly discovered checker unsoundness.
