## ITERATE: exact conditional theorem
Let G_flat be an explicit finite-alphabet, topologically ordered, source-authenticated transcript. Each of at most q fresh auxiliaries is introduced in a **separately paid** bounded-input binary DEF. Original source names never change. All wire, literal, pivot, ROW, LOCAL and RES fields are **typed** as variable coordinates or as immutable record IDs/constants; no uncharged opaque nested circuits. Every rule is equivariant under an injective fresh-variable renaming. Let M be supplied proof bits, N original source bits, u distinct original variables.

**Theorem.** There is one uniform deterministic two-way *indexed read-only-input/write-only-output* transducer that replaces the jth DEF identifier by the jth least positive integer absent from the original source variable set, consistently throughout all typed fields. Each new identifier is at most u+q. It preserves original source clauses byte-for-byte, exactly q paid nodes, all dependencies, and every original-assignment Boolean meaning. With character-by-character rescans,

$$
T_{\mathrm{rename}}(M,N)=O((M+N+2)^4),\qquad S_{\mathrm{scratch}}(M,N)=O(\log(M+N+2)).
$$

Its emitted encoding has at most O((M+N+2) log(M+N+2)) bits. Proof: find the definition rank of each referenced old aux by rescanning all DEF records, enumerate candidates through u+q and test original-name membership by rescans, retaining only O(log(M+N)) addresses/ranks and write the new token immediately. A source identifier cannot be captured. A DAG induction proves every definition's value is preserved by coordinate renaming, and name equivariance preserves every consumer-visible inference and pivot. The conservative quartic time upper bound charges every input-symbol comparison, head/index movement, failed candidate and output write.

**Critical physical qualification:** supplied M-bit proof acquisition is not free in an implemented SAT solver. If source and proof and normalized proof are *materialized on writable tapes*, peak space is at least the length of what is retained, not O(log M). The theorem's space bound is only scratch with indexed read-only evidence and external write-only output. A Python implementation buffers text, so actual host RSS does NOT measure indexed TM logspace. Rule validation, acquisition of opaque circuit content, auxiliary proof discovery, caching and downstream machine guests are not covered. In the FLMV materialized-child recurrence rho must include every phase. For arbitrary huge M this polynomial-in-M result is not a bound polynomial in N+q. It therefore does **not** complete the native source retraction or normalize arbitrary hidden payloads.
