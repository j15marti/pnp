\section{Single integrated target, model, and falsifiers}
The target is the existing uniform arbitrary total ordinary-SAT decider $A\mapsto\Phi(A)$ on the identical deterministic indexed read-only-input random-access Turing-machine model of Fortnow--Lipton--van Melkebeek--Viglas (FLMV). All source scans, policy discovery, failed policies, clause representations, output-bit access, guest/index tape steps, ancestor retention, proof verification, and peak writable space must count. No all-input $\Phi$ has been constructed. The original source clause-indexed all-TRUE $S_j$ and all-FALSE $U_j$ targets are adverse controls, not an independent proof route.

Four concrete falsifiers were tested. F1: a universal controller may maintain an arbitrary dense ternary partial assignment as stable random-access working state while claiming $N^{1/2}$ space. F2: every one of the $\binom m2$ clause-pair compatibility records must be stored independently in strict signed exact-$(2+,2-)$ 3CNF. F3: eager $S/U$ source diagnostics necessarily improve total search work versus an otherwise identical unit-propagating DPLL solver. F4: a lower bound for this dynamic assignment-query interface applies to all correct SAT deciders. F1, F2 and F3 are falsified in their stated forms; F4 is also false as a generalization, because an unrestricted SAT decider need not maintain or answer individual assignment-state queries.

\section{Restricted exact state theorem and polynomial-time FLMV transfer}
Fix a SINGLE original read-only source input $F$ naming $n$ Boolean variables. A dynamic controller processes an arbitrary internally generated history of $t$ distinct variable pins, with each pin chosen from $\{0,1\}$, then supports an exact query $\operatorname{status}(i)\in\{*,0,1\}$ for any name $i$ without retaining the history on a separate free input or receiving semantic advice. A query may reread the fixed $F$ but cannot retrieve the earlier updates from it. There are
\[
M(n,t)=\binom nt2^t
\]
possible states, and any two are distinguished by a query about one differing variable.

\begin{theorem}[Exact dynamic-state information requirement, restricted]
Every deterministic exact internal representation for this declared interface has at least $M(n,t)$ distinguishable post-update configurations. In a conventional counted binary register representation it needs at least
\[
b(n,t)=\Big\lceil\log_2\binom nt+t\Big\rceil
\]
bits. On a fixed finite-tape FLMV machine with finite alphabets, input length $N$, total elapsed time $T\le N^{O(1)}$, and counted peak space $s$, the full machine configurations have at most $2^{O(s+\log(T+2)+\log(N+2))}$ possibilities, provided that no history or assignment-dependent advice is available on any uncounted input. Thus, if $t=\Theta(n)$ and $n=\Theta(N/\log N)$, this exact interface demands $s=\Omega(n)=\Omega(N/\log N)$. It cannot occur as an obligatory persistent interface inside a machine using $O(N^d)$ counted space for any fixed $d<1$.
\end{theorem}
\begin{proof}
Each $t$-pin name subset and Boolean value tuple yields one legal state. If two distinct states had the same decoder configuration, query a name whose recorded status differs: deterministic continuation on the same fixed source and same query could not return both answers. Hence the injectivity and bit count.

For the FLMV model, each of finitely many work/index tape contents over finite alphabets has at most $2^{O(s)}$ possibilities when its occupied/visited extent is charged; internal states contribute a constant factor. Each ordinary head makes at most $T$ ordinary moves, while a random-access jump address described on an index tape of charged extent $s$ is below $2^{O(s)}$. Thus the head-coordinate and other bounded-time control positions contribute at most $2^{O(s+\log(T+2)+\log(N+2))}$ configurations. The input is fixed, output is write-only and its position also has at most $T+1$ possibilities. This upper bound must dominate $M(n,t)$. For $t=\theta n$ with fixed $0<\theta<1$, $\log_2M(n,t)=\Theta(n)$, while $\log T=O(\log N)=o(n)$, so $s=\Omega(n)$. For strict22 fixed-width source encoding $m=4n/3$ and each name uses $\Theta(\log n)$ bits, hence $N=\Theta(n\log n)$ and $s=\Omega(N/\log N)$. Since $(N/\log N)/N^d\to\infty$ for each $d<1$, the proposed low-space bound fails for this exact state interface.
\end{proof}
\noindent\textbf{Escape firewall.} No lower bound is asserted for a controller that never materializes every possible assignment state, does not require arbitrary later status queries, recomputes its state from a differently encoded history with all costs paid, recognizes an easy source family, outputs a witness sequentially, or decides SAT directly without producing a witness. The source-specific semantic quotient may have far fewer states than $M(n,t)$. This is standard information counting, not unrestricted SAT hardness or a new complexity separation.

\section{Sparse original-clause compatibility and paid access}
For strict signed exact-$(2+,2-)$ proper original 3CNF, each original variable occupies four distinct clauses. It contributes at most $\binom42=6$ unordered clause-pair overlaps, of which at most $2$ are same-polarity pairs and $4$ opposite-polarity pairs. The number of original clause pairs whose local $SS,SU,US,UU$ modes are not all feasible is therefore at most $6n$. This does NOT mean all such pairs are independent or must be stored.

The four modes are sourced from each pair's actual original signed occurrences: $SS,UU$ feasible iff no shared opposite sign; $SU,US$ feasible iff no shared same sign. For mixed same/opposite shared variables, none is feasible, and at least one clause is always in true-literal category $1$ or $2$. This does not imply formula SAT or UNSAT. A complete $4\binom m2$-bit compatibility matrix requires $\Theta(m^2)$ bits if explicitly retained, whereas an occurrence-index edge representation holds $O(n)$ exceptional records. Its own variable-to-occurrence index can occupy $\Theta(n\log n)$ writable bits, still too large for the targeted FLMV regime if naively retained. The alternative is paid on-demand source reads and address arithmetic, with potentially repeated costs. Indexed word-RAM constant probes do not automatically equal constant native FLMV steps.
