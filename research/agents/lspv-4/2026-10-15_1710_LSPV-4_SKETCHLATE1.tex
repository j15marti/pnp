\section{CONSTRUCTION OR PROOF ATTEMPT}
Fix constants d,r, m input bits X, d explicit masks w_{a,i}, and b arbitrary Boolean truth tables h_j on d+r inputs. First compute global P_a(X)=XOR_i w_{a,i}X_i; numeric addresses J_j (j=1,...,r) are logically disclosed later, with out-of-range reads zero. Each output equals h_j(P_1,...,P_d,X_{J_1},...,X_{J_r}). Optional outputs COPY all m bits. Source length L is linear in dm+b2^{d+r}. Pack g=ceil(log_2 m) bits per K=GF(2^g) symbol and extend the p=ceil(m/g) data coordinates and r address coordinates canonically to E=GF(2^{2g}), degree less than q=2^g separately in each coordinate.

For each alpha in K, delta_alpha(Z)=1+(Z+alpha)^{q-1} interpolates the grid address indicator. Trace-dual basis polynomials L_i(Z)=sum_{u<g}(e_i^*)^{2^u}Z^{2^u} interpolate bit i. Let a subset U of d+r labeled factors have parity labels A and query labels J. At pack t with valid cells I_t, define H_{a,t}(Z)=sum_{i in I_t} w_{a,i}L_{i-tg}(Z), and
\[
B_t(U;z)=\sum_{\phi:J\to I_t}\prod_{j\in J}\delta_{\alpha_{\phi(j)}}(z_{J,j})
\left[\prod_{a\in A}H_{a,t}(Z)\prod_{j\in J}L_{\phi(j)-tg}(Z)\bmod(Z^q-Z)\right]_{Z=z_{X,t}}.
\]
Query-index repetitions are ALLOWED. Compute D_0(empty)=1, remaining zero, and D_{t+1}(U)=sum_{V subset U} D_t(U setminus V)B_t(V;z).
\begin{theorem}
For fixed d,r, an ordinary deterministic multitape machine computes every canonical off-grid scalar extension of the b outputs and streams all m COPY extensions with joint time O_{d,r}((m+L+b)polylog(m+L+b)) and writable space polylog(m+L+b), including source/input scans, rewinds, field arithmetic, and output.
\end{theorem}
\begin{proof}
On the input grid each parity expands as a sum of pack contributions and each indexed read as a sum of address-equality selectors times the selected bit. Expanding their product assigns each factor to one pack and assigns queries to potentially repeated cells. The B_t polynomial precisely interpolates that pack's product after reduction modulo Z^q-Z. Independent coordinate factors multiply without loss of canonical degree. The subset recurrence enumerates all pack assignments and agrees with the source function on every grid point; uniqueness of degree-less-than-q interpolation proves exactness everywhere, including off-grid collisions. Every h_j has a constant-sized Boolean ANF in these factors, so all b outputs reuse the same 2^{d+r} final D values. A pack uses g^{O(d+r)} exact field operations, with p=O(m/g) packs; explicit copies and source reads are linear up to polylog factors. Only constant many subset states and polylogarithmically many monomial coefficients are live. Field setup is deterministic polylog at characteristic two.
\end{proof}
The grammar is not universal: X=111 and Y=100 have the same total XOR and first selected bit, but global AND differs; a legal ordinary O(m)-time program computes AND. Same-oracle gates may similarly exceed this grammar. Source semantics alone does not establish nonrelativization or nonalgebrization. At local m=N^{3/5}, each eligible evaluation is N^{3/5+o(1)} time and N^{o(1)} scratch. N^{1/2} calls cost N^{11/10+o(1)}; m calls cost N^{6/5+o(1)}. Writable materialization of m field outputs requires Omega(m log m) storage. Neither graph-level call count nor arbitrary-decider-to-source compilation has been shown.
