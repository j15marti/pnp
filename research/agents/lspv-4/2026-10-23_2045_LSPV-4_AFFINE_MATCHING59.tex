\section{Falsifiable proposals, model and prior work}
We test (A) whether disjoint affine complement pairs and only positive ternary clauses already form an NP-complete subclass, (B) whether the exact $q$-field 2-SAT base can be embedded in that class without deciding first, with a pointwise charged input-observation bound, and (C) whether growing ternary count alone forces exponential work. A and B hold in their exact models; C is false as a universal per-instance claim. We use one four-word record (arity and three signed-literal slots, zero padding for binary) per clause and two header words. With $n$ variables and $m$ clauses, $w=\lceil\log_2(64(n+m+1))\rceil$ and encoded bit length $N=(4m+2)w$. A source word read/write is charged as one word-RAM operation, as are parsing, validation, failed branches, reduction construction, output, witness reconstruction and replay. The target is all uniform deterministic total exact deciders, not an enumerator or detached oracle. Our reduction calculus comprises local complement-pair creation, signed-literal renaming, copying ternary records, and one explicitly verified four-clause forcing gadget; it contains no SAT-answer computation.

\section{Baseline exact binary chain}
For $q\ge1$, $b\in\{0,1\}^q$, let
\[
F_b=(z_0\vee u)(z_0\vee\neg u)(\neg z_q\vee v)(\neg z_q\vee\neg v)\bigwedge_{i=1}^q(\neg z_{i-1}\vee\ell_i),
\quad \ell_i=\begin{cases}z_i&b_i=1\\\neg z_i&b_i=0.\end{cases}
\]
Its counts are $n=q+3$, $m=q+4$, $N=(4q+18)w$. The endpoints force $z_0=1,z_q=0$. The all-one chain implies $z_q=1$ and is UNSAT; if $b_j=0$ is the first zero then $z_i=1$ for $i<j$ and $z_i=0$ for $i\ge j$ satisfies the chain. Thus $F_b$ is UNSAT iff $b=1^q$. An exact orientation-field query decider needs all $q$ fields on $1^q$ by a single-unread-bit flip; a linear scan/SCC solves it. This is a model-specific $\Omega(N/\log N)$ input-acquisition bound.
\section{Disjoint affine matching plus positive genuine ternaries}
For an arbitrary proper source 3-SAT $\Phi$ on $n_0$ variables and $k$ clauses, introduce pair-members $p_i,m_i$ for each source $x_i$ and the binary constraints $(p_i\vee m_i)(\neg p_i\vee\neg m_i)$, which exactly express $p_i\oplus m_i=1$. Map signed source literals by $Y(x_i)=p_i$, $Y(\neg x_i)=m_i$, and each source clause $(\ell_1\vee\ell_2\vee\ell_3)$ to the all-positive $(Y(\ell_1)\vee Y(\ell_2)\vee Y(\ell_3))$. Original clauses have three distinct source indices, so output positive ternaries use three distinct matching pairs.
\begin{theorem}[Parsimonious endpoint; PROVED/EXACT]
The output has $n=2n_0$, $m_2=2n_0$, $k=m_3$, $m=2n_0+k$, and $N=(8n_0+4k+2)w$. Every source assignment uniquely extends via $(p_i,m_i)=(x_i,1-x_i)$; this preserves every clause truth value and is an exact bijection of witnesses. The canonical matching-plus-positive-ternary language is NP-complete. Source grammar recognition, forward map, inverse decoder, witness lifting, and certificate replay use $O(n_0+k)$ word operations and linear live space.
\end{theorem}
\begin{proof}
The pair clauses permit precisely $(1,0),(0,1)$. Thus each output witness projects to unique $x_i=p_i$ and each signed literal has the same truth value before and after mapping. A canonical parser checks the ordered two-clause pair records and every positive ternary's three distinct pair indices; invalid encodings are NO. Proper 3-SAT polynomially reduces, and the restricted problem is in NP. Both separate constraint types are easy: a matching of affine XOR-one equations and positive clauses alone. With nonaffine width at most two the combined system remains 2-CNF, decidable by SCC. At unbounded positive genuine width three it is NP-complete. This is a constraint-expressiveness boundary, not a deterministic time lower bound.
\end{proof}
Padding each binary pair clause by $(a\vee b)\mapsto(a\vee b\vee y)(a\vee b\vee\neg y)$ yields proper 3-CNF with $n'=4n_0$, $m'=k+4n_0$ and $2^{2n_0}$ free extensions per source witness. These fresh $y$ variables are independent satisfying-assignment freedoms, not independent hidden computation.
\section{Local answer-blind lift of the $q$-chain}
Add three underlying variables $t,a,b$ with complement pairs, and write four all-positive ternaries
\[
\mathcal G_t=\bigwedge_{\alpha,\beta\in\{+,-\}}(Y(\neg t)\vee Y(\alpha a)\vee Y(\beta b)).
\]
If $Y(\neg t)=0$, these clauses become all four sign patterns of a binary disjunction on $a,b$, which jointly are UNSAT. Therefore they force $t=0$ and leave $a,b$ free. In this particular template each clause excludes only one of four assignments when $t=1$, so four are necessary. This does not prove global gadget minimality.
Replace each original binary clause $(\ell_1\vee\ell_2)$ by $(Y(\ell_1)\vee Y(\ell_2)\vee Y(t))$. The last literal is forced false, hence SAT iff the old clause is satisfied. Every original satisfying assignment has four extensions from $a,b$. All ternaries are genuine, positive and use distinct matching pairs. The output has
\[
\boxed{n=2q+12,\quad m_2=2q+12,\quad k=q+8,\quad m=3q+20,\quad N=(12q+82)w.}
\]
\begin{theorem}[All-decider source-word bound, not a time separation; PROVED/EXACT]
On this lifted source for $b=1^q$, every deterministic total exact decider of the full canonical NP-complete matching-positive-ternary language reads at least $q$ addressed input words. Consequently $T_A=\Omega(N/\log N)$ in the stated word-access model.
\end{theorem}
\begin{proof}
Changing a single orientation $b_i$ from one to zero changes only one encoded positive literal identifier, from $Y(z_i)$ to $Y(\neg z_i)$, in one fixed ternary record. The $q$ changed-cell locations are pairwise disjoint, while every header, record width and other word stays identical. The baseline label changes UNSAT to SAT, and the lift is equisatisfiable. Missing an entire changed-cell location would make a deterministic algorithm follow identical read transcripts on opposite labels. Thus it reads every one. A source-aware check and scan solve the family in $O(q)$ word operations. Reduction construction itself writes $\Theta(q)$ records, so transport yields no post-acquisition lower bound.
\end{proof}
\section{The semantic bipolar kernel and hostile control}
For each matching pair $i$, inspect its appearances in the positive ternary section. Let $P$ contain those pairs for which \emph{both} members appear and put $p=|P|$. For a pair appearing in only one polarity, assign that member true and discard all ternaries containing it. Absent pairs receive arbitrary values. Remaining ternaries use only $P$.
\begin{lemma}[Exact semantic pure-polarity normalization; PROVED/EXACT]
This charged scan preserves SAT iff, leaves at most $p$ underlying variables and at most $k$ ternaries, and reconstructs a source witness in $O(n_0+k)$ extra time. The resulting exact decision upper bound is $O(2^p\operatorname{poly}(N))$; $p=O(\log N)$ is polynomial.
\end{lemma}
\begin{proof}
Every deleted clause is made true by a chosen member of a one-polarity pair. Every retained clause mentions only bipolar pairs. A satisfying residual assignment and the chosen preferred values give a satisfying original assignment; a satisfying original restricts to all retained clauses.
\end{proof}
Every Boolean output variable occurs positively and negatively in the matching backbone, so an elementary syntactic pure-literal test sees none, even at $p=0$ where the semantic kernel immediately accepts. A large ternary count $k$, strong-backdoor size or residual variable count does not imply mandatory $2^k$ work. If $\tau_{\rm src}$ is the minimum hitting set of underlying source ternary supports and $h$ the syntactic strong-2CNF backdoor size of the output, then $\tau_{\rm src}\le h\le2\tau_{\rm src}$, by projecting an output hitting set and lifting each source member to both pair variables.
