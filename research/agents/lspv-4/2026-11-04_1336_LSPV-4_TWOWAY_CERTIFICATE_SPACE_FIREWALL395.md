## ITERATE: precise result 1, two-way supplied SAT model
Let F be a strictly canonical signed CNF of length N with n dense declared variables, n<=N. Put an independently supplied n-bit assignment w on a two-way immutable certificate tape, F on two-way read-only source tape. A uniform deterministic total checker parses F and w, rejects malformed strings and scans each clause. For literal with absolute index i, rewind/rescan w to w_i, compare sign and accept iff all clauses have a true literal. A fixed number of binary counters (source position, clause status, literal ID, witness index, header metadata) requires O(log M) writable bits for M=N+n. With O(M) literal occurrences and O(M) certificate head moves per lookup, a conservative O(M^3) machine-step upper bound accommodates bit-counter arithmetic. Hence some w is accepted iff F is SAT. There is no UNSAT certificate and no witness-finding procedure.
**KNOWN CLASSICAL CHARACTERIZATION:** With logspace Cook-Levin reduction, every NP language has polynomially bounded **two-way read-only certificates** checkable by a deterministic logspace verifier. The standard NL certificate formulation uses a **one-way, read-once** certificate. Accordingly low-space verification cannot be promoted to SAT in L, NP=NL, B3 or an FLMV contraction.

## ITERATE: precise result 2, strict streaming state lower bound
**PROVED/EXACT elementary lemma.** A deterministic checker that reads a k-bit prefix b once, then a k-bit suffix y once, cannot revisit b, and accepts precisely b=y, needs at least 2^k distinct work configurations after the prefix. Proof: for any b!=b', append the common y=b; the run after b must accept but after b' must reject. Thus those two prefixes cannot lead to the same state. Log2 of 2^k is k bits. A k-bit buffer meets the bound. By contrast two-way immutable tapes with repeated reads use only O(log k) writable counter bits. The strict streaming lemma specializes to k signed source units assigning each x_i=b_i and a supplied model y. The lower bound does not apply to FLMV's indexed machine model.
