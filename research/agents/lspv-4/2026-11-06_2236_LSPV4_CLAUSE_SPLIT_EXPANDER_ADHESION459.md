## Original established family, exact encoding and allowed shortcuts
Choose connected cubic edge-expander graphs $G_H=(V,E)$ with $H=|V|$, $|E|=3H/2$ and fixed expansion $|\delta_G(S)|\ge\epsilon|S|$ for every $S\subseteq V$ of size at most $H/2$. Let $x_e$ be an ORIGINAL Boolean variable for each $e\in E$, and let $\chi\in\{0,1\}^V$ have odd charge sum. For each degree-three vertex $v$ with incident edges $e_1,e_2,e_3$, include the four strict 3-clauses 
$$
C_{v,a}=\bigvee_{i=1}^3
\begin{cases}x_{e_i},&a_i=0,\\ \neg x_{e_i},&a_i=1,\end{cases}
\qquad a_1\oplus a_2\oplus a_3\ne\chi_v.
$$
These are precisely the four source clauses excluding wrong parity assignments. The source has $4H$ original clauses, $3H/2$ original variables, and $M=\Theta(H\log H)$ encoded bits with dense integer IDs. Summing all graph parity equations yields $0=1$: UNSAT is certified mathematically by GF(2). Urquhart [R1] supplies exponential ORDINARY shared-DAG Resolution refutation-size lower bounds on suitable growing expander families, NOT a bound for this mixed calculus or for arbitrary SAT algorithms. Gaussian elimination or summing charges is a polynomial-time shortcut and a mandatory upper-bound control. No reduction to arbitrary 3-SAT is needed: this is already strict 3-CNF.

## Theorem 459.A (PROVED/RESTRICTED)
Let the original $4H$ clauses be assigned in ANY way, one copy each, to nodes of a tree $T$ of maximum degree at most three. Let every tree node own at most $b\le H/4$ source clauses. For each ORIGINAL variable $x_e$, require the tree nodes carrying its source occurrences to lie in a connected subtree, allowing additional free transit/bag appearances (a RELAXATION of native adjacent-owner TREE3). Suppose every tree edge has an interface listing all original variables carried across it, of size at most $w$. Then
$$
\boxed{\quad w\ge\epsilon H/12.\quad}
$$
This lower bound remains true even if each vertex's four original clauses are split across FOUR different tree nodes, with arbitrary other original clauses mixed into each node. It is ONLY a structural bound for original-clause/source-variable-preserving tree factorizations and not for unrestricted SAT compression, auxiliary-variable rewrites, algebraic elimination or arbitrary proof DAGs.

**Proof.** For each original vertex $v$, select *any one* of its four source clauses, and call the tree node containing that clause $home(v)$. Every selected original clause contains all three original edge variables incident to $v$. A tree node can be home for at most $b$ original graph vertices since each such home requires a different source clause.

Put weight 1 at $home(v)$ for every vertex $v$. The weighted tree-centroid lemma yields a node $c$ whose deletion leaves components each holding at most $H/2$ home weights. At most $b\le H/4$ homes lie at $c$, so the other components have total weight at least $3H/4$. The tree degree is at most 3. Select one or several whole components whose total home weight lies between $H/4$ and $H/2$: if a component already lies in that interval, take it; otherwise all components weigh less than $H/4$, so greedy union crosses $H/4$ before reaching $H/2$.

Let $S\subseteq V(G)$ consist of original vertices whose home lies in selected components. Then $H/4\le|S|\le H/2$, so $|\delta_G(S)|\ge\epsilon H/4$. For each crossing graph edge $e=uv$, its variable $x_e$ occurs in the selected home clause for $u$ and the unselected home clause for $v$. By connectedness of source-variable support across the tree, the path between these two homes carries $x_e$, crossing at least one tree edge incident to centroid $c$ on the selected side. Since at most three tree edges touch $c$, and each carries at most $w$ original variables, $|\delta_G(S)|\le3w$. Combining inequalities yields $w\ge\epsilon H/12$. QED.

**Encoded size consequence.** If source blocks each have at most $M^{1/2+o(1)}$ explicit encoded bits, their clause count satisfies $b=o(H)$, hence $b\le H/4$ for sufficiently large $H$. Consequently $w=\Omega(H)=\Omega(M/\log M)$, incompatible with the promised $w=O(\log M)$ for LSPV-2/459 and /461. Packet preservation is NOT necessary for this contradiction. Running-intersection/source-variable preservation and a bounded-degree tree ARE necessary.
