\section{Target, pre-source falsifiers, and original-machine guard}
Define \(E\) as the upward-closed set of \emph{joint} pairs \((t,s)\)
achieved by one fixed, uniform, deterministic, total and exact
ordinary-SAT machine \(A\), correct on \emph{every} ordinary \(N\)-bit input,
with \(T_A(N)\le N^{t+o(1)}\), writable/index
\(S_A(N)\le N^{s+o(1)}\) on FLMV's indexed read-only-input
random-access Turing machine. Under \(P=NP\), some finite
\((K,K)\in E\).
The same machine would have to meet
\[
t<c_\star=\frac{241}{200},\qquad
s<d_\star=\frac{11642479}{23232400}=\beta(c_\star),\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right)
\]
to enter the chosen strict forbidden box. The proposed successor
\((t,s)\mapsto(\max\{11/10,3/5+t/2\},\max\{1/2,s/2\})\)
and every necessary all-input semantic edge are \OPEN.
The previously advertised universal
\(t+s<2\cos(\pi/7)\) endpoint remains \textbf{FALSIFIED/RETIRED}.

Before consulting FLMV/Williams original primary references, this
run fixed four falsifiable resource proposals:
\begin{description}

\item[] \textbf{H3 (two-level falsifier).} Compare every row and

\section{Exact ordinary encoding and two genuinely shorter levels}
Let \(m\ge3\), \(p=m^2\), \(q=m\), \(v=3p\). A packet has
exactly \(p\) ordered ternary clauses, each with three \emph{distinct}
literal-variable identifiers drawn from \([v]\). Repeated clauses
are permitted; this is ordinary 3CNF, not a claim of membership in a
duplicate-free special grammar. There are \(q^2=p\) packets
\(P_{ij}\) for \(0\le i,j<q\), with disjoint original
variable-name ranges, relabeled on input as
\(1+v(iq+j),\ldots,v(iq+j+1)\). Set
\[
 F=\bigwedge_{i=0}^{q-1}\bigwedge_{j=0}^{q-1}P_{ij},
 \quad H_i=\bigwedge_{j=0}^{q-1}P_{ij},
 \quad G_{ij}=P_{ij}.
\tag{1}
\]
For \(H_i\) relabel to the row-local \([qv]\);
for \(G_{ij}\) relabel to the packet-local \([v]\).
The source has \(p^2\) clauses and \(3p^2\) declared variables;
a row has \(pq=p^{3/2}\) clauses and \(3pq\) variables;
a leaf has \(p\) clauses and \(3p\) variables.

Use one concrete injective self-delimiting binary format,
\[
 {\rm Enc}(V,\mathcal C)
  =10011010\, U(V)\,U(|\mathcal C|)
   \prod_{C\in\mathcal C}\prod_{\ell\in C}
   \bigl[{\rm sign}(\ell)\,{\rm bin}_{w}(|\ell|)\bigr],
 \quad
 w=\lceil\log_2(V+1)\rceil,
\tag{2}
\]
where \(U(z)=1^{|\operatorname{bin}(z)|}0\operatorname{bin}(z)\),
\({\rm sign}(\ell)=1\) for negative literals, and each ordered clause
has three different identifiers. The fixed prefix and the two unary
length fields must be parsed and written; there is no zero-cost header.
The number of encoded bits is exactly
\[
 L(V,M)=8+|U(V)|+|U(M)|+3M(1+w).
\tag{3}
\]
Thus, with \(N=L(3p^2,p^2)\),
\[
N=\Theta(p^2\log p),\qquad
L_1=L(3pq,pq)=N^{3/4+o(1)},\qquad
L_2=L(3p,p)=N^{1/2+o(1)}.
\tag{4}
\]
No virtual descriptor is passed to the guest. Its declared
input bits are exactly those of \({\rm Enc}\) in (2).

\begin{theorem}[Exact scope and both-label heredity]
On the explicitly recognized grid-packet promise
\(\mathcal P=\bigcup_{m\ge3}\mathcal P_m\), all source, row and
leaf clauses in (1) are legitimate ordinary 3CNF instances, and
\[
 \SAT(F)=\bigwedge_i\SAT(H_i)
 =\bigwedge_{i,j}\SAT(G_{ij}).
\tag{5}
\]
Both Boolean values and both real levels occur within \(\mathcal P\)
and its row/packet descendants. The identities hold for
\emph{every} packet content obeying the declared local-variable
grammar, not only the finite experiment patterns.
\end{theorem}
\begin{proof}
Each packet uses a separate set of original variable identifiers;
after renaming, a row contains pairwise disjoint packets, and
distinct rows are disjoint. Independent CNF conjunctions are
satisfiable exactly when all components are satisfiable.
Consistent bijective renaming preserves both satisfiability and
unsatisfiability. The above finite lists are actual serialized
ordinary SAT children. The second-level factory reads an actual
eligible row, using its construction-known boundary and packet
partition, so no unproved hereditary property of \emph{arbitrary}
SAT inputs is invoked.
\end{proof}

\section{Source-indexed bit service and counted single-machine route}
For row \(i\), a local field at clause index
\(h\in[0,pq)\) maps to source clause
\(ipq+h\); its variable ID is the source ID minus \(iqv\).
For leaf \((i,j)\), clause \(h\in[0,p)\) maps
to source clause \((iq+j)p+h\); its local
ID is the source ID minus \((iq+j)v\). Both maps use
\(O(\log N)\)-bit indices. Every request for a sign or name bit
reads the indicated source field at its real position, reconstructs
and checks the full source name, subtracts the declared base,
and then emits the requested bit. A request for a length/header bit
computes the corresponding exact field of (2). Each field requires
at most \(O(\log N)\) source-indexed bit reads,
\(O(\log^cN)\) bit operations for some fixed \(c\),
and \(O(\log^c N)\) live writable/index workspace. A
\emph{nested} grandchild read can instead interrogate the row
accessor, with at most \(O(\log^2N)\) underlying source probes
and \(O(\log^cN)\) total bit operations. Neither route stores
a whole row, leaf, label table, or read-write copy of \(F\).

A uniform, deterministic grammar verifier can parse (2), check
\(q=m\), \(p=m^2\), declared \(V,M\), all packet-local source
identifiers, three distinct literals per clause and exact total
length with \(O(N\operatorname{polylog}N)\) elementary
bit work and \(O(\operatorname{polylog}N)\) live
writable/index bits. The verifier checks the promise, not SAT.
If it fails, this \emph{promise decider} may reject the input
without being a correct ordinary-SAT decider. A total
all-input SAT extension would need a correct fallback.

\begin{theorem}[Restricted locally addressable single-realization route]
Fix one uniform total exact ordinary-SAT decider \(A\) with
joint all-input bounds
\(T_A(L)\le L^{t+o(1)}\) and
\(S_A(L)\le L^{s+o(1)}\) on the indexed,
read-only-input FLMV model. There exists one fixed uniform
deterministic \emph{promise} decider \(B_A\), correct on every
grid-packet source \(F\in\mathcal P\), whose actual time
and simultaneously live writable/index space satisfy
\[
 \boxed{
 T_{B_A}(N)\le
 N^{\max\{1,\frac12+\frac12t\}+o(1)},\qquad
 S_{B_A}(N)\le
 N^{s/2+o(1)}+N^{o(1)}.}
\tag{6}
\]
Every \(A\) call receives the exact ordinary packet string,
with its input probes implemented by the charged addressable
accessor. Two correct semantic reduction levels in (5) are
available and checked; source reconstruction is not presumed
free.
\end{theorem}
\begin{proof}
The fixed \(B_A\) first validates the packet grid, performs
\(q^2=p=N^{1/2+o(1)}\) depth-first leaf decisions,
combines their exact SAT bits using one running AND bit,
and may short-circuit on the first UNSAT leaf. In the worst
case all leaves are visited. Since each has size
\(L_2=N^{1/2+o(1)}\), the sum of fully simulated guest
steps, source probes, work/index tape reads and writes
(including unchanged writes), arithmetic and control steps is
\(p\,L_2^{t+o(1)}\operatorname{polylog}N
=N^{1/2+t/2+o(1)}\).
The initial verification and name/address work contribute
\(N^{1+o(1)}\). Program-description size depends on the
\emph{fixed} \(A\), not on \(N\). Nested row accesses
have polylogarithmic access overhead and do not change
these exponents. At any instant \(B_A\) retains only its
counters, verifier/generator/index state and one simulated
guest state of size \(L_2^{s+o(1)}\);
its input is virtual on the fixed indexed read-only source,
not a readable output tape. A one-way output bit is written
only after gluing the final result, and is not reused as
writable memory. The guest is reset/discarded between leaf
calls. The peak bound holds for \emph{one realization} at
all times; it does not combine time and space from different
algorithms.
\end{proof}

The incurred work counts each source and workspace read;
each index-tape write, including values unchanged from a
previous step; arithmetic over actual finite addresses;
SAT-call setup/reset; header reconstruction; name
renaming; validation; branch and output steps. Failed
routes or policy selection would be additional charged
operations, though the fixed grammar here has no
unexplained discovery policy. No free SAT bit, RAM
word operation, ancestor buffer or cache hit is assumed.
This accounting distinguishes simulated bit steps from
input-field logical probes, transitions that change a
stored bit, cumulative live bit-time, and physical
switch/transistor counts. The latter two are
\emph{not} bounded or measured by the finite reproducer.

\section{Numerical frontier and the decisive FLMV-hardness firewall}
Equation (6) has the mathematical conditional consequence that
an \emph{assumed} joint all-input \(A\) at \((t,s)=(7/5,4/5)\)
yields a \emph{promise-only} \(B_A\) at \((6/5,2/5)\).
That pair satisfies
\[
 6/5<241/200,\qquad 2/5<11642479/23232400,
\tag{7}
\]
but \emph{does not belong to \(E\) by this construction}:
it decides only disjoint grid products, not arbitrary SAT.
This is not a contradiction with FLMV. It would be
invalid to transfer the strict forbidden box to a product
promise that has no proved locally-indexed FLMV-hard
embedding. The earlier illustrative seed \((6/5,1/2)\)
already lies in the FLMV forbidden box, so it is
\emph{not} used as an actually achievable seed in (7).

For a general ordinary input \(F\) with a non-grid
cross-packet clause, the root may be SAT even though
an arbitrary guessed partition creates UNSAT children,
or vice versa. Validation prevents applying (5) off
the promise but does not solve that input. Calling
\(A(F)\) as a fallback costs \(N^{t+o(1)}\) time and
\(N^{s+o(1)}\) space on the parent, destroying
joint contraction. A source-dependent shortcut that
recognizes this easy family need not work for an
FLMV-hard image. A low-width or product normalizer
\emph{unconditionally} covering FLMV-hard SAT
at strict forbidden resources would already conflict
with FLMV, consistent with Role 2's SCOPE-TOLL160.
An \(A\)-dependent such compiler is the \OPEN{}
and fully charged missing mathematical arrow.
The four eager/lazy depth combinations of
MIXED-EAGER-FRONTIER116 and the nested virtual
access tax of NESTED-ACCESS-TAX113 remain valid;
(6) is their low-\(g\) special case \emph{on an easy
explicit promise}, not a general repair.
