\section{A decoder, not a unique original source}
\begin{theorem}[Exact balanced-source retraction]\label{thm:decode}
There is a total deterministic polynomial-time procedure $D$ such that
\[
 D(y)=\bot\iff y\notin\Img(\enc\circ U),\qquad
 D(\enc(U(F)))=B(F)\quad(F\in\mathcal S).                  \tag{2}
\]
For an accepted string, $D(y)\in\mathcal B$ is the unique balanced source with
$\enc(U(D(y)))=y$. Moreover
\[
 B(B(F))=B(F),\qquad
 U(F)=U(F')\iff B(F)=B(F').                                \tag{3}
\]
\end{theorem}
\begin{proof}
Balancing adds no gadgets when all signed counts already equal $r_x\ge2$.
Consequently $B$ is idempotent and fixes every member of $\mathcal B$.

Parse and validate the full target byte string. If it has $M$ clauses and $v$
active variables, require $M$ divisible by 24 and $v=3M/4$. Set $m_B=M/12$
and $R=M/8$. In the implication block, record $j$, for $0\le j<R$, must be
\[
 (-(j+1),s_j,R+15\lfloor j/3\rfloor+p_{j\bmod3}),
 \qquad(p_0,p_1,p_2)=(1,7,13).                             \tag{4}
\]
Each clone cycle occupies one consecutive ID interval of length at least two.
Its successor $s_j$ is the next integer except at the final member, where it
is the interval's first integer. These two cases are disjoint. Reading (4)
therefore reconstructs every interval boundary and its balanced-variable
number uniquely. Reject any failure of this pattern, including a final
unclosed interval.

Use the resulting clone-to-balanced-variable map to decode the first $m_B$
clauses. Reject non-clone IDs there, improper or repeated clauses, missing
dense IDs, or unbalanced signed counts. Call the result $B_y$.
Finally compute $U(B_y)$ and compare the \emph{entire} serialized output with
$y$. Accept exactly on equality. Local format checks alone are insufficient.

On every genuine output, the actual clone map is recovered, so $B_y=B(F)$.
Idempotence gives $U(B_y)=U(F)$, proving completeness. Conversely, successful
full recompilation explicitly supplies a source preimage, proving soundness
and reject-off-image semantics. The cycle parse is unique, so the restriction
of $C$ to $\mathcal B$ is injective. Combining that injectivity with
$U=C\circ B$ proves (3).
\end{proof}

\begin{theorem}[Entire original-source fiber]\label{thm:fiber}
If $D(y)=B$ with $m_B$ clauses and $n_B$ active variables, every preimage $F$
is one of the prefixes of $B$ of lengths $m_B-7g$, where
\[
 0\le g\le \min\left\{\left\lfloor\frac{m_B-1}{7}\right\rfloor,
                         \left\lfloor\frac{n_B-3}{5}\right\rfloor\right\}.
                                                                    \tag{5}
\]
Checking these prefixes gives the whole fiber in deterministic polynomial
time, without a SAT oracle. Its size is at most one plus the bound in (5).
\end{theorem}
\begin{proof}
Equation (3) says a preimage must satisfy $B(F)=B$. Balancing preserves the
source as the initial ordered clause block, appending exactly seven clauses
and five fresh variables per gadget. Thus $m=m_B-7g$, $n=n_B-5g$ and $m\ge1$,
$n\ge3$ give (5). For each candidate prefix, validate the dense active IDs
and check $B(F)=B$ by exact balancing and comparison. Every real preimage is
checked; every retained prefix is a real preimage. There are only $O(m_B)$
candidates.
\end{proof}

\paragraph{Counterexample to unique original preimages.}
Take $F=((1,2,3))$. Then $F\ne B(F)$ but $U(F)=U(B(F))$. The audit obtains
$n_B=48$, $m_B=64$, $v=576$, $M=768$, and ten source preimages with clause
counts $64,57,50,43,36,29,22,15,8,1$. The symbolic inequality and identity
already falsify injectivity of $U$; the ten-element census is
\textbf{COMPUTATIONAL}. Uniqueness is valid only for the balanced preimage.

\section{Language consequence and semantic compatibility}

 K_U=\{y:D(y)\ne\bot\ \land\ \SAT(D(y))\}
     =L_{22}\cap\Img(\enc\circ U).                        \tag{6}

Thus recognition of image syntax is in P; deciding satisfiability on that

The old preimage-witness proof is sufficient but is not the strongest
recognition statement available for this ordered encoding.

For a formula $F=(C_1,\ldots,C_m)$, define the compatibility relation
\[
 H(F)=\{(\eta_1,\ldots,\eta_m):\eta_i\in\{0,1\}^{\operatorname{Vars}(C_i)},
 \ \eta_i\models C_i,\ \eta_i|_{V_i\cap V_j}=\eta_j|_{V_i\cap V_j}
 \ \forall i,j\}.                                       \tag{7}
\]
Since every active variable occurs, this is in bijection with the global
satisfying assignments. For $B=D(y)$, copying a balanced assignment around
its clone cycles and setting every $Q$ variable to zero supplies a section
$H(B)\to H(y)$. Conversely, every target model has false $Q$ ports and equal
clones, so reading one value per interval projects to $H(B)$. Projection
composed with this section is the identity. These maps act on a supplied
assignment; they neither enumerate $H$ nor force an arbitrary decider to
materialize it. Counting solutions is not preserved by this section.

\section{Costs and the fixed-language proof arrow}
Let $N=|y|$ in encoded bits. Reject IDs exceeding three times the clause
count before allocating any ID-indexed table. A conservative deterministic
multitape implementation uses scans and pairwise comparisons rather than
unit-cost hash-table assumptions. There are $O(N)$ records with $O(\log N)$
valid indices; polynomially bounded scans reconstruct occurrence lists,
clone intervals, decoded clauses and the recompilation. Allowing an extra
factor for tape access gives the deliberately loose bounds
\[
 T_D(N)=O(N^3),\qquad S_D(N)=O(N^2).                       \tag{8}
\]
The accepted decoded source has $O(N)$ encoded length. Reusing the work tapes
for the $O(N)$ prefix candidates gives $O(N^4)$ time and $O(N^2)$ workspace
for fiber enumeration; writing all preimages also takes only polynomial
output. No subpolynomial-space implementation is asserted. Python runtime
measurements do not certify (8); the scanning realization supplies its
polynomial machine-model interpretation.

Suppose a fixed exact decider $A$ has time at most $cN^d$, for arbitrary fixed
$c,d$. On an image input, decoding and recompiling before running $A$ costs
\[
 O(N^3)+T_A(y),\qquad \enc(U(D(y)))=y.                    \tag{9}
\]
The same exact input is returned to the same solver. It retains the unknown
exponent, and iterating this route does not shrink it. The factor $12$ in
clause counts is a syntactic decoding reduction, not a repeatable $L_{22}$
shrinker: $D(y)$ need only be balanced, not exact-$(2,2)$. A fixed finite number of constant-factor calls retains the polynomial
exponent. A genuinely uniform growing-depth reduction could behave
differently, but would need its own closure and charged recurrence; (9)
provides no such reduction.

The advanced arrow is therefore
\[
 \text{ordered compiler output}\ \longrightarrow\
 \text{polynomially acquired balanced source and complete preimage fiber}.
\]
It is neither a target-run-to-PC/PCR proof extraction nor an all-decider time
lower bound. The desired theorem remains
\[
 \forall A\in\operatorname{Dec}(L_{22})\ \forall k\ge1,C>0,N_0\ \exists G\in\mathcal C_{22}:
 \quad |\enc(G)|\ge N_0,\quad T_A(\enc(G))>C|\enc(G)|^k.   \tag{10}
\]
No unconditional model-matched contradiction with $L_{22}\in P$ was obtained.
