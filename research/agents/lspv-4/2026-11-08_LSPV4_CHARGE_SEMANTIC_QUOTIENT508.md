## Family/encoding/model ledger

Fix simple connected cubic G=(V,E), H=|V| even, m=3H/2, edge variables e_1,...,e_m in lexicographic edge order. At each vertex v, place four **original proper signed width-3 clauses** excluding exactly those assignments to its three incident edge variables whose XOR disagrees with charge chi_v. Clauses are ordered by lexicographic forbidden triple, edge IDs increasingly in each clause. There are exactly 4H original source clauses and 12H literal occurrences, no new variables. Use explicitly stipulated 8-bit A5 marker, 12-bit H, 12-bit m, and for each literal a w=ceil(log2(m+1))-bit ID and a single polarity bit (sign=forbidden triple bit). Then

$$
N=32+12H(w+1)=\Theta(H\log H).
$$

This is LSPV-4/507's own fixed-field encoding, NOT byte-identical to LSPV-2/495, not an authenticated historical R_mix341 parser. Validity of the graph/template and fixed-field syntax is an additional source promise. For connected G, incidence-matrix GF(2) rank H-1 gives `SAT(F_chi) iff XOR_v chi_v=0`. A flip of chi_v changes exactly the four third-literal sign positions Q_v in its four clauses, leaving identifiers and length unchanged. On growing cubic expanders with odd total charge, ordinary shared-DAG **Resolution** refutations have exponential size under the cited model; a GF(2) shortcut decides promised-family satisfiability in polynomial time. No hardness transfer to all algorithms or fixed R_mix341 follows.

## ITERATE: exact semantic quotient and Gray-code source-sharing control

**Theorem 508.1 (PROVED/RESTRICTED).** Fix any order of the H charges and compute their parity under the fixed source promise. The canonical reduced *ordered read-once* BDD for the SAT predicate has **exactly 2H-1 nonterminal nodes** and two terminal nodes. This is minimum within OBDDs respecting the chosen order, not a shortest unrestricted SAT computation. At level zero there is one parity residual. For each level k=1,...,H-1 there are precisely two distinct nonconstant residual functions of the remaining suffix, parity and its complement. They cannot share a node because their output differs on every common suffix. Conversely, maintain the one-bit running parity and make two nodes at each subsequent level, merging equal residuals: exactly 1+2(H-1) nodes. Thus total explicit DAG nodes are 2H+1, versus 2^H distinct completed input-read trace-answer cylinders and 2^(H+1)-1 nodes of the *unreduced* complete binary source-charge trie. **The structures represent different kinds of reuse; the latter leaf bound is not an all-DAG lower bound.**

The first forbidden clause at each vertex is 001 if chi_v=0 and 000 if chi_v=1. Hence the third-literal polarity bit at that clause's fixed record is b_v=1 XOR chi_v. Since H is even, XOR_v b_v = XOR_v chi_v. Therefore a source-structure-aware promised-family reader needs only H indexed representative sign reads and one accumulator bit for the SAT label, *after* a valid source promise has been justified; no semantic oracle is used.

**Theorem 508.2 (PROVED/RESTRICTED).** Let g(i)=i XOR floor(i/2) denote the H-bit binary-reflected Gray code, 0<=i<2^H. Adjacent g(i) differ in one charge coordinate. XOR of the H bits of g(i) equals i mod 2 because the shifted bits cancel telescopically. Therefore the SAT labels of the q=2^H **implicitly generated** sources in Gray order alternate. An enumerator with H-bit index and one output bit can emit all q labels with O(q) amortized elementary counter operations, O(H) workspace, and O(q) output bits, *without separately materializing or authenticating q source strings*. Materializing q original binary CNFs instead requires Omega(qN) output operations, and processing q independent untrusted source strings invokes their own read/authentication charges. This does NOT violate the [P2-L4-507] qH bound for fresh independent guest executions: the Gray enumerator is a different explicit, correlated-source algorithm.

## FULL resource ledger: work, depth, simultaneous space

- **Exact source authentication:** For an independently supplied N-bit source, compare header, IDs, sign-quartet consistency, graph/template structure and length, not merely its representative sign bits. A byte-by-byte uniform-template regeneration strategy uses at least Omega(N) INPUT/OUTPUT comparisons; an O(N polylog N) bound with O(log N) WORK needs an additionally stipulated logspace-uniform graph generator and a proven native indexed implementation. If the input is a syntactically valid CNF outside this specialized source family, rejecting it as UNSAT/MALFORMED would be WRONG; fall back to a correct generic SAT decider.
- **Promised-source read-only decision:** H representative reads, O(H log N) indexed index-write/read/erase operations under straightforward binary counters, O(log N) WORK/INDEX plus a parity bit, subject to graph/order uniformity. This is O(N polylog N) time on actual N-bit sources and no proof of universal SAT-in-P.
- **Explicit shared semantic ROBDD:** 2H-1 paid decision nodes, two leaves, O(H log H) explicit node/edge pointer bits and construction work within a separately defined OBDD representation; depth H. A streaming interpreter needs an H-step logical computation and O(log H) state/counter bits if graph-template positions are computable, not storage of the whole BDD. These nodes are not certified native R_mix341 inference steps.
- **Implicit Gray portfolio:** q=2^H label output bits, O(q) amortized binary counter updates, O(H) live bits; no q separate guest runs. If q FULL original CNF bitstrings are requested, output/materialization alone costs Omega(qN). If q are given as independent untrusted strings, any independently required authentication is separately charged. A complete trace-cylinder cache is allowed zero hits yet a different legal semantics-aware algorithm can still be small.
- **Shared proof DAG versus execution schedule:** The semantic BDD is a branching *decision DAG*, not an UNSAT refutation. Do not assign it R_mix341 proof weights or discharge branch assumptions by fiat. Full per-inference work, critical-path span, and realizable time/peak-space remain separately accounted. H sequential parity updates have O(H) work/span; an explicit parallel XOR tree has O(H) work, O(log H) span, and a separately charged scheduling/storage cost. The abstract 2H-1 ROBDD minimum does NOT imply that same number of FLMV machine transitions.
