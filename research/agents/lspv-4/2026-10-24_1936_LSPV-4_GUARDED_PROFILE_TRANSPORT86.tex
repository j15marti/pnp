\section{Target, proposals, model and source history}
The shared goal remains a charged finite route in the region $E$ of simultaneous resource pairs $(t,s)$ for one fixed uniform total exact ordinary-SAT machine, correct on every ordinary input in the Fortnow--Lipton--van Melkebeek--Viglas (FLMV) deterministic random-access Turing model. An alleged favorable successor pair is not in $E$ until the identical machine achieves both time and counted live work-space bounds. We do not assert such a successor.

Three falsifiable proposed transfers were audited: (M1) a guarded boundary profile can be emitted bitwise with logarithmic writable state and polynomial logarithmic work; (M2) an all-valid-guard-profile decider inherits a model-matched FLMV forbidden pair; (M3) the same lower bound transfers to plain SAT of the unpinned guarded parent. We prove M1, supply a rigorously typed FLMV reduction for M2 with its upstream source contract, and \textbf{falsify M3}. Role~3's GUARD90 already established the two-clause gadget and NP-complete boundary membership; there is no claim of priority for the gadget.

The matched indexed model is FLMV Section~2.1: original input tape is read-only with a counted index tape, other work/index tapes and head/address state count as space, and a write-only output tape is exempt. Index arithmetic, all source reads, rule choice, changed and unchanged work writes, live buffers, failed attempts, and reconstruction must be charged. We do not equate temporal flips with total bit work.

\section{Exact guarded encoding and independent SAT/UNSAT controls}
For a proper ordered three-CNF $H=\bigwedge_{i=1}^{m}(\ell_{i1}\vee\ell_{i2}\vee\ell_{i3})$ over $[n]$, with distinct source IDs within every clause, introduce private $a_i=n+i$ and guard $x=n+m+1$, and form
\begin{equation}\label{eq:guard}
G_H=\bigwedge_{i=1}^{m}
\left[(\neg x\vee\ell_{i1}\vee a_i)
\wedge(\neg a_i\vee\ell_{i2}\vee\ell_{i3})\right].
\end{equation}
It has $n_G=n+m+1$ variables and $M_G=2m$ proper ternary clauses, and the non-isolated incidence graph is connected. Set
\[
Q_H(b)=\left[\exists\,\mathbf y,\mathbf a\quad G_H(x=b,\mathbf y,\mathbf a)\right].
\]
The first equation of the exact profile is $Q_H(0)=1$ (use $x=0$ and every $a_i=0$); the second is
\[
Q_H(1)=\SAT(H),\qquad \SAT(G_H)=1
\]
since $\exists a_i[(\ell_{i1}\vee a_i)\wedge(\neg a_i\vee\ell_{i2}\vee\ell_{i3})]$ is precisely its original source clause. No global SAT label is assumed or read by the generator.

Use two unsigned header words $(n,m)$, then for each proper clause four words $(3,\operatorname{lit}(\ell_1),\operatorname{lit}(\ell_2),\operatorname{lit}(\ell_3))$, with
\[
\operatorname{lit}(\ell)=2|\ell|+\mathbf1_{\ell<0},\quad
w(n,m)=\left\lceil\log_2(64(n+m+1))\right\rceil.
\]
The exact lengths are
\[
N_H=(4m+2)w(n,m),\qquad
N_G=(8m+2)w(n+m+1,2m).
\]
For used-source identifiers and $3\le n\le3m$ the two lengths are $\Theta$-equivalent. With eight distinct ternaries on three variables, $H_U$ is UNSAT; replacing one by a duplicate makes $H_S$ SAT. Their lengths match exactly: $N_H=340$, $N_G=726$, and $N_{\mathrm{pin}}=984$ for the four-clause unit-pinned target. In both cases the unpinned guarded parent is SAT; the $x=1$ profile gives opposite labels.

\section{New local ordinary-output bit theorem}
\begin{theorem}[Exact indexed guard bit service; PROVED/EXACT]\label{thm:bit}
There exists one fixed uniform deterministic controller that, on valid canonical $H$ and arbitrary address $b\in[0,N_G)$, returns bit $b$ of the \emph{independently serialized ordinary} $G_H$ with $O(\log^2 N_H)$ elementary bit work and $O(\log N_H)$ live writable bits in the FLMV-style indexed read-only-input model. This includes output header computation, signed-literal conversion, source index, source reads, and returning the requested bit. There is no intermediate full guard array.
\end{theorem}
\begin{proof}
Find the output word $u=\lfloor b/w_G\rfloor$ and within-word index $b\bmod w_G$. Output words 0 and 1 are $n+m+1$ and $2m$. For $u\ge2$, let $(j,f)$ be quotient and remainder of $(u-2)/4$, then let $(i,p)$ be quotient and remainder of $j/2$. When $p=0$, the selected four values are $3,\operatorname{lit}(-x),\operatorname{lit}(\ell_{i+1,1}),\operatorname{lit}(a_{i+1})$. When $p=1$, they are $3,\operatorname{lit}(-a_{i+1}),\operatorname{lit}(\ell_{i+1,2}),\operatorname{lit}(\ell_{i+1,3})$. Extract the indexed bit of the selected word. All integers, index tapes, and controllers have $O(\log N_H)$ bits. Binary schoolbook divisions, multiplications if required, header width and signed-code arithmetic cost $O(\log^2 N_H)$ bit work with counted $O(\log N_H)$ work bits; a constant number of original indexed source reads suffices. The output is an ordinary encoded source bit, not a free decision oracle.
\end{proof}

\section{Forbidden endpoint: a \emph{profile} transport and its failure for parent SAT}
Define the guarded-profile language $\mathcal{GP}=\{G_H:Q_H(1)=1\}$ on the promised exact grammar, and require a machine to output $Q_H(1)$ on \emph{every valid guarded input}. Invalid encodings can be totalized, but our reduction only presents valid encodings. The task is not to output $\SAT(G_H)$.
\begin{theorem}[FLMV-composed guarded-profile lower bound; model-matched]\label{thm:flmv}
Use the locally indexed, quasilinear-size NTIME$[n]$-to-3CNF reduction from FLMV Section~3 and its standard bounded-width properization and fixed-record output service, with at most $3m$ source IDs and $O(\mathrm{polylog}\,n)$ per queried bit and $O(\log n)$ controller space. Then for every fixed $c>1$ and $\beta(c)=\frac12((c+2)/c^2-c)>0$, no fixed uniform deterministic exact \emph{guarded-profile} decider on every valid guarded input has simultaneous time $N^{t+o(1)}$ with $t<c$ and counted work-space $N^{s+o(1)}$ with $s<\beta(c)$ in the FLMV model. At $c=241/200$,
\[
\beta(c)=11642479/23232400>1/2.
\]
This is a lower-bound transfer to the named profile task, \textbf{not} to SAT of the always-YES guarded parent.
\end{theorem}
\begin{proof}
If a claimed fast profile machine $B$ existed, simulate $B$ using as its read-only tape an indexed bit service for $G_H$. By Theorem~\ref{thm:bit}, the simulated $B$ receives \emph{exactly} its canonical ordinary target bits; all random-address source dereferences and guest index/work tapes are counted. The same fixed simulated machine decides $\SAT(H)$ exactly since its answer equals $Q_H(1)=\SAT(H)$. It has simultaneous
\[
T_H(N)\le N\operatorname{polylog}N+
T_B(\Theta(N))\operatorname{polylog}N,\qquad
S_H(N)\le S_B(\Theta(N))+O(\log N).
\]
Compose with the indexed quasilinear source-encoding interface assumed above. Strict time and space margins absorb all polylogarithms, yielding NTIME$[n]\subseteq\DTISP[n^c,o(n^{\beta(c)})]$, contrary to FLMV Corollary~5.8. The upstream properization is charged by the cited local-reduction hypothesis, not treated as an unproved free general normalizer.
\end{proof}

\paragraph{Sharp rejection.} Ordinary $\SAT(G_H)$ is identically true and has a source-independent witness $x=0,a_i=0$. The hard bit is $Q_H(1)$, whose computation a SAT-only machine need never perform. Plain pinning $x=1$ creates an ordinary target of length
\[
N_{\rm pinned}=(8m+18)w(n+m+3,2m+4)=N_G^{1+o(1)},
\]
not $N_G^{1/2+o(1)}$. A pin is a root-scale SAT call, not an ARC contractor. Complexity of an output relation must not be promoted to mandatory decision work of an always-SAT parent.
