\section*{Falsified lemma: declared indices are not appearing variables}
\begin{theorem}[Exponential query blowup under naive header enumeration]
For strict signed DIMACS-style CNFs, the compiler which literally outputs $\exists x_1\cdots\exists x_n F$ with one quantifier per \emph{declared header variable}, even when unused, can have $2^{\Omega(N)}$ output on a valid input of length $N$. Thus this implementation does not have polynomial worst-case running time.
\end{theorem}
\begin{proof}
Take declared $n=10^d$ and the single clause $(x_n)$. A decimal header and the sole literal together require $O(d)$ bytes; the formula is SAT. Its naive quantified prefix requires $10^d=2^{\Omega(N)}$ quantifier tokens. The analogous two-clause UNSAT formula $(x_n)\land(\neg x_n)$ has a one-node Resolution contradiction but the same naive-prefix problem. On neither instance does the large declared variable range imply SAT hardness.
\end{proof}

\begin{theorem}[Corrected fully source-authenticated query compiler]
Any valid encoded general CNF of bit length $N$, even with exponentially large declared unused-variable maximum, admits a deterministic truth-equivalent existential-QBF query of length $O(N\log(N+2))$ bits, constructed in polynomial total time and polynomial all-phase writable space without a semantic oracle. The only queried variables are the distinctly occurring original variables.
\end{theorem}
\begin{proof}
Scan the source's actual literal occurrences and sort/deduplicate their variable identifiers. There are $r$ distinct such identifiers, with $r$ no greater than the number of occurrences, hence $r\le N$. Replace their names by the consecutive indices $1,\ldots,r$, and quantify precisely these $r$ names. The matrix contains at most $N$ literal occurrences. Every new name requires $O(\log(N+2))$ bits, so the matrix, quantifier prefix and necessary delimiters have $O(N\log(N+2))$ bits. Explicit sorting, renaming, counting, parsing and writing all take polynomial time, including bit-cost comparison of potentially $O(N)$-bit old identifiers. The transformation is a bijective renaming of the occurring variables, so SAT is preserved. The empty conjunction is true and an empty clause is false. A TQBF oracle answers this explicit sentence in one abstract oracle call, whose unit query cost is \emph{only} part of the oracle model.
\end{proof}

\paragraph{No hidden low-space conclusion.}
Materializing the query or a sorted source index typically uses $\tilde O(N)$ writable bits, so no implementation with the required all-phase space exponent $\rho\le\tfrac12$ has been established. On a physical indexed-input Turing machine, parsing, indexing, source rereads, guest code and heads, output and all simultaneously live memory must be charged. The all-phase formula remains
\[
s'\le\max\{\rho,\eta,\lambda,\lambda s\}.
\]
The satisfiability oracle itself cannot be silently imported into a normal SAT decision algorithm or into $R_{\mathrm{mix341}}$.
