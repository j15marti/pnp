## Established hardness control and exact encoding

For a connected cubic graph G with H vertices, one edge variable per edge and four signed strict ternary clauses at each vertex, parity charge XOR_{e incident v} x_e=b_v forbids four of the eight local assignments. The original source has 4H clauses and 3H/2 variables, N=Theta(H log H) under fixed-width binary literal IDs. For a growing connected cubic **expander** and odd total charge, Ben-Sasson--Wigderson Cor. 4.5 gives 2^Omega(H) **ordinary shared-DAG Resolution** size. Gaussian elimination solves this original parity system in polynomial time; no bound is transferred to full R_mix341, every algorithm or the prism below. The prism is an implementation/space **control**, not an asserted Resolution-hard expander.

Define a canonical 3-regular prism G_m with m divisible by 3, m>=6, H=2m. Outer cycle u_i, inner cycle w_i, spokes (u_i,w_i) (indices mod m). Edge variables are e_i=i+1, f_i=m+i+1, s_i=2m+i+1. Source packet order: u_0,...,u_{m-1},w_0,...,w_{m-1}; four original strict signed ternary clauses in each packet, with ordered variable supports (e_{i-1},e_i,s_i) or (f_{i-1},f_i,s_i). The designated exceptional set D={u_i:i mod 3=0} is independent and has k=m/3=H/6 vertices. Every other packet must represent a parity equation; every D packet may contain any four signed clauses (including repeats or a parity packet). The intact graph G_m-D is connected via the inner cycle. This is a genuine original 3-CNF source, not a transformed 3-CNF encoding.

The binary source starts with 1^ell 0, followed by ell bits encoding m, ell=bitlength(m); every literal is one sign bit and W=bitlength(3m) variable-ID bits in the fixed packet support order. Exact length is N=2ell+1+24m(W+1), hence Theta(m log m). The source verifier rejects incorrect dimensions, any corrupt/nonbinary input, ID/support mismatch, invalid normal parity packet or noncanonical slot layout as MALFORMED or OUTSIDE rather than claiming UNSAT. ## Lemma 477.1: exact parity-spectrum characterization (PROVED/RESTRICTED)

A signed ternary clause on three distinct variables forbids exactly one local truth triple. Four such clauses exclude at most four triples. If all allowed triples have the same XOR parity p, all four opposite-parity triples must have been forbidden, so the four clauses are exactly the ordinary parity packet. Therefore **every nonparity four-clause packet allows an assignment of each parity**. Every parity packet allows exactly one parity. Define P_v subseteq {0,1} as the set of allowed XOR parities at designated exceptional vertex v; it is always {0}, {1} or {0,1}.

For each intact vertex v, let b_v be its authenticated charge; put q=XOR_{v not in D} b_v. Then the **entire original source** is SAT iff

$$
q\in\bigoplus_{v\in D}P_v.
$$

Necessity: sum the intact component equations; its internal edges cancel, leaving exactly the XOR of all D-boundary edges, which is the XOR of the local parities of D assignments. Sufficiency: independent D packets share no edges, so choose one satisfying triple at each D with the required XOR. The connected intact component has even residual charge and its GF(2) incidence matrix has rank |V\D|-1; hence an internal-edge extension exists. These are **AND obligations** on all intact equations with **OR alternatives** within P_v; no branch-local fact is reused illegally. If any designated packet is truly nonparity, its P_v={0,1}, so SAT is automatic for this exact grammar (subject to all normal packets being valid).

## Lemma 477.2: source-authenticated low-space constructive schedule (PROVED/RESTRICTED)

A fixed finite-tape indexed read-only-source implementation scans all 8m original packets and authenticates every variable ID and literal. It maintains m, current source address, packet counter, q, XOR of singleton P_v parities, and the position of one P_v={0,1} packet. This uses O(log N) **live and high-water writable/index bits**. Each packet has at most 12 literal fields, constant-local tuple and mask space. The SAT test checks the global parity summary in O(1) state.

For a SAT witness, fix all flexible D parities to 0 except the first flexible packet, chosen to make the XOR equal q; singleton packets take their unique parity. Re-read each needed original packet on demand and choose its first allowed triple of the selected parity. Set e_i to the D packet's local edge value if incident to D, otherwise 0. Set s_i at each intact outer vertex by b_{u_i} XOR e_{i-1} XOR e_i, and at each D vertex from its chosen triple. Set f_{m-1}=0, and for 0<=i<m-1 set f_i=XOR_{j=0}^i(b_{w_j} XOR s_j). The last inner parity equation holds by the global XOR condition. Output e_*, f_*, s_* sequentially, on a write-only output tape. Recompute each packet on demand instead of retaining all tables, predecessor assignments or an output vector.

A direct bounded-width arithmetic implementation uses O(N polylog N) same-model native steps, including complete source scan, typed address calculation, input INDEX writes, sequential/indexed reads, literal decoding, controlled repeated packet reads, branch tests, witness output and malformed/OUTSIDE classification. Each arithmetic operand and physical noninput workspace is O(log N) bits; the input is read-only and the output is write-only. The finite host-language tester below is NOT a compiled native FLMV program. As in LSPV-4/472 and /476, INDEX-head erasure semantics must be fixed in any literal instruction translation. **No arbitrary virtual child INPUT, WORK interpreter, unknown-exponent uniform compiler, or all-input recursive iteration is proved.**

In contrast, an implementation that **actually retains one nonempty per-vertex table record per D** has at least k=H/6 physical state records, hence Omega(H)=Omega(N/log N) retained bits for this family, much larger than N^(1/2) for unbounded H.
