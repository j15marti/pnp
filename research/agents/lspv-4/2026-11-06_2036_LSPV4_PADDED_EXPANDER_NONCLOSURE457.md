## Source theorem / published family ledger
Take a sequence of connected **3-regular edge expanders** G_H on H vertices, with |δ(U)|>=epsilon min(|U|,H-|U|) for a fixed epsilon>0. One edge variable x_e per edge, 3H/2 variables. Assign vertex charges chi_v with XOR_v chi_v=1. For each vertex v with incident edges e1,e2,e3 include **exactly four strict signed original ternary clauses**, one clause for each falsifying assignment a to those three bits with a1 XOR a2 XOR a3 != chi_v: the clause is the OR of x_ej when a_j=0 and NOT x_ej when a_j=1. The resulting F_H has 4H clauses, N_guest=M=Theta(H log H) binary bits under dense indices. Adding all vertex equations gives 0=1, hence F_H is mathematically UNSAT. This is not an accepted R_mix341 certificate.
Established proof-complexity control: Urquhart (JACM 1987) proved exponential length lower bounds for ordinary Resolution refutations of Tseitin expander formulas. Ben-Sasson and Wigderson (JACM 2001) give width-based Resolution size lower bounds. Pitassi, Rossman, Servedio and Tan (STOC 2016) treat strict 3-CNF Tseitin contradictions on 3-regular expanders in bounded-depth Frege. **Their bounds are restricted to their stated systems and do not certify hardness for arbitrary SAT algorithms or historical full R_mix341.** A linear GF(2) sum is the mandatory polynomial-time upper-bound shortcut.

## 457.1 Restricted parent-to-guest nonclosure theorem
For every such F_H, build a complete binary tree of h=2^d-1=Theta(H) contiguous original strict-3CNF source blocks, selecting the least such h >=4H. Put all original F_H clauses in the root block (the original four-clause vertex packets remain intact). At every other block put 4H proper positive ternary clauses over globally private fresh variables. All tree-edge interfaces are empty (w=0). All h blocks contain Theta(H) clauses, each block length Theta(H logH); the full parent source has N=Theta(H^2 logH) bits. Thus h,L_max <= N^(1/2+o(1)) and w<=log_2(N)/10, exactly the **promised grammar constraints** of LSPV-2/459 (with ordinary read-only authenticated typed block headers). Each dummy subtree is satisfiable, so every child message on an empty interface is TRUE. The root query is therefore **exactly G_root=F_H**: no pin or blocker clause is present. The parent can be SAT or UNSAT according to the charge parity; the required guest cofactor retains its real label. The outer compiler's conditional upper-bound arithmetic holds at this first level.

**PROVED/RESTRICTED:** There is no automatic recursive promise closure for this compiler even after allowing a fresh *source-packet-preserving* balanced binary-tree re-encoding of that root guest into blocks each of length M^(1/2+o(1)) and interfaces width O(log M), under the same edge-variable ownership rule.

Proof. The original root guest has H four-clause parity packets, and each new allowed block has at most Q=o(H) packets because M^(1/2+o(1))=o(H) while each packet has positive encoded length. Put packet counts as nonnegative weights on the vertices of the proposed binary decomposition tree, maximum node weight Q. A weighted centroid exists with all components of the deleted centroid having weight <=H/2. Because the tree has maximum undirected degree three, some component has weight in [(H-Q)/3,H/2] for H>Q. Its unique tree-parent edge separates a packet subset U of that size from the others. Expander edge boundary gives at least epsilon(H-Q)/3 distinct original edge variables crossing U. Since an original edge variable appears in the two packets of its endpoint vertices and must be owned by either one block or one adjacent-block interface, all those variables must cross that single tree edge. Hence its interface width is Omega(H), contradicting O(log M). QED.

**Important quantifier:** This theorem refutes only recursive closure of the specified *original-packet-preserving tree grammar*. The guest might be solved by GF(2) without recursion, transformed using extensions/algebra, or handled by an altogether different compiler. In particular, it does NOT establish an all-machine lower bound, refute [P2-A2], or imply P!=NP.
