\section{Hitting-clause logic and occurrence-degree firewall}
Let $H_F$ be the classical source conflict graph: original source indices are vertices; $\{j,h\}$ is an edge precisely when some $x_i$ occurs positively in one and negatively in the other. A clique $K$ is a pairwise \emph{UU-incompatible} source subfamily, called hitting in the clause-set literature~\cite{Kullmann2003,Kullmann2011}. For each original variable used among $K$, call it \emph{one-sided} if all its occurrences within $K$ have one polarity; let $P_K$ assign each such variable the value making all these occurrences FALSE. Oppositely occurring variables remain free. Write $w_j$ for the number of free occurrences left in $C_j|_{P_K}$.
\begin{theorem}[Source-indexed conditional hitting certificate, known principle in an exact22 form]
For any proper signed 3CNF and any original-clause clique $K$ of $H_F$, under the coherent one-sided partial assignment $P_K$ the residual source-clause falsification events are pairwise disjoint. Therefore
\[
 W_K:=\sum_{j\in K}2^{3-w_j}\le8.
\]
If $W_K=8$, every original full assignment extending $P_K$ falsifies some original parent clause, so the original formula entails the non-tautological learned clause
\[
 L_K=\bigvee_{v\in\mathrm{dom}(P_K)}(x_v\;\text{if }P_K(v)=0;\ \neg x_v\;\text{if }P_K(v)=1).
\]
The certificate consists solely of original clause indices, one opposite-signed \emph{free} variable witnessing each pair edge, the one-sided pin values, residual widths and the exact integer equation $W_K=8$.
\end{theorem}
\begin{proof}
A free opposing-sign source variable in each distinct pair cannot make the literals of both clauses false, so the conditional falsification events are disjoint. A residual clause of width $w_j$ is falsified by exactly a $2^{-w_j}$ fraction of the coherent free assignments, irrespective of other variables. The sum of disjoint fractions is at most one. Equality makes their union the entire free Boolean cube. A satisfying assignment therefore cannot extend $P_K$, proving $L_K$. The pins are coherent because each chosen variable has only one sign within $K$.
\end{proof}
\begin{theorem}[Strict22 structural and resource bounds]
Suppose every original clause is a proper 3-clause and every original variable occurs exactly twice positively and twice negatively. Then (i) $\Delta(H_F)\le6$; (ii) every source hitting family has at most six clauses, and this upper bound is attained; (iii) all original hitting cliques and all the above canonical conditional covering certificates can be found and source-verified in $O(N)$ indexed word-RAM operations and $O(N)$ indexed words, when the indexed source has length $N=\Omega(m+n)$; at most $O(m)$ bounded-width derived clauses or certificates are emitted. This certificate search is \emph{incomplete for SAT}.
\end{theorem}
\begin{proof}
Every original clause has three occurrences, each facing exactly two source clauses with the opposite sign, giving degree at most six. Let $K$ have $q$ clauses, and $p_v,r_v\in\{0,1,2\}$ be the numbers of positive and negative occurrences of $x_v$ inside $K$. Hitting requires an opposite-sign event for every pair, hence
\[
 {q\choose2}\le\sum_vp_vr_v\le\sum_v(p_v+r_v)=3q.
\]
This excludes $q\ge8$. At $q=7$, both inequalities must be equalities. Equality in $p_vr_v\le p_v+r_v$ for a used variable is possible only when $(p_v,r_v)=(2,2)$, forcing $3q=21$ to be divisible by four, contradiction. Thus $q\le6$. The independently verified proper strict22 source $K_6$ in the accompanying raw data has a six-clique, so this is sharp. For each source clause $j$, enumerate subsets of its at most six higher-index conflict neighbors, at most $2^6$ candidates. Check all source-indexed pair edges, collect one-sided variables, calculate the at most six widths and test the constant-size sum $W_K$. Each test uses at most 18 literal occurrences and 15 pair witnesses. Building the occurrence lists, authenticating degree quotas, enumerating at most $64m$ subsets, source-proof verification and retaining the resulting $O(m)$ constant-size certificates all cost $O(N)$ indexed word-RAM operations and indexed words. An optional dense original $SS/SU/US/UU$ pair table is a \emph{separate mandatory diagnostic output} of $4{m\choose2}$ bits; the solver need not materialize it.
\end{proof}
\noindent\textbf{Root firewall.} An unpinned strict22 source has $w_j=3$ for every original clause, so $W_K=q\le6<8$. There is \emph{no} unconditional source hitting contradiction of this form in the original strict22 formula. Derived cubes arise only after coherent original-variable pins, and failure to find one cannot prove SAT or UNSAT.

\section{Explicit strict22 source and six-step proof beyond root UP/2SAT}
The new connected, proper, duplicate-free $n=6,m=8$ original source $G_8$ is (original indices zero-based):
\[
\begin{array}{llll}
 C_0=(x_1\vee x_2\vee x_4),& C_1=(\neg x_1\vee x_3\vee x_5),\\
 C_2=(\neg x_2\vee\neg x_3\vee x_6),& C_3=(x_1\vee\neg x_2\vee x_3),\\
 C_4=(\neg x_1\vee x_2\vee\neg x_3),& C_5=(x_4\vee\neg x_5\vee\neg x_6),\\
 C_6=(\neg x_4\vee x_5\vee\neg x_6),& C_7=(\neg x_4\vee\neg x_5\vee x_6).
\end{array}
\]
Each variable appears exactly twice with each sign. The source pairwise U targets of $K=\{C_0,C_1,C_2,C_3,C_4\}$ clash for \emph{every distinct parent pair}. Within $K$, $x_1,x_2,x_3$ appear in both signs and stay free, while $x_4,x_5,x_6$ appear only positively, giving coherent $P_K:(x_4,x_5,x_6)=(0,0,0)$. The original source clauses reduce, without independently assigning occurrences, to
\[
(x_1\vee x_2),\ (\neg x_1\vee x_3),\ (\neg x_2\vee\neg x_3),\ (x_1\vee\neg x_2\vee x_3),\ (\neg x_1\vee x_2\vee\neg x_3).
\]
Their widths are $(2,2,2,3,3)$, so $W_K=2+2+2+1+1=8$. The five falsification cubes partition the eight coherent assignments on $x_1,x_2,x_3$. Consequently $G_8\models x_4\vee x_5\vee x_6$. Crucially root UP finds no unit and the original formula is all ternary. After the three pins, the residual binary \emph{subformula} consisting only of the first three clauses is SAT, so checking that 2SAT component alone does not detect the contradiction. This does not evade failed-literal tests or bounded resolution.

Here is a six-step non-tautological original-parent resolution DAG, with $R_5,\ldots,R_{10}$ retaining exact pivot provenance:
\[
\begin{aligned}
R_5&=\mathrm{Res}_{x_1}(C_3,C_1)=\neg x_2\vee x_3\vee x_5,\\
R_6&=\mathrm{Res}_{x_3}(R_5,C_2)=\neg x_2\vee x_5\vee x_6,\\
R_7&=\mathrm{Res}_{x_1}(C_4,C_0)=x_2\vee\neg x_3\vee x_4,\\
R_8&=\mathrm{Res}_{x_3}(R_7,C_1)=x_2\vee\neg x_1\vee x_4\vee x_5,\\
R_9&=\mathrm{Res}_{x_1}(R_8,C_0)=x_2\vee x_4\vee x_5,\\
R_{10}&=\mathrm{Res}_{x_2}(R_9,R_6)=x_4\vee x_5\vee x_6.
\end{aligned}
\]
Thus the coherent partial cube $x_4=x_5=x_6=0$ is excluded by a formal, original-source checkable proof; $G_8$ itself is SAT, with exactly 12 verified full models. This is a restricted proof of a \emph{single source-derived shortcut}, not a general UNSAT decision theorem.
