\section{Single load-bearing target and four falsifiers}
The five existing LSPV research roles are directed to one fully charged universal adaptive residual-SAT controller. The accountant must not assume access to a subroutine that reads arbitrary decider code and discovers its true asymptotic time exponent. The four falsifiers are: (F1) a universal computable classifier recognizes a low-degree wrapper for \emph{all} promised polynomial SAT deciders; (F2) finite guest timing identifies all eventual polynomial exponents; (F3) a dummy delay preserves guest SAT correctness but necessarily incurs polynomially large additional writable space; (F4) failure of F1 excludes all possible uniform $A$-oblivious ARC compilers. F1--F3 are false, under their exact declared models; F4 is an invalid inference.

\begin{theorem}[Undecidability of a promised SAT-guest exponent test, conditional on $\mathrm{SAT}\in P$]
Assume there exists a fixed deterministic total exact ordinary-SAT decider $A$ on the FLMV indexed-input random-access Turing machine with worst-case time $O(N^K)$ for some fixed finite $K\ge1$ and counted space $S_A(N)$. Fix any integer $D>K+2$. There is no total computable algorithm that, on the code of every machine \emph{promised} to be a correct total polynomial-time SAT decider on that same machine model, determines whether its worst-case running time is $O(N^{D-1})$. Moreover the counterexample machines may all have counted space $O(S_A(N)+\log(N+2))$.
\end{theorem}
\begin{proof}
Take an arbitrary two-counter machine $M$ and starting configuration $u$. The halting problem for such machines is undecidable [2]. Uniformly compile the code of a SAT decider $B_M$ that on an $N$-bit input $x$ first discovers $N$ by scanning its read-only source; simulates exactly the first $N$ steps of $M$ starting at $u$; if no halt was seen, performs a deterministic dummy delay of at least $N^D$ transitions; then calls the fixed SAT decider $A$ on the unchanged original input $x$ and returns precisely its bit. Every $B_M$ is a total correct polynomial-time SAT decider on both SAT and UNSAT inputs. Two-counter values after $N$ steps are at most their fixed initial values plus $N$, so the simulation uses $O(\log(N+2))$ additional work/index tape positions and $O(N\operatorname{polylog}N)$ time. The delay uses $O(\log(N+2))$ counter positions and polynomial time, regardless of halting. All input, index, work and guest tapes belong to the same fixed FLMV machine; no free oracle or auxiliary read-only tape is supplied.
If $M$ halts after $h$ steps, then for all $N\ge h$ the delayed branch is not reached, and the machine uses $O(N^K+N)$ time, hence $O(N^{D-1})$. Finite exceptional lengths affect the constant, not asymptotic membership. If $M$ never halts, then on \emph{every} length-$N$ source the wrapper spends at least $N^D$ transitions before calling $A$; therefore it cannot run in $O(N^{D-1})$. A hypothetical total promised classifier applied to the effectively obtained code of $B_M$ would decide whether $M$ halts, a contradiction. The compiler uses a single \emph{fixed} $A$ and a single fixed $D$; it does not require computing the unknown $K$ from program text.
\end{proof}

\paragraph{Scope.}
This is a direct known halting-problem technique specialized to exact polynomial-time SAT wrapper codes. It prevents an exact computable asymptotic-exponent selector from being used \emph{for free}; it neither rules out a uniformly charged code-oblivious compiler nor implies a runtime lower bound for arbitrary SAT algorithms. If $\mathrm{SAT}\notin P$, the promised polynomial-SAT-decider domain is empty and this conditional theorem has no unconditional content. Finite traces cannot certify nonhalting: a wrapper that halts after $h$ simulated steps resembles a nonhalting wrapper on all lengths $N<h$.

\section{Same-source ledger, not a surrogate machine model}
For a given source $F$ of bit length $N$, the original input is preserved byte-for-byte for $A$. The wrapper's charged operations are source-length acquisition $O(N)$; at most $N$ two-counter steps at $O(\operatorname{polylog}N)$ per step; delay of at least $N^D$ steps if selected; original guest call $T_A(N),S_A(N)$; and additional live counted work/index/head coordinates $O(\log(N+2))$. Only a constant number of tapes is required for the fixed wrapper, in addition to $A$'s existing tapes. Each distinct $M$ yields a distinct but fixed finite program. For a native implementation one must still audit the exact placement and high-water positions of all tapes; the result uses no arbitrary-word RAM assumption.

For the main ARC transformation the unresolved accounting is different: it must produce at most $N^{3/5+o(1)}$ physically ordinary SAT children of length at most $N^{1/2+o(1)}$, charge bit emitters, child selection, failed policies and inherited guest simulation, and maintain joint writable space at the same input realization. Applying $A$ to the full parent $F$ pays $T_A(N)$ and does not supply a $K\mapsto3/5+K/2$ contraction. The theorem here only prohibits reliance on an \emph{exact} introspective exponent oracle; a fixed portfolio/dovetailing policy may be correct but must include the work of all failed runs.
