\section*{Restricted sparse-anchor lemma}
Keep the guest input-index symbols (blank, zero, one) in a sparse binary trie. Each trie node stores charged pointers and the largest position of a 1 below it. Store the index-tape head position separately. Maintain an immutable anchor root $H$ representing the address supplied by the most recent indexed jump and a signed ordinary-move offset $\delta$. The logical read-only input coordinate is $p=\operatorname{val}(H)+\delta$, saturated at the left end. An indexed jump sets $(H,\delta)=(\mathrm{current\ index\ root},0)$, erases the current index symbols by giving them an empty root, and \emph{does not reset the index-tape head}. Left and right moves change only $\delta$.
\begin{theorem}[Amortized charged abstract-index accounting, restricted]
For a trace of $T$ guest transitions on a genuine $M$-character ordinary child, let $u$ be the maximum number of simultaneously live nonblank symbols across the current and anchored input-index tries. There is an exact, source-label-blind sparse-tree implementation of guest indexed jumps, tape erasure, retained index-head position, ordinary input moves, blank reads and re-entry, with amortized $O(T\log^C(M+T+2))$ bit-operation work for a fixed constant $C$ (a conservative $C=5$), and
\[
O\!\left(M+S_A(M)+u\log^2(M+T+2)+R+\log(M+T+2)\right)
\]
peak live bits, including physically written child storage, guest tapes, retained controller state $R$, trie node metadata and address scratch.
\end{theorem}
\begin{proof}
In $T$ transitions the guest index-tape head visits positions at most $T$ from its starting point, so a sparse trie needs depth $O(\log(T+2))$. With $u$ live nonblank cells, there are $O(u\log(T+2))$ trie nodes, each storing $O(\log(T+2))$ pointer/position bits. Index writes and clears update a root-to-leaf path, paying for all allocated/recycled nodes. Following an indexed jump, an old anchor is reclaimed by a charged node traversal or remains physically live, in which case it appears in the peak; across the execution, total reclaim visits are amortized against allocations. A left/right input move updates only $\delta$, which has $O(\log(T+2))$ bits since the latest jump. On read, compare the cached largest set-bit index of $H$ to the binary length of $M-1-\delta$. If $H$ is larger, return blank. Otherwise, read the $O(\log(M+T+2))$ low-order address bits through the trie, compute $p$, and return the actual stored child symbol if $p<M$, else blank. Treat the left-end boundary exactly. Each step requires at most polynomially logarithmic pointer/address work; induction preserves every guest input and index symbol and its index-head position, so both SAT and UNSAT answers agree with physical execution.
\end{proof}
