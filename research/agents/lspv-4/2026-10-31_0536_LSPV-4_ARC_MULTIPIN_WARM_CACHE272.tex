\section{Exact original-source construction}
Define four proper 3CNF forcing clauses
\[
G(L;a,d)=\bigwedge_{\epsilon,\delta\in\{-1,1\}}
 (L\lor\epsilon a\lor\delta d).
\]
By successive resolution this gadget entails $L$; if $L$ holds, all four clauses hold. For $q\ge3$, take $q$ independent bits $b_j$, fresh selectors $z_j$, a forced-true variable $t$ and forced-false variable $p$. Encode each $b_j$ with the \emph{original} signed clause
\[
P_j(b)=(\ell_j\lor\neg z_j\lor p),\qquad
\ell_j=t\;(b_j=1),\quad\ell_j=\neg t\;(b_j=0).
\]
Let $O_q$ be the existential chain of $q-2$ clauses expressing $\bigvee_jz_j$:
\[
(z_1\lor z_2\lor y_1)\land
\bigwedge_{i=1}^{q-4}(\neg y_i\lor z_{i+2}\lor y_{i+1})
\land(\neg y_{q-3}\lor z_{q-1}\lor z_q),
\]
with the obvious single ternary clause when $q=3$. Add $r(q)=\lceil q^{5/3}\rceil$ separately indexed copies of the satisfiable clause $(f_1\lor f_2\lor f_3)$. Define
\[
F_{q,b}=G(t)\land G(\neg p)\land
\bigwedge_jP_j(b)\land O_q\land(f_1\lor f_2\lor f_3)^{\wedge r(q)}.
\]
For each $j$ form an \emph{ordinary} proper 3CNF child
\[
C_{q,b,j}=G(t)\land G(\neg p)\land G(s)\land
(\ell_j\lor\neg s\lor p)\land
\bigwedge_{i=1}^{h(q)}(u_{i,1}\lor u_{i,2}\lor u_{i,3}),
\quad h(q)=\left\lceil\sqrt{r(q)/\log_2(q+2)}\right\rceil.
\]
All unmentioned auxiliaries are private and distinct. The last clauses use independent fresh variables, and are always simultaneously satisfiable. Every \emph{original} source clause retains its index and signed occurrence; duplicate filler clauses are not mistaken for independent truth restrictions.

\begin{theorem}[Restricted, same-source both-label compiler]
For every $q\ge3$ and every $b\in\{0,1\}^q$,
\[
C_{q,b,j}\in SAT\iff b_j=1,\quad
F_{q,b}\in SAT\iff \bigvee_j(C_{q,b,j}\in SAT),\quad
F_{q,b}\in UNSAT\iff\bigwedge_j(C_{q,b,j}\in UNSAT).
\]
With fixed-width signed decimal DIMACS-compatible tokens, $N=|F_{q,b}|$ and $M=|C_{q,b,j}|$ in physical bits obey
\[
N=\Theta(q^{5/3}\log q),\quad M=\Theta(\sqrt N),\quad
q=N^{3/5-o(1)},\quad qM=N^{11/10-o(1)}.
\]
\end{theorem}
\begin{proof}
The gadgets force $t=s=1$, $p=0$. Therefore $P_j$ forces $\neg z_j$ exactly when $b_j=0$. The standard OR chain has an existential assignment exactly when one selector is true. Consequently the original source is satisfiable exactly when $\bigvee_jb_j=1$. In child $j$ its pin reduces to the constant $b_j$, and its independent filler has a witness. This proves both directions for SAT and UNSAT and the child-specific label. The original has $\Theta(r(q))$ width-three records on $O(q)$-indexed variables, hence $\Theta(q^{5/3}\log q)$ bits. Each child has $\Theta(h(q))$ records on $O(h(q))$-indexed variables, hence $\Theta(q^{5/6}\sqrt{\log q})=\Theta(\sqrt N)$ bits. Multiplication gives the total physical output exponent. This holds for the explicit recognizable grammar only.
\end{proof}

\section{Exact quiescent INDEX lemma and a matching escape}
Suppose a deterministic preprocessor, after reading $F_{q,b}$, leaves a canonicalized state consisting of an $s$-bit persistent source-dependent summary. All subsequent original-source reads, readable output files, and other uncharged source-dependent states are forbidden. A deterministic decoder on $(q,j,summary)$ must return the $j$th child SAT label or the corresponding signed output character for every $b,j$.
\begin{theorem}[Restricted exact quiescent summary bound]
This interface necessarily satisfies $s\ge q$.
\end{theorem}
\begin{proof}
If two different $q$-bit vectors gave identical summaries, querying an index where they differ would require two different correct answers from identical decoder inputs. Thus the summaries injectively encode all $2^q$ vectors, and $2^s\ge2^q$. This is the standard deterministic INDEX/one-way message argument, not unrestricted SAT complexity.
\end{proof}
Canonicalized control and head metadata must be included in $s$. Without that hypothesis the result is \emph{not} a direct lower bound on FLMV counted workspace, because read-only tape head positions and indexed movements require separate same-machine accounting.

There is an explicit legal \emph{escape}: for literal-field width $W_F$, source clause stride $D_F=3W_F+5$, and header length $H_F$, the original sign for $b_j$ is at zero-based source byte index
\[
H_F+(8+j)D_F,\qquad 0\le j<q.
\]
Its output-child sign is at $H_C+12D_C$. One charged indexed source read retrieves it in $O(\mathrm{polylog}\,N)$ address arithmetic and $O(\log N)$ auxiliary bits. Retain \emph{one current child sign} while running that guest, release it on child completion, and pay one new indexed source read for the next child. No $q$-bit simultaneous cache is necessary. A byte-address output accessor uses constant-stride arithmetic and formats only the requested clause, at local $O(\mathrm{polylog}\,N+|i|)$ cost per address, provided the grammar has been paid-for authenticated.
