\section{Exact locally uniform NAND DAG-to-formula bridge}
\begin{theorem}[Gate-path unfolding, PROVED/EXACT under locality]\label{th:gate}
Fix a family of fan-in-two NAND DAGs $C_N$ computing $f_N:\{0,1\}^N\to\{0,1\}$. Suppose every output-to-input path has length at most
$D_N=(c+o(1))\log_2N$ for a fixed $c$, gate IDs use $\log^{O(1)}N$ bits, and a fixed deterministic algorithm, given $(x,N,v)$, returns the type and two ordered predecessor IDs (or an input-bit address/constant at leaves) for gate $v$, with at most $\log^{O(1)}N$ bit operations, \emph{including all indexed reads, index arithmetic, and policy-dependent control}. Then there is an exact NAND \emph{formula} family computing $f_N$ with depth at most $D_N$ and an input-aware gate-at-path locator running in $\log^{O(1)}N$ bit operations. Explicit tree output is \emph{not} needed for this uniformity reduction.
\end{theorem}
\begin{proof}
Unfold the output NAND gate recursively, duplicating a shared predecessor on every distinct root-to-gate path. By induction on path depth the resulting tree computes exactly the same Boolean value, including every SAT and UNSAT output. Given a length-$\ell\le D_N$ binary path $b$, start from the output gate ID and iterate the predecessor-locator $\ell$ times according to its bits. Return the reached gate's NAND/input/constant descriptor; report absent descendants of leaves in the standard tree encoding. The locator uses $O(D_N\log^{O(1)}N)=\log^{O(1)}N$ time and at most polylogarithmic indexed scratch. No gate value, SAT bit, uncomputed certificate, or source answer is guessed. Tree depth is unchanged by duplicating shared gates. This proves both functionality and gate-position uniformity.
\end{proof}
A terminal-leaf boundary convention can be implemented by describing invalid descendants as absent; this does not alter valid formula nodes. Thus, for $c<4\cos(\pi/7)$, [3] rules out an all-input SAT NAND circuit family \emph{meeting these exact depth and gate-predecessor locality hypotheses}. The theorem does \emph{not} cover a merely polynomial-time gate generator, a general polynomial-depth circuit obtained from an unknown polynomial SAT solver, a non-NAND basis with uncharged conversion, or a per-instance circuit encoding a single answer. In ARC the missing issue is the \emph{cheap all-input selector/locator plus low depth}, not syntactic sharing itself. The whole bridge is classical circuit unfolding plus the paper's published gate-at-path notion; it is not claimed as an unconditional new SAT lower bound.

\section{Exact hostile control: tiny NAND DAG, huge syntactic unfolding}

\quad\text{total tree nodes }2L_k-1.
\]
At $k=30$: \emph{29} NAND gates, \emph{58} incoming wires, versus \emph{1,346,269} formula leaves and \emph{2,692,537} formula nodes. The depth remains at most $29$. This is only a syntactic expansion, \emph{not} a lower bound on minimal equivalent formula size: the computed function depends on just two bits and has a constant-size representation. It is an important affine/direct-recognizer-friendly false-time-space control for any accounting argument that multiplies circuit reuse savings into both time and workspace without selecting an implementation.

\section{Adaptive ordinary child-volume and two-level peak ledger}
\begin{lemma}[Conditional adaptive volume theorem; prior corpus result verified]\label{lem:volume}
Let a \emph{previously proved all-input correct} parent procedure call a single uniform exact guest SAT machine $A$ sequentially on ordinary encoded children of lengths $m_i$. The child list/order may depend on earlier returned answers. Suppose $V=\sum_i m_i\le N^{b+o(1)}$, $M=\max_i m_i\le N^{\lambda+o(1)}$, each invocation of $A$ takes $m_i^{d+o(1)}$ time and $m_i^{s+o(1)}$ workspace with uniform constants, aggregate other work is $N^{r+o(1)}$, and aggregate input-access, reconstruction, probe/locator/replay cost is \emph{already bounded} by $N^{u+o(1)}$. Then
\[
\sum_i m_i^d\le VM^{d-1}\quad(d\ge1),\qquad
t'\le\max\{r,u,b+\lambda(d-1)\}.
\]
\end{lemma}
\begin{proof}
For every $i$, $m_i^d=m_i\,m_i^{d-1}\le m_iM^{d-1}$. Sum over the \emph{actual adaptive branch}, which is arbitrary but bounded. Uniform $o(1)$ factors, constant finite code size, local work and charged aggregate access are absorbed in the stated maximum. This is a bound on a declared \emph{correct implementation}, not a transformation that supplies such children.
\end{proof}
Simultaneous \emph{peak space} must separately include $m_i^s$ guest work, one explicit child buffer $M$ if eager, all live source and ancestor work states, virtual locator metadata, index/address bits, solver call stack, retained answer arrays, and output bodies if materialized. If these external exponents are bounded by $\kappa,\eta,\delta$, the \emph{conditional} sequential bound is
\[
s'\le\max\{\lambda s,\ \mathbf1_{\rm eager}\lambda,\ \kappa,\eta,\delta\}.
\]
For two levels there are \emph{simultaneously live} parent and child generators and optionally materialized grandchildren; one cannot silently discard ancestor buffers. For a countercontrol that literally writes and retains $\lceil N^{0.9}\rceil$ answer/junk cells, the actual peak is $\Omega(N^{0.9})$, outside the FLMV rectangle, even if all children are 64-bit trivial CNFs and a simpler streaming implementation would do better. This falsifies a ledger \emph{for that implementation} that leaves out retained memory, not all SAT deciders. Full traversal of adaptive failed routes and all SAT/UNSAT validations remains charged.
