\section*{Executive result}
\textbf{P versus NP remains OPEN.}  This run tests the surviving suggestion
from APIFLAT1: replace an internal ``the solver must expose $H(F)$'' claim by
an external black-box extractor that interrogates an arbitrary exact SAT
decider.  The resulting candidate
\texttt{BLACKBOX-EXTRACTION-TO-SAME-RUN-CHARGE1} is \RETIRED.

The exact replacement theorem is
\texttt{BLACKBOX-EXTRACTION-CHARGE-SEPARATION1} (\EXACT, pending independent
review): a deterministic adaptive machine that sees an exact SAT decider only
through its one-bit answers has the same query/answer transcript for every
exact implementation.  Its output is therefore a source-defined
$\mathsf{FP}^{\SAT}$ computation.  Its work and all of its oracle invocations
belong to the composed extractor machine; they are not work performed by, or
state exposed in, the original single execution $A(F)$.

\section{Claim card and exact quantifiers}
Let $\mathcal D_{\SAT}$ be the class of total deterministic exact SAT deciders
on one fixed self-delimiting CNF encoding.  Thus
\[
  \forall A\in\mathcal D_{\SAT}\ \forall G,\qquad
  A(G)=\mathbf 1[G\in\SAT].
\]
Let $E$ be a deterministic adaptive oracle machine.  On source formula $F$ it
may form queries $G_1,G_2,\ldots,G_q$, with $G_i$ depending on earlier answer
bits, and finally output an object $W$.  The candidate under attack asserted
that, if $E^A(F)$ recovers a compatibility object for every exact $A$, then the
original run $A(F)$ exposed or paid for that object.

The candidate silently identifies two different executions:
\[
  \underbrace{A(F)}_{\text{one decision run}}
  \qquad\text{and}\qquad
  \underbrace{E^A(F)}_{\text{extractor work plus many separate calls}}.
\]
That identification is false without a new compiler theorem.

\section{Clean-core semantic compatibility}
For a CNF $F$ and a consistent partial assignment $\alpha$, define
\[
 H(F,\alpha)=1
 \quad\Longleftrightarrow\quad
 \exists\beta\supseteq\alpha\;[\beta\models F].
\]
On the corrected signed Monotone $3$SAT-$(2,2)$ clean core this is still just
SAT of the restricted formula $F\upharpoonright\alpha$.  A lexicographically
least satisfying assignment is externally recoverable using at most $n+1$
adaptive decision calls: query $F$, then query whether the current prefix can
be extended with $x_i=0$, choosing $0$ if YES and $1$ otherwise.  This fact is
useful, but it is a search-to-decision computation carried out by the
extractor.  It does not force the original call $A(F)$ to materialize the
table of $H$, a witness, a frontier, or a transcript.

\section{Exact black-box theorem}
\paragraph{Theorem (transcript extensionality).}
For every deterministic adaptive oracle machine $E$, every input $F$, and
every $A,B\in\mathcal D_{\SAT}$, the ordered query/answer transcript of
$E^A(F)$ equals that of $E^B(F)$.  In particular, whenever both halt,
\[
 E^A(F)=E^B(F).
\]

\paragraph{Proof.}
Induct on the query number.  Before the first query the deterministic
configurations agree, so the first query string agrees.  Exactness gives
$A(G_1)=B(G_1)=\mathbf 1[G_1\in\SAT]$.  If configurations and answer bits
agree through query $i-1$, determinism gives the same $i$th query, and
exactness gives the same $i$th answer.  The final configurations and outputs
therefore agree. \hfill$\square$

\paragraph{Corollary (source factorization).}
Every total output of such an extractor is a function of $F$ and the SAT
language, not of the chosen exact implementation.  If $E$ has polynomial own
work, makes polynomially many polynomial-length queries, and $\SAT\in\mathsf
P$, then the output is in $\mathsf{FP}$ by replacing the oracle with the
assumed polynomial SAT decider.  This conclusion concerns the new machine
$E^A$, not the internal state of $A(F)$.

\paragraph{Corollary (exact charge).}
If $E$ performs $t_E(F)$ ordinary steps and issues queries
$G_1,\ldots,G_q$ to $A$, then a sequential simulation has
\[
 T_{E^A}(F)=t_E(F)+\sum_{i=1}^{q}T_A(G_i)+T_{\rm encode}(F),
\]
up to the declared universal-machine constants.  Peak workspace includes
the extractor state, query storage, and the peak workspace of each invoked
run.  None of the terms $T_A(G_i)$ for $G_i\ne F$, and none of $t_E$, is a
cost of the original execution $A(F)$.  Even when $G_1=F$, subsequent calls
remain distinct executions.  Thus black-box recovery alone gives no
\same{} transfer.

\section{Primary-literature and obstacle preflight}
The two major obstacles are (i) attribution of an external oracle
computation to one selected ordinary execution and (ii) a model-matched
absolute time--space landing after all oracle calls are compiled away.

\begin{itemize}[leftmargin=*]
\item Baker--Gill--Solovay's relativization theorem is a \KNOWN{} barrier:
opposite $P$ versus $NP$ outcomes occur relative to different oracles.  The
transcript theorem above relativizes and therefore supplies no escape.
\item Aaronson--Wigderson's algebrization framework is a \KNOWN{} stronger
warning.  Replacing an exact answer oracle by its algebraic extension does not
turn the extractor's separate executions into the run $A(F)$.
\item Bogdanov--Trevisan prove barriers for broad nonadaptive worst-case to
average-case reductions for NP problems.  Their theorem does not prove the
elementary transcript lemma and is not imported as a SAT lower bound; it makes
the LWE-style extraction analogy especially nonautomatic.
\item Classical SAT search-to-decision is a directly transferable algorithmic
fact.  It establishes external recoverability, not internal exposure.
\end{itemize}

\section{Barrier and transfer audit}
\paragraph{SAME\_REALIZATION.}
Fails at the exact boundary above.  The selected ordinary machine must be
$E^A$ if the extractor's work is used.  A lower bound must apply to that same
fully charged machine, not retroactively to $A(F)$.

\paragraph{Relativization and algebrization.}
The proof uses only equality of exact oracle answers and survives oracle
replacement.  It is a no-go guard, not a nonrelativizing or nonalgebrizing
separation step.

\paragraph{Natural Proofs and nonuniformity.}
No constructive large circuit property is asserted.  The extractor is one
uniform program; allowing a different extractor or hardwired answer table per
length would introduce a separate nonuniformity gap and is not used.

\paragraph{Solver-to-protocol transfer.}
HEC, VSC-HEC, G-PPC-HEC, CRS-PPC, RCCN, and CCSPC contain exact restricted-model
state or causal guards, but their static-to-online compilers remain \OPEN.
An extensional SAT oracle transcript cannot by itself supply the missing
predecision state, anti-batching, or no-reread hypotheses.

\paragraph{Cross-domain classification.}
Oracle-query accounting and SAT search-to-decision are directly transferable.
VLSI module calls, control-theoretic observability, communication transcripts,
and proof-system interpolation are useful structural analogies only; each
requires an interface-preserving theorem before it can constrain an arbitrary
ordinary SAT decider.  Treating an external module's work as work of the
queried component is a misleading analogy.

\item Collision extraction/special soundness:
