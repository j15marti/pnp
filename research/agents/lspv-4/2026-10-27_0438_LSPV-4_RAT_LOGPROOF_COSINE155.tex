\section{Exact simultaneous verifier semantics}
Fix ONE uniform total deterministic verifier $V(F,\pi)$ on the
index-addressed, read-only source bit-Turing/RAM model matched to the
Williams/FLMV SAT theorem. For every \emph{ordinary} valid CNF formula
$F$ of physical length $N$:
\[
\begin{split}
F\in\mathsf{SAT}&\implies\forall\pi,\ |\pi|\le\ell(N),\quad V(F,\pi)=0,\\
F\in\mathsf{UNSAT}&\implies\exists\pi,\ |\pi|\le\ell(N),\quad V(F,\pi)=1.
\end{split}\tag{1}
\]
Require $\ell(N)\le(a+o(1))\log_2N$ with an efficiently computed
uniform cap and \emph{simultaneous} worst-candidate time
$T_V\le N^{r+o(1)}$, counted work/index space
$S_V\le N^{s+o(1)}$. Require all malformed candidates to halt
within the clock and return zero. The counted work includes source
addresses, proof bits, guest registers, retained ancestor state,
proof grammar, virtual child access and proof-bit access. The
same fixed $V$ handles every input; successful proof \emph{search}
is not presumed.

\begin{lemma}[Indexed epoch-tag memory reset]\label{le:epoch}
Let $M(N)=2^{\ell(N)+1}-1$ and let an indexed-bit-TM
verifier have work-space ceiling $S_V$ measured using
physical work/index addresses, input excluded. Its $M$ fresh-blank
executions can be simulated by one deterministic indexed machine
without scanning/clearing its earlier guest work addresses, using
\[
T_D=O\bigl(N\operatorname{polylog}N+
M(T_V+1)\operatorname{polylog}(N+T_V+M)\bigr),\tag{2}
\]
\[
S_D=O\bigl((S_V+1)(\ell+2)+\ell+\log(N+T_V+M)\bigr).\tag{3}
\]
The source remains read-only, output is a final one-bit decision,
and there is no separate uncharged proof head.
\end{lemma}
\begin{proof}
Number canonical candidate strings by $j=1,\ldots,M$.
Reserve epoch tag zero for physically blank cells and use
$b=\lceil\log_2(M+1)\rceil$ bits per guest work cell for epoch
tags $1,\ldots,M$, plus that cell's payload bit.
Represent guest writable address $u$ by an indexed physical
block beginning at $(b+1)u$; any fixed number of guest tapes
uses disjoint explicitly accounted blocks. At epoch $j$,
a guest read returns blank if the stored tag differs from $j$,
otherwise it returns the stored payload. A guest write
sets tag $j$ and payload to the new symbol, including
same-symbol writes as needed. All other guest finite control,
input-address and proof registers are reinitialized from
the counted enumeration counter before each run. The
original input is never altered and a candidate's proof bits
are stored in counted work. Induction over every guest
transition shows exact equality with a separate fresh-blank
execution. Each virtual work access takes polynomial-logarithmic
bit operations to form the address and inspect/write its
$b+1$ physical bits. The largest physical touched work
address is at most $(b+1)(S_V+O(1))$, up to
charged registers; the source may be indexed independently.
No tag wraps before candidate $M$. This proves (2)--(3),
including the $S_V$-small edge case where address registers
still cost $O(\log N)$.
\end{proof}

\begin{theorem}[Subpolynomial-space Williams proof-cap face]
Under (1), if $S_V(N)=N^{o(1)}$ and $T_V=N^{r+o(1)}$,
then necessarily
\[
\boxed{\max(1,r+a)\ge\gamma}\quad\Longleftrightarrow\quad
\boxed{r+a\ge\gamma},\qquad\gamma=2\cos(\pi/7).\tag{4}
\]
Consequently $r=1$ forces $a\ge\gamma-1=0.8019377358\ldots$.
\end{theorem}
\begin{proof}
The $M$-run machine from Lemma~\ref{le:epoch} outputs UNSAT if
any candidate accepts and SAT otherwise. Equation (1)
makes it a deterministic total decider for \emph{all ordinary SAT}.
The tagged representation gives simultaneous resources
\[
T_D=N^{\max(1,r+a)+o(1)},\qquad S_D=N^{o(1)}.\tag{5}
\]
If $\max(1,r+a)<\gamma$, choose a constant strictly between
that exponent and $\gamma$. Equation (5) then contradicts the
published Williams deterministic random-access SAT bound.
Equality in (4) is not excluded. This is a direct
\emph{corollary} of an existing lower bound, not a separation
of $P$ and $NP$ and not a time lower bound on candidate discovery.
\end{proof}

\section{Two distinct sequential machine ledgers}
\begin{description}
\item[] \textbf{M1 shared single writable tape:} the original
input contributes $P_1\ge N$, and one head charges actual physical
crossings/movements. The conservative decision-only simulation has
$T_1=O(T_k(N+S_k+\log(T_k+2)))$ and
$P_1=O(N+S_k+\log(T_k+2))$.
These are simulation \emph{upper} bounds, not reverse lower bounds.
Retained transducer output $L$ needs separate footprint accounting.
\item[] \textbf{Mk fixed sequential work tapes:} one sequential
read-only input head plus $k$ fixed sequential work tapes;
visited work cells, head motion, input reversals and actual
writes are charged. For the easy signed exact-(2,2) DISJ promise,
the separate single-head crossing theorem imposes
$t+s\ge2$; it is not a native RAT SAT lower bound.
\item[] \textbf{RAT indexed bit machine:} read-only input and
indexed charged work tape, address-register writes and
polylogarithmic indexed accesses; the tag simulation and
Williams/FLMV numerical frontiers belong only here.
A log-word RAM correspondence requires bounded word size and
implemented arithmetic/indirection costs. The two-tape
Hennie--Stearns simulation is not a one-tape time promise.
\end{description}
The HEADMOVE1 $h+s\ge2$, $r+s\ge1$ and UTM-CROSS-WRITE1
$d+ks+\min(d,s)\ge1$, strengthened by EDIT152's
$d+ks\ge1$ and NDET154 accepting-path qualifications,
remain restricted to the explicitly one-sequential-input-head
promise/interpreter setting. Reversals, bit probes, edits and
crossings are subcounters in the transition ledger, not new
additive runtime expenses.
