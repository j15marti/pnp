\section{Model, source, and exact quantified promise}

\[
\SAT(F_m(a,b))\iff \bigwedge_{i<m}\neg(a_i\land b_i),

\]
Every $X_a$ is SAT, and every two distinct diagonals force at
least one UNSAT crossed source. The fixed-width source has
$N_m=\Theta(m\log(m+2))$ bits with $G_m=\Theta(N_m)$
common invariant middle cuts.

Fix ONE deterministic $q$-state finite-alphabet interpreter $U$,
ONE two-way sequential read-only original input head,
and $k=O(1)$ initially blank sequential read/write work tapes.
The full finite state contains \emph{all cached finite flags}.
Every eligible program $p$ is inline \emph{entirely left} of every
selected source cut, may vary with $a$, and is globally sound:
\[
\forall p\in\mathcal P\;\forall F\in\mathsf{3CNF}:
 U(p\#F)\downarrow\mathrm{accept}\Longrightarrow \SAT(F).
\tag{1}
\]
An individual $p$ need not accept every SAT source.
Count $D$ actual changed work-cell symbols, $S\ge1$ total

\section{Prefix-free global chronology}
At any source cut $c$ record every actual change as
$\mathsf W(\mathrm{tape},\mathrm{coordinate},\mathrm{new\ symbol})$
and every crossing as
$\mathsf C(\mathrm{direction},\mathrm{full\ finite\ state},
\mathrm{all\ work\ head\ positions})$.
For a transition with multiple work-cell changes followed by
a source crossing, order writes by tape index and the crossing last.
Starting from blank maps, replay reconstructs \emph{complete}
crossing configurations. Signed coordinates have magnitudes at
most $S+O(1)$ relative to fixed work origins.

For each accepted run choose the leftmost gap cut with the fewest
crossings $C_c$; then $C_c\le H/G_m$. Let $\gamma(z)$ be Elias gamma
coding of a positive integer, with
$|\gamma(z)|=2\lfloor\log_2z\rfloor+1$.
If $L=D+C_c$ and
$w_U(S)\le c_U(1+\log_2(S+2))$
bounds a tagged work-change or crossing event, encode
\[
\gamma(S+1)\ \Vert\
[c]_{\lceil\log_2G_m\rceil}\ \Vert\
\gamma(L+1)\ \Vert\ \text{all $L$ ordered events}.
\tag{2}
\]
The event tags specify type-dependent fixed widths after reading
$S$. This is prefix-free for fixed $U,m,k$ and its bit length obeys
\[
\ell\le|\gamma(S+1)|+\lceil\log_2G_m\rceil+
|\gamma(L+1)|+Lw_U(S),\qquad
L\le D+\lfloor H/G_m\rfloor .                          \tag{3}
\]

\begin{theorem}[Heterogeneous per-run density; restricted]
For every fixed $m\ge4$ there is a set
$\mathcal H_m\subseteq\{0,1\}^m$,
$|\mathcal H_m|\ge3\cdot2^{m-2}$, such that
\[
\forall a\in\mathcal H_m\ \forall p\in\mathcal P:
\ U(p\#X_a)\downarrow\mathrm{accept}
\Longrightarrow\ell(U,p,X_a)\ge m-2.                  \tag{4}
\]
No common resource ceiling or count of left-inline programs is
assumed. If the runs being compared are polynomial-time
$T\le N_m^K$ for one fixed finite $K$ (hence $S\le k(T+1)$),
the \emph{same runs} satisfy
\[
\boxed{(D+1+H/G_m)(1+\log(S+2))=\Omega(m),}
\tag{5}
\]
\[
\boxed{D+H/G_m=\Omega(N_m/\log^2N_m).}                 \tag{6}
\]
In particular any of these runs with
$D\le N_m^{1-\epsilon}$, fixed $\epsilon>0$, has
$T\ge H=\Omega(N_m^2/\log^2N_m)$.
These statements concern the EASY sequential promise, not
ordinary all-input indexed SAT.
\end{theorem}
\begin{proof}
Equality of the full binary code (2) determines the same cut,
the same order of all work changes and the same full control,
direction and all work-head coordinates at each crossing.
Blank-map replay yields equal complete crossing histories.
If distinct diagonals possessed the same code, splicing their
accepted left/right subcomputations would accept at least one
crossed UNSAT source. The original selected program on the
\emph{left} is preserved, remains eligible and globally sound
by (1), contradiction. This does not require equal $S,D,H$,
equal programs or common resource ceilings.

Therefore the sets of codes available to distinct diagonals
are disjoint. For each diagonal with an eligible accepting run
choose any shortest code (finite integer length). The
self-delimiting grammar is prefix-free, hence fewer than
$2^{m-2}$ different codes have length below $m-2$.
At least $3\cdot2^{m-2}$ diagonals have no such run.
Diagonals with no eligible accepting run satisfy (4) vacuously.
Polynomial $T$ makes $S,H,D$ polynomial in $N_m$, so the
gamma headers and $w_U(S)$ are $O_K(\log N_m)$.
Now use (3), $m=\Theta(N_m/\log N_m)$ and
$G_m=\Theta(N_m)$ to derive (5)--(6).
Sublinear-power $D=o(N_m/\log^2N_m)$ then forces the
claimed travel/time bound. All terms belong to the same run.
\end{proof}

\section{Adversarial finite controls}
\begin{counterexample}[Omitting a cached bit]
The finite tagged DISJ promise comparator places a fixed mark
at work cell zero, uses the work-head displacement as a unary
module counter, and carries the latest Alice bit in finite
control while traveling across the middle gap. The two
SAT diagonals $(a,b)=(0,1)$ and $(1,0)$ for $m=1$ have
identical edit/crossing records if the label only records the
named phase \texttt{FIND\_R} and omits the cached Alice bit.
After the full phase/cache pair is encoded, the two records
are distinct. Hence a nominal $q$ must include \emph{every}
finite cached register, not merely a host-language field
named \texttt{state}.
\end{counterexample}
The standalone stdlib Python finite simulator exhausts the
$1,364$ separated input pairs for $m\le5$, then all
$2^m$ SAT diagonals for $m\le8$. It records actual
one-cell moves, reversible head displacement, one
changed marker, complete crossing phases and flags,
and the exact binary code, including gamma decoding.
Tests verify prefix-freeness and injection, cut averaging,
finite no-change epochs, simultaneous changes on two
work tapes, chronology-order sensitivity and blank-start
failure controls. Exactly 1,887,198 deterministic checks
passed, zero failures, with no randomness.
The finite source is \emph{tagged tokens}, not a complete
ordinary fixed-width 3CNF parser; it only tests the
event-code protocol and a concrete sound EASY-promise
machine. Reproducing finite tests is not an asymptotic proof.
