\begin{abstract}
In a restricted online-context model with one read-only sequential source head starting at a source-independent position, a complete $L$-bit retained state and $t$ independent source signs spaced by $g$ bits, the exact optimum worst-case input-head movement for all subsequent singleton SAT-context queries is
\[
 H_{\min}=\max\{0,\lceil g(t-L-1)/2\rceil\}.
\]
Preprocessing and decoding may be arbitrary deterministic computations. This is an \emph{input-head movement} result, not a full-step SAT-runtime lower bound. If preprocessing chooses the source-head location adaptively, its address must be counted. Indexed RAM reads and writable re-encoding escape the sequential-head hypothesis. Independent referee review is pending; P versus NP remains OPEN.
\end{abstract}

\section{BUILD: formula and machine}
For $s\in\{0,1\}^t$, let
\[
 A_s=\bigwedge_{j=1}^t(z\vee(a_j\oplus s_j)\vee b_j)
 \land\bigwedge_{j=1}^t(\neg z\vee c_j\vee d_j),
\]
where $a_j\oplus s_j$ means literal $a_j$ if $s_j=0$ and its negation otherwise. Future context
$B_i=\neg a_i\land\neg b_i\land\neg c_1\land\neg d_1$ forces $z=0$ and reduces the $i$th left clause to $s_i$. Therefore
\[
\operatorname{SAT}(A_s\land B_i)\iff s_i=1.
\]
All unqueried $A_s$ are satisfiable. These are proper connected 3CNF sources, not claimed to be strict signed exact-$(2,2)$. The unit context can be converted to proper 3CNF with charged gadgets.

Encode the public formula template in fixed-width binary fields: $t$ sign bits occupy positions $p_j=p_0+(j-1)g$ with $g=\Theta(\log(t+2))$, all other bits fixed, and total $N=\Theta(t\log(t+2))$. In the reproducible serialization the sign record is $01\Vert{\rm bin}_d(j)\Vert101\Vert s_j\Vert011$, $d=\lceil\log_2(4t+3)\rceil$, $g=d+9$, plus a public header and deterministic tail. This is a lossless fixed format, not literal DIMACS.

Preprocessing before seeing $i$ retains a \emph{complete} fixed-length $L$-bit noninput configuration. One read-only input head starts at a source-independent position $p$. The arbitrary deterministic adaptive online continuation receives index $i$, must answer exactly, and may move that source head at most $H$ cells. Temporary working memory is allowed and charged separately. Each independent query restarts at the same prepared configuration; reuse/reset costs must be charged for an interactive stream. All persistent information, caches, work-head positions and control bits must be included in the declared configuration budget, with fixed machine control treated as constant. No uncharged source copy or oracle is granted.

\begin{theorem}[Exact fixed-start storage/head frontier]
For $0\le L\le t$ in the specified model, the minimum possible worst-query source-head travel is
\[
\boxed{H_{\min}(t,L;g)=
\begin{cases}
\lceil g(t-L-1)/2\rceil,&L<t,\\0,&L=t.
\end{cases}}
\]
\end{theorem}
\begin{proof}
All source bits read by a decoder making at most $H$ head movements lie in the fixed radius-$H$ window around $p$. The window contains at most $r=\lfloor2H/g\rfloor+1$ independent sign fields. If two inputs have identical retained $L$-bit states and identical window signs, all future query transcripts, irrespective of adaptive choices, are equal. Since all query answers recover the original $t$-bit $s$, the map $s\mapsto(m_s,s|_W)$ must be injective: $2^t\le2^{L+r}$. Therefore $2H\ge g(t-L-1)$. Conversely, store the first $L$ literal signs, start the source head at the integer midpoint of the remaining source sign positions, and for each future query use the stored bit or move directly to the requested sign. This meets the displayed ceiling; all source scanning, storing, index parsing, and moving steps are nonzero and charged separately.
\end{proof}

\begin{theorem}[Source-dependent initial position]
If the starting input-head position $p_s$ may depend on the source, while all other persistent configuration bits are included in $L$, then every exact all-context deterministic decoder satisfies
\[
\boxed{t\le L+\lceil\log_2 N\rceil+
\lfloor2H/g\rfloor+1+O(1).}
\]
For $h$ read-only heads, conservatively charge $h\lceil\log_2N\rceil$ position bits and $h(\lfloor2H/g\rfloor+1)$ visible sign bits.
\end{theorem}
\begin{proof}
The map $s\mapsto(m_s,p_s,s|_{W(p_s,H)})$ is injective because those data simulate all later query answers. There are at most a fixed finite-control factor times $2^L N2^{\lfloor2H/g\rfloor+1}$ possible encodings. Count them.
\end{proof}

\section{Resource ledgers, re-encoding controls, value}
The literal-prefix scheme takes at most $2N$ preparation input-head movements. A conservative fixed multitape implementation uses $O(N^3)$ total transitions per construction/query phase and $L+O(\log N)$ writable cells, besides the physically present $N$-bit read-only source. A conservative single-read/write-tape simulation takes $O(N^4)$ time and $O(N)$ total visited footprint \emph{including input}. These are implementation upper bounds, not exact native exponents, and a fixed universal machine introduces further polynomial overhead. Charge any query resets, failed policies, output, memory updates, and work-tape operations.

On an indexed bit-RAM, the source-present singleton query computes the fixed sign address and probes it once in $O(\operatorname{polylog}N)$ bit operations and $O(\log N)$ auxiliary bits. This invalidates any general RAM transfer. On a writable input tape, $t$ sparse signs can be copied into a dense prefix, using at most $t$ changed input cells, $O(tN)$ preprocessing head movement, and the same counted $N$-cell source footprint; future sign gap is $g'=1$. The read-only unchanged-layout hypothesis is then false, as required.

For certified knowledge $K$ and target $W$, a distinct, explicitly defined support potential is $\Phi_W(K)=\log_2|\{\pi_W(s):s\models K\}|$, with contextual score
\[
v_\Phi(I\mid s,K,W)=\Phi_W(K)-\Phi_W(K\cup\{I\}),
\qquad (I)\mid_v.
\]
This is not Shannon entropy or measured running-time progress. For target $x$, XOR shares $(x\oplus r=1)$ and $(r=1)$ each score zero alone but one after the other; duplicate information scores zero. Costs to acquire, certify, apply or compute scores are not free, and net scores can be negative. Benefits of correlated facts are not summed.

\section{Reproduction and limits}
An independent checker exhaustively verifies all 34 four-pin $(t,s,i)$ cases for $t=1,2,3$, tests 29 discrete frontier settings for $t=4,8,16,32,64$, five writable-source re-encoding controls and XOR-share synergy/redundancy. At $(t,L)=(64,32)$, $N=2384$ source bits, $g=18$ and $H_{\min}=279$ input-head moves; returning the head to its prepared position can cost another 279. The GitHub checker is a smaller independent control; a separate downloadable local Python reproducer records more detailed data. This is COMPUTATIONAL evidence, not a machine-checked proof.
