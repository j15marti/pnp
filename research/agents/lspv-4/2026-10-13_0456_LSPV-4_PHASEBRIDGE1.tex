\section*{Exact model and quantifiers}
Inputs are strings \(x\in\{0,1\}^N\) in one fixed self-delimiting encoding.
The machine is a uniform deterministic random-access word RAM with
\(\Theta(\log N)\)-bit words. Input reads, buffering, simulation, table
storage, reconstruction, and output are charged. Let \(L\subseteq\{0,1\}^*\)
be decidable, let \(A\) be any total deterministic decider of \(L\), and let
\(W\subseteq[N]\) contain \(k\) source positions. The P-vs-NP application
uses the fixed NP-complete signed Monotone \(3\)-SAT-\((2,2)\) core, but the
negative theorem applies to every decidable language.

For a formula encoding \(F\), semantic compatibility is external:
\[
H(F,\alpha)=1 \iff F\upharpoonright\alpha \text{ is satisfiable}.
\]
The decider's contract is only the single bit \(\operatorname{SAT}(F)\).
Recovering all values of \(H(F,\cdot)\) is a stronger output problem and
cannot be assumed to occur internally.

\section*{SOURCE-COVERAGE-NO-SEMANTIC-CHARGE1}
\textbf{Theorem (\PROVED, independent review pending).}
For every \(A,L,N,W\) as above there is an extensionally equivalent uniform
deterministic decider \(B_{A,W}\) that, before reading \(W\), simulates
\(A\) on all \(2^k\) virtual completions and stores their output bits. It
then reads \(x|_W\), selects the corresponding bit, and returns it. Its costs
are
\[
T_B(N)=O\!\left(N+2^kT_A(N)+2^k\right),\qquad
S_B(N)=O\!\left(N+S_A(N)+2^k+\log N\right).
\]
After the final source read, \(B\) uses \(O(1)\) word operations when
\(k=O(\log N)\), or \(O(k)\) bit operations.

\paragraph{Proof.}
Read and buffer positions outside \(W\). For each
\(\beta\in\{0,1\}^k\), simulate \(A\) while answering probes in \(W\) from
\(\beta\) and all other probes from the buffer. Totality makes each
simulation halt. The table entry at \(\beta\) is \(L(x^{(\beta)})\).
After reading the actual \(\beta^\star=x|_W\), output its entry, which is
\(L(x)\). Sequential simulation reuses the \(A\)-workspace, yielding the
claimed bounds. \(\square\)

\paragraph{Bridge consequence.}
Assume SAT is in P with an arbitrary exponent \(K_A\). For
\(k\le c\log N\), the compiler remains polynomial but retains \(K_A+c\).
Thus it produces no fixed-exponent contraction into an unconditional
time-space lower-bound region. More strongly, an implication of the form
\[
\forall A\;\exists F:
\operatorname{work}_{A,F}(\text{after complete source coverage and before
output})>N^d
\]
is false for every decidable language. A whole-execution statement is not
refuted; it is simply the desired lower bound itself.

\paragraph{Compatibility consequence.}
The source buffer plus the final \(k\) bits extensionally determines \(F\),
so an external extractor may separately compute \(H(F,\alpha)\). That
computation must be charged and may retain the arbitrary solver exponent.
Nothing in the actual suffix of \(B\) evaluates \(H\), materializes a
compatibility graph, produces a witness, or reconstructs a proof. Hence
source availability is not solver-paid semantic exposure.

\paragraph{Wrapper gauge and SAME\_REALIZATION.}
An equivalent DELAY wrapper can place \(N^p\) dead steps after the final read
for any fixed \(p\), while the cofactor wrapper leaves only lookup/output.
Late-phase work is therefore presentation-dependent. The compiler preserves
the same input/output realization but intentionally changes the internal
trace; this is enough to refute a universal claim over all deciders, not to
claim that \(A\)'s original trace was normalized.
