\section*{Declared native indexed-input portfolio model}

\begin{theorem}[Space-capped persistent block dovetailing]
Let $I_B(x)=\{i:S_{A_i}(x)\le B(N)\}$ for input $x$ of bit length $N$, and if nonempty let $\tau(x)=\min_{i\in I_B(x)}T_{A_i}(x)$. The uniform block portfolio $P_B$ runs the guests sequentially in persistent blocks of $1,2,4,\ldots$ additional steps per stage. It freezes a guest on its first attempt to exceed $B(N)$ writable/index cells. On every input with $I_B(x)\ne\emptyset$ it returns the correct SAT/UNSAT/malformed label and satisfies
\[
T_{P_B}(x)=O_m\!\left(N+C_B(N)+\tau(x)+B(N)\bigl[1+\log_2(\tau(x)+1)\bigr]\right),
\]
\[
S^{\mathrm{all\ phase}}_{P_B}(x)
=O_m\!\left(B(N)+\log(N+\tau(x)+2)\right).
\]
On other inputs it may return \texttt{UNRESOLVED}; it is not an all-input SAT decider without a separate complete fallback.
\end{theorem}
\begin{proof}
Let $R$ be the first stage with $2^{R+1}-1\ge\tau$. A feasible winning guest finishes by stage $R$. Each of the $m$ guests executes at most $2^{R+1}-1<2(\tau+1)$ steps, including failed attempts and aborted computation. At most $m(R+1)$ context switches occur, each fully charged $O(B)$ for index save/restore and head movement. Initially scan input length in $O(N)$ native time with $O(\log N)$ writable space; compute the budget at its stipulated costs. Dedicated retained work tapes, saved index tapes, one active index tape and stage/source counters occupy $(m+1)B+O_m(\log(N+\tau+2))$ cells at all times. No $N$-bit writable input copy is assumed. Because each fixed guest is total and correct, a guest's halting label is sound. If all guests exceed the cap there is no such label; returning unresolved is necessary for this procedure.
\end{proof}

\begin{theorem}[Explicit totality falsifier]
For any fixed correct total CNF decider $E$, the uniform decider $A^{\rm pad}$ that first allocates and retains $2N$ writable cells and then runs $E$ is still correct on both labels and malformed strings. But a finite portfolio consisting only of such deciders has $I_{\sqrt N}(x)=\emptyset$ for every sufficiently long input. It is not a sound total yes/no square-root-space solver. Adding an exhaustive fallback that itself materializes an $N$-bit writable buffer gives all-phase $\rho\ge1$ in that realization even if it frees the buffer before child calls.
\end{theorem}
\begin{proof}Padding does not alter the return value; the $2N$-cell initial live array exceeds $\sqrt N$ before any answer. This is an implementation-specific falsifier, not an unrestricted SAT space lower bound.\end{proof}
