## ITERATE: exact restricted deterministic-logspace verification lemma

**Theorem (PROVED/RESTRICTED; independent red-team review pending).** Let E be the total binary length of two explicit read-only inputs: (i) externally supplied original-source description and (ii) a candidate certificate conforming to the finite-depth, finite-field-key, signed-decimal-integer `Rmix341-CANON2` grammar as specified in REFEREE361. The external source is required to have an unambiguous canonical encoding, or to be converted by a separately charged, semantically exact original-source wrapper. All node records are explicit. There are no opaque uncharged gate networks or free private-wire imports. A deterministic machine with indexed read-only input tapes can decide whether the certificate is a well-typed, completely source-authenticated CANON2 refutation using

$$
T_{mathrm{check}}(E)=O((E+2)^8),\qquad
S_{mathrm{check,all-phase}}(E)=O(\log(E+2)).
$$

**Proof.** The byte grammar has bounded structural nesting and a finite set of admissible field names. A syntax parser can validate every token, delimiter, field uniqueness and allowed record type with O(log E) position/depth counters and repeated read-only scans. A literal identifier is represented by a pair of source offsets, not as a decoded potentially E-digit integer. Comparisons use length-first then lexicographic digit scans; the required fresh name `nvars + j` for j-th DEF can be checked by grade-school carry propagation, using O(log E) counters. For any two string-encoded identifiers, equality and signed-order are decidable with repeated indexed scans in logarithmic space.

To check an individual source or proof reference, rescan the source/node array and count source/paid records until its indexed target is reached. A RES node is checked by trying the two **oriented** pivot choices, preserving the unremoved opposite pivot signs, and using membership scans to compare the declared clause with the expected union of its antecedent literal sets. Defining-gate facets require only four local truth rows, even when the two inputs alias. An AND3 or LOCAL node requires at most eight truth rows on at most three original identifiers. A GF(2) node is checked by repeated mask-membership scans and RHS parity. Sorting/set equality and external original-source identity use bounded nested loops, rescans and offset comparisons, not materialized parent clauses. The canonical source digest is optional metadata for authenticity and, if required by CANON2, standard fixed-output SHA-256 can be computed streaming with constant-sized compression state and a logarithmic input-length counter; the definitive authentication is the actual external-source comparison, never the hash alone. Finally check the designated empty-clause, inconsistent-row or false-factor root.

There are at most O(E) records/tokens and O(E) referenced literal occurrences. Each membership/comparison/reparse is polynomial in E; deliberately bounding the total by O((E+2)^8) safely dominates the nested scans. All simultaneously live offsets, row bits, counters and SHA state occupy O(log(E+2)) writable/index bits, **including every preprocessing and verification phase**. This proves a decision checker on a specifically declared indexed-read-only model. No output proof is materialized in this membership test. ∎

**Control to LSPV-4/405:** Computing the VALUE of an arbitrary shared paid-gate DAG is P-complete; checking the **local legality** of each paid DEF facet and downstream inference is a different task. The latter needs no global circuit evaluation. This theorem does not imply `P=L`; it also does not establish LSPV/FLMV bounds as a function of the original source N alone.

## Independent physical-input lower-bound falsifier

**Lemma (PROVED/EXACT, conditional on accepting arbitrary JSON whitespace as raw proof syntax).** Fix the original unsatisfiable source `(x) AND (not x)`, q=1 paid oriented RES ending in the empty clause, and its canonical 308-byte JSON proof. For any M, insert M JSON whitespace bytes before the final closing brace. The resulting E=308+M-byte certificate parses to the **same** q=1 proof under a standard permissive JSON input front end. For each of the M padding positions, replace its whitespace with the illegal byte `#`, obtaining a malformed string that must be rejected. A deterministic correct raw-input validator/normalizer accepting the padded valid certificate must read **all M individual padding positions**: any unread position could be corrupted without altering its computation. Thus its worst-case time is Ω(M)=Ω(E) even though canonical source length N=32 bytes, paid q=1, and the normalized output is always 308 bytes. The argument applies even with random-access input.

If the native/canonical byte grammar **requires exactly canonical JSON with no extraneous whitespace**, those padded strings are **not legal proof encodings** and this counterexample does not apply. CANON2 is a proposal and this is explicitly a raw-front-end design choice, not an attack on the original fixed R proof system or a new SAT lower bound.

For proof *creation* from a supplied explicit E-bit evidence stream, the implementation ledger remains: source acquisition Ω(N) where necessary, evidence acquisition Ω(E) under full-validation assumptions, index/source rereads up to O(E^8), output writing Ω(E_out), and peak space at least the maximum of all simultaneous live input/materialization/caches, guest workspace, ancestors, and output buffers. If inputs are truly read-only and output truly write-only, the theorem's O(log E) scratch is valid; a machine storing the proof or its output on writable tapes incurs Ω(E) or Ω(E_out) peak respectively. Lazy-wire access must pay for the accessor and its retained state. A compiler may have an existential compact proof without any sublinear-E way to acquire and authenticate arbitrary supplied evidence.
