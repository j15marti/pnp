\section{New restricted cofactor physical-length theorem}
Declare the fixed-slot ordinary CNF source/child encoding with $n$ active variable IDs, $m=4n/3$ proper three-literal original clauses, $w=\lceil\log_2(n+2)\rceil$ signed-ID bits, $B=2+3(w+1)$ bits per source clause slot (arity plus three signed-ID fields), and fixed $H=16+2w$-bit header, total $N=H+mB$. Plain restriction deletes clauses made TRUE by a global partial assignment, retains every other clause as an exact shorter/unit/empty padded record, and does no global normalization.
\begin{theorem}[Signed22 cofactor deletion barrier, restricted]
If exactly $t$ original Boolean variables are pinned, the number $D$ of removed original clauses obeys $D\le2t$, and its physically encoded plain-cofactor length is
\[
N_\rho=H+(m-D)B\ge N-2tB.
\]
Thus, for any fixed $0<\lambda<1$, $N_\rho\le N^\lambda$ requires
\[
t\ge\frac{m}{2}-\frac{N^\lambda-H}{2B}
=\frac{2n}{3}-O(N^\lambda/\log N)=\Omega(n).
\]
In particular, $t=o(n)$ leaves $N_\rho=\Theta(N)$. This does not rule out semantic compilers, global easy-class recognition or different encodings.
\end{theorem}
\begin{proof}Each fixed strict22 variable has exactly two original literal occurrences made TRUE by its chosen value, in distinct source clauses because every source clause is proper. Every deleted clause contains one of these TRUE occurrences. Their union contains at most $2t$ original clauses. Multiply the remaining record count by $B$. Since $N=\Theta(n\log n)$ and $B=\Theta(\log n)$, the remaining inequalities follow. A clause merely shortened or falsified is not deleted.\end{proof}
Naive full binary cofactor enumeration to this depth has $2^t$ leaves in the absence of certified pruning or merging. This is an architecture-specific accounting fact, not an all-algorithm SAT lower bound. Previous LSPV-4 ARC-VIRTUAL-DELTA-SAME-SCALE112 already established that a short edit \emph{descriptor} cannot be substituted for the ordinary guest input length; ARC-LINEAR22-SATURATION1 likewise provides an easy globally recognizable family despite local elimination expansion.

\section{Conditional child setup/access and actual space}
Assume, \emph{without claiming to construct it}, a single uniform total correct arbitrary-$A$ SAT successor with $q(N)\le N^{\gamma+o(1)}$ ordinary children of physical length at most $M(N)\le N^{\lambda+o(1)}$. The entire local discovery, child output, failed trials and source/index preparation use $N^{\alpha+o(1)}$ time. Per-child additive setup takes $N^{\delta+o(1)}$ steps, whereas a virtual-child-bit accessor can add a \emph{multiplicative} $N^{\varepsilon+o(1)}$ overhead per guest machine step. Let parent/child/ancestor/work-tape retained space have exponent bound $\sigma$, except for additional cache exponent $\rho$.
\begin{theorem}[Conditional ledger, not a compiler]
For a serial physically simulated guest $A$ with simultaneous guest bounds $(K,L)$, the supported abstract resource inequalities are
\[
K'\le\max\{\alpha,\gamma+\delta,\gamma+\varepsilon+\lambda K\},
\quad L'\le\max\{\sigma,\lambda,\lambda L,\rho\}.
\]
Writing fresh $q$ children each of size $\Theta(M)$ costs $\Omega(qM)$ bit writes. Keeping that entire \emph{full-sized} batch in disjoint readable work slots costs $\Omega(qM)$ writable bits. Neither lower bound follows merely from the stated upper bound $|child|\le M$ if children are much shorter or shared; all occupancy assumptions must be checked.
\end{theorem}
\begin{proof}Sum the $q$ additive setups and $q$ slowed guest calls, plus local source work. Sequentially release child writable contents, while charging the largest still-live ancestor, indices and guest work. For a full-sized disjoint batch, count the written/retained physical bit slots. An FLMV write-only output tape is not a free reusable readable input tape.\end{proof}
For $(\alpha,\gamma,\lambda,\sigma)=(11/10,3/5,1/2,1/2)$, $L'=\max(1/2,L/2)$ requires $\rho\le1/2$. With $\varepsilon=0$ and additive $\delta\le1/2$, the proposed formal time map is $K'=\max(11/10,3/5+K/2)$. An additive per-child $N^{3/5}$ preparation changes the local time ceiling to $N^{6/5}$, but keeps the same $6/5$ fixed point: this is \emph{not} an $N^{3/5}$ multiplicative guest-step slowdown. A multiplicative $\varepsilon>0$ yields fixed time $6/5+2\varepsilon$, requiring $\varepsilon<1/400$ for entry at $c=241/200$, or $\varepsilon<(c_{1/2}-6/5)/2\simeq0.0027847152$ after optimizing nearby $c$. Equality does not cross the strict FLMV border. Eagerly caching $N^{3/5}$ full $N^{1/2}$-bit children would use $N^{11/10}$ writable space, not $N^{1/2}$. A padded full-parent guest remains noncontractive. These are \textbf{CONDITIONAL} arithmetic results, not a proof of $\Phi$.
