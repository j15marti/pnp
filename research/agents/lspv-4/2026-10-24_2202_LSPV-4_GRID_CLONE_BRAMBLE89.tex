\section{Scalable connected proper-3CNF SAT and UNSAT controls}
Fix $r\ge2$. Let $G_r$ be the $r\times r$ grid on variables $x_{ij}$, with $e=2r(r-1)$ edges. For each edge $uv$ make one fresh variable $z_{uv}$ and the proper ternaries
\[
(u\vee v\vee z_{uv})\wedge(u\vee v\vee\neg z_{uv}).\tag{1}
\]
Add fresh $a,b,c,y$ and $(a\vee x_{11}\vee y)\wedge(a\vee x_{11}\vee\neg y)$. Let $Q_U(a,b,c)$ be the eight possible signed proper ternaries on the three variables. Let $Q_V$ replace the positive clause $(a\vee b\vee c)$ in $Q_U$ by a duplicate of $(\neg a\vee b\vee c)$. Define $U_r$ and $V_r$ by adjoining $Q_U$ and $Q_V$, respectively, to the common grid and bridge clauses.

The original source contains no functional auxiliaries. All $e+1$ variables $z_{uv},y$ are free when their binary bases hold. All clauses are proper triples even though one entire clause is intentionally duplicated in $V_r$. Both source primal graphs are connected, with maximum vertex degree at most eight and clique number exactly three; no variable appears more than ten times.

With two fixed-width header records and four signed-literal records per clause,
\[
 n=3r^2-2r+4,\quad m=4r(r-1)+10,\quad
 h=\lceil\log_2(64(n+m+1))\rceil,\quad N=(4m+2)h
 =\Theta(r^2\log r).\tag{2}
\]
Both labels share exact $n,m,N$; changing one clause sign leaves encoded length and identifiers unchanged.

\begin{theorem}[Exact model count and witness, PROVED/EXACT]
Let $I_r^\star$ be the number of independent vertex sets of the grid avoiding $(1,1)$. Then
\[
 \#\mathrm{SAT}(U_r)=0,\qquad
 \#\mathrm{SAT}(V_r)=2^{e+1}I_r^\star>0.\tag{3}
\]
\end{theorem}
\begin{proof}
The eight signed clauses reject every assignment to $(a,b,c)$, proving $U_r$ unsatisfiable. The seven distinct remaining clauses in $V_r$ force $(a,b,c)=(0,0,0)$; its bridge then requires $x_{11}=1$. Eliminating each $z_{uv}$ imposes $u\vee v$, so the grid zero-set is an independent set not containing $(1,1)$. Each such assignment leaves all $e+1$ private variables free. In particular all grid variables one, core zero, and all auxiliaries zero is a directly verifiable satisfying witness.
\end{proof}

\section{An elementary grid-cross lower bound, not an SAT runtime bound}
A valid source-preserving scoped stream opens each named source variable once, closes it once, and emits every original clause unchanged while all its variables are live. Independent satisfiable padding may be appended or interleaved. The width $w$ is the maximum number of simultaneously open variables.

\begin{theorem}[Source-name preserving width, PROVED/EXACT restricted]
For either label, every such closed stream has $w\ge r$, and an explicitly serialized stream has $w\le2r+1$. In particular $w_{\min}=\Theta(r)$ despite degree at most eight and clique number three.
\end{theorem}
\begin{proof}
Let $I_v$ be the live interval of original grid vertex $v$. Each grid edge occurs in a source clause with both endpoints, so $I_u\cap I_v\neq\varnothing$ for every edge $uv$. For each row $R_i$ and column $C_j$, the cross $X_{ij}=R_i\cup C_j$ is connected; the union $J_{ij}=\bigcup_{v\in X_{ij}}I_v$ is an interval since adjacent intervals intersect. Every pair of crosses intersects at some grid vertex, so their $J$ intervals intersect pairwise. Interval Helly yields a common time $\tau$ in every $J_{ij}$. The grid vertices live at $\tau$ hit every cross. Fewer than $r$ vertices leave some row and some column empty, contradicting hitting their union. Thus at least $r$ source variables are live. For the upper bound process the three-variable signed core, then the bridge, then grid rows successively, holding one row while opening the next, processing each edge with its private $z$ immediately opened and closed, and closing the older row; the peak is at most $2r+1$.
\end{proof}

\section{Connected-copy theorem and explicit equality compiler}
Permit a separate nonempty clone group $H_v$ for each source grid variable $v$. Assume the clone groups are pairwise disjoint, each group induces a connected subgraph of the target CNF primal graph, and every source grid edge $uv$ has a target primal edge joining $H_u$ to $H_v$. Private auxiliaries and arbitrary independent padding are allowed. This is a specific source-coherent variable-splitting calculus, not an arbitrary SAT-equivalent rewrite.

\begin{theorem}[Connected-copy width firewall, PROVED/EXACT restricted]
Every scoped stream for every target satisfying this connected-copy and cross-edge contract has $w\ge r$, irrespective of the number of cloned variables or private auxiliaries.
\end{theorem}
\begin{proof}
Take the union of live intervals for all clones in each $H_v$. Connectedness of $H_v$ and overlap of intervals along each primal edge make this union one interval $J_v$. Each original grid edge is represented by a cross-group target edge, so $J_u\cap J_v\neq\varnothing$. Apply the row-column cross proof above to the $J_v$ intervals. At the common time at least $r$ distinct clone groups have a live variable; disjointness forces at least $r$ distinct live target variables. Private auxiliary intervals can only add to this number.
\end{proof}

A completely explicit ordinary proper-3CNF target is obtained as follows. For every grid vertex $v$ and incident edge $e$ make a copy $v_e$. Each original grid edge $e=uv$ is represented by $(u_e\vee v_e\vee z_e)\wedge(u_e\vee v_e\vee\neg z_e)$. Connect successive copies of the same grid vertex in a path of equalities. One equality link $s=t$ is encoded by
\[
(\neg s\vee t\vee p)\wedge(\neg s\vee t\vee\neg p)\wedge
(s\vee\neg t\vee q)\wedge(s\vee\neg t\vee\neg q),\tag{4}
\]
with two fresh private variables $p,q$. The bridge uses one copy of $x_{11}$, and the signed core is retained. Equation (4) enforces equality, and both padding variables are free whenever it holds. All target clauses are proper triples. Its source-name clone groups are disjoint, connected equality paths, and the original grid-edge incidences remain direct target primal edges.

Let $L=\sum_v(\deg(v)-1)=2e-r^2$ be the number of equality links. Then the exact target ledger is
\[
\begin{array}{ll}
\hbox{clone variables}=2e,&\hbox{grid-private variables}=e,\\
\hbox{equality-padding variables}=2L,&\hbox{core+bridge variables}=4,\\
n'=7e-2r^2+4,&m'=10e-4r^2+10,\\
h'=\lceil\log_2(64(n'+m'+1))\rceil,&N'=(4m'+2)h'.
\end{array}\tag{5}
\]
The number of free auxiliaries is $e+2L+1$, and
\[
\#\mathrm{SAT}(\mathrm{Clone}(U_r))=0,\qquad
\#\mathrm{SAT}(\mathrm{Clone}(V_r))=I_r^\star2^{e+2L+1}.\tag{6}
\]
The clone target still has maximal primal degree eight, maximal clause occurrence ten, and clique number three, and its minimal scope width remains at least $r$.

\begin{theorem}[Polynomial-output floor, restricted]
For any fixed $C$ and any connected-copy source target padded to $N'\le N^C$,
\[
 \frac{w}{\log_2N'}\ge\frac{r}{C\log_2N}
 =\Omega(r/\log r)\longrightarrow\infty.\tag{7}
\]
More generally, attaining $w=o(\log N')$ without violating the connected-copy contract entails $\log N'=\omega(r)$, or $N'=2^{\omega(r)}$.
\end{theorem}
\begin{proof}
Apply $w\ge r$ and $N=\Theta(r^2\log r)$; rearrange the asymptotic width condition. This lower-bounds representation length for this calculus, not decision time.
\end{proof}
