\section{Declared source and child encoding}
Let a valid source have $n$ variables, $m=4n/3$ proper monotone clauses, $w=\lceil\log_2(n+1)\rceil$. Use Elias gamma positive integer headers $\gamma(n)\gamma(m)$ followed by $m$ fixed source records: one sign bit and three $w$-bit source variable identifiers in original clause order. Thus $N=|\gamma(n)|+|\gamma(m)|+m(1+3w)=\Theta(n\log n)$.
For a coherent $k$-pin assignment $p$, delete original clauses with true assigned literals, and remove assigned false literals from the rest. Encode the ordinary raw child with header $\gamma(n)\gamma(m-s)$ and $(m-s)$ records, each with original sign, 2-bit width 0--3, and three $w$-bit ID slots zero-padded to fixed width. An empty clause is UNSAT; an empty entirely satisfied residual is a SAT terminal rather than a recursive child. This is explicitly NOT D\"ocker's language.

\begin{theorem}[Charged virtual raw-cofactor bit access]
For any valid source and coherent $k\ge1$ original-variable assignment yielding a nonempty residual, a deterministic indexed-source bit emitter constructs a directory of at most $4k$ original affected clause IDs and $2k$ original deleted clause IDs by one sequential source pass. For each child output bit it performs sequential scans of at most $O(k)$ directory records and at most one indexed source-bit read. A conservative fixed-tape indexed simulation costs setup $O(Nk\log N)$, each output-bit request $O(k\log N+\log N)$ and retained work/index tape storage $O((k+1)\log N)$. The theorem assumes grammar validity; malformed input validation is not free. This is an implementation upper bound, not a native FLMV transition measurement.
\end{theorem}
\begin{proof}
Each pivot occurs in four distinct source clauses, so at most $4k$ original clauses are affected. Each pivot has exactly two occurrences of the sign made true, so at most $2k$ original clauses are deleted. A sequential source scan parses each record, scans the $k$ pinned names, and stores the source-indexed kept-slot masks and deleted indices. Let $d_0<\cdots<d_{s-1}$ be deleted clause indices. The source index for surviving child clause $j$ is $j+a$, where $a$ is the number of indices $i$ satisfying $d_i-i\le j$. Its original sign and retained literal slots follow from the stored mask. Each actual output sign/identifier bit is either a constant (header, width, padding), or exactly one bit of the original input record. Preparing binary indexed addresses, head moves and erasures are charged in the bounds. This emits exactly the direct raw cofactor. Shannon restriction preserves both SAT and UNSAT \emph{conditionally on the assigned branch}, $F|p\in\mathrm{SAT}\iff F\land p\in\mathrm{SAT}$; it does not preserve $F$'s full label branch-free.
\end{proof}
\begin{theorem}[Necessary multi-pin canonical completion count]
Suppose $k$ source names are pinned, $s$ original clauses are satisfied/deleted, and $e$ additional unassigned names disappear, leaving $r=n-k-e$ active source names and $m-s$ shortened clauses. Any valid canonical target \emph{completion} retaining all surviving clauses and literal occurrences, padding short clauses, and adding $z$ new/reintroduced names and $c$ new clauses satisfies
\[
\boxed{3c-4z=3s-4(k+e)}.
\]
\end{theorem}
\begin{proof}Target quotas and ternarity give $3(m-s+c)=4(r+z)$ and $3m=4n$. Substitute $r=n-k-e$ and rearrange. This is only necessary, not sufficient for exact signed deficits, duplicate-freedom, pin binding or equisatisfiability. At $k=1,s=2,e=0$ it recovers REF255's $3c-4z=2$.\end{proof}
By the earlier exact source-survivor bound, $r\ge n-2k$. Hence $k=o(n)$ pins cannot yield a source-identity-preserving canonical $N^\lambda$-bit child for a fixed $\lambda<1$, even with polylogarithmic source-bit access. A declared explicit $\Theta(k\log N)$-bit directory with $k=\Omega(n)$ itself needs $\Theta(N)$ writable bits and misses $\sigma=1/2$. This is a restricted architecture limitation, not a lower bound on compressed descriptors, semantic re-encoders or arbitrary SAT machines.
