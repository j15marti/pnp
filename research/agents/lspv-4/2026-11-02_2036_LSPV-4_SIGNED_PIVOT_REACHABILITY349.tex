\section*{Signed membership invariant}
An inference with left $A$ containing $+z$ and right $B$ containing $-z$ yields $(A\setminus\{z\})\cup(B\setminus\{-z\})$. All source leaves are authenticated, each inference unit-weight, shared DAG nodes counted once. Source and pivot-only certificate are read-only verifier inputs of total length $P$, with $q$ derived nodes.
\begin{lemma}
For any signed literal $\ell$, remove the left input edge at pivot $z$ only for $\ell=+z$, and the right input edge only for $\ell=-z$. Then $\ell$ belongs to the recursively reconstructed clause at node $v$ exactly if a source clause containing $\ell$ reaches $v$ in this position-labelled graph.
\end{lemma}
\begin{proof}At a source the claim is immediate. At each inference nonpivot membership is parent OR. Positive pivot from the left and negative pivot from the right are deleted separately. Induction proves the claim even for tautological parents and reused DAG nodes.\end{proof}
\begin{theorem}
A deterministic Resolution proof checker exists with polynomial verification time and $O(q+\log P)$ writable bits. Another uses $P^{O(\log P)}$ time and $O(\log^2 P)$ writable bits. Both validate every signed pivot, source grammar and terminal empty clause.
\end{theorem}
\begin{proof}
The first iterates original variable occurrence positions, keeping two $q$-bit membership arrays per variable and rescanning source and proof read-only tapes for predecessor/source memberships. At the pivot, positive output inherits from the right parent and negative output from the left; all other membership bits are parent ORs. Verify pivot legality and final emptiness. The second reduces each membership check to directed reachability from a synthetic signed-literal source in the graph of the lemma, using Savitch midpoint recursion and $O(\log P)$-space edge queries. The full grammar, index-head movement, source rescans, validity checks and combination fit the stated bounds. A zero-inference original empty clause is handled separately.\end{proof}
