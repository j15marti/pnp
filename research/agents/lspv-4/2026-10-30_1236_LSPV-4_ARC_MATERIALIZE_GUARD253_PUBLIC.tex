\section{New restricted theorem: far-index input head}
\begin{theorem}[Naive materialization is not arbitrary-guest space preserving]
Assume a correct uniform polynomial ordinary SAT decider $B$ exists. For each fixed integer $D\ge2$ form a correct polynomial SAT decider $A_D$ which scans input length $m$, writes $p=2^{D\lceil\log_2m\rceil}\ge m^D$ on its read-only \emph{input} index tape, performs and ignores one blank read at $p$, indexes back to the beginning, and runs $B$. The extra time is polynomial and the extra writable space is $O(D\log m)$. An emulator which copies the guest's length-$m$ input onto an indexable \emph{work} tape and blindly redirects that far guest input indexed move to the child work tape consumes at least $p\ge m^D$ charged workspace. There is no guest-uniform $O(m+S_B(m))$ space upper bound for that naive emulation.
\end{theorem}
\begin{proof}
On a read-only input tape the far head position does not contribute to writable space, and the read beyond the finite input returns blank. The ignored read changes neither SAT nor UNSAT correctness. The guest's input index tape has $O(D\log m)$ occupied bits, but an indexed read at position $p$ on the substituted work tape contributes position $p$ to the model's space measure, regardless of the blank symbol there. Choose $D$ greater than the polynomial space exponent of $B$ to contradict the claimed uniform bound.
\end{proof}
A \emph{necessary} repair for each guest indexed input request $j$ compares $j$ to the exact physical child length $m$ and returns blank without physically indexing work tape $W$ whenever $j\ge m$; only $j<m$ may index $W[j]$. A guest index tape is erased on each indexed jump, so comparison is charged to the written address bits plus $O(\log m)$, not free. This fixes the displayed jump counterexample. Complete arbitrary-$A$ handling of subsequent ordinary input-head moves, long live pointers, all work/index tapes and amortized simulation remains an independent OPEN machine-transfer obligation; the report does not presume a free complete simulator.
