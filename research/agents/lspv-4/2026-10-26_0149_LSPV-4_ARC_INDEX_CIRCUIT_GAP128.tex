\section{Quantifiers, fixed model, and four falsifiers set before literature search}

$T_A(N)\le N^{t+o(1)}$ and simultaneous writable/index-tape peak $S_A(N)\le N^{s+o(1)}$ in the indexed read-only-input random-access Turing model. Uniformity does not grant an uncharged stored copy of the source, oracle SAT labels, arbitrary input-length advice, or a nonuniform full decision circuit. $P=NP$ gives only an unknown fixed $(K,K)\in E$.

\section{Indexed access versus NAND circuit size}
Let $L=2^k$ and let
$\operatorname{INDEX}_L(a,z)=z_{\mathrm{unsigned}(a)}$,
where $a\in\{0,1\}^k$ and $z\in\{0,1\}^L$.
Here $L$ counts payload bits, \emph{not} the physical ordinary SAT input length $N$.

\begin{theorem}[Indexed-read versus bounded-fan-in circuitization, restricted model]\label{th:index}
An indexed-read-only-input random-access bit-Turing machine decides $\operatorname{INDEX}_L$ in $O(k)$ bit-time and $O(k)$ counted writable/index bits when the fixed-width address and payload layout is known. Every fan-in-at-most-two single-output Boolean circuit for this function, even nonuniform, has at least $L-1$ internal gates. Consequently there is no valid \emph{model-independent} upper bound $O(T\operatorname{polylog}T)$ on circuit gate count using only such an indexed machine's sublinear running time $T=O(\log L)$.
\end{theorem}
\begin{proof}
Read the $k$ address bits, write the selected data index to the counted index tape, read its one data bit, and emit the label. Charge every address write, increment and read: all are $O(k)$ operations and $O(k)$ bits for the fixed layout.

For each $i\in\{0,\dots,L-1\}$, setting $a=i$ and flipping $z_i$ flips the output. Thus the output depends on \emph{each} of $L$ different data-input nodes. Prune a circuit to the subgraph feeding the output, with $g$ internal gates and $m\ge L$ distinct relevant input nodes. The undirected underlying graph is connected and has at least $g+m-1$ edges. Fan-in at most two gives at most $2g$ edges, so $g\ge m-1\ge L-1$. Shared gates and arbitrary fanout do not defeat this count.
\end{proof}
\textbf{Scope safeguard.} The ordinary-tape Pippenger--Fischer theorem is \emph{not} refuted. A circuitization procedure allowed $N$ input-layout work, or applied to machines with $T\ge N$, is consistent with this lower bound. The point is that indexed-input, possibly sublinear access time and gate volume cannot be silently identified.

\section{Explicit proper-3CNF SAT encoding of the index promise}
Build $\Phi_{k,a,z}$ with $L$ leaf variables, $k$ address variables and $L-1$ binary-multiplexer output variables. An asserted literal $\ell$ is enforced by two fresh variables $u,v$ and the four \emph{proper} ternary clauses
\[
(\ell\vee u\vee v),\quad(\ell\vee u\vee\neg v),\quad
(\ell\vee\neg u\vee v),\quad(\ell\vee\neg u\vee\neg v).
\]
For each multiplexer $y=(\neg s\wedge l)\vee(s\wedge h)$ use the four proper clauses
\[
(s\vee\neg l\vee y),\quad(s\vee l\vee\neg y),\quad
(\neg s\vee\neg h\vee y),\quad(\neg s\vee h\vee\neg y).
\]
Fix all $L$ leaf variables to their payload bits and the $k$ shared selector variables to their address bits by the unit gadgets, then force the root output true. No clause contains repeated variables. Every satisfying assignment propagates the unique selected payload value, and each consistent selection extends to an assignment of all auxiliaries, so
\[
\boxed{\SAT(\Phi_{k,a,z})=\operatorname{INDEX}_L(a,z).}
\]
The exact counts are $n=4L+3k+1$ variable names and $m=8L+4k$ clauses. Let
$w=\lceil\log_2(\max\{n,m\}+1)\rceil$,
encode the header as $1^w0\ \mathrm{bin}_w(n)\ \mathrm{bin}_w(m)$,
and every 3-clause as three polarity-plus-$w$-bit-ID records. The physical input length is
\[
\boxed{N=3w+1+3m(w+1)=\Theta(L\log L).}
\]
The sign of data unit-block $i$ occurs first at physical zero-based offset $3w+1+4i\,3(w+1)$. The sign of address unit-block $j$ first occurs at offset $3w+1+(4L+4j)\,3(w+1)$. These are literal-local \emph{promise} selectors. On this fixed-layout family, the source reader obtains $w,n,m$ from the header, computes $k=n-1-m/2$, reads $k$ address signs and one selected payload sign, and decides in $\operatorname{polylog}N$ bit-time and $O(\log N)$ workspace. All header, index arithmetic, control and actual read operations are charged.

Theorem~\ref{th:index} transfers to this proper-CNF \emph{promise} because each of the $L$ disjoint data-sign groups can individually influence the SAT label on different valid promised encodings. Any bounded-fan-in circuit deciding the restricted subfamily must depend on at least one physical input coordinate per group. Consequently its gate count is $\Omega(L)=\Omega(N/\log N)$. This is \emph{not} a lower bound beyond the linear input scale and does not approach the conditional full-decision-circuit threshold $q=811801/561801$.

\begin{lemma}[Off-promise single-bit failure, exact]
Choose a valid promised instance with selected payload bit zero and all other payload bits one. Its physical ordinary SAT encoding is UNSAT. Flip \emph{only} the polarity bit in the \emph{second} clause of the selected leaf's four-clause unit gadget. The result is still a valid proper-3CNF ordinary SAT encoding with identical header, number of variables and clauses, and becomes SAT. The fast promise reader sees the same initial data sign and returns UNSAT.
\end{lemma}
\begin{proof}
With $\ell=\neg z_i$, the four-clause gadget forces $z_i=0$. Flipping one clause's copy of $\neg z_i$ to $z_i$ permits $z_i=1$: of the remaining three binary conditions on $u,v$, each excludes one assignment, so one assignment survives. All other leaf pins and multiplexer clauses extend consistently to root $1$. The selected first sign and every address sign are unchanged; the fixed-layout reader returns its original value. All clauses remain ternary with distinct variables, so this is not a malformed \emph{ordinary SAT} input, merely off the structured promise.
\end{proof}

\section{Two ordinary child levels, and why their contraction is spurious}
For a source already decided by the cheap INDEX promise reader, output an ordinary proper-3CNF constant-label child: a positive unit gadget on a fresh variable if the label is SAT; additionally a negative unit gadget on that same variable if it is UNSAT. Repeat the same construction once to get a genuine second physically encoded ordinary child. On the tested instances, labels agree at both levels, including UNSAT. The encoded child occupies $58$ bits in the positive case and $133$ bits in the negative case under the declared encoding. However the policy \emph{first computed the parent's answer}. Its favorable child-size exponent has \emph{no} all-input ARC implication and cannot be inserted into a recursive time contraction as if the children supplied the answer.

\section{Adaptive-volume ledger, dual access interpretations, and space}
\begin{lemma}[Weighted work and access, conditional]\label{lem:volume}
Suppose a fully specified uniformly correct adaptive construction generates ordinary children of lengths $m_i$, with volume $V=\sum_i m_i\le N^{b+o(1)}$, maximum $M\le N^{\lambda+o(1)}$, and a fixed all-input base solver with $T_A(m)\le m^{d+o(1)}$, $d\ge1$. Charge all local/selection/failed-route/output work in $N^{r+o(1)}$ and suppose every guest simulated step can demand at most $N^{u+o(1)}$ \emph{additional per-probe} generation work. Then, for an implementation with no uncounted fallback or additional calls,
\[
T_{\mathrm{new}}(N)\le N^{\max\{r,\,u+b+\lambda(d-1)\}+o(1)}.
\]
If instead $N^{u+o(1)}$ bounds \emph{the aggregate over all probes}, the bound becomes
$N^{\max\{r,u,b+\lambda(d-1)\}+o(1)}$.
\end{lemma}
\begin{proof}
The elementary inequality $\sum_i m_i^d\le M^{d-1}\sum_i m_i\le N^{b+\lambda(d-1)+o(1)}$ holds term by term, including for adaptively selected lists on each execution. Multiplying by the worst per-probe overhead gives the first bound; adding an independently bounded total lookup bill gives the second. A per-bit exponent and an already accumulated total cannot be used interchangeably.
\end{proof}
For a sequential eager child, actual buffer length $M$, the guest's $m_i^{s+o(1)}$ peak, retained parent/ancestor bits, program/index tape, generator workspace and output fields are simultaneously live and must be charged. An admissible schematic peak exponent is $\max\{\lambda,\lambda s,p\}$ when $p$ \emph{already} upper-bounds all other concurrently live counted objects. For lazy access omit $\lambda$ only if the virtual input is genuinely never materialized, and charge every regeneration read/probe. Two recursive levels contribute their simultaneous active paths, not the product of the two agents' best separate space measurements. If $N^\xi$ sibling answers/certificates are retained, $\xi$ is included in $p$. This accounting alone does not provide a semantic child list.

For \emph{coNTIME}, a guessed UNSAT certificate is legal only if the resulting co-nondeterministic acceptance convention is correct on every input and every relevant branch; its guessed symbols and verification steps still count toward time and any stored certificate bits count toward peak space. A nondeterministically guessed certificate cannot be silently treated as one that a deterministic contractor \emph{finds} or emits for free.
