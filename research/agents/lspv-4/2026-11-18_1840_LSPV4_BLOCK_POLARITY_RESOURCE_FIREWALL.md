## Candidate and falsifiers
The candidate is a one-sided, source-authenticated specialist finding a locally UNSAT block for each fixed shared assignment z, without free SAT/UNSAT advice. Four falsifiers: (1) row aggregation may be OR rather than AND; (2) a SAT instance can admit a genuine bad-block certificate on a particular z; (3) advice, child buffers, seed queries and all z branches may be uncharged; (4) input-length or machine-model normalization may invalidate any alleged FLMV forbidden region.

## Exact quantified factorization (PROVED/EXACT)
For F(z,x)=AND_{j=1}^q B_j(z,x_j) with pairwise disjoint private x_j, elementary Cartesian-product semantics give:
F UNSAT iff ALL z have SOME j for which B_j|z is UNSAT.
F SAT iff SOME z have ALL blocks SAT.
The quantified order and AND grammar are essential. If F=AND_r OR_j B_{rj}, one bad block in one OR row is insufficient: (x AND NOT x) OR y is SAT.

Counterexample family: for t shared bits and q=2^t blocks, let C_u(z) be the unique t-literal clause false at z=u; give each block a private x_u and set B_u=(C_u OR x_u) AND (C_u OR NOT x_u). Let F_U=AND_{u in U}B_u, declaring all private variables even when U omits blocks. F_U is UNSAT iff U contains all q indices. Removing u* produces a SAT formula with exactly 2^q full witnesses (z=u*, all x free), but for every z !=u*, the SAME bad block B_z and same tiny UNSAT evidence remain valid in both full-UNSAT and missing-one-SAT formulas. A single correct path, or a short program describing j(z), does not certify that every z is covered. For arbitrary CNF, even a false original clause for a supplied assignment is a locally UNSAT block after fixing all variables; this is cheap yet does not prove global UNSAT.

## Three distinct algorithms and soundness (PROVED or CONDITIONAL)
**Supplied correct k-bit path:** an untrusted read-only certificate may be verified but cannot be assumed true. SAT witness claims are verified against all source clauses. UNSAT index alone is NOT a sound coNP certificate; authenticate a correct deterministic UNSAT child computation, exhaustive private search, or a genuine sound proof. Wrong paths must REJECT or UNKNOWN, never accept a false label.

**Deterministic one-sided specialist:** for fixed z, sequentially inspect source blocks, materialize or virtually access B_j|z, call a hypothetical total correct deterministic CNF-SAT seed A on EACH attempted block, stop on first UNSAT. Otherwise report all SAT, which for authentic disjoint private sets proves the cofactor SAT. No free polarity routing or answer advice is used. On the original formula, a local BAD(z) is not a global UNSAT answer. Enumerate every z for a total decision; on SAT find one good z and construct all private witnesses.

**Strategy verification:** a proposed map j(z), even a tiny formula/circuit, needs globally authenticated coverage and correct local UNSAT claims. All universal z branches are required, not one existential transcript. For a bounded total sound verifier V(F,a), deterministic enumeration of all k-bit advice strings takes O(2^k(T_V+k)+T_parse) time and O(S_V+k+log N) writable bits when sequential. A one-polarity accepting verifier alone is not a both-label deterministic decider. An answer-polarity oracle is inadmissible. Read-only advice saves writable bits only; its production, addressing and replay are not free.

## Same-machine ledger and conditional exponents
Let full actual source bit length N, shared width t, q blocks of child length at most L. Let a hypothetical total deterministic guest have time T_A(L)=O(L^p), workspace S_A(L)=O(L^s), p>=1. With explicit sequential child materialization, per-z costs include source parsing, index discovery, all failed child searches, physical guest encoding O(qL polylog N), q genuine seed calls, guard validation, result/output verification:
T_one_z=O(T_parse+T_index+q[L polylog N+T_A(tilde O(L))]+T_output).
S_peak=O(t+L polylog N+S_A(tilde O(L))+S_index+S_result+log N).
This is the SAME execution, not summing peaks of mutually sequential children. A virtual guest needs a charged address translator and per-access time; a full N-bit copied source consumes Omega(N) writable bits; parallel children cost aggregate space. The total decider must enumerate 2^t z; a decision-only seed generally incurs an extra L factor to self-reduce SAT private witnesses.

If h<=n^0.195 rows, B<=n^0.65 blocks PER row and L<=n^0.35, q<=n^0.845, the direct per-z seed upper bound is n^(0.845+0.35p+o(1)); n^1.33 requires p<=1.385714..., and full z enumeration requires 2^t<=n^(0.485-0.35p-o(1)), for p=1: t<=(0.135-o(1))log2 n. Standard decision-only private witness recovery is bounded above by n^(0.845+0.35(p+1)+o(1)), or n^1.545 for p=1, with no implication that all algorithms require this time. To achieve n^0.5 writable space via physical child, need s<=10/7 plus sufficiently small indices and t. If B is total across rows, replace exponent .845 by .65. The grammar and scale must be authenticated.

CRUCIAL LENGTH GUARD: if q=n^.845 distinct blocks really have independent n^.35 encoded bytes each, then N=Omega(n^1.195). It is mathematically inconsistent to treat n as both complete source-bit length and that explicit sum. Under N=Theta(n^1.195), proposed (n^1.33,n^.5) translates to (N^1.112970711,N^.418410042). Such a uniform general-CNF SAT decider would violate the published deterministic FLMV exclusion below, but the promise specialist itself is NOT forbidden. If n is true input bits with B total across rows, this rescaling need not apply.
