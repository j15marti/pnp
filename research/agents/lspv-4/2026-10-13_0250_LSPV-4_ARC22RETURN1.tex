\section{Exact return-size obstruction}
\begin{theorem}[Balanced restriction--return expansion]\label{thm:return}
Let $F$ be any proper distinct-clause balanced 3-CNF with $m$ clauses and let
$x$ occur $r$ times with each sign, $r\ge2$. In (1), for each $b$,
\[
 |R_b|_{\rm clauses}=m-r,\qquad |P_b|_{\rm clauses}=m,
 \qquad 2r\le g(P_b)\le6r.                              \tag{3}
\]
Consequently the parent has $M=12m$ clauses, while
\[
 M_b=12\bigl(m+7g(P_b)\bigr)\ge12(m+14r)>M.              \tag{4}
\]
Both returned children are strictly longer in the declared encoded bits.
\end{theorem}
\begin{proof}
Assigning $x$ deletes its $r$ satisfied clauses and shortens its $r$ opposite
clauses. The remaining clauses comprise $m-2r$ ternary and $r$ binary clauses.
There are no duplicate binary clauses: duplicates would have arisen from
identical source clauses containing the same falsified literal. The unchanged
ternary clauses are distinct as well. Dense relabelling is injective.
Replacing each binary by two proper ternaries therefore gives $m$ clauses.

Each of the $r$ fresh properization variables has signed counts $(1,1)$ and
requires two balancing gadgets. This proves the lower bound in (3). For the
upper bound, use
\[
 f(p,q)=2\max\{p,q,2\}-p-q.
\]
It is 1-Lipschitz under a unit change in either count. Initially $f=0$ for
every old variable. Apart from $x$, deletion of satisfied clauses removes
$2r$ literal occurrences, and duplication of shortened clauses adds $2r$.
Their total contribution to the new balancing deficit is at most $4r$.
Dropping variables with no remaining occurrences cannot increase that sum.
The fresh variables contribute $2r$, giving $g(P_b)\le6r$.
The established compiler count now gives (4).

For any dense exact-$(2,2)$ proper 3-CNF on $v$ variables and $M=4v/3$
clauses, its compact JSON length is exactly
\[
 J(v)=5M+2v+4\sum_{i=1}^{v}\operatorname{digits}_{10}(i)+1
 \quad\text{bytes}.                                      \tag{5}
\]
Each ID occurs four times, twice negatively; clause punctuation contributes
$5M+1$ characters. This strictly increasing function is independent of clause
and literal order. The parent has $v=9m$ and each child has
$v_b=9(m+7g(P_b))>v$. Hence $8J(v_b)>8J(v)$.
\end{proof}

For every $\alpha>0$, this particular two-query return satisfies
\[
 \sum_{b=0}^{1}\left(\frac{|y_b|}{|y|}\right)^\alpha>2,    \tag{6}
\]
so it cannot meet the existing ARC gate of at most $0.99$, including
$\alpha=6/5$. This is stronger than the earlier identity
$U(D(y))=y$: even intervening one-variable branching does not make this
return compiler contract. It is \textbf{FALSIFIED/RETIRED} as a mandatory
contracting implementation, not as a sound SAT reduction.

This theorem bounds query lengths for (1), not the runtimes of arbitrary
algorithms on those queries. A larger formula can still be easy.

\section{The useful repair: typed iterative depadding}
\begin{theorem}[A uniform typed bypass]\label{thm:depad}
If $F=D(y)$ is already in the syntactic domain $\mathcal C_{22}$, return the
single query $\enc(F)$ without reapplying $U$. It preserves the $L_{22}$
answer and has length strictly less than $|y|/12$. Repeating this rule while
its type check succeeds defines one uniform polynomial-time, SAT-preserving,
idempotent normalizer $E$ on $\mathcal C_{22}$.
\end{theorem}
\begin{proof}
For $F\in\mathcal C_{22}$ on $v$ variables, $m=4v/3$ and $U(F)$ has $12v$
variables. Let $S(v)=\sum_{i=1}^{v}\operatorname{digits}_{10}(i)$.
Partition $1,\ldots,12v$ into blocks of 12. Every number in block $i$ is at
least $i$, so $S(12v)\ge12S(v)+3$, with the extra three contributed already
by 10, 11, and 12. Formula (5) yields
\[
 J(12v)-12J(v)=4\bigl(S(12v)-12S(v)\bigr)-11\ge1.         \tag{7}
\]
Thus the replacement has the stated strict contraction and remains in the
same decision domain. The implementation loops on this test; it does not use
an advice string depending on depth. When the decoder fails, or returns a
balanced source not in $\mathcal C_{22}$, it stops with the unresolved current
formula. It never substitutes a NO answer for failed decoding.

Lengths decrease geometrically, so there are $O(\log N)$ successful steps.
Using the preceding conservative decoder bounds, sequentially discarding old
buffers gives
\[
 \sum_j O((N/12^j)^3)=O(N^3),\qquad S_E(N)=O(N^2).        \tag{8}
\]
The unsuccessful final check is charged. The terminal object satisfies the
same stop condition on the next call, proving idempotence.
\end{proof}

This removes growing-depth padding without claiming growing-depth SAT
solving. For $y=U^t(F)$ with $F\in\mathcal C_{22}$, the recognizable outer
layers can be removed, but $F$ still needs its decision. For a fixed decider
$A$ with arbitrary constants $c_A,k_A$,
\[
 T_{E;A}(y)\le O(N^3)+c_A|E(y)|^{k_A}.                   \tag{9}
\]
There are inputs on which $E(y)=y$. No worst-case polynomial exponent is
erased. The fixed NP-complete language is not replaced by an all-NO benchmark.

\section{Charging the actual source-first execution}

counts occurrences, scans all $3m$ source literals for each branch, renumbers
active variables, properizes, balances, compiles, serializes and consumes every
query byte. Children are built and consumed sequentially. No SAT oracle was
called during this construction. The output consumer computes a digest; its
cost is not represented as a decision procedure.

Theorems 1 and (3) give $v_b\le22v$, hence $|y_b|=O(N)$ in (5). All local
processing admits the conservative deterministic bit-cost bound $O(N^3)$
and workspace $O(N^2)$, with buffers and maps charged. If a fixed decider

\[
 T=T_{\rm phase}+T_A(y_0)+T_A(y_1),\qquad
 S\le S_{\rm phase}+\max_b S_A(y_b).                     \tag{10}
\]
Parent data retained during a call are included in $S_{\rm phase}$. There is
no recursion in the one-phase experiment. Any multi-phase recursion needs
