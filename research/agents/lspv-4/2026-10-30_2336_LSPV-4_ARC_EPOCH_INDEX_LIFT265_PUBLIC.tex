\section{A conditional finite-tape simulation lemma}
Work in the FLMV indexed read-only-input deterministic Turing-machine model. Let $y(x,j)$ be an already constructed ordinary SAT child of physical length $m$, where $x$ is the original source and $j$ is a paid descriptor. Assume a deterministic reentrant accessor $B(x,j,i)$ returns precisely $y_i$ for $0\le i<m$ and BLANK otherwise, including preparation, source indexed probes, cleanup and scratch restoration in time $b$ and counted space $s_B$ per invocation. A parent retains $R$ counted bits. A fixed guest $A$ has a supplied valid running-step bound $T$, charged guest work/index footprint $S_A$ and guest \emph{input-index tape head high-water} $H_A$.
\begin{theorem}[Budgeted indexed-input lift]
A fixed finite-tape deterministic simulator can reproduce the exact guest computation and its label on $y$ (for either SAT or UNSAT) in
\[
T_{\rm sim}=O(T[b+\log^2(m+T+2)]),\qquad
S_{\rm sim}=O(S_A+H_A\log(m+T+2)+s_B+R+\log(m+T+2)).
\]
No assertion of a known $T$ for arbitrary $A$, nor of the existence of a cheap universal $B$, is included.
\end{theorem}
\begin{proof}
Choose $r=\lceil\log_2(m+T+2)\rceil$ and a logical epoch tag of $\lceil\log_2(T+2)\rceil+O(1)$ bits. Store each logical guest input-index tape bit in a separate fixed-width physical block with its most recent write epoch. A stale block represents zero. On a guest indexed input jump, increment the epoch to erase all logical index-tape bits without visiting blocks, preserving the virtual input-index head position. An ordinary move between neighboring blocks costs $O(\log(T+2))$ physical steps.

Maintain $v=\sum_{i<r}b_i 2^i$ and the count $h$ of live one-bits in positions $i\ge r$. Each index-tape write uses the old logical bit to update $v$ or $h$ in conservatively $O(\log^2(m+T+2))$ finite-tape operations. On an indexed input jump, put the virtual input head at $v$ if $h=0$ and $v\le m+T$, or else in a single state FAR; reset $v=h=0$ and increase the epoch. A bit above position $r-1$ implies an address at least $2^r>m+T$. The simulator keeps valid positions exactly; FAR remains blank for at most $T$ ordinary movements, which cannot reach any nonblank child address $0,\ldots,m-1$. Any valid-position guest input read invokes the charged reentrant $B$, while guest work and other index tapes are simulated on disjoint counted finite tapes. Inductively all guest visible symbols, index-reset effects, work transitions and final output agree. Summing at most $T$ paid events proves time; summing simultaneously live epoch blocks, guest tapes, accessor work, source control and retained parent memory proves space. \qed
\end{proof}

\section{Guest accessor exponent and exact infinite FLMV frontier}

\[
K'\le\max\{11/10,3/5+\beta+K/2\},\qquad K_*=6/5+2\beta.
\]
At the fixed strict FLMV time test $c=241/200$, $\beta<1/400$ is necessary for this recurrence to enter the forbidden time budget. Peak writable space separately includes every live ancestor, active guest, index tape, source accessor, physical child buffer if any and policy/cache/proof state; a mere max over individually live parts is invalid.

FLMV 5.7 defines $f_0=1$, $f_k=cf_{k-1}/(1+f_{k-1})$ and $d_k(c)=\min\{(1/f_k-c)/k,c^{-k}\}$, $d_*(c)=\max_{k\ge1}d_k(c)$. Our independent exact-fraction checker evaluates $f_k=c^k/(2+\sum_{j=1}^{k-1}c^j)$ and excludes the full infinite tail $k\ge4$ because $d_k(c)\le c^{-k}\le c^{-4}<d_2(c)$ at each tested point:
\[
d_*(6/5)=23/45,\qquad d_*(241/200)=11642479/23232400.

Both have optimal index $k=2$.
