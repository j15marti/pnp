\section{Target, falsifiable mechanisms and exact prior work}
The shared target is a charged existential successor for pairs
$(t,s)$ attained \emph{simultaneously} by one total uniform
deterministic exact SAT machine on every ordinary bitstring.
Three possibilities were fixed before testing.
First, must $Q=N^{3/5}$ selections each of $K=\Theta(N^{1/2}/\log N)$
clause indices require an explicit $K$-index array?
Second, does disjointness of every \emph{consecutive} child force
$\Omega(QK)$ parent writes even when children are served virtually?
Third, can a family of such well-addressed deletion children
recover an arbitrary parent's SAT bit from their SAT labels?
The answers are respectively no for a fixed arithmetically indexed
portfolio, no for virtual service but yes for a fixed flat materialized
buffer, and no for status-only gluing. The third negative answer was
already proved in MINIMAL-UNSAT-PROJECTION20; it is not claimed
as new here.

\section{Fixed-width ordinary encoding}
A parent proper 3-CNF has $n$ variables and $M$ ordered clauses.
Its header is $(n,M)$. Every clause occupies the four fixed-width
words $(3,\ell_1,\ell_2,\ell_3)$, with signed literal code
$2|\ell|+\mathbf{1}_{\ell<0}$ and width
\[
w(n,M)=\left\lceil\log_2(64(n+M+1))\right\rceil.
\]
Thus the parent length in bits is
\[
N=(4M+2)w(n,M).
\]
No source pointer is included in the ordinary child encoding.
A deletion child uses the \emph{same} variable header $n$,
its own clause count $K$, and the child word width $w(n,K)$.
It is a self-contained proper 3-CNF of exact length
\[
L=(4K+2)w(n,K).
\]
Retaining unused source variable names is allowed by this declared
encoding. Each literal bit is explicitly obtained from the read-only
source by a charged index computation and source access.

For the scalable controls choose $M=2^h\ge16$ and
$m=(M-6)/2$, so $n=2m+3=M-3$.
Let $K$ be an odd integer satisfying
$K=\Theta(\sqrt N/\log N)$ and $2K\le M$.
Set
\[
Q=\min\{M,\lfloor N^{3/5}\rfloor\}.
\]
For sufficiently large $h$, $Q=\lfloor N^{3/5}\rfloor<M$.
Therefore $K=\Theta(N^{1/2}/\log N)$,
$L=\Theta(N^{1/2})$ and $QK=N^{11/10+o(1)}$,
where the negative logarithmic factor is retained in the exact
finite accounting.

\section{An all-valid-source, uniform cyclic child service}
For each $0\le j<Q$ define the \emph{ordered} $K$-clause child
\[
C_j=(D_{s(j,0)},\ldots,D_{s(j,K-1)}),\qquad
s(j,i)=(jK+i)\bmod M.
\tag{1}
\]
Clause order is part of the encoding, so no sorting is required.

\begin{theorem}[PROVED/EXACT: logarithmic-state indexed service]
For every valid ordinary proper 3-CNF parent of the declared length
and for the uniform schedule (1), one fixed deterministic machine
using $O(\log N)$ writable bits beyond its read-only source pointer
returns \emph{any requested bit} of the exact ordinary child $C_j$
in $\polylog N$ elementary bit operations. The schedule has $Q$
distinct children. Consecutive children are disjoint as clause-index
sets when $2K\le M$.
\end{theorem}
\begin{proof}
The machine stores $n,M,K,Q,j$ and the queried child position,
all $O(\log N)$-bit integers. It divides the position by $w(n,K)$.
Word indices $0,1$ return $n,K$; subsequent words identify the
local clause $i$ and one of its four fields. Compute
$s(j,i)$ by multiplication, addition and modular reduction of
$O(\log N)$-bit integers; address the corresponding parent record;
read its type or signed literal code and write the requested
child-width bit. All arithmetic, addressing, bit conversion and
source reads take $\polylog N$ bit work and $O(\log N)$ work bits.
This exactly reproduces an ordinary serialized child, including
headers and bit-width changes; the child is not a source handle.
Because $M$ is a power of two and $K$ is odd,
$\gcd(K,M)=1$, hence the starting positions $jK\bmod M$
are distinct for $0\le j<M$. A cyclic interval of length
$0<K<M$ has a unique starting point, so the children are distinct.
The intervals for $j$ and $j+1$ partition two consecutive
length-$K$ blocks on the cyclic order, and are disjoint whenever
$2K\le M$. The procedure is uniform in $n,M,j,K$ and has no
nonuniform list of selectors.
\end{proof}

\begin{theorem}[PROVED/EXACT: flat-buffer update separation]
Suppose that after each completed child invocation one \emph{same}
flat canonical word array is required to hold the next entire
ordinary child, at fixed field addresses. If all $M$ parent clause
records are distinct, consecutive children in (1) force changes to
at least $K$ literal fields. Thus the $Q$-call flat-buffer
implementation uses at least $(Q-1)K$ changed word-field writes
and at least that many changed \emph{bits} across these transitions.
This is not a lower bound on every representation or SAT decider.
\end{theorem}
\begin{proof}
No clause in one child appears in the next. At each of the $K$
fixed record positions, the old and new parent clause records
are distinct. Both type fields equal three, hence at least one
literal-code field differs and at least one constituent bit changes.
All positions must agree with the new ordinary child when the
next invocation begins. Therefore at least $K$ field writes and
$K$ bit changes are necessary per transition. The virtual service
stores no flat child array and is not subject to this premise.
\end{proof}
A fresh serializer has $QL$ bit writes; a flat reuser
has $\Omega(QK)$ changed bit or field writes. Neither establishes
a $\Omega(QK)$ write lower bound for a virtual or source-aware solver.
The full-selector capacity bound
$\log_2\binom MK=\Theta(N^{1/2})$ is unaffected:
that theorem serves \emph{all} $K$-subsets using a fixed decoder,
whereas (1) serves only $Q$ arithmetically generated selectors.
An index $j$ containing $O(\log N)$ bits is therefore sufficient.

\section{Same-machine composition and exact conditional exponents}
Let $A$ be one fixed uniform random-access Turing machine that
decides \emph{all} ordinary SAT inputs with simultaneous time
$T_A(L)$ and work space $S_A(L)$.
The virtual-bit lemma constructs one simulation of $A(C_j)$
whose charged bounds are
\[
T_{\mathrm{call}}(N)=\widetilde O(T_A(L)+1),\qquad
S_{\mathrm{call}}(N)=\widetilde O(S_A(L)+\log N).
\tag{2}
\]
The decoder computes and returns an ordinary child input bit on
demand, and repeated random access is charged on every occasion.
Simulated solver workspace is retained during a call and cleared
or reused between calls with its reset cost charged. No whole
child is materialized or treated as external read-only memory.
Let $R(N)$ and $H(N)$ denote \emph{additional} charged
parent-local decision, compatibility, policy-selection, failed-trial,
and live-ancestor costs, not asserted to vanish.
A \emph{hypothetical separately proved} correct gluing rule
using this exact portfolio would yield
\[
T(N)\le\widetilde O\!\left(N+R(N)+Q\,T_A(L)+Q\right),\qquad
S(N)\le\widetilde O\!\left(\log N+H(N)+S_A(L)\right).
\tag{3}
\]
For $R=N^{r+o(1)}$, $H=N^{\sigma+o(1)}$ and
$T_A(L)=L^{t+o(1)}$, $S_A(L)=L^{s+o(1)}$,
the conditional exponent ledger is
\[
t'\le\max\{1,r,3/5+t/2\},\qquad
s'\le\max\{0,\sigma,s/2\}.
\tag{4}
\]
The $1/2$ space floor from \emph{storing an entire child}
has disappeared for this restricted schedule, not for an
arbitrary all-input SAT successor. In particular, the parent
gluing mechanism of (3) does not exist in this report.
The fast data service (2) is not a proof of (3) for SAT.

\section{Hostile semantic pair and adaptive policy}
For $m=(M-6)/2$, define
$\operatorname{FORCE}(\ell;a,b)$ to be the four proper
clauses $(\ell\lor\pm a\lor\pm b)$ over all sign pairs.
Let $P_i=(\neg x_i\lor x_{i+1}\lor c_i)
\land(\neg x_i\lor x_{i+1}\lor\neg c_i)$.
The archived MINIMAL-UNSAT-PROJECTION20 formulas are
\[
F_m=\operatorname{FORCE}(x_1;a_0,b_0)\land
\bigwedge_{i=1}^{m-1}P_i\land
\operatorname{FORCE}(\neg x_m;a_m,b_m),
\tag{5}
\]
and $G_m$ is obtained by replacing
$(\neg x_m\lor a_m\lor b_m)$ with
$(\neg x_m\lor a_m\lor x_1)$.
They have $n=2m+3=M-3$ and $M=2m+6$
distinct proper ternary clauses.
The archived proof shows $F_m$ is minimally UNSAT and
$G_m$ is SAT. Every $K<M$-clause subformula of either is SAT.
Thus for \emph{every} schedule (1), including adaptively
selected calls to any of its short deletion children,
the sequence of child SAT responses is identically all YES
for opposite parent labels.
A parent-aware controller may nevertheless inspect the source
to detect (5), or add coherent pinned constraints; its extra
work and space must be included in $R,H$.
This demonstrates failure of status-only semantic gluing,
not a lower bound on arbitrary algorithms.

For a substantive state-switching control, the executable
implements one \emph{total uniform} policy. It first acquires the
source grammar and attempts a paid exact recognition of (5) or
its $G_m$ counterpart using expected-clause access without storing
a second full formula. If recognition succeeds it directly decides
the known label. If recognition fails it switches to a complete
ordinary DPLL fallback. Both canonical SAT and canonical UNSAT
instances are handled without a label oracle. A mutated formula,
a small Horn-like SAT formula and the eight signed clauses on a
triple exercise fallback. Recognized inputs take
$O(N\,\polylog N)$ elementary bit work and $O(\log N)$
scratch in the abstract streaming implementation.
The Python executable's diagnostic objects are not a physical
FLMV tape-space measurement.

\section{BIT-RESOURCE1 ledger}
Keep distinct $(W,R_s,R_w,W_w,F_{\rm flip},S_{\rm peak},
B_{\rm time},P_{\rm repr})$, where work counts elementary bit
operations, $R_s$ source reads, $R_w,W_w$ mutable memory reads and
writes, $F_{\rm flip}$ actual full-state value changes,
$S_{\rm peak}$ live writable bits, $B_{\rm time}$ cumulative
live-bit-time, and $P_{\rm repr}$ program or stored representation.
The initial source grammar scan costs $O(N\polylog N)$ bit work.
For each virtual bit requested by $A$, (2) charges source
address computation, all source reads, control, arithmetic,
write activity and workspace. The \emph{controller alone}
uses $O(\log N)$ live bits and
$\widetilde O(Q)$ bit work to advance $j$;
this excludes the solver's own operations and the validation scan.
Binary counter flips are measured separately and are never
substituted for all primitive work. The same exact execution,
rather than mixing resources from a virtual machine with the
time of a materialized machine, supplies each pair in (2).
Cumulative bit-time is charged on actual live states, not
the artificial sum of residual potentials.
