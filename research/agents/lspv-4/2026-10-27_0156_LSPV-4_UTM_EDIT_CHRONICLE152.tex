\section{Exact finite lemma}
Fix the W1 sign-pair clause layout of UTM-CROSS-WRITE1. For $m$ modules the physical encoded input length is $N=\Theta(m\log m)$, there are $G=\Theta(N)$ middle-gap cuts, and $F_m(a,\neg a)$ is satisfiable for each $a\in\{0,1\}^m$. For $a\neq a'$, at least one of $F_m(a,\neg a')$ and $F_m(a',\neg a)$ is unsatisfiable. A fixed finite interpreter $U$ has $q$ states, exactly one bounded sequential read-only source head, $k$ fixed sequential blank-start work tapes of constant alphabet size $g$, and optional inline code prefix wholly on the left source shore. For each accepted run charge $S$ visited work cells (blank included), $D$ actual work-symbol changes, $R$ input-head reversals and $T$ transitions. Each accepted program must be sound on all promised NO sources. Any input-dependent initially nonblank work pattern must be charged by adding its placement and symbols to the chronology; known fixed endmarkers may be part of the fixed machine convention.
Set
\[
h=2S+3,\quad V=2qh^k,\quad C=1+V+khg.
\tag{1}
\]
At a source cut $c$ chronologically record only: (a) every source cut crossing with its direction, finite state and $k$ work-head coordinates, and (b) every actual work-symbol change with tape index, cell coordinate and new symbol. Fix change-before-crossing ordering when both happen in one transition.
\begin{lemma}[Faithful history]\label{l:decode}Given fixed initially blank tapes, the event word reconstructs every full work-tape symbol map at each crossing.\end{lemma}
\begin{proof}Initialize the fixed work map as blank. Replay the change letters, writing each new symbol to its tape and coordinate. Crossing labels already contain control, direction and all head coordinates. No omitted transition changes the tape contents; induction on the event word establishes the complete traditional crossing history. Edits restoring blanks count as changes too.\end{proof}
\begin{lemma}[No-change epochs]\label{l:epoch}A halting accepted run crosses any fixed cut at most
\[
L=\min\{R+1,(D+1)V+D\}.
\tag{2}
\]
\end{lemma}
\begin{proof}The $D$ changing transitions split a run into at most $D+1$ unchanged-work-content epochs. Within an epoch, repeating the full control/input-cut side/work-head-position configuration would repeat the complete state and hence loop. There are at most $V$ such directed states per cut per epoch. Up to $D$ boundary crossings may coincide with symbol-changing transitions. Consecutive cut crossings require a source-head reversal, giving $R+1$.\end{proof}
\begin{theorem}[Edit-chronicle packing]\label{t:packing}
If every one of the $2^m$ SAT diagonals has a globally sound accepting inline-code run under simultaneous ceilings $S,D,R,T$, then
\[
\boxed{2^m\le C^{L+D+1}},\qquad
\boxed{2^m\le G C^{\lfloor T/G\rfloor+D+1}},\qquad
\boxed{2^m\le C^{(D+1)V+2D+1}}.
\tag{3}
\]
\end{theorem}
\begin{proof}
For any fixed gap cut, two accepted diagonal sources cannot have matching traditional complete crossing histories: splicing, keeping the inline code on the left shore, would accept an unsatisfiable cross-source. Lemma \ref{l:decode} makes the event words injective across these sources even with different inline programs. An event word has at most $D+\ell$ letters of an alphabet of size $C$, yielding at most $\sum_{j=0}^{D+L} C^j\le C^{D+L+1}$ possibilities. Lemma \ref{l:epoch} supplies (3)'s first and third bounds. For the time bound, total crossing events across all $G$ gap cuts on a run is at most $T$; select one cut with at most $\lfloor T/G\rfloor$ crossings, and encode its cut ID and event word. Two sources with the same chosen cut and event word would splice. Therefore there are at most $G C^{\lfloor T/G\rfloor+D+1}$ combinations.
\end{proof}
\begin{theorem}[Strict exponent firewall]
With polynomial resource ceilings $S=N^{s+o(1)}$, $D+1=N^{d+o(1)}$, $R+1=N^{r+o(1)}$, $T=N^{t+o(1)}$ on this SAME fixed model, the necessary conditions are
\[
\boxed{d+ks\ge1,\quad \max(r,d)\ge1,\quad \max(t-1,d)\ge1}.
\tag{4}
\]
\end{theorem}
\begin{proof}Here $\log C=O(\log N)$, $V=O((S+1)^k)$, $G=\Theta(N)$ and $m=N^{1-o(1)}$. Taking logarithms of (3) yields the three asserted necessary exponent inequalities. Equality does not give a contradiction.\end{proof}
The point $k=1,s=1/2,d=1/4$ saturates the OLD face $d+ks+\min(d,s)=1$ but violates the NEW face by $1/4$. For $k=1,s=.4,d=.3$, the old face is 1 and the new is .7, with strict margin .3.
