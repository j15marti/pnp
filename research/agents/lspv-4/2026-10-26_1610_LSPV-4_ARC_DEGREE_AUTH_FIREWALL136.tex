The virtual oracle returns $f_G(y)$ for one addressed $y$ with its full physical time and space costs; it does not hand the simulator a free truth table, a free source-authenticity proof, or a full SAT decision circuit.
\begin{description}
\item[] \textbf{H1 (exact degree hierarchy).} The identity predicate $\forall y\,f(y)=0$ on the \emph{promised} class of degree-$\le d$ Boolean functions has deterministic exact value-query complexity $D(k,d)$, interpolating between the affine $k+1$ and unrestricted $2^k$. \textbf{PROVED/EXACT}, Theorem~\ref{th:rm}.

\item[] \textbf{H3 (resource bridge).} $k=O(\log N)$ and constant authenticated degree automatically make all bookkeeping free. \textbf{FALSIFIED}: probes cost $D(k,d)$ times the \emph{actual} bit-access overhead and authentication cost; no uniform all-UNSAT degree bound or tiny source-to-summary compiler follows, Corollary~\ref{cor:cost}.

\section{Sharp degree-indexed identity-testing theorem}
For $0\le d\le k$, let $\mathcal P_{k,d}$ be the vector space of Boolean functions with algebraic normal form
\begin{equation}
 f(x)=\bigoplus_{\substack{S\subseteq[k]\\|S|\le d}} a_S\prod_{i\in S}x_i,\qquad a_S\in\F.
 \label{eq:anf}
\end{equation}
Write $D(k,d)=\sum_{j=0}^d\binom{k}{j}$. The \emph{addressed-value} model supplies only answers to queries $f(x)$ at chosen $k$-bit addresses. It does not supply a readable coefficient vector or the generator's source code.
\begin{theorem}[Sharp black-box identity-query complexity]\label{th:rm}
For every $0\le d\le k$, an exact deterministic adaptive algorithm that, promised $f\in\mathcal P_{k,d}$, decides whether $f\equiv0$ has worst-case query complexity precisely $D(k,d)$. In particular $D(k,1)=k+1$ and $D(k,k)=2^k$.
\end{theorem}
\begin{proof}
For the upper bound query the $D(k,d)$ inputs $1_T$, with $T\subseteq[k]$ and $|T|\le d$, where $1_T$ is the characteristic word of $T$. On these inputs $f(1_T)=\bigoplus_{S\subseteq T}a_S$, so M\"obius inversion over $\F$ recovers every coefficient as $a_T=\bigoplus_{S\subseteq T}f(1_S)$. Hence all queried values are zero if and only if all coefficients are zero.

For the lower bound, run any purported exact deterministic tester on the identically zero oracle. If the run asks $q<D(k,d)$ addresses, the $q$ homogeneous response equations in the $D(k,d)$ independent unknown coefficients have a nonzero solution $a\ne0$. The corresponding nonzero polynomial $g\in\mathcal P_{k,d}$ vanishes on all addresses on that zero-oracle path. Determinism forces the same path and same final answer on $g$, contradicting exactness. This holds for adaptively chosen addresses because the all-zero transcript fixes them. Thus $q\ge D(k,d)$.
\end{proof}
\paragraph{Hostile small-circuit control.} For any $a\in\{0,1\}^k$, the point function $p_a(x)=\bigwedge_{i=1}^k(x_i=a_i)$ has $O(k)$ ordinary Boolean gates and degree exactly $k$ in the multilinear expansion. If $|a|>d$, it vanishes at every canonical probe $1_T$ with $|T|\le d$ but is not identically zero. This falsifies removal of the degree promise; it is \emph{not} a lower bound against an algorithm allowed to inspect the code of $p_a$.

\section{Authenticating the degree promise is a distinct decision problem}
Let $\mathrm{DEG}_d=\{\langle C\rangle: \deg_{\F}(f_C)\le d\}$ for arbitrary acyclic Boolean circuits $C$ with any standard complete finite fan-in gate set and variable input length. The zero function has degree $-\infty$ for this definition; a nonzero constant has degree zero. Gate-list validity is decidable in polynomial time.
\begin{theorem}[Fixed-degree source-authentication firewall]\label{th:hard}
For every fixed nonnegative integer $d$, the language $\mathrm{DEG}_d$ is coNP-complete under polynomial-time many-one reductions. Hardness holds even on circuits obtained from a Boolean source circuit $D$ by appending exactly $d+1$ fresh input bits $z$ and a chain of AND gates computing $C_D(x,z)=D(x)\wedge z_1\wedge\dots\wedge z_{d+1}$.
\end{theorem}
\begin{proof}
For hardness reduce $\mathrm{CIRCUIT}\text{-}\mathrm{UNSAT}$, which is coNP-complete, to $\mathrm{DEG}_d$. If $D\equiv0$, then $C_D\equiv0$ has degree $-\infty\le d$. Otherwise the multilinear representation of $D$ has some nonzero monomial of degree $r\ge0$. The $z_i$ are disjoint fresh variables, so multiplying by $\prod_i z_i$ produces a nonzero monomial of degree $r+d+1\ge d+1$. Thus $C_D\notin\mathrm{DEG}_d$. The map is uniform and increases gate count by $O(d)$.

For membership in coNP at each \emph{fixed} $d$, if a Boolean function has degree at least $d+1$, there is a set $I$ of $d+1$ variables and a base assignment $y$ on the other variables for which the $(d+1)$-fold Boolean finite difference
\[
 \bigoplus_{T\subseteq I}f_C(y\oplus1_T)=1.
\]
Indeed choose $I$ from the support of some highest-degree monomial; its finite difference is a nonzero polynomial, and hence nonzero at some $y$. The witness consists of $I,y$. It is checked using $2^{d+1}$ circuit evaluations, which is polynomial for fixed $d$. Hence $\overline{\mathrm{DEG}_d}\in NP$ and $\mathrm{DEG}_d\in coNP$.
\end{proof}
\paragraph{Careful boundary.} The theorem does \emph{not} claim polynomial checking of degree $d$ for variable or growing $d$, nor a deterministic superpolynomial lower bound unless the corresponding complexity separation is independently proved. If a source-authenticated summary is literally presented in checked ANF form with only degree-$\le d$ monomials, checking the syntactic cap and its coefficients is straightforward; the expensive part may be proving that this ANF correctly captures the original SAT boundary semantics. The latter semantic lifting was already identified as hard in LSPV-3 SOURCE-CUT-QBF-BARRIER128.

\section{Charged interpolation as an ARC subroutine, not an ARC edge}\label{sec:charge}
Assume a \emph{uniformly authenticated} degree bound $d$ for a summary of $k$ Boolean boundary names. Let $Q(N)$ be the number of proposed summaries on the current run; let $U(N)$ bound the physical bit-time cost of each addressed evaluation \emph{including} source-byte lookup, gate evaluation, index decoding, and virtual-input generation. Let $A_{\mathrm{auth}}(N)$ denote authentication time and $W_{\mathrm{auth}}(N)$ its peak workspace. Then independent exact zero-checks by Theorem~\ref{th:rm} cost at most
\[
 T_{\mathrm{join}}\le A_{\mathrm{auth}}(N)+Q(N)D(k,d)\bigl(U(N)+\operatorname{poly}(k)\bigr)
\]
with space bounded by the \emph{simultaneously live} authenticated source state, the current address and the evaluator's actual peak space. If the verifier merely queries the canonical zero-test probes without reconstructing the entire ANF, the addresses are generated in $O(k)$ index bits; no $2^k$ truth table needs be materialized. If a circuit summary and its provenance must be retained through a DAG merge, their retained space is added, not discarded. Deterministic certificate \emph{discovery} is separately charged for ARC; co-nondeterministic guessing instead needs an all-branch uniform cap and a correct acceptance polarity.
\begin{corollary}[A parameterized cost, conditional on actual authentication]\label{cor:cost}
If $k=\alpha\log_2N+O(1)$ for fixed $\alpha>0$, $Q(N)\le N^{q+o(1)}$, $U(N)\le N^{u+o(1)}$, and $A_{\mathrm{auth}}(N)\le N^{r+o(1)}$, then for fixed $d$ the above strategy has time exponent at most $\max(r,q+u)$, subject to the stated extra polynomial-log factors and actual same-machine model transport. If instead $d=\lfloor\gamma k\rfloor$ with fixed $0<\gamma<1/2$, its addressed-query exponent is $\alpha H_2(\gamma)+o(1)$, where $H_2(\gamma)=-\gamma\log_2\gamma-(1-\gamma)\log_2(1-\gamma)$; for fixed $\gamma\ge1/2$, it is $\alpha+o(1)$. None of these formulas supplies an all-UNSAT authenticated-degree coverage theorem.
\end{corollary}
\begin{proof}
For fixed $d$, $D(k,d)=O(k^d)$ and $k=O(\log N)$. For proportional $d$, standard binomial-sum estimates give $\log_2D(k,\gamma k)=kH_2(\gamma)+o(k)$ when $\gamma<1/2$ and $k+o(k)$ when $\gamma\ge1/2$. Insert these into the charged work expression. The coefficient summaries themselves may require $D(k,d)$ bits to describe; any storage or transmission used by the chosen machine is additionally charged.
\end{proof}
