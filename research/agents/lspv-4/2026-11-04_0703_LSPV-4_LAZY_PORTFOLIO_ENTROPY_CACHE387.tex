\begin{theorem}[parent-input range cap]\label{cap}
For every deterministic function \(G:\{0,1\}^N\to(\{0,1\}^{B})^Q\), the range of its concatenated \(QB\)-bit output contains at most \(2^N\) strings. For any fixed deterministic controller and fixed deterministic guest, the complete adaptive query/answer transcript is also a function of the \(N\)-bit parent input and has at most \(2^N\) possible values. For randomized algorithms, the same statement holds conditional on a fixed random tape. These facts do not upper bound computational time or output size.
\end{theorem}
\begin{proof}A map from a domain of size \(2^N\) has image size at most \(2^N\). Apply this also to the transcript mapping.\end{proof}

\begin{theorem}[uniform two-label lazy portfolio]\label{port}
Fix any integer \(K\ge2\), put \(\lambda=1/(5K)\), \(\zeta=\lambda/5\), and use \(N\) for the binary encoded source size. There exist infinitely many, uniformly recognizable signed-CNF sources \(F_{n,b}\), \(b\in\{0,1\}\), and a uniform compiler producing \(Q=\lceil N^{1-\lambda+\zeta}\rceil\) pairwise syntactically distinct CNF children \(G_{n,b,j}\), each of encoded length \(\Theta(N^\lambda)\), such that
\[
 {\rm SAT}(F_{n,b}) \iff \bigwedge_{j\le Q}{\rm SAT}(G_{n,b,j})
 \iff \bigvee_{j\le Q}{\rm SAT}(G_{n,b,j})\iff b=1.
\]
The explicit concatenated child encodings have \(\Theta(N^{1+\zeta})\) bits, but the full vector of child SAT statuses has only two possibilities. On this restricted recognizable source family, one fixed uniform exact controller checks the entire source grammar and outputs \(b\), or streams every child status, in \(O(N\,{\rm polylog}\,N+Q\,{\rm polylog}\,N)\) bit time and \(O(\log N)\) all-phase writable space, with a read-only source and streamed output. A virtual child-bit accessor uses \(O(\log N)\) space and \({\rm polylog}\,N\) bit work per queried bit.
\end{theorem}
\begin{proof}
For \(n\ge1\), take
\[
 F_{n,b}=(u)\wedge(\ell_b(u))\wedge\bigwedge_{i=1}^{n}(v_i),\qquad
 \ell_1(u)=u,\quad\ell_0(u)=\neg u.
\]
In explicit signed indexed DIMACS the source length is \(N=\Theta(n\log(n+2))\). It is SAT iff \(b=1\). Set \(D=\max\{1,\lceil N^\lambda/\log_2(N+2)\rceil\}\). For each \(1\le j\le Q\), let
\[
 G_{n,b,j}=(w_j)\wedge(\ell_b(w_j))
           \wedge\bigwedge_{t=1}^{D}(a_t),
\]
where the root variable index \(w_j\) is distinct for each \(j\) and the padding indices are larger than \(Q\). Each child is SAT iff \(b=1\), and its indexed bytes differ from those of every other child. The padding contributes \(D\,\Theta(\log Q)=\Theta(N^\lambda)\) encoded bits for sufficiently large \(N\); headers and the two root units add \(O(\log N)\). Hence the concatenated size is \(\Theta(QN^\lambda)=\Theta(N^{1+\zeta})\).
A uniform parser validates the parent grammar with logarithmic counters and obtains the polarity \(b\), rejecting malformed encodings. Its running time is at most \(O(N\,{\rm polylog}\,N)\). It need store only \(b,n\), and a few logarithmic counters. To answer a virtual child-bit request, compute the field (header, root units, or indexed padding), its numeric digit and \(b\) if needed. All indices and fixed rational-power counts fit in \(O(\log N)\) bits; their arithmetic costs \({\rm polylog}\,N\) time. No child is materialized by the status controller.
\end{proof}

\begin{proposition}[explicit-cache capacity]\label{cache}
A physical cache that simultaneously stores one writable status bit for every child requires at least \(Q=N^{1-4\lambda/5+o(1)}\) writable bits. Since \(K\ge2\), \(1-4\lambda/5\ge23/25>1/5\), such a cache violates an \(N^{1/5+o(1)}\) all-phase writable-space limit. Simultaneously materializing all child codes takes \(\Theta(N^{1+\zeta})\) writable bits. This \emph{does not} apply to implicit/compressed caches, whose access algorithms and correctness must instead be charged.
\end{proposition}
\begin{proof}Count the declared simultaneously live result cells or child-code cells. The example of Theorem~\ref{port} has a one-bit implicit representation, namely \(b\).\end{proof}
