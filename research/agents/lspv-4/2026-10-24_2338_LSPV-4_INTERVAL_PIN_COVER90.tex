\section{Exact family}
For the canonical implication-chain formula $F_q(b)$, the endpoint gadgets force $z_0=1$, $z_q=0$, and $C_i$ is $(\neg z_{i-1}\lor z_i)$ if $b_i=1$, otherwise $(\neg z_{i-1}\lor\neg z_i)$. Hence $\operatorname{SAT}(F_q(b))$ iff some orientation is zero. Properization of each binary clause $(a\lor c)$ by fresh $t$ gives $(a\lor c\lor t)\land(a\lor c\lor\neg t)$ and the proper-3CNF $P_q(b)$ of size $n=2q+7$, $m=2q+8$, $N_q=(8q+34)\lceil\log_2(64(4q+16))\rceil$.
\begin{theorem}
Partition $[q]$ into consecutive intervals $I_j$ of lengths $h_j\le K$. For each, construct an ordinary proper-3CNF $P_{h_j}(b|I_j)$ with fresh forced endpoints and fresh free auxiliaries. Then
\[
\operatorname{SAT}(P_q(b))\iff\bigvee_j\operatorname{SAT}(P_{h_j}(b|I_j)).
\]
Each child has length $L_j=(8h_j+34)\lceil\log_2(64(4h_j+16))\rceil$ and belongs recursively to the same promise.
\end{theorem}
\begin{proof}The parent is SAT iff one orientation is zero. Each child is SAT iff its own interval contains a zero. Disjoint intervals cover all orientations. Every SAT child supplies a zero position from which the global transition witness is reconstructed with paid source reads.\end{proof}
\section{Adaptive acquisition theorem}
Define a restricted source-linked oracle that can directly read orientation fields or ask for a child's SAT status on an interval of length at most $K$, specified only by endpoints. It is not an ordinary zero-cost SAT call.
\begin{theorem}
For every deterministic adaptive exact controller on the all-one UNSAT source, if $r$ distinct orientations are directly read and $Q$ interval calls issued, then $r+KQ\ge q$.
\end{theorem}
\begin{proof}If a position is not read or covered by any queried interval, flipping only that position gives identical direct-read answers and identical interval-SAT answers, by induction on the adaptive decision policy. The parent label changes, contradicting exactness. Thus all $q$ positions are covered.\end{proof}
At $K=\lceil\sqrt q\rceil$, the number and individual sizes of ordinary children are both $N_q^{1/2+o(1)}$. For one fixed exact uniform all-input child decider of simultaneous exponents $(t,s)$, this \emph{recognized promise} admits a charged eager wrapper with $t'\le\max\{1,(1+t)/2\}$, $s'\le\max\{1/2,s/2\}$. An indexed virtual child generator can save readable child-buffer space but must charge source dereferences, headers, control, cache and peak space. A total exact fallback on arbitrary inputs retains the original worst-case exponent, so there is no all-input achievable ARC edge.
