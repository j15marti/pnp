\section{Exact binary representation and compiler}
For any candidate encoded bitstring \(x\) of length \(N\), parse the self-delimiting width prefix \(1^w0\), then a \(w\)-bit nonnegative variable header \(k\), a \((w+1)\)-bit clause count \(m\), then \(3m\) signed literal fields each consisting of one sign bit and a \(w\)-bit variable ID. In a syntactically valid field sequence, literal IDs inside each three-literal clause are increasing and nonzero; this last condition is \emph{grammar}, not header parse. The width is canonically \(w=\lceil\log_2(k+1)\rceil\), including \(w=0\) when \(k=0\). A parsable header satisfies
\[
N=3w+2+3m(w+1),\qquad k\le N.
\]
Parsing the width, headers, source length and arithmetic overflow requires only \(O(\operatorname{polylog}N)\) addressed bit work and \(O(\log N)\) writable bits; it does \emph{not} validate clauses, occurrences, duplicates, or polarity.

Let \(Y\in\CS\) have positive unsigned supports \(123,145,246,356\) and negative supports \(124,136,235,456\); it has exactly twenty models and witness \(111000\). For a parsable header, set \(k'=k+6\), \(m'=m+8\), \(w'=\lceil\log_2(k'+1)\rceil\). If \(m'\) is not expressible by \(w'+1\) bits, output the fixed malformed word \(\texttt{0}\). Otherwise emit the new proper header, copy each old \emph{literal sign} unchanged, and reencode its ID in width \(w'\). An old ID \(v\le k\) (including the invalid sentinel \(v=0\)) is retained. An old ID \(v>k\), which is invalid in the old encoding but could become newly legal when \(k'\) grows, is instead reencoded as the \emph{reserved invalid ID zero}. Finally append the eight sorted records of \(Y\), with each of its six IDs shifted by \(k\). For malformed header, nonbinary source, or inconsistent total length, output \(\texttt{0}\) directly. Call this map \(f\).

\begin{theorem}[Total monotone-type transparency; PROVED/EXACT in declared binary grammar]
For every binary string \(x\), with \(f(x)\) as just defined,
\[
\boxed{\quad x\text{ encodes some }F\in\CM\ \Longleftrightarrow\ f(x)\text{ encodes some }G\in\CS.\quad}
\]
For valid source \(F\), \(G=F\dot\cup Y\) after fresh-ID relabeling and
\[
\boxed{\SAT(G)\Longleftrightarrow\SAT(F),\qquad \#\SAT(G)=20\,\#\SAT(F).}
\]
Therefore \(x\in\LM\iff f(x)\in\LS\), including every invalid input.
\end{theorem}
\begin{proof}
A parsable valid \(F\in\CM\) has all original IDs in \([k]\), and copying its clauses preserves uniqueness, properness, polarity and both occurrence quotas. All shifted \(Y\) IDs are new, so there are no cross-component source-variable occurrences or duplicate clauses. \(Y\) remains unpaired, hence the output is in \(\CS\). Model assignments decompose independently, proving the product formula and witness extension/projection.

For the converse, if \(f(x)\) is a valid \(\CS\) formula, it cannot be the one-bit malformed sentinel. The source header must therefore have been parsable. Every old literal sign and every legal old source ID was copied verbatim; any illegal old ID was replaced by zero, which is still illegal in the output. None of the appended clauses uses old IDs, and each new ID occurs exactly twice with both signs exclusively inside \(Y\). Therefore output distinctness, properness, clause monotonicity, old-variable signed occurrence counts and positive source-ID validity each imply the corresponding old-input condition. The old header and exact field length were parsed without repair. Thus the source is valid \(\CM\). If the old input was invalid, the new output consequently remains invalid, whether or not the header passed. Validity of the output moreover forces the unpaired property through \(Y\), so the equivalence is as stated.
\end{proof}

\section{Near-identity length, random access and SAME\_REALIZATION transport}
For a valid source \(N=3w+2+3m(w+1)\), and \(N'=3w'+2+3(m+8)(w'+1)\). On valid \(\CM\) inputs \(w'-w\in\{0,1\}\), whence
\[
\boxed{N'-N=3(m+1)(w'-w)+24(w'+1)=O(N/\log(N+2)+\log(N+2)),\quad N'=N^{1+o(1)}.}
\]
For each desired bit address \(j<N'\), a fixed uniform \emph{virtual child input} decoder parses only the source header, locates the corresponding original literal field or \(Y\) constant, uses \(O(\log N)\) source bit queries to read/recode an old ID if needed, and emits the exact \(j\)-th target bit. Each random-access query costs \(\operatorname{polylog}N\) elementary bit work and \(O(\log N)\) live writable/index bits. Parsing repeated per query is explicitly charged. No \(N'\)-bit writable output tape is created. For total source strings with parsable header but invalid clauses, the output length is computed identically and invalidity is preserved by the theorem; a prior whole-source validator is unnecessary.

\begin{theorem}[Joint total \(\LM\)-to-\(\LS\) resource transport; PROVED/EXACT in stated model]
Suppose one fixed deterministic uniform \emph{total exact} \(\LS\) decider \(A\), correct on every binary input, runs simultaneously in time \(n^{t+o(1)}\) and writable/index space \(n^{s+o(1)}\) on one indexed read-only-input random-access Turing machine. Then a single fixed uniform total exact \(\LM\) decider \(B\), in the same machine class and read-only-source convention, has joint bounds
\[
\boxed{T_B(N)\le N^{t+o(1)},\qquad S_B(N)\le N^{s+o(1)}+O(\log N).}
\]
The exponent statement includes \(t=0\) or \(s=0\) using \(N^{o(1)}\) for polylog factors.
\end{theorem}
\begin{proof}
Machine \(B\) parses the source header and if necessary rejects through the malformed target output. Otherwise \(B\) simulates \(A\) on \(f(x)\), keeping \(A\)'s ordinary work tape, index registers and control state, but replacing each indexed read-only-input bit access by the decoder above. The simulator uses its \emph{one} original read-only input and \(O(\log N)\) auxiliary counters; it does not assert a second free read-only tape. Every step of \(A\) costs at most \(\operatorname{polylog}N\) source-machine bit operations, with no full target materialization. All output semantics, including invalid inputs, follow from the total reduction. Composing the polylog overhead and \(N'=N^{1+o(1)}\) with the original joint bounds yields the claimed simultaneous pair for \(B\), without borrowing time and space from different implementations.
\end{proof}

\noindent\textbf{Limit of transport.} This theorem improves the earlier ANCHOR96 conservative total-language estimate \(T_{\CM}\le N^{\max\{2,t\}+o(1)}\) based on a nested-scan grammar validator; it does \emph{not} invalidate that earlier correct algorithm. The improvement is to avoid validation entirely while preserving malformed-source rejection in the target syntax. However \(\LM\) is NP-complete but is \emph{not} ordinary SAT with the FLMV fine-grained input semantics.
