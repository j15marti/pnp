\section*{Exact addressing theorem and constructive falsifiers}
For a fixed $w$-bit binary index-address tape define $a_0=0$, and let $a_1,\ldots,a_Q\in\{0,1\}^w$ be the actual sequence of requested read-only-input addresses. Count an individual written index-tape cell as one bit write; do not count native Turing-machine steps.
\begin{theorem}[Exact necessary and sufficient index-cell bit writes]
If intermediate address changes are explicit and an address must equal $a_i$ at the $i$th read, then
\[
D(a_1,\dots,a_Q)=\sum_{i=1}^{Q}\operatorname{popcount}(a_{i-1}\oplus a_i)
\]
is the exact minimum number of index-cell value changes. A work tape with a sequential index head incurs \emph{additional} head movements, unchanged writes, parsing and arithmetic. No identification of $D$ with native time is justified.
\end{theorem}
\begin{proof}
Each register cell differing at two consecutive required addresses must change at least once between them. Intervals have disjoint time order, so summing gives the lower bound. Flipping exactly the differing cells implements each transition, obtaining the matching \emph{bit-change} upper bound. The tape-head movement schedule remains uncharged in this auxiliary metric and must be added for a native implementation.
\end{proof}
For $Q=2^w$ requested distinct addresses, the strictly ascending sequence $0,1,\ldots,Q-1$ incurs $2Q-w-2$ writes, since bit $j$ changes $2^{w-j}-1$ times; the reflected Gray \emph{permutation of physical binary addresses} $i\oplus\lfloor i/2\rfloor$ incurs $Q-1$ writes. An alternating sequence $0,2^w-1,0,2^w-1,\ldots$ incurs $(Q-1)w$ writes; a repeated zero address incurs zero. Gray ordering is allowed only when the validator is free to reorder independent source reads; changing the encoding of a \emph{fixed requested} address is not a zero-cost alternative. Thus there is neither a universal $\Omega(Q\log N)$ address-bit-write floor nor a universal $O(Q)$ bit-write upper bound for arbitrary forced request sequences.

\section*{Acquisition/query-cost theorem for actual indexed source claims}
Consider a canonical explicit binary CNF grammar with variable and clause counts bounded by its encoded bit length $N$, length-delimited clauses, separately encoded literal sign fields and fixed-width identifiers. A streaming logspace parser can verify the grammar, index ranges and exact terminal length using $O(\log N)$ work/index bits. A read-only proof/claim tape of length $P$ contains $Q$ records $(j,t,b)$ identifying a source clause $j$, literal position $t$ and asserted sign bit $b$. Both the CNF and the complete claim stream are provided \emph{read-only and indexable}; this is not a guessed free certificate. Put $M=N+P+2$.
\begin{theorem}[Charged named-source replay]
There is one uniform deterministic exact authenticator which (i) rejects malformed CNF, malformed claim streams and absent or out-of-range source occurrences, (ii) accepts precisely when every named literal-sign claim matches its actual source occurrence, and (iii) uses
\[
T_{\mathrm{native}}\le O\!\left([P+(Q+1)N]\log(M+2)\right),\qquad
S_{\mathrm{all\ phase}}=O(\log(M+2)).
\]
The input and claims are read-only external data included in $M$. The stated time is a conservative indexed-bit-machine upper bound including indexed-head setting, literal scanning, source/query switching and all parsing. It does \emph{not} validate any derivation's semantic inference rule.
\end{theorem}
\begin{proof}
Parse the CNF in one source pass, rejecting syntax errors. For every query, retain its $(j,t,b)$ and a bookmark for the current proof-tape location. Return by paid index writes to the beginning of the source, parse its clause and literal headers sequentially until $(j,t)$ is found, and compare the sign. Resume at the bookmarked claim position. A single scan requires $O(N)$ indexed source observations; each address update, bit operation and head motion is bounded conservatively by $O(\log M)$ steps. Proof parsing adds $O(P\log M)$ steps. Only a fixed number of current addresses, sizes, counters and field values are simultaneously writable, each $O(\log M)$ bits. All phases, including the initial syntax check, have logarithmic peak writable space. If the claim stream is \emph{not} pre-supplied read-only, acquiring/materializing it requires additional charged work and space.
\end{proof}
If the claim carries only an \emph{absolute bit offset}, exact raw-bit comparison is cheaper, but binding that offset to an authenticated named clause/literal also requires syntactic justification. The reparse method pays for this binding. Its $Q$ source rescans can be replaced by a full source-sign cache, but allocating $\Theta(L)$ sign bits immediately yields a linear peak for that \emph{alternative} phase, even if released later. The no-reread delayed-index/Fano theorem (reports 355/356) remains correct for its separate one-pass model, but cannot be imported into this indexed-reread realization.
