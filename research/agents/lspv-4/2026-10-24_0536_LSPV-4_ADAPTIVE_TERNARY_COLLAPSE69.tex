\section{Target, predecessor and three falsifiable mechanisms}
The run target is a growing mixed-width family with both SAT and UNSAT labels
and a state-adaptive \emph{full-CNF} solver whose available structural
parameters change dramatically during execution. The predecessor
LSPV-3 ADAPTIVE-SPLIT74 exists with its report header and final sentinel.
It established that two contrived exact algorithms can have complementary
exponential regions while a source-aware chooser is fast. The present
test is different: it studies mechanical, evidence-driven binary
implication and ternary collapse, without assigning a slow branch by fiat.

\noindent\textbf{M1, CANDIDATE tested:} a family can have
$k=\Theta(n)$ genuine ternary clauses and minimum raw strong syntactic
2-CNF backdoor $h=\Theta(n)$ yet admit a certified $O(N/\log N)$
adaptive word-time decision on both labels.

\noindent\textbf{M2, CANDIDATE tested:} no initial unit and a satisfiable
binary backbone may coexist with a one-seed binary implication certificate
that eliminates every ternary before a final SCC solve.

\noindent\textbf{M3, hostile control:} a fixed exhaustive-backdoor policy
might require $2^h$ tested assignments while another exact policy uses a
changing representation. This measures that \emph{specific} fixed policy,
never all algorithms or all branchers.

\section{Exact scalable construction}
Let $q\ge1$, $b=(b_1,\ldots,b_q)\in\{0,1\}^q$.
Introduce
\[
z_0,\ldots,z_q;\qquad p_0,\ldots,p_q;\qquad
y_0,\ldots,y_q;\qquad u,v.
\]
Let $C_i=(\neg z_{i-1}\vee z_i)$ if $b_i=1$, and
$C_i=(\neg z_{i-1}\vee\neg z_i)$ if $b_i=0$.
Put
\[
\begin{split}
B_{q,b}={}&(z_0\vee u)(z_0\vee\neg u)
(y_q\vee v)(y_q\vee\neg v)(\neg z_0\vee p_0)\\[-2pt]
&{}\land\bigwedge_{i=1}^{q}(\neg p_{i-1}\vee p_i)
\land\bigwedge_{i=1}^{q}C_i,
\end{split}
\]
where adjacent parenthesized clauses in the first line are also joined
by $\wedge$. Define the genuine ternary XOR quartet
\[
X_i=(z_i\vee y_i\vee\neg p_i)
\land(z_i\vee\neg y_i\vee p_i)
\land(\neg z_i\vee y_i\vee p_i)
\land(\neg z_i\vee\neg y_i\vee\neg p_i).
\]
It is equivalent to $z_i\oplus y_i\oplus p_i=0$.
Our target family is
\[
\boxed{H_{q,b}=B_{q,b}\wedge\bigwedge_{i=0}^{q}X_i.}
\tag{1}
\]
All variables are active; every clause is proper, all clauses have
width two or three, no initial unit exists, and every variable has
both signs somewhere in the full input.
The XOR-triple variable supports
$\{z_i,y_i,p_i\}$ are pairwise disjoint, although the \emph{binary}
clauses couple these triples. This is not disjoint-component padding.

The exact unpadded ledger is
\[
\begin{gathered}
n=3q+5,\quad m_2=2q+5,\quad k=4(q+1),\quad
M=m_2+k=6q+9,\\
w=\left\lceil\log_2(64(n+M+1))\right\rceil
=\left\lceil\log_2(64(9q+15))\right\rceil,\\
\boxed{N=(4M+2)w=(24q+38)w.}\tag{2}
\end{gathered}
\]
The source variables are $z_0,\ldots,z_q,u,v$: $q+3$ originals.
There are $2(q+1)$ new functional auxiliaries $p_i,y_i$,
no new free auxiliaries, and no eliminated source variables ($d=0$).
The source's $u,v$ remain genuinely free in every satisfying fiber.

\begin{theorem}[PROVED/EXACT: labels, witness bijection and backdoors]
For all $q,b$:
\[
H_{q,b}\in\UNSAT\iff b=1^q,\qquad
\#\SAT(H_{q,b})=\#\SAT(F_b),
\tag{3}
\]
where $F_b$ is the specified original $q$-orientation 2-SAT chain.
Moreover the minimum \emph{raw syntactic strong} 2-CNF backdoor is
\[
\boxed{h(H_{q,b})=q+1=k/4.}\tag{4}
\]
The binary-only skeleton $B_{q,b}$ is satisfiable for \emph{every}
$b$, including those for which $H_{q,b}$ is UNSAT.
\end{theorem}
\begin{proof}
The first endpoint pair entails $z_0=1$. The implication
$z_0\to p_0$ and the $p$ chain entail $p_0=\cdots=p_q=1$.
Each quartet then becomes the two binary clauses
$(z_i\vee y_i)$ and $(\neg z_i\vee\neg y_i)$, forcing
$y_i=\neg z_i$. The other endpoint pair entails $y_q=1$,
hence $z_q=0$. The remaining $C_i$ are exactly those in $F_b$.
All $b_i=1$ propagate $z_q=1$ from $z_0=1$ and contradict it.
A first zero permits setting $z_i=1$ before that position and
$z_i=0$ from that position onward. Each source model extends
uniquely via $p_i=1,y_i=1-z_i$, proving the counting bijection.

Each four-clause XOR quartet has the same underlying triple, and
different quartets have disjoint triples. Under raw restriction, a
strong 2-CNF backdoor must contain at least one variable from each
triple, regardless of the value assigned; selecting all $p_i$ suffices.
This proves (4). For the binary skeleton, set $z_0=1$, choose
$z_i=b_i$ when $z_{i-1}=1$ and $z_i=0$ otherwise; set every $p_i=1$
and $y_q=1$. All binary clauses are satisfied; the unused $y_i$ and
$u,v$ may be chosen freely.
\end{proof}

\section{One-seed trigger and adaptive trajectory}
Define a separate, \emph{analysis-only} parameter $g_B(F)$: the
minimum number of sound locally binary-resolvable unit seeds which,
under ordinary binary unit propagation, assign at least one variable
from every original ternary-clause support. If no such seeds exist,
set $g_B=\infty$. The seed must be justified by an actual pair of
binary source clauses; its discovery is not free. For (1),
\[
\boxed{g_B(H_{q,b})=1,\quad h(H_{q,b})=q+1.}\tag{5}
\]
Indeed the two clauses on $(z_0,u)$ resolve to the seed $z_0$,
whose binary implication closure contains all the $p_i$.
There are no initial unit clauses, so zero seeds propagate nothing.
The algorithm below does not receive either optimal parameter.

\begin{theorem}[PROVED/EXACT: source-independent hybrid upper bound]
There is a single total uniform deterministic exact CNF decider
$\mathcal A_{\mathrm{hyb}}$ that, on every $H_{q,b}$, charges
$O(n+M)=O(q)=O(N/\log N)$ addressed-word operations and $O(q)$
peak live words, counting full source reads, rule discovery,
unit propagation, ternary simplification, SCC solving, witness
verification, policy tests and switching. The algorithm is exact on
\emph{all} finite CNF inputs by a complete deterministic fallback.
\end{theorem}
\begin{proof}
Read the entire input as CNF, collect its binary clauses, and use
hashed binary-pair checks to derive sound units $a$ from
$(a\vee x)\wedge(a\vee\neg x)$. Propagate them by a watched
binary implication adjacency graph. Restrict \emph{all} clauses by
these logically implied units. If an empty clause appears, return
UNSAT. If only width-at-most-two clauses remain, apply the standard
linear-time SCC 2-SAT procedure, reconstruct an assignment including
the forced units, and verify it on the original input. Otherwise run
an ordinary complete DPLL fallback. Every rule is sound on arbitrary
CNFs. On (1), the first binary pair discovers $z_0$, which
propagates along $p_0,\ldots,p_q$, killing all ternaries.
The all-one UNSAT case is detected by a falsified quartet after
binary closure; the SAT cases reduce to 2-CNF and use SCC.
The source input, binary adjacency graph, restricted formula,
SCC arrays and witness occupy $O(n+M)$ simultaneously live words.
All relevant steps scan at most $O(n+M)$ nodes, edges or clauses.
\end{proof}
A direct source-aware grammar recognizer and check for a zero bit
is a \emph{second}, equally fast, uniform policy on this image.
The hybrid is useful as an alternative \emph{without knowing that
grammar or the target label}; no mandatory use of the hybrid is
claimed.

\paragraph{Adaptive-state ledger (the actually tested path).}
At $S_0$, the source is raw (1); the analysis knows
$(n,M,k,h,g_B)=(3q+5,6q+9,4q+4,q+1,1)$, but the solver knows
only the parsed clause stream, clause widths and its current
working state. It pays $(4M+2)$ addressed-word reads to acquire it.
At $S_1$, pair discovery yields source-certified units including
$z_0$ and $y_q$, at $O(M)$ hashed comparisons. Implication
propagation obtains every $p_i$ and perhaps some $z_i$;
a linear-size graph and queue are charged.
The choice between immediate conflict and clause restriction is
determined by observed state, not an SAT/UNSAT oracle.
At $S_2$ the live ternary count is zero; an empty clause may
already certify UNSAT. Otherwise $S_3$ holds a binary residual,
and SCC produces a SAT witness or an UNSAT SCC certificate.
The SAT witness is replayed over the original source.
The policy includes a correct DPLL fallback for unrecognized
residuals. Its measured event counts comprise reads, pair probes,
implication traversals, clause touches, graph operations, selection
tests, switches and verification. The parameter vector evolves
rather than being assigned one fixed exponential work formula.

\section{Restricted static comparison and acquisition lower bound}
The standard backdoor algorithm can select $S=\{p_0,\ldots,p_q\}$
and try all $2^{q+1}$ assignments, solving the restricted 2-CNF at
each leaf. If a \emph{restricted} fixed policy deliberately makes
every complete leaf assignment before using any binary propagation
or pruning, it makes exactly $2^{q+1}$ leaf calls on both our
all-one UNSAT input and the SAT input $b=(0,1,\ldots,1)$:
every leaf except the final all-one $p$ assignment contradicts
the binary source. This is a bound on that policy, \emph{not}
on DPLL, CDCL, optimal backdoor algorithms or all adaptive deciders.
A competent solver can propagate the same $p_i$ before branching.

For the all-one UNSAT input, flipping \emph{any one} orientation
sign in $C_i$ produces SAT while preserving length, identifiers
and all other words. The changed signed-literal fields are disjoint.
Every deterministic exact decider of the full fixed-width language
must therefore inspect all $q$ fields on that input, yielding
\[
\boxed{\Omega(q)=\Omega(N/\log N)}
\tag{6}
\]
addressed-word probes. The upper bound matches. A machine with
larger packed-word access or another grammar requires a new charge;
(6) is no encoding-independent $\Omega(N)$ theorem.

The canonical forward map $F_b\mapsto H_{q,b}$ has $O(q)$

\paragraph{Hostile controls.}
SCC on the binary skeleton alone always reports SAT and is
therefore \emph{incorrect} on the full all-one family.
Affine Gaussian elimination can recognize the XOR quartets,
but the arbitrary binary backbone is not promised affine.
Horn-only reasoning is incomplete on raw positive/negative
quartets. Proper-3CNF free-variable padding preserves labels
but changes counting and can leave no forced pivot.
Independent components, source-readable witnesses,
reordering, variable complementation, caching and direct
recognition are alternate shortcuts, not hardness amplifiers.
A finite method portfolio is never a proxy for all deciders.
