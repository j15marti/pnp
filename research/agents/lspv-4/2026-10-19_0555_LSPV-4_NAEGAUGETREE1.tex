\subsection*{Construction}
Let $F=\bigwedge_{i=1}^m(a_i\vee b_i\vee c_i)$ be a nonempty proper signed
3-CNF.  Give the $m$ clauses as leaves of a full binary tree $T$.  Introduce
$u_i,p_i$ at leaf $i$, one gauge $q_v$ at every internal node, and one fresh
$e_{xy}$ per tree edge $xy$.  Add
\[
 A_i=\operatorname{NAE}(a_i,b_i,u_i),\qquad
 B_i=\operatorname{NAE}(\neg u_i,c_i,p_i),
\]
and for every edge $xy$ of $T$ add
\[
 E^0_{xy}=\operatorname{NAE}(x,\neg y,e_{xy}),\qquad
 E^1_{xy}=\operatorname{NAE}(x,\neg y,\neg e_{xy}).
\]
Here a leaf's tree variable is $p_i$ and an internal node's tree variable is
$q_v$.

\paragraph{Lemma 1 (equality edge, PROVED/EXACT).}
The two clauses $E^0_{xy},E^1_{xy}$ are jointly satisfiable in $e_{xy}$ iff
$x=y$.  If $x=y$, both values of $e_{xy}$ work.  This follows by the four-row
truth table and is also exhaustively checked by the attached program.

\paragraph{Lemma 2 (decision and witness equivalence, PROVED/EXACT).}
The target is satisfiable iff $F$ is satisfiable.  Moreover both witness maps
are uniform and linear-time after parsing.

\emph{Proof.} Lemma 1 makes all tree gauges equal to one bit $g$.  For fixed
$g$, existential elimination of $u_i$ gives
\[
 \exists u_i\,[A_i\wedge B_i]
 \quad\Longleftrightarrow\quad
 \begin{cases}
 a_i\vee b_i\vee c_i,&g=0,\\
 \neg a_i\vee\neg b_i\vee\neg c_i,&g=1.
 \end{cases}
\]
Thus a target witness $X$ projects to the source witness
$x_j=X_j\oplus g$.  Conversely, from a source witness $x$, choose either
$g$, set every tree gauge to $g$, set target source coordinates to
$X_j=x_j\oplus g$, choose each $u_i$ from its two-row local table, and set all
$e_{xy}=0$.  Every clause is then satisfied.  This also proves that there is
no hidden absolute pin: simultaneous complementation of all target variables
preserves every signed NAE clause. \qed

\paragraph{Lemma 3 (size, properness, degree, PROVED/EXACT).}
The compiler has
\[
 N=n+5m-3,\qquad M=6m-4.
\]
Indeed, besides the $n$ source variables there are $m$ variables of each of
types $u,p$, $m-1$ internal gauges, and $2m-2$ edge variables.  There are
$2m$ frontend clauses and $2(2m-2)$ equality clauses.  All triples are proper
because every introduced variable is fresh.  Occurrences are: $u_i:2$;
$p_i:3$; internal gauge $q_v:2\deg_T(v)\leq6$; and $e_{xy}:2$.  Hence maximum
auxiliary occurrence is six (and therefore at most eight).  Source-variable
occurrences are unchanged. \qed

\paragraph{Lemma 4 (aligned separator, PROVED/EXACT).}
Delete a tree edge $xy$ and partition the source clauses by the resulting leaf
sets.  If the source boundary contains $w$ variables, assign each frontend to
its leaf component, every non-cut equality gadget to its component, and the
cut-edge gadget to the child component.  Then the target boundary is exactly
the source boundary plus the parent endpoint $y$, hence has size $w+1$.

\emph{Proof.} Every non-cut tree edge has both endpoints in one component.
The fresh edge variable of the cut gadget occurs nowhere else.  Its child
endpoint remains on the child side, while its parent endpoint also occurs in
the nonempty complementary tree component.  Frontend auxiliaries are local.
Only original variables already shared by source clauses can contribute any
other boundary variable. \qed

This establishes explicit $6\mapsto7$ and $8\mapsto9$ ledgers for aligned
cuts.  It does not preserve an arbitrary clause partition: with pairwise
disjoint source clauses and alternating colours on sibling leaves, exact tree
dynamic programming finds a minimum of $m/2$ bichromatic equality edges for
$m=8,16,32$.  Thus the tree repairs the old path only when its topology is
aligned with the intended recursive decomposition; it is not a universal
separator shrinker.
