\section{Claim card, encoding, and exact quantifiers}
Fix one self-delimiting binary encoding of CNF formulas.  Let \(|F|=n\) be
encoded input length, not variable count.  Let \(\mathcal D_{\SAT}\) be the
class of total deterministic uniform exact SAT deciders:
\[
 \forall D\in\mathcal D_{\SAT}\ \forall G,\qquad
 D(G)=\mathbf 1[G\in\SAT].
\]
Fix three uniform deterministic machines, independent of \(D\):
\begin{enumerate}[leftmargin=*]
\item an adaptive oracle extractor \(E\), which on \(F\) issues queries
\(G_1,\ldots,G_q\) and produces transcript \(\tau\);
\item an accessor \(A(F,\tau,i)\) for a possibly exponentially long virtual
object \(Z(F,\tau)\); and
\item an evaluator \(V\), which adaptively chooses
\(i_1,\ldots,i_r\), receives the accessor bits, and outputs one bit.
\end{enumerate}
All parsing, query generation, encoding, calls, failed routes, transcript
retention or replay, address generation, access, reconstruction, validation,
and output are charged.  There is no free table, advice string, persistent
cross-call state, or oracle other than the displayed SAT calls.

The false candidate asserted that any successful such construction shows that
the original single run \(D(F)\) exposed or paid for \(\tau\), \(Z\), or the
queried bits.  The exact quantifier mismatch is
\[
 \underbrace{D(F)}_{\text{one selected run}}
 \quad\ne\quad
 \underbrace{V^{A(F,E^D(F),\cdot)}(F)}_{\text{new composed execution}}.
\]

\section{Clean-core semantic compatibility}
For a CNF \(F\) and consistent partial assignment \(\alpha\), define
\[
 H(F,\alpha)=1
 \quad\Longleftrightarrow\quad
 \exists\beta\supseteq\alpha\;[\beta\models F].
\]
This is a semantic object.  Any selected value is externally decidable by a
separate call on \(F\upharpoonright\alpha\); a lexicographically least
witness is externally recoverable by at most one initial SAT query plus one
restriction query per variable.  Those facts do not imply that \(D(F)\)
materializes the table of \(H\), a witness, a frontier, or a canonical
representation.  A decision algorithm is required to return only one bit.

The corrected signed Monotone \(3\)SAT-\((2,2)\) clean core is NP-complete.
Accordingly, a direct all-algorithm superpolynomial lower bound on that fixed
encoded core would itself separate \(P\) from \(NP\); no extension from the
core to every unrestricted 3-CNF family is required.  The missing statement
is still universal over every uniform decider for that core, so easy
subfamilies and equivalent wrappers remain decisive hostile controls against
an unqualified exposure claim.

\section{Exact composition theorem}
\paragraph{Theorem (black-box lazy composition gate).}
Assume \(\SAT\in\Pclass\), witnessed by a total deterministic uniform decider
\(D\) satisfying \(T_D(m)\le m^K\) for all sufficiently large \(m\), for
some finite \(K\).  Suppose, on every length-\(n\) source input:
\begin{itemize}[leftmargin=*]
\item \(E\) has charged local work \(t_E(n)\), makes
\(q(n)\le n^b\) SAT queries, and every query has length at most \(n^c\);
\item \(V\) has charged local work \(t_V(n)\), makes
\(r(n)\le n^e\) accessor calls, and every address has length at most
\(n^d\); and
\item one accessor call, including source/transcript reads, costs at most
\(n^{a\max\{1,d\}}\), with every transcript replay or retained-state cost
included.
\end{itemize}
If \(t_E,t_V\) and all encoding/output costs are polynomial, then there is
one ordinary deterministic uniform polynomial-time machine \(C_D\) producing
the same output as the extractor--accessor--evaluator composition.

\paragraph{Proof.}
Inline every oracle instruction of \(E\) with a fresh run of \(D\).  Store or
replay the resulting transcript exactly as specified.  Inline each accessor
call made by \(V\), including construction of its address and every read of
\(F\) or \(\tau\).  Determinism and exactness of \(D\) preserve the entire
adaptive transcript.  The resulting ordinary machine has time
\[
\begin{split}
T_{C_D}(F)\ \le\ &t_E(F)+\sum_{j=1}^{q(F)}T_D(G_j)+t_V(F)\\
&+\sum_{\ell=1}^{r(F)}T_A(F,\tau,i_\ell)
+T_{\rm enc/replay/out}(F).
\end{split}
\]
The oracle part is at most \(n^{b+cK+o(1)}\), and the accessor part is at
most \(n^{e+a\max\{1,d\}+o(1)}\).  Taking the maximum with the fixed local
exponents proves polynomial time.  Peak workspace is the retained extractor
and evaluator state, query/address buffers, transcript storage or replay
state, and the maximum workspace of one active subcall; it is not obtained by
adding time to space. \hfill\(\square\)

\paragraph{Transcript extensionality.}
For any two exact deciders \(D_0,D_1\), induction on the adaptive query
number gives the same query strings and SAT-answer bits.  Hence \(E^{D_0}(F)\)
and \(E^{D_1}(F)\) produce the same transcript, and the fixed accessor and
evaluator produce the same semantic output.  Internal traces and costs may
differ arbitrarily.

\paragraph{Trilemma.}
There are only three accounting outcomes for this architecture:
\begin{enumerate}[leftmargin=*]
\item polynomially many polynomial-length charged calls with polynomial
local work compose to an ordinary \(\Pclass\) machine;
\item a superpolynomial call count, query/address length, accessor, replay, or
local component leaves the desired polynomial bridge unproved; or
\item free table bits, uncharged calls, or per-length hardwiring introduce
advice/oracle/nonuniform power and change the model.
\end{enumerate}

\paragraph{No fixed landing.}
Even in the first branch the bound contains \(b+cK\).  Since the hypothesis
``\(\SAT\in\Pclass\)'' supplies some finite but otherwise arbitrary \(K\),
the composition theorem provides no fixed solver-independent exponent and no
contraction into a prescribed Fortnow--Lipton--van Melkebeek--Viglas
time--space forbidden region.  A theorem removing that dependence would be a
new load-bearing result, not an accounting corollary.

\section{Primary-literature and transfer preflight}
The two current obstacles are (i) a source-defined transfer into the same
fully charged ordinary realization and (ii) an absolute endpoint whose
parameters do not depend on an arbitrary source exponent.
\begin{itemize}[leftmargin=*]
\item Cook's NP-completeness theorem is directly transferable: a lower bound
for every uniform polynomial decider of one fixed NP-complete clean core is a
separation, not merely evidence about an exact-SAT base.
\item Baker--Gill--Solovay relativization and Aaronson--Wigderson
algebrization are \KNOWN{} barriers.  The transcript and inlining arguments
relativize and algebrize; they are guards, not escapes.
\item Galperin--Wigderson's succinct-representation phenomenon is a useful
direct warning: exponentially large semantic objects can have compact
generators, so length alone is not runtime.
\item Bogdanov--Trevisan's worst-case/average-case barriers make an LWE-style
external-extraction analogy nonautomatic.  Their theorem is not imported as
a SAT lower bound.
\item FLMV time--space lower bounds are directly transferable only after the
same fully charged ordinary realization is proved to lie in the theorem's
exact model and simultaneous resource region.  No such landing is obtained.
\end{itemize}

Electronics/VLSI congestion, control observability, distributed
communication cuts, feasible interpolation, and local-to-global gluing are
useful structural analogies requiring a new interface-preserving transfer
theorem.  Treating work performed by an external module as work performed by
the queried component is a misleading analogy and is rejected.

\section{Barrier audit}
\paragraph{SAME\_REALIZATION.}
The theorem preserves it only for \(C_D\), which pays for every component.
It gives no retrospective charge to the original selected run \(D(F)\).

\paragraph{Wrappers and alternate representations.}
COPY, DEAD, DELAY, INTERP, and RECOMP preserve the decision function while
changing traces and costs.  Any internal-state necessity not invariant under
these transformations remains implementation dependent.

\paragraph{Nonuniformity and pointwise minimization.}
A different precomputed table or decider per input length is advice.  The
POINTINF1 pointwise infimum \(\forall n\exists A_n\) does not yield one
uniform \(\exists A\forall n\) decider and is not used.

\paragraph{Natural Proofs.}
No constructive large circuit property is given.  This theorem neither
invokes nor escapes the Razborov--Rudich barrier.

\paragraph{Protocol transfer.}
HEC, VSC-HEC, G-PPC-HEC, CRS-PPC, RCCN, and CCSPC retain exact restricted
state/causal results.  They still lack a total compiler from every static
decider and a model-matched unconditional endpoint.  Combining them with a
black-box accessor does not fill either arrow.
