\section{Coherent occurrence targets}
For each original clause $C_j$, preserve each original signed occurrence $x_{i,j}$ (the SAME global Boolean $x_i$). Local $U_j$ makes all original clause literals FALSE, demanding $x_i=0$ for positive and $x_i=1$ for negative occurrences. Local $S_j$ makes all literals TRUE; inversion swaps $S_j$ and $U_j$. Original pair SS and UU are feasible iff there is no shared opposite-signed variable; SU and US iff there is no shared same-signed variable. Ordinary SAT means at least one literal TRUE, not necessarily all three.
\begin{theorem}[Pure-literal rule; known]
If all occurrences of a variable in a residual formula share one sign, satisfying that sign preserves satisfiability. Any model with its opposite value can be changed to satisfy that sign without breaking any other clause.
\end{theorem}
\begin{theorem}[TRUE-occurrence selector is vacuous on bipolar sources]
If every variable occurs in both polarities then, for every coherent complete assignment, every variable appears as a TRUE literal in some original SAT clause. Thus selecting potential flips solely from TRUE literals in SAT clauses admits every variable. For strict signed exact-$(2+,2-)$ 3CNF each variable has exactly TWO TRUE literal occurrences under every assignment, so the original pure-variable phase is empty.
\end{theorem}
\begin{proof}If $x_i=1$ a positive occurrence is TRUE, and if $x_i=0$ a negative occurrence is TRUE. A TRUE literal makes its containing clause SAT. Two occurrences of either sign give the exact signed22 count.\end{proof}
