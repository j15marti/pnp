## Established family, encoding and lower-bound model
Let $G$ be a simple cubic graph on even $H$ vertices with a specified Hamiltonian cycle $e_i=(i,i+1\bmod H)$ and a complementary perfect matching $m_j=(u_j,v_j)$, $u_j<v_j$. For each vertex $v$, with its three incident edge IDs $a<b<c$, define exactly four original proper signed 3-CNF clauses:
$$
C_{v,p,q}=\ell_p(x_a)\vee\ell_q(x_b)\vee\ell_{p\oplus q\oplus1\oplus\chi_v}(x_c),\quad
p,q\in\{0,1\},\quad\ell_0(x)=x,\quad\ell_1(x)=\neg x .
$$
This is the full CNF of $x_a\oplus x_b\oplus x_c=\chi_v$ with $4H$ clauses and $12H$ literal occurrences. The finite Möbius-ladder control uses $m_j=(j,j+H/2)$ and compact IDs, whose project packet has $N=12H(w+1)+4H+12$, $w=\lceil\log_2(3H/2+1)\rceil$. To cover *arbitrary* Hamiltonian matchings without a free matching table, use an alternate **canonical endpoint-coded original-3CNF encoding**: $\mathrm{id}(e_i)=H^2+1+i$, $\mathrm{id}(\{u,v\})=1+H\min(u,v)+\max(u,v)$. Each variable ID uses $O(\log H)$ bits, so $N=\Theta(H\log H)$. Clause positions are canonical by vertex and $p,q$ order. Locally decode the matching partner; retrieve its indexed quartet and verify reciprocal IDs and all signed facets. Reject inconsistent partners, bad signs, duplicate slots, malformed lengths and IDs. Indexed sequential authentication takes $O(N\,\mathrm{polylog}N)$ time and $O(\log N)$ work space, conditional on this precisely specified packet.

For growing cubic expander graphs satisfying Urquhart's hypotheses and with odd charge, the corresponding original Tseitin 3-CNF has $2^{\Omega(H)}$ **ordinary shared-DAG Resolution** lower bounds. Suitable Hamiltonian cubic expanders exist by published random-regular graph results; the variable-ID recoding is bijective renaming, so it preserves Resolution proof length exactly with $O(\log H)$ bits per occurrence. **This is not hardness for ER, GF(2), full $R_{\rm mix341}$, or arbitrary SAT algorithms.** The finite Möbius ladders are correctness controls, not certified growing hard sequences. Global GF(2) charge parity is a known efficient shortcut for every connected graph in this family.

## Theorem 450.1 (PROVED/RESTRICTED)
Choose up to $k=O(\log N)$ matching edges using the first $k$ anchor vertices, storing each unique chosen matching edge once (if both endpoints are anchors, use the smaller endpoint). Let $\alpha,\beta$ be two assignments to these edges and $d_j=\alpha_j\oplus\beta_j$. For each cycle edge $e_i$ define
$$
z_{e_i}=\bigoplus_{j\text{ selected}}d_j\,\mathbf1\{u_j\le i<v_j\},\qquad z_e=0\ \text{for unselected matching }e.
$$
Then $z_{e_{H-1}}=0$ and translating unassigned variables by $x_e\mapsto x_e\oplus z_e$ induces a bijection $F_\alpha\cong F_\beta$ **on the exact original signed residual-clause multisets** (not just the SAT labels). Each cofactor has $4(H-2m)$ ternary and $4m$ binary clauses, where $m\le k$ is the number of distinct matching edges fixed; its ordinary encoded size is still $\Theta(N)$ when $k=O(\log N)$.

**Proof.** Changing selected matching bit $j$ affects vertex charges precisely at its two endpoints. The cycle-edge prefix-cut indicator has incidence boundary precisely these two endpoints. By linearity over GF(2), $B_{\rm cycle}z=B_S(\alpha\oplus\beta)$. At every vertex the residual charge changes by the incidence of $z$, so translating remaining variables maps the local XOR equation under $\alpha$ into the equation under $\beta$. The four local signed clauses enumerate all forbidden truth triples. After fixing a matching bit the two remaining binary clauses enumerate the forbidden residual pairs. Translating cycle variables permutes exactly those forbidden patterns and hence the complete clause multiset. QED.

**Explicit resource construction.** For a query $z_{e_i}$, scan the first $k$ anchor vertices, read each selected matching partner from its authenticated ID, and XOR the matching assignment difference iff the interval straddles cut $i$. No $H$-bit gauge array and no $k\log H$ pointer list. There are only $O(k)=O(\log N)$ branch bits; addresses, comparisons, counters and index heads use $O(\log N)$ bits. With indexed-input access, each query costs $O(k\operatorname{polylog}N)$ bit steps and $O(\log N)$ work bits. Streaming all $H$ gauge bits costs $O(Hk\operatorname{polylog}N)=O(N\operatorname{polylog}N)$ time and logarithmic temporary space. Source inspection, reciprocal indexed reads, complete canonical signed-clause authentication and index updates are included in the stated bounds. A write-only output stream is **not** a free writable child buffer.
