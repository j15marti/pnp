\section{A tight one-query unindexed selector acquisition floor}
Let \(m\ge1\). A bit-query input is \(b=x1^m\) of length \(2m\), where
\(x\in\{0,1\}^m\) is unknown. The query
\(\operatorname{Select}_m(b)\) returns the one-based position of the
\(m\)-th \(1\) in \(b\). No preprocessing advice or maintained prefix-index
representation is supplied. Every physical input-bit read is charged,
whether the input head is sequential or indexed.

\begin{theorem}[Exact unindexed source-probe floor]\label{th:select}
For all \(m\) and \(x\), with \(|x|\) the Hamming weight,
\[
  \operatorname{Select}_m(x1^m)=2m-|x|.
\]
Every deterministic, total, exact bit-probe algorithm answering this
query on the declared family must probe all \(m\) unknown prefix bits
when \(x=0^m\), even with unrestricted computation and writable memory.
The bound is attained by an \(m\)-probe sequential count using
\(O(\log(m+1))\) writable bits. With any preprocessing stage, the
\emph{combined} preprocessing-plus-query source-probe count on
\(0^m1^m\) is at least \(m\).
\end{theorem}
\begin{proof}
If the prefix contains \(w\) ones, the \(m\)-th one appears as the
\((m-w)\)-th suffix one at position \(m+(m-w)=2m-w\), with the
\(w=m\) endpoint giving the same formula. Let the input be \(0^m1^m\).
For any unprobed prefix coordinate \(i\), changing only \(x_i\) from
zero to one leaves every answer in the executed deterministic probe
transcript unchanged, including all suffix bits, but changes the
correct output from \(2m\) to \(2m-1\). This contradiction applies
independently to all \(m\) coordinates, and to the combined
preprocessor/query transcript. Conversely, count all \(m\) prefix bits,
store \(w\) in \(\lceil\log_2(m+1)\rceil\) bits, and return \(2m-w\).
\end{proof}

\begin{corollary}[No automatic repeated-query direct sum]
Once the \(m\)-bit prefix has been scanned and \(w\) retained,
\(q\) further requests for the \emph{same} \(\operatorname{Select}_m\)
need no additional source bit probes. Thus the theorem does not
imply \(\Omega(qm)\) time or a linear-memory lower bound.
\end{corollary}
This is an \emph{unindexed binary metadata} result, not a direct
lower bound for ordinary 3CNF, its semantic SAT value, or the
arithmetically addressable W1 occurrence map. A complete
source-to-metadata compiler and its length/space costs must be
proved separately before applying it to an ARC construction.

\section{Quantitative failure of virtual movement as indexed bit-time}
Fix the ordered, exact signed-(2,2) W1 DISJ promise family of peer report
142, of physical encoded length \(N=\Theta(m\log m)\) and a common
middle gap of \(G=\Theta(N)\) bits. Let a fixed exact indexed-input
decider \(A\) make \(Q\) input-bit probes to physical positions
\(a_1,\dots,a_Q\in[0,N-1]\), and define the artificial source-path
movement \(D=\sum_{i=2}^{Q}|a_i-a_{i-1}|\).
Let \(B_A\) be the number of bits in its complete \emph{counted}
indexed-RAT configuration for the communication-cut simulation;
one cannot replace this by the time of a different machine.

\begin{theorem}[Virtual-path-to-probe projection; restricted]\label{th:proj}
For any such input trace, \(D\le N(Q+1)\).
Consequently, if the previously established restricted W1
communication argument supplies on one SAT input
\[
  (D+1)(B_A+1)=\Omega(N^2/\log N),
\]
then on that same input it supplies at most the necessary implication
\[
  (Q+1)(B_A+1)=\Omega(N/\log N).
\]
For the counted-bit model \(B_A=O(S_A+\log(T_A+N+2))\),
the projected exponent condition is no stronger than
\(q+s\ge1\) for polynomial time and work space.
\end{theorem}
\begin{proof}
Each of the \(Q-1\) successive physical addresses differs by at most
\(N-1\). Allowing a possible initial or final address only adds
\(O(N)\). Hence \(D+1\le N(Q+1)+1\). Substitute this upper bound
into the stated predecessor lower bound and cancel a factor \(N\).
For polynomial-resource ceilings, logarithmic terms cost exponent zero.
\end{proof}

\noindent\textbf{Hostile matching control.}
The indexed algorithm reading W1 A and B sign controls for each
component alternately uses \(Q=2m\), computes addresses from the known
fixed-width template in \(\operatorname{polylog}N\) bit-time each,
and retains \(O(\log N)\) bit counters. Its total time is
\(O(m\operatorname{polylog}N)=N^{1+o(1)}\) on the \emph{promise}
family, even though the alternation forces
\(D=\Theta(mN)=N^{2-o(1)}\) virtual address displacement.
For \(m=512\), the reproduced canonical lengths are

\(D=405358678\). This is a direct counterexample to charging
\(D\) as RAT head-movement time, not to any communication bound.
