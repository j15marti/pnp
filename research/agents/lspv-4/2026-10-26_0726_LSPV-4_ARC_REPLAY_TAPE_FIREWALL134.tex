\section{Typed proof interface and exact state lower bound}
Fix $N$ as the physical bits of the original ordinary SAT source, on an indexed read-only source tape. Distinguish the $P$-bit proof supplied (i) as a sequential nondeterministically chosen stream, (ii) as a genuinely independent two-way indexed read-only tape, or (iii) as a physically stored, previously guessed writable region. Only (i) and the charged construction (iii) are used below without any extra proof-oracle assumption.

For $k\ge1$, consider the abstract source-independent compatibility interface which first supplies all bits of $u\in\{0,1\}^k$ and only then supplies $v\in\{0,1\}^k$. Define
\[
 \operatorname{REPLAY}_k(u,v)=1\iff u=v.\tag{1}
\]
This is a deliberately restricted model of repeated proof commitments, \emph{not} the LSPV-3 BRANCH/EMPTY/PATH certificate language and \emph{not} ordinary SAT.

\begin{theorem}[One-way exact replay-state barrier]\label{th:eq}
Every standard one-pass deterministic or nondeterministic exact checker for (1), with at least one accepting run on each equal pair and no accepting run on unequal pairs, has at least $2^k$ distinct reachable midpoint configurations after consuming $u$. Thus at least $k$ bits of distinguishable live state are needed; standard finite-alphabet constant-tape machines require $\Omega(k)$ writable/index storage.
\end{theorem}
\begin{proof}
For each $u$, select an accepting computation of $uu$, and let $q_u$ be the complete machine configuration just after the first $k$ proof bits. If $q_u=q_w$ for different $u,w$, splice the legal computation prefix of $ww$ through $q_w$ with the accepting continuation for $uu$ after $q_u$, whose remaining input is $u$. The same fixed SAT source, proof-head position, live tapes and transition relation give an accepting computation of $wu$. This contradicts exact soundness since $w\ne u$. The argument applies to nondeterminism because it copies legal choice sequences. All $2^k$ states $q_u$ therefore differ. Tape-head positions and finite control add at most polynomial factors in the number of live finite-alphabet cells, yielding $\Omega(k)$ writable bits. Absolute wall-clock advice or a preloaded independently indexed guessed tape is not part of the standard machine.
\end{proof}
\begin{corollary}[No free replay-DAG extension]
Suppose $k=\lceil N^{3/5}\rceil$, proof replay payload $P=2k$ bits and semantic branch depth $h=O(1)$. A one-way checker enforcing (1) cannot use just $O((h+1)\log(N+P))$ live bits. Its information-storage exponent $3/5$ is strictly outside the selected FLMV space region:
\[

 =\frac{2296961}{23232400}>0,\qquad
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).\tag{2}
\]
This is only a one-way checker/ordering obstruction. Different canonical proof schedules, recomputation, externally supplied read-only certificates and other SAT solvers can evade it.
\end{corollary}

\section{Charged proof materialization and separate ARC costs}
\begin{theorem}[Uniformly capped proof-tape conversion]\label{th:conversion}
Suppose one fixed deterministic verifier $V(F,\pi)$ is sound for \emph{every} ordinary $N$-bit SAT input $F$: all proposed proofs fail on SAT sources, while each UNSAT source has one accepted proof of length at most a computable length-only cap $P_*(N)$. If, with a genuine two-way indexed read-only proof tape, $V$ runs in time $T_V(N,P)$ and space $S_V(N,P)$ including physical parsing and access, then a standard co-nondeterministic SAT machine can nondeterministically \emph{guess, write, and retain} at most $P_*$ proof bits, simulate $V$, and reject if and only if validation succeeds. Every malformed or timed-out branch accepts. Its resource bounds are conservatively
\[
 T=O\left(P_*\operatorname{polylog}(P_*+2)+\max_{P\le P_*}T_V(N,P)
       \operatorname{polylog}(N+P_*+2)\right),\tag{3}
\]
\[
 S=O\left(P_*+\max_{P\le P_*}S_V(N,P)+\log(N+P_*+2)\right).\tag{4}
\]
If $P_*\le N^{a+o(1)}$ and $T_V\le(N+P_*)^{1+o(1)}$, the coNTIME exponent is at most $\max(1,a)$, \emph{not} an asserted deterministic space exponent.
\end{theorem}
\begin{proof}
Set a length-only cap and global timeout. On each computational branch, choose proof bits and physically write each to the work region, charging the writes and indexes. Treat that fixed region as the indexed simulated proof input. On SAT all guesses fail sound verification, hence all branches accept. On UNSAT some valid guessed proof succeeds, hence some branch rejects, giving the co-nondeterministic SAT polarity. Model-conversion polylog overheads and the full retained tape are included in (3)--(4). No deterministic proof finder is used.
\end{proof}

For deterministic ARC there is no externally chosen valid $\pi$: the one fixed all-input algorithm must discover the candidate, count failed attempts, pay source reads, verifier/generator time, retain or regenerate every proof bit, and pay simultaneous peak writable/index memory. Simply retaining a proof of $\Theta(N^{3/5})$ bits violates the selected $N^{0.501131\ldots}$ space target. This only rules out that storage policy and not all SAT algorithms.
