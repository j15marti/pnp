\section*{Fixed-DAG frontier theorem}
Let $V$ be those 62 RES identities and $u\prec v$ when $u$ is a paid RES parent of $v$. SOURCE parents are freely retrieved from read-only original input but still incur physical access cost outside this slot proxy. For an order ideal $D\subseteq V$, let
\[
L(D)=\{u\in D:\text{some RES consumer }v\notin D\text{ uses }u\}.
\]
For a complete topological ordering $\sigma=(v_1,\ldots,v_{62})$, put $D_i=\{v_1,\ldots,v_i\}$ and $D_0=\varnothing$. The fresh-before-release retained-result peak is exactly
\[
S_{\mathrm{fresh}}(\sigma)=\max_{1\le i\le62}\bigl(1+|L(D_{i-1})|\bigr).
\]
\begin{theorem}[Complete ideal-state decision recurrence]
For any finite fixed acyclic inference DAG and the specified fresh-result, last-use, no-recomputation execution model, define
\[
\mathrm{Reach}_b(\varnothing)=1,\quad
\mathrm{Reach}_b(D\cup\{v\})\gets1
\]
whenever $\mathrm{Reach}_b(D)=1$, $v\notin D$, $\mathrm{Pred}(v)\subseteq D$ and $1+|L(D)|\le b$.
Then a completed schedule of fresh peak at most $b$ exists if and only if $\mathrm{Reach}_b(V)=1$.
\end{theorem}
\textbf{Proof.} Every actual execution prefix without recomputation produces an order ideal $D$. Every already computed paid result with a later unexecuted consumer must remain live; deleting it would make that consumer impossible without a newly paid repeated computation. Results with no future consumer can be released immediately, which is never worse than keeping them. Before computing the next node, a fresh output occupies an additional slot while any live parent has not yet been released. Hence the transition's necessary and sufficient peak condition is $1+|L(D)|\le b$. Dependency readiness is exactly $\mathrm{Pred}(v)\subseteq D$. Induct on the number of executed nodes in both directions. Every legal schedule induces a path in the recurrence, and each recurrence edge gives a realizable legal computation with immediate last-use release. $\square$

The recurrence is a \emph{complete} finite-state resource abstraction for \emph{this particular fixed DAG and schedule discipline}. Its identity map sends every concrete step into the same abstract transition, keeps the empty-clause goal, and exactly preserves native paid work $W^\#=W=63\le W_{\mathrm{concrete}}$. The state contains the complete done-set and parent-incidence relation; no shared paid owner or inference is counted twice. This does not satisfy the missing full historical calculus P2-C3 obligation.
