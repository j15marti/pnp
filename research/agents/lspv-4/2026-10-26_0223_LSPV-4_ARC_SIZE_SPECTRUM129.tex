\section{New dyadic distribution-sensitive theorem}
\begin{theorem}[Conditional all-history bucket bound]\label{th:spectrum}
Let an independently proved exact deterministic all-input SAT procedure make a sequential, adaptively chosen list of ordinary SAT calls to ONE fixed solver $A$, each input length $m_i\ge1$, with $T_A(m)\le m^{d+o(1)}$ for $d\ge1$. Suppose $M=\max_i m_i\le N^{O(1)}$ and, uniformly over every source, SAT/UNSAT label, failed strategy and attainable adaptive answer history, there are at most $B_j(N)$ actual calls with $2^j\le m_i<2^{j+1}$. Then
\[
\sum_i T_A(m_i)
\le O(\log N)\max_{j:B_j>0}\bigl(B_j(N)2^{(j+1)(d+\epsilon)}\bigr)
\]
for every fixed $\epsilon>0$, with a uniform constant. For finitely many power-scale buckets, with $B_j\le N^{a_j+o(1)}$ and $m_i\le N^{\lambda_j+o(1)}$, the sufficient guest-time exponent is
\[
h_d\le\max_j\{a_j+d\lambda_j\}.
\]
It can strictly improve upon $b+\lambda(d-1)$ where $V=\sum_i m_i\le N^{b+o(1)}$ and $M\le N^{\lambda+o(1)}$.
\end{theorem}
\begin{proof}
Choose any $\epsilon>0$ and a finite uniform $C_\epsilon$ with $T_A(m)\le C_\epsilon m^{d+\epsilon}$ for every $m\ge1$; finitely many exceptional small $m$ can be absorbed into $C_\epsilon$. Sum within each dyadic class, bound by its maximum length to power $d+\epsilon$, then multiply the maximum contribution by the $O(\log N)$ possible classes. The logarithm is an $N^{o(1)}$ factor. The bounds apply independently to each realized history, so no nonadaptive child list or free selector is needed. The coarse alternative follows termwise from $m_i^d\le m_iM^{d-1}$. \end{proof}

If all parent-local work, source scanning, invalid-input handling, policy discovery, failed routes, arithmetic, headers, certificate production, validation, copying, cache and output writes cost $N^{r+o(1)}$ and ALL aggregate indexed-access/generator work costs $N^{u_{\rm agg}+o(1)}$, then
\[
t'\le\max\{r,u_{\rm agg},h_d\}.
\]
If instead a virtual input probe in bucket $j$ costs $N^{u_j}$ \emph{per guest read}, the safe lazy upper bound is $\max\{r,\max_j(a_j+d\lambda_j+u_j)\}$, not the preceding aggregate formula. Same-machine space additionally takes the maximum of all simultaneously live physical child buffers, guest working/index tape, generator and index metadata, retained ancestor state, output/certificate buffers, retained sibling answers and failed-route data. Input and output gates, NAND wires, work-cell writes, actual bit flips and hardware metrics remain distinct.
