\section*{New theorem 586.1: every padding byte is query-essential}
\begin{theorem}[accepted-byte padding sensitivity]
Let $p$ be the original K4 compact packet above. For every nonnegative integer $n$ for which the accepted string is representable by the recovered program, let $p_n=\texttt{SPACE}^n\,p$. Then the original /341 checker accepts $p_n$ with exactly the same parsed fixture DAG, source, parent applications and stipulated $W=15$. For $n>0$, changing \emph{any} of the first $n$ bytes from \texttt{SPACE} to \texttt{\#} makes the packet reject at strict JSON parsing. Consequently, every \emph{deterministic exact} byte-query decider for this complete accepted-byte language must query all $n$ prefix positions on the \emph{accepting} input $p_n$. In the one-byte-per-query model
\[
\boxed{T_{\rm query}(p_n)\geq n,\qquad |p_n|=3090+n,\qquad W(p_n)=15.}
\]
A word-query model reading at most $w$ bytes per query gives only $T_{\rm word}\geq\lceil n/w\rceil$, not $n$.
\end{theorem}
\begin{proof}
JSON permits leading ASCII whitespace and the parsing of $p_n$ yields precisely the same JavaScript object as parsing $p$, hence the proof checker subsequently takes the same path and assesses the same logical records. Replacing one of the leading spaces with \texttt{\#} makes the JSON text syntactically invalid, and the original program rejects before any proof check. Suppose a deterministic exact decider accepts $p_n$ without querying one of those $n$ positions. Its full transcript, including all adaptively selected addresses and returned bytes, is identical on the modified input since the single changed position was never queried. It therefore also accepts an invalid byte string, contradiction. Each position must be queried. Distinct byte accesses are at least $n$; a machine word containing $w$ bytes can cover at most $w$ such positions. \end{proof}
\noindent This is a lower bound on \emph{verification of a particular padded accepted input}, not a universal lower bound on SAT solving, the optimal native $W_R$, or writable memory. The unbounded mathematical string-family assertion is conditional on permitting arbitrary finite JSON byte strings; the physical Node/V8 implementation can have finite input-size limits. This result strengthens the earlier LSPV-4/578 observation that evidence bytes can grow at constant paid $W$ by proving that the extra whitespace is \emph{query-essential} for exact-byte verification.

\[
\boxed{(Q^\star(656+k),\,S,\,B)
=\left(38700-\sum_{i=1}^k d_i,\ 656+k,\ B_0\right),

\begin{proof}
