\section*{Quantified source and native machine}
Let $H(a,b)$ be the authenticated proper signed exact-(2,2) 3CNF W1 gadget with 15 variables, 20 clauses, and satisfying-assignment counts $(772,272,272,0)$ for $(a,b)=(00,01,10,11)$. Put $m$ independent modules in the order Alice-dependent clauses, $16m$ fixed clauses, Bob-dependent clauses. The resulting ordinary source encoding $F_m(a,b)$ satisfies
\[
 \operatorname{SAT}(F_m(a,b))\iff \bigwedge_{i<m}\neg(a_i\land b_i),
 \qquad N=\Theta(m\log m),\quad G=\Theta(N).
\]
Every $Y_a=F_m(a,\bar a)$ is SAT, with $2^m$ distinct diagonals; for distinct $a,a'$ at least one crossed formula is UNSAT.

Fix one finite-state, finite-alphabet, globally sound deterministic interpreter $U$ with exactly \emph{two standard independent read/write tapes}, each one-cell-move head. Tape 1 holds the initial source and an at-most-$b=O(\log N)$-bit inline program; tape 2 starts blank. There is no third head, usable output memory, free program advice, indexed access, or initially nonblank tape 2. $D_1,D_2$ count actual symbol changes on tapes 1,2, including restoring a symbol; same-symbol writes do not count. $S_2$ counts visited auxiliary tape-2 cells \emph{including blank}; it is not total physical space, which includes the initial $N$-bit tape 1. $T$ is the actual transition count; $H_1\le T$ counts head-1 moves. Each accepted execution has one common resource ledger. The soundness quantifier is
\[
 \forall p\ \forall F\in\operatorname{UNSAT}:
 \quad U(p,F)\text{ never accepts}.
\]
On each SAT diagonal, a different short program is permitted for completeness.

\section*{Independent total-change referee}
\begin{lemma}[All-time change and auxiliary workspace, already proposed]
At a fixed source-gap cut, chronologically record an unlabelled $W_1$ token for every actual tape-1 symbol change, a $W_2(j,\sigma)$ token for every tape-2 change, and $C(\mathrm{direction},q,j)$ for each tape-1 cut crossing. The $W_2$ tokens reconstruct all tape-2 contents at each $C$. Within a segment without any tape symbol change, repeating the same crossing direction, control and tape-2 head position at one cut repeats the complete deterministic configuration and prevents halting. Therefore
\[
 \#C\le C_U(D_1+D_2+1)(S_2+2),\quad
 |E|\le C'_U(D_1+D_2+1)(S_2+2)\log_2(S_2+2).
\]
\end{lemma}
Same-program identical reconstructed crossing histories for two distinct accepted diagonals permit soundness-violating left/right splicing. Counting the at-most-$2^{b+1}$ short programs gives
\[
 (D_1+D_2+1)(S_2+2)\log(S_2+2)=\Omega(N/\log N),
 \qquad d_{\rm total}+s_2\ge1.
\]
The face is strictly excluded only for exponent sums below 1. \emph{It is false if $D_1$ is discarded.} Unlike the 2-OFF model, tape 1 in 2-RW legitimately stores state through its changed symbols.

\section*{New theorem: unrestricted tape-1 changes}
\begin{lemma}[Auxiliary-change plus sparse crossing code]
Omit every $W_1$ event, retaining only $W_2(j,\sigma)$ and $C(\mathrm{direction},q,j)$. Its replay still reconstructs the entire auxiliary tape-2 crossing state, and tape-1 changes remain local to the portion of the source occupied between cut crossings. Select for each accepted run a cut of the fixed $G$-cell gap crossed at most $\lfloor T/G\rfloor$ times, and prefix the cut index and program. If $\mathcal A_m$ is the set of diagonal SAT sources accepted by some globally sound program within simultaneous $(D_2,T,S_2)$ ceilings, then
\[
 \log_2|\mathcal A_m|
 \le b+1+\lceil\log_2G\rceil+
 C_U(D_2+\lfloor T/G\rfloor+2)\log_2(S_2+2)+O_U(1).
 \tag{1}
\]
No limit on $D_1$ is used.
\end{lemma}
\begin{proof}
Equal full $W_2+C$ chronicles reconstruct identical complete tape-2 crossing sequences, so splicing along the same cut would accept an UNSAT crossed source. Thus the triples (program, selected cut, chronicle) are injective. All visited tape-2 positions are bounded by $S_2$, and each event costs $O_U(\log(S_2+2))$ bits. A gap cut of crossing count at most $T/G$ always exists by averaging tape-1 moves across all $G$ cuts. The cut identity is explicitly charged. Nothing in this argument requires bounding tape-1 symbol changes.
\end{proof}
\begin{theorem}[Critical-logarithm auxiliary-write/time dichotomy]
For some fixed sufficiently small constants $\delta,\tau>0$, for every sufficiently large $m$, at least $1-2^{-m/2}$ of the $2^m$ diagonal SAT sources have \emph{no} globally sound short-program accepting run satisfying both
\[
 D_2\le\delta N/(\log_2N)^2,\qquad
 T\le\tau N^2/(\log_2N)^2.
\]
This holds with arbitrarily many tape-1 changes and no initial polynomial-$T$ premise.
\end{theorem}
\begin{proof}
Within the displayed $T$ ceiling, physical head motion gives $S_2\le T+O(1)\le N^2$, so $\log(S_2+2)\le3\log N$. The source encoding supplies $m\ge cN/\log N$ and $G\ge gN$ for fixed $c,g>0$. Equation (1) becomes
\[
 \log_2|\mathcal A_m|\le O(\log N)+
 3C_U(\delta+\tau/g+o(1))N/\log_2N.
\]
Choose positive $\delta,\tau$ small enough that the constant coefficient is less than $c/2$. Then $|\mathcal A_m|\le2^{m/2}$. In particular, a family-covering sound program portfolio with $D_2\le N^{1-\epsilon}$ cannot have a fixed worst-case exponent $t<2$.
\end{proof}
