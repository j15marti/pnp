\section{Exact trusted-stream first-use theorem}
An \emph{executable certified scoped producer} $G$ is one fixed total
deterministic machine. On every ordinary source input it either takes the
specified total invalid-input path or emits a closed stream of
$\mathrm{OPEN}(v)$, $\mathrm{CLAUSE}(C)$, $\mathrm{CLOSE}(v)$, EOF records.
Each used name opens once, closes once and occurs only while open.
Every CLAUSE is ordinary and syntactically valid; its overall conjunction
$H_F$ obeys $\SAT(H_F)=\SAT(F)$ on \emph{both} SAT and UNSAT inputs.
The proof of this producer's certification must be independent of
the first-use compiler. The produced stream uses at most
$M\le N^{\mu+o(1)}$ records, each of $N^{o(1)}$ bits, including
full names and event framing. All of $G$'s work, paid access to $A$,
selector switching, failed candidates, validation, source/workspace
traffic, EOF and output bits are charged as
$T_G\le N^{r+o(1)},\ S_G\le N^{\eta+o(1)}$.

Let $U_j$ be the set of names which are currently \emph{open in the
original stream} and have already occurred in a CLAUSE by position $j$.
Put $u=\max_j|U_j|$. This is the \emph{touched-live width}, not the
unrestricted syntactic width $w=\max_j|\mathrm{OPEN}_j|$.
In general $u\le w$, and the inequality can be arbitrarily large.

\begin{theorem}[First-use postponement, exact and charged]
There is one fixed, deterministic \emph{streaming} transformation $D$ of
the executable certified $G$ that emits a valid closed scoped stream
with \emph{exactly the same ordinary clauses in the same order},
opens each used name only immediately before its first CLAUSE,
and closes it at the original $\mathrm{CLOSE}$.
Its maximum live width is exactly $u$, it does not replay $G$,
and it emits at most $4M+O(1)$ self-delimited records.
If $u\le\delta\log_2N+O(1)$ for fixed $\delta\ge0$, then
a direct named-frontier DP consuming $D(G)$ is one fixed exact
ordinary-SAT machine with \emph{simultaneous} envelope
\[
\boxed{\quad
t_{\mathrm{deferred}}\le\max\{r,\mu+\delta\},\qquad
s_{\mathrm{deferred}}\le\max\{\eta,\delta\}.
\quad}\tag{1}
\]
Both bounds concern the same complete execution, not two programs.
This theorem holds only for an \emph{already certified} $G$;
it does not construct such a $G$ on all ordinary inputs.
\end{theorem}
\begin{proof}
Maintain a dictionary $D_{\rm live}$ containing only names already
mentioned in a clause and not yet closed. Ignore an original OPEN.
On an original CLAUSE, inspect its at most three source names, issue
a new OPEN for each not in $D_{\rm live}$, insert those names, then
copy the CLAUSE without semantic modification. On original CLOSE$(v)$,
emit CLOSE$(v)$ and remove $v$ exactly when $v\in D_{\rm live}$;
otherwise do nothing. Forward explicit EOF.
Certification of the original stream guarantees each first clause
occurrence is between the source OPEN and source CLOSE, and no name
occurs again after being closed. Thus the output is globally valid and
closed. At each source position $D_{\rm live}=U_j$; the emitted clause
conjunction is literally unchanged. The program needs no lookahead
and never retains the names of as-yet-unused original OPEN records.

At most three new OPEN records occur per CLAUSE; each used name
closes once. The output has $O(M)$ records of the same $N^{o(1)}$
maximum bit length. With $u=O(\log N)$, a deterministic linear
dictionary search over charged $N^{o(1)}$-bit names takes
$N^{o(1)}$ operations per event and retains
$O(uN^{o(1)}+\log M)$ writable/index bits. Original producer state
and output interception remain live and charged; there is no
write-only-output-to-input shortcut. A direct frontier DP keeps a
Boolean table of at most $2^u$ reachable assignments and a second
update table, plus at most $O(uN^{o(1)})$ name/index bits. Every
record, whether it changes the truth table or not, is processed with
$2^uN^{o(1)}$ elementary steps counting all source/workspace reads,
all writes including unchanged writes, addressing, arithmetic,
control and event copying. The exact frontier invariant is:
the row lists current assignment projections extendible to satisfy
all previous clauses. First-use expansion, clause filtering, and
original CLOSE projection preserve this invariant for SAT and UNSAT.
Because the stream ends closed, the final empty row decides the source.
One machine holds simultaneously its $G$ configuration, dictionary,
current record, two frontier tables and index buffers, so
$T\le T_G+M2^uN^{o(1)}$ and
$S\le S_G+2^uN^{o(1)}$, proving (1).
\end{proof}

\paragraph{A tighter activity profile.}
With $u_j=|U_j|$ and $\widehat u_j=\max\{u_{j-1},u_j\}$,
the direct-DP work has the more refined \emph{upper bound}
$T_G+N^{o(1)}\sum_j2^{\widehat u_j}$, provided the named-row
update is performed as above. Its peak frontier space
remains $N^{o(1)}2^{\max_j u_j}$. The activity sum offers
per-instance savings but does not justify a smaller worst-case
uniform resource exponent without an all-source bound.

\section{Precise validity limitation and two-level shared-name falsifier}
The transformation is \emph{not} a validator. Consider the invalid
source event sequence
\[
\mathrm{OPEN}(x),\mathrm{OPEN}(y),\mathrm{OPEN}(z),
\mathrm{CLOSE}(x),\mathrm{OPEN}(x),
\mathrm{CLAUSE}(x\lor y\lor z),
\mathrm{CLOSE}(x),\mathrm{CLOSE}(y),\mathrm{CLOSE}(z),\mathrm{EOF}.
\]
The first-use machine ignores the first OPEN/CLOSE$(x)$ and can
emit a \emph{valid} one-clause sequence, despite the illegal
source reopening of $x$. Thus using $D$ in place of a producer
freshness proof is unsound. Role-4
SCOPE-FRESHNESS-VALIDATION91 already established a distinct
one-pass global-name validation barrier; it is \emph{adopted}, not
claimed here as new. A certified program $G$ may be trusted because
its outputs are \emph{proved} valid, whereas an arbitrary supplied
untrusted event stream requires a separate fully charged validator.

For an exact two-label witness, take positive unit constraints on
$x_1,\ldots,x_q$ and a final positive or negative unit on $x_1$.
Implement every unit $\ell$ as the ordinary \emph{proper}
three-literal four-clause gadget
\[
\bigwedge_{a,b\in\{-1,1\}}
(\ell\lor y^{(a)}\lor z^{(b)}),
\]
where $y^{(+1)}=y$, $y^{(-1)}=\neg y$, and similarly for $z$,
with fresh private auxiliaries per unit.
The whole root is SAT when the final literal is $x_1$ and
UNSAT when it is $\neg x_1$.
The valid emitter opens all $q$ original names first, opens two
private auxiliaries for each gadget, emits four clauses, closes
the auxiliaries, closes $x_i$ after its last use, and retains
$x_1$ until the final gadget. The raw live width is exactly $q+2$;
the first-use stream width is exactly $4$ for $q\ge 2$.
The producer can generate this restricted stream by counters
using logarithmic space.

Partition the gadget sequence at three positions into four
consecutive groups $L_1,\ldots,L_4$. Every other source variable
and every gadget auxiliary is private to one group; only $x_1$
can occur in two far-separated groups. The \emph{exact} named
interface condition is
\[
 \SAT(F)\iff
 \bigvee_{b\in\{0,1\}}\ \bigwedge_{j=1}^4
 \SAT\bigl(L_j\land[x_1=b]\bigr).
 \tag{2}
\]
The pinned formulas are fully serialized \emph{ordinary proper
3CNF} inputs with new private unit-gadget auxiliaries. Grouping
the first two and last two leaves produces first-level
ordinary child formulas; splitting each gives a second real
ordinary level, with identical pin $b$ and independently
checked both-label joins at each level.
If the last literal is $\neg x_1$, each unpinned leaf is
individually SAT, yet the source is UNSAT:
\[
 \bigwedge_j\SAT(L_j)=\mathrm{TRUE},\qquad \SAT(F)=\mathrm{FALSE}.
\]
The harmless typesetting in this displayed line is understood
as $\SAT$ for every leaf; it is the compatibility error that matters.
Closing $x_1$ at the first block boundary rather than the
original CLOSE loses the shared-name constraint.
