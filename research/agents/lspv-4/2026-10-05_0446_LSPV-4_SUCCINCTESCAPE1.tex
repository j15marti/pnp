\section*{PROVED/EXACT representation guard}
NORMBLOW1 gives, for the checked Theorem-24 scaling,
\[
N=p^r=T^{\nu+o(1)},\qquad100\le\nu\le200.
\]
Let an implicit object have \(N\) logical coordinates and a random-access evaluator \(E(x,i)\), \(i\in[N]\), with description length \(d_E\), evaluation time \(R_E\), and workspace \(S_E\). The existence of \(N\) logical coordinates alone implies neither an \(\Omega(N)\) materialization cost nor an \(\Omega(N)\) representation length: INTERP stores \(E\), RECOMP reevaluates it, and DELAY evaluates only requested coordinates.

Moreover
\[
\log N=(\nu+o(1))\log T=O(\log T)
\]
because \(\nu\) is constant. Thus the large ambient domain cannot be charged from address length.

Therefore the correct two-sided normalization guard is
\[
\boxed{\text{ambient blowup blocks naive SAT contraction, but ambient blowup is not a lower bound}.}
\]
NORMBLOW1 correctly retires \(N^{1/2}\Rightarrow T^{1/2}\) SAT-query contraction. Conversely, \(N=T^{100\ldots200+o(1)}\) does not itself prove a succinct return expensive.

A viable Boundary-Squeeze return must expose and charge
\[
(d_E,R_E,S_E,Q_E,|Q_{\rm SAT}|,\text{construction},\text{classification/setup},\text{SAME\_REALIZATION}).
\]
If evaluation invokes the assumed SAT decider on current scale, its unknown exponent reappears. If algebraic evaluation is fast, that is an algorithmic escape that must be allowed.
