\section*{Target implication}
The causal branch requires a theorem stronger than ordinary static correctness:
\[
\operatorname{CorrectStaticSAT}(A)\Longrightarrow
\operatorname{GlobalContinuationRobust}({\cal C}_A).
\]
Canonical CCSPC instead specifies one realized trajectory
\[
p_i\to\Phi_i\to T_i\to B_i\to q_i\to Y_i\to p_{i+1},
\]
and explicitly separates this from the strengthened all-future-challenge game.

\section*{PROVED/EXACT semantic countermodel}
\paragraph{ROBUSTGAP1.}
Static SAT correctness alone does not logically imply global continuation robustness for canonical CCSPC.

\paragraph{Proof.}
Fix any exact deterministic SAT decider \(A\). Define a realization \({\cal C}_A\) that, on the actual CCSPC trajectory, invokes \(A\) on the currently realized formula, computes only the currently required deterministic transition/audit information, and continues after the realized fresh block is revealed. This realization is correct on every static SAT query presented to \(A\), and it can be correct on the realized CCSPC path whenever the local transition primitives are correctly implemented.

Global continuation robustness, however, requires a different predicate: before or at a current history it must support the strengthened obligation over every legal future challenge continuation, equivalently a recursive condition of the form
\[
W_i=V_i\wedge
\forall B_{i+1}\exists w_{i+1}\,W_{i+1}.
\]
Nothing in the definition of exact static SAT correctness requires \(A\), or the local realized-path realization just defined, to compute or represent this all-continuations object. Hence there is a model satisfying the antecedent while the strengthened consequent is not imposed. Therefore the implication is not a logical consequence of static SAT correctness or canonical CCSPC semantics. Any valid implication needs an additional compiler/robustness theorem. \(\square\)

\section*{Why this is not merely a wording issue}
LOCALSEM1 identified the semantic separation and conservatively labeled it CANDIDATE pending red-team review. ROBUSTGAP1 independently validates the separation as an exact non-implication. It does not prove that no compiler can force global continuation. It proves that such forcing is an additional load-bearing theorem, not inherited from SAT correctness.

\section*{Hostile wrapper audit}
\textbf{RECOMP:} the realization may compute only the response needed after the actual challenge is known. No all-futures strategy need be stored.

\textbf{INTERP:} a universal interpreter can implement the same extensional SAT decider while changing native trace/provenance structure.

\textbf{DEAD/COPY/DELAY:} these alter trace geometry without adding a global continuation obligation.

\textbf{Preprocessing/compact strategies:} if a proposed compiler does produce a global strategy, its representation and construction cost must be charged; explicit strategy-tree size is not automatically necessary because compact circuits may represent strategies.

Thus SAME\_REALIZATION does not repair the missing implication by itself.
