\section{2-SAT baseline and stage ladder}
For $q\ge1$, with variables $z_0,\ldots,z_q,u,v$, define
\[
F_b=(z_0\vee u)(z_0\vee\neg u)(\neg z_q\vee v)(\neg z_q\vee\neg v)\bigwedge_{i=1}^q(\neg z_{i-1}\vee \ell_i),
\quad\ell_i=\begin{cases}z_i&b_i=1\\\neg z_i&b_i=0.\end{cases}
\]
The first four clauses force $z_0=1,z_q=0$. All-one $b$ makes this UNSAT by implication propagation. For the first zero at $j$, choose $z_i=1$ for $i<j$, $z_i=0$ for $i\ge j$; this satisfies the formula and leaves $u,v$ free. Consequently $F_b\in\mathrm{UNSAT}$ iff $b=1^q$; $n=q+3,m=q+4,k=0,N=(4q+18)w$. An exact deterministic orientation-query algorithm reads all $q$ fields on $1^q$, by an unread-one-bit flip adversary, and a scan/SCC decision matches in $O(q)$ word time. This is $\Omega(N/\log N)$ input queries, not an unrestricted lower bound.
Paired padding $C=(a\vee b)\mapsto (a\vee b\vee y_C)(a\vee b\vee\neg y_C)$ gives proper 3-CNF with $n'=2q+7$, $m'=k'=2q+8$, $N'=(8q+34)w'$, a fresh free $y_C$ per old clause, and $2^{q+4}$ witness extensions for each original satisfying assignment. This is an equisatisfiable syntactic conversion, not amplification.
For arbitrary 2-CNF $B$ with $M$ clauses plus $k$ genuine ternaries, choose one original variable from each ternary; the set $S$ has $|S|\le k$. Every assignment to $S$ leaves 2-CNF, yielding $2^{|S|}\operatorname{poly}(N)$ upper time, polynomial if $k=O(\log N)$. At unrestricted $k$, graph 3-coloring maps to this class using one 3-choice positive clause and three at-most-one binaries per graph vertex, plus three negative binaries per graph edge: $n=3V$, $k=V$, $M=3V+3E$, and model-preserving witnesses. The endpoint is KNOWN NP-complete, not a lower bound.

\section{Connected cubic prism construction}
For $t\ge3$, let $G_t$ be the $t$-gonal prism: two length-$t$ cycles joined by $t$ vertical edges. It is simple, connected, cubic, has $|V|=2t,|E|=3t$, has a perfect matching of vertical edges, and remains connected after deletion of any one vertex. Put a Boolean source variable $x_e$ on each edge. Choose $b\in\{0,1\}^{2t}$ and impose for every vertex $v$
\[
\bigoplus_{e\ni v} x_e=b_v.
\]
Each degree-three parity equation becomes four genuine width-three clauses excluding the four wrong-parity assignments. For a canonical triple $(x,y,z)$ and orientation bit $b_v$, index the four excluded tuples by $(a,c)\in\{0,1\}^2$ and take third forbidden bit $d=1\oplus b_v\oplus a\oplus c$. A clause blocking assignment $(a,c,d)$ has positive literal for forbidden value zero and negative for forbidden value one. Denote the resulting CNF $P_{t,b}$. It has
\[
n=3t,\quad m=k=8t,\quad N=(32t+2)\lceil\log_2(64(11t+1))\rceil,
\]
no extra variables, no units, no pure literals, four positive and four negative appearances per edge variable, and a single connected clause-variable incidence component.

\begin{theorem}[Exact both-label semantics and certificate; PROVED/EXACT]
\[
\#\mathrm{SAT}(P_{t,b})=
\begin{cases}2^{t+1},&\bigoplus_v b_v=0,\\0,&\bigoplus_v b_v=1.\end{cases}
\]
A uniform source-aware algorithm recognizes the parity grammar and decides both labels in $O(t)$ word time with $O(t)$ peak words. A satisfying assignment or an algebraic UNSAT certificate can be reconstructed and verified in $O(t)$ word time.
\end{theorem}
\begin{proof}
The binary edge-vertex incidence matrix of any connected graph has rank $|V|-1=2t-1$. Every column occurs twice, so the only dependence among rows is their total XOR, which demands $\bigoplus b_v=0$. In the consistent case the affine dimension is $|E|-|V|+1=t+1$; set non-tree edges to zero and solve the tree edges from leaves. In the inconsistent case XOR all vertex equations to obtain $0=1$. Recognition is paid: group clause triple supports with deterministic three-pass integer sorting, check all four exclusion masks have the required parity, every edge variable occurs in two distinct groups and the inferred group graph is connected. Invalid sources fall back to a general correct decider.
\end{proof}

\begin{theorem}[All-clause-critical and linear minimum backdoor; PROVED/EXACT]
If $\bigoplus_vb_v=1$, then deleting any one of the $8t$ clauses makes the CNF SAT with exactly $2^{t-1}$ source assignments. Both SAT and UNSAT members have minimum strong syntactic 2-CNF backdoor size
\[
h(P_{t,b})=t=n/3=k/8.
\]
\end{theorem}
\begin{proof}
If a clause at vertex $v$ is deleted, set the three incident edge variables to its uniquely excluded assignment, whose parity is $1\oplus b_v$. Delete $v$ from the graph. The remaining graph is connected and the boundary assignment matches $\bigoplus_{u\ne v}b_u=1\oplus b_v$, so the remaining equations have solutions. Among $|E|-3$ free internal edges, incidence rank is $|V|-2$, giving $2^{(|E|-3)-(|V|-2)}=2^{t-1}$ solutions. The omitted clause alone is falsified at $v$.
A variable set is a strong syntactic 2-CNF backdoor exactly when it intersects every original 3-clause support. The supports are the edge triples incident to prism vertices, hence a backdoor is an edge cover of the prism. Each edge covers at most two of the $2t$ graph vertices, so at least $t$ variables are needed; the $t$ vertical edges give a cover of size $t$.
\end{proof}

\begin{theorem}[Both-label all-decider source-word bound; PROVED/EXACT, fixed-record model]
On every $P_{t,b}$, every total deterministic exact decider for unrestricted properly encoded 3-CNF SAT must read at least $2t=\Omega(N/\log N)$ addressed input words. An $O(t)$ source scan matches this bound.
\end{theorem}
\begin{proof}
Flip a single independent orientation $b_v$. Only the third literal-sign word in each of the four clauses belonging to $v$ changes, with no header/length changes; the global parity, hence the SAT label, reverses. These four-cell sets are disjoint across all $2t$ vertex groups. Any deterministic exact decider omitting an entire one of these sets on the original input would have an identical read transcript and wrong answer after the corresponding flip. Thus it must read at least one cell from each of $2t$ groups. This is source acquisition, not an exponential post-acquisition bound.
\end{proof}

\section{Affine core plus $p$ non-affine ternaries}
\begin{lemma}[Exact choice upper bound; PROVED/EXACT]
If $A$ is any explicit affine GF(2) equation system and $D_1,\ldots,D_p$ are clauses of width at most three, exact SAT of $A\wedge\bigwedge_jD_j$ is decidable in $O(3^p\operatorname{poly}(N))$ time and polynomial peak space including every failed Gaussian-elimination trial and witness replay.
\end{lemma}
\begin{proof}
Choose one true literal from each added clause, at most $3^p$ choice vectors, and enforce every chosen literal as an affine unit equation. Gaussian elimination checks each set of forced values and reconstructs a model when consistent. A satisfying assignment chooses at least one literal in each clause, so completeness holds. Verification against the original input provides soundness. For $p=O(\log N)$ this is polynomial; unrestricted $p$ with an empty affine core contains ordinary 3-SAT. No matching lower bound is inferred.
\end{proof}
