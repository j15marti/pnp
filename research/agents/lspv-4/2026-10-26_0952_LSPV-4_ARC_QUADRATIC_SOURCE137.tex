\section{Exact grammar and source authentication}
Let F be a canonical ASCII proper signed ternary CNF of physical input length N bits; all source clauses use three distinct variable names. A leaf partial assignment alpha fixes original variables. Each certificate record includes a physical first-byte source offset and names either: (i) one actual source clause whose restriction has at most two remaining literals, or (ii) four distinct source clause offsets using the same triple of variables and forbidding exactly the four assignments with parity opposite a declared bit b. In case (i) the authenticated generator is the false indicator
\[
g_C(x)=\prod_{\ell\in C|_\alpha}(1-\ell(x))=0.
\]
In case (ii), direct checking of the four signs authenticates
\[
g_X(x)=x_i+x_j+x_k+b=0\quad\text{in }\F.
\]
All reductions are in the multilinear Boolean ring R=F_2[x]/(x_i^2-x_i). A record can use multiplier 1; a generator of syntactic degree at most one may also use one named unassigned variable as multiplier. No other multiplication is allowed. The verifier re-reads original source bytes and checks that all signed source literals, original names, distinct offsets, branch restrictions and multiplier rules are legal, expands the constant number of terms, and tests the exact coefficient identity
\[
\boxed{\sum_j m_j g_j=1\quad\text{in }R,\qquad\deg_{\rm syntactic}(m_jg_j)\le2.}
\]
This is a \emph{restricted static degree-two Nullstellensatz grammar}, not full degree-two polynomial calculus, and it does not assume a degree bound on an unauthenticated general circuit.

\begin{theorem}[Soundness, PROVED/EXACT for declared grammar]
For any accepted leaf proof pi and partial assignment alpha, F|alpha is unsatisfiable. If a genuine complete binary branching tree on two distinct original variables has four accepted leaves, F is unsatisfiable, even if unrelated source ternaries survive each restriction.
\end{theorem}
\begin{proof}
Every assignment satisfying F also satisfies every genuine clause and thus zeros its false indicator. The four source clauses comprising a parity macro exclude each assignment violating the declared linear parity equation; any source-satisfying assignment zeros it as well. Multiplying by an allowed monomial preserves zero. Consequently an extension satisfying F and alpha cannot satisfy the identity 1=0. Every full assignment follows one of the four exhaustive leaves, proving the claim. Authentication uses real immutable source offsets and does not ask the parent SAT decision.
\end{proof}

\section{A connected example with necessary second level}
Choose six variables a,b,c,u,v,w. The twelve proper source clauses are:
\begin{enumerate}
\item The four clauses expressing a+b+c=0 mod 2 on (a,b,c), each forbidding one odd-parity assignment.
\item (a or b or u), (not a or not b or u), (a or b or not u), (not a or not b or not u).
\item (not c or v or w), (not c or v or not w), (not c or not v or w), (not c or not v or not w).
\end{enumerate}
The incidence graph is connected. Branch on u at the first level and v at the second. For either bit value of u the first two active residual source clauses give
\[
g_1=(1+a)(1+b)=1+a+b+ab,\qquad g_2=ab.
\]
For either bit value of v two active residual source clauses give
\[
g_3=c(1+w)=c+cw,\qquad g_4=cw.
\]
The original fully authenticated XOR quartet gives g_5=a+b+c. Hence, identically in R,
\[
\boxed{g_1+g_2+g_3+g_4+g_5=1.}
\]
All five multipliers are 1, all five source records are physically authenticated. The first four polynomials alone have a common zero (a,b,c)=(0,1,0); the affine macro alone has a common zero. This is genuinely mixed.

At the root, all non-XOR clauses still have three unassigned variables, and the XOR generator is satisfiable. After branching u but not v, accessible generators have the common zero (a,b,c)=(0,1,1). After branching v but not u, they have the common zero (a,b,c)=(0,0,0). Thus no certificate in the specified algebraic span exists at the root or either selected first-level branch. After both branches each of the four leaves has the five-record identity. This is a proof of a \emph{restricted} depth-two advantage, not a hardness claim about arbitrary SAT algorithms.

Serialized root size is exactly 1016 physical ASCII bits. With the actual ordinary-CNF restriction and regenerated headers, each first-level child is 824 bits and each second-level grandchild is 616 bits. Every UNSAT branch is checked exhaustively. Removing source clause (a or not b or c) makes a SAT control, and all four second-level descendants become SAT; the quartet parity authentication no longer applies. The JSON four-leaf certificate has 7752 bits and is therefore \emph{larger than the root}. No ARC length/time contraction follows.

\section{Fully charged verification versus FLMV}
Each proof record has O(log(N+P)) address bits and a constant number of polynomial monomials. A conservative exact deterministic multitape verification of a guessed P-bit proof stores its physically generated coefficient events, sorts them by monomial index, cancels in sorted order and authenticates all original source references. This gives, including input pre-validation, sorting, index operations, malformed/timeout branches,
\[
T_V=O(N\,\mathrm{polylog}N+P\,\mathrm{polylog}(N+P)),\qquad
S_V=O(P\,\mathrm{polylog}(N+P)).
\]
Here the proof tape's materialized contents are charged; the verifier is \emph{not} asserted to run in sublinear deterministic space. A dense direct coefficient accumulator would hold
\[
D(n)=1+n+\binom n2
\]
bits, and one cannot silently treat random work-tape coefficient updates as unit-cost on FLMV's indexed-read-only-input Turing machine. A purported low-space repeated replay must explicitly store the guessed proof or establish a lawful replay interface. The experimental Python search is not the machine-realization proof.

Only under an additional \emph{unproved} uniform all-UNSAT bound P(N)<=N^{a+o(1)} and a branchwise clock would this support a co-nondeterministic SAT companion with c<=max(1,a). Van Melkebeek Theorem 1.3 also requires a separate deterministic small-space SAT algorithm; the extra illustrative seed d=901/500 does not follow from P=NP. There is no established ARC successor from an arbitrary finite polynomial K. All one-machine FLMV time and peak-space thresholds remain OPEN.
