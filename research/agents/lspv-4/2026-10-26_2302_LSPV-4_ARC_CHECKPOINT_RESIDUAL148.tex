\section{Cold-to-warm residual source-access theorem}
Let $f:D\to\{0,1\}$, with $x^0\in D$ and
$f(x^E)\ne f(x^0)$ for all $E\in\mathcal E$, where
$x^E=x^0\oplus\mathbf1_E\in D$. Partition physical source bits into
charged cells $\mathcal P$, and put
$B(E)=\{P\in\mathcal P:P\cap E\ne\varnothing\}$.
Fix one fully clocked randomized algorithm $A$ whose only source-dependent
observations are counted cell reads; in particular, inline every adaptive
guest, source parser, child header/endmarker generation and source
authentication rather than granting semantic oracle answers.
On each baseline run with coins $\omega$, partition all \emph{first}
original source-cell reads into disjoint checkpoint sets
$A_0(\omega),\ldots,A_\ell(\omega)$.
All rule switches, failed probes, caches, shared work and output are still
part of the actual machine's resources.

Let $\epsilon_0$ and $\epsilon_E$ bound respective baseline and
mutant error probabilities, and define
\[
\delta_E=\max\{0,1-\epsilon_0-\epsilon_E\},\qquad
p_{j,E}=\Pr_\omega[B(E)\cap\textstyle\bigcup_{i<j}A_i(\omega)
\ne\varnothing],\qquad
z_{i,P}=\Pr_\omega[P\in A_i(\omega)].
\]
Here $p_{j,E}$ is a probability of \emph{at least one earlier hit}, not
a sum of probabilities of past accesses.

\begin{theorem}[Residual checkpoint LP]\label{th:res}
For every $j=0,\ldots,\ell$ and $E\in\mathcal E$,
\[
\boxed{\sum_{i=j}^{\ell}\sum_{P\in B(E)} z_{i,P}
\ \ge\ (\delta_E-p_{j,E})_+.}\tag{1}
\]
Consequently the expected number of \emph{new} original source cells
read from checkpoint $j$ through termination is at least
\[
\boxed{\min_{z_P\ge0}\ \sum_{P\in\mathcal P}z_P
\quad\text{subject to}\quad
\sum_{P\in B(E)}z_P\ge(\delta_E-p_{j,E})_+
\quad(\forall E\in\mathcal E).}\tag{2}
\]
Nonnegative fixed cell weights may replace the unit weights in the
objective. Actual head movements, indexed-address operations and peak
working memory are separate machine-native costs.
\end{theorem}
\begin{proof}
Couple the baseline and $E$-mutant executions using the same random tape.
Until a source cell in $B(E)$ is read, the source answers agree. By
induction on executed instructions, their complete source-dependent
transcripts, branches and outputs coincide on an all-unhit run.
Since the true labels differ, at least one coupled execution is wrong
on that event. A union bound on errors thus implies that some source
cell in $B(E)$ is read with probability at least $\delta_E$.
The event of any hit is contained in the union of an earlier hit
(probability $p_{j,E}$) and a first hit at some stage $i\ge j$.
A union bound over the latter first touches gives (1).
Put $z_P=\sum_{i\ge j}z_{i,P}$; these probabilities sum without
double-counting because the $A_i(\omega)$ are disjoint for each
fixed run. This feasible LP vector has objective equal to the
expected number of new later source cells. Weighted objectives
follow by the same reasoning.
\end{proof}

\begin{corollary}[Deterministic exact checkpoint]\label{co:det}
For a deterministic exact machine, if $H$ is the set of original cells
inspected before checkpoint $j$ on baseline $x^0$, its future first-read
set must hit every edge $B(E)$ disjoint from $H$. It therefore has
cardinality at least the \emph{integral} transversal number of the
residual unhit-edge hypergraph. For $r$ disjoint edges, if $b$ have
already been hit then at least $r-b$ remain compulsory on the
\emph{same} deterministic baseline execution.
\end{corollary}
\begin{proof}
For any $E$ disjoint from $H$, an additionally unhit edge through
termination would leave baseline and mutant complete computations
identical, in contradiction with total exact correctness.
\end{proof}

\section{Exact three-phase model and conditional-error counterexample}
For $M$ divisible by four, let $f(x)=\operatorname{OR}_M(x)$ on
$\{0,1\}^M$ and baseline $0^M$. Draw one two-bit uniform seed
$r\in\{0,1,2,3\}$ and in each phase $j=0,1,2$ scan only positions
$i$ satisfying $(i+r)\bmod4=j$. A found one yields output one;
if none is found, output zero. The three read sets are disjoint.
For each coordinate the probabilities of first reading it at phases
zero, one and two are each $1/4$, and of never reading it are $1/4$.
Thus baseline error is zero and every nonzero input has error at
most $1/4$. Singleton mutants have exact $\delta=3/4$,
$p_{1,E}=1/4$, $p_{2,E}=1/2$.
Equation (2) is attained with equality at both checkpoints:
\[
\mathbb E|A_0|=M/4,\quad
\mathbb E|A_1\cup A_2|=M/2,\quad
\mathbb E|A_2|=M/4,\quad
\mathbb E|\cup_{i=0}^{2}A_i|=3M/4.
\]
For every nonempty mutation edge, the earlier-hit probability is at
least its singleton counterpart; the singleton LP constraints already
force all these exact values. Recharging $3M/4$ at all three visits
would demand $9M/4$ distinct source cells, despite only $M$ input cells.

\begin{counterexample}[Invalid conditional error transfer]
\label{ce:conditional}
Condition on the complete checkpoint state after phase zero with
seed $r=3$ and baseline $x=0^M$. Coordinate $i=0$ has not been read
and will never be read in either continuation phase. The singleton
mutant $e_0$ consequently has \emph{conditional} error probability one
on that state, although unconditional error is $1/4$.
A global Monte Carlo error guarantee therefore cannot be inserted
unchanged into a per-state conditional residual LP. Theorem~\ref{th:res}
uses \emph{unconditional} baseline coins and is unaffected.
\end{counterexample}

\paragraph{Full-cache negative control.}
An exact source-OR streaming preprocessor may read every source cell,
store one result bit, and answer arbitrarily many later label requests
without another input read. In this case $p_{j,E}=1$ for every
later checkpoint and nonempty $E$, so (1)--(2) correctly yield
zero residual source-cell cost. Memory after the pass may be
$O(\log M)$, including the input index. No positive reusable
source potential follows from a one-time transversal.

\paragraph{M1: deterministic one-tape shared input/work model.}
Physical footprint $P_1$ includes the initial $N$-bit input,
with $P_1\ge N$. Actual one-head transitions and crossing
sequences must be charged independently of source-cell count.
Our stochastic OR control is not a deterministic M1 SAT solver.

\paragraph{$M_k$: deterministic fixed-$k$ sequential-input model.}
The read-only input head incurs physical moves and reversals,
and all visited writable work cells count as $S_k$.
The analogous sequential sampler can use $O(\log M)$ bits and
$O(M\operatorname{polylog}M)$ time, including scanning and
counter updates. The conservative M1 simulator has
$T_1=O(T_k(N+S_k+\log(T_k+2)))$ and
$P_1=O(N+S_k+\log(T_k+2))$, giving only
$t_1\le t_k+\max(1,s_k)$ and
$p_1\le\max(1,s_k)$ for polynomial ceilings.
No reverse necessary inequality or one-tape crossing lower bound
may be assigned to a random-access machine.

\paragraph{RAT: FLMV indexed read-only-input model.}
Each addressed source-bit read pays index generation and full
bit-time, and work/index tapes contribute to peak space.
The OR control takes $3M/4$ distinct source probes for every coin
value and has an $O(M\operatorname{polylog}M)$ indexed
implementation, with $O(\log M)$ register/index bits. The
FLMV deterministic and co-nondeterministic small-space lower
bounds have different quantified hypotheses; neither licenses
randomized adaptive oracle calls as a free deterministic successor
\cite{flmv}. A hypothetical $P=NP$ gives only some unknown polynomial
time exponent $K$, not $d=1.802$ with $s=o(1)$.
