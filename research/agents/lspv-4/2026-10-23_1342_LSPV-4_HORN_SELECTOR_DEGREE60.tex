\section{Source-coherent Horn selector lift}
For proper exactly-three-clause CNF $\Phi=\bigwedge_{j=1}^{m}(\ell_{j1}\vee\ell_{j2}\vee\ell_{j3})$ over $n_0$ source variables, with distinct identifiers per clause, introduce three fresh selectors per clause and set
\[
H(\Phi)=\bigwedge_{j=1}^{m}\left[
(s_{j1}\vee s_{j2}\vee s_{j3})\wedge
\bigwedge_{a=1}^{3}(\neg s_{ja}\vee\ell_{ja})\right].
\]
Every binary clause is Horn, every ternary is genuine, positive, and selector-disjoint. Each selector occurs once positively and once negatively. Each original source variable occurs only in binary consequents and keeps its original positive and negative occurrence counts. Either factor considered alone is always satisfiable.
\begin{theorem}[Exact correspondence]
$\Phi$ is SAT iff $H(\Phi)$ is SAT. Fix an original-variable assignment $\alpha$ and let $t_j$ be the number of true source literals in clause $j$. The number of selector extensions is exactly $\prod_{j=1}^{m}(2^{t_j}-1)$. Counts are $n=n_0+3m$, $M_2=3m$, $k=m$, $M=4m$ and
\[
N=(16m+2)\lceil\log_2(64(n_0+7m+1))\rceil.
\]
Source parsing, construction, grammar recognition, inverse source decoding, witness reconstruction and replay have $O(n_0+m)$ word time and peak live words. Output writes cost $16m+2$ words.
\end{theorem}
\begin{proof}
At least one selector is true in each group, and each true selector forces its source literal true. Conversely, a satisfied source clause admits every nonempty subset of its true literals as active selectors. Multiply the independent group counts. A canonical parser verifies record order, identifiers, arities, exact implication pairing and source variable distinctness, rejecting malformed inputs rather than assuming a hidden promise.
\end{proof}
\begin{theorem}[Exact strong backdoors]
Under raw restriction and all assignments to the chosen backdoor, the minimum strong syntactic 2-CNF backdoor is $m$, and the minimum strong syntactic Horn backdoor is $2m$.
\end{theorem}
\begin{proof}
The positive ternary supports are disjoint. One selected variable per triple is necessary and sufficient to reduce width to at most two. If fewer than two from a triple are chosen for Horn, set selected variables false and a positive clause of width at least two survives, which is not Horn. Two per triple suffice; all original binary implications remain Horn.
\end{proof}
\section{Sharp degree three versus four boundary}
Let $\Delta(\Phi)$ count the maximum original-variable occurrences in proper source clauses, with both polarities counted.
\begin{theorem}[Degree at most three, PROVED/EXACT]
If $\Delta(\Phi)\le3$ and every clause contains exactly three distinct source variables, then $\Phi$ and $H(\Phi)$ are SAT. A witness is constructible with $O(n_0+m\sqrt m)$ charged word operations and $O(n_0+m)$ live words.
\end{theorem}
\begin{proof}
Build clause-variable incidence graph. Any set $Q$ of clauses has $3|Q|$ incident edges, and each neighboring source variable is incident to at most three, giving $|N(Q)|\ge |Q|$. Hall's theorem yields a matching saturating every clause. Assign each matched variable to satisfy the signed literal in its uniquely matched clause, with unmatched variables arbitrary. No source variable is assigned inconsistently. Hopcroft--Karp and original-source replay achieve the stated resource bounds.
\end{proof}
\begin{theorem}[Degree four, KNOWN THEOREM and charged lift]
The canonically recognized Horn-selector language with $\Delta(\Phi)\le4$ is NP-complete. NP-completeness remains when each original variable has exactly two positive and two negative source occurrences, so every output variable occurs in both polarities with maximum target occurrence degree four.
\end{theorem}
\begin{proof}
Tovey (1984) proves the exact proper-3SAT max-four occurrence endpoint; D\"ocker (2019) proves the stronger signed exact-(2,2) monotone subclass. The above reduction preserves signed original occurrences and places each selector in exactly one positive ternary and one negative binary. It has linear construction cost and exact witness transport. Canonical grammar and source-degree validation are deterministic polynomial, so the language is in NP with invalid strings rejected.
\end{proof}
As a connected hostile control, for $t\ge5$ take $C_i=(x_i\vee\neg x_{i+1}\vee x_{i+2})$ indexed modulo $t$. All original variables appear exactly three times and in both signs. The Horn lifts have $n=4t$, $M_2=3t$, $k=t$, $M=4t$, no units/pure literals, and minimum backdoors $t$ and $2t$. Yet the all-true $x$ assignment with one true selector per group is a linear-time witness. Therefore linear backdoor size does not imply exponential solver work.
