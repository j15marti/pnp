\noindent\fbox{\parbox{.965\linewidth}{\textbf{PROVED/EXACT, restricted model; independent formal referee pending.} For a uniform family of future parity SAT contexts, the minimum number of source-dependent retained bits for an arbitrary deterministic preprocessor and a fixed one-way source-head budget $H$ is exactly the minimum projected GF(2) rank outside a length-$H$ physical window. The lower bound permits \emph{nonlinear} summaries and adaptive continuation. The matching construction uses a linear summary and charged Gaussian elimination. Finite code controls are \textbf{COMPUTATIONAL}. There is no unrestricted SAT-time lower bound, and $P$ versus $NP$ remains \textbf{OPEN}.}}

\begin{abstract}
A full answer-vector rank, an information-value score, and physical source access are different resources. We prove an exact rank-of-outside-window law for a source-present, online parity-context service with a single initially fixed, read-only source head that is permitted to move only right. This converts a source-dependent summary lower bound into a physical head-movement frontier without pretending that the source disappears or that local arithmetic is free. It also gives a sharp counterexample to any proposed resource accounting based on output rank alone: one sparse and one dense parity have equal rank one and equal final value, yet with no stored bits their minimum continuation movements are respectively zero and $g(t-1)$. Source rewriting and indexed random access defeat the physical-window premise and are charged as separate controls.
\end{abstract}

\section{PROPOSE: one missing lemma and four falsifiable mechanisms}
The missing bridge is a necessary-and-sufficient \emph{single-query} construction/storage/continuation law for a uniform decoder that prepares before the future context is selected, with access to the original source retained. In the exact one-way-head model, four possibilities are tested. \textbf{M1:} arbitrary nonlinear preparation could outperform the projected affine rank; \textbf{M2:} projected rank outside the reachable window is a tight complete storage invariant; \textbf{M3:} rank of the target answer space alone could determine physical continuation cost; \textbf{M4:} writable re-encoding or RAM indexing could avoid a sequential-head bound. M1 is falsified, M2 proved within the model, M3 falsified, M4 verified as a model escape. None is a claimed general SAT bound.

\section{Exact information and physical model}
Fix $t\ge1$ source bits $a=(a_0,\dots,a_{t-1})\in\F^t$ at publicly known read-only physical tape coordinates $p_i=p_0+ig$ for integer $g\ge1$. All remaining source symbols are fixed and public; a fixed-width SAT serialization has $g=\Theta(\log(t+2))$ and physical $N=\Theta(t\log(t+2))$ for a uniformly described query family. Let $W\subseteq\F^t$ be a finite nonempty \emph{public} collection of parity masks with a polynomial-time uniform description (or an explicitly charged public matrix input). For a later index $w\in W$, the exact answer is $w\cdot a\in\F$.

This has a literal SAT composition embedding: $A_a(X)=\bigwedge_i(x_i=a_i)$ fixes the shared variables, while $B_{w,\tau}(X,Z)$ is a standard chained XOR3 CNF imposing $w\cdot X=\tau$, so
\[\operatorname{SAT}(A_a\land B_{w,\tau})\iff w\cdot a=\tau.\]
Auxiliary XOR gates use four width-three clauses each. The class is \emph{not} asserted to be strict exact-$(2,2)$, and the original $A_a$ remains readable after preprocessing.

The preprocessor knows $W$, $t$, $g$, and the physical encoding, but not the future $w$. It may read all of $A_a$, preprocess for arbitrary time, and leave a \emph{complete $L$-bit source-dependent retained summary} $\sigma(a)$. The source read-only head must finish at a fixed \emph{source-independent} coordinate $p$. All other retained \emph{source-dependent} writable bits, cached answers, machine state and other head-position channels count in $L$. Public fixed program control and any input encoding of $W$ are reported separately in complete physical footprint. The continuation sees one $w$, may use polynomial work space and arbitrary adaptive local computations, and may move the source head only \emph{right} by at most $H$ physical cells before responding; it may never modify or otherwise access the source. Only one later query is executed, so reset/replay is not free or needed. The theorem optimizes $L$ with $H$ while accounting for $P$, actual bit operations and peak space in the upper bound.

For a consecutive field interval $J=[u,u+r-1]\subseteq[t]$, let $W_{\bar J}$ denote the family of row vectors obtained by restricting every $w\in W$ to coordinates outside $J$. Put
\[\rho_W(J)=\operatorname{rank}_{\F}\langle W_{\bar J}\rangle,\qquad r(H)=\min\{t,1+\lfloor H/g\rfloor\}.\]

\begin{theorem}[Exact one-way reachable-window rank]\label{th:window}
In the declared model, for every fixed nonnegative movement budget $H$, the minimum number of source-dependent retained bits among \emph{all deterministic preprocessors and decoders}, including nonlinear summaries and adaptive reading strategies, is exactly
\[
\boxed{L^*_W(H)=\min_{0\le u\le t-r(H)}\rho_W(\{u,u+1,\ldots,u+r(H)-1\}).}\]
The first phase may take arbitrary time; an explicit uniform polynomial-time linear preprocessor and decoder attain the bound for public polynomially represented $W$.
\end{theorem}
\begin{proof}
Fix a source-independent prepared head position $p$ and a maximum rightward travel $H$. The source bits that \emph{any} continuation can read lie in the fixed physical interval $[p,p+H]$; let $J$ be its consecutive sign positions. This contains at most $r(H)$ consecutive indices. Fix all source bits $a_J$. If $\sigma(a)=\sigma(a')$ for two inputs agreeing on $J$, then for every future mask $w$ the deterministic decoder reads identical accessible source contents and must give the same answer. Hence $Wa=Wa'$ for the entire public query family. As the unrestricted outside vector $a_{\bar J}$ ranges over $\F^{|\bar J|}$, the output vector ranges over a space of size exactly $2^{\rho_W(J)}$. A fixed-length $L$-bit summary must therefore satisfy $2^L\ge2^{\rho_W(J)}$. Enlarging a short interval to $r(H)$ fields can only weakly reduce projected rank, proving the displayed lower bound. This argument makes no linearity assumption about $\sigma$ or the decoder.

For the reverse bound choose a minimizing interval $J$ of length $r(H)$ and position the prepared source head at its first field. Let $\beta_1,\ldots,\beta_L$ be a GF(2) basis for the rowspace of the restricted masks $W_{\bar J}$ and store the $L$ parity bits $\beta_i\cdot a_{\bar J}$. For any future $w$, ordinary Gaussian elimination expresses $w_{\bar J}$ as a linear combination of the $\beta_i$, giving its outside contribution exactly from the summary. Sweep the original tape once to the right over $J$, accumulating $w_J\cdot a_J$. The movement is $(r(H)-1)g\le H$, and the xor of inside and outside contributions is $w\cdot a$. A basis and its coefficients can be discovered in polynomial time from the public matrix for $W$, with all searches, scans, work cells, and reconstruction charged. Thus equality holds.\qedhere
\end{proof}

\begin{corollary}[Sharp rank-only insufficiency]\label{cor:failure}
For any $t\ge2$, the two future-query families $W_{\rm sparse}=\{e_0\}$ and $W_{\rm dense}=\{\mathbf1\}$ have the same output rank one. With $L=0$ and optimized source-independent initial head position, their minimum one-way continuation movement is respectively $H^*_{\rm sparse}=0$ and $H^*_{\rm dense}=g(t-1)$. Both tasks have one output bit and one bit of rank potential to resolve.
\end{corollary}
\begin{proof}
For $e_0$, place the head on $a_0$ and read it without movement. For $\mathbf1$, if the reachable window omits even one bit, the outside projected row has rank one and Theorem~\ref{th:window} requires $L\ge1$. Thus the zero-summary decoder must reach all $t$ fields, requiring $g(t-1)$ movement. One sweep attains it.\qedhere
\end{proof}

\noindent\textbf{Nonlinear summaries.} A second independent finite test exhausts all $2^8=256$ one-bit nonlinear functions $\sigma:\F^3\to\F$ for the full-coordinate future family and a fixed one-sign reachable window. None can answer all queries: the outside rank is two. A two-bit outside-coordinate summary works. This is a finite checker, not the proof of the theorem.

\noindent\textbf{Writable re-encoding.} On a \emph{different, writable-source} machine, a preprocessor can append the $t$ scattered signs to adjacent writable cells. It changes at most $t$ symbols, uses $O(tN)$ single-head movements in a simple gather-and-append routine, increases peak physical footprint by $t$, and reduces subsequent full-parity travel from $g(t-1)$ to $t-1$. For $t=7,g=18$, the reproducer records at most seven changes, 703 construction head moves, and six later movements, with $N$ increasing from 109 to 116 cells. This does not contradict Theorem~\ref{th:window}: it modifies the source and explicitly pays for doing so.

\noindent\textbf{Indexed RAM and affine controls.} Indexed source-bit probes can jump to any $a_i$ and bypass head distance, while still charging addresses and word operations. Gaussian elimination computes dense parity summaries without expansion. A simple affine or Tseitin chain can be processed in polynomial time and may have a compact exact response. Such controls block unwarranted SAT-hardness conclusions.

\section{Contextual value $x\mid_v$ and the resource ledger}
For an independently chosen rank potential $\Phi_W(K)=\dim(WU)$ on a certified affine candidate set $a_0+U$, a consistent fact $I$ has contextual value
\[I\mid_{v_{\Phi_W}(I\mid s,K)},\qquad v_{\Phi_W}(I\mid s,K)=\Phi_W(K)-\Phi_W(K\cup\{I\}).\]
This is an \emph{information score}, not a machine-time oracle. Duplicate facts have value zero; for target $a_0\oplus a_1$, knowing either individual share has zero value, while learning both has joint value one. The dense-parity and sparse-coordinate examples both have one-bit eventual target value, but different one-way physical acquisition costs. With a changed target family, potential can rise rather than fall, so a policy must explicitly charge target discovery and cannot assume monotonicity across changing contexts. Stored masks, past computation, parity evaluation, and output verification all have independent costs.

\noindent\textbf{Native model bookkeeping.} With source length $N$ and public family description $M_W$ (if not generated by the uniform program), the construction's total bit-time is conservatively $O((N+|M_W|)^5)$ on a fixed-$k$ read-only-input multitape TM, including a complete source scan, GF(2) elimination and head repositioning; peak writable cells $O((N+|M_W|)^2)$ cover explicit public matrix working copies, $L$ summary bits, address arithmetic, and coefficient computation. The source itself remains read-only and counted separately. The continuation has source head movement at most $H$, local GF(2) bit operations at most $O((N+|M_W|)^3)$, and output verification cost polynomial. These intentionally coarse \emph{constructive upper bounds} are not tight native machine exponents. A deterministic single read/write tape simulating this multitape program has conservative time $O((N+|M_W|)^7)$ and total visited footprint $O((N+|M_W|)^2)$, counting input; its own head need not satisfy our one-way restriction. A two-fully-writable-tape machine can implement the simulation with polynomial overhead, but arbitrary source writes invalidate the lower bound. An indexed bit RAM allows arbitrary source jumps; its probe count and address-bit time are distinct from $H$. A fixed universal machine has polynomial simulation with no certified precise exponent here. Failed basis choices, matrix elimination, source scans, query parsing, and witness reconstruction are charged in these ceilings. Neither maxima of different inputs nor alternate machines have been combined into one alleged forbidden region.

\noindent\textbf{Exact next lemma:} Remove the one-way restriction while preserving the complete-state convention, and characterize the optimal worst-query bidirectional movement when queries may read a selected union of source intervals, including affine-coded summaries. A correct extension must allow source-dependent head-position information only if its bits are charged, and must remain valid after cheap source compression, RAM access, and new cache state are explicitly modeled. No further static rank bound is promoted to general SAT hardness without a uniform reduction.
