\section*{PROVED/EXACT fixed-point guard}
Fix an ordinary SAT decider $A$ with $T_A(n)\le n^{K+o(1)}$. For a declared recursive implementation let $C(K)$ cover a semantic branch $a+\beta K$ and a recursive branch $\eta+\theta C(K)$, where $0\le\theta<1$. The least exponent budget satisfying
\[
C(K)\ge\max\{a+\beta K,\eta+\theta C(K)\}
\]
is
\[
\boxed{C_*(K)=\max\left\{a+\beta K,\frac{\eta}{1-\theta}\right\}.}
\]
Indeed feasibility forces both lower inequalities, and their maximum satisfies the recurrence.

If $\beta>0$, this budget remains unbounded as the unknown constant $K$ varies. If $\beta=1$ and $a\ge0$, then $C_*(K)\ge K$, so this implementation certifies no strict exponent improvement. If $0<\beta<1$, the branch may be compatible with self-improvement only if that fractional scale is itself source-certified or recursively contracted.

For the fuller declared ledger,
\[
C(K)\ge\max\{r,\chi,\delta+p,a+\beta K,\eta+g+\theta C(K)\},
\]
the least budget is
\[
\boxed{C_*(K)=\max\left\{r,\chi,\delta+p,a+\beta K,\frac{\eta+g}{1-\theta}\right\}.}
\]
This is upper-bound accounting for the declared simulation, not a lower bound on all SAT algorithms.

\section*{Boundary-Squeeze consequence}

Every branch containing $K$ must either have zero original-scale exponent, enter a proved contraction with scale below one, or be replaced by an independently bounded algorithm.
