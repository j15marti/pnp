## Obstruction and theorem

The load-bearing goal remains an all-valid-source, malformed-rejecting, both-label-correct, fully charged hereditary adaptive contractor for **Döcker's duplicate-free proper monotone 3-SAT-(2,2)**, plus a separately justified numerical FLMV transfer from ordinary SAT. This run audits a tempting *unpaid* preprocessing step in such a transfer: lexicographically sorting output clauses before allowing local bit access.

Let \(F_9\) be the valid source with positive triples (156),(238),(135),(469),(247),(789) and negative triples -(468),-(167),-(234),-(358),-(129),-(579). For \(t\ge2\), let \(F_t\) be \(t\) variable-disjoint renamed copies, \(n=9t,m=12t\). Let \(G_t\) swap variable labels 1 and 10 everywhere in \(F_t\). Both are valid canonical target-language formulas, not all-positive/easy hardness targets. They differ in **exactly eight original clause records**, have identical SAT labels, and have the same source length \(N=2H+m(1+3B)=\Theta(t\log t)\), \(B=\lceil\log_2(9t+1)\rceil,H=\lceil\log_2(12t+1)\rceil\).

**Restricted theorem (shuffled-row sorted-first-bit query lower bound).** Inputs present the clauses in an arbitrary permutation of **fixed-width** records, but output positive clauses are lexicographically sorted. The requested output bit is **bit 3, zero indexed**, of the second variable in the lexicographically first positive clause. A uniform no-setup source-bit or entire-record probing procedure, correct on all the specified promised valid target inputs, needs **\(\Omega\(m\)=\Omega(N/\log N)\)** worst-case source probes. Moreover, under the equally likely paired inputs (\pi\(F_t\),\pi\(G_t\)) with uniform hidden clause permutation \(\pi\), any adaptive randomized procedure touching at most \(q\) distinct clause records has mean success probability at most
\[
\frac12+\frac12\left(1-\frac{\binom{m-8}{q}}{\binom{m}{q}}\right)
\le \frac12+\frac{4q}{m}.
\]
Thus success at least 3/4 on this input distribution requires \(q\ge m/16\). For \(q>m-8\) the binomial-ratio term is interpreted as zero.

**Proof.** The first sorted positive clause in \(F_t\) is (1,3,5); in \(G_t\) it is (1,12,14). Their second-variable bit 3 is respectively 0 and 1. The two variables moved by the swap each have exactly four signed occurrences and occur in disjoint copies, so only eight clause records differ. Couple the two equally likely inputs under the same uniformly random row permutation. Before the probe procedure touches one of those eight changed records, **the complete transcripts agree bit-for-bit**, including header, source-bit values and adaptive decisions. The eight exceptional row positions are a uniformly random subset of the \(m\) positions. The probability of touching one in \(q\) distinct record locations is \(1-\binom{m-8}{q}/\binom{m}{q}\le8q/m\). On identical transcripts the algorithm cannot distinguish the equally likely cases better than probability 1/2. This proves the bound. Even one-bit probes cannot improve it, since every bit query touches at most one record. The same coupling applies to arbitrary randomized policies, averaged over their internal randomness. QED.

This is a **known adversary/selective-reading principle specialized to a fully valid signed-quota SAT source family**, not a new general data-structure or SAT lower bound. It does not apply if the input is already sorted, the desired output is order-insensitive, a preprocessing index is paid for, or the compiler emits unsorted fixed-slot clauses. In particular it does **not** exclude near-linear time **one-time** preprocessing: a complete scan computes this single output bit in \(O(N\,\mathrm{polylog}N)\) time and \(O(\log N)\) auxiliary space. It only blocks treating a data-dependent lex-sort accessor as a free \(N^{o(1)}\)-time *stateless per-bit request*. A general SAT-to-Döcker reduction remains OPEN.

## Explicit FLMV-index input microprotocol, not a complete native-machine trace

FLMV §2.1 uses indexed read-only input with an index tape **atomically erased at each jump**; index and work tapes count in space, while input and write-only one-way output tapes do not. Consider the declared full-row-scan protocol: for each source clause at address (a_j=2H+jR), (R=1+3B), construct a width-(w=\lceil\log_2(N+2)\rceil) index, rewind its head, jump/erase, and sequentially read (R) source bits. Before **address arithmetic, comparisons, witness/proof construction, selector switching, failed policies or guests**, the protocol charges (mR) source reads, (mw) index-cell writes (including unchanged-zero writes), (2m(w-1)) index-head moves, \(m\) atomic jumps and (m(3w-1+R)) counted native action slots. Physical cumulative index-content XOR is exactly (2\sum_{j=0}^{m-1}\mathrm{popcount}(a_j)); its endpoint XOR is zero, and the peak index-tape extent is (w). Atomic erasure invalidates an unqualified one-written-bit-per-native-step inference.

At (t=64,N=23828), the protocol counts **23,808** source-bit reads, **11,520** index-cell writes, **21,504** index-head moves, **768** jumps and **57,600** primitive action slots before address arithmetic/comparisons. Index-content XOR totals **10,890**, endpoint 0, and a declared explicit-counter/record/index payload uses at most **112** simultaneous bits (excluding all missing implementation and guest state). This is a **protocol-specific component ledger**, NOT a complete FLMV implementation, upper bound for all algorithmic actions, or a claim of native SAT decision cost. Sequential source scanning can do better than per-record indexed jumps. The lower bound above needs only source probes and is independent of this particular scan protocol.
