\section{Grammar and exact bit-length obligation}
The input is a canonical physical \(N\)-bit proper signed 3CNF with verified compact header, three distinct nonzero IDs per line, zero terminator and immutable authentic first-byte source offsets. Names and offsets are bounded by \(N\). An overflow-aware source parser rejects enormous decimal headers before allocating more than \(O(\log N)\) counters. Extending this to every alternate ordinary SAT encoding requires a separately charged normalizer.

A DFS proof stream has \(\mathsf{BRANCH}(x,P_0,P_1)\), \(\mathsf{EMPTY}(p)\) and \(\mathsf{PATH}(x,\gamma_+,\gamma_-)\). BRANCH checks both restrictions and prohibits repeated variable IDs on a path. EMPTY checks an actual original clause at source offset \(p\) has become empty. PATH checks two directed, source-offset-authenticated paths \(x\leadsto\neg x\) and \(\neg x\leadsto x\) through genuine residual unit/binary \emph{subset} clauses, each path at most \(2n-1\) edges. Untouched ternary clauses are allowed. Each edge encodes its actual source pointer and signed endpoints and has no free semantic status. Let \(B\) be internal nodes, \(L=B+1\) leaves, \(E\) actual source-edge records, \(R=B+L+E\), \(h\) maximum depth, \(P\) physical guessed proof bits. For a fixed canonical record format with one type tag, \(O(1)\) bounded IDs/counts per node and \(O(1)\) per edge,
\[
P\le C R\lceil\log_2(N+2)\rceil.
\]
No arbitrary padding/comments, no unbounded-length ID, no omitted terminator and no uncharged index word. Without this grammar restriction, retain an independent \(+P\) term in every bound.

\section{STREAM-DICT132: exact restricted resource lemma}
\begin{theorem}[PROVED/EXACT, conditional on the declared canonical machine interface]
A single uniform deterministic source-authenticated verifier exists with
\[
T_V=O\left(N\operatorname{polylog}(N+2)+(P+R)\operatorname{polylog}(N+P+2)\right),\qquad
S_{V,\mathrm{peak}}=O\left((h+1)\log(N+P+2)\right)
\]
writable/index bits, charging all source seeks, proof-bit reads, changed/unchanged writes, comparisons, address computation, index resets, working node slots, rollback/ancestor state, parser and output flag. For canonical records \(P=O(R\log N)\), this gives \(T_V=(N+R)\operatorname{polylog}(N+R)\) instead of Role-3's conservative \(N\operatorname{polylog}N+R(h+1)\operatorname{polylog}(N+P)\).
\end{theorem}
\begin{proof}
Validate the immutable source with a saturating compact-header parser in a single scan. Maintain a depth-first BRANCH frame stack (up to \(h\) live ID, assignment, child-phase and parser records) and a balanced search tree keyed by exactly the assigned original variable IDs. Each dictionary node holds an ID, bit, two child/one parent address and balance information, each \(O(\log(N+P))\) bits. An iterative parent-pointer AVL implementation uses \(O(\log(h+2))\) worst-case node searches/rotations/updates and \(O(\log(N+P))\) extra working/index bits; every node access and comparison takes only polylogarithmically many charged bit/index-tape operations. On branch entry reject a previously assigned ID, insert value 0, verify child 0, toggle to 1, verify child 1, then remove the ID. Thus the tree equals the live ancestor assignment at each point; no full residual CNF, proof tree or source-directory table is stored.

At a leaf authenticate each claimed line-start offset against the read-only source and parse its three literals; each literal has one balanced lookup. For PATH also check the signed implication endpoint pair, vertex continuity, remaining unassigned pivot, maximum path length and residual width at most 2. Each clause/edge entails \(O(1)\) balanced operations, each charged \(\operatorname{polylog}(N+P)\) bit steps. Parsing/guessing \(P\) bits costs at least \(P\), and the original source scan costs at least \(N\). Only \(O(h)\) dictionary/stack records and \(O(1)\) leaf buffers are live, giving the stated simultaneous bounds for the \emph{same verifying machine}. Induction over BRANCH/EMPTY/PATH preserves Role-3's all-SAT soundness and existential (unbounded) UNSAT completeness; replacing a linear scan by an exact dictionary never changes an assignment or source clause.
\end{proof}
