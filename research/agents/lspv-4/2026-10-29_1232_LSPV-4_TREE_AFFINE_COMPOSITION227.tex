\begin{abstract}
An exact full-shared-interface tree dynamic program makes unrestricted global dependency count compatible with polynomial computation \emph{provided} the given, verifiable decomposition has polynomially many nodes, local affine codimension uniformly bounded, and full shared interfaces of logarithmic size. The cost is explicitly $D+\operatorname{poly}(N)\sum_t2^{b_t}N_t^{O(e_t)}$, including interface enumeration, local acquisition, joins, and witness reconstruction. The local algorithm is already known: the GF$(2)^e$ specialization of the group-valued 2SAT recursion of Brakensiek--Gopi--Guruswami, and Arvind--Guruswami Theorems 2 and 17. We reproduce it and exhibit minimal structural and branch-mass counterexamples against two unjustified shortcuts. Neither counterexample is an algorithm-independent SAT lower bound.
\end{abstract}

\section{BUILD I: authenticated full-interface composition}
Let a finite Boolean constraint system of physical size $N$ be distributed over a \emph{rooted tree} of $M$ modules. Each source constraint, with a unique authenticated identifier, belongs to exactly one module $t$, and every constraint's full variable scope is contained in that module's bag $X_t$. For each variable $x$, the set of bags containing $x$ is connected in the tree (running intersection). Set
\[
B_t=\{x\in X_t: x\text{ occurs in at least one other bag}\},\qquad b_t=|B_t|.
\]
These are the \emph{complete shared interfaces}, including descendants' or siblings' variables; they cannot be replaced by only the parent separator. Every other variable in $X_t$ is private to $t$. Module $t$ contains a 2CNF $C_t$ and an explicitly listed system $A_tx=c_t$ over $\GF$ of rank (codimension) $e_t$. Let $L_t$ be its full local encoded bit length, and $D(N)$ the deterministic \emph{acquisition and complete authentication} time for the entire decomposition. Authentication includes variable IDs, constraint ownership, scope coverage, tree acyclicity, running intersection and all interface sizes.
\begin{theorem}[Exact composition; conditional on discovered structure]
For every such authenticated instance, deterministic single-controller dynamic programming decides satisfiability, and reconstructs a witness on YES, in finite-$k$ multitape time
\[
T_k(N)=O\!\left(D(N)+\operatorname{poly}(N)\sum_{t=1}^{M}2^{b_t}(L_t+1)^{c(e_t+1)}\right),
\]
for an absolute algorithm-dependent constant $c$. An implementation materializing a witness for every passing row uses at most
\[
S_k(N)=O\!\left(\operatorname{poly}(N)+\sum_t2^{b_t}(b_t+N)\right)
\]
writable cells, including all row witnesses and tables, and all materialized intermediate states. A recomputation variant can store only table bits/backpointers and reconstruct the chosen witnesses with at most polynomial additional time. If $M,D$ and all $L_t$ are polynomial in $N$, $b_t\le c_0\log N$, and $e_t\le e_0$ for fixed $c_0,e_0$, both bounds are polynomial, independently of the total number of affine equations in the input.
\end{theorem}
\begin{proof}
Root the authenticated tree, process nodes bottom-up, and for \emph{each} $\beta\in\{0,1\}^{B_t}$ pin the interface. For child $u$ let $S_{ut}=X_u\cap X_t$. Because $S_{ut}\subseteq B_t\cap B_u$, its already computed projected subtree table can be queried with $\beta|_{S_{ut}}$. Reject any row whose child projection fails. The remaining local question is $(C_t\wedge[A_tx=c_t])|_{B_t=\beta}$; it is again 2CNF plus affine equations. Coordinate pinning cannot increase residual affine rank, since taking a column submatrix has rank at most $e_t$; a zero-row equation $0=1$ is detected immediately. Brakensiek--Gopi--Guruswami / Arvind--Guruswami therefore decide the pinned local problem in $(L_t+1)^{O(e_t+1)}$ time. Save passing rows and compatible witness pointers. The connected occurrence condition ensures that if a variable appears in two subtrees, it occurs in their connecting parent bags; thus no incompatible assignment can survive the full-interface joins. Induction over the tree proves that every table row is equivalent to a satisfying completion of its entire subtree. The root's empty projection decides SAT. Walk back through stored rows and verify every original source constraint to reconstruct a correct model. The same program returns NO when no root row survives; no SAT/UNSAT side bit is provided. There are exactly $2^{b_t}$ candidate rows per node. Summing their charged local calls, child projections, table storage and reconstruction proves the stated bounds.
\end{proof}
\begin{lemma}[Native-machine accounting firewall]
For the above fixed-$k$ read-only-input multitape realization, if $T_k$ and $S_k$ are the actual charged worst-case resources, a conventional full-scan one-tape simulation has
\[
T_1=O\!\left(T_k(N+S_k+\log(T_k+2))\right),\qquad P_1=O(N+S_k+\log(T_k+2)).
\]
The physical single tape contains the initial source. This is an \emph{upper-bound translation only}. A deterministic two-fully-writable-tape implementation and an indexed-RAM implementation must separately charge head movements, tape writes, input cell probes and actual word sizes. A fixed universal machine adds simulation/description overhead; no exact native RAM, two-tape or fixed-universal-machine exponent is claimed.
\end{lemma}
\section{BUILD II: smallest structural counterexample}
\begin{counterexample}[Three-bag path without running intersection]
Take bags $X_0=\{x,u\}$, $X_1=\{u,v\}$, $X_2=\{x,v\}$ joined as a path $0-1-2$. Put the unary clause $(x)$ at node 0 and $(\neg x)$ at node 2, and no clause at node 1. Every local system is satisfiable, but the conjunction is UNSAT. The occurrences of $x$ are disconnected because the middle bag omits $x$. A naive parent-separator projection drops this incompatibility and outputs SAT. A correct running-intersection validator rejects this decomposition. A two-node tree cannot exhibit this disconnected-appearance pattern, so three is minimal in module count. This is a falsification of an \emph{invalid decomposition}, not evidence of SAT hardness.
\end{counterexample}
\begin{counterexample}[Six-variable strict signed exact22 root: $n^2$ potential]
Take $n=6$ with clauses $(x_i\lor x_{i+1}\lor\neg x_{i+2})$ for $i\bmod6$ and $(\neg x_0\lor\neg x_1\lor\neg x_2)$, $(\neg x_3\lor\neg x_4\lor\neg x_5)$. Each variable occurs twice positively and twice negatively. The source is satisfiable, has eight clauses and primal minimum degree four. Any tree decomposition covering every source clause must have a bag of at least five variables: graphs of treewidth at most three are three-degenerate, contradiction. If each original clause is made a separate module, all six source variables occur in multiple bags and this bag forces $b_t\ge5$. This is a \emph{one-clause-per-module architecture floor}, not a universal interface lower bound. Pinning either truth value of $x_0$ retains all five other variable names and at least binary clauses. A purported root recurrence charging two child costs $(n-1)^2$ gives $2\cdot25=50>36=n^2$; it cannot be paid by a strictly decreasing $n^2$ potential. For any fixed $p>0$, $2(n-1)^p>n^p$ for all sufficiently large $n$.
\end{counterexample}
