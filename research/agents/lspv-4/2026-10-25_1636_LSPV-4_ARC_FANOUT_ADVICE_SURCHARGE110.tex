\section{The literal fanout-concurrency surcharge}
\begin{theorem}[Separate-live-instance accounting]
Fix $0\le b$, $0<\rho\le1$, and let $Q=N^{b+o(1)}$ \emph{simultaneously live, separately represented} calls have ordinary input lengths $n=N^{\rho+o(1)}$. Suppose a fixed supplied decider's independent work/index state in each live call occupies at least $n^{u-o(1)}$ cells. A literal controller retaining all such states has
\[
\boxed{S_{\mathrm{live}}=\Omega(N^{b+\rho u-o(1)})}.
\]
If it separately materializes each readable ordinary query string, then also
\[
\boxed{S_{\mathrm{live}}=\Omega(N^{b+\rho-o(1)})}.
\]
For a conventional independent-state simulation of an algorithm bounded by $n^{s+o(1)}$ space these are matching upper exponents, subject to separately charged controller/ancestor buffers. Advancing all $Q$ copies through $\tau(n)$ steps by a \emph{literal sequential step simulator} requires $\Omega(Q\tau(n))$ simulated operations. This is not a lower bound for an arbitrary code-aware/shared-state SAT decider.
\end{theorem}
\begin{proof}
The premise requires simultaneously distinct live work/index tape configurations; their occupied cells are disjoint in the declared representation, hence add. The same argument counts distinct materialized readable input buffers. The number of ordinary sequential simulation operations is the sum of the program steps actually performed across copies. A cleverer representation, deliberate serialization or recomputation changes a premise and must be separately analyzed. \end{proof}

\begin{theorem}[Tight padded-decider witness in the literal model]
Let $A$ be a total uniform exact ordinary-SAT decider with joint upper bound $(t,s)$ and $0\le s\le t$. There is a fixed correct $A^{\rm pad}$ with the same upper exponent pair which, before its SAT computation, visits and initializes $\lceil n^s\rceil$ distinct writable cells, retains them, and then runs $A$. Every fully live independent copy therefore occupies at least $n^{s-o(1)}$ cells. Repeated unchanged writes still contribute bit work although they need not contribute actual complete-state flips.
\end{theorem}
\begin{proof}
A polynomially padded counter writes/scans the declared cells using $n^{s+o(1)}$ work and at most $n^{s+o(1)}$ space, then calls $A$ while retaining them. Since $s\le t$, the same time upper exponent is preserved; correctness is unchanged. This proves tightness \emph{for literal independent copies of an eligible padded program}, not that all source transformations must simulate those copies independently. \end{proof}

At the illustrative ARC values $b=3/5$, $\rho=1/2$, $s=1/2$, the separate live scratch space exponent is $17/20=0.85$, while all materialized query bodies cost $11/10=1.1$. Both exceed $d_0\approx0.50113$. For the strict FLMV box, a literal virtual-input race would require
\[
\boxed{b<d_0-\rho s=\frac{5834379}{23232400}},
\]
and a literal materialized-input race requires
\[
\boxed{b<d_0-\rho=\frac{26279}{23232400}}.
\]
These are \emph{model-specific necessary conditions} for the described all-live policy. They are not necessary for serial calls, source-shared virtual views or other ARC approaches.

\section{Two simultaneous levels versus depth-first composition}
With $N^{a+o(1)}$ children of length $N^{\lambda+o(1)}$ per parent, level $d$ contains
\[
Q_d=N^{a(1-\lambda^d)/(1-\lambda)+o(1)},\qquad
n_d=N^{\lambda^d+o(1)}.
\]
If every level-$d$ node is concurrently held as an independent padded-work solver state, its literal peak exponent is
\[
\boxed{\sigma_d^{\rm work}
=a\frac{1-\lambda^d}{1-\lambda}+\lambda^d s}.
\]
For separately materialized child inputs,
\[
\boxed{\sigma_d^{\rm body}
=a\frac{1-\lambda^d}{1-\lambda}+\lambda^d}.
\]
At $(a,\lambda,s)=(3/5,1/2,1/2)$, level one has $(\sigma_1^{\rm work},\sigma_1^{\rm body})=(17/20,11/10)$; level two has $(41/40,23/20)$. The depth-$d$ scratch exponent approaches $6/5$. These formulas count an actually concurrent frontier, not the total sequential work spent across a depth-first tree.

The earlier \texttt{DEPTH-FIRST-VIRTUAL-COMPOSITION68} already established the contrasting fixed-depth \emph{conditional} depth-first space recurrence. With one child active at a time, reusable workspace and paid locally readable descriptors, the valid bound is
\[
s'\le\max\{\lambda s,\eta,\kappa\}
\]
for a virtual child, or $\max\{\lambda,\lambda s,\eta,\kappa\}$ if one ordinary child is materialized. The fanout $a$ then appears in time, not automatically in peak space. The new contribution here is the \emph{explicit synchronous fanout penalty and exact strict-box thresholds}, not reinvention of that depth-first lemma.

\section{A corollary concerning existential solver-code selection}
\begin{corollary}[Finite hardwiring does not evade extensional elimination]
Fix \emph{one} hypothetical polynomial ordinary-SAT decider $A$ and any finite controller program $C_A$ chosen after inspecting its source code, exponent, or a finite proof. Suppose that on every ordinary input $C_A$ is exact and total, its \emph{runtime} dependence on $A$ consists only of correct SAT membership bits on fractionally shorter ordinary queries, and every policy/selector query and nonoracle operation satisfies the two-channel bounds of \texttt{ARC-EXT-SELECTOR-NOGO109}. If these bounds lie in that result's forbidden extensional region, then such a controller cannot exist.
\end{corollary}
\begin{proof}
Once $A$ and the finite controller are selected, $C_A$ is a fixed uniform extensional SAT-oracle transducer. The code-selection step need not be effective: the mathematical existence of one such finite program is enough. Strong induction on shorter query length replaces every SAT answer oracle by recursive calls to the \emph{same} finite controller, yielding one ordinary exact decider with
\[
\tau=\max\{1,r,a/(1-\lambda),b/(1-\rho)\},\quad
\sigma=\max\{h,\lambda,\rho\}.
\]
If $(\tau,\sigma)$ is in the strict published FLMV box, contradiction. This is explicitly a corollary of \texttt{MODELBRIDGE-0011}/\texttt{NOGO109}, not a distinct unconditional lower-bound theorem. It does not apply when a controller actually inspects timing, internal tape state or other implementation-specific runtime information of $A$, or calls $A$ at parent length: those costs and semantic consequences remain \emph{OPEN}. \end{proof}

\section{Actual two-level SAT/UNSAT ordinary-CNF experiment}
For each independent block $i$ with three private variables, form seven of the eight ternary signed clauses that exclude one assignment each; omit the clause falsified by $(1,1,1)$ for a uniquely SAT block, or include all eight for an UNSAT block. The source is a conjunction of $p$ disjoint blocks. For a list of $n$ block IDs, choose $q=\lceil n^{3/5}\rceil$ windows, each of $h=\lceil n^{1/2}\rceil$ IDs, with starts $jh$ modulo $n$. The first $\lceil n/h\rceil$ windows cover every block; extras repeat already represented blocks. Because each block is independent,
\[
\SAT(F)=\bigwedge_j \SAT(F_j)
\quad\text{and}\quad
\SAT(F_j)=\bigwedge_\ell \SAT(F_{j,\ell})
\]
for both source labels at \emph{two real recursive levels}. Each child is an explicit valid ordinary 3CNF, but this easy source family generally lies outside strict M22.

The full standard-library Python auditor exercised $p=2,3,4,8,16,64,256,512$, four SAT/UNSAT placements per $p$, hence 32 two-level cases with zero failures. Independent exhaustive full-assignment comparisons of the original CNF and the covered-child conjunction on $p=2,3,4$ checked 18,688 assignments.
