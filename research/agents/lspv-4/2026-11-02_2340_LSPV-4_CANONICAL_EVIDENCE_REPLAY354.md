## Exact theorem, proof and assumptions
Let N be binary source length, n <= N the number of distinct original variables (canonicalized by first occurrence), m <= N the number of original clauses, and q the number of charged nodes in a legal shared contradiction DAG. Source axioms are free; each paid node has unit cost; choice of the optimal proof is free. The canonical typed presentation uses RES clauses, AND3 truth tables of at most three variables, affine GF(2) rows, and one fresh two-input Boolean gate per DEF. Nodes have up to two predecessor references and a constant number of variable identifiers. Any LOCAL-CONVERT circuit must have a bounded-size truth-table representative whose substitution preserves *all downstream rule legality*. This extensional-normalization requirement remains **unverified for every presentation of the original full Rmix341**.

**Canonical evidence theorem.** There is a same-q variable-renamed typed certificate whose source-plus-proof bit length obeys
B <= N + q(8V + 4h + 4b + 64) <= 100(N+q+2)^2,
where V=n+q, h=ceil(log2(m+q+2)), b=ceil(log2(V+2)).
A deterministic multitape verifier with full line materialization uses at most O((N+q+2)^4) bit steps and O((N+q+2)^2) peak writable bits, including input parsing and antecedent retrieval.

**Proof.** Deterministically rename source variable IDs to 1..n while checking them against input. Each charged DEF adds at most one variable. A signed clause is a 2V-bit vector, an XOR row a V-bit mask plus one RHS bit, a local factor an eight-bit truth table with at most three named variables, and a two-input gate a fixed four-bit function plus three variable references. Parent indices require at most h bits each. The stated padding suffices. Checking RES recomputes the *signed* pivot resolvent; AND3 examines at most eight rows; XOR validates two row masks; DEF checks freshness and conservative equality without asserting that its output is true. At most q materialized size-O(V) lines are held, with extra sequential scanning giving the conservative quartic verifier bound. Any proof with polynomial q has polynomial bit evidence. Conversely, polynomial bit evidence includes at least one bit per charged node.

This is a verifier/evidence upper bound only. It does *not* prove that a fast SAT decider emits the proof, nor that its internal computation dominates proof construction. Cook-Reckhow (1979) gives the existence of some polynomially bounded proof system under NP=coNP, not polynomial boundedness of the fixed Rmix341. An A-dependent oracle or custom proof rule would change R and is not B3.
