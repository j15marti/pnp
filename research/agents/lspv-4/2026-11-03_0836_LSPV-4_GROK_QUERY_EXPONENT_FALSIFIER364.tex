\section*{Source and theorem}
Start from Haken (1985): ordinary DAG resolution on the standard
$\mathrm{PHP}_{h+1}^{h}$ needs $2^{\Omega(h)}$ clauses/nodes, whereas
its ASCII DIMACS encoding has $N=O(h^3\log h)$ bits. This establishes
a superpolynomial lower bound for the fixed ordinary Resolution proof
system, not general SAT computation and not automatically the preselected
mixed $R_{\rm mix341}$. Cook--Reckhow (1979) and Buss (1987) give
polynomial Extended-Frege/Frege pigeonhole proofs. The already certified

\section*{Precise conditional counterexample, including tight worst case}
Assume for contradiction-testing that a correct total ordinary
general-CNF SAT algorithm $B$ runs in $O(N^{k_0})$ time, handling valid
SAT, UNSAT and malformed inputs. For any integer $K>k_0+1$ build a
fixed uniform correct decider $A$: first parse the source, returning UNSAT
on recognized opposite units and SAT on an all-TRUE satisfying witness.
For an easily recognizable infinite family of valid SAT sentinels
with only negative unit clauses, perform exactly $\Theta(N^K)$ dummy
steps (using logarithmic counters) and invoke $B$. Otherwise invoke $B$.
It follows that $T_A^{wc}(N)=\Theta(N^K)$ (on dense sentinel lengths)
while $A$ answers each source from the distinct valid unsatisfiable
family $(x_1)\wedge(\neg x_1)$ plus $N^{\Theta(1)}$ tautological
$(x_2\vee\neg x_2)$ padding clauses after one linear parse.
For $q=\lfloor N^\epsilon\rfloor$, $0<\epsilon<0.1$,
the $q$ guest calls use $O(qN\log N)$ indexed-input bit work, NOT
$\Omega(qN^K)$. This refutes the proposed guest lower bound even
when $K$ is a tight global exponent, conditioned only on existence
of $B$. It does not refute B2 or B3. No SAT oracle is assumed in
the project proof. The finite code below uses a small exhaustive
oracle only to independently label test instances.
