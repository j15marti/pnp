\section*{Model and complete recurrence}
Let \(V\) be the fixed 62 paid Resolution occurrences; \(D\subseteq V\) an already computed order ideal; \(L(D)=\{u\in D:\exists v\notin D,\ u\to v\}\) the live paid results. An eligible last-use overwrite for a ready \(v\) exists exactly when some paid parent \(u\in L(D)\) has no other uncomputed consumer:
\[
r(D,v)=1 \ \Longleftrightarrow\
\exists u\to v\ \bigl[\{w\notin D:u\to w\}=\{v\}\bigr].
\]
For the nonexpansion variant require in addition
\[
|\operatorname{JSON}(C_u)|\geq|\operatorname{JSON}(C_v)|,
\]
where \(C_i\) is the exact signed canonical clause and the length is only the serialized clause array, not the complete record or all physical storage.

\begin{theorem}
In this fixed-DAG no-recomputation atomic whole-clause-slot model, a \(b\)-slot execution exists if and only if \(V\) is reachable from the empty ideal through ready-node edges
\[
D\longrightarrow D\cup\{v\},\qquad |L(D)|+1-r(D,v)\leq b.
\]
The same equivalence holds with the additional nonexpansion condition on \(r\).
\end{theorem}
\textbf{Proof.} Every result with a future consumer must remain retained because recomputation is forbidden. Every other result may be freed immediately. Producing \(v\) requires one output position, which can be the storage of a last-use paid parent after reading it, and otherwise requires a new slot. This proves necessity and sufficiency of the transition bound. An induction on \(|D|\) establishes the reachable-ideal characterization. The optional nonexpansion test merely restricts which last-use parents qualify. This theorem assumes atomic whole-clause register operations; it does not bound working bits or scratch used for an actual in-place resolution implementation. \(\square\)
