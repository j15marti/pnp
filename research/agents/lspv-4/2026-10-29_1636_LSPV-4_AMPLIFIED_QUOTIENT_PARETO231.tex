\section{BUILD: an exact signed amplification construction}
A proper signed strict exact-$(2,2)$-3CNF has three \emph{distinct} variable names per clause and exactly two positive and two negative occurrences per variable. A fixed boundary $Y$ of $b>0$ names is removed to expose $k$ connected private modules $Z_i$. No clause contains private names from two different modules. A local private set $B_i\subseteq Z_i$ hits every clause \emph{disjoint from $Y$}; clauses already meeting $Y$ are considered hit by the global boundary. Put $q=\max_i\min |B_i|$.

Start with the signed connector-tree $G_b$ from \cite{component}. Its $b$ boundary names form a path; each consecutive pair is joined by a four-private-name connector, while degree-deficit slots at boundary names are occupied by five-private-name leaves. The numbers are $b-1$ connectors and $2b+2$ leaves, hence $k=3b+1$. Every boundary name occurs four times (twice per sign); every private name occurs twice per sign. A leaf has the seven unsigned scopes
\[
(y,a,b), (a,c,d),(a,c,e),(a,d,e),(b,c,d),(b,c,e),(b,d,e),
\]
and the positive occurrence indices are $a:\{0,1\}$, $b:\{0,4\}$, $c:\{1,2\}$, $d:\{1,3\}$, $e:\{5,6\}$, with indices starting at zero. A connector has the six scopes
\[
(y_i,a,b),(y_{i+1},c,d),(a,b,c),(a,b,d),(a,c,d),(b,c,d),
\]
and positive occurrence indices $a:\{0,2\}$, $b:\{0,2\}$, $c:\{1,4\}$, $d:\{3,5\}$. All other private occurrences are negative. Assign two positive and two negative signs per boundary name. Leaves have residual hitting set $\{a,b\}$ and connectors $\{a,c\}$, both exactly minimum two in the base source.

For each of the $k$ private modules, choose $r=q-2\ge0$ and, when $r>0$, add a fresh copy of the cyclic exact-$(2,2)$ source on $3r$ variables $x_0,\dots,x_{3r-1}$,
\begin{align}\label{eq:cycle}
 C_i&=(x_i\vee x_{i+1}\vee\neg x_{i+2}), && i\in\mathbb Z_{3r},\\
 D_j&=(\neg x_{3j}\vee\neg x_{3j+1}\vee\neg x_{3j+2}),&&0\le j<r.
\end{align}
Swap, between $C_0$ and one old \emph{private} module clause, two positive literals: $x_1$ and the module's positive occurrence of $c$ in leaf clause index 1, or connector clause index 4. The exchange is literal-position-preserving: both signed occurrence totals remain unchanged. The exchanged clauses have new scopes $C'_0=(x_0\vee c\vee\neg x_2)$ and, respectively, leaf $C'_1=(a\vee x_1\vee d)$ or connector $C'_4=(\neg a\vee x_1\vee\neg d)$. For $r=1$, the three original cyclic triples have the same set of three names but distinct signed clause strings; every resulting clause still has three distinct names.

\begin{theorem}[Exact multi-module realized integer frontier]\label{th:main}
For every pair of integers $b\ge1$ and $q\ge2$, the described source $F_{b,q}$ is a connected proper strict signed exact-$(2,2)$-3CNF whose authenticated private components satisfy
\begin{equation}\label{eq:counts}
\boxed{k=3b+1,\quad n=(9q-3)b+3q,\quad m=4n/3,\quad \min|B_i|=q\ \text{for every }i.}
\end{equation}
Moreover, its global projected boundary relation $R_Y$ is identically TRUE, and both source construction and an explicit satisfying assignment are polynomial-time uniform in the physical output length. At its own fixed $(n,b)$, the necessary arithmetic bound is attained \emph{exactly after integer rounding}: 
\[
 q_{\sharp}(b)=\left\lceil\frac{n-3b}{9b+3}\right\rceil
 =\left\lceil q-\frac{6b}{9b+3}\right\rceil=q,
\]
because $0<6b/(9b+3)<1$.
\end{theorem}
\begin{proof}
The base quotient tree has one edge per boundary occurrence; it is connected, and every base module is connected after boundary deletion. Each attached cyclic gadget is joined to exactly one base module by the two swapped clauses, so it neither merges modules nor creates new boundary occurrences. The swap exchanges two \emph{positive} appearances and keeps exactly three distinct names per clause. Before and after swapping every old private name and every new cyclic name has exactly two appearances of each sign. The old source has $15b+6$ variables and $20b+8$ clauses. Each of $3b+1$ modules gains $3r$ variables and $4r$ clauses. Substituting $r=q-2$ proves \eqref{eq:counts}.

For every module, select the $r$ cyclic names $x_{3j}$ and additionally select old leaf $\{a,b\}$ or connector $\{a,c\}$. Every negative block $D_j$, every cyclic triple $C_i$ (including the swapped $C'_0$, which retains $x_0$), and every base-private clause (including the swapped one, which retains one selected old name) is hit, so $\min |B_i|\le r+2$.

For a leaf, the five unexchanged old private clauses have empty common variable intersection and therefore need at least two \emph{old} names to hit them. The $r$ disjoint cyclic block clauses $D_j$ need at least $r$ additional cyclic names. Thus the leaf minimum is at least $r+2$.

For a connector, the three unexchanged old private scopes $(a,b,c),(a,b,d),(b,c,d)$ intersect only at $b$. The same $r$ disjoint blocks force $r$ cyclic choices, so an assumed hitting set of size $r+1$ must choose precisely $b$ among old private names and precisely one cyclic name per block. The swapped connector scope $(a,x_1,d)$ then requires $x_1$ to be selected. The remaining cyclic triples $C_1,\dots,C_{3r-1}$ number $3r-1$; of the $r$ chosen cyclic names, $x_1$ meets only two of these and every other cyclic name meets at most three. Covering all $3r-1$ triples therefore requires every triple to be hit \emph{exactly once}. Starting with $x_1$ selected, the consecutive-triple equations force the unique selected phase $\{x_{3j+1}\}$. But the exchanged cyclic clause $C'_0=(x_0,c,\neg x_2)$ is not hit by that phase or by the sole old choice $b$, a contradiction. This proves the connector minimum $r+2$ for $r\ge1$; at $r=0$ the original four connector triples have empty total intersection and minimum two. Thus every module has exact minimum $q$.

Finally, fix \emph{any} boundary assignment. Set every old private name to TRUE and each attached cyclic gadget to periodic $110$, i.e. $x_{3j}=x_{3j+1}=1$, $x_{3j+2}=0$. Every old boundary clause contains a positive old private literal, every old internal clause contains a positive literal, both exchanged clauses retain a true positive literal, every cyclic $C_i$ is satisfied, and every $D_j$ is satisfied by $\neg x_{3j+2}$. This proves $R_Y=\mathrm{TRUE}$ and gives a linear-size witness after deterministic source generation.
\end{proof}

\begin{corollary}[Infinitely many globally optimal \emph{integer proxy} points]\label{cor:optimal}
For every integer $j\ge2$ there is an actual source with
\[
 \boxed{n=9j^2,\quad b=q=j,\quad k=3j+1,\quad t_{\rm proxy}=b+q=2j,\quad s_{\rm table}=b=j.}
\]
For \emph{every} integer pair $b'\ge1,q'\ge0$ satisfying the known necessary inequality \eqref{eq:sharp} at this same $n$, one has $b'+q'\ge2j$. Thus the realized structural exponent $2j$ is the \emph{global integer minimum permitted by the sharpened inequality}, not merely a local or continuous optimum. The full signed family is nevertheless polynomial-time recognizable with a canonical certificate and SAT-witnessed.
\end{corollary}
\begin{proof}
Substitute $b=q=j$ into \eqref{eq:counts}. The continuous relaxation of \eqref{eq:sharp}, in its positive-$q$ range, is $t_\sharp(b)=b+(n-3b)/(9b+3)$. Its minimum is $\frac23(\sqrt{n+1}-1)$, which at $n=9j^2$ lies strictly between $2j-1$ and $2j$. The truncated branch $q=0$ has $b\ge n/3=3j^2$ and so is no smaller. Every integer permitted $b'+q'$ is therefore at least $2j$. The construction attains equality.
\end{proof}

\section{Derivatives, crossings, limits, and physically normalized proxies}
The \emph{new family} has continuous interpolation at fixed $n$ of
\[
 q_{\rm fam}(b)=\frac{n+3b}{9b+3},\quad
 t_{\rm fam}(b)=b+q_{\rm fam}(b),\quad s_{\rm table}(b)=b.
\]
Where $q\ge2$, differentiation yields
\begin{equation}\label{eq:derivatives}
 \frac{dt_{\rm fam}}{db}=1-\frac{9(n-1)}{(9b+3)^2},\quad
 \frac{d^2t_{\rm fam}}{db^2}=\frac{162(n-1)}{(9b+3)^3}>0,\quad
 b^*_{\rm fam}=\frac{\sqrt{n-1}-1}{3},\quad
 t^*_{\rm fam}=\frac23\sqrt{n-1}.
\end{equation}
The refined necessary relaxation has instead $b^*_{\sharp}=(\sqrt{n+1}-1)/3$ and $t^*_{\sharp}=\frac23(\sqrt{n+1}-1)$. \section{SAME-RUN time--space firewall and five model-native ledgers}
Suppose a separate arbitrary source is supplied together with an authenticated $Y$, its private partition, and ownership of every clause. Discover each local $q$-hitting set by branching on an uncovered ternary clause in at most $3^q\operatorname{poly}(N)$ search effort. Enumerate $2^b$ boundary settings; for each, enumerate at most $2^q$ local backdoor assignments and solve the residual 2CNF by SCC. The \emph{same uniform deterministic program} processes SAT and UNSAT, and no answer-class bit is free. With $A=k(3^q+2^{b+q})$, a deliberately generous fixed-read-only-input multitape implementation has
\[
 T_{\rm multi}=O(AN^5),\quad S_{\rm multi}=O(N^2)\text{ writable cells};\qquad
 T_1=O(AN^7),\quad P_1=O(N^2)
\]
under the conservative single-tape simulation $T_1=O(T_{\rm multi}(N+S_{\rm multi}+\log(T_{\rm multi}+2)))$, including the original $N$ input cells. This is a constructive ceiling, not an exact exponent. With the same generous scanning conventions, a fixed \emph{two-fully-writable-tape} program can emulate the single-tape routine within $O(AN^7)$ transitions and $O(N^2)$ auxiliary cells; a word-RAM using $O(\log N)$-bit words can use $O(AN^4)$ word steps with $O(N^2)$ work bits. A \emph{fixed universal TM} pays interpreter and source encoding costs separately, with a polynomial simulation but no certified numerical exponent. Native head movements, input probes, failed local attempts, verification, joins, output and replay are charged within the polynomial factors. These inequalities are not reverse implications and may not be imported as RAM lower bounds.

The one-shot streaming implementation stores $O(\operatorname{poly}(N))$ writable bits, not $2^b$ bits. If a separate implementation \emph{materializes all $2^b$ truth rows}, that optional representation uses $\Omega(2^b)$ bits, or more with indexing. For the \emph{new family}, its entire projected boundary table is TRUE and can be represented by a constant Boolean value; even its $2^{b+q}$ syntax-enumeration proxy is unnecessary. This defeats any universal inference from the realized static frontier to SAT time, space, or a FLMV forbidden region. The transition of an unrestricted correct SAT solver into any model-native forbidden region remains OPEN.
