\section{An explicit proper 3CNF with four authenticated UNSAT leaves}
For integer $r\ge2$, let $z,w,x,a,b$ be five named variables. For each $v\in\{0,1\}$ and each direction $d\in\{+,-\}$ take $r-1$ \emph{fresh} intermediate variables, and form a directed literal chain of exactly $r$ edges, from $x$ to $\neg x$ if $d=+$ or from $\neg x$ to $x$ if $d=-$. For an edge $u\to v'$ in the chain insert the proper signed ternary source clause
\[
 (g_v\vee\neg u\vee v'),\qquad g_0=z,\quad g_1=\neg z.\tag{1}
\]
The literals in each source clause have three distinct underlying names. Also insert harmless source clauses $(w\vee a\vee b)$ and $(\neg w\vee a\vee b)$ so that $w$ is an actual source name. All $4r+2$ clauses are original clauses, and there are exactly $4r+1$ original variable names.

\begin{lemma}[Authentic two-level refutation]\label{lem:ref}
The resulting proper three-CNF $F_r$ is UNSAT. It has a depth-two source-authenticated refutation with \(\mathsf{BRANCH}(z)\), then \(\mathsf{BRANCH}(w)\) in each child, and four \(\mathsf{PATH}(x,\gamma_+,\gamma_-)\) terminals. Each terminal authenticates exactly $2r$ original clause-offset edge records, so $(B,L,E,h)=(3,4,8r,2)$.
\end{lemma}
\begin{proof}
At $z=v$, the guard $g_v$ in (1) is false and all guards for the opposite value are true. Thus the first set becomes actual binary implications $x\leadsto\neg x$ and $\neg x\leadsto x$, giving a contradictory strongly connected pair by the ordinary 2CNF implication-graph criterion. The choice of $w$ cannot restore a model: one filler clause is satisfied and the other reduces to $(a\vee b)$. At each terminal, scan its two declared paths and authenticate every physical pointer, signed clause, guard restriction and implication endpoint. Both branch values are explicit at each internal node. Induction on branch labels proves the source UNSAT claim. An unrelated unmentioned ternary remains permissible in this grammar.\end{proof}

The source is serialized with one canonical DIMACS clause line per clause and a physical ``\texttt{p cnf}'' header. Label the clauses in each chain by step $i=0,\ldots,r-1$. Print ALL even-step clauses first, ordered by guard, path direction and step, then the two filler clauses, then ALL odd-step clauses in that same within-parity order. Original byte offsets point to actual line starts; no alleged edge table substitutes for immutable source bytes. The complete source length in physical \emph{bits} is $N_r=\Theta(r\log r)$; the proof has $P_r=\Theta(r\log r)=\Theta(N_r)$ bits in this explicit uncompressed representation. Fixed-size unknown-length headers are avoided.

\section{Physical input itinerary and the different two-head machine}
The online immediate authenticator reads the proof records in their required depth-first order. For each edge it moves the unique sequential source head to the recorded original-clause offset, reads and checks that clause \emph{before reading the next edge}, and does not replace this action by an earlier cached copy or a reordered validation. It may initially scan the whole original source for canonical syntax. These restrictions define \emph{one particular verifier implementation}; the theorem does not quantify over all possible verification algorithms.

\begin{theorem}[Restricted native transport separation]\label{th:transport}
For the above $F_r$ and explicit proof, this one-head immediate-authentication schedule has
\[
H_{\mathrm{one}}=\Omega(rN_r)=\Omega(N_r^2/\log N_r).
\tag{2}
\]
The same proof order admits a separate two-independent-source-head realization with $H_{\mathrm{two}}=O(N_r)$ source-head movements; indexed original-clause access permits $O(N_r\operatorname{polylog}N_r+E\operatorname{polylog}(N_r+P_r))$ bit-time verification and $O((h+1)\log(N_r+P_r))$ writable/index bits under STREAM131's model hypotheses.
\end{theorem}
\begin{proof}
For each of the four directed chains, consecutive path edges alternate between the physical even-step left block and odd-step right block. Their separation includes $\Theta(r)$ complete intervening original clause records, collectively of length $\Theta(r\log r)=\Theta(N_r)$, independent of which of the four chains is chosen. There are $r-1$ switches per path and eight paths across the four leaves, so a single immediate-checking source head must physically traverse $\Omega(rN_r)$ cells. This count charges only actual head movements; it does not add those movements a second time to transition time.

With two source heads, place one in each physical parity block after a paid initial scan. Within \emph{each} of the eight directed path traversals, the successive even-step pointers and successive odd-step pointers are each in nondecreasing physical order, so each head makes at most $O(N_r)$ movements during that traversal. There are only eight traversals, so total head movement is $O(N_r)$. This uses a new second independently moving source head and is \emph{not} a valid simulation preserving the original one-head machine. An indexed machine writes an $O(\log N_r)$ address for each source clause and reads its $O(\log N_r)$-bit body, avoiding sequential travel by its \emph{native} access semantics.\end{proof}

\paragraph{Scope and adversarial bypass.} The bound (2) is NOT a verifier-independent time lower bound. A better source-aware checker may recognize the family from a scan, reorder source checks with a paid external store, exploit correlations, or choose a different UNSAT proof. An actual one-head input with another independently movable proof head is a further different model. The roles' all-time work-edit chronicle bounds constrain a totally different separated-DISJ acceptance task, and may not be substituted for (2).

\section{A separate output-retention simulation exception}
\begin{proposition}[Decision-versus-transducer footprint]
Let $M_k$ be a fixed-$k$ machine with a separate \emph{write-only} output stream excluded from its writable space, which on an $n$-byte input emits precisely $n^2$ bytes while maintaining only $O(\log n)$ work cells in $\Theta(n^2)$ transitions. If a purported one-shared-read/write-tape simulator must retain this exact contiguous output physically on its only counted tape, it has footprint $P_1=\Omega(n^2)$, even if input cells may be overwritten. Thus the conservative decision-machine simulation claim
\[
P_1=O(n+S_k+\log(T_k+2))=O(n)
\tag{3}
\]
\emph{cannot} be extended to such transducers without counting materialized output. A safe coarse shared-tape footprint budget includes $L$; for instance $P_1=O(n+S_k+\log(T_k+2)+L)$, with its own charged time for writes and repositioning.
\end{proposition}
\begin{proof}
Two binary counters of $O(\log n)$ bits implement the $n$ by $n$ output loops. Every transition emits at most one byte, so $T_k=\Theta(n^2)$. Retaining $L=n^2$ contiguous bytes on one read/write tape visits at least $L$ cells irrespective of any index compression or rewrites of the initial input. This contradicts the output-omitting bound (3), but not the valid \emph{decision-only} simulator, nor a machine with a genuinely separate output-only port exempt from counted footprint.\end{proof}
