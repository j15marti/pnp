\paragraph{Published hard-family anchor and exact model.}
Haken (1985) proves that the standard explicit unary $\mathrm{PHP}(h+1,h)$ signed CNF, with $h(h+1)$ variables, $m_h=(h+1)+h\binom{h+1}{2}$ source clauses and $N_h=\Theta(h^3\log(h+2))$ binary-index source bits, has an ordinary shared-DAG Resolution length lower bound $2^{ch}$ for some fixed $c>0$ and every sufficiently large $h$, quantifying over every unrestricted ordinary Resolution refutation of that particular source. \paragraph{The circuit model.}
A cut is a set $Z$ of distinct gate-output wire values whose removal separates all primary-input-to-output paths. Width $w=|Z|$ counts distinct boundary values, rather than duplicate fanout edges. The reachable interface relation $\mathcal R_Z$ is $\{Z(x):x\in\{0,1\}^n\}$, not necessarily the whole $\{0,1\}^w$. A correct circuit-SAT split must retain/check upstream reachability of each proposed boundary tuple, downstream output acceptance, encoding size, semantic soundness, and the cost of obtaining that split.

\begin{theorem}[All ports used; rank-one reachable interface]
For every $w\ge2$, two fixed uniform, explicitly encoded fan-in-two circuits $A_w,U_w$, each using only one Boolean input $x$, have $\Theta(w)$ gates and a complete cut of $w$ distinct wires, all used downstream, but $|\mathcal R_Z(A_w)|=|\mathcal R_Z(U_w)|=2$, with $\mathrm{SAT}(A_w)=1$ and $\mathrm{SAT}(U_w)=0$.
\end{theorem}
\begin{proof}
Define $z_i=x\wedge x$ for $1\le i\le w$ and use all $z_i$ in a binary AND accumulator $g=\bigwedge_{i=1}^w z_i$. Set outputs $o_A=g\wedge1$ and $o_U=g\wedge\neg z_1$. Each cut value is either $0^w$ or $1^w$, and both are attainable. But $o_A=x$ and $o_U=x\wedge\neg x=0$. The extra use of $z_1$ in $U_w$ increases edge fanout, not distinct wire width. A single template checker parses all IDs/pointers and verifies the identities, accumulation and terminal, using repeated paid read-only input scans: conservative $O(M^3)$ bit-time and $O(\log M)$ peak writable space. It handles both labels and rejects malformed sources. It is not a polynomial decider for arbitrary circuits; outside the templates a total correct algorithm may use exponential fallback.
\end{proof}

\begin{theorem}[Width one retains full clause-preserving residual]
Given any explicit signed CNF with at least one clause and no empty source clause $F=\bigwedge_j C_j$ with $L$ literal occurrences, compile its literal, OR and AND structure into a source-labelled fan-in-two evaluator $C_F(x)$. Add a final gate $y=C_F(x)\wedge1$. The single output wire $z=C_F(x)$ forms a complete width-one cut. Forcing $y=1$ forces the upstream child $z=1$, which under the declared explicit source-preserving gate/Tseitin encoding retains all source clauses and $\Omega(L)$ upstream gates. On the canonical PHP inputs it retains $\Omega(N_h)$ encoded original-source bits.
\end{theorem}
\begin{proof}
Every input-to-$y$ path passes through $z$; the other terminal gate input is a constant. The upstream equality $C_F(x)=1$ is the original SAT formula in its explicitly generated evaluation representation, with no clause or sign erased. A source-literal-preserving construction needs at least $L-1$ upstream gates, and the declared canonical input retains its full original signed source fields. The result is restricted to this representation: a more powerful source-authenticated semantic simplifier might produce a smaller child, but its work and correctness must be charged and proved.
\end{proof}

\paragraph{Falsifiers and interpretation.}
F1 is false: small boundary width alone does not imply small encoded child size, as the terminal width-one PHP cut shows. F2 is false: all cut wires being used does not imply $2^w$ reachable configurations, as the aliases $z_i=x$ show. F3 is false: enumeration count $2^w$ is a compulsory lower bound on computation; the two rank-one families have a paid uniform pattern recognizer, and reachable configurations may be compressed. F4 remains open: an arbitrary-correct-decider-dependent splitter might find some other small sound residual, but this requires a new constructive and model-preserving theorem.
