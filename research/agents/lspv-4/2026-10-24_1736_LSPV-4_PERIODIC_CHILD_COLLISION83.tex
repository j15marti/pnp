\section{Fixed-width ordinary encoding and exact construction}
Use six variables \(x_1,x_2,x_3,u,v,w\) and \(M=2^h\) ordered proper ternary clauses. The header stores \((6,M)\); each clause stores \((3,\ell_1,\ell_2,\ell_3)\), with sign code \(2|\ell|+\mathbf1_{\ell<0}\) and fixed width
\[
b(6,m)=\lceil\log_2(64(m+7))\rceil,\quad
N=(4M+2)b(6,M).
\]
Global duplicates are legal: proper means three distinct variables in each individual clause. Choose odd \(K\ge3\) with \(K=\Theta(\sqrt N/\log N)\), put
\[
p=2^{\lceil\log_2(8K)\rceil},\quad g=p/8>K,\quad
Q=\min\{M,\lfloor N^{3/5}\rfloor\},
\]
and take sufficiently large \(h\) with \(p\mid M\) and \(Q\ge p\).
Write \(D=(u\vee v\vee w)\). For each \(a=0,\ldots,7\), let \(C_a\) be the clause on the first three variables in which \(x_i\) is negated iff bit \(i-1\) of \(a\) is one. Hence \(C_a\) forbids exactly one assignment to the core triple. Source \(U_M\) has \(C_a\) in positions \(j\bmod p=ag\), and \(D\) elsewhere. Source \(V_M\) differs only by replacing \(C_7\) with \(C_6\) at those positions. The two parents have identical \(M,n,N\).
For source \(F\), child \(H_{F,j}\) contains ordered parent records at indices
\[
s(j,i)=(jK+i)\bmod M,\quad 0\le i<K,\quad0\le j<Q.
\]
Each child is a self-contained ordinary proper-3CNF with the same \(n=6\) header and exact bit length \(L=(4K+2)b(6,K)\).

\begin{theorem}[PROVED/EXACT: opposite parents, identical child counts]
The full parent model counts are \(\#\mathrm{SAT}(U_M)=0\) and \(\#\mathrm{SAT}(V_M)=7\). Every indexed child of either parent is SAT. For every fixed \(j\), the exact six-variable model count agrees between \(H_{U,j}\) and \(H_{V,j}\): it is 56 if the selected window has no core clause and 49 if it has one. Hence the entire ordered vector of isolated child model counts is the same despite opposite parent labels.
\end{theorem}
\begin{proof}
All eight \(C_a\) exclude all eight core assignments in \(U_M\). In \(V_M\) exactly one core assignment survives, and the separate filler clause has seven models. Distinguished source positions are spaced \(g\) apart cyclically; a length-\(K\) window with \(K<g\) contains at most one distinguished clause. No core gives \(8\cdot7=56\) models; one core eliminates one of eight and gives \(7\cdot7=49\). The marker positions are identical for both source labels.
\end{proof}

\begin{theorem}[PROVED/EXACT: content collisions and input-dependent write ceiling]
For \(Q\le M\), all \(Q\) ordered index tuples are distinct, and consecutive index sets are disjoint if \(2K\le M\). Nevertheless, for \(Q\ge p\) the number of distinct \emph{serialized ordinary child bitstrings} is
\[
D_U=1+8K,\qquad D_V=1+7K.
\]
For this source family, a fixed-address flat child array undergoing consecutive child substitutions changes at most six literal-code fields per transition. Thus it requires at most \(6(Q-1)\) value-changing field updates, corresponding to at most \(6b(6,K)(Q-1)\) bit flips in literal fields. This is not a bound on addressing or total work.
\end{theorem}
\begin{proof}
Odd \(K\) is coprime to both powers of two \(M,p\), so index start positions are all different and the first \(p\) child starts cover every phase of the periodic record word. A content window has either only filler, or one special core record at one of \(K\) offsets. This gives one filler-only bitstring and one for each distinct core type and offset: eight types in \(U_M\), seven in \(V_M\). A pair of consecutive child arrays differs at no more than two record positions; each record has three literal-code fields and the headers and type fields are unchanged.
\end{proof}

For \(N=\Theta(M\log M)\), \(K=\Theta(N^{1/2}/\log N)\), \(p=\Theta(K)\), and \(Q=N^{3/5+o(1)}\), we have \(D_U,D_V=\Theta(K)=o(Q)\); the ratio \(Q/D_U=\Theta(N^{1/10}\log N)\). These are structural output classes, not a hardness measure.
