\section{Rechecked static lemma}
For connected proper strict signed exact-(2,2)-3CNF with $n$ variables and $m=4n/3$ ternary clauses, suppose a fixed $b$-variable global boundary $Y$, disjoint nonempty private modules $Z_i$ ($k$ total), no cross-module private names in any clause, and syntactic clause-hitting $B_i\subseteq Z_i$ with $|B_i|\le q$. Then
\[
k\le4b,\quad n\le3(b+\sum_i|B_i|)\le3b+12bq,\quad b+q\ge\sqrt{n/3}-1/4.
\]
Indeed each private module touches a boundary clause, of which there are at most $4b$; $Y\cup\bigcup B_i$ hits every clause and each variable touches four clauses; AM--GM completes the bound. For $b=0$ the connected formula has one private module and $q\ge n/3$. This is a syntactic-architecture obstruction, not a time lower bound. The attached Library \texttt{Connected\_Interface\_Audit.zip} was independently rerun with exact JSON agreement: 4680 boundaries, 7191 hitting-set tests, 139 decision comparisons.
\section{BUILD: connected exact-(2,2) grid-width family}
Let $L\ge2$ and let indices $r,c$ be modulo $L$. Introduce $A_{r,c},B_{r,c},C_{r,c}$. For each cell add
\begin{align*}
D^0_{r,c}&=(A_{r,c}\vee B_{r,c}\vee C_{r,c}),\\
D^1_{r,c}&=(A_{r,c}\vee B_{r+1,c}\vee C_{r,c}),\\
D^2_{r,c}&=(\neg A_{r,c}\vee\neg B_{r,c}\vee\neg C_{r,c+1}),\\
D^3_{r,c}&=(\neg A_{r,c}\vee\neg B_{r+1,c}\vee\neg C_{r,c+1}).
\end{align*}
There are $n=3L^2$ names and $m=4L^2$ clauses. Every type is a three-layer perfect matching; hence every variable appears exactly twice positively and twice negatively, every clause has three distinct variables, and the $A$ layer is a minimum hitting set of size $n/3$. The explicit assignment $A=1,\ B=C=0$ satisfies the formula, illustrating why this is not a decision hardness theorem.
\begin{theorem}[Unbounded moving and hierarchical syntactic interfaces]
The primal graph is connected; every variable order has maximum processed-to-unprocessed vertex frontier at least $L-1$, and every tree decomposition has a bag of at least $L$ vertices. A cell-major order has frontier at most $9L$. Thus minimum pathwidth and treewidth are $\Theta(L)=\Theta(\sqrt{N/\log N})$ for unpadded canonical length $N=\Theta(L^2\log L)$.
\end{theorem}
\begin{proof}
Each nonwrapping row-direction grid edge between $A_{r,c}$ and $A_{r+1,c}$ is subdivided by $B_{r+1,c}$, with two primal edges from clause types 1 and 0. Each column-direction edge between $A_{r,c}$ and $A_{r,c+1}$ is subdivided by $C_{r,c+1}$, from clause types 2 and 0. Their internal vertices are disjoint. Hence an $L$ by $L$ subdivided grid is present; all remaining names touch an $A$ name and the primal graph is connected.

For each grid row $r$ take its subdivided row path $R_r$; for each column $c$ take its subdivided column path $K_c$. The connected crosses $X_{r,c}=R_r\cup K_c$ are pairwise intersecting, since row $r$ intersects column $c'$ at $A_{r,c'}$. Any vertex set of size less than $L$ misses some entire row and some entire column, hence misses a cross. In any tree decomposition, the bags meeting each connected cross form a subtree, and these subtrees pairwise intersect. The Helly property for subtrees yields one bag hitting every cross, requiring at least $L$ vertices. A vertex ordering with frontier $w$ supplies a path decomposition with bags at most $w+1$, so $w\ge L-1$. Cell-major row-by-row ordering retains processed variables with future neighbors only in the first, previous, or current row, containing at most $9L$ names. This is a matching asymptotic structural upper bound.
\end{proof}
\section{Native resource firewall}
For the cyclic-scope class in the Library audit, a directly authenticated input can be decided by a width-four relation with at most 16 frontier assignments. Repeated source scans give a conservative fixed-$k$ read-only-input multitape implementation $T_k=O(nN\operatorname{polylog}N)$ and visited work space $S_k=O(\log N)$, including scope authentication. Conventional one-read/write-tape simulation has
\[
T_1=O(T_k(N+S_k+\log(T_k+2))),\quad P_1=O(N+S_k+\log(T_k+2)),
\]
counting the original input in $P_1$. For this explicit implementation, $T_1=O(nN^2\operatorname{polylog}N)$, $P_1=O(N)$. These are conservative one-way simulations, not tight FLMV/Williams exponent transfers. A universal TM must charge its interpreter separately.
The cyclic class admits a paid one-child constant-size YES/NO reduction because it is already explicitly decidable. On the grid family, frontier capacity is $2^{\Theta(L)}$, but actual feasible states can compress and all displayed instances are easy. No superpolynomial SAT time follows.
A virtual child's source-access recurrence $G_i\le a_i+q_iG_{i-1}$ must charge parent probes, address generation, ancestors, caching and failed attempts. A polynomial-length encoded descent rank need not have polynomial VALUE.
