For EVERY fixed correct total uniform FLMV-indexed general-CNF SAT decider A with guest time L^(t+o(1)) and writable peak L^(s+o(1)), a source-specific wrapper has

$$

Correctness: maintain the exact prefix frontier table M_(i-1)(a). Encode every forbidden a as the real CNF blocking clause D_a, false only on that a. For each outgoing b, call A on the literal CNF F_i AND all D_a AND pins (Z_i=b). The accepted label equals OR_a [M_(i-1)(a) AND SAT(F_i|a,b)]; the induction preserves a single compatible prefix witness. Empty forbidden predecessor emits a real empty clause. Source validation must finish before final output. No illegal branch-local proof reuse or R_mix341 extension is invoked.

Physical input: each virtual guest bit j selects among (a) O(log N)-bit generated CNF header, (b) the original block's contiguous bit span read from the immutable root input by a PAID indexed access, or (c) a physically retained encoded auxiliary blocker/pin suffix. Source blocks remain on the FLMV read-only original input and are never moved to writable work tape. Each indexed guest read pays length comparison, source or suffix index setup, index erasure and head restore, all polylog N native work and polylog scratch.

Reset of arbitrary guest work/index tapes is not an uncharged L^s scan. Use q epochs and physically store each guest work symbol with its O(log q)-bit epoch stamp, interpreting stale cells as blank. Indexed tape addresses are scaled by a polylog factor. For a guest index jump carrying J bits, readdressing costs O(J polylog N), amortized against the Omega(J) guest steps needed to construct the index since its previous mandatory erase. Thus the guest's worst-case native time incurs polylog overhead even if an indexed guest can reach space much larger than time. The fixed host has finitely many tapes; its index and high-water positions, stamps, descriptors and guest work all count toward peak. This is an outline of a native simulator, not a measured native execution.
