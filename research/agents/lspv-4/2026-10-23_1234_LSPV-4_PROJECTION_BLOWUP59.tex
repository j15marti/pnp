\section{Core exact theorem}
For each $p\ge1$, let $A=\{a_1,\ldots,a_p\}$ and $B=\{b_1,\ldots,b_p\}$. Introduce one mediator $u$ and source 2-CNF
\[
M_p=\bigwedge_{i=1}^p(\neg a_i\lor u)
\ \land\ \bigwedge_{j=1}^p(\neg u\lor\neg b_j).
\]
\begin{theorem}[PROVED/EXACT, output-model scope]
For all $p\ge1$ and all assignments $\alpha$ to $A\cup B$,
\[
\exists u\ M_p(\alpha,u)\ \iff\
P_p(\alpha)=\bigwedge_{i,j=1}^p(\neg a_i\lor\neg b_j).
\]
Any logically equivalent auxiliary-free CNF over precisely $A\cup B$, with clauses of arbitrary width, contains at least $p^2$ non-tautological clauses. The displayed $P_p$ attains the bound. The mediator source has only $2p$ clauses.
\end{theorem}
\begin{proof}
A true $a_i$ forces $u=1$, forcing all $b_j=0$; if all $a_i=0$, choose $u=0$. Thus the relation excludes precisely assignments with some true $a_i$ and some true $b_j$. For each pair $(i,j)$ define the forbidden assignment $\omega_{ij}$ with only $a_i=b_j=1$, all other $A,B$ values zero. Any non-tautological clause $C$ implied by $P_p$ must contain a negative $A$ literal, since otherwise one can falsify $C$ while setting all $A$ variables zero; similarly $C$ must contain a negative $B$ literal. If $C$ is false at $\omega_{ij}$, all its negative $A$ literals must be $\neg a_i$ and all its negative $B$ literals must be $\neg b_j$. Hence the same clause cannot be false at any different $\omega_{i'j'}$. All $p^2$ forbidden assignments must falsify a clause of an equivalent CNF, requiring at least $p^2$ clauses, regardless of width. The conjuncts of $P_p$ meet this lower bound.
\end{proof}

\section{Both-label ternary controls and exact ledger}
For each $x\in\{s,t,v,w\}$, force $x=0$ using binary $(\neg x\lor r_x)\land(\neg x\lor\neg r_x)$, with private free $r_x$. For each $z\in A\cup B$, add two private fillers $f_z,g_z$, functional helpers $h_{f_z},h_{g_z}$, ternary $(z\lor f_z\lor g_z)$, and binary equivalences $f_z\leftrightarrow h_{f_z}$ and $g_z\leftrightarrow h_{g_z}$ (two binary clauses each). Append ternaries
\[
D_A=(a_1\lor s\lor t),\qquad D_B^\lambda=(\lambda b_1\lor v\lor w),
\]
with $\lambda\in\{+1,-1\}$ denoting the sign of $b_1$. Call this $H_{p,\lambda}$. All binary and ternary clause supports are proper, there are no initial units or pure literals, and $\lambda$ flips just one signed-literal word with identical metadata. Exact counts:
\[
n=10p+9,\quad m_2=10p+8,\quad k=m_3=2p+2,\quad m=12p+10.
\]
With four fixed-width words per clause, two header words, and
$w=\lceil\log_2(64(n+m+1))\rceil$ bits per word, source length
$N=(2+4m)w=(48p+42)w=\Theta(p\log p)$ bits.

The genuine-ternary boundary $X$ has $6p+4$ variables ($A,B$, blockers and fillers). Exactly $4p+5$ variables ($u$, four blocker auxiliaries, and filler equality helpers) are eliminated by projecting the binary backbone. This projection is $P_p$ conjoined with four blocker units, while fillers are unrestricted. Fixing blockers and fillers to zero in any boundary-only equivalent CNF recovers $P_p$, so the $p^2$ lower bound remains valid for the complete boundary.

The blockers force $s=t=v=w=0$. Clause $D_A$ forces $a_1=1$; then the mediator forces $u=1$ and every $b_j=0$. Thus $H_{p,+1}$ is UNSAT and $H_{p,-1}$ is SAT. Exact source-model count for the SAT label is
\[
\#SAT(H_{p,-1})=64\cdot7^{p-1}\cdot3^p;
\]
the UNSAT count is zero. The source has a constant-size UNSAT contradiction core. A fully paid uniform source-template recognizer and source witness constructor run in $O(p)$ word operations, independently of auxiliary-free projection.
