\section{BUILD I: $q=0$ equality for every $b$}
For indices $i\in\mathbb Z_b$, take boundary $y_i$ and private $u_i,v_i$; put the following four clauses per index:
\[
\begin{array}{ll}
(y_i\lor u_i\lor\neg v_i),&
(\neg y_i\lor u_i\lor\neg v_{i-1}),\\
(y_i\lor\neg u_{i+1}\lor v_i),&
(\neg y_i\lor\neg u_{i+1}\lor v_{i-1}).
\end{array}
\]
All three variable families are disjoint, so clauses are proper even at $b=1$; in that case the four signed triples are distinct. Each $y_i$ has two occurrences of each polarity, each $u_i$ has two positive incidences at block $i$ and two negative at block $i-1$, and each $v_i$ has two of each sign. The source and the private graph after boundary deletion are connected. Every clause meets $Y$, so the unique module has exact minimum residual hitting size zero. Setting all $u_i=v_i=1$ satisfies every clause for every boundary assignment. Hence
\[
\boxed{n=3b,\quad m=4b,\quad k=1,\quad q=0,\quad R_Y=\mathrm{TRUE}.}

\section{BUILD II: $q=1$ equality for every $b$}
For each cyclic edge $(y_i,y_{i+1})$ create two separate modules, each with fresh private $w,u,v,z$. Each module has four internal clauses
\[
(w\lor u\lor\neg v),\
(\neg w\lor\neg u\lor v),\
(w\lor u\lor\neg z),\
(\neg w\lor\neg u\lor z),
\]
and two boundary clauses
\[
(\sigma_L(y_i)\lor v\lor\neg z),\qquad
(\sigma_R(y_{i+1})\lor\neg v\lor z).
\]
Choose the boundary occurrence signs in deterministic clause order so every boundary name occurs twice positively and twice negatively. Each name appears four times, two of each sign. Each connected private module has four internal clauses hit by $\{w\}$ but not the empty set; no clause contains private names from different modules. Even $b=1$ is valid: the two boundary occurrences within a module refer to the same $y_0$ but are in distinct clauses. Setting every private variable true satisfies all clauses for every boundary choice. Hence
\[
\boxed{n=9b,\quad m=12b,\quad k=2b,\quad q=1,\quad R_Y=\mathrm{TRUE}.}
\]
A module has $v_i=4$, $r_i=1$, two boundary incidences $a_i=2$, and zero hitting surplus. Thus it saturates $v_i\le3r_i+2a_i-3$ even though $k=2b<3b+1$; the missing quotient term is multiplied by $q-1=0$.
