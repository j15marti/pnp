\section{Per-jump indexed address theorem}
Use the deterministic FLMV indexed read-only-input multitape Turing model, with a finite fixed tape count and alphabet and an associated writable input-index tape. A native indexed move jumps to the binary address and \emph{atomically erases the index tape without resetting its head}. Index positions are physical binary cells with blank represented by zero. For $a\ge0$, let $\operatorname{wt}(a)$ denote the number of one-bits in the positional representation of $a$.

\begin{theorem}[Restricted one-indexed-jump-per-access policy]
For a computation that makes separate indexed moves to input addresses $a_1,\ldots,a_R$ and whose index tape starts blank, let $q$ be the fixed number of zero-to-one index-cell edits possible per native step. With all history charged,
\[
\boxed{W_{\rm index}\ge\sum_{j=1}^R\operatorname{wt}(a_j),\qquad
T\ge q^{-1}\sum_{j=1}^R\operatorname{wt}(a_j).}
\]
This is independent of the SAT/UNSAT label, but only applies to this exact access policy.
\end{theorem}
\begin{proof}
Each native indexed move erases its index tape. Immediately before the next move to $a_j$, the tape must contain the binary representation of $a_j$. Each of its $\operatorname{wt}(a_j)$ one-bit positions therefore requires a zero-to-one edit since the previous erasure. The preparation intervals are disjoint. Summing and dividing by the fixed maximum $q$ edits per step gives the result. Reads, index-head movement, guest operations and retries add further nonnegative time.
\end{proof}

\begin{proposition}[Consecutive source bits and XOR checkpoint granularity]
For an $H$-bit input header followed by $P$ payload bits, a schedule making one indexed move to \emph{every} payload position, in any order, requires
\[
W_{\rm index}\ge B(H+P)-B(H),\quad
B(X)=\sum_{h\ge0}\left[2^h\lfloor X/2^{h+1}\rfloor+
\max\{0,X\bmod2^{h+1}-2^h\}\right].
\]
For $H=O(\log P)$ this equals $\Theta(P\log P)$. For a step-separated actual implementation that writes only address one-bits then erases the index on jump, adjacent physical content XOR is exactly $D_{\rm fine}=2W$, yet the blank-to-blank endpoint XOR per request is $D_{\rm coarse}=0$.
\end{proposition}
\begin{proof}
In the interval $[0,X)$, binary digit $h$ is one on the latter half of each block of size $2^{h+1}$. Summing its full periods and remainder proves $B$. Each low-order digit occurs one on nearly half the addresses in any length-$P$ interval, giving the lower asymptotic bound, and there are at most $P\lceil\log_2(H+P+1)\rceil$ ones, giving the upper bound. In the declared step-separated microtrace, each created index one-bit later erases, contributing exactly two changed physical cells across native checkpoints. Empty index tapes at both endpoints give zero coarse distance. A solver that computes these XORs online must charge its own XOR-scanning work; our tracing is OFFLINE.
\end{proof}
