\section*{Definitions and exact theorem}
Let $x\in\{0,1\}^L$, $L\ge1$, and let $u_i=z_i$ for $x_i=1$, $u_i=\neg z_i$ otherwise. Define
\[
F_x=\bigwedge_{i=1}^L(u_i)\ \wedge\ 
\left(\bigvee_{i=1}^L\neg u_i\right).
\]
General CNF-SAT remains the ambient problem. The fixed $R_{\mathrm{mix341}}$ has free authenticated original clauses, binary RES, AND3, binary GF(2), checked conversions and charged conservative source-independent two-input VARDEF; every charged node has at most two named proof antecedents and cost one. No new macro or free semantic oracle is used.

\begin{theorem}[Global exact mixed minimum]
For every $L,x$, $F_x$ is minimally UNSAT, every individual literal-sign flip makes it SAT, and
\[
\boxed{W_{R_{\mathrm{mix341}}}(F_x)=L.}
\]
\end{theorem}
\begin{proof}
All units force a unique assignment falsifying the final blocking clause. Removing a unit allows its literal to be false and all others true; removing the blocking clause allows all units true. Flipping a unit sign is repaired by changing its variable; flipping a blocking-clause sign is repaired by the original all-units-true assignment. Thus all $m=L+1$ source clauses are indispensable. Every sound conservative binary-premise contradiction DAG must contain all $m$ sources in its connected ancestry. With $q$ paid vertices and $E$ antecedent edges, $m+q-1\le E\le2q$, so $q\ge m-1=L$. Resolving the long clause successively with the $L$ signed units supplies exactly $L$ genuine RES nodes. This minimum freely chooses the best derivation; no optimizer time is charged.
\end{proof}

\section*{One-pass delayed INDEX theorem}
The source-first model reads the complete canonical representation of $F_x$ once, then loses access to it. Only \emph{after} this pass an adversary supplies an index $i$ and a claimed sign bit $b$. The checker must accept exactly when the original named source sign $x_i$ equals $b$, for all $2^L$ valid signed sources and all legal $i,b$. This is a contract for exact \emph{source authentication}, not for merely announcing UNSAT.

\begin{theorem}[Tight retained-state information]
Any deterministic exact source-first delayed-index authenticator has at least $2^L$ distinguishable post-source configurations, thus at least $L$ bits of total retained configuration information. If it has $c$ fixed finite-control states and $h$ nonwritable head/index configurations, the writable state must contain $S\ge L-\log_2(ch)$ bits. Storing the $L$ source signs attains this bound up to counters and parser overhead.
\end{theorem}
\begin{proof}
For distinct $x,y$ choose $i$ with $x_i\ne y_i$. The same post-source state would respond identically to the same later query $(i,x_i)$, yet exact authentication requires acceptance after $F_x$ and rejection after $F_y$. Therefore the $2^L$ inputs require distinct retained configurations. Count these configurations.
\end{proof}

\noindent \textbf{Critical model firewall.} The ASCII DIMACS input length for this family is $N=\Theta(L\log(L+1))$, giving $\Omega(N/\log N)$ retained post-source information in the one-pass model. With indexed read-only input, a post-source query can instead reread the signed occurrence using $O(\log N)$ index bits, paying head/address/source-access steps. If the query is known before the pass, it also needs only logarithmic memory. The stronger conclusion is \emph{false} for ordinary SAT deciders, since every $F_x$ is an easily recognized UNSAT instance. A semantically sound refuter on this family need not authenticate an arbitrary later claim unless the proof-checker contract explicitly requires it. No FLMV contradiction follows.

\section*{Four falsifiers}
\begin{description}
\item[] F1: Can a conservative zero-proof-premise VARDEF beat $L$ inference nodes? No, the source-ancestry bound applies in the unchanged binary-premise calculus.
\item[] F2: Can a deterministic one-pass checker authenticate any delayed indexed sign after storing fewer than $L$ total bits? No, the $2^L$ post-source distinguishability proof excludes this.
\item[] F3: Does this force $L$ writable bits on an indexed-read-only machine? No. Rereads and indices change the source-acquisition model.
\item[] F4: Does an unvalidated certificate sign prove arbitrary CNF UNSAT? No. Only exact source-authenticated proof lines count; the SAT sign-flip neighbors and malformed controls enforce this distinction.
\end{description}
