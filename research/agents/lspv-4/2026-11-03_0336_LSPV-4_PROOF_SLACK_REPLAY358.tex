\section*{Statement}
Let a sound finite source-explicit refutation DAG have $s$ used distinct source clauses, $q$ positive-cost unit-weight inference nodes of indegree $k_v\le2$, one contradiction sink, and $E=\sum_v k_v$ authenticated dependency edges, with parallel edges counted. Retain only ancestry of the sink and put $V=s+q$, $\beta=E-V+1$ and $\delta=\sum_v(2-k_v)$.
\begin{theorem}[Source-cycle-slack and unfolding]
\[
\boxed{q=s-1+\beta+\delta,\quad 0\le\beta\le q-s+1.}
\]
In a clause-minimally UNSAT instance with $m$ indispensable distinct sources and sound conservative rules, $s=m$. If $U$ denotes nodes in the full tree unfolding (one node copy per directed path to the sink), and $L$ its source-leaf copies, then
\[
\boxed{V\le U\le V2^\beta,\qquad L\le s2^\beta.}
\]
A favorable evaluation order of this already-supplied unfolded tree uses at most $\lfloor\log_2 L\rfloor+1$ live value records if a consumed operand can be overwritten, or one extra record otherwise. At most $V2^\beta$ local inference checks are replayed.
\end{theorem}
\begin{proof}
The weakly connected ancestry multigraph has cycle rank $E-(V-1)$; substituting $E=2q-\delta$ proves the identity. Indispensable omitted sources would give a sound contradiction from satisfiable remaining clauses, impossible. Every nonsink vertex has positive number $d^+(v)$ of consumers and $\sum_{v\ne sink}(d^+(v)-1)=E-(V-1)=\beta$. Each directed path from a node to the sink chooses one outgoing edge at each relevant vertex, so the number of such paths is at most $\prod_{v\ne sink}d^+(v)\le2^{\sum_v(d^+(v)-1)}=2^\beta$. Summing copies proves $U$ and $L$. The binary expression-tree register recurrence is $r(leaf)=1$, $r(v)=\max(r(a),r(b))$ when unequal, otherwise $r(a)+1$. Induction using the leaf count gives $r(v)\le\lfloor\log_2 L_v\rfloor+1$; higher-register child first meets the value-record budget. Copied local justifications remain legal.
\end{proof}
\paragraph{Correct resource direction.}
For a minimally UNSAT source and a supplied proof with $q=m-1+e$, the bound $U\le(m+q)2^e$ is an \emph{upper} bound on recomputation when replaying that particular proof. It is not a lower bound on solving the formula or on $W_R$, and does not establish B3. If a record uses at most $B$ bits, live values use $O(B(\log s+\beta+2))$ bits under this favorable schedule. A paid source/proof-local check with work $C(P,B)$ makes the replay work $O(U C(P,B))$. Schedule acquisition, encoding (potentially $\Theta(U\log V)$ bits), indexed source reads, preprocessing, head movement, intermediate materialization and local scratch are additional real costs. No FLMV indexed-machine low-space implementation is established. Full-source writable materialization still forces all-phase $\rho\ge1$ in $s'\le\max\{\rho,\eta,\lambda,\lambda s\}$.
