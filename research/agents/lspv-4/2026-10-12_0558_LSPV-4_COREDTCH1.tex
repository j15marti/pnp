\section{Target and exact quantifiers}

Let \(\mathcal D\) be the total uniform deterministic exact SAT deciders on a
complete encoded-CNF domain.  The encoding contains a declared variable count
and the clause list; its bit length is \(N\).  For an encoded formula \(G\)
with declared source variables \(X\), write
\[
 H_G(\alpha)=1
 \quad\Longleftrightarrow\quad
 \exists x\succeq\alpha\ \exists z\;G(x,z)=1,
 \qquad \alpha\in\{0,1,\star\}^{X}.
\]
The attacked promotion was
\begin{equation}
\tag{ANHCO1}
\begin{split}
&K\text{ is polynomial-time recognizable and NP-hard, and}\\
&|\operatorname{MinBad}(H_G)|=2^{\Omega(m)}\text{ on infinitely many }G\in K
\\
&\hspace{18mm}\Longrightarrow
\text{every exact decider on }K\text{ exposes or pays for that frontier.}
\end{split}
\end{equation}
Here ``pays for'' means a charge causally attributable to evaluating,
materializing, extracting, reconstructing, communicating, or storing the
frontier, rather than the unrelated cost of deciding a retained hard source.
The theorem below falsifies (ANHCO1).  It does not assert that the NP-hard
image is easy.

\section{Construction}

For \(m\ge1\), target \(b\in\{0,1\}\), and layout
\(\rho\in\{\text{left},\text{balanced}\}\), let
\(P_{m,b}^{\rho}(X,Z)\) be the proper duplicate-free 3-CNF parity encoding
from MINFRONT1.  Every XOR gate \(z=a\oplus c\) uses
\[
(a\vee c\vee\neg z),\ (a\vee\neg c\vee z),\
(\neg a\vee c\vee z),\ (\neg a\vee\neg c\vee\neg z),
\]
and four proper clauses with two fresh padding variables force the final
output to \(b\).  The component has \(4m\) clauses and \(2m+1\) variables,
is satisfiable for both targets, and has primal treewidth at most two.

For any encoded 3-CNF \(F\) on \(m\) declared variables, rename the parity
variables above \(m\) and define
\[
 T_{b,\rho}(F)=F\ \wedge\ P_{m,b}^{\rho}.
\]
The component namespaces are disjoint.  Canonicalization fixes clause and
literal order.  The total declared-variable count is \(3m+1\), so a recognizer
recovers \(m=(V-1)/3\), validates either target/layout, and returns the
residual clauses over variables \(1,\ldots,m\).  Sorting gives
\(O(N\log N)\) time and \(O(N)\) workspace; on the canonical ordered image a
single scan suffices.  Duplicate clauses, clause order, and literal order may
be quotiented without semantic work.

\section{Exact detachable-frontier theorem}

\begin{theorem}[\texttt{DETACHABLE-FRONTIER-HARDENING1}]
For every \(m\ge1\), every encoded base \(F\), both targets \(b\), and both
layouts \(\rho\):
\begin{enumerate}[label=(\roman*),leftmargin=2em]
\item \(\SAT(T_{b,\rho}(F))=\SAT(F)\).  The map \(F\mapsto T_{b,\rho}(F)\)
is injective, polynomial-time computable, polynomially length-bounded, and
polynomial-time invertible on its image.  Hence if the base family is
many-one NP-hard---in particular if it is \(\Hsigned\)---the image family is
many-one NP-hard.
\item For partial assignments on the parity source variables,
\[
H_{T_{b,\rho}(F)}(\alpha)
=\SAT(F)\wedge
\left[
(\exists i\;\alpha_i=\star)
\ \vee\
(\alpha\in\{0,1\}^m\wedge\bigoplus_i\alpha_i=b)
\right].
\]
Consequently
\[
|\operatorname{MinBad}(H_{T_{b,\rho}(F)})|
=\begin{cases}
2^{m-1},&\SAT(F)=1,\\
1,&\SAT(F)=0,
\end{cases}
\]
where the unique obstruction in the second line is the empty partial
assignment.
\item For every \(A\in\mathcal D\), there is a total uniform exact decider
\(W_A\in\mathcal D\) such that
\[
 W_A(T_{b,\rho}(F))=A(F).
\]
If \(A\) takes time \(T_A\) and workspace \(S_A\), then the normalization
implementation takes
\[
O(N\log N)+T_A(|F|)\text{ time},\qquad O(N)+S_A(|F|)\text{ workspace}.
\]
On recognized image inputs it makes one child call and performs no evaluation,
materialization, extraction, reconstruction, or communication of \(H\) or
its frontier.
\end{enumerate}
\end{theorem}

\begin{proof}
The parity component is satisfiable and variable-disjoint, proving (i).
Canonical parsing returns exactly the base block, so injectivity and
invertibility are explicit.  Composing any reduction to the base family with
\(T_{b,\rho}\) proves image hardness.

For (ii), an extension of \(\alpha\) satisfies the conjunction exactly when
the base has a model and the parity source extends to target \(b\).  If one
source coordinate is free, choose the last free bit to set the parity.  If no
coordinate is free, compatibility is exactly the parity equation.  Thus, for
a satisfiable base, all and only the \(2^{m-1}\) full wrong-parity assignments
are minimal bad assignments.  For an unsatisfiable base the predicate is
identically zero, making the empty partial the unique minimal element.

For (iii), define \(W_A(G)\) to normalize and validate the isolated parity
component.  On success it runs \(A\) on the residual; on failure it runs
\(A(G)\).  Success is sound for every accepted input, not merely generated
ones, because deleting an isolated satisfiable conjunct preserves SAT.
Failure is correct by exactness of \(A\).  The displayed resource bounds
include reading, sorting, validation, residual construction, and the actual
child run.  The program never calls the compatibility evaluator.  \qed
\end{proof}

\begin{corollary}
\texttt{AMBIENT-NP-HARDNESS-TO-COMPONENT-OBLIGATION1} is \RETIRED.  Under
the counterfactual \(\SAT\in\mathsf P\), choose a polynomial \(A\); then
\(W_A\) is itself a polynomial exact decider avoiding the parity semantic
object.  Without that assumption, the same construction still shows that any
cost inherited from \(A(F)\) is a base-decision cost, not a charge for the
detachable frontier.
\end{corollary}

\section{What the theorem does and does not transfer}

This result is stronger than a recognizable easy-island counterexample: the
ambient image carries the full many-one hardness of the base.  It is weaker
than a full-domain avoiding algorithm.  It does not negate the cofinal
worst-case target
\[
\forall A\ \forall d\ \forall N_0\ \exists F\in\Hsigned:
T_A(F)>|F|^d,
\]
which COREEQUIV1 proves equivalent to \(P\ne NP\).  Nor does it show that
every hard family contains a removable component.  It closes only the proposed
repair ``make the semantic family NP-hard.''

The surviving bridge must make the charged object \emph{decision-entangled}:
after every allowed polynomial embedding, quotient, and satisfiable-component
deletion, removing or bypassing the object must change the decision on some
same-answer-controlled instance or yield a model-matched forbidden machine.
Stating that requirement is not a proof.  The required all-decider compiler,
same-execution charge, solver-exponent-independent contraction, and
unconditional endpoint remain \OPEN.

\paragraph{Natural Proofs.}
No large constructive circuit property or unrestricted circuit lower bound
is proved, so the Razborov--Rudich barrier is neither triggered nor escaped.

\paragraph{Nonuniformity and arbitrary exponents.}
The wrapper is uniform and inherits the child's unknown exponent unchanged.
It provides no fixed exponent contraction.  Any attempt to call the inherited
cost a parity-frontier lower bound would silently assume the missing causal
link.

\paragraph{\same.}
\(W_A\) is an explicit alternative decider.  This is sufficient to refute an
all-decider component obligation, but it proves no trace fact about the
original run of \(A(T(F))\).  Conversely, externally evaluating \(H\) is a
new execution and cannot be charged to either run.

\section{DUPLICATION / CONTRADICTION AUDIT}

MINFRONT1 already proved the exact parity frontier and its linear evaluator,
but correctly classified that family as an easy island.  QGUARD1 showed why
one easy island does not negate a full-domain worst-case statement.
COREEQUIV1 proved the signed-core worst-case time statement equivalent to
\(P\ne NP\).  The new contribution is orthogonal: it embeds MINFRONT1's
frontier as a removable satisfiable component of a polynomially recognizable
NP-hard image and constructs a total strip-and-delegate decider.  No prior
report located by the search proves this hard-host component-detachment
theorem.

There is no contradiction with QGUARD1 or COREEQUIV1.  The image decider may
still incur the full cost of \(A(F)\); the theorem denies only that this cost
was forced by the appended frontier.  HEVALLB1's uniform full compatibility
evaluator equivalence is also preserved: \(W_A\) does not evaluate the full
\(H\) table.
