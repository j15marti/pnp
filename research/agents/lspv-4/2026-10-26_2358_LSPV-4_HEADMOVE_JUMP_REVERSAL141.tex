\section{Machine and exact promise}
In model $M_J$ there is one two-way read-only input head,
fixed $k$ finite-alphabet sequential work tapes, and
a charged atomic input-head command that moves by at most $J(N)$ cells.
The destination address is chosen before its symbol is read.
No intervening input symbols are revealed by a jump.
Each write of an index or offset requires its actual binary bit operations;
all index and work cells are included in $S$.
$R$ counts changes of direction between nonzero input-head movements.
This differs from a multiple-input-head machine and from a random-access
work-memory RAT.

Consider fixed-layout input records with left bits $a\in\{0,1\}^m$,
a common fixed gap of $G=\Theta(N)$ physical bits,
and right bits $b\in\{0,1\}^m$. Decide
$\mathrm{DISJ}_m(a,b)=\bigwedge_i\neg(a_i\wedge b_i)$.
For $a$ arbitrary the pair $(a,\neg a)$ is a YES instance;
if $a\ne b$, at least one of $(a,\neg b)$ and $(b,\neg a)$ is NO.
The original W1 15-variable 20-clause signed exact-$(2,2)$ source
is reported to implement this predicate via opposite-sign switches
with model counts $(772,272,272,0)$. This report independently establishes
the \emph{abstract communication} theorem but does not claim a fresh
complete CNF compiler reconstruction.

\section{Jump-crossed-cut theorem and proof}
\begin{theorem}[Same-run jump--reversal tradeoff]
For every deterministic exact $M_J$ machine deciding all declared
$\mathrm{DISJ}_m$ promise inputs and for its simultaneous worst-input bounds
$T,S$, there is a single accepting pair $(a,\neg a)$ whose run satisfies
\[
 (R+1)B=\Omega(m),\qquad HJB=\Omega(Gm),\quad
 B=O_k(S+\log(N+T+2)+1),
\]
where $H\le T$ counts input-head movement commands.
Consequently
$TJ(S+\log(N+T+2)+1)=\Omega(N^2/\log N)$,
and any fixed polynomial exponent ceilings
$T\le N^{t+o(1)},S\le N^{s+o(1)},
J\le N^{j+o(1)},R+1\le N^{r+o(1)}$ require
\[
 \boxed{r+s\ge1,\quad t+s+j\ge2}.
\]
\end{theorem}
\begin{proof}
Fix a cut $c$ in the fixed middle gap.
For every $a\in\{0,1\}^m$ record the complete crossing transcript
of the accepted run on $(a,\neg a)$. Each record contains control,
crossing direction, all future-readable work cells and their head positions,
and (for jumps) the source and destination input coordinates.
This costs $O_k(S+\log(N+T+2)+1)$ bits because $k$ is fixed
and visited work-tape intervals are contiguous.
When a jump crosses a cut, conceptually split it into
target-selection, boundary communication, then destination-bit inspection.
The destination bit is never visible before the boundary communication.
Identical complete transcripts on two distinct accepted inputs would
permit deterministic splicing at $c$, accepting a mixed input
$(a,\neg b)$ or $(b,\neg a)$, one of which is a NO input.
Thus all $2^m$ transcripts are distinct.

By counting the finite-alphabet strings of bounded record width $B$,
the average length of these injective transcripts over uniform $a$
is $\Omega(m/B)$ at \emph{each} gap cut.
This is an average, not a per-cut maximum.
Sum over the $G$ cuts, then average over $a$,
to obtain a \emph{single} accepted pair $(a,\neg a)$ with
$\sum_c C_c(a)=\Omega(Gm/B)$.
A jump of length at most $J$ crosses at most $J$ gap cuts,
hence $HJ\ge\sum_c C_c(a)$ on this same run.
Some gap cut has $C_c(a)\ge \Omega(m/B)$ crossings,
and crossing directions of one fixed cut alternate.
Thus $R+1\ge C_c(a)$.
Finally substitute $N=\Theta(m\log m)$, $G=\Theta(N)$,
$H\le T$, and the polynomial ceiling assumptions.
For $B\ge\Omega(m)$ the reversal inequality is trivial;
the required traversal of the gap supplies the remaining
large-space boundary case.
\end{proof}

\section{Controls, native implications and numerical audit}
The one-head $J=N$ case permits near-linear head movement at
subpolynomial space, but still requires $R=N^{1-o(1)}$
on some YES input. Two independent read-only input heads
can move forward together, with $R=O(1)$ and polynomially bounded
near-linear time on the \emph{same promise}.
Indexed RAT likewise does not have this one-head position history.
The model's jump allowance must not be transferred to indexed
work-tape RAM without a separate simulation.
Native sequential-tape and FLMV/Williams/Buss--Williams
random-access exclusion regions are distinct.

A co-nondeterministic SAT verifier on this easy DISJ promise
guesses $i$, reads $a_i$ and $b_i$ in one forward input sweep,
and rejects iff both are $1$.
Every branch accepts when the instance is SAT; some branch rejects
when it is UNSAT. It uses $N^{1+o(1)}$ time,
$N^{o(1)}$ work space, and $O(1)$ reversals.
Thus the deterministic reversal theorem is not a coNTIME bound.

A conservative fixed-$k$ sequential multitape to one-tape simulator has
$T_1=O(T_k(N+S_k+\log(T_k+2)))$ and
$P_1=O(N+S_k+\log(T_k+2))$, including initial input in footprint.
Its exponent consequence $t_1\le t_k+\max(1,s_k)$
cannot be inverted into $t_k+s_k\ge2$.
The indexed FLMV machine instead charges binary-index writing;
a one-tape crossing theorem does not constrain an arbitrary RAT solver.

The standalone Python and JavaScript audits separately checked
43,435 fooling-set pairs, 5,460 exact DISJ truth-table pairs,
135 buffer/jump/input-size configurations, explicit headed travel
and reversals, one-bit-index writing, and a last-coordinate mismatch.
The Python run passed 59,395 assertions; the independent JavaScript
passed 58,408, both with zero failures.
At $m=128$ and $B=1$, $N=43,520$ in the abstract fixed-record layout:
$J=1$ produced 9,985,682 commanded movements and 254 reversals,
while $J=N$ produced 256 movements and 254 reversals.
These are counts for a specified \emph{abstract algorithm},
not FLMV timing benchmarks or a materialized exact-$(2,2)$ CNF.
