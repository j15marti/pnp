\section{Mandatory original-source indexed extremes}
Let $F=\bigwedge_{j=0}^{m-1}C_j$ be a proper three-CNF over original globally shared variables $x_1,\ldots,x_n$. For signed occurrence $x_{i,j}$, let $\nu_{ij}=0$ for literal $x_i$ and $1$ for $\neg x_i$. Its original-clause local all-three-literals-TRUE target $S_j$ requires $x_i=1\oplus\nu_{ij}$. Its all-three-literals-FALSE target $U_j$ requires $x_i=\nu_{ij}$. Inverting each occurrence value maps $S_j$ to $U_j$, and inverting the original $U_j$ returns $S_j$. Occurrence symbols are never separately assignable Boolean variables. Ordinary disjunctive clause SAT means $t_j\ge1$, not $t_j=3$.
For distinct original clauses $j,k$, the mode pair $SS$ (and $UU$) is globally coherent exactly when no common variable has opposite signs; $SU$ (and $US$) is coherent exactly when no common variable has equal signs. Sharing both kinds makes all four extreme pairs infeasible, yet both original disjunctions may be SAT via a middle literal count $1$ or $2$. Each named original pair and all four Boolean entries, with same/opposite-variable reasons, is stored in the raw JSON. Independent finite enumeration verified every pair mode; sampled triples were checked separately under one coherent global variable map.
At the two \emph{actually evaluated} complete assignments $0^n$ and $1^n$, and at every sampled intermediate global flip, the experiment stores the full original $t_j\in\{0,1,2,3\}$ vector, the four category counts $N_0,\ldots,N_3$ and the original source indices of SAT and UNSAT clauses. Under actual full complementation $\bar a$, $t_j(\bar a)=3-t_j(a)$ and $N_q(\bar a)=N_{3-q}(a)$; a selected global flip set $T$ changes a source count by the number of initially FALSE occurrences in $T$ minus the number initially TRUE there. Both endpoint failures never certify formula UNSAT.
\section{Explicit complement-orbit theorem and exact resource price}
\begin{theorem}[Optimal single-bit explicit quotient traversal, restricted model]
For every proper source three-CNF on $n\ge1$ original variables, choose exactly the $2^{n-1}$ coherent assignments with $x_n=0$ as representatives of the bitwise-complement orbits. Traverse these representatives by the $(n-1)$-bit binary-reflected Gray code $g(k)=k\oplus(k\!\gg\!1)$, $0\le k<2^{n-1}$. Maintaining all original $t_j$ and $N_0,\ldots,N_3$ with an occurrence index yields an exact complete SAT/UNSAT decider: a representative $a$ witnesses SAT iff $N_0(a)=0$, its complement witnesses SAT iff $N_3(a)=0$, and if neither holds on all representatives the formula is UNSAT. With maximum source occurrence degree $\Delta$, its indexed word-RAM work is $O(N+\Delta2^{n-1})$ and its untraced working storage is $O(N+n+m)$ words, where $N$ is the explicit source length. For strict signed exact-$(2+,2-)$ three-CNF every one-bit step changes exactly four original clause truth counters, so the complete UNSAT traversal performs precisely
\[\boxed{2^{n-1}-1\text{ coherent global flips},\qquad 4(2^{n-1}-1)\text{ affected-clause counter updates}.}\]
Among tasks required to visit all complement orbits by one-bit transitions and explicitly maintain each changing original $t_j$, this meets the minimum possible number of transitions and counter writes. This lower bound is \emph{only for the specified explicit path representation}, not for arbitrary SAT algorithms or for a symbolic aggregate compiler.
\end{theorem}
\begin{proof}
Every complement pair has exactly one member with $x_n=0$. Thus $g(0),\ldots,g(2^{n-1}-1)$ covers all pairs without repetition, and the reflected Gray property makes consecutive representatives differ in exactly one original variable. Each flip updates just its occurrences; strict22 supplies exactly four distinct original clauses per variable. At each representative the complement histogram is the reversed four-vector, so both orientations are decided without a second source scan. A failed complete traversal establishes $N_0(a)>0$ and $N_3(a)>0$ for every pair and is therefore an exhaustive UNSAT decision. Any explicit path visiting $2^{n-1}$ distinct representatives needs at least $2^{n-1}-1$ transitions. Each one-bit strict22 transition changes all four incident original $t_j$ values, so an explicitly updated per-clause counter array must perform at least four writes. The algorithm achieves both counts. This is a direct Gray-code application, not a new SAT lower bound.
\end{proof}
\begin{proposition}[Explicit output firewall]
A transcript explicitly writing the entire $m$-component source $t_j$ vector for each of the $2^{n-1}$ representative states requires $m2^{n-1}$ output fields, regardless of delta-computation costs. The full vector for both orientations requires $m2^n$ output fields. In contrast, a streamed reproducible traversal records the source formula and Gray counter with $O(N+n+m)$ live words, and a stored delta trace uses one flipped original variable index per transition plus a one-time indexed source table. Reconstructing the expanded full transcript necessarily repays its output cost. No inference about decision-time lower bounds follows when a solver is allowed to prune or compress computation.
\end{proposition}

\section{Peak space, acquisition cost and non-transfer barriers}
There are two separate space claims. The theoretical streamed Gray solver retains $O(n+m)$ indexed state words besides the read-only source and occurrence table, while the actual mandatory experiment also retains an explicit $4\binom m2$ four-way clause-pair matrix and all generated source target maps; that is quadratic in $m$ if retained densely, and prior SPARSE-EXTREME-SLACK244 already proved it can be replaced by an $O(n)$-record sparse representation for strict22. Storing each DPLL contradiction-leaf proof separately in the present Python implementation uses space proportional to the number of leaves times their assignment records; peak memory is not the abstract streamed solver bound. Parent-indexed DAG sharing avoids duplicating the original clauses but not the cost of discovering/checking derived clauses.
On the same W1 source, independently collected Python \texttt{tracemalloc} peaks were 60,536 bytes for the baseline DPLL proof-tree-producing run, 13,916 for minimal streamed quotient Gray, 151,266 for quotient Gray while retaining its dense source audit, and 214,237 for the eight-resolvent DPLL path while retaining the same audit. These are Python-tracked allocation snapshots, not maximum resident set size nor a Turing-machine space complexity measurement. The recorded code and raw work ledger make interpreter overhead, oracle work, branch failures and proof replay explicit. The 14-source complete finite battery passed 5,988 source pair-mode checks, 536 triple target modes, 336,688 complete coherent assignment/complement validations, and 92 replayed UNSAT DPLL contradiction leaves.
