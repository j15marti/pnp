\noindent\textbf{STATUS: PROVED/EXACT for the declared tagged two-dimensional DISJ promise; independent referee review pending.}
A deterministic machine with ONE two-way sequential read-only input head and exactly TWO sequential initially blank work tapes can recognize a separated disjointness family with \emph{zero} actual symbol changes, \(S=2\sqrt m+2\) visited work cells, and \(C=2m\) crossings of a fixed large input gap on its all-pairs-checked accepting runs. Consequently the previously proved no-change-epoch bound \(C=O_U((S+2)^k)\) is sharp in the exponent when \(k=2\), and the zero-write boundary \(d+2s\ge1\) is attained at \((d,s)=(0,1/2)\), up to the logarithm in the independent lower bound. This does \textbf{not} settle the WRITE-TIGHT2 interior frontier, and the example is a \emph{tagged easy promise}, not the canonical fixed-width signed exact-(2,2)-3CNF source. Ordinary SAT, ARC-EDGE-90 and \(P\ne NP\) remain \textbf{OPEN}.

\item[] \textbf{H3 (OPEN).} The same construction runs without additional bookkeeping on the \emph{canonical} fixed-width exact22 clause sequence. That sequence has no explicit row separators; a separate charged compiler, row locator, or authenticated comment/whitespace embedding is needed. No canonical-exact22 upper bound is claimed.
\item[] \textbf{H4 (falsified as transfer).} The zero-write crossing frontier is a lower bound on indexed random-access SAT or a proof that a polynomial-time SAT algorithm must change many work symbols. Indexed heads, a second input head, source-external certificates, or unrestricted SAT algorithms do not satisfy that inference.
\end{description}

\section{Exact finite-state model and tagged input}
Fix \(B\ge1\), \(m=B^2\), \(a,b\in\{0,1\}^m\). Let
\[
\operatorname{rows}_B(a)=a_{0,0}\cdots a_{0,B-1}\mid
 a_{1,0}\cdots a_{1,B-1}\mid\cdots\mid
 a_{B-1,0}\cdots a_{B-1,B-1}.
\]
The fixed-alphabet source is
\[
I_B(a,b)=\texttt{\^}\,\operatorname{rows}_B(a)\,
 \texttt{\#}\,\texttt{X}^{8m}\,\texttt{\#}\,
 \operatorname{rows}_B(b)\,\texttt{\$},\qquad
N=10m+2B+O(1)=\Theta(m).
\]
The source decision promise is \(\operatorname{DISJ}(a,b)\), so
\[
 \operatorname{YES}(I_B(a,b))\iff
 \bigwedge_{r,c<B}\neg(a_{r,c}\land b_{r,c}).
\]
Every diagonal \(I_B(a,\bar a)\) is YES and two distinct diagonals have at least one NO crossed input. The input has ONE moving read-only head, two ordinary \emph{sequential} work heads on initially blank semi-infinite tapes with detectable immutable left ends, a fixed finite-state controller, no output head, no advice, no other work storage. Count \(S\) as \emph{all visited blank work cells}, \(D\) actual symbol changes, \(T\) all finite transitions, \(H\) actual input moves, \(R\) input reversals, \(C\) crossings of a fixed cut inside the \(8m\)-symbol gap. A physical index in the host simulator is instrumentation of a head location, not an extra writable register of the simulated machine.

\begin{theorem}[Two-head blank-positional endpoint, restricted]
One fixed deterministic finite-state controller, independent of \(B\), decides this entire well-formed tagged promise, with
\[
D=W=0,\quad S\le2(B+1),\quad
T=O(mN),\quad H=O(mN),\quad R=O(m).
\]
On every complete accepting diagonal \(I_B(a,\bar a)\),
\[
S=2(B+1),\qquad C=2m=\Theta(S^2).
\]
\end{theorem}
\begin{proof}
The two blank work-head distances from their fixed left ends are a row index \(r\) and column index \(c\). To fetch \(a_{r,c}\), start at the Alice source marker; scan complete rows until the row head reaches home, moving that work head left once for each \texttt{|} row separator. Within the selected row move the column work head left once per bit, until it reaches home. The input head then reads the target bit, or encounters a row/block delimiter and reports an out-of-range coordinate. Reverse the \emph{same source traversal}, restoring the column head only over the selected row and the row head only over crossed row separators. The phases and the cached single Alice bit require only constant finite control, not a stored index. Return the input head to the unique source-start marker. Perform the same operation in the Bob block; if both bits are \(1\), reject. Otherwise advance the column work head one square. An out-of-range column resets that work head to its immutable home and advances the row head one square; an out-of-range row terminates and accepts. No work tape cell is ever changed. Source delimiters, not an uncharged integer \(B\), terminate all loops; there are at most \(m\) successful pair checks plus \(O(B)\) out-of-range checks. Each check and its inverse traversal use \(O(N+B)\) charged moves, yielding \(O(mN)\) transitions. During a full run each work head visits exactly coordinates \(0,\dots,B\), giving \(S=2(B+1)\). For each checked pair the input head passes the chosen middle cut once Alice-to-Bob and once Bob-to-Alice; all accepting diagonals check all \(m\) pairs, giving \(C=2m\). Work-head positions together with finite phase and the cached Alice bit are part of the complete crossing labels.
\end{proof}

\begin{theorem}[Matched lower exponent on this same promise; prior chronicle method]
For any \emph{globally sound on the tagged promise}, fixed-state deterministic one-input-head, two-blank-work-tape acceptor that accepts all diagonal YES inputs with \(D=0\) and a common visited-cell ceiling \(S\),
\[
 m\le O_U((S+2)^2\log(S+2)),\qquad
 S=\Omega\!\left(\sqrt{m/\log(m+2)}\right).
\]
\end{theorem}
\begin{proof}
At any fixed middle cut a full directed crossing label consists only of constant control/direction and two work-head positions, each from at most \(S+2\) possibilities. With no symbol changes, repeating a crossing configuration in a halting deterministic run would loop; hence at most \(O_U((S+2)^2)\) crossings are possible. There are at most \(2^{O_U((S+2)^2\log(S+2))}\) complete crossing histories. Distinct accepting YES diagonals need distinct histories by the standard left/right disjointness fooling argument: equal complete histories splice to an accepted NO crossing. There are \(2^m\) diagonals. This gives the inequality and the displayed lower bound. The proof uses the same mechanism already present in WRITE--TIGHT2, \emph{not} a new SAT theorem.
\end{proof}

\section{Native-model ledgers and falsification controls}
\noindent\textbf{Mk (native):} Here \(k=2\); the two \emph{head positions} are the only mutable memory. Charging nonblank cells instead of visited cells would falsely report \(S=0\), contradicting the legitimate endpoint. On the audited \(B=16,m=256\) accepting source, the observer recorded \(S=34,D=0,H=1{,}332{,}784,R=1{,}057,T=2{,}161{,}061\) and \(C=512\) at \(N=2{,}594\). Every head step and every source read is charged.

\noindent\textbf{M1 simulation (not a converse):} The conservative one-tape representation gives \(T_1=O(T_k(N+S_k+\log(T_k+2)))\) and \(P_1=O(N+S_k+\log(T_k+2))\), whence \(t_1\le t_k+\max(1,s_k)\), \(p_1\le\max(1,s_k)\) for polynomial ceilings. The initial input counts toward \(P_1\); \(S_k\) excludes it. The observed \((t_k,s_k)=(2,1/2)\) is consistent with an upper simulation \((t_1,p_1)\le(3,1)\); no one-tape lower bound has been reversed.

\noindent\textbf{Indexed RAM/RAT:} A log-word indexed machine reads paired source bits without physically crossing the gap each time and decides this EASY promise in near-linear time. FLMV, Williams and Buss--Williams have native indexed-work/input hypotheses, strict margins and specified determinism/polarity. In particular the \(2\cos(\pi/7)\) time exponent requires \(N^{o(1)}\) work, and \(P=NP\) would give an unknown polynomial exponent \(K\), not those bounds.

\noindent\textbf{COMPUTATIONAL.} Two genuinely independent simulators were built: a Python physical-head itinerary and a Node.js finite-controller reproducer. The published Node source exhaustively checks all \(4^m\) input pairs at \(B=1,2\) (260 pairs), all 512 \(B=3\) YES diagonal crossing histories and the 18 smaller diagonals (530 total unique crossing histories), 896 seeded additional pairs at \(B=3,4,8\), and 24 hostile endpoint runs for \(B=1,2,3,4,8,16\), with zero failures. On full runs the exact fixed-cut crossing count is \(2m\), actual writes and symbol changes remain \(0\), and total visited space is \(2(B+1)\).
