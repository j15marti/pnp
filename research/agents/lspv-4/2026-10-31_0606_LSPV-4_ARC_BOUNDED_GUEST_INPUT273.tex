\section{Restricted machine theorem}
Let $x$ be an \emph{ordinary} SAT input of actual encoded length $M$, already physically written onto an extra indexed work tape, with $M$ writable cells charged. Fix a deterministic total FLMV guest $A$ with finitely many tapes. Consider only input executions for which (i) the head of its \emph{input index tape} never moves beyond $h\le C\log(M+2)$, and (ii) all guest read-only input-head addresses remain in $[0,2M+O(1)]$. The latter excludes huge far-index jumps while allowing a bounded blank suffix. Count guest work and index tapes in $S_A(M)$; $T_A(M)$ includes all guest operations. The original source remains on the host's separate read-only input tape. Addresses and heads are not free objects.

\begin{theorem}[Bounded guest-input reentry, restricted]
Under these hypotheses, a fixed host FLMV multitape machine with one additional child-buffer work tape faithfully simulates the guest's indexed input jumps, index-tape erasure and preserved index-head position, ordinary input movements and blank reads, and arbitrarily many other fixed guest work/index tapes. With the child already materialized, it uses
\[
T_{\mathrm{sim}}(M)=O\!\left(T_A(M)\log(M+2)+M\right),\qquad
S_{\mathrm{sim}}(M)=O\!\left(S_A(M)+M+\log(M+2)\right).
\]
If the host must reset a previously used guest workspace before a new call, additionally charge $O(S_A(M)+M)$ time for full sequential clearing, without multiplying peak workspace by the number of \emph{sequential} calls. No claim is made for a guest with an unbounded input-index head.
\end{theorem}
\begin{proof}
Copy the $M$ literal child characters to one indexed host \emph{work} tape and charge every write and its $M$-cell spatial high-water mark. Emulate the guest input-index tape on an independent host work tape of $h+O(1)$ cells; maintain its current head coordinate, and store the guest input-head coordinate in $O(\log M)$ binary bits. A guest input-index cell edit or one-cell index-head move is copied to the corresponding host work cell and head. Upon an indexed input-head move, scan all $h+O(1)$ guest input-index cells, decode the address, clear those cells, restore the unchanged \emph{input-index head}, and set the guest input-head coordinate to the decoded address. The scan, erase and head restoration cost $O(h)$ physical host steps; no erasure or head movement is free. For input reads with address below $M$, write its binary address onto the host child-buffer index tape and perform one host indexed move and read. For addresses $\ge M$, return blank \emph{without} jumping the host work head into an unnecessarily distant blank region; the bound $2M+O(1)$ ensures logarithmic coordinate width. Ordinary guest input-head movements update that coordinate with binary carry and cost $O(h)$ steps. Thus a guest input action costs $O(h)$ host time. All other guest work tapes and their associated index tapes are mirrored on corresponding host tapes: an indexed jump erases the associated physical host index tape in precisely the guest's semantics. There are a fixed finite number of tapes because $A$ is fixed. Initial copying and final clearing cost at most $O(M+S_A(M))$ when needed; a sequential scan can clear the entire high-water visited region. The host's read-only \emph{original} source input tape remains available, but is not silently repurposed as a second read-only child tape. Accumulating these charged operations gives the stated bounds. Each simulated transition preserves the guest configuration, so all accepting and rejecting results are unchanged. \qed
\end{proof}

\paragraph{Necessary machine qualification.}
The FLMV output tape is one-way write-only and uncharged in space. Writing a child to it does \emph{not} make those bytes a readable guest input. The physical-buffer proof \emph{does} charge $M$ counted work-tape cells. Output-only emission and readable child storage are distinct resources. A source-backed virtual accessor could avoid the buffer, but would require a separate fully charged indexed-input simulation theorem; the present proof does not silently provide one.

\section{Correctness-preserving wrapper that defeats the bounded hypothesis}
For \emph{any} fixed exact total SAT decider $A$, define $B_A$ on an $M$-byte ordinary input: move the guest input-index tape head $M$ cells, write a single one-bit there, perform an indexed input jump to address $2^M$, read the blank symbol, clear the index tape via the jump, move the index head back to its initial coordinate, then run $A$ on the \emph{unchanged} source, restoring the original input head as needed. The jump erases contents but does not move the index-tape head. This wrapper is total and returns the same answer as $A$ for every SAT and UNSAT input. It costs $O(M)$ extra time and has $S_{B_A}(M)\ge M$ index-tape high-water usage, hence remains a polynomial-time correct SAT decider whenever $A$ is. In particular the logarithmic input-index-head premise is \emph{not hereditary under arbitrary correct SAT wrappers}. The example \emph{does not} prove that every compiler must simulate these dummy operations rather than optimize them away.
