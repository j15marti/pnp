\begin{abstract}
We refine the project's full-port signature floor to an \emph{online continuation interface}: a family of connected proper 3CNF sources is uniformly satisfiable, but $t$ individually available, four-variable context tests recover its $t$ independent sign bits. A source-free deterministic summary that answers any context supplied \emph{after} preprocessing requires at least $t$ bits of retained information on some source, regardless of how the summary is computed. On a fixed finite-alphabet, fixed-head polynomial-time machine this implies $\Omega(t)$ visited writable cells after the original source becomes inaccessible. A source-present machine instead answers each context in polynomial time and $O(\log N)$ auxiliary space, because the $N=\Theta(t\log t)$-bit source remains physically accessible. The lower bound concerns a particular online contextual interface, not decision-only SAT, exact-$(2,2)$ formulas, unrestricted SAT runtime, or $P$ versus $NP$.
\end{abstract}

\section{PROPOSE: four falsifiable alternatives}
\begin{description}
\item[]\textbf{M1: Few queried pins might defeat full-port counting.} Restrict future contexts to only four forced variables, then test whether the $2^t$ source signatures remain distinguishable.
\item[]\textbf{M2: A constant-size child plus a source pointer might evade retained-information cost.} Test with and without access to the original source, charging physical source size and readback travel separately.
\item[]\textbf{M3: Full relation construction might be necessary to answer a context.} Seek an explicit source-scanning strategy using only the sign queried, showing that the family is easy even though it has an information floor.
\item[]\textbf{M4: Head positions might secretly retain arbitrarily many bits.} Count fixed-machine head positions and finite control in the post-preprocessing configuration, and state the exact runtime assumption required for a writable-cell bound.
\end{description}

\section{BUILD: a constant-touch online continuation lower bound}
For $t\ge1$, let $s=(s_1,\ldots,s_t)\in\{0,1\}^t$ and take shared variable $z$ and private variables $a_i,b_i,c_i,d_i$. The notation $(a_i\oplus s_i)$ denotes the literal $a_i$ when $s_i=0$ and $\neg a_i$ when $s_i=1$. Define
\begin{equation}\label{eq:family}
 F_{t,s}=\bigwedge_{i=1}^{t}
 \left(z\vee(a_i\oplus s_i)\vee b_i\right)
 \land\bigwedge_{i=1}^{t}
 \left(\neg z\vee c_i\vee d_i\right).
\end{equation}
There are exactly $2t$ proper width-three clauses, $4t+1$ variables, and a connected incidence graph. A canonical unpadded fixed-width index encoding (using $\lceil\log_2(4t+2)\rceil$ bits per identifier) has $N_t=\Theta(t\log(t+2))$, with all $2^t$ signed encodings of equal length. The independent Python audit also uses an equivalent variable-width textual encoding for some tests; no Python operation count is treated as a TM bound. Each $F_{t,s}$ is SAT, for instance by choosing $z=0$ and all $b_i=1$.

\begin{theorem}[Four-pin INDEX continuation]\label{th:index}
For every $i\in[t]$, let $Q_i$ be the conjunction of only four literal constraints
\[
 Q_i=(\neg a_i)\land(\neg b_i)\land(\neg c_1)\land(\neg d_1).
\]
Then for every $s$ and $i$,
\[
 \boxed{\operatorname{SAT}(F_{t,s}\land Q_i)\iff s_i=1.}
\]
Consequently, any deterministic offline preprocessor that sees $F_{t,s}$, discards access to its source, and retains a state from which one fixed decoder must correctly answer an adversarially chosen $Q_i$ needs at least $2^t$ distinguishable post-processing states. If states are encoded as arbitrary binary strings, their maximum length is at least $t$ bits. This remains true for nonlinear, source-adaptive representations and for a decoder of unrestricted running time.
\end{theorem}
\begin{proof}
The pinned $c_1=d_1=0$ falsify the first right clause if $z=1$, so any satisfying assignment must have $z=0$. The $i$th left clause becomes $(a_i\oplus s_i)\lor b_i=s_i$, because $a_i=b_i=0$. If $s_i=0$ this clause is false, proving UNSAT. If $s_i=1$, choose $z=0$, $b_j=1$ for all $j\ne i$, and otherwise satisfy the four pins. This satisfies all left clauses; every right clause is satisfied because $\neg z=1$. Thus the answer equals the $i$th bit of $s$.

If two different sign strings $s,s'$ produced the same postprocessing state, choose any coordinate $i$ where they differ and provide the \emph{same} query $Q_i$. The decoder would have to output both $s_i$ and $s'_i$ from identical inputs and state, impossible. Therefore the map $s\mapsto\text{state}$ is injective on $2^t$ inputs. Only $2^t-1$ binary strings have length at most $t-1$, giving the stated bound.
\end{proof}

\begin{lemma}[Proper-3CNF context compiler]
Each of the four pinned unit literals can be replaced by four proper 3CNF clauses with two fresh variables. For a required literal $\ell$, use
\[
 (\ell\vee u\vee v)\land(\ell\vee u\vee\neg v)\land
 (\ell\vee\neg u\vee v)\land(\ell\vee\neg u\vee\neg v).
\]
Their conjunction is satisfiable exactly when $\ell$ is true, independently of $u,v$. Thus each $Q_i$ has a 16-clause, eight-auxiliary proper-3CNF compilation; with ordinary variable indices its complete description uses $O(\log(t+2))$ bits when the shared $t$ and canonical naming grammar are fixed.
\end{lemma}
\begin{proof}
When $\ell$ is true all four clauses hold. If $\ell$ is false, every assignment to $u,v$ falsifies one of the four clauses. The fresh variables ensure each clause contains three distinct names. The four context variables are also distinct for every $t\ge1$.
\end{proof}

\section{Physical resource ledgers and source-replay firewall}
The information theorem counts all data accessible after the preprocessing phase. For a fixed finite alphabet and fixed $k$ machine heads, suppose $S$ writable cells remain accessible and the preprocessing finishes by time $T$ on an initial source of length $N_t$. The number of possible machine configurations is bounded by $2^{O(S)}(N_t+T+2)^{O(k)}$ when no source signs remain externally accessible. Therefore
\begin{equation}\label{eq:config}
\boxed{t\le C S+C'k\log_2(N_t+T+2)}
\end{equation}
for machine-dependent positive constants $C,C'$. At fixed $k$ and polynomial $T$, this forces $S=\Omega(t)$ on some source. It is a post-source online-memory lower bound, not a general SAT running-time bound. If the original read-only source remains readable, \eqref{eq:config} cannot be applied with that source omitted from accessible information.

The source-present readback is trivial: scan the canonical formula to clause $2i-1$ and inspect the sign on $a_i$. It does not require constructing all projected truth values. A source-free implementation can retain the $t$-bit sign string and attain the information lower bound; it is still polynomial. With $h$ future queries, charge $h$ replays, tape travel, parsing and any retained source pointer. All answer classes are processed by one fixed decoder: $s_i=1$ is SAT and $s_i=0$ is UNSAT for the contextual instance, although the \emph{unaugmented} source is always SAT.
