## Exact theorem: rank k, minimum k+1 complete trace classes

Let $F_d$, $d\in\{0,1\}^k$, be the strict-three original-source guarded K4 selector from LSPV-2/516. Four disjoint literal-sign positions encode each bit $d_j$. The zero descriptor is UNSAT, every nonzero descriptor is SAT. Let $K_A$ be the number of equivalence classes of **completed observed INPUT-value traces plus correct observable decision** of a single deterministic total correct SAT guest $A$, restricted to these $2^k$ physical original binary sources; non-input initial state and code are fixed.

**PROVED/RESTRICTED:** For every such $A$, $K_A\ge k+1$. To distinguish $F_0$ from $F_{e_j}$, a correct deterministic guest must read at least one of the four physical sign positions controlled by $j$, since all other input symbols are identical. If completed traces on $F_{e_i}$ and $F_{e_j}$ were identical for $i\ne j$, the value read at the position witnessing $j$ or $i$ would differ, contradiction. The zero transcript also differs from each singleton's by correctness. Thus the $k+1$ sources $\{F_0,F_{e_1},\ldots,F_{e_k}\}$ lie in distinct complete-trace classes. This is a source-observation/decision-tree bound, NOT a time lower bound against all SAT algorithms or a lower bound on fresh guest calls when alternative certified methods are permitted.

**PROVED/RESTRICTED (attainment):** There exists a fixed sound fastpath which, on every structurally authenticated member of the *larger* signed-template language (all $4k$ tag signs independently variable), accepts SAT at the **first positive pin literal** and returns UNSAT iff all $4k$ tag literals are negative. Indeed, for a pin clause group containing all four binary combinations $(a\vee b)$, $(a\vee\neg b)$, $(\neg a\vee b)$, $(\neg a\vee\neg b)$ with independently signed guard literals, $g_j=1$ is feasible iff some guard literal is positive; $g_j=0$ is feasible iff some guard literal is negative. Hence all pins force guard output zero exactly when all $4k$ signs are negative. The guarded odd K4 contradiction is UNSAT at guard zero and all its clauses are satisfiable at guard one (choose each fresh split variable $h=0$). This establishes classification for all $2^{4k}$ sign patterns, not only promised descriptors.

To authenticate the larger language without destroying the claimed trace partition, parse the unary length header, compute its canonical fixed header/ID/clause layout, compare every invariant bit, skip all tag-sign positions using indexed INPUT jumps, and check the predicted end marker/blank. A malformed or off-template source invokes a fully charged *correct generic SAT-decider fallback* after cleanup. Exhaustive fallback exists unconditionally but is exponential in worst case; substituting a hypothetical polynomial SAT decider yields a global polynomial wrapper only CONDITIONALLY on SAT in P. For an accepted template, the auth observations are identical on all descriptor-consistent $F_d$. On $F_d$, a zero group contributes four negative reads, while the first positive group contributes one positive read and halts. Exactly $k+1$ distinct completed trace classes result. The alternative sound wrapper always reads all $4k$ signs before deciding and has exactly $2^k$ completed classes on the same descriptor-consistent inputs.

Thus $K_{\min}=k+1$ under this model of full observed transcripts and arbitrary total correct deterministic guests. The shared-data resource implications are sharp: an explicit shortcircuit trie has $k$ TEST nodes and $k+1$ output leaves, $O(k\log k)$ representation bits; a full scanner has $2^k-1$ TEST nodes and $2^k$ leaves, $\Theta(k2^k)$ explicitly stored address/edge bits. This says nothing about minimum underlying computational work of a better non-trie algorithm. In particular, full read rank $k$ on $F_0$ [P2-L2-516] is compatible with only $k+1$ total trace classes. Rank alone is not a lower bound of $2^k$ distinct executions.

## Exact encoding, source family, native-resource ledger

K4 has 6 edge variables, 16 original signed proper three-literal Tseitin clauses, one odd-charge vertex; the selector gadget has 4 pin ternaries per coordinate, 5 proper ternaries per OR gate, and 2 proper ternaries per split/guarded core clause. For $k\ge1$:
$$
n(k)=19+6k,\qquad m(k)=27+9k,\qquad
w=\lceil\log_2(n(k)+1)\rceil,
$$
$$
M(k)=8+n(k)+1+3m(k)(w+1)+2=\Theta(k\log k).
$$
The 8-bit magic is 10110110; the source is unary $1^n0$ followed by ordered literal ID/sign records and terminal 01. Exactly four independent sign positions per descriptor bit toggle. On every fixed-source template all other bits are authenticated, so the packet is original strict-three CNF, not an unconstrained promise.

For all $q=2^k$ descriptors, the sound short-circuit fastpath makes exactly $5q-5$ **tag-sign reads** in aggregate; the full-scanning fastpath makes $4kq$ tag-sign reads. Both exclude the $O(qM)$ invariant-position validation reads if each child is independently started and checked, and exclude all indexing/conversion/output costs. For $k=10$, $q=1024$, packet length 2898, exact trace classes are 11 versus 1024 and tag-sign reads 5115 versus 40960. Authenticated source construction/checking remains $O(M\,\mathrm{polylog}\,M)$ *candidate* time and $O(\log M)$ supplemental local WORK for the specified indexed syntax checker, with concrete native instruction-level replay not established. The fallback has time $T_A(M)$ and peak space $S_A(M)$ and may dominate ALL-input worst-case. No global time or space contraction follows.

**Physical cost firewall:** At every stage separately charge unary parsing and invalid-header rejection, source INPUT/INDEX/head operations, index writing/erasure and clipping, source-to-child bit translation, output, guest WORK/INDEX/OUTPUT simulation, cache basis and pointer bits, construction of the first and subsequent trace class, failed searches, verification, snapshots, ancestor-child coexistence, reset, retrieval and recomputation. $K$ is a distinct-trace count, **not** the number of unavoidably paid executions or a lower bound on computation. All-phase temporary high-water, rather than final resident bytes, controls FLMV WORK space. If a compiler materializes all $q$ children its output and scratch can cost $\Omega(qM)$; a cache of full guest states rather than finite labels may cost $\Omega(K S_A(M))$ space if simultaneously retained. If each input is validated independently, source-authentication work is $\Omega(qM)$ before any cache savings; cross-child shared authentication is a separate legal candidate that must be constructed and charged.

**Family/theorem/encoding/known-shortcut/transfer ledger:** Finite K4 selector is an exact correctness and resource-control family, not certified asymptotic hard. Urquhart's expander Tseitin family gives exponential **ordinary shared-DAG Resolution** lower bounds for suitable expanding cubic graphs; that lower bound does not automatically survive guard/pin existential variables nor apply to Cook ER, GF(2), historical mixed R_mix341, or arbitrary algorithms. Standard Gaussian elimination on the charge equations and native local source authentication are legitimate strong shortcut controls. Replacing K4 by a published expander family requires separate lower-bound-preservation or simulation proof with explicit bit overhead before calling the transformed family proof-hard. Existing FLMV lower bound applies to its native random-access machine, not a zero-cost RAM. Neither this trace optimum nor finite experiments supplies [P2-A2] all-input contraction, [P2-A4] full physical resource accounting, or [P2-A5] recursion.
