\section{Declared event encoding and padding operation}
A valid scoped proper-three-CNF stream has events
$\mathrm{OPEN}(v)$, $\mathrm{CLAUSE}(\ell_1,\ell_2,\ell_3)$,
$\mathrm{CLOSE}(v)$, with consecutively increasing fresh
OPEN identifiers, no repeated variable in a clause, every clause
referencing active identifiers, and all variables closed at the
end. Let $n$ be the opened-variable count, $m$ the clause count,
$w$ the maximum live-variable count and
\[
 h(n,m)=\left\lceil\log_2(64(n+m+1))\right\rceil,\qquad
 L(n,m)=(2+4n+4m)h(n,m).
 \tag{1}
\]
The encoding has two header words, two words for each OPEN/CLOSE
event, four words per CLAUSE event. Signed literal records and
event tags occupy one $h(n,m)$-bit word each. Input is read-only,
work and index tapes writable and counted; output is write-only
unless an ordinary readable child is explicitly materialized.
This declared encoding is a test model, not an automatic equivalence
to the exact FLMV machine.

Let $E$ be a \emph{valid closed} stream of length $L(E)$, and
let $B\ge L(E)$ be a target lower length. Appending one
\emph{fresh isolated block} means
\[
 \mathrm{OPEN}(a),\mathrm{OPEN}(b),\mathrm{OPEN}(c),\quad
 \mathrm{CLAUSE}(a,b,c),\quad
 \mathrm{CLOSE}(c),\mathrm{CLOSE}(b),\mathrm{CLOSE}(a).
 \tag{2}
\]
Identifiers $a,b,c$ are the next three unused consecutive
positive integers. The single positive proper ternary clause has
seven satisfying assignments over its three variables.
The block has three live variables and does not share any
variable with preceding events. For $g\ge0$ let $E\oplus g$
denote $g$ appended blocks. The $g$ blocks are not free
variables: they are independent, satisfiable, and collectively
have $7^g$ assignments.
\begin{theorem}[Charged scoped length floor; PROVED/EXACT restricted]
For every valid closed stream $E$ and every integer $B\ge L(E)$,
there is a uniform deterministic padding operation, not supplied
the SAT label, returning a valid closed stream $E'$ such that
\[
 \begin{split}
 \mathrm{SAT}(E')&=\mathrm{SAT}(E),\\
 \#\mathrm{SAT}(E')&=7^g\,\#\mathrm{SAT}(E),\\
 n'&=n+3g,\qquad m'=m+g,\qquad
 w'\le\max\{w,3\},\\
 B&\le L(E')\le 2B+O(\log(B+2)).
 \end{split}\tag{3}
\]
Any feasible assignment to an original shared boundary extends
through the appended blocks, and every satisfying extension
projects to an original witness. Given certified valid input,
a sequential implementation takes
$O((L(E)+B)\operatorname{polylog}(B+2))$ elementary bit work,
$O(\log(B+2))$ writable controller bits \emph{besides}
any required source-validity checker, ancestor state, or
readable child buffer. A full readable child requires
$\Theta(L(E'))$ additional live bits, including headers.
\end{theorem}
\begin{proof}
Define $f(g)=L(n+3g,m+g)$. It strictly increases, and
$f(g)\rightarrow\infty$. Compute the least $g\ge0$ for
which $f(g)\ge B$, by doubling and binary search on
integers with $O(\log B)$ bits. The event sequence (2)
preserves source validity, closes its own variables and
changes maximum live width only as displayed. The new
source is a conjunction with $g$ independent
proper ternary clauses, proving the SAT, model-count
and boundary-projection identities without a SAT
decision.

For $g>0$, write $A=2+4n+4m$, $h=h(n+3(g-1),m+g-1)$ and
$A_-=A+16(g-1)$. Minimality gives $A_-h<B$; one more
block increases the record count by sixteen and the
word width by at most one, so
\[
 f(g)\le(A_-+16)(h+1)
 < B+B/h+16h+16
 \le 2B+O(\log(B+2)).
\]
(The final inequality follows from
$h=O(\log(B+2))$ for the preceding stream.)
The $g=0$ case has $L(E)\le B$, hence equality. Sequential
copying and emission write $O(B)$ output bits, with
charged addressing, control and unchanged-value writes.
The integer search requires polynomially many elementary
operations in $\log B$. The controller stores counters
and widths but no output bitstring. An eager ordinary
child buffer, if chosen, separately stores all output bits.
\end{proof}

\section{Exact fixed-depth eligibility repair, with an essential scope}
\begin{theorem}[Conditional inherited-width repair; PROVED/EXACT as an implication]
Fix constants $0<\lambda<1$ and integer depth $r\ge1$.
Suppose a \emph{source-correct} scoped child factory already
generates at most $N_j^{a+o(1)}$ children at level $j$,
each valid and closed, of encoded length
$L\le N_j^{\lambda+o(1)}$, and with live width
$w_{j+1}\le w_j+C$ for constant $C$.
Apply the preceding padding with $B_j=\lceil N_j^\lambda\rceil$,
using a minor asymptotic slack to accommodate the factory's
$o(1)$ size factor. The resulting levels satisfy
\[
 N_{j+1}=N_j^{\lambda+o(1)}\ \text{with both an
 upper and a lower bound},\qquad
 \log N_j=(\lambda^j+o(1))\log N_0.\tag{4}
\]
If $w_0=o(\log N_0)$, then $w_j=o(\log N_j)$
for all fixed $j\le r$.
For a fixed-ratio promise $w_j\le c\log N_j$, a
sufficient stronger root condition is
$w_0\le(c\lambda^r-\epsilon)\log N_0-Cr$
for fixed positive slack $\epsilon$.
\end{theorem}
\begin{proof}
Equation (3) gives a two-sided polynomial scale,
and induction gives (4). The assumed width growth
implies $w_j\le w_0+Cj$. Divide this by
$(\lambda^j+o(1))\log N_0$ and use fixed $r$.
The fixed-ratio case follows with the displayed margin.
\end{proof}
\noindent\textbf{Scope guard.}
If a factory guarantees only $L\le N_j^{\lambda+o(1)}$
rather than $L\le N_j^\lambda$, take
$B_j=N_j^{\lambda+\epsilon_j}$ with
$\epsilon_j\to0$ chosen to dominate that upper-bound
error, or use $B_j=\max\{\lceil N_j^\lambda\rceil,L\}$.
This is a conditional repair of a \emph{given} correct
factory. It is neither the missing arbitrary-input
normalizer nor a proof that the unrecovered
HEREDITARY-SCOPED10 code already has that width property.
It assumes the original child outputs are legitimate
closed scoped streams, not arbitrary virtual handles.

\[
 \mathbf R=(U,R_{\rm source},R_{\rm work},W_{\rm work},
 \Delta_{\rm state},S_{\rm peak},BT,|P|),\qquad
 BT=\sum_{\text{charged step }i}S_{\rm live}(i).
 \tag{5}
\]
Here $U$ is primitive bit work; unchanged-value writes
remain in $W_{\rm work}$; $\Delta_{\rm state}$ counts
actual complete-machine bit flips, not active circuit
gates or merely the number of one-bits in an output.

binary search, re-encoding wider signed records,
source rereads, generated pins/auxiliary variables,
boundary compatibility, caching, DAG reuse, ancestors,
and exact witness replay when demanded by the algorithm.

Let a \emph{separate} all-input source-correct contractor
use $Q\le N^{a+o(1)}$ children of size
$B=N^{\lambda+o(1)}$, and let a fixed source solver
have simultaneous pair $(t,s)$.
The eager-output schedule has the \emph{conditional}
same-machine exponent bounds
\[
 t'\le\max\{r_{\rm semantic},\,a+\lambda,\,
                  a+\lambda t\},\qquad
 s'\le\max\{\sigma_{\rm semantic},\,\lambda,\,
                  \lambda s\}. \tag{6}
\]
The symbols $r_{\rm semantic},\sigma_{\rm semantic}$
cover source acquisition, selection, failed calls,
parent-child gluing, caches, buffers and ancestors.
The equation is a resource ledger, not an achieved
transition of $E$.
At $a=3/5,\lambda=1/2$ and $t\ge1$, it reduces to
$t'\le\max\{r_{\rm semantic},\,3/5+t/2\}$,
$s'\le\max\{\sigma_{\rm semantic},1/2,s/2\}$;
using a more conservative independent source-scan
and header budget yields the previously advertised
$\max\{1.1,0.6+t/2\}$ time cap. A padded child
cannot magically remove an original root-scale
hard continuation. One-bit decision might avoid
building all children, so output-cost lower bounds
apply only to policies that really emit them.
