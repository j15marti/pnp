\section{Declared ordinary representation and exact virtual bit theorem}
For a fixed-slot ordinary 3CNF subgrammar, encode eight-bit slot width $w$, then $w$-bit bounds $n,m$, then $m$ records of $B=2+3w$ bits: a two-bit arity and three signed $w$-bit literal positions, padded by zero slots. An adequate, not necessarily minimum $w$ is allowed so restriction retains exactly the same width; malformed strings are rejected. Let $H=8+2w$, $N=H+mB$, $w=\Theta(\log N)$. This declaration does \emph{not} identify arbitrary binary SAT encodings with this grammar.

\begin{theorem}[Bounded-edit exact accessor]
For an ordinary source of maximum occurrence degree $\Delta$, assigning $d$ distinct variables affects at most $q=\Delta d$ original clauses. The exact restricted formula can be presented as an ordinary fixed-slot encoded child of length $L=H+(m-z)B$, where $z\le q$ clauses were deleted. Its random-access bits can be produced from the indexed read-only root with $O(q\log N)$ writable/index bits, $O(q\,\operatorname{polylog}N)$ bit work per requested child bit, and an $O(N\operatorname{polylog}N)$ initial charged scan. In particular $L\ge N-qB$. No child string needs to be materialized. The semantics of full binary restriction are exact on SAT and UNSAT.
\end{theorem}
\begin{proof}
Scan source clause records in order with one $O(B)$-bit working register. For each clause touched by a chosen variable, store its original ordinal. A satisfied clause is a deletion ordinal; an unsatisfied touched clause is represented by its altered arity and literal record after deleting false assigned literals. Keep the sorted deletion ordinals and edited records; only $q$ can exist. A requested child bit in the header is computed directly. For a body bit, recover its child record ordinal and record offset; walk the sorted deletion ordinals to find its corresponding original record ordinal. Return the stored edited record bit if present and the indexed read-only parent bit otherwise. This implements literal restriction in exactly the original clause order. The record and ordinal tables occupy $O(q(\log m+B))$ bits. All source reads, unchanged and changed workspace writes, index/control arithmetic and retained tables are included in the stated upper bounds. The read-only parent is not counted as writable memory. Exactly $z$ full records are removed, giving $L=N-zB$. The Shannon identity $\SAT(F)=\SAT(F|_{x=0})\vee\SAT(F|_{x=1})$ proves exactness at two levels, independently of the adaptive pivot choice.
\end{proof}

\section{The decisive length and same-machine ledger}
In the strict M22 source grammar each original variable occurs twice positive and twice negative, hence $\Delta=4$ and $N=\Theta(k\log k)$. Two restriction levels touch at most $q=8$ records per leaf. Therefore
\[
N-8B\le L_2\le N,\qquad L_2=N-O(\log N)=\Theta(N).
\]
A fixed supplied ordinary-3CNF decider $A$ with $T_A(L)\le L^{t+o(1)}$, $S_A(L)\le L^{s+o(1)}$ can be simulated on at most four virtual grandchildren, sequentially, with polylogarithmic on-demand input-read overhead. Charging acquisition and all state gives only
\[
T_{C_A}(N)\le N^{\max\{1,t\}+o(1)},\quad
S_{C_A}(N)\le N^{s+o(1)}+O(\log N).
\]
Thus the virtual descriptor improves peak storage over eager materialization but does \emph{not} make the guest's input $O(\log N)$ bits long or halve either exponent. The $N^a$ / $N^\lambda$ ARC ledger is inapplicable with $\lambda=1$ here. For any source outside the bounded-edit eligibility check, a fully total wrapper can call $A$ directly, paying a parent-scale noncontractive fallback. This gives exact ordinary-input scope (after declaring the receiving grammar) without improving all-input resources. It never upgrades an M22-only claim into an arbitrary-SAT successor.

\begin{theorem}[Padded guest defeats this exact two-level route]
Assume $P=NP$ and let $B_0$ be any fixed uniform polynomial SAT decider with exponent $K_0$. Choose integer $D>\max\{K_0,2\}$; program $A_D$ first performs $L^D$ content-independent charged steps on every valid input of length $L$ and then executes $B_0$. The joint pair $(D,D)$ is achievable. On every growing eligible M22 source for which this two-level compiler actually runs a guest leaf, that invocation costs $\Omega(N^{D-o(1)})$. It cannot realize the proposed $\max\{11/10,3/5+D/2\}<D$ time exponent.
\end{theorem}
\begin{proof}
Every such residual ordinary child has $L=\Theta(N)$ by the previous theorem. The fixed padded program incurs its full delay regardless of SAT label. Calling it is an actual charged operation, unlike reading a membership bit from an ideal oracle. This excludes the particular route architecture; existential ARC routes may choose a different program and remain \textbf{OPEN}.
\end{proof}

\begin{lemma}[Same-exponent transcript spoofing]
For a fixed exact SAT program $A$ with joint $(t,s)$, $t\ge1$, prepend either a forward or reverse dummy read of every source bit and then run $A$. Both wrappers decide the same language, and the scans cost $N\operatorname{polylog}N$ time and $O(\log N)$ extra index bits, preserving achievable joint exponents. Their precomputation read-address sequences are opposite. Raw read order alone is not a matched-resource invariant.
\end{lemma}
This does not rule out a genuinely semantic, source-aware selector, which requires its own proved bound and invariance argument.
