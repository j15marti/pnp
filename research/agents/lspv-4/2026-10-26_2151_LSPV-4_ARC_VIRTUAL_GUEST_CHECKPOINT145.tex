\section{New exact two-level guest-path covering}
\begin{theorem}[actual requests with variable-length children]\label{th:guest}
Let $F_0\in\UNSAT$ have immutable encoded bit length $N$ and $m$ distinct positions $D$ such that every single-bit mutant $F_i=F_0\oplus e_i$, $i\in D$, is a valid SAT instance of the \emph{same} length. Take a fixed deterministic SAT-polarity-preserving, two-level, virtual ordinary-SAT child realization, possibly adaptive and cached. On the rejecting run for $F_0$, let $r_0$ count all otherwise unclassified direct source bit reads, let $p_1$ bound source reads during first-layer initialization, and let each first-layer request read at most $q_1$ additional source bits. Let second-layer initialization perform at most $p_2$ calls to the first-layer service, and let each second-layer service request perform at most $q_2$ first-layer requests. Let the guest make $Q$ second-layer service requests. The service includes requests for child length, headers, endmarkers, body bits and malformed-input status, not just fixed data positions. All source reads must be assigned to a charged class. Then
\[
\boxed{m\le r_0+p_1+q_1(p_2+q_2Q).}
\tag{1}
\]
The identical pathwise claim holds for any rejecting computation branch of a \emph{sound} co-nondeterministic SAT machine, whose nondeterministic guesses are held fixed, with all SAT branches required to accept. If the source promise provides $r$ pairwise-disjoint SAT-producing two-bit mutations instead, the left side is $r$.
\end{theorem}
\begin{proof}
Unroll the actual rejecting computation and each virtual interface request, including cache updates, constructor failures, proof authentication and source-dependent timing. The total number of original bits read is at most the right side. If some sensitive position $i$ was not read, the same deterministic transitions, virtual answers, lengths, addresses, stopping point and final rejection occur when only $i$ is flipped. This rejects the valid SAT source $F_i$, a contradiction. For a co-nondeterministic rejecting branch, fixing all guesses reproduces a rejected SAT branch, also impossible. For disjoint two-bit perturbations, the read set must hit each pair, so its cardinality is at least $r$. No claim about superlinear running time follows.
\end{proof}
\begin{corollary}[source acquisition does not close FLMV]
For ARC191's explicitly encoded connected $h$-prism, $m=24h$ sensitive sign bits and $N=\Theta(h\log h)$. An accepting UNSAT proof verification path or rejecting coSAT path therefore has $\Omega(N/\log N)$ bit-source reads, or the appropriate hit-set count with word-cell packing as in SIGN-SENSITIVITY-WORD-FIREWALL171. Under the exact-$(4,4)$ source promise use the $12h$ balanced paired perturbations, not the illegal single-sign mutations. The derived exponent is one, not a superlinear unrestricted SAT lower bound.
\end{corollary}
\paragraph{An essential falsifier.}
The length-only toy virtual source $g(x)$ having length $1+\bigvee_{j=1}^m x_j$ distinguishes the zero string from every singleton neighbor. Treating the length request as free gives $q_1=0$ and a false bound. The correct implementation must read all $m$ source bits during that one length request, even if no child data bit is requested.

\section{A positive charged canonical clause-ordinal index}
\begin{theorem}[checkpoint clause-start oracle]\label{th:checkpoint}
Fix canonical proper ASCII 3CNF: one header \texttt{p cnf n m} and one clause per newline, with three nonzero signed decimal names per clause, pairwise distinct absolute IDs, one separating space, terminator \texttt{0}, no comments or alternative whitespace. Let $N$ be physical \emph{bits} and restrict to $1\le n\le N^3$, $0\le m\le N$, so each numeric token and record has $O(\log N)$ bytes. For $1\le B\le m$, there is a deterministic one-pass construction of an indexed table of every $B$th clause starting byte offset, using
\[
S_{\rm index}=O(\lceil m/B\rceil\log N+\log N)
\tag{2}
\]
writable/index bits, at charged $O(N\operatorname{polylog}N)$ indexed-bit-time. For a requested clause ordinal $j$, its physical source offset and three literals can be authenticated by indexed lookup of checkpoint $\lfloor j/B\rfloor$ and a scan of fewer than $B$ preceding records, with $O(B\operatorname{polylog}N)$ indexed-bit-time and $O(\log N)$ additional scratch.
\end{theorem}
\begin{proof}
Maintain only $O(\log N)$-bit header/counter/literal registers, validate each original source byte in a streaming pass, and append a physical offset every $B$ clauses. At most $\lceil m/B\rceil$ absolute offsets of $O(\log N)$ bits are written. To answer ordinal $j$, indexed-read entry $\lfloor j/B\rfloor$, skip $j-B\lfloor j/B\rfloor<B$ canonical lines, and parse/authenticate the selected clause directly from its immutable original bytes. With $n\le N^3$ each line has $O(\log N)$ bytes; actual indexed address-register manipulation adds at most polylogarithmic bit-time per accessed byte.
\end{proof}
An arbitrary canonical ASCII input can declare exponentially large numeric variable IDs using $O(N)$ decimal digits. Such a source is \emph{not} covered by the simple $O(\log N)$ numeric-register proof. A lexicographic source-substring verifier might repair that gap with separate time costs; it has not been proved here. A completely general DIMACS parser must also handle comments, redundant whitespace and other encodings, whereas this theorem rejects them. This index is one simple upper-bound construction, not a static rank/select or source-probe lower bound.

\section{Three separate native ledgers and the ARC budget}
In an indexed input/work model, a batch of $Q$ ordinal lookups in the indexed checkpoint construction has the certified upper bounds
\[
T_{\rm indexed}=O(N\operatorname{polylog}N+QB\operatorname{polylog}N),\quad
S_{\rm indexed}=O((m/B)\log N+\log N).
\tag{3}
\]
On fixed-$k$ sequential input/work tapes, input-head travel to a stored physical source address and work-head travel to the indexed checkpoint entry must instead be charged. On a one-tape read/write machine the original $N$ source bits already contribute $N$ to total footprint. For the \emph{prescribed} alternating first/last-clause itinerary, one sequential head can require $\Theta(QN)$ travel, even though the indexed model pays no travel across the intervening gap. Source queries that can be reordered or cached may avoid this itinerary.

For $m=N^{1+o(1)}$, $B=N^{\beta+o(1)}$, and $Q=N^{\gamma+o(1)}$, (3) supplies the upper-bound exponent ledger
\[
t\le\max\{1,\gamma+\beta\},\qquad s\le1-\beta.
\tag{4}
\]
These are not universal lower bounds, nor do they establish a strict FLMV forbidden-box contradiction. In particular, the required small-space deterministic SAT seed $d=1.802,s=o(1)$ is not entailed by $P=NP$; only an unknown polynomial exponent $K$ follows. The conservative fixed-$k$ multitape-to-one-tape simulator remains $T_1=O(T_k(N+S_k+\log(T_k+2)))$, $P_1=O(N+S_k+\log(T_k+2))$, with one-way exponent ceilings $t_1\le t_k+\max(1,s_k)$ and $p_1\le\max(1,s_k)$. These directions cannot be reversed to import one-tape crossing lower bounds into indexed RAM.
