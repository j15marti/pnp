\section{Exact uniform duplex construction}
For $q\ge1$, let the prescribed baseline $F_b$ have variables
$z_0,\ldots,z_q,u,v$ and clauses
$(z_0\vee u),(z_0\vee\neg u),
(\neg z_q\vee v),(\neg z_q\vee\neg v)$ and
\[
C_i=(\neg z_{i-1}\vee z_i)\ \ (b_i=1),\qquad
C_i=(\neg z_{i-1}\vee\neg z_i)\ \ (b_i=0).
\]
It has $q+3$ variables and $q+4$ binary clauses; it is UNSAT iff
$b=1^q$. A first zero permits a $1\to0$ source transition.
Take two variable-disjoint sources $F_{b^0},F_{b^1}$ and a fresh
original switch $x$. For every source clause
$D=(\ell_1\vee\ell_2)$ in arm $a\in\{0,1\}$, create fresh
$p_{a,D},c_{a,D,1},c_{a,D,2}$. Using two binary clauses per
equivalence, force
\[
c_{a,D,j}\leftrightarrow\operatorname{var}(\ell_j),
\qquad p_{a,D}=x\oplus a.
\]
Add one proper signed ternary
\[
(p_{a,D}\vee\widehat\ell_1\vee\widehat\ell_2),
\]
where $\widehat\ell_j$ uses its private copy with the original sign.
The pivot links are $(\neg p\vee x)\land(p\vee\neg x)$ for arm zero
and $(p\vee x)\land(\neg p\vee\neg x)$ for arm one.
Call the resulting binary-backbone-plus-ternary formula
$D_{q,b^0,b^1}$. This source-local compiler does not decide the input.

\begin{theorem}[Exact counts, labels and witnesses; PROVED/EXACT]
For every $q,b^0,b^1$,
\[
n=8q+31,\quad m_2=12q+48,\quad k=2q+8,\quad M=14q+56.
\]
There are $2q+7$ original variables (both source blocks and $x$)
and $3k$ newly introduced functional auxiliary variables, no new free
auxiliaries and no eliminated original variables in the tested solver.
Fixing the originals uniquely fixes every equality copy and pivot.
With $s(b)=\#SAT(F_b)$,
\[
D_{q,b^0,b^1}\in UNSAT\iff b^0=b^1=1^q,\qquad
\#SAT(D_{q,b^0,b^1})=2^{q+3}(s(b^0)+s(b^1)).
\]
The binary-only backbone is SAT and implies no individual literal on
either label; there are no initial unit clauses. Its incidence graph
together with ternaries is connected. All $k$ ternary supports are
pairwise disjoint; $h_0=k$ exactly.
\end{theorem}
\begin{proof}
Fix $x=a$. Every arm-$a$ pivot is zero and its ternary becomes the
corresponding original binary clause. Every opposite-arm pivot is one
and satisfies its ternary; its $q+3$ source variables remain arbitrary.
Every auxiliary extension is unique because the links are equalities.
The source endpoints force $z_0=1,z_q=0$, giving the stated labels.
Each source clause gadget has three auxiliaries, six binary clauses
and one ternary. All $2(q+4)$ ternary supports have fresh physical
variables, giving the minimum raw backdoor. Any values of the original
variables and $x$ extend uniquely to a model of the binary-only
backbone, so that backbone implies no literal.
\end{proof}

\begin{theorem}[Deletion-critical UNSAT ternaries]
For $b^0=b^1=1^q$, deleting any one of the $k$ ternary clauses makes
the resulting formula SAT while all binary links remain intact.
\end{theorem}
\begin{proof}
Every binary clause of $F_{1^q}$ is necessary for its contradiction:
deleting a chain clause permits one $1\to0$ transition; deleting
either start endpoint permits $z_0=0$ and a suitable $u$, and
deleting either final endpoint permits $z_q=1$ and a suitable $v$.
Select the arm of the removed ternary using $x$, satisfy that reduced
source, and reconstruct all auxiliaries.
\end{proof}

\section{The paid SCC-to-one-interface theorem}
\begin{theorem}[General recognizable common-pivot rule]
Let $F=B\land T$, with $B$ 2-CNF and $T$ proper ternary clauses. If $B$
is SAT, replace each ternary signed literal with a representative
of its SCC in the binary implication graph, deduplicating and deleting
tautologies. If all surviving width-three clauses contain one common
variable $x$ in either polarity, two assignments to $x$ leave
only clauses of width at most two. Both branches are decided by SCC
in $O(n+M)$ addressed-word operations and $O(n+M)$ peak logical words,
including source read, SCC computation, pivot discovery, restrictions
and SAT witness replay. A common variable, if present, is found by
checking at most three candidates from the first ternary.
\end{theorem}
\begin{proof}
Mutually reachable literals agree under all $B$-models. The
substitution therefore preserves $F$ on all source assignments
satisfying $B$. A signed occurrence of $x$ in each ternary either
satisfies that clause or reduces its width upon fixing $x$.
The two values exhaust all source assignments, and binary SCC solves
each residual. Each traversal and the bounded number of branch
solves cost linear work. A separate complete DPLL fallback retains
exactness if the sufficient test fails.
\end{proof}

On $D_{q,b^0,b^1}$, each occurrence copy SCC-identifies with its
original and the pivots identify with $x$ or $\neg x$.
Every ternary nevertheless remains proper and of width three:
\[
(x\vee\ell_1\vee\ell_2)\quad\text{or}\quad
(\neg x\vee\ell_1\vee\ell_2).
\]
Hence $k_1=k$, yet the newly available minimum syntactic
2-CNF backdoor is $h_1=1$. A single evidence-selected branch
on the discovered $x$ reduces $k_2$ to zero by binary propagation.
No initial unit, binary-implied singleton or XOR recognition is
needed. The optimum $h_0,h_1$ is analysis-only until the policy
discovers its valid pivot by scanning and checking the current clauses.

\section{State-adaptive execution and full accounting}
The tested algorithm is one uniform total exact policy: validate all
clauses, build binary adjacency lists and SCCs, check backbone
consistency, quotient signed literals, scan at most three common-pivot
candidates, select the witnessed pivot, run at most two binary
propagation/restriction/SCC branches, replay any SAT witness against
the original input, otherwise return UNSAT. An unsuccessful pivot
recognition or a residual longer clause invokes exact DPLL. Failed
work, mode tests, rereads, source storage, switching and peak space
are counted. No true SAT/UNSAT label is supplied.

\section{Input query bound, fixed-policy comparison and ladder}
On the all-one UNSAT input, flipping any of the $2q$ private
source orientation signs changes the label to SAT and changes
exactly one word without changing signed record metadata, $n,M,N$,
or any other word. Every deterministic exact decider must
therefore inspect those $2q$ words on that input, giving
\[
\boxed{T_A(D_{q,1^q,1^q})\ge 2q=\Omega(N/\log N)}
\]
in the declared addressed-word model. A source-aware scan matches
the bound in $O(q)$ operations. It is not an encoding-independent
superlinear time lower bound; charged materializing reductions
consume linear work.

A deliberately restricted comparator enumerates assignments to
one physical pivot variable from each of the $k$ disjoint
ternary supports, with no early partial pruning, and solves
the resulting binary residuals in lexicographic order. It makes
$2^k$ completed leaves on the UNSAT pair and $2^{q+4}$ leaves
when the first arm is SAT and the second UNSAT. This is
\textbf{not} a lower bound for DPLL, CDCL, any adaptive algorithm,
or a solver choosing a different representation.

The ladder is exact: the original $F_b$ is 2-SAT; the duplex has
linear raw $k,h_0$; charged SCC gives $h_1=1$ without reducing $k$;
one discovered interface split gives 2-SAT; unrestricted 2-CNF
plus $k$ proper ternaries contains arbitrary 3-SAT and is
\textbf{KNOWN NP-complete}. Even if one requires disjoint physical
ternary supports and an equality-only binary backbone,
NP-completeness follows by cloning the three literals of each
source 3-SAT clause and linking them to originals with two binary
equalities per clone: $n=n_E+3t,m_2=6t,k=t,M=7t$,
a polynomial exact witness-preserving compiler. This is a known
style of source-occurrence lifting, not padding-based amplification.
