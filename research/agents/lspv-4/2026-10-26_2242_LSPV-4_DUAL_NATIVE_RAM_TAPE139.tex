\section{Four falsifiable claims fixed before source search}
We distinguish $M_1$, one deterministic finite-alphabet read/write tape initially containing the full $N$-bit input; $M_k$, one \emph{sequential} read-only input head plus a fixed number $k$ of sequential read/write work tapes; and RAT, indexed read-only input and indexed work memory with the index-tape bit-time costs. These are different models, not three names for one machine.
\begin{description}
\item[] \textbf{H1:} The conservative $M_k\to M_1$ scan simulator yields $T_1=O(T_k(N+S_k+\log(T_k+2)))$ and $P_1=O(N+S_k+\log(T_k+2))$ with fixed $k$, provided extreme blank-input-head positions are encoded rather than materialized. \textbf{PROVED} below.
\item[] \textbf{H2:} A putative $M_1$ exact22 lower bound with exponent $2$ imposes an additional nontrivial necessary restriction on source $M_k$ exponents via \emph{this} simulator. \textbf{FALSIFIED}: $t_k+\max\{1,s_k\}\ge2$ already follows from $t_k\ge1$.
\item[] \textbf{H3:} Native sequential-input $t+s\ge2$ can be imported unchanged into indexed RAM/RAT SAT from an easy exact22 SAT promise without simulated address and head motion. \textbf{FALSIFIED as a model-transfer inference}: an indexed comparator on the same left--gap--right promise uses $(t,s)=(1,0)$, while the sequential proof depends on a single moving input head. This is not an all-input SAT decision algorithm.
\item[] \textbf{H4:} The prior RAM-indexed balanced certificate dictionary has $O(\log h)$ \emph{physical sequential-tape time} per lookup without a new representation lemma. \textbf{FALSIFIED as an automatic transfer} by a $2^d-1$-node breadth-first tape layout requiring $2^d-2$ head moves on a $d$-comparison search. Other sequential implementations remain possible.
\end{description}

\section{Two native tape ledgers and conservative simulation}
\begin{theorem}[Fixed-$k$ sequential multitape simulation, model-native]\label{th:sim}
For $M_k$ with one read-only sequential input head and fixed $k$ sequential finite-alphabet work heads, let $T_k(N)\ge1$ count transitions and $S_k(N)$ count the \emph{distinct visited work cells}, excluding input. A deterministic standard one-tape simulator preserving the exact output can be constructed with
\[
T_1(N)=O_k\!\left(T_k(N)\,[N+S_k(N)+\log(T_k(N)+2)]\right),\quad
P_1(N)=O_k(N+S_k(N)+\log(T_k(N)+2)).\tag{1}
\]
$P_1$ is its total physical footprint \emph{including the initial input}. For polynomial ceilings $T_k\le N^{t_k+o(1)}$ and $S_k\le N^{s_k+o(1)}$ with $t_k\ge0$, the certified ceilings are
\[
t_1\le t_k+\max\{1,s_k\},\qquad p_1\le\max\{1,s_k\}.\tag{2}
\]
These are upper bounds on the constructed simulator, not lower bounds on the source machine or all one-tape implementations.
\end{theorem}
\begin{proof}
Use a constant-size multitrack alphabet to store the original input symbols and the $k$ simulated work-tape symbols/head marks, with separate logical tape origins and a simulated input-head mark. Each sequential transition needs only the $k+1$ current symbols and finite control. A one-tape sweep locates the marked heads, records their constant-size tuple in its finite control, and sweeps again to apply writes and head changes. Since each work-tape head moves at most one cell per source step, its visited interval has length bounded by its contribution to $S_k$. Thus the combined represented work intervals occupy $O_k(S_k)$ physical cells. The original input occupies $N$ cells initially. If the input head can wander outside the physical input into a homogeneous infinite blank tail, represent its tail offset by a binary counter of $O(\log(T_k+2))$ bits rather than allocate $T_k$ blank cells. The same holds for a symmetric left blank tail if allowed. A sweep costs $O_k(N+S_k+\log(T_k+2))$ transitions, with a constant number of sweeps per source step. No separate $+Q_k$ or $+C_k$ time term is appended: source physical cell probes and crossings are already included in $T_k$. The simulator's own sweeps account for their physical head movements. The initial tape footprint includes $N$ without a separate charged input-writing phase. Fixed alphabet recoding and output production are included; the one-tape output is never a free rereadable work tape. Taking polynomial exponents gives (2), since $\log(T_k+2)=N^{o(1)}$.
\end{proof}
\begin{corollary}[No quadratic stripe gain from this simulation]\label{cor:barrier}
If a selected promise language has a native one-tape lower bound $T_1\ge N^{2-o(1)}$, substituting only the particular upper-bound simulator (1) yields the necessary exponent condition
\[
 t_k+\max\{1,s_k\}\ge2.\tag{3}
\]
For $t_k\ge1$ this is tautologically true. It cannot recover the \emph{stronger} native sequential-input inequality $t_k+s_k\ge2$ when $s_k<1$.
\end{corollary}
\begin{proof}
If the constructed simulator were certified with $t_k+\max(1,s_k)<2$, it would contradict the one-tape stripe. But $t_k\ge1$ makes the sum at least two. A reverse conclusion $t_k\ge2$ from $t_1\ge2$ does not follow: the same equality promise has an $M_k$ algorithm of time $O(N)$ using $O(N)$ remembered bits, for which (1) gives at most quadratic one-tape time.
\end{proof}

\paragraph{Native event accounting.} On $M_1$, $N\le P_1\le N+O(T_1)$, $H_1\le T_1$, and crossings of any fixed cut satisfy $C_1\le T_1$. On $M_k$, $S_k\le kT_k+O(k)$ and $Q_k,C_k=O_k(T_k)$ for elementary finite-alphabet head operations; the original read-only input does not count toward $S_k$. A \emph{native} input-gap crossing proof may charge a full work configuration of $O_k(S_k+\log(T_k+N)+1)$ bits per crossing, but that information accounting is not a separate physical per-step time surcharge. It is the \emph{crossing argument}, not the simulation (1), that can supply a nontrivial $t_k+s_k$ diagonal on the one-input-head tape model.

\section{A concrete sequential-head dictionary counterexample}
\begin{theorem}[Logical AVL comparison count does not certify physical tape time]\label{th:dict}
For every $d\ge2$, a perfectly balanced binary search tree of $h=2^d-1$ nodes stored in breadth-first array order admits a successful search using exactly $d$ logical node comparisons, whose \emph{literal pointer-following implementation} from a sequential work-tape head at the root requires at least $h-1$ head moves. Hence $O(\log h)$ RAM node accesses do not justify $O(\operatorname{polylog}h)$ \emph{physical time} for that tape implementation.
\end{theorem}
\begin{proof}
Index the array from zero. The rightmost root-to-leaf path visits addresses $0,2,6,14,\ldots,2^d-2=h-1$. There are $d$ comparisons. An ordinary sequential work-tape head must traverse the distance between successive addresses; their monotone path has total displacement $(h-1)-0=h-1$, even if comparisons and arithmetic cost nothing. For $d\to\infty$ the ratio $\Theta(h/\log h)$ diverges. This is a \emph{layout-and-implementation} counterexample only, not a lower bound for all data structures: reordering, caching, regenerating, batching or choosing another certificate parser might avoid the particular path, but each such strategy needs its own same-machine time and memory proof.
\end{proof}
\paragraph{Impact on STREAM-DICT132.} Its $T_V=(N+P+R)\operatorname{polylog}(N+P)$ bound and $O(h\log(N+P))$ work/index bits are \emph{RAT-indexed} conditional claims. Copying its logical AVL comparison bound to $M_1$ or $M_k$ without physically charging node-address head travel is not valid. A conservative application of (1) to a RAT implementation is itself not justified until a sequential-tape simulation of indexed accesses has been exhibited. Even with an appropriate $M_k$ realization, the generic $M_k\to M_1$ exponent penalty removes any quadratic one-tape stripe contradiction from a source time exponent at least one.
