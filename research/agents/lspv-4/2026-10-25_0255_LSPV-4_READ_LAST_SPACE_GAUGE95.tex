\section{Exact single-machine theorem}
\begin{theorem}[Space-preserving read-last normal form]
Let $A$ be any fixed uniform total deterministic exact decider for a decidable bitstring language $L$. Its machine has random-access to a \emph{read-only} indexed input, with writable work and address/index tapes counted, and a one-bit output. Assume for finite fixed $t,s\ge0$ that on every $N$-bit input simultaneously
\[
T_A(N)\le N^{t+o(1)},\qquad S_A(N)\le N^{s+o(1)}.
\]
There is one fixed uniform total exact machine $B_A$ in the \emph{same} input/work machine model, such that for every input $x$ with $N\ge1$:
\[
B_A(x)=A(x),\qquad
T_{B_A}(N)=O((N+T_A(N))\log^c(N+2)),\quad
S_{B_A}(N)=O(S_A(N)+\log(N+2))
\]
for some constant $c$ depending only on the fixed machine implementation. The first time $B_A$ has read \emph{every} real source bit occurs at its last previously unread source query. After that query it performs at most a constant number of bit-control/output operations before halting. In particular, when $t\ge1$ the new machine realizes the same joint exponents $(t,s)$, not an improved pair.
\end{theorem}
\begin{proof}
Use zero-based positions and withhold $j=N-1$. Read the other $N-1$ physical positions once, charging the entire scan and retaining no prefix copy. For $b=0,1$, sequentially simulate the complete fixed machine $A$ on the virtual ordinary input $x^{(b)}$ obtained by replacing only position $j$ by $b$. When $A$ requests virtual position $i$, pay for comparison to $j$ on counted index tapes. If $i=j$, supply controller constant $b$, otherwise read the real source at $i$, again paying addressing and the source read. The real bit $x_j$ remains unread in both simulations. The two outputs $a_0,a_1$ are kept in finite controller state; the simulated work area is reused, never held in duplicate. This works even if a virtual completion is a malformed formula, since $A$ is total on bitstrings.

Before the last query, set the real input index to $j$ using paid address work. Read the physical $x_j$ exactly once and immediately select $a_{x_j}$. Since $x^{(x_j)}=x$, the result equals $A(x)$. Selection and output are constant control steps. The initial scan uses $N-1$ queries, the simulations at most $2T_A(N)$ real source queries, and the last action one query. Index comparisons, source seeking, reset, and step simulation cost a polylogarithmic bit-operation overhead per simulated step. The two runs reuse all writable tapes, and extra counters/virtual address state occupy $O(\log N)$ bits, without any $N$-bit prefix array. Since $A$ is fixed, the source code of $B_A$ is fixed; no nonuniform advice or discovery of $t,s$ occurs.
\end{proof}

\paragraph{Model qualification.}
Acquisition here means first-read \emph{coverage}. If acquisition instead demands all $N$ values simultaneously stored in \emph{writable} cells, it already costs $\Omega(N)$ space, incompatible with an $N^{1/2+o(1)}$ ARC space budget. The theorem never silently treats a work tape or serialized child as an extra free read-only input.

\section{Matched opposite-label ordinary proper-3CNF}
Take all eight sign patterns $C_{\sigma}=(\sigma_1x\vee\sigma_2y\vee\sigma_3z)$ on the same three variables, with $(x\vee y\vee z)$ last. The conjunction $U$ is UNSAT, since each assignment falsifies one clause. Flip only the sign of the \emph{last literal} of the last clause, duplicating $(x\vee y\vee\neg z)$; the resulting $V$ is SAT with exactly one assignment. Both are proper ternary CNFs with $n=3$, $m=8$ and identical fields other than that sign. In the finite test grammar, a 16-bit header and 26-bit fixed records give
\[
|U|=|V|=16+8(26)=224.
\]
The last encoded bit is exactly this sign. The 223-bit common prefix admits cofactor answers $(a_0,a_1)=(0,1)$; the real final source bit selects the opposite labels in one controller step. \emph{Both cofactor decisions were actually computed and fully charged.}

\section{BIT-RESOURCE1 ledger and the two required spines}
Let $R_A\le T_A$ count simulated input reads. Every elementary source/work bit read, unchanged-value write, control/address step and policy decision counts as work. Literal value-changing flips are an independent activity metric. Define cumulative bit-time as the sum of actually simultaneously live writable bits at all charged steps. Conservative resource bounds for the \emph{one constructed machine} are
\[
\begin{array}{ll}
R_{\mathrm{physical\ source}}\le N+2R_A(N),&
W_{\mathrm{primitive}}\le O((N+T_A(N))\log^c(N+2)),\\
R_{\mathrm{work}}+W_{\mathrm{work}}+
W_{\mathrm{address/control}}\le O((N+T_A(N))\log^c(N+2)),&
S_{\mathrm{peak}}\le O(S_A(N)+\log(N+2)),\\
0\le F_{\mathrm{complete\ state}}\le O(W_{\mathrm{primitive}}),&
BT\le W_{\mathrm{primitive}}S_{\mathrm{peak}},\quad
P_B=O(P_A+1).
\end{array}
\]
No entire child formula is generated, no first-read source bit is stored in a prefix array, and no sibling/ancestor body, cache, hash, or free semantic oracle is retained. The two complete virtual runs, physical source rereads, all address comparisons, index-tape updates, simulator setup, cleanup, and final output are included. The $O(\cdot)$ inequalities are machine proofs, \emph{not} measurements of hardware transistors or data-register flips.

\paragraph{Adaptive-state trajectory.}
At $C_0$ the source and true label are unknown. A charged scan visits each real position except $j$ and discards its value. In $C_1$ the source is incomplete but queryable; the policy runs $A$ under virtual bit zero and one, with its original adaptive branching, SCC, Horn, affine, cache, direct-decision or other strategy entirely allowed and completely simulated. In $C_2$ both completed answer bits reside in finite control, while $j$ remains unread. A charged final indexed read reaches $C_*$ with full first-read coverage, then one cached selection halts. Correctness is exact on SAT and UNSAT, with no true-label oracle.

\paragraph{Contraction spine.}
The simultaneous successor pair of this wrapper is bounded by $(\max\{1,t\},s)$, which for $t\ge1$ is just $(t,s)$. The wrapper is therefore \textbf{FALSIFIED as a favorable ARC contraction}. \paragraph{Direct lower-bound spine.}
Suppose a complete-state potential independent of unknown optimal time has terminal value zero and satisfies for \emph{every} legal bit transition
\[
\Phi_N(C)-\Phi_N(C')\le L(N)\,w(C,C').
\]
Our $B_A$ has $W_{\mathrm{post}}\le c_0$ for a fixed finite controller constant once every real bit has first been read. Telescoping, as in INDEXED-MERGE-POTENTIAL-CEILING133, gives
\[
\boxed{\Phi_N(C_*)\le c_0L(N)}.
\]
Thus \emph{for every exact decider} a universal claim of a superpolynomial potential at its all-bits-first-read checkpoint is false when $L$ is polynomial. This does not prohibit a pre-acquisition or whole-execution noncircular potential, nor does it lower-bound general SAT time. The previously proved input-query hitting potential $\tau\le N$ is not summed or counted twice.
