\section{Exact clause-indexed target semantics}
Original signed occurrence $x_{i,j}$ always means the same global variable $x_i$ in source clause $C_j$. A local $S_j$ sets all three original literals TRUE, and local $U_j$ sets them all FALSE; bitwise inversion swaps the two. These local targets are not separately assignable global occurrences. SS and UU for a pair are compatible iff no shared variable has opposite polarity; SU and US iff no shared variable has the same polarity. A clause is ordinarily SAT if its TRUE-literal count $t_j(a)$ is at least one. For coherent full assignments, $t_j(\bar a)=3-t_j(a)$, so $N_s(\bar a)=N_{3-s}(a)$. The full local Python experiment separately records every indexed $S/U$ occurrence, both inversions, all four pair modes, coherent $0^n,1^n$, multi-flips, original clause counts $N_0,\ldots,N_3$, and complete assignments and complements.
\section{Falsification of strict endpoint descent}
For any full source assignment $a$ and original variable $x$, let $r_x(a)$ count originally FALSE clauses containing $x$ and $d_x(a)$ count clauses in which $x$ is the unique TRUE literal. Only those clauses change false status under the flip, giving the exact \emph{make-break identity}
\[
N_0(a\oplus\{x\})-N_0(a)=d_x(a)-r_x(a).
\]
\begin{theorem}
For every integer $r\ge1$ there is a connected proper duplicate-free strict signed exact-(2,2)-3CNF $H_r$ with $n=6r,m=8r$ that is SAT, but both globally coherent endpoints falsify exactly $r$ original clauses, and every single-variable flip from either endpoint also falsifies exactly $r$ clauses. The smallest possible $n$ for a strict22 double-endpoint plateau with neither endpoint satisfying is six.
\end{theorem}
\begin{proof}
For each block $j$ modulo $r$, take six variables $x_{j,1},\ldots,x_{j,6}$ and eight original clauses
\[
\begin{array}{ll}
(x_{j-1,1}\vee x_{j,3}\vee x_{j,5}),&(x_{j,1}\vee\neg x_{j,3}\vee x_{j,6}),\\
(\neg x_{j,1}\vee x_{j,4}\vee x_{j,5}),&(\neg x_{j,1}\vee\neg x_{j,4}\vee x_{j,6}),\\
(x_{j,2}\vee x_{j,3}\vee\neg x_{j,5}),&(x_{j,2}\vee\neg x_{j,3}\vee\neg x_{j,6}),\\
(\neg x_{j,2}\vee x_{j,4}\vee\neg x_{j,5}),&(\neg x_{j,2}\vee\neg x_{j,4}\vee\neg x_{j,6}).
\end{array}
\]
The cross-block first clause joins the otherwise connected blocks cyclically. Every variable has exactly two positive and two negative original occurrences; no clause repeats a variable or duplicates another clause. At zero, exactly the first clause of every block is FALSE, and each variable which repairs one of these clauses also destroys one uniquely-TRUE clause. At one, exactly the last clause of every block is FALSE, and the analogous repair/destruction equality holds for each variable. Therefore $r_x=d_x$ at both endpoints for all variables. The coherent assignment $x_{j,1}=x_{j,3}=x_{j,5}=1$ and $x_{j,2}=x_{j,4}=x_{j,6}=0$ satisfies every original clause. For minimality, $3m=4n$, hence $n$ is a multiple of three. With $n=3,m=4$, both endpoints failing requires an all-positive and an all-negative ternary clause, leaving only two source clauses; blocking all three zero-endpoint improvements requires three distinct clauses with exactly one negative literal. Contradiction.
\end{proof}
