\section{CONSTRUCTION OR PROOF ATTEMPT}
Let $P(c,y)$ be a total explicit RAM source program, with $r$ Boolean CONTROL inputs and $m$ Boolean DATA inputs. Program counter, guards, addresses and write destinations depend only on CONTROL, never DATA; for fixed control input, DATA operations are only XOR, NOT, copy, constants and control-addressed reads. Let $T$ be worst-case instruction count, $S$ live working bits, $L$ encoded source length, and $K=\mathbb F_{2^\ell}$.
\begin{theorem}[Control quotient]
The unique multilinear field extension of the terminal Boolean bit satisfies
\[
\widehat f_P(a,z)=\sum_{u\in\{0,1\}^r}
\prod_{i=1}^r\bigl(u_i a_i+(1-u_i)(1-a_i)\bigr)\,P_K(u,z).
\]
A single uniform deterministic machine running all control assignments sequentially uses
\[
\mathrm{TIME}\le\mathrm{poly}(L)+O(2^r(T+S+r)\mathrm{poly}(\ell+\log(L+m+T))),
\quad
\mathrm{SPACE}=O((S+r+\log(L+m+T))\ell).
\]
Both are charged on the same output machine, including parsing, source input reads, resets, field arithmetic and output.
\end{theorem}
\begin{proof}
For fixed $u$, the DATA path and addresses do not depend on DATA values. Induction on all executed instructions shows each DATA register is affine in the independent inputs $y$ over $\mathbb F_2$. Executing those operations over $K$ therefore yields precisely the canonical affine extension. Every summand is multilinear in $a,z$ and the control selector basis takes value one exactly on its selected Boolean control vertex. The sum agrees with the Boolean truth table and so equals its unique multilinear extension. Enumerate $u$ sequentially using one reused scratch workspace and explicitly charge every call, reset, input access and field operation.
\end{proof}
\begin{theorem}[Query sharpness, already known in project INDEXQUERY1]
For independent Boolean table entries $y_u$, $f(c,y)=y_c$ requires all $2^r$ table probes to evaluate its extension at any off-grid control point $a$ with each $a_i\notin\{0,1\}$, in the worst-case independent-cell query model.
\end{theorem}
\begin{proof}
Every coefficient of $y_u$ in the extension is nonzero. Toggling an unqueried cell changes the answer while leaving the transcript unchanged.
\end{proof}
Two explicit falsifiers prevent an unjustified generalization: indirect address $y_0$ into the array $(y_0,y_1)$ computes $y_0y_1$, not an affine DATA map; the Boolean identity $y\oplus(y\wedge y)=0$ gives naive off-grid field evaluation $z+z^2\ne0$. Hence unconstrained DATA-dependent control and nonlinear field lifting are excluded.
