\begin{abstract}
We independently rerun the Library's original connected-interface audit and red-team the proposed SAT contraction through full projected semantics. We prove that an elementary, uniformly SAT, proper 3CNF family with $N_t=\Theta(t\log(t+2))$ input bits realizes $2^t$ distinct exact projections onto the same $4t$ named ports, despite each projection having an $O(t)$-gate circuit and a $t+O(\log t)$-bit template description. Consequently any source-free, single-child representation, regardless of its language or decoder running time, which preserves \emph{all} port assignments requires at least $t$ bits for some member. No uniform $N^\lambda$ full-port contraction, $0<\lambda<1$, exists on this family without charged retained ancestor data. In contrast, every source is SAT and admits a constant-size decision-only YES child. The theorem is an unconditional architectural information bound, not an unrestricted SAT time/space lower bound. We reproduce the 69,904 original resolution-control assignments and perform over one million additional finite full-port assignments. $P$ versus $NP$ remains OPEN.
\end{abstract}

\section{PROPOSE: falsifiable mechanisms}
\noindent\textbf{M1, compression despite quadratic resolution:} the $t^2$ resolvents may have a compact equivalent circuit. This is true but is \emph{not} sufficient for power-short full-port compression.\par
\noindent\textbf{M2, implicit universal template:} a fixed interpreted template might avoid materializing every port identifier. It succeeds at $t+O(\log t)$ bits; the test is whether $o(t)$ bits work for \emph{every} signed source. The counting theorem below rules that out.\par
\noindent\textbf{M3, dynamic retained context:} a child shorter than $t$ might be supplemented by an ancestor, an oracle, a head position, or a table. Such auxiliary information can retain the necessary bits, but must be charged.\par
\noindent\textbf{M4, decision-only escape:} the same family could still admit an immediate constant-size SAT-only successor. It does. Thus the obstruction cannot be promoted to $P\ne NP$.\par
The current missing global lemma is a uniformly polynomial-time, answer-preserving, single-child successor on arbitrary SAT with a polynomially bounded complete descent rank, rather than a universally small exact function over all possible future contexts.

\section{BUILD: exponentially many cheap full-port relations}
For $t\ge1$, take distinct port variables $a_i,b_i,c_i,d_i$ for $1\le i\le t$, and one forgotten variable $z$. For each sign pattern $s\in\{0,1\}^t$, define
\[
 A_i^{(s)}=(a_i\oplus s_i)\lor b_i,
 \qquad B_i=c_i\lor d_i,
\]
where $a_i\oplus s_i$ denotes the signed Boolean literal $a_i$ if $s_i=0$, and $\neg a_i$ if $s_i=1$. Define the proper ternary CNF
\begin{equation}\label{eq:source}
 F_{t,s}(z,u)=\bigwedge_{i=1}^t(z\lor A_i^{(s)})
 \land\bigwedge_{j=1}^t(\neg z\lor B_j),
 \qquad u\in\{0,1\}^{4t}.
\end{equation}
Every clause contains three different variable names; there are exactly $2t$ clauses, $4t+1$ variables, and a connected incidence graph because $z$ lies in every clause. Each source is SAT: set every $b_i=c_i=1$. It is not strict exact-$(2,2)$, since $z$ has $2t$ incidences and many other variables occur once. Unpadded canonical numeric identifiers give $N_t=\Theta(t\log(t+2))$ physical bits, uniformly over $s$.

\begin{proposition}[Exact projection with quadratic explicit resolvents]
The full port relation is
\begin{equation}\label{eq:projection}
 \phi_{t,s}(u):=(\exists z)F_{t,s}(z,u)
 =\left(\bigwedge_i A_i^{(s)}\right)\lor\left(\bigwedge_j B_j\right)
 =\bigwedge_{i,j}(A_i^{(s)}\lor B_j).
\end{equation}
The naive resolution output has $t^2$ proper width-four clauses. The factored form has $O(t)$ Boolean gates and an explicit bounded-fan-in circuit encoding of $O(t\log(t+2))$ bits. The stronger fixed-template description needs only $t+2\lfloor\log_2 t\rfloor+1$ bits, encoding the signs with an Elias-gamma length prefix. Every formulation computes the same full port function.
\end{proposition}
\begin{proof}
At $z=0$ exactly the $A_i$ clauses constrain the ports; at $z=1$ exactly the $B_j$ clauses constrain them. Existentially combining the two possibilities gives the disjunction. Distributivity gives the $t^2$ resolvents. A fixed evaluator of the template parses $t$, reads the $t$ signs, and loops through the $4t$ externally supplied port bits. The Elias-gamma prefix uses $2\lfloor\log_2t\rfloor+1$ bits. No SAT oracle is used.
\end{proof}

\begin{theorem}[Full-port minimax signature floor, PROVED/RESTRICTED]\label{th:floor}
For each fixed $t$, the $2^t$ functions $\phi_{t,s}$ are pairwise distinct. Let $E$ be \emph{any} deterministic map assigning each $F_{t,s}$ one binary child string $C_s$; let $D$ be any fixed decoder satisfying $D(C_s,u)=\phi_{t,s}(u)$ for every port assignment $u$, with no access to $s$, $F_{t,s}$, an ancestor, an advice table or a target-specific oracle besides $C_s$. There exists $s$ such that
\[\boxed{|C_s|\ge t.}\]
This holds even if $E$ and $D$ have unlimited running time and the child language is arbitrarily expressive. In particular, for every $0<\lambda<1$, no such map can satisfy $|C_s|\le N_t^\lambda$ for \emph{all} sufficiently large $t$ and all $s$.
\end{theorem}
\begin{proof}
For distinct $s,s'$ choose $i$ with $s_i\ne s'_i$. Set $b_i=0$, $b_h=1$ for $h\ne i$, and $c_1=d_1=0$ to falsify $\bigwedge_jB_j$. Set $a_i=1\oplus s_i$, leaving other ports arbitrary. Then $A_i^{(s)}=1$ but $A_i^{(s')}=0$, while all other $A_h$ are true, so $\phi_{t,s}(u)=1$ and $\phi_{t,s'}(u)=0$. Thus the functions are pairwise distinct. Exactness of $D$ implies the child strings $C_s$ are pairwise distinct. There are only $\sum_{\ell=0}^{t-1}2^\ell=2^t-1$ binary strings shorter than $t$, so one output has length at least $t$. Since $N_t=O(t\log(t+2))$, we have $N_t^\lambda=o(t)$ for every fixed $\lambda<1$. The claimed all-input power bound is impossible.
\end{proof}

\begin{corollary}[Charged retained information, source-free checkpoint]
If, instead of a single string, the checkpoint retains a total of $R$ binary bits encoding the child, ancestors, dynamic tables and persistent update state, and the fixed decoder has no access to the original source, then some checkpoint uses $R\ge t$ bits when the retained configuration is encoded in a single self-delimiting binary string. For a fixed-alphabet $k$-tape machine with at most $T=\poly(N_t)$ steps and $S$ visited writable cells, its complete state can take at most $2^{O(S)+O(k\log(T+2))}$ values. Distinguishing $2^t$ port relations therefore requires $S=\Omega(t)$ for fixed $k$ under the source-free, polynomial-time assumptions. In contrast, a read-only copy of the original $F_{t,s}$ can be reread, invalidating this source-free lower bound.
\end{corollary}
\begin{proof}
Exact port semantics still distinguishes the $2^t$ sources, so the complete retained configuration must be injective in $s$. A finite state controller and fixed number of heads contribute only $O(k\log T)$ positional bits in a $T$-step execution; the writable tape alphabet contributes $O(S)$ bits. Since $t=\Theta(N_t/\log N_t)$ and $\log T=O(\log N_t)$, the conclusion follows. If the original source remains accessible, the decoder can obtain $s$ by rereading; the stipulated injectivity of \emph{retained} state then does not apply.
\end{proof}

\paragraph{No decision-only obstruction.}
Every $F_{t,s}$ is satisfiable. A uniform polynomial-time parser can authenticate this grammar and output one fixed YES base formula. This constant-size decision-preserving successor is valid on the restricted class and trivially bypasses Theorem~\ref{th:floor}. The theorem concerns \emph{all future port assignments}, not the SAT answer alone; neither $P=NP$ nor $P\ne NP$ follows. The minimax statement does not assert that every individual $s$ needs $t$ description bits: some sign patterns are short programs.

\section{Complete encoded-size, time and peak-space ledgers}
Let $N=N_t$, let $L=t+2\lfloor\log_2t\rfloor+1$ be the compact child length, and include the $4t$-bit port assignment as physical input to any later exact function query. The constructive compiler checks the canonical source clauses and writes the sign bitmap. Under a conservative fixed read-only-input plus $k$ work/output-tape implementation, $T_k=O(N^2)$, visited writable cells $S_k=O(t+\log N)$ when materialized output is counted, with extra transient counters $O(\log N)$. On a two-fully-writable-tape implementation, $T_2=O(N^2)$, work/output visits $O(t+\log N)$ and original input footprint $N$; the total number of changes is at most $O(N^2)$, with no stronger write claim. Applying the project's conservative single-tape simulator gives
\[
 T_1=O\!\left(T_k(N+S_k+\log(T_k+2))\right)=O(N^3),\qquad
 P_1=O(N+S_k+\log(T_k+2))=O(N).
\]
These are robust algorithmic \emph{upper} bounds, not measured step counts or automatically kernel-certified exponents. An efficient fixed universal TM simulates this fixed deterministic compiler with polynomial overhead; its exact exponent depends on its encoding and interpreter and is not claimed. On indexed RAM, each port function query to the compact child costs $O(t)$ word operations once sign bits and port bits are available; on sequential tapes a conservative $O(t^2)$ query-time bound suffices. For $Q$ different contexts, charge $Q$ such queries, plus construction, input movement, and peak retained output. A supplied truth-table oracle is not a free classical child.

The compact child shrinks $N=\Theta(t\log t)$ to $\Theta(t)$ but \,\emph{not}\, to $N^\lambda$ for any $\lambda<1$. It also changes the input grammar from proper 3CNF to an interpreted bitmap: the required closed-class SAT recursion is not established. The dimension $4t$ of external future port assignments is not a hidden constant. An unrestricted SAT proof needs a different decision-only descent or must account for all retained bits.

\section{COMPUTATIONAL tests, role-specific handoff and limits}
The dependency-free script independently compared three representations in \eqref{eq:projection} on exactly $69{,}904$ assignments for $t=1,2,3,4$ with fixed positive signs; it also enumerated $1{,}082{,}400$ complete port assignments across all $2^t$ signatures for those $t$ and found $2^t$ distinct functions in every case. It checked $43{,}435$ pairwise constructive witnesses for all signatures through $t=8$ and $1{,}500$ seeded witnesses for $t=12,24,48$. All tests passed. The original Library ZIP was independently reexecuted, with byte-identical \texttt{results.json}.

The tests support the implementation; the infinite-family counting theorem is proved by the argument above, not by the tests. The new result is a representation-independent \emph{worst-case full-port size} obstruction. It is not a runtime lower bound for general SAT, not a strict signed exact-$(2,2)$ obstruction, not a proof that arbitrary knowledge compilation must blow up, and not a failed search result dressed as impossibility. For LSPV-1 and LSPV-5: keep decision-only and context-preserving children separate; require a complete resource ledger for every retained source bit, ancestor and oracle. The next LSPV-4 target is to audit whether a proposed universal successor truly needs all-context port equivalence or can certify a lower-cost decision-only descent with all acquisition and update costs paid. The $P$ versus $NP$ question remains OPEN.
