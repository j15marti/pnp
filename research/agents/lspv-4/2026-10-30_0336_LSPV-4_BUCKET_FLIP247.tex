\section*{Exact constant-time gain updates in proper strict22}
For a proper source CNF $F$ and global full assignment $a$, define for every original variable $x_i$ the *repair count* $R_i(a)$ to be the number of currently FALSE source clauses containing $x_i$, and the *break count* $B_i(a)$ to be the number of clauses with exactly one TRUE literal, namely $x_i$'s occurrence. Define $g_i=R_i-B_i$.
\begin{theorem}[Linear strict-descent preprocessing on exact $(2+,2-)$ 3CNF]
Let $F$ be proper signed exact-$(2+,2-)$ 3CNF with $n$ original variables, $m=4n/3$ original ternary clauses, and indexed occurrence access. From an arbitrary coherent full assignment $a$, a deterministic controller can repeatedly select a variable with \emph{maximum strictly positive} $g_i$ and flip the global variable until it finds a SAT assignment or reaches a local optimum. Excluding its optional expanded flip-trace output, the entire procedure, including input parsing, all original-clause $t_j$ and $N_0,\dots,N_3$, all gain updates, selection and final source witness verification, takes $O(N+m)$ indexed word-RAM time and $O(N)$ indexed machine words for input size $N$. At most $m$ strict flips occur, with $O(1)$ worst-case indexed work per flip after initial scanning. A failed run outputs UNRESOLVED, never UNSAT.
\end{theorem}
\begin{proof}
For any global variable flip, only source clauses containing that variable can change. A previously FALSE clause containing it becomes SAT; a previously SAT clause becomes FALSE iff the flipped literal was its only TRUE literal. Thus
\[N_0(a\oplus e_i)-N_0(a)=B_i(a)-R_i(a)=-g_i(a).\]
For strict22, every variable occurs in exactly four distinct proper original clauses, so $-4\le g_i\le4$. Maintain nine doubly linked buckets indexed by gain $-4,-3,\dots,4$; insert and remove any variable in constant time. Selecting a positive maximum requires checking at most four bucket heads. After flipping $x_i$, exactly its four incident clause truth counts and their $N_h$ class entries change. In each affected ternary clause, the clause contribution to every variable gain is $+1$ for a false clause, $-1$ for the unique TRUE occurrence in a singleton clause, and $0$ otherwise. Subtract its old contribution and add its new contribution, at most $2\cdot4\cdot3=24$ per-clause gain-counter updates, affecting at most $1+4(3-1)=9$ distinct variables. Thus a constant number of intrusive list updates repairs the gain buckets exactly. Input/occurrence construction, bucket initialization and first clause-status computation take $O(N+m)$; each positive flip decreases the integer $N_0$ by at least one, so at most $m$ flips occur. Reaching $N_0=0$ yields a verified SAT witness. With no positive bucket, no completeness claim is made.
\end{proof}
The theorem concerns a \emph{restricted search prepass}, not SAT decision. It does not make the search complete, improve DPLL fallback asymptotics, constrain arbitrary algorithms, prove a complexity lower bound, or improve on existing SAT local-search theory except for an explicit resource specialization for degree four.

\section*{Output-size theorem: do not hide quadratic scientific work}
\begin{theorem}[Full versus delta trace resource firewall]
If an experiment explicitly outputs all $m$ original-clause truth counts after each of $q$ coherent flips, its uncompressed trace necessarily contains $m(q+1)$ clause-count fields and requires $\Omega(m(q+1))$ field-write work and storage if retained. In contrast, on a strict22 source a replayable trace of the initial $m$ truth counts and, after each flip, the variable ID and up to four changed original source clause indices and counts needs $O(m+q)$ indexed records, retaining enough information to reconstruct every full intermediate vector. Re-expanding all complete intermediate vectors restores the $\Omega(mq)$ output cost.
\end{theorem}
\begin{proof}
The first claim follows because the requested explicitly expanded output has $m$ fields at each of $q+1$ time points. For the second, every global flip touches exactly four original indexed clauses. Record their old/new $t_j$, the variable flipped, and the initial full vector. The resulting chronological delta stream deterministically reconstructs all $t_j$ and $N_h$ and retains identical logical status information. These are information-preserving source-indexed logs but the compact output is not an already-materialized full table.
\end{proof}
This is not an information-theoretic lower bound on compressed trajectories; it is an output-length bound for the explicitly specified full-table representation. Source proof-DAG sharing similarly saves retained proof records only when repeated provenance subproofs are truly identical and amortized lookup costs are paid.

\noindent\textbf{Implementation-versus-model caution.} The theorem uses an indexed word array for assignment bits, so reading or toggling a designated original variable is one bounded word-RAM action. The published Python producer uses arbitrary-precision integer masks for convenience; a Python mask operation may touch multiple machine words and is charged as one \emph{declared logical} flip action, not a native constant-time instruction. Further, its experimental delta-trace records retain full Python integer masks for independent convenience checks, whereas the proved $O(m+q)$ \emph{optimal encoding} would retain only the initial assignment and the flipped variable ID at later steps. Thus neither the measured Python memory nor its complete published delta objects should be mistaken for a bit-level realization of the optimal bound. No physical/Turing resource lower bound is asserted.
