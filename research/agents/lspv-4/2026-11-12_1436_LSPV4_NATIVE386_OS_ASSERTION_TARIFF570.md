**A_CLI(P(k,front)) = A_CLI(P(k,late)) = 3915 + 42k**

where A_CLI counts calls to the exact source-code check() assertion function, not elapsed CPU instructions, bit operations, input-byte probes, or memory bytes. ## Full resource model and cost-soundness limits

Native /386 SOURCE has tariff 0 but costs input bytes/source comparisons; predeclared paid owner declarations cost 1 each once (not per DEF facet); each true DEF facet costs 0 extra logical work but requires bytes, parsed arrays and per-visit checks; each signed binary RES costs 1 per actual deduction, with two parent lookups, pivot validation, canonical resolvent construction and record retention. For this fixed family the paid dependency DAG, 35 paid inference execution identities, 70 parent applications, logical span, derived-only retention game and minimum logical cost of the displayed proof do not change with k. The original CLI additionally allocates the whole input Buffer and parsed JSON objects. We did not measure RSS, peak physical writable bits, physical elapsed verification steps, or optimal proof discovery.

An abstraction may erase irrelevant zero-paid facets when minimizing logical work (LSPV-2/579), but it cannot claim exact per-presentation verifier costs after forgetting their serialized bytes and rechecks. Treating these extra facets as paid would overcharge every legal native certificate, violating P2-C3. Conversely, arbitrarily expensive padded accepted certificates say nothing about the minimum W_R, actual SAT decision complexity, or all-proof lower bounds. Node's raw text and JSON parser costs, large identifier widths, compact affine rows, extension variables, zero-cost closures, branching, learning, reconvergence and recomputation remain separate admissible resource questions.
