\section{Verified grammar and notation}
Input length $N$ includes original unary/binary clauses and GF(2) affine equations, source IDs, and a claimed or discovered module-tree description. A deterministic source authenticator verifies once-only constraint ownership, each constraint's scope inside its owner bag $V_t$, and running intersection (all occurrences of each variable form a connected set of bags). At node $t$ let $S_t=V_t\cap V_{p(t)}$ be the parent separator (empty at the root), $s_t=|S_t|$, and $e_t$ the coefficient rank of \emph{original} owned affine rows. Contradictory affine rows are detected, not silently dropped. Let $R_t\subseteq\{0,1\}^{S_t}$ be its \emph{exact} subtree feasibility relation. Child $u$ is good when the fully computed $R_u$ is recognized and verified exactly 2CNF-definable; every other child is exceptional, and its full table is retained. Write
\[
 E_t=S_t\cup\bigcup_{u\text{ exceptional child}}S_u,
 \qquad h_t=|E_t|.
\]
The union is a set of physical variable names and counts overlap once.

\begin{lemma}[Exact table-to-2CNF recognizer]
For any explicit Boolean relation $R$ of arity $s$, conjoin all unary/binary clauses true on every row of $R$, including an empty clause if the table is empty. The resulting formula $C_R$ defines $R$ if and only if $R$ is 2CNF-definable. A deterministic equality check over all $2^s$ assignments takes $2^s\operatorname{poly}(s)$ time.
\end{lemma}
\begin{proof}
All retained clauses hold on $R$. Conversely, if some 2CNF $C$ defines $R$, each clause of $C$ holds on $R$ and appears in the complete retained list, so $C_R$ entails $C$ and has no additional satisfying tuples. Equality is then exact. The reverse direction is immediate by exhibiting $C_R$.
\end{proof}

\begin{theorem}[Hybrid exact exceptional-union composition]
Given a source-authenticated running-intersection module tree of polynomial total encoded size, one fixed deterministic controller exactly decides SAT or UNSAT and reconstructs an original SAT witness in
\[
 \boxed{D(N)+\operatorname{poly}(N)
 \sum_t \left[2^{h_t}(N_t+1)^{O(e_t+1)}
 +2^{s_t}\operatorname{poly}(s_t+1)\right],}
 \tag{1}
\]
where $D(N)$ charges discovery/verification, and $N_t$ is the physically encoded local source plus compiled good-child clauses. Peak writable storage is bounded by a polynomial work buffer plus $O(N\sum_t2^{s_t})$ bits for exact separator rows and witness pointers. If $D(N)=\operatorname{poly}(N)$, there are polynomially many modules, local $e_t\le e_0$ for fixed $e_0$, and $s_t,h_t=O(\log N)$ for all nodes, the entire controller is polynomial-time and polynomial-space even with linear full shared interfaces.
\end{theorem}
\begin{proof}
Process nodes bottom-up. Absorb each exact good child relation into the owner's 2CNF using the previous lemma. Retain every exceptional child relation as a complete table. Enumerate all assignments $\alpha$ to the \emph{union} $E_t$, discarding a choice if its restriction to any exceptional child separator is absent from that child's exact table. Otherwise pin $\alpha$ by unary 2CNF constraints and apply the known deterministic 2CNF-plus-codimension-$e_t$ affine solver to the owner's original affine rows, owner's 2CNF and good-child constraints. Pins and absorbed good messages add \emph{no} affine rows, so the rank remains bounded by $e_t$. A successful local model projects to one feasible row of $R_t$; test this full relation for exact 2CNF-definability and store its table, compiled constraints if any, and reconstruction pointers. By running intersection, different child-subtree private variables are independent after conditioning on their parent edge separators, and each source constraint is owned exactly once. Thus a local model passing all child-message checks glues to a global extension, while any global extension produces an enumerated $\alpha$ and passes the same tests. Exactness follows by induction. The root's empty tuple is feasible exactly when the original source is satisfiable. On SAT, replay stored models and check every original source constraint. On UNSAT, all finite attempts have been deterministically exhausted; neither side is supplied as an oracle bit.

There are at most $2^{h_t}$ local calls at node $t$, including failed attempts and all discovery; each has cost bounded by the known $(N_t+1)^{O(e_t+1)}$ fixed-codimension method times polynomial bit bookkeeping. Full table compilation costs $2^{s_t}\operatorname{poly}(s_t)$, all source reads and storage costs are charged in (1), and all stored tables/witness pointers are polynomially bounded under the stated caps.
\end{proof}

\section{Smallest falsifier and constructive controls}
In a star, the centre owns one rank-one affine equation
\[
 \bigoplus_{i=1}^q(x_i\oplus y_i)
 \oplus \bigoplus_{j=1}^h(a_j\oplus b_j\oplus c_j)=\beta.
\]
Each equality leaf owns $x_i\oplus y_i=0$ and sends a good binary 2CNF equality relation. Each odd-parity leaf owns $a_j\oplus b_j\oplus c_j=1$ and sends a bad ternary relation, since coordinatewise majority of $001,010,100$ is $000$, which is not odd parity. Every module has original affine rank one, all edge separators have width at most three, and the centre has full shared interface size $2q+3h$ but exceptional union size $3h$. The star is SAT precisely for $\beta=h\bmod2$. At $q=32,h=1$, the test source has 67 full shared names, only three exceptional names, and 140 actual local solver calls. Taking $h$ arbitrarily large gives $2^{3h}$ attempted union assignments under this specific controller. Thus edge width three does \emph{not} imply a polynomial guarantee for \emph{this method}, but does not prove algorithm-independent hardness.

Two odd-parity children on the same three variables have total individual separator widths six but a union of only three. If the centre pins all three variables to zero, the complete source is UNSAT. Both individual children remain satisfiable, so loss of their joint constraints would be unsound.
