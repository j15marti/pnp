\section{Four falsifiers and the target interface}
The selected target is the two-level \emph{source dependency} obligation, not a general SAT runtime lower bound. Before committing to this bridge, the candidate falsifiers were: 
\begin{description}
\item[] H1: Fully sensitive source signs force a two-level preprocessing/probe/output-size inequality. \textbf{PROVED/EXACT restricted}.
\item[] H2: The same barrier disappears under signed exact-$(4,4)$ source promises. \textbf{FALSIFIED}: source-audited matched two-sign SAT neighbors establish a half-sized bound.
\item[] H3: Output-length shrinkage is impossible for arbitrary semantic reductions. \textbf{FALSIFIED}: global OR of an easy sensitive promise produces one output bit, but reads all input bits.
\item[] H4: Small local per-bit probes can be composed while ignoring construction/metadata probes. \textbf{FALSIFIED as an inference}: the distinct $p_1$ and $p_2$ terms are load-bearing.
\end{description}
Neither the bounded locality of any arbitrary solver nor the output's fixed layout is assumed free: these are explicit \emph{restricted hypotheses} to be checked against actual compilers.

\section{Exact adaptive two-level interface}
Fix a valid original source $x^0\in\{0,1\}^N$ with label $f(x^0)=0$ and $m$ separately addressable sign coordinates $J$ such that flipping each one yields a legal source with label $1$. A first uniform deterministic program constructs a shared descriptor $D_1$ from the original input using at most $p_1$ source probes \emph{along the baseline}. Subsequently, an indexed request for any of its $L_1$ virtual child bits uses at most $q_1$ additional original source probes along the baseline. A second deterministic program constructs its shared descriptor $D_2$ using at most $p_2$ first-level child-bit requests. It then produces each of its fixed $L_2$ final output bits using at most $q_2$ first-level requests. Neither layer receives uncharged advice, unlogged caches, direct source oracles bypassing the accessors, or variable output lengths on the tested neighbor promise. All headers and source-dependent tags are logically counted as final bits or explicitly descriptor-produced fields. The final child language label agrees with the original label on the tested neighbors.

\begin{theorem}[Two-level sensitivity covering, PROVED/EXACT]\label{th:cover}
With these exact quantified interfaces and one deterministic realization at both levels,
\[
\boxed{m\le p_1+q_1p_2+q_1q_2L_2.}\tag{1}
\]
More generally, if there are $b$ pairwise disjoint subsets of source coordinates $E_1,\ldots,E_b$ such that each legal change $x^0\oplus{\bf 1}_{E_i}$ reverses the language label, then
\[
\boxed{b\le p_1+q_1p_2+q_1q_2L_2.}\tag{2}
\]
These quantify the baseline source-read union, not hypothetical queries or cross-machine time/space.
\end{theorem}
\begin{proof}
Run $D_1(x^0)$, then $D_2$ against the virtual $R_1(x^0)$, and generate \emph{all} final $L_2$ bits. Record every distinct original source address actually inspected, including descriptor construction, failed or repeated requests, and cached value acquisition. Their union $Q$ has cardinality at most $p_1+q_1p_2+q_1q_2L_2$. If a sensitive coordinate $j\notin Q$, flip $j$ and couple the deterministic computations step by step. Every probed bit agrees, hence the descriptor, branching, virtual addresses, caches, output bitstrings and final child language labels agree. This contradicts both-label correctness. Thus $J\subseteq Q$, yielding (1). For a disjoint neighbor set $E_i$, if $Q\cap E_i=\emptyset$ the same coupling contradicts its reversed label. Distinct disjoint sets need distinct inspected coordinates, so $b\le|Q|$ and (2) follows. Adaptive query order is explicitly permitted.
\end{proof}

\begin{corollary}[Source-local length exponent surface]\label{co:surface}
For the connected signed-(4,4) prism source with ordinary one-sign SAT neighbors, if
$p_1=N^{\pi_1+o(1)}$, $q_1=N^{\alpha_1+o(1)}$, $p_2=N^{\pi_2+o(1)}$, $q_2=N^{\alpha_2+o(1)}$, and $L_2=N^{\lambda+o(1)}$, then
\[
\boxed{\max\{\pi_1,\alpha_1+\pi_2,\alpha_1+\alpha_2+\lambda\}\ge 1.}\tag{3}
\]
The exponent conclusion survives the signed exact-$(4,4)$ promise using its $m/2=12h$ disjoint balanced SAT-producing sign-pairs. In particular, if $p_1+q_1p_2=o(N/\log N)$ and $q_1q_2=N^{o(1)}$, then $L_2\ge N^{1-o(1)}$.
\end{corollary}
\begin{proof}
The source has $m=24h=\Theta(N/\log N)$ distinct sensitive positions and $m/2$ disjoint sensitive signed-promise pairs. Equations (1)--(2) respectively force the claimed input union. If all three exponent terms on the right were strictly below one, their sum would be $N^{1-\epsilon+o(1)}$ for some fixed $\epsilon>0$, contradicting the corresponding left side $N^{1-o(1)}$. The subpolynomial statement follows by rearranging (1).
\end{proof}

\section{Independent finite controls, limitations and exact statuses}
A zero-dependency Python reproducer reconstructs the connected odd-charge prism-Tseitin source and evaluates every original/mutant 3CNF against the complete $2^{3h}$ truth table via independently built assignment bitsets. For $h=3,4,5$, it checks $(N,m,b)=(448,72,36),(568,96,48),(688,120,60)$, all $m$ one-sign SAT mutations, all $b=m/2$ disjoint paired-sign SAT mutations, proper ternary clauses and unchanged signed exact-$(4,4)$ counts on paired mutants. This independently corroborates Role 1's source theorem by a different finite method, not by replaying its algebraic solver. Six other tests exhaust \emph{all} inputs to two genuine Boolean group-OR layers for $m=8,10,12$ and block widths $(q_1,q_2)=(2,2),(3,2),(4,3),(2,3),(1,4)$. They preserve both labels (zero versus nonzero) and attain $L_2=\lceil m/(q_1q_2)\rceil$, showing tightness up to ceilings. A global one-bit OR with $q_1=m$ defeats any claimed unconditional output-length floor without contradicting (1). There were \textbf{36,423 deterministic assertions, zero failures}, seed not applicable.

\textbf{Scope:} these are Boolean bit-view controls and connected original SAT source neighborhoods, \emph{not} a pair of instantiated ordinary-SAT descendants that each preserve syntax, nor FLMV transition measurements. Fixed output length/layout, complete descriptor/probe charging and semantic locality are \emph{hypotheses}; arbitrary source-dependent compilers may use a large global computation to compress. On M1 the source is initially on the tape and $P_1\ge N$; on Mk each required source probe incurs actual input-head motion; on FLMV RAT the source index and erasable index-tape bit-time must be paid. No bound here upgrades sequential head reversals to RAM, converts SAT guessing into deterministic certificate acquisition, or mixes two machines' exponent coordinates.

\paragraph{DUPLICATION/CONTRADICTION AUDIT.} Earlier CLAUSE-LENGTH130 and PINNED131 proved an output floor for particular explicit compilers; Role 1 ARC191 supplied the connected bit-sensitive source, and source-dependency-cone work supplied locality diagnostics. New here is the \emph{combined two-level} $p_1,q_1,p_2,q_2,L_2$ necessary covering condition with adaptive cached accessors, matched ordinary and quota-preserving sign-neighbor controls, and a quantitatively explicit exponent surface. The old source sensitivity and signed matching are not credited as new. A nonlocal solver computes a global OR on an easy promise and escapes the restricted bound, so no arbitrary SAT runtime conclusion follows.
