\section{PROPOSE: exact missing lemma}

\section{Canonical syntax and theorem}
For every integer $q\ge2$, write indices modulo $q$, introduce variables $A_{r,c},B_{r,c},C_{r,c}$, and use four clauses per cell:
\begin{align*}
D^0_{r,c}&=(A_{r,c}\vee B_{r,c}\vee C_{r,c}),&
D^1_{r,c}&=(A_{r,c}\vee B_{r+1,c}\vee C_{r,c}),\\
D^2_{r,c}&=(\neg A_{r,c}\vee\neg B_{r,c}\vee\neg C_{r,c+1}),&
D^3_{r,c}&=(\neg A_{r,c}\vee\neg B_{r+1,c}\vee\neg C_{r,c+1}).
\end{align*}
Call the conjunction $F_q$. It is proper and connected, with $n=3q^2$ variables and $m=4q^2$ clauses. Every variable occurs exactly twice positively and twice negatively. The assignment $A=1,B=C=0$ satisfies all clauses.

Translate each clause $\ell_{j1}\vee\ell_{j2}\vee\ell_{j3}$ to a \emph{single atomic gadget} with private selectors $s_{j1},s_{j2},s_{j3}$, the affine equation
$\ s_{j1}\oplus s_{j2}\oplus s_{j3}=1,$
the three selector at-most-one binary clauses, and the three binary implications $\neg s_{ji}\vee\ell_{ji}$. Projecting its selectors recovers the source clause exactly. Selector triples are disjoint across clauses, so every collection of $p$ owned gadget parity rows has coefficient rank exactly $p$.

A \emph{clause-atomic module tree} is any tree $T$ assigning each whole gadget to exactly one module; each module bag contains all three original variables of every owned source clause, and occurrences of each original variable across module bags form a connected subtree. Extra transit names may appear. Let $p_t$ be the number of source gadgets at node $t$, let $X_t$ be its original-variable bag, and let $B_t\subseteq X_t$ contain \emph{every} original variable also appearing in another module bag. Put $b_t=|B_t|$ and $e_t=\operatorname{rank}(\text{owned gadget XOR rows})=p_t$. Here $b_t$ is the \emph{full shared interface}, not merely the parent edge separator.

\begin{theorem}[Atomic rank--interface tradeoff]\label{thm:tradeoff}
For all $q\ge2$ and every such clause-atomic running-intersection module tree for $F_q$, there is a node $t$ with
\[
\boxed{\qquad b_t+3e_t\ \ge\ q.\qquad}
\]
Consequently, if all $e_t\le E(q)$, then some $b_t\ge q-3E(q)$; and if all $b_t\le B(q)$, then some $e_t\ge(q-B(q))/3$. Under unpadded physical source encoding $N=\Theta(q^2\log q)$, no unbounded family with both $\max e_t=O(1)$ and $\max b_t=O(\log N)$ fits this exact clause-atomic grammar.
\end{theorem}
\begin{proof}
The primal graph contains a subdivision of the ordinary $q\times q$ grid. A horizontal grid edge $A_{r,c}$ to $A_{r+1,c}$ is routed through $B_{r+1,c}$ using types $D^1$ and $D^0$; a vertical edge $A_{r,c}$ to $A_{r,c+1}$ is routed through $C_{r,c+1}$ using types $D^2$ and $D^0$. Choose only nonwrapping edges. All internal $B$ and $C$ vertices in those paths are distinct.

Consider the family of connected row--column crosses in the resulting subdivided grid. Every pair of crosses intersects. Any set of fewer than $q$ vertices misses one entire grid row and one entire grid column and hence fails to hit their cross. The bag subtrees meeting each cross pairwise intersect, so by the Helly property of tree subtrees there is a single bag meeting all crosses. Thus any tree decomposition of the primal graph has a bag with at least $q$ original variables.

The bags $X_t$ form precisely such a tree decomposition: each source-clause scope is in its owner bag, and running intersection holds by assumption. Hence some $X_t$ has $|X_t|\ge q$. Any original variable in $X_t$ that does not occur in one of the $p_t$ owned source clauses must occur in a clause owned elsewhere, so it lies in $B_t$. At most $3p_t$ other original names can occur in owned clauses. Therefore $|X_t|\le3p_t+b_t=3e_t+b_t$, proving the displayed inequality. The two asymptotic consequences follow immediately.
\end{proof}

\section{Architectural polarity, exact work, and machine models}
The result constrains the specified \emph{atomic selector-gadget}\slash\emph{full-interface-table} implementation. It does not apply to splitting or recompressing gadgets, arbitrary formula rewrites, arbitrary 2CNF-defined child messages, alternative semantic interfaces, or algorithms which do not explicitly compute all interface rows. In particular these $F_q$ inputs are easy SAT instances and give no decision lower bound. The rank $e_t$ is the \emph{original owned affine-row rank}, not a claim that the full mixed system cannot be simplified or that its local solver needs $N_t^{\Omega(e_t)}$ work.

For the previously proved full-table architecture, the row-output mass is $W=\sum_t2^{b_t}$. If $e_t\le E$ at every module, Theorem~\ref{thm:tradeoff} forces $W\ge2^{q-3E}$; a literal full table generator requires at least this many row examinations, and an explicitly materialized table needs at least that many output bits. This is a restricted \emph{implementation} lower bound. If $b_t=O(\log N)$ instead, the theorem forces a local rank $e_t=\Omega(q)$; the known $N^{O(e_t)}$ solver supplies no polynomial-time guarantee, but no lower bound on its true runtime follows.

Source length is $N=\Theta(q^2\log q)$ bits, and the fully materialized selector translation has $m$ affine rows, $6m$ binary clauses, $3m$ new selectors, and length $N_G=\Theta(q^2\log q)$. It is a same-order expansion, not an $N^\lambda$ contraction. A straightforward fixed-multitape compiler has conservative $O(N^2)$ time and $O(N)$ writable output footprint. The stipulated single-tape simulation yields $O(N^3)$ time and $O(N)$ total physical footprint including the input. A fixed two-writable-tape compiler has polynomial time and linear total physical storage; a fixed universal machine incurs a model-specific polynomial simulation overhead not numerically certified here. Indexed RAM may access canonical fixed fields directly under stated word-size assumptions, but tape-based crossing or row-count claims are not RAM SAT lower bounds. All queries to retained source or ancestors must be charged in other architectures.

For one-variable source branching, neither child is guaranteed to shrink beyond $n-1$ source names; for any fixed $p>0$, $2(n-1)^p>n^p$ eventually, so the previously proposed two-child $n^p$ potential does not certify polynomial total search. A rank of polynomial \emph{bit length} could still have exponentially large numerical value; only a polynomial-value strictly decreasing rank with paid transitions can bound steps polynomially.
