\paragraph{PROVED/EXACT: minimax image theorem.}
Let $L:G\to V$ be a homomorphism of finite groups with kernel $K$, and let $A\subseteq G$ be any nonempty accepted set. Then
\[
|L(A)|\ge \left\lceil\frac{|A|}{|K|}\right\rceil.
\]
Moreover this is the \emph{best possible lower bound using only $|A|$ and $|K|$}. For every feasible cardinality $a\le |G|$, choose $q=\lceil a/|K|\rceil$ kernel cosets and fill $q-1$ completely plus the required number of points in the last coset. The resulting set has size $a$ and image size exactly $q$. Hence
\[
\boxed{\min_{A\subseteq G,\ |A|=a}|L(A)|=\left\lceil a/|K|\right\rceil.}
\]

Equivalently, no collision-entropy, additive-energy, coding, or PQ argument that uses only accepted-set cardinality and kernel dimension can improve the generic image lower bound. Any stronger conclusion must use additional structure of the actual accepted set, such as affine restrictions, pseudorandomness across cosets, local-test constraints, or an explicit anti-concentration theorem.

For $G=\mathbb F_2^\ell$ and rank-$r$ $L$, $|K|=2^{\ell-r}$, so the exact minimax bound is
\[
|L(A)|\ge\left\lceil |A|2^{-(\ell-r)}\right\rceil.
\]
Therefore the established bad-rank counting threshold $|L(A)|>2^{\kappa+M}$ can be forced from cardinality and rank alone only when
\[
\boxed{|A|>2^{\kappa+M+\ell-r}.}
\]
This condition is also sharp at the level of those two parameters.
