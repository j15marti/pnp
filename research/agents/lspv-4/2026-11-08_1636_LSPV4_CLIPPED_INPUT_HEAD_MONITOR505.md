## IDEA and falsifiers set before searching

**Hypothesis:** An unbounded indexed INPUT coordinate need not force a corresponding indexed WORK mask or unbounded private address register if the binary INPUT is physically present and its end is distinguishable by blank. Track only source-near INPUT head positions and a FAR sentinel; recover the exact coordinate after a long sequential return into the source. This should preserve observed source symbols and their read-position set, with total recovery work amortized against actual guest INPUT moves.

Falsifiers: (F1) an indexed INPUT jump to a huge position can return to the source without an intervening detectable native indexed jump or at least M sequential steps; (F2) a guest index write erases/changes the INDEX digits before the monitor can update its bounded summary; (F3) an arbitrary source byte or malformed binary input has an internal blank interpreted as an end marker; (F4) storing the footprint or recovering coordinates silently requires an address-dependent WORK high-water or an uncharged guest restart. A separate cache-soundness falsifier is mismatched child lengths: a blank read in one source can be nonblank in another. We therefore require equal authenticated lengths for any source-mask comparison.

## ITERATE: source-near sentinel theorem (PROVED/RESTRICTED)

Fix a deterministic fresh-start guest B running for T>=1 steps on a **physically present** read-only binary INPUT string of exactly M>=1 bits in positions 1,...,M (all other cells blank). Its INPUT head starts at position 1. The original indexed random-access operations and INDEX tape semantics are retained. We can instrument its complete run and collect the set R of INPUT coordinates it actually observes at positions 1,...,M, while preserving B's exact output and every guest-visible transition, with an additional source read-mask at WORK high-water at most M. The total additional time is O(M + T polylog(M+T)), including scanning, marking, INDEX summaries and source discovery. Extra writable high-water is O(M+log(T+M)); guest space S_B is charged simultaneously, yielding the conservative whole-program bound O(max{M,S_B,log(T+M)}). Constants depend on the fixed guest program. The argument makes **no** claim of small trace archives, source transformations or universal solver contraction.

**Construction.** Before running B, find M by one sequential INPUT scan and return its head to 1, using a binary O(log M) counter. Retain a source-read bit mask with exactly M slots on a new non-index WORK tape. Track the guest INPUT head exactly while its coordinate j<=2M; when j>2M, keep only a FAR sentinel while leaving the actual physical INPUT head at its true position. All native INPUT indexed moves to absolute j are decoded before the associated INDEX tape is erased. The guest's INPUT-INDEX tape is never modified by instrumentation: maintain the low B0=ceil(log2(2M+1)) bits of its indexed address plus the count of nonzero digits above that cutoff, updating on each guest index-digit write and resetting on the actual native erase. The INDEX head position (moved sequentially) and high-bit count use O(log(T+2)) writable bits. This permits testing j<=2M without materializing an astronomical coordinate in WORK memory. When j<=2M, retain the exact j in O(log M) bits.

On a sequential guest INPUT move, update j if near, or retain FAR if far. Since every native step reads the current INPUT symbol, the first read of 0/1 while FAR detects a return to the original source. Recover j by temporarily scanning left to the input boundary at position 0 and then exactly j steps right, restoring the guest INPUT head without changing guest state; this costs at most 2M extra INPUT transitions and O(log M) count bits. Each such FAR->near recovery needs at least M native unit INPUT moves after the preceding entry into FAR, since FAR started strictly beyond 2M and the source ends at M. Indexed jumps back to the source are recognized directly and need no scan. The intervening intervals are disjoint; thus the **total** re-entry scans cost O(T). When in-source, write a bit at its j-th mask coordinate through a fully charged O(log M) INDEX construction and an indexed WORK write. The mask is physically charged to high-water M, not to the number of set bits.

**Proof.** Induct on guest transitions: in near mode, stored j is exact; in far mode, the actual source cell is blank until a native indexed jump (whose target is decoded) or a detected sequential return. A return from beyond 2M cannot reach <=M in fewer than M unit moves. The recovery scan restores the guest head and gives exact coordinate, so every input symbol, guest control transition and mask mark agrees with the original run. The amortization above bounds extra time. The guest INDEX tape itself executes the same writes and mandatory erasures; a finite product-control machine can maintain the low-bit/high-count summary using polylogarithmic transition overhead and O(log(M+T)) private scratch. All extra tapes are disjoint and the guest is never restarted. QED within the specified native instruction semantics and standard asymptotic bounded-counter implementation.

**Limits and red-team controls.** (1) The claim concerns one fresh-start full run, NOT an arbitrary previously checkpointed suffix with an unknown initial INPUT head or arbitrary WORK live-ins. (2) To reuse an anchor trace on another source, verify equal authenticated length M and agreement on every anchor-read position; otherwise a read beyond the shorter source could be blank only there. WORK first-read-before-write live-ins, control, head positions and assumption contexts must ALSO match, per LSPV-2/505. (3) Only ONE mask has O(M) footprint; K retained masks cost O(KM), and an arbitrary stored trace may require Omega(T) bits. (4) For virtual/lazy child INPUT, each temporary recovery scan invokes its transducer and must be charged; no O(1) virtual reads are assumed. (5) The asymptotic bound is mathematical compilation accounting, NOT a native FLMV interpreter measurement, and does not resolve [P2-A2]/[P2-A5]. (6) An arbitrary guest's non-index WORK high-water is still counted; sparse improvements require independent legal compilation proofs. (7) Guest input syntax may be malformed, but the physical INPUT alphabet remains binary 0/1 and blank outside the supplied length.
