\section{Receiving obligation, primary sources, and three falsifiers}
The desired theorem is an all-input existential closure of the jointly achievable exponent region
\[
 E=\{(t,s):\exists \text{ one fixed uniform total exact SAT random-access TM }A,\quad
 T_A(N)\le N^{t+o(1)},\ S_A(N)\le N^{s+o(1)}\}.
\]
A cofinal finite sequence of achievable simultaneous pairs entering the published FLMV forbidden region would contradict \(P=NP\), but no such transition is known. One machine must jointly witness the time and space of each pair. The published endpoint at \(c_*=241/200\) is \(\beta(c_*)=11642479/23232400>1/2\), where
\(\beta(c)=((c+2)/c^2-c)/2\), with strict model-matched transfer margins \cite{flmv}. The previously used universal product condition involving \(2\cos(\pi/7)\) remains \textbf{FALSIFIED/RETIRED}.

This run tests three mechanisms. \textbf{M1, FALSIFIED as unrestricted transport}: the full-rank named SAT relation and the \(p\)-pass fooling-set lower bound of NAME-ONLY-MULTIPASS93 compel large workspace in the FLMV indexed-input model. \textbf{M2, PROVED/EXACT restricted}: a fully charged, fixed-program, indexed merge decides both labels with \(O(\log N)\) writable bits and near-linear bit work on exactly that canonical sorted family. \textbf{M3, PROVED/EXACT restricted}: even losing the sorted-name promise leaves a source-aware \(O(\log N)\)-space, polynomial-time pairwise-comparison algorithm for the larger valid signed-unit-gadget class. \section{Exact ordinary proper-3CNF and encoding}
For even \(q\ge2\), let \(A,B\subseteq[q]\) have \(|A|=|B|=q/2\). For each block \(j\) introduce distinct auxiliary names \(u_j,v_j\). With \(\ell\) a signed primary literal, write
\[
\operatorname{Pin}(\ell;u,v)=
(\ell\vee u\vee v)(\ell\vee u\vee\neg v)
(\ell\vee\neg u\vee v)(\ell\vee\neg u\vee\neg v),
\]
where juxtaposition denotes conjunction. The original \(J_q(A,B)\) consists of the \(q/2\) positive blocks \(\operatorname{Pin}(x_a;u_j,v_j)\), \(a\in A\) in increasing order, and then \(q/2\) negative blocks \(\operatorname{Pin}(\neg x_b;u_j,v_j)\), \(b\in B\) in increasing order. Helper IDs are \(q+2j-1,q+2j\). No helper is functional. Each block has four proper ternaries with three distinct variables. All signs, clause placements, helper IDs, headers and record width are fixed; only primary identifier fields encode \(A,B\).

As proved in NAME-ONLY-MULTIPASS93,
\[
 n=3q,\quad m=4q,\quad w(q)=\left\lceil\log_2(64(7q+1))\right\rceil,\quad
 N_q=(16q+2)w(q)=\Theta(q\log(q+2)),
\]
\[
 \SAT(J_q(A,B))\Longleftrightarrow A\cap B=\varnothing
 \Longleftrightarrow B=[q]\setminus A,
 \qquad
 \#J_q(A,B)=2^{2q}\mathbf1[A\cap B=\varnothing].
\]
The compatibility matrix on balanced subset pairs is a permutation matrix of rank \(\binom q{q/2}\) over every field. Its rank is a property of that represented relation, not mandatory machine workspace.

\section{Indexed random-access counterstrategy}
\begin{theorem}[PROVED/EXACT: recognized sorted source]
There exists one uniform deterministic exact \emph{promise-family} decision procedure \(M\), implemented in the FLMV-style indexed read-only input/charged work-and-index-tape model, that on \emph{every} \(J_q(A,B)\) decides its SAT label in
\[
 T_M(N)=O(N\,\operatorname{polylog}N),\qquad S_M(N)=O(\log N)
\]
elementary bit work and peak writable/index bits. The procedure knows neither the source label nor its name sets without paid acquisition. If extended to arbitrary ordinary SAT inputs with an exact unrestricted fallback, it is total but has no asserted polynomial all-input bound.
\end{theorem}
\begin{proof}
Derive candidate \(q\) from a charged inspection of the two source headers. Verify \(q\) is even, \(n=3q,m=4q\), the expected total word count \(16q+2\), the canonical width \(w(q)\), and for each of the \(q\) blocks all four clauses, ternary arities, signed primary literal fields, ordered private helper fields, block polarity, legal primary range and strict within-half ascending order. The certifier computes source offsets and compares fields using fixed counters and \(O(\log N)\) work/index bits. It accepts exactly the declared grammar and pays for reading every source word and bit used by each comparison.

After acceptance, maintain two \(O(\log N)\)-bit indices \(i,j\) into the two sorted halves, initially zero. Read their \(w\)-bit primary names at indexed source locations
\[
 3+16i,\qquad 3+16(q/2+j)
\]
for the declared zero-based word numbering (two header words, sixteen words per four-clause block). Let the names be \(a,b\). If \(a=b\), reject as UNSAT. If \(a<b\), increment \(i\); otherwise increment \(j\). If either pointer reaches \(q/2\) without equality, accept as SAT. Every comparison either detects an intersection or increases one pointer, so at most \(q-1\) comparisons and \(2(q-1)\) independent name dereferences occur. Indexed tape address preparation, returns, decoding, comparisons, controller state and output are all charged and fit \(O(\log N)\) writable bits. The verification scan and merge together use \(O(N\,\operatorname{polylog}N)\) bit work. Sorted-list intersection correctness and the preceding SAT equivalence establish both labels. No proof system, model-count table, witnesses, DNNF or family of child SAT calls is required.
\end{proof}

\begin{theorem}[PROVED/EXACT: unsorted extension]
Consider all signed-unit Pin-gadget formulas with \(q\) positive/negative blocks, legal primary IDs \([q]\), fixed private helper structure, but arbitrary primary block order and repetitions. Their SAT label is still equivalent to the \emph{absence} of a primary name occurring in both polarities. A fixed deterministic source-indexed controller verifies the gadget syntax and decides the label in \(O(N^2\operatorname{polylog}N)\) charged bit work and \(O(\log N)\) writable bits.
\end{theorem}
\begin{proof}
For each positive block reread and compare its primary name with each negative block, using two nested indexed counters; reject on any equality. If there is none, assign every positive-name variable true and every negative-name variable false, with arbitrary values on the remaining primaries and all helpers. Each Pin forces its literal and leaves its two helpers free. Conversely a repeated name with opposite polarity would require both Boolean values. There are \(O(q^2)\) indexed name comparisons, each with \(O(\operatorname{polylog}N)\) bit overhead. The fixed grammar validator uses only logarithmic counters. Repeated names within a single polarity impose no inconsistency. This extension is an \emph{upper} bound, not evidence of a mandatory sorting or memory cost.
\end{proof}

\section{Why the preceding multi-pass lower bound remains valid}
For one forward-only pass the two source halves are held by different communication parties. The previous theorem
\[
 (2p-1)(B+c_M+2)\ \ge\ \log_2\binom q{q/2}\ \ge\ q-\log_2(q+1)
\]
holds whenever \(p\) is an a priori maximum number of complete \emph{forward sequential} passes and \(B\) counts all portable state. The indexed algorithm performs alternating seeks between early- and late-half addresses, potentially \(\Theta(q)\) such alternations. Its source-access pattern is not representable by a constant number of forward passes; simulating it by complete sequential rewinds would change the resource accounting and may cost \(\Theta(q)\) passes. There is therefore no conflict between the two theorems.

The semantic rank is exponential in \(q\), but the same fixed relation has a compact source-readable intersection test. A boundary matrix rank is a lower bound for communication under a declared channel, not a lower bound on arbitrary indexed-SAT time, required cached states, circuit gates, switches or temporal bit flips. A hypothetical ARC compiler that first constructs a representation from arbitrary high-width input must charge that construction. The source-recognized subset here cannot establish a universal closure of \(E\).

\section{Adaptive state and BIT-RESOURCE1 ledger}
The complete state vector for the tested procedure has source format and current source addresses, acquired \(q,w,n,m\), two name offsets and decoded names, current recognizer/merge/nested-scan mode, counters, failure flag, optional witness-write progress and remaining resource budget. At \emph{entry}, the true SAT/UNSAT label, validated grammar, sortedness and source names are unavailable. The rule selector tries charged Pin grammar/sortedness verification, considering general SCC, Horn, affine and direct DPLL as alternative exact subroutines. Failed recognitions are paid and enter an exact fallback for unsupported ordinary CNF. A valid sorted member selects indexed merge. An unsorted but valid gadget member may select nested indexed comparisons. The post-state after a merge either contains a witnessed name collision (UNSAT) or disjoint scanned name lists (SAT); a SAT witness may be streamed if independently demanded, with output length paid. One-bit decision emits only one bit.

Maintain distinct quantities
\[
 (U,R_{\rm src},R_{\rm work},W_{\rm work},\Delta_{\rm complete},
 S_{\max},\mathrm{BT},|P|,|R|),\qquad
 \mathrm{BT}=\sum_{\text{actual steps }t}S_{\rm live}(t).
\]
\(U\) counts elementary work including source/space reads and \emph{unchanged} writes, index arithmetic, grammar acquisition, policy evaluation, failed tests, source rereads and machine control. The read-only source is excluded from counted writable space as in FLMV; input addresses, work/index tapes, cached names and auxiliary state are counted. There is no ordinary child generated, no retained ancestor, no free external cache and no uncharged readable output. The complete-machine flip count \(\Delta_{\rm complete}\) is not identified with set-mask flips, selected source bits or output bits. A source-aware controller has \(S_{\max}=O(\log N)\); its true bit-time has the valid upper bound \(O(U\log N)\) if the chosen counted live-bit measure charges the complete \(O(\log N)\) writable footprint at each step. These are analytic upper bounds in the declared model; Python counters do not measure physical FLMV transitions or flips.
