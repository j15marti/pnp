## IDEA and predeclared falsifiers

**Hypothesis:** A completed deterministic UNSAT trace on an authenticated odd-charge original Tseitin 3-CNF must query all its $D=12H$ original literal-polarity bits. Therefore a single trusted anchor's input-read cylinder excludes every one-bit SAT neighbor, and the sum of fresh, independent candidate lookups across all $D$ neighbors has the *exact* decision-tree star floor $D(D+1)/2$ source-bit probes even when the anchor's query order is freely optimized. This is an information-acquisition restriction, not a lower bound on arbitrary shared batch computation or global SAT time.

Predeclared falsifiers: (F1) an original clause is not essential, so flipping an occurrence need not produce SAT; (F2) a one-bit mutation changes grammar, literal IDs or length; (F3) two different-labeled sources can share the *same genuine completed deterministic in-range INPUT read trace* from an identical start state; (F4) the sum-of-ranks lower bound fails for a legal adaptive query order, for example because source changes before the first differing query alter a control transition.

## Established family, source grammar, theorem, model and shortcut ledger

Fix a simple connected cubic bipartite graph $G=(V,E)$, $H=|V|$, and odd-charge vector $\chi\in\{0,1\}^{V}$. For each vertex $v$ use four proper signed 3-clauses forbidding the four assignments of its incident edge variables having parity different from $\chi_v$. Each edge variable is one Boolean variable, so $3H/2$ variables, $4H$ original three-literal clauses, $12H$ signed-literal records. For the LSPV-2/495 diagonal original-source grammar, let $W=\lceil\log_2(2H+1)\rceil$ and sign-polarity be one separate bit per occurrence. The exact fixed-field encoded size is

$$
N=3H+12+12H(W+1),\qquad D=12H=\Theta(N/\log N).
$$

The original source is UNSAT by summing vertex GF(2) equations to $0=1$. On suitable established cubic-expander families, original odd-charge Tseitin has $2^{\Omega(H)}$ **ordinary DAG Resolution** proof-size lower bounds. Graphs used as finite controls here are K3,3, Q3 and Heawood, plus K4 (finite non-bipartite control). A finite graph or numerical SAT solver runtime is NOT an asymptotic hardness certificate. GF(2) summation is a polynomial-time known shortcut; efficient source-family detection, algebra, extensions and branching must remain available. No lower-bound preservation into the full fixed historical R_mix341 is asserted.

## ITERATE: critical-cylinder star theorem (PROVED/RESTRICTED)

**Theorem 506.1.** On the above fixed-field original odd-charge source $F$ with $D$ separately addressable polarity positions, assume $G-v$ is connected for each vertex $v$. Let $A$ be *any* deterministic, total, correct SAT/UNSAT/MALFORMED decider for the entire encoded proper 3-CNF domain, using read-only INPUT access; every source bit must be observed through an explicitly charged input-read transition. Let $\tau_F$ be its genuine complete INPUT read trace from the fixed fresh initial configuration. Then every one of the $D$ original polarity bits appears in $\tau_F$. In the LSPV-2/507 trace-cylinder vocabulary, no one-bit polarity SAT neighbor of $F$ lies in $C(\tau_F)$, and the cylinder fixes at least $D$ coordinates, so among all $N$-bit strings its cardinality is at most $2^{N-D}$.

Let $F^{(i)}$ for $i=1,\dots,D$ be the $D$ valid SAT sources obtained by flipping a different one of these polarity positions. When each $F^{(i)}$ is processed as an **independent fresh input call** by the same deterministic decision tree, or queried against only the single authenticated $\tau_F$ trace with no inter-query learning, the sum of distinct input-bit probes is at least

$$
\boxed{\sum_{i=1}^{D}Q(F^{(i)})\ \ge\ \frac{D(D+1)}{2}=\Omega(H^2)=\Omega\!\left(\frac{N^2}{\log^2N}\right).}
$$

This is an aggregate cost on **$D$ different source inputs**, NOT a superlinear time lower bound for any single source. An online cache that inserts SAT mutants, batch-processes sources, proves algebraic identities, or uses a different legal shared computation is NOT covered by the star sum.

**Proof.** By LSPV-4/499, every original vertex clause is essential: for any vertex $v$ and forbidden local assignment, $G-v$ connectivity makes the other $H-1$ parity equations solvable with that incident assignment. The resulting assignment violates exactly the chosen original clause. Flipping any one polarity in that clause produces another valid 3-CNF of the same size that this assignment satisfies, so each $F^{(i)}$ is SAT. Suppose an actual halting trace on UNSAT $F$ did not read polarity coordinate $i$. Source $F$ and $F^{(i)}$ then have identical observed symbols at every anchor read, so determinism implies identical transitions and output, contradicting correct opposite labels. Thus every $i$ must be read. Order the *first occurrences* of these distinct bits along $\tau_F$ as $i_1,\ldots,i_D$. On $F^{(i_j)}$ every observation before the first read of $i_j$ agrees with the execution on $F$. Hence the fresh execution must make at least $j$ distinct source-bit reads before it can diverge; other reads only increase the count. Summing $j=1,\ldots,D$ gives $D(D+1)/2$. The same prefix argument applies to a one-anchor trusted trace-cylinder lookup. Each critical bit fixed to its value in $F$ reduces the cylinder size by a factor two. QED.

**Interpretation relative to LSPV-2/507:** The favorable trie theorem is valid, but its free choice of a small authenticated-anchor set does **not** supply a worst-case sublinear lookup guarantee. This lower bound holds even when the deterministic guest is correctness-optimal about which sign bits to read and even with a perfectly authenticated anchor. It is stronger than LSPV-4/500's deliberately full-scanning guest control because *correctness forces the scans on this one UNSAT source*. It remains a direct, already-understood sensitivity-to-certificate principle, not evidence of computational hardness beyond input acquisition.

## Full resource ledger and barriers

Single trusted anchor: original source parsing/authentication and acquisition of $\tau_F$ cost at least $D$ distinct INPUT reads, with physical INDEX/head and WORK effects separately charged by the actual compiler. A self-contained explicit read event record can require $\Omega(D)$ records if it directly stores every occurrence; a specialized source-family program may reconstruct sign positions compactly, so NO universal storage lower bound is claimed. A charged trie path must query all $D$ sensitive coordinates on $F$; for the SAT one-bit neighbor star, the above single-anchor independent-lookup sum holds. Worst-case physical time also includes parsing, index-digit writing/erasure, guest simulation, source reads, output and cache lookup; this theorem only lower-bounds distinct source-bit probes. Working peak includes all simultaneous source buffers, WORK/INDEX high-water, guest state, masks, anchor/child records and failed policies; no space lower bound follows from probe count. Shared-DAG proof nodes, critical-path span under a separate parallel model, and actual implementation schedules remain distinct quantities; no R_mix341 weights are altered.
