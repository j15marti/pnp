\section*{Quantitative explicit-output barrier}
\noindent\textbf{PROVED/EXACT:} Fix a finite alphabet, one native output symbol per constant number of machine steps, and a target format explicitly listing every derived proof line. For any polynomial-size family of valid mixed PHP refutations, \emph{every} reverse compiler, even a nonuniform one, writing a complete ordinary Resolution DAG proof of the same formula must take
\[
T_{\rm writer}\ge 2^{\Omega(h)}
 =\exp\left(\Omega((N_h/\log N_h)^{1/3})\right).
\]
Indeed, the output has at least Haken's lower-bound number of lines, minus $\Theta(h^3)$ free original clauses. Even knowing the optimal output DAG cannot avoid writing its lines. This is a lower bound for an \emph{explicit proof converter}, not for arbitrary SAT decision, proof search, or machine space.

\noindent\textbf{CONDITIONAL on the Braun preprint:} Analogously any algorithm explicitly writing a Res$(\oplus)$ proof from a short authenticated mixed wide-bit-PHP proof requires
\[
T_{\rm writer}\ge
 \exp\left(\Omega\left(N_\ell^{1/3}/(\log N_\ell)^{8/3}\right)\right).
\]
Subtracting polynomially many source lines is essential. The exponent $8/3$ uses the actual variable-identifier bit cost, not merely the $\Theta(n^3\ell)$ literal count. If output is only a succinct program, its expansion no longer meets the declared explicit-proof target and the conclusion does not directly apply.
