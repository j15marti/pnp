\section*{Exact source-library theorem}
Let $Y=\{y_1,\dots,y_n\}$ be fixed witness variables. Let $H_n(Y,Z)$ be any explicitly listed CNF, with arbitrary auxiliary selectors $Z$. Each restriction $\rho:Z\to\{0,1\}$ fixes \emph{only} $Z$ and leaves \emph{every} $y_i$ unassigned and unchanged. Restriction deletes satisfied clauses and false assigned auxiliary literals, without arbitrary semantic rewriting, variable complementation, or proof-system substitution. For any nonempty proper signed clause $C$ over $Y$, define the clause-minimally UNSAT source $F_C=\{C\}\cup\{\{\neg\ell\}:\ell\in C\}$. Declaring $n$ variables, all such sources have ASCII-DIMACS size $O(n\log(n+2))$ bits.

\begin{theorem}[Fixed-witness clause-dictionary barrier]
If for every nonempty proper signed $C$ there is some auxiliary assignment $\rho_C$ with \emph{literal source equality} $H_n|_{\rho_C}=F_C$, then $H_n$ contains at least $3^n-1$ distinct original source clauses. In particular any such universal family covering all UNSAT general CNFs through encoded length $N_n=\Theta(n\log(n+2))$ requires at least
\[
3^n-1=\exp(\Omega(N_n/\log(N_n+2)))
\]
explicit clause records. It cannot be generated in polynomial $N_n$ output time. This is not a lower bound on $W_R$, decision time, proof search, or writable memory.
\end{theorem}
\begin{proof}
For each clause $D$ of $H_n$, let $D_Y$ be its fixed signed witness-literal projection. Under any auxiliary-only restriction $D$ either disappears or becomes \emph{exactly} $D_Y$. Thus any desired source clause $C$ appearing literally in some restricted $F_C$ requires a source $D_C$ with $D_{C,Y}=C$. Two different $C$ cannot use the same $D_C$. Each witness variable has three independent choices (absent, positive, negative), giving $3^n-1$ nonempty proper signed clauses. Each $F_C$ has at most $n+1$ clauses and $2n$ literal occurrences, with $O(\log(n+2))$-bit indices. This proves the bound.
\end{proof}
\begin{proposition}[Matching qualitative exponential wrapper]
An explicitly sourced UNSAT CNF of $O(n3^n)$ clauses can specialize exactly to every $F_C$ using this same interface.
\end{proposition}
\begin{proof}
Let $C_1,\ldots,C_M$ enumerate all $M=3^n-1$ clauses, and introduce selectors $z_i$. Encode exactly one true selector using a linear-size sequential prefix-OR one-hot source CNF. Add guards $(\neg z_i\vee C_i)$ and $(\neg z_i\vee\neg\ell)$ for each $\ell\in C_i$. Exactly one selected block is contradictory, so the wrapper is UNSAT. Pin all selectors and the authenticated prefix variables to the consistent unique-one pattern. All one-hot source clauses and unselected guards disappear; precisely $F_{C_i}$ survives. The guard count is $O(nM)$.
\end{proof}

\section*{Falsifiers and limits}
\begin{description}

\item[] F2: Proper width-three specialization suffers the same exponential library cost. \textbf{FALSIFIED}: it needs only $8\binom n3$ signed triple clauses; LSPV-1's 3-CNF reflection is not contradicted.
\item[] F3: A polynomial 3-CNF normalizer automatically proves B3 for general CNF. \textbf{OPEN}: equisatisfiable Tseitin auxiliaries are not a source-exact proof backtranslation. A full mixed, source-authenticated cost-preserving lift from $\mathcal N(F)$ to the \emph{original} $F$ remains necessary.
\item[] F4: Original-witness substitution, signed renaming, implicit circuits, or semantic LOCAL-CONVERT cannot evade the theorem. \textbf{OUTSIDE HYPOTHESES}: these genuinely change the interface and need separate grammar/charging proofs.
\end{description}
The theorem is a restriction on a universal \emph{wrapper source library}, not on the minimum shared logical DAG. In an explicit-output native machine, writing $3^n-1$ source clauses takes $\Omega(3^n)$ steps. Materializing the library incurs that much storage, but a stream writer may avoid it; no general writable-space lower bound is claimed. Every all-phase peak-space transfer must still use $s'\le\max\{\rho,\eta,\lambda,\lambda s\}$ with $\rho$ covering parsing, source/index/head access, materialization, conversion, output and simultaneous ancestors.
