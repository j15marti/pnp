\section{Original-clause experiment and prior firewall}
A signed occurrence $x_{i,j}$ is variable $x_i$ in original clause $C_j$ with its literal sign $\sigma_{ij}=1$ for positive and $0$ for negative. The local $S_j$ target (every literal TRUE) demands $a_i=\sigma_{ij}$; the local $U_j$ target (every literal FALSE) demands $a_i=1-\sigma_{ij}$. Inverting each produces the opposite target. This does not allocate new variables per occurrence. For distinct source clause IDs $j,k$, modes $SS,UU$ are feasible exactly when no opposite-polarity variable is shared, and $SU,US$ exactly when no same-polarity variable is shared. Ordinary source-clause SAT is $t_j(a)\ge1$, not $t_j(a)=3$. All coherent global $0^n,1^n$ statuses, multiple flip trails and complements are included in the full raw record, with $t_j(\bar a)=3-t_j(a)$ for proper 3CNF.

Prior LSPV-1 and LSPV-5 reports already established that pairwise compatible local $S/U$ unary demands have a globally consistent joint assignment, and that checking impossible joint modes cannot prune a coherent original-variable DPLL branch. That is a representation firewall and is \emph{not} presented here as a new result. The present incremental result is a complete one-round proof-carrying resolution resource bound, together with independently measured net costs.

\section{Exact proof-event theorem}
\begin{theorem}[Complete source-parent resolution classification and linear first round]
Let $C_j,C_k$ be two distinct proper original width-three clauses. Let $o_{jk}$ be the number of shared source variables occurring with opposite polarity, and $s_{jk}$ the number shared with equal polarity. A non-tautological direct resolvent from these source parents exists if and only if $o_{jk}=1$; it then has width exactly $4-s_{jk}$. For proper signed exact-$(2,2)$ width-three CNF with $n$ variables, all non-tautological \emph{first-generation source-parent proof events} number at most $4n$. Given indexed original clauses, the entire list, source-parent indices, pivot IDs, falsifying cubes, and direct RUP checks can be produced in $O(N+n)$ indexed word-RAM operations using $O(N+n\log n)$ bits for the indexed source and records, where $N$ is source encoding length. This excludes iterated resolution and tape-specific head transport.
\end{theorem}
\begin{proof}
Resolve on an opposing shared pivot. The two parents leave four literal occurrences. Any second opposing shared variable yields both $z$ and $\neg z$, making this resolvent tautological. If the pivot is the sole opposing common variable, properness excludes any further opposite pair, so the resolvent is non-tautological. Each same-sign shared variable supplies one duplicate literal, giving width $4-s_{jk}$. Every variable in the exact-$(2,2)$ source has two positive and two negative occurrences, hence exactly $2\cdot2=4$ opposite-polarity original-clause occurrence pairs. Across $n$ variables there are $4n$ candidate source pivots. Indexed occurrence arrays enumerate each in constant bounded-literal work. Direct RUP checking of a non-tautological resolvent under its negation makes the two parents the opposing units $x_i$ and $\neg x_i$, so verification with those explicit source-parent hints is constant indexed work per event. The records use $O(\log n)$ bits per literal or source index. Source parsing and representation are charged. No statement is made about a second generation or complete SAT search.
\end{proof}

An incompatible four-way source-extreme pair with $o_{jk}\ge2$ produces only tautological direct resolvents. For example $(x\vee y\vee z)$ and $(x\vee\neg y\vee\neg z)$ have no feasible extremal mode and no non-tautological original-source resolvent. For $(x\vee y\vee z)$ and $(x\vee\neg y\vee w)$, however, resolving on $y$ yields $(x\vee z\vee w)$: under $x=z=w=0$, the source parents become the contradicting units $y,\neg y$. The latter certifies a genuinely prohibited partial-assignment cube. These implications are the known Davis--Putnam resolution rule, not a claim of new inference soundness.
