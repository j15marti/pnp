## Theorem 475.1: exact static-pinned source-index Pareto (PROVED/RESTRICTED)
Fix a physical host INPUT-INDEX sequential head at position $H\ge1$. Postulate for this **specified** adapter that indexed erasure leaves the INDEX head at that location. On a cache miss, the adapter must visit the low-order INDEX position 0 to construct a nontrivial original-source aliased address, issue the indexed read and immediately restore the physical INDEX head to $H$. Charge every head movement. Let an immutable virtual child contain $d$ read-only source bits at known labels $0,\ldots,d-1$, which may vary independently across original inputs. The guest-request sequence consists of $r$ complete cycles through those labels, with $q=rd$. No guest sequential-INPUT-head movements or guest writes occur during this trace.

Choose $c\in\{0,\ldots,d\}$ labels permanently pinned in a source-bit cache, initialized empty; on a request, the adapter uses a cached value if available, otherwise performs the charged source access, and stores it iff the label is pinned. Then **exactly**
$$
M_{\rm pin}(d,c,r)=d+(r-1)(d-c)
$$
source misses and, with a deliberately prescribed $2H$-move miss protocol, **exactly**
$$
J_{\rm pin}(H,d,c,r)=2H\,[d+(r-1)(d-c)]
$$
physical INDEX-head movements occur. Every guest read returns the correct immutable bit. For $d=1,c=1$, the old /474 $2Hq$ head movement becomes **$2H$ total**, plus $O(q)$ constant-time cache accesses. One bit of source-value state (plus key/tag/controller bookkeeping) suffices.

**Proof.** The first cycle contains $d$ cold misses. After that, exactly $c$ pinned labels remain resident forever, so each subsequent cycle has exactly $d-c$ misses. Immediate-return excursion from $H$ to 0 and back requires $2H$ head moves on each such source access by the prescribed protocol. Read-only source immutability makes repeated cached values sound. QED.

**General information floor and phase-wise miss floor (PROVED/RESTRICTED).** If all $d$ bits are independent, source rereads and other reconstruction are prohibited after warmup, and the adapter's *entire* persistent data state must answer any future request, then it must distinguish $2^d$ possible source vectors; therefore it needs at least $d$ information bits (including compressed representations). Separately, for any cache holding no more than $c$ *literal values* at the start of each distinct-$d$ cycle, with no other source-dependent state, at least $d-c$ bits require acquisition during that cycle. Under the explicitly immediate-return miss protocol, that is at least $2H(d-c)$ extra head movement per cycle. This is **not** a lower bound on arbitrary caches with richer coded state, alternative head scheduling, cross-bit inference or guest-code-specific shortcuts.

**Proof.** With no source rereads, two different $d$-bit sources leading to the same persistent state would answer one differing coordinate identically, violating correctness; injectivity gives $2^d$ states. At cycle start at most $c$ of $d$ independent values are resident as literal entries, so each initially missing requested label must be acquired; any prefetch counts as acquisition. The per-miss head movement follows only from the imposed protocol. QED.

**Full charged abstract-adapter costs.** A straightforward linear-scan cache holding $c$ tagged virtual addresses takes $O(c\log(N+H+2))$ metadata bits plus $c$ cached bits (or $O(c)$ value bits for fixed public keys); per guest read lookup takes $O(c\log(N+H+2))$ ordinary bit work under a sequential implementation. Actual source acquisition includes constructing index-address bits, indexed access, index erasure, guest-head restoration, tag checking and cache insertion. A safe *abstract* upper bound for this restricted component is
$$
T_{\rm adapter}=O\!\left(q(c+1)\operatorname{polylog}(N+H+2)+2H M_{\rm pin}\right)
$$
and $S_{\rm adapter}=O(c\log(N+H+2))$ **only for the adapter's auxiliary data**. Guest WORK/INDEX contents, input parsing, child generation and validation, cache lifetimes, simultaneous ancestor/guest buffers, guest simulation, failed policies, output, source authentication, and all other physical phases are separately charged or remain OPEN. For the $d=c=1$ repeated-read witness, the additional head-movement exponent is only amortized $O(H+q)$, not $\Theta(Hq)$. The repair can fail to save space if $d$ is large; no worst-case exponent contraction is inferred.

**Scope caveats.** A large indexed non-INDEX WORK address may have physical high-water cost; INDEX-head preservation and INDEX-space accounting remain model unsettled, as in /472. For $d>1$, the abstract requested-key cycle need not be a low-time realizable native guest INDEX trace. Original source may be shorter than a chosen aliased address; in that case the machine's blank-input semantics must be checked rather than assumed. Native FLMV interpreter, arbitrary guest sequential INPUT moves, guest output and head semantics, all malformed input classes and recursive closure are **OPEN**. Zero-cache protocol is a defensible hostile test of one implementation, not evidence against the legal cached implementation.
