\section*{Original occurrences and the four extreme modes}
For each proper original clause $C_j$ and occurrence $x_{i,j}$ of one globally shared variable $x_i$, write $\nu_{ij}=1$ if it occurs negatively. The all-literals-TRUE local target $S_j$ requires $x_i=1\oplus\nu_{ij}$; its inversion, the all-literals-FALSE target $U_j$, requires $x_i=\nu_{ij}$. Inverting $U_j$ returns $S_j$. A normally SAT clause needs only one true literal, not all three. The complete raw experiment stores source indices, signed occurrences, both targets and inversions, all four $SS,SU,US,UU$ joint possibilities, $0^n,1^n$ and coherent flips with every $t_j\in\{0,1,2,3\}$. For full coherent assignments $a$,
\[
t_j(\bar a)=3-t_j(a),\quad N_s(\bar a)=N_{3-s}(a),\quad
t_j(a\oplus M)-t_j(a)=|M\cap L^0_j(a)|-|M\cap L^1_j(a)|.
\]
For source clauses $j,k$, the $SS,UU$ modes exist iff there is no opposite-signed shared variable; $SU,US$ exist iff no same-signed shared variable. Both shared-sign types forbid all four local extreme pairs, but may allow ordinary simultaneous disjunctive SAT by middle states.

\begin{theorem}[Exact sparse S/U compatibility representation]
Let $F$ be a proper signed exact-$(2+,2-)$ 3CNF with $n$ original variables, $m=4n/3$ original clauses, and source bit length $N$. Of the $\binom m2$ source clause pairs, at most $6n$ have a nondefault four-mode compatibility entry. An exact sorted table of these pairs has $O(n\log m)$ bits and is constructible in $O(N+n\log n)$ indexed word-RAM operations, after authenticating the source. Every absent pair has all four modes feasible. An explicit dense four-bit-per-pair matrix takes $4\binom m2$ output bits if materialized, but the compatibility relation itself does not require quadratic retained memory.
\end{theorem}
\begin{proof}
For each original $x_i$, the four source occurrences have two positive and two negative signs. Their six unordered occurrence-pair events comprise two equal-polarity and four opposite-polarity events. Each equal-sign event forbids $SU$ and $US$ for its clause pair; each opposite-sign event forbids $SS$ and $UU$. Properness ensures distinct parent clauses. Sort and merge the $6n$ source-indexed pairs, OR-ing two Boolean flags when a pair appears more than once. Unrepresented pairs share no variable and impose no extreme-mode conflict. Store two $O(\log m)$-bit indices and two flags per unique pair; source scanning, list building, sorting, and record access are charged.
\end{proof}
The conservative pair-record payload is at most $6n(2\lceil\log_2m\rceil+2)$ bits, \emph{excluding} original input, occurrences, sorting workspace, object allocation, and stored output. The first eligible $m$ divisible by four where this worst-case payload does not exceed the dense four-mode array is $m=28,n=21$. For the actual connected $H_{200}$, $n=1200,m=1600$, there are $7200$ occurrence-pair events and $5200$ distinct nondefault pairs, so the dense bitpacked four-mode payload is $5{,}116{,}800$ bits versus $124{,}800$ sparse pair-record bits. These are representation estimates, not native machine-peak measurements.

\section*{Exact signed-occurrence balance and backdoor accounting}
Fix a coherent UP-saturated partial original-variable assignment $\rho$, with $k$ fixed coordinates and no residual empty/unit original clause. Let $c_j$ be the number of already fixed-TRUE source literals and $u_j$ its free literal count. Put $Z=|\{j:c_j=0\}|$, $H_q=|\{j:c_j=q\}|$ for $q=2,3$, $w=|\{j:c_j=0,u_j=3\}|$, and $e=\sum_{c_j>0}u_j$. Define the signed-occurrence slack $d=m/2-H_2-H_3$.

\begin{theorem}[Quantitative UP-saturated slack identity]
Every such proper strict22 source obeys
\[
\boxed{2d=w+e,\qquad w\le 2d.}
\]
Choosing one current free variable from each of the $w$ remaining ternary clauses, omitting duplicates, constructs a source-indexed strong 2-SAT backdoor of size $h\le w$. All $2^h$ settings leave residual 2CNF, solved and witnessed by standard SCC. A deliberately conservative indexed-word-RAM implementation using repeated source UP scans and leaf-by-leaf proof checking takes $O(N+2^h nN)$ work and $O(N\log N)$ peak working bits including the parsed source if UNSAT certificates are streamed; explicit proof output may contain $O(2^hN\log N)$ bits and is charged separately.
\end{theorem}
\begin{proof}
Each fixed original variable supplies exactly two TRUE occurrences, so $\sum_j c_j=2k$. Thus $H_2+H_3=\sum_j(c_j-1)_+=2k-m+Z$ and, using $m=4n/3$, $d=2(n-k)-Z$. Each free original variable occurs exactly four times, and at the nonconflicting UP fixed point each uncovered clause has two or three free literals. Thus $4(n-k)=2Z+w+e$. Subtraction gives $2d=w+e$. Picking one free coordinate per length-three residual clause hits all those clauses, so all its complete pin assignments create 2CNF. DFS across these settings, source reconstruction, SCC implication-path certificates, repeated source scans, and proof checking provide the advertised upper bound. The branch tree cannot infer an UNSAT answer bit without exhausting its selected settings.
\end{proof}
This uses the previously known 2-SAT backdoor principle [Williams--Gomes--Selman 2003; Nishimura--Ragde--Szeider 2004]. It is not a universal polynomial SAT theorem. The earlier LSPV-1 BALANCED-OCCURRENCE-FIREWALL243 proves the $d=0$ special case. The new exact identity explicitly exposes an \emph{easy} $w=0$ residual with large $d$.

\section*{Connected constant-proof forbidden cube}
Take the previously verified connected strict22 SAT family $H_r$ with cyclic block $j$ and eight original clauses
\[
\begin{array}{ll}
A_j=(x_{j-1,1}\vee x_{j,3}\vee x_{j,5})&
B_j=(x_{j,1}\vee\neg x_{j,3}\vee x_{j,6})\\
C_j=(\neg x_{j,1}\vee x_{j,4}\vee x_{j,5})&
D_j=(\neg x_{j,1}\vee\neg x_{j,4}\vee x_{j,6})\\
E_j=(x_{j,2}\vee x_{j,3}\vee\neg x_{j,5})&
G_j=(x_{j,2}\vee\neg x_{j,3}\vee\neg x_{j,6})\\
I_j=(\neg x_{j,2}\vee x_{j,4}\vee\neg x_{j,5})&
J_j=(\neg x_{j,2}\vee\neg x_{j,4}\vee\neg x_{j,6})
\end{array}
\]
with all block indices modulo $r$. This source is connected, duplicate-free, proper strict22 with $n=6r,m=8r$ and SAT witness $(x_{j,1},\ldots,x_{j,6})=(1,0,1,0,1,0)$ for each block.

\begin{theorem}[Large slack, no original source UP, and five-step proof]
Pin $\rho_r:\ x_{j,5}=x_{j,6}=0$ for every block. The residual $H_r|\rho_r$ is UNSAT but has no empty or unit clause at the source UP fixed point. It consists of $4r$ binary clauses, with $w=0$, $e=8r$, $d=4r$. Nevertheless, original sources derive for any block $j$ the non-tautological forbidden-cube clause
\[
R_j=x_{j,5}\vee x_{j,6}\vee x_{j-1,5}\vee x_{j-1,6},
\]
collapsing duplicates if $r=1$, by at most five two-premise resolution steps. Its falsifying partial original-variable cube is impossible.
\end{theorem}
\begin{proof}
Under $\rho_r$, $A_j,B_j,C_j,D_j$ become binary, while $E_j,G_j,I_j,J_j$ are already satisfied. None is a unit or empty clause, giving $Z=4r$, $H_2=H_3=0$, and the displayed $d,w,e$. Original-source resolution gives, in order,
\[
\begin{aligned}
P_j&=\operatorname{Res}_{x_{j,4}}(C_j,D_j)
      =\neg x_{j,1}\vee x_{j,5}\vee x_{j,6},\\
Q_j&=\operatorname{Res}_{x_{j,1}}(B_j,P_j)
      =\neg x_{j,3}\vee x_{j,5}\vee x_{j,6},\\
V_j&=\operatorname{Res}_{x_{j,3}}(A_j,Q_j)
      =x_{j-1,1}\vee x_{j,5}\vee x_{j,6},\\
P_{j-1}&=\operatorname{Res}_{x_{j-1,4}}(C_{j-1},D_{j-1}),\\
R_j&=\operatorname{Res}_{x_{j-1,1}}(V_j,P_{j-1}).
\end{aligned}
\]
For $r=1$ reuse $P_j=P_{j-1}$. Each step is non-tautological with original parent provenance. The pinned cube falsifies $R_j$ and is UNSAT, even while the unrestricted $H_r$ is SAT. A large endpoint/occurrence slack is therefore not a lower bound on source-proof or decision work, even for connected strict22.
\end{proof}
