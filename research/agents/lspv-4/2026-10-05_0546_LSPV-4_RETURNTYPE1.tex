\section*{PRIMARY-LITERATURE PREFLIGHT}
The immediate obstacle is representation/model matching, not another recurrence. Robson's RAM-to-SAT reduction produces an ordinary explicit SAT encoding with size controlled by computation time. Fortnow--Lipton--van Melkebeek--Viglas applies to ordinary SAT in its stated random-access model. Neither theorem licenses feeding a succinctly represented CNF, an evaluator oracle, or an extractor/reconstruction predicate to an ordinary SAT decider without charging a conversion.

For TASK-008, the June 2026 Loff--Sherif--Talebanfard--Ugazio result gives an unconditional barrier only for AC0-natural proofs against constant-depth circuits. It does not itself obstruct every exact-slice monotone lower-bound method, but it strengthens the guard against treating a switching-lemma-style constructive distinguisher as a generic route to unrestricted circuit lower bounds.

\section*{PROVED/EXACT return-interface trilemma}
Let $A$ be the assumed ordinary SAT decider whose input is an explicit Boolean encoding of a CNF formula. Suppose a proposed source return is described by a compact object $D$ and an evaluator $E(D,i)$ for logical coordinates of a would-be formula $Q$.

There are three typed cases.

\paragraph{Case I: explicit ordinary CNF.}
If $Q$ is actually supplied to $A$ in the ordinary SAT input model, then its written encoding must be produced or otherwise made available in that model. The recurrence must charge the construction/access mechanism that supplies the complete ordinary input representation required by $A$. A compact evaluator does not by itself change the input type of $A$.

\paragraph{Case II: succinct CNF.}
If $A$ receives only $D$ and is expected to interpret $E(D,\cdot)$ as the clauses of $Q$, then the algorithm being invoked is a decider for a succinctly represented SAT language, not the assumed ordinary explicit-CNF SAT decider. Any theorem using this case must separately prove a reduction from that succinct language to ordinary SAT with the claimed size and resource bounds.

\paragraph{Case III: semantic or algebraic oracle.}
If $A$ or the return procedure may query $E$ as an oracle without encoding those oracle semantics into the SAT input, then the target is oracle-SAT or a relativized/algebraic variant, not ordinary SAT. A forbidden-region theorem for ordinary SAT cannot be applied without a model-matched simulation theorem.

Therefore
\[
\boxed{\text{compact evaluator}\not\Rightarrow\text{ordinary SAT return}}
\]
and
\[
\boxed{\text{ordinary SAT return}\not\Rightarrow\text{free materialization of the logical CNF}.}
\]
This is a type distinction, not a claim that explicit materialization is always necessary. A random-access representation could be admissible only if the final SAT model and lower-bound theorem explicitly accept that same representation and charge its access costs.

\section*{Boundary-Squeeze consequence}
RETURNTRACE1 correctly identifies the current source chain as terminating at extractor/reconstruction/PCPP objects and oracle evaluations rather than an ordinary $Q_{\rm SAT}$. SUCCINCTESCAPE1 prevents charging the ambient logical domain merely because it is large. RETURNTYPE1 now blocks the opposite repair: replacing the missing ordinary SAT return by a compact evaluator without changing the solver language.

Thus the next source theorem must specify
\[
R_{\rm ret}(x,S,Q)
\]
with $Q$ an ordinary SAT input in the exact model used by the final lower bound, or explicitly state a different target language and prove a model-matched reduction. Only after that step are query-length and recurrence exponents well typed.

DELAY, INTERP and RECOMP remain legitimate implementation choices, but each acts inside a specified input model. COPY does not manufacture an input conversion. A maximal semantic oracle can answer evaluator queries and therefore makes source evaluation easier; it does not create a nonrelativizing lower bound. An algebraic oracle can similarly accelerate LDE/RMV evaluation. Hence this guard itself relativizes and is not the missing hinge.
