\section{One target and hypotheses registered before primary-source search}
The one active ARC/FLMV task is a finite, uniformly machine-witnessed,
all-input, fully charged route from cofinally many achievable integer
diagonals into
\[
t<c_\star=\frac{241}{200},\qquad
s<d_\star=\frac{11642479}{23232400},\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right),
\quad d_\star=\beta(c_\star).
\]
A point $(t,s)$ belongs to the upward-closed region $E$ only if
\emph{one fixed uniform deterministic total exact ordinary-SAT decider}
$A$ on \emph{every} ordinary $N$-bit input simultaneously has
$T_A(N)\le N^{t+o(1)}$ and writable/index
$S_A(N)\le N^{s+o(1)}$ in the FLMV random-access indexed-read-only-input
Turing-machine model. Under $P=NP$ a finite $(K,K)\in E$ exists.
The illustrative ARC-EDGE-90 successor
\[
(t,s)\longmapsto
\left(\max\{11/10,3/5+t/2\},\max\{1/2,s/2\}\right)
\]
is \OPEN; its finite arithmetic is not an algorithm.  Route depth may
depend on fixed $A,K$ but not on uncharged varying-$N$ advice. The
old universal cosine-sum endpoint is \textbf{FALSIFIED/RETIRED}.

The following falsifiable attempts were specified before this run's
primary-paper search:
\begin{description}

\item[] H2. Determine whether a cache using strictly less than

\section{An exact restricted replay-cache theorem}
Let $D$ named first-child virtual input bits be served through a
fixed opaque accessor $G_1$. A required two-level execution requests
these bits in $R$ complete sweeps of $D$ \emph{distinct} addresses each,
with the same publicly known order in every sweep. A raw-value
cache may retain at most $B$ pairs (address,bit) between requests, initially
empty. It may call $G_1$ and store returned individual bits, but is
\emph{not} permitted to replace a sweep by an aggregate, use a
semantically stronger source-specific algorithm, or derive unqueried
bits. Every service invocation is charged for all of its source and
work accesses. Address tags add $O(\log N)$ bits per stored record.

\begin{theorem}[Exact minimum misses for full sweeps]\label{th:miss}
For $0\le B\le D$, every such mandatory replay in this raw-record
interface has at least
\[
\boxed{\quad M_{\rm miss}\ \ge\
D+(R-1)(D-B).\quad}\tag{1}
\]
This bound is tight: pin the first $B$ named bits on their initial
queries, do not cache the other $D-B$ bits, and replay the same sweep
order. If a fixed opaque service invocation executes at least $P$
elementary source reads, the particular replay program incurs at least
\[
P\{D+(R-1)(D-B)\}
\]
source reads, separately from guest and index/control work. For an
ordinary deterministic LRU raw-value cache and $B<D$, repeated
increasing-order sweeps instead miss on all $RD$ accesses.
\end{theorem}
\begin{proof}
The first sweep contains $D$ different addresses and the cache is empty,
so it must invoke $G_1$ at least $D$ times. At the start of each later
sweep at most $B$ of the $D$ individual records are held. Each one of
the other $D-B$ \emph{distinct} addresses must be obtained from $G_1$
before its value can be emitted. Prefetches count as invocations;
extra evictions cannot decrease the bound. Summing proves (1).
Pinning the first $B$ addresses obtains all $D$ bits in the first
sweep and fetches exactly the remaining $D-B$ once per later sweep,
achieving equality. For LRU, each requested bit is separated from its
next use by $D-1\ge B$ distinct other requests when $B<D$; it is
therefore evicted before the next use and every request misses.
\end{proof}

This is a \textbf{PROVED/EXACT restricted protocol theorem}, not a
TM cell-probe or SAT time lower bound. In particular, it \emph{assumes}
the complete sweep transcript and the fixed expensive service.
A compiler may precompute sufficient statistics, fuse generators,
read the actual source directly, or make fewer virtual requests.
Such redesigns fall outside (1), and cannot be excluded by (1).

\begin{lemma}[Asymptotic cache crossover]\label{lem:cross}
Assume $D=N^{\delta+o(1)}$, $R=N^{\pi+o(1)}$,
$P=N^{g+o(1)}$ with $\delta,\pi,g>0$, and the fixed mandatory
interface above. If an allowed cache has
$B\le N^{\theta+o(1)}$ for $\theta<\delta$, then
$B=o(D)$, $M_{\rm miss}=N^{\delta+\pi+o(1)}$, and
mandatory service work has exponent $\delta+\pi+g$.
A full $D$-entry cache uses $N^{\delta+o(1)}$ writable bits
and can reduce service calls to $N^{\delta+o(1)}$, while the
$RD$ record lookups still cost $N^{\delta+\pi+o(1)}$
bit operations up to logarithmic factors. More generally, if
$B=D-H$, with $H=N^{h+o(1)}$, the pinned service-call
count is
\[
M_{\rm miss}=
N^{\max\{\delta,\pi+h\}+o(1)}
\]
provided $R=N^{\pi+o(1)}$ and $D=N^{\delta+o(1)}$,
and its cache still occupies $N^{\delta+o(1)}$ bits when $H=o(D)$.
\end{lemma}
\begin{proof}
Substitute the stated scales into the exact identity (1).
For $B=o(D)$, every later sweep requires $(1-o(1))D$ new
service calls. If $B=D-H$, the count is $D+(R-1)H$.
A fixed indexed cache with explicitly stored bits and tags incurs
$O(D\log N)$ retained bits and polylogarithmic charged
address operations per hit, which changes only $o(1)$ exponents.
No uncounted work-tape or reusable output buffer is assumed.
\end{proof}

The second statement is a per-protocol \emph{lower and upper}
count, not a claim that every SAT solver must cache those bits.

\section{Two actual ordinary 2CNF generations and a rank-summary escape}
For every $q\ge7$ and $b=(b_0,\ldots,b_{q-1})\in\{0,1\}^q$,
build an ordinary cycle formula $F_b$ on $q$ variables imposing
$x_i\oplus x_{i+1}=b_i$ for each cyclic edge, expressed as the
usual two binary CNF clauses. Thus
\[
\boxed{\SAT(F_b)=1\quad\Longleftrightarrow\quad
\bigoplus_{i=0}^{q-1}b_i=0.}\tag{2}
\]
Its explicit fixed-slot unary-width-header bit encoding has
$N=\Theta(q\log(q+2))$. For all sufficiently large $q$ choose
\[
D=\left\lfloor\frac{N^{3/5}}{\log_2(N+2)}\right\rfloor,
\qquad M=\lfloor N^{1/4}\rfloor,\quad
R=\lfloor N^{2/5}\rfloor,\quad P=\lfloor N^{1/4}\rfloor.
\]
The finite reproducer clamps these sizes to legal nonempty
small-input ranges, never using the finite cutoffs as asymptotic
claims. Eventually $q>D>M>1$.

Make the \emph{ordinary} first 2CNF child $Y_b$ with the unit
$(y_1)$, and $(\neg y_1)$ on an odd root parity or the
tautology $(y_1\vee\neg y_1)$ on even parity. Append exactly
$D$ independent tautological ordered clauses
$(y_{j+2}\vee\neg y_{j+2})$, orienting each pair by the
corresponding $b_j$. The orientation represents one genuine
addressable raw bit but changes no SAT label. Hence
\[
\SAT(Y_b)=\SAT(F_b),\qquad |Y_b|=N^{3/5+o(1)}.
\]
Partition its $D$ tag bits into $M$ nonempty consecutive
blocks $I_1,\ldots,I_M$. The second \emph{ordinary} 2CNF
child $Z_b$ has the analogous unit/contradicting-unit core,
with status read from the $Y_b$ core; its $j$th tautology
orientation equals the computed block parity
$\sigma_j(Y_b)=\bigoplus_{k\in I_j}b_k$. Then
\[
\SAT(Z_b)=\SAT(Y_b)=\SAT(F_b),\qquad
|Z_b|=N^{1/4+o(1)}=|Y_b|^{5/12+o(1)}.\tag{3}
\]
The mapping computes real ordinary CNF encodings and all tag
positions, not just semantic labels. But it is a deliberately
easy, \emph{promised}, source-specific reduction, not a uniform
hard-image contractor.

The literal two-level virtual accessor computes every requested
$\sigma_j$ by reading \emph{all} $Y_b$ tags in block $I_j$.
Require $R$ complete guest scans of all $M$ output tags.
The request transcript contains exactly $RD$ intermediate-bit
reads and $RM$ output-tag probes. A deliberately specified opaque
$Y_b$ tag service first performs $P$ indexed source-bit reads
before returning the true tag (and also reads that tag).
This is an \emph{implementation choice}: the tag may instead
be read directly from the easy cycle source. For the literal
opaque protocol and a raw cache satisfying
$\theta<d_\star<3/5$, Lemma~\ref{lem:cross} gives
\[
\underbrace{T_{\rm source}}_{\text{mandatory only for this interface}}
=N^{\,3/5+2/5+1/4+o(1)}
=N^{5/4+o(1)},\qquad
S_{\rm cache}\le N^{\theta+o(1)}. \tag{4}
\]
The first exponent exceeds $c_\star$. Full raw-bit caching
reduces total work to $N^{1+o(1)}$ but itself requires
$N^{3/5+o(1)}$ space, exceeding $d_\star$. This is a
\emph{restricted} two-coordinate cache-frontier counterexample
to treating replay and peak space independently, \emph{not}
an unconditional FLMV forbidden pair.

By contrast, a \emph{paid} source-aware algorithm reads the
$q$ orientation bits to learn the parity status and $D$ source
tags to form the $M$ independent linear block sums once.
It retains the $M$ sums and answers all $RM$ guest tag requests:
\[
T_{\rm aggregate}
=O((q+D+RM)\operatorname{polylog}N)=N^{1+o(1)},\qquad
S_{\rm aggregate}=O(M\log N+\log N)=N^{1/4+o(1)}. \tag{5}
\]
Every indexed source read and workspace record is charged.
The $M$ block parities are a sufficient-statistic vector;
the disjoint-block linear map has rank exactly $M$ over
$\mathbb F_2$. Their \emph{acquisition} is elementary
streaming computation here; such a rank summary is neither
known to exist nor known to be efficiently acquired for
arbitrary hard SAT formulas. Direct SCC, affine elimination
or even one root parity scan already decides this promised
family in the same easy resources.
