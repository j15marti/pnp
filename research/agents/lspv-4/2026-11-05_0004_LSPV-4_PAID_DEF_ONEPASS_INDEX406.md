## ITERATE: exact theorem and proof

Original SAT control F+=(x) and UNSAT control F-=(x) AND (NOT x). For every q>=1 and bit vector b in {0,1}^q create q **separately unit-paid** fresh conservative two-input DEF nodes: g_i=XOR(x,x)=0 if b_i=0, and g_i=XNOR(x,x)=1 if b_i=1. Every output is a constant function of all original variables. Introduce one more **separately unit-paid** DEF h=AND(g_j,g_j), but reveal the selector j only in the final record. The semantic query LAST-WIRE outputs h=b_j on either x assignment, without any semantic oracle or hidden gates. This query does **not** assert a native LOCAL-CONVERT conclusion.

**Theorem, PROVED/EXACT restricted:** For each fixed q every deterministic one-pass left-to-right evaluator, which cannot revisit input or read copies of it and must answer after the final selector, has at least 2^q distinguishable configurations after reading the q definitions. It therefore needs at least q mutable state bits at that cut, up to finite-control constants.

**Proof:** Suppose prefixes b and b' yield the same post-prefix state. Because b!=b' there exists j with b_j!=b'_j. Append exactly the same legal final gate h=AND(g_j,g_j) to both streams. The machine's final output must be identical, but exact semantics requires b_j and b'_j respectively. Contradiction. Thus all 2^q prefixes have distinct states. Input-head position is the same for all prefixes. Caches, saved input, mutable index tapes and readable output storage count as memory. This is the standard deterministic one-way INDEX argument on an explicit separately-paid gate grammar, not a P versus NP hardness theorem.

The **model restriction is decisive**: a two-pass read-only-input procedure learns j at the end and then rescans g_j using O(log M) scratch and O(M^2) conservative bit time; indexed random access permits the same. The restricted one-pass q-bit lower bound DOES NOT hold against arbitrary FLMV indexed-input machines, does not force SAT decision time, and does not lower-bound minimum proof DAG size.

The test ASCII grammar is Q{five-digit-q}:{q opcode bits}:A{fixed-width binary j}, q<=99999. For fixed q all prefixes have identical length; M=8(9+q+max(1,ceil(log2 q))) binary bits. Standard flat records with explicit binary IDs use O(q log q+N) bits. Every gate is paid even where opcodes compress to one character. The original /341 gives fresh conservative two-input DEF but does not settle how a public named DEF output becomes an asserted LOCAL conclusion or a selectable DEF-CNF facet. Consequently the theorem is **not** a legal-native LOCAL counterexample. If the public port selector were ratified, checking F+=(x) entails positive unit h would distinguish b_j=1 from b_j=0, subject to exact source authentication.
