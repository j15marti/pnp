\section*{Target and quantifiers}
Boundary-Squeeze needs a uniform construction whose resource bound improves an assumed SAT decider rather than merely using its final semantic answer. The hostile target is any claimed return theorem of the form
\[
\forall A\in {\rm SATDEC}\ \forall F\ \exists Q:
\quad SAT(F)=SAT(Q),\qquad |Q|\ll |F|,
\]
when construction of $Q$ may depend on $A(F)$ or an equivalent semantic oracle bit.

\section*{PROVED/EXACT semantic-return vacuity}
Fix any satisfiable constant CNF $Q_1$ and any unsatisfiable constant CNF $Q_0$. For every exact SAT decider $A$, define
\[
R_A(F)=Q_{A(F)}.
\]
Then
\[
SAT(F)=SAT(R_A(F))
\]
for every $F$, while
\[
|R_A(F)|=O(1).
\]
Thus satisfiability preservation plus arbitrarily strong output contraction does not imply structural acquisition, recursive progress, or a faster SAT algorithm. The constructor has already solved the source instance.

If $A$ has time exponent $K$ and the constructor invokes $A$ on an instance of length $n^{\beta+o(1)}$, that invocation contributes an achievable-time term $n^{\beta K+o(1)}$. For $\beta=1$, no exponent erasure has occurred. The constant-size return cannot remove this charged current-scale call.

Therefore a load-bearing return theorem must be \emph{decision-oblivious at the unresolved scale}: its construction bound must be proved without using $SAT(F)$, an equivalent semantic oracle answer, or a current-scale call whose cost contains the unresolved exponent $K$. This is a requirement on the proof architecture, not a claim that every useful reduction is syntactically oblivious to all semantic information.

\section*{Maximal-oracle hostile test}
Give the constructor one free bit $SAT(F)$. The return problem collapses immediately to the constant pair $(Q_0,Q_1)$. Hence any alleged necessity theorem inferred only from existence, uniqueness, size, or semantic correctness of the returned $Q$ is falsified by this oracle control. A surviving resource must be forced by a stronger interface, for example a source-restricted local construction whose correctness is established without the final answer bit and whose acquisition costs are independently bounded.

This guard relativizes. It is not the missing nonrelativizing hinge.
