\section{BUILD I: a fixed-length ordinary proper-3CNF representation}
Let $b=(b_1,\ldots,b_m)\in\{0,1\}^m$. Introduce variables $x_i$ and $y_0,\ldots,y_m$ and fresh, disjoint auxiliary variables. For each $i$, force $x_i=b_i$ by the four proper clauses
\[
 (\ell_i\vee u_i\vee v_i),\; (\ell_i\vee u_i\vee\neg v_i),\;
 (\ell_i\vee\neg u_i\vee v_i),\; (\ell_i\vee\neg u_i\vee\neg v_i),
 \qquad \ell_i=\begin{cases}x_i,& b_i=1,\\\neg x_i,&b_i=0.\end{cases}
\]
These four clauses are logically equivalent to the unit literal $\ell_i$, but their scopes never change with the control bit. Enforce $y_i\leftrightarrow(y_{i-1}\wedge x_i)$ with the five proper clauses
\[
 (\neg y_i\vee y_{i-1}\vee t_i),\quad
 (\neg y_i\vee y_{i-1}\vee\neg t_i),\quad
 (\neg y_i\vee x_i\vee w_i),\quad
 (\neg y_i\vee x_i\vee\neg w_i),\quad
 (y_i\vee\neg y_{i-1}\vee\neg x_i).
\]
Use two more four-clause forcing gadgets for $y_0=1$ and $y_m=1$. Call the resulting formula $\Phi_m(b)$. Every clause has three \emph{distinct} original-or-auxiliary variables, and there are exactly $9m+8$ clauses and $6m+5$ variables for every $b$. The signed-literal template and variable identifiers are independent of $b$ except for the first literal's sign in four clauses per $i$.

\begin{lemma}[Physical source normalization]\label{lem:cnf}
The formula $\Phi_m(b)$ is satisfiable iff $\bigwedge_{i=1}^m b_i=1$. In the unpadded, fixed-width signed-literal binary encoding that stores every signed literal as the integer $2|\ell|+\mathbf1_{\ell<0}$ in $w_m=\lceil\log_{256}(2(6m+5)+2)\rceil$ bytes, all $2^m$ input strings have exactly the same encoded bit length
\[
 N_m=8\bigl(8+|\operatorname{varint}(m)|+|\operatorname{varint}(w_m)|+3(9m+8)w_m\bigr)=\Theta(m\log(m+2)).
\]
The leading constant-eight byte magic and self-delimiting integers are part of the source, and no variable, clause, proof table, or padding is hidden.
\end{lemma}
\begin{proof}
The four sign clauses force their common literal. Each pair of split clauses is equivalent to its underlying binary clause, and the last clause completes the usual conjunction equivalence. Inductively $y_i=\bigwedge_{j\le i}b_j$ under $y_0=1$; demanding $y_m=1$ yields the claim. In the specified physical encoding a sign flip changes one low-order bit of the literal word without changing its width. There are precisely $3(9m+8)$ words, proving equal physical lengths. The Python implementation authenticates the complete expected clause template on readback, rejecting noncanonical sign inconsistencies.
\end{proof}

\section{BUILD II: an exact finite-horizon equivalence theorem}
Fix $0\le h\le m$ and consider a deterministic preprocessing machine that receives one canonical $\Phi_m(b)$, discards its ability to reread source bits, retains a finite configuration $z$, then receives an adversarial online stream of at most $h$ point overwrites $b_i\gets c\in\{0,1\}$. It must answer SAT correctly after each update, including the possibility of zero updates. Every retained work-symbol, head position, finite control state, emitted-but-retrievable table and auxiliary transcript counts in $z$. The program is one fixed machine; no SAT/UNSAT-side advice bit is provided.

\begin{theorem}[Exact initial-state distinguishability]\label{thm:classes}
Let $E(m,h)$ be the number of distinct response behaviours of source strings under every permitted common future overwrite stream. Then
\[
 \boxed{ E(m,h)=\begin{cases}1+\displaystyle\sum_{j=0}^{h}\binom{m}{j},&0\le h<m,\\2^m,&h\ge m.\end{cases}}
 \qquad\boxed{B_{\rm retained}\ge\left\lceil\log_2 E(m,h)\right\rceil.}
\]
The bound applies already when future overwrites are restricted to setting selected positions to one. For $1\le h\le m/2$, $B_{\rm retained}=\Omega(h\log(m/h))$; for $h\ge m/2$, it is $\Omega(m)$. At $h=1$, the necessary initial information is $\lceil\log_2(m+2)\rceil$ bits for $m>1$, not $\Omega(m)$.
\end{theorem}
\begin{proof}
Associate each source with its set $S\subseteq[m]$ of initially zero coordinates. If $|S|>h$, no sequence of at most $h$ overwrites can make all coordinates one, so all such sources return UNSAT throughout every permitted stream and are equivalent. If $S\ne T$ both satisfy $|S|,|T|\le h$, choose whichever of $S,T$ is not contained in the other, say $T\nsubseteq S$, and issue the common stream setting all positions in $S$ to one. On source $S$ the final answer is SAT; on $T$ at least one zero outside $S$ remains, giving UNSAT. If instead $S\nsubseteq T$, interchange them. Each small set is likewise distinguished from the overflow class by setting all its own positions to one. Thus every zero set of size at most $h$ is its own equivalence class, plus exactly one overflow class if $h<m$. When $h\ge m$, every zero set is small and all $2^m$ are distinct. Two distinct behaviours cannot share one retained deterministic configuration, proving the information bound. Standard binomial estimates give the asymptotic claims.
\end{proof}

\begin{proposition}[Matching small-horizon construction]\label{prop:cache}
There is one uniform, exact no-reread updater that retains $O(\min\{m,h\log(m+2)\}+\log(m+2))$ bits, preprocesses the complete authenticated source, handles every SAT/UNSAT output during up to $h$ arbitrary overwrites, and never receives a free answer-class bit. For $h\le m^{1-\varepsilon}$ with fixed $\varepsilon>0$, its information space is optimal up to a constant factor; for $h=\Theta(m)$, the bit-array implementation is likewise optimal up to a constant factor.
\end{proposition}
\begin{proof}
During source preprocessing count zero bits until $h+1$. If that threshold is exceeded, save an overflow marker and return UNSAT on every subsequent query, because at most $h$ coordinates can be repaired. Otherwise retain the initial zero-set as a list of at most $h$ addresses. On an overwrite $b_i\gets c$, delete $i$ from that set if $c=1$, and insert it if $c=0$. After at most $h$ updates the set has at most $2h$ elements. Output SAT exactly when the set is empty. Use $O(h\log m)$ bits, or use a full $m$-bit vector when that is smaller. Every insertion, deletion, source validation, output and failed adaptive overwrite is charged. For $h\le m^{1-\varepsilon}$, $\log(m/h)\ge\varepsilon\log m$, matching Theorem~\ref{thm:classes}; the linear-budget case follows similarly.
\end{proof}

\paragraph{Polarity.} On the \emph{initially UNSAT} subfamily, the $\sum_{j=1}^h\binom{m}{j}$ distinct nonempty small zero sets and the overflow class require separate retained states. The all-ones initial SAT source is a single initial class, but the same uniform update machine handles both sides and may acquire many stored zeros later. The classes concern \emph{update maintenance}, not general static SAT hardness or an all-input same-run SAT time-space bound.
