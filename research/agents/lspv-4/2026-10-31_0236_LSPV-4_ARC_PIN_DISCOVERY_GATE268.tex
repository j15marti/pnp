\section{Exact same-source SAT and UNSAT promise}
For integers $b\ge2,q\ge2$, use common boundary variables $x_1,\dots,x_b$. For every component $i$, introduce disjoint private XOR outputs and pin variables and encode
\[
 y_{i,2}=x_1\oplus x_2,\quad
 y_{i,j}=y_{i,j-1}\oplus x_j\ (3\le j\le b),\quad
 y_{i,b}=r_i,\qquad r_i\in\{0,1\}.
\]
Encode each XOR gate as the four proper width-three clauses falsifying the incorrect truth-table rows. Encode every final pin with four proper width-three clauses, using two additional fresh private variables. Every variable and occurrence retains its exact original clause index and sign. The first literal in each terminal-pin clause is positive for pin $1$ and negative for pin $0$; flipping the pin changes four literal signs but leaves the entire unsigned support, source length, variable names, and other clauses fixed. All blocks share only the boundary variables. For the \emph{length-oblivious native-DIMACS probe theorem}, extend each component by one additional independent private four-clause width-three pin on three fresh variables, forcing its first variable to $1-r_i$. The original terminal pin forces its first variable to $r_i$ and the balancing pin forces the opposite. The balancing pin is always existentially satisfiable, and its four polarity changes exactly cancel the four minus-sign changes of the original pin. Therefore each complete source component block has identical byte length for $r_i=0$ and $r_i=1$, with all ASCII differences confined to that component. All clauses remain proper and their variable IDs and unsigned supports remain fixed across the opposite-label pair. The balanced \emph{source} uses canonical signed-integer DIMACS, while the contracted \emph{child} deletes these redundant private balancing pins. The underlying parity projection (1) remains unchanged. Without the balancing gadget, raw textual DIMACS source length leaks a changed pin through the input end marker, and the claimed one-bit-per-pin source-probe lemma would be false for that unpadded ASCII representation. The separate legacy-format controls are retained but are not used to justify that native-DIMACS indistinguishability premise.

For a fixed boundary assignment $\beta$, a component's private variables can satisfy all its original clauses if and only if $\bigoplus_j\beta_j=r_i$. The forward implication follows from exact four-clause truth tables; the reverse follows by reconstructing each private cumulative parity and choosing pin auxiliaries arbitrarily. Hence
\[
\operatorname{SAT}(F_{b,\mathbf r})
\iff\bigwedge_i\left(\bigoplus_{j=1}^b x_j=r_i\right)
\iff\bigl|\{r_i\}\bigr|=1.
\tag{1}
\]
This proves both YES and NO for the very same ordinary source grammar, not from a simulated oracle. A canonical distinct-pin child retains one fresh-private chain for each distinct value of $r_i$; it has exactly the original SAT label and genuine ordinary-CNF serialization, with a source-specific indexed output-character accessor provided and independently tested in LSPV-2 report 268. The child must not be used until the source grammar is authenticated, or until an exact fallback is employed.

\section{New restricted source-pin acquisition theorem}
\begin{theorem}[Pin-block probe requirement, deterministic and adaptive]
Fix $b\ge2$ and $q\ge2$. Let $F_0=F_{b,(0,\ldots,0)}$ and $F_i=F_{b,(0,\ldots,1,\ldots,0)}$ with the sole $1$ in component $i$, for $i\in\{1,\ldots,q\}$. Here $F_0,F_i$ use the just-defined \emph{balanced} source grammar. They are valid native ASCII-DIMACS proper 3CNF sources with identical physical lengths, original-clause counts and unsigned supports. Source headers and all component byte intervals are identical across the family, and only bytes \emph{inside the changed component's terminal-pin-plus-balancer portion} can differ. Consider any deterministic exact algorithm that decides SAT on this $q+1$-member promise by adaptively probing individual original-source bits, with no uncharged source-dependent advice, external certificate, or already-computed answer. Count all distinct source probes during preparation, discovery, strategy selection, and continuation. On input $F_0$ the algorithm must read at least one of the source bit positions changed by the pin of \emph{every} one of the $q$ terminal blocks. In particular it makes at least $q$ distinct original-source bit probes.
\end{theorem}
\begin{proof}
By (1), $F_0$ is SAT while each $F_i$ is UNSAT. For contradiction run the algorithm on $F_0$ and suppose some block $i$ receives no probe at any original-source bit position whose value differs between $F_0$ and $F_i$. Those positions lie wholly within block $i$ because the opposite pin's four sign changes are balanced by its paired private pin. All source bits actually inspected on $F_0$ have identical values on $F_i$. Induction over the deterministic adaptive execution makes the entire machine's observed source transcript, internal state, adaptive query choices, and final answer identical on $F_0$ and $F_i$. This is impossible because the answers differ. Arbitrarily large or nonlinear summaries do not help unless their acquisition has already read a changed bit or they contain uncharged source information, which is explicitly excluded. At least one changed source bit must therefore be inspected per disjoint pin block. In a fixed-width sign-field representation the source differences are exactly the eight sign fields; in the balanced native DIMACS serialization, the unchanged total block length guarantees that even shifted ASCII characters cannot leak information outside the component. \qed
\end{proof}
For fixed $b$, an explicit fixed-ID-width encoding has $N=\Theta(q\log q)$ source bits, so the promise-interface requirement is $q=\Omega(N/\log N)$ \emph{original-bit probes}. This is a classical adversary/decision-tree argument instantiated on an exact both-label ordinary-SAT source, not an unrestricted SAT time lower bound. Full untrusted grammar validation requires checking all source records and can be implemented with one sequential original-source scan, an $O(1)$ two-bit pin-presence summary and $O(\log N)$ positional counters, conditional on fixed canonical ordering. All read operations, counted work/index-tape coordinates, and source-bit access are charged. Even in this easy family, repeated validation once per $N^{3/5}$ guest children would cause $N^{8/5-o(1)}$ source traffic, but one validated pass and reusable certified descriptor avoids that multiplicative tax. Neither behavior is universal: source-specific optimization is permitted.
