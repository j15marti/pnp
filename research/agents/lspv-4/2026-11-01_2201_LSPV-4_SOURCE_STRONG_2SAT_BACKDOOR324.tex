\section{Elementary all-original theorem}
Let $n$ be the number of original variables and $m=4n/3$ be the original source clause count, by the signed occurrence quota. A set $B$ is a strong \emph{syntactic} 2CNF backdoor iff it meets each source triple. If a clause is disjoint from $B$, it retains width three under every assignment to $B$; if hit, it is satisfied or shrinks to width two or less. This exact clausewise criterion is already in project reports LSPV-3 271 and LSPV-2 283/303, and belongs to classical backdoor theory \cite{nrs2004}.

\begin{theorem}[Paid deterministic 2SAT backdoor and decision bound]
On every well-formed canonical original $F$ with physical encoded length $N$ there is a uniform deterministic source-reading algorithm constructing a strong 2CNF backdoor $B$ of size at most $2n/3$ by polynomial total work. A complete exact solver that enumerates assignments to $B$ and runs source-ID-certified 2SAT on the residuals satisfies
\[
 T(F)\le \operatorname{poly}(N)\bigl(1+2^{|B|}\bigr)
 \le\operatorname{poly}(N)\bigl(1+2^{2n/3}\bigr),
 \qquad S_{\mathrm{work+index}}(F)=\operatorname{poly}(N).
\]
This is a conservative asymptotic bit-TM upper bound, including read-only input and index work; no native FLMV step-count or strict numerical exponent follows. SAT emits a complete original-clause-checked witness. UNSAT emits an exhaustive branching tree whose leaves have an actually empty original clause or original-source-ID implication-SCC contradiction.
\end{theorem}
\begin{proof}
Choose each original variable independently in auxiliary set $S$ with probability $1/2$. Define
\[
 \Psi(S)=|S|-\sum_{C\in F}{\bf1}\{\operatorname{var}(C)\subseteq S\}.
\]
Then $\mathbb E\Psi=n/2-m/8=n/3$. Derandomize by assigning each inclusion bit successively to the value maximizing its source-computed conditional expectation. Exact scaled-by-eight expectations are sums of $n$ one-variable and $m$ three-variable terms; each trial scans the true original source. The final selected set has $\Psi(S)\ge n/3$. Delete one selected variable from each clause fully contained in $S$; at most as many deletions are made as selected internal clauses. The remainder $I$ hits no entire source clause and obeys $|I|\ge\Psi(S)\ge n/3$. Thus $B=V\setminus I$ meets every source clause and has $|B|\le2n/3$. For each coherent $\beta:B\rightarrow\{0,1\}$, original source clauses reduce to 2CNF and a literal implication graph can be built and solved by strongly connected components \cite{apt1979}. A satisfying leaf's full original witness is checked; if all leaves fail, record their empty-clause or contradictory implication-path certificates. The complete branching is exhaustive. The selector performs polynomial source passes, each leaf takes polynomial source/index/graph/proof work, and only one branch and its ancestors are retained at a time. \end{proof}

\section{New exact F9 combinatorial audit and same-original lower-bound escape}
\begin{lemma}[F9 minimum strong 2SAT backdoor is exactly four]
The source-authenticated F9 with nine originals, twelve distinct signed source triples and 70 models has $\tau(F9)=4$.
\end{lemma}
\begin{proof}
Every variable occurs in four \emph{distinct} source clauses. If three selected original variables covered all twelve clauses, none of those variables could occur together in any source clause, or their combined incidence hits would count fewer than twelve distinct clauses. But the only pairs of original F9 variables with \emph{no} co-occurring source clause are
\[
 (1,4),(1,8),(2,5),(2,6),(3,6),(3,7),(3,9),(4,5),
\]
and this eight-edge graph is triangle-free. Therefore no three selected variables cover F9. The explicit $B=\{x_1,x_3,x_4,x_9\}$ hits all twelve clauses, proving $\tau=4$. Both the producer and independent full Python combinations enumeration count exactly fifteen minimum four-variable covers. \end{proof}

\begin{theorem}[Source-aware easy family despite linear backdoor]
Let $F_t$ be the conjunction of $t$ variable-disjoint original F9 copies. Then $F_t$ is still a \emph{valid canonical} D\"ocker original with $n=9t$, $m=12t$, and $\tau(F_t)=4t$. There exists one uniform exact source-aware algorithm that decides \emph{every coherent pin restriction} of every $F_t$ in polynomial time and space, including the verified same-original SAT and UNSAT pin pair.
\end{theorem}
\begin{proof}
The clause-variable incidence components are the $t$ connected F9 blocks. A polynomial source scanner finds connected components and tests each against the constant signed nine-original F9 template up to name and clause permutation, with no solution oracle. Hitting sets split by components, so their minimum cardinalities sum to $4t$. For any source pin restriction, independently examine at most $2^9$ assignments on each nine-original component, then AND the results. This is $O(t)$ constant-size exhaustive tests plus fully paid source parsing, template recognition and output. If the formula is recognized, it has an efficiently checked solution or one rejecting component. If the source is not of this form, the uniform general decider may use ordinary complete fallback. The same \emph{original} F9 has common pins $(x_3,x_5,x_6,x_7,x_8)=(0,1,0,0,0)$ with $x_1=0$ admitting two completions, while $x_1=1$ admits zero. Put this same-source both-label pair on the first block of $F_t$ and leave other blocks free. Thus a universal \emph{per-instance} time lower bound $2^{\Omega(\tau(F))}$ against \emph{all} correct source-aware algorithms is false. This does not falsify an unrelated worst-case lower bound on some other canonical family. \end{proof}
