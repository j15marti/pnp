# LSPV-4/436 | Forward-only descriptor replay under charged indexed resources
**2026-11-06 02:36 PST, America/Los_Angeles. PROVED/RESTRICTED port lemma; COMPUTATIONAL finite controls. Route A primary; P versus NP OPEN.**

## IDEA → SEARCH → ITERATE
Hypothesis: LSPV-4/435's reversible one-bank DFS need not assume random access to *individual* child edits. The parent may instead contain an authenticated read-only directory of stream start pointers and variable-length forward-only edit streams. Precise falsifiers: (F1) reverse order is indispensable for rollback; (F2) variable-length edits force quadratic reconstruction time; (F3) adaptive edit generation may safely be replayed using the mutated bank; (F4) an explicitly generated descriptor catalog can be treated as read-only input without construction cost.

F1/F2 were falsified *for commuting XOR edits*: replaying the same forward stream cancels every toggle and scans each encoded bit twice. F3 fails, as established by the earlier adaptive generator counterexample in LSPV-4/435, so immutable descriptors are essential. F4 is invalid for an implemented compiler: materializing the catalog on a work tape incurs its complete physical high-water, even if freed later. This result strengthens only a restricted read-only port, not an all-input SAT contraction.

## Published hard-family ledger
For a connected simple cubic graph $G=(V,E)$ with $H=|V|$, $M=3H/2$ edge variables, sorted incident edge IDs $a_v<b_v<c_v$, and charge $\chi_v\in\{0,1\}$, define $\ell_0(x)=x$ and $\ell_1(x)=\neg x$. The exact strict 3-CNF source is the $4H$ clauses
$$
C_{v,p,r}(\chi)=\ell_p(x_{a_v})\vee\ell_r(x_{b_v})\vee\ell_{p\oplus r\oplus1\oplus\chi_v}(x_{c_v}),\qquad p,r\in\{0,1\}.
$$
Connectedness yields SAT iff $\bigoplus_v\chi_v=0$. The actual test's canonical source layout is eight magic bits, unary $H,M$, $H$ charges, $3H$ width-$w$ incident IDs, and $12H$ signed-literal fields of width $w+1$, with $w=\operatorname{bitlength} M$. Exact bit length:
$$
N_{\rm CNF}=8+(H+1)+(M+1)+H+3Hw+12H(w+1)=\Theta(H\log H).
$$
For suitable *growing expander* cubic graphs, odd Tseitin sources require $2^{\Omega(H)}$ ordinary shared-DAG **Resolution** size (Urquhart 1987; Ben-Sasson/Wigderson 2001); this is not hardness for all algorithms or for the full fixed mixed $R_{\rm mix341}$. There is no wider-to-3-CNF reduction in this test. K4/cube/Petersen are finite SAT/UNSAT controls, not certified growing hard instances. GF(2), extended resolution and source-authenticated structural shortcuts remain legal controls.

## Theorem 436.1 (PROVED/RESTRICTED)
Assume the immutable parent packet is $B$ bits on the FLMV read-only input tape. A paid $O(\log B)$-bit directory entry gives the start of each visited DFS edge's contiguous edit stream, consisting of a unary edit count and variable-length self-delimiting vertex identifiers. A concrete implemented code for ID $v$ is $1^{b-1}0\,\mathrm{bin}_b(v+1)$, where $b=\operatorname{bitlength}(v+1)$; no per-edit offsets are provided. The original source and directory are authenticated, and original charge/incidence access is charged and polylogarithmic. There are $q$ visited edge occurrences, total $R$ edit occurrences, $B_{\rm scan}$ bits across their streams counting each edge visit once, $Q$ original-source-port queries and maximum DFS depth $D$.

A single densely addressed $H$-bit work bank $Z$ starts at zero. Scan a child's edit stream in increasing source order and XOR $Z[v]$ for each ID. On child return, replay *the same stream in the same order*. Since $​(x\oplus a)\oplus a=x$ and all edits commute, the parent is restored exactly, including duplicate IDs. Original clauses use charge $\chi_v\oplus Z[v]$, so are reconstructed bit-for-bit. On the FLMV indexed random-access Turing machine, charging work/index head operations, index creation and erasure, physical high-water, start-pointer reads, and both descriptor scans, the **port only** satisfies
$$
T_{\rm port}=O((H+B_{\rm scan}+q+Q+D)\operatorname{polylog}(B+H+B_{\rm scan}+Q+q)),
\qquad S_{\rm port}\le H+O(D\log(B+H+B_{\rm scan}+Q+q)).
$$
Each visited edge incurs exactly two sequential stream traversals; no reverse descriptor access and no individual-edit random-access query are assumed. If every *explicit input* stream is visited at most once, $B_{\rm scan}\le B$, so descriptor traversal costs $B^{1+o(1)}$ time. Source authentication $V$, policy construction and failures $P$, all guest computation, branch joins $J$, output, cache retention and recomputation remain **separately charged**. Peak space must be taken over *all phases* and simultaneously live guest/ancestor buffers.

### Important implementation obstruction
A compiler that *builds* $B$ descriptor bits on a sequential work tape incurs high-water $\Omega(B)$ for that materializing architecture, even if erased before guest calls. A separately supplied read-only portfolio is not a free catalog generated by the universal compiler. At $q=N^{3/5}$, $L=N^{1/2}$, explicit complete-child materialization occupies $qL=N^{11/10}$ bits, far above the target $N^{1/2}$ peak budget, unless an independently proved streaming/lazy alternative is used.

## Finite verification (COMPUTATIONAL)
A Python producer and an **independent Node.js parser/referee** checked six exact signed-CNF sources, even/odd charges on K4 ($H=4,M=6$), cube ($H=8,M=12$) and Petersen ($H=10,M=15$). Each source supplied 39 self-delimiting variable-length edit streams for a three-way, depth-three DFS. Source charge/clauses, exact source hashes, every visited state and source-clause SHA-256, two-pass replay, full restoration and rejection of malformed magic, corrupted original signed clauses and illegal offset entries were checked. Python completed **1,434 grouped checks**; independent Node.js completed **2,650 checks**. Across six packets: **912** physical XOR toggles; descriptor source-bit reads were 822, 874, 1050, 990, 1098, and 1150 respectively. Full packet bit lengths were 1064, 1090, 1580, 1510, 1755, 1781. These are host-language counts and mathematical upper bounds, NOT actual FLMV machine traces, proof-size lower bounds or a P/NP result.
