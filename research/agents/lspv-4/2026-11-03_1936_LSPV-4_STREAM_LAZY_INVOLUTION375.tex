\section*{Published anchor and unchanged proof calculus}
For the canonical unary pigeonhole CNF $P_h=\mathrm{PHP}_{h+1}^h$ there are $v_h=h(h+1)$ variables, $m_h=(h+1)+h\binom{h+1}{2}$ source clauses: one positive clause per pigeon and one negative two-literal clause per colliding pair per hole. Haken (1985) proves that there exist $c>0,h_0$ such that for every $h\ge h_0$ and every unrestricted shared-DAG ordinary Resolution refutation of $P_h$, there are at least $2^{ch}$ lines. With free source leaves and charged derived resolvents, $W_{\rm Res}(P_h)\ge 2^{ch}-m_h=2^{\Omega(h)}$. Explicit ordered ASCII DIMACS sources have $N_h=\Theta(h^3\log h)$ bytes. This theorem is NOT an Extended Resolution, Res$(\oplus)$, fixed $R_{\rm mix341}$, or arbitrary Turing-machine SAT lower bound. Cook (1976) gives polynomial Extended Resolution PHP proofs; the existing cubic odd-Tseitin family has a $4h-1$-node mixed GF(2) certificate. Both are mandatory countercontrols.

Keep the original $R_{\rm mix341}$ fixed: free authenticated source leaves, unit-paid distinct shared binary RES, AND3, GF(2), LOCAL-CONVERT and conservative DEF inferences. No result below changes its grammar, weights, or B3 obligations.

\section*{New time-space sharpening}
\begin{theorem}[Complete charged streaming realization]
For the SAME fixed total involution $E$, there is a single uniform deterministic transducer with read-only indexed input, a fixed number of writable tapes, and append-only write-only output which never becomes readable, satisfying on every $N$-bit input
\[
T_E(N)=O(N\log^4(N+2)),\qquad S_E(N)=O(\log(N+2)).
\]
Time charges precise input-length acquisition, template generation, source/head/index reads, binary arithmetic, decimal conversion, membership tests, output generation, and EOF. Space is peak writable space over ALL phases, including preprocessing and length identification. Every output has exactly $N$ bits.
\end{theorem}
\begin{proof}
Read the input length in binary using $O(\log N)$ counter bits. If it is not byte-aligned, copy it. For byte-aligned input let $M$ denote its number of bytes. To compare a candidate template length $N_h$ against $M$, generate both unpadded formula streams character by character and count their lengths, stopping when their sum plus eight exceeds $M$. Source clause indices and variable identifiers are polynomial in $h$, so if $h\le M$, all loop counters and partial lengths need $O(\log M)$ bits. Each capped candidate test emits at most $M+1$ characters with $O(\log^2 M)$ bit work per generated character. Since the strictly increasing $N_h$ can be searched by binary search over $1\le h\le M$, there are $O(\log M)$ such tests, with no exponentially large or even linear-length intermediate writable object.

If there is no length match, copy the input. For the unique matched $h$, regenerate both padded templates and compare to the input in charged passes. Retain only two match flags, a fixed number of indices and counters, and the two template lengths. If the input equals $X_h$, regenerate and write $Y_h$; if it equals $Y_h$, write $X_h$; otherwise copy. Each clause and decimal literal is formatted online, with no materialized CNF or entire output. A conservative extra logarithmic overhead for fixed-tape arithmetic and index operations gives the claimed $O(N\log^4 N)$ time. All counters are $O(\log N)$ bits, even when $v_h=O(N^2)$ and $m_h=O(N^3)$, because only their binary representations are retained. Complete output requires an unavoidable $\Omega(N)$ writes. The exchanged strings are uniformly recognized UNSAT sources and all other strings are fixed, proving total label preservation without a SAT oracle.
\end{proof}

\begin{theorem}[Paid random-access firewall]
An indexed downstream guest making $Q$ reads of the transformed source can be supplied by a lazy, paid output-bit accessor with $O(\log N)$ extra writable bits and
\[
O(N\log^4(N+2)+QN\log^2(N+2))
\]
additional bit work. Recognition occurs once; requested output bits are regenerated from the authenticated output template, scanning at most $N$ generated bits per request. Alternatively, explicitly retaining the complete transformed $N$-bit source on writable tapes entails $\Omega(N)$ live writable bits in that materialization schedule. A write-only output port cannot be silently reclassified as a free random-access guest input.
\end{theorem}
\begin{proof}
Retain $h$, template class, and two base lengths after the first charged recognition. For every output index generate its corresponding source template up to that index, using only counters. A full writable copy has at least $N$ explicitly retained bit positions by the stipulated copy model. These bounds concern two implementations, not a universal per-instance space lower bound; compact alternatives and recomputation are permitted but must be charged. In the corrected all-phase child-space recurrence $s'\le\max\{\rho,\eta,\lambda,\lambda s\}$, full writable materialization forces $\rho\ge1$, even if freed before a child call. The lazy implementation avoids that space allocation but can destroy an intended time exponent.
\end{proof}
