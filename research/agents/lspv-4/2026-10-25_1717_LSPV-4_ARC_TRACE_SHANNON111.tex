\section{Constructed exact all-input program-dependent contractor}
Fix an exact uniform total ordinary-SAT program $A$. A uniformly fixed interpreter simulates a charged finite prefix of its actual computation on the present formula, recording its input reads; if that prefix halts correctly, return the result, charging it. Otherwise choose the first source variable genuinely read (or a deterministic source fallback), construct both restrictions $F|_{v=0},F|_{v=1}$, repeat once on each child, and call $A$ on all resulting ordinary leaves. Malformed bit encodings are rejected by a paid canonical parser. Three instrumented programs differ in source-read order, so the selected variables genuinely depend on the fixed implementation, though not on the unknown SAT answer.
\begin{theorem}[Exact Shannon reconstruction]
For every ordinary CNF and every deterministic variable policy, including any policy computed from the implementation trace of $A$,
\[
\operatorname{SAT}(F)
=\bigvee_{b_1,b_2\in\{0,1\}}
\operatorname{SAT}(F|_{v_1=b_1,\ v_2(b_1)=b_2}).
\]
The equality holds with distinct second-level pivot choices on separate branches and for UNSAT as well as SAT. No common witness reconstruction is required for an exact one-bit decision.
\end{theorem}
\begin{proof}At every node, satisfying assignments partition by the selected variable's two Boolean values. Reapply this tautological identity at the second level. Trace choices affect the partition only, not the identity. A correct early halt is already an exact decision and all its computation is charged.\end{proof}

\section{New restricted fanout--length incompatibility}
The canonical target $\mathcal C_\star$ comprises unique proper clausewise-monotone ternary clauses with each active variable twice positive and twice negative, excluding only fully complementary-clause-paired formulas. Write $k$ for active variables, $m=4k/3$, and $N=\Theta(k\log k)$ for the declared full input bits.
\begin{theorem}[Trace-independent M22 clause-retention barrier]
In a pure Shannon-restriction full binary tree, if a root-to-leaf path assigns $d$ distinct original variables and does not perform additional learned deletion, semantic projection, source-dependent compression or early pruning, then at least $m-4d$ original clauses survive untouched. Every ordinary child that has $N^{\lambda+o(1)}$ encoded bits for a fixed $\lambda<1$ must have $d\ge k/3-o(k)$. If every leaf reaches that depth, the full binary tree has at least $2^{k/3-o(k)}$ leaves. This conclusion is independent of any bounded program trace used to choose pivots.
\end{theorem}
\begin{proof}Each pivot occurs in exactly four original clauses; a union of $d$ pivot supports touches at most $4d$ clauses. All remaining original full-width records survive intact and require $\Theta(\log k)$ bits each. A fractional-power child must retain $o(k)$ such records, hence $m-4d=o(k)$. Every full binary tree of minimum leaf depth $d$ has at least $2^d$ leaves.\end{proof}
This is a theorem only about this full restriction architecture; source-aware propagation, learning, SCC/Horn/affine solving, alternative representations, certified branch pruning and early decisions change its premises. The $m-4d$ component appeared earlier in M22-DP-COVER106; this run audits the stronger fanout-versus-length implication for trace-guided splitting.
\paragraph{Net enumerative budget.} Four full second-level children with $k-2$ remaining source variables have $\Psi=4\cdot2^{k-2}=2^k$ and $R_{\rm search}=k-\log_2\Psi=0$. Although $R_{\rm raw}=2$ variable assignments per leaf, no net aggregate enumeration budget was removed. This is NOT a mandatory-work lower bound.

\section{Same-machine charged resources and extensional firewall}

\[
T_{C_A}(N)\le\sum_{\ell<d}2^\ell(B(L_\ell)+2G(L_\ell))

\]
Peak simultaneous writable space counts the current child, retained ancestors, actual child solver work and index cells, trace interpreter and caches. \begin{theorem}[Cheap trace-prefix hardwiring, scoped corollary]
Once a finite program $A$ is fixed, an $N^{u+o(1)}$-cost prefix of its execution is a uniform locally computable function of the input. If a hypothetical all-input controller uses only that cheaply simulated trace plus correct membership bits from strictly smaller ordinary SAT queries, and has the fully charged time, writable-space and query hypotheses of MODELBRIDGE-0011, the existing downward oracle-elimination theorem applies after hardwiring the fixed description of $A$. Its resulting unconditional same-machine SAT bounds cannot enter the FLMV forbidden box.
\end{theorem}
This is a restricted corollary of prior work, not a new unrestricted model lower bound. With $(a,\lambda,r,p)=(3/5,1/2,11/10,1/2)$, downward elimination would yield $(6/5,1/2)$ in the strict box. Consequently cheap, locally simulated implementation traces ALONE cannot yield such a universally correct extensional controller.
