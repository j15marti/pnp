\section*{Exact port acquisition}
The input is a topologically ordered, explicitly indexed signed fan-in-two Boolean DAG with conservative CONST0/CONST1, AND, OR, NOT gates and three publicly named earlier wires $u,v,w$. The output is a named port $p$, and the compiler must emit its canonical eight-bit table
\[
\operatorname{PORTMAP}_3(G,p)=\sum_{a=0}^7 2^a p(a_0,a_1,a_2),\quad a=a_0+2a_1+4a_2.
\]
Malformed records and forward gate references are rejected. Arbitrarily large internal gate DAGs are permitted, with fully paid encoding and validation.

\begin{theorem}
Computing $\operatorname{PORTMAP}_3$ is P-complete under logspace reductions, even for one nonconstant public output and the same syntactic three-wire cut. Consequently, an unannotated deterministic $O(\log M)$-workspace compiler for every such instance would imply $L=P$. This is a conditional complexity-class implication, not a proved superlogarithmic space lower bound.
\end{theorem}
\noindent\textbf{Proof.} Membership in P follows by eight explicit topological DAG evaluations. Reduce the constant-fed monotone Circuit Value problem, P-complete by Ladner and Goldschlager. If the input DAG has designated bit $t$, add a constant number of AND/OR/NOT gates computing
\[
p(u,v,w)=(u\oplus v)\oplus(t\land w).
\]
Each XOR has a four-gate AND/OR/NOT implementation, and all parent pointers are earlier IDs. For $t=0$ the output mask is \texttt{0x66} (102); for $t=1$ it is \texttt{0x96} (150). Both ports are nonconstant. Their output at $(u,v,w)=(0,0,1)$ is $t$. The reduction is logspace uniform. A correct fixed-bank alias which preserves the output relation must distinguish these masks, and its canonical fixed-bank decoding similarly recovers $t$. This proves the claim.

\noindent\textbf{Both-label CNF control.} For each gate add standard unique-extension Tseitin equivalence clauses. Add $\neg u,\neg v,w,p$. The resulting ordinary CNF has $\Theta(g)$ clauses and $O(g\log g)$ binary-encoded bits and is SAT iff $t=1$, UNSAT iff $t=0$. One uniform polynomial-time evaluator decides both; its rejecting answer is not thereby an $R_{\mathrm{mix341}}$ proof.
