## Exact source, theorem, permitted methods and model

Let G=(V,E) be ANY finite simple cubic graph, possibly disconnected, with H vertices and M=3H/2 edges. An original source is the four **proper signed** ternary clauses per vertex v that exclude precisely the local assignments a to its three incident original edge variables with XOR(a) != chi_v:

$$
F_{G,\chi}=\bigwedge_{v\in V}\;\bigwedge_{a:\oplus a\ne\chi_v}
\left(\ell_{e_1,a_1}\lor\ell_{e_2,a_2}\lor\ell_{e_3,a_3}\right),\qquad
\ell_{e,0}=x_e,\quad\ell_{e,1}=\neg x_e.
$$

There are exactly 4H original clauses and 3H/2 source variables. For O(H)-sized variable IDs, encoded bit length N=Theta(H log(H+2)); arbitrary-length decimal variable names enlarge actual N. The source may arbitrarily permute clauses, literals and injectively rename variables. The full parser must reject malformed encodings and report OUTSIDE for a well-formed source not matching the exact four-mask/simple-cubic incidence grammar. It never silently assumes the graph metadata.

**Theorem 485.1 (PROVED/RESTRICTED, standard logspace transducer):** There exists ONE deterministic algorithm on read-only source / write-only output / O(log(N+2)) writable workspace which, for every binary input encoding strict original signed cubic-Tseitin 3-CNF, returns either UNSAT with an odd-charge component identifier or SAT and emits a complete correct edge-variable satisfying assignment, and which returns BAD_FORMAT or OUTSIDE on other binary strings as indicated by its fixed syntax. All outputs are correct; the algorithm runs in polynomial time of **unspecified exponent**.

**Proof and explicit construction.** Apply the prior LSPV-2/442 support-triple/mask recognizer using input offsets, token comparisons and repeated source scans, all within O(log N) writable cells. For recognized source, enumerate support triples as vertices and distinct original variable-token names as edges, using first-occurrence ranks with O(log N)-bit counters. This defines a fixed total order e_1,...,e_M on edges. For each e_i=(u_i,v_i), test USTCON in the graph G_{<i} consisting only of earlier-ranked edges. Let

$$
e_i\in T\quad\Longleftrightarrow\quad u_i\not\leftrightarrow v_i\text{ in }G_{<i}.
$$

This is precisely Kruskal's canonical **spanning forest** T, regardless of graph connectivity; membership queries do not materialize T. Loop over vertex-minimum component representatives using ordinary USTCON on G. If any component C has \(\oplus_{v\in C}\chi_v=1\), output UNSAT and its representative. If all components are even, set every edge outside T to 0 and for each e_i in T define S_i as the component containing u_i in T\{e_i}. Output

$$
\boxed{x_{e_i}=\bigoplus_{v\in S_i}\chi_v}\qquad(e_i\in T),\qquad x_{e_i}=0\quad(e_i\notin T).
$$

All endpoint/component membership queries in T\{e_i} are USTCON on an **implicit** undirected graph. Its adjacency predicate requires at most one inner USTCON test in G_{<j} to establish whether e_j is a Kruskal edge. Thus the nesting depth of logspace machines is constant, and standard logspace closure under such composition preserves O(log N) total workspace with polynomial time. Each original variable ID may be streamed directly from source offsets to the output, even if its token has enormous length; no O(length-of-token) WORK buffer is used. Output length is O(N), as every edge variable occurs a constant number of times in the original source.

For any vertex v, removing each incident tree edge partitions its tree component into the corresponding branches and {v}. Since component charge parity is zero, the XOR of branch charges is chi_v. Tree-edge assignments are exactly those branch charges, and non-tree edges are zero. Hence every original vertex equation, and therefore every original signed source clause, holds. Conversely an odd-charge component cannot be satisfied because summing its vertex XOR equations cancels each internal edge twice. The emitted original-source assignment is therefore complete and correct. QED using Reingold as a published dependency.

**Actual resources, not symbolic proof-node costs:** source/INDEX/head reads, parser rescans, token ranking, nested reachability, output streaming, and recomputation are all part of the unspecified polynomial time. A constant number of O(log N)-space USTCON machines at constant nesting, their live configs, head positions and loop counters occupy O(log N) writable cells; no dense graph, table, forest, branch cache, all-answers vector or materialized CNF child is retained. All source bytes are read-only; all output is append-only. Explicit graph construction, polynomially many connectivity calls and output copying are NOT free; the bound does not assign them near-linear time. Exact native FLMV INDEX semantics and time exponent remain UNVERIFIED. No SAT-child guest simulation occurs; no search/restarts/failed policies occur in this fixed deterministic construction. This is an **upper-bound search algorithm for a strict source family**, not an LSPV-2 all-input A->Phi(A) compiler, nor a native R_mix341 proof.
