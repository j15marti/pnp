## ITERATE: exact lower bound, no SAT hardness inferred
Fix an accepted source-bound one-node oriented RES refutation of the valid strict-DIMACS bytes
`c a^M\np cnf 1 2\n1 0\n-1 0\n`, where `a^M` denotes M literal comment payload bytes. Change any single comment `a` to `b` in the **external original source**, leaving the accepted proof and embedded exact raw bytes unchanged. Every mutation is again valid and parses to the **same labelled UNSAT** CNF. An exact raw-byte checker must reject each, and therefore on the accepted input must read every one of the M source-byte positions. Otherwise a never-read byte can be altered with exactly the same deterministic trace. Hence **T >= M single-byte input probes**, or >= ceil(M/w) fixed-w-bit probes (>=M/k native read steps for fixed k independent heads). This is a theorem about *source authentication*, not arbitrary SAT algorithms: a semantic-only SAT solver can ignore comments and M is already part of original input length N.
