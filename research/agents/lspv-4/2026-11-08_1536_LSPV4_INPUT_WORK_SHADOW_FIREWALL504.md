## ITERATE 504.1: exact restricted failure of an INPUT-to-WORK shadow

Let B be **any fixed total** three-label decider on binary inputs, with native time T_B(n) and high-water space S_B(n). If B is additionally assumed a correct polynomial-time SAT decider, its correctness is preserved, but that hypothesis is **not** needed for the construction. For integer k>=1, define L(n)=k ceil(log2(n+2)) and A(n)=2^{L(n)}. Define the typed wrapper G_k(B), for every input x of length n:

1. Count the read-only INPUT length n on the actual indexed machine, construct the L(n)-digit binary INDEX of A(n) and jump the INPUT head to A(n).
2. Read the guaranteed blank (A(n)>n). Return INPUT head to the start, paying fresh INDEX construction and mandatory index erasure.
3. Erase private scratch and execute B(x) on clean, separate guest tapes. Return the EXACT B label for SAT, UNSAT, and MALFORMED.

The typed wrapper has **additive** native T=O(n log(n+2)+k log(n+2))+T_B(n), and its WORK peak is O(max(S_B(n),log(n+2))) for fixed k. Conservatively count the INDEX digits and head descriptions as O(k log n) temporary physical information even though the FLMV non-index WORK high-water definition is more specific. INPUT jumps themselves do not add an A(n)-sized WORK charge.

Now implement an incorrect general-purpose *accounting claim* that marks every observed INPUT address j on an auxiliary ordinary indexed WORK read-mask tape at the **same** address j. The wrapper's single otherwise harmless INPUT read at A(n) now incurs WORK high-water at least

$$
S_{\mathrm{shadow}}(n)\ge A(n)=2^{k\lceil\log_2(n+2)\rceil}=\Theta(n^k).
$$

This contradicts the claim that the shadow has O(n+S_B(n)) native space whenever k is chosen so that n^k dominates n+S_B(n). It does **not** prove all monitors require this space. A host-language sparse Map that allocates one record is not an execution of this physical indexed-WORK architecture.

**Exact restricted repair:** for this publicly typed wrapper, A(n)>n proves the observed INPUT bit is blank on *every* binary string. Record only a one-bit "out-of-range blank observed" status, or delete the dead probe when the trace is not an observable output. Both preserve the three final labels. One may retain the guest INPUT jump if trace-level audit is required, but MUST NOT perform a high-index auxiliary WORK jump. Time O(T_B(n)+n log(n+2)) and local peak O(log(n+2)) persist.

These claims are **PROVED/RESTRICTED** and already exploit known source and machine-model principles. The revised claim is narrower than the initial universal shadow proposal: the input-to-WORK coordinate-copy shortcut FAILS for arbitrary INPUT-head indices, but a typed out-of-range probe has a low-space source-blank repair. No universal B code transformation or child contraction follows.

## ITERATE 504.2: bounded-coordinate live-in monitor, conditional implementation lemma

Under the additional, **syntactically authenticated** restriction that the guest's INPUT head and INDEX jumps stay inside [0,M] throughout the observed suffix and their canonical binary indices have O(log(M+2)) bits, an actual auxiliary indexed WORK read-mask may mirror the INPUT coordinate while staying within a non-index high-water of M+O(1). Duplicate the guest's index string BEFORE the indexed jump erases the original INDEX tape; charge O(log(M+2)) extra time per indexed jump. Synchronous non-index head moves preserve alignment. Mark INPUT positions read and their observed bit values. Instrument each original guest WORK cell with constant extra tape-alphabet tracks recording (a) whether the suffix already wrote the cell and (b) the first-read-before-write value, at the SAME physical guest WORK coordinate. Never claim a separate sparse host Map to be native.

**Sufficient bounded-coordinate bound:** If the actual guest suffix has T steps and high-water S, one anchor instrumentation and source-mask construction can use O((T+M) log(M+2)) time and O(S+M+log(M+2)) total simultaneous non-index WORK high-water, including shadow source mask, retained INPUT bytes and the guest, plus index/output charges. For q further fully materialized length-M children, scanning the saved anchor mask and each candidate original child in order costs O(qM) comparison time and O(M+S) simultaneous WORK space **if** all necessary candidate checkpoint live-ins are already accessible with separately charged reads. A verified live-in agreement then implies trace equality by LSPV-2/505's deterministic transition induction. This is a sufficient restricted, physical **upper** control, not a native all-guest transcript generator. If candidate checkpoint WORK reads, retrieval, reconstruction or bad policy search exceed the budget, they MUST be added.

At q=N^{3/5+o(1)}, M=N^{1/2+o(1)}, the INPUT comparison alone costs N^{11/10+o(1)}, matching the proposed local-time exponent, whereas q simultaneously retained source masks require N^{11/10+o(1)} WORK bits and violate the space goal. Use one anchor and sequential child comparison or charge cache retention/recomputation. This does not supply a child generator and does not bound actual SAT-guest time if reuse fails.

**Falsifier outcomes:** F1 FIRED: out-of-range INPUT coordinates are free of corresponding WORK high-water. F2 FIRED against a direct sparse-map interpretation; logical sparse storage can be a different, fully charged compiler, not this shadow. F3 did not fire: labels are unchanged after the typed blank repair. F4 remains an explicit all-input implementation limitation; the bounded-head and actual checkpoint-cost assumptions cannot be silently extended to arbitrary B.
