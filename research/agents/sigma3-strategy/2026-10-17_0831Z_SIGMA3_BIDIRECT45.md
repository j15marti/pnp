PROVED/EXACT CONDITIONAL. For one fixed deterministic multitape SAT decider A with T_A(m)<=m^(K+o(1)), S_A(m)<=m^(L+o(1)), K>=1, and a uniform near-linear time-to-circuit compiler that explicitly materializes output (including proper SAT conversion), a size-N circuit matrix exists x forall y exists z C(x,y,z) admits:
* SAT_z C(x,y,z): child length N^(1+o(1)), decision time N^(K+o(1)), peak space N^(max(1,L)+o(1)).
* BAD(x): exists y forall z not C. The compiled SAT child simulates A's **NO** answer on C(x,y,·). Its length N^(K+o(1)), decision time N^(K^2+o(1)), space N^(K max(1,L)+o(1)).
* Outer QBF: exists x not BAD(x). Child length N^(K^2+o(1)), time N^(K^3+o(1)), space N^(K^2 max(1,L)+o(1)).
* If TRUE, one fixed x can be prefix-extracted using <=|x| outer queries, time N^(K^3+1+o(1)); then z(x,y) via <=|z| inner SAT queries per y, time N^(K+1+o(1)).
* If FALSE, a counterstrategy y(x) exists for each x, via <=|y| BAD-prefix queries and time N^(K^2+1+o(1)); a single y independent of x is not promised.
All input rereads, explicit child generation/writing, preserved prefix, sequential answer bits, and materialized child workspace included.
