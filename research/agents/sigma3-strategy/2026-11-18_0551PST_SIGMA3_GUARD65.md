## THEOREM A: Source-built universal candidate versus hard winning certification
Take any explicitly encoded nonempty 3CNF F(x)=AND_{j<m} C_j(x) of length N. Let j be a universal clause index (out-of-range indices select true clauses), and g_F(x,j)=1 iff selected clause C_j is false. A deterministic gate circuit enforces all trace wires uniquely, including bit h=g_F(x,j). Define
  Phi_F = EXISTS x FORALL j EXISTS h,z:
      [h=g_F(x,j)] AND [ (h=0 AND z=(j mod 2)) OR (h=1 AND z=0 AND z=1) ].
For fixed x,j, exactly one h exists. If h=0 exactly one z exists. If h=1 the local Horn unit pair z=0 and z=1 makes continuation impossible. The selected local continuation is constant-size affine equality or constant-size Horn contradiction, but the nonlinear selector retains all source information. The formula Phi_F is TRUE iff F is SAT. Its restricted language is NP-complete, NOT claimed Sigma3-complete, because there are only polynomially many indexed j challenges.

Construct j_F(x) as the first falsified clause index if any, else index zero. A priority encoder and m local clause-violation gates give an O(m log m) size circuit constructed from F WITHOUT a SAT solve. It is an explicit proposed Herbrand counterstrategy for EVERY F. Yet
   forall x, g_F(x,j_F(x))=1   iff   F is UNSAT.
Thus testing whether this particular mechanically source-built strategy is winning is coNP-complete (under the mapping F -> j_F); the complement has a satisfying assignment x. For false Phi, every proposed x has a genuine counterchallenge j_F(x) and independently checkable local NO unit contradiction. But source-building the circuit alone does NOT establish the global unsatisfiability claim. For true Phi, there is a compact winning x and a constant trace response h=0,z=(j mod 2). This separates compact strategy descriptions from global winning validation, without inferring a time/space lower bound from the exponentially many possible x states.

## THEOREM B: Semantic one-bit separator verification is coNP-complete
Given an arbitrary Boolean circuit C(s,u), checking whether C(0,u)=C(1,u) for all u is in coNP (a violating u is an NP witness for complement). Reduce UNSAT(F) by setting C(s,u)=s AND F(u): it is independent of s iff F is UNSAT. Hence semantic source partition checking can be coNP-complete even for a single proposed independent bit. In contrast, syntactic clause-support checking for an already authenticated tagged decomposition is polynomial. Do not count semantic certification for unrestricted circuits as free. This is an elementary scoped reduction, not an unconditional superpolynomial lower bound.

## K/L conditional resource accounting on one uniform machine
Let a fixed correct deterministic SAT decider A use time m^{K+o(1)} and writable space m^{L+o(1)} (K>=1, L>=0). Decide Phi_F via A(F): N^{K+o(1)} time, N^{max(1,L)+o(1)} simultaneous space with a mutable full-source/query buffer. YES complete witness extraction uses <=n+1<=N+1 ordinary SAT calls on pinned sources of size O(N): N^{K+1+o(1)} time, N^{max(1,L)+o(1)} same-machine space. Skolem z(j), h=0 generated after verified x. NO uses an actually charged A(F)=NO decision; then build the j_F source circuit at O(N log N) gate/output size. Its correctness as a winning universal strategy depends on that negative decision (or a separate UNSAT proof), not merely on its construction. A local (x,j) continuation is tiny only after full selector evaluation and does not constitute an equivalent smaller SAT child. Ordinary source-preserving SAT self-reduction still yields lambda=1. No forbidden simultaneous time-space pair and no all-input hereditary lambda<1 were obtained.
