## Theorem A1, PROVED/EXACT, closed checkpoint vs two-stage interface
Let m=2^r >=2, v in {0,1}^m, and F(v) ANY Boolean circuit including arbitrary CNF, with possibly nonlinear dependence on all coordinates. A first universal challenge j selects the genuine indirect address k=j XOR p, where p=F(v). The forced continuation trace is z=(p,v_k), uniquely determined. A later universal challenge (a,b) requires z=(a,b). The exact decision service D_F(v,j,a,b) is YES iff (a,b)=(p,v_{j XOR p}); otherwise NO and an actual forced trace provides a checkable mismatching-bit certificate.

Any deterministic **closed, prechallenge** representation h(v) that must reproduce D_F for every j,a,b with no rereading v is injective; at least m bits are required in the worst case. Proof: identical h gives identical YES/NO response profiles. Requesting (a,b)=(p,v_{j XOR p}) implies equality of both trace bits for all j, so F(v)=F(w)=p. For every k choose j=k XOR p; v_k=w_k. Thus v=w, and h has 2^m distinct values. In contrast, after j is fixed, h_j(v)=(p,v_{j XOR p}) is two bits and is sufficient for all later (a,b).

The bound is an exact, elementary one-way INDEX-style communication/storage bound under an explicit no-reread contract, NOT an arbitrary SAT runtime or workspace bound. Critical falsifier: for nonlinear F(v)=OR_i v_i on an immutable read-only source, the algorithm scans for p, then scans again for v_{j XOR p}; time O(m) and writable space O(log m), defeating any extrapolation from closed checkpoint width to general low-space machine time.

## Theorem A2, PROVED/EXACT, globally uniform outer strategy
For any 3CNF G(v)=AND_j C_j(v), pad clause challenges by tautologies. Define
  Psi_G = EXISTS v FORALL j EXISTS z_0,z_1 :
    C_j(v) AND [z_0=F(v)] AND [z_1=v_{(j+z_0) mod n}].
For every fixed v,j the *gate trace is unique*, but the matrix is satisfiable iff C_j(v). Hence Psi_G TRUE iff G SAT. A true instance gives a SINGLE global v and adaptive z(j). For any false candidate v, a genuinely falsified clause j(v) defeats that commitment and has a checkable local NO certificate. Producing a short circuit for j(v) is not an UNSAT proof: verifying that it wins against ALL v is coNP-complete. This is a uniform polynomial-time source reduction, not a new NP hardness theorem. A two-bit local trace must not be mistaken for a two-bit child encoding; full source evaluation and global commitment remain.

Prefix controls: EXISTS x FORALL y (x=y) false, FORALL y EXISTS x (x=y) true. Unique trace never licenses swapping the quantifier prefix. Affine, Horn and parity controls remain easy despite high treewidth; nonlinear coupled guards do not magically inherit their grammar.
