## A. Exact source CNF with unique row-dependent local blocker (PROVED)

Take R=2^h shared assignments z, B disjoint one-bit private variables y_j, and any function p:[R]->[B]. Let D_r(z) be the clause expressing z!=r. Define ordinary CNF

`G_p(z,y) = (AND_j y_j) AND (AND_{r in [R]} [D_r(z) OR NOT y_{p(r)}])`.

Block j contains unit y_j and precisely the guards assigned to j. After pinning z=r, D_s is true for every s!=r, and D_r becomes false. Thus exactly block p(r) contains opposite units and is UNSAT; every other block is satisfiable. The full CNF is UNSAT. Deleting exactly r0's guarded negative clause makes a SAT sibling witnessed by z=r0, all y_j=1; other rows retain their individual blockers.

The local refutation is a **source-checked unit pair after restriction**, not an unverified index. Any incorrect block index at a row must yield UNKNOWN, never a global opposite label.

**Selector-entropy caution:** B^R arbitrary p tables need at least ceil(R log2 B) bits if encoded separately **without source access**. This is not a bound on general algorithm work space when p is explicitly readable from the source.

## B. Tight restricted row-query bound (PROVED, SOURCE-OPAQUE ONLY)

If the only allowed oracle operation reveals SAT/UNSAT of a selected (r,j) child, then a deterministic uniform solver distinguishing 'every row has a NO' from 'some row is entirely YES' can be forced to make RB queries: answer YES on the first B-1 new probes of each row and NO on the last. A correct UNSAT decision must exhibit a NO on every row, or an all-YES row remains compatible with the transcript. Row-by-row first-NO scan matches RB. ## C. T5 H_t all-row selector (PROVED, canonical prior family)

For the existing LSPV-3 graph H_t, T5 traversed forward-path differences are {1,3}, backward {2,4}; direct F support is {1,3}, FBB is {0,1,2,4}, intersection {1}. Link i connects u_i to u_(i+1) with both F and FBB. A closure path W_t from u_t to u_0 excludes d=-t mod5, with W_t=BB when d=0, else B^(d-1)F^(4-d).

**Algorithm:** scan i in order; let delta=(color(u_(i+1))-color(u_i)) mod5. If delta=3, select link i's FBB; else if delta!=1 select direct F. If all deltas equal 1, select closure. In the first case chosen support excludes delta; in the second, telescope gives closure difference -t, excluded from W_t. Therefore every terminal row has a genuinely impossible local path, selected by O(t) canonical-input operations and O(log t) writable selector state (plus charged source parsing and validation).

For each of the 2t+1 original path blocks a dedicated terminal row makes it uniquely bad, so the **static source-path menu** has 2t+1 essential entries, yet a single short deterministic program chooses among them. Menu size, strategy program size, validity proof, and execution resources are different quantities. Prior H_t intrinsic-critical construction and general path-cover proof are credited to LSPV-3.

## D. Quantifiers, correct paths and matching SAT cost

For authentic disjoint private blocks,
`SAT(F) iff EXISTS z FORALL j EXISTS Y_j F_j(z,Y_j)`.
`UNSAT(F) iff FORALL z EXISTS j FORALL Y_j NOT F_j(z,Y_j)`.
A single favorable row or one guessed blocker does not satisfy the second quantifier pattern. `FORALL z EXISTS j` cannot be exchanged with `EXISTS j FORALL z`.

With R<=N^.195, B<=N^.65 per row, m<=N^.35, and a fixed total exact uniform SAT seed of time m^K and work space m^L, charged row scanning has time
`P(N)+N^(1.195+o(1))+N^(.845+.35K+o(1))`;
one-child-at-a-time work space
`S_P(N)+N^(.35+o(1))+N^(.35L+o(1))`.
This assumes streaming and no retained N^.65 index table. The one-step (1.33,.5) gates need K<=97/70=1.385714..., L<=10/7 and paid preprocessing/peak storage. SAT in P alone gives neither exponent.

An externally supplied complete NO route has k=R ceil(log2 B) bits, and can be verified with R *actual negative child decisions*, plus route creation/access/replay and full source validation. A wrong index returns UNKNOWN. Nondeterministically choosing indices one row at a time also requires every row to pass. Deterministic naive enumeration costs 2^k verifier runs, but **because these product-row certificates factor**, uniform row-local search costs RB calls instead of B^R. ## E. Rigorous literature polarity firewall

- **Deterministic all-input SAT decision** on compatible random-access model: Buss–Williams 2015 Figure 8.2 gives an alternation-trading refutation at (c,epsilon)=(1.34070,.5). Therefore a genuine uniform unrestricted (1.33,.5) SAT decider is excluded.
