## Theorem A (PROVED/EXACT, restricted source grammar)
A CNF source explicitly supplies boundary variables S (|S|=k), a total owner map for otherwise disjoint private sets V_1,...,V_q, and PERSISTENT clause tags. Clause tagged i may contain only variables in S union V_i, with encoded block length <= b. A source-only verifier checks the owner table, tags, bounds, and every occurrence. Boundary-only clauses keep their ORIGINAL tags.

For each a in {0,1}^S, F[a] is a conjunction of independent private CNFs. Therefore SAT(F) iff there exists a boundary a for which SAT(F_i[a]) holds for every i. Any YES merges valid private witnesses with a. For a FALSE F, each a has a specific failing child. A genuine correct SAT decider must answer NO on that child, and is actually run to do so. Such negative calls are not counted as free coNP certificates.

For ANY partial assignment to S and/or private variables, deleting satisfied clauses and false literals and RETAINING original clause tags preserves the tag relation and never increases the length of any tagged block under fixed-width encodings. Hence even arbitrarily repeated source restrictions preserve this specific authenticated sublinear-child grammar. Retagging newly boundary-only clauses to one giant common block would lose the size bound; preserving tags is essential.

## Theorem B (PROVED/EXACT): explicit separator obstruction
F_m = AND_{i<j}(v_i OR v_j) has C(m,2) explicit 2-CNF clauses. For any global S with |S|=k, every pair of non-S variables occurs together in a clause, forcing ALL non-S variables into the SAME private block in this grammar. That block has at least C(m-k,2) clauses, and after two pins outside S at least C(m-k-2,2) clauses remain untouched. When k=O(log N), m grows and source length N=Theta(m^2 log m), this is Omega(N) physical child size. m=160,k=8: 12,720 parent records, >=11,476 in the forced largest child, >=11,175 after two pins. This is a strict syntactic separator obstruction ONLY: the example is easy 2-SAT, and alternative equivalent encodings or algorithms are not excluded.

## Theorem C (prior clause-index principle, SAT-dependent nonlinear guard)
Given arbitrary 3CNF F(x), define g_F(x,j)=1 iff clause j is falsified by x, and 0 for invalid challenge indices. Set
Phi_F = EXISTS x FORALL j EXISTS z: [z=g_F(x,j)] AND [z=0].
For every (x,j), the functional gate trace z=g_F(x,j) is UNIQUE. Yet Phi_F is TRUE iff SAT(F). For UNSAT F and a given x, the universal player must select an actually falsified clause j(x); this can depend on x and is verified by evaluating F. A single fixed clause j does not in general defeat all x (e.g. F=(x) AND (NOT x)). Global validation of a purported counterstrategy remains equivalent to an UNSAT claim. Compact trace and local service width do not extract a globally consistent x and do not make NO answers free. This is a scoped restatement and adversarial test of earlier project reductions.
