# RED-0007 — Trace noninvariance and wrapper-insertion attack

**Agent:** RED
**Global status:** P versus NP remains OPEN.
**Target:** trace/source access as the proposed intensional channel after EXTENSIONAL-SHADOW1.

## TRACE-INSERTION1

Fix a deterministic polynomial-time exact SAT decider A. For any polynomial-time computable polynomial-output-length h, define A_h(F) to compute h(F) by a semantically dead auxiliary computation, then execute A(F), then return A(F).

A_h remains an exact polynomial-time SAT decider. Under an ordinary step-by-step trace convention recording the auxiliary computation, Trace(A_h,F) contains an implementation-dependent segment encoding the computation of h(F), while SAT semantics are unchanged.

Therefore exact SAT correctness alone does not constrain the full execution trace to a canonical provenance object.

## TRACE-INVARIANCE1

If a trace functional Phi is required to be invariant under every such semantically dead polynomial-time insertion, then Phi cannot obtain load-bearing information merely from the inserted auxiliary segment. This does not prove Phi extensional; a robust intensional core may remain.

## INTERP / RECOMP

A fixed universal interpreter can replace direct execution by U(<A>,F), radically changing low-level traces without changing SAT semantics. RECOMP can replace retained state by later recomputation. Thus trace length, literal state identity, retained-state volume, and raw trace provenance are not semantic invariants.

## Counterfactual P=NP control

Under P=NP, fix polynomial-time exact SAT decider A. Its complete polynomial execution trace can be regenerated by simulating A, and every polynomial-time functional of that trace remains polynomial. Hence trace exposure alone cannot force the desired superpolynomial acquisition contradiction. This sharpens, and is consistent with, TRACECLOSE1.

## Trace trilemma

1. Literal trace: intensional but wrapper-sensitive.
2. Semantic quotient trace: robust but risks program-equivalence/minimization.
3. Explicit proof-generated projection: plausible, but must prove wrapper covariance, genuine nonextensionality, charged acquisition, and a model-matched lower bound.

## Easy-family controls

The same pathology occurs for 2-SAT/SCC, XOR/Tseitin/Gaussian elimination, Horn closure, and bounded-treewidth DP: arbitrary polynomial dead computation can inflate traces while the decision problem remains polynomial.
