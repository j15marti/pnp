\section{Same-machine bit-descent theorem}
\begin{theorem}[Strict one-child descent]\label{th:descent}
Let $C$ be a fixed uniform deterministic algorithm with $O(n^c)$ fully charged time per invocation, $c\ge1$, which on every valid $x$ of length $n>N_0$ outputs a physically materialized $y=C(x)$ satisfying the displayed closure, correct-answer and $|y|\le n-1$ properties. Suppose every base instance of length at most $N_0$ has a fixed correct decider. Then $L\in P$. If $L$ is NP-complete, $P=NP$. If the stronger $|y|\le n^\lambda$ holds for a fixed $0<\lambda<1$, total time is $O(n^c)$ when the invocation cost already includes making the emitted child usable as the next input.
\end{theorem}
\begin{proof}
Repeatedly call $C$ and use the answer on the last base instance. Answer preservation establishes correctness for both SAT and UNSAT by induction, without a free membership bit. One-bit descent makes at most $n-N_0$ invocations, so total native cost is
\[
 T(n)\le\sum_{m=N_0+1}^{n}O(m^c)=O(n^{c+1}).
\]
For power descent, the lengths are bounded by $n,n^\lambda,n^{\lambda^2},\ldots$, with $O(\log\log n)$ nonbase calls, giving
\[
 T(n)\le O(n^c+n^{c\lambda}+n^{c\lambda^2}+\cdots)=O(n^c).
\]
If ancestor storage is not reclaimed, summing all polynomial intermediate spaces still gives a polynomial footprint. In-place reclamation is optional, not an uncharged assumption. An NP-complete $L$ gives SAT in $P$ after a polynomial many-one reduction.
\end{proof}
\begin{remark}[Equivalence firewall]
The bare mathematical existence of an efficient bit-shrinking map on such a class is itself logically equivalent to $P=NP$. In the reverse direction, under $P=NP$, decide $x$ first and output one of two fixed, valid YES/NO instances. This direction \emph{uses a SAT decider}, and is not an admissible unconditional construction for the research target. Therefore the equivalence is a precise reformulation, not a P-versus-NP resolution. The central new work must supply a specific noncircular compiler. One fewer variable is irrelevant if the \emph{encoded bit length} increases.
\end{remark}

\section{Exact projection and optimal auxiliary-free CNF count}
Let the $4t$ variables $a_i,b_i,c_j,d_j$ all be distinct and define
\[
 A_i=a_i\vee b_i,\quad B_j=c_j\vee d_j,\qquad
 F_t(z,x)=\bigwedge_{i=1}^{t}(z\vee A_i)
             \land\bigwedge_{j=1}^{t}(\neg z\vee B_j).
\]
By the two values of $z$ and distributivity,
\begin{equation}\label{eq:project}
 G_t(x)=\exists z F_t(z,x)
 =\left(\bigwedge_i A_i\right)\vee\left(\bigwedge_j B_j\right)
 =\bigwedge_{i,j}(A_i\vee B_j).
\end{equation}
With an arbitrary disjoint core $R(y)$ the projection is $R(y)\land G_t(x)$.

\begin{theorem}[Irredundant prime-corner barrier]\label{th:clauses}
Any CNF representing $G_t$ as the same Boolean function \emph{using only the original $4t$ variables and no auxiliaries} has at least $t^2$ clauses, even allowing negative literals, repeated literals and arbitrary width. The $t^2$ four-literal resolvents in \eqref{eq:project} attain the bound. A shared binary AND/OR circuit computes the same projected function using exactly $4t-1$ gates.
\end{theorem}
\begin{proof}
For every $(i,j)$ let $x_{ij}$ set precisely $a_i,b_i,c_j,d_j$ to zero and all other original variables to one. Then $G_t(x_{ij})=0$. Flipping any of the four zero variables to one makes all $A_i$ or all $B_j$ true and hence makes $G_t$ true. In every equivalent CNF a clause $D_{ij}$ is falsified by $x_{ij}$. It must become true after each single flip. The only literal that can change false-to-true under flipping a particular zero coordinate is its \emph{positive} literal, so $D_{ij}$ contains the four positive literals $a_i,b_i,c_j,d_j$. At every other $x_{pq}$ at least one of these four literals is one, so $D_{ij}$ cannot be its falsified clause. There are therefore $t^2$ distinct clauses. The resolvents attain this, while a circuit uses $2t$ OR gates for the $A_i,B_j$, $2(t-1)$ AND gates for their conjunctions, and one final OR, totaling $4t-1$.
\end{proof}
\noindent With $w=\lceil\log_2(4t+2)\rceil$ bits per variable identifier, the parent has $6t$ literal tokens while the direct projected CNF has $4t^2$ tokens, requiring at least $6t(w+1)$ versus $4t^2(w+1)$ literal-field bits in this fixed natural encoding. The shared DAG needs $O(t\log t)$ serialized bits, not a fixed power-shrink from $\Theta(t\log t)$. Reintroducing $z$ yields the original $2t$ clauses. \textbf{Scope warning:} Standalone $F_t$ is always satisfiable; a decision-only compressor could simply output YES. This theorem constrains \emph{function-preserving auxiliary-free CNFs}, not arbitrary satisfiability-preserving preprocessing and not general SAT algorithms.
