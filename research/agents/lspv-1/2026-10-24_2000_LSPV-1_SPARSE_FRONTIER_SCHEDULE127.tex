\section{Independent structural parameters and machine contract}
An all-input uniform virtual normalizer accepts an ordinary SAT source \(F\) of \(N\) encoded bits. It creates a finite equisatisfiable stream of events \(\mathsf{OPEN}(v)\), \(\mathsf{CLAUSE}(\ell_1,\ell_2,\ell_3)\), \(\mathsf{CLOSE}(v)\), where each variable has a single contiguous active interval, each clause mentions only active variables, all shared variable identities are preserved or correctly reconstructed, and the stream ends with an empty frontier. The normalizer's semantic correctness is a \emph{hypothesis}, never inferred merely from syntactic widths or unrelated child SAT bits. Source parsing, recognition, failed candidates, auxiliary variables, ordinary child headers and bit access, index arithmetic, gluing, caches, and switching must be charged.

Assume the complete valid encoded stream contains \(B(F)\le N^{\mu+o(1)}\) bits and can be discovered and validated in \(N^{r+o(1)}\) primitive bit work, \(N^{\zeta+o(1)}\) live work/index bits. A uniform sequential decoder can deliver each stream bit at time \(N^{a+o(1)}\) and simultaneous counted space \(N^{\sigma+o(1)}\), including source reads and all program control. No nonuniform advice and no free readable output tape are allowed. Let \(L(F)\le B(F)\) be the event count, and let \(w_i\) denote the number of live variables after event \(i\), with \(w_0=w_L=0\). Define an \emph{analysis-only structural parameter, independent of actual runtime}:
\[
 \Psi(F)=\sum_{i=1}^{L(F)}2^{\max\{w_{i-1},w_i\}}.
 \tag{1}
\]
Assume the uniform every-input upper guarantees
\[
  \max_i w_i\le \kappa\log_2 N+o(\log N),\qquad
  \Psi(F)\le N^{\chi+o(1)}.
  \tag{2}
\]
The solver need not compute \(\Psi\) or receive the correct SAT/UNSAT label. The decoder may follow an arbitrary uniform computable state-dependent policy; the contract is on its complete observed execution.

\section{Weighted charged simulation and proof}
\begin{theorem}[Trajectory-weighted virtual frontier theorem]
Under the preceding all-input typed normalizer contract, there exists one fixed uniform deterministic all-input exact SAT decider with simultaneous FLMV-model bounds
\[
 \boxed{t'\le\max\{r,\mu+a,\chi\},\quad
 s'\le\max\{\zeta,\sigma,\kappa\}.}
 \tag{3}
\]
Both coordinates refer to the same implementation, and all exponents retain \(o(1)\) simulation slack.
\end{theorem}
\begin{proof}
Maintain a table whose rows are exactly the assignments to active variables extendable to an assignment satisfying the processed event prefix. On \(\mathsf{OPEN}\), duplicate rows with both values. On \(\mathsf{CLAUSE}\), discard falsifying rows. On \(\mathsf{CLOSE}\), existentially project the closing variable. The contiguous lifetime invariant makes this inductively exact, including global cross-clause compatibility; final table nonemptiness equals \(\operatorname{SAT}(F)\). The width at each event controls the row visits by \(O(2^{\max(w_{i-1},w_i)}\operatorname{polylog}N)\), because active width is \(O(\log N)\). Summing over actual events gives \(O(\Psi(F)\operatorname{polylog}N)\) work. Read and buffer the current event record \emph{once} per event, not once per table row; at most \(N^{\mu+o(1)}\) decoder bit reads cost \(N^{\mu+a+o(1)}\). Discovery and validation cost \(N^{r+o(1)}\). One frontier table, event buffer, and simultaneous generator/decoder state take \(N^{\max(\zeta,\sigma,\kappa)+o(1)}\) writable bits. Every transformation, cache, source read, index, failure and switch is part of the promised paid generator or decoder. Polylog overhead for indexed random-access simulation does not change any exponent. Thus both coordinates are achieved by one fixed machine.
\end{proof}

\begin{proposition}[Strict refinement of the prior Role-1 envelope]
The earlier maximum-width bound \(t'_{\rm old}\le\max\{r,\mu+\max(a,\kappa)\}\) is recovered since \(\Psi\le L2^{w_{\max}}\le B2^{w_{\max}}\). A valid connected restricted stream with \(\Theta(N)\) low-width events, but only \(O(\log N)\) events at width \(\kappa\log N\), \(0<\kappa<1\), can have \(\Psi=O(N+N^\kappa\log N)=N^{1+o(1)}\) while \(B2^{w_{\max}}=N^{1+\kappa+o(1)}\). Such streams can be constructed by adding short hub-connected bursts of additional variables to a long width-three clause segment. This is an upper-bound improvement for a restricted algorithm; it is \emph{not} all-decider coverage.
\end{proposition}

\section{Exact forbidden profile}
FLMV Theorem 3.1 and Corollary 5.8 prohibit uniform exact all-input indexed random-access SAT time exponent \(t<c\) jointly with space exponent \(s<\beta(c)\), for
\[
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right),\quad c>1.
 \tag{4}
\]
\begin{theorem}[Conditional universal normalizer exclusion]
No all-input normalizer satisfying all previous contracts exists with
\[
(\mu,a,\kappa,\chi,r,\sigma,\zeta)
=(1,1/20,43/100,1,1,43/100,43/100).
\]
\end{theorem}
\begin{proof}
Theorem 1 gives the simultaneous pair \((21/20,43/100)\). At \(c=53/50\),
\[
 21/20<53/50,\quad
 \beta(53/50)=233623/280900>43/100.
\]
This enters the actual FLMV forbidden region, contradiction. In contrast, the older unweighted \emph{upper estimate} gives \((143/100,43/100)\), and \(\beta(143/100)=505793/4089800<43/100\). The older two-level test is inconclusive, not evidence of achievability.
\end{proof}
The retired product criterion \(t+s<2\cos(\pi/7)\) is not used. A source-aware SAT decider may choose a wholly different representation without paying this particular table; this result therefore does not furnish any ARC successor.
