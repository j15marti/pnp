**Standard lemma, already /442:** Let a valid ordinary oriented binary-RES shared DAG \(\pi\) have source clauses \(C_i\), paid-node count \(q\) and depth \(d\). If every \(C_i\) is replaced by an **already legally available, same-context** \(D_i\subseteq C_i\), a topological compiler assigns each old node \(v\) a derived or referenced \(D_v\subseteq C_v\). On a RES pivot \(x\), resolve the two new parents only if both opposite pivots survive. Otherwise forward the parent's stronger clause whose pivot is missing. Each original node emits at most one paid RES node and each old node maps to exactly one new node or alias, giving \(q'\le q\), \(d'\le d\), and empty final root, without weakening or breaking sharing. This is a known Resolution proof-replay result, not an unrestricted simulation theorem.
