\section{Declared source grammar and independent parameters}
Fix an integer $r\ge1$ and original Boolean variables $x_0,\ldots,x_{r+1}$. Each of the $r$ local gate positions $i=0,\ldots,r-1$ has an arbitrary forbidden set $Q_i\subseteq\{0,1\}^3$, explicitly encoded by one proper ternary clause on the named triple $(x_i,x_{i+1},x_{i+2})$ for each $q\in Q_i$. The clause is false exactly on $q$. Thus the local allowed relation is $R_i=\{0,1\}^3\setminus Q_i$; the relation is acquired from actual signed source clauses, not supplied as a free semantic oracle. Clause groups occur in nondecreasing $i$ and contain no duplicate signed clause. Empty groups are permitted. Source validation checks the complete record sequence and original variable identities.

Three unit conditions $x_0=1$, $x_1=1$, $x_{r+1}=b$ are each encoded by four proper ternaries $(\ell\vee \pm a\vee\pm c)$ with distinct fresh local auxiliaries; all four sign combinations occur. The exact source grammar fixes their order and variable numbering. A canonical header carries $n=r+8$; the clause count is at most $8r+12$. Read-only encoded bit length is $N=(4m+2)\lceil\log_2(64(n+m+1))\rceil$ in the project's fixed-record convention. This is a \emph{restricted canonical ordered-3CNF} language, not ordinary all-input SAT. On rejecting the grammar, a total solver must invoke an exact paid fallback.

The structural interface parameter between successive groups is the two-source-variable set $\{x_{i+1},x_{i+2}\}$, hence its assignment count is four. The set is defined solely from the input's true variable occurrence identities, independently of running time, truth label, and the algorithm eventually chosen. The number of ordinary graph cycles is a different parameter.

\section{Exact source-consistent nonlinear join}
\begin{theorem}[Four-state forward join; PROVED/EXACT restricted]
Every correctly recognized canonical input above is exactly decidable by a uniform four-state dynamic program using $O(r)$ Boolean relation transitions, $O(N\operatorname{polylog}N)$ elementary bit work for complete source acquisition/validation, and $O(\log N)$ writable work/index bits in a source-streaming implementation. SAT yields a reconstructible witness with optional additional replay; UNSAT requires no specified proof format. The statement is \emph{not} an all-input time bound.
\end{theorem}
\begin{proof}
Define $D_0=\{(1,1)\}$ and, for each $i$,
\[
 D_{i+1}=\{(v,w):\exists u\in\{0,1\},
      (u,v)\in D_i,\ (u,v,w)\notin Q_i\}.
\]
After all gates accept precisely when $(v,b)\in D_r$ for some $v$. By induction, $D_i$ is exactly the projection onto $(x_i,x_{i+1})$ of assignments satisfying the initial pins and gate positions $0,\ldots,i-1$. Each transition checks at most eight Boolean triples. The shared pair is retained under identical original names; no independent child witnesses are glued inconsistently. Four feasibility bits encode $D_i$, eight bits encode the current $Q_i$. Sorted signed clause groups and the final three forced-literal gadgets can be checked by a single source scan with $O(\log N)$ counters and addresses. Reading all $N$ encoded source bits, computing masks, checking headers, signs, duplicates and auxiliary IDs, and streaming the eight-case relation updates takes $O(N\operatorname{polylog}N)$ bit operations; the claimed memory excludes only the read-only source. If a SAT witness is required, repeat the source scan with a charged recomputation/backward-selection protocol or retain backpointers with explicitly larger space. One-bit decision does not mandate witness materialization.
\end{proof}

The dynamic step is a typed SIL Boolean relational join and existential projection, $\pi_{\{x_{i+1},x_{i+2}\}}(D_i\Join R_i)$, with a constructive acquisition map and exact preservation certificate. It does not identify a foreign algebraic summary with the SAT decision without proof. This is the standard bounded-width CSP principle (Freuder 1990), instantiated here for source-preserving proper-3CNF nonaffine ternary relations.

\section{An explicit nonlinear connected both-label countercontrol}
For every position $i$, choose the AND relation $x_{i+2}=x_i\land x_{i+1}$. Its four allowed triples are
\[
 \{000,010,100,111\},
\]
and its four forbidden triples are $\{001,011,101,110\}$, so the gadget contains exactly four proper clauses. This relation is \emph{not affine}: $010$ and $100$ are admitted, while their vector sum $110$ is not. Let $A_r^+$ pin the final $x_{r+1}=1$ and $A_r^-$ pin it to zero, keeping both initial variables equal to one. Both CNFs have
\[
 n=r+8,\qquad m=4r+12
\]
and identical ordered unsigned clause supports and bit lengths. Every original gate forces the next value to one, hence
\[
 \operatorname{SAT}(A_r^+)=1,\qquad
 \operatorname{SAT}(A_r^-)=0.
\]

\begin{theorem}[Cycle rank and UNSAT block-span are not decision costs]
The primal graph of each matched formula above is connected and has cyclomatic number \emph{exactly} $r+3$. Moreover, every UNSAT subformula of $A_r^-$ contains at least one clause from each of its $r$ distinct AND-gate blocks; hence it has at least $r$ clauses. Nevertheless both labels are decided by the same source-validated four-state algorithm in $O(N\operatorname{polylog}N)$ bit work and $O(\log N)$ writable space.
\end{theorem}
\begin{proof}
The original variables form the square of a path on $r+2$ vertices, with $2r+1$ edges. Its cycle rank is $(2r+1)-(r+2)+1=r$. Each of the three four-clause unit gadgets adds two private vertices forming a triangle with its original unit variable; each adds one independent cycle. Thus the connected full primal graph has $(r+3)$ cycles in the cycle-space dimension. To see the core statement, delete \emph{all} four clauses of any gate $i$. Set the prefix variables through $x_{i+1}$ to one, choose $x_{i+2}=0$ at the missing gate, and satisfy all subsequent AND gates: the following variable is zero and all later variables remain zero. This satisfies both initial unit pins and the final zero pin, and all remaining clauses extend by appropriate auxiliary values. Any UNSAT subformula omitting the whole $i$-th gate block would be contained in this satisfiable formula, a contradiction. Consequently each gate contributes at least one clause to any UNSAT subformula. The four-state algorithm still applies and is correct for both labels without advance knowledge of the label.
\end{proof}
This is a \textbf{FALSIFIED/RETIRED inference}, not a claim that \emph{all} high-cycle-rank/nonaffine 3CNFs are easy. The restricted positive algorithm improves the $2^{\Theta(r)}$ explicit off-tree-enumeration strategy on this family to an $O(r)$ relation-DP continuation, without claiming an unconditional lower bound on the conditioning algorithm's \emph{alternatives}.
