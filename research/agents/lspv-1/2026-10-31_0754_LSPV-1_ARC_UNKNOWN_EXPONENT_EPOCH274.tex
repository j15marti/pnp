\section{The one integrated target and four falsifiers}
The required target is a uniform, hereditary, source-authenticated residual-SAT controller $\Phi$, applicable to \emph{every fixed correct deterministic polynomial-time ordinary SAT decider} $A$ with unknown finite joint exponents $(K,L)$, on the same FLMV indexed read-only input model. The unconstructed goal is
\[
K'\le\max\{11/10,3/5+K/2\},\qquad L'\le\max\{1/2,L/2\}.
\]
The controller must pay for parsing, discovery, switching, failed strategies, original source reads, authenticated child construction, serialized outputs or reentrant accessors, guest execution, source/guest index tapes, resetting or abandoning workspaces, certificates, retained ancestors and the largest physically visited writable position.

\begin{description}
\item[] \textbf{F1, fixed advice-dependent tag width.} A preset $C\log N$-bit generation tag suffices for arbitrary polynomial guest erasure counts without knowing $K$. \textbf{FALSIFIED as a no-wrap claim}: a DELAY wrapper can perform $M^D$ logically erasing indexed jumps for arbitrarily large fixed $D$ before deciding either label, exceeding any fixed polynomial tag range when $D$ is large enough. Detecting wrap and scrubbing restores correctness but creates a separate tariff.
\item[] \textbf{F2, exponent-oblivious superlogarithmic tags.} A fixed $\lceil(\log_2(N+2))^2\rceil+2$-bit tag width covers \emph{every fixed polynomial} number of erasings eventually without knowledge of its exponent. \textbf{PROVED/EXACT restricted} below. It does not cover all superpolynomial guests.
\item[] \textbf{F3, no-reset correctness.} Reusing dirty physical guest cells while merely resetting the virtual heads implements logically fresh calls. \textbf{FALSIFIED}: a cell written in one child is incorrectly visible in the next. Generation tags prevent this.
\item[] \textbf{F4, semantic ARC leap.} Removing a tape-reset tariff constructs genuine power-short ordinary SAT descendants on every original source. \textbf{FALSIFIED as a logical implication}: the tested Shannon children preserve both labels but are not bounded by $N^{1/2}$ in the required worst-case physical encoding. No source-only or guest-assisted universal shrinker was produced.
\end{description}

\section{Exact exponent-oblivious generation theorem}
Let $N$ denote original-source physical length. Suppose one fixed \emph{sequential} controller constructs $q(N)\le N^{a+o(1)}$ physically accessible ordinary child strings $y_i$ of lengths $M_i\le N^{\lambda+o(1)}$. It invokes one fixed finite-tape deterministic total machine $A$ on each child, with \emph{unknown} finite polynomial time and work/index-space exponents $K,L$:
\[
T_A(M)\le M^{K+o(1)},\qquad S_A(M)\le M^{L+o(1)}.
\]
Assume a correct guest primitive-level virtual tape interpreter has already determined the current \emph{nonnegative logical cell address} and operation, with every address-computation step to be charged. In particular this initial lemma does \emph{not} posit a free ordinary-SAT child or a free indexed jump.

\begin{theorem}[Unknown-$K$-oblivious logical tape erasings]
For every such fixed $A$ and controller, without being supplied $K,L$, a single \emph{uniform} generation-tag tape representation realizes all new-child blank-tape initializations and all indexed-tape content-erasure events exactly. Put
\[
B(N)=\left\lceil(\log_2(N+2))^2\right\rceil+2.
\]
Represent each guest logical cell at a dense physical block of $B(N)+O(1)$ work-tape cells containing a generation tag and symbol, and maintain a separate generation number for each fixed guest tape. New-child initialization increments each tape generation and resets virtual heads. An indexed jump first reads and decodes the relevant index-tape contents, then increments \emph{that index tape's} generation while leaving its virtual index-head position unchanged. Each read returns blank for a mismatched tag; each write updates the complete tag and symbol.

For all sufficiently large $N$ (threshold permitted to depend on the fixed $A$, not known by the compiler), no generation counter wraps. The reset/erasure bookkeeping per event costs $N^{o(1)}$ machine steps, never an additional whole-tape wipe; each indexed work-tape's largest physically visited position is at most
\[
O((\max_i S_A(M_i)+1)(B(N)+O(1))).
\]
For the finitely many smaller input lengths, a detected impending wrap can be handled by completely clearing \emph{the one tape whose logical contents are becoming blank}, then restarting its generation count. This makes the fixed implementation correct on every finite input without changing its asymptotic time/space exponents for any fixed polynomial guest.
\end{theorem}
\begin{proof}
There are finitely many guest tapes. The total number of events that logically erase a tape, including start-of-call resets, is at most
\[
E_N\le c\left(q(N)+\sum_{i=1}^{q(N)} T_A(M_i)\right)
       \le N^{a+\lambda K+o(1)}
\]
for a fixed machine-dependent constant $c$. As $\log N\to\infty$,
$B(N)/\log_2 N\to\infty$. Therefore for every fixed finite $a+\lambda K$,
$E_N<2^{B(N)}-1$ eventually. The representation's width is a single explicit function of $N$ and never uses $K$ as advice.

Induct on guest primitives. On an initially blank virtual tape all previously stored tags mismatch the new positive generation, so reads yield blank. A read in the current generation returns exactly the last written symbol; a write stores precisely the new symbol. A guest indexed jump obtains its address from the \emph{old} index-tape generation, clears the virtual index contents by advancing only that generation, preserves the index-tape head coordinate and changes the indexed tape's head to the decoded coordinate. Thus both ordinary and indexed transitions agree exactly with a genuinely fresh guest run, for SAT and for UNSAT inputs. A representation-level epoch collision can arise only after $2^{B(N)}$ erasings. Detect counter exhaustion before increment. Because the transition being implemented already demands a logically blank tape, clearing its physical prefix cannot destroy any retained guest data; its virtual head coordinate remains in a separate register. The tape has a finite highest physical position reached, so such a recovery terminates. It occurs for only finitely many input sizes under each fixed polynomial $A$. For every guest logical cell address $p$ actually reached, the corresponding block is at $O((p+1)B(N))$, so the highest physical touched guest-tape position is $O((S_A+1)B(N))$. Full tag reads/writes, address formation, counter updates and unchanged writes are charged, at $N^{o(1)}$ per primitive given polynomial guest tape-address magnitudes. No guest workspace is retained across \emph{sequential} calls. \qed
\end{proof}

\paragraph{Precise physical-model qualification.}
The theorem addresses resetting and erasing virtual tapes once a guest primitive and its logical address have been decoded. A general FLMV indexed jump may have a far-flung index-tape head or a very long address; its \emph{decoding} cost is a separate obligation. In particular, this theorem by itself is \emph{not} an exact arbitrary-$A$ input/work tape simulator. It cannot silently replace the complete guest-machine accounting from LSPV-4 ARC-FAR-BLANK-GUARD274.

\begin{corollary}[Restricted full-machine combination]
Suppose additionally \emph{every guest index tape}, including input-index and work-index tapes, visits only positions $h_A(M)=O(\log(M+2))$ on every guest input. Every guest indexed-jump address can then be decoded using at most $O(h_A)$ virtual tagged-cell reads, each with charged $N^{o(1)}$ overhead. Ordinary head moves and actual child input reads can be simulated with $O(\log(S_A+T_A+M+2))$-bit virtual coordinates and charged physical indexed-buffer accesses, including far-input blanks. For genuinely serialized children, with verified parent Boolean join and local acquisition/time budget $N^{\alpha+o(1)}$, guest simulation admits the \emph{conditional} bounds
\[
T_{\rm host}\le N^{\alpha+o(1)}+
 N^{o(1)}\sum_{i=1}^{q(N)}(M_i+T_A(M_i)),
\]
\[
S_{\rm host}\le S_{\rm retained}(N)+
 N^{o(1)}\left(M_{\max}+\max_i S_A(M_i)+1\right).
\]
Thus for $(a,\lambda)=(3/5,1/2)$, when the fully charged acquisition and join fit $\alpha=11/10$, the resulting time and space exponents are bounded by
\[
K'\le\max\{11/10,3/5+K/2\},\qquad
L'\le\max\{\sigma,1/2,L/2\}
\]
if $S_{\rm retained}\le N^{\sigma+o(1)}$ and $\sigma=1/2$.
\end{corollary}
\begin{proof}
For a guest with bounded index-head extent, explicit bit-by-bit decoding of each guest index tape takes polylogarithmic many tagged-cell operations. Every nonblank work cell is encoded densely at a block address $O(S_A B)$ and guest work/index heads are stored as binary registers; input coordinates can be maintained virtually, with any coordinate at least the physical child length yielding the correct blank without touching a far host buffer cell. All parent-source accesses, serialized child writes, failures, policy choices and retained parent state remain in the separate charged local term. Induction on the exact indexed-machine transitions proves both labels. Summing sequential costs and taking a maximum rather than a sum over no-longer-live guest workspaces proves the displayed bounds. Crucially, arbitrary correct SAT deciders with index-head extent larger than $O(\log M)$ are \emph{outside} this corollary. \qed
\end{proof}

\paragraph{Important accounting boundary.}
The arbitrary-$A$ contract must include guests whose index-tape heads deliberately reach $\Omega(M)$ or farther, even if their work is semantically useless (DELAY/INTERP/COPY wrappers). The corollary supplies no reason that a code-aware compiler can replace their programs with bounded-index guests. Nor does serial reuse preserve a suspended guest: retaining such a configuration requires an additional independently charged arena, checkpoint or replay.
