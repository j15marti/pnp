\section{Four falsifiable mechanisms fixed before targeted source inspection}
\begin{description}
\item[] \textbf{H1.} Adaptive proof-bit addresses invalidate
enumeration by $2^{q}$ observed answer strings, even when repeated
addresses must be consistent. \textbf{FALSIFIED as an obstruction}:
record only the first answer to each distinct address; replay gives a
complete deterministic enumerator (Lemma~\ref{le:oracle}).
\item[] \textbf{H2.} A polynomially long source-authenticated proof tape
can hide low-cost accepting certificates from the logarithmic frontier,
despite only logarithmically many genuinely \emph{read} bits.
\textbf{FALSIFIED under fixed public length, exact one-bit queries and
a uniform machine clock}. Nominal length is not the relevant advice entropy.
\item[] \textbf{H3.} A two-bit word or an uncharged variable certificate
length may be counted as one queried binary bit, without affecting sound
enumeration. \textbf{FALSIFIED}: both are extra information channels,
as independently checked by finite counterexamples.
\item[] \textbf{H4.} The observed-bit bound automatically yields an
adaptive ordinary-SAT successor with lower exponent than any arbitrary
hypothetical $P=NP$ solver. \textbf{FALSIFIED as an inference}.
No all-input verifier, small observed-query cap, acquisition bound,
or hereditary source-to-child contraction is supplied by this lemma.
\end{description}

\section{Exact native machine and all-input quantifiers}
Fix constants $p,r,s,a\ge0$. Let $F$ range over \emph{every}
ordinary valid encoded CNF of physical source length $N$.
Fix \emph{one} uniform deterministic total verifier $V$.
It has the indexed read-only original source of FLMV and its
ordinary charged work and index tapes.
In addition, it may consult a fixed read-only binary proof
oracle $\pi\in\{0,1\}^{L(N)}$ by \emph{one-bit} queries:
each queried index and returned bit is a genuine part of its
computation. The public cap
\[
 1\le L(N)\le N^p,\qquad
 q(N)\le(a+o(1))\log_2N
\tag{2}
\]
is \emph{uniformly calculable} within
$N^{o(1)}$ arithmetic overhead and $N^{o(1)}$
work, or has an explicit equivalent formula. Fix the
proof's exact physical length to $L(N)$ by public padding:
its length cannot secretly encode additional evidence.
Index generation, source access, proof-query handling,
local SAT/UNSAT checks, certificate parsing, child
generation and validation, failed attempts, caches, resets
and the one-bit output are all charged.
All proof-input lengths and native work/index addresses
are polynomially bounded in $N$.
No free semantic oracle or unaccounted source-dependent
advice is present.

All proof strings, including malformed ones, run in
\[
 T_V(N)\le N^{r+o(1)},\qquad
 S_V(N)\le N^{s+o(1)}
\tag{3}
\]
simultaneously for this \emph{same} $V$; alternatively
a certified uniform clock rejects longer executions.
The precise semantics are
\begin{align}
 \forall F\in\SAT\;\forall\pi\in\{0,1\}^{L(N)}
   &:\ V(F,\pi)=0, \tag{4}\\
 \forall F\in\UNSAT\;\exists\pi\in\{0,1\}^{L(N)}
   &:\ V(F,\pi)=1
       \ \land\ Q_V(F,\pi)\le q(N). \tag{5}
\end{align}
$Q_V$ is the number of \emph{distinct proof bit positions
actually inspected on that accepting run}; queries may be
adaptive, repeated and far apart.
Equation (5) bounds \emph{only a chosen accepting path}:
rejecting paths may read more than $q$ proof locations.
All malformed ordinary-CNF sources are resolved by the
same deterministic parser according to the fixed ordinary
SAT encoding convention.

\begin{lemma}[First-read proof-oracle enumeration]
\label{le:oracle}
Under (2)--(5), one uniform total deterministic ordinary-SAT
decider $D$ exists in the \emph{same} indexed input/work model with
\[
 \boxed{T_D(N)\le N^{\max\{1,r+a\}+o(1)},\qquad
 S_D(N)\le N^{\max\{0,s\}+o(1)}.}
 \tag{6}
\]
No materialization, enumeration, or acquisition of the
$L(N)$-bit full certificates is needed.
\end{lemma}
\begin{proof}
After a paid ordinary-CNF parse, enumerate each binary
answer string $z\in\{0,1\}^{q(N)}$ in a fixed uniform order.
There are $2^{q(N)}\le N^{a+o(1)}$ such strings.
For each $z$ restart a complete fresh simulation of $V$,
with its actual original source unchanged.

Maintain a temporary finite dictionary $M$ from
previously inspected \emph{proof indices} to bits.
On the first query to address $i$, take the next unused
bit of $z$, set $M[i]$ to it, and return that bit.
On every later query to $i$, return $M[i]$ rather than
consuming another guessed bit. If a simulated execution
asks its $(q+1)$-st \emph{distinct} proof address before
accepting, abandon this candidate $z$ as unsuccessful.
If it accepts before that threshold, output UNSAT.
If none of the answer strings leads to acceptance,
output SAT. No branch is given the true SAT label.
All $V$ transitions, source-bit accesses, child
creation, proof-address computations and output
are executed exactly as prescribed, not shortcut.

\emph{Soundness of enumeration:} the dictionary on
every accepting simulated run is a consistent partial
binary function on at most $q(N)$ of the $L(N)$
proof positions. Extend it by zeros (or arbitrary bits)
to one actual fixed $\pi\in\{0,1\}^{L(N)}$.
The deterministic $V$ follows precisely the same query
answers and accepts this genuine $\pi$. By (4), the
original source is UNSAT. The source was never changed.

\emph{Completeness:} for each UNSAT source choose the
$\pi$ of (5), and let $z$ list the bits it returns at
successive \emph{first visits to distinct proof positions}.
Pad that list arbitrarily to $q(N)$ bits. The enumerator
will simulate that accepting path, including its repeated
queries, and output UNSAT. Every valid SAT/UNSAT source
gets one correct deterministic label.

\emph{One-machine resource bound:} at most $q(N)$
proof-index/answer pairs are live, each costing
$O(\log L)=O(\log N)$ bits. The proof map therefore
costs $O(q\log N)=O(\log^2 N)$ bits, and its lookup/erase
costs a polynomial in $\log N$. A sparse dictionary of
currently touched \emph{verifier work} cells, default blank,
provides fresh-start simulation and clearing in
$T_V(N)\operatorname{polylog}N$ time and
$S_V(N)\operatorname{polylog}N$ peak space under the
original indexed address convention (as in ARC199).
No failed candidate's state survives except the
paid enumeration counter. The input is still the
same read-only original source. The parser is
$N^{1+o(1)}$ time; all answer strings cost
$2^qT_V\operatorname{polylog}N$ time.
This establishes both bounds in (6), jointly on
one resulting uniform machine.
\end{proof}

\begin{theorem}[An observed-proof-bit forbidden region]
\label{th:flmv}
Let
\[
 c_\star=\frac{241}{200}=1.205,\qquad
 s_\star=\frac{11642479}{23232400}
   =\beta(c_\star)\simeq0.501131135827551.
\]
For the \emph{all-ordinary-UNSAT} proof-oracle verifier
specified above, the original deterministic FLMV
indexed-model exclusion and Lemma~\ref{le:oracle}
yield the \emph{necessary} condition
\[
 \boxed{s<s_\star\ \Longrightarrow\
        \max\{1,r+a\}\ge c_\star .}                 \tag{7}
\]
In particular, with near-linear verification
$r=1$, subpolynomial writable/index space $s=0$,
and polynomially long proofs \emph{of any fixed degree},
every such universally complete verifier requires
$a\ge41/200=0.205$. Equality is not excluded.
\end{theorem}
\begin{proof}
If both inequalities were strict in the opposite
direction, (6) would give \emph{one} correct deterministic
ordinary-SAT decider strictly inside the known
indexed-RAT forbidden region derived from FLMV
Corollary~5.8 and SAT's quasi-linear log-space
completeness. All fixed polylogarithmic simulation
losses are absorbed by the positive exponent margins.
The contradiction concerns the \emph{existence of
a verifier satisfying (2)--(5)}, not the complexity
of any one UNSAT formula or the length of arbitrary
nonuniform proofs. Neither a one-tape nor a
sequential-input-head lower bound is used.
\end{proof}

\section{Exact side-channel counterexamples and the information budget}
\begin{counterexample}[A proof word is not one binary bit]
Suppose a proof oracle returns one \emph{two-bit word}
$w\in\{0,1,2,3\}$ instead of one bit, and the verifier
accepts a local contradictory module indexed by $w$.
On the genuine signed W1 four-module promise there
are valid UNSAT sources for which \emph{only module 3}
has the unsatisfiable $(1,1)$ mode.
The correct witness is $w=3$. Enumerating only the
two answers $\{0,1\}$ as if this oracle call supplied
one bit misses it. The four possible words must be
charged as \emph{two} observed bits. For any
$w$-bit returned record, charge its full $w$-bit
alphabet, including all parser and locator work.
\end{counterexample}
\begin{counterexample}[Uncharged proof length]
For that same four-module promise, suppose the
verifier reads \emph{no proof content} but can
inspect the proof's independently chosen length
$\ell\in\{0,1,2,3\}$ for free and accepts when
module $\ell$ is $(1,1)$. The proof length carries
two bits of source-dependent advice despite
$Q_V=0$. Fixing one public padded length, or
charging the full length/endmarker information,
is indispensable. More generally enumerating
all $L(N)$ possible lengths may add a factor
$L(N)$ to the deterministic work.
\end{counterexample}
\begin{counterexample}[Repeated-address inconsistency]
An alleged verifier that accepts iff it reads
proof bit $0$ twice and receives first $0$, then
$1$, has \emph{no} accepting \emph{fixed proof}.
A simulator that independently guesses at every
access would invent a false accepting path.
The dictionary in Lemma~\ref{le:oracle}
prevents precisely this error.
\end{counterexample}

The correct invariant is \emph{binary entropy of
the accepted proof-visible stream}, with first-read
address choices generated and paid by the fixed
verifier. It is not nominal proof size, number of
high-bandwidth records, raw source accesses, nor
arbitrary nondeterministic branches with mutable
time-dependent advice. A public fixed polynomial
proof address universe and bounded charged decoding
are load-bearing.

\begin{corollary}[Conditional two-hereditary-level query accounting]
Suppose a \emph{single fully implemented} indexed
verifier generates and authenticates all its parent,
child and grandchild sources, including both SAT and
UNSAT branches, from one original source $F$.
It may consult several fixed read-only proof tapes,
whose \emph{complete joint address universe is
publicly polynomial in $N$}, with a unique stable
pair (child identifier, proof position) per
potential binary query. If every needed accepting
computation observes at most
\[
 Q_{\mathrm{total}}(N)\le(a+o(1))\log_2N
\]
\emph{distinct} advice bits \emph{across both
hereditary levels}, and has the same uniform all-input
soundness/coverage and charged native per-run
time/space ceilings $(r,s)$, then (6)--(7)
apply to the complete verifier.
\end{corollary}
\begin{proof}
Namespace the proof-index pairs and regard the
result as one polynomially addressed read-only
proof oracle. First-read caching and the accepted
response enumeration are unchanged. Its cost
is the \emph{complete} runtime of the wrapper
including the actual source/child lengths,
\(\sum_i m_i^d\) paid calls, locality validation,
failed alternatives, output, and simultaneous
retained ancestor plus descendant workspace.
There is no asserted bound on that cost: the
corollary applies \emph{only if} these hypotheses
have separately been proved.
\end{proof}
No index width or first-read cap automatically follows
from source-authenticated recursion, and neither
side of SAT/UNSAT can be dropped.
All source-dependent certificates cannot be
chosen by a free perfect selector.

$C_{A,N}$, a witness-checker circuit, and an

objects. There is no $q=1.29$ full circuit
