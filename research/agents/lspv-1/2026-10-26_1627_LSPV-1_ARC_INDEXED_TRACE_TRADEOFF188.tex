\section{Exact trace type and the new indexed point}
Let $A$ be one fixed, deterministic, total, correct ordinary-SAT decider
with one sequential read-only input head and fixed $k$ work tapes (Mk).
For raw input $F$ of length $N$, let $\tau$ be a self-delimiting
complete computation history with $R$ canonical transition records,
initial source and blank-work configuration, source/work head positions,
symbols read and written, finite-control state and the final output.
Every genuine head coordinate has $O(\log(N+R+2))$ bits because each
sequential head moves at most one cell per transition.
Write $M=N+R+2$ and
\[
 P=|\tau|=\Theta(R\log M),\qquad
 X=|F\#\tau|=\Theta(N+R\log M).
\]
The subject language is the PAIR language
\[
 L_{A,\mathrm{trace}}=\{(F,\tau):\tau\text{ is precisely the full
 rejecting computation history of }A\text{ on }F\}.
\]
It is not SAT or UNSAT on $F$ alone.

\begin{theorem}[Indexed source-authenticated sparse trace verifier]
For every such fixed $A$ there is a uniform deterministic indexed
read-only-input random-access verifier $V_A$ for
$L_{A,\mathrm{trace}}$, with
\[
 T_{\mathrm{RAT}}=O((N+R^2)\log^3 M),\qquad
 S_{\mathrm{RAT}}=O(\log M).
\]
Index, address arithmetic, all counters, read-only source and proof lookups,
control and head state, malformed input, and output are fully charged.
On every raw encoded formula input $F$,
\[
 F\in\UNSAT\ \Longleftrightarrow\
 \exists\tau: V_A(F,\tau)=1,\qquad
 F\in\SAT\ \Longrightarrow\
 \forall\tau:V_A(F,\tau)=0.
\]
The existential quantifier has NO favorable certified uniform cap.
\end{theorem}
\begin{proof}
Validate the header, canonical record width, total compound-input physical
length, initial state, legal finite transitions, head moves, adjacent states
and rejecting terminal condition. For a record reading an original input
bit, use the indexed read-only source and authenticate the actual bit or
out-of-bounds blank. For every work-tape read of cell $(j,a)$ at time $t$,
scan records $t-1,t-2,\ldots,0$ by index until finding the latest write
to exactly $(j,a)$, and require the claimed read symbol to equal its value.
If none exists, demand the declared blank symbol. There are $O(kR^2)$
record examinations because $k$ is fixed; each fixed-width $O(\log M)$
record and index calculation costs a fixed power of $\log M$ bit steps.
The verifier holds only one record, one earlier record, the current state,
the head coordinates and counters, hence $O(\log M)$ work/index bits.
By induction on $t$, accepted claimed source reads and last-write work
reads equal the real machine's values. A legal transition and the unique
initial state then force exactly the actual deterministic computation.
Since $A$ is total and exact on every raw ordinary SAT input, a rejecting
history exists exactly for UNSAT, and no SAT source has one. The
verifier never calls $A(F)$ as a full-parent SAT oracle.
\end{proof}

\section{Three-model same-machine ledger and input-type separation}
\begin{theorem}[Conservative upper constructions, not lower bounds]
On that SAME PAIR language with compound input length $X$,
the following separately implemented resource ceilings are valid:
\[
\begin{array}{c|c|c}
\text{model/realization}&\text{time}&\text{storage}\\\hline
\mathrm{RAT,\ indexed\ last\ write}&\widetilde O(N+R^2)&O(\log M)\\
\mathrm{Mk,\ sequential\ emulation}&\widetilde O(X(N+R^2))&O(\log M)\\
\mathrm{M1,\ shared\ scan}&\widetilde O(X^2(N+R^2))&O(X)\ \text{footprint}\\
\mathrm{Mk,\ ARC187\ fast\ sorter}&\widetilde O(X)&\widetilde O(X)\ \text{work}
\end{array}
\]
The first Mk row is made by traveling as far as $X$ physical input
positions for each indexed source/proof lookup; the M1 row then uses
the fixed-$k$ rescan theorem
\[
 T_1=O(T_k(X+S_k+\log(T_k+2))),\quad
 P_1=O(X+S_k+\log(T_k+2)).
\]
Thus for ceilings measured against the same $X$, only
$t_1\le t_k+\max(1,s_k)$ and $p_1\le\max(1,s_k)$ follow.
The separate fast Mk verifier has different higher storage and cannot
contribute a free time coordinate to the low-space indexed verifier.
The one-tape footprint INCLUDES the compound source and proof input;
the Mk work space and FLMV indexed space do not.
\end{theorem}
\begin{proof}
The indexed verifier is Theorem 1. A fixed sequential-input machine
realizes each indexed compound input read by repositioning its input
head with an explicit binary counter, in $O(X)$ steps and $O(\log M)$
work. Simulate that precise fixed Mk machine with a marked single
shared tape and one full sweep per transition. This proves the
displayed conservative upper bounds and includes all actual source
reads, head travel, copies, failed records and buffers. The last
row is the distinct materialize-and-sort result of ARC187.
\end{proof}

\begin{corollary}[One-way nondeterminism is not an indexed proof tape]
A literal guess-copy-and-reread implementation of the first row must
write and retain the complete $P$-bit guessed proof on writable indexed
storage. For THAT implementation this costs $\Omega(P)$ writes and
$\Omega(P)$ peak work bits. Ordinary one-way nondeterministic choices
cannot be reread for free. Van Melkebeek's Definition 2.1 carefully
distinguishes guessed TWO-WAY read-only input from one-way nondeterminism.
This does not exclude another verification grammar with lower space;
it retires the uncharged transfer of Theorem 1 into an ordinary
coNTIME SAT machine.
\end{corollary}

\begin{corollary}[Unknown-$K$ faithful-trace limitation]
If a chosen hypothetical decider has a faithful rejecting run with
$R=N^{K+o(1)}$ for some fixed $K\ge1$, the first row gives
$(T,S)=(N^{2K+o(1)},N^{o(1)})$ on a pair input of length
$X=N^{K+o(1)}$. It is NOT an ordinary SAT achievable pair.
An $N^r$-step DELAY wrapper yields $\Omega(N^r)$ mandatory faithful
records for this particular syntax without affecting correctness.
For $K\ge2$, van Melkebeek Theorem 1.3's strict first alternative
requires a coNTIME exponent $c<1+1/K$, whereas $2K$ does not suffice;
the other alternative also fails. No deterministic matching
small-space RAT SAT solver or arbitrary-$K$ ARC contraction follows.
\end{corollary}
