\section*{Fixed definitions}
Fix the original binary-premise, unit-weight sound conservative Rmix341 (RES, AND3, XOR, LOCAL-CONVERT, charged two-input DEF) and distinguish W_R minimum distinct derived nodes from source/evidence bits, verification steps, and actual time/peak writable space. All machine T/S statements below use one fixed uniform deterministic machine, read-only sequential input and logarithmic writable counters; they do not follow from W_R.

For h=2^\ell, h\ge2, and p\in\{h,h+1\}, label pigeon i by \ell original Boolean bits. For each pigeon pair i<j and hole a<h, form the signed 2\ell-literal collision clause that excludes both labels equalling a. Replace a clause of width r>3 by the standard private Tseitin chain of r-2 three-clauses and r-3 fresh variables; for r=2 leave its binary clause intact. Emit canonical DIMACS with numbered variables and aux variables in lexicographic (i,j,a) order, decimal signed literals, a fixed header and row terminators. Call the resulting exact byte string G_{h,p}. The private chains preserve satisfiability: for each original bit assignment, extension variables can be assigned to satisfy the chain if and only if the wide source clause is true. Thus G_{h,h} is SAT (bijective placement), and G_{h,h+1} is UNSAT (pigeonhole counting). For h>=4 both encodings are proper three-CNF; h=2 is a two-CNF edge control.

\begin{theorem}[Fixed-uniform two-label canonical recognition]
Let g_1,\ldots,g_d be a finite, \emph{fixed} collection of source-generators whose individual output symbols and total output lengths can be computed in logarithmic writable space and polynomial time in the resulting source length, with the index parameters bounded by polynomial functions of source length. Suppose all outputs are valid CNFs with a correct label (SAT or UNSAT) computable from their parameters in logarithmic space, and that conflicting labels never generate identical strings. Then there exists one total correct uniform general-CNF-SAT decider A such that, for every output x in this union,
\[
T_A(x)=|x|^{O(1)},\qquad S_A(x)=O(\log(|x|+2)).
\]
For the canonical G_{h,h} / G_{h,h+1} strings above, these hypotheses hold unconditionally. Neither conclusion asserts polynomial worst-case time or logarithmic space on arbitrary non-family inputs.
\end{theorem}
\begin{proof}
On an arbitrary binary input x, enumerate bounded candidate generator indices and both labels, compute each candidate's length (capped at |x|+1), and compare the generated symbols against the read-only input. All loop indices, byte positions, decimal-digit conversion scratch and candidate counters require O(log(|x|+2)) writable bits; at most polynomially many candidates and source symbols are checked. On an exact match output its independently justified SAT or UNSAT label. Because all matched strings are valid and genuinely have that label, these early outputs are correct. Otherwise invoke a fixed exhaustive, syntax-checking general CNF-SAT decider, rejecting malformed sources and deciding either label; the fallback is correct and total but may be exponential and use much more space. For the particular BPHP generators there are only O(log |x|) candidate hole counts, two pigeon counts for each, and every output symbol is computable by nested bounded counters and standard logspace decimal arithmetic. Therefore the claimed restrictions hold on the matched family. A family-specific small-space performance bound has no implication for all-input polynomial SAT.
\end{proof}

\section*{Four falsifiers and results}
F1: a supposedly UNSAT canonical G_{h,h+1} can be satisfiable. Symbolic pigeonhole counting excludes it, with direct original-bit enumeration for h=2 and 4. F2: the private chain silently changes the label. Verified all 16 four-literal input patterns with existential auxiliary-bit enumeration. F3: small signed perturbation invalidates the label promise. For 5 pigeons/4 holes the original wide formula has 0 models; flipping one specific source literal yields exactly 6 original-bit models. Such a formula is \emph{not} on the canonical early-output list and must use the correct fallback. F4: malformed or corrupted inputs are accepted by the canonical comparator. Four altered strings (bad count, missing terminator, added literal, trailing garbage) all failed exact recognition; one altered signed formula remained syntactically valid, confirming that syntactic validity is not authenticated family membership.

Six canonical h=2,4,8 two-label cases were generated with complete source hashes and exact counts; an independent Node implementation with different control flow recomputed all six SHA256 hashes, all formula sizes and small model counts, with 32 assertions PASS. All host-Python/Python-string memory is excluded from the logspace theorem: this is a symbolic construction, not an empirical native machine-space measurement.

\section*{Quantifier and bridge audit}
This is an explicit \emph{family-specific time--space bypass}, not a B1/B2/B3 theorem. That would falsify a B1 pointwise transfer for that restricted calculus but \emph{not} B2, because its all-input fallback may have exponential worst-case runtime, nor B3 for the stronger unchanged mixed calculus.
