\begin{abstract}
In the \emph{fixed, finite, deterministic one-sequential-input-head} model of
WRITE-TIGHT2, a sparse-write event chronicle is injective \emph{across different
sound input-selected inline programs}, not merely within each program class.
Consequently its distributional counting bounds have \emph{no program
multiplicity factor} even if the common inline prefix slot is as long as the
source. This combines the cross-program splicing firewall already established
for full crossing histories in ARC197 with WRITE-TIGHT2's more economical
actual-symbol-change chronicle.  Under polynomial time and
$D\le N^{1-\varepsilon}$, at least three quarters of the diagonal satisfiable
promise inputs lack any sound inline-program acceptance in
$T\le cN^2/\log^2N$ for a sufficiently small model-dependent $c>0$.
This is \textbf{PROVED/EXACT only as a restricted-model mathematical
derivation; independent referee review pending}.  It is \emph{not} an
unrestricted SAT or indexed-RAM lower bound.  $P$ versus $NP$ remains
\OPEN.
\end{abstract}

\section{Exact source, interpreter, quantifiers, and resource model}
Adopt the verified proper signed exact-$(2,2)$, clause-distinct
$15$-variable, $20$-clause component $H(a,b)$ with exhaustive model counts
$(772,272,272,0)$ for $ab=00,01,10,11$.
Take $m$ disjoint copies and place all $2m$ Alice-varying clauses,
then the $16m$ invariant clauses, then all $2m$ Bob-varying clauses.
Let $F_m(a,b)$ be the resulting canonical fixed-width binary source.
Its physical \emph{formula} bit length is $N=\Theta(m\log(m+2))$, the
common invariant middle interval contains $G=\Theta(N)$ physical cuts,
and
\[
 \SAT(F_m(a,b))\Longleftrightarrow a\wedge b=0^m.
 \tag{1}
\]
Set $Y_a=F_m(a,\overline a)$, so all $2^m$ $Y_a$ are SAT; for $a\ne a'$,
at least one of $F_m(a,\overline {a'})$, $F_m(a',\overline a)$ is UNSAT.

Fix \emph{one} deterministic interpreter $U$ with fixed finite state set,
fixed alphabet and $k\ge1$ fixed initially blank one-head semi-infinite
work tapes.  It has exactly \emph{one} two-way \emph{sequential} read-only
source input head.  A selectable program $p$ is a literal string
occupying a fixed-width, potentially source-length or larger, read-only
input prefix \emph{wholly left of all $G$ cuts}; its capacity $b(m)$
may vary with $m$, but the slot and its delimiter are uniform across
all $a$ for this $m$.  A different $p$ is allowed for each $Y_a$, even
with perfect hindsight.  The one fixed $U$ parses the resulting
$p\Vert F$ record; every eligible program is \emph{globally sound}:
\[
 \boxed{\quad\forall p\in\mathcal P_m\ \forall F\in\UNSAT:
                 U(p,F)\text{ never accepts.}\quad}
 \tag{2}
\]
Soundness must hold for \emph{all} ordinary well-formed formulas in the
declared input interface, not just the diagonal promise.  Completeness
for a particular $a$ means $\exists p\in\mathcal P_m$ with an accepting
run on $Y_a$; programs need not accept any other SAT input.
No writable program copy, independently readable proof tape, uncharged
input jump, movable output head, infinite-state control, or preloaded work
contents is allowed.

For one accepted run count $T$ genuine $U$ transitions,
$H\le T$ physical source-head cell moves, $R$ source-head reversals,
$S$ total distinct work cells visited (blank included),
$D$ actual work-cell symbol \emph{changes} including restoring blank,
and $L$ any emitted output.  Same-symbol formal writes do not increase
$D$.  Program decoding, failed internal probes, parsing, source
authentication, strategy switching, output materialization, all
work-head movements and simultaneous peak space are included in the
same run.  A genuine separate one-way, unreadable output port may not
be reread and may not contribute a usable head coordinate; otherwise
it is a work tape and must be charged.

For fixed ceilings $(T_0,S_0,D_0)$ shared over runs, define
\[
 \Acc_m(T_0,S_0,D_0)=
 \{a\in\{0,1\}^m:\exists p\in\mathcal P_m\
       U(p,Y_a)\text{ accepts with }T\le T_0,\
       S\le S_0,\ D\le D_0\}.
 \tag{3}
\]
This is \emph{one fixed interpreter} and \emph{per-accepted-run
simultaneous} ceilings; the existential program may depend on $a$.

\section{Chronicles and the cross-program injection}
For any cut $c$ in the common central gap, encode the chronological
events of an accepted run as
\[
 \begin{array}{ll}
  \mathrm{W}(j,x,\sigma):&\text{tape $j$, absolute visited cell $x$
                      actually changes to symbol $\sigma$},\\
  \mathrm{C}(\delta,q,h_1,\ldots,h_k):&
       \text{input head crosses $c$, direction $\delta$,
                      state $q$, all work-head positions $h_i$}.
 \end{array}
 \tag{4}
\]
Within one physical transition, list concurrent writes in tape order
before the crossing.  Initially blank contents plus the ordered writes
reconstruct the \emph{full} work-tape contents at each crossing.
Hence equal event strings imply equal complete crossing configurations,
including the work-head positions and finite control.

\begin{lemma}[cross-program injection, restricted model]
For a fixed relative central source cut $c$, suppose $a\ne a'$ and
$p,p'$ are separately globally sound in the sense of (2).
Then accepting computations $U(p,Y_a)$ and $U(p',Y_{a'})$
cannot have the same event chronicle (4), even if $p\ne p'$.
\end{lemma}
\begin{proof}
If chronicles agree, the complete crossing configurations agree in
both deterministic runs.  Decompose each run into successive sojourns
on the left and right of the \emph{same physical source-relative} cut.
Determinism and equality of the complete boundary configurations
allow the left sojourns of the first run to be combined with the right
sojourns of the second run, and vice versa.  Work contents match at
every swap because the full write chronology reconstructs them.
The program prefix is \emph{entirely left}, so the first hybrid runs
under the original program $p$ on $F_m(a,\overline {a'})$; the second
runs under $p'$ on $F_m(a',\overline a)$.  The standard terminating
crossing-sequence splicing argument yields accepting hybrids.
At least one hybrid formula is UNSAT by (1), contradicting the
global soundness of the program appearing on its left shore.
Nothing requires $p=p'$ or a program identifier in the code.
\end{proof}

\paragraph{Epoch capacity and prefix-free coding.}
During any interval containing \emph{no actual symbol change}, an
identical crossing tuple $(\delta,q,h_1,\ldots,h_k)$ at the same fixed
cut would repeat the complete deterministic configuration and loop.
Consequently a halting run has at most
$c_U(S+2)^k$ crossings per no-change epoch.
There are at most $D+1$ epochs.  Every write or crossing event costs
at most $c'_U(\lceil\log_2(S+2)\rceil+1)$ bits, including tag, finite
control, symbol, tape id and positions.  Include an unambiguous
terminator; increase one model constant $C_U$ to obtain
\[
 \begin{aligned}
 B_{\rm w}(D,S)
   &=C_U(D+1)(S+2)^k
                   (\lceil\log_2(S+2)\rceil+1),\\
 B_{\rm t}(D,S,T)
   &=C_U(D+\lfloor T/G\rfloor+2)
                   (\lceil\log_2(S+2)\rceil+1).
 \end{aligned}
 \tag{5}
\]
These are \emph{upper bounds on one chronological event code},
not lower bounds on time or work space. The second follows by
choosing, for each accepted run, a gap cut traversed at most
$H/G\le T/G$ times. Its identity costs $\lceil\log_2G\rceil$
bits, equivalently a factor $G$ in counting.
Only $U,k$ and the fixed tape alphabets enter $C_U$.

\begin{theorem}[ARC205 distribution, exact restricted model]
For all $m$ and all nonnegative ceilings $T_0,S_0,D_0$, with the
source family and globally sound inline portfolio of (1)--(3),
\[
 \boxed{\begin{split}
 |\Acc_m(T_0,S_0,D_0)|\ \le\ \min\Bigl\{2^m,&\
 2^{B_{\rm w}(D_0,S_0)+1}-1,\\
 &G\bigl(2^{B_{\rm t}(D_0,S_0,T_0)+1}-1\bigr)\Bigr\}.
 \end{split}}
 \tag{6}
\]
All codeword lengths may be rounded upward to integers.  There is
\emph{no} factor $2^{b(m)+1}$ or other program-cardinality factor.
In particular, when either nontrivial term on the right is at most
$2^{m-2}$, at least $3/4$ of the diagonal YES sources admit \emph{no}
accepting computation under these simultaneous ceilings for
\emph{any} globally sound inline program.
\end{theorem}
\begin{proof}
For each $a$ in the set (3) choose one accepting program and one
qualifying run. At one \emph{fixed} gap cut, use its entire chronicle.
The injection lemma makes these codes distinct even when the
chosen programs differ; (5) bounds their lengths by $B_{\rm w}$.
There are at most $2^{B_{\rm w}+1}-1$ finite binary words up to
that length.  This proves the second term.  Alternatively choose
a low-traffic cut for each $a$ and encode its identity with the
associated chronicle.  Any two inputs with the same cut and
chronicle would contradict the injection lemma, giving at most
$G(2^{B_{\rm t}+1}-1)$ possibilities.  Intersect with the
trivial $2^m$ bound.  No multiplication by the number of eligible
programs is legitimate or needed, because the injection was already
proved \emph{across} programs.
\end{proof}

\begin{corollary}[constant-fraction sparse-change time barrier]
Fix $U,k,K<\infty$ and $\varepsilon>0$.  For sufficiently large $m$,
assume $S\le k(T+1)$ and $D_0\le N^{1-\varepsilon}$. There exists a
constant $c=c(U,k,K,\varepsilon,\text{encoding})>0$ such that
\[
 |\Acc_m(cN^2/\log^2N,\ N^K,\ N^{1-\varepsilon})|
                \le 2^{m-2}
 \tag{7}
\]
whenever the same accepted run also obeys $T\le N^K$.
Thus \emph{at least 75\%} of diagonal satisfiable formulas defeat
\emph{every} sound inline program having those three ceilings.
In exponent notation, all-source coverage still requires
\[
             d+ks\ge1,\qquad
             d<1\ \Longrightarrow\ t\ge2
 \tag{8}
\]
for the declared one-sequential-input-head model with one fixed
polynomial $T$ bound.
\end{corollary}
\begin{proof}
Since $m=\Theta(N/\log N)$, $G=\Theta(N)$,
and $S\le N^K$ along qualifying runs, (5) yields
\[
 B_{\rm t}=O_{U,k,K}\bigl[
       (N^{1-\varepsilon}+T/G+2)\log N\bigr].
\]
At $T\le cN^2/\log^2N$ the first contribution is
$o(N/\log N)$ and the second is $O(cN/\log N)$.
Choose $c>0$ small enough that
$B_{\rm t}+\log_2G+2<m$ for all large $m$.
Then (6) gives (7).
The first exponent constraint in (8) follows from the
$B_{\rm w}$ counting term and the second from (7), with strict
exponent margins. \emph{A bare $d<1$ without a fixed polynomial
time cap does not justify $\log S=O(\log N)$.}
\end{proof}

\section{Hostile finite controls and machine firewall}
\begin{description}
\item[] \textbf{Different programs, same encoded work but different
control states.} A promise-sound finite comparator stores
$a\oplus p$ and carries the bit $p$ in finite control when
crossing the source gap.  With $a=0^m,p=0$ and
$a'=1^m,p'=1$, the \emph{work-write records coincide} but
the complete crossing states differ. Dropping that state
falsely identifies the two transcripts. This is an explicit
reason why full crossing configurations are essential.
\item[] \textbf{Omitted actual writes.}  Distinct $a$ with the same
$p$ and work-head position give identical state-only
crossing records even though their complete work contents
differ.  The chronological actual-change log is essential.
\item[] \textbf{Two sequential source heads.} Position one read
head on Alice and the second on Bob, then scan both
selectors together. It uses $O(N)$ source transitions,
$S=D=0$ and decides the easy disjointness promise,
violating (8) \emph{after changing the input-head model}.
\item[] \textbf{Independent readable proof head.} A certificate
$z$ can assign each selector position to the Alice or Bob
shore. Check $a_i z_i=0$ on the first pass and
$b_i(1-z_i)=0$ on the second using an independently
positioned proof head. This is a one-sided nondeterministic
DISJ certificate on the promise, but its proof tape holds
unaccounted physical information. It is not an inline
program on the unique input head. A globally sound
ordinary-CNF wrapper would also have to authenticate the
source grammar and charge all overhead.
\item[] \textbf{Uncharged initial data or extra output head.}
Initially preloaded nonblank work contents or an independent
usable head coordinate invalidates the blank-replay/epoch
ledger. Count these channels explicitly before using (6).
\end{description}

\paragraph{Transport firewall.}
For the \emph{same solver} on a fixed-$k$ sequential multitape
machine, the conservative materializing one-tape simulation has
$T_1=O(T_k(N+S_k+\log(T_k+2)))$ and
$P_1=O(N+S_k+\log(T_k+2))$ for decision output
(including longer materialized output length $L$ in footprint when
relevant).  This is an \emph{upper simulation bound},
$t_1\le t_k+\max(1,s_k)$, not an intrinsic lower bound on
$t_k$.  FLMV's indexed read-only-input random-access bounds
are applied only to a \emph{single resulting native machine};
neither (7) nor the one-tape crossing stripe can be
intersected with its strict forbidden box without a charged
transfer.  No total SAT decision circuit follows merely from
a witness-verifier circuit.
