\section{Research question, model and falsifiers}
The priority question is whether every total uniform deterministic exact SAT decider must pay for a rich backward relation, or pay comparable cost under any state-adaptive alternative. We do \emph{not} assume either half of this dichotomy. Fix explicit, well-formed width-at-most-three CNF-SAT as the NP-complete target for the executable four-expert race. The Python experiment receives parsed integer-literal tuples; a full fixed-bitstring decider must first charge lexical validation and reject malformed encodings. Proper, duplicate-free signed exact-$(2,2)$ 3-CNF, with each variable twice in each polarity, is a distinct NP-complete sublanguage used for strong positive controls. When that stricter language is the target, prepend a charged signed-occurrence/uniqueness grammar validator which rejects invalid instances \emph{before} invoking the generic CNF-SAT race; the present Python script tests valid strict examples but does not implement the external input-string validator. Under a source-record word-RAM, a clause is encoded using four signed/identifier words and there are two header words, with $w=\lceil\log_2(64(n+m+1))\rceil$ and $N=(4m+2)w$. Every source read, rule test, representation switch, rejected method, branch, gate/auxiliary record, witness replay, and peak live space must be charged. The Python tests use \emph{abstract logical events}; no equivalence to RAM machine cycles is claimed.

Three falsifiable mechanisms were posed before the experiment. \emph{M1}: choosing one best static parameter or one backward table must represent the best solver. \textbf{FALSIFIED/RETIRED as a universal inference} by previous connected exact-$(2,2)$ and graph-parity examples, and tested anew with adaptive portfolios. \emph{M2}: a finite uniform portfolio may choose a source-dependent ranking and safely switch between complete exact methods, including both SAT and UNSAT continuations, without being handed the label. \textbf{PROVED/EXACT for the specified finite scheduler and COMPUTATIONAL for this implementation}. \emph{M3}: converting one source into Circuit-SAT creates mandatory extra decision freedom because it adds gate variables. \textbf{FALSIFIED/RETIRED as an automatic inference}: the functional gate variables are uniquely determined once the original inputs are set.

\section{Charged adaptive race theorem}
\begin{theorem}[PROVED/EXACT: source-observed geometric portfolio]
Let $A_0,\ldots,A_{s-1}$ be known, total, uniform deterministic exact deciders for one fixed language, realized on an agreed resumable step model. A source-only inspection costing $C_{\rm obs}(F)$ computes a permutation $\pi(F)$, without seeing the SAT label. For stages $r=0,1,\ldots$, grant expert at position $i$ exactly $2^{\max(0,r-i)}$ simulated steps and return the first completed answer. If $t_i(F)$ is that expert's standalone number of successful simulated steps (before its final halt indication), then, for every $i$,
\[
T_{\rm race}(F)\ \le\
C_{\rm obs}(F)+8\,2^i(t_i(F)+1)
+s\!\left(i+\lceil\log_2(t_i(F)+1)\rceil+1\right)+O(1)
\tag{1}
\]
in the declared unit-step-plus-dispatch model. Thus the right hand side may be minimized over all positions $i$ \emph{after the fact}; the algorithm is not given the minimizing index. If all configurations are retained, peak live storage is bounded by the stored source plus the sum of live expert spaces and scheduler state. This is an \emph{upper} bound, not a SAT lower bound.
\end{theorem}
\begin{proof}
Every expert gives the correct root SAT bit and halts, so the first answer is exact and the race is total. Fix an expert at position $i$ and set $R=i+\lceil\log_2(t_i+1)\rceil$. By stage $R$ its allocated quantum is at least $t_i+1$, forcing its termination if no prior exact expert has halted. For each earlier stage $r$, total simulated steps across all experts are at most $\sum_{j<s}(2^{r-j}+1)<2^{r+1}+s$. Summing through $R$ costs less than $2^{R+2}+s(R+1)$; using $2^R<2^{i+1}(t_i+1)$ proves (1). One dispatch check per expert per stage is included. The inspection is paid once before these steps. Retaining all resumable configurations gives the stated storage sum. The theorem is not silently transported to a different instruction model: universal TM or RAM simulation overhead must be inserted explicitly.
\end{proof}

\section{Backward Circuit-SAT with exact source identities}
For a proper exactly-three-clause source $F$ on $n$ named source inputs and $m\ge1$ clauses, construct one shared NOT gate for each input; two binary OR gates per clause; and $m-1$ binary AND gates. Its output is TRUE exactly when $F$ is satisfied. The basis is $\{\mathrm{NOT1},\mathrm{OR2},\mathrm{AND2}\}$, with
\[
G=n+3m-1,\qquad W=n+6m-2.
\tag{2}
\]
Create a separate gate-definition variable for each gate. A NOT equivalence takes two binary clauses; an OR/AND equivalence takes three clauses of widths at most three; the final output receives one unit clause. The complete gate-definition CNF has
\[
n_{\rm all}=2n+3m-1,\qquad
m_{\rm gate}=2n+9m-2.
\tag{3}
\]
\begin{lemma}[PROVED/EXACT functional gate extension; standard Tseitin fact]
For every source assignment $a$ there is a \emph{unique} assignment to the $G$ gate variables satisfying all gate definitions, obtained in topological order. The output unit is satisfied by that extension exactly when $a\models F$. Consequently the circuit CNF and source CNF have identical SAT labels and equal numbers of satisfying extensions over their respective variable sets.
\end{lemma}
\begin{proof}
Every gate definition is a Boolean biconditional $g\leftrightarrow \operatorname{op}(\ldots)$ and the circuit is acyclic, so its value is uniquely forced by earlier wires. The root AND enforces all clause OR outputs; shared named inputs, including complementary polarity uses, have only one source value. Appending the output unit accepts exactly the source satisfying assignments. All gate construction, source copying, gate evaluation and verification are linear in $G+W$ for the canonical representation, but this is a \emph{compiler} upper bound and not a SAT-solving circuit lower bound.
\end{proof}
For signed exact-$(2,2)$, $4n=3m$, reducing (2) to $G=5n-1,W=9n-2$. The occurrence conflict graph is a disjoint union of $n$ copies of $K_{2,2}$; a consistent choice of one true literal occurrence per clause is an exact independent transversal. This is a small intensional formulation; evaluation of its nonemptiness is still the full SAT question.

\section{Independent amortization and first missing implication}
\textbf{PROVED/EXACT source-probe obstruction (adopted from the ladder, not new).}
On the all-positive length-$q$ implication ladder, every one of the $q$ independently encoded consequent orientations is critical: toggling just that sign changes UNSAT to SAT. Let $U_t$ be the number of these sign fields still unread by an arbitrary deterministic exact source-query strategy after $t$ probes of that input. The potential $U_t$ is independent of the solver's chosen representation and decreases by at most one per sign-field read. If an exact decider leaves one critical sign unread, its observed transcript is identical on the corresponding opposite-label source, a contradiction. Therefore it must read all $q$ fields, regardless of any adaptive switching. This yields only $\Omega(q)=\Omega(N/\log N)$ addressed-word acquisition, matched by SCC and source-aware scanning. It is not superpolynomial.

\textbf{DUPLICATION/CONTRADICTION AUDIT.} MAIN101 already proved finite portfolio dominance; MAIN107 already constructed a linear-backdoor family whose ternaries collapse after a paid rule switch; ADAPTIVE-BIDIR65 already recognized graph parity; AFFINECUTDP82 already compared good/bad variable orders. None gives a universal lower bound. The additional observation here is an actually executed and charged \emph{source-prioritized four-method} bidirectional/control race with a standalone circuit-extension audit. The finite tests prove no asymptotic speed-up. The theorem (1) is a model-restricted upper-bound extension, not a general fastest SAT machine theorem.

\textbf{WHAT CHANGED RELATIVE TO ROOT MAIN.} Add the source-observed geometric racing upper bound, trace data, and the charged source/circuit parsimony control. Adopt exact-(2,2) pairing and the ROOT-LABEL-QUOTIENT85 warning; retain the source-probe ladder obstruction and the P-versus-NP OPEN status. Reject a mandatory rich backward table or initial-parameter-only universal decision bound. No previous theorem is strengthened to an unrestricted lower bound.

\textbf{OPEN first missing implication.} With $A$ ranging over \emph{every} total uniform deterministic exact decider for a single fixed NP-complete encoding, prove or refute
\[
\forall A\;\forall c>0\;\forall N_0\;\exists F_A:\quad
|F_A|\ge N_0,\quad T_A(F_A)>|F_A|^c .
\]
Neither the source-observation vector nor the per-expert event race supplies a representation-independent, superpolynomial charged-work obstruction for all adaptive policies. A candidate universal bridge must still permit unbounded state-dependent changes, source retention, Horn/SCC/affine methods, branching, learning, backtracking, caching, gate recovery and direct decision. The first requisite theorem is a \emph{model-matched, all-policy} extraction or forced expensive continuation statement, not an assertion that every decider constructs a table.
