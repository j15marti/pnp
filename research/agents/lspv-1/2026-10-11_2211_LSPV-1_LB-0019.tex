\begin{abstract}
We test a concrete amplification proposal for the clean-core block lower bound: place satisfiable one-bit tags at every internal node of a constant-arity tree whose leaves are the previously verified satisfiable/unsatisfiable block pair.  The totality adversary still forces one hit in every leaf block on the all-satisfiable input.  However, summing that obligation over tree depth either double-counts the same source characters or explicitly materializes copies whose bits are already charged to the input.  In the canonical encoding the purported depth amplification is only $O(N)$, and every unrestricted deterministic bit-probe decider has the trivial ceiling $N$.  Thus the candidate superlinear source-probe theorem is Status{FALSIFIED/RETIRED}.  No time, memory, communication, or arbitrary-computation lower bound follows.  P versus NP remains Status{OPEN}.
\end{abstract}

\section{Barrier-transfer literature preflight}

The two blocking obstacles are (i) transferring a source-access adversary to unrestricted uniform computation, and (ii) obtaining an unconditional lower bound in exactly that target model.  The following primary literature was checked before the present argument.

\begin{itemize}
\item Borodin--Cook and Fortnow--Lipton--van Melkebeek--Viglas establish time--space tradeoffs for specified machine models.  This is a emph{directly transferable theorem type} only after a model-preserving reduction supplies the required access pattern.  It does not imply that arbitrary SAT deciders materialize compatibility data.
\item Jain--Klauck--Santha prove decision-tree direct-sum theorems.  This is directly relevant to independent source blocks, but its charge is queries, not unrestricted running time or memory.
\item Baker--Gill--Solovay and Aaronson--Wigderson show that relativizing and algebraizing proof strategies cannot settle P versus NP.  These are barrier theorems, not lower bounds for the present family.
\item Razborov--Rudich concerns large, constructive circuit properties under pseudorandomness assumptions.  It warns against an unjustified circuit transfer; it is not itself a refutation of the query result.
\item Ajtai's branching-program tradeoffs are model-specific.  A branching program corresponding to a chosen execution can be charged only after bounding that realization; no such bound is supplied here.
\end{itemize}

Consequently, electronics-style routing congestion and distributed cut arguments are useful structural analogies but require a theorem mapping arbitrary RAM/Turing-machine executions to the same charged realization.  No such transfer is known in the corpus.

\section{Explicit nested clean-core family}

The verified LB-0018 construction supplies equal-length, syntactically aligned 3-CNF blocks $Y$ and $U$ with $Y$ satisfiable and $U$ unsatisfiable.  The REDTAG1 construction supplies satisfiable 3-CNF tags $T_0,T_1$ encoding one semantic bit without themselves determining total satisfiability.

Fix arity $b\ge 2$ and depth $d\ge 1$.  Put $L=b^d$ leaves in a full rooted $b$-ary tree.  For a leaf string $s=(s_1,\ldots,s_L)\in\{0,1\}^L$, define
\[
  B_{s_i}=\begin{cases}Y,&s_i=1,\\U,&s_i=0,\end{cases}
\]
using fresh variables for every component.  For each internal node $v$, let
\[
  a_v(s)=\bigwedge_{i\in\operatorname{leaves}(v)}s_i
\]
and include the disjoint satisfiable tag $T_{a_v(s)}$.  The formula is
\[
  F_{b,d}(s)=\left(\bigwedge_{i=1}^{L}B_{s_i}\right)
  \wedge\left(\bigwedge_{v\text{ internal}}T_{a_v(s)}\right).
\]
All components are variable-disjoint.  Hence
\[
  F_{b,d}(s)\in\mathrm{SAT}\quad\Longleftrightarrow\quad
  \bigwedge_{i=1}^{L}s_i=1.
\]
The number of internal nodes is
\[
  I=\frac{L-1}{b-1}=\Theta(L).
\]
With canonical decimal identifiers and delimiters, each constant-size component costs $\Theta(\log L)$ characters, so
\[
  N_{b,d}(s)=\Theta((L+I)\log L)=\Theta(L\log L).
\]

\section{Exact lower bound and exact ceiling}

\begin{theorem}[NESTED-TAG-LEAF-FLOOR1]
For every deterministic total decider $D$ correct on all well-formed 3-CNF encodings, the execution of $D$ on $F_{b,d}(1^L)$ probes at least one character in each leaf block $Y_i$.  Therefore it makes at least $L$ source probes.
\end{theorem}

\begin{proof}
Suppose $D$ probes no character of leaf block $Y_j$.  Replace only that aligned block by $U_j$, leaving every satisfiable tag unchanged, including tags whose advertised bit is now semantically stale.  The resulting string is still a well-formed 3-CNF and is unsatisfiable, because it contains $U_j$ as a conjunct.  The two inputs agree at every probed position, so deterministic $D$ follows the same transcript and returns the same bit, contradicting total correctness.  Repeating for every $j$ proves the claim.  Notice that the hostile input deliberately does not recompute ancestor tags; totality, rather than a promise of tag consistency, is the load-bearing premise.
\end{proof}

\begin{theorem}[DEPTH-SUM-ENCODED-CEILING1]
For the explicit family, the sum of one leaf obligation per level is not a superlinear lower bound in encoded length:
\[
  dL=L\log_b L\le L\log_2 L=O(N_{b,d}).
\]
Moreover, every Boolean language on $N$-bit strings has deterministic bit-probe complexity at most $N$.
\end{theorem}

\begin{proof}
The first assertion follows from $L=b^d$ and the length accounting above.  For the second, read all $N$ input bits and then perform arbitrary local computation on the recovered string.  Since local computation is uncharged in the query model, this is an $N$-probe decider.
\end{proof}

\begin{lemma}[MATERIALIZATION-CHARGING1]
Suppose an alternative encoding contains a separately addressable constant-size macroblock for every leaf--ancestor pair, and identifiers are self-delimiting.  Then it contains $dL$ such blocks and has length $\Omega(dL\log(dL))$.  Charging $\Omega(dL)$ probes is therefore at most linear up to the unavoidable addressing factor.
\end{lemma}

\begin{proof}
There are exactly $d$ proper ancestors per leaf.  Distinguishing $dL$ blocks requires $\Omega(\log(dL))$ bits per explicit identifier in the stated encoding.  Their concatenation supplies the bound.  Any compression that removes those physical copies also removes the independent source locations needed by the proposed adversary.
\end{proof}

These results separate semantic multiplicity from source-access cost.  The $d$ ancestor predicates may all depend on the same leaf bit, but a decision tree can read that bit once and reuse it without charge.  A one-bit output strengthens this objection: neither a compatibility table nor a satisfying assignment is part of the required output.

\section{Model-matched P=NP audit}

Assume, only for audit, that 3SAT has a uniform deterministic polynomial-time decider $A$.  Then $A$ decides every $F_{b,d}(s)$ in $N^{O(1)}$ time.  The theorem above forces $L=\Omega(N/\log N)$ source probes on the all-YES execution, which is compatible with polynomial time.  It does not force $dL$ distinct reads, any internal tag representation, any reconstruction procedure, or any superlinear memory/communication cost.  Therefore no unconditional model-matched contradiction follows.  Using the desired time lower bound as a premise would simply smuggle P$\ne$NP into the argument.

Padding and alternative encodings make the need for invariant quantification sharper.  If $p(N)$ ignored characters are appended, the same semantic instance has length $N+p(N)$ while the adversary still charges only the original leaves.  Equivalent wrappers may copy, delay, interpret, recompute, or erase intermediate compatibility data.  A universal theorem must quantify over such extensionally equivalent programs and cannot name a particular internal state unless that state is externally extracted with all costs charged.

\section{Post-quantum technique ledger}

For the selector map $L:\{0,1\}^L\to\{0,1\}$ given by AND, the fibers have sizes $2^L-1$ and $1$.  Thus the collision count is exactly
\[
  \operatorname{Coll}(L)=(2^L-1)^2+1,
\]
and Cauchy--Schwarz yields only the two-point image lower bound.  This is an Status{EXACT OBJECT/THEOREM TRANSFER} of the collision-entropy identity, but it exposes extreme lossiness rather than hardness.

Worst-case/average-case external extraction is an Status{ANALOGY/CANDIDATE}; a reduction from black-box SAT behavior to a charged source-access object is missing and must survive known NP reduction barriers.  Schur-square distinguishers, quadratic-relation rank, Hilbert functions, syzygies, and graded Betti numbers are Status{FAILED TRANSFER} here: no code or evaluation-map object is compelled by an arbitrary decider.  Collision extraction/special soundness is also a Status{FAILED TRANSFER} without two externally obtainable openings.  Hash and random-oracle methods are inadmissible for an unconditional P-versus-NP proof.  In every case hidden algebraic structure could aid an algorithm rather than force cost.

\section{DUPLICATION / CONTRADICTION AUDIT}

LB-0018 already proves the independent-block $\Omega(N/\log N)$ source-probe floor.  REDTAG1 already identifies the totality seam: consistent tags create a one-probe promise algorithm, while stale tags restore the leaf adversary for total deciders.  SYNTHESIS-0015 already warns that compatibility work can be laundered through preprocessing or hidden representations.  The new contribution is narrower: it formally closes the proposed tree-depth amplification by matching the depth sum to encoded length and by proving the universal $N$-probe ceiling.

No contradiction was found between these verified components.  A recurring overstatement was found in informal route descriptions that treat repeated semantic dependence as repeated physical access.  That inference is false unless a SAME\_REALIZATION theorem produces independently charged source locations.

\section{STALE OR OVERSTATED CLAIMS FOUND}

Any claim that the current clean core yields a superlinear arbitrary-algorithm lower bound is stale or overstated.  The strongest exact statement remains a representation-sensitive source-probe floor of order $N/\log N$ on an explicit family.  The new nested construction does not improve that order.  Structural, representation, proof-system, and query lower bounds must not be relabeled as lower bounds for unrestricted uniform computation.

\section{Precise handoff and open arrow}

The missing implication is:
\[
\begin{gathered}
\text{for every uniform deterministic 3SAT decider }A,\\
\exists\text{ an external extractor/reduction }E^A\text{ with all preprocessing charged,}\\
\text{such that one execution realizes independently chargeable source obligations}\\
\text{whose unconditional lower bound exceeds the full cost of }E^A\text{ and }A.
\end{gathered}
\]
It must quantify in encoded length, tolerate affine elimination and semantic shortcuts, be invariant under equivalent wrappers and padding, and culminate in a lower bound for the same computational model.  Until this arrow is proved, the universal-core program does not separate P from NP.
