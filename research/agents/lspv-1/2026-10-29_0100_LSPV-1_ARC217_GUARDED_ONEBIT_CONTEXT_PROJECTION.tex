\section{PROPOSE: exact missing arrow and four falsifiable mechanisms}
The current load-bearing constructive arrow is not the \emph{existence} of a small exact relation but its polynomial-time \emph{acquisition}, adaptive use, and hereditary closure on arbitrary source instances. ARC215 constructs polynomial two-language projections when the \emph{entire syntactic overlap} is kept; ARC216 gives an algorithm when the projected affine nullity is small. The following mechanisms were fixed before source search and experimentation.
\begin{description}
\item[]\textbf{M1, proved restricted.} Guard a mixed 2CNF--XOR3 encoding by one control bit $g$ so that the whole instance is satisfiable regardless of the original $3$CNF, but its exact \emph{contextual} projection to $g$ distinguishes SAT from UNSAT.
\item[]\textbf{M2, not justified by the stated premises.} Because the retained external interface has one bit and both component languages are individually easy, its exact relation is always polynomial-time constructible. M1 makes this imply a polynomial arbitrary-3SAT decider, which remains open.
\item[]\textbf{M3, proved restricted.} The difficulty persists with \emph{three-variable} GF$(2)$ equations and proper binary clauses, and under a promise that the input mixed instance is satisfiable. Pinning $g=0$ restores both SAT and UNSAT sides of one fixed solver.
\item[]\textbf{M4, open.} An adaptive representation-changing process might construct an answer-only successor without materializing all external boundary values. This is outside the contextual-summary theorem.
\end{description}

\section{BUILD: a uniform promise-satisfiable guarded transformation}
Let $F(x)=\bigwedge_{j=1}^{m}C_j(x)$ be any signed 3CNF, with $C_j=\ell_{j1}\vee\ell_{j2}\vee\ell_{j3}$. Introduce one \emph{global} bit $g$ and, for each clause, four \emph{fresh private} bits $y_{j1},y_{j2},y_{j3},t_j$. Define the mixed formula
\begin{align}
 H_F(g,x,y,t)&=\bigwedge_{j=1}^{m}G_j(g,x,y_j,t_j),\\
 G_j&:=\bigwedge_{i=1}^{3}(\ell_{ji}\vee y_{ji})\ \wedge\
 (y_{j1}\oplus y_{j2}\oplus t_j=0)\ \wedge\
 (t_j\oplus y_{j3}\oplus g=0). \label{eq:guard}
\end{align}
Every Boolean clause has width two; every parity row has exactly three \emph{distinct} variables. For a proper source clause the binary clauses are proper. The generator writes $3m$ binary clauses, $2m$ XOR3 rows, $4m$ fresh variables, and one $g$, with a full encoding length $N'=O((n+m)\log(n+m+2))$ under canonical integer-name serialization. It runs uniformly in polynomial time by direct enumeration of the source clauses, without testing satisfiability.

\begin{lemma}[Pointwise guarded projection]\label{lem:gadget}
For every source assignment $x$ and every $g\in\{0,1\}$,
\[
 \exists y,t\ H_F(g,x,y,t)\quad\Longleftrightarrow\quad
 g\vee F(x).
\]
\end{lemma}
\begin{proof}
For each clause the two parity rows combine into $y_{j1}\oplus y_{j2}\oplus y_{j3}=g$. If $g=1$, take all three $y$ bits equal to $1$, and $t_j=0$. This satisfies every binary clause and both parity rows regardless of the original literals. If $g=0$ and $C_j(x)$ is true, select any true literal position, set the corresponding $y$ bit to $0$ and the two other $y$ bits to $1$, then set $t_j=y_{j1}\oplus y_{j2}$. The clauses and both rows hold. Conversely, if $g=0$ and all three source literals are false, all binary clauses force $y_{j1}=y_{j2}=y_{j3}=1$, an odd parity contradiction. Because all private bits are disjoint across the clauses, the local equivalences conjoin without an additional compatibility assumption.
\end{proof}

\begin{theorem}[One-bit contextual-projection hardness on a satisfiable input promise]\label{thm:main}
There is an explicit deterministic polynomial-time map $F\mapsto H_F$ into proper binary clauses plus ternary affine XOR equations, with one distinguished control bit $g$, satisfying the following for \emph{every} signed $3$CNF $F$:
\begin{align}
 &H_F\text{ is satisfiable, with a uniformly constructible witness at }g=1;\\
 &R_F(g):=\exists x,y,t\ H_F(g,x,y,t)
   \equiv\begin{cases}1,&F\in\mathrm{SAT},\\g,&F\notin\mathrm{SAT};\end{cases} \label{eq:onebit}
\end{align}
Consequently, deciding whether a promised-satisfiable instance of this mixed language admits a model with $g=0$ is NP-complete. Deciding whether it \emph{entails} $g=1$ is coNP-complete, still under that satisfiable-input promise. Computing an exact two-entry relation table for the externally retained \emph{single} bit $g$ in deterministic polynomial time for all $H_F$ implies $P=NP$.
\end{theorem}
\begin{proof}
The witness at $g=1$ is the one in Lemma~\ref{lem:gadget}, for any assignment to $x$. Existentially quantifying $x$ in that lemma gives $R_F(0)=1$ exactly when $F$ is satisfiable, while $R_F(1)=1$ always. Construction is a many-one reduction from ordinary $3$SAT to the pinned extension question. A satisfying assignment for the mixed instance with $g=0$ is a polynomially checkable NP witness, so the pinned extension problem is NP-complete. Similarly, $H_F\models g$ exactly when $F$ is unsatisfiable. A counterexample to entailment is a polynomially checkable model with $g=0$, giving coNP membership, and the reduction from $3$UNSAT gives coNP-hardness. A complete exact table explicitly returns $R_F(0)$, deciding $3$SAT. All statements use one finite algorithm and a standard encoded language; the promise is the syntactically described output of the total generator, not an oracle supplying an answer-class bit.
\end{proof}

\begin{corollary}[Separate consistency is insufficient even under a SAT promise]
Each binary-clause subsystem of $H_F$ is satisfiable under both values of $g$ by taking all $y$ bits to be $1$. Each affine subsystem is satisfiable under both values of $g$ by choosing suitable $y,t$. Nevertheless the full conjunction pinned to $g=0$ is satisfiable exactly when $F$ is. In particular, use the eight signed clauses over three variables to obtain a hostile UNSAT pinned conjunction with separately satisfiable components.
\end{corollary}

\section{Crucial interface and decision-only firewalls}
The \emph{external contextual interface} is $\{g\}$, but the \emph{syntactic overlap} between the binary and affine subsystems includes all $3m$ different $y$ variables. Thus the result does \emph{not} contradict ARC215's polynomial projection over the \emph{entire} overlap, nor ARC216's $2^r$ enumeration: with $g$ pinned, each disjoint triple contributes one independent parity row on three overlap bits, so the projected affine nullity is $r=2m$. The original mixed whole-instance satisfiability question is trivial here, since $g=1$ always works. A \emph{decision-only} compressor may output fixed YES for $H_F$ and violate no theorem. What is NP-hard is preserving the complete extension relation for both subsequent contexts $g=0$ and $g=1$. Pinning $g=0$ restores the ordinary source SAT/UNSAT problem; it does not supply the outcome to the solver.

For a general moving/hierarchical summary proposal, this construction blocks the unsupported implication
\[
 \bigl|\text{exact relation on external interface}\bigr|=O(1)
 \quad\Longrightarrow\quad \text{uniform polynomial acquisition}.
\]
It does \emph{not} block arbitrary answer-preserving transformations, nor show any lower bound on all algorithms unless $P\neq NP$ is independently established. It supplies a hardness reduction under a specific \emph{context-preserving} output requirement, not a resource contradiction.

\section{Resource ledgers and the two-sided program restriction}
\begin{description}
\item[]\textbf{Single shared read/write tape:} the original input is part of physical footprint. Input parsing, new identifiers, the $O(m)$ new constraints, full output, head movements, temporary copies and peak tape footprint are charged. A conventional explicit writer yields polynomial time and storage; no particular crossing exponent is claimed.
\item[]\textbf{One-input-head multitape, with read-only input:} distinguish visited work cells, input-head travel, all generated output, and any separate work tapes. The explicit construction is polynomial but is not a low-space transformation in the exact FLMV indexed-input model.
\item[]\textbf{Two fully writable tapes:} count changes on \emph{both} tapes, never only the auxiliary tape; the gadget gives no sparse-change lower bound and no transfer from sequential input to random access.
\item[]\textbf{Indexed RAM:} every input access, allocated/visited word, Boolean evaluation and emitted encoded bit is charged under its declared word cost. The pinned-extension hardness is complexity-theoretic and model-robust under ordinary polynomial simulations, not a numeric RAM time--space exponent.
\item[]\textbf{Fixed common-input universal machine:} use one fixed interpreter and one fixed program for the generator, including program parsing and the output. No instance-specific advice or unchecked accepting program is used. Its simulation is polynomial, but the construction is not an SAT decider.
\end{description}
For each fixed correct SAT solver $A$, define $A_{+}$ and $A_{-}$ as the restrictions of \emph{the same} $A$ to $F\in\mathrm{SAT}$ and $F\notin\mathrm{SAT}$. The pinned family $H_F\wedge(\neg g)$ contains both restrictions. The unpinned $H_F$ family is uniformly satisfiable and by itself yields no side-specific lower bound. Separate maxima of $T_{+},S_{+}$ or $T_{-},S_{-}$ are not asserted to occur in one computation.
