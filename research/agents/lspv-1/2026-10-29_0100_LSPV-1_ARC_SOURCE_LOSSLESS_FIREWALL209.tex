\section{Build: two full-answer fibers}
Let $\ell_i(\beta)$ be $x_i$ if $\beta_i=0$ and $\neg x_i$ otherwise. On disjoint variables put
\[
 H_m(\beta)=\bigwedge_{i=1}^m(\ell_i\lor y_i\lor z_i)
       \land(\neg\ell_i\lor u_i\lor v_i).
\]
Every $H_m(\beta)$ is SAT, setting all $y_i=u_i=1$.
Let $U$ be all eight three-literal signed clauses over fresh $p,q,r$.
Every assignment falsifies one clause, so $U$ is UNSAT.
Each of the two families $\{H_m(\beta)\}$ and $\{H_m(\beta)\land U\}$
has $2^m$ distinct proper 3CNF strings of equal physical length
$N_m^\pm=\Theta(m\log(m+2))$ within each family, under canonical ASCII DIMACS.
The equal length follows because each pair of rows carries exactly one
negative sign regardless of $\beta_i$.
\begin{theorem}[Lossless sidecar bound, PROVED/RESTRICTED]
For either family, suppose maps $G_m,A_m$ produce strings of
maximum bit lengths $L_m,B_m$, and a decoder recovers every input:
$R_m(G_m(F),A_m(F))=F$. Then
\[
 L_m+B_m\ge m-2=\Omega(N_m^\pm/\log N_m^\pm).
\]
In particular $L_m\le (N_m^\pm)^\lambda$ and
$B_m\le(N_m^\pm)^\sigma$ cannot both hold eventually
for any fixed $\lambda,\sigma<1$.
\end{theorem}
\begin{proof}
The pair must be injective on $2^m$ sources. There are fewer than
$2^{L_m+1}$ and $2^{B_m+1}$ variable-length outputs respectively.
Therefore $2^m<2^{L_m+B_m+2}$, implying the stated lower bound.
For every $\rho<1$, $(N_m^\pm)^\rho=o(m)$, proving the second assertion.
\end{proof}
\noindent This theorem does not refute lossy SAT-equivalent
compression, short hash authentication, or P=NP.
A retained ancestor source provides missing information, but then
a recursive child that reads it is not a standalone $T(N^\lambda)$
invocation unless all retained-input access is charged.

\section{Build: closure exponent-product lemma}
\begin{lemma}[Re-entry product, PROVED/CONDITIONAL]
Let a total uniform polynomial-time SAT-preserving map $E$ take any
ordinary SAT encoding of size $n$ to a recognized family $\mathcal E$
of size $O(n^\alpha(\log n)^a)$. Let a total uniform polynomial-time
SAT-preserving map $C$ take each member of $\mathcal E$ to exactly one
physically emitted ordinary-SAT child of size
$O(N^\lambda(\log N)^b)$. Then the composition $G=C\circ E$ is
defined on all ordinary SAT and has length
\[
 |G(x)|=O(n^{\alpha\lambda}(\log n)^{a\lambda+b}).
\]
If $\alpha\lambda<1$, this is a recursively closed power-short
SAT successor above some threshold, and consequently P=NP.
\end{lemma}
\begin{proof}
Substitute the output size of $E$ into that of $C$. If
$\alpha\lambda<1$, choose $\alpha\lambda<\mu<1$, absorbing every
fixed polylogarithm into $n^{\mu-\alpha\lambda}$. Both computations
are polynomial-time, and the output is ordinary SAT, so $G$ can
be reapplied. Strict power descent has $O(\log\log n)$ levels and
polynomial total time, with fixed finite base cases.
\end{proof}
The previously proved LSPV-2 canonical cross-product embedding has
physical size $\Theta(t^2\log t)$ and one legitimate selector child
of $\Theta(t\log t)$ bits. Its child escapes the expanded grammar.
An arbitrary ordinary-SAT input requires the separate embedding,
approximately quadratic in its size; the square-root reduction
places the exponent product at $2(1/2)=1$, not below one.
The output still carries the original arbitrary SAT context.
This pipeline does not demonstrate power-short recursion.
The boundary product alone does not rule out a different
strict constant-factor contraction. None is constructed here.
