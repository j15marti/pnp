\section{Primary model and independent definitions}
Fortnow, Lipton, van Melkebeek and Viglas (FLMV) \cite{flmv}, Corollary 5.8, in their indexed random-access Turing-machine model, gives a forbidden box $(t,s)$ whenever for some fixed $c>\max\{1,t\}$,
\[
s<\beta(c),\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\tag{1}
\]
This uses their Theorem 3.1 reduction when carrying the endpoint to a standard ordinary SAT/3-CNF encoding; the reduction and its indexed-bit cost must be preserved. At $c_*=241/200$,
\[
\beta(c_*)=\frac{11642479}{23232400}>\frac12.
\tag{2}
\]
Strict inequalities provide slack for polylogarithmic simulations. The historical $t+s<2\cos(\pi/7)$ as an unrestricted SAT product endpoint is \textbf{FALSIFIED/RETIRED}.

An \emph{active-slot scoped stream} of bit length $M$ consists of self-delimiting OPEN, CLAUSE, CLOSE and END events. A CLAUSE uses only active slots. A slot is closed only after its last source occurrence and never reappears as a different copy of the same original variable. Temporary variables may occur, but the \emph{whole output conjunction} must be SAT-equivalent to the original source. Peak simultaneously live Boolean slots is $w$. Metadata and finite event fields use $O(\log(M+N+2))$ bits each, or their actual longer encoded costs are included in $M$.

\par\noindent A \emph{virtual scoped normalizer} is ONE fixed uniform total source-queryable machine $V$ that, for every ordinary input $F$ of $N$ bits, supplies the length $M(F)$ and the $i$th bit of a uniquely defined valid scoped stream $B(F)$, independently of prior queries. Every query is an ordinary charged invocation starting and ending with a reusable canonical decoder workspace, includes original-source reads, control/index tape operations, metadata, cleanup, failures and all bit writes, and returns exactly one bit. Its parameter hypotheses are independently defined as
\[
\begin{split}
M(F)&\le N^{\mu+o(1)},\quad
w(B(F))\le \kappa\log_2 N+o(\log N),\\
T_V(N)&\le N^{a+o(1)}\text{ per requested bit, including reset},\\
S_V(N)&\le N^{\sigma+o(1)}\text{ simultaneously},
\end{split}\tag{3}
\]
with constants $\mu,a,\kappa,\sigma\ge0$ and all bounds uniform in every $F$ and requested index. Length/header discovery and any upfront validation must either satisfy the same joint bound or be charged separately, below. No SAT-label oracle is available. The original source is read-only; the virtual output is \emph{not} uncharged writable storage.

\section{Exact virtual composition and forbidden tradeoff}
\begin{lemma}[Decode-once existential-table simulation, PROVED/EXACT]
For a valid virtual scoped stream satisfying (3), if its length/header and source-grammar preflight cost at most $N^{r+o(1)}$ time and $N^{\zeta+o(1)}$ space, there is ONE uniform exact source decider with
\[
\boxed{\begin{aligned}
t'&\le\max\{r,\ \mu+\max(a,\kappa)\},\\
s'&\le\max\{\zeta,\sigma,\kappa\}.
\end{aligned}}\tag{4}
\]
Both exponents refer to the SAME adaptive execution of ONE machine.
\end{lemma}
\begin{proof}
Perform the charged preflight. Iterate the index $i=0,\ldots,M(F)-1$, invoke $V(F,i)$ and parse the returned event bits into a logarithmic-size instruction buffer. Each virtual bit is decoded ONCE, regardless of the number of frontier-table rows. Maintain the exact set of currently live assignments extendible to a satisfying assignment of the already processed prefix. Opening one variable duplicates rows, a clause filters rows, and closing projects existentially and merges duplicates. The usual induction proves this invariant after each event, including both SAT and UNSAT parents. At END, the remaining empty assignment exists iff the output conjunction, hence $F$, is SAT.
There are $O(M)$ bit-service invocations costing $M N^{a+o(1)}$, and at most $O(M)$ event updates, each inspecting at most $2^w$ rows with polylogarithmic bookkeeping. Thus
\[
T=O\!\left(N^{r+o(1)}+N^{\mu+a+o(1)}
       +N^{\mu+\kappa+o(1)}\right).
\]
The decoder scratch is reused, not stored separately for every row; the DP table, decoder scratch, active-slot labels, event buffer and source index coexist in one configuration. They require $N^{\max\{\zeta,\sigma,\kappa\}+o(1)}$ writable bits. All source and workspace reads/writes, address operations, failed decoder attempts and cleanup are within the stated bounds. The code is uniform in $N$ and uses no nonuniform advice. This proves (4).
\end{proof}

\begin{theorem}[Virtual-normalizer FLMV fence, PROVED/EXACT in declared model]
No total uniform exact all-input virtual scoped normalizer exists with (3) and the preflight bounds above whenever there exists a fixed $c>1$ such that
\[
\boxed{
\max\{r,\mu+\max(a,\kappa)\}<c,\qquad
\max\{\zeta,\sigma,\kappa\}<\beta(c).
}\tag{5}
\]
\end{theorem}
\begin{proof}
The preceding lemma produces ONE uniform all-input exact SAT machine with both resource exponents strictly inside the FLMV-forbidden region. Apply FLMV's model-matched indexed SAT reduction, retaining its polylogarithmic overhead. This contradicts Corollary 5.8. No symbolic representation-size lower bound is asserted; only the specified low-resource \emph{all-input service contract} is excluded.
\end{proof}

For example, the jointly specified hypothetical contract
\[
(\mu,a,\kappa,r,\sigma,\zeta)
=(1,1/10,1/10,11/10,2/5,2/5)
\]
would yield $(t',s')=(11/10,2/5)$, forbidden by $c=241/200$. A lazy decoder can avoid storing the output but not the cost of all its individually decoded bits and the live DP. Equation (4) is sharper than the naive bound $\mu+a+\kappa$: reading each event before scanning the table permits reuse. Neither theorem rules out a decider that bypasses the virtual stream altogether.
