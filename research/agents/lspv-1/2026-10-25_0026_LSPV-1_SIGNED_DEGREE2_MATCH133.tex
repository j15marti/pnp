\section{Source language and independently specified parameters}
A signed exact-one source $H$ consists of constraints $E(C_i)$, each a list of one to three signed literals with distinct nonzero source variable identifiers, satisfied iff exactly one literal in the list evaluates TRUE. It is not ordinary disjunctive CNF. Define the source occurrence count $\deg_H(x)$ without reference to solver runtime, and $k(H)=|\{x:\deg_H(x)\ge3\}|$. Original source name and polarity are retained across constraints. Any compilation into proper ordinary 3CNF must charge all extra clauses, auxiliary variables, source headers and bits.

\begin{theorem}[Mandatory-node weighted matching, PROVED/EXACT restricted]
Every signed exact-one source $H$ with $\deg_H(x)\le2$ for every variable has a uniform polynomial-time exact SAT/UNSAT decision and optional source witness algorithm. The graph has $O(m+n)$ nodes and edges, weights in $\{1,2\}$.
\end{theorem}
\begin{proof}
For every source clause make one required vertex $c_i$. A variable occurring only once in clause $i$ is represented by an optional edge from $c_i$ to a private optional leaf, selected exactly when that literal is true. A variable occurring twice with the \emph{same} literal sign in clauses $i,j$ is represented by an optional edge $c_ic_j$, selected exactly when both occurrences are true. Parallel edges from distinct same-sign variables have identical effect on the required endpoints; keep one named representative per clause pair, treating every discarded variable as false-literal in a recovered witness. A variable occurring twice with \emph{opposite} signs is represented by one new \emph{required} vertex $h_x$ and two edges $h_xc_i,h_xc_j$. Its Boolean value makes exactly one occurrence literal true, so the chosen edge determines a single globally coherent source-variable value; $h_x$ must be saturated.

Let $R$ be all clause vertices and all $h_x$. Assign edge $uv$ weight $[u\in R]+[v\in R]$. A matching's total weight is exactly the number of required vertices saturated; it cannot exceed $|R|$. Therefore the maximum weighted matching has weight $|R|$ iff all clause vertices and all opposite-sign choice nodes can be saturated. A satisfying Boolean assignment yields such a matching: every clause has exactly one true occurrence, and each opposite-sign source variable selects exactly one incident clause. Conversely a saturating matching sets same-sign or degree-one variables true-literal when their corresponding edge was selected, and opposite-sign variables according to the endpoint of their matched $h_x$ edge. Every clause is covered once, giving exactly one true literal there; the same global value is used for both occurrences of a source variable. Polynomial general-graph weighted matching is known [Edmonds; Gabow]; source grouping, edge creation and reconstruction are charged polynomial operations. No correctness assumption about local child SAT bits is used.
\end{proof}

\begin{theorem}[High-occurrence parameter, PROVED/EXACT restricted]
Every signed exact-one source $H$ is exactly decidable, with optional witness, by one uniform algorithm in $2^{k(H)}\operatorname{poly}(|H|)$ time and polynomial peak writable space.
\end{theorem}
\begin{proof}
Enumerate all assignments to the $k(H)$ original variables occurring at least three times. For each source clause, reject if two or more fixed high-occurrence literals are true. If exactly one is true, replace each remaining low-occurrence literal $\ell$ by a unary exact-one constraint $E(\neg\ell)$ to force it false. If none is true, retain an exact-one constraint on all remaining low-occurrence literals, rejecting if none remain. Each low variable participates in no more residual constraints than its original source occurrences, at most two. The first theorem decides the residual. Replay a recovered low assignment together with the fixed high assignment on the original clauses; every accepting branch is sound, and every global satisfying assignment appears in one enumerated branch, giving completeness. Process branches sequentially, charging all failures, graph constructions, strategy selection and reconstruction; only polynomial writable space is live at any moment.
\end{proof}

Moore--Robson [MR] establish NP-completeness of planar cubic monotone 1-in-3 SAT, where each positive source variable occurs in exactly three clauses. Thus source-occurrence two is polynomial even with arbitrary literal signs while positive occurrence three contains an NP-complete subclass. This sharp \emph{source-language threshold} supplies no new unrestricted deterministic time lower bound.
