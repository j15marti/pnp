\section{PROPOSE: the missing lemma and four falsifiable mechanisms}
The original research goal is a single fixed uniform deterministic polynomial-time successor $K$ operating on a closed, canonical encoded problem class containing SAT, preserving the answer on both SAT and UNSAT sources, writing exactly one child of length at most $N^\lambda$ for constant $0<\lambda<1$ above a fixed threshold, and directly deciding bounded base cases. We target four falsifiable claims.\par
\noindent\textbf{M1:} Uniform polynomial-cost one-child contraction is only a sufficient and not a necessary property if $P=NP$. This is \textbf{FALSIFIED} as a logical distinction under the stated definition: its existence is equivalent to $P=NP$. A particular local structural construction is not necessary as a \emph{proof strategy}.\par
\noindent\textbf{M2:} Any complete polynomial-time SAT decider necessarily admits universal polynomial-size \emph{ordinary-resolution} UNSAT certificates. This is \textbf{FALSIFIED unconditionally} by the established exponential resolution complexity of pigeonhole formulas.\par
\noindent\textbf{M3:} Adding source-authenticated XOR deductions automatically removes all proof-size obstructions. This remains \textbf{OPEN} for arbitrary certificate grammars. A September 2026 formalized-preprint claim establishes a lower bound even for a particular broad parity-resolution system; the present run does not independently certify that new theorem.\par
\noindent\textbf{M4:} A uniform oracle architecture with a single recursive call supplies a classical SAT algorithm if oracle encoding/access is uncharged. This is \textbf{FALSIFIED} as an algorithmic inference: a target-dependent Boolean oracle may itself encode arbitrarily difficult information and must be paid for.

\section{BUILD I: the exact logical equivalence}
Let $L$ be SAT under a fixed uniformly decodable canonical encoding. Let $\mathcal C$ be a closed, uniformly polynomially recognizable encoded decision class with (i) a deterministic polynomial-time answer-preserving reduction from SAT to $\mathcal C$, (ii) a deterministic polynomial-time answer-preserving reduction from $\mathcal C$ to SAT, and (iii) two fixed valid YES and NO encodings $y_{\rm YES},y_{\rm NO}\in\mathcal C$ that are directly decidable as base instances. The special choice $\mathcal C=\mathrm{SAT}$ satisfies all three conditions. A \emph{uniform strict successor} is a single deterministic program $K$ that on every $x\in\mathcal C$ of length $N$ runs in $O(N^c)$ steps for a fixed $c$, produces one $K(x)\in\mathcal C$, preserves the answer and, for all $N\ge N_0$, produces $|K(x)|\le N^\lambda$ with constant $0<\lambda<1$.
\begin{theorem}[Exact equivalence for the decision problem]\label{thm:equiv}
Under the above hypotheses, with $N_0$ larger than the two terminal encodings, such a uniform strict successor exists if and only if $SAT\in P$. Consequently, its existence is equivalent to $P=NP$. More generally, for a nontrivial decision class $\mathcal C$ with two fixed terminal instances, the successor property is equivalent to $\mathcal C\in P$, and its equivalence with SAT requires both reductions.
\end{theorem}
\begin{proof}
For the forward implication, first map each SAT source into $\mathcal C$ and recurse on the unique child until its length is below $N_0$. If the initial encoded length is $N$, the number of nonbase calls is at most
\[
 d(N)\le 1+\left\lceil\frac{\log(\log N/\log N_0)}{\log(1/\lambda)}\right\rceil
 =O(1+\log\log N),
\]
for $N$ sufficiently large. Charging all rule choices, failed internal tests, buffers, child generation, parsing and output in $O(N_i^c)$ at level $i$, the sum is at most $O(N^c(1+\log\log N))$, plus polynomial initial mapping and base decision. This is a deterministic polynomial SAT decider. Conversely, if SAT is in deterministic polynomial time, apply the polynomial reduction from $\mathcal C$ to SAT, decide the resulting SAT instance and write $y_{\rm YES}$ or $y_{\rm NO}$. The output is one fixed terminal child, physically bounded by a constant. Increasing $N_0$ if necessary makes it at most $N^\lambda$ for every longer input. The program and the base answers are uniform, and no advice or oracle is used.\end{proof}
\paragraph{Important quantifier correction.}
The phrase ``this sufficient target is not necessary for $P=NP$'' is inaccurate if it refers to the \emph{existence} of the specified uniform map. The corrected statement is that one need not discover this particular architectural map \emph{before proving} $P=NP$ by some other method, but once $P=NP$ holds such a map exists. Its explicit construction \emph{without relying on an assumed SAT decider} is still the project's central OPEN step.

\begin{corollary}[Polynomial-value adaptive rank equivalence]
An unrestricted deterministic answer-preserving state machine with polynomial-size complete states, polynomial transition and discovery costs, and a strictly decreasing nonnegative integer rank of initial value at most $\operatorname{poly}(N)$ decides SAT in polynomial time. Conversely, if SAT is in $P$, such a machine exists with one transition and rank initially $1$. Thus this \emph{unrestricted existence} criterion is also equivalent to $P=NP$.
\end{corollary}
The rank must be polynomial in \emph{value}, not just in encoding length. Rank $2^N$ occupies only $N+1$ bits but permits exponentially many decrements. Nonuniform per-size selectors, unknown solver exponents, and uncharged base-oracle evaluation do not satisfy the theorem.

\section{BUILD II: universal polynomial resolution proof coverage is already false}
For $h\ge1$, let $PHP_{h+1}^{h}$ have variables $p_{i,j}$ for $h+1$ pigeons and $h$ holes and clauses
\[
 \bigvee_{j=1}^{h} p_{i,j}\qquad(i=1,\ldots,h+1),
 \qquad \neg p_{i,j}\vee\neg p_{i',j}\quad(i<i',\ j\in[h]).
\]
The formula is unsatisfiable by the pigeonhole principle. It has $h(h+1)$ variables, $h+1+h\binom{h+1}{2}$ clauses and canonical bit length polynomial in $h$.
\begin{theorem}[Known resolution coverage obstruction, Haken 1985]
Every ordinary-resolution refutation of the standard $PHP_{h+1}^{h}$ family has $2^{\Omega(h)}$ lines. Therefore the hypothesis ``every UNSAT CNF has a polynomial-length ordinary-resolution refutation'' is false unconditionally, independently of whether $P=NP$.
\end{theorem}
\paragraph{Proof-system firewall.} This theorem rules out using \emph{ordinary resolution} as an all-input polynomial-size UNSAT certificate grammar. It does not refute polytime \emph{decision} algorithms, algorithms returning other certificates, or polytime \emph{witness discovery} conditional on $P=NP$. Buss proved polynomial-size Frege proofs of PHP, illustrating that the proof system matters \cite{buss1987}. Converting arbitrary wide clauses to 3CNF by adding auxiliaries can change proof complexity; no lower bound is transported to a gadgetized exact-(2,2)-3CNF family without a proof-preserving reduction.

\paragraph{Parity-resolution extension, source-verified claim only.}
Braun's September 2026 manuscript \cite{braun2026} states that for $h=2^\ell$, $\ell\ge32$, any DAG-like resolution-over-parities refutation of the \emph{bit-encoded} $PHP_{h+1}^{h}$ requires more than
\[
 \exp\left(\frac{h}{32768\ell^2}\right)
\]
lines. The actual Lean declaration \path{MathResearch.bitPHP_exponential} was found at the source path given above. The manuscript and its own reproducibility audit report a formalization, but this run neither invoked a Lean kernel nor independently reviewed all Lean dependencies. Mark \textbf{EXTERNAL CLAIM / SOURCE INSPECTED}, not a new proved project theorem. It also does not cover arbitrary extended resolution, Frege or the custom XOR-plus-branch certificate language used by ARC222.
