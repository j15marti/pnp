\section{Target and obstruction}
The one canonical target is D\"ocker's NP-complete duplicate-free proper clausewise-monotone 3-SAT-(2,2): three distinct same-polarity literals in every original clause and exactly two positive and two negative occurrences per original variable. A binary decider returns YES on valid SAT strings, NO on valid UNSAT or malformed strings. The broader proper signed strict-2P2N language is only a comparative superset, never an easy-subfamily hardness surrogate.

\textbf{Obstruction.} Can arbitrary deterministic, source-authenticated indexed-input SAT deciders skip original signed-hypergraph input bits when an adaptive policy or child description is used? Does source acquisition force writable XOR activity? \section{Explicit binary encoding and exact theorem}
Encode original \(n\) in a self-delimiting header of \(O(\log n)\) bits, set \(m=4n/3\), \(w=\lceil\log_2 n\rceil\). Each original clause record is one polarity bit followed by three distinct \(w\)-bit source IDs in \([0,n-1]\). Check each signed original clause is unique, every variable appears twice per polarity, and the exact record count. The payload length is
\[
P(n)=m(1+3w)=\frac{4n}{3}(1+3\lceil\log_2 n\rceil),\quad N=P(n)+O(\log n).
\]
Fixed-length source bit positions and original clause/variable indices are preserved.
\begin{theorem}[One-bit isolation, every valid source]\label{iso}
For each valid source \(x\) and every payload bit \(j\), \(x\oplus e_j\) is malformed and has unchanged header, length and \(n\).
\end{theorem}
\begin{proof}
Flipping a clause sign changes three signed occurrences and violates the exact positive/negative degree quotas. Flipping one variable-ID bit changes that name: an out-of-range or within-clause duplicated name is invalid; otherwise exactly one signed occurrence moves from its old source variable to a distinct new variable, so both degree quotas are violated. No assignment or SAT label is used.
\end{proof}
\begin{theorem}[Every valid SAT source must be fully observed]\label{satfloor}
Every fixed uniform deterministic \emph{total exact} indexed-input decider for this binary target language probes \emph{each of the \(P(n)\) payload bits} on every valid SAT input \(x\), including source-dependency probes delegated to a virtual child or arbitrary guest. If the machine has \(r_A\) simultaneous source-bit reading heads, \(T_A(x)\ge P(n)/r_A=\Omega(N)\).
\end{theorem}
\begin{proof}
Assume the machine returns YES on \(x\) without probing bit \(j\). The one-bit mutant \(x'=x\oplus e_j\) must be rejected by Theorem~\ref{iso}. Induct over deterministic transitions: identical replies on every source query imply identical work/index contents, machine state, head locations, adaptive actions, charged guest evaluations and final YES output on \(x'\), a contradiction. This is the standard transcript/decision-tree sensitivity adversary, specialized to this target grammar. Its strength is only a linear read-time floor, not a physical-write or writable-space floor.
\end{proof}
\begin{theorem}[Infinite valid UNSAT sources with short NO transcripts]\label{nofloor}
A single total deterministic exact target decider \(B\) has infinitely many valid UNSAT inputs \(G_k\), \(N_k\to\infty\), on which it reads only \(O(\log N_k)\) original input bits.
\end{theorem}
\begin{proof}
Use the original certified UNSAT \(U_{198}\): 198 variables, 264 signed clause records, six 42-clause private modules and two global constraints. Every one of its 64 boundary assignments is refuted (16 by global clauses, 48 by at least one independently UNSAT module). The remaining ten cross-module clauses are unnecessary for this UNSAT subformula proof. Let \(Y_6\) be a valid SAT six-variable, eight-clause M22 formula. For \(k\ge1\), set \(G_k=U_{198}\wedge\bigwedge_{i=1}^k Y_6^{(i)}\), disjointly renaming the copies. It is valid M22 and UNSAT, with \(n=198+6k\), \(m=264+8k\). The fixed decider \(B\) reads the \(n\) header, compares just the first 264 records with the hardwired \(U_{198}\) using current field width \(w\), and returns NO immediately on an exact match, irrespective of any unread suffix (including malformed suffixes). Otherwise it runs a complete exact grammar-checking exhaustive fallback. This is globally sound and reads \(264(1+3w)+O(\log n)=O(\log n)\) bits on \(G_k\), compared with \(N=\Theta(n\log n)\). The worst-case fallback is not polynomial. Three-way INVALID/UNSAT/SAT output is a different problem and is not assumed.
\end{proof}

\section{Source-indexed S/U, physical XOR and adaptive ledger}
For each original clause \(C_j\), local \(S_j\) demands all literals TRUE and local \(U_j\) demands all FALSE; inversion swaps them. These are local \emph{source occurrence requests}, not independently assignable variables. For two monotone original clauses with shared source variables, the compatibility word \(SS,SU,US,UU\) is \(1001\) for the same polarity, \(0110\) for opposite polarity, and \(1111\) for disjoint clauses. A shared variable simultaneously with the same and opposite polarity is impossible for a pair of individually monotone clauses, unlike the broader signed strict-2P2N superset.

For a coherent one-pass \(0^n\) to \(1^n\) flip path, logical two-bit clause-true-count XOR sums to \(4m\) in binary coding, \(3m\) in Gray coding, and has endpoint distance \(2m\) in either. Assignment bits add \(n\) changed coordinates. These identities are OFFLINE representational observations and do not force physical writes by an implicit/lazy solver. The native FLMV amortized index-erasure bound from ARC-INDEX-RECHARGE283 still gives \(D_{\rm phys}\le2qT\) on initially blank index tapes, but this paper supplies no positive lower bound on \(D_{\rm phys}\) or on peak writable space. Charge original indexed input reads, creation/clearing of index addresses, strategy recognition/selection/switching, failed trials, guest/child access, verification, proof provenance, output and retained parent/child/caches in one simultaneous time/space ledger. The source-read floor \(\Omega(N)\) fits within the proposed \(N^{11/10}\) local ARC budget.
