\section{Construction: fixed-template proper 3-CNF parity}
Write $U(\ell;a,b)$ for the conjunction of four proper three-literal clauses
\[
U(\ell;a,b)=\bigwedge_{\sigma,\tau\in\{+1,-1\}}
  (\ell\lor \sigma a\lor\tau b).
\]
For all assignments, $U(\ell;a,b)$ holds if and only if $\ell$ is true: if $\ell$ is false, the four clauses require each of the four sign choices on $(a,b)$ and are jointly inconsistent.
For Boolean variables $a,b,z$, define $X(a,b,z)$ by one proper three-literal clause forbidding each of the four assignments where $z\ne a\oplus b$. Then $X(a,b,z)$ is equivalent to $z=a\oplus b$.

For every integer $p\ge2$ and parameter $\mathbf b=(b_1,\ldots,b_p)\in\{0,1\}^p$, form $F_{p,\mathbf b}$ as follows. Introduce primary variables $x_1,\ldots,x_p$ and distinct fresh auxiliary pairs $(a_i,c_i)$, plus chain variables $y_1,\ldots,y_{p-1}$ and a final auxiliary pair $(u,v)$. Include $U(x_i;a_i,c_i)$ if $b_i=1$, and $U(\neg x_i;a_i,c_i)$ otherwise. Include $X(x_1,x_2,y_1)$ and, for $2\le j\le p-1$, include $X(y_{j-1},x_{j+1},y_j)$. Finally include $U(y_{p-1};u,v)$. All clause and variable numbers are independent of $\mathbf b$:
\[
 n_p=4p+1,\qquad m_p=8p,\qquad
 N_p=2w_p+24p(w_p+1)=\Theta(p\log p),
 \quad w_p=\left\lceil\log_2(8p+1)\right\rceil.
\]
Here the declared input format contains two $w_p$-bit header fields and each of $24p$ literal positions consists of one sign bit followed by its $w_p$-bit name. All clauses are proper, and fixed namespaces make the clause list duplicate-free. \textbf{This source family is ordinary signed proper 3-CNF; it is neither clause-monotone nor exact-$(2,2)$.} Any transfer to another language is an additional charged theorem, not an identification of grammars.

\begin{theorem}[Exact parity relation and input locality, PROVED/EXACT]
For every $p\ge2$ and $\mathbf b\in\{0,1\}^p$,
\[
\SAT(F_{p,\mathbf b})\iff\bigoplus_{i=1}^p b_i=1.
\]
For each index $i$, replacing $b_i$ by $1-b_i$ changes \emph{exactly four source sign bits}, all in a fixed disjoint group $D_i$ of four positions; it changes no other encoded bit, header, clause count, variable identifier, or clause incidence.
\end{theorem}
\begin{proof}
Every $U$ block fixes $x_i=b_i$. The XOR clauses inductively fix $y_j=b_1\oplus\cdots\oplus b_{j+1}$; the last $U$ block requires $y_{p-1}=1$. Conversely, for odd parity, these forced assignments extend to the independent unit-block auxiliaries, since every unit gadget is satisfied when its distinguished literal is true. The only input-dependent literal is the sign of $x_i$ in the four clauses of its own $U$ block, so changing one $b_i$ flips those and only those four sign fields. The variable IDs and the fixed clause layout remain identical.
\end{proof}

\section{The transcript/output distinction and exact query theorem}
A \emph{query transcript} records each indexed source-bit address and returned value, as well as the stopping point. A \emph{final output} is just SAT or UNSAT. These are different objects. The already-valid checkpoint upper bound
\[
\#\{\text{state-and-answer transcripts}\}\le2^{S+q}
\tag{1}
\]
uses $S$ initial writable/index bits and $q$ subsequent \emph{one-bit} source reads, or $2^{S+qw}$ when each probe returns at most $w$ bits. Its input-dependent starting-state distribution, if any, must be stated rather than hidden.

\begin{theorem}[One-bit SAT requires $2^p$ initial transcripts on the parity promise]
Fix $p\ge2$. Let $A$ be \emph{any} deterministic exact decider for all ordinary SAT inputs, hence correct on every $F_{p,\mathbf b}$. Place the checkpoint before the first source-dependent read, with the same initial machine state for every $\mathbf b$. On \emph{every} promised input $F_{p,\mathbf b}$, $A$ must query at least one bit from each source group $D_i$, and therefore at least $p$ distinct source-bit locations. Across the $2^p$ promised inputs, its full query transcripts are pairwise distinct, even though its final output takes only two values.
\end{theorem}
\begin{proof}
Fix any $\mathbf b$ and coordinate $i$. If the deterministic run did not inspect any of the four addresses in $D_i$, then by the locality lemma it would receive the identical answer to each source query on $F_{p,\mathbf b}$ and $F_{p,\mathbf b\oplus e_i}$. Inductively the full runs and outputs would be identical, contradicting the exact parity theorem. Hence each coordinate must be queried and at least $p$ disjoint groups are touched. Now suppose two distinct inputs $\mathbf b\ne\mathbf c$ had identical full transcripts. Choose $i$ where they differ. The run for $\mathbf b$ queries at least one source position in $D_i$, whose answer is the complement of that position's answer on the $\mathbf c$ source. Thus the transcripts cannot be identical. Consequently the transcript map is injective and has $2^p$ values.
\end{proof}

\begin{corollary}[Required correction to the R-label bound]
It is correct that the cardinality of \emph{final decision labels} is at most two. It is \textbf{FALSIFIED/RETIRED} to infer from that fact alone that the number of necessary \emph{initial probe transcripts} in (1) is at most two. The present SAT promise has $R_{\mathrm{out}}=2$ and $R_{\mathrm{transcript}}=2^p$. In the FLMV one-bit-probe model, this gives only $q\ge p=\Omega(N_p/\log N_p)$ on this easy promise family, not a superlinear time-space lower bound for arbitrary SAT.
\end{corollary}

\begin{lemma}[Arbitrary checkpoint is a different quantifier, PROVED/EXACT]
There is a uniform deterministic algorithm that reads all $p$ designated sign bits, maintains only their parity in one Boolean work cell plus logarithmic indexing, and then stores one output bit at a later checkpoint. After that later checkpoint it uses zero further input probes. Hence a claim $S+q\ge p$ at \emph{every} checkpoint with charged preprocessing omitted is false. Equation (1) itself remains valid because the final post-checkpoint behaviour has only two possible states.
\end{lemma}
\begin{proof}
Sequentially XOR the $p$ sign bits, then retain the XOR result. The $p$ reads and index increments occurred \emph{before} the second checkpoint and cannot be erased from a total-run resource bound. After they occur the entire promised decision reduces to the stored Boolean bit, requiring no source probe. On the initial checkpoint, the preceding theorem still forces $p$ source reads.
\end{proof}

\section{A linear circuit despite exponentially many query transcripts}
\begin{theorem}[Promise circuit/circuit-size firewall, PROVED/EXACT]
The restricted length-$p$ function $\mathbf b\mapsto\SAT(F_{p,\mathbf b})$ has an explicit \emph{uniform} circuit of $4(p-1)$ two-input NAND gates and depth at most $3\lceil\log_2p\rceil$. In particular, $2^p$ necessary initial transcripts do \emph{not} imply an exponential full-decision-circuit size lower bound, even for a one-bit SAT promise family.
\end{theorem}
\begin{proof}
One XOR gate has the four-NAND circuit
\[
 t=\operatorname{NAND}(a,b),\quad
 u=\operatorname{NAND}(a,t),\quad
 v=\operatorname{NAND}(b,t),\quad
 a\oplus b=\operatorname{NAND}(u,v).
\]
Organize $p-1$ XOR operations in a balanced tree. Its depth is at most three times the tree height, and its exact NAND count is $4(p-1)$. The input bits $b_i$ are available as one chosen sign bit per fixed group $D_i$ with a fixed NOT convention. Their bit addresses are explicit arithmetic functions of $i,p$; an optional sign inversion per input adds at most $p$ NOT gates, still linear size. This circuit computes only the \emph{promise-restricted} SAT function, not the all-length-$N$ ordinary SAT function $C_{A,N}$ for arbitrary encodings.
\end{proof}

\section{Exact-class transfer firewall and all-UNSAT certificate arrow}
The peer LSPV-2 report CIRCUIT-R15-VIRTUAL-ACCESS163 supplies a source-fixed-incidence virtual compiler $R_{15}$ into \emph{proper signed} exact-$(2,2)$-3-CNF, whose output bits are claimed to be constants or one fixed source polarity with paid polylogarithmic random-access overhead. Conditional on independently validating its gadget equations and local-access interface, applying $R_{15}$ to $F_{p,\mathbf b}$ transfers the parity SAT labels to a family of signed exact-$(2,2)$ children. Since each output bit is governed by at most one $b_i$, distinct input coordinate influences remain disjoint; if an influence vanished altogether, source satisfiability preservation would be contradicted. Therefore the $p$-group probe theorem transports \emph{conditionally} to that particular virtual fixed-incidence family. It does not transport to the strictly \emph{clause-monotone} exact-$(2,2)$ class by this lemma, nor establish FLMV-hardness of the parity promise.

This query theorem is a source-sensitivity bound, not an UNSAT-certificate lower bound. A verifier for this parity promise reads the $p$ controlling signs and computes parity in $O(p\operatorname{polylog}p)$ bit time and $O(\log p)$ workspace. No all-input low-volume adaptive UNSAT certificate follows. The weighted child lemma remains exact arithmetic,
\[
\sum_i m_i^d\le(\max_i m_i)^{d-1}\sum_i m_i\quad(d\ge1),
\]
but the existence, construction, and completeness of the child list remain \OPEN. Nothing here supplies the second deterministic small-space machine required by van Melkebeek's Theorem 1.3. A contradiction restricted to $(d,s)=(1.802,o(1))$ would not establish $P\ne NP$.
