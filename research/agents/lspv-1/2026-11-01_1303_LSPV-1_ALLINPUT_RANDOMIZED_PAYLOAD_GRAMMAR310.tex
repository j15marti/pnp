\section{Model and quantified theorem}
Let $L$ contain the valid satisfiable duplicate-free proper D\"ocker Monotone 3-SAT-(2,2) strings; malformed strings and valid UNSAT originals have label zero. Encode an original by $E(F)=\gamma(n)\gamma(m)\prod_{j=1}^m[s_j,b_w(v_{j1}),b_w(v_{j2}),b_w(v_{j3})]$, where $m=4n/3$, $w=\lceil\log_2(n+1)\rceil$, $\gamma$ is Elias-gamma, $s_j$ is one source-clause sign bit, and $b_w$ is an unsigned $w$-bit variable identifier. Put $N=|E(F)|$ and $M=m(1+3w)=N-|\gamma(n)|-|\gamma(m)|$. An indexed read-only-input machine pays for every native source-bit read, index/head move, deduction, guest, and selection action. $R_A(x)$ denotes the number of DISTINCT source cells read; $Q_A(x)$ counts all reads including repetitions.
\begin{theorem}[Exact bounded-error source-observation floor]
For EVERY valid SAT original $F$, EVERY fixed-code total all-binary-input randomized decision machine $A$ with worst-input error $0\le\epsilon<1/2$ (including deterministic machines at $\epsilon=0$), and the declared input encoding and native bit-access model,
\[
\boxed{\mathbb E R_A(E(F))\ge(1-2\epsilon)M,\qquad
\mathbb E Q_A(E(F))\ge\mathbb E R_A(E(F)).}
\]
In particular every exact deterministic accepting run must read ALL $M=N-O(\log N)$ payload bits. No assignments, pin keys, source trajectories or injective internal representations need be retained. The theorem is independent of internal representation, not independent of the declared physical input encoding.
\end{theorem}
\begin{proof}
For every payload position $i$, flipping that one bit makes a malformed same-length string $y_i$. Flipping a clause sign changes the signed occurrence quota of its three variables; flipping an identifier bit changes an occurrence from name $x$ to a distinct integer $y$, either invalid/duplicated or violating the exact 2-positive/2-negative quotas at both $x$ and $y$. Thus $L(E(F))=1$ and $L(y_i)=0$. Couple the two runs under identical random bits. Until $i$ is read, all input observations and all internal/control/guest transitions coincide. Their outputs can differ only if $i$ is read on $E(F)$. But the difference of acceptance probabilities is at least $(1-\epsilon)-\epsilon=1-2\epsilon$, hence $\Pr[i\text{ read on }E(F)]\ge1-2\epsilon$. Sum over the $M$ payload positions by linearity; repeated reads cannot lower $Q_A$. QED.
\end{proof}
