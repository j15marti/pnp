\section{User-approved change of the sufficient target}
Maintain two formulations within the SINGLE ARC/FLMV simultaneous time--space spine. ARC-EDGE-90A (all-input) asks for a sequence of simultaneously achievable pairs of uniform total exact ordinary-SAT machines, correct and bounded on every encoded length-\(N\) source. ARC-EDGE-90B (image-promise) permits the root solver's correctness and bounds to be required only on a specified near-linearly SAT-complete fixed reduction-image family. Every typed reachable descendant must nevertheless be covered by the correct promise contract. Intermediate steps are not required to shrink every input individually, but their \emph{worst-case} bound on the required family must hold; an expensive fallback on a reachable image is not free. Both formulations are sufficient, neither is established.
For 90A let \(E\) be the upward-closed set of \((t,s)\) jointly achieved by ONE fixed uniform deterministic total SAT decider, using \(N^{t+o(1)}\) time and counted writable/index workspace \(N^{s+o(1)}\) in FLMV's indexed read-only-input random-access Turing-machine model. \[
t<c_\star=\frac{241}{200},\qquad
s<\beta(c_\star)=\frac{11642479}{23232400},\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).

The proposed but OPEN successor \((t,s)\mapsto(\max\{11/10,3/5+t/2\},\max\{1/2,s/2\})\) has fixed point \((6/5,1/2)\). Finite-entry arithmetic does not construct the machine. The old purported universal \(t+s<2\cos(\pi/7)\) endpoint is FALSIFIED/RETIRED.

\section{Primary theorem and indexed bit access}
FLMV's 2005 paper, Sections 2.1 and 3.1, Theorem 3.1 and its proof, uses indexed read-only-input random-access Turing machines with counted writable/index tapes and erased index contents on indexed moves. For every \emph{fixed} \(L\in\NTIME[n]\), the proof constructs a uniform SAT reduction \(R_L(x)\) of length \(n\log^{O(1)}n\). An indexed output bit is generated in \(\log^{O(1)}n\) time and \(O(\log n)\) auxiliary workspace. Thus a SAT machine can be simulated \emph{without materializing} the full reduction, with multiplicative polylogarithmic time overhead and additive logarithmic workspace. Corollary 5.8 is
\[
\NTIME[n]\not\subseteq\DTISP[n^c,o(n^{\beta(c)})]
\quad(c>1).
\]
The reduction family and decoder are fixed once the nondeterministic input language is fixed; no nonuniform per-length program selection is permitted.
\section{A fixed, fine-grained complete image}
Ordinary SAT, including malformed-input rejection, has a nondeterministic \(N\log^{O(1)}N\)-time verifier under the standard encoded-input model. Fix a large \emph{constant} padding exponent \(d\). Let \(\operatorname{pad}(F)\) be a self-delimiting encoding of the arbitrary ordinary SAT bitstring \(F\), followed by enough checkable zero padding that \(|\operatorname{pad}(F)|=N\log^{O(1)}N\) dominates the verifier time. Define \(L_{\mathrm{pad}}\) to accept \emph{exactly} padded strings whose represented \(F\) is a YES SAT instance. Checking the padding and running the nondeterministic verifier takes time linear in the padded length. Therefore \(L_{\mathrm{pad}}\in\NTIME[n]\). Each requested padding bit can be generated in \(\log^{O(1)}N\) time and \(O(\log N)\) workspace using the original indexed read-only \(F\).
Choose once and for all the \emph{uniform} reduction \(R_{\mathrm{pad}}\) supplied by the cited FLMV proof for this one language. Put
\[
Q(F)=R_{\mathrm{pad}}(\operatorname{pad}(F)),\qquad
\mathcal H_\circ=\{Q(F):F\in\{0,1\}^{*}\}.
\]
The reduction is defined for \emph{every} source bitstring, including malformed SAT encodings; NO is preserved. The output \(Q(F)\) is a valid ordinary SAT formula, the output length is at most \(N\log^{O(1)}N=N^{1+o(1)}\), and an addressed bit is generated in \(\log^{O(1)}N\) time with \(O(\log N)\) extra writable/index storage. Output length can be obtained from the fixed tableau template. Both SAT and UNSAT images occur.
\begin{theorem}[Fixed-image quantitative promise transfer]\label{th:transfer}
Let \(B\) be ONE fixed uniform deterministic total machine. Assume for \emph{every} \(y\in\mathcal H_\circ\), the very same \(B\) satisfies
\[
B(y)=\SAT(y),\quad
T_B(y)\le |y|^{t+o(1)},\quad
S_B(y)\le |y|^{s+o(1)}
\]
jointly in the FLMV indexed model, for constants \(t\ge1,s\ge0\). Behavior and bounds \emph{outside} \(\mathcal H_\circ\) need not solve SAT. Then a fixed uniform total exact ordinary-SAT decider \(D_B\) exists on ALL bitstrings \(F\) with
\[
T_{D_B}(N)\le N^{t+o(1)},\qquad
S_{D_B}(N)\le N^{s+o(1)}
\]
simultaneously in the same model. Consequently, the image-promise achievable set \(E_\circ\) and ordinary all-input set \(E\) are identical at polynomial-exponent precision for \(t\ge1,s\ge0\).
\end{theorem}
\begin{proof}
Simulate \(B\) on the virtual input \(Q(F)\). Every \emph{actual} attempted source read by \(B\) is answered by the fixed on-demand reduction accessor and the padded-source bit accessor, both using the original read-only \(F\), a paid address/index tape and \(O(\log N)\) additional counted workspace. FLMV Theorem 3.1 gives multiplicative \(\log^{O(1)}N\) time cost for this type of indexed simulation and additive \(O(\log N)\) counted space; no write-only output is used as a free child input. Including a harmless \(O(N\log^{O(1)}N)\) source-check/initialization allowance, the same machine obeys
\[
T_{D_B}(N)\le (T_B(|Q(F)|)+N)\log^{O(1)}N=N^{t+o(1)},\quad
S_{D_B}(N)\le S_B(|Q(F)|)+O(\log N)=N^{s+o(1)}.
\]
Since \(Q(F)\in\mathcal H_\circ\) for \emph{every} \(F\), we have \(D_B(F)=B(Q(F))=\SAT(Q(F))=\SAT(F)\), even when \(F\) is malformed (then both sides are NO). Fixed \(B,Q\) give one uniform total decider, and all source/index/live workspace costs are charged. This proves \(E_\circ\subseteq E\). The reverse inclusion follows by restricting any ordinary exact SAT decider to \(\mathcal H_\circ\).
\end{proof}
\begin{theorem}[One-image FLMV forbidden box]\label{th:box}
No \(B\) in Theorem~\ref{th:transfer} has simultaneous exponents \(t<241/200\) and \(s<11642479/23232400\).
\end{theorem}
\begin{proof}
Theorem~\ref{th:transfer} yields an all-input ordinary-SAT machine with those exponents. Choose \(c\) with \(t<c<241/200\). Since \(\beta\) is strictly decreasing on \(c>0\), we have \(s<\beta(241/200)<\beta(c)\); the composed space is \(o(N^{\beta(c)})\), contradicting FLMV's Theorem 3.1 and Corollary 5.8.
\end{proof}
This is a \textbf{derived corollary}, not a new separation. Restricting \emph{coverage} to this image may help exploit tableau structure, but the chosen fixed image is itself fine-grained complete, so it does not weaken the achievable-exponent endpoint.

\section{Two actual descendant levels: a precise promise counterexample}
Let \(\mathcal H_{\mathrm{guard}}\) consist of ordinary CNFs whose first two clauses are distinct tautological guards \((z\vee\neg z)\) and \((w\vee\neg w)\), with otherwise unused guard names, and whose remaining clauses form Horn CNF \(G\). This family has both SAT and UNSAT inputs. A total uniform program \(B_{\mathrm{guard}}\) checks the promise grammar and runs the polynomial-time Horn algorithm on the tail if promised; off promise it simply outputs SAT. Thus \(B_{\mathrm{guard}}\) is correct on every \(\mathcal H_{\mathrm{guard}}\) source.
Define \(F_0=(z\vee\neg z)\wedge(w\vee\neg w)\wedge G\), \(F_1=(w\vee\neg w)\wedge G\), \(F_2=G\). Each of the TWO actual ordinary-CNF child transformations preserves both SAT and UNSAT truth. Yet \(F_1,F_2\notin\mathcal H_{\mathrm{guard}}\). Taking \(G=(x)\wedge(\neg x)\), the promised root \(F_0\) is UNSAT and correctly rejected, while calls \(B_{\mathrm{guard}}(F_1)\) and \(B_{\mathrm{guard}}(F_2)\) incorrectly return SAT. Exact child semantics alone is insufficient; \emph{promise eligibility is an independent typed proof obligation}. This counterexample does not assert any property of actual FLMV tableaux.
\textbf{COMPUTATIONAL audit:} All 128 subsets of seven fixed Horn clauses on two variables were tested against independent truth-table enumeration, with 56 SAT, 72 UNSAT, 642 assertions and no discrepancies. Both guard removals retained correct actual labels but left the promise. A naive off-promise call falsely returned SAT for all 72 UNSAT cases after either level. The finite test explicitly serializes 40,960 first-child bits and 30,720 second-child bits in aggregate. Python counts are \emph{not} FLMV Turing-machine primitive work or space measurements.
