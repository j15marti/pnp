\begin{theorem}[No-reprobe multi-index cache]
Fix $m\ge2$, $1\le t\le m$ and a label $b$. For each source $F_{\pi,b}$ allow an arbitrary deterministic preprocessor to inspect the complete read-only source and retain at most $s$ source-dependent bits, including any advice embedded in generated code. A subsequent fixed deterministic decoder with no original-source access, receiving only the retained source-dependent state and fixed named queries $x_1,\ldots,x_t$, must return exact original-clause indices $\pi^{-1}(1),\ldots,\pi^{-1}(t)$ for all $\pi$. Then
\[
\boxed{s\ge\left\lceil\log_2\frac{m!}{(m-t)!}\right\rceil.}
\]
In particular $t=m$ requires $\lceil\log_2m!\rceil=\Omega(N_m)$ persistent bits, so an $N_m^{1/2+o(1)}$-bit no-reprobe cache cannot implement this interface.
\end{theorem}
\begin{proof}
Every partial injection $(j_1,\ldots,j_t)$ from the $t$ distinct named variables to the $m$ clause positions is realized by a permutation; there are $m!/(m-t)!$ such transcripts. With no new source input, a deterministic query transcript is a function of the retained cache. Hence different required transcripts need different cached states and $2^s\ge m!/(m-t)!$. Stirling's elementary factorial bounds imply $\log_2m!=m\log_2m-O(m)=\Theta(N_m)$. The same proof holds for either SAT label.
\end{proof}
