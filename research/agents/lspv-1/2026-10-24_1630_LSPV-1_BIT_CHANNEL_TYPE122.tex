\section{Exact theorem and proof}
Fix a deterministic machine with read-only input. Encode each complete instantaneous configuration in disjoint coordinate sets: work-memory bits, head positions, address/index state, finite control and any other mutable state. Let $U$ count all charged bit events, including unchanged writes, and $W_{\rm work}$ count one-bit writes to work-memory cells only. Let $\Delta_j$ sum actual Hamming changes in coordinate set $j$ along a run.
\begin{theorem}[Typed-resource correction, PROVED/EXACT]
\[
\boxed{\Delta_{\rm work}\le W_{\rm work}\le U,\quad
\Delta_{\rm total}=\Delta_{\rm work}+\Delta_{\rm head}
+\Delta_{\rm addr}+\Delta_{\rm ctrl}+\Delta_{\rm other}.}
\]
If each event flips at most one bit, $\Delta_{\rm total}\le U$; more generally it is bounded by the sum of per-event flip caps. No finite-valued function $g$ bounds $\Delta_{\rm total}\le g(W_{\rm work})$ over arbitrary-length read-only finite-control scanners.
\end{theorem}
\begin{proof}
A work bit changes only on a write that changes its value, and Hamming distances add over disjoint coordinates. A scanner that advances a source head through $q$ positions and stores parity only in finite control has $W_{\rm work}=0$, but each distinct head position changes its complete configuration, so $\Delta_{\rm total}\ge q$. Since $q$ is arbitrarily large, no finite $g(0)$ exists. Counting head/control transitions as work writes would redefine $W_{\rm work}$ rather than repair the claim.
\end{proof}
This falsifies the displayed $\Delta_{\rm total}\le W_{\rm work}$ in BIT-LEDGER-CEILING120 when its left side includes head/control/address flips and its right side excludes their mutation. The independent global Hamming-Lipschitz diameter theorem in that report is unaffected. FLIPGAUGE-ARC121's autonomous nonstuttering result is unaffected.
\section{Proper-3CNF paired-label control}
For $q\ge1$ and $b\in\{0,1\}^q$, force $z_0=z_q=0$ and impose $z_i=z_{i-1}\oplus b_i$ using two binary clauses per link. Split $(a\vee c)$ into $(a\vee c\vee h)\wedge(a\vee c\vee\neg h)$ with a fresh $h$. Encode each endpoint unit $L$ with four proper ternaries over $L$ and two fresh helpers. The resulting proper 3CNF has
\[
n=3q+5,\quad m=4q+8,\quad
\operatorname{SAT}(F_b)\iff\bigoplus_{i=1}^q b_i=0.
\]
The helpers can be eliminated existentially, proving equivalence. All records for fixed $q$ have the same identifiers and length; only source literal signs differ.
A uniform read-only finite-control promise scanner extracts these orientation signs from fixed clause slots, tracks parity, and decides both SAT and UNSAT promised members with zero work-memory writes. Complete head-state flips grow at least linearly with the number of sign positions traversed. This is not a total all-input SAT decider; validation and fallback may not be dropped.
\section{Finite audit and adaptive-state ledger}
