\section{Exact sparse-exception theorem}
\begin{definition}[uniform surgical mutability]
An execution predicate \(P(A,x)\) is surgically mutable at
\(z_k=F_{0^k}\) if for every uniform polynomial-time decider \(A\) there is a
uniform polynomial-time wrapper \(W[A]\) satisfying
\[
 W[A](x)=A(x)\quad\hbox{for all }x,                       \tag{3}
\]
while on \(D_k\) the required property fails exactly at \(z_k\). The wrapper
recognizes \(z_k\) in \(O(N_k)\), calls \(A\), and makes the declared trace
mutation without changing the answer bit.
\end{definition}

Marker, named-copy, delay, and named-extraction predicates often admit this
mutation. An extensional or total-cost invariant need not.

\begin{theorem}[\texttt{UNIFORM-DENSITY-SPARSE-EXCEPTION1}]
If \(P\) is uniformly surgically mutable, then for every uniform polynomial
decider \(A\), the equivalent \(W[A]\) has
\[
 V_k=\{x\in D_k:P(W[A],x)\text{ fails}\}=\{z_k\}.         \tag{4}
\]
For uniform \(U_k\) on \(D_k\),
\[
 \Pr_{x\sim U_k}[x\in V_k]=2^{-k}
   =2^{-\Theta(N_k/\log N_k)}.                            \tag{5}
\]
An auditor using \(q(N_k)\) independent samples detects the violation with
probability
\[
 1-(1-2^{-k})^{q(N_k)}\le q(N_k)2^{-k}.                  \tag{6}
\]
For every fixed \(d\), this tends to zero when \(q(N)=N^d\).
\end{theorem}

\begin{proof}
Equation (4) is the mutation hypothesis and (2) gives (5). The miss
probability is \((1-2^{-k})^q\), and the union bound gives (6). Since
\(N_k=\Theta(k\log k)\), every fixed power of \(N_k\) is \(2^{o(k)}\).
Recognition costs \(O(N_k)\), simulation keeps \(T_A\), and the mutation is
charged, so the wrapper stays uniform polynomial whenever \(A\) is.
\end{proof}

The exact scope is
\[
\forall A\in\mathsf{PolyDec}:
 \operatorname{SurgMut}(P,A)\Rightarrow
 \exists W[A]\ \forall k\quad \mu_{U_k}(V_k)=2^{-k}.       \tag{7}
\]
There is no claim that every useful property is surgically mutable. A targeted
sampler that outputs the recognizable \(z_k\) detects the exception
immediately, and white-box source inspection is outside the theorem.
Accordingly the full density-or-direct target remains \OPEN.

\section{Falsified inference and smallest repair}
The theorem falsifies only
\[
 \text{one violation per large layer}
 \Longrightarrow
 \text{polynomial uniform sampling finds it}.             \tag{8}
\]
It does not falsify a construction-specific distribution or targeted
extractor. The smallest repair must simultaneously:
\begin{enumerate}
\item prove mutation invariance for one precisely defined property;
\item fix an efficiently samplable distribution and prove inverse-polynomial
violation mass for every arbitrary decider on the same executions; and
\item transfer detection to a model-matched whole-execution lower bound while
charging sampling, source access, simulation, replay, reconstruction, and the
one-bit output.
\end{enumerate}
No current report proves these obligations.

\section{Literature and barrier-transfer preflight}
Goldreich--Goldwasser--Ron property testing is a
\textbf{DIRECTLY TRANSFERABLE THEOREM} only for a specified representation,
distance, and proximity parameter~\cite{GGR98}; it does not make an
exponentially sparse exception uniformly visible. Current work explicitly
separates query complexity from computational time~\cite{GGR25}, so even a
tester theorem is not itself a SAT time lower bound.

Finite-state conformance testing with a bounded extra-state fault domain is a
\textbf{USEFUL STRUCTURAL ANALOGY REQUIRING A NEW TRANSFER THEOREM}~\cite{VAB24}.
SYNTHESIS-0026 shows that no fixed finite/polynomial intensional cap contains
every polynomial-time equivalent ordinary program.

Circuit, branching-program, proof-system, communication, VLSI, and FLMV-style
time--space results are \textbf{FAILED TRANSFERS} without a compiler placing
the same execution in the restricted model. The theorem relativizes and
algebrizes and gives no Natural-Proofs escape. Baker--Gill--Solovay and
Aaronson--Wigderson remain barriers, not premises~\cite{BGS75,AW09}.
