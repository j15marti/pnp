\begin{theorem}[Source-readable FLMV-hard image; elementary derivation]
There is a fixed canonical encoding choice for which:
\begin{enumerate}
\item $\SAT(\widehat R(x))=L^\dagger(x)$ on BOTH source labels;
\item $|\widehat R(x)|=n\log^{O(1)}n$ and every addressed
output bit can be produced in $\log^{O(1)}n$ time and
$O(\log n)$ additional counted writable/index space;
\item on the image promise, a fixed uniform indexed extractor
given $(\widehat R(x),i)$ returns the source bit $x_i$ with
$\log^{O(1)}|\widehat R(x)|$ time and $O(\log|\widehat R(x)|)$
writable/index space per requested bit;
\item a single fixed uniform total machine correct on
EVERY image member cannot have simultaneous upper exponents
$t<c_\star$ and $s<d_\star$ in the FLMV machine model.
\end{enumerate}
The source extractor does not need to recognize arbitrary off-image
strings, and it does not by itself solve SAT.
\end{theorem}
\begin{proof}
All added clauses have fresh variables, with independently selectable
satisfying assignments, and the old Cook variables are injectively
renamed. Thus the SAT and UNSAT bits are preserved exactly.
There are $O(n)$ extra constant-width clauses whose names are
$O(n)$; their encoded length is $O(n\log n)$.
The original tableau layout has a polynomially bounded
variable-index range and an indexed canonical output map.
Fixed-record packing, padding, and the known variable offset
change only polylogarithmic-bit record/address arithmetic.
An output-bit generator computes tag coordinates from one source
bit and computes renamed Cook coordinates via the original FLMV
local generator. Every read, shifted name, address and emitted
bit is paid; no fully materialized formula is assumed.
On a promised image, the first signed marker index determines
$n$ and fixed record positions. Inspect the sign of the first
literal in tag clause $i$ to obtain $x_i$. These operations have
the asserted charged polylogarithmic bounds.

Suppose, to the contrary, that uniform $B$ were correct on all
$y\in\widehat{\mathcal H}$ with joint exponents $t<c_\star$,
$s<d_\star$. Given any original $x$, one fixed simulator feeds
$B$ the virtual input $\widehat R(x)$ and on every requested guest
input position computes the encoded bit by the preceding local
reduction. The simulation is deterministic and total on every $x$,
preserves the correct source label, and incurs simultaneous bounds
$n^{t+o(1)}$ and $n^{s+o(1)}+O(\log n)$ after paid
probe/address arithmetic. The strict exponent gaps place it in
$\DTISP[n^{c_\star},o(n^{d_\star})]$, contradicting the
selected FLMV-hard source language.
\end{proof}

\section{Two genuine tagged recursive levels, but no exponent shrink}
Let $C(0)$ be the conjunction of seven out of the eight possible
signed proper ternary clauses on a private triple, and $C(1)$
all eight clauses. Then $C(0)$ is satisfiable and $C(1)$ is
unsatisfiable. With disjoint triple names let
\[
 F(z)=\bigwedge_{i=1}^{p} C(z_i),\quad
 \SAT(F(z))=\bigwedge_i [z_i=0],\quad
 H(z)=\operatorname{Tag}(F(z),z).
\]
Here $\operatorname{Tag}$ is the source marker construction above,
now applied to an EASY independent-component core, not to
$L^\dagger$. The source-only split $z=uv$ has an exact typed
ordinary-input join on BOTH labels,
\[
 \SAT(H(z))=\SAT(H(u))\land\SAT(H(v)).
\]
Every child is a genuinely serialized ordinary-CNF input in
the same declared easy tagged promise. Repeat the halving once more
for two actual ordinary-CNF recursive levels. On $p=4$, all
16 parents and all 32 children and 64 grandchildren were checked
independently with DPLL, including SAT and UNSAT cases.

The apparent size decrease of roughly one-half is only
multiplicative: $|H(z)|=\Theta(p\log p)$ and the half
has $\Theta((p/2)\log p)=\Theta(|H(z)|)$ bits.
Hence asymptotic exponent $\lambda=1$, not the ARC-required
$\lambda<1$. The easy family has a direct linear scan/solution,
so this exact composition is not FLMV-hard.
