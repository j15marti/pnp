\section{Definitions and exact matched machine model}
Let $E$ be the upward-closed set of simultaneous pairs $(t,s)$ achieved by one fixed uniform deterministic total exact ordinary-SAT decider on every standard SAT input of bit length $N$, with time $N^{t+o(1)}$ and writable/index space $N^{s+o(1)}$ in the indexed-read-only-input random-access Turing-machine model of FLMV~\cite{FLMV}. The indexed input is never an uncharged second tape; simulation pays every address, read, output bit, workspace bit and index-tape erasure. Let $E_{\mathcal H}$ denote corresponding pairs for a fixed uniform machine that halts and is correct on every string in the specified image $\mathcal H$, with no promise about its other inputs. In general $E_{\mathcal H}\not\subseteq E$: a merely FLMV-hard language $L^\dagger$ need not be a known fine-grained near-linear complete source.

Fix a standard ordinary SAT encoding, including the convention that malformed formulas are NO instances. A nondeterministic verifier $V$ can decide SAT on an $N$-bit input in $N\log^{q}N$ steps, for some constant $q$, by guessing an assignment and checking all indexed literal occurrences with fully charged word/bit addressing. Define one fixed \emph{clocked padded-verifier language} $L_V$: a nondeterministic linear-time machine on an arbitrary self-delimited input $y$ extracts a candidate formula prefix and simulates $V$ for at most a constant fraction of $|y|$ clock ticks, rejecting malformed encodings. This defines a language in $\NTIME[n]$ on ALL $y$; membership outside the intended padding syntax is simply determined by the same fixed clocked machine. The source padding $P(F)$ places a self-delimited $F$ inside a locally indexable string of length $|F|\log^{q+O(1)}|F|$, with enough additional ticks for $V$ to finish. Therefore
\[
 F\in\SAT\quad\Longleftrightarrow\quad P(F)\in L_V,
 \qquad |P(F)|=|F|^{1+o(1)}.
\]
Padding does not use a SAT oracle or decide $F$. It consists of a header, unchanged formula bits and fixed filler; every addressed padding bit is computed in polylog time and $O(\log |F|)$ writable/index space. All constants and the verifier machine are fixed independently of input size and of the hypothetical polynomial SAT solver.

FLMV Theorem 3.1 and its Section 3.1 proof provide a fixed reduction $R_{L_V}$ into the paper's ordinary SAT target encoding. For every $y$, $R_{L_V}(y)\in\SAT\Longleftrightarrow y\in L_V$, its output length is $|y|\log^{O(1)}|y|$, and each indexed output bit can be regenerated in $\log^{O(1)}|y|$ counted time using $O(\log |y|)$ extra writable/index space and addressed source bits. Define
\[
 J(F)=R_{L_V}(P(F)),\qquad
 \mathcal H_{\rm loc}=\{J(F):F\text{ is an ordinary encoded string}\}.
\]
This fixes one locally complete \emph{image family}, distinct from the arbitrary hard image $\mathcal H^\dagger$ selected in ARC-SINGLE-HARD-IMAGE161. Any grammar conversion between FLMV's target SAT encoding and a different CNF encoding must be separately proved and charged; none is silently assumed here.

\begin{theorem}[Locally complete image and joint-exponent equivalence]\label{th:equiv}
The fixed uniform map $J$ has exact both-label semantics, output length $M(N)=N^{1+o(1)}$, and an $N^{o(1)}$ per-bit accessor using $O(\log N)$ extra counted writable/index space. For the declared matched SAT encoding,
\[
 \boxed{E_{\mathcal H_{\rm loc}}=E.}
\]
In particular, a correct same-machine pair $(t,s)$ on all $\mathcal H_{\rm loc}$ outputs, even if the solver fails or diverges off-image, can be transported to an all-ordinary-input decider with the SAME exponent pair, up to $o(1)$ losses.
\end{theorem}
\begin{proof}
For every ordinary input $F$, $J(F)\in\mathcal H_{\rm loc}$ and $F\in\SAT\iff J(F)\in\SAT$ by composition. Simulate a promised decider $B$ on its logical indexed read-only input $J(F)$ without writing $J(F)$ to counted tape. On every input-bit probe, invoke the fixed composed output-bit accessor. The original FLMV proof (Section 3.1) shows how to perform this inside the indexed random-access machine with multiplicative polylogarithmic time and additive $O(\log N)$ writable/index space overhead; all relevant index writes/erasures, arithmetic and extra source-bit probes are counted. Since $|J(F)|=N^{1+o(1)}$, the simulator $D$ is total and correct for every $F$, with
\[
 T_D(N)\le N^{t+o(1)},\qquad S_D(N)\le N^{s+o(1)}+O(\log N)=N^{s+o(1)}.
\]
The same $D$ witnesses both exponents. Thus $E_{\mathcal H_{\rm loc}}\subseteq E$; restricting any global SAT decider to $\mathcal H_{\rm loc}$ gives the reverse containment. In particular this is an exponent-scale equivalence, not a claim of identical hidden polylogarithmic factors or a fast recognizer for the image.\end{proof}

\begin{lemma}[Two-level recursive promise re-entry, conditional on a contractor]\label{lem:reentry}
Suppose a fixed uniform, exact parent SAT procedure produces ordinary children $G_i$ with a source-bit accessor. A child may be outside $\mathcal H_{\rm loc}$. Replace every call $B(G_i)$, where $B$ is guaranteed only on $\mathcal H_{\rm loc}$, by $B(J(G_i))$. Then every call lies in the promised domain and preserves both SAT and UNSAT truth. The replacement is legal for any fixed number of real recursive levels. If $|G_i|\le N^{\lambda+o(1)}$, then $|J(G_i)|\le N^{\lambda+o(1)}$. If one addressed bit of $G_i$ costs $N^{g+o(1)}$ time and uses $N^{\eta+o(1)}$ extra counted space, an addressed bit of $J(G_i)$ costs $N^{g+o(1)}$ time and uses $N^{\eta+o(1)}+O(\log N)$ space. The parent must retain its simultaneous live source, work, index, buffers and ancestors.
\end{lemma}
\begin{proof}
The equality $\SAT(G_i)=\SAT(J(G_i))$ gives semantic correctness independently for YES and NO. Each output bit of $J$ requests at most $\log^{O(1)}|G_i|$ ordinary source-bit operations, so composing the two fixed accessors multiplies time by a polylog and requires logarithmically many new index/address bits on top of the original transducer state. At the next recursive level apply the same construction, obtaining another polylogarithmic factor; any FIXED finite nesting has total $N^{o(1)}$ overhead. No child membership test is necessary because the algorithm itself generates the promised form. There is no free guest oracle and all actual queries are charged.\end{proof}

For a parent making $N^{a+o(1)}$ sequential calls, the known conditional eager ledger, with $g$ interpreted as per-materialized-bit access cost, remains
\[
 t'\le\max\{r,a+\lambda+g,a+\lambda t\},\quad
 s'\le\max\{\lambda,\lambda s,\eta,\kappa\}.
\]
A fully virtual, repeatedly decoded implementation has
\[
 t'\le\max\{r,a+\lambda t+g\},\quad
 s'\le\max\{\lambda s,\eta,\kappa\},
\]
with logarithmic accessor workspace suppressed only at exponent scale. The formulas must be interpreted consistently: the normalization does NOT reduce $a,\lambda,r,\eta$ or $\kappa$ and does not excuse policy discovery, failed routes, source name compatibility, SAT/UNSAT gluing or near-parent-scale fallback.

\section{Reproducible two-real-level hostile test}
For the finite auditor, a toy locally indexed CNF wrapper appends a forced-true and a forced-false fresh variable, preserving every original clause and original identifier. Headers encode variable and clause counts in 16 bits, while each clause has three fixed-width signed literal slots. Its $J_{\rm toy}$ accessor computes each output bit directly from the source header and one original clause record. This is a finite illustration, NOT FLMV's Cook reduction and not an unbounded encoding theorem.

The promise solver $B_{\rm toy}$ decides guarded image inputs by exhaustive truth tables but deliberately returns SAT for all inputs failing the guard. Restrict the first fresh forced-true guard. The child remains SAT-equivalent but is off-image; $B_{\rm toy}$ is wrong for UNSAT sources. Apply $J_{\rm toy}$ to re-enter the image and obtain the correct answer. Repeat the actual restriction on the newly wrapped child and re-enter a second time. Original variable names are unchanged; fresh guard identifiers and headers are serialized and charged.

The bounded Python 3 standard-library auditor exhaustively checked all $2^{10}=1024$ subsets of ten declared unit/binary clauses on three variables, comprising 317 SAT and 707 UNSAT cores. It performed 118,784 addressed-output-bit comparisons to explicit serialization, 9,217 structural/semantic assertions, 2,048 repaired calls, and 1,024 genuine two-level descendants with no failed assertion. All first and second descendants were off-image; the intentionally off-image-guarantee-free solver returned a wrong SAT bit for all 707 UNSAT first descendants. One explicit UNSAT control contains $(x_1)$ and $(\neg x_1)$; its six successive encoded bit lengths were 50,80,68,92,80,122. Run:
