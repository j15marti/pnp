\section{Exact gadget, physical source and authenticated proof grammar}
Let $W_1$ be the public 15-variable, 20-clause proper signed exact-$(2,2)$ unsatisfiable source in the project original \path{experiments/review/early22_compiler_redteam_audit.py}. A module $H(a,b)$ reverses two opposite-sign source occurrences in the Alice group when $a=0$ and two opposite-sign occurrences in the Bob group when $b=0$. The four truth-table counts, independently reproduced here, are
\[
\#\mathrm{Mod}(H(0,0))=772,\quad
\#\mathrm{Mod}(H(0,1))=272,\quad
\#\mathrm{Mod}(H(1,0))=272,\quad
\#\mathrm{Mod}(H(1,1))=0.\tag{1}
\]
All four preserve proper signed exact-$(2,2)$ degree, and $H(1,1)=W_1$. Form $F_m(a,b)$ by $m$ variable-disjoint copies, ordered with all $2m$ Alice clauses, then $16m$ fixed clauses, then $2m$ Bob clauses. Thus
\[
\SAT(F_m(a,b))\iff \bigwedge_{i=1}^m \neg(a_i\wedge b_i),\qquad
N_m=\Theta(m\log(m+2)),\quad G_m=\Theta(N_m).\tag{2}
\]
The physical checker uses a canonical \emph{dense-identifier} binary literal layout: a short width/header record with declared $1\le n\le 3m\le3N$ and $n,m\le N$ followed by each three-literal clause, three $(\mathrm{sign},\mathrm{identifier})$ bit fields and an explicit record delimiter. The original \emph{record-start byte offsets} are authenticated against this actual source, not trusted as declarations from the certificate. This is one specified ordinary three-CNF encoding; a compiler from a different encoding must be charged.

A certificate is $\pi=(v_1,\ldots,v_{15}; o_1,\ldots,o_{20})$, where the $v_i$ are 15 pairwise different physical source variable numbers and each $o_j$ is a different record-start source offset. There is a \emph{fixed} template $W_1=(C_1,\ldots,C_{20})$. The verifier checks the entire source syntax and whether the clause physically starting at $o_j$ is exactly $C_j$ with the injective variable renaming $x_i\mapsto x_{v_i}$, for all 20 records. It accepts the UNSAT \emph{certificate} only if every test succeeds; malformed proof/source always fails.

\begin{theorem}[Globally sound local contradiction grammar]\label{th:global}
For all canonically encoded ordinary proper ternary formulas $F$, all strings $\pi$, and any source length $N$,
\[
 V(F,\pi)=1\quad\Longrightarrow\quad F\notin\SAT.\tag{3}
\]
For every $m\ge1$ and every $a,b\in\{0,1\}^m$ with $a\wedge b\ne0$, there is a certificate $\pi_{a,b}$ satisfying $V(F_m(a,b),\pi_{a,b})=1$ and
\[
 |\pi_{a,b}|\le 35\lceil\log_2(N_m+1)\rceil+O(1).\tag{4}
\]
There is one fixed deterministic verifier with \emph{one sequential read-only input head} and a fixed number of work tapes which, with the 35 fields of $\pi$ available in workspace (or guessed and stored once), checks the entire canonical physical source in $N\operatorname{polylog}(N+2)$ bit-time and $O(\log(N+2))$ visited work cells. This is a checker, not a polynomial-time UNSAT proof constructor for all inputs.
\end{theorem}
\begin{proof}
If $V$ accepts, the source includes all twenty clauses of an injectively renamed copy of $W_1$. A renamed $W_1$ is UNSAT by (1); adding any other clauses cannot make it SAT. This proves (3) even for completely unrelated extra clauses and regardless of any exact-$(2,2)$ property of the parent. For $F_m(a,b)$ with $a_i=b_i=1$, select the 15 variables of its $i$th module and the 20 authentic source record offsets of that module. Those records equal $W_1$, proving (4).

For the verifier, store the constant 35 binary fields, each of length $O(\log N)$, along with a 20-bit checked-record mask and $O(\log N)$ counters. First scan the input once to measure its total physical length $N$ and rewind, at $O(\log N)$ counter space. Reject any header with $n>3m$ or $n,m>N$, so that every subsequent identifier, offset, and header integer uses $O(\log N)$ bits. On the second scan, parse the self-delimiting header and each clause record, validate every literal's range and three distinct names, and compare the current offset with the constant-sized pointer table. At a pointed record, calculate the corresponding three renamed literals from the stored name table, compare all sign and identifier bits, and set the mask bit only on exact agreement. At end-of-input accept iff exactly the declared number of records was parsed and all 20 bits are set. No source, child, oracle answer, or proof body is silently read for free. A fixed-$k$ sequential work-tape implementation of $O(\log N)$-bit field arithmetic and comparisons costs $\operatorname{polylog}N$ steps per source bit, establishing the stated time and space bounds. Explicit physical output is the single decision bit.\end{proof}

\begin{corollary}[Promise coNTIME polarity versus deterministic YES hardness]\label{cor:polarity}
There exists one uniform co-nondeterministic algorithm for the \emph{promise} $\{F_m(a,b)\}$, on the declared one-input-head fixed-$k$ tape model, with one uniform length-dependent clock, time $N^{1+o(1)}$ and visited work space $N^{o(1)}$: nondeterministically choose $i$ and the $35$ certificate fields, run $V$, and \emph{reject} exactly when $V=1$. All branches accept on SAT promise inputs; at least one branch rejects on UNSAT promise inputs. This is \emph{not} an ordinary-SAT coNTIME decider because an arbitrary UNSAT formula need not contain $W_1$.

On the same promise, the UTM--CROSS--WRITE1 fixed-universal \emph{deterministic} common-YES portfolio inequality for at most $2^{b+1}$ sound programs is
\[
2^m\le2^{b+1}G_m(2q)^{\lfloor T/G_m\rfloor+1};\tag{5}
\]
for $b=O(\log N)$ this forces some common YES input to require $T=\Omega(N^2/\log N)$ if it is accepted by every eligible program under the displayed uniform ceiling. Equation (5) and the co-nondeterministic promise upper bound do not conflict: \emph{polarity, nondeterminism and physical tape interface differ}. In particular no deterministic SAT/UNSAT machine in the FLMV forbidden box is constructed.
\end{corollary}
\begin{proof}
Soundness of $V$ gives the SAT universal-branch condition; the presence of an $H(1,1)$ copy on each UNSAT promise source gives the existential rejecting branch. Guessing 35 length-$O(\log N)$ fields, syntax-checking and scanning take the theorem's uniform bounds. Inequality (5) is retained from the governance crossing-history theorem under its \emph{fixed-universal, one shared writable-tape, fixed finite control, same-program splice} assumptions. Its conclusion applies to YES acceptance of a deterministic portfolio, not to the guessed rejecting branch of this different co-nondeterministic machine.\end{proof}
