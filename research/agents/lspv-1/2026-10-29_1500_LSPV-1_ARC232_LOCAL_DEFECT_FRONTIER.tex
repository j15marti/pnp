\section{Mathematical model and a common resource ledger}
Let $F$ be a physically encoded Boolean CSP of bit length $N$, given as original source-ID tagged unary/binary clauses and affine equations. A tree $\mathcal T$ with $k\le\operatorname{poly}(N)$ nodes has bags $V_t$ and once-only owned source constraints $C_t$. Every constraint scope belongs to its owner's bag, every variable's bag-occurrence set is connected in $\mathcal T$, and every original source is owned exactly once. The entire purported structure, sources, signs, ranks, edge order, and running intersection are independently verified. Its discovery or transmission costs $D(N)$ bit operations and polynomially many bits; without a polynomial discoverer the theorem concerns inputs \emph{with a verified decomposition}.

Root at $r$. For $t\ne r$, let $S_t=V_t\cap V_{p(t)}$ and $s_t=|S_t|$, with $S_r=\varnothing$. Let $R_t\subseteq\{0,1\}^{S_t}$ be the exact subtree extension relation. A child $u$ is \emph{good} when $R_u$ has an independently checked exact 2CNF presentation; otherwise it is \emph{bad}. Set
\[
 U_t=\bigcup_{u\text{ bad child of }t} S_u,\qquad
 W_t=S_t\cup U_t,\qquad w_t=|W_t|=s_t+|U_t\setminus S_t|,\tag{1}
\]
and denote by $b_t=|V_t\cap\bigcup_{v\ne t}V_v|$ its \emph{full} shared interface. One always has $s_t\le w_t\le b_t$, but $b_t$ can be arbitrarily larger than $w_t$. Let $e_t$ be the coefficient rank of the original affine equations owned by $t$, which is bounded by a fixed $e_0$. Inconsistent local rows are detected exactly. Define $M_t$ as the entire physically encoded local instance after adding all compiled \emph{good} child messages, plus pins, not merely its original source-clause count. All message bytes and source offsets are charged.

For a fixed native model $\mathcal M$, let $T_{\mathcal M}(I)$ be the \emph{same-run} total time and $S_{\mathcal M}(I)$ its peak simultaneously live footprint, including certificate/access/discovery/failed tries. Define $t_{\mathcal M}=\log_N(\max\{2,T_{\mathcal M}\})$ and $s_{\mathcal M}=\log_N(\max\{2,S_{\mathcal M}\})$. Report pointwise pairs $(t,s)$; independently attained max-time and max-space need not occur on the same input. The term ``frontier'' below refers to attainable \emph{algorithmic upper-bound envelopes} or explicitly labelled architectural proxies, never an unrestricted algorithm lower boundary.
\section{Main theorem and exact proof}
\begin{lemma}[Source-complete gluing]
For each child $u$ of $t$, the only names shared by the subtree rooted at $u$ and its complement occur in $S_u$. Thus a parent-local assignment extends to all child subtrees iff its restriction to each $S_u$ lies in $R_u$.
\end{lemma}
\begin{proof}
Every tree path from the child subtree to a module outside it crosses the edge $up(u)$. Running intersection forces a variable present on both sides to occur in both endpoint bags. After fixing the parent bag, the private variables of distinct child subtrees are disjoint, and once-only source ownership ensures there are no missing cross-subtree constraints. Hence independently chosen compatible extensions glue.
\end{proof}
\begin{lemma}[Exact relation test and affine-rank stability]
For an explicit relation $R\subseteq\{0,1\}^s$, enumerate every unary/binary clause valid on all tuples of $R$, and check that their conjunction accepts precisely $R$. This decides exact 2CNF definability in $2^{O(s)}\operatorname{poly}(s)$ operations and outputs an equivalent 2CNF if it exists. Restricting any coordinates by unary \emph{2CNF pins} cannot increase the coefficient rank $e$ of the separately stored affine equations.
\end{lemma}
\begin{proof}
There are $O(s^2)$ possible unary/binary signed clauses, and at most $2^s$ tuples. Comparing all tuples with the valid-clause conjunction proves equality or provides an explicit counterexample. For the second claim, original affine rows are unchanged because pins remain in the CNF; if pins are substituted into affine equations instead, deleting fixed columns cannot increase row rank. A locally inconsistent affine system is rejected immediately.
\end{proof}
\begin{theorem}[Adaptive non-bijunctive defect composition, restricted]\label{th:hybrid}
On any verified module tree described above, one deterministic source-authenticated algorithm returns SAT/UNSAT and reconstructs an original SAT witness, using
\[
 T_{\rm bit}(F) \le D(N)+\operatorname{poly}(N)\sum_{t\in\mathcal T}
 \left(2^{w_t}\sum_{i=0}^{e_t}\binom{|V_t|}{i}
 +2^{s_t}\operatorname{poly}(s_t+1)\right),\tag{2}
\]
where each attempted local solver and all source/message reads, failed candidates, table joins, exact relation checks, and witness storage are included in the polynomial. The explicit stored data satisfies the conservative bound
\[
 S_{\rm bit}(F) \le \operatorname{poly}(N)+
 O\left(\sum_t 2^{s_t}(|V_t|+s_t+1)\log(N+2)\right)\tag{3}
\]
for fixed $e_0$, including full stored witnesses for each successful parent-separator assignment. Thus if $D$ is polynomial, $k$ is polynomial, $e_t\le e_0$ for fixed $e_0$, and $\max_t w_t\le c\log_2 N$ for a fixed $c$, the decision and witness reconstruction run in polynomial time and space. The total number of global affine dependencies can be unbounded.
\end{theorem}
\begin{proof}
Process the verified tree bottom-up. By induction, each child's exact table $R_u$ is available. For good children, conjoin their \emph{equivalent} 2CNF presentations with the parent's original 2CNF. For bad children, retain their complete tables and include their full separator names in $U_t$. Iterate all $2^{w_t}$ assignments $a:W_t\to\{0,1\}$. Reject the assignment immediately if $a|_{S_u}\notin R_u$ for some bad child. Otherwise add unary CNF pins specifying $a$ and invoke the known deterministic fixed-codimension 2-SUB-SAT method on the parent's local 2CNF (including compiled good-child clauses) together with \emph{only its original affine rows}. The solver discovers and verifies a local witness or exhausts its polynomial-for-fixed-$e_t$ branches. Its affine rank remains at most $e_t$. A successful $a$ marks $a|_{S_t}$ feasible and stores the local witness plus child continuation pointers. By gluing, every marked parent tuple extends to a full valid subtree solution; conversely every subtree solution supplies an enumerated $a$ that the complete local decision accepts. Hence the computed table equals $R_t$, for SAT and UNSAT alike. Classify $R_t$ by exact 2CNF-table equality and continue. At the root, $R_r$ has either the empty tuple or is empty. Recursively glue the stored local witnesses, verify every original source once, and output the answer. The \emph{same uniform controller} handles both answer classes without a supplied label.

Every separator has $s_t\le w_t$. By the known Arvind--Guruswami result, a fixed affine rank $e_t$ gives at most a polynomial factor times $\sum_{i\le e_t}\binom{|V_t|}{i}$ local work; the complete physical $M_t$ and all compiled child constraints are included in $\operatorname{poly}(N)$. Each good table contains $2^{s_t}$ explicit slots and an $O(s_t^2)$-clause encoding. Stores for one successful local assignment per parent tuple require $O(2^{s_t}|V_t|\log N)$ bits. Failed solver paths are part of the total work; if a verifier wants complete NO transcripts it may replay the same polynomially bounded deterministic search without assuming a short resolution refutation. Equations (2) and (3) follow. For the final polynomial claim, $w_t=O(\log N)$ and fixed $e_0$ make every sum factor polynomial in $N$.
\end{proof}
\paragraph{Contract limitations.} The theorem is not an unrestricted reduction of strict exact-$(2,2)$ 3SAT: its input grammar is mixed 2CNF+affine with a verified module tree. It does not prove polynomial discovery of that tree, closure of arbitrary CNF under transformations, or a nontrivial SAT time lower bound. A third-party formula with a large bad-child union may be rejected as \texttt{UNKNOWN} by a budget-limited recognizer, not declared UNSAT.
\section{Two infinite families and a false shortcut}
\begin{proposition}[Unbounded non-bijunctive messages, locally bounded defect]
Let $X_0,\ldots,X_{k-1}$ be disjoint ternary variable groups. For each $i<k-1$, a module owns $\bigoplus X_i\oplus\bigoplus X_{i+1}=0$ and the terminal module owns $\bigoplus X_{k-1}=r$. Root unary clauses fix $X_0=(a,0,0)$. Bags are $X_i\cup X_{i+1}$ and the final $X_{k-1}$, with a path tree. Each local affine coefficient rank is one; each nonroot separator has three names; every nonroot exact message is ternary parity and \emph{not} 2CNF-definable. Nevertheless $w_t\le6$ at every node, the global affine rank is $k$, and the formula is SAT iff $a=r$. ARC229's all-bijunctive branch rejects every such nonroot message; theorem~\ref{th:hybrid} handles all $k$.
\end{proposition}
\begin{proof}
Induct from the leaf: $R_{k-1}(X_{k-1})$ fixes $\bigoplus X_{k-1}=r$. Each coupling equation forces the predecessor triple's parity to agree with its successor, so $R_i(X_i)$ is exactly parity $r$. Parity on three bits is not majority-closed (the majority of 001, 010, 100 is 000), hence not 2CNF-definable. The parent separator and one bad child separator involve six names; the leaves involve three. The equations have distinct leading groups and are linearly independent, giving global rank $k$. Root pins force the claimed SAT condition.
\end{proof}
\begin{proposition}[Unbounded full interface and increasing primal width]
Create a root module with $q$ disjoint shared variable pairs $(a_i,b_i)$ and one shared triple $z=(z_1,z_2,z_3)$. Each pair-child owns the binary clause $(a_i\lor b_i)$; the triple-child owns $z_1\oplus z_2\oplus z_3=r$. The root owns unary clauses $\neg z_i$, positive links joining the pairs to $z_1$, and a positive 2CNF clique on $a_1,\ldots,a_q$. All local affine ranks are at most one, $b_{root}=2q+3$, but $w_{root}=3$, and $\tw(F)\ge q-1$. It is SAT iff $r=0$. For all $q$, the hybrid algorithm uses only eight root assignments while full-interface enumeration has $2^{2q+3}$ root tuples.
\end{proposition}
\begin{proof}
Each pair-child relation is 2CNF and compiles exactly into its single clause. The triple-child sends ternary parity and is bad. Thus the root pins only $z$, not the $2q$ already-compiled pair coordinates. The original root units force $z=000$, which meets the parity iff $r=0$. Taking every $a_i=1$ satisfies all other source clauses. The root's binary clique gives a primal $K_q$, hence treewidth at least $q-1$. All source ownership and running intersections hold by construction.
\end{proof}
\noindent\textbf{FALSIFIED/RETIRED shortcut.} Replacing the odd-parity relation $R=\{001,010,100,111\}$ by its 2CNF hull produces the tautological relation (each unary or binary pattern occurs in $R$). A parent that pins $000$ would incorrectly accept if it dropped the actual table. Exact equality checking before 2CNF compilation is therefore indispensable.
\section{Static backdoor curve, crossings, and asymptotic slopes}
For the original connected strict signed exact-$(2,2)$ static-coverage hypothesis with fixed global $b>0$ and local clause hitting $q$, the \emph{necessary structural} inequality $n\le3b+12bq$ implies $q\ge\max\{0,n/(12b)-1/4\}$. It is not a SAT runtime lower bound. For the \emph{illustrative algorithmic enumeration proxy} $E_T=b+q$ and explicit-table proxy $E_S=b$, the relaxed nonzero branch has
\[
 E_T(b)=b+\frac{n}{12b}-\frac14,\quad
 E_T'(b)=1-\frac{n}{12b^2},\quad
 E_T''(b)=\frac{n}{6b^3}>0,\quad
 b_*=\sqrt{\frac n{12}},\quad E_T(b_*)=\sqrt{\frac n3}-\frac14.\tag{4}
\]
At fixed $n$, the proxy Pareto slope $dE_T/dE_S=1-n/(12b^2)$ is negative for $b<b_*$, zero at $b_*$, and positive after it. In the \emph{integer} relaxation $q_b=\lceil\max(0,n/(12b)-1/4)\rceil$, $n=1200$ has minimum $b+q_b=20$ at $b=9,10,11$. Of these tied points, $(E_T,E_S)=(20,9)$ dominates the other two \emph{as proxies}; no point's actual decomposition realizability is asserted. The first equality $E_T=E_S$ occurs at $q=0$, with earliest allowed integer $b=400$ and both exponents 400. At $b=10$, the relaxed derivative is zero; at $b=400$, the exponent equality does not imply equality of actual $T$ and $S$.

As $n\to\infty$ and $b=c\sqrt n$, the relaxed proxy exponent is $\sqrt n(c+1/(12c))-1/4$ with slope $1-1/(12c^2)$. Under canonical $N=\Theta(n\log n)$, its minimum is $\Theta(\sqrt{N/\log N})$, so $2^{E_T}$ is superpolynomial \emph{for this enumeration proxy}, not across all SAT algorithms. If measured $T=2^{E_T}N^a$ and explicit cached space $S=2^{E_S}N^d$, the model-native normalized coordinates are
\[
 t=a+\frac{E_T}{\log_2N},\qquad s=d+\frac{E_S}{\log_2N}.\tag{5}
\]
For $n=1200$, using $N=n\log_2n\approx12275$ as one scaling convention, $b=9$ gives additive exponents $1.4724$ in $t$ and $0.6626$ in $s$. Polynomial factors $a,d$, memory units, realizability and machine simulation are not captured by these proxy additions. Streaming verification of each complete boundary assignment can use polynomial working space instead of the explicit $2^b$ table, so $E_S=b$ is not a necessary decision-space bound.

\section{Simultaneous algorithmic upper-bound envelopes}
For a verified width-$h$ decomposition, conventional Boolean DP has \emph{attainable} upper bounds $T_W\le D_W+\operatorname{poly}(N)2^h$, $S_W\le\operatorname{poly}(N)2^h$ with full tables. For one affine+2CNF source of fixed coefficient rank $e$, the known algorithm yields $T_A\le\operatorname{poly}(N)\sum_{i\le e}\binom ni$ and polynomial space, even when the primal graph has large width. For the verified static backdoor modules, source-hitting sets can be discovered by $3^q\operatorname{poly}(N)$ search \emph{once the module partition and global boundary are supplied}; an actual enumerating controller admits $T_B\le D_B+\operatorname{poly}(N)(k3^q+2^bk2^q)$, but its \emph{streaming decision space} can be polynomial. ARC229 gives an upper bound when all exact edge messages are bijunctive. Theorem~\ref{th:hybrid} replaces its exponent $s_t$ by $w_t$ only at defective nodes. These are \emph{upper bounds for different certified source classes}, not one global lower tradeoff.

For a uniform adaptive controller trying methods $A_1,\ldots,A_m$, the actual winner index $j(I)$ yields
\[
 T_{\rm ctrl}(I)\le D_{\rm shared}(I)+\sum_{i\le j(I)}T_i^{\rm spent}(I)+T_{\rm joins}(I),\qquad
 S_{\rm ctrl}(I)\le S_{\rm shared}(I)+\max_{i\le j(I)}S_i^{\rm live}(I)+S_{\rm caches}(I),\tag{6}
\]
with failed attempts, strategy discovery, re-encoding, row/bit accesses, and reconstruction charged. There is no free pointwise $\min_i T_i$ oracle. The Pareto set consists only of nondominated \emph{realized same-run pairs} from algorithms applicable to the same source and one specified machine model; different bounds cannot be crossed to infer contradiction.

For the star family, root full-table exponent is $b=2q+3$ while the selective bad-edge exponent is $w=3$, a formal gap $2q$. The observed total fixed-$e$ calls scale linearly with children, with a polynomial-size rank-zero root 2CNF clique. In particular $q=40$ gives $b=83$, $w=3$, 172 local solver calls, and 169 separator table slots; those calls and slots are \emph{different resource units} and not measured TM steps. The root primal width is at least 39. \emph{This is a restricted constructive speedup over raw full-interface enumeration, not a proof of time lower bounds.}

\section{Model-native ledgers, tests, and barriers}
\noindent\textbf{RAM/bit model.} All source and module encodings, source-ID comparisons, physical table writes, GF(2) row operations, and local solver trials count; $T_{\rm bit},S_{\rm bit}$ in (2)--(3) are upper bounds for an implementable indexed algorithm with bit-level charges. No word-RAM constant-cost treatment of unbounded integers is assumed. \textbf{Two-tape or fixed-$k$ sequential-input TMs.} Simulating a polynomial bit algorithm is polynomial but requires explicitly charged head travel and work tapes; a safe generic deterministic multitape-to-one-tape simulation upper bound is $O(T_k^2)$ time and $O(N+T_k)$ footprint, not a same-exponent identity. \textbf{Single shared tape and two fully writable tapes.} Tape input counting, writes, head traffic and peak visited work cells have their native definitions, not RAM exponents. \textbf{Fixed UTM.} Keep one interpreter and program encoding, charge parsing/program evaluation and interpreter overhead polynomially. None of these \emph{upper-bound} simulations proves an unrestricted machine lower bound or a forbidden FLMV intersection.

\section{Next falsifiable lemma}
Determine whether an input-uniform polynomial-time algorithm can \emph{discover} and verify, without a supplied module tree, a bounded-defect decomposition on a new hereditary class of mixed sources whose primal treewidth grows and whose non-bijunctive messages occur at unboundedly many levels. Charge the discovery and update costs, and find an adversarial source on which the guessed decomposition fails. Do not postulate the desired decomposition for arbitrary strict22 or unrestricted SAT.
