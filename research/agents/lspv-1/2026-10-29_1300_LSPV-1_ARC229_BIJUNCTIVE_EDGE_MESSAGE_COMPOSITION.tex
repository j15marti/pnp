\section{The exact missing lemma and falsifiable mechanisms}
ARC228 proved exact source-authenticated composition for a tree of 2CNF-plus-affine modules, charging a full shared interface $B_t$ of size $b_t$ at every node.  LSPV-5's independently checked FULL-INTERFACE-GLUING-REFEREE204 exhibited an UNSAT star with $b_{\mathrm{center}}=2q$, every \emph{edge} width two and every local affine rank one, for which raw centre enumeration takes $4^q$ entries.  Gaussian elimination easily decides that particular star, so the example falsifies only replacing full-interface size by edge width in the \emph{raw-table} algorithm.  The missing question here is whether the exact child relations can be re-encoded as constraints in a tractable local language before combining them.

\begin{description}
\item[] \textbf{M1.} Every relation on at most two Boolean separator variables has an exact source-computable 2CNF encoding. \textbf{PROVED/EXACT.}
\item[] \textbf{M2.} Replacing each child table by its verified 2CNF encoding allows the fixed-codimension local solver to absorb arbitrarily many child messages without increasing the local affine rank. \textbf{PROVED/EXACT} under running intersection and exact ownership.
\item[] \textbf{M3.} Every width-three child relation is also 2CNF-definable. \textbf{FALSIFIED/RETIRED} by an exact ternary parity message.
\item[] \textbf{M4.} Every arbitrary strict exact-(2,2) 3CNF has a polynomially discoverable tree of this kind. \textbf{OPEN}; not hypothesized as a fact.
\end{description}

\section{Definitions and exact ownership contracts}
Let $I$ be a physically encoded instance of $N$ bits comprising a canonical original constraint multiset, distinct source IDs, and a claimed tree decomposition $T$ with $k\le\operatorname{poly}(N)$ modules.  A module $t$ has bag $V_t$ and an exact subset of source constraints $I_t$, each a unary/binary CNF clause or an affine equation over $\F$.  The verifier must ensure \emph{each original source constraint is owned exactly once}, every constraint scope is contained in its owner's bag, the edge graph is a tree, and for each variable $x$, the nodes $\{t:x\in V_t\}$ form a connected subtree (running intersection).  A source parser must verify full original IDs, signs, multiplicities, affine right-hand sides and scope; a claimed manifest is not an external oracle.  Let the local affine coefficient rank, i.e. affine codimension before adding any intermodule messages, be $e_t$.  Assume $e_t\le e_0$ for one fixed integer $e_0$; inconsistent local affine systems are recognized and yield empty tables.

Root $T$ at $r$, and for each nonroot node $t$, define its \emph{parent-edge separator} $S_t=V_t\cap V_{p(t)}$ and $s_t=|S_t|$.  In contrast, the \emph{full accumulated interface} is $B_t=V_t\cap\bigcup_{u\ne t}V_u$, whose size need not be bounded by $s_t$.  Let $R_t\subseteq\{0,1\}^{S_t}$ be the set of assignments extendible to all constraints owned by nodes in the rooted subtree of $t$.  The only semantic object passed upward is $R_t$.

\begin{lemma}[Exact decomposition gluing]\label{lem:gluing}
For a child $u$ of $t$, the only variables shared between the subtree of $u$ and its complement lie in $S_u$.  For any assignment $a$ to $V_t$, extension into all child subtrees exists iff $a|_{S_u}\in R_u$ for every child $u$.
\end{lemma}
\begin{proof}
The unique path in the tree from a module in the child subtree to any module outside it crosses edge $up(u)$.  The running-intersection property forces every variable occurring at both endpoints of this path into the two bags on that edge.  Conversely, each child subtree has disjoint private variables from every other child subtree after fixing the parent bag's coordinates.  Exact once-only source ownership leaves no unaccounted cross-subtree constraint.  Thus compatible extensions can be glued independently.
\end{proof}

\begin{lemma}[Every binary Boolean relation is 2CNF-definable]\label{lem:binary}
For $s\le2$, each relation $R\subseteq\{0,1\}^s$, including the empty relation, has an exact 2CNF presentation of at most $2^s$ clauses.  Given its complete table, the presentation can be constructed and verified in constant time for fixed $s$.
\end{lemma}
\begin{proof}
For every forbidden tuple $a\in\{0,1\}^s\setminus R$, add the width-$s$ clause $\bigvee_{i=1}^s(x_i\ne a_i)$.  That clause excludes precisely $a$ and accepts every other tuple.  For $s=0$, $R$ is either $\{()\}$ or empty, represented by true or the empty clause.  Conjunction over the forbidden tuples gives exactly $R$; all resulting clauses have width at most two.
\end{proof}

\begin{theorem}[Exact edge-message composition; restricted]\label{th:main}
Suppose the verified input above satisfies $e_t\le e_0$ for all nodes, and every nonroot edge separator has $s_t\le2$.  Then a single deterministic program decides SAT and UNSAT, reconstructs an original SAT witness, and provides a reproducible finite trace of exhaustive local checks in polynomial time and peak space \emph{even if} $\max_t|B_t|=\Omega(N^\alpha)$ for a positive $\alpha$.  The more general algorithm is correct and has the native indexed-RAM bit-time upper bound
\[
 D(N)+N^{O(1)}\sum_{t\in T}2^{s_t} (|V_t|+1)^{O(e_t)},\tag{1}
\]
provided $s_t=O(\log N)$ and every \emph{actually computed} exact message $R_t$ is independently verified to be 2CNF-definable.  $D(N)$ counts discovery and complete certificate validation.  If an encountered message is not 2CNF-definable, the program returns \texttt{UNKNOWN}; it never silently strengthens that relation.  The exponent implicit in $O(e_t)$ comes from the \emph{known} Arvind--Guruswami fixed-codimension method, not a uniform polynomial in growing $e_t$.
\end{theorem}
\begin{proof}
Process nodes bottom-up.  Assume inductively that the exact child relations have been compiled as CNF clauses of width at most two and checked against their original full separator tables.  At node $t$, form the conjunction of (i) $t$'s owned 2CNF, (ii) every \emph{compiled} child 2CNF message, interpreted on $V_t$, and (iii) $t$'s \emph{original} affine rows of rank $e_t$.  The whole non-affine part remains 2CNF no matter how many children are present.  For each of the $2^{s_t}$ assignments $\sigma$ to the parent edge $S_t$ (at the root, only the empty assignment), add $s_t$ unary 2CNF pins and invoke the deterministic 2-SUB-SAT solver.  The pins are \emph{not} appended as affine equations, so the affine rank remains at most $e_t$.  Record exactly those $\sigma$ for which a satisfying local model exists, together with a local model and child pointers.  By Lemma~\ref{lem:gluing} this is exactly $R_t$, not an approximation.  Check the complete truth table against the 2CNF comprised of all unary and binary clauses valid on $R_t$; accept the encoding only when the two finite relations coincide.  Lemma~\ref{lem:binary} guarantees this always succeeds for $s_t\le2$.  For $s_t=O(\log N)$, the table has polynomially many rows, so exact compilation and checking remain polynomial whenever a 2CNF representation exists.

At the root a feasible empty assignment means SAT.  Follow stored local models down the tree, maintaining equality on shared coordinates, and check the resulting assignment against \emph{every original source constraint}.  An empty root table means UNSAT because every enumerated separator assignment and every local solver call was exhaustive and the separator induction is exact.  A checker may replay the complete deterministic trace including every failed subcall; there is no uncharged oracle answer, nonuniform advice, or free class bit.

Charge the complete original input scan, decomposition recognition, source ownership and running-intersection verification to $D(N)$.  At node $t$ there are $2^{s_t}$ local calls.  Each handles at most a polynomial number of original and compiled child clauses, with coefficient rank $e_t$ and polynomially encoded assignments; known 2-SUB-SAT costs $N^{O(1)}(|V_t|+1)^{O(e_t)}$.  Table compilation enumerates $O(s_t^2)$ candidate unary/binary clauses and explicitly checks $2^{s_t}$ rows, within the stated polynomial factor.  Child-message access, failed plucking and SCC calls, stored source pointers, complete table encoding, witness backpointers, output, and the maximum simultaneous storage are covered by the same conservative polynomial envelope times $\sum_t2^{s_t} (|V_t|+1)^{O(e_t)}$.  With $e_t\le e_0$, $k\le\operatorname{poly}(N)$ and either $s_t\le2$ or $s_t\le c\log N$ with recognized bijunctivity, this bound is polynomial.  No claim is made that such a decomposition exists or is efficiently discoverable for arbitrary SAT.
\end{proof}

\section{Star countercontrol: avoiding the full-interface blowup}
For every $q\ge1$, form a $(q+1)$-module star.  Centre bag $V_0$ contains all pairs $x_i,y_i$ and owns one affine equation
\[
 \bigoplus_{i=1}^{q}(x_i\oplus y_i)=b.
\]
Leaf $i$ owns exactly $x_i\oplus y_i=0$ on $V_i=\{x_i,y_i\}$.  Every module's affine rank is one; each edge separator has exactly two variables; but the centre's full shared interface is $B_0=\{x_i,y_i:1\le i\le q\}$, so $|B_0|=2q$.  The system is SAT precisely when $b=0$.  Every leaf exact message is the binary equality relation, expressed by $2$CNF $(\neg x_i\lor y_i)\land(x_i\lor\neg y_i)$.  The centre then solves a single long XOR together with $q$ equality conditions by the \emph{known} fixed-codimension-$1$ algorithm.  Only $4q+1$ local separator calls are required, not $4^q$.  Omitting any one leaf equation makes the $b=1$ control satisfiable, showing the all-leaf join is semantically essential even though its bit cost can be polynomially compiled.

This proves a strict extension over ARC228's full-raw-interface \emph{sufficient} criterion: its cost bound remains valid for raw enumeration, but does not characterize optimal exact message representations.  The easy star does not imply arbitrary SAT is tractable.

\section{Exact failure at three shared variables}
A child with a single rank-one affine equation $x\oplus y\oplus z=1$ projects to
\[
 R=\{001,010,100,111\}.
\]
Its three satisfying tuples $001,010,100$ have coordinatewise majority $000\notin R$.  Every 2CNF solution relation is majority-closed; hence no 2CNF on $x,y,z$ represents this exact message.  A parent with three unary pins $\neg x,\neg y,\neg z$ makes the entire instance UNSAT.  The present bounded-language controller correctly reports \texttt{UNKNOWN\_NON\_BIJUNCTIVE} at the child, rather than losing that parity constraint.  A width-three child can nevertheless pass if its \emph{actual} table is 2CNF-definable, for example $x=0$ together with $x\oplus y\oplus z=1$, which reduces to a binary XOR relation.

\textbf{Native indexed RAM ledger.} Count parsing, discovery, source reads, every failed branch, GF(2) row reduction, SCC recomputation, child table access, 2CNF reconstruction and verification, all written tables, witness pointers, original source check and peak simultaneous storage in the theorem's polynomial envelope.  A literal source ID is not free indexed advice.  \textbf{Read-only-input fixed-$k$ multitape ledger.} Explicit polynomial simulations handle scanning, random-access emulation, storage and output without claiming preservation of RAM exponents.  \textbf{Single shared read/write tape ledger.} Input footprint and tape-head travel are included; ordinary polynomial-time simulation of the fixed algorithm gives a possibly higher polynomial bound, not a SAT lower bound.  \textbf{Two fully writable tapes.} Account for changes to both tapes, including marks on the input tape, separately.  \textbf{Fixed UTM ledger.} The interpreter is fixed and source parsing, program description, access and reconstruction are charged; this is an upper-bound simulation only. \section{Exact boundary and next lemma}
The proved claim concerns a \emph{verified} structural promise, not uniform discovery of the promise on all SAT inputs and not the strict signed exact-(2,2) grammar.  The algorithm's \texttt{UNKNOWN} status is permitted only outside the edge-width-two guaranteed class or when a larger exact message fails 2CNF recognition.  For unknown inputs, no answer-preserving shrinking child is asserted.  All-algorithm time/space lower bounds remain \textbf{OPEN}; decision-only summaries need not preserve arbitrary future contexts.  Both $P=NP$ and $P\ne NP$ remain \textbf{OPEN}.

\textbf{Next precise missing lemma:} Find a polynomial-time \emph{source-discoverable and verifiable} family of moving tree decompositions with unbounded full interfaces and logarithmic edge separators whose exact non-bijunctive child messages nevertheless admit a compact repeatably composable grammar (for example 2CNF plus $O(1)$ affine rows) with proof that the \emph{aggregate} affine rank at every parent stays bounded after all child joins; or exhibit a concrete small-width counterfamily that forces aggregate-rank growth in this richer grammar.  Do not confuse a compact local representation with a polynomial-time \emph{computed} representation.
