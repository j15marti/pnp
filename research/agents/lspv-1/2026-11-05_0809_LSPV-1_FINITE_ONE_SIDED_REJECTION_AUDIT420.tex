\section*{The theorem}
Fix a universal explicitly common-polynomial-clock program language in which running a program A on F costs at most a fixed polynomial in \(|A|+|F|\). Let the input to the following decision problem be \((A,1^L)\), with unary \(L\):
\[
\mathsf{SafeReject}_{\le L}(A)\iff\forall F,a:
\bigl(|F|\le L\land\mathrm{ValidCNF}(F)\land\mathrm{Eval}(F,a)\bigr)
\Longrightarrow A(F)\ne\mathrm{UNSAT}.
\]
A failed audit has a polynomial witness consisting of a correctly encoded source, assignment to its occurring coordinates, and a clocked erroneous UNSAT output, even when legal source headers use enormous sparse integer indices. Hence this indexed-program decision problem is in coNP.

\begin{theorem}
The indexed finite rejection-soundness problem is coNP-complete even if every possible false UNSAT response by the tested program is on an explicitly satisfiable proper 2-CNF source.
\end{theorem}
\begin{proof}
For an arbitrary 3-CNF \(G\) on \(n\ge1\) variables, let \(z=x_{n+1}\). For each \(w\in\{0,1\}^n\), encode the distinct, non-tautological width-two clauses
\[
S_w=\bigwedge_{i=1}^n(z\lor\ell_i(w_i)),\qquad
\ell_i(1)=x_i,\quad\ell_i(0)=\neg x_i.
\]
All such sources are SAT by \(z=1\), and have one canonical signed-DIMACS encoded length \(L_n=O(n\log(n+2))\). A program \(A_G\) with \(G\) in its program description rejects exactly those sources \(S_w\) for which \(\mathrm{Eval}(G,w)=1\), returning SAT on all other valid sources and INVALID on malformed encodings. The program has a common polynomial clock in program and source lengths. Consequently
\[
\mathsf{SafeReject}_{\le L_n}(A_G)\iff G\in\mathrm{UNSAT}.
\]
This is a polynomial many-one reduction from coNP-complete 3UNSAT; coNP membership was established above.
\end{proof}

\begin{theorem}[Conditional UNSAT-complete promise]
If one fixed correct total polynomial-time SAT decider \(D\) exists, replace \(A_G\)'s behavior off the sentinel family by \(D(F)\), obtaining \(B_G\). Every \(B_G\) rejects \emph{all} genuine UNSAT sources, yet
\(\mathsf{SafeReject}_{\le L_n}(B_G)\iff G\in\mathrm{UNSAT}\).
\end{theorem}
\begin{proof}
All sentinels are SAT, so all UNSAT sources use the correct \(D\); a false rejection occurs exactly on a sentinel associated with a satisfying assignment to \(G\).
\end{proof}
\noindent\textbf{Quantifier firewall.} If SAT is in P, then coNP equals P; thus no superpolynomial checking-time consequence is claimed in that hypothetical world. The code \emph{varies} with \(G\), whereas B3 can exploit one specially chosen correct decider. The correctness of \(D\) is not formalized by this theorem. This result neither refutes B3 nor supplies polynomial native certificates.
