\section{Canonical target and exact obstruction}
The sole hardness language is D\"ocker's established NP-complete duplicate-free proper Monotone 3-SAT-(2,2): each source clause contains three distinct literals of one polarity, every variable has exactly two occurrences of each sign, and source clauses are unique. All malformed strings must be rejected. The larger nonmonotone proper strict-2P2N grammar is a comparison superset, not a substitute hardness target. Original clause IDs, the signed $x_{i,j}$ occurrences, and coherent original-variable pins are immutable source identities.
This result extends the published SATURATED-CYCLE-AFFINE-TERMINAL1 disjoint affine theorem from saturated budget $\delta=0$ to every nonnegative integer $\delta$, using explicitly enumerated and paid nonzero defect tickets. The precise obstruction is that odd literal-truth parity by itself is not the same as exactly one true literal, and odd cycles require nonzero overfull edges.
\section{Exact signed conservation}
For any valid $F$ and coherent pinned source assignment $p$, let $X$ be the $f$ free variables, $U$ the $u$ original clauses not already satisfied by a pinned literal, and reject immediately when an uncovered clause has no free literal. Among the covered original clauses, free variable $x$ has $s_x^+$ positive and $s_x^-$ negative occurrences. Put
\[
e=2f-u,\quad \eta=\sum_{x\in X}\min(s_x^+,s_x^-),\quad w_x=|s_x^+-s_x^-|,
\quad b_x=\begin{cases}0&s_x^+>s_x^-\\1&s_x^->s_x^+\\ *&w_x=0.\end{cases}
\]
For every satisfying original-source completion $a$, writing $t_j(a)$ for the number of TRUE free literals in uncovered clause $C_j$,
\begin{equation}\label{eq:conservation}
e-\eta=\sum_{j\in U}(t_j(a)-1)+\sum_{x:w_x>0}w_x\mathbf 1[a_x\ne b_x].
\end{equation}
Indeed every free source variable has exactly two true literal occurrences across its four signed occurrences, and its TRUE occurrences in covered original clauses contribute $\min(s_x^+,s_x^-)$ plus exactly $w_x$ if it takes the nonpreferred value. Every displayed term is nonnegative for an actual SAT extension.
Let $\mathcal C=(E_1,\ldots,E_\nu)$ be any \emph{actually acquired} family of edge-disjoint simple odd cycles among the residual two-literal clauses, with original-source clause edge IDs distinct and lengths $\ell_i=|E_i|$. In every SAT completion some edge of each $E_i$ has two true literals, since otherwise all its edges enforce $x\oplus y=1$ and an odd cycle would be 2-colored. Therefore
\[
\delta=e-\eta-\nu<0\implies\mathrm{UNSAT}(F\mid p).
\]
Cycles may share variable vertices, but not original source clause edges; proof and acquisition are charged.
\begin{theorem}[All nonnegative residual defects: exact disjoint affine union]\label{thm:union}
For every valid canonical source $F$, coherent $p$ without an original falsified clause, and authenticated edge-disjoint odd binary-cycle family $\mathcal C$, when $\delta\ge0$, the entire set of SAT completions of $p$ is a \emph{pairwise disjoint union} of exactly defined GF$(2)$ affine-system solution sets $\mathcal A_\sigma$. Each branch uses only equations on the original free variables, with signed source-clause and ticket provenance. Consequently
\[
\#\mathrm{SAT}(F\mid p)=\sum_{\sigma:\mathcal A_\sigma\ne\varnothing}2^{f-\operatorname{rank}(M_\sigma)}.
\]
A single consistent system, followed by checking the complete original-source witness, proves SAT. Exhaustion of every branch with an original-source replayable row-XOR contradiction proves UNSAT. If $q=O(N)$ is the number of defect-ticket sites, the number of affine systems is at most
\[
B\le\left(\prod_{i=1}^\nu\ell_i\right)
\sum_{k=0}^{\min(\delta,q)}\binom qk4^k
=\left(\prod_i\ell_i\right)N^{O(\delta)}.
\]
For polynomially acquired greedy triangles ($\ell_i=3$), this yields a fully enumerated \emph{word-algorithmic} bound $O(3^\nu N^{O(\delta)}\mathrm{poly}(N))$, not a uniform polynomial bound for unbounded $(\delta,\nu)$ and not a native FLMV time-space assertion.
\end{theorem}
\begin{proof}
For each certified cycle $E_i$, select the lowest original clause ID $b_i$ whose two literals are TRUE in the proposed completion. Force its two true literal values by GF$(2)$ unary equations. Every earlier edge in that cycle has exactly one TRUE literal and is encoded by $x\oplus y=1$. Each later edge either has exactly one TRUE literal (the same XOR equation, cost zero) or has two TRUE literals (two unary equations, a cost-one \emph{extra} edge ticket). Distinct original clause-ID edges prevent duplicated cycle charges.
For each uncovered clause \emph{outside} all cycles, the default cost-zero row says the XOR of its residual literal-truth values is one. For width two this means exactly one TRUE literal; for width one it fixes the literal TRUE; for width three it allows either one or three TRUE literals. The optional nonzero tickets for a width-two clause force both TRUE, cost one. For width three, choose one of three false-literal positions and fix the other two TRUE, cost one, or force all three TRUE, cost two. These are all unary GF$(2)$ rows. For each $w_x>0$, the default row fixes $a_x=b_x$, while a ticket of cost $w_x$ fixes $a_x=1-b_x$. Free variables with $w_x=0$ get no preference row. Every row has an original clause or source-variable provenance record.
Construct an affine system for every lowest-ID cycle-edge choice and every compatible ticket assignment of \emph{total additional cost exactly $\delta$}. Every solution of such a system satisfies every original clause: odd residual parity implies at least one TRUE literal, explicit overfull tickets force at least two TRUE literals, cycle edges are satisfied, and already-covered clauses remain true. By (\ref{eq:conservation}) and the $\nu$ distinct obligatory base edges, there is exactly $\delta$ total nonbaseline excess in every SAT completion. The chosen tickets already consume all $\delta$, so a default ternary clause \emph{cannot} quietly have three TRUE literals, nor can an unmarked binary edge be doubly TRUE. This establishes the exact ticket interpretation even though default ternary constraints were only affine parity rows.
Conversely, take any full satisfying completion. Each cycle has a uniquely determined earliest doubly TRUE original clause edge. Mark the later doubly TRUE cycle edges, the unique true-count pattern of every outside uncovered clause, and each weighted preference mismatch. The source conservation identity forces their nonbaseline costs to sum to exactly $\delta$. This produces one and only one branch containing that completion. Thus the union covers all and is disjoint. Every consistent affine system has $2^{f-r}$ extensions at rank $r$, and each inconsistent system yields an XOR row combination $0=1$. Finally, there are at most $\delta$ positive-cost ticket sites out of $q$ and at most four nondefault options per site, establishing the claimed finite enumeration bound.
\end{proof}
