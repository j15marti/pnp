\section{Exact source and restricted architecture}
For $F\in\mathcal C_{\mathrm{M22}}$, every clause contains exactly three distinct source variables and has one polarity, clauses are unique, and every active name occurs exactly twice positively and twice negatively. $\bar C$ reverses signs but retains OR; $\mathcal C_\star$ excludes \emph{only} fully complemented clause-paired instances, not partially paired or disconnected formulas. Set $k=n(F)$, $m=4k/3$, $N=\Theta(k\log(k+2))$ for a dense indexed ordinary clause-list. Each name occurs in precisely four source clauses.

A \emph{raw pin-and-copy descendant} assigns a set $Q$ of distinct source names, deletes a clause if satisfied by a pin, removes any false pinned literals from touched clauses, and retains verbatim, up to injective renumbering, all clauses disjoint from $Q$. Resulting clauses may be shorter or empty; the ordinary-CNF child need not itself belong to M22. This restricted architecture \emph{does not} include propagation cascades, derivation of new relations, adaptive learned constraints, symbolic factorization, cache merging, source recognition or direct terminal answers. It is not a model of every possible SAT solver.

\begin{theorem}[Exact occurrence floor and power-short necessary cost]
For every $F\in\mathcal C_{\mathrm{M22}}$, every pin set $Q$ of $q$ distinct source names, and every Boolean assignment to $Q$, the corresponding explicitly serialized raw pin-and-copy child retains at least
\[
u(F,Q)\ge m-4q=\frac{4k}{3}-4q
\]
original untouched three-literal clauses. If $q=O(\log N)$, every such child's fully indexed dense ordinary representation has length $\Theta(N)$. Conversely, if a child has full encoded length $O(N^\lambda)$ for any fixed $\lambda<1$, then necessarily
\[
q\ge\frac{k}{3}-O(N^\lambda)=\frac{k}{3}-o(k).
\]
\end{theorem}
\begin{proof}
Only clauses incident to some variable of $Q$ can change. Since every original name occurs in four clauses, at most $4q$ distinct clauses are touched. Thus at least $m-4q$ untouched clauses survive identically, independent of pinned values. For $q=O(\log N)$, the surviving count is $\Theta(k)$. Their union contains at least $3u/4=\Theta(k)$ distinct unpinned names because an unpinned original name occurs at most four times. Even after arbitrary dense injective renumbering, each of $\Theta(k)$ intact clause-name fields requires $\Omega(\log k)$ bits, giving $\Omega(k\log k)=\Omega(N)$ encoded bits. A direct ordinary serialization of a raw descendant has $O(m)$ clauses and $O(k)$ names, giving $O(N)$ bits. Conversely, each intact clause uses at least one encoded bit, so $u=O(N^\lambda)$ if the entire child is $O(N^\lambda)$; therefore $m-4q=O(N^\lambda)$. Since $N^\lambda=o(k)$ for every fixed $\lambda<1$, the stated necessary bound follows.
\end{proof}

\begin{corollary}[Two or any fixed number of genuine levels]
Consider a complete independent binary pin tree of fixed depth $d$ where each root-to-leaf path assigns $q$ distinct original names, enumerating all $2^q$ settings and explicitly forming all resulting raw residual leaves. If its total independent leaf count $B=2^q\le N^{a+o(1)}$ for a constant $a$, then $q=O(\log N)$ and \emph{every} leaf has $N^{1+o(1)}$ encoded bits, i.e. its size exponent is $\lambda=1$, not any fixed $\lambda<1$. Conversely, if all leaves must be $O(N^\lambda)$ for fixed $\lambda<1$, then
\[
B\ge 2^{k/3-o(k)}=N^{\omega(1)}.
\]
\end{corollary}
\begin{proof}
The complete independent assignment tree has precisely $2^q$ represented leaves, so polynomial leaf count implies $q\le(a+o(1))\log_2N$. Theorem 1 applies to the accumulated distinct source pins after every actual level, even if original names are locally renumbered. For the converse, each leaf's encoded length forces $q\ge k/3-o(k)$ and full enumeration forces $2^q$ different represented assignments. These are logical branch counts, not lower bounds on executed steps of a merging or early-exit algorithm.
\end{proof}

\section{ARC resource ledger and boundary of the inference}
For a full independent enumeration with $B=N^{a+o(1)}$ and pin-only children of $\Theta(N)$ bits, $\lambda=1$. An \emph{eager} implementation that writes all $B$ complete child bitstrings has at least $\Omega(BN)$ output-bit writes, in addition to source reads, indexing, controls, clause renumbering, branch generation and gluing. Materializing one entire child on counted writable tapes consumes $\Omega(N)$ peak cells in the FLMV model. A \emph{virtual} indexed child need not allocate this buffer, but each addressed child bit must be generated at charged cost and the child remains a logical length-$\Theta(N)$ oracle input. This result is an architecture-specific output cost, \emph{not} an arbitrary algorithm lower bound.

For a real $N^a$-child solver-dependent constructor with $N^\lambda$-bit children, local work exponent $r$, per-bit generation $g$, generator workspace $\eta$ and live ancestors $\kappa$, the standard \emph{conditional} eager envelope is
\[
t'\le\max\{r,a+\lambda+g,a+\lambda t\},\quad
s'\le\max\{\lambda,\lambda s,\eta,\kappa\},
\]
while a fully lazy per-probe implementation has
\[
t'\le\max\{r,a+\lambda t+g\},\quad
s'\le\max\{\lambda s,\eta,\kappa\}.
\]
These are upper envelopes conditional on a genuine implementation and exact parent SAT/UNSAT semantics, not compulsory costs for every possible decider. Charge changed and unchanged writes, reads, address bits, control, selector discovery/switches, failed branches, source re-reads, query headers, caches, compatibility joins, ancestors, buffers and same-machine peak storage. Temporal physical flips, gates/wires and cumulative bit-time are distinct metrics. Merely inserting $\lambda=1/2$ into such envelopes without a real all-input contractor is invalid.
