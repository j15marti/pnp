\section{One model, one machine: zero observed proof bits}
Fix a uniform total deterministic indexed read-only-source verifier $V(F,\pi)$, with every source $F$ a well-formed ordinary CNF of physical length $N$. Its immutable binary proof has a publicly fixed polynomial-bounded length $L(N)$ and no source-dependent endmarker, length advice or uncharged clock channel. All proof-bit indices, input positions, child locations, caches, source parsing, work/index cells, resets, failed attempts, and final bit are charged. Its simultaneous worst-case indexed bit-time and workspace ceilings are $T_V(N)$ and $S_V(N)$ on \emph{all} sources and proofs. Let $Q(F,\pi)$ count distinct queried physical proof bits. Assume
\begin{align}
 \forall F\in\SAT\;\forall\pi\in\{0,1\}^{L(N)} &: V(F,\pi)=0,\tag{1}\\
 \forall F\in\UNSAT\;\exists\pi\in\{0,1\}^{L(N)} &: V(F,\pi)=1\ \wedge\ Q(F,\pi)=0.\tag{2}
\end{align}

\begin{theorem}[Zero-observation equivalence for all ordinary inputs]\label{th:zero}
Under (1)--(2), $D(F)=1-V(F,0^{L(N)})$ is a single uniform total deterministic ordinary-SAT decider on the same indexed source model with $T_D\le T_V\operatorname{polylog}(N+T_V+2)$ and $S_D\le S_V\operatorname{polylog}(N+T_V+2)+O(\log N)$. In a direct implementation, the fixed-zero proof reply costs no polynomial exponent and its address generation remains charged. Conversely, any deterministic total SAT decider $A$ in this model defines the globally sound, all-UNSAT-complete $V_A(F,\pi)=1-A(F)$ that ignores $\pi$ and has $Q\equiv0$, with the same time and workspace polynomial exponents. Accordingly, the \emph{existence} of a polynomial-time zero-observation system for all ordinary UNSAT is equivalent to $P=NP$, not a certificate-derived speedup.
\end{theorem}
\begin{proof}
If $F$ is UNSAT, choose the accepting $\pi$ from (2). Until it halts, this deterministic computation has read \emph{zero proof bits}. Replacing its proof by the fixed all-zero string cannot alter any previous observable state, source probe, or transition, so $V(F,0^{L(N)})$ also accepts and $D$ rejects. If $F$ is SAT, (1) rejects \emph{every} fixed proof, in particular the all-zero one, so $D$ accepts. The publicly fixed zero proof need not be physically materialized: every requested proof bit can be supplied as zero, while each address computation and guest transition remains charged. No second machine's favorable space bound is borrowed. For the converse, execute the stipulated total $A$ on the original source and complement its answer. This verifier performs no proof read and has exactly the same source/work/resource burden apart from constant output logic.
\end{proof}

\begin{proposition}[Arbitrary-exponent fixed point under $P=NP$]\label{pr:K}
If $P=NP$, let one existing deterministic ordinary-SAT indexed machine have unknown finite simultaneous bounds $T_A=N^{K_0+o(1)}$, $S_A=N^{s_0+o(1)}$. For each fixed integer $K\ge K_0$, a padded correct solver $A_K$ exists with time $O(N^{K+o(1)})$ and work $N^{\max(0,s_0)+o(1)}$; the verifier $V_{A_K}(F,\pi)=1-A_K(F)$ has $q=0$. Applying first-read enumeration to $V_{A_K}$ recovers exponent $K$, without a strict successor. This does not rule out eliminating deliberately wasted steps by inspecting algorithm code; it rules out deducing arbitrary-$K$ contraction from zero proof-bit observation alone.
\end{proposition}
\begin{proof}
Execute the original solver, then use a charged $O(\log N)$-bit nested loop to perform $N^K$ dummy transitions (or an equivalent clocked delay), retain the result and output it. All paths, SAT and UNSAT, terminate with the correct bit; proof-bit count remains zero. Enumeration over $2^0$ possible proof replies is exactly one call to this solver and cannot on that basis yield a new smaller exponent.
\end{proof}

\section{Signed exact-(2,2) W1 construction and exact probe matching}
The original immutable $W_1$ of LSPV-2 has 15 variables, 20 distinct clauses with three distinct variables per clause, and two positive/two negative appearances per variable. Paired opposite-sign switches $A=\{(6,0),(11,0)\}$ and $B=\{(17,2),(9,2)\}$ produce the four source modes $H(a,b)$ with exact model counts
\[
 (\#H(0,0),\#H(0,1),\#H(1,0),\#H(1,1))=(772,272,272,0).\tag{3}
\]
The indexes are zero-based source clause/literal slots and the clauses are the exact 20 W1 rows in the committed reproducer. For $m$ disjoint renamed modules, let
\[
 F_m(y)=\bigwedge_{i<m}H(y_i,1),\quad
 \SAT(F_m(y))\iff y=0^m,\quad
 \UNSAT(F_m(y))\iff\bigvee_{i<m}y_i=1.\tag{4}
\]
The canonical fixed-width signed clause layout places each of the $2m$ A clauses first, the $16m$ fixed clauses next and the $2m$ B clauses last. Every source occurrence is an actual signed binary variable identifier, $N=\Theta(m\log(m+2))$, and the 20 original physical row offsets for a given module index are computable by $O(\operatorname{polylog}N)$ indexed bit operations.

\begin{proposition}[Authentic local proof and matching deterministic source-probe floor]\label{pr:w1}
There is a uniform indexed verifier taking one fixed $\lceil\log_2m\rceil$-bit candidate index $i$ and accepting exactly when the \emph{20 actual source clauses} belonging to that module equal the known UNSAT source $H(1,1)$. It uses $O(\operatorname{polylog}N)$ bit time and $O(\log N)$ indexed work on the promised source image. Even on other \emph{well-formed} CNFs, acceptance is SAT-sound because the authenticated subset itself is UNSAT; the claimed completeness is only for this canonical image, not all ordinary UNSAT. Every deterministic indexed bit-probe decider correct on the entire canonical family must read at least $m$ distinct A-controlled source signs on $F_m(0^m)$. This is tight by a direct $m$-probe scan, and $m=\Theta(2^q)$ for $q=\lceil\log_2m\rceil$, so the first-read bit enumeration cost can be necessary in the \emph{source-probe} metric on an easy restricted promise.
\end{proposition}
\begin{proof}
By (3), all $H(y_i,1)$ with $y_i=0$ are SAT and $H(1,1)$ is UNSAT. A proof index selects the 20 original rows; reject out-of-range indices and compare all three signed literals of each row. The claimed authenticator checks physically present source clauses, not an untrusted boundary row or an assumed SAT oracle. Any formula containing this contradictory subset is UNSAT, irrespective of other clauses, establishing soundness. The fixed layout makes each clause-bit locator arithmetically explicit and charged.

For the lower bound, run a deterministic source-bit-probe promise decider on the SAT source $F_m(0^m)$. If for some module $i$ it has read neither of the two A-controlled sign bits, toggle both. This transforms the formula into $F_m(e_i)$ without changing any inspected source bit. The two sign flips preserve the signed exact-(2,2) quotas because they are opposite occurrences of one variable in different source clauses. Determinism forces the identical full observed transcript and output on both inputs, yet by (4) one is SAT and the other UNSAT. Contradiction. Therefore at least one distinct sensitive sign from every module must be inspected, so at least $m$ indexed bit probes are necessary on the all-zero SAT source. An elementary comparator reads one A sign per module and meets this bound. Since $2^{q-1}<m\le2^q$, the factor $2^q$ is optimal up to two in this \emph{particular probe interface}. It does not imply a lower bound of $2^qT_V$ on arbitrary shared-work algorithms, and the promise is easy on a random-access machine.
\end{proof}

\section{Adaptive children, three native ledgers, and barrier audit}
For a genuine two-level source-authenticated ARC compiler with child lengths $m_i$, a guest exponent $d$, a source visit-volume cap $\sum_i m_i\le N^b$, and maximum child size $M\le N^\lambda$,
\[
 \sum_i m_i^d\le M^{d-1}\sum_i m_i\le N^{b+\lambda(d-1)}.\tag{5}
\]
This is a charged \emph{upper} recurrence only after all discovery, failed branches, selector computation, input-source parsing, actual child/proof access, parent semantic verification, full output, and hereditary peak space are included. The zero-bit verifier of Proposition~\ref{pr:K} calls the full original solver at length $N$; it has $\lambda=1$ rather than the missing strict noncircular contraction.
