\begin{abstract}
We test the natural repair to the wrapper obstruction: replace a faithful
resource majorant over every equivalent implementation by the pointwise
minimum cost among all exact deciders.  The repair is implementation
invariant but vacuous.  For every decidable language (L), including SAT
unconditionally, the length-(N) pointwise optimum is at most linear time
and constant work space.  A different exact machine can hardwire the complete
truth table on each selected length into exponential finite control and use
any fixed total decider elsewhere.  This proves
\texttt{POINTWISE-OPTIMUM-NONUNIFORMITY1} and retires
\texttt{POINTWISE-LOWER-ENVELOPE-AS-UNIVERSAL-RESOURCE1}.  It does not give
one uniformly selected polynomial-time SAT decider.  The missing quantifier
is exactly the uniformity required by \(P=NP\).  P versus NP remains OPEN.
\end{abstract}

\section{Result card and exact target}

\paragraph{Active clean core.}
Let \(\mathcal H^{\pm}_{2,2}\) be the duplicate-free proper signed
Monotone \(3\)SAT-\((2,2)\) family from the current root synthesis, under the
canonical self-delimiting indexed encoding of bit length \(N\).  Every
variable occurs twice positively and twice negatively, hence \(3m=4n\).
NP-completeness of the family is a \KNOWN; the incidence equality is
\PROVED.  No claim below depends on special algebraic structure of this
family, because the no-go theorem applies to every decidable language.

For a deterministic total exact decider \(A\), write
\[
 \tau_A(N)=\max_{|x|=N}T_A(x),\qquad
 \sigma_A(N)=\max_{|x|=N}S_A(x),
\]
in a standard read-only-input, finite-control multitape model.  The candidate
semantic lower envelopes are
\[
 \underline T_L(N)=\inf_{A\in\Dec(L)}\tau_A(N),\qquad
 \underline S_L(N)=\inf_{A\in\Dec(L)}\sigma_A(N).
 \tag{1}
\]

\paragraph{Candidate under test.}
Can (1) be an implementation-invariant universal resource whose growth on
the clean core supplies a lower-bound intermediary?  The answer is no:
\texttt{POINTWISE-LOWER-ENVELOPE-AS-UNIVERSAL-RESOURCE1} is \RET.

\section{Exact theorem: per-length hardwiring collapse}

\begin{theorem}[POINTWISE-OPTIMUM-NONUNIFORMITY1]
Let \(L\subseteq\{0,1\}^*\) be decidable.  In the model above there are
absolute constants \(a,b,c\) such that for every \(N\),
\[
 \underline T_L(N)\le aN+b,\qquad
 \underline S_L(N)\le c.
 \tag{2}
\]
More explicitly,
\[
 \forall N\;\exists A_N\in\Dec(L)\;\forall x\in\{0,1\}^N:
 T_{A_N}(x)\le aN+b\ \land\ S_{A_N}(x)\le c.
 \tag{3}
\]
The description of \(A_N\) may contain \(\Theta(2^N)\) finite-control states.
The family \((A_N)_N\) need not have a computable, polynomial-time, or
polynomial-size uniform generator.
\end{theorem}

\begin{proof}
Fix any total exact decider \(B\) for \(L\); decidability is the only premise.
For one fixed \(N\), construct a new finite machine \(A_N\).  Its finite
control contains the full depth-\(N\) binary decision tree.  The state reached
after reading a prefix \(u\in\{0,1\}^{\le N}\) records \(u\) in the control
state, not on a work tape.  At depth \(N\), the two possible output states are
hardwired according to the truth table of \(L\cap\{0,1\}^N\).  The tree has
at most \(2^{N+1}-1\) prefix states, plus constant glue.

On an input of exactly length \(N\), \(A_N\) reads each symbol once, verifies
the right endmarker, and emits the hardwired bit.  This costs \(N+O(1)\)
transitions and \(O(1)\) work cells.  On every other length, it rewinds as
needed and runs \(B\).  Thus \(A_N\) is one total exact decider for \(L\),
although only its cost at length \(N\) is controlled.  The transition table
is finite for each fixed \(N\), so its size is a machine constant in (1).
The same step and workspace constants work for all selected lengths, proving
(2)--(3).  No effective construction of the sequence \(A_0,A_1,\ldots\) is
asserted or needed.  \qed
\end{proof}

\begin{corollary}[SAT and the clean core]
Since SAT is decidable by exhaustive search, (2) holds unconditionally for
the full SAT language.  It therefore also destroys any claimed superlinear
pointwise lower-envelope obstruction on encoded clean-core lengths.  In
particular, this conclusion neither assumes nor proves \(P=NP\).
\end{corollary}

\section{The exact quantifier error}

The theorem proves
\[
 \forall N\;\exists A_N\;\forall |x|=N:
       T_{A_N}(x)=O(N),\quad S_{A_N}(x)=O(1),
 \tag{4}
\]
not
\[
 \exists A\;\forall N\;\forall |x|=N:
       T_A(x)=N^{O(1)}.
 \tag{5}
\]
For \(L=\SAT\), (5) is precisely the kind of single uniform global decider
whose existence is equivalent to \(P=NP\).  Promoting (4) to (5) would
smuggle the open problem into the bridge.

Charging the transition-table description repairs the accounting but removes
the collapse: \(A_N\) uses an exponential-size table in the worst case.
Requiring a uniform polynomial-time compiler \(1^N\mapsto A_N\) with
polynomial-size output is stronger still and is not supplied by the semantic
infimum.  Advice-theoretically, (4) is more permissive than ordinary
\(P/\mathrm{poly}\): the per-length machine may have exponential description
and no uniform generator.

\paragraph{SAME\_REALIZATION.}
For each fixed \(N\), the same machine \(A_N\) jointly realizes the claimed
time and workspace bounds on every \(N\)-bit input.  The failure occurs
between lengths: there is no one selected realization to which all the
bounds attach.  Thus this is a uniformity/quantifier failure, not a
time--space SAME\_REALIZATION mismatch.

\section{Primary-literature and obstacle preflight}

The two major obstacles were (i) selecting one global uniform realization
rather than a different implementation at every length and (ii) landing the
same fully charged ordinary machine in an unconditional time--space forbidden
region.

\begin{itemize}
\item Blum's machine-independent complexity axioms and speedup phenomena are
\KNOWN context for the hazards of program optimization.  They are not used
to prove the elementary hardwiring theorem and do not yield a SAT lower bound.
\item Meyer--Fischer's effective-operator speedup theorem is likewise a
useful warning that a canonical fastest program need not exist in broad
settings.  Importing it as a theorem about the pointwise SAT envelope would
be a misleading transfer; our proof is direct.
\item Karp--Lipton's advice-machine formalism is the directly relevant
uniform/nonuniform distinction.  The present \(A_N\) family is even less
restricted than polynomial advice because description size is uncharged.
No Karp--Lipton collapse theorem is invoked.
\item Fortnow--Lipton--van Melkebeek--Viglas give the model-matched
\KNOWN SAT time--space endpoint used by the project.  Their theorem constrains
one ordinary uniform machine; it does not constrain the lengthwise infimum
over different machines.  The missing landing remains \OPEN.
\end{itemize}

The electronics analogy of fabricating a different exponentially large
truth-table chip for each input width is structurally useful but requires an
area/description charge; it is not an ordinary-TM lower bound.  VLSI
area--time tradeoffs, control observability, communication cuts, coding
duality, and proof-system interpolation are \emph{useful analogies requiring
a new transfer theorem} when their interfaces are explicit.  Treating
per-size hardware as one uniform SAT program is a \emph{misleading analogy / 
failed transfer}.

\section{Barrier audit}

\paragraph{Relativization.}
The hardwiring theorem relativizes for each fixed oracle: the length-\(N\)
truth table of \(L^O\) can be embedded into \(A_N^O\).  It is a no-go guard,
not a nonrelativizing separation step.

\paragraph{Algebrization.}
No algebraic extension is used.  Allowing algebraic oracle access does not
produce a uniform selector for the machines \(A_N\).  There is no
nonalgebrizing hinge.

\paragraph{Natural Proofs.}
No large constructive circuit property is asserted, so the Natural Proofs
conditions are not triggered.  Promoting the hardwired tables to a general
circuit lower bound would require a separate audit.

\paragraph{Arbitrary exponents and one-bit output.}
The pointwise collapse is independent of the baseline decider's exponent,
because the baseline is invoked only off the selected length.  The length-
specific path returns one bit and materializes no witness, compatibility
table, proof, frontier, or communication transcript.

\section{DUPLICATION / CONTRADICTION AUDIT}

Prior corpus text already says that an input-length-dependent table is
nonuniform advice and that minimization over all codes is not acquisition.
This report does not relabel those warnings as new.  The new increment is the
general quantified theorem (2)--(3), its simultaneous time/space
SAME\_REALIZATION proof for each length, and its explicit pairing with
MAJORANTNOGO1: universal majorants inflate while pointwise minima collapse.

No contradiction was found with TDLG1, KCALIB1, CLKSLACK1, JOINTGAUGE1,
CALQNT1 or MODELBRIDGE-0022.  The apparent conflict with a universal SAT
time lower bound disappears because FLMV constrains one uniform machine,
whereas (1) changes the machine with \(N\).
