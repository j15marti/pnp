\section{Exact direct-DP dominance theorem}
\begin{theorem}[One-pass frontier DP and joint Pareto dominance]
For every fixed $(A,G_A)$ with the declared interface, there is ONE
fixed uniform total deterministic exact ordinary-SAT decider $D_{A,G_A}$
with the simultaneous bounds
\[
\boxed{\quad t_{\rm DP}\le\max\{r,\mu+\delta\},\qquad
s_{\rm DP}\le\max\{\eta,\delta\}.\quad}\tag{1}
\]
At any fixed depth $d\ge2$, the certified row-embedded guest envelope
from \texttt{ARC-ROW-EMBED-FUSION166} is
\[
\begin{split}
t_{\rm row}&\le
 \max\{r,\mu+d\delta,
       \mu(1-2^{-d})+d\delta+\mu2^{-d}t\},\\
s_{\rm row}&\le
 \max\{\eta,\mu/2,\delta,\mu2^{-d}s\}.
\end{split}\tag{2}
\]
For nonnegative $\mu,\delta$ and ordinary nonnegative $(t,s)$, the
right sides of (1) are coordinatewise no larger than the right sides
of (2). They also dominate the older two-boundary stream-fusion
envelopes with $2d\delta$ replacing $d\delta$. The comparison is
of \emph{charged upper certificates}, not a universal lower bound
on actual guest implementation resources.
\end{theorem}
\begin{proof}
Initialize a reachable-assignment row containing only the empty
assignment. On $\mathrm{OPEN}(v)$, extend every row with values 0 and 1;
on $\mathrm{CLAUSE}(C)$, delete each live assignment violating $C$;
on $\mathrm{CLOSE}(v)$, existentially project coordinate $v$.
By induction on the event stream, each retained row is exactly a
currently live assignment extendible to satisfy the earlier emitted
clauses. A closed variable never appears in a later clause by the
scoped-stream contract. At final empty frontier, the empty assignment
remains if and only if $H_F$ is satisfiable, including on UNSAT
sources. The invalid-input path is total as required of $G_A$.

There are at most $2^w=N^{\delta+o(1)}$ rows. Retain two consecutive
tables and the $O(w\log N)$ named indexes. Each emitted event can be
processed in $2^w\operatorname{polylog}N$ operations, including every
unchanged and changed write, address and control step. With the paused
producer state still live, total time is
$O(T_G+M2^w\operatorname{polylog}N)$ and peak counted space is
$O(S_G+2^w\operatorname{polylog}N)$. This is ONE execution realizing
both exponents, not borrowing time and space from distinct programs.

For all fixed $d\ge1$ and $\delta\ge0$,
$\mu+\delta\le\mu+d\delta$. Also the space list
$\{\eta,\delta\}$ is a subset of
$\{\eta,\mu/2,\delta,\mu2^{-d}s\}$.
Adding a nonnegative guest term or changing the row surcharge to
$2d\delta$ cannot improve the upper envelope. This proves the claim.
\end{proof}
