\section{BUILD: meet generators}
Let $R\subseteq\{0,1\}^n$ be nonempty and majority-closed,
choose $a\in R$ and $D=R\oplus a$. The identity
$\mathrm{maj}(a,a\oplus u,a\oplus v)=a\oplus(u\wedge v)$
shows $D$ is AND-closed. For each coordinate $i$ that is
one in some $d\in D$, define
$g_i=\bigwedge\{d\in D:d_i=1\}$, which belongs to $D$.
\begin{lemma}
The vectors $g_i$ span $\operatorname{span}_{\mathbb F_2}D$.
\end{lemma}
\begin{proof}
Define $i\preceq j$ if $d_i=1$ implies $d_j=1$ for
every $d\in D$. Mutual implication identifies columns that
are identical in all members of $D$. Quotienting by mutual implication
gives a partial order on $h$ active equivalence classes.
Each $g_i$ is the incidence row of the principal upset of its class.
Under a linear extension, the $h$ such rows form an upper-triangular
$h$ by $h$ matrix with diagonal ones, and hence are linearly independent.
All $d\in D$ are zero outside active coordinates and constant
on each equivalence class, so the full span has dimension at most $h$.
Therefore the $g_i$ span it.
\end{proof}
\begin{theorem}
A deterministic algorithm decides an arbitrary 2CNF formula $C$
conjoined with exactly one parity constraint
$\bigoplus_{i\in S}x_i=b$
using at most $n(n+1)+1$ ordinary 2SAT calls and polynomial bit time
and space, producing an original assignment on YES or a
fully replayable NO transcript.
\end{theorem}
\begin{proof}
The model relation of every 2CNF is majority-closed.
Find an original model $a$ by an SCC-based 2SAT solver, or
return its UNSAT certificate. If $a$ meets the parity, accept.
For each coordinate $i$, a 2SAT test with $x_i\ne a_i$
determines whether it is active. For active $i$, the 2SAT
test $C\land(x_i\ne a_i)\land(x_j=a_j)$ is UNSAT
exactly when $g_i[j]=1$. Thus all $g_i$ can be reconstructed
with $O(n^2)$ 2SAT calls and each $a\oplus g_i$ is a model.
A linear parity functional changes on some member of $R$
if and only if it changes on some generator by the lemma.
Output the first generator giving the requested parity.
If none exists, recheck the exhaustive pinned 2SAT queries
and apply the span lemma to certify infeasibility. Both sides
use one uniform program; all failed queries are charged.
\end{proof}
\begin{theorem}[Observed affine rank deficiency at most one]
Parse source-authenticated complete four-clause XOR3 quartets,
with all remaining clauses unary or binary. Let the affine
row system have parametrization
$x_i=c_i\oplus\langle v_i,t\rangle$, and let $\mathcal V$
be the distinct nonzero $v_i$ observed in binary clauses.
If $e=|\mathcal V|-\operatorname{rank}(\mathcal V)\le1$,
there is a deterministic polynomial-time decision/witness/NO-certifier
for this restricted input grammar.
\end{theorem}
\begin{proof}
Substitute new names $u_v=\langle v,t\rangle$ into
the unary/binary clauses, producing 2CNF $C'(u)$.
If $e=0$, the image of the linear map $t\mapsto(u_v)$
is all of $\mathbb F_2^{|\mathcal V|}$. If $e=1$,
the image is exactly the hyperplane defined by the single
linear dependency $\bigoplus_{v\in S}u_v=0$.
The preceding theorem solves the exact existential
projection in polynomial time. Reconstruct original assignments
by Gaussian solving and check every signed source clause.
For NO, check every quartet, row operation and pinned 2SAT
probe transcript. On recognized physical input length
$N\ge512$, output a fixed 18- or 19-byte YES/NO terminal
formula, so $|K(F)|\le N^{3/4}$; next level checks the base.
For other inputs return UNKNOWN. No all-SAT contraction follows.
\end{proof}
