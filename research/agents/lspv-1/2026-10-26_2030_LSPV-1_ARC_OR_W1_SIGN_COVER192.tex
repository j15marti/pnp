\section{Source-exact two-clause guard and connected OR semantics}
For every $k\ge3$, take $k$ variable-disjoint copies $W_i$ of $W_1$,
using names $x_{ij}$, and write their 20 clauses as
$C_{ih}=a_{ih}\vee b_{ih}\vee c_{ih}$.
Give module $i$ a fresh selector $s_i$ and every clause its own
new guard variable $z_{ih}$. Replace every source clause by the
two distinct three-name clauses
\[
(\neg s_i\vee a_{ih}\vee z_{ih})
\quad\wedge\quad
(\neg z_{ih}\vee b_{ih}\vee c_{ih}).
\tag{1}
\]
Append the standard $k-2$ proper ternary OR-chain encoding
$s_0\vee\cdots\vee s_{k-1}$, with $k-3$ new chain names.
The resulting ordinary CNF is $F_k$.

For each Boolean valuation of $s,a,b,c$,
\[
\exists z\,
[(\neg s\vee a\vee z)(\neg z\vee b\vee c)]
\quad\Longleftrightarrow\quad
\neg s\vee a\vee b\vee c.
\tag{2}
\]
When $s=0$, take $z=0$. When $s=1,a=0$, the first
clause forces $z=1$ and the second requires $b\vee c$.
When $s=1,a=1$, take $z=0$.
Distinct $z_{ih}$ permit independent elimination.
Consequently, for any modules $M_i$ on these same
literal supports,
\[
\SAT(G(M_0,\ldots,M_{k-1}))
\quad\Longleftrightarrow\quad
\bigvee_{i=0}^{k-1}\SAT(M_i).
\tag{3}
\]
For canonical self-delimiting width/count headers followed by
one polarity bit and $w$ identifier bits per ternary literal,
\[
n_k=15k+k+20k+(k-3)=37k-3,\qquad
m_k=40k+(k-2)=41k-2,\qquad
N_k=H_k+3m_k(w_k+1)=\Theta(k\log(k+2)),
\tag{4}
\]
where $w_k=\lceil\log_2(n_k+1)\rceil$,
$H_k=O(\log(k+2))$.
Every new clause is proper and pairwise distinct.
The clause-variable incidence graph is connected via the
selector chain. Original W1 names still have signed quota
$(2,2)$, but selectors and guard names generally do not.
Therefore NO global exact22 or clause-monotone transfer
has been claimed.

\section{A same-run source authentication theorem}
\begin{theorem}[The connected all-module-sensitive source]
$F_k$ is UNSAT. For every $i$, each original variable
$x$ in module $i$, and every one of its four opposite-sign
occurrence pairs $(p,q)$, flipping only those \emph{two actual
physical source sign bits} produces a SAT ordinary proper
3CNF with precisely the same encoded size, original variable
names, headers, clause supports and order.
Thus $F_k$ has $60k$ distinct SAT neighbors of Hamming distance two.

For any nondeterministic exact verifier that can accept only
UNSAT on \emph{all ordinary inputs}, every accepting computation
on this same $F_k$ reads at least $30k$ distinct original
source sign-bit positions. The identical floor applies to the
rejecting run of any total deterministic correct ordinary
SAT decider:
\[
\boxed{Q(F_k)\ge 30k=\Omega(N_k/\log N_k).}
\tag{5}
\]
\end{theorem}
\begin{proof}
Every unmutated $W_i$ is UNSAT, so by (3) $F_k$
is UNSAT. By the finite lemma, one opposite-sign
two-occurrence swap makes its chosen $W_i$ SAT.
Then (3) makes the full modified guarded OR SAT.
The guarded transformation places each original literal
occurrence in exactly one unique source guard-clause literal
slot, so precisely two literal polarity fields change.
Fixed supports preserve propriety, connectivity, names
and binary serialization width.

Fix a sound accepting UNSAT path, including its
nondeterministic choices and all preprocessing actually run.
If it fails to read both positions of any one of the $60k$
SAT-producing pairs, replay the path on that SAT neighbor.
All probed input bits agree, so the same accepted path
would violate soundness. For each original name,
the inspected sign positions therefore form a
vertex cover of $K_{2,2}$ and have size at least two.
The $15k$ source-variable occurrence sets are disjoint;
summing gives $2(15k)=30k$. No proof length
or SAT guest-call cost has been set to zero.
\end{proof}

\section{Short authenticated refutations and source access are different}
\begin{lemma}[Linear-size Resolution control]
The same $F_k$ admits a general-Resolution refutation with
$O(k)$ inference lines and $O(k\log k)$ bits in an indexed
fixed-width proof encoding.
\end{lemma}
\begin{proof}
Because $W_1$ is a fixed finite UNSAT formula,
fix a finite Resolution refutation of it with $R_0$ lines.
For each guard pair (1), resolve its distinct $z_{ih}$
to obtain $\neg s_i\vee a_{ih}\vee b_{ih}\vee c_{ih}$.
Lift every line of that fixed W1 refutation by adding
$\neg s_i$. This derives unit $\neg s_i$ with
at most $20+R_0$ source-inference lines.
Resolve all $k$ selector units against the ternary
OR chain to derive the empty clause in $O(k)$ lines.
The lifted proof width is fixed by the constant W1
refutation, so each serialized line/index is $O(\log N)$
bits. All source axioms still require authentication.
\end{proof}
The disconnected $k$-fold conjunction of W1 is a
critical hostile control: swapping one module does
\emph{not} change the global UNSAT label. The OR
selector solves only this label-sensitivity defect,
not the problem of universal certificate coverage.
A proof verifier, its local source-authenticating
transition circuit, and a full all-input length-$N$
SAT decision circuit $C_{A,N}$ are distinct objects.
