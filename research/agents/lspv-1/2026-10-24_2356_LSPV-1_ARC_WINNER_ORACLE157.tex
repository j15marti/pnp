\section{Exact theorem: the faster program's index is SAT}
For a total deterministic decider \(D\) of an arbitrary decidable Boolean language \(L\), let \(\ell(x)=D(x)\in\{0,1\}\) and let \(d(x)\) be its actual charged bit work. Fix any integer \(H\ge2\). Define a delay procedure \(\Delta_H(N)\) that executes \(\Theta(N^H\operatorname{polylog}N)\) actual counted elementary steps by traversing \(H\) logarithmic-bit counters, using only \(O_H(\log N)\) simultaneously writable/index bits.

Hardwire \(i=0\) or \(i=1\) into the same fixed uniform program template:
\[
A_i(x):\quad b\gets D(x);\quad
\text{if }b\ne i,\ \text{execute }\Delta_H(|x|);\quad
\text{return }b.
\]

\begin{theorem}[Globally correct winner-index encoding]
Both \(A_0\) and \(A_1\) are fixed total uniform exact deciders for the SAME language \(L\), and for all sufficiently large inputs their faster-program index satisfies
\[
\boxed{\operatorname{winner}(A_0,A_1;x)=\ell(x).}
\]
Each program's peak writable/index bits are at most \(S_D(x)+O_H(\log N)\); their completion work, modulo fixed interpreter overhead, is
\[
W_{A_i}(x)=d(x)+O(1)+[\ell(x)\ne i]\Delta_H(N).
\]
Assuming \(P=NP\), choose a polynomial ordinary-SAT decider \(D\) of time exponent \(K\), then choose \(H>K+2\). Both portfolio programs are uniform polynomial-time, globally SAT-correct, have worst-case time exponent \(H\) and the same valid joint space upper bound, while the identity of the faster program equals the SAT decision bit.
\end{theorem}
\begin{proof}
Both compute and return exactly \(D(x)\). Their common simulation uses the same fixed interpreter; exactly one program executes the positive-count delayed suffix. Any constant overhead discrepancy between the two hardwired mode bits is dominated for all sufficiently large \(N\). The slower program cannot finish before the other. During the delay only \(H\) counters and indices are live beyond the completed \(D\) state. Under \(P=NP\), the fixed \(D\) takes at most \(N^{K+o(1)}\) time and the delayed program at most \(N^{H+o(1)}\), while on oppositely labeled arbitrarily large inputs each delayed branch costs \(\Omega(N^H)\). Ordinary indexed SAT admits arbitrarily large SAT and UNSAT formulas, including paired fixed-size-clause-count controls. There is no input-dependent advice, label oracle, free fastest-time computation, or assumption of a computable universally optimal program.
\end{proof}

\begin{corollary}[Joint FLMV floor for a winning-index selector]
If one fixed total deterministic machine \(W\) computes the identity of the faster of these two fixed SAT programs on every sufficiently long ordinary input, and its simultaneous FLMV-model time and workspace exponents are \((u,v)\), then \((u,v)\in\mathcal E\) after a constant finite-length repair. Consequently
\[
\boxed{\neg\bigl(u<241/200\ \wedge\ v<11642479/23232400\bigr).}
\]
\end{corollary}
\begin{proof}
Hardwire the fixed portfolio into \(W\), then return its winner index as the ordinary-SAT bit. The theorem proves correctness on sufficiently long inputs; finitely many shorter strings admit a constant hardwired decision table. Thus the same machine has the alleged joint resource bounds for SAT, contradicting the matched FLMV forbidden box.
\end{proof}

\paragraph{Scope guard.}
This does NOT show that winner discovery requires the full artificial delay \(N^H\). Running \(D\) already chooses correctly in \(T_D\) time; a parallel race can identify a winner only after paying real computation and simultaneous storage. The result does NOT create any favorable ARC child, prove \(P\ne NP\), or preclude an explicit cheaper selector for some other portfolio. It shows that an asserted free statewise optimal policy may hide the original decision problem even for only two globally correct choices. Hutter's theorem has a different certified-program/provable-time scope \cite{hutter}; Blum's general speedup result does not establish a SAT-specific fastest-program obstruction \cite{blum}.
