\section{Exact fixed-program quantifiers}
Fix a binary CNF encoding with a distinct MALFORMED outcome and a standard deterministic multitape Turing machine model. Each total correct SAT decider A is one finite program, fixed across all lengths. Define
\[
T_A^{wc}(N)=\max_{|x|\le N}T_A(x),\quad
\overline W_R(N)=\max_{\substack{F\in\mathrm{UNSAT}\\|\langle F\rangle|\le N}}\min_{\pi:F\vdash_R\bot}\sum_{v\in\pi}w_R(v).
\]
The fixed sound and complete calculus R, unit weights and proof encodings precede all inputs. Proof discovery is excluded from the minimum. The approved B2 is
\[
\forall A\in\mathrm{DecSAT}\ \exists p_A\ \forall N:\quad
\overline W_R(N)\le p_A(N+T_A^{wc}(N)).
\]
The program A must be fixed before N varies.
\begin{theorem}[Moving-algorithm hardcoding]
For every decidable language L and every N, there exists a total correct fixed decider A[N] with worst-case time at most c(N+1) on inputs of length at most N, with c independent of N, but its program may have 2^{\Theta(N)} finite-control states. Hence \inf_{A\in\mathrm{DecSAT}} T_A^{wc}(N)=O(N) for every N regardless of P versus NP.
\end{theorem}
\begin{proof}
A full binary prefix trie has 2^{N+1}-1 states, one per prefix of length at most N, each storing the correct membership or MALFORMED label for a terminated input. Reading an input of length at most N takes |x|+O(1) transitions. Longer inputs trigger a rewind and call to any fixed complete decider for L. Each A[N] is total/correct at all lengths, but the code changes with N and has exponential finite-control size. Code acquisition is NOT free when studying the entire moving family under a charged-code machine model.
\end{proof}
\begin{theorem}[Falsified moving-minimax transfer]
For ordinary DAG resolution with unit inference cost there is no polynomial p such that
\[
\forall N:\quad\overline W_{\mathrm{Res}}(N)\le p\bigl(N+\inf_{A\in\mathrm{DecSAT}}T_A^{wc}(N)\bigr).
\]
This does not refute the real B2.
\end{theorem}
\begin{proof}
The preceding theorem makes the polynomial's argument O(N). Haken's 1985 polynomially encoded pigeonhole CNFs have superpolynomial minimum Resolution refutations, so the displayed inequality would incorrectly make their worst-case minimum polynomial. It improperly exchanges the quantifiers by selecting a different A[N] for every N.
\end{proof}
\section{One portfolio for each fixed code budget}
Fix any k at least the description length of an exhaustive exact SAT decider. Let
\[
\mathcal C_k=\{A:|\langle A\rangle|\le k,\ A\text{ total correct SAT decider on all binary strings}\},\quad D_k(N)=\min_{A\in\mathcal C_k}T_A^{wc}(N).
\]
\begin{theorem}[Finite correct-program portfolio]
There exists one fixed total correct P_k and a polynomial q_k such that
\[
T_{P_k}(x)\le q_k\left(|x|+1+\min_{A\in\mathcal C_k}T_A(x)\right),\quad
T_{P_k}^{wc}(N)\le q_k(N+1+D_k(N)).
\]
\end{theorem}
\begin{proof}
The correct-program set is finite (although not computably recognizable). Hardcode all of its members into P_k; simulate them round-robin on paid input copies, and return the first halting answer. Each member is already assumed correct for SAT, UNSAT and malformed inputs, so no fastest-machine response can be false. Standard finite multitape simulation incurs a polynomial overhead in length and fastest runtime, with constants depending on k, not N. Choose a member attaining D_k(N) to obtain the second inequality, while keeping the same P_k across lengths.
\end{proof}
\begin{proposition}[Exact reformulation of B2]
B2 for R is equivalent to
\[
\forall k\ge k_0\ \exists\text{ polynomial }p_k\ \forall N:\quad
\overline W_R(N)\le p_k(N+T_{P_k}^{wc}(N)).
\]
Also SAT belongs to P if and only if some P_k has polynomial worst-case time.
\end{proposition}
\begin{proof}
B2 applies to each correct P_k. Conversely, for any A take k\ge\max(k_0,|\langle A\rangle|); substitute the polynomial portfolio runtime majorant into p_k, replacing p_k by a monotone polynomial majorant if needed. If SAT is polynomial for some A, a sufficiently large fixed k contains A and makes P_k polynomial. Conversely P_k itself is correct.
\end{proof}
