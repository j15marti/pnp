\section{Indexed source extrema}
Each signed original occurrence $x_{i,j}$ in original clause $C_j$ has sign bit $\sigma_{ij}$.
Local all-literals-TRUE $S_j$ requires $x_i=\sigma_{ij}$, while all-literals-FALSE $U_j$ requires $x_i=1-\sigma_{ij}$.
Inverting $S_j$ gives $U_j$ and vice versa, but simultaneous independent occurrence targets need not form a coherent variable assignment.
The indexed pair compatibility conditions are
\[
SS=UU\iff\text{no opposite-sign shared variable},\quad
SU=US\iff\text{no same-sign shared variable}.
\]
All extreme modes can fail while both disjunctions are SAT.
For coherent complete $a$, $t_j(\bar a)=3-t_j(a)$ and $N_r(\bar a)=N_{3-r}(a)$.
For source-variable flips $H$, $\Delta t_j=|H\cap L_j^0(a)|-|H\cap L_j^1(a)|$.
The raw source-indexed audit contains every source occurrence target and inversion, four pair modes, genuine $0^n,1^n$, complements, flips, and proof-parent resolvents.
For the indexed W1/SWAP6 original clauses $C_0=(\neg x_1\vee x_3\vee\neg x_{14})$, $C_{19}=(\neg x_1\vee x_{13}\vee x_{14})$, all four pair modes fail.
The sound non-tautological resolvent is $(\neg x_1\vee x_3\vee x_{13})$, forbidding the cube $x_1=1,x_3=x_{13}=0$.
\section{Exact bounded-support theorem}
For coherent original partial cube $\rho$, let $R=F\mid\rho$ be source-indexed residual clauses.
For free variable set $V$, put $R[V]=\{C\in R:\operatorname{var}(C)\subseteq V\}$.
Let $\operatorname{cyl}_V(U_C)$ be all assignments to $V$ extending residual clause $C$'s all-FALSE target.
\begin{theorem}
There is an UNSAT subformula of $R$ supported on at most $r$ variables if and only if
there is a $V$ with $|V|\le r$ such that
\[
\bigcup_{C\in R[V]}\operatorname{cyl}_V(U_C)=\{0,1\}^V.
\]
This source-authenticated cover forbids the entire cube $\rho$.
If original clauses have width at most three and maximum original occurrence degree $d$, a deterministic indexed-RAM search, returning UNKNOWN otherwise, takes
\[
O\left(N+ndr^2 2^r\sum_{j=0}^{r-1}(2d)^{2j}\right)
\]
time and $O(N+dr2^r)$ peak words, where $n$ is the number of free variables and $N$ the encoded input size.
For bounded $d$ and $r=O(\log N)$ this is polynomial.
\end{theorem}
\begin{proof}
Every residual clause is false exactly on its all-FALSE cylinder.
Complete coverage is therefore equivalent to unsatisfiability of $R[V]$, and any bounded-support UNSAT subformula is contained in some such $R[V]$.
A clause-minimal UNSAT subformula has connected primal variable support.
At maximum variable degree $2d$, every connected $t$-variable set has a spanning tree with a depth-first closed walk of length $2(t-1)$.
Enumerate $n$ roots and at most $(2d)^{2(t-1)}$ walks per root; for each inspected support extract at most $dt$ residual source clauses and test at most $2^t$ coherent assignments.
The bound charges all duplicates, failed walks, source lookup, cover verification and live storage; it applies to this restricted method only.
\end{proof}
\section{Seven/eight-of-eight same-triple rule}
Each original signed ternary clause on a fixed triple forbids one of eight local assignments.
Eight distinct all-FALSE targets imply UNSAT; seven force the one missing triple assignment in every model.
This is established hitting-clause logic, not a new SAT inference.
A proper strict signed exact-$(2+,2-)$ 3CNF variable has only four occurrences, so seven original clauses on the same triple are impossible.

\section{Source-specific finite obstruction}
The authenticated 15-variable, 20-clause W1 strict22 formula is UNSAT.
The sign-swapped SWAP6 source has exactly 54 SAT models, all requiring $x_2=1$.
Its residual under $x_2=0$ is UNSAT on fourteen remaining free variables; unit propagation does not refute, and its two binary residual clauses are jointly satisfiable.
Yet for every remaining free variable $v$, the source-induced subformula omitting clauses mentioning $v$ is SAT.
An independently replayed full mask with bit $i-1$ representing original $x_i$ is
\[
\begin{array}{c|rrrrrrr}
v&1&3&4&5&6&7&8\\\hline
a&0&8209&608&10245&24597&0&608\\
v&9&10&11&12&13&14&15\\\hline
a&616&96&840&8213&0&1&8213
\end{array}
\]
Independent exhaustive evaluation verifies zero SAT completions with $x_2=0$ and these fourteen witnesses.
Thus no UNSAT residual subformula on fewer than fourteen free original variables refutes this specified cube.
This finite claim does NOT constrain resolution width: the separately authenticated 28-step width-three RUP certificate already refutes the same residual.
An inconsistent binary XOR cycle has the analogous unbounded local-support obstruction but is polynomially easy for 2SAT and GF(2).
