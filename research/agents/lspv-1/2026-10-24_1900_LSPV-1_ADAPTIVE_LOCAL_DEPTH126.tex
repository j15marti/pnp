\section*{Precise protocol model}
An ordered proper 3CNF is \(F=(C_1,\ldots,C_m)\), with three distinct variable identifiers per clause and a declared variable universe \([n]\). Let \(p(C)\in\{0,1\}^8\) be the truth table of an \emph{isolated} clause after renaming its three positions to \(1,2,3\). The parent-local interface reveals public metadata \((n,m,N)\), a clause index \(i\), and arbitrary responses determined by \(p(C_i)\) and the query's local history. It withholds original source-variable identifiers and forbids a query that combines clauses from distinct original indices. The controller may be deterministic or randomized and may adapt indices, pins, representation, recursion depth, caching and stopping to all prior responses. Queries can return complete canonical local child strings, SAT/\#SAT bits, local satisfying relations, or any computable function of the chosen isolated clause and query history. Every terminating execution has finitely many queries. No global source read is allowed to leak the withheld incidence field.

This is an explicitly \emph{restricted} observation channel, \emph{not} the unrestricted read-only source tape of the FLMV random-access model. Charging the local provider's reads and materialization does not make this channel universal.

\begin{theorem}[Growing connected local-depth indistinguishability]
For every \(k\ge0\) there exist connected, duplicate-free, proper ordered 3CNFs \(U_k,V_k\), each with
\[
n_k=51+2k,\qquad m_k=36+k,\qquad
N_k=(4m_k+2)\left\lceil\log_2(64(n_k+m_k+1))\right\rceil,
\]
such that
\[
\SAT(U_k)=0,\qquad \SAT(V_k)=1,\qquad
p((U_k)_i)=p((V_k)_i)\quad(1\le i\le m_k).
\]
For every adaptive controller accessing only the specified clause-local channel, every finite query transcript on \(U_k\) is identical to the corresponding transcript on \(V_k\) when the controller's random coins are coupled. Consequently, no such deterministic exact controller decides both inputs correctly, and no randomized controller achieves error \(<1/2\) on both, regardless of its allowed finite recursion depth and number of queries.
\end{theorem}
\begin{proof}
Let \(C_\eta(v_1,v_2,v_3)\) range over the eight possible sign patterns for one proper ternary clause. In \(U_0\), the first eight clauses put all \(C_\eta\) on the \emph{same} variables \(v_1,v_2,v_3\), making their conjunction UNSAT. In \(V_0\), the corresponding \(C_\eta\) use the eight disjoint triples \((v_{3i+1},v_{3i+2},v_{3i+3})\), \(i=0,\ldots,7\), making the conjunction SAT. Append to both formulas the 24 clauses \((g\vee v_i\vee v_{27+i})\) for \(i=1,\ldots,24\), where \(g=v_{25}\), and the four-clause proper unit gadget
\[
{\cal U}(g;a,b)=\bigwedge_{\epsilon,\delta\in\{-1,1\}}
(g\vee \epsilon a\vee\delta b),\qquad a=v_{26},\ b=v_{27}.
\]
This forces \(g=1\) and makes every bridge trivially satisfied, while connecting all occurrences and preserving both labels. For each \(j=0,\ldots,k-1\), add the clause
\((g\vee v_{52+2j}\vee v_{53+2j})\) to both. These clauses are distinct, bring every new variable into the connected incidence graph, and impose no restriction when \(g=1\). Hence counts, connectedness, duplicate-freeness, and opposite labels hold for all \(k\).

Corresponding clauses have identical \emph{position-wise sign patterns}; they differ only in some original variable identifiers. Accordingly all isolated-clause truth profiles agree at each index. Any local response is a function of the same profile and the same local query history. Couple randomized coins. Induction on the number of queries shows that controller state, next query, response and cache contents remain identical. The final output distribution is therefore identical for opposite-label parents. If its probability of outputting SAT is \(p\), its error on \(U_k\) is \(p\) and on \(V_k\) is \(1-p\); the larger is at least \(1/2\). The same induction covers arbitrarily deep \emph{finite} local child queries because each query stays inside its root clause.
\end{proof}

\begin{corollary}[What repairs and what does not]
Restoring the ordered variable-ID triples \(V_i\) to the eight-row profiles makes the encoding losslessly invertible: the unique zero row recovers the three signs of each clause, so \((n,m,(V_i,p_i)_i)\) is exactly the source proper 3CNF in another notation. The exact consistency question
\[
\exists a\in\{0,1\}^n\ \forall i,\qquad a|_{V_i}\in\{b:p_i(b)=1\}
\]
is the original SAT/CSP join. This repaired representation is neither a universal faster algorithm nor a lower bound; it merely restores the lost cross-clause identity channel. More local query depth cannot change that fact without acquiring genuine cross-clause information.
\end{corollary}

\section*{Concrete hybrid controls and adaptive-state ledger}
A deterministic executable uses exactly the signed clauses specified in the theorem, a complete eight-row profile routine, canonically renamed unit-pin child construction, a direct DPLL solver with unit and pure-literal propagation, and a pseudorandom \emph{adaptive} 512-query controller. For \(k=0,1,4,32\) it checks matched profiles, opposite SAT/UNSAT labels, distinct clauses, complete variable universe, and identical adaptive answer sequences. At \(k=0\), 36 complete clause profile comparisons and all \(36\cdot8\cdot13=3744\) source-anonymized pinned-child clause profiles agree; the 512 recorded queries have depths in \(\{0,1,2,3\}\). Independent DPLL uses seven search nodes on UNSAT and one on SAT. These are \textbf{COMPUTATIONAL} checks, not FLMV-machine measurements.

For the protocol actually tested, state \(S_0\) contains a source index, public \((n,m,N)\), a local history/counter, a coin seed and remaining resource budget; no SAT label. Acquisition reads the selected original clause's three signed fields and canonically renames its variable IDs; this work \emph{must} be charged to the provider, despite hiding IDs from the controller. The rule switches among locally pinned child generation, cached local-profile access and direct local truth evaluation; other legal \emph{full-source} algorithms, including SCC/Horn/affine and direct DPLL, are controls outside the restricted channel. A new \(S_1\) contains the returned profile bit and updated query state. Local correctness means the bit matches a genuine clause pin; global correctness fails on the matched opposite-label inputs. The resource vector to charge on any physical implementation is
\[
(U,R_{\rm source},R_{\rm work},W_{\rm work},
\Delta_{\rm complete},S_{\rm peak},BT,|P|).
\]
All source reads, addressing/control, unchanged writes, rule choices, failed attempts, serialization, caches, rereads and live ancestors count. The finite Python audit records logical events but \emph{does not} certify these quantities in the FLMV Turing model. In particular, a plain full-source recognizer distinguishes \(U_k,V_k\) cheaply by reading the original occurrence IDs.
