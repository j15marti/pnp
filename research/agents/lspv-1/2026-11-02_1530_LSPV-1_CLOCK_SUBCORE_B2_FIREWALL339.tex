\section{Fixed calculus and exact minimum}

A proof authenticates $U\subseteq F$, refutes it with $R_0$, and additionally must derive the counter token $G(U,2^{L(U)}-1)$ from $G(U,0)$ via only the increment rule $G(U,i)\to G(U,i+1)$. Only a final charged rule with premises the $R_0$ empty clause and terminal clock produces REFUTED(F). Clock tags denote true statements and encode no semantic oracle. \begin{theorem}

\[
\boxed{W_{R_{\mathrm{tick}}[R_0]}(F)=
\min_{\substack{U\subseteq F\\U\in\mathrm{UNSAT}}}
(2^{L(U)}+W_{R_0}(U)+1).}
\]

\begin{proof}

SAT inputs cannot produce an $R_0$ empty clause.
\end{proof}
