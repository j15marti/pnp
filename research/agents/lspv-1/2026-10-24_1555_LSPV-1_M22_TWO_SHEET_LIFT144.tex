\section{Canonical target, source quantifiers and three falsifiers}
The canonical \(\CM\) consists of ordinary proper three-variable OR clauses with
distinct source names, unique signed clauses, each clause all-positive or
all-negative, and exactly two occurrences of each active variable in each
polarity.  For clause \(C\), \(\bar C\) reverses all literal signs but retains OR.
Write \(\mathcal P_{\rm pair}=\{F\in\CM:\forall C\in F,\bar C\in F\}\),
\(\CS=\CM\setminus\mathcal P_{\rm pair}\), and
\(L_\star=\{\operatorname{enc}(F):F\in\CS,\operatorname{SAT}(F)\}\).
Invalid encodings are rejected.  Partial pairs, disconnected sources, easy
sources, and sources not minimally UNSAT remain within the target.
For \(k\) original active names, \(m\) clauses and full dense indexed bits \(N\),
\(3m=4k\), \(m_+=m_-=2k/3\), and
\(N=\Theta(k\log(k+2))\).
Let \(P,Q\) be the positive/negative unsigned support sets and
\(q(F)=|P\setminus Q|=|Q\setminus P|\).
The canonical \(Y\) fixture and D\"ocker's established NP-completeness theorem
prove \(L_\star\) NP-complete, not superpolynomial SAT decision time.

Three mechanisms are audited.
\begin{description}
\item[H1.] Can every \(F\in\CM\), including an UNSAT \(F\in\CS\), be
mapped by a uniform source-sign-preserving two-cover to a \emph{satisfiable}
\(\Lambda(F)\in\CM\), maintaining full/nonfull pairing status and
doubling \(q\)? \textbf{PROVED/EXACT restricted}, below.
\item[H2.] Can such local source covers serve as an exact SAT-preserving
ordinary child and thereby an ARC improvement? \textbf{FALSIFIED for this
specific cover}: all images are SAT, output size increases, and source UNSAT
labels are not preserved.
\item[H3.] Can original-name degree-four incidence, high \(q\), and
connectedness alone force a large pointwise post-acquisition potential
on every valid source? \textbf{FALSIFIED as that inference}: every cover
has an explicitly source-readable satisfying assignment.  This does not
falsify a selective algorithm-dependent worst-case potential.
\end{description}

\section{An exact satisfiable two-sheet covering}
Assume the original active names are the dense set \([k]\), obtainable by a
paid polynomial relabeling if necessary.  Associate two distinct names
\(v_0=2v-1\) and \(v_1=2v\) with every source \(v\).
For each source clause \(C\) of polarity
\(\sigma(C)\in\{+,-\}\), sort its original three distinct names
\(a<b<c\). Introduce exactly the following two clauses:
\[
 C_0^\Lambda=\sigma(C)\,(a_0\vee b_0\vee c_1),
 \qquad
 C_1^\Lambda=\sigma(C)\,(a_1\vee b_1\vee c_0).
\]
Here \(\sigma(C)\) means negate all three literals for a negative source
clause and leave all positive for a positive source clause; it is not
Boolean negation of the disjunction.
Equivalently the occurrence at sorted position \(i\in\{0,1,2\}\)
in lifted sheet \(s\in\{0,1\}\) uses clone
\(v_{s\oplus[i=2]}\). Denote the conjunction of all
\(2m\) lifted clauses by \(\Lambda(F)\).

\begin{theorem}[Target-typed, source-sign-preserving satisfiable cover]
For every valid \(F\in\CM\), the transformation above is a
two-fold covering of the unsigned clause-variable incidence graph,
with the original incidence signs preserved. It satisfies
\[
\Lambda(F)\in\CM,\quad
k(\Lambda F)=2k(F),\quad m(\Lambda F)=2m(F),\quad
q(\Lambda F)=2q(F),
\quad \operatorname{SAT}(\Lambda F)=1.
\]
Moreover \(F\in\CS\iff\Lambda(F)\in\CS\), and the uniform fixed
assignment
\[
\boxed{x_{v_0}=0,\qquad x_{v_1}=1\quad\forall v\in[k]}
\]
satisfies every lifted clause, with both values represented in each
lifted clause's three variable fields. The same statements iterate
for every fixed finite number \(r\) of coverings, with
\(k_r=2^rk,\ m_r=2^rm,\ q_r=2^rq\).
\end{theorem}
\begin{proof}
Every original incidence \(v\in C\) is replaced by a perfect matching
between the two variable clones \(v_0,v_1\) and the two clause clones
\(C_0,C_1\); the chosen voltage is \(0,0,1\) by sorted position.
Thus all degree, sign and neighborhood-star information at variable and
clause vertices is copied.  Every original variable has exactly two
positive and two negative incident clauses; each clone inherits exactly
one incidence from each corresponding original occurrence, hence precisely
two incidences of each sign. Every lifted clause has three distinct
names because the base names are distinct, and signs are uniform.
Different unsigned base supports cannot become identical on projection.
For a fixed base support, the two clone supports are distinct.
Therefore unique signed source clauses remain unique.

If a support \(S\) occurs with both signs in \(F\), the same sorted
\(0,0,1\) voltage pattern creates identical two clone supports
in both signs. If it occurs in only one sign, none of its clone supports
can have a partner, since projecting any partner would supply a missing
base partner.  Therefore the number of unmatched positive supports and
negative supports each doubles, giving \(q(\Lambda F)=2q(F)\),
and the fully paired/nonpaired status is preserved.

In the displayed clone assignment every \(C_0^\Lambda\) sees original
variable values \(0,0,1\), and every \(C_1^\Lambda\) sees \(1,1,0\).
Both triples contain a true bit and a false bit.
Consequently each all-positive lifted clause contains a true literal,
and each all-negative lifted clause contains a negated-false true literal.
The original SAT label is never queried. Reapplying the same construction
proves the finite-depth statement by induction.
\end{proof}

\begin{corollary}[Connected UNSAT sources have connected SAT two-covers]
If \(F\in\CM\) is incidence-connected and UNSAT, then
\(\Lambda(F)\) is incidence-connected and SAT.
\end{corollary}
\begin{proof}
For a connected base, a two-fold covering has either one connected
degree-two component or two degree-one components, each graph-isomorphic
to the base with all literal signs preserved.
If the lift were disconnected, each component would be a signed-clause
copy of the UNSAT base and would therefore be UNSAT.
But the fixed satisfying clone assignment exists, contradiction.
\end{proof}
This does not require the second iterated cover to stay connected.
In fact the reproduced 198-variable original below has
connected first cover and a second cover with two 396-variable components.
The canonical target does not require connectedness.

\section{What is and is not computationally unavoidable}
A single fixed uniform total exact SAT decider can first read and parse
the input, evaluate the fixed alternating odd/even variable assignment,
return SAT if the witness verifies, and otherwise perform a fully charged
generic exact fallback.  The direct witness test takes polynomial
elementary bit work with \(O(\log N)\) writable/index storage under a
dense indexed read-only input convention, using repeated source scans if
needed.  Thus this \emph{one} total algorithm is efficient on the entire
image \(\Lambda(\CM)\), even when the base source is connected, maximally
unpaired, or UNSAT.

An attempted pointwise claim of the form
\(W_{\rm post,A}(\Lambda(F))\ge2^{\Omega(q(\Lambda F))}\) for
\emph{every} total exact \(A\) and every image is therefore false.
Likewise a terminal-zero independently specified complete-state
potential \(\Phi\) satisfying
\(\Phi(C)-\Phi(C')\le\Gamma(N)w(C,C')\) for every legal transition
of every exact algorithm has, on the scan-first witness checker,
\(\Phi(C_{\rm acquired}(\Lambda F))\le\Gamma(N)N^{O(1)}\).
This rules out universally exponential initial potential on
\emph{all} such post-read states when \(\Gamma\) is polynomial.
It does not address the required worst-case quantifier
\(\forall A\,\forall p\,\exists\text{ arbitrarily large }F\in\CS:
T_A(F)>p(N)\).  The potential may depend on algorithm and state;
no global source-only scalar is imposed.

The transformation \(\Lambda\) is deliberately \emph{not} an
equisatisfiability reduction: it sends every base, including UNSAT, to
SAT. It cannot furnish a source-correct recursive decision child.
No output-table abundance, covering multiplicity, or new 2-sheet
variable count implies a lower bound against arbitrary deciders.

\section{Disjoint adaptive-state and resource ledger}
On the specified \emph{valid} dense source promise, a virtual lifted
bit-address accessor decodes sheet index, clause index, source-variable
field, sign and sorted position, then reads the corresponding old source
fields. Sorting three variable names costs
\(\operatorname{polylog}N\) primitive bit work and
\(O(\log N)\) writable/index bits per addressed output bit.
Full materialization of \(N'=\Theta(N)\) bits costs at least
\(\Omega(N')\) elementary output writes, and can be done in
\(O(N\operatorname{polylog}N)\) bit work with
\(O(\log N)\) controller workspace if write-only output is allowed.
It is not a readable child tape. For each fixed \(r\),
\(N_r=\Theta(2^r k\log(2^rk))\); the two actual depths \(r=1,2\)
increase the ordinary encoded length rather than power-shrink it.
Validation of arbitrary malformed input, non-dense renaming,
source-field searches, headers, caches and ancestor handles must be
charged separately by any total generator.

The required vector is
\[
(W_{\rm bit},R_{\rm source},R_{\rm work},W_{\rm work},
\Delta_{\rm complete},S_{\rm peak},BT,
|\text{program}|,|\text{representation}|),\quad
BT=\sum_\tau S_{\rm live}(\tau).
\]
Read-only input, indexing, Boolean work, writes including unchanged
writes, failed recognition, witness replay, header generation, recursive
source rereads, caches and output buffers are not free.
Physical complete-state flips and actual cumulative bit-time were not
measured; gate/wire/switch counts are separate axes.
For checkpoint \(T_A=C_A+T_{\mathrm{finish},A}\), neither
\(R_{\rm raw}\) nor an independent exhaustive \(R_{\rm search}\) has been
certified by the cover. The identities involving
\(\Psi=\sum_j2^{r_j}\) and
\(T_{\rm model}=C(N,R)+2^{k-R}\) remain optional accounting of a
\emph{declared} exhaustive continuation, not lower bounds.
