\section{Connected proper-3CNF compiler}
Fix any proper three-literal CNF $F(x_1,\ldots,x_n)$ with $m\ge1$
clauses, distinct variables in every clause, and each named source
variable used, where $n\ge3$. Let $b=(b_0,\ldots,b_{d-1})$ be $d\ge1$
fresh boundary variables. Choose $1\le h\le2^d$ and let
$C_{d,h}(b)=[\mathrm{unsigned}(b)<h]$, with $b_0$ the least significant bit.
A fixed deterministic prefix comparator has $O(d)$ fan-in-two Boolean
gates. Standard bidirectional Tseitin constraints encode each gate
without guessing its output, while each binary $(u\vee v)$ is replaced
by the two proper ternaries
\[
 (u\vee v\vee z)\wedge(u\vee v\vee\neg z)
\]
with a fresh $z$. A required unit $u$ is represented by the four
proper clauses $(u\vee\pm p\vee\pm q)$ with fresh $p,q$.
Thus a proper three-CNF $K_{d,h}(b,y)$ has
\[
 \exists y\,K_{d,h}(b,y)=C_{d,h}(b).
\]
For $h=2^d$, take $K=\top$.

We now add a \emph{functional total connector} for every source variable
$x_j$ with $j>1$ and every boundary variable $b_i$. For any distinct
$a,b$ and fresh $e$, let $\mathsf{XOR}(a,b;e)$ be the four ternaries
\[
 (a\vee b\vee\neg e),\
 (\neg a\vee\neg b\vee\neg e),\
 (a\vee\neg b\vee e),\
 (\neg a\vee b\vee e).
\]
Its unique satisfying $e$ for fixed $a,b$ is $e=a\oplus b$.
Define the source-preserving formula
\[
 H_{F,d,h}=F(x)\land K_{d,h}(b,y)\land
 \bigwedge_{j=2}^n\mathsf{XOR}(x_1,x_j;e_j)
 \land\bigwedge_{i=0}^{d-1}\mathsf{XOR}(x_1,b_i;f_i).
 \tag{1}
\]
Every conjunct is a proper ternary clause after padding.
All $x_j$ and $b_i$ connect to $x_1$ through functional XOR gadgets;
the incidence graph is connected, even if the source $F$ was
disconnected. Original source literal identities and signs are
preserved verbatim in the $F$ conjunct. The uniform compiler adds
$O(n+d)$ connector clauses and $O(d)$ comparator clauses,
so its ordinary encoded bit length is
$O((m+n+d)\log(n+m+d))$; each source read, output header,
auxiliary identifier and generated clause is paid.

\begin{theorem}[Root-hard, projection-rank-one family]
For every legal $F,d,h$ and every pinned boundary word $b$,
\[
 \boxed{\SAT(H_{F,d,h}[b])=C_{d,h}(b)\wedge\SAT(F).} \tag{2}
\]
Moreover
\[
 \boxed{\SAT(H_{F,d,h})=\SAT(F).} \tag{3}
\]
For fixed $d,h$ with $h\ge1$, the complete vector of $2^d$ pinned
answers over all possible source inputs has exactly two values:
the all-zero vector, and the public comparator truth vector.
Even a source-closed exact \emph{full boundary-membership service}
needs only one source-dependent bit after paying for the source
decision, plus the public $O(d)$-gate comparator and query counter.
\end{theorem}
\begin{proof}
Fix $x,b$. Every connector imposes a unique value on its fresh XOR
output and imposes no restriction on $x,b$. The Tseitin comparator
extends precisely if $C_{d,h}(b)=1$. Thus existentially quantifying all
non-source and non-boundary variables leaves
$F(x)\wedge C_{d,h}(b)$. Existentially quantifying $x$ gives (2).
Since $h\ge1$, the public word $b=0^d$ passes $C_{d,h}$, giving (3).
The complete answer vector is $\SAT(F)$ times a fixed nonzero
Boolean vector. Consequently its set of possible values has
cardinality exactly two. One stored decision bit selects the vector.
\end{proof}

\paragraph{Uniform hardness without an easy-root loophole.}
Fix $d=1,h=1$. The polynomial and source-identical reduction
$F\mapsto H_{F,1,1}$ proves that deciding the root within this
connected proper-3CNF image is NP-complete, using the standard
NP-completeness of ordinary proper 3SAT. Unlike the earlier OR-guard
families, the root is UNSAT whenever $F$ is UNSAT; no common
source-independent satisfying root witness exists.
At $h=2^d$, \emph{all} $2^d$ boundary membership questions equal
$\SAT(F)$, although the parent decision is exactly as hard as $F$.
This does not make $\SAT(F)$ free. It proves that projected-hard
cardinality, even accompanied by an NP-complete root and connectivity,
cannot be interpreted as independent decisions.

\section{Exact opposite-label same-size control}
Use the cubic triangular-prism graph, with six vertices and nine edge
variables. At each vertex encode the parity of its three incident
edges using the four proper ternaries excluding incorrect parity.
All-zero vertex charges give a SAT source, and one flipped vertex
charge gives an UNSAT source. Both have the same nine variables,
24 clauses, unsigned incidence, and encoding length, and both are
handled by the same compiler. For $d=3,h=4$, both compiled parents
have 31 variables and 82 proper ternary clauses. Their pinned
spectra are respectively $(1,1,1,1,0,0,0,0)$ and the all-zero
eight-bit vector. A source-aware parity scanner solves this special
pair cheaply; NP-completeness of the unrestricted root image does
\emph{not} assert that this particular pair is hard.

\section{Adaptive policy and complete resource ledger}
An exact control policy receives the actual clause source, current
representation, partial assignments, cache, and remaining budget,
without knowing the SAT label. It first tries and verifies an
all-zero witness, paying source/header reads and failed checks,
then switches to complete DPLL if unsuccessful. The independent
audit invokes the same policy on each pinned child, with pins
physically enforced. Alternative SCC, Horn, affine, memoized, cached
or source-decide-first implementations remain legal: this finite
policy menu cannot cover all deciders.

The typed vector is
\[
 (U,R_{\mathrm{src}},R_{\mathrm{work}},W_{\mathrm{work}},
 \Delta_{\mathrm{state}},S_{\mathrm{peak}},BT,
 L_{\mathrm{program}},L_{\mathrm{representation}}),
\quad BT=\sum_j S_{\mathrm{live}}(j).
\]
Every primitive operation, including unchanged writes, source
queries, control, addressing, switches, generated children, and
compatibility/reconstruction is charged. The Python audit measures
formula truth, method switches, clauses and DPLL nodes, \emph{not}
actual FLMV elementary bit work, complete-state flips, peak live
writable bits or physical bit-time; no fictional zero values are
assigned to uninstrumented metrics. Source-prefix recognition
of the canonical image is itself charged. An all-input fallback
outside the image can retain the original worst-case exponent,
so this construction gives no ARC improvement.
