\section{One fixed length-indexed proof calculus}
Fix a sound recursively axiomatized arithmetic theory T with polynomial-time proof checking and enough arithmetic to formalize CNF evaluation and a universal deterministic machine. Let $\mathrm{Ref}^{-}_{e,N}$ assert that for all $x$ of encoded length at most N, any locally checked rejecting execution of machine e on valid CNF x implies no satisfying assignment exists for x.
\begin{theorem}[Fixed sound certificate calculus]
A single complete sound proof system $R_T^{\mathrm{len}}$ accepts ordinary Resolution certificates or a tuple $(e,N,\delta,1^t)$ where $\delta$ is a genuine T-proof of $\mathrm{Ref}^{-}_{e,N}$ and a universal interpreter confirms that e rejects the actual valid F of length at most N within the unary clock t. This system has polynomial-time proof verification and certificate length $O(|F|+|e|+\log(N+2)+|\delta|+t)$; it charges the certificate, theorem checker, input and execution trace rather than assigning the whole step unit cost.
\end{theorem}
\begin{proof}
Resolution ensures completeness. The reflection track verifies T proof syntax, the exact theorem statement, the valid source input and length bound, then simulates e using a unary clock. If the trace rejects, external T soundness entails UNSAT(F). Each check is polynomial in the encoded certificate length. On malformed sources the verifier rejects; no SAT/equivalence oracle is used. The certificate-checking computation can be unrolled as a paid primitive derivation DAG.
\end{proof}
\begin{theorem}[Weaker sufficient B3 premise]
Assume SAT in P entails the existence of \emph{one} total polynomial-time correct SAT decider A and a polynomial p such that for every N, T has a proof $\delta_{A,N}$ of $\mathrm{Ref}^{-}_{A,N}$ with $|\delta_{A,N}|\le p(N)$. Then $R_T^{\mathrm{len}}$ has polynomial worst-case minimum proof work. Any fixed R with a polynomial, evidence-charged simulation of $R_T^{\mathrm{len}}$ satisfies B3. Global T-provability of the all-length soundness of A is not needed, and proof discovery is free.
\end{theorem}
\begin{proof}
For each UNSAT F of length N choose the supplied finite reflection proof and a unary-clocked polynomial rejecting run of A(F). Their encoded length and verification work are bounded by one fixed polynomial in N. Take maxima over F. No assumption currently establishes this premise for the selected $R_{\rm mix341}$.
\end{proof}
\section{Finite/global provability separation}
Fix consistent sound T satisfying second incompleteness hypotheses, and a total exact brute-force SAT decider B whose correctness is T-provable. Permit one syntactically valid padded SAT sentinel $s_N$ of every sufficiently large encoded length N. Let $V_T(k)$ check whether binary integer k encodes a T-proof of contradiction. Define a single total machine
\[
A_T(x)=
\begin{cases}
\mathrm{UNSAT},&x=s_{|x|}\ \wedge\ V_T(\operatorname{bin}|x|)=1,\\
B(x),&\mathrm{otherwise}.
\end{cases}
\]
\begin{theorem}[Separation of all-length and length-N certificates]
(i) If T is consistent, $A_T$ decides SAT/UNSAT and malformed input correctly.
(ii) T cannot prove the global one-sided UNSAT soundness of $A_T$, assuming the formalized proof-code padding lemma.
(iii) For each concrete N, T proves $\mathrm{Ref}^{-}_{A_T,N}$.
(iv) Under the explicit local-certification hypothesis LC that concrete polynomial-time proof-checker computations have T-proofs of polynomial length, the proofs in (iii) can be chosen of length $N^{O(1)}$.
\end{theorem}
\begin{proof}
Consistency makes $V_T$ reject every proof code, so $A_T=B$. A T-proof of global soundness would imply no contradiction proof code can occur: an accepted code k beyond the fixed sentinel threshold would cause $A_T$ to reject the satisfiable $s_k$ of length k. A formalizable padding operation shifts any contradiction proof to a large valid code, giving $\operatorname{Con}(T)$, which T cannot prove by the second incompleteness theorem. For any fixed N, each of finitely many codes 0,...,N is a concrete nonproof; T proves the corresponding correct calculations and a finite disjunction that on all strings of length at most N, $A_T=B$. This proves the bounded statement. Under LC, O(N) individual calculations of bit length O(log(N+2)), followed by a finite length-case derivation, give polynomial-size proofs. The global statement does not follow.
\end{proof}
\noindent This is a genuine separation between required \emph{certificate types}, not an unconditional P versus NP implication. $A_T$ is not claimed polynomial-time. The polynomial bounded-reflection condition for a hypothetical P solver, the B3 bridge for the same mixed system, and superpolynomial $\overline W_R$ all remain OPEN.
