\section{Quantifiers and four preregistered falsifiers}
A source $F$ is a canonically encoded proper signed exact-$(2,2)$ 3CNF with $n$ active original names, $m$ three-distinct-variable clauses, two positive and two negative literal occurrences per name, and physical source length $N$. Original source byte offsets are immutable; residuals are ordinary CNFs and need not preserve the exact-$(2,2)$ promise. Clause-monotone exact-$(2,2)$ is a strict syntactic subfamily, not a synonym for signed exact-$(2,2)$, and no ordinary-input reduction is granted for free.

Before literature/source search the hypotheses were: \textbf{H1}, greedy disjoint-clause matching has $h\ge2n/15$ under exact signed occurrence, permitting an authenticated seven-way pruning per selected clause; \textbf{H2}, two true hereditary branching levels can be replayed without calling SAT on the parent; \textbf{H3}, the resulting refutation is polynomial in physical input bits or meets the conditional van Melkebeek coNTIME frontier; \textbf{H4}, a compact witness-verifier circuit yields the full SAT decision circuit. H1 and H2 are \textbf{PROVED/EXACT} within the declared grammar. H3 and H4 are \textbf{FALSIFIED AS INFERENCES}.

\section{Matching and source-authenticated tree}
\begin{lemma}[Greedy source-clause packing]\label{lem:match}
If an $m$-clause proper ternary formula has maximum distinct-clause variable degree $\Delta$, greedily selecting a clause and deleting every clause sharing one of its three names produces $h$ variable-disjoint clauses satisfying
\[
h\ge\left\lceil\frac{m}{3\Delta-2}\right\rceil.
\]
For proper signed exact-$(2,2)$, $3m=4n$, $\Delta=4$, hence
\[
\boxed{\lceil2n/15\rceil\le h\le n/3.}\tag{1}
\]
The algorithm and its original source-offset index are constructible in polynomial source-bit time.
\end{lemma}
\begin{proof}
One selected clause and its overlapping neighbors remove at most $1+3(\Delta-1)=3\Delta-2$ clauses. Every source clause is eventually removed. Pairwise disjoint three-variable supports consume exactly $3h$ distinct original names. Four signed occurrences per name and three per clause give $4n=3m$. No exact-$(2,2)$ inheritance by descendants is claimed.
\end{proof}

Use the exact role-3 source-authenticated grammar: $\mathsf{BRANCH}(x,P_0,P_1)$ retains both assignments to a not-yet-pinned original name; $\mathsf{EMPTY}(p)$ is accepted only if the \emph{actual} original source clause beginning at physical byte offset $p$ is falsified by all current branch literals. Every original source read, parsed offset, node, rejected branch and proof output bit is charged. No call to a parent SAT machine or semantic oracle occurs.

\begin{theorem}[Packed BRANCH/EMPTY refutation]\label{th:pack}
For every proper signed exact-$(2,2)$ ternary $F$ and every greedily obtained matching of $h$ clauses, a single uniform source algorithm, on UNSAT $F$, produces a sound authenticated BRANCH/EMPTY tree with exactly
\[
L(h,n)=\sum_{i=0}^{h-1}7^i+7^h2^{n-3h}
=\frac{7^h-1}{6}+7^h2^{n-3h}\tag{2}
\]
leaves, $2L-1$ nodes, and a simple checked encoding of $O(nL\log(N+2))$ bits. On SAT sources the same algorithm finds a true satisfying assignment and never incorrectly accepts an UNSAT proof. It admits a $\operatorname{poly}(N)L$ deterministic time upper envelope and $\operatorname{poly}(N)$ simultaneous peak writable bits in an indexed read-only-input machine with a separate, never-reread output stream.
\end{theorem}
\begin{proof}
In a fixed order branch on the three original variables in each selected clause. Exactly one of its eight local assignments falsifies the selected three-distinct-variable clause; stop that binary subtree with $\mathsf{EMPTY}(p)$ using the \emph{authenticated original} physical source clause. Continue the other seven assignments to the next matched clause. After $h$ clauses, $7^h$ partial assignments survive. On each, assign the remaining $n-3h$ names in a complete binary tree. At each full assignment inspect the original source: emit $\mathsf{EMPTY}(p)$ for a genuinely false clause, or exhibit the actual satisfying assignment. If $F$ is UNSAT every complete assignment falsifies some original clause, so all leaves are valid and all binary joins certify UNSAT. If $F$ is SAT, one actual model satisfies each selected clause and survives all seven-way filters, so its full assignment appears and defeats an UNSAT assertion.

The $i$th selected clause contributes exactly $7^i$ immediately falsified leaves; the suffix contributes $7^h2^{n-3h}$. A full binary tree has $2L-1$ nodes. Each branch token carries one original name/bit and each terminal carries an original byte offset, with $O(\log(N+2))$ bits per name or pointer. A deterministic depth-first traversal keeps at most $n$ branch frames, polynomial-size counters/directory, and no readable output buffer; all $O(L)$ leaves can be checked in polynomial source-bit time each. This proves soundness, completeness, output bounds and simultaneous charged upper envelopes.
\end{proof}

\begin{corollary}[Explicit exponential, not polynomial, bound]\label{cor:alpha}
Put
\[
\alpha=1+\frac{2}{15}\log_2(7/8)=0.9743139896076806\ldots,
\quad 2^\alpha=1.9647067447612432\ldots.
\]
Then
\[
\boxed{L(h,n)\le\frac76\,2^n(7/8)^h
\le\frac76\,2^{\alpha n}.}\tag{3}
\]
For a conventional unpadded exact-$(2,2)$ source encoding $N=\Theta(n\log n)$, this certified \emph{upper} bound is exponential in $N/\log N$ and supplies neither a polynomial certificate cap nor a lower bound on optimal algorithms.
\end{corollary}
\begin{proof}
Because $n-3h\ge0$, the suffix term $7^h2^{n-3h}$ is at least $7^h$, exceeding six times the preceding geometric-sum coefficient. Thus $L\le(7/6)7^h2^{n-3h}=(7/6)2^n(7/8)^h$; use $h\ge2n/15$.
\end{proof}
