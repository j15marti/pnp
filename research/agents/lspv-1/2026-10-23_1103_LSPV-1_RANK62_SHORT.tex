\section*{RANK62: Affine observation amortization}
P versus NP remains OPEN.
Let $b\in\mathbb F_2^q$ encode the orientation of the known implication ladder
$F_b=(z_0)\wedge(\neg z_q)\wedge\bigwedge_i C_i(b_i)$,
where $C_i(1)=(\neg z_{i-1}\vee z_i)$ and
$C_i(0)=(\neg z_{i-1}\vee\neg z_i)$.
The input is UNSAT exactly when $b=1^q$:
all positive edges propagate $z_q=1$, and at the first negative edge,
assign earlier variables one and subsequent variables zero.
The declared observation calculus receives only adaptively selected
linear parity answers $a\cdot b$; arbitrary row operations are permitted.
Define $\rho=q-\operatorname{rank}_{\mathbb F_2}(A)$ for the matrix
$A$ of queried rows.
\begin{theorem}
Every deterministic exact algorithm in this calculus requires $q$
linearly independent query answers on $b=1^q$. A parity answer decreases
$\rho$ by at most one, and linear combinations decrease it by zero.
\end{theorem}
\begin{proof}
If $\rho>0$, choose $0\ne u\in\ker A$.
Then $1^q+u$ produces the identical adaptive transcript, but is SAT.
The algorithm cannot decide before $\rho=0$. Coordinate queries match
the lower bound.
\end{proof}
For 2-CNF plus $k$ ternary clauses, assigning a variable from a live
ternary decreases the live-ternary count exactly by the number of
incident ternary clauses. A depth-$k$ branching algorithm with SCC 2-SAT
leaves uses at most $2^{k+1}-1$ nodes, giving the established
$2^k\operatorname{poly}(N)$ upper bound, not a lower bound.
A binary backbone enforcing $x=y=z$ is individually compatible with
$T_+=(x\vee y\vee z)$ and $T_-=(\neg x\vee\neg y\vee\neg z)$
but incompatible with both. The minimum ternary-variable transversal
remains one. This is an exact first interaction at $k=2$,
but source-aware equality reasoning solves it in linear time.
The parity-query restriction does not cover general nonlinear operations,
SCC, Horn, Gaussian elimination on explicit source, CDCL, caching,
or decide-first normalization. No unrestricted superpolynomial
deterministic SAT lower bound follows. P versus NP remains OPEN.
