\section{FLMV's tape-position space gauge}
FLMV Section 2.1 permits indexed work tapes and indexed access to the read-only original input. Its work-tape space contribution is the \emph{largest work-tape position ever read/indexed}, not just the current number of nonblank cells or abstract live values. Writable index tapes count too. Changed and unchanged writes, original reads, index formation, control and generator work cost actual time. Bit flips, bit-time and hardware are separate resources.

\begin{lemma}[One remote cell is not one bit of FLMV space]\label{lem:far}
For each $N$, a fixed total uniform machine may perform an auxiliary indexed read of work-tape position $P(N)=\lceil N^{3/4}\rceil$ while storing only one auxiliary value bit, with $O(\operatorname{polylog}N)$ address preparation. Its FLMV work-tape space is nevertheless at least $P(N)$. The auxiliary operation may be prepended to any exact total SAT machine without changing its output.
\end{lemma}
\begin{proof}
Construct $P(N)$ in binary on an index tape with charged arithmetic, index a blank work tape to that coordinate, read the cell, optionally write and later erase a marker, then run the original program ignoring the cell's value. A single work-tape read at coordinate $P(N)$ already contributes space $\Omega(P(N))$. No further nonblank data are required. This is a warning about an implementation, not an unavoidable cost for an arbitrary SAT decider.
\end{proof}
Thus a claimed $s'=1/2$ based only on a few simultaneously nonblank cells can fail badly if its \emph{physical} guest, cache or ancestor tape layout touches a coordinate $N^{3/4}$. A verified dense layout avoids this particular issue.

\section{Resetless sequential guest composition: exact compiler}
Suppose one fixed parent policy makes polynomially many calls to the same total guest $A$ on true ordinary (not descriptor-only) child strings. A direct reuse of dirty guest tapes would violate $A$'s blank-input-tape precondition; wiping every visited tape prefix can cost one guest space bound per call. The following exact epoch-tag simulation is an alternative.

\begin{theorem}[FLMV epoch-tagged tape compiler]\label{th:tag}
Fix a deterministic uniform total ordinary-SAT decider $A$ with simultaneous all-input bounds
\[
T_A(M)\le M^{t+o(1)},\qquad S_A(M)\le M^{s+o(1)}.
\]
Suppose one fixed uniform total root policy makes at most $Q(N)\le N^{a+o(1)}$ \emph{sequential} calls to $A$ on proper ordinary SAT encodings of length $L(N)\le N^{\lambda+o(1)}$. Each requested guest-input bit is produced by a fixed \emph{total} virtual generator in at most $G(N)\le N^{g+o(1)}$ counted root steps and at most $N^{\eta+o(1)}$ work/index space, \emph{including all nested virtual probes, source reads, address arithmetic, and required generator reset}. Other source parsing, policy/discovery, strategy switching/failure, child eligibility and exact both-label join cost at most $N^{r+o(1)}$ root time. Ancestors, selectors, caches and parent state retained simultaneously occupy at most $N^{\kappa+o(1)}$ work/index space. The guest has a fixed finite number of tapes, and a computable polynomial bound on total calls is part of the compiler contract.

There is one fixed deterministic uniform FLMV implementation of this \emph{declared} exact policy with logically fresh guest work \emph{and index} tapes at every call, without paying a separate $Q(N)S_A(L)$ reset cost. Its conservative exponent envelope is
\[
\boxed{\quad
t'\le\max\{r,a+\lambda t+g\},\qquad
s'\le\max\{\kappa,\eta,\lambda s,0\}.
\quad}\tag{1}
\]
All resource coordinates belong to this \emph{same compiled machine}. The theorem is purely a conditional simulator and does not provide an eligible normalizer, power-short children or ARC-EDGE-90.
\end{theorem}
\begin{proof}
Fix a constant integer $C>a+2$ making $Q(N)<(N+2)^C$ for all sufficiently large $N$, adjusting $C$ for finitely many smaller inputs. Set an epoch width $w=\lceil C\log_2(N+2)\rceil+O(1)$. On each simulated work tape and simulated guest index tape, represent logical cell $j$ by a physical block of $w$ epoch bits and a constant-sized symbol field, at physical coordinate $O(jw)$. The parent stores one $w$-bit epoch number. Initially all physical tags are zero.

Before call $i$, increment the epoch to $i\ge1$. A logical read decodes a stored symbol only when the tag equals $i$; for every stale tag it returns the logical blank symbol. On every guest write, set both current tag and value, charging \emph{all} read/write operations, including unchanged bits. Epochs do not repeat before the polynomial call bound, hence each guest observes exactly fresh blank work/index tapes. No prior work prefix is wiped. Reading/erasing an index tape and performing an indexed jump are simulated with explicit tag checks and binary address arithmetic; both have polylogarithmic overhead per guest primitive step. The guest input is a logically read-only virtual string: each actual input probe invokes the \emph{charged} root-source bit generator. The guest output/accept state is passed to the parent, not stored for free on the one-directional write-only output tape.

The number of guest input probes is at most its counted $T_A(L)$. Hence the total number of root steps is
\[
O\!\left(
\left[N^{r+o(1)}
+Q(N)\bigl(T_A(L)(G(N)+1)+1\bigr)\right]\operatorname{polylog}N
\right),
\]
which gives the time envelope. As a guest's highest indexed/read position is at most $S_A(L)$, each physical guest tape reaches at most $O((S_A(L)+1)\log N)$ cells. There are only finitely many fixed guest tapes. Generator and ancestor work/index state remain live while the guest runs, so the same-machine peak is bounded by their sum, whose polynomial exponent is the maximum shown in (1). This includes tag registers and arithmetic. The algorithm is total and exact \emph{provided} the stipulated policy, exact ordinary children and bit generator are actually total and exact.
\end{proof}

\paragraph{Falsifiers and scope.}
One parent-scale call to the base machine $A$ has to be separately charged at $N^{t+o(1)}$ time and $N^{s+o(1)}$ peak space, and cannot be hidden in the shorter-child terms. Failed strategies count toward $Q,r,\kappa$. An eager full child serialization costs its generated header/body bits and any readable buffer. If child promises are not inherited under actual restriction, or generator/selector uses free SAT labels, the theorem's semantic premise is false. Epoch wrap, a call count without a proved polynomial bound, a hidden virtual-tape oracle or an uncharged guest-state cache also invalidate the stated compiler. A $C_\star$-only upper bound does not transport to ordinary SAT without a paid reduction. This compiler can avoid an \emph{implementation} tape-cleanup term, but cannot eliminate any source SAT reasoning.
