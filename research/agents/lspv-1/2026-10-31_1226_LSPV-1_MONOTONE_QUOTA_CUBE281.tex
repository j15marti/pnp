\section{One NP-complete target and four falsifiers}

\section{Exact original-source partial-cube theorem}
Let $F$ have $n$ original variables and $m_+=m_-=2n/3$
positive and negative source clauses. Let $\rho$ be a coherent partial
assignment fixing $t$ original variables TRUE and $f$ FALSE.
For $s=-$, let $q_{r,-}(\rho)$ count negative original clauses with exactly
$r\in\{0,1,2,3\}$ literals not already fixed FALSE by $\rho$.
Define $q_{r,+}$ analogously for positive clauses. An unassigned literal
is \emph{not} fixed FALSE; $q_{0,s}$ counts actual falsified
original clauses and carries its original clause indices.

\begin{theorem}[Signed occurrence conservation and subsumed quotas]
For every canonical source $F$ and every coherent $\rho$,
\[
\boxed{q_{0,-}=2\left(t-\frac{2n}{3}\right)+q_{2,-}+2q_{3,-},}
\qquad
\boxed{q_{0,+}=2\left(f-\frac{2n}{3}\right)+q_{2,+}+2q_{3,+}.}
\]
Thus $t>2n/3$ forces at least $2(t-2n/3)$ \emph{specific}
falsified original negative clauses, and $f>2n/3$ forces
at least $2(f-2n/3)$ falsified original positive clauses.
A residual policy already rejecting every cube falsifying an original
clause gains no extra prohibited cube from either weight threshold.
The converse is false: for any valid $n\ge6$ source, fixing
the three variables of one negative original clause to TRUE falsifies
it while $t=3\le2n/3$; the positive analogue fixes them FALSE.
\end{theorem}
\begin{proof}
Every source variable appears twice negatively, so the $t$ fixed TRUE
variables falsify exactly $2t$ negative literal occurrences.
Consequently
\[
\sum_{r=0}^3q_{r,-}=\frac{2n}{3},
\qquad \sum_{r=0}^3r q_{r,-}=2n-2t.
\]
Subtracting these equalities and isolating $q_{0,-}$ gives
the first identity. Repeating with the $2f$ fixed-FALSE
positive occurrences proves the second. Since $q_2,q_3$
are nonnegative, quota violation already implies an
original source clause with all three literals fixed FALSE,
which direct UP/DPLL detects. A single locally falsified
clause witnesses the converse. No occurrence was assigned
independently of its original variable.
\end{proof}

\begin{theorem}[Formula-independent endpoint and first-flip histograms]
For every well-formed source $F$ and every original variable $i$,
where $N_r(a)$ is the number of original clauses with $r$ TRUE literals,
\[
\mathbf N(0^n)=\mathbf N(1^n)
=\left(\frac{2n}{3},0,0,\frac{2n}{3}\right),
\quad
\mathbf N(0^n\oplus\{i\})=\mathbf N(1^n\oplus\{i\})
=\left(\frac{2n}{3}-2,2,2,\frac{2n}{3}-2\right).
\]
Therefore an algorithm observing only those four-bucket
histograms cannot distinguish equal-size opposite-label
canonical sources. This says nothing about algorithms using
source clause identities, deeper flips or proof search.
\end{theorem}
\begin{proof}
At all zero, all positive clauses have zero TRUE literals and all
negative clauses have three; all one swaps them. Every variable
appears twice under each sign in separate source clauses, so
one flip changes exactly two $0\to1$ and two $3\to2$
clauses (or the complementary reverse).
\end{proof}

\section{Adversarial original-clause S/U and proof certificates}
Each original indexed signed occurrence has a local all-TRUE
target $S_j$, inverted all-FALSE target $U_j$, and the inverse
mapping $U_j\mapsto S_j$. For clause pair $(j,k)$, the source-pair
compatibility matrix stores all four $(SS,SU,US,UU)$ cells;
$SS,UU$ are feasible iff no opposite-sign shared variable,
and $SU,US$ iff no same-sign shared variable.
The complete lexicographic source-indexed matrix is encoded
with mask bits $(1,2,4,8)$, with no source occurrence treated
as an independent variable. Opposing source parents
$(x\vee A)$ and $(\neg x\vee B)$ produce the standard
non-tautological resolvent $A\vee B$ and its
source-indexed impossible partial cube. These controls are
known resolution and conflict-graph consequences and are
not the primary new research route.
