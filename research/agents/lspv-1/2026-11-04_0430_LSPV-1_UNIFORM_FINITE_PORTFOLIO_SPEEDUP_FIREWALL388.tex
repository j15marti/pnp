\section*{The known speedup input}
Use a fixed acceptable deterministic multitape programming system on canonical binary encodings $b(n)$ of nonnegative integers, with measured bit-operation time $T_i(b(n))$. Blum's Speedup Theorem (J. ACM 1967, Theorem 5) states that for any total recursive function $r(n,t)$ there is one total recursive Boolean predicate $f$ satisfying
\[
\forall i\;[\varphi_i=f]\;\exists j\;[\varphi_j=f]\;\exists n_0\;\forall n\ge n_0:
T_i(b(n))>r(n,T_j(b(n))).
\]
The theorem is KNOWN, not re-proved or claimed new. Fix $r(n,t)=2^{n+t+10}$ and the corresponding one $f$. Define a total three-label binary classifier $L_f$: on the canonical $b(n)$ return YES/NO according to $f(n)$; on empty strings or strings starting with 0 except the singleton $0$, return MALFORMED. Parsing the malformed prefix costs $O(1)$ in the declared input-head model.

\begin{theorem}[Derived all-binary finite-portfolio speedup firewall]
For this one decidable three-label language $L_f$, for every fixed $k\ge1$ and every $k$ fixed total exact uniform deterministic all-binary deciders $A_1,\ldots,A_k$, there exists one further total exact uniform deterministic all-binary decider $B$ and threshold $N_0$ such that
\[
\forall n\ge n_0:\quad T_B(b(n))<\min_{i\le k}T_{A_i}(b(n)),
\]
and also, with $T_A^{\rm wc}(N)=\max_{x\in\{0,1\}^{\le N}}T_A(x)$,
\[
\boxed{\forall N\ge N_0:\quad T_B^{\rm wc}(N)<\min_{i\le k}T_{A_i}^{\rm wc}(N).}
\]
Every program is fixed before the quantified input lengths; no per-$N$ machine, advice, or answer table is used.
\end{theorem}
\begin{proof}
Fix the finite portfolio. A single fixed machine $P$ computes $f$ by dovetailing the $k$ correct $A_i$ on the \emph{same} canonical $b(n)$ and returning the first answer. Since all answer correctly, there is a fixed monotone polynomial $Q_k$ depending only on those programs with
\[
T_P(b(n))\le Q_k\bigl(|b(n)|+1+\min_iT_{A_i}(b(n))\bigr).
\]
Blum's theorem applied to this particular uniform $P$ produces one program $J$ computing $f$ with, for all sufficiently large $n$,
\[
T_P(b(n))>2^{n+T_J(b(n))+10}.
\]
Hardwire $J$ in a fixed all-binary classifier $B$: reject the malformed prefix in constant time and otherwise run $J$. On canonical inputs $T_B(b(n))\le T_J(b(n))+c_J$ with a constant fixed by the machine implementation (polynomial fixed-compiler overhead would also be absorbed). If for infinitely many arbitrarily large $n$ some $A_i$ were no slower than $B$, the race bound would imply
\[
2^{n+T_J(b(n))+10}
<Q_k\bigl(O(\log n)+T_J(b(n))+c_J\bigr),
\]
contradicting exponential dominance over the fixed polynomial for every value $T_J(b(n))\ge0$ and all sufficiently large $n$. Hence one fixed $B$ eventually beats all $A_i$ on every canonical string.

Blum speedup applied to $J$ itself implies $T_J(b(n))$ is unbounded: a bounded running time cannot exceed $2^{n+T_{J'}(b(n))+10}$ eventually. $B$ has constant malformed-input cost and therefore its worst-case prefix maximum, for all sufficiently large $N$, is reached at some canonical $b(n_N)$ with $n_N$ above the pointwise threshold. For each $i$,
\[
T_{A_i}^{\rm wc}(N)\ge T_{A_i}(b(n_N))>T_B(b(n_N))=T_B^{\rm wc}(N).
\]
This maximization genuinely includes every binary string, including malformed cases. \qed
\end{proof}

\section*{Four explicit falsifiers and limits}
\noindent\textbf{F1 FALSIFIED (general decidable languages):} a single asymptotically fastest uniform correct algorithm, or any finite fixed menu realizing it, must always exist. Blum plus the corollary provides one decidable counterexample.

\noindent\textbf{F2 FALSIFIED (quantifier attack):} the faster algorithm here is reselected per input or per length. The actual quantifiers are $\exists L_f\;\forall k,\mathbf A\;\exists B,N_0\;\forall N\ge N_0$. The improvement is a single uniform total machine for each fixed finite menu.

\noindent\textbf{F3 NOT ESTABLISHED for SAT:} the theorem's existential pathological language is not SAT. Whether SAT admits Blum-type universal speedup is not proved, and no implication from restricted Resolution hardness to machine hardness is claimed.

\noindent\textbf{F4 NOT ESTABLISHED for space or mixed-proof cost:} neither peak space nor sound R-proof simulation follows. The dovetail machine's own time, input access, program simulation, output and all live state must be charged. A theorem about runtime on $L_f$ supplies no FLMV same-machine bound.
