\section{Exact language, model and falsifiers}
Let $L$ contain exactly valid satisfiable duplicate-free proper D\"ocker
monotone 3-SAT-(2,2) originals and reject all malformed encodings.
Each clause contains three distinct all-positive or all-negative literals;
each variable appears exactly twice in each polarity. Write the binary
encoding as Elias-gamma headers $\gamma(n),\gamma(m)$ followed by $m$
sign-plus-three-ID records, with $b(n)=\lceil\log_2(n+1)\rceil$ bits per ID:
\[
N(n,m)=|\gamma(n)|+|\gamma(m)|+m(1+3b(n)).
\tag{1}
\]
The machine has finite control, read-only input and ordinary work/index
tapes. Charge source-bit reads, head/index movement, grammar/parsing,
all attempted policies and switches, proof/GE/cache/replay/guest work,
output and simultaneous peak writable space. Logical XOR is offline only.

Falsifiers: (F1) the designated U198 source is malformed or SAT;
(F2) disjoint union violates canonical quotas; (F3) early prefix rejection
can reject some valid SAT original; (F4) parser/head/index work must
access a linear fraction of the source. All were attacked.

The exact source $U$ is the previously independently verified canonical
$198$-variable, $264$-clause UNSAT instance at
\path{experiments/arc/lspv2_296/U198.txt}; its complete $64$-separator-row
certificate was independently replayed in this run (6,717 assertion
groups, 152 module checks, 493,674 local DPLL nodes). The independent
valid SAT $F9$ source has $n=9,m=12$ and 70 satisfying assignments.
Construct for each $t\ge0$ the \emph{original} formula
\[
F_t=U\sqcup F9_1\sqcup\cdots\sqcup F9_t,\quad
n_t=198+9t,\quad m_t=264+12t.
\tag{2}
\]
All variable supports are disjoint, and the source serialization puts the
264 unchanged signed clauses of $U$ first. The language does not require
connected originals. Children may be noncanonical.

\begin{theorem}[UNSAT-PREFIX-DECISION311]
There exists one deterministic total correct all-binary-input decider
$D\in\operatorname{Dec}(L)$, independent of $t$, such that \emph{every}
$F_t$ is a valid UNSAT canonical original and the number of distinct
source bits inspected on its actual execution is exactly
\[
Q_D(E(F_t))=
|\gamma(n_t)|+|\gamma(m_t)|+264(1+3b(n_t))=O(\log N_t),
\quad N_t=|E(F_t)|=\Theta(t\log t).
\tag{3}
\]
On a fixed-tape indexed-input TM, a conservative straightforward
implementation satisfies, on this same infinite family,
\[
T_D(E(F_t))=O((\log N_t)^2),\qquad
S_{\rm peak,D}(E(F_t))=O(\log N_t).
\tag{4}
\]
No assignment recovery, residual key, semantic oracle, policy-best
oracle or size-dependent machine advice is used.
\end{theorem}
\begin{proof}
The disjoint source (2) is valid: signed occurrence quotas, three
distinct literals, monotonicity and duplicate-freeness are preserved by
disjoint union. It is UNSAT because its unchanged original subformula
$U$ is independently certified UNSAT.

Construct the following single finite program $D$. Its finite control
holds the 264 signed triples of $U$ and the fixed source UNSAT
certificate. Decode the gamma headers. If $n\ge198,m\ge264$, compare
the first 264 complete fixed-width records with those triples; on
an exact match output $0$ immediately. Otherwise rewind and run an
all-input total fallback: parse and authenticate the \emph{entire}
canonical grammar, rejecting malformed strings, then enumerate the
$2^n$ assignments and accept precisely when one satisfies all original
clauses. If the prefix matches, no completion of the source can be
SAT, regardless of whether the untouched suffix is valid or malformed.
If the prefix fails, fallback correctness is immediate. Both routes
halt, so this is a correct decider for \emph{every} binary input.

On $E(F_t)$ the prefix route succeeds. It reads exactly the two headers
and 264 fixed-size records, giving (3), whereas the full length grows
as $\Theta(t\log t)$. Decoding and comparing $O(\log t)$ bits with
$O(\log t)$ binary counters costs conservatively $O(\log^2t)$
native indexed-tape steps and $O(\log t)$ live bits. The hardwired fixed
certificate/program contributes a constant machine-description cost,
independent of $t$; it is not input-dependent advice. The decision output
is one bit and no suffix needs to be read.
\end{proof}

\begin{corollary}[Retired pointwise UNSAT floors]
For every $\epsilon>0$ the assertion that \emph{every} all-input
correct decider must expend $\Omega(N^\epsilon)$ time (or even a
linear fraction of source probes) on \emph{every sufficiently large}
valid UNSAT original is FALSE. The result does \emph{not} disprove the
worst-case quantifiers $\forall D\,\exists$ arbitrarily large hard
inputs, and the all-input polynomial-time problem remains OPEN.
\end{corollary}

\section{Adaptive controller and complete ledger}
For a fixed authenticated original $F$, coherent pins $p$, dynamic
certified parameter vector $\kappa$, proof DAG $\Pi$ and actual cache
$C$, the executable selector can use signed-spill/slack, saturated-cycle
GF(2), odd-cycle/K4, matroid, Horn/2SAT/XOR, typed AND/OR,
semantic transfer and exact fallback. An exact work recurrence is
\[
 W_D(z)=C_{\rm grammar/source/head/index}
 +\sum_{\pi\in\mathrm{attempted}(z)}C_{\rm acquire/select/switch/fail}(\pi)
 +C_{\rm proof/GE/cache/replay/guest/output}
 +\sum_{y\in\mathrm{executedChildren}(z)}
 (C_{\rm child}(z,y)+W_D(y)).
\tag{5}
\]
SAT requires an original-clause checked witness. UNSAT requires complete
checked coverage (or an authenticated contradictory original subformula).
Ordinary residuals need not be canonical, and any target-language child
requires paid proof-carrying reencoding. Exact fallback has a well-founded
decrease in free original-variable support even when $\delta$ increases,
but may use exponentially many total nodes. Peak space sums all
simultaneously live writable/index/ancestor/guest/cache/proof cells, not
independent maxima. On the prefix family there are no explored children,
failed policies, GE, guest calls or dynamic caches; all source parsing
and index work in (3)--(4) remains paid. A fixed source-certificate
checker can be executed at constant per-instance cost if requested.
