\section{Definitions and complete entropy argument}
The input is an immutable canonically encoded proper signed exact-$(2,2)$
ternary formula $F$ with each original name twice positive and twice
negative and three distinct names per clause. Its physical length is $N$,
its clause count is $m=4n/3$. Clause-monotone exact-$(2,2)$ is separately
a syntactic subfamily, for which the same result holds. The theorem
does not assert a free reduction from every ordinary CNF.

Fix a permutation $(v_1,\ldots,v_n)$ before reading branch values. Let
$S_k=\{v_1,\ldots,v_k\}$ and let $A_k$ be the set of assignments to $S_k$
that do not completely falsify any authentic original source clause.
Write $P_k=|A_k|$ and let $f_k$ be the number of clauses whose complete
three-name support lies in $S_k$.

\begin{lemma}[Shearer, with proof]
If each coordinate of a random vector $X=(X_1,\ldots,X_k)$ occurs in
at least $d$ subsets $E_1,\ldots,E_m\subseteq[k]$, then
$dH(X)\le\sum_i H(X_{E_i})$.
\end{lemma}
\begin{proof}
The chain rule, followed by conditioning monotonicity, gives
$H(X_{E_i})\ge\sum_{j\in E_i}H(X_j\mid X_{[j-1]})$ for any fixed
coordinate order. Sum over $i$. Each coordinate's nonnegative
conditional entropy occurs at least $d$ times, so the sum is at least
$d\sum_j H(X_j\mid X_{[j-1]})=dH(X)$.
\end{proof}

\begin{theorem}[All-prefix entropy frontier]\label{t:entropy}
For every proper signed exact-$(2,2)$ three-CNF $F$, every
branch-independent variable permutation, and every $0\le k\le n$,
\[
\boxed{P_k^4 8^{f_k}\le 2^{4k}7^{f_k}},\qquad
\boxed{P_k\le 7^{n/3}(4/7)^{n-k}}.
\tag{1}
\]
In particular $\#\mathrm{SAT}(F)=P_n\le7^{n/3}$.
\end{theorem}
\begin{proof}
If $P_k=0$ there is nothing to prove. Otherwise select $X$ uniformly
from $A_k$. Each original clause $C_i$ meets $S_k$ in $\ell_i\le3$
names. Its projection onto those names has at most $2^{\ell_i}$
possible patterns if $\ell_i<3$, and at most seven if $\ell_i=3$,
because the one falsifying pattern is excluded. Each prefix name
belongs to exactly four clauses. Shearer's lemma applied to the
intersections $\operatorname{vars}(C_i)\cap S_k$ gives
\[
4\log_2P_k \le\sum_i H(X_{\operatorname{vars}(C_i)\cap S_k})
\le \sum_i\ell_i-f_k\log_2(8/7)
=4k-f_k\log_2(8/7).
\]
The exact integer inequality in (1) follows by exponentiation.
There are $4(n-k)$ remaining literal occurrences. Every unfinished
clause contains at least one, hence
$f_k\ge m-4(n-k)$. Writing $c=\log_2(8/7)\in(0,1)$ and $m=4n/3$,
\[
\log_2P_k\le k-\tfrac14 f_k c
\le k-\tfrac14mc+(n-k)c
=\tfrac n3\log_2 7-(n-k)\log_2(7/4).
\]
Exponentiate to obtain (1). No assumption about SAT/UNSAT,
independence of clause events, or a residual exact-$(2,2)$ promise is used.
\end{proof}

\section{Constructive sound all-input proof tree}
\begin{theorem}[Authenticated bounded tree]\label{t:tree}
There is one fixed uniform deterministic source-reading algorithm
which, on any valid proper signed exact-$(2,2)$ input $F$, explores
a full-depth binary prefix decision tree of at most
\[
\boxed{U(F)\le 1+\frac83\,7^{n/3}} \tag{2}
\]
nodes. Every failed child is immediately authenticated by a physical
original source clause offset $p$ for which the entire clause is
falsified. On SAT roots the algorithm discovers a genuine full model.
On UNSAT roots a second deterministic pass emits a valid
$\mathsf{BRANCH}(v,P_0,P_1)$/$\mathsf{EMPTY}(p)$ proof of
$O(7^{n/3}\log(N+2))$ bits without a parent SAT call.
Decision and certificate-construction time is
$O(\operatorname{poly}(N)7^{n/3})$ with
$O(N\operatorname{polylog}N)$ peak indexed writable/index bits if the
certificate output is one-way and never reread.
\end{theorem}
\begin{proof}
At every locally consistent depth-$k<n$ prefix, branch on the next
fixed original name with both values. If a child falsifies an original
clause, close it with $\mathsf{EMPTY}(p)$ after reading and authenticating
the clause at $p$. Otherwise proceed. A locally consistent depth-$n$
assignment satisfies every source clause and is a genuine SAT witness.
Thus the actual number of visited tree nodes, including every failed
child and the root, is
\[
U=1+2\sum_{k=0}^{n-1}P_k
\le1+2\cdot7^{n/3}\sum_{j=1}^n(4/7)^j
<1+\frac83\,7^{n/3}.
\]
First decide the label without emitting a proof. If SAT, return its
verified witness. Only if UNSAT, repeat the same source-driven traversal
and stream the complete authenticated refutation. This two-pass
construction prevents false SAT-side proof claims and charges
certificate discovery, construction, output, and every failed trial.
Every node contains either one original variable name or original byte
offset, each $O(\log(N+2))$ bits. A conservative source rescan for
every node and a depth-$n$ ancestor stack give the asserted
time/space envelopes. All original names, sign bits, source parsing,
selector bytes, two hereditary branch levels and peak live state
are charged. The output stream is not a free re-readable child.
\end{proof}

\begin{corollary}[Exact project baseline improvement]
Put $\beta=\log_2(7)/3=0.9357849740192014\ldots$.
Then $U=2^{\beta n+O(1)}$ versus the earlier
ARC193 upper exponent
$\alpha=1+(2/15)\log_2(7/8)=0.9743139896076806\ldots$.
The improvement $\alpha-\beta=0.0385290155884792\ldots$
is exponential in active variables, but both are
$2^{\Theta(N/\log N)}$ under the canonical unpadded input encoding.
It does not prove polynomially bounded all-ordinary-UNSAT proofs.
\end{corollary}

\item[] \textbf{M1 native single writable tape:}
The input counts in physical footprint. A decision-only direct

Physically retaining a proof of length $L$ adds at least $L$
tape cells and $L$ writes; no one-tape crossing lower bound is
silently transferred to a multitape or RAM model.
\item[] \textbf{Mk native fixed-$k$ sequential-input tapes:}
All source scans, input-head travel and work visits are charged.
Space is $O(N\operatorname{polylog}N)$ distinct visited work
bits with a declared write-only proof-output port, not
unrestricted hidden replay storage.
\item[] \textbf{Indexed RAM/RAT:}
Input-address generation, actual source decoding, proof
construction, verification and peak writable/index storage
are charged on one fixed realization. The algorithm is
exponential in $n$, and therefore does not yield a polynomial
$(t,s)$ in the strict FLMV forbidden box.
\end{description}
The construction upper simulation $t_1\le t_k+\max(1,s_k)$ for

HEADMOVE-1's $H(S+1)$ and $(R+1)(S+1)$ and augmented-radius

lower bounds. The only valid coNTIME application requires a
