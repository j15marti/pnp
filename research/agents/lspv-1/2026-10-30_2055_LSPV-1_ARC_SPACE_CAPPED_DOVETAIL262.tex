\section{Deterministic residual and proof-authority contract}
The original indexed CNF $F$ is immutable. A deterministic state is
\[
 z=(F,\rho,\mathcal{D},\Pi,h,p,\mathcal{H}),\qquad
 \kappa(z)=(N,n,m,|\rho|,\text{certified class},q,B,M,\text{source probes},
 \text{failed trials},\text{proof bits},\text{guest bits},\text{peak live bits}),
\]
where $\rho$ is a coherent assignment to original variables, $\mathcal D$ contains only source-authenticated derived clauses with guards, $\Pi$ is the active policy description, $h$ the input-head state, $p$ the full proof or witness trace, and $\mathcal H$ the charged replay/selection history. The vector is \emph{measured and computed}, not an oracle. A SAT output must be a fully checked original-source witness. An UNSAT output on $F|_\rho$ must have a checked original-source refutation or an authorized correct exact decision, and exports only the blocker $B_\rho$, never an unguarded empty clause. In particular,
\[
 F|_\rho\text{ UNSAT}\iff F\models B_\rho.
\]
For $F=(x\vee y)\wedge(x\vee\neg y)$, $\rho=(x=0)$ is UNSAT although $F$ is SAT; the valid blocker is $x$.

\section{Exact finite-port\-folio theorem}
\begin{theorem}[Restarted, space-capped certified search]
Fix an ordinary source $F$ and an explicitly enumerable list $P_1,\dots,P_q$ of deterministic potentially partial programs. The output of a program is accepted only after complete source-authenticated verification of either a SAT witness or an UNSAT refutation with its assumption scope. Suppose a sequential runner can enforce at most $M$ writable work bits per trial, restart a program from its deterministic initial state, and count all simulation, original-source reads, certificate checks and output instructions in the trial's step budget. It makes no decision from a timeout. Run each $P_i$ with budgets $1,2,4,\ldots$, discarding each failed trial and retaining no candidate workspace between trials. If some $P_j$ emits a valid certificate with complete charged time $t\ge1$ and space at most $M$, then the first accepted certificate is sound, and
\[
  W_{\rm runner}<4qt
\]
counted simulated instructions, including failed trials. Its peak live memory is bounded by $M$ plus the runner's enumeration, counter and simulator overhead. With sequentially accessible immutable policy descriptions and a faithful constant-overhead executor, the additional counters occupy $O(\log(qtN))$ bits; in a nontrivial TM interpretation all emulator and address-access overhead must be charged separately.
\end{theorem}
\begin{proof}
Let $r=\lceil\log_2t\rceil$. The $j$th program completes in round $r$ at the latest. All earlier rounds and the prefix of this round execute fewer than $q\sum_{k=0}^{r}2^k<q\,2^{r+1}\le4qt$ program steps. Every accepted output has been checked against the immutable source, so both SAT and UNSAT polarity are correct. A timeout or failed checker has no authority; the old candidate's state is deleted before the next one starts. Hence memory is the maximum single-trial cap plus the charged scheduler/simulator state, not a sum of all $q$ work tapes. No claim of constant-overhead universal simulation on the indexed FLMV TM is made here.
\end{proof}
\begin{lemma}[Opaque winner tariff, both labels]
In the restricted black-box \emph{candidate-only acceptance} interface, require the deterministic scheduler to return a decision only by accepting an actually emitted valid candidate certificate and to be complete whenever at least one candidate eventually emits one. Give the scheduler no code inspection, independent source-solving or external proof-generation operation. For every such scheduler and either a SAT or an UNSAT source with an available certificate, some $q$-program portfolio forces at least $qt$ executed candidate steps before the first certificate: one hidden program emits the certificate only on its $t$th step and all other programs remain silent.
\end{lemma}
\begin{proof}
Against the transcript consisting solely of silence, select as winner the last candidate that the scheduler would give $t$ steps. Prior to this event all observations are identical. That candidate must receive $t$ steps, and every other candidate has received $t$ steps already. An appropriate witness or finite resolution refutation is hard-coded only into the winning opaque candidate. This is an interface-specific worst case, not a bound against code-reading or source-reading SAT algorithms.
\end{proof}
A complete fallback $A(F)$ can make the controller total for every fixed correct SAT decider $A$, but this full-parent call costs $T_A(N)$ and defeats the desired arbitrary-exponent contraction for DELAY$(A)$ wrappers. Dovetailing does not remove that obligation.

\section{The ARC selector tariff and exact forbidden-region comparison}
For a hypothetical ARC stage with $N^\gamma$ physically smaller guest children of size $N^\lambda$ and independent $q=N^\delta$-policy sequential selection \emph{per child}, a worst-case charged winner time of order $N^{\lambda K}$ yields the \emph{upper bound}
\[
 K'\le\max\{\alpha,\gamma+\delta+\lambda K\},
\quad K_*=\max\{\alpha,(\gamma+\delta)/(1-\lambda)\}.
\]
The opaque-winner lemma shows the factor $q$ is real in that restricted interface, not a necessary cost for an arbitrary source-aware compiler. With $\alpha=11/10,\gamma=3/5,\lambda=1/2,\sigma=1/2$ this stage's envelope has $K_*=6/5+2\delta$ for $\delta\ge0$. At the \emph{actual} FLMV test point $c=241/200$ and $d_*(c)=11642479/23232400$, strict inclusion requires
\[
 \boxed{\delta<1/400}
\]
as a necessary condition \emph{for this upper-bound certificate to suffice}, not an impossibility statement about alternative compressors. A portfolio of $N^{1/10}$ independent candidate trials per guest child cannot certify this particular recurrence in the strict box. Every parent/source scan, candidate generator, failed policy, proof checker, child-bit accessor, guest instruction, retained-ancestor bit and high-index writable-tape position still needs separate accounting. If selecting policies is instead done once per parent, or repeated work is shared, the tariff must be recomputed, not blindly multiplied into $\gamma$. The FLMV indexed random-access input model and Theorem 5.7 are the binding reference \cite{flmv}.
