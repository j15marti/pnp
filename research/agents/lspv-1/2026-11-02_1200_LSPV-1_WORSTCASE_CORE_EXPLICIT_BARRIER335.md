# LSPV-1 WORSTCASE-CORE-EXPLICIT-BARRIER335

2026-11-02 12:00 PST. Status: PROVED/EXACT elementary theorems; COMPUTATIONAL finite controls. P versus NP OPEN.

## Scope and fixed optimal-derivation model
Use arbitrary valid CNF-SAT, not the superseded monotone 2,2 restriction. Fix one sound source-labelled calculus R independently of inputs, with nonnegative weights and an acyclic inference DAG. W_R(F) is the minimum sum of distinct inference-node weights over refutations of UNSAT F. The best valid sequence is supplied for free in this lower-bound relaxation; proof-search costs are excluded. Sharing counts derived nodes once, while actual memory and retrieval depend on a separately charged execution schedule.
Let H_R(B) = max{W_R(F): UNSAT F, |enc(F)|<=B}. The load-bearing arbitrary-decider transfer TR(R) is: for every fixed uniform correct SAT decider A there exists a polynomial p_A such that every UNSAT F satisfies W_R(F)<=p_A(|enc(F)|+T_A(F)). TR remains OPEN for representation-inclusive systems and was already FALSIFIED for ordinary resolution by LSPV-1 334.

## Theorem 1, worst-case minimal-UNSAT core reduction
Assume R is SOURCE-HEREDITARY: every R-refutation of a clause-subformula U subset F remains a valid R-refutation from F with no larger cost, and removing clauses does not enlarge the encoding. These assumptions hold for ordinary source-labelled binary Resolution with unit inference weights and for genuinely source-local rules with unchanged costs. They need not hold for rules whose legality or weight depends on the whole original grammar.
PROVED/EXACT: for each UNSAT F there is a clause-minimally UNSAT U subseteq F with W_R(U)>=W_R(F). Consequently H_R(B)=max{W_R(U): U is minimally UNSAT, |enc(U)|<=B}. Proof: delete clauses until an inclusion-minimal UNSAT subset U remains. A cheapest U-refutation is admissible from F, so W_R(F)<=W_R(U). As U is no larger than F, compare both maxima. This equality is for shortest refutations under stated R, NOT arbitrary A runtime or source-size-dependent bit weights.
Under independent occurrence-sign encodings, every sign of a minimally UNSAT CNF is sensitive: flipping one sign makes it SAT. Consequently every deterministic all-CNF decider must query all L sign fields on this input (or at least ceil(L/w) w-bit probes). This earlier proved linear bound combines with the core theorem, but does not give superpolynomial time.

## Theorem 2, explicit-generator barrier to arbitrary-decider domination
Let g(1^j) output a valid UNSAT CNF F_j in j^O(1) time with j<=|enc(F_j)|<=j^O(1). If W_R(F_j) exceeds every polynomial in |enc(F_j)|, TR(R) is FALSE, independently of the details of R.
Proof: one fixed uniform correct general-SAT decider A_g validates the input, enumerates generator indices j=1..N for N=|input|, compares the produced F_j with input, answers UNSAT upon a match, and runs complete exhaustive assignment search otherwise. Every generator output is UNSAT by hypothesis, so it is both-label correct and rejects malformed strings. Its runtime on all F_j is polynomial in |F_j|, including unsuccessful generations and comparisons. TR(R) would force polynomial W_R(F_j), contradiction.
This is an explicit-generator strengthening of the P-recognizable UNSAT-subfamily necessary condition already proved in LSPV-1 334; no novelty claim beyond this exact corollary. It rules out jointly proving superpolynomial W_R on a poly-time generated known-UNSAT family and proving TR(R) for the SAME R. It does NOT rule out nonconstructive worst-case hard inputs, algorithm-dependent adversarial inputs, or P!=NP by another route. Expander Tseitin refutations in ordinary Resolution supply the known example: exponential W_Res and a polynomial GF(2) recognizing/solving bypass.

## Worst-case quantified statement and direction of transfer
The unrestricted time claim is forall uniform total correct A, forall k, forall N0, exists UNSAT F with |F|>=N0 and T_A(F)>|F|^k. This is equivalent to P!=NP via the polynomial UNSAT-side timer lemma. It does not say there is one finite F hard for every A. If TR(R), H_R(B)<=p_A(B+max_UNSAT,|F|<=B T_A(F)) after a monotone polynomial majorant; a superpolynomial H_R would then rule out polynomial all-input SAT deciders. That joint result remains OPEN. A rejecting machine trace does not independently justify the correctness of the program being simulated; LSPV-5 REFEREE294 covers the fixed-theory reflection countercontrol.

Exact fixed R for the experiment: binary Resolution, with all 8 non-tautological nonempty clauses of width <=2 over two variables, source axioms free, unit cost per new derived distinct clause, DAG sharing allowed. Breadth-first closure obtains shortest proof; a separately implemented no-import JavaScript recursion recomputes every optimum.
Across all 256 subformulas: 161 UNSAT, 11 minimally UNSAT. ## Four falsifiers and precise remaining gap
1. Try auxiliary-variable or global adaptive rules that violate source-heredity; do not apply theorem 1 without checking its stated hypothesis.
2. Given any explicit claimed superpolynomial W_R family, build the polynomial generator recognizer A_g; if it exists, TR(R) fails on that family.
3. Demand a sound independent justification for arbitrary A's UNSAT decision; do not count a raw rejecting machine trace or free program-correctness oracle as a logical refutation.
4. Replace unit inference weights with verified bit-work weights and retest core monotonicity plus the real machine-to-proof translation. Include all-phase peak memory, source probes, caches, and representation switches in implementation upper bounds.
Remaining missing theorem: one fixed representation-inclusive R with both superpolynomial worst-case H_R and universal arbitrary-A polynomial domination. No such joint theorem has been established. P versus NP OPEN.
