\section{Source semantics and full affine-cube dual}
Take $b\ge1$, $q\ge1$, rows $v_i$ of $V\in\mathbb F_2^{q\times b}$ and a pin vector $r\in\mathbb F_2^q$. A source-authenticated proper 3CNF $F_{V,r}(B,P)$ contains the \emph{complete} four-clause truth table of each private cumulative XOR gate and complete proper-ternary padded unit-pin blocks. Component-private variables are disjoint; only boundary bits $B=(x_1,\ldots,x_b)$ are shared. A zero row is encoded by a fresh private bit pinned to zero and to its required output. Every source clause/occurrence has an original index, authenticated sign and gate provenance. At every coherent complete boundary assignment $\beta$,
\[
(\exists P)\,F_{V,r}(\beta,P)\quad\Longleftrightarrow\quad V\beta=r. \tag{2}
\]
A partial assignment $\rho$ to \emph{boundary variables only} fixes coordinate set $J$ and leaves $U$ free:
\[
\SAT(F_{V,r}|_\rho)\ \Longleftrightarrow\
\exists y\in\mathbb F_2^U:\ V_Uy=r+V_J\rho. \tag{3}
\]
For private-variable assumptions use the complete authenticated gate-equation system, not (3) blindly.

\begin{theorem}[Exact boundary-cube blocker duality]\label{thm:dual}
For every $V,r,J,\rho$ of the stated source type, the restricted original CNF is UNSAT if and only if there is a nonzero $w\in\mathbb F_2^q$ such that
\[
w^\top V_U=0,\qquad w^\top(r+V_J\rho)=1. \tag{4}
\]
The vector $w$, its original complete gate/pin source indices and the source-scoped assumption cube constitute a verifiable affine UNSAT certificate. Every rejected boundary cube has such a certificate, and no extendible cube does.
\end{theorem}
\begin{proof}
Let $c=r+V_J\rho$. The remaining system $V_U y=c$ is consistent exactly when $c$ lies in the column space of $V_U$. Over $\mathbb F_2$ the latter fails exactly when a linear functional $w$ annihilates every column of $V_U$ but satisfies $w^\top c=1$. Equation (2) transfers the resulting incompatibility to the authenticated original proper 3CNF. Conversely such a $w$ would imply $0=1$ for any putative source completion. This proves both directions with no free semantic selector.
\end{proof}

\begin{theorem}[Exact all-label pin-descriptor criterion]\label{thm:descriptor}
For $q\ge2$ consider the candidate rule $D(r)=\SAT$ if and only if $r$ is constant, i.e.\ $r=0^q$ or $r=1^q$. The following are equivalent:
\[
\begin{split}
&\forall r\in\mathbb F_2^q:\quad \SAT(F_{V,r})\iff D(r)=\SAT,\\
&\operatorname{im}(V)=\operatorname{span}_{\mathbb F_2}(1_q),\\
&\exists v\in\mathbb F_2^b\setminus\{0\}:\quad v_i=v\quad(1\le i\le q). \tag{5}
\end{split}
\]
\end{theorem}
\begin{proof}
Equation (2) shows that satisfiable right-hand sides are precisely the vectors of $\operatorname{im}(V)$. Hence the first line is equivalent to the second. A matrix with image $\{0^q,1^q\}$ has each column either $0^q$ or $1^q$, with at least one nonzero column. This is precisely the condition that all rows are the same nonzero vector. Conversely such a matrix has image exactly the span of $1_q$.
\end{proof}

\begin{corollary}[Inclusion-minimal boundary cubes]
For identical nonzero row $v$ and identical pin $r_*$, a coherent boundary cube is unextendible if and only if it fixes \emph{every} variable in $\operatorname{supp}(v)$ to an assignment with parity opposite to $r_*$. The inclusion-minimal forbidden cubes number $2^{|\operatorname{supp}(v)|-1}$ and each has exactly $|\operatorname{supp}(v)|$ literals. If the pins conflict, the empty cube is a global blocker.
\end{corollary}
\begin{proof}
One unfixed support bit allows either parity, whereas all fixed support bits determine it. Variables outside the support are irrelevant; deleting any support assignment restores an extension. Opposing requirements on an identical left-hand side contradict without assumptions.
\end{proof}

\section{Counterexamples and original-clause adverse controls}
\begin{description}
\item[] \textbf{Mixed-label SAT:} $b=3$, rows $x_1\oplus x_2$ and $x_2\oplus x_3$, pins $(1,0)$. Assignment $(x_1,x_2,x_3)=(1,0,0)$ satisfies both although the pin-only rule says UNSAT.
\item[] \textbf{Homogeneous-label UNSAT:} $b=2$, rows $x_1,x_2,x_1\oplus x_2$, pins $(1,1,1)$. The first two force $x_1=x_2=1$, contradicting the third. The exact source parity combination $w=(1,1,1)$ yields $0=1$ although the pin-only rule says SAT.
\item[] \textbf{SAT root with rejected cube:} Two $x_1\oplus x_2\oplus x_3=0$ sources are SAT, but $\rho=(1,0,0)$ is UNSAT with witness $w=(1,0)$, without making the parent UNSAT.
\item[] \textbf{Zero-row contradiction:} $0=1$ jointly with $x_1\oplus x_2=1$ has homogeneous pins but is UNSAT.
\end{description}
All instances are source-authenticated proper 3CNFs with stable signed occurrences, not separate occurrence variables. Original clause-local S (all literals true) and U (all false), each inversion, and the SS/SU/US/UU pair compatibility conditions are independently checked, along with globally coherent $0^n/1^n$, complements and partial flip trails. A pair sharing both same- and opposite-sign variables can forbid all four local extremes without making the formula UNSAT.
