\begin{abstract}
P versus NP remains \OPEN.  The newest bridge report correctly rejects bare
full-trace factorization because the initial configuration contains the
source, and proposes deleting that carrier.  This run proves that deletion of
the read-only input field is not enough.  For every deterministic decider and
every finite input family, an extensionally equivalent uniform wrapper copies
the encoded source to a mutable work track in linear time.  The input-erased
mutable trace is then source-injective at one configuration.  Its image can
have size $2^N$ on $N$-bit sources although acquisition costs only $O(N)$.
Conversely, a cleaned terminal projection contains only the answer bit.  Thus
mutable-trace image size, collision entropy, source specificity, and terminal
state are presentation-sensitive and do not yield a solver-independent SAT
lower bound.  The surviving target is an implementation-invariant resource
inequality charged to one execution, or a direct lower bound for a fixed
NP-complete clean core.
\end{abstract}

\section{Explicit clean core and exact target}
Let $K$ be signed Monotone $3$SAT-$(2,2)$: every clause contains three
distinct variables and is all-positive or all-negative, clauses are unique,
and every variable occurs exactly twice with each sign.  D\"ocker proves that
$K$ is NP-complete\footnote{J.~D\"ocker, ``Monotone 3-Sat-(2,2) is
NP-complete,'' 2019, \url{https://arxiv.org/abs/1912.08032}.}.  Fix a
self-delimiting binary encoding and write $N=|\langle F\rangle|$.

The direct target is
\begin{equation}
 \forall A\ \forall d\ \forall N_0\ \exists F\in K:\quad
 |\langle F\rangle|\ge N_0\ \land\
 T_A(\langle F\rangle)>|\langle F\rangle|^d,              \tag{1}
\end{equation}
where $A$ ranges over total correct uniform deterministic deciders in one
fixed random-access or multitape model and parsing, source access, output,
time, and peak workspace are charged.  Statement (1) is \OPEN; because $K$ is
NP-complete, proving it would separate $P$ from $NP$.

The attacked bridge was weaker in appearance: after deleting the raw input
carrier, require every polynomial-time $A$ to expose a derived trace object
with many distinguishable values, then infer time, space, or communication.
The next theorem falsifies the inference from range alone without assuming
$P\ne NP$.

\section{Exact wrapper theorem}
Let $X\subseteq\{0,1\}^*$ be any finite or infinite input set.  For a machine
$M$, let $\operatorname{MTr}_M(x)$ denote the sequence of control states,
head positions, and mutable work-store contents, explicitly excluding the
read-only input tape.

\begin{theorem}[\claim{MUTABLE-TRACE-COPY-LEAKAGE1}]
For every total deterministic decider $A$ there is a uniform total
deterministic decider $W[A]$ computing the same language such that, for every
input $x$ of length $N$:
\begin{enumerate}[label=(\roman*)]
\item $W[A]$ copies $x$ to a designated mutable work track and reaches a
configuration $C^{\rm copy}(x)$ before simulating $A$;
\item $x\mapsto C^{\rm copy}(x)$ is injective although the read-only input is
excluded from the observed configuration;
\item
\[
 T_{W[A]}(x)=T_A(x)+O(N),\qquad
 S_{W[A]}(x)\le \max\{S_A(x),N\}+O(1);
\]
\item on every length layer $X_N$, the projection selecting the copy track
has image exactly $|X_N|$; copying only the first $j\le N$ source bits costs
$O(j)$ and realizes every prefix value present in $X_N$.
\end{enumerate}
After the simulated decision, the wrapper may erase its work and halt in one
of two answer states, so its terminal mutable-state projection has range at
most two.
\end{theorem}

\begin{proof}
Scan the input from left to right, writing each bit and one end marker to a
fresh work track.  This uses $N+O(1)$ transitions and $N+O(1)$ writable cells.
At the end of the scan, the work track contains a self-delimiting copy of
$x$, so decoding is fixed and injectivity is immediate.  Reposition the input
head if required and simulate $A$ with constant-factor universal-simulation
overhead absorbed into the machine-dependent constants.  The same-language
property follows from correctness of the simulation.  The displayed time and
space bounds follow by charging the scan, copy, repositioning, simulation,
and maximum simultaneous store.  The prefix variant stops after $j$ bits.
Finally retain $A(x)$, overwrite the wrapper's designated tracks, and enter
one of two fixed halt states.  This cleanup changes neither the language nor
the asymptotic time bound.  It is the same realized wrapper execution, not an
external extractor.
\end{proof}

\begin{corollary}[Exponential image is compatible with linear acquisition]
On $X_N=\{0,1\}^N$, the copy configuration has $2^N$ distinct values and is
produced using $N+O(1)$ reads and writes.  Therefore a counting argument from
$|\operatorname{im}\pi(\operatorname{MTr})|=2^N$ to $2^{\Omega(N)}$ time is
false.  At most the literal output/copy size is forced for this declared
representation.
\end{corollary}

\begin{corollary}[The proposed input-erasure repair is insufficient]
Deleting $C_0$ or the read-only tape from a trace does not establish
noninterference, internal semantic derivation, or unavoidable cost.  A
projection that sees named mutable coordinates is presentation-sensitive:
COPY can make it source-injective and cleanup can collapse its terminal
range.  Hence \claim{DERIVED-TRACE-RANGE-AS-HARDNESS1} is \RETIRED.
\end{corollary}

This does not prove that every conceivable derived projection is useless.
It shows the next definition must be invariant under extensionally equivalent
source-copy, delay, interpreter, recomputation, and cleanup wrappers while
still faithfully lower-bounding a resource of the same execution.  No such
projection theorem is known.

\section{Primary-literature and barrier-transfer preflight}
The two main obstacles were (i) distinguishing transported source bits from
internally derived semantics, and (ii) converting any trace property into a
model-matched lower bound for arbitrary computation.

Goguen--Meseguer noninterference compares outputs under changes to designated
high inputs\footnote{J.~A.~Goguen and J.~Meseguer, ``Security Policies and
Security Models,'' 1982 IEEE Symposium on Security and Privacy,
\url{https://www.cs.purdue.edu/homes/ninghui/readings/AccessControl/goguen_meseguer_82.pdf}.}.
This is a \textbf{directly transferable definition} once the observation map
is fixed; it is not a runtime lower bound and arbitrary equivalent SAT
programs need not share an observation map.  Information-flow taint systems
and control-theoretic observability are therefore \textbf{useful structural
analogies requiring a new transfer theorem}.  They become misleading when
``observable'' is silently replaced by ``computationally expensive.''

Fortnow--Lipton--van Melkebeek--Viglas give unconditional SAT time--space
tradeoffs in their specified random-access model\footnote{L.~Fortnow,
R.~Lipton, D.~van Melkebeek, and A.~Viglas, ``Time-space lower bounds for
satisfiability,'' \emph{J. ACM} 52(6), 2005,
\url{https://doi.org/10.1145/1101821.1101822}.}.  This is a directly usable
endpoint only after one \same{} machine is placed in its forbidden joint
region.  The copy theorem gives no such landing.

Baker--Gill--Solovay exhibit oracles with opposite $P$ versus $NP$
relationships\footnote{T.~Baker, J.~Gill, and R.~Solovay,
``Relativizations of the $P=?NP$ Question,'' \emph{SIAM J. Comput.} 4(4),
1975, \url{https://doi.org/10.1137/0204037}.}; Aaronson--Wigderson formalize
the stronger algebrization barrier\footnote{S.~Aaronson and A.~Wigderson,
``Algebrization: A New Barrier in Complexity Theory,'' 2009,
\url{https://eccc.weizmann.ac.il/eccc-reports/2008/TR08-005/Paper.pdf}.}.
Source copying relativizes and algebrizes, so this negative result crosses
neither barrier.  Natural Proofs is not directly invoked: no constructive
large circuit property is asserted.

\section{Assuming \texorpdfstring{$P=NP$}{P=NP}: model-matched consequence}
Assume $K\in P$ and fix a total uniform decider $A$ with time $N^{k+o(1)}$
and space $N^{s+o(1)}$, where $k,s$ are finite but otherwise arbitrary.  The
wrapper theorem yields a source-injective input-erased mutable trace in
$N^{\max\{1,k\}+o(1)}$ time and $N^{\max\{1,s\}+o(1)}$ space.  Large trace
range is therefore fully compatible with the assumption.  Conversely,
cleanup gives an answer-only terminal state.  Neither branch creates a fixed
FLMV-forbidden exponent pair.  No premise assumes the desired conclusion.

An explicit table of all compatibility answers may require exponential
output, but the original SAT decider outputs one bit.  Affine/Tseitin systems
may expose enormous semantic assignment sets while Gaussian elimination
decides them compactly.  Bounded-treewidth formulas admit compact dynamic
programs; independent products can stream and reuse memory.  These controls
show why semantic-state cardinality is not actual algorithmic cost.
