\section{Quantifiers, model, and target}
Fix one ordinary SAT encoding with physical input bit length $N$.
An achievable pair $(d,s)$ belongs to $E$ only if \emph{one fixed, uniform,
deterministic, total, all-input exact} machine $A$ in the indexed read-only
input random-access model simultaneously obeys
$T_A(N)\le N^{d+o(1)}$ and $S_A(N)\le N^{s+o(1)}$, including its
index/writable tape and every execution path. The assertion $P=NP$
implies that some finite unknown $(K,K)$ belongs to $E$. It does \emph{not}
imply a particular $(1.802,o(1))$ pair. All reductions between ordinary
SAT, proper signed exact-$(2,2)$ ternary SAT, and the strictly narrower
clause-monotone exact-$(2,2)$ class require paid input-length, random-access,
work, and peak-space simulation. A circuit deciding all $N$-bit sources
$C_{A,N}$ is different from a fixed-instance trace or a projected
interface relation.

For this run the precise proof target is: derive the two-algorithm
inequalities under their original source premises, then test a claimed
sufficient \emph{label-only} adaptive UNSAT cover rule on genuine
clause-monotone exact-$(2,2)$-3-CNF, including exact target-class children.

\section{Literature check, latest peers, and inherited status}
Verified directly in van Melkebeek's original 2007 survey\footnote{\url{https://eccc.weizmann.ac.il/report/2007/099/download}}, p.~2,
Theorem~1.3: for real $c,d$ satisfying
\begin{equation}\label{eq:van}
 (c-1)d<1 \qquad\text{or}\qquad cd(d-1)-2d+1<0,
\end{equation}
there exists $e>0$ such that SAT cannot have both a
\emph{co-nondeterministic} random-access algorithm with time $N^c$ and
a \emph{deterministic} random-access algorithm with time $N^d$ and
space $N^e$. The theorem supplies neither algorithm. The two algorithms
need not be the same program; its second program must nevertheless
have both claimed resources simultaneously.

Bathie--Williams, ITCS 2024,\footnote{\url{https://doi.org/10.4230/LIPIcs.ITCS.2024.10}}
proves the reported $3.603\log_2N$ depth lower bound for
\emph{polylogtime-uniform NAND circuits} deciding SAT. This does not
lower-bound general indexed random-access machines or arbitrary
per-instance certificate relations. The FLMV 2005 simultaneous
random-access time-space bound is a separate theorem; the old purported
universal $t+s<2\cos(\pi/7)$ test remains retired, without denying
Williams' valid special $N^{o(1)}$-space time bound.

\section{Formal co-nondeterministic certificate interface}
Define a deterministic clocked verifier $V(F,\pi)$ on arbitrary candidate
certificate strings, whose outcome is zero on all malformed strings,
invalid source pointers, failed semantic joins, or timeouts. A one means
that $\pi$ is a valid, \emph{complete} UNSAT certificate of $F$.

\begin{lemma}[Correct two-sided certificate polarity: PROVED/EXACT]
Suppose $V$ obeys, for every ordinary SAT input $F$,
\[
 F\in\UNSAT\Longrightarrow\exists\pi\; V(F,\pi)=1,
 \qquad F\in\SAT\Longrightarrow\forall\pi\;V(F,\pi)=0,
\]
where certificates have a uniform length bound and every branch, including
invalid strings and timeouts, is clocked within $N^{c+o(1)}$.
Then there exists a uniform co-nondeterministic SAT machine with time
$N^{c+o(1)}$, in the random-access model subject to an explicitly paid
uniform verifier simulation.
\end{lemma}
\begin{proof}
Guess $\pi$ and run the verifier. \emph{Reject} if and only if it returns
one. Every computation branch accepts for a satisfiable source; at least
one branch rejects for an unsatisfiable source. Invalid/time-out branches
accept. This is the universal-acceptance convention of co-nondeterminism.
The clock and all source-bit, index, candidate, arithmetic, and machine
simulation work must be charged; no oracle answer is postulated.
\end{proof}

\emph{Coverage is an independent hypothesis.} Guessing a syntactically
valid but partial refutation of one branch cannot meet the quantifier.
If children partition the search space, ALL alternative assignments must
be discharged, with the original source names and every compatibility
condition respected. A leaf may query one fixed deterministic exact
solver $A$ only when its query and result are actually computed and charged.

\begin{lemma}[Weighted terminal work: PROVED/EXACT arithmetic]
For $d\ge1$ and positive integer encoded child lengths $m_i$,
$M=\max_i m_i$ and $V=\sum_i m_i$,
\[
 \sum_i m_i^d\le M^{d-1}V.
\]
If $M\le N^{\lambda+o(1)}$, $V\le N^{b+o(1)}$,
per-guest work has a multiplicative local-access overhead
$N^{u+o(1)}$, all additional construction and semantic verification
work costs $N^{r+o(1)}$, and certificate parse length is
$N^{v+o(1)}$, the co-nondeterministic verifier time can be bounded by
\begin{equation}\label{eq:time}
 c\le \max\{v,r,u+b+\lambda(d-1)\}+o(1),
\end{equation}
\emph{provided} the listed costs include all failed routes, restarts,
index logic, input decoding, repeats, full terminal calls and validation.
This asserts no small-volume certificate for any specific UNSAT source.
\end{lemma}
\begin{proof}
Each $m_i^d=m_i\,m_i^{d-1}\le m_i M^{d-1}$.
Sum, multiply by the declared per-guest overhead, and add the local and
certificate-reader work. The largest monomial determines the polynomial
exponent. For only an additive $N^u$ cost per child, charge the number
of child calls separately; it is at most $V$, giving instead the
upper envelope $\max\{v,r,b+u,b+\lambda(d-1)\}$.
\end{proof}

\begin{theorem}[Exact combined strict frontier: PROVED/EXACT algebra]
For a deterministic seed exponent $d>1$, the strict admissible
co-nondeterministic exponent window in the cited Theorem~1.3 is
\[
 c<H(d),\qquad
 H(d)=\max\!\left\{1+\frac1d,\frac{2d-1}{d(d-1)}\right\}
 =\begin{cases}
 \frac{2d-1}{d(d-1)},&1<d\le2,\\
 1+\frac1d,&d\ge2.
 \end{cases}
\]
For $d=901/500=1.802$,
\[
 C(d)=\frac{651000}{361301}=1.8018217497322177\ldots,
 \quad C(d)-d=-0.000178250267782\ldots.
\]
With $\lambda=1/2$ and $u=0$, the \emph{conditional}
volume criterion for Theorem~1.3 is
\[
 b<C(d)-\frac{d-1}{2}
 =1.4008217497322177\ldots,
 \qquad r,v<C(d).
\]
An $A$ with deterministic space $N^{o(1)}$ and time
$N^{d+o(1)}$ would satisfy the theorem's deterministic space premise
with $N^e$ for every fixed $e>0$, but the premise of \emph{affordable,
sound, complete UNSAT certificate coverage} remains \openstatus.
\end{theorem}
\begin{proof}
Rearrange the two strict inequalities in~\eqref{eq:van}. Their union
permits $c$ below the larger right endpoint. Subtracting gives
\[
 \frac{2d-1}{d(d-1)}-\left(1+\frac1d\right)
 =\frac{2-d}{d-1}.
\]
The sign changes at $d=2$. The rational computation follows from
$2d-1=651/250$ and $d(d-1)=361301/250000$.
To apply a theorem stated for fixed real power bounds to $o(1)$
exponents, choose fixed positive slack below the strict frontier
and above the proved upper bounds. The unknown $e>0$ is then dominated
by $S_A=N^{o(1)}$ asymptotically. No unproved algorithm exists by this algebra.
\end{proof}

\begin{corollary}[Arbitrary-exponent seed firewall: PROVED/EXACT]
The above near-boundary contradiction, even if all certificates were
constructed, does \emph{not} establish $P\ne NP$: $P=NP$ yields some
unknown fixed polynomial pair $(K,K)$, not
$(1.802,o(1))$. Moreover $H(K)=1+1/K$ for $K\ge2$ and tends to one,
whereas the amount of allowed co-nondeterministic work and any local
normalization are independent proof obligations.
\end{corollary}

\section{Genuine clause-monotone exact-(2,2) opposite-label counterexample}
Let $\mathcal M_{22}$ be the proper, clause-distinct, clause-monotone
ternary class where every active variable has exactly two positive
and two negative occurrences. Source $U\in\mathcal M_{22}$ is
D\"ocker's original 198-variable, 264-clause UNSAT formula.
Let $V$ replace precisely two positive clauses,
\[
\begin{aligned}
 C_1=(194,196,197)&\longmapsto(5,196,197),\\
 C_7=(5,7,8)&\longmapsto(194,7,8),
\end{aligned}
\]
with zero-based positions used in the executable (indices 1 and 7).
$U$ and $V$ each remain in $\mathcal M_{22}$ because this is a
positive-incidence swap on two distinct variables and no resulting
clause is duplicated. A complete explicit witness $W$ satisfies $V$.
$W$ also satisfies all of $U$ except clause $C_1$. The UNSAT of $U$
is checked by a replayed 89-node refutation of its 32-variable
module, replicated six times, and an exhaustive six-variable core
contradiction (64 assignments). Thus the opposite labels do not rest
solely on a heuristic SAT solver.

\begin{theorem}[No label-only block join, even after exact-class restoration:
PROVED/EXACT with finite certified dependencies]
There exist a proper clause-monotone exact-(2,2) formula $U$ with
$\neg\SAT(U)$ and another such formula $V$ with $\SAT(V)$ and a
partition into four corresponding nonempty source clause blocks
$B_0,B_1,B_2,B_3$, such that \emph{all eight blocks are SAT}. Furthermore,
using the previously proved exact $\mathcal M_{22}$ compiler of
ARC177, all eight children $R(B_j)$ belong to $\mathcal M_{22}$,
are independently SAT, and preserve the partition's all-one
local SAT label vector. Therefore no purported exact parent decision
rule depending \emph{only} on this vector can correctly decide both
$U$ and $V$; the original-name-compatible join relation must be
represented, acquired, and checked.
\end{theorem}
\begin{proof}
Take $B_0$ as source clause index 1, and divide the remaining
263 clauses by increasing source index into 88, 88, and 87-clause
blocks. The explicit assignment $W$ witnesses SAT of each of the
three latter blocks of $U$, and every block of $V$.
The singleton $B_0$ of $U$ is SAT by setting $x_{194}=1$.
All four blocks in both instances consequently have answer one.
The exact ARC177 compiler maps each proper monotone residual with
per-sign degree at most two to a proper monotone exact-(2,2)
formula, preserving SAT by neutral fillers and forced-value padding.
For every one of the eight compiled children, the executable
constructs and verifies an extension of the corresponding source
assignment. Thus label-only interfaces produce the same vector
$(1,1,1,1)$ on the opposite-label parents. Any function of that
vector must answer identically on both and hence fails on at least one.
This refutes only the stated restricted join rule; richer compatible
boundary relations can be sound, although their acquisition and
resources remain \openstatus.
\end{proof}

\section{Adversarial branch and certificate checks}
The proper 3-CNF
\[
 P=(x\vee a\vee b)\land(x\vee a\vee\neg b)
\land(x\vee\neg a\vee b)\land(x\vee\neg a\vee\neg b)
\]
is equivalent to $x$. Its $x=0$ residual is UNSAT, but $P$ is SAT;
thus a lone valid UNSAT child never certifies the parent. This
is inherited from the independent LSPV-5 referee and was retested.

A deterministic standard-library exhaustive certificate verifier
was run on seven small CNF controls (3 SAT, 4 UNSAT).
It accepts complete trees on the four UNSAT controls, and rejects
35 malformed or incomplete candidate trees. Every leaf names a
source clause falsified under a \emph{full} assignment; every internal
node covers both assignments of the next variable. This finite
complete truth-table scheme has worst-case exponential size and
\emph{does not} establish an affordable universal certificate family.
