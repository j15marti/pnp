\section{Model and backward-Circuit-SAT semantics}
Fix the NP-complete proper, duplicate-free signed exact-$(2,2)$ 3-CNF language: every clause has three distinct source variables, each variable occurs exactly twice positively and twice negatively. Thus $4n=3m$. Reject illegal source encodings. We declare $w=\lceil\log_2(64(n+m+1))\rceil$ source bits per word and $N=(4m+2)w$ encoded input bits. Every source read, recognition, failed method, transformation, switch, branch and full-source replay is charged on a deterministic uniform word RAM. Peak live words are counted separately.
The shared-source NOT1, OR2 and AND2 evaluation circuit has $n+3m-1$ gates and $n+6m-2$ gate-input incidences. Backward from output TRUE, every clause OR must be TRUE. A consistent selection of one literal occurrence per clause, with no complementary selected pair, exists iff SAT. The occurrence-conflict graph contains exactly $n$ disjoint copies of $K_{2,2}$; clause triples partition $4n=3m$ occurrence vertices. These are evaluation and exact-encoding facts, \emph{not} lower bounds on SAT-solving circuits or optional selector materialization.

For every disjoint complementary-pair contraction
\[
(a\vee b\vee x)\wedge(a\vee b\vee\neg x)\equiv(a\vee b)
\]
write the assignment-equivalent residual as $F\equiv B\wedge T$, where $B$ is 2-CNF and $T$ has $\delta=m-2p$ unmatched ternary clauses. The earlier source proof shows that each variable appearing in $T$ occurs there either twice or four times. Let $r_2,r_4$ count those variables, $a=r_2+r_4$, and note
\[
2r_2+4r_4=3\delta,\qquad
a=\frac{3\delta}{4}+\frac{r_2}{2}.
\]
All parameters are determined by source structure, independently of observed runtime or the unknown SAT label.

\section{A deterministic half-clause strong backdoor}
\begin{theorem}[HALFRANDOM89, PROVED/EXACT]
There is a deterministic uniform $O(a+\delta)$-word constructor, after grammar and pair validation, which produces a set $X$ of original variables meeting every ternary in $T$ with
\[
\boxed{|X|\le\left\lfloor\frac{\delta}{2}+\frac{r_2}{4}\right\rfloor.}
\]
For the strict signed exact-$(2,2)$ case with no complementary clause pair, $r_2=0$ and $\delta=m$; hence $|X|\le\lfloor m/2\rfloor$.
\end{theorem}
\begin{proof}
Choose each of the $a$ residual source variables independently with probability $1/2$, and add any one variable from every ternary that was left uncovered. The resulting variable set meets every ternary. The initial expected selected count is $a/2$. Each proper ternary has three distinct variables, so its probability of being missed is $1/8$, and the expected number of missed clauses is $\delta/8$. Therefore
\[
\mathbb E[\#\text{selected}+\#\text{uncovered}]
=\frac a2+\frac\delta8=\frac{\delta}{2}+\frac{r_2}{4}.
\]
Derandomize in the original-variable order using conditional expectations. Keep a Boolean active/unhit flag for every clause and its number $q_C\in\{1,2,3\}$ of not-yet-decided variables. For undecided variable $v$, the exact conditional expected-cost difference is
\[
E[v\gets1]-E[v\gets0]
=1-\sum_{\substack{C\ni v\\C\text{ still unhit}}}2^{-(q_C-1)}.
\]
Set $v=1$ if the difference is negative; otherwise set it to zero. If selected, mark its incident clauses hit; if rejected, decrement the corresponding active $q_C$. The conditional expected cost never increases. Each variable is incident on at most four source ternaries, so every decision and update takes $O(1)$ word operations once the $3\delta$ adjacency sockets have been built. At termination the expectation is the actual selected count plus actual uncovered-clause count; add one variable per uncovered clause. This constructs a hitting set in $O(a+\delta)$ word operations and live words whose integer size is at most the floor above. Every assignment to $X$ turns all residual ternaries into width-at-most-two clauses. The contracted $B$ was already 2-CNF.
\end{proof}
\begin{theorem}[Charged switching upper bound, PROVED/EXACT]
There is a total uniform deterministic exact decider that constructs both this new cover and the earlier general-matching cover, chooses the smaller based on observed costs and source data, branches over that set, solves each branch using exact 2-SAT SCC, and replay-checks a witness on the original source. Its bound is
\[
\boxed{
T(F)=O\left(m\log(m+2)+\delta^4+
2^{h_*}(n+m+1)\right),\
h_*=\min\left\{\left\lfloor\frac{3\delta}{5}\right\rfloor,
\left\lfloor\frac{\delta}{2}+\frac{r_2}{4}\right\rfloor\right\}
}
\]
with $O(n+m)$ reusable peak work words.
\end{theorem}
\begin{proof}
Grammar and complement-pair recognition are charged before branching. A general graph matching procedure constructs the earlier $3\delta/5$ cover; the conditional-expectation procedure constructs the second. Choose the smaller of the \emph{actual} computed covers, enumerate its assignments, and use SCC to decide every 2-CNF child. Every satisfying source assignment restricts to one covered branch; conversely any successful child can be lifted and verified against the source. Exhaustion proves UNSAT. The matching step has conservative cost $O(\delta^4)$ and child processing $O(n+m+1)$ each, while buffers are reused. This is an \emph{upper} bound, not a branch-count or representation lower bound.
\end{proof}

\section{Connected signed exact-(2,2) hostile control}
For $t\ge1$, make $t$ octahedral blocks. Each has six variables
$a_{i,0},a_{i,1},b_{i,0},b_{i,1},c_{i,0},c_{i,1}$
and eight clauses indexed by $(u,v,w)\in\{0,1\}^3$. Clause $(u,v,w)$ contains $a_{i,u}$ positively iff $v=w$, $b_{i,v}$ positively iff $u=w$, and $c_{i,w}$ positively iff $u=v$. Between consecutive blocks swap the positive $a_{i,0}$ literal from $(0,1,1)$ at block $i$ with the positive $a_{i+1,0}$ literal from $(0,0,0)$ in block $i+1$. Both clauses remain proper and preserve signs.
\begin{theorem}[Connected easy island, PROVED/EXACT]
The resulting $G_t$ is connected, proper, duplicate-free signed exact-$(2,2)$ 3-CNF with $n=6t$, $m=8t$, no complementary clause pair, and minimum source-variable set hitting all ternaries exactly $2t$. Nevertheless, the canonical sources are recognizable in $O(t)$ word operations and a witness is source-verifiable in the same time and $O(t)$ words. Consecutive two-block bags yield a path decomposition with at most twelve source variables per bag.
\end{theorem}
\begin{proof}
Initially every variable occurs twice under each sign, with different clause supports. Exchanging positive $a_0$ occurrences in distinct blocks maintains sign counts, clause properness and uniqueness; the shared swapped variables connect the adjacent block incidence components while $b,c$ preserve each block's internal connectivity. Distinct original $(u,v,w)$ supports and the unchanged $b,c$ pairs exclude complementary clause pairs. Selecting $b_{i,0},b_{i,1}$ in each block hits all its clauses, giving $h\le2t$. At least six clauses per block are untouched by the two possible neighboring swaps. They contain only variables from their block, each such variable occurring in at most four of these six, requiring at least two selected variables per block. Distinct block variable sets give $h\ge2t$. The assignment $(a_0,a_1,b_0,b_1,c_0,c_1)=(0,0,0,0,1,1)$ in every block satisfies each original clause and remains valid after swapping identically valued positive $a_0$ literals. A uniform full grammar recognizer regenerates the source and checks it word for word, then emits and replays this witness. Off-canonical inputs use an unrestricted exact SAT fallback. Each clause involves only one or two neighboring blocks, giving the stated path decomposition.
\end{proof}
Thus even a connected strict NP-complete-language \emph{input family} can have a minimum strong 2-CNF backdoor increasing linearly with input length while its SAT label is directly decided in linear time. This defeats any unconditional claim that all exact deciders must expend $2^{\Omega(h)}$ time on \emph{these inputs}. It does not rule out algorithm-dependent hard inputs elsewhere.
