\section{The source-verified two-algorithm threshold}
\begin{lemma}[Theorem 1.3 algebra: KNOWN THEOREM plus exact rearrangement]
Suppose SAT has both a uniform co-nondeterministic random-access
$N^{c+o(1)}$-time algorithm and a uniform deterministic random-access
$N^{K+o(1)}$-time algorithm using at most $N^{e}$ writable/index space,
where $e>0$ is the suitably small exponent from van Melkebeek's
Theorem 1.3. They cannot coexist if
\[
(c-1)K<1\quad\text{or}\quad cK(K-1)-2K+1<0.
\]
For $K\ge2$ the sufficient strict window is
\[
\boxed{c< H(K)=1+\frac1K.}
\]
For $1<K\le2$ use
$H(K)=(2K-1)/(K(K-1))$ instead (with equality at $K=2$).
\end{lemma}
\begin{proof}
The two premises and OR condition are the literal original theorem,
not a consequence of the proposed certificate scheme. Algebra gives the
union threshold
$\max\{1+1/K,(2K-1)/(K(K-1))\}$; their difference is
$(2-K)/(K-1)$, so $1+1/K$ dominates for $K\ge2$.
Choose strict epsilon margins to handle $o(1)$ in implementation costs.
The theorem requires the deterministic space condition on \emph{that
same deterministic decider}; from P=NP one only obtains an unspecified
polynomial space exponent, not the required $e$.
\end{proof}

\section{Exact finite-depth conservation law}
\begin{theorem}[Balanced certificate ledger: PROVED/EXACT arithmetic]
Fix \emph{constants} $K\ge2$, $\kappa\ge0$, integer $L\ge1$.
\emph{Assume} a correct, sound, complete, uniformly clocked all-UNSAT
certificate grammar is available whose every internal subtree of encoded
length $n$ has at most $n^{1/2+\kappa+o(1)}$ actual ordinary SAT children,
all of encoded length at most $n^{1/2+o(1)}$, and all the leaves are
checked by \emph{one fixed} exact solver $A$ with time $m^{K+o(1)}$.
Assume generation has polylogarithmic amortized primitive-bit cost per
emitted child bit, local checking costs $n^{1+o(1)}$ per parent,
root/source verification is paid, and the full certificate description,
compatible join checking, failed routes and input-index service fit these
bounds. The model permits fixed depth depending on $K$, never on $N$.

Then the \emph{certified upper-bound exponents}, not mandatory lower
bounds on all possible deciders, are
\[
P_L=(1+2\kappa)(1-2^{-L}),\qquad
\lambda_L=2^{-L},\qquad
b_L=P_L+\lambda_L=1+2\kappa(1-2^{-L}),
\]
\[
\boxed{c_L=P_L+K\lambda_L
=1+2\kappa+(K-1-2\kappa)2^{-L}.}\tag{1}
\]
All earlier eager emission and $n^{1+o(1)}$ local checking fit
$c_L$ under the declared promises.
\end{theorem}
\begin{proof}
At level $i$, a root length-$N$ input induces descendant lengths
$N^{2^{-i}+o(1)}$. Put $P_0=0$ and note that each node at level $i$
creates at most $N^{(1/2+\kappa)2^{-i}+o(1)}$ actual children.
Thus $P_{i+1}=P_i+(1/2+\kappa)2^{-i}$, whence
$P_i=(1+2\kappa)(1-2^{-i})$.
Terminal volume has exponent $P_L+2^{-L}$; terminal solver time
has exponent $P_L+K2^{-L}$. At level $i<L$ the aggregate eager
child-bit production exponent is
\[
G_i=P_i+(1+\kappa)2^{-i}
=1+2\kappa-\kappa2^{-i}\le b_L,
\]
and the aggregate local work exponent is
\[
R_i=P_i+2^{-i}=1+2\kappa-2\kappa2^{-i}\le b_L.
\]
Since $K\ge1$, $c_L\ge b_L$. Fixed-depth polylogarithmic overheads
contribute only $o(1)$ to all exponents. Every hypothetical reduction,
certificate grammar, terminal call and semantic join remains explicitly
an \emph{assumption}; there is no all-input machine construction here.
\end{proof}

\begin{corollary}[Sharp fixed-depth numeric gate: PROVED/EXACT]
For each $K\ge2$, there exists some finite $L\ge1$ such that the
certified bound $(1)$ is \emph{strictly} inside van Melkebeek's
co-nondeterministic window $c_L<1+1/K$ if and only if
\[
\boxed{\kappa<\frac{1}{2K}.}\tag{2}
\]
Whenever (2) holds, the least sufficient integer depth is the least
$L\ge1$ satisfying
\[
\boxed{2^L>\frac{K-1-2\kappa}{1/K-2\kappa}.}\tag{3}
\]
In particular, at $\kappa=0$ the exact criterion is
$2^L>K(K-1)$, so $L=O(\log K)$ suffices for each \emph{fixed}
finite $K$. But any \emph{fixed} $\kappa>0$ fails to certify this
frontier for all sufficiently large seed exponents $K$.
\end{corollary}
\begin{proof}
Write $z=2^{-L}$ and observe
$c_L=(1-z)(1+2\kappa)+zK$, a strict convex combination of the
finite-depth entry cost and seed cost. Because $K\ge2>1+1/K$
and $z>0$, if $1+2\kappa\ge1+1/K$ no finite depth works.
If $1+2\kappa<1+1/K$, the limit as $L\to\infty$ is strictly
below the frontier, so sufficiently large finite $L$ works.
Rearranging the strict inequality yields (3), since the denominator
is positive under (2). This is a statement about the \emph{derived
ledger upper bound}; it does not preclude another, more efficient
solver or certificate system.
\end{proof}

\paragraph{Additional cost firewall.}
If each root child bit requires \emph{multiplicative}
$N^{g+o(1)}$ access time, the first generation contributes
$1+\kappa+g$. Thus a frontier proof by these upper bounds also needs
$\kappa+g<1/K$, in addition to (2).
A terminal per-access factor $N^{u+o(1)}$ instead raises the
terminal exponent to $c_L+u$; its limiting floor demands
$2\kappa+u<1/K$. A global local-verification exponent $r$ demands
$r<1+1/K$ as a sufficient strict resource budget.
For $K\to\infty$, every fixed positive overhead above the
near-linear baseline can defeat this \emph{specific} gate.
Peak writable/index space for the deterministic seed remains a
\emph{separate} hypothesis. Even a perfect $c_L$ does not force a
small deterministic-space machine from an arbitrary $(K,K)$ seed.

\section{Exactly compatible joins, and two real relational levels}
Let clause blocks be $B_0,\dots,B_{j-1}$, with named variable sets
$V_i$. For any index subset $I$, define its interface
$S_I=(\bigcup_{i\in I}V_i)\cap(\bigcup_{i\notin I}V_i)$ and the
semantic relation $R_I\subseteq\{0,1\}^{S_I}$ consisting of
assignments extendible to satisfy every clause in those blocks.
For disjoint $I,J$, with all shared names appearing in both children,
\[
R_{I\cup J}=\{(r_I\cup r_J)|_{S_{I\cup J}}:
 r_I\in R_I,\ r_J\in R_J,\
 r_I|_{S_I\cap S_J}=r_J|_{S_I\cap S_J}\}.
\]
This is an exact identity: compatible witnesses can be glued because
any variable appearing in two subtrees lies in their recorded
interfaces. It is \emph{not} a budget on acquiring these relations.
At the root $S_{\{0,\ldots,j-1\}}=\varnothing$, so its relation
is $\{()\}$ iff the original formula is satisfiable and empty otherwise.
