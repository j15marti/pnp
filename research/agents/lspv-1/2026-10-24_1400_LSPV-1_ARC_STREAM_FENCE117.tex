\section{Model, primary endpoint, and exact typed target}
Let $N$ denote the full encoded bit length of an ordinary SAT input in the fixed language used by the FLMV reduction. Each machine is uniform, total, exact on \emph{every} input, with read-only indexed source; work/index tapes are charged and write-only output is not free readable storage. A point $(t,s)$ denotes the simultaneous asymptotic resources of \emph{one} fixed machine. The primary FLMV 2005 Theorem 3.1 and Corollaries 3.2, 5.8 give the model-matched forbidden region
\[
 {\cal B}=\{(t,s):\exists c>\max(1,t),\
  s<\beta(c)\},\qquad
 \beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
 \tag{1}
\]
We checked the actual primary PDF, including screenshot pages 6 and 18 (zero-index pages 5 and 17). The retired claim $t+s<2\cos(\pi/7)$ is not a general SAT forbidden endpoint.

An \emph{active-slot scoped 3-CNF stream} is a self-delimiting sequence of instructions $\mathrm{I},\mathrm{C},\mathrm{D},\mathrm{END}$ with canonical live-slot indices. An $\mathrm{I}$ event introduces a fresh Boolean variable at a new active slot. A $\mathrm{C}$ event emits a proper three-distinct-variable clause referring only to currently live slots, with signs. A $\mathrm{D}$ event existentially forgets an active slot that \emph{will never be needed by any later clause}; its identity never returns. A valid stream ends by deleting its live variables and issuing $\mathrm{END}$. Its semantics is the conjunction of all emitted clauses over the introduced variables. Slot-address bits are $O(\log(w+2))$ for live width $w$; no unbounded source variable-ID dictionary is silently supplied. The producer must be semantically correct, not just valid on a promise.

\begin{lemma}[Exact streaming existential table, \EXACT]
For every trusted valid stream of bit length $M$ and peak live width $w$, a deterministic exact SAT decider runs in
\[
 T_{\rm stream}=O(M\,2^w\operatorname{polylog}(M+2)),\qquad
 S_{\rm stream}=O(2^w\operatorname{polylog}(M+2))
 \tag{2}
\]
in the declared random-access Turing-machine model. No full output stream is stored.
\end{lemma}
\begin{proof}
After each event, retain the set of assignments to current live variables extendible to a satisfying assignment of all clauses already seen, existentially quantifying deleted variables. Introduce duplicates each current row with both values of the new variable. A clause filters out falsifying rows. Delete maps the set to the projection on remaining slots and merges duplicates by Boolean OR. Induction proves the invariant for both SAT and UNSAT. At $\mathrm{END}$ the empty-assignment row exists exactly when the whole formula is satisfiable. There are at most $2^w$ rows, of $O(w)$ bits; each event costs $2^w\operatorname{polylog}(M+2)$ bit operations. The slot grammar needs only the active-slot map and a logarithmic event buffer. A single FLMV random-access machine can implement these operations at the stated bounds up to polylogarithmic model overhead.
\end{proof}

\begin{theorem}[All-input normalization firewall, \EXACT{} conditional on the \emph{normalizer's specified output contract}]
Fix constants $\mu,\kappa,r,\sigma\ge0$. There is \emph{no} fixed uniform total transducer $P$ such that simultaneously, for every ordinary SAT source $F$ of $N$ bits:
\[
\begin{gathered}
P(F)\text{ is a valid active-slot scoped stream},\quad
 \operatorname{SAT}(P(F))=\operatorname{SAT}(F),\\
|P(F)|\le N^{\mu+o(1)},\qquad
w(P(F))\le\kappa\log_2N+o(\log N),\\
T_P(N)\le N^{r+o(1)},\qquad S_P(N)\le N^{\sigma+o(1)},
\end{gathered}\tag{3}
\]
whenever there exists a fixed $c>\max\{1,r,\mu+\kappa\}$ with
\[
 \max\{\sigma,\kappa\}<\beta(c).
 \tag{4}
\]
All bounds refer to that same producer $P$ in the same FLMV input/work/index model; output is intercepted as a \emph{one-way} event stream, not placed in a free readable buffer.
\end{theorem}
\begin{proof}
Simulate $P$ on input $F$, pausing after enough output bits to parse an event, update the DP table of the preceding lemma, and resume $P$. The DP cannot read future output or the input except via $P$; it holds only its own live table and event buffer, simultaneously with $P$'s work tapes. Consequently one fixed uniform total SAT decider has resources
\[
 T(N)\le N^{\max\{r,\mu+\kappa\}+o(1)},\qquad
 S(N)\le N^{\max\{\sigma,\kappa\}+o(1)}.
 \tag{5}
\]
The strict inequalities (4) provide time and space slack after the polylogarithmic FLMV Theorem 3.1 SAT-to-NTIME transfer, contradicting Corollary 5.8. Thus no such producer exists. Notice that the claim excludes an overly powerful \emph{all-input normalization contract}, not a general decider or an arbitrary representation transformation.
\end{proof}
