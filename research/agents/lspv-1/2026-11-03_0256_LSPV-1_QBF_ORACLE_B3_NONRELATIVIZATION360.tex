\section*{Fixed system and quantifiers}
Keep unchanged the preselected source-independent $R_{\mathrm{mix341}}$: original signed CNF source clauses cost zero; distinct derived shared DAG nodes each cost one; legal operators include authentic binary Resolution, exact typed AND3, GF(2) XOR, justified LOCAL-CONVERT and paid conservative signed two-input VARDEF. The strict ordinary Resolution subsystem $R_{\rm res}$ has no oracle rule. For each fixed $R$ define
\[
W_R(F)=\min_{\pi:F\vdash_R\bot}\sum_{v\in\pi_{\rm derived}}1,\qquad
\overline W_R(N)=\max_{\substack{F\ {\rm valid\ UNSAT}\\|\operatorname{enc}(F)|\le N}}W_R(F),
\]
with empty maximum zero; $N$ is encoded bit length. For an oracle decider $A^{\mathcal O}$, let $T_{A^{\mathcal O}}^{\rm wc}(N)=\max_{x\in\{0,1\}^{\le N}}T_{A^{\mathcal O}}(x)$, including malformed strings. The oracle-\emph{relative} B2 extension replaces ordinary algorithms by oracle algorithms but keeps the proof system $R$ and its weights unchanged. This is a model test, not an assumption in the original B2.

\begin{theorem}[Exact oracle-relative B2 and B3 countermodel for ordinary Resolution]
With $\mathcal Q=\mathrm{TQBF}$, there is one fixed, uniform, total polynomial-time oracle SAT decider $A^{\mathcal Q}$, correct for SAT, UNSAT and MALFORMED on all binary inputs, with
\[
P^{\mathcal Q}=NP^{\mathcal Q}=\mathrm{PSPACE},\qquad
T_{A^{\mathcal Q}}^{\rm wc}(N)\le c(N+1)^d
\]
for some constants $c,d$, and at the same time
\[
\forall k,C>0\ \forall N_0\ \exists N\ge N_0:
\overline W_{R_{\rm res}}(N)>C(N+1)^k.
\]
Therefore the natural oracle-relative B1 and B2 inequalities, and the oracle-relative B3 conditional, are all false for the \emph{fixed ordinary Resolution subsystem}. This is not a refutation of unrelativized B1/B2/B3 for $R_{\mathrm{mix341}}$.
\end{theorem}
\begin{proof}
TQBF is PSPACE-complete, so $\mathrm{PSPACE}\subseteq P^{\mathcal Q}$. A nondeterministic polynomial-time machine with a PSPACE query oracle can simulate each polynomial-length oracle query in polynomial space and reuse workspace, so by Savitch,
$NP^{\mathcal Q}\subseteq NPSPACE=PSPACE$. This gives the class equality.

A single deterministic algorithm reads and parses an arbitrary signed-CNF input, returns MALFORMED on syntax failure, otherwise canonically renumbers the appearing variables and writes the quantified formula $\exists x_1\ldots\exists x_v F$. It asks TQBF once and returns SAT on YES, UNSAT on NO. The query encoding and parsing costs are polynomial in input bits; the machine is uniform and has polynomial \emph{all-input} worst-case time.

The ordinary pigeonhole CNFs $PHP_{n+1}^{n}$ have $n(n+1)$ variables and $O(n^3)$ signed clauses, and a standard binary source encoding of $N_n=O(n^3\log(n+2))$ bits. Haken's theorem gives ordinary Resolution size $W_{R_{\rm res}}(PHP_{n+1}^{n})\ge2^{\Omega(n)}$. It follows that $\overline W_{R_{\rm res}}(N_n)$ beats every fixed polynomial in $N_n+T_{A^{\mathcal Q}}^{\rm wc}(N_n)$. Taking the same formulas individually defeats oracle-relative B1. The output language's membership in $P^{\mathcal Q}$ defeats oracle-relative B3 for $R_{\rm res}$. No semantic oracle is inserted into a Resolution inference.
\end{proof}

\begin{corollary}[Nonrelativization requirement, conditional on full mixed hardness]
For any fixed oracle-free calculus $R$, if $\overline W_R$ is superpolynomial, then a proposed universal extension
\[
\forall\mathcal O:\quad SAT\in P^{\mathcal O}\Longrightarrow
\overline W_R(N)=N^{O_{\mathcal O}(1)}
\]
is false. In particular, if future work proves a superpolynomial minimum for the \emph{same} $R_{\mathrm{mix341}}$, its sufficient B3 implication must use a genuinely nonrelativizing step or a model restriction not preserved by arbitrary oracle substitution.
\end{corollary}
\begin{proof}
Choose $\mathcal O=\mathrm{TQBF}$. Its oracle machine decides SAT in polynomial worst-case time, but the assumed fixed-system superpolynomial $\overline W_R$ is unchanged by the external oracle.
\end{proof}
