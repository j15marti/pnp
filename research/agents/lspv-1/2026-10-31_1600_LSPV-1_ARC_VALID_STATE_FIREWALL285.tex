\section{Exact source encoding and theorems}
Use Elias-gamma-coded positive headers $n,m$, $w=\lfloor\log_2 n\rfloor+1$, and for each indexed original clause one sign bit followed by three length-$w$ binary \emph{positive integer} identifiers. For every valid formula $m=4n/3$, and the total encoded length is
\[
N(n)=|\gamma(n)|+|\gamma(m)|+m(1+3w)=\Theta(n\log n).
\]
The fixed header is held constant in the following one-bit statement. Thus it is a precise \emph{payload-encoding} theorem, not a claim about arbitrary changing gamma headers.

\begin{theorem}[Fixed-header isolated valid source strings]
Every one-bit mutation in the payload of a valid canonical target source makes it malformed. In the induced Hamming-distance-one graph on fixed-header \emph{valid} payloads there are no edges.
\end{theorem}
\begin{proof}
A clause sign flip changes all three occurrences from one polarity to the opposite and spoils the exact two-of-each polarity quota for each original name. A flipped identifier bit changes exactly one source literal's name from $u$ to a distinct value $v$: either $v$ is outside the allowed range or the signed quota of $u$ loses one occurrence. No simultaneous compensating payload edit occurs. Both transformations violate the required target grammar.
\end{proof}

\begin{theorem}[Unbounded two-bit SAT/UNSAT source cliffs]
For every $k\ge0$, define
\[
U_k=U_{198}\wedge Y_6^{(1)}\wedge\cdots\wedge Y_6^{(k)},\qquad
V_k=V_{198}\wedge Y_6^{(1)}\wedge\cdots\wedge Y_6^{(k)},
\]
with pairwise disjoint source-name sets for the appended copies of a verified six-name target-valid SAT formula $Y_6$. The authenticated D\"ocker $U_{198}$ is UNSAT, and the target-valid $V_{198}$ is SAT. Both resulting inputs are valid target formulas with the same $n=198+6k$, $m=264+8k$, same header, and \emph{exactly two different source payload bits}; their length tends to infinity. Every two-step Hamming path in the input hypercube from $U_k$ to $V_k$ contains a malformed intermediate.
\end{theorem}
\begin{proof}
The $V_{198}$ source exchanges positive occurrences of identifiers $196$ and $197$ at zero-based original clauses 2 and 44, literal slot 2. This preserves each variable's exact $(2,2)$ polarity counts, properness and clause uniqueness. The two identifiers differ in their binary final bit, so each of the two exchanged fields changes exactly one bit, even as the shared fixed width grows. An independently checked 198-bit assignment witnesses SAT for $V_{198}$. The original $U_{198}$ is UNSAT from the verified 64-boundary-row six-module decomposition, with 16 immediate boundary conflicts and 152 checked residual DPLL calls. The six-name $Y_6$ has 20 satisfying assignments, so all disjoint additions preserve the respective SAT/UNSAT labels and target grammar. Every one-bit intermediate is malformed by the preceding theorem.
\end{proof}

\begin{corollary}[Source-read sensitivity is not source edit distance]
For a correct \emph{deterministic, total} indexed-bit decider that accepts a valid target source $F$, every one of its $P=m(1+3w)$ payload bits must be probed during that accepting execution. In the declared fixed-head indexed machine this yields $T(F)=\Omega(P)=\Omega(N)$, notwithstanding the two-bit opposite-label pair family. It does not imply an UNSAT-source read floor or writable-bit change floor.
\end{corollary}
\begin{proof}
If an accepted source bit were never probed, changing just that bit would preserve the deterministic query/answer transcript and acceptance. The one-bit mutant is malformed and must be rejected. Input reads are native work; the input source itself is immutable. A recognizably UNSAT prefix may permit earlier UNSAT rejection on different sources.
\end{proof}
