\section{Exact input family and fixed physical model}
The 15-variable, 20-clause proper signed exact-$(2,2)$ gadget $H(a,b)$ has actual numbers of satisfying assignments $(772,272,272,0)$ in mode order $00,01,10,11$. Disjoint variable-name copies yield
\[
 \operatorname{SAT}(F_m(a,b))\iff a\wedge b=0^m.
\]
Order all $2m$ Alice-dependent source clauses, then $16m$ fixed clauses, then $2m$ Bob-dependent clauses. Canonical encoded length $N_m=\Theta(m\log(m+2))$ admits $G_m=\Theta(N_m)$ fixed middle source cuts. Put $X_a=F_m(a,\bar a)$. All $2^m$ diagonals $X_a$ satisfy SAT, whereas for $a\ne a'$ at least one of the crossed inputs $F_m(a,\bar a')$ and $F_m(a',\bar a)$ is UNSAT.

Fix ONE finite-state deterministic universal interpreter $U$ with $q$ control states, ONE two-way sequential read-only source input head and $k$ fixed sequential read/write work heads/tapes of fixed alphabet size $g$, all initially blank. Input is $p\#X_a$; the entire program prefix $p$ is LEFT of every middle cut. Eligible programs are globally sound:
\[
 \forall p\in\mathcal P\ \forall F\in\mathsf{3CNF}:\ 
 U(p\#F)\downarrow\mathrm{accept}\implies\operatorname{SAT}(F).
\]
Each diagonal can choose a different arbitrarily long sound $p$ with complete hindsight; individual $p$ need not be complete for SAT. All input parsing, program decoding, discovery, failed choices, switching, work-head moves, source reads, work edits, output and halting costs are paid on the same interpreted run.

Define $S$ as all VISITED work cells (including blank), $D$ as ACTUAL symbol changes including restoration to blank, $R$ as input direction reversals, and $T$ as transitions. For common SAME-RUN ceilings $(S_0,D_0,R_0,T_0)$, let
\[
 \begin{split}
 h&=2S_0+3,\qquad V=2q h^k,\qquad C=1+V+khg,\\
 L_0&=\min\{R_0+1,(D_0+1)V+D_0\},\\
 L_*&=\min\{L_0,\lfloor T_0/G_m\rfloor\},\\
 B_C(z)&=\sum_{j=0}^{z}C^j.
 \end{split}
\]
$C$ counts an over-approximation to one full directed crossing event or one actual work-symbol change event (tape, coordinate, new symbol). Initially blank work maps plus chronological edits determine every future-readable work-map at a crossing. No auxiliary independently moving proof head is present.

\begin{theorem}[Joint edit-chronicle distributional capacity]\label{th:density}
Let $\mathcal A_m$ be all diagonal indices $a\in\{0,1\}^m$ for which SOME globally sound inline $p$ leads to ONE accepting $U(p\#X_a)$ run meeting all four ceilings. Then
\[
 \boxed{|\mathcal A_m|\le
 \min\{2^m,\ B_C(D_0+L_0),\
             G_m B_C(D_0+L_*)\}.}\tag{1}
\]
No factor for the number or length of inline programs is necessary in this restricted model.
\end{theorem}

\begin{proof}
For each qualifying $a$ choose an arbitrary eligible accepting run. At each fixed source cut, interleave all actual work-symbol edits with crossings labeled by control, direction and all work-head coordinates. Replaying the edit stream from blank starting maps reconstructs each entire work configuration. Actual edits divide the run into $D_0+1$ no-change epochs. Within one epoch, a repeated complete directed crossing state would repeat a deterministic configuration and loop, contrary to halting. There are at most $V$ directed control/head states per epoch and at most $D_0$ transitions where an edit coincides with a crossing. Thus crossings at any fixed cut are bounded by $(D_0+1)V+D_0$, and independently by $R_0+1$. Consequently each fixed-cut event word has length at most $D_0+L_0$.

If distinct diagonals have equal event words at a predesignated cut, they have identical complete crossing histories. Classical deterministic crossing-sequence splicing produces accepting computations on both opposite cross-sources. Each LEFT shore retains its complete selected sound program prefix; one crossed formula is UNSAT, contradicting global soundness. Therefore distinct accepted diagonal indices map injectively to words of length at most $D_0+L_0$, establishing the first nontrivial bound.

For each accepted run, all $G_m$ middle cuts are crossed in total at most $T_0$ times since one sequential head transition crosses at most one boundary. Select a cut $c(a)$ of at most $\lfloor T_0/G_m\rfloor$ crossings, with event word length at most $D_0+L_*$. Equality of a pair $(c(a),\mathrm{word})$ for two distinct diagonals gives the same crossed-source soundness contradiction. Injection into $G_m$ possible cut IDs times $B_C(D_0+L_*)$ words proves (1), together with the trivial $2^m$ ceiling. The selected cut, program and run may depend arbitrarily on the source, but all charged resources belong to its one realization.
\end{proof}
