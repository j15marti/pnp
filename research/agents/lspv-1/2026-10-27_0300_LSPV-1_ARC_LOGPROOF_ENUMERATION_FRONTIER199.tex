\section{Exact indexed-model quantifiers}
Let $F$ range over \emph{all} ordinary valid encoded CNFs of physical
length $N$. Fix \emph{one} uniform deterministic, total verifier
$V(F,\pi)$ in the indexed read-only-input random-access bit-Turing
machine model of FLMV. The proof bits $\pi$ are explicitly present in
its counted writable/index storage or a model-simulated indexed proof
buffer; no uncharged independent oracle/proof head is supplied.
Require a uniform integer cap $\ell(N)$ computable in $N^{1+o(1)}$
time and $N^{o(1)}$ extra indexed work (for example an explicit
closed formula), together with a uniform per-branch
clock and simultaneous bounds
\[
\ell(N)\le(a+o(1))\log_2N,\quad
T_V(N)\le N^{r+o(1)},\quad
S_V(N)\le N^{s+o(1)}.                                  \tag{1}
\]
All bounds hold for every candidate $\pi$ of length at most $\ell(N)$
(including malformed, wrong-sign, wrong-source and timed-out candidates).
The machine checks actual source addresses and every claimed child,
cache, symbol, transition and proof join; a fixed finite grammar may be
part of $V$ but is not a free semantic primitive. The soundness and
coverage quantifiers are
\[
\begin{split}
 \forall F\in\SAT\ \forall\pi\ (|\pi|\le\ell(N)) &: V(F,\pi)=0,\\
 \forall F\in\UNSAT\ \exists\pi\ (|\pi|\le\ell(N)) &: V(F,\pi)=1.
\end{split}                                                   \tag{2}
\]
A linear-time, logarithmic-space syntactic parser rejects invalid
ordinary-CNF encodings before enumeration; it uses the \emph{same}
indexed input model. A one-bit output is counted. For the displayed
coefficient we assume $r\ge1$, although the theorem also records
the parser-dominated case.

\begin{lemma}[Uniform candidate enumeration with peak-space reuse]
\label{le:enum}
Under (1)--(2), a \emph{single} uniform deterministic total ordinary
SAT decider $D_V$ exists in the same indexed model, with
\[
 T_{D_V}(N)\le N^{\max\{1,r+a\}+o(1)},\qquad
 S_{D_V}(N)\le N^{\max\{0,s\}+o(1)}.                   \tag{3}
\]
\end{lemma}
\begin{proof}
Parse the physical input once. Enumerate all binary strings $\pi$
of lengths $0,\ldots,\ell(N)$ in a uniform canonical order. There are
$\sum_{j=0}^{\ell}2^j=2^{\ell+1}-1\le N^{a+o(1)}$.
For each candidate, start $V$ in its genuine prescribed blank state
with the source $F$ unchanged. If any run returns one, $D_V$
returns UNSAT; if all runs return zero, it returns SAT.
Soundness and completeness in (2) prove both labels, and a
uniform clock handles all malformed/time-out candidates.

For physical reset and the exact same space claim, a fixed simulator
keeps an address-indexed dictionary of only the work addresses actually
touched by $V$; its default is blank. Balanced-tree or sorted indexed
storage supplies $O(\log(N+T_V))$ bit/word overhead per read or
write, and $O(\log(N+T_V))$ storage overhead per live entry. At most
$S_V$ live addressed work cells, finitely many index registers, and
$O(\ell+\log N)$ counter/proof bits are simultaneously retained.
Between candidates, erase/reinitialize the \emph{compacted}
dictionary, never scan arbitrary unused physical source addresses.
Each run visits no more than its physical time bound's number of
work cells, so clearing costs at most $T_V\,\mathrm{polylog}N$;
peak space is $S_V\,\mathrm{polylog}N+O(\log N)$.
All directory and pointer operations are implemented on the native
indexed bit-Turing model with polylogarithmic overhead, not
unit-cost unbounded words. Source reads still request the genuine
read-only source; no data from a failed candidate survives except
the paid enumeration counter. This proves (3) with the same
machine's joint time-space costs.
\end{proof}

\begin{theorem}[A strict all-UNSAT proof-cap forbidden region]
\label{th:flmv}
Write
\[
 c_\star=\frac{241}{200},\qquad
 s_\star=\frac{11642479}{23232400}
   =\frac12\left(\frac{c_\star+2}{c_\star^2}-c_\star\right).
\]
Using the established strict FLMV random-access SAT exclusion in
the verified project source ledger, a verifier satisfying
(1)--(2) must obey
\[
 \boxed{\ s<s_\star\quad\Longrightarrow\quad
       \max(1,r+a)\ge c_\star. \ }                    \tag{4}
\]
For $r\ge1$ this is $r+a\ge c_\star$. In particular
$r=1,s=o(1)$ requires
\[
 \boxed{a\ge c_\star-1=\frac{41}{200}=0.205.}          \tag{5}
\]
The conclusion is that \emph{no such uniform, all-UNSAT-complete
verifier with all bounds strictly inside (4) exists}; it does not
assert a lower bound on every individual certificate or every
restricted source.
\end{theorem}
\begin{proof}
If $s<s_\star$ and $\max(1,r+a)<c_\star$, Lemma~\ref{le:enum}
produces one fixed uniform all-ordinary-SAT decider with
simultaneous native indexed-model exponents \emph{strictly} inside
the excluded FLMV box. Positive exponent slack absorbs
the $o(1)$ and polylogarithmic dictionary overhead.
This contradicts the stated lower-bound theorem. Neither the
time of one machine and space of another nor a sequential-tape
inequality enters this proof. Equality is \emph{not} excluded.
\end{proof}

\paragraph{Precisely what the quantifiers exclude.}
The theorem excludes existence of a uniform globally sound/complete
family under the declared \emph{joint} low clock, proof cap and work
space. It does not say a given hard $F$ has a long proof for
every possible verifier, nor that a nonuniform polynomial-size
proof circuit exists or does not exist. A uniformly effective
catalog of at most $N^{a+o(1)}$ proofs admits the same enumeration
argument if the catalog generator is itself charged within the
stated time/space ceilings.

\section{Separate one-sequential-input-head promise control}
For the genuine signed exact-$(2,2)$ four-mode source $H(u,v)$,
the authenticated $15$-variable/$20$-clause clause list has
model counts $(772,272,272,0)$ and
$\SAT(H(u,v))\Longleftrightarrow\neg(u\land v)$.
With $m$ independent copies in Alice--fixed--Bob order,
$F_m(a,b)$ is SAT exactly when $a\land b=0^m$ and
$N_m=\Theta(m\log m)$.
A single $0$-based index $i$ identifies an UNSAT
$H(1,1)$ module using $\lceil\log_2m\rceil$ bits,
provided the verifier also authentically checks the
selected module or the canonical promise.

\begin{corollary}[Native sequential-input certificate frontier,
restricted and promise-only]
\label{co:tape}
For the above DISJ source family, fix a deterministic verifier
with exactly ONE sequential read-only input head, fixed $k$
sequential work tapes, a simultaneously charged fresh-start
candidate clock $N^{r+o(1)}$, visited-work space $N^{s+o(1)}$,
and all-UNSAT \emph{promise} coverage with candidate cap
$(a+o(1))\log_2N$, sound on all SAT promise sources.
Then the verified HEADMOVE1 native lower bound implies
\[
 \boxed{\ a+\max(1,r)+s\ge2. \ }                      \tag{6}
\]
For a shared one-tape writable-input implementation that
explicitly preserves/reinitializes the entire original source
and whose per-candidate time bound already charges this
operation, the one-tape crossing stripe instead requires
$a+\max(1,r)\ge2$. These are \emph{different} machine contracts.
\end{corollary}
\begin{proof}
On the read-only input machine enumerate $\le N^{a+o(1)}$
candidate indices, resetting the one source head by at most
$O(N)$ physical movements and clearing the at most
$N^{s+o(1)}$ visited work cells between runs.
A verifier touching $S$ cells already uses $T=\Omega(S)$
physical transitions, so the sequential enumerator has
time $N^{a+\max(1,r)+o(1)}$ and peak visited space
$N^{s+o(1)}$. It decides \emph{every promised} $F_m(a,b)$.
The HEADMOVE1 same-machine promise bound
$T(S+1)=\Omega(N^2/\log N)$ yields (6).
In M1, reinitialize the input copy before each run and
include its full traversal in the asserted per-candidate
clock; if that explicit preservation hypothesis is absent
the M1 coefficient claim is not made.
\end{proof}

For the simple DISJ promise, $(r,a,s)=(1,1,0)$ is compatible
with equality in both native tape inequalities.
The same source has near-linear \emph{indexed} acquisition,
so no tape bound such as (6) may be written into FLMV's
random-access ledger. Source only $O(\log N)$ proofs on this
easy promise do not give all-ordinary-UNSAT coverage.

\noindent\textbf{Hostile controls.} An unchecked Alice-only
witness printer is not a globally sound SAT acceptor.
An extra independently movable uncharged proof head
invalidates one-head crossing splicing. Padding a guest SAT
algorithm by $N^D$ delay steps defeats any claim that
full-run certificates with exponent $K$ have a uniform
small $r$. Concise Resolution/affine proofs on easy
minimal-UNSAT controls show that clause minimality,
input sensitivity or large deterministic communication
do not force long certificates. An extensional selector's
small \emph{instance-specific} circuit is not a full
$C_{A,N}$ decision circuit. Cryptographic digests or PCP
sampling require their own exact source-authentication
cost and do not change (2) for free.
