\section{PROPOSE: exact missing implication and four falsifiable mechanisms}
The load-bearing constructive arrow is an unconditional single uniform deterministic polynomial-time map $K$ on a recursively closed class containing arbitrary SAT, satisfying
\[\operatorname{SAT}(K(F))=\operatorname{SAT}(F),\qquad |K(F)|\le |F|^\lambda\quad(0<\lambda<1)\]
for all sufficiently large inputs. Neither the existence of a compact projection nor its polynomial-time construction has been proved. The alternative separation route needs one model-native, all-algorithm resource contradiction. Four narrower mechanisms were registered for this run:
\begin{description}
\item[] \textbf{M1.} A single fully charged program can combine bounded primal elimination width with a small \emph{discovered} strong-2CNF syntactic backdoor and return fully authenticated UNSAT proof records. Falsifier: a mismatched SAT/UNSAT label or an unauthenticated inference. \textbf{PROVED/RESTRICTED}, finite auditing separate.
\item[] \textbf{M2.} Both structural islands can be selected without an answer-class oracle, with failure and intermediate costs polynomial at logarithmic caps. Falsifier: an exponentially long rejected search or a missing cost in one route. \textbf{PROVED/RESTRICTED}.
\item[] \textbf{M3.} An initial reduction to a fixed YES/NO child implies hereditary power shrink on \emph{all} ordinary SAT inputs. Falsifier: a correctly rejected instance for which identity is the only authenticated fallback. \textbf{FALSIFIED for this selector}, not for arbitrary successors.
\item[] \textbf{M4.} The static exact-$(2,2)$ clause-hitting obstruction can be escaped merely by finding a logarithmic strong-2CNF backdoor. \textbf{FALSIFIED}: every exact-$(2,2)$ source has strong-2CNF hitting size at least $n/3$, though width/semantic methods may still succeed.
\end{description}

\section{BUILD: one fixed source-authenticated selector}
Let $F$ be a fully parsed physical proper CNF of clauses of width at most three and bit length $N$. Define $g(F)$ to be the induced width of the \emph{specific deterministic min-fill ordering}, computed from the actual source primal graph, and $\tau_3(F)$ the minimum cardinality of a set of original variables meeting every ternary source clause. Fix $h(N)=\lfloor\log_2\max\{2,N\}\rfloor$. The selector has the following exact and charged control flow:
\begin{description}
\item[] \textbf{Width route.} Compute a min-fill order. If $g(F)\le h(N)$, perform full Davis--Putnam elimination using all genuine source axioms, retaining every non-tautological derived resolvent, pivot, parent identifier, failed candidate pair and complete indexed proof DAG. If the empty clause is derived, output an authenticated refutation; otherwise reconstruct an assignment in reverse elimination order and verify it against the original source.
\item[] \textbf{Backdoor route.} Only when the first width test fails, search an unhit ternary source clause and branch on each of its three original variables, stopping after $h(N)$ choices. All failed branches are charged. If none of the search branches hits every ternary clause, return \texttt{UNKNOWN}. Otherwise enumerate the $2^{|B|}$ assignments to a discovered set $B$. At every residual 2CNF, compute SCCs. SAT returns a full original-variable witness. UNSAT returns either an actual empty residual clause with source index or two source-indexed directed implication paths $x\leadsto\neg x$ and $\neg x\leadsto x$. Parent nodes require both children, with authentic original names.
\item[] \textbf{Physical successor.} A validated \texttt{YES} becomes the fixed proper three-CNF $Y=(x_1\vee x_2\vee x_3)$ (18 ASCII bytes in the executable). A validated \texttt{NO} becomes all eight signed ternary clauses on three variables, $Z$, (86 ASCII bytes). An \texttt{UNKNOWN} becomes the \emph{identical input bytes}, with no claimed shrinking and no guessed label. The two fixed bases are terminal, not recursively compiled again.
\end{description}

\begin{theorem}[Uniform, exact, costed dual-parameter island]
Set
\[\mathcal I=\{F:g(F)\le h(|F|)\ \lor\ \tau_3(F)\le h(|F|)\}.\]
One fixed deterministic uniform program has a polynomial bit-time bound on \emph{every} valid proper width-at-most-three input, returns correct SAT/UNSAT on all $F\in\mathcal I$, and otherwise returns only \texttt{UNKNOWN}. On an UNSAT member it constructs a complete, independently checkable source-indexed resolution or exhaustive SCC-path certificate. Both answer classes are restrictions of \emph{the same program}; there is no free SAT/UNSAT bit.
\end{theorem}
\begin{proof}
A min-fill ordering and its actual width are polynomially computable. If width $w\le h$, each surviving clause on the unprocessed neighborhood of the eliminated vertex has one of at most $3^w$ positive/negative/absent patterns. The width-route stores at most $n3^w$ distinct derived clauses and tries at most $n9^w$ candidate pairs; proof output and verification are charged. Davis--Putnam existential elimination is exact. Its recorded source-parent-pivot DAG derives the empty clause precisely on UNSAT, and reverse elimination produces a correctly verified witness otherwise.

If width fails, a strong syntactic 2CNF backdoor is exactly a hitting set for all ternary clauses: choosing one variable in each eliminates every ternary clause for every assignment. The ternary-edge branching has at most $(3^{h+1}-1)/2$ nodes, scans the genuine source at every node, and finds a hitting set of cardinality at most $h$ if and only if one exists. Exhaustively testing at most $2^h$ residual 2CNFs is exact. SCC contradiction paths are sound when their edge source indices authenticate actual unit or binary residual clauses; the branch-tree verifier checks \emph{both} polarities of every selected variable. A reconstructed SAT assignment is checked against the full parent. Source bytes, parsing, attempted eliminations, unsuccessful hitting branches, all SCC arcs, DFS/reverse passes, proof output, ancestor frames and peak workspace are all within $\operatorname{poly}(N+n9^h+3^h+2^hN)$ bit operations/space. Since $h=O(\log N)$, this is polynomial on every input. No hidden advice, semantic-oracle query or unbounded intermediate representation is used.
\end{proof}

\begin{proposition}[Precise restricted physical descent]
Let $\lambda=3/4$, $N_0=512$, and let $\mathcal C$ consist of $\mathcal I$ and all well-formed inputs with $N<N_0$, together with the two fixed bases. Every $F\in\mathcal C$ with $N\ge N_0$ has one uniformly constructible, answer-preserving child $K(F)\in\mathcal C$ of physical bit length at most $N^\lambda$; all smaller instances are directly solvable using bounded brute force. Hence \emph{this recognized restricted class} is polynomial-time and recursively closed. The same polynomial-time operator defined on arbitrary SAT instances uses an identity fallback and does \emph{not} satisfy the all-input power-shrink requirement.
\end{proposition}
\begin{proof}
The theorem determines the answer on the recognized input before emitting one of two fully serialized bases; $|Z|=86<512^{3/4}$. Both bases have fewer than $N_0$ bits and are terminal. Inputs below the fixed threshold require only constant maximum brute-force time. Outside $\mathcal I$, the identical source is a sound answer-preserving child but has length $N$, so no $N^\lambda$ bound holds for $N>1$. This is a counterexample to inferring a universal contracting successor from recognized-island reductions.
\end{proof}

\begin{proposition}[Balanced-occurrence backdoor firewall]
For every proper signed strict exact-$(2,2)$ three-CNF on $n$ names, every strong syntactic 2CNF backdoor has size at least $n/3$. Under canonical unpadded length $N=\Theta(n\log(n+2))$, the selector's logarithmic backdoor route cannot recognize arbitrary growing exact-$(2,2)$ families. This lower bound constrains this \emph{hitting-set method}, not general SAT time or semantic width.
\end{proposition}
\begin{proof}
The exact quota gives $3m=4n$. Every chosen original name hits exactly four source clauses, hence $4|B|\ge m=4n/3$. The claimed inequality follows. A moving-width decision algorithm may remain efficient (as in the connected cyclic source in the supplied audit).
\end{proof}
