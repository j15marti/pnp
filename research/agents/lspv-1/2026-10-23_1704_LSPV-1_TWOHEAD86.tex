\section{Exact CNF and backward Circuit-SAT bookkeeping}
Put $Q(\ell;a,b)=\bigwedge_{\epsilon,\delta\in\{+,-\}}(\ell\vee a^\epsilon\vee b^\delta)\equiv\ell$. For each $i=1,\ldots,k$ use five distinct source variables $(x_i,a_i,b_i,c_i,d_i)$ and two orientation bits $u_i,v_i$. Define
\[
E_k(u,v)=\bigwedge_{i=1}^k Q(x_i^{u_i};a_i,b_i)\ \land\
\bigwedge_{i=1}^k Q(x_i^{v_i};c_i,d_i),\qquad
x_i^1=x_i,\quad x_i^0=\neg x_i .
\]
All $u$ quartets physically precede all $v$ quartets on one immutable source tape. They are proper, duplicate-free, exactly-three-literal clauses. The complete fixed-width source has
\[
n=5k,\quad m=8k,\quad W=32k+2\ {\rm words},\quad
w=\lceil\log_2(64(13k+1))\rceil,\quad N=Ww\ {\rm bits}.
\]
The exact source semantics are
\[
\boxed{\operatorname{SAT}(E_k(u,v))\iff u=v},
\qquad\#\operatorname{SAT}(E_k(u,u))=2^{4k}.
\]
A shared-input NOT1/OR2/AND2 evaluation circuit has $G=n+3m-1=29k-1$ gates and $J=n+6m-2=53k-2$ gate-input incidences. Its functional gate-definition CNF has $34k-1$ variables and $82k-2$ clauses including output TRUE. Every auxiliary gate is uniquely fixed by original inputs. Backward AND demands and OR literal choices, if used, must preserve shared variable identities. Neither evaluation-gate count nor independent-transversal enumeration is a SAT-solving lower bound.

\paragraph{Signed exact-(2,2) boundary.} $E_k$ is not strict signed exact-(2,2), because $x_i$ occurs eight times. A separately audited connected $H_g$ family has $n=3g,m=4g$, exactly two occurrences of each sign per variable, and its occurrence conflict graph consists of $n$ disjoint $K_{2,2}$ blocks with $4n$ opposite-polarity edges and clause triples partitioning $4n$ occurrence vertices. \section{The exact head-count separation}
A locally moving read-only input head traverses only adjacent \emph{source-word} cells, at one charged step per cell; each source read costs one step. Both independent heads initially occupy the first header word on the same input. Every movement, read, grammar rejection, policy test, switch and entire mutable configuration is charged.

\begin{theorem}[TWOHEAD86, PROVED/EXACT for two local heads]
There is a single uniform deterministic total exact CNF decider $B$ with two independently moving read-only local input heads such that, for every $u,v\in\{0,1\}^k$,
\[
\boxed{T_B(E_k(u,v))=O(k),\qquad S_B(E_k(u,v))=O(\log(k+2))\text{ bits}.}
\]
The space claim includes counters, both head position indices, comparison signs, and policy state. Off this recognizable input family $B$ may fall back to exhaustive exact DPLL.
\end{theorem}
\begin{proof}
A single charged sequential sweep validates the header and every source-literal and quartet pattern, with logarithmic counters and a saved sign bit. If validation fails, use the total exact fallback. Otherwise the $Q$ identity certifies the conjunction of the $2k$ requested literals. Return head one to the first $u$ quartet and advance head two from the leftmost word to the first $v$ quartet. Each repositioning costs $O(W)$ adjacent moves and is paid, not a free seek. Advance the heads in lockstep through their respective consecutive blocks, comparing corresponding $x_i$ signs using two bits and an index. A mismatch forces both $x_i$ and $\neg x_i$, so return UNSAT. Equality through all $k$ pairs provides a satisfying assignment, so return SAT. The scan, head alignment, all source reads, and the comparison total $O(W)=O(k)$ work; peak mutable state, even counting both physical head positions in binary, is $O(\log k)$. The fallback handles all other valid CNFs, establishing total uniform exactness.
\end{proof}

\begin{theorem}[One versus two local heads, model-specific separation]
Let $A$ be any fixed total uniform deterministic exact CNF decider with one locally moving read-only input head whose \emph{complete portable configuration space} on length-$k$ sources has $\sigma_A(k)\le c_A\log_2(k+2)+c'_A$ bits. Then, for all sufficiently large $k$, some satisfying $E_k(z,z)$ requires
\[
\boxed{T_A(E_k(z,z))=\Omega_A(k^2/\log k),}
\]
whereas the two-head $B$ uses $O(k)$ on \emph{all} members. The resulting restricted-model separation factor is $\Omega_A(k/\log k)$.
\end{theorem}
\begin{proof}
Import the already proved CUTFLOW85 complete-crossing-transcript bound
\[
\mathbb E_{z\sim U_k}T_A(E_k(z,z))
\ge \frac{(k-1)(k-2)}{\sigma_A(k)+1}.
\]
Distinct diagonal prefixes produce distinguishable complete crossing sequences; otherwise one-head cut splicing accepts a mixed unequal pair. Summing prefix-free information across the $2(k-1)$ distinct physical quartet cuts yields the bound. Hence some diagonal input attains at least the expectation. The two-head result follows from the first theorem. A second simultaneously located input head invalidates \emph{one-head} cut-splicing: far-side symbols can be consulted directly from another head without transporting them in the portable work state. Charging both head positions does not restore that splicing premise.
\end{proof}

A one-head batch comparator retaining $b$ signs has a charged $O(k+k^2/b)$ upper bound and $b+O(\log k)$ live bits. With $b=\Theta(\log k)$ this matches the one-head lower-bound order. Random access also bypasses the transport premise; an interleaved \emph{different source layout} permits a single sequential comparison. TWOHEAD86 is sharper as it keeps the source byte-for-byte identical.
