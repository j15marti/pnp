\section{Explicit source class and legal machine operations}
A source in $\PATH_0$ is an ordinary, canonically module-sorted CNF on
$3p$ variables, with $p\ge1$. Module $i$ owns variables
$(3i+1,3i+2,3i+3)$, and contains the four proper signed ternary
clauses excluding even-parity bit assignments. Thus each module
satisfies $x_{i,1}\oplus x_{i,2}\oplus x_{i,3}=1$. Every additional
clause is unary or binary, and every binary crosses at most
one neighboring module. Its owning module is the smaller module index
of its variables. A root has at most $C_0=16$ additional
clauses per owner, and all clause records are ordered by owner.
There may be duplicates and contradictory units; both labels occur.
For depth $j$, define $\PATH_j$ by the same grammar with cap
$C_j=16+6j$ on extras per owner. Missing XOR clauses,
nonlocal clauses, malformed records, unsorted ownership or exceeded
caps are outside the declared domain. This validation is effective by
a single source scan with logarithmic-size counters and a four-bit
mask per current module; it makes no SAT-label query.

At any block cut, all clauses crossing the cut involve only the last
module on the left and the first on the right. A boundary signature
is the assignment to just those coordinates appearing in crossing
clauses. Projecting the four odd-parity module assignments onto any
subset $S$ of its three coordinates yields at most four signature
values, even for $|S|=3$ (instead of eight raw states).
For $|S|=1$ there are exactly two signatures.
The per-block left/right joint signature count is at most $4\cdot4=16$.
Construct an actual ordinary child by retaining the block's entire
module contents, discarding only outgoing/incoming cross-cut binary
clauses (handled by the parent), densely renumbering its variables,
and adding unit pins for its incoming/outgoing signature bits. A block
with one module may acquire six pins, so the child lies in
$\PATH_{j+1}$; for longer blocks the cap is conservative.

\begin{lemma}[Exact compatible gluing, both labels]
Let a parent $F\in\PATH_j$ be partitioned into contiguous complete
module blocks $I_1,\dots,I_B$. For a boundary word $\ell$ on the first
module's external coordinates and $r$ on the last module's external
coordinates, let $C_b(\ell,r)$ be the ordinary pinned child and
$R_b(\ell,r)=\SAT(C_b(\ell,r))$.
Then $\SAT(F)$ holds if and only if there is a selection of one
$(\ell_b,r_b)$ per block with every $R_b=1$ and every original
cross-cut binary clause satisfied by its neighboring $r_b$ and
$\ell_{b+1}$. The equivalence holds also when blocks contain contradictory
units and when a one-module block's two sets of pins overlap.
\end{lemma}
\begin{proof}
Every model of $F$ induces module signature projections and a model
of each pinned block. Conversely, satisfying pinned child witnesses
live on pairwise disjoint original module sets; preserving original
names at each cut allows these witnesses to be united. The crossed
binary clauses are separately checked on their actual endpoint
variables. The union therefore satisfies every original clause.
Absence of a compatible choice certifies UNSAT. The proof requires
no independent per-block witness to agree with a differently named
copy of a shared variable: each module belongs to exactly one block.
\end{proof}

\section{Actual depth-two compiler and joint resource envelope}
Fix any one uniform exact all-input ordinary-SAT machine $A$ with joint
achievable $(t,s)$, $t\ge1$, and any fixed integer depth $d\ge1$.
A fixed contractor $C_{A,d,j}$ on promised $\PATH_j$ inputs uses
$B=\lceil\sqrt p\rceil$ balanced contiguous module blocks. It scans
the canonically grouped read-only source in order, stores one
$O(\sqrt p\log p)$-bit block and its $O(1)$ cut descriptors, tests all
at-most-sixteen signature pairs, serializes the resulting ordinary
children one at a time, and runs $C_{A,d-1,j+1}$ on each.
A constant-state dynamic program combines the exact relations and the
original cross-cut clauses. The base case runs the one fixed
supplied all-input $A$ on physically serialized ordinary children.
No parent-scale $A$ call, oracle SAT label, or free write-only child
input is used along promised paths. All source reads, output writes
including unchanged writes, parser and arithmetic/control operations,
child header/body bits, renumbering, switching, negative child results,
index changes, buffers and live ancestor state contribute to the costs.

\begin{theorem}[Restricted all-label simultaneous exponent contractor]
For every fixed $d$, there is a uniform exact machine on every
$\PATH_0$ input, with simultaneous conditional upper exponents
\[
\boxed{\quad t_d\le1+2^{-d}(t-1),\qquad
s_d\le\max\{1/2,2^{-d}s\}.\quad}
\tag{1}
\]
These are source-promised exponents, not new pairs in the ordinary
all-input achievable set $E$. The child class is precisely
$\PATH_{j+1}$ at stage $j$, including its at-most-six extra pins.
\end{theorem}
\begin{proof}
For fixed $j$, $C_j$ is constant and there are four mandatory
ternary records per module, so the ordinary canonical CNF bit length
is $N=\Theta(p\log(p+2))$. Each of $B=\Theta(\sqrt p)$ blocks
contains $O(\sqrt p)$ modules and $O(C_j\sqrt p)$ clauses. Its
physically serialized child has $N^{1/2+o(1)}$ bits. At most $16B$
children are ever invoked per parent. Validation uses a streaming
constant-mask/count controller. Because ownership is canonically
sorted, a single sequential pass identifies and buffers each block;
there is no $B$-fold full-source rescan. Each output bit, pin and
literal renaming is paid, giving $N^{1+o(1)}$ time for construction
and DP, and a peak writable/index buffer of $N^{1/2+o(1)}$ bits.
The matched TM simulation of a guest's indexed input on its
physical work-tape buffer incurs polylogarithmic access and
addressing costs, including guest index tapes. Sequential depth-first
calls reuse guest tapes, so no sibling state is live concurrently.
Thus, conditional on the supplied machine's joint exponents,
\[
 t_{j+1}\le\max\{1,\tfrac12+\tfrac12t_j\},\qquad
 s_{j+1}\le\max\{\tfrac12,\tfrac12s_j\}.
\]
For $t\ge1$, finite induction gives (1), and all constant caps,
program text and recursion depth are independent of the CNF length.
\end{proof}

\section{All-input total dispatcher and its exact obstruction}
Define $W_A(F)$ as follows: syntax-check an arbitrary ordinary CNF input.
If it lies in $\PATH_0$, run the above fully charged contractor; otherwise
run the original all-input solver $A$ on the unchanged full-length input.
This is ONE uniform, total exact ordinary-SAT decider on every input,
with both SAT and UNSAT protected. However its certified global envelope is
\[
 t_W\le\max\{1,t\},\qquad s_W\le\max\{1/2,s\},
\]
which does not improve arbitrary initial high exponents.
For every fixed polynomial SAT solver under the assumption $P=NP$,
there exists a sound padded guest $A_K$ spending $N^K$ steps before
solving SAT; a family of noncanonical or missing-XOR ordinary formulas
causes this particular wrapper to call $A_K$ at parent length $N$.
Therefore a favorable all-input ARC edge cannot be certified from this
literal fallback architecture. A different existential/program-aware
construction is not excluded.

\paragraph{Finite hardness firewall.}
The promised class has a direct linear-frontier dynamic program with
constant affine state, so it is a polynomial-time decidable class even
without any supplied hypothetical $A$. A near-linear, model-preserving
FLMV-hard reduction image wholly contained in this class would itself
contradict the published FLMV theorem. Such image membership cannot be
assumed as a reduction transport step.

\section{Discontinuity interpretation, dependency DAG and handoff}
A single affine projection from three raw boundary bits to two
independent bits reduces the number of feasible signatures from eight
to four. Switching from one interface bit to two changes the number
of signatures from two to four. Such bounded-size discontinuities
alter constant factors, not asymptotic resource exponents. To obtain a
nonzero time-exponent change from an enumeration fanout $2^{w(N)}$,
one needs a net $\Theta(\log N)$ change in effective width, unless a
separate structural algorithmic transition changes the rule itself.
This is a falsifiable ARC resource target, not a lower bound.
