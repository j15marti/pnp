\section{Single proof-arrow target, exact machine, and four preregistered falsifiers}
The target is one sound locally authenticated alternative to validating the \emph{totality} of Role 1's canonical first-falsified-clause circuit $J_F$. Fix an indexed read-only source tape encoding an ordinary CNF formula $F$ of physical length $N$ and a one-way read-only or conondeterministically supplied proof stream $\pi$ of length $P$. Every source-clause pointer denotes a physical byte offset in the authentic source; the verifier checks the actual line boundary, terminator, signed literal identifiers, and equalities, not an untrusted memoized clause table. We distinguish \emph{semantic proof existence}, \emph{proof discovery}, and \emph{machine-wide worst-case verification}.

The longer-range ARC-achievable set $E$ contains pairs $(d,s)$ jointly attained by \emph{one fixed uniform deterministic total all-ordinary-input} SAT decider $A$ in FLMV's indexed-read-only-input random-access machine, $T_A(N)\le N^{d+o(1)}$ and writable/index $S_A(N)\le N^{s+o(1)}$. Under $P=NP$ some unknown $(K,K)$ is in $E$. A fixed $d=1.802$ and $s=o(1)$ is a separate hypothesis; neither is assumed here.

\section{Authenticated rule grammar and exact SAT-side soundness}
Represent literals by nonzero signed identifiers; two distinct literals have distinct absolute identifiers. Define the local source macros
\begin{align}
 \mathsf{PAIR2}(a,b,z)&:\quad (a\vee b\vee z)\wedge(a\vee b\vee\neg z) \equiv a\vee b, \label{eq:pair}\\
 \mathsf{QUAD1}(a,y,z)&:\quad\bigwedge_{\epsilon,\delta\in\{+1,-1\}}(a\vee\epsilon y\vee\delta z)\equiv a.\label{eq:quad}
\end{align}
Here $a,b,y,z$ are signed literals, with three distinct underlying variable names as appropriate; complements are signed-literal negations. The macro record includes \emph{two or four} physical source-byte offsets, the claimed literal tuple, and an implication endpoint pair. Every offset is authenticated against the actual proper source clause (with no arithmetic inference from a printed ordinal). Equation~\eqref{eq:pair} certifies edges $\neg a\to b$ and $\neg b\to a$; Equation~\eqref{eq:quad} certifies $\neg a\to a$. The same source offsets may be reused; the verifier rereads and charges each access. For the read-only source family, each macro has a constant number of ternary local witnesses. No purported line is accepted merely because its literals appeared in a guessed circuit.

\begin{theorem}[Source-authenticated two-path refutation, PROVED/EXACT]\label{th:proof}
For \emph{every} proper signed ternary $F$, if a finite proof stream consisting of valid authenticated PAIR2 and QUAD1 edge records contains a directed path $x\leadsto\neg x$ and a directed path $\neg x\leadsto x$ for some source variable $x$, then $F$ is UNSAT. In particular, for every SAT $F$, no such accepted proof stream exists, irrespective of its guessed length or content. This does not assume the separate canonical circuit $J_F$ is a total conflict selector or query any SAT oracle.
\end{theorem}
\begin{proof}
Every checked edge is an actual logical consequence of two or four authentic source clauses, hence of $F$. A satisfying assignment of $F$ must respect each implication along either path. If $x$ is true, the first path forces $\neg x$, contradiction; if $x$ is false, the second path forces $x$, contradiction. Therefore no satisfying assignment exists. Each source offset is checked, so a forged edge or guessed proof cannot introduce an invalid consequence.\end{proof}

\begin{lemma}[Uniform streamed checker, restricted claimed machine bound]\label{lem:resources}
For a certificate of $E_\pi$ edge records, each referencing at most four source clauses, there is a fixed, total, deterministic verifier with source read-only random access and sequential proof access that takes
\[
 T_V(N,P)=O\bigl((N+P)\operatorname{polylog}(N+P)\bigr),\qquad
 S_V(N,P)=O\bigl(\log(N+P)\bigr)
\]
working and index bits, uniformly over \emph{all guessed proofs}. It may reject on exhausted clock, malformed source, invalid offsets, or an incomplete path. The implemented Python reproducer retains the parsed source and is \emph{not} a physical FLMV-workspace benchmark. No corresponding sublinear-space \emph{certificate generator} is established.
\end{lemma}
\begin{proof}
One source pass checks the DIMACS header and canonical three-literal proper line grammar using counters, a constant number of signed indices and source positions. For each streamed proof edge, the checker stores two endpoint identifiers, up to four $O(\log N)$-bit offsets, and a bounded number of signed literals. It seeks and parses each authentic source record using its index tapes, verifies every paired/quad clause equality and one of the allowed implication orientations, then updates the current path vertex. The two paths are checked sequentially; the shared pivot requires one $O(\log N)$-bit register. At most a constant number of source lines is decoded per edge, and each physical byte read, output proof symbol, unchanged write, address operation and control update is charged by the displayed polylogarithmic factor. There are no residual stores, cached oracle answers, or parent $A$ invocations. An a priori polynomial cap on proof bits produces a single valid uniform clock, but an input-specific minimum proof length is not silently substituted for it.\end{proof}

\section{An explicit connected minimally UNSAT proper signed 3CNF family}
For every $n\ge2$ consider the underlying minimally UNSAT $2$CNF chain
\[
 Q_n=(x_1)\wedge\bigwedge_{i=1}^{n-1}(\neg x_i\vee x_{i+1})\wedge(\neg x_n).\tag{3}
\]
Its satisfying assignments would need $x_1=\cdots=x_n=1$ by forward implication, contradicting the final unit. Removing the left unit is witnessed by all zeros; removing the right unit by all ones; removing any middle implication with index $i$ is witnessed by the step assignment $x_1=\cdots=x_i=1$, $x_{i+1}=\cdots=x_n=0$.

Pad every binary $(a\vee b)$ with its own new variable $z$ into the \emph{two} proper ternaries of~\eqref{eq:pair}. Pad every unit $(a)$ with its own two fresh variables $y,z$ into the \emph{four} ternaries of~\eqref{eq:quad}. Write the resulting proper signed three-CNF as $F_n=\operatorname{Pad}(Q_n)$. Every original constraint equals its pad bundle as a Boolean formula \emph{for every value of the fresh variables}, not merely after existential projection.

\begin{theorem}[Connected minimality and global hitting bound, PROVED/EXACT]\label{th:family}
For all $n\ge2$, $F_n$ has exactly $2n+3$ variables and $2n+6$ unique proper ternary clauses, is connected in its clause-variable incidence graph, and is minimally UNSAT: deleting \emph{any single ternary clause} makes it satisfiable. Let $B\subseteq V(F_n)$ intersect the variables of every original ternary clause. Then
\[
 |B|\ge\left\lfloor\frac n2\right\rfloor
       =\Omega\!\left(\frac{N_n}{\log N_n}\right),
 \quad N_n=|\operatorname{enc}(F_n)|=\Theta(n\log n).
\]
Despite that global clause-hitting lower bound, $F_n$ has a zero-branch PAIR2/QUAD1 certificate with \emph{exactly $2n$ implication-edge records}, physical proof size $O(n\log n)$, and no call to an arbitrary SAT solver.
\end{theorem}
\begin{proof}
There are $n-1$ fresh binary-pad names and four distinct endpoint-unit-pad names, hence $2n+3$ variables and $2(n-1)+8=2n+6$ clauses. Each ternary contains three distinct variables; privately fresh pad names and distinct base clauses prevent duplicates. The $x_i$ chain links every original variable, and every pad variable attaches to one of these original variables, so the incidence graph is connected. Unsatisfiability follows from the exact pair/quad identities.

For minimality, remove one ternary of the first unit quartet. Use the all-zero $x$ assignment and choose its two pad bits to falsify \emph{exactly} the deleted ternary; the other three quartet members become true. Do the sign-dual construction with all $x$ true for a deletion from the last quartet. For a deletion from binary pair $i$, choose $x_1=\cdots=x_i=1$ and $x_{i+1}=\cdots=x_n=0$; the original implication $\neg x_i\vee x_{i+1}$ is false, but one can set its pad variable to satisfy the surviving ternary. Every other base constraint is true, hence all its pad clauses hold. This constructs a total source assignment satisfying every remaining ternary.

For odd indices $i=1,3,\ldots\le n-1$, select one ternary from the $i$th binary pad pair. Its three-variable support is $\{x_i,x_{i+1},z_i\}$. These supports are pairwise disjoint. Any global clause-hitting set must hit one variable in each selected support, yielding at least $\lfloor n/2\rfloor$ names.

A local certificate first follows $x_1\to x_2\to\cdots\to x_n$ by the pair-derived forward implications, then uses the final quad-derived $x_n\to\neg x_n$ and the pair-derived contrapositives $\neg x_n\to\cdots\to\neg x_1$. This first path has $2n-1$ edges. The first unit quartet supplies the final $\neg x_1\to x_1$ second path, for a total of $2n$ edges. Its only references are authentic source offsets, each of $O(\log N_n)$ bits. Theorem~\ref{th:proof} establishes soundness.\end{proof}

\begin{corollary}[Exact polynomial coverage for the padded $2$CNF image only]\label{co:2sat}
For every UNSAT $2$CNF $Q$ with $q$ distinct active variables and $m$ nonempty clauses, $\operatorname{Pad}(Q)$ admits an accepted PAIR2/QUAD1 certificate with at most $4q-2$ implication records and length $O(q\log N)$, with $N=|\operatorname{enc}(\operatorname{Pad}(Q))|$. Every SAT $Q$ admits none. This is a sound, complete and uniformly polynomially bounded \emph{restricted-image} proof relation; proof construction by an implication-graph algorithm can use linear-size writable graph storage and is fully separate from low-workspace verification. It does not furnish a coNTIME SAT decider on all ordinary inputs.
\end{corollary}
\begin{proof}
Every base binary/unit constraint has an exact pair/quad source derivation. Its implications form exactly the classical $2$SAT graph of $Q$. By the Aspvall--Plass--Tarjan criterion \cite{aspvall1979}, $Q$ is UNSAT iff some $x$ has paths $x\leadsto\neg x$ and $\neg x\leadsto x$. Take simple paths in a $2q$-vertex graph, each with at most $2q-1$ edges. Encode each edge by its original source pad offsets and authenticated local rule; Theorem~\ref{th:proof} proves the converse.\end{proof}

\section{Strong negative control: the requested clause-monotone exact-$(2,2)$ language}
\begin{theorem}[Typing firewall, PROVED/EXACT]\label{th:monotone}
No \emph{proper clause-monotone} ternary source, regardless of the signed occurrence quotas, contains a valid PAIR2 or QUAD1 source-line pattern with pairwise distinct variable names. Consequently a bare leaf-only grammar containing just these two rules cannot produce a nonempty implication path for any such formula, including the original 198-variable, 264-clause UNSAT source of D\"ocker. This is a failure of this limited grammar, \emph{not} a lower bound on arbitrary adaptive source-authenticated proofs, arbitrary SAT algorithms, or signed exact-$(2,2)$ regularization.
\end{theorem}
\begin{proof}
In PAIR2, both clauses contain the same two signed literals $a,b$ and contain $z$ and $\neg z$, respectively. If $a,b$ have opposite signs, neither clause is monotone. If they have the same sign, exactly one of the complementary $z$ choices could yield a monotone clause. Hence both required clauses cannot simultaneously be monotone. QUAD1 requires both polarities of each private $y,z$ alongside the same $a$, so at least one quartet member is mixed-sign. No rule fires.\end{proof}

The original D\"ocker source was recovered at
\path{research/agents/lspv-2/2026-10-24_0011_DOECKER61_original_source.txt}, and its 264 original records were independently checked in the source connector: every original variable has precisely two occurrences per sign and every clause is monotone. There are zero PAIR2 matches among 264 clauses. The independent fifteen-variable, twenty-clause UNSAT $W_1$ source (signed exact-$(2,2)$ but nonmonotone), included in the reproducible script, also has zero such pairs and was UNSAT by independent $2^{15}$ exhaustive assignments. Neither instance proves an impossibility for the richer Role-3 $\mathsf{BRANCH}/\mathsf{EMPTY}/\mathsf{PATH}$ grammar.

\textbf{Duplication/difference audit.} Role-3 already proved an authenticated partial-2CNF $\mathsf{PATH}$ rule after original-variable restrictions, and the existing backdoor-SCC family covers bounded-source supports. \textbf{Theorem-model firewall.} Van Melkebeek Theorem 1.3, in its original ECCC PDF \cite{vanmelkebeek2007}, requires \emph{both} a co-nondeterministic \emph{all-SAT} random-access time-$N^c$ machine and a separate deterministic \emph{all-SAT} machine with simultaneous time $N^d$, space $N^e$, under $(c-1)d<1$ \emph{or} $cd(d-1)-2d+1<0$. Our verifier is a restricted-image UNSAT proof checker, neither such a total all-SAT conondeterministic machine nor a deterministic decision circuit $C_{A,N}$. The FLMV joint forbidden region \cite{flmv2005} applies to a same-model one-program all-input decider; a $2$CNF-family conditional bound cannot be inserted into its strictly forbidden box. Ben-Sasson--Wigderson's resolution size/width theorems \cite{bensasson2001} further warn that tractability of a restricted proof system on selected formulas cannot provide all-formula affordable proofs, and that resolution lower bounds do not transfer to arbitrary SAT algorithms or stronger algebraic proof systems. The constructed family is easy for implication-graph algorithms, including known SAT and UNSAT-side shortcuts.
