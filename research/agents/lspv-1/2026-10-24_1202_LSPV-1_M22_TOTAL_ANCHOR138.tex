\section{Canonical language and three falsifiable hypotheses}
Let $\CM$ consist of CNFs with exactly three distinct variables per clause, unique clause records, each clause wholly positive or negative, and every active variable occurring exactly twice per sign. For each clause $C$, let $\bar C$ flip all literal signs while retaining OR. Define $\mathcal P_{\rm pair}=\{F\in\CM:\forall C\in F,\bar C\in F\}$ and $\CS=\CM\setminus\mathcal P_{\rm pair}$. The decision language $L_\star$ accepts precisely the valid encodings of satisfiable $\CS$ instances and rejects all invalid encodings. Partial complementary pairs, disconnected formulas, easy instances and non-minimally-unsatisfiable instances remain allowed. For valid inputs $k=n(F)$, $3m=4k$ and $m_+=m_-=2k/3$. The full encoded bit length $N=\Theta(k\log(k+2))$ is distinct from $k$.

D\"ocker's theorem that $\CM$ is NP-complete and his fully paired SAT theorem are \textbf{KNOWN THEOREM} [1]. Three hypotheses were tested.

\item[] H2: Appending a fresh valid six-variable anchor restores arbitrary pinned recursive children to $\CS$. \textbf{FALSIFIED/RETIRED} by the precise Role 5 nonadapter lemma.
\item[] H3: Every target input with an unbounded unmatched-support count requires superpolynomial \emph{post-acquisition} work from every exact decider. \textbf{FALSIFIED} by an easy recognizable family; this does not refute correctly quantified worst-case hardness.
\end{description}

\section{Declared bit encoding and fixed anchor}
Use the following precise dense indexed \emph{clause-list} encoding. For $k\ge6$, set $w=\lceil\log_2(k+1)\rceil$. Encode a header $1^w0$ followed by a $w$-bit unsigned $k$ and a $(w+1)$-bit unsigned $m$. Each of the $m$ clauses has three literal records, each one signed bit followed by a $w$-bit unsigned variable ID. Literal IDs must strictly increase within each clause, be in $\{1,\ldots,k\}$, and all three signs must agree. The complete length is $N=3w+2+3m(w+1)$. Unique signed clauses and the four-per-variable signed counts are validity requirements; the clause list itself need not be globally sorted. All malformed bit strings are outside the language.

Let $Y$ have positive supports $\{123,145,246,356\}$ and negative supports $\{124,136,235,456\}$. \section{Exact new link: total grammar reflection without full validation}
Define a header-only gate $G(x)$ on an arbitrary binary source $x$. It checks the unary-width terminator, the two header fields, canonical width, $k\ge6$, $3\mid k$, $m=4k/3$, and exact physical input length $3w+2+3m(w+1)$. It does not check any source literal, duplicate, sign, occurrence quota or SAT answer. If $G$ rejects, output the fixed invalid bit string \texttt{0}.

If $G$ passes, set $k'=k+6$, $m'=m+8$, $w'=\lceil\log_2(k'+1)\rceil$, and create the correct target header. For each of the original $3m$ literal fields copy its sign and transform its variable ID using
\[
f_k(a)=\begin{cases}a&1\le a\le k,\\0&a=0\text{ or }a>k.\end{cases}
\]
Finally append the eight $Y$ clauses, with six fresh IDs $k+1,\ldots,k+6$. Denote the transformed binary string $A_{\rm total}(x)$.

\begin{theorem}[Malformed-input-reflecting total anchor; PROVED/EXACT]
For every binary string $x$, without a promise that $x$ represents a valid source,
\[
\boxed{\operatorname{Valid}_{\CM}(x)\iff\operatorname{Valid}_{\CM}(A_{\rm total}(x)).}
\]
When $x$ is valid the output belongs to $\CS$, has $k'=k+6$, $m'=m+8$, and
\[
\boxed{\#\mathrm{SAT}(A_{\rm total}(x))=20\#\mathrm{SAT}(x).}
\]
Consequently $x\in L_{\mathrm{M22}}\iff A_{\rm total}(x)\in L_\star$, including all malformed NO instances. A streamed explicit transformation takes $N\operatorname{polylog}N$ elementary bit work and $O(\log N)$ writable/index bits excluding write-only output. A random-access bit accessor for the target takes $\operatorname{polylog}N$ elementary bit work per target bit and $O(\log N)$ extra peak live bits, without an $N'$-bit writable target tape.
\end{theorem}
\begin{proof}
A failed header gate rejects a condition required of every valid source; its one-bit output is invalid. On a passed header, copying the original signed fields preserves every valid original clause and source-variable count. Extra $Y$ variables are disjoint, so cannot fix a duplicate source clause, a mixed-sign clause, an unsorted source triple, a missing source name, or a wrong original signed count. An out-of-range original ID is mapped to zero, which is explicitly illegal in the target, so it cannot be repaired merely because the enlarged target permits more variable IDs. Conversely, every valid target has no zero ID and, when restricted to the first $k$ source names and first $m$ clause records, satisfies each original grammar condition. Thus source validity is equivalent to target validity.

The fresh $Y$ support includes a clause without its literalwise complementary clause, irrespective of the old source. Therefore every valid target lies in $\CS$. SAT assignments of a disjoint union multiply; $Y$ has 20 models, proving the exact model-count identity and both-label correctness.

A target header bit depends only on $k,m,w$. For an original literal field, an accessor uses the target index to locate its original source field; it returns its unchanged sign or reads the $w=O(\log N)$ old identifier bits, compares the result to $k$, then returns the correct $w'$-bit representation of $f_k(a)$. A fresh-$Y$ bit is synthetic from a fixed table. All index arithmetic, reads, comparisons, access control and writes are charged. The accessor retains only $O(\log N)$ bits. Producing each of $N'=N+O(k+\log k)$ explicit bits through this accessor yields the stated streamed bound.
\end{proof}

\begin{corollary}[Simultaneous resource transport, not an ARC edge]

\[
T_{\mathrm{M22}}(N)\le(1+T_\star(N'))\operatorname{polylog}(N+2),\qquad
S_{\mathrm{M22}}(N)=O(S_\star(N')+\log(N+2)).
\]
Here $N'=\Theta(N)$ on framed source strings. Thus for fixed exponents $t\ge1,s\ge0$, one jointly achievable $(t,s)$ upper bound on $L_\star$ transports to $L_{\mathrm{M22}}$ without the earlier conservative quadratic full-validator penalty. No fine-grained ordinary-SAT-to-$L_\star$ transport or FLMV forbidden endpoint follows.
\end{corollary}
\begin{proof}
Simulate target indexed read-only input probes using the accessor, never materializing a readable target; keep target machine work and index tapes and the $O(\log N)$-bit descriptor. Charge every target/source probe, address operation and unchanged write. Header-gate rejection directly outputs NO. Polylogarithmic per-probe simulation overhead preserves both resource exponents \emph{within one machine}.
\end{proof}
