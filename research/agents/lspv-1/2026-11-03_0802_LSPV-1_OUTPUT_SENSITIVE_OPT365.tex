\section*{Fixed calculus, exact quantifiers}
The unchanged $R_{\mathrm{mix341}}$ permits authenticated zero-cost original general-CNF source clauses and paid unit-cost strict RES, exact local AND3, binary GF$(2)$ XOR, LOCAL-CONVERT and source-independent conservative fresh two-input signed VARDEF. Distinct inference DAG nodes count once. The present theorem concerns only $E=\mathrm{ER2}$, the already fixed signed RES plus paid fresh-AND-VARDEF fragment with three authenticated signed definition slots. No changes to rules, weights, syntax or semantic justifications are made. Let $N=|\operatorname{enc}F|$ \emph{bits}, $q=W_E(F)$ the minimum paid inference-node count over all legal refutation DAGs, and $\overline W_E(N)$ the worst such minimum over valid UNSAT encodings of length at most $N$ (empty maximum zero). Complete RES and positive integer weights ensure $q$ exists for UNSAT inputs. Free optimum choice does not waive real optimizer work.

\begin{lemma}[Direct polynomial ER2 evidence normalization]
For every valid general-CNF $F$ and any $q$-node paid $E$ proof, there is a variable-renamed, source-authenticated equivalent proof with $O((N+q+2)^3)$ encoded bits and a polynomial-time deterministic verifier. Every accepted proof is sound.
\end{lemma}
\begin{proof}
Dense-renumber original variables (at most $N$) and fresh extension variables (at most $q$). Every RES conclusion has at most $N+q$ distinct signed literals; each paid gate record contains two signed inputs, one fresh output, and three constant-width signed slots. $q$ node records need $O((N+q+2)^2\log(N+q+2))$ bits including explicit conclusions, premise and slot references. The verifier checks source syntax, topological references, signed pivots and exact nontautological resolvents, definition freshness/acyclicity, all conservative slots, the empty root and the charged count. This argument depends on \emph{ER2's fixed bounded-output grammar}. It does not imply that one unit-cost unrestricted circuit-valued LOCAL-CONVERT node has polynomial bit size.
\end{proof}

\begin{theorem}[Budget-free output-sensitive exact proof acquisition]
Assume SAT is in P and fix any one uniform polynomial-time total correct general-CNF SAT decider $A$, which also rejects malformed inputs. There exist a single total uniform algorithm $S_A$ and constants $C_A,c_A>0$ such that, for every valid UNSAT $F$ of $N$ encoded bits, $S_A(F)$ outputs a genuine minimum-cost ER2 contradiction DAG with
\[
T_{S_A}(F)\le C_A(N+W_E(F)+2)^{c_A}.
\tag{1}
\]
The algorithm is not given $W_E(F)$ or a proof budget. On SAT inputs it outputs a verified satisfying assignment, and on malformed inputs it reports an error.
\end{theorem}
\begin{proof}
The unary-budget language $\mathcal B_E=\{(\operatorname{enc}F,1^b): F\text{ valid and }W_E(F)\le b\}$ belongs to NP: the preceding lemma supplies a witness of size polynomial in $N+b$ and the verifier tests all inferences. Given $A$ and Cook--Levin, we can decide $\mathcal B_E$ in time $(N+b+2)^{O_A(1)}$, and extract a complete authentic witness by polynomially many SAT prefix self-reduction calls, with independent final replay.

First parse $F$, then use $A$ to classify it. For SAT, recover and verify a model by ordinary SAT self-reduction; malformed inputs never enter the proof loop. For UNSAT query budget $b=0$. If YES, the original source contains the empty clause and $q=0$. Otherwise query $b=1,2,4,8,\ldots$ until the first YES, which exists by RES completeness. With $q=W_E(F)\ge1$, the first successful $B$ obeys $q\le B<2q$ (allow equality $B=q=1$). Binary search $[0,B]$ to determine the exact minimum $q$ and recover a proof at budget $q$. The number of budget calls is $O(\log(q+2))$, each using work polynomial in $N+B=O(N+q)$. Including construction of each Cook--Levin instance, all SAT oracle simulations by $A$, certificate-bit retrieval, proof checking, failed budgets, output and memory operations yields (1). No rejecting trace of $A$ is treated as an UNSAT axiom.
\end{proof}

\section*{Consequences and the precise remaining gap}
This is \emph{output-polynomial}, not polynomial solely in $N$. An explicit proof producer pays at least $\Omega(q)$ bit-output operations, which does \emph{not} lower-bound the time of an arbitrary SAT decider that emits no proof. This result strengthens LSPV-1 BUDGETED-PROOF-SEARCH364 only by removing the externally supplied unary budget and proving a direct ER2 evidence bound. The statement that SAT in P alone forces $q$ polynomial in $N$ is still missing. In particular,
\[
\mathrm{SAT}\in P\stackrel{?}{\Longrightarrow}\exists C,k\ \forall N:
\overline W_{R_{\mathrm{mix341}}}(N)\le C(N+1)^k
\]
remains the primary unproved B3. The algorithm's output need not be globally shortest in full $R$, since $W_R(F)\le W_E(F)$.

LSPV-4 LOCAL-CONVERT-CVP363 and LSPV-5 REFEREE315 give a separate conditional syntax-U counterexample to \emph{raw} evidence length being polynomial in paid-node count, by hiding an arbitrarily long circuit inside a single LOCAL-CONVERT payload. Thus the present direct ER2 normalization must not be silently generalized to the full mixed grammar. Any extension requires a downstream-preserving normal form or an explicit gate-payload charging convention determined \emph{before} the instances. Machine time includes all parsing/source/index/head reads, output, search, failed budgets, child materialization, checks and caches. Peak simultaneously live space includes each phase; the corrected recursive envelope remains $s'\le\max\{\rho,\eta,\lambda,\lambda s\}$. No same-machine FLMV transfer is established.
