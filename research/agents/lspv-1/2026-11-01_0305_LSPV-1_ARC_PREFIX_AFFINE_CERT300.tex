\section{Original-source affine saturation}
Let $F$ be any valid canonical source and $p$ any coherent original-variable partial assignment with no original clause falsified. Let $f$ be the number of free originals and $U(p)$ the set of original clauses not already satisfied by pinned literals, $u=|U(p)|$. For each free original $x$, let $s_x^+,s_x^-$ count its signed occurrences in already-satisfied original clauses, and define
\[
 e=2f-u,\quad \eta=\sum_x\min(s_x^+,s_x^-),\quad w_x=|s_x^+-s_x^-|.
\]
If $w_x>0$, the preferred $b_x\in\{0,1\}$ minimizes true covered occurrences. Every actual satisfying completion $a$ obeys the \emph{source-indexed} identity
\begin{equation}\label{eq:slack}
 e-\eta=\sum_{j\in U(p)}(t_j(a)-1)+\sum_{x:w_x>0}w_x[a_x\ne b_x].
\end{equation}
This follows because every free original contributes exactly two true literals across its four signed source occurrences. Choose an \emph{authenticated original-clause-edge-disjoint} family of simple odd cycles $\mathcal C=(E_1,\ldots,E_\nu)$ in the residual binary-clause graph. The odd-cycle condition forces at least one doubly true binary edge in each cycle in any SAT completion. Set $\delta=e-\eta-\nu$. A negative $\delta$ certifies the entire cube UNSAT. At $\delta=0$, every SAT completion has exactly one doubly true edge per cycle, no outside-cycle true-count excess, and every nonzero-weight free variable at its preferred value.

Write $B$ for the common affine system consisting of $x=b_x$ for $w_x>0$, plus odd \emph{literal-truth parity} on every uncovered clause outside all selected cycles. For residual source clause $C_j$ with $r_j$ free literals, its GF(2) row is
\[
 \bigoplus_{x\in\operatorname{free}(C_j)}x
 =1\oplus\bigl([C_j\text{ is negative}](r_j\bmod2)\bigr).
\]
The pinned source literals in uncovered clauses are false, so contribute zero. For each cycle $E_i$ and original source edge $e\in E_i$, let $R_i(e)$ be the affine rows setting both free endpoints of $e$ to literal-true and enforcing $x\oplus y=1$ on every other edge of that cycle. The published SATURATED-CYCLE-AFFINE-TERMINAL1 theorem gives the disjoint union
\begin{equation}\label{eq:union}
 \operatorname{Mod}(F\mid p)=\bigsqcup_{e_i\in E_i}\operatorname{Sol}_{\GF}\left(B\cup\bigcup_{i=1}^{\nu}R_i(e_i)\right).
\end{equation}
These source-conditional rows are \emph{not} unconditional logical consequences of ordinary $F$; their validity is tied to the signed conservation and exact saturation proof. Outside-cycle odd parity is insufficient as a SAT certificate by itself, as the authenticated F9 control demonstrates.

\begin{theorem}[Exact disjoint prefix-cut UNSAT certificates]\label{thm:prefix}
Fix $F,p,\mathcal C$ as above with $\delta=0$ and any deterministic order of the $\nu$ cycles. For a choice prefix $s=(e_1,\ldots,e_k)$, set $B_s=B\cup\bigcup_{i\le k}R_i(e_i)$. A \emph{contradictory prefix certificate} comprises a row-XOR combination of rows in $B_s$ whose left-hand side is zero and whose right-hand side is one, with every row authenticated to an original source clause/preferring-variable and this selected choice prefix.

If a family $\mathcal P$ of such contradictory prefixes covers every complete choice vector in $E_1\times\cdots\times E_\nu$ by the prefix relation, then $F\mid p$ is UNSAT. Conversely, if $F\mid p$ is UNSAT, the collection of all full-length choice vectors with row-XOR refutations is a valid covering family. A redundant family can be pruned to a prefix-free cover. If some complete choice vector has a consistent affine system, it supplies a fully original-source-checked SAT witness and contributes exactly $2^{f-\operatorname{rank}(B_s)}$ models. The rank contributions of distinct complete choices sum without overlap.
\end{theorem}
\begin{proof}
Equation~\eqref{eq:union} is an exact disjoint union for every valid original source and every coherent source cube at saturation, including both satisfiable and unsatisfiable outcomes. Every satisfying extension lies in precisely one complete choice system. If a row-XOR contradiction occurs already at prefix $s$, no assignment can satisfy $B_s$, and appending any later rows cannot restore consistency. A prefix cover therefore eliminates every complete choice system. Conversely, when the union is empty, every complete choice system is inconsistent, and Gaussian elimination gives a linear combination $0=1$ of its finite input rows. Remove all certificates whose prefixes properly extend an already contradictory prefix to obtain a prefix-free covering set. For any consistent complete choice, standard affine rank-nullity counts its solutions; source saturation proves every such solution satisfies the original $F$ and disjointness prohibits multiple counting. A SAT witness is checked against all original clauses before acceptance. A failed bounded search that has \emph{not} covered the choice space is \textbf{UNRESOLVED}, not UNSAT.
\end{proof}

\begin{lemma}[Rollback Gaussian invariant]\label{lem:rollback}
Maintain an unreduced pivot basis in which inserting a row reduces only the \emph{new} row, with each basis row retaining a GF(2) provenance bitset of previously inserted row IDs. Record any new pivot in a stack and do not overwrite existing basis rows. Undoing the rows introduced after a prefix checkpoint, in reverse order, restores exactly the prior equation span and proof provenance. An inserted row reducing to $(0,1)$ yields a checkable source-indexed row-XOR contradiction; this proof is valid for the current prefix and every extension of that prefix, but not for incompatible sibling choices.
\end{lemma}
\begin{proof}
Each new pivot row belongs to the span of prior inserted rows and the appended row, and the provenance bitset is the symmetric difference of exactly these rows. Existing pivots are never mutated, so rollback deletes precisely the newly introduced pivots and their trailing row records. Linear span at the checkpoint is therefore restored. When a zero-mask row has right-hand side one, its provenance XORs to the impossible equation $0=1$; rechecking the explicit tagged row set proves the contradiction. It depends on the prefix choice rows, so promoting it outside its authenticated source/prefix is unsound.
\end{proof}
