\begin{theorem}
Let ordered ticket sites $D_i$ have finite options $O_i$, each with nonnegative integer cost $c(o)$ and authenticated GF$(2)$ row set $R(o)$. Only complete total-cost-$\delta$ descriptions are admissible. For a choice prefix $s=(o_1,\ldots,o_k)$ set $R_s=\bigcup_{i\le k}R(o_i)$ and $c(s)=\sum_{i\le k}c(o_i)$. Define $H_{q+1}=\{0\}$ and
\[
H_i=\{c(o)+h:o\in O_i,\ h\in H_{i+1},\ c(o)+h\le\delta\}.
\]
A prefix can be safely eliminated if $\delta-c(s)\notin H_{k+1}$ or if a checked row XOR using \emph{only rows already committed in $R_s$} equals $(0\mid1)$. A prefix-free exact cover of all admissible ticket descriptions is a complete UNSAT certificate. Any consistent complete affine description yields SAT after checking its witness against every original clause.
\end{theorem}
\begin{proof}
The cost recurrence lists precisely attainable suffix costs, by induction. Every future ticket extension retains the rows already committed by the prefix, so their contradiction survives. A default odd-parity row from an undecided clause is not committed because a later overfull ticket can replace it. Thus such a row cannot support an ancestor prefix cut. Exhaustive prefix coverage refutes every affine branch of the inherited disjoint union; a checked complete consistent branch yields SAT. Incomplete coverage is UNRESOLVED, not UNSAT.
\end{proof}
