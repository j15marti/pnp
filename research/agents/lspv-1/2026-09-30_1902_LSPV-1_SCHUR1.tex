\section*{LSPV-1: Schur-square reformulation and reachable-image models}

\textbf{STATUS: OPEN.} P versus NP remains open. This run asks how other areas avoid the gap between an ambient algebraic family and the subclass actually reachable from a valid computation, then tests the closest models against the SU/vMS product-span target.

\paragraph{PROVED/EXACT: the target is a Schur-square dimension.}
For the actual final Boolean coordinate functions $g_i:U\to\mathbb F_2$, set
\[
C_H=\operatorname{span}_{\mathbb F_2}\{1,g_1,\ldots,g_m\}\subseteq\mathbb F_2^U.
\]
Because $1\in C_H$,
\[
\boxed{\rho(E_H)=
\dim_{\mathbb F_2}\operatorname{span}\{1,g_i,g_ig_j\}
=\dim_{\mathbb F_2}(C_H^{\star2}),}
\]
where $\star$ denotes coordinatewise multiplication. Thus the project's rank problem is exactly a square-code problem.

\paragraph{PROVED/EXACT for a declared SU05/Hadamard realization.}
Let the q-ary orbit output at outer seed $v$ be
$a(v)=(a_1(v),\ldots,a_m(v))$, and let
$\ell(a_i(v))\in\mathbb F_2^k$ be the binary message supplied to the Hadamard inner code allowed by SU05 Lemma 4.16. Form the $m\times k$ binary matrix
\[
B_v[i,*]=\ell(a_i(v)).
\]
For fixed $v$ and Hadamard coordinate $j\in\mathbb F_2^k$, the final output is
\[
g(v,j)=B_vj.
\]
Hence the outputs from one outer seed are exactly the linear subspace
$S_v=\operatorname{im}B_v\subseteq\mathbb F_2^m$, and
\[
H=\bigcup_v S_v,\qquad
\rho=\dim\operatorname{span}_v\operatorname{span}\{\Phi_2(x):x\in S_v\},
\]
where $\Phi_2(x)=(1,x_i,x_ix_j)_{i<j}$. If $r_v=\dim S_v$, then one block has exact quadratic-feature dimension
\[
1+r_v+\binom{r_v}{2}.
\]
Equivalently, low global rank requires the quadratic lifts of the $S_v$ to be strongly aligned. This bypasses full bit-blasting for this specific Hadamard realization.

\paragraph{KNOWN THEOREM analogues.}
Coding theory gives both behaviors. Structured evaluation codes can have small Schur square: for GRS codes the square is the evaluation code of doubled polynomial degree, and AG-code cryptanalysis exploits anomalously small square dimension to distinguish/recover hidden algebraic structure. Random linear codes behave oppositely: Cascudo--Cramer--Mirandola--Z\'emor prove that when the length is roughly at most $k^2/2$, the square of a random $k$-dimensional code typically fills the ambient space. Reed--Muller codes satisfy
$RM(r,n)\star RM(s,n)=RM(r+s,n)$; in particular
\[
\dim RM(1,n)^{\star2}=1+n+\binom n2,
\]
so Hadamard/affine structure alone already has quadratic square dimension.

Two other literatures address SAME\_REALIZATION differently. GKR-style arithmetization keeps gate values as auxiliary variables and checks local low-degree identities instead of eliminating the computation. Feasible interpolation extracts a circuit from proofs in restricted proof systems, but Bonet--Pitassi--Raz show that such extraction does not extend generically to Frege or even $TC^0$-Frege under standard factoring hardness. Algebraic implicitization uses elimination ideals/Gr\"obner bases to derive equations of the image of a polynomial parametrization; this is conceptually exact for the reachable-image question, but elimination can increase degree and computational cost.

\paragraph{COMPUTATIONAL candidate-model battery.}
A deterministic seed-1 exact-arithmetic experiment is in
\texttt{experiments/product\_span/schur\_image\_models.py}, with raw output in
\texttt{results/raw/product\_span/2026-09-30\_LSPV1\_schur\_image\_models.json}.
Finite results are only COMPUTATIONAL.

For GRS controls $(p,n,k)=(13,11,4),(17,13,5),(29,20,6)$, square ranks were
$7,9,11=2k-1$. Across 200 random full-rank codes at the same parameters, the square was maximal in $198/200,200/200,199/200$ trials.

For random Hadamard block subspaces, the quadratic rank reached the full
$M=1+m+\binom m2$ after 14 blocks for $(m,k)=(12,3),(16,4)$ and after 16 blocks for $(20,5)$. A cyclic shift of one random base subspace also gave ranks
$97/137,199/211,301/301,481/529$ at $(m,k)=(16,3),(20,4),(24,5),(32,5)$.
Thus orbit/cyclic symmetry alone does not force low rank.

A deliberately aligned model behaves differently. If
$S_t=\operatorname{span}\{e_t,\ldots,e_{t+k-1}\}$ cyclically and $k\le m/2$, then exactly
\[
\rho=1+mk,
\]
confirmed at $49,81,121,161$. In an even stronger periodic sliding-label model all windows generate the same $k$-space, giving
$\rho=1+k+\binom k2$, while random label sequences at the same parameters reached full rank. The surviving structural question is therefore \emph{alignment of the actual PCP-LDE Hadamard block subspaces}, not mere orbit structure.

\paragraph{FALSIFIED/RETIRED candidate shortcut.}
LSPV-4 proposed first computing the linear map from arbitrary proof-table values to orbit evaluations. That is useful but not sufficient by itself because validity of a PCP proof is a nonlinear restriction. Toy control: the ambient cube $\mathbb F_2^3$ has quadratic-feature rank $7$, while the valid subset
\[
H=\{(a,b,c):c=ab\}
\]
has rank $4$ and the exact quadratic relation $c+ab=0$. Thus full rank of the ambient linear evaluation map does not prove full rank on accepted SAME\_REALIZATION proofs. One must impose the PCP acceptance constraints before concluding.

Likewise, local quadratic gate constraints do not imply a low-degree relation after projecting away internal variables. The GKR strategy succeeds by \emph{retaining} those variables. Adding such coordinates to our final range post hoc would change the object and fails the project's auxiliary-variable/SAME\_REALIZATION guard unless a model-preserving transfer is proved.

\paragraph{vMS typing.}
Theorem 24 does impose the narrow reachable subclass: the generator guesses a PCP proof $y_i$, verifies acceptance with probability $1$, views $y_i$ as a Boolean function $g_i$, takes its canonical low-degree extension $\widehat g_i$, then outputs $RMV(\widehat g_i)$. Therefore the relevant family is not all low-degree polynomials but LDEs of perfectly accepted PCP proofs.

\paragraph{Barrier audit.}
Schur-square rank remains structural and relativizing; a maximal semantic/algebraic oracle can expose the square or its annihilator. DEAD/COPY/DELAY/INTERP/RECOMP, padding, Horn, 2-SAT, affine/Tseitin and treewidth controls remain mandatory for any later runtime inference. No arbitrary-algorithm transfer follows.
