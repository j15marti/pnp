\section{Barrier-transfer literature preflight}

The two load-bearing obstacles are unchanged.  First, a lower bound for a
chosen representation or decision-tree interface must transfer to every
uniform deterministic SAT computation on the ordinary explicit encoding.
Second, the target must land in the same machine model as an unconditional
forbidden region, with all source access and workspace charged.  D\"ocker's
primary construction supplies a fixed 198-variable, 264-clause unsatisfiable
proper Monotone 3-Sat-(2,2) instance \cite{docker}.  The Fortnow--Lipton--van
Melkebeek--Viglas time--space results remain the relevant model-matched
endpoint literature \cite{flmv}; they do not follow from a decision-tree
input-reading bound.  Evasiveness literature studies related query models
\cite{rv,kss}, but the theorem below is an elementary direct-product adversary
and does not import graph-property topology.

Classification: the fixed D\"ocker component is a \KNOWN\ dependency; the
AND decision-tree adversary is an exact theorem transfer to the declared
random-access source model; VLSI routing, communication cuts and graph
e-vasiveness are useful analogies requiring a compiler; treating any of them
as an unrestricted Turing-machine lower bound is a failed transfer.

\section{Clean-core family and encoded length}

Let $Y$ be the disjoint union of 22 paired $K_{3,3}$ components.  Each
component has one variable for every edge, the six vertex-neighborhood clauses
positively, and the same six clauses negatively.  Hence $Y$ has 198 variables,
264 distinct proper monotone clauses, and every variable occurs twice in each
polarity.  A diagonal perfect matching satisfies $Y$.

Let $U$ be D\"ocker's fixed unsatisfiable instance with the same two dimensions
and the same exact-(2,2) properties.  For $k\ge1$ and
$s=(s_1,\ldots,s_k)\in\{0,1\}^k$, put fresh relabelled copies on consecutive
198-variable intervals and define
\[
 F_{k,s}=B_{s_1}\wedge\cdots\wedge B_{s_k},
 \qquad B_1=Y,\quad B_0=U.
\tag{1}
\]
Disjoint union preserves properness, duplicate-freeness and exact occurrence
counts, so $F_{k,s}\in\Htwo$, and
\[
 F_{k,s}\in\mathsf{SAT}\iff \bigwedge_{i=1}^k s_i=1.
\tag{2}
\]

Fix a block-concatenated indexed encoding: the common $(n,m)$ header is followed
by the $k$ equal-length, canonically ordered clause blocks; a literal uses one
sign bit and $\lceil\log_2(n+1)\rceil$ identifier bits.  With $n=198k$ and
$m=264k$,
\[
 N_k=3m\bigl(1+\lceil\log_2(n+1)\rceil\bigr)+O(\log n)
     =\Theta(k\log k).
\tag{3}
\]
This fixes the representation and avoids silently moving between clause count,
variable count and encoded bit length.

\section{Exact quantified lower bound}

For block $i$, let $D_i$ be the set of bit positions in its encoding segment
where its copy of $Y$ differs from its copy of $U$.  The sets are nonempty and
pairwise disjoint because a satisfiable and an unsatisfiable formula cannot
have identical encodings.

\begin{theorem}[\texttt{H22-BLOCK-AND-PROBE1}; \EXACT]
For every deterministic total exact SAT decider $A$ in the random-access
bit-probe model and every $k\ge1$, on the single all-$Y$ input
$F_{k,1^k}$, $A$ probes at least one position in every $D_i$.  Consequently
\[
 T_A(F_{k,1^k})\ge k=\Omega(N_k/\log N_k).
\tag{4}
\]
The same asymptotic lower bound holds for $O(\log N_k)$-bit aligned word probes,
because one word intersects only constantly many disjoint block segments.
\end{theorem}

\begin{proof}
Run $A$ on $F_{k,1^k}$.  If no probed position lies in $D_i$, replace only
block $i$ by $U$.  Determinism and adaptivity cause no problem: every answer
along the original execution remains unchanged, so the complete transcript and
output are identical.  The original formula is satisfiable, whereas the
modified formula is unsatisfiable by (2), contradicting exactness.  Thus every
$D_i$ is hit.  They are disjoint, giving $k$ probes.  Equation (3) converts the
bound to encoded length.  For word access, block alignment, or a constant-factor
boundary loss without padding, gives the same $\Omega(k)$ conclusion.
\end{proof}

The theorem has unusually strong pointwise quantifiers:
\[
 \forall A\in\operatorname{Dec}_{\rm det}(\mathsf{SAT})\;
 \forall k\ge1:\quad T_A(F_{k,1^k})\ge k.
\tag{5}
\]
It is not a statement that $A$ materializes $s$, a witness, a compatibility
matrix or any semantic core.  It forces only source discrimination.

\section{Falsification of the P-versus-NP transfer}

\paragraph{Easy-language control.}
The identical proof applies to equal-length YES/NO macroblocks for 2SAT, Horn,
affine systems, bounded-treewidth CSPs and other polynomial-time languages.
The direct product computes AND, whose all-YES input has $k$ sensitive blocks.
Therefore \texttt{PROBE-LB-IMPLIES-NP-HARDNESS1} is \RETIRED.  The theorem
measures explicit input information, not semantic hardness.

\paragraph{One-bit output and semantic shortcuts.}
A decider need not reconstruct any assignment.  It may compare one known
distinguishing bit per macroblock and keep one accumulator bit.  Thus the lower
bound is tight on the promise up to encoding constants, uses $O(1)$ state beyond
the address counter, and is compatible with a one-bit decision output.

\paragraph{Alternative encoding.}
If a promise encoding appends a trusted bit equal to
$\bigwedge_i s_i$, one probe decides the same promise.  If the bit is untrusted,
verifying it restores the source problem.  Hence
\texttt{REPRESENTATION-INVARIANT-PROBE1} is \RETIRED.  Equation (4) is exact
only for the declared ordinary indexed encoding; no invariant computational
obligation follows from syntax alone.

\paragraph{Padding, redundancy and wrappers.}
Padding and repeated clauses enlarge $N$ without increasing $k$ and can only
weaken the $N$-form of the bound.  DIRECT/COPY/DEAD/DELAY/INTERP/RECOMP alter
internal traces but cannot make two explicit inputs with identical answers on
all probed positions distinguishable.  COPY may pay more; DELAY may pay more;
neither yields a stronger necessary exponent.  Compact branching-program or
circuit representations can encode the selector vector differently and must
be re-audited rather than inherited.

\paragraph{Assuming $P=NP$.}
Under $P=NP$, a fixed polynomial SAT algorithm still must read enough source
information to separate the paired promise inputs, so (4) remains true.  Its
$\Omega(N/\log N)$ cost is polynomial and gives no contradiction.  Any step
from (4) to superpolynomial time would already supply the missing P-versus-NP
lower bound; it cannot be inserted as a premise.

\section{SAME\_REALIZATION and barrier audit}

Equation (4) is charged to the actual execution of $A$ on the actual all-$Y$
source, so it satisfies \textsc{same\_realization} in the declared bit/word
probe model.  It does not transfer to a model where a free semantic oracle is
given the whole input by handle.  In an ordinary oracle-Turing model, writing
the query still costs its length.  The adversary relativizes with any oracle
that reveals no unprobed source bits and has no nonalgebrizing hinge.  It does
not establish a constructive large circuit property, so Natural Proofs is not
the active obstruction.  Nonuniform advice depending only on $k$ does not help;
advice containing the input selector vector changes the model.

The FLMV time--space endpoint remains unreachable: a linear-in-$k$ probe floor
does not force simultaneous large time and space, and the promise algorithm
uses a one-bit accumulator.  \texttt{UCORE-TIME1}, arbitrary-polynomial-exponent
bootstrap, nonrelativization, nonalgebrization and a final contradiction remain
\OPEN.

\section{Post-quantum and cross-domain ledger}

\textbf{EXACT OBJECT/THEOREM TRANSFER.}  Lossiness/collision entropy applies to
the transcript map on the selector promise: if block $i$ is never hit in
$D_i$, the all-$Y$ source and the one-$U$ source collide.  This is exactly the
adversary proof, not a time-space theorem.

\textbf{ANALOGY/CANDIDATE needing a new bridge.}  Worst-case/average-case
reduction architecture suggests hiding selector bits and extracting them from
black-box behavior.  The explicit syntax defeats cryptographic hiding, and no
unconditional NP worst-case/average-case bridge is supplied.  Communication
cuts, VLSI locality and observability language describe the same sensitivity
but require model-specific compilers.

\textbf{FAILED TRANSFER.}  Schur squares, quadratic-relation ranks, Hilbert
functions, syzygies, collapse binding, hashes and random oracles do not alter
the elementary source discrimination theorem and do not promote it to an
arbitrary-computation lower bound.  Hidden algebraic structure may instead
make the local blocks easier.
