\section*{IDEA, falsifiers, and precise mathematical construction}
Question: Can one polynomial-time correct SAT decider have a syntactically hard error audit without its decision function being hard? Predict YES by inserting a semantically dead explicit UNSAT-witness check. Falsifiers: a reachable bad rejection; nonuniform per-size code; invalid/malformed source escaping the fallback; an unjustified transfer from ordinary Resolution to the full mixed calculus.

Let \(H_k(y)\) be an explicit uniformly constructible UNSAT CNF with \(m(k)\) variables, polynomial construction and assignment evaluation. Choose \(H_k=\mathrm{PHP}^{k+1}_{k}\), with variables \(y_{ij}\), one positive clause per pigeon, and one negative binary conflict clause per two pigeons in a common hole. There are \(m=k(k+1)\) variables. For every bitstring \(w\in\{0,1\}^m\), construct a canonically signed original CNF source
\[
S_{k,w}=(z)\land\bigwedge_{t=1}^m (z\lor\neg z\lor\ell_t(w_t)), \qquad
\ell_t(1)=u_t,\quad\ell_t(0)=\neg u_t,
\]
on \(m+1\) variables with ordered clauses. Every \(S_{k,w}\) is SAT via \(z=1\). The sign of the unique \(u_t\) in the \(t\)th tautological clause encodes \(w_t\). A fixed parser recognizes the source and recovers \(k,w\) in polynomial time from the actual signed input bitstring, of length \(N_k=\Theta(k^2\log k)\).

For any fixed total correct SAT decider \(A\), define \emph{one fixed machine} \(B\) on all binary inputs. On exact sentinel \(S_{k,w}\), output UNSAT precisely if \(H_k(w)=1\); otherwise output SAT. On every non-sentinel or malformed input, call \(A\). Since \(H_k\) is unsatisfiable, the sentinel branch always returns SAT; thus \(B(x)=A(x)\) for every binary input and \(T_B^{wc}(N)\le T_A^{wc}(N)+\mathrm{poly}(N)\). Under SAT in P, both are polynomial-time uniform correct deciders, with no per-\(k\) advice.

\begin{theorem}[Dead-branch source-only audit embedding]
The sentinel-specific false-rejection predicate \(E_{B,k}(w)=[B(S_{k,w})=\mathrm{UNSAT}]\) is \emph{literally} the CNF \(H_k(w)\). Therefore the exact source-only branch-audit CNF has whatever restricted proof-complexity lower bound is known for \(H_k\), even when the corresponding SAT decider runs in polynomial time.
\end{theorem}

Thus the source-only branch audit of \(B\) is exponentially Resolution-hard even if SAT in P. This uses \emph{no new lower bound for \(R_{\mathrm{mix341}}\)} and no arbitrary-SAT-machine runtime lower bound. \section*{Same-run iteration 2: proper, non-tautological source strengthening}
The preceding theorem remains true with a stronger source encoding that avoids \emph{all} tautological, duplicate, and subsumed clauses:
\[
\boxed{S^{\rm proper}_{k,w}=\bigwedge_{t=1}^{m}(z\vee\ell_t(w_t)).}
\]
Every clause is a proper width-two clause using one common \(z\) and one distinct private \(u_t\). There is no unit \((z)\), so no clause is subsumed by another. No clause contains complementary literals, and every clause is distinct. The explicit satisfying witness sets \(z=1\); every \(w_t\) is still recoverable from the signed private literal in ordered source clause \(t\). The uniform recognizer and the polynomial input bound are unchanged. This encoding is preferred whenever a native parser requires proper non-tautological clauses, and it eliminates any dependency on allowing syntactic tautologies in the source grammar. It is still a \emph{signed-encoding} rather than a semantic-invariant theorem, as intended.
