\section*{Model, quantifiers and fixed calculus}
Preserve unchanged \(R_{\mathrm{mix341}}\): original signed sources free, genuine binary RES, exact AND3, GF(2) XOR, LOCAL-CONVERT and paid conservative signed two-input VARDEF, each distinct derived node charged one. Shared DAGs count once. Define
\[
W_R(F)=\min_{\pi:F\vdash_R\bot}\sum_{v\in\pi_{\rm derived}}\omega(v),\qquad
\overline W_R(N)=\max_{\substack{F\text{ valid UNSAT}\\|\operatorname{enc}F|\le N}}W_R(F)
\]
(empty maximum zero, \(N\) encoded bits). The new theorem applies only to the separately named \(\mathrm{Res}\) subcalculus, with unit charge for every distinct genuine binary resolvent. Proof discovery, proof bytes, proof checking, native time and peak space are different costs.

Fix any uniform total correct SAT decider \(A\) for valid SAT, valid UNSAT and malformed binary sources, and integers \(v\ge3,m\ge1,b\ge1\). Let \(\mathcal T_v\) be all \(M=8\binom v3\) proper signed three-literal clauses on the named variables \(y_1,\dots,y_v\). For each clause slot \(j\in[m]\), introduce mutually exclusive selectors \(s_{j,C}\) for \(C\in\mathcal T_v\). A polynomial-size one-hot CNF with selector-only auxiliary variables requires exactly one choice per slot. A fixed polynomial-size decoder turns \(s\) into the canonical DIMACS encoding of \(F_s\). Introduce a genuine source clause for every slot and template:
\[
G_{j,C}(s,y)=(\neg s_{j,C}\lor C(y)).
\]
Let \(\mathrm{Reject}_{A,b}(s,z)\) be the \emph{actual bounded deterministic tableau Tseitin CNF} whose output is TRUE iff \(A\) rejects \(\mathrm{Dec}(s)\) within \(b\) machine steps. All tableau variables \(z\) are independent of the witness \(y\), and the output TRUE unit is included. Define
\[
H_{A,v,m,b}=\mathrm{OneHot}(s)\land\mathrm{Reject}_{A,b}(s,z)\land
\bigwedge_{j,C}G_{j,C}(s,y). \tag{1}
\]
The clock is unary and the fixed-machine simulation is polynomial-size in \(v+m+b\). There are \(mM=O(mv^3)\) gated clauses. No hidden SAT or equivalence oracle occurs in the source or proof rules.

\begin{lemma}[Exact source specialization]\label{special}
For every valid strict-three-CNF \(F\) with the declared \(v\) named variables and exactly \(m\) signed clause slots, if \(A(F)\) correctly rejects within \(b\) steps, some partial assignment \(\rho_F\) to every \(s,z\) (and every one-hot auxiliary variable), leaving \(y\) free, satisfies
\[
\boxed{H_{A,v,m,b}|_{\rho_F}=F(y)}
\tag{2}
\]
as an exact multiset of surviving source clauses.
\end{lemma}
\begin{proof}
Set exactly one template selector per slot to one. Satisfy the selector-only one-hot auxiliaries. Specialize the entire deterministic \(A\) tableau to the actual rejecting run on that decoded source, including the output unit. All these clauses become TRUE, independently of \(y\). Every inactive guarded source becomes TRUE, and the unique active guarded source in slot \(j\) literally reduces to its selected \(C_j(y)\). No witness-evaluation gadget survives and clause multiplicity is unchanged.
\end{proof}

\begin{lemma}[Strict Resolution restriction]\label{restriction}
For every partial assignment \(\rho\) with \(H|_\rho\) UNSAT,
\[
W_{\mathrm{Res}}(H|_\rho)\le W_{\mathrm{Res}}(H). \tag{3}
\]
\end{lemma}
\begin{proof}
Restrict a strict Resolution DAG in topological order and retain a derived clause \emph{subsuming} the restriction of its original line. If a pivot is fixed, one surviving parent's restricted clause subsumes the restricted resolvent and can be retained at no cost. If the pivot is unset and persists with opposite polarity in retained parents, resolve once; if a retained parent omits it, retain the stronger parent. The surviving root subsumes the empty clause, hence is empty. No weakening, free logical consequence rule, new source axiom or additional paid node is needed. Shared ancestors remain shared.
\end{proof}

\begin{theorem}[Clocked soundness reflection inherits old hardness]\label{main}
For every fixed total externally correct \(A\) and every \(v,m,b\), \(H_{A,v,m,b}\) is UNSAT and
\[
\boxed{W_{\mathrm{Res}}(H_{A,v,m,b})\ge
\max_{\substack{F\text{ proper strict 3CNF on }v,m\\
A(F)\text{ returns UNSAT within }b}}
W_{\mathrm{Res}}(F).} \tag{4}
\]
For the explicit classical odd-charge cubic expander Tseitin sequence \(F_h\), \(v=3h/2\) edge variables and \(m=4h\) authentic three-literal parity-blocking clauses. Its encoded length is \(\Theta(h\log h)\) and the established unrestricted DAG-Resolution lower bound is \(W_{\mathrm{Res}}(F_h)\ge 2^{c h}\), for some constant \(c>0\) and all sufficiently large eligible \(h\). A single uniform total correct \(A_\oplus\) recognizes and solves authenticated Tseitin blocks using GF(2), reverting to exhaustive valid-CNF search on other inputs and rejecting malformed syntax. Its run on \(F_h\) is polynomial in \(h\), so choose \(b_h=h^d\). Then
\[
|H_{A_\oplus,3h/2,4h,b_h}|=h^{O(1)},\qquad
W_{\mathrm{Res}}(H_{A_\oplus,3h/2,4h,b_h})\ge2^{c h}. \tag{5}
\]
\end{theorem}
\begin{proof}
If \(H\) had a satisfying assignment, its selectors would decode a valid CNF \(F_s\), the authentic rejecting trace would show that the externally correct \(A\) returns UNSAT on \(F_s\), and the gated original clauses would supply a satisfying witness for that same \(F_s\), contradiction. Equation (4) follows from Lemmas \ref{special} and \ref{restriction}. Odd-charge cubic expander Tseitin lower bounds are classical; recognized signed parity equations can be checked and solved by polynomial-time Gaussian elimination while the fallback makes \(A_\oplus\) total and correct. The selector/source size is \(O(h^4)\), and the bounded tableau plus all auxiliary conventions have polynomial encoded size for \(b_h=h^d\). Thus (5) follows. This is ordinary-Resolution source-proof hardness, not arbitrary SAT machine work.
\end{proof}

\section*{Mandatory falsifiers and correct transfer direction}
\begin{enumerate}
\item[] F1: use a witness-dependent evaluation circuit instead of guarded literal source clauses. \textbf{REJECTED}: tableau wires then depend on \(y\); setting them as constants cannot leave exactly \(F(y)\).
\item[] F2: infer a short strict Resolution proof of \(H\) from its additional selectors and computation trace. \textbf{FALSIFIED}: exact restriction plus (3) would give an equally short proof of hard \(F_h\).
\item[] F3: infer the same exponential lower bound for \(R_{\mathrm{mix341}}\). \textbf{FALSIFIED as a generic transfer}: the original \(F_h\) has a known exact mixed proof of \(4h-1\) nodes, by four-clause local parity extraction and GF(2) XOR summation (LSPV-2 341). This is a family countercontrol, not proof that the reflection \(H\) itself has short mixed proofs.
\item[] F4: extend the \(8\binom v3\) one-hot templates to arbitrary unbounded-width general CNF for free. \textbf{REJECTED}: unrestricted clause-template enumeration is exponential and requires a new polynomial-size witness-transparent compiler.
\end{enumerate}
The theorem \emph{does not} establish a nonrelativizing B3 transfer. The exact missing implication is still \(\mathrm{SAT}\in P\Rightarrow\overline W_{R_{\mathrm{mix341}}}(N)=N^{O(1)}\) for the SAME previously fixed mixed rules. In particular, soundness of a rejecting machine trace must not be imported as an inference axiom. The proof-search optimizer is not a charge in \(W_R\).
