\paragraph{Executive status.}
\textbf{FALSIFIED/RETIRED:} an unqualified extensional black-box
fork/extraction stage cannot serve as a solver-independent intermediate
lower-bound target for every uniform deterministic polynomial-time SAT
decider.  Positive-polynomial query scale is vulnerable to exact delay
wrappers; subpolynomial query scale collapses, after fixing any polynomial
SAT solver under $\SAT\in\mathrm P$, to an ordinary source computation;
implementation-sensitive escape routes lose full replacement covariance.
This is a barrier theorem and not a separation.  \textbf{OPEN:} a
full-language source-only compiler whose \emph{same realized ordinary
machine}, including construction, verification, extraction and writing
costs, lies in a model-matched unconditional forbidden region.  Therefore
\textbf{P versus NP remains open}.

\section{Claim card}

\paragraph{Claim ID.}
\texttt{BLACKBOX-FORK-SCALE-TRILEMMA1}.

\paragraph{Run mode.}
Red-team: attempt to falsify a proposed all-algorithm necessity.

\paragraph{Source clean core and encoding.}
Let $\Hcore$ be the duplicate-free proper monotone
$\mathrm{3SAT}\text{-}(2,2)$ family: every clause contains three distinct
positive literals; every variable occurs in exactly two clauses; duplicate
clauses are forbidden.  Inputs use the repository's explicit variable-index
encoding.  For $n$ variables and $m=2n/3$ clauses,
\[
        N:=|\operatorname{enc}(F)|=\Theta(n\log n).
\]
For any ordered vertex interface $S=(x_1,\ldots,x_t)$ define the semantic
compatibility object
\[
 H_S(F):=\{a\in\{0,1\}^{t}:\exists b\in\{0,1\}^{n-t}\ F(a,b)=1\}.
\]
This object is representation-independent, but its cardinality is not a
runtime lower bound and an exact decider need only output one bit.

\paragraph{Purported universal intermediate.}
Let $\mathsf{PolySAT}$ be the set of uniform deterministic exact SAT
deciders running in polynomial time.  Assume only for the conditional audit
that $\SAT\in\mathrm P$, hence $\mathsf{PolySAT}\ne\varnothing$.
Fix one deterministic extensional oracle compiler $E$.  On source $F$,
challenge $e$, and oracle access to $A\in\mathsf{PolySAT}$, it returns a
commitment/opening pair $(c,z)$ and makes at most
$N^{\eta+o(1)}$ adaptive SAT queries.  Its non-oracle time and space are
$N^{r+o(1)}$ and $N^{p+o(1)}$.  Let
\[
 q_E(N):=\max_{|F|=N,e,\text{ reached query }Q}|Q|=N^{\sigma_E(N)}.
\]
The attacked claim demanded a fixed charged exponent, independent of the
choice of $A$, and a common commitment admitting two valid openings for
distinct challenges.

\paragraph{Quantifiers.}
The rejected form is
\[
 \exists E\,\exists c\,\forall A\in\mathsf{PolySAT}\,
 \forall^{\infty}N\,\forall F\in\Hcore\cap\{0,1\}^{N}:
 \quad E^A(F,\cdot)\text{ realizes the charged fork within }N^{c+o(1)}.
\]
The quantifier $\forall A$ includes semantically identical exact delay
wrappers.  No premise asserts $\mathrm P\ne\mathrm{NP}$.

\paragraph{SAME\_REALIZATION ledger.}
The charged realization is the single ordinary computation obtained by
executing $E$, constructing every query, running the chosen $A$, storing and
checking answers, producing both openings, applying the proposed extractor,
and writing all explicit output.  Semantic-state counts, proof-system size,
and a different reconstruction algorithm are not charged to this machine.

\section{Exact result}

\begin{theorem}[Black-box fork-scale trilemma]
\label{thm:trilemma}
Assume $\SAT\in\mathrm P$ and let $E$ satisfy the claim-card bounds.
\begin{enumerate}
\item If $\limsup_N\sigma_E(N)>0$, then no fixed exponent $c$ upper-bounds
the realized running time of $E^A$ for every $A\in\mathsf{PolySAT}$ on all
sufficiently large source lengths.
\item If $\sigma_E(N)\to0$, then after fixing any
$A\in\mathsf{PolySAT}$ with running time $|Q|^{K+o(1)}$, the oracle calls can
be inlined and $E^A$ is an ordinary source algorithm with
\[
 T(N)=N^{\max\{r,\eta\}+o(1)},\qquad
 S(N)=N^{p+o(1)}+N^{o(1)}.
\]
If the two-opening relation is balanced, polynomially decidable and total,
then under $\SAT\in\mathrm P$ its lexicographically first tuple is itself
source-searchable in polynomial time by standard NP prefix search.  Thus the
fork is not an intermediate problem strictly between SAT and a known
unconditional endpoint.
\item If $E$ avoids the first two alternatives by allowing the commitment
or accepted relation to depend on code, trace, timing or representation of
the oracle implementation, then full constant-replacement covariance fails.
Any replacement-covariant commitment factors through the source:
$c_A(F)=r(F)$.  Covering all arbitrary deciders then requires a new typed
orbit-coverage theorem and is not implied by semantic correctness.
\end{enumerate}
Consequently the unqualified candidate
\texttt{UNIVERSAL-BLACKBOX-FORK-INTERMEDIATE1} is
\textbf{FALSIFIED/RETIRED}.
\end{theorem}

\begin{proof}
For (1), choose $\epsilon>0$ and infinitely many $N$ for which a reached
query has length at least $N^\epsilon$.  Given an exact polynomial SAT
decider $A_0$, define the extensionally identical uniform wrapper
\[
       A_d(Q):=\text{wait exactly }|Q|^d\text{ steps, then run }A_0(Q).
\]
For any proposed common exponent $c$, choose an integer $d>c/\epsilon$.
The realized execution on that reached query alone costs at least
$N^{\epsilon d}>N^c$.  The output language and every oracle answer are
unchanged.  Therefore a common all-decider exponent cannot be extensional.

For (2), a reached query of length $q_E(N)=N^{\sigma_E(N)}$ costs
\[
 q_E(N)^{K+o(1)}=N^{K\sigma_E(N)+o(1)}=N^{o(1)}
\]
for the fixed $K$.  Multiplying by at most $N^{\eta+o(1)}$ queries and
including local computation gives the displayed time bound; storing a query
and the fixed-solver workspace adds only $N^{o(1)}$ beyond the stated local
space bound.  The source-searchability statement is the usual polynomially
balanced NP search-to-decision reduction: encode the relation and recover
the lexicographically first tuple one prefix bit at a time.  This implication
is conditional on $\SAT\in\mathrm P$ and supplies no contradiction by itself.

For (3), let $c_A(F)$ be invariant under replacement of $A$ by every exact
implementation $B\in\mathsf{PolySAT}$.  Fix any $A_\star$ and set
$r(F)=c_{A_\star}(F)$.  Replacement covariance gives
$c_A(F)=c_{A_\star}(F)=r(F)$ for every $A$.  Conversely, implementation
dependence violates that invariance.  The three alternatives exhaust,
respectively, positive-scale extensional access, vanishing-scale extensional
access, and nonextensional access.  None establishes an unconditional
general-computation lower bound.
\end{proof}

\section{Barrier and transfer audit}

\paragraph{Relativization.}
Baker--Gill--Solovay exhibit oracles giving opposite answers to relativized
P versus NP.  The positive-scale branch here is deliberately black-box and
relativizing.  It is used only to retire a route, not to claim a separation.
A surviving proof must identify a nonrelativizing, source-level endpoint.

\paragraph{Algebrization.}
No polynomial-extension or arithmetization step appears in the theorem.
Aaronson--Wigderson therefore supplies a warning, not a transferred lower
bound.  Status: \textbf{useful structural analogy requiring a new transfer
theorem}.

\paragraph{Natural Proofs.}
Razborov--Rudich concerns constructive large properties against circuit
classes under pseudorandomness assumptions.  The present theorem is about
uniform oracle composition and exact delay wrappers, not a large property
of truth tables.  Status: \textbf{misleading analogy / failed transfer} as a
direct proof; no Natural-Proofs conclusion is claimed.

\paragraph{Model-matched endpoint.}
Fortnow--Lipton--van Melkebeek--Viglas prove that for every
$c<\varphi=(1+\sqrt5)/2$ there is $d>0$ such that SAT has no deterministic
random-access-Turing-machine algorithm simultaneously using time $N^c$ and
space $N^d$.  This is a \textbf{directly transferable theorem} only after a
full-language compiler yields the same ordinary random-access machine with
all costs counted.  The present fork relation supplies no such compiler.

\paragraph{Cross-domain preflight.}
Cryptographic special soundness explains why two valid openings for a
common commitment can yield a witness, but it presupposes acquisition of
those openings.  VLSI routing and communication-cut lower bounds charge
local wires/messages in restricted architectures; they do not lower-bound
an arbitrary random-access decider.  Observability in control theory
concerns recovery of state in a specified dynamical model; a SAT decider is
not obliged to expose that state.  These are \textbf{useful structural
analogies requiring a new transfer theorem}, not direct imports.

\paragraph{Post-quantum technique ledger.}
Schur squares, quadratic-relation ranks, Hilbert functions and syzygies
apply exactly to the repository's code objects, but no theorem forces an
arbitrary SAT decider to materialize those representations.  Status:
\textbf{ANALOGY/CANDIDATE needing a new bridge}.  Collision entropy gives
the exact inequality
\[
        |\operatorname{im}L|\ge |A|^2/\operatorname{Coll}(L),
\]
but it lower-bounds an image of a specified map, not arbitrary decision
time; direct transfer is \textbf{FAILED TRANSFER}.  The LWE
worst-case/average-case architecture motivates external black-box
extraction, but known NP reduction barriers and the scale trilemma leave the
needed bridge \textbf{OPEN}.  Special-soundness/collapse-binding is an exact
object-level analogy only after a common fork is obtained; cryptographic
assumptions and random-oracle methods are inadmissible as unconditional
endpoints.

\section{STALE OR OVERSTATED CLAIMS FOUND}

Any wording suggesting that two ordinary satisfying assignments create a
special-soundness fork is stale: distinct challenges and a common binding
commitment are additional requirements.  Any wording treating replacement
covariance as evidence that the original solver exposed the commitment is
overstated: it proves source factorization.  Any claim of a fixed all-solver
exponent for positive-scale black-box calls is false under exact delay

strengthened.
