\noindent\textbf{PROVED/EXACT elementary pair-language theorem, independent review pending.}
For a fixed finite-alphabet deterministic sequential-head guest $A$, the \emph{invalidity} of its alleged complete rejecting history on a compound indexed input has a near-linear-time, logarithmic-work \emph{nondeterministic} witness. Equivalently, \emph{validity} of that source/trace pair is in the corresponding small-space \emph{co-nondeterministic} class. This is not an ordinary-source-only SAT or TAUTOLOGY algorithm, does not grant the trace a free proof head, and does not contract an arbitrary hypothetical $P=NP$ running-time exponent. The report supplies a complete symbolic proof and 23,585 deterministic finite assertion checks, zero failures.
\par\noindent\textbf{OPEN:} all-input affordable source-authenticated UNSAT proof coverage, deterministic acquisition, arbitrary-$K$ contraction, ARC-EDGE-90 and $P\ne NP$.

\section{One fixed guest, one indexed compound input, exact quantifiers}
Let $A$ be any fixed deterministic total finite-alphabet machine with one two-way sequential read-only original-source head, $k\ge1$ fixed sequential read/write work heads, fixed tape alphabets, and a halting output bit. Fix a valid ordinary-CNF original source $F$ with physical bit length $N$. The proposed complete rejecting history $\tau$ lists $R\ge1$ records, each with the guest control state, all head coordinates, actual source symbol, each work-tape before/after symbol, the finite transition, and successor control/head coordinates. Coordinates use canonical fixed-width binary encodings and obey physical reachability bounds $|x|\le R+O(N)$. Let $M=N+R+2$ and let the compound indexed input be $x=F\#\tau$ of length
\[
 X=|x|=\Theta(N+R\log M)
\]
for a canonical complete fixed-width record grammar, with an explicitly self-delimited framing header whose length is checked against the entire actual input. All source-bit access, parsing, index-bit construction and work are charged. An invalid header cannot buy a giant uncharged $R$ or time clock. A separate immutable proof oracle is \emph{not} assumed.

Define
\[
 \mathrm{GOOD}_A=\{F\#\tau:\text{$F$ is valid and $\tau$ is the authentic \emph{complete rejecting} run of $A(F)$}\},
 \qquad \mathrm{BAD}_A=\overline{\mathrm{GOOD}_A}.
\]
If $A$ correctly decides ordinary SAT, then
\[
 \forall F:\quad F\in\UNSAT\iff\exists\tau:\ F\#\tau\in\mathrm{GOOD}_A,
 \quad F\in\SAT\implies\forall\tau:\ F\#\tau\notin\mathrm{GOOD}_A.
 \tag{1}
\]
Equation (1) says nothing about the cost of producing $\tau$ or storing/re-reading it.

\begin{theorem}[Near-linear small-space \emph{invalidity} witness]\label{th:bad}
For every fixed $A$ and the declared canonical compound input, one uniform nondeterministic indexed-input random-access Turing machine recognizes $\mathrm{BAD}_A$ in
\[
 \boxed{\quad T_{\mathrm{bad}}(X)=X\log^{O(1)}(X+2),\qquad
 S_{\mathrm{bad}}(X)=O(\log(X+2))\ \text{bits.}\quad}\tag{2}
\]
All branches terminate under a uniform physical-input-length-derived clock. Consequently $\mathrm{GOOD}_A\in \coNTISP(X^{1+o(1)},O(\log X))$ with respect to the same \emph{compound-input} machine and length measure. The statement is not a lower bound and is not an assertion that ordinary $\UNSAT$ lies in $\NTISP(N^{1+o(1)},O(\log N))$.
\end{theorem}
\begin{proof}
The nondeterministic machine first validates the actual physical input framing and all public field widths, paying $O(X\operatorname{polylog}X)$ bit-time and $O(\log X)$ counters. If any malformed source, noncanonical record, incorrect record count, nonsensical bound, absent final rejecting state, wrong initial control or head, or incomplete halt condition is discovered, the machine may accept for this explicit invalidity reason.

On an otherwise well-formed pair, nondeterministically choose a mode and a record index $t<R$ using $O(\log X)$ guessed bits; for a work condition choose one of the fixed $k$ tapes. Mode I tests one local control/coordinate/transition defect, including the actual indexed source symbol or a nonblank claimed initial tape cell. All data occupy $O(\log X)$ counters; an offending record can be tested in $\operatorname{polylog}X$ indexed time.

Mode II tests work-cell temporal consistency. Read the claimed pre-symbol $a$ and work-head coordinate $u$ at step $t$ on the chosen tape. Scan precisely the chronological records $j<t$, retaining one \emph{finite-alphabet} register $v$ initialized to blank; whenever a record claims a write at exactly coordinate $u$ on this tape, replace $v$ by its claimed after-symbol. At the end accept this branch iff $a\ne v$. The scan is $O(R\operatorname{polylog}X)\subseteq O(X\operatorname{polylog}X)$ time and needs only $O(\log X)$ loop and address registers plus $O(1)$ symbol bits. A write of the \emph{same} symbol, repeated reading, and revisiting the same cell are all handled by chronological replacement, not by counting writes or trusting unvalidated predecessor pointers.

For soundness, if the pair is an actual complete rejecting run, its syntax, source reads, local transitions, heads and last-write memories are all authentic. No mode accepts. For completeness, suppose the pair is not a true rejecting run. If a grammar, source-authentication, state, head, transition or termination condition fails, Mode I (or direct parsing) detects it. Otherwise suppose every chronological read agrees with the most recent alleged write or the initially blank symbol. By induction on $t$, each alleged work configuration and source-head state then equals the actual deterministic guest configuration. Its locally valid next transition is forced and equals the actual transition. Induction through the final record proves a genuine rejecting run, contrary to invalidity. Thus some earliest memory discrepancy exists and Mode II accepts it. All nondeterministic modes stay within the stated simultaneous time and space ceilings. Taking the complement gives the co-nondeterministic pair-language claim.
\end{proof}

\begin{corollary}[The explicit existential/universal polarity firewall]\label{cor:quant}
Under (1), for a uniform deterministic indexed defect predicate $\mathrm{DEFECT}_A(F,\tau,w)$ whose witness $w$ encodes a parsing/local/last-write defect,
\[
 F\in\UNSAT\iff
 \exists\tau\in\{0,1\}^{O(R\log M)}
 \ \forall w\in\{0,1\}^{O(\log X)}:
 \neg\mathrm{DEFECT}_A(F,\tau,w).
 \tag{3}
\]
The $\exists\tau$ quantifier is not eliminated by the shortness of $w$. The additional $O(R\log M)$-bit trace must be generated, guessed and made consistently accessible in the same machine before (2) can be invoked. A standard one-way nondeterministic choice stream is not a free, independently indexed read-only trace tape. Thus (3) neither satisfies van Melkebeek's ordinary-source coNTIME input requirement nor turns the DMW nondeterministic TAUTOLOGY bound into a contradiction.
\end{corollary}

\section{Explicit hostile forged rejection and finite controls}
The exact toy control has initially blank cells and three deterministic phases. Phase 0 reads work cell 0 as 0 and writes 1 before moving to cell 1. Phase 1 reads cell 1 as 0 and moves back to cell 0. Phase 2 accepts upon reading 1, rejects upon reading 0. The \emph{true} third read is 1 and the genuine execution accepts. The forged third record claims a read of 0 and a locally legal rejecting transition. Every local state/position/transition check passes, yet a backwards last-write check reports the earlier cell-0 write of 1. A merely step-by-step local checker would accept a fabricated rejection. This is a toy trace checker control, not an alleged ordinary-SAT solver.

The dependency-free JavaScript reproducer exhaustively enumerates all 64 six-bit before/after assignments to the three steps, tests both final polarities, compares local syntax to full work coherence, and checks the chronological last-write rule in $6^5$ additional event lists over three work addresses. Recorded counts:
\[
 64\text{ candidates},\quad128\text{ polarity inspections},\quad
 23{,}328\text{ last-write assertions},\quad
 23{,}585\text{ assertion groups},\quad0\text{ failures}.
\]
Exactly one locally legal rejecting trace is forged; no authentic rejecting trace exists for that toy run. An authentic accepting trace is also checked. The finite experiment is \textbf{COMPUTATIONAL}; it is not the proof of Theorem~\ref{th:bad}.

\section{Arbitrary-$K$ and three-model resource ledger}
If hypothetical $P=NP$ supplies an unknown fixed correct guest $A$ with a total worst-case time $R\le N^{K+o(1)}$, then even an authentic shortest full history has $X=O(N^{\max(1,K)+o(1)})$ compound bits, and the checker (2) costs $N^{K+o(1)}$ in the worst case of long histories. In the ordinary source-only computational problem, either generating the actual history or paying for an existentially guessed \emph{readable} immutable trace remains a separate obligation. The present theorem proves no strict $K\mapsto K-\epsilon$ transition. Padding, Horn/2SAT, affine Gaussian systems, independently contradictory components and DELAY/COPY wrappers are compatible controls, not unconditional hardness evidence.
