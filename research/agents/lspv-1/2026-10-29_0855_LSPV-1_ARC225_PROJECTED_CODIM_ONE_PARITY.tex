\section{PROPOSE and exact missing arrow}
The missing general lemma is a uniform, polynomial-cost, answer-preserving single-child contraction for arbitrary SAT, preserving both YES and NO with all source, exploration, transition and output costs charged. ARC223 handles independent observed affine forms, and ARC224 charges the dimension of the cyclic affine core. We proposed four falsifiable mechanisms before source search: (M1) one dependency permits polynomial time even when the cyclic-core dimension is high; (M2) separate consistency tests for multiple dependencies suffice; (M3) high primal width and large cyclic core force large time; and (M4) this restricted technique supplies an arbitrary-SAT compressor. M1 is proved under the specified grammar, M2 is falsified, M3 is falsified as a general hardness inference, and M4 remains open.

\section{Grammar, projection and paid rank}
An input CNF has its ternary clauses partitioned into disjoint, complete four-clause encodings of signed XOR3 equations. Every remaining clause has width one or two. Parse and authenticate source quartet identities, or return UNKNOWN. Each four-clause block is pointwise equivalent to an XOR equation. Form the affine system \(Ax=d\). If inconsistent, output a source-indexed XOR row-combination contradiction. Otherwise Gaussian elimination gives
\[
x_i=c_i\oplus\langle v_i,t\rangle,\qquad t\in\mathbb F_2^r.
\]
Let \(V\) be the distinct nonzero coefficient vectors \(v_i\) appearing in the remaining 2CNF, \(p=|V|\), \(\rho=\operatorname{rank}(V)\), and \(\delta=p-\rho\). Each variable with zero coefficient becomes a constant; each other variable becomes a coordinate \(y_v=\langle v,t\rangle\), possibly complemented. Thus the remaining source clauses become a 2CNF \(B(y)\). The image of the free affine parameters is \emph{exactly} the simultaneous solution set of \(\delta\) independent parity equations on \(y\), computed by Gaussian elimination. This includes every auxiliary and original variable cost, with no free semantic oracle.
\begin{theorem}[Exact codimension-one selector; restricted]
There is one deterministic uniform polynomial-bit-time program which, on the stated authenticated source grammar, decides SAT or UNSAT when the affine part is inconsistent or \(\delta\le1\), and returns UNKNOWN otherwise. On YES it constructs an original-source-replayable assignment. On NO it emits an affine row contradiction or a checkable labeled implication-graph and parity-exclusion certificate. Parsing, all Gaussian operations, failed 2SAT trials, graph construction, lifting, verification and physical output are charged.
\end{theorem}
\begin{proof}
An inconsistent affine system has a row sum giving \(0=1\), each source row being authenticated by four signed clauses. Otherwise construct \(B(y)\) and the full dependence space as above. If \(\delta=0\), every coordinate choice is reachable, so apply ordinary implication-graph 2SAT. If \(\delta=1\), the only dependency is a known XOR parity of the observed coordinates. Apply Lemma 2. For a satisfying \(y\), solve the explicit linear preimage equations \(v\cdot t=y_v\), recover \(x_i\), and replay every original clause. For a rejection, use source-labeled implication paths and parity exclusion, together with the affine rank and quartet provenance. There are polynomially many variables, SCC calls and full work buffers, all of polynomial bit length.
\end{proof}
\begin{lemma}[Known 2CNF plus one parity algorithm]
Given 2CNF \(B\), a set \(S\) and a bit \(d\), there is a deterministic polynomial algorithm deciding \(B(y)\wedge\bigoplus_{i\in S}y_i=d\), with constructible witnesses and checkable exclusions.
\end{lemma}
\begin{proof}
Construct the 2SAT implication digraph, its strongly connected components and a model \(a\), unless complementary literals share a component, in which case two labeled paths certify inconsistency. Pair each SCC with its complementary SCC. For a pair \(P\), let \(w_P\) be the parity of the variables of \(S\) belonging to that pair. Any two models of \(B\) can be connected by moves that flip all variables in one complementary SCC pair at a time: on the condensation DAG, choose a sink of SCCs false in the current model and true in the target; flipping its pair preserves all implications, including contrapositives, and reduces the number of mismatched pairs. A pair flip changes the target parity iff \(w_P=1\). If the parity of \(a\) matches \(d\), accept. Otherwise, for each odd-weight pair test the opposite pair orientation by an ordinary 2SAT call fixing one representative variable. If any odd pair is flexible, the path to an opposite-orientation model includes a move changing parity, producing the desired model. If no odd pair is flexible, its value is forced in all models, and all models have the same parity as \(a\). Implication paths certify the forced orientations. Greedy 2SAT/parity self-reduction reconstructs one witness with polynomially many calls.
\end{proof}
\section{BUILD: a high-width, high-cyclic-core family}
For \(k\ge3\), encode \(x_1\oplus\cdots\oplus x_k=0\) by \(k-2\) authenticated XOR3 quartets and \(k-3\) private chain variables. Add all \(\binom{k}{2}\) binary clauses \((\neg x_i\vee\neg x_j)\). The observed-variable clique has primal treewidth at least \(k-1\), and the complete encoding is \(\Theta(k^2\log k)\) bits. The observed affine vectors have \(p=k,\rho=k-1,\delta=1\), and none is a coloop, so ARC224's cyclic-core parameter is \(h=k-1\). ARC225 nevertheless solves each instance in polynomial time. Fixing the first \(k-1\) variables to zero and \(x_k\) to zero gives a SAT control; fixing \(x_k=1\) gives an UNSAT control. The isolated affine and isolated binary languages are satisfiable in both controls. This is not signed strict exact-(2,2)-3SAT and does not prove a general lower bound. A shortcut for two dependencies is false: \(B=(u\vee v)\), with \(u=0\) individually and \(v=0\) individually feasible, but together impossible.

\section{Three separate native ledgers and open dependency chain}
For a recognized source, one uniform program decides the answer and emits a canonical constant-size terminal instance, yielding a restricted \(N^{3/4}\) single child for \(N\ge4096\), with direct bounded base cases. On an indexed RAM, matrix operations and \(O(p^2(p+|B|+1))\) graph work are polynomial, all failed calls and intermediate outputs included. A deterministic read-only-input multitape TM has polynomial but different tape-transport overhead. A one writable shared-tape TM counts input footprint and all head moves, with a polynomial universal simulation but no imported RAM lower bound. A fixed universal interpreter charges program and simulation overhead. For two fully writable tapes, writable-input storage is accounted separately. SAT and UNSAT are restrictions of \emph{one} correct solver, not machines given a free answer bit.

The lead dependency chain is: source authentication \(\to\) affine form extraction \(\to\) paid codimension computation \(\to\) the known SCC one-parity routine \(\to\) source-replayed SAT or UNSAT certificate \(\to\) restricted terminal child. A uniformly computable, recursively closed \emph{all-input} answer-preserving \(N^\lambda\) child or polynomial-value rank descent remains OPEN.
