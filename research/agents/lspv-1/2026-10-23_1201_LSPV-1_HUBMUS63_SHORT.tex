\section*{HUBMUS63: high-order ternary conflict with linear decision}
\textbf{PROVED/EXACT in declared models. P versus NP OPEN.}
Fix binary-or-ternary CNF in fixed four-word clause records, with
$w=\lceil\log_2(64(n+m+1))\rceil$-bit words and $N=(2+4m)w$.
Here $k$ counts ternaries, $d$ eliminated variables, $r=n-d$.
Three falsifiable mechanisms: high-order relative incompatibility;
charged unit-and-projection normalization; all-field source sensitivity.

For a satisfiable 2-CNF backbone $B$ and identified ternaries
$\mathcal T=\{T_1,\ldots,T_k\}$ define
\[
\iota_B(\mathcal T)=\min\{|J|: B\land\bigwedge_{j\in J}T_j
\text{ is UNSAT}\},
\]
with value infinity if the complete formula is SAT. This is semantic
but independent of observed solver runtime.

Fix $t\ge3$ and variables $x_0,\ldots,x_{t-1},y,u$. Put
$B=(\neg y\vee u)\land(\neg y\vee\neg u)$.
For each cycle edge $i$ encode $x_i\oplus x_{i+1}=b_i$,
indices modulo $t$, with two binary clauses: if $b_i=0$ use
$(\neg x_i\vee x_{i+1}),(x_i\vee\neg x_{i+1})$;
if $b_i=1$ use $(x_i\vee x_{i+1}),(\neg x_i\vee\neg x_{i+1})$.
Replace each such $(a\vee c)$ by the proper ternary $(y\vee a\vee c)$.
Call the result $H_{t,b}$. Exactly $k=2t$ ternaries,
$n=t+2$, $m=k+2$, $N=(8t+10)\lceil\log_2(64(3t+5))\rceil$.

\begin{theorem}
For every odd-parity edge vector $b$, $H_{t,b}$ is clause-minimally
UNSAT and $\iota_B(\mathcal T)=k$. It has no unit clause, pure variable,
or strict subsumption, so $d=0$, $r=n=t+2$, and
$r/\log N\to\infty$. Nevertheless its minimum strong 2-CNF backdoor
is one, found by a linear source scan; two SCC 2-SAT calls decide
both labels in $O(n+m)$ word time and $O(n+m)$ reusable words.
Every one of the $k$ signed-hub literal fields is sensitive on this
UNSAT input, so every total deterministic exact word-probe SAT
decider must read at least $k$ distinct source words.
\end{theorem}
\begin{proof}
Resolution of the two backbone clauses yields $\neg y$.
The ternaries then reduce to the binary XOR cycle. XORing all
edge equations forces even parity, so odd parity is UNSAT.
If any ternary is deleted, satisfy all other edge equations and violate
only its edge. Exactly one of that edge's binary pair is false;
complementing all primary variables switches which one. This gives a
witness for deletion of either ternary. If a backbone clause is
deleted, choose $y=1$ and an appropriate $u$; all ternaries are true.
All clauses are essential. Every variable has both signs and the
different clause supports preclude strict subsumption.
Every ternary contains $y$. Intersect variables of the first ternary
with all subsequent ternary supports to discover that common
backdoor, then restrict on its two assignments; each branch is 2-CNF.
Finally, flip the sign of $y$ in one ternary. Since the backbone forces
$y=0$, the changed ternary becomes automatically true, and minimality
gives the opposite SAT label with an identical-length valid encoding.
Any solver omitting that word would execute identically on the pair.
This works for each of the $k$ distinct word positions.
\end{proof}

\section*{Exact restricted amortization}
The declared explicit projection calculus first resolves $B$ to
derive $\neg y$, then resolves each original ternary
$(y\vee a_i\vee c_i)$ with the unit to materialize
$(a_i\vee c_i)$. Let $\Phi$ count unprojected ternary records.
The unit inference changes $\Phi$ by zero; each separate projection
reduces it by exactly one and emits a binary record. Normalizing all
$k$ records requires exactly $k$ projections, $k+1$ inferences
including the hub unit, and $k$ output records. This is a restricted
representation-work statement, not a universal decision lower bound.

For $b=(0,\ldots,0,1)$, the refutation uses one unit inference, $k$
ternary projections, $2(t-2)$ forward/reverse implication compositions
and three endpoint inferences: exactly $2k$ DAG resolution inferences.
Repeating the unit derivation separately for each ternary gives a
tree-like proof with $3k-1$ inferences, no derived-node reuse.
Both proof encodings have $O(k\log k)$ bits.

For general 2-CNF plus at most $k$ ternaries, greedy ternary-variable
hitting followed by branching and SCC gives the known
$O(2^k\operatorname{poly}(N))$ upper bound, not a lower bound.
MAIN TERNARY-PROJECTION-KERNEL88 projects out 2-CNF-only variables;
for this example its projected backbone is equivalent to $\neg y$.
