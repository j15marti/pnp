\section{Canonical targets and three falsifiable gap-fill hypotheses}
The canonical target $\mathcal C_{\rm M22}$ contains duplicate-free three-distinct-variable OR clauses, each entirely positive or negative, with each active variable appearing exactly twice per sign. Literalwise complementation $\bar C$ preserves OR and is not Boolean negation. $\mathcal C_\star=\mathcal C_{\rm M22}\setminus\{F:\forall C\in F,\bar C\in F\}$ excludes only fully paired sources; partial pairs, disconnected, and easy members are included. $L_\star$ is its total valid-and-SAT language, rejecting malformed strings. Write $k=n(F)$, $m=4k/3$ and $N=|\mathrm{enc}(F)|=\Theta(k\log(k+2))$ for dense target encoding. D\"ocker's NP-completeness and the checked six-variable SAT fixture $Y$ establish $L_\star$ NP-complete, not a time lower bound.

The \emph{source} in the new compiler below is instead an indexed, fixed-record, arbitrary signed 3-CNF with $L=3m$ literal occurrences of $b$-bit variable identifiers. Its bit length $N_0=\Theta(Lb)$, and the associated ordinary SAT language must not be confused with $\mathcal C_\star$.

\item[H2 (FILLED restricted).] The resulting fixed-layout bounded-fanout circuit supports both locally computed children and locally computed parent ports. The explicit stage/channel and internal-template wiring does; this does \emph{not} infer inverse adjacency for arbitrary JMV circuits.

\section{Exact source verifier without occurrence-rank scanning}
Fix a well-formed width-three source $F=(C_0,\ldots,C_{m-1})$. Let $a_i\in[1,2^b-1]$ be the named identifier and $\sigma_i\in\{+,-\}$ the sign of occurrence $i\in[0,L)$. Introduce a Boolean \emph{existential} bit $y_i$ for each \emph{occurrence}, not for each variable. Put
\[
V_F(y)=\bigwedge_{j<m}\bigvee_{i=3j}^{3j+2}\mathrm{lit}(y_i,\sigma_i)
\quad\wedge\quad
\bigwedge_{\substack{i,i'<L\\a_i=a_{i'}}}(y_i\leftrightarrow y_{i'}).
\]
The second formula is displayed semantically; the compiler does not output all $L^2$ equalities.

\begin{theorem}[Oblivious-sort consistency equivalence; restricted exact]
For every such well-formed indexed source $F$,
\[
\boxed{\operatorname{SAT}(F)\iff \exists y\,V_F(y).}
\]
There is a uniform deterministic bit-indexed reduction to an ordinary Tseitin 3CNF whose length is $O(N_0\log^3(N_0+2))$, with an output-bit accessor using $(\log(N_0+2))^{O(1)}$ time and $O(\log(N_0+2))$ writable/index space on a read-only indexed source. The source-input occurrence inversion is not materialized. Every addressed gate has a constant-size \emph{locally computable} parent-port list in the constructed bounded-fanout circuit.
\end{theorem}
\begin{proof}
Assign each occurrence a record $(d,a,y)$, where $d=0$ for real positions. Pad to $P=2^{\lceil\log_2 L\rceil}<2L$ records by dummy records with $d=1$. Sort lexicographically on $(d,a)$ using the fixed Batcher bitonic network, carrying the unconstrained witness payload $y$. Equal real names form consecutive blocks in the output, independently of the input data. Assert for each adjacent output pair: if both are real and have equal identifier, their payload bits agree. Transitivity of equality on each block is equivalent to \emph{all} pairwise original-name equalities in $V_F$. Clause gates on the \emph{unsorted} witness occurrence bits impose the first conjunction. A satisfying named source assignment makes every occurrence payload equal to its original bit and passes. Conversely any accepting occurrence payloads agree within each variable's block and induce a single named satisfying source assignment.

Let $p=\log_2P$. Batcher's fixed schedule consists of $D=p(p+1)/2$ stages, each with $P/2$ compare-exchanges. At stage $(r,h)$, where $1\le r\le p$ and $0\le h<r$, the partner of channel $i$ is $i\oplus2^h$, with comparison orientation determined by the $r$th bit of $i$ (the last stage always ascending). A fixed Boolean ripple comparator and multiplexer network compare and carry $b+2$-bit records with $O(b)$ constant-fanin gates per pair. Duplicate a comparison-control signal by an explicitly indexed binary copy tree so that individual gate fanout is bounded by an absolute constant. Every gate is named by a constant-depth tuple of stage, pair/channel, field bit and gate-template offset. From one such name, children and parents are given by a constant number of arithmetic shifts, exclusive-ORs, neighbor-stage lookups and fixed template cases. No data-dependent inverse permutation or global occurrence table is queried. All arithmetic is on $O(\log N_0)$-bit indices; bit complexity is polylogarithmic.

The sorter uses $O(Pb\log^2P)=O(N_0\log^2(N_0+2))$ gates. Equality checks, source signs and clause disjunctions, a binary conjunction tree, source constants, and optional fixed-field validity circuits fit the same bound. Standard constant-size Tseitin clauses for $\{\wedge,\vee,\neg\}$ and output assertions give $O(N_0\log^2 N_0)$ clauses, with $O(\log N_0)$ bits per identifier, hence $O(N_0\log^3 N_0)$ indexed bits. At a target-bit address, fixed-range division identifies the owning gate/template and literal slot, computes its child index using the local formula, and reads only the input-source bits if the owner is a source-constant gate. One deterministic finite program performs this for all input sizes. For malformed fixed-width records, an in-circuit range/check predicate forces output false; gross header/length mismatches are resolved directly by logarithmic-bit arithmetic. This establishes the declared fixed-record totality, without silently extending it to every other source encoding.
\end{proof}

\paragraph{Parent-tag transfer limitation.}

The constructed sorter meets those \emph{interface} assumptions, so its Tseitin syntax admits this exact tagging procedure. However tagging a mixed-sign gate-CNF is not a proof that it can be transformed \emph{locally and correctly} to the required tagged clausewise-monotone $(3,3)$ intermediate. The theorem here improves that first-leg interface on fixed-record 3CNF only, not the tagged grammar or general FLMV source.
