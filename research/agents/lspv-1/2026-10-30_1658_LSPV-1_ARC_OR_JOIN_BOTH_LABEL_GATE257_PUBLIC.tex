\section{Exact guarded 3CNF source family}
For each $i$, let $G_i(0)$ be the eight signed ternary clauses on three private variables. Exactly one of these eight clauses is falsified by each complete assignment, so $G_i(0)$ is UNSAT. Form $G_i(1)$ by replacing its all-negative clause by a duplicate of the existing clause $(u_i\vee\neg v_i\vee\neg w_i)$. This has eight original indexed records of the same width and is SAT, with all-one witness. For $b\in\{0,1\}^q$, let
\[
H_b=(s_1\vee\cdots\vee s_q)\wedge
\bigwedge_{i=1}^q\bigwedge_{C\in G_i(b_i)}(\neg s_i\vee C).
\]
Replace each guarded four-clause $(\neg s_i\vee l_1\vee l_2\vee l_3)$ by
$(\neg s_i\vee l_1\vee a_{i,C})\wedge(\neg a_{i,C}\vee l_2\vee l_3)$,
where $a_{i,C}$ is fresh. Replace the long selector OR by the standard existential ternary chain, including the two-ternary equivalent for $q=2$. Add the independent satisfiable mixed-overlap pair
$(p\vee r\vee t)\wedge(p\vee\neg r\vee z)$.
Call the resulting proper three-CNF $F_b$.

\begin{theorem}[Both original labels preserved]
For every $q\ge2$ and every $b$, $\operatorname{SAT}(F_b)$ if and only if $\bigvee_i b_i=1$.
\end{theorem}
\begin{proof}
Existentially eliminating each fresh guard auxiliary gives the corresponding four-clause; existentially eliminating selector-chain auxiliaries gives $s_1\vee\cdots\vee s_q$. A satisfying parent has some active $s_i$, which requires all clauses of $G_i(b_i)$, and therefore $b_i=1$. Conversely, choose one $i$ with $b_i=1$, make only $s_i$ true, use the all-one private witness for that block, extend all inactive blocks and the selector chain, and set $p=1$ for the control pair.
\end{proof}

\section{Necessary completed-query cost only in the declared interface}
\begin{theorem}[Known OR decision-tree bound; source-blind label-only model]
A deterministic controller receives the $q$ child labels $b_i$ only by completed indexed calls and no other source-derived information. On the promise $b\in\{0^q,e_1,\dots,e_q\}$, any exact OR decoder must complete all $q$ distinct calls on $0^q$, and some one-hot YES source also requires $q$ calls.
\end{theorem}
\begin{proof}
If a NO transcript leaves index $j$ unqueried, the YES vector $e_j$ produces the identical answers but needs the opposite decision. Therefore every index must be queried on all-NO. Put the single YES at the final index in that deterministic all-NO query order. All prior replies remain zero, so the YES path also needs $q$ completed calls. Sequential querying is tight.
\end{proof}

Fix any correct SAT guest $A_0$ and any positive integer $D$. The correct guest $A_D$ waits at least $m^D$ physical steps on each ordinary $m$-bit input before running $A_0$. The declared sequential protocol on all-NO must therefore pay at least $qm^D$. If $q=N^{\theta-o(1)}$, $m=N^{\eta-o(1)}$, the ARC time envelope necessitates
\[
\theta+D\eta\le\max\{\alpha,\gamma+\lambda\max(K_0,D)\}
\]
for every fixed $D$. Letting the fixed integer $D$ be arbitrarily large implies $\eta\le\lambda$, and at equality $\theta\le\gamma$. This is the prior completed-guest-spectrum inequality specialized to a forced all-NO transcript, not a new general lower bound.

\noindent\textbf{Critical source-aware counterexample.} All $G_i(b_i)$ are visibly eight-clause signed masks. A single authenticated pass recognizes the normalized source promise and determines each label by the missing-all-negative/duplicated-sign pattern. It decides the entire promised family in $O(N)$ bit time and $O(\log N)$ writable space, without any guest calls. Arbitrary SAT algorithms may inspect and preprocess original sources, make virtual children, select different policies, or independently certify answers. Thus the response-only query floor cannot be transferred to arbitrary machines. A correct nonpromise fallback is necessary and remains unconstrained. Interruption without a completed answer is never an UNSAT proof.
