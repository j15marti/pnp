\section{PROPOSE: the exact missing lemma}
ARC229 and the independent LSPV-3 BINARY-ADHESION-COMPOSITION166 prove a polynomial exact message algorithm on verified module trees with edge separators of size at most two, provided every module's \emph{raw original} affine row rank is bounded by one fixed constant. LSPV-4 HYBRID-BAD-MESSAGE228 extends composition to a bounded union of non-bijunctive child separators, retaining the same bounded \emph{raw} rank assumption. ARC228 already implements implication-graph SCC compression in its local Arvind--Guruswami-style solver. The question is whether these existing pieces yield a genuinely larger, formally specified tree class by checking affine rank \emph{after} absorbing source-authenticated bijunctive child messages and quotienting forced literal equivalences, instead of bounding the unprocessed local affine rank.

\begin{description}
\item[] \textbf{M1, effective-rank replacement:} every exact 2CNF child message may be absorbed before SCC quotient, and the quotient affine rank, not the original rank, controls the known fixed-codimension solver. \textbf{PROVED/EXACT} below as a restricted composition extension.
\item[] \textbf{M2, unbounded-rank hostile source:} polynomially many independent original affine rows can collapse to one quotient row through authenticated binary child messages. \textbf{PROVED/EXACT} by an unbounded family, tested through $q=128$.
\item[] \textbf{M3, budget-exceeded safety:} an input with excessive effective rank can be classified UNSAT merely because the bounded-rank strategy fails. \textbf{FALSIFIED/RETIRED} as a sound rule; the controller explicitly returns UNKNOWN.
\item[] \textbf{M4, strict22 lift:} every strict signed exact-$(2,2)$-3CNF admits a polynomially discoverable decomposition and suitably low effective rank. \textbf{OPEN}; no reduction or coverage theorem is supplied.
\end{description}

\section{A source-authenticated SCC quotient}
A \emph{module tree} is a polynomial-bit encoded tree $T$ with bags $V_t$, a complete list of original constraints, and an assignment of each unique source-ID to \emph{exactly one} owner $t$ containing its entire scope. Each constraint is either a unary/binary clause or an explicit GF(2) equation. For every variable, the bags containing it form a connected subtree. These conditions, including original source IDs and absence of unowned crossing constraints, are checked in polynomial time; the decomposition is \emph{given and verified}, not discovered for free.

Root $T$ and write $S_t=V_t\cap V_{p(t)}$, with $S_r=\varnothing$. Let $R_u\subseteq\{0,1\}^{S_u}$ be the exact feasibility relation of a child subtree. For $|S_u|\le2$, $R_u$ has a computable exact 2CNF description with at most four clauses, one for each forbidden tuple. At a node $t$, append all these child descriptions to the original local 2CNF $C_t$, yielding $C_t^*$. For each assignment $\alpha\in\{0,1\}^{S_t}$, let $C_{t,\alpha}$ be $C_t^*$ with the corresponding unit pins. Let $M_t x=b_t$ denote \emph{only the original affine rows owned by} $t$.

Construct the directed implication graph of $C_{t,\alpha}$. If a literal and its negation belong to the same SCC, the 2CNF is UNSAT. Otherwise, for every complementary pair of SCCs choose one Boolean coordinate, obtaining an affine substitution
\[
 x=A_{t,\alpha}z+c_{t,\alpha}.
\]
This substitution is built from true literal equivalences, not conjectured equalities. Transform all original affine rows into
\[
 M_tA_{t,\alpha}z=b_t+M_tc_{t,\alpha},
 \qquad e_{t,\alpha}:=\operatorname{rank}_{\F}(M_tA_{t,\alpha}).
\]
A transformed zero-coefficient row with right side one certifies an immediate affine inconsistency. The \emph{effective rank} $e_{t,\alpha}$ can be far below $\operatorname{rank}(M_t)$.

\begin{lemma}[Exact SCC quotient and rank monotonicity]
For satisfiable $C_{t,\alpha}$, its satisfying assignments correspond bijectively to the satisfying assignments of the explicitly substituted 2CNF in $z$. The combined 2CNF--affine system has precisely the same SAT answer after the substitution, with a polynomial-time inverse witness map. Moreover,
\[
0\le e_{t,\alpha}\le\operatorname{rank}(M_t).
\]
Adding further sound literal identifications or fixed-coordinate pins cannot increase the affine coefficient rank after quotient.
\end{lemma}
\begin{proof}
Every path of Boolean implications between two literal vertices enforces the corresponding implication on each satisfying assignment. Vertices in the same SCC therefore have identical truth values in every satisfying model. Opposite literals belong to complementary SCCs; with no SCC contradiction, assigning a fresh coordinate per complementary pair and replacing every original signed occurrence produces an explicit, total literal substitution. A model of the old CNF maps to a model of the new CNF by the SCC equalities, and every new model lifts to an old model because every original clause is included in the transformed CNF. This establishes the bijection on satisfying assignments. Substituting the same affine map in each original equation preserves its truth value. Since $\operatorname{rank}(MA)\le\operatorname{rank}(M)$ over a field, the rank bound follows; further identifications or pins factor the affine map through another linear map, and cannot increase its rank. Contradictory constant equations are checked before calling the subspace solver.
\end{proof}

\begin{theorem}[Verified-tree effective-rank composition, PROVED/EXACT restricted]
Fix a constant $e_0\ge0$. Suppose an input includes a polynomially discoverable or supplied-and-polynomially-verifiable running-intersection module tree of polynomial total encoded size, with $k\le\operatorname{poly}(N)$ modules and parent-edge separators $s_t=|S_t|\le2$. Suppose that, for every module $t$ and every separator assignment $\alpha$ for which the absorbed local 2CNF is consistent and its transformed affine equations have no immediate contradiction, the \emph{effective} coefficient rank satisfies $e_{t,\alpha}\le e_0$.

Then one uniform deterministic program decides SAT and UNSAT and reconstructs an original source assignment on YES inputs in
\[
\boxed{D(N)+\operatorname{poly}(N)\sum_t 2^{s_t}(N_t+1)^{O(e_0+1)}},
\]
where $D(N)$ charges parsing, decomposition discovery when required, complete source authentication, SCC and rank computation, all unsuccessful local queries, message compilation, tables, bit-level output and model replay; $N_t$ includes the local encoded source and all actually compiled child descriptions. The bound is polynomial even if the original affine rank $\operatorname{rank}(M_t)$ is unbounded at individual modules and the union of a node's shared names has linear size. If $e_{t,\alpha}>e_0$ in an unproved case, the controller returns UNKNOWN, never an unchecked NO answer.
\end{theorem}
\begin{proof}
Process the verified tree bottom-up. Every child relation on at most two shared bits is exactly 2CNF-definable, including the empty relation. Absorb each completed child message into $C_t^*$. Enumerate all $2^{s_t}\le4$ parent assignments $\alpha$. If the pinned local 2CNF is inconsistent or an affine zero row contradicts its right side, mark that row infeasible. Otherwise compute the SCC quotient, and apply the known deterministic Arvind--Guruswami fixed-codimension algorithm to the \emph{quotient} source, where the rank is at most $e_0$. Each successful local call stores its complete local witness and a feasible parent row. The exact parent message is the table of feasible rows. Source-once ownership and running intersection imply, by induction, that compatible child witnesses glue independently to the parent witness, and every global satisfying assignment appears among the tested local rows. Thus the empty root separator is feasible exactly when the original source is SAT. Replay stored child models to reconstruct one globally consistent assignment and check all original source constraints. A negative result arises only after all locally bounded calls have been exhaustively decided. If a rank cap is violated, the result is UNKNOWN; it cannot be misreported as UNSAT. Each source-level read, failed branch and output is bounded by the displayed deterministic per-module sum, and stored tables have at most four entries each. This is a sufficiency theorem on a \emph{verified mixed grammar}, not a universal decomposition finder or a 3SAT contraction.
\end{proof}

\section{Unbounded raw local rank: an exact two-label family}
\begin{proposition}[Connected star with rank $q\to1$]
For each integer $q\ge2$, let the root bag contain $z,x_1,y_1,\ldots,x_q,y_q$, owning the $q$ affine equations
\[
 x_i\oplus y_i\oplus z=\beta_i,\qquad 1\le i\le q.
\]
For every $i$, attach a distinct leaf owning the two 2CNF clauses $\neg x_i\vee y_i$ and $x_i\vee\neg y_i$; its separator is $\{x_i,y_i\}$. All conditions of the theorem hold with $e_0=1$. The original root affine matrix has rank exactly $q$, while after compiling authenticated equality leaves and SCC quotient it has rank one. The entire mixed formula is SAT iff $\beta_1=\cdots=\beta_q$, and is UNSAT otherwise.
\end{proposition}
\begin{proof}
The leaf clauses enforce $x_i=y_i$, and both values are realizable. Every root row contains a pair of variables unique to that row, so the $q$ coefficient rows are linearly independent. SCC quotient substitutes $y_i=x_i$, making every root equation $z=\beta_i$. These have one independent nonzero coefficient, or a constant contradiction when the right sides disagree. Assigning $z$ to the common bit and choosing arbitrary equal $x_i,y_i$ proves SAT; two unequal right sides prove UNSAT. The root is adjacent to every leaf, every variable occurs in a connected set of bags, and every constraint has exactly one owner. Physical input and outputs have polynomial length in $q$. The full accumulated root interface contains $2q$ bits although every edge has only two.
\end{proof}

\section{Separate native machine ledgers and corpus reconciliation}
The displayed algorithm is uniformly polynomial on an explicit indexed-bit-RAM implementation for the stated class. A fixed-$k$ read-only-input multitape machine can parse and implement all operations with a polynomial time overhead and an explicit polynomial count of distinct work cells; a two-tape machine with one read-only input head and one writable work tape can simulate the fixed-$k$ program with further polynomial overhead. A single shared read/write tape can simulate that program in polynomial time with the original input occupying its footprint; head crossings, written input changes, failed branches, child-table accesses and all physical output are charged. One fixed universal interpreter can run the single program with a constant interpreter description and polynomial simulation overhead. No one-tape crossing lower bound is transferred to two-tape, RAM, or UTM, and no numerical time exponent is asserted identical across models. SAT and UNSAT are restrictions of this \emph{one} controller, not programs given an answer-class advice bit.
