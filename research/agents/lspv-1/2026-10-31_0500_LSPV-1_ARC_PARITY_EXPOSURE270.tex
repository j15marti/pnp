\section{Explicit same-source proper-ternary family}
Fix $m\ge1$ and $b\in\{0,1\}^m$. Introduce $x_0,\ldots,x_m,z,u,v$, giving $n=m+4$ original variables. For each $i=1,\ldots,m$ define two binary clauses $P_i,Q_i$: if $b_i=0$, take $(\neg x_{i-1}\vee x_i)$ and $(x_{i-1}\vee\neg x_i)$; if $b_i=1$, take $(x_{i-1}\vee x_i)$ and $(\neg x_{i-1}\vee\neg x_i)$. Replace each binary clause $D$ by $(D\vee z)\wedge(D\vee\neg z)$ using \emph{one shared} variable $z$. For each $t\in\{0,m\}$ add the four clauses
\[
(\neg x_t\vee \epsilon u\vee \eta v),\qquad
(\epsilon,\eta)\in\{+1,-1\}^2,
\]
where $\epsilon u$ denotes $u$ for $+1$ and $\neg u$ for $-1$, and similarly for $v$. These clauses force $x_0=x_m=0$. Every original clause is proper width three, and there are exactly $4m+8$ clause records.
\begin{theorem}[Both-label source and physical-child semantics]
For every $m$ and every $b$, $F_{m,b}$ has exactly eight satisfying assignments when $\bigoplus_{i=1}^m b_i=0$, and zero otherwise. A fixed ordinary proper 3-CNF child $G_{\mathrm{YES}}$ is formed from all eight sign choices on variables $y_1,y_2,y_3$ by replacing the first clause with a duplicate of the second. $G_{\mathrm{NO}}$ retains all eight. Each has eight physical proper-ternary records of identical declared fixed-width length. The child $G_b=G_{\mathrm{YES}}$ for even parity and $G_b=G_{\mathrm{NO}}$ for odd parity obeys
\[
\operatorname{SAT}(F_{m,b})\Longleftrightarrow\operatorname{SAT}(G_b)
\]
for \emph{both} labels. The YES child has one original-variable assignment and the NO child has none.
\end{theorem}
\begin{proof}
$(D\vee z)\wedge(D\vee\neg z)\equiv D$ for every $z$. The four clauses for each pin reduce to $\neg x_t$, independently of $u,v$. The two binary clauses in block $i$ impose precisely $x_{i-1}\oplus x_i=b_i$. Therefore $x_0=0$ uniquely determines the chain, and $x_m=0$ holds iff the parity of $b$ is even. The three auxiliary variables $z,u,v$ are then unrestricted, giving eight solutions. Every 3-bit assignment falsifies exactly one of the eight fully signed clauses; the all-eight child is UNSAT and deleting one distinct clause (by replacing it with a duplicate) leaves exactly one model. This proves both polarities and the source/child equivalence.
\end{proof}
\section{Tight actual encoded-bit query theorem and caching}
Serialize $F_{m,b}$ with a fixed-width ASCII signed literal record format: header \texttt{CNF:nn:mmmm}, then \texttt{Cjjjj:} and three signed, fixed-width integer IDs separated by vertical bars, one source clause per line. For each fixed $m$ the length is independent of $b$, $N=\Theta(m\log(m+2))$, and \emph{every changing encoded bit lies in the four clause records of exactly one $b_i$}. No output header or clause index encodes two $b$ bits.
\begin{theorem}[Exact cold source-bit depth]
On the promise $\{\operatorname{enc}(F_{m,b}):b\in\{0,1\}^m\}$, the worst-case deterministic adaptive \emph{source-bit} query complexity of the original SAT/UNSAT label is exactly $m$, even with unlimited computation and arbitrary persistent internal state. The same $m$-query lower bound applies to computing the particular child character at which $\operatorname{enc}(G_{\mathrm{YES}})$ and $\operatorname{enc}(G_{\mathrm{NO}})$ differ. After a fully charged scan, the parity may be retained in one bit, allowing repeated accesses at no \emph{additional source-parity-probe} cost.
\end{theorem}
\begin{proof}
Every source bit read is either constant on the promise or depends on only one $b_i$. If a deterministic algorithm terminates without querying an informative bit from some block $i$, replacing $b_i$ by $1-b_i$ preserves its entire query transcript, including adaptively chosen addresses, but reverses the SAT label and the chosen child character. Hence at least one informative query per block is required. Conversely, for each block choose a bit of a known sign byte that distinguishes the two canonical alternatives. Query those $m$ positions and XOR the outcomes; this exactly computes the label. Once the parity is stored, its reuse does not require source reclassification. Neither result concerns arbitrary source encodings, an oracle beyond bit reads, or source recognition outside the promise.
\end{proof}
A single streaming syntax recognizer, with an $O(\log N)$-bit record counter, current-block bit, three fixed-width literal IDs and one parity bit, authenticates this canonical grammar on actual source bytes in $N\operatorname{polylog}N$ time and $O(\log N)$ work bits in a conventional indexed read-only input-tape implementation. On a recognized source it can emit the eight-record constant-size ordinary child and invoke \emph{any fixed} correct total SAT decider $A$ there, even a polynomial DELAY wrapper. The parser itself has already determined the parity, making $A$ unnecessary for this restricted family. Nonmembers require a separate exact fallback, with no polynomial FLMV guarantee supplied here. Cold input reads, source grammar validation, policy choice, serialized child emission, guest reads, output, cache and live state are not free.
