\section{Quantified generalized necessary work}
Let L be the encoded satisfiable duplicate-free proper D\"ocker Monotone 3-SAT-(2,2) language. Malformed strings and valid UNSAT formulas are rejected. Use Elias-gamma headers n,m, and m records of one sign bit plus three fixed-width binary variable IDs, w=floor(log_2 n)+1. An indexed read-only-input machine reads at most one source bit in one physical bit-read operation. Let Q_A(x) count reads including repeats and R_A(x) count distinct read locations. The algorithm is NOT required to output, store, or reconstruct an assignment, syntactic pin key or transcript.

For an accepted length-N x and any same-length collection G of opposite-label strings, set D(x,y)={i:x_i != y_i}. Write tau(G;x) for the minimum cardinality of a source-position hitting set of all D(x,y), and tau*(G;x) for the fractional set-cover LP minimum: minimize sum_i z_i subject to z_i>=0 and sum_{i in D(x,y)}z_i>=1 for every y.

\begin{theorem}[Exact and randomized source-query adversary; classical method]
For EVERY uniform total exact deterministic all-input decider A and EVERY accepted x, Q_A(x)>=R_A(x)>=tau(G;x). For EVERY bounded-error randomized all-input decider A, correct on each malformed and well-formed input with error at most epsilon<1/2,
\[
\boxed{\mathbb E Q_A(x)\ge\mathbb E R_A(x)\ge(1-2\epsilon)\tau^*(G;x).}
\]
No internal state-representation or assignment-recovery assumption occurs. The input encoding and indexed-bit access semantics are declared, not representation-free across different source encodings.
\end{theorem}
\begin{proof}
A deterministic run on x that never reads D(x,y) has exactly the same complete transcript on y, contradicting opposite correct labels. Hence its query set hits all differences. For randomness couple the two runs by the SAME coin tape. With probability at least 1-2 epsilon both answer opposite labels correctly. On that event x must query D(x,y), or both transcripts coincide. Let p_i be the probability x reads input position i at least once. Thus sum_{i in D(x,y)}p_i>=1-2 epsilon for each y. Then z_i=p_i/(1-2 epsilon) is a feasible fractional hitting set, and E R_A(x)=sum p_i proves the bound. Repeated reads and all other computation only increase total work.
\end{proof}

\[
Q_A(E(F_t))\ge t.
