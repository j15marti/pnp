\section{Target and falsifiable hypotheses}
Write $E$ for pairs $(t,s)$ realized \emph{simultaneously by one fixed}
uniform deterministic total ordinary-SAT decider on every ordinary $N$-bit
input, in the indexed read-only-input FLMV random-access Turing-machine
model, with $T(N)\le N^{t+o(1)}$ and writable/index
$S(N)\le N^{s+o(1)}$. In the matched model the known strict forbidden
box is
\[
c_*=\frac{241}{200},\qquad d_*=\frac{11642479}{23232400}
=\beta(c_*),\qquad
\beta(c)=\frac12\left(\frac{c+2}{c^2}-c\right).
\]
Assuming $P=NP$ yields some finite achievable integer diagonal $(K,K)$;
a finite completely charged machine-producing route from cofinally many
such diagonals into $t<c_*,s<d_*$ would contradict FLMV. The route,
ARC-EDGE-90, is \OPEN. The illustrative two-coordinate contraction and
the heterogeneous finite-hit arithmetic are conditional. The former
universal cosine endpoint is \textbf{FALSIFIED/RETIRED}.

Before this run's targeted repository and primary-source search, four
falsifiers were set:
\begin{description}
\item[] \textbf{C1.} A one-sided solver guaranteed fast and low-space
\emph{only on all SAT inputs} may nevertheless compile to a total
all-input exact machine with the same strict exponent margins.
\item[] \textbf{C2.} Simply interleaving two label-successful machines
preserves their successful-side FLMV peak-space bounds.
\item[] \textbf{C3.} Two real ordinary Shannon levels and correctly
typed one-sided guests might themselves guarantee power-short
descendants and a favorable ARC successor.
\item[] \textbf{C4.} Both a SAT-successful and an UNSAT-successful
algorithm are necessary for all-input deterministic total completion.
\end{description}
C1 is established with \emph{pre-access} tape/index caps and arbitrarily
small fixed exponent slack; C2 is false for uncapped dovetailing;
C3 fails at the power-short all-input successor; C4 is false under
a global one-label time-and-space success guarantee.

\section{One-label simultaneous completion theorem}
Malformed inputs are rejected by a fixed source syntax checker using
$N^{1+o(1)}$ time and $N^{o(1)}$ work/index space. All statements below
then concern valid ordinary SAT encodings.

\begin{theorem}[One-sided pre-access bounded completion]\label{th:one}
Fix a uniform deterministic \emph{partial} machine $B_+$ which
can only output SAT, never outputs SAT on a false formula,
and, on \emph{every} satisfiable ordinary input $x$ of length $N$,
outputs SAT within
\[
T_{B_+}(x)\le N^{u+o(1)},\qquad
S_{B_+}(x)\le N^{v+o(1)}
\]
\emph{simultaneously in that one successful computation}.
On UNSAT inputs $B_+$ may diverge, make very expensive accesses or
perform arbitrary unsuccessful work. For every fixed rational
$\varepsilon>0$ there is a single uniform deterministic \emph{total}
ordinary-SAT decider $W_{+,\varepsilon}$, correct on both labels, with
\[
\boxed{\
T_W(N)\le N^{\max\{1,u\}+\varepsilon+o(1)},\qquad
S_W(N)\le N^{\max\{0,v\}+\varepsilon+o(1)}.\
}\tag{1}
\]
The completely dual assertion holds for a partial $B_-$ that
only outputs UNSAT correctly and terminates with the same joint
bounds on every UNSAT formula: upon timeout or pre-access abort,
$W_{-,\varepsilon}$ outputs SAT on a valid formula.
The claim is an \emph{existential fixed-machine compiler given the
stated side machine and its exponent guarantee}; it does not
construct any such favorable side machine.
\end{theorem}
\begin{proof}
Choose fixed rational caps $U>\max\{1,u\}$ and
$V>\max\{0,v\}$ within a prescribed fraction of $\varepsilon$
of those maxima. For sufficiently large $N$, the promised successful
side terminates before $\lceil N^U\rceil$ guest steps and does not
read/index beyond $\lceil N^V\rceil$ work-tape coordinates or use more
index-tape cells. Build a fixed interpreter for $B_+$ with one
clock and a separate capped, densely laid-out representation of
each guest work \emph{and index} tape. Before every guest indexed
read, write, head jump or index operation, check that the
\emph{proposed} counted guest work/index-tape position lies within
the space cap. An offending operation is \emph{not executed};
instead the compiler stops the guest and returns UNSAT.
If the time cap is reached first it also returns UNSAT.
A simulated SAT output is trusted only because soundness of $B_+$
was a theorem premise. Every SAT source has a successful trace
inside both caps and is accepted; every UNSAT source cannot produce
a false SAT output and is rejected. Thus the fixed compiler is
total and exact without an UNSAT oracle or an UNSAT proof.

Represent guest cells in consecutive polylogarithmic-size tagged
physical blocks, including guest index tapes. Blank untouched
guest positions remain logically blank; it is unnecessary to
initialize or sweep the entire cap prefix. All tag comparisons,
unchanged writes, arithmetic, indexing, source reads, cap tests,
output handling and guest simulation are paid. Each bounded guest
step takes $\log^{O(1)}N$ real steps in FLMV's model, and the
farthest actual work/index tape coordinate is
$O(N^V\log^{O(1)}N)$. The clock and all fixed-precision
cap arithmetic require $O(\log N)$ bits. Therefore
$T_W\le N^{U+o(1)}$, $S_W\le N^{V+o(1)}$,
yielding (1) after selecting rational caps with enough slack.
Hardwire the finitely many exceptional shorter lengths, or
use a fixed exact baseline decider \emph{only on those lengths}.
Those finite exceptions do not change either asymptotic bound.
The dual machine uses the same construction with opposite timeout
label, after rejecting malformed encodings.
\end{proof}

\begin{theorem}[Strict-box one-sided endpoint, FLMV consequence]\label{th:box}
If a fixed uniform $B_+$ or $B_-$ as above were sound and
successful on \emph{every} respective-label ordinary source
with $u<c_*$ and $v<d_*$ simultaneously,
then FLMV would be contradicted. The same statement applies to
one correctly transported, locally indexed fixed FLMV-hard
source image, \emph{only when} the side success, bit access,
space charges and off-image limitations are explicitly preserved.
\end{theorem}
\begin{proof}
Choose $\varepsilon>0$ smaller than both strict margins.
Theorem~\ref{th:one} would produce one total uniform exact
ordinary-SAT decider within the FLMV strict forbidden box.
For a hard image use the separately charged local Cook reduction
and prove the promise transport before invoking FLMV.
\end{proof}

\paragraph{What this changes in ARC.}
A legitimate \emph{last stage} of ARC could be a fixed $A$-dependent
\emph{SAT-side sound recognizer}, not a full UNSAT-successful
contractor, provided it accepts \emph{every SAT source}
within the strict \emph{joint} budget. Exact SAT-accepting joins
may be sufficient; total UNSAT rejection then comes from the
space-capped timeout. This relaxes the desired semantic interface,
\emph{not} its resource requirement or the missing solver-dependent
machine production. Source eligibility, read/write traffic,
generators, switching, failures, caches, ancestors and any
full-size $A$ calls still count. A witness does not become free.
One cannot apply the lemma if success holds only on an easy
SAT subclass, if the side program accepts any UNSAT input,
or if it has fast SAT time but unbounded SAT-side space.

\section{Why ordinary uncapped racing is not a joint-space proof}
\begin{lemma}[Cross-label space contamination]
Successful-label resource bounds alone do not bound the
farthest indexed position reached by a literal uncapped
round-robin simulation of two partial machines.
\end{lemma}
\begin{proof}
Let $D$ be a fixed exact polynomial-time/space SAT machine,
as exists \emph{conditionally} under $P=NP$, bounded by a
sufficiently large integer exponent $K$ in both coordinates.
Modify $B_+$ to recognize a growing family of obvious
contradictory-unit UNSAT inputs. On that \emph{wrong} label,
before any answer it builds the $O(K\log N)$-bit address
$N^{K+2}$, reads that far work-tape position and loops.
On SAT inputs it instead runs $D$ and outputs SAT when $D$
accepts. Let $B_-$ on that obvious UNSAT family deliberately
spend $\Theta(N)$ counted steps before correctly rejecting,
and otherwise run $D$, outputting only on UNSAT inputs.
Both side-successful traces have joint polynomial
$(K,K)$ bounds. Yet a one-for-one uncapped race on the
obvious UNSAT inputs permits $B_+$'s far read after
$O(\log^{O(1)}N)$ steps, before $B_-$ returns.
FLMV peak work-space then reaches at least $N^{K+2}$.
This falsifies \emph{that mechanical uncapped composition
certificate}, not the existence of a different small-space
ordinary-SAT solver. Pre-access caps prevent this execution.
\end{proof}
A capped two-sided portfolio also works, with the maximum of
the two successful-side time and space exponents plus fixed
slack, but Theorem~\ref{th:one} often gives an equal or
better certificate using just one globally successful side.
Racing remains useful on restricted promises or for
input-dependent practical speed, not as a source of a
free simultaneous exponent improvement.

\section{Executed controls and quantitative limitations}
The reproducible Node/V8 experiment builds twelve actual
ordinary DIMACS roots, six SAT and six UNSAT, including
Horn, affine/XOR, unit contradiction, binary clause products,
empty CNF and empty-clause controls. Every root is serialized
and reparsed, and incurs a \emph{paid} root guest call.
Both Shannon values for source variable 1 create 24 genuine
ordinary first children. Each first child is then actually
restricted on variable 2, serialized and reparsed, creating
48 genuine ordinary grandchildren. Independent full
assignment tables verify 10 SAT/14 UNSAT first children,
14 SAT/34 UNSAT grandchildren and both nested OR joins.

Each of the 60 ordinary root/leaf guest calls runs a
SAT-positive and UNSAT-negative partial search process.
The two independent \emph{single-side} capped-timeout
compilers are checked for each guest, making 120 extra
one-sided decisions. A malicious off-label indexed read
at symbolic position 81 against cap 64 was attempted and
blocked 53 times. The uncapped comparison reached position
81 on those 53 instances, while the capped source-level
symbolic maximum was 14. There were \textbf{473 assertions
and zero failures}, 114,208 charged symbolic source-bit
probes, 8,344 serialized-output bits, 2,928 modeled work-bit
writes (including unchanged writes), and 814 runner events.
No random seed was used.

\emph{Test-development correction:} an initial UNSAT-side
search erroneously rejected SAT formulas after testing all
assignments without remembering whether one satisfied.
An independent single-side timeout assertion detected it.
The reproducer was repaired to track the found-witness bit
before promotion; the displayed data come only from the
verified corrected revision. The original race alone had
hidden this unsoundness because the SAT guest won first.
This validates the need to test \emph{each partial machine's
soundness independently}, not only the portfolio's final label.

The source-level event counters are \emph{not} physical
FLMV transition, farthest-coordinate, hardware, flip or
bit-time measurements. The two-level children are not
uniformly power-short ($\lambda<1$ is unproved), the
finite cap 64 is not an asymptotic ARC budget, and the
toy brute-force guest has no favorable global exponent.
No SAT hard image was experimentally normalized.
