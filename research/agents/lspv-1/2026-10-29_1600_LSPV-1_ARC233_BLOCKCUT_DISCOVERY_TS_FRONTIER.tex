\section{Target, falsifiable mechanisms, and provenance}

\section{Uniform physical models and soundness rules}
Let $N$ be the complete source length in \emph{bits}, including source IDs, variable indices, binary clauses and affine rows. Let $n\le N$ be its number of original variables. For one native machine $M$ and one input $F$, let $T_M(F)$ be all time and $S_M(F)$ the simultaneous \emph{peak writable} bits/cells, with the input included in single-shared-tape footprint but treated separately on a read-only-input multitape machine. Define $t_M(F)=\log_N\max\{2,T_M(F)\}$ and $s_M(F)=\log_N\max\{2,S_M(F)\}$ for $N>1$. RAM word-space counts words of $O(\log N)$ bits and is not numerically identical to tape-cell space. A fixed universal interpreter's constant program is charged through a separate simulation. All claims concern \emph{one fixed deterministic program} on both SAT and UNSAT inputs, not separately chosen algorithms given an answer-class bit.

An \emph{algorithmic Pareto upper envelope} is the set of nondominated jointly attainable resource pairs $(T_A(F),S_A(F))$ across a specified family of real implementations. For a space budget $\sigma$, $\inf\{t_A(F):s_A(F)\le\sigma\}$ can be bounded \emph{from above} by an available algorithm; drawing the envelope of unrelated estimated lower bounds is invalid. Discovery, failure, cache retention, witness recovery, output and simulation are always paid.

\section{A discoverable source-deletion-hereditary tractable class}
Consider \emph{typed} source constraints: ordinary clauses of width at most two, together with explicitly encoded affine equations $\bigoplus_{v\in Q}x_v=\beta$ over $\F$. A source-deletion operation removes whole constraints and preserves their types; it is not an arbitrary literal-deletion or strict signed exact-$(2,2)$ reentry operation. Build the primal graph $G_F$ by making each constraint scope a clique (unary constraints add no edges). Its biconnected blocks form the usual block-cut forest, with isolated variables treated as singleton blocks. Every non-unary constraint belongs to exactly one block: its scope is a clique. Unary constraints are assigned once to any containing block, with a deterministic tie-breaking rule.

For every block $B$, let $E_B$ be the assigned affine coefficient rows restricted to the block variables and $e_B=\operatorname{rank}_{\F}(E_B)$. For fixed $e_0\ge0$, define
\[
 \mathcal{BC}_{e_0}=\{F:\ F\text{ is a well-formed typed source and }\max_B e_B\le e_0\}.
\]
This is not a language of strict 3CNF encodings and makes no occurrence-preservation claim.

\begin{theorem}[Discoverable block-cut affine SAT, PROVED/EXACT restricted]\label{th:block}
For each fixed integer $e_0$, membership in $\mathcal{BC}_{e_0}$ and satisfiability on this class are decidable by \emph{one} uniform deterministic program in polynomial bit time and polynomial peak writable space. The program discovers all blocks, assigns every source constraint once, computes exact Boolean messages of arity at most one, reconstructs a full satisfying assignment, and checks that witness against every original constraint. UNSAT is determined by a deterministic exhaustive local table with at most two calls per nonroot block and one per root. If $B(F)$ is the number of blocks, its charged native bound is
\[
 T(F)\le D(N)+(2B(F)+1)\,P_{e_0}(N)+\operatorname{poly}(N),\qquad
 S(F)\le\operatorname{poly}(N)+S_{e_0}(N),
\]
where $D(N)$ is the paid source parsing, primal construction, Tarjan decomposition, ownership and rank verification, $P_{e_0}(N)=N^{O(e_0+1)}$ is the \emph{known} deterministic Arvind--Guruswami local 2CNF-plus-affine bound, and $S_{e_0}(N)\le P_{e_0}(N)$ is a conservative workspace bound. The dependence on $e_0$ is not FPT, and $e_0=O(\log N)$ is not certified polynomial by this theorem.
\end{theorem}
\begin{proof}
Tarjan computes all maximal biconnected blocks. An edge belongs to one block; a clique with at least three vertices cannot span blocks because every two edges of a triangle belong to the same biconnected block. Thus all original non-unary constraints have a unique assigned owner. For each connected component of the block-cut forest, choose a root block. Process child blocks bottom-up. A child shares exactly one articulation variable $a$ with the rest of the already unprocessed source, so its subtree transmits exactly $R_{\text{child}}(a)\subseteq\{0,1\}$. If several children touch the same articulation, intersect their allowed value sets. Every such compatibility condition is either impossible, no constraint, or one unary CNF pin. For each possible value of the parent articulation (two possibilities, or one root test), solve the owner's 2CNF together with these unary pins and its original rank-$e_B$ affine equations by the known deterministic fixed-codimension algorithm. Adding unary pins to the 2CNF leaves the affine coefficient rank unchanged. Store feasibility flags and one local witness for every feasible flag. Correctness is by induction: any satisfying subtree assignment restricts to a local model obeying all child messages; conversely local models and child witnesses glue uniquely on their common articulation values, and no source constraint spans two owner blocks. A root is feasible iff its entire component is satisfiable. Independent component results are conjoined. The final satisfying assignment is rechecked against the authenticated source. Failed local tests are included in the at most $2B+1$ calls.

With input scopes explicitly encoded, $|E(G_F)|\le O(N^2)$ (usually much less), so Tarjan, source ownership, rank computation, gluing and reconstruction have polynomial bit-time implementations. The local solver makes at most two calls per nonroot block. At most polynomially many one-bit messages, local witnesses, source pointers, and program buffers coexist, giving the stated peak space. On a single tape or restricted two-tape machine a standard explicit polynomial simulation can be charged; this does not inherit the displayed RAM coefficient or establish any SAT lower bound.
\end{proof}

\begin{proposition}[Source-deletion heredity, PROVED/EXACT]\label{prop:her}
For fixed $e_0$, if $F\in\mathcal{BC}_{e_0}$ and $F'$ is obtained by deleting any collection of entire typed constraints, then $F'\in\mathcal{BC}_{e_0}$.
\end{proposition}
\begin{proof}
The primal graph of $F'$ is an edge-subgraph of $G_F$. Every biconnected edge block of a subgraph is contained in some original edge block: an original articulation remains a separator between its incident original blocks under edge deletion. Hence each new block's source affine coefficient rows are a subset of rows assigned to one old block. Coefficient rank cannot increase under taking subsets. New singleton blocks have affine rank at most one for a unary equation, and the old containing block's coefficient rank already bounds it. Therefore the maximum block rank remains at most $e_0$.
\end{proof}

\section{Unbounded width and codimension, bounded local work}
For integer $q\ge3$, construct $q$ anchor variables $a_1,\dots,a_q$ and include all positive binary clauses $(a_i\vee a_j)$ for $i<j$. For each $i$, introduce private variables $u_i,v_i$ and the single affine equation
\[
 a_i\oplus u_i\oplus v_i=0.
\]
The primal graph has a $K_q$ block and $q$ attached triangular blocks, so $\tw(F_q)\ge q-1$. The $q$ affine coefficient rows are linearly independent because each includes private $u_i$, hence global affine codimension equals $q$, but the maximum \emph{block} codimension is one. All $F_q$ are SAT by setting each $a_i=1$ and choosing the private variables accordingly. The UNSAT version additionally pins $u_1,v_1,u_2,v_2$ to zero with unary clauses. This forces $a_1=a_2=0$, contradicting $(a_1\vee a_2)$. Both sides use the same program. The original source has $3q$ variables and $\binom q2+q+O(1)$ typed constraints; its physical indexed encoding is $N=\Theta(q^2\log q)$ under the usual word encoding. Thus global codimension and primal width grow like $\Theta(\sqrt{N/\log N})$, while the exact block-cut controller makes $2q+1$ local calls and remains polynomial.

\section{Four distinct resource frontiers, and how to interpret them}
\noindent\textbf{Static backdoor architecture: a necessary structure bound only.} For the specified connected strict exact-$(2,2)$ modular hypothesis, $n\le3b+12bq$ is a \emph{necessary} inequality. The relaxed permitted minimum is $q_{\min}(b)=\max\{0,n/(12b)-1/4\}$. The two display proxies, not measured SAT complexity, have base-2 exponents
\[
 E_T(b)=b+q_{\min}(b),\qquad E_{S,\mathrm{table}}(b)=b.
\]
In the active range $0<b<n/3$,
\[
 E_T'(b)=1-\frac{n}{12b^2},\quad E_T''(b)=\frac{n}{6b^3}>0,\quad
 b_* =\sqrt{n/12},\quad E_T(b_*)=\sqrt{n/3}-1/4.
\]
The slope $dE_T/dE_S=1-n/(12b^2)$ tends to $-\infty$ as $b\downarrow0$, vanishes at $b_*$, and equals $1$ once $b\ge n/3$ (where $q_{\min}=0$). The two displayed log proxies first coincide at $q=0$, the earliest permitted integer $b=\lceil n/3\rceil$. This is \emph{not} an equality between physical peak writable space and decision time. Streaming assignments uses $O(N+b+q)$ writable bits instead of storing $2^b$ rows. Nor is any permitted proxy point guaranteed realizable as a decomposition. At $n=1200$, integer rounding yields $E_T=20$ at $b=9,10,11$, with only $(b,q)=(9,11)$ among them Pareto-optimal; the complete permitted proxy Pareto set has $b=1,\ldots,9$. Under canonical $N=\Theta(n\log n)$, $b_*=\Theta(\sqrt n)$ yields proxy $E_T/\log_2 N\to\infty$, not a polynomial-time SAT implication.

\noindent\textbf{Primal-width DP: an attainable restricted upper bound.} Given width-$w$ certified bags, conventional DP has $\operatorname{poly}(N)2^{O(w)}$ time, and an explicitly materialized implementation may use $\operatorname{poly}(N)2^{O(w)}$ space. Discovery is separately charged: Bodlaender et al.'s known $2^{O(k)}n$ algorithm either certifies width above $k$ or returns width at most $5k+4$. Thus $k=O(\log N)$ gives a polynomially discoverable upper bound, not a general lower bound. On the above $K_q$ family, $w\ge q-1$ but the discovered block-cut algorithm is polynomial.

\noindent\textbf{Hybrid affine plus 2CNF composition: a certified structural upper bound.} The existing LSPV-4 HYBRID-BAD-MESSAGE228 theorem and ARC232 independently verified specialization, on a \emph{verified or polynomially discovered} module tree, charge
\[
 D(N)+\operatorname{poly}(N)\sum_t\left[2^{h_t}(N_t+1)^{O(e_t+1)}
 +2^{s_t}\operatorname{poly}(s_t+1)\right],
\]
where $h_t$ is the union of the parent separator and exceptional child separators, and $s_t$ is the full parent separator width. This is polynomial when $h_t,s_t=O(\log N)$, all local $e_t\le e_0$ and discovery is polynomial. It does not supply a general decomposition. In the discoverable class $\mathcal{BC}_{e_0}$, the primal block-cut tree has separator width one, no special message test is needed, and discovery is explicit.

\noindent\textbf{State-dependent portfolios: jointly charged \emph{upper} envelopes.} For one fixed controller that tests methods $A_1,\ldots,A_r$, total execution time is bounded by $T_D+\sum_{j\in J(F)}(T_{\mathrm{recognize},j}+T_{A_j,\mathrm{attempt}})$ and writable peak is the maximum of live-workspace sums on the \emph{same actual input execution}. The pointwise minima of the individual $T$ and $S$ maxima need not coincide. Resource claims across RAM, single-tape, two-tape and a fixed universal interpreter require explicit simulations and may change exponents. There is no inferential path from the static $n\le3b+12bq$ inequality to an unrestricted SAT lower bound.

\section{Computational audit, checks, and limitations}
The standalone reproducible Python file \texttt{arc233\_blockcut\_frontier.py} uses the already published ARC232 deterministic fixed-codimension subroutine, with a newly implemented Tarjan block finder, exact source-owner mapping, articulation-message reconstruction and final source verification. It compares 400 random well-formed mixed sources on one to eight variables with exhaustive SAT search: 350 recognized and correct, 50 correctly returned UNKNOWN for rank beyond the cap, zero false answers. Independently, NetworkX's separate block finder agreed on all 400 primal decompositions. The explicit dense SAT/UNSAT families at $q=4,8,16,32$ all passed, with respectively 9,17,33,65 local calls; at $q=32$ the Python peak \texttt{tracemalloc} measurement was 295244 bytes on SAT and 299836 on UNSAT. Those wall-clock/allocator measurements are \emph{not} native Turing-machine bounds. Inputs, deterministic seed 202610291600, full counters and normalized proxy data are in the associated raw JSON. Each experimental chunk completed in under 30 seconds. A separate PDF and source audit of Arvind--Guruswami verified the deterministic/randomized polarity of Theorems 2, 17 and W[1]-hardness of Theorem 19. No formal-proof-assistant kernel was run.

\section{Next specific missing lemma}
Can an explicit deterministic polynomial-time recognizer discover \emph{bounded-overlap} affine/2CNF separators of size $O(\log N)$, strictly extending primal articulation cuts, on a specified \emph{source-deletion-hereditary} grammar whose global block-cut graph is biconnected and has unbounded treewidth? It must charge failed separators, all interface assignments, codimension after restriction, physical message representation, joins, reconstruction and simultaneous peak workspace. A finite family showing failure of a proposed discovery rule would be a legitimate FALSIFIED/RETIRED result; no unrestricted SAT theorem is presumed.
