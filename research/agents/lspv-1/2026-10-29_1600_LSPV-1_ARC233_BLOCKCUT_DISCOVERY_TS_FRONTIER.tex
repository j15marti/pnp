\section{Propose, search, and constructive lemma}
The falsifiable target is an algorithmically discoverable source-deletion-hereditary class of mixed 2CNF and GF(2) equations with arbitrarily large global affine rank and primal treewidth. Mechanisms examined: native block-cut detection, unary message gluing, deletion heredity, and the invalid inference that width/rank imply all-algorithm hardness.
\begin{theorem}[Polynomial discovered block-cut affine composition]
Fix $e_0\ge0$. A typed source contains width-at-most-two CNF clauses and explicit GF(2) equations. Form its primal graph by adding a clique on each constraint scope. Compute all biconnected blocks $B$ and assign each constraint to exactly one containing block. If the rank $e_B$ of affine coefficient rows owned by every block is at most $e_0$, a single uniform deterministic algorithm decides SAT and UNSAT and reconstructs a source-verified SAT witness in polynomial bit time and writable space. The membership condition and the algorithmic class are preserved by deleting entire typed constraints. With $B(F)$ blocks, its charged time is
\[
T(F)\le D(N)+(2B(F)+1)N^{O(e_0+1)}+\operatorname{poly}(N),
\]
where $D$ includes all parsing, source ownership, graph discovery, rank checks, and physical bookkeeping. There is no general claim at $e_0=O(\log N)$.
\end{theorem}
\begin{proof}
A constraint scope is a clique, hence every non-unary constraint lies in one biconnected block; unary constraints are owned once by deterministic tie breaking. The block-cut incidence graph is a forest. Root each connected component at a block. Every child block joins its parent subtree on precisely one articulation variable, and sends the exact set of feasible values in $\{0,1\}$. Intersect such child messages on each shared articulation, obtaining either an impossible condition, no condition, or a unary 2CNF pin. For each possible parent-articulation value, at most two per nonroot block, use the known deterministic Arvind--Guruswami 2CNF-plus-affine-codimension-$e_B$ algorithm on the locally owned constraints and all child unary pins. Pins do not add affine coefficient rows. By induction on the block-cut forest, messages are exact: any global model passes each local test, and every collection of passing local witnesses glues on shared articulation values; no source constraint crosses its assigned owner. Join components, reconstruct and check the full original assignment. Thus the decision algorithm is sound and complete on both answer classes and uses at most $2B(F)+1$ local calls. Every graph, source ownership, row rank, failed call, witness and output operation is polynomial for fixed $e_0$. A subgraph obtained by source deletion cannot form a new biconnected edge block crossing original cut vertices, and its owned affine rows are subsets of those in one old block, so rank cannot increase. Singleton unary rows have rank at most one, inherited from an original containing block.
\end{proof}
\section{Explicit hostile family and simultaneous resources}
For $q\ge3$, put positive clauses $(a_i\vee a_j)$ for every anchor pair and add disjoint-private equations $a_i\oplus u_i\oplus v_i=0$ for each $i\in[q]$. The root graph block is $K_q$; each equation forms a triangular leaf attached at $a_i$. Global affine rank is $q$ because each row has a unique private variable; primal treewidth is at least $q-1$; all local block ranks are at most one. The source is SAT; pinning $u_1=v_1=u_2=v_2=0$ makes it UNSAT. The same deterministic controller handles both. Canonical indexed physical size $N=\Theta(q^2\log q)$, while $2q+1$ local calls suffice.
Native $t_M=\log_N\max\{2,T_M(F)\}$ and $s_M=\log_N\max\{2,S_M(F)\}$ denote one machine's same-run resources. Explicit stored-table space, RAM workspace and single/two/multitape cell counts are distinct. Any transport requires a charged simulation; no arbitrary-algorithm lower bound follows from the structural control.
\section{Static parameter frontier and adaptive envelope}
For the previously proved \emph{necessary static} exact-$(2,2)$ bound $n\le3b+12bq$, the permitted proxy exponents are $E_T=b+\max(0,n/(12b)-1/4)$ and $E_{S,\mathrm{table}}=b$. In the active region,
\[
E_T'=1-\frac{n}{12b^2},\quad E_T''=\frac{n}{6b^3}>0,\quad
b_*=\sqrt{n/12},\quad E_T(b_*)=\sqrt{n/3}-1/4.
\]
For $n=1200$, the rounded time proxy has minimum exponent 20 at $b=9,10,11$; only $b=9$ is nondominated among these. First log-proxy equality occurs at $b=400,q=0$, but it is dominated and neither measured nor guaranteed realizable. Streaming enumeration can use polynomial writable bits rather than materialize $2^b$ rows. Width-$w$ DP and hybrid affine-message composition provide \emph{upper} bounds under paid decomposition discovery, not universal runtime lower bounds. Adaptive controllers charge every attempted recognizer, failed search, reencoding and simultaneous live state; separate best-case time and space coordinates may not describe one actual run.
