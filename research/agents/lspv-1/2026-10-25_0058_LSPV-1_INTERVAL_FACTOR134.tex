\section{Source language and exact graph-factor reduction}
A source instance \(H\) has a finite set of named Boolean variables and
a list of source clauses \(C_j=(\ell_{j1},\ldots,\ell_{jd_j})\) with
independent integer bounds \(0\le L_j\le U_j\le d_j\).
Every literal is signed; within a clause, source variables are distinct.
A clause accepts assignment \(x\) precisely when
\[
 L_j\le\sum_{h=1}^{d_j}\mathbf 1[\ell_{jh}(x)=1]\le U_j.
\]
An occurrence means one literal in one source clause; source variables
may occur positively, negatively or not at all.
Let \(r_v\) count the occurrences of source variable \(v\).
The theorem's promise is \(r_v\le2\) for all \(v\).
The source language includes exact-one, exact-two, interval
pseudo-Boolean and ordinary CNF (\(L_j=1,U_j=d_j\)) clauses.

\begin{theorem}[Signed interval degree-two to feasible graph factor]
\label{thm:factor}
For every such degree-two source \(H\), a graph \(G_H\), allowing parallel
edges and containing \(O(|H|)\) vertices and edges, and integer degree
intervals \([g(z),f(z)]\) can be constructed in polynomial time such that
\[
 \boxed{\operatorname{SAT}(H)\iff
 \exists M\subseteq E(G_H)\ \forall z\
 g(z)\le\deg_M(z)\le f(z).}
\]
Every feasible factor can be transformed back to a coherent Boolean
source assignment in polynomial time, and conversely.
\end{theorem}
\begin{proof}
Create one clause vertex \(c_j\) with degree interval \([L_j,U_j]\).
For each source variable \(v\), independently inspect its at most two
literal occurrences.
If \(v\) occurs once in clause \(j\), create a private leaf \(p_v\)
with allowed degree \([0,1]\) and the edge \(c_jp_v\).
Selecting that edge means that its literal is true.
If \(v\) occurs twice, in distinct clauses \(i,j\), with equal signs,
insert one edge \(c_ic_j\). Selecting it makes \emph{both} literal
occurrences true; not selecting it makes both false. The variable's
Boolean value is uniquely reconstructed from the sign and selection.
If the signs are opposite, create a fresh \emph{choice vertex}
\(q_v\) with exact degree interval \([1,1]\), and two edges
\(q_vc_i,q_vc_j\). Exactly one must be selected, just as exactly one
of the opposite-signed literal occurrences is true for every assignment.
Unused variables may be assigned arbitrarily.
All source clauses have distinct names within each clause, so there is no
self-edge from two occurrences of a variable within one clause.
Parallel edges from distinct variables are retained.

Given a source assignment, choose the edges corresponding to true
literal occurrences; the opposite-sign choice vertex receives exactly one.
Each clause-vertex degree equals precisely its number of satisfied
literal occurrences and therefore obeys its demand interval.
Conversely, from any feasible edge subset, reconstruct a source variable:
on a singleton or equal-sign pair, the edge's selected status determines
the literal truth; on an opposite-sign pair, the unique selected incident
choice edge identifies the true occurrence. These decisions agree on both
occurrences of every source variable. The clause-vertex degrees exactly
recover the original truth counts. This gives both directions, including
witness reconstruction, with only linear-size graph construction.
\end{proof}

\begin{corollary}[Polynomial algorithm and high-occurrence parameter]
\label{cor:param}
Signed interval-cardinality SAT with every source occurrence degree at most
two is in deterministic polynomial time. For a general instance, define
the \emph{source} parameter
\(k(H)=|\{v:r_v\ge3\}|\), independently of runtime or SAT label.
Branching over precisely those \(k\) variables and adjusting the
remaining demand intervals yields one exact algorithm with
\[
 \boxed{T(H)=2^{k(H)}\operatorname{poly}(|H|),\qquad
 S(H)=\operatorname{poly}(|H|).}
\]
In particular \(k=O(\log|H|)\) is a polynomial-time subfamily.
\end{corollary}
\begin{proof}
Feasible undirected \((g,f)\)-factor testing is polynomial by classical
general-factor/matching methods (see the cited literature).
For the second claim, enumerate all assignments of the \(k\) designated
variables. For each assignment, remove those literal occurrences and
subtract their true-literal contributions from both sides of every
constraint, rejecting a branch when the residual interval is infeasible.
Every residual variable now has at most two occurrences; apply
Theorem~\ref{thm:factor}. Take the OR of the outcomes.
A complete assignment to the selected variables lies on one branch,
so both SAT and UNSAT correctness hold. Enumeration, demand updating,
factor construction, failed branches, witness reconstruction when requested,
and peak storage are included. \(\operatorname{poly}(|H|)\) here denotes a
deterministic \emph{bit-machine} polynomial upper bound, not an asserted
small FLMV exponent pair.
\end{proof}

\section{An additional exact parity certificate}
\begin{lemma}[Two-occurrence exact-cardinality parity]
\label{lem:parity}
Suppose every source variable occurs \emph{exactly twice}, all clauses
have exact demands \(L_j=U_j=b_j\), and \(h\) variables have opposite
literal signs across their occurrences. Then satisfiability requires
\[
 \boxed{\sum_j b_j\equiv h\pmod2.}
\]
\end{lemma}
\begin{proof}
Each same-sign variable contributes either zero or two true
literal occurrences. Each opposite-sign variable contributes exactly
one, irrespective of its Boolean value. Summing all clause truth counts
and reducing modulo two gives the condition.
\end{proof}
This gives an \(O(|H|)\)-input-scan certificate for some UNSAT cases but
no all-machine work lower bound. It is a special structural shortcut,
not a free semantic oracle.

For the four-clause, six-variable \(K_4\) incidence instance, each clause
lists the three edge variables incident to one graph vertex. All-positive
exact-one clauses are SAT (select a perfect matching); all-positive
exact-two are SAT (select a four-cycle). Flip the sign of \emph{one}
occurrence of the same source edge while keeping every unsigned clause,
threshold and identifier unchanged. The mixed-sign count becomes \(h=1\),
whereas the total exact demands are respectively \(4\) and \(8\).
The parity lemma makes both flipped sources UNSAT.
These are connected opposite-label pairs recognized by the polynomial
factor algorithm. They preclude promoting an incidence/sign complexity
proxy into unavoidable expensive time.

\section{Adaptive state and typed resource ledger}
We do \emph{not} assume an advance SAT/UNSAT label. A total uniform
meta-solver can inspect the ordinary source, try Horn/SCC/affine,
recognize this restricted grammar or select another decomposition,
and use an exact fallback when recognition fails.
The construction being tested has the following distinct stages.
\begin{description}
\item[Raw state.] Pay for reading encoded source bits, clause headers,
indices, signs, demands and variable identifiers. No structural degree
counts are assumed known for free.
\item[Recognition state.] Build source occurrence counts, test per-clause
variable uniqueness, check bounds and recognize the degree-two branch.
A wrong guess or failed recognizer incurs its actual cost.
\item[Representation state.] Construct the degree-interval multigraph,
including every private leaf and choice vertex. Keep edge/source-name
correspondence and graph memory live; do not silently merge parallel edges.
\item[Decision state.] Run a deterministic polynomial \((g,f)\)-factor
algorithm and, if needed, reconstruct a source assignment. One-bit UNSAT
decision does not require enumerating witnesses.
\item[High-degree state.] Branch on the independently computed \(k(H)\)
high-occurrence source variables. Charge \(2^k\) assignments, all
unsuccessful branches, graph rebuild/reuse, caches, ancestor storage and
the peak simultaneous live representation.
\item[Unrecognized state.] An exact all-input implementation must invoke
a fully charged fallback; it inherits the fallback's worst-case exponent
unless another theorem proves a genuine improvement.
\end{description}
For all tested mechanisms, distinguish primitive bit operations,
source/workspace reads and writes (including unchanged writes), actual
complete-state flips, peak writable bits, cumulative live bit-time and
program/representation length. The Python finite checker measures
assertion counts and exact Boolean/factor semantics, \emph{not} those
machine resources. The polynomial algorithm invoked is a known
graph-factor existence theorem on a constructed finite graph,
not an uncharged primitive within a claimed FLMV runtime.

\section{Why this cannot be an unrestricted P-versus-NP proof}
The factor reduction only applies to a restricted \emph{source}
language. If \(k(H)\) is linear in the input size, the generic
branching algorithm is exponential. Its upper bound gives no lower
bound for another algorithm. Converting a general 3SAT instance to
a cardinality source may increase occurrence degree, and any
transformation/compatibility costs must be charged.
A small graph-factor representation for this subfamily does not
demonstrate a compiler from every arbitrary SAT decider to a
simultaneously improved \((t,s)\) point. The FLMV model requires
same-machine time and writable-space guarantees on \emph{every}
ordinary input. \textbf{ARC-EDGE-90 remains OPEN.}
