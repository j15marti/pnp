\section{The inherited static lemma}
Let $F$ be connected, proper, strict signed exact-$(2,2)$-3CNF with $n$ variables, $m=4n/3$ source clauses, a fixed boundary $Y$ of size $b>0$, and $k$ disjoint nonempty private modules $Z_i$, with no original clause meeting private variables of two modules. Suppose a private syntactic hitting set $B_i\subseteq Z_i$, $|B_i|\le q$, and all clauses touch $Y\cup B_i$ for their module. The verified static lemma says
\begin{equation}\label{eq:lower}
k\le4b,\qquad n\le3(b+\sum_i|B_i|)\le3b+12bq,
\qquad b+q\ge\sqrt{n/3}-\tfrac14.
\end{equation}
Every private module must touch $Y$, and separate modules consume distinct boundary incidences, giving $k\le4b$. Also $H=Y\cup\bigcup_i B_i$ hits all $4n/3$ clauses and each variable covers at most four clauses. These two counts prove (\ref{eq:lower}). For $b=0$, connectivity forces $k=1$ and $q\ge n/3$. This result concerns a static architecture, not time or space.

\section{New matched-expansion construction}
Fix any integer $r\ge2$, put $b=3r$ and $k=b$. Use boundary variables $Y=\{y_0,\ldots,y_{b-1}\}$ and private variables $Z_j=\{p_{j,0},\ldots,p_{j,b-1}\}$ for $0\le j<b$. Indices on the second coordinate and on $y$ are interpreted modulo $b$. Define all original signed ternary clauses as follows:
\begin{align}
 C_j^Y&=(y_j\vee y_{j+1}\vee\neg p_{j,0}) &&(0\le j<b),\label{eq:ybridge}\\
 Q_h^Y&=(\neg y_{3h}\vee\neg y_{3h+1}\vee\neg y_{3h+2})&&(0\le h<r),\label{eq:yblock}\\
 C_{j,i}^P&=(p_{j,i}\vee p_{j,i+1}\vee\neg p_{j,i+2})&&(0\le j,i<b),\label{eq:pcycle}\\
 Q_{j,0}^P&=(\neg y_{j+2}\vee\neg p_{j,1}\vee\neg p_{j,2})&&(0\le j<b),\label{eq:pbridge}\\
 Q_{j,h}^P&=(\neg p_{j,3h}\vee\neg p_{j,3h+1}\vee\neg p_{j,3h+2})&&(0\le j<b,\ 1\le h<r).\label{eq:pblock}
\end{align}
Assign $C_j^Y$ and all private clauses indexed by $j$ to module $M_j$; assign the boundary-only $Q_h^Y$ to $M_0$. No clause mixes private variables of different modules. The construction is a literal swap: $\neg y_{j+2}$ from the original boundary cyclic clause $C_{j}^Y$ is exchanged for $\neg p_{j,0}$ from the original private block clause $Q_{j,0}^P$. Hence it preserves every signed occurrence count.

\begin{theorem}[Square-root exponent is sharp for static modular coverage]\label{thm:tight}
For every $r\ge2$, the formula $F_r$ defined by (\ref{eq:ybridge})--(\ref{eq:pblock}) is incidence-connected, proper, has unique signed three-literal clauses, and is strict signed exact-$(2,2)$ with
\[
n=9r^2+3r,\quad m=12r^2+4r=\frac{4n}{3},\quad b=k=3r.
\]
The fixed source-authenticated module decomposition above has per-module \emph{minimum} private ternary-clause-hitting number $q=r$. Consequently
\[
b+q=4r=\Theta(\sqrt{n}),\qquad k=b=\Theta(\sqrt n).
\]
In particular, no inequality $b+q=\Omega(n^\delta)$ with $\delta>1/2$ holds solely under the hypotheses of (\ref{eq:lower}). Nevertheless every $F_r$ is satisfiable by the explicit period-three assignment $y_i=p_{j,i}=1$ for $i\equiv0,1\pmod3$, with the remaining variables assigned zero.
\end{theorem}
\begin{proof}
The displayed clauses have three distinct variables because $b\ge6$ and the boundary and private names are disjoint. The four clause types use respectively two boundary/one private, three boundary, three private, and one boundary/two private names; within a module the different source scope/sign types are distinct, so signed clause uniqueness follows. Every boundary $y_t$ appears positively in $C_t^Y,C_{t-1}^Y$ and negatively in one $Q_h^Y$ and $Q_{t-2,0}^P$. Every private $p_{j,0}$ appears positively in $C_{j,0}^P,C_{j,b-1}^P$ and negatively in $C_{j,b-2}^P,C_j^Y$. For $i\ne0$, $p_{j,i}$ keeps the two positive cyclic occurrences, one negative cyclic occurrence and its unique negative private block occurrence, except $i=1,2$ whose negative block occurrence is in $Q_{j,0}^P$. Hence each variable has exactly two occurrences of each sign. The boundary variables form a connected cycle by the two boundary names in every $C_j^Y$. Each private cycle $C_{j,i}^P$ is connected, and $C_j^Y$ connects it to $Y$. Thus the complete incidence graph is connected.

There are $b$ boundary names and $b$ modules of $b$ private names each, yielding $n=b+b^2$. The listed clause counts are $b+r+b(b+r)=4r+12r^2$.

For module $j$, let $B_j=\{p_{j,3h}:0\le h<r\}$. This hits every private cyclic triple and every unchanged private block triple. The modified private block $Q_{j,0}^P$ and boundary cyclic bridge $C_j^Y$ both meet $Y$. The boundary-only clauses assigned to $M_0$ meet $Y$ as well. Hence $|B_j|=r$ suffices. Conversely, exactly $b+(r-1)=4r-1$ clauses of module $j$ contain \emph{only} private variables. Since each private variable occurs in at most four source clauses in total, any private set hitting all $4r-1$ private-only clauses contains at least $\lceil(4r-1)/4\rceil=r$ variables. Therefore the true per-module optimum is $r$.

For the periodic assignment, each pair of consecutive indices includes at least one of residues $0,1$ modulo three, so every cyclic clause (private or boundary) has a true positive literal. Each all-negative boundary block and every unchanged private block contains a residue-two variable set to zero. The mixed private block $Q_{j,0}^P$ has $\neg p_{j,2}$ true. Thus all clauses are satisfied. Finally $n=9r^2+3r$ and $b+q=4r$, giving sharp order $\Theta(\sqrt n)$.\end{proof}
