\section{Exact promise and state}
Fix $k\ge2$ and $Q=2^k$. Two modules share a boundary $B=(x_1,\dots,x_k)$ and otherwise have disjoint private variables. For each $a\in\{0,1\}^k$ a deterministic complete fan-in-two AND-gate encoding computes $e_a=[B=a]$, with full Boolean equivalences encoded in proper 3CNF. Add a padded binary guard $(\neg e_a\lor z_a)$, and a four-ternary-clause pin gadget fixing $z_a$ to source sign-bit $s_a$, respectively $t_a$. Width-two clauses $(l\lor m)$ are padded as $(l\lor m\lor u)\wedge(l\lor m\lor\neg u)$, with fresh $u$. All source-dependent choices are source-indexed pin signs. Each source has the same clause/variable count and explicit fixed-width length $N_k=\Theta(k^2 2^k)$.
\[
(\exists U)H_s(b,U)\iff s_{\operatorname{index}(b)}=1,\quad
(\exists V)H_t(b,V)\iff t_{\operatorname{index}(b)}=1.
\]
Thus
\[
\operatorname{SAT}(H_s\wedge H_t)\iff\bigvee_{a<Q}(s_a\land t_a),\qquad
\operatorname{UNSAT}(H_s\wedge H_t)\iff\bigwedge_{a<Q}(\neg s_a\lor\neg t_a).\tag{1}
\]

\begin{theorem}[Sharp adaptive membership-query certificate, restricted]
Let a finite, coherent transcript $\tau$ reveal some indexed pin bits $s_a$ and $t_a$. It forces SAT on \emph{every} completion of unqueried source bits if and only if there is an index $a$ at which it has observed both $s_a=t_a=1$. It forces UNSAT on every completion if and only if for \emph{every} $a$ it has observed at least one of $s_a=0$, $t_a=0$. Hence every exact deterministic adaptive membership-query policy makes at least $Q$ distinct informative pin-block queries on any NO input. There is a deterministic policy needing at most $2Q$ such queries and $O(k)$ scratch bits after paid grammar authentication.
\end{theorem}
\begin{proof}
Two observed ones at a common index certify a shared boundary assignment and jointly extendible private gate traces. If none exist, fill all unqueried bits with zero: the resulting completion has no overlap, so the transcript does not force SAT. One observed zero at every index proves (1) false. If some index has no observed zero, fill its unqueried pin bits with one, preserving the observed signs; the resulting completion has an overlapping boundary model, so the transcript does not force UNSAT. Distinct indices require distinct observed zero blocks on every negative transcript. A matching sequential algorithm queries $s_a$ at each $a$ and, only when it equals one, queries $t_a$; it accepts immediately if both equal one and otherwise rejects after examining all indices. Its counter/current-value scratch is $O(k)$ bits. Fully authenticating the proper 3CNF grammar and accessing indexed source characters require additional charged reads and head motions.
\end{proof}

\begin{theorem}[Original indexed ternary resolution cover at $k=3$]
Take eight indexed source slots per module. At slot $a$, store the proper source clause $D_a$, false exactly at boundary assignment $a$, when the corresponding source bit is zero; otherwise store $(p\lor u\lor v)$ where a four-clause ternary gadget forces $p=1$. Thus each source module has twelve proper three-distinct-variable clauses, and the conjunction has 24 clauses on 13 variables. If $s\wedge t=0$, selecting one original $D_a$ for every $a$ yields an eight-leaf, 15-node source-indexed resolution refutation. Otherwise every common permitted $a$ supplies a SAT witness, and the complete model count is $2^8\operatorname{popcount}(s\wedge t)$.
\end{theorem}
\begin{proof}
The four pin clauses force $p$ but leave four private variables unconstrained in each module. If $s_a=t_a=1$, the common boundary assignment $a$ satisfies both modules with $2^8$ private extensions. If disjoint, every $D_a$ appears in at least one source. Resolve each of four $x_3$-complementary pairs, obtaining four binary clauses; resolve the two $x_2$-complementary pairs to obtain $(x_1)$ and $(\neg x_1)$, then resolve to the empty clause. The eight initial parents are authenticated by their original source indices. Distinct source occurrences are not independent Boolean variables.
\end{proof}

\section{Matched SAT/UNSAT finite experiment}

Source-resolution discovery, proof verification, failed candidate searches, complete external enumeration, the host interpreter and all simultaneously live raw data are not included in those comparator counters. This is \textbf{not} a native FLMV machine timing or space theorem, and it does not show a universal improvement.

\section{Why this does not construct ARC}
The source grammar is syntactically recognizable. After full paid authentication, comparing indexed membership pin blocks gives $O(N_k\operatorname{polylog}N_k)$ time and $O(\log N_k)$ scratch-space decisions for both labels. On NO, each zero pin is a valid original-source exclusion; on YES, two positive pins determine a common boundary witness. No $2^k$-bit reusable message is needed: source rereads, read-head movements and on-demand queries are charged. This is the precise escape from the predecessor no-reread INDEX storage bound. The constant-size physical SAT/UNSAT guest children in the experiment are selected \emph{after} the original label is already known and do not give a nontrivial arbitrary-$A$ contraction.

Nonmember sources still need a total correct fallback. A compulsory parent-scale $A(F)$ call fails the proposed bound under a correctness-preserving DELAY wrapper with unknown exponent. The guest's input-index head extent, far-blank reads, child output, live ancestors, restarts and full machine space cannot be elided. The arithmetic FLMV fixed point $(6/5,1/2)$ and strict comparison with $c=241/200$, $d=11642479/23232400$ are conditional only. The one load-bearing arrow remains a uniform, same-source both-label, hereditary, all-input $A\mapsto\Phi(A)$ with truly power-short ordinary children or certified terminals and a complete resource ledger.
