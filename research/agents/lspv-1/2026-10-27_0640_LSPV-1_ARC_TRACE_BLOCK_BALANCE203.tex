\section{The declared guest, source and proof mediums}
Fix a \emph{single} uniform deterministic total correct \emph{ordinary-SAT} guest $A$, a standard finite-alphabet machine with one two-way sequential read-only input head and $k\ge1$ fixed sequential work tapes, one head per tape. On physical source $F$ of length $N$, its unique computation takes $R\ge1$ transitions; at step $t<R$, all guest source/work head coordinates are in $[-R,N+R]$ and each work coordinate is in $[-R,R]$. The compound \emph{immutable} input $F\#\tau$ supplies a canonical, fixed-width full alleged rejecting history $\tau$: state, before/after work symbols, work and source positions, transition, head moves, the source symbol seen, and final output. Each record has $O(\log M)$ bits for $M=N+R+2$, so
\[
 P=|\tau|=O(R\log M),\qquad X=|F\#\tau|=O(N+R\log M).
\]
The verifier has an \emph{indexed read-only} view of this entire compound input and independent charged \emph{indexed writable} scratch. This is the pair language
\[
 L_{A,\mathrm{rejtrace}}=\{(F,\tau): \tau\text{ is exactly the complete rejecting run of }A(F)\},
\]
not ordinary SAT on input $F$ alone. The public capacity policy is charged and efficiently evaluable from the length fields. The $R$ field is checked against the actual record count and physical compound length; a malicious superlong header is rejected rather than buying free memory or a clock. All private symbol changes, index bits, block clears, rejected scans and final output are charged.

\begin{theorem}[Finite-alphabet bucketed last-write authentication]\label{th:block}
For every fixed guest $A$ as above and every public policy $1\le B(R,N)\le R$ whose capacity is computable in $\operatorname{polylog}(N+R+2)$ bit-time and $O(\log(N+R+2))$ work bits, one fixed uniform deterministic \emph{indexed read-only pair-input} random-access machine $V_{A,B}$ decides $L_{A,\mathrm{rejtrace}}$ with
\begin{align}
 T_{A,B}(N,R)&=O\left((N+R+R^2/B)\log^{O(1)}(N+R+2)\right),\label{eq:T}\\
 S_{A,B}(N,R)&=O\left(B+\log(N+R+2)\right)\text{ bits}.\label{eq:S}
\end{align}
The hidden constants may depend on the fixed guest and tape alphabets, never on $N,R,B$. These are upper constructions, not optimal lower bounds. Every accepted source/trace pair is a true rejecting guest run; if $A$ is total and correct then
\[
 \forall F:\quad F\in\UNSAT\Longleftrightarrow
 \exists\tau\,V_{A,B}(F,\tau)=1,\qquad
 F\in\SAT\Longrightarrow\forall\tau\,V_{A,B}(F,\tau)=0 .
\]
Proof search and certificate acquisition are not included in this existential statement and must be charged in any deterministic solver.
\end{theorem}
\begin{proof}
First scan the encoded source and the entire presented trace, verifying length/record framing, initial control state, initial head positions, source symbol at each \emph{actual} indexed position including out-of-range blanks, each transition of the fixed finite guest program, head move constraints, consecutive control states and head positions, and final rejecting halt. Reject a malformed source or any transition with an impossible coordinate. This costs $O((N+R)\operatorname{polylog}M)$ time and $O(\log M)$ index/work bits. In this pass, the claimed \emph{before} work symbols are provisional: finite transition legality alone does not authenticate their last writers.

For each of the $k$ work tapes separately, partition the fixed entire possible visited coordinate interval $[-R,R]$ into consecutive \emph{physical-address} buckets of at most $B$ cells. For a selected bucket $I=[\ell,\ell+B)$ initialize at most $B$ cache slots with the true initial blank symbol. Make one full chronological indexed scan through the same immutable $\tau$. For every event whose work tape equals the selected tape and whose guest address $a\in I$, compare its claimed before/read work symbol against the cache slot $a-\ell$; reject on disagreement, then overwrite that slot with the claimed after/write symbol. Ignore only the \emph{work-check} for events outside the current bucket: their finite guest transition and original source reads have already been authenticated. A work head writes only its current actual location and each pair $(\mathrm{tape},a)$ belongs to exactly one bucket, so induction on chronological events proves that each accepted read equals the symbol left by the latest actual prior write, or the initial blank if none. All possible work addresses are covered.

There are at most $k\lceil(2R+1)/B\rceil=O_k(R/B)$ bucket passes. Every pass scans $R$ records of $O(\log M)$ bits and uses $O(B)$ finite-alphabet cell slots, one $O(\log M)$ current record and bucket/index counters. Block reset costs at most $O(B)$ writes per bucket; across all buckets this is $O(R)$. The true proof is never modified or silently duplicated. This proves (\ref{eq:T})--(\ref{eq:S}).

Completeness takes the unique actual rejecting run when $F$ is UNSAT. For soundness, the verified source reads, authenticated initial work blanks, checked transitions and before/after equality force the entire claimed trace to coincide, event by event, with that unique actual deterministic run. SAT inputs therefore have no accepted rejecting history. The verifier never invokes SAT on the full parent as a semantic oracle; it only authenticates the fixed guest's finite transitions. The same proof works for any fixed $k$ and any finite work alphabet.
\end{proof}

\begin{corollary}[Explicit parameter continuum, not a diagonal contraction]\label{cor:K}
For any fixed rational $0\le\theta\le1$, choose the \emph{public computable} capacity $B=\max(1,\lceil R^\theta\rceil)$, capped at $R$. Then the single corresponding pair-input verifier has
\[
 (T,S)=
 \left(\widetilde O(N+R^{2-\theta}),
       O(R^\theta+\log(N+R+2))\right).
\tag{3}
\]
If a hypothetical $P=NP$ guest $A$ has unknown arbitrary worst-case time exponent $K\ge1$, with rejecting histories $R\le N^{K+o(1)}$, the \emph{upper} exponents measured against the original source $N$ are
\[
 t_{\mathrm{pair}}\le K(2-\theta)\quad\text{and}\quad
 s_{\mathrm{pair}}\le K\theta
\]
up to the displayed log terms. For $\theta=0$ the source-indexed pair checker is quadratic in the guest steps with logarithmic space; for $\theta=1$ it is linear in guest steps with linear work. Intermediate $\theta$ are available but $K(2-\theta)\ge K$ always. No arbitrary-$K$ strict time improvement or matched low-space ordinary-SAT decider follows.
\end{corollary}
\begin{proof}
Substitute $B=R^\theta$ into (\ref{eq:T})--(\ref{eq:S}). Rational powers and required integer rounding are computable from the charged binary $R$ field using $O(\log R)$-bit counters and polynomially many bit operations in $\log R$. If $R$ is small, the additive $N$ source term dominates. The proof medium still contains $\Theta(R\log(N+R))$ bits that are not generated for free. DELAY wrappers of $A$ produce proportionally longer faithful traces and preserve the limitation. We neither conflate the pair-input length $X$ with $N$ nor confuse these favorable \emph{pair-verification} upper bounds with a SAT achievable-resource point.
\end{proof}

\begin{lemma}[Proof-medium and source-authentication firewall]\label{lem:medium}
A literal ordinary one-way nondeterministic implementation that guesses the full $P$-bit trace and subsequently executes these $O(R/B)$ backward or repeated indexed proof accesses must first retain a rereadable copy of its guessed trace. For \emph{that implementation}, both the $P$ bit writes and $\Omega(P)$ visited work space are charged. A separate two-way indexed proof tape is an additional access model, not the one-way choice tape of van Melkebeek's ordinary $\mathsf{coNTIME}$ premise. This does not prove that every other possible UNSAT certificate grammar needs $\Omega(P)$ space.
\end{lemma}
\begin{proof}
The declared bucket routine intentionally revisits arbitrary previous trace positions in multiple chronological passes. Ordinary one-way nondeterministic choice bits cannot be revisited; a literal replay must store them on writable memory. A $P$-bit faithful trace contains $P$ potentially separate proof positions, so writing this concrete full-copy implementation reaches at least $P$ distinct cells. This is an \emph{implementation accounting} lemma only, not an information lower bound against all proof systems or all nondeterministic algorithms.
\end{proof}

\noindent\textbf{Hostile controls.}
A forged claimed before-symbol and compensating after-symbol may pass the \emph{local transition equation}, but fails bucket last-write replay. Altering one actual source symbol invalidates first-pass source authentication. Work-tape aliases must be keyed by the exact tape ID and address; bucket-local offsets cannot stand for distinct global cells. The original $W_1$ signed exact-$(2,2)$ source and the clause-monotone exact-$(2,2)$ class are separate from the ordinary-SAT guest's unconstrained raw input; no in-class properization is asserted. A connected minimally UNSAT $U_k$ can admit a tiny authenticated Resolution proof despite many sensitive source signs (ARC196). Horn, 2-SAT, affine/Gaussian and bounded-treewidth controls may have much cheaper direct decisions than the present trace replay. HEC delayed-audit and VLSI bandwidth analogies supply only a \emph{restricted} correspondence unless a static all-SAT compiler and exact medium transfer are proved. No source-only cheap all-input splitter, oracle, uncharged child or read-only proof store is postulated.

\noindent\textbf{Relativization, algebrization and Natural Proofs.}
The bucket algorithm is an ordinary finite trace-consistency checker and relativizes wherever source-symbol queries are still authenticated; it cannot separate $P$ from $NP$. No algebraic-oracle extension, large constructive circuit property, pseudorandomness assumption or universal selector compressor is established. In particular, the one-bit function computed by a sound rejecting \emph{witness verifier} is not the all-input Boolean circuit of the decision machine, and first-read proof enumeration still pays its physical observed union with a public effective cap.
