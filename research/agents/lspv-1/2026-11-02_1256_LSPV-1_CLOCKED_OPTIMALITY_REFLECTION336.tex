\section{Fixed quantifiers and proof metric}
Fix a single sound complete polynomial-proof-time-verifiable CNF refutation calculus R, with binary encoded acyclic proof DAGs, unit-cost derived nodes and each node occupying at least one encoded bit. For every UNSAT F define W_R(F) as the minimum derived DAG node count and L_R(F) as the minimum proof bit length. Let \overline W_R(N) be the maximum W_R over valid UNSAT inputs of encoded bit length at most N. Thus W_R(F)\le L_R(F), a logical upper comparison, not a machine-time lower bound. The optimizer is given the best valid proof for free. A size-optimal Cook--Reckhow R simulates every polynomial-time verifiable complete UNSAT proof system Q in proof length: L_R(F)\le q_Q(L_Q(F)+|F|) for a polynomial q_Q, without requiring a polynomial-time translator. Existence of an optimal propositional proof system is OPEN [1,2,3].
\begin{lemma}[Unary-clock verifier]\label{clock}
For each fixed uniform total correct SAT decider A, regardless of its runtime, there is a polynomial-time-verifiable complete sound UNSAT proof system Q_A with L_{Q_A}(F)=O_A(|F|+T_A(F)+1) for all UNSAT F.
\end{lemma}
\begin{proof}
Let F_0=(x_1)\land(\neg x_1) be a fixed known contradiction. On certificate y, parse a self-delimiting pair (\langle F\rangle,1^t). If parsing fails or F is malformed, output F_0. Otherwise simulate fixed A on F for t native steps, output F iff A returns UNSAT within the bound, and F_0 otherwise. The resulting total proof-system function is polynomial-time in |y| because the clock t is UNARY and bounded universal simulation is polynomial in t. It only outputs unsatisfiable formulas by external correctness of A. Every UNSAT F has certificate (\langle F\rangle,1^{T_A(F)}) of length O(|F|+T_A(F)+1). No semantic SAT oracle or effective test of correctness of arbitrary A was introduced.
\end{proof}
\begin{theorem}[Conditional bridge: size-optimal R implies B1]\label{bridge}
If the same fixed R is size-optimal, then
\[\boxed{\forall A\in{\rm DecSAT}\;\exists p_A\ {\rm polynomial}\;\forall F\in{\rm UNSAT}:\ W_R(F)\le p_A(|F|+T_A(F)).}\]
Thus B1, B2 and B3 all hold. If \overline W_R is additionally superpolynomial, then NP\ne coNP and hence P\ne NP.
\end{theorem}
\begin{proof}
For fixed A, Lemma~\ref{clock} gives a valid Cook--Reckhow system Q_A. Size-optimality and node/bit domination give W_R(F)\le L_R(F)\le q_{Q_A}(L_{Q_A}(F)+|F|)\le p_A(|F|+T_A(F)). Taking worst-case maxima yields B2; taking a hypothetical polynomial-time A yields B3. If NP=coNP, Cook--Reckhow's theorem gives some polynomially bounded UNSAT proof system Q; optimal R simulates it, making \overline W_R polynomial, contrary to the assumed superpolynomial lower bound. Both optimality and hardness remain separate OPEN obligations.
\end{proof}
\section{Independent correctness-index firewall}
\begin{theorem}[No effective enumeration of all correct SAT deciders]\label{index}
The index set C of deterministic total all-input correct SAT deciders is not recursively enumerable. If SAT belongs to P, correctness is still not recursively enumerable within one computably indexed syntactically polynomial-time family of total programs.
\end{theorem}
\begin{proof}
Fix any total correct SAT decider B. Choose a polynomial-time recognizable infinite family S of valid SAT encodings with unbounded lengths, for instance k copies of the unit clause (x_1). Given arbitrary program e, compile total M_e(w): simulate e on blank input for |w| steps; if it halts within that bound and w is in S, output the false label UNSAT; otherwise run B(w). If e never halts, M_e=B and is correct. If e halts at step t, choose a SAT sentinel s in S with |s|\ge t, and M_e incorrectly rejects s. Thus nonhalting many-one reduces to C, so C is not r.e. Conditionally on SAT\in P choose polynomial-time B. The bounded simulation and sentinel test are polynomial in |w| for fixed e, proving the same non-enumerability inside a syntactically clocked polynomial-time machine family.
\end{proof}
\noindent This no-go rules out a fixed sound recursively enumerable correctness-certificate scheme complete for ALL correct decider indices. It does not refute B1--B3: the optimality argument considers each semantically sound Q_A separately and never tests which A are correct. It complements project REFEREE294's narrower fixed-theory Godelian example.
