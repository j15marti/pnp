\begin{abstract}
A paid selector decides source-authenticated mixtures of XOR3 quartets and
a logarithmic number of non-entailed unary/binary clauses, returns independently
checkable SAT witnesses or exhaustive affine refutations, and physically contracts
each recognized source to one fixed terminal child.  The unrestricted all-SAT
contraction theorem and P versus NP remain \textbf{OPEN}.
This note reproduces the core proof and links a separately retained 7-page
fuller report, reproducible Python code and raw data. It neither asserts
polynomial mixed-CSP solving nor proof-assistant verification.
\end{abstract}
\section{PROPOSE}
The missing arrow is an unconditional uniform all-input successor preserving
both SAT and UNSAT and shrinking one complete encoded child by a fixed
power, or decreasing a polynomial-\emph{value} rank with polynomially bounded
intermediate encodings.  We test four falsifiable mechanisms.
M1: recognize complete source-authenticated XOR3 quartets (restricted proved).
M2: delete affine-entailed exceptional clauses with a paid certificate
(restricted proved). M3: branch over a logarithmic number of surviving
constraints, with every UNSAT leaf authenticated (restricted proved).
M4: derive a general SAT compressor from this partial selector (OPEN).

\section{Exact source grammar}
Let $N$ be the physical byte length of canonical 3CNF source $F$.
Every width-three clause is partitioned into four distinct signed
clauses on one three-variable scope, precisely the four assignments
falsifying one equation $x\oplus y\oplus z=b$. This is verified with
complete clause IDs and byte offsets. All remaining clauses have arity
one or two. Let $E$ be the recovered GF(2) system and
$C_1,\ldots,C_c$ the remaining clauses.
For each exceptional $C_j$, run Gaussian elimination on
\[
 E\wedge\bigwedge_{\ell\in C_j}\neg\ell.
\]
Delete $C_j$ only if this is inconsistent, accompanied by a verifiable
sum of source-indexed original equations and the temporary unit rows
equaling $0=1$. Let $k$ be the count of surviving exceptional clauses,
and $u\le k$ their binary count.
\begin{theorem}[Paid source-authenticated partial decider]
There is a single fixed deterministic total polynomial-time
algorithm returning one of
$\{\mathrm{YES},\mathrm{NO},\mathrm{UNKNOWN},\mathrm{INVALID}\}$
on all encoded sources such that, if every ternary clause belongs
to a complete authenticated XOR3 quartet, all remaining clauses
are unary/binary, and
\[
 k\le\lfloor\log_2 N\rfloor,
\]
the algorithm returns YES if and only if $F$ is satisfiable.
A YES result includes a complete source-verified assignment.
A NO result includes a complete source-verified proof in an
explicit XOR-plus-disjunction-branch grammar. All discovery,
failed branches, source access, proof verification and physical output
are charged and bounded polynomially in $N$ for one and the same
algorithm on both answer classes.
\end{theorem}
\begin{proof}
The quartet truth tables show that recovery preserves the complete
assignment relation. Removal of $C_j$ is logically equivalent to
$E\models C_j$ and is certified by the inconsistent affine
extension above. Every assignment satisfying all retained clauses
selects at least one true literal from each. Conversely, any
assignment satisfying the affine system and the chosen unit literals
satisfies all retained clauses and, by affine entailment, all deleted
ones. Enumerating the selected literal for each of the $u$ binary
clauses, with unary literals forced, covers all satisfying assignments.
This generates $2^u\le2^k\le N$ affine leaves.
If one is consistent, recheck its witness on the complete original
source and return YES. If every leaf is inconsistent, verify each
$0=1$ XOR combination against its authenticated original equations
and its chosen unit rows, and return NO with all leaf proofs.
All operations have polynomial bit complexity on $O(N)$ rows and
variables, including complete provenance vectors. There are at most
$c+1+2^u\le 2N+1$ Gaussian calls; all failing calls and written
certificates are counted. Otherwise return UNKNOWN without
concluding satisfiability. No answer-class hint, SAT oracle or
uncounted source access is used.
\end{proof}
\begin{corollary}[Restricted physical one-child contraction]
Enlarge the recognized grammar by two fixed terminal encodings:
\texttt{p cnf 3 1; 1 2 3 0} and
\texttt{p cnf 1 2; 1 0; -1 0}, each with explicit newlines.
On every recognized source of $N\ge512$ bytes the algorithm
physically emits one decision-equivalent child of 18 or 19 bytes,
hence
\[
 |F'|\le19\le N^{3/4}.
\]
A second call on that exact base terminates.
For smaller recognized sources, the same paid decider terminates
directly. General SAT contraction is \emph{not} implied.
\end{corollary}

\section{Machine ledgers, corpus reconciliation and open DAG}
For a native indexed bit RAM, all Gaussian reductions, provenance,
failed tests, proof output and peak storage are polynomial.
One read-only-input fixed multitape TM can simulate the explicitly
stored polynomial-size structures with polynomial scan overhead.
A single shared read/write tape includes the $N$ input
symbols in footprint and adds a separately charged polynomial
transport overhead. The fixed UTM pays interpreter and program
simulation costs; it inherits only polynomial bounds, not borrowed
RAM exponents. No tape-head crossing theorem is transferred to
RAM, and no worst-case maxima from distinct SAT and UNSAT
inputs are combined as a same-run lower bound.
