## Exact scoped theorem (PROVED/RESTRICTED)

Fix original CNF F(X), with m signed source clauses and original variables X. Define a distinct, fixed, sound extended proof calculus R_extPC1^2. It allows *only* Pang's syntactic Res(PC_1/F_2) rules (clauses of affine equations, syntactic weakening, contraction, false-constant deletion, two-premise linear combination and multiplication when every displayed polynomial remains degree <=1), plus paid, acyclic, globally fresh two-input Boolean gate definitions z_j=f_j(u_j,v_j) with all defining CNF facets. Every auxiliary occurring in any line belongs to an earlier paid definition; each original assignment extends uniquely. Charge at least one distinct node per gate definition, all proof inferences and stated reference costs; no semantic oracle, branch/discharge inference, LOCAL-CONVERT or arbitrary factor rule is added. Let q be paid inference/definition node count, so g<=q for g declared gates. Define nu(pi) as the number of gates among these g whose bivariate algebraic-normal form has a nonzero uv coefficient (syntactic nonaffinity), even if repeated inputs or unreachable gates make the semantic function simpler.

**Theorem:** For any original-source-authenticated shared-DAG refutation pi in R_extPC1^2, there exists a source-only *syntactic* Res(PC_1/F_2) refutation pi' of exactly F, with

$$
S_{\mathrm{Res}(\mathrm{PC}_1/\mathbb F_2)}(F)
 \le C(m+g+q+1)(\nu(\pi)+3)^3\,2^{\nu(\pi)}.
$$

C is absolute for the fixed binary-Boolean-gate basis and target grammar. Sharing is retained inside each leaf; shared originals are not fabricated or counted as derived axioms.

**Proof.** Write each Boolean gate uniquely as f(u,v)=c+a u+b v+d uv over GF(2). Process the paid gate DAG in topological order. Where d=0, substitute its affine form. Where d=1, the already processed two gate inputs are affine in original X under the current leaf context; branch on the *first input's affine form* L(X)=0 and L(X)=1. On either branch the output is affine in the second input. Keep each branch guard as the OR of its negated affine equations. All original assignments follow exactly one formal leaf (infeasible leaves remain logically harmless). This reuses /484's known stratification and gives <=2^nu leaves.

For each leaf l and EVERY original proof line D, write the source-only line G_l OR sigma_l(D), where sigma_l substitutes affine functions of original X for all auxiliaries. An original F-source clause maps to its unchanged signed source clause with guard G_l and follows by paid weakening; no extra original axiom is introduced. A complete defining facet of a conservative gate maps to a clause that is tautological *under that leaf's guard*, so its **guarded** projection is a globally tautological affine-equation clause. Derive it from Pang's 0=0 axiom by the polynomially syntactically simulable affine semantic weakening of Itsykson–Sokolov Proposition 2.6, using O((nu+3)^2) native nodes for a source facet of constant width. The same treatment applies to Boolean axioms for auxiliary variables. Original Boolean axioms remain native axioms.

Every original allowed syntactic inference commutes with affine substitution: weakening and contraction are direct, false-constant deletion stays valid, two-premise linear combination is preserved, and multiplication preserves its degree-<=1 side condition because affine substitution does not increase degrees. Prefixing both premises with G_l gives the same inference with duplicated guards; pay at most O(nu+1) contractions. No hypothetical semantic entailment inference is used for an arbitrary proof step. At the original empty refutation line the leaf image is G_l. At each internal guard-tree node, the child conclusions D OR (L=0) and D OR (L=1) yield D by Pang's binary linear combination, paid false-constant deletion and contraction. Every AND-obligation branch is discharged and no branch-local lemma leaks. This uses O(2^nu) joins. Summing initial/step/guard costs gives the stated O((m+g+q+1)(nu+3)^3 2^nu) **node** upper bound. This is a source-preserving compiler, but ONLY for R_extPC1^2. Its target clauses encode the same original F, not a changed Tseitin extension or an equisatisfiable surrogate. QED.

## Hard 3-CNF control and quantified consequence

Pang's *preprint* Theorem 7.2(a) (24 Oct 2026) applies to independently chosen proper signed 3-CNF clauses F_n sampled from the 8*binom(n,3) possibilities, with 8n draws allowing repeats. Original n variables, m=8n clauses, ordinary binary source length N=Theta(n log n). For p=2,r=1 it gives exp(kappa n) source-only syntactic Res(PC_1/F_2) size with probability 1-o(1). Therefore, CONDITIONAL on this cited theorem, every R_extPC1^2 refutation of such a hard F_n satisfies

$$
\log(q+8n+1)+\nu\ln 2+3\log(\nu+3)\ge\kappa n-O(1).
$$

Hence q=n^{O(1)} forces nu=Omega(n), and nu=o(n) forces q=exp(Omega(n)). This allows polynomial-size proofs with linear **paid nonlinear gate count**, so it proves neither unrestricted mixed-proof hardness nor all-machine SAT hardness. Unlike the old /503 *original-variable-cone* b, nu can remain 1 when one AND gate's inputs are dense global parity forms. The transfer does NOT cover historical R_mix341 AND3/LOCAL-CONVERT/branching rules or provide B3.
