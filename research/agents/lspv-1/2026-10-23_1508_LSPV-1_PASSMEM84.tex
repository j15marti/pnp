\section{Question, proposed mechanisms, and corpus}
This run investigates a lower bound which is \emph{parameterized}, both by independent source information $k$ and by permitted complete source passes $p$, and which covers all state-adaptive computations \emph{within the declared source-access model}. It does not presume a fixed normalization, backdoor, or algebraic representation.

Three proposals were made before source/literature review: (M1) embed equality in a canonical proper-3CNF SAT bit and obtain $s=\Omega(k/p)$ live-streaming-space regardless of adaptive internal computation; (M2) build a complete-grammar-tested multipass batch algorithm nearly matching the bound; (M3) try to transfer this memory bound to unrestricted random-access SAT time, and search for a bypass.

\section{Canonical proper-3CNF equality encoding}
For $k\ge1$, independent input data $u,v\in\{0,1\}^k$, and private Boolean source variables $(x_i,a_i,b_i,c_i,d_i)$, let
\[
\lambda_t(x)=\begin{cases}x&t=1\\ \neg x&t=0,\end{cases}
\quad
Q(\ell;a,b)=\bigwedge_{\epsilon,\delta\in\{+1,-1\}}(\ell\vee a^\epsilon\vee b^\delta).
\]
Define the clause-ordered formula
\[
E_k(u,v)=\left(\bigwedge_{i=1}^k Q(\lambda_{u_i}(x_i);a_i,b_i)\right)
\wedge
\left(\bigwedge_{i=1}^k Q(\lambda_{v_i}(x_i);c_i,d_i)\right).
\tag{1}
\]
\begin{lemma}[PROVED/EXACT, exact source relation]
Every formula is proper unique exactly-three-literal CNF with $n=5k$ variables and $m=8k$ clauses. Moreover,
\[
E_k(u,v)\equiv\bigwedge_i(\lambda_{u_i}(x_i)\wedge\lambda_{v_i}(x_i)),
\quad
E_k(u,v)\in\mathsf{SAT}\iff u=v.
\tag{2}
\]
On a SAT source, exactly $2^{4k}$ original-variable assignments satisfy the formula; on UNSAT sources, zero do.
\end{lemma}
\begin{proof}
When $\ell$ is true, all four clauses of $Q$ are true. When $\ell$ is false, the four binary clauses exclude all possible pairs $(a,b)$, so $Q\equiv\ell$. Thus equal signs pin every $x_i$ and leave four auxiliary variables per $i$ free. Opposite signs for any $i$ contradict each other. Each clause's three variable identifiers are distinct; private auxiliaries also make all clause records unique.
\end{proof}
All $u$ blocks precede all $v$ blocks. Under the fixed-width four-record-words-per-clause format,
\[
w=\lceil\log_2(64(13k+1))\rceil,\quad W=32k+2,\quad
N=Ww=\Theta(k\log(k+2)).
\tag{3}
\]
Only the $k$ signs in the first half depend on Alice's string; only the $k$ signs in the second depend on Bob's. Public identifiers, clause lengths and headers are fixed by $k$. This source is \emph{not} signed exact-$(2,2)$ since each $x_i$ has eight signed occurrences. Strict exact-$(2,2)$ controls were tested separately, never conflated with the source family.

For a shared-named-input NOT1/OR2/AND2 formula evaluation circuit, gates $G=n+3m-1=29k-1$, directed gate-input incidences $J=n+6m-2=53k-2$, functional gate-trace CNF source-plus-gate variables $n+G=34k-1$, and gate-definition-plus-TRUE-output clauses $2n+9m-2=82k-2$. The internal gate values are uniquely determined by the $5k$ original source variables. These counts concern formula evaluation, not a SAT-solving circuit lower bound.

\section{The exact parameterized lower bound}
A uniform deterministic exact decider may use propagation, SCC, Horn or affine rules, learning, caches, branching, recomputation, DPLL, restarts, and any symbolic representation or state-dependent switching. However, the \emph{declared} channel is a sequential, read-only source-word stream. A backward jump is legal only by completing and rewinding the stream for the next left-to-right pass. There is no free random seek, second persistent storage channel, input-dependent advice or precomputed digest. The complete transferable control/configuration, including learned state, stores at most $s$ bits at each half-stream crossing. There are at most $p$ passes. Fixed headers and half boundaries are public, and early halting may be padded by a halted configuration included in $s$.

\begin{theorem}[PROVED/EXACT, all adaptive deterministic streaming policies]\label{th:pass}
Every exact deterministic $p$-pass decider under this source-access model that handles every canonical $E_k(u,v)$ satisfies
\[
\boxed{(2p-1)s\ge k.}
\tag{4}
\]
The $2^k$ satisfying diagonal sources already force the requisite accepting-transcript diversity. This is $s=\Omega(k/p)=\Omega(N/(p\log N))$, not a time-only bound on random-access SAT.
\end{theorem}
\begin{proof}
Alice knows $u$ and simulates every source word in the first half; Bob knows $v$ and simulates every word of the second. After each Alice half, the entire live state is sent to Bob. After each Bob half, it is sent back unless this is the last pass. An arbitrary adaptive policy thereby yields an exact deterministic two-party equality protocol with $p+(p-1)=2p-1$ state messages of at most $s$ bits. The $2^k$ pairs $(u,u)$ must all be accepted. Each accepting protocol transcript defines a rectangle. If a rectangle contained both $(u,u)$ and $(u',u')$ for $u\ne u'$, it would contain the rejected cross pair $(u,u')$, a contradiction. Consequently the accepting transcripts number at least $2^k$ while the padded transmitted bitstrings number at most $2^{(2p-1)s}$. Taking logarithms proves (4). Every internal computation and state-dependent method switch is simulated exactly, because its persistent effects must cross halves in the charged state.
\end{proof}
\paragraph{Sequential time--space corollary.}
Let $T_{\max}$ be maximal read/advance operations over this family, $s_{\max}$ maximal live bits and $W=32k+2$ the stream words. Every additional pass beyond the first requires a full $W$-word advance, giving $p\le T_{\max}/W+1$ for the algorithm's actual worst-case pass count. Hence
\[
\boxed{s_{\max}\left(2T_{\max}/W+1\right)\ge k.}
\tag{5}
\]
The inequality is about joint worst-case parameters in the \emph{streaming} model and remains well below an unrestricted superpolynomial result.

\section{Matching adaptive algorithm, access escape and controls}
After paying to validate all source quartet identifiers, signs and grammar, a policy with payload budget $B$ records up to $B$ signs of $u$ during a pass, compares those positions with the corresponding later $v$ signs, and replays the source for the next batch if necessary. A verified mismatch returns UNSAT; all checked positions return the one-bit SAT answer. If an explicit witness is requested, an additional charged full source pass reconstructs $x_i=u_i$ with all auxiliary variables false, requiring $W=32k+2$ more source-word reads, $O(k)$ write-only output and verification, and $O(\log k)$ live reconstruction bits. Every pass rereads and validates all source records. The count is
\[
p=\lceil k/B\rceil,\qquad s\le B+O(\log k),\qquad
T_{\rm read}\le (32k+2)\lceil k/B\rceil.
\tag{6}
\]
A full-language exact total hybrid invokes standard complete DPLL after a charged failed template recognition; that fallback may use more space and exponentially many steps. Recognition cannot be credited for free, nor can a missing sign vector be presumed cached.

\paragraph{FALSIFIED/RETIRED unrestricted transport.}
Random-access machines can validate the same public template and compare $u_i$ with $v_i$ by their addressed records using $O(k)$ time and $O(\log k)$ working bits. In the gate formulation, backwards TRUE through shared AND/OR gates can use the exact local identity $Q(\ell;a,b)\equiv\ell$. No backward choice table or exponential model count is mandatory. Thus the source-stream pass-memory obstruction does \emph{not} lower-bound all RAM exact SAT deciders.

\paragraph{Actual adaptive-state ledger.}
$S_0$ obtains $n,m,k$ and budget $B$ from charged header reads; it does not know $u,v$ or SAT/UNSAT. $S_1$ reads four-clause blocks and retains the selected $B$ prefix signs, considering one-pass versus batch/replay; each local contraction is source-checked. $S_2$ reads the second half, compares only paid retained signs, and either records an observed contradiction or switches to the next batch after a complete scan. $S_3$ returns SAT only after all $k$ pairs match, or UNSAT after a validated mismatch; the SAT witness is verified against all original clauses if requested. $S_{\rm other}$ invokes complete DPLL on unrecognized CNF. Selection, counters, rejected recognizer, source reads, replays and retained bits are charged; the true label is never an input.

\paragraph{COMPUTATIONAL.}
A standalone deterministic Python standard-library audit completed \textbf{594 assertion-accounted checks, zero failures}: exhaustive source assignment/model counts on every $(u,v)$ for $k=1,2$; independent DPLL SAT tests; 48 source/circuit evaluation checks; 60 full-scan adaptive traces ($k=8,32,128,512$ with memory budgets $B=1$ to $k$); ten positive/negative, malformed-template, 2SAT, unit/Horn-like and strict signed-$(2,2)$ $H_g$ fallback controls. No source-sign prescan is used in the streaming scanner. Its Python harness stores the read-only source as test input, not as declared solver workspace. These are abstract event counts, not physical RAM time or measured Python RSS.

For $k=512$, $B=64$, a SAT source makes eight full scans and $131{,}088$ source-word reads; a first-coordinate UNSAT mutation stops after one complete $16{,}386$-word scan, and a last-coordinate mutation takes eight. At $B=1$ the SAT source makes 512 scans and $8{,}389{,}632$ source-word reads. At $B=512$ it makes one scan and $16{,}386$ reads. All end labels are exact for the family.

\section{Scope and next missing lemma}
\textbf{WHAT CHANGED RELATIVE TO ROOT MAIN.}
A two-parameter exact pass--space lower bound is now available for one proper-3CNF decision subfamily and every \emph{adaptive streaming} policy within the declared channel. This complements, but does not replace, MAIN108's weighted source-query ceiling and ONEPASS66's two-pass-collapsible INDEX family. Communication and lookahead restrictions are model constraints, not evidence that an arbitrary SAT decider must use the channel. The current unrestricted cost bridge remains OPEN.

\textbf{BARRIER AUDIT.} Exact zero-error hash/state compression cannot break the rectangle lower bound unless an uncharged outside information source is introduced. Allowing charged random seeks or independent complete RAM source retention invalidates this particular transfer, as a linear direct recognizer demonstrates. No ETH/SETH or cryptographic premise was used. Signed exact-$(2,2)$ and clause-monotone strict NP-complete grammars remain separate.

\textbf{OPEN FIRST MISSING IMPLICATION.} Define a noncircular parameter vector for \emph{complete} adaptive policies that survives source-aware random access, SCC, affine/Horn reasoning, learning, caching, replay and direct root decision; prove an all-policy charged lower bound and establish parameter growth on algorithm-dependent hard inputs. A candidate $T_A(F)\ge 2^{a\rho_A(F)}/N^b$ would suffice only if the actual bound were proved for every decider $A$ and $\rho_A(F)/\log N$ were unbounded on some growing $A$-dependent inputs. The exact target is
\[
\forall A\ \forall c>0\ \forall N_0\ \exists F_A:
|F_A|\ge N_0\land T_A(F_A)>|F_A|^c.
\]
This remains OPEN. Neither $P=NP$ nor $P\ne NP$ is proved.
