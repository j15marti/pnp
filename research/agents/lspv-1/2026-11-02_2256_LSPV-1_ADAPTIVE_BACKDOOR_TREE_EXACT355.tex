\section*{Fixed calculus, encoded length and allowed adaptivity}
The single preselected system is unchanged source-independent-VARDEF \(R_{\rm mix341}\): authenticated original CNF source clauses cost zero; each distinct at-most-binary-premise derived node costs one; legal rules are genuine binary Resolution, exact local AND3, verified GF(2) XOR, local conversions, and charged conservative two-input VARDEF. Shared DAGs count once, temporary growth and reuse are allowed, and the hindsight optimum does not pay discovery. Let
\[
W_R(F)=\min_{\pi:F\vdash_R\bot}\sum_{v\in\pi_{\rm derived}}1,\qquad
\overline W_R(N)=\max_{\substack{F\ {\rm valid\ UNSAT}\\|\operatorname{enc}(F)|\le N}}W_R(F).
\]
The maximum of an empty set is zero; \(N\) counts encoded bits, not variables. All algorithms claimed in B1/B2 must be one fixed total correct program for valid SAT, valid UNSAT, and malformed strings.

A \emph{complete easy-leaf refutation tree} for UNSAT \(F\) is a rooted binary variable-decision tree. Its nodes may select a different unassigned variable depending on the previous assignment. Every leaf restriction \(F|_\alpha\) must be UNSAT and syntactically Horn or 2CNF (the choice may differ by leaf). Put \(L_{\rm H/K}(F)\) equal to the minimum number of leaves of such a tree. It is finite: full assignment eventually produces a witnessed empty clause. This is an \emph{existence} parameter, and discovering the optimal tree is not free in a real solver.

\begin{lemma}[Resolution-only, source-authenticated adaptive lift]\label{lift}
For any UNSAT \(F\), any complete variable-decision tree with \(L\) leaves, and any ordinary Resolution refutation of \(F|_{\alpha}\) containing \(q_{\alpha}\) paid derived nodes at each leaf, there is a legal original-source Resolution refutation of \(F\) with at most
\[
\sum_{\alpha\ {\rm leaf}}q_{\alpha}+L-1
\]
charged derived nodes, independent of the leaf-variable choices and without invoking the unproved full mixed proof restriction/retyping theorem.
\end{lemma}
\begin{proof}
For each leaf, lift every residual source to the corresponding original clause and replay every Resolution pivot on an \emph{unassigned} variable. Added literals were all false under the leaf assignment, so none is an opposite-signed pair; the final lifted clause contains only literals falsified by \(\alpha\), hence is a subclause of the assignment blocker. At siblings for variable \(x\), resolve the two blockers if both contain opposite \(x\) literals; if one already omits \(x\), retain it. The retained or resolved clause remains a subclause of the common parent's assignment blocker. Process the tree upwards. There are at most \(L-1\) internal binary-resolution steps, and the root has empty blocker, so its certified subclause is the empty clause. No weakening, semantic oracle, no uncharged source copy, and no mixed proof restriction compiler is required.
\end{proof}

\begin{theorem}[Fourth screening parameter: adaptive easy-leaf count]\label{screen}
For a universal constant \(c\) and every valid UNSAT CNF \(F\) of encoded bit length \(N\),
\[
\boxed{W_{R_{\rm mix341}}(F)\le W_{\rm Res}(F)
\le L_{\rm H/K}(F)\bigl(c(N+1)^2+1\bigr)-1.}
\]
Consequently \(L_{\rm H/K}(F)=N^{O(1)}\) guarantees a polynomial minimum refutation in the unchanged combined calculus. A superpolynomial worst-case hard sequence must escape this parameter in addition to the earlier deficiency, treewidth and strong-static-backdoor filters.
\end{theorem}
\begin{proof}
Every residual Horn contradiction has a polynomial-size unit-propagation Resolution refutation; every unsatisfiable 2CNF has short contradictory implication-path Resolution proofs. A common \(c(N+1)^2\) bound is conservative, since restrictions cannot enlarge the source's literal population. Apply Lemma~\ref{lift}, with \(q_\alpha\le c(N+1)^2\), and count no more than \(L-1\) additional internal steps. These are genuine Resolution derivations contained in \(R_{\rm mix341}\). The optimizer need not find the tree efficiently for the logical minimum.
\end{proof}

\section*{All-size exact separation: static backdoor versus adaptive path}
For \(d\ge0\), let \(k=2^d\). Take the full depth-\(d\) binary selector tree with \(k-1\) distinct selector variables \(z_p\) indexed by internal prefixes \(p\in\{0,1\}^{<d}\). Each leaf \(\beta\in\{0,1\}^d\) has three fresh private variables \(a_\beta,b_\beta,c_\beta\). Define its guard
\[
g_\beta=\bigvee_{j=0}^{d-1}
\begin{cases}
z_{\beta_{<j}},&\beta_j=0,\\
\neg z_{\beta_{<j}},&\beta_j=1.
\end{cases}
\]
This guard is false exactly when all selectors along the path take the bits of \(\beta\). For each \(u\in\{0,1\}^3\), let \(B_{\beta,u}\) be the three-literal clause uniquely falsified by the private assignment \(u\). The original source is
\[
F_d=\bigwedge_{\beta\in\{0,1\}^d}\bigwedge_{u\in\{0,1\}^3}(g_\beta\vee B_{\beta,u}).
\]
It has \(n=4k-1\) variables, \(m=8k\) source clauses of width \(d+3\), and \(N=\Theta(k(\log(k+1))^2)\) bits in canonical decimal DIMACS (the case \(k=1\) is constant size). It is general CNF; do not silently call it strict 3CNF.

\begin{theorem}[Exact minimum and exponential static/adaptive gap]\label{gap}
For every \(d\ge0\), \(F_d\) is clause-minimally UNSAT, every individual source signed literal occurrence is SAT-repairable, and for the unchanged full mixed calculus
\[
\boxed{W_{R_{\rm mix341}}(F_d)=8k-1.}
\]
If \(b_{\rm H/K}(F_d)\) is the minimum cardinality of a \emph{strong static} heterogeneous Horn-or-2CNF backdoor, then
\[
\boxed{k\le b_{\rm H/K}(F_d)\le2k-1,\qquad
L_{\rm H/K}(F_d)\le 2k,\qquad D_{\rm adaptive}(F_d)\le d+1.}
\]
Thus the static backdoor parameter can be linear in \(k\), while an adaptive complete easy-leaf tree has logarithmic depth, and the exact mixed proof is linear in the source count.
\end{theorem}
\begin{proof}
Every selector valuation chooses exactly one active leaf. Its eight three-literal blockers exclude all eight assignments to that leaf's private variables, so \(F_d\) is UNSAT. To witness deletion of clause \(g_\beta\vee B_{\beta,u}\), set the selector path to \(\beta\) and its three private bits to \(u\). This falsifies \emph{only} the designated source clause. Hence every one of the \(8k\) sources is indispensable; the identical witness satisfies the source after flipping any chosen occurrence sign in that clause. In any sound conservative binary-premise refutation, all \(8k\) ancestors must reach the contradiction, requiring at least \(8k-1\) distinct paid nodes, regardless of mixed rules, shared derivations or auxiliary definitions.

An authentic matching Resolution tree takes each leaf's eight guarded blockers and resolves the three private variables successively in \(7\) paid nodes to obtain \(g_\beta\). It then resolves guarded siblings on the path selector, in \(k-1\) nodes, to obtain the empty clause. Total \(7k+(k-1)=8k-1\), certifying the \emph{global} hindsight optimum of the entire fixed mixed calculus.

For the static lower bound, any proposed static backdoor set that omits \emph{all three} private variables of some leaf \(\beta\) fails: choose assigned selector variables consistently with \(\beta\), so no guard literal is true. The particular original source \(g_\beta\vee a_\beta\vee b_\beta\vee c_\beta\), restricted by this backdoor assignment, retains all three positive private literals. Thus the residual is neither Horn nor 2CNF. The k disjoint leaf-private triples must all be hit, so \(b_{\rm H/K}\ge k\). The upper \(2k-1\) is attained by selecting all \(k-1\) selectors and the first private variable in each leaf: every complete assignment activates one leaf with only width-\(\le2\) blockers. For the adaptive tree, branch on selectors along the encountered path, then only on the first private variable at that active leaf. There are \(2k\) leaves, each an UNSAT 2CNF (four assignment blockers of the remaining two bits), at depth \(d+1\).
\end{proof}
