\section{Exact clean-core family and quotient theorem}
Let \(H_F(\alpha)=1\) iff the partial assignment \(\alpha\) extends to a
satisfying assignment of (F).  BALCOMP1 constructs fixed equal-size blocks
\(B_0,B_1\in\Core\), with \(B_b\) satisfiable exactly when \(b=1\), and two
satisfiable six-variable blocks \(G_0,G_1\in\Core\).  For a fixed partial
assignment \(\beta\),
\[
 H_{G_0}(\beta)=1,\qquad H_{G_1}(\beta)=0.
\]
For \(b\in\{0,1\}\) and \(u\in\{0,1\}^k\), set
\[
 E_{b,u}=B_b\sqcup G_{u_1}\sqcup\cdots\sqcup G_{u_k}.
\]
Every member has encoded length
\[
 N_k=h(k)+(792+24k)\bigl(1+\lceil\log_2(198+6k+1)\rceil\bigr)
     =\Theta(k\log k),                                      \tag{1}
\]
under the declared indexed encoding.  Let \(S_k\) permute the \(k\) payload
blocks, hence the coordinates of \(u\).  Let \(\alpha_i\) apply \(\beta\) only
to block (i).

\begin{theorem}[\texttt{SYMMETRY-QUOTIENT-COLLAPSE1}]
For each \(k\ge1\):
\begin{enumerate}[label=(\roman*)]
\item the \(S_k\)-orbits on \(\{E_{b,u}:b\in\{0,1\},u\in\{0,1\}^k\}\) are
classified exactly by ((b,|u|)), so there are (2(k+1));
\item every \(S_k\)-invariant function of the formula factors through
((b,|u|));
\item the orbit of the probe fingerprint
\(C(E_{b,u})=(H_{E_{b,u}}(\alpha_1),\ldots,H_{E_{b,u}}(\alpha_k))\)
is classified by its number of ones and has only (k+1) possible values;
\item the maximal formula-invariant key uses
\(\lceil\log_2(2(k+1))\rceil\) bits and the compatibility-orbit key uses
\(\lceil\log_2(k+1)\rceil\) bits.  Both are computable by one canonical parse
and \(O(k)\) block updates, hence \(O(N_k)\) time.
\end{enumerate}
Thus exponential labeled compatibility diversity does not imply exponential
orbit-valued or invariant state, communication, extraction, or time on this
family.
\end{theorem}

\begin{proof}
Two binary strings are in the same coordinate-permutation orbit exactly when
they have the same Hamming weight.  The leading block is not permuted, proving
(i).  Any invariant is constant on orbits, which is exactly factorization
through the orbit map, proving (ii).

BALCOMP1 gives
\[
 C(E_{1,u})=(1-u_1,\ldots,1-u_k),\qquad C(E_{0,u})=0^k.       \tag{2}
\]
Binary vectors are likewise classified under \(S_k\) by their number of
ones.  As \(u\) ranges, (2) realizes every count \(0,\ldots,k\), while the NO
case adds no new value.  This proves (iii).  Counting the keys gives the bit
bounds.  The declared macroblock grammar exposes (b) and each payload type
during a left-to-right parse, proving (iv).
\end{proof}

The theorem does not say that every invariant on arbitrary formulas is small.
It falsifies the proposed \emph{universal repair} on the explicit counterfamily.
A label-sensitive canonical order can retain all \(u_i\), but then it abandons
the quotient premise; that is an algorithmic escape, not a contradiction.

\section{Recovered exact-((2,2)) proof-complexity benchmark}
The recovered source establishes the following restricted benchmark.
\begin{enumerate}[label=R\arabic*.]
\item \EXACT: an occurrence-halving compiler maps every proper exact-((4,4))
3-CNF on (n) variables to a proper exact-((2,2)) 3-CNF on (24n)
variables and (32n) clauses.  A literal/constant substitution projects the
compiled formula back to the source after tautology cleanup.
\item \EXACT{} construction plus \KNOWN{} endpoint: endpoint-local pairing
on simple 2-vertex-connected cubic Tseitin sources makes the compiled formulas
minimally UNSAT; Urquhart's expander-Tseitin theorem and substitution closure
give general-Resolution size \(2^{\Omega(v)}\), hence also exponential
tree-like Resolution.
\item \EXACT{} normalization: with ordinary indexed encoding
\(L=\Theta(v\log v)\), the proof-size statement is
\[
 \operatorname{ResSize}(F_L)=2^{\Omega(L/\log L)}.            \tag{3}
\]
The family is signed/mixed-polarity exact-((2,2)); it is not the separate
clause-monotone cubic-pair construction.
\end{enumerate}
Here ``general Resolution'' means DAG Resolution, not arbitrary computation.
Equation (3) is therefore not an SAT time lower bound.

\begin{lemma}[\texttt{DECIDER-TRACE-PROOF-MISMATCH1}]
Let (A) be a correct deterministic SAT decider running in time (T(N)).
For UNSAT inputs define \(V_A(F,\pi)=1\) exactly when \(\pi\) is the complete
valid accepting computation trace of (A(F)) ending with output UNSAT.  Then
\(V_A\) is a sound and complete proof relation for UNSAT, verifiable in
\(O(|\pi|)\) time, and every UNSAT \(F\) has a proof of size \(O(T(|F|))\).
If (T) is polynomial, this tailored proof system is polynomially bounded.
\end{lemma}
\begin{proof}
Local transition checking verifies a deterministic trace.  Correctness of
(A) gives soundness, totality gives one accepting trace for every UNSAT
formula, and writing all configurations costs at most a polynomial factor in
the machine time and configuration width (absorbed into the declared trace
encoding).
\end{proof}

Consequently, using (3) against (A) requires a new \COND{} compiler that
turns the \emph{same execution} trace into a Resolution refutation with only
polynomial overhead.  No such theorem is supplied; arbitrary deciders can
have short tailored traces while Resolution remains exponentially long.  A
lower bound against every tailored trace system is already separation-strength
and cannot be smuggled in as a ``compatibility'' premise.

\section{Arbitrary algorithms, barriers, and all costs}
Assume SAT is in P and fix an arbitrary uniform deterministic decider (A).
The BALCOMP wrapper can recognize \(E_{b,u}\), return \(b\), and avoid all
compatibility work; its costs are \(O(N_k)\) parsing, \(O(1)\) output, zero
fallback calls, zero compatibility queries, and zero reconstruction.  The
quotient keys, if voluntarily computed, still cost only \(O(N_k)\) time and
\(O(\log k)\) output space.  The Resolution benchmark constrains only programs
whose UNSAT evidence is forced into Resolution or polynomially translates to
it.  There is no SAME\_REALIZATION theorem forcing arbitrary \(A\) into that
proof model.

The quotient theorem and wrapper argument relativize and are compatible with
both \(P=NP\) and \(P\ne NP\).  No arithmetization is used, so there is no
escape from algebrization.  The report asserts no constructive large property
of Boolean functions, so Natural Proofs is not the direct reason for failure;
the immediate failure is model mismatch.  Nonuniform circuit or branching-
program representations can only add escapes unless a uniform acquisition
and translation theorem is proved.  Padding changes (N) but not the quotient
and cannot strengthen any exponent.

\section{Next exact target}
The surviving target is not another semantic count.  It is to prove or
falsify, with explicit encoding and costs, a transfer theorem of the form
\[
 \forall A\in\mathsf{P}\text{-time SAT deciders}\ \exists E^A\ \forall F
 \in\mathcal H:
 \quad E^A(F,\operatorname{trace}_A(F))\in\mathcal P(F),      \tag{4}
\]
where \(E^A\) has polynomial overhead, is invariant under equivalent wrappers,
uses the same execution, and \(\mathcal P\) is a proof/computation model with
a model-matched unconditional superpolynomial lower bound on \(\mathcal H\).
Resolution supplies the endpoint but not (4); tailored traces supply the
counterpressure.  Until both arrows are proved, P versus NP remains \OPEN.
