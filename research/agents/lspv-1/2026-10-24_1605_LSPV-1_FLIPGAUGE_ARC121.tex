\section{Model and exact complete-state theorem}
Fix a deterministic total uniform program and immutable input $x$. Its complete instantaneous configuration $C$ contains the entire finite control, source/work-head and address state, mutable and index tape contents, and every other state coordinate necessary to determine the next transition. Any external clock or random tape, when permitted, must be included in the complete state or is a different nonautonomous model. Let a halting run have $T$ genuine transitions and an injective, coordinate-stable binary representation $\iota$ of all configurations. Put
\[
\Delta_A(x)=\sum_{i=0}^{T-1}d_H(\iota(C_i),\iota(C_{i+1})).
\]
\begin{theorem}[PROVED/EXACT within the declared autonomous model]
Every such halting deterministic run satisfies $T\le\Delta_A(x)$. If every primitive transition changes at most $b(N,T)$ represented bits, then
\[
\boxed{T\le \Delta_A(x)\le b(N,T)T.}
\]
When $b=O(1)$, complete-state flips and time are within constant factors. For $b=\operatorname{polylog}(N+T)$, they are within polylogarithmic factors. Thus an unavoidable superpolynomial bound on \emph{complete} flips across all exact SAT deciders in a bit-local model is already essentially an unavoidable time lower bound, not a free alternate endpoint.
\end{theorem}
\begin{proof}
Were $C_i=C_{i+1}$, the deterministic transition on the fixed input would repeat that same configuration indefinitely, so the computation could not halt. Injectivity gives Hamming distance at least one on every genuine transition, and summation proves the lower bound. The upper bound sums at most $b$ changes at each transition. A billed unchanged-value write with no change in the represented state is an accounting microevent, not a separate autonomous machine transition unless head, clock or control progress is included.
\end{proof}
\paragraph{FLMV model firewall.} Fortnow--Lipton--van Melkebeek--Viglas (FLMV) count index/work tapes, use read-only random-access input and a one-way write-only output. Their indexed-input operation can erase an index tape in one macrostep. Accordingly, a constant/polylogarithmic bit-flip cap on every FLMV step does \emph{not} follow without a charged simulation or a restriction on index length. The present theorem is not a new FLMV forbidden endpoint and does not establish an all-input SAT speedup.

\section{Bit-resource vector and partial-activity counterexample}
Record primitive work $U$, source/work reads, workspace writes including unchanged writes, actual complete-state flips $\Delta$, peak writable bits $S$, cumulative bit-time $BT=\sum_{i=0}^{U}B_i$, and representation/program size. For $B_i$ simultaneously live bits, $S=\max B_i$ gives $S\le BT\le(U+1)S$. A $D$-bit descriptor kept for $H$ steps contributes $DH$ to this trajectory, but no arbitrary SAT decider must retain that descriptor.

\begin{lemma}[PROVED/EXACT scoped streaming counterexample]
The exact streaming parity algorithm reads every one of $n$ input bits and bills an accumulator write after each read. On $0^n$, every accumulator write is unchanged and the number of accumulator flips is zero. The machine still changes head/address/control state and performs charged source queries. Thus source query complexity does not lower-bound value-changing \emph{accumulator} writes.
\end{lemma}
\begin{proof}The update is $\pi\leftarrow\pi\oplus x_i$ with $\pi=0$ initially. For all-zero input $\pi$ never changes, while each bit is read. Other inputs, including odd-parity controls, are decided correctly by the same label-blind program.\end{proof}
For the same address trace $0,1,\ldots,n$, Gray encoding uses one address-register flip per increment whereas binary encoding may use several. These are encoding-dependent activity metrics, not intrinsic thermodynamic dissipation.
