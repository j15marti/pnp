\section{Source, encoding, complete minimality}
Use \(x_1,\ldots,x_{k+1}\), \(z_1,\ldots,z_k\), and private \(a,b,c,d\). Define
\[
 {\rm PIN}(\ell;p,q)=\bigwedge_{\epsilon,\delta\in\{\pm1\}}
 (\ell\vee\epsilon p\vee\delta q),\qquad
 {\rm LINK}(u,v;z)=(u\vee v\vee z)\wedge(u\vee v\vee\neg z)
\]
and
\[
U_k={\rm PIN}(x_1;a,b)\wedge
\bigwedge_{i=1}^k{\rm LINK}(\neg x_i,x_{i+1};z_i)
\wedge{\rm PIN}(\neg x_{k+1};c,d). \tag{1}
\]
Its \(V=2k+5\) variables, \(M=2k+8\) distinct ternary clauses, three-distinct-name condition and connected clause-variable incidence graph are immediate. It is \emph{ordinary} proper 3CNF, not signed exact-\((2,2)\): each \(z_i\) appears once positively and once negatively, while \(x_1\) appears four times positively, twice negatively.

For an all-\(k\) encoding let \(w=\lfloor\log_2(\max(V,M))\rfloor+1\), write unary \(1^w0\), then \(V,M\) in \(w\) binary bits each, followed by \(M\) records, each of three \((\text{sign bit},w\text{-bit name})\) fields and a delimiter bit. This has
\[
N_k=3w+1+M(3(w+1)+1)=\Theta(k\log(k+2)). \tag{2}
\]
Every single literal-sign change preserves encoded length, header, arity and within-clause distinctness. Ordinary proper SAT permits repeated clauses in the neighboring inputs; this is not a claimed clause-uniqueness-promise result.

\begin{theorem}[Minimality and one-bit SAT neighbors]\label{th:min}
For every \(k\ge1\), \(U_k\) is clause-minimally UNSAT and, for each original clause \(j\) and literal position \(h\in\{1,2,3\}\), flipping only the corresponding physical source sign bit produces a SAT ordinary proper ternary formula \(U_k^{j,h}\).
\end{theorem}
\begin{proof}
Existentially eliminating each PIN auxiliary pair enforces its unit \(\ell\). Eliminating \(z_i\) from LINK enforces \(\neg x_i\vee x_{i+1}\). Thus \(x_1=1\) propagates to \(x_{k+1}=1\), contradicting the last unit. To remove any one first PIN clause, set all chain \(x\)'s false and set \(a,b\) to falsify precisely that omitted clause; all other clauses are satisfied. For an omitted last PIN clause, set all \(x\)'s true and similarly select \(c,d\). For an omitted link member at position \(i\), set \(x_1,\ldots,x_i=1\) and all later \(x\)'s false, choosing \(z_i\) to falsify the omitted literal and satisfy the other member. All remaining auxiliary values are harmless. Each chosen deletion witness falsifies all \emph{three} literals of the omitted clause, so flipping any one makes the complete formula SAT. This proof covers every source index \(j,h\).
\end{proof}
\begin{theorem}[Sound path reads every original polarity bit]\label{th:probe}
Let \(V\) be any fixed nondeterministic UNSAT-certificate verifier such that
\[
\forall F\in{\rm SAT}\ \forall\pi\ \forall\rho:
 V(F,\pi;\rho)\ne{\rm UNSATaccept}, \tag{3}
\]
where \(F\) ranges over all valid ordinarily encoded proper three-CNF formulas, \(\pi\) is the proof, and \(\rho\) fixes a computation path. For every accepted path \(V(U_k,\pi;\rho)\), all \(3M=6k+24\) original literal-sign bits were read in that same complete execution. This also holds for a deterministic correct UNSAT decision or a rejecting branch of co-nondeterministic SAT.
\end{theorem}
\begin{proof}
If an accepted path never inspects one sign bit, replay identical proof and choices on its same-length SAT one-bit mutant from Theorem~\ref{th:min}. All queried input symbols, adaptive addresses, states and the final acceptance are identical. This contradicts (3). Repeat for every sign position. Earlier parsing, caches, child queries, failed attempts, selector moves and local verification are included in the run, not given free as a late checkpoint.
\end{proof}
\begin{theorem}[Explicit optimal authenticated binary Resolution]\label{th:res}
There is a binary-Resolution refutation of \(U_k\), with actual original source clauses as authenticated axioms, whose inference count is exactly \(I=2k+7=M-1\); it has \(2M-1\) total lines, maximum width three, and \(O(M\log(M+2))=O(N_k)\) encoded bits. Every binary-Resolution refutation of \(U_k\) has at least \(M-1\) inference nodes.
\end{theorem}
\begin{proof}
From the first four PIN clauses, resolve the first pair and second pair on \(b\), then their results on \(a\), deriving the unit \(x_1\) in three steps. For each link \(i\), resolve its original two source clauses on \(z_i\) to obtain \((\neg x_i\vee x_{i+1})\), then with the previous unit on \(x_i\) to obtain the next unit, two inferences per link. Resolve the final PIN clauses in three steps to derive \(\neg x_{k+1}\), and resolve with \(x_{k+1}\) to get the empty clause. Total \(3+2k+3+1=2k+7\); every source axiom is used. For optimality, because deleting any source clause makes the formula SAT, each source clause must be in the ancestral refutation DAG. With \(M\) axiom nodes and \(I\) binary inference nodes, the connected underlying graph has \(M+I\) nodes and \(2I\) premise edges, so \(2I\ge M+I-1\), hence \(I\ge M-1\). Each source record offset, pivot and previous-line index takes \(O(\log M)\) bits. A verifier must authenticate source axioms, not trust an unsourced proof.
\end{proof}
\begin{theorem}[Globally sound zero-advice local grammar]\label{th:zero}
One uniform deterministic verifier \(Z\), with an empty certificate and globally sound on \emph{all} ordinary proper three-CNF strings in the displayed encoding, recognizes every \(U_k\) as UNSAT. On a fixed-\(k_0\) multitape machine with a single read-only sequential input head and \(k_0=O(1)\) work tapes, its two charged source scans take \(N\operatorname{polylog}(N+2)\) transitions and \(O(\log(N+2))\) distinct visited work cells. Its only output is one bit.
\end{theorem}
\begin{proof}
\(Z\) measures source length and rewinds. It then checks the unary width, \(V,M\), length, syntax and every signed literal record against the \emph{canonical clause order} in (1), using counters for \(k,i,j\) and the expected names. Enforce \(w=O(\log N)\) and \(V=2k+5,M=2k+8\) before comparisons, so a constant number of counters and current fields occupy \(O(\log N)\) bits. All other strings, malformed headers and excess/truncated records fail. Acceptance therefore implies that the physical input is exactly some \(U_k\), which is UNSAT by Theorem~\ref{th:min}. Scanning and comparing binary fields needs at most polylogarithmic bit time per source bit on fixed sequential work tapes. Every sign bit is in fact read, as required by Theorem~\ref{th:probe}. This special grammar does not accept general UNSAT instances, and the zero-bit proof is not a zero-cost source read.
\end{proof}
