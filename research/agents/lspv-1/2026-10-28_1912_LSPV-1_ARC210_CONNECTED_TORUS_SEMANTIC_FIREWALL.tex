\section{Independent static-interface derivation}
\begin{proposition}
Let $F$ be connected proper strict signed exact-$(2,2)$-3CNF on $n$ variables, with a supplied boundary $Y$ of $b>0$ variables and $k$ disjoint nonempty private-variable modules. Every original clause belongs to one module, cannot mix private names from two modules, and meets $Y$ or a module-local syntactic clause-hitting set $B_i$ of size at most $q$. Then
\[
 k\le4b,\quad n\le3(b+\sum_i|B_i|)\le3b+12bq,\quad b+q\ge\sqrt{n/3}-1/4.
\]
For $b=0$, connectedness implies $k=1$ and $q\ge n/3$.
\end{proposition}
\begin{proof}
Every nonempty private module must touch $Y$ in a source clause, else it is an isolated incidence component. There are at most $4b$ boundary-clause incidences, and one clause cannot mix private modules, so $k\le4b$. The union $H=Y\cup\bigcup_iB_i$ meets every clause. Exact occurrences imply $m=4n/3$, while each $H$ variable touches four clauses; thus $m\le4|H|$ and $n\le3|H|$. Rearrange to $b(q+1/4)\ge n/12$ and use AM--GM. The $b=0$ case has one module and the same incidence count.
\end{proof}
The archive Connected\_Interface\_Audit.zip, Library id libfile\_a2862f0165b4819195a88d9e896a42a7, was materialized. REPORT.tex and its five-page REPORT.pdf were inspected. Its audit.py was rerun independently, obtaining exactly the committed results.json, namely 4680 boundary subsets, 7191 local search checks and 139 brute-force decision comparisons. The syntactic inequality rules out universal $b,q=O(\log N)$ under unpadded $N=\Theta(n\log n)$, but is \emph{not} a SAT runtime bound. \section{BUILD: a one-variable-per-grid-cell signed control}
For $L\ge6$ divisible by six, take $x_{r,c}$ for $(r,c)\in\mathbb Z_L^2$. For every row $r$, offset $o\in\{0,1\}$ and $j<L/3$, insert
\[
P_{r,o,j}=(x_{r,o+3j}\vee x_{r,o+3j+1}\vee x_{r,o+3j+2}).
\]
For every column $c$ with the same offsets and blocks insert
\[
Q_{c,o,j}=(\neg x_{o+3j,c}\vee\neg x_{o+3j+1,c}\vee\neg x_{o+3j+2,c}).
\]
Indices are cyclic modulo $L$.
\begin{theorem}
The resulting $T_L$ has $n=L^2$ variables, $m=4n/3$ distinct proper ternary clauses, connected incidence graph and exactly two positive and two negative occurrences per variable. Its minimum global syntactic clause-hitting set is $n/3$. Every variable ordering has maximum processed/unprocessed primal frontier $w\ge L-1$; row-major order has $w\le5L$. The explicit assignment $x_{r,c}=1$ iff $r\equiv c\pmod3$ satisfies $T_L$.
\end{theorem}
\begin{proof}
The two shifted horizontal and two shifted vertical triple partitions each use each variable exactly once, with respective positive and negative signs. The union of horizontal partitions contains each horizontal nearest-neighbor pair, and similarly vertically, so the connected primal graph contains the toroidal $L$-by-$L$ grid. The set $H=\{x_{r,c}:r\equiv c\bmod3\}$ hits every three-consecutive-cell block; it has size $n/3$. The four-occurrence clause count proves the matching lower bound.
For the frontier, consider the row-column crosses $X_{r,c}=R_r\cup C_c$ in the embedded grid. Any two crosses intersect, and a set of fewer than $L$ vertices misses a complete row and complete column, hence their cross. Bag subtrees for these connected crosses pairwise intersect. Helly for tree subtrees yields a common bag meeting every cross, so every tree decomposition has a bag of at least $L$ vertices. An ordering of maximum frontier $w$ induces path-decomposition bags of size at most $w+1$, hence $w\ge L-1$. Row-major processing keeps processed sources with future scope-neighbors only in the current, two preceding and two wraparound first rows, at most $5L$. In every positive row triple the displayed assignment has one true literal; in every negative column triple two literals are true.
\end{proof}
Thus minimum syntactic width is $\Theta(L)=\Theta(\sqrt{N/\log N})$. No exponential SAT runtime follows because these canonical instances have a directly constructible satisfying assignment. \section{Small exact summary versus paid computation}
\begin{proposition}
For any ordinary 3CNF $F(x)$, the exact projection to empty frontier $E_F(\varnothing)=\exists x\,F(x)$ has a one-bit representation. A deterministic uniform polynomial-time constructor of this bit for all ordinary 3CNFs exists if and only if $P=NP$.
\end{proposition}
\begin{proof}
If constructible in polynomial time, read the bit to decide SAT. If SAT is in P, decide the formula and print the bit. Both directions are uniform and fully materialized.
\end{proof}
This elementary equivalence is a \emph{circularity warning}, not an attack on P versus NP: small extensional summary size alone says nothing about its computation cost. A decreasing polynomial numerical VALUE rank and polynomial full-state transitions suffice for polynomial time; a rank with only $O(N)$ bits permits $2^N$ decrements and is insufficient.
