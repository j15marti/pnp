\textbf{PROVED/EXACT, independent review pending.}
A probabilistic verifier with constant local proof queries does not supply a globally sound accepting certificate.
The necessary observed-information budget for a deterministic verification is the physical union over all random seeds, not a per-seed maximum.

\section{Falsifiers proposed before source inspection}
\begin{enumerate}
\item[] H1. Accepting one random seed is a sound UNSAT certificate.
\textbf{FALSIFIED} on a signed exact-(2,2) source.
\item[] H2. One proof query per seed yields one global proof-bit query.
\textbf{FALSIFIED} by disjoint proof addresses.
\item[] H3. Deterministic all-seed aggregation preserves soundness with a charged $R$ multiplier. \textbf{PROVED} below.
\item[] H4. The resulting first-read enumeration composes with the Williams cosine bound for subpolynomial space. \textbf{PROVED under explicit conditions}.
\end{enumerate}

\section{Uniform indexed machine and exact quantifiers}
For each ordinary CNF source $F$ of physical length $N$, fix ONE
uniform total deterministic indexed-RAT checker $V(F,\pi,z)$ with
binary proof $\pi$ of publicly fixed length $L(N)\le N^p$,
and random seed $z\in\{0,1\}^{h(N)}$.
Its physical proof-store plus bit-address map is stable, uniform,
and charged. Public polynomially bounded indices and a uniform clock
prevent hidden advice channels. Write
\[
R=2^{h(N)}\le N^{\rho+o(1)},\qquad
T_V\le N^{v+o(1)},\qquad S_V\le N^{s+o(1)}. \tag{1}
\]
All three ceilings apply together to the SAME $V$, on every
source, seed and proof, including failed branches.
Let fixed $0\le\sigma<c\le1$ satisfy
\[
\begin{split}
\forall F\in{\sf SAT}\;\forall\pi:
&\quad \sum_{z=0}^{R-1} V(F,\pi,z)\le\sigma R,\\
\forall F\in{\sf UNSAT}\;\exists\pi:
&\quad \sum_{z=0}^{R-1} V(F,\pi,z)\ge cR .
\end{split} \tag{2}
\]
For a fixed proof, let $Q_z(F,\pi)$ be the set of distinct physical
binary proof cells read during seed $z$. The \emph{global} observed
proof budget is
\[
Q_{\rm all}(F,\pi)=\left|\bigcup_{z=0}^{R-1}Q_z(F,\pi)\right|. \tag{3}
\]
Assume independently, for EVERY ordinary UNSAT source, that
there is a proof satisfying (2) \emph{and}
\[
Q_{\rm all}(F,\pi)\le(a+o(1))\log_2 N. \tag{4}
\]
Local per-seed queries do not imply (4). A child-local proof position
is not a physical key unless its store and offset mapping is
injective and paid. All source authentication, local discovery,
virtual access, child creation, resets and failed trials count
within $V$.


\begin{theorem}[Sound all-seed aggregation]
Under (1)--(2), define
\[
 W(F,\pi)=\left[\sum_{z=0}^{R-1}V(F,\pi,z)>\sigma R\right]. \tag{5}
\]
Then $W$ is SAT-sound for all fixed proofs and all-UNSAT-complete
for some fixed proof, with the SAME indexed machine ceilings
\[
T_W=N^{\rho+v+o(1)},\quad S_W=N^{s+o(1)}
\]
apart from the separately charged linear-time ordinary-CNF parse.
Its observed proof information is precisely (3).
\end{theorem}
\begin{proof}
For SAT sources and every proof, (2) bounds the accepted seed
count by $\sigma R$, so the strict threshold rejects.
For UNSAT choose a proof from (2); its accepted count is
at least $cR>\sigma R$. Every seed is executed with the same
immutable proof and same source. The simulator runs each seed,
reinitializing guest work in a charged reset or indexed epoch
layout, retaining only the current guest state, the seed
counter and the acceptance count. An ordinary indexed sparse
layout adds at most polylogarithmic time/space overhead; all
proof-bit addresses, child generation, parsing, source access,
failed branches and independent seed attempts cost actual
time. Therefore $R$ runs cost
$RT_V\operatorname{polylog}N$, with peak work
$S_V\operatorname{polylog}N+O(\log R+\log N)$.
Proof reads across the complete run are exactly (3).
\end{proof}

\begin{theorem}[First-read seed-union compiler and cosine frontier]
If (1)--(4) hold on every ordinary input, there exists
one uniform deterministic indexed-RAT ordinary-SAT decider
with simultaneous ceilings
\[
\boxed{T_D=N^{\max\{1,\rho+v+a\}+o(1)},\qquad
S_D=N^{s+o(1)}} . \tag{6}
\]
If $s=o(1)$ for this same resulting native machine, the
known Williams deterministic SAT lower bound implies the
strict necessary condition
\[
\boxed{\rho+v+a\ge\gamma,\qquad
       \gamma=2\cos(\pi/7)=1.801937735804838\ldots .} \tag{7}
\]
Equality is not excluded.
\end{theorem}
\begin{proof}
Apply ARC200's first-read proof-bit simulation to the
\emph{deterministic} aggregated verifier $W$.
For each of at most $2^{q(N)}\le N^{a+o(1)}$
binary answer strings, restart a complete independent $W$
execution. The simulator stores a sparse dictionary indexed
by each canonical physical proof-store/address pair. It
assigns the next guessed bit on first access and repeats
the stored answer on subsequent reads, including accesses
from other seeds and other hereditary children. It aborts
at the $(q+1)$st distinct address. Any accepted dictionary
is a partial assignment extendible to a genuine immutable
binary proof, hence cannot accept a SAT source by
Theorem 1. For each UNSAT source the witness guaranteed by
(4) is reproduced exactly by one candidate answer word.
Charging the whole $W$ simulation for each attempted
word gives $2^q RT_V\operatorname{polylog}N$ time,
the ordinary linear parse, and one live work-state
plus an $O(q\log N)$-bit proof dictionary.
Thus (6) is a simultaneous bound for one machine.
The original corrected Williams $N^{o(1)}$-space
SAT theorem excludes exponent strictly below
$\gamma>1$ in this indexed model. This gives (7).
No polynomial-time all-input proof system was constructed
in this argument.
\end{proof}

\section{Exact hostile controls on canonical proper signed exact-(2,2) W1}
The immutable 15-variable, 20-clause W1 source has three
distinct variables per clause and exactly two positive and
two negative appearances of each variable. Its four
source modes $H(a,b)$ have exactly
$(772,272,272,0)$ satisfying assignments for
$00,01,10,11$. Thus ONLY $11$ is UNSAT.

For any $R\ge2$, take a fixed $R$-bit proof. A toy
\emph{source-authenticated promise verifier} checks the
entire W1 clause list against the four canonical modes.
On UNSAT mode $11$ and seed $z$, it accepts iff
$\pi_z=1$, reading one bit from physical address $z$.
On any of the other three SAT modes it ignores the proof
and accepts exactly when $z=0$.
The SAT soundness probability is $1/R<1$ for every proof.
The UNSAT mode has perfect completeness with proof $1^R$.
But \emph{each SAT mode possesses an accepting seed};
the existential single-seed shortcut is unsound.
On UNSAT mode, every seed makes one proof query,
while the complete union is exactly $R$ distinct
cells, not one. If $R=N^\rho$, exhaustive answer
enumeration for that full physical union can cost
$2^{N^{\rho+o(1)}}$ rather than polynomial time.
This restricted easy-promise checker is not claimed
to solve arbitrary SAT or to prove a global PCP lower bound.
