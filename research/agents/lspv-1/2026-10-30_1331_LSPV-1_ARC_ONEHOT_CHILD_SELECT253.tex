\section{One integrated target, quantifiers, and falsifiers}
The controlling project objective is an all-input source-authenticated adaptive parameterized residual SAT decider, with a single uniform hereditary compilation step $\Phi(A)$ for \emph{every fixed correct deterministic polynomial ordinary-SAT decider} $A$, whose unknown finite exponents $K,L$ satisfy
\[
K'\le\max\{\alpha,\gamma+\lambda K\},\qquad
L'\le\max\{\sigma,\lambda L\}.
\tag{1}
\]
The proposed $(\alpha,\gamma,\lambda,\sigma)=(11/10,3/5,1/2,1/2)$ is still \emph{hypothetical}. The finished procedure must be a single uniform exact ordinary-SAT decider, preserving both SAT and UNSAT and charging source input reads, selection, failed methods, physical child bit production, guest execution, caching, switching, and simultaneous work/index space. These are not consequences of a bound on syntactic child length.

Three falsifiers are examined. \emph{F1:} any very short syntactic cofactor can be emitted as an ordinary random-access guest input with a uniformly cheap, stateless bit oracle. \emph{F2:} once a cofactor is short, both sides of an ordinary SAT branch are automatically power-short. \emph{F3:} caching repairs F1 without paying construction or persisted-bit cost. All three fail for the explicitly described \emph{source/bit-probe architecture}. This negative control does not purport to refute a more powerful compiler.

\section{Exact one-hot signed source family}
Fix even $m\ge4$. Use original variables $x,z,a_0,\ldots,a_{m-1}$, numbered $x=1,z=2,a_i=i+3$. Optionally add three independent variables $u,v,w$ and the fixed contradiction
\[
G_{\rm NO}(u,v,w)=\bigwedge_{(s,t,r)\in\{+,-\}^3}
(su\vee tv\vee rw),\qquad G_{\rm YES}=\top.
\tag{2}
\]
For a marked index $h\in\{0,\ldots,m-1\}$ and label control $b\in\{\mathrm{YES},\mathrm{NO}\}$, define the \emph{proper original indexed ternary source}
\[
 F_{m,h,b}=G_b\wedge\bigwedge_{i=0}^{m-1}
 (\ell_i\vee a_i\vee z),\quad
 \ell_i=\begin{cases}x&i=h,\\\neg x&i\ne h.\end{cases}
\tag{3}
\]
All sources with the same $m,b$ have identical header, variable identifiers, clause positions and every literal bit \emph{except the sign of the $x$ occurrence in each of the $m$ source clauses}. Exactly one sign bit is positive. The $G_{\rm NO}$ control is unsatisfiable by exhaustive polarity coverage of the three independent variables; $G_{\rm YES}$ is true. Thus $F_{m,h,b}$ is SAT iff $b=\mathrm{YES}$, independently of $h$. Indeed, set every $a_i=z=1$ to satisfy all marked clauses for either $x$; this family is \emph{easy}, not SAT-hard.

Under the ordinary syntactic restriction $x=0$, all unmarked clauses disappear, leaving exactly one binary clause
\[
 F_{m,h,b}\restriction(x=0)=G_b\wedge(a_h\vee z).
\tag{4}
\]
Under $x=1$, the marked clause disappears and the $m-1$ unmarked clauses survive as binary clauses. With a fixed-width literal-record encoding, parent length $N=\Theta(m\log m)$, the first child has $O(\log m)$ bits (the constant eight-clause $G_{\rm NO}$ is harmless), but the second has $\Theta(m\log m)=\Theta(N)$ bits. These statements concern \emph{ordinary explicit output grammar}; changing grammar or recognizing the easy promise is permitted but must be charged and separately proved.

\section{Main restricted lower bound, independent of adaptive bit-order}
The online question requests a \emph{single fixed physical output bit} of the first child: the least significant bit of the $a_h$ variable-ID field in the unique non-core clause of (4). This bit is $h+3\pmod2$, so exactly $m/2$ legal sources output each possible bit. The header and core-clause records are identical for all $h$. The bit-probe model grants arbitrary indexed access to original source bits, adaptive order, arbitrary deterministic computation, an arbitrary summary computed before the query, and arbitrary retained side information \emph{only if derived from inspected source bits}. All source-dependent advice, leakage and preprocessing transcript information are charged. Let $P$ and $Q$ be uniform worst-case counts of source-sign-bit probes respectively before and after query disclosure; repetitions are charged.

\begin{theorem}[One-hot compacted-child bit selection, PROVED/RESTRICTED]
For every deterministic exact two-stage algorithm serving the stated child output bit for every $F_{m,h,b}$, with no free source-dependent advice,
\[
\boxed{P+Q\ge m/2.} \tag{5}
\]
The bound permits arbitrary adaptive probe order and arbitrary nonlinear summaries. It is tight when $P=0$: read every one of the $m/2$ source signs in one parity class, then output whether the one mark was discovered. For output of the \emph{entire child} including the identity of $a_h$, one must have
\[
\boxed{P+Q\ge m-1,} \tag{6}
\]
where $Q$ now means the aggregate sign-bit reads required by the complete continuation, including shared cache. Equation (6) is tight by inspecting any $m-1$ marked positions and inferring the last one if necessary.
\end{theorem}
\begin{proof}
Follow the all-zero response path to inspected sign bits. If fewer than $m/2$ distinct signs have been read, at least one even and one odd original position remain uninspected, because each parity class has size $m/2$. Two legal one-hot sources placing their unique positive sign at these two positions yield \emph{identical entire preprocessing and continuation transcripts}, yet require opposite answers for the requested output bit. This contradicts exactness. Arbitrary summary strings cannot distinguish identical transcripts, proving (5), including preprocessing/continuation adaptivity. For the complete child, the $m$ candidates carry $m$ distinct variable IDs. Under fewer than $m-1$ different sign probes the all-zero transcript leaves at least two different possible indices, which yield different child encodings. This proves (6). The matching upper bounds are immediate from scanning one parity class or all but one sign position, respectively.
\end{proof}

\begin{remark}[Machine-specific significance and legal escape]
An original fixed-width source representation occupies $N=\Theta(m\log m)$ bits, so (5) forces $\Omega(N/\log N)$ \emph{source bit probes} for one output bit if no preprocessing has already paid them. This is not a time lower bound for deciding SAT, since the entire family is immediately recognized as a tractable promise by a scan, and the regular parent formula may simply be retained. An exact preprocessing pass taking $O(m)$ source probes can persist $h$ in $\lceil\log_2 m\rceil$ bits and then answer every future child bit in polylogarithmic time. One may also materialize the short child or use a more sophisticated index. Construction and cache storage must be included. The theorem thus falsifies only \emph{free} source-indexed compaction, not an all-input compiler.
\end{remark}

\section{Correct SAT/UNSAT guest semantics and policy ledger}
For every original CNF source $F$, ordinary cofactor branching has the exact Boolean join
\[
\SAT(F)=\SAT(F\restriction x=0)\lor\SAT(F\restriction x=1).
\tag{7}
\]
A child YES permits early parent YES; parent NO requires \emph{both} child NO. A single short child is not a universal SAT reduction: the four source clauses $(x\vee s y\vee t z)$ for $(s,t)\in\{+,-\}^2$ are satisfiable, while their $x=0$ child is UNSAT, and the $x=1$ child is trivially SAT. Four analogous negative-$x$ clauses appended to them yield a source-authenticated UNSAT proof: resolve twice on $z$, once on $y$ to derive $x$, do the same to derive $\neg x$, then resolve to the empty clause. No free branch-label bit or unsupported NO inference is present.

At controller state $s$, a certified evolving parameter vector may include source record length, actual residual clause count, measured source addresses, a discovered class proof, discovered separator or affine rank, child-bit access time, reentry grammar, cache allocation and peak work/index space. The policy computes each component by paid algorithms; exact class tests can return UNKNOWN. A complete deterministic fallback gives correctness without implying P. For a fixed guest $A$ of unknown exponents $(K,L)$, a hypothetical semantic child-construction and guarded virtual-input simulator making $N^{\gamma+o(1)}$ sequential completed calls on lengths $N^{\lambda+o(1)}$ with per-input-bit reconstruction cost $N^{\delta+o(1)}$ has the \emph{conditional} time envelope
\[
 K'\le\max\{\alpha,\gamma+\delta+\lambda K\},\qquad
 L'\le\max\{\sigma,\zeta,\lambda L\}, \tag{8}
\]
where $\zeta$ is generator scratch and all additional guard/ancestor/failed-policy costs must fit the displayed maxima. This is the previously known virtual-input accounting of LSPV-4, \emph{not a new compiler theorem}. In the one-hot family, the stated stateless child-output bit oracle has $\delta=1-o(1)$ in the probe metric, which is incompatible with the numerical ARC target \emph{if used at a saturated number of guest reads}; a one-time source scan plus an $O(\log m)$-bit cache avoids the repeated tax on this easy family. Neither implies an all-input lower bound.
