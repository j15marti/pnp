## Theorem 610.1 (semantic implication with one support-type guard)

Let \`b\` be any JSON packet accepted by the unchanged /341 fixture verifier, with each in-band original SOURCE \`c.literals\` an array of ordinary nonzero signed safe-integer literal values over its E graph edges. Assume every derivation record with \`p.rule==="AND3"\` has \`Array.isArray(p.support)===true\`. Let F_b be the conjunction of the **actual original signed SOURCE occurrences** in the packet. Then F_b is UNSAT.

This is a *conditional theorem about a subclass of accepted parsed packets*, not a mutation of the historical acceptance predicate.

**Proof.** Interpret an original-source factor as the actual 3-clause truth function on a complete assignment x in {0,1}^E. The checker builds its table from exactly those signed literals and incidence support. Thus every model of F_b satisfies each source factor. Proceed through the accepted chronological paid nodes. Suppose every parent factor's \`support\` is an array of numeric edge indices and its table defines the genuine Boolean formula obtained by conjoining its source ancestry. This holds for all sources. For an AND3 node, the numeric union \`sup\` of its parents contains distinct integer indices. Because \`p.support\` is an Array of the same length, has that many distinct elements and \`Array.includes\` uses exact value equality, and every element of \`sup\` occurs in it, \`p.support\` MUST be a permutation of \`sup\`. Therefore its bit-index table loop exhausts exactly the assignments to the real parent coordinates, and its computed table is exactly the conjunction of its two parent factors for every complete x. This proves the induction.

If this AND3 node additionally exports affine row (M,r), the checker tests the table against the parity of M on all 2^|support| local bit assignments, and checks that for every edge e less than E, M's e-th bit is zero outside the support. Hence on every complete x satisfying the node's factor, parity of the low E bits of M evaluated at x equals r. **No mask-range guard is required for this implication:** interpret all coordinates >=E as zero. For every signed BigInt M, the relevant coefficient vector is M modulo 2^E; two's-complement negative or out-of-range high bits do not change the parity of the low-E coordinates. Bitwise XOR of arbitrary signed BigInts commutes with this projection, and XOR of the already numeric RHS bits is exact mod 2. Every following XOR record is consequently a sound affine consequence of its two row parents. Chronological lookup enforces availability of both premises and fresh IDs forbid self-reference or a proof cycle.

The checker requires the last affine row to have exactly M=0 and r=1. On any assignment satisfying F_b, the induction would imply 0=1, a contradiction. Therefore F_b is UNSAT. QED.

**Corollary (necessary parser defect for a SAT-source accepted packet):** For a signed-integer well-formed in-band SOURCE, any actual checker-accepted SAT-source packet **must** contain at least one AND3 node whose support is not a JavaScript Array. This includes LSPV-3/551, /582, and LSPV-1/609 string-support forgeries. This is necessary, not sufficient: non-array supports can sometimes be semantically harmless.
