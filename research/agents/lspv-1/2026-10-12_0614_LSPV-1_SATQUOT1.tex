\section{Exact endomorphism quotient theorem}

\begin{definition}[Decision-preserving endomorphism]
Let $K$ be a set of valid encodings and $b:K\to\{0,1\}$ a nonconstant
decision map.  An endomorphism is a total map $\tau:K\to K$.  It is
decision preserving if $b(\tau(x))=b(x)$ for every $x\in K$.  Write
$\mathrm{End}_{\mathsf P}(K,b)$ for those endomorphisms computed by one
uniform deterministic polynomial-time machine in encoded input length.
\end{definition}

\begin{theorem}[\texttt{SAT-ENDOMORPHISM-QUOTIENT1}]
\label{thm:quot}
Let $K_0=b^{-1}(0)$ and $K_1=b^{-1}(1)$ be nonempty.  Fix representatives
$y_0\in K_0$ and $y_1\in K_1$, and define
\[
 \kappa(x)=y_{b(x)}.                                      \tag{1}
\]
For every set $\Omega$ and every map $R:K\to\Omega$, the following are
equivalent:
\begin{enumerate}[label=(\roman*),leftmargin=1.7em]
\item $R\circ\tau=R$ for every decision-preserving endomorphism $\tau$;
\item $R\circ\kappa=R$;
\item there is a unique $g:\{0,1\}\to\Omega$ on the attained answers such
that $R=g\circ b$.
\end{enumerate}
In particular $|R(K)|\le2$.
\end{theorem}

\begin{proof}
(i) implies (ii) because $b(\kappa(x))=b(y_{b(x)})=b(x)$.  If (ii) holds,
then for every $x$,
\[
 R(x)=R(\kappa(x))=R(y_{b(x)}).
\]
Define $g(a)=R(y_a)$.  This proves (iii), and nonempty fibers make $g$
unique.  Finally, if $R=g\circ b$ and $\tau$ preserves $b$, then
$R(\tau(x))=g(b(\tau(x)))=g(b(x))=R(x)$, proving (i).
\end{proof}

This is an abstract \EXACT{} theorem.  It neither assumes nor proves a lower
bound, and it does not infer runtime from the two resource values.

\begin{corollary}[Corrected clean core under $P=NP$]
\label{cor:clean}
Let $K=\Hsigned$ use the canonical indexed encoding and let
$b(F)=\SAT(F)$.  Under the \COND{} premise $\SAT\in\mathsf P$, the map
\(\kappa(F)=Y\) when $F$ is satisfiable and \(\kappa(F)=U\) otherwise is in
$\mathrm{End}_{\mathsf P}(K,b)$, where $Y\in K_1$ and $U\in K_0$ are fixed
canonical formulas.  Consequently every resource invariant under all of
$\mathrm{End}_{\mathsf P}(K,b)$ factors through the SAT bit.
\end{corollary}

\begin{proof}
D\"ocker's \KNOWN{} NP-completeness theorem and the explicit SAT/UNSAT clean
blocks already recorded in the corpus ensure both fibers are nonempty.  Fix
one representative in each.  Under $\SAT\in\mathsf P$, run a fixed
polynomial SAT decider on $F$ and emit the appropriate constant string.
Core recognition and canonical parsing are polynomial time and may reject
malformed inputs.  If the assumed decider has time $T_A(N)$ and space
$S_A(N)$, the complete transducer has
\[
 T_\kappa(N)=T_A(N)+N^{O(1)},\qquad
 S_\kappa(N)=S_A(N)+N^{O(1)},                              \tag{2}
\]
and constant output length.  Theorem~\ref{thm:quot} applies.
\end{proof}

Equation (2) deliberately inherits the unknown polynomial exponent.  It is
not an FLMV landing and creates no contradiction.  It shows only that under
the contradiction hypothesis, demanding invariance under all polynomial
SAT-preserving endomorphisms erases every superconstant source distinction.
