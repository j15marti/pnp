\section{CONSTRUCTION OR PROOF ATTEMPT}
Let $x_i$ be block-private Boolean variables, $z$ shared,
$u\in\F^h$ free slack variables, $M\in\F^{d\times h}$ an explicitly
stored matrix, $L_i(x_i)\in\F^{h+d}$ an explicitly sparse linear
syndrome map, and $b(z)\in\F^{h+d}$ an affine output.
The typed input defines
\[
 F=\bigwedge_{i=1}^{B} C_i(x_i,z)\ \land\
 \left[\bigoplus_i L_i(x_i)\oplus(u,Mu)=b(z)\right].       \tag{1}
\]
The variables $u$ occur nowhere outside this systematic XOR term.
Clause parsing and recognition of that restriction are charged.
Define $\pi_M(p,q)=q+Mp$ for $p\in\F^h,q\in\F^d$.
\begin{lemma}[Exact quotient and explicit lift]
For every $v,b\in\F^{h+d}$,
\[
(\exists u)\ v+(u,Mu)=b\iff \pi_M(v)=\pi_M(b).
\]
If feasible, $u=b_{\rm low}+v_{\rm low}$ is the unique lift.
\end{lemma}
\begin{proof}
The low coordinates force the displayed $u$. Substituting it into
the high coordinates gives
$v_{\rm high}+M(v_{\rm low}+b_{\rm low})=b_{\rm high}$,
exactly the quotient equality. This is reversible.
\end{proof}
For fixed $z$ define
$T_i(z)=\{\pi_M(L_i(x_i)):C_i(x_i,z)=1\}\subseteq\F^d$.
\begin{theorem}[Exact syndrome convolution]
\[
 F\in{\rm SAT}\iff
 \exists z:\quad\pi_M(b(z))\in T_1(z)\oplus\cdots\oplus T_B(z).
\]
Every accepting choice of private values lifts through the lemma.
\end{theorem}
\begin{proof}
Necessity follows by projecting each local contribution.
For sufficiency choose independently satisfying assignments
witnessing the XOR sum. Their private variables are disjoint,
and the explicit slack lift enforces the original high-
and low-coordinate equations.
\end{proof}
\begin{theorem}[Charged contractor on an explicitly typed class]
Let encoded parent length be $N$. Assume the grouped source layout
is checked in $N^{1+o(1)}$ time; $B\le N^{1/2+o(1)}$;
each original local block and its sparse syndrome list have length
at most $N^{1/2+o(1)}$; $h\le N^{1/2+o(1)}$; and
$|z|+d\le(1/10)\log_2 N+o(\log N)$.
The $d$-by-$h$ matrix fits in $N^{1/2+o(1)}$ space.
Each local private variable has O(1) listed syndrome contributions,
or an equivalent source-list length bound.
The source order permits sequential block scanning, and
$b(z)$ is computable in $N^{1+o(1)}$ time using
$N^{1/2+o(1)}$ live space.
If SAT decider $A$ runs with simultaneous time and space
exponents $(t,s)$ on ordinary random-access encoded 3-CNF,
then this promised class has an exact decision algorithm with
\[
 t'\le\max\{11/10,3/5+t/2\},\qquad
 s'\le\max\{1/2,s/2\}.                                 \tag{2}
\]
\end{theorem}
\begin{proof}
For each $z$ and each block $i$, test each of the $2^d$
possible local projected syndromes $q$ by calling $A$ on
$C_i(x_i,z)\land[\pi_M L_i(x_i)=q]$.
Expand the $d$ XOR equations into proper ternary XOR-gate
CNF clauses and use fresh local labels.
Sparse coefficient lists and matrix columns permit construction
in $N^{1/2+o(1)}$ bit work and output length per query,
including every variable index, XOR gadget, and source read.
The number of calls is at most
$B2^{|z|+d}\le N^{3/5+o(1)}$.
A Boolean dynamic program of $2^d$ entries convolves
reachable XOR states; its total work is
$O(B2^{|z|+2d})\le N^{7/10+o(1)}$.
Each shared assignment scans the original source once, costing
$N2^{|z|}\le N^{11/10+o(1)}$.
All child construction, failed queries, answers, and recomputation
are charged within that bound. Retain only one block, one
child buffer, $M$, two quotient DP arrays, and counters:
parent space $N^{1/2+o(1)}$.
The sequential child calls add $N^{3/5+t/2+o(1)}$
time and $N^{s/2+o(1)}$ space in the same realization.
The maximum exponents yield (2).
\end{proof}
The theorem permits raw syndrome dimension $h+d$ far beyond
$\log N$, yet only $d$ quotient bits are enumerated.
It is not a SAT-all-input solver; the promised class is
not proved NP-complete under exponent-preserving reduction
and is not closed under recursive child generation.
\begin{lemma}[One-pass transposition barrier]
Let a deterministic one-pass read-only streaming transducer
with append-only output receive independent $L$-bit records
$A_1,\ldots,A_B,B_1,\ldots,B_B$ and be required to output
$A_1,B_1,A_2,B_2,\ldots,A_B,B_B$.
Immediately before reading $B_1$, its state contains at least
$(B-1)L$ bits of information. For $B=L=\Theta(\sqrt N)$
this is $\Omega(N)$ live bits.
\end{lemma}
\begin{proof}
Before the first $B_1$ arrives, the output cannot contain
any $A_i$ for $i>1$ without violating the required order.
The independent tuple $(A_2,\ldots,A_B)$ has
$2^{(B-1)L}$ possibilities, each demanding distinct future
output under the same future input. These prefixes therefore
require distinct machine states. Taking logarithms gives
the bound. Multiple passes, sorting, rewriting the output
contract and arbitrary SAT algorithms are not excluded.
\end{proof}
