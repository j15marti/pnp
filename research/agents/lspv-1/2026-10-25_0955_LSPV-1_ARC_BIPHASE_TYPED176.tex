\section{Concrete grammar and exact two-phase transformations}

A typed source $\mathcal{P}_{m}$ has ports
$p_0,\ldots,p_m$, auxiliaries $a_0,\ldots,a_{m-1}$,
a prescribed bit word $(b_i)_{i<m}$, and at most
a fixed number of endpoint unit pins. Module $i$ is
\[
 (p_i\oplus p_{i+1}\oplus a_i=0)\ \land\ (a_i=b_i),
 \tag{2}
\]
with the XOR equation expanded into the standard four
proper 3-clauses and the second relation as an actual unit
clause. All ports and auxiliaries are ordinary Boolean variables.
A fixed canonical source layout lists the five records per
module followed by endpoint pins; the input is an \emph{ordinary}
CNF, not a magic semantic oracle. A recognizer validates
the whole source in indexed/streaming bit work
$N^{1+o(1)}$ and $N^{o(1)}$ writable/index space, because
the five-record pattern and endpoint pins are canonical
and sequentially checkable. Child renaming is explicit.
For the finite test we serialize ordinary DIMACS and
parse every emitted child independently; the symbolic
FLMV ledger instead uses packed indexed ordinary clause
records with an explicit $O(N\operatorname{polylog}N)$
conversion/source-pass bound. The Python finite test
is not itself a calibrated FLMV machine implementation.

\begin{lemma}[Typed endpoint interface; exact]
For a block of consecutive modules $[u,v)$,
let $R_{u,v}(\ell,r)$ equal $\SAT$ of its ordinary CNF with
$p_u=\ell$ and $p_v=r$, retaining all source endpoint
pins inherited into that block. For any partition into
consecutive blocks $0=i_0<i_1<\cdots<i_g=m$,
\[
 \SAT(\mathcal{P}_m)\iff
 \bigvee_{z_0,\ldots,z_g\in\{0,1\}}
 \bigwedge_{j=1}^{g}R_{i_{j-1},i_j}(z_{j-1},z_j).
 \tag{3}
\]
All children remain in the \emph{same} endpoint-pinned
ordinary-CNF grammar after canonical source-name remapping.
\end{lemma}
\begin{proof}
Every global assignment restricts to a satisfying block
assignment with matching pin values on each shared port,
proving forward implication. Conversely, choose satisfying
block assignments for all relations in (3). Distinct blocks
share no variable other than the named ports
$p_{i_1},\dots,p_{i_{g-1}}$, on which the assignments have
identical chosen $z_i$. Their union is a satisfying assignment
of every original clause, including inherited endpoint units.
An emitted child contains exactly the original source clauses
of its block under bijective local renaming, plus endpoint
units. Thus it meets the same grammar and can undergo a
second real level of subdivision. No assumption that a
general CNF extension or arbitrary continuation respects
the quotient is made.
\end{proof}

There are two concrete state-dependent rules. Phase $\mathsf L$
evaluates the four boundary-pinned children per block and
composes the resulting $2\times2$ Boolean relations from
left to right. Phase $\mathsf R$ computes the same tables
and composes from right to left. Each switches its
orientation for the next recursive child. The boundary
transition is a two-bit Boolean vector update, so it does
not require storing the whole set of boundary assignments.
These are \emph{actual distinct rule choices}; they
are not the hypothetical unconstructed resource matrices
$\operatorname{diag}(2,1/5)$ and
$\operatorname{diag}(1/5,2)$ in ARC175.

\section{Two real levels and simultaneous resource envelopes}

Let the parent contain $m$ modules, hence ordinary indexed
length $N=\Theta(m\log m)$.
Choose consecutive blocks of $\lfloor\sqrt m\rfloor$
modules, with an $O(1)$ remainder block. There are
$g=O(\sqrt m)$ blocks and four ordinary SAT calls per
block. Every child is $N^{1/2+o(1)}$ bits long.
A streaming source validator reads the original source
and endpoint records; one working child is materialized,
fully written including unchanged bits, read by the guest,
and released before the next. Source and child headers,
addressing, arithmetic, original-name-to-local-name
renaming, boundary table updates, switches, failed
recognizer tests and epoch tape tag operations are
charged. A fixed recognizer with source rescans, or
sequential block passes, suffices; no full source copy
is needed. For one same-machine exact guest $A$ with
$(t,s)$ the promised-input envelope is
\[
 t'\le \max\left\{1,\frac12+\frac t2\right\},
 \qquad
 s'\le \max\left\{\frac12,\frac s2\right\}.
 \tag{4}
\]
This upper bound is for the typed promise only. All
guest calls use the \emph{same} $A$ and are sequential.
Peak space includes one child buffer, one active guest,
the source-work indices and live ancestors; it never
mixes one solver's best time with a different solver's
best space. Full guest indexed writes and reads, including
unchanged writes, are charged in the simulated guest
bound. Physical bit flips, bit-time and fixed hardware
gate/wire counts are distinct measures.

At two genuine recursive levels using $\mathsf L$ then
$\mathsf R$, (4) gives the exact valid upper envelopes
\[
 t^{(2)}\le\max\{1,\tfrac34+\tfrac t4\},\qquad
 s^{(2)}\le\max\{\tfrac12,\tfrac s4\}.
 \tag{5}
\]
The child grammar is proved eligible for both levels
by the preceding lemma. This is a real source-dependent
constructor, not a final-root query to the original
guest. In the finite audit, 16 original sources produced
704 genuine first-level and 9,728 second-level calls.
Each leaf received serialized and reparsed ordinary CNF,
independently decided by exact DPLL.

\begin{theorem}[Heterogeneous two-phase reusable ledger;
PROVED/EXACT conditional interface]
Let two \emph{fixed reusable uniform} typed transformations
have, respectively, child count exponents $a_0,a_1$,
size exponents $0<\lambda_0,\lambda_1<1$,
fully charged local-work exponents $r_0,r_1$,
and charged depth-first frame-space exponents
$\delta_0,\delta_1$. Assume exact both-label joins,
hereditary type eligibility, ordinary child access,
and uniform fixed-degree polylogarithmic overhead
over all depths. Then a two-phase macro transition has
\[
 a_{\rm cyc}=a_0+\lambda_0a_1,\quad
 \lambda_{\rm cyc}=\lambda_0\lambda_1,\quad
 r_{\rm cyc}=\max\{r_0,a_0+\lambda_0r_1\},\quad
 \delta_{\rm cyc}=\max\{\delta_0,\lambda_0\delta_1\}.
 \tag{6}
\]
Uniformly reusing the macro to depth
$\Theta(\log\log N)$ and exactly settling bounded-size
leaves yields one typed exact machine with
\[
 t_\infty\le\max\left\{r_{\rm cyc},
 \frac{a_{\rm cyc}}{1-\lambda_{\rm cyc}}\right\},
 \qquad s_\infty\le\delta_{\rm cyc}.
 \tag{7}
\]
\end{theorem}
\begin{proof}
There are $N^{a_0+o(1)}$ first-phase children.
Each has $N^{\lambda_0+o(1)}$ input bits and yields
$N^{\lambda_0a_1+o(1)}$ second-phase children,
proving $a_{\rm cyc}$ and $\lambda_{\rm cyc}$.
Charged local work is $N^{r_0+o(1)}$ at the first
phase plus
$N^{a_0+\lambda_0r_1+o(1)}$ for all reached
second phases. Sequential depth-first execution
keeps one first-phase frame and one nested second
frame, giving the exponent $\delta_{\rm cyc}$;
fixed constant factors and geometric live ancestor
buffers do not increase that exponent.
After $j$ macros the live node count is at most
\[
 N^{a_{\rm cyc}(1-\lambda_{\rm cyc}^j)/
 (1-\lambda_{\rm cyc})+o(1)}.
\]
At a node on depth $j$, local work has exponent
$r_{\rm cyc}\lambda_{\rm cyc}^j$. Multiplying and
maximizing over levels yields the larger of the two
endpoint exponents in (7). Depth
$\Theta(\log\log N)$ makes guest leaves bounded size.
A fixed reusable code and fixed-degree polylog overhead
accumulate only $N^{o(1)}$ along this depth.
The same depth-first proof bounds peak space.
\end{proof}

For the present actual typed program,
$a_0=a_1=\lambda_0=\lambda_1=\delta_0=\delta_1=1/2$
and $r_0=r_1=1$. Formula (6) gives
\[

 r_{\rm cyc},\delta_{\rm cyc})=(3/4,1/4,1,1/2),
 \qquad
 (t_\infty,s_\infty)\le(1,1/2)
 \tag{8}
\]
\emph{on the promised path-XOR family only}.
This agrees with MAIN ARC-UNIFORM-DEEPENING170's
single-reusable-machine theorem and explicitly

a direct parity scan already solves this grammar

\section{The exact all-input fallback firewall}

Define a total wrapper $W_A$ for \emph{all} ordinary
CNFs: validate the grammar; if valid, run the two-level
typed contractor with the same exact guest $A$;
otherwise call $A$ on the \emph{untouched parent source}
of length $N$. This preserves SAT and UNSAT on every
input. However, its only general upper envelopes are
\[
 t_{W_A}\le \max\{1,t\},\qquad
 s_{W_A}\le \max\{1/2,s\},
 \tag{9}
\]
so on any achievable diagonal $(K,K)$ with $K\ge1$
the certificate remains $(K,K)$, not a favorable ARC edge.

\begin{lemma}[Padded-guest falsifier; restricted to this
fallback architecture]
Assume $P=NP$ and let $A_0$ be any fixed polynomial
exact all-input SAT decider. For any sufficiently large
fixed integer $K$, one can construct a uniform exact
guest $A_K$ that agrees with $A_0$ but performs
$\Theta(N^K)$ additional paid time and writable-tape
traffic on each non-typed input. Then $W_{A_K}$
really takes $\Omega(N^K)$ time and
$\Omega(N^K)$ writable/index space on infinitely many
ordinary off-type inputs. Hence this concrete
recognize-or-parent-fallback scheme cannot certify
strict improvement for every achieved diagonal.
\end{lemma}
\begin{proof}
On each off-type input let $A_K$ use a work-tape
counter to visit and write one symbol to
$N^K$ distinct cells before running $A_0$.
The counter, addresses, tape writes and their time
are charged; choose $K$ greater than the fixed
polynomial time/space degrees of $A_0$.
There are arbitrary large valid ordinary CNFs outside
the canonical typed grammar (indeed Horn/Krom
examples suffice). On those inputs $W_{A_K}$
calls $A_K$ on the unchanged $N$-bit source,
so it pays the full delay and tape occupancy.
This is a counterexample to this specific
architectural inference, not to the existence
of another unknown solver-dependent ARC compiler.
\end{proof}

A model-matched, sufficiently cheap streaming
SAT-preserving reduction of \emph{every} ordinary
source to the present path-XOR grammar would also
supply a fast all-input SAT solver by parity
decoding. The FLMV theorem precludes a normalized
composition inside (1). This is a \textbf{KNOWN
THEOREM CONSEQUENCE}, not a discovered
near-linear SAT-to-easy-language reduction.
