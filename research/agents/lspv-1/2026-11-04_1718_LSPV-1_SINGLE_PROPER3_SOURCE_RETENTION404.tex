\section*{Fixed objects and exact quantifiers}
Use a strict canonical signed proper-3CNF encoding with variable bound, authentic source clause labels and accurate header counts; malformed strings retain SAT-label zero. For n\ge3 let a_i=x_{3i-2}, b_i=x_{3i-1}, c_i=x_{3i}, and
\[
B_i=\bigwedge_{s,t\in\{+1,-1\}}(a_i\vee s b_i\vee t c_i),\quad
H_n=\bigwedge_{i=1}^{n}B_i,\quad D=(\neg a_1\vee\neg a_2\vee\neg a_3).
\]
All source clauses and D are proper width three. Each B_i is equivalent to a_i. Hence H_n has 4^n satisfying assignments, while H_n\wedge D is UNSAT. The explicit input encoding has N_n=\Theta(n\log(n+2)) bits.

Define an effectively presented class of total explicitly polynomial-clocked transducers T_P. They copy every valid canonical 3CNF F with declared variable bound at least nine, and append just D if P(F)=1; otherwise they copy F unchanged. They leave malformed inputs unchanged. The added D refers only to existing variables; no aux variable or new rule is introduced. Every source read, predicate step, output byte and peak bit is charged.
\begin{theorem}[Single original 3-clause global soundness index]
\[
GOOD_3=\{\langle P\rangle:\forall x\in\{0,1\}^*\
SAT(T_P(x))=SAT(x)\}
\]
is \Pi^0_1-complete under computable many-one reductions.
\end{theorem}
\begin{proof}
Failure is enumerable: enumerate binary inputs, run each explicitly clocked converter, and compute the finite source/output SAT labels by exhaustive assignments. For hardness, given arbitrary TM M,w, build one fixed polynomial-time predicate P_{M,w}: accept precisely the canonical H_n for which M(w) halts within n simulated steps, and reject other strings. Byte-exact recognition and bounded simulation are polynomial in |H_n|, since M,w are program constants and n=O(|H_n|). If M(w) never halts, T_P is the identity on every string. If M(w) halts after t steps, for any n\ge\max(3,t) the SAT H_n is converted into UNSAT H_n\wedge D. Thus NONHALT reduces to GOOD_3. No per-N advice, semantic oracle or uncharged machine output is used.
\end{proof}
