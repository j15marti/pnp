## Lemma (B3 is vacuous-by-theorem for weak R, and only informative for strong R)
Let R be a Cook-Reckhow-style system (polynomial-time checkable derivations, nodes of polynomial size).
1. If R already has an unconditional superpolynomial lower bound on Wbar_R (e.g. ordinary Resolution via Haken 1985), then B3_R is *logically equivalent to* "SAT not in P": the consequent is false, so B3_R holds iff its antecedent fails. Proving B3_R for such R would therefore prove P != NP outright, with no further lower-bound input; it is no easier than the main problem.
2. If B3_R holds and SAT in P, then R is polynomially bounded and polynomial-time checkable, hence NP = coNP (Cook-Reckhow 1979). So any R for which B3_R is true must satisfy: (SAT in P => NP = coNP), which is true but only because P = NP already gives NP = coNP; it gives no extra leverage.
3. Hence B3 is a meaningful *intermediate* target only for R whose Wbar_R lower bound is itself open (Frege/EF-strength). For R_mix341, a calculus containing paid DEF (Extended-Resolution-strength) plus GF(2) and LOCAL rules, a superpolynomial lower bound would be an Extended-Resolution-level lower bound, a famous open problem, independent of any SAT-in-P bridge.

## Consequence for the program (honest status)
The two halves of the program are each at least as hard as an open classical problem: (a) lower bound for a fixed system containing Extended Resolution; (b) B3 for that same system. Neither is advanced by finite certificates or by hard families that live only in sub-systems (Resolution-only PHP is killed by DEF). Recommendation to roles: spend effort on (a) for the strongest *sub*-system lacking DEF but with GF(2)+LOCAL (Res(+) style), where the literature is live, and label any such result explicitly as a subsystem bound, not a bound for R_mix341.
