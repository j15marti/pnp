\noindent\textbf{Status summary.}
The previous run (PROVLADDER-0001, branch \texttt{ccr-1695bd63-3qbc8a}) proved that no correct polynomial-time SAT decider
has a $V^0$-provable clocked soundness sentence, and asked two questions: is its Step~2 sound, and does a rung above $V^0$
collapse by a known route? Answers:
\begin{enumerate}
\item \textbf{Red team (PROVED/EXACT).} Steps 1--4 are correct. The argument is an instance of the known principle
``if $T$ proves the reflection of a proof system $Q$, then the proof system of $T$ simulates $Q$'' (Krajíček--Pudlák 1989), applied
to the system whose proofs are rejecting tableaux of $D$. The novelty claim is therefore downgraded to \emph{a known principle plus
known lower bounds}. The red team also found that the argument has slack: Step~1 may lose a \emph{quasipolynomial} factor
and still yield a contradiction, because the lower bounds are $\exp(n^{\Omega(1)})$.
\item \textbf{New (PROVED/EXACT relative to cited KNOWN THEOREMS; independent review pending).} Using that slack,
Theorem~\ref{thm:band} kills a strictly wider band: for every $m\ge1$, no correct polynomial-clock SAT decider has clocked soundness
provable in relativized bounded arithmetic $S_2(\alpha)$ plus the mod-$m$ counting axiom scheme $\Count_m(\alpha)$.
The band includes theories that refute Tseitin formulas cheaply (for $m=2$; Remark~\ref{rem:tseitin}), so Gaussian elimination
does not rescue it.
\item \textbf{Frontier (OPEN).} What remains live is the band where the inputs are \emph{comprehended} as strings
(the $V^0(2)$, $\mathrm{VTC}^0$, $\mathrm{VNC}^1$, PV/EF rungs). For these, no 3-CNF lower bound is known; a 2025--2026 literature check
found none for $\mathrm{AC}^0[p]$-Frege on CNFs.
\end{enumerate}
The bridge $\SAT\in\mathsf P\Rightarrow\Wb_R(N)\le\mathrm{poly}(N)$ for every strong fixed $R$ remains OPEN.

\section{Setting (unchanged from PROVLADDER-0001)}
$D$ is a deterministic multitape Turing machine with polynomial clock $p$. The input is a 3-CNF with binary encoding length $n$.
$\mathrm{Tab}_{D,p}(F,Q)$ says that $Q$ is a valid rejecting tableau of $D$ on $F$ of height $p(n)$, and $\mathrm{Sat}(F,X)$ says that $X$ satisfies $F$.
\[
\Snd_{D,p}:\quad \forall F,X,Q\ \big(\mathrm{Tab}_{D,p}(F,Q)\to\neg\mathrm{Sat}(F,X)\big).
\]
In the relativized one-sorted setting, $F,X,Q$ are coded in a single unary relation $\alpha$ together with a size parameter $a$ (with
$n=|F|\le a$). The number quantifiers range over $[0,a^{O(1)}]$, and the matrix is a bounded formula in the language with $\alpha$.
\textbf{Machine model.} Only the existence of the tableau $Q_0$ is used, so any model with local tableau validity works. No
time--space bound is claimed for $D$; the statement concerns provability.

\section{Red team of PROVLADDER-0001, Theorem 1}
\paragraph{Step 1 (translation).} For $V^0$, Cook--Nguyen Thm.~VII.2.3 gives \emph{polynomial}-size bounded-depth PK proofs of
$\|\varphi\|_n$ for every $\Sigma^B_0$ theorem $\varphi$ with free string variables. $\Snd_{D,p}$ is $\Sigma^B_0$ with free
$F,X,Q$ whose lengths are bounded by polynomials in $|F|$, so the translation applies. \emph{Verdict: correct.}
\paragraph{Step 2 (closed evaluation).} After the $F$- and $Q$-atoms are set to the constants $F_0,Q_0$,
$\|\mathrm{Tab}\|(F_0,Q_0)$ is a variable-free formula of depth $O(1)$ and size $\mathrm{poly}(p(n))$. Every true closed formula of
depth $e$ and size $s$ has a depth-$e$ PK proof of size $O(s^2)$, by induction on subformulas with the constants propagated.
Simplifying $\|\mathrm{Sat}\|(F_0,X)$ to $\bigwedge_{C\in F_0}C(X)$ is also a closed-structure computation of the same kind,
because the clause-membership bits are constants. \emph{Verdict: correct.} The depth grows by an additive constant, which is
harmless because the lower bound in Step~4 holds for every fixed depth.
\paragraph{Step 4 (lower bound).} Ben-Sasson 2002 gives $\exp(n^{\Omega_d(1)})$ for Tseitin formulas on bounded-degree expanders.
With 3-regular expanders, these are 3-CNFs with 4 clauses per vertex. \emph{Verdict: correct.}
\paragraph{Credit correction (STALE/OVERSTATED).} PROVLADDER-0001 presented Theorem~1 as possibly folklore. It is exactly the
Krajíček--Pudlák reflection-simulation principle~\cite{KP89}, specialised to the proof system whose proofs of $\neg F$
are $D$'s rejecting tableaux. That proof system is p-bounded iff $D$ decides UNSAT correctly in polynomial time. The theorem
stays PROVED, but it should be cited as an \emph{application} of known results, not as a new theorem.
\paragraph{Slack found.} Step 4's bound is $\exp(n^{\varepsilon})$, while Steps 1--3 only need size $\le 2^{(\log n)^{O(1)}}$
to reach a contradiction. This permits theories whose translations are quasipolynomial, which leads to the next section.

\section{The dead band}
\begin{definition}
Let $\Count_m^N$ be the propositional statement that there is no perfect partition of an $N$-element set into $m$-blocks
($N\not\equiv0\bmod m$). The variables are $Y_e$ for the $m$-subsets $e$. $\neg\Count^N_m$ is a CNF with clauses
$\bigvee_{e\ni v}Y_e$ for each point $v$ and $\neg Y_e\vee\neg Y_f$ for overlapping $e\neq f$~\cite{BR98}.
$F_d+\Count_m$ is depth-$d$ Frege with all substitution instances of $\Count_m^N$ as extra axioms.
$\Count_m(\alpha)$ is the first-order axiom scheme stating the same principle for bounded-definable families.
For $m=1$, read ``$+\Count_1$'' as no extra axiom.
\end{definition}

\begin{lemma}[KNOWN THEOREM, translation]\label{lem:pw}
If $S_2(\alpha)+\Count_m(\alpha)\vdash\varphi(\alpha)$ for a bounded formula $\varphi$, then there are $d,c$ such that the propositional
translations $\langle\varphi\rangle_a$ have $F_d+\Count_m$ proofs of size $\le 2^{(\log a)^c}$
(Paris--Wilkie~\cite{PW85}; Krajíček~\cite[Ch.~9]{Kra95}; used in exactly this form in~\cite[Cor.~9.5]{BR98}).
\end{lemma}

\begin{lemma}[KNOWN THEOREM, separation]\label{lem:br}
If $q$ has a prime factor not dividing $m$, then every depth-$d$ Frege proof of $\Count^N_q$ that may use axiom schemas for
$\Count_m$ has size $2^{N^{\Omega(1/4^d)}}$ (Beame--Riis~\cite[Cor.~9.3]{BR98}, crediting~\cite{BIKPRS96}; for $m=1$ this is
the earlier bound for plain bounded-depth Frege). Checked this run against the text of~\cite{BR98}.
\end{lemma}

\begin{lemma}[3-CNF conversion keeps the lower bound; PROVED]\label{lem:conv}
Let $G'$ be the 3-CNF made from a CNF $G$ by the chain substitution. Each wide clause $(\ell_1\vee\dots\vee\ell_w)$ becomes
$(\ell_1\vee\ell_2\vee z_1)$, then $(\neg z_j\vee\ell_{j+2}\vee z_{j+1})$, and finally $(\neg z_{w-3}\vee\ell_{w-1}\vee\ell_w)$.
Then a depth-$d$ $F_d+\Count_m$ refutation of $G'$ of size $s$ yields a depth-$(d+2)$ refutation of $G$ of size
$\mathrm{poly}(s,|G|)$.
\end{lemma}
\begin{proof}
Substitute $z_j:=\bigvee_{i\ge j+2}\ell_i$, a depth-1 formula, everywhere. Substitution instances of axiom-schema instances are
still instances, and every inference stays valid. Under the substitution, the first converted clause becomes the original
clause $\bigvee_i\ell_i$, which is a hypothesis of $G$. Every other converted clause becomes a tautology of the form
$\neg(\ell\vee B)\vee\ell\vee B$, which has an $O(|B|)$-size depth-3 proof. Clauses of width $\le3$ are unchanged.
\texttt{countladder/count\_3cnf\_control.py} checks the tautology/identity claims by brute force for every chain of width up to 12 in the
test formulas.
\end{proof}

\begin{theorem}[the relativized-counting band is empty]\label{thm:band}
Fix $m\ge1$. Let $D$ be a deterministic machine with polynomial clock $p$ that rejects every unsatisfiable 3-CNF within $p(n)$ steps.
Then $S_2(\alpha)+\Count_m(\alpha)\nvdash\Snd_{D,p}(\alpha)$. This holds unconditionally.
In particular it holds for $I\Delta_0(\alpha)$, which is $V^0$, and for every fragment $S^i_2(\alpha)$, $T^i_2(\alpha)$, with or without $\Count_m(\alpha)$.
\end{theorem}
\begin{proof}
Suppose the sentence is provable. Pick a prime $q\nmid m$ (take $q=2$ if $m$ is odd, and otherwise the least odd prime not dividing $m$).
For $N\not\equiv0\bmod q$, let $F_0$ be the 3-CNF conversion of $\neg\Count^N_q$. It is unsatisfiable, its size is $n=N^{O(q)}$,
and \texttt{count\_3cnf\_control.py} confirms both satisfiability claims on small cases.
By Lemma~\ref{lem:pw}, $\langle\Snd_{D,p}\rangle_{a}$ with $a=\mathrm{poly}(n)$ has an $F_d+\Count_m$ proof of size $2^{(\log n)^c}$.
$D$ rejects $F_0$ within $p(n)$ steps, which gives a tableau $Q_0$. Exactly as in Steps~2--3 of PROVLADDER-0001, set the input and tableau
atoms to the constants $F_0,Q_0$, evaluate the closed formula $\langle\mathrm{Tab}\rangle(F_0,Q_0)$, and simplify $\langle\mathrm{Sat}\rangle$.
This gives an $F_{d+O(1)}+\Count_m$ refutation of $F_0$ of size $2^{(\log n)^{c}}\cdot\mathrm{poly}(p(n))=2^{(\log N)^{O(1)}}$.
By Lemma~\ref{lem:conv}, $\neg\Count^N_q$ itself has a refutation of size $2^{(\log N)^{O(1)}}$. This refutation is a proof of $\Count^N_q$ of
the same size in the same depth class. It contradicts Lemma~\ref{lem:br} for large $N$, because $2^{N^{\Omega(1/4^{d'})}}$ eventually exceeds
every quasipolynomial.
\end{proof}

\begin{remark}[quantitative form, CANDIDATE]
For a correct UNSAT-rejecting $D$ with clock $t(n)$ and $S_2(\alpha)+\Count_m(\alpha)$-provable clocked soundness, where the theory is taken
with size parameter $a=t(n)$ so that the tableau is codable, the same argument gives $2^{(\log t(n))^{c}}\ge 2^{n^{\varepsilon_d}}$, i.e.\
$t(n)\ge 2^{n^{\varepsilon'}}$. So a decider whose correctness is provable in relativized bounded arithmetic with modular counting
is nearly exponential. This is a lower bound for a class of \emph{algorithms defined by how their correctness can be proved}, not for arbitrary algorithms.
The constants are not yet audited; the remark is CANDIDATE.
\end{remark}

\begin{remark}[hostile control: Gaussian elimination does not rescue the band]\label{rem:tseitin}
For $m=2$ the band contains $F_d+\Count_2$, which polynomially simulates Nullstellensatz over $\mathbb F_2$
(Impagliazzo--Segerlind~\cite{IS06}, abstract checked this run). Tseitin 3-CNFs have $\mathbb F_2$-Nullstellensatz refutations of
constant degree: sum the vertex parity constraints, each of which is derivable from its four clauses in degree 3. Their size is
polynomial, so Tseitin is \emph{easy} there (CANDIDATE detail: exact NS size bound not re-derived). This rung therefore already handles
Gaussian-elimination instances, yet Theorem~\ref{thm:band} kills it through $\Count_3$. The obstacle is the modular-counting
mismatch, not ``parity''.
\end{remark}

The dividing line is now sharp and structural. A theory is dead whenever its provable bounded statements about the input translate into
proofs of \emph{bounded depth}, even with modular counting \emph{axioms} and quasipolynomial blow-up. A theory is live once it can
\emph{compute} a modular count as a connective or comprehend new strings. Note the contrast in the S-hierarchy: unrelativized $S^1_2$,
where inputs are numbers and $\Sigma^b_1$-definable sets are formed, is live. The relativized $S_2(\alpha)$, where the input is only an oracle, is dead.
The difference is string comprehension, which is exactly what Step~1 cannot translate to bounded depth.
