## Statements

**S1 (KNOWN, Cook–Reckhow 1979).** There is a Cook–Reckhow proof system R (poly-time verifier V_R(F,π)) with W̄_R ≤ poly iff NP = coNP. So "W̄_R superpolynomial for all R" is equivalent to NP ≠ coNP. For a single R it is strictly weaker, which is why a bridge is needed at all.

**S2 (PROVED/EXACT, elementary; the "circular bridge").** Suppose a polytime decider M for SAT exists. Define R_M: π = empty string, V(F, π) accepts iff M(F) rejects. If M is correct, R_M is sound, complete and has W̄_{R_M}(N) = O(1) in proof length (or poly(N) if cost is verifier time). So Bridge(R_M) holds. But R_M exists as a known system only if SAT ∈ P is already known. A superpolynomial bound on W̄_{R_M} says exactly SAT ∉ P, so that bridge is a restatement of the goal. Consequence: any usable bridge must name an R fixed before M, independent of M.

**S3 (KNOWN; the provability bridge).** Cook 1975 / Krajíček–Pudlák: if PV ⊢ ∀F (M(F)=0 → F∈UNSAT) for a polytime M, then extended Frege (eF) has polynomial-size proofs of every UNSAT F, with size poly(|F|). Hence Bridge_prov(eF): SAT ∈ P via some M with PV-provable soundness ⇒ W̄_eF ≤ poly. Contrapositive: W̄_eF superpolynomial ⇒ no polytime SAT algorithm has PV-provable correctness. This is a genuine theorem, but it concludes only "no provably correct polytime SAT algorithm", not P ≠ NP.

**S4 (the gap; status OPEN/unknown).** The hypothesis SAT ∈ P gives truth of M's correctness, not an R-proof of it. For fixed natural R (resolution, polynomial calculus, Frege, eF) I know of no unconditional proof of Bridge(R) other than via S3's provability hypothesis. Literature: the sentence "PV proves P = NP via f" is itself conjectured false for every f and follows from P ≠ NP (KPT91 shows provability would collapse the T_2(PV) hierarchy). I did not find a result showing Bridge(eF) holds unconditionally, nor an oracle separating it. I claim neither.

**S5 (design consequences).**
1. Charging for strategy search is irrelevant, as the directive says: W̄_R is a minimum over π.
2. Lower bounds on W̄_R for weak R (resolution, bounded-depth Frege, Res(XOR), polynomial calculus) are KNOWN to be superpolynomial for some families. They bridge to nothing, because for those R the unconditional lower bound makes W̄_R superpolynomial regardless, so Bridge(R) is true only if its hypothesis SAT ∈ P is false (S6 below). A usable R must be strong enough that no unconditional lower bound is known.
3. So the programme is squeezed: R must be (a) strong enough that Bridge(R) is plausible, which needs eF-strength, and (b) weak enough that a superpolynomial lower bound could be proved. The only gap left is eF/Frege-type strength, which is exactly where no lower bound is known.

**S6 (PROVED/EXACT, trivial but worth logging).** If R has an unconditional superpolynomial lower bound (e.g. resolution on PHP-type formulas or Tseitin on expanders), then, since Bridge(R) is the implication (SAT ∈ P) ⇒ (W̄_R ≤ poly) with a false consequent, Bridge(R) is equivalent to SAT ∉ P. Both directions are immediate. That is, bridging through a weak system is *equivalent* to P ≠ NP and therefore circular. Use only as a firewall: **a bridge for R is informative only if W̄_R ≤ poly is plausible**.

## Direction recommended to the five roles
- Treat eF-strength (or stronger: a system that formalises polytime algorithm correctness) as the only informative R. Work on the conditional bridge Bridge_prov and on identifying the weakest theory T whose proofs translate into R and that suffices for the hypothesis.
- For lower bounds use: efficient-adversary / anticheckers framework (Khaniki–Pich–Sokolov, CCC 2026, found in literature search), and the Santhanam reduction of Implicit eF lower bounds to circuit lower bounds (arXiv 2405.02232). Both are conditional or reduce the problem to circuit lower bounds, so neither is a lower bound.
- Hard families should be tested against weak R only as firewall controls (S6), not as evidence for the bridge.
