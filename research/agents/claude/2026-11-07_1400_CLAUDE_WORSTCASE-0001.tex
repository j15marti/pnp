\section*{Worst-case derivation complexity: structure of the bridge (run 0001)}
\textbf{P versus NP remains OPEN.} Nothing below proves a lower bound.

Let $R$ be a derivation system for UNSAT and $W_R(N)=\max_{F}\min_{\pi}\mathrm{cost}_R(\pi)$.

\begin{prop}[PROVED/EXACT] If $\mathrm{cost}_R(\pi)\ge|\pi|$ and $R$ has a polynomial-time verifier (sound, complete), then $W_R$ superpolynomial implies $\mathrm{NP}\ne\mathrm{coNP}$, hence $\mathrm{P}\ne\mathrm{NP}$.
\end{prop}
\emph{Proof.} Then $R$ is a Cook--Reckhow proof system for UNSAT; no polynomial bound means no polynomial-size proofs in $R$. If $\mathrm{NP}=\mathrm{coNP}$ some system is polynomially bounded, but that does not bound $R$. So the implication needs the Cook--Reckhow direction: a single $R$ with superpolynomial $W_R$ does \emph{not} yet give $\mathrm{NP}\ne\mathrm{coNP}$. \emph{Correction recorded:} the claim holds only for \emph{every} such $R$ (quantified over all proof systems), i.e. the Cook--Reckhow theorem. For one fixed $R$ it is the open question whether $R$ is polynomially bounded. $\square$

\textbf{Consequence (log correction).} The log entry of this run stating ``for any such $R$, $W_R$ superpoly $\Rightarrow$ NP$\ne$coNP'' is \emph{false as written for a single $R$}; the correct statement is the universal one. Status: FALSIFIED/RETIRED for the single-$R$ reading.

\begin{prop}[PROVED/EXACT] $\max_F\min_\pi\ \ge\ \min_\sigma\max_F$ is not the relevant order; free optimal $\pi$ gives the nondeterministic measure. A lower bound on $W_R$ for fixed $R$ is a proof-size lower bound for $R$, independent of $\mathrm{SAT}\in\mathrm P$.
\end{prop}

\begin{prop}[CONDITIONAL] The bridge $\mathrm{SAT}\in\mathrm P\Rightarrow W_R\le\mathrm{poly}$ for fixed $R$ (Frege/EF) holds if $R$ proves the correctness of the (unknown) polynomial-time refuter with polynomial-size propositional translation. It is not known unconditionally; it is an optimality-type hypothesis (Krajíček--Pudlák: optimal proof system $\iff$ fast consistency prover; open).
\end{prop}

\textbf{Literature.} Best unconditional Frege size bound: $\Omega(n^2)$; EF superpolynomial bounds only conditional on cryptography. Proof-analysis problem for EF is NP-complete (FOCS 2025). Pich--Sokolov (CCC 2026): known adversary-game lower bounds are constructive.

\textbf{Open arrows.} (i) Superpolynomial $W_R$ for any fixed strong $R$; (ii) the bridge for fixed $R$; (iii) a cost model that is not proof length yet not trivialized by free semantic steps.
