The next step yields a matching upper bound for our test family and a precise reason why padding or repeating it cannot produce superpolynomial hardness. This helps distinguish a real lower bound from a construction that only makes the tape head travel farther.

1. The near-quadratic bound is tight on the equality family

Recall
F_{a,b}=A_a\land P_k\land B_b,
\qquad
F_{a,b}\in\mathrm{SAT}\iff a=b,
with
|a|=|b|=k,\qquad N=\Theta(k\log k).

On inputs promised to have this format, a single-tape machine can:

1. Find the next unprocessed literal in A_a.
2. Remember its sign in its finite control.
3. Traverse the tape to the next unprocessed literal in B_b.
4. Compare the signs, mark both positions as processed, and repeat.

The variables occur in the same prescribed order, so the machine need not maintain a large index. Each comparison costs O(N) steps, and there are k comparisons. Hence
T=O(kN)=O\!\left(\frac{N^2}{\log N}\right),
\qquad
S_{\mathrm{total}}=O(N).

Together with the previous crossing-sequence proof, this gives the tight worst-case bound
\boxed{
T_{\mathrm{equality}}(N)
=\Theta\!\left(\frac{N^2}{\log N}\right)
}
along the constructed lengths, for the promised family.

The lower bound still applies to every general 3-SAT decider because those machines must correctly handle these inputs. The matching upper bound concerns the restricted family, not general 3-SAT.

2. Increasing the distance does not increase the exponent indefinitely

Let the middle block have length L, instead of fixing it at \Theta(k\log k). Then
N=\Theta(k\log k+L).

The same crossing-sequence argument gives
T=\Omega(kL),
while the comparison algorithm gives
T=O(kN).

When L\ge k\log k, these match up to constants:
T=\Theta(kL).

However, making L enormous increases the input size too. Since
k\log k\le O(N),\qquad L\le O(N),
this construction cannot force more than
O\!\left(\frac{N^2}{\log N}\right)
through this information-times-distance mechanism.

For example, padding to L=k^3 produces
T=\Theta(k^4),\qquad N=\Theta(k^3),
so the exponent measured against the actual input length becomes
T=\Theta(N^{4/3}),
smaller than before.

This is a concrete failure of padding as a work amplifier.

3. Repeating the comparisons does not solve the problem either

There are two cases:

Construction	Available shortcut
Repeat the same equality constraint	Compare once; reuse the result after checking the repeated structure
Add independent equality constraints	Solve each comparison sequentially

For r independent, separately laid-out blocks of length B, the sequential algorithm takes
O\!\left(r\,\frac{B^2}{\log B}\right),
\qquad N=rB.

That is additive work across blocks. It does not establish a recurrence that squares the previous minimum solving time.

Interleaving blocks could increase travel, but then a new lower-bound proof is required; independence alone supplies no multiplicative gain.

4. A sharper limitation of the communication argument

At any fixed cut in an N-symbol input, imagine two parties holding the initial tape contents on opposite sides. If local computation is unrestricted, one party can send its entire input portion to the other using O(N) bits. The recipient can then decide satisfiability locally, however slowly.

Therefore:
\boxed{
\text{Unrestricted communication complexity at a single input cut is at most }O(N).
}

This does not give a fast SAT algorithm. It explains why a communication lower bound alone cannot capture all the computational difficulty: the communication model gives local computation away for free.

Summing such information requirements over O(N) input boundaries naturally reaches a quadratic scale. To exceed it, we must prove something about the cost of computing with the information, beyond the amount that must cross a boundary.

This agrees with your boundary-DAG report: large boundary tables or many potential continuations do not prove that every solver must construct them.

The resulting research target is now more precise: construct a family where correctness forces expensive computation after information has been gathered, and show that this expense survives arbitrary summaries, rearrangement, and reuse. The equality family gives a rigorous baseline with tight time and linear total space, but neither padding nor independent repetition turns it into that stronger result.
