## Lemma 1 (KNOWN THEOREM shape, Cook 1975 / Krajicek-Pudlak; restated, not re-proved here)
Let M be a poly-time SAT decider and R a system simulating EF. If the reflection statement Corr_M ("M(F)=0 implies F has no satisfying assignment") has uniform poly-size R-proofs (e.g. PV-provable), then for UNSAT F: W_R(F) <= poly(|F|): evaluate M on F (poly-size trace), then instantiate Corr_M. So B3 holds for that (R,M) pair. Cost accounting: trace evaluation plus one instantiation, all charged.

## Lemma 2 (PROVED/EXACT, elementary): B3 for fixed R is exactly a statement about R
B3(R) := (SAT in P => R is p-bounded on UNSAT). By case split: if SAT in P then NP = coNP, so SOME p-bounded system exists; but B3 asks for the preselected R. Hence B3(R) is not implied by P = NP via Cook-Reckhow alone. It is equivalent to "R p-simulates every system on UNSAT, given SAT in P", which needs either an optimal system or a reflection hypothesis. (Existence of an optimal proof system is itself open.)

## Gap analysis (the real obstruction, CANDIDATE diagnosis)
Levin-style universal search gives the SAT side only: output assignments are verified, so "accept => SAT" is checkable. The UNSAT side of M is a completeness claim ("if F is satisfiable M finds it"), and its proof in R is exactly the unproved reflection Corr_M. Any B3 proof for an EF-like R must therefore supply uniform R-provability of that completeness claim for some M, or avoid M via an optimality argument. This agrees with the project's earlier finding that a machine trace alone is not a sound UNSAT certificate.

## Consequence for the program (CONDITIONAL)
A proof of Wbar_R superpolynomial plus B3(R) would give P != NP, but B3 for R of EF strength is as hard as a Pich-Santhanam style feasible-provability hypothesis. A cheaper route may be to pick R so that B3 is true by construction: R_A = EF + explicit reflection axiom for a candidate algorithm. That is allowed only if the axiom is uniform in N and not instance-tailored; it then makes B3 tautological for that A but turns the lower bound into a statement about R_A that no longer targets all A (family failure of generality). Flag as FALSIFIED-as-strategy unless a single R handles all A.

## Falsifiers proposed

2. A short R_mix341 derivation family for any proposed hard family (family failure).
3. Show P=NP does not give EF-provable Corr_M for any M (would need independence-style result; open).
