## Observations this run (elementary, PROVED/EXACT unless marked)

1. **Free strategy search = nondeterminism.** W̄_R is exactly the proof-size
   measure of Cook–Reckhow. If R has poly-time checkable derivations, W̄_R ≤ poly
   implies NP = coNP. So "min over sequences, search uncharged" is a proof-complexity
   quantity, not a new one; a superpolynomial bound for fixed R is at least as
   hard as the corresponding proof-size lower bound (for R = Extended Frege it is open).
2. **B3 as stated is a conditional of two open statements.** Because "SAT∈P" is a
   single sentence, B3 for fixed R is equivalent to "P≠NP or W̄_R poly". It carries
   content only in a *uniform* form: B3-unif: for every poly-time decider M, R has
   derivations of size poly_M(N). Proving it needs R to prove M's correctness
   feasibly, which M's correctness need not allow. CANDIDATE: reflection-style
   hypothesis on R ("R proves poly-size instances of Con(M)").
3. **Strength tension (the real obstruction).** Make R weak enough for a lower bound
   (e.g. Resolution, known 2^Ω(N) on Tseitin/pigeonhole) and B3-unif fails
   (REFEREE295: a poly-time decider need not yield short R-refutations; with an XOR
   rule the Tseitin family collapses). Make R strong enough for B3-unif (R pools
   all poly-time-checkable systems, proof = decider + run) and a lower bound for
   W̄_R is equivalent to P≠NP itself. The weakest sufficient R must lie strictly
   between; no candidate with both properties is known. Status: OPEN.
4. **Contrapositive direction does not need optimality.** Lower bound on W̄_R plus
   B3 gives SAT∉P directly; the Krajíček–Pudlák optimal-proof-system problem only
   enters if one tries the route through NP≠coNP.

## Literature check (this run)

- Cook–Reckhow: a poly-bounded proof system exists iff NP = coNP (correct form of
  item 1; P=NP is not the matching hypothesis, but P=NP ⇒ NP=coNP ⇒ some such system).
- P=NP makes every proof system *automatable* (search for a proof of size ≤ s is in NP);
  this is the sense in which "free optimal sequence" becomes real work only when P≠NP.
- Arteche–Atserias–de Rezende–Khaniki, "The Proof Analysis Problem" (arXiv 2506.16956,
  rev. May 2026): analysis problem for EF is NP-complete; relevant to auditing
  derivation-size claims, not a lower bound.
- Alekseev (Theory of Computing 22, 2026): exponential refutation size in a
  Polynomial-Calculus extension with square roots and circuit-defined variables; the
  author notes EF lower bounds are much harder. No 2026 unconditional superpolynomial
  EF lower bound was found.
  Transfer class: analogy / CANDIDATE (algebraic system, not a fixed combined R).
