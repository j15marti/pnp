\section*{Setup}
Fix a sound, complete, polynomial-time-verifiable proof system $R$ for UNSAT with size cost. For a correct total SAT decider $A$ define the \emph{trace system} $R_A$: a proof of $F$ is the full computation tableau of $A$ on $F$ ending in ``unsatisfiable''; size $t_A(F)$ with $T_A(F)\le t_A(F)\le cT_A(F)^2$. $R_A$ is sound because $A$ is correct (soundness of a Cook--Reckhow system is semantic, not required to be provable). Bridges (as in LSPV-1/418):
$\mathrm{B1}(R)$: $\forall A\,\exists p_A\,\forall F\in\mathrm{UNSAT}:W_R(F)\le p_A(|F|+T_A(F))$; $\mathrm{B3}(R)$: $\mathrm{SAT}\in P\Rightarrow\overline W_R$ polynomial.

\begin{proposition}[B1 is pointwise simulation of all trace systems]
$\mathrm{B1}(R)$ holds iff for every correct $A$ there is a polynomial $p$ with $W_R(F)\le p(|F|+W_{R_A}(F))$ for all UNSAT $F$.
\end{proposition}
\emph{Proof.} Immediate from $T_A\le t_A\le cT_A^2$ and absorbing into $p$. \hfill$\square$

\begin{proposition}[Quantifier order]
$\forall A\,\exists R$ with the B1 inequality is trivial (take $R=R_A$). The target is $\exists R\,\forall A$. If $R$ is an optimal proof system in the Krajíček--Pudlák sense (polynomially bounded relative to every proof system), then $\mathrm{B1}(R)$ holds. Hence the existence of an optimal proof system for TAUT/UNSAT implies $\exists R\,\mathrm{B1}(R)$.
\end{proposition}
\emph{Proof.} $R_A$ is a proof system. \hfill$\square$

\noindent The class $\{R_A\}$ is indexed by a \emph{semantic} set (correct deciders), so a universal system cannot simply list pairs (program, transcript): accepting such a pair is sound only if the program is correct, which is not checkable. This is exactly why free ``semantic answers'' and cross-machine borrowing are retired in the corpus.

\begin{proposition}[B3 with superpolynomial $\overline W_R$ is equivalent to P$\ne$NP]
If $\overline W_R$ is superpolynomial (e.g.\ ordinary Resolution, Haken 1985), then $\mathrm{B3}(R)$ is logically equivalent to $\mathrm{SAT}\notin P$. So proving B3 for such an $R$ proves P$\ne$NP; it is a reformulation, not a weaker target. The only content is proving B3 for an $R$ whose lower bound is \emph{not} already known.
\end{proposition}

\begin{theorem}[KNOWN translation; sufficient hypothesis REF]
Let $R$ be Extended Frege. If $A$ is a polynomial-time SAT decider and the bounded-arithmetic theory PV (equivalently $S^1_2$ for this purpose) proves the UNSAT-side correctness of $A$, then there is a polynomial $q$ with $W_{EF}(F)\le q(|F|+T_A(F))$ for all UNSAT $F$. (Cook 1975; Paris--Wilkie; Krajíček: reflection instances for a PV-provable statement have polynomial-size EF proofs, and the computation of $A$ on $F$ is written with extension variables.)
\end{theorem}
Consequently
\[
\bigl[\overline W_{EF}\ \text{superpoly}\bigr]\ \wedge\ \bigl[\mathrm{SAT}\in P\Rightarrow\exists\text{ poly-time }A\text{ with PV}\vdash\mathrm{Corr}(A)\bigr]\ \Longrightarrow\ \mathrm{P}\neq\mathrm{NP}.
\]
Both hypotheses are OPEN. This is the template used by Pich--Santhanam (arXiv:2312.08163), whose theorem needs additional assumptions (hardness of a function provable in $S^1_2$, plus self-provability of circuit upper bounds); I could only read abstracts, so I do not claim their exact statement. Classification: structural \emph{template}, EXACT for the translation above, ANALOGY for everything else.

\begin{proposition}[Why uniform reflection is circular as a ``weakest'' bridge]
A per-instance reflection statement $\mathrm{Ref}_{A,F}$ (``if $A$ rejects $F$ then $F$ has no model'') has an $R$-proof of size $\mathrm{poly}(T_A(F))$ iff $W_R(F)\le\mathrm{poly}(T_A(F))$ up to the trivial transcript; so any per-instance form of the bridge is B1 restated. Only a \emph{uniform} short proof of $\mathrm{Ref}_{A,n}$ (all $F$ of length $n$) is a genuinely different, stronger, sufficient condition (it is what PV-provability supplies).
\end{proposition}
