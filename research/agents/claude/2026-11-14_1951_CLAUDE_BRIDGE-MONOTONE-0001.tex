\section*{Shared objective (as assigned)}
For a fixed sound and complete refutation calculus $R$ with a cost measure
$\operatorname{cost}_R$,
\[
\Wb_R(N)=\max_{\substack{F\in\mathrm{UNSAT}\\|\langle F\rangle|\le N}}
\ \min_{\pi:F\vdash_R\bot}\operatorname{cost}_R(\pi),
\qquad
B_R:\quad \SAT\in\mathrm P\implies \Wb_R(N)\le\poly(N).
\]
The user's remark is correct and adopted: minimizing over all derivations,
with the optimal sequence given for free, is a valid lower bound on the cost of
\emph{executing any $R$-derivation}. Consequently $\Wb_R$ is exactly the
Cook--Reckhow proof complexity of $R$ (with cost in place of length; see the
byte-domination caveat of REFEREE357). The free-strategy convention moves
\emph{all} of the difficulty into $B_R$, because an arbitrary SAT algorithm
need not emit an $R$-derivation.

\section{Monotonicity}
Write $R\le_p R'$ if $R'$ p-simulates $R$ (polynomial-time translation of
$R$-refutations into $R'$-refutations, cost-polynomially). Write
$\mathrm{LB}_R$ for ``$\Wb_R(N)$ is superpolynomial''.
\begin{lemma}[PROVED/EXACT]
If $R\le_p R'$ then $B_R\Rightarrow B_{R'}$ and $\mathrm{LB}_{R'}\Rightarrow
\mathrm{LB}_R$. Moreover $B_R\wedge\mathrm{LB}_R\Rightarrow\mathrm{P}\neq\mathrm{NP}$.
\end{lemma}
\begin{proof}
$\Wb_{R'}(N)\le q(\Wb_R(N)+N)$ for the simulation polynomial $q$; both
implications follow. The last claim is modus tollens.
\end{proof}
Thus moving to a weaker calculus makes the lower bound easier and the bridge
harder, and conversely: there is no free lunch along the p-simulation order.

\section{Collapse of the bridge for every calculus with a known lower bound}
\begin{lemma}[PROVED/EXACT]
If $\mathrm{LB}_R$ is a theorem, then $B_R\iff\mathrm P\neq\mathrm{NP}$.
\end{lemma}
\begin{proof}
($\Leftarrow$) If $\SAT\notin\mathrm P$ the implication $B_R$ is vacuous.
($\Rightarrow$) Lemma~1.
\end{proof}
\begin{corollary}[PROVED/EXACT, given the cited KNOWN THEOREMS]
For $R\in\{$Resolution, tree-like Resolution, Cutting Planes (Pudlák 1997),
bounded-depth Frege, Polynomial Calculus over any field, Res($\oplus$)
tree-like$\}$, and for any multisign DAG-hypergraph reduction calculus that
is p-simulated by one of them, proving $B_R$ is exactly as hard as proving
$\mathrm P\neq\mathrm{NP}$.
\end{corollary}
\begin{lemma}[PROVED/EXACT; separation form]
If there is an explicit proof system $S$ and an explicit UNSAT family with
polynomial $S$-refutations but superpolynomial $R$-refutations, then
$B_R\iff\mathrm P\neq\mathrm{NP}$.
\end{lemma}
\begin{proof}
The hypothesis gives $\mathrm{LB}_R$ unconditionally; apply Lemma~2. (It also
follows from REFEREE357: under $\SAT\in\mathrm P$, $B_R$ would force $R$ to be
p-optimal, contradicting the unconditional separation.)
\end{proof}
Hence a non-trivial bridge requires $R$ to be a \emph{candidate p-optimal}
system: one not unconditionally separated from any proof system. Today that
means at least Frege/EF strength, where no superpolynomial lower bound is
known (frontier check above).

\section{The theory-indexed bridge that \emph{is} provable}
For a consistent recursively axiomatized theory $T\supseteq\mathrm{PA}$
(or any theory proving the needed $\Sigma_1$ facts), let $R_T$ accept
$\langle F;\,A,c,w\rangle$ iff $w$ is a $T$-proof of
\[
\mathrm{Corr}(A,c):\ \forall G\ [\,A(G)\text{ halts within }(|G|+2)^c
\text{ steps and outputs }1\leftrightarrow G\in\SAT\,],
\]
and $A(F)$ halts within $(|F|+2)^c$ steps with output $0$.
\begin{lemma}[PROVED/EXACT; Krajíček--Pudlák-style]
(i) $R_T$ is polynomial-time verifiable and sound. (ii) If some $A$ and $c$
satisfy $T\vdash\mathrm{Corr}(A,c)$, then $\Wb_{R_T}(N)\le O(N^{c})+O_A(1)$.
\end{lemma}
\begin{proof}
(i) Proof checking is linear in $|w|$; the clocked run is polynomial in $|F|$
by construction since $c$ is part of the proof. $\mathrm{Corr}(A,c)$ is
$\Pi_1$ (all inner quantifiers bounded), and a consistent $T\supseteq Q$ is
$\Pi_1$-sound, so every accepted $F$ is UNSAT. (ii) Fix the constant-size
$w$; each UNSAT $F$ has the proof $\langle A,c,w\rangle$ and verification
time $O(|F|^c)$.
\end{proof}
So the bridge \emph{with provable hypothesis},
$[\exists A,c:\ T\vdash\mathrm{Corr}(A,c)]\Rightarrow\Wb_{R_T}\le\poly$, is a
theorem. The residual gap to $B_{R_T}$ is precisely the scenario
``$\SAT\in\mathrm P$ but not $T$-provably'' (an independence scenario). The
lower-bound half, $\mathrm{LB}_{R_T}$, would imply that no polynomial-time
SAT algorithm is $T$-provably correct. For the extension $R_T^{+}$ that also
accepts EF refutations (sound because $T\supseteq\mathrm{PA}$ proves EF's
reflection), $R_T^{+}$ p-simulates EF, so $\mathrm{LB}_{R_T^{+}}$ would imply
an EF lower bound, beyond the 2026 frontier; Lemma~3(ii) holds verbatim for
$R_T^{+}$. Classification: \textbf{EXACT OBJECT TRANSFER}
(from proof complexity / bounded arithmetic) of the bridge; the lower bound
remains \textbf{OPEN}.
