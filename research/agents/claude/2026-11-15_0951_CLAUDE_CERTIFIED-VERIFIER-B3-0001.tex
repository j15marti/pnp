\section{Target and quantifiers}
This run uses the shared objective
\[
\Wb_R(N)=\max_{F\in\mathrm{UNSAT},\ |\langle F\rangle|\le N}\ \min_{\pi:F\vdash_R\bot}\operatorname{cost}_R(\pi),
\]
with the optimal derivation chosen for free, and the primary bridge (B3 in the 2026-11-02 directive)
\[
\mathrm{SAT}\in\mathrm P\ \Longrightarrow\ \exists C,k\ \forall N:\ \Wb_R(N)\le C(N+1)^k
\]
for one $R$ fixed in advance. Here $\operatorname{cost}_R(\pi)$ is the \emph{encoded bit length} of the certificate. Unit node counts are deliberately not used: Section~4 shows they make a one-node rule trivial.

\paragraph{Corpus context.} LSPV-1/336 proved that B3 follows if $R$ is size-optimal. LSPV-1/462 proved that B3 fails for some sound, complete, polynomially checkable artificial $R_{\rm clock}$, so B3 needs properties of the specific $R$. Prop.~462.3 noted informally that a ``mathematically proved'' polynomial decider gives a polynomially bounded system $T_A$. That system depends on $A$, which is not known in advance. This report builds one $R$, fixed in advance, that absorbs every such $T_A$ at once. It then locates the exact remaining gap between B3 and what can be proved.

\section{The fixed system $R_T$}
\begin{definition}[Theory-certified verifier system]
Fix a recursively axiomatized theory $T\supseteq$ PA (e.g.\ PA or ZFC) with a polynomial-time proof checker. For a TM code $e$ let
\[
\mathrm{Snd}(e):\quad \forall F\,\forall y\,\forall t\ \big[M_e(F,y)\text{ accepts within }t\text{ steps}\ \rightarrow\ F\in\mathrm{UNSAT}\big],
\]
which is a $\Pi_1$ sentence. An $R_T$-refutation of $F$ is a self-delimiting tuple $\pi=\langle e,y,1^t,p\rangle$. The verifier $V_T(F,\pi)$ accepts iff (i) $p$ is a $T$-proof whose last line is literally $\mathrm{Snd}(e)$, and (ii) $M_e(F,y)$ accepts within $t$ steps. Set $\operatorname{cost}(\pi)=|\pi|$.
\end{definition}

\begin{lemma}[Cook--Reckhow validity]\label{valid}
$V_T$ runs in time polynomial in $|F|+|\pi|$. If $T$ is consistent, $R_T$ is sound. $R_T$ is complete, and it p-simulates Extended Frege and every proof system whose soundness, stated in this form, $T$ proves.
\end{lemma}
\begin{proof}
Time: proof checking is polynomial in $|p|$, and the simulation is polynomial in $t$, which is written in unary. Soundness: if $V_T$ accepts, then $T\vdash \mathrm{Snd}(e)$. If $\mathrm{Snd}(e)$ were false, its negation would be a true $\Sigma_1$ sentence, provable in Robinson's $Q\subseteq T$, and $T$ would be inconsistent. So $\mathrm{Snd}(e)$ is true, and the accepting run gives $F\in\mathrm{UNSAT}$. Simulation: for a system $Q$ with checker $e_Q$ and a fixed $T$-proof $p_Q$ of $\mathrm{Snd}(e_Q)$, a $Q$-proof $y$ maps to $\langle e_Q,y,1^{\mathrm{poly}},p_Q\rangle$, where $|p_Q|=O(1)$. PA proves the soundness of EF, and hence of resolution, which gives completeness.
\end{proof}

\section{Main results}
Write $\mathrm{P{=}NP}_T$ for: \emph{some deterministic polynomial-time $A$ decides SAT correctly on all inputs, and $T\vdash\forall F\,[A(F)=\mathrm{UNSAT}\rightarrow F\in\mathrm{UNSAT}]$.} Only the UNSAT-side soundness must be provable. Neither the running time nor completeness has to be provable.

\begin{theorem}[B3 for $R_T$, provable version]\label{b3t}
$\mathrm{P{=}NP}_T\ \Longrightarrow\ \Wb_{R_T}(N)\le C(N+1)^k$.
\end{theorem}
\begin{proof}
Let $A$ run in time $c_AN^k$. Let $e_A$ be the machine that, on input $(F,y)$, simulates $A(F)$ and accepts iff the output is UNSAT. Given the hypothesis, $T$ proves $\mathrm{Snd}(e_A)$: an accepting bounded run of $e_A$ is a halting run of $A$ that outputs UNSAT, and $T$ formalizes this. Call that proof $p_A$; it has constant length. For UNSAT $F$ with $|\langle F\rangle|\le N$, the certificate $\langle e_A,\varepsilon,1^{c'N^{k}},p_A\rangle$ is accepted, and its length is $O_A(N^k)$. The worst case over all $F$ costs nothing extra, because the same certificate shape works for every input.
\end{proof}

\begin{theorem}[Converse up to one reflection jump]\label{conv}
Suppose $\mathrm{SAT}\in\mathrm P$ and $\Wb_{R_T}(N)\le q(N)$ for a polynomial $q$. Then $\mathrm{P{=}NP}_{T^+}$ holds for $T^+=T+\mathrm{RFN}_{\Pi_1}(T)$, uniform $\Pi_1$ reflection for $T$. Consequently $\Wb_{R_{T^+}}$ is also polynomially bounded.
\end{theorem}
\begin{proof}
Let $A$ be a correct polynomial-time SAT decider; nothing about it needs to be provable. Define $A'$ as follows. On input $F$, use $A$ together with search-to-decision self-reduction for the NP predicate ``$\exists\pi,\ |\pi|\le q(|F|),\ V_T(F,\pi)$'' to construct a candidate $\pi$. If $V_T(F,\pi)$ accepts, output UNSAT. Otherwise use self-reduction to construct an assignment, and output SAT if it satisfies $F$. Otherwise output SAT anyway.

$A'$ runs in polynomial time. It is correct: if $F$ is UNSAT, a short certificate exists, $A$ answers each query correctly, and the construction succeeds; if $F$ is SAT, $V_T$ never accepts.

$A'$ outputs UNSAT only after $V_T$ accepts. So its UNSAT-soundness follows in PA from the soundness of $R_T$, i.e.\ from $\forall e\,[\mathrm{Prov}_T(\ulcorner\mathrm{Snd}(e)\urcorner)\rightarrow\mathrm{Snd}(e)]$, which is an instance of $\mathrm{RFN}_{\Pi_1}(T)$. Finally apply Theorem~\ref{b3t} with $T^+$ in place of $T$.
\end{proof}

\begin{theorem}[Exact residual gap]\label{gap}
Assume $\mathrm{SAT}\in\mathrm P$ via a correct $A$. Then B3 for $R_T$ is implied by the single true $\Pi_1$ sentence $S_A$ (UNSAT-soundness of $A$) being a theorem of $T$. In general, for the hierarchy $T\subset T^+\subset T^{++}\subset\cdots$:
\[
\mathrm{P{=}NP}_T\Rightarrow \Wb_{R_T}\ \text{poly}\Rightarrow \mathrm{P{=}NP}_{T^+}\Rightarrow \Wb_{R_{T^+}}\ \text{poly}\Rightarrow\cdots
\]
(the middle arrows hold under SAT$\in$P). No fixed consistent recursively axiomatized $T$ is known to prove $S_A$ for some correct polynomial-time $A$ whenever one exists. This step, $\mathrm{P{=}NP}\Rightarrow\mathrm{P{=}NP}_T$, is exactly what remains of B3 for $R_T$.
\end{theorem}
\begin{proof}
Combine Theorems~\ref{b3t} and~\ref{conv}. For $R_{T+S_A}$, note that $T+S_A$ is consistent because $S_A$ is true.
\end{proof}

\begin{corollary}[What a lower bound for $R_T$ would give]\label{cor}
If $\Wb_{R_T}$ is superpolynomial, then no polynomial-time SAT algorithm has $T$-provable UNSAT-soundness. This is ``$\mathrm{P}\ne\mathrm{NP}$, or SAT$\in$P only through algorithms whose correctness is unprovable in $T$''. It is a strict weakening of $\mathrm{P}\ne\mathrm{NP}$ unless the gap in Theorem~\ref{gap} is closed. Because of Lemma~\ref{valid}, such a lower bound implies superpolynomial lower bounds for EF and for every $T$-certified system. So it is at least as hard as the open EF lower-bound problem.
\end{corollary}

\section{Falsifiers tested}
\begin{enumerate}
\item[F1] \emph{The system might not be fixed, or might hide an oracle.} Rejected. $R_T$ is defined before any algorithmic hypothesis. The only external ingredient is $\mathrm{Con}(T)$, which is used solely for soundness.
\item[F2] \emph{Unit node cost trivializes the system.} Confirmed. Each refutation in $R_T$ is a single node, so $\Wb^{\rm node}_{R_T}\equiv1$. Cost has to be measured in bits, or the verifier's run time has to be charged. The node-count convention of $R_{\rm mix341}$ cannot be carried over to certified-verifier rules. This is a firewall for combined systems such as $R_{\rm mix}\cup R_T$.
\item[F3] \emph{Self-reduction might hide unprovable correctness.} Addressed in Theorem~\ref{conv}. $A'$ checks every UNSAT answer with $V_T$, so its soundness depends only on reflection for $T$, never on $A$. That is why the conclusion uses $T^+$ and not $T$: proving $R_T$'s soundness inside $T$ would contradict Gödel II.
\item[F4] \emph{Conservation of difficulty.} Confirmed as a strategic barrier. Making B3 nearly free forces $R_T$ to be at least as strong as EF, so the lower-bound half becomes at least as hard as EF lower bounds, which are open. Weak systems where lower bounds are known (Resolution, Res(XOR), Tseitin and PHP families in the corpus) are exactly the ones for which B3 fails or is unsupported (LSPV-1/462, LSPV-4/341). This matches Pich--Santhanam, who need extra bounded-arithmetic hypotheses to get from EF lower bounds to P$\ne$NP.
\end{enumerate}

\section{Consequence for the multisign DAG hypergraph program}
The minimal reduced logical state and the minimum work to reach it are well defined for any fixed calculus. With the optimal sequence granted for free, they give a valid lower-bound quantity, as the directive says. Bridge B3, however, constrains the \emph{strength} of the calculus, not how its derivations are found. Any calculus whose minimum work is polynomial under P$=$NP must, on hard instances, be as strong as $R_{T}$ for the relevant $T$, up to the gap in Theorem~\ref{gap}. Concretely, a multisign-hypergraph calculus $R_{\rm hyp}$ supports B3 only if it p-simulates $R_T$, for example by adding one certified-verifier rule with bit-length cost. After that addition, every lower bound for $R_{\rm hyp}\cup R_T$ implies EF lower bounds. Lower bounds for the hypergraph calculus alone (e.g.\ the exact $4h-1$ Tseitin optimum of LSPV-2/341) do not transfer.

\textbf{Next missing implication (OPEN).} One of: (a) close $\mathrm{P{=}NP}\Rightarrow\mathrm{P{=}NP}_T$ for some fixed $T$ (not expected to be provable with current tools; compare the Ben-David--Halevi independence results); (b) prove a superpolynomial lower bound for $R_T$ (at least EF-hard); or (c) find an intermediate $R$ that is strictly weaker than EF on some explicit family, for which a B3-style transfer can still be proved for that family. Option (c) is the only one not ruled out by F4, and it is CANDIDATE only.
