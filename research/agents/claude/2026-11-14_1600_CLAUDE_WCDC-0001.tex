\section{Objects and exact quantifiers}
\begin{definition}
A \emph{refutation system} $R$ (Cook--Reckhow) is a polynomial-time checker $V_R(F,\pi)$ such that
$F\in\UNSAT$ iff $\exists\pi\,V_R(F,\pi)=1$. The charged cost $\mathrm{cost}_R(\pi)$ is the encoded
length of $\pi$, or any cost polynomially related to it (nodes plus all identifiers, signs and
coefficients). For a $3$-CNF $F$ let $w_R(F)=\min_{\pi:V_R(F,\pi)=1}\mathrm{cost}_R(\pi)$ and
\[
 \Wb_R(N)=\max_{F\in\UNSAT,\ |\langle F\rangle|\le N}\ \min_{\pi:F\vdash_R\bot}\mathrm{cost}_R(\pi).
\]
Define the two halves of the program
\[
 B_R:\quad \SAT\in\mathrm P\implies \Wb_R(N)\le \poly(N),\qquad
 LB_R:\quad \Wb_R(N)\ge N^{\omega(1)} .
\]
\end{definition}
The user's multisign DAG hypergraph calculus is an instance: signed hyperedges are clauses,
a reduction step replaces/adds hyperedges by a sound local rule, the ``minimal reduced logical state''
for an UNSAT input is the hyperedge $\bot$, and the minimal work is $w_{R_{\mathrm{ms}}}(F)$.
Two sub-cases must be separated because they behave oppositely:
$R_{\mathrm{ms}}^{-}$ (merge/eliminate/subsume signed hyperedges on the \emph{original} variables; every
step is a resolution or weakening step on clauses, so it is p-simulated by DAG Resolution), and
$R_{\mathrm{ms}}^{+}$ (additionally allows a shared DAG node to name a \emph{fresh} variable defined
by a gate on older nodes, i.e.\ extension; this p-simulates Extended Resolution $\equiv$ EF).

\section{Results}
\begin{proposition}[Bridge squeeze]\label{prop:squeeze}
For every refutation system $R$:
(a) $B_R\wedge LB_R\implies \mathrm P\ne\mathrm{NP}$;
(b) if $LB_R$ is a theorem, then $B_R\iff \mathrm P\ne\mathrm{NP}$;
(c) if $\mathrm P=\mathrm{NP}$, then $B_R\iff R$ is polynomially bounded.
\end{proposition}
\begin{proof}
(a) contrapositive of $B_R$. (b) ``$\Leftarrow$'': if $\mathrm P\neq\mathrm{NP}$, $B_R$ is vacuous.
``$\Rightarrow$'' is (a). (c) the premise of $B_R$ is then true.
\end{proof}
\begin{corollary}
For tree-like Resolution, Resolution, $R_{\mathrm{ms}}^{-}$, Cutting Planes, Polynomial Calculus,
and bounded-depth Frege, $LB_R$ is a KNOWN THEOREM (Haken 1985; Urquhart 1987; Chv\'atal--Szemer\'edi 1988;
Pudl\'ak 1997; Razborov 1998; Ajtai, Beame--Impagliazzo--Pitassi, Kraj\'i\v{c}ek et al.),
so for these systems the ``weakest sufficient bridge'' $B_R$ is \emph{equivalent to} $\mathrm P\neq\mathrm{NP}$.
In the world-ledger taxonomy it is an equivalent reformulation, not a weakening.
A nontrivial two-part program exists only for systems with no known $LB_R$ (Frege, EF, $R_{\mathrm{ms}}^{+}$, \dots).
\end{corollary}

\begin{proposition}[Scope of the free-optimal-sequence concession]\label{prop:free}
Let $A$ be any algorithm whose run on $F$ \emph{writes} (or can be read off in linear time as) an
$R$-derivation of $\bot$. Then $\mathrm{time}_A(F)\ge w_R(F)$ up to the read-off constant,
whatever search $A$ performs. For an algorithm whose run is not an $R$-derivation, no such inequality
follows from the definition.
\end{proposition}
\begin{proof}
The written derivation is one of the $\pi$ in the minimum, and writing it costs at least its length.
For the second sentence see Proposition~\ref{prop:tseitin}.
\end{proof}
So the user's point is \textbf{correct and adopted}: not charging strategy discovery only weakens the
lower bound one would have to prove, and is legitimate. But it is legitimate \emph{only inside the class
of $R$-producing algorithms}. Passing from that class to all algorithms is exactly $B_R$.

\begin{proposition}[Pointwise-transfer falsifier; KNOWN THEOREM transfer]\label{prop:tseitin}
There is a total, correct, deterministic SAT decider $A^\ast$ and an explicit family $T_n$ of UNSAT
$3$-CNFs with $|\langle T_n\rangle|=\Theta(n\log n)$ such that
$\mathrm{time}_{A^\ast}(T_n)=O(n^3)$ while $w_{R}(T_n)=2^{\Omega(n)}$ for $R\in\{\text{Resolution}, R_{\mathrm{ms}}^{-}\}$.
\end{proposition}
\begin{proof}
$T_n$: Tseitin formulas with odd total charge on explicit $3$-regular expanders (every vertex
constraint is a parity of $3$ edge variables, i.e.\ $4$ clauses of width $3$).
Urquhart (1987) and Ben-Sasson--Wigderson (2001, width $\Omega(n)$ $\Rightarrow$ size $2^{\Omega(n)}$)
give the Resolution bound; $R_{\mathrm{ms}}^{-}$ is p-simulated by Resolution. $A^\ast$: if the input
is syntactically a Tseitin encoding (checkable in polynomial time), solve the GF(2) system by Gaussian
elimination; otherwise run exhaustive search. $A^\ast$ is total and correct on all inputs.
\end{proof}
Consequences: (i) the ``pointwise simulation'' secondary target is FALSIFIED/RETIRED for every
resolution-strength multisign calculus; (ii) the requested test ``survive algebraic reasoning / adaptive
strategy switching'' fails for Tseitin and also for pigeonhole (counting); (iii) the worst-case version
survives only because $\max_F$ ranges over families on which \emph{no} algorithm is known to be fast,
which is precisely the open content. Enlarging the calculus to $R_{\mathrm{ms}}^{+}$ removes this
falsifier (Tseitin and PHP have polynomial Frege, hence EF, proofs; Buss 1987, Urquhart) but then
$LB_{R_{\mathrm{ms}}^{+}}$ is the open EF lower-bound problem.

\begin{proposition}[Non-explicit existence is trivial]\label{prop:exist}
$\exists R\ B_R$ is a theorem (classically).
\end{proposition}
\begin{proof}
If $\mathrm P\neq\mathrm{NP}$, any $R$ works. If $\mathrm P=\mathrm{NP}$ via decider $A$, the system
$S_A$ (empty proof; checker runs $A$) has $\Wb_{S_A}(N)=O(1)$.
\end{proof}
Hence every acceptable bridge must be stated for an \textbf{explicit} $R$ fixed in advance, with $B_R$
proved; otherwise the bridge carries no information. This is a required quantifier repair for the shared
objective.

\begin{proposition}[EF bridge under provable soundness; KNOWN THEOREM, Cook 1975]\label{prop:pv}
If $\SAT$ is decided by a polynomial-time $A$ such that Cook's theory $\mathrm{PV}$ (equivalently, for
$\forall\Sigma^b_1$-consequences, $S^1_2$) proves the $\forall\Pi^b_1$ soundness statement
$\forall F,\alpha\,[A(F)=0\to \neg\mathrm{Sat}(F,\alpha)]$, then $\Wb_{\mathrm{EF}}(N)\le\poly(N)$.
\end{proposition}
This is the corpus's B3 route (LSPV-1/357, /361), adopted, not new. The residual obstruction is a
correct polynomial algorithm whose soundness is not PV-provable; Pich--Santhanam (2023/2026) show
how EF lower bounds would imply $\mathrm P\ne\mathrm{NP}$ under further explicit assumptions and also
identify a barrier to improving such results.

\begin{proposition}[Fixed bridge from $\mathrm E=\mathrm{NE}$; KNOWN THEOREM transfer, new to corpus]\label{prop:kp}
Kraj\'i\v{c}ek--Pudl\'ak (1989): if $\mathrm E=\mathrm{NE}$ then a p-optimal refutation system $R^\ast$ exists.
For such $R^\ast$, $B_{R^\ast}$ holds and $LB_{R^\ast}\iff\mathrm{NP}\ne\mathrm{coNP}$. Moreover
$\mathrm P=\mathrm{NP}\Rightarrow\mathrm E=\mathrm{NE}$ (padding), so in the only case where $B_R$ is not
vacuous, a fixed universal bridge system exists.
\end{proposition}
\begin{proof}
Under $\SAT\in\mathrm P$ via $A$, $S_A$ is p-bounded and $R^\ast$ p-simulates $S_A$, so $\Wb_{R^\ast}$ is
polynomial. $LB_{R^\ast}$: $R^\ast$ is p-bounded iff some system is (p-optimality), iff $\mathrm{NP}=\mathrm{coNP}$
(Cook--Reckhow). Padding: a unary/exponential-padding of an NE language lies in NP.
\end{proof}
Assessment: this \emph{closes} $B$ for a fixed system (conditionally on E=NE, and non-explicitly) at the
price of moving the entire difficulty into $LB$, which becomes NP $\neq$ coNP (stronger than the goal).
Existence of p-optimal systems is itself OPEN and faces known relativization barriers (arXiv:2408.07408 and references), and the one-bit-advice version is known (Cook--Kraj\'i\v{c}ek 2007). Classification: EXACT
OBJECT/THEOREM TRANSFER, but a \emph{conservation law}, not progress: across the systems examined, strengthening
$R$ transfers difficulty from $B_R$ to $LB_R$ without removing it.
