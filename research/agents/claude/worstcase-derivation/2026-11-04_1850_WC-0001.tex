\section{Definitions}
A \emph{Cook--Reckhow system} $R$ is a polynomial-time $V_R(F,\pi)$ with $\exists\pi\,V_R(F,\pi)\iff F\in\UNSAT$. A multisigned DAG-hypergraph derivation (nodes: signed clauses/states, hyperedges: inference rules) is an $R$-proof when $V_R$ checks it. $\mathrm{cost}_R(\pi)$ is size (optionally a vector: size, width, peak space).
$$\W_R(N)=\max_{F\in\UNSAT,\,|F|\le N}\ \min_{\pi}\mathrm{cost}_R(\pi).$$
$\mathrm{Bridge}(R):\ \mathrm{SAT}\in P\Rightarrow \W_R(N)\le \mathrm{poly}(N)$.

\section{Results}
\begin{thm}[free strategy = nondeterminism] $\W_R$ is polynomially bounded iff $R$ is a polynomially bounded proof system; then $\UNSAT\in NP$, so $NP=coNP$. Conversely $NP=coNP$ gives some such $R$. 
\end{thm}
\emph{Proof.} Not charging the search for the minimizer is exactly the existential quantifier: guess $\pi$ of size $\le\W_R(|F|)$, verify with $V_R$. Converse is Cook--Reckhow. \qed

\begin{thm}[verifier necessity] If derivations need not be checked by a fixed polynomial-time verifier (e.g.\ cost = running time of the best program per instance, or ``state reduced by any valid-looking sequence''), then $\min_\pi\mathrm{cost}=O(N)$ for every $F$.
\end{thm}
\emph{Proof.} For each $F$ the program ``print UNSAT'' costs $O(|F|)$ to emit. \qed

\emph{Hence the ``minimal reduced state / minimal work'' must be defined through a fixed verifiable rule set.}

\begin{thm}[bridge collapse] Suppose $\W_R$ is unconditionally superpolynomial (resolution, bounded-depth Frege, polynomial calculus, cutting planes with small coefficients and other systems with known exponential lower bounds). Then $\mathrm{Bridge}(R)\iff \mathrm{SAT}\notin P$.
\end{thm}
\emph{Proof.} The consequent is false, so the implication is equivalent to the negation of its antecedent. \qed

\begin{rem} Any proof of the bridge for such $R$ is a proof of $P\ne NP$; so hard-instance work for these systems is evidence about reasoning methods, not part of the bridge. The informative $R$ are those with $\W_R$ unknown (Frege, Extended Frege, stronger).\end{rem}

\begin{thm}[per-algorithm systems] Let $A$ be a correct SAT decider running in time $N^c$. Let $R_A$ be Frege plus extension variables and the axiom instances $\mathrm{Rej}_A(F)\to\neg F$ (the computation of $A$ on $F$ encoded as a circuit; membership is poly-time checkable). Then $R_A$ is a sound Cook--Reckhow system and $\W_{R_A}(N)\le \mathrm{poly}(N)$.
\end{thm}
\emph{Proof sketch.} The proof is the encoding of $A$'s run on $F$ followed by one axiom instance. Soundness uses that $A$ is correct. \qed

\begin{rem} $\mathrm{Bridge}(R)$ for a single fixed $R$ is thus: $R$ $p$-simulates $R_A$ for every correct $A$. The set of correct $A$ is not recognizable, so one cannot union the $R_A$ into one sound system; this is the optimal-proof-system problem (Kraj\'{\i}\v{c}ek--Pudl\'ak; existence is known under $NE=coNE$, open unconditionally).\end{rem}

\begin{thm}[CONDITIONAL, recalled from the literature, not re-derived here] If SAT$\in P$ via $A$ whose correctness is provable in $PV$ (or $S^1_2$), then Extended Frege has polynomial-size proofs of all tautologies, i.e.\ $\mathrm{Bridge}(EF)$ holds along such $A$. \end{thm}
Unconditional $\mathrm{Bridge}(EF)$ is OPEN.

\section{Consequences for the five roles}
Load-bearing open arrows: (i) $\mathrm{Bridge}(R)$ for some $R$ with open $\W_R$; (ii) superpolynomial $\W_R$ for that same $R$. Even then both are needed at the \emph{same} $R$. Resolution-type hard families (Hypergraph role) must additionally be pushed through extension-variable compression. Cost vectors (size, width, space) for the Auditor must be defined through $V_R$ only (Thm 2).
