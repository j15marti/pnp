\section{Target}
For a sound, complete, polynomial-time-checkable refutation system $R$ (a Cook--Reckhow proof system),
\[\overline W_R(N)=\max_{F\in\mathrm{UNSAT},\,|\langle F\rangle|\le N}\ \min_{\pi:F\vdash_R\bot}\operatorname{cost}_R(\pi).\]
The multisign DAG-hypergraph reduction calculus is one such $R$ once its rules are fixed: a ``minimal reduced logical state'' reached by a ``valid reduction sequence'' is a refutation $\pi$, and the minimal work is $\min_\pi \operatorname{cost}_R(\pi)$. Taking the minimum over sequences, which grants free knowledge of the best sequence, is a valid lower-bound convention (PROVED/EXACT, trivially): any lower bound on the minimum bounds every execution of every sequence \emph{inside $R$}. The load-bearing question is the bridge
\[ B_R:\quad \mathrm{SAT}\in\mathrm P\ \Longrightarrow\ \overline W_R(N)\le \mathrm{poly}(N).\]

\section{Results of this run}
\begin{theorem}[PROVED/EXACT; elementary]\label{t:collapse}
If $\overline W_R(N)$ is unconditionally superpolynomial, then $B_R$ is logically equivalent to $\mathrm{SAT}\notin\mathrm P$.
\end{theorem}
\begin{proof}The consequent of $B_R$ is false, so $B_R\equiv\neg(\mathrm{SAT}\in\mathrm P)$.\end{proof}
\begin{corollary}[PROVED/EXACT]
For resolution (Haken 1985: PHP), tree-like resolution, cutting planes, polynomial calculus, bounded-depth Frege, and every other system with a known superpolynomial lower bound, proving $B_R$ is \emph{exactly as hard as} proving $\mathrm P\ne\mathrm{NP}$. If the DAG-hypergraph calculus is p-simulated by resolution (for example, when its rules are local clause or hyperedge merges with no definitional new nodes), then it is in this class. In that case, ``prove the bridge'' is a reformulation, not a weakening, of the target.
\end{corollary}
\noindent So the strategy ``lower bound plus weakest bridge'' has a fixed trade-off. A weak $R$ makes the lower bound provable but turns the bridge into $\mathrm P\neq\mathrm{NP}$ itself. A strong $R$ (Frege, Extended Frege, or stronger) makes the bridge plausible, but then the lower bound is the open Cook--Reckhow problem.

\begin{theorem}[KNOWN THEOREM: Cook--Reckhow 1979]
There is a proof system $R$ with $\overline W_R(N)\le\mathrm{poly}(N)$ if and only if $\mathrm{NP}=\mathrm{coNP}$. Hence $\mathrm{SAT}\in\mathrm P$ implies that \emph{some} $R$ is polynomially bounded. One such system is $R_A$: a proof of $F$ is empty, and the verifier runs the hypothetical algorithm $A$. $B_R$ for a \emph{fixed} $R$ is equivalent to the claim that $R$ polynomially simulates $R_A$ for every polynomial-time $A$ deciding SAT.
\end{theorem}

\begin{theorem}[KNOWN THEOREM; Krajíček--Pudlák 1989 plus padding]
$\mathrm{NE}=\mathrm{coNE}$ implies that an optimal proof system exists, and $\mathrm E=\mathrm{NE}$ implies that a p-optimal one exists. $\mathrm P=\mathrm{NP}$ implies $\mathrm E=\mathrm{NE}$, so under $\mathrm{SAT}\in\mathrm P$ a polynomially bounded p-optimal system exists. If an optimal $R^\ast$ exists, $B_{R^\ast}$ holds (CONDITIONAL). Whether an explicit optimal system exists is OPEN, and Krajíček and Pudlák conjecture that none does. Therefore $B_R$ for a fixed explicit $R$ is not available from known theorems.
\end{theorem}

\begin{theorem}[KNOWN THEOREM, reflection principle (Cook 1975; Krajíček 1995 monograph). The exact theorem number is still to be verified against the primary source.]
If the theory $\mathrm{PV}$ (equivalently $S^1_2$ for this purpose) proves the soundness of a proof system $Q$, then Extended Frege polynomially simulates $Q$.
\end{theorem}
\begin{corollary}[CONDITIONAL, derived from the theorem above]\label{c:pv}
$B_{\mathrm{EF}}$ holds for every polynomial-time SAT algorithm $A$ whose correctness is provable in $\mathrm{PV}$. So a superpolynomial lower bound on $\overline W_{\mathrm{EF}}$ (OPEN) would yield only this: \emph{no PV-provably correct polynomial-time SAT algorithm exists.} That is strictly short of $\mathrm P\ne\mathrm{NP}$.
\end{corollary}
\noindent\textbf{Exact remaining gap (OPEN).} The weakest bridge known to be within reach is $B_{\mathrm{EF}}$ restricted to PV-verifiable algorithms. Two arrows are open:
(G1) a superpolynomial lower bound on $\overline W_{\mathrm{EF}}$ (or on the DAG-hypergraph calculus, if that calculus is at least EF-strong);
(G2) removing the PV-provability hypothesis, that is, handling SAT algorithms whose correctness is true but not feasibly provable.
(G2) is the precise place where ``an arbitrary algorithm need not produce an $R$-derivation'' bites. Granting free choice of the optimal sequence does not touch it.

\section{Computational evidence (COMPUTATIONAL; finite)}
Script: \texttt{research/agents/claude/worst-case-derivation/treelike\_min.py}. Results: \texttt{treelike\_min\_results.json}. The script computes the exact minimum tree-like resolution refutation size as the minimum size of a falsified-clause decision tree, by exhaustive dynamic programming with branch and bound over partial assignments. It runs in under 1\,s.
PHP$^{m+1}_m$, $m=1,2,3$: minimum sizes $5, 21, 85$, which equal $(4^{m+1}-1)/3$ on these three points only. This is not an asymptotic claim; the known bound is $2^{\Theta(m\log m)}$ for tree-like resolution (Beyersdorff--Galesi--Lauria 2010).
Random UNSAT 3-CNF with $6n$ clauses, 12 samples each: maximum minimum sizes $21, 29, 37$ for $n=6,8,10$. At this clause density and these sizes the instances are easy; this is finite evidence only.
These numbers give a sanity baseline for the Builder and Red Team roles. Any claimed minimal DAG-hypergraph reduction must be at most these tree-like values whenever the calculus p-simulates tree-like resolution.
