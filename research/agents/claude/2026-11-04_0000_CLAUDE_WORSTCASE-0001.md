# WORSTCASE-0001: transfer-bridge audit for W_R(N)

Status: P versus NP remains **OPEN**. Nothing below proves a lower bound.

Target: W_R(N) = max over UNSAT F, |F|<=N, of min over derivations pi of cost_R(pi). The minimum is free, so strategy search is not charged.

## Corpus reviewed
AGENTS.md, research/agents/claude/*, the world-ledger README, and the file names of the recent LSPV-1..5 reports and coordination handoffs. I did not re-read every LSPV report in full. No earlier file defines W_R under this name, so I treat the formalization as new here, not as a duplicate.

## Results
**R1 (KNOWN THEOREM, Cook-Reckhow 1979).** For a proof system R with polynomial-time proof verification, W_R(N) <= poly(N) for all N iff R is polynomially bounded. Some such R exists iff NP = coNP. So with the best derivation chosen for free, W_R is exactly proof size, not computation time.

**R2 (PROVED/EXACT, direct from R1).** Any superpolynomial lower bound on W_R for every sound R with poly-time verification would give NP != coNP, hence P != NP. A bound for one fixed R, such as Extended Frege, is a weaker and still open statement. It would not give P != NP, because Cook-Reckhow allows other systems.

**R3 (PROVED/EXACT, the weakest bridge is a statement about specific R).** "SAT in P implies W_R <= poly" can fail to be provable for a natural R even if SAT is in P. Take the polynomial-time solver M and the system R_M, whose proof of F is the run of M on F. R_M is polynomially bounded, but its soundness rests on M being correct, and a fixed natural R such as resolution or EF has no reason to simulate it. EF proves its own consistency-style statements only up to what it can formalize. The bridge for EF is equivalent to the open question "does P = NP imply EF is polynomially bounded?" Without a theory-provability hypothesis, the bridge is not available.

**R4 (FAILED TRANSFER).** If R is defined to include "any deterministic TM computation trace", then cost_R = minimal decider time. The bridge is then trivial, but the required lower bound is just P != NP restated, with no new leverage.

**R5 (CONDITIONAL).** The bridge holds for R = EF if one assumes that EF proves, for some polynomial-time algorithm M that decides SAT, the formalised statement that M is correct. This is the bounded-arithmetic route: it needs the theory to prove M correct, which is stronger than SAT in P.

**R6 (observation, not a theorem).** Hard instances for resolution (Haken, pigeonhole) have short EF proofs. Any hard family for the strong system R must beat Frege and algebraic simulations (Nullstellensatz, PC), and circuit compression via shared DAGs. Shared DAGs already put us at or above Extended Frege strength, where no superpolynomial lower bound is known. This is the existing barrier, not a new one.

**Consequence for the multisign DAG hypergraph.** The proposal fixes a system and a size measure. By R2, a lower bound there is a P != NP-strength claim only if it covers all poly-verifiable R. A bound for one concrete system is a proof-complexity result in its own right, and the natural-proofs and feasible-interpolation barriers apply to it (Krajicek-Pudlak: EF is not automatable under RSA-type assumptions).

## Next target
Choose the one system the multisign-DAG inference rules define, show that it p-simulates, or is p-simulated by, a known system (Frege, EF, PC), and classify it. If it is p-simulated by Frege, any lower bound needs a new Frege lower bound.

## Literature check (2026-11-04)
Cook-Reckhow: NP = coNP iff some proof system is polynomially bounded. Extended Frege has no known lower bound. P = NP makes every system automatable, but automatability is separate from polynomial boundedness. Under a standard assumption EF is not automatable (Krajicek-Pudlak). Depth-d Frege is not automatable unless P = NP (CCC 2024). Sources: [Cook-Reckhow summary](https://www.wikipedia.org/wiki/Proof_complexity), [CCC 2024 automatability](https://drops.dagstuhl.de/storage/00lipics/lipics-vol300-ccc2024/LIPIcs.CCC.2024.22/LIPIcs.CCC.2024.22.pdf), [Buss slides](https://mathweb.ucsd.edu/~sbuss/ResearchWeb/Swansea_July2006/talkslides.pdf).
