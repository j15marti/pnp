\paragraph{Status.} P versus NP remains \textbf{OPEN}. Nothing below proves a lower bound.

\paragraph{Setup.} $R$ is a fixed inference system whose derivation cost is at least the size of a locally checkable derivation DAG; then $R$ is a Cook--Reckhow proof system and $\overline W_R(N)$ is its worst-case minimal proof size (free choice of $\pi$ is exactly ``minimum over proofs''). If checking is not charged, $R$ is not a proof system and nothing below applies. Define $B(R):\ \mathrm{SAT}\in\mathrm P\Rightarrow \overline W_R\le\mathrm{poly}$.

\begin{prop}[Circularity; PROVED/EXACT]
If $\overline W_R$ is unconditionally superpolynomial (Resolution, Res$(k)$, bounded-depth Frege, cutting planes), then $B(R)\iff \mathrm{SAT}\notin\mathrm P$.
\end{prop}
\emph{Proof.} The consequent is false, so $B(R)$ is the contrapositive-equivalent of $\neg(\mathrm{SAT}\in\mathrm P)$. $\square$

So the bridge is useful only for $R$ with no known superpolynomial bound (Frege, Extended Frege), where it cannot be settled by an existing lower bound.

\begin{prop}[Non-uniform triviality; PROVED/EXACT]
$\exists R\,B(R)$. If $\mathrm P\ne\mathrm{NP}$ any $R$ works; if $\mathrm P=\mathrm{NP}$ then $\mathrm{NP}=\mathrm{coNP}$ and Cook--Reckhow gives a $p$-bounded $R$. $\square$
\end{prop}
The content lies in an \emph{explicit} $R$ together with a proof of $B(R)$; the case split gives neither.

\begin{thm}[KNOWN THEOREM, cited from memory --- verify before load-bearing use]
If $A$ decides SAT in polynomial time and $\mathrm{PV}\vdash$ ``$A$ is correct'', then Extended Frege has polynomial-size proofs of all tautologies (Cook 1975; Krajíček--Pudlák).
\end{thm}
The gap to $B(\mathrm{EF})$ is that a ``no'' answer of $A$ carries no certificate, and Levin-style search verifies only ``yes'' answers. Hence the bridge reduces to \textbf{T-REFL (OPEN)}: find the weakest hypothesis on $A$ (reflection / short proofs of $\mathrm{Cor}_A(n)$ in $R$) that yields $B(R)$ for an explicit $R$ of the multisign-hypergraph form, and show that hypothesis is implied by $\mathrm{SAT}\in\mathrm P$ or is unavoidable.

\paragraph{Scope warning.} A superpolynomial bound for one fixed $R$ gives only ``$R$ not $p$-bounded''; it implies $\mathrm P\ne\mathrm{NP}$ only via $B(R)$, and for all $R$ simultaneously it is $\mathrm{NP}\ne\mathrm{coNP}$ (stronger than needed). Feasible-interpolation/natural-proofs barriers (Razborov--Rudich; Krajíček) apply to any circuit-compression hard family.

\paragraph{Literature checked.} Krajíček--Pudlák: optimal proof system $\iff$ fast consistency prover, implied by $\mathrm{NP}=\mathrm{coNP}$, converse open (see Joosten, arXiv:2004.05431). The search did not find any result giving $\mathrm P=\mathrm{NP}\Rightarrow$ explicit $p$-bounded system.
