\noindent\textbf{Status: P versus NP remains OPEN.} No lower bound is claimed.

\section*{Setup}
$R$ is a sound, complete refutation system for UNSAT with a polynomial-time checkable proof predicate (Cook--Reckhow), $\mathrm{cost}_R$ = proof size up to polynomial factors, and
$W_R(N)=\max_{F\in\mathrm{UNSAT},|F|\le N}\min_{\pi:F\vdash_R\bot}\mathrm{cost}_R(\pi)$. Bridge: $B_R:\ \mathrm{SAT}\in\mathrm P\Rightarrow W_R\le\mathrm{poly}$.

\begin{prop}[PROVED/EXACT: circularity] If $W_R$ is a theorem to be superpolynomial, then $B_R\iff \mathrm{SAT}\notin\mathrm P$.\end{prop}
\emph{Proof.} $B_R$ is $P\Rightarrow Q$ with $\neg Q$ true, so it is equivalent to $\neg P$. $\square$
(Applies to Resolution, Cutting Planes, bounded-depth Frege.)

\begin{prop}[PROVED/EXACT: reduction to p-boundedness] $B_R\iff(\mathrm P=\mathrm{NP}\Rightarrow R\text{ is p-bounded})$, and $W_R\le\mathrm{poly}$ iff $R$ is p-bounded, which implies $\mathrm{NP}=\mathrm{coNP}$.\end{prop}
\emph{Proof.} Definitions; $\mathrm{SAT}\in\mathrm P\Rightarrow\mathrm{NP}=\mathrm{coNP}$ by closure of P under complement, so the only content is p-boundedness. $\square$

\begin{prop}[PROVED/EXACT: free semantic answers] If soundness of a derivation is required only on the instance $F$ and not on all inputs, then $\min_\pi\mathrm{cost}=O(1)$ for every $F$ (a one-step rule ``$F\vdash\bot$''). Hence an admissible $R$ must charge a uniform poly-time verification predicate. (This is the retired ``free semantic SAT answers'' route.)\end{prop}

\begin{prop}[CONDITIONAL, folklore/Cook 1975] If some polynomial-time SAT decider $M$ has correctness provable in $PV$ (equivalently its propositional translations have short EF proofs), then Extended Frege is p-bounded.\end{prop}
So $B_{EF}$ follows from ``$\mathrm P=\mathrm{NP}$ via a provably correct algorithm'', not from $\mathrm P=\mathrm{NP}$ alone. Whether $B_{EF}$ holds unconditionally is OPEN.

\section*{Consequence}
Granting the optimal derivation for free is harmless (it only lowers $W_R$, so lower bounds on $W_R$ remain valid), but a lower bound for one fixed $R$ yields $\mathrm P\ne\mathrm{NP}$ only through $B_R$, which is non-circular only for $R$ with no known unconditional bound, where it is open. Pointwise min over programs is time-bounded instance complexity; known hard-instance theorems (Orponen--Ko--Sch\"oning--Watanabe; Fortnow--Kummer) assume $\mathrm P\ne\mathrm{NP}$, hence cannot supply the lower bound.
