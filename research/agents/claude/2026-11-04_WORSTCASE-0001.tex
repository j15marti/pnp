\section{Setup (PROVED/EXACT definitions)}
$R$ is a fixed sound, complete, polynomially verifiable refutation system (the multisign DAG hypergraph rules are one such $R$; a derivation $\pi$ is a DAG). For a cost measure $\mathrm{cost}_R\in\{$size, lines, width, space, time$\times$space$\}$,
$\overline W_R(N)=\max_{F\in\mathrm{UNSAT},|F|\le N}\min_{\pi:F\vdash_R\bot}\mathrm{cost}_R(\pi)$.

\begin{lem}[free strategy is legitimate; PROVED/EXACT]
Any algorithm that outputs an $R$-refutation of $F$ runs in time $\ge \min_\pi |\pi|$ for size-type cost. So $\overline W_R(N)$ lower-bounds every $R$-based search, with no charge for finding the strategy. Conversely $\overline W_R\le\mathrm{poly}$ means UNSAT has polynomial certificates, i.e.\ it is a coNP-side statement (Cook--Reckhow).
\end{lem}

\begin{cor}[PROVED/EXACT, Cook--Reckhow]
If $\overline W_R\le \mathrm{poly}$ for some sound complete $R$ then $\mathrm{NP}=\mathrm{coNP}$. Hence ``$\overline W_R$ superpolynomial for every $R$'' is equivalent to $\mathrm{NP}\ne\mathrm{coNP}$, which is stronger than $P\neq NP$. A lower bound for one fixed $R$ is far weaker, so the bridge is what carries the weight.
\end{cor}

\section{Triviality dichotomy for the bridge (PROVED/EXACT)}
\begin{thm}
Let $R$ have an unconditionally proved superpolynomial lower bound (Resolution, Cutting Planes, bounded-depth Frege, Polynomial Calculus over some fields, etc.). Then the bridge $B_R:\ \mathrm{SAT}\in P\Rightarrow \overline W_R\le\mathrm{poly}$ is equivalent to $P\ne NP$.
\end{thm}
\begin{proof} The consequent is false, so $B_R\iff\neg(\mathrm{SAT}\in P)$. \qed\end{proof}
So for every system with known lower bounds the bridge is a reformulation of the target, not progress (ledger category: ``equivalent to $P\ne NP$''). The bridge is only a nontrivial intermediate goal for systems where lower bounds are unknown: Frege, Extended Frege (EF), and stronger. Any hard family must therefore defeat Frege/EF, not merely Resolution.

\section{The one known partial bridge (KNOWN THEOREM, cited from memory; verify before relying)}
Cook (1975), via the PV$\to$EF translation (Krajíček--Pudlák; Krajíček's \emph{Proof Complexity}, 2019): if $\mathrm{PV}\vdash$ ``$M$ decides SAT correctly'' (the soundness of the $0$-answers is a $\Pi^b_1$ statement), then $\overline W_{EF}\le\mathrm{poly}$.

\begin{cor}[CONDITIONAL, follows from the above]
Define $B^{\mathrm{prov}}_{EF}$: ``$\mathrm{SAT}\in P$ \emph{with PV-provable correctness} $\Rightarrow \overline W_{EF}\le \mathrm{poly}$''. This holds. Hence a superpolynomial EF lower bound proves only: \emph{$P=NP$ is not witnessed by a PV-provably correct algorithm}. It does not prove $P\ne NP$.
\end{cor}
This is the honest content of the ``weakest sufficient transfer'' at present. The missing step to $P\neq NP$ is a feasible-provability principle: if $\mathrm{SAT}\in P$ then some correct algorithm is PV (or EF) provably correct. That is open; it is related to the existence of optimal proof systems (Krajíček--Pudlák) and Levin-style universal search, whose universal algorithm is correct if $P=NP$ but its correctness need not be provable. Status: OPEN.
