\section{Target, as assigned}
For a fixed sound and complete refutation system $R$ (multisign DAG hypergraph
reduction calculus or any other) and a cost $\operatorname{cost}_R$,
\[
\overline W_R(N)=\max_{F\in\UNSAT,\ |\langle F\rangle|\le N}\
\min_{\pi:F\vdash_R\bot}\operatorname{cost}_R(\pi),\qquad
\textbf{Bridge}(R):\ \SAT\in\mathrm P\implies \overline W_R(N)\le\poly(N).
\]
The inner minimum grants the optimal reduction sequence for free. That is
legitimate for a \emph{lower bound on derivations}: discovery cost can only add
work. The gap that remains is a different one: an arbitrary SAT algorithm's run
need not be an $R$-derivation at all. The bridge is exactly that transfer.

\section{Identification (KNOWN THEOREM)}
If $R$ is checkable in polynomial time (proof $\pi$ verified in time
$\poly(|F|+|\pi|)$) and $\operatorname{cost}_R(\pi)\ge|\pi|^{\Omega(1)}$ and
$\le\poly(|\pi|)$, then $R$ is a Cook--Reckhow proof system and
$\overline W_R$ is, up to polynomial distortion, its worst-case refutation-size
function. Cook--Reckhow (1979): some $R$ has $\overline W_R\le\poly$ iff
$\mathrm{NP}=\mathrm{coNP}$. Hence ``superpolynomial $\overline W_R$ for every
$R$'' is \emph{equivalent} to $\mathrm{NP}\ne\mathrm{coNP}$ (a strengthening of
$\mathrm P\ne\mathrm{NP}$); the multisign DAG hypergraph program, once its
rules are fixed and poly-checkable, is an instance of Cook's program.
Consequence: no hypergraph-specific vocabulary can avoid the proof-complexity
barriers below; it can only choose which $R$.

\section{The bridge squeeze (PROVED/EXACT, elementary)}
\begin{proposition}[Vacuity for systems with known lower bounds]
Let $R$ be any system for which $\overline W_R(N)\ge N^{\omega(1)}$ is an
unconditional theorem (tree-like and general Resolution [Haken 1985, Urquhart
1987, Chv\'atal--Szemer\'edi 1988, Ben-Sasson--Wigderson 2001], Cutting Planes
[Pudl\'ak 1997], bounded-depth Frege [Ajtai; Beame--Impagliazzo--Pitassi;
H\aa stad--Risse 2025], Polynomial Calculus [Razborov 1998]). Then
$\textbf{Bridge}(R)\iff\SAT\notin\mathrm P$.
\end{proposition}
\begin{proof}
($\Rightarrow$) $\textbf{Bridge}(R)$ and $\SAT\in\mathrm P$ give
$\overline W_R\le\poly$, contradicting the lower bound; so $\SAT\notin\mathrm P$.
($\Leftarrow$) If $\SAT\notin\mathrm P$ the implication is vacuously true.
\end{proof}
So for every presently \emph{lower-bounded} $R$, proving the ``weakest
sufficient bridge'' is not weaker than P$\ne$NP: it \emph{is} P$\ne$NP
(World-Ledger rule: a reformulation, not progress). In particular a multisign
hypergraph calculus whose rules are resolution-like (signed hyperedge merge on
one pivot, subsumption, unit propagation) is p-simulated by Resolution, and for
it the bridge is P$\ne$NP verbatim.

\begin{proposition}[Where the bridge is plausible, the lower bound is open]
If $\SAT\in\mathrm P$ via an algorithm $A$ whose soundness
$\forall F\,(A(F)=0\to F\in\UNSAT)$ is provable in Cook's theory $PV$, then
$\overline W_{EF}(N)\le\poly(N)$ (Cook 1975 translation; KNOWN THEOREM). Every
proof system $Q$ is p-simulated by $EF+\mathrm{Ref}_Q$ (KNOWN THEOREM).
\end{proposition}
Thus \textbf{Bridge}$(EF)$ holds CONDITIONALLY on $PV$-provable correctness of
the hypothetical algorithm, and \textbf{Bridge} holds for a p-optimal system
if one exists ($\mathrm P=\mathrm{NP}\Rightarrow\mathrm E=\mathrm{NE}
\Rightarrow$ p-optimal systems exist, Kraj\'\i\v{c}ek--Pudl\'ak 1989, but the
witness system depends on $A$ and is not fixed in advance). For Frege and $EF$
no superlinear-beyond-quadratic refutation-size lower bound is known; this run's
literature check (ECCC 2025/080, 2025/098, 2025/134; H\aa stad--Risse 2025;
Je\v{r}\'abek 2025) found no 2025--2026 superpolynomial Frege bound.

\paragraph{Squeeze.} For every fixed $R$ currently known: either the lower bound
is known and the bridge is equivalent to P$\ne$NP, or the bridge is available
(conditionally) and the lower bound is a famous open problem (Frege/EF).
The only unconditional route through $\overline W_R$ requires a \emph{new}
superpolynomial lower bound for a system that p-simulates the trace system of
every polynomial-time algorithm whose correctness is feasibly provable --- at
least $EF$ strength. The extension rule is exactly the multisign DAG's
ability to name shared sub-hyperedges; dropping it returns to the vacuous case.

itself open. Small exact minima are evidence about tree-like Resolution only and
imply nothing asymptotic.
