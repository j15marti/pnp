# WCDC-0001: formalizing W_R and the transfer bridge

Status: nothing here proves P != NP. P vs NP remains OPEN.
Roles covered by this single run: lower-bound lead, reduction builder, certificate/hard-family check, resource audit, red team (one agent, so not independent).

## Setup (PROVED/EXACT, definitional)
R is a Cook-Reckhow system: proofs checkable in time poly(|pi|+|F|), sound and complete for UNSAT. Cost = size (or time/peak-space of the DAG; all are poly-related to size for DAG-like R, except space, which is <= size).
The multisign DAG hypergraph is a representation of derivations. "Reduced logical state" = a set of derived nodes; the min over derivation sequences is a proof-complexity measure. Free choice of the optimal pi means W_R is exactly the optimal-proof-size function. Charging for search could only raise cost, so lower bounds on W_R are unaffected (the user's remark holds).

## Result 1 (PROVED/EXACT): poly W_R only implies NP = coNP
If W_R(N) <= poly(N) then UNSAT is in NP (guess pi, verify), hence NP = coNP. Conversely a lower bound on W_R shows only that R is not polynomially bounded; it says nothing about NP vs coNP unless some bridge is added.

## Result 2 (PROVED/EXACT): the bridge is circular for any R with a known lower bound
Let R have an unconditional superpolynomial lower bound (e.g. Resolution: Haken 1985; also Cutting Planes, bounded-depth Frege, Polynomial Calculus). Then W_R is superpolynomial, so the implication B_R: "SAT in P => W_R poly" is logically equivalent to "SAT not in P". So B_R cannot be proved by a method independent of P != NP; proving it already proves P != NP (SAT not in P gives P != NP).
Consequence: hard-family constructions for weak systems (Tseitin, PHP, expander-based) are useful only as controls. The programme needs R for which the lower bound is unknown (Frege, Extended Frege), and the bridge must be proved there.

## Result 3 (KNOWN THEOREM style, CONDITIONAL): when the bridge holds for EF
Claim: if some polynomial-time A decides SAT and the completeness statement "phi(a)=1 -> A(phi)=1", suitably the search version, is provable in PV_1 (Cook's equational theory), then EF has polynomial-size refutations of every UNSAT formula. Sketch: PV proofs translate to polynomial-size EF proofs of the propositional instances (Cook; Krajicek, Bounded Arithmetic, Propositional Logic and Complexity Theory). For UNSAT F, EF evaluates A(F)=0 as a polynomial-size trace, and with the translated implication derives that no assignment satisfies F. I did not re-derive the translation details here; treat this as imported literature, not new.
So "P = NP, with a PV-provable algorithm, implies W_EF poly". Hence a superpolynomial lower bound for W_EF would show that no PV-provably-correct polynomial SAT algorithm exists. This is a known, weaker conclusion than P != NP, and it is the honest form of the bridge. Removing the provability hypothesis is the open Cook-Reckhow-type problem (related to whether EF is p-optimal; the existence of p-optimal systems is open, with Krajicek-Pudlak conditional results: E = NE gives p-optimal systems). A Levin-style universal prover does not fill the gap because soundness of the guessed algorithm is not checkable.

## Result 4 (PROVED/EXACT, trivial but useful): fixing the algorithm is fine, fixing R is the issue
For each fixed poly-time A deciding SAT there is a system R_A (proof = trace of A) with W_{R_A} poly. The bridge needs one R chosen before A. A direct-product/portfolio argument over all A hits the same uniformity wall as the corpus's UWI work (see AGENTS.md ledger rows L29-L37), which is consistent.

## Hostile-control checklist
- Resolution, shared DAGs: lower bounds known, bridge circular (Result 2).
- Algebraic (PC/IPS), circuit compression (Frege/EF): lower bounds open; no hard family known for EF; natural-proofs-type obstacles for Frege lower bounds are discussed in the literature (Razborov; Krajicek) and are not resolved here.
- Adaptive strategy switching: covered by taking R = union of systems, but a union of finitely many systems is still a fixed R with the same status; unbounded unions are a new R and need soundness.
