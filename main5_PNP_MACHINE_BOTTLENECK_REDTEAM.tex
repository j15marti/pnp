\section{Model, quantifiers and authentic source}
For each fixed constant \(C\ge2\) and fixed total deterministic table
\(\delta:[C]\times\{0,1\}\to[C]\times\{0,1\}\), for every \(B\ge1\),
every \(x\in\{0,1\}^B\), and every \(1\le L\le B\), a single
uniform conventional multitape machine with a read-only \emph{locally moving}
input head can produce
\[
F_\delta(x)=[\,2\sum_{i=1}^B m_i\ge B\,],
\quad (q_i,m_i)=\delta(q_{i-1},x_i),\quad q_0=0.
\]
Use the binary word \(\gamma(B)\,0\,x\), with Elias gamma
\(\gamma(B)=0^{t-1}\operatorname{bin}(B)\) and
\(t=\lfloor\log_2 B\rfloor+1\). The total encoded input length is
\(N=B+2\lfloor\log_2 B\rfloor+2\).
Incorrect headers, delimiters, lengths or symbols are rejected after
charged source scanning. Computing \(B,L\), indices, and addresses uses
\(O(\log N)\) scratch bits. This is a source-authenticated
\emph{canonical blank-start} class, not arbitrary preloaded checkpoints.

The underlying physical service uses a STATE work symbol written
at every source step, a MOVE head advancing iff \(m_i=1\), and a
separately paid LENGTH head for the final \(2p_B\ge B\) comparison.
Its complete decider has \(T_{\rm orig}=\Theta(B)\) and
\(S_{\rm orig}=\Theta(B)\) visited writable cells. The independent
program checks semantic source transitions and virtual accesses, not
a gate-level Turing transition microcode for this original comparator.

\section{Verified exact ordered-source-head lemma}
Let \(R=\lceil B/L\rceil\),
\(w=\lceil\log_2 C\rceil+\lceil\log_2(B+1)\rceil\), and
\(B=d_1+\cdots+d_R\) with \(d_i=L\) except a final shorter block.
Store the genuine \((q_a,p_a)\) records at
\(a=0,L,\ldots<B\), on a sequentially headed writable anchor tape.
For the \emph{fixed} query order \(j=1,\ldots,B\), start each replay
at \(a_j=L\lfloor(j-1)/L\rfloor\) and finish at input position \(j\).
The true paid input-head movements \emph{within the queries} are exactly
\[
H_{\rm query}
=\sum_{i=1}^R\sum_{t=1}^{d_i}[(t-1)+t]
=\sum_{i=1}^R d_i^2\le BL.
\]
Indeed, after query \(j-1\) the head is at \(j-1\), while
the required anchor is \(t-1\) symbols behind; replay advances \(t\)
symbols. At each block boundary both positions agree. The entire
authentication pass moves the head \(N\) symbols; rewinding from the
endmarker to the payload start costs \(B\), so
\[
H_{\rm total}=N+B+\sum_i d_i^2.
\]
Exact source symbol reads are \(N+\sum_i d_i(d_i+1)/2\).
The actual anchor tape is written once and scanned as a sequential
tape for each of \(Q=B\) queries; its movement/read tax is
\(O(BRw)\), not a free random-access record lookup.
The evaluator adds the returned \(m_j\) to its \(O(\log B)\)-bit
accumulator. After query \(j\) the accumulator equals \(p_j\) by
induction. Hence its final YES/NO label is correct for every source.

The \emph{same sequential-input implementation} consequently satisfies
\[
\boxed{\quad S=O(Rw+\log B),\qquad
T=O\bigl((N+BL+BRw)\operatorname{polylog}(B+2)\bigr).\quad}
\]
All parsing, head positions, queries, checkpoint copying, integer
arithmetic and output are included. With
\(L=\lceil\sqrt B\rceil\), this is
\(S=O(\sqrt B\log B)\) and
\(T=O(B^{3/2}\operatorname{polylog}B)\).
The theorem is PROVED/EXACT \emph{for this fixed ordered streaming class};
external mathematical review remains OPEN. No general Tree Evaluation,
arbitrary checkpoint provider, DTISP exclusion or SAT lower bound follows.
In fact a direct one-pass algorithm legally computes the same result
in \(O(B\operatorname{polylog}B)\) time and \(O(\log B)\) writable space.

\paragraph{Restricted all-head-oblivious construction.}
After a complete input scan and rewind, stage $j$ returns
the INPUT head to the beginning of the word, traverses the
fixed-length prefix to gate $j$, reads the opcode, then traverses
both $n$-bit operand masks. The VALUE work head, starting
at zero, sweeps all $n$ work cells against the first mask,
rewinds, sweeps all $n$ again against the second, seeks to
cell $j$ to write its computed bit, and returns to zero.
Both genuine head itineraries depend only on $n,j$, never
on the gate data. Induction shows that all written work bits
are exactly the corresponding gate values. The charged
movement and access ledger is
\[
\begin{aligned}
H_{\mathrm{INPUT}}&=2N+2n(n+1)(n+2),&
H_{\mathrm{VALUE}}&=4n(n-1),\\
Q_{\mathrm{read}}&=2n^2,&Q_{\mathrm{write}}&=n .
\end{aligned}
\]
Each row-$j$ input round trip reaches position
$n+1+(j+1)(2+2n)$; the VALUE head performs three
$(n-1)$-moves sweeps and a seek to $j$ plus return.
All counters, index arithmetic and gate operations can be
padded with full-width fixed-duration scans, so every
scratch-head movement can also be scheduled solely by $n$.
One actual uniform locally headed implementation therefore
obeys jointly
\[
\boxed{T=O(n^3\log(n+2)),\qquad
S_{\mathrm{peak}}=O(n+\log(n+2)).}
\]
The exact INPUT/VALUE \emph{macro} trajectories were
independently replayed; native finite-transition scratch-head
padding has a symbolic proof, not executed microcode.

\paragraph{P-completeness, correct scope.}

logspace many-one reductions (Ladner 1975).

\section{Independent C1f address-domain theorem and exact-count bridge}
Fix \(m,v\ge1\), \(\ell\ge\max(1,\lceil\log_2m\rceil)\),
a total map \(D:\{0,1\}^{\ell}\to(\{\pm1,\dots,\pm v\})^3\),
and a candidate assignment \(a\in\{0,1\}^v\).
Let \(B_a(i)\) mean all three signed literals of \(D(i)\) evaluate
false under \(a\), and let
\[
 G_a(i)=[i<m]\wedge B_a(i).
\]
Then, with \(\phi=\bigwedge_{i=0}^{m-1}D(i)\),
\[
 \#G_a=\sum_{i=0}^{m-1}B_a(i),
 \qquad \#G_a=0\ \Longleftrightarrow\ a\models\phi.
\]
This is PROVED/EXACT for this model. Each index contributes once
only when authentic and violated. Functional four-row Tseitin constraints
for every shared binary gate force a unique gate extension, hence their
positive-output CNF counts exactly \(\#G_a\).
The TMR-1 all-input normalizer also preserves that count.

\paragraph{Smallest legal false-positive without the guard.}
For \(m=1,\ell=v=1\), put \(D(0)=(x_1,x_1,x_1)\),
\(D(1)=(\neg x_1,\neg x_1,\neg x_1)\), and \(a_1=1\).
The authentic formula is satisfied, but unguarded \(B_a\)
has exactly one accepting address, namely the unused index 1.
The guarded circuit has count zero. Therefore a generic clause
decoder whose \(2^\ell-m\) spare addresses are undefined cannot

\section{Independent pinned input-length absorption: C1e/056}
The original Anthropic Lean \texttt{MainResults.encInput} promises
$k\ge1$, $n\ge4$, $m\ge2$, \texttt{AllOccur} and \texttt{IsKCNF};
in particular every ordered clause list is distinct.
Its actual low-bit-first input uses unary $k$ and unary $n$
and $k$ fixed-width slots for each clause.
With
\[
 w=\lfloor\log_2(2n)\rfloor+1,\quad
 B=k+n+2+mk\,w,\quad
 E=\min\left\{\frac{km}{\sqrt{\log_2m}},
 \frac{k^2n\log_2\log_2n}{\sqrt{\log_2n}}\right\},
\]
our independent all-promised-input lemma proves the explicit
uniform bound
\[
 \boxed{\quad B\le2^{8E}\quad}.
\]
The constant eight is independent of $k$. To prove it, write
$x=km\ge n\ge4$. Then $B\le x(\log_2x+5)\le x^3$,
so $\log_2 B\le3\log_2x\le3E_m$ using
$2^y\ge y^{3/2}$ for $y=\log_2x\ge2$.
By distinct ordered clauses, $m\le(2n+1)^k$.
For $y=\log_2n\ge2$,
$\log_2 B\le3k[1+\log_2(2n+1)]
\le(15/2)ky\le8E_n$,
using $2^y\ge y^{3/2}$ again and $\log_2y\ge1$.
Thus the full unary headers, all original clause slots,
$n+1$ output bits and any fixed-polynomial front end
fit inside $2^{O(E)}$ time on a standard bit machine.

When the conditional pinned finite-stack bound is
$t\le\lfloor2^{CE}\rfloor$, the fixed physical TMR-1/058
simulator with authentic input loading costs on the
\emph{same execution}
\[
 T_{\rm phys}=O_M(B+t+1)
  =O_M\bigl(2^{\max(C,8)E}\bigr),
 \qquad S_{\rm peak}=O_M(B+t+1).
\]
No sublinear-space implication is claimed; this is a

\section{Independent TMR-2 OR-of-bilinear source-to-count extension /057}
For every fully authenticated canonical ASCII source with genuine binary
AND edge gates \(E(u,v)=x_uy_v\), XOR gates depending only on edge/XOR
gates, and a top-level shared OR DAG with \(q\) distinct non-OR layer
roots, we independently close the named
\emph{D2-OR-OF-BILINEAR-LAYERS} source-to-count dependency at
the exact declared grammar. Root-reachable original gates and
variable use are checked, records may be permuted, repeated children
and arbitrary fan-out are preserved, and the mandatory \(n\le 2g\)
guard is checked before allocating \(n\)-sized arrays.
An OR-DAG visited by original gate ID reveals \(q\) actual disjuncts
without unfolding duplicate OR subgraphs. Genuine GF(2) reverse
propagation through shared XOR DAGs constructs
\(A_1,\ldots,A_q\in\mathbb F_2^{a\times b}\) so that
\[
F(x,y)=\bigvee_{i=1}^q[x^\top A_i y=1\pmod2].
\]
For every \(J\subseteq[q]\), set \(A_J=\bigoplus_{i\in J}A_i\)
and \(r_J=\operatorname{rank}_{\mathbb F_2}(A_J)\). Orthogonality of
the binary characters gives the \emph{exact original-input} identity
\[
\boxed{\quad
\#F=2^{n}-2^{-q}\sum_{J\subseteq[q]}2^{n-r_J},
\qquad n=a+b.
\quad}
\]
Indeed, the indicator that all \(q\) layers reject equals
\(2^{-q}\sum_J(-1)^{x^\top A_Jy}\).
For any \(J\), summing first over \(y\) leaves
\(2^{b}\) on the kernel of \(A_J^\top\) and zero otherwise, hence
\(2^{n-r_J}\). Divisibility by \(2^q\) is automatic.
A streamed Gray-code traversal and exact Gaussian elimination
compute the sum without storing exponentially many matrices.
One single fixed, locally headed deterministic authenticated
source-to-count machine, including all source seeks, graph discovery,
sharing, \(q\) coefficient extractions, matrix updates, integer
precision and output, admits the conservative joint bit-machine
resource ledger
\[
\boxed{\quad
T(N,q)=O(2^qN^8),\qquad
S_{\mathrm{peak}}(N,q)=O(N^3),\qquad q\le g\le N.
\quad}
\]
This is polynomial in complete input bit length \(N\) for
\(q=O(\log N)\), and \emph{not} a general Circuit-SAT speedup.
One wire per original gate and three uniquely zero-pinned
variables yield a proper, strict, count-preserving \(3\)-CNF
with \(V=n+g+3\) and \(m\le4g+8\); repeated-child XOR is forced
zero and repeated-child OR is wire equality.

\paragraph{Counterexample to individual-rank-only normalization.}
The authentic three-input circuits with disjuncts
\(x_1y,x_2y\) and \(x_1y,x_1y\) both have individual-rank
vector \((1,1)\), but their accepting assignment counts are
respectively \(3\) and \(2\). In the second source the unused
original \(x_2\) is genuinely reached by a canceled
\(x_2y\oplus x_2y\) gate and is not a free phantom input.
Their subset-rank multisets are respectively \(\{0,1,1,1\}\)
and \(\{0,1,1,0\}\). Thus the individual ranks alone
are insufficient; the combined-subset ranks correctly recover
both counts. No hard assignment indicator or general SAT work
bound is inferred.

\section{Independent strict-C local reduction and SAT time--space transfer /058}\label{sec:058}
\paragraph{Object and quantifiers.}
The proof lead maps every fixed-width indexed \(3\)-CNF \(F\) with
\(v,m\ge1\) to a graph \(H_3\) (base triangle \(T,F,B\); complementary
literal pairs; per clause a fresh pair \(s,\bar s\) and the split
\(\mathrm{NAE}(a,b,s)\wedge\mathrm{NAE}(\bar s,c,F)\) via two triangles),
then to \(H_5\) by two universal adjacent apices, and then to the strict-C
instance \(K(F)\) with one fresh head per edge, where
\(R(a,b)\iff b-a\bmod5\in\{1,3\}\) and
\(C(x,y,z)=R(x,y)R(y,z)R(z,x)\vee R(x,z)R(z,y)R(y,x)\).
\paragraph{Independent verification (PROVED/EXACT).}
\(V_3=3+2v+8m\), \(E_3=3+3v+15m\), \(E_5=E_3+1+2V_3=10+7v+31m\),
\(V_C=V_5+E_5=15+9v+39m\), \(M_C=E_5\).
For \(u\ne w\) exactly one of \(R(u,w),R(w,u)\) holds; if \(R(u,w)\) with
\(d=w-u\in\{1,3\}\), a head needs \((u-h)+(h-w)=-d\in\{2,4\}\), a sum of
two elements of \(\{1,3\}\); for \(u=w\) both disjuncts need \(R(u,u)\),
which is false. Thus \(\exists h\,C(h,u,w)\iff u\ne w\).
The NAE split gives \(a\vee b\) when \(s\) is false and
\(c\wedge\neg(a\wedge b)\) when \(s\) is true, whose union is \(a\vee b\vee c\).
\(C\) has exactly ten affine symmetries \(x\mapsto\pm x+k\).
Clause \(i\) of \(K(F)\) is computed from the header and at most one
source clause by segment arithmetic.
\paragraph{Falsified size claim and local repair.}
The output has \(\Theta((v+m)\log(v+m))\) bits, not
\(|F|^{1+o(1)}\): with \(v=2^k-1\) declared and \(m=1\), a
\((8k+17)\)-bit source yields \(10+7v+31\) C clauses
(\(30{,}064{,}771{,}106\) at \(k=32\)). Restricting to \(v\le3m\),
checked in \(O(\log)\) space, repairs this; every formula used by
the transfer satisfies it. Equisatisfiability and locality are unaffected.
\paragraph{Transfer (CONDITIONAL on P1; external review OPEN).}
In the random-access Turing-machine model of van Melkebeek's survey
(FnT-TCS 2007, Lemma~2.3 and Corollary~2.4), every NT\((n)\) language
reduces to SAT in quasi-linear size, with each output bit in polylog time
and logarithmic space. \emph{Premise P1:} the reduction can be put in
clause-indexed fixed-width \(3\)-CNF form with \(v\le3m\), by uniform
clause padding and Tseitin splitting. Composing with \(K\) and running a
hypothesized strict-C solver on the virtual input, recomputing each
accessed bit with no retained state, gives
\[
\text{strict-C-SAT}_{\rm fw}\in\mathrm{DTISP}(n^{c},n^{\epsilon})
\ \Longrightarrow\
\mathrm{NT}(n)\subseteq\mathrm{DTISP}(n^{c+o(1)},n^{\epsilon+o(1)}).
\]
Buss and Williams (Comput.\ Complexity 24, 2015, Fig.~8.2--8.3) report
an alternation-trading refutation at \((c,\epsilon)=(1.34070,0.5)\) and
none at \(1.34071\), with \(2\cos(\pi/7)\) optimal for that method as
\(\epsilon\to0\). Hence, given P1, strict-C-SAT\(_{\rm fw}\notin
\mathrm{DTISP}(n^{1.33},n^{0.5})\) and
\(\notin\mathrm{DTISP}(n^{1.80},n^{o(1)})\) for total deterministic
random-access deciders. This is a KNOWN-THEOREM corollary inherited by
every problem with local quasi-linear SAT reductions; it is not an
improved exponent, says nothing about randomized or quantum machines,
and is capped by the Buss--Williams ceiling far below any superpolynomial
or P-versus-NP consequence.
