\section{Verified exact ordered-source-head lemma}
Let \(R=\lceil B/L\rceil\),
\(w=\lceil\log_2 C\rceil+\lceil\log_2(B+1)\rceil\), and
\(B=d_1+\cdots+d_R\) with \(d_i=L\) except a final shorter block.
Store the genuine \((q_a,p_a)\) records at
\(a=0,L,\ldots<B\), on a sequentially headed writable anchor tape.
For the \emph{fixed} query order \(j=1,\ldots,B\), start each replay
at \(a_j=L\lfloor(j-1)/L\rfloor\) and finish at input position \(j\).
The true paid input-head movements \emph{within the queries} are exactly
\[
H_{\rm query}
=\sum_{i=1}^R\sum_{t=1}^{d_i}[(t-1)+t]
=\sum_{i=1}^R d_i^2\le BL.
\]
Indeed, after query \(j-1\) the head is at \(j-1\), while
the required anchor is \(t-1\) symbols behind; replay advances \(t\)
symbols. At each block boundary both positions agree. The entire
authentication pass moves the head \(N\) symbols; rewinding from the
endmarker to the payload start costs \(B\), so
\[
H_{\rm total}=N+B+\sum_i d_i^2.
\]
Exact source symbol reads are \(N+\sum_i d_i(d_i+1)/2\).
The actual anchor tape is written once and scanned as a sequential
tape for each of \(Q=B\) queries; its movement/read tax is
\(O(BRw)\), not a free random-access record lookup.
The evaluator adds the returned \(m_j\) to its \(O(\log B)\)-bit
accumulator. After query \(j\) the accumulator equals \(p_j\) by
induction. Hence its final YES/NO label is correct for every source.

The \emph{same sequential-input implementation} consequently satisfies
\[
\boxed{\quad S=O(Rw+\log B),\qquad
T=O\bigl((N+BL+BRw)\operatorname{polylog}(B+2)\bigr).\quad}
\]
All parsing, head positions, queries, checkpoint copying, integer
arithmetic and output are included. With
\(L=\lceil\sqrt B\rceil\), this is
\(S=O(\sqrt B\log B)\) and
\(T=O(B^{3/2}\operatorname{polylog}B)\).
The theorem is PROVED/EXACT \emph{for this fixed ordered streaming class};
external mathematical review remains OPEN. No general Tree Evaluation,
arbitrary checkpoint provider, DTISP exclusion or SAT lower bound follows.
In fact a direct one-pass algorithm legally computes the same result
in \(O(B\operatorname{polylog}B)\) time and \(O(\log B)\) writable space.

\paragraph{Restricted all-head-oblivious construction.}
After a complete input scan and rewind, stage $j$ returns
the INPUT head to the beginning of the word, traverses the
fixed-length prefix to gate $j$, reads the opcode, then traverses
both $n$-bit operand masks. The VALUE work head, starting
at zero, sweeps all $n$ work cells against the first mask,
rewinds, sweeps all $n$ again against the second, seeks to
cell $j$ to write its computed bit, and returns to zero.
Both genuine head itineraries depend only on $n,j$, never
on the gate data. Induction shows that all written work bits
are exactly the corresponding gate values. The charged
movement and access ledger is
\[
\begin{aligned}
H_{\mathrm{INPUT}}&=2N+2n(n+1)(n+2),&
H_{\mathrm{VALUE}}&=4n(n-1),\\
Q_{\mathrm{read}}&=2n^2,&Q_{\mathrm{write}}&=n .
\end{aligned}
\]
Each row-$j$ input round trip reaches position
$n+1+(j+1)(2+2n)$; the VALUE head performs three
$(n-1)$-moves sweeps and a seek to $j$ plus return.
All counters, index arithmetic and gate operations can be
padded with full-width fixed-duration scans, so every
scratch-head movement can also be scheduled solely by $n$.
One actual uniform locally headed implementation therefore
obeys jointly
\[
\boxed{T=O(n^3\log(n+2)),\qquad
S_{\mathrm{peak}}=O(n+\log(n+2)).}

\section{Independent C1f address-domain theorem and exact-count bridge}

a total map \(D:\{0,1\}^{\ell}\to(\{\pm1,\dots,\pm v\})^3\),
and a candidate assignment \(a\in\{0,1\}^v\).
Let \(B_a(i)\) mean all three signed literals of \(D(i)\) evaluate
false under \(a\), and let
\[
 G_a(i)=[i<m]\wedge B_a(i).
\]
Then, with \(\phi=\bigwedge_{i=0}^{m-1}D(i)\),
\[
 \#G_a=\sum_{i=0}^{m-1}B_a(i),
 \qquad \#G_a=0\ \Longleftrightarrow\ a\models\phi.
\]
This is PROVED/EXACT for this model. Each index contributes once
only when authentic and violated. Functional four-row Tseitin constraints
for every shared binary gate force a unique gate extension, hence their
positive-output CNF counts exactly \(\#G_a\).
The TMR-1 all-input normalizer also preserves that count.

\section{Worst-case derivation bridge audit}\label{sec:bridge}
Fix a Cook--Reckhow system \(R\) (polynomial-time verifier, sound and
complete for unsatisfiable CNFs) and let \(\operatorname{cost}_R\) be
encoded proof length. Then \(\overline W_R\) is exactly the worst-case
proof-size function of \(R\); minimizing over all refutations
grants the optimal reduction sequence for free, as intended. A fixed
rule set on the multisign clause hypergraph is a DAG-like system of
this kind. Write \(\mathrm{Bridge}(R)\) for
\(\mathrm{SAT}\in\mathrm P\Rightarrow\overline W_R(N)\le\operatorname{poly}(N)\).

\paragraph{Theorem A (PROVED/EXACT, elementary; review OPEN).}
If \(\overline W_R(N)\ge N^{\omega(1)}\) is unconditionally known, then
\(\mathrm{Bridge}(R)\iff\mathrm P\ne\mathrm{NP}\).
\emph{Proof.} If \(\mathrm P\ne\mathrm{NP}\) the antecedent fails. Conversely
the bridge and the known lower bound give \(\mathrm{SAT}\notin\mathrm P\)
by contraposition. \(\square\)
Such lower bounds are KNOWN THEOREMS for tree-like and DAG resolution
(Haken 1985; Urquhart 1987; Chv\'atal--Szemer\'edi 1988;
Ben-Sasson--Wigderson 2001), polynomial calculus (Razborov 1998),
cutting planes (Pudl\'ak 1997) and bounded-depth Frege (Ajtai 1988).
For all of them the bridge carries the entire difficulty; it is not a
weaker intermediate step.

\paragraph{Theorem B (PROVED/EXACT, elementary; review OPEN).}
For every \(R\), \(\mathrm P\ne\mathrm{NP}\Rightarrow\mathrm{Bridge}(R)\);
if \(\mathrm P=\mathrm{NP}\) then \(\mathrm{Bridge}(R)\) holds iff \(R\) is
polynomially bounded. For a sound theory \(T\) with polynomial-time proof
checking let \(R_T\) accept \((A,k,p,1^{|F|^k})\) when \(p\) is a
\(T\)-proof that \(A\) is a correct SAT decider in time \(n^k\) and
\(A\) rejects \(F\) within \(|F|^k\) steps. Then \(R_T\) is a
Cook--Reckhow system, and if some polynomial-time SAT algorithm has
\(T\)-provable correctness and time bound then \(\overline W_{R_T}\) is
polynomial. Cook (1975) gives the analogous statement for extended Frege
under PV-provable correctness; Kraj\'\i\v{c}ek--Pudl\'ak (1989) give a
p-optimal system under \(\mathrm E=\mathrm{NE}\), which is not
explicit in advance. Truth of \(\mathrm{SAT}\in\mathrm P\) alone is not
known to bound any explicitly fixed system. This provability premise is
the exact OPEN arrow of the shared objective.

\paragraph{Scope of the free-sequence minimum (KNOWN).}

run on unsatisfiable inputs yields an \(R\)-refutation of comparable size
(DPLL and tree-like resolution, CDCL and resolution). It says nothing
about algorithms whose transcripts are not \(R\)-proofs; that gap is

\section{Switch composition and the combined system}\label{sec:switch}
This section tests the shared priority that proposed hard instances should
\emph{survive} resolution, algebraic reasoning, cutting planes, extension and
adaptive switching. Let \(F(x)\) and \(G(y)\) be unsatisfiable CNFs on disjoint
variables, \(z\) a fresh variable, and
\[
H=\{C\vee z: C\in F\}\cup\{D\vee\neg z: D\in G\}.
\]

\paragraph{Theorem C (PROVED/EXACT, elementary; independent review OPEN).}
(i) \(H\) is unsatisfiable, \(H|_{z=0}=F\) and \(H|_{z=1}=G\).
(ii) For every proof system closed under restriction without size increase
(tree-like and DAG resolution, \(\mathrm{Res}(\oplus)\), polynomial calculus,
cutting planes, Frege, extended Frege),
\(s_R(H)\ge\max(s_R(F),s_R(G))\).
(iii) For tree-like resolution, measured by minimum refuting decision-tree
leaves, \(T(H)=T(F)+T(G)\) exactly.
(iv) If a system \(U\) contains \(R_1\) and \(R_2\) with a clause interface,
\(R_1\) refutes \(F\) in size \(s_1\) and \(R_2\) refutes \(G\) in size \(s_2\),
and both admit weakening by a literal with polynomial overhead, then
\(s_U(H)\le\operatorname{poly}(s_1)+\operatorname{poly}(s_2)+O(1)\).

\emph{Proof.} (i) is direct. (ii) Substitute the constant for \(z\) in every line.
(iii) Every clause of \(H\) mentions \(z\), so every leaf of a refuting decision
tree has \(z\) assigned. Keeping only the \(0\)-child at each \(z\)-node yields a
refuting tree for \(F\) whose leaves are the \(z=0\) leaves; queries to
\(y\)-variables can be removed by keeping the smaller child, since \(F\) does not
mention \(y\). So there are at least \(T(F)\) such leaves, and likewise at least
\(T(G)\) leaves with \(z=1\), disjointly. Querying \(z\) first attains the sum.
(iv) Derive \((z)\) from the weakened copy of \(F\), derive \((\neg z)\) from
\(G\), and resolve. Weakening is free in resolution. In polynomial calculus,
with \(1\) meaning true, the falsity polynomial of \(C\vee z\) is \(p_C(1-z)\);
multiplying every line by \((1-z)\) at most doubles size and adds one to degree.
No cutting-planes weakening bound is claimed here. \(\square\)

\paragraph{Consequence (the componentwise criterion is FALSIFIED).}
If \(F\) is easy for \(R_1\) and hard for \(R_2\), and \(G\) the reverse, then
\(H\) is superpolynomially hard for \(R_1\) and for \(R_2\) separately but
polynomial for their union. An instance from KNOWN THEOREMS, CONDITIONAL on
matching the cited encodings with independent check OPEN, is
\(R_1=\mathrm{PC}_{\mathbb F_2}\), \(R_2=\mathrm{PC}_{\mathbb F_3}\),
\(F\) the mod-3 Tseitin formula and \(G\) the mod-2 Tseitin formula on
bounded-degree expanders. Buss--Grigoriev--Impagliazzo--Pitassi
(J.~Comput.\ Syst.\ Sci.\ 62, 2001) give linear degree lower bounds in the
wrong characteristic; Impagliazzo--Pudl\'ak--Sgall (Comput.\ Complexity 8, 1999)
convert them into exponential size; each formula is easy by linear algebra in
its own characteristic. Survival tests must therefore be run against the
combined system itself, including its switching rule.

\paragraph{Corollary D (KNOWN THEOREM composition).}
If the combined system contains resolution and the extension rule, it
p-simulates extended resolution, which is p-equivalent to extended Frege
(Cook--Reckhow 1979; Kraj\'\i\v{c}ek 1995). A superpolynomial lower bound on
\(\overline W_{R_{\rm comb}}\) would then be a superpolynomial extended Frege
lower bound, which is OPEN for every family. This answers the /053 next lemma
in the affirmative whenever extension is included.

\paragraph{Literature status of the extension-free combination.}
For unrestricted DAG-like \(\mathrm{Res}(\oplus)\), ECCC TR25-188 records that no
superpolynomial size lower bound was known; known bounds are tree-like,
regular (Efremenko--Garl\'\i k--Itsykson, STOC 2024) or bounded depth
(arXiv:2507.23008; arXiv:2511.20023). K.~Braun, arXiv:2609.23015
(September 2026), claims a \(2^{\Omega(n/\log^2 n)}\) DAG-like

Tseitin formulas have quasipolynomial cutting-planes refutations
(Dadush--Tiwari, CCC 2020); random constant-width 3-CNF in cutting planes remains OPEN.

\section{Bit pigeonhole collapses under extension}\label{sec:bphp}
This section tests the shared priority that a candidate hard family should
survive circuit compression and shared DAGs. It uses the family named
hard for both arms of the extension-free combination \(R^-_{\rm comb}\) by the /055 next lemma
(Section~\ref{sec:switch}). For \(n=2^k\) holes and \(m=n+1\) pigeons,
\(\mathrm{BPHP}^{n+1}_n\) has variables \(x_{i,b}\) (\(i<m\), \(b<k\)) and, for
every pair \(i<i'\) and every hole \(h\), the \(2k\)-literal clause stating
\(x_i\ne h\lor x_{i'}\ne h\). Its encoding has
\(|\langle F\rangle|=\binom{n+1}{2}\,n\cdot 2k=\Theta(n^3\log n)\) literal
occurrences.

\paragraph{KNOWN lower bounds (primary sources checked this run).}
Size \(2^{\Omega(n/\log n)}\) for resolution and \(2^{\Omega(n^{1-\epsilon})}\) for
\(\mathrm{Res}(k)\) with \(k\le\log^{1/2-\epsilon}n\), and \(2^{\Omega(n/\log^2 n)}\) for
Sherali--Adams (Dantchev--Galesi--Ghani--Martin); \(2^{\Omega(n^{1/8})}\) for semantic
cutting planes (Hrube\v{s}--Pudl\'ak 2017), improved to \(2^{\Omega(n^{1/4})}\) and to
\(2^{n^{1-o(1)}}\) for tree-like cutting planes by Beame--Whitmeyer (ICALP 2025,
LIPIcs~334, 21; ECCC TR25-057). The DAG \(\mathrm{Res}(\oplus)\) bound
\(2^{\Omega(n/\log^2 n)}\) of Braun (arXiv:2609.23015) remains a CANDIDATE that TMR-5
has not verified. The same introduction records that \(\mathrm{BPHP}\) has
polynomial-size Sum-of-Squares refutations (Dantchev et al.). Since
\(n=\Theta((N/\log N)^{1/3})\), every listed bound is superpolynomial in \(N\).

\paragraph{Theorem E (PROVED/EXACT; ingredients KNOWN; independent review OPEN).}
For every \(k\ge1\), \(\mathrm{BPHP}^{n+1}_n\) has an explicit extended-resolution
refutation, written as RUP lines plus conservative definitions of fresh variables.
It uses
\[
\#\mathrm{ext}=n(n+1)+\tfrac{(n+1)n(n-1)}{3},\qquad
\#\mathrm{RUP}=(n+1)(n-1)+\tbinom{n+1}{2}n+\sum_{h=2}^{n}\Bigl(h+3(h-1)\tbinom h2\Bigr)+1
=\tfrac38 n^4+O(n^3),
\]
together with \(n(n+1)(k+1)+\tfrac43(n+1)n(n-1)\) extension clauses. Every RUP line
expands to a trivial resolution derivation with at most \(O(n)\) steps
(Beame--Kautz--Sabharwal 2004). The total extended-resolution size is therefore
\(O(n^5)=O(N^{5/3})\), with \(O(N^{4/3})\) lines. Replacing each \(k\)-ary AND by
binary definitions adds \(O(n^2k)\) variables.

\emph{Proof.} Stage~1 decodes the binary encoding into the unary one.
Define \(y_{i,h}\leftrightarrow\bigwedge_b[x_{i,b}=h_b]\).
\((\neg y_{i,h}\lor\neg y_{i',h})\) is RUP: the two assumptions fix all bits of both
pigeons, which falsifies the source clause for \((i,i',h)\). For a bit prefix
\(\sigma\) of length \(t<k\), the lemma \(\bigvee_{h\supseteq\sigma}y_{i,h}\lor
\bigvee_{b<t}[x_{i,b}\ne\sigma_b]\) is RUP from its two children \(\sigma0,\sigma1\):
the children force opposite values of \(x_{i,t}\). For \(t=k\) the lemma is a
definition clause. The root \(t=0\) is \(P_i=\bigvee_h y_{i,h}\). This gives
\(\mathrm{PHP}^{n+1}_n\) on \(y\).

Stage~2 is Cook's 1976 reduction. On level \(h\) define
\(q_{i,j}\leftrightarrow p_{i,j}\lor(p_{i,h-1}\land p_{h,j})\) for \(i<h\), \(j<h-1\).
The pigeon clause \(\bigvee_j q_{i,j}\) is RUP: falsifying all \(q_{i,j}\) forces
\(p_{i,h-1}\), then \(\neg p_{h,j}\) for all \(j<h-1\), then \(p_{h,h-1}\), which
contradicts the hole clause \((i,h,h-1)\). A hole clause
\(\neg q_{i,j}\lor\neg q_{i',j}\) follows from the RUP lemmas
\(\neg q_{i,j}\lor\neg q_{i',j}\lor\neg p_{i,j}\) and
\(\neg q_{i,j}\lor\neg q_{i',j}\lor\neg p_{i',j}\). Given those two lemmas, the
assumptions \(q_{i,j},q_{i',j}\) force \(p_{i,h-1}\) and \(p_{i',h-1}\), which
contradicts the hole clause \((i,i',h-1)\). At \(h=1\) the empty clause is RUP.
Extension is conservative and deletion only weakens the database, so the
refutation is sound. \(\square\)
