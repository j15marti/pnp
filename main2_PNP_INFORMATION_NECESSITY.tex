\section{Status and end-to-end target}
This paper establishes a restricted but fully constructive source-to-output exact-counting pipeline for a canonical strict proper 3-CNF encoding of bipartite independent sets. It also proves a future-count-continuation congruence strictly coarser than the earlier neighborhood rank equivalence on a perfect matching. These are \textbf{PROVED/EXACT} in the stated models, with independent mathematical review \textbf{OPEN}. Finite tests are \textbf{COMPUTATIONAL}. No unrestricted SAT or circuit lower bound follows. \textbf{P versus NP remains OPEN}.

The fixed target, D2-COUNT-PIPELINE, is encoded source bytes $\to$ full parse and family authentication $\to$ recovered graph neighborhoods $\to$ charged matching recognizer or general exact weighted union DP $\to$ the exact integer $\#F$. A valid non-family width-at-most-three CNF is counted by a terminating exhaustive fallback. Malformed sources are rejected. This is a total exact-counting method on its declared valid-input domain, not a polynomial-time general \#SAT algorithm. We do not replace counting by mere satisfiability or by evaluation of a single assignment.

\section{Authentic source and semantic proof}
Fix $a,b\geq 0$ and a simple graph $G=(A\sqcup B,E)$ with every edge crossing, $|A|=a$, $|B|=b$. The input is a DIMACS source containing a declared \texttt{c split a b} and \texttt{p cnf a+b+3 m+7}. Its first seven proper ternary clauses on three fresh variables $p,q,r$ exclude each nonzero triple. For every original edge $\{u,v\}$, $u\in A,v\in B$, add $(\neg u\lor\neg v\lor p)$. The parser checks the header, literal ranges, ordered pin clauses, split, crossing-edge form and duplicate edges. The input bit length $N$ includes headers, addresses, clauses and all whitespace.

\paragraph{Lemma 1 (unique pins, pointwise and exact-count semantics).}
The pins are forced to $(0,0,0)$. Every independent-set assignment of the original $a+b$ variables has \emph{exactly one} satisfying extension; every violating assignment has none. In particular,
\[
\#F_G=\sum_{S\subseteq A}2^{b-|U(S)|},\qquad
U(S)=\bigcup_{u\in S}N_G(u)\subseteq B.
\]
\emph{Proof.} Each of the seven pin clauses excludes exactly one distinct nonzero pin value, leaving only zero. With $p=0$, an edge clause becomes $\neg u\lor\neg v$, forbidding selecting both endpoints. For a fixed left set $S$, precisely the right subsets avoiding $U(S)$ remain. Their count is $2^{b-|U(S)|}$. The pin extension is unique. \hfill$\square$

These are fixed-formula assignment constraints and exact counts, not a lower bound for the SAT decision function on encoded inputs. The all-zero original assignment supplies a cheap SAT witness.

\section{Paid union-state evaluator}
Let $F_t=\{U(S):S\subseteq A_{\le t}\}$, $r_t=|F_t|$, $r=\max_t r_t=r_a$. Store for each actual $U\in F_t$ an integer $W_t(U)$ counting left-prefix sets giving that union. Initially $W_0(\varnothing)=1$. For each real state $(U,w)$ at step $t+1$, add $w$ to keys $U$ and $U\cup N(a_{t+1})$. Repeated keys are consolidated by exact integer addition. Finally output
\[
Z=\sum_{U\in F_a} W_a(U)\,2^{b-|U|}.
\]

\paragraph{Lemma 2 (end-to-end counting correctness).}
For every valid recognized source the evaluator returns exactly $\#F_G$. For every other valid declared width-at-most-three CNF the exhaustive fallback returns its exact count.

\emph{Proof.} The DP starts with the sole empty prefix. Excluding and including the next left vertex are disjoint and exhaustive choices, and update the forbidden right union exactly as indicated. Induction shows $W_t(U)$ equals the number of prefixes with union $U$. Lemma 1 gives the final count. The fallback evaluates every complete assignment under the input clause list, including an empty or contradictory clause, and so is correct. \hfill$\square$

The earlier TMR-2/053 Boolean-lattice zeta result proves that the assignment-evaluation matrix for the original cross-only relation has rank $r$ over every field. This \emph{representational} equality does not show that all $r$ states must be built by an arbitrary counting or decision algorithm.

\section{A counting-relevant future quotient}
Let $R_t=A_{>t}$. For any realized union $U$ at stage $t$, define the cardinality continuation vector
\[
\sigma_t(U)=\bigl(|U\cup N(S)|:S\subseteq R_t\bigr),
\]
with one fixed order on the future subsets. Write $U\equiv_t V$ precisely when $\sigma_t(U)=\sigma_t(V)$; denote the number of realized classes by $q_t$. This signature is \emph{not} the Boolean residual assignment function.

\paragraph{Theorem 3 (exact two-branch future congruence).}
For $U\equiv_t V$ and next left vertex $u\in R_t$,
\[
U\equiv_{t+1}V,\qquad
U\cup N(u)\equiv_{t+1}V\cup N(u).
\]
After all left vertices are processed, equivalent unions contribute the same number of right-side completions. Thus a weighted evaluator can merge equivalent states at every stage while preserving the exact final integer count.

\emph{Proof.} Every continuation $S\subseteq R_{t+1}$ is also a subset of $R_t$, so the old signature equates $|U\cup N(S)|$ and $|V\cup N(S)|$. It also equates the two unions after adjoining $u$, because $S\cup\{u\}\subseteq R_t$. Both successor choices therefore have identical new signatures. At $t=a$ the only remaining subset is empty, so equivalence means $|U|=|V|$ and hence identical factors $2^{b-|U|}$. Integer weights add without losing multiplicity. \hfill$\square$

The exact signature can require enumerating $2^{a-t}$ future subsets per queried state; computing it is \textbf{NOT FREE}. The published executable runs this expensive construction only as a finite independent audit. A claimed asymptotic speedup must supply a constructive smaller signature and pay for its discovery, switches and evaluation.

\section{One family with exponential rank but polynomial exact counting}
For a perfect matching of $k$ original left and $k$ original right variables, after $t$ left variables
\[
r_t=2^t,\qquad
q_t=t+1,\qquad
\operatorname{rank}_K(D_{G_k})=2^k
\quad\text{for every field }K.
\]
Indeed, each matching neighborhood is a distinct singleton. A continuation's union size is $j+|S|$ when the current left set has size $j$; therefore its signature depends only on $j\in\{0,\ldots,t\}$. The paid source recognizer checks that every original vertex has degree at most one and that all edges have the authenticated form. Writing $m=|E|$ and allowing isolated vertices, it returns
\[
\boxed{\#F_G=3^m\,2^{a+b-2m}.}
\]
The arithmetic is repeated exact multiplication and output; no exponential state table is constructed. This is a \emph{fully implemented fixed uniform} polynomial-time algorithm for a restricted \#CNF family, not a uniform polynomial-time method for arbitrary \#3SAT.

\section{Same-realization resource ledger and TMR-4 interface}
For an ordinary deterministic multitape implementation with balanced lookup (not unit-time hash oracles), masks need $b$ bits and multiplicities need at most $a+1$ bits. Let $N$ be full original source bits, $r=r_a$. Conservative upper bounds for source validation, graph construction, integer arithmetic, all $2|F_t|$ transitions, lookups, retaining tables and producing the exact output are
\[
T_{\mathrm{union}}=O(N^3+a r(N+a+b)^3),\qquad
S_{\mathrm{union}}=O(N^2+r(N+a+b)^2).
\]
On recognized degree-at-most-one sources, the \emph{same} parser/recognizer/product-output execution has
\[
T_{\mathrm{match}}=O(N^3),\qquad S_{\mathrm{match}}=O(N^2).
\]
These are intentionally conservative bit-machine bounds, not an unperformed instruction-level replay. For the explicit finite signature audit, add at least $\sum_t q_t2^{a-t}$ suffix-subset inspections and the required union/popcount bit costs; those are not part of the production matching route. An arbitrary non-family source uses exhaustive enumeration and is not claimed to obey the matching bound. Network sequential work and aggregate live storage cannot be replaced by span or worker-local storage.

The named proposed invariant for TMR-4 is \textbf{D2-FUTURE-QUOTIENT}: the number and identifiers of \emph{actually materialized} future-count-continuation classes in the stated integer-weighted, left-to-right evaluator, together with the exact stored weights. Its transition interface includes source authentication, explicit edge/neighborhood generation, both state updates, paid equality tests/merges, graph-specific simplifications, alternative algorithms, caching, sharing, recomputation, adaptive switching and all output. An unrestricted solver need not materialize this domain. This is a legitimate restricted correctness invariant, \emph{not} a necessary work lower bound for every SAT or \#SAT machine.
