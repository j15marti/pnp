\section{Authentic source and semantic proof}
Fix $a,b\geq 0$ and a simple graph $G=(A\sqcup B,E)$ with every edge crossing, $|A|=a$, $|B|=b$. The input is a DIMACS source containing a declared \texttt{c split a b} and \texttt{p cnf a+b+3 m+7}. Its first seven proper ternary clauses on three fresh variables $p,q,r$ exclude each nonzero triple. For every original edge $\{u,v\}$, $u\in A,v\in B$, add $(\neg u\lor\neg v\lor p)$. The parser checks the header, literal ranges, ordered pin clauses, split, crossing-edge form and duplicate edges. The input bit length $N$ includes headers, addresses, clauses and all whitespace.

\paragraph{Lemma 1 (unique pins, pointwise and exact-count semantics).}
The pins are forced to $(0,0,0)$. Every independent-set assignment of the original $a+b$ variables has \emph{exactly one} satisfying extension; every violating assignment has none. In particular,
\[
\#F_G=\sum_{S\subseteq A}2^{b-|U(S)|},\qquad
U(S)=\bigcup_{u\in S}N_G(u)\subseteq B.
\]
\emph{Proof.} Each of the seven pin clauses excludes exactly one distinct nonzero pin value, leaving only zero. With $p=0$, an edge clause becomes $\neg u\lor\neg v$, forbidding selecting both endpoints. For a fixed left set $S$, precisely the right subsets avoiding $U(S)$ remain. Their count is $2^{b-|U(S)|}$. The pin extension is unique. \hfill$\square$

These are fixed-formula assignment constraints and exact counts, not a lower bound for the SAT decision function on encoded inputs. The all-zero original assignment supplies a cheap SAT witness.

\section{Paid union-state evaluator}
Let $F_t=\{U(S):S\subseteq A_{\le t}\}$, $r_t=|F_t|$, $r=\max_t r_t=r_a$. Store for each actual $U\in F_t$ an integer $W_t(U)$ counting left-prefix sets giving that union. Initially $W_0(\varnothing)=1$. For each real state $(U,w)$ at step $t+1$, add $w$ to keys $U$ and $U\cup N(a_{t+1})$. Repeated keys are consolidated by exact integer addition. Finally output
\[
Z=\sum_{U\in F_a} W_a(U)\,2^{b-|U|}.
\]

\paragraph{Lemma 2 (end-to-end counting correctness).}
For every valid recognized source the evaluator returns exactly $\#F_G$. For every other valid declared width-at-most-three CNF the exhaustive fallback returns its exact count.

\emph{Proof.} The DP starts with the sole empty prefix. Excluding and including the next left vertex are disjoint and exhaustive choices, and update the forbidden right union exactly as indicated. Induction shows $W_t(U)$ equals the number of prefixes with union $U$. Lemma 1 gives the final count. The fallback evaluates every complete assignment under the input clause list, including an empty or contradictory clause, and so is correct. \hfill$\square$

The earlier TMR-2/053 Boolean-lattice zeta result proves that the assignment-evaluation matrix for the original cross-only relation has rank $r$ over every field. This \emph{representational} equality does not show that all $r$ states must be built by an arbitrary counting or decision algorithm.

\section{A counting-relevant future quotient}
Let $R_t=A_{>t}$. For any realized union $U$ at stage $t$, define the cardinality continuation vector
\[
\sigma_t(U)=\bigl(|U\cup N(S)|:S\subseteq R_t\bigr),
\]
with one fixed order on the future subsets. Write $U\equiv_t V$ precisely when $\sigma_t(U)=\sigma_t(V)$; denote the number of realized classes by $q_t$. This signature is \emph{not} the Boolean residual assignment function.

\paragraph{Theorem 3 (exact two-branch future congruence).}
For $U\equiv_t V$ and next left vertex $u\in R_t$,
\[
U\equiv_{t+1}V,\qquad
U\cup N(u)\equiv_{t+1}V\cup N(u).
\]
After all left vertices are processed, equivalent unions contribute the same number of right-side completions. Thus a weighted evaluator can merge equivalent states at every stage while preserving the exact final integer count.

\emph{Proof.} Every continuation $S\subseteq R_{t+1}$ is also a subset of $R_t$, so the old signature equates $|U\cup N(S)|$ and $|V\cup N(S)|$. It also equates the two unions after adjoining $u$, because $S\cup\{u\}\subseteq R_t$. Both successor choices therefore have identical new signatures. At $t=a$ the only remaining subset is empty, so equivalence means $|U|=|V|$ and hence identical factors $2^{b-|U|}$. Integer weights add without losing multiplicity. \hfill$\square$

The exact signature can require enumerating $2^{a-t}$ future subsets per queried state; computing it is \textbf{NOT FREE}. The published executable runs this expensive construction only as a finite independent audit. A claimed asymptotic speedup must supply a constructive smaller signature and pay for its discovery, switches and evaluation.

\section{One family with exponential rank but polynomial exact counting}

\quad\text{for every field }K.

\section{TMR-2/092: girth-six rank-three finite-core saturation}

\paragraph{Theorem (exact restricted satisfiability).}
Every finite simple oriented graph $G$ without loops or digons, with
undirected girth at least six and cyclomatic number
$\beta(G)=|E|-|V|+c(G)\leq 3$, admits a homomorphism $G\to T_5$,
where $R(a,b)$ holds precisely when
$(b-a)\bmod 5\in\{1,3\}$.
This extends the girth-five, rank-at-most-two theorem of
TMR-2/091; the girth-five, rank-three counterexample remains
valid and is not a counterexample here.

\paragraph{Reduction to 15 fixed multigraph cores.}
Delete leaves and isolated vertices (two allowed labels for
each direction of a pendant arc). In any surviving connected
rank-three component, suppress maximal degree-two paths,
recording each exact five-state endpoint transfer. The
connected multigraph core has minimum degree at least three,
has $e=v+2$, and hence $v\leq4$. Loops, bridges,
multiple core edges and articulation vertices are permitted.
Enumeration of all connected multigraphs with these
conditions up to vertex permutation gives exactly fifteen
unlabeled cores (counts $1,4,5,5$ for $v=1,2,3,4$).
Components with smaller rank follow from the previous theorem.

\paragraph{Path-state lemma.}
Let $S$ be the cyclic $5\times5$ shift and $A=S+S^3$.
An oriented path of length $\ell$ with $r$ reversed arcs
induces the exact cofactor $A^\ell S^r$.
For $\ell=1,2,3$ there are respectively $2,3,4$
possible reversal-count states, making nine short
existential transfer types. Every $\ell\geq4$ has full
endpoint support; replace it by a tenth unrestricted support
type, formally assigned effective length six solely
for a conservative girth-cycle test. This effective
length is not the original path length and is never
used to assert a source-cost reduction.

\paragraph{Finite-core certificate.}
Enumerate all ten states per core edge, rejecting any
assignment for which an elementary cycle composed of
short-state paths has total length below six. Cycles
containing unrestricted long paths are conservatively
allowed because actual long paths can be at least six.
For every remaining configuration, pin one branch label
to zero using cyclic color symmetry and intersect the
path-support masks over the at most $5^{v-1}\leq125$
branch assignments. Of the $1{,}428{,}850$ enumerated
prefix choices, $778{,}143$ completed configurations
pass the necessary girth test. None has an empty mask.
The minimum surviving gauge-mask cardinality is one.
This proves satisfiability for every original graph
in the theorem's scope, by extending the compatible
branch assignment independently through each path
and then through the pruned trees.

The per-core completed counts are

3500,1000,31440,122052,602916).
\]

\section{An exact cycle-syndrome dynamic invariant and a girth-six multi-theta collapse (TMR-2/093)}

\paragraph{Exact modular recoding.}
For an authenticated source of $n$ vertices, $m$ arcs and $c$ weak
components, choose an undirected spanning forest and the $\beta=m-n+c$
fundamental cycles. Let
$H\in\mathbb F_5^{\beta\times m}$ be the signed incidence matrix
whose rows traverse each chord in its source-arc direction and the
unique forest path back, assigning coefficients $+1,-1,0$ according
to whether each arc is traversed forward, backward or not at all.
The two allowable edge differences admit the unique representation
$d_e=x_{v_e}-x_{u_e}=1+2b_e\pmod5$ for $b_e\in\{0,1\}$.
The forest-integration bijection, with one free root color per weak
component, gives the exact original-label identity
\[
\boxed{Z(G)=5^c\#\{b\in\{0,1\}^m:
                    Hb=-3H\mathbf1\pmod5\}.}
\]
This is a \emph{counting equality}, not an analogy to an affine CSP:
the binary coordinates are restricted to $\{0,1\}$, so modular
Gaussian elimination alone does not decide the original problem.

\paragraph{Paid source-transition evaluator.}
Writing $h_e$ for column $e$ of $H$ and $r=-3H\mathbf1$,
initialize $D_0(0)=1$ and use actual source-arc transitions
\[
D_{k+1}(s)=D_k(s)+D_k(s-h_{e_k}),\qquad
Z(G)=5^cD_m(r).
\]
The complete integer vector $D_k$, its nonzero support and the
paid number of updates define the named invariant
\textbf{D2-T5-EXACT-CYCLE-SYNDROME-SHORT-CORE093}.
At most $5^\beta$ syndromes exist. A direct sparse DP therefore
takes $O(m(\beta+1)5^\beta)$ coordinate-and-integer arithmetic work,
in addition to source parsing and construction of $H$; counters
can have $O(m)$ bits, giving the conservative bit-operation bound
$O(m^2(\beta+1)5^\beta)+\operatorname{poly}(n,m)$.
This sharpens the previous coarse $5^{2\beta}$ feedback-edge
exact-count upper bound. Neither syndrome support nor its width
is an unrestricted branching-program or decision-time lower bound.

\paragraph{Matched identical-skeleton dynamic counterexample.}
For the nine-vertex, eleven-arc, girth-five $\beta=3$ four-path
obstruction from /091 and its one-arc-flipped YES partner,
the source-ordered syndrome support profile is \emph{identical}:
\[
 (1,2,3,6,9,12,24,36,48,78,103,119).
\]
Both use 644 explicit source-transition accumulator updates,
yet $D_m(r)$ equals $0$ and $27$, respectively. The exact
original-label counts are $0$ and $135$.
Thus even a genuine, prefix-by-prefix dynamic \emph{support-size}
invariant fails to distinguish a certified mixed pair; the
target-indexed \emph{integer} cofactor distinguishes them.
This is a restricted counterexample to support-size necessity
arguments, not a runtime lower bound.

\paragraph{Girth-six multi-theta theorem at unrestricted cycle rank.}
Every orientation of an undirected graph consisting of arbitrarily
many internally disjoint paths between two terminals has a $T_5$
homomorphism whenever its undirected girth is at least six.
Indeed the shortest two path lengths sum to at least six.
If there is a path of length one or two, every other path has
length at least five or four, respectively, and permits any
terminal colors. Otherwise all paths have length at least three,
and the equal-terminal choice is feasible on every path:
length-three transfer supports include difference zero, while
all paths of length at least four have full support.
Every path interior can then be assigned independently.
This theorem applies at \emph{arbitrarily large} cyclomatic number
within the specified two-terminal family.

\paragraph{Polynomial-time short-core YES certificate and girth bound.}
Delete leaves and suppress maximal degree-two paths, preserving
their exact endpoint transfer supports. Designate a suppressed
core edge \emph{short} if its original path has at most three arcs.
If the short-edge core is a forest, root each tree and assign
compatible terminal colors, then extend all long paths (length
at least four) independently. The input is SAT.
For a connected, loopless, simple oriented source with
$\beta\geq2$, the minimum-degree-three suppressed core has
at most $3(\beta-1)$ edges. An UNSAT source requires a cycle
of short edges, whose total original length is at most
$3\cdot3(\beta-1)$. Therefore
\[
\boxed{\operatorname{UNSAT}(G)\Longrightarrow
             \operatorname{girth}(G)\leq9(\beta(G)-1).}
\]
Forests and loopless single-cycle cores are SAT as well.
The bound is not claimed sharp and does not imply any
unrestricted lower bound.

\section{Explicit-source correct-path firewall for T5 block comparisons (TMR-2/094)}

\paragraph{Exact polarities and the black-box obstruction.}
For an original conjunctive source
$F(z,y)=\bigwedge_{b=1}^{M}F_b(z,y_b)$,
where private scopes $y_b$ are disjoint after fixing shared $z$,
\[
\operatorname{SAT}(F)\iff
  \exists z\,\forall b\,\exists y_b\,F_b(z,y_b),
\qquad
\operatorname{UNSAT}(F)\iff
  \forall z\,\exists b\,\forall y_b\,\neg F_b(z,y_b).
\]
Nonconjunctive row aggregators need their own semantic proof.
For a black-box independent oracle $Q(z,b)$ declaring
whether a block fails, the read-once AND-of-OR function
$H(Q)=\bigwedge_z\bigvee_b Q(z,b)$ has exact deterministic
bit-query complexity $2^q M$, with positive certificate
size $2^q$ and negative certificate size $M$.
This is a \emph{restricted oracle theorem}, not a source
runtime lower bound.

\paragraph{Source-visible three-resolution counterexample.}
For every $q\ge1$, let $C_0=(z_1)$,
$C_1=(\neg z_1)$, and $C_i=(z_i\vee\neg z_i)$
for $i\ge2$.  Give each clause one fresh private variable
$y_i$ and set
\[
 B_i=(C_i\vee y_i)\wedge(C_i\vee\neg y_i).
\]
Each block is unconditionally satisfiable and
$\exists y_iB_i=C_i$; every shared assignment has
a refutable block.  Yet the whole original CNF has a
three-inference ordinary Resolution refutation:
resolve the two $B_0$ clauses to obtain $z_1$,
the two $B_1$ clauses to obtain $\neg z_1$,
then resolve these units.  Flipping $C_1$ produces
the same block grammar with a SAT source.
Authenticating the original source, locating and verifying
those inferences is charged; $2^q$ cases are not
necessary.  An arbitrary bounded-width CNF also embeds
semantics-preservingly into this private-block format
by doubling each clause with fresh positive/negative
private literals.  Thus source access invalidates the
suggested oracle-to-general-SAT lower-bound transfer.

\paragraph{Correct paths, soundness and polarity.}
Every explicit CNF has a uniform scan returning the
first clause falsified by a complete $z$, or a sentinel
when none is falsified.  An index uses $O(\log M)$ bits.

modulo-five beat relation, or the analogous sentinel.
These short selectors exist on SAT as well as UNSAT
sources.  Their \emph{total absence of a sentinel}

A uniform polynomial verifier with $k=O(\log N)$

certificate system would imply

\section{An explicit-source independent-block search frontier (/095)}
\paragraph{Genuine CNF source embedding (PROVED, restricted).}
T5 remains the primary CSP; this auxiliary source-embedded
Boolean family tests information necessity with real input access.
Let $q\ge1$, $r=2^q$, $m\ge1$ and $h\in\{0,1\}^{r\times m}$.
For $u\in\{0,1\}^{q}$ define
\[
G_u(z)=\bigvee_{i:u_i=0}z_i\ \lor\
       \bigvee_{i:u_i=1}\neg z_i,
\]
which is false exactly when $z=u$. Each cell has
a fresh private variable $y_{u,b}$ and two actual
source clauses
\[
B_{u,b}=(G_u\lor y_{u,b})\land
        (G_u\lor\ell_{u,b}),\qquad
\ell_{u,b}=
\begin{cases}y_{u,b}&h_{u,b}=0,\\
\neg y_{u,b}&h_{u,b}=1.\end{cases}
\]
A duplicate-free variant uses two private variables $y,t$
per cell and the three pairwise distinct clauses
$(G_u\lor y)$,
$(G_u\lor((h=0)?y:\neg y)\lor t)$ and
$(G_u\lor\neg t)$, where the ternary expression
denotes a selected literal, not a new logical connective.
Its exact satisfying-assignment count is
$g(h)\,4^{(r-1)m}$: an active $h=0$ cell
forces $(y,t)=(1,0)$, an active $h=1$ cell is
contradictory, and inactive cells have four
assignments. The independent sign-cell theorem
therefore does not depend on allowing duplicate
CNF clauses.

All private scopes are disjoint. For
$F_h=\bigwedge_{u,b}B_{u,b}$,
\[
\operatorname{UNSAT}(F_h)\iff
 \bigwedge_{u\in\{0,1\}^{q}}\bigvee_{b=1}^{m}h_{u,b},
\quad
\#\operatorname{SAT}(F_h)=
 \#\{u:\forall b,\ h_{u,b}=0\}\,2^{(r-1)m}.
\]
Each $h_{u,b}$ is a distinct real literal-sign input
bit. There are $2rm$ clauses of width $q+1$
and $\Theta(rm(q+1))$ literal occurrences,
so physical input length $N=\Omega(rm)$.

\paragraph{Precisely surviving query lower bound.}
With the fixed source skeleton promised and one
independently probed cell per sign, the deterministic
adaptive sign-probe decision complexity is exactly
$rm$. Return zero to the first $m-1$ distinct probes
per row and one on its last probe, regardless of
interleaving. Any incomplete row could still be all-zero
or contain a one, so both answers are consistent.
A direct fully authenticated parser decides this
special family in $O(N)$ time. Thus the surviving
$\Omega(rm)$ source-probe lower bound is at most
linear in real input length and yields no superlinear
or superpolynomial SAT decision lower bound.
If a machine word exposes $w$ signs, the generic
word-probe lower bound is only $\Omega(rm/w)$.
Syntax authentication remains charged.

\paragraph{Correct-path soundness and resources.}
A source-verified UNSAT path supplies one column
per each of the $r$ rows, with read-only advice length
$k_-=r\lceil\log_2m\rceil$ bits and $r$ checked signs.
A SAT path supplies one zero row, with $k_+=q$
bits and all $m$ signs checked. An authenticated
sequential source and certificate-tape parser runs
in $O(N)$ time and $O(q\log(rm)+\log m)$
writable bits; materializing all negative advice
as writable data adds $k_-$ bits. Invalid or wrong
advice is rejected rather than accepted. Enumerating
negative paths costs up to $m^r$ trials; adapting
the path or using alternating quantifiers charges
all failed probes, child calls, and universal branches.
For an arbitrary source, negative child claims still
require genuine refutations, not only indices.

If rows are *already* the $2^q$ shared assignments,
the row count must not be multiplied by a second
$2^q$ enumeration factor. If they represent an
independent axis, the older conditional
$1.3105+\log_N(2^q)$ exponent ledger applies
with authenticated materialization and space charges.
