\section{Status and end-to-end target}
This paper establishes restricted but fully constructive source-to-output exact-counting pipelines for canonical strict proper 3-CNF encodings of bipartite independent sets. It proves a future-count-continuation congruence; constructs a polynomial-time sufficient frontier signature on connected even cycles; and discovers false-twin quotient cycles in arbitrarily relabeled original graphs of unbounded treewidth, evaluating exact counts by a four-register weighted matrix trace. These examples retain exponentially increasing fixed-formula assignment-tensor rank. These are \textbf{PROVED/EXACT} in the stated models, with independent mathematical review \textbf{OPEN}. Finite tests are \textbf{COMPUTATIONAL}. No unrestricted SAT or circuit lower bound follows. \textbf{P versus NP remains OPEN}.

The fixed target, D2-COUNT-PIPELINE, is encoded source bytes $\to$ full parse and family authentication $\to$ recovered graph neighborhoods $\to$ charged matching recognizer, source-discovered connected-cycle frontier DP, source-discovered false-twin quotient with cyclic weighted register evaluation, or general exact weighted union DP $\to$ the exact integer $\#F$. A valid non-family width-at-most-three CNF is counted by a terminating exhaustive fallback. Malformed sources are rejected. This is a total exact-counting method on its declared valid-input domain, not a polynomial-time general \#SAT algorithm. We do not replace counting by mere satisfiability or by evaluation of a single assignment.

\section{Authentic source and semantic proof}
Fix $a,b\geq 0$ and a simple graph $G=(A\sqcup B,E)$ with every edge crossing, $|A|=a$, $|B|=b$. The input is a DIMACS source containing a declared \texttt{c split a b} and \texttt{p cnf a+b+3 m+7}. Its first seven proper ternary clauses on three fresh variables $p,q,r$ exclude each nonzero triple. For every original edge $\{u,v\}$, $u\in A,v\in B$, add $(\neg u\lor\neg v\lor p)$. The parser checks the header, literal ranges, ordered pin clauses, split, crossing-edge form and duplicate edges. The input bit length $N$ includes headers, addresses, clauses and all whitespace.

\paragraph{Lemma 1 (unique pins, pointwise and exact-count semantics).}
The pins are forced to $(0,0,0)$. Every independent-set assignment of the original $a+b$ variables has \emph{exactly one} satisfying extension; every violating assignment has none. In particular,
\[
\#F_G=\sum_{S\subseteq A}2^{b-|U(S)|},\qquad
U(S)=\bigcup_{u\in S}N_G(u)\subseteq B.
\]
\emph{Proof.} Each of the seven pin clauses excludes exactly one distinct nonzero pin value, leaving only zero. With $p=0$, an edge clause becomes $\neg u\lor\neg v$, forbidding selecting both endpoints. For a fixed left set $S$, precisely the right subsets avoiding $U(S)$ remain. Their count is $2^{b-|U(S)|}$. The pin extension is unique. \hfill$\square$

These are fixed-formula assignment constraints and exact counts, not a lower bound for the SAT decision function on encoded inputs. The all-zero original assignment supplies a cheap SAT witness.

\section{Paid union-state evaluator}
Let $F_t=\{U(S):S\subseteq A_{\le t}\}$, $r_t=|F_t|$, $r=\max_t r_t=r_a$. Store for each actual $U\in F_t$ an integer $W_t(U)$ counting left-prefix sets giving that union. Initially $W_0(\varnothing)=1$. For each real state $(U,w)$ at step $t+1$, add $w$ to keys $U$ and $U\cup N(a_{t+1})$. Repeated keys are consolidated by exact integer addition. Finally output
\[
Z=\sum_{U\in F_a} W_a(U)\,2^{b-|U|}.
\]

\paragraph{Lemma 2 (end-to-end counting correctness).}
For every valid recognized source the evaluator returns exactly $\#F_G$. For every other valid declared width-at-most-three CNF the exhaustive fallback returns its exact count.

\emph{Proof.} The DP starts with the sole empty prefix. Excluding and including the next left vertex are disjoint and exhaustive choices, and update the forbidden right union exactly as indicated. Induction shows $W_t(U)$ equals the number of prefixes with union $U$. Lemma 1 gives the final count. The fallback evaluates every complete assignment under the input clause list, including an empty or contradictory clause, and so is correct. \hfill$\square$

The earlier TMR-2/053 Boolean-lattice zeta result proves that the assignment-evaluation matrix for the original cross-only relation has rank $r$ over every field. This \emph{representational} equality does not show that all $r$ states must be built by an arbitrary counting or decision algorithm.

\section{A counting-relevant future quotient}
Let $R_t=A_{>t}$. For any realized union $U$ at stage $t$, define the cardinality continuation vector
\[
\sigma_t(U)=\bigl(|U\cup N(S)|:S\subseteq R_t\bigr),
\]
with one fixed order on the future subsets. Write $U\equiv_t V$ precisely when $\sigma_t(U)=\sigma_t(V)$; denote the number of realized classes by $q_t$. This signature is \emph{not} the Boolean residual assignment function.

\paragraph{Theorem 3 (exact two-branch future congruence).}
For $U\equiv_t V$ and next left vertex $u\in R_t$,
\[
U\equiv_{t+1}V,\qquad
U\cup N(u)\equiv_{t+1}V\cup N(u).
\]
After all left vertices are processed, equivalent unions contribute the same number of right-side completions. Thus a weighted evaluator can merge equivalent states at every stage while preserving the exact final integer count.

\emph{Proof.} Every continuation $S\subseteq R_{t+1}$ is also a subset of $R_t$, so the old signature equates $|U\cup N(S)|$ and $|V\cup N(S)|$. It also equates the two unions after adjoining $u$, because $S\cup\{u\}\subseteq R_t$. Both successor choices therefore have identical new signatures. At $t=a$ the only remaining subset is empty, so equivalence means $|U|=|V|$ and hence identical factors $2^{b-|U|}$. Integer weights add without losing multiplicity. \hfill$\square$

The exact signature can require enumerating $2^{a-t}$ future subsets per queried state; computing it is \textbf{NOT FREE}. The published executable runs this expensive construction only as a finite independent audit. A claimed asymptotic speedup must supply a constructive smaller signature and pay for its discovery, switches and evaluation.

\section{One family with exponential rank but polynomial exact counting}
For a perfect matching of $k$ original left and $k$ original right variables, after $t$ left variables
\[
r_t=2^t,\qquad
q_t=t+1,\qquad
\operatorname{rank}_K(D_{G_k})=2^k
\quad\text{for every field }K.
\]
Indeed, each matching neighborhood is a distinct singleton. A continuation's union size is $j+|S|$ when the current left set has size $j$; therefore its signature depends only on $j\in\{0,\ldots,t\}$. The paid source recognizer checks that every original vertex has degree at most one and that all edges have the authenticated form. Writing $m=|E|$ and allowing isolated vertices, it returns
\[
\boxed{\#F_G=3^m\,2^{a+b-2m}.}
\]
The arithmetic is repeated exact multiplication and output; no exponential state table is constructed. This is a \emph{fully implemented fixed uniform} polynomial-time algorithm for a restricted \#CNF family, not a uniform polynomial-time method for arbitrary \#3SAT.


\section{A constructed future-count frontier for connected cycles}
The previously defined full future vector $\sigma_t(U)$ may take exponentially many entries to evaluate. For a specified ordering of left vertices define processed/future neighborhood masks
\[
P_t=\bigcup_{i\le t}N(a_i),\qquad Q_t=\bigcup_{i>t}N(a_i),\qquad B_t=P_t\cap Q_t.
\]
For every realized prefix union $U\subseteq P_t$ write
\[
\kappa_t(U)=(h,X)=(|U|,U\cap B_t),\qquad f=\max_t|B_t|.
\]
This is a computable \emph{sufficient refinement} of equality of complete future-count signatures; the partition is not claimed minimal.

\paragraph{Theorem 4 (explicit paid count-congruence).}
For every graph and every supplied left order, equal $\kappa_t$ keys imply equal $\sigma_t$ vectors. The exact successor keys for a next-left neighborhood $H=N(a_{t+1})$ are
\[
\begin{array}{ll}
\mathrm{exclude}:&(h,X\cap B_{t+1}),\\
\mathrm{include}:&(h+|H|-|X\cap H|,(X\cup H)\cap B_{t+1}).
\end{array}
\]
The weighted evaluator on these keys counts exactly $\#F_G$ using at most $(b+1)2^f$ simultaneous states and $2a(b+1)2^f$ two-branch transitions.

\emph{Proof.} Since $N(S)\subseteq Q_t$ for any future set $S$ and $U\subseteq P_t$,
$U\cap N(S)=(U\cap B_t)\cap N(S)$, so
$|U\cup N(S)|=h+|N(S)|-|X\cap N(S)|$.
This proves entire-signature equality. Since $H\subseteq Q_t$, also $U\cap H=X\cap H$. Any previously present vertex still incident to later left vertices lies in the old frontier, implying $U\cap B_{t+1}=X\cap B_{t+1}$. The two updates follow. Inductively, integer weights aggregate every left-prefix assignment, counting shared arcs with multiplicity. At termination $B_a=\varnothing$ and the completion contribution of (h,empty) is exactly $2^{b-h}$. There are at most $b+1$ values of $h$ and $2^f$ distinct boundary masks. \hfill$\square$

\paragraph{Theorem 5 (connected, authentically recognized family).}
Every properly encoded, arbitrarily relabeled connected bipartite even cycle $C_{2k}$, $k\ge3$, is recognized by a deterministic source parser, degree-two checks and a complete alternating-cycle traversal. The traversal constructs a left order with $|B_t|=2$ at each interior stage and zero at endpoints. Therefore the entire source-to-count chain has polynomial work and space, and returns exactly
\[
\#F_{C_{2k}}=L_{2k},
\]
the classical Lucas independent-set count. Nevertheless the fixed-formula assignment matrix across its original left/right variables satisfies
\[
\operatorname{rank}_K(D_{C_{2k}})\ge2^{\lfloor k/2\rfloor}
\quad\text{over every field }K.
\]
\emph{Proof.} In a connected degree-two bipartite graph an alternating walk visits each vertex before returning to its start. Authentication explicitly checks that all $k$ left vertices were visited, excluding disconnected cycle unions. The cyclic left order leaves exactly two right vertices incident to both processed and future left vertices. Theorem 4 computes the exact independent-set count; its equality to the classical Lucas recurrence is an independent characterization, not an oracle used by the evaluator. Choose $\lfloor k/2\rfloor$ pairwise separated left vertices with disjoint right neighborhoods. Their subsets produce $2^{\lfloor k/2\rfloor}$ distinct unions; the exact subset-zeta theorem of TMR-2/053 says their number is precisely the matrix rank over any field. \hfill$\square$

The cycle has treewidth two, is Horn/Krom after the uniquely forced pin elimination, and has an explicit zero satisfying assignment. This is an end-to-end falsifier for a static-rank-to-necessary-exact-counting-work transfer, not evidence of general SAT hardness. The code discovers its order without advice. Its frontier key avoids computing the exponential full future vector.


\section{A constructed weighted-register transfer beyond bounded original treewidth}
The new dependency \textbf{D2-CROSS-MODEL-COUNT-INTERFACE} is closed for an authenticated \emph{false-twin blow-up of an even cycle}. It is not closed for arbitrary shared circuits. Let the left false-twin classes $A_0,\ldots,A_{k-1}$ have sizes $\alpha_i\ge1$, the right classes $B_0,\ldots,B_{k-1}$ have sizes $\beta_i\ge1$, with $k\ge3$ and quotient edges precisely $(A_i,B_i)$ and $(A_{i+1\bmod k},B_i)$. Every quotient edge represents a complete bipartite subgraph. All group memberships, sizes and cyclic order must be \emph{discovered from the original encoded graph}, not supplied as additional input.

\paragraph{Theorem 6 (exact authenticated twin-cycle transfer).}
The existing seven-pin strict proper 3-CNF encoding uniquely extends each independent set. Define
\[
w_i(0)=1,\quad w_i(1)=2^{\alpha_i}-1,\qquad
r_i(x,y)=\begin{cases}2^{\beta_i}&x=y=0,\\1&\text{otherwise}.\end{cases}
\]
Then the original complete-assignment count, preserving every multiplicity, equals
\[
\#F_G=\sum_{x\in\{0,1\}^k}\prod_{i=0}^{k-1}w_i(x_i)r_i(x_i,x_{i+1\bmod k})
=\operatorname{tr}\left(\prod_{i=0}^{k-1}M_i\right),\qquad
M_i=\begin{pmatrix}2^{\beta_i}&1\\ 2^{\alpha_i}-1&2^{\alpha_i}-1\end{pmatrix}.
\]
The algorithm computes the genuine adjacency table, groups identical left rows and right columns, validates that each pair of classes is uniformly complete or empty, and checks that their quotient is one spanning connected alternating degree-two cycle. It then multiplies these $2$-by-$2$ exact integer matrices and prints their trace. It is polynomial time and space on this recognized original-source family.

\emph{Proof.} For a left class, choosing the empty set has multiplicity one, while choosing any nonempty subset has multiplicity $2^{\alpha_i}-1$. A right class is unrestricted exactly when neither adjacent left class is active, giving $2^{\beta_i}$ choices; otherwise it must be all-zero, giving one choice. Conditional on the entire left activity vector, all these group choices are independent. Their product therefore counts every original independent set exactly once. Expansion of the matrix trace sums over precisely the cyclic activity vectors, including the wraparound constraint $x_k=x_0$. The previously proved pin lemma transfers this count bijectively to the actual strict 3-CNF satisfying assignments. Two equal-neighborhood original vertices have identical adjacencies, so their recovered classes induce the complete/empty quotient asserted; the exhaustive degree, connectivity and cycle traversal validates the ordering used. All transforms and integer operations are explicit and paid. \hfill$\square$

\paragraph{Theorem 7 (unbounded original treewidth and exponential cut rank are compatible with cheap constructed count).}
For the uniform family $\alpha_i=\beta_i=g$, the graph has $n=2kg$ original vertices and $2kg^2$ edges. A quotient edge induces $K_{g,g}$; contracting $g-1$ disjoint edges shows a $K_{g+1}$ minor, so its treewidth is at least $g$. Choosing $g=k$ gives $\operatorname{tw}(G_k)\ge k$ with $n=2k^2$. Nevertheless Theorem 6 gives a polynomial source-to-count algorithm. Over \emph{every} field $K$ the fixed-formula left:right assignment matrix satisfies
\[
\operatorname{rank}_{K}(D_{G_k})\ge 2^{\lfloor k/2\rfloor}.
\]
\emph{Proof.} The exact neighborhood-zeta theorem proves rank equals the number of distinct unions of left neighborhoods. Choose $\lfloor k/2\rfloor$ nonconsecutive quotient-left classes. Their quotient-right neighborhoods are pairwise disjoint and nonempty. Selecting one representative from any subset yields $2^{\lfloor k/2\rfloor}$ distinct original-right neighborhood unions. The treewidth claim follows from the stated clique minor. The algorithm and its costs follow from Theorem 6. \hfill$\square$

\paragraph{Same-realization weighted register and cost.}
The named invariant supplied to TMR-4 is \textbf{D2-TWIN-TRANSFER-TRACE}: the actual retained four integers $P_t$ satisfy $P_0=I$ and $P_{t+1}=P_tM_t$; each entry is the exact weighted path sum between specified starting/current group activity bits. At the end the output is $\operatorname{tr}(P_k)$. This is an executable arithmetic-register correctness invariant \emph{not} a monotone necessary-work measure for unrestricted solvers. The complete physical interface covers every original source byte, pin and graph check, duplicate detection, both-side twin comparisons, all quotient completeness and connectivity checks, discovered cyclic order, shifts for $2^{\alpha_i}$ and $2^{\beta_i}$, eight integer multiplications and four integer additions per stage, live buffers, printout, failed recognitions, alternate methods and correct fallback. No quotient oracle or free unbounded-precision arithmetic is assumed.

For complete source bit length $N$, an intentionally conservative \emph{single deterministic locally headed multitape realization} has $T=O(N^8)$ and $S_{\rm peak}=O(N^3)$ writable bits on the recognized subclass. The source adjacency table, grouping, quotient/order, current/next matrices, exact count and output are simultaneously charged. All register values have at most $n+1$ bits because they count partial completions; $8k$ schoolbook multiplications of $O(n)$-bit nonnegative integers take $O(kn^2)$ bit operations apart from charged address seeks. The unrecognized-family exact-count fallback is correct but may be exponential. This theorem concerns an easy class of Horn/Krom formulas after pin elimination, \emph{not} a SAT decision lower bound.

\section{Same-realization resource ledger and TMR-4 interface}
For an ordinary deterministic multitape implementation with balanced lookup (not unit-time hash oracles), masks need $b$ bits and multiplicities need at most $a+1$ bits. Let $N$ be full original source bits, $r=r_a$. Conservative upper bounds for source validation, graph construction, integer arithmetic, all $2|F_t|$ transitions, lookups, retaining tables and producing the exact output are
\[
T_{\mathrm{union}}=O(N^3+a r(N+a+b)^3),\qquad
S_{\mathrm{union}}=O(N^2+r(N+a+b)^2).
\]
On recognized degree-at-most-one sources, the \emph{same} parser/recognizer/product-output execution has
\[
T_{\mathrm{match}}=O(N^3),\qquad S_{\mathrm{match}}=O(N^2).
\]
These are intentionally conservative bit-machine bounds, not an unperformed instruction-level replay. For a graph with a \emph{specified or actually discovered} left order and maximum frontier $f$, put $R=(b+1)2^f$. The same source-authenticating, frontier-generating, two-table integer-DP and output execution admits
\[
T_{\mathrm{frontier}}=O(N^3+aR(N+a+b)^3),\qquad
S_{\mathrm{frontier}}=O(N^2+R(N+a+b)^2).
\]
For the authenticated cycle, $f=2$, $a=b=k\le N$; hence a conservative single-realization bound is $T=O(N^6)$ and $S_{\rm peak}=O(N^4)$ bits. Parser, graph discovery, order selection, all branch updates, masks, exact integers, input seeks, caches and output are included; the published V8 hash table is not itself a physical Turing-machine trace. A nonfamily input retains the correct exponential fallback. For the explicit finite signature audit, add at least $\sum_t q_t2^{a-t}$ suffix-subset inspections and the required union/popcount bit costs; those are not part of the production matching route. An arbitrary non-family source uses exhaustive enumeration and is not claimed to obey the matching bound. Network sequential work and aggregate live storage cannot be replaced by span or worker-local storage.

The named proposed invariant for TMR-4 is \textbf{D2-CERTIFIED-COUNT-FRONTIER}: the actual constructed frontier keys $(h,X)$, exact integer weights, source/graph authentication, discovered order, boundary masks and charged zero/one transitions. The prior \textbf{D2-FUTURE-QUOTIENT} remains the number and identifiers of \emph{actually materialized} future-count-continuation classes in the stated integer-weighted, left-to-right evaluator, together with the exact stored weights. Its transition interface includes source authentication, explicit edge/neighborhood generation, both state updates, paid equality tests/merges, graph-specific simplifications, alternative algorithms, caching, sharing, recomputation, adaptive switching and all output. An unrestricted solver need not materialize this domain. This is a legitimate restricted correctness invariant, \emph{not} a necessary work lower bound for every SAT or \#SAT machine.
