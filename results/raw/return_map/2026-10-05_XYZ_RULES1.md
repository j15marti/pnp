# XYZ-RULES1 typed propagation engine

Status: COMPUTATIONAL / PROVED-EXACT only for the stated finite tests. P versus NP remains OPEN.

## State types

X_i is immutable variable identity. In the prime-labelled interpretation X_i carries a unique prime token, but no factorization hardness is assumed.

Y_i is a Boolean value in {0,1,unresolved}.

Z is a typed live constraint. Implemented types:
POS/NOT are represented as literal incidence polarity; UNIT; OR2; OR3; EQ; NEQ; IMP.

Every Z constraint carries a support set of X identities. Support is provenance/audit metadata and is not itself a computational lower bound.

## Propagation rules

UNIT(l) forces its literal true.
OR2/OR3: if one literal is true, the constraint is satisfied; if all known literals are false and exactly one remains unresolved, force that literal true; if all are false, contradiction.
EQ(i,j): a known endpoint copies to the other; unequal known endpoints contradict.
NEQ(i,j): a known endpoint forces the complement at the other; equal known endpoints contradict.
IMP(i,j): i=1 forces j=1; j=0 forces i=0; i=1,j=0 contradicts.
Assignments are monotone. Attempting to assign both values to the same Y point creates contradiction.
Identity/support labels never silently change.

## Exhaustive local validation

n=1 through n=5.
All single constraints of the implemented kinds, with every partial assignment over {unresolved,0,1}.
Cases checked: 46,572.
Failures: 0.

Failure means either an unsound propagated assignment or a missed contradiction for a single local constraint. Thus the implemented local transition table is exact on this finite test domain.

These are finite diagnostics only. Local propagation is deliberately incomplete for global logical consequence. The low recall is not hardness evidence. In particular, 2SAT has an efficient global SCC algorithm, XOR has Gaussian elimination, and bounded-width families admit compact dynamic programming despite local propagation gaps.

## Interpretation

The useful object is a typed rewriting system H=(X,Y,Z;R), not raw prime products.

Earlier LIVE-sign tests show unary historical labels collapse to ordinary positive/negative live polarity. Genuinely additional live types arise as relations such as EQ, NEQ and IMP, and higher-arity constraints such as OR3.

The present engine exposes a precise distinction:
1. local propagation closure,
2. exact semantic closure,
3. compact family-specific global closure.

A future lower-bound candidate cannot charge the gap between 1 and 2 unless it also defeats compact global representations in 3.
