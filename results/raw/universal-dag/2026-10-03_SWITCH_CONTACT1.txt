Date: 2026-10-03
Status: COMPUTATIONAL finite experiment plus KNOWN-THEOREM model correspondences. P versus NP remains OPEN.

Idea:
Replace AND/OR gates by literal on/off contacts in a fixed two-terminal network.
Each clause-presence bit x_c directly controls one or more physical-style contacts.
The Boolean output is terminal connectivity.

Classical literature:
- Shannon 1938 established the relay/contact switching-network formulation. Series contacts realize conjunction, parallel contacts disjunction, and normally-closed contacts complementation.
- A general contact scheme is an undirected graph whose edges are labelled by variables or negations; an input accepts iff its enabled-edge subgraph connects the terminals.
- Pudlak-Zak show polynomially related contact-scheme size characterizes nonuniform space logarithmically: CS(F)=DCS(F)=NU-SPACE(log F) in their stated asymptotic framework.
- Jukna 1987 used communication complexity to lower-bound bounded-depth contact-gating schemes, explicitly connecting contact-scheme cuts to information flow.
- Jukna 1988 developed entropy-based lower bounds for contact circuits.
- Potechin proves N^{Omega(log N)} lower bounds for monotone switching networks for directed connectivity, but emphasizes that analogous general-network bounds would touch L versus NL.
- Biclique-cover/rectifier-network literature shows depth-2 and unrestricted routing complexity can differ polynomially; Iván et al. exhibit Cov(G) >= Rect(G)^(3/2-epsilon) separations.

Model used in this experiment:
For fixed m=8, D(n,8) is SAT iff at least one selected pair of clauses has overlapping falsifying subcubes.
Let H_n be that clause-conflict graph.
A depth-2 passive contact component for a biclique K_{A,B} uses:
- |A| parallel contacts x_a from source to an intermediate junction,
- |B| parallel contacts x_b from that junction to sink.
It uses |A|+|B| controlled contacts and realizes all pair terms x_a x_b for A x B.
Putting biclique components in parallel realizes the SAT classifier exactly on the weight-eight promise.
Therefore minimum controlled-contact count in this declared depth-2 architecture is exactly the minimum weighted biclique-cover cost of H_n.

D(4,8):
clause bits = 32
conflict graph edges = 96
maximal biclique types = K_{1,6}, K_{2,2}, K_{6,1}
maximum edge-per-contact efficiency kappa = 1, attained by K_{2,2}
standard |E|/kappa lower bound = 96 contacts

Exact MILP over all maximal bicliques:
minimum weighted biclique-cover cost = 96 contacts
optimum uses 24 K_{2,2} bicliques
each of the 96 conflict edges is covered exactly once
Thus:
C_contact^(depth2)(4,8) = 96
for this declared passive biclique-form model.

D(5,8):
clause bits = 80
conflict graph edges = 960
maximal bicliques enumerated = 15542
maximum efficiency kappa = 42/13, attained by K_{6,7}/K_{7,6}
therefore weighted biclique-cover lower bound:
ceil(960/(42/13)) = 298 contacts
A deterministic greedy cover over the maximal bicliques gives:
605 contacts using 48 bicliques
Thus the currently verified finite interval is:
298 <= C_contact^(depth2)(5,8) <= 605.
The lower bound is exact for the standard efficiency argument, not necessarily the true minimum weighted cover; the upper bound is constructive but not certified optimal.

Key hostile-control insight:
Counting only on/off contacts is insufficient if static wires, junctions, rectifiers, or input fanout are free.
A complicated relation can be embedded into fixed topology while reusing a small number of controlled contacts.
Therefore the useful resource vector must include at least:
C = controlled contact occurrences,
R = static routing/topology complexity (wires/rectifiers/junctions),
L = maximum multiplicity/load of one input control,
D = conductive path depth / propagation delay,
B = cut breadth or communication width,
and, for sequential/intermediate-relay models, T/S = settling cycles and retained relay state.

New candidate augmentation:
multisign clause geometry
 -> conflict/incidence relation
 -> weighted biclique / rectifier factorization
 -> contact/topology cut lower bounds
 -> nonuniform-space / time-space interpretation within the declared network model.

Important limitation:
The switch model does not escape Boolean complexity by itself. Shannon's series/parallel translation shows Boolean operations reappear as network topology. Passive contact schemes are a restricted representation class. Allowing intermediate relays whose outputs control later contacts restores sequential/circuit-like power and requires explicit time/state charging.

Fixed m=8 remains an easy hostile control because the conflict relation supplies polynomial switch/network representations. No unrestricted SAT-time lower bound follows.
