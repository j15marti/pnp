General exact-weight-m cut theorem:
Let N=8*C(n,3) possible genuine 3-clauses and let the promise domain be all m-subsets of [N].
For a passive monotone contact scheme whose connectivity represents a positive class P, let Z
be the number of negative promised inputs. If an s-t cut uses d distinct clause labels, every
m-subset avoiding those labels disconnects. Hence:
C(N-d,m) <= Z.

Define tau_Z=min{d:C(N-d,m)<=Z}.
If every clause label occurs in some negative promised input, every s-t path contains at least
two controlled contacts. Menger then gives:
C_contact >= 2*tau_Z.

For 8<=m<=7*C(n,3), every clause occurs in both a SAT and an UNSAT promised formula:
- UNSAT: embed the clause in an exact 8-clause UNSAT core and add clauses.
- SAT: choose an assignment satisfying the clause and add other clauses satisfied by it.
Therefore the two-contact path lemma applies to either output polarity.

If a final output inversion is free, connectivity may represent SAT or UNSAT.
Let S,U be the exact SAT and UNSAT counts. Any implementation therefore obeys:
C_contact >= 2*min(tau_U,tau_S)
           = 2*tau_max(S,U).
This is the polarity-robust cut/Menger lower bound.

Linear-density asymptotic ceiling:
Let m=alpha*n and N=(4/3)n^3+O(n^2).
If the majority-class fraction q=max(S,U)/C(N,m) tends to a constant q in (1/2,1),
then solving
C(N-d,m)/C(N,m) <= q
gives:
d ~ (N/m)*ln(1/q)
  ~ (4/(3*alpha))*ln(1/q)*n^2.
At exact balance q=1/2:
C_contact >= (8 ln 2/(3 alpha)+o(1))*n^2.
At alpha=4.267 this coefficient is approximately 0.433*n^2.
Thus this count-only cut method has an O(n^2) scale near a balanced linear-density transition.
If either SAT or UNSAT becomes overwhelmingly dominant and final inversion is free, the
polarity-robust bound collapses.

Main falsification:
The count-only passive cut quantity is not a common hardness invariant.
It is controlled primarily by class balance, not by solver difficulty:
- it vanishes on the empirically easy low-density side once output polarity is optimized;
- it peaks near the SAT/UNSAT crossover at only Theta(n^2);
- it vanishes again in the overwhelmingly UNSAT high-density regime where resolution
  proof complexity can still be nontrivial/hard.

This is useful negative evidence. The switch route needs structural information across cuts,
not merely the number of positive/negative promised inputs.

Literature context:
- Random 3-SAT has a sharp-threshold sequence, but for k=3 the exact limiting threshold remains
  unresolved; rigorous bounds remain separated, while physics/empirical predictions place the
  crossover near 4.26.
- ECCC TR26-145 proves an O(n/log n) scaling window for random k-SAT for every fixed k>=3.
- Jukna's entropy/contact-circuit work is directly relevant to the needed augmentation:
  cut complexity should measure inner information/local dependence, not just class cardinality.
