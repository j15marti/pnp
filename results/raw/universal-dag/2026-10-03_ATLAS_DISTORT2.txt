Date: 2026-10-03
Status: COMPUTATIONAL finite experiment + KNOWN-THEOREM model correspondence.
P versus NP remains OPEN.

Target:
Test the repair proposed after SOLUTION-GEOMETRY1:
raw solution geometry -> efficiently acquired tractable atlas -> residual/normalized geometry.

Critical acquisition rule:
A coordinate chart is NOT free merely because the solution set happens to admit it.
In particular, a singleton satisfying set is mathematically affine but is not granted a Gaussian atlas unless the input CNF itself is efficiently recognized as an XOR encoding.
This prevents semantic hindsight from smuggling a SAT solution into the atlas.

Finite experiment:
n in {18,20}.
Random simple genuine 3-SAT at alpha in {3,3.5,4,4.25}, two satisfiable samples per cell.
Controls:
1. CHAIN: planted local 3-CNF with clauses on consecutive triples, density 4.
2. XORR: sparse random rank-(n-4) 3-XOR system encoded as standard four-clause XOR blocks.
3. XORDENSE: high-primal-width affine control. Choose a random 4-dimensional nullspace N; enumerate many weight-3 parity equations from N^perp, all consistent with a planted solution, and encode each as four 3-CNF clauses. The selected equations span rank n-4, so the exact solution set has dimension 4 and 16 assignments.

For every formula:
- exhaustive enumeration of all 2^n assignments;
- raw single-bit solution geometry;
- affine-hull dimension and affine-defect bits = dim(affine hull)-log2(|S|);
- exact primal pathwidth via subset DP for vertex separation;
- exact optimal ordering reconstructed;
- maximum number of extendible solution projections on the path separator of that ordering;
- syntactic recognizer for complete standard four-clause XOR blocks.

Exact control results:

XORDENSE, n=20:
rep A: 304 CNF clauses, 16 solutions, 16 one-bit components, largest component size 1,
20 frozen variables, disconnected-pair fraction 1, exact primal pathwidth 12, maximum live separator projections 16 (4 bits).
rep B: 268 clauses, same 16 singleton components and 20 frozen variables, exact pathwidth 10, maximum live separator projections 16.
Both formulas are syntactically recognized as complete standard XOR-block systems.
Gaussian elimination gives rank 16 and four free coordinates.
Under those acquired coordinates the solution set is exactly F_2^4:
normalized components=1, frozen=0, local flexibility=1, intrinsic/Hamming stretch=1, and no residual affine constraints remain.

CHAIN, n=20:
rep A: 285 solutions, 3 components, 10 frozen variables in largest component, disconnected-pair fraction 0.645.
rep B: 49 solutions, 4 components, 14 frozen variables, disconnected-pair fraction 0.755.
For both instances exact primal pathwidth = 2.
Along an exact optimal pathwidth ordering, the maximum number of extendible separator states is 4 and 3 respectively, requiring at most 2 bits of interface state.

Random 3-SAT, n=20:
alpha 3.0: exact pathwidth 12, live separator projections 139 and 81;
alpha 3.5: pathwidth 14 and 13, live projections 47 and 51;
alpha 4.0: pathwidth 15 and 15, live projections 14 and 22;
alpha 4.25: pathwidth 14 and 13, live projections 14 and 1.
No tested random formula is recognized as a complete XOR-block system.
Typical affine-defect values are positive and large, roughly 5-13 bits in nontrivial samples.

Important acquisition counterexample:
One alpha=4.25 random instance has exactly one satisfying assignment.
Its solution set is mathematically a zero-dimensional affine space and its semantic separator-state count is 1.
Nevertheless the formula has exact pathwidth 13 and is not an XOR-block input.
We therefore do NOT grant it a Gaussian atlas.
This demonstrates why minimizing over coordinate systems after seeing the solution set is circular/free acquisition.

n=18 gives the same qualitative separation:
- XORDENSE: 16 isolated solutions, all 18 variables frozen, pathwidth 11-12, Gaussian atlas -> flat F_2^4.
- CHAIN: pathwidth exactly 2, <=4 live separator states despite 4-12 raw components.
- random 3-SAT: pathwidth 11-14 over the tested densities, no XOR atlas.

Interpretation:
The experiment supports a narrower notion of atlas-normalized distortion:
1. fix an explicit atlas family A with polynomial/FPT-recognizable structure;
2. charge atlas acquisition;
3. normalize only by a chart actually recovered from the same input realization;
4. measure residual geometry/state after normalization.

The current atlas family contains:
- standard XOR-block detection + Gaussian elimination;
- bounded pathwidth decomposition + dynamic programming.

Under this declared atlas, the easy affine and low-pathwidth controls collapse as intended while the tested random 3-SAT formulas do not.

But this is NOT yet a lower-bound invariant.
Main risks:
- atlas incompleteness: another unknown polynomial-time representation may flatten random 3-SAT;
- atlas search: minimizing over all polynomial-time charts could itself encode the SAT solver;
- semantic-state collapse: few remaining solutions can make continuation state counts tiny even when acquiring them is hard;
- no theorem maps large residual atlas-normalized geometry to arbitrary SAT runtime.

Candidate refined object:
For a fixed charged atlas class A, Dist_A(F) = minimum residual geometric/continuation obstruction over charts R that are actually and efficiently acquired from F.
The minimization domain must be syntactically/algorithmically specified in advance, not all coordinate systems that make F easy.

Next target:

Compare affine, bounded-width, Horn/2-SAT, and random 3-SAT residuals.
If a single residual state/cut invariant survives all known tractable charts, then test it against branching-program/bpdim and resolution-width machinery.
