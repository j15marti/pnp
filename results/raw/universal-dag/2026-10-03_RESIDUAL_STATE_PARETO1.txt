Finite rank observation:
At the displayed peak cuts, the GF(2) rank of the residual-completion incidence matrix equals the exact number of active nonterminal continuation classes:
D4: rank 20 = active states 20.
D5: rank 123 = active states 123.
This is a finite COMPUTATIONAL identity for these cuts. It is not a theorem that ordinary rank, projective dimension, or bitwise decomposable projective dimension coincide in general.

Hostile controls:
1. Parity: total parity on N bits has decision depth N but exactly two residual functions at each proper cut, hence continuation-state width 2 (one live bit). Thus the state measure does not confuse maximum decision depth with state complexity on this affine control.
2. Fixed m=8 SAT has an O(n^6) pair-conflict circuit from DN8-FRONTIER1. Therefore growth of read-once residual-state width cannot be promoted to unrestricted SAT hardness.
3. Histories with different selected-count k are allowed to merge because under the exact-weight promise their valid continuation domains are disjoint. Treating k as mandatory state is falsified.

Literature correspondence:
- Bova-Slivovsky 2017 subterm width is a total-function OBDD analogue: number of distinct residual CNFs/subfunctions across prefixes controls OBDD compilation size.
- Dinesh-Koroth-Sarma 2016 bitwise decomposable projective dimension characterizes deterministic branching-program size up to polynomial factors. Ordinary projective dimension alone can be exponentially separated from branching-program size.
- Beame-Jayram-Saks 2001 prove nontrivial time-space tradeoffs for general branching programs, showing that joint state/time restrictions can be stronger than size-only accounting.
- Pebbling/cumulative-memory literature supplies STORE-vs-RECOMPUTE analogues, but no current theorem transfers the present static SAT residual-state certificate to arbitrary RAM computation.

Current interpretation:
The continuation-incompatibility construction is a promise-domain version of a residual/subfunction-state lower-bound method.
The strongest finite observation is not the numerical width itself, but that characteristic-two residual-incidence rank exactly certifies the active state count at the best tested D4/D5 peak cuts.
This gives a concrete finite place to test whether the multisign/product-span machinery can lower-bound a state resource rather than a raw semantic multiplicity.

Limitations:
- The displayed schedules were found heuristically and are not proven globally optimal over all read-once schedules.
- The model is a fixed read-once/nonadaptive clause-bit schedule; adaptive rereading/general branching programs may be smaller.
- active state area and cumulative log-width are model-specific read-once diagnostics, not RAM memory lower bounds.
- bpdim has not been computed for these promise functions, and the published characterization is stated for total Boolean functions.
- P versus NP remains OPEN.
