FORMULA-CONTINUATION4
Date: 2026-10-03
Status: PROVED/EXACT for the declared finite quotient calculations; COMPUTATIONAL for tested 3SAT4 order search. P versus NP remains OPEN.

Target
-----
Replace solution-space continuation with a formula-level decision quotient.

For a finite constraint universe U and an order pi, let P_k be the first k constraint-presence bits and S_k the remaining bits. A prefix history H subseteq P_k induces the residual Boolean function
  r_H(K) = SAT(H union K), K subseteq S_k.
Two histories are equivalent at cut k iff they have the same residual function for every legal suffix K.

Let W_pi(k) be the number of equivalence classes. This is the exact deterministic one-way state count / reduced OBDD width at that cut for the declared presence-bit encoding and order. It is a restricted streaming/ordered-branching resource, not an arbitrary RAM/Turing lower bound.

Canonical residual representation
---------------------------------
Every tested family is a conjunction of constraints over n Boolean assignments. A prefix formula eliminates a set C of assignments. For a suffix constraint set, the residual UNSAT predicate is the positive monotone CNF
  AND_{a notin C} OR_{c in suffix: c falsifies a} z_c.
After deleting duplicate/superset clauses, this antichain is a canonical residual signature. This lets the code compare residual functions exactly without enumerating every suffix formula.

Wrapper controls
----------------
On the complete 3-variable 2-SAT universe:
  BASE M=12 exact min peak 17.
  DEAD: add a tautological/no-effect presence bit, M=13 -> exact min peak 17.
  COPY: add a duplicate copy of an existing clause bit, M=13 -> exact min peak 17.
So the minimized finite quotient survives these DEAD/COPY wrappers in this test.
Output complementation also preserves the class count trivially because it bijectively complements every residual Boolean function.

Literature interpretation
-------------------------
- Aspvall-Plass-Tarjan: 2-SAT is linear-time via implication-graph SCCs.
- Dowling-Gallier: Horn-SAT is linear-time via graph/data-flow/pebbling.
- OBDD residual subfunctions and deterministic one-way communication characterize ordered branching state.
- Chen-Lin-Tsai (WADS 2025), Theorem 31: one-pass streaming 2-SAT requires Omega(n^2) bits, even though offline 2-SAT is linear-time. This is direct evidence that a large formula-continuation quotient is fundamentally a streaming/access-model resource rather than an offline P-vs-NP resource.
- Bova-Slivovsky and Amarilli et al.: solution/knowledge-compilation width can be exponentially large for tractable CNF families; FORMULA-CONTINUATION4 avoids the specific all-solutions compilation error by quotienting only SAT/UNSAT future behavior, but the streaming-model limitation remains.

Falsification / promotion status
--------------------------------
1. The formula-level quotient is a better decision-relevant object than solution-space geometry.
2. It exactly recognizes tractable canonical states as sufficient on the tested 2-SAT, Horn, XOR, and separator controls.
3. Canonical solver states are often substantially over-refined relative to the exact quotient.
4. The quotient is robust to finite DEAD/COPY tests.
5. It is highly clause-order dependent.
6. Most importantly, known one-pass 2-SAT lower bounds prove that large quotient/stream state can coexist with linear-time offline decision.

Therefore:
  FORMULA-CONTINUATION-STATE -> arbitrary SAT runtime remains OPEN.
No P != NP conclusion follows.

Best surviving use
------------------
Treat W as a calibrated minimum state resource under a declared clause-stream/ordered-access model.
The next hostile extension should remove fixed order:
  - adaptive clause-query/FBDD version of the formula-presence decision problem;
  - then read-twice/RECOMP;
  - compare exact small-family quotients with branching-program projective-dimension style invariants.
A useful result would be a state measure that survives adaptive access; a collapse under adaptive access is equally informative.
