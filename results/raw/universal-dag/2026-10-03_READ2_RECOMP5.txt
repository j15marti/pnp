General occurrence lemma
------------------------
Let
  f(x)=AND_j C_j(x)
be a CNF over input variables x_i. Suppose each input variable occurs in at most Delta clauses.
Then f has a deterministic syntactic read-Delta branching program with at most
  L = sum_j |C_j|
query nodes:
process clauses one by one, query their literals until one is satisfied; reject if a clause is exhausted.
A variable is tested at most once per clause in which it occurs, hence at most Delta times on every path.

This is an unconditional construction, not a lower bound.

Occurrence barrier:
Any lower-bound candidate based on a low-occurrence CNF/contact representation is automatically weak against bounded rereading. In particular Delta=2 immediately yields a linear-size read-2 branching program.

Q4 edge-cover representation
----------------------------
The 32 genuine 3-clauses on four Boolean variables correspond bijectively to the 32 edges of Q4:
a 3-clause is falsified by exactly the two assignments differing in the omitted variable.
A selected clause set is UNSAT iff its falsifying edges cover all 16 assignments.
Thus the full clause-presence UNSAT function is
  EC_Q4(x) = AND_{v in V(Q4)} OR_{e incident v} x_e.

Every edge variable occurs in exactly two vertex clauses.

Exact linear-width / read-once calibration

A closed-set dynamic program implementing the Kobayashi-Nakahata commitment method gives:
  lw(Q4)>6,

For edge cover, a read-once ordered computation only needs to remember which frontier vertices are already covered; if a vertex leaves the frontier uncovered, the computation rejects.
The reduced OBDD under this width-7 order has:
  1773 query nodes,
  peak width 128 = 2^7.

This explains the earlier 257 residual-class value: the natural frontier representation has at most 2^7 live coverage states plus terminal behavior; the previous clause-order experiment was not using an optimal edge-frontier order.

Read-2 collapse
---------------
Sequentially verify each of the 16 vertex clauses.
Each vertex block queries at most its four incident edge bits and proceeds as soon as one bit is 1.
The number of query nodes is exactly
  sum_v deg(v)=16*4=64=2|E(Q4)|.
Each edge appears in exactly its two endpoint blocks, so each input variable is queried at most twice on every path.

Therefore:
  size_read2(EC_Q4) <=64.

Relative to the certified width-7 OBDD:
  1773 -> 64 query nodes,
a 96.3903% reduction.

This is a construction, not a minimum-read2 theorem.

Exact-weight-eight promise
--------------------------
For an 8-edge subset of Q4:
  edge cover of all 16 vertices
iff every vertex has degree exactly 1
iff the 8 edges form a perfect matching
iff the corresponding D(4,8) formula is UNSAT.

Hence the SAME 64-node deterministic read-2 program, with terminal labels exchanged, computes SAT correctly on the exact-weight-eight D(4,8) promise.
This is important because output complementation is free in deterministic branching programs (unlike nondeterministic switch-network acceptance).

(1,+k) calibration
-------------------
The 64-node vertex-scan architecture can choose a separate order of the four incident edges at each vertex.
A deterministic seeded search found a concrete set of local orders for which exact MILP verification over all possible computation paths gives:
  at most 17 DISTINCT input variables are queried twice on any path.
The reject-stop / final-accept maxima across the 17 possible stopping cases are:
  0,1,2,2,3,4,6,8,8,9,11,11,13,15,15,17,17.
Thus this explicit construction is also a valid (1,+17)-branching program of size 64.

No claim is made that 17 is the minimum possible k, or that 64 is minimum size for (1,+17).

Interpretation
--------------
This run FALSIFIES Q4 edge-cover / D(4,8) as a candidate for a lower bound that survives read-twice recomputation.

The experiment separates three resources:
  * read-once frontier state: exact graph linear-width 7; certified OBDD width 128;
  * representation size: 1773 query nodes for the certified read-once OBDD;
  * recomputation/reread: 64 query nodes when every edge may be reread at its second endpoint.

Rereading is functioning exactly as a memory-vs-recomputation trade:
instead of retaining enough frontier state to remember whether both endpoints are already covered, the program simply asks an edge value again when checking its second endpoint.

General lesson
--------------
For any graph G,
  EC_G = AND_v OR_{e incident v} x_e
has a syntactic read-2 BP with exactly 2|E| query nodes.
Therefore no edge-cover family can yield superlinear, let alone exponential, read-2 branching-program lower bounds.

More generally, low occurrence Delta in a CNF gives an immediate read-Delta linear-size program.

This does not contradict the (1,+k)/read-k lower-bound literature: those hard functions are designed so that limited rereading does not locally discharge every constraint. Our edge-cover representation has exactly the opposite property.

--------------
