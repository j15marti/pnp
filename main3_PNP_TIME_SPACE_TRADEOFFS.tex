\section{Full declared source-to-output pipeline}
Fix a constant $C\ge2$ and a total deterministic table
\[
\delta:[C]\times\{0,1\}\longrightarrow[C]\times\{0,1\}.
\]
The common authentic original input is a canonical self-delimiting
binary length $B\ge1$, a separator, then exactly $B$ binary
payload symbols $x=x_1\cdots x_B$, of total encoded length
$N=B+O(\log(B+2))$. A charged initial header parse and
source authentication reject malformed encodings in
$O(N\operatorname{polylog}(N+2))$ time and $O(\log(N+2))$
auxiliary space. This also fixes $B$ before selecting the
anchor gap; no uncharged source-length oracle is assumed.
On the authenticated payload the fixed streaming machine
begins with blank STATE and MOVE work tapes. 
The STATE[0] blank denotes initial state $q_0=0$. At authentic 
paid step $i$ it reads the previously written STATE symbol 
$q_{i-1}$ and $x_i$, writes $q_i$ and advances MOVE's work-tape 
head iff $m_i=1$, where
\[
(q_i,m_i)=\delta(q_{i-1},x_i),\qquad
p_i=\sum_{j=1}^{i}m_j.
\]
The source head advances every input step. The graph-service
prefix uses $B$ paid update steps plus a stop; its MOVE head
ends at position $p_B$ and visits $p_B+1$ writable cells,
even if many cells are blank. To make this an authentic
\emph{Boolean decider}, a third writable LENGTH tape advances 
its head once per input step, ending at $B$. At endmarker,
a fixed finite-control comparator moves LENGTH left twice
per one MOVE-left step until the detectable left boundary
is reached. It accepts exactly when LENGTH reaches the
boundary no later than MOVE (including the equality case).
Thus the complete original decider computes
\[
F_\delta(x)=[p_B\ge\lceil B/2\rceil]
\]
in $\Theta(B)$ total paid transitions and $\Theta(B)$
visited work cells from LENGTH, plus MOVE and STATE.
The finite executable checks the graph-service prefix
and the Boolean threshold independently; it does not
run a compiled native comparator transition table.
A space-saving simulator may compute the same output
without physically visiting MOVE's or LENGTH's full path.
This is a decision procedure for this explicitly
restricted family, not SAT.

The pipeline is: encoded source $\to$ blank-start source 
authentication $\to$ authentic canonical checkpoint map 
$\to$ paid virtual state/head-position/graph-label access 
$\to$ height-$B$ left-comb evaluation $\to$ correct Boolean 
output. The original process is allowed to depend on a 
previously written work symbol, but is \emph{constant-state}.

\section{Exact restricted provider theorem}
Choose an anchor separation $1\le L\le B$, put
\[
R=\left\lceil\frac{B}{L}\right\rceil,\quad
w=\left\lceil\log_2 C\right\rceil+
  \left\lceil\log_2(B+1)\right\rceil.
\]
On a machine with an \emph{indexed read-only input port} whose 
address formation and symbol access are charged in 
$\operatorname{polylog}(B+2)$ bit operations, store the 
$R$ genuine records $(q_a,p_a)$ at times 
$a=0,L,2L,\ldots<B$ on an ordinary \emph{sequential} 
writable anchor tape. The input is read and authenticated in 
one full preprocessing pass. The provider answers each adaptive 
query $j\in[B]$ for $(q_j,p_j,m_j)$ by scanning the anchor 
tape to
\[
a_j=L\left\lfloor\frac{j-1}{L}\right\rfloor
\]
and replaying $\delta$ for the at most $L$ source symbols 
$x_{a_j+1},\ldots,x_j$. By induction, every returned triple 
is the exact authentic canonical configuration/edge label.

The restricted Tree Evaluation instance is a left comb of
height $B$: its $j$th leaf is $m_j$, its $j$th 
internal function is $v_j=v_{j-1}+m_j$, and $v_0=0$.
A bottom-up streaming evaluator makes exactly $Q=B$ 
leaf requests and outputs $[v_B\ge\lceil B/2\rceil]$,
which equals $F_\delta(x)$ for every original binary input.

For the \emph{same implementation}, including stored anchors, 
indices, input-access work, sequential anchor-tape seeking,
repeated source reads, the accumulator and output,
\[
S_{\rm all}(B,L)=O(Rw+\log(B+2)),
\]
\[
T_{\rm all}(B,L,Q)=
O\bigl((B+Q(L+Rw))\operatorname{polylog}(B+2)\bigr).
\]
The first $B$ term covers the full source-authentication pass 
and anchor construction. The $Q L$ term covers genuine 
input replays; the $Q Rw$ term pays for sequential anchor 
record access. Registers and arithmetic are simultaneously 
live with the stored records, not borrowed from another run. 
No graph of $B$ labels is kept on a writable tape.

For $Q=B$ and $L=\lceil\sqrt B\rceil$,
\[
S_{\rm all}=O(\sqrt B\log(B+2)),\qquad
T_{\rm all}=O(B^{3/2}\operatorname{polylog}(B+2)).
\]
These are bounds with respect to the \emph{real} $B$-step 
original service. It would be incorrect to rename 
$B^{3/2}$ as the original time by adding padding and then 
claim a new generic cube-root-space simulation.

\section{Tightness in the declared forward-replay architecture}
Suppose checkpoints may only be stored at fixed state times 
and each query must start at the greatest anchor strictly 
before its requested index, with no more than $L$ forward 
steps. The consecutive gaps from time zero to the endpoint 
$B$ are positive, sum to $B$, and each is at most $L$. 
Therefore at least $R=\lceil B/L\rceil$ anchors 
(including the initial one) are necessary. Uniform spacing 
attains this \emph{restricted record-count} bound. It is not
an intrinsic bit-space lower bound: compressed transition 
products, alternate data structures and a fused streaming 
evaluator are legitimate shortcuts.

For this same finite-state family, one forward source scan
computes $F_\delta$ in $O(B\operatorname{polylog}(B+2))$
time and $O(\log(B+2))$ workspace, with no anchor tape 
and no random graph queries. This shortcut is a \emph{positive}
control. The original MOVE service may have used $\Theta(B)$ 
visited work cells; the simulator need not reproduce them 
physically when only its output is required.

\section{Sequential-input firewall and remaining generic bridge}
The indexed source port is a real model qualification. 
On a standard single locally moving read-only input head,
repeated accesses to alternating remote source intervals 
can cost $\Theta(B)$ head moves per query in the specified 
restarted-replay provider. In the executed case 
$B=64,L=8,Q=64$, the alternating query schedule requires 
3,809 source-head seek moves alone. This does not prohibit
caching or a different source schedule.

Williams's general block-respecting reduction uses 
implicitly generated computation graphs and arbitrary

The current comb evaluator uses associativity and the 
finite-state source promise; its improved height dependence 
is \emph{not} a generic evaluator. TMR-3/053 supplies a 
different all-preloaded-checkpoint information bound 
$s+q\ge k$. The present construction concerns only 
canonical blank-start reachable checkpoints. A future 
full-chain theorem must support arbitrary revisited work 
cells, arbitrary adaptive graph/node queries and a proved 
generic evaluator query volume.


\section{A public movement graph does not supply arbitrary canonical work values}
\paragraph{Selected dependency and exact authenticated source.}
TMR-3/055 examines the named \textsf{C3-VALUE-PROVIDER} arrow:
authentic binary circuit word $\to$ blank-start, revisiting-value-tape
evaluation $\to$ a publicly computable value-tape head schedule
$\to$ canonical terminal work-bit $\to$ the Boolean output.
For $n\ge1$, the source word consists of unary $1^n0$ followed by $n$
topologically ordered gate records. Each record has a two-bit operation
code for constant zero, constant one, AND or OR, and two $n$-bit
one-hot predecessor masks. Binary gate masks select earlier gates;
constant gate masks are zero. The length is exactly
\[
N= (n+1)+n(2+2n)=2n^2+3n+1.
\]
A uniform deterministic parser rejects malformed words, duplicate
one-hot marks and references to future gates, without retaining
the whole input in writable memory.

\paragraph{One physical source-to-output service.}
One fixed conventional locally headed multitape machine begins
with blank work tapes and uses a VALUE tape with $n$ visited
binary cells. At stage $j\in\{0,\ldots,n-1\}$ it physically
returns the VALUE head to cell zero, sweeps all $n$ previously
written cells, captures the two source-designated predecessor
bits, then seeks to cell $j$ and writes the gate result.
The source record is recovered by a paid original-input scan,
not a free preloaded gate table. Only constant-bit captures
and $O(\log(n+2))$ counters are retained in addition to VALUE.
By induction, every written cell equals the true value of its
gate; the final work cell is the correct circuit output.

The VALUE-head movement schedule at a stage depends only on
$(n,j)$, regardless of all operations, masks and gate outputs.
It is computable with $O(\log n)$ additional workspace. Its
exact physical macro-operation counts on a valid source are
\[
Q_{\mathrm{read}}=n^2,\quad Q_{\mathrm{write}}=n,\quad
H_{\mathrm{VALUE}}=2n^2-3n+1.
\]
The ordinary locally moving original source head performs
$O(nN)$ movements with paid counters. One complete deterministic
source-to-output execution satisfies the simultaneous upper bound
\[
T=O(n^3\log(n+2)),\qquad
S_{\mathrm{peak}}=O(n+\log(n+2)).
\]
The executed Python checker logs full trajectories and hence is
\emph{not} a native tape-space measurement. The fixed machine
has been specified symbolically, not independently compiled
to its native finite transition table.

\paragraph{P-complete canonical terminal-bit theorem and scope.}
The language of authenticated sources for which the final VALUE
cell contains one is P-complete under uniform logspace reductions.
Membership follows from the preceding physical upper bound.
For hardness, take topologically ordered Circuit Value, which
is P-complete by Ladner~\cite{Ladner1975} and the standard
P-completeness treatment~\cite{GHR1995}. A logspace transducer
replaces each general gate by a dual-rail monotone true/false
pair; NOT swaps rails, and AND/OR use the De Morgan dual.
The transducer outputs unary size and one-hot gate masks using
$O(\log n)$ counters and rescans; append a legal identity
AND($z,z$) to place the true output at the final gate.
The new word has polynomial length and the same Boolean answer.
Thus even an authenticated canonical \emph{one-bit} work-value
provider in uniform $O(\log N)$ workspace and polynomial time
for all these sources would imply $\mathrm{L}=\mathrm{P}$,
which is OPEN. This is a conditional implication, \emph{not}
a superlogarithmic space lower bound, an impossibility of
$O(T^{1/3})$ space, or P versus NP.

Unlike the streaming graph in TMR-3/054, here the movement
schedule is easier than the values, and genuine previous
work-tape symbols must still be read or reconstructed.
The result does not make the \emph{entire} vector of physical
tape-head movements oblivious. Arbitrary adaptive node values
and a genuinely height-sublinear evaluator for general,
nonassociative Tree Evaluation are still OPEN.

\section{A compact, authenticated source whose Tree Evaluation can cost exponentially many queries}
\paragraph{Named dependency and concrete grammar (TMR-3/056).}
The new dependency \textsf{C3-QUERY-VOLUME} asks whether a compact,
uniformly available node/leaf provider justifies an inexpensive
\emph{complete} Tree Evaluation. We separate source recognition,
local node access and evaluator query count.

Fix $k,m\ge1$, $w=\lceil\log_2(k+1)\rceil$. An authenticated bit source
is unary $1^k0$, unary $1^m0$, $k$ quantifier bits
($1=\exists$, $0=\forall$), and $m$ consecutive clauses, each with
three signed $(w+1)$-bit literal records identifying an original
variable in $[1,k]$. Repetitions and complementary literals are
permitted. Exact source length is
\[
  N=2k+m+2+3m(w+1).
\]
A total read-only-source parser rejects invalid headers, indices,
lengths and trailing symbols in $O(N^2)$ bit time and $O(\log N)$
writable bits by rescans. The corresponding complete binary tree
has height $k$; depth-$i$ internal nodes use OR for existential
variables and AND for universal variables. A leaf with path
$a\in\{0,1\}^k$ equals the formula value $F(a)$.
An actual local provider, given a read-only node path, returns a
gate, child descriptor bit or formula leaf in $O(N^2)$ time
and $O(\log N)$ \emph{additional} writable space.
The path itself is \emph{not} free writable memory.

\paragraph{Complete same-execution reference evaluator.}
A left-first depth-first short-circuit evaluator retains a writable
$k$-bit path and at most $O(k)$ branch-return bits, makes
$Q\le2^{k+1}-1$ real node requests, and returns precisely the
original quantified-formula answer by induction over its prefix.
Including the authentication, every node access, original-source
rereads, path operations and output, one fixed deterministic
simulation satisfies
\[
  T_{\rm full}=O(2^kN^2),\qquad
  S_{\rm full}=O(k+\log(N+2)).
\]
The space belongs to the \emph{whole} evaluator, not just the
logarithmic auxiliary service. A conventional parser and evaluator
with locally moving read-only heads may pay up to quadratic source
and descriptor rereads per node, included in this upper bound.
This is not a new sublinear-height evaluator.

\paragraph{PSPACE completeness and exact limitation.}
The authenticated succinct-tree language is PSPACE-complete under
polynomial-time reductions. Membership follows from the above
space-bounded evaluator. For hardness, reduce prenex TQBF by turning
its quantifier-free matrix into a binary circuit, adding functional
width-at-most-three Tseitin clauses, and quantifying the new gate
variables existentially \emph{after} the original prefix. The unique
gate extension preserves the matrix for every original assignment.
Thus a uniform polynomial-time \emph{all-source} succinct-tree
evaluator would imply $\mathrm P=\mathrm{PSPACE}$, which is OPEN.
This is an old class-theoretic consequence applied to an explicit
charged interface, not an unconditional lower bound or a transfer
to the special block-respecting computation graphs in Williams.

\paragraph{A source-aware easy family that forces full query traversal.}
For $n\ge1$, every $q\in\{\exists,\forall\}^n$ and desired bit
$g\in\{0,1\}$, let $e_i=0$ for OR and $e_i=1$ for AND. Introduce
original variables $a_i$ and auxiliary $z_0,\ldots,z_n$, with
quantifier prefix $q(a)\ \exists z_0\cdots\exists z_n$.
Assert $z_0=g$, all exact functional gates
\[
  z_i=(a_i?z_{i-1}:e_i),
\]
and $z_n=1$. Each gate has four literal three-CNF truth-table
clauses, and the two pins are repeated-literal ternary clauses.
There are exactly $k=2n+1$ variables and $m=4n+2$ clauses, with
authentic source length $N=\Theta(n\log n)$.

For a fixed $a$, the functional gates have a unique extension:
starting at $g$, each $a_i=0$ resets the desired value to $e_i$,
while $a_i=1$ preserves it. By backward induction, the subtree
of an original-variable node returns its desired value.
Its $a_i=0$ child returns the neutral value $e_i$, so ordinary
left-first short circuit can never skip the $a_i=1$ branch.
Therefore the whole QBF has value $g$, while that evaluator
must enter all $2^n$ depth-$n$ subtrees:
\[
  Q_{\rm specified}\ \ge\ 2^{n+1}-1.
\]
Nevertheless a single uniform \emph{source-aware} recognizer can
check the precise canonical clause pattern with rescan counters
and return the visible goal bit $g$ in $O(N^3)$ time and
$O(\log N)$ writable space. This is a genuine legal shortcut.
The expensive evaluator is not evidence of unavoidable SAT or
QBF work.

For comparison, under a \emph{black-box} independent leaf-bit
oracle, the all-OR tree needs $2^k$ leaf queries on the
all-zero oracle: flipping any unread leaf changes its root.
This is a query-model lower bound, not an encoded-source machine
lower bound. No complexity conclusion is derived by silently
converting the black-box interface into an ordinary source.

\section{Paid source-indexed frontier evaluator (TMR-3/058)}
\paragraph{Scope and theorem.}
Fix a deterministic finite-alphabet blank-start machine with $p$
writable tapes and an authentic original source $x$ of length $N$.
Suppose the machine is genuinely block-respecting for $B$ time
blocks of $b$ steps, and that a uniform original-source-only
algorithm $G(x,h,j)$ produces the actual active $b$-cell work
block of tape $h$ during time block $j$, in paid time $\tau$ and
workspace $g$. The source parser has peak writable workspace $s_A(N)$ in addition to time $A(N)$. These are \emph{premises} about the real machine,
not guessed graph labels. The generator may depend on $x$ but
not unknown intermediate work-cell contents. Define
\[
F_j=\{(h,a):\exists i\le j,\ \exists k>j,\
G(x,h,i)=G(x,h,k)=a\},\quad
w=\max_{0\le j\le B}|F_j|.
\]
For every authentic source with this schedule contract, one
uniform sequential simulator determines the same accept/reject
answer, with simultaneous resources
\[
S=O(s_A(N)+(w+p)(b+\log(B+2))+g+\log(N+B+2)),
\]
\[
T=O(A(N)+pB^2(\tau+1)+
Bp(w+p)(b+\log(B+2))+Bb),
\]
where $A(N)$ is charged source authentication and $\tau$ includes
all source-head seeks, indexing and restoration of the simulated
input-head location. No second machine's memory or parallel span
is substituted. These bounds are polynomial in $N$ if all the
named input parameters and the generator runtime are polynomial.
They do not apply to arbitrary adaptive work-dependent schedules.

\emph{Proof.}
At block $j$ use the authentic indices from $G$ to load the
at most $p$ active block contents from a sequential dictionary.
If a block is absent it is truly blank: previously touched
blocks are discarded only when they have no later access.
Simulate all $b$ genuine transitions of the finite machine,
paying the original read-only-source head operations. For each
active block enumerate its authentic future block indices by
calling $G$ at later times and retain its updated contents if
and only if it is visited again. Other entries remain retained.
Induction gives the exact real finite control and tape blocks
at every step. The retained dictionary after $j$ is precisely
the future-live set and has at most $w$ entries; while processing
$j$, at most $p$ additional $b$-cell buffers are present.
Each entry has $O(b+\log B)$ bits. The procedure makes at most
$pB^2$ paid generator calls, $O(Bp(w+p))$ sequential table
inspections and $Bb$ actual local transition simulations.
The final bit is thus exact on the same total execution. $\square$

\paragraph{Authentic nonlinear time-cell witness.}
Canonical binary inputs are $1^B0x$ for $B\ge1$ and
$x\in\{0,1\}^{B}$, of length $N=2B+1$; malformed sources
are rejected. A fixed blank-start, nearest-neighbor one-work-tape
machine processes each $x_j$ in finite control. When $x_j=1$
it makes an extra genuine read-only bounce through addresses
$j-1,j-2,j-1$; it then always visits
$j-1,j-2,j-1,j$, captures the values $a$ and $p$ of
$j-2$ and $j-1$, and writes
\[
c_j=(p\land a)\oplus x_j,\qquad c_{-1}=c_0=0.
\]
The source bit chooses the public schedule, while the real
transition is nonlinear in two independently variable past
values for $j=3$. There are exactly
$H=4B+3\sum_jx_j$ genuine work-tape accesses and $B+2$
distinct visited cells. The original-source-indexable schedule
uses $O(\log N)$ space and $O(N)$ time per requested position.
Its past/future address frontier is at most two. A chronological
virtual-cell evaluator retaining only these two cells, with
paid future-access scans, computes the correct output in
$O(NH^2)=O(N^3)$ sequential time and $O(\log N)$ workspace,
including all source rereads, header checks, indices and
output. The original work tape visits $\Theta(B)$ cells.
A more direct two-register streaming shortcut is legal and
cheaper; this is an \emph{upper-bound} construction, not
a hardness lower bound. This genuine cell-time example is not
asserted to be the output of Williams's separate
$b\ge\log t$ block-respecting conversion.

\section{A genuine Williams-image Fibonacci query-volume falsifier (TMR-3/057)}

\paragraph{Authentic encoded source and physical service.}
For integers $b\ge3$, $B\ge1$ and $x_j\in\{0,1\}$ define
\[
X_{b,B,x}=1^{b-1}0
\prod_{j=1}^{B}\left(x_j1^{b-2}0\right),
\qquad N=b(B+1).
\]
One fixed parser validates the unary header and all records in
$O(N\log(N+2))$ time and $O(\log(N+2))$ writable space,
rejecting malformed sources. On a fresh blank work tape, one fixed
finite-control service moves its head right $b-1$ times during the
header, then alternates access between physical cells $b-1$ and
$b$ across the successive $b$-step source records. At each record's
first symbol, it reads its current work-cell bit $a$, updates the
one-bit control $p$ by $p\leftarrow p\oplus a\oplus x_j$,
and writes the new $p$ into that cell. At the delimiter zero,
it crosses the work-block boundary and reverses direction.
The head stays within one work block during each record until the
final boundary step, so the authenticated suffix is
block-respecting. The suffix pays $N$ read-only-source steps,
$b-1+B$ actual work-head moves, and $b+1$ distinct visited
writable cells, plus terminal output. No checkpoint or movement
trace is preloaded.

With $c_{-1}=c_0=0$, the genuine mutable-cell dynamics obey
\[
\boxed{c_j=c_{j-1}\oplus c_{j-2}\oplus x_j.}
\]
The old symbol at stage $j\ge3$ is physically the value last
written during stage $j-2$, while finite control stores
$c_{j-1}$. Both predecessor arguments are semantically relevant
as source bits vary. Thus the Williams Section~3.2 graph of
\cite{Williams2025}, restricted to its work-tape stage nodes,
contains the mandatory state-time edge $(j-1,j)$
and distinct last-work-block edge $(j-2,j)$ for all $j\ge3$.
Other genuine tape/source edges are not erased.

\paragraph{Exact query recurrence for a named, deliberately naive evaluator.}
For the fixed no-cache, two-child recursive unrolling of those
authentic work-data dependencies, let $Q_j$ count positive-index
stage-node calls. Then $Q_{-1}=Q_0=0$ and
\[
Q_j=1+Q_{j-1}+Q_{j-2},
\qquad
\boxed{Q_B=F_{B+2}-1=2^{\Omega(B)}}
\]
for Fibonacci $F_0=0,F_1=1$, proved by induction.
The complete depth-first recursive implementation with a
locally moving source head obeys the \emph{same-run} upper ledger
\[
 \Omega(Q_B)\le T_{\rm recursive}=O(N^2 Q_B+N^2),\qquad
 S_{\rm recursive}=O(B\log(N+2)).
\]
Every source seek, invocation, return frame and final output is
charged. In the cofinal family $b=s$, $B=s^2$, $N=s^3+s$,
this named evaluator must perform
$Q_B=2^{\Omega(N^{2/3})}$ calls, even though its actual
underlying graph has only $O(B)$ distinct stage nodes and
constant indegree. This \emph{falsifies polynomial time for
that naive image evaluator}, not for Cook--Mertz or other
shared algorithms.

Induction proves both-label output equivalence, and the same
parser rejects malformed encodings. This separate complete

It does not simulate physically visiting the original
