\section{Full declared source-to-output pipeline}
Fix a constant $C\ge2$ and a total deterministic table
\[
\delta:[C]\times\{0,1\}\longrightarrow[C]\times\{0,1\}.
\]
On original read-only binary source $x=x_1\cdots x_B$ the fixed 
streaming machine begins with blank STATE and MOVE work tapes. 
The STATE[0] blank denotes initial state $q_0=0$. At authentic 
paid step $i$ it reads the previously written STATE symbol 
$q_{i-1}$ and $x_i$, writes $q_i$ and advances MOVE's work-tape 
head iff $m_i=1$, where
\[
(q_i,m_i)=\delta(q_{i-1},x_i),\qquad
p_i=\sum_{j=1}^{i}m_j.
\]
The source head advances every input step. The graph-service
prefix uses $B$ paid update steps plus a stop; its MOVE head
ends at position $p_B$ and visits $p_B+1$ writable cells,
even if many cells are blank. To make this an authentic
\emph{Boolean decider}, a third writable LENGTH tape advances 
its head once per input step, ending at $B$. At endmarker,
a fixed finite-control comparator moves LENGTH left twice
per one MOVE-left step until the detectable left boundary
is reached. It accepts exactly when LENGTH reaches the
boundary no later than MOVE (including the equality case).
Thus the complete original decider computes
\[
F_\delta(x)=[p_B\ge\lceil B/2\rceil]
\]
in $\Theta(B)$ total paid transitions and $\Theta(B)$
visited work cells from LENGTH, plus MOVE and STATE.
The finite executable checks the graph-service prefix
and the Boolean threshold independently; it does not
run a compiled native comparator transition table.
A space-saving simulator may compute the same output
without physically visiting MOVE's or LENGTH's full path.
This is a decision procedure for this explicitly
restricted family, not SAT.

The pipeline is: encoded source $\to$ blank-start source 
authentication $\to$ authentic canonical checkpoint map 
$\to$ paid virtual state/head-position/graph-label access 
$\to$ height-$B$ left-comb evaluation $\to$ correct Boolean 
output. The original process is allowed to depend on a 
previously written work symbol, but is \emph{constant-state}.

\section{Exact restricted provider theorem}
Choose an anchor separation $1\le L\le B$, put
\[
R=\left\lceil\frac{B}{L}\right\rceil,\quad
w=\left\lceil\log_2 C\right\rceil+
  \left\lceil\log_2(B+1)\right\rceil.
\]
On a machine with an \emph{indexed read-only input port} whose 
address formation and symbol access are charged in 
$\operatorname{polylog}(B+2)$ bit operations, store the 
$R$ genuine records $(q_a,p_a)$ at times 
$a=0,L,2L,\ldots<B$ on an ordinary \emph{sequential} 
writable anchor tape. The input is read and authenticated in 
one full preprocessing pass. The provider answers each adaptive 
query $j\in[B]$ for $(q_j,p_j,m_j)$ by scanning the anchor 
tape to
\[
a_j=L\left\lfloor\frac{j-1}{L}\right\rfloor
\]
and replaying $\delta$ for the at most $L$ source symbols 
$x_{a_j+1},\ldots,x_j$. By induction, every returned triple 
is the exact authentic canonical configuration/edge label.

The restricted Tree Evaluation instance is a left comb of
height $B$: its $j$th leaf is $m_j$, its $j$th 
internal function is $v_j=v_{j-1}+m_j$, and $v_0=0$.
A bottom-up streaming evaluator makes exactly $Q=B$ 
leaf requests and outputs $[v_B\ge\lceil B/2\rceil]$,
which equals $F_\delta(x)$ for every original binary input.

For the \emph{same implementation}, including stored anchors, 
indices, input-access work, sequential anchor-tape seeking,
repeated source reads, the accumulator and output,
\[
S_{\rm all}(B,L)=O(Rw+\log(B+2)),
\]
\[
T_{\rm all}(B,L,Q)=
O\bigl((B+Q(L+Rw))\operatorname{polylog}(B+2)\bigr).
\]
The first $B$ term covers the full source-authentication pass 
and anchor construction. The $Q L$ term covers genuine 
input replays; the $Q Rw$ term pays for sequential anchor 
record access. Registers and arithmetic are simultaneously 
live with the stored records, not borrowed from another run. 
No graph of $B$ labels is kept on a writable tape.

For $Q=B$ and $L=\lceil\sqrt B\rceil$,
\[
S_{\rm all}=O(\sqrt B\log(B+2)),\qquad
T_{\rm all}=O(B^{3/2}\operatorname{polylog}(B+2)).
\]
These are bounds with respect to the \emph{real} $B$-step 
original service. It would be incorrect to rename 
$B^{3/2}$ as the original time by adding padding and then 
claim a new generic cube-root-space simulation.

\section{Tightness in the declared forward-replay architecture}
Suppose checkpoints may only be stored at fixed state times 
and each query must start at the greatest anchor strictly 
before its requested index, with no more than $L$ forward 
steps. The consecutive gaps from time zero to the endpoint 
$B$ are positive, sum to $B$, and each is at most $L$. 
Therefore at least $R=\lceil B/L\rceil$ anchors 
(including the initial one) are necessary. Uniform spacing 
attains this \emph{restricted record-count} bound. It is not
an intrinsic bit-space lower bound: compressed transition 
products, alternate data structures and a fused streaming 
evaluator are legitimate shortcuts.

For this same finite-state family, one forward source scan
computes $F_\delta$ in $O(B\operatorname{polylog}(B+2))$
time and $O(\log(B+2))$ workspace, with no anchor tape 
and no random graph queries. This shortcut is a \emph{positive}
control. The original MOVE service may have used $\Theta(B)$ 
visited work cells; the simulator need not reproduce them 
physically when only its output is required.

\section{Sequential-input firewall and remaining generic bridge}
The indexed source port is a real model qualification. 
On a standard single locally moving read-only input head,
repeated accesses to alternating remote source intervals 
can cost $\Theta(B)$ head moves per query in the specified 
restarted-replay provider. In the executed case 
$B=64,L=8,Q=64$, the alternating query schedule requires 
3,809 source-head seek moves alone. This does not prohibit
caching or a different source schedule.

Williams's general block-respecting reduction uses 
implicitly generated computation graphs and arbitrary 
constant-arity TreeEval functions \cite{Williams2025}.
The current comb evaluator uses associativity and the 
finite-state source promise; its improved height dependence 
is \emph{not} a generic evaluator. TMR-3/053 supplies a 
different all-preloaded-checkpoint information bound 
$s+q\ge k$. The present construction concerns only 
canonical blank-start reachable checkpoints. A future 
full-chain theorem must support arbitrary revisited work 
cells, arbitrary adaptive graph/node queries and a proved 
generic evaluator query volume.
