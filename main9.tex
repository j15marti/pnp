\begin{abstract}
This run advances the WRAPPER proof spine in three exact ways.  First, it
constructs a shared residual-acquisition object for any fixed route trie and
proves exact recovery of every child without rereading the source.  Second,
it proves that a compact multi-output generator for an exact disjunctive cover
already compiles, through the ordinary CNF witness verifier, into a smaller
ordinary 3-CNF.  The initially proposed composition with one circuit copy of
an assumed SAT machine is valid but unnecessary once the generator exists.
Third, it proves a layout gate separating source-major blocking from the
child-major online acquisition actually needed at the equality frontier.

A natural source-major block schedule has minimum time-space exponent sum
exactly $2$ on the aggregate-linear frontier, whereas a hypothetical
child-major online generator would attain $5/3$ at the $(1/3,2/3)$ point.
Thus shared scanning and aggregate-linear output are not enough by
themselves.  The missing theorem remains the cheap all-input construction of
a strict ordinary successor, or a more general favorable typed mixed epoch.
Finite reapplication would then eliminate the unknown solver exponent.  No
such construction is proved here, so the present work does not prove
$P\ne NP$.
\end{abstract}

\section{The exact proof spine and the remaining arrow}

Under the contradiction hypothesis, fix one clocked uniform exact SAT
machine $A$ with certified constants $K,\sigma<\infty$ such that
\begin{equation}
 T_A(n)\le n^{K+o(1)},\qquad S_A(n)\le n^{\sigma+o(1)}.
 \label{eq:A-bounds}
\end{equation}
The intended argument does not need a compiler that works for every
extensionally equivalent implementation of SAT.  It may select and exploit
one $A$.  This relaxation is useful but not free.

\begin{theorem}[Fixed-code erasure]
Let $A$ be fixed.  If a uniform procedure uses the finite string
$\langle A\rangle$, finite preprocessing independent of its input, ordinary
computation, and explicit calls to $A$, then hardwiring the finite data gives
a uniform procedure with the same asymptotic bounds up to constants.  Any
table depending on the input length must instead be constructed at charged
cost or declared as nonuniform advice.
\end{theorem}

\begin{proof}
Substitute $\langle A\rangle$ and every finite input-independent function of
it into the transition table of the new program.  These strings have constant
length after $A$ is selected.  Input-dependent preprocessing and calls remain
unchanged.  A distinct externally supplied table for each length is not one
finite hardwired constant.
\end{proof}

Thus ``use the code of $A$'' is not itself a complexity improvement.  The
source code must lead to a uniform source-dependent shortcut whose work is
proved.  The exact logical spine has two alternative branches:
\begin{equation}
\begin{split}
 P=NP
 &\Longrightarrow \text{choose a clocked }A\text{ satisfying
 \eqref{eq:A-bounds}}\\
 &\mathrel{\mathop{\Longrightarrow}^{\Open}}
   \begin{cases}
    \text{construct a charged strict successor with }h=2/3,\\
    \text{construct a favorable charged typed epoch,}
   \end{cases}\\
 &\mathrel{\mathop{\Longrightarrow}^{\Exact}}
   \begin{cases}
    (t,s)=(1,2/3),\\
    (t,s)=(C_0^*,\rho_0^*)\text{ with }C_0^*+\rho_0^*<\gamma,
   \end{cases}\\
 &\mathrel{\mathop{\Longrightarrow}^{\Known}}
   \bot.
\end{split}
\label{eq:spine}
\end{equation}
The second arrow is the open theorem.  A generated legal-child cover does not
weaken it: Theorem~\ref{thm:generator-collapse} below converts such a cover
directly into the strict ordinary successor.  All later arrows have explicit
constructions and proofs once one of the two open constructions is supplied.

The old intuition that a $2^K$ scale must be divided by repeated $2^x$
contractions belongs to the strict-successor branch of \eqref{eq:spine}.  It
correctly
removes the unknown exponent after a strict shrinker exists.  It does not
construct the first shrinker or pay its acquisition cost.

\section{One fixed-machine circuit for an entire OR family}

For padded length $m$, standard uniform circuitization of the fixed clocked
machine gives a bounded-fan-in circuit $C_{A,m}$ of size
$m^{K+o(1)}$ computing $A$ on $m$ input bits.  The construction uses
explicit unrolling only as an upper bound \cite{pippengerfischer1979}.

\begin{theorem}[OR-MUX-COMPILE1]
Given $q$ explicit strings $x_1,\ldots,x_q\in\{0,1\}^m$, one can construct a
bounded-fan-in circuit $D$ and an ordinary 3-CNF $Q$ such that
\begin{align}
 D(z)&=C_{A,m}(x_z),\nonumber\\
 \SAT(Q)&=1\quad\Longleftrightarrow\quad
    \exists i\le q:\ A(x_i)=1,\label{eq:or-mux}\\
 |Q|&=m^{K+o(1)}+(qm)^{1+o(1)}.\label{eq:or-mux-size}
\end{align}
The construction does not execute $A$ on any $x_i$.
\end{theorem}

\begin{proof}
Pad $q$ to a power of two.  Map unused selector values to one fixed valid,
padded UNSAT CNF encoding.  A bounded-fan-in binary multiplexer selects the
$m$ input bits of one $x_i$ using $O(qm)$ gates.  Feed those outputs into one
copy of $C_{A,m}$, constrain its output gate to one, and apply the gate-by-gate
Tseitin transformation.  The selector and all internal wires become
existential CNF variables.  The result is satisfiable exactly when one
selected input is accepted.  Gate identifiers and the self-delimiting CNF
encoding add only polylogarithmic factors, so its encoded length is
$m^{K+o(1)}+(qm)^{1+o(1)}$.
\end{proof}

The theorem supplies real computation sharing.  Separate unrollings would
cost $qm^{K+o(1)}$; OR-MUX uses one copy of the solver circuit.  It does not
solve the source-volume problem for explicit children.  If $m=M^b$ and
$qm=M^{v+o(1)}$, then the returned formula has scale
\begin{equation}
 M^{\max\{bK,v\}+o(1)}.
 \label{eq:explicit-or-scale}
\end{equation}
At the aggregate-linear frontier $v=1$, the explicit listing term is still
parent-scale.  This observation motivates a compact multi-output generator.

\section{Compact generated covers give ordinary strict shrinkers}
\label{sec:generated}

\begin{definition}[Generated exact OR cover]
For a source CNF $F$ of encoded length $M$, a circuit $E_F$ has selector
input $z$ and exactly $m(M)$ output bits.  Each output string is a padded
ordinary CNF encoding, with unused selector values mapped to a fixed UNSAT
encoding.  It is an exact generated cover when
\begin{equation}
 \SAT(F)=1\quad\Longleftrightarrow\quad
 \exists z:\ \SAT(E_F(z))=1.
 \label{eq:generated-cover}
\end{equation}
The size of $E_F$ counts every gate, selector terminal, output terminal,
embedded source constant, and wiring-description bit.  The recursive
consumer receives no undeclared oracle access to $F$.
\end{definition}

This representation can describe more routes than an explicit polynomial
list.  The circuit itself must nevertheless be genuinely sublinear in the
source.  In particular, a nominally small graph with $M$ uncounted source
constants is not a small generated cover.

\begin{theorem}[GENERATOR-COLLAPSE1]\label{thm:generator-collapse}
Suppose constants $0<2b\le h<1$, $r\ge h$, and $p\le h$ and one uniform
constructor $G$ have the following properties for every ordinary CNF $F$ of
length $M$:
\begin{align}
 |E_F|&\le M^{h+o(1)}, &
 m(M)&\le M^{b+o(1)},\label{eq:gen-size}\\
 T_G(F)&\le M^{r+o(1)}, &
 S_G(F)&\le M^{p+o(1)}.\label{eq:gen-cost}
\end{align}
Assume that $E_F$ satisfies \eqref{eq:generated-cover}, that all failed
construction work is included in \eqref{eq:gen-cost}, and that $G$ makes no
parent-scale SAT call.  Then there is a uniform map $\operatorname{Shrink}$
from ordinary CNF to ordinary 3-CNF such that
\begin{align}
 \SAT(\operatorname{Shrink}(F))&=\SAT(F),\label{eq:shrink-eq}\\
 |\operatorname{Shrink}(F)|&\le M^{h+o(1)},\label{eq:shrink-size}\\
 T_{\operatorname{Shrink}}(F)&\le M^{r+o(1)},\label{eq:shrink-time}\\
 S_{\operatorname{Shrink}}(F)&\le M^{h+o(1)}.\label{eq:shrink-space}
\end{align}
The returned object is an explicit CNF, not a succinct-SAT instance.
\end{theorem}

\begin{proof}
Run $G(F)$ to produce $E_F$.  Leave its selector inputs and a proposed
assignment $y$ existentially free.  A uniform bounded-fan-in circuit of size
$O(m^2\operatorname{polylog}m)$ parses the selected padded child and verifies
that $y$ satisfies it.  A conservative construction assigns a witness bit to
each literal occurrence, checks pairwise consistency whenever two encoded
variable identifiers agree, and then evaluates every clause.  Compose that
verifier with $E_F$,
constrain its output to one, and
Tseitin-expand every gate.  By \eqref{eq:generated-cover}, the resulting
ordinary 3-CNF is satisfiable exactly when $F$ is satisfiable.  Its size is
\[
 \widetilde O\bigl(|E_F|+m^2\bigr)
 =M^{\max\{h,2b\}+o(1)}=M^{h+o(1)}.
\]
The output and verifier-generation work fit in $M^{r+o(1)}$ because
$r\ge h$.  Streaming gate generation while retaining the explicit output
uses the maximum of $M^{p+o(1)}$ and $M^{h+o(1)}$ live bits.
\end{proof}

The theorem is \Exact.  It corrects the first fixed-machine interpretation of
this route.  Composing $E_F$ with $A$ is valid, but the ordinary witness
verifier is no larger and does not use $P=NP$.  Thus the existence of $G$ is
not a weaker consequence waiting to be extracted from the code of $A$.  It
already entails the missing shrinker and may be a stronger premise.  In the
opposite representational direction, any charged ordinary shrinker gives a
one-selector generated cover whose circuit size and output width are both
$M^{h+o(1)}$; that degenerate cover need not satisfy the stronger
$2b\le h$ output-width contract.

\begin{theorem}[Finite exponent elimination]
For a fixed positive integer $d$, set
\[
 F_0=F,\qquad F_{j+1}=\operatorname{Shrink}(F_j),
 \qquad B_d(F)=A(F_d).
\]
Then
\begin{align}
 |F_j|&\le M^{h^j+o(1)},\label{eq:iter-size}\\
 T_{B_d}(M)&\le M^{\max\{r,h^dK\}+o(1)},\label{eq:iter-time}\\
 S_{B_d}(M)&\le M^{\max\{h,p,h^d\sigma\}+o(1)}.
 \label{eq:iter-space}
\end{align}
\end{theorem}

\begin{proof}
Induction gives \eqref{eq:iter-size}.  The fixed number of construction
levels costs a geometric sequence dominated by $M^{r+o(1)}$, while the final
call to $A$ costs $M^{h^dK+o(1)}$.  A depth-first implementation retains the
first explicit successor plus smaller descendants, and the final invocation
uses $M^{h^d\sigma+o(1)}$ space.  Taking maxima proves
\eqref{eq:iter-time}--\eqref{eq:iter-space}.
\end{proof}

Set
\begin{equation}
 h=\frac23,\qquad r=1,\qquad p\le\frac23,
 \qquad b=\frac{1}{3K},\quad K\ge1.
 \label{eq:landing-params}
\end{equation}
Then $2b\le2/3=h$.  Choose the fixed $d$ so that
$(2/3)^dK\le1$ and $(2/3)^d\sigma\le2/3$.  The resulting algorithm has
\[
 (t,s)=\left(1,\frac23\right),\qquad
 t+s=\frac53<\gamma.
\]
The arithmetic and finite composition are \Exact.  The endpoint conclusion
is \Conditional{} on the open generator premise.

\section{What shared BatchAcquire now accomplishes}

The new residual compiler gives a genuine positive result rather than a
mere contract.  Let $T$ be a finite assignment trie, let $\rho_v$ be the
partial assignment on the root-to-$v$ path, and let its leaves be pairwise
inconsistent.  A clause-first trie can be obtained by taking, for a selected
source clause $C=(\ell_1\vee\cdots\vee\ell_w)$, the disjoint routes
\[
 \tau_i=\{\ell_1=0,\ldots,\ell_{i-1}=0,\ell_i=1\}.
\]
Repeated source-clause selection preserves disjoint coverage of every source
model.

For each source clause, the compiler follows trie edges only until the clause
is satisfied or its current residual becomes stable throughout the remaining
subtree.  In the stable case it stores one interned fragment at the highest
such node.  A leaf child is recovered by collecting payloads along one
root-to-leaf path and canonicalizing the clause multiset.

\begin{theorem}[TRIE-BATCHACQUIRE1]
For every CNF $F$, every finite assignment trie $T$, and every leaf $u$, one
source-clause scan after $T$ is fixed constructs a shared object $H$ such that
\begin{equation}
 \operatorname{Recover}(H,u)
 =\operatorname{canon}(F\upharpoonright\rho_u).
 \label{eq:batch-recover}
\end{equation}
Recovery makes no source-literal read.
\end{theorem}

\begin{proof}
Fix a source clause $C$ and a leaf $u$.  Symbolic propagation follows the
unique path to $u$ until an edge satisfies $C$, or until the residual of $C$
is stable below the current node, or until $u$ is reached.  In the first case
$C$ contributes nothing to $F\upharpoonright\rho_u$.  In either remaining
case, exactly the residual $C\upharpoonright\rho_u$ is stored once on the
path.  Applying the argument to every source clause gives exactly the
canonical residual after interning and duplicate removal.  The source clauses
are read only by the compilation loop.
\end{proof}

The theorem resolves the narrow repeated-parent-read problem for a fixed
route family.  It does not bound the number of symbolic trie visits, the size
of $H$, total recovery, ordinary-child emission, or route discovery.  The
common-core antichain control is decisive: one shared scan replaced 64 scans,
yet materializing the 64 ordinary children emitted 478,208 bits and incurred
2,204,160 charged recovery units.  Sharing storage and sharing a source scan
did not make the standalone children cheap.

The exact interface alternatives are therefore:
\begin{description}
\item[] \textbf{Standalone ordinary children.}
Existing SAT bounds apply, but every recovered and emitted bit is charged.

\item[] \textbf{Parent-aware descriptors.}
A leaf identifier beside $H$ may be short, but $(H,u)$ is a distinct typed
problem, not an ordinary CNF of the identifier's length.  All queries to $H$
need a model-matched recursive evaluator.

\item[] \textbf{Self-contained descriptors.}
Copying the required shared state into each child restores the ordinary
interface, but can restore parent-scale information or aggregate output.
\end{description}

GENERATOR-COLLAPSE1 supplies a fourth presentation: represent the complete OR
family by one small circuit and existentially absorb its selector into one
ordinary successor formula.  The forward implication also shows why this is
not a weaker escape hatch.  Constructing that circuit on every source at the
required cost already constructs the missing ordinary successor.

\section{BATCH-LAYOUT-GATE1: why the acquisition order matters}
\label{sec:layout}

Suppose $a\ge0$, $0\le b<1$, and $0\le\delta\le a$.  There are
$q=N^{a+o(1)}$ explicit children, each of length $L=N^{b+o(1)}$.  Consider an
optimistic source-major block schedule that retains
$B=N^{\delta+o(1)}$ children at once.  It has read-only random access to the
$N$-bit source, processes blocks sequentially, scans the source once per
block, routes source information within the selected block at no additional
exponent cost, and uses no live state larger than the buffer and one active
recursive call.  Assume that the same schedule is recursively closed at every
child scale.  Its fully charged recurrence is
\begin{align}
 C&\ge\max\{1+a-\delta,\ a+b,\ a+bC\},\nonumber\\
 S&\ge\max\{b+\delta,\ bS\}.\nonumber
\end{align}
The least solution is
\begin{align}
 C(\delta)&=\max\left\{1+a-\delta,\frac{a}{1-b}\right\},
 \label{eq:layout-time}\\
 S(\delta)&=b+\delta,
 \qquad 0\le\delta\le a.
 \label{eq:layout-space}
\end{align}

\begin{theorem}[BATCH-LAYOUT-GATE1]
The minimum joint exponent of the schedule
\eqref{eq:layout-time}--\eqref{eq:layout-space} is
\begin{equation}
 J_{\min}(a,b)=
 \begin{cases}
 1+a+b,& b\le 1/(1+a),\\[2pt]
 b+a/(1-b),& b>1/(1+a).
 \end{cases}
 \label{eq:layout-min}
\end{equation}
In particular, if $a+b=1$ with $b<1$, then $J_{\min}(a,b)=2$.
\end{theorem}

\begin{proof}
Write $X=a/(1-b)$.  If $X\le1+a$, equivalently
$b\le1/(1+a)$, the two time terms cross at some
$\delta_0=1+a-X\ge0$.  On $0\le\delta\le\min\{a,\delta_0\}$,
the scan term is active and
\[
 C(\delta)+S(\delta)
 =(1+a-\delta)+(b+\delta)=1+a+b.
\]
After the crossing the objective is $X+b+\delta$ and cannot be smaller.
If $X>1+a$, the recursive term is already active at $\delta=0$, so the
minimum is $X+b$.  When $a+b=1$, the first case applies because
$b(1+a)=b(2-b)\le1$, and \eqref{eq:layout-min} equals $2$.
The omitted $a+b$ time floor is redundant: if $a+b\le1$, the source-scan
floor dominates it, and if $a+b\ge1$, then $a/(1-b)\ge a+b$.  At
$b=1/(1+a)$ both displayed branches agree; the statement assigns equality to
the first branch.
\end{proof}

At $(a,b)=(1/3,2/3)$, source-major blocking therefore gives $C+S=2$,
above $\gamma$.  By contrast, if a child-major online builder already emits
one complete child at a time in $N^{1+o(1)}$ total construction work, its
idealized ledger is
\begin{equation}
 C_{\rm online}=\max\left\{1,\frac{a}{1-b}\right\},
 \qquad S_{\rm online}=b.
\end{equation}
At the same point this is $1+2/3=5/3<\gamma$.

The conclusion is scoped.  BATCH-LAYOUT-GATE1 does not lower-bound a
child-major generator, semantic compiler, or arbitrary SAT algorithm.  It
proves that aggregate-linear output plus a naive scan-versus-block tradeoff
does not reach the endpoint.  The missing construction must transpose the
semantic information into child-major order online, avoid explicit per-child
recovery through a compact generator, or exploit a different typed route.

\section{The typed mixed-epoch alternative}
\label{sec:typed}

The generated-cover route is sufficient but not necessary.  A WRAPPER may
first execute a finite charged administrative epoch, close some branches by
directly obtained $\VALUE$ answers, and send the remainder through typed
recursive channels.  Same-scale raw steps are permissible inside the epoch
when a proved rank or potential makes the epoch finite.  After collapsing the
epoch, every feasible recurrent macro cycle must contract.

Let $I$ be a fixed finite type set.  An edge $e:i\to j$ has child scale
$0\le\theta_e\le1$ and recursive multiplier exponent $w_e$.  If its fanout
exponent is $f_e$ and each unit of recursive work pays decoder, simulation, or
replay exponent $u_e$, then $w_e=f_e+u_e$.  Let $R_i$ be the complete local
time floor, including setup, classification, all failed portfolio members,
generation, acquisition, parent reads, $\VALUE$ work, combination, and
one-time replay; in particular, one-time per-child generation exponent $g_e$
contributes $f_e+g_e$.  Let $P_i$ be the local live-space floor, including
either an explicit child buffer of exponent $\theta_e$ or the state of its
virtual decoder/generator, and let $h_e$ be the parent state retained across
the child call.  The exact Bellman ledger is
\begin{align}
 C_i&\ge R_i,& C_i&\ge w_e+\theta_eC_j,
 \label{eq:bellman-time}\\
 \rho_i&\ge P_i,& \rho_i&\ge h_e,&
 \rho_i&\ge\theta_e\rho_j.
 \label{eq:bellman-space}
\end{align}

\begin{theorem}[Typed path and cycle criterion]
Within the declared recurrence, the least finite time budget is
\begin{equation}
 C_i^*=\sup_P\left(W_P+\Theta_P R_{\operatorname{end}(P)}\right),
 \label{eq:path-budget}
\end{equation}
where for a path $P=e_0\cdots e_{m-1}$,
\[
 \Theta_P=\prod_{k<m}\theta_{e_k},\qquad
 W_P=\sum_{k<m}\left(\prod_{\ell<k}\theta_{e_\ell}\right)w_{e_k}.
\]
The least streamed-space budget is the analogous supremum of transported
local and retained-state floors.  A finite typed system suppresses every
finite inherited exponent when every feasible reachable directed cycle has
scale product strictly below one.  A reachable unit-product cycle does not
generically suppress an arbitrarily large inherited exponent.
\end{theorem}

\begin{proof}
Repeated substitution of \eqref{eq:bellman-time} gives the lower bound for
every finite path.  Conversely, prefixing an edge to the supremum in
\eqref{eq:path-budget} shows that it dominates
$w_e+\theta_eC_j^*$ and every local floor, so it is the least pre-fixed
point.  The same substitution proves the space formula.  In a finite graph,
every long path decomposes into a bounded simple prefix and cycles.  Strict
cycle contraction makes the inherited boundary term tend to zero.  A
unit-product cycle consists entirely of unit-scale edges and preserves that
term, with positive discounted weight causing further growth.
\end{proof}

For a two-wrapper cycle $A\to B\to A$, let the scales be $\alpha,\beta$, the
weights be $x,y$, and define
$H_A=\max\{P_A,h_{AB}\}$ and $H_B=\max\{P_B,h_{BA}\}$.
If $\alpha\beta<1$, exact substitution gives
\begin{align}
 C_A^*&=\max\left\{R_A,x+\alpha R_B,
             \frac{x+\alpha y}{1-\alpha\beta}\right\},\label{eq:double-time}\\
 \rho_A^*&=\max\{H_A,\alpha H_B\}.
 \label{eq:double-space}
\end{align}
A same-scale outer phase is therefore legal when $\alpha=1$ and
$\beta<1$.  The rational point
\[
 \alpha=1,\quad\beta=\frac12,\quad x=\frac15,\quad y=\frac25,
 \quad R_A=R_B=1,\quad H_A=H_B=\frac12
\]
has $(C_A^*,\rho_A^*)=(6/5,1/2)$ and sum $17/10<\gamma$.  This is an exact
arithmetic target and a \Conditional{} SAT route.  No all-input WRAPPER is
known to realize its charges.

\begin{theorem}[Mass-potential epoch bound]
Suppose a finite administrative plan tree on an $N$-bit source has a positive
source-checkable mass $\mu$.  Assume
\begin{align*}
 \mu(\mathrm{root})&\le N^{\kappa+o(1)},&
 \sum_{u\text{ child of }v}\mu(u)&\le\mu(v),\\
 \mu(v)&\ge N^{-\xi+o(1)}\quad\text{for internal }v,&
 D(N)&\le N^{\delta+o(1)}.
\end{align*}
If one internal node costs $N^{u+o(1)}$, all internal work has exponent at
most $\kappa+\xi+\delta+u$.  If recursive exits of class $e$ have mass at
least $N^{-\xi_e+o(1)}$, their fanout exponent is at most
$f_e=\kappa+\xi_e$.
\end{theorem}

\begin{proof}
At one depth, mass conservation and the minimum internal-node mass bound the
node count by $N^{\kappa+\xi+o(1)}$.  Multiply by the depth and per-node work.
All terminal nodes form an antichain with total mass at most the root mass,
so class $e$ has at most $N^{\kappa+\xi_e+o(1)}$ exits.
\end{proof}

If each exit has one-time generation exponent $g_e$, then $R_i$ contains
$f_e+g_e$.  If each unit of recursive work pays decoder or replay exponent
$u_e$, then $w_e=f_e+u_e$.  A depth-first administrative stack with frame
exponent $h$ has exponent $h+\delta$.  These charges prevent a same-scale raw
tree from being relabeled as free amortization.

The conditional values
\[
 \kappa=\frac16,\quad \xi=\xi_e=\frac1{12},\quad
 \delta=0,\quad u=\frac34,\quad u_e=0,\quad\theta_e=\frac34
\]
give $R=1$, $w=1/4$, $C^*=1$, and explicit-child space $P=3/4$.
The sum $7/4<\gamma$.  The missing step is an all-CNF, cheaply verified mass
certificate with these or better parameters.

For a fixed set $I_0$ of possible root types, the same-realization endpoint is
\begin{equation}
 \boxed{\max_{i\in I_0} C_i^*+\max_{i\in I_0}\rho_i^*<\gamma.}
 \label{eq:same-realization}
\end{equation}
It is not enough that $C_i^*+\rho_i^*<\gamma$ separately for every type,
because the worst time and worst space may occur on different inputs of the
same uniform algorithm.

\section{Literature reconciliation}

The primary literature now gives several closer controls but no construction
of the open arrow in \eqref{eq:spine}.

\begin{description}
\item[] \textbf{Equality frontier.}
Dell and van Melkebeek rule out certain multi-query reductions for dense
$d$-SAT when the query-number exponent plus query-length exponent is strictly
below $d$ \cite{dellvanmelkebeek2014}.  For dense 3-CNF, the
$(1/3,2/3)$ target in encoded length becomes $(1,2)$ in variable scale and
sits at equality.  Their result neither excludes nor constructs the balanced
equality point.

\item[] \textbf{CSP nonredundancy.}
Recent nonredundancy characterizations imply that preserving all clause
violation counts by deleting or reweighting source constraints cannot shrink
ordinary dense clause predicates below their dense scale
\cite{brakensiekguruswami2026}.  Exact one-pass CSP preprocessing likewise
has full dense-scale space on ordinary clause languages in the declared
streaming model \cite{sharmavelusamy2026}.  These are scoped barriers.  They
do not exclude derived clauses, source rereads, a multi-query restriction
cover, or the generated circuit of Section~\ref{sec:generated}.

\item[] \textbf{CSP core reduction.}
When a constraint language has redundant domain elements, exact streamable
core reduction is a genuine positive preprocessing rule
\cite{brakensiekputterman2026}.  Ordinary Boolean clause languages do not
obtain the required contraction from that mechanism.  It remains a valid
structured portfolio branch.

\item[] \textbf{Truth-table and search-to-decision structure.}
Bounded rounds of SAT access can be normalized to a nonadaptive truth-table
family, but the normalization does not reduce query count or encoded length
\cite{busshay1991}.  Current circuit-lower-bound work separately identifies
deterministic nonadaptive search-to-decision as an open bottleneck
\cite{renwilliams2026}.  Solving that problem could help route acquisition
without by itself proving size shrinkage.

\item[] \textbf{Backdoors and compilation.}
Backdoor DNFs give exactly the right disjunctive semantics on promised
families, and width-based knowledge compilation can make merging cheap after
favorable structure is supplied \cite{ordyniak2021bdnf,darwiche2002}.  No
cited theorem finds an endpoint-compatible cover or compact generator on
every CNF at near-linear charged cost.

\item[] \textbf{Self-improvement.}
Williams's circuit-analysis self-improvement theorem is a precedent for
finite bootstrapping from a weak algorithmic hypothesis
\cite{williams2024}.  It does not construct the ordinary-CNF or generated
cover needed in the polynomial SAT regime.
\end{description}

The literature therefore supports the distinction exposed by
BATCH-LAYOUT-GATE1: output volume, access order, semantic generation, and
ordinary-instance return are separate obligations.

\section{The exact next theorem}

GENERATOR-COLLAPSE1 removes a false distinction: a compact exact generator of
legal children satisfying $2b\le h$ entails an ordinary strict successor and
may impose a stronger contract.  The
strongest single target is therefore stated directly.

\begin{center}
\fbox{\begin{minipage}{0.92\textwidth}
\textbf{CHARGED STRICT SUCCESSOR-$2/3$ (OPEN).}
Assume $P=NP$.  Select a clocked uniform exact SAT decider $A$ with certified
time and space exponents $K,\sigma$.  Construct one fixed uniform algorithm
$R_A$ which, on every $M$-bit ordinary CNF $F$, uses $M^{1+o(1)}$ time and
$M^{2/3+o(1)}$ space and emits one ordinary CNF $Q_{A,F}$ satisfying
\[
 |Q_{A,F}|\le M^{2/3+o(1)},\qquad
 \SAT(Q_{A,F})=\SAT(F).
\]
Count all discovery, failed routes, generation, source reads, embedded source
bits, wiring, decoding, replay, and verification.  The constructor may not
execute $A$ on an $M^{1-o(1)}$ input, retain an undeclared parent oracle, or
receive per-length advice.  The same guarantee must hold for every ordinary
successor produced by $R_A$.  An exact generated cover may implement $R_A$,
but by GENERATOR-COLLAPSE1 its stronger $2b\le h$ contract already entails
this semantic contraction.
\end{minipage}}
\end{center}

This target moves the unknown work into one visibly load-bearing statement.
It is not yet proved by the wrapper DAG, recursive paths, prime labels,
hashes, clause tries, backdoors, or shared residual pool.  Those mechanisms
remain useful candidate components and falsification tools.

The typed alternative is equally precise:
\begin{center}
\fbox{\begin{minipage}{0.92\textwidth}
\textbf{MIXED-EPOCH FINAL LINK (OPEN).}
From the same selected $A$, construct on every ordinary CNF a finite exact
epoch whose terminal channels are charged $\VALUE$ leaves or typed recursive
exits.  Charge classification, failed members, acquisition, source access,
decoder traffic, replay, combination, retained state, and stack space.
Require every feasible macro return cycle to contract and require the least
same-realization root budgets from \eqref{eq:bellman-time}--
\eqref{eq:bellman-space} to satisfy $C_0^*+\rho_0^*<\gamma$.
\end{minipage}}
\end{center}

Either target would complete the final link.  The direct successor statement
is the cleanest single-type goal.  The mixed-epoch theorem is more general
and may succeed even when no one global shrinker exists.  OR-MUX-COMPILE1 is
useful inside a candidate construction, but explicit aggregate-linear volume
keeps it parent-scale and a compact legal-child generator collapses back to
the direct target.

\section{Present proof status}

The proof has advanced from an unspecified demand for favorable merging to a
source-checkable conditional compiler and two exact architecture gates.  A
compact exact generated cover no longer leaves a succinct-input gap: the
ordinary CNF witness verifier and Tseitin expansion return it to ordinary
CNF, and finite iteration removes $K$ and $\sigma$.  The correction is also
limiting: the generated cover already contains the missing contraction, so
it is not obtained merely by fixing the assumed solver $A$.
The batch experiment separately proves that exact shared source acquisition
and no-reread recovery are possible for fixed route families.  The layout
gate explains why that sharing has not yet met the endpoint: source-major
recovery trades time for space to a joint value of two on the equality
frontier.

What remains is a new all-input semantic theorem, either CHARGED STRICT
SUCCESSOR-$2/3$ or the more general MIXED-EPOCH FINAL LINK.
No current construction or cited theorem proves either statement.  Until one
of them is proved with the same-realization resource ledger, the proof spine
is conditional and $P$ versus $NP$ remains \Open.
