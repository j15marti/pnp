\section{Source model, quantifiers, and parsing}
For every $q\ge1$, $G\ge0$, and explicit topologically ordered shared fan-in-two Boolean truth-table DAG $D$, there are $q$ named original input bits, $G$ distinct named gates, arbitrary predecessor reuse and fan-out, and one named output bit. Each 4-bit gate table is an arbitrary binary function, including constants, XOR, and repeated operands. Gates are authenticated in source order and are \emph{not} unfolded when they share predecessors.

Put $V=q+G$ and $w_C=\lfloor\log_2\max(2,V)\rfloor+1$. The source binary word is $1^q0\,1^G0$, followed by two low-bit-first $w_C$-bit predecessor indices plus four low-bit-first gate-function bits for each gate, then one low-bit-first $w_C$-bit output index. Exact source length:
\[
B_C=q+G+2+G(2w_C+4)+w_C.
\]
A fixed parser rejects nonbinary data, invalid delimiters or lengths, forward/out-of-range gate references and invalid output indices; every invalid word has a deterministic defined failure response. The target output on a valid source is the exact nonnegative integer
\[
\#D=\left|\{x\in\{0,1\}^q:D(x)=1\}\right|.
\]
The full source read, graph construction, all names and output are charged. There is no free access oracle or hidden initial gate DAG.

\section{Count-preserving shared-gate compiler}
\begin{lemma}[Functional shared-DAG Tseitin compiler, TMR-1/054]
There is a uniform polynomial-bit-time construction of a width-at-most-three CNF $H_D$ on precisely $V=q+G$ declared variables and $m\le4V$ clauses. It satisfies outer-list \texttt{NoDup}, every variable occurs, and $\#H_D=\#D$; for each original input the number of satisfying gate-variable extensions equals $D(x)\in\{0,1\}$.
\end{lemma}
\begin{proof}
For every gate $z=f(a,b)$ emit, for all $u,v\in\{0,1\}$, the clause
\[
 (a\ne u)\lor(b\ne v)\lor(z=f(u,v)).
\]
For given predecessor bits exactly the matching pair forces $z$, and the other three clauses are satisfied. Induction on topological gate order gives exactly one auxiliary gate assignment, even with constants, dead gates, repeated operands and fan-out. Pin the designated circuit output with a positive unit clause. If an original input was never mentioned by the gate constraints or output unit, add its tautology $(x\lor\neg x\lor x)$, preserving the \emph{original input count}. Delete only duplicate \emph{ordered outer clause lists}. If $u\le q$ inputs were missing, $m\le4G+1+u\le4(q+G)$, as $q\ge1$. Thus the number of CNF satisfying assignments equals the number of accepted original inputs.
\end{proof}


\section{Local-essential source quotient and exact original count lifting (C1a-LOCAL-ESSENTIAL)}
\begin{lemma}[Uniform locally-essential shared-DAG quotient, TMR-1/063]
For every well-formed C1a $q$-input, $G$-gate explicit binary
truth-table DAG $D$, there is a uniform source-authenticated
polynomial-time construction of a restricted circuit $D^*$ on
$r$ original input ports and $L$ original named gate identities,
where $r\le q$, $L\le G$, and
\[
\boxed{\#D=2^{q-r}\#D^*.}
\]
With $R=r+L\ge1$, the canonical core CNF has $R$ declared variables,
at most $4L+1$ ordered clauses before duplicate deletion,
no absent declared variables and precisely $\#D^*$ satisfying
assignments. Applying C1c requires exactly
$d_*=\max(1,4-R)$ auxiliary pins, yielding
$n'=R+d_*$ and $2\le m'\le4n'$ in the pinned
\texttt{IsKCNF 3}/\texttt{AllOccur}/\texttt{NoDup} domain.
\end{lemma}
\begin{proof}
Read and authenticate all $B_C$ original source bits, including
gate records subsequently discarded. For each original
$z=f(a,b)$ with $a=b$, restrict the truth table to
$h(t)=f(t,t)$; the gate is now constant or unary.
For distinct $a,b$, mark the first argument essential
exactly if $f(0,v)\ne f(1,v)$ for some $v$, and the second
exactly if $f(u,0)\ne f(u,1)$ for some $u$.
The resulting constant/unary/binary local gate is pointwise
identical to the source gate, with exactly its locally
influential predecessor edges. Walk these edges backwards
from the source output, deduplicate all reached gate identities,
and remap only the reached original inputs and gate names.
Topological induction proves $D(x)=D^*(x|_I)$ for every
original $q$-bit input $x$. The projection onto the $r$
reached inputs has precisely $2^{q-r}$ preimages,
proving the exact count identity, even for $r=0$.

Give a retained constant gate one unit defining clause,
a unary gate its two truth-table defining clauses, and
a binary gate its four three-literal defining clauses.
Append the positive output unit. Each retained gate has
a unique assignment given the retained inputs; every
retained original input occurs in a defining clause or
is the designated output, and every gate output occurs
in its defining clauses. Deleting exact ordered duplicate
clauses preserves the count. Thus $m_0\le4L+1\le4R+1$,
$u=0$ and
\[
\left\lceil(m_0+u+1-4R)/3\right\rceil\le1,
\]
so the preceding C1c density-normalizer formula gives
$d_*=\max(1,4-R)$. Its uniquely extending pins retain
the exact core count. Finally shift the fully decoded
$(n'+1)$-bit formal count by $q-r$ places to emit the
original count in $q+1$ output bits.
\end{proof}

\section{An exact four-density promise totalizer}
\begin{lemma}[C1c-DENSITY-OPTIMAL: all declared width-three inputs]
For every width-at-most-three CNF $H$ on $n\ge0$ declared original
variables and any finite ordered list of $m$ clauses, including unused
variables, duplicate and empty clauses and repeated literals,
let $m_0$ be its number of \emph{distinct ordered} old clauses and
$u$ its number of unused original variables. Set
\[
d_*=\max\left\{1,\ 4-n,\
\left\lceil\frac{m_0+u+1-4n}{3}\right\rceil\right\}.
\]
There is a uniform polynomial-bit-time map $H\mapsto\widehat H$
with exactly one satisfying auxiliary extension of each satisfying
old assignment, and
\[
n'=n+d_*\ge4,\qquad
2\le m'=m_0+u+d_*+1\le4n',\qquad
\#\widehat H=\#H.
\]
Every output variable occurs, every clause has width at most three
and the outer clause list satisfies \texttt{NoDup}.
Within \emph{this specified additive normalizer} and with $d\ge1$,
$d_*$ is the smallest number of forced-zero variables meeting
both $n'\ge4$ and the four-density condition. No claim is made
that this is optimal among arbitrary count-preserving compilers.
\end{lemma}
\begin{proof}
Keep the $m_0$ unique ordered old clauses. For each unused original
variable $x_i$ append the tautology $(x_i\lor\neg x_i)$.
Introduce the $d_*$ fresh variables $t_1,\ldots,t_{d_*}$,
append the $d_*$ unit clauses $(\neg t_j)$ and finally
$(t_1\lor\neg t_1)$. Old duplicates and inserted tautologies
do not affect satisfaction; all old variables, including originally
free ones, remain declared. The fresh pins force exactly the
auxiliary assignment $t_j=0$ for all $j$. All added clauses
are pairwise distinct and distinct from old clauses because
they involve missing old indices or fresh indices. Therefore
$m'=m_0+u+d_*+1$ exactly, \texttt{AllOccur} holds and
the output satisfies the minimum size and width promises,
including for the empty source CNF and an empty source clause.
For this template, the density condition is equivalent to
\[
m_0+u+d+1\le4(n+d)
\quad\Longleftrightarrow\quad
3d\ge m_0+u+1-4n.
\]
Together with $d\ge1$ and $n+d\ge4$ this proves both
four-density and minimality of the chosen integer $d_*$.
Since $m_0\le m$ and $u\le n$, the materialized output has
$O(n+m+1)$ clauses and variables. Given an explicit unary-$n$
source of $B$ bits, source authentication, deduplication, used-name
bookkeeping, all integer arithmetic, clause writing and exact
low-first formal encoding admit $O((B+1)^4)$ bit time and
$O((B+1)^2)$ peak writable space \emph{on one physical run}.
Its complete formal input has $O(B\log(B+2))$ bits.
\end{proof}

\section{Physical semantics of the fixed formal finite-stack machine}
\begin{lemma}[C1e-STACK-PHYSICAL: uniformly charged fixed-machine simulation]
Fix any $M:\mathrm{TM2ComputableAux}(\mathrm{Bool},\mathrm{Bool})$
with $\forall i,\ \mathrm{Finite}(M.\mathrm{tm}.\Gamma_i)$.
There is one ordinary deterministic finite-alphabet, locally headed
multitape machine $U_M$ and constants $a_M,b_M$ such that for every
input word $x$ of length $B$ and every $t$ for which the pinned
$\mathrm{TM2OutputsInTime}(M.\mathrm{tm},x,\mathrm{some}(y),t)$
holds, the \emph{same complete physical run} of $U_M$ on the
read-only source word $x$ outputs exactly $y$ with
\[
 T_{U_M}(x)\le a_M(B+t+1),\qquad
 S_{\mathrm{peak},U_M}(x)\le b_M(B+t+1).
\]
These bounds include initialization, input copying/reversal, all
stack accesses, finite-control lookups, output copying/reversal and
completion. This is a fixed-machine simulation theorem and does
not independently verify the source theorem's Lean proof.
\end{lemma}
\begin{proof}
The pinned Mathlib \texttt{FinTM2} structure supplies a finite number
$K$ of stacks, finite label type $\Lambda$, finite internal state
type $\sigma$, a fixed main label and a fixed statement tree
$m(\lambda)$ for each label. The pinned \texttt{MainTheorem} adds
finite alphabets on \emph{every} stack, not only its input stack.
Every finite-state function inside a statement is thus a fixed
finite lookup table. Let $L$ be the maximum number of syntactic nodes
on a root-to-leaf path across the finitely many $m(\lambda)$.
Both $K$ and $L$ are constants of $M$, independent of $B,t,x$.

Allocate one writable tape per stack with its head immediately after
the present top symbol and a bottom marker. A \texttt{push} writes
one finite-alphabet symbol and moves its head right; a \texttt{pop}
moves left and erases the top (or reads the bottom marker if empty);
a \texttt{peek} visits the last symbol and returns to the head.
Each operation needs bounded local tape steps. The other
\texttt{load}, \texttt{branch}, \texttt{goto}, \texttt{halt}
operations change only the fixed finite control. Initialize the
input stack from the actual read-only word using a linear temporary
copy and reverse sweep; the other stacks start genuinely empty.
This costs $O_M(B+1)$ physical steps and $O(B)$ writable cells.

In Mathlib's \texttt{TM2.step}, \texttt{stepAux} evaluates only
one path down the fixed finite statement tree until the first
\texttt{goto} or \texttt{halt}. Hence each formal step costs
$O_M(L)$ physical actions, and at most $Lt$ new stack symbols
can be pushed over $t$ steps. The total live stack contents are
bounded by $B+Lt$. The pinned \texttt{haltList} requires exactly
the designated output list, empty nondesignated stacks, and restored
internal state. Copying the output stack into the ordinary output
tape, including order reversal if required, costs
$O_M(B+Lt+1)$. Counting temporary buffers and all initialized
cells yields both bounds on the identical execution.
\end{proof}

\begin{lemma}[J56: charged uniform recovery of a fixed-size junta]
For each fixed integer $w\ge1$, an explicit evaluator for every Boolean
$f:\{0,1\}^{\ell}\to\{0,1\}$ depending on at most $w$ coordinates permits a
deterministic exact $O(w2^w)$-gate fan-in-two circuit reconstruction using at most
\[
 2\ell\sum_{j=0}^{w-1}\binom{\ell-1}{j}+2^w
\]
evaluator calls and polynomial additional bit work.
\end{lemma}
\begin{proof}
For each position $i$, query $f(1_S)$ and $f(1_{S\cup\{i\}})$ for all
$S\subseteq[\ell]\setminus\{i\}$ of size at most $w-1$. A relevant position
has a witness in which only its at most $w-1$ other relevant coordinates
might be nonzero, so some tested pair changes. Every irrelevant position
leaves all tests unchanged. Reconstruct the truth table over precisely the
discovered support by at most $2^w$ extra paid evaluations, then build its
Boolean Shannon expansion. Each call actually computes $f$; there is no
free support-location oracle.
\end{proof}



\begin{lemma}[C1f-JMV-VECTOR-SUPPORT: one batched low-weight suite]
Let $\ell,b\ge1$, $0\le w\le\ell$ and
$F:\{0,1\}^{\ell}\to\{0,1\}^{b}$ be an explicitly evaluable
total Boolean vector function. Assume that \emph{each} output
component depends on at most $w$ input coordinates, with no
supports supplied as free advice. Exactly
\[
Q(\ell,w)=\sum_{j=0}^{w}\binom{\ell}{j}
\]
nonadaptive \emph{whole-vector} evaluations suffice to recover
every support and every restricted truth table, and to compile
a pointwise identical shared fan-in-two circuit with at most
\[
3b(2^w-1)+\ell
\]
noninput NOT/AND/OR gates. No additional oracle evaluations
are needed after support discovery.
\end{lemma}
\begin{proof}
Query the full vector once for every Boolean address of Hamming
weight at most $w$, retaining all $bQ$ answer bits. For each
component $F_j$ and coordinate $i$, compare the stored values at
$1_S$ and $1_{S\cup\{i\}}$ over all $S$ not containing $i$ with
$|S|\le w-1$. If $i$ influences $F_j$, some setting of its at
most $w-1$ other relevant coordinates witnesses a change;
setting all irrelevant coordinates to zero supplies exactly
one of these charged query pairs. Irrelevant coordinates never
produce a change. Thus the discovered support $R_j$ is exact.
Every assignment to $R_j$ has at most $w$ ones and its value
at zero elsewhere was already queried; it fills the entire
$2^{|R_j|}$-entry component truth table without a new query.
A binary Shannon tree needs at most $3(2^{|R_j|}-1)$ AND/OR
gates, and at most $\ell$ negations are shared across all
components. Sum these bounds.
\end{proof}

\section{C1h: an exact-counting relativization obstruction to NP promotion}
\begin{theorem}[C1h-NP-RELATIVIZATION-BRIDGE: restricted oracle countermodel]
There exists one fixed oracle $A=\mathrm{TQBF}$, one uniform
deterministic oracle multitape transducer $U^A$ and a constant
integer $d\ge1$ such that \emph{every} authentic encoded C1a
shared fan-in-two Boolean circuit $D$ is parsed, compiled to the
exact C1b--C1d promised counting formula, and counted correctly
by $U^A$ in polynomial oracle time and polynomial simultaneous
writable space. Malformed source words are rejected. Nevertheless,
\[
\mathrm{P}^{A}=\mathrm{NP}^{A}=\mathrm{PSPACE}.
\]
For original source length $B_C$, formal input length $B_A$,
original input-port count $q$, and normalized variable count $n'$,
write $P=1+B_C+B_A+q$. On the \emph{same complete oracle execution},
\[
Q_A\le n'+1,\quad
T_{\mathrm{oracle}}=O(P^4+(n'+1)P^d),\quad
S_{\mathrm{peak}}=O(P+P^d).
\]
Oracle membership calls are charged at unit cost \emph{only in the
declared relativized model}; this is not a physical no-oracle
counting-speed theorem. It falsifies any NP-level separation
inferred from fast exact counting by \emph{relativizing reasoning
alone}, without refuting the conditional $E^{NP}$ circuit result.
\end{theorem}
\begin{proof}
For a complete C1d unary-$n'$ encoded CNF $\phi$ (hence $n'\le P$) and
integer $h\in[0,2^{n'}]$, the predicate $\#\phi\ge h$ lies in
$\mathrm{PSPACE}$: enumerate the assignments, test all clauses
and maintain an $(n'+1)$-bit counter, taking polynomial writable
space but possibly exponential time. Since TQBF is PSPACE-complete,
one fixed uniform polynomial-time many-one reduction $R$ emits
a whole TQBF question $R(\phi,h)$ of at most $O(P^d)$ bits and
uses at most $O(P^d)$ locally headed tape steps and writable bits
for a fixed sufficiently large $d$.

On the actual binary input, authenticate every header, edge,
gate table and output index. Materialize C1b and C1c, and serialize
the exact C1d low-first word. Keep a single reusable oracle-query
buffer. Binary search over the $2^{n'}+1$ possible exact counts
with at most $n'+1$ questions $R(\phi,h)$, including wrong
candidate thresholds and all query-tape writes, and emit the
$q+1$ original-count bits. Compiler, output and full malformed
rejection contribute $O(P^4)$ oracle-independent bit work.
The complete query construction, copies, head movement,
addresses, arithmetic and answer processing contribute
$O((n'+1)P^d)$ time and $O(P^d+P)$ simultaneous peak
writable storage. Shared physical objects are counted once;
no input-specific advice or parallel span is used.

Because $A=\mathrm{TQBF}$ is PSPACE-complete and is in PSPACE,
$\mathrm{PSPACE}\subseteq\mathrm{P}^A\subseteq\mathrm{PSPACE}$.
Also $\mathrm{NP}^A\subseteq\mathrm{NPSPACE}
=\mathrm{PSPACE}$ by Savitch's theorem. Hence
$\mathrm{P}^A=\mathrm{NP}^A=\mathrm{PSPACE}$.
The oracle's uncharged \emph{internal} answer complexity
prevents any substitution of $T_{\mathrm{oracle}}$ for
the physical finite-stack $T_M$ of C1e.
\end{proof}

\section{C1h-FULL-ORACLE: authentic relativization and the missing CNF compiler}
The preceding C1h theorem used an \emph{ordinary Boolean} CNF and a
TQBF oracle for count thresholds. A full relativization additionally
allows oracle-query gates \emph{inside} the input circuit. The following
strengthens the countermodel on that genuine source domain. It is a
new scoped mathematical audit of the dependency, not a no-oracle
algorithm or a proof of an NP separation.

\begin{theorem}[C1h-FULL-ORACLE: fully relativized countermodel, PROVED restricted]
There exist one fixed oracle $A=\mathrm{TQBF}$, one uniform deterministic
oracle transducer $U^A$ and an integer $d\ge1$ such that for every
complete authentic $N$-bit encoding $z$ of a $q$-input, acyclic,
shared Boolean-and-$A$-oracle gate circuit $C_z^A$, the transducer
outputs its exact original-input acceptance count in $q+1$ bits.
Malformed sources are rejected. Its \emph{same complete oracle execution}
has
\[
 Q_A\le q+1,\qquad
 T_{\mathrm{total}}=O((q+1)(N+q+1)^d),\qquad
 S_{\mathrm{peak}}=O((N+q+1)^d),
\]
yet $\mathrm{P}^A=\mathrm{NP}^A=\mathrm{PSPACE}$.
\end{theorem}
\begin{proof}
Authenticate a unary-$q$, unary-gate-count source. Its topologically
ordered records are either ordinary fixed four-bit binary truth-table
gates or $A$-gates specifying a unary query-word length and a list of
earlier source wires giving \emph{each actual query bit}; the final
record specifies an output wire. All source bits, record lengths,
indices, repeated and shared wires and trailing data are checked,
and each query word has at most $N$ bits. The oracle gate semantics
are $A$-membership on the fully constructed predecessor word.

For fixed $A=\mathrm{TQBF}$, a source evaluation on one original
input assignment uses deterministic polynomial \emph{space}:
each TQBF query has polynomial input length and TQBF is in
$\mathrm{PSPACE}$. Enumerate all $2^q$ original assignments and
retain a $(q+1)$-bit exact count. Thus the threshold predicate
$\#C_z^A\ge h$ belongs to ordinary $\mathrm{PSPACE}$ on explicit
input $(z,h)$ of length $O(N+q)$. The standard uniform polynomial
many-one reduction from this \emph{fixed} threshold language
to TQBF writes one query of $(N+q+1)^{O(1)}$ bits within matching
locally headed bit time and workspace. Binary search over
$0,\ldots,2^q$ makes at most $q+1$ paid adaptive queries.
Input authentication, complete question serialization, failed
thresholds, addresses, heads, shared buffers, arithmetic and
final exact output are charged on the same machine.
The oracle's internal computation is unit-cost \emph{only}
in this explicitly relativized model.

TQBF completeness gives $\mathrm{PSPACE}\subseteq\mathrm P^A$,
and simulation of polynomial-length oracle queries in polynomial
space, followed by Savitch, gives
$\mathrm{NP}^A\subseteq\mathrm{NPSPACE}=\mathrm{PSPACE}$.
Thus $\mathrm P^A=\mathrm{NP}^A=\mathrm{PSPACE}$ even while
the authentic $A$-circuit count belongs to $\mathrm{FP}^A$.
\end{proof}

authentic TQBF-oracle circuit of the preceding model to an ordinary
polynomial-length Boolean 3CNF, preserving whether \emph{some original
input} makes its output true, then
$\mathrm{PSPACE}=\mathrm{NP}$.
\end{lemma}
\begin{proof}
Given a closed quantified Boolean formula $\psi$, construct
an oracle circuit with one dummy input, polynomially many constant
gates spelling the actual bits of $\psi$, and one oracle gate
querying $\psi$ and serving as output. Its original-input count
is two when $\psi\in\mathrm{TQBF}$ and zero otherwise.
The proposed compiler gives a uniform polynomial many-one
reduction from TQBF to ordinary 3SAT. PSPACE completeness implies
$\mathrm{PSPACE}\subseteq\mathrm{NP}$; the reverse inclusion is
standard.
\end{proof}
