\section{Source model, quantifiers, and parsing}
For every $q\ge1$, $G\ge0$, and explicit topologically ordered shared fan-in-two Boolean truth-table DAG $D$, there are $q$ named original input bits, $G$ distinct named gates, arbitrary predecessor reuse and fan-out, and one named output bit. Each 4-bit gate table is an arbitrary binary function, including constants, XOR, and repeated operands. Gates are authenticated in source order and are \emph{not} unfolded when they share predecessors.

Put $V=q+G$ and $w_C=\lfloor\log_2\max(2,V)\rfloor+1$. The source binary word is $1^q0\,1^G0$, followed by two low-bit-first $w_C$-bit predecessor indices plus four low-bit-first gate-function bits for each gate, then one low-bit-first $w_C$-bit output index. Exact source length:
\[
B_C=q+G+2+G(2w_C+4)+w_C.
\]
A fixed parser rejects nonbinary data, invalid delimiters or lengths, forward/out-of-range gate references and invalid output indices; every invalid word has a deterministic defined failure response. The target output on a valid source is the exact nonnegative integer
\[
\#D=\left|\{x\in\{0,1\}^q:D(x)=1\}\right|.
\]
The full source read, graph construction, all names and output are charged. There is no free access oracle or hidden initial gate DAG.

\section{Count-preserving shared-gate compiler}
\begin{lemma}[Functional shared-DAG Tseitin compiler, TMR-1/054]
There is a uniform polynomial-bit-time construction of a width-at-most-three CNF $H_D$ on precisely $V=q+G$ declared variables and $m\le4V$ clauses. It satisfies outer-list \texttt{NoDup}, every variable occurs, and $\#H_D=\#D$; for each original input the number of satisfying gate-variable extensions equals $D(x)\in\{0,1\}$.
\end{lemma}
\begin{proof}
For every gate $z=f(a,b)$ emit, for all $u,v\in\{0,1\}$, the clause
\[
 (a\ne u)\lor(b\ne v)\lor(z=f(u,v)).
\]
For given predecessor bits exactly the matching pair forces $z$, and the other three clauses are satisfied. Induction on topological gate order gives exactly one auxiliary gate assignment, even with constants, dead gates, repeated operands and fan-out. Pin the designated circuit output with a positive unit clause. If an original input was never mentioned by the gate constraints or output unit, add its tautology $(x\lor\neg x\lor x)$, preserving the \emph{original input count}. Delete only duplicate \emph{ordered outer clause lists}. If $u\le q$ inputs were missing, $m\le4G+1+u\le4(q+G)$, as $q\ge1$. Thus the number of CNF satisfying assignments equals the number of accepted original inputs.
\end{proof}

\section{New all-input promise totalizer}
\begin{lemma}[C1-Promise: entire declared-CNF domain]
For every width-at-most-three CNF $H$ on $n\ge0$ \emph{declared} original variables and $m\ge0$ clause lists, including repeated or empty clauses, there is one polynomial-bit-time map $H\mapsto\widehat H$ with
\[
d=\max(1,4-n),\quad n'=n+d\ge4,\quad
2\le m'\le m+n+d+1,\quad \#\widehat H=\#H.
\]
Every declared variable of $\widehat H$ occurs, its outer clause list has no duplicates, and every satisfying old assignment has precisely one satisfying extension. If $m\le4n$, then also $m'\le4n'$.
\end{lemma}
\begin{proof}
Delete exact duplicate ordered clause lists. For every original variable absent from all old clauses, insert the tautology $(x_i\lor\neg x_i)$. Introduce $d$ fresh variables $t_1,\ldots,t_d$, each forced zero by its unit clause $(\neg t_j)$, and insert one additional tautology $(t_1\lor\neg t_1)$. These new lists are pairwise distinct and contain fresh symbols absent from old lists. Every original assignment has a unique extension $t_j=0$; its truth value is unchanged even if $H$ had no clauses or contained the empty clause. Every variable now occurs, with at least $d+1\ge2$ distinct clauses. At most $n+d+1$ lists are added, proving the stated upper bound. Finally, if $m\le4n$, then
\[
m'\le4n+d+1\le4n+4d=4n'
\]
because $d\ge1$. The old variables remain declared and free if they were free; removing them instead would silently divide the exact count by two.
\end{proof}

Applying both lemmas, \emph{every} valid circuit, including $q+G=1,2,3$, yields a CNF with $n'=V+d\ge4$, $2\le m'\le4n'$, \texttt{AllOccur} and \texttt{IsKCNF 3}. The latter permits clauses shorter than three, opposite signs and repeated literals \emph{within} a clause, but requires \emph{outer} \texttt{Nodup}. This is not an assertion of strict proper three-literal CNF. Empty clauses and original unused variables retain correct counting semantics.

\begin{theorem}[One-model counting transfer, CONDITIONAL on the pinned proposition]
One uniform physical deterministic multitape algorithm, on every well-formed encoded circuit $D$, computes $\#D$ exactly and satisfies, on the \emph{same execution},
\[
 T_{\rm phys}=O\bigl((B_C+B_A)^4+T_M(3,n',m')\bigr),
 \quad
 S_{\rm peak}=O(B_C+B_A+T_M(3,n',m')).
\]
Invalid binary sources are rejected with charged polynomial work. For all sufficiently large $V=q+G$,
\[
T_{\rm phys}\le2^{(12C+o(1))V/\sqrt{\log_2V}}.
\]
The claim is measured in \emph{all} source circuit gates, not just its $q$ inputs.
\end{theorem}
\begin{proof}
Parse and validate the original encoded DAG, construct its functional CNF,
apply C1-Promise, write exactly $B_A$ formal input bits, and simulate the
fixed formal finite-stack TM2 on a fixed number of conventional locally
headed writable tapes. Each source machine block performs boundedly many
finite-alphabet stack operations, each implemented with boundedly many real
tape actions; source-word preparation and output order reversal are allowed
$O(B_A^2)$ actions conservatively. The entire parser, deduplication, arithmetic
and encoding cost is bounded by $O((B_C+B_A)^4)$ bit steps.
Keep every live simulated stack symbol, buffer, graph, address and output cell
in the same peak storage tally; there are at most $O(T_M+B_C+B_A)$ such cells.
The first time exponent arm satisfies
\[
\frac{3m'}{\sqrt{\log_2m'}}
\le\frac{12n'}{\sqrt{\log_2(n'/3)}}
=(12+o(1))\frac{V}{\sqrt{\log_2V}},
\]
using $m'\le4n'$ and $n'\le3m'$ from \texttt{AllOccur}.
The polynomial preparation cost is absorbed for sufficiently large $V$.
\end{proof}

\section{Binary-source nondeterministic hierarchy and the remaining NP gap}
The named \textsc{C1f-BINARY} dependency now uses a genuine \emph{binary}
nondeterministic time-hierarchy witness instead of relying on a tally-specific
hierarchy claim. This subsection proves an end-to-end \emph{conditional}
E$^{NP}$ circuit consequence; independent mathematical review remains OPEN.

\begin{lemma}[J56: charged uniform recovery of a fixed-size junta]
For each fixed integer $w\ge1$, an explicit evaluator for every Boolean
$f:\{0,1\}^{\ell}\to\{0,1\}$ depending on at most $w$ coordinates permits a
deterministic exact $O(w2^w)$-gate fan-in-two circuit reconstruction using at most
\[
 2\ell\sum_{j=0}^{w-1}\binom{\ell-1}{j}+2^w
\]
evaluator calls and polynomial additional bit work.
\end{lemma}
\begin{proof}
For each position $i$, query $f(1_S)$ and $f(1_{S\cup\{i\}})$ for all
$S\subseteq[\ell]\setminus\{i\}$ of size at most $w-1$. A relevant position
has a witness in which only its at most $w-1$ other relevant coordinates
might be nonzero, so some tested pair changes. Every irrelevant position
leaves all tests unchanged. Reconstruct the truth table over precisely the
discovered support by at most $2^w$ extra paid evaluations, then build its
Boolean Shannon expansion. Each call actually computes $f$; there is no
free support-location oracle.
\end{proof}

Fix, by the binary nondeterministic time hierarchy, a language
$H\in\operatorname{NTIME}(2^n)\setminus\operatorname{NTIME}(2^{n/2})$.
For every actual $x\in\{0,1\}^n$, the Jahanjou--Miles--Viola
constant-local 3-CNF reduction uniformly generates in polynomial time an
index-to-clause Boolean decoder $D_x$ of address length
$\ell=n+O(\log n)$, $v=\Theta(\ell)=O(n)$ variable-label bits (up to $2^v$ named variables) and $O(n)$ output bits,
each depending on at most a fixed constant $w$ index coordinates.
Its represented formula $\phi_x$ is satisfiable if and only if $x\in H$.
Apply J56 to every output bit: $O(n)$ recovered small subcircuits form an
$O(n)$-gate clause decoder, with every discovery, query and synthesis step
charged polynomial time. This source theorem is cited at its actual scope;
it is not a free source or a claim of arbitrary local encodability.

Choose constant integer $d$ large enough to encode a binary $x$ of length
$n$, one canonical variable index $i$ for $\phi_x$, and zero padding
in a word of length $N=dn$. Let $W(x,i)$ be bit $i$ of the lexicographically
first satisfying assignment of $\phi_x$, or zero on UNSAT, malformed
or noncanonical inputs. Define $W=0$ on other input lengths. A deterministic
$E^{NP}$ machine can explicitly generate the $2^{\ell}$ clauses in
$2^{O(n)}$ time, make $2^{O(n)}$ NP prefix-extension queries on descriptions
of size $2^{O(n)}$, and recover the requested bit. Hence $W\in E^{NP}$.

\begin{theorem}[Binary hierarchy transfer, CONDITIONAL]
Assume the Jahanjou--Miles--Viola local reduction has the preceding
uniform fixed-junta interface and Anthropic's pinned
\texttt{MainResults.mainTheorem} is valid under its stated finite-stack
machine semantics. Then for some $W\in E^{NP}$ and constant
$\eta>0$, infinitely many lengths $N$ have general shared
fan-in-two circuit complexity greater than
$\eta N\sqrt{\log_2 N}$. This does not establish an NP lower bound.
\end{theorem}
\begin{proof}
Suppose instead all sufficiently large lengths $N=dn$ admit such
a circuit $A_N$ of size $s_N\le\eta N\sqrt{\log_2N}$.
On actual binary $x$, a uniform nondeterministic machine guesses and
validates a description of $A_N$ and specializes its $x$ and padding
inputs. Three copies of $A_N$ evaluated on the decoded literal indices
of $D_x$ produce a gate circuit indicating violation of an addressed
clause. It has $q=\ell=n+O(\log n)$ address inputs and
$G\le3s_N+O(n)$ gates. The already proved C1a--C1d compiler and
totalizer give a count-preserving CNF with $V=q+G$ variables
and $m'\le4n'$, $n'=V+O(1)$, including full parsing and all wire taxes.

Conditional on the pinned uniform counter theorem and the physical
finite-stack transfer, the \emph{same actual machine} counts violations
within
\[
 T_{\rm phys}
 \le\operatorname{poly}(V\log V)
  +2^{(12C+o(1))V/\sqrt{\log_2V}}
 =2^{(36C\eta d+o(1))n},
 \qquad S_{\rm peak}=O(T_{\rm phys}+V\log V).
\]
Choose $0<\eta<1/(144d\max(1,C))$; all source generation,
J56 queries, nondeterministic circuit guessing, compilation, simulation
and output fit strictly inside $2^{n/2}$ time for sufficiently large $n$.
For a YES source $x$, the correct global circuit for $W$ yields a
satisfying witness and zero violating addresses; some nondeterministic
branch accepts. For a NO source every possible alleged assignment
violates a clause, so every branch rejects. This puts
$H$ in $\operatorname{NTIME}(2^{n/2})$, contradiction.
\end{proof}

The hierarchy construction is conditional on its original source
premises, with independent verification OPEN. It gives neither a
superpolynomial bound nor any contradiction with $P=NP$.
A $q$-input circuit with $G=q^4$ produces $V=\Theta(q^4)$, so
the counting bound is not $2^{o(q)}$ for arbitrary polynomial gate
size. A distinct nonrelativizing NP-level theorem would be required
to advance a P-versus-NP separation.
