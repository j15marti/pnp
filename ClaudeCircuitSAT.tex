\section{Goal and method}
Find lower bounds, possibly parametrized, for \CSAT. Method: start from the simplest instances, add inputs one at a time, and record for each step (i) the minimum number of gates and wires of any circuit whose satisfiability question is non-degenerate, and (ii) what is forced on a solver. The ladder is a bookkeeping device; each rung states exactly what is proved.

\section{Model (fixed)}
A circuit is a DAG on $n$ inputs $x_1..x_n$, with gates of fan-in 2 computing any of the 16 binary operations ($B_2$), unbounded fan-out, one output. Size $s$ = number of gates; \emph{wires} $=2s$ (one per gate input). Instance length $N=\Theta((s+n)\log(s+n))$ in a standard encoding. Problem: given $C$, is there $x$ with $C(x)=1$? Parameters considered: $n$, $s$, and structural parameters $\theta$ (treewidth/pathwidth of $C$, cut-frontier, see \S5).

\section{Proved elementary rungs}
\begin{thm}[Support bound; PROVED/EXACT]
If the output of a fan-in-2 circuit depends on all $n$ inputs, it has $s\ge n-1$ gates and $\ge 2(n-1)$ wires, and this is tight (AND of literals).
\end{thm}
\begin{proof}
Every input must reach the output, so the underlying undirected graph on $n+s$ vertices is connected after deleting any vertex not reaching the output; this graph needs $\ge n+s-1$ edges. It has exactly $2s$ edges, so $2s\ge n+s-1$. The AND tree meets it. \qedhere
\end{proof}
\begin{thm}[Reading bound; PROVED/EXACT]
Any correct \CSAT\ decider that is given the circuit as a read-only string must read $\Omega(n)$ wires on some input of $n$ variables.
\end{thm}
\begin{proof}
Take the AND tree $C$ of $x_1..x_n$ (satisfiable). Replacing any single leaf wire by constant 0 gives an unsatisfiable circuit. An algorithm that skips a leaf wire cannot distinguish the two. \qedhere
\end{proof}
\begin{thm}[Black-box evaluation bound; PROVED/EXACT, model-restricted]
A decider with only evaluation access to $C$ needs $2^n$ queries in the worst case (adversary answers 0 until one point remains).
\end{thm}
This is not a lower bound for the white-box problem, since a solver sees the wires. It is the rung that white-box structure must beat or match, so every candidate white-box bound should be stated as how much structure the solver can exploit.

\section{Known upper bounds that any lower bound must respect}
\begin{itemize}
\item \textbf{KNOWN THEOREM:} brute force $O(2^n s)$.
\item \textbf{KNOWN THEOREM (folklore dynamic programming):} $2^{O(\mathrm{tw}(C))}\cdot s$ for treewidth tw of the circuit's primal graph, so a parametrized lower bound with parameter tw can be at most exponential in tw.
\item \textbf{KNOWN, to be verified:} non-trivial $2^{n-\Omega(\cdot)}$ algorithms exist for circuits with $s\le cn$ (small-size circuit SAT line of work). Literature check is a next-run item; no claim is made here.
\item \textbf{CONDITIONAL:} ETH implies no $2^{o(n)}\mathrm{poly}(s)$ algorithm (3-SAT embeds with $s=O(n)$). SETH implies no $(2-\varepsilon)^n\mathrm{poly}(s)$ (CNF is a circuit). Under ETH a bound of the form $T\ge 2^{a\min(n,\mathrm{tw})}/\mathrm{poly}$ is the natural parametrized target (CANDIDATE form, not verified from primary sources here).
\end{itemize}

\section{Parametrized candidate and wire-by-wire frontier}
\textbf{Frontier.} For a topological order $\pi$ of the gates, let $F_\pi(t)$ be the number of already-computed signals still feeding later gates. $\mathrm{fr}(C)=\min_\pi\max_t F_\pi(t)$ is a pathwidth-type parameter and DP over $\pi$ gives $T\le 2^{\mathrm{fr}(C)}\mathrm{poly}(s)$ (CANDIDATE bookkeeping; the exact relation to pathwidth is not proved here).

\textbf{Candidate shape} (in the repository's directive of 23 Oct 2026, \texttt{research/governance/2026-10-23\_2127Z\_PARAMETERIZED\_LOWER\_BOUNDS.tex}): for each uniform decider $A$ there are hard instances with $T_A\ge 2^{a_A\rho}/N^{b_A}$ and $\rho/\log N\to\infty$. Three obligations are separate: the work inequality, the growth of $\rho$, and coverage of all adaptive policies. Status of all three for $\rho=\mathrm{fr}$ or $\mathrm{tw}$: \OPEN.

\textbf{Ladder obligation.} Rung $n\to n{+}1$: (a) minimum wire increase of a non-degenerate instance is $\ge 2$ (Theorem~1); (b) the max over functions grows ($0,1,4,\dots$) but this is a statement about \emph{computing} $f$, not about \emph{deciding} its satisfiability. The gap between (b) and a solver-cost lower bound is exactly the open problem; no rung so far touches it.
