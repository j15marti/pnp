\section*{Status discipline}
Labels: PROVED/EXACT, KNOWN THEOREM, COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN, FALSIFIED/RETIRED.
No unconditional super-polynomial lower bound for circuit-SAT is claimed anywhere below.

\section{Plan}
Ladder: for each step $s=1,2,\dots$ fix a class $\mathcal C_s$ of circuits (inputs $n_s$, gates $m_s$, fan-in 2),
and record (a) the minimal number of gates/wires $G_s,W_s=2G_s$ needed to \emph{build} the relevant functions, and
(b) the best proved lower bound $L_s(n,m,\theta)$ for \emph{deciding} satisfiability, where $\theta$ is a
parameter (treewidth, depth, number of non-linear gates, \dots). The target is a bound of the form $L(n,m,\theta)$,
possibly parameterized; the full unparameterized bound is the open P vs NP question.

\section{Rung 0: building blocks (PROVED/EXACT)}
\begin{lem}[connectivity]\label{lem:conn}
A fan-in-2 circuit depending on all of $x_1..x_n$ has $\ge n-1$ gates, hence $\ge 2(n-1)$ wires; tight for $\mathrm{AND}_n$.
\end{lem}
\begin{proof} Each input has a path to the output, so the underlying undirected graph on inputs$\,\cup\,$gates is connected;
a connected graph on $n+g$ vertices has $\ge n+g-1$ edges, and edges $=$ wires $\le 2g$, so $2g\ge n+g-1$, i.e. $g\ge n-1$.
A balanced tree of ANDs attains it.\end{proof}

\begin{thm}[probe lower bound for the decider]\label{thm:probe}
Any deterministic algorithm that decides satisfiability of a circuit given as a read-only list of $m$ gate descriptors
(random access) must read $\ge m$ descriptors in the worst case.
\end{thm}
\begin{proof} Take $n=m$ inputs and the instance $C_0$: gate $g_i=x_i\wedge x_i$ ($i\le m-1$) feeding a fixed final AND tree:
output $=\bigwedge_i g_i$ with each $g_i$ a buffer of $x_i$; $C_0$ is satisfiable. If the algorithm never reads $g_j$'s descriptor,
replace $g_j$ by the constant $0$ gate; the run is identical but the instance is unsatisfiable. Hence every descriptor is read. (Tree gates
are fixed and cost $O(1)$ extra; the bound is $m-O(1)$.)\end{proof}
Status: PROVED/EXACT, but only a linear \emph{input-reading} bound; it says nothing about search over $2^n$ assignments.

\section{Rung 2: from building to deciding (what is and is not known)}
\begin{itemize}
\item KNOWN THEOREM: explicit functions need $\ge 3.1n-o(n)$ gates over $B_2$ (Li--Yang, STOC 2022; to be re-checked against current literature).
This bounds \emph{computing} a function, not \emph{deciding SAT} of a circuit input.
\item CONDITIONAL (parameterized): circuit-SAT with treewidth $\theta$ is solvable in $2^{O(\theta)}\mathrm{poly}(m)$; a SETH-type assumption gives
$2^{(1-\varepsilon)\theta}$ hardness. Not unconditional.
\item Brute-force baseline: $2^n\cdot O(m)$. Any proved lower bound of the shape $L(n,m,\theta)=2^{\Omega(\theta)}$ unconditionally would imply separation of
the relevant restricted classes; this is OPEN.
\end{itemize}
