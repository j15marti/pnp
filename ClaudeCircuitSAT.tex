\section*{Status (strict labels)}
\textbf{P versus NP remains OPEN.} No super-linear unconditional lower bound for CIRCUIT-SAT on general circuits in the RAM/Turing model is claimed. Everything below is labelled PROVED, COMPUTATIONAL, KNOWN, CANDIDATE or OPEN.

\section{Goal and plan}
CIRCUIT-SAT: given a DAG circuit $C$ over basis $B_2$ (all 2-input gates) with $n$ inputs and $m$ gates (so $2m$ wires into gates plus fan-out edges), decide $\exists x\;C(x)=1$. Parameters: $n$ (inputs), $m$ (gates), $w$ (wires), fan-out profile, depth, and treewidth $\mathrm{tw}$.
Plan (the ``ladder''): for each level $(n,m)$ record (a) the minimal number of gates/wires to realise each function, (b) the information an algorithm must read, (c) the best provable bound on decision work. Look for a parametrized bound $T(n,m,\dots)$ whose shape is not killed by the known barriers.

The whole difficulty is the gap between the first two rows and the third: an algorithm may exploit the \emph{wiring}. The ladder studies how much wiring structure an instance must carry.

\begin{lemma}[L1, oracle bound, PROVED]
Any deterministic algorithm that only evaluates $C$ on chosen inputs needs $2^n$ evaluations in the worst case.\end{lemma}
\emph{Proof.} Answer 0 to every query; after $<2^n$ queries some $x$ is unqueried, and $C=\mathbb 1_{x}$ is consistent with all answers while $C\equiv0$ is too. \qed

\begin{lemma}[L2, reading bound, PROVED]
For every $m$ there are $n=1$ instances with $m$ gates such that any algorithm (deterministic or randomized with error $<1/2$ after normalisation) must inspect $\Omega(m)$ cells of the encoding.\end{lemma}
\emph{Proof.} $g_0=x$, $g_i=g_{i-1}\wedge g_{i-1}$, output $g_m$: satisfiable. Replace one $g_j$ by $g_{j-1}\wedge\neg g_{j-1}$ (constant 0): unsatisfiable. The $m{+}1$ instances differ in one gate each, so an algorithm that misses gate $j$ cannot distinguish; a randomized one must read a constant fraction. \qed

\section{Parametrized targets (CANDIDATE)}
\begin{enumerate}
\item $T(n,m)$ for white-box CIRCUIT-SAT. Trivial: $\Omega(m)$ (L2). Upper: $2^n m$. Target shape $\Omega(m\cdot f(n))$ with unconditional $f$ superconstant under a restricted algorithm class.
\item Restricted classes where an honest proof may exist: (i) \emph{gate-elimination} (DPLL-style) algorithms, where each branch fixes an input and simplifies; (ii) oblivious/read-once branching algorithms; (iii) sequential-access / one-tape models (see repository note \texttt{2026-10-28\_1521\_CLAUDE\_ONETAPE-0001.tex}).
\item Fixed-parameter view: with treewidth $k$, CIRCUIT-SAT is $2^{O(k)}m$; a matching lower bound under SETH is known for CNF-SAT in treewidth, so a parametrized lower bound should be measured in $\mathrm{tw}$, not $n$.
\end{enumerate}
