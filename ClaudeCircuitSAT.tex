\section{Goal and method}
Goal: lower bounds for circuit-SAT. Method: start from the smallest instances, build circuits gate by gate, record every wire, and track the exact minimum number of gates (wires $=2\times$ gates in the fan-in-2 basis $B_2$, where negation is free) for each target function as the number of inputs $n$ grows. Two different quantities are tracked and must not be conflated:
\begin{enumerate}
\item $s(f)$: minimum $B_2$-circuit size of a fixed function $f$ (e.g.\ a CNF verifier $V_\varphi(x)=\varphi(x)$);
\item $T_{\mathrm{SAT}}(N)$: cost of deciding satisfiability of an $N$-bit encoded circuit. A superpolynomial bound on the circuit size of $\mathrm{SAT}_N$ would give $\mathrm{NP}\not\subseteq \mathrm{P/poly}$; it is not implied by lower bounds on $s(V_\varphi)$, which are always $\le$ the size of $\varphi$.
\end{enumerate}

\section{Rung 0: connectivity (PROVED/EXACT)}
\textbf{Lemma 1.} A fan-in-2 circuit whose output depends on all $n$ inputs has at least $n-1$ gates, hence at least $2(n-1)$ wires.
\emph{Proof.} The underlying graph restricted to the cone of the output is connected with $n$ source inputs; a gate merges at most two components, so $n-1$ merges are needed. \qed

Tight for $\mathrm{AND}_n$, $\mathrm{XOR}_n$ (trees). Data below: AND$_4$, XOR$_4$ cost 3 gates (6 wires).

\section{Rung 2: query model for circuit-SAT (PROVED/EXACT, restricted model)}
\textbf{Proposition 2.} Let the instance be an $m$-gate circuit presented by a wire oracle (``what feeds input $b$ of gate $i$?''). Any deterministic algorithm deciding satisfiability makes $\ge m$ wire queries in the worst case.
\emph{Proof.} Let $h_i=\mathrm{AND}(x_i,\neg x_i)$ for $i\le m$ (wires fixed by the oracle's default) and output $=\bigvee_i h_i$: unsatisfiable. Instance $I_j$ rewires the second input of $h_j$ to $x'_j$ (a fresh variable): satisfiable. An algorithm that answers UNSAT on the default instance without reading $h_j$'s second wire cannot distinguish it from $I_j$. \qed

This is a probe/acquisition bound, not a time bound for an unrestricted RAM; it matches the repository's fixed-width acquisition rung (root \texttt{main.tex}, Proof spine: $\Omega(N/\log N)$ word probes).

\section{Barriers and what each rung does \emph{not} give}
\begin{itemize}
\item KNOWN THEOREM (cited from memory, not re-verified this run): best explicit $B_2$ lower bounds are linear, $\approx 3.1n$ (gate elimination; Find--Golovnev--Hirsch--Kulikov 2016, Li--Yang 2022). Wire counting alone stalls at linear size.
\item Natural proofs, relativization, algebrization apply to any argument via a large, constructive property of truth tables; the exact tables above are not such an argument.
\item Rung 1 values are for fixed functions of tiny $n$; no extrapolation to $n\to\infty$ is claimed.
\end{itemize}
