\section{Goal and method}
Find (possibly parametrized) lower bounds for Circuit-SAT: given a fan-in-2 circuit with
$n$ inputs and $m$ gates, is there an input making the output 1? Method: start from the smallest
circuits, record the exact minimum number of gates (hence wires, $w=2g$) needed for each function
as $n$ grows, and look for structure that transfers to a bound on deciding satisfiability.
Parameters tracked: $n$ (inputs), $m$ (gates), $w=2m$ (wires), and later treewidth/depth $d$.

These counts match the known $B_2$ values (max 4 for $n=3$); extending to $n=4$ (max 7 gates) requires a
chunked search and is the next step.

\subsection{Step 2: a parametrized, unconditional probe lower bound (PROVED)}
Model: the circuit is given by gate-labelled adjacency lists; an algorithm learns the circuit only by
probes (``what is gate $i$'s label / input $j$?''), and must output SAT/UNSAT correctly.
\begin{prop}
Any deterministic (or randomized zero-error) probe algorithm deciding satisfiability of circuits with $m$ gates
and $n\ge m/2$ inputs makes at least $m/2-O(1)$ probes in the worst case, independent of $n$ beyond that.
\end{prop}
\begin{proof}
Let $k=\lfloor m/4\rfloor$. Base instance $C_0$: AND of $2k$ literal leaves; leaf $i$ and leaf $k+i$ are both $x_i$
($1\le i\le k$). It is satisfiable. For $j\in[k]$, instance $C_j$ replaces leaf $k+j$ by $\neg x_j$; it is unsatisfiable.
$C_0$ and $C_j$ differ only in one leaf label. If on $C_0$ the algorithm never probes leaf $k+j$, it
behaves identically on $C_j$ and errs. Hence it probes all $k$ leaves $k+1..2k$: $\ge k=\Omega(m)$. \qed
\end{proof}
This is the trivial ``must read the input'' bound; its value is as the baseline of the ledger: any
super-linear bound needs an argument that is not an input-reading argument.

\item Link: Circuit-SAT of $C$ asks whether $f_C\ne 0$; study which \emph{sub-circuit-size} structure forces

\end{enumerate}

\section{Known results used (KNOWN)}
Unconditional general-model lower bounds for Circuit-SAT beyond linear are not known; under ETH/SETH the
conditional bound $2^{\Omega(n)}$ (resp.\ $2^{(1-o(1))n}$ for CNF-SAT) holds. Gate elimination: Blum 1984
$3n-o(n)$; Find--Golovnev--Hirsch--Kulikov 2016 $3.011n$ for $B_2$ (functions, not SAT time).
