\section{Goal and method}
Goal: a lower bound for Circuit-SAT (NP-complete). Method: start with the smallest circuits, add inputs one at a time, and ledger (i) the minimum number of gates $g(n)$ and wires $w(n)$ needed to \emph{build} a circuit with $n$ inputs having a given property, and (ii) what any SAT-decider must \emph{read}. Convention: fan-in-2 gates over the full binary basis $B_2$; $w=2g$ counting gate input wires (output wires = fan-out are tracked separately).

\section{Ladder}
\paragraph{Rung 0 ($n=1$).} Circuits are $x$, $\neg x$, $0$, $1$ (up to free negation, $g=0$, $w=0$). SAT decided by reading one description. PROVED/EXACT.

\begin{lemma}[Connectivity rung, PROVED/EXACT]\label{lem:conn}
A fan-in-2 circuit with a single output that depends on all $n$ inputs has $g\ge n-1$ and $w\ge 2(n-1)$; equality holds for AND$_n$, OR$_n$, XOR$_n$ (a tree).
\end{lemma}
\begin{proof} Each input has a path to the output, so the underlying undirected graph on $n$ inputs plus $g$ gates is connected, hence has $\ge n+g-1$ edges; wires $=2g$ (each gate has two in-wires) gives $2g\ge n+g-1$, i.e.\ $g\ge n-1$. \end{proof}

\begin{lemma}[Read-all rung, PROVED/EXACT, deterministic, descriptive model]\label{lem:read}
Let instances be $C=\mathrm{AND}(h_1,\dots,h_m)$ in which each $h_i$ is a literal or constant $0$, encoded as a list of $m$ cells. A deterministic algorithm deciding SAT must read all $m$ cells.
\end{lemma}
\begin{proof} On the all-literal (consistent) instance, if a cell is unread, set it to $0$: the answer flips from SAT to UNSAT, indistinguishable. \end{proof}
This matches the repository's fixed-width $\Omega(N/\log N)$ acquisition bound (root \texttt{main.tex}): a linear-in-wires rung, \emph{not} a time lower bound against arbitrary algorithms.

\section{Why the ladder does not simply continue}
\begin{itemize}
\item \textbf{Wire count is a construction cost, not a solver cost.} Lemma~\ref{lem:conn} lower-bounds the circuit \emph{being built}; a SAT solver's cost is a different quantity. Linking them needs a theorem that every solver must ``use'' each wire in a way that compounds; none known (CANDIDATE only).
\item \textbf{Barriers.} Relativization (Baker--Gill--Solovay), natural proofs (Razborov--Rudich), algebrization (Aaronson--Wigderson) rule out the generic ways to extend counting arguments; any new rung must be checked against all three.
\item \textbf{Gate elimination plateau.} Removing $O(1)$ gates per restricted variable yields only linear bounds; the repo's AGGREGATION-CEILING91 and DENSE-COUPLING-FIREWALL90 results are the same phenomenon for the acquisition model (linear-type ceilings).
\end{itemize}

\section{Theoretical search bounds: a model hierarchy (CCS3, no computation)}
Setting: a Circuit-SAT instance is a circuit $C$ with $n$ inputs and $m$ gates. A \emph{search algorithm} explores partial assignments. Lower bounds are only available when the model restricts \emph{what the algorithm may infer}; we ladder the models, each defeating the previous hard family, and mark where the ladder stops.

\subsection*{S0. Information cannot give superlinear bounds (PROVED/EXACT)}
\begin{proposition}[Descriptive cap]\label{prop:cap}
In the model where the algorithm may read the $O(m\log m)$-bit description of $C$ and is charged only for reads, Circuit-SAT has read complexity $\Theta(m)$ (up to the encoding width): the $\ge m$ cells bound is Lemma~\ref{lem:read}, and reading everything is an upper bound. Hence any superlinear lower bound for Circuit-SAT must be a \emph{computational} (not an information) bound.
\end{proposition}
This is why the acquisition bounds in the repository are linear-type ceilings, and why ``count the wires that must be read'' cannot by itself reach NP-hardness.

\subsection*{S1. Black-box search (KNOWN THEOREM, irrelevant to white-box)}
Treating $C$ as an oracle, unique-SAT needs $\Theta(2^n)$ deterministic queries, $\Omega(2^{n})$ randomized (constant success), and $\Theta(2^{n/2})$ quantum (Bennett--Bernstein--Brassard--Vazirani; Grover). Classification: FAILED TRANSFER for lower bounds on real SAT solvers, because a solver sees the wires (relativization: the same bound holds relative to oracles where P$=$NP is false \emph{and} true on other oracles---Baker--Gill--Solovay).

\subsection*{S2. Ternary-evaluation branching (PROVED/EXACT, restricted model)}
Model $\mathcal T$: the algorithm branches on inputs, evaluates $C$ on the partial assignment in Kleene three-valued logic, prunes a branch only when the output is $0$, and accepts when it is $1$.
\begin{proposition}\label{prop:xor}
Let $C_n=\mathrm{XOR}(x_1..x_n)\wedge\neg\mathrm{XOR}(x_1..x_n)$ (two separate trees, size $O(n)$, unsatisfiable). Any $\mathcal T$-algorithm explores all $2^n$ full assignments.
\end{proposition}
\begin{proof} A Kleene-XOR gate outputs $\ast$ if any input is $\ast$; by induction every gate on a path from a free input to the output is $\ast$. So the output is $\ast$ on every proper partial assignment and equals $0$ only at full assignments; no branch is pruned before depth $n$. \end{proof}
This family is easy for stronger models (S3): the model is too weak, not the instance hard.

\subsection*{S3. Propagation, learning, resolution (KNOWN THEOREMS; the exact transfer)}
Tseitin-encode $C$ to a CNF $F_C$ of size $O(m)$. DPLL with unit propagation on an unsatisfiable $F_C$ yields a tree-like resolution refutation of $F_C$ of size at most the run-time; CDCL with unrestricted restarts and suitable learning polynomially simulates general resolution (Pipatsrisawat--Darwiche; Atserias--Fichte--Thurley). Hence, for these algorithm classes, \emph{search time $\ge$ (tree-like, resp.\ general) resolution refutation size}: EXACT OBJECT/THEOREM TRANSFER (statement direction: algorithm $\Rightarrow$ proof). Known hard families: pigeonhole (Haken, $2^{\Omega(n)}$ resolution size); Tseitin formulas on expanders (Urquhart; Ben-Sasson--Wigderson width--size, tree-like $2^{\Omega(n)}$). Prop.~\ref{prop:xor}'s family has linear-size resolution refutations (bounded width), confirming the hierarchy.
\emph{Circuit-specific caveat:} these hard formulas must be realized as Tseitin encodings of small circuits with $\Theta(n)$-size description and a single output; pigeonhole counting circuits and graph-parity circuits qualify, but the bound is then a bound for \emph{resolution-based solvers}, not for all algorithms (CANDIDATE for any broader claim).

\subsection*{S4. Beyond resolution: where the ladder is OPEN}
Stronger systems (cutting planes, bounded-depth Frege, Frege, extended Frege) each define a search-model class when the algorithm must certify UNSAT inside the system. Lower bounds: cutting planes (Pudl\'ak; monotone interpolation, KNOWN), constant-depth Frege on pigeonhole (Ajtai; KNOWN). General Frege/extended Frege: OPEN, and a superpolynomial extended-Frege bound would separate NP from co-NP. Honest conclusion: the model ladder reproduces proof complexity; no step is new here.

\subsection*{S5. Wire-by-wire potential for a model (CANDIDATE)}
To keep the user's wire-ladder idea inside a valid model, define for a search tree the \emph{frontier} $W(\rho)$ = set of wires whose value is determined under partial assignment $\rho$. Stage-$k$ conjecture: in model $\mathcal M$ every branch must raise $|W|$ by at most $\delta_{\mathcal M}$ per assigned input, so reaching a decision ($W\ni$ output) needs depth $\ge m/\delta_{\mathcal M}$---a \emph{linear depth} bound at best, giving size $2^{\Omega(\cdot)}$ only if branching is forced at each level. Proposition~\ref{prop:xor} is the case $\delta=0$ until the last input. Open arrow: an instance family with $\delta_{\mathcal M}$ small \emph{and} no stronger-model shortcut; for $\mathcal M=$ resolution this is exactly pigeonhole/Tseitin width, so the potential is a re-derivation of width lower bounds (analogy, no new theorem).

\subsection*{S6. Barrier audit}
Natural proofs: S2--S3 bounds are not ``large and constructive over all functions'' (they target one proof system), so no barrier applies to them. Any attempt to lift S3 to \emph{all} algorithms hits: relativization (resolution lower bounds do not relativize but are model-specific), algebrization and natural proofs for circuit-class lower bounds, and the fact that the lift is equivalent to NP$\ne$co-NP-type statements. No such lift is claimed.
