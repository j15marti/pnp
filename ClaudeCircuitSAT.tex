\section{Goal and model}
Circuit-SAT: given a Boolean circuit $C$ over $n$ inputs with $m$ fan-in-2 gates (basis $B_2$, all 16 binary gates), decide $\exists x\ C(x)=1$. Two measures are tracked, grown step by step in $n$:
\begin{itemize}
\item $s(f)$: minimum gates (so $2s$ gate-input wires) of a circuit computing $f$ --- the \emph{construction cost} of an instance.
\item $q(n,m)$: worst-case number of gate descriptions an algorithm must read (probe model) --- the \emph{solving cost} lower bound, possibly parametrized by $n$, $m$.
\end{itemize}

\section{Proved results (small, exact)}
\begin{lemma}[Connectivity, PROVED/EXACT]\label{l:conn}
If $f$ depends on all $n$ inputs, any $B_2$ circuit for $f$ has $\ge n-1$ gates and $\ge 2(n-1)$ gate-input wires.
\end{lemma}
\begin{proof} Each essential input has a path to the output; the union of these paths is a fan-in-2 DAG with one sink and $n$ sources, which needs $\ge n-1$ internal nodes (each gate merges at most two components). \end{proof}
A function with a unique satisfying assignment and all $n$ variables essential (e.g.\ $\bigwedge_i \ell_i$) meets this, so $s=n-1$.

\begin{lemma}[Probe lower bound, PROVED/EXACT]\label{l:probe}
Any algorithm deciding Circuit-SAT for $m$-gate circuits by reading gate descriptions must read $\ge m$ gates in the worst case (for $m\ge n-1$).
\end{lemma}
\begin{proof} Let $C_0$ be the AND-chain on $n$ inputs padded to $m$ gates (padding gates are AND of the previous gate with itself, so every gate lies on the path to the output); $C_0$ is satisfiable. Replacing any single gate by the constant-0 gate gives an unsatisfiable $C_i$. An algorithm that skips gate $i$ cannot distinguish $C_0$ from $C_i$. \end{proof}
This is a \emph{trivial} $\Omega(m)$ bound: it counts reading the input, not search.
