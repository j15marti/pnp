\section{Program and measure}
\textbf{Goal.} Lower-bound the size of Boolean circuits deciding an NP-complete problem, built up from the smallest instances.

\textbf{Model.} Fan-in-2 circuits over the full basis $B_2$ (negation free). $s(f)$ = minimum gates, $w(f)=2s(f)$ = wires into gates (output wire not counted). Fan-out is tracked separately: a gate-elimination step may delete $1+$(fan-out of the eliminated input) gates, which is why fan-out matters.

\textbf{Family (uniform in the instance, not a single fixed circuit).} $\SAT_{n,k}$: input is a CNF with $k$ clauses over $n$ variables, each clause given by $2n$ membership bits $(p_{c,v},q_{c,v})$ (positive/negative literal present). Output $1$ iff satisfiable. Fixing one circuit instance makes the problem constant, so the lower bound must be on the \emph{decider} for the encoded family. This is the standard non-uniform formulation; $\SAT_{n,k}$ is NP-complete as $n,k$ grow polynomially.

\section{Ladder of steps}
\begin{proposition}[PROVED/EXACT, trivial] If $f$ depends on all $N$ inputs then $s(f)\ge N-1$ (connectivity: a fan-in-2 circuit with a single output reaching $N$ inputs has $\ge N-1$ gates), so $w(f)\ge 2N-2$. $\SAT_{n,k}$ depends on all $2nk$ inputs (checked for $(2,2)$ by COMPUTATIONAL flip test; in general each bit can be made pivotal).\end{proposition}

\begin{proposition}[PROVED/EXACT, construction] $s(\SAT_{n,k})\le 2^n nk-1$ (OR over assignments of AND over clauses of OR of satisfied literals).\end{proposition}

\textbf{Observation.} In all solved steps $s=N-1$: the decider is a read-once-like tree, so no wire beyond connectivity is forced. The first step where the trivial bound might fail to be tight is $(n,k)=(2,2)$; if its exact value exceeds $7$, that is the first genuine ``extra wire'' datum. \section{Literature context (KNOWN THEOREM)}
Best known lower bound for an explicit function in $B_2$ is $3.1n-o(n)$ gates (Li--Yang, STOC 2022, ECCC TR21-023; improving Blum's $3n-o(n)$ and Find--Golovnev--Hirsch--Kulikov $(3+1/86)n$), by gate elimination for affine dispersers. Any superlinear bound for an NP function would be a major breakthrough; none is claimed. Gate elimination is the technique to extend: $\SAT_{n,k}$ has too much slack to be an affine disperser directly, so a bridge is needed (OPEN).

\section{Barriers to respect}
Natural proofs (conditional on one-way functions), relativization and algebrization do not rule out gate elimination for linear bounds but constrain any approach to superpolynomial size. Any proposed technique must state which barrier it evades.
