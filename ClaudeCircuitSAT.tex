\section{Goal and method}
Goal: lower bounds for \CSAT: given a fan-in-2 circuit $C$ on $n$ inputs with $s$ gates ($w=2s$ wires), decide whether $\exists x\,C(x)=1$. Programme: start from the simplest circuits, build up gate by gate, record the \emph{minimum number of wires} any circuit needs to realise each target function, and increase $n$ step by step, tracking the resulting lower bound as a function of the parameters $(n,s,k)$ ($k$ = number of satisfying assignments, or treewidth, or depth). Bounds are expected to be parametrized, e.g.\ $T(n,s)\ge f(n)\,s$.

Model: basis $B_2$ (all binary gates, negation free). Size $=$ number of gates; wires $=2\cdot$gates when every gate is non-degenerate.

\section{Level ladder (min wires to build the target)}
\begin{definition} $S(f)$ = minimum number of $B_2$ gates computing $f$; $W(f)=2S(f)$.\end{definition}

\begin{lemma}[Connectivity, PROVED]\label{lem:conn} If $f$ depends on all $n$ inputs then $S(f)\ge n-1$, so $W(f)\ge 2(n-1)$.\end{lemma}
\begin{proof} The cone of the output is a DAG with one sink; every input in it must reach the sink. Consider the underlying undirected graph on the $n$ input nodes plus $S$ gate nodes; it is connected, so has $\ge n+S-1$ edges. Each gate has exactly 2 in-edges, so edges $=2S$ (counting only wires into gates). Hence $2S\ge n+S-1$, i.e.\ $S\ge n-1$.\end{proof}

\begin{proposition}[Tightness for unique-SAT, PROVED]
The minterm $\mathrm{AND}_n$ (exactly one satisfying assignment) and $\mathrm{XOR}_n$ have $S=n-1$, $W=2n-2$. So for $k=1$ and for $k=2^{n-1}$ the build cost is linear; the ladder is flat at slope 2 wires per input.\end{proposition}

\section{Algorithmic lower bound: probe model}
Encode $C$ as a list of $s$ gate records (type, two predecessor pointers).
\begin{theorem}[Linear probe bound, PROVED, trivial]\label{thm:probe}
Any deterministic algorithm deciding \CSAT\ on size-$s$ instances in the record-probe model makes $\ge s$ probes.\end{theorem}
\begin{proof} Instance $C_0$: chain $g_i=g_{i-1}\wedge x_i$, output $g_s$; satisfiable. The adversary answers every probe truthfully for $C_0$. If gate record $i$ is never probed, $C_0'$ (gate $i$ replaced by constant $0$) answers identically yet is unsatisfiable.\end{proof}
This is only an input-reading bound; it is the baseline $T(n,s)\ge s$. Everything beyond it is where hardness lives.
