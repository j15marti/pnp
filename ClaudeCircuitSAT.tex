\section*{Status}
\textbf{P versus NP remains OPEN.} No unconditional super-polynomial lower bound for Circuit-SAT is claimed. This document records exact small-case facts (COMPUTATIONAL / PROVED) and a ledger of parameterized bounds.

\section{Model and ledger}
Circuits: fan-in-2 gates over all 16 binary operations, fan-out unrestricted. $\mathrm{C}(f)$ = minimum gate count. Wires = gate input edges ($2\times$gates). Parameters: $n$ inputs, $s$ gates, $w=2s$ wires.

\section{Step-by-step minimal construction}
\paragraph{Step 0 (PROVED/EXACT).} $n=1$: functions $0,1,x,\neg x$ cost $0$ gates ($\neg x$ costs 0 under the all-binary-ops basis, since $x\oplus x$-type gates are not needed as negation is absorbed; with only a fixed single-input NOT it costs 1).
\paragraph{Step 1 (PROVED/EXACT).} A function depending essentially on $n$ variables needs $\ge n-1$ gates and $\ge 2(n-1)$ wires: the circuit restricted to its cone must connect $n$ input nodes to one output, and each gate merges at most two components. AND$_n$ and XOR$_n$ attain $n-1$. Hence for connected-support circuits $s\ge n-1$.
\paragraph{Step 2 (COMPUTATIONAL).} Exhaustive search (\texttt{experiments/claude\_circuitsat/mincircuit.py}, depth 3, $n=3$): of 256 functions on 3 variables, 232 have $\mathrm{C}\le3$ (histogram by cost $0,1,2,3$: $5,33,114,80$ with constants/projections cost 0); the remaining 24 need $\ge4$ gates (known max is 4, Knuth). Parity$_3$ and AND$_3$ cost 2.

\section{From circuit size to Circuit-SAT lower bounds}
\begin{itemize}
\item (PROVED, trivial) Any decider must read the circuit description: time $\Omega(s)$ on size-$s$ instances; Step 1 gives $s\ge n-1$ for essential-support instances, so time $\Omega(n)$.
\item (KNOWN THEOREM) Time--space tradeoffs for SAT (Fortnow--van Melkebeek; Williams; the FLMV line): no algorithm with $n^{o(1)}$ space runs in time $n^{c}$ for $c$ below roughly $1.8$ (see repo ARC/FLMV spine). Treated here as input, not reproduced.
\item (CONDITIONAL) Parameterized form: under SETH, no $O((2-\epsilon)^n\,\mathrm{poly}(s))$ algorithm. Lower bound as function of $(n,s)$ is thus $2^{n}\cdot s^{O(1)}$ conditionally; unconditionally only $\Omega(s)$ plus tradeoff bounds.
\end{itemize}
