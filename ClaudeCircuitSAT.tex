\section*{Status}
\textbf{P versus NP remains open.} No superlinear unconditional lower bound for Circuit-SAT in a general
model is claimed. Status labels: PROVED/EXACT, COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN, FALSIFIED/RETIRED.

\section{Model and parameters}
A circuit $C$ has $n$ inputs and $m$ binary gates (AND/OR, negation free on wires). Each gate has two
in-wires, so $w(C)=2m$ gate-input wires (+1 output wire). Circuit-SAT: given $C$, decide $\exists x\,C(x)=1$.
Parameters: $(n,m)$, and later depth, fan-out, treewidth/pathwidth. A \emph{parameterized} bound is a
function $T(n,m)$; the instance length is $N=\Theta(m\log(n+m))$ bits.

\section{Ladder, proved statements}
\begin{lemma}[Connectivity floor; PROVED/EXACT]\label{l:conn}
If $C$ depends on all $n$ inputs then $m\ge n-1$ and $w\ge 2(n-1)$.
\end{lemma}
\begin{proof} Consider the undirected graph on inputs and gates with an edge per wire. A gate that
depends on $k$ inputs lies in a connected component with those inputs; the output component contains
all $n$ inputs and $n+m'$ vertices ($m'\le m$ gates in it), hence $\ge n+m'-1$ wires. Every wire enters
a gate, so wires $=2m'$, giving $2m'\ge n+m'-1$, i.e.\ $m\ge m'\ge n-1$.\end{proof}

\begin{proposition}[Read-all-wires bound; PROVED/EXACT]\label{p:read}
For every $k$ there are instances with $n=k$ inputs and $m=2k-1$ gates such that any deterministic
decider (or any decider that is correct on all instances of the family) must read at least $k$ wire
descriptions; hence time $\Omega(m)$ in any model charging per wire read.
\end{proposition}
\begin{proof} Let $A_i=\mathrm{AND}(x_i,\neg x_i)$ and $C_0=\mathrm{OR}_{i\le k}A_i$ (unsatisfiable;
$k$ ANDs, $k-1$ ORs). Redirecting the second in-wire of $A_i$ from $\neg x_i$ to $x_i$ gives a
satisfiable $C_i$ differing from $C_0$ in one wire. If the algorithm does not read that wire on input
$C_0$, it behaves identically on $C_i$ and errs. So all $k$ critical wires are read.\end{proof}

Reading: the hardest $n$-variable function costs $m^*(n)$ gates; Shannon counting gives
$m^*(n)=\Theta(2^n/n)$ asymptotically (KNOWN THEOREM), so the wire count needed \emph{to even write down}
a worst-case function grows exponentially in $n$; this is a statement about circuit size, not solving time.
