\section{Setup}
A circuit $C$ over $n$ inputs has $g$ fan-in-2 gates (any of the 16 binary functions) and $w=2g$ gate-input wires, plus output. Circuit-SAT: given $C$, is $\exists x\,C(x)=1$? Two size measures: instance size $m=(g,w)$ and input count $n$. Candidate parameters: $n$, $w$, treewidth $\mathrm{tw}(C)$, max fan-out $\phi$, depth.

\section{Step-by-step wire accounting (building up)}
\begin{prop}[PROVED, counting] If $f$ depends on all $n$ inputs and $C$ computes $f$, then $g\ge n-1$, i.e.\ $w\ge 2(n-1)$; equality is attained by a read-once tree (e.g.\ AND of literals).\end{prop}
\emph{Proof.} Every input must have a path to the output, so the underlying undirected graph on $n+g$ nodes is connected: edges $2g\ge n+g-1$. A fan-in-2 tree attains it. \qed

\begin{prop}[PROVED, counting] A \emph{non-read-once} dependence (fan-out $\ge2$ on some node) adds one wire per extra use; a circuit with $r$ ``reconvergent'' wires has $w=2(n-1)+r$ when $g=n-1+r/2$.\end{prop}
(Bookkeeping identity $w=2g$; $g=n-1+\text{(extra gates beyond the spanning tree)}$.) Each added fan-out is exactly where hardness can enter: tree-like ($\mathrm{tw}=1$, $r=0$) circuits are SAT-decidable in $O(w)$ time by bottom-up dynamic programming.

\section{Lower bounds for \emph{solving}}
\begin{prop}[PROVED, query/adversary] In the evaluation-oracle (black-box) model, deciding SAT for the family $\{C_a=\bigwedge_i \ell_i^{a_i}\}_{a\in\{0,1\}^n}\cup\{0\}$ requires $2^n$ evaluations in the worst case (adversary answers 0 until one candidate is left), although each $C_a$ has only $n-1$ gates, $2(n-1)$ wires.\end{prop}
Interpretation: small circuits ($w=O(n)$) are already black-box hard, so any algorithm beating $2^n$ \emph{must} read the wiring. This is the natural interface for the wire-by-wire program: a lower bound must show that reading wires cannot help \emph{enough} for dense, reconvergent wirings.
\begin{prop}[PROVED, trivial] Any algorithm needs $\Omega(w)$ time/reads (relevant wires must be read when the circuit is the input) in the standard encoding.\end{prop}

\section{Candidate program (CANDIDATE / OPEN)}
Define $\lambda(n,r)$ = least time of a correct SAT algorithm on all $n$-input circuits with $r$ reconvergent wires. Known: $\lambda(n,0)=\Theta(n)$ (trees); $\lambda(n,r)\le 2^{\min(n,O(r))}\mathrm{poly}$ (branch on $r$ fan-out stems: cutting $r$ reconvergence points leaves a tree). \textbf{Conjecture (CANDIDATE):} $\lambda(n,r)\ge 2^{\Omega(r)}$ for $r\le n$ in a restricted model (e.g.\ DPLL/resolution-style or monotone branching), then lift. Prop.~3 is the $r=n$ black-box end. The upper bound $2^{O(r)}$ (stem-cutting) is a PROVED easy fact: fixing the $r$ stems makes the rest fan-out-free.
Open arrows: (i) a general-model lower bound in $r$ (essentially OPEN, implies superpolynomial bounds when $r=\omega(\log w)$); (ii) relation to treewidth: $\mathrm{tw}\le r+1$.
