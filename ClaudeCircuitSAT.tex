\section{Program}
Start from the smallest circuits, grow input count $n$ and size $m$ (gates; wires $w$), and track (i) the minimum size needed to build each function, (ii) what any solver must examine/spend to decide satisfiability, as a function of parameters $(n,m,w,\text{width/treewidth }k,\dots)$. Target shape: $T(n,m,k)\ge f(n,m,k)$, possibly parameterized.

\section{Step 2: what a Circuit-SAT solver must pay}
\begin{prop}[Reading bound, PROVED] Any algorithm (random-access, read-only input) correctly deciding satisfiability of circuits of $w$ wires reads $\Omega(w)$ input cells in the worst case.\end{prop}
\emph{Proof.} Take $C=\bigwedge_{i\le n}\ell_i$ (balanced AND tree) with distinct non-complementary literals: SAT. If the algorithm leaves wire cell of $\ell_i$ unread (and $n\ge2$), the adversary replaces $\ell_i$ by $\neg\ell_j$ ($j\ne i$) consistent with all reads: now UNSAT, same transcript. So $\ge n-1=\Omega(w)$ reads. \qed

\begin{prop}[Black-box bound, PROVED] If $C$ is accessible only through evaluation queries, deciding SAT on $n$ inputs needs $2^n$ queries worst case (deterministic) --- adversary answers 0 until one point is left.\end{prop}
This is the $2^n$ shape; a white-box solver is not so limited, so it does not bound the real problem. Gap between $\Theta(w)$ (reading) and $2^n$ (black box) is exactly the content of the open problem.

\section{Step 3: parameterized landscape}
\begin{itemize}
\item KNOWN: dynamic programming over a width-$k$ (treewidth/pathwidth) decomposition decides SAT in $2^{O(k)}\,\mathrm{poly}(m)$; at $k=O(\log m)$ it is polynomial. So any hardness must live in width $k=\omega(\log m)$.
\item CONDITIONAL: under SETH, no $2^{(1-\varepsilon)n}\mathrm{poly}(m)$ algorithm for Circuit-SAT (and for CNF-SAT of pathwidth $k$, no $(2-\varepsilon)^k$), \emph{literature recollection, to be checked against primary sources next run}.
\item KNOWN: Williams-type time--space tradeoffs give $n^{2\cos(\pi/7)-o(1)}\approx n^{1.80}$ for SAT on RAMs with $n^{o(1)}$ space; this is the strongest unconditional non-linear statement of this type. The repository's ARC/FLMV spine targets exactly this regime; see \texttt{main.tex}, status OPEN.
\item CANDIDATE parameterized target: $T\ge \Omega(m)+2^{\Omega(k)}$ for width-$k$ instances in a restricted model (e.g.\ monotone/read-once-per-width-layer algorithms); not claimed.
\end{itemize}
