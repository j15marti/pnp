\section{Model and accounting}
A circuit is a DAG of 2-input AND gates with free negation on edges (AIG); $n$ inputs,
$g$ gates, $w=2g$ wires (gate input connections), plus one output pointer.
Circuit-SAT: given $C$, decide $\exists x\,C(x)=1$. Parameters: $n$, $g$, $w$.
Let $G(f)$ be the minimum gate count for $f$ and $W(f)=2G(f)$.

\section{Proved bounds (elementary)}
\begin{theorem}[connectivity, PROVED]
If $f$ depends on all $n$ inputs, any AIG for $f$ has $g\ge n-1$, so $w\ge 2(n-1)$.
In particular a unique-satisfying-assignment function (a minterm) has $G=n-1$, matching the
table ($0,1,2$ for $n=1,2,3$) and a balanced AND tree.
\end{theorem}
\begin{proof}
Every input is connected to the output in the underlying undirected graph on $n+g$ nodes
(a relevant input must reach the output). A connected graph has $\ge n+g-1$ edges, and edges
$=2g$ (outputs have no wire), so $g\ge n-1$. Tightness: AND tree.
\end{proof}
\begin{theorem}[wire-probing bound, PROVED]
Let $\mathcal C_m$ be encodings of circuits with $m$ wires. Any deterministic algorithm
that reads the encoding by probing wire endpoints needs $\ge m$ probes to decide
Circuit-SAT on $\mathcal C_m$ in the worst case.
\end{theorem}
\begin{proof}
Take $C=\bigwedge$ of $n$ literals as an AND tree ($m=2(n-1)$, satisfiable). For each wire $e$
let $C_e$ replace the source of $e$ by constant $0$ (unsatisfiable). If an algorithm
skips wire $e$ on $C$, the adversary answers consistently with $C_e$; outputs coincide yet
answers differ. So all $m$ wires are read.
\end{proof}
\begin{remark}
This is linear in the input size, the trivial barrier. It is a \emph{parametrized} bound
$\Omega(w)$ but says nothing about $2^{\Omega(n)}$ time. Circuit-SAT has no known
unconditional bound beyond reading the input; conditional bounds (SETH:
no $2^{(1-\varepsilon)n}\mathrm{poly}$) are KNOWN-conditional and not proofs.
\end{remark}
