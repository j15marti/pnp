\section{Model and measures}
A circuit $C$ has $n$ inputs, $g$ fan-in-2 AND gates, free inverters on wires (AIG), one output. Measures:
size $g$; wires $m=2g+1$; \emph{cutwidth} $w(C)$ = min over linear orders of the gates of the max number of wires crossing a cut.
Circuit-SAT: given $C$, is there $x$ with $C(x)=1$? A lower bound is sought as a function $T(n,m,w)$ (parametrized).

\section{Proved lower bounds on the circuit side}
\begin{theorem}[dependence/connectivity, PROVED]\label{t:dep}
If $C$ depends on all $n$ inputs then $g\ge n-1$ and $m\ge 2n-1$.
\end{theorem}
\emph{Proof.} The ancestors of the output form a connected graph on $n+g$ nodes (every input is relevant, hence an ancestor), with $2g$ edges. Connectivity needs $\ge n+g-1$ edges, so $2g\ge n+g-1$. \qed

\begin{proposition}[reading bound, PROVED]\label{p:read}
Any algorithm (random-access model, circuit given as a list of gate descriptions) solving Circuit-SAT needs $\Omega(g)$ time.
\end{proposition}
\emph{Proof.} Let $C_0$ be the AND of $x_1,\dots,x_n$ and $g-n$ pad gates $x_1\wedge x_1$, all chained into the output by ANDs; it is satisfiable. For any pad gate, the instance $C_0'$ with that gate's input replaced by constant 0 is unsatisfiable. An algorithm that never reads that gate's description answers identically on $C_0,C_0'$, so it must read all $\Omega(g)$ pad gates. \qed

\begin{proposition}[evaluation-only bound, PROVED]\label{p:oracle}
An algorithm that accesses $C$ only through evaluation queries $x\mapsto C(x)$ needs $2^n-1$ queries in the worst case, even when $C$ is a point-function circuit with $m=2n-1$.
\end{proposition}
\emph{Proof.} Adversary answers 0 until one point remains. \qed

\emph{Reading.} Prop.~\ref{p:oracle} is the trivial relativizing bound and uses no wire structure; any real lower bound must read the wires. That is the point of tracking the wire structure.

\section{Parametrized view: the wire cut is the right parameter}
\begin{proposition}[upper bound, KNOWN/standard]\label{p:dp}
Circuit-SAT is solvable in time $O(2^{w}\cdot m)$ given an order witnessing cutwidth $w$: sweep gates in order, keep the set of consistent assignments to the wires crossing the cut.
\end{proposition}
Hence $T(n,m,w)\le \mathrm{poly}\cdot 2^{\min(n,w)}$. The AND-chain point-function family has $w=2$, so it is easy; a lower bound must come from families where the wire cut grows.
\begin{conjecture}[CONDITIONAL on SETH]
No algorithm solves Circuit-SAT in $(2-\varepsilon)^{w}\mathrm{poly}(m)$. (Analogue of the known SETH bound for CNF-SAT by pathwidth, Lokshtanov--Marx--Saurabh 2011; pathwidth $\le$ cutwidth. Transfer to circuits stated as CANDIDATE, not re-derived here.)
\end{conjecture}
