\section{Goal and method}
Goal: lower bounds for the NP-complete problem Circuit-SAT. Method: start from the
smallest instances, grow the number of inputs $n$ and gates $s$ step by step, and at each
step record the minimum number of wires (connections) any circuit \emph{deciding} the
instance must contain, then look for a pattern that survives to a general bound.

\subsection*{The ladder problem $\CSAT_{n,s}$}
An instance encodes a circuit with $n$ inputs and $s$ AND-gates with optional negation on
each input wire: gate $j\in\{0,\dots,s-1\}$ picks two earlier nodes (indices in $[0,n+j)$,
$\lceil\log_2(n+j)\rceil$ bits each) and a negation bit per wire; the output is the last gate.
Out-of-range codes are rejected. $\CSAT_{n,s}(\text{code})=1$ iff some $x\in\{0,1\}^n$ makes
the encoded circuit output $1$. The code length is
\[
N(n,s)=2\sum_{j=0}^{s-1}\bigl(\lceil\log_2(n+j)\rceil+1\bigr).
\]
This is a faithful finite slice of Circuit-SAT (AND with negations is a complete basis).

\section{Exact lemmas}
\begin{lemma}[Connectivity / wire bound; PROVED/EXACT]\label{lem:wire}
If $f$ depends essentially on $N$ variables, every fan-in-2 circuit computing $f$ has at
least $N-1$ gates and at least $2N-2$ wires among gates and inputs, and each essential
input has fan-out $\ge 1$.
\end{lemma}
\emph{Proof.} The output gate must reach each essential input; the sub-DAG reaching them is
connected with $N$ leaves and fan-in $\le 2$, so it has $\ge N-1$ internal gates, each
receiving exactly $2$ wires (or fewer only if a gate is degenerate, which removes essentiality).
Counting in-edges gives $\ge 2(N-1)$ wires. \qed

\section{Honest assessment}
\begin{itemize}
\item The ladder bound is \emph{linear in the input length} $N$. This is the trivial
``must read the input'' bound; it is exactly the order the repository already records as
the query ceiling (INPUT-QUERY-CEILING86 in root \path{main.tex}: pure query amplification
beyond input order is retired). Classification: EXACT OBJECT, no new strength.
\item Known frontier (KNOWN THEOREM, quoted from memory, not re-verified this run): the best
explicit general-circuit lower bounds over the full binary basis are $\approx 3.1N-o(N)$
(Li--Yang, STOC 2022), still linear. Superlinear circuit lower bounds for any explicit
function are open; Circuit-SAT $\notin$ P/poly-size would imply P$\ne$NP-type separations
only after superpolynomial bounds, far beyond this ladder.
\item Barriers any real step must clear: relativization, natural proofs, algebrization.
This ladder is a counting argument on essential variables, so it is natural-proof-neutral
but cannot exceed linear.
\end{itemize}
