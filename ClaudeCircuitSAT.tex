\section{Program}
Start from the smallest circuit families, count exactly the wires (edges) any circuit computing a target function needs as the number of inputs $n$ grows, and ask which wire-count statements can be turned into a lower bound on solving Circuit-SAT, possibly parameterized (by $n$, wire count $m$, depth, treewidth, fan-out).

\section{Model}
A circuit is a DAG of fan-in-2 AND gates with free edge negation (AIG). $g(f)$ is the minimum gate count of $f$; the wire count is $w(f)=2g(f)$ plus output wire (internal wires only: $2g$). Circuit-SAT: given $C$ with $n$ inputs and $m$ wires, decide $\exists x\,C(x)=1$.

\section{Two different quantities (important separation)}
\begin{enumerate}
\item \emph{Construction cost} $g(f)$: a circuit-size lower bound for a function. Unconditional only for restricted families; for explicit functions in general models only linear ($\approx 3.1n$ gates, Li--Yang 2022, KNOWN THEOREM).
\item \emph{Solving cost} of Circuit-SAT on an instance: no unconditional super-linear bound in the general RAM/TM model is known (this is essentially P vs NP). Best-known conditional: SETH gives no $(2-\epsilon)^n\mathrm{poly}(m)$ algorithm (CONDITIONAL).
\end{enumerate}
A large $g(f)$ forces large \emph{instances}; it forces nothing on the time to \emph{decide} them. Any step of the ladder must therefore be tagged with which quantity it bounds.

\section{Ladder, step by step}
\paragraph{Step 0 (PROVED/EXACT).} If the output depends on all $n$ inputs, then $g\ge n-1$ and every input has a wire, so internal wires $\ge 2(n-1)$ for the AND chain; $g(\mathrm{AND}_n)=n-1$.

\paragraph{Step 1 (COMPUTATIONAL, exact).} Exhaustive search (\texttt{research/agents/claude/circuitsat/aig\_min.py}, results in \texttt{aig\_min\_results.json}) gives minimum AIG size over \emph{all} functions:

1&4&0&0&0&0\\ 2&16&3&1&3&6\\ 3&256&6&2&6&12\\\bottomrule\end{tabular}\end{center}
Gate histogram for $n=3$ (gates:count): 0:8, 1:24, 2:64, 3:30, 4:104, 5:8, 6:18. Matches the known $g(\mathrm{XOR}_n)=3(n-1)$ in this basis for $n\le3$ (Schnorr-type bound is KNOWN THEOREM for general $n$).

\paragraph{Step 2 (PROVED/EXACT, trivial parameterized bound).} Sensitivity argument: for the family of AND chains with one wire's negation flipped, satisfiability changes, so any correct algorithm must read every wire: time $\Omega(m)$. This bounds input-reading only; it is the base of the parameter ladder $T(n,m)\ge m$.

\paragraph{Step 3 (KNOWN THEOREM, black-box).} With only oracle access to $C$, finding a unique satisfying input needs $\Omega(2^n)$ queries (Bennett--Bernstein--Brassard--Vazirani for quantum; $2^n$ classical). Not a white-box bound; relativization applies, so it cannot decide P vs NP.

\section{Parameterized targets (CANDIDATE)}
