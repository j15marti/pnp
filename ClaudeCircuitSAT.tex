\section{Model and the parameters we track}
A circuit $C$ over the full binary basis $B_2$ (negation free) has $n$ inputs, $g$ fan-in-2 gates, hence $w=2g$ gate-input wires (plus one output wire). $\CSAT$: given $C$, decide $\exists x\,C(x)=1$. Tracked parameters: $n$ (inputs), $g$ (gates), $w$ (wires), $\mathrm{fo}$ (max fan-out), $\mathrm{tw}$ (treewidth of the underlying graph), $k$ (number of satisfying assignments).
Two lower-bound questions are kept separate throughout:
\begin{enumerate}
\item[(B)] \emph{Building}: $\mathrm{cost}(f)=$ minimum $g$ (equivalently $w$) of a circuit computing $f$.
\item[(S)] \emph{Solving}: time of an algorithm deciding $\CSAT$ on instances with parameters $(n,g,\dots)$. The target is a bound $T(n,g,\mathrm{tw},\dots)$.
\end{enumerate}

\section{Rung 0--1: trivial bounds (PROVED/EXACT)}
\begin{proposition}[connectivity]\label{p:conn}
If $C$ has $n$ inputs all relevant to the output then $g\ge n-1$ and $w\ge 2(n-1)$. The bound is tight for $\mathrm{AND}_n,\mathrm{OR}_n,\oplus_n$ (a binary tree).
\end{proposition}
\emph{Proof.} The graph of relevant nodes is weakly connected with $n+g$ vertices and every gate has two in-wires, so edges $=2g\ge n+g-1$, giving $g\ge n-1$. A balanced tree attains it. \qed

\begin{proposition}[reading bound for (S)]\label{p:read}
Any correct deterministic $\CSAT$ algorithm in a model where $C$ is given as an explicit string must, on worst-case instances, inspect every gate of a minimal-size instance family on which flipping one gate's opcode changes the answer; hence $T=\Omega(g)$. The family $C_i=\mathrm{AND}$ tree whose $i$-th gate opcode is $\wedge$ vs.\ a constant-0 opcode changes $\mathsf{SAT}$ status, so each gate must be read.
\end{proposition}
This is the trivial linear bound and sets the baseline $T\ge\Omega(g)$.

\begin{proposition}[black-box bound]\label{p:bb}
If $C$ is accessible only as an oracle $x\mapsto C(x)$ then every (even randomized, zero-error-on-UNSAT) algorithm needs $2^n$ queries in the worst case (one-sided: $\Omega(2^n)$ for success prob.\ $\ge 2/3$). \emph{Proof:} adversary hides a unique accepting $x^*$ chosen uniformly. \qed
\end{proposition}
This is why any decision-time lower bound better than $\Omega(g)$ \emph{must use the explicit structure} of $C$; relativization (Baker--Gill--Solovay) shows this cannot be done by query arguments alone.

\section{Rung 3: from building cost to a parameterized solving bound}
\paragraph{Known unconditional circuit-size bounds (KNOWN THEOREM).} Explicit functions need $3.1n-o(n)$ gates over $B_2$ (Li--Yang, STOC 2022) and $5n-o(n)$ over $U_2$ (Iwama--Lachish--Morizumi--Raz). No explicit function in NP is known to need $\omega(n)$ gates; this is a barrier for (B) itself. \textbf{Citations to be re-verified against primary sources next run.}
\paragraph{Parameterized solving bounds (CONDITIONAL).} CNF-SAT with $n$ variables solvable in $2^{n}\mathrm{poly}$ trivially; SETH asserts no $(2-\varepsilon)^n$ for all $\varepsilon>0$. For $\CSAT$ with treewidth $\mathrm{tw}$ the dynamic program gives $2^{O(\mathrm{tw})}g$, and SETH implies $(2-\varepsilon)^{\mathrm{tw}}\mathrm{poly}$ is impossible (Lokshtanov--Marx--Saurabh type result for Independent Set/SAT-like problems; the circuit version is CANDIDATE pending exact citation).
\paragraph{Proposed ladder statement (CANDIDATE).} $T_{\CSAT}(n,g,\mathrm{tw})\ \ge\ \Omega(g)+2^{\Omega(\min(n,\mathrm{tw}))}$ \emph{conditionally on SETH}; the unconditional part is only $\Omega(g)$ (Prop.~\ref{p:read}). The goal of this document is to narrow the gap by identifying structural classes where the unconditional bound can be raised, e.g.\ restricted models (monotone, read-once, bounded-width branching programs, resolution/DPLL refutation size, where $2^{\Omega(n)}$ lower bounds are known).
