\section{Goal and conventions}
Goal: a (possibly parametrized) lower bound for an NP-complete Circuit-SAT problem, built by a ladder:
start from the simplest circuit, add inputs one at a time, and track the minimum number of wires needed.

\paragraph{Wire model.} A circuit is a DAG over inputs $x_1..x_n$ with fan-in-2 gates from a basis
$\Omega$ ($B_2$ unless stated; negation free). $g(C)$ = gates, $W(C)=2g(C)$ = wires between nodes
(output edge not counted), fan-out $\phi(v)$ = out-degree. For $f$: $g(f)=\min_C g(C)$, $W(f)=2g(f)$.
Two measures are tracked separately, never conflated:
\begin{enumerate}
\item \textbf{Construction cost} $W(f_n)$: wires needed to build the circuit for the $n$-input function.
\item \textbf{Solving cost}: resources (probes or time) needed to decide SAT of a circuit \emph{given as input}
(wire list). Parameters: $n$ (inputs), $w$ (wires), $\phi$ (max fan-out), tw (treewidth of circuit graph).
\end{enumerate}

\section{Rung 0--3: exact construction cost (\PROVED/\COMP)}
\begin{lemma}[connectivity floor, \PROVED]\label{lem:conn}
If $f$ depends on all $n\ge1$ inputs, any fan-in-2 circuit has $g\ge n-1$, hence $W\ge 2(n-1)$; tight for
$\mathrm{AND}_n,\mathrm{OR}_n,\mathrm{XOR}_n$.
\end{lemma}
\begin{proof} Restrict to the cone of the output: $g$ gates, $2g$ edges. Each of the $n$ inputs has out-degree $\ge1$
and each gate except the output has out-degree $\ge1$, so $2g\ge n+(g-1)$, i.e.\ $g\ge n-1$.
A balanced or chain tree of one gate type attains it. \end{proof}

\section{Rung $\infty$: solving cost in a restricted model}
\paragraph{Probe model.} The instance is a wire list; an algorithm reads one entry (a leaf's label) per probe.
\begin{proposition}[leaf-collision SAT, \PROVED in the probe model]\label{prop:probe}
Let $I_{n,m}$ be AND-chains with $n$ leaves, leaf $i$ labelled by a literal $x_{v_i}^{s_i}$, $v_i\in[m]$, $m\ge 2n$,
$s_i\in\{\pm\}$. The instance is UNSAT iff some variable appears with both signs. Every deterministic
probe algorithm needs exactly $n$ probes (for $n\ge2$).
\end{proposition}
\begin{proof} Upper: read all $n$. Lower: answer all probes with distinct variables (SAT). If leaf $j$ is unread
and another leaf $i$ was read, change leaf $j$ to $x_{v_i}^{-s_i}$: UNSAT, consistent with all answers.
So all leaves must be read. \end{proof}
Parametrized form: with $w=2(n-1)$ wires, probes $=w/2+1$. This is the \emph{acquisition} bound already
catalogued in root \texttt{main.tex} (AGGREGATION-CEILING91, SHARED-INTERFACE-TABLE92): it is linear in
instance size and does not amplify under independent composition. It is the correct floor for reading the
input, not a time lower bound for general algorithms.

\section{Known upper-level facts (\KNOWN)}
\begin{itemize}
\item Best explicit $B_2$ circuit lower bound is $(3.1-o(1))n$ gates for affine dispersers (Li--Yang, STOC 2022,
ECCC TR21-023), by gate elimination, improving Find--Golovnev--Hirsch--Kulikov $(3+1/86)n$.
De Morgan basis: $5n-o(n)$ (Iwama--Morizumi). These bound \emph{construction} cost of explicit functions
and say nothing about SAT \emph{solving} time.
\item Gate elimination natively gives parametrized statements ``$\ge cn$ wires/gates for fan-out/degree class''; this is the
natural parameter space for our ladder: bound as a function of $(n,\phi,\text{basis})$.
\end{itemize}

\section{Barrier audit}
Natural proofs, relativization, algebrization apply to any attempt to jump from rung 4 to rung 5.
Gate elimination is not known to avoid the 5n-type linear ceiling; an exact ladder for increasing $n$ is a data source,
not a proof. A rising $W(f_n)$ for a fixed explicit family would give circuit lower bounds, not SAT time bounds,
unless a bridge theorem (e.g.\ a uniform-algorithm-to-small-circuit compression with advice) is supplied: \CAND\ /\OPEN.
