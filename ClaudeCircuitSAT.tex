\section{Goal and method}
Build Circuit-SAT instances from the simplest case upward; for each step record
(i) the minimum number of gates and wire incidences needed to \emph{construct} the instance
and (ii) the best lower bound on the cost of \emph{solving} it, as a function of the
parameters $n$ (inputs) and $s$ (gates). Lower bounds may be parametrized, $T(n,s)$.
Basis: $B_2$ (all fan-in-2 gates, free negation); size = number of gates; wire count = $2\cdot$gates.

\section{Proved lower bounds}
\begin{theorem}[PROVED/EXACT: connectivity wire bound]
A $B_2$ circuit (DAG, fan-in 2) whose output depends on all $n$ inputs has $g\ge n-1$ gates and
at least $2n-2$ gate-input wires; equality holds for the AND-tree computing $[x=a]$.
\end{theorem}
\begin{proof} Every input reaches the output, so the underlying undirected graph on $n+g$
vertices is connected: $2g\ge (n+g)-1$, i.e.\ $g\ge n-1$. \end{proof}
Hence a unique-satisfying-assignment instance costs $n-1$ gates; computed values 1, 2 match.

\begin{theorem}[PROVED/EXACT, oracle model only: black-box Circuit-SAT]
Any deterministic algorithm that accesses $C:\{0,1\}^n\to\{0,1\}$ only through evaluation queries
and correctly decides satisfiability makes $\ge 2^n-1$ queries.\end{theorem}
\begin{proof} Adversary answers 0 to the first $2^n-1$ distinct queries; the unqueried point may or may not
satisfy. \end{proof}
Classification: model-restricted, relativizes; says nothing about algorithms that read the wiring.
Randomized $\Omega(2^n)$ and quantum $\Theta(2^{n/2})$ (Grover/BBBV) are the known analogues (KNOWN THEOREM).

\section{Parametrized picture}
Trivial upper bound $O(2^n s)$. Oracle lower bound $2^n-1$ queries, so the open gap is the factor $s$
and, more importantly, whether wiring information can beat $2^{n}$. KNOWN THEOREM (restricted):
DPLL/resolution on Tseitin formulas over expanders needs $2^{\Omega(n)}$ (Urquhart; Ben-Sasson--Wigderson),
parametrized by treewidth/width. KNOWN: gate elimination gives $\approx3.1n$ circuit-size bounds for
explicit functions (Find et al.; Li--Yang) --- these bound circuit size, not SAT time.
Unconditional super-polynomial RAM time for Circuit-SAT: \OPEN{} (equivalent to $\mathrm{P}\ne\mathrm{NP}$ territory);
conditional: SETH $\Rightarrow$ no $2^{(1-\epsilon)n}\mathrm{poly}(s)$.
