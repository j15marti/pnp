\section*{Status (honest)}
\textbf{No superpolynomial lower bound for Circuit-SAT is proved here; P versus NP remains OPEN.}
The only unconditional bounds so far are the linear ``read the wires'' bound (Rung~A) and the exact small-case data below.

\section{Model}
A circuit $C$ on $n$ inputs has $g$ fan-in-2 AND/OR gates, free negation on wires, output the last gate; it has $m=2g$ gate-input wires.
Parameters: $(n,g)$; the target is a lower bound $T(n,g)$ on the cost of an exact Circuit-SAT decider, in two models:
(Q) the wire-list query model (cost = wire probes) and (T) Turing/RAM time.

\section{Rung A: wire sensitivity (PROVED, query model)}
For a circuit $C$ let $s(C)$ be the number of wires $w$ such that re-sourcing $w$ to some other signal flips satisfiability.
\begin{prop}[Sensitivity bound]\label{p:sens} Any deterministic exact decider in model (Q) probes at least $s(C)$ wires on input $C$.\end{prop}
\emph{Proof.} If a sensitive wire is unprobed, the adversary answers consistently with $C$ yet the rewired $C'$ has the opposite answer and the same transcript. \qed
\begin{prop}\label{p:chain} For $g\ge1$, $n\ge g+1$, the chain $G_j=G_{j-1}\wedge x_{j+1}$ ($G_0=x_1$) has $s=2g=m$.\end{prop}
\emph{Proof.} $C$ is satisfiable. Re-source any wire to $\neg x_k$ where $x_k$ is a literal feeding the other side of the same conjunction chain; this forces $x_k\wedge\neg x_k$ on every path, so $C'$ is unsatisfiable. (For the wire carrying $x_{j+1}$, use $\neg x_1$.) \qed

Hence $T_Q(n,g)=\Theta(g)$ on the worst case for $n>g$: the linear bound is tight for the query model of \emph{this} family and is the trivial floor for all $(n,g)$. It says nothing about the $2^{n}$-type search cost; query models that expose the wire list cannot see hardness, since reading is the only cost.

\section{Rung B: the real target (OPEN)}
Wire-reading is a floor; hardness must come from \emph{search}. Candidate parameterized shapes, with status:
\begin{itemize}
\item $T(n,g)\ge 2^{\Omega(n)}\cdot\mathrm{poly}(g)$ for all exact deciders: OPEN (would imply P$\neq$NP).
\item CONDITIONAL (SETH): no $2^{(1-\varepsilon)n}\mathrm{poly}(g)$ algorithm for CNF/circuit-SAT -- a hypothesis, not a theorem. KNOWN: the best unconditional bounds for restricted classes are the sensitivity/gate-elimination bounds ($\sim 3n$ for explicit functions, Li--Yang STOC'22 $3.1n-o(n)$); these bound circuit \emph{size of functions}, not SAT-decider time.
\item Parameterized view: for fixed $g=n+k$ (``excess'' $k$), the SAT instance is the question whether the $k$ extra wires (cycle space of the wire graph, dimension $m-n_{\text{gates}}+1$) can be consistently satisfied; track treewidth/cutwidth $w$ of the wire graph: known upper bound $2^{O(w)}\mathrm{poly}(g)$ (KNOWN, dynamic programming), so any hard instance family needs $w=\Omega(n)$-type expansion. A lower bound of the form $T\ge2^{\Omega(w)}$ is OPEN; a candidate sub-ladder is: $w=1$ (trees, linear), $w=2$ (series--parallel), \dots, tracking minimum wires per step.
\end{itemize}
