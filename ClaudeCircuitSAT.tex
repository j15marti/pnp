\section{Goal and method}
Goal: lower bounds for CircuitSAT $=\{C : \exists x\, C(x)=1\}$, possibly parameterized by $(n,m,w)$ = (inputs, gates, wires).
Method (user's idea): build circuits wire by wire from the simplest instance, record the minimum number of gates/wires
$\mathrm{L}(f)$ needed for each function $f$ on $n$ inputs, increase $n$, and see which structural lower bound on the \emph{cost of deciding}
satisfiability follows at each rung. Conventions: B$_2$ basis (all non-degenerate 2-input gates), free literal negation, fan-in 2,
so wires $w=2m$ (plus one output wire).

\section{Rung 0--1: trivial ladder (PROVED/EXACT)}
\begin{lemma}[Connectivity] If $C$ has $n$ essential inputs and fan-in-2 gates, then $m\ge n-1$ and $w\ge 2(n-1)$; the unique-satisfier
function $\mathrm{AND}(\ell_1,\dots,\ell_n)$ meets this with equality (a tree).\end{lemma}
\begin{proof} The gate graph restricted to essential inputs is connected to the output; a fan-in-2 DAG connecting $n$ sources to one sink has $\ge n-1$ gates. \end{proof}

\section{What the ladder gives for deciding SAT}
\begin{theorem}[Read lower bound, PROVED/EXACT]\label{thm:read}
Any correct deterministic algorithm for CircuitSAT in a model with indexed read-only access to the encoding must read $\Omega(m)$ cells on some size-$m$ instances.\end{theorem}
\begin{proof} Let $T_i=(x_i\vee\neg x_i)$ (3 gates) and $C=\bigwedge_{i\le k}T_i$ ($m=\Theta(k)$), satisfiable. Replacing one $T_i$'s OR gate by AND gives an unsatisfiable circuit
differing in one cell. An algorithm that leaves a gate-type cell of every $T_i$ unread cannot distinguish, so it reads one cell per $T_i$: $\ge k=\Omega(m)$. \end{proof}

\begin{theorem}[Black-box evaluation bound, PROVED/EXACT, not a Turing bound]
If $C$ is accessed only by evaluation queries $x\mapsto C(x)$, deciding satisfiability of unique-satisfier circuits $[x=a]$ needs $2^n$ queries (adversary answers 0 until one point remains).
\end{theorem}
Theorem 2 does not transfer to white-box algorithms (the circuit's wires are visible); this is the usual gap, so it is a \emph{model} lower bound only.

\section{Parameterized shape (CANDIDATE)}
Define $T(n,m)$ the optimal time. Known/trivial: $\Omega(m)$ (Thm.~\ref{thm:read}), $O(2^n m)$. Candidate ladder statement:
\[T(n,m)\ \ge\ \Omega\big(m\big)\ \text{unconditionally;}\quad T(n,m)\ge 2^{\Omega(n)}\ \text{for}\ m=\mathrm{poly}(n)\ \text{is P}\neq\text{NP-strength.}\]
Natural intermediate parameter: wires $w$ versus $n$; for $w<2(n-1)$ the circuit cannot depend on all inputs (Lemma 1), so SAT collapses to
a smaller instance in $O(w)$. For $w\ge 2(n-1)$ there are $\ge$ one-satisfier circuits, i.e.\ the hard regime begins at tree-like density.
Known size-lower-bound technology for the \emph{circuit-synthesis} side (gate elimination: $3n-o(n)$ Blum; roughly $3.1n$ Find--Golovnev--Hirsch--Kulikov)
bounds $\mathrm{L}(f)$, not SAT time, and is recalled from memory (KNOWN THEOREM, citation not re-checked this run).
