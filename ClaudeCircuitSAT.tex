\section{Goal and method}
Circuit-SAT: input a fan-in-2 circuit $C$ over $B_2$ with $n$ inputs, $m$ gates, $w=2m$ gate-input wires; decide $\exists x\,C(x)=1$. Plan: start from the simplest circuits, track for each construction step (i) the minimum number of gates/wires needed to build the function and (ii) what any SAT-decider must learn about $C$; then raise $n$, and state bounds in parameters $(n,m,k)$ with $k$ a structural width (treewidth/pathwidth/depth).

\subsection{Connectivity ladder for the simplest SAT family (PROVED)}
\begin{lemma}[AND-chain] Any fan-in-2 circuit whose output depends on all $n$ inputs has at least $n-1$ gates and $2(n-1)$ gate-input wires. Hence $\mathrm{AND}_n$ has $C=n-1$, attained by a chain.\end{lemma}
\emph{Proof.} The underlying graph restricted to the cone of the output is connected and contains the $n$ input nodes; with $g$ gates of in-degree 2 and one source per input, connectivity of $n+g$ nodes needs $\ge n+g-1$ edges only if tree-like, so counting: edges $=2g\ge n+g-1\Rightarrow g\ge n-1$. \qed

Ladder: $n=1$: 0 gates; $n=2$: 1 gate/2 wires; $n=3$: 2 gates/4 wires (matches table: $\mathrm{AND}_3$ in the $g=2$ column); general $2(n-1)$.

\subsection{Reading lower bound for the decider (PROVED)}
\begin{theorem}[Every gate must be read] Fix $n\ge 1$ and the AND-chain $C_n$ with gates $g_1,\dots,g_{n-1}$. Any deterministic algorithm that decides Circuit-SAT on the family $\{C_n\}\cup\{C_n^{(i)}\}$, where $C_n^{(i)}$ replaces gate $g_i$ by constant $0$, must inspect the description of every gate; so time $\Omega(m)$ (and $\Omega(w\log m)$ bits for a standard encoding of wiring).\end{theorem}
\emph{Proof.} $C_n$ is satisfiable, each $C_n^{(i)}$ unsatisfiable, and they differ only in $g_i$. An unread $g_i$ lets an adversary answer incorrectly. \qed

This is the trivial $m$-term of any bound $T(n,m)$; the content must sit in the dependence on $n$.
