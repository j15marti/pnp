\section{Model and parameters}
Input: a circuit $C$ with $n$ input variables, $m$ gates of fan-in $\le 2$ ($w\le 2m$ wires),
given as a list of gates with predecessor pointers, read by random access.
Question: $\exists x\; C(x)=1$. Parameters: $n$, $m$ (or $w$), treewidth $\tau$.
Known upper bounds (KNOWN): $O(2^n m)$ brute force; $O(2^{\tau} m)$ by dynamic programming.

\section{A proved unconditional bound: reading wires}
\begin{prop}[Linear reading bound, PROVED]
Any deterministic algorithm deciding Circuit-SAT in the random-access pointer model on instances with $m$ gates and $n\ge 2$ inputs must read $\Omega(m)$ pointers.
\end{prop}
\begin{proof}
Let $g_1=x_1$, and $g_i=g_{i-1}\wedge \ell_i$ for $i=2..m$, with $\ell_i=x_{\min(i,n)}$ (the ``good'' instance, satisfiable by all-ones). Let $B_j$ be the same circuit with $\ell_j$ replaced by $\bar x_1$; $B_j$ is unsatisfiable since $g_j$ contains $x_1\wedge\bar x_1$. An algorithm that does not read the pointer of $\ell_j$ on the good instance behaves identically on $B_j$ and errs on one. So it reads all $m-1$ literal pointers.
\end{proof}
This is trivial but pins the parametrized baseline: $\Omega(m)\le T(n,m)\le O(2^{\min(n,\tau)}m)$. The whole content of the problem lives in the gap in the exponent of $n$ (SETH-type, CONDITIONAL; not claimed).
