\section{Model}
A circuit $C$ on inputs $x_1..x_n$ is a DAG of $s$ gates over the basis $B_2$ (all binary gates; negation counted as a gate unless stated), fan-in $\le 2$.
A \emph{wire} is an edge (input or gate $\to$ gate). \textsc{CSAT}$(n,s)$: given $C$, decide $\exists x\,C(x)=1$.
Two different lower-bound questions must not be mixed:
(a) \emph{circuit size/wires needed to build a function} (ladder below), (b) \emph{resources needed to decide CSAT}.
Parameters: $n$ (inputs), $s$ (gates), $w=2s$ (wires), later $\mathrm{tw}$, depth.

\section{Ladder, step 2: wire lower bound by connectivity (PROVED)}
\begin{lemma}If $f:\{0,1\}^n\to\{0,1\}$ depends on all $n$ inputs, every fan-in-$\le2$ circuit for $f$ has $g\ge n-1$ gates and at least $n+g-1\ge 2n-2$ wires.\end{lemma}
\begin{proof}Every input has a path to the output, so the undirected graph on the $n$ inputs and the $g$ gates that lie on such paths is connected: $\ge n+g-1$ edges. Each gate has $\le2$ in-wires, so edges $\le 2g$, giving $g\ge n-1$ and hence edges $\ge 2n-2$.\end{proof}
Tight for $\mathrm{AND}_n,\mathrm{OR}_n,\mathrm{XOR}_n$ over $B_2$ ($n-1$ gates, $2n-2$ wires); consistent with the table ($n=3$: 2 gates).

\section{Ladder, step 3: beyond linear---known gate-elimination results (KNOWN THEOREM, re-verify)}
Over $B_2$, explicit functions need $3n-o(n)$ gates (Blum 1984); the best known is about $3.1n-o(n)$ (Li--Yang, STOC 2022; earlier Find--Golovnev--Hirsch--Kulikov $\approx 3.011n$). Over $U_2$ (no XOR) the bound is $5n-o(n)$ (Iwama--Morizumi) and parity needs $3(n-1)$ (Schnorr). Counting gives functions needing $\Omega(2^n/n)$ gates, but no explicit function beyond $\approx 3.1n$ is known. These bound \emph{building} a function; they do not bound \emph{deciding} CSAT.
\textbf{Barrier:} a superlinear bound for an explicit NP function over general $B_2$ circuits is open; gate elimination is not known to exceed linear.

\section{Deciding CSAT: first proved bound (PROVED)}
Model: decider has random access to the encoding (gate $i$ = (op, pointer$_1$, pointer$_2$)); cost = number of fields read.
\begin{theorem}Any deterministic decider for \textsc{CSAT}$(n,s)$ with $n=s$ reads $\ge s$ pointer fields in the worst case.\end{theorem}
\begin{proof}Let $B$ be the AND-chain $g_i=g_{i-1}\wedge x_i$ (SAT, unique model $1^n$), with a constant-0 node available. Let $B_j$ replace the pointer $x_j$ of $g_j$ by the constant-0 node: $B_j$ is UNSAT. $B$ and $B_j$ differ in one field. If the decider on $B$ leaves field $j$ unread it answers identically on $B_j$, wrongly. So it reads all $s$ fields.\end{proof}
This is only the trivial ``read the input'' bound $\Omega(s)$, parameterized by $s$; it holds even with $n$ small relative to $s$ by padding with chain gates. It says nothing about $2^{\Omega(n)}$.

\section{Upper-bound landscape (context, not lower bounds)}
Brute force $O(2^n s)$; branching/CDCL-type exact algorithms $2^{(1-\epsilon_s)n}$ for restricted size ($s\le cn$) classes; dynamic programming over a tree decomposition $2^{O(\mathrm{tw})}\,s$. A parameterized conjecture that fits the project: SETH $\Rightarrow$ no $2^{(1-\epsilon)n}\mathrm{poly}(s)$ algorithm (CONDITIONAL, not a proof of anything unconditional). Candidate parameter pairs for the target bound: $T(n,s)$, $T(n,\mathrm{tw})$, space--time pairs $(T,S)$ as in the repository's FLMV time--space spine.
