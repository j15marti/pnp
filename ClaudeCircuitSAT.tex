\section{Goal and method}
Circuit-SAT: given a Boolean circuit $C$ over basis $B_2$ (fan-in 2) with $n$ inputs and
$m$ gates ($w=2m$ wires), decide $\exists x\,C(x)=1$. We seek lower bounds on the cost of deciding this,
possibly parametrized by $(n,m)$ or by structural parameters (treewidth $t$, fan-out $f$, depth $d$).
Method: a \emph{ladder}. Rung $n$ tracks, wire by wire, the minimum number of wires
$W_n$ of circuits needed for the hardest $n$-input functions, and the cheapest circuits for SAT-flavoured
predicates; then ask which rung-to-rung increments could survive as an algorithmic (not merely circuit-size) bound.

\section{Rung ledger: exact minimum circuit size ($B_2$, all 16 gates)}
Computed by exhaustive iterative-deepening search over gate lists

Wires counted as $2\times$gates (fan-in 2). Search depth $\ge$ the maximum found, so all values are exact.

Named $n=3$ functions: AND, OR, XOR: 2 gates; MUX: 3; MAJ, EXACT-1, EXACT-2: 4 gates (8 wires). \COMP.
Increments: $\max$ gates $0\to1\to4$; the first non-linear jump ($n=3$) is the first function needing
\emph{shared} (fan-out $>1$) intermediate wires: MAJ$_3$ uses fan-out.
Connectivity floor (\PROVED, standard): a function depending on all $n$ inputs needs $\ge n-1$ gates, i.e.\ $\ge 2(n-1)$ wires.
Shannon counting (\KNOWN): almost all $n$-input functions need $\Omega(2^n/n)$ gates.

\section{What can be said about Circuit-SAT itself}
\begin{enumerate}
\item \textbf{Read lower bound} (\PROVED, trivial). Any algorithm deciding Circuit-SAT must read $\Omega(m)$ gates:
take $\bigvee_{i\le m}(x_i\wedge c_i)$ with all constant wires $c_i=0$ (unsatisfiable); flipping any single unread $c_i$ to $1$ makes it satisfiable.
Parametrized form: $\Omega(m)$ reads for every $n\ge1$.
\item \textbf{Circuit-size lower bounds} (\KNOWN, quoted from memory, to be re-verified against sources next run):
gate elimination gives $5n-o(n)$ for explicit functions over $B_2$ and $\approx 3.1n-o(n)$ over $U_2$. These bound
\emph{circuit size of a fixed function}, not SAT-solver time; they do not transfer to Circuit-SAT (\textsc{failed transfer} until a bridge exists).
\item \textbf{Conditional} (\COND): under ETH/SETH, no $2^{o(n)}$ / $(2-\varepsilon)^n\mathrm{poly}(m)$ algorithm;
parametrized by treewidth $t$ of the circuit graph, $2^{O(t)}\mathrm{poly}(m)$ algorithms exist (\KNOWN), so any
unconditional bound must be $2^{\Omega(t)}$-shaped only conditionally.
\item \textbf{General superlinear / superpolynomial bound}: \OPEN.
\end{enumerate}
