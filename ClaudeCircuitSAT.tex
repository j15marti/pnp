\section{Program}
Build circuits from the simplest case upward, add inputs one at a time, and at each step record
(i) the exact minimum number of gates $g(f)$ and wires $w(f)$ needed for the function $f$, and
(ii) what that implies for the cost of deciding satisfiability of a circuit of that size.

\paragraph{Model.} Circuits are DAGs over inputs $x_1..x_n$ with fan-in-2 gates from the full basis $B_2$ (all 16 binary gates; negation is free). Size is gate count $g$; wires $w$ count gate input edges, so $w=2g$ exactly in this model. Fan-out is unrestricted unless stated.

\section{Step ladder}
\begin{lemma}[connectivity, PROVED/EXACT]\label{l:conn}
If $f$ depends on all $n\ge1$ inputs then any $B_2$ circuit for $f$ has $g\ge n-1$ gates and $w\ge 2(n-1)$ wires.
\end{lemma}
\emph{Proof.} The subgraph of gates and inputs reaching the output is a connected DAG with $n$ input nodes and a single sink; each gate has indegree 2, so merging $n$ sources into one needs at least $n-1$ gates. \qed

\begin{lemma}[tight for AND/OR/XOR, PROVED/EXACT]
$g(\mathrm{AND}_n)=g(\mathrm{OR}_n)=g(\mathrm{XOR}_n)=n-1$, so $w=2(n-1)$ for every $n\ge1$.
\end{lemma}
\emph{Proof.} Upper bound: balanced tree. Lower bound: Lemma~\ref{l:conn}. \qed

\section{From function wires to Circuit-SAT cost}
Let $\mathrm{CSAT}$ be: given a circuit $C$ with $n$ inputs and $m$ wires, is $C$ satisfiable?
\begin{itemize}
\item Upper bound: $O(2^n m)$ by enumeration (KNOWN).
\item Lower bounds on $w(f)$ for \emph{explicit} $f$ are \emph{circuit} lower bounds; they do not by themselves lower-bound the \emph{time} of an algorithm deciding CSAT. The gap between ``every circuit computing $f$ is large'' and ``every algorithm deciding satisfiability of circuits is slow'' is the core obstacle. CANDIDATE bridge: none yet.
\item KNOWN THEOREMS (cited from memory; to be verified against primary sources in a later run): gate-elimination gives $3.1n-o(n)$ for explicit functions over $B_2$ (Find--Golovnev--Hirsch--Kulikov, FOCS 2016) and $5n-o(n)$ over $U_2$ (Li--Yang, STOC 2022). Nothing superlinear is known for $B_2$. Natural-proofs, relativization and algebrization barriers apply to any approach via general circuit lower bounds.
\item CONDITIONAL: under SETH-type assumptions CSAT on $m$-wire circuits has no $2^{(1-\epsilon)n}\mathrm{poly}(m)$ algorithm; not a proof of anything unconditional.
\end{itemize}

\section{Current obstacles}
\begin{enumerate}
\item \textbf{Function-to-algorithm gap.} Wire counts of functions are circuit lower bounds; CSAT needs algorithm lower bounds on arbitrary solvers. Missing theorem: a reduction making a fast CSAT solver yield a small circuit for a hard function (as in Williams' algorithmic method, which gives ACC$^0$-type bounds only).
\item \textbf{Linear barrier.} Wire-counting/gate-elimination currently saturates at linear size.
\end{enumerate}
