\section{Program}
Build circuits $C$ over basis $B_2$ (all fan-in-2 gates, free negation) from the simplest case upward, tracking for each $(n,s)$: minimal gates, minimal wires (edges), and the strongest provable lower bound on solving $\mathrm{CSAT}(n,s)$ under a stated model. Parameters: $n$ inputs, $s$ gates, $w$ wires, $k$ = any structural parameter (depth, treewidth, fan-out). A parameterized bound has the form $T(n,s,k)$.

\section{Level 0--1: basic wire counting}
\begin{prop}[PROVED/EXACT] If $f$ depends essentially on $m$ inputs and is computed by a fan-in-2 circuit with $s$ gates, then $s\ge m-1$ and the number of wires is $w\ge 2s\ge 2(m-1)$ (each gate has two in-wires; the circuit graph restricted to the cone of the output is connected, a tree needs $m-1$ internal nodes).\end{prop}
\begin{prop}[PROVED/EXACT, black-box model] An algorithm that only evaluates $C$ as an oracle needs $2^n$ evaluations in the worst case to decide $\mathrm{CSAT}$ for point functions $[x=a]$ (adversary answers 0 until one assignment remains). Cost $2^n$ evaluations; this is \emph{not} a lower bound for algorithms that read $C$.\end{prop}
\begin{prop}[PROVED/EXACT, reading model] Any correct algorithm must read every wire of the output cone that is not redundant: for a unsatisfiable-vs-satisfiable pair differing in one gate, a single unread gate decides the answer. So time $\Omega(s)$ in the indexed-random-access model for the \emph{worst-case family}; this is the trivial linear bound.\end{prop}

\section{Parameterized view}
Known upper bounds (KNOWN THEOREM): $\mathrm{CSAT}$ in $O(2^n s)$ (brute force); in $2^{O(\mathrm{tw})}s$ for treewidth $\mathrm{tw}$ of the circuit graph; $O(s)$ for tree-like (fan-out 1) circuits via bottom-up satisfiability propagation \emph{only} when no input repeats. Hence the hardness must come from \emph{reconvergent fan-out}: define $r$ = number of reconvergent fan-out stems. CANDIDATE conjecture: with $r$ stems, the work of any natural algorithm is $2^{\Omega(r)}$; a lower bound for algorithms in a restricted model (e.g.\ DPLL-style / resolution) is the targeted next step, via known exponential resolution lower bounds (KNOWN THEOREM for tree-like resolution on specific families); transfer to arbitrary algorithms is OPEN.
