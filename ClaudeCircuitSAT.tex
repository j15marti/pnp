\section{Model}
An instance is an AIG: inputs $x_1..x_n$, gates $g_j=\ell\wedge\ell'$ where each of the two input wires carries a free negation, one output literal. $g$ = number of gates, wires $w=2g$ (+1 output). Constants are free. $\mathrm{SAT}(C)$ asks whether some $a\in\{0,1\}^n$ gives $C(a)=1$. Parameters: $n$ (inputs), $g$ (size), $s=|C^{-1}(1)|$ (solution count), later treewidth/pathwidth.

\section{The ladder: minimal wires per step}
Let $G_n(s)$ = least number of AIG gates of a circuit on $n$ inputs with exactly $s$ satisfying assignments.

\begin{theorem}[Needle construction bound, PROVED/EXACT]\label{thm:needle}
$G_n(1)=n-1$ for $n\ge1$; hence a unique-solution instance needs exactly $2(n-1)$ gate-input wires.
\end{theorem}
\begin{proof}
Upper: AND-chain of the literals of the solution $a$, $n-1$ gates. Lower: a function with exactly one solution depends on every variable (flipping an unread variable keeps a solution, giving $s\ge2$). A fan-in-2 circuit whose output depends on $n$ inputs is connected through its cone, a tree-spanning argument: the cone containing $n$ input nodes and $g$ binary gates has at most $g+1$ distinct leaf-sources in the connected underlying graph rooted at the output, so $g\ge n-1$.
\end{proof}

\section{Decision lower bounds: what is provable now}
\begin{proposition}[Needle-in-description adversary, PROVED/EXACT]\label{prop:adv}
Any deterministic algorithm deciding SAT on AND-chains of $n$ literals over $n$ positions, reading the description through probes, must probe all $n$ literal fields; so $\Omega(n)=\Omega(g)$ probes.
\end{proposition}
\begin{proof}
Let $A$ be the chain with distinct variables $x_1,\dots,x_n$ (SAT). If position $j$ is unprobed, let $B_j$ replace the literal at $j$ by $\neg$(literal at position $k\ne j$): UNSAT. $A$ and $B_j$ agree on all probed fields, so the algorithm errs on one.
\end{proof}
This is just input-reading and is \emph{not} evidence of hardness; it is the base rung. The real question, a $2^{\Omega(\cdot)}$ bound in a parameter, is:

\begin{definition}[Parameterized targets]
$T(n,g)$: decision time for circuits with $n$ inputs and $g$ gates. Known upper bounds: $O(2^n g)$ brute force; $O(2^{\mathrm{tw}}g)$ via DP over tree decompositions of the circuit graph (KNOWN THEOREM, standard).
\end{definition}
\begin{itemize}
\item \textbf{CONDITIONAL (to be verified against the literature in a later run):} SETH-style statements that no $(2-\varepsilon)^{n}\mathrm{poly}(g)$ algorithm exists; and that the $2^{\mathrm{tw}}$ DP is optimal up to $(2-\varepsilon)$ (Lokshtanov--Marx--Saurabh-type pathwidth bounds). These are conditional, not unconditional lower bounds.
\item \textbf{OPEN:} any unconditional bound $T(n,g)>\mathrm{poly}$ for general circuits, and in restricted models (monotone, bounded-depth, read-once) which circumvent the needle obstruction.
\end{itemize}
