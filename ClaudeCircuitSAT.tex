\section{Goal and method}
Goal: lower bounds, possibly parametrized, for Circuit-SAT. Method: start from the
smallest instances and build up, tracking for each step the minimum number of
gates/wires a circuit needs, while increasing the number $n$ of inputs.

\textbf{Model.} Circuits over the basis $B_2$ (all binary gates, negation free), fan-in~2,
unbounded fan-out. $\mathrm{gates}(f)$ is the minimum number of gates computing $f$;
\emph{wires} $=2\cdot$gates (each gate has two incoming wires). Parameters: $n$ inputs,
$g$ gates, $\sigma=|f^{-1}(1)|$ number of satisfying assignments. A Circuit-SAT instance
is a circuit $C$; the question is whether $\sigma(C)>0$.

\section{Step 0: connectivity (the first wires)}
\begin{lemma}[PROVED/EXACT]\label{lem:conn}
If a circuit computes a function depending on all $n$ variables then it has
$g\ge n-1$ gates, hence $\ge 2(n-1)$ wires.
\end{lemma}
\begin{proof}
Restrict to the ancestors of the output: $n$ input nodes and at most $g$ gates, all
relevant inputs are ancestors. This graph is (weakly) connected, so it has at least
$n+g-1$ edges; it has exactly $2g$ edges (two per gate). So $2g\ge n+g-1$.
\end{proof}
\begin{proposition}[PROVED/EXACT]
The single-solution function $\mathrm{AND}_n$ (up to input negations) has
$\mathrm{gates}=n-1$, wires $=2(n-1)$; every function with $\sigma=1$ on $n$ variables
depends on all variables, so $\mathrm{gates}=n-1$ for all of them.
\end{proposition}
Hence the cheapest satisfiable-with-unique-witness instances cost exactly $n-1$ gates, and
this is tight but only linear. It is the base row of the ladder below.

\section{Parametrized bounds available now}
\begin{proposition}[PROVED/EXACT, evaluation-oracle model]
Any deterministic algorithm that decides satisfiability of an $n$-input circuit and
may only \emph{evaluate} the circuit on chosen inputs needs $2^n$ evaluations in the
worst case.
\end{proposition}
\begin{proof}
Adversary answers $0$ to every query; after $2^n-1$ queries one unqueried point
remains, where it may place a solution or not.
\end{proof}
\begin{remark}[Failed transfer]
This is a black-box bound. A white-box algorithm reads the wires; the proposition
says nothing about it. The wire-by-wire approach is exactly the attempt to replace
black-box evaluation by structural reading, so the next target is a bound in a model
that charges for reading wires.
\end{remark}
Known upper bound: $O(2^n\cdot g)$ by exhaustive evaluation. Parametrized form of the
open question: is there $c<1$ with time $2^{cn}\,\mathrm{poly}(g)$ for all circuits?
(Strong ETH says no for CNF-SAT; CONDITIONAL, not a theorem.)

\section{Known circuit-size landscape (KNOWN THEOREM, from memory; verify before citing)}
\begin{itemize}
\item Counting (Shannon): some $n$-variable function needs $\Omega(2^n/n)$ gates.
\item Gate elimination: explicit functions need $3n-o(n)$ gates in $B_2$ (Blum 1984);
  improvement to roughly $3.1n$ (Li--Yang 2022). Nothing superlinear is known for
  explicit functions in $B_2$ (and none for NP functions).
\end{itemize}
Gate elimination is the natural engine for a ``wire-by-wire'' count: each input
restriction removes a bounded number of wires. Its linear ceiling is the main obstacle.

\section{Obstacles and plan}
\begin{enumerate}
\item \textbf{Size lower bounds $\ne$ SAT time lower bounds.} A circuit-size bound for an
  explicit function $f$ does not bound the time to decide satisfiability of a given circuit.
  Needed bridge: a model (e.g.\ read-the-wires / bounded-space) where solving forces
  reading a growing fraction of wires depending on $n$.
\item \textbf{Linear barrier of gate elimination} at about $3n$ in $B_2$.
\end{enumerate}
Plan for later runs:
(a) extend exact sizes to $n=4$ (known max 7 gates, to verify) with a smarter search;
(b) tabulate minimal wires for \emph{structured} families (parity, threshold, adders)
  as the parameter $n$ grows and fit the ladder;
(c) define a wire-reading cost model and prove a parametrized bound for it;
(d) mine the repository (ARC/FLMV time--space spine; ledger rows L34--L40 on
  alternation trading and one-tape bounds) for time--space tradeoffs that can be
  expressed in $(n,g)$.
