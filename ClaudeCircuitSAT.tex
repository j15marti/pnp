\section{Program}
Start from the smallest Circuit-SAT instances and grow them one gate and one input at a time. Record (i) the minimum number of gates $s$ and wires $w=2s$ (fan-in 2, basis $B_2$, negation free) needed to build an instance with a given property, and (ii) the cost any algorithm must pay to decide it. Parameters: $n$ (inputs), $s$ (gates), $w$ (wires), $d$ (depth), $t$ (treewidth). A bound may be a function of several of these.

\section{Construction ledger (build side)}
\begin{lemma}[PROVED/EXACT, folklore]\label{lem:conn}
If a fan-in-2 circuit's output depends on all $n$ inputs, then $s\ge n-1$ and $w\ge 2(n-1)$.
\end{lemma}
\emph{Proof.} The underlying graph must connect $n$ input nodes to the output. Each gate adds one node and at most one merge of two components (two in-wires), so $n-1$ gates are needed to join $n$ components. \qed

Matching upper bound: an AND-tree of $n$ literals has exactly $n-1$ gates, $2n-2$ wires, and a unique satisfying assignment.

\section{Solve side: what any algorithm must pay}
\begin{lemma}[PROVED/EXACT, trivial input-reading bound]\label{lem:read}
Any deterministic algorithm deciding Circuit-SAT for AND-trees of $n$ literals (leaf $k$ wired to variable $v_k$ with polarity $b_k$; SAT iff no variable occurs with both polarities) must read at least $n-1$ leaf wires.
\end{lemma}
\emph{Proof.} Adversary: answer every probe with a fresh variable (instance stays SAT). If two or more leaves are unprobed, leaf $k$ unprobed gives an instance consistent with all answers in which $k$ is rewired to the opposite literal of any other leaf, making it UNSAT; the algorithm cannot distinguish. With only one unprobed leaf $k$, rewire it against a probed leaf $j$; this is also consistent. So at least $n-1$ probes are needed to be correct on both. \qed

Hence $\Omega(w)$ in the wire-probe model: a trivial bound that is linear in the instance size. It shows the correct form of the target: a bound in $(n,w)$ must at least reach $\Omega(w)$, and the interesting content is the dependence on $n$ at fixed $w$.

Note: Circuit-SAT is NP-complete, so any unconditional super-polynomial bound in $w$ would prove $\mathrm{P}\ne\mathrm{NP}$. Only restricted-model bounds (probe model, monotone, bounded depth/treewidth) are within reach.
