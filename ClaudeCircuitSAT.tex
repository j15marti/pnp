\section{Goal and method}
Find lower bounds, possibly parameterized, for Circuit-SAT: input a fan-in-2 circuit $C$ with
$n$ inputs and $m$ gates (so $2m$ internal wires), decide whether $\exists x\,C(x)=1$.
Ladder: for $n=1,2,3,\dots$ record (i) the minimum number of gates/wires of a circuit with a
required property, (ii) the resulting bound on solving the instance family, with parameters $(n,m)$.

\section{Proved statements}
\begin{theorem}[L3, connectivity]\label{thm:conn}
If a fan-in-2 circuit computes $f$ depending on all $n$ inputs with a single output, then it
has $\ge n-1$ gates.
\end{theorem}
\begin{proof} Each essential input has a path to the output; the underlying graph restricted to the
cone is connected with $n$ source nodes, and a fan-in-2 gate merges at most two components in a tree
sense, so $n-1$ gates are needed.\end{proof}

\begin{theorem}[L4, query lower bound]\label{thm:q}
Let the instance be a list of $m$ gates (type and two predecessor pointers) read by queries.
Any deterministic algorithm deciding Circuit-SAT makes $\ge m$ queries (parameterized by $m$,
independent of $n\ge 2$).
\end{theorem}
\begin{proof} Take chain $c_1=x_1$, $c_{j+1}=c_j\wedge x_{(j \bmod n)+1}$, output $c_m$; satisfiable
(all ones). Let $D_i$ be the same circuit with gate $i$ replaced by the constant-0 gate
($x_1\wedge\neg x_1$ realised by a type change); $D_i$ is unsatisfiable. An adversary answers every
query as in the chain. If some gate $i$ is unqueried after $<m$ queries, both the chain and $D_i$
are consistent with all answers but have different SAT value.\end{proof}
This is exactly the trivial ``must read the input'' bound; it is a model-limited statement
(black-box queries), not a Turing-machine time bound.

\section{Parameterized view}
The meaningful parameters are $(n,m)$ and possibly treewidth/depth $w$. Candidate shape of a
true bound: $T(n,m)\ge m\cdot g(n)$ with $g$ superpolynomial (ETH-type: $2^{\Omega(n)}$ conditionally,
CONDITIONAL, not proved). Known unconditional circuit-size bounds for explicit functions are
only linear in $n$ (gate elimination, about $3n$--$3.5n$ as tracked in \texttt{GROKPROOF/}); they
bound circuit \emph{size of a function}, not Circuit-SAT \emph{time}, so they do not transfer.
