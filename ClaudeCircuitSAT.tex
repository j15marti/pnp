\section{Model}
A circuit $C$ has $n$ inputs and $g$ fan-in-2 gates (basis $B_2$, all 16 binary ops; negations are free on wires). Wires $=2g$ gate-input edges (plus output). $\mathrm{CSAT}(g,n)$: given $C$ as a gate list, decide $\exists x\,C(x)=1$. Parameters: $g$ (size), $n$ (inputs), later fan-out and depth. Goal: lower bounds $T(g,n)$, possibly parametrized.

\subsection{Connectivity bound (PROVED)}
\begin{lemma}A circuit whose output depends essentially on all $n$ inputs has $g\ge n-1$, hence $\ge 2(n-1)$ wires.\end{lemma}
\begin{proof}The input--gate graph must connect all $n$ inputs to the output; a fan-in-2 DAG with $g$ gates has at most $g+1$ source nodes reaching a single sink.\end{proof}
Tight: AND/XOR trees. Table above agrees ($n=3$: $\ge2$ gates).

\subsection{Probe lower bound for CSAT (PROVED, trivial)}
\begin{theorem}Any deterministic algorithm deciding CSAT on gate-list encodings with $g$ gates must probe $\ge g$ wire entries in the worst case (adaptive probes, random access).\end{theorem}
\begin{proof}Let $C_0$ be the AND-chain over literals $x_1,\dots,x_{g+1}$ ($n=g+1$), satisfiable. Let $C_j$ replace the $j$-th leaf literal ($j\ge2$) by $\lnot x_1$; $C_j$ is unsatisfiable and differs from $C_0$ in one wire entry. Run the algorithm on $C_0$ (answer SAT). If some leaf entry $j\ge2$ is unprobed, the run on $C_j$ is identical, wrongly answering SAT. So all $g$ leaf entries ($j=2..g+1$) are probed.\end{proof}
This is an input-reading bound; it is tight ($O(g)$ reading plus work) only for easy instances and says nothing about the $2^{\Omega(n)}$ regime.
