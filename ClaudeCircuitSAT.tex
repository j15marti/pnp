\subsection{Read-all-wires lower bound (PROVED/EXACT, query model)}
\begin{prop} In the model where the circuit is given by a wire-pointer table (read-only random access), any deterministic Circuit-SAT algorithm on circuits with $m$ wires, $n\ge m/4$ inputs, makes $\Omega(m)$ queries.\end{prop}
\emph{Proof.} Take $k=\lfloor m/4\rfloor$. Instance $I_0$: output $=\bigvee_{j\le k} (x_j\wedge y_j)$ where each $y_j$ is wired to constant $0$. $I_0$ is unsatisfiable. Instance $I_j$ rewires only $y_j$ to constant $1$; $I_j$ is satisfiable ($x_j=1$). An algorithm that never reads the wire of $y_j$ behaves identically on $I_0$ and $I_j$, so a correct algorithm must read all $k$ such wires. $\square$

This is only linear in input size: it says the \emph{parameter} $m$ is necessary, nothing about $2^n$. It also shows the right parametrization is $T(n,m)\ge\Omega(m)$ trivially, with the hard question being $T(n,m)\ge m\cdot 2^{\epsilon n}$ (OPEN; implies P$\ne$NP-type consequences, ETH-flavored).
