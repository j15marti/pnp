\section{Goal and method}
Build from the smallest circuits upward. For each $n$ (number of inputs) track
(i) $C(n)$: the exact minimum number of gates (wires) needed by the worst $n$-input function,
and (ii) the cost any algorithm must pay to decide satisfiability of an instance of size $s$.
Lower bounds may be parametrised by $(n,s,w)$ with $w$ a width parameter (treewidth/pathwidth).

\section{Model}
AIG model: 2-input AND gates, free negation on edges, constants free.
A circuit with $g$ AND gates has $2g$ input wires plus one output edge. Size is $g$; wires $=2g+1$.

\section{Ledger of exact minimum sizes (COMPUTATIONAL, exhaustive)}

a function's minimum is exact since all sets of $\le k$ gates are enumerated. Runs $\le 20$\,s each.

\section{Proved elementary bounds (PROVED/EXACT)}
\begin{lem}[Relevance wires]\label{lem:rel}
A circuit whose output depends on $r$ inputs has at least $r-1$ AND gates and $\ge 2(r-1)+1$ wires.
\end{lem}
\emph{Proof.} Connectedness of the cone of the output: a fan-in-2 DAG whose cone touches $r$ input leaves has $\ge r-1$ internal nodes (a binary tree has $r-1$). \qed

\begin{thm}[Reading lower bound]\label{thm:read}
Any algorithm deciding \CSAT\ on $m$-gate instances in the input-reading model must read $\Omega(m)$ wires, even for a promise class.
\end{thm}
\emph{Proof.} Take $\varphi_0=x_1\wedge\bigwedge_{i=1}^{m'} (\text{slot}_i)$ where each slot is either the tautology $(y_i\vee\neg y_i)$ or fixed. Instance $A$: all slots tautologies (SAT). Instance $B_j$: slot $j$ replaced by $\neg x_1$ (UNSAT). An algorithm that leaves slot $j$ unread outputs the same on $A$ and $B_j$; so it reads all $m'=\Theta(m)$ slots. \qed

\begin{thm}[Black-box evaluation bound]\label{thm:bb}
Any algorithm that accesses $C:\{0,1\}^n\to\{0,1\}$ only through evaluation queries needs $2^n$ queries (deterministic) / $\Omega(2^n)$ (randomised) / $\Omega(2^{n/2})$ (quantum) to decide SAT.
\end{thm}
\emph{Proof.} Standard adversary / BBBV; the adversary answers 0 until one point remains. \qed
\textbf{Status:} PROVED but \emph{not} a \CSAT\ bound: a real algorithm reads the wiring. Gap = the whole problem.
