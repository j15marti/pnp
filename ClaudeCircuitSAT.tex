\section{Goal and method}
Goal: a lower bound for Circuit-SAT (NP-complete). Method: start with the smallest circuits, add inputs one at a time, and ledger (i) the minimum number of gates $g(n)$ and wires $w(n)$ needed to \emph{build} a circuit with $n$ inputs having a given property, and (ii) what any SAT-decider must \emph{read}. Convention: fan-in-2 gates over the full binary basis $B_2$; $w=2g$ counting gate input wires (output wires = fan-out are tracked separately).

\section{Ladder}
\paragraph{Rung 0 ($n=1$).} Circuits are $x$, $\neg x$, $0$, $1$ (up to free negation, $g=0$, $w=0$). SAT decided by reading one description. PROVED/EXACT.

\begin{lemma}[Connectivity rung, PROVED/EXACT]\label{lem:conn}
A fan-in-2 circuit with a single output that depends on all $n$ inputs has $g\ge n-1$ and $w\ge 2(n-1)$; equality holds for AND$_n$, OR$_n$, XOR$_n$ (a tree).
\end{lemma}
\begin{proof} Each input has a path to the output, so the underlying undirected graph on $n$ inputs plus $g$ gates is connected, hence has $\ge n+g-1$ edges; wires $=2g$ (each gate has two in-wires) gives $2g\ge n+g-1$, i.e.\ $g\ge n-1$. \end{proof}

\begin{lemma}[Read-all rung, PROVED/EXACT, deterministic, descriptive model]\label{lem:read}
Let instances be $C=\mathrm{AND}(h_1,\dots,h_m)$ in which each $h_i$ is a literal or constant $0$, encoded as a list of $m$ cells. A deterministic algorithm deciding SAT must read all $m$ cells.
\end{lemma}
\begin{proof} On the all-literal (consistent) instance, if a cell is unread, set it to $0$: the answer flips from SAT to UNSAT, indistinguishable. \end{proof}
This matches the repository's fixed-width $\Omega(N/\log N)$ acquisition bound (root \texttt{main.tex}): a linear-in-wires rung, \emph{not} a time lower bound against arbitrary algorithms.

\begin{lemma}[Counting rung, KNOWN THEOREM (Shannon)]
Almost all $n$-input Boolean functions need $\Omega(2^n/n)$ gates. Non-constructive; gives no lower bound for a specific NP function.
\end{lemma}

\section{Why the ladder does not simply continue}
\begin{itemize}
\item \textbf{Wire count is a construction cost, not a solver cost.} Lemma~\ref{lem:conn} lower-bounds the circuit \emph{being built}; a SAT solver's cost is a different quantity. Linking them needs a theorem that every solver must ``use'' each wire in a way that compounds; none known (CANDIDATE only).
\item \textbf{Barriers.} Relativization (Baker--Gill--Solovay), natural proofs (Razborov--Rudich), algebrization (Aaronson--Wigderson) rule out the generic ways to extend counting arguments; any new rung must be checked against all three.
\item \textbf{Gate elimination plateau.} Removing $O(1)$ gates per restricted variable yields only linear bounds; the repo's AGGREGATION-CEILING91 and DENSE-COUPLING-FIREWALL90 results are the same phenomenon for the acquisition model (linear-type ceilings).
\end{itemize}
