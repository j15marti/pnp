\section{Program}
Build from the smallest Circuit-SAT instances upward: for each input count $n$ and each target function $f$,
record $C(f)$ (minimum gates over the basis $B_2$) and $W(f)=$ minimum number of wires (gate input connections),
then track the growth in $n$ and look for a parameter $k$ (inputs, treewidth, fan-out, depth) in which a lower bound can be stated.
Circuit-SAT$(C)$: given a circuit $C$ with $n$ inputs and $m$ gates, is there $x$ with $C(x)=1$?

\section{Proved basics}
\begin{lemma}[PROVED/EXACT, connectivity] If a $B_2$ circuit with one output depends on $n$ inputs then it has at least $n-1$ gates and at least $2(n-1)$ wires (counting wires into gates).\end{lemma}
\emph{Proof.} Contract the DAG: each gate has two in-wires. A gate-connected graph on $n$ inputs plus $g$ gates reaching one output needs $g+n-1\le$ wires/2... concretely, the underlying undirected graph on $n+g$ nodes is connected, so it has $\ge n+g-1$ edges; every edge is a wire and wires $=2g$, so $2g\ge n+g-1$, i.e.\ $g\ge n-1$. \qed

\begin{lemma}[PROVED/EXACT, trivial algorithmic bound] Any algorithm deciding Circuit-SAT must read every gate that can influence the output; in the worst case $\Omega(m)$ time. Brute force gives $O(2^n m)$.\end{lemma}

\section{Known landscape (KNOWN THEOREM, cited from memory, to be re-verified)}
Best explicit gate-elimination bounds for $B_2$ circuits are linear ($\approx 3.1n$, Li--Yang 2022); for $U_2$ basis $\approx 5n$ (Iwama et al.). No super-linear explicit bound is known for general circuits. Shannon counting gives $2^n/n$ for most functions. Williams-type results give SAT time--space tradeoffs (see the repository's ARC/FLMV spine and world ledger row L13).

\section{Parametrized targets (CANDIDATE)}
\begin{enumerate}
\item Parameter $k=n$: lower bound for circuits solving ``SAT of a width-$k$ CNF on $n$ variables'' is the open core.
\item Parameter fan-out $f$: study $W$ as a function of fan-out cap; wire count versus gate count separates only when fan-out is bounded (to be computed for $n=4$).
\item Parameter treewidth $t$: Circuit-SAT is $2^{O(t)}\mathrm{poly}$; a matching SETH-type lower bound $2^{(1-\epsilon)t}$ is CONDITIONAL, not unconditional.
\end{enumerate}
