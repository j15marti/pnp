\section{Two different quantities (do not conflate)}
\begin{enumerate}
\item $\mathrm{CS}(f)$: minimum number of fan-in-2 gates/wires of a circuit \emph{building} a function $f$ (circuit complexity; basis $B_2$ unless stated).
\item $T_{\mathrm{SAT}}(n,s)$: time/queries of an \emph{algorithm} deciding satisfiability of an arbitrary given circuit with $n$ inputs and $s$ gates.
\end{enumerate}
The user's ladder (build the circuit wire by wire, track minimum connections) addresses (1); a lower bound for (2) needs an additional bridge. Known: (1) lower bounds for explicit functions are only linear ($\approx 3.1n$ in $B_2$; KNOWN THEOREM, Li--Yang, STOC 2022, to be re-verified against source); a superlinear bound would already be a breakthrough. (2) superpolynomial is equivalent to $\mathrm{P}\neq\mathrm{NP}$ for Circuit-SAT: \OPEN.

\section{Model}
Circuit: DAG, $n$ input nodes, $g$ gates each with exactly two in-wires, one designated output. Wires $w=2g$ (excluding output pointer). Constants and projections cost nothing; negation is absorbed into the $B_2$ gate.

\section{Proved general rungs}
\begin{lem}[Connectivity, PROVED/EXACT]\label{lem:conn}
If $f$ depends on all $n$ inputs then any circuit for $f$ has $g\ge n-1$ gates and $w\ge 2(n-1)$ wires.
\end{lem}
\emph{Proof.} Every input must reach the output, so the underlying undirected graph on $n+g$ nodes restricted to ancestors of the output is connected, hence has $\ge n+g-1$ edges. It has exactly $2g$ edges, so $2g\ge n+g-1$. $\square$

\begin{prop}[Tight for AND/OR, PROVED/EXACT]
$\mathrm{CS}(\bigwedge_{i\le n}x_i)=n-1$ (a binary tree). Hence the unique-satisfying-assignment circuit with $n$ literals needs exactly $n-1$ gates and $2(n-1)$ wires. Lemma~\ref{lem:conn} gives the lower bound.
\end{prop}

\begin{prop}[Read-all adversary for solving, PROVED/EXACT in the query model]
Any algorithm that decides Circuit-SAT with $s$ gates, with query access to the gate descriptions, must in the worst case read $\Omega(s)$ of them (for circuits where every gate is in the cone of the output).
\end{prop}
\emph{Sketch.} Given an unread gate $v$ in a tree-shaped AND instance (satisfiable), replace its type with a constant-0 gate: satisfiability flips, and the algorithm cannot distinguish without reading $v$. This is only a linear bound and is not a barrier-breaking result.

\section{Barriers (audit)}
Linear circuit lower bounds (gate elimination) are not known to relativize-fail but stall near $3n$; superlinear explicit bounds would need new techniques; natural-proofs, relativization and algebrization barriers apply to any proposed route to $\mathrm{NP}\not\subseteq\mathrm{P/poly}$. Unconditional super-polynomial Circuit-SAT time bound: \OPEN.
