\section{Model and parameters}
\begin{definition}
A circuit $C$ has $n$ inputs, $g$ gates of fan-in $2$ over the basis $B_2$ (all binary gates; negations free), one output. \emph{Wires} $w=2g$ (gate in-edges). \SAT$(n,g)$: given such $C$, is there $x$ with $C(x)=1$?
\end{definition}
Parameters: $n$ (inputs), $g$ (gates/wires), and possibly treewidth/depth. A bound is \emph{parametrized} if stated as $T(n,g)$.
Two distinct questions are tracked and must not be conflated:
(A) \emph{construction cost}: the least $g$ needed to build a given function on $n$ inputs ($C_{B_2}(f)$); (B) \emph{solving cost}: time to decide \SAT$(n,g)$.

\section{Step ledger: minimal construction cost, small $n$}
\begin{lemma}[Connectivity, PROVED/EXACT]\label{lem:conn}
If $f$ depends on all $n$ inputs then any $B_2$ circuit for $f$ has $g\ge n-1$ gates, hence $w\ge 2(n-1)$.
\end{lemma}
\begin{proof}
The cone of the output is a connected (undirected) graph on $n+g'$ vertices ($g'\le g$ gates) with at most $2g'$ edges, so $2g'\ge n+g'-1$.
\end{proof}
Consequently $\mathrm{AND}_n$ and $\mathrm{PAR}_n$ have cost exactly $n-1$ (tree upper bound).

Exact minimum gate counts over all $2^{2^n}$ functions (script \texttt{research/agents/claude/circuitsat/mincircuit.py}, output \texttt{mincircuit\_results.txt}):

$\mathrm{AND}_3,\mathrm{PAR}_3$ cost $2=n-1$, meeting Lemma~\ref{lem:conn}. The $n=3$ maximum $4$ agrees with the known value for 3-variable functions; for $n=4$ the literature value is $7$ (KNOWN, quoted not recomputed). \end{proposition}

\section{Solving-cost lower bounds, parametrized}
\begin{lemma}[Input must be read, PROVED/EXACT]\label{lem:read}
Every correct deterministic \SAT{} algorithm reads $\Omega(g)$ bits of the circuit.
\end{lemma}
\begin{proof}
Let $o=\bigvee_{i=1}^m h_i$ with each $h_i=x\wedge\neg x$ (one gate): unsatisfiable, $g=2m-1$. Changing the gate type of any single $h_j$ to $x\wedge x$ gives a satisfiable circuit. An algorithm that never reads $h_j$'s description answers identically on both.
\end{proof}
\begin{lemma}[Black-box, PROVED/EXACT but relativizing]\label{lem:bb}
With only evaluation access $x\mapsto C(x)$, any deterministic algorithm needs $2^n$ queries (adversary answers $0$ until one point remains). \emph{Barrier:} relativizes, so says nothing about P vs NP; it shows the target must use the circuit's wire structure.
\end{lemma}
\begin{proposition}[CONDITIONAL / KNOWN reductions]
CNF-SAT with $n$ variables and $m$ clauses reduces to \SAT$(n,O(m))$. Hence SETH implies no $2^{(1-\epsilon)n}\mathrm{poly}(g)$ algorithm for \SAT. Parametrized by (primal) treewidth $k$, \SAT{} is solvable in $2^{O(k)}g$ and a $(2-\epsilon)^k$-type bound is SETH-tight in the literature (citation to be verified next run).
\end{proposition}
So the working parametrized target is $T(n,g)\ge 2^{(1-\epsilon)n}$ for $g=\mathrm{poly}(n)$ (CONDITIONAL on SETH only; unconditional version OPEN).

\section{Link to the wire ledger (the proof idea)}
The step-by-step idea: lower-bound the \emph{circuit size} $C_{B_2}(\mathrm{SAT}_N)$ of the decision function on $N$-bit encodings by building up from small $N$ and tracking forced wires. A superpolynomial bound would give $\mathrm{NP}\not\subseteq \mathrm{P/poly}$, hence $\mathrm{P}\ne\mathrm{NP}$ (KNOWN implication). Current state of the art for explicit functions in $B_2$ is $3.1N-o(N)$ (gate elimination; citation to verify), so the gap to superpolynomial is the whole problem (OPEN). Lemma~\ref{lem:conn} is the base case of gate elimination: each input must contribute a wire.
