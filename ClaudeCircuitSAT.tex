\section{Setup and parameters}
A circuit $C$ has $n$ inputs, $g$ fan-in-2 gates, $m=2g+1$ wires (two input wires per gate, one output wire).
Circuit-SAT: given $C$, decide $\exists x\; C(x)=1$.
Parameters: $n$ (inputs), $m$ (wires), and possibly treewidth/depth/cutwidth $k$.
Target shape of a bound: $T(n,m,k)$, e.g.\ $\Omega(m)$, $2^{\Omega(n)}\mathrm{poly}(m)$, $2^{\Omega(k)}m$.

\section{PROVED/EXACT: wire-query lower bound for Circuit-SAT}
Model: $C$ is given by an oracle \texttt{src}$(g,i)$ returning the source of input $i$ of gate $g$; an algorithm may also compute freely.
\begin{theorem}\label{thm:wires}
Every deterministic algorithm deciding Circuit-SAT on circuits with $n$ inputs and $m$ wires must make $\ge \lfloor m/3\rfloor-O(1)$ wire queries in the worst case, even promised $m\le 5n$ and bounded depth $O(\log n)$.
\end{theorem}
\begin{proof}
Family $D_n$: gadgets $G_i=x_i\wedge\neg x_i$ for $i\le n$ (3 wires each: $x_i\!\to\!\wedge$, $x_i\!\to\!\neg$, $\neg\!\to\!\wedge$), outputs combined by a balanced OR tree, so $D_n$ is UNSAT.
For each gadget, redirecting the wire $x_i\to\neg$ to $x_j$ ($j\ne i$) yields $x_i\wedge\neg x_j$, so the circuit becomes satisfiable.
Adversary answers all queries by $D_n$. If some gadget's wire $x_i\to\neg$ is unqueried, the same transcript is consistent with the modified satisfiable circuit, so the algorithm errs on one of them.
Hence all $n$ such wires are queried; $m=3n+2(n-1)=5n-2$ counting the OR tree. The other two wires of each gadget are critical by the same argument (rewiring $x_i\to\wedge$ to $x_j$ gives $x_j\wedge\neg x_i$, satisfiable), so $2n\ge \lfloor 2m/5\rfloor$ queries are needed, which implies the stated bound.
\end{proof}
\textit{Honest scope:} this is only the ``must read the input'' bound $\Omega(m)$; it is a query bound, not a time lower bound beyond linear.

Useful: ledger rows L13, L34--L37 (TPORT barrier: alternation trading cannot beat linear time for a UWI-size portfolio; provable exponent $1+\Theta(1-d)$ for sublinear portfolios) show that time--space methods are the only unconditional route giving superlinear Circuit-SAT/SAT bounds, and are capped near $1.8$. A statement equivalent to P$=$NP is a reformulation, not progress.
Gate elimination bounds circuit \emph{size} of explicit functions; it does not by itself bound SAT \emph{time}.
Transfer classification: gate elimination $\to$ SAT time = ANALOGY needing a bridge (a fast SAT algorithm would have to yield small circuits, which holds only non-uniformly via $\mathrm{P/poly}$ and is circular).
