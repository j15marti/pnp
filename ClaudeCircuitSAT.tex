\section{Goal and method}
Build up from the smallest circuits: for $n=1,2,3,\dots$ inputs track (i) the minimal number of gates $C(f)$ and wires $E(f)=2C(f)$ (fan-in~2, full binary basis $B_2$, negation free) needed to realize $f$, and (ii) the cost of deciding satisfiability of a circuit of $s$ gates on $n$ inputs. The lower bound is \emph{parameterized} by $(n,s)$.

\subsection{Wire lower bound for any $n$-dependent function}
\begin{lemma}[PROVED/EXACT]\label{lem:conn}
If a fan-in-2 circuit's output depends on all $n$ inputs then it has $\ge n-1$ gates and $\ge 2(n-1)$ in-wires.
\end{lemma}
\begin{proof} The cone of the output must contain all $n$ inputs. Contracting, each gate merges at most two connected components of the cone's underlying forest-of-sources; starting from $n$ components one needs $\ge n-1$ merges. Each gate has $2$ in-wires. \end{proof}
Tight for $\mathrm{AND}_n,\mathrm{XOR}_n$ (rungs above). Incremental view: adding input $x_{n+1}$ that $f$ truly depends on costs $\ge 2$ wires, with equality for AND/XOR.

\subsection{Reading lower bound for \SAT (adaptive gate-description oracle)}
Model: the decider is given $n,s$ and may query the type/in-wires of any gate; count queries.
\begin{proposition}[PROVED/EXACT]\label{prop:read}
Any (even randomized-with-error-$<1/2$ on worst-case) decider for \SAT\ on instances with $s$ gates needs $\ge s$ queries (deterministic), for every $n\ge2$, $s\ge n-1$.
\end{proposition}
\begin{proof} Let $C_0$ be an AND-tree of $n$ inputs padded with $s-n+1$ gates computing $g\wedge 1$ along a chain, so every gate lies on the unique path to the output and $C_0$ is satisfiable by $1^n$ . For gate $g$ let $C_g$ replace $g$ by constant $0$: unsatisfiable. If a deterministic decider never queries $g$ on $C_0$ it answers identically on $C_g$, so it errs. Hence every gate is queried. (Randomized: pick $g$ uniformly; a decider with $<s/2$ expected queries misses $g$ w.p.\ $>1/2$.) \end{proof}
Consequence: $\Omega(s)$ in the query model, i.e.\ \emph{linear in the wire count}; this is the only unconditional rung so far. It does \emph{not} touch time beyond linear. KNOWN contrast: brute force costs $O(2^n s)$; Williams-type time--space results give $n^{2\cos(\pi/7)-o(1)}$ for SAT in the sequential time-space model (KNOWN THEOREM, not re-derived here).
