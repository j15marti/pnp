\section{Program}
Build circuits bottom-up: for each number of inputs $n$ record the minimum wires $w(n)$ (and gates $g(n)$) of circuits
for all $n$-input functions, then ask how the cost of \emph{deciding satisfiability} of a circuit with parameters
$(n,m)$ ($m$ = wires) must scale. Lower bound is allowed to be parameterized: $T(n,m)$.

\section{Proved elementary facts}
\begin{prop}[PROVED/EXACT: connectivity] A function depending on all $n$ inputs needs $\ge n-1$ fan-in-2 gates, i.e.\ $\ge 2(n-1)$ wires; $\mathrm{AND}_n$ meets this.\end{prop}
\begin{prop}[PROVED/EXACT: reading bound, parameterized]
In the model where the circuit is a read-only list of $m$ gate descriptors, every deterministic Circuit-SAT decider
inspects $\Omega(m)$ descriptors on worst-case inputs.\end{prop}
\emph{Proof.} Take an AND-chain over inputs (satisfiable). Altering any single unread gate's second operand to constant~0
makes it unsatisfiable, so an algorithm that skips a gate errs on one of the two instances. \qed

This is only linear and is a description-size bound, not a computational lower bound; it is the base rung.

\section{Parameterized targets (CANDIDATE / OPEN)}
\begin{itemize}
\item Fixed-$n$ ladder: $T(n,m)\ge \Omega(m)$ (proved) vs.\ brute force $O(2^n m)$. Gap is the whole question.
\item Next rung: restricted classes (read-once, monotone, bounded fan-out/treewidth $k$): known $2^{O(k)}m$ algorithms
  for bounded treewidth---a parameterized \emph{upper} bound; look for matching conditional lower bounds in $k$.
\item Compute $g^*(4)$ and per-function wire minima via SAT-based exact synthesis; tabulate wire-vs-$n$ growth against
  Lupanov $2^n/n$.
\end{itemize}
