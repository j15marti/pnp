\section*{Status}
\textbf{P versus NP remains OPEN.} Nothing here is an unconditional superpolynomial lower bound for Circuit-SAT. Labels: PROVED, COMPUTATIONAL, KNOWN, CONDITIONAL, CANDIDATE, OPEN.

\section{Goal and method}
Build up from the simplest circuit-SAT instances; for each rung track (i) the minimum number of gates $g$ and wires $w$ (here $w=2g$ for fan-in-2 gates, plus one output wire) needed to build the instance, and (ii) the best lower bound on deciding it. Parameters: $n$ inputs, $m$ gates/wires, and possibly solution count $k=|f^{-1}(1)|$. A bound may be parameterized, e.g.\ $T(n,m)\ge \phi(n)\,m$.

Model for construction cost: circuits over all 16 binary gates (complement free), fan-out unbounded, $C(f)$ = min gates. Truth tables are normalised $f(0)=0$ because $C(f)=C(\neg f)$.

\section{Proved rungs}
\begin{prop}[connectivity, PROVED] If $f$ depends on all $n$ inputs, $C(f)\ge n-1$ and the circuit has $\ge 2(n-1)$ input-to-gate wires. Hence the minimal \emph{wire count} of an $n$-input instance whose answer depends on every input is $2n-2$, attained by AND/OR/XOR trees (matches the table: $n=2,3$ give $1,2$).
\end{prop}
\begin{prop}[read-all, PROVED, black-box wire model] Any algorithm that gets a circuit $\Phi$ with $m$ gates only through queries to gate descriptions and is correct on all circuits must read $\Omega(m)$ descriptions in the worst case on the instance family ``$\Phi$ = a fixed unsatisfiable circuit, plus one hidden gate whose flip makes it satisfiable''. Adversary: answer consistently with the all-clean instance until one gate is unread, then flip it. This is a query bound only, not a time bound for explicit inputs.
\end{prop}
