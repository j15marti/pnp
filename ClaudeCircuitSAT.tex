\section{Goal and method}
Let $\mathrm{CSAT}(n,s)$ be circuit satisfiability for fan-in-2 circuits over $B_2$ with $n$ inputs and $s$ gates.
The lower bound sought is a function $T(n,s)$ (parameterized in both $n$ and $s$).
Method: ladder $L_0,L_1,\dots$ of problem classes of increasing $(n,s)$; at each rung record
(i) the minimum number of gates/wires needed to build the relevant functions and (ii) the best rigorous lower bound on solving CSAT.
Wires counted: $W=$ number of gate-input connections ($=2s$ for fan-in 2), plus output wire.

\section{Proved elementary lemmas}
\begin{lemma}[connectivity, PROVED/EXACT]\label{l:conn}
If $f$ depends on all $n$ inputs, any fan-in-2 circuit computing $f$ has $\ge n-1$ gates and $\ge 2(n-1)$ gate-input wires.
\end{lemma}
\begin{proof} Every relevant input has a path to the output; the circuit's DAG restricted to the cone is connected with $n$ sources and a single sink, and each gate has $\le2$ in-edges, so by induction on gates a cone with $g$ gates reaches $\le g+1$ distinct inputs. Hence $g\ge n-1$. Tight for $\mathrm{AND}_n$ and parity over $B_2$.\end{proof}

\begin{lemma}[read lower bound for CSAT, PROVED/EXACT]\label{l:read}
In the model where a circuit with $s$ gates is given as read-only wire list, every deterministic algorithm deciding CSAT must read $\Omega(s)$ positions (precisely, at least one description cell per gate in a chain instance).
\end{lemma}
\begin{proof} Take $C=\mathrm{AND}$-chain $g_i=g_{i-1}\wedge x_{i}$, satisfiable. Replace gate $i$'s second operand by constant $0$: unsatisfiable. The two instances differ only in cell(s) of gate $i$; an algorithm not reading them cannot distinguish. So all $s$ gates' cells are read. \end{proof}
Remark: this is an input-reading bound only; it gives $T(n,s)=\Omega(s)$, trivially. (Brute force gives $O(2^n s)$.)

\section{Bridge: size lower bound vs.\ CSAT time}
A size lower bound for an explicit $f$ is not a time lower bound for CSAT. Candidate bridge (CANDIDATE, unproved): restrict algorithms to ``wire-local'' ones that decide CSAT by successive gate eliminations/substitutions; then each rung's minimal-wire count bounds the number of elimination steps. Needs a theorem relating arbitrary algorithms to this model; unlikely without new ideas (relativization/natural-proofs barriers apply).
