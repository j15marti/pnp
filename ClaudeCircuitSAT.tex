\section{Model and parameters}
A circuit $C$ has $n$ inputs, $g$ fan-in-2 AND gates with free negation on wires (so OR is included), hence $w=2g+1$ wires counting the output. Circuit-SAT: is there $x$ with $C(x)=1$? Parameters: $n$, $g$ (or $w$), fan-out, depth, treewidth $\tau$. A lower bound is a function $T(n,g,\dots)$.

\begin{lemma}[connectivity] A circuit whose output depends on all $n$ inputs has $\ge n-1$ gates and $\ge 2(n-1)$ gate-input wires.\end{lemma}
\emph{Proof.} The underlying graph restricted to the cone of the output must connect $n$ input nodes to the output; each fan-in-2 gate merges at most two components, so $n-1$ gates are needed. \qed

\section{First lower bound (query/read model)}
\begin{theorem}[PROVED, trivial but parametrized] Any algorithm that decides Circuit-SAT for circuits given as wire lists must examine $\Omega(g)$ wires, even for $n=1$.\end{theorem}
\emph{Proof sketch.} Take a chain of $g$ gates computing $x\wedge x\wedge\cdots$, plus one designated wire $e$. Adversary: all wires are consistent except that exactly one wire $e$ (chosen last) is rewired to a gate computing $\neg x$ conjoined into the chain, making the circuit unsatisfiable; the algorithm cannot distinguish without reading $e$, so it reads $\ge g/2$ wires on average. \qed

This is only linear. The parametrized frontier is where the real content lies:
\begin{itemize}
\item Upper bound (KNOWN): $2^n\cdot g$ by enumeration; $2^{O(\tau)}g$ by dynamic programming over a tree decomposition; so any lower bound must grow with $\tau$.
\item Conditional (KNOWN): under SETH no $2^{(1-\varepsilon)n}\mathrm{poly}(g)$ algorithm exists; this is conditional and not admissible as a proof.
\item Unconditional restricted models (KNOWN): resolution/read-once branching programs give exponential bounds in $n$ for specific families; these do not bound general algorithms.
\end{itemize}
