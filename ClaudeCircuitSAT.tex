\textbf{P versus NP remains OPEN.} No unconditional superlinear lower bound for general Circuit-SAT is claimed. Status labels: PROVED/EXACT, KNOWN THEOREM, COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN, FALSIFIED/RETIRED.

\section{Setup and parameters}
Circuit: DAG of fan-in-2 AND/OR gates, negation free on wires. Parameters: $n$ inputs, $g$ gates, $w=2g$ wires (connections). Circuit-SAT$(n,g)$: is there $x\in\{0,1\}^n$ with $C(x)=1$? Bounds are sought as functions $T(n,g)$, e.g.\ $\Omega(g)$ (reading), $2^{\epsilon n}$ (conditional).

\section{Step ladder: minimal connections}
\subsection{Wire count of a connected circuit (PROVED/EXACT)}
\begin{lemma}\label{lem:conn}
If $C$ has an output depending on all $n$ inputs, then $g\ge n-1$ and $w\ge 2n-2$; equality holds iff $C$ is a formula tree with each input used once.
\end{lemma}
\begin{proof} The ancestor graph of the output is connected with $n+g'$ nodes ($g'\le g$ gates), so it has $\ge n+g'-1$ undirected edges. It has exactly $2g'$ edges, so $g'\ge n-1$. Equality of edges and spanning tree forces no cycles, i.e.\ fan-out~1. \end{proof}
Consequence: the unique-SAT ``minterm'' $x_1^{a_1}\wedge\dots\wedge x_n^{a_n}$ costs exactly $n-1$ gates ($2n-2$ wires).

\section{Lower bound I: wire-probe model (PROVED/EXACT, weak)}
Model: instance is a gate list; the algorithm probes single wire entries (source id and polarity bit).
\begin{theorem}\label{thm:probe}
Every deterministic algorithm deciding Circuit-SAT on instances with $w$ wires probes $\ge (w+2)/4$ entries.
\end{theorem}
\begin{proof} Take $k$ gadgets $A_i=\mathrm{AND}(x_1,\neg x_1)$ joined by an OR-tree of $k-1$ gates; $w=2k+2(k-1)=4k-2$. The base instance is unsatisfiable. Flipping the polarity bit of the second wire of one gadget $A_i$ gives $x_1\wedge x_1$, satisfiable, and changes nothing else. If the algorithm leaves that bit of some $A_i$ unprobed, the adversary answers the base instance on all probes and the algorithm cannot distinguish the base instance from the $i$-th perturbation. So it probes all $k=(w+2)/4$ gadget bits. \end{proof}
Scope: this is a reading bound, $\Omega(g)$ in the description-probe model. It says nothing about $2^n$ and does not bound Turing-machine time beyond input reading. Randomized version by Yao on a random perturbation: $\Omega(w)$ probes (CANDIDATE, not written out).

\section{Lower bound II: exponential in $n$ (CONDITIONAL / KNOWN)}
ETH/SETH-type: no $2^{(1-\epsilon)n}\mathrm{poly}(g)$ algorithm for Circuit-SAT under SETH (CNF-SAT embeds with $g=O(m n)$). This is a conditional parameterized bound $T(n,g)\ge 2^{(1-\epsilon)n}$, not new here. Unconditional: only the $\Omega(g)$ of Theorem~\ref{thm:probe} and the known time-space tradeoffs (Fortnow--van Melkebeek, Williams) for SAT; the repository records a barrier (ledger rows L13, L34, L38--L40 in \texttt{research/agents/claude/world-ledger/}) showing alternation trading cannot reach the relevant exponents with portfolios of $\approx N$ programs.
