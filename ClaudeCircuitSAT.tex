\section{Model}
A circuit $C$ is a DAG of fan-in-2 gates over basis $B_2$ (all 16 binary gates) on inputs $x_1..x_n$;
size $s(C)$ = #gates; wires $w(C)=2s(C)$ (+1 output tap). $\mathrm{CSAT}$: given $C$, decide $\exists x\,C(x)=1$.
Two quantities are tracked per stage $n$:
\begin{enumerate}
\item $S(n)=\max_f \min\{s(C):C\text{ computes }f\}$ (hardest $n$-input function), and $S_{ess}(n)$ restricted to functions depending on all inputs;
\item $W_{crit}(C)$ = number of wires whose rewiring (to a constant) changes satisfiability (``critical wires'').
\end{enumerate}

\section{Stage-by-stage exact values}
\begin{proposition}[COMPUTATIONAL, exhaustive; \path{scripts/circuit_min_size.py}]

\section{A proved (trivial) wire lower bound}
\begin{lemma}[PROVED/EXACT, adversary]
Let $C$ be given as a wire list and let every wire of $C$ be critical in the above sense for some pair $(C,C')$ differing in one wire. Any deterministic algorithm deciding CSAT correctly on both $C$ and all single-wire modifications must read every critical wire; hence it uses $\ge W_{crit}(C)$ reads.
\end{lemma}
\emph{Proof.} If wire $e$ is unread on input $C$, the algorithm behaves identically on $C$ and its modification $C_e$, which differ in satisfiability. $\square$

\textbf{Limitation (honest).} $W_{crit}\le 2s+1$, so this gives only $\Omega(|C|)$: the trivial input-reading bound. It is a bound on \emph{queries to the description}, not on running time in terms of $n$. It cannot separate P from NP; this is the model-matched statement of why wire counting alone is insufficient: the hard part is the number of \emph{evaluations/assignments}, not wires.

\section{Why a naive wire$\to$time bound fails (FAILED TRANSFER notes)}
\begin{itemize}
\item Counting gates for a \emph{fixed function} (Shannon/Lupanov $\Theta(2^n/n)$ for the worst function) is a non-uniform bound on the function, not on the CSAT decision procedure for a given $C$.
\item Best known explicit $B_2$ circuit lower bounds are $\approx 3.1n$ (Li--Yang, STOC 2022), far from superpolynomial; this is the known barrier for any ``minimal wires for an explicit function'' route. (KNOWN THEOREM; citation from memory, re-verify.)
\item CSAT restricted to $O(1)$ gates is in P trivially; restricted to formulas of size $s$ it is solvable in $2^{n}\,\mathrm{poly}(s)$ and, under SETH, no $2^{(1-\epsilon)n}$ (CONDITIONAL, not usable unconditionally).
\end{itemize}
