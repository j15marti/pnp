\section{Model}
A circuit $C$ has $n$ inputs, $s$ fan-in-2 gates over $B_2$ (all 16 binary gates), one output;
wires = gate in-edges ($2s$ total). Circuit-SAT: given $C$, is there $x$ with $C(x)=1$?
Input size is $\Theta(s\log s)$ bits. Parameter vector $(n,s,w)$ with $w$ the treewidth of the underlying graph.

\section{Rung 1: wire counting (PROVED/EXACT)}
\begin{lemma}[connectivity]\label{lem:conn}
If $C$ depends on all $n$ inputs, then $s\ge n-1$ and $C$ has $\ge 2(n-1)$ wires; equality is attained by $\mathrm{AND}_n$.
\end{lemma}
\begin{proof}
Every input lies in the cone of the output, which is a connected graph on $n+g$ nodes ($g\le s$ gates)
with $2g$ edges; connected $\Rightarrow 2g\ge n+g-1$, i.e.\ $g\ge n-1$. A balanced tree of $n-1$ AND gates attains it.
\end{proof}
Consequence: any algorithm for a circuit family depending on all inputs must read $\Omega(n)$ wires; reading is not the bottleneck.

\section{Rung 3: black-box evaluation bound (PROVED/EXACT in model, not P vs NP)}
\begin{theorem}\label{thm:bb}
Let $\mathcal F_n=\{C_w:w\in\{0,1\}^n\}$, $C_w(x)=[x=w]$ (each realised by $n-1$ gates, Lemma~\ref{lem:conn}) together with the all-zero circuit.
Any deterministic algorithm that accesses $C$ only by evaluating it on chosen points needs $2^n-1$ evaluations to decide
satisfiability in the worst case; with a promise that $w$ lies in a set $S$, it needs $|S|-1$.
\end{theorem}
\begin{proof}
Adversary answers $0$ to every query; after $q<|S|-1$ queries two untested candidates remain, one consistent with $C_w$, one with the zero circuit.
\end{proof}
If each evaluation is charged $\ge n-1$ gate-evaluations (Lemma~\ref{lem:conn}) the black-box cost is $\ge(2^n-1)(n-1)$.
\textbf{Status of transfer:} FAILED TRANSFER to the white-box problem: the algorithm may read $C$'s wires (here, $C_w$ reveals $w$ in $O(n)$ time). This is the relativization barrier; the bound only motivates which structure must be hidden.
