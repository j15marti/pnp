\section{Model}
A circuit has $n$ inputs and $s$ binary AND gates; negation is free on edges (an AIG). Wires $=$ edges $=2s$ plus one output pin. Parameters: $n$ (inputs), $s$ (gates), $w$ (treewidth), $d$ (refutation depth, below).

\section{Ladder of exact small results}
\begin{theorem}[Connectivity floor, PROVED]
If the output depends on all $n$ inputs, then $s\ge n-1$ and wires $\ge 2(n-1)$. Tight (AND tree).
\end{theorem}
\emph{Proof.} The underlying graph on $n+s$ nodes is connected to the output through every input, so it has $\ge n+s-1$ edges; it has $2s$ edges, so $s\ge n-1$.\hfill$\square$

\begin{lemma}[Needle floor, PROVED]
A circuit with exactly one satisfying assignment depends on all $n$ inputs, so needs $\ge n-1$ gates; the AND of $n$ literals attains it.
\end{lemma}

\begin{theorem}[Netlist-probe lower bound, PROVED, trivial but wire-exact]
Let an algorithm read the netlist through probes ``which literal is pin $i$''. On $m$-literal AND-chains over $n\ge m$ variables, any deterministic algorithm deciding satisfiability needs $\ge m$ probes.
\end{theorem}
\emph{Proof.} Adversary answers every probe with a fresh positive variable (consistent, SAT). If some pin $j$ is unprobed, the instance with pin $j$ replaced by the negation of an already-probed variable is UNSAT and agrees with every answer.\hfill$\square$
So every one of the $\Theta(s)$ wires is essential; this is an input-size bound, not a computation-time bound.
