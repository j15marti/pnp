\section{Ladder method}
Level $n$: Boolean functions on $n$ inputs computed by DAG circuits of fan-in-2 gates (all 16 binary gates).
For each level we track $g_{\min}(f)$ (gates) and wires $w=2g$ (gate-input edges), and the cost of \emph{deciding} satisfiability
of an instance of that size. Parameters: $n$ (inputs), $g$ (gates), $w$, depth, and $k$ (weight, for weighted variants).

\section{Proved lower bounds on structure}
\begin{theorem}[PROVED: connectivity bound] If the output of a fan-in-2 circuit depends on all $n$ inputs, then $g\ge n-1$ and $w=2g\ge 2(n-1)$.\end{theorem}
\begin{proof} Each input has a path to the output, so the underlying undirected graph on $n+g$ nodes is connected and has $2g$ edges (counting multiplicity);
$2g\ge (n+g)-1$ gives $g\ge n-1$. Equality holds for $\mathrm{AND}_n$ (a tree). \end{proof}

\begin{theorem}[PROVED: linear read bound for white-box deciders] Any correct deterministic Circuit-SAT decider on encodings of $g$-gate circuits must read $\Omega(g)$ encoding symbols.\end{theorem}
\begin{proof} Take $C_{b}=\bigwedge_{j=1}^{m}(x_j\wedge y_j)$ with $y_j=x_j$ or $\neg x_j$ ($b_j\in\{0,1\}$): satisfiable iff every $y_j=x_j$.
Adversary answers ``$y_j=x_j$'' to every read; if some descriptor $j$ is unread, flipping it flips the answer, so the decider is wrong on one of two instances agreeing on all reads. Hence all $m=\Theta(g)$ descriptors are read. \end{proof}
(Both are trivial; they fix the baseline $\Omega(w)$ that any real bound must exceed.)

\section{Decision-side bounds and parameters}
\begin{itemize}
\item KNOWN (black box): with only evaluation access to $C:\{0,1\}^n\to\{0,1\}$, deterministic search needs $2^n$ queries in the worst case (adversary answers 0); weight-$k$ version needs $\binom{n}{k}$. The white-box setting is exactly where this fails to transfer: the circuit text is available.
\item KNOWN: best explicit lower bound for a function in NP over $B_2$ is about $3.1n$ gates (Li--Yang 2022; cite to be rechecked). No superlinear bound known.
\item CONDITIONAL: SETH/ETH give $2^{(1-o(1))n}$-type bounds for CNF-SAT; these are assumptions, not proofs.
\item Parameterized candidate: bound of form $T(n,g)\ge f(n)\cdot g^{c}$; Weighted-Circuit-SAT is W[P]-complete, so a bound $n^{\Omega(k)}$ would be conditional on FPT$\ne$W[P]. All OPEN.
\end{itemize}
