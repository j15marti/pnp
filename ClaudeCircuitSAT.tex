\section{Goal and plan}
Find (possibly parameterized) lower bounds for Circuit-SAT. Method: start from the simplest circuits, add inputs one at a time, record the minimum number of wires needed at each step, and record what any SAT algorithm must do on those instances. Parameters: $n$ = inputs, $g$ = gates, $m$ = wires. In the model used, gates are fan-in-2 AND with free negation on wires, so $m=2g$ (plus one output wire).

\section{Model and instance family}
A circuit is a DAG over inputs $x_1,\dots,x_n$ with fan-in-2 AND gates; each wire may carry an inversion. OR is AND with inverted wires (De~Morgan), so this basis is $\{\wedge,\vee,\neg\}$ with negation free. Circuit-SAT: given $C$, decide whether some $a\in\{0,1\}^n$ has $C(a)=1$. The encoding is the wire list: for every wire, its source node and inversion bit.

\section{Proved facts}
\begin{lemma}[PROVED/EXACT: wire ladder for unique-SAT]
A circuit that depends on $n$ inputs needs at least $n-1$ fan-in-2 gates, hence at least $2(n-1)$ wires; the minterm $x_1^{a_1}\wedge\dots\wedge x_n^{a_n}$ attains this. So the minimum wire count of a satisfiable instance with a unique solution is $2(n-1)$, matching the ladder $1,2,3$ above.
\end{lemma}
\begin{proof}
Each gate merges at most two connected components of the graph on inputs; $n$ inputs reached from one output need $n-1$ merges. The chain of ANDs with inversion bits $a_i$ achieves it.
\end{proof}

\begin{lemma}[PROVED/EXACT: reading lower bound $\Omega(m)$]
Any deterministic algorithm that decides Circuit-SAT by probing the wire list must probe $\Omega(m)$ wire entries on some instance.
\end{lemma}
\begin{proof}
Take the chain $g_i=g_{i-1}\wedge \ell_i$ with $\ell_1=x_1$ and $\ell_i\in\{x_1,\neg x_1\}$ for $i\ge2$ ($m=\Theta(n)$ for any fixed padding with other inputs). The instance is satisfiable iff no $\ell_i=\neg x_1$. Answer every probe as ``$\ell_i=x_1$''. If some $\ell_j$ were never probed, flipping it to $\neg x_1$ gives an unsatisfiable instance with the same transcript, so a correct algorithm probes all $\ell_j$.
\end{proof}

\begin{lemma}[PROVED/EXACT: black-box $2^n$]
If the circuit is only accessible by evaluation queries, finding or deciding a unique satisfying assignment needs $2^n$ queries in the worst case (adversary answers 0 until one point remains). With $m$ wires per evaluation this is $\Omega(m2^n)$ time in the query-charged model.
\end{lemma}
\emph{Caveat.} Lemma~3 is a black-box bound. It is \emph{not} a white-box bound: the minterm instances above are solved in time $O(m)$ by reading the wires. White-box $2^{(1-\epsilon)n}$ is the SETH-type CONDITIONAL statement, not proved here.

\section{What the ladder shows}
\begin{enumerate}
\item Size-minimal unique-SAT circuits ($m=2(n-1)$) are easy: the solution is written in the inversion bits. Any hardness must come from instances whose wire count is large relative to the information needed to describe the solution.
\item The only unconditional bound reached so far is linear, $\Omega(m)$ (Lemma~2), uniformly in $n$. The parameterized shape to aim for is $T(n,m)\ge m\cdot f(n)$ with $f$ superpolynomial; this is OPEN, and by Lemma~3 it can only come from white-box reasoning.
\item The minimum-gate table is a tool for choosing test families, not itself a lower bound.
\end{enumerate}

\section{Link to the repository (read this run)}
Read: \texttt{AGENTS.md}, the world ledger (\texttt{research/agents/claude/world-ledger/}), the TPORT and ONETAPE notes. Useful items:
\begin{itemize}
\item KNOWN THEOREM (Williams 2008, Buss--Williams 2015, ledger row L13): SAT cannot be solved in time $n^{c}$, $c<2\cos(\pi/7)\approx1.80$, with $n^{o(1)}$ space. A circuit with $m$ wires converts to a CNF of size $O(m)$ by Tseitin, so Circuit-SAT inherits $m^{1.80-o(1)}$ for time with $m^{o(1)}$ space (conversion adds variables, which is harmless for the size parameter $m$). This is the strongest unconditional superlinear bound available for the parameter $m$, in the time--space model only.
\item Ledger row L34/L35 and the ONETAPE note: alternation-trading proofs cannot reach linear-time portfolio bounds at the UWI size; one-tape bounds do not separate P from NP. These bar certain proof styles for a ``portfolio'' form of the problem; they do not bear on the white-box lower bound above directly.
\end{itemize}
Status of transfer: the time--space bound is a direct consequence (Tseitin) and counts as KNOWN THEOREM; no new theorem is claimed.
