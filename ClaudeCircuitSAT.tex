\section*{Status (read first)}
\textbf{P versus NP remains OPEN.} Nothing here is an unconditional time lower bound for Circuit-SAT.
Everything proved below is a \emph{wire-query} (description-reading) bound, which is linear in circuit size and is
a necessary-cost statement only; it does not constrain an algorithm that is free to compute on the circuit.
Labels: PROVED/EXACT, COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN, FALSIFIED/RETIRED.

\section{Model and ledger}
A circuit in $\mathcal F(n,g)$ has $n$ inputs, $g$ fan-in-2 AND gates in topological order, and $2g$ \emph{wires} (input
slots). Each slot names a source: a literal $x_i,\neg x_i$ ($2n$ options) or an earlier gate. The output is the last gate.
A \emph{wire query} reveals the source of one slot. $D(n,g)$ is the minimal worst-case number of wire queries of a
deterministic adaptive algorithm deciding satisfiability. Trivially $D(n,g)\le 2g$. The ledger tracks $(n,g,2g,D)$;
the lower bound is allowed to be parameterized by $g$ (equivalently the wire count $w=2g$), independent of $n$.

\section{Proved base case: the wide-AND rung}
\begin{theorem}[PROVED/EXACT]\label{thm:wide}
Let $k\ge2$, $n\ge1$. For circuits consisting of one AND of $k$ literal slots (equivalently an AND tree of $k-1$
fan-in-2 gates, $k$ leaf wires), deciding satisfiability needs exactly $k$ leaf-wire queries.
\end{theorem}
\begin{proof}
Upper bound: read all $k$. Lower bound: the adversary answers $x_1$ to every query. The instance is SAT iff no
complementary pair. If some slot $j$ is unread when the algorithm halts, at least one other slot was read (as $k\ge2$)
and is $x_1$; replacing slot $j$ by $\neg x_1$ gives an UNSAT instance consistent with all answers, while
$x_1$ in slot $j$ gives a SAT instance. So the algorithm errs on one. Hence all $k$ are read. \qed
\end{proof}
This is the elementary ``every wire is critical'' principle: in a SAT instance with a single satisfying cone, one
unread wire can be flipped to destroy satisfiability.

\begin{conj}[CANDIDATE]
$D(n,g)=2g$ for all $n\ge1,g\ge1$ in the DAG family. Natural proof route: generalise the adversary of
Theorem~\ref{thm:wide} to a path-structured instance where each gate's other input is a fixed satisfiable literal.
Not yet proved.
\end{conj}

\section{Barrier audit}
\begin{itemize}
\item \textbf{Failed transfer:} $D=2g$ is a bound in the query-to-description model; a Turing-machine/RAM
solver reading the same description also pays $\Omega(g)$ time, but this is just input length. It says nothing
about super-polynomial time. Relativization-style barriers are not engaged because no oracle is involved, and no
claim beyond linear is made.
\item \textbf{Next rung needed:} a measure that charges \emph{computation} rather than reading, e.g.\ a monotone/
parameterized resource such as treewidth $\mathrm{tw}$ of the wire graph with a conjectured $2^{\Omega(\mathrm{tw})}$
bound (CANDIDATE; ETH-conditional upper-bound matching known for SAT parameterized by treewidth, so any
unconditional version is as hard as the main problem).
\end{itemize}
