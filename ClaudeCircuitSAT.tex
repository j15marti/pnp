\paragraph{Status.} P versus NP remains \textbf{OPEN}. No unconditional super-polynomial lower bound for Circuit-SAT is claimed. Status labels: PROVED/EXACT, KNOWN THEOREM, COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN, FALSIFIED/RETIRED.

\section{Program}
Build Circuit-SAT bottom-up: fix a basis ($B_2$ = all binary gates, fan-in 2), grow the number of inputs $n$ and gates $m$, and for each stage record (i) the minimal wire/gate count needed to \emph{build} the instance, (ii) the minimal work needed to \emph{decide} it, as a parametrized bound in $(n,m,k)$ with $k$ a structural parameter (treewidth, depth, number of fan-out wires).

\section{Stage ledger}
\subsection*{Stage 0: reading bound (PROVED/EXACT)}
\begin{lemma} Let $\mathrm{CSAT}_m$ be circuits with $m$ gates given as gate lists. Any deterministic decider in the random-access model must, on some instance, read $\Omega(m)$ input cells.\end{lemma}
\emph{Sketch.} Take a chain $g_1=x_1\wedge x_2$, $g_{i+1}=g_i\wedge x_{i+2}$ (output $g_m$) -- satisfiable. An unread gate record can be replaced by $g_i:=\mathrm{const}\;0$, making the instance unsatisfiable, so a correct decider reads every record. Gives $\Omega(m)$ with the trivial bound only; it says nothing about super-linear time.

\section{Parametrized bounds (ledger)}
\begin{itemize}
\item KNOWN THEOREM (Shannon counting): some $n$-input function needs $\Omega(2^n/n)$ gates; says nothing about explicit functions or SAT.
\item KNOWN THEOREM: best explicit $B_2$ circuit lower bound is $\approx 3.1n$ (Find--Golovnev--Hirsch--Kulikov 2016; Li--Yang STOC 2022: $(3.1-o(1))n$ ). Circuit-SAT hardness over $n$ inputs is thus unrelated to current unconditional size bounds.
\item CONDITIONAL: SETH $\Rightarrow$ no $O(2^{(1-\epsilon)n}\mathrm{poly}(m))$ algorithm for CNF-SAT; ETH $\Rightarrow$ no $2^{o(n)}$ for 3-SAT. Parameter $n$ is the right one for these.
\item KNOWN THEOREM: Circuit-SAT is FPT in treewidth $k$: time $2^{O(k)}\cdot m$; under SETH, $(2-\epsilon)^{k}$ is impossible for fixed formulations (Lokshtanov--Marx--Saurabh for SAT with primal treewidth). Candidate parametrization: $T(n,m,k)=2^{\Theta(k)}\,m$ for $k\le n$.
\item OPEN: unconditional $\omega(m)$ time lower bound for Circuit-SAT in any universal model.
\end{itemize}
