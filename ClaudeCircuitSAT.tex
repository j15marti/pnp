\section{Setup and parameters}
A circuit $C$ has $n$ inputs, $s$ binary gates (basis $B_2$, all 16 two-input functions, so negation is free), hence $w=2s$ gate-input wires.
CIRCUIT-SAT$[n,s]$: given $C$, decide $\exists x\in\{0,1\}^n: C(x)=1$. Encoded input length $N=\Theta(s\log(n+s))$.
Candidate parametrized lower bound: $T(n,s)\ge F(n,s)$, to be studied in regimes $s=n^{O(1)}$ (e.g.\ $s=cn$) and $s$ near $n-1$.
Let $\mathrm{C}(f)$ be the minimum $B_2$ gate count of $f$.

\section{Elementary facts (PROVED/EXACT)}
\begin{prop}[Connectivity] If $f$ depends on $d$ inputs then every $B_2$ circuit for $f$ has $\ge d-1$ gates ($\ge 2(d-1)$ wires).
\end{prop}
\emph{Proof.} Each essential input has a path to the output; the gates form a DAG in which the $d$ essential inputs must be joined into one component; each fan-in-2 gate reduces the component count by at most 1. \qed

\begin{prop}[Minimal unique-SAT instances] The function with exactly one satisfying point on $n$ variables has $\mathrm C=n-1$ (matches data: $n=2,3$: 1, 2).
\end{prop}
\emph{Proof.} Upper: AND of $n$ literals. Lower: all $n$ variables essential, apply the Connectivity proposition. \qed

\textbf{Consequence / limitation.} The \emph{cheapest} hard-looking instances (unique solution, $s=n-1$) are trivially solved in time $O(s)$ by reading the AND-tree. A real lower bound must hold for the family of circuits an adversary chooses, so the parameter that matters is the \emph{structure} (not only $s$): instance size $s$ is a lower bound for reading (any algorithm needs $\Omega(s)$ if it must examine every wire, KNOWN/trivial), and the open question is the exponent in $n$.

\section{Black-box barrier (KNOWN THEOREM, FAILED TRANSFER)}
In the oracle (evaluation-only) model, finding the unique satisfying point of an $n$-variable function needs $2^{n-1}$ expected queries (classically; $\Omega(2^{n/2})$ quantumly, BBBV). This does \emph{not} transfer to white-box Circuit-SAT because an algorithm sees the wires (the AND-tree above is solved in linear time). Any real argument must use circuit structure; relativization-type arguments are therefore insufficient.
