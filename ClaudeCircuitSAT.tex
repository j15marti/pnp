\section{Goal and method}
Circuit-SAT: given a fan-in-2 circuit $C$ with $n$ inputs and $m$ gates (so $2m$ gate-input wires), decide whether $\exists x\,C(x)=1$.
Plan: (i) fix the cost measure (gates/wires), (ii) climb from tiny cases, tracking the minimum wires needed to build each instance class as $n$ grows, (iii) express any bound as $T(n,m,\text{parameter})$, (iv) record which steps give unconditional bounds and which are only conditional.
Gate basis $B_2$: the 10 non-degenerate 2-input gates, output negation free; repeated input wires allowed.

\section{Step 1: wire cost of depending on $n$ inputs}
\begin{lemma}[PROVED/EXACT]\label{l:wires} If $f$ depends on all $n\ge1$ inputs, any fan-in-2 circuit for $f$ has $g\ge n-1$ gates and at least $n+g-1\ge 2n-2$ wires (edges of the circuit graph, at most $2g$ in total).
\end{lemma}
\begin{proof} Every input has a directed path to the output, so the underlying undirected graph on the $n+g$ nodes is connected, hence has $\ge n+g-1$ edges (distinct wires; parallel wires only add). Edges $\le 2g$, so $g\ge n-1$ and edges $\ge n+g-1\ge 2n-2$. \end{proof}
Tight: the AND chain on $n$ literals. Consequence: a \emph{unique-SAT} instance (exactly one satisfying point $a$, namely $\bigwedge_i \ell_i$) costs exactly $n-1$ gates, so the smallest hard-looking instances are tiny.

\section{Step 3: unconditional $\Omega(m)$ and why it is the only unconditional rung so far}
\begin{proposition}[PROVED/EXACT, trivial]\label{p:read} Any deterministic algorithm deciding Circuit-SAT on instances with $m$ gates, given the circuit description as read-only cells, makes $\Omega(m)$ cell reads in the worst case.\end{proposition}
\begin{proof} Let $g_0=x_1$, $h_i=(x_1\vee\neg x_1)$ for $i=1..m$, $g_i=g_{i-1}\wedge h_i$, output $g_m$. Call this $I_0$: satisfiable ($x_1=1$). $I_i$: change only the type cell of $h_i$ to $x_1\wedge\neg x_1$; then $h_i\equiv0$ and $I_i$ is unsatisfiable. An algorithm that never reads that cell on $I_0$ behaves identically on $I_i$, so errs. Hence it reads all $m$ type cells. \end{proof}
Parameterized form: the best known \emph{upper} bound is $O(2^n\cdot m)$ (and $2^{O(\mathrm{pw})}m$ for pathwidth/treewidth $\mathrm{pw}$ of the circuit graph). Unconditional gap: $\Omega(m)$ vs $2^n m$.
