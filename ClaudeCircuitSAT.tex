\section{Model}
An instance is a circuit $C$ with $n$ inputs, $g$ fan-in-2 gates (AND/OR, optional negation on each wire),
$w=2g$ gate-input wires, one output. $\mathrm{CSAT}$: is there $x$ with $C(x)=1$?
Cost measures tracked on the ladder: (i) wires $w$ that any correct decider must read (description-probe model);
(ii) a parameter $k$ (treewidth/pathwidth of the wire graph) for parametrized bounds.

\noindent Call a wire \emph{critical} for $C$ if rerouting it to constant $0$ or $1$ changes satisfiability.
Exhaustive enumeration ($n\le3$, $g\le3$, no dead gates; 82\,k circuits) found, for every $(n,g)$, a circuit whose

\begin{prop}[Description-reading bound; PROVED/EXACT]
For $n\ge2$, any deterministic algorithm that decides $\mathrm{CSAT}$ for all circuits with $g=n-1$ gates, in the model
where the gate wiring is accessed by probes, makes at least $2(n-1)$ wire probes.
\end{prop}
\begin{proof}
Take $C=\bigwedge_i x_i$ (AND-tree, satisfiable). If the algorithm leaves one wire $e$ unprobed, the adversary
answers consistently with $C$ yet the instance $C'$ with $e$ rerouted to constant $0$ is unsatisfiable and agrees on all
probed wires. Hence the algorithm errs on one of $C,C'$. \qed
\end{proof}
This is only linear in the description size; it separates \emph{reading} from \emph{solving} and gives the base rung.

\section{Where the ladder must go next}
\begin{itemize}
\item \textbf{Parametrized upper envelope (KNOWN THEOREM):} $\mathrm{CSAT}$ on width-$k$ circuits is solvable in $2^{O(k)}\mathrm{poly}$ time
(dynamic programming over a tree decomposition). Any true lower bound parametrized by $k$ is therefore at most $2^{O(k)}$; the interesting candidate is
\begin{conj}[CONDITIONAL on SETH; CANDIDATE as a stand-alone bound]
No algorithm decides CSAT on pathwidth-$k$ circuits in $(2-\varepsilon)^k\mathrm{poly}$.
\end{conj}
\item \textbf{Next rung (OPEN):} exact minimal \emph{probe} complexity of CSAT on width-2 circuit families for growing $n$; extend the enumeration to
$g=4,5$ using canonical-form pruning, and track the minimum number of wires in a circuit whose satisfiability \emph{cannot} be decided
without reading a non-local fraction of the wires (probe-adaptive hard instances).
\item \textbf{Ideas to test:} counting argument (number of distinct functions on $g$ gates vs.\ $2^n$ inputs) as a parametrized lower bound for
\emph{size of a witness-free certificate}; relation to fan-out accounting (wire reuse) as the quantity that separates formulas ($\mathrm{fanout}=1$) from circuits.
\end{itemize}
