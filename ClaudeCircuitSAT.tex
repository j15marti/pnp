\section{Goal and plan}
Build lower bounds for $\CSAT$ from the bottom up: start with the smallest circuits, track exactly how many wires (connections) each rung needs, raise the number of inputs $n$ one step at a time, and record the bound as a function of parameters $(n,s,w,\dots)$ (inputs, size, width/treewidth, fan-out). A parametrized bound is acceptable; a bound only in $n$ is not expected to separate P from NP.

\paragraph{Model.} Circuits are DAGs over fan-in-2 gates from $B_2$ (all 16 binary Boolean functions), single output, free output negation. A \emph{wire} is a directed edge (gate input). A circuit with $g$ gates has exactly $2g$ wires. Outputs of inputs/gates may fan out freely unless a fan-out parameter is stated.

\section{Proved lower bounds so far}
\begin{lemma}[connectivity floor]\label{lem:conn}
If $f$ depends essentially on all $n$ inputs, any $B_2$ circuit for $f$ has at least $n-1$ gates and at least $2n-2$ wires; if every input has fan-out $1$ the circuit is a tree and equality is attained exactly by trees.
\end{lemma}
\begin{proof}
The output node reaches every essential input (else $f$ would not depend on it). A DAG with one sink reaching $n$ sources through fan-in-2 gates: induct on gates; the sub-DAG on the reachable set has $n+g$ nodes and is connected, so it has $\ge n+g-1$ edges, while it has exactly $2g$ edges. Hence $2g\ge n+g-1$, so $g\ge n-1$. \end{proof}
\textbf{Label:} PROVED (folklore). The $n=2,3$ tables meet it with equality for 10 of 10 and 114 of 114 minimum-size functions.

\begin{theorem}[probe lower bound for the wire-reading model]\label{thm:probe}
Let an algorithm read a circuit only through wire-probes ``what feeds gate $v$'s $i$-th input?''. Any deterministic correct $\CSAT$ algorithm needs $\ge n$ probes on some $n$-input, $(n-1)$-gate instance.
\end{theorem}
\begin{proof}
Base instance $C_0$: a balanced tree computing $x_1\wedge\dots\wedge x_n$ (satisfiable). Run the algorithm on $C_0$; if it probes fewer than $n$ leaf wires, some leaf $j$ is unread. Let $C_1$ rewire leaf $j$ to $\neg x_i$ for some $i\ne j$ (a literal of another leaf; use an extra negation gate absorbed by $B_2$). $C_1$ contains $x_i\wedge\neg x_i$ and is unsatisfiable, yet the transcript is identical. Contradiction. \end{proof}
\textbf{Label:} PROVED, but only an $\Omega(\text{input size})$ statement; it forbids no polynomial algorithm. It is the correct ``rung 0'' of a wire-sensitivity argument: define the \emph{critical wire set} of an instance as the wires whose single rewiring flips satisfiability; probes $\ge$ block sensitivity.

\section{Parametrized targets (CANDIDATE / OPEN)}
\begin{itemize}
\item \textbf{Size/width.} Dynamic programming over a tree decomposition gives $\CSAT$ in $2^{O(w)}\mathrm{poly}(s)$, $w$ the circuit treewidth (KNOWN). A matching lower bound $2^{\Omega(w)}\mathrm{poly}(s)$ is known only under SETH; unconditional version OPEN. Ladder goal: for each rung, tabulate the minimum width $w_{\min}(n)$ of the circuits that compute each hard function, to see whether width must grow linearly with $n$ on a family of satisfiability-hard instances.
\item \textbf{Fan-out.} Track $\mathrm{fo}(f)$ = min over optimal circuits of the max fan-out. If SAT-hard instances forced high fan-out, wire count grows beyond $2n$. Not yet measured: next run, extend the $n=3$ search to record fan-out and depth of each optimal circuit.
\item \textbf{Explicit circuit size bounds.} The best known unconditional lower bound for an explicit function in $B_2$ is of the form $3.1n-o(n)$ (Li--Yang, recalled from memory; verify). Shannon counting gives $\Omega(2^n/n)$ for most functions. Neither bears on $\CSAT$ for \emph{polynomial-size} circuits, which is the actual P versus NP question: a linear-in-$s$ bound on time is trivial, a superpolynomial bound is OPEN.
\end{itemize}
