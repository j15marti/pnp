\section{Program}
Start from the simplest Circuit-SAT instances, grow the circuit gate by gate and wire by wire, and for each stage record
(i) the minimum number of gates/wires forced by the function computed, and
(ii) the best provable lower bound on the work needed to decide satisfiability.
Model: fan-in-2 circuits over the full binary basis $B_2$, constants free, wires $=$ gate-input edges (so $w=2g$ for gates of fan-in 2).
Let $\mathrm{SAT}(C)=1$ iff $\exists x\in\{0,1\}^n: C(x)=1$.

\section{Ladder}
\begin{lemma}[PROVED/EXACT: connectivity floor]\label{lem:conn}
If $f:\{0,1\}^n\to\{0,1\}$ depends on all $n$ inputs, every fan-in-2 circuit for $f$ has $\ge n-1$ gates and $\ge 2(n-1)$ wires; $\mathrm{AND}_n$ attains both, so $g_{\min}(\mathrm{AND}_n)=n-1$.
\end{lemma}
\begin{proof}
The underlying graph restricted to the cone of the output is connected and contains the $n$ input nodes, each of fan-out $\ge1$ (a dependent input must reach the output). The output cone is a connected graph with $n+g$ vertices, hence $\ge n+g-1$ edges, while it has exactly $2g$ edges; so $2g\ge n+g-1$, i.e.\ $g\ge n-1$. A balanced tree of ANDs meets this.
\end{proof}

\begin{claim}[PROVED/EXACT: trivial instances]
For every circuit $C$ that is a read-once formula (tree), $\mathrm{SAT}(C)$ is decidable in $O(|C|)$ time by bottom-up evaluation of the pair (can-be-0, can-be-1). So the first stage at which hardness can appear requires \emph{fan-out $\ge 2$} (reconvergence). Wire-ledger consequence: a hard instance needs $w>2(n-1)$, i.e.\ at least one input or internal node with fan-out $\ge 2$.
\end{claim}

\begin{claim}[PROVED/EXACT: black-box floor]
Any deterministic algorithm that only evaluates $C$ on chosen points and must decide $\mathrm{SAT}(C)$ for all $C$ with $n$ inputs needs $2^n$ evaluations: an adversary answers $0$ to every query; after $<2^n$ queries some point is unqueried and the circuit that is $1$ only there is consistent with all answers yet has opposite SAT value. This is a statement about oracles and does not bound white-box algorithms.
\end{claim}

\section{Barrier ledger}
\begin{itemize}
\item Relativization: the black-box floor relativizes, hence cannot by itself separate P from NP (Baker--Gill--Solovay). KNOWN THEOREM.
\item Natural proofs / algebrization: any argument that is constructive, large and useful against $P/\mathrm{poly}$ must be audited. OPEN for every route below.
\item Gate-elimination ceiling: current technique yields only linear bounds; reaching superlinear needs a new idea. OPEN.
\end{itemize}
