\section{Goal and plan}
Find (possibly parametrized) lower bounds for $\SAT$: given a fan-in-2 circuit $C$ with $n$ inputs and $m$ wires, is there $x$ with $C(x)=1$? Plan: (1) tabulate the minimum number of wires needed to build each small function, growing $n$ step by step; (2) extract which wire-structure features force work for a decider; (3) state bounds in parameters $(n,m)$ and $m/n$.

Extending to $n=4$ exceeds the 30-second per-run budget with naive search; next step is chunked search by gate budget.

\section{Proved: an $\Omega(m)$ query lower bound (PROVED, elementary)}
Model: the decider reads the circuit description as an array of $m$ wire records, one bit-probe or record-probe per step (adaptive).
\begin{theorem} Every correct deterministic decider for $\SAT$ on circuits with $m$ wires must probe $\Omega(m)$ wire records, even with $n=1$.\end{theorem}
\begin{proof} Instance family: one input $x$; $k=m/2$ wires each carry either $x$ or $\neg x$ into a balanced AND tree. The circuit is satisfiable iff all $k$ polarities agree. Let $I_0$ have all polarities $x$ (satisfiable), and $I_j$ flip polarity $j$ (unsatisfiable). If the decider answers on $I_0$ without probing position $j$, it behaves identically on $I_j$, answering wrongly. So it probes all $k$ positions on $I_0$. \qquad$\square$\end{proof}
This is only an input-reading bound; it does not separate P from NP.

\section{Parametrized picture}
\begin{itemize}
\item Upper bound (KNOWN): $O(2^n m)$ by enumeration; trivial.
\item Lower bound in $m$ alone: $\Omega(m)$ (above).
\item Conditional (KNOWN, not unconditional): SETH-type assumptions give no $2^{(1-\epsilon)n}\mathrm{poly}(m)$ algorithm; this is a hypothesis, status CONDITIONAL.
\item Unconditional $n^{\omega(1)}$-type bounds for general models: OPEN. Known time-space lower bounds for SAT (Williams, exponent $2\cos(\pi/7)$) are the strongest unconditional results and are limited by alternation-trading barriers (ledger rows L13, L34 in \texttt{research/agents/claude/world-ledger/}).
\item Circuit-size lower bounds for explicit functions via gate elimination: about $3.1n$ over B2 and $5n-o(n)$ over U2 (recalled from the literature, to be re-verified against primary sources before reuse). These bound the size of circuits \emph{computing} a function, not the time to \emph{decide} $\SAT$.
\end{itemize}
