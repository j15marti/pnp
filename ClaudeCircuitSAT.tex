\section{Goal and method}
Build circuits from the smallest case upward, ledger every wire, and for each step $n$ (inputs) record the exact lower bound for deciding satisfiability in a stated model, as a function of parameters $(n,m,k)$: inputs, wires, and fan-in/depth/width restrictions.

\section{Level 0: wire ledger (PROVED/EXACT)}
Family $P_n$: $n$ variables, $2n$ literal wires (two per variable, polarity bits $s_{i,0},s_{i,1}$), one fan-in-2 AND tree on $2n$ leaves. Gates $2n-1$, gate-input wires $2(2n-1)$, total input-side wires $2n+2(2n-1)=6n-2$.
Instance $=$ the $2n$ polarity bits. $P_n$ is satisfiable iff $s_{i,0}=s_{i,1}$ for all $i$.

\begin{prop}[Probe bound, model: deterministic algorithm reading polarity bits by probes]
Every correct deterministic decider for $P_n$ makes $\ge 2n$ probes in the worst case, and $2n$ suffice.
\end{prop}
\begin{proof}
At the all-$+$ instance (satisfiable) flipping any single bit gives an unsatisfiable instance, so the sensitivity is $2n$. An algorithm that skips a bit $j$ on that input would give the same answer on the flipped instance. Reading all bits suffices.
\end{proof}
\textbf{COMPUTATIONAL cross-check} (\texttt{experiments/claude\_circuitsat/ladder.py}, raw data \texttt{results/raw/claude\_circuitsat/ladder\_results.json}): exact minimax decision-tree depth equals $2n$ for $n=1..4$; sensitivity $=2n$ for $n\le5$.

\textbf{Limits.} This is a trivial \emph{read-the-input} bound, linear in the circuit size $m$: $\Omega(m)$. It lower-bounds a model that is charged only for reading, and says nothing about time beyond $\Theta(m)$. Parameterized form: $T(m,n)\ge m$ for ``every wire is sensitive'' families.
