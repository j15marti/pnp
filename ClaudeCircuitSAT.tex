\paragraph{Status.} P versus NP and every superpolynomial lower bound for Circuit-SAT remain \textbf{OPEN}. Labels: PROVED, COMPUTATIONAL, CANDIDATE, OPEN, KNOWN.

\section{Program}
Build circuits gate by gate, track the minimum number of wires $w(n)$ needed at each stage, and track what any decider must do as the number of inputs $n$ and size $s$ grow. Bounds are expected to be parametrized in $(n,s)$, e.g. $\Omega(s)$, $2^{\Omega(n)}$ conditional.

\section{Stage 1: wire counts (fan-in 2, circuit read-once of the dependence graph)}
\begin{lem}[PROVED] A circuit with fan-in-2 gates whose output depends on all $n$ inputs has at least $n-1$ gates, hence at least $2(n-1)$ gate-input wires. Proof: the underlying graph restricted to the cone of the output is connected on $n$ inputs plus $g$ gates; each gate adds at most one new merge, so $g\ge n-1$.\end{lem}
\begin{lem}[PROVED] A function with exactly one satisfying assignment on $n$ variables (a minterm) needs $n-1$ gates; the AND-tree with free negation meets it. So the ``simplest'' uniquely satisfiable instance has $n-1$ gates, $2(n-1)$ wires.\end{lem}

\section{Stage 3: decider lower bound in a probe model}
\begin{thm}[PROVED, weak] Any deterministic algorithm that decides satisfiability of circuits given as a gate list of size $s$, and is correct on the family below, must probe $\Omega(s)$ gate descriptions in the worst case.\end{thm}
\emph{Proof sketch.} Family: AND-chain over $n$ literals, satisfiable; plus variants in which one leaf literal is replaced by the negation of another leaf's variable (unsatisfiable). An adversary answering each probe with a ``consistent'' literal keeps the choice of the conflicting pair open until all but one leaf is read, so $\ge n-1$ probes. This is only linear and says nothing about time beyond reading the input.

\section{Stage 4: parametrized targets (OPEN)}
\begin{itemize}
\item Brute force: $O(2^n s)$. SETH-type conditional: no $2^{(1-\epsilon)n}\mathrm{poly}(s)$ algorithm (KNOWN as a hypothesis, not a theorem).
\item Unconditional route to try: for $s$ close to $n$ (few extra wires over the minimal $n-1$), the parameter $k=s-(n-1)$ ``excess wires''. Question: is Circuit-SAT FPT in $k$ (plausibly $2^{O(k)}\mathrm{poly}$ since removing $k$ reconvergent wires leaves a tree)? Conjecture CANDIDATE: time $2^{O(k)}\cdot s$, and a matching lower bound under SETH for $k=\Theta(n)$. This yields the parametrized scale: excess wires $k$ is the hardness measure; $k=0$ (trees) is linear time.
\item Repository link: row L13 (Buss--Williams) and the TPORT/ONETAPE notes constrain time--space approaches; none gives a superpolynomial circuit-SAT bound.
\end{itemize}
