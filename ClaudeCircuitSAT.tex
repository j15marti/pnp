Status labels: PROVED/EXACT, KNOWN THEOREM, COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN, FALSIFIED/RETIRED.
The document tracks, for $n=1,2,3,\dots$ inputs, (i) the minimum number of gates/wires needed to \emph{express} the relevant instances, and (ii) the best known lower bound on \emph{solving} them, as a function of parameters $(n,s,w)$ (inputs, gates, treewidth).

\section{Model}
A circuit $C$ is a DAG; sources are inputs $x_1..x_n$ (and constants), every gate has fan-in $2$ over the full binary basis $B_2$; one gate is the output. Size $s$ = number of gates; wires $=2s$ (in-wires; fan-out is paid at the sink). Circuit-SAT: given $C$, is there $x$ with $C(x)=1$? Parameters: $n$, $s$, primal treewidth $w$.

\section{Proved lemmas}
\begin{lemma}[Connectivity / wire floor]\status{PROVED/EXACT}
If the output of a fan-in-2 circuit with $g$ gates depends on $k$ distinct inputs, then $g\ge k-1$ (so $\ge 2(k-1)$ wires).
\end{lemma}
\begin{proof} The cone of the output is a connected graph on $g+k$ nodes (gates + reached inputs) with $2g$ edges (as a multigraph); connectivity needs $2g\ge g+k-1$, i.e.\ $k\le g+1$. \end{proof}
Tightness: $x_1\wedge\dots\wedge x_n$ (and any literal-AND with unique satisfier $a$) uses exactly $n-1$ gates. Hence unique-satisfier instances $C_a$ have a hidden object $a\in\{0,1\}^n$ of $n$ bits encoded in $\Theta(n)$ wires.

\begin{lemma}[Black-box bound, parametrized]\status{PROVED/EXACT}
Let $\mathcal F_{n}=\{C_a:a\in\{0,1\}^n\}\cup\{\bot\}$ where $C_a=[x=a]$ ($n-1$ gates plus literal polarities) and $\bot\equiv0$. Any deterministic algorithm that decides SAT using only evaluation queries $C(x)$ needs $2^n-1$ queries in the worst case. Consequently, for circuits with at most $s$ gates the black-box complexity is $\ge 2^{\min(n,\,s+1)}-1$.
\end{lemma}
\begin{proof} Adversary answers $0$ to every query; after $q<2^n-1$ queries at least two points are unqueried so both $\bot$ and some $C_a$ remain consistent. The second statement uses Lemma 1: embed $\min(n,s+1)$ relevant variables. \end{proof}
\noindent\emph{Caveat.} This is an oracle-access bound; a white-box algorithm reads the wires and (here) decides the family in $O(n)$. It shows the \emph{obstacle shape}: the wire floor is linear while the black-box cost is exponential, so any lower bound must prove that wires cannot be exploited uniformly. \status{This does not bound white-box time.}

\begin{lemma}[Trivial reading bound]\status{PROVED/EXACT}
Any correct Circuit-SAT algorithm must read $\Omega(s)$ wires in the worst case (adversary flips one unread gate type in a family where the answer depends on it). This is the only unconditional white-box bound in this document.
\end{lemma}
