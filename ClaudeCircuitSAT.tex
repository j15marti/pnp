\section*{Status}
P versus NP remains OPEN. No unconditional super-linear lower bound for Circuit-SAT is claimed. Statuses: PROVED, COMPUTATIONAL, KNOWN, OPEN.
\section{Model}
Circuit $C$: $n$ inputs, $g$ fan-in-2 gates over $B_2$, $w=2g$ wires (plus output). Parameters: $(n,g,w)$. Target: bound $T(n,g)$ on decision time for $\exists x\,C(x)=1$, with parameterized form $T=\Omega(f(k)\,g^c)$ for a structural parameter $k$ (e.g.\ treewidth, fan-out).
\section{Wire-by-wire construction ledger}
\begin{proposition}[PROVED, connectivity] If $f$ depends on all $n$ inputs, any fan-in-2 circuit computing $f$ has $g\ge n-1$ gates and $w\ge 2(n-1)$ wires. (Underlying graph must connect $n$ inputs to the output; a tree on $n$ leaves has $n-1$ binary nodes.)\end{proposition}
\begin{proposition}[PROVED, query lower bound for the encoding] In the model where the algorithm reads the circuit description by single-cell queries, deciding SAT on $m$ gates requires $\Omega(m)$ queries. Proof: take an AND-tree of $m$ gates (satisfiable); an adversary replaces any unqueried gate by constant 0, which flips the answer. This is a trivial \emph{input-size} bound, not a computational one.\end{proposition}

\section{Parameterized direction}
Gate elimination (Schnorr; Stockmeyer; Iwama--Morizumi; Find--Golovnev--Hirsch--Kulikov) gives the best known explicit general-circuit lower bound $\approx 3.1n$ gates for a single function; this is linear and does not transfer to a time lower bound for Circuit-SAT as a decision problem. Parameterized candidate (OPEN): for treewidth-$k$ circuits SAT is $2^{O(k)}g$ by DP, so a lower bound of form $2^{\Omega(k)}\mathrm{poly}(g)$ would be SETH-type conditional (CONDITIONAL, not proved).
