\section{Goal and method}
Circuit-SAT: given a fan-in-2 circuit $C$ with $n$ inputs and $m$ gates, decide $\exists x\,C(x)=1$. Plan: (1) tabulate exact minimum construction cost (gates, hence wires $=2g$) of every function for growing $n$; (2) identify which structural invariants (wire count, fan-out, depth, treewidth) drive the cost of \emph{deciding} satisfiability; (3) seek bounds as a function of parameters $(n,m,\text{tw},\dots)$.

\section{Proved baseline: the trivial linear lower bound}
\begin{lemma}[Read-all-gates, PROVED/EXACT in the gate-query model]
Any deterministic algorithm that decides Circuit-SAT, accessing the circuit description by queries to gate/wire descriptors, needs $\ge m-O(1)$ queries.
\end{lemma}
\emph{Proof.} Let $g_1,\dots,g_{m-1}$ each be $x_1\wedge\neg x_1$ and the output be $\bigvee_i g_i$: unsatisfiable. Changing any single $g_i$ to $x_1\vee\neg x_1$ gives a satisfiable instance. An algorithm that skips $g_i$ answers identically on both, so it errs. \qed

So the entire open question is the gap between $\Theta(m)$ and the best upper bound $2^n\mathrm{poly}(m)$ (brute force), or $2^{\mathrm{tw}}\mathrm{poly}(m)$ via treewidth DP (KNOWN THEOREM).
