\section{Setup and parameters}
A \emph{CSAT instance} is a fan-in-2 circuit over the basis $B_2$ (all 16 binary gates, negation free)
with $k$ inputs and $s$ gates; it has $m=2s$ gate-input wires (plus one output pointer). Parameters:
$k$ (inputs), $s$ (gates), $m=2s$ (wires), and optionally depth/treewidth $w$.
Goal: a lower bound $T(k,s)$ on the time of any algorithm deciding satisfiability.
Two different ``lower bounds'' must not be conflated:
(a) $C(f)$, the minimal wires to \emph{build} a function (circuit complexity), and
(b) $T_{\rm CSAT}(k,s)$, the time to \emph{decide} satisfiability of a given circuit.
The plan: tabulate (a) step by step (Section 3), and use it as the hardness source / ledger for (b).

\section{Decision lower bounds: what is actually provable}
\begin{prop}[Reading bound, PROVED]\label{prop:read}
Any deterministic algorithm deciding CSAT in the explicit-description model with random access
needs $\ge s$ probes on instances with $s$ gates (any $k\ge 2$); hence $T(k,s)=\Omega(s)$, tight up to the
model's constant for reading.
\end{prop}
\begin{proof}
Take the chain $g_j=g_{j-1}\wedge x_{1+(j \bmod k)}$ ($g_0=x_1$); it is satisfiable.
Let $I_i$ replace gate $i$ by $g_{i-1}\wedge\neg g_{i-1}$ ($\equiv 0$): $I_i$ is unsatisfiable. If an algorithm
leaves gate $i$'s description unprobed on the chain, it receives identical answers on $I_i$ and must err on one.
So all $s$ descriptions are probed.
\end{proof}
This is the only unconditional decision bound proved here; it is linear and carries no hardness.
\begin{prop}[Parametrized upper bounds, KNOWN/trivial]
$T(k,s)=O(2^k s)$ (evaluate all assignments); the CNF case has $s=O(\text{clauses}\cdot\text{width})$.
\end{prop}
\begin{prop}[SETH-conditional, CONDITIONAL]
If SETH holds then for every $\epsilon>0$ there is no $O(2^{(1-\epsilon)k}\,\mathrm{poly}(s))$ algorithm for CSAT
(CNF-SAT embeds with $s=\mathrm{poly}(k)$). This is a restatement of SETH, not progress.
\end{prop}
Open parametrized target: any \emph{unconditional} bound of the form $T(k,s)\ge s\cdot\omega(1)$ in a general
RAM/Turing model; the repository's time--space spine (ARC/FLMV, T-PORT rows L34--L37) gives only
\emph{model-restricted} statements and conditional exponent barriers, not this.

\begin{prop}[Connectivity bound, PROVED]
A fan-in-2 circuit depending essentially on all $n$ inputs has $\ge n-1$ gates ($\ge 2(n-1)$ wires):
each gate merges at most two connected components of the input/gate graph. Tight for AND, OR, parity.
\end{prop}
\paragraph{Literature (KNOWN, quoted from memory, not re-verified this run).} Shannon/Lupanov: almost all
$n$-variable functions need $\Theta(2^n/n)$ gates. Best explicit $B_2$ lower bounds by gate elimination are
$\approx 3n$ (Blum $3n-o(n)$; later $\approx 3.1n$); the Schnorr bound $2n-3$ for parity is tight for $\oplus$.
The step ledger must be extended past $n=3$ with a SAT-based exact synthesis to see where sharing appears.
