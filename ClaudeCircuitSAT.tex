\section{Setup and parameters}
A circuit $C$ has $n$ inputs, $m$ fan-in-2 gates over the full basis $B_2$, so $w=2m$ gate wires (plus input fan-out). Circuit-SAT$(n,m)$ asks whether some $x\in\{0,1\}^n$ has $C(x)=1$. The lower-bound target is a function $T(n,m)$ (parameterised), together with the \emph{construction cost} $w_{\min}(f)=2C_{B_2}(f)$ of the circuit family used at each rung of the ladder.

\section{Rung lemmas}
\begin{lemma}[Connectivity, PROVED/EXACT]
If $f$ depends on all $n$ variables then every circuit for $f$ has $\ge n-1$ gates and $\ge 2(n-1)$ gate wires; $\mathrm{AND}_n$ meets this. \emph{Proof.} The output must be connected to each input in the underlying graph; with fan-in 2 a connected graph on $n$ inputs needs $\ge n-1$ gates, each contributing two wires. \qed
\end{lemma}
Consistent with the table: $n=3$ parity/AND cost $2$ gates.

\begin{lemma}[Read-every-gate, PROVED/EXACT]
In the gate-list encoding (random access, constant-size gate records), every deterministic algorithm deciding Circuit-SAT needs $\Omega(m)$ queries, even for $n=m$ and satisfiable-or-not families.\\
\emph{Proof.} Let $C_0$: $g_1=x_1$, $g_i=g_{i-1}\wedge x_i$, output $g_m$ (satisfiable only by all ones). For any $j$, replacing the op of $g_j$ by the constant-$0$ op gives $C_j$ unsatisfiable, and $C_0,C_j$ differ only in record $j$. An algorithm that does not read record $j$ on $C_0$ answers identically on $C_j$. \qed
\end{lemma}
This is the trivial input-size bound and shows the parameter that matters is $m$ (wires), not just $n$. It yields no super-linear bound.

\begin{prop}[Known conditional picture, KNOWN/CONDITIONAL]
Brute force is $O(2^n m)$. SETH implies no $O(2^{(1-\varepsilon)n}\mathrm{poly}(m))$ algorithm. Unconditionally, only time--space tradeoffs for SAT (Fortnow--Lipton--Van~Melkebeek--Viglas, Williams) are known; see the repository ledger rows L13, L34--L40 (alternation-trading barrier; one-tape $N^2$ discussion) in \texttt{research/agents/claude/world-ledger/}.
\end{prop}
