This document builds a ladder: start with the simplest circuits, increase the number of inputs $n$, and track

\section{Model}
A circuit is a DAG over basis $B_2$ (all 16 binary gates, negations free), $n$ inputs, one output.
$C_{B_2}(f)$ = minimum gates; wires $=2\cdot$gates. Circuit-SAT$(C)$: is there $x$ with $C(x)=1$?
Parameters tracked: $n$ (inputs), $s$ (gates), $w$ (wires), and the \emph{essential} input count.

\section{Rung table (wire-by-wire accounting)}
\begin{lemma}[Connectivity, PROVED/EXACT]\label{lem:conn}
If $f$ depends on all $n$ inputs then $C_{B_2}(f)\ge n-1$ gates, i.e.\ $\ge 2(n-1)$ wires.
\end{lemma}
\begin{proof}
Every input must reach the output, so the underlying undirected graph on $n$ inputs $+\,g$ gates is connected:
edges $2g\ge n+g-1$ (at least $n+g-1$ edges), hence $g\ge n-1$. (Fan-out only lowers edge count per node used,
not the bound.)
\end{proof}
\begin{proposition}[Point function, PROVED/EXACT]
The unique-satisfying-assignment function $\mathrm{AND}_n$ (up to negations) has $C_{B_2}=n-1$ gates, $2(n-1)$ wires.
\end{proposition}
Upper bound: a balanced tree; lower bound: Lemma~\ref{lem:conn}. So the \emph{structural} minimum is linear and
tight; hardness of Circuit-SAT cannot come from this count.

\section{From size to SAT time: a parametrized view}
\begin{proposition}[FPT in size, PROVED/EXACT]
Circuit-SAT of a circuit with $s$ gates is solvable in time $O(4^{s}\,s)$: at most $2s$ input wires exist, so at
most $2s$ distinct inputs matter; enumerate them. Treewidth $k$ of the circuit graph gives $2^{O(k)}\mathrm{poly}(s)$.
\end{proposition}
\begin{proposition}[Conditional parametrized lower bound, CONDITIONAL]
Assuming ETH, no algorithm decides Circuit-SAT in time $2^{o(s)}\mathrm{poly}$ (parameter $s$ = gates):
by Sparsification Lemma, 3-SAT with $m=O(n)$ clauses maps to a circuit with $s=O(m)$ gates.
Under SETH, no $(2-\varepsilon)^{n}\mathrm{poly}(s)$ in the number of inputs $n$.
\end{proposition}
Both are standard consequences of cited hypotheses, \emph{not} unconditional results.

\section{Known unconditional circuit-size lower bounds (KNOWN THEOREM; cited from memory, to be re-verified)}
Gate elimination: $2n-O(1)$ (Schnorr), $3n-o(n)$ (Blum), $\approx 3.1n-o(n)$ in $B_2$ (Li--Yang 2022),
$5n-o(n)$ in the basis $U_2$ (Iwama--Lachish--Morizumi--Raz). These bound the size of \emph{explicit functions},
not the running time of a SAT algorithm; nothing here exceeds linear.
