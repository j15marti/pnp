\section{Setup and ladder}
A circuit $C$ has $n$ inputs, $m$ fan-in-2 gates (basis $B_2$), hence $2m$ wires. Circuit-SAT: given $C$, decide $\exists x\,C(x)=1$. Plan: a ladder of instance classes $\mathcal C_{n,m}$, tracking (i) minimal wires needed to realize a function, (ii) minimal work to decide satisfiability, with parameters $n$, $m$, treewidth/pathwidth $w$, depth, fan-out.

\section{Step 4: trivial linear bound (PROVED)}
\begin{prop}
Any deterministic algorithm deciding Circuit-SAT on size-$m$ circuits in the indexed-input RAM model reads $\Omega(m)$ description cells.
\end{prop}
\emph{Proof.} Let $C$ be the chain $g_i=\mathrm{AND}(g_{i-1},x_i)$ (satisfiable). For each $j$ let $C_j$ replace $g_j$ by $\mathrm{AND}(g_{j-1},\neg g_{j-1})$ (constant 0, so unsatisfiable; one extra NOT gate keeps the encoding length $\Theta(m)$). An algorithm that never reads the cells of gate $j$ behaves identically on $C$ and $C_j$ but must answer differently. So it reads some cell of every gate. $\square$

This is the baseline: the gap between $\Omega(m)$ and the best upper bound $2^n\,\mathrm{poly}(m)$ is the open question.

\section{Parameterized landscape (KNOWN, cited from memory; verify before use)}
\begin{itemize}
\item Upper bound $2^{n}\mathrm{poly}(m)$ trivially, and $2^{O(w)}\mathrm{poly}(m)$ by treewidth DP.
\item Conditional: under SETH no $(2-\varepsilon)^{pw}\mathrm{poly}$ algorithm for CNF-SAT (Lokshtanov--Marx--Saurabh), and no $2^{(1-\varepsilon)n}\mathrm{poly}$ for $m=\mathrm{poly}(n)$ gates. These are conditional, hence not a proof.
\item Unconditional formula/circuit lower bounds for explicit functions: $\sim 3.1n$ (Li--Yang 2022) for circuits; none superlinear.
\end{itemize}
Candidate parametrized target (CANDIDATE, not proved): a bound $T(n,m,w)\ge f(w)\cdot m$ with $f$ superpolynomial, for restricted models (e.g.\ monotone, bounded-depth, or read-once-branching algorithms), where unconditional results are plausible.
