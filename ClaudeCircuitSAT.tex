\section{Model and parameters}
A circuit is a DAG of $g$ fan-in-2 gates over the full binary basis $B_2$ on $n$ inputs, one output; \emph{wires} $W=2g$ (plus input fan-out edges counted separately). An instance has encoding size $m=\Theta(W\log W)$. $\CSAT$: is there $x\in\{0,1\}^n$ with $C(x)=1$? Parameters: $n$ (inputs), $m$ (wires), $w$ (treewidth), $d$ (depth). The target is a bound $T(m,n)$, possibly parameterized, e.g.\ $T\ge 2^{cn}\cdot m^{c'}$.

\section{Proved basic lemmas}
\begin{lemma}[Connectivity floor, \st{PROVED}]
A circuit whose output depends on all $n$ inputs has $g\ge n-1$ gates, hence $W\ge 2(n-1)$ wires.
\end{lemma}
\emph{Proof.} The underlying undirected graph on $n+g$ nodes is connected (every input reaches the output), so it has $\ge n+g-1$ edges; fan-in 2 gives $\le 2g$ edges; hence $2g\ge n+g-1$. \qed

\begin{theorem}[Probe lower bound, \st{PROVED}; model: algorithm accesses the circuit by wire/gate probes]\label{thm:probe}
Every deterministic $\CSAT$ algorithm correct on all instances with $g$ gates makes $\ge g$ probes, even for $n=1$.
\end{theorem}
\emph{Proof.} Family: $g_1=x$, $g_i=\mathrm{AND}(g_{i-1},w_i)$ where $w_i\in\{x,\bar0\!=\!1,0\}$; output $g_g$. The all-$x$ instance is satisfiable. Adversary answers every probe of gate $i$ as ``$w_i=x$''. If gate $i$ is unprobed, replacing $w_i$ by $0$ gives an unsatisfiable instance consistent with all answers. So all gates must be probed. \qed

This is the $\Omega(m)$ ``read the instance'' floor; it is parameter-free in $n$. It is tight up to the encoding model and shows that any lower bound beyond linear must be a \emph{computation}, not an information, bound.

\section{Upper bounds that a lower bound must be compared with \st{KNOWN}}
$T=O(2^n m)$ by enumeration; $T=2^{O(w)}m$ via treewidth DP; $T=O(m)$ if $n=O(1)$. Hence the natural parameterized target is the \emph{dependence on $n$ (or $w$)}: is $T(m,n)\ge 2^{\epsilon n}$? Under SETH no $(2-\epsilon)^n\mathrm{poly}(m)$ algorithm exists for CNF-SAT, hence for $\CSAT$ \st{CONDITIONAL}. Unconditionally, the best known are time--space tradeoffs for SAT (Fortnow--van Melkebeek, Williams; the repository tracks the $n^{2\cos(\pi/7)}$-type exponents and its FLMV box in \texttt{main.tex}); these are not circuit-wire bounds.

\section{Gate-elimination context \st{KNOWN}}
Lower bounds on circuit \emph{size of an explicit function} ($3n-o(n)$ Blum; $\approx 3.01n$ Find--Golovnev--Hirsch--Kulikov) are by gate elimination: fix a variable, delete the gates it kills. They bound wires needed to \emph{compute} $f$, not time to \emph{decide satisfiability}. \st{CANDIDATE bridge}: a $\CSAT$ algorithm that is $o(2^n)$-like on all circuits would yield a circuit family via Karp--Lipton/advice only conditionally; no unconditional bridge is known, and none is claimed here.
