\section{Model and the ladder idea}
Circuits are DAGs of fan-in-2 gates over the full binary basis $B_2$ (all 16 functions); size
$s$ = number of gates; wire count $=2s$ (each gate has two incoming wires; fan-out is free).
For a family $F_k$ of SAT-type functions we track, for growing parameters (variables $n$, clause
width $w$, clause count), (i) the number of input bits $N$, (ii) the best upper bound, (iii) the best
proved lower bound, (iv) exact value when known.

\paragraph{Instance families.} $\mathrm{U}_n$: input bit per \emph{unit} clause over $n$ variables
($N=2n$); output = ``the selected clause set is satisfiable''.
$\mathrm{W2}_n$: input bit per nonempty clause of width $\le 2$ on distinct variables
($N=2n+4\binom n2=2n^2$).  Full circuit-SAT $\mathrm{CSAT}_{n,s}$ takes an encoded circuit.

\section{Proved lower-bound tools}
\begin{lemma}[relevant-input bound, \PROVED]\label{lem:rel}
If $f$ depends on $N$ input bits then every $B_2$ circuit for $f$ has $\ge N-1$ gates
(hence $\ge 2N-2$ wires).
\end{lemma}
\emph{Proof.} The ancestors of the output form a weakly connected DAG containing all $N$ relevant inputs and some $s'\le s$ gates. Connectivity gives $\#\text{edges}\ge\#\text{nodes}-1$, i.e.\ $2s'\ge N+s'-1$, so $s\ge s'\ge N-1$. \qed

\begin{proposition}[ladder rung $\mathrm U_n$, \PROVED]
The $B_2$ size of $\mathrm U_n$ is exactly $2n-1$ (wires $4n-2$).
\end{proposition}
\emph{Proof.} Upper: $\bigwedge_v \mathrm{NAND}(p_v,q_v)$ uses $n+(n-1)$ gates.  Lower:
each of the $2n$ bits is relevant (set $p_v=q_v=1$ and everything else $0$: unsatisfiable;
clearing any one bit restores satisfiability), so Lemma~\ref{lem:rel} gives $2n-1$. \qed

\section{Parametrized view}
For fixed $n$ every size is a constant, so the meaningful statement is a growth law in a
parameter.  Current ledger:
\begin{itemize}
\item \PROVED{} $\mathrm{U}_n$: $\Theta(n)$, exact $2n-1$.
\item $\mathrm W2_n$ ($N=2n^2$ inputs): lower $2n^2-1$ (\PROVED, Lemma~\ref{lem:rel});
upper $O(2^n n^2)$ by assignment enumeration (\PROVED{} construction, $2$-SAT's polynomial
algorithms give a poly upper bound in $N$ that has not been circuit-compiled here).
Closing the gap to the true $\mathrm{poly}(n)$ is a \emph{finite, tractable} next rung; no claim yet.
\item General $k$-CNF / circuit-SAT with parameter $n$ (variables): trivial lower bound linear in
$N$; upper bound $2^n\mathrm{poly}$.  Any \emph{unconditional} bound $\omega(N)$ is \OPEN.
Bounds of the form $2^{\Omega(n)}$ under SETH are \COND{} and not usable here.
\end{itemize}

\section{Known landscape (\KNOWN, recalled from memory, \emph{not} re-verified this run)}
Gate elimination gives $3n-o(n)$ for explicit functions over $B_2$ (Find--Golovnev--Hirsch--Kulikov
$3.011n$; Li--Yang $3.1n-o(n)$); no explicit function is known with $\omega(n)$ size over
$B_2$.  Natural proofs, relativization and algebrization bar the standard routes to
superpolynomial bounds.  A literature search is a TODO for the next run.
