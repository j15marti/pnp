\section{Programme}
Build Circuit-SAT bottom-up. Fix basis $B_2$ (all 2-input gates, free negation). A circuit has $n$ inputs, $g$ gates, $w=2g$ gate-input wires (plus output marker). The parameters are $(n,g,w)$ and later depth/fan-out. For each stage record (i) the minimum number of gates/wires needed to \emph{build} the circuits whose satisfiability is asked, and (ii) a lower bound on the work to \emph{decide} satisfiability, as a function of the parameters.

\section{Stage A: building ledger (COMPUTATIONAL)}
Script \texttt{experiments/claude\_circuitsat/min\_circuit\_size.py} computes by exhaustive closure the exact minimum $B_2$ size $C(f)$ of every $f:\{0,1\}^n\to\{0,1\}$, $n\le 3$ (raw: \texttt{results/raw/claude\_circuitsat/}). Run time a few seconds.

Tracked minimal wire counts: $w_{\min}=2C$ for formulas; the fan-out-aware count is $\ge n+C-1$ distinct signals feeding the output cone (Lemma 1).

\begin{lemma}[Connectivity, PROVED]
If $f$ depends on all $n$ inputs, any fan-in-2 circuit for $f$ has $\ge n-1$ gates and $\ge 2(n-1)$ gate-input wires.
\end{lemma}
\emph{Proof.} The output cone is a connected DAG reaching $n$ input leaves; a fan-in-2 DAG with a single sink and $n$ sources has at least $n-1$ internal nodes (each gate merges at most two components in the undirected spanning argument). Each gate has two input wires. \qed

\section{Stage B: decision lower bound in the read model (PROVED, linear)}
Instance encoding: gate list, each gate $(\text{op},\text{src}_1,\text{src}_2)$; algorithm has random-access read-only input; cost = cells read.

\begin{proposition}[Read lower bound]
Any deterministic algorithm deciding Circuit-SAT on instances with $g$ gates reads at least $g$ gate descriptors on some instance; with parameter $n$ the bound is $\Omega(n+g)$.
\end{proposition}
\emph{Proof.} Take $I_0$: chain $h_i=h_{i-1}\wedge x_{i+1}$, $i=1..g$ ($n=g+1$), satisfiable. If the algorithm leaves descriptor $i$ unread on $I_0$, replace gate $i$ by $h_i=h_{i-1}\wedge\bot$ (constant-0 source). The view is identical but the instance is unsatisfiable, contradiction. So all $g$ descriptors, hence $\ge g=n-1$ cells, are read. \qed

This is the trivial end of the ledger: it shows the \emph{parametrised linear floor} $T(n,g)\ge g$. Gate elimination is the known route beyond (KNOWN: $3n-o(n)$ for explicit functions in $B_2$, Li--Yang STOC'22 improved to $3.1n-o(n)$); those bound circuit size of a fixed function, not the time to decide SAT.
