\section{Goal and model}
Build circuit-SAT instances from the simplest case upward, count wires at each step, and track the best lower bound for \emph{solving} the instance, as a function of parameters $(n,s)$: $n$ inputs, $s$ gates.
Basis $B_2$ (all 16 binary gates, so negation is free), fan-in 2, fan-out unbounded. A circuit with $s$ gates has exactly $w=2s$ gate-input wires; the fan-out sum equals $w$.
$\CSAT(n,s)$: given such a circuit $C$, decide $\exists x\in\{0,1\}^n: C(x)=1$.

\section{Rung ledger}
\paragraph{Rung 0 (dependence).} 
\begin{lemma}[PROVED/EXACT]\label{lem:conn}
If $f$ computed by a $B_2$ circuit depends on all $n$ inputs then $s\ge n-1$ and $w\ge 2(n-1)$. Both are tight for $\mathrm{AND}_n,\mathrm{XOR}_n$ (balanced tree).
\end{lemma}
\begin{proof} Each essential input has a path to the output, so the undirected circuit graph (vertices: $n$ inputs $+\,s$ gates) is connected on the vertices used; it has $w=2s$ edges, hence $2s\ge n+s-1$. \end{proof}

\section{Lower bounds on solving $\CSAT(n,s)$}
\begin{lemma}[PROVED/EXACT: black-box model]
Any algorithm with only oracle access to $x\mapsto C(x)$ needs $2^n$ queries (deterministic worst case) to decide $\CSAT$. 
\end{lemma}
\begin{proof} Adversary answers 0 until one point is unqueried; that point may be the unique satisfier. \end{proof}
Quantum analogue $\Omega(2^{n/2})$ is the BBBV theorem (KNOWN THEOREM, recalled). This model is \emph{irrelevant} to P vs NP: a white-box algorithm sees the wires.

\begin{lemma}[PROVED/EXACT: wire-probe model]\label{lem:probe}
Let an algorithm access $C$ only by probing the label of a given leaf wire. On AND-trees with $n$ leaves, every deterministic correct algorithm probes all $n$ leaves in the worst case.
\end{lemma}
\begin{proof} $I_0$: leaf $i$ is literal $x_i$ (SAT). $I_{1,p,q}$: leaf $p$ replaced by $\neg x_q$, $q\ne p$ (UNSAT, since $x_q\wedge\neg x_q$). An algorithm that skips leaf $p$ cannot separate $I_0$ from $I_{1,p,q}$. \end{proof}
This gives $\Omega(w)$ (linear-in-wires) and nothing more; it is consistent with the fixed-width acquisition bound in root \texttt{main.tex}.

\paragraph{Parametrized shape.} The unconditional picture so far: $T(n,s)\ge \Omega(s)$ (white-box), $T\ge 2^n$ (black-box). Upper bound $O(2^n s)$ by brute force. The gap between $\Omega(s)$ and $2^{\Omega(n)}$ is the whole problem. CONDITIONAL: under SETH, no $2^{(1-\varepsilon)n}\mathrm{poly}(s)$ algorithm for $\CSAT$ (standard formulation; CNF-SAT$\le$CSAT trivially). Any parametrized statement ``$T(n,s)\ge f(n)\cdot s$'' is OPEN.

\section{Circuit-size lower bounds as a side ladder}
KNOWN THEOREMS (recalled, to be re-checked against primary sources next run): (i) the classical gate-elimination bound for $B_2$ is $2n-O(1)$ (Schnorr; Paul) for explicit functions (not $\mathrm{XOR}_n$, which costs $n-1$), improved to about $3.1n$ (Find--Golovnev--Hirsch--Kulikov; Li--Yang). Circuit-\emph{size} lower bounds for explicit functions are not circuit-SAT \emph{time} lower bounds; the link is only via the encoding of a hard function into the instance, which yields no time bound against white-box solvers. Classification: ANALOGY; missing bridge: an unconditional white-box theorem.
