\section{Theorem 1 (every wire is critical)}
\begin{theorem} Let $C_n$ be the AND-chain: $g_1=x_1\wedge x_2$, $g_i=g_{i-1}\wedge x_{i+1}$, output $g_{n-1}$. It is satisfiable, and cutting any one of its $2(n-1)$ wires to constant $0$ makes it unsatisfiable. Hence any algorithm (deterministic, or randomized with error $<1/2$ up to factor) deciding Circuit-SAT from the wire list must read $\Omega(m)$ wires: an unread wire can be replaced by the adversary.\end{theorem}
\begin{proof} Only $x=1^n$ satisfies $C_n$, and every wire lies on the path to the output, so setting it to $0$ forces output $0$. A deterministic algorithm that skips wire $w$ gives the same answer on $C_n$ and $C_n$ with $w$ cut, which differ in satisfiability. \end{proof}
Computational check for $n\le 8$: \texttt{research/agents/claude/circuitsat/verify\_chain.py}.
\emph{Limit:} this is a linear input-reading bound, the trivial ceiling of the method; it says nothing about $2^n$.

\section{Parametrized view}
A bound $T(n,s)$ can be superlinear only via structure: (a) fan-out/reuse (many wires per input), (b) depth. Candidate next step: for $n$ inputs and circuits where every input has fan-out $\ge d$, compute the minimal wires needed for a SAT-hard family and test whether any exact resource measure (e.g.\ the time--space tradeoffs of the repo's ARC/FLMV spine, ledger rows L13, L34) gives $\omega(s)$ in the parametrized regime $n=\Theta(\log s)$ (where brute force is polynomial, so no superpolynomial bound can hold; this regime is a sanity control).
