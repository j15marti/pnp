\section{Setup}
Circuit: DAG over $n$ inputs, fan-in-2 gates (any of the 16 binary functions, negation free), one output.
\emph{Connections} $w$ = number of gate-input wires $=2g$ for $g$ gates. Circuit-SAT$(C)$: $\exists x\; C(x)=1$.
Parameters: $n$ (inputs), $g$ (gates), $k$ (treewidth). A lower bound is a function $L(n,g,k)$.

\begin{prop}[Dependence bound]\label{p1}
If a fan-in-2 circuit's output depends on all $n$ inputs then $g\ge n-1$ and $w\ge 2(n-1)$.
\end{prop}
\begin{proof} Every input has a directed path to the output, so the underlying graph restricted to inputs and
gates is connected with $n+g$ vertices; each gate has two in-edges, so $2g\ge$ edges $\ge n+g-1$, giving $g\ge n-1$. \qed
\end{proof}

\section{Parameterized view}
\begin{itemize}
\item Upper bound: $O(2^n\,g)$ time, KNOWN. Treewidth-$k$: $2^{O(k)}\mathrm{poly}(g)$ by DP, KNOWN.
\item \textbf{Black-box (query) lower bound.} PROVED/EXACT, trivial: an algorithm that only evaluates $C$ on points needs $2^n$ evaluations in the worst case (adversary answers 0 until one point remains; hiding the unique satisfying input).
This model excludes reading the wiring, so it does not bound general algorithms; the gap between it and the wire-reading model is the whole difficulty.
\item Reading bound: $\Omega(g)$ time just to read the instance, PROVED/EXACT.
\item CONDITIONAL: SETH implies no $2^{(1-\epsilon)n}\mathrm{poly}(g)$ algorithm; ETH implies no $2^{o(k)}$ in treewidth. Not unconditional.
\item Unconditional general-circuit lower bounds on explicit functions remain linear ($\approx 3.1n$ gates, from memory, not re-verified this run), KNOWN; far from needing super-polynomial.
\end{itemize}
