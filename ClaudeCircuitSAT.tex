\section{Model}
A circuit has $n$ inputs and $g$ binary gates (any of the 16 two-input functions; negation free), unbounded fan-out, one output. Wires $=$ gate input connections $=2g$. $\mathrm{CSAT}[n,g]$: given $C$, is there $x$ with $C(x)=1$? Parameters of interest: $n$, $g$, and later width/pathwidth.

\section{Wire counting}
\begin{thm}[cone bound] If the output of $C$ depends on $k$ inputs and the relevant cone has $g'$ gates, then $g'\ge k-1$ (so $\ge 2(k-1)$ wires), and $k\le g+1$.\end{thm}
\begin{proof} Take the cone: $k+g'$ nodes, $2g'$ wires (edges). The cone is connected as an undirected graph (every node reaches the output), so $2g'\ge k+g'-1$, i.e.\ $g'\ge k-1$. A function depending on an input needs a path from it to the output, so each relevant input lies in the cone; hence $k\le g'+1\le g+1$. \end{proof}
Equality: $\mathrm{AND}$ of $k$ literals uses $k-1$ gates, a tree.

\section{Parametrized black-box bound}
Black-box: the algorithm sees $C$ only through queries $x\mapsto C(x)$.
\begin{thm}\label{t2} Let $k=\min(n,g+1)$. Every deterministic black-box algorithm deciding $\mathrm{CSAT}[n,g]$ needs $\ge 2^{k}$ queries in the worst case; every randomized one with error $\le1/3$ needs $\ge 2^{k-1}$.\end{thm}
\begin{proof} Hard family: for $S\subseteq[n]$, $|S|=k$, $a\in\{0,1\}^S$: $f_{S,a}(x)=[x|_S=a]$, computed with $k-1\le g$ gates; compare with the constant-0 circuit. \emph{Deterministic:} the adversary answers 0. After $q<2^k$ queries, fix any $S$; each query kills exactly one $a$, so some $f_{S,a}$ is consistent with all answers, as is the constant 0; the algorithm cannot decide. \emph{Randomized:} take $S$ fixed, $a$ uniform. Any single query hits $a$ with probability $2^{-k}$ regardless of earlier answers, so $q$ queries hit w.p.\ $\le q2^{-k}$. Without a hit the transcript equals that of constant 0, so $\Pr[\text{accept}\mid\text{no hit}]\le1/3$ is forced; acceptance on the needle w.p.\ $\ge2/3$ needs $\Pr[\text{hit}]\ge1/2$, i.e.\ $q\ge2^{k-1}$ (Yao).\end{proof}
\begin{thm}[ladder form] The black-box query complexity of $\mathrm{CSAT}[n,g]$ lies between $2^{k-1}$ (randomized) and $2^{n}$.\end{thm}
\begin{proof} Lower bound: Thm~\ref{t2}. Upper: query all $2^n$ points (for $g+1<n$ the Remark improves it).\end{proof}
\begin{lem}[Remark 3, KNOWN] A circuit with $g$ gates is a junta on $\le g+1$ coordinates (Thm 1), and a satisfiable junta is hit by any $(n,g+1)$-universal set, so $2^{g+1}(g+1)^{O(\log g)}\log n$ queries suffice deterministically (Naor--Schulman--Srinivasan 1995, universal sets; citation from memory, to verify). So for $g<n-1$ the black-box bound is tight up to $g^{O(\log g)}\log n$.\end{lem}
\textbf{Reading.} The parameter that governs black-box cost is the \emph{number of wires} $2g$: cost $2^{g+1}$ up to the cap $2^n$. Each added wire pair (one gate) at most doubles the needle search space, and the needle shows this doubling is forced when the algorithm cannot read the circuit.

\section{Why this is not a Circuit-SAT lower bound, and where to push}
Circuit-SAT hands the algorithm the wiring. White-box upper bounds: $2^{k}\cdot g$ via junta reduction; $2^{O(\mathrm{pw})}g$ for pathwidth $\mathrm{pw}$. Lower bounds on these are only SETH-conditional (SAT in $2^{(1-\epsilon)n}$ poly$(g)$ would refute SETH; pathwidth-tight conditional bounds are in the literature, citations to verify). The repository ledger (\texttt{research/agents/claude/world-ledger}, rows L13, L34--L40) shows alternation-trading and one-tape routes cannot give more than limited exponents; the black-box ladder above is consistent with, and does not circumvent, those barriers (black-box bounds relativize).
