\section*{0. Executive status}
\textbf{No unconditional super-linear lower bound for an NP-complete circuit-SAT problem is proved here. P versus NP remains OPEN.}
This document tracks a \emph{ladder}: start with the smallest circuit families, add inputs one at a time, and record (i) the exact minimum gate/wire count of the relevant function, and (ii) which general lower-bound technique (gate elimination, cut-width, \dots) explains the number. Everything is labelled by strict status.

\section{Model and ladder}
Circuits: DAGs over $B_2$ (all 16 two-input gates), fan-in 2, unbounded fan-out. Size $s(f)$ = number of gates; \emph{wires} $w=2s$ gate-input edges (plus output). Parameters tracked per step: $n$ inputs, $s$ gates, \emph{cut-width} $\kappa$ (max wires crossing a topological prefix cut), \emph{fan-out profile}.

Two distinct objects must not be conflated:
\begin{enumerate}
\item \textbf{Function lower bounds} $s(f_n)$ for an explicit family (e.g.\ the SAT-verifier $V_{n,m}(\text{formula},x)$). Non-uniform; the best unconditional bound for an explicit function in $B_2$ is $3.1n-o(n)$ (Li--Yang, STOC 2022) [KNOWN THEOREM, quoted not re-proved].
\item \textbf{Algorithm lower bounds} for deciding $\exists x\,C(x)=1$ given $C$. Black-box ($C$ as oracle) needs $2^n$ queries (relativised only); white-box bounds are exactly P vs NP [OPEN]. The parametrised view is the only place where unconditional statements are plausible (Section 4).
\end{enumerate}

\section{Proved elementary rungs}
\begin{prop}[connectivity; PROVED/EXACT, standard] If $f:\{0,1\}^n\to\{0,1\}$ depends on all inputs, every $B_2$ circuit for $f$ has $\ge n-1$ gates and the underlying undirected graph is connected, so $\ge 2(n-1)$ gate-input wires.\end{prop}
\begin{prop}[fan-out forcing; PROVED/EXACT, standard] If $f$ is not a read-once formula function (e.g.\ MAJ$_3$), any circuit has an input of fan-out $\ge2$ or a gate of fan-out $\ge 2$, so $s(f)\ge n$.\end{prop}
(Both are classical; included to fix the ladder's base.)

\section{Parametrised direction (the likely home of a real bound)}
\begin{itemize}
\item \textbf{Upper bound / tractability} [KNOWN THEOREM]: Circuit-SAT on circuits of treewidth (or cut-width) $\kappa$ is solvable in $2^{O(\kappa)}\cdot\mathrm{poly}$. Any lower bound for an NP-complete circuit-SAT family therefore \emph{must} be stated as: hard instances need $\kappa=\Omega(\text{something growing})$.
\item \textbf{Conditional} [CONDITIONAL on ETH/SETH]: no $2^{o(\kappa)}$ algorithm for treewidth-$\kappa$ CNF-SAT / Circuit-SAT (Lokshtanov--Marx--Saurabh style, SETH $\Rightarrow$ no $(2-\epsilon)^{\mathrm{pw}}$).
\item \textbf{Target statement} [CANDIDATE]: define $\mathsf{CSAT}[\kappa]$; seek an \emph{unconditional} bound of the form: any circuit $D$ (size $S$) that decides $\mathsf{CSAT}[n,\kappa]$ must have cut-width $\ge g(\kappa)$ — a cut-width (not size) lower bound, which gate-elimination-type invariants can address because cut-width is local. OPEN; no proof yet.
\end{itemize}

\section{Barrier ledger}
Relativisation (black-box $2^n$ is not a white-box bound) -- applies to any query-counting argument. Natural proofs: gate-elimination bounds for explicit functions are not natural against the standard PRF assumptions only if they are not large+constructive; we have not yet checked that for any candidate here. Algebrization: not yet audited. All [OPEN audits].
