\section*{Status (read first)}
\textbf{P versus NP remains OPEN.} Nothing here is a superlinear lower bound for Circuit-SAT in any unrestricted model. Labels: PROVED, COMPUTATIONAL, KNOWN, CANDIDATE, OPEN.
The aim is a ladder: start with the simplest circuits, track the wires needed, raise the number of inputs $n$, and record the best honest lower bound at each rung, as a function of parameters $(n,m,w,k)$ = inputs, gates, wires, width (pathwidth/treewidth).

\section{Model}
A circuit $C$ has $n$ inputs and $m$ fan-in-2 gates over $B_2$ (all 16 binary operations; negation free). Wires $w=2m$ (gate-input wires), plus fan-out wires counted by out-degree. Circuit-SAT: is there $x$ with $C(x)=1$?

\section{Rung 0: connection counting (wire ledger)}
\begin{lemma}[PROVED] If a fan-in-2 circuit's output depends on all $n$ inputs then $m\ge n-1$ and $w\ge 2(n-1)$; equality iff the circuit is a tree (formula) with each input used once.\end{lemma}
\begin{proof} The underlying graph must connect the output to all $n$ inputs; a connected graph on $n+m$ vertices has $\ge n+m-1$ edges, while it has exactly $2m$ edges into gates, so $2m\ge n+m-1$.\end{proof}
So every $n$-input SAT instance whose answer depends on all variables has a $\Theta(n)$ wire floor; this is the trivial ``must read all inputs'' bound.

\section{Rung 1: probe lower bound (adversary)}
Model: the algorithm sees $n,m$ and learns gate $g_i$'s type and two input pointers only by probing $i$.
\begin{theorem}[PROVED] Every deterministic algorithm deciding Circuit-SAT in this model needs $\ge m$ probes, for every $m$ (with $n=m+1$).\end{theorem}
\begin{proof} Base circuit $C$: $g_1=x_1\wedge x_2$, $g_i=g_{i-1}\wedge x_{i+1}$, output $g_m$; satisfiable (all ones). The adversary answers every probe according to $C$. If some $g_i$ is unprobed at halt, let $C'$ replace $g_i$ by the constant-0 gate. $C'$ agrees with $C$ on all probed answers (probing $g_{i+1}$ reveals only its pointer to $g_i$) but is unsatisfiable, so the output is wrong on one of them.\end{proof}
This rung is linear in the circuit size and uses only the encoding; it is a representation bound, not computational hardness.
