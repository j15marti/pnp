\section{Goal and parameters}
CircuitSAT$(n,m)$: given a fan-in-2 circuit $C$ with $n$ inputs and $m$ gates (so $2m$ input pins/wires), decide $\exists x\;C(x)=1$.
Lower bounds are sought as functions $T(n,m)$ (parametrized). Known upper bound (KNOWN): $O(m\,2^n)$ by exhaustive evaluation.

\section{The ladder}
Level $L_k$: all circuits on $k$ inputs. Track $g_k(f)$, the minimum number of 2-input gates (basis $B_2$, all 16 binary functions) computing $f$, and $w_k=2g_k$ pins.

\begin{theorem}[Connectivity floor, PROVED/EXACT]
If $f$ depends on all $n$ inputs, any fan-in-2 circuit for $f$ has $\ge n-1$ gates and $\ge 2(n-1)$ wires; formulas that are trees meet this.
\end{theorem}
\begin{proof}
Each input must have a directed path to the output, so the underlying graph of the cone is connected with $n+g$ vertices (inputs and gates), hence $\ge n+g-1$ edges. Edges $=2g$ gives $g\ge n-1$. \qed
\end{proof}

\section{Lower bounds for solving}
\begin{theorem}[Encoding-read bound, PROVED/EXACT, trivial]
Any deterministic algorithm for CircuitSAT in the random-access model must read $\Omega(m)$ gate descriptions, even for $n=1$.
\end{theorem}
\begin{proof}
Take $m/3$ blocks $b_i=x\wedge\neg x$ OR-ed together (unsatisfiable). Replacing the NOT gate of any single block by identity makes that block, hence $C$, satisfiable. An algorithm skipping a block's gate cannot distinguish the two circuits. \qed
\end{proof}
Hence $T(n,m)=\Omega(m)$ unconditionally, against the upper bound $O(m2^n)$. The open parametrized question is the $2^n$ factor.

\begin{lemma}[CONDITIONAL]
Under SETH, no $2^{(1-\varepsilon)n}\mathrm{poly}(m)$ algorithm exists for CircuitSAT (CNF-SAT is a special case). This is a parametrized lower bound relative to a hypothesis, not unconditional.
\end{lemma}

\item Wire-count bounds for explicit functions are the circuit-lower-bound regime; best known for $B_2$ is about $3.1n$ gates (KNOWN THEOREM, Li--Yang 2022), far from superlinear. Any ladder claim beyond that for an NP function would be a breakthrough and should be checked against natural-proofs and relativization barriers.
\end{itemize}

\section{Open arrows and next steps}
\begin{enumerate}
\item OPEN: exact $\max_f g_n(f)$ for $n=4,5$ (SAT-based exact synthesis; keep each run $<30$ s, chunk by gate count).
\item OPEN: define a \emph{search-side} wire measure: minimum number of wires an algorithm must inspect to certify UNSAT for a fixed circuit, as a function of $n$ and $m$; compare with the Theorem~2 $\Omega(m)$.
\item CANDIDATE: parametrize by treewidth $k$ of the circuit; upper bound $O(m\,2^k)$ (KNOWN); seek a matching lower bound under SETH-type hypotheses.
\item CANDIDATE: relate the ladder's wire excess $g_n^{\max}-(n-1)$ to hardness of the hardest instance on $n$ inputs.
\end{enumerate}
