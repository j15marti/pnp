\section{Program}
Ladder: for $n=1,2,3,\dots$ inputs, track the exact minimum number of gates/wires needed to
build circuits (fan-in-2 basis $B_2$, free negation), and the resulting lower bound on
deciding satisfiability of an instance of that size, as a parametrized bound in
$(n,m)$ = (inputs, gates).

\section{Proved rungs}
\begin{prop}[Connectivity floor, PROVED/EXACT]
A fan-in-2 circuit whose output depends on all $n$ inputs has $\ge n-1$ gates and
$\ge 2(n-1)$ gate-input wires.
\end{prop}
\begin{proof} Each gate has two in-wires; the undirected graph on $n$ inputs and $g$ gates must connect
every input to the output, giving $\ge n+g-1$ edges in a connected graph, while a tree cone
with $n$ leaves of fan-in 2 has $n-1$ gates; each gate contributes 2 in-wires so wires $=2g\ge 2(n-1)$.
(Fan-out $>1$ only adds wires.)\end{proof}

\begin{prop}[Read-everything bound for Circuit-SAT, PROVED/EXACT, query model]
Any deterministic algorithm that decides satisfiability of a circuit given as a gate list of $m$ gates
must probe $\Omega(m)$ description cells in the worst case.\end{prop}
\begin{proof} Take $C$ = AND-tree over $m+1$ distinct leaf variables (SAT). Altering any single leaf
$x_i$ to a negated copy of a sibling leaf $x_j$ (or an AND with $\neg x_i$ on an unprobed gate) makes
the output unsatisfiable; an algorithm skipping a cell cannot distinguish. Thus every cell on a leaf path must be read.\end{proof}
So parametrized: $T_{\rm SAT}(n,m)=\Omega(m)$ unconditionally (trivial); $\Omega(m)$ is the only unconditional
bound on the ladder so far. \textit{Caveat:} the sibling-negation argument is a sketch; a careful version should fix
the encoding (to do next run).

\section{Parametrized conditional ceiling (CONDITIONAL)}
Under SETH, Circuit-SAT on $n$ inputs and $m$ gates requires $2^{(1-\varepsilon)n}\mathrm{poly}(m)$
for every $\varepsilon>0$; ETH gives $2^{\delta n}$ for $m=O(n)$-size CNF instances. Upper bound: brute force $O(2^n m)$.
These are CONDITIONAL, not part of an unconditional chain.
