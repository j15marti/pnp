\paragraph{Status.} \textbf{P versus NP remains OPEN.} Nothing here is a super-polynomial
lower bound for Circuit-SAT. This document is a step-by-step ledger of what \emph{can} be proved
about wires/gates/inputs as $n$ grows, with strict labels (PROVED/EXACT, KNOWN THEOREM,
COMPUTATIONAL, CONDITIONAL, CANDIDATE, OPEN).

\section{Model}
A circuit $C$ over inputs $x_1..x_n$ is a DAG of fan-in-2 gates from the full binary basis $B_2$
(negation free). $|C|$ = number of gates; \emph{wires} $=2|C|$ (gate input edges) plus the output.
$\mathrm{CSAT}$: given $C$, is there $x$ with $C(x)=1$? Two quantities are tracked per step $n$:
\begin{itemize}
\item $\mu(n)$ = minimal wires needed to build a circuit whose satisfiability genuinely depends on all $n$ inputs;
\item $T(n)$ = lower bound on the work (here: wire reads, parametrized by $n$, $s=|C|$) to decide CSAT.
\end{itemize}

\section{Step ledger}
\subsection*{Step 0--1 ($n\le 1$)}
Output is a constant, an input or its negation: 0 gates, 0 wires. Decision needs $\Theta(1)$ reads.

\section{Proved general statements}
\begin{lemma}[Connectivity / wire floor]\label{lem:conn}
If $f$ has $m$ essential inputs, every fan-in-2 circuit for $f$ has $\ge m-1$ gates and $\ge 2(m-1)$ wires; the AND-tree attains it.
\end{lemma}
\begin{proof} An essential input must have a directed path to the output. In the subgraph of gates lying on such paths
with $g$ gates, the number of distinct source nodes reaching the output is at most $g+1$ (induction: each gate merges
at most two cones). So $m\le g+1$. The balanced AND tree uses exactly $m-1$ gates. \end{proof}
Status: \PR. This fixes $\mu(n)=2(n-1)$.

\begin{theorem}[Wire-reading bound for CSAT]\label{thm:read}
In the model where $C$ is accessed by probes ``what feeds gate $g$?'', any (even randomized, zero-error on this family)
procedure that decides CSAT correctly on all circuits with $n$ inputs must make $\ge n$ (deterministically) probes
on the family $\mathcal F_n=\{\mathrm{AND\text{-}tree}(\ell_1,\dots,\ell_n)\}$ with literals $\ell_i\in\{x_i,\neg x_i\}$ plus all
single-leaf rewirings.
\end{theorem}
\begin{proof} Let $C_0=\mathrm{AND}(\ell_1..\ell_n)$ (satisfiable). If a deterministic algorithm leaves leaf $j$ unprobed,
let $C_1$ be $C_0$ with leaf $j$ rewired to the negation of $\ell_i$ ($i\neq j$): $C_1$ is unsatisfiable, and every
probe the algorithm made gives identical answers on $C_0,C_1$, so it errs on one. \end{proof}
Status: \PR\ but weak: it is a \emph{query} bound $\Omega(\text{wires})$, i.e.\ linear in input size, tight, and says nothing about time beyond reading.

\section{Parametrized view}
Parameters: $n$ inputs, $s$ gates, and structural parameters (treewidth $w$, fan-out $\phi$, depth $d$).
\begin{itemize}
\item Upper bounds: $O(2^n s)$ brute force (\KT); $2^{O(w)}\,s$ via dynamic programming over a tree decomposition of the circuit graph (\KT, standard).
So any hard CSAT family must have $w=\omega(\log s)$ (unless $\mathrm P=\mathrm{NP}$-type collapse): treewidth is the natural parameter for \emph{where} hardness must live.
\item Lower bounds: no unconditional super-linear time bound; under SETH, no $2^{(1-\varepsilon)n}\mathrm{poly}(s)$ (\COND). Under ETH, no $2^{o(n)}\mathrm{poly}(s)$ (\COND).
\item Circuit-size lower bounds for explicit functions are linear: best known $\approx 3.1n-o(n)$ in $B_2$ (Li--Yang 2022; \KT, to be re-verified against the primary source in a later run). Our ledger $2(n-1)$ wires vs.\ this shows how far unconditional gate counting is from $2^{\Omega(n)}$.
\end{itemize}
