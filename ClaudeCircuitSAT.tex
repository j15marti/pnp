\section{Model}
A circuit is a DAG of fan-in-2 gates over inputs $x_1..x_n$ with free negation on wires;
$m$ = number of wires $=2g$ for $g$ gates. CIRCUIT-SAT: given the circuit, is there $x$ with output 1?
Algorithms read the description via random access; cost = probes/steps.

\section{Rung A: building cost (connectivity)}
\begin{theorem}[PROVED] A function depending on all $n$ inputs needs $g\ge n-1$ gates, i.e.\ $m\ge 2(n-1)$ wires; tight for $\mathrm{AND}_n$.\end{theorem}
\begin{proof} The sub-DAG reaching the output contains all $n$ inputs and $g'\le g$ gates and is
connected, so its edge count $2g'\ge n+g'-1$, giving $g'\ge n-1$. A balanced tree of ANDs attains it.\end{proof}

\section{Rung B: reading (sensitivity) lower bound}
Let $U_n=\bigvee_{i=1}^n (x_i\wedge\neg x_i)$, unsatisfiable, $m=4n-2$ wires ($2n$ in the gadgets).
\begin{theorem}[PROVED] Any deterministic algorithm correct on all circuits with $\le 4n-2$ wires
(in the model of Sec.~1) must probe $\ge 2n=\Omega(m)$ cells of its input on $U_n$.\end{theorem}
\begin{proof} Toggling the negation bit of any one of the $2n$ gadget wires turns $x_i\wedge\neg x_i$ into
$x_i\wedge x_i$ (or $\neg x_i\wedge\neg x_i$), making the circuit satisfiable. If some such bit is unprobed, the
adversary answers identically on both circuits but the correct outputs differ.\end{proof}
COMPUTATIONAL check: for $n\le 8$ exactly $2n$ single-wire toggles flip satisfiability (matches). This is a
linear, input-size bound only; it says nothing about search hardness.
