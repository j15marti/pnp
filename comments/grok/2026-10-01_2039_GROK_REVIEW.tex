\section*{What is adopted}
\begin{itemize}
\item Global status remains OPEN while any load-bearing arrow is open.
\item REACQ1 is the correct hostile closure for deterministic polynomial selectors
on static readable inputs: if \(y=S(x)\) with \(S\in\mathrm{FP}\), a later
polynomial-time audit can regenerate \(y\) by rerunning \(S\). Generic
STORE-or-REACQUIRE is not a superpolynomial lower bound.
\item ROOT2ADIC1 is standard algebra for the declared orbit. If \(N=p^d-1\) for an
odd prime \(p\), then \(N\) is even, and over \(\mathbb{F}_2\)
\[
z^N-1=(z^{N_0}-1)^{2^\nu},\qquad N=2^\nu N_0,\ N_0\text{ odd}.
\]
Odd-\(N\) ordinary DFT formulas are unreachable on this same realization.
The Hasse-jet identity is an algebra conjugacy, not a runtime lower bound.
\item DIMSUM2,
\[
\rho(H)\ge 1+\dim W_R+\dim U_R,
\]
is a rank lower bound. A same-realization family with
\(\dim W_R+\dim U_R=\omega(m)\) refutes a global \(O(m)\) product-span claim for
that family. It does not, by itself, bound SAT time.
\item BOOL candidates C77--C79 (prime-implicant cardinality, canalizing depth, and
incidence rank-width) remain falsified as general predictors. Schaefer islands,
Gaussian elimination, padding, and representation-relative escapes still apply.
\end{itemize}

\section*{Comments, without strengthening}
\begin{enumerate}
\item The source map in root \texttt{main.tex} lagged the LSPV-1 ownership region.
The owned region already cites RANKTRANS1, LDELEAF1, HASSETEST1, ROOT2ADIC1, and
DIMSUM2, while the source map stopped at SYNCWEDGE1. That is a documentation lag,
not a mathematical contradiction. The living document is updated to cite the newer
owned artifacts. Specialist proof text is left unchanged.
\item Finite nonconstant-leaf batteries that report
\(\dim W=m\) and \(\dim U=\binom{m}{2}\) are computational evidence against an
\(O(m)\) contraction on those instances. They are not an asymptotic theorem, and
the ownership region already says so. RANKTRANS1's small-grid deficiencies when
\(p\) is close to \(h\) are likewise computational. No threshold at the vMS
separation \(h=m^{100}\), \(\Delta=hr\), \(p\ge\Delta^{100}\) is claimed here.
\item Generalized Reed--Solomon codes with small Schur squares block the shortcut
``large field implies maximal square dimension'' for those codes. That is an
analogy until a proved correspondence identifies the binary-labeled, same-shift
SU/Hadamard orbit with a GRS code. Classification for this pass: analogy /
candidate, not a theorem transfer.
\item The surviving spine still has six open arrows: exact source typing, exterior
rank or kernel, same-realization acquisition, reconstruction-exponent accounting,
a nonrelativizing and nonalgebrizing step, and a hierarchy contradiction.
Closing the rank question in either direction would not finish the proof.
\item Relativization, algebrization, and natural-proofs barriers are named in the
project protocol and are not discharged by repeated-root algebra, Hasse jets, or
BOOL indices. Those objects remain inside named models.
\end{enumerate}
