\subsection*{Gap selected}
The T4 report (\texttt{a184133}) and its partner recommendation propose scoring orders by the quotient-effective width
$\lambda(P)-\dim(H_Q\cap U_P)$ with $H_Q=\sum_{i\in Q}\Per(S_i)$. Its first OPEN arrow asks for a guard-aware order with \emph{logarithmic

\subsection*{Setting}
Let $S_1,\dots,S_m\subseteq\F^h$ be finite nonempty explicit dictionaries. Feasibility means $\bigoplus_i s_i=b$ with $s_i\in S_i$. For a cut $P|Q$ let
$T_Q=\sum_{i\in Q}S_i$, and let $\Per(A)=\Stab(A)=\{p: A+p=A\}$. T4 merges two attained prefix syndromes $s,s'$ when $s+s'\in H_Q$.

\begin{proposition}[Target-oblivious merging $=$ stabilizer quotient; \textbf{PROVED}]\label{prop:stab}
For $s,s'\in\F^h$ the following are equivalent:
(i) for every target $b$, $b+s\in T_Q \iff b+s'\in T_Q$;
(ii) $s+s'\in\Stab(T_Q)$.
Moreover $\sum_{i\in Q}\Per(S_i)\subseteq\Stab(T_Q)\subseteq U_Q$, and the first inclusion can be strict.
\end{proposition}
\begin{proof}
The set of targets $b$ with $b+s\in T_Q$ is exactly $T_Q+s$. So (i) says $T_Q+s=T_Q+s'$, that is, $T_Q+(s+s')=T_Q$, which is (ii).
If $p_i\in\Per(S_i)$, then $\sum_i S_i+\sum_i p_i=\sum_i(S_i+p_i)=\sum_iS_i$. If $p\in\Stab(T_Q)$ and $t\in T_Q$, then $p=(t+p)+t\in U_Q$.
For strictness see Lemma~\ref{lem:sep}.
\end{proof}
\noindent So any merge rule that is sound for all targets and tests only the pair $(s,s')$ can merge no more than the $\Stab(T_Q)$-cosets.
$\Stab(T_Q)$ is therefore the ceiling for target-oblivious period quotients, and T4's $H_Q$ is a computable inner approximation to it.
A target-\emph{dependent} merge (at most 2 classes: feasible or not) is the decision problem itself.

\begin{lemma}[Fusion monotonicity; \textbf{PROVED}]\label{lem:fuse}
Replace a run of consecutive blocks $S_j,\dots,S_{j+\ell}$ by the explicit fused dictionary $S'=S_j+\dots+S_{j+\ell}$, keeping one backpointer tuple per element.
Then at every cut that survives (no cut inside the run): (a) the prefix and suffix sumsets, the affine hulls $A_P,A_Q$ and $\lambda(P)$ are unchanged;
(b) the T4 period group grows, $H_Q'\supseteq H_Q$; (c) the number of live quotient states after exact affine suffix pruning does not increase.
Hence the maximum live-state count over cuts does not increase. The fused dictionary has size at most $\prod|S_i|$, and $\Per(S')$ is found with at most $|S'|^2$ exact
membership tests (T4's own procedure). For runs of constant length over polynomial-size dictionaries, this is polynomial. Witness lifting uses the backpointers.
\end{lemma}
\begin{proof}
(a) Sumsets are associative. (b) $\Per(S_j+\dots+S_{j+\ell})\supseteq\sum\Per(S_i)$ by the same argument as in Proposition~\ref{prop:stab}.
(c) The live set at a surviving cut is the same set of actual syndromes, $\{s\in\Sigma_P: b+s\in A_Q\}$. Quotienting by a larger subgroup gives no more classes.
The DP stays exact by T4's induction, since $H_Q'$ is still a period group of $T_Q$.
\end{proof}

\begin{lemma}[Exponential separation; \textbf{PROVED}]\label{lem:sep}
Fix $k\ge1$ and $h=4k+2$. On coordinates $a_j,b_j,c_j,d_j$ (component $j$) and $e,f$, define $R_j=\{0,a_j,b_j,c_j,d_j\}$,
$S_j=\{0,a_j,b_j,a_j{+}b_j,c_j\}$, $T_j=\{0,c_j,d_j,c_j{+}d_j,a_j\}$ (the T3 explicit pair) and $Z=\{0,e,f\}$. Use the block order
$R_1,\dots,R_k,S_1,T_1,\dots,S_k,T_k,Z$ and target $b=\beta+\varepsilon$ with $\beta$ in the component span and $\varepsilon\in\{e,e{+}f\}$. Then:
\begin{enumerate}
\item The instance is YES iff $\varepsilon=e$.
\item $\Per(R_j)=\Per(S_j)=\Per(T_j)=\Per(Z)=0$. At the cut after $R_k$: $\lambda=4k$ and $H_Q=0$. The T4 module (unfused) keeps exactly $5^k$ live states there,
against the bound $2^{4k}$.
\item $S_j+T_j=\F^4$ (component $j$), so $\Per(S_j+T_j)$ is the whole component. With each pair $(S_j,T_j)$ fused, the T4 module keeps
\textbf{one} live quotient state at every intermediate cut, with at most 25 options per fused layer.
\end{enumerate}
\end{lemma}
\begin{proof}
$|S_j+T_j|=16$ was checked by enumeration. The 25 sums cover $\F^4$, and $S,T$ have odd size, so neither has a nonzero period. Hence every component target is reachable,
and feasibility reduces to $\varepsilon\in Z$, which gives (1). For (2): the suffix after $R_k$ spans all component directions and $e,f$. So $A_Q$ is the whole space and pruning removes nothing.
The $5^k$ sums of $R_1,\dots,R_k$ are distinct (direct sum), and $H_Q=\sum\Per=0$. For (3): after the fused groups $G_1,\dots,G_j$, the suffix hull no longer contains the directions of components
$1,\dots,j$. Pruning therefore forces those components to equal $\beta$. Components $j{+}1,\dots,k$ lie in $H_Q'$ and are quotiented away, and the $e,f$ bits are still $0$. That leaves one class.
\end{proof}
\noindent\textbf{Honest scope.} This family is affine-easy: T3 cube closure and component recognition also solve it. The lemma separates two
\emph{quotient rules} of the T4 module. It is not hardness evidence and not a universal speedup. Note that the unfused order $S_j,T_j$ is
also a valid T4 input, so T4's quotient-effective width is \emph{not an invariant of the instance}. It depends on dictionary granularity, which the
partner's proposed order score $\lambda-\dim(H_Q\cap U_P)$ has to fix before comparing orders.

\subsection*{Limits and what remains OPEN}
\begin{itemize}
\item \textbf{OPEN:} a polynomial-time algorithm for $\Stab(T_Q)$ when the suffix is long. $T_Q$ is exponential in size, and membership in $T_Q$ is the NP-complete
syndrome problem (20:51 KST Grok log, via KNOWN THEOREM, Schaefer). The data show that constant-size fusion misses part of the stabilizer.
\item \textbf{OPEN} (the T4 arrow itself): whether every native input admits dictionaries and an order of logarithmic quotient-effective width, even with
the stabilizer ceiling. By Proposition~\ref{prop:stab}, the stabilizer is the best any target-oblivious period quotient can do. A universal success of this route would need a
different mechanism (target-dependent pruning, T3 closure, T2 Lemma B, etc.) whenever $\lambda-\dim(\Stab(T_Q)\cap U_P)$ is large.
\item \textbf{CANDIDATE} recommendation for T4 and coordinator: compute the order score after a deterministic pairwise-fusion pass, using
$\Per(S_i+S_{i+1})$ at $\le|S_i|^2|S_{i+1}|^2$ tests per pair. Report fusion cost separately and include it in the original-$N$ ledger.
\item Guards: as in T4, guard tags must be encoded into the dictionaries \emph{before} fusion and stabilizer computation, because an untagged stabilizer element is not portable.
\end{itemize}
