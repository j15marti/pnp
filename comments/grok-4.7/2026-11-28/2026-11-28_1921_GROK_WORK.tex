\section{Result}
\begin{definition}[Clause-level admission class $\mathcal A_{w,g}$]
Starting from a CNF $F_0$ with $n$ variables and measure $N=\sum_{C}(|C|+1)$, a run applies moves:
(M1) BVE of $v$: replace all clauses containing $v$ by all non-tautological resolvents on $v$;
(M2) gate-based elimination of a defined variable (outputs only resolvents between gate and non-gate clauses);
(M3) one-sided/pure elimination (delete all clauses of $v$ when $v$ occurs in one polarity);
(M4) unit propagation (unit resolution, deleting satisfied clauses);
(M5) deletion of tautologies, duplicates, subsumed clauses;
(M6) exact regional re-encoding: for a clause set $R$ on a scope $W$, $|W|\le w$, and $\emptyset\ne Y\subseteq W$
whose variables occur nowhere else, replace $R$ by any CNF $R'$ over $W\setminus Y$ with $R'\equiv\exists Y\,R$;
(M7) a guard tree of depth $\le g$ (case splits on $\le g$ variables), each leaf run with (M1)--(M6).
The run respects ceiling $L$ if every intermediate formula has measure $\le L$.
\end{definition}
This contains exactly the T2 stricter closure arms (gate arity $\le3$, single-sided, BVE pairs, UP), the
T2/T3/T4 ``exact one-interior resolvent/subsumption recomposition'', and the coordinator's
``width $O(\log N)$ regional table'' moves, with bounded prefix guards.

\begin{lemma}[Simulation; \lab{PROVED}]\label{lem:sim}
If an $\mathcal A_{w,g}$ run under ceiling $L$ on unsatisfiable $F_0$ terminates with $\bot$, then $F_0$ has a
resolution refutation of size at most $2^{g+1}\bigl(N+n\,L\,2^{w+1}\bigr)$.
\end{lemma}
\begin{proof}
Single leaf first. Invariant: every clause $C$ present at time $t$ has a resolution derivation from $F_0$ of some
subclause $C'\subseteq C$. (M1)/(M2): a new clause $r$ is a resolvent of present $p,q$ on $v$; given $p'\subseteq p$,
$q'\subseteq q$, either both contain the pivot literals and their resolvent is $\subseteq r$ (one step), or one of them,
say $p'$, lacks $v$, whence $p'\subseteq r$ (no step). (M3)/(M5) only delete. (M4): unit resolution is (M1)-type.
(M6): each $D\in R'$ is implied by $R$, hence by the subclause set $R''$; let $\rho$ falsify $D$; $R''|_\rho$ is
unsatisfiable on $\le w$ variables, so a complete decision tree gives a tree-like refutation of size $<2^{w+1}$,
which lifts (un-restricting $\rho$) to a derivation of a subclause of $D$ from $R''$. Counting: each clause-creating
move (M1, M2, M4, M6 with $Y\ne\emptyset$) eliminates at least one variable, so there are $\le n$ of them, each adding
$\le L$ clauses (ceiling), each costing $\le 2^{w+1}$ derived lines. At termination $\bot$ is present, so the empty
subclause is derived. (M7): each leaf $\rho_\ell$ gives a refutation of $F_0|_{\rho_\ell}$, which lifts to a derivation
of a subclause of $\neg\rho_\ell$ from $F_0$; resolving these up the guard tree adds $<2^{g+1}$ lines.
\end{proof}

\begin{lemma}[Stall dichotomy; \lab{PROVED}]\label{lem:stall}
Every move in (M1)--(M6) preserves satisfiability-equivalence, and every clause-creating move removes a variable.
Hence a ceiling-respecting run on unsatisfiable $F_0$ either derives $\bot$ within $\le n$ clause-creating moves or
\emph{stalls} (no admissible candidate under $L$).
\end{lemma}

\begin{theorem}[Scoped refusal for $\mathcal A_{w,g}$; \lab{PROVED} by reduction to \lab{KNOWN THEOREM}]\label{thm:main}
Let $G_n$ be $3$-regular graphs on $n$ vertices with edge expansion $e(G_n)\ge \varepsilon n$ and let $T_n$ be
the Tseitin formula with one odd vertex ($N=\Theta(n)$). Fix constants $a,c$ and put $L=N^a$, $w,g\le c\log_2 N$.
For all sufficiently large $n$, \emph{every} $\mathcal A_{w,g}$ run on $T_n$ under ceiling $L$ stalls; equivalently,
every successful run has peak measure $\ge 2^{\Omega(n)}/N^{O(c)}$. The same holds whp for random 3-CNF with
$m=\Delta n$ clauses, $\Delta$ a large constant.
\end{theorem}
\begin{proof}
KNOWN THEOREM (Urquhart 1987, J.\ ACM 34; Ben-Sasson--Wigderson 2001, J.\ ACM 48: width $\ge e(G)$ and
$S\ge\exp(\Omega((W-3)^2/m))$ with $m=3n/2$ variables): every resolution refutation of $T_n$ has size
$2^{\Omega(n)}$. Random 3-CNF: Chv\'atal--Szemer\'edi 1988 (J.\ ACM 35), size $2^{\Omega(n)}$ whp.
Lemma~\ref{lem:sim} gives a refutation of size $\le 2^{g+1}(N+nN^a2^{w+1})=N^{O(1)}$, a contradiction for large $n$;
by Lemma~\ref{lem:stall} the run stalls.
\end{proof}

\begin{corollary}[Answer to the T2 ``Next lemma''; \lab{FALSIFIED} for $\mathcal A_{w,g}$]
The universal statement ``explicit gate/one-sided/resolution/regional ($w=O(\log N)$) candidates always yield a
productive contraction under a fixed polynomial ceiling'' is FALSIFIED: expander Tseitin (and random 3-CNF) is a
growing family defeating precisely this admission class. The T2 finite stall (JOINT 0 events, RANDOM 1 event) is
thereby upgraded from a measured stall to a proved asymptotic refusal for this class.
\end{corollary}

\begin{remark}[Positive side; \lab{KNOWN THEOREM}]
If the variable-interaction graph has an elimination order of induced width $w^*$, DP along it (Davis--Putnam 1960;
directional resolution, Dechter--Rish 1994) keeps every clause on $\le w^*+1$ variables, so the measure stays
$\le n\,3^{w^*+1}(w^*+2)$; with $w^*=O(\log N)$ this is a polynomial ceiling. So the class succeeds on
bounded-induced-width families and is refused on expanders: the ceiling is \emph{not} the binding constraint;
interaction-graph width/expansion is.
\end{remark}

\subsection*{Limits (what is not covered)}
\begin{itemize}
\item \textbf{Affine/GE moves are excluded.} Tseitin is solved in polynomial time by Gaussian elimination, so
expander Tseitin does \emph{not} defeat a hybrid class with exact GF(2) lanes (which the repository has). For a
resolution+GE hybrid, random 3-CNF is the natural candidate, but general Res($\oplus$) lower bounds are
\textbf{OPEN} (only restricted, e.g.\ regular/bounded-depth Res($\oplus$), lower bounds are known).
\item Extension variables (fresh defined variables) give extended resolution; no lower bound known; excluded.
\item Guards of depth $\omega(\log N)$ or regional scopes of width $\omega(\log N)$ break the polynomial simulation.
\item The theorem refuses one admission class; it is not a lower bound for SAT algorithms. P vs NP stays OPEN.
\end{itemize}
