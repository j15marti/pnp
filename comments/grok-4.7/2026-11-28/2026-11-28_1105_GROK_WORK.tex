\section{Gap tackled: bounded-boundary exact min-cost buckets (T3-07 NEXT)}
\subsection{Setting}
Let $F$ be a CNF on variables $V$ ($|V|=n$) with primal graph $G$: $u\sim v$ iff some clause
contains both. A \emph{min-sum bucket step} on $v$ with current factor set $\mathcal F$
(nonnegative integer cost tables, initially one violation indicator per clause) does
three things. It removes the bucket $\mathcal F_v$ of factors whose scope contains $v$.
It sets the boundary $\partial v=\bigcup_{f\in\mathcal F_v}\mathrm{scope}(f)\setminus\{v\}$.
It adds the single table $g_v(y)=\min_{x_v}\sum_{f\in\mathcal F_v}f(y,x_v)$ on $\partial v$,
with arg-min reverse map. T3-07's NEXT asks for this step restricted to $|\partial v|\le w$.

\begin{lemma}[Exactness; \lab{KNOWN THEOREM}: bucket elimination, Dechter 1999]\label{lem:exact}
After any sequence of min-sum bucket steps, $\min_x\sum_{f\in\mathcal F}f$ equals the
original minimum number of violated clauses, and the reverse maps rebuild a minimizer. If
all variables are eliminated, the constant left over is that minimum. So $F$ is UNSAT iff
the constant is $\ge1$.
\end{lemma}
\noindent This is the cost-preserving replacement T3-07 asks for, in place of unweighted
resolvents (its pivot lemma's $\min(P,Q)$ is the special case of a single bucket of
clauses). Code part B confirms it on 40 random 3-CNFs ($n\le14$, $m=\mathrm{round}(4.6n)$):
the constant, the brute-force minimum, and the violation count of the reconstructed
assignment agree in 40/40 cases.

\begin{theorem}[Residual lower bound for bounded-boundary buckets; \lab{PROVED}, elementary]\label{thm:tw}
Fix $w\ge0$. Run any sequence of min-sum bucket steps (any order, any interleaving, any
stopping rule) in which every step has $|\partial v|\le w$. Let $X$ be the eliminated set
and $R=V\setminus X$. Then
\[ \tw(G)\ \le\ \max\bigl(w,\ \tw(G_R)\bigr),\]
where $G_R$ is the primal graph of the residual factor set. In particular, if
$\tw(G)>w$, then $|R|\ge\tw(G_R)+1\ge\tw(G)+1$.
\end{theorem}
\begin{proof}
By induction on the steps, the scope of every current factor is a clique of the filled
graph $\widehat G$. This graph starts at $G$, and when $v$ is eliminated it gains all
edges inside $\partial v$ and loses $v$. Moreover $\partial v$ is exactly the neighbourhood
of $v$ in the current filled graph. The new table's scope is $\partial v$, which becomes a
clique, and conversely every neighbour of $v$ shares a factor with $v$ by the same
induction. Therefore the elimination of $X$ is an initial segment of an elimination
ordering of $G$ in which each $v\in X$ has at most $w$ higher neighbours. After it, the
filled graph on $R$ is exactly $G_R$. Append to $X$ an optimal elimination ordering of
$G_R$, of width $\tw(G_R)$. The whole ordering has width $\max(w,\tw(G_R))$. The width
of any elimination ordering bounds $\tw(G)$ from above (the classical equivalence of
treewidth and elimination width; \lab{KNOWN THEOREM}). Finally, any graph on $|R|$
vertices has treewidth $\le|R|-1$.
\end{proof}

\begin{theorem}[Clause-form analogue for BVE; \lab{PROVED}, elementary]\label{thm:bve}
Run any sequence of DP / bounded-variable-elimination steps in which every retained
resolvent has width $\le w$; omitting resolvents subsumed by retained clauses, as T3-07
does, is allowed. Let $R$ be the set of variables left. If $F$ is UNSAT, then
$\mathrm{w}(F\vdash\bot)\le\max(w,\,3,\,|R|)$, where $\mathrm{w}(F\vdash\bot)$ is the
minimum resolution refutation width. Hence $|R|\ge\mathrm{w}(F\vdash\bot)$ whenever
$\mathrm{w}(F\vdash\bot)>\max(w,3)$.
\end{theorem}
\begin{proof}
Every retained clause is a resolvent of earlier clauses, so it has a resolution derivation
from $F$ in which every line has width $\le\max(w,3)$. A clause subsumed by a retained
clause is a weakening and is never needed. The residual CNF $F_R$ on $R$ is UNSAT, since DP
preserves satisfiability, and has some resolution refutation. Every clause on $|R|$
variables has width $\le|R|$. Concatenating the derivations gives a refutation of $F$ of
width $\le\max(w,3,|R|)$.
\end{proof}

\begin{corollary}[Random 3-CNF; \lab{PROVED} relative to \lab{KNOWN THEOREM}s]\label{cor:rand}
Let $F$ be a random 3-CNF with $n$ variables and $\Delta n$ clauses, with $\Delta$ a
constant above the satisfiability threshold. With probability $1-o(1)$:
\begin{enumerate}
\item[(a)] $\mathrm{w}(F\vdash\bot)\ge\varepsilon n$ for some $\varepsilon=\varepsilon(\Delta)>0$
(\lab{KNOWN THEOREM}: Ben-Sasson--Wigderson, JACM 48 (2001), via Chv\'atal--Szemer\'edi
expansion). By Theorem~\ref{thm:bve}, every width-$\le w$ BVE run with $w<\varepsilon n$
leaves at least $\varepsilon n$ variables.
\item[(b)] $\tw(G)\ge\mathrm{w}(F\vdash\bot)-1\ge\varepsilon n-1$, because DP along an elimination
ordering of width $t$ is a width-$\le t{+}1$ refutation, by the argument of
Theorem~\ref{thm:tw}. Independently, $G$ contains one random edge per clause, so
$\tw(G)=\Omega(n)$ already for $\Delta>1/2$ (\lab{KNOWN THEOREM}: Lee--Lee--Oum, J.\ Graph
Theory 70 (2012): $G(n,c/n)$, $c>1$, has linear treewidth; transfer to the $m$-edge model is
standard and I did not re-derive it). By Theorem~\ref{thm:tw}, every boundary-$\le w$
min-sum run with $w<\varepsilon n-1$ leaves at least $\varepsilon n$ variables, and every
remaining variable has current boundary $>w$ if the run stops only when no step is
admissible.
\item[(c)] A complete exact min-sum elimination must therefore create, for some bucket, a
table on at least $\varepsilon n-1$ boundary variables. With explicit tables, that is
$2^{\Omega(n)}$ entries.
\end{enumerate}
\end{corollary}

\paragraph{Consequence for the obligation (label \lab{FALSIFIED/RETIRED} for this restricted form).}
MIN-COST-RESPONSE with a fixed, or even $o(n)$, boundary cap cannot by itself be the
``universal acquisition'' step on the random family. Each run of it stalls on a
linear-size residual. The same holds for T3-07's accepted BVE rule (width $\le4$,
non-increasing count), which is a special case of Theorem~\ref{thm:bve}. This is a
statement about one named restricted operation. It is not a lower bound for the

lane follows the stall inherits a linear-size residual with large boundaries. For PC-type

\subsection{Limits}
\begin{itemize}
\item The result covers bounded-boundary min-sum tables and width-bounded BVE only. It
says nothing about guarded, cross-scope algebraic, F3, matching or flow lanes beyond what
earlier logs proved for PC. In particular the T1 F2+F3 \emph{mixed} hybrid is not a
single-field PC system, and I know of no lower bound that covers it. That stays
\lab{OPEN}.
\item Corollary~\ref{cor:rand} is asymptotic and probabilistic. It makes no claim about the
two pinned finite instances, where $\varepsilon n$ is a small constant.
\item Elimination with $w=\Theta(n)$ is still complete and exact, at $2^{\Theta(n)}$ table
cost. So the obligation is not unsound; it is just not polynomial in this form.
\item Next \lab{OPEN} step: does \emph{guarded} min-sum elimination (branch on $g$
variables, then bounded-boundary buckets) beat Theorem~\ref{thm:tw}? Conditioning on $g$
variables lowers treewidth by at most $g$, so any polynomial-cost version needs
$g=\Omega(n)$ guard variables, i.e.\ an exponential number of leaves unless the leaves
are shared. That is the same branch-credit arrow T4-06 leaves OPEN.
\end{itemize}
