TARGET AND LOGIC
[P1-00] KNOWN THEOREM | Formal target.
P = NP means every language in NP is decidable by a deterministic uniform polynomial-time machine. P subseteq NP is standard. It suffices to show a single uniform polynomial-time decider for a fixed NP-complete language, such as encoded 3-CNF-SAT. The decider must be one algorithm with one fixed polynomial bound on ALL binary inputs of each length, not a per-instance optimizer, nonuniform size-dependent lookup table, or promise-only solver.
Depends: standard Cook-Levin/Karp NP-completeness results. Evidence: Cook (1971), Levin (1973), Karp (1972).
Gap: NONE for this standard logical equivalence.

[P1-01] OPEN | Construct a general deterministic SAT decider A.
Required quantifiers: EXISTS a fixed finite program A, constants c>0 and integer k, FOR ALL binary strings x, A halts with the correct encoded-CNF SAT/UNSAT/malformed classification and T_A(x) <= c(|x|+1)^k. A may use branching, learning, shared DAGs, GF(2), algebra, preprocessing, adaptive heuristics and extensions, but must pay real machine costs.
Evidence required: executable or formal machine plus a proved all-input correctness and worst-case runtime theorem. Finite benchmarks, specialized families and hypothetical oracle calls do NOT close the node.
Owner: LSPV-2 for algorithmic constructions, LSPV-4 for resource charges; LSPV-1 audits quantifiers; LSPV-5 red-teams.
Next falsifier: give a single legal input family escaping a proposed uniform runtime/correctness bound.

[P1-02] KNOWN THEOREM | Reducing arbitrary NP verification to the chosen SAT encoding.
For any language L in NP and input x, construct an instance f_L(x) of 3-CNF-SAT in polynomial time and polynomial encoded length such that x in L iff f_L(x) is SAT. A fixed all-input polynomial 3-SAT decider would thereby decide each L in P.
This is a decision reduction. It does NOT imply any proof-size lower-bound preservation when converting a known hard CNF family to 3-CNF.
Owner: LSPV-1. Gap: NONE for standard NP completeness; document concrete encodings for any proposed new algorithm.

[P1-03] OPEN | Prove both-label correctness, source interpretation, and totality for A.
Specify the exact input parser and handling of malformed encodings; prove SAT outputs are true and UNSAT outputs exclude all assignments. A rejecting computation trace alone is not proof of UNSAT without the correctness theorem for the machine. Every heuristic or subroutine must be shown sound on every input.
Owner: LSPV-1 with LSPV-3 certificate audit and LSPV-5 adversarial checks.
Dependencies: P1-01. Missing: actual candidate uniform A and full proof.

[P1-04] OPEN | Fully charged runtime/space theorem for the SAME A.
Count parsing, input/index/head reads, branching decisions, failed policies, repeated work, learning and clause storage, conversion, verification, all-phase simultaneous peak memory, output, and final classification. A small ideal proof DAG or a short semantic description is not a physical runtime bound. The time exponent must hold for all inputs, not just known hard-family instances.
Owner: LSPV-4; LSPV-2 implementation. Dependencies: P1-01 and P1-03.

[P1-05] CONDITIONAL | Consequences of a correct polynomial-time SAT decider.
If P1-01 through P1-04 hold, P=NP follows by P1-02. Standard SAT self-reduction then finds witnesses in polynomial time. SAT in P also implies coNP=P and permits some polynomially bounded Cook-Reckhow proof system for UNSAT. None of these consequences is a construction of the decider. In particular, a polynomially bounded SOME proof system or NP=coNP alone does NOT establish P=NP.
Owner: LSPV-1. Missing: P1-01 through P1-04.

PARTIAL ALGORITHMS AND CONTROLLED SUBCLASSES (NOT A GENERAL P=NP PROOF)
[P1-S1] KNOWN THEOREM | Horn-SAT, 2-SAT and affine/XOR-SAT have polynomial-time algorithms (unit implication, SCC, Gaussian elimination). These are regression controls, not a partition of all 3-CNF inputs into easy classes.
[P1-S2] PROVED/RESTRICTED (project-reported, pending native-checker audit) | Local linear-system 3-CNF encodings admit short declared-semantic mixed AND3/GF(2) refutations. See LSPV-1/452: research/agents/lspv-1/2026-11-06_0911_LSPV1_PROPER3_PARITY_NATIVE_COMPILER452.md. This describes proof existence for affine input families, not a universal polynomial SAT decision method.
[P1-S3] PROVED/RESTRICTED (project-reported) | Specific bounded-separator / original-source block decompositions admit charged, specialized solvers, not an all-input guarantee. See latest LSPV-2 and LSPV-4 reports and issue #3, including LSPV-2/456, LSPV-2/457 (OR-folded moving-frontier SAT calls q <= h*2^w with w <= (log2 N)/10, restricted original strict-3CNF path grammar; separate raw/test evidence), and LSPV-4/453-454. Exact input grammar, connector bounds and resource model must be retained.
[P1-S4] PROVED/RESTRICTED (project-reported) | Affine hulls of arbitrary CNF model sets are computable using at most r+1 SAT-search oracle queries; under SAT in P this yields a polynomial algorithm for the hull. See LSPV-1/432. The negative oracle answers cannot be treated as free authenticated UNSAT proofs, and the result is conditional, not a SAT solver.
[P1-S5] CANDIDATE | Combine known branching, learned clauses, GF(2), decomposition, extensions, reconvergence and shared computation. To promote to P1-01, show ALL inputs are covered and derive a fixed polynomial worst-case cost including acquisition and fallback.
[P1-S6] KNOWN THEOREM / FALSIFICATION CONTROL | Even a correct fast algorithm on an established Resolution-hard Tseitin/PHP family does not imply an all-input polynomial algorithm. Sparse hard instances and empirical performance cannot replace P1-01.
