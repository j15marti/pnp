## 3. Obstacles and collapse

1. **Paid joint preprocessing and matching upper bound.** Every transition used to compute, store, or re-cross for any residual is already included in the whole-run lower bound of the original theorem. The matching O(N^{2})/O(N^{3}) solver authenticates the family, compares the maps once, and caches the single equality bit; subsequent residuals are deterministic functions of that bit and the original blocks and can be generated without additional physical transport of the source maps.

2. **Deterministic whole-run replay.** In the deterministic single-tape model the entire execution path is a deterministic function of the input and the fixed machine. A decoder (or the machine itself) can replay the first transport from the original input blocks, recover any needed intermediate values, and generate the full residual chain within the same charged (or free-access) pass already accounted for. No additional independent obligations are forced.

3. **Free attention and low-dimensional aggregates.** Unlimited poly-dimensional and poly-depth attention can embed and compare the maps via soft weights or aggregate statistics, but verifying exact equality on adversarial (incompressible) maps still embeds the same information-transport requirement in the charged physical layout when the solver must produce a correct decision on every hybrid. The total remains O(N^{2}) / O(N^{3}) CM when the number of residuals is polynomial. Soft statistics do not certify exact equality without retaining or re-accessing the source data.

Consequently both candidates fail the requirement that the obligations remain compulsory after static (or free-local) transport can be completed. The constructions collapse under deterministic replay, paid joint preprocessing, and the existing matching upper bound.

## 4. Revised scope: residual compatibility bottleneck under free resources

The free resources resolve every local fragment (2-SAT, GE, Horn/dual-Horn, local embeddings) but leave the global map-equality as a residual compatibility obligation. On the charged permutation family, incompressible maps still require Ω(N^{2}) time and Ω(N^{3}) cumulative memory for exact decision, because the information must be co-located or transported across the physical cut. Attention (even unlimited poly-dimensional and poly-depth) represents the comparison differently—via embeddings, soft weights, or aggregate statistics—but does not escape the synchronization/compatibility bottleneck for exact decision on adversarial maps. The static ceiling continues to bind; no superpolynomial amplification is obtained from multi-residual chains or attention embeddings that remain functions of a single paid comparison of the source blocks.

A viable DYNAMIC-COMPATIBILITY-OBLIGATION1 must produce obligations whose information is not jointly recoverable from a single paid or free comparison (including path replay) of the source blocks, or must force re-materialization of data that cannot be generated by deterministic replay of the original input (e.g., data whose description depends on an external source outside the deterministic model). Uniform simulation of arbitrary correct machines remains the load-bearing open premise.
