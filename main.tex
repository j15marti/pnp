\paragraph{Newest exact result.}
Let \(A\) be any uniform polynomial-time decider. For every fixed exponent
\(c\), an equivalent wrapper can visit \(N^{c+1}\) distinct counter
configurations and then run \(A\), remaining polynomial time while escaping an
\(N^c\) intensional cap. For every fixed layer \(N_0\) and finite cap
\(B(N_0)\), a uniform wrapper may hard-code the finite exceptional delay
\(B(N_0)+1\) only on that layer and then run \(A\); finite exceptional cost
changes only the machine constant. Thus neither one fixed polynomial cap nor
exact per-layer finite caps contain all polynomial-time equivalent deciders.
Quotienting implementations by their one-bit behaviour makes the domain
extensional, but then nonconstant trace, runtime, memory-layout, and
representation properties are not defined on the quotient.

\paragraph{Consequence for BBTEST1 and conformance transfer.}
BBTEST1 proved that a finite black-box audit misses a one-input trace mutation
outside its query set and proposed a complete fault domain or a density theorem
as the smallest repairs. The finite-domain repair is now closed at
arbitrary-program scope. Chow-style FSM conformance theorems remain valid for
their declared bounded implementation domains; importing that bound to the
union of all polynomial-time ordinary machines is a failed model transfer.
A compiler-image fault domain remains construction-specific and needs an
independent universality theorem.

 L\in\mathsf P
