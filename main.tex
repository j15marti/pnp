\section{Proof spine}
All routes from an arbitrary polynomial-time decider to a superpolynomial lower bound remain \OPEN{}.

The fixed-width implication chain gives the exact base rung: its formula is
UNSAT iff every orientation field is one, and every deterministic exact
field-query decider reads all $q$ orientations on the all-one input.  Under
the declared fixed-width encoding this is an $\Omega(N/\log N)$ word-probe
acquisition bound, not an unrestricted time theorem.

For
\[
F(X,Y)=T(X)\wedge B(X,Y),
\]
where $B$ is 2-CNF, $T$ has at most $k$ clauses of width at most three, and
$X$ is the set of variables occurring in $T$, let $s=|X|\le3k$.
The exact 2-CNF projection $Q_B(X)\equiv\exists Y\,B$ has at most $2s^2$
unit/binary clauses.  One SCC computation plus reachability traversals from
the $2s$ signed boundary literals constructs it in
\[
O((1+s)(n+m)+s^2)=O(k(n+m)+k^2)
\]
word time.  The exact kernel $T\wedge Q_B$ has at most $3k$ variables and
$k+18k^2$ clauses.  This is a restricted upper bound and transport barrier,
not a lower bound.

DENSE-COUPLING-FIREWALL90 gives equal-size 3-coloring labels with source
treewidth exactly $t$ and one-hot-CNF primal treewidth in $[t,3t+2]$, yet a
canonical $O(N/\log N)$ source scan decides the label.  Density, unbounded
treewidth, large syntactic residual, essential constraints, and padding do
not alone force expensive continuation.

AGGREGATION-CEILING91 now closes the independent-composition rung.  For $p$
chain blocks with $q$ orientation fields each and any read-once AND/OR
aggregation tree, a linear-size guarded width-three CNF has the exact aggregate
SAT label, while its deterministic orientation-field complexity is exactly
$pq$.  The proof uses full multilinear degree $pq$.  A constant-overhead map
reaches ordinary proper 3CNF.  However the source already contains $pq$
independent fields and the target length is $\Theta((pq+p)\log N)$, so the
bound is only $\Theta(N/\log N)$ acquisition.  Independent products, disjoint
components, and guarded selectors therefore do not amplify beyond input order.

SHARED-INTERFACE-TABLE92 tests the first explicit shared-interface rung.
For a $J\times 2^h$ feasibility table, the parent label is
\[
\bigvee_{a\in\{0,1\}^h}\bigwedge_{j=1}^J r_{j,a}.
\]
Its exact deterministic orientation-field depth is $J2^h$: the unique
multilinear polynomial contains the full monomial.  A fixed-metadata map to
ordinary proper 3CNF has $\Theta(J2^h h)$ clauses and variables.  This still
does not amplify: the source already contains $J2^h$ fields, paid construction
cost is $\Theta(J2^h h)$, and direct inclusion preserves only input-order
acquisition.  Succinct shared compatibility and all-decider continuation
remain OPEN.

RELATION-ALGEBRA-BOUNDARY93 separates the next succinct relation rung.
Three-valued permutation constraints $x_v=x_u+b\pmod3$ admit exact linear
holonomy normalization on arbitrary graphs, regardless of cycle count or
treewidth.  For arbitrary explicit binary relations, a supplied feedback
vertex set of size $c$ gives an exact $O(3^c(|V|+|E|))$ continuation
algorithm; a cycle plus $h$ chords has $c\le h+1$.  Replacing functional
relations by inequality reaches graph 3-coloring, but this relation-language
inclusion transports no superlinear bound.  The affine source bound is
consumed by linear construction or preserved only at input-acquisition order.

EXCEPTION-KERNEL94 gives the charged interpolation between those endpoints.
After contracting all permutation records, $p$ arbitrary binary-relation
exceptions leave at most $2p$ active three-valued roots.  Taking one endpoint
per exception gives a vertex cover of size $c\le p$, hence an exact
$O(N+3^c p)$-word algorithm with linear peak space.  The one-hot decision
kernel has at most $6p$ Boolean variables and $23p$ clauses of width at most
three.  A matched family forces exactly $p$ relation-field reads, but a direct
$O(p)$ scan matches it, so the bound remains input-order acquisition.

SELECTOR-GRAPH-BOUNDARY95 now makes the domain/structure progression exact.
Arbitrary binary CSP over domain two compiles with at most four binary clauses
per relation and is therefore 2-SAT.  For domain $d$, a forest constraint
graph is solved in $O(ed^2+gd)$ word time, and a supplied feedback vertex set
of size $c$ gives $O(ed^2+gd+d^c(ed^2+gd))$ time with linear peak space.
At domain three, restricting relations to inequality gives graph 3-coloring.
The compatible CNF has $2dg$ variables, $g(d-1)$ genuine ternaries, and at
most $g(\binom d2+2d)+ed^2$ binary clauses.  A two-selector table can force
$d^2$ field reads, but a table scan matches that input-order bound.

PALETTE-SOURCE-CYCLE56 and DEGREE-BOUNDARY96 now sharpen direct inclusion.
The first gives a proper exactly-three-clause family whose parity orientation
records force \(q=\Omega(N/\log N)\) word reads on both labels, with a matching
linear recognizer.  The second locates the exact graph rung: by Brooks,
maximum-degree-three 3-colorability is decided in linear time by detecting
\(K_4\) components, while maximum-degree-four 3-colorability is known
NP-complete.  A \(p\)-block equal-metadata family inside the latter fixed
language forces every exact decider to read \(p=\Theta(N/\log N)\) packed edge
words on its SAT input.  This identity transport avoids construction cost,
but the degree-three scan still matches it in \(O(p)\) time.  Hence direct
inclusion preserves a genuine all-decider acquisition bound and still does
not amplify beyond input order.

HORN-SELECTOR-DEGREE60 and HORN-TRANSPORT-CEILING100 now add the
sharp exact-three occurrence rung.  A source degree bound of three makes
every instance satisfiable by a clause-saturating Hall matching, while the
degree-four canonical Horn-selector language is NP-complete.  For the padded
implication-chain image, flipping orientation $i$ changes exactly two
disjoint target consequent words, so every exact target-query decider reads
$q=\Theta(N/\log N)$ fields on the all-one target.  However explicit
materialization writes $32q+130$ words, giving transport numerator at most
$q-(32q+130)-H<0$.  Direct sensitivity survives; paid transport and any
amplification beyond input order do not.  The chain image is in the
unrestricted canonical language, not the maximum-degree-four sublanguage.

ADAPTIVE-TRAJECTORY-FIREWALL107 adds the required state-dependent correction.
There is a coupled both-label family \(H_{q,b}\) with
\[
 k_0=4(q+1),\qquad h_0=q+1,
\]
where \(h_0\) is the minimum raw strong syntactic 2-CNF backdoor.  A total
uniform exact policy pays to discover source-certified binary resolvents,
propagates them, and reaches \(k_1=h_1=0\) in \(O(q)\) word time.  UNSAT
terminates on an observed conflict; SAT switches to SCC and replays one
witness.  Unsupported states select Horn or exact fallback, with failed
tests and switches charged.  Thus neither initial \(k\), initial \(h\), nor
one fixed rule models every adaptive solver.  The missing invariant must
cover the full paid state trajectory, arbitrary representation changes,
SAT/UNSAT asymmetry and retained cache.

For every proposed reduction, only
\[
T_{\rm new}^{\le}(g(q))\ge
\frac{L_{\rm old}(q)-R(q)-H(q)}{Q(q)\tau(q)}
\]
is justified, and only with a positive numerator.  Linear construction or
recognition consumes the linear chain/direct-sum bound.  Direct inclusion
preserves the same query order but supplies no amplification.
