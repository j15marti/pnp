\section{Current target and exact quantifiers}
For satisfiable encoded formulas, the retained universal-work benchmark is
\[
H(F)=\min_{|p|\le b_0+\lfloor\log_2(|F|+2)\rfloor}
       \bigl(t_p(F)+q(|F|)+1\bigr).                         \tag{1}
\]
Polynomial boundedness of $H$ on all satisfiable inputs is equivalent to
$P=NP$ in the declared project model.  This is a transfer equivalence, not a
lower bound.  Its obstruction has common-input quantifiers: for each budget a
single satisfiable $F$ must defeat every eligible short program.  This differs
from a direct decision-language lower bound, where the hard input may depend on
the algorithm.

The active structured object is
\[
G=(B_Xx=c)\land Q(u,v,x),
\qquad x=a+Lz,
\qquad G\equiv Q(u,v,a+Lz).                                \tag{2}
\]
All parsing, decomposition discovery, Gaussian elimination, circuit access,
candidate testing, reconstruction, verification, and encoded bit length are
charged.  Full source access, arbitrary polynomial workspace, compact circuits,
and input-assisted witness lifting are permitted.

\section{Shortest verified proof map}
\begin{enumerate}
\item \textbf{Affine base---\EXACT.}  A consistent Tseitin system has a
uniform spanning-forest witness algorithm.  Charge incompressibility is not a
barrier.
\item \textbf{Residual contraction---\EXACT.}  For residual edge support
$R$,
\[
\rho=\dim\pi_R\ker B_X
   =|R|+\operatorname{cc}(X)-\operatorname{cc}(X-R),         \tag{3}
\]
with all isolated vertices counted.  Feasible projections form an affine
space of $2^\rho$ points and every point extends in polynomial time.
\item \textbf{Upper-bound escape---\EXACT.}  If $Q$ has no other free
variables, direct search costs $2^\rho\operatorname{poly}(N)$.  With $h$
external Boolean variables the honest bound is
$2^{\rho+h}\operatorname{poly}(N)$.  Thus $\rho=O(\log N)$ is uniformly easy.
\item \textbf{Cotree relocation---\EXACT.}  For a spanning forest $T$ and
cotree $C=E\setminus T$, projection is a polynomial-time witness bijection onto
the free cotree coordinates.  Arbitrary SAT placed there is relocated, not
amplified.
\item \textbf{High-rank nonlinear firewalls.}  Linear projected
rank plus a bounded-weight nonlinear residual is easy.  A paired quadratic
using every cotree coordinate remains easy despite full polar rank.  Even after
a concise dense affine mixing, the candidate selector is: if
\[
q(z)=\bigoplus_i z_{2i-1}z_{2i},\quad Q(y)=[q(Ay+r)=b],       \tag{4}
\]
choose $z=0$ for $b=0$ or $z=e_1+e_2$ for $b=1$, solve
$Ay=z+r$, and lift through the forest.
The first two statements are \EXACT{}; the dense-mixing extension is \CAND{}
pending independent review.
\item \textbf{Amplification---\COND.}  If satisfiable $F_j$ satisfy
$s_{j+1}\le As_j$ and
\[
H(F_{j+1})\ge H(F_j)\,r(s_j)/B,
\qquad r(s)\longrightarrow\infty,                          \tag{5}
\]
for fixed $A,B$, then $H$ is superpolynomial.  No verified construction
supplies (5).
\item \textbf{Unrestricted lower bound---\OPEN.}  No theorem forces every
eligible short program or every uniform decider to pay a superpolynomial cost
for (2), instantiate a preferred representation, or emit a proof-system
certificate.
\end{enumerate}

\section{Barrier and hostile-control ledger}
\begin{itemize}
\item DNNF, PC/PCR, Resolution, pebbling, single-tape, communication, and
expanded-ANF lower bounds do not transfer to unrestricted witness search
without a model-preserving theorem.
\item A successful trace need not represent all models.  Program description
length is not workspace.  A fixed percentage overhead is not a fixed exponent
gap.
\item Horn, dual-Horn, Krom, affine/Tseitin, bounded treewidth, independent
products, padding, renaming, complementation, compact representations,
DEAD/COPY/DELAY, and INTERP/RECOMP remain mandatory controls.
\item A semantic or algebraic oracle defeats purely extensional or algebraic
state-count claims.  The current firewalls relativize and algebrize; no
nonrelativizing hinge is known.  Natural Proofs is not invoked by the current
construction.
\item Cryptographic hardness, ETH, random-oracle assumptions, and average-case
MQ evidence are not unconditional lower bounds here.
\end{itemize}
