A direct fixed-language separation requires every correct total uniform
deterministic decider to fail every polynomial worst-case time bound:
\[
 \forall A\text{ deciding }L\;\forall k\in\mathbb N\;\forall C>0\;
 \forall N_0\;\exists x:\quad |x|\ge N_0,\quad T_A(x)>C(|x|+2)^k.
\]
Hard inputs may depend on the decider. A direct non-P proof for one fixed
NP-complete language needs no extra broadening step. It need not use a
universal source-code compiler or a general circuit lower bound.

No explicit lower-bound function is necessary: refuting the existence of an
arbitrary polynomial decider for this one language suffices. The requirement
still covers every possible correct polynomial-time implementation, not only
our tabular or circuit-elimination program.

The separate common-input UWI benchmark is
\[
 H(F)=\min_{|p|\le b_0+\lfloor\log_2(|F|+2)\rfloor}
                   (t_p(F)+q(|F|)+1).
\]
Polynomial boundedness on all satisfiable inputs is equivalent to P=NP in
the retained model. This is an equivalence, not a lower bound. A common-input
obstruction must defeat every eligible short program on the same satisfiable
input; it is not the preceding algorithm-dependent quantifier.

The active residual is
\[
 G=(B_Xx=c)\land Q(u,v,x),\qquad x=a+Lz,
 \qquad \exists x\,G\iff\exists z\,Q(u,v,a+Lz)
\]
after checking consistency. Parsing, elimination, every remaining free
variable, source access, compact algebra, reconstruction, verification,
output and encoded bit length are charged. Polynomial workspace is allowed;
program description length is not memory.

\paragraph{BINARYPROJ1: polynomial existential elimination of the Boolean interior.}
\CAND{}, complete source-specific proof; independent review pending.
For source lists $A_v\subseteq\{0,1,2\}$, let
$U=\{v:|A_v|=3\}$, $B=V\setminus U$ and $k=|U|$. Empty lists reject.
Encode the one/two choices at each vertex of $B$ as Boolean options and its
internal edges as a 2-CNF $\Phi_B$. If it is unsatisfiable, the source is NO.
For every boundary color event $p=(u=a)$, record its forced interior literals
$\Lambda_p$. In the fixed implication graph of satisfiable $\Phi_B$,
\[
 \Phi_B\land\bigwedge_{\ell\in S}\ell\text{ is unsatisfiable}
 \iff\exists\ell,m\in S:\ell\leadsto\neg m.
\]
Every incompatible collection of forced Boolean literals therefore has a
one- or two-requirement explanation. Construct all corresponding unary/binary
boundary exclusions and retain the original boundary-edge exclusions.
The exact extension relation on every full boundary coloring is thereby
represented with at most $3k+9\binom{k}{2}$ forbidden assignments.
Reachability, path certificates, storage, all source access and output are
polynomially charged. Every accepting boundary assignment lifts through a
constructive 2-SAT solve to the original source and pinned two-tree witness.

The output is a general three-color binary constraint system, not necessarily
a graph with inequality edges. The path $u-x-v$, with $A_x=\{0,1\}$ and full
endpoint lists, excludes only $(u,v)=(0,1),(1,0)$, while accepting equal colors.
No insertion/deletion of an ordinary edge on the same endpoints represents it.
A three-choice center instead produces the old no-rainbow relation, so the
at-most-two-choice hypothesis is essential. The interior 2-SAT need not be
affine, and ROOTGLUE1's Gaussian argument is not silently applied to it.

When $k=O(\log N)$, checking the polynomial kernel over $3^k$ assignments and
lifting one witness is polynomial; for $k=0$ the whole source is 2-SAT.
For general $k$, this is an upper-bound algorithm, not a proof of required
search. Large all-three-choice bipartite instances remain easy. With $B$
empty the construction retains ordinary three-coloring, so the unresolved
semantic problem has not been proved outside P or converted to 2-SAT.

\paragraph{MERGEGUARD1: an exact guarded quotient.}
\CAND{}, complete proof and implementation; independent review pending.
At a variable $x$, merge two allowed values $a,b$ to $M$. The naive incident
relation is their union. For neighbor-value pairs having opposite singleton
supports in $\{a,b\}$, add the guard
\[
 \neg[(x=M)\land(y=c)\land(z=e)].
\]
There are at most $9\binom{n-1}{2}$ guards. They give exactly the image of
the original solution set: nonempty subsets of a two-element set have empty
joint intersection only if two of them are opposite singletons. An accepted
quotient assignment lifts by testing at most two original representatives,
with the rest of the source assignment unchanged. Discovery, guard writes,
source access and full verification are polynomially charged. This extends
the known broken-triangle-free merge by explicit guards; it is not a new
foundational value-merging method. The output can be ternary, so a binary-only
projection theorem cannot silently be reapplied to it.

\paragraph{Global merge safety is an extra problem, not necessary solver work.}
The exact-image safety predicate is coNP-complete on explicit binary
three-color instances. An unsafe witness is a quotient solution whose one or
two original representatives all fail. For hardness take $P_G=G\sqcup K_4$
and merge two colors at one K4 vertex. The source is always NO, while the
quotient has exactly $6|\operatorname{Sol}(G)|$ solutions. Thus safety holds
exactly when $G$ is not three-colorable. This is a complexity classification
of the extra certification service, not a proof that it is outside P and
not a runtime lower bound for $P_G$, whose four-clique is immediately visible.
A decider is not required to find or certify a safe merge. Under P=NP this
coNP predicate could also be polynomially decided without contradiction.

\paragraph{Simultaneous fibers can be checked without materializing all guards.}
Retain the original binary source. A proposed quotient assignment specifies
one block of size at most two at each variable. Booleanize those choices;
each incompatible original pair becomes a 2-clause. Constructive 2-SAT
therefore decides and lifts that one fiber in polynomial time. This does not
find a successful fiber in polynomial time and does not pretend accumulated
ternary guards are binary. In the ordinary graph case, grouping $\{0,1\}$
and $\{2\}$ gives the exact criterion
\[
 S\text{ independent}\quad\land\quad G[V\setminus S]\text{ bipartite},
\]
where $S$ is the set assigned the singleton color. The naive quotient checks
only independence; the all-merged triangle is a false positive. Odd-cycle
exclusions characterize the missing condition but need not all be listed:
one proposed $S$ is checked by graph traversal. Finding some such $S$ is
exactly three-coloring, not a new polynomial algorithm.
