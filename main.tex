\section{Computational Information Value and Reusable Summaries}
\PROVED\ (exact generalized-support frontier; linear persisted summaries).
Let a fixed parity batch have row code \(C\le\mathbb F_2^b\) of dimension
\(r\), and let \(d_k(C)\) be its \(k\)-th generalized Hamming weight.  If
preprocessing persists at most \(L\) linear source bits while continuation
retains the original source and may adaptively probe raw coordinates, then
\[
 Q^*_{\rm lin}(L)=d_{r-L}(C).
\]
At each reachable leaf, exactness gives \(C\subseteq S+E_J\), so
\(C\cap E_J\) contains an \((r-L)\)-dimensional subcode supported on the
queried coordinates.  Conversely, store a complement of an attaining
subcode and read its support.  The theorem permits stored linear forms
outside \(C\) and adaptive continuation, but not arbitrary nonlinear
summary fibers.

\FALSIFIED\ (compact representation implies cheap construction).
At \(L=r-1\), the optimum is \(d_1(C)\), the minimum distance of \(C\).
Computing this value for general binary linear codes is NP-hard.  A supplied
attaining subcode is polynomially verifiable and executable, but finding it
is a separate \(P_{\rm discover}\) obligation.  In the finite nonlinear
control through \(b=4\), 1,672,200 one-bit summaries produced no advantage
over the linear frontier; this is \COMPUTATIONAL\ evidence only.  The
arbitrary-nonlinear frontier, strict22 authentication, and native tape/UTM
transport remain \OPEN.  Source:
\path{research/main/2026-10-29_2048_MAIN_GENERALIZED-SUPPORT-FRONTIER-REFEREE212.tex}.

\PROVED\ (batch answer-vector transcript bound; indexed binary-source model).
For a fixed batch of future contexts let \(R\) be the number of distinct exact
batch answer vectors induced by the source family.  If preprocessing uses at
most \(P_{\rm src}\) binary source probes and leaves at most \(L\)
source-dependent persisted bits, while the continuation uses at most
\(Q_{\rm src}\) binary source probes across the entire batch with arbitrary
adaptive caching and recomputation, then
\[
 2^{\min(P_{\rm src},L)+Q_{\rm src}}\ge R.
\]
All source-dependent side channels must be charged in the persisted state.
For a linear parity batch \(Wa\) this gives
\(\min(P_{\rm src},L)+Q_{\rm src}\ge\rank W\); coordinate batches attain
every point \(P_{\rm src}=L,\ Q_{\rm src}=\rank W-L\).
Thus multiplying a one-query probe lower bound by the number of contexts is
\FALSIFIED\ when retained-source access and persistent caching are allowed:
all \(b\) source bits can be read once and reused for any polynomial parity
batch.  Query input, output, arithmetic, verification and peak storage remain
charged.  This is not a SAT lower bound.

\PROVED\ (exact finite interaction model; restricted application).
For a declared state, known certified facts, target, cost model and independently
defined potential, write \(I\mid_v\) with
\(v_\Phi(I\mid s,K)=\Phi(s,K)-\Phi(s,K\cup\{I\})\).
For a finite fact menu \(E\), the gain set function
\(g(S)=\Phi(s,K)-\Phi(s,K\cup S)\) has the unique interaction dividends
\[
 d(U)=\sum_{V\subseteq U}(-1)^{|U|-|V|}g(V),\qquad
 g(S)=\sum_{U\subseteq S}d(U).
\]
The marginal of fact \(I\) after \(S\) is the sum of precisely those dividends
containing \(I\) and contained in \(S\cup\{I\}\).  Positive higher-order
terms capture complementarity; negative terms capture redundancy.  Actual
marginals telescope along a certified execution, but initial singleton labels
are not additive.  An arbitrary normalized Boolean ledger on \(m\) facts has
\(2^m-1\) independent bits; fixed certified interaction order \(k\) leaves only
\(\sum_{j\le k}\binom mj=O(m^k)\) coefficients, whose discovery and bit lengths
must still be charged.

\PROVED\ (detached reusable-summary quantifier firewall).
For source family \(\mathcal A\), future contexts \(\mathcal B\), and answer
vectors \(r_A=(D(A,B))_{B\in\mathcal B}\), any deterministic fixed-length
detached summary exact for all later contexts satisfies
\(L\ge\lceil\log_2|\{r_A\}|\rceil\).  For all pin contexts these vectors are
the boundary functions \(f_A(x)=\exists y\,A(x,y)\).  The theorem does not
apply when the continuation retains indexed access to \(A\): the bit-vector
control uses \(L=0\) and one source probe.  Nor does it apply to a joint solver
seeing \(A,B\).  Since at most \(2^{N+1}-1\) source descriptions have length
at most \(N\), and storing the original source is legal, this counting alone
cannot force exponential summary length relative to \(N\).

\FALSIFIED\ (unrestricted value policy).

initially zero-valued XOR shares solve the target cheaply.  Value acquisition,
authentication, verification, application and score computation remain separate
charged costs.  These are policy and accounting theorems, not SAT lower bounds.

\section{Time-Space Tradeoffs}
\KNOWN\ (Fortnow--Lipton--van Melkebeek--Viglas, Williams).  
In the indexed read-only-input random-access model, SAT cannot be decided simultaneously in time $N^{t+o(1)}$ and space $N^{s+o(1)}$ whenever
\[
s < \beta(t) := \frac12\Bigl(\frac{t+2}{t^2}-t\Bigr)
\]
for the applicable range of $t$, and in particular cannot be decided in time $N^{2\cos(\pi/7)-o(1)}$ and space $N^{o(1)}$ (Williams). These are the strongest published simultaneous bounds used in the present investigation. Numerical evaluation confirms $2\cos(\pi/7)\approx 1.801938$. Buss--Williams established that this endpoint is optimal within the framework of alternation-trading proofs for the subpolynomial-space case.

\section{Constructive Single-Child Route and Oracle Firewall}
\PROVED\ (elementary sufficient theorem, peer review pending).
Let $\mathcal C$ be a closed encoded class containing an NP-complete language.
If one fixed deterministic total uniform algorithm physically produces, on
every valid nonbase $x\in\mathcal C$, one answer-preserving child
$G(x)\in\mathcal C$ with $|G(x)|\le |x|^\lambda$ for fixed
$0<\lambda<1$, and all construction/access cost is $O(|x|^c)$, then
\[
 T(N)\le N^c+T(N^\lambda)=O(N^c).
\]
Fixed bounded bases therefore give SAT in P.  Bare existence of such a map is
a reformulation rather than progress: if SAT were already in P, a decider
could output one of two fixed YES/NO bases.

\FALSIFIED\ (theorem transfer).
At OpenAI \texttt{math} commit
\texttt{adc7f1241b42e322a6451854ab7e4b4c146bf78a}, the unitary-synthesis
preprint proves a uniformly generated polynomial quantum skeleton with one
smaller quantum call per level, but the target chooses unrestricted Boolean
oracle contents.  The source explicitly gives no efficient classical
constructor for those contents and states that the generator never computes a
table entry.  The quantifiers $\forall x\,\exists f_x$ alone give no
classical upper bound: a one-query skeleton can use the hindsight bit
$f_x(0)=L(x)$ for any language $L$.  A valid classical repair needs one fixed
polynomial evaluator $E(x,q)=f_x(q)$, or a uniformly materialized and charged
oracle circuit; then ordinary composition is polynomial.

\PROVED\ (restricted representation audit, peer review pending).
For
\[
 F_t(z)=\bigwedge_i(z\vee A_i)\wedge
        \bigwedge_j(\neg z\vee B_j),
\qquad
 \exists z\,F_t=
 (\bigwedge_iA_i)\vee(\bigwedge_jB_j)

\section*{Conclusion}
The constructive and separation tracks meet at the same missing discipline:
an unrestricted transformation must be uniform, correct on both answer
classes, physically encoded, recursively closed, and fully charged on one
realization. Canonical ordinary 3CNF can now be embedded pointwise into
connected strict exact22, and exact equality fanout is available inside that
class. These are transport and regularization results: compiler re-entry
multiplies exact22 variable count by 12 and every fanout is additive. The
remaining constructive arrow is therefore semantic forgetting with complete
joint correctness, effective acquisition, source authentication, physical
re-entry and a polynomial-value descent rank. Restricted affine--2CNF and
truth-table families show that genuine one-child shrinking is possible on
easy closed grammars; static-interface, marginal-parity, saturation and
monotone-rank controls prevent extrapolation to arbitrary SAT. Published
time--space theorems remain valid model-specific barriers, but no all-input
