\section{Executive summary}

The current program is a contradiction architecture. We temporarily assume \(P=NP\), fix a
deterministic polynomial-time exact SAT decider \(A\), and try to force that same realization into a
second, independently justified description whose resource requirements violate an unconditional
bound. The central discipline is that all resource claims must refer to the same actual computation:
semantic multiplicity, representation size, certificate existence, and runtime are kept distinct.

The shortest surviving route is built around a concrete algebraic-combinatorial question:
for one exact final Boolean range
\[
H=\{g(u):u\in\{0,1\}^s\}\subseteq \{0,1\}^m,
\]
understand
\[
\boxed{
  \rho(E_H)
  =
  \dim_{\Ftwo}\operatorname{span}
  \left\{
    1,\ g_i,\ g_i g_j
  \right\}.
}
\]
A construction-specific bound \(\rho(E_H)=O(m)\) would yield a sparse quadratic annihilator
\(Q\), after which several downstream steps are substantially better understood. Conversely, an
explicit \(\Omega(m^2)\) independent minor for the real construction would decisively retire this
quadratic-rank contraction route.

The parallel HEC/CRS--PPC/CCSPC branch is now a restricted-model control branch rather than
the shortest contradiction route. Its online no-reread and fresh-snapshot theorems remain exact
within their stated models, including \(s\ge K-r\). However, REREAD1 shows that static random
access defeats the proposed persistent-storage consequence, PCLOSE1-R1 proves polynomial-depth
deterministic SAT-dependent causal composition remains polynomial under \(P=NP\), and RANDCLOSE1
extends the closure to bounded-error randomized computations with adaptive NP calls through
\[
\mathrm{BPP}^{NP}=P\qquad\text{under }P=NP.
\]
Thus causal depth, canonicalization, latent path count, delayed audits, and fresh randomness plus
polynomial causal depth are retired as standalone static-hardness mechanisms. A surviving causal
route would need an independently proved resource outside this P-closed simulation and a
model-preserving compiler forcing it on every static SAT decider.

In parallel, the battery / mana / short-circuit line has been reformulated as a
\emph{primitive-trace} program. A shortcut is not an atomic free operation: it must be expanded into
its real machine-level execution. This removes one abstraction-level escape, but it does not yet
provide the missing noncircular potential needed for an unrestricted SAT lower bound.

\subsection{What materially changed}

\begin{itemize}
  \item CRS--PPC is now the canonical causal branch. Its exact core includes fresh snapshots at
  stopping times, constant-rate entropy, list precommitment, \(s\ge K-r\), timing sensitivity,
  transcript determinacy, and explicit hostile upper bounds.
  \item Repeated cyclic/affine shifts are retired as accumulating hardness: they compose to one
  compact group element. A revealed shift is also defeated by one static payload reread.
  A private OTP/permutation is therefore only a challenge-map use of fresh \(G\)-randomness,
  not a separate hardness resource.
  \item A causal NDTM need not predict future \(G\)-bits. For polynomially many explicit
  satisfiable epochs it can wait for the current formula, guess the current witness, and verify it;
  polynomially many such epochs do not imply NEXP.
  \item Runtime-sensitive snapshots yield SAME_REALIZATION provenance but also a machine-relative
  transcript obstruction; exact reference-trace reproduction is simulation, not automatically SAT hardness.
  \item For the declared Hadamard branch, HADCOEF1 proves an exact coefficient map \(\Psi\) with
  \[
  \boxed{K_2(H)=\ker\Psi,\qquad \rho(H)=\operatorname{rank}\Psi.}
  \]
  Since \(M=1+m+\binom m2=\Theta(m^2)\), an \(O(m)\) contraction requires
  \(\dim K_2(H)=M-O(m)=\Theta(m^2)\).
  \item SU05 source analysis now verifies that Hadamard is a source-sanctioned legal computational
  binary conversion, although it is not the unique conversion and has not been proved to be the
  uniquely active SU09/vMS realization.
  \item For any fixed declared legal binary code \(c\), the active quadratic feature rank is exactly
  the rank of the stacked slice matrices \([B_v]_v\), with
  \[
  K_2(H)=\bigcap_{v\ \mathrm{legal}}\ker B_v.
  \]
  A violating state for a candidate relation \(q\) is an NP-search problem once the legal-state
  predicate and slice evaluator are explicit; acquisition is therefore chargeable under the
  counterfactual SAT decider rather than free.
  \item HEC-SAT proves in its online no-reread model the exact side-information bound
  \(s\ge K-r\), the free-SAT-answer corollary \(s\ge K-1\), and the multi-epoch direct-state
  accumulation bound \(s\ge\sum_e K_e-r\). The missing Static-to-HEC compiler remains OPEN.
  \item Generic arguments from short source length, canonicity, locality, field degree, or
  list-decodability to low quadratic rank are now \statusretired.
  \item The affine-coordinate lemma is \statusproved: if the final coordinates really lie in a
  common affine source span of dimension \(r\), then
  \[
     \rho(E_H)\le 1+r+\binom{r}{2}.
  \]
  Hence \(r=O(\sqrt m)\) is already enough for an \(O(m)\)-monomial quadratic annihilator.
  \item The actual final SU/vMS coordinates have \emph{not} been proved affine in a common source.
  Adaptive query addresses may raise the Boolean degree.
  \item The reconstruction quantifier audit blocks the naive \(k^3\) collapse. The project therefore
  retains a conservative \(k^4\) ledger pending a sharper model-matched theorem.
  \item A scalar battery is only useful if defined independently of future optimal runtime; otherwise
  it is circular. Typed resources add content only through genuine state-dependent enabling conditions.
  \item Optional failed shortcuts cannot support a universal lower bound: an arbitrary solver can
  simply skip them. High-level shortcuts should instead be expanded into primitive traces.
  \item Raw one-tape crossing geometry and raw CNF incidence cutwidth are not sufficient SAT hardness
  measures. Easy Horn and affine/Tseitin formulas can share the same apparent nonlocal geometry.
\end{itemize}

\subsection{Retired or falsified routes}

\begin{warningbox}
The following failures are part of the project's progress. They should not be silently restarted
without a genuinely new theorem.
\end{warningbox}

\begin{itemize}
  \item Short source length, canonicity, list-decodability, field degree, or locality
        \(\not\Rightarrow\) low Boolean quadratic product span.
  \item Linear underlying oracle answers plus adaptive local queries
        \(\not\Rightarrow\) affine final Boolean coordinates.
  \item Ordinary switching lemmas on a Cook--Levin style representation do not provide an
        arbitrary-RAM bridge.
  \item Pure extractor-level chiral/provenance monodromy disappears once the terminal oracle is
        extensionally identical.
  \item TransportCert, by itself, is an accounting interface rather than a lower-bound theorem.
  \item A free arbitrary TC4 escape \(K=A_{\mathrm{SAT}}\) trivializes an abstraction-level
        transition system; high-level shortcuts must be expanded into their real execution.
  \item Optional failed shortcuts cannot be charged universally.
  \item An unrestricted potential defined as remaining optimal runtime is a tautological,
        circular battery.
  \item Polynomial tape capacity is not a hardness source: polynomial-time machines automatically
        touch only polynomially many cells, while SAT is already solvable in polynomial space.
  \item Unsigned incidence cutwidth / edge-crossing count cannot be a universal SAT-time resource.
        A trivially easy all-negative Horn formula can share the identical incidence hypergraph with
        a generic signed 3-CNF.
  \item Representation size, semantic multiplicity, witness count, or proof-system size do not become
        arbitrary-machine runtime without a proved transfer theorem.
  \item Repeated cyclic/affine shifts do not accumulate hardness; they compose to one compact
        group element.
  \item A late permutation does not force storage under static random access; one post-challenge
        payload reread suffices.
  \item A private OTP/permutation is not an independent hardness resource; its entropy comes from \(G\).
  \item A causal NDTM may wait for each current satisfiable epoch and guess its witness; it need not
        predict future source bits.
  \item Polynomially many explicit SAT epochs do not imply NEXP merely because their semantic
        branch tree is exponential.
  \item If \(G\) fixes every variable, the remaining 3-CNF task is formula evaluation.
  \item Runtime-sensitive transcript divergence is not itself a language separation.
\end{itemize}

\section{Global invariants and proof discipline}

Every proposed lower-bound object is audited against the following guards.

\begin{enumerate}
  \item \textbf{Semantic multiplicity is not machine state.}
        Many assignments, contexts, or witnesses do not force a machine to materialize them.
  \item \textbf{Existence is not acquisition.}
        A sparse \(Q\), decomposition, backdoor, or certificate can exist without being cheaply
        obtainable.
  \item \textbf{Representation size is not runtime.}
        A solver may compute with an implicit or transformed representation.
  \item \textbf{One-bit output matters.}
        SAT ultimately produces one bit, defeating naive information-counting arguments unless a
        forced intermediate recovery task is independently proved.
  \item \textbf{\same.}
        Time, space, witness, source, rank object, and lower-bound resource must belong to the same
        declared execution unless an explicit model-preserving transformation is proved and charged.
  \item \textbf{Quantifiers are explicit.}
        In particular, \(\forall A\,\exists F_A\) may not be replaced by
        \(\exists F\,\forall A\).
  \item \textbf{Easy controls are mandatory.}
        Horn, dual-Horn, 2-SAT/Krom, affine/Tseitin with Gaussian elimination, bounded treewidth,
        independent products, padding, renaming, auxiliary variables, and compact summaries must not
        trigger a false hardness claim.
  \item \textbf{Wrapper invariance is mandatory.}
        DEAD, COPY, DELAY, INTERP, and RECOMP are used to detect syntactic or provenance quantities
        that are not genuine computational resources.
\end{enumerate}

\[

\[
\rho(E_H)=\dim_{\Ftwo}\operatorname{span}\{1,g_i,g_ig_j\}

\section{HEC to CRS--PPC: causal state/result separation}

The original HEC state theorem remains the base result, but the active causal branch is now
CRS--PPC. Its purpose is to force a future challenge whose response cannot be replaced by the
current SAT decision bit or by ordinary post-challenge witness guessing.

\begin{provedbox}
\textbf{No-reread state theorem.} For a \(K\)-bit payload and a free semantic side channel
with at most \(2^r\) values, exact future recovery of arbitrary coordinates implies
\[
\boxed{s\ge K-r.}
\]
A free SAT decision bit leaves \(s\ge K-1\).
\end{provedbox}

\subsection{Exogenous source, stopping-time snapshots, and precommitment}
Let \(G=(R_1,R_2,\ldots)\) be an IID fair-bit source released at constant rate. If
\(\tau\) is a causal stopping time, the next \(b\) unseen bits remain independent uniform:
\[
\boxed{(R_{\tau+1},\ldots,R_{\tau+b})\mid\mathcal F_\tau \sim U(\{0,1\}^b).}
\]
Only \(O(T)\) fresh bits can enter by elapsed time \(T\). If an agent commits beforehand
to at most \(2^w\) possible \(b\)-bit blocks, then
\[
\boxed{\Pr[B\in L]\le2^{w-b}.}
\]

\subsection{Runtime sensitivity and the machine-relative obstruction}
With epoch recurrence \(\tau_{i+1}=\tau_i+b_i+c_i\), fixed solver/controller/input/source
determine a unique transcript. Distinct runtime-induced length-\(b\) snapshot windows agree
with probability \(2^{-b}\) under the blind-source hypotheses.

\begin{warningbox}
\textbf{Machine-relative transcript obstruction.} Different solvers generally encounter different
future snapshots. Judging each solver on its own transcript permits a faster NDTM to see different
future formulas; requiring every solver to reproduce a reference solver's exact timed transcript
reduces to trace simulation with ordinary simulation overhead. Provenance alone is not SAT hardness.
\end{warningbox}

\subsection{Permutation and reread controls}
Late bijections preserve the no-reread state theorem, but static random access gives a one-reread
bypass after the challenge. Efficient group-valued shift histories also compress to one group
element. A private OTP/permutation is therefore only a way to use fresh \(G\)-bits to hide or
relabel a challenge; it adds no independent hardness resource.

\subsection{Nondeterministic control}
\begin{warningbox}
For polynomially many explicit satisfiable 3-CNF epochs, a causal NDTM may wait for each current
formula, guess its satisfying assignment, verify it, and continue. It need not predict future
\(G\)-bits, and polynomially many such epochs do not imply NEXP. If \(G\) fully assigns
all variables, the residual task is formula evaluation.
\end{warningbox}

\subsection{CRS--PPC audit game}
The strongest surviving auxiliary model fixes a SAT-derived object and dependency DAG \(D_n\).
A reusable subcomponent is now formalized as the \textbf{Canonical Causal SAT Pointer Cascade
(CCSPC)}. At level \(i\), a uniform codebook maps pointer \(p_i\) to a SAT instance \(\Phi_i\),
a unique canonical SAT result \(T_i\) is computed, fresh post-result randomness selects a delayed
audit \(q_i\) of the just-completed computation, and the audit response \(Y_i\) determines the
next pointer:
\[
p_{i+1}=F_i(p_i,T_i,B_i,Y_i).
\]
CCSPC explicitly rejects latent-branch counting as a lower bound: only one path is realized, an NDTM
can always simulate the DTM, and polynomially many explicit stages do not imply NEXP. Its purpose is
instead to concentrate the open STORE/RECOMPUTE and anti-batching questions into one canonical
SAT-dependent pointer transition.

A second reusable subcomponent is the \textbf{Routed Causal Computation Network (RCCN)}. It permits
result-dependent handoffs and cycles among deterministic modules. Two exact facts are now recorded.
First, every fixed finite deterministic RCCN flattens to one DTM with only standard simulation and
explicit communication overhead, so routing cannot force an NDTM to explore all latent routes.
Second, if a prior \(K\)-bit ephemeral record is discarded before a later arbitrary-coordinate
challenge, and all persistent network state plus messages contains \(s\) bits while free side
information has at most \(2^r\) values, then
\[
\boxed{s\ge K-r.}
\]
Cycles do not evade this bound: deterministic revisitation cannot recreate discarded information.
Equivalently, if \(s<K-r\), some additional post-cut information depending on the discarded record
must be reacquired. The open strengthening is to prove that such reacquisition/recomputation is
itself expensive for arbitrary implementations; static random access may otherwise answer a delayed
coordinate with one reread.
Fresh private source blocks choose partial restrictions, audit locations, or outgoing pointer
choices. The charged resource is
\[
\boxed{\mathcal R=S_{\rm data}+S_{\rm pointer}+wQ_{\rm reread}+C_{\rm recompute}+C_{\rm sequential}.}
\]
Pebbling is the closest exact STORE-versus-RECOMPUTE abstraction; online Merlin--Arthur and
delay-function results remain restricted-model analogues.

\textbf{Future-bit precommitment refinement.}
A standard NDTM does not literally observe future \(G\)-bits, but existential branching can
retrospectively guess any polynomial-length future block and reject incorrect guesses later. Thus
future secrecy alone is not a lower bound. The exact precommitment object is the complete response
signature
\[
\Sigma(X)=\bigl(f_B(X)\bigr)_{B\in\{0,1\}^b}.
\]
If one \(s\)-bit state is committed before \(B\) exists and must answer every later audit without
new \(X\)-dependent information, then
\[
\boxed{
s\ge
\log_2\max_z
\left|
\{\Sigma(X):Z(X)=z\}
\right|.
}
\]
For \(X\in\{0,1\}^K\) and an injective response signature on a largest side-information fiber,
this yields \(s\ge K-r\). If the bound is violated, post-cut \(X\)-dependent reacquisition is
necessary. The OPEN step is to prove that such reread/recomputation/sequential reacquisition is
superpolynomial for every selector implementation; exponential latent branch count by itself is
explicitly not used.

\section{Battery, mana, short circuits, and primitive traces}

This side program asks whether an independently defined computational potential can support a
telescoping lower bound. For a trace
\[
S_0\to S_1\to\cdots\to S_T
\]
with step costs \(c_t\), a valid potential would satisfy
\[
\Phi(S_t)-\Phi(S_{t+1})\le c_t
\]
for every legal primitive step, so that
\[
\sum_{t<T} c_t
\ge
\Phi(S_0)-\Phi(S_T).
\]

\subsection{What typed resources contributed}

A vector of typed obligations
\[
D(S)=(D_1(S),\ldots,D_d(S))
\]
collapses back to a scalar battery whenever fixed nonnegative weights
\(\lambda\) suffice:
\[
\Phi_\lambda(S)=\lambda\cdot D(S).
\]
The distinct content of typed resources therefore lies in state-dependent enabling conditions,
nonlinear conversion, locality, or other nonconvex constraints. A high-powered transition may be
available only after the execution has actually built the data structure or state required to perform
it.

\subsection{Short-circuit correction}

The idea that a solver tries a fast route and fails is useful operationally but cannot itself produce
a universal lower bound. A solver can skip optional tests. The clean formulation is instead:
\[
\text{macro }K
\quad\rightsquigarrow\quad
C_0^K\to C_1^K\to\cdots\to C_\ell^K.
\]
All reads, writes, translations, and failed work are then charged by the real microtrace.

\subsection{Circularity guard}

Every computational problem admits the tautological potential
\[
\Phi^*(S)=\operatorname{dist}(S,\text{terminal states}),
\]
which exactly encodes optimal remaining runtime. Therefore a useful battery must be independently
defined from the source/computation structure and cannot depend on unknown future continuation cost.

\subsection{Sequential tape and transport}

Crossing-sequence arguments provide an exact local transport model for one-tape machines. They are
useful diagnostics because an ordinary shortcut has an internal trace, while an oracle call can make
the corresponding semantic jump atomically. This exposes a precise potential nonrelativizing seam.

However:
\begin{itemize}
  \item polynomial tape usage is automatic under polynomial time;
  \item standard simulations preserve polynomial time despite polynomial overhead;
  \item simple crossing/context counting naturally yields only polynomial-scale restricted-model
        bounds;
  \item large unsigned incidence cutwidth also occurs in easy Horn and affine controls.
\end{itemize}
Thus tape geometry is not currently an unrestricted SAT lower bound.
