\section{Fixed objective and actual source interface}
The objective is to refute the existence of any fixed total uniform
deterministic decider for one fixed NP-complete language with a bound
$C(N+2)^d$, for arbitrary fixed $C,d$. No explicit superpolynomial rate is
required. The target language remains the total two-tree compatibility
language $L_{\rm TT}$, with its eight-bit header, unary universe size $h$,
two membership vectors and two adjacency triangles, length $9+h^2+2h$.
Malformed strings reject. A direct non-P theorem there needs no additional
family broadening or mandatory general-circuit compiler.

PINCORE1's literal canonical decoder recovers a source graph and color lists
from actual target bits and pins. BINARYPROJ1 removes all at-most-two-choice
vertices, leaving general unary and binary constraints on the remaining
three-choice variables. Its output is not necessarily an inequality graph.
We use exactly that representation: domains $D_v\subseteq\COL$ and one
allowed-pair relation $R_{uv}\subseteq\COL^2$ per unordered variable pair;
a missing relation is universal. Source pins, role maps and original input
remain available for the previously proved witness lift.

For explicit bit conventions, a dense internal encoding may store an
eight-bit type header, $1^n0$, $3n$ domain bits and nine bits per pair. Its
length is $9+4n+9\binom n2$. A merge query appends a valid pivot index and
two two-bit color labels, rejecting malformed records. The implementation
validates parsed domains, pairs and pivot data, rather than claiming a new
byte parser. The previous $L_{\rm TT}$ encoding is unchanged. All algorithms
below allow full source access and arbitrary polynomial workspace. Literal
colors here name the earlier three nonzero field colors.

\section{Primary literature and the candidate tested}
Cooper, El Mouelhi, Terrioux and Zanuttini define precisely the union-based
value merge and the broken-triangle condition in Definitions 3--4 of
\cite{btp}. Their Proposition 5 proves safety when no broken triangle occurs,
with a constructive lift. This is \textbf{KNOWN THEOREM}, not a discovery of
this run. The written proof and its general-arity qualifications were read.
The browser screenshot of printed page 4136 failed; no visual inspection of
that figure is claimed. All used definitions are in the parsed proof text.

Bordeaux, Cadoli and Mancini prove coNP-completeness for several exact
semantic property tests in Theorems 4--5 of \cite{bcm}. Those properties are
not silently identified with the precise merge-image predicate defined below;
we give its own reduction. Their distinction between preserving every
solution and merely retaining a solution is directly relevant. Constraint
elimination via local forbidden patterns is also an established program
\cite{patterns}. The project contribution is the explicit guarded repair,
the exact safety reduction, and integration into the current kernel and
same-input witness maps, not a foundational new merging method.

The attempted contradiction was that arbitrary three-choice states either
merge cheaply or force a hard exact-merge service, which might rule out a
polynomial decider. The first alternative requires a correctness condition;
the second is not a compulsory service of every decider. The next sections
make both failures precise while providing useful constructive replacements.

\section{A two-value merge and its exact guarded repair}
Fix a variable $x$ and distinct $a,b\in D_x$. Let $q$ replace $a,b$ by a new
label $M$ at $x$, leaving every other variable and color unchanged. The
\emph{naive quotient} $Q$ keeps all nonincident constraints and sets
\[
 R'_{xy}(M,c)=R_{xy}(a,c)\lor R_{xy}(b,c).
\]
Rows for any unmerged third color remain unchanged. This is a relaxation:
$q(\Sol(P))\subseteq\Sol(Q)$, but equality need not hold.
For every $y\ne x$ and $c\in D_y$, define
\[
 S_y(c)=\{r\in\{a,b\}:(r,c)\in R_{xy}\}.
\]
For each pair of distinct nonpivot variables $y,z$, and each compatible
pair $(c,e)\in R_{yz}$ whose support sets are opposite singletons, add
\begin{equation}\label{eq:guard}
             \neg[(x=M)\land(y=c)\land(z=e)].
\end{equation}
Here ``opposite'' means $S_y(c)=\{a\},S_z(e)=\{b\}$ or the reverse.
These are exactly the local broken-triangle combinations. Let $Q^+$ be $Q$
with all such guards.

\begin{theorem}[Exact guarded quotient]\label{thm:guard}
For every explicit binary instance $P$, pivot $x$ and permitted pair $a,b$,
\[
                       \Sol(Q^+)=q(\Sol(P)).
\]
There are at most $9\binom{n-1}{2}$ guards. Their construction has polynomial
bit time and space. Every solution of $Q^+$ lifts to an original solution
agreeing on all nonpivot variables, by testing at most two representatives.
\end{theorem}
\begin{proof}
An original solution cannot activate a guard: its chosen pivot value belongs
to both relevant support sets. Thus every original image is accepted.
Conversely let $t$ satisfy $Q^+$. If $t(x)\ne M$, it already satisfies $P$.
If $t(x)=M$, each support set $S_y(t(y))$ is nonempty by the naive incident
constraints. Nonempty subsets of the two-element set $\{a,b\}$ have empty
joint intersection only when two are the opposite singletons. Those two
assignments are compatible under $R_{yz}$ because $t$ satisfies the unchanged
background. They would activate a guard, which is impossible. A common
representative therefore exists, and replacing $M$ by it satisfies every
original constraint.

There are at most nine color pairs per nonpivot variable pair. Enumerate
these pairs, inspect the fixed-size relation masks and write the guards.
Indices, source reads, guard storage and final verification have polynomial
bit cost. Testing $a$ and $b$ against the original source produces the lift;
no satisfiability oracle, advice, or preselected source witness is used.
\end{proof}

With zero guards, this specializes to the known BT-free merge theorem.
A nonempty guard list is \emph{not} proof that a spurious global assignment
exists: a local pattern may be blocked elsewhere. Thus the polynomial test
is sufficient but not a complete recognition of safe unguarded merges.

\paragraph{Two finite controls.}
On the path with center $x$ and leaves $y,z$, all domains full and inequality
edges, merge colors zero and one. The tuple $(M,0,1)$ satisfies the naive
quotient but has no original preimage in that fiber. The original coloring
$(2,0,1)$ is valid, but maps to $(2,0,1)$, not $(M,0,1)$. This distinguishes
satisfiability preservation from exact image preservation.

For $K_4$, merging zero and one at one vertex gives six spurious quotient
solutions: its remaining triangle uses all three colors, while $M$ is
separately compatible with each neighbor. No single representative works.
The guards reject all six. By contrast, an equality triangle has a safe
context-dependent merge: neighboring values determine whether to lift to
zero or one. The pair need not be interchangeable by one fixed replacement
on every original solution.

\paragraph{The output-language boundary.}
The guards are ternary, even though the source is binary. The theorem does
not license repeated use of a binary-only rule on the changed presentation.
Retaining the original source and using its exact lift service is another
legal implementation; expanding every accumulated guard is not compulsory.

\section{Global safety certification can be harder than the source decision}
Define SAFE-MERGE to contain valid encoded $(P,x,a,b)$ for which the naive
quotient has \emph{no} spurious solution, equivalently
$\Sol(Q)=q(\Sol(P))$. Reject malformed query encodings. This is a separate
language about the proposed transformation, not the target $L_{\rm TT}$.

\begin{theorem}[Exact merge-image safety is coNP-complete]\label{thm:safe}
SAFE-MERGE is coNP-complete for explicit three-color binary instances. Its
hardness already holds on instances consisting of an arbitrary graph
component and a disjoint, displayed $K_4$, whose original three-colorability
answer is always NO.
\end{theorem}
\begin{proof}
For a valid unsafe query, a polynomial certificate is a complete satisfying
assignment of the naive quotient. Check that it is accepted and that neither
of its at most two original representatives satisfies $P$. These tests are
polynomial; malformed encodings are decidably outside SAFE-MERGE as well.
Thus its complement is in NP.

For hardness, map a graph $G$ to $P_G=G\sqcup K_4$, with full domains and
inequality constraints. Merge colors zero and one at one fixed vertex of
the $K_4$ component. The original instance has no solution. Its quotient
has a solution exactly when $G$ is three-colorable: the other three gadget
vertices form a triangle, with six colorings, and the merged value is
compatible with all of them. Indeed
\[
                         |\Sol(Q_G)|=6|\Sol(G)|.
\]
Consequently the merge is safe exactly when $G$ is not three-colorable.
This is a polynomial reduction from the complement of 3COL.
\end{proof}

This does not prove SAFE-MERGE outside P. Under $P=NP$, coNP also equals P.
More importantly, deciding the original $P_G$ does not require solving this
safety test: the displayed four-clique certifies NO immediately. Therefore
one cannot transfer the certification problem's hardness to every decider
of the original inputs merely by calling it a required merge operation.

The theorem concerns exact image preservation, not an unsupported complexity
classification of every possible satisfiability-preserving transformation.
An arbitrary correct SAT or coloring algorithm may skip this merge, use
another representation, or recognize a different certificate.

\section{Simultaneous grouping: each fixed fiber remains polynomial}
At every variable choose a partition of its original domain into blocks of
size at most two. Let $z$ specify one chosen block $F_v(z)$ per variable.
Empty selected domains are rejected. These blocks are part of the proposed
quotient assignment, not supplied satisfying values.

\begin{theorem}[Source-retained fiber test]\label{thm:fiber}
For every explicit binary CSP and every such full block assignment $z$,
whether an original solution belongs to $\prod_v F_v(z)$ is decidable in
polynomial time. A successful test returns a complete original witness.
\end{theorem}
\begin{proof}
Introduce one Boolean variable selecting one of the at most two elements
of each $F_v(z)$. A singleton is fixed by a unit clause. For every original
binary constraint, exclude each disallowed pair of choices by a 2-clause.
The resulting 2-SAT instance has $O(n)$ variables and $O(n^2)$ clauses and
is satisfiable exactly when the prescribed fiber contains an original
solution. Constructively solve it, translate its choices back, and check
all source constraints. Source retention, relation reads, construction,
workspace and witness emission have polynomial bit cost.
\end{proof}

This permits checking one fully specified quotient assignment without
materializing a growing list of all induced higher-arity constraints. It
uses the original binary instance, not an invalid assumption that the
successive guarded quotients remain binary. It does not find a successful
$z$ in polynomial time or decide an arbitrary partial block assignment.

\paragraph{Graph-only characterization.}
Group colors $\{0,1\}$ together and keep color two separate. Let $S$ be the
vertices assigned the singleton block $\{2\}$. Then
\begin{equation}\label{eq:graphfiber}
 z\text{ has an original lift}
 \iff S\text{ is independent and }G[V\setminus S]\text{ is bipartite}.
\end{equation}
The proof is direct: use color two on $S$ and the two remaining colors on
its complement. A supplied $S$ is checked by graph traversal. Finding some
such $S$ is equivalent to three-coloring, not an established polynomial solver.
The naive simultaneous pair quotient checks only independence of $S$; an
all-merged triangle is its smallest missed odd-cycle obstruction.

With Boolean variables the same construction is a 2-SAT. The general fiber
test is the CSP analogue. Both remain model-restricted: they decide a
prescribed fiber, not the unrestricted three-coloring problem.
