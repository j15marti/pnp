\section{MCSP/MKTP: the conditional separation chain}

\paragraph{Status and scope.}
\textbf{CONDITIONAL / OPEN.} This is a dependency summary, not a new
separation argument. Published theorems are cited rather than reproved; the
elementary proofs below are supplied here to make the corresponding
repository claims independently checkable. No finite experiment was rerun
for this summary. The magnification theorems below are published results
in different models; they are not successive arrows that can be composed
without additional hypotheses. The project's ordinary-MKTP route is
\[
\begin{array}{c}
 P=NP\\
 \Downarrow\\
 \text{one fixed polynomial-time solver for ordinary }\Sigma_3\mathrm{SAT}\\
 \Downarrow\\
 \boxed{\text{charged, total, both-label target }R_k\quad\textbf{OPEN}}\\
 \Downarrow\\
 \text{ordinary }\mathrm{MKTP}[p_k]\text{ streamer}\\
 \Downarrow\\
 \text{same-machine simultaneous SAT bounds}\\
 \Downarrow\\
 \text{matched FLMV contradiction.}
\end{array}
\]
The first implication follows by collapse of the polynomial hierarchy under
$P=NP$. The boxed target constructor, including its promised complexity
gap, is not supplied by that collapse, MMW, CHMY, or OPS.

\paragraph{Objects must not be interchanged.}
Write $N$ for the source SAT encoding length and $M$ for the emitted target
length. Ordinary indexed $\mathrm{KT}$ minimizes description length plus
worst-case indexed-bit running time. It is not Levin's printing complexity
$\mathrm{Kt}$, whose time contribution is logarithmic. Consequently
$\mathrm{MKTP}$ and $\mathrm{MKtP}$ must retain their capitalization.
An ordinary target is one actual bit string, not a conditional description
with a free source oracle, hidden table, or caller-tape pointer.

\subsection{Published contracts: three separate interfaces}

\paragraph{MMW: downstream streaming, not target construction.}
For time-constructible $p(M)\geq\log M$, MMW Theorem~4.2 gives a streaming
algorithm for $\mathrm{MKTP}^{A}[p(M)]$, for any oracle $A$, with time
$O(Mp)$, space $O(p)$, and $\Sigma_3\mathrm{SAT}^{A}$ queries of length
$O(p)$. Take $A$ trivial for ordinary MKTP. Its circuit version retains a
global old circuit in each Stream-Merge update. It does not construct a
SAT-derived target or permit replacing that circuit by independent fragment
statuses. Source: \url{https://people.csail.mit.edu/rrw/MCSP-MKTP-stoc19.pdf},
Sections~1.1 and~4, Theorem~4.2.

\paragraph{CHMY: a restricted machine lower bound.}
For every oracle $O$ and fixed $1/2<\mu'<\mu<1$, CHMY Theorem~16 excludes
time $M^{2(\mu'-o(1))}$ for $\mathrm{MCSP}[M^\mu]$, on $M=2^m$-bit truth
tables, in its randomized two-sided-error model: one one-way read-only
input tape, one two-way read/write work tape, and oracle queries of length
$M^{o(1)}$. Error is at most $1/3$. Corollary~23 supplies a local PRG with
seed bound
\[
 \widetilde O\!\left((\sqrt T+\log(1/\epsilon))
                    \log(q2^\ell T)\right)
\]
for $q$-state, time-$T$ oracle RTMs with query length at most $\ell$,
$T\geq M$. ``Local'' means each output truth table has circuit complexity
at most the seed length. The comparison is with uniform strings of the
same length, using an independent uniform seed and independent machine
coins. Source:
\url{https://doi.org/10.4230/LIPIcs.STACS.2021.23}, Theorem~16,
Corollary~23 and Section~2.6. This does not establish a general-circuit
lower bound or an unrestricted random-access lower bound.

\paragraph{OPS: cofinal nonuniform promise magnification.}
OPS Theorem~1.4 states that a universal $c\geq1$ exists such that
\[
 \begin{gathered}
 \exists\epsilon>0\ \forall\text{ sufficiently small }\beta>0:
 \operatorname{GapMCSP}[M^\beta/(c\log_2M),M^\beta]
 \notin\operatorname{Circuit}[M^{1+\epsilon}]\\
 \Longrightarrow NP\not\subseteq P/\mathrm{poly}.
 \end{gathered}
\]
LOW and HIGH mean circuit size at most the first threshold and at least the
second; intermediate inputs are outside the promise. Source:
\url{https://theoryofcomputing.org/articles/v017a011/v017a011.pdf}.
CHMY's one-work-tape lower bound at thresholds above $M^{1/2}$ supplies
neither this nonuniform circuit model nor its cofinal small-$\beta$ premise.

\paragraph{Retained-source firewall.}
SOURCE-REFERENCE-FLOOR15 separates ordinary input from a shared-source
oracle. A query containing a pointer to the caller's SAT input is not an
ordinary short $\Sigma_3\mathrm{SAT}$ instance. Copying the source into it
must be charged at its actual length; keeping source bits in writable state
must be charged in workspace. Lossless descriptions of all $N$-bit strings
need at least $N$ bits in the worst case, since fewer than $2^N$ descriptions
have length below $N$. For fixed $d$, a budget
$p^d=N^{ad/k+o(1)}$ cannot encode all those strings for cofinally large fixed
$k$. This does not rule out a lossy SAT-preserving map: semantic fibers may
discard almost everything if their label is correctly acquired. Nor does an
upper bound $L^C$ for a query solver become a lower bound on its actual
runtime. What fails is the justification for dividing its exponent by $k$
when query length is no longer controlled by $p$.

\subsection{The exact missing target and the cofinal ledger}

For an unbounded set of fixed integers $k$, the proposed interface requires
a deterministic ordinary target generator $R_k$, with a single declared
label orientation, such as
\[
 \forall F:\quad F\in\mathrm{SAT}
       \Longleftrightarrow \mathrm{KT}(R_k(F))\leq p_k,
 \qquad p_k=M^{1/k+o_k(1)}\geq\log M.
\]
Thus every opposite-label input must yield $\mathrm{KT}>p_k$; it is not
enough to handle one promise side or selected examples. Let
\[
 M=N^{a+o_k(1)},\qquad
 G_k=M^{g_k+o_k(1)},\qquad H_k=M^{h_k+o_k(1)}
\]
bound total generation time and peak workspace. All source acquisition,
solver calls if permitted by the proposed interface, replay, target writes,
query serialization and retained state must be charged. Bursty generation
is allowed when the consumer can pause and no uncharged rewind is needed.
Composition must be justified on the declared endpoint machine, not by
silently providing a second work tape in the CHMY model.

After $P=NP$ fixes one ordinary query solver with time/space exponents
$C,D$, the conservative source-relative resource ledger used in
COFINAL-AMORTIZED-PIPE13 is
\[
 t_k=a\max\{g_k,1+(C+1)/k\},\qquad
 s_k=a\max\{h_k,\max(1,D)/k\}.
\]
\textbf{Proof of the accounting implication.}
There are at most $O(Mp)$ oracle-stage steps. Replacing each ordinary
$O(p)$-bit query by time $p^{C+o(1)}$ gives the safe time bound
$M p^{C+1+o(1)}$. Sequential reuse requires at most
$p^{\max(1,D)+o(1)}$ workspace besides generation. Times add and peak
workspaces add, so their exponents combine by maximum. Substitution of
$M=N^{a+o_k(1)}$ gives the displayed bounds. This is an upper-bound ledger,
not a construction of $R_k$.

At $a=6/5$, the project's strict box is
\[
 t_k<\tau=241/200,\qquad s_k<1/2.
\]
An unbounded set of fixed $k$ satisfying
$g_k<241/240$ and $h_k<5/12$ suffices: after fixing $C,D$, choose a member
also satisfying
\[
 k>\max\{240(C+1),(12/5)\max(1,D)\}.
\]
For that one fixed $k$, all finite $k$-dependent constants and the
$o_k(1)$ terms are absorbed by the strict exponent margins.
\textbf{The order is fix solver, choose fixed $k$, then let $N$ grow.}
It is not necessary to algorithmically recover the exponent of an arbitrary
solver. It is invalid to replace $k$ by a growing $k(N)$ without new uniform
bounds: $2^{2^k}N^r=O_k(N^r)$ for every fixed $k$, whereas at
$\log_2N=q^2$, $k=q$, its extra exponent is $2^q/q^2\to\infty$.

\paragraph{Endpoint, only after the ledger closes.}
FLMV Corollary~5.8 excludes
$\operatorname{NTIME}[n]\subseteq\operatorname{DTISP}[n^c,o(n^{d(c)})]$,
where $d(c)=((c+2)/c^2-c)/2$, in the deterministic random-access model.
At $c=241/200$,
\[
 d(c)=\frac{11642479}{23232400}
     =\frac12+\frac{26279}{23232400}>\frac12.
\]
The local/quasilinear SAT transfer and strict slack absorb encoding and
polylogarithmic costs. Source:
\url{https://lance.fortnow.com/papers/files/tst.pdf}, Section~2.1,
Section~3 and Corollary~5.8. This conditional contradiction does not close
the boxed target-construction gap.

\section{Elementary obstructions that delimit the missing arrow}

\subsection{Short tags and adaptive transcripts do not create high KT}

\textbf{PROVED/EXACT, with runtime explicit.}
Fix the actual universal machine used for ordinary KT and a fixed replay
interpreter. Suppose a base generator has description length $c_x$, and an
adaptive deterministic compiler's realized Boolean answer transcript is
$a\in\{0,1\}^h$. If the final $L$-bit output can be replayed at any index
from that generator and $a$, with no further oracle access, let $R_U$ be the
full worst-case indexed replay time on that universal machine, including
simulation, base accesses, and transcript accesses. Standard self-delimiting
pairing gives
\[
 \mathrm{KT}(y)\leq c_x+h+O(\log(c_x+h+L+2))+R_U.
\]
\textbf{Proof.} Hardwire the base description, transcript and length
information. Reconstruct each adaptive query and supply its next hardwired
answer. Adaptivity adds no information beyond the realized path. The
description and actual indexed runtime give the stated KT bound.
For fixed base and compiler, exactly $h$ Boolean answers select at most
$2^h$ targets; allowing all lengths through $h$ gives at most
$2^{h+1}-1$. These counts are upper bounds, not lower bounds on minimum KT.

If $c_x+R_U+\log(c_x+h+L+2)=o(p)$ and $\mathrm{KT}(y)>p$, the transcript
must have $\Omega(p)$ bits, unless another source-specific component was
omitted from the replay premise. A difficult-to-discover SAT label is still
one hardwirable bit. Fixed-size digests and polylogarithmic tags with
polylogarithmic indexed decoders therefore remain polylogarithmic-KT, on
both source labels. No claim of constant-factor universal-machine simulation
is needed: $R_U$ explicitly includes that cost.

This summarizes the short-tag closure and adaptive-transcript firewall
reports (31--32). The later DIGEST-GATE17 handoff applies the
same argument to a fixed 256-bit SHA-256 key and indexed output decoder.
Its finite audit package was not published in the frozen tree, so its
reported assertion count is not treated here as an independently reproduced
experiment.

\subsection{Injectivity obstructs strict threshold compression}

\textbf{PROVED/EXACT.}
Let $N,M$ be truth-table lengths, $M=N^{a+o(1)}$, and
$0<a\beta'<\beta<1$. Every injective map
$R_N:\{0,1\}^N\to\{0,1\}^M$ eventually has some source $f$ with
\[
 \mathrm{CC}(f)\leq N^\beta,
 \qquad \mathrm{CC}(R_N(f))>M^{\beta'}.
\]
\textbf{Proof.} Choose $a\beta'<\gamma<\beta$ and let
$h=\lfloor N^\gamma\rfloor$. The $2^h$ functions arbitrary on the first
$h$ addresses and zero elsewhere have size $O(h\log N)<N^\beta$ by a
minterm DNF. There are at most
$2^{O(s\log(M+s))}=2^{N^{a\beta'+o(1)}}=2^{o(h)}$ target functions with
circuits of size $s=\lfloor M^{\beta'}\rfloor$. Their number is too small
to contain the distinct images of all $2^h$ sources.

The equality case $a\beta'=\beta$ is not covered. A lossy reduction is not
excluded, but each produced fiber must be source-label-monochromatic:
equal outputs cannot carry different required target labels. That necessity
does not give an efficient procedure for constructing the fibers.

\subsection{Public repeated coordinates cancel}

\textbf{PROVED/EXACT.}
For $M>N$, let $E(f)_i=f_{\pi(i)}\oplus h_i$ with public
$\pi:[M]\to[N]$ and public mask $h$. Two of the first $N+1$ positions
have the same source index, say $a<b$. Therefore every image obeys
\[
 E(f)_a\oplus E(f)_b=h_a\oplus h_b.
\]
A one-way tester stores one bit at $a$ and checks at $b$. It accepts all
images and accepts $U_M$ with probability $1/2$. At each fixed length,
positions and mask bits can be compiled into $O(M)$ control states;
uniform implementation requires their charged generation.

For the concrete Bridge33 map
\[
 E(f)(x,y)=f(x)\oplus\bigl(y_0\wedge(x_0\oplus y_1)\bigr),
 \qquad M=N^2,\quad N=2^n,\ n\geq3,
\]
in $x$-major, $y$-minor binary order, the first eight bits form four equal
adjacent pairs. A single constant-size tester checks those eight bits;
uniform acceptance probability is $1/16$, giving advantage $15/16$.
This tester is genuinely uniform and uses no work-tape cell.
Consequently the failed arrow is precisely
\[
 G_N(U)\text{ fools tests against }U_N
 \ \not\Longrightarrow\ 
 E(G_N(U))\text{ fools tests against }U_M.
\]
The valid pushforward reference would instead be $E(U_N)$, and even that
comparison requires a model-correct simulator. Correct circuit-complexity
preservation does not establish uniformity of the expanded distribution.

\paragraph{Threshold slack does not repair a full-stream lift.}
The specific Bridge34 certificate has source parameters
$1/2<\nu<\theta<1$, security time $N^{2\nu+o(1)}$, and source LOW cutoff
$N^\theta/(c\log N)$. For a circuit-preserving expansion $M=N^r$ to
transport the whole LOW promise, exponent matching requires
$r\beta'\geq\theta$ (boundary constants need separate care). Thus
$\beta'<1/2$ requires $r>2\theta$. A literal $M$-bit scan fitting the
source time requires $r\leq2\nu$. These conditions contradict
$\nu<\theta$. This excludes the declared full-stream, whole-promise
certificate, not all reductions or all possible PRGs.

\subsection{Every affine expansion has a dual parity}

\textbf{PROVED/EXACT (Bridge35), with a uniformity firewall.}
For every public affine map
\[
 E:\mathbb F_2^N\times\mathbb F_2^d\to\mathbb F_2^M,
 \qquad E(f,z)=Af+Bz+h,
\]
if $M>N+d$, then there is $v\neq0$ such that
\[
 \forall f\ \forall z:\quad v^TE(f,z)=v^Th.
\]
\textbf{Proof.} The $M\times(N+d)$ matrix $[A\ B]$ has rank
$r\leq N+d<M$, so its transposed kernel has a nonzero $v$. This proves
the identity. Uniform input maps uniformly onto the affine image, whose
size is $2^r$. Hence
\[
 \operatorname{TV}(E(U_{N+d}),U_M)=1-2^{r-M}.
\]
A forward scanner XORs the coordinates in the support of $v$; it accepts
every image and half the uniform strings. High dual distance increases
the number of participating coordinates, not the size of the parity
accumulator. Avoiding a dimension-forced parity requires $d\geq M-N$,
a necessary, not sufficient, condition for full row rank.

The length-specific scanner uses one live parity bit and $M$ input moves,
with its support in control. A uniform one-work-tape conclusion must also
charge support computation and its storage. Thus the algebraic obstruction
is unconditional, while its precise uniform resource transfer is not free.
It does not exclude genuinely nonlinear encoders or prove a SAT lower bound.

\subsection{Global witnesses and the restricted fragmentation barrier}

\textbf{PROVED/EXACT within the declared interface.}
If $2^b$ possible old prefixes require different correct global output
circuits after the same future block, a deterministic compressor retaining
only $d$ bits and making $m$ fixed-length $\ell$-bit queries to a fixed
deterministic oracle has at most $2^{d+m\ell}$ retained-state/query
transcripts. If it cannot inspect the old circuit or source, correctness
requires $d+m\ell\geq b$. Equal transcripts force equal replies and output,
so a collision among different required prefixes is impossible. This is a
restricted communication/counting statement, not a lower bound on every
multiquery compiler. Published MMW retains the old circuit and survives it.

For the explicitly tested naive fragmentation strategy, put
$s=N^\beta$, query length $\ell=N^\delta$, and total time cap
$N^{1+g}$, $0<g<1$. Fragmenting $\Theta(N)$ queries into
$\Theta(s/\ell)$ pieces requires $\delta\geq\beta-g$.
The CHMY seed-locality certificate used by that strategy requires
$\delta<\beta-(1+g)/2$. Both could hold only if $g>1$, a contradiction.
This retires that fragmentation and no broader compiler class.

\section{What is closed, and what is still open}

\begin{itemize}
\item \textbf{KNOWN THEOREM:} MMW streaming, CHMY restricted lower bounds,
OPS nonuniform promise magnification, and FLMV only with their own models,
input measures and quantifiers.
\item \textbf{PROVED/EXACT:} fixed-parameter absorption; the explicit
hardwiring, injectivity, repeated-coordinate, and affine-rank obstructions
above, in their stated scope.
\item \textbf{FALSIFIED/RETIRED:} short locally replayable semantic tags as
high-KT sources; public repeated-coordinate/mask/permutation PRG lifts;
high-dual-distance affine mixing as a way to remove all image parity tests;
the tested digest-only global-witness replacement and naive fragmentation.
\item \textbf{OPEN:} a deterministic standard-model, all-input, both-label
ordinary-MKTP target family with a proved KT gap and cofinally feasible
generation exponents; a same-machine composition with all access charged;
or a distinct model-correct CHMY-to-OPS/MMW bridge supplying the exact
published premise. Nonlinear mixing alone proves none of these.
\end{itemize}
No output count, easy-family test, finite audit, circuit rank, or
representation lower bound is promoted to unrestricted SAT decision time.
\textbf{P versus NP remains OPEN.}
