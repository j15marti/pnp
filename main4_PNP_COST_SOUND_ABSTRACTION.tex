\section{Target, status, exact model}
This is a coherent restricted end-to-end pipeline from an explicitly encoded register-stream Boolean program, an ordinary shared fan-in-two circuit with a supplied live-frontier layout, a no-layout read-once Boolean formula tree with a uniformly discovered logarithmic frontier, and a general no-advice acyclic shared-gate DAG with a discovered long-edge spill budget, through complete read-once branching programs to exact decision/count semantics and declared source-width rank implications. Arbitrary circuit-to-register translation, general SAT-time lower bounds, and P versus NP remain OPEN.

Fix $n,s\geq1$. The source has original inputs $x\in\{0,1\}^n$, $s$ retained register bits, initial register $r_0$, and precisely $n$ stages. Each stage has a topologically ordered shared fan-in-two Boolean truth-table gate DAG which selects an index $j_t$ \emph{before} inspecting its value and updates $r_{t+1}=U_t(r_t,x_{j_t})$. The selector is independent of the unread bit on all reachable states, and no index is repeated along any path. After stage $n$ a shared Boolean DAG returns the one-bit answer $h(r_n)$. The finite encoding is canonical ASCII JSON with fields for version, dimensions, initial register, stages, and terminal circuit, and binary gate records $(a,b,\tau)$ for any of the 16 binary truth tables. Shared fan-out, repeated operands, constants and adaptive choice are allowed. The compiler rejects malformed encodings and reachable read-once or pre-read-selector violations. Let $L$ count the entire source encoding in bits.

The named dependency is D4-COMPILER: encoding and authentication $\longrightarrow$ paid full-history construction $\longrightarrow$ adaptive FBDD $\longrightarrow$ exact field-rank transfer $\longrightarrow$ lower bound on the declared SOURCE persistent bits. Falsifiers tested include DISJ's cheap interleaving, hidden input reinspection, incorrectly merging distinct read masks, and unpaid fan-out or graph construction. \section{All-step compiler and semantic proof}
A validation history is $(t,r,m)$, with $m\subseteq[n]$ the inspected set. The compiler starts at $(0,r_0,\varnothing)$; at each reachable history it evaluates the real stage DAG for each hypothetical $z\in\{0,1\}$, checks that both choose the same $j<n$ and $j\notin m$, and follows
\[
(t,r,m)\xrightarrow{z}(t+1,U_t(r,z),m\cup\{j\}).
\]
For terminal histories it evaluates the original output DAG. A target node is identified by $(t,r)$, retaining the selected input label and two actual successor pointers. Different masks may be quotiented only because the source's future control and update depend solely on $(t,r)$ and the next tested bit. The compiler checks shared outgoing pointers for consistency.

\paragraph{Lemma 1 (pointwise costed simulation).}
Every accepted source and every $x\in\{0,1\}^n$ produce the same accept/reject bit in the source and the compiled FBDD. The FBDD is deterministic, acyclic and read-once; its distinct internal node count $V$ and the number of distinct checked histories $H$ satisfy
\[
V\leq n2^s,\qquad H\leq 2^s(2^n-1).
\]
\emph{Proof.} At $t=0$ source and target have the same register. If registers agree at $t$, the checked selector and actual source DAG select the same original input $x_j$, then the same branch computes the same successor register. Induct to $t=n$ and use the identical terminal gate DAG. The exhaustive validation checks every possible history mask, so no merged source path causes a repeat. There are at most $2^s$ registers for each of the $n$ nonterminal stages, and at most $2^s\binom nt$ histories at stage $t$. Summation yields the bounds. Each node is shared once and has exactly two outgoing arcs. \hfill$\square$

\section{Transfer back to a declared source parameter}
Let $M_{X,Y}(f)$ be the original-input assignment-evaluation matrix over any field $K$.

\paragraph{Lemma 2 (fixed-order persistent memory).}
When the indices selected by source stages are a fixed public permutation, every prefix cut of that order has
\[
\operatorname{rank}_K(M_{\mathrm{prefix},\mathrm{suffix}})\leq 2^s,
\qquad
s\geq\left\lceil\log_2\operatorname{rank}_K(M_{\mathrm{prefix},\mathrm{suffix}})\right\rceil.
\]
\emph{Proof.} After a prefix, the suffix function is entirely determined by the current $s$-bit persistent source register and public stage number. There are at most $2^s$ distinct rows. \hfill$\square$

\paragraph{Lemma 3 (adaptive side switches).}
Partition the original variables $X\sqcup Y=[n]$, and let $b$ be the maximum number of changes in which side owns consecutive actual tests. Then
\[
R=\operatorname{rank}_K M_{X,Y}
\leq\sum_{j=0}^{b}V^j
\leq\sum_{j=0}^{b}(n2^s)^j.
\]
For $b\geq1$, $\log_2R\leq\log_2(b+1)+b(\log_2 n+s)$; for $b=0$, $R\leq1$.
\emph{Proof.} The current side owner simulates maximal local segments of the actual shared FBDD and sends the switch-destination node ID upon each change of owner. For a fixed accepting transcript the $X$-only segments constrain only $X$ and the $Y$-only segments constrain only $Y$. Accepted inputs producing that transcript form a Cartesian rectangle, whose matrix has rank at most one over $K$. Deterministic transcripts partition the accepting inputs; at most $V^j$ transcripts have $j$ switches. Sum the rectangle matrices. This is the TMR-4/053 factorization now attached to a genuine source compiler. \hfill$\square$

The conclusion bounds the declared persistent inter-stage register bits and the number of actual source owner switches. It does not bound all intra-stage gate buffers, the cost of arbitrary circuit evaluation, or general SAT decision time. A direct cheap computation is always legal.

\section{Single-realization cost ledger}
Let $G_{\max}$ denote maximum stage/terminal gate count. Every stage DAG is stored with source sharing preserved; it is evaluated for both hypothetical bit outcomes at each checked history, with all source wire indexes, arithmetic, fan-out, failed paths, cache lookups and output charged. A fixed deterministic multitape implementation with conservative sequential table scans has joint live bit budget
\[
D=L+O\bigl(H(n+s+\log(H+2))+V(n+s+\log(V+2))\bigr)
\]
covering source storage, validation queue, history masks, output-node IDs, gate buffers, addresses, both arcs of each shared node and fully serialized output. An ordinary compiler followed by one physical target evaluation on the SAME execution admits
\[
T_{\rm total}=O\bigl((H(G_{\max}+n+s+1)+1)D^2+nD+n^2\bigr),
\quad S_{\rm peak}=O(D).
\]
Here $D^2$ pays for deliberately naive bit-address and table searches, $nD$ pays for target-node accesses and $n^2$ pays for physical input-head motion. No time lower bound or polynomial-time general-circuit compiler is claimed; $H$ is potentially exponential. Network aggregate memory and total work are never replaced by span or per-worker memory.


\section{An ordinary shared-circuit source compiler with a supplied live frontier}
The previous compiler starts with an already restricted read-once register program. We now close the named D4-UNRESTRICTED-CONVERSION arrow for an explicit, nontrivial subclass of \emph{ordinary} shared Boolean circuits equipped with an authenticated topological evaluation layout. This is a restriction on the supplied layout, \emph{not} on the gate functions or fan-out. No optimized layout is presumed or discovered for free.

Let $C$ be a fan-in-two shared DAG with $n\geq1$ original Boolean inputs, $g$ binary truth-table gates, constants, repeated operands, arbitrary fan-out, and a designated output. The finite binary/JSON encoding supplies all records and a topological schedule $\pi$ listing every original input and gate exactly once, beginning with $x_0$. A gate follows both dependencies. Reject a malformed encoding, duplicate identifier, invalid truth-table index, missing input/output, forward reference, or missing schedule vertex. An output is a pseudo-consumer just after the final scheduled vertex. For each nonconstant wire identity $v$, let $\ell(v)$ be the last later gate-use or the pseudo-output-use, or $-1$ if none. Define, after position $t$,
\[
L_t=\{v:\operatorname{pos}_{\pi}(v)\le t<\ell(v)\},\qquad
w(\pi)=\max_t |L_t|.
\]
Each shared signal contributes one bit regardless of its number of consumer wires. The order $\rho$ of input introductions along $\pi$ is a fixed public permutation. Its input introductions partition $\pi$ into $n$ segments, each comprising one input introduction followed by zero or more gates before the next introduction. Let $w_i$ be the number of live wires at the end of segment $i$, so $w_i\le w$.

\paragraph{Theorem 4 (end-to-end supplied-frontier transfer).}
For every valid $(C,\pi)$ as above there is a \emph{uniform}, fully charged compiler to the source class of Lemma 1, with $n$ stages, $s=w$ persistent bits, and a total of exactly $g$ original combinational gate records across all stage DAGs. Each stage retains at most $w$ wire-value slots and shares each original gate once. There is an explicitly materialized complete leveled OBDD with
\[
V\le n2^w
\]
distinct internal nodes and two arcs per node. It computes $f_C(x)$ for every $x$ and, when parallel arcs and merged paths are counted with multiplicity, its accepting-path count equals $\#\{x:f_C(x)=1\}$. For each prefix of $\rho$,
\[
\operatorname{rank}_K M_{\rho_{\le i},\rho_{>i}}(f_C)
\le 2^{w_i}\le2^w
\]
over every field $K$. Thus a rank-$R$ prefix forces $w(\pi)\ge\lceil\log_2R\rceil$ for \emph{that supplied schedule}; it does not force large size or work for arbitrary circuits.

\emph{Proof.} At the start of each segment, assign the previous boundary's live signals to its persistent register slots. The newly read $x_{\rho(i)}$ and the segment's original gates form a shared DAG with the original binary truth tables and predecessor IDs. An earlier predecessor not local to the segment must still be live, since the current gate is a future use; hence it has a register slot. Evaluate the original segment in topological order, retaining precisely its final live signals. Induction on \emph{each original schedule vertex}, rather than only segment boundaries, gives identical source and compiled intermediate gate values and identical retained bits. At termination the output pseudo-use retains the original designated output, giving both accepting and rejecting correspondence. One temporary gate-result bit may be needed \emph{inside} a stage in addition to the $w$ inter-stage bits and is charged separately.

The public stage input sequence $\rho$ is fixed and read-once. For each layer and reachable $w$-bit register, add both genuine binary successors and merge equal next-layer register values. There are at most $2^w$ values at a layer. Every original assignment induces exactly one length-$n$ path, and the reverse path labels uniquely determine its assignment. Merging equal states therefore preserves \emph{path multiplicities} and exact count, not just reachability. After prefix $i$, any remaining computation is determined by the boundary register and public stage number, so there are at most $2^{w_i}$ distinct suffix cofactors, yielding the rank bound. \hfill$\square$

B=O\bigl(L+(g+nw+n)\lceil\log_2(M+w+2)\rceil\bigr)

T_{\rm total}=O(D^5+n^2),\qquad S_{\rm peak}=O(D).

\paragraph{Theorem 5 (uniform no-advice tree-to-OBDD transfer, known tree ordering plus restricted new integration).}
Define the Sethi--Ullman/Ershov label $r(x_i)=1$ and for gate $v=\tau(a,b)$,
\[
r(v)=\begin{cases}r(a)+1,&r(a)=r(b),\\
\max\{r(a),r(b)\},&r(a)\ne r(b).
\end{cases}
\]
A fixed compiler authenticates the complete tree, computes the labels in postorder, and emits the larger-labeled child subtree first (fixed tie rule), then the other child subtree, then the original gate. Let $w$ be maximum live original-wire frontier of this \emph{constructed} topological schedule, counting the root pseudo-output use. Then
\[
w=r(\mathrm{root})\le1+\lfloor\log_2n\rfloor,\qquad
V\le n2^w\le2n^2.
\]
Every original input is read exactly once in the \emph{computed} permutation $\rho$, which may begin with an input other than $x_0$. The first-$x_0$ convention in the earlier \emph{test harness} is not a mathematical hypothesis of the all-step simulation proof: actual original input labels are retained as stage selectors, and physical input seeks are charged. Source and target agree after every original gate and at both terminal labels, with exact assignment-count preservation when parallel arcs of merged branching-program states retain multiplicity. For each actual prefix cut,
\[
\operatorname{rank}_K M_{\rho_{\le i},\rho_{>i}}(f_C)
\le2^{w_i}
\]
over every field $K$. Thus the source's \emph{particular once-only structural schedule} has $w_i\ge\lceil\log_2\operatorname{rank}_K M_i\rceil$, but this is not a source circuit-size or all-algorithm time lower bound.

\emph{Proof.}
The label recurrence and larger-child-first optimality for disjoint computation trees are the classical Sethi--Ullman tree theorem. A completed child result must be carried while the other subtree is evaluated; the two candidate peaks are $\max(r(a),1+r(b))$ and $\max(r(b),1+r(a))$. The tree exchange lemma removes any beneficial interleaving. A label-$k$ tree has at least $2^{k-1}$ leaves by induction, proving the logarithmic upper bound. The emitted order is topological by structural induction; at each original gate, authentic predecessors are present locally or in the computed live frontier. The prior all-step proof of Theorem 4 therefore applies with the actual input permutation rather than a prescribed $x_0$ first. Stage state identity includes the complete retained frontier. Both outgoing labelled arcs remain even when their successor is shared, yielding a bijection between original assignments and complete labelled target paths. Row factorization through at most $2^{w_i}$ registers yields the rank claim. \hfill$\square$

\paragraph{An independently cheaper exact-count algorithm and a genuine all-chain shortcut.}
Every child pair has disjoint original variable sets, so store exact counts $(c_0,c_1)=(1,1)$ for a leaf and for truth table $\tau$ compute
\[
c_z(v)=\sum_{\tau(i,j)=z}c_i(a)c_j(b).
\]
Each count fits in $n+1$ bits; the root's $c_1$ is $\#C$. This does not materialize an OBDD. In particular a balanced AND formula on $n=2^k$ distinct leaves requires $k+1$ \emph{structural nonrecomputing live values} under any topological evaluation of that tree, but its Boolean function is simply $\bigwedge_ix_i$ and admits a source-authenticated linear sequential input sweep with one Boolean accumulator (plus actual physical head/configuration state). The exact count is one. This \emph{legal} semantic shortcut falsifies any transfer from optimal original-tree frontier to mandatory memory of all equivalent algorithms. DISJ, equality, affine, Horn, treewidth, product, autarky, padding, selector and compact shared-circuit alternatives remain legal.

\section{Uniform no-advice shared-gate DAG transfer with long-edge spill}
\paragraph{D4-LONG-EDGE-SPILL: source construction closed, unrestricted transfer OPEN.}
The /058 theorem admitted original shared-gate DAGs only when every gate edge
joined consecutive depth layers and every input was used at a single layer.
The next theorem removes \emph{both} restrictions for an authentic
single-output acyclic fan-in-two shared Boolean circuit, without pretending
that a low-width schedule exists for every circuit. A certified layout with
width parameter $w$ is \emph{constructed from the input}, not supplied as
an oracle, and every original fan-out object is retained only once.

\paragraph{Canonical source, domain and all-input authentication.}
The complete source is canonical ASCII JSON with exactly
\texttt{n,gates,out}. There are $n\ge1$ original input identities
$x_0,\ldots,x_{n-1}$; $g\ge1$ uniquely numbered gate identities
$g_0,\ldots,g_{g-1}$ in arbitrary record order; and a single gate output.
Each record has exactly \texttt{a,b,id,op}, with $\texttt{op}\in
\{0,\ldots,15\}$ denoting an original binary truth table. Parse the
\emph{complete} source, reject noncanonical or duplicate keys/IDs, illegal
references, disconnected/dead gates, unused inputs and cyclic graphs.
A malformed source is rejected, \emph{not} designated UNSAT. As every
valid original input is an operand of some gate and $g$ binary gates have
only $2g$ operand references, check $n\le2g$ \emph{before} allocating
$n$-indexed tables. This fixes the invalid-huge-arity defect already
detected and repaired in the /058 v2 source. No layout or promise of
adjacent gate edges is present in the input.

\paragraph{Definition (authentic discovered spill).}
Compute gate-only longest-path depth
\[
d(g)=1+\max\bigl(\{d(h):h\text{ is a gate operand of }g\}
\cup\{0\}\bigr).
\]
For an input $x$ let $\beta(x)$ be the \emph{earliest} depth of a real
gate using $x$; for a gate $g$ let $\beta(g)=d(g)$.
For every signal $v$ let $\ell(v)$ be the \emph{latest}
depth of a real consuming gate; give the designated output a terminal
pseudo-use at depth $D+1$, with $D=\max_g d(g)$.
Define $X_d=\{x:\beta(x)=d\}$,
$G_d=\{g:d(g)=d\}$ and
\[
k=\max_{1\le d\le D}\max\{|X_d|,|G_d|\}.
\]
The genuinely charged spill sets are
\[
S_d=
\{x:\beta(x)\le d-1,\ \ell(x)\ge d\}
\ \cup\
\{g:\beta(g)\le d-2,\ \ell(g)\ge d\},
\qquad c=\max_d |S_d|.
\]
In particular an input first read at depth $d-1$ but reused at depth
$d$ \emph{must be in $S_d$}. The immediately preceding
\emph{gate} layer $G_{d-1}$ is excluded from $S_d$, since it is charged
separately. A shared gate/input identity is counted once regardless
of the number of consuming wires.

\paragraph{Theorem 6 (arbitrary authentic DAG, parameterized transfer).}
For every valid source $C$ in the preceding class, there is one
uniform deterministic no-advice compiler producing a topological
schedule of the original vertices and a complete input-read-once
ordered branching program $B(C)$, whose input permutation $\rho$
is derived from $C$. For every original Boolean input assignment $a$,
the original gate values, output bit and both terminal labels are
preserved along the unique labelled path.
The accepted labelled path count is the original exact count
$\#C=\#\{a:f_C(a)=1\}$, \emph{including} parallel labelled
arcs to merged successors. With $w$ the actual maximum number
of distinct retained source signals needed after any schedule event,
\[
\boxed{w\le c+3k,\qquad
V(B(C))\le n2^w\le n2^{c+3k}.}
\]
For every field $K$ and every prefix $j$ of the discovered order,
\[
\operatorname{rank}_K M_{\rho_{\le j}:\rho_{>j}}(f_C)
\le \#\{\text{reachable boundary tuples at }j\}\le2^w.
\]
This is a representation/source-\emph{schedule} bound, not a
lower bound on the resources of all equivalent circuits or SAT deciders.

\emph{Proof.} Emit each $x\in X_d$ once in numeric order, then
each $g\in G_d$ once in numeric order, for increasing $d$.
Every real gate predecessor has strictly smaller depth, and every
original input's first use is no later than each gate consuming it:
thus every original operand precedes its genuine gate evaluation.
Retain a distinct value until its \emph{last actual consumer};
only the designated output survives to final emission.
At any intermediate position in depth $d$, every retained original
signal lies in one of the four real categories $S_d,G_{d-1},X_d,G_d$.
Their cardinalities are at most $c,k,k,k$, proving the width bound.
Temporary physical Boolean-gate scratch adds at most a constant number
of machine cells, not extra original source-signal identities.

Induct on all $n+g$ original schedule events. Introducing an input
stores its actual assigned bit. Evaluating a gate reads both present
authentic operands and applies its original truth table, then retires
only values whose final use is complete. Its result therefore equals
the original gate DAG value on \emph{every} assignment, including
repeated inputs and reconvergent shared values. Collapse intervening
gate-only events into the input-read stages. The retained tuple
determines every future source step, so there are at most $2^w$
states in each of $n$ input layers; materialize both genuine $0$ and
$1$ arcs from every reachable state, even when they have the same
successor. The input order visits all original $n$ identities exactly
once and induces a bijection from full source assignments to labelled
complete target paths. Thus both output bits and exact count agree.
After any prefix the suffix function is completely determined by
the actual boundary tuple; rows of the original assignment matrix

\section{Depth-heavy DFS: no-advice low-congestion shared-DAG family /060}

\paragraph{No-advice schedule theorem and proof.}
Compute the longest original gate-predecessor depth $d(v)$ from the
authenticated source, taking $d(x_j)=0$. Starting at its output, visit
actual predecessors in decreasing $d$, breaking ties by original
identity; emit each source identity once \emph{after} its authentic
predecessors. At each stage the deeper accumulator chain is visited
before the local shallow $h_i$. Thus the emitted sequence processes
the genuine four-gate modules consecutively, including each pair of
original inputs only when the module is reached.
After any authentic event the retained original-signal set has size
at most three: previous accumulator plus at most two new input bits;
after computing $h_i$ the two input identities expire, after
$p_i$ the possible triple is $(a_{i-1},h_i,p_i)$, after $q_i$
the first two identities expire, and after $a_i$ the two
intermediate gates expire. Therefore the discovered source schedule
has $w_{\rm DFS}\leq3$ for \emph{every} $m$.
In contrast, /059's genuine depth ordering introduces all $2m$
fresh pair-input values before any first-depth $h_i$ gate, so its
retained width satisfies $w_{\rm depth}\geq2m$. This lower bound
is for that particular schedule, not for all equivalent algorithms.
