\section{Target, status, exact model}
This is a coherent restricted end-to-end pipeline from an explicitly encoded shared Boolean gate program to an adaptive shared read-once branching program (FBDD), its assignment-matrix rank, and a proved source-register implication. Semantic preservation and the scoped rank bound are PROVED/EXACT, with independent mathematical review OPEN. Finite checks are COMPUTATIONAL. Arbitrary circuit-to-register translation, general SAT-time lower bounds, and P versus NP remain OPEN.

Fix $n,s\geq1$. The source has original inputs $x\in\{0,1\}^n$, $s$ retained register bits, initial register $r_0$, and precisely $n$ stages. Each stage has a topologically ordered shared fan-in-two Boolean truth-table gate DAG which selects an index $j_t$ \emph{before} inspecting its value and updates $r_{t+1}=U_t(r_t,x_{j_t})$. The selector is independent of the unread bit on all reachable states, and no index is repeated along any path. After stage $n$ a shared Boolean DAG returns the one-bit answer $h(r_n)$. The finite encoding is canonical ASCII JSON with fields for version, dimensions, initial register, stages, and terminal circuit, and binary gate records $(a,b,\tau)$ for any of the 16 binary truth tables. Shared fan-out, repeated operands, constants and adaptive choice are allowed. The compiler rejects malformed encodings and reachable read-once or pre-read-selector violations. Let $L$ count the entire source encoding in bits.

The named dependency is D4-COMPILER: encoding and authentication $\longrightarrow$ paid full-history construction $\longrightarrow$ adaptive FBDD $\longrightarrow$ exact field-rank transfer $\longrightarrow$ lower bound on the declared SOURCE persistent bits. Falsifiers tested include DISJ's cheap interleaving, hidden input reinspection, incorrectly merging distinct read masks, and unpaid fan-out or graph construction. This does not assume all circuits admit low-cost streaming encodings.

\section{All-step compiler and semantic proof}
A validation history is $(t,r,m)$, with $m\subseteq[n]$ the inspected set. The compiler starts at $(0,r_0,\varnothing)$; at each reachable history it evaluates the real stage DAG for each hypothetical $z\in\{0,1\}$, checks that both choose the same $j<n$ and $j\notin m$, and follows
\[
(t,r,m)\xrightarrow{z}(t+1,U_t(r,z),m\cup\{j\}).
\]
For terminal histories it evaluates the original output DAG. A target node is identified by $(t,r)$, retaining the selected input label and two actual successor pointers. Different masks may be quotiented only because the source's future control and update depend solely on $(t,r)$ and the next tested bit. The compiler checks shared outgoing pointers for consistency.

\paragraph{Lemma 1 (pointwise costed simulation).}
Every accepted source and every $x\in\{0,1\}^n$ produce the same accept/reject bit in the source and the compiled FBDD. The FBDD is deterministic, acyclic and read-once; its distinct internal node count $V$ and the number of distinct checked histories $H$ satisfy
\[
V\leq n2^s,\qquad H\leq 2^s(2^n-1).
\]
\emph{Proof.} At $t=0$ source and target have the same register. If registers agree at $t$, the checked selector and actual source DAG select the same original input $x_j$, then the same branch computes the same successor register. Induct to $t=n$ and use the identical terminal gate DAG. The exhaustive validation checks every possible history mask, so no merged source path causes a repeat. There are at most $2^s$ registers for each of the $n$ nonterminal stages, and at most $2^s\binom nt$ histories at stage $t$. Summation yields the bounds. Each node is shared once and has exactly two outgoing arcs. \hfill$\square$

\section{Transfer back to a declared source parameter}
Let $M_{X,Y}(f)$ be the original-input assignment-evaluation matrix over any field $K$.

\paragraph{Lemma 2 (fixed-order persistent memory).}
When the indices selected by source stages are a fixed public permutation, every prefix cut of that order has
\[
\operatorname{rank}_K(M_{\mathrm{prefix},\mathrm{suffix}})\leq 2^s,
\qquad
s\geq\left\lceil\log_2\operatorname{rank}_K(M_{\mathrm{prefix},\mathrm{suffix}})\right\rceil.
\]
\emph{Proof.} After a prefix, the suffix function is entirely determined by the current $s$-bit persistent source register and public stage number. There are at most $2^s$ distinct rows. \hfill$\square$

\paragraph{Lemma 3 (adaptive side switches).}
Partition the original variables $X\sqcup Y=[n]$, and let $b$ be the maximum number of changes in which side owns consecutive actual tests. Then
\[
R=\operatorname{rank}_K M_{X,Y}
\leq\sum_{j=0}^{b}V^j
\leq\sum_{j=0}^{b}(n2^s)^j.
\]
For $b\geq1$, $\log_2R\leq\log_2(b+1)+b(\log_2 n+s)$; for $b=0$, $R\leq1$.
\emph{Proof.} The current side owner simulates maximal local segments of the actual shared FBDD and sends the switch-destination node ID upon each change of owner. For a fixed accepting transcript the $X$-only segments constrain only $X$ and the $Y$-only segments constrain only $Y$. Accepted inputs producing that transcript form a Cartesian rectangle, whose matrix has rank at most one over $K$. Deterministic transcripts partition the accepting inputs; at most $V^j$ transcripts have $j$ switches. Sum the rectangle matrices. This is the TMR-4/053 factorization now attached to a genuine source compiler. \hfill$\square$

The conclusion bounds the declared persistent inter-stage register bits and the number of actual source owner switches. It does not bound all intra-stage gate buffers, the cost of arbitrary circuit evaluation, or general SAT decision time. A direct cheap computation is always legal.

\section{Single-realization cost ledger}
Let $G_{\max}$ denote maximum stage/terminal gate count. Every stage DAG is stored with source sharing preserved; it is evaluated for both hypothetical bit outcomes at each checked history, with all source wire indexes, arithmetic, fan-out, failed paths, cache lookups and output charged. A fixed deterministic multitape implementation with conservative sequential table scans has joint live bit budget
\[
D=L+O\bigl(H(n+s+\log(H+2))+V(n+s+\log(V+2))\bigr)
\]
covering source storage, validation queue, history masks, output-node IDs, gate buffers, addresses, both arcs of each shared node and fully serialized output. An ordinary compiler followed by one physical target evaluation on the SAME execution admits
\[
T_{\rm total}=O\bigl((H(G_{\max}+n+s+1)+1)D^2+nD+n^2\bigr),
\quad S_{\rm peak}=O(D).
\]
Here $D^2$ pays for deliberately naive bit-address and table searches, $nD$ pays for target-node accesses and $n^2$ pays for physical input-head motion. The packed BP output has $O(V(\log n+\log(V+2)))$ bits. The source itself retains $s$ inter-stage bits but may need $G_{\max}$ temporary intra-stage gate bits, plus source-ROM/address storage. No time lower bound or polynomial-time general-circuit compiler is claimed; $H$ is potentially exponential. Network aggregate memory and total work are never replaced by span or per-worker memory.
